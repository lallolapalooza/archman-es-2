SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq keyring filter - Unir claves en un llavero aplicando un filtro

SINOPSIS

sq keyring filter [OPCIONES] ARCHIVO

DESCRIPCIÓN

Unir claves en un llavero aplicando un filtro.

Esto se puede usar para filtrar claves basándose en predicados dados, por ejemplo, si tienen un ID de usuario que contiene una dirección de correo electrónico con un dominio específico. Adicionalmente, las claves pueden ser podadas para incluir solo componentes que coincidan con los predicados.

Si no se proporcionan filtros, todo coincide.

Si se dan múltiples predicados, estos se combinan con "OR", es decir, una clave coincide si alguno de los predicados coincide. Para requerir que todos los predicados coincidan, encadene múltiples invocaciones de este comando. Vea EJEMPLOS para inspiración.

Nota: este comando se considera experimental y puede cambiar en futuras versiones. Para reconocer esto, debe proporcionar la bandera `--experimental` al invocar este comando.

OPCIONES

Opciones de subcomando

--cert=HUella|ID_CLAVE
Coincidir en huellas de certificados y IDs de clave
Coincidir en claves primarias, incluyendo aquellos certificados que coincidan con la huella o ID de clave dada.
--domain=FQDN
Coincidir en dominio de correo electrónico FQDN
Analiza los IDs de usuario en nombre y dirección de correo electrónico y coincide de forma sensible a mayúsculas y minúsculas en el dominio de la dirección de correo electrónico, requiriendo una coincidencia exacta.
--email=DIRECCION
Coincidir en la dirección de correo electrónico DIRECCION
Analiza los IDs de usuario en nombre y dirección de correo electrónico y coincide de forma sensible a mayúsculas y minúsculas en la dirección de correo electrónico, requiriendo una coincidencia exacta.
--experimental
Optar por usar una función experimental
Este comando se considera experimental y puede cambiar en futuras versiones. Para reconocer esto, debe proporcionar la bandera `--experimental` al invocar este comando.
En el futuro, podemos estabilizar este comando. Cuando eso suceda, `--experimental` ya no será requerido, pero se ignorará silenciosamente.
--key=HUella|ID_CLAVE
Coincidir en huellas y IDs de clave (sub)clave
Coincidir en claves primarias y subclaves, incluyendo aquellos certificados que coincidan con la huella o ID de clave dada.
--name=NOMBRE
Coincidir en el NOMBRE
Analiza los IDs de usuario en nombre y correo electrónico y coincide de forma sensible a mayúsculas y minúsculas en el nombre, requiriendo una coincidencia exacta.
--output=ARCHIVO
Escribir en ARCHIVO o stdout si se omite
[predeterminado: -]
--prune-certs
Eliminar componentes de certificado que no coincidan con el filtro
--to-cert
Convertir cualquier clave de entrada en certificados
Convertir una clave en un certificado elimina el material de clave secreta de la clave, convirtiéndola así en un certificado.
--userid=ID_USUARIO
Coincidir en ID_USUARIO
Coincide de forma sensible a mayúsculas y minúsculas en el ID de usuario, requiriendo una coincidencia exacta.

ARCHIVO
Leer desde ARCHIVO o stdin si se omite

Opciones globales

Vea sq(1) para una descripción de las opciones globales.

EJEMPLOS

Convertir todas las claves a certificados (es decir, eliminar cualquier material de clave secreta).

sq keyring filter --experimental --to-cert certs.pgp

Obtener todos los certificados con un ID de usuario en example.org.

sq keyring filter --experimental --domain=example.org \
certs.pgp

Obtener todos los certificados con un ID de usuario en example.org o example.net.

sq keyring filter --experimental --domain=example.org \
--domain=example.net certs.pgp

Obtener todos los certificados con un ID de usuario de nombre que coincida con Romeo.

sq keyring filter --experimental --name=Romeo certs.pgp

Obtener todos los certificados con un ID de usuario de nombre que coincida con Romeo en example.org.

sq keyring filter --experimental --domain=example.org \
certs.pgp \
| sq keyring filter --experimental --name=Romeo

Obtener todos los certificados con un ID de usuario en example.org, poda otras IDs de usuario.

sq keyring filter --experimental --domain=example.org \
--prune-certs certs.pgp
