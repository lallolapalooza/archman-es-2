SQFSCAT(1) Comandos de Usuario SQFSCAT(1)

NOMBRE

sqfscat - herramienta para volcar archivos de un sistema de archivos squashfs a la salida estándar

SINOPSIS

sqfscat [OPCIONES] SISTEMA_DE_ARCHIVOS [lista de archivos para volcar a la salida estándar]

DESCRIPCIÓN

Squashfs es un sistema de archivos de solo lectura altamente comprimido para Linux. Utiliza compresión gzip/xz/lzo/lz4/zstd para comprimir tanto archivos como inodos y directorios. Los inodos en el sistema son muy pequeños y todos los bloques se empaquetan para minimizar la sobrecarga de datos. Se admiten tamaños de bloque mayores que 4K hasta un máximo de 1Mbyte (tamaño de bloque predeterminado de 128K).

Squashfs está destinado al uso general de sistemas de archivos de solo lectura, para uso de archivo (es decir, en casos donde se podría usar un archivo .tar.gz) y en sistemas de dispositivos de bloque/memoria restringidos (por ejemplo, sistemas integrados) donde se necesita una sobrecarga baja.

OPCIONES

Opciones de tiempo de ejecución:

-v, -version
imprimir información de versión, licencia y derechos de autor.
-p NÚMERO, -processors NÚMERO
usar NÚMERO procesadores. Por defecto, usará el número de procesadores disponibles.
-mem TAMAÑO
usar TAMAÑO de memoria física para cachés. Use K, M o G para especificar Kbytes, Mbytes o Gbytes respectivamente. Por defecto 512 Mbytes.
-mem-percent PORCENTAJE
usar PORCENTAJE de memoria física para cachés.
-o BYTES, -offset BYTES
saltar BYTES al inicio de SISTEMA_DE_ARCHIVOS. Opcionalmente se puede dar un sufijo de K, M o G para especificar Kbytes, Mbytes o Gbytes respectivamente (predeterminado 0 bytes).
-ig, -ignore-errors
tratar los errores al escribir archivos a la salida estándar como no fatales.
-st, -strict-errors
tratar todos los errores como fatales.
-no-exit, -no-exit-code
no establecer el código de salida (a distinto de cero) en errores no fatales.

Opciones de filtro:

-no-wild, -no-wildcards
no usar coincidencia de comodines en nombres de archivo.
-r, -regex
tratar los nombres de archivo como expresiones regulares POSIX en lugar de usar la expansión de comodines del shell (globbing) predeterminada.

Opciones de ayuda:

-h, -help
imprimir resumen de ayuda al paginador (o salida estándar si no es un terminal).
-help-option REGEX
imprimir la información de ayuda para opciones que coincidan con REGEX al paginador (o salida estándar si no es un terminal).
-help-section SECCIÓN
imprimir la información de ayuda para la SECCIÓN al paginador (o salida estándar si no es un terminal). Si SECCIÓN no coincide exactamente con un nombre de sección, se trata como una expresión regular y se muestran todos los nombres de sección que coincidan. Use "list" como nombre de sección para obtener una lista de secciones y sus nombres.
-help-all
imprimir la información de ayuda para todas las opciones y secciones de Sqfscat al paginador (o salida estándar si no es un terminal).
-ho REGEX
alternativa abreviada a -help-option.
-hs SECCIÓN
alternativa abreviada a -help-section.
-ha
alternativa abreviada a -help-all.
-no-pager
no usar un paginador para la salida de información de ayuda.
-cols ANCHO
usar ANCHO columnas para la salida de información de ayuda. Útil si la salida no es a un terminal.

ESTADO DE SALIDA

0
El archivo o archivos se volcaron a la salida estándar correctamente.
1
Ocurrieron errores FATALES, por ejemplo, corrupción del sistema de archivos, errores de E/S. Sqfscat no continuó y abortó.
2
Ocurrieron errores no fatales, por ejemplo, no es un archivo regular, o no se pudo resolver la ruta. Sqfscat continuó y no abortó.

Vea las opciones -ignore-errors, -strict-errors y -no-exit-code para ver cómo afectan el estado de salida.

DESCOMPRESORES DISPONIBLES

gzip, lzo, lz4, xz, zstd, lzma

ENTORNO

SQFS_CMDLINE
Si se establece, se utiliza como directorio para escribir el archivo sqfs_cmdline, que contiene los argumentos de la línea de comandos dados a Sqfscat. Cada argumento de línea de comandos se envuelve entre comillas para garantizar que no haya ambigüedades cuando los argumentos contienen espacios. Si el archivo ya existe, se añade la línea de comandos al archivo.
PAGER
Si se establece, se utiliza como nombre del programa que se usará para mostrar el texto de ayuda. El valor puede ser un comando simple o una ruta. El valor predeterminado es /usr/bin/pager.

EJEMPLOS

sqfscat IMAGEN.SQFS hola
Volcar el contenido de "hola" a la salida estándar.
sqfscat IMAGEN.SQFS hola mundo
Volcar el contenido de "hola" y luego "mundo" a la salida estándar.
sqfscat IMAGEN.SQFS "*.[ch]"
Volcar el contenido de todos los archivos en el directorio raíz que coincidan con el comodín *.[ch] a la salida estándar, por ejemplo, hello.c, hello.h, world.c, world.h.

Nota: al pasar nombres con comodines a Sqfscat, deben ir entre comillas (como en los ejemplos anteriores), para garantizar que no sean procesados por el shell.
