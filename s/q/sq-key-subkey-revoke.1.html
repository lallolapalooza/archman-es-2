SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-key-subkey-revoke - Revocar una subclave

SINOPSIS

sq key subkey revoke [OPCIONES]

DESCRIPCIÓN

Revoca una subclave.

Crea un certificado de revocación para una subclave.

Si se proporcionan `--revoker` o `--revoker-file`, se utiliza esa clave para crear el certificado de revocación. Si esa clave es diferente de la clave que se está revocando, esto resulta en una revocación de terceros. Esto normalmente solo es útil si el propietario del certificado designó la clave como un revocado designado.

`sq key subkey revoke` respeta la hora de referencia establecida por el argumento de nivel superior `--time`. Cuando se establece, utiliza la hora especificada en lugar de la hora actual al determinar qué claves son válidas, y establece la hora de creación del certificado de revocación a la hora de referencia en lugar de la hora actual.

OPCIONES

Opciones de subcomando

--cert=HUERLLA|IDCLAVE
Revoca las subclaves especificadas en la clave con la huella digital o ID de clave especificada
--cert-email=CORREO
Revoca las subclaves especificadas en la clave donde un ID de usuario incluye la dirección de correo especificada
--cert-file=RUTA
Revoca las subclaves especificadas en la clave leída de RUTA
--cert-userid=IDUSUARIO
Revoca las subclaves especificadas en la clave con el ID de usuario especificado
--key=HUERLLA|IDCLAVE
Revoca la subclave especificada
--message=MENSAJE
Un texto corto y explicativo
El texto se muestra a quien vea el certificado de revocación y explica por qué se ha revocado la subclave. Por ejemplo, si Alice ha creado una clave nueva, generaría un certificado de revocación `superseded` para su clave antigua, y podría incluir el mensaje "He creado una nueva subclave, por favor, actualicen el certificado."
--output=ARCHIVO
Escribe en el ARCHIVO especificado
Si no se especifica, y el certificado se leyó del almacén de certificados, importa el certificado modificado en el almacén de certificados. Si no se especifica, y el certificado se leyó de un archivo, escribe el certificado modificado en stdout.
--reason=RAZÓN
La razón de la revocación
Si la razón ocurrió en el pasado, debes especificarlo usando el argumento `--time`. Esto permite que las implementaciones de OpenPGP razonen más precisamente sobre artefactos cuya validez depende de la validez del ID de usuario.
[posibles valores: compromised, superseded, retired, unspecified]
--revoker=HUERLLA|IDCLAVE
Utiliza la clave con la huella digital o ID de clave especificado para crear el certificado de revocación
Firma el certificado de revocación usando la clave especificada. Por defecto, se utiliza el certificado que se está revocando. Usando esta opción, es posible crear una revocación de terceros.
--revoker-email=CORREO
Utiliza la clave donde un ID de usuario incluye la dirección de correo especificada para crear el certificado de revocación
Firma el certificado de revocación usando la clave especificada. Por defecto, se utiliza el certificado que se está revocando. Usando esta opción, es posible crear una revocación de terceros.
--revoker-file=RUTA
Lee la clave de RUTA para crear el certificado de revocación
Firma el certificado de revocación usando la clave especificada. Por defecto, se utiliza el certificado que se está revocando. Usando esta opción, es posible crear una revocación de terceros.
--revoker-userid=IDUSUARIO
Utiliza la clave con el ID de usuario especificado para crear el certificado de revocación
Firma el certificado de revocación usando la clave especificada. Por defecto, se utiliza el certificado que se está revocando. Usando esta opción, es posible crear una revocación de terceros.
--signature-notation NOMBRE VALOR
Añade una notación a la firma
El nombre de una notación definida por el usuario debe tener el formato `nombre@un.dominio.que.controlas.org`. Si el nombre de la notación comienza con un `!`, entonces la notación se marca como crítica. Si un consumidor de una firma no entiende una notación crítica, entonces ignora la firma. La notación se marca como legible por humanos.

Opciones globales

Ver sq(1) para una descripción de las opciones globales.

EJEMPLOS

Revocar la subclave de firma de Alice.

sq key subkey revoke \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 --reason \
retired --message "Rotación de subclave."

Revocar la subclave de firma y las subclaves de cifrado de Alice.

sq key subkey revoke \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 \
--key=74DCDEAF17D9B995679EB52BA6E65EA2C8497728 --reason \
retired --message "Rotación de subclave."
