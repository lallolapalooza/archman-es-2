NOMBRE

sqop-validate-userid - Valida un ID de usuario en un certificado OpenPGP

SINOPSIS

sqop validate-userid [--addr-spec-only] [--debug] [--validate-at] [-h|--help] <USERID> <CERTS>

DESCRIPCIÓN

Valida un ID de usuario en un certificado OpenPGP

OPCIONES

--addr-spec-only
Trata USERID como una dirección de correo electrónico y haz coincidir solo con la parte de la dirección de correo electrónico de cada ID de usuario correctamente enlazado.
--debug
Emite una salida detallada para depuración.
--validate-at <VALIDATE_AT>
Evalúa la validez del ID de usuario en la hora especificada, no en la hora actual.
-h, --help
Imprime la ayuda.
<USERID>
El ID de usuario a validar.
<CERTS>
Certificados OpenPGP de autoridad, es decir, raíces de confianza.
