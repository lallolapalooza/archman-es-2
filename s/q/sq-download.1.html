SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-download - Descargar y autenticar los datos

SINOPSIS

sq download [OPCIONES]

DESCRIPCIÓN

Descarga y autentica los datos.

Este comando descarga los datos de la URL especificada, comprueba la firma y luego autentica al firmante. Si el firmante no puede ser autenticado, los datos se eliminan, si es posible.

OPCIONES

Opciones de subcomando

--cleartext
Verificar un mensaje firmado en texto plano
--message
Verificar un mensaje firmado en línea
--output=ARCHIVO
Escribir en ARCHIVO o stdout si ARCHIVO es '-'
--signature-url=URL
URL de la firma
Usar esto cuando la firma está separada de los datos.
Si no se especifica ninguna firma, se asume que la firma está en línea.
--signatures=N
Establecer el umbral de firmas válidas a N
Si no se alcanza este umbral, el mensaje no se considerará verificado.
[por defecto: 1]
--signer=HUella_digital|ID_CLAVE
Requerir una firma de un certificado con la huella digital o ID de clave especificado
--signer-domain=DOMINIO
Requerir una firma de un certificado donde un ID de usuario incluya una dirección de correo electrónico para el DOMINIO especificado
--signer-email=CORREO_ELECTRONICO
Requerir una firma de un certificado donde un ID de usuario incluya la dirección de correo electrónico especificada
--signer-file=RUTA
Requerir una firma de un certificado leído desde RUTA
--signer-userid=ID_USUARIO
Requerir una firma de un certificado con el ID de usuario especificado
--url=URL
Los datos a descargar

Opciones globales

Vea sq(1) para una descripción de las opciones globales.

EJEMPLOS

Descargar y verificar el archivo de sumas de verificación de Debian 12.

sq download --url=file://debian/SHA512SUMS \
--signature-url=file://debian/SHA512SUMS.sign \
--signer=DF9B9C49EAA9298432589D76DA87E80D6294BE9B \
--output=SHA512SUMS
