NOMBRE

sq-network-dane-search - Recuperar certificados usando DANE

SINOPSIS

sq network dane search [OPCIONES] DIRECCIÓN

DESCRIPCIÓN

Recuperar certificados usando DANE.

Por defecto, todos los certificados devueltos se almacenan en el almacén de certificados local. Esto se puede anular usando la opción `--output`.

Cuando un certificado se recupera usando DANE y se importa en el almacén de certificados local, cualquier ID de Usuario con la dirección de correo electrónico que se buscó se certifica con una clave local específica de DANE. Ese certificado proxy, a su vez, se certifica como una CA mínimamente confiable (nivel de confianza: 1 de 120) por la raíz de confianza local. La confianza en la CA proxy de DANE se puede ajustar usando `sq pki link add` o `sq pki link retract` de la manera habitual.

OPCIONES

Opciones del subcomando

--all
Buscar actualizaciones para todos los certificados conocidos
--output=ARCHIVO
Escribir en ARCHIVO (o stdout si se omite) en lugar de importar en el almacén de certificados

DIRECCIÓN
Recuperar certificado(s) para DIRECCIÓN

Opciones globales

Ver sq(1) para una descripción de las opciones globales.

EJEMPLOS

Recuperar el certificado de Alice a través de DANE.

sq network dane search alice@example.org

Recuperar actualizaciones para todos los certificados conocidos a través de DANE.

sq network dane search --all

VER TAMBIÉN

sq(1), sq-network(1), sq-network-dane(1).

Para la documentación completa, consulte https://book.sequoia-pgp.org/.
