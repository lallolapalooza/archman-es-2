SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-cert - Gestionar certificados

SINOPSIS

sq cert import [OPCIONES] ARCHIVO
sq cert export [OPCIONES]
sq cert list [OPCIONES] HUELLA|IDDECLAVE|PATRÓN
sq cert lint [OPCIONES]

DESCRIPCIÓN

Gestionar certificados.

Usamos el término "certificado", o "cert" para acortar, para referirnos a claves OpenPGP que no contienen secretos. Esta suborden proporciona primitivas para generar y manipular certificados.

Por el contrario, usamos el término "clave" para referirnos a claves OpenPGP que sí contienen secretos. Ver `sq key` para operaciones con claves.

SUBORDENES

sq cert import

Importar certificados al almacén de certificados local.

sq cert export

Exportar certificados del almacén de certificados local.

Si se especifican varios predicados, se devuelve un certificado si al menos uno de ellos coincide.

Esto no comprueba la autenticidad de los certificados de ninguna manera. Antes de usar los certificados, asegúrate de validarlos y autenticarlos.

Al coincidir con subclaves o ID de usuario, el componente debe tener una autocertificación válida según la política.

Falla si se especifican criterios de búsqueda y ninguno de ellos coincide con ningún certificado. Nota: esto significa que si el almacén de certificados está vacío y no se especifican criterios de búsqueda, esto devolverá éxito.

sq cert list

Listar certificados y ID de usuario.

Lista certificados y ID de usuario que coinciden con una consulta, son utilizables y pueden ser autenticados. Por defecto, los enlaces (pares de certificado e ID de usuario) deben estar completamente autenticados. Si no coinciden certificados o enlaces con una consulta, el comando devuelve un código de salida distinto de cero.

Si no se proporcionan consultas, se listan todos los enlaces que son utilizables y pueden ser autenticados. Si no hay tales enlaces, el comando aún tiene éxito.

Por defecto, se omiten los certificados no utilizables, es decir, aquellos que no son válidos según la política, están revocados o no están activos. Del mismo modo, se omiten las autocertificaciones de ID de usuario y las certificaciones que no son válidas según la política, y los ID de usuario que están revocados.

sq cert lint

Comprobar certificados en busca de problemas.

`sq cert lint` comprueba los certificados proporcionados en busca de los siguientes problemas relacionados con SHA-1:


- Si una revocación de certificado utiliza SHA-1.


- Si la autocertificación actual para un ID de usuario no revocado utiliza SHA-1.


- Si la firma de enlace de subclave actual para una subclave no revocada y activa utiliza SHA-1.


- Si una firma de enlace de clave primaria ("backsig") para una subclave no revocada y activa utiliza SHA-1.

Los diagnósticos se imprimen en stderr. Al final, se muestran algunas estadísticas. Esto es útil al examinar un keyring. Si se especifica `--fix` y se pudo solucionar al menos un problema, los certificados corregidos se imprimen en stdout.

Esta herramienta no admite actualmente tarjetas inteligentes. Pero, si solo las subclaves están en una tarjeta inteligente, esta herramienta aún puede reparar parcialmente el certificado. En particular, podrá solucionar cualquier problema con las autocertificaciones de ID de usuario y las firmas de enlace de subclave para subclaves capaces de cifrado, pero no podrá generar nuevas firmas de enlace de clave primaria para ninguna subclave capaz de firma.

EJEMPLOS

sq cert import

Importar un certificado.

sq cert import juliet.pgp

sq cert export

Exportar certificados con un ID de usuario que contenga la dirección de correo electrónico.

sq cert export --cert-email=alice@example.org

Exportar certificados que contengan un ID de usuario con *alguna* (¡no ambas!) de las direcciones de correo electrónico.

sq cert export --cert-email=alice@example.org \
--cert-email=bob@example.org

Exportar todos los certificados.

sq cert export --all

sq cert list

Listar todos los enlaces para ID de usuario que contengan una dirección de correo electrónico de example.org y que puedan ser autenticados.

sq cert list @example.org

Listar todos los enlaces autenticados para ID de usuario que contengan una dirección de correo electrónico específica.

sq cert list --cert-email=alice@example.org

Listar todas las rutas hacia certificados que contengan una dirección de correo electrónico específica.

sq cert list --gossip --show-paths \
--cert-email=alice@example.org

sq cert lint


Recopilar estadísticas sobre los certificados en un keyring.

sq cert lint --cert-file certs.pgp

Corregir una clave con problemas conocidos.

sq key export --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
| sq cert lint --fix --cert-file=- \
| sq cert import
