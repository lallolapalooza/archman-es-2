NOMBRE

sq-packet-dearmor - Convertir ASCII a binario

SINOPSIS

sq packet dearmor [OPCIONES] ARCHIVO

DESCRIPCIÓN

Convierte ASCII a binario.

Para que los datos cifrados sean más fáciles de manejar y transportar, los datos OpenPGP pueden transformarse a una representación ASCII llamada ASCII Armor. sq maneja datos encriptados de forma transparente, pero este subcomando puede usarse para convertir explícitamente datos OpenPGP codificados en ASCII a su representación binaria.

La operación inversa es `sq packet armor`.

OPCIONES

Opciones del subcomando

--output=ARCHIVO
Escribe en ARCHIVO o en la salida estándar si se omite
[por defecto: -]

ARCHIVO
Lee desde ARCHIVO o desde la entrada estándar si ARCHIVO es '-'
[por defecto: -]

Opciones globales

Vea sq(1) para una descripción de las opciones globales.

EJEMPLOS

Convierte un mensaje OpenPGP en ASCII Armor a un mensaje OpenPGP binario.

sq packet dearmor --output=mensaje.bin mensaje.pgp

VER TAMBIÉN

sq(1), sq-packet(1).

Para la documentación completa vea https://book.sequoia-pgp.org/.
