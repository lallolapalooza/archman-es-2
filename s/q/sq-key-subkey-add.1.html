NOMBRE

sq-key-subkey-add - Añadir una subclave a un certificado

SINOPSIS

sq key subkey add [OPCIONES]

DESCRIPCIÓN

Añade una nueva subclave a un certificado.

Una subclave tiene una o más capacidades.

`--can-sign` establece la capacidad de firma, y significa que la clave puede ser usada para firmar. `--can-authenticate` establece la capacidad de autenticación, y significa que la clave puede ser usada para autenticación (por ejemplo, como una clave SSH). `--can-certify` establece la capacidad de certificación, y significa que la clave puede ser usada para hacer certificaciones de terceros. Estas capacidades pueden combinarse.

`--can-encrypt=storage` establece la capacidad de cifrado de almacenamiento, y significa que la clave puede ser usada para cifrado de almacenamiento. `--can-encrypt=transport` establece la capacidad de cifrado de transporte, y significa que la clave puede ser usada para cifrado de transporte. `--can-encrypt=universal` establece ambas capacidades de cifrado, de almacenamiento y de transporte, y significa que la clave puede ser usada tanto para cifrado de almacenamiento como de transporte. Las capacidades de cifrado no deben combinarse con las capacidades de firma o autenticación.

Normalmente, `sq` solicita al usuario una contraseña para usar al cifrar el material de la clave secreta. La contraseña para la nueva subclave puede ser diferente de las otras claves. Al usar `--without-password`, `sq` no solicita una contraseña y no protege la subclave con contraseña.

Por defecto, una nueva subclave no expira por sí misma. Sin embargo, su período de validez está limitado por el del certificado. Usar el argumento `--expiration` permite establecer una fecha de expiración diferente.

`sq key subkey add` respeta el tiempo de referencia establecido por el argumento de nivel superior `--time`. Establece el tiempo de creación de la subclave a la hora especificada.

OPCIONES

Opciones de subcomando

--can-authenticate
Añadir una subclave con capacidad de autenticación
--can-encrypt=PROPÓSITO
Añadir una subclave con capacidad de cifrado [por defecto: universal]
Las subclaves con capacidad de cifrado pueden ser marcadas como adecuadas para cifrado de transporte, cifrado de almacenamiento, o ambas, es decir, universal.
[valores posibles: transport, storage, universal]
--can-sign
Añadir una subclave con capacidad de firma
--cert=HUella_DIGITAL|ID_CLAVE
Añadir una subclave a la clave con la huella digital o ID de clave especificado
--cert-email=EMAIL
Añadir una subclave a la clave donde un ID de usuario incluya la dirección de correo electrónico especificada
--cert-file=RUTA
Añadir una subclave a la clave leída desde RUTA
--cert-userid=ID_USUARIO
Añadir una subclave a la clave con el ID de usuario especificado
--cipher-suite=SUITE_CIFRADO
Seleccionar los algoritmos criptográficos para la subclave
El valor por defecto puede ser cambiado en el archivo de configuración usando la configuración `key.generate.cipher-suite`.
[por defecto: cv25519]
[valores posibles: rsa2k, rsa3k, rsa4k, cv25519]
--expiration=EXPIRACIÓN
Establece la hora de expiración
EXPIRACIÓN es una fecha en formato ISO 8601 con hora opcional o una duración personalizada. Una duración tiene el formato `N[ymwds]`, donde las letras representan años, meses, semanas, días y segundos, respectivamente. Alternativamente, la palabra clave `never` no establece una hora de expiración.
[por defecto: never]
--new-password-file=ARCHIVO_CONTRASEÑA
Archivo que contiene la contraseña para cifrar el material de la clave secreta
Tenga en cuenta que todo el archivo de clave se usará como contraseña, incluyendo cualquier espacio en blanco circundante como un salto de línea final.
--output=ARCHIVO
Escribir en el ARCHIVO especificado
Si no se especifica, y el certificado fue leído desde el almacén de certificados, importa el certificado modificado en el almacén de claves. Si no se especifica, y el certificado fue leído desde un archivo, escribe el certificado modificado en la salida estándar.
--without-password
No proteger el material de la clave secreta de la subclave con una contraseña

Opciones globales

Vea sq(1) para una descripción de las opciones globales.

EJEMPLOS

Añadir una nueva subclave con capacidad de firma a la clave de Alice.

sq key subkey add --can-sign \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0
