SQRT14

Documentación de Función/Subrutina

real function sqrt14 (character trans, integer m, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldx, * ) x, integer ldx, real, dimension( lwork ) work, integer lwork)

SQRT14

Propósito:

!>
!> SQRT14 comprueba si X está en el espacio de filas de A o A'. Lo hace
!> escalando tanto X como A para que sus normas estén en el rango
!> [sqrt(eps), 1/sqrt(eps)], luego computando una factorización QR de [A,X]
!> (si TRANS = 'T') o una factorización LQ de [A',X]' (si TRANS = 'N'),
!> y devolviendo la norma del triángulo final, escalada por
!> MAX(M,N,NRHS)*eps.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transpuesta, comprobar si X está en el espacio de filas de A
!>          = 'T':  Transpuesta, comprobar si X está en el espacio de filas de A'.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de X.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>          La matriz A de M por N.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>

X

!>          X es array REAL, dimensión (LDX,NRHS)
!>          Si TRANS = 'N', la matriz X de N por NRHS.
!>          Si TRANS = 'T', la matriz X de M por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.
!>

WORK

!>          WORK es array REAL dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          longitud del array de espacio de trabajo requerido
!>          Si TRANS = 'N', LWORK >= (M+NRHS)*(N+2);
!>          si TRANS = 'T', LWORK >= (N+NRHS)*(M+2).
!>
