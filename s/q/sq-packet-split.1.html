SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-packet-split - Dividir un mensaje en paquetes

SINOPSIS

sq packet split [OPCIONES] ARCHIVO

DESCRIPCIÓN

Dividir un mensaje en paquetes.

Dividir una secuencia de paquetes en paquetes individuales, y luego recombinarlos libremente con `sq packet join` es una excelente manera de experimentar con datos OpenPGP.

Por defecto, los paquetes se escriben en la salida estándar como una secuencia de bloques codificados en ASCII. Es posible editar este archivo directamente (por ejemplo, moviendo, añadiendo o eliminando paquetes), y luego usar `sq packet join` para ensamblar el flujo.

Alternativamente, si se proporciona `--output-prefix`, los paquetes se escriben en archivos individuales que comienzan con el prefijo, y se pueden reensamblar con `sq packet join`.

La operación inversa es `sq packet join`.

OPCIONES

Opciones del subcomando

--binary
Emitir datos binarios
--output=ARCHIVO
Escribir en ARCHIVO o en la salida estándar si se omite
--output-prefix=PREFIJO
Escribir paquetes en archivos individuales que comienzan con el prefijo dado.
Los nombres de archivo se forman uniendo el prefijo, la ruta del paquete en el objeto fuente (recuerde: los paquetes pueden estar anidados) y un tipo de paquete legible con guiones ('-').

ARCHIVO
Leer desde ARCHIVO o desde la entrada estándar si ARCHIVO es '-'
[predeterminado: -]

Opciones globales

Consulte sq(1) para una descripción de las opciones globales.

EJEMPLOS

Dividir un certificado en paquetes individuales impresos en la salida estándar.

sq packet split --output=- juliet.pgp

Dividir un mensaje firmado en línea en paquetes individuales escritos en archivos separados con el prefijo 'packet'.

sq packet split --output-prefix packet document.pgp

Luego, reensamblar el mensaje, transformándolo en un mensaje firmado de estilo antiguo con una firma de prefijo.

sq packet join --output prefix-signature.pgp --label message \
packet-2-Signature-Packet packet-1-Literal-Data-Packet

VER TAMBIÉN

sq(1), sq-packet(1).

Para la documentación completa, consulte https://book.sequoia-pgp.org/.
