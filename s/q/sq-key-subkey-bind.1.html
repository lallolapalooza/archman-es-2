NOMBRE

sq-key-subkey-bind - Vincula claves de un certificado a otro

SINOPSIS

sq key subkey bind [OPCIONES]

DESCRIPCIÓN

Vincula claves de un certificado a otro.

Este comando permite al usuario adjuntar una clave principal o una subclave adjunta a un certificado a otro certificado. Digamos que quieres transicionar a un nuevo certificado, pero tienes una subclave de autenticación en tu certificado actual que quieres conservar porque permite el acceso a un servidor y la actualización de su configuración no es factible. Este comando facilita la adjunción de la subclave al nuevo certificado.

Después de la operación, la clave se vincula tanto al certificado antiguo como al nuevo. Para eliminar material de clave secreta del certificado antiguo, usa `sq key subkey delete` o `sq key delete`, según corresponda. Para revocar la subclave o clave antigua, usa `sq key subkey revoke` o `sq key revoke`, respectivamente.

OPCIONES

Opciones de subcomando

--allow-broken-crypto
Permitir adoptar claves de certificados que utilizan criptografía rota
--can-authenticate
Establecer el indicador de capacidad de autenticación
--can-encrypt=PROPÓSITO
Establecer el indicador de capacidad de cifrado
Las subclaves con capacidad de cifrado pueden marcarse como adecuadas para cifrado de transporte, cifrado de almacenamiento o ambas, es decir, universales. [predeterminado: universal]
[posibles valores: transport, storage, universal]
--can-sign
Establecer el indicador de capacidad de firma
--cannot-authenticate
No establecer el indicador de capacidad de autenticación
--cannot-encrypt
No establecer el indicador de capacidad de cifrado
--cannot-sign
No establecer el indicador de capacidad de firma
--cert=HUELLA|IDCLAVE
Añadir las subclaves especificadas a la clave con la huella digital o ID de clave especificado
--cert-email=CORREO
Añadir las subclaves especificadas a la clave donde un ID de usuario incluye la dirección de correo electrónico especificada
--cert-file=RUTA
Añadir las subclaves especificadas a la clave leída desde RUTA
--cert-userid=IDUSUARIO
Añadir las subclaves especificadas a la clave con el ID de usuario especificado
--creation-time=TIEMPO_CREACIÓN
Hacer que las subclaves enlazadas tengan el tiempo de creación especificado
Normalmente, se conserva el tiempo de creación de la clave. La excepción es si el tiempo de creación de la clave es la época Unix. En ese caso, se usa el tiempo actual.
Esta opción permite establecer el tiempo de creación de la clave a un valor especificado. Nota: cambiar el tiempo de creación de una clave también cambia su huella digital. Cambiar la huella digital hará que sea imposible buscar la clave para la verificación de firmas, por ejemplo.
--expiration=EXPIRACIÓN
Establece el tiempo de expiración
EXPIRACIÓN es una fecha en formato ISO 8601 con hora opcional o una duración personalizada. Una duración tiene el formato `N[ymwds]`, donde las letras representan años, meses, semanas, días y segundos, respectivamente. Alternativamente, la palabra clave `never` no establece un tiempo de expiración.
[predeterminado: never]
--key=CLAVE
Añadir la clave o subclave CLAVE al certificado
--output=ARCHIVO
Escribir en el ARCHIVO especificado
Si no se especifica, y el certificado se leyó del almacén de certificados, importa el certificado modificado al almacén de certificados. Si no se especifica, y el certificado se leyó de un archivo, escribe el certificado modificado en la salida estándar.

Opciones globales

Ver sq(1) para una descripción de las opciones globales.

EJEMPLOS

Vincular la subclave de autenticación antigua de Alice a su nuevo certificado.

sq key subkey bind \
--cert=C5999E8191BF7B503653BE958B1F7910D01F86E5 \
--key=0D45C6A756A038670FDFD85CB1C82E8D27DB23A1

Vincular una clave desnuda a un certificado de Alice. Una clave desnuda es una clave pública sin componentes ni firmas. Esto simplifica el trabajo con claves brutas, por ejemplo, claves generadas en una tarjeta OpenPGP, un dispositivo TPM, etc.

sq key subkey bind --keyring=bare.pgp \
--cert=C5999E8191BF7B503653BE958B1F7910D01F86E5 \
--key=B321BA8F650CB16443E06826DBFA98A78CF6562F \
--can-encrypt=universal
