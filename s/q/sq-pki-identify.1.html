NOMBRE

sq-pki-identify - Identifica un certificado

SINOPSIS

sq pki identify [OPCIONES]

DESCRIPCIÓN

Identifica un certificado.

Identifica un certificado encontrando enlaces autenticados (pares de ID de usuario y certificado).

Se devuelve un error si no se pudo autenticar ningún enlace al nivel especificado (por defecto: completamente autenticado, es decir, una cantidad de confianza de 120).

Si se pudo autenticar parcialmente un enlace (es decir, su cantidad de confianza es mayor que 0), se muestra el enlace, incluso si la confianza está por debajo del umbral especificado.

OPCIONES

Opciones del subcomando

--amount=CANTIDAD
La cantidad requerida de confianza
120 indica autenticación completa; los valores inferiores a 120 indican autenticación parcial. Cuando se pasa `--certification-network`, este valor por defecto es 1200, es decir, este comando intenta encontrar 10 rutas.
--cert=HUellaD|IDDECLAVE
Utiliza certificados con la huella digital o ID de clave especificado
--certification-network
Trata la red como una red de certificación
Normalmente, la maquinaria de autenticación trata la red Web of Trust como una red de autenticación donde una certificación solo significa que el enlace es correcto, no que el objetivo deba ser tratado como un introductor de confianza. En una red de certificación, los objetivos de las certificaciones se tratan como introductorios de confianza con profundidad infinita, y se ignoran todas las expresiones regulares. Nota: La cantidad de confianza permanece sin cambios. Así es como funcionan la mayoría de los algoritmos de búsqueda de rutas PGP.
--gossip
Trata todos los certificados como raíces de confianza no fiables
Esta opción es útil para averiguar qué piensan los demás sobre un certificado (es decir, chismes o rumores). En otras palabras, esto encuentra rutas arbitrarias a un certificado particular.
El chisme es útil para ayudar a identificar formas alternativas de autenticar un certificado. Por ejemplo, imagina que Ed quiere autenticar el certificado de Laura, pero pedirle directamente es inconveniente. Ed descubre que Micah ha certificado el certificado de Laura, pero Ed aún no ha autenticado el certificado de Micah. Si Ed está dispuesto a confiar en Micah como un introductor de confianza, y autenticar el certificado de Micah es más fácil que autenticar el certificado de Laura, entonces Ed ha aprendido una forma más fácil de autenticar el certificado de Laura.
Estable desde 1.1.0.
--show-paths
Muestra por qué se autentica un enlace
Por defecto, solo se muestra el ID de usuario y el grado de autenticación del enlace del certificado (un valor entre 0 y 120). Esto cambia la salida para mostrar también cómo se calculó ese valor mostrando las rutas desde las raíces de confianza hasta los enlaces.
--unusable
Muestra enlaces que son inutilizables
Normalmente, no se muestran los certificados y enlaces inutilizables. Esta opción considera los enlaces, incluso si no son inutilizables, porque (o los certificados) no son válidos según la política, están revocados o no están activos.
Esta opción solo tiene sentido con `--gossip`, porque los enlaces inutilizables todavía se consideran no autenticados.
Estable desde 1.1.0.

Opciones globales

Ver sq(1) para una descripción de las opciones globales.

EJEMPLOS

Identifica los ID de usuario que se pueden autenticar para el certificado.

sq pki identify --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Enumera todos los ID de usuario que han sido certificados por alguien.

sq pki identify --gossip --cert \
511257EBBF077B7AEDAE5D093F68CB84CE537C9A
