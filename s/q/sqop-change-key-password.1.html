NOMBRE

sqop-change-key-password - Actualiza la contraseña de una clave

SINOPSIS

sqop change-key-password [--debug] [--no-armor] [--new-key-password] [--old-key-password] [-h|--help]

DESCRIPCIÓN

Actualiza la contraseña de una clave.

La salida serán el mismo conjunto de Claves Secretas Transferibles de OpenPGP que la entrada, pero con todo el material de clave secreta bloqueado según la contraseña indicada por la opción `--new-key-password` (o, sin contraseña alguna, si `--new-key-password` está ausente). Tenga en cuenta que `--old-key-password` se puede proporcionar varias veces, y cada contraseña proporcionada se intentará para desbloquear cualquier material de clave bloqueado que se encuentre. Normalizará una Clave Secreta Transferible para que utilice una sola contraseña, incluso si originalmente tenía contraseñas distintas que bloqueaban cada una de las subclaves.

Si algún paquete de clave secreta está bloqueado pero no se puede desbloquear con ninguno de los argumentos `--old-key-password` proporcionados, este subcomando debería fallar con `KEY_IS_PROTECTED`.

OPCIONES

--debug
Emitir salida detallada para depuración
--no-armor
No aplicar ASCII-armor a la salida
--new-key-password <NUEVA_CONTRASEÑA_CLAVE>
La nueva contraseña con la que bloquear la clave, o simplemente desbloquear la clave si la opción está ausente
--old-key-password <ANTIGUA_CONTRASEÑA_CLAVE>
Desbloquear las claves con estas contraseñas
-h, --help
Imprimir ayuda (ver un resumen con '-h')
