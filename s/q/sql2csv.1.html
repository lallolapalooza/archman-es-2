NOMBRE

sql2csv - Documentación de sql2csv

DESCRIPCIÓN

Ejecuta comandos arbitrarios contra una base de datos SQL y muestra los resultados como un CSV:

uso: sql2csv [-h] [-v] [-l] [-V] [--db CADENA_CONEXION] [--query CONSULTA]
               [-e CODIFICACION] [-H]
               [ARCHIVO]
Ejecuta una consulta SQL en una base de datos y muestra el resultado en un archivo CSV.
argumentos posicionales:
  ARCHIVO               El archivo a usar como consulta SQL. Si ARCHIVO y --query
                        se omiten, la consulta recibe datos a través de STDIN.
argumentos opcionales:
  -h, --help            muestra este mensaje de ayuda y sale
  --db CADENA_CONEXION  Una cadena de conexión de SQLAlchemy para conectarse a una
                        base de datos.
  --engine-option OPCION_MOTOR OPCION_MOTOR
                        Un argumento de palabra clave para create_engine() de SQLAlchemy,
                        como un par separado por espacios. Esta opción puede especificarse
                        varias veces. Por ejemplo: thick_mode True
  --execution-option OPCION_EJECUCION OPCION_EJECUCION
                        Un argumento de palabra clave para execution_options() de SQLAlchemy,
                        como un par separado por espacios. Esta opción puede especificarse
                        varias veces. Por ejemplo:
                        stream_results True
  --query CONSULTA      La consulta SQL a ejecutar. Anula ARCHIVO y STDIN.
  -e CODIFICACION, --encoding CODIFICACION
                        Especifica la codificación del archivo de consulta de entrada.
  -H, --no-header-row   No mostrar nombres de columna.

EJEMPLOS

Carga datos de ejemplo en una tabla usando csvsql y luego consulta usando sql2csv:

csvsql --db "sqlite:///dummy.db" --tables "test" --insert examples/dummy.csv
sql2csv --db "sqlite:///dummy.db" --query "select * from test"

Carga datos sobre beneficiarios de ayuda financiera en PostgreSQL. Luego encuentra los tres estados que recibieron más, al mismo tiempo que filtra filas vacías:

createdb recipients
csvsql --db "postgresql:///recipients" --tables "fy09" --insert examples/realdata/FY09_EDU_Recipients_by_State.csv
sql2csv --db "postgresql:///recipients" --query "select * from fy09 where \"State Name\" != '' order by fy09.\"TOTAL\" limit 3"

Incluso puedes usarlo como una simple calculadora SQL (en este ejemplo, se utiliza una base de datos SQLite en memoria como predeterminada):

sql2csv --query "select 300 * 47 % 14 * 27 + 7000"

La cadena de conexión *acepta parámetros*. Por ejemplo, para establecer la codificación de una base de datos MySQL:

sql2csv --db 'mysql://user:pass@host/database?charset=utf8' --query "SELECT myfield FROM mytable"
