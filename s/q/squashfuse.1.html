NOMBRE

squashfuse — montar un archivo SquashFS con FUSE

SINOPSIS

squashfuse [-o opciones] archivo punto_montaje

DESCRIPCIÓN

squashfuse monta el sistema de archivos SquashFS archivo en el directorio punto_montaje. El sistema de archivos se puede desmontar usando umount(8) o fusermount(8). La implementación squashfuse es de un solo hilo.

Se admiten las opciones soportadas por la biblioteca fuse(8). Además, se admiten las siguientes opciones:

-o offset=N
desplazamiento N bytes dentro del archivo para montar
-o subdir=RUTA
montar el subdirectorio RUTA como la raíz del sistema de archivos
-o notify_pipe=RUTA
tubería con nombre que recibirá 's' (éxito) o 'f' (fallo) cuando el punto de montaje esté listo

Aquí hay una selección de opciones de la biblioteca FUSE generalmente útiles:

-h, --help
mostrar ayuda
-V, --version
mostrar la versión de FUSE
-d, -o debug
activar salida de depuración (implica -f)
-f
operación en primer plano
-o allow_other
permitir el acceso a otros usuarios
-o allow_root
permitir el acceso al superusuario

VER TAMBIÉN

fuse(8), fusermount(8), mount(8), umount(8)
