NOMBRE

sqlite3 - una interfaz para el motor de base de datos SQLite3

SINOPSIS

sqlite3 nombre_comando ?archivo?

DESCRIPCIÓN

SQLite3 es un motor de base de datos SQL autocontenido, sin configuración y transaccional. Esta extensión proporciona una interfaz fácil de usar para acceder a archivos de base de datos SQLite desde Tcl.

Para la documentación completa, consulte https://sqlite.org/ y, en particular, https://sqlite.org/tclsqlite.html.
