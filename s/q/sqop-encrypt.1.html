NOMBRE

sqop-encrypt - Cifra un Mensaje

SINOPSIS

sqop encrypt [--debug] [--no-armor] [--profile] [--as] [--with-password] [--sign-with] [--with-key-password] [--session-key-out] [-h|--help] [CERTS]

DESCRIPCIÓN

Cifra un Mensaje

OPCIONES

--debug
Emitir salida detallada para depuración
--no-armor
No blindar la salida ASCII
--profile <PERFIL>
Seleccionar el perfil a usar para cifrar
--as <AS> [por defecto: binary]
Cifrar datos binarios o texto UTF-8
--with-password <CON_CONTRASEÑA>
Cifrar con contraseñas
--sign-with <SIGN_WITH>
Claves para firmar
--with-key-password <CON_CONTRASEÑA_DE_CLAVE>
Intentar descifrar las CLAVES de firma con estas contraseñas
--session-key-out <SESSION_KEY_OUT>
Escribir la clave de sesión aquí
-h, --help
Imprimir ayuda
[CERTS]
Cifrar para estos certificados
