SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-network-dane - Recupera y publica certificados a través de DANE

SINOPSIS

sq network dane search [OPCIONES] DIRECCION
sq network dane generate [OPCIONES]

DESCRIPCIÓN

Recupera y publica certificados a través de DANE.

La Autenticación de Entidades Nombradas basada en DNS (DANE) es un método para publicar y recuperar certificados en DNS según se especifica en RFC 7929.

SUBCOMANDOS

sq network dane search

Recupera certificados usando DANE.

Por defecto, cualquier certificado devuelto se almacena en el almacén de certificados local. Esto se puede anular usando la opción `--output`.

Cuando se recupera un certificado usando DANE y se importa al almacén de certificados local, cualquier ID de usuario con la dirección de correo electrónico que se buscó se certifica con una clave local específica de DANE. Ese certificado proxy está a su vez certificado como una CA mínimamente confiable (monto de confianza: 1 de 120) por la raíz de confianza local. Cuánto se confía en la CA proxy de DANE se puede ajustar usando `sq pki link add` o `sq pki link retract` de la manera habitual.

sq network dane generate

Genera registros DANE para el dominio y los certificados dados.

Los certificados se minimizan y se emite un registro por dirección de correo electrónico. Si varios IDs de usuario se mapean a una dirección de correo electrónico, todos los IDs de usuario coincidentes se incluyen en los certificados emitidos.

Por defecto, se emiten registros de recursos OPENPGPKEY. Si su servidor DNS no los entiende, use `--type generic` para emitir registros genéricos en su lugar.

EJEMPLOS

sq network dane search

Recupera el certificado de Alice a través de DANE.

sq network dane search alice@example.org

Recupera actualizaciones para todos los certificados conocidos a través de DANE.

sq network dane search --all

sq network dane generate

Genera registros DANE a partir de juliet.pgp para example.org.

sq network dane generate --domain=example.org \
--cert-file=juliet.pgp

Genera registros DANE para todos los certificados con un ID de usuario autenticado en example.org.

sq network dane generate --domain=example.org --all
