SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-key-expire - Cambiar la fecha de caducidad de un certificado

SINOPSIS

sq key expire [OPCIONES]

DESCRIPCIÓN

Cambiar la fecha de caducidad de un certificado.

Este subcomando cambia la fecha de caducidad de un certificado. Para cambiar la fecha de caducidad de una subclave individual, utilice el subcomando `sq key subkey expire`.

OPCIONES

Opciones del subcomando

--cert=HUELLA_DIGITAL|ID_CLAVE
Cambiar la caducidad de la clave con la huella digital o ID de clave especificado.
--cert-email=CORREO
Cambiar la caducidad de la clave donde un ID de usuario incluya la dirección de correo electrónico especificada.
--cert-file=RUTA
Cambiar la caducidad de la clave leída desde RUTA.
--cert-userid=ID_USUARIO
Cambiar la caducidad de la clave con el ID de usuario especificado.
--expiration=CADUCIDAD
Establece la fecha de caducidad.
CADUCIDAD es una fecha en formato ISO 8601 con una hora opcional o una duración personalizada. Una duración tiene el formato `N[amwds]`, donde las letras representan años, meses, semanas, días y segundos, respectivamente. Alternativamente, la palabra clave `never` no establece una fecha de caducidad.
[predeterminado: never]
--output=ARCHIVO
Escribir en ARCHIVO o en stdout si se omite.

Opciones globales

Consulte sq(1) para ver una descripción de las opciones globales.

EJEMPLOS

Cambiar el certificado de Alice para que expire en un año.

sq key expire --expiration 1y --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Cambiar el certificado de Alice para que nunca expire.

sq key expire --expiration never --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0
