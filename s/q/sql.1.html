sql(1)

Paquete: parallel

Licencias: GPL-3.0-or-later

SQL(1) paralelo SQL(1)

NOMBRE

sql - ejecutar un comando en una base de datos determinada por una dburl

SINOPSIS

sql [opciones] dburl [comandos]

sql [opciones] dburl < archivo_comandos

#!/usr/bin/sql --shebang [opciones] dburl

DESCRIPCIÓN

GNU sql pretende proporcionar una interfaz sencilla y unificada para acceder a bases de datos a través de los diferentes clientes de línea de comandos de las bases de datos. Hasta ahora, el enfoque ha sido proporcionar una forma común de especificar la información de inicio de sesión (protocolo, nombre de usuario, contraseña, nombre de host y número de puerto), tamaño (tamaño de la base de datos y tabla) y ejecutar consultas.

La base de datos se aborda mediante una DBURL. Si se omiten los comandos, obtendrás el shell interactivo de esa base de datos.

GNU sql se usa a menudo en combinación con GNU parallel.

dburl
Una DBURL tiene la siguiente sintaxis: [sql:]proveedor:// [[usuario][:contraseña]@][host][:puerto]/[base_de_datos][?consulta_sql]

Ver la sección DBURL a continuación.

comandos
Los comandos SQL a ejecutar. A cada argumento se le añadirá una nueva línea.

Ejemplo: "SELECT * FROM foo;" "SELECT * FROM bar;"

Si los argumentos contienen '\n' o '\x0a', se reemplazarán por una nueva línea:

Ejemplo: "SELECT * FROM foo;\n SELECT * FROM bar;"

Si no se proporcionan comandos, SQL se lee desde el teclado o desde STDIN.

Ejemplo: echo 'SELECT * FROM foo;' | sql mysql:///

--csv
Salida CSV.
--db-size
--dbsize
Tamaño de la base de datos. Muestra el tamaño de la base de datos en disco. Para Oracle, esto requiere acceso para leer la tabla dba_data_files; el usuario system tiene ese acceso.
--help
-h
Imprime un resumen de las opciones para GNU sql y sale.
--html
Salida HTML. Activa la salida tabular en formato HTML.
--json
--pretty
Salida JSON formateada (pretty).
--list-databases
--listdbs
--show-databases
--showdbs
Lista las bases de datos (espacios de tabla) en la base de datos.
--listproc
--proclist
--show-processlist
Muestra la lista de consultas en ejecución.
--list-tables
--show-tables
--table-list
Lista las tablas en la base de datos.
--noheaders
--no-headers
-n
Elimina encabezados y pies de página e imprime solo tuplas. Error en Oracle: todavía imprime el número de filas encontradas.
-p paso_a_paso
La cadena que sigue a -p se pasará al programa de conexión a la base de datos como argumentos. Múltiples -p se unirán con un espacio. Ejemplo: pasar '-U' y el nombre de usuario al programa:

-p "-U scott" también se puede escribir como -p -U -p scott.

--precision <rfc3339|h|m|s|ms|u|ns>
Precisión de las marcas de tiempo.

Especifica el formato de las marcas de tiempo de salida: rfc3339, h, m, s, ms, u o ns.

-r
Intenta 3 veces. Versión corta de --retries 3.
--retries nveces
Intenta nveces. Si el programa cliente devuelve un error, reintenta el comando. El valor predeterminado es --retries 1.
--sep cadena
-s cadena
Separador de campos. Usa cadena como separador entre columnas.
--skip-first-line
No utilizar la primera línea de entrada (utilizada por el propio GNU sql cuando se llama con --shebang).
--table-size
--tablesize
Tamaño de las tablas. Muestra el tamaño de las tablas en la base de datos.
--verbose
-v
Imprime qué comando se envía.
--version
-V
Imprime la versión de GNU sql y sale.
--shebang
-Y
GNU sql puede ser llamado como comando shebang (#!) como la primera línea de un script. Así: 
#!/usr/bin/sql -Y mysql:///
SELECT * FROM foo;

Para que esto funcione, --shebang o -Y deben establecerse como la primera opción.

DBURL

Una DBURL tiene la siguiente sintaxis: [sql:]proveedor:// [[usuario][:contraseña]@][host][:puerto]/[base_de_datos][?consulta_sql]

Para codificar caracteres especiales, usa la codificación % especificada en http://tools.ietf.org/html/rfc3986#section-2.1 (Por ejemplo, una contraseña que contenga '/' contendría '%2F').

csv:///%2Ftmp%2Fparallel-bug-56096/mytable csv:////tmp/parallel-bug-56096/mytable mysql://me@/me/ mysql:////

sqlite3:///%2Frun%2Fshm%2Fparallel.db sqlite3:///%2Frun%2Fshm%2Fparallel.db/table sqlite:///%2Ftmp%2Ffile.sqlite?SELECT csv:///%2Ftmp%2Fparallel-CSV/OK csv:///%2Fmust%2Ffail/fail sqlite3:///%2Frun%2Fshm%2Fparallel.db

Ejemplos:

mysql://scott:tiger@my.example.com/mydb
influxdb://scott:tiger@influxdb.example.com/foo
sql:oracle://scott:tiger@ora.example.com/xe
postgresql://scott:tiger@pg.example.com/pgdb
pg:///
postgresqlssl://scott@pg.example.com:3333/pgdb
sql:sqlite2:////tmp/db.sqlite?SELECT * FROM foo;
sqlite3:///../db.sqlite3?SELECT%20*%20FROM%20foo;

Proveedores actualmente soportados:

  • MySQL (mysql) con SSL (mysqls, mysqlssl)
  • Oracle (oracle, ora)
  • PostgreSQL (postgresql, pg, pgsql, postgres) con SSL (postgresqlssl, pgs, pgsqlssl, postgresssl, pgssl, postgresqls, pgsqls, postgress)
  • SQLite2 (sqlite, sqlite2)
  • SQLite3 (sqlite3)
  • InfluxDB 1.x (influx, influxdb) con SSL (influxdbssl, influxdbs, influxs, influxssl)

Los alias deben comenzar con ':' y se leen de /etc/sql/aliases y ~/.sql/aliases. El ~/.sql/aliases del propio usuario solo debe ser legible por el usuario.

Ejemplo de alias:

:myalias1 pg://scott:tiger@pg.example.com/pgdb
:myalias2 ora://scott:tiger@ora.example.com/xe
# Forma corta de mysql://`whoami`:nopassword@localhost:3306/`whoami`
:myalias3 mysql:///
# Forma corta de mysql://`whoami`:nopassword@localhost:33333/mydb
:myalias4 mysql://:33333/mydb
# Alias para un alias
:m      :myalias4
# el alias más corto posible
:       sqlite2:////tmp/db.sqlite
# Incluyendo una consulta SQL
:query  sqlite:////tmp/db.sqlite?SELECT * FROM foo;

EJEMPLOS

Obtener un prompt interactivo

El uso más básico de GNU sql es obtener

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

et un prompt interactivo:

sql sql:oracle://scott:tiger@ora.example.com/xe

Si ha configurado un alias, puede hacer:

sql :myora

Ejecutar una consulta

Para ejecutar una consulta directamente desde la línea de comandos:

sql :myalias "SELECT * FROM foo;"

Oracle requiere saltos de línea después de cada sentencia. Esto se puede hacer así:

sql :myora "SELECT * FROM foo;" "SELECT * FROM bar;"

O así:

sql :myora "SELECT * FROM foo;\nSELECT * FROM bar;"

Copiar una base de datos PostgreSQL

Para copiar una base de datos PostgreSQL, use pg_dump para generar el volcado y GNU sql para importarlo:

pg_dump pg_database | sql pg://scott:tiger@pg.example.com/pgdb

Vaciar todas las tablas en una base de datos MySQL

Usando GNU parallel, es fácil vaciar todas las tablas sin eliminarlas:

sql -n mysql:/// 'show tables' | parallel sql mysql:/// DELETE FROM {};

Eliminar todas las tablas en una base de datos PostgreSQL

Para eliminar todas las tablas en una base de datos PostgreSQL, haga esto:

sql -n pg:/// '\dt' | parallel --colsep '\|' -r sql pg:/// DROP TABLE {2};

Ejecutar como un script

En lugar de hacer:

sql mysql:/// < sqlfile

puede combinar el archivo sql con el DBURL para crear un script de UNIX. Cree un script llamado demosql:

#!/usr/bin/sql -Y mysql:///

SELECT * FROM foo;

Luego haga:

chmod +x demosql; ./demosql

Usar --colsep para procesar múltiples columnas

Use --colsep de GNU parallel para separar columnas:

sql -s '\t' :myalias 'SELECT * FROM foo;' | parallel --colsep '\t' do_stuff {4} {1}

Reintentar si la conexión falla

Si el acceso a la base de datos falla ocasionalmente, --retries puede ayudar a asegurar que la consulta tenga éxito:

sql --retries 5 :myalias 'SELECT * FROM really_big_foo;'

Obtener información sobre el sistema de base de datos en ejecución

Mostrar qué tan grande es la base de datos:

sql --db-size :myalias

Listar las tablas:

sql --list-tables :myalias

Listar el tamaño de las tablas:

sql --table-size :myalias

Listar los procesos en ejecución:

sql --show-processlist :myalias

DEPENDENCIAS

GNU sql usa Perl. Si está instalado mysql, los dburls de MySQL funcionarán. Si está instalado psql, los dburls de PostgreSQL funcionarán. Si está instalado sqlite, los dburls de SQLite2 funcionarán. Si está instalado sqlite3, los dburls de SQLite3 funcionarán. Si está instalado sqlplus, los dburls de Oracle funcionarán. Si está instalado rlwrap, GNU sql tendrá un historial de comandos para Oracle.
