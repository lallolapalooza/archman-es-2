SQRT02

Documentación de función/subrutina

subroutine sqrt02 (integer m, integer n, integer k, real, dimension( lda, * ) a, real, dimension( lda, * ) af, real, dimension( lda, * ) q, real, dimension( lda, * ) r, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

SQRT02

Propósito:

!>
!> SQRT02 prueba SORGQR, que genera una matriz m por n, Q, con
!> columnas ortonormales que se define como el producto de k
!> reflectores elementales.
!>
!> Dada la factorización QR de una matriz m por n, A, SQRT02 genera
!> la matriz ortogonal Q definida por la factorización de las primeras k
!> columnas de A; compara R(1:n,1:k) con Q(1:m,1:n)'*A(1:m,1:k),
!> y comprueba que las columnas de Q son ortonormales.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz Q a generar. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz Q a generar.
!>          M >= N >= 0.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. N >= K >= 0.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>          La matriz m por n, A, que fue factorizada por SQRT01.
!>

AF

!>          AF es array REAL, dimensión (LDA,N)
!>          Detalles de la factorización QR de A, tal como devuelve SGEQRF.
!>          Ver SGEQRF para más detalles.
!>

Q

!>          Q es array REAL, dimensión (LDA,N)
!>

R

!>          R es array REAL, dimensión (LDA,N)
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A, AF, Q y R. LDA >= M.
!>

TAU

!>          TAU es array REAL, dimensión (N)
!>          Los factores escalares de los reflectores elementales
!>          correspondientes a la factorización QR en AF.
!>

WORK

!>          WORK es array REAL, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es array REAL, dimensión (M)
!>

RESULT

!>          RESULT es array REAL, dimensión (2)
!>          Las razones de prueba:
!>          RESULT(1) = norm( R - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
