SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-key-export - Exportar claves del almacén de claves

SINOPSIS

sq key export [OPCIONES]

DESCRIPCIÓN

Exportar claves del almacén de claves.

Exporta el material de clave secreta asociado con un certificado. Tenga en cuenta que incluso si el material de clave secreta está disponible, es posible que no sea exportable. Por ejemplo, el material de clave secreta almacenado en un módulo de seguridad de hardware generalmente no se puede exportar desde el dispositivo.

Itera sobre todos los certificados especificados y exporta las claves (clave primaria y subclaves) con material de clave secreta. Se devuelve un error si algún certificado especificado no contiene material de clave secreta.

Si solo desea exportar una clave en particular y no todas las claves asociadas con un certificado, use `sq key subkey export`.

OPCIONES

Opciones de subcomando

--cert=HUELLA_DIGITAL|ID_CLAVE
Exportar claves con la huella digital o ID de clave especificada
--cert-domain=DOMINIO
Exportar claves donde un ID de usuario incluye una dirección de correo electrónico para el dominio especificado
--cert-email=EMAIL
Exportar claves donde un ID de usuario incluye la dirección de correo electrónico especificada
--cert-grep=PATRÓN
Exportar claves con un ID de usuario que coincida con el patrón, sin distinguir entre mayúsculas y minúsculas
--cert-userid=ID_USUARIO
Exportar claves con el ID de usuario especificado
--output=ARCHIVO
Escribir en ARCHIVO o en la salida estándar si se omite
[por defecto: -]

Opciones globales

Vea sq(1) para una descripción de las opciones globales.

EJEMPLOS

Exportar el certificado de Alice con todo el material de clave secreta disponible.

sq key export --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Exportar el certificado de Alice con todo el material de clave secreta identificado por dirección de correo electrónico.

sq key export --cert-email alice@example.org

VER TAMBIÉN

sq(1), sq-key(1).

Para la documentación completa, consulte https://book.sequoia-pgp.org/.
