NOMBRE

sq-network-wkd-search - Recuperar certificados de un Directorio de Claves Web

SINOPSIS

sq network wkd search [OPCIONES] DIRECCION

DESCRIPCIÓN

Recupera certificados de un Directorio de Claves Web.

Por defecto, cualquier certificado devuelto se almacena en el almacén de certificados local. Esto puede ser anulado utilizando la opción `--output`.

Cuando un certificado se recupera de un WKD y se importa en el almacén de certificados local, cualquier ID de usuario con la dirección de correo electrónico buscada se certifica con una clave local específica de WKD. Esa clave proxy se certifica a su vez como una CA mínimamente confiable (nivel de confianza: 1 de 120) por la raíz de confianza local. Cuánto se confía en la CA proxy de WKD se puede ajustar usando `sq pki link add` o `sq pki link retract` de la manera habitual.

OPCIONES

Opciones del subcomando

--all
Obtener actualizaciones para todos los certificados conocidos
--output=ARCHIVO
Escribir en ARCHIVO (o stdout si se omite) en lugar de importar en el almacén de certificados

DIRECCION
Recuperar certificado(s) para DIRECCION

Opciones globales

Consulte sq(1) para ver una descripción de las opciones globales.

EJEMPLOS

Recuperar el certificado de Alice a través de WKD.

sq network wkd search alice@example.org

Obtener actualizaciones para todos los certificados conocidos a través de WKD.

sq network wkd search --all

VER TAMBIÉN

sq(1), sq-network(1), sq-network-wkd(1).

Para la documentación completa, consulte https://book.sequoia-pgp.org/.
