SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-config-inspect-paths - Inspecciona rutas relevantes

SINOPSIS

sq config inspect paths [OPCIONES]

DESCRIPCIÓN

Inspecciona rutas relevantes.

Imprime las rutas que utiliza sq, como la ubicación del directorio principal, el archivo de configuración, el almacén de certificados, el almacén de claves, etc.

OPCIONES

Opciones globales

Para una descripción de las opciones globales, consulte sq(1).

EJEMPLOS

Inspecciona rutas relevantes.

sq config inspect paths

VER TAMBIÉN

sq(1), sq-config(1), sq-config-inspect(1).

Para la documentación completa, consulte https://book.sequoia-pgp.org/.
