SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-network - Recuperar y publicar certificados a través de la red

SINOPSIS

sq network search [OPCIONES] CONSULTA
sq network keyserver [OPCIONES] SUBCOMANDO
sq network wkd [OPCIONES] SUBCOMANDO
sq network dane [OPCIONES] SUBCOMANDO

DESCRIPCIÓN

Recuperar y publicar certificados a través de la red.

Los certificados OpenPGP pueden ser descubiertos y actualizados desde, y publicados en servicios accesibles a través de la red. Esta es una colección de comandos para interactuar con estos servicios.

SUBCOMANDOS

sq network search

Recuperar certificados utilizando todos los servicios de red compatibles.

Este comando intentará localizar certificados relevantes dada una consulta, que puede ser una huella digital, un ID de clave, una dirección de correo electrónico o una URL https. También puede descubrir e importar certificados relacionados con el consultado, como certificados alternativos, certificados caducados o certificados revocados.

El descubrimiento de certificados relacionados es útil: los certificados alternativos admiten rotaciones de claves, los certificados caducados permiten la verificación de firmas realizadas en el pasado y el descubrimiento de certificados revocados es importante para obtener la información de revocación. El mecanismo PKI ayudará a seleccionar el certificado correcto, consulte `sq pki`.

Por defecto, cualquier certificado devuelto se almacena en el almacén de certificados local. Esto se puede anular utilizando la opción `--output`.

Cuando un certificado se recupera de un servidor de claves de verificación (actualmente, esto se limita a una lista de servidores conocidos: `hkps://keys.openpgp.org`, `hkps://keys.mailvelope.com` y `hkps://mail-api.proton.me`), WKD, DANE o a través de https, y se importa en el almacén de certificados local, los IDs de usuario también se certifican con una clave local específica del servidor. Esa clave proxy se certifica a su vez como una CA mínimamente confiable (monto de confianza: 1 de 120) desde la raíz de confianza local. La confianza de una CA de servidor de claves proxy se puede ajustar usando `sq pki link add` o `sq pki link retract` de la forma habitual.

sq network keyserver

Recuperar y publicar certificados a través de servidores de claves.

El Protocolo de Servidor de Claves HTTP de OpenPGP (HKP) es un método para publicar y recuperar certificados de servidores de claves.

sq network wkd

Recuperar y publicar certificados a través de Directorios de Claves Web.

El Directorio de Claves Web (WKD) es un método para publicar y recuperar certificados de servidores web.

sq network dane

Recuperar y publicar certificados a través de DANE.

Autenticación de Entidades Nombradas Basada en DNS (DANE) es un método para publicar y recuperar certificados en DNS según lo especificado en RFC 7929.

EJEMPLOS

Buscar el certificado de firma maestra de Qubes.

sq network search 427F11FD0FAA4B080123F01CDDFA1A3E36879494

Buscar certificados asociados a una dirección de correo electrónico.

sq network search alice@example.org
