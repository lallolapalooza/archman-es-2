SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-packet-dump - Listar paquetes

SINOPSIS

sq packet dump [OPCIONES] ARCHIVO

DESCRIPCIÓN

Listar paquetes.

Crea una descripción legible por humanos de la secuencia de paquetes. Además, puede imprimir artefactos criptográficos e imprimir el flujo de octetos crudo similar a hexdump(1), anotando específicamente qué bytes se analizan en valores OpenPGP.

Si el flujo de paquetes incluye un contenedor de cifrado, `sq` intentará descifrarlo.

OPCIONES

Opciones de subcomando

--cert=HUELLA|ID_CLAVE
Listar los paquetes del certificado con la huella digital o ID de clave especificado.
--cert-email=CORREO
Listar los paquetes del certificado donde un ID de usuario incluye la dirección de correo especificada.
--cert-file=RUTA
Listar los paquetes del certificado leído desde RUTA.
--cert-userid=ID_USUARIO
Listar los paquetes del certificado con el ID de usuario especificado.
--hex
Imprimir un hexdump.
--mpis
Imprimir artefactos criptográficos.
--output=ARCHIVO
Escribir en ARCHIVO o en la salida estándar si se omite.
[predeterminado: -]
--recipient-file=ARCHIVO_CLAVE
Descifrar el mensaje usando la clave en ARCHIVO_CLAVE.
--session-key=CLAVE_SESION
Descifrar un mensaje cifrado usando CLAVE_SESION.

ARCHIVO
Leer desde ARCHIVO o desde la entrada estándar si ARCHIVO es '-'
[predeterminado: -]

Opciones globales

Consulte sq(1) para una descripción de las opciones globales.

EJEMPLOS

Imprimir los paquetes de un certificado.

sq packet dump juliet.pgp

Imprimir los paquetes, incluidos los artefactos criptográficos, de un certificado.

sq packet dump --mpis juliet.pgp

Imprimir los paquetes, incluido un volcado de cada byte de un certificado.

sq packet dump --hex juliet.pgp

Imprime los paquetes de un mensaje cifrado, descifrándolo utilizando un archivo de clave secreta.

sq packet dump --recipient-file bob-secret.pgp message.pgp

VER TAMBIÉN

sq(1), sq-packet(1).

Para la documentación completa consulte https://book.sequoia-pgp.org/.
