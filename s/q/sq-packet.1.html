Paquete: sequoia-sq

SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-packet - Manipulación de paquetes de bajo nivel

SINOPSIS

sq packet armor [OPCIONES] ARCHIVO
sq packet dearmor [OPCIONES] ARCHIVO
sq packet dump [OPCIONES] ARCHIVO
sq packet decrypt [OPCIONES] ARCHIVO
sq packet split [OPCIONES] ARCHIVO
sq packet join [OPCIONES] ARCHIVO

DESCRIPCIÓN

Manipulación de paquetes de bajo nivel.

Un flujo de datos OpenPGP consta de paquetes. Estas herramientas permiten trabajar con flujos de paquetes. Son principalmente de interés para los desarrolladores, pero `sq packet dump` puede ser útil para una audiencia más amplia, tanto para proporcionar información valiosa en informes de errores a software relacionado con OpenPGP, como herramienta de aprendizaje.

SUBCOMANDOS

sq packet armor

Convertir binario a ASCII.

Para que los datos cifrados sean más fáciles de manejar y transportar, los datos OpenPGP se pueden transformar a una representación ASCII llamada ASCII Armor. sq emite datos armados por defecto, pero este subcomando se puede usar para convertir datos OpenPGP existentes a su representación codificada en ASCII.

La operación inversa es `sq packet dearmor`.

sq packet dearmor

Convertir ASCII a binario.

Para que los datos cifrados sean más fáciles de manejar y transportar, los datos OpenPGP se pueden transformar a una representación ASCII llamada ASCII Armor. sq maneja datos armados de forma transparente, pero este subcomando se puede usar para convertir explícitamente datos OpenPGP codificados en ASCII a su representación binaria.

La operación inversa es `sq packet armor`.

sq packet dump

Listar paquetes.

Crea una descripción legible por humanos de la secuencia de paquetes. Además, puede imprimir artefactos criptográficos e imprimir el flujo de octetos crudo similar a hexdump(1), anotando específicamente qué bytes se analizan en valores OpenPGP.

Si el flujo de paquetes incluye un contenedor de cifrado, `sq` intentará descifrarlo.

sq packet decrypt

Desempaquetar un contenedor de cifrado.

Descifra un mensaje, mostrando el contenido del contenedor de cifrado sin procesamiento adicional. El resultado es un mensaje OpenPGP válido que puede, entre otras cosas, ser inspeccionado usando `sq packet dump`.

sq packet split

Dividir un mensaje en paquetes.

Dividir una secuencia de paquetes en paquetes individuales y luego recombinarlos libremente con `sq packet join` es una excelente manera de experimentar con datos OpenPGP.

Por defecto, los paquetes se escriben en stdout como una secuencia de bloques armados en ASCII. Es posible editar este archivo directamente (por ejemplo, mover, añadir o eliminar paquetes), y luego usar `sq packet join` para ensamblar el flujo.

Alternativamente, si se proporciona un `--output-prefix`, los paquetes se escriben en archivos individuales que comienzan con el prefijo y se pueden reasemblar con `sq packet join`.

La operación inversa es `sq packet join`.

sq packet join

Unir paquetes divididos en varios archivos.

Dividir una secuencia de paquetes en paquetes individuales y luego recombinarlos libremente con `sq packet join` es una excelente manera de experimentar con datos OpenPGP.

La operación inversa es `sq packet split`.

EJEMPLOS

sq packet armor

Convertir un mensaje OpenPGP binario a un mensaje OpenPGP armado en ASCII.

sq packet armor mensaje.bin

Convertir un mensaje OpenPGP binario a un mensaje OpenPGP armado en ASCII eligiendo explícitamente la etiqueta de armadura.

sq packet armor --label=mensaje mensaje.bin

sq packet dearmor

Convertir un mensaje OpenPGP armado en ASCII a un mensaje OpenPGP binario.

sq packet dearmor --output=mensaje.bin mensaje.pgp

sq packet dump

Imprimir los paquetes de un certificado.

sq packet dump juliet.pgp

Imprimir los paquetes incluyendo artefactos criptográficos de un certificado.

sq packet dump --mpis juliet.pgp

Imprimir los paquetes incluyendo una volcado de cada byte de un certificado.

sq packet dump --hex juliet.pgp

Imprime los paquetes de un mensaje cifrado, descifrándolo usando un archivo de clave secreta.

sq packet dump --recipient-file bob-secret.pgp message.pgp

sq packet decrypt

Desempaqueta el cifrado revelando el mensaje firmado.

sq packet decrypt --recipient-file bob-secret.pgp message.pgp

sq packet split

Divide un certificado en paquetes individuales impresos en stdout.

sq packet split --output=- juliet.pgp

Divide un mensaje firmado en línea en paquetes individuales escritos en archivos separados con el prefijo 'packet'.

sq packet split --output-prefix packet document.pgp

Luego reensambla el mensaje, transformándolo en un mensaje firmado de estilo antiguo con una firma de prefijo.

sq packet join --output prefijo-firma.pgp --label mensaje \
packet-2-Signature-Packet packet-1-Literal-Data-Packet

sq packet join

Divide un mensaje firmado en línea en paquetes individuales escritos en archivos separados con el prefijo 'packet'.

sq packet split --output-prefix packet document.pgp

Luego reensambla el mensaje, transformándolo en un mensaje firmado de estilo antiguo con una firma de prefijo.

sq packet join --output prefijo-firma.pgp --label mensaje \
packet-2-Signature-Packet packet-1-Literal-Data-Packet
