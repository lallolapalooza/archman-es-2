SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq key subkey - Gestionar subclaves

SINOPSIS

sq key subkey add [OPCIONES]
sq key subkey export [OPCIONES]
sq key subkey delete [OPCIONES]
sq key subkey password [OPCIONES]
sq key subkey expire [OPCIONES]
sq key subkey revoke [OPCIONES]
sq key subkey bind [OPCIONES]

DESCRIPCIÓN

Gestionar subclaves.

Añadir nuevas subclaves a un certificado existente, cambiar su caducidad y revocarlas.

SUBCOMANDOS

sq key subkey add

Añadir una nueva subclava a un certificado.

Una subclava tiene una o más capacidades.

`--can-sign` establece la capacidad de firma y significa que la clave puede ser utilizada para firmar. `--can-authenticate` establece la capacidad de autenticación y significa que la clave puede ser utilizada para autenticación (por ejemplo, como clave SSH). `--can-certify` establece la capacidad de certificación y significa que la clave puede ser utilizada para realizar certificaciones de terceros. Estas capacidades pueden combinarse.

`--can-encrypt=storage` establece la capacidad de cifrado de almacenamiento y significa que la clave puede ser utilizada para cifrado de almacenamiento. `--can-encrypt=transport` establece la capacidad de cifrado de transporte y significa que la clave puede ser utilizada para cifrado de transporte. `--can-encrypt=universal` establece ambas capacidades de cifrado (almacenamiento y transporte) y significa que la clave puede ser utilizada tanto para cifrado de almacenamiento como de transporte. Las capacidades de cifrado no deben combinarse con la capacidad de firma o autenticación.

Normalmente, `sq` solicita al usuario una contraseña para usarla al cifrar el material de la clave secreta. La contraseña de la nueva subclava puede ser diferente de la de las otras claves. Al usar `--without-password`, `sq` no solicita una contraseña y no protege la subclava con contraseña.

Por defecto, una nueva subclava no caduca por sí sola. Sin embargo, su período de validez está limitado por el del certificado. El uso del argumento `--expiration` permite establecer una fecha de caducidad diferente.

`sq key subkey add` respeta el tiempo de referencia establecido por el argumento `--time` de nivel superior. Establece la hora de creación de la subclava a la hora especificada.

sq key subkey export

Exportar material de clave secreta desde el almacén de claves secretas.

Exporta el material de la clave secreta. Tenga en cuenta que incluso si el material de la clave secreta está disponible, es posible que no se pueda exportar. Por ejemplo, el material de clave secreta almacenado en un módulo de seguridad de hardware generalmente no se puede exportar desde el dispositivo.

Se exporta todo el certificado, pero solo se exporta el material de clave secreta de la clave especificada. Se devuelve un error si el material de clave secreta para la clave especificada no está disponible.

Si desea exportar todo el material de clave secreta asociado con un certificado, use `sq key export`.

sq key subkey delete

Eliminar el material de clave secreta de un certificado.

A diferencia de `sq key delete`, que elimina todo el material de clave secreta, este comando solo elimina el material de clave secreta especificado.

Si el material de clave secreta es gestionado por múltiples dispositivos, se elimina de todos ellos.

Aunque se elimina el material de clave secreta, las claves públicas se conservan. Si no desea que las claves se utilicen más, debería revocar las claves usando `sq key subkey revoke`.

sq key subkey password

Cambiar la contraseña que protege el material de clave secreta.

El material de clave secreta puede ser protegido por una contraseña. Este subcomando cambia o borra la contraseña de una o más claves.

Para eliminar la contraseña, use `--clear` o proporcione una contraseña de longitud cero cuando se le solicite la nueva contraseña.

Si una clave está protegida por contraseña y no se proporcionó la contraseña correcta usando el argumento `--password-file`, se le pedirá al usuario la contraseña. De manera similar, si no se proporciona la nueva contraseña, se le pedirá al usuario.

sq key subkey expire

Cambiar la fecha de caducidad de una subclava.

Este subcomando cambia la fecha de caducidad de una clave. Para cambiar la fecha de caducidad del certificado, use el subcomando `sq key expire`.

Cambiar la fecha de caducidad de la clave primaria es equivalente a cambiar la fecha de caducidad del certificado. La fecha de caducidad de una subclava está limitada por la caducidad del certificado.

sq key subkey revoke

Revocar una subclava.

Crea un certificado de revocación para una subclava.

Si se proporcionan `--revoker` o `--revoker-file`, entonces esa clave se utiliza para crear el certificado de revocación. Si esa clave es diferente del certificado que se está revocando, esto resulta en una revocación por terceros. Esto normalmente solo es útil si el propietario del certificado designó la clave como un revoker designado.

`sq key subkey revoke` respeta el tiempo de referencia establecido por el argumento `--time` de nivel superior. Cuando se establece, utiliza el tiempo especificado en lugar del tiempo actual al determinar qué claves son válidas, y establece el tiempo de creación del certificado de revocación al tiempo de referencia en lugar del tiempo actual.

sq key subkey bind

Vincular claves de un certificado a otro.

Este comando permite al usuario adjuntar una clave primaria o una subclava adjunta a un certificado a otro certificado. Supongamos que desea transicionar a un nuevo certificado, pero tiene una subclava de autenticación en su certificado actual que desea conservar porque permite el acceso a un servidor y la actualización de su configuración no es factible. Este comando facilita la vinculación de la subclava al nuevo certificado.

Después de la operación, la clave está vinculada tanto al certificado antiguo como al nuevo. Para eliminar el material de clave secreta del certificado antiguo, use `sq key subkey delete` o `sq key delete`, según corresponda. Para revocar la subclava o clave antigua, use `sq key subkey revoke` o `sq key revoke`, respectivamente.

EJEMPLOS

sq key subkey add

Añadir una nueva subclava capaz de firmar a la clave de Alice.

sq key subkey add --can-sign \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

sq key subkey export

Exportar las subclaves de Alice capaces de firmar y cifrar, pero no su clave primaria ni su subclava capaz de autenticar.

sq key subkey export \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 \
--key=74DCDEAF17D9B995679EB52BA6E65EA2C8497728

sq key subkey delete

Eliminar la subclava de firma de Alice.

sq key subkey delete \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8

sq key subkey password

Cambiar la contraseña de la clave de firma de Alice a la contraseña del archivo especificado.

sq key subkey password --new-password-file=archivo-contraseña.txt \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8

Eliminar la protección de contraseña para la clave de firma de Alice.

sq key subkey password --password-file=archivo-contraseña.txt \
--clear-password \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8

sq key subkey expire

Cambiar la subclava de autenticación de Alice

sq-key-subkey(1) — Sequoia PGP

NAME

sq-key-subkey

manage subkeys

SYNOPSIS

sq key subkey subcommand

DESCRIPTION

This subcommand is the parent of all subkey-specific subcommands.

SUBCOMMANDS

add add a subkey to a key
delete delete a subkey from a key
export export a subkey
expire change the expiration date of a subkey
password change the password of a subkey
revoke revoke a subkey
bind bind a subkey to a certificate

EXAMPLES

sq key subkey expire

Change the expiration date of Alice's signing subkey to expire in 6 months.

sq key subkey expire --expiration 6m \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=0D45C6A756A038670FDFD85CB1C82E8D27DB23A1

sq key subkey revoke

Revoke Alice's signing subkey.

sq key subkey revoke \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 --reason \
retired --message "Subkey rotation."

Revoke Alice's signing subkey and encryption subkeys.

sq key subkey revoke \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=42020B87D51877E5AF8D272124F3955B0B8DECC8 \
--key=74DCDEAF17D9B995679EB52BA6E65EA2C8497728 --reason \
retired --message "Subkey rotation."

sq key subkey bind

Bind Alice's old authentication subkey to Alice's new certificate.

sq key subkey bind \
--cert=C5999E8191BF7B503653BE958B1F7910D01F86E5 \
--key=0D45C6A756A038670FDFD85CB1C82E8D27DB23A1

Bind a bare key to Alice's certificate. A bare key is a public key without any components or signatures. This simplifies working with raw keys, e.g., keys generated on an OpenPGP card, a TPM device, etc.

sq key subkey bind --keyring=bare.pgp \
--cert=C5999E8191BF7B503653BE958B1F7910D01F86E5 \
--key=B321BA8F650CB16443E06826DBFA98A78CF6562F \
--can-encrypt=universal
