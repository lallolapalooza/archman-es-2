SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-pki-path - Verifica la ruta especificada

SINOPSIS

sq pki path [OPCIONES] HUELLA DIGITAL|ID DE CLAVE

DESCRIPCIÓN

Verifica la ruta especificada.

Una ruta es una secuencia de certificados que comienza en la raíz, y un ID de usuario. Esta función comprueba que cada segmento de la ruta tenga una certificación válida, que también satisfaga cualquier restricción (monto de confianza, profundidad de confianza, expresiones regulares).

Si no se encuentra una ruta válida, este subcomando también la analiza (lint). En particular, informa si alguna certificación es insuficiente, p. ej., falta profundidad de confianza, o inválida, p. ej., porque utiliza SHA-1, pero el uso de SHA-1 ha sido deshabilitado.

OPCIONES

Opciones del subcomando

--amount=MONTO
El monto requerido de confianza
120 indica autenticación completa; los valores menores a 120 indican autenticación parcial. Cuando se pasa `--certification-network`, el valor predeterminado es 1200, es decir, este comando intenta encontrar 10 rutas.
--certification-network
Trata la red como una red de certificación
Normalmente, la maquinaria de autenticación trata la red de la Red de Confianza como una red de autenticación donde una certificación solo significa que la vinculación es correcta, no que el objetivo debe ser tratado como un introductor de confianza. En una red de certificación, los objetivos de las certificaciones son tratados como introductoras de confianza con profundidad infinita, y se ignoran las expresiones regulares. Nota: El monto de confianza permanece sin cambios. Así es como funcionan la mayoría de los algoritmos de búsqueda de rutas PGP.
--email=CORREO_ELECTRONICO
Autentica la dirección de correo electrónico especificada
Esto verifica si es posible autenticar el ID de usuario que consiste solo en la dirección de correo electrónico especificada. El ID de usuario no necesita ser autofirmado.
--userid=ID_DE_USUARIO
Autentica el ID de usuario especificado
El ID de usuario especificado no necesita ser autofirmado.
--userid-by-email=CORREO_ELECTRONICO
Autentica el ID de usuario autofirmado con la dirección de correo electrónico especificada
Esto verifica si es posible autenticar el ID de usuario autofirmado con la dirección de correo electrónico especificada.
Si el certificado es inválido o no hay un ID de usuario autofirmado con la dirección de correo electrónico especificada, se utiliza un ID de usuario con solo la dirección de correo electrónico.

HUELLA DIGITAL|ID DE CLAVE
La ruta a autenticar
Una ruta consta de uno o más certificados. El primer certificado es la raíz, y el último certificado es el que se está autenticando para el ID de usuario especificado.

Opciones globales

Ver sq(1) para una descripción de las opciones globales.

EJEMPLOS

Verifica que Alice certificó un ID de usuario particular para el certificado de Bob.

sq pki path EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
511257EBBF077B7AEDAE5D093F68CB84CE537C9A --userid \
"Bob <bob@example.org>"
