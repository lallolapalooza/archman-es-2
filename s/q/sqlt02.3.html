DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine sqlt02 (integer m, integer n, integer k, real, dimension( lda, * ) a, real, dimension( lda, * ) af, real, dimension( lda, * ) q, real, dimension( lda, * ) l, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

SQLT02

Propósito:

!>
!> SQLT02 prueba SORGQL, que genera una matriz m x n, Q, con
!> columnas ortonormales que se define como el producto de k
!> reflectores elementales.
!>
!> Dada la factorización QL de una matriz A de m x n, SQLT02 genera
!> la matriz ortogonal Q definida por la factorización de las últimas k
!> columnas de A; compara L(m-n+1:m, n-k+1:n) con
!> Q(1:m, m-n+1:m)'*A(1:m, n-k+1:n), y comprueba que las columnas de Q
!> sean ortonormales.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz Q a generar. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz Q a generar.
!>          M >= N >= 0.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. N >= K >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          La matriz A de m x n que fue factorizada por SQLT01.
!>

AF

!>          AF es array REAL, dimension (LDA,N)
!>          Detalles de la factorización QL de A, tal como es devuelta por SGEQLF.
!>          Consultar SGEQLF para más detalles.
!>

Q

!>          Q es array REAL, dimension (LDA,N)
!>

L

!>          L es array REAL, dimension (LDA,N)
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A, AF, Q y L. LDA >= M.
!>

TAU

!>          TAU es array REAL, dimension (N)
!>          Los factores escalares de los reflectores elementales correspondientes
!>          a la factorización QL en AF.
!>

WORK

!>          WORK es array REAL, dimension (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es array REAL, dimension (M)
!>

RESULT

!>          RESULT es array REAL, dimension (2)
!>          Las razones de prueba:
!>          RESULT(1) = norm( L - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
