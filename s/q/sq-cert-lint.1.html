NOMBRE

sq-cert-lint - Comprueba certificados en busca de problemas

SINOPSIS

sq cert lint [OPCIONES]

DESCRIPCIÓN

Comprueba certificados en busca de problemas.

`sq cert lint` comprueba los certificados suministrados en busca de los siguientes problemas relacionados con SHA-1:


- Si una revocación de certificado utiliza SHA-1.


- Si la firma automática actual para un ID de usuario no revocado utiliza SHA-1.


- Si la firma de enlace de subclave actual para una subclave activa y no revocada utiliza SHA-1.


- Si una firma de enlace de clave primaria ("backsig") para una subclave activa y no revocada utiliza SHA-1.

Los diagnósticos se imprimen en stderr. Al final, se muestran algunas estadísticas. Esto es útil al examinar un keyring. Si se especifica `--fix` y se pudo solucionar al menos un problema, los certificados corregidos se imprimen en stdout.

Esta herramienta actualmente no soporta tarjetas inteligentes. Pero, si solo las subclaves están en una tarjeta inteligente, esta herramienta aún puede reparar parcialmente el certificado. En particular, podrá solucionar cualquier problema con las firmas automáticas de ID de usuario y las firmas de enlace de subclave para subclaves capaces de cifrar, pero no podrá generar nuevas firmas de enlace de clave primaria para ninguna subclave capaz de firmar.

OPCIONES

Opciones de subcomando

--cert=HUELLA_DIGITAL|ID_CLAVE
Usa certificados con la huella digital o ID de clave especificada
--cert-domain=DOMINIO
Usa certificados donde un ID de usuario incluye una dirección de correo electrónico para el dominio especificado
--cert-email=CORREO_ELECTRONICO
Usa certificados donde un ID de usuario incluye la dirección de correo electrónico especificada
--cert-file=RUTA
Lee certificados desde RUTA
--cert-grep=PATRÓN
Usa certificados con un ID de usuario que coincida con el patrón, sin distinguir mayúsculas y minúsculas
--cert-userid=ID_USUARIO
Usa certificados con el ID de usuario especificado
--fix
Intenta corregir certificados, cuando sea posible
--output=ARCHIVO
Escribe en el ARCHIVO especificado
Si no se especifica, y el certificado se leyó desde la tienda de certificados, importa el certificado modificado a la tienda de certificados. Si no se especifica, y el certificado se leyó desde un archivo, escribe el certificado modificado en stdout.

Opciones globales

Ver sq(1) para una descripción de las opciones globales.

EJEMPLOS


Recopilar estadísticas sobre los certificados en un keyring.

sq cert lint --cert-file certs.pgp

Corregir una clave con problemas conocidos.

sq key export --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
| sq cert lint --fix --cert-file=- \
| sq cert import
