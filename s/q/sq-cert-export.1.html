SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-cert-export - Exportar certificados del almacén de certificados local

SINOPSIS

sq cert export [OPCIONES]

DESCRIPCIÓN

Exportar certificados del almacén de certificados local.

Si se especifican varios predicados, se devuelve un certificado si al menos uno de ellos coincide.

Esto no verifica la autenticidad de los certificados de ninguna manera. Antes de utilizar los certificados, asegúrese de validarlos y autenticarlos.

Al coincidir con subclaves o IDs de usuario, el componente debe tener una autocertificación válida según la política.

Falla si se especifican criterios de búsqueda y ninguno de ellos coincide con ningún certificado. Nota: esto significa que si el almacén de certificados está vacío y no se especifican criterios de búsqueda, esto se considerará un éxito.

OPCIONES

Opciones de subcomando

--all
Exportar todos los certificados
--cert=HUELLA_DIGITAL|ID_CLAVE
Usar certificados con la huella digital o ID de clave especificados
--cert-domain=DOMINIO
Usar certificados donde un ID de usuario incluye una dirección de correo electrónico para el dominio especificado
--cert-email=CORREO_ELECTRONICO
Usar certificados donde un ID de usuario incluye la dirección de correo electrónico especificada
--cert-grep=PATRÓN
Usar certificados con un ID de usuario que coincida con el patrón, sin distinguir entre mayúsculas y minúsculas
--cert-userid=ID_USUARIO
Usar certificados con el ID de usuario especificado
--local
Exportar firmas locales (no exportables)
Por defecto, las firmas no exportables no se emiten al exportar certificados, los componentes de certificado que solo están vinculados por firmas no exportables no se emiten, y los certificados que constan solo de componentes no exportables no se emiten.
Esta bandera habilita la exportación de firmas, componentes y certificados no exportables. Esto es útil para la sincronización entre los dispositivos de uno, por ejemplo.
--output=ARCHIVO
Escribir en ARCHIVO o en la salida estándar si se omite
[por defecto: -]

Opciones globales

Vea sq(1) para una descripción de las opciones globales.

EJEMPLOS

Exportar certificados con un ID de usuario que contenga la dirección de correo electrónico.

sq cert export --cert-email=alice@example.org

Exportar certificados que contengan un ID de usuario con *cualquiera* de las direcciones de correo electrónico (¡no ambas!).

sq cert export --cert-email=alice@example.org \
--cert-email=bob@example.org

Exportar todos los certificados.

sq cert export --all

VER TAMBIÉN

sq(1), sq-cert(1).

Para la documentación completa, consulte https://book.sequoia-pgp.org/.
