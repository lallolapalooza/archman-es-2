SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-key-userid-revoke - Revocar un ID de usuario

SINOPSIS

sq key userid revoke [OPCIONES]

DESCRIPCIÓN

Revoca un ID de usuario.

Crea un certificado de revocación para un ID de usuario.

Si se proporcionan `--revoker` o `--revoker-file`, entonces se utiliza esa clave para crear el certificado de revocación. Si esa clave es diferente de la clave que está siendo revocada, esto resulta en una revocación por terceros. Esto normalmente solo es útil si el propietario de la clave designó la clave para ser un revocador designado.

Para revocar un ID de usuario, el certificado debe ser válido bajo la política actual. Si el certificado no es válido bajo la política actual, considere revocar todo el certificado, o corregirlo usando `sq cert lint` después de verificar la integridad del certificado. Si el certificado es válido bajo la política actual, pero el ID de usuario que desea revocar no lo es, aún puede revocar el ID de usuario usando `--add-userid`.

`sq key userid revoke` respeta el tiempo de referencia establecido por el argumento de nivel superior `--time`. Cuando se establece, utiliza el tiempo especificado en lugar del tiempo actual al determinar qué claves son válidas, y establece el tiempo de creación del certificado de revocación al tiempo de referencia en lugar del tiempo actual.

OPCIONES

Opciones de subcomando

--add-email=EMAIL
Utiliza un ID de usuario con la dirección de correo electrónico especificada
El ID de usuario consiste solo en la dirección de correo electrónico. La dirección de correo electrónico no tiene que aparecer en un ID de usuario autofirmado.
--add-userid=USERID
Utiliza el ID de usuario especificado
El ID de usuario especificado no necesita ser autofirmado.
Debido a que usar un ID de usuario que no es autofirmado a menudo es un error, necesitas usar esta opción para aceptarlo explícitamente.
--allow-non-canonical-userids
No rechaces nuevos IDs de usuario que no estén en forma canónica
Los IDs de usuario canónicos tienen la forma `Nombre (Comentario) <parteLocal@ejemplo.org>`.
--cert=FINGERPRINT|KEYID
Revoca el ID de usuario de la clave con la huella digital o ID de clave especificado
--cert-email=EMAIL
Revoca el ID de usuario de la clave donde un ID de usuario incluye la dirección de correo electrónico especificada
--cert-file=PATH
Revoca el ID de usuario de la clave leída desde PATH
--cert-userid=USERID
Revoca el ID de usuario de la clave con el ID de usuario especificado
--email=EMAIL
Usa un ID de usuario que consiste solo en la dirección de correo electrónico, si la dirección de correo electrónico aparece en un ID de usuario autofirmado
--message=MENSAJE
Un texto corto y explicativo
El texto se muestra a quien vea el certificado de revocación y explica por qué se ha revocado el certificado. Por ejemplo, si Alice ha dejado la organización, podría decir a quién contactar en su lugar.
--output=ARCHIVO
Escribe en el ARCHIVO especificado
Si no se especifica y el certificado se leyó de la tienda de certificados, importa el certificado modificado a la tienda de certificados. Si no se especifica y el certificado se leyó de un archivo, escribe el certificado modificado en la salida estándar.
--reason=RAZÓN
La razón de la revocación
Si la razón ocurrió en el pasado, deberías especificarla usando el argumento `--time`. Esto permite a las implementaciones de OpenPGP razonar con mayor precisión sobre artefactos cuya validez depende de la validez del ID de usuario.
[posibles valores: retired, unspecified]
--revoker=FINGERPRINT|KEYID
Usa la clave con la huella digital o ID de clave especificada para crear el certificado de revocación
Firma el certificado de revocación usando la clave especificada. Por defecto, se utiliza la clave que se está revocando. Usando esta opción, es posible crear una revocación por terceros.
--revoker-email=EMAIL
Usa la clave donde un ID de usuario incluye la dirección de correo electrónico especificada para crear el certificado de revocación
Firma el certificado de revocación usando la clave especificada. Por defecto, se utiliza la clave que se está revocando. Usando esta opción, es posible crear una revocación por terceros.
--revoker-file=PATH
Lee la clave desde PATH para crear el certificado de revocación
Firma el certificado de revocación usando la clave especificada. Por defecto, se utiliza la clave que se está revocando. Usando esta opción, es posible crear una revocación por terceros.
--revoker-userid=USERID
Usa la clave con el ID de usuario especificado para crear el certificado de revocación
Firma el certificado de revocación usando la clave especificada. Por defecto, se utiliza la clave que se está revocando. Usando esta opción, es posible crear una revocación por terceros.
--signature-notation NOMBRE VALOR
Añade una notación a la firma
El nombre de una notación definida por el usuario debe tener la forma `nombre@un.dominio.que.controlas.org`. Si el nombre de la notación comienza con un `!`, entonces la notación se marca como crítica. Si un consumidor de una firma no entiende una notación crítica, entonces ignorará la firma. La notación se marca como legible por humanos.
--userid=USERID
Usa el ID de usuario autofirmado especificado
El ID de usuario especificado debe ser autofirmado.
--userid-by-email=EMAIL
Usa el ID de usuario autofirmado con la dirección de correo electrónico especificada

Opciones globales

Vea sq(1) para una descripción de las opciones globales.

EJEMPLOS

Retirar un ID de usuario en la clave de Alice.

sq key userid revoke --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0 --userid \
"Alice <alice@example.org>" --reason retired --message \
"Ya no está en example.org."
