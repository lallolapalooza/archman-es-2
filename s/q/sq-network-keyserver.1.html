NOMBRE

sq-network-keyserver - Recupera y publica certificados a través de servidores de claves

SINOPSIS

sq network keyserver search [OPCIONES] CONSULTA
sq network keyserver publish [OPCIONES]

DESCRIPCIÓN

Recupera y publica certificados a través de servidores de claves.

El Protocolo de Servidores de Claves HTTP (HKP) de OpenPGP es un método para publicar y recuperar certificados de servidores de claves.

SUBCOMANDOS

sq network keyserver search

Recupera certificados de servidores de claves.

Por defecto, cualquier certificado devuelto se almacena en el almacén de certificados local. Esto se puede anular utilizando la opción `--output`.

Cuando un certificado se recupera de un servidor de claves de verificación (actualmente, esto se limita a una lista de servidores conocidos: `hkps://keys.openpgp.org`, `hkps://keys.mailvelope.com`, y `hkps://mail-api.proton.me`), y se importa en el almacén de certificados local, los IDs de usuario también se certifican con una clave local específica del servidor. Esa clave proxy está certificada a su vez como una CA mínimamente confiable (nivel de confianza: 1 de 120) por la raíz de confianza local. La confiabilidad de una CA de servidor de claves proxy se puede ajustar usando `sq pki link add` o `sq pki link retract` de la manera habitual.

sq network keyserver publish

Publica certificados en servidores de claves.

Envía certificados a los servidores de claves configurados para su publicación. Por defecto, los certificados se envían a `hkps://keys.openpgp.org`, `hkps://mail-api.proton.me`, `hkps://keys.mailvelope.com`, `hkps://keyserver.ubuntu.com`, y `hkps://sks.pod01.fleetstreetops.com`. Esto se puede modificar utilizando `--servers`.

EJEMPLOS

sq network keyserver search

Recupera el certificado de Alice de los servidores de claves por defecto.

sq network keyserver search alice@example.org

Recupera el certificado de Alice dirigido por su huella digital de los servidores de claves por defecto.

sq network keyserver search \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Recupera el certificado de Alice de un servidor de claves no por defecto.

sq network keyserver search --server=hkps://keys.example.org \
alice@example.org

Recupera actualizaciones para todos los certificados conocidos de los servidores de claves por defecto.

sq network keyserver search --all

sq network keyserver publish

Publica el certificado de Alice en los servidores de claves por defecto.

sq network keyserver publish --cert-email=alice@example.org
