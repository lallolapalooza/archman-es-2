SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-pki-link-list - Listar enlaces

SINOPSIS

sq pki link list [OPCIONES] PATRÓN

DESCRIPCIÓN

Lista enlaces.

Este comando lista todos los enlaces que están enlazados o cuyo enlace ha sido retirado.

Devuelve un código de salida distinto de cero si un certificado designado explícitamente nunca fue enlazado.

OPCIONES

Opciones de subcomando

--ca
Solo lista enlaces enlazados como CAs
Es decir, solo lista un enlace si su profundidad de confianza es mayor que 0.
--cert=HUELLA_DIGITAL|ID_CLAVE
Usar certificados con la huella digital o ID de clave especificados
--cert-domain=DOMINIO
Usar certificados donde un ID de usuario incluya una dirección de correo electrónico para el dominio especificado
--cert-email=EMAIL
Usar certificados donde un ID de usuario incluya la dirección de correo electrónico especificada
--cert-grep=PATRÓN
Usar certificados con un ID de usuario que coincida con el patrón, sin distinguir entre mayúsculas y minúsculas
--cert-userid=ID_USUARIO
Usar certificados con el ID de usuario especificado

PATRÓN
Un patrón para seleccionar los enlaces a autenticar
El patrón se trata como una cadena codificada en UTF-8 y se realiza una búsqueda de subcadena insensible a mayúsculas y minúsculas (usando la configuración regional actual) contra cada ID de Usuario. Si un ID de Usuario no es UTF-8 válido, el enlace se ignora.

Opciones globales

Consulte sq(1) para una descripción de las opciones globales.

EJEMPLOS

Enlazar el certificado EB28F26E2739A4870ECC47726F0073F60FD0CBF0 con la dirección de correo electrónico alice@example.org.

sq pki link add \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--email=alice@example.org

Listar todos los enlaces.

sq pki link list

Listar enlaces a certificados con un ID de usuario autenticado que contenga una dirección de correo electrónico en el dominio especificado.

sq pki link list --cert-domain=example.org

VER TAMBIÉN

sq(1), sq-pki(1), sq-pki-link(1).

Para la documentación completa, consulte https://book.sequoia-pgp.org/.
