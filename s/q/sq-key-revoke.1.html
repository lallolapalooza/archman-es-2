NOMBRE

sq-key-revoke - Revocar un certificado

SINOPSIS

sq key revoke [OPCIONES]

DESCRIPCIÓN

Revoca un certificado.

Crea un certificado de revocación para un certificado.

Si se proporcionan `--revoker` o `--revoker-file`, entonces esa clave se utiliza para crear el certificado de revocación. Si esa clave es diferente de la clave que se está revocando, esto da como resultado una revocación por terceros. Esto normalmente solo es útil si el propietario del certificado designó la clave como un revocador designado.

`sq key revoke` respeta el tiempo de referencia establecido por el argumento de nivel superior `--time`. Cuando se establece, utiliza el tiempo especificado en lugar del tiempo actual al determinar qué claves son válidas, y establece la hora de creación del certificado de revocación en la hora de referencia en lugar de la hora actual.

OPCIONES

Opciones de subcomando

--cert=HUellaDIGITAL|IDDECLAVE
Revoca la clave con la huella digital o ID de clave especificados
--cert-email=CORREO
Revoca la clave donde un ID de usuario incluye la dirección de correo electrónico especificada
--cert-file=RUTA
Revoca la clave leída desde RUTA
--cert-userid=IDDEUSUARIO
Revoca la clave con el ID de usuario especificado
--message=MENSAJE
Un texto corto y explicativo
El texto se muestra a un espectador del certificado de revocación y explica por qué se ha revocado el certificado. Por ejemplo, si Alice ha creado una nueva clave, generaría un certificado de revocación `superseded` para su clave antigua, y podría incluir el mensaje `He creado un nuevo certificado, $FINGERPRINT, úselo en el futuro.`
--output=ARCHIVO
Escribir en el ARCHIVO especificado
Si no se especifica, y el certificado se leyó desde el almacén de certificados, importa el certificado modificado al almacén de certificados. Si no se especifica, y el certificado se leyó desde un archivo, escribe el certificado modificado en la salida estándar.
--reason=RAZÓN
La razón de la revocación
Si la razón ocurrió en el pasado, deberías especificarlo usando el argumento `--time`. Esto permite a las implementaciones de OpenPGP razonar con mayor precisión sobre artefactos cuya validez depende de la validez del certificado.
[valores posibles: compromised, superseded, retired, unspecified]
--revoker=HUellaDIGITAL|IDDECLAVE
Utiliza la clave con la huella digital o ID de clave especificados para crear el certificado de revocación
Firma el certificado de revocación usando la clave especificada. Por defecto, se utiliza el certificado que se está revocando. Usando esta opción, es posible crear una revocación por terceros.
--revoker-email=CORREO
Utiliza la clave donde un ID de usuario incluye la dirección de correo electrónico especificada para crear el certificado de revocación
Firma el certificado de revocación usando la clave especificada. Por defecto, se utiliza el certificado que se está revocando. Usando esta opción, es posible crear una revocación por terceros.
--revoker-file=RUTA
Lee la clave desde RUTA para crear el certificado de revocación
Firma el certificado de revocación usando la clave especificada. Por defecto, se utiliza el certificado que se está revocando. Usando esta opción, es posible crear una revocación por terceros.
--revoker-userid=IDDEUSUARIO
Utiliza la clave con el ID de usuario especificado para crear el certificado de revocación
Firma el certificado de revocación usando la clave especificada. Por defecto, se utiliza el certificado que se está revocando. Usando esta opción, es posible crear una revocación por terceros.
--signature-notation NOMBRE VALOR
Añade una notación a la firma
El nombre de una notación definida por el usuario debe tener el formato `nombre@dominio.que.controlas.org`. Si el nombre de la notación comienza con un `!`, entonces la notación se marca como crítica. Si un consumidor de una firma no entiende una notación crítica, ignorará la firma. La notación se marca como legible por humanos.

Opciones globales

Vea sq(1) para una descripción de las opciones globales.

EJEMPLOS

Revoca la clave de Alice, indicando que hay un nuevo certificado.

sq key revoke --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--reason superseded --message \
"Mi nuevo certificado es C5999E8191BF7B503653BE958B1F7910D01F86E5"

Revoca la clave, indicando que el material de la clave secreta fue comprometido.

sq key revoke --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--reason compromised --message \
"Ordenador atacado, material de clave secreta comprometido"
