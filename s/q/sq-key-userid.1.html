SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-key-userid - Gestionar IDs de usuario

SINOPSIS

sq key userid add [OPCIONES]
sq key userid revoke [OPCIONES]

DESCRIPCIÓN

Gestionar IDs de usuario.

Añade IDs de usuario a una clave o las revoca.

SUBCOMANDOS

sq key userid add

Añadir un ID de usuario.

Un ID de usuario puede contener un nombre, como `Juliet`, o una dirección de correo electrónico, como `<juliet@example.org>`. Históricamente, un nombre y una dirección de correo electrónico solían combinarse como un único ID de usuario, como `Juliet <juliet@example.org>`. Sin embargo, los IDs de usuario que incluyen información diferente, como nombre y dirección de correo electrónico, son más difíciles de razonar, por lo que hoy en día se prefiere el uso de IDs de usuario distintos para el nombre y la dirección de correo electrónico.

`sq key userid add` respeta el tiempo de referencia establecido por el argumento de nivel superior `--time`. Establece la hora de creación de la firma de enlace del ID de usuario a la hora especificada.

sq key userid revoke

Revocar un ID de usuario.

Crea un certificado de revocación para un ID de usuario.

Si se proporcionan `--revoker` o `--revoker-file`, esa clave se utiliza para crear el certificado de revocación. Si esa clave es diferente de la clave que se está revocando, esto resulta en una revocación por terceros. Esto normalmente solo es útil si el propietario del certificado designó la clave como revocador designado.

Para revocar un ID de usuario, el certificado debe ser válido según la política actual. Si el certificado no es válido según la política actual, considere revocar todo el certificado o corregirlo usando `sq cert lint` después de verificar la integridad del certificado. Si el certificado es válido según la política actual, pero el ID de usuario que desea revocar no lo es, aún puede revocar el ID de usuario usando `--add-userid`.

`sq key userid revoke` respeta el tiempo de referencia establecido por el argumento de nivel superior `--time`. Cuando se establece, utiliza la hora especificada en lugar de la hora actual al determinar qué claves son válidas, y establece la hora de creación del certificado de revocación a la hora de referencia en lugar de la hora actual.

EJEMPLOS

sq key userid add

# Añadir un nuevo ID de usuario a la clave de Alice.

sq key userid add --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0 --name Alice \
--email alice@work.example.com

sq key userid revoke

Retirar un ID de usuario en la clave de Alice.

sq key userid revoke --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0 --userid \
"Alice <alice@example.org>" --reason retired --message \
"Ya no está en example.org."
