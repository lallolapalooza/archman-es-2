NOMBRE

squirtorus - cómo se hacen los arcoíris.

SINOPSIS

squirtorus [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id número] [--delay número] [--speed número] [--count número] [--fps]

DESCRIPCIÓN

Un paisaje en desplazamiento emite arcoíris toroidales hacia el cielo. Arriba, las estrellas se van apagando lentamente.

OPCIONES

--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--delay número
Retraso por fotograma, en microsegundos. Predeterminado: 30000 (0.03 segundos).
--speed número
Velocidad de desplazamiento. 2.0 significa el doble de rápido, 0.5 significa la mitad de rápido.
--count número
Conteo. 1 - 50. Predeterminado: 12.
--fps | --no-fps
Si se muestra o no un indicador de fotogramas por segundo en la parte inferior de la pantalla.

AMBIENTE

DISPLAY
para obtener el host y número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
