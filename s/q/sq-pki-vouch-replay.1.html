SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-pki-vouch-replay - Reenvía avales

SINOPSIS

sq pki vouch replay [OPCIONES]

DESCRIPCIÓN

Reenvía avales.

Este comando reenvía los avales realizados por un certificado utilizando otro certificado. Esto es principalmente útil cuando se reemplaza un certificado y se desea que el nuevo certificado haya realizado las mismas certificaciones que se realizaron con el certificado antiguo.

Debido a que las certificaciones se asocian con el certificado certificado, y no con el certificado del certificador, esto puede no reenviar todas las certificaciones que la fuente realizó.

Este comando solo copia la certificación activa para un ID de usuario y certificado determinado. Esto incluye tanto las certificaciones exportables (avales) como las certificaciones no exportables (enlaces). Excluye las certificaciones caducadas. Tampoco reenvía certificaciones realizadas en certificados inválidos, caducados o revocados, o IDs de usuario revocados.

Este comando reenvía todos los parámetros de las certificaciones, incluyendo cualquier tiempo de expiración, pero el tiempo de creación se establece en el tiempo actual.

Estable desde 1.2.0.

OPCIONES

Opciones de subcomando

--allow-dissimilar-userids
No comprobar que la fuente y el destino comparten un ID de usuario autofirmado
Normalmente, este comando comprueba que los certificados de origen y destino tengan un ID de usuario en común. Esta bandera omite esa comprobación.
--output=ARCHIVO
Escribir en ARCHIVO o stdout si se omite
--source=HUellaDactilar|IDdeClave
Usar certificados con la huella dactilar o ID de clave especificado
--source-email=CORREO
Usar certificados donde un ID de usuario incluya la dirección de correo especificada
--source-file=RUTA
Leer certificados de RUTA
--source-userid=IDdeUsuario
Usar certificados con el ID de usuario especificado
--target=HUellaDactilar|IDdeClave
Usar certificados con la huella dactilar o ID de clave especificado
--target-email=CORREO
Usar certificados donde un ID de usuario incluya la dirección de correo especificada
--target-file=RUTA
Leer certificados de RUTA
--target-userid=IDdeUsuario
Usar certificados con el ID de usuario especificado

Opciones globales

Ver sq(1) para una descripción de las opciones globales.

EJEMPLOS

Alice genera un nuevo certificado y reenvía las certificaciones que realizó con el certificado antiguo utilizando el nuevo.

sq pki vouch replay \
--source=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--target=C5999E8191BF7B503653BE958B1F7910D01F86E5
