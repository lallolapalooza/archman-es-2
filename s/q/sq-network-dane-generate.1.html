SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-network-dane-generate - Genera registros DANE para el dominio y certificados dados

SINOPSIS

sq network dane generate [OPCIONES]

DESCRIPCIÓN

Genera registros DANE para el dominio y certificados dados.

Los certificados se minimizan y se emite un registro por dirección de correo electrónico. Si varios IDs de usuario se mapean a una dirección de correo electrónico, todos los IDs de usuario coincidentes se incluyen en los certificados emitidos.

Por defecto, se emiten registros de recursos OPENPGPKEY. Si su servidor DNS no los entiende, use `--type generic` para emitir registros genéricos en su lugar.

OPCIONES

Opciones de subcomando

--all
Publica certificados autenticados con un ID de usuario que coincida con el dominio
Utiliza todos los certificados que tienen un ID de usuario que coincide con el dominio dado al parámetro `--domain` que puede ser autenticado completamente.
--cert=HASH|IDCLAVE
Utiliza certificados con el hash o ID de clave especificado
--cert-email=EMAIL
Utiliza certificados donde un ID de usuario incluye la dirección de correo electrónico especificada
--cert-file=RUTA
Lee certificados desde RUTA
--cert-userid=IDUSUARIO
Utiliza certificados con el ID de usuario especificado
--domain=FQDN
Genera registros DANE para este nombre de dominio
--size-limit=BYTES
Intenta reducir los certificados a este tamaño
[por defecto: 12288]
--ttl=DURACION
Establece el TTL (duración máxima de caché) de los registros de recursos
[por defecto: 10800]
--type=TIPO
Cambia el tipo de registro de recursos emitido
[por defecto: openpgp]
[valores posibles: openpgp, generic]

Opciones globales

Ver sq(1) para una descripción de las opciones globales.

EJEMPLOS

Genera registros DANE desde juliet.pgp para example.org.

sq network dane generate --domain=example.org \
--cert-file=juliet.pgp

Genera registros DANE para todos los certificados con un ID de usuario autenticado en example.org.

sq network dane generate --domain=example.org --all
