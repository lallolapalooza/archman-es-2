NOMBRE

sq-pki-vouch-list - Listar certificaciones

SINOPSIS

sq pki vouch list [OPCIONES]

DESCRIPCIÓN

Listar certificaciones.

Si se proporciona el argumento certificador, se muestran las certificaciones hechas por el certificado especificado. Si se proporciona el argumento certificado, se muestran las certificaciones del certificado especificado. Si se proporcionan ambos, se muestran las certificaciones del certificado especificado hechas por el certificador especificado.

Este comando lista todas las certificaciones, no solo la certificación activa.

Dado que las certificaciones están asociadas al certificado certificado y no al certificado del certificador, esta lista probablemente esté incompleta.

Estable desde 1.2.0.

OPCIONES

Opciones del subcomando

--cert=HUELLA_DIGITAL|ID_CLAVE
Usar certificados con la huella digital o ID de clave especificada
--cert-email=EMAIL
Usar certificados donde un ID de usuario incluya la dirección de correo electrónico especificada
--cert-file=RUTA
Leer certificados desde RUTA
--cert-userid=ID_USUARIO
Usar certificados con el ID de usuario especificado
--certifier=HUELLA_DIGITAL|ID_CLAVE
Usar certificados con la huella digital o ID de clave especificada
--certifier-email=EMAIL
Usar certificados donde un ID de usuario incluya la dirección de correo electrónico especificada
--certifier-file=RUTA
Leer certificados desde RUTA
--certifier-self
Crear la certificación usando tu clave de certificación predeterminada
Esto utiliza los certificados establecidos en el archivo de configuración bajo `pki.vouch.certifier-self` como clave de certificación.
Actualmente, no hay una clave de certificación predeterminada.
--certifier-special=ESPECIAL
Usar certificados identificados por el nombre especial
[posibles valores: public-directories, keys.openpgp.org, keys.mailvelope.com, proton.me, wkd, dane, autocrypt, web]
--certifier-userid=ID_USUARIO
Usar certificados con el ID de usuario especificado

Opciones globales

Vea sq(1) para una descripción de las opciones globales.

EJEMPLOS

Listar certificaciones hechas por Alice.

sq pki vouch list \
--certifier=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Listar certificaciones hechas por Alice para el certificado de Bob.

sq pki vouch list \
--certifier=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--cert=511257EBBF077B7AEDAE5D093F68CB84CE537C9A
