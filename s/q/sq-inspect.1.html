SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-inspect - Inspecciona datos, como file(1)

SINOPSIS

sq inspect [OPCIONES] ARCHIVO

DESCRIPCIÓN

Inspecciona datos, como file(1).

A menudo es difícil saber por una inspección superficial usando cat(1) o file(1) qué tipo de OpenPGP se está mirando. Esta suborden inspecciona los datos y proporciona una descripción significativa en un formato legible por humanos.

`sq inspect` respeta la hora de referencia establecida por el argumento de nivel superior `--time`. Utiliza la hora de referencia al determinar qué firmas de enlace están activas.

OPCIONES

Opciones de suborden

--cert=HUELLA_DIGITAL|ID_CLAVE
Inspecciona certificados con la huella digital o ID de clave especificado
--cert-domain=DOMINIO
Inspecciona certificados donde un ID de usuario incluye una dirección de correo electrónico para el dominio especificado (nota: los ID de usuario no están autenticados)
--cert-email=CORREO
Inspecciona certificados donde un ID de usuario incluye la dirección de correo electrónico especificada (nota: los ID de usuario no están autenticados)
--cert-file=RUTA
Lee certificados desde RUTA
--cert-grep=PATRÓN
Inspecciona certificados con un ID de usuario que coincide con el patrón, sin distinguir mayúsculas y minúsculas (nota: los ID de usuario no están autenticados)
--cert-userid=ID_USUARIO
Inspecciona certificados con el ID de usuario especificado (nota: los ID de usuario no están autenticados)
--certifications
Muestra las certificaciones de terceros
--dump-bad-signatures
Descarga las firmas que son definitivamente malas

ARCHIVO
Lee desde ARCHIVO o stdin si ARCHIVO es '-'
[por defecto: -]

Opciones globales

Consulte sq(1) para una descripción de las opciones globales.

EJEMPLOS

Inspecciona un certificado.

sq inspect juliet.pgp

Muestra cómo se veía el certificado el 21 de julio de 2013.

sq inspect --time 20130721 juliet.pgp

Inspecciona un mensaje cifrado.

sq inspect message.pgp

Inspecciona una firma separada.

sq inspect document.sig

VER TAMBIÉN

sq(1).

Para la documentación completa, consulte https://book.sequoia-pgp.org/.
