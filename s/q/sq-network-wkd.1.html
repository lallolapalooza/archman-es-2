NOMBRE

sq-network-wkd - Recupera y publica certificados a través de Directorios de Claves Web

SINOPSIS

sq network wkd search [OPCIONES] DIRECCION
sq network wkd publish [OPCIONES] DESTINO

DESCRIPCIÓN

Recupera y publica certificados a través de Directorios de Claves Web (Web Key Directories).

El Directorio de Claves Web (WKD) es un método para publicar y recuperar certificados de servidores web.

SUBCOMANDOS

sq network wkd search

Recupera certificados de un Directorio de Claves Web.

Por defecto, cualquier certificado devuelto se almacena en el almacén de certificados local. Esto se puede anular utilizando la opción `--output`.

Cuando se recupera un certificado de un WKD y se importa en el almacén de certificados local, cualquier ID de usuario con la dirección de correo electrónico que se buscó se certifica con una clave específica del WKD local. Esa clave proxy está a su vez certificada como una CA mínimamente confiable (monto de confianza: 1 de 120) por la raíz de confianza local. La cantidad de confianza en la CA proxy del WKD se puede ajustar usando `sq pki link add` o `sq pki link retract` de la manera habitual.

sq network wkd publish

Publica certificados en un Directorio de Claves Web.

Publica certificados o actualizaciones de certificados en un Directorio de Claves Web (WKD). Puede crear o actualizar una jerarquía de WKD en el sistema local especificando una ruta como destino.

Normalmente, un WKD se almacena en un servidor web. Si se proporciona `--rsync`, este comando gestiona jerarquías de directorios WKD remotos utilizando rsync(1).

Para insertar un nuevo certificado en el WKD, utilice `--cert`.

Cualquier actualización de certificados ya existente en el WKD se publicará automáticamente.

Nota: Para actualizar una jerarquía de WKD, primero se copia a una ubicación temporal en la máquina local, se insertan los nuevos certificados o actualizaciones de certificados en la copia local y la jerarquía se copia de nuevo a su ubicación original. Como esto no es una operación atómica, se debe tener cuidado para evitar actualizaciones concurrentes.

EJEMPLOS

sq network wkd search

Recupera el certificado de Alice a través de WKD.

sq network wkd search alice@example.org

Recupera actualizaciones de todos los certificados conocidos a través de WKD.

sq network wkd search --all

sq network wkd publish

Crea una nueva jerarquía WKD en el directorio local `public_html`, e inserta el certificado de Alice.

sq network wkd publish --create \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--domain=example.org public_html

Agrega el certificado de Bob a la jerarquía WKD existente en el directorio local `public_html`.

sq network wkd publish \
--cert=511257EBBF077B7AEDAE5D093F68CB84CE537C9A \
--domain=example.org public_html

Agrega todos los certificados con un ID de usuario autenticado en example.org a la jerarquía WKD existente.

sq network wkd publish --domain=example.org --all public_html

Actualiza todos los certificados en la jerarquía WKD existente en el directorio local `public_html` desde el almacén de certificados.

sq network wkd publish --domain=example.org public_html
