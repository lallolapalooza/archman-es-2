NOMBRE

sqliterepo_c - Genera archivos de base de datos sqlite para un repositorio en formato rpm-md

SINOPSIS

sqliterepo_c [opciones] <directorio_repo>

OPCIONES

-V --version

Muestra el número de versión del programa y sale.

-q --quiet

Ejecutar en modo silencioso.

-v --verbose

Ejecutar en modo detallado.

-f --force

Sobrescribir las bases de datos existentes.

--keep-old

No eliminar bases de datos antiguas. Usar solo en combinación con --force.

--xz

Usar xz para la compresión de repodata.

--compress-type <tipo_compresion>

Qué tipo de compresión usar.

--checksum <tipo_checksum>

Qué tipo de checksum usar en repomd.xml para bases de datos sqlite.

--local-sqlite

Generar bases de datos sqlite localmente (en un directorio para archivos temporales). A veces, sqlite tiene problemas para generar bases de datos en montajes NFS, usa esta opción en esos casos. Esta opción puede llevar a un mayor consumo de memoria si TMPDIR está configurado a /tmp o no está configurado en absoluto, ya que entonces se usa el directorio /tmp y el directorio /tmp suele ser un ramdisk.
