NOMBRE

sq-network-keyserver-search - Recuperar certificados de servidores de claves

SINOPSIS

sq network keyserver search [OPCIONES] CONSULTA

DESCRIPCIÓN

Recupera certificados de servidores de claves.

Por defecto, cualquier certificado devuelto se almacena en el almacén de certificados local. Esto puede ser anulado usando la opción `--output`.

Cuando un certificado se recupera de un servidor de claves verificador (actualmente, esto se limita a una lista de servidores conocidos: `hkps://keys.openpgp.org`, `hkps://keys.mailvelope.com` y `hkps://mail-api.proton.me`), y se importa en el almacén de certificados local, los IDs de usuario también se certifican con una clave local específica del servidor. Esa clave de proxy se certifica a su vez como una CA mínimamente confiable (nivel de confianza: 1 de 120) por la raíz de confianza local. Cuánto se confía en una CA de servidor de claves proxy se puede ajustar usando `sq pki link add` o `sq pki link retract` de la manera habitual.

OPCIONES

Opciones del subcomando

--all
Obtener actualizaciones para todos los certificados conocidos
--output=ARCHIVO
Escribir en ARCHIVO (o stdout cuando se omite) en lugar de importar en el almacén de certificados
--server=URI
Establecer un servidor de claves a usar (se puede dar varias veces)
El valor predeterminado se puede cambiar en el archivo de configuración usando el ajuste `network.keyserver.servers`.
[predeterminado: hkps://keys.openpgp.org, hkps://mail-api.proton.me, hkps://keys.mailvelope.com, hkps://keyserver.ubuntu.com, hkps://sks.pod01.fleetstreetops.com]

CONSULTA
Recuperar certificado(s) usando CONSULTA
Esto puede ser una huella digital, un ID de clave o una dirección de correo electrónico.

Opciones globales

Ver sq(1) para una descripción de las opciones globales.

EJEMPLOS

Recuperar el certificado de Alice de los servidores de claves predeterminados.

sq network keyserver search alice@example.org

Recuperar el certificado de Alice dirigido por huella digital de los servidores de claves predeterminados.

sq network keyserver search \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Recuperar el certificado de Alice de un servidor de claves no predeterminado.

sq network keyserver search --server=hkps://keys.example.org \
alice@example.org

Recuperar actualizaciones para todos los certificados conocidos de los servidores de claves predeterminados.

sq network keyserver search --all
