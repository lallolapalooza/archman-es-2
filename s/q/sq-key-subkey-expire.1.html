NOMBRE

sq-key-subkey-expire - Cambiar el tiempo de expiración de una subclave

SINOPSIS

sq key subkey expire [OPCIONES]

DESCRIPCIÓN

Cambia el tiempo de expiración de una subclave.

Este subcomando cambia el tiempo de expiración de una clave. Para cambiar el tiempo de expiración del certificado, usa el subcomando `sq key expire`.

Cambiar el tiempo de expiración de la clave principal es equivalente a cambiar el tiempo de expiración del certificado. El tiempo de expiración de una subclave está limitado por la expiración del certificado.

OPCIONES

Opciones de subcomando

--cert=HUELLA_DIGITAL|ID_CLAVE
Cambia la expiración de las subclaves especificadas en la clave con la huella digital o ID de clave especificada.
--cert-email=EMAIL
Cambia la expiración de las subclaves especificadas en la clave donde un ID de usuario incluye la dirección de correo electrónico especificada.
--cert-file=RUTA
Cambia la expiración de las subclaves especificadas en la clave leída desde RUTA.
--cert-userid=ID_USUARIO
Cambia la expiración de las subclaves especificadas en la clave con el ID de usuario especificado.
--expiration=EXPIRACIÓN
Establece el tiempo de expiración.
EXPIRACIÓN es una fecha en formato ISO 8601 con una hora opcional o una duración personalizada. Una duración tiene el formato `N[ymwds]`, donde las letras representan años, meses, semanas, días y segundos, respectivamente. Alternativamente, la palabra clave `never` no establece un tiempo de expiración.
[por defecto: never]
--key=HUELLA_DIGITAL|ID_CLAVE
Usa la clave con la huella digital o ID de clave especificada.
--output=ARCHIVO
Escribe en el ARCHIVO especificado.
Si no se especifica, y el certificado se leyó desde el almacén de certificados, importa el certificado modificado al almacén de certificados. Si no se especifica, y el certificado se leyó desde un archivo, escribe el certificado modificado en la salida estándar.

Opciones globales

Ver sq(1) para una descripción de las opciones globales.

EJEMPLOS

Cambiar la subclave de autenticación de Alice para que expire en 6 meses.

sq key subkey expire --expiration 6m \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--key=0D45C6A756A038670FDFD85CB1C82E8D27DB23A1
