SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-decrypt - Descifrar un mensaje

SINOPSIS

sq decrypt [OPCIONES] ARCHIVO

DESCRIPCIÓN

Descifrar un mensaje.

Descifra un mensaje utilizando las claves proporcionadas, o solicitando una contraseña. Si se detecta manipulación del mensaje, se devuelve un error. Consulte a continuación para obtener más detalles.

Si se proporcionan certificados utilizando la opción `--signer-file`, cualquier firma encontrada se verifica utilizando estos certificados. La verificación solo tiene éxito si no hay firmas incorrectas y el número de firmas verificadas con éxito alcanza el umbral configurado con el parámetro `--signatures`.

Si la verificación de la firma falla, o si se detecta manipulación del mensaje, el programa termina con un estado de salida que indica fallo y el archivo de salida se elimina. Si la salida se envió a stdout, se retienen los últimos 25 MiB del mensaje (en consecuencia, si el mensaje es menor a 25 MiB, no se produce ninguna salida).

La operación inversa es `sq encrypt`.

OPCIONES

Opciones de subcomando

--dump-session-key
Imprime la clave de sesión en stderr
--output=ARCHIVO
Escribe en ARCHIVO o stdout si se omite
[predeterminado: -]
--recipient-file=ARCHIVO_CLAVE
Descifra el mensaje usando la clave en ARCHIVO_CLAVE
--session-key=CLAVE_SESION
Descifra un mensaje cifrado usando CLAVE_SESION
--signatures=N
Establece el umbral de firmas válidas a N
El mensaje solo se considerará verificado si se alcanza este umbral. [predeterminado: 1 si se proporciona al menos un archivo de certificado de remitente, 0 en caso contrario]
--signer=HUella_DIGITAL|ID_CLAVE
Requiere una firma de un certificado con la huella digital o ID de clave especificado
--signer-domain=DOMINIO
Requiere una firma de un certificado donde un ID de usuario incluye una dirección de correo electrónico para el DOMINIO especificado
--signer-email=EMAIL
Requiere una firma de un certificado donde un ID de usuario incluye la dirección de correo electrónico especificada
--signer-file=RUTA
Requiere una firma de un certificado leído desde RUTA
--signer-userid=ID_USUARIO
Requiere una firma de un certificado con el ID de usuario especificado

ARCHIVO
Lee desde ARCHIVO o stdin si ARCHIVO es '-'
[predeterminado: -]

Opciones globales

Vea sq(1) para una descripción de las opciones globales.

EJEMPLOS

Descifrar un archivo usando una clave secreta

sq decrypt --recipient-file juliet-secret.pgp ciphertext.pgp

Descifrar un archivo verificando firmas

sq decrypt --recipient-file juliet-secret.pgp --signer-file \
romeo.pgp ciphertext.pgp

descifrar un archivo usando el almacén de claves

sq decrypt ciphertext.pgp
