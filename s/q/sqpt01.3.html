real function sqpt01 (integer m, integer n, integer k, real, dimension( lda, * ) a, real, dimension( lda, * ) af, integer lda, real, dimension( * ) tau, integer, dimension( * ) jpvt, real, dimension( lwork ) work, integer lwork)

SQPT01

Propósito:

!>
!> SQPT01 prueba la factorización QR con pivoteo de una matriz A. El
!> array AF contiene la factorización QR (posiblemente parcial) de A, donde
!> el triángulo superior de AF(1:k,1:k) es un factor triangular parcial,
!> las entradas debajo de la diagonal en las primeras k columnas son los
!> vectores de Householder, y el resto de AF contiene una matriz parcialmente
!> actualizada.
!>
!> Esta función devuelve ||A*P - Q*R|| / ( ||norm(A)||*eps*max(M,N) )
!> donde || . || es la norma uno de la matriz.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de las matrices A y AF.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y AF.
!>

K

!>          K es INTEGER
!>          El número de columnas de AF que se han reducido
!>          a forma triangular superior.
!>

A

!>          A es un array REAL de dimensión (LDA, N)
!>          La matriz original A.
!>

AF

!>          AF es un array REAL de dimensión (LDA,N)
!>          La salida (posiblemente parcial) de SGEQPF. El triángulo superior
!>          de AF(1:k,1:k) es un factor triangular parcial, las entradas
!>          debajo de la diagonal en las primeras k columnas son los vectores
!>          de Householder, y el resto de AF contiene una matriz parcialmente
!>          actualizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de los arrays A y AF.
!>

TAU

!>          TAU es un array REAL de dimensión (K)
!>          Detalles de las transformaciones de Householder devueltas por
!>          SGEQPF.
!>

JPVT

!>          JPVT es un array INTEGER de dimensión (N)
!>          Información de pivote devuelta por SGEQPF.
!>

WORK

!>          WORK es un array REAL de dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= M*N+N.
!>
