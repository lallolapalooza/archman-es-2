SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-packet-armor - Convertir binario a ASCII

SINOPSIS

sq packet armor [OPCIONES] ARCHIVO

DESCRIPCIÓN

Convertir binario a ASCII.

Para facilitar el manejo y transporte de datos cifrados, los datos OpenPGP pueden transformarse a una representación ASCII llamada ASCII Armor. sq emite datos "armored" por defecto, pero este subcomando se puede usar para convertir datos OpenPGP existentes a su representación codificada en ASCII.

La operación inversa es `sq packet dearmor`.

OPCIONES

Opciones de subcomando

--label=ETIQUETA
Seleccionar el tipo de encabezado de armor
[por defecto: auto]
[valores posibles: auto, message, cert, key, sig, file]
--output=ARCHIVO
Escribir en ARCHIVO o stdout si se omite
[por defecto: -]

ARCHIVO
Leer de ARCHIVO o stdin si ARCHIVO es '-'
[por defecto: -]

Opciones globales

Ver sq(1) para una descripción de las opciones globales.

EJEMPLOS

Convertir un mensaje OpenPGP binario a un mensaje OpenPGP codificado en ASCII.

sq packet armor mensaje.bin

Convertir un mensaje OpenPGP binario a un mensaje OpenPGP codificado en ASCII eligiendo explícitamente la etiqueta de armor.

sq packet armor --label=message mensaje.bin

VER TAMBIÉN

sq(1), sq-packet(1).

Para la documentación completa, véase https://book.sequoia-pgp.org/.
