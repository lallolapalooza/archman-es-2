Documentación de la Función/Subrutina

subroutine sqrt03 (integer m, integer n, integer k, real, dimension( lda, * ) af, real, dimension( lda, * ) c, real, dimension( lda, * ) cc, real, dimension( lda, * ) q, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

SQRT03

Propósito:

!>
!> SQRT03 prueba SORMQR, que calcula Q*C, Q'*C, C*Q o C*Q'.
!>
!> SQRT03 compara los resultados de una llamada a SORMQR con los resultados de
!> formar Q explícitamente mediante una llamada a SORGQR y luego realizar la multiplicación
!> de matrices mediante una llamada a SGEMM.
!>

Parámetros

M 
!>          M es INTEGER
!>          El orden de la matriz ortogonal Q.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de filas o columnas de la matriz C; C es m-por-n si
!>          Q se aplica desde la izquierda, o n-por-m si Q se aplica desde
!>          la derecha.  N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define la
!>          matriz ortogonal Q.  M >= K >= 0.
!>

AF

!>          AF es REAL array, dimension (LDA,N)
!>          Detalles de la factorización QR de una matriz m-por-n, como
!>          devuelto por SGEQRF. Consulte SGEQRF para más detalles.
!>

C

!>          C es REAL array, dimension (LDA,N)
!>

CC

!>          CC es REAL array, dimension (LDA,N)
!>

Q

!>          Q es REAL array, dimension (LDA,M)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de los arrays AF, C, CC y Q.
!>

TAU

!>          TAU es REAL array, dimension (min(M,N))
!>          Los factores escalares de los reflectores elementales correspondientes
!>          a la factorización QR en AF.
!>

WORK

!>          WORK es REAL array, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK debe ser al menos M, y debería ser
!>          M*NB, donde NB es el tamaño del bloque para este entorno.
!>

RWORK

!>          RWORK es REAL array, dimension (M)
!>

RESULT

!>          RESULT es REAL array, dimension (4)
!>          Las razones de prueba comparan dos técnicas para multiplicar una
!>          matriz aleatoria C por una matriz ortogonal m-por-m Q.
!>          RESULT(1) = norm( Q*C - Q*C )  / ( M * norm(C) * EPS )
!>          RESULT(2) = norm( C*Q - C*Q )  / ( M * norm(C) * EPS )
!>          RESULT(3) = norm( Q'*C - Q'*C )/ ( M * norm(C) * EPS )
!>          RESULT(4) = norm( C*Q' - C*Q' )/ ( M * norm(C) * EPS )
!>
