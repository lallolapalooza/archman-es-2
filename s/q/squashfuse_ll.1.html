NOMBRE

squashfuse_ll — montar un archivo SquashFS con FUSE de bajo nivel

SINOPSIS

squashfuse_ll [-o opciones] archivo punto_de_montaje

DESCRIPCIÓN

squashfuse_ll monta el sistema de archivos SquashFS usando FUSE archivo en el directorio punto_de_montaje. Generalmente es compatible con squashfuse(1) pero utiliza la interfaz FUSE de bajo nivel de mayor rendimiento y soporta multihilo.

Consulte la página del manual squashfuse(1) para ver las opciones. Tenga en cuenta que algunas de las opciones de la biblioteca fuse(8) solo se admiten en FUSE de alto nivel y, por lo tanto, no se aplican. Estas opciones adicionales también se admiten, incluidas algunas que normalmente solo se admiten en FUSE de alto nivel:

-o timeout=N
inactivo N segundos para desmontaje automático
-o uid=N
establecer el propietario del archivo en uid N
-o gid=N
establecer el grupo del archivo en gid N

VER TAMBIÉN
