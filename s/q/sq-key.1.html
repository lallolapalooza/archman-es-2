NOMBRE

sq-key - Administrar claves

SINOPSIS

sq key list [OPCIONES] HUELLA DIGITAL|ID DE CLAVE|PATRÓN
sq key generate [OPCIONES]
sq key rotate [OPCIONES]
sq key import [OPCIONES] ARCHIVO_CLAVE
sq key export [OPCIONES]
sq key delete [OPCIONES]
sq key password [OPCIONES]
sq key expire [OPCIONES]
sq key revoke [OPCIONES]
sq key userid [OPCIONES] SUBCOMANDO
sq key subkey [OPCIONES] SUBCOMANDO
sq key approvals [OPCIONES] SUBCOMANDO

DESCRIPCIÓN

Administra claves.

Usamos el término "clave" para referirnos a claves OpenPGP que contienen secretos. Esta subcomando proporciona primitivas para generar y manipular claves de otras maneras.

Por el contrario, usamos el término "certificado", o "cert" para abreviar, para referirnos a claves OpenPGP que no contienen secretos. Consulte `sq cert` para operaciones sobre certificados.

SUBCOMANDOS

sq key list

Lista las claves administradas por el almacén de claves.

sq key generate

Genera una nueva clave.

Generar una clave es el requisito previo para recibir mensajes cifrados y crear firmas. Hay algunos parámetros para este proceso, pero proporcionamos valores predeterminados razonables para la mayoría de los usuarios.

Al generar una clave, también generamos un certificado de revocación de emergencia. Esto se puede usar en caso de que la clave se pierda o se vea comprometida. Se guarda junto con la clave. Esto se puede cambiar usando el argumento `--rev-cert`.

Por defecto, una clave expira después de 3 años. Esto se puede cambiar usando el argumento `--expiration`.

`sq key generate` respeta el tiempo de referencia establecido por el argumento de nivel superior `--time`. Establece la hora de creación de la clave principal, todas las sub-claves y las firmas de enlace a la hora de referencia.

sq key rotate

Rota un certificado.

Genera un nuevo certificado para reemplazar uno existente.

El nuevo certificado tendrá las mismas capacidades que el certificado antiguo. Esto se puede anular utilizando los argumentos `--can-sign`, `--cannot-sign`, etc. Nota: el nuevo certificado puede tener una forma diferente al certificado antiguo. Por ejemplo, si la clave principal del certificado antiguo tiene capacidad tanto de certificación como de firma, la clave principal del nuevo certificado tendrá capacidad de certificación y tendrá una sub-clave de firma.

Por defecto, el certificado expira después de 3 años. Esto se puede cambiar usando el argumento `--expiration`.

El nuevo certificado tendrá los mismos IDs de usuario auto-firmados que el certificado antiguo. Los IDs de usuario revocados se ignoran.

El nuevo certificado y el certificado antiguo se certificarán mutuamente como introductoras confiables sin restricciones.

El nuevo certificado se vinculará de la misma manera que el certificado antiguo. Esto se puede anular utilizando el argumento `--own-key` o `--shared-key`.

El nuevo certificado certificará los mismos certificados que el certificado antiguo. Es decir, se reproducirán las certificaciones del certificado antiguo. Consulte `sq pki vouch replay` para obtener más información.

Se emitirá un certificado de revocación que indica que el certificado antiguo está retirado y que se debe utilizar el nuevo certificado en su lugar. Por defecto, entrará en vigor en 182 días. Esto se puede cambiar o suprimir utilizando el argumento `--retire-in`.

Al usar `--output`, el nuevo certificado y todos los demás certificados actualizados se escriben en el archivo especificado.

Estable desde 1.2.0.

sq key import

Importa claves al almacén de claves.

sq key export

Exporta claves del almacén de claves.

Exporta el material de clave secreta asociado con un certificado. Tenga en cuenta que incluso si el material de clave secreta está disponible, puede que no sea exportable. Por ejemplo, el material de clave secreta almacenado en un módulo de seguridad de hardware generalmente no se puede exportar del dispositivo.

Itera sobre todos los certificados especificados y exporta cualquier clave (clave principal y sub-claves) con material de clave secreta. Se devuelve un error si algún certificado especificado no contiene material de clave secreta.

Si solo desea exportar una clave en particular y no todas las claves asociadas con un certificado, utilice `sq key subkey export`.

sq key delete

Elimina el material de clave secreta de un certificado.

sq key password

Cambia la contraseña que protege el material de clave secreta.

El material de clave secreta puede estar protegido por una contraseña. Este subcomando cambia o borra la contraseña.

Para eliminar la contraseña, utilice `--clear` o proporcione una contraseña de longitud cero cuando se le solicite la nueva contraseña.

Si una clave está protegida por contraseña y no se proporcionó la contraseña correcta usando el argumento `--password-file`, se le pedirá al usuario la contraseña. De manera similar, si no se proporciona la nueva contraseña, se le pedirá al usuario.

sq key expire

Cambia la fecha de expiración de un certificado.

Este subcomando cambia la fecha de expiración de un certificado. Para cambiar la fecha de expiración de una sub-clave individual, utilice el subcomando `sq key subkey expire`.

sq key revoke

Revoca un certificado.

Crea un certificado de revocación para un certificado.

Si se proporcionan `--revoker` o `--revoker-file`, esa clave se utiliza para crear el certificado de revocación. Si esa clave es diferente del certificado que se está revocando, esto resulta en una revocación por terceros. Esto normalmente solo es útil si el propietario del certificado designó la clave como un revocador designado.

`sq key revoke` respeta el tiempo de referencia establecido por el argumento de nivel superior `--time`. Cuando se establece, utiliza el tiempo especificado en lugar del tiempo actual al determinar qué claves son válidas, y establece la hora de creación del certificado de revocación en el tiempo de referencia en lugar del tiempo actual.

sq key userid

Administra IDs de usuario.

Añade IDs de usuario a una clave o los revoca.

sq key subkey

Administra sub-claves.

Añade nuevas sub-claves a un certificado existente, cambia su expiración y las revoca.

sq key approvals

Administra aprobaciones de certificación.

Los titulares de claves pueden aprobar certificaciones de terceros asociadas con su certificado. Este subcomando administra las aprobaciones.

Para prevenir ataques de inundación de certificados, los servidores de claves modernos impiden la distribución no controlada de certificaciones de terceros en los certificados. Para permitir que el titular de la clave controle qué información se distribuye con su certificado, estos servidores de claves solo distribuyen certificaciones de terceros que el titular de la clave ha aprobado explícitamente.

EJEMPLOS

sq key list

Lista las claves administradas por el servidor de almacén de claves.

sq key list

Lista las claves administradas por el servidor de almacén de claves con un ID de usuario en example.org.

sq key list --cert-domain=example.org

sq key generate

Genera una clave y la guarda en el almacén de claves.

sq key generate --own-key --name Alice --email \
alice@example.org

Genera una clave y la guarda en un archivo en lugar de en el almacén de claves.

sq key generate --own-key --name Alice --email \
alice@example.org --output alice-priv.pgp --rev-cert \
alice-priv.rev

sq key rotate

Rota una clave.

sq key rotate --output retired.pgp --retire-in 182 \
--new-key 1 --new-key-sig-badger \
--new-key-can-sign --new-key-not-after \
2024-12-31T23:59:59Z \
--new-key-expiration 3y \
--new-key-can-certify \
--new-key-can-sign \
--new-key-can-encrypt-comm \
--new-key-can-encrypt-storage \
--new-key-master-badger \
alice@example.org

sq key import

Importa una clave desde un archivo.

sq key import bob.pgp

sq key export

Exporta claves desde el almacén de claves.

sq key export --output alice.pgp alice@example.org

sq key delete

Elimina la clave de Alice del almacén de claves.

sq key delete alice@example.org

sq key password

Cambia la contraseña de la clave de Alice.

sq key password alice@example.org

Borra la contraseña de la clave de Alice.

sq key password --clear alice@example.org

sq key expire

Cambia la fecha de expiración de la clave de Alice a 1 año.

sq key expire --new-expiration 1y alice@example.org

sq key revoke

Revoca la clave de Alice.

sq key revoke alice@example.org

Revoca la clave de Alice con el certificado de revocación guardado en `alice.rev`.

sq key revoke --output alice.rev alice@example.org

Revoca la clave de Alice con la clave de Bob como revoker.

sq key revoke --revoker bob@example.org alice@example.org

sq key userid

Añade un nuevo ID de usuario a la clave de Alice.

sq key userid --add --user-id \
"Alice Smith <alice.smith@example.org>" alice@example.org

Revoca un ID de usuario de la clave de Alice.

sq key userid --revoke --user-id \
"Alice Smith <alice.smith@example.org>" alice@example.org

sq key subkey

Añade una nueva sub-clave de firma a la clave de Alice.

sq key subkey --add --can-sign --expiration 1y \
alice@example.org

Añade una nueva sub-clave de cifrado a la clave de Alice.

sq key subkey --add --can-encrypt-comm \
--can-encrypt-storage --expiration 1y \
alice@example.org

Cambia la fecha de expiración de la primera sub-clave de Alice a 1 año.

sq key subkey --expiration 1y --index 1 alice@example.org

Revoca la primera sub-clave de Alice.

sq key subkey --revoke --index 1 alice@example.org

sq key approvals

Aprobación de una certificación de terceros.

sq key approvals --approve --cert-sig \
sha256:42d574e20d0711e7b368e7793b8b4129a6767f32e2512151f9443e44c508e498 \
alice@example.org

Rechaza una certificación de terceros.

sq key approvals --reject --cert-sig \
sha256:42d574e20d0711e7b368e7793b8b4129a6767f32e2512151f9443e44c508e498 \
alice@example.org

Crea un certificado de aprobación de certificación.

sq key approvals --output approve.pgp alice@example.org

Lista las aprobaciones de certificación para la clave de Alice.

sq key approvals alice@example.org

NOMBRE

sq key - gestionar las claves de Sequoia

SINOPSIS

Comandos de subgrupo de claves de sq key:

sq key list [OPCIONES]
Listar las claves del almacén.
sq key generate [OPCIONES]
Generar una nueva clave.
sq key rotate [OPCIONES] CERT...
Rotar las claves del almacén.
sq key import [OPCIONES] ARCHIVO...
Importar claves al almacén.
sq key export [OPCIONES] CERT...
Exportar claves del almacén.
sq key delete [OPCIONES] CERT...
Eliminar claves del almacén.
sq key password [OPCIONES] CERT...
Cambiar la contraseña de las claves del almacén.
sq key expire [OPCIONES] CERT...
Cambiar la fecha de expiración de las claves del almacén.
sq key revoke [OPCIONES] CERT...
Revocar las claves del almacén.
sq key userid [OPCIONES] CERT...
Gestionar los IDs de usuario de las claves del almacén.
sq key subkey [OPCIONES] CERT...
Gestionar las subclaves de las claves del almacén.
sq key approvals [OPCIONES] CERT...
Gestionar las aprobaciones de las claves del almacén.

DESCRIPCIÓN

Este es un documento maestro para los subcomandos de claves de Sequoia.

SUBCOMANDOS

sq key rotate
Rota el certificado de Alice.
sq key import
Importa las claves al almacén.
sq key export
Exporta el certificado de Alice con todo el material de clave secreta disponible.
sq key delete
Elimina cualquier clave secreta asociada con el certificado de Alice.
sq key password
Cambia la contraseña de todas las claves de Alice a la contraseña en el archivo especificado.
Borra la protección de contraseña para todas las claves de Alice.
sq key expire
Cambia el certificado de Alice para que expire en un año.
Cambia el certificado de Alice para que nunca expire.
sq key revoke
Revoca la clave de Alice, indicando que hay un nuevo certificado.
Revoca la clave, indicando que el material de la clave secreta fue comprometido.

EJEMPLOS

sq key rotate

Rota el certificado de Alice.

sq key rotate --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0

sq key import

Importa las claves al almacén.

sq key import alice-secret.pgp

sq key export

Exporta el certificado de Alice con todo el material de clave secreta disponible.

sq key export --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Exporta el certificado de Alice con todo el material de clave secreta disponible identificado por dirección de correo electrónico.

sq key export --cert-email alice@example.org

sq key delete

Elimina cualquier clave secreta asociada con el certificado de Alice.

sq key delete --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Elimina cualquier clave secreta asociada con el certificado de Alice seleccionado por ID de usuario.

sq key delete --cert-email=alice@example.org

sq key password

Cambia la contraseña de todas las claves de Alice a la contraseña en el archivo especificado.

sq key password --new-password-file password-file.txt --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Borra la protección de contraseña para todas las claves de Alice.

sq key password --password-file password-file.txt \
--clear-password --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

sq key expire

Cambia el certificado de Alice para que expire en un año.

sq key expire --expiration 1y --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Cambia el certificado de Alice para que nunca expire.

sq key expire --expiration never --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

sq key revoke

Revoca la clave de Alice, indicando que hay un nuevo certificado.

sq key revoke --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--reason superseded --message \
"Mi nuevo certificado es C5999E8191BF7B503653BE958B1F7910D01F86E5"

Revoca la clave, indicando que el material de la clave secreta fue comprometido.

sq key revoke --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--reason compromised --message \
"Ordenador atacado, material de clave secreta comprometido"
