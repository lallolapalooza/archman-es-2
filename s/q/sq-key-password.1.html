SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-key-password - Cambia la contraseña que protege el material de clave secreta

SINOPSIS

sq key password [OPCIONES]

DESCRIPCIÓN

Cambia la contraseña que protege el material de clave secreta.

El material de clave secreta puede ser protegido por una contraseña. Este subcomando cambia o borra la contraseña.

Para eliminar la contraseña, utiliza `--clear` o proporciona una contraseña de longitud cero cuando se te solicite la nueva contraseña.

Si una clave está protegida por contraseña y no se proporcionó la contraseña correcta usando el argumento `--password-file`, se le pedirá al usuario la contraseña. De manera similar, si no se proporciona la nueva contraseña, se le pedirá al usuario.

OPCIONES

Opciones del subcomando

--cert=HUellaDactilar|IDCLAVE
Cambia la contraseña para el material de clave secreta de la clave con la huella digital o ID de clave especificado.
--cert-email=CORREO
Cambia la contraseña para el material de clave secreta de la clave donde un ID de usuario incluye la dirección de correo electrónico especificada.
--cert-file=RUTA
Cambia la contraseña para el material de clave secreta de la clave leída desde RUTA.
--cert-userid=IDUSUARIO
Cambia la contraseña para el material de clave secreta de la clave con el ID de usuario especificado.
--clear-password
Borra la contraseña que protege el material de clave secreta.
--new-password-file=ARCHIVO_CONTRASEÑA
Archivo que contiene la contraseña para cifrar el material de clave secreta.
Ten en cuenta que se utilizará todo el archivo de clave como contraseña, incluyendo cualquier espacio en blanco circundante, como una nueva línea final.
--output=ARCHIVO
Escribe en ARCHIVO o en la salida estándar si se omite.

Opciones globales

Consulta sq(1) para una descripción de las opciones globales.

EJEMPLOS

Cambia la contraseña de todas las claves de Alice a la contraseña en el archivo especificado.

sq key password --new-password-file archivo-contraseña.txt --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Borra la protección por contraseña para todas las claves de Alice.

sq key password --password-file archivo-contraseña.txt \
--clear-password --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0
