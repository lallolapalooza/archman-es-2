SQ-KEYRING-LINTER(1) Comandos de usuario SQ-KEYRING-LINTER(1)

NOMBRE

sq-keyring-linter - sq-keyring-linter

DESCRIPCIÓN

sq-keyring-linter 0.5.0

"sq-keyring-linter" comprueba y opcionalmente repara certificados OpenPGP que utilizan SHA-1.

USO:

sq-keyring-linter [FLAGS] [OPTIONS] [--] [FILES]...

FLAGS:

-e, --export-secret-keys

Al reparar un certificado, el certificado reparado se exporta sin ningún material de clave secreta. El uso de este interruptor hace que cualquier material de clave secreta también se exporte.

-f, --fix

Intenta reparar certificados, cuando sea posible.

-h, --help

Imprime información de ayuda.

-k, --list-keys

Si se establece, emite una lista de huellas dactilares, una por línea, de los certificados que tienen problemas. Esta salida está destinada a ser utilizada por scripts.
Esta opción implica "--quiet". Si también especifica "--fix", los errores aún se imprimirán en stderr, y los certificados reparados aún se emitirán en stdout.

-q, --quiet

Silencioso; no emite ningún diagnóstico.

-V, --version

Imprime información de la versión.

OPCIONES:

-p, --password <contraseña>...

Contraseña de una clave.
Normalmente no es necesaria: si stdin está
conectado a un tty, el linter pedirá una contraseña cuando sea necesario.

ARGUMENTOS:

<FILES>...
Una lista de keyrings OpenPGP a procesar.
Si no se
especifica ninguno, se lee un keyring desde stdin.

"sq-keyring-linter" comprueba los certificados proporcionados en busca de los siguientes problemas relacionados con SHA-1:

- Si la revocación de un certificado utiliza SHA-1.
- Si la firma propia actual de un ID de usuario no revocado utiliza
SHA-1.
- Si la firma de enlace de subclave actual de una subclave
activa y no revocada utiliza SHA-1.
- Si una firma de enlace de clave principal (un "backsig") para
una subclave activa y no revocada utiliza SHA-1.

Los diagnósticos se imprimen en stderr. Al final, se muestran algunas estadísticas. Esto es útil al examinar un keyring. Si se especifica "--fix" y al menos un problema pudo ser reparado, los certificados reparados se imprimen en stdout.

Esta herramienta no admite tarjetas inteligentes actualmente. Pero, si solo las subclaves están en una tarjeta inteligente, esta herramienta aún puede reparar parcialmente el certificado. En particular, podrá solucionar cualquier problema con las firmas propias de los ID de usuario y las firmas de enlace de subclave para subclaves capaces de cifrado, pero no podrá generar nuevas firmas de enlace de clave principal para ninguna subclave capaz de firmar.

ESTADO DE SALIDA:

Si --fix" no se especifica:"

2
si se encontraron problemas,
1
si no se encontraron problemas, pero hubo errores al leer la entrada,
0
si no hubo problemas.

Si --fix" se especifica:"

3
si no se pudieron solucionar algunos problemas,
1
si no se encontraron problemas, pero hubo errores al leer la entrada,
0
si se solucionaron todos los problemas o no hubo problemas.

EJEMPLOS:

# Para recopilar estadísticas, simplemente ejecuta: $ sq-keyring-linter keyring.pgp
# Para reparar una clave: $ gpg --export-secret-keys FPR | sq-keyring-linter --fix -p contraseña

-p contraseña123 | gpg --import

# Para obtener una lista de claves con problemas: $ sq-keyring-linter --list-keys keyring.pgp | while read FPR; do

algo; done
