SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-keyring - Gestionar colecciones de claves o certificados

SINOPSIS

sq keyring list [OPCIONES] ARCHIVO
sq keyring split [OPCIONES] ARCHIVO
sq keyring merge [OPCIONES] ARCHIVO
sq keyring filter [OPCIONES] ARCHIVO

DESCRIPCIÓN

Gestionar colecciones de claves o certificados.

Las colecciones de claves o certificados (también conocidas como "keyrings" cuando contienen material de claves secretas, y "certrings" cuando no) son cualquier número de certificados concatenados. Esta subcomando proporciona herramientas para listar, dividir, fusionar y filtrar keyrings.

Nota: En la documentación de este subcomando, a veces usamos los términos claves y certificados de forma intercambiable.

SUBCOMANDOS

sq keyring list

Listar claves en un keyring.

Imprime la huella digital así como el identificador de usuario principal para cada certificado encontrado en el keyring.

sq keyring split

Dividir un keyring en claves individuales.

Dividir un keyring en claves individuales ayuda a curar un keyring.

La operación inversa es `sq keyring merge`.

sq keyring merge

Fusionar claves o keyrings en un solo keyring.

Se fusionan múltiples versiones del mismo certificado. Donde los datos son reemplazados (por ejemplo, material de claves secretas), se prefieren los datos del certificado posterior.

sq keyring filter

Unir claves en un keyring aplicando un filtro.

Esto puede ser usado para filtrar claves basándose en predicados dados, por ejemplo, si tienen un identificador de usuario que contiene una dirección de correo electrónico con un dominio específico. Adicionalmente, las claves pueden ser podadas para incluir solo componentes que coincidan con los predicados.

Si no se proporcionan filtros, todo coincide.

Si se dan múltiples predicados, se combinan con un OR, es decir, una clave coincide si alguno de los predicados coincide. Para requerir que todos los predicados coincidan, encadena múltiples invocaciones de este comando. Ver EJEMPLOS para inspiración.

Nota: este comando se considera experimental y puede cambiar en futuras versiones. Para reconocer esto, debes dar la bandera `--experimental` al invocar este comando.

EJEMPLOS

sq keyring list

Listar todos los certificados.

sq keyring list certs.pgp

Listar todos los certificados con un identificador de usuario en example.org.

sq keyring filter --experimental --domain=example.org \
certs.pgp \
| sq keyring list

sq keyring split

Dividir todos los certificados.

sq keyring split certs.pgp

Dividir todos los certificados, fusionándolos primero para evitar duplicados.

sq keyring merge certs.pgp \
| sq keyring split

sq keyring merge

Fusionar actualizaciones de certificados.

sq keyring merge bob.pgp bob-updates.pgp

sq keyring filter

Convertir todas las claves a certificados (es decir, eliminar cualquier material de clave secreta).

sq keyring filter --experimental --to-cert certs.pgp

Obtener todos los certificados con un identificador de usuario en example.org.

sq keyring filter --experimental --domain=example.org \
certs.pgp

Obtener todos los certificados con un identificador de usuario en example.org o example.net.

sq keyring filter --experimental --domain=example.org \
--domain=example.net certs.pgp

Obtener todos los certificados con un identificador de usuario de nombre que coincida con Romeo.

sq keyring filter --experimental --name=Romeo certs.pgp

Obtener todos los certificados con un identificador de usuario de nombre que coincida con Romeo en example.org.

sq keyring filter --experimental --domain=example.org \
certs.pgp \
| sq keyring filter --experimental --name=Romeo

Obtener todos los certificados con un identificador de usuario en example.org, podando otros identificadores de usuario.

sq keyring filter --experimental --domain=example.org \
--prune-certs certs.pgp
