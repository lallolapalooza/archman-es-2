NOMBRE

sq-key-approvals-update - Aprueba certificaciones de terceros permitiendo su distribución

SINOPSIS

sq key approvals update [OPCIONES]

DESCRIPCIÓN

Aprueba certificaciones de terceros permitiendo su distribución.

Para prevenir ataques de inundación de certificados, los servidores de claves modernos impiden la distribución incontrolada de certificaciones de terceros en certificados. Para permitir que el titular de la clave controle qué información se distribuye con su certificado, estos servidores de claves solo distribuyen certificaciones de terceros que el titular de la clave ha aprobado explícitamente.

Por defecto, se consideran todos los IDs de usuario, pero si se proporciona al menos un argumento de `--name`, `--email` o `--userid`, solo se considerarán los IDs de usuario que coincidan.

Después de que las aprobaciones hayan sido cambiadas, el certificado debe ser distribuido, por ejemplo, subiéndolo a un servidor de claves.

OPCIONES

Opciones del subcomando

--add-all
Aprueba todas las certificaciones pendientes
--add-authenticated
Aprueba todas las certificaciones de certificadores autenticados
Para todas las aprobaciones pendientes, intenta autenticar cualquier ID de usuario en el certificador, y si alguno puede ser autenticado, aprueba la certificación.
--add-by=HUella_digital|ID_de_clave
Aprueba todas las certificaciones de este certificador
--cert=HUella_digital|ID_de_clave
Lista las aprobaciones en el certificado con la huella digital o ID de clave especificado
--cert-email=CORREO
Lista las aprobaciones en el certificado donde un ID de usuario incluye la dirección de correo electrónico especificada
--cert-file=RUTA
Lista las aprobaciones en el certificado leído desde RUTA
--cert-userid=ID_de_usuario
Lista las aprobaciones en el certificado con el ID de usuario especificado
--email=CORREO
Usa el ID de usuario autofirmado con la dirección de correo electrónico especificada
--output=ARCHIVO
Escribe en el ARCHIVO especificado
Si no se especifica, y el certificado fue leído desde el almacén de certificados, importa el certificado modificado al almacén de certs. Si no se especifica, y el certificado fue leído desde un archivo, escribe el certificado modificado en la salida estándar.
--remove-all
Elimina todas las aprobaciones previas
Por defecto, este comando se añade al conjunto de certificaciones ya aprobadas. Si se proporciona esta bandera, las aprobaciones existentes se ignoran, y solo se aprueban las certificaciones recién seleccionadas, si las hay.
--remove-by=HUella_digital|ID_de_clave
Elimina todas las aprobaciones previas de certificaciones de este certificador
--userid=ID_de_usuario
Usa el ID de usuario autofirmado especificado
El ID de usuario especificado debe ser autofirmado.

Opciones globales

Ver sq(1) para una descripción de las opciones globales.

EJEMPLOS

Aprueba todas las certificaciones de todos los IDs de usuario de Alice.

sq key approvals update --add-all \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Aprueba todas las certificaciones de todos los IDs de usuario de Alice hechas por Bob, descartando primero todas las aprobaciones previas.

sq key approvals update --remove-all \
--add-by=511257EBBF077B7AEDAE5D093F68CB84CE537C9A \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Aprueba todas las certificaciones de un ID de usuario específico por certificadores que pueden ser autenticados, descartando primero todas las aprobaciones previas.

sq key approvals update --remove-all --add-authenticated \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--userid="Alice <alice@example.org>"

Elimina la aprobación de la certificación de Bob en todos los IDs de usuario de Alice.

sq key approvals update \
--remove-by=511257EBBF077B7AEDAE5D093F68CB84CE537C9A \
--cert=EB28F26E2739A4870ECC47726F0073F60FD0CBF0
