SQ(1) Comandos de usuario SQ(1)

NOMBRE

sq-sign - Firma mensajes o archivos de datos

SINOPSIS

sq sign [OPCIONES] ARCHIVO

DESCRIPCIÓN

Firma mensajes o archivos de datos.

Crea mensajes firmados o firmas separadas. Las firmas separadas se usan a menudo para firmar paquetes de software.

La operación inversa es `sq verify`.

`sq sign` respeta la hora de referencia establecida por el argumento superior `--time`. Cuando se establece, utiliza la hora especificada en lugar de la hora actual, al determinar qué claves son válidas, y establece la hora de creación de la firma a la hora de referencia en lugar de la hora actual.

OPCIONES

Opciones del subcomando

--append
Añade una firma a una firma existente
--binary
Genera datos binarios
--cleartext
Crea un mensaje con firma de texto claro
--merge=MENSAJE_FIRMADOR
Fusiona firmas de la entrada y MENSAJE_FIRMADOR
--message
Crea un mensaje con firma en línea
--mode=MODO
Selecciona el modo de firma
Las firmas se pueden hacer en modo binario o en modo texto. El modo texto normaliza los finales de línea, lo que hace que las firmas sean más robustas cuando un texto se transporta a través de un canal que puede cambiar los finales de línea. En caso de duda, cree firmas binarias.
[predeterminado: binary]
[valores posibles: binary, text]
--notarize
Firma un mensaje y todas las firmas existentes
--output=ARCHIVO
Escribe en ARCHIVO o en la salida estándar si se omite
[predeterminado: -]
--signature-file=SIG
Crea un archivo de firma separado
--signature-notation NOMBRE VALOR
Añade una notación a la firma
El nombre de una notación definida por el usuario debe tener el formato `nombre@a.dominio.que.controlas.org`. Si el nombre de la notación empieza por un `!`, entonces la notación se marca como crítica. Si un consumidor de una firma no entiende una notación crítica, entonces ignorará la firma. La notación se marca como legible por humanos.
--signer=HUellaDATO|IDCLAVE
Crea la firma utilizando la clave con la huella digital o ID de clave especificada
--signer-email=EMAIL
Crea la firma utilizando la clave donde un ID de usuario incluye la dirección de correo electrónico especificada
--signer-file=RUTA
Crea la firma utilizando la clave leída desde RUTA
--signer-self
Firma usando tus claves de firma predeterminadas
Esto añade los certificados listados en el archivo de configuración bajo `sign.signer-self` a la lista de claves de firma.
Actualmente, la lista de claves a añadir está vacía.
--signer-userid=IDUSUARIO
Crea la firma utilizando la clave con el ID de usuario especificado

ARCHIVO
Lee desde ARCHIVO o desde la entrada estándar si ARCHIVO es '-'
[predeterminado: -]

Opciones globales

Vea sq(1) para una descripción de las opciones globales.

EJEMPLOS

Crear un mensaje firmado.

sq sign --signer-file juliet-secret.pgp --message document.txt

Crear una firma separada.

sq sign --signer-file juliet-secret.pgp \
--signature-file=document.txt.sig document.txt

VER TAMBIÉN

sq(1).

Para la documentación completa, consulte https://book.sequoia-pgp.org/.
