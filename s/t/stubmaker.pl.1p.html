NOMBRE

stubmaker.pl - Genera stubs de cliente a partir de un archivo WSDL.

OPCIONES

-d <nombre_directorio>
Especifica el directorio donde se desea generar los archivos. El directorio debe existir previamente.
-v
Activa la salida detallada ("verbose") durante el proceso de generación de stubs de código. Para ser honesto, el programa no produce mucha salida, pero si usted necesita ver algo en la consola, esta opción encaja.
--help
Muestra un breve mensaje de ayuda.
--version
Muestra la versión actual de stubmaker.pl.

ARCHIVOS DE STUB

SUBRUTINAS DE STUB

La "clase" o "paquete" creado por stubmaker.pl es en realidad una subclase del objeto principal SOAP::Lite. Como resultado, todos los métodos que se pueden llamar en SOAP::Lite también se pueden llamar en los stubs generados.

Por ejemplo, suponga que desea obtener una salida legible del stub generado, simplemente llame a readable(1) en la instancia del stub. Vea el ejemplo a continuación.

Las siguientes subrutinas son únicas para las clases de stub generadas y ayudan al usuario a controlar y configurar la clase de stub.

want_som(booleano)
Cuando se establece en 1, SOAP::Lite devolverá objetos SOAP::SOM al usuario al invocar un método en un servicio remoto. Esto es muy útil cuando necesita verificar si el valor de retorno es un SOAP::Fault o no. Cuando se establece en 0, SOAP::Lite devolverá el valor de retorno del método.

EJEMPLOS

Invocando stubmaker.pl desde la línea de comandos

> perl stubmaker.pl http://www.xmethods.net/sd/StockQuoteService.wsdl O: > perl "-MStockQuoteService qw(:all)" -le "print getQuote('MSFT')"

Trabajando con clases de stub

Línea de comandos: > perl stubmaker.pl http://ws1.api.re2.yahoo.com/ws/soap-demo/full.wsdl

Archivo: echo.pl > use full; > use SOAP::Lite +trace => qw( debug ); > my $f = new full; > $f->use_prefix(0); > $f->readable(1); > $f->want_som(1); > $som = $f->echoViaBase64("foo");
