STAP-MERGE(1) Manual de comandos generales STAP-MERGE(1)

NOMBRE

stap-merge - Fusionador binario por CPU de systemtap

SINOPSIS

stap-merge [ OPCIONES ] [ NOMBRES_DE_ARCHIVO_ENTRADA ]

DESCRIPCIÓN

El ejecutable stap-merge se aplica cuando la opción -b se ha utilizado al ejecutar un script de stap. La opción -b generará archivos por CPU, basados en el campo de marca de tiempo. Luego, stap-merge fusionará y ordenará los archivos por CPU basándose en el campo de marca de tiempo.

OPCIONES

El ejecutable de fusión de systemtap admite las siguientes opciones.

-v
Modo detallado, muestra tres campos adicionales por conjunto de datos recopilados. 
[cpunúmero,secuencianúmerodedatos,lalongituddelconjuntodedatos]
-o NOMBRE_ARCHIVO_SALIDA

Especifique el nombre del archivo en el que desea que se redirija la salida. Si no se especifica esta opción, la salida se enviará a la salida estándar.

EJEMPLOS

$ stap -v -b -e 'probe syscall.open { printf("%s(%d) open\n",
execname(), pid()) }'

Esto debería dar lugar a varios archivos stpd_cpu (cada uno etiquetado con un número que representa la CPU de la que se produjo el archivo).

$ stap-merge -v stpd_cpu0 stpd_cpu1

Ejecutar el programa stap-merge en el mismo directorio que el script stap del ejemplo anterior, producirá una secuencia ordenada de paquetes con la etiqueta de tres partes para cada conjunto de datos. Este resultado se enviará a través de la salida estándar. Se podría haber especificado un archivo de salida utilizando la opción "-o".
