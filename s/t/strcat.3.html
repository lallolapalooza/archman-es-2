strcpy(3) Manual de Funciones de Biblioteca strcpy(3)

NOMBRE

stpcpy, strcpy, strcat - copiar o concatenar una cadena

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <string.h>
char *stpcpy(char *restrict dst, const char *restrict src);
char *strcpy(char *restrict dst, const char *restrict src);
char *strcat(char *restrict dst, const char *restrict src);
Requisitos de Macro de Prueba de Características para glibc (ver feature_test_macros(7)):

stpcpy():

    Desde glibc 2.10:
        _POSIX_C_SOURCE >= 200809L
    Antes de glibc 2.10:
        _GNU_SOURCE

DESCRIPCIÓN

stpcpy()
strcpy()
Estas funciones copian la cadena apuntada por src, a un búfer en la dirección apuntada por dst. El programador es responsable de asignar un búfer de destino lo suficientemente grande, es decir, strlen(src) + 1. Para la diferencia entre las dos funciones, ver VALOR DE RETORNO.
strcat()
Esta función concatena la cadena apuntada por src, después de la cadena apuntada por dst (sobrescribiendo su byte nulo terminador). El programador es responsable de asignar un búfer de destino lo suficientemente grande, es decir, strlen(dst) + strlen(src) + 1.

Una implementación de estas funciones podría ser:


char *
stpcpy(char *restrict dst, const char *restrict src)
{
    char  *p;
    p = mempcpy(dst, src, strlen(src));
    *p = '\0';
    return p;
}
char *
strcpy(char *restrict dst, const char *restrict src)
{
    stpcpy(dst, src);
    return dst;
}
char *
strcat(char *restrict dst, const char *restrict src)
{
    stpcpy(dst + strlen(dst), src);
    return dst;
}

VALOR DE RETORNO

stpcpy()
Esta función devuelve un puntero al byte nulo terminador de la cadena copiada.
strcpy()
strcat()
Estas funciones devuelven dst.

ADVERTENCIAS

Las cadenas src y dst no pueden superponerse.

Si el búfer de destino no es lo suficientemente grande, el comportamiento es indefinido. Ver _FORTIFY_SOURCE en feature_test_macros(7).

strcat() puede ser muy ineficiente. Lea sobre Shlemiel the painter.

EJEMPLOS

#include <err.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int
main(void)
{
    char    *p;
    char    *buf1;
    char    *buf2;
    size_t  len, size;
    size = strlen("Hello ") + strlen("world") + strlen("!") + 1;
    buf1 = malloc(sizeof(*buf1) * size);
    if (buf1 == NULL)
        err(EXIT_FAILURE, "malloc()");
    buf2 = malloc(sizeof(*buf2) * size);
    if (buf2 == NULL)
        err(EXIT_FAILURE, "malloc()");
    p = buf1;
    p = stpcpy(p, "Hello ");
    p = stpcpy(p, "world");
    p = stpcpy(p, "!");
    len = p - buf1;
    printf("[len = %zu]: ", len);
    puts(buf1);  // "Hello world!"
    free(buf1);
    strcpy(buf2, "Hello ");
    strcat(buf2, "world");
    strcat(buf2, "!");
    len = strlen(buf2);
    printf("[len = %zu]: ", len);
    puts(buf2);  // "Hello world!"
    free(buf2);
    exit(EXIT_SUCCESS);
}
