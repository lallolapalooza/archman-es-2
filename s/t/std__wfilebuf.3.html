template<typename _CharT, typename _Traits>

class std::basic_filebuf< _CharT, _Traits >

"El trabajo real de entrada y salida (para archivos)."

Parámetros de Plantilla

_CharT Tipo de flujo de caracteres.
_Traits Rasgos para el tipo de carácter, por defecto es char_traits<_CharT>.

Esta clase asocia tanto su secuencia de entrada como de salida con un archivo de disco externo, y mantiene una posición conjunta del archivo para ambas secuencias. Muchas de sus semánticas se describen en términos de comportamiento similar en los flujos FILE de la Biblioteca Estándar de C.

Requisitos sobre traits_type, específicos para esta clase:

  • traits_type::pos_type debe ser fpos<traits_type::state_type>
  • traits_type::off_type debe ser streamoff
  • traits_type::state_type debe ser Assignable y DefaultConstructible,
  • traits_type::state_type() debe ser el estado inicial para codecvt.

template<typename _CharT, typename _Traits> void std::basic_filebuf< _CharT, _Traits >::_M_set_buffer (streamsize __off) [inline], [protected]

Esta función establece los punteros del búfer interno, tanto en el área de lectura como en la de escritura. Típicamente:

__off == egptr() - eback() en underflow/uflow (modo de lectura); __off == 0 en overflow (modo de escritura); __off == -1 al abrir, setbuf, seekoff/pos (modo no confirmado).

NOTA: epptr() - pbase() == _M_buf_size - 1, ya que _M_buf_size refleja la memoria asignada real y la última celda está reservada para el carácter de desbordamiento de un área de escritura completa.

Cierra el archivo actualmente asociado.

Devuelve

this en caso de éxito, NULL en caso de fallo

Si no hay ningún archivo abierto actualmente, esta función falla inmediatamente.

Si existe un área de búfer de escritura, se llama a overflow(eof) para vaciar todos los caracteres. Luego, el archivo se cierra.

Si alguna operación falla, esta función también falla.

template<typename _CharT, typename _Traits> basic_filebuf< _CharT, _Traits >::int_type std::basic_filebuf< _CharT, _Traits >::overflow (int_type __c = _Traits::eof()) [protected], [virtual]

Consume datos del búfer; escribe en la secuencia controlada.

Parámetros

__c Un carácter adicional para consumir.

Devuelve

eof() para indicar fallo, algún otro valor (generalmente __c, o not_eof())

Informalmente, esta función se llama cuando el búfer de salida está lleno (o no existe, ya que el almacenamiento en búfer no necesita ser realizado). Si existe un búfer, se consume, con algún efecto en la secuencia controlada. (Típicamente, el búfer se escribe en la secuencia sin cambios.) En ambos casos, el carácter c también se escribe, si __c no es eof().

Para una definición formal de esta función, consulte un buen texto como Langer & Kreft, o [27.5.2.4.5]/3-7.

Se puede crear un streambuf de salida funcional sobrescribiendo solo esta función (no se usará área de búfer).

Nota

La versión de la clase base no hace nada, devuelve eof().

template<typename _CharT, typename _Traits> streamsize std::basic_filebuf< _CharT, _Traits >::showmanyc () [protected], [virtual]

Investigando los datos disponibles.

Retorna

Una estimación del número de caracteres disponibles en la secuencia de entrada, o -1.

Si retorna un valor positivo, entonces las llamadas sucesivas a underflow() no retornarán traits::eof() hasta que al menos ese número de caracteres hayan sido suministrados. Si showmanyc() retorna -1, entonces las llamadas a underflow() o uflow() fallarán. [27.5.2.4.3]/1

El estándar añade que la intención no es solo que las llamadas [a underflow o uflow] no retornen eof() sino que retornen inmediatamente.

El estándar añade que los morfemas de showmanyc son es-how-many-see, no show-manic.

template<typename _CharT, typename _Traits> streamsize std::basic_filebuf< _CharT, _Traits >::underflow () [protected], [virtual]

Obtiene más datos de la secuencia controlada.

Retorna

El primer carácter de la secuencia pendiente.

Informalmente, esta función se llama cuando el búfer de entrada está agotado (o no existe, ya que no es necesario que se realice ningún búfer). Si existe un búfer, se vuelve a llenar. En cualquier caso, se retorna el siguiente carácter disponible, o traits::eof() para indicar una secuencia pendiente nula.

Se puede crear un streambuf de entrada funcional al anular solo esta función (no se usará ningún área de búfer). Para un ejemplo, consulte https://gcc.gnu.org/onlinedocs/libstdc++/manual/streambufs.html
