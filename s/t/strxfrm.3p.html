STRXFRM(3P) Manual del programador de POSIX STRXFRM(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

strxfrm, strxfrm_l — transformación de cadenas

SINOPSIS

#include <string.h>
size_t strxfrm(char *restrict s1, const char *restrict s2, size_t n);
size_t strxfrm_l(char *restrict s1, const char *restrict s2,
    size_t n, locale_t locale);

DESCRIPCIÓN

Para strxfrm(): La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1-2017 remite al estándar ISO C.

Las funciones strxfrm() y strxfrm_l() transformarán la cadena apuntada por s2 y colocarán la cadena resultante en el array apuntado por s1. La transformación es tal que si strcmp() se aplica a dos cadenas transformadas, devolverá un valor mayor que, igual a, o menor que 0, correspondiente al resultado de strcoll() o strcoll_l(), respectivamente, aplicado a las mismas dos cadenas originales con la misma configuración regional. No se colocan más de n bytes en el array resultante apuntado por s1, incluido el carácter NUL terminador. Si n es 0, se permite que s1 sea un puntero nulo. Si se produce una copia entre objetos que se superponen, el comportamiento es indefinido.

Las funciones strxfrm() y strxfrm_l() no modificarán la configuración de errno si tienen éxito.

Dado que no se reserva ningún valor de retorno para indicar un error, una aplicación que desee verificar situaciones de error debe establecer errno en 0, luego llamar a strxfrm() o strxfrm_l(), y luego verificar errno.

El comportamiento es indefinido si el argumento locale de strxfrm_l() es el objeto de configuración regional especial LC_GLOBAL_LOCALE o no es un manejador de objetos de configuración regional válido.

VALOR DE RETORNO

Al completarse con éxito, strxfrm() y strxfrm_l() devolverán la longitud de la cadena transformada (sin incluir el carácter NUL terminador). Si el valor devuelto es n o superior, el contenido del array apuntado por s1 no está especificado.

En caso de error, strxfrm() y strxfrm_l() pueden establecer errno, pero no se reserva ningún valor de retorno para indicar un error.

ERRORES

Estas funciones pueden fallar si:

EINVAL
La cadena apuntada por el argumento s2 contiene caracteres fuera del dominio de la secuencia de ordenación.

USO POR PARTE DE LA APLICACIÓN

La función de transformación es tal que dos cadenas transformadas pueden ser ordenadas por strcmp() según la información de la secuencia de ordenación en la configuración regional actual (categoría LC_COLLATE).

El hecho de que cuando n es 0, s1 pueda ser un puntero nulo, es útil para determinar el tamaño del array s1 antes de realizar la transformación.
