Documentación de la función/subrutina

subroutine stpsv (character uplo, character trans, character diag, integer n, real, dimension(*) ap, real, dimension(*) x, integer incx)

STPSV

Propósito:

!>
!> STPSV resuelve uno de los sistemas de ecuaciones
!>
!>    A*x = b,   o   A**T*x = b,
!>
!> donde b y x son vectores de n elementos y A es una matriz triangular
!> superior o inferior de n por n, unitaria o no unitaria, suministrada
!> en forma empaquetada.
!>
!> En esta rutina no se incluye ninguna prueba de singularidad o
!> casi-singularidad. Dichas pruebas deben realizarse antes de llamar
!> a esta rutina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si la matriz es superior o
!>           inferior triangular de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           En la entrada, TRANS especifica las ecuaciones a resolver de la
!>           siguiente manera:
!>
!>              TRANS = 'N' o 'n'   A*x = b.
!>
!>              TRANS = 'T' o 't'   A**T*x = b.
!>
!>              TRANS = 'C' o 'c'   A**T*x = b.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           En la entrada, DIAG especifica si A es unitaria
!>           triangular o no de la siguiente manera:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es unitaria triangular.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitaria
!>                                  triangular.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

AP

!>          AP es un array REAL, de dimensión al menos
!>           ( ( n*( n + 1 ) )/2 ).
!>           Antes de la entrada con  UPLO = 'U' o 'u', el array AP debe
!>           contener la matriz triangular superior empaquetada secuencialmente,
!>           columna por columna, de modo que AP( 1 ) contenga a( 1, 1 ),
!>           AP( 2 ) y AP( 3 ) contengan a( 1, 2 ) y a( 2, 2 )
!>           respectivamente, y así sucesivamente.
!>           Antes de la entrada con UPLO = 'L' o 'l', el array AP debe
!>           contener la matriz triangular inferior empaquetada secuencialmente,
!>           columna por columna, de modo que AP( 1 ) contenga a( 1, 1 ),
!>           AP( 2 ) y AP( 3 ) contengan a( 2, 1 ) y a( 3, 1 )
!>           respectivamente, y así sucesivamente.
!>           Tenga en cuenta que cuando  DIAG = 'U' o 'u', los elementos
!>           diagonales de A no se referencian, sino que se asume que son
!>           la unidad.
!>

X

!>          X es un array REAL, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array incrementado X debe contener el
!>           vector b del lado derecho de n elementos. En la salida, X se
!>           sobrescribe con el vector solución x.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>
