strtol(3) Manual de funciones de biblioteca strtol(3)

NOMBRE

strtol, strtoll, strtoq - convertir una cadena a un entero largo

BIBLIOTECA

Biblioteca estándar de C (libc, -lc)

SINOPSIS

#include <stdlib.h>
long strtol(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
long long strtoll(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

strtoll():

    _ISOC99_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPCIÓN

La función strtol() convierte la parte inicial de la cadena en nptr a un valor de entero largo según la base dada, que debe estar entre 2 y 36 inclusive, o ser el valor especial 0.

La cadena puede comenzar con una cantidad arbitraria de espacios en blanco (según lo determinado por isspace(3)) seguida de un único signo '+' o '-' opcional. Si base es cero o 16, la cadena puede incluir un prefijo "0x" o "0X", y el número se leerá en base 16; si base es cero o 2, la cadena puede incluir un prefijo "0b" o "0B", y el número se leerá en base 2; de lo contrario, una base cero se toma como 10 (decimal) a menos que el siguiente carácter sea '0', en cuyo caso se toma como 8 (octal).

El resto de la cadena se convierte a un valor long de la manera obvia, deteniéndose en el primer carácter que no sea un dígito válido en la base dada. (En bases superiores a 10, la letra 'A' en mayúsculas o minúsculas representa 10, 'B' representa 11, y así sucesivamente, con 'Z' representando 35).

Si endptr no es NULL, y la base es compatible, strtol() almacena la dirección del primer carácter inválido en *endptr. Si no había ningún dígito, strtol() almacena el valor original de nptr en *endptr (y devuelve 0). En particular, si *nptr no es '\0' pero **endptr es '\0' al regresar, toda la cadena es válida.

La función strtoll() funciona igual que la función strtol() pero devuelve un valor de entero long long.

VALOR DE RETORNO

La función strtol() devuelve el resultado de la conversión, a menos que el valor cause un desbordamiento inferior o superior. Si ocurre un desbordamiento inferior, strtol() devuelve LONG_MIN. Si ocurre un desbordamiento superior, strtol() devuelve LONG_MAX. En ambos casos, errno se establece en ERANGE. Exactamente lo mismo se aplica a strtoll() (con LLONG_MIN y LLONG_MAX en lugar de LONG_MIN y LONG_MAX).

ERRORES

Esta función no modifica errno en caso de éxito.

EINVAL
(no en C99) La base dada contiene un valor no compatible.
ERANGE
El valor resultante estaba fuera de rango.

La implementación también puede establecer errno en EINVAL en caso de que no se realizara ninguna conversión (no se encontraron dígitos y se devolvió 0).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
strtol (), strtoll (), strtoq () Seguridad en hilos MT-Safe locale

VERSIÓNES

Según POSIX.1, en locales distintos de "C" y "POSIX", estas funciones pueden aceptar otras cadenas numéricas definidas por la implementación.

BSD también tiene


quad_t strtoq(const char *nptr, char **endptr, int base);

con una definición completamente análoga. Dependiendo del tamaño de palabra de la arquitectura actual, esto puede ser equivalente a strtoll() o a strtol().

ADVERTENCIAS

Comprobaciones de rango

Dado que strtol() puede devolver legítimamente 0, LONG_MAX o LONG_MIN (LLONG_MAX o LLONG_MIN para strtoll()) tanto en éxito como en fracaso, el programa que llama debe establecer errno a 0 antes de la llamada, y luego determinar si ocurrió un error verificando si errno == ERANGE después de la llamada.


errno = 0;
n = strtol(s, &end, base);
if (end == s)
	goto no_number;
if ((errno == ERANGE && n == LONG_MIN) || n < min)
	goto too_low;
if ((errno == ERANGE && n == LONG_MAX) || n > max)
	goto too_high;

base

Si la base necesita ser probada, debe probarse en una llamada donde se sabe que la cadena tiene éxito. De lo contrario, es imposible diferenciar los errores de forma portable.


errno = 0;
strtol("0", NULL, base);
if (errno == EINVAL)
    goto unsupported_base;

ERRORES

Espacios en blanco

Estas funciones aceptan silenciosamente espacios en blanco iniciales. Para rechazar espacios en blanco, llame a isspace(3) antes de strtol().

EJEMPLOS

El programa que se muestra a continuación demuestra el uso de strtol(). El primer argumento de la línea de comandos especifica una cadena de la cual strtol() debe analizar un número. El segundo argumento (opcional) especifica la base que se utilizará para la conversión. (Este argumento se convierte a forma numérica usando atoi(3), una función que no realiza ninguna comprobación de errores y tiene una interfaz más simple que strtol().) Algunos ejemplos de los resultados producidos por este programa son los siguientes:


$ ./a.out 123
strtol() devolvió 123
$ ./a.out '    123'
strtol() devolvió 123
$ ./a.out 123abc
strtol() devolvió 123
Caracteres adicionales después del número: "abc"
$ ./a.out 123abc 55
strtol: Argumento no válido
$ ./a.out ''
No se encontraron dígitos
$ ./a.out 4000000000
strtol: Resultado numérico fuera de rango

Código fuente del programa

#include <errno.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    int base;
    char *endptr, *str;
    long val;
    if (argc < 2) {
        fprintf(stderr, "Uso: %s str [base]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    str = argv[1];
    base = (argc > 2) ? atoi(argv[2]) : 0;
    errno = 0;    /* Para distinguir éxito/fracaso después de la llamada */
    strtol("0", NULL, base);
    if (errno == EINVAL) {
        perror("strtol");
        exit(EXIT_FAILURE);
    }
    errno = 0;    /* Para distinguir éxito/fracaso después de la llamada */
    val = strtol(str, &endptr, base);
    /* Comprobar varios posibles errores.  */
    if (errno == ERANGE) {
        if (val == LONG_MAX)
            printf("strtol: Resultado numérico fuera de rango (alto)\n");
        else if (val == LONG_MIN)
            printf("strtol: Resultado numérico fuera de rango (bajo)\n");
        else
            printf("strtol: Resultado numérico fuera de rango (indefinido)\n");
    } else if (endptr == str) {
        printf("No se encontraron dígitos\n");
    } else if (*endptr != '\0') {
        printf("strtol() devolvió %ld\n", val);
        printf("Caracteres adicionales después del número: \"%s\"\n", endptr);
    } else {
        printf("strtol() devolvió %ld\n", val);
    }
    exit(EXIT_SUCCESS);
}

EJEMPLOS

strtol("123", NULL, 0);
// Devuelve 123

char *endptr;
long val;

// Con base 10
val = strtol("  -4567", &endptr, 10);
// val es -4567, *endptr es '\0'

// Con base 0 (detecta la base)
val = strtol("077", &endptr, 0);
// val es 63 (octal), *endptr es '\0'

val = strtol("0x77", &endptr, 0);
// val es 119 (hexadecimal), *endptr es '\0'

val = strtol("   12345foo", &endptr, 10);
// val es 12345, *endptr es "foo"

val = strtol("12345foo", &endptr, 0);
// val es 12345, *endptr es "foo"

// Valor fuera de rango (ejemplo con LONG_MAX)
long minval;
char *str = "9223372036854775807"; // Valor aproximado de LONG_MAX
char *endptr2;

errno = 0;
minval = strtol(str, &endptr2, 10);
if (errno == ERANGE) {
    perror("strtol");
    exit(EXIT_FAILURE);
}
if (endptr2 == str) {
    fprintf(stderr, "No digits were found\n");
    exit(EXIT_FAILURE);
}
// Si llegamos aquí, strtol() analizó un número correctamente.
printf("strtol() returned %ld\n", val);
if (*endptr2 != '\0')        // No es necesariamente un error.
    printf("Further characters after number: \"%s\"\n", endptr2);
exit(EXIT_SUCCESS);
