static_assert(3) Manual de funciones de la biblioteca static_assert(3)

NOMBRE

static_assert, _Static_assert - falla la compilación si la aserción es falsa

BIBLIOTECA

Biblioteca estándar de C (libc)

SINOPSIS

#include <assert.h>
void static_assert(bool expresión-constante, const char *msg);
/* Desde C23: */
void static_assert(bool expresión-constante);

DESCRIPCIÓN

Esta macro es similar a assert(3), pero funciona en tiempo de compilación, generando un error de compilación (con un mensaje opcional) cuando la entrada es falsa (es decir, es igual a cero).

Si la entrada es distinta de cero, no se emite código.

msg debe ser un literal de cadena. Desde C23, este argumento es opcional.

Existe una palabra clave, _Static_assert(), que se comporta de manera idéntica y puede usarse sin incluir <assert.h>.

VALOR DE RETORNO

No se devuelve ningún valor.

VERSIÓNES

En C11, el segundo argumento (msg) era obligatorio; desde C23, se puede omitir.

ESTÁNDARES

C11 y posteriores.

EJEMPLOS

static_assert() no se puede usar en algunos lugares, como por ejemplo en el ámbito global. Para eso, se puede escribir una macro must_be() utilizando static_assert(). El siguiente programa usa la macro para obtener el tamaño de un array de forma segura.


#include <assert.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
/*
 * Esta macro se comporta como static_assert(), fallando en
 * la compilación si su argumento no es verdadero. Sin embargo,
 * siempre devuelve 0, lo que permite usarla dondequiera que se
 * pueda usar una expresión.
 */
#define must_be(e)                                        \
(                                                         \
    0 * (int) sizeof(                                     \
        struct {                                          \
            static_assert(e);                             \
            int  ISO_C_forbids_a_struct_with_no_members;  \
        }                                                 \
    )                                                     \
)
#define is_same_type(a, b)  \
    __builtin_types_compatible_p(typeof(a), typeof(b))
#define is_array(arr)       (!is_same_type((arr), &*(arr)))
#define must_be_array(arr)  must_be(is_array(arr))
#define sizeof_array(arr)   (sizeof(arr) + must_be_array(arr))
#define NITEMS(arr)         (sizeof((arr)) / sizeof((arr)[0]) \
                             + must_be_array(arr))
int     foo[10];
int8_t  bar[sizeof_array(foo)];
int
main(void)
{
    for (size_t i = 0; i < NITEMS(foo); i++) {
        foo[i] = i;
    }
    memcpy(bar, foo, sizeof_array(bar));
    for (size_t i = 0; i < NITEMS(bar); i++) {
        printf("%d,", bar[i]);
    }
    exit(EXIT_SUCCESS);
}
