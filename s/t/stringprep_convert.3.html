stringprep_convert(3) libidn stringprep_convert(3)

NOMBRE

stringprep_convert - Función de la API

SINOPSIS

#include <stringprep.h>

char * stringprep_convert(const char * str, const char * to_codeset, const char * from_codeset);

ARGUMENTOS

const char * str
cadena de entrada terminada en cero.
const char * to_codeset
nombre del conjunto de caracteres de destino.
const char * from_codeset
nombre del conjunto de caracteres de origen, tal como lo usa str .

DESCRIPCIÓN

Convierte la cadena de un conjunto de caracteres a otro utilizando la función iconv() del sistema.

Valor de retorno: Devuelve una cadena recién asignada y terminada en cero que es str transcodificada a to_codeset.
