DESCRIPTION

std::forward_list is a container that encapsulates dynamic size arrays, similarly to std::vector [], but with different performance characteristics.

Quick reference:

Average case
Access no random access
Insertion O(1) worst case
Deletion O(1) worst case

A std::forward_list is a sequence container that allows fast insertion and deletion, but no random access.

The container is implemented as a singly linked list. Elements are not stored contiguously in memory. The list is specified by a pointer to its first element (head). Insertion and deletion of elements anywhere in the container can be performed in constant time, and removal of the first element in constant time, respectively. However, only forward iteration to any element can be achieved in linear time, and there is no random access to any element of the container.

std::forward_list supports only forward iterators. This means that you cannot use std::adjacent_find, std::copy_backward, std::is_sorted, std::move_backward, std::partition, std::remove, std::remove_if, std::replace, std::replace_if, std::reverse, std::rotate, std::search, std::set_difference, std::set_intersection, std::set_symmetric_difference, std::set_union, std::splice, std::stable_partition, std::stable_sort, std::swap_ranges, std::transform, std::unique, or std::unique_copy. Likewise, std::forward_list does not support the subscript operator ([]) or the std::at member functions.

std::forward_list requires allocators that conform to the C++11 requirements for allocators. For example, the allocator must be copyable and movable.

The C++11 standard requires that the member types allocator_type, const_iterator, difference_type, iterator, reference, size_type, and value_type are defined.

Element type

_Tp Type of element.
_Alloc Allocator type, defaults to allocator<_Tp>.

Meets the requirements of a container, a sequence, including the optional sequence requirements with the exception of at and operator[].

This is a singly linked list. Traversal up the list requires linear time, but adding and removing elements (or nodes) is done in constant time, regardless of where the change takes place. Unlike std::vector and std::deque, random-access iterators are not provided, so subscripting ([]) access is not allowed. For algorithms which only need sequential access, this lack makes no difference.

Also unlike the other standard containers, std::forward_list provides specialized algorithms unique to linked lists, such as splicing, sorting, and in-place reversal.

Nombre

std::forward_list - un contenedor de lista enlazada simple

Sinopsis

#include <forward_list>

Descripción

std::forward_list es un contenedor de secuencia que representa una lista enlazada simple.

A diferencia de std::list, std::forward_list solo permite la inserción y el acceso a los elementos en la parte frontal (inicio) y la eliminación de elementos después de un iterador dado.

Las características clave de std::forward_list incluyen:

  • Inserción y eliminación eficientes en la parte frontal.
  • Inserción y eliminación eficientes después de un iterador dado.
  • No permite acceso aleatorio.
  • El tamaño no se mantiene explícitamente; se calcula al solicitarlo.
  • Requiere menos memoria por elemento que std::list ya que solo almacena un puntero de avance.

std::forward_list es útil cuando se necesita una lista enlazada y la eficiencia de la memoria es una preocupación importante, o cuando las operaciones principales son en el frente de la lista.

Ejemplo

Aquí hay un ejemplo simple de uso de std::forward_list:

#include <iostream>
#include <forward_list>

int main() {
    std::forward_list<int> fl = {1, 2, 3, 4, 5};

    // Insertar un elemento al principio
    fl.push_front(0);

    // Insertar un elemento después de un iterador
    auto it = fl.begin();
    std::advance(it, 2); // Apunta al tercer elemento (índice 2)
    fl.insert_after(it, 99);

    // Eliminar un elemento después de un iterador
    it = fl.begin();
    std::advance(it, 4); // Apunta al quinto elemento
    fl.erase_after(it);

    // Recorrer la lista
    for (int i : fl) {
        std::cout << i << " ";
    }
    std::cout << std::endl;
    // Salida: 0 1 99 2 4 5

    return 0;
}
