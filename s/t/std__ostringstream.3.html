int std::ios_base::xalloc () [static], [inherited]

Acceso a índices únicos.

Devuelve

Un entero diferente de todas las llamadas previas.

Esta función devuelve un entero único cada vez que se llama. Puede usarse para cualquier propósito, pero está diseñada principalmente para ser un índice único para las funciones `iword` y `pword`. La expectativa es que una aplicación llame a `xalloc` para obtener un índice en los arrays `iword` y `pword` que pueda usarse sin temor a conflictos.

La implementación mantiene una variable estática que se incrementa y se devuelve en cada invocación. Se garantiza que `xalloc` devuelve un índice seguro para usar en los arrays `iword` y `pword`.
