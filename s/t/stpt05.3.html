Documentación de Función/Subrutina

subrutina stpt05 (character uplo, character trans, character diag, integer n, integer nrhs, real, dimension( * ) ap, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real, dimension( ldxact, * ) xact, integer ldxact, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) reslts)

STPT05

Propósito:

!>
!> STPT05 prueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones A*X = B, donde A es una
!> matriz triangular en formato de almacenamiento empaquetado.
!>
!> RESLTS(1) = prueba del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta relación no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( (n+1)*EPS + (*) ), donde
!>             (*) = (n+1)*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B  (Sin transposición)
!>          = 'T':  A'* X = B  (Transpuesta)
!>          = 'C':  A'* X = B  (Transpuesta conjugada = Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitriangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

N

!>          N es INTEGER
!>          El número de filas de las matrices X, B y XACT, y el orden
!>          de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X, B y XACT.
!>          NRHS >= 0.
!>

AP

!>          AP es un array REAL, dimension (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por columnas
!>          en un array lineal. La j-ésima columna de A se almacena en el
!>          array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Si DIAG = 'U', los elementos diagonales de A no se referencian
!>          y se asumen que son 1.
!>

B

!>          B es un array REAL, dimension (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array REAL, dimension (LDX,NRHS)
!>          Los vectores solución calculados. Cada vector se almacena como
!>          una columna de la matriz X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

XACT

!>          XACT es un array REAL, dimension (LDX,NRHS)
!>          Los vectores solución exactos. Cada vector se almacena como
!>          una columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es INTEGER
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR es un array REAL, dimension (NRHS)
!>          Los límites de error hacia adelante estimados para cada vector
!>          solución X. Si XTRUE es la solución verdadera, FERR limita la
!>          magnitud de la entrada más grande en (X - XTRUE) dividida por
!>          la magnitud de la entrada más grande en X.
!>

BERR

!>          BERR es un array REAL, dimension (NRHS)
!>          El error hacia atrás relativo componente a componente de cada
!>          vector solución (es decir, el cambio relativo más pequeño en
!>          cualquier entrada de A o B que hace que X sea una solución exacta).
!>

RESLTS

!>          RESLTS es un array REAL, dimension (2)
!>          El máximo sobre los vectores solución NRHS de las relaciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( (n+1)*EPS + (*) )
!>
