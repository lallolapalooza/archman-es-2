STGEVC

Propósito:

!>
!> STGEVC calcula algunos o todos los vectores propios derechos y/o izquierdos de
!> un par de matrices reales (S,P), donde S es una matriz cuasi-triangular
!> y P es triangular superior. Los pares de matrices de este tipo se producen por
!> la factorización de Schur generalizada de un par de matrices (A,B):
!>
!>    A = Q*S*Z**T,  B = Q*P*Z**T
!>
!> como se calcula por SGGHRD + SHGEQZ.
!>
!> Los vectores propios derechos x y los vectores propios izquierdos y de (S,P)
!> correspondientes a un valor propio w se definen por:
!>
!>    S*x = w*P*x,  (y**H)*S = w*(y**H)*P,
!>
!> donde y**H denota la transpuesta conjugada de y.
!> Los valores propios no son una entrada para esta rutina, sino que se calculan
!> directamente a partir de los bloques diagonales de S y P.
!>
!> Esta rutina devuelve las matrices X y/o Y de vectores propios derechos e izquierdos
!> de (S,P), o los productos Z*X y/o Q*Y,
!> donde Z y Q son matrices de entrada.
!> Si Q y Z son los factores ortogonales de la factorización de Schur
!> generalizada de un par de matrices (A,B), entonces Z*X y Q*Y
!> son las matrices de vectores propios derechos e izquierdos de (A,B).
!>
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R': calcular solo vectores propios derechos;
!>          = 'L': calcular solo vectores propios izquierdos;
!>          = 'B': calcular ambos vectores propios derechos e izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular todos los vectores propios derechos y/o izquierdos;
!>          = 'B': calcular todos los vectores propios derechos y/o izquierdos,
!>                 transformados inversamente por las matrices en VR y/o VL;
!>          = 'S': calcular vectores propios derechos y/o izquierdos seleccionados,
!>                 especificados por el array lógico SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY='S', SELECT especifica los vectores propios a calcular.
!>          Si w(j) es un valor propio real, el vector propio real correspondiente
!>          se calcula si SELECT(j) es .TRUE..
!>          Si w(j) y w(j+1) son las partes real e imaginaria de un
!>          valor propio complejo, el vector propio complejo correspondiente
!>          se calcula si SELECT(j) o SELECT(j+1) es .TRUE.,
!>          y en la salida SELECT(j) se establece a .TRUE. y SELECT(j+1)
!>          se establece a .FALSE..
!>          No referenciado si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de las matrices S y P.  N >= 0.
!>

S

!>          S es un array REAL, de dimensión (LDS,N)
!>          La matriz cuasi-triangular superior S de una factorización de Schur
!>          generalizada, como se calcula por SHGEQZ.
!>

LDS

!>          LDS es INTEGER
!>          La dimensión principal del array S.  LDS >= max(1,N).
!>

P

!>          P es un array REAL, de dimensión (LDP,N)
!>          La matriz triangular superior P de una factorización de Schur
!>          generalizada, como se calcula por SHGEQZ.
!>          Los bloques diagonales de 2x2 de P correspondientes a bloques
!>          de 2x2 de S deben estar en forma diagonal positiva.
!>

LDP

!>          LDP es INTEGER
!>          La dimensión principal del array P.  LDP >= max(1,N).
!>

VL

!>          VL es un array REAL, de dimensión (LDVL,MM)
!>          En la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de NxN (normalmente la matriz ortogonal Q
!>          de vectores de Schur izquierdos devuelta por SHGEQZ).
!>          En la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de vectores propios izquierdos de (S,P);
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los vectores propios izquierdos de (S,P) especificados por
!>                      SELECT, almacenados consecutivamente en las columnas de
!>                      VL, en el mismo orden que sus valores propios.
!>
!>          Un vector propio complejo correspondiente a un valor propio complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la

LDVL

!>

VR

!>          contener una matriz Z de NxN (normalmente la matriz ortogonal Z
!>          de vectores de Schur derechos devuelta por SHGEQZ).
!>
!>          En la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de vectores propios derechos de (S,P);
!>          si HOWMNY = 'B' o 'b', la matriz Z*X;
!>          si HOWMNY = 'S' o 's', los vectores propios derechos de (S,P)
!>                      especificados por SELECT, almacenados consecutivamente en las
!>                      columnas de VR, en el mismo orden que sus
!>                      valores propios.
!>
!>          Un vector propio complejo correspondiente a un valor propio complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real y la segunda la imaginaria.
!>
!>          No referenciado si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.  LDVR >= 1, y si
!>          SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizadas para almacenar los vectores propios. Si HOWMNY = 'A' o 'B',
!>          M se establece a N. Cada vector propio real seleccionado ocupa una

WORK

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.

NAME

stgevc - computes the eigenvectors of a generalized eigenvalue problem A*v = w*B*v or v*A = w*v*B.

Function/Subroutine Documentation

The right eigenvectors are computed by the subroutine.

The matrix C is defined as C = A - w B.

For the right eigenvectors, the equation to be solved is C*v = 0. Here, v is a column vector with components v(i+1:n) set to 0. The equation to be solved is:

  n                   i
0 = sum  C(j,k) v(k)  = sum  C(j,k) v(k)     for j = i,. . .,1
     k=j                 k=j

The method is:

  1. v(i) := 1

  2. for j = i-1,. . .,1:

    1. compute s = - sum(k=j+1 to i) C(j,k) v(k)

    2. v(j) := s / C(j,j)

Step 3 is sometimes called the "forward substitution" step, since it is an inner product between the j-th row and the portion of the eigenvector that has been computed so far.

The "columnwise" method consists basically in doing the sums for all the rows in parallel. As each v(j) is computed, the contribution of v(j) times the j-th column of C is added to the partial sums. Since FORTRAN arrays are stored columnwise, this has the advantage that at each step, the elements of C that are accessed are adjacent to one another, whereas with the rowwise method, the elements accessed at a step are spaced LDS (and LDP) words apart.

When finding left eigenvectors, the matrix in question is the transpose of the one in storage, so the rowwise method then actually accesses columns of A and B at each step, and so is the preferred method.
