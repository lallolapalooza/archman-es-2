string(n)

Paquete: tcl

Licencias: TCL

string(n) Comandos integrados de Tcl string(n)

NOMBRE

string - Manipular cadenas

SINOPSIS

string opción arg ?arg ...?

DESCRIPCIÓN

Realiza una de varias operaciones de cadena, dependiendo de opción. Las opciónes legales (que pueden ser abreviadas) son:

string cat ?cadena1? ?cadena2...?
Concatena las cadenas dadas tal como si estuvieran directamente una al lado de la otra y devuelve la cadena compuesta resultante. Si no hay cadenas presentes, el resultado es una cadena vacía.

Este primitivo es ocasionalmente más útil que la yuxtaposición de cadenas cuando se desean comillas mixtas, o cuando el objetivo es devolver el resultado de una concatenación sin recurrir a return -level 0, y es más eficiente que construir una lista de argumentos y usar join con una cadena de unión vacía.

string compare ?-nocase? ?-length longitud? cadena1 cadena2
Realiza una comparación carácter por carácter de las cadenas cadena1 y cadena2. Devuelve -1, 0 o 1, dependiendo de si cadena1 es lexicográficamente menor que, igual a, o mayor que cadena2. Si se especifica -length, entonces solo se usan los primeros longitud caracteres en la comparación. Si -length es negativo, se ignora. Si se especifica -nocase, entonces las cadenas se comparan sin distinguir entre mayúsculas y minúsculas.
string equal ?-nocase? ?-length longitud? cadena1 cadena2
Realiza una comparación carácter por carácter de las cadenas cadena1 y cadena2. Devuelve 1 si cadena1 y cadena2 son idénticas, o 0 cuando no lo son. Si se especifica -length, entonces solo se usan los primeros longitud caracteres en la comparación. Si -length es negativo, se ignora. Si se especifica -nocase, entonces las cadenas se comparan sin distinguir entre mayúsculas y minúsculas.
string first cadenaAgujadestino cadenaHaystack ?indiceInicio?
Busca en cadenaHaystack una secuencia de caracteres que coincidan exactamente con los caracteres de cadenaAgujadestino. Si se encuentra, devuelve el índice del primer carácter de la primera coincidencia en cadenaHaystack. Si no se encuentra, devuelve -1. Si se especifica indiceInicio (en cualquiera de las formas descritas en ÍNDICES DE CADENAS), entonces la búsqueda se limita a comenzar con el carácter en cadenaHaystack especificado por el índice. Por ejemplo,
string first a 0a23456789abcdef 5

devolverá 10, pero

string first a 0123456789abcdef 11

devolverá -1.

string index cadena indiceCaracter
Devuelve el carácter indiceCaracter de el argumento cadena. Un indiceCaracter de 0 corresponde al primer carácter de la cadena. indiceCaracter puede especificarse tal como se describe en la sección ÍNDICES DE CADENAS.

Si indiceCaracter es menor que 0 o mayor o igual a la longitud de la cadena, entonces este comando devuelve una cadena vacía.

string is clase ?-strict? ?-failindex varname? cadena
Devuelve 1 si cadena es un miembro válido de la clase de caracteres especificada, de lo contrario devuelve 0. Si se especifica -strict, entonces una cadena vacía devuelve 0, de lo contrario una cadena vacía devolverá 1 en cualquier clase. Si se especifica -failindex, entonces si la función devuelve 0, el índice en la cadena donde la clase ya no era válida se almacenará en la variable llamada varname. El varname no se establecerá si string is devuelve 1. Se reconocen las siguientes clases de caracteres (el nombre de la clase puede abreviarse):
alnum
Cualquier carácter alfanumérico Unicode.
alpha
Cualquier carácter alfabético Unicode.
ascii
Cualquier carácter con un valor menor a \u0080 (aquellos que están en el rango ascii de 7 bits).
boolean
Cualquiera de las formas permitidas para Tcl_GetBoolean.
control
Cualquier carácter de control Unicode.
digit
Cualquier carácter de dígito Unicode. Tenga en cuenta que esto incluye caracteres fuera del rango [0-9].
double
Cualquiera de las formas permitidas para Tcl_GetDoubleFromObj.
entier
Cualquiera de los formatos de cadena válidos para un valor entero de tamaño arbitrario en Tcl, con espacios en blanco opcionales alrededor. Los formatos aceptados son exactamente los aceptados por la rutina C Tcl_GetBignumFromObj.
false
Cualquiera de las formas permitidas para Tcl_GetBoolean donde el valor es falso.
graph
Cualquier carácter de impresión Unicode, excepto el espacio.
integer
Cualquiera de las formas de cadena válidas para un valor entero de 32 bits en Tcl, con espacios en blanco opcionales alrededor. En caso de desbordamiento en el valor, se devuelve 0 y el varname contendrá -1.
list
Cualquier estructura de lista correcta, con espacios en blanco opcionales alrededor. En caso de estructura de lista incorrecta, se devuelve 0 y el varname contendrá el índice del "elemento" donde falla el análisis de la lista, o -1 si esto no se puede determinar.
lower
Cualquier carácter alfabético Unicode en minúsculas.
print
Cualquier carácter de impresión Unicode, incluido el espacio.
punct
Cualquier carácter de puntuación Unicode.
space
Cualquier carácter de espacio en blanco Unicode, separador vocálico mongol (U+180e), espacio de ancho cero (U+200b), unidor de palabras (U+2060) o espacio de no separación de ancho cero (U+feff) (=BOM).
true
Cualquiera de las formas permitidas para Tcl_GetBoolean donde el valor es verdadero.
upper
Cualquier carácter alfabético Unicode en mayúsculas.
wideinteger
Cualquiera de las formas válidas para un entero ancho en Tcl, con espacios en blanco opcionales alrededor. En caso de desbordamiento en el valor, se devuelve 0 y el varname contendrá -1.
wordchar
Cualquier carácter de palabra Unicode. Es decir, cualquier carácter alfanumérico y cualquier carácter de puntuación conector Unicode (por ejemplo, guion bajo).
xdigit
Cualquier carácter de dígito hexadecimal ([0-9A-Fa-f]).

En el caso de boolean, true y false, si la función devolverá 0, entonces el varname siempre se establecerá en 0, debido a la naturaleza variada de un valor booleano válido.

string last cadenaAgujadestino cadenaHaystack ?indiceFinal?
Busca en cadenaHaystack una secuencia de caracteres que coincidan exactamente con los caracteres de cadenaAgujadestino. Si se encuentra, devuelve el índice del primer carácter de la última coincidencia en cadenaHaystack. Si no hay coincidencia, devuelve -1. Si se especifica indiceFinal (en cualquiera de las formas descritas en ÍNDICES DE CADENAS), entonces solo se considerarán en la búsqueda los caracteres en cadenaHaystack en o antes del indiceFinal especificado. Por ejemplo,
devolverá 10, pero

cadena último a 0a23456789abcdef 9

devolverá 1.

cadena longitud cadena
Devuelve una cadena decimal que indica el número de caracteres de cadena. Tenga en cuenta que esto no es necesariamente lo mismo que el número de bytes utilizados para almacenar la cadena. Si el valor es un valor de array de bytes (como los devueltos al leer un canal codificado en binario), entonces esto devolverá la longitud real de bytes del valor.
cadena mapa ?-nocase? mapeo cadena
Reemplaza subcadenas en cadena basándose en los pares clave-valor de mapeo. mapeo es una lista de clave valor clave valor ... tal como se devuelve en array get. Cada instancia de una clave en la cadena será reemplazada por su valor correspondiente. Si se especifica -nocase, la coincidencia se realiza sin tener en cuenta las diferencias de mayúsculas y minúsculas. Tanto clave como valor pueden tener varios caracteres. El reemplazo se realiza de forma ordenada, por lo que la clave que aparece primero en la lista se comprobará primero, y así sucesivamente. cadena solo se recorre una vez, por lo que los reemplazos de claves anteriores no afectarán a las coincidencias de claves posteriores. Por ejemplo,
cadena mapa {abc 1 ab 2 a 3 1 0} 1abcaababcabababc

devolverá la cadena 01321221.

Tenga en cuenta que si una clave anterior es un prefijo de una posterior, enmascarará completamente la posterior. Por lo tanto, si el ejemplo anterior se reordena de esta manera,

cadena mapa {1 0 ab 2 a 3 abc 1} 1abcaababcabababc

devolverá la cadena 02c322c222c.

cadena coincidir ?-nocase? patron cadena
Verifica si patron coincide con cadena; devuelve 1 si lo hace, 0 si no. Si se especifica -nocase, el patrón intenta coincidir con la cadena sin distinguir entre mayúsculas y minúsculas. Para que las dos cadenas coincidan, sus contenidos deben ser idénticos, excepto que las siguientes secuencias especiales pueden aparecer en patron:
*
Coincide con cualquier secuencia de caracteres en cadena, incluida una cadena nula.
?
Coincide con cualquier carácter individual en cadena.
[caracteres]
Coincide con cualquier carácter del conjunto dado por caracteres. Si aparece una secuencia de la forma x-y en caracteres, coincidirá cualquier carácter entre x e y, inclusive. Cuando se utiliza con -nocase, los puntos finales del rango se convierten primero a minúsculas. Mientras que {[A-z]} coincide con “_” al coincidir de forma sensible a mayúsculas y minúsculas (ya que “_” está entre la “Z” y la “a”), con -nocase esto se considera como {[A-Za-z]} (y probablemente lo que se pretendía en primer lugar).
\x
Coincide con el carácter individual x. Esto proporciona una forma de evitar la interpretación especial de los caracteres *?[]\ en patron.
cadena rango cadena primer último
Devuelve un rango de caracteres consecutivos de cadena, comenzando con el carácter cuyo índice es primer y terminando con el carácter cuyo índice es último. Un índice de 0 se refiere al primer carácter de la cadena. primer y último se pueden especificar como para el método index. Si primer es menor que cero, se trata como si fuera cero, y si último es mayor o igual que la longitud de la cadena, se trata como si fuera fin. Si primer es mayor que último, se devuelve una cadena vacía.
cadena repetir cadena cuenta
Devuelve cadena repetida cuenta veces.
cadena reemplazar cadena primer último ?nuevacadena?
Elimina un rango de caracteres consecutivos de cadena, comenzando con el carácter cuyo índice es primer y terminando con el carácter cuyo índice es último. Un índice de 0 se refiere al primer carácter de la cadena. Primer y último se pueden especificar como para el método index. Si se especifica nuevacadena, se inserta en el rango de caracteres eliminado. Si primer es menor que cero, se trata como si fuera cero, y si último es mayor o igual que la longitud de la cadena, se trata como si fuera fin. Se devuelve la cadena inicial sin cambios si primer es mayor que último, o si primer es igual o mayor que la longitud de la cadena inicial, o último es menor que 0.
cadena invertir cadena
Devuelve una cadena que tiene la misma longitud que cadena pero con sus caracteres en orden inverso.
cadena minúsculas cadena ?primer? ?último?
Devuelve un valor igual a cadena excepto que todas las letras mayúsculas (o de título) se han convertido a minúsculas. Si se especifica primer, se refiere al índice del primer carácter de la cadena donde comenzar a modificar. Si se especifica último, se refiere al índice del carácter de la cadena donde detenerse (inclusive). primer y último se pueden especificar utilizando los formatos descritos en ÍNDICES DE CADENA.
cadena título cadena ?primer? ?último?
Devuelve un valor igual a cadena excepto que el primer carácter de cadena se convierte a su variante de título Unicode (o mayúscula si no hay variante de título) y el resto de la cadena se convierte a minúsculas. Si se especifica primer, se refiere al índice del primer carácter de la cadena donde comenzar a modificar. Si se especifica último, se refiere al índice del carácter de la cadena donde detenerse (inclusive). primer y último se pueden especificar utilizando los formatos descritos en ÍNDICES DE CADENA.
cadena mayúsculas cadena ?primer? ?último?
Devuelve un valor igual a cadena excepto que todas las letras minúsculas (o de título) se han convertido a mayúsculas. Si se especifica primer, se refiere al índice del primer carácter de la cadena donde comenzar a modificar. Si se especifica último, se refiere al índice del carácter de la cadena donde detenerse (inclusive). primer y último se pueden especificar utilizando los formatos descritos en ÍNDICES DE CADENA.
cadena recortar cadena ?caracteres?
Devuelve un valor igual a cadena excepto que se eliminan los caracteres iniciales o finales presentes en la cadena dada por caracteres. Si no se especifica caracteres, se eliminan los espacios en blanco (cualquier carácter para el que cadena es espacio devuelve 1, y "\0").
cadena recortarizq cadena ?caracteres?
Devuelve un valor igual a cadena excepto que se eliminan los caracteres iniciales presentes en la cadena dada por caracteres. Si no se especifica caracteres, se eliminan los espacios en blanco (cualquier carácter para el que cadena es espacio devuelve 1, y "\0").
cadena recortardch cadena ?caracteres?
Devuelve un valor igual a cadena excepto que se eliminan los caracteres finales presentes en la cadena dada por caracteres. Si no se especifica caracteres, se eliminan los espacios en blanco (cualquier carácter para el que cadena es espacio devuelve 1, y "\0").

SUBCOMANDOS OBSOLETOS

Estos subcomandos se admiten actualmente, pero es probable que desaparezcan en una futura versión, ya que su funcionalidad casi nunca se utiliza o es muy engañoso.

cadena longitudbytes cadena
Devuelve una cadena decimal que indica el número de bytes utilizados para representar cadena en memoria cuando se codifica en UTF-8 modificado interno de Tcl; Tcl también puede utilizar otras codificaciones para cadena, y no garantiza utilizar solo una codificación para una cadena particular. Dado que UTF-8 utiliza un número variable de bytes para representar caracteres Unicode, la longitud de bytes no será la misma que la longitud de caracteres en general. Los casos en los que un script se preocupa por la longitud de bytes son raros.

En casi todos los casos, debe usar la operación cadena longitud (incluida la determinación de la longitud de un valor de array de bytes de Tcl). Consulte la entrada del manual Tcl_NumUtfChars para obtener más detalles sobre la representación UTF-8.

Formalmente, la operación cadena longitudbytes devuelve el contenido del campo length de la estructura Tcl_Obj, después de llamar a Tcl_GetString para asegurar que el campo bytes esté poblado. Esto es muy poco probable que sea útil para scripts de Tcl, ya que la codificación interna de Tcl no es UTF-8 estricto, sino un CESU-8 modificado con un NUL desnormalizado (idéntico al utilizado en varios lugares por el mecanismo de serialización de Java) para permitir el procesamiento básico con funciones C no conscientes de Unicode. Dado que esta representación solo debería ser utilizada por la implementación de Tcl, el número de bytes utilizados para almacenar la representación tiene un valor muy bajo (excepto para el código de extensión C, que tiene acceso directo con fines de gestión de memoria, etc.)

Nota de compatibilidad: es probable que este subcomando se retire en una futura versión de Tcl. Es mejor usar el comando encoding convertto para convertir una cadena a una codificación conocida y luego aplicar cadena longitud a eso.

cadena longitud [codificación convertto utf-8 $lacaden]
cadena finde palabra cadena indicecaracter
Devuelve el índice del carácter justo después del último carácter de la palabra que contiene el carácter indicecaracter de cadena. indicecaracter puede especificarse utilizando los formatos en ÍNDICES DE CADENA. Una palabra se considera cualquier con

STRING OPERATIONS

string op ?arg ...?

This command is used to perform various operations on strings. The supported operations are:

string bytelength string
Returns the number of bytes in string.
string byval string
Returns string. This is a no-op, used for compatibility.
string cat ?string value ...?
Concatenates all of the string value arguments together and returns the result.
string compare ?-nocase? ?-length N? first second
Compares the two strings first and second lexicographically. Returns -1 if first comes before second, 0 if they are equal, and 1 if first comes after second. If the -nocase flag is given, then case is ignored during comparison. If the -length flag is given, then only the first N characters are compared. If N is negative, then it is treated as the length of the shorter string. If N is larger than the length of either string, then the entire string is used.
string equal ?-nocase? ?-length N? first second
Returns 1 if the two strings first and second are equal, and 0 otherwise. The -nocase and -length flags are interpreted in the same way as for string compare.
string index string i
Returns the character at index i in string. Indices start at 0. Negative indices count from the end of the string. Invalid indices return an empty string.
string is type ?string?
Tests whether the given string matches the given character type. If string is not specified, it defaults to the empty string. The possible values for type are:
alnum
Returns 1 if all characters in the string are letters or digits, 0 otherwise. An empty string returns 1.
alpha
Returns 1 if all characters in the string are letters, 0 otherwise. An empty string returns 1.
ascii
Returns 1 if all characters in the string are within the ASCII range (0-127), 0 otherwise. An empty string returns 1.
boolean
Returns 1 if the string is a valid boolean value ("0", "1", "true", "false", "yes", "no", "on", "off" in any case), 0 otherwise.
digit
Returns 1 if all characters in the string are decimal digits, 0 otherwise. An empty string returns 1.
espace
Returns 1 if all characters in the string are whitespace characters, 0 otherwise. An empty string returns 1.
graph
Returns 1 if all characters in the string are printable characters (not whitespace and not control characters), 0 otherwise. An empty string returns 1.
lower
Returns 1 if all characters in the string are lowercase letters, 0 otherwise. An empty string returns 1.
print
Returns 1 if all characters in the string are printable characters (not control characters), 0 otherwise. An empty string returns 1.
punct
Returns 1 if all characters in the string are punctuation characters, 0 otherwise. An empty string returns 1.
space
Returns 1 if all characters in the string are whitespace characters, 0 otherwise. An empty string returns 1.
upper
Returns 1 if all characters in the string are uppercase letters, 0 otherwise. An empty string returns 1.
wordchar
Returns 1 if all characters in the string are alphanumeric or underscore, 0 otherwise. An empty string returns 1.
xdigit
Returns 1 if all characters in the string are hexadecimal digits, 0 otherwise. An empty string returns 1.
string length string
Returns the number of characters in string.
string range string first last
Returns the substring of string starting at index first and ending at index last (inclusive). Indices may be specified using the forms in STRING INDICES. If first or last are out of bounds, they are clamped to the valid range. If first is greater than last, an empty string is returned.
string repeat string count
Returns a new string consisting of string repeated count times.
string reverse string
Returns a new string which is the reverse of string.
string tolower string
Returns a copy of string with all uppercase letters converted to lowercase.
string toupper string
Returns a copy of string with all lowercase letters converted to uppercase.
string trim ?-all? ?-left? ?-right? ?chars? string
Returns a copy of string with leading and/or trailing characters removed. By default, leading and trailing whitespace is removed. The chars argument specifies a string containing the characters to be removed. If -all is specified, then all characters in chars are removed from both ends. If -left is specified, then only leading characters are removed. If -right is specified, then only trailing characters are removed. If neither -left nor -right is specified, then both leading and trailing characters are removed. If chars is not specified, then all whitespace characters are removed. If -all is specified and chars is empty, then all characters are removed.
string trimleft ?-all? ?chars? string
Equivalent to string trim -left ?-all? ?chars? string.
string trimright ?-all? ?chars? string
Equivalent to string trim -right ?-all? ?chars? string.
string wordend string charIndex
Returns the index of the character immediately following the end of the word containing character charIndex of string. charIndex may be specified using the forms in STRING INDICES. A word is considered to be any contiguous range of alphanumeric (Unicode letters or decimal digits) or underscore (Unicode connector punctuation) characters, or any single character other than these.
string wordstart string charIndex
Returns the index of the first character in the word containing character charIndex of string. charIndex may be specified using the forms in STRING INDICES. A word is considered to be any contiguous range of alphanumeric (Unicode letters or decimal digits) or underscore (Unicode connector punctuation) characters, or any single character other than these.

STRING INDICES

When referring to indices into a string (e.g., for string index or string range) the following formats are supported:

integer
For any index value that passes string is integer -strict, the char specified at this integral index (e.g., 2 would refer to the “c” in “abcd”).
end
The last char of the string (e.g., end would refer to the “d” in “abcd”).
end-N
The last char of the string minus the specified integer offset N (e.g., “end-1” would refer to the “c” in “abcd”).
end+N
The last char of the string plus the specified integer offset N (e.g., “end+-1” would refer to the “c” in “abcd”).
M+N
The char specified at the integral index that is the sum of integer values M and N (e.g., “1+1” would refer to the “c” in “abcd”).
M-N
The char specified at the integral index that is the difference of integer values M and N (e.g., “2-1” would refer to the “b” in “abcd”).

In the specifications above, the integer value M contains no trailing whitespace and the integer value N contains no leading whitespace.

EXAMPLE

Test if the string in the variable string is a proper non-empty prefix of the string foobar.

set length [string length $string]
if {$length == 0} {
    set isPrefix 0
} else {
    set isPrefix [string equal -length $length $string "foobar"]
}
