NOMBRE

stardict-editor - programa para editar, compilar y descompilar diccionarios stardict

SINOPSIS

stardict-editor

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando stardict-editor.

stardict-editor es un programa que permite editar, compilar y descompilar diccionarios stardict desde una interfaz Gtk sencilla.

OPCIONES

Este programa no acepta ninguna opción.

AUTOR
