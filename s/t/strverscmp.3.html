strverscmp(3) Manual de funciones de biblioteca strverscmp(3)

NOMBRE

strverscmp - comparar dos cadenas de versión

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <string.h>
int strverscmp(const char *s1, const char *s2);

DESCRIPCIÓN

Para un conjunto de datos como jan1, jan2, ..., jan9, jan10, ..., ordenarlo lexicográficamente produce jan1, jan10, ..., jan2, ..., jan9. La tarea de strverscmp() es comparar dos cadenas produciendo el orden anterior, mientras que strcmp(3) solo encuentra el orden lexicográfico. Esta función no utiliza la categoría de localización LC_COLLATE, por lo que está pensada principalmente para situaciones en las que se espera que las cadenas estén en ASCII. Esto es diferente del orden producido por sort(1) -V.

Lo que hace esta función es lo siguiente. Si ambas cadenas son iguales, devuelve 0. De lo contrario, encuentra la posición entre dos bytes con la propiedad de que antes de ella ambas cadenas son iguales, mientras que directamente después de ella hay una diferencia. Encuentra las cadenas de dígitos consecutivas más grandes que contienen (o que empiezan en, o que terminan en) esta posición. Si una o ambas de estas son vacías, devuelve lo que strcmp(3) habría devuelto (orden numérico de los valores de los bytes). De lo contrario, compara ambas cadenas de dígitos numéricamente, donde las cadenas de dígitos con uno o más ceros iniciales se interpretan como si tuvieran un punto decimal delante (de modo que en particular las cadenas de dígitos con más ceros iniciales van antes que las cadenas de dígitos con menos ceros iniciales). Por lo tanto, el orden es 000, 00, 01, 010, 09, 0, 1, 9, 10.

VALOR DE RETORNO

La función strverscmp() devuelve un entero menor que, igual a, o mayor que cero si s1 se encuentra, respectivamente, antes que, igual a, o después que s2.

ESTÁNDARES

GNU.

EJEMPLOS

El programa a continuación se puede utilizar para demostrar el comportamiento de strverscmp(). Utiliza strverscmp() para comparar las dos cadenas dadas como argumentos de su línea de comandos. Un ejemplo de su uso es el siguiente:


$ ./a.out jan1 jan10;
jan1 < jan10

Código fuente del programa

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int
main(int argc, char *argv[])
{
    int res;
    if (argc != 3) {
        fprintf(stderr, "Uso: %s <cadena1> <cadena2>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    res = strverscmp(argv[1], argv[2]);
    printf("%s %s %s\n", argv[1],
           (res < 0) ? "<" : (res == 0) ? "==" : ">", argv[2]);
    exit(EXIT_SUCCESS);
}
