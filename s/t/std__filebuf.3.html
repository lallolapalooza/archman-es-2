NAME

template<typename _CharT, typename _Traits> std::basic_filebuf

The actual work of input and output (for files).

SYNOPSIS

template<typename _CharT, typename _Traits>

class std::basic_filebuf< _CharT, _Traits >

DESCRIPTION

The template class basic_filebuf<CharT, Traits> associates both its input and output sequence with an external disk file, and maintains a joint file position for both sequences. Many of its semantics are described in terms of similar behavior in the Standard C Library's FILE streams.

Template Parameters

_CharT Type of character stream.

_Traits Traits for character type, defaults to char_traits<_CharT>.

Requirements on traits_type, specific to this class:

  • traits_type::pos_type must be fpos<traits_type::state_type>
  • traits_type::off_type must be streamoff
  • traits_type::state_type must be Assignable and DefaultConstructible,
  • traits_type::state_type() must be the initial state for codecvt.

template<typename _CharT, typename _Traits> void std::basic_filebuf< _CharT, _Traits >::_M_set_buffer (streamsize __off) [inline], [protected]

This function sets the pointers of the internal buffer, both get and put areas. Typically:

__off == egptr() - eback() upon underflow/uflow (read mode); __off == 0 upon overflow (write mode); __off == -1 upon open, setbuf, seekoff/pos (uncommitted mode).

NB: epptr() - pbase() == _M_buf_size - 1, since _M_buf_size reflects the actual allocated memory and the last cell is reserved for the overflow char of a full put area.

    template<typename _CharT, typename _Traits> basic_filebuf< _CharT, _Traits >::int_type std::basic_filebuf< _CharT, _Traits >::overflow (int_type __c = _Traits::eof()) [protected], [virtual]

    Consume datos del búfer; escribe en la secuencia controlada.

    Parámetros

    __c Un carácter adicional a consumir.

    Devuelve

    eof() para indicar fallo, algún otro valor (generalmente *__c*, o *not_eof()*)

    Informalmente, esta función se llama cuando el búfer de salida está lleno (o no existe, ya que el almacenamiento en búfer no es obligatorio). Si existe un búfer, se *consume*, con *algún efecto* en la secuencia controlada. (Típicamente, el búfer se escribe en la secuencia sin cambios.) En cualquier caso, el carácter *c* también se escribe, si *__c* no es eof().

    Para una definición formal de esta función, consulte un buen texto como Langer & Kreft, o [27.5.2.4.5]/3-7.

    Se puede crear un `streambuf` de salida funcional sobrescribiendo solo esta función (no se utilizará área de búfer).

    Nota

    La versión de la clase base no hace nada, devuelve eof().
