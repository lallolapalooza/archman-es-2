Parámetros de Plantilla

_Tp Tipo de elemento.
_Sequence Tipo de secuencia subyacente, por defecto es deque<_Tp>.

Cumple con muchos de los requisitos de un contenedor, pero no define nada relacionado con iteradores. Muy pocas de las otras interfaces de contenedores estándar están definidas.

No es un contenedor real, sino un adaptador. Mantiene otro contenedor y proporciona una interfaz envoltorio para ese contenedor. El envoltorio es lo que impone el estricto comportamiento de pila de primero en entrar, último en salir.

El segundo parámetro de plantilla define el tipo de la secuencia/contenedor subyacente. Por defecto es std::deque, pero puede ser cualquier tipo que soporte back, push_back y pop_back, como std::list, std::vector, o un tipo definido por el usuario apropiado.

Los miembros que no se encuentran en los contenedores *normales* son container_type, que es un typedef para el segundo parámetro Sequence, y push, pop, y top, que son operaciones estándar de pila/FILO.

Elimina el primer elemento. Esta es una operación típica de pila. Reduce la pila en uno. La complejidad temporal de la operación depende de la secuencia subyacente.

Detailed Description

This class-template supports the Stack Stack data structure, which is a container that supports pushing and popping elements from only one end of the container. The stack is implemented by using another container adapter class, which is a container that provides a specific interface. The default underlying container is std::deque.

The std::stack container adapter provides the following member functions:

  • push(): Adds an element to the top of the stack.
  • pop(): Removes the top element from the stack.
  • top(): Returns a reference to the top element of the stack.
  • empty(): Checks if the stack is empty.
  • size(): Returns the number of elements in the stack.

Constructor & Destructor Documentation

The constructor of std::stack can take an optional underlying container as an argument. If no container is provided, a default-constructed std::deque is used.
