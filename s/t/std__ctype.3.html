Descripción Detallada

template<typename _CharT>

class std::ctype< _CharT >"Faceta principal de la plantilla de clase ctype.

Esta plantilla de clase define funciones de clasificación y conversión para conjuntos de caracteres. Envuelve la funcionalidad de cctype. Ctype es utilizada por los streams para muchas operaciones de E/S.

Esta plantilla proporciona las funciones virtuales protegidas que el desarrollador tendrá que reemplazar en una clase derivada o especialización para crear una faceta funcional. Las funciones públicas que acceden a ellas están definidas en __ctype_abstract_base, para permitir flexibilidad en la implementación. Ver ctype<wchar_t> para un ejemplo. Las funciones se documentan en __ctype_abstract_base.

Nota: se proporcionan implementaciones para todas las funciones virtuales protegidas, pero probablemente no serán útiles.

NOMBRE

std::ctype, isalnum, isalpha, isblank, iscntrl, isdigit, isgraph, islower, isprint, ispunct, isspace, isupper, isxdigit, tolower, toupper - Classification and conversion of characters

SINOPSIS

#include <cctype>

int isalnum(int c); int isalpha(int c); int isblank(int c); int iscntrl(int c); int isdigit(int c); int isgraph(int c); int islower(int c); int isprint(int c); int ispunct(int c); int isspace(int c); int isupper(int c); int isxdigit(int c); int tolower(int c); int toupper(int c);

DESCRIPCIÓN

The functions in this group classify characters and convert case. Each function takes an int argument, the value of which shall be representable as an unsigned char or the value of EOF. If the argument has any other value, the behavior is undefined.

The behavior of these functions depends on the current locale. Specifically, the character classification functions return non-zero if the character belongs to the specified class, and zero otherwise. The classification is based on the character's value and the settings of the locale's LC_CTYPE category. The conversion functions return the converted character, or the original character if no conversion is applicable.

  • isalnum(c): Checks if c is an alphanumeric character (a letter or a digit).
  • isalpha(c): Checks if c is an alphabetic character (a letter).
  • isblank(c): Checks if c is a blank character (space or tab).
  • iscntrl(c): Checks if c is a control character.
  • isdigit(c): Checks if c is a decimal digit character (0-9).
  • isgraph(c): Checks if c is a graphical character (any character that is not a space and not a control character).
  • islower(c): Checks if c is a lowercase letter.
  • isprint(c): Checks if c is a printable character (any character that is not a control character).
  • ispunct(c): Checks if c is a punctuation character (any graphical character that is not a digit or an alphabetic character).
  • isspace(c): Checks if c is a whitespace character (space, tab, newline, vertical tab, form feed, carriage return).
  • isupper(c): Checks if c is an uppercase letter.
  • isxdigit(c): Checks if c is a hexadecimal digit character (0-9, a-f, A-F).
  • tolower(c): Converts c to lowercase if it is an uppercase letter; otherwise, returns c unchanged.
  • toupper(c): Converts c to uppercase if it is a lowercase letter; otherwise, returns c unchanged.

VALORES DE RETORNO

The classification functions return a non-zero value if the character belongs to the specified class, and 0 otherwise. The conversion functions return the converted character, or the original character if no conversion is applicable.

ERRORES

No errors are reported.

EJEMPLOS

#include <iostream>
#include <cctype>

int main() {
    char c = 'A';
    if (std::isupper(c)) {
        std::cout << c << " is an uppercase letter." << std::endl;
        std::cout << "Lowercase: " << (char)std::tolower(c) << std::endl;
    }
    return 0;
}

NOTAS

The behavior of these functions is locale-dependent. For portable code, it is recommended to use the functions from the <locale> header, such as std::isalpha(c, std::locale()).
