strfile(1)

Paquete: fortune-mod

Licencias: BSD-4-Clause-UC

STRFILE(1) 4ª Distribución de Berkeley STRFILE(1)

NOMBRE

strfile - crea un archivo de acceso aleatorio para almacenar cadenas
unstr - vuelca cadenas en orden de puntero

SINOPSIS


strfile [-iorsx]
[-c caracter]
archivo_fuente
[archivo_salida]


unstr [-c caracter]
archivo_datos.[ext]
[archivo_salida]

DESCRIPCIÓN

strfile lee un archivo que contiene grupos de líneas separadas por una línea que contiene un solo signo de porcentaje `%` (u otro carácter delimitador especificado) y crea un archivo de datos que contiene una estructura de cabecera y una tabla de offsets de archivo para cada grupo de líneas. Esto permite el acceso aleatorio a las cadenas.

El archivo de salida, si no se especifica en la línea de comandos, se denomina archivo_fuente.dat.

El propósito de unstr es deshacer el trabajo de strfile. Imprime las cadenas contenidas en el archivo fuente, que es archivo_datos.ext sin su extensión, o archivo_datos si no se especifica ninguna extensión (en este caso, la extensión .dat se añade al nombre del archivo de datos) en el orden en que se enumeran en el archivo de cabecera archivo_datos. Si no se especifica ningún archivo_salida, imprime en la salida estándar; de lo contrario, imprime en el archivo especificado. unstr también puede cambiar universalmente el carácter delimitador en un archivo de cadenas. Es posible crear versiones ordenadas de los archivos de entrada utilizando strfile -o y luego usando unstr para volcaras en el orden de la tabla.

Opciones

Las opciones son las siguientes:

-c caracter

Cambia el carácter delimitador del signo de porcentaje a caracter. Esta opción está disponible tanto para strfile como para unstr.

-i

Ignora mayúsculas y minúsculas al ordenar las cadenas.

-o

Ordena las cadenas alfabéticamente. La tabla de offsets se ordenará alfabéticamente por los grupos de líneas a los que se hace referencia. Se ignoran los caracteres no alfanuméricos iniciales. Esta opción hace que se establezca el bit STR_ORDERED en el campo str_flags de la cabecera. (¡Y ahora realmente ordena! Antes no lo hacía).

-r

Aleatoriza el acceso a las cadenas. Las entradas en la tabla de offsets se ordenarán aleatoriamente. Esta opción hace que se establezca el bit STR_RANDOM en el campo str_flags de la cabecera. (Y realmente aleatoriza).

-s

Ejecuta en silencio; no muestra un mensaje de resumen al finalizar.

-x

Tenga en cuenta que cada carácter alfabético en los grupos de líneas se rota 13 posiciones en un cifrado César simple. Esta opción hace que se establezca el bit STR_ROTATED en el campo str_flags de la cabecera. Tenga en cuenta que no rota las cadenas; esa operación debe realizarse por separado.

Cabecera

El formato de la cabecera es:

#define VERSION 1 unsigned long str_version; /* número de versión */ unsigned long str_numstr; /* # de cadenas en el archivo */ unsigned long str_longlen; /* longitud de la cadena más larga */ unsigned long str_shortlen; /* longitud de la cadena más corta */ #define STR_RANDOM 0x1 /* punteros aleatorizados */ #define STR_ORDERED 0x2 /* punteros ordenados */ #define STR_ROTATED 0x4 /* texto rot-13'd */ unsigned long str_flags; /* campo de bits para indicadores */ char str_delim; /* carácter delimitador */

Todos los campos se escriben en orden de bytes de red.

ERRORES

Menos ahora, se espera. Sin embargo, las fortunas (cadenas de texto) que comienzan con una línea en blanco parecen ordenarse entre letras aleatorias. Esto incluye arte ASCII que no contiene letras, y primeras líneas que son únicamente no alfanuméricas, aparentemente. No tengo idea de por qué debería ser así.

OTROS USOS

¿Qué puedes hacer con esto además de imprimir mensajes sarcásticos y obscenos en las pantallas de los usuarios al iniciar o cerrar sesión?

Existen otras posibilidades. El código fuente de un programa de ejemplo, randstr, se incluye con esta distribución: randstr se sitúa entre unstr y fortune. Lee un único archivo especificado y selecciona aleatoriamente una única cadena de texto.

1

Incluir strfile.h en un programa de lectura/publicación de noticias, para generar firmas aleatorias. Tin(1) hace algo similar, de una manera mucho más compleja.

2

Incluirlo en un juego. Aunque strfile no soporta 'campos' o 'registros', no hay ninguna razón por la que las cadenas de texto no puedan ser consistentes: la primera línea, el resultado de una tirada de dados; la segunda línea, una puntuación; la tercera línea y subsiguientes, un mensaje de texto.

3

Úselo para almacenar su agenda de direcciones. Caramba, algunos de los tipos que conozco harían bien en usarlo para decidir a quién llamar los viernes por la noche (y para algunos, no importaría si hubiera números de teléfono o no).

4

Úselo en situaciones de 'lotería'. Si eres un ISP, escribe un script para almacenar nombres de inicio de sesión y GECOS de /etc/passwd en formato strfile, escribe otro para enviar 'felicidades, has ganado' al inicio de sesión afortunado seleccionado. El premio podría ser un mes de servicio gratuito, o si eres AOL, un mes gratis en un proveedor de servicios real.

VER TAMBIÉN

byteorder(3), fortune(6)

HISTORIA

La utilidad strfile apareció por primera vez en 4.4BSD. Esta versión fue modificada extensamente, gran parte de ella de maneras peculiares de Linux. Desde entonces se ha trabajado para hacer el código más genérico, y hasta ahora ha sido probado para funcionar con SunOS 4.x. Se espera que se soporten más plataformas a medida que el trabajo continúe.
