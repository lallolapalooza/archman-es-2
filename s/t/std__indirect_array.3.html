Descripción Detallada

plantilla<clase _Tp>

class std::indirect_array< _Tp >"Referencia a un subconjunto arbitrario de un array.

Un indirect_array es una referencia a los elementos reales de un array especificado por un array ordenado de índices. La forma de obtener un indirect_array es llamar a operator[](valarray<size_t>) en un valarray. El indirect_array devuelto permite entonces realizar operaciones en el subconjunto de elementos referenciado en el valarray original.

Por ejemplo, si se obtiene un indirect_array usando el array (4,2,0) como argumento, y luego se asigna a un array que contiene (1,2,3), entonces el array subyacente tendrá array[0]==3, array[2]==2, y array[4]==1.
