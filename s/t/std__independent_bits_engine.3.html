Detailed Description

The class template independent_bits_engine produces random numbers with a specified number of bits, using an underlying random number engine (the template parameter _RandomNumberEngine) to supply entropy.

The generated random numbers have exactly __w bits of randomness. __w must be a positive integer, and must not be greater than the number of bits in the _UIntType type.

The underlying engine _RandomNumberEngine must also meet the requirements of a UniformRandomBitGenerator.

The class template independent_bits_engine is a template parameter pack that takes the following parameters:

_RandomNumberEngine
The underlying random number engine. Must meet the requirements of a UniformRandomBitGenerator.
__w
The number of random bits in the generated random numbers. Must be a positive integer, and must not be greater than the number of bits in _UIntType.
_UIntType
The unsigned integer type used to represent the generated random numbers. Must have at least __w bits.
