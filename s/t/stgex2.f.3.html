subrutina stgex2 (wantq, wantz, n, a, lda, b, ldb, q, ldq, z, ldz, j1, n1, n2, work, lwork, info)
STGEX2 intercambia bloques diagonales adyacentes en un par de matrices triangulares superiores (cuasi) mediante una transformación de equivalencia ortogonal.

Documentación de Función/Subrutina

subrutina stgex2 (logical wantq, logical wantz, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldq, * ) q, integer ldq, real, dimension( ldz, * ) z, integer ldz, integer j1, integer n1, integer n2, real, dimension( * ) work, integer lwork, integer info)

STGEX2 intercambia bloques diagonales adyacentes (A11, B11) y (A22, B22) de tamaño 1x1 o 2x2 en un par de matrices triangulares superiores (cuasi) (A, B) mediante una transformación de equivalencia ortogonal.

Propósito:

!>
!> STGEX2 intercambia bloques diagonales adyacentes (A11, B11) y (A22, B22)
!> de tamaño 1x1 o 2x2 en un par de matrices triangulares superiores (cuasi)
!> (A, B) mediante una transformación de equivalencia ortogonal.
!>
!> (A, B) debe estar en forma canónica de Schur real generalizada (como la
!> devuelta por SGGES), es decir, A es triangular superior por bloques con
!> bloques diagonales de 1x1 y 2x2. B es triangular superior.
!>
!> Opcionalmente, se actualizan las matrices Q y Z de vectores de Schur
!> generalizados.
!>
!>        Q(entrada) * A(entrada) * Z(entrada)**T = Q(salida) * A(salida) * Z(salida)**T
!>        Q(entrada) * B(entrada) * Z(entrada)**T = Q(salida) * B(salida) * Z(salida)**T
!>
!>

Parámetros

WANTQ 
!>          WANTQ es LOGICAL
!>          .TRUE. : actualizar la matriz de transformación izquierda Q;
!>          .FALSE.: no actualizar Q.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          .TRUE. : actualizar la matriz de transformación derecha Z;
!>          .FALSE.: no actualizar Z.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B. N >= 0.
!>

A

!>          A es array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz A del par (A, B).
!>          En la salida, la matriz A actualizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es array REAL, de dimensión (LDB,N)
!>          En la entrada, la matriz B del par (A, B).
!>          En la salida, la matriz B actualizada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

Q

!>          Q es array REAL, de dimensión (LDQ,N)
!>          En la entrada, si WANTQ = .TRUE., la matriz ortogonal Q.
!>          En la salida, la matriz Q actualizada.
!>          No referenciado si WANTQ = .FALSE..
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= 1.
!>          Si WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z es array REAL, de dimensión (LDZ,N)
!>          En la entrada, si WANTZ =.TRUE., la matriz ortogonal Z.
!>          En la salida, la matriz Z actualizada.
!>          No referenciado si WANTZ = .FALSE..
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1.
!>          Si WANTZ = .TRUE., LDZ >= N.
!>

J1

!>          J1 es INTEGER
!>          El índice del primer bloque (A11, B11). 1 <= J1 <= N.
!>

N1

!>          N1 es INTEGER
!>          El orden del primer bloque (A11, B11). N1 = 0, 1 o 2.
!>

N2

!>          N2 es INTEGER
!>          El orden del segundo bloque (A22, B22). N2 = 0, 1 o 2.
!>

WORK

!>          WORK es array REAL, de dimensión (MAX(1,LWORK)).
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >=  MAX( N*(N2+N1), (N2+N1)*(N2+N1)*2 )
!>

INFO

!>          INFO es INTEGER
!>            =0: Salida exitosa
!>            >0: Si INFO = 1, la matriz transformada (A, B) estaría
!>                demasiado alejada de la forma de Schur generalizada; los
!>                bloques no se intercambian y (A, B) y (Q, Z) no cambian.
!>                El problema de intercambio es demasiado mal condicionado.
!>            <0: Si INFO = -16: LWORK es demasiado pequeño. El valor apropiado
!>                para LWORK se devuelve en WORK(1).
!>
