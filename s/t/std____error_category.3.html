Descripción Detallada

Clase base abstracta para tipos que definen una categoría de códigos de error.

Una categoría de error define un contexto que da significado al entero almacenado en un objeto error_code o error_condition. Por ejemplo, las constantes errno estándar como EINVAL y ENOMEM están asociadas con la categoría "genérica" y otros números de error específicos del SO están asociados con la categoría "del sistema", pero una categoría definida por el usuario podría dar significados diferentes a los mismos valores numéricos.

Una categoría definida por el usuario puede anular las funciones miembro equivalent para definir la correspondencia entre errores en diferentes categorías. Por ejemplo, una categoría para errores de E/S de disco podría considerar algunos de sus números de error como equivalentes a ENOSPC y ENOENT en la categoría genérica.
