subrutina strsna (character job, character howmny, logical, dimension( * ) select, integer n, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, real, dimension( * ) s, real, dimension( * ) sep, integer mm, integer m, real, dimension( ldwork, * ) work, integer ldwork, integer, dimension( * ) iwork, integer info)

STRSNA

Propósito:

!>
!> STRSNA estima los números de condición recíprocos para valores propios y/o
!> vectores propios derechos especificados de una matriz real superior
!> cuasi-triangular T (o de cualquier matriz Q*T*Q**T con Q ortogonal).
!>
!> T debe estar en forma canónica de Schur (como la devuelta por SHSEQR), es decir,
!> bloque triangular superior con bloques diagonales de 1x1 y 2x2; cada
!> bloque diagonal de 2x2 tiene sus elementos diagonales iguales y sus
!> elementos fuera de la diagonal de signo opuesto.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          valores propios (S) o vectores propios (SEP):
!>          = 'E': solo para valores propios (S);
!>          = 'V': solo para vectores propios (SEP);
!>          = 'B': para ambos, valores propios y vectores propios (S y SEP).
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcula los números de condición para todos los pares propios;
!>          = 'S': calcula los números de condición para pares propios seleccionados
!>                 especificados por el array SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los pares propios para los que
!>          se requieren los números de condición. Para seleccionar los números de
!>          condición para el valor propio real w(j) correspondiente,
!>          SELECT(j) debe establecerse en .TRUE.. Para seleccionar los números de
!>          condición correspondientes a un par conjugado complejo de valores
!>          propios w(j) y w(j+1), SELECT(j) o SELECT(j+1) o ambos, deben
!>          establecerse en .TRUE..
!>          Si HOWMNY = 'A', SELECT no se referencia.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array REAL, de dimensión (LDT,N)
!>          La matriz superior cuasi-triangular T, en forma canónica de Schur.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array REAL, de dimensión (LDVL,M)
!>          Si JOB = 'E' o 'B', VL debe contener los vectores propios izquierdos de T
!>          (o de cualquier Q*T*Q**T con Q ortogonal), correspondientes a los
!>          pares propios especificados por HOWMNY y SELECT. Los vectores propios
!>          deben almacenarse en columnas consecutivas de VL, tal como los devuelve
!>          SHSEIN o STREVC.
!>          Si JOB = 'V', VL no se referencia.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.
!>          LDVL >= 1; y si JOB = 'E' o 'B', LDVL >= N.
!>

VR

!>          VR es un array REAL, de dimensión (LDVR,M)
!>          Si JOB = 'E' o 'B', VR debe contener los vectores propios derechos de T
!>          (o de cualquier Q*T*Q**T con Q ortogonal), correspondientes a los
!>          pares propios especificados por HOWMNY y SELECT. Los vectores propios
!>          deben almacenarse en columnas consecutivas de VR, tal como los devuelve
!>          SHSEIN o STREVC.
!>          Si JOB = 'V', VR no se referencia.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.
!>          LDVR >= 1; y si JOB = 'E' o 'B', LDVR >= N.
!>

S

!>          S es un array REAL, de dimensión (MM)
!>          Si JOB = 'E' o 'B', los números de condición recíprocos de los
!>          valores propios seleccionados, almacenados en elementos
!>          consecutivos del array. Para un par conjugado complejo de valores
!>          propios, se asignan dos elementos consecutivos de S al mismo valor.
!>          Por lo tanto, S(j), SEP(j) y las columnas j de VL y VR corresponden
!>          todas al mismo par propio (pero no necesariamente al j-ésimo par
!>          propio, a menos que se seleccionen todos los pares propios).
!>          Si JOB = 'V', S no se referencia.
!>

SEP

!>          SEP es un array REAL, de dimensión (MM)
!>          Si JOB = 'V' o 'B', los números de condición recíprocos estimados de
!>          los vectores propios seleccionados, almacenados en elementos
!>          consecutivos del array. Para un vector propio complejo, se asignan
!>          dos elementos consecutivos de SEP al mismo valor. Si los valores
!>          propios no se pueden reordenar para calcular SEP(j), SEP(j) se
!>          establece en 0; esto solo puede ocurrir cuando el valor real sería
!>          muy pequeño de todos modos.
!>          Si JOB = 'E', SEP no se referencia.
!>

MM

!>          MM es INTEGER
!>          El número de elementos en los arrays S (si JOB = 'E' o 'B')
!>          y/o SEP (si JOB = 'V' o 'B'). MM >= M.
!>

M

!>          M es INTEGER
!>          El número de elementos de los arrays S y/o SEP realmente
!>          utilizados para almacenar los números de condición estimados.
!>          Si HOWMNY = 'A', M se establece en N.
!>

WORK

!>          WORK es un array REAL, de dimensión (LDWORK,N+6)
!>          Si JOB = 'E', WORK no se referencia.
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          LDWORK >= 1; y si JOB = 'V' o 'B', LDWORK >= N.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (2*(N-1))
!>          Si JOB = 'E', IWORK no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!> El recíproco del número de condición de un valor propio lambda se
!> define como
!>
!>          S(lambda) = |v**T*u| / (norm(u)*norm(v))
!>
!> donde u y v son los vectores propios derecho e izquierdo de T
!> correspondientes a lambda; v**T denota la transpuesta de v, y norm(u)
!> denota la norma Euclidiana. Estos números de condición recíprocos
!> siempre están entre cero (muy mal condicionado) y uno (muy bien
!> condicionado). Si n = 1, S(lambda) se define como 1.
!>
!> Un límite de error aproximado para un valor propio calculado W(i) se da por
!>
!>                      EPS * norm(T) / S(i)
!>
!> donde EPS es la precisión de la máquina.
!>
!> El recíproco del número de condición del vector propio derecho u
!> correspondiente a lambda se define de la siguiente manera. Supongamos
!>
!>              T = ( lambda  c  )
!>                  (   0    T22 )
!>
!> Entonces el número de condición recíproco es
!>
!>          SEP( lambda, T22 ) = sigma-min( T22 - lambda*I )
!>
!> donde sigma-min denota el valor singular más pequeño. Aproximamos
!> el valor singular más pequeño por el recíproco de una estimación de
!> la norma uno de la inversa de T22 - lambda*I. Si n = 1, SEP(1) es
!> definido como abs(T(1,1)).
!>

Function/Subroutine Documentation

 subroutine strsna(uplo, job, kase, n, t, ldt, vl, ldvl, vr, ldvr, int_t)
  character          :: uplo
  character          :: job
  character          :: kase
  integer, intent(in) :: n
  real, dimension( ldt, * ) :: t
  integer, intent(in) :: ldt
  real, dimension( ldvl, * ) :: vl
  integer, intent(in) :: ldvl
  real, dimension( ldvr, * ) :: vr
  integer, intent(in) :: ldvr
  integer, intent(out) :: int_t

  !
  ! Purpose
  ! =======
  !
  ! strsna computes the Schur vectors from the Schur decomposition of a
  ! general matrix A.
  !
  ! This subroutine is the scalar-dispatched version of strsna.
  !
  ! Arguments
  ! =========
  !
  ! uplo    (input) CHARACTER*1
  !         Specifies whether the matrix T is upper or lower triangular.
  !         = 'U': T is upper triangular.
  !         = 'L': T is lower triangular.
  !
  ! job     (input) CHARACTER*1
  !         Specifies the desired type of Schur vectors to be computed.
  !         = 'V': Compute the right Schur vectors VR.
  !         = 'L': Compute the left Schur vectors VL.
  !         = 'B': Compute both the left and right Schur vectors VL and VR.
  !
  ! kase    (input) CHARACTER*1
  !         Specifies the task to be performed.
  !         = 'A': compute the Schur vector for all eigenvalues.
  !         = 'S': compute the Schur vector for the 1-st eigenvalue.
  !         = 'D': compute the Schur vector for the selected block of eigenvalues.
  !
  ! n       (input) INTEGER
  !         The order of the matrix T.  0 <= n <= n.
  !
  ! t       (input) REAL array, dimension (ldt, n)
  !         The upper or lower triangular matrix T in the Schur decomposition
  !         of a matrix A. The structure of T is assumed to be that given
  !         by the output of a standard Schur decomposition algorithm.
  !
  ! ldt     (input) INTEGER
  !         The leading dimension of the array T.  ldt >= max(1, n).
  !
  ! vl      (output) REAL array, dimension (ldvl, k)
  !         If job = 'L' or 'B', vl is an array containing the required
  !         left Schur vectors. If kase = 'A', k = n. If kase = 'S', k = 1.
  !         If kase = 'D', k is the number of eigenvalues in the selected
  !         block.
  !         The Schur vectors are normalized so that the 1-norms of the
  !         differences between the computed Schur vectors and the exact
  !         Schur vectors are minimized.
  !
  ! ldvl    (input) INTEGER
  !         The leading dimension of the array vl.
  !         If job = 'L' or 'B', ldvl >= max(1, n).
  !
  ! vr      (output) REAL array, dimension (ldvr, k)
  !         If job = 'V' or 'B', vr is an array containing the required
  !         right Schur vectors. If kase = 'A', k = n. If kase = 'S', k = 1.
  !         If kase = 'D', k is the number of eigenvalues in the selected
  !         block.
  !         The Schur vectors are normalized so that the 1-norms of the
  !         differences between the computed Schur vectors and the exact
  !         Schur vectors are minimized.
  !
  ! ldvr    (input) INTEGER
  !         The leading dimension of the array vr.
  !         If job = 'V' or 'B', ldvr >= max(1, n).
  !
  ! int_t   (output) INTEGER
  !         The number of eigenvalues (with their algebraic multiplicities)
  !         in the selected block.
  !
  ! Error handling
  ! ==============
  !
  ! If the algorithm fails to converge, the Schur vectors may be computed
  ! incorrectly.
  !
  ! Further Details
  ! ===============
  !
  ! The Schur vectors are computed by solving a generalized Sylvester
  ! equation. The approximate error bounds for the computed Schur vectors are
  ! given by
  !
  !                       EPS * norm(T) / SEP(i)
  !
  ! where EPS is the machine epsilon, norm(T) is the 1-norm of T, and SEP(i)
  ! is the separation between the i-th eigenvalue and the rest of the
  ! eigenvalues.
  !
  ! The approximate error bound for a computed right eigenvector VR(i)
  ! is given by
  !
  !                       EPS * norm(T) / SEP(i)
  !
