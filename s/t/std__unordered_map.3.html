DESCRIPTION

A standard container composed of unique keys (containing at most one of each key value) that associates values of another type with the keys.

Since

C++11

Template Parameters

_Key Type of key objects.
_Tp Type of mapped objects.
_Hash Hashing function object type, defaults to hash<_Value>.
_Pred Predicate function object type, defaults to equal_to<_Value>.
_Alloc Allocator type, defaults to std::allocator<std::pair<const _Key, _Tp>>.

Meets the requirements of a container, and unordered associative container

The resulting value type of the container is std::pair<const _Key, _Tp>.

Base is _Hashtable, dispatched at compile time via template alias __umap_hashtable.

std::unordered_map Reference

The C++ Standard Library provides a hash-table based associative container.

Include the <unordered_map> header to use
the std::unordered_map class template.

A std::unordered_map is an unordered associative container that supports efficient element retrieval (average case O(1)) and insertion.

An unordered_map is defined as a template class that takes four template parameters:

template<
    typename Key,
    typename T,
    typename Hash = std::hash<Key>,
    typename Pred = std::equal_to<Key>,
    typename Alloc = std::allocator<std::pair<const Key, T> >
> class unordered_map;

Here:

  • Key is the type of the keys used in the map.
  • T is the type of the mapped values.
  • Hash is a function object type that takes a key object as an argument and returns a hash value. The default is std::hash<Key>.
  • Pred is a function object type that takes two key objects as arguments and returns true if they are considered equal, and false otherwise. The default is std::equal_to<Key>.
  • Alloc is the allocator type used for storing map elements. The default is std::allocator<std::pair<const Key, T> >.

The elements stored in the unordered_map are of type std::pair<const Key, T>.

See the C++ reference for more details:

  • https://en.cppreference.com/w/cpp/container/unordered_map

The rest of this documentation describes the implementation details of std::unordered_map as found in the GNU C++ standard library.

Note that the template parameters for the GNU implementation often use a leading underscore, e.g. _Key instead of Key.

Also note that the GNU implementation uses _Hashtable internally to implement the unordered_map. The documentation below refers to the unordered_map interface, but may also reference implementation details of _Hashtable.

Example:

#include <iostream>
#include <unordered_map>

int main()
{
    std::unordered_map<std::string, int> word_count;

    // Insert elements
    word_count["hello"] = 1;
    word_count["world"] = 1;
    word_count["hello"] = word_count["hello"] + 1;

    // Access elements
    std::cout << "Count of 'hello': " << word_count["hello"] << std::endl;
    std::cout << "Count of 'world': " << word_count["world"] << std::endl;

    // Iterate through elements
    for (const auto& pair : word_count) {
        std::cout << pair.first << ": " << pair.second << std::endl;
    }

    return 0;
}

Output:

Count of 'hello': 2
Count of 'world': 1
hello: 2
world: 1
