strcasecmp(3) Manual de funciones de biblioteca strcasecmp(3)

NOMBRE

strcasecmp, strncasecmp - compara dos cadenas de texto ignorando las mayúsculas/minúsculas

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <strings.h>
int strcasecmp(const char *s1, const char *s2);
int strncasecmp(size_t n;
                const char s1[n], const char s2[n], size_t n);

DESCRIPCIÓN

La función strcasecmp() realiza una comparación byte a byte de las cadenas s1 y s2, ignorando la capitalización de los caracteres. Devuelve un entero menor que, igual a, o mayor que cero si s1 se encuentra, respectivamente, que es menor que, que coincide con, o que es mayor que s2.

La función strncasecmp() es similar, excepto que compara como máximo n bytes de s1 y s2.

VALOR DE RETORNO

Las funciones strcasecmp() y strncasecmp() devuelven un entero menor que, igual a, o mayor que cero si s1 se encuentra, después de ignorar la capitalización, que es menor que, que coincide con, o que es mayor que s2, respectivamente.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
strcasecmp (), strncasecmp () Seguridad en hilos MT-Safe locale

ESTÁNDARES

POSIX.1-2008.

HISTORIAL

4.4BSD, POSIX.1-2001.

Las funciones strcasecmp() y strncasecmp() aparecieron por primera vez en 4.4BSD, donde se declaraban en <string.h>. Por lo tanto, por razones de compatibilidad histórica, el archivo de cabecera <string.h> de glibc también declara estas funciones, si se define el macro de prueba de características _DEFAULT_SOURCE (o, en glibc 2.19 y anteriores, _BSD_SOURCE).

El estándar POSIX.1-2008 dice sobre estas funciones:

Cuando la categoría LC_CTYPE de la configuración regional que se está utilizando proviene de la configuración regional POSIX, estas funciones se comportarán como si las cadenas se hubieran convertido a minúsculas y luego se hubiera realizado una comparación byte a byte. De lo contrario, los resultados no están especificados.
