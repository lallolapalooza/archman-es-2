stropts.h(0p) Manual del Programador POSIX stropts.h(0p)

PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

stropts.h — Interfaz STREAMS (STREAMS)

SINOPSIS

#include <stropts.h>

DESCRIPCION

El archivo de cabecera <stropts.h> definirá la estructura bandinfo, que incluirá al menos los siguientes miembros:

int            bi_flag  Tipo de vaciado.
unsigned char  bi_pri   Banda de prioridad.

El archivo de cabecera <stropts.h> definirá la estructura strpeek, que incluirá al menos los siguientes miembros:

struct strbuf  ctlbuf   La porción de control del mensaje.
struct strbuf  databuf  La porción de datos del mensaje.
t_uscalar_t    flags    RS_HIPRI o 0.

El archivo de cabecera <stropts.h> definirá la estructura strbuf, que incluirá al menos los siguientes miembros:

char  *buf     Puntero al búfer.
int    len     Longitud de los datos.
int    maxlen  Longitud máxima del búfer.

El archivo de cabecera <stropts.h> definirá la estructura strfdinsert, que incluirá al menos los siguientes miembros:

struct strbuf  ctlbuf   La porción de control del mensaje.
struct strbuf  databuf  La porción de datos del mensaje.
int            fildes   Descriptor de archivo de otro STREAM.
t_uscalar_t    flags    RS_HIPRI o 0.
int            offset   Ubicación relativa del valor almacenado.

El archivo de cabecera <stropts.h> definirá la estructura strioctl, que incluirá al menos los siguientes miembros:

int    ic_cmd     Comando ioctl().
char  *ic_dp      Puntero al búfer.
int    ic_len     Longitud de los datos.
int    ic_timout  Tiempo de espera de respuesta.

El archivo de cabecera <stropts.h> definirá la estructura strrecvfd, que incluirá al menos los siguientes miembros:

int    fd   Descriptor de archivo recibido.
gid_t  gid  GID del remitente.
uid_t  uid  UID del remitente.

El archivo de cabecera <stropts.h> definirá los tipos uid_t y gid_t a través de typedef, como se describe en <sys/types.h>.

El archivo de cabecera <stropts.h> definirá los tipos t_scalar_t y t_uscalar_t, respectivamente, como tipos opacos con signo y sin signo de igual longitud de al menos 32 bits.

El archivo de cabecera <stropts.h> definirá la estructura str_list, que incluirá al menos los siguientes miembros:

struct str_mlist  *sl_modlist  Nombres de módulos STREAMS.
int                sl_nmods    Número de nombres de módulos STREAMS.

El archivo de cabecera <stropts.h> definirá la estructura str_mlist, que incluirá al menos el siguiente miembro:

char  l_name[FMNAMESZ+1]  Un nombre de módulo STREAMS.

I_ATMARK
¿Está el mensaje superior "marcado"?
I_CANPUT
¿Está una banda en modo escritura?
I_CKBAND
Verificar si existen mensajes en una banda.
I_FDINSERT
Enviar información definida por la implementación sobre otro STREAM.
I_FIND
Buscar un módulo STREAMS.
I_FLUSH
Vaciar un STREAM.
I_FLUSHBAND
Vaciar una banda de un STREAM.
I_GETBAND
Obtener la banda del mensaje superior en un STREAM.
I_GETCLTIME
Obtener el tiempo de espera de cierre.
I_GETSIG
Recuperar señales de notificación actuales.
I_GRDOPT
Obtener el modo de lectura.
I_GWROPT
Obtener el modo de escritura.
I_LINK
Conectar dos STREAMs.
I_LIST
Obtener todos los nombres de módulos en un STREAM.
I_LOOK
Obtener el nombre del módulo superior.
I_NREAD
Tamaño del mensaje superior.
I_PEEK
Mirar el mensaje superior en un STREAM.
I_PLINK
Conectar persistentemente dos STREAMs.
I_POP
Quitar un módulo STREAMS.
I_PUNLINK
Desmontar un enlace STREAMS persistente.
I_PUSH
Insertar un módulo STREAMS.
I_RECVFD
Obtener un descriptor de archivo enviado a través de I_SENDFD.
I_SENDFD
Pasar un descriptor de archivo a través de una tubería STREAMS.
I_SETCLTIME
Establecer el tiempo de espera de cierre.
I_SETSIG

I_SRDOPT

I_STR

I_SWROPT
Establecer el modo de escritura.
I_UNLINK
Desconectar dos STREAMs.

El archivo de cabecera <stropts.h> definirá al menos la siguiente constante simbólica para su uso con I_LOOK:

FMNAMESZ
El tamaño mínimo en bytes del búfer al que se hace referencia mediante el argumento arg.

El archivo de cabecera <stropts.h> definirá al menos las siguientes constantes simbólicas para su uso con I_FLUSH:

FLUSHR
Vaciar colas de lectura.
FLUSHRW
Vaciar colas de lectura y escritura.
FLUSHW
Vaciar colas de escritura.

El archivo de cabecera <stropts.h> definirá al menos las siguientes constantes simbólicas para su uso con I_SETSIG:

S_BANDURG
Cuando se usa en conjunto con S_RDBAND, se genera SIGURG en lugar de SIGPOLL cuando un mensaje de prioridad llega al frente de la cola de lectura del cabezal STREAM.
S_ERROR
La notificación de una condición de error llega al cabezal STREAM.
S_HANGUP
La notificación de una desconexión llega al cabezal STREAM.
S_HIPRI
Hay un mensaje de alta prioridad en la cola de lectura del cabezal STREAM.
S_INPUT
Ha llegado un mensaje, que no es de alta prioridad, al cabezal de una cola de lectura del cabezal STREAM.
S_MSG
Un mensaje de señal STREAMS que contiene la señal SIGPOLL llega al frente de la cola de lectura del cabezal STREAM.
S_OUTPUT
La cola de escritura para datos normales (banda de prioridad 0) justo debajo del cabezal STREAM ya no está llena. Esto notifica al proceso que hay espacio en la cola para enviar (o escribir) datos normales aguas abajo.
S_RDBAND
Ha llegado un mensaje con una banda de prioridad distinta de cero.

DESCRIPTION

El archivo de cabecera <stropts.h> define las constantes simbólicas que se utilizan con las llamadas al sistema relacionadas con STREAMS, incluidas las constantes utilizadas con la llamada al sistema ioctl().

El archivo de cabecera <stropts.h> definirá al menos las siguientes constantes simbólicas para su uso con ioctl:

I_LOOKUP
Devuelve el número de módulo de un módulo en la pila STREAMS.
I_PUSH
Inserta un módulo en la pila STREAMS.
I_POP
Elimina el módulo superior de la pila STREAMS.
I_LINK
Enlaza un STREAM a otro.
I_UNLINK
Desenlaza un STREAM.
/
Envía una solicitud de control al nivel más bajo de la pila STREAMS.
/
Obtiene los indicadores de notificación de la cola de lectura de la cabeza del STREAM.
/
Establece los indicadores de notificación de la cola de lectura de la cabeza del STREAM.
/
Lee un mensaje de la cabeza de la cola de lectura de la cabeza del STREAM.
/
Escribe un mensaje en la cola de escritura de la cabeza del STREAM.
/
Permite inspeccionar el mensaje en la cabeza de la cola de lectura de la cabeza del STREAM sin eliminarlo.
/
Inserta un mensaje que contiene un descriptor de archivo en el STREAM.
/
Envía un descriptor de archivo a través de un STREAM.
/
Recibe un descriptor de archivo a través de un STREAM.
/
Establece las opciones de escritura para un STREAM.
/
Obtiene las opciones de escritura para un STREAM.
/
Establece las opciones de lectura para un STREAM.
/
Obtiene las opciones de lectura para un STREAM.
/
Comprueba si el STREAM está en una marca.
/
Comprueba la cuota de una cola STREAMS.
/
Borra la cuota de una cola STREAMS.
I_LIST shayari/
Lista todos los módulos STREAMS de un STREAM.
I_PLINK shayari/
Obtiene el ID del proceso del proceso que enlaza el STREAM.

El archivo de cabecera <stropts.h> definirá al menos las siguientes constantes simbólicas para su uso con I_GETmsg, I_PUTmsg, I_PEEK, I_FDINSERT, I_SENDFD, I_RECVFD, y llamadas relacionadas:

S_HIPRI
Un mensaje de alta prioridad ha llegado a la cabeza de una cola de lectura de la cabeza del STREAM.
S_INPUT
Ha llegado un mensaje normal (banda de prioridad establecida en 0) a la cabeza de una cola de lectura de la cabeza del STREAM.
S_MSG
Un mensaje ha llegado a la cabeza de una cola de lectura de la cabeza del STREAM.
S_OUTPUT
La cola de escritura para un módulo STREAMS está lista para aceptar escritura.
S_RALL
Cualquier mensaje ha llegado a la cabeza de una cola de lectura de la cabeza del STREAM.
S_RDNORM
Un mensaje normal (banda de prioridad establecida en 0) ha llegado a la cabeza de una cola de lectura de la cabeza del STREAM.
S_WRBAND
La cola de escritura para una banda de prioridad distinta de cero justo debajo de la cabeza del STREAM ya no está llena.
S_WRNORM
Equivalente a S_OUTPUT.

El archivo de cabecera <stropts.h> definirá al menos la siguiente constante simbólica para su uso con I_PEEK:

RS_HIPRI
Solo buscar mensajes de alta prioridad.

El archivo de cabecera <stropts.h> definirá al menos las siguientes constantes simbólicas para su uso con I_SRDOPT:

RMSGD
Modo de descarte de mensajes.
RMSGN
Modo de no descarte de mensajes.
RNORM
Modo de flujo de bytes, el predeterminado.
RPROTDAT
Entrega la parte de control de un mensaje como datos cuando un proceso ejecuta una llamada a read().
RPROTDIS
Descarta la parte de control de un mensaje, entregando cualquier parte de datos, cuando un proceso ejecuta una llamada a read().
RPROTNORM
Falla la llamada a read() con [EBADMSG] si un mensaje que contiene una parte de control está al frente de la cola de lectura de la cabeza del STREAM.

El archivo de cabecera <stropts.h> definirá al menos la siguiente constante simbólica para su uso con I_SWOPT:

SNDZERO
Envía un mensaje de longitud cero hacia abajo cuando ocurre una llamada a write() de 0 bytes.

El archivo de cabecera <stropts.h> definirá al menos las siguientes constantes simbólicas para su uso con I_ATMARK:

ANYMARK
Comprueba si el mensaje está marcado.
LASTMARK
Comprueba si el mensaje es el último marcado en la cola.

El archivo de cabecera <stropts.h> definirá al menos la siguiente constante simbólica para su uso con I_UNLINK:

MUXID_ALL
Desenlaza todos los STREAM enlazados al STREAM asociado con fildes.

El archivo de cabecera <stropts.h> definirá las siguientes constantes simbólicas para getmsg(), getpmsg(), putmsg() y putpmsg():

MORECTL
Queda más información de control en el mensaje.
MOREDATA
Queda más datos en el mensaje.
MSG_ANY
Recibe cualquier mensaje.
MSG_BAND
Recibe un mensaje de la banda especificada.
MSG_HIPRI
Envía/recibe mensaje de alta prioridad.

El archivo de cabecera <stropts.h> puede hacer que todas las símbolos de <unistd.h> sean visibles.

El archivo de cabecera <stropts.h> también puede definir macros para tipos de mensajes utilizando nombres que comienzan con M_.

Lo siguiente se declarará como funciones y también puede definirse como macros. Se proporcionarán prototipos de función.

int    fattach(int, const char *);
int    fdetach(const char *);
int    getmsg(int, struct strbuf *restrict, struct strbuf *restrict,
           int *restrict);
int    getpmsg(int, struct strbuf *restrict, struct strbuf *restrict,
           int *restrict, int *restrict);
int    ioctl(int, int, ...);
int    isastream(int);
int    putmsg(int, const struct strbuf *, const struct strbuf *, int);
int    putpmsg(int, const struct strbuf *, const struct strbuf *, int,
           int);
