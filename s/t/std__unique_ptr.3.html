This is a conceptual reference page for std::unique_ptr. For full details, see the C++ standard.

unique_ptr is a Smart Pointer that owns and manages another object through the regular pointer interface and disposes of that object when the unique_ptr itself is destroyed.

This elimination happens either by the unique_ptr being destroyed by the user, or by the unique_ptr being reassigned or going out of scope.

unique_ptr enforces strict ownership semantics that a copy of the unique_ptr cannot be made; it can only be transferred.

unique_ptr is an adapter template that requires the following arguments:

template<typename _Tp, typename _Dp =
default_delete<_Tp>
>
class unique_ptr;

Here, _Tp is the type of the object being managed. _Dp is the type of the function or functor used to delete the object when the unique_ptr is destroyed. The default deleter is default_delete<T> which simply calls delete on the managed pointer.

unique_ptr does not support the management of arrays, use unique_ptr<T[]> for that.

The following member types are defined:

element_type: _Tp

deleter_type: _Dp

pointer: pointer.

A number of helper templates are defined to facilitate the creation and management of unique_ptr instances.
