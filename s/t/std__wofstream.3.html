template<typename _CharT, typename _Traits> void std::basic_ios< _CharT, _Traits >::exceptions (iostate __except) [inline], [inherited]

Lanzamiento de excepciones ante errores.

Parámetros

__except La nueva máscara de excepciones.

Por defecto, los flags de error se establecen silenciosamente. Puede establecer una máscara de excepciones para cada stream; si un bit de la máscara se establece en los flags de error, se lanza una excepción de tipo std::ios_base::failure.

Si el flag de error ya está establecido cuando se agrega la máscara de excepciones, la excepción se lanza inmediatamente. Intente ejecutar lo siguiente en GCC 3.1 o posterior:

#include <iostream>
