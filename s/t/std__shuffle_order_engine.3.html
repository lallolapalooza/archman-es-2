Description

The std::shuffle_order_engine is a random number engine adaptor that produces a sequence of pseudo-random numbers by shuffling the output of another underlying random number engine.

It maintains an internal buffer of size __k, which is filled with values generated by the underlying engine. When a random number is requested, the engine picks a random element from the buffer, returns it, and replaces it with a new value generated by the underlying engine.

This ensures a more uniform distribution of random numbers, especially when the underlying engine has a short period or predictable patterns.
