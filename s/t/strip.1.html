STRIP(1) Herramientas de desarrollo de GNU STRIP(1)

NOMBRE

strip - descarta símbolos y otros datos de archivos objeto

SINOPSIS

strip [-F nombre_bfd |--target=nombre_bfd]
[-I nombre_bfd |--input-target=nombre_bfd]
[-O nombre_bfd |--output-target=nombre_bfd]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nombre_simbolo|--keep-symbol=nombre_simbolo]
[-M|--merge-notes][--no-merge-notes]
[-N nombre_simbolo |--strip-symbol=nombre_simbolo]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nombre_seccion |--remove-section=nombre_seccion]
[--keep-section=patron_seccion]
[--remove-relocations=patron_seccion]
[--strip-section-headers]
[-o archivo] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[--plugin nombre]
[-v |--verbose] [-V|--version]
[--help] [--info]
archivo_objeto...

DESCRIPCIÓN

strip de GNU descarta todos los símbolos de los archivos objeto archivo_objeto. La lista de archivos objeto puede incluir archivos. Se debe proporcionar al menos un archivo objeto.

strip modifica los archivos nombrados en sus argumentos, en lugar de escribir copias modificadas con nombres diferentes.

OPCIONES

-F nombre_bfd
--target=nombre_bfd
Trata el archivo_objeto original como un archivo con el formato de código objeto nombre_bfd y lo reescribe en el mismo formato.
--help
Muestra un resumen de las opciones de strip y sale.
--info
Muestra una lista que contiene todas las arquitecturas y formatos de objeto disponibles.
-I nombre_bfd
--input-target=nombre_bfd
Trata el archivo_objeto original como un archivo con el formato de código objeto nombre_bfd.
-O nombre_bfd
--output-target=nombre_bfd
Reemplaza archivo_objeto con un archivo en el formato de salida nombre_bfd.
-R nombre_seccion
--remove-section=nombre_seccion
Elimina cualquier sección llamada nombre_seccion del archivo de salida, además de las secciones que de otro modo se eliminarían. Esta opción se puede dar varias veces. Tenga en cuenta que el uso inapropiado de esta opción puede hacer que el archivo de salida sea inutilizable. El carácter comodín * puede darse al final de nombre_seccion. Si es así, se eliminará cualquier sección que comience con nombre_seccion.

Si el primer carácter de patron_seccion es el signo de exclamación (!) entonces las secciones coincidentes no se eliminarán incluso si un uso anterior de --remove-section en la misma línea de comandos las eliminara de otro modo. Por ejemplo:

--remove-section=.text.* --remove-section=!.text.foo

eliminará todas las secciones que coincidan con el patrón '.text.*', pero no eliminará la sección '.text.foo'.

--keep-section=patron_seccion
Al eliminar secciones del archivo de salida, conserva las secciones que coinciden con patron_seccion.
--remove-relocations=patron_seccion
Elimina las reubicaciones del archivo de salida para cualquier sección que coincida con patron_seccion. Esta opción se puede dar varias veces. Tenga en cuenta que el uso inapropiado de esta opción puede hacer que el archivo de salida sea inutilizable. Se aceptan caracteres comodín en patron_seccion. Por ejemplo: 
--remove-relocations=.text.*

eliminará las reubicaciones de todas las secciones que coincidan con el patrón '.text.*'.

Si el primer carácter de patron_seccion es el signo de exclamación (!) entonces las secciones coincidentes no tendrán sus reubicaciones eliminadas, incluso si un uso anterior de --remove-relocations en la misma línea de comandos causara de otro modo que las reubicaciones fueran eliminadas. Por ejemplo:

--remove-relocations=.text.* --remove-relocations=!.text.foo

eliminará todas las reubicaciones para secciones que coincidan con el patrón '.text.*', pero no eliminará las reubicaciones para la sección '.text.foo'.

--strip-section-headers
Elimina las cabeceras de sección. Esta opción es específica de los archivos ELF. Implica --strip-all y --merge-notes.
-s
--strip-all
Elimina todos los símbolos.
-g
-S
-d
--strip-debug
Elimina solo los símbolos de depuración.
--strip-dwo
Elimina el contenido de todas las secciones DWARF .dwo, dejando las secciones de depuración restantes y todos los símbolos intactos. Vea la descripción de esta opción en la sección de objcopy para más información.
--strip-unneeded
Elimina todos los símbolos que no son necesarios para el procesamiento de reubicaciones, además de los símbolos y secciones de depuración eliminados por --strip-debug.
-K nombre_simbolo
--keep-symbol=nombre_simbolo
Al eliminar símbolos, conserva el símbolo nombre_simbolo incluso si normalmente se eliminaría. Esta opción se puede dar varias veces.
-M
--merge-notes
--no-merge-notes
Para archivos ELF, intenta (o no intenta) reducir el tamaño de las secciones de tipo SHT_NOTE eliminando notas duplicadas. Por defecto se intenta esta reducción a menos que se esté eliminando información de depuración o DWO.
-N nombre_simbolo
--strip-symbol=nombre_simbolo
Elimina el símbolo nombre_simbolo del archivo fuente. Esta opción se puede dar varias veces y se puede combinar con otras opciones de strip, excepto con -K.
-o archivo
Coloca la salida eliminada en archivo, en lugar de reemplazar el archivo existente. Cuando se usa este argumento, solo se puede especificar un argumento archivo_objeto.
-p
--preserve-dates
Conserva las fechas de acceso y modificación del archivo.
-D
--enable-deterministic-archives
Opera en modo determinista. Al copiar miembros de archivo y escribir el índice del archivo, utiliza cero para UID, GID, marcas de tiempo y utiliza modos de archivo consistentes para todos los archivos.

Si binutils fue configurado con --enable-deterministic-archives, entonces este modo está activado por defecto. Se puede deshabilitar con la opción -U, abajo.

strip(1) — Arch Linux man pages

NAME

strip - discard symbols from object files

SYNOPSIS

strip [OPTION...] [‪FILE‬...]

DESCRIPTION

The strip utility removes symbols from object files. It can be used to reduce the size of executable files and object files. It is most commonly used to remove debugging symbols from compiled programs.

If no files are specified, or if a file is specified as -, the standard input is read.

A file that has been stripped can not be stripped again.

OPTIONS

-a
--discard-all
Remove all symbols except for those that are in the relocation entries. This option is equivalent to -x.
-s
--strip-debug
Remove debugging symbols and sections. This is the default action when no other stripping option is given.
-g
--strip-unneeded
Remove all symbols, except those that are needed for relocation processing. This is the default action when no other stripping option is given.
-D
--enable-deterministic-archives
Operate in deterministic mode. This is the inverse of the --disable-deterministic-archives option, below: when copying archive members and writing the archive index, use fixed values for UID, GID, timestamp, and file mode. This ensures that archives are created identically each time, regardless of the file metadata.
-h
--help
Show the help message.
-i
--info
List the symbols that will be stripped.
-k
--keep-symbols
Do not strip symbols that are listed in the argument. The symbols argument is a comma-separated list of symbol names. This option can be used multiple times. Regular expressions can be used in symbol names if the --wildcard option is also specified.
-K
--keep-global-symbols
Do not strip global symbols that are listed in the argument. The symbols argument is a comma-separated list of symbol names. This option can be used multiple times. Regular expressions can be used in symbol names if the --wildcard option is also specified.
-p
--strip-symbol
Do not strip the symbols that are listed in the argument. The symbols argument is a comma-separated list of symbol names. This option can be used multiple times. Regular expressions can be used in symbol names if the --wildcard option is also specified.
-r
--strip-relative-with-plt
Strip symbols that have the relative relocation bit set in the symbol table entry. This option is intended to be used with shared libraries. It effectively strips symbols that are not needed for dynamic linking. This option is intended for use with ELF files only.
-S
--strip-debugging
Remove debugging symbols. This is equivalent to --strip-debug.
-t
--strip-symbols
Remove all symbols that are listed in the argument. The symbols argument is a comma-separated list of symbol names. This option can be used multiple times. Regular expressions can be used in symbol names if the --wildcard option is also specified.
-U
--disable-deterministic-archives
Do not operate in deterministic mode. This is the inverse of the -D option, above: when copying archive members and writing the archive index, use their actual UID, GID, timestamp, and file mode values.

This is the default unless binutils was configured with --enable-deterministic-archives.

-w
--wildcard
Permit regular expressions in symbolnames used in other command line options. The question mark (?), asterisk (*), backslash (\) and square brackets ([]) operators can be used anywhere in the symbol name. If the first character of the symbol name is the exclamation point (!) then the sense of the switch is reversed for that symbol. For example: 
-w -K !foo -K fo*

would cause strip to only keep symbols that start with the letters "fo", but to discard the symbol "foo".

-x
--discard-all
Remove non-global symbols.
-X
--discard-locals
Remove compiler-generated local symbols. (These usually start with L or ..)
--keep-section-symbols
When stripping a file, perhaps with --strip-debug or --strip-unneeded, retain any symbols specifying section names, which would otherwise get stripped.
--keep-file-symbols
When stripping a file, perhaps with --strip-debug or --strip-unneeded, retain any symbols specifying source file names, which would otherwise get stripped.
--only-keep-debug
Strip a file, emptying the contents of any sections that would not be stripped by --strip-debug and leaving the debugging sections intact. In ELF files, this preserves all the note sections in the output as well.

Note - the section headers of the stripped sections are preserved, including their sizes, but the contents of the section are discarded. The section headers are preserved so that other tools can match up the debuginfo file with the real executable, even if that executable has been relocated to a different address space.

The intention is that this option will be used in conjunction with --add-gnu-debuglink to create a two part executable. One a stripped binary which will occupy less space in RAM and in a distribution and the second a debugging information file which is only needed if debugging abilities are required. The suggested procedure to create these files is as follows:

1.<Link the executable as normal. Assuming that it is called>
"foo" then...
1.<Run "objcopy --only-keep-debug foo foo.dbg" to>
create a file containing the debugging info.
1.<Run "objcopy --strip-debug foo" to create a>
stripped executable.
1.<Run "objcopy --add-gnu-debuglink=foo.dbg foo">
to add a link to the debugging info into the stripped executable.

Note---the choice of ".dbg" as an extension for the debug info file is arbitrary. Also the "--only-keep-debug" step is optional. You could instead do this:

1.<Link the executable as normal.>
1.<Copy "foo" to "foo.full">
1.<Run "strip --strip-debug foo">
1.<Run "objcopy --add-gnu-debuglink=foo.full foo">

i.e., the file pointed to by the --add-gnu-debuglink can be the full executable. It does not have to be a file created by the --only-keep-debug switch.

Note---this switch is only intended for use on fully linked files. It does not make sense to use it on object files where the debugging information may be incomplete. Besides the gnu_debuglink feature currently only supports the presence of one filename containing debugging information, not multiple filenames on a one-per-object-file basis.

--plugin name
Load the plugin called name to add support for extra target types. This option is only available if the toolchain has been built with plugin support enabled.

If --plugin is not provided, but plugin support has been enabled then strip iterates over the files in ${libdir}/bfd-plugins in alphabetic order and the first plugin that claims the object in question is used.

Please note that this plugin search directory is not the one used by ld's -plugin option. In order to make strip use the linker plugin it must be copied into the ${libdir}/bfd-plugins directory. For GCC based compilations the linker plugin is called liblto_plugin.so.0.0.0. For Clang based compilations it is called LLVMgold.so. The GCC plugin is always backwards compatible with earlier versions, so it is sufficient to just copy the newest one.

-V
--version
Show the version number for strip.
-v
--verbose
Verbose output: list all object files modified. In the case of archives, strip -v lists all members of the archive.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
