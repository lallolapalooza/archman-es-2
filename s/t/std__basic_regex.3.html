Descripción Detallada

template<typename _Ch_type, typename _Rx_traits = regex_traits<_Ch_type>>

class std::basic_regex< _Ch_type, _Rx_traits >"Una expresión regular.

Las especializaciones de esta plantilla de clase representan expresiones regulares construidas a partir de secuencias de tipo de carácter _Ch_type. Utilice el typedef std::regex para std::basic_regex<char>.

Una secuencia de caracteres pasada al constructor se analizará según la gramática elegida y se utilizará para crear una máquina de estados que represente la expresión regular. El objeto regex puede luego pasarse a algoritmos como std::regex_match para hacer coincidir secuencias de caracteres.

La bandera syntax_option_type pasada al constructor selecciona una de las gramáticas de expresiones regulares admitidas. El valor predeterminado es ECMAScript y las otras son basic, extended, awk, grep y egrep, que son variaciones de las expresiones regulares POSIX.

Since

C++11

Detailed Description

Represents a regular expression.

This class template defines a regular expression object. It stores a regular expression pattern and can be used to match sequences of characters against the pattern.

The template parameters are:

_Ch_type
The character type of the regular expression. This is typically `char` for regular expressions using the default `regex_traits`.
_Rx_traits
The traits class that defines character properties and conversions. The default is `std::regex_traits<_Ch_type>`.
