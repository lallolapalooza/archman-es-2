STRNCPY(3P) Manual de Programador POSIX STRNCPY(3P)

PROLOG

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

stpncpy, strncpy — copia una cadena de longitud fija, devolviendo un puntero al final del array

SINOPSIS

#include <string.h>
char *stpncpy(char *restrict s1, const char *restrict s2, size_t n);
char *strncpy(char *restrict s1, const char *restrict s2, size_t n);

DESCRIPCIÓN

Para strncpy(): la funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C no es intencional. Este volumen de POSIX.1-2017 remite al estándar ISO C.

Las funciones stpncpy() y strncpy() copiarán no más de n bytes (los bytes que siguen a un carácter NUL no se copian) desde el array apuntado por s2 al array apuntado por s1.

Si el array apuntado por s2 es una cadena más corta que n bytes, se añadirán caracteres NUL a la copia en el array apuntado por s1, hasta que se escriban n bytes en total.

Si la copia se realiza entre objetos que se solapan, el comportamiento es indefinido.

VALOR DE RETORNO

Si se escribe un carácter NUL en el destino, la función stpncpy() devolverá la dirección del primer carácter NUL de este tipo. De lo contrario, devolverá &s1[n].

La función strncpy() devolverá s1.

No se reservan valores de retorno para indicar un error.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO POR LA APLICACIÓN

Las aplicaciones deben proporcionar el espacio en s1 para los n bytes a transferir, así como asegurarse de que los arrays s2 y s1 no se solapen.

El movimiento de caracteres se realiza de forma diferente en distintas implementaciones. Por lo tanto, los movimientos solapados pueden dar lugar a sorpresas.

Si no hay un byte de carácter NUL en los primeros n bytes del array apuntado por s2, el resultado no estará terminado en NUL.
