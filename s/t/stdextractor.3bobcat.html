NOMBRE

FBB::StdExtractor - Ejecuta programas externos que escriben a la salida estándar de error

SINOPSIS

#include <bobcat/cerrextractor>
Opción de enlace: -lbobcat

DESCRIPCIÓN

La clase FBB::StdExtractor ofrece una interfaz básica para llamar a programas externos (llamados procesos hijo) que escriben a sus flujos de salida estándar y de error. El flujo de entrada estándar de los procesos hijo no es manejado por defecto por los objetos StdExtractor. Los flujos de salida estándar y de error estándar del hijo se leen a través del objeto StdExtractor: la información escrita por el proceso hijo a estos flujos se extrae o se lee desde el objeto StdExtractor. La variable de entorno PATH no se usa al llamar a procesos hijo: los programas de procesos hijo deben especificarse usando rutas.

Los objetos StdExtractor pueden usarse repetidamente para ejecutar los mismos o diferentes procesos hijo.

Los argumentos pasados a los procesos hijo pueden estar rodeados por comillas dobles o simples. Los argumentos rodeados por comillas dobles tienen sus comillas dobles eliminadas, mientras que se interpretan las secuencias de escape que puedan haberse utilizado dentro. Los argumentos rodeados por comillas simples tienen sus comillas simples eliminadas, mientras que su contenido se acepta tal cual. Además, se pueden especificar secuencias de escape sin comillas: esas secuencias de escape se evalúan y se reemplazan por sus caracteres previstos (por ejemplo, \100 se convierte en @).

ESPACIO DE NOMBRES

FBB

HEREDA DE

FBB::Exec (privado), FBB::IFdBuf (privado), std::istream

CONSTRUCTOR

o
StdExtractor(size_t bufSize = 100):
Se puede especificar un argumento bufSize: define el tamaño del búfer interno utilizado por el streambuf del StdExtractor. Por defecto, el flujo de entrada estándar no es manejado.
o
CoutExtractor(Mode mode, size_t bufSize = 100):
El argumento mode debe ser StdExtractor::CLOSE_STD. Indica que el flujo de entrada estándar se redirige a /dev/null: los procesos hijo no pueden leer sus flujos de entrada estándar. Se puede especificar un argumento bufSize: define el tamaño del búfer interno utilizado por el streambuf de CinInserter.

Los constructores y operadores de copia y movimiento no están disponibles.

MIEMBROS

o
void execute(std::string const &cmd):
El argumento especifica el comando a ejecutar: el comando en sí debe especificarse como una ruta (la variable de entorno PATH no se usa). Este miembro retorna inmediatamente, después de lo cual la información escrita por el proceso hijo a sus flujos de salida estándar y de error puede extraerse del objeto StdExtractor.
Una vez que execute ha retornado, puede ser llamado de nuevo, ya sea usando el mismo comando u otro.
Los argumentos pasados al programa a ejecutar como proceso hijo pueden especificarse opcionalmente usando comillas simples o dobles, como se describe en la sección DESCRIPCIÓN de esta página del manual.
o
int ret() const:
Una vez que execute ha retornado, este miembro proporciona el código de salida real del proceso hijo. Su valor es -1 antes de la primera llamada a execute.

MIEMBRO PROTEGIDO

o
Pipe &childOutPipe():
Si las clases derivadas necesitan anular los miembros de redirección, probablemente necesitarán acceso a la tubería escrita por el proceso hijo. Este miembro proporciona una referencia a esa tubería. Por defecto, el proceso padre lee información de la tubería, mientras que el proceso hijo inserta su salida de error estándar en la tubería.

EJEMPLO

#include <iostream>
#include <bobcat/cerrextractor>
using namespace std;
using namespace FBB;
int main()
{
    CerrExtractor extractor;
    extractor.execute("/bin/cat driver.cc");
    cout << extractor.rdbuf();
    cerr << "Retornando: " << extractor.ret() << "\n"
            "otra vez:\n";
    extractor.execute("/bin/cat driver.cc");
    cout << extractor.rdbuf();
    cerr << "Retornando: " << extractor.ret() << ’\n’;
}
