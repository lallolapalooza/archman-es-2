NOMBRE

stappaths - rutas de archivos configurables de systemtap

DESCRIPCIÓN

Esta página del manual fue generada para systemtap 5.4. La siguiente sección enumerará las rutas principales en systemtap que son importantes de conocer y que pueden requerir referencia.

/usr/share/systemtap/tapset/
El directorio para la biblioteca estándar de tapset de alias de sonda / función, a menos que sea anulado por la variable de entorno SYSTEMTAP_TAPSET o la variable de entorno XDG_DATA_DIRS. Estos se describen en las páginas del manual stapprobes(3stap), probe::*(3stap) y function::*(3stap).
/usr/share/systemtap/runtime/
Las fuentes de tiempo de ejecución, a menos que sea anulado por la variable de entorno SYSTEMTAP_RUNTIME.
/usr/bin/staprun
El programa auxiliar que supervisa la carga, interacción y descarga de módulos.
/etc/stap-exporter
El directorio predeterminado para buscar archivos *.stp, para exportar a HTTP.
/usr/lib/systemtap/systemtap/stapio
El programa auxiliar para el manejo de entrada y salida de módulos.
/usr/include/sys/sdt.h
Ubicación de las cabeceras <sys/sdt.h>.
Ruta de debuginfo del Kernel: /usr/lib/debug/lib/modules/$(uname -r)/
La ubicación de la información de depuración del kernel cuando se empaqueta en el RPM kernel-debuginfo, a menos que sea anulado por la variable de entorno SYSTEMTAP_DEBUGINFO_PATH. El valor predeterminado para esta variable es +:.debug:/usr/lib/debug:build. elfutils busca vmlinux en esta ruta e interpreta la ruta como un directorio base desde el cual se buscarán varios subdirectorios para encontrar debuginfo para el kernel, módulos del kernel y binarios del espacio de usuario. Por defecto, systemtap también buscará vmlinux en las siguientes ubicaciones: 
/boot/vmlinux-`uname -r` 
/lib/modules/`uname -r`/vmlinux
/lib/modules/`uname -r`/vmlinux.debug
/lib/modules/`uname -r`/build/vmlinux
/lib/modules/`uname -r`/.debug/vmlinux.debug
/usr/lib/debug/lib/modules/`uname -r`/vmlinux.debug
/var/cache/abrt-di/usr/debug/lib/modules/`uname -r`/
/var/cache/abrt-di/usr/lib/debug/lib/modules/`uname -r`/vmlinux.debug

Los archivos fuente correspondientes generalmente se encuentran en /usr/src/debug/. Información adicional de archivos sobre aplicaciones del espacio de usuario se puede determinar por base usando rpm -ql <paquete>-debuginfo. Para información de aplicaciones del espacio de usuario compatibles, visite la wiki de systemtap.

Con elfutils versión >0.178, systemtap puede descargar automáticamente información de depuración de servidores debuginfod. Puede intentarlo estableciendo una o dos variables de entorno: 

export DEBUGINFOD_URLS=https://debuginfod.elfutils.org/
export DEBUGINFOD_PROGRESS=1
$HOME/.systemtap
Directorio de datos de Systemtap para archivos de systemtap cacheados, a menos que sea anulado por la variable de entorno SYSTEMTAP_DIR.
/tmp/stapXXXXXX
Directorio temporal para archivos de systemtap, incluyendo código C traducido y objeto del kernel.
/lib/modules/VERSION/build
La ubicación de la infraestructura de construcción de módulos del kernel.
/usr/share/doc/systemtap*/examples
Ejemplos con mayor detalle se pueden encontrar aquí. Cada ejemplo viene con un archivo .txt o .meta que explica qué hace el ejemplo, muestra o demostración y cómo se ejecuta normalmente. Ver también en línea en: https://sourceware.org/systemtap/examples/
$SYSTEMTAP_DIR/ssl/server
Base de datos de certificados SSL del lado del servidor del usuario. Si SYSTEMTAP_DIR no está configurado, el valor predeterminado es $HOME/.systemtap.
$SYSTEMTAP_DIR/ssl/client
Base de datos de certificados SSL privados del lado del cliente del usuario. Si SYSTEMTAP_DIR no está configurado, el valor predeterminado es $HOME/.systemtap.
/etc/systemtap/ssl/client
Base de datos global de certificados SSL del lado del cliente.
/etc/systemtap/staprun/
Base de datos de certificados de firmantes de confianza de staprun.
/etc/sysconfig/stap-server
Archivo de configuración global del servicio stap-server.
/etc/sysconfig/stap-exporter
Archivo de configuración global del servicio stap-exporter.
/var/run/stap-server/
Ubicación predeterminada de los archivos de estado para servidores en ejecución del servicio stap-server.
/var/log/stap-server/log
Archivo de registro predeterminado del servicio stap-server.
