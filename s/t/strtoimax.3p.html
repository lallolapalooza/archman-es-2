STRTOIMAX(3P) Manual de Programador de POSIX STRTOIMAX(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

strtoimax, strtoumax — convertir cadena a tipo entero

SINOPSIS

#include <inttypes.h>
intmax_t strtoimax(const char *restrict nptr, char **restrict endptr,
    int base);
uintmax_t strtoumax(const char *restrict nptr, char **restrict endptr,
    int base);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia se alinea con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

Estas funciones serán equivalentes a las funciones strtol(), strtoll(), strtoul() y strtoull(), excepto que la porción inicial de la cadena se convertirá a la representación intmax_t y uintmax_t, respectivamente.

VALOR DE RETORNO

Estas funciones devolverán el valor convertido, si lo hay.

Si no se pudo realizar ninguna conversión, se devolverá cero y errno puede establecerse en [EINVAL].

Si el valor de base no es compatible, se devolverá 0 y errno se establecerá en [EINVAL].

Si el valor correcto está fuera del rango de valores representables, se devolverá {INTMAX_MAX}, {INTMAX_MIN} o {UINTMAX_MAX} (según el tipo de retorno y el signo del valor, si lo hay), y errno se establecerá en [ERANGE].

ERRORES

Estas funciones fallarán si:

EINVAL
El valor de base no es compatible.
ERANGE
El valor a devolver no es representable.

Estas funciones pueden fallar si:

EINVAL
No se pudo realizar ninguna conversión.

USO DE LA APLICACIÓN

Dado que el valor de *endptr no está especificado si el valor de base no es compatible, las aplicaciones deben asegurarse de que base tenga un valor compatible (0 o entre 2 y 36) antes de la llamada, o verificar si hay un error [EINVAL] antes de examinar *endptr.
