Documentación de la función/subrutina

subrutina strsv (character uplo, character trans, character diag, integer n, real, dimension(lda,*) a, integer lda, real, dimension(*) x, integer incx)

STRSV

Propósito:

!>
!> STRSV resuelve uno de los sistemas de ecuaciones
!>
!>    A*x = b,   o   A**T*x = b,
!>
!> donde b y x son vectores de n elementos y A es una matriz n por n unitaria, o
!> no unitaria, superior o inferior triangular.
!>
!> Esta rutina no incluye pruebas de singularidad o casi singularidad.
!> Dichas pruebas deben realizarse antes de llamar a esta rutina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           A la entrada, UPLO especifica si la matriz es una matriz superior o
!>           inferior triangular de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           A la entrada, TRANS especifica las ecuaciones a resolver de la
!>           siguiente manera:
!>
!>              TRANS = 'N' o 'n'   A*x = b.
!>
!>              TRANS = 'T' o 't'   A**T*x = b.
!>
!>              TRANS = 'C' o 'c'   A**T*x = b.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           A la entrada, DIAG especifica si A es unitaria o no
!>           triangular de la siguiente manera:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es triangular unitaria.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es triangular
!>                                  unitaria.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el orden de la matriz A.
!>           N debe ser mayor o igual a cero.
!>

A

!>          A es un array REAL, dimension ( LDA, N )
!>           Antes de la entrada con  UPLO = 'U' o 'u', la parte superior
!>           triangular principal de n por n del array A debe contener la matriz
!>           triangular superior y la parte estrictamente inferior triangular de
!>           A no se referencia.
!>           Antes de la entrada con UPLO = 'L' o 'l', la parte inferior
!>           triangular principal de n por n del array A debe contener la matriz
!>           triangular inferior y la parte estrictamente superior triangular de
!>           A no se referencia.
!>           Nótese que cuando  DIAG = 'U' o 'u', los elementos diagonales de
!>           A tampoco se referencian, pero se asumen como unidad.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal como se declara
!>           en el programa llamador (subrutina). LDA debe ser al menos
!>           max( 1, n ).
!>

X

!>          X es un array REAL, dimensionado al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el vector
!>           del lado derecho b de n elementos. A la salida, X se sobrescribe
!>           con el vector solución x.
!>

INCX

!>          INCX es INTEGER
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>
