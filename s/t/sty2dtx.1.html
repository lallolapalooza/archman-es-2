DESCRIPCIÓN

Convierte un archivo .sty (paquete LaTeX) a formato .dtx (código fuente documentado de LaTeX), rodeando las definiciones de macros con los entornos 'macro' y 'macrocode'. El nombre de la macro se inserta automáticamente como argumento del entorno 'macro'. Las líneas de código fuera de las definiciones de macros se envuelven solo en entornos 'macrocode'. Se eliminan las líneas en blanco. El script no está pensado para ser infalible y 100% preciso, sino como un buen punto de partida para convertir archivos de estilo no documentados a archivos .dtx.

Uso básico

perl sty2dtx.pl infile [infile ...] outfile

o

perl sty2dtx.pl < file.sty > file.dtx

Definiciones soportadas

Las siguientes definiciones de macros se detectan cuando están al principio de una línea (pueden ir precedidas por \global, \long, \protected y/o \outer):

\def   \edef   \gdef   \xdef
\newcommand{\name}     \newcommand*{\name}
\newcommand\name       \newcommand*\name
\renewcommand{\name}   \renewcommand*{\name}
\renewcommand\name     \renewcommand*\name
\providecommand{\name} \providecommand*{\name}
\providecommand\name   \providecommand*\name
\@namedef{\name}       \@namedef\name

Las siguientes definiciones de entornos se detectan cuando están al principio de una línea:

\newenvironment{name}  \renewenvironemnt{name}  \provideenvironment{name}

La definición de macro o entorno debe terminar en la misma línea o con un '"}"' por sí solo en una línea.

USO

sty2dtx [<opciones>] [--<VAR>=<VALOR> ...] [--] [<infile(s)>] [<outfile>]

Archivos

  • puede ser '"-"' para STDIN o STDOUT, que es el valor predeterminado si no se proporcionan archivos
  • múltiples archivos de entrada se fusionan en un solo archivo de salida

Variables

Las variables se pueden definir usando

--<VAR>=<VALOR>

o

--<VAR> <VALOR>

y se utilizarán para sustituciones en el archivo de plantilla.

Variables comunes:

author, email, maintainer, year (para copyright),
version, date, description (del paquete/clase),
type (ya sea 'package' por defecto o 'class'),
filebase (se establece automáticamente a partir del nombre del archivo de salida o entrada),

Opciones

-h           Imprime este texto de ayuda
-H           Imprime ayuda extendida
-V           Imprime versión y copyright
-v           Sé verboso
-o salida    Usa el archivo dado como salida
-O           Sobrescribe los archivos de salida ya existentes
-B           Usa el nombre base del archivo de entrada único para el archivo de salida
-I           Crea también el archivo .ins (instalación)
-c           Usa solo la sección de código (como v1.0)
-r           Elimina los entornos existentes de 'macro', 'macrocode', etc.
-R           No elimina los entornos existentes de 'macro', 'macrocode', etc.
-i archivo-ins  Crea el archivo .ins con el nombre dado
-t plantilla  Usa este archivo como plantilla en lugar del predeterminado
-T plantilla  Usa este archivo como plantilla para el archivo .ins
-e archivo      Exporta la plantilla .dtx predeterminada al archivo y sale
-E archivo      Exporta la plantilla .ins predeterminada al archivo y sale
-D           Usa la fecha actual como fecha del archivo
-F archivo      Lee más opciones y variables del archivo.
-N           No lee el archivo de configuración predeterminado; debe ser la primera opción

Archivos de configuración

Se busca un archivo de configuración predeterminado llamado 'sty2dtx.cfg' o '.sty2dtx.cfg' en el directorio actual, el directorio personal del usuario y el directorio de este script, en ese orden. Se carga el primero que se encuentra. Si no se encuentra ninguno, se busca en el árbol 'texmf' un archivo de configuración 'sty2dtx.cfg'. Al igual que con los archivos -F, el archivo de configuración debe contener una opción o variable por línea. Se ignoran las líneas que comienzan con '"%"' o '"#"'.

Ejemplos

Producir 'file.dtx' a partir de 'file.sty':

sty2dtx.pl < file.sty > file.dtx

o

sty2dtx.pl file.sty file.dtx

o

sty2dtx.pl -B file.sty

Producir 'file.dtx' y 'file.ins' a partir de 'file.sty':

sty2dtx.pl -I file.sty file.dtx

o

sty2dtx.pl file.sty -i file.sty file.dtx

o

sty2dtx.pl -IB file.sty

Establecer valores de variable personalizados:

sty2dtx.pl --author Me --email me@there.com mypkg.sty my

DESCRIPTION

sty2dtx converts a LaTeX style file (.sty) into a TEX Document Preparation eXchange (DTX) file. It wraps the content of the style file in a texcode environment and adds appropriate documentation comments and header information.

The DTX format is commonly used for distributing LaTeX packages, allowing the source code and documentation to be compiled from a single file.

USAGE

The basic syntax for using sty2dtx is:

sty2dtx [options] input.sty output.dtx

Where:

  • input.sty is the path to the LaTeX style file to be converted.
  • output.dtx is the path where the generated DTX file will be saved.

Available options include:

-h, --help
Display a help message and exit.
-v, --version
Display version information and exit.
-t TYPE, --type TYPE
Specifies the type of the input file. Supported types are:
class
The input file is a LaTeX class file (e.g., .cls).
package
The input file is a LaTeX package file (e.g., .sty). This is the default.
-c, --compact
Produce a more compact DTX file by omitting some redundant comments.

Examples

Convert a package file:

sty2dtx mypackage.sty mypackage.dtx

Convert a class file:

sty2dtx --type class myclass.cls myclass.dtx

Produce a compact DTX file for a package:

sty2dtx --compact mypackage.sty mypackage.dtx

Convert a style file named `pkg.sty` to `pkg.dtx`:

sty2dtx pkg.sty pkg.dtx

Produce DTX file for a class:

sty2dtx --type class mycls.sty mycls.dtx
