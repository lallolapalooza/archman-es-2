std::aligned_storage< _Len, _Align > - Almacenamiento alineado.

SINOPSIS

#include <type_traits>

Descripción Detallada

template<size_t _Len, size_t _Align = __aligned_storage_default_alignment(_Len)>

struct std::aligned_storage< _Len, _Align >"Almacenamiento alineado.

El typedef miembro type es un tipo POD adecuado para su uso como almacenamiento no inicializado para cualquier objeto cuyo tamaño sea como máximo _Len y cuya alineación sea un divisor de _Align.

Es importante usar el tipo anidado como almacenamiento no inicializado, no el tipo std::aligned_storage en sí, que es una clase vacía con alineación de 1 byte. Por lo tanto, esto es correcto:

typename std::aligned_storage<sizeof(X), alignof(X)>::type m_xobj;

Esto es incorrecto:

std::aligned_storage<sizeof(X), alignof(X)> m_xobj;

En C++14 y posteriores, se puede usar std::aligned_storage_t<sizeof(X), alignof(X)> para referirse al typedef miembro type.

El valor predeterminado de _Align debe ser el requisito de alineación fundamental más estricto para cualquier tipo de objeto C++ cuyo tamaño no sea mayor que _Len (ver [basic.align] en el estándar C++).

Obsoleto

Obsoleto en C++23. Los usos se pueden reemplazar por un arreglo std::byte[_Len] declarado con alignas(_Align).
