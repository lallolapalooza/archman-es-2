Documentación de función/subrutina

subroutine strsm (character side, character uplo, character transa, character diag, integer m, integer n, real alpha, real, dimension(lda,*) a, integer lda, real, dimension(ldb,*) b, integer ldb)

STRSM

Propósito:

!>
!> STRSM  resuelve una de las ecuaciones matriciales
!>
!>    op( A )*X = alpha*B,   o   X*op( A ) = alpha*B,
!>
!> donde alpha es un escalar, X y B son matrices de m por n, A es una matriz
!> triangular unitaria o no unitaria, superior o inferior, y op( A )  es una de
!>
!>    op( A ) = A   o   op( A ) = A**T.
!>
!> La matriz X se sobrescribe en B.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>           En la entrada, SIDE especifica si op( A ) aparece a la izquierda
!>           o a la derecha de X como sigue:
!>
!>              SIDE = 'L' o 'l'   op( A )*X = alpha*B.
!>
!>              SIDE = 'R' o 'r'   X*op( A ) = alpha*B.
!>

UPLO

!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si la matriz A es superior o
!>           inferior triangular como sigue:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANSA

!>          TRANSA es CHARACTER*1
!>           En la entrada, TRANSA especifica la forma de op( A ) a usar en
!>           la multiplicación de matrices como sigue:
!>
!>              TRANSA = 'N' o 'n'   op( A ) = A.
!>
!>              TRANSA = 'T' o 't'   op( A ) = A**T.
!>
!>              TRANSA = 'C' o 'c'   op( A ) = A**T.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           En la entrada, DIAG especifica si A es unitaria triangular o no
!>           como sigue:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es unitaria triangular.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitaria
!>                                  triangular.
!>

M

!>          M es INTEGER
!>           En la entrada, M especifica el número de filas de B. M debe ser
!>           al menos cero.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el número de columnas de B.  N debe ser
!>           al menos cero.
!>

ALPHA

!>          ALPHA es REAL
!>           En la entrada,  ALPHA especifica el escalar  alpha.  Cuando  alpha es
!>           cero,  A no se referencia y  B no necesita ser establecido antes
!>           de la entrada.
!>

A

!>          A es array REAL, dimension ( LDA, k ),
!>           donde k es m cuando SIDE = 'L' o 'l'
!>             y k es n cuando SIDE = 'R' o 'r'.
!>           Antes de la entrada con  UPLO = 'U' o 'u',  la  parte  triangular
!>           superior  de k por k  de  la  array A  debe  contener la matriz
!>           triangular superior  y la parte estrictamente triangular inferior
!>           de A no se referencia.
!>           Antes de la entrada con  UPLO = 'L' o 'l',  la  parte  triangular
!>           inferior  de k por k  de  la  array A  debe  contener la matriz
!>           triangular inferior  y la parte estrictamente triangular superior
!>           de A no se referencia.
!>           Nótese que cuando  DIAG = 'U' o 'u',  los elementos diagonales de
!>           A  tampoco se referencian,  sino que se asumen como  unidad.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal como
!>           se declaró en el programa (sub)llamador.  Cuando  SIDE = 'L' o 'l',
!>           entonces  LDA  debe ser al menos  max( 1, m ), cuando SIDE = 'R' o 'r'
!>           entonces LDA debe ser al menos max( 1, n ).
!>

B

!>          B es array REAL, dimension ( LDB, N )
!>           Antes de la entrada,  la parte  principal  de m por n  de  la
!>           array B  debe  contener  la  matriz  del lado derecho  B, y
!>           a la salida contiene la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>           En la entrada, LDB especifica la primera dimensión de B tal como
!>           se declaró en el programa (sub)llamador.  LDB  debe ser al menos
!>           max( 1, m ).
!>
