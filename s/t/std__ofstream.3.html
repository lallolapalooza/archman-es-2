Inserciones
Todas las funciones operator<< (también conocidas como *funciones de salida formateada*) tienen un comportamiento común. Cada una comienza construyendo un objeto temporal de tipo std::basic_ostream::sentry. Esto puede tener varios efectos, concluyendo con el establecimiento de una bandera de estado; véase la documentación de sentry para más información.

Si el estado de sentry es bueno, la función intenta generar los datos apropiados para el tipo del argumento.

Si se lanza una excepción durante la inserción, ios_base::badbit se activará en el estado de error del flujo sin causar el lanzamiento de una ios_base::failure. La excepción original será relanzada.

Unformatted Output Functions

All the unformatted output functions have some common behavior. Each starts by constructing a temporary object of type std::basic_ostream::sentry. This has several effects, concluding with the setting of a status flag; see the sentry documentation for more.

If the sentry status is good, the function tries to generate whatever data is appropriate for the type of the argument.

If an exception is thrown during insertion, ios_base::badbit will be turned on in the stream's error state. If badbit is on in the stream's exceptions mask, the exception will be rethrown without completing its actions.

Detailed Description

Class template documentation

El comportamiento de las operaciones de entrada/salida de C++ se define por un conjunto de clases que trabajan juntas. La clase std::basic_ios es la clase base para las clases std::basic_istream y std::basic_ostream. Contiene el estado del flujo y los métodos de manipulación de formato. Como std::ios_base, no se puede instanciar directamente; se deriva de std::ios_base y se utiliza como clase base para clases de flujo más específicas como std::fstream y std::stringstream.

La clase std::basic_ios maneja las operaciones de formato y estado del flujo, como el conjunto de indicadores de formato, el ancho de campo, el carácter de relleno y el estado del flujo (bueno, eof, fail, bad). También proporciona métodos para gestionar el búfer de flujo asociado.

Se pueden pasar manipuladores de flujo y manipuladores de flujo de biblioteca (por ejemplo, std::endl, std::setw) a los flujos para modificar su comportamiento. Estos manipuladores son funciones que toman un objeto de flujo como argumento y devuelven el mismo objeto de flujo, permitiendo su encadenamiento.
