strdup(3) Manual de funciones de biblioteca strdup(3)

NOMBRE

strdup, strndup, strdupa, strndupa - duplicar una cadena

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <string.h>
char *strdup(const char *s);
char *strndup(size_t n;
              const char s[n], size_t n);
char *strdupa(const char *s);
char *strndupa(size_t n;
              const char s[n], size_t n);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

strdup():

    _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.12: */ _POSIX_C_SOURCE >= 200809L
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

strndup():

    Desde glibc 2.10:
        _POSIX_C_SOURCE >= 200809L
    Antes de glibc 2.10:
        _GNU_SOURCE

strdupa(), strndupa():

    _GNU_SOURCE

DESCRIPCIÓN

La función strdup() devuelve un puntero a una nueva cadena que es una duplicación de la cadena s. La memoria para la nueva cadena se obtiene con malloc(3), y puede liberarse con free(3).

La función strndup() es similar, pero copia como máximo n bytes. Si s es más larga que n, solo se copian n bytes y se añade un byte nulo terminador ('\0').

strdupa() y strndupa() son similares, pero usan alloca(3) para asignar el búfer.

VALOR DE RETORNO

En caso de éxito, la función strdup() devuelve un puntero a la cadena duplicada. Devuelve NULL si no había suficiente memoria disponible, con errno establecido para indicar el error.

ERRORES

ENOMEM
Memoria insuficiente disponible para asignar la cadena duplicada.
