template<typename _CharT> string std::numpunct< _CharT >::grouping () const [inline], [heredado]

Devuelve la especificación de agrupación. Esta función devuelve una cadena que representa las agrupaciones para la parte entera de un número. Las agrupaciones indican dónde deben insertarse los separadores de miles en la parte entera de un número.

Cada `char` en la cadena devuelta se interpreta como un entero en lugar de un carácter. Estos números representan la cantidad de dígitos en un grupo. El primer `char` en la cadena representa la cantidad de dígitos en el grupo menos significativo. Si un `char` es negativo, indica un número ilimitado de dígitos para el grupo. Si se requieren más `char`s de la cadena para agrupar un número, se usa el último `char` repetidamente.
