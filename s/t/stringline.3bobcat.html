FBB::StringLine(3bobcat) Extractor de líneas FBB::StringLine(3bobcat)

NOMBRE

FBB::StringLine - extracción de líneas usando operator>>

SINOPSIS

#include <bobcat/stringline>

DESCRIPCIÓN

El operador de extracción de cadenas estándar operator>>(std::istream &, std::string &) extrae la primera "palabra" de un flujo. En casos donde la intención es extraer líneas del flujo, este operador no se puede usar, pero getline(std::istream &, std::string &) se llama habitualmente.

Sin embargo, getline no es llamado por muchas herramientas de algoritmos genéricos, como el istream_iterator.

La clase (en realidad, la estructura) StringLine se deriva simplemente de std::string y define su propio operator>>, leyendo la siguiente línea del std::istream especificado.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::string

CONSTRUCTORES

StringLine es una cáscara vacía alrededor de std::string. No define constructores explícitamente.

Están disponibles constructores y operadores de asignación de copia y movimiento.

OPERADOR SOBRECARGADO

o
std::istream &operator>>(std::istream &in, StringLine &str):
El operador de extracción devuelve la siguiente línea en in a str, llamando a getline(std::istream &, std::string &).

FUNCIONES MIEMBRO

Todos los miembros de std::string están disponibles, ya que FBB::StringLine hereda de estas clases.

EJEMPLO

El siguiente ejemplo extrae todas las líneas de std::cin y las añade al std::vector<std::string> lines:

#include <iostream>
#include <algorithm>
#include <iterator>
#include <vector>
#include <bobcat/stringline>
using namespace std;
using namespace FBB;
int main()
{
    vector<string> lines;
    copy(
        istream_iterator<StringLine>(cin), istream_iterator<StringLine>(),
        back_inserter(lines)
    );
}

ARCHIVOS

bobcat/stringline - define la interfaz de la clase y operator>>.

Hay archivos de objeto StringLine en la biblioteca Bobcat, por lo que no es necesario enlazar a Bobcat al usar StringLine.
