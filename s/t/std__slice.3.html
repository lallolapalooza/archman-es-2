Descripción detallada

Clase que define un subconjunto unidimensional de un array.

La clase slice representa un subconjunto unidimensional de un array, especificado por tres parámetros: el desplazamiento inicial, el tamaño y el paso. El desplazamiento inicial es el índice del primer elemento del array que forma parte del subconjunto. El tamaño es el número total de elementos en el subconjunto. El paso es la distancia entre cada elemento sucesivo del array que se incluirá en el subconjunto.

Por ejemplo, con un array de tamaño 10 y un slice con desplazamiento 1, tamaño 3 y paso 2, el subconjunto consta de los elementos del array 1, 3 y 5.
