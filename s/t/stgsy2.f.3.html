Documentación de la función/subrutina

subrutina stgsy2 (carácter trans, entero ijob, entero m, entero n, real, dimensión( lda, * ) a, entero lda, real, dimensión( ldb, * ) b, entero ldb, real, dimensión( ldc, * ) c, entero ldc, real, dimensión( ldd, * ) d, entero ldd, real, dimensión( lde, * ) e, entero lde, real, dimensión( ldf, * ) f, entero ldf, real scale, real rdsum, real rdscal, entero, dimensión( * ) iwork, entero pq, entero info)

STGSY2 resuelve la ecuación de Sylvester generalizada (algoritmo sin bloques).

Propósito:

!>
!> STGSY2 resuelve la ecuación de Sylvester generalizada:
!>
!>             A * R - L * B = scale * C                (1)
!>             D * R - L * E = scale * F,
!>
!> usando BLAS de Nivel 1 y 2. Donde R y L son matrices desconocidas M-por-N,
!> (A, D), (B, E) y (C, F) son pares de matrices dadas de tamaño M-por-M,
!> N-por-N y M-por-N, respectivamente, con entradas reales. (A, D) y (B, E)
!> deben estar en forma canónica de Schur generalizada, es decir, A y B son
!> cuasi triangulares superiores y D y E son triangulares superiores. La solución (R, L)
!> sobrescribe (C, F). 0 <= SCALE <= 1 es un factor de escala de salida
!> elegido para evitar desbordamientos.
!>
!> En notación matricial, resolver la ecuación (1) corresponde a resolver
!> Z*x = scale*b, donde Z se define como
!>
!>        Z = [ kron(In, A)  -kron(B**T, Im) ]             (2)
!>            [ kron(In, D)  -kron(E**T, Im) ],
!>
!> Ik es la matriz identidad de tamaño k y X**T es la transpuesta de X.
!> kron(X, Y) es el producto de Kronecker entre las matrices X e Y.
!> En el proceso de resolver (1), resolvemos un número de tales sistemas
!> donde Dim(In), Dim(In) = 1 o 2.
!>
!> Si TRANS = 'T', resuelve el sistema transpuesto Z**T*y = scale*b para y,
!> lo que es equivalente a resolver para R y L en
!>
!>             A**T * R  + D**T * L   = scale * C           (3)
!>             R  * B**T + L  * E**T  = scale * -F
!>
!> Este caso se utiliza para calcular una estimación de Dif[(A, D), (B, E)] =
!> sigma_min(Z) usando comunicación inversa con SLACON.
!>
!> STGSY2 también (IJOB >= 1) contribuye al cálculo en STGSYL
!> de un límite superior para la separación entre dos pares de matrices. Entonces
!> las entradas (A, D), (B, E) son sub-lápices del par de matrices en
!> STGSYL. Ver STGSYL para detalles.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': resuelve la ecuación de Sylvester generalizada (1).
!>          = 'T': resuelve el sistema 'transpuesto' (3).
!>

IJOB

!>          IJOB es INTEGER
!>          Especifica qué tipo de funcionalidad se va a realizar.
!>          = 0: resuelve (1) solamente.
!>          = 1: se calcula una contribución de este subsistema a una estimación
!>               basada en la norma de Frobenius de la separación entre dos pares
!>               de matrices. (se utiliza la estrategia "look ahead").
!>          = 2: se calcula una contribución de este subsistema a una estimación
!>               basada en la norma de Frobenius de la separación entre dos pares
!>               de matrices. (se utiliza SGECON en subsistemas).
!>          No se hace referencia si TRANS = 'T'.
!>

M

!>          M es INTEGER
!>          En la entrada, M especifica el orden de A y D, y la dimensión
!>          de fila de C, F, R y L.
!>

N

!>          N es INTEGER
!>          En la entrada, N especifica el orden de B y E, y la dimensión
!>          de columna de C, F, R y L.
!>

A

!>          A es un array REAL, dimensión (LDA, M)
!>          En la entrada, A contiene una matriz cuasi triangular superior.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A. LDA >= max(1, M).
!>

B

!>          B es un array REAL, dimensión (LDB, N)
!>          En la entrada, B contiene una matriz cuasi triangular superior.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B. LDB >= max(1, N).
!>

C

!>          C es un array REAL, dimensión (LDC, N)
!>          En la entrada, C contiene el lado derecho de la primera matriz
!>          de la ecuación en (1).
!>          En la salida, si IJOB = 0, C ha sido sobrescrita por la
!>          solución R.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal de la matriz C. LDC >= max(1, M).
!>

D

!>          D es un array REAL, dimensión (LDD, M)
!>          En la entrada, D contiene una matriz triangular superior.
!>

LDD

!>          LDD es INTEGER
!>          La dimensión principal de la matriz D. LDD >= max(1, M).
!>

E

!>          E es un array REAL, dimensión (LDE, N)
!>          En la entrada, E contiene una matriz triangular superior.
!>

LDE

!>          LDE es INTEGER
!>          La dimensión principal de la matriz E. LDE >= max(1, N).
!>

F

!>          F es un array REAL, dimensión (LDF, N)
!>          En la entrada, F contiene el lado derecho de la segunda matriz
!>          de la ecuación en (1).
!>          En la salida, si IJOB = 0, F ha sido sobrescrita por la
!>          solución L.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal de la matriz F. LDF >= max(1, M).
!>

SCALE

!>          SCALE es REAL
!>          En la salida, 0 <= SCALE <= 1. Si 0 < SCALE < 1, las soluciones
!>          R y L (C y F en la entrada) contendrán las soluciones de un
!>          sistema ligeramente perturbado pero las matrices de entrada A, B, D y
!>          E no han sido modificadas. Si SCALE = 0, R y L contendrán
!>          las soluciones del sistema homogéneo con C = F = 0. Normalmente,
!>          SCALE = 1.
!>

RDSUM

!>          RDSUM es REAL
!>          En la entrada, la suma de cuadrados de las contribuciones calculadas a
!>          la estimación de Dif-calculada por STGSYL, donde el
!>          factor de escala RDSCAL (ver abajo) ha sido extraído.
!>          En la salida, la suma de cuadrados correspondiente actualizada con las
!>          contribuciones del subsistema actual.
!>          Si TRANS = 'T', RDSUM no se modifica.
!>          NOTA: RDSUM solo tiene sentido cuando STGSY2 es llamado por STGSYL.
!>

RDSCAL

!>          RDSCAL es REAL
!>          En la entrada, factor de escala utilizado para evitar desbordamientos en RDSUM.
!>          En la salida, RDSCAL se actualiza con respecto a las contribuciones
!>          actuales en RDSUM.
!>          Si TRANS = 'T', RDSCAL no se modifica.
!>          NOTA: RDSCAL solo tiene sentido cuando STGSY2 es llamado por
!>                STGSYL.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (M+N+2)
!>

PQ

!>          PQ es INTEGER
!>          En la salida, el número de subsistemas (de tamaño 2x2, 4x4 y
!>          8x8) resueltos por esta rutina.
!>

INFO

!>          INFO es INTEGER
!>          En la salida, si INFO se establece a
!>            =0: Salida exitosa
!>            <0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>            >0: Los pares de matrices (A, D) y (B, E) tienen valores propios comunes o muy
!>                cercanos.
!>

Autor

NAME

stgsy2 – roduce la matriz triangular superior S de la forma S = A*X*B, donde X es una matriz triangular inferior.

SYNOPSIS

 SUBROUTINE STGSY2( TRANS, UPLO, JOB, M, N, A, LDA, B, LDB, C, LDC, X, LD X,
                 SCALE, INFO )
      INTEGER            INFO, LDA, LDB, LDC, LD X, M, N
      REAL               SCALE
      CHARACTER          JOB, TRANS, UPLO
      REAL               A( LDA, * ), B( LDB, * ), C( LDC, * ), X( LD X, * )

Function/Subroutine Documentation

STGSY2 computes a solution X to the generalized Sylvester equation:

A*X*B

where A and B are matrices and X is the desired unknown matrix.

Under the assumptions provided by the input arguments, STGSY2 produces the unique solution X.

The subroutine STGSY2 is available for both single and double precision.

Arguments

TRANS

CHARACTER*1. On entry, TRANS specifies the form of the generalized Sylvester equation to be solved:

          If TRANS = 'N', then A*X*B = C.
          If TRANS = 'T', then A**T*X*B**T = C.
UPLO

CHARACTER*1. On entry, UPLO specifies the upper triangular form of the matrices A and B:

          If UPLO = 'U', then A and B are upper triangular.
          If UPLO = 'L', then A and B are lower triangular.
JOB

CHARACTER*1. On entry, JOB specifies whether or not the solution X is required:

          If JOB = 'X', then the solution X is computed and returned.
          If JOB = 'N', then the solution X is not computed.
M

INTEGER. On entry, M specifies the number of rows of matrices A and C. M >= 0.

N

INTEGER. On entry, N specifies the number of columns of matrices B and C. N >= 0.

A

REAL array, dimension (LDA, k). On entry, the leading m-by-k matrix A. k is m if UPLO = 'U' and k is n if UPLO = 'L'.

LDA

INTEGER. On entry, LDA specifies the leading dimension of the array A. LDA >= max(1, m).

B

REAL array, dimension (LDB, n). On entry, the leading k-by-n matrix B. k is n if UPLO = 'U' and k is m if UPLO = 'L'.

LDB

INTEGER. On entry, LDB specifies the leading dimension of the array B. LDB >= max(1, k).

C

REAL array, dimension (LDC, n). On entry, the right-hand side matrix C.

LDC

INTEGER. On entry, LDC specifies the leading dimension of the array C. LDC >= max(1, m).

X

REAL array, dimension (LDX, n). On exit, if JOB = 'X', X contains the solution matrix X.

LDX

INTEGER. On entry, LDX specifies the leading dimension of the array X. LDX >= max(1, m).

SCALE

REAL. On exit, SCALE is an overall scaling factor. The solution X is scaled by SCALE. The equation is A*X*B = C.

INFO

INTEGER. On exit, INFO is an integer diagnostics value. INFO = 0 is for successful exit. INFO < 0 indicates an invalid argument. INFO = -k indicates that the k-th argument had an invalid value. INFO > 0 indicates that the solution could not be computed. The diagonal element k of the matrix product A*B is zero, indicating that the generalized Sylvester equation has no unique solution. The problem may have either no solution or infinitely many solutions.

Information

The generalized Sylvester equation is a matrix equation of the form

A*X*B = C

where A, B, C, and X are matrices. The equation can also be written as

A*X + X*B = C

This equation arises in various applications, including control theory, signal processing, and robotics.

The subroutine STGSY2 solves the generalized Sylvester equation using a blocked algorithm that takes advantage of the matrix structure. The algorithm is based on the Schur decomposition of the matrices A and B, which transforms the matrices into upper triangular form. The resulting equation is then solved by backward substitution.

The subroutine STGSY2 requires that the matrices A and B are upper or lower triangular. If the matrices are not triangular, they must first be transformed into triangular form using the subroutine ZTRSEN.

The subroutine STGSY2 is part of the LAPACK library, which is a standard library for numerical linear algebra. LAPACK provides a wide range of routines for solving linear systems, eigenvalue problems, and least squares problems.
