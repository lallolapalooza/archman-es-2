FBB::Stat(3bobcat) Características de un objeto en el sistema de archivos FBB::Stat(3bobcat)

NOMBRE

FBB::Stat - Determina características de archivos

SINOPSIS

#include <bobcat/stat>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Stat es un envoltorio para las funciones del sistema stat(2) y lstat(2). En particular, ofrece funcionalidades para probar directamente las características de objetos que ofrecen estas dos funciones. Para determinar si un objeto puede construirse correctamente, utilice el operador de conversión Stat bool. Si este operador devuelve false, entonces no se deben usar otros miembros excepto error.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

ENUMERACIONES

Stat::Combine:
Esta enumeración define los siguientes valores:

o
ALL: requiere que coincidan todos los valores especificados de Mode o SpecialMode;
o
ANY: requiere cualquier coincidencia de los valores especificados de Mode o SpecialMode (una coincidencia es suficiente);

Stat::Mode:
Esta enumeración define los siguientes valores:

o
UR: el propietario del objeto tiene permisos de lectura
o
UW: el propietario del objeto tiene permisos de escritura
o
UX: el propietario del objeto tiene permisos de ejecución
o
GR: el grupo al que pertenece el objeto tiene permisos de lectura
o
GW: el grupo al que pertenece el objeto tiene permisos de escritura
o
GX: el grupo al que pertenece el objeto tiene permisos de ejecución
o
OR: otros tienen permisos de lectura
o
OW: otros tienen permisos de escritura
o
OX: otros tienen permisos de ejecución
o
READ: igual a UR | GR | OR
o
WRITE: igual a UW | GW | OW
o
EXEC: igual a UX | GX | OX
o
RWX: todos los anteriores.

Stat::SpecialMode:
Esta enumeración define los siguientes valores:

o
SUID: el bit set UID está activado
o
SGID: el bit set GID está activado
o
SB: el bit sticky está activado

Stat::Type:
Esta enumeración, que es idéntica a la enumeración Type de glob(3bobcat), define los siguientes valores:

o
BLOCK_DEVICE (0060000): el objeto es un dispositivo de bloques;
o
CHARACTER_DEVICE (0020000): el objeto es un dispositivo de caracteres;
o
DIRECTORY (0040000): el objeto es un directorio;
o
FIFO (0010000): el objeto es una tubería con nombre (una cola);
o
REGULAR_FILE (0100000): el objeto es un archivo regular;
o
SOCKET (0140000): el objeto es un socket;
o
SYMBOLIC_LINK (0120000): el objeto es un enlace simbólico;
o
ANY: cualquiera de los tipos anteriores.

Stat::Lstat:
Esta enumeración tiene un valor: LStat, que puede especificarse por constructores y algunos miembros cuando el objeto Stat debe distinguir archivos regulares y enlaces simbólicos (llamando a lstat(2)) en lugar de considerar los enlaces simbólicos como archivos regulares (usando stat(2)).

Los constructores y miembros que definen los parámetros de Stat::Lstat llaman a lstat(2), distinguiendo así los enlaces simbólicos de los archivos regulares, mientras que los constructores y miembros que no definen parámetros de Stat::Lstat usan stat(2).

Los valores de retorno de los miembros statStruct y type y typeStr (ver abajo) solo distinguen los enlaces simbólicos de los archivos regulares cuando se ha utilizado el argumento Stat::LStat.

Los constructores y las funciones miembro listadas a continuación para las cuales se especifica [Stat::Lstat,] como primer parámetro pueden especificar opcionalmente el argumento Stat::LStat.

CONSTRUCTORES

o
Stat():
El constructor por defecto, que crea un objeto Stat vacío. Se utiliza principalmente como objeto por defecto al definir, por ejemplo, vectores de objetos Stat. Como no se refiere a una entrada existente en el sistema de archivos, su operador bool devuelve false;
o
Stat([Stat::Lstat,] std::string const &fname):
Inicializa un Stat con un nombre de objeto dado;
o
Stat([Stat::Lstat,] std::string const &fname, std::string const &searchPath):
Inicializa un Stat con un nombre de objeto dado, donde el objeto se busca en los directorios de searchPath, que es una cadena separada por dos puntos con nombres de directorio. Los nombres de archivo se construyen añadiendo fname a cada uno de los elementos de searchPath hasta que se encuentra un objeto existente. Este objeto se utiliza entonces. Si fname es una ruta absoluta, se ignora searchPath.

Están disponibles los constructores de copia y movimiento (y los operadores de asignación).

OPERADORES SOBRECARGADOS

o
operator bool() const:
Este operador devuelve true si el objeto Stat contiene información sobre un objeto existente. De lo contrario, devuelve false. Cuando devuelve false, no se deben usar otros miembros, excepto los operadores de asignación, el miembro error y los miembros set.

FUNCIONES MIEMBRO

o
bool access(FBB::User const &user, size_t spec, bool useEffective = true) const:
Devuelve true si user tiene los permisos especificados en spec (de los cuales solo se interpretan los bits Mode definidos). Si se especifica una combinación de permisos de lectura, escritura y/o ejecución, entonces se debe conceder al menos uno de los permisos de lectura, uno de los permisos de escritura y uno de los permisos de ejecución, o la función devuelve false. Por ejemplo, al especificar access(user, UW | UR | GR), el usuario debe tener permisos de escritura, pero el usuario o el grupo del usuario deben tener permisos de lectura. Si se especifican múltiples permisos de lectura, múltiples permisos de escritura o múltiples permisos de ejecución (como UR | GR), este miembro devuelve true si se concede al menos uno de los permisos de lectura, escritura o ejecución solicitados para

Devuelve true si el objeto tiene el tipo sondeado, de lo contrario se devuelve false.

Devuelve el número de inodo (st_ino).
o
size_t gid() const:
Devuelve el ID de grupo del propietario del objeto (st_gid).

FBB::DateTime lastAccess() const:
Devuelve un objeto FBB::DateTime que contiene información sobre la hora del último acceso del objeto (st_atime) (usando UTC).
o
FBB::DateTime lastChange() const:
Devuelve un objeto FBB::DateTime que contiene información sobre la hora del último cambio de estado del objeto (st_ctime) (usando UTC).
o
FBB::DateTime lastModification() const:
Devuelve un objeto FBB::DateTime que contiene información sobre la hora de la última modificación del objeto (st_mtime) (usando UTC).
o
size_t mode() const:
Devuelve el modo bruto y no interpretado del objeto (st_mode & RWX). Tenga en cuenta que este valor generalmente se muestra (y se procesa más fácilmente) como un valor octal.
o
bool mode(size_t mode, Combine combine = ALL):
Devuelve true si el objeto tiene el modo indicado. Se pueden establecer múltiples modos, que pueden combinarse mediante el operador lógico bitor. Por defecto, si se especifican múltiples modos, el patrón resultante debe representar exactamente el modo del objeto para que la función miembro devuelva true. Se puede especificar un argumento opcional ANY si la función debe devolver true si al menos un modo especificado coincide con el modo real del objeto. Se lanza una excepción Exception si el mode especificado contiene valores distintos de los valores definidos de Mode o SpecialMode.
o
std::string modeStr() const:
Devuelve la representación de cadena estándar del modo del objeto (por ejemplo, rw-r--r--). Los modos especiales (por ejemplo, suid) se indican con s en lugar de x cuando el objeto es ejecutable por el usuario y/o grupo, y con S si el objeto tiene los bits de modo especial establecidos, pero no es ejecutable. Para el indicador de modo ejecutable `otro', se utiliza t (bit `sticky') y T si el objeto no es ejecutable por `otro'.
o
std::string const &name() const:
Devuelve el nombre del objeto según lo especificado en el constructor o en la función miembro set().
o
size_t nBlocks() const:
Devuelve el número de bloques asignados del objeto (st_blocks).
o
size_t nLinks() const:
Devuelve el número de enlaces duros del objeto (st_nlink).
o
std::string path() const:
Devuelve la ruta completa del objeto. Si no se pudo determinar la ruta completa, se devuelve una cadena vacía.
o
bool set([Stat::Lstat,] std::string const &name):
Redefine el objeto Stat para representar la información sobre el nombre de objeto indicado.
o
bool set([Stat::Lstat,] std::string const &name, std::string const &pathlist):
Redefine el objeto Stat para representar la información sobre el nombre de objeto indicado, donde el objeto se busca en los directorios de pathlist, que es una cadena separada por dos puntos de nombres de directorios. Los nombres de los objetos se construyen añadiendo fname a cada uno de los elementos de searchPath hasta que se encuentra un objeto existente. Luego se utiliza este objeto. Si fname es una ruta absoluta, searchPath se ignora.
o
off_t size() const:
Devuelve el tamaño del objeto en número de bytes (st_size).
o
bool specialMode(size_t special, Combine combine = ALL):
Devuelve true si el objeto tiene los modos especiales indicados. Se pueden especificar múltiples modos especiales, que pueden combinarse mediante el operador lógico bitor. Por defecto, si se especifican múltiples modos, el patrón resultante debe representar exactamente el modo del objeto para que la función miembro devuelva true. Se puede especificar un argumento opcional ANY si la función debe devolver true si al menos un modo especificado coincide con el modo real del objeto. Los modos no especiales se ignoran, pero se lanza una excepción Exception si special contiene valores distintos de los definidos por la enumeración SpecialMode.
o
Stat::stat const &statStruct() const:
Devuelve una referencia a la estructura stat del objeto.
o
Stat::Type type() const:
Devuelve el valor Stat::Type del objeto.
o
std::string typeStr() const:
Devuelve una representación textual del tipo del objeto según lo devuelto por la función miembro Stat::type().
o
size_t uid() const:
Devuelve el ID de usuario del propietario del objeto (st_uid).

EJEMPLO

/*
                              driver.cc
*/
#include <iostream>
#include <string>
#include "../stat"
#include <bobcat/datetime>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    if (argc == 1)
    {
        cout << "Uso: driver [-l] objeto [ruta de búsqueda separada por dos puntos]\n";
        return 1;
    }
    bool lstat = "-l"s == argv[1];
    if (lstat)
    {
        ++argv;
        --argc;
    }
    Stat st;
    if (argc == 2)
    {
        if (lstat)
            st.set(Stat::LStat, argv[1]);
        else
            st.set(argv[1]);
    }
    else if (argc == 3)
    {
        if (lstat)
            st.set(Stat::LStat, argv[1], argv[2]);
        else
            st.set(argv[1], argv[2]);
    }
    if (!st)
    {
        cout << "No se puede acceder a " << argv[1] << ", errno = " << st.error() << endl;
        return 1;
    }
    cout << st.name() << ": acceso: " << st.lastAccess() << "\n" <<
            st.name() << ": cambio: " << st.lastChange() << "\n" <<
            st.name() << ": modif:  " << st.lastModification() << "\n"
            "Modo: " << oct << st.mode() <<  " (" << st.modeStr() << ")\n"
            "Tipo: " << st.type() << " (" << st.typeStr() << ")\n"
            "Ruta completa:  " << st.path()  << endl;
}
