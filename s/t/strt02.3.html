subrutina strt02 (character uplo, character trans, character diag, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldx, * ) x, integer ldx, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) work, real resid)

STRT02

Propósito

!>
!> STRT02 calcula el residuo de la solución calculada para un sistema
!> de ecuaciones lineales triangulares op(A)*X = B, donde A es una
!> matriz triangular. La relación de prueba es el máximo sobre
!>    norm(b - op(A)*x) / ( ||op(A)||_1 * norm(x) * EPS ),
!> donde op(A) = A o A**T, b es la columna de B, x es el vector solución,
!> y EPS es el épsilon de la máquina.
!> La norma utilizada es la norma 1.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U': Triangular superior
!>          = 'L': Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  A    * X = B  (Sin transpuesta)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitriangular o no.
!>          = 'N': Triangular no unitaria
!>          = 'U': Triangular unitaria
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices X e B.  NRHS >= 0.
!>

A

!>          A es un array REAL, dimension (LDA,N)
!>          La matriz triangular A.  Si UPLO = 'U', la parte superior
!>          triangular de tamaño n por n de la matriz A contiene la
!>          matriz triangular superior, y la parte estrictamente triangular
!>          inferior de A no se referencia.  Si UPLO = 'L', la parte
!>          triangular inferior de tamaño n por n de la matriz A contiene
!>          la matriz triangular inferior, y la parte estrictamente
!>          triangular superior de A no se referencia.  Si DIAG = 'U',
!>          los elementos diagonales de A tampoco se referencian y se
!>          asumen como 1.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

X

!>          X es un array REAL, dimension (LDX,NRHS)
!>          Los vectores solución calculados para el sistema de ecuaciones
!>          lineales.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

B

!>          B es un array REAL, dimension (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un array REAL, dimension (N)
!>

RESID

!>          RESID es REAL
!>          El máximo sobre el número de lados derechos de
!>          norm(op(A)*X - B) / ( norm(op(A)) * norm(X) * EPS ).
!>
