STTY(1) Comandos de usuario STTY(1)

NOMBRE

stty - cambiar e imprimir la configuración de la línea del terminal

SINOPSIS

stty [DEVICE -F | --file=DEVICE] [AJUSTE]...
stty [DEVICE -F | --file=DEVICE] [-a|--all]
stty [DEVICE -F | --file=DEVICE] [-g|--save]

DESCRIPCIÓN

Imprimir o cambiar las características del terminal.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-a, --all
imprimir todas las configuraciones actuales en formato legible por humanos
-g, --save
imprimir todas las configuraciones actuales en un formato legible por stty
-F, --file=DEVICE
abrir y usar DEVICE en lugar de la entrada estándar
--help
mostrar esta ayuda y salir
--version
mostrar información de la versión y salir

Un guion opcional antes de AJUSTE indica negación. Un * marca configuraciones no POSIX. El sistema subyacente define qué configuraciones están disponibles.

Caracteres especiales:

* discard CHAR
CHAR activará/desactivará el descarte de salida
eof CHAR
CHAR enviará un fin de archivo (terminará la entrada)
eol CHAR
CHAR terminará la línea
* eol2 CHAR
CHAR alternativo para terminar la línea
erase CHAR
CHAR borrará el último carácter escrito
intr CHAR
CHAR enviará una señal de interrupción
kill CHAR
CHAR borrará la línea actual
* lnext CHAR
CHAR entrará en el siguiente carácter citado
quit CHAR
CHAR enviará una señal de salida
* rprnt CHAR
CHAR redibujará la línea actual
start CHAR
CHAR reiniciará la salida después de detenerla
stop CHAR
CHAR detendrá la salida
susp CHAR
CHAR enviará una señal de detención de terminal
* swtch CHAR
CHAR cambiará a una capa de shell diferente
* werase CHAR
CHAR borrará la última palabra escrita

Ajustes especiales:

N
establecer las velocidades de entrada y salida a N bauds
cols N
indicar al kernel que el terminal tiene N columnas
* columns N
igual que cols N
* [-]drain
esperar la transmisión antes de aplicar los ajustes (activado por defecto)
ispeed N
establecer la velocidad de entrada a N
* line N
usar la disciplina de línea N
min N
con -icanon, establecer un mínimo de N caracteres para una lectura completada
ospeed N
establecer la velocidad de salida a N
rows N
indicar al kernel que el terminal tiene N filas
size
imprimir el número de filas y columnas según el kernel
speed
imprimir la velocidad del terminal
time N
con -icanon, establecer el tiempo de espera de lectura de N décimas de segundo

Ajustes de control:

[-]clocal
desactivar señales de control del módem
[-]cread
permitir la recepción de entrada
* [-]crtscts
activar el handshake RTS/CTS
csN
establecer el tamaño del carácter a N bits, N en [5..8]
[-]cstopb
usar dos bits de parada por carácter (uno con '-')
[-]hup
enviar una señal de desconexión cuando el último proceso cierra el tty
[-]hupcl
igual que [-]hup
[-]parenb
generar bit de paridad en la salida y esperar bit de paridad en la entrada
[-]parodd
establecer paridad impar (o paridad par con '-')
* [-]cmspar
usar paridad "stick" (marca/espacio)

Ajustes de entrada:

[-]brkint
las interrupciones causan una señal de interrupción
[-]icrnl
traducir retorno de carro a nueva línea
[-]ignbrk
ignorar caracteres de interrupción
[-]igncr
ignorar retorno de carro
[-]ignpar
ignorar caracteres con errores de paridad
* [-]imaxbel
emitir un pitido y no vaciar un buffer de entrada lleno en un carácter
[-]inlcr
traducir nueva línea a retorno de carro
[-]inpck
activar la comprobación de paridad de entrada
[-]istrip
borrar el bit alto (8º) de los caracteres de entrada
* [-]iutf8
asumir que los caracteres de entrada están codificados en UTF-8
* [-]iuclc
traducir caracteres en mayúsculas a minúsculas
* [-]ixany
dejar que cualquier carácter reinicie la salida, no solo el carácter de inicio
[-]ixoff
activar el envío de caracteres de inicio/parada
[-]ixon
activar el control de flujo XON/XOFF
[-]parmrk
marcar errores de paridad (con una secuencia de caracteres 255-0-)
[-]tandem
igual que [-]ixoff

Ajustes de salida:

* bsN
estilo de retardo de retroceso, N en [0..1]
* crN
estilo de retardo de retorno de carro, N en [0..3]
* ffN
estilo de retardo de avance de página, N en [0..1]
* nlN
estilo de retardo de nueva línea, N en [0..1]
* [-]ocrnl
traducir retorno de carro a nueva línea
* [-]ofdel
usar caracteres de borrado para relleno en lugar de caracteres NUL
* [-]ofill
usar caracteres de relleno (relleno) en lugar de tiempos para los retardos
* [-]olcuc
traducir caracteres en minúsculas a mayúsculas
* [-]onlcr
traducir nueva línea a retorno de carro-nueva línea
* [-]onlret
nueva línea realiza un retorno de carro
* [-]onocr
no imprimir retornos de carro en la primera columna
[-]opost
posprocesar la salida
* tabN
estilo de retardo de tabulación horizontal, N en [0..3]
* tabs
igual que tab0
* -tabs
igual que tab3
* vtN
estilo de retardo de tabulación vertical, N en [0..1]

Ajustes locales:

[-]crterase
mostrar caracteres de borrado como retroceso-espacio-retroceso
* crtkill
matar toda la línea obedeciendo los ajustes echoprt y echoe
* -crtkill
matar toda la línea obedeciendo los ajustes echoctl y echok
* [-]ctlecho
mostrar

stty(1) — GNU coreutils 9.9

NAME

stty - configure or report terminal line settings

SYNOPSIS

stty [OPTION]...

stty SETTING...

DESCRIPTION

Handle the tty line connected to standard input. Without arguments, prints baud rate, line discipline, and deviations from stty sane.

In settings, CHAR is taken literally, or coded as in ^c, 0x37, 0177 or 127; special values ^- or undef used to disable special characters.

Control characters:

* [-]aflf
same as [-]noaffl
* [-]affl
enable the pause between output lines
* [-]altwerase
use the alternate kill/erase character
* [-]apl
use the alternate pause
* [-]crt
same as [-]echoe [-]echok
* [-]crterase
same as [-]echoe
* [-]crtkill
same as [-]echok
[-]ctlecho
echo control characters in hat notation ('^c')
[-]echo
echo input characters
* [-]echoctl
same as [-]ctlecho
[-]echoe
same as [-]crterase
[-]echok
echo a newline after a kill character
* [-]echoke
same as [-]crtkill
[-]echonl
echo newline even if not echoing other characters
* [-]echoprt
echo erased characters backward, between '\' and '/'
* [-]extproc
enable "LINEMODE"; useful with high latency links
* [-]flusho
discard output
[-]icanon
enable special characters: erase, kill, werase, rprnt
[-]iexten
enable non-POSIX special characters
[-]isig
enable interrupt, quit, and suspend special characters
[-]noflsh
disable flushing after interrupt and quit special characters
* [-]prterase
same as [-]echoprt
* [-]tostop
stop background jobs that try to write to the terminal
* [-]xcase
with icanon, escape with '\' for uppercase characters

Combination settings:

* [-]LCASE
same as [-]lcase
cbreak
same as -icanon
-cbreak
same as icanon
cooked
same as brkint ignpar istrip icrnl ixon opost isig icanon, eof and eol characters to their default values
-cooked
same as raw
crt
same as echoe echoctl echoke
dec
same as echoe echoctl echoke -ixany intr ^c erase 0177 kill ^u
* [-]decctlq
same as [-]ixany
ek
erase and kill characters to their default values
evenp
same as parenb -parodd cs7
-evenp
same as -parenb cs8
* [-]lcase
same as xcase iuclc olcuc
litout
same as -parenb -istrip -opost cs8
-litout
same as parenb istrip opost cs7
nl
same as -icrnl -onlcr
-nl
same as icrnl -inlcr -igncr onlcr -ocrnl -onlret
oddp
same as parenb parodd cs7
-oddp
same as -parenb cs8
[-]parity
same as [-]evenp
pass8
same as -parenb -istrip cs8
-pass8
same as parenb istrip cs7
raw
same as -ignbrk -brkint -ignpar -parmrk -inpck -istrip -inlcr -igncr -icrnl -ixon -ixoff -icanon -opost -isig -iuclc -ixany -imaxbel -xcase min 1 time 0
-raw
same as cooked
sane
same as cread -ignbrk brkint -inlcr -igncr icrnl icanon iexten echo echoe echok -echonl -noflsh -ixoff -iutf8 -iuclc -ixany imaxbel -xcase -olcuc -ocrnl opost -ofill onlcr -onocr -onlret nl0 cr0 tab0 bs0 vt0 ff0 isig -tostop -ofdel -echoprt echoctl echoke -extproc -flusho, all special characters to their default values

Handle the tty line connected to standard input. Without arguments, prints baud rate, line discipline, and deviations from stty sane. In settings, CHAR is taken literally, or coded as in ^c, 0x37, 0177 or 127; special values ^- or undef used to disable special characters.
