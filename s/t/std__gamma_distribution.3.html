Detailed Description

This is the class template for the gamma distribution. It generates random numbers in the range [0, inf) according to the probability density function:

f(x; α, β) = βα / Γ(α) * xα-1 * exp(-βx)

where α is the shape parameter and β is the rate parameter.

Note: Some literature refers to the scale parameter 1/β instead of the rate parameter β.

The parameters are named alpha and beta in this implementation.

Note: This is a non-central gamma distribution. The non-central gamma distribution has PDF:

f(x; α, β, λ) = βα / Γ(α) * xα-1 * exp(-βx - λ/2) * Iα-1(sqrt(2λx))

where λ is the non-centrality parameter and Iv is the modified Bessel function of the first kind.

This implementation uses a different algorithm and therefore does not implement the non-central gamma distribution.

The parameters are alpha and beta. alpha is the shape parameter, and beta is the rate parameter.

Example:

```cpp std::vector<double> v(10); std::gamma_distribution<double> distribution(2.5, 1.0); // alpha=2.5, beta=1.0 std::generate(v.begin(), v.end(), [&]() { return distribution(engine); }); ```

The above code snippet generates 10 random numbers from a gamma distribution with alpha = 2.5 and beta = 1.0.

The algorithm used is described in:

G. and Tsang, W. W. "A Simple Method for Generating Gamma Variables" ACM Transactions on Mathematical Software, 26, 3, 363-372, 2000.
