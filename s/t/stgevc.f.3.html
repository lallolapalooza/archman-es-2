Documentación de Función/Subrutina

subroutine stgevc (character side, character howmny, logical, dimension( * ) select, integer n, real, dimension( lds, * ) s, integer lds, real, dimension( ldp, * ) p, integer ldp, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, real, dimension( * ) work, integer info)

STGEVC

Propósito:

!>
!> STGEVC calcula algunos o todos los autovectores derechos y/o izquierdos de
!> un par de matrices reales (S,P), donde S es una matriz cuasi-triangular
!> y P es triangular superior. Los pares de matrices de este tipo se producen por
!> la factorización de Schur generalizada de un par de matrices (A,B):
!>
!>    A = Q*S*Z**T,  B = Q*P*Z**T
!>
!> como se calcula por SGGHRD + SHGEQZ.
!>
!> El autovector derecho x y el autovector izquierdo y de (S,P)
!> correspondientes a un autovalor w se definen por:
!>
!>    S*x = w*P*x,  (y**H)*S = w*(y**H)*P,
!>
!> donde y**H denota la transpuesta conjugada de y.
!> Los autovalores no son una entrada para esta rutina, sino que se calculan
!> directamente a partir de los bloques diagonales de S y P.
!>
!> Esta rutina devuelve las matrices X e/o Y de autovectores derechos e izquierdos
!> de (S,P), o los productos Z*X y/o Q*Y,
!> donde Z y Q son matrices de entrada.
!> Si Q y Z son los factores ortogonales de la factorización de Schur
!> generalizada de un par de matrices (A,B), entonces Z*X y Q*Y
!> son las matrices de autovectores derechos e izquierdos de (A,B).
!>
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R': calcular solo autovectores derechos;
!>          = 'L': calcular solo autovectores izquierdos;
!>          = 'B': calcular ambos autovectores derechos e izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular todos los autovectores derechos y/o izquierdos;
!>          = 'B': calcular todos los autovectores derechos y/o izquierdos,
!>                 backtransformados por las matrices en VR y/o VL;
!>          = 'S': calcular autovectores derechos y/o izquierdos seleccionados,
!>                 especificados por el array lógico SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY='S', SELECT especifica los autovectores a calcular.
!>          Si w(j) es un autovalor real, se calcula el autovector real
!>          correspondiente si SELECT(j) es .TRUE..
!>          Si w(j) y w(j+1) son las partes real e imaginaria de un
!>          autovalor complejo, se calcula el autovector complejo
!>          si SELECT(j) o SELECT(j+1) es .TRUE.,
!>          y a la salida SELECT(j) se establece a .TRUE. y SELECT(j+1) se
!>          establece a .FALSE..
!>          No referenciado si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de las matrices S y P.  N >= 0.
!>

S

!>          S es un array REAL, de dimensión (LDS,N)
!>          La matriz cuasi-triangular superior S de una factorización de Schur
!>          generalizada, como la calculada por SHGEQZ.
!>

LDS

!>          LDS es INTEGER
!>          La dimensión principal del array S.  LDS >= max(1,N).
!>

P

!>          P es un array REAL, de dimensión (LDP,N)
!>          La matriz triangular superior P de una factorización de Schur
!>          generalizada, como la calculada por SHGEQZ.
!>          Los bloques diagonales de 2x2 de P correspondientes a los bloques
!>          de 2x2 de S deben estar en forma diagonal positiva.
!>

LDP

!>          LDP es INTEGER
!>          La dimensión principal del array P.  LDP >= max(1,N).
!>

VL

!>          VL es un array REAL, de dimensión (LDVL,MM)
!>          A la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de NxN (normalmente la matriz ortogonal Q
!>          de vectores de Schur izquierdos devuelta por SHGEQZ).
!>          A la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de autovectores izquierdos de (S,P);
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los autovectores izquierdos de (S,P) especificados por
!>                      SELECT, almacenados consecutivamente en las columnas de
!>                      VL, en el mismo orden que sus autovalores.
!>
!>          Un autovector complejo correspondiente a un autovalor complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real y la segunda la parte imaginaria.
!>
!>          No referenciado si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.  LDVL >= 1, y si
!>          SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un array REAL, de dimensión (LDVR,MM)
!>          A la entrada, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Z de NxN (normalmente la matriz ortogonal Z
!>          de vectores de Schur derechos devuelta por SHGEQZ).
!>
!>          A la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de autovectores derechos de (S,P);
!>          si HOWMNY = 'B' o 'b', la matriz Z*X;
!>          si HOWMNY = 'S' o 's', los autovectores derechos de (S,P)
!>                      especificados por SELECT, almacenados consecutivamente en las
!>                      columnas de VR, en el mismo orden que sus
!>                      autovalores.
!>
!>          Un autovector complejo correspondiente a un autovalor complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real y la segunda la parte imaginaria.
!>
!>          No referenciado si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.  LDVR >= 1, y si
!>          SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizadas para almacenar los autovectores.  Si HOWMNY = 'A' o 'B'
!>          se establece a N. Cada autovector real seleccionado ocupa una
!>          columna y cada autovector complejo seleccionado ocupa dos
!>          columnas.
!>

WORK

!>          WORK es un array REAL, de dimensión (6*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          > 0:  el bloque de 2x2 (INFO:INFO+1) no tiene un autovalor complejo.
!>
