strfromd(3) Manual de Funciones de Biblioteca strfromd(3)

NOMBRE

strfromd, strfromf, strfroml - convertir un valor de punto flotante a una cadena

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
int strfromd(size_t n;
             char str[restrict n], size_t n,
             const char *restrict format, double fp);
int strfromf(size_t n;
             char str[restrict n], size_t n,
             const char *restrict format, float fp);
int strfroml(size_t n;
             char str[restrict n], size_t n,
             const char *restrict format, long double fp);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

strfromd(), strfromf(), strfroml():

    __STDC_WANT_IEC_60559_BFP_EXT__

DESCRIPCIÓN

Estas funciones convierten un valor de punto flotante, fp, en una cadena de caracteres, str, con una cadena de formato configurable. Se almacenan como máximo n caracteres en str.

El byte nulo terminador ('\0') se escribe si y solo si n es suficientemente grande, de lo contrario la cadena escrita se truncará en n caracteres.

Las funciones strfromd(), strfromf(), y strfroml() son equivalentes a


snprintf(str, n, format, fp);

excepto por la cadena de formato.

Formato de la cadena de formato

La cadena de formato debe comenzar con el carácter '%'. Esto es seguido por una precisión opcional que comienza con el carácter punto (.), seguido de un entero decimal opcional. Si no se especifica ningún entero después del carácter punto, se usa una precisión de cero. Finalmente, la cadena de formato debe tener uno de los especificadores de conversión a, A, e, E, f, F, g, o G.

El especificador de conversión se aplica en función del tipo de punto flotante indicado por el sufijo de la función. Por lo tanto, a diferencia de snprintf(), la cadena de formato no tiene un carácter modificador de longitud. Ver snprintf(3) para una descripción detallada de estos especificadores de conversión.

La implementación se conforma al estándar C99 sobre la conversión de valores NaN e infinito:

Si fp es un NaN, +NaN, o -NaN, y f (o a, e, g) es el especificador de conversión, la conversión es a "nan", "nan", o "-nan", respectivamente. Si F (o A, E, G) es el especificador de conversión, la conversión es a "NAN" o "-NAN".

Igualmente, si fp es infinito, se convierte a [-]inf o [-]INF.

Una cadena de formato mal formada resulta en un comportamiento indefinido.

VALOR DE RETORNO

Las funciones strfromd(), strfromf(), y strfroml() devuelven el número de caracteres que se habrían escrito en str si n hubiera tenido suficiente espacio, sin contar el byte nulo terminador. Por lo tanto, un valor de retorno de n o mayor significa que la salida fue truncada.

NOTAS

EJEMPLOS

Para convertir el valor 12.1 como tipo float a una cadena usando notación decimal, resultando en "12.100000":


#define __STDC_WANT_IEC_60559_BFP_EXT__
#include <stdlib.h>
int ssize = 10;
char s[ssize];
strfromf(s, ssize, "%f", 12.1);

Para convertir el valor 12.3456 como tipo float a una cadena usando notación decimal con dos dígitos de precisión, resultando en "12.35":


#define __STDC_WANT_IEC_60559_BFP_EXT__
#include <stdlib.h>
int ssize = 10;
char s[ssize];
strfromf(s, ssize, "%.2f", 12.3456);

Para convertir el valor 12.345e19 como tipo double a una cadena usando notación científica con cero dígitos de precisión, resultando en "1E+20":


#define __STDC_WANT_IEC_60559_BFP_EXT__
#include <stdlib.h>
int ssize = 10;
char s[ssize];
strfromd(s, ssize, "%.E", 12.345e19);

VER TAMBIÉN

atof(3), snprintf(3), strtod(3)

strfromd(3)

strfromd — format a floating-point number into a string

SYNOPSIS

#include <stdio.h>

size_t strfromd(char *s, size_t n, const char *format, double f);

DESCRIPTION

The strfromd() function formats the double-precision floating-point number f into the character array pointed to by s. The maximum number of characters to write is n. The format argument specifies the conversion specifier. The strfromd() function supports the following conversion specifiers:

'a', 'A'
Hexadecimal floating-point format. (See printf(3) for details.)
'e', 'E'
Decimal exponent format. (See printf(3) for details.)
'f', 'F'
Decimal fixed-point format. (See printf(3) for details.)
'g', 'G'
Decimal format. (See printf(3) for details.)
'n'
The number of characters written so far is stored into the integer pointed to by the argument. This character can only appear in format if it is the last character.
'x', 'X'
Hexadecimal floating-point format. (See printf(3) for details.)

The format argument is a string that may contain ordinary characters and conversion specifiers. Ordinary characters are copied verbatim into the output string. Conversion specifiers are introduced by a '%' character. The '%' character may be followed by:

  • Optional flags: '-', '+', ' ', '#', '0'.
  • An optional decimal integer width.
  • An optional precision, specified by a '.' character followed by an optional decimal integer.
  • An optional length modifier.
  • A conversion specifier character.

The strfromd() function will write at most n-1 characters to the buffer s and will always null-terminate the resulting string. If the conversion is not possible, or if n is zero, the buffer s will be empty (i.e., s[0] = '\0') and zero will be returned.

If the string that would be generated for f is longer than or equal to n, the behavior is undefined.

If s is NULL, strfromd() behaves like snprintf(3) and returns the number of characters that would have been written.

RETURN VALUE

The strfromd() function returns the number of characters that would have been written to s if n had been sufficiently large, not counting the terminating null character.

STANDARDS

C11.

HISTORY

The strfromd() function first appeared in FreeBSD 10.0.
