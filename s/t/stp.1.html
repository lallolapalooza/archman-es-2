STP(1) Comandos de usuario STP(1)

NOMBRE

stp - Solucionador SMT Simple Theorem Prover

DESCRIPCIÓN

USO: stp [opciones] <archivo-entrada>

donde la entrada es SMTLIB1/2 o CVC dependiendo de las opciones y la extensión del archivo

Opciones más importantes:

-h [ --help ]
imprimir esta ayuda
--version
imprimir número de versión

Simplificaciones:

--disable-simplifications
desactivar todas las simplificaciones
-w [ --switch-word ]
desactivar el solucionador de nivel de palabra
-a [ --disable-opt-inc ]
desactivar el simplificador de reescritura
--disable-cbitp
desactivar la propagación de bits constantes
--disable-equality
desactivar la propagación de igualdad
--size-reducing-only
solo simplificaciones que reducen el tamaño
--unconstrained-variable-elimination arg (=1)
Se eliminan las variables no restringidas.
--aig-rewrite-passes arg (=0)
Iteraciones de reescritura de AIG a realizar
--flattening arg (=0)
Habilita el aplanamiento consciente de compartir de nodos de aridad >2
--rewriting arg (=1)
Habilita la reescritura consciente de compartir
--split-extracts arg (=1)
Crea nuevas variables para algunas extracciones
--ite-context-simplifications arg (=0)
Utiliza lo que se sabe que es cierto en un nodo if-then-else para simplificar las ramas verdadera o falsa
--aig-core-simplification arg (=0)
Simplifica el núcleo proposicional con AIGs
--use-intervals arg (=1)
Simplifica con análisis de intervalos
--pure-literals arg (=1)
Se reemplazan los literales puros.
--always-true arg (=0)
Los nodos que siempre son verdaderos (por ejemplo, afirmados) se reemplazan en todo el problema por verdadero
--merge-same arg (=0)
Utiliza reglas simples de álgebra booleana para combinar conjunciones en el nivel superior
--bit-blast-simplification arg (=0)
A mitad del proceso de simplificación, convierte a AIGs y busca bits que los AIGs determinen que son verdaderos/falsos o iguales a otro nodo. Si la dificultad es menor que este número. -1 significa siempre.
--size-reducing-fixed-point-limit arg (=0)
Si el número de nodos no hoja es menor que este número, ejecuta las simplificaciones que reducen el tamaño hasta un punto fijo. -1 significa siempre.
--simplify-to-constants-only arg (=0) Utiliza solo las simplificaciones del
conjunto potencialmente de aumento de tamaño que transforma nodos en constantes
--difficulty-reversion arg (=1)
Deshace las simplificaciones que aumentan el tamaño si no han hecho el problema más simple

Opciones del solucionador SAT:

--cryptominisat
usa cryptominisat como solucionador. Solo usa CryptoMiniSat 5.0 o superior (predeterminado).
--threads arg (=1)
Número de hilos para cryptominisat
--simplifying-minisat
usa la versión instalada de simplifying minisat como solucionador
--minisat
usa la versión instalada de minisat como solucionador

Opciones de refinamiento:

-r [ --ackermanize ]
codifica ansiosamente los axiomas de lectura de arreglos (Ackermannización)

Opciones de bit-blasting:

--bb.div-v1 arg (=1)
variante de codificación de división sin signo 1
--bb.div-v2 arg (=1)
variante de codificación de división sin signo 2
--bb.div-v3 arg (=0)
variante de codificación de división sin signo 3
--bb.add-v1 arg (=1)
variante de codificación de adición 1
--bb.add-v2 arg (=1)
variante de codificación de adición 2
--bb.vle-v1 arg (=1)
variante de codificación de comparación 1
--bb.mult-variant arg (=1)
variante de multiplicación sin signo
--bb.mult-v2 arg (=0)
variante de multiplicación sin signo 2
--bb.conjoin-constant arg (=0)
Cuando la propagación de bits constantes detecta un bit constante durante la construcción de AIG, afirma el nodo AIG y reemplázalo, en el AIG, por el bit constante

Opciones de impresión:

-b [ --print-stpinput ]
imprime la entrada STP de nuevo en cout
--print-back-CVC
imprime la entrada en formato CVC, luego sale
--print-back-SMTLIB2
imprime la entrada en formato SMT-LIB2, luego sale
--print-back-SMTLIB1
imprime la entrada en formato SMT-LIB1, luego sale
--print-back-GDL
imprime el formato de gráfico de AiSee, luego sale
--print-back-dot
imprime el formato de gráfico de dotty/neato, luego sale
-p [ --print-counterex ]
imprime contraejemplo
-y [ --print-counterexbin ]
imprime contraejemplo en binario
-q [ --print-arrayval ]
imprime el orden declarado de arrayval
-s [ --print-functionstat ]
imprime estadísticas de funciones
-t [ --print-quickstat ]
imprime estadísticas rápidas
-v [ --print-nodes ]
imprime nodos
-n [ --print-output ]
Imprime salida

Opciones de entrada:

-m [ --SMTLIB1 ]
usa el analizador de formato SMT-LIB1
--SMTLIB2
usa el analizador de formato SMT-LIB2
--CVC
usa el analizador de formato CVC

Output options:

--output-CNF
Guarda la CNF en output_[0..n].cnf. NOTA: las variables no se pueden mapear hacia atrás, y los problemas resueltos únicamente por el simplificador de preprocesamiento no generarán ninguna CNF, ya que el solucionador SAT nunca se invoca.
--output-bench
Guarda en el formato bench de ABC en output.bench.

Opciones de salida:

--exit-after-CNF
Sale después de que se haya generado la CNF.
-g [ --max-num-confl ] arg (=-1)
Número de conflictos después del cual el solucionador SAT se rinde. -1 significa nunca.
-k [ --max-time ] arg (=-1)
Número de segundos después del cual el solucionador SAT se rinde. -1 significa nunca.
-d [ --check-sanity ]
Construye un contraejemplo y lo verifica.

Opciones ocultas:

--file arg
Archivo de entrada.

VER TAMBIÉN

La documentación completa de stp se mantiene como un manual de Texinfo. Si los programas info y stp están correctamente instalados en su sitio, el comando

info stp

debería darle acceso al manual completo.
