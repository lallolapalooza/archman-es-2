NOMBRE

std::ios_base - La base de la jerarquía de clases de E/S.

SINOPSIS

#include <ios>

Heredada por std::basic_ios< char_type, traits_type >, std::basic_ios< char >, std::basic_ios< wchar_t >, y std::basic_ios< _CharT, _Traits >.

Definición del Documento

Define todo lo que se puede definir sobre E/S que no depende del tipo de caracteres que se estén leyendo o escribiendo. La mayoría de las personas solo verán `ios_base` cuando necesiten especificar el nombre completo de las diversas banderas de E/S (por ejemplo, los modos de apertura).

Documentación de Typedef de Miembros

typedef void(* std::ios_base::event_callback)(event __e, ios_base &__b, int __i)

El tipo de una función de devolución de llamada de evento.

Parámetros

__e Uno de los miembros de la enumeración `event`.
__b Referencia al objeto `ios_base`.
__i El entero proporcionado cuando se registró la devolución de llamada.

Las devoluciones de llamada de eventos son funciones definidas por el usuario que se llaman durante varias funciones de `ios_base` y `basic_ios`, específicamente `imbue()`, `copyfmt()` y `~ios()`.

typedef _Ios_Iostate std::ios_base::iostate

Este es un tipo de máscara de bits. _Ios_Iostate está definido por la implementación, pero es válido realizar operaciones bit a bit con estos valores y esperar que ocurra lo correcto. Los objetos definidos de tipo `iostate` son:

  • badbit
  • eofbit
  • failbit
  • goodbit

typedef _Ios_Openmode std::ios_base::openmode

Este es un tipo de máscara de bits. _Ios_Openmode está definido por la implementación, pero es válido realizar operaciones bit a bit con estos valores y esperar que ocurra lo correcto. Los objetos definidos de tipo `openmode` son:

  • app
  • ate
  • binary
  • in
  • out
  • trunc

typedef _Ios_Seekdir std::ios_base::seekdir

Este es un tipo enumerado. _Ios_Seekdir está definido por la implementación. Los valores definidos de tipo `seekdir` son:

  • beg
  • cur, equivalente a `SEEK_CUR` en la biblioteca estándar de C.
  • end, equivalente a `SEEK_END` en la biblioteca estándar de C.

enum std::ios_base::event

El conjunto de eventos que se pueden pasar a una función de devolución de llamada de evento. `erase_event` se utiliza durante `~ios()` y `copyfmt()`. `imbue_event` se utiliza durante `imbue()`. `copyfmt_event` se utiliza durante `copyfmt()`.

Documentación de Constructores & Destructores

virtual std::ios_base::~ios_base () [virtual]

Invoca cada devolución de llamada con `erase_event`. Destruye el almacenamiento local.

Tenga en cuenta que el objeto `ios_base` para los flujos estándar nunca se destruye. Como resultado, las devoluciones de llamada registradas con los flujos estándar no se invocarán con `erase_event` (a menos que se utilice `copyfmt`).

int std::ios_base::xalloc () [static]

Acceso a índices únicos.

Devoluciones

Un entero diferente de todas las llamadas anteriores.

Esta función devuelve un entero único cada vez que se llama. Se puede utilizar para cualquier propósito, pero está pensada principalmente como un índice único para las funciones iword y pword. La expectativa es que una aplicación llame a xalloc para obtener un índice en las matrices iword y pword que se pueda usar sin temor a conflictos.

La implementación mantiene una variable estática que se incrementa y devuelve en cada invocación. Se garantiza que xalloc devuelve un índice que es seguro de usar en las matrices iword y pword.
