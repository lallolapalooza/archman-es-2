Descripción Detallada

template<typename _Tp, typename _Sequence = std::vector<_Tp>, typename _Compare = std::less<typename _Sequence::value_type>>

class std::priority_queue< _Tp, _Sequence, _Compare >"Un contenedor estándar que ordena automáticamente sus contenidos.

Parámetros de Plantilla

_Tp Tipo de elemento.
_Sequence Tipo de secuencia subyacente, por defecto es vector<_Tp>.
_Compare Tipo de objeto de función de comparación, por defecto es less<_Sequence::value_type>.

Esto no es un contenedor real, sino un adaptador. Contiene otro contenedor y proporciona una interfaz envolvente para ese contenedor. El envoltorio es lo que impone la ordenación basada en prioridad y el comportamiento de cola. Se cumplen muy pocos de los requisitos de interfaz de contenedor/secuencia estándar (por ejemplo, iteradores).

El segundo parámetro de plantilla define el tipo de la secuencia/contenedor subyacente. Por defecto es std::vector, pero puede ser cualquier tipo que admita front(), push_back, pop_back e iteradores de acceso aleatorio, como std::deque o un tipo definido por el usuario apropiado.

El tercer parámetro de plantilla proporciona los medios para realizar comparaciones de prioridad. Por defecto es less<value_type> pero puede ser cualquier cosa que defina un orden débil estricto.

Los miembros que no se encuentran en contenedores normales son container_type, que es un typedef para el segundo parámetro Sequence, y push, pop y top, que son operaciones de cola estándar.

Nota

No se proporcionan operadores de igualdad/comparación para priority_queue.

La ordenación de los elementos se produce a medida que se añaden y se retiran de la priority_queue utilizando las funciones miembro de la priority_queue. Si accede a los elementos por otros medios y cambia sus datos de manera que el orden de clasificación sería diferente, la priority_queue no volverá a ordenar los elementos por usted. Builds a queue from a range.

Parameters

__first An input iterator.
__last An input iterator.
__x A comparison functor describing a strict weak ordering.
__s An initial sequence with which to start.

Begins by copying __s, inserting a copy of the elements from [first,last) into the copy of __s, then ordering the copy according to __x.
