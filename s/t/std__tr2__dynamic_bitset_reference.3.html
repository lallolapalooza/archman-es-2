class std::tr2::dynamic_bitset< _WordT, _Alloc >::reference"Esto encapsula el concepto de un solo bit. Una instancia de esta clase es un proxy para un bit real; de esta manera, las operaciones de bits individuales se realizan como instrucciones bitwise de tamaño de palabra más rápidas.

La mayoría de los usuarios nunca necesitarán usar esta clase directamente; las conversiones desde y hacia bool son automáticas y deberían ser transparentes. Los operadores sobrecargados ayudan a preservar la ilusión.

(En un sistema típico, esta "referencia de bit" es 64 veces el tamaño de un bit real. Ja.)
