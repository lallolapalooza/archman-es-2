Descripción Detallada

template<typename _Tp, std::size_t _Nm>

struct std::array< _Tp, _Nm >"Un contenedor estándar para almacenar una secuencia de elementos de tamaño fijo.

Cumple los requisitos de un contenedor, un contenedor reversible y una secuencia.

Los conjuntos soportan iteradores de acceso aleatorio.
