PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

stdarg.h — manejar lista de argumentos variables

SINOPSIS

#include <stdarg.h>
void va_start(va_list ap, argN);
void va_copy(va_list dest, va_list src);
tipo va_arg(va_list ap, tipo);
void va_end(va_list ap);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1-2017 se remite al estándar ISO C.

La cabecera <stdarg.h> contendrá un conjunto de macros que permiten escribir funciones portátiles que aceptan listas de argumentos variables. Las funciones que tienen listas de argumentos variables (como printf()) pero que no utilizan estas macros son intrínsecamente no portátiles, ya que diferentes sistemas utilizan diferentes convenciones de paso de argumentos.

La cabecera <stdarg.h> definirá el tipo va_list para las variables utilizadas para recorrer la lista.

La macro va_start() se invoca para inicializar ap al principio de la lista antes de cualquier llamada a va_arg().

La macro va_copy() inicializa dest como una copia de src, como si la macro va_start() se hubiera aplicado a dest seguida de la misma secuencia de usos de la macro va_arg() que se había utilizado previamente para llegar al estado actual de src. Ni la macro va_copy() ni va_start() se invocarán para re-inicializar dest sin una invocación intermedia de la macro va_end() para el mismo dest.

El objeto ap puede pasarse como argumento a otra función; si esa función invoca la macro va_arg() con el parámetro ap, el valor de ap en la función que llama no está especificado y se deberá pasar a la macro va_end() antes de cualquier referencia posterior a ap. El parámetro argN es el identificador del parámetro más a la derecha en la lista de parámetros variables en la definición de la función (el que está justo antes de los ...). Si el parámetro argN se declara con la clase de almacenamiento register, con un tipo de función o tipo de matriz, o con un tipo que no es compatible con el tipo que resulta después de la aplicación de las promociones de argumentos predeterminadas, el comportamiento no está definido.

La macro va_arg() devolverá el siguiente argumento en la lista apuntada por ap. Cada invocación de va_arg() modifica ap para que los valores de los argumentos sucesivos se devuelvan en turno. El parámetro type será un nombre de tipo especificado de tal manera que el tipo de un puntero a un objeto que tenga el tipo especificado se pueda obtener simplemente añadiendo un '*' al tipo. Si no hay un siguiente argumento real, o si type no es compatible con el tipo del siguiente argumento real (promocionado según las promociones de argumentos predeterminadas), el comportamiento no está definido, excepto en los siguientes casos:

*
Un tipo es un tipo entero con signo, el otro tipo es el tipo entero sin signo correspondiente, y el valor es representable en ambos tipos.
*
Un tipo es un puntero a void y el otro es un puntero a un tipo de carácter.
*
Ambos tipos son punteros.

Se pueden mezclar diferentes tipos, pero depende de la rutina saber qué tipo de argumento se espera.

La macro va_end() se utiliza para limpiar; invalida ap para su uso (a menos que se invoque va_start() o va_copy() de nuevo).

Cada invocación de las macros va_start() y va_copy() deberá corresponderse con una invocación de la macro va_end() en la misma función.

Son posibles múltiples recorridos, cada uno delimitado por va_start() ... va_end().

Las siguientes secciones son informativas.

EJEMPLOS

Este ejemplo es una posible implementación de execl():

#include <stdarg.h>
#define  MAXARGS     31
/*
 * execl se llama mediante
 * execl(file, arg1, arg2, ..., (char *)(0));
 */
int execl(const char *file, const char *args, ...)
{
    va_list ap;
    char *array[MAXARGS +1];
    int argno = 0;
    va_start(ap, args);
    while (args != 0 && argno < MAXARGS)
    {
        array[argno++] = args;
        args = va_arg(ap, const char *);
    }
    array[argno] = (char *) 0;
    va_end(ap);
    return execv(file, array);
}

USO DE APLICACIÓN

Depende de la rutina que llama comunicar a la rutina llamada cuántos argumentos hay, ya que no siempre es posible que la rutina llamada lo determine de otra manera. Por ejemplo, a execl() se le pasa un puntero nulo para señalar el final de la lista. La función printf() puede saber cuántos argumentos hay por el argumento format.

    stdarg.h

    stdarg.h - macros para acceso a argumentos de función de lista variable

    #include <stdarg.h>

    DESCRIPCIÓN

    El archivo de cabecera <stdarg.h> define un tipo de dato, macros y una función que permiten el manejo de funciones que toman un número variable de argumentos de entrada.

    Las funciones que toman un número variable de argumentos se denominan funciones de lista variable. Los ejemplos más comunes son printf() y scanf(). Estas funciones son útiles cuando el número de argumentos que se pasan a la función no se puede determinar hasta el tiempo de ejecución.

    El tipo de dato definido en <stdarg.h> es va_list. Este tipo se utiliza para almacenar información sobre la secuencia de argumentos variables.

    Las macros definidas en <stdarg.h> son:

    • va_start(ap, last): Inicializa la variable ap (de tipo va_list) para que apunte al primer argumento variable después del último argumento con nombre last.
    • va_arg(ap, type): Devuelve el valor del siguiente argumento variable en la secuencia apuntada por ap, y avanza ap para que apunte al siguiente argumento. El tipo del argumento devuelto debe ser type.
    • va_end(ap): Limpia la variable ap (de tipo va_list). Esta macro debe ser llamada antes de que la función que utiliza argumentos variables retorne.
    • va_copy(dest, src): Copia la información de estado de src (de tipo va_list) a dest (de tipo va_list).

    La función definida en <stdarg.h> es:

    • void *va_param_ptr(va_list ap): Devuelve un puntero al siguiente argumento variable en la secuencia apuntada por ap. Esto puede ser útil para pasar punteros a argumentos variables a otras funciones.

    USO EN LA APLICACIÓN

    Las funciones de lista variable son útiles en situaciones donde el número de argumentos no se conoce de antemano. Por ejemplo, una función que toma un número variable de enteros y los suma podría usar stdarg.h para procesar los argumentos.

    
                #include <stdio.h>
                #include <stdarg.h>

                int sum_ints(int count, ...) {
                    va_list args;
                    int sum = 0;
                    int i;

                    va_start(args, count);
                    for (i = 0; i < count; i++) {
                        sum += va_arg(args, int);
                    }
                    va_end(args);
                    return sum;
                }

                int main() {
                    printf("Suma de 1, 2, 3: %d\n", sum_ints(3, 1, 2, 3));
                    printf("Suma de 10, 20, 30, 40: %d\n", sum_ints(4, 10, 20, 30, 40));
                    return 0;
                }

    FUNDAMENTO

    El uso de stdarg.h permite a los programadores escribir funciones más flexibles que pueden manejar un número variable de argumentos. Esto es especialmente útil para funciones de registro, funciones de formato y otras utilidades que necesitan operar en un conjunto de datos de tamaño desconocido.

    DIRECCIONES FUTURAS

    El estándar C ya ha incorporado mecanismos para el manejo de argumentos variables. Es poco probable que haya cambios significativos en esta área en el futuro cercano.
