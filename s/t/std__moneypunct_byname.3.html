template<typename _CharT, bool _Intl> string std::moneypunct< _CharT, _Intl >::grouping () const [inline], [inherited]

Especificación de agrupación de retorno. Esta función devuelve una cadena que representa las agrupaciones para la parte entera de un importe. Las agrupaciones indican dónde se deben insertar los separadores de miles.

Cada carácter de la cadena de retorno se interpreta como un entero en lugar de un carácter. Estos números representan el número de dígitos en un grupo. El primer carácter de la cadena representa el número de dígitos en el grupo menos significativo. Si un carácter es negativo, indica un número ilimitado de dígitos para el grupo. Si se requieren más caracteres de la cadena para agrupar un número, el último carácter se utiliza repetidamente.

Por ejemplo, si `grouping()` devuelve `\003\002` y se aplica al número 123456789, esto corresponde a 12,34,56,789. Tenga en cuenta que si la cadena fuera 32, esto colocaría más de 50 dígitos en el grupo menos significativo si el conjunto de caracteres es ASCII.

La cadena se devuelve llamando a `moneypunct<char_type>::do_grouping()`.

Devuelve

Cadena que representa la especificación de agrupación.

Referencias a do_grouping().

template<typename _CharT, bool _Intl> pattern std::moneypunct< _CharT, _Intl >::neg_format () const [inline], [inherited]

Patrón de retorno para valores monetarios. Esta función devuelve un patrón que describe el formato de un importe monetario con valor positivo o negativo. Lo hace devolviendo `moneypunct<char_type>::do_pos_format()` o `moneypunct<char_type>::do_neg_format()`.

El patrón tiene 4 campos que describen el orden del símbolo, signo, valor y ninguno o espacio. Debe haber uno de cada uno en el patrón. Los enumerados `none` y `space` no pueden aparecer en el primer campo y `space` no puede aparecer en el campo final.

Las partes de una cadena monetaria deben aparecer en el orden indicado por los campos del patrón. El campo `symbol` indica que el valor de `curr_symbol()` puede estar presente. El campo `sign` indica que el valor de `positive_sign()` o `negative_sign()` debe estar presente. El campo `value` indica que está presente el valor absoluto del importe monetario. `none` indica 0 o más caracteres de espacio en blanco, excepto al final, donde no permite espacios en blanco. `space` indica que deben estar presentes 1 o más caracteres de espacio en blanco.

Por ejemplo, para la configuración regional de EE. UU. y el patrón `pos_format()` `{symbol,sign,value,none}`, `curr_symbol()` == '$', `positive_sign()` == '+', y el valor 10.01, y las opciones establecidas para forzar el símbolo, la cadena correspondiente es $+10.01.

Devuelve

Patrón para valores monetarios.

Referencias a do_neg_format().

Detailed Description

The template classstd::moneypunct_byname is a template class that is a subclass of std::moneypunct. It is used to format and parse monetary values according to the conventions of a specific locale.

The _CharT parameter specifies the character type used by the locale (e.g., char or wchar_t). The _Intl parameter is a boolean value that indicates whether to use international monetary formatting conventions.

The constructor ofstd::moneypunct_byname takes a const char* argument that specifies the name of the locale to use. For example, to create a moneypunct_byname facet for the German locale, you would use:

std::moneypunct_byname<char> mypunct("de_DE");
