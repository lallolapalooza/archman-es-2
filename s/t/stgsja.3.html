Documentación de la función/subrutina

subroutine stgsja (character jobu, character jobv, character jobq, integer m, integer p, integer n, integer k, integer l, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real tola, real tolb, real, dimension( * ) alpha, real, dimension( * ) beta, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldv, * ) v, integer ldv, real, dimension( ldq, * ) q, integer ldq, real, dimension( * ) work, integer ncycle, integer info)

STGSJA

Propósito:

!>
!> STGSJA calcula la descomposición de valores singulares generalizada (GSVD)
!> de dos matrices reales triangulares superiores (o trapezoidales) A y B.
!>
!> A la entrada, se asume que las matrices A y B tienen las siguientes
!> formas, que pueden haber sido obtenidas por la subrutina de preprocesamiento SGGSVP
!> a partir de una matriz general M-por-N A y una matriz P-por-N B:
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> donde la matriz K-por-K A12 y la matriz L-por-L B13 son no singulares
!> triangulares superiores; A23 es L-por-L triangular superior si M-K-L >= 0,
!> de lo contrario, A23 es (M-K)-por-L trapezoidal superior.
!>
!> A la salida,
!>
!>        U**T *A*Q = D1*( 0 R ),    V**T *B*Q = D2*( 0 R ),
!>
!> donde U, V y Q son matrices ortogonales.
!> R es una matriz triangular superior no singular, y D1 y D2 son
!> matrices "diagonales", que son de las siguientes estructuras:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) a la salida.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> donde
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N) y R33 se almacena
!>     (  0  R22 R23 )
!> en B(M-K+1:L,N+M-K-L+1:N) a la salida.
!>
!> El cálculo de las matrices de transformación ortogonal U, V o Q
!> es opcional. Estas matrices pueden formarse explícitamente, o pueden
!> postmultiplicarse en las matrices de entrada U1, V1 o Q1.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U':  U debe contener una matriz ortogonal U1 a la entrada, y
!>                  el producto U1*U se devuelve;
!>          = 'I':  U se inicializa a la matriz identidad, y la
!>                  matriz ortogonal U se devuelve;
!>          = 'N':  U no se calcula.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'V':  V debe contener una matriz ortogonal V1 a la entrada, y
!>                  el producto V1*V se devuelve;
!>          = 'I':  V se inicializa a la matriz identidad, y la
!>                  matriz ortogonal V se devuelve;
!>          = 'N':  V no se calcula.
!>

JOBQ

!>          JOBQ es CHARACTER*1
!>          = 'Q':  Q debe contener una matriz ortogonal Q1 a la entrada, y
!>                  el producto Q1*Q se devuelve;
!>          = 'I':  Q se inicializa a la matriz identidad, y la
!>                  matriz ortogonal Q se devuelve;
!>          = 'N':  Q no se calcula.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.
!>

K

!>          K es INTEGER
!>

L

!>          L es INTEGER
!>
!>          K y L especifican los subbloques en las matrices de entrada A y B:
!>          A23 = A(K+1:MIN(K+L,M),N-L+1:N) y B13 = B(1:L,N-L+1:N)
!>          de A y B, cuya GSVD se va a calcular con STGSJA.
!>          Ver Detalles Adicionales.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          A la entrada, la matriz M-por-N A.
!>          A la salida, A(N-K+1:N,1:MIN(K+L,M) ) contiene la matriz
!>          triangular R o parte de R. Ver Propósito para detalles.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array REAL, de dimensión (LDB,N)
!>          A la entrada, la matriz P-por-N B.
!>          A la salida, si es necesario, B(M-K+1:L,N+M-K-L+1:N) contiene
!>          una parte de R. Ver Propósito para detalles.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,P).
!>

TOLA

!>          TOLA es REAL
!>

TOLB

!>          TOLB es REAL
!>
!>          TOLA y TOLB son los criterios de convergencia para el
!>          procedimiento de iteración Jacobi-Kogbetliantz. Generalmente, son los
!>          mismos que los utilizados en el paso de preprocesamiento, por ejemplo
!>              TOLA = max(M,N)*norm(A)*MACHEPS,
!>              TOLB = max(P,N)*norm(B)*MACHEPS.
!>

ALPHA

!>          ALPHA es un array REAL, de dimensión (N)
!>

BETA

!>          BETA es un array REAL, de dimensión (N)
!>
!>          A la salida, ALPHA y BETA contienen los pares de valores singulares
!>          generalizados de A y B;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          y si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = diag(C),
!>            BETA(K+1:K+L)  = diag(S),
!>          o si M-K-L < 0,
!>            ALPHA(K+1:M)= C, ALPHA(M+1:K+L)= 0
!>            BETA(K+1:M) = S, BETA(M+1:K+L) = 1.
!>          Además, si K+L < N,
!>            ALPHA(K+L+1:N) = 0 y
!>            BETA(K+L+1:N)  = 0.
!>

U

!>          U es un array REAL, de dimensión (LDU,M)
!>          A la entrada, si JOBU = 'U', U debe contener una matriz U1 (normalmente
!>          la matriz ortogonal devuelta por SGGSVP).
!>          A la salida,
!>          si JOBU = 'I', U contiene la matriz ortogonal U;
!>          si JOBU = 'U', U contiene el producto U1*U.
!>          Si JOBU = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M
) si !> JOBU = 'U'; LDU >= 1 en caso contrario. !>

V

!>          V es un array REAL, de dimensión (LDV,P)
!>          En la entrada, si JOBV = 'V', V debe contener una matriz V1 (normalmente
!>          la matriz ortogonal devuelta por SGGSVP).
!>          En la salida,
!>          si JOBV = 'I', V contiene la matriz ortogonal V;
!>          si JOBV = 'V', V contiene el producto V1*V.
!>          Si JOBV = 'N', V no se referencia.
!>

LDV

!>          LDV es un INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 en caso contrario.
!>

Q

!>          Q es un array REAL, de dimensión (LDQ,N)
!>          En la entrada, si JOBQ = 'Q', Q debe contener una matriz Q1 (normalmente
!>          la matriz ortogonal devuelta por SGGSVP).
!>          En la salida,
!>          si JOBQ = 'I', Q contiene la matriz ortogonal Q;
!>          si JOBQ = 'Q', Q contiene el producto Q1*Q.
!>          Si JOBQ = 'N', Q no se referencia.
!>

LDQ

!>          LDQ es un INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q'; LDQ >= 1 en caso contrario.
!>

WORK

!>          WORK es un array REAL, de dimensión (2*N)
!>

NCYCLE

!>          NCYCLE es un INTEGER
!>          El número de ciclos requeridos para la convergencia.
!>

INFO

!>          INFO es un INTEGER
!>          = 0: Salida exitosa
!>          < 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1: El procedimiento no converge después de MAXIT ciclos.
!> 
!>  Parámetros Internos
!>  ===================
!>
!>  MAXIT   INTEGER
!>          MAXIT especifica el número total de bucles que el procedimiento iterativo
!>          puede tomar. Si después de MAXIT ciclos, la rutina no logra
!>          converger, devolvemos INFO = 1.
!> .fi

Detalles adicionales:




!>
!>  STGSJA utiliza esencialmente una variante del algoritmo de Kogbetliantz para reducir
!>  la matriz triangular (o trapezoidal) de dimensión min(L,M-K)-por-L, A23, y la matriz de dimensión L-por-L, B13, a la forma:
!>
!>           U1**T *A13*Q1 = C1*R1; V1**T *B13*Q1 = S1*R1,
!>
!>  donde U1, V1 y Q1 son matrices ortogonales, y Z**T es la transpuesta
!>  de Z. C1 y S1 son matrices diagonales que satisfacen
!>
!>                C1**2 + S1**2 = I,
!>
!>  y R1 es una matriz triangular superior L-por-L no singular.
!>
