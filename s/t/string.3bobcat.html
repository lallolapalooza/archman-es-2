FBB::String(3bobcat) Operaciones en objetos std::string FBB::String(3bobcat)

NOMBRE

FBB::String - Varias operaciones en objetos std::string

SINOPSIS

#include <bobcat/string>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Esta clase ofrece facilidades para transformaciones frecuentemente usadas en objetos std::string, que no son soportadas por la clase std::string misma. Todos los miembros de FBB::String son estáticos.

Inicialmente esta clase se derivó de std::string. Sin embargo, derivar de std::string se considera un mal diseño, ya que std::string no fue diseñada como clase base.

FBB::String ofrece una serie de funciones miembro estáticas que proporcionan las facilidades implementadas originalmente como miembros no estáticos. Uno de estos miembros es el miembro split (sobrecargado), que divide una cadena en elementos separados por uno o más caracteres configurables. Estos elementos pueden contener o consistir en subcadenas con comillas dobles o simples y caracteres de escape. Los caracteres de escape se convierten a sus valores de byte implícitos (por ejemplo, \n se convierte al valor de byte 10) a menos que estén incrustados en subcadenas con comillas simples. Las comillas que rodean subcadenas con comillas dobles y simples se eliminan de los elementos devueltos por los miembros split.

ENUMERACIONES

t
Type:
Esta enumeración indica la naturaleza del contenido de un elemento en el array devuelto por los miembros split sobrecargados (ver abajo).
DQUOTE, un subconjunto de los caracteres en el elemento string coincidente fue delimitado por comillas dobles en la cadena que fue analizada por los miembros split.
DQUOTE_UNTERMINATED, el contenido de la cadena que fue analizada por los miembros split comenzó en algún momento con una comilla doble, pero faltaba la comilla doble final correspondiente.
ESCAPED_END, el contenido de la cadena que fue analizada por los miembros split terminó en una mera barra invertida.
NORMAL, una cadena normal;
SEPARATOR, un separador;
SQUOTE, un subconjunto de los caracteres en el elemento string coincidente fue delimitado por comillas en la cadena que fue analizada por los miembros split.
SQUOTE_UNTERMINATED, el contenido de la cadena que fue analizada por los miembros split comenzó en algún momento con una comilla, pero faltaba la comilla final correspondiente.
t
SplitType:
Esta enumeración se utiliza para especificar cómo los miembros split deben dividir la información en los objetos de cadena que se pasan a estos miembros:
TOK: el miembro split actúa como la función C estándar strtok(3). La esencia aquí es que no se devuelven elementos vacíos. Por ejemplo, una cadena que contiene "a,," que se procesa utilizando el modo TOK devuelve un elemento NORMAL que contiene "a".
TOKSEP: el miembro split actúa como la función C estándar strtok(3), devolviendo también información sobre los separadores encontrados. Dado que strtok no devuelve elementos vacíos, TOKSEP utiliza elementos vacíos para indicar la ocurrencia de separadores. Por ejemplo, una cadena que contiene "a,," que se procesa utilizando el modo TOKSEP devuelve un elemento NORMAL que contiene "a", seguido de dos elementos SEPARATOR vacíos.
STR: el miembro split actúa como la función C estándar strstr(3). La esencia aquí es que también se devuelven elementos vacíos. Por ejemplo, una cadena que contiene "a,," que se procesa utilizando el modo STR devuelve un elemento que contiene "a", seguido de dos elementos NORMAL vacíos.
STRSEP: el miembro split actúa como la función C estándar strstr(3), devolviendo también información sobre los separadores encontrados. Por ejemplo, una cadena que contiene "a,," que se procesa utilizando el modo STRSEP devuelve un elemento NORMAL que contiene "a", seguido de un elemento SEPARATOR que contiene ",", seguido de un elemento NORMAL vacío, seguido de un elemento SEPARATOR que contiene ",", y finalmente seguido de un elemento NORMAL vacío.

TIPO ANIDADO

La estructura SplitPair define un std::pair<std::string, String::Type> y es utilizada por algunos miembros split sobrecargados (ver abajo).

FUNCIONES MIEMBRO ESTÁTICAS

f
char const **argv(std::vector<std::string> const &words):
Devuelve un puntero a una serie asignada de punteros a las cadenas C almacenadas en el vector words. El llamador es responsable de devolver el array de punteros al pool común, pero no debe eliminar las cadenas C a las que apuntan los punteros. Se garantiza que el último elemento del array devuelto es un puntero 0.
f
int casecmp(std::string const &lhs, std::string const &rhs):
Realiza una comparación insensible a mayúsculas y minúsculas del contenido de dos objetos std::string. Se devuelve un valor negativo si lhs debe ordenarse antes que rhs; se devuelve 0 si las dos cadenas tienen contenido idéntico; se devuelve un valor positivo si el objeto lhs debe ordenarse después de rhs.
f
std::string escape(std::string const &str, char const *series = "’\"\""):
Devuelve una copia de str en la que todos los caracteres de series están precedidos por un carácter de barra invertida.
f
std::string join(std::vector<std::string> const &words, char sep):
Los elementos del vector words se devuelven como una sola cadena, separados entre sí por el carácter sep;
f
std::string join(std::vector<SplitPair> const &entries, char sep, bool all = true):
Los primeros campos de los elementos en entries se devuelven como una sola cadena, separados entre sí por el carácter sep. Si el parámetro all se especifica como false, se ignoran los elementos cuyos segundos campos son iguales a String::SEPARATOR.
f
std::string lc(std::string const &str) const:
Devuelve una copia de str en la que todas las letras fueron transformadas a minúsculas.
f
std::vector<String::SplitPair> split(std::string const &str, SplitType mode, char const *sep = " \t"):
La cadena str se divide en subcadenas, separadas por cualquiera de los caracteres en sep. Las subcadenas se devuelven en un vector de elementos SplitPair, utilizando el modo SplitType especificado (cf. la descripción de los diversos valores SplitPair y sus efectos en la sección ENUMERACIONES).
f
std::vector<String::SplitPair> split(std::string const &str, char const *separators = " \t", bool addEmpty = false):
Este miembro actúa como el anterior, utilizando addEmpty == false para seleccionar mode TOK y addEmpty == true para seleccionar el mode TOKSEP.

NAME

String - C++ String class methods

SYNOPSIS

#include <bobcat/string>

namespace FBB
{
class String
{
    public:
        // ... member functions
        enum SplitType
        {
            TOK,
            TOKSEP,
            STRSEP,
            DQUOTE,
            DQUOTE_STRSEP,
            SQUOTE,
            SQUOTE_STRSEP,
        };
        typedef std::pair<std::string, SplitType> SplitPair;
        typedef enum Type
        {
            NORMAL,
            DQUOTE_UNTERMINATED,
            SQUOTE_UNTERMINATED,
            ESCAPE_END,
        } Type;
};

// ... non-member functions
size_t split(std::vector<String::SplitPair> *entries,
            std::string const &str, String::SplitType stype,
            char const *sep = " \t");
size_t split(std::vector<std::string> *words, std::string const &str,
            String::SplitType stype, char const *sep = " \t");
std::string lc(std::string const &str);
std::string trim(std::string const &str);
std::string uc(std::string const &str);
std::string unescape(std::string const &str);
std::string urlDecode(std::string const &str);
std::string urlEncode(std::string const &str);
// ... etc.
};

DESCRIPTION

This class provides a set of overloaded static member functions for string manipulation. In addition, several non-member functions are provided for convenience.

o
size_t split(std::vector<String::SplitPair> *entries, std::string const &str, SplitType mode, char const *sep = " \t"):
Splits the string str according to the mode and the separator string sep. The resulting tokens (and their types) are stored in the vector pointed to by entries, after clearing the vector. The function returns the new size of the vector.
o
size_t split(std::vector<String::SplitPair> *entries, std::string const &str, char const *sep = " \t", bool addEmpty = false):
This is a convenience overload for the previous function. If addEmpty is false, it uses SplitType::TOK mode. If addEmpty is true, it uses SplitType::TOKSEP mode.
o
std::vector<std::string> split(Type *type, std::string const &str, SplitType stype, char const *sep = " \t"):
Splits the string str according to the stype and the separator string sep. Only the tokens themselves (not their types) are stored in the returned vector. The type parameter points to a variable that will be set to indicate the status of the last token:
  • NORMAL: The string was parsed successfully.
  • DQUOTE_UNTERMINATED: A closing double quote was missing.
  • SQUOTE_UNTERMINATED: A closing single quote was missing.
  • ESCAPE_END: The string ended with a backslash.
o
std::vector<std::string> split(Type *type, std::string const &str, char const *sep = " \t", bool addEmpty = false):
This is a convenience overload for the previous function. If addEmpty is false, it uses SplitType::TOK mode. If addEmpty is true, it uses SplitType::TOKSEP mode.
o
size_t split(std::vector<std::string> *words, std::string const &str, SplitType stype, char const *sep = " \t"):
Splits the string str according to the stype and the separator string sep. The resulting tokens are stored in the vector pointed to by words, after clearing the vector. The function returns the new size of the vector.
o
size_t split(std::vector<std::string> *words, std::string const &str, char const *sep = " \t", bool addEmpty = false):
This is a convenience overload for the previous function. If addEmpty is false, it uses SplitType::TOK mode. If addEmpty is true, it uses SplitType::TOKSEP mode.
o
std::string lc(std::string const &str):
Returns a copy of str in which all letters have been converted to lowercase.
o
std::string trim(std::string const &str):
Returns a copy of str with leading and trailing whitespace removed.
o
std::string uc(std::string const &str):
Returns a copy of str in which all letters have been converted to uppercase.
o
std::string unescape(std::string const &str):
Returns a copy of str with backslash escape sequences interpreted. Standard escape sequences like \a, \b, \f, \n, \r, \t, \v are recognized. Hexadecimal escapes of the form \xNN and octal escapes of the form \NNN are also supported. Other backslash characters are removed, and the following character is preserved.
o
std::string urlDecode(std::string const &str):
URL-encoded strings use %xx escapes for non-alphanumeric characters (except for - _ . ~). This function returns a copy of str with these escapes decoded.
o
std::string urlEncode(std::string const &str):
Returns a copy of str with characters that require URL encoding converted to %xx escapes.

EXAMPLE

#include <iostream>
#include <vector>
#include <bobcat/string>
using namespace std;
using namespace FBB;
static char const *type[] =
{
    "DQUOTE_UNTERMINATED",
    "SQUOTE_UNTERMINATED",
    "ESCAPED_END",
    "SEPARATOR",
    "NORMAL",
    "DQUOTE",
    "SQUOTE",
};
int main(int argc, char **argv)
{
    cout << "Program’s name in uppercase: " << String::uc(argv[0]) << "\n\n";
    vector<String::SplitPair> splitpair;
    string text{ "one, two, ’thr\\x65\\145’" };
    string encoded{ String::urlEncode(text) };
    cout << "The string `" << text << "’\n"
            "   as url-encoded string: `" << encoded << "’\n"
            "   and the latter string url-decoded: " <<
                                    String::urlDecode(encoded) << "\n"
            "\n"
            "Splitting `" << text << "’ into " <<
                    String::split(&splitpair, text, String::STRSEP, ", ") <<
                " fields\n";
    for (auto it = splitpair.begin(); it != splitpair.end(); ++it)
        cout << (it - splitpair.begin() + 1) << ": " <<
                type[it->second] << ": `" << it->first <<
                "’, unescaped: `" << String::unescape(it->first) <<
                "’\n";
    cout << ’\n’ <<
        text << ":\n"
        "   upper case: " << String::uc(text) << ",\n"
        "   lower case: " << String::lc(text) << ’\n’;
}
/*
    Calling the program as
        driver’
    results in the following output:
        Program’s name in uppercase: DRIVER
        Splitting `one, two, ’thr\x65\145’’ into 9 fields
        1: NORMAL: `one’, unescaped: `one’
        2: SEPARATOR: `,’, unescaped: `,’
        3: NORMAL: `’, unescaped: `’
        4: SEPARATOR: ` ’, unescaped: ` ’
        5: NORMAL: `two’, unescaped: `two’
        6: SEPARATOR: `,’, unescaped: `,’
        7: NORMAL: `’, unescaped: `’
        8: SEPARATOR: ` ’, unescaped: ` ’
        9: SQUOTE: `thr\x65\145’, unescaped: `three’
        one, two, ’thr\x65\145’:
           upper case: ONE, TWO, ’THR\X65\145’,
           lower case: one, two, ’thr\x65\145’
*/
