STBT03

Propósito:

!>
!> STBT03 calcula el residuo de la solución a un sistema triangular escalado
!> de ecuaciones  A*x = s*b  o  A'*x = s*b  cuando A es una
!> matriz triangular de banda. Aquí A' es la transpuesta de A, s es un escalar,
!> y x e b son matrices N por NRHS.  La relación de prueba es el máximo
!> sobre el número de lados derechos de
!>    norm(s*b - op(A)*x) / ( norm(op(A)) * norm(x) * EPS ),
!> donde op(A) denota A o A' y EPS es la epsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  A *x = b  (Sin transponer)
!>          = 'T':  A'*x = b  (Transpuesta)
!>          = 'C':  A'*x = b  (Transpuesta conjugada = Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales o subdiagonales de la
!>          matriz triangular de banda A.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices X e B.  NRHS >= 0.
!>

AB

!>          AB es un array REAL, dimensión (LDAB,N)
!>          La matriz triangular de banda superior o inferior A, almacenada en las
!>          primeras kd+1 filas del array. La j-ésima columna de A se almacena
!>          en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

SCALE

!>          SCALE es REAL
!>          El factor de escala s utilizado al resolver el sistema triangular.
!>

CNORM

!>          CNORM es un array REAL, dimensión (N)
!>          Las normas 1 de las columnas de A, sin contar la diagonal.
!>

TSCAL

!>          TSCAL es REAL
!>          El factor de escala utilizado al calcular las normas 1 en CNORM.
!>          CNORM contiene en realidad las normas de columna de TSCAL*A.
!>

X

!>          X es un array REAL, dimensión (LDX,NRHS)
!>          Los vectores solución calculados para el sistema de ecuaciones
!>          lineales.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

B

!>          B es un array REAL, dimensión (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un array REAL, dimensión (N)
!>

RESID

!>          RESID es REAL
!>          El máximo sobre el número de lados derechos de
!>          norm(op(A)*x - s*b) / ( norm(op(A)) * norm(x) * EPS ).
!>
