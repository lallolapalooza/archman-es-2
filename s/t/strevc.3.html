Documentación de Función/Subrutina

subroutine strevc (character side, character howmny, logical, dimension( * ) select, integer n, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, real, dimension( * ) work, integer info)

STREVC

Propósito:

!>
!> STREVC calcula algunos o todos los vectores propios derechos y/o izquierdos
!> de una matriz T real cuasi-triangular.
!> Las matrices de este tipo son producidas por la factorización de Schur de
!> una matriz general real:  A = Q*T*Q**T, como se calcula por SHSEQR.
!>
!> Los vectores propios derechos x y los vectores propios izquierdos y de T correspondientes
!> a un valor propio w se definen por:
!>
!>    T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> donde y**H denota la transpuesta conjugada de y.
!> Los valores propios no son una entrada para esta rutina, sino que se leen directamente
!> de los bloques diagonales de T.
!>
!> Esta rutina devuelve las matrices X e/o Y de vectores propios derechos e izquierdos
!> de T, o los productos Q*X y/o Q*Y, donde Q es una matriz de entrada. Si Q es el factor ortogonal que reduce una matriz
!> A a la forma de Schur T, entonces Q*X y Q*Y son las matrices de vectores propios derechos e izquierdos
!> de A.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R':  solo se calculan los vectores propios derechos;
!>          = 'L':  solo se calculan los vectores propios izquierdos;
!>          = 'B':  se calculan ambos vectores propios derechos e izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A':  se calculan todos los vectores propios derechos y/o izquierdos;
!>          = 'B':  se calculan todos los vectores propios derechos y/o izquierdos,
!>                  transformados hacia atrás por las matrices en VR y/o VL;
!>          = 'S':  se calculan los vectores propios derechos y/o izquierdos seleccionados,
!>                  como se indica en el array lógico SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los vectores propios a calcular.
!>          Si w(j) es un valor propio real, el vector propio real correspondiente
!>          se calcula si SELECT(j) es .TRUE..
!>          Si w(j) y w(j+1) son las partes real e imaginaria de un
!>          valor propio complejo, el vector propio complejo correspondiente se
!>          calcula si SELECT(j) o SELECT(j+1) es .TRUE., y
!>          a la salida, SELECT(j) se establece en .TRUE. y SELECT(j+1) se establece en
!>          .FALSE..
!>          No se referencia si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array REAL, de dimensión (LDT,N)
!>          La matriz T cuasi-triangular superior en forma canónica de Schur.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión líder del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array REAL, de dimensión (LDVL,MM)
!>          En la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de N*N (normalmente la matriz ortogonal Q
!>          de vectores de Schur devuelta por SHSEQR).
!>          En la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de vectores propios izquierdos de T;
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los vectores propios izquierdos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VL, en el mismo orden que sus
!>                           valores propios.
!>          Un vector propio complejo correspondiente a un valor propio complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real y la segunda la parte imaginaria.
!>          No se referencia si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión líder del array VL. LDVL >= 1, y si
!>          SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un array REAL, de dimensión (LDVR,MM)
!>          En la entrada, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Q de N*N (normalmente la matriz ortogonal Q
!>          de vectores de Schur devuelta por SHSEQR).
!>          En la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de vectores propios derechos de T;
!>          si HOWMNY = 'B', la matriz Q*X;
!>          si HOWMNY = 'S', los vectores propios derechos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VR, en el mismo orden que sus
!>                           valores propios.
!>          Un vector propio complejo correspondiente a un valor propio complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real y la segunda la parte imaginaria.
!>          No se referencia si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión líder del array VR. LDVR >= 1, y si
!>          SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizadas para almacenar los vectores propios.
!>          Si HOWMNY = 'A' o 'B', M se establece en N.
!>          Cada vector propio real seleccionado ocupa una columna y cada
!>          vector propio complejo seleccionado ocupa dos columnas.
!>

WORK

!>          WORK es un array REAL, de dimensión (3*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
