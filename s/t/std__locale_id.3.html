Descripción detallada

Clase de ID de facetas.

La clase ID proporciona a las facetas un índice utilizado para identificarlas. Cada clase de faceta debe definir un miembro estático público locale::id, o derivar de una faceta que proporcione este miembro, de lo contrario, la faceta no se puede utilizar en una locale. locale::id asegura que cada tipo de clase obtenga un identificador único.

template<typename _Facet> bool has_facet (const locale & __loc) [friend]

Comprueba la presencia de una faceta. has_facet comprueba la faceta del argumento locale para la presencia del tipo de faceta proporcionado como parámetro de plantilla. Las facetas derivadas del parámetro de faceta también devolverán true.

Parámetros de plantilla

_Facet El tipo de faceta para el que se comprueba la presencia.

Parámetros

__loc La locale a comprobar.

Retorna

true si __loc contiene una faceta del tipo _Facet, de lo contrario, false.

template<typename _Facet> const _Facet & use_facet (const locale & __loc) [friend]

Devuelve una faceta. use_facet busca y devuelve una referencia a una faceta del tipo Facet, donde Facet es el parámetro de plantilla. Si has_facet(locale) es true, hay una faceta adecuada para devolver. Lanza std::bad_cast si la locale no contiene una faceta del tipo Facet.

Parámetros de plantilla

_Facet El tipo de faceta al que acceder.

Parámetros

__loc La locale a utilizar.

Retorna

Referencia a la faceta del tipo Facet.

Excepciones

std::bad_cast si __loc no contiene una faceta del tipo _Facet.
