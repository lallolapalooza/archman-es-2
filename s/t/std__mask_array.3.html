Descripción Detallada

template<class _Tp>

class std::mask_array< _Tp >"Referencia a un subconjunto seleccionado de un array.

Un `mask_array` es una referencia a los elementos reales de un array especificado por una máscara de bits en forma de un array de booleanos. La forma de obtener un `mask_array` es llamar a `operator[](valarray<bool>)` en un `valarray`. El `mask_array` devuelto permite entonces realizar operaciones en el subconjunto de elementos referenciados en el `valarray` subyacente.

Por ejemplo, si se obtiene un `mask_array` utilizando el array (false, true, false, true) como argumento, el `mask_array` tendrá dos elementos que hacen referencia a `array[1]` y `array[3]` en el array subyacente.
