NAME

std::regex_iterator - Regex iterators

SYNOPSIS

#include <regex>

template<typename _Bi_iter, typename _Ch_type, typename _Rx_traits>
class std::regex_iterator;

Description

Iterators for finding matches of a regex in a sequence.

The class template regex_iterator provides an iterator interface to find all successive matches of a regular expression in a character sequence.

The iterators are templated on the type of the sequence iterator (_Bi_iter), the character type (_Ch_type), and the traits class (_Rx_traits).

A default-constructed regex_iterator is an end-of-sequence iterator. For a non-end-of-sequence iterator, regex_iterator will hold the results of applying a regular expression.

The sequence is defined by a pair of _Bi_iter iterators, a regular expression object, and optionally, flags.

The members of regex_iterator are:

operator=
Copy assigns one regex_iterator to another.
operator==
Tests the equivalence of two regex iterators.
