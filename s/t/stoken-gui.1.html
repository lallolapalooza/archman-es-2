NOMBRE

stoken-gui - token de software GTK+

SINOPSIS

stoken-gui [opciones]

DESCRIPCIÓN

stoken-gui es un token de software compatible con tokens RSA SecurID de 128 bits (AES). La interfaz gráfica de usuario proporciona soporte limitado para la entrada de contraseñas y la visualización del token actual. La importación inicial del token y otros elementos de configuración se gestionan a través de la interfaz de línea de comandos, stoken(1).

Después de usar stoken import para poblar ~/.stokenrc, se puede invocar stoken-gui para mostrar el código del token y el contador. El código del token cambia una vez por minuto; stoken-gui puede dejarse ejecutando indefinidamente y copiará el código del token actual al portapapeles bajo demanda.

Si se requiere una contraseña y/o PIN, stoken-gui mostrará un cuadro de diálogo solicitando la información apropiada.

OPCIONES

--small
Muestra una ventana mínima que solo muestra el código del token y una barra de progreso. Hacer clic en el código del token lo copia al portapapeles.
--rcfile=archivo
Usa un archivo .stokenrc alternativo. Esto se usa típicamente para soportar múltiples tokens en la misma cuenta de usuario.
--password=contraseña, -p contraseña
Usa una contraseña proporcionada desde la línea de comandos, en lugar de pedírsela al usuario. Ver las notas en CONSIDERACIONES DE SEGURIDAD en la página del manual de stoken(1).
--pin=pin, -n pin
Usa un PIN proporcionado desde la línea de comandos, en lugar de pedírselo al usuario. Ver las notas en CONSIDERACIONES DE SEGURIDAD en la página del manual de stoken(1).
--force, -f
Anula la comprobación de la fecha de caducidad del token.
--file=archivo
Usa un token del archivo en lugar del archivo .stokenrc. Solo para fines de prueba.
--token=cadena_token
Usa un token de la línea de comandos en lugar del archivo .stokenrc. Ver las notas anteriores sobre --file.
--random
Genera un token aleatorio sobre la marcha. Se usa solo para pruebas o demostraciones. Estos tokens no deben usarse para autenticación real.
--help, -h
Muestra información básica de uso.
--version, -v
Muestra información de la versión.

VER TAMBIÉN

stoken(1).

ARCHIVOS

~/.stokenrc
Archivo de configuración por defecto.
