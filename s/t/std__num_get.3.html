Descripción Detallada

template<typename _CharT, typename _InIter>

class std::num_get< _CharT, _InIter >"Plantilla de clase primaria num_get.

Este facet encapsula el código para analizar y devolver un número de una cadena. Es utilizado por los operadores de extracción numérica de istream.

La plantilla num_get utiliza funciones virtuales protegidas para proporcionar los resultados reales. Los accesores públicos reenvían la llamada a las funciones virtuales. Estas funciones virtuales son ganchos para que los desarrolladores implementen el comportamiento que requieren del facet num_get.

Análisis numérico. Analiza el flujo de entrada en la variable integral v. Lo hace llamando a num_get::do_get().

Los caracteres de entrada se analizan como el especificador g de scanf. También se utiliza el modificador de longitud de tipo coincidente.

El carácter del punto decimal utilizado es numpunct::decimal_point(). La agrupación de dígitos se interpreta de acuerdo con numpunct::grouping() y numpunct::thousands_sep(). Si el patrón de grupos de dígitos no es consistente, establece err a ios_base::failbit.

Si el análisis de la cadena produce un valor válido para v, se establece v. De lo contrario, establece err a ios_base::failbit y deja v sin modificar. Establece err a ios_base::eofbit si el flujo se vacía.

Análisis numérico. Analiza el flujo de entrada en la variable integral v. Lo hace llamando a num_get::do_get().

El análisis se ve afectado por la configuración de las banderas en io.

El análisis básico se ve afectado por el valor de io.flags() & ios_base::basefield. Si es igual a ios_base::oct, analiza como el especificador o de scanf. Si es igual a ios_base::hex, analiza como el especificador X. Si basefield es 0, analiza como el especificador i. De lo contrario, analiza como d para tipos con signo y u para tipos sin signo. También se utiliza el modificador de longitud de tipo coincidente.

La agrupación de dígitos se interpreta de acuerdo con numpunct::grouping() y numpunct::thousands_sep(). Si el patrón de grupos de dígitos no es consistente, establece err a ios_base::failbit.

Si el análisis de la cadena produce un valor válido para v, se establece v. De lo contrario, establece err a ios_base::failbit y deja v sin modificar. Establece err a ios_base::eofbit si el flujo se vacía.

Detailed Description

The class template std::num_get is an abstract base class for all numeric conversion facets. It is templated on the character type _CharT and the input iterator type _InIter.

A locale object may contain a collection of facets. The num_get facet is one of these facets. It provides the functionality for parsing numeric values from a sequence of characters.

The member function get() is the public interface for this facet. It is used to parse a numeric value from the input stream defined by the iterators __in and __end. It uses the flags in the ios_base object __io to determine the formatting of the input. It stores the parsed value in the variable __v. The error flags are updated in __err. The function returns an iterator pointing to the character immediately following the last character parsed.

The actual parsing is done by the protected virtual function do_get(). Derived classes should override this function to provide specific parsing behavior.

The behavior of get() is affected by the formatting flags set in the ios_base object __io. The following flags are relevant:

  • ios_base::basefield: This flag determines the base of the number to be parsed.
    • If it is ios_base::oct, the input is parsed as an octal number (base 8).
    • If it is ios_base::hex, the input is parsed as a hexadecimal number (base 16).
    • If it is 0, the input is parsed using the i specifier of scanf, which means that the base is inferred from the input format (e.g., 0 prefix for octal, 0x or 0X for hexadecimal, decimal otherwise).
    • Otherwise, the input is parsed as a decimal number (base 10) for signed types, or an unsigned decimal number for unsigned types.
  • Type length modifiers: The parsing also takes into account type length modifiers (e.g., h, l, ll) which affect the interpretation of the numeric value for integral types.

Digit grouping is interpreted according to the numpunct facet, specifically using numpunct::grouping() and numpunct::thousands_sep(). If the pattern of digit groups is not consistent with the locale's conventions, the ios_base::failbit is set in __err.

If the parsing is successful and yields a valid value for __v, the value of __v is updated. Otherwise, __err is set to ios_base::failbit, and __v is left unaltered.

If the entire input stream is consumed during parsing (i.e., the end of the input is reached before a complete number can be parsed), __err is set to ios_base::eofbit.
