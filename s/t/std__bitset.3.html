class std::bitset< _Nb >"La clase bitset representa una secuencia de bits de *tamaño fijo*.

(Nota que bitset *no* cumple con los requisitos formales de un contenedor. Principalmente, carece de iteradores.)

El argumento de plantilla, Nb, puede ser cualquier número no negativo, especificando el número de bits (ej. "0", "12", "1024*1024").

En el caso general no optimizado, el almacenamiento se asigna en bloques del tamaño de una palabra. Sea B el número de bits en una palabra, entonces se usarán (Nb+(B-1))/B palabras para el almacenamiento. Quedan B - NbB bits sin usar. (Son los bits de orden superior en la palabra más alta.) Es un invariante de clase que esos bits sin usar sean siempre cero.

Si piensas en bitset como *un simple array de bits*, ten en cuenta que tu imagen mental está invertida: un bitset se comporta de la misma manera

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

as bits en los enteros, con el bit en el índice 0 en la posición menos significativa / derecha, y el bit en el índice Nb-1 en la posición más significativa / izquierda. Por lo tanto, a diferencia de otros contenedores, el índice de un bitset cuenta de derecha a izquierda, por decirlo de forma muy general.

Este comportamiento se conserva al traducir a y desde cadenas. Por ejemplo, la primera línea del siguiente programa probablemente imprima b('a') es 0001100001 en un sistema ASCII moderno.

#include <bitset>
#include <iostream>
#include <sstream>
using namespace std;
int main()
{
    long         a = 'a';
    bitset<10>   b(a);
    cout << "b('a') es " << b << endl;
    ostringstream s;
    s << b;
    string  str = s.str();
    cout << "el índice 3 en la cadena es " << str[3] << " pero\n"
         << "el índice 3 en el bitset es " << b[3] << endl;
}

También ver: https://gcc.gnu.org/onlinedocs/libstdc++/manual/ext_containers.html para una descripción de las extensiones.

La mayor parte del código real no está contenido en bitset<> en sí, sino en la clase base _Base_bitset. La clase base trabaja con palabras completas, no con bits individuales. Esto nos permite especializar _Base_bitset para el caso especial importante en el que el bitset es solo una palabra única.

Puede resultar una confusión adicional debido al hecho de que el almacenamiento para _Base_bitset es una matriz regular, y se indexa como tal. Esto está cuidadosamente encapsulado.

Detailed Description

A bitset is an array of bools, of size N, where N is a compile-time constant.

The class manages a contiguous sequence of bits.

The size of the bitset is fixed at compile time.

The elements are indexed with an unsigned integer type.

These bitsets can be manipulated as a sequence of bits.

An instance of bitset< _Nb > represents a sequence of _Nb bits.

The bits are numbered from 0, starting at the least significant bit.

Example:

bitset<8> b;

The first element is b[0], and the last element is b[7].

The bitset is converted to a string, with the most significant bit first.

bitset<8> b(42);

This produces a string “00101010”.

template<size_t _Nb> bitset< _Nb >::bitset (const std::string& __str) [inline]

Constructs a bitset from a string.

The string must consist of `0` and `1` characters.

The string is interpreted with the most significant bit first.

If the string is too long, the bits that do not fit are ignored.

If the string is too short, the remaining bits are initialized to false.

Exceptions

std::invalid_argument If the string contains characters other than `0` or `1`.
