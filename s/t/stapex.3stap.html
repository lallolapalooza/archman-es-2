NOMBRE

stapex - ejemplos de systemtap

BASES DEL LENGUAJE

Estos ejemplos dan una idea de la sintaxis básica de systemtap y las estructuras de control.

global odds, evens
probe begin {
  # "no" y "ne" son enteros locales
  for (i=0; i<10; i++) {
    if (i % 2) odds [no++] = i
    else evens [ne++] = i
  }
  delete odds[2]
  delete evens[3]
  exit ()
}
probe end {
  foreach (x+ in odds) {
    printf ("odds[%d] = %d\n", x, odds[x])
  }
  foreach (x in evens-) {
    printf ("evens[%d] = %d\n", x, evens[x])
  }
}

Esto imprime:

odds[1] = 1
odds[3] = 5
odds[4] = 7
odds[5] = 9
evens[5] = 8
evens[4] = 6
evens[2] = 2
evens[1] = 0

Tenga en cuenta que todos los tipos de variables se infieren y que todas las variables locales y globales se inicializan automáticamente.

Este script imprime los números primos entre 0 y 49.

function isprime (x) {
  if (x < 2) return 0
  for (i=2; i<x; i++) {
    if (x % i == 0) return 0
    if (i * i > x) break
  }
  return 1
}
probe begin {
  for (i=0; i<50; i++)
    if (isprime (i)) printf("%d\n", i)
  exit()
}

Este script demuestra funciones recursivas.

function fibonacci(i) {
  if (i < 1) error ("número incorrecto")
  if (i == 1) return 1
  if (i == 2) return 2
  return fibonacci (i-1) + fibonacci (i-2)
}
probe begin {
  printf ("11º número de fibonacci: %d\n", fibonacci (11))
  exit ()
}

Cualquier número mayor puede exceder los límites MAXACTION o MAXNESTING, y resultar en un error.

SONDEO

Para rastrear la entrada y salida de una función, use un par de sondas:

probe kernel.function("sys_mkdir") { println ("entrada") }
probe kernel.function("sys_mkdir").return { println ("salida") }

Para listar las funciones sondeables en el kernel, use el modo de listado.

% stap -l 'kernel.function("*")'

Para listar las funciones sondeables y las variables locales en el kernel, use otro modo de listado.

% stap -L 'kernel.function("*")'
