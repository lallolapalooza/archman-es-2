DESCRIPCIÓN

La biblioteca libstatgrab proporciona una interfaz multiplataforma para obtener varias estadísticas del sistema. Las estadísticas del sistema no están estandarizadas, por lo que la biblioteca statgrab intenta elegir los valores más importantes en todos los sistemas operativos soportados. Esto implica que algunos valores podrían no estar disponibles en todos los sistemas operativos, mientras que algunos valores específicos faltan cuando no tienen contrapartes en ningún otro sistema operativo.

Libstatgrab está organizada en componentes, cada uno para estadísticas interrelacionadas.

componente estadísticas
cpu sg_cpu_stats, sg_cpu_percents
disk sg_disk_io_stats, sg_fs_stats
load sg_load_stats
mem sg_mem_stats
network sg_network_io_stats, sg_network_iface_stats
os sg_host_info

NAME

statgrab — library for retrieving system statistics

SYNOPSIS

#include <statgrab.h>

sg_error_t *sg_init();
void sg_shutdown();
const char *sg_version();

DESCRIPTION

The statgrab library is a collection of functions for retrieving system statistics. The functions are designed to be cross-platform and abstract away the differences between operating systems.

The following table lists the available statistics and the corresponding functions:

Statistic Function
CPU statistics sg_get_cpu_stats()
Disk I/O statistics sg_get_disk_io_stats()
File system statistics sg_get_fs_stats()
Host information sg_get_host_info()
Load average sg_get_load_stats()
Memory statistics sg_get_mem_stats()
Network I/O statistics sg_get_network_io_stats()
Network interface statistics sg_get_network_iface_stats()
Page statistics sg_get_page_stats()
Process statistics sg_get_process_stats(), sg_get_process_count()
Swap statistics sg_get_swap_stats()
User statistics sg_get_user_stats()

The library was originally written to support the i-scream central monitoring system, but has since become a standalone package. It has been ported to work on Linux, NetBSD, FreeBSD, OpenBSD, DragonFly BSD, Solaris, HP-UX, AIX and Cygwin.
