STRCOLL(3P) Manual del programador de POSIX STRCOLL(3P)

PROLOG

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

strcoll, strcoll_l — comparación de cadenas usando información de ordenación

SINOPSIS

#include <string.h>
int strcoll(const char *s1, const char *s2);
int strcoll_l(const char *s1, const char *s2,
    locale_t locale);

DESCRIPCIÓN

Para strcoll(): la funcionalidad descrita en esta página de referencia se alinea con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Las funciones strcoll() y strcoll_l() compararán la cadena apuntada por s1 con la cadena apuntada por s2, ambas interpretadas según corresponda a la categoría LC_COLLATE de la localidad actual, o de la localidad representada por locale, respectivamente.

Las funciones strcoll() y strcoll_l() no cambiarán la configuración de errno si tienen éxito.

Dado que no hay un valor de retorno reservado para indicar un error, una aplicación que desee comprobar situaciones de error debe establecer errno a 0, luego llamar a strcoll() o strcoll_l(), y luego comprobar errno.

El comportamiento no está definido si el argumento locale de strcoll_l() es el objeto de localidad especial LC_GLOBAL_LOCALE o no es un identificador de objeto de localidad válido.

VALOR DE RETORNO

Al completarse con éxito, strcoll() devolverá un entero mayor que, igual a, o menor que 0, según si la cadena apuntada por s1 es mayor que, igual a, o menor que la cadena apuntada por s2 cuando ambas se interpretan según corresponda a la localidad actual. En caso de error, strcoll() puede establecer errno, pero no se reserva ningún valor de retorno para indicar un error.

Al completarse con éxito, strcoll_l() devolverá un entero mayor que, igual a, o menor que 0, según si la cadena apuntada por s1 es mayor que, igual a, o menor que la cadena apuntada por s2 cuando ambas se interpretan según corresponda a la localidad representada por locale. En caso de error, strcoll_l() puede establecer errno, pero no se reserva ningún valor de retorno para indicar un error.

ERRORES

Estas funciones pueden fallar si:

EINVAL
Los argumentos s1 o s2 contienen caracteres fuera del dominio de la secuencia de ordenación.

EJEMPLOS

Comparación de Nodos

El siguiente ejemplo utiliza una función definida por la aplicación, node_compare(), para comparar dos nodos basándose en un orden alfabético del campo string.

#include <string.h>
...
struct node { /* Estos se almacenan en la tabla. */
    char *string;
    int length;
};
...
int node_compare(const void *node1, const void *node2)
{
    return strcoll(((const struct node *)node1)->string,
        ((const struct node *)node2)->string);
}
...

USO DE LA APLICACIÓN

Se deben utilizar las funciones strxfrm() y strcmp() para ordenar listas grandes.
