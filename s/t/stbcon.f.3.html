Documentación de la función/subrutina

subroutine stbcon (character norm, character uplo, character diag, integer n, integer kd, real, dimension( ldab, * ) ab, integer ldab, real rcond, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

STBCON

Propósito:

!>
!> STBCON estima la inversa del número de condición de una matriz
!> de banda triangular A, en norma 1 o en norma infinito.
!>
!> Se calcula la norma de A y se obtiene una estimación de
!> norm(inv(A)), luego se calcula la inversa del número de condición como
!> RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica si se requiere el número de condición en norma 1 o
!>          en norma infinito:
!>          = '1' o 'O':  norma 1;
!>          = 'I':         norma Infinito.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

DIAG

!>          DIAG es CHARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales o subdiagonales de la
!>          matriz de banda triangular A.  KD >= 0.
!>

AB

!>          AB es un array REAL de dimensión (LDAB,N)
!>          La matriz de banda triangular superior o inferior A, almacenada
!>          en las primeras kd+1 filas del array. La j-ésima columna de A
!>          se almacena en la j-ésima columna del array AB de la siguiente
!>          manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>          Si DIAG = 'U', los elementos diagonales de A no se referencian
!>          y se asume que son 1.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

RCOND

!>          RCOND es REAL
!>          La inversa del número de condición de la matriz A,
!>          calculada como RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK es un array REAL de dimensión (3*N)
!>

IWORK

!>          IWORK es un array INTEGER de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
