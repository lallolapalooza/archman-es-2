DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine stgexc (logical wantq, logical wantz, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldq, * ) q, integer ldq, real, dimension( ldz, * ) z, integer ldz, integer ifst, integer ilst, real, dimension( * ) work, integer lwork, integer info)

STGEXC

Propósito:

!>
!> STGEXC reordena la descomposición de Schur generalizada real de un par
!> de matrices reales (A,B) usando una transformación de equivalencia ortogonal
!>
!>                (A, B) = Q * (A, B) * Z**T,
!>
!> de modo que el bloque diagonal de (A, B) con índice de fila IFST se mueva
!> a la fila ILST.
!>
!> (A, B) debe estar en forma canónica de Schur generalizada real (como se
!> devuelve por SGGES), es decir, A es triangular superior por bloques con
!> bloques diagonales de 1x1 y 2x2. B es triangular superior.
!>
!> Opcionalmente, las matrices Q y Z de vectores de Schur generalizados se
!> actualizan.
!>
!>        Q(entrada) * A(entrada) * Z(entrada)**T = Q(salida) * A(salida) * Z(salida)**T
!>        Q(entrada) * B(entrada) * Z(entrada)**T = Q(salida) * B(salida) * Z(salida)**T
!>
!>

Parámetros

WANTQ 
!>          WANTQ es LOGICAL
!>          .TRUE. : actualizar la matriz de transformación izquierda Q;
!>          .FALSE.: no actualizar Q.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          .TRUE. : actualizar la matriz de transformación derecha Z;
!>          .FALSE.: no actualizar Z.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B. N >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, la matriz A en forma canónica de Schur generalizada
!>          real.
!>          En la salida, la matriz A actualizada, de nuevo en forma canónica
!>          de Schur generalizada real.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es array REAL, dimension (LDB,N)
!>          En la entrada, la matriz B en forma canónica de Schur generalizada
!>          real (A,B).
!>          En la salida, la matriz B actualizada, de nuevo en forma canónica
!>          de Schur generalizada real (A,B).
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

Q

!>          Q es array REAL, dimension (LDQ,N)
!>          En la entrada, si WANTQ = .TRUE., la matriz ortogonal Q.
!>          En la salida, la matriz Q actualizada.
!>          Si WANTQ = .FALSE., Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= 1.
!>          Si WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z es array REAL, dimension (LDZ,N)
!>          En la entrada, si WANTZ = .TRUE., la matriz ortogonal Z.
!>          En la salida, la matriz Z actualizada.
!>          Si WANTZ = .FALSE., Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1.
!>          Si WANTZ = .TRUE., LDZ >= N.
!>

IFST

!>          IFST es INTEGER
!>

ILST

!>          ILST es INTEGER
!>          Especifica la reordenación de los bloques diagonales de (A, B).
!>          El bloque con índice de fila IFST se mueve a la fila ILST, mediante
!>          una secuencia de intercambios entre bloques adyacentes.
!>          En la salida, si IFST apuntaba en la entrada a la segunda fila de
!>          un bloque de 2x2, se cambia para apuntar a la primera fila;
!>          ILST siempre apunta a la primera fila del bloque en su
!>          posición final (que puede diferir de su valor de entrada en
!>          +1 o -1). 1 <= IFST, ILST <= N.
!>

WORK

!>          WORK es array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= 1 cuando N <= 1, de lo contrario LWORK >= 4*N + 16.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>           =0:  salida exitosa.
!>           <0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>           =1:  La matriz par transformada (A, B) estaría demasiado lejos
!>                de la forma de Schur generalizada; el problema está mal
!>                condicionado. (A, B) puede haber sido reordenada parcialmente,
!>                y ILST apunta a la primera fila de la posición actual
!>                del bloque que se está moviendo.
!>
