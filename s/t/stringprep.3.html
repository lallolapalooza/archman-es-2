Paquete: libidn

Licencias: GPL3, LGPL

stringprep(3) libidn stringprep(3)

NOMBRE

stringprep - función de API

SINOPSIS

#include <stringprep.h>

int stringprep(char * in, size_t maxlen, Stringprep_profile_flags flags, const Stringprep_profile * profile);

ARGUMENTOS

char * in
array de entrada/salida con la cadena a preparar.
size_t maxlen
longitud máxima del array de entrada/salida.
Stringprep_profile_flags flags
un valor Stringprep_profile_flags, o 0.
const Stringprep_profile * profile
puntero a Stringprep_profile a utilizar.

DESCRIPCIÓN

Prepara la cadena de entrada UTF-8 terminada en nulo según el perfil stringprep, y escribe el resultado de vuelta en la cadena de entrada.

Tenga en cuenta que debe convertir las cadenas introducidas en la configuración regional del sistema a UTF-8 antes de usar esta función, consulte stringprep_locale_to_utf8().

Dado que la operación stringprep puede expandir la cadena, maxlen indica el tamaño del búfer que contiene la cadena. Esta función no leerá ni escribirá en caracteres fuera de ese tamaño.

Los flags son uno de los valores de Stringprep_profile_flags, o 0.

El profile contiene las instrucciones de Stringprep_profile a realizar. Su aplicación puede definir nuevos perfiles, posiblemente reutilizando las tablas genéricas de stringprep que siempre formarán parte de la biblioteca, o usar uno de los perfiles actualmente soportados.

Valor de retorno: Devuelve STRINGPREP_OK si la operación fue exitosa, o un código de error.
