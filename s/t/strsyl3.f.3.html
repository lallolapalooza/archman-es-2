Documentación de función/subrutina

subroutine strsyl3 (character trana, character tranb, integer isgn, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldc, * ) c, integer ldc, real scale, integer, dimension( * ) iwork, integer liwork, real, dimension( ldswork, * ) swork, integer ldswork, integer info)

STRSYL3

Propósito:

!>
!>  STRSYL3 resuelve la ecuación matricial de Sylvester real:
!>
!>     op(A)*X + X*op(B) = scale*C o
!>     op(A)*X - X*op(B) = scale*C,
!>
!>  donde op(A) = A o A**T, y A y B son ambas cuasi-triangulares superiores.
!>  A es M por M y B es N por N; el lado derecho C y la solución X son M por N;
!>  y scale es un factor de escala de salida, establecido en <= 1 para
!>  evitar desbordamientos en X.
!>
!>  A y B deben estar en forma canónica de Schur (como la devuelta por SHSEQR),
!>  es decir, triangular superior por bloques con bloques diagonales de 1x1 y
!>  2x2; cada bloque diagonal de 2x2 tiene sus elementos diagonales iguales
!>  y sus elementos fuera de la diagonal de signo opuesto.
!>
!>  Esta es la versión de bloque del algoritmo.
!>

Parámetros

TRANA 
!>          TRANA es CHARACTER*1
!>          Especifica la opción op(A):
!>          = 'N': op(A) = A    (Sin transposición)
!>          = 'T': op(A) = A**T (Transpuesta)
!>          = 'C': op(A) = A**H (Transpuesta conjugada = Transpuesta)
!>

TRANB

!>          TRANB es CHARACTER*1
!>          Especifica la opción op(B):
!>          = 'N': op(B) = B    (Sin transposición)
!>          = 'T': op(B) = B**T (Transpuesta)
!>          = 'C': op(B) = B**H (Transpuesta conjugada = Transpuesta)
!>

ISGN

!>          ISGN es INTEGER
!>          Especifica el signo en la ecuación:
!>          = +1: resuelve op(A)*X + X*op(B) = scale*C
!>          = -1: resuelve op(A)*X - X*op(B) = scale*C
!>

M

!>          M es INTEGER
!>          El orden de la matriz A, y el número de filas en las
!>          matrices X y C. M >= 0.
!>

N

!>          N es INTEGER
!>          El orden de la matriz B, y el número de columnas en las
!>          matrices X y C. N >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,M)
!>          La matriz A cuasi-triangular superior, en forma canónica de Schur.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array REAL, dimensión (LDB,N)
!>          La matriz B cuasi-triangular superior, en forma canónica de Schur.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

C

!>          C es un array REAL, dimensión (LDC,N)
!>          En la entrada, la matriz C del lado derecho de M por N.
!>          En la salida, C se sobrescribe con la matriz solución X.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M)
!>

SCALE

!>          SCALE es REAL
!>          El factor de escala, scale, establecido en <= 1 para evitar desbordamientos en X.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK. LIWORK >=  ((M + NB - 1) / NB + 1)
!>          + ((N + NB - 1) / NB + 1), donde NB es el tamaño de bloque óptimo.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula la dimensión óptima del array IWORK,
!>          devuelve este valor como la primera entrada del array IWORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LIWORK.
!>

SWORK

!>          SWORK es un array REAL, dimensión (MAX(2, ROWS),
!>          MAX(1,COLS)).
!>          En la salida, si INFO = 0, SWORK(1) devuelve el ROWS óptimo
!>          y SWORK(2) devuelve el COLS óptimo.
!>

LDSWORK

!>          LDSWORK es INTEGER
!>          LDSWORK >= MAX(2,ROWS), donde ROWS = ((M + NB - 1) / NB + 1)
!>          y NB es el tamaño de bloque óptimo.
!>
!>          Si LDSWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula las dimensiones óptimas de la matriz SWORK,
!>          devuelve estos valores como la primera y segunda entrada de la matriz
!>          SWORK, y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          = 1: A y B tienen valores propios comunes o muy cercanos; se usaron
!>               valores perturbados para resolver la ecuación (pero las matrices
!>               A y B no se modifican).
!>
