Detailed Description

A random number engine adapter that produces random numbers by discarding blocks of values from another random number engine.

A discard_block_engine has two parameters:

  • The first parameter, _RandomNumberEngine, is the underlying random number engine.
  • The second and third parameters, _p and _r, are unsigned integer type values. For every _p values that are returned by the underlying engine, _r values are discarded.
