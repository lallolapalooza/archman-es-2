Un generador de números aleatorios que produce números pseudaleatorios a través de la función lineal: x_{i+1} ]

El parámetro de plantilla _UIntType debe ser un tipo integral sin signo lo suficientemente grande como para almacenar valores hasta (__m-1). El tamaño del estado es $1$.

Detailed Description

This is a template class that generates pseudo-random numbers using the linear congruential method. It is defined by the recurrence relation:

    X(n+1) = (a * X(n) + c) mod m

where:

a
is the multiplier.
c
is the increment.
m
is the modulus.
X(0)
is the seed.

The template parameters are:

_UIntType
An unsigned integer type to hold the state and generated numbers.
__a
The multiplier.
__c
The increment.
__m
The modulus.
