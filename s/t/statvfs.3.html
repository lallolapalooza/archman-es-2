statvfs(3) Manual de funciones de biblioteca statvfs(3)

NOMBRE

statvfs, fstatvfs - obtener estadísticas del sistema de archivos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOSIS

#include <sys/statvfs.h>
int statvfs(const char *restrict ruta, struct statvfs *restrict buf);
int fstatvfs(int fd, struct statvfs *buf);

DESCRIPCIÓN

La función statvfs() devuelve información sobre un sistema de archivos montado. ruta es la ruta de cualquier archivo dentro del sistema de archivos montado. buf es un puntero a una estructura statvfs definida aproximadamente de la siguiente manera:


struct statvfs {
    unsigned long  f_bsize;    /* Tamaño del bloque del sistema de archivos */
    unsigned long  f_frsize;   /* Tamaño del fragmento */
    fsblkcnt_t     f_blocks;   /* Tamaño del sistema de archivos en unidades de f_frsize */
    fsblkcnt_t     f_bfree;    /* Número de bloques libres */
    fsblkcnt_t     f_bavail;   /* Número de bloques libres para
                                  usuarios no privilegiados */
    fsfilcnt_t     f_files;    /* Número de inodos */
    fsfilcnt_t     f_ffree;    /* Número de inodos libres */
    fsfilcnt_t     f_favail;   /* Número de inodos libres para
                                  usuarios no privilegiados */
    unsigned long  f_fsid;     /* ID del sistema de archivos */
    unsigned long  f_flag;     /* Banderas de montaje */
    unsigned long  f_namemax;  /* Longitud máxima del nombre de archivo */
};

Aquí los tipos fsblkcnt_t y fsfilcnt_t se definen en <sys/types.h>. Ambos solían ser unsigned long.

El campo f_flag es una máscara de bits que indica varias opciones que se emplearon al montar este sistema de archivos. Contiene cero o más de las siguientes banderas:

ST_MANDLOCK
Se permite el bloqueo obligatorio en el sistema de archivos (ver fcntl(2)).
ST_NOATIME
No actualizar los tiempos de acceso; ver mount(2).
ST_NODEV
Denegar el acceso a archivos especiales de dispositivo en este sistema de archivos.
ST_NODIRATIME
No actualizar los tiempos de acceso de los directorios; ver mount(2).
ST_NOEXEC
La ejecución de programas está prohibida en este sistema de archivos.
ST_NOSUID
Los bits set-user-ID y set-group-ID son ignorados por exec(3) para archivos ejecutables en este sistema de archivos.
ST_RDONLY
Este sistema de archivos está montado como solo lectura.
ST_RELATIME
Actualizar atime en relación con mtime/ctime; ver mount(2).
ST_SYNCHRONOUS
Las escrituras se sincronizan con el sistema de archivos inmediatamente (ver la descripción de O_SYNC en open(2)).

No está especificado si todos los miembros de la estructura devuelta tienen valores significativos en todos los sistemas de archivos.

fstatvfs() devuelve la misma información sobre un archivo abierto referenciado por el descriptor fd.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EACCES
(statvfs()) Se niega el permiso de búsqueda para un componente del prefijo de ruta de ruta. (Ver también path_resolution(7)).
EBADF
(fstatvfs()) fd no es un descriptor de archivo válido y abierto.
EFAULT
Buf o ruta apuntan a una dirección inválida.
EINTR
Esta llamada fue interrumpida por una señal; ver signal(7).
EIO
Ocurrió un error de E/S al leer del sistema de archivos.
ELOOP
(statvfs()) Se encontraron demasiados enlaces simbólicos al traducir ruta.
ENAMETOOLONG
(statvfs()) ruta es demasiado larga.
ENOENT
(statvfs()) El archivo al que se refiere ruta no existe.
ENOMEM
No había suficiente memoria del kernel disponible.
ENOSYS
El sistema de archivos no soporta esta llamada.
ENOTDIR
(statvfs()) Un componente del prefijo de ruta de ruta no es un directorio.
EOVERFLOW
Algunos valores eran demasiado grandes para ser representados en la estructura devuelta.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
statvfs (), fstatvfs () Seguridad en hilos MT-Safe

VERSIÓNES

Solo las banderas ST_NOSUID y ST_RDONLY del campo f_flag están especificadas en POSIX.1. Para obtener definiciones de las banderas restantes, se debe definir _GNU_SOURCE.

NOTAS

El kernel de Linux tiene llamadas al sistema statfs(2) y fstatfs(2) para soportar esta llamada a biblioteca.

Las implementaciones de glibc de


pathconf(ruta, _PC_REC_XFER_ALIGN);
pathconf(ruta, _PC_ALLOC_SIZE_MIN);
pathconf(ruta, _PC_REC_MIN_XFER_SIZE);

usan respectivamente los campos f_frsize, f_frsize y f_bsize devueltos por una llamada a statvfs() con el argumento ruta.

En Linux, f_favail es siempre lo mismo que f_ffree, y no hay forma de que un sistema de archivos informe lo contrario. Esto no es un problema, ya que no existen sistemas de archivos con una reserva de raíz de inodos.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

Antes de glibc 2.13, statvfs() poblaba los bits del campo f_flag escaneando las opciones de montaje mostradas en /proc/mounts. Sin embargo, a partir de Linux 2.6.36, la llamada al sistema subyacente statfs(2) proporciona la información necesaria a través del campo f_flags, y desde glibc 2.13, la función statvfs() usará la información de ese campo en lugar de escanear /proc/mounts.
