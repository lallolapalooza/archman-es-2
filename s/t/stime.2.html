stime(2) Manual de llamadas al sistema stime(2)

NOMBRE

stime - establecer hora

SINOPSIS

#include <time.h>
[[deprecated]] int stime(const time_t *t);
Requisitos de macro de prueba de características para glibc (véase feature_test_macros(7)):

stime():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _SVID_SOURCE

DESCRIPCIÓN

NOTA: Esta función está obsoleta; use clock_settime(2) en su lugar.

stime() establece la idea del sistema de la hora y la fecha. La hora, apuntada por t, se mide en segundos desde la Época, 1970-01-01 00:00:00 +0000 (UTC). Solo el superusuario puede ejecutar stime().

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EFAULT
Error al obtener información del espacio de usuario.
EPERM
El proceso que llama tiene privilegios insuficientes. En Linux, se requiere el privilegio CAP_SYS_TIME.

ESTÁNDARES

Ninguno.

HISTORIA

SVr4.

A partir de glibc 2.31, esta función ya no está disponible para aplicaciones enlazadas recientemente y ya no se declara en <time.h>.

VER TAMBIÉN

date(1), settimeofday(2), capabilities(7)
