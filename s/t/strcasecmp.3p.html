STRCASECMP(3P) Manual de programador POSIX STRCASECMP(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

strcasecmp, strcasecmp_l, strncasecmp, strncasecmp_l — comparaciones de cadenas sin distinción entre mayúsculas y minúsculas

SINOPSIS

#include <strings.h>
int strcasecmp(const char *s1, const char *s2);
int strcasecmp_l(const char *s1, const char *s2,
    locale_t locale);
int strncasecmp(const char *s1, const char *s2, size_t n);
int strncasecmp_l(const char *s1, const char *s2,
    size_t n, locale_t locale);

DESCRIPCIÓN

Las funciones strcasecmp() y strcasecmp_l() comparan, ignorando las diferencias de mayúsculas/minúsculas, la cadena apuntada por s1 con la cadena apuntada por s2. Las funciones strncasecmp() y strncasecmp_l() comparan, ignorando las diferencias de mayúsculas/minúsculas, no más de n bytes de la cadena apuntada por s1 con la cadena apuntada por s2.

Las funciones strcasecmp() y strncasecmp() utilizan la configuración regional actual para determinar la mayúscula o minúscula de los caracteres.

Las funciones strcasecmp_l() y strncasecmp_l() utilizan la configuración regional representada por locale para determinar la mayúscula o minúscula de los caracteres.

Cuando la categoría LC_CTYPE de la configuración regional que se está utilizando proviene de la configuración regional POSIX, estas funciones se comportarán como si las cadenas se hubieran convertido a minúsculas y luego se hubiera realizado una comparación de bytes. De lo contrario, los resultados no están especificados.

El comportamiento no está definido si el argumento locale a strcasecmp_l() o strncasecmp_l() es el objeto de configuración regional especial LC_GLOBAL_LOCALE o no es un manejador de objetos de configuración regional válido.

VALOR DE RETORNO

Al finalizar, strcasecmp() y strcasecmp_l() devolverán un entero mayor que, igual a, o menor que 0, si la cadena apuntada por s1 es, ignorando mayúsculas/minúsculas, mayor que, igual a, o menor que la cadena apuntada por s2, respectivamente.

Al finalizar con éxito, strncasecmp() y strncasecmp_l() devolverán un entero mayor que, igual a, o menor que 0, si el array apuntado por s1, terminado o no en nulo, es, ignorando mayúsculas/minúsculas, mayor que, igual a, o menor que el array apuntado por s2, respectivamente.
