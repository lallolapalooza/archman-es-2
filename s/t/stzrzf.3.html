subrutina stzrzf (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

STZRZF

Propósito:

!>
!> STZRZF reduce la matriz real de trapecio superior M por N ( M<=N ) A
!> a forma triangular superior mediante transformaciones ortogonales.
!>
!> La matriz de trapecio superior A se descompone como
!>
!>    A = ( R  0 ) * Z,
!>
!> donde Z es una matriz ortogonal N por N y R es una matriz triangular
!> superior M por M.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= M.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la parte principal de trapecio superior M por N de
!>          la matriz A debe contener la matriz a descomponer.
!>          En la salida, la parte principal triangular superior M por M de A
!>          contiene la matriz triangular superior R, y los elementos M+1 a
!>          N de las primeras M filas de A, junto con el array TAU,
!>          representan la matriz ortogonal Z como un producto de M
!>          reflectores elementales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es un array REAL, de dimensión (M)
!>          Los factores escalares de los reflectores elementales.
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,M).
!>          Para un rendimiento óptimo, LWORK >= M*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

!>
!>  La matriz N por N Z puede calcularse como
!>
!>     Z =  Z(1)*Z(2)* ... *Z(M)
!>
!>  donde cada Z(k) de N por N viene dada por
!>
!>     Z(k) = I - tau(k)*v(k)*v(k)**T
!>
!>  siendo v(k) el k-ésimo vector fila de la matriz M por N
!>
!>     V = ( I   A(:,M+1:N) )
!>
!>  I es la matriz identidad M por M, A(:,M+1:N)
!>  es la salida almacenada en A en la salida de STZRZF,
!>  y tau(k) es el k-ésimo elemento del array TAU.
!>
!>
