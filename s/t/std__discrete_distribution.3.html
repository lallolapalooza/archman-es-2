NAME

std::discrete_distribution - Random number distribution producing integers according to a discrete probability distribution.

SYNOPSIS

template<typename _IntType = int> class discrete_distribution {
public:
  // types
  typedef _IntType result_type;

  template<typename InputIt>
  discrete_distribution(InputIt first, InputIt last);

  typename std::conditional<true, _IntType, double>::type> ilist);
  template<typename ForwardIt>

  result_type operator()(URBG&& __g,
                         const param_type& __p);
  template<typename URBG>
  result_type operator()(URBG&& __g);
  param_type param() const;

  // modifiers
  void reset();

  template<typename URBG>
  void __populate(URBG&& __g, const param_type& __p);
};

Detailed Description

This is a C++ standard library random number distribution. It produces integers in the range [0, n-1] (where n is the number of weights) according to the discrete probability distribution specified by the given weights.
