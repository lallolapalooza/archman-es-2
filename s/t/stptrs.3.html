Documentación de función/subrutina

subroutine stptrs (character uplo, character trans, character diag, integer n, integer nrhs, real, dimension( * ) ap, real, dimension( ldb, * ) b, integer ldb, integer info)

STPTRS

Propósito:

!>
!> STPTRS resuelve un sistema triangular de la forma
!>
!>    A * X = B  o  A**T * X = B,
!>
!> donde A es una matriz triangular de orden N almacenada en formato empaquetado, y B es una matriz N por NRHS.
!>
!> Esta subrutina verifica que A no sea singular, pero los llamadores deben notar que solo se detecta la singularidad exacta. Es concebible que uno o más elementos diagonales de A sean números subnormalmente pequeños sin que esta subrutina señale un error.
!>
!> Si la pérdida de precisión numérica debido a matrices casi singulares es una preocupación, el llamador debe verificar que A no sea singular dentro de alguna tolerancia antes de llamar a esta subrutina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B  (Sin transponer)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AP

!>          AP es un array REAL, de dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por columnas en
!>          un array lineal.  La j-ésima columna de A se almacena en el array
!>          AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>

B

!>          B es un array REAL, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, si INFO = 0, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el i-ésimo elemento diagonal de A es exactamente cero,
!>                indicando que la matriz es singular y las
!>                soluciones X no se han calculado.
!>
