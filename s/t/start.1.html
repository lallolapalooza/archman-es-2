NOMBRE

start - Ejemplo de script de inicio OTP para Unix

DESCRIPCIÓN

El script start es un script de ejemplo sobre cómo iniciar el sistema Erlang en modo embebido en Unix.

Para obtener más información sobre su uso, consulte la Guía del usuario del sistema embebido en la Documentación del sistema.

start [ archivo_datos ]

Argumento:

archivo_datos

Opcional. Especifica qué archivo start_erl.data utilizar.

La variable de entorno RELDIR se puede establecer antes de llamar a este ejemplo, lo que establece el directorio donde encontrar los archivos de lanzamiento.

Ver también

run_erl(1), start_erl(1)
