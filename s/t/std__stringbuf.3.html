template<typename _CharT, typename _Traits, typename _Alloc>

class std::basic_stringbuf< _CharT, _Traits, _Alloc >

El trabajo real de entrada y salida (para std::string).

Parámetros de plantilla

_CharT Tipo de flujo de caracteres.
_Traits Rasgos para el tipo de carácter, por defecto es char_traits<_CharT>.
_Alloc Tipo de asignador, por defecto es allocator<_CharT>.

Esta clase asocia una o ambas de sus secuencias de entrada y salida con una secuencia de caracteres, que puede ser inicializada desde, o ponerse a disposición como, un std::basic_string. (Paráfrasis de [27.7.1]/1.)

Para esta clase, los modos de apertura (de tipo ios_base::openmode) tienen in establecido si la secuencia de entrada puede ser leída, y out establecido si la secuencia de salida puede ser escrita.

template<class _CharT, class _Traits, class _Alloc> basic_stringbuf< _CharT, _Traits, _Alloc >::int_type std::basic_stringbuf< _CharT, _Traits, _Alloc >::overflow (int_type __c = traits_type::eof()) [protected], [virtual]

Consume datos del buffer; escribe en la secuencia controlada.

Parámetros

__c Un carácter adicional para consumir.

Retorna

eof() para indicar fallo, algo más (normalmente __c, o not_eof())

Informalmente, esta función se llama cuando el buffer de salida está lleno (o no existe, ya que no es necesario que el buffering se realice efectivamente). Si existe un buffer, este es consumido, con algún efecto en la secuencia controlada. (Típicamente, el buffer se escribe en la secuencia tal cual.) En cualquier caso, el carácter c también se escribe, si __c no es eof().

Para una definición formal de esta función, consulte un buen texto como Langer & Kreft, o [27.5.2.4.5]/3-7.

Se puede crear un buffer de flujo de salida funcional sobrescribiendo solo esta función (no se utilizará un área de buffer).

Nota

La versión de la clase base no hace nada, retorna eof().

NAME

std::basic_stringbuf, std::stringstream, std::wstringstream - string stream buffer

         typename _Alloc = std::allocator<_CharT> >
class std::basic_stringstream : public std::basic_iostream<_CharT, _Traits>;

typedef std::basic_stringstream<char> std::stringstream;

typedef std::basic_stringstream<wchar_t> std::wstringstream;

Description

The std::basic_stringbuf class provides an interface for managing a stream of characters stored in a string. It inherits from std::basic_streambuf and implements the stream buffer logic for manipulating a sequence of characters within a string object.

There are two common typedefs:

  • std::stringstream: An alias for std::basic_stringstream<char>, used for streams of bytes (typically ASCII or UTF-8).
  • std::wstringstream: An alias for std::basic_stringstream<wchar_t>, used for streams of wide characters (typically UTF-16 or UTF-32).

The std::basic_stringstream class is built upon std::basic_stringbuf and provides an interface for performing input and output operations on a string. It inherits from std::basic_iostream.
