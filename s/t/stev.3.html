subrutina dstev (character jobz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer info)

DSTEV calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para OTRAS matrices

Propósito:

!>
!> DSTEV calcula todos los valores propios y, opcionalmente, los vectores
!> propios de una matriz tridiagonal simétrica real A.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array de DOUBLE PRECISION, dimensión (N)
!>          En la entrada, los n elementos diagonales de la matriz
!>          tridiagonal A.
!>          En la salida, si INFO = 0, los valores propios en orden
!>          ascendente.
!>

E

!>          E es un array de DOUBLE PRECISION, dimensión (N-1)
!>          En la entrada, los (n-1) elementos subdiagonales de la matriz
!>          tridiagonal A, almacenados en los elementos 1 a N-1 de E.
!>          En la salida, el contenido de E se destruye.
!>

Z

!>          Z es un array de DOUBLE PRECISION, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los vectores
!>          propios ortonormales de la matriz A, con la i-ésima columna
!>          de Z conteniendo el vector propio asociado con D(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, dimensión (max(1,2*N-2))
!>          Si JOBZ = 'N', WORK no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor
!>                ilegal
!>          > 0:  si INFO = i, el algoritmo falló en converger; i
!>                elementos fuera de la diagonal de E no convergieron a
!>                cero.
!>
