strtoimax(3) Manual de funciones de biblioteca strtoimax(3)

NOMBRE

strtoimax, strtoumax - convertir cadena a entero

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <inttypes.h>
intmax_t strtoimax(const char *restrict nptr, char **restrict endptr,
                   int base);
uintmax_t strtoumax(const char *restrict nptr, char **restrict endptr,
                   int base);

DESCRIPCIÓN

Estas funciones son iguales a strtol(3) y strtoul(3), excepto que devuelven un valor de tipo intmax_t y uintmax_t, respectivamente.

VALOR DE RETORNO

En caso de éxito, se devuelve el valor convertido. Si no se encontró nada que convertir, se devuelve cero. En caso de desbordamiento o subdesbordamiento, se devuelve INTMAX_MAX o INTMAX_MIN o UINTMAX_MAX, y errno se establece a ERANGE.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).
