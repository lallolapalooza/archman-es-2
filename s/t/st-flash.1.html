NOMBRE

st-flash - Flashea archivos binarios al dispositivo STM32

SINOPSIS

st-flash [OPCIONES] {read|write|erase} [ARCHIVO] <DIRECCION> <TAMANO>

DESCRIPCIÓN

Flashea archivos binarios a secciones arbitrarias de memoria, o lee direcciones arbitrarias de memoria a un archivo binario.

Puedes usar esto en lugar de st-util(1) si lo prefieres, pero recuerda usar la imagen .bin, en lugar del archivo .elf.

Usa formato hexadecimal para la DIRECCION y el TAMANO.

COMANDOS

write ARCHIVO DIRECCION
Escribe el firmware ARCHIVO al dispositivo comenzando desde DIRECCION
read ARCHIVO DIRECCION TAMANO
Lee el firmware del dispositivo comenzando desde DIRECCION hasta TAMANO bytes a ARCHIVO
erase
Realiza un borrado masivo del firmware del dispositivo
reset
Reinicia el objetivo

OPCIONES

--version
Imprime la información de la versión
--debug
TODO
--reset
Activa un reinicio antes y después de flashear
--opt
Habilita la optimización para ignorar los bytes finales vacíos
--serial iSerial
TODO
--flash=fsize
Donde fsize es el tamaño en decimal, octal o hexadecimal seguido de un multiplicador opcional `k' para KB, o `m' para MB. Usa un prefijo “0x” para especificar hexadecimal, o un cero inicial para octal.

EJEMPLOS

Flashea firmware.bin al dispositivo

$ st-flash write firmware.bin 0x8000000

Lee el firmware del dispositivo (4096 bytes)

$ st-flash read firmware.bin 0x8000000 0x1000

Borra el firmware del dispositivo

$ st-flash erase
