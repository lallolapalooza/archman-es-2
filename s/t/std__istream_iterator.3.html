NAME

std::istream_iterator - An iterator that reads elements from an input stream.

SYNOPSIS

#include <iterator>

Template class for input stream iterators.

Detailed Description

The std::istream_iterator is an input iterator that reads elements of type T from an input stream (std::istream). It uses the extraction operator (>>) to read elements from the stream. When the end-of-stream is reached or an error occurs during extraction, the iterator becomes equal to the default-constructed istream_iterator, which acts as the end-of-stream iterator.

Example:

#include <iostream>
#include <vector>
#include <iterator>
#include <algorithm>

int main() {
    std::cout << "Enter numbers separated by spaces: ";
    std::istream_iterator<int> input_begin(std::cin);
    std::istream_iterator<int> input_end; // Default constructor is end-of-stream iterator

    std::vector<int> numbers(input_begin, input_end);

    std::cout << "You entered: ";
    for (int num : numbers) {
        std::cout << num << " ";
    }
    std::cout << std::endl;

    return 0;
}
