Esta faceta encapsula el código para convertir un número a una cadena. Es utilizada por los operadores de inserción numérica de ostream.

La plantilla num_put utiliza funciones virtuales protegidas para proporcionar los resultados reales. Los accesores públicos reenvían la llamada a las funciones virtuales. Estas funciones virtuales son ganchos para que los desarrolladores implementen el comportamiento que requieren de la faceta num_put.

Formato numérico. Formatea el valor de punto flotante v y lo inserta en un flujo. Lo hace llamando a num_put::do_put().

El formato se ve afectado por la configuración de las banderas en io.

El formato básico se ve afectado por el valor de io.flags() & ios_base::floatfield. Si es igual a ios_base::fixed, el formato es como el especificador f de printf. Si no, si es igual a ios_base::scientific, el formato es como e o E con ios_base::uppercase sin establecer o establecido respectivamente. De lo contrario, el formato es como g o G dependiendo de uppercase. Tenga en cuenta que si tanto fixed como scientific están establecidos, el efecto también será como g o G.

La precisión de la salida viene dada por io.precision(). Esta precisión está limitada a numeric_limits::digits10 + 2 (diferente para double y long double). La precisión predeterminada es 6.

Si ios_base::showpos está establecido, se muestra '+' antes de los valores positivos. Si ios_base::showpoint está establecido, siempre se mostrará un punto decimal.

El carácter del punto decimal utilizado es numpunct::decimal_point(). Los separadores de miles se insertan según numpunct::grouping() y numpunct::thousands_sep().

Si io.width() no es cero, se insertan suficientes caracteres de relleno para que el resultado tenga al menos ese ancho. Si (io.flags() & ios_base::adjustfield) == ios_base::left, el resultado se rellena al final. Si es ios_base::internal, el relleno ocurre inmediatamente después de un '+' o '-', o después de '0x' o '0X'. De lo contrario, el relleno ocurre al principio.

DESCRIPTION

Numeric formatting. Formats the integral value v and inserts it into a stream. It does so by calling num_put::do_put().

Formatting is affected by the flag settings in io.

The basic format is affected by the value of io.flags() & ios_base::basefield. If equal to ios_base::oct, formats like the printf o specifier. Else if equal to ios_base::hex, formats like x or X with ios_base::uppercase unset or set respectively. Otherwise, formats like d, ld, lld for signed and u, lu, llu for unsigned values. Note that if both oct and hex are set, neither will take effect.

If ios_base::showpos is set, '+' is output before positive values. If ios_base::showbase is set, '0' precedes octal values (except 0) and '0[xX]' precedes hex values.

The decimal point character used is numpunct::decimal_point(). Thousands separators are inserted according to numpunct::grouping() and numpunct::thousands_sep().

If io.width() is non-zero, enough fill characters are inserted to make the result at least that wide. If (io.flags() & ios_base::adjustfield) == ios_base::left, result is padded at the end. If ios_base::internal, then padding occurs immediately after either a '+' or '-' or after '0x' or '0X'. Otherwise, padding occurs at the beginning.

Detailed Description

La plantilla de clase num_put es una faceta de std::locale que define las operaciones de formato de números en una secuencia de salida.

Esta faceta proporciona la funcionalidad para convertir tipos numéricos (enteros y de punto flotante) en una representación de caracteres, respetando la configuración regional actual.
