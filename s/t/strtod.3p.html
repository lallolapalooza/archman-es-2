PRÓLOGO

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

strtod, strtof, strtold — convertir una cadena a un número de doble precisión

SINOPSIS

#include <stdlib.h>
double strtod(const char *restrict nptr, char **restrict endptr);
float strtof(const char *restrict nptr, char **restrict endptr);
long double strtold(const char *restrict nptr, char **restrict endptr);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones convertirán la porción inicial de la cadena apuntada por nptr a representación de **double**, **float** y **long double**, respectivamente. Primero, descomponen la cadena de entrada en tres partes:

1.
Una secuencia inicial, posiblemente vacía, de caracteres de espacio en blanco (según lo especificado por isspace())
2.
Una secuencia sujeto interpretada como una constante de punto flotante o que representa infinito o NaN
3.
Una cadena final de uno o más caracteres no reconocidos, incluido el carácter NUL de terminación de la cadena de entrada

Luego, intentarán convertir la secuencia sujeto a un número de punto flotante y devolverán el resultado.

La forma esperada de la secuencia sujeto es un signo opcional de **'+'** o **'-'**, luego una de las siguientes opciones:

*
Una secuencia no vacía de dígitos decimales que opcionalmente contienen un carácter radix; luego una parte de exponente opcional que consiste en el carácter **'e'** o el carácter **'E'**, opcionalmente seguido por un carácter **'+'** o **'-'**, y luego seguido por uno o más dígitos decimales
*
Un 0x o 0X, luego una secuencia no vacía de dígitos hexadecimales que opcionalmente contienen un carácter radix; luego una parte de exponente binario opcional que consiste en el carácter **'p'** o el carácter **'P'**, opcionalmente seguido por un carácter **'+'** o **'-'**, y luego seguido por uno o más dígitos decimales
*
Uno de INF o INFINITY, ignorando mayúsculas/minúsculas
*
Uno de NAN o NAN(n-char-sequenceopt), ignorando mayúsculas/minúsculas en la parte NAN, donde:
n-char-sequence:
    digit
    nondigit
    n-char-sequence digit
    n-char-sequence nondigit

La secuencia sujeto se define como la subsecuencia inicial más larga de la cadena de entrada, comenzando con el primer carácter que no sea espacio en blanco, que tenga la forma esperada. La secuencia sujeto no contiene caracteres si la cadena de entrada no tiene la forma esperada.

Si la secuencia sujeto tiene la forma esperada para un número de punto flotante, la secuencia de caracteres que comienza con el primer dígito o el carácter de punto decimal (lo que ocurra primero) se interpretará como una constante flotante del lenguaje C, excepto que el carácter radix se utilizará en lugar de un punto, y que si ni una parte de exponente ni un carácter radix aparecen en un número decimal de punto flotante, o si un exponente binario no aparece en un número hexadecimal de punto flotante, se asumirá una parte de exponente del tipo apropiado con valor cero después del último dígito de la cadena. Si la secuencia sujeto comienza con un <guion-menos>, la secuencia se interpretará como negada. Una secuencia de caracteres INF o INFINITY se interpretarán como un infinito, si es representable en el tipo de retorno, de lo contrario, como si fuera una constante flotante demasiado grande para el rango del tipo de retorno. Una secuencia de caracteres NAN o NAN(n-char-sequenceopt) se interpretará como un NaN silencioso, si es compatible en el tipo de retorno, de lo contrario, como si fuera una parte de secuencia sujeto que no tiene la forma esperada; el significado de las secuencias n-char depende de la implementación. Se almacenará un puntero a la cadena final en el objeto al que apunta endptr, siempre que endptr no sea un puntero nulo.

Si la secuencia sujeto tiene la forma hexadecimal y FLT_RADIX es una potencia de 2, el valor resultante de la conversión se redondeará correctamente.

El carácter radix se define en la configuración regional actual (categoría LC_NUMERIC). En la configuración regional POSIX, o en una configuración regional donde el carácter radix no está definido, el carácter radix será por defecto un <punto> ('.').

En configuraciones regionales distintas de C o POSIX, se pueden aceptar formas de secuencia sujeto adicionales específicas de la configuración regional.

Si la secuencia sujeto está vacía o no tiene la forma esperada, no se realizará ninguna conversión; el valor de nptr se almacenará en el objeto al que apunta endptr, siempre que endptr no sea un puntero nulo.

Estas funciones no cambiarán la configuración de errno si tienen éxito.

Dado que se devuelve 0 en caso de error y también es un retorno válido en caso de éxito, una aplicación que desee verificar situaciones de error debe establecer errno en 0, luego llamar a strtod(), strtof(), o strtold(), luego verificar errno.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán el valor convertido. Si no se pudo realizar ninguna conversión, se devolverá 0 y errno puede establecerse en **[EINVAL]**.

Si el valor correcto está fuera del rango de los valores representables, se devolverá ±HUGE_VAL, ±HUGE_VALF, o ±HUGE_VALL (según el signo del valor), y errno se establecerá en **[ERANGE]**.

Si el valor correcto causara un subdesbordamiento, se devolverá un valor cuya magnitud no sea mayor que el número positivo normalizado más pequeño en el tipo de retorno y errno se establecerá en **[ERANGE]**.

ERRORES

Estas funciones fallarán si:

ERANGE
El valor a devolver causaría desbordamiento o subdesbordamiento.

Estas funciones pueden fallar si:

EINVAL
No se pudo realizar ninguna conversión.

strtod

PROLOG

Este es un formato de página de manual del programador de Linux. Las páginas de manual originales de POSIX suelen encontrarse en el volumen de Definiciones Base de POSIX.1-2017.

NAME

strtod, strtof, strtold — convertir una cadena a un valor de punto flotante

SYNOPSIS

       #include <stdlib.h>

       double strtod(const char *restrict nptr, char **restrict endptr);
       float strtof(const char *restrict nptr, char **restrict endptr);
       long double strtold(const char *restrict nptr, char **restrict endptr);

DESCRIPTION

Estas funciones convierten la parte inicial de la cadena apuntada por nptr en un valor de punto flotante de tipo double, float o long double.

Las funciones primero eliminan cualquier espacio en blanco inicial (como define isspace(3)) en la cadena apuntada por nptr.

Luego, intentan interpretar la cadena como un número de punto flotante. El formato del número de punto flotante es el siguiente:

[sign] [índice] [índice_número] [[.] | [índice_número] . [índice_número]] [e | E [sign] [índice]]

donde:

sign       es '+' o '-'
índice     es "0x" o "0X"
índice_número es un dígito del 0 al 9
índice_número es un dígito hexadecimal del 0 al 9, o una letra de la 'a' a la 'f' o de la 'A' a la 'F'

La conversión se detiene en el primer carácter que no es parte de un número de punto flotante válido (incluyendo un signo opcional en el exponente). Si endptr no es NULL, se establece un puntero al primer carácter no convertido.

Si la cadena apuntada por nptr no puede ser interpretada como un número, no se realiza ninguna asignación, y el valor devuelto es cero. Si endptr no es NULL, se establece en nptr.

Si ocurre un desbordamiento de rango, el valor devuelto es según lo definido en environ(7). Si el valor correcto es demasiado grande para ser representado como un double, float o long double, se devuelve un valor de rango apropiado (la más grande o la más pequeña representable) y errno se establece en ERANGE. Si el valor correcto es demasiado pequeño (demasiado cercano a cero) para ser representado, se devuelve cero y errno se establece en ERANGE.

RETURN VALUE

Estas funciones devuelven el valor de punto flotante convertido. Para obtener más detalles, consulta la descripción anterior.

ERRORS

Estas funciones pueden establecer errno en los siguientes valores:

ERANGE
Se produjo un desbordamiento de rango.

EXAMPLES

El siguiente código de ejemplo utiliza strtod para convertir una cadena en un valor de punto flotante:

#include <stdio.h>
#include <stdlib.h>

int main() {
    char *str = "123.456";
    char *endptr;
    double val;

    val = strtod(str, &endptr);

    if (endptr == str) {
        printf("No se pudo convertir la cadena.\n");
    } else if (*endptr != `\0') {
        printf("Se convirtio la parte inicial: %f\n", val);
        printf("Resto de la cadena: %s\n", endptr);
    } else {
        printf("Se convirtio toda la cadena: %f\n", val);
    }

    return 0;
}

Salida:

Se convirtio toda la cadena: 123.456000

APPLICATION USAGE

La siguiente función de ejemplo determina el tipo de número representado por una cadena:

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int what_kind_of_number(const char *s)
{
    char *endp;
    long val;

    val = strtol(s, &endp, 0);
    if (s != endp && *endp == `\0')
        printf("It's an integer with value %ld\n", val);
    else {
        double dval;
        dval = strtod(s, &endp);
        if (s != endp && *endp == `\0')
            printf("It's a float with value %g\n", dval);
        else
            return 1;
    }
    return 0;
}

Si la función se llama con:

what_kind_of_number("0x10")

una biblioteca compatible con el estándar ISO/IEC 9899:1990 dará como resultado que la función imprima:

It's an integer with value 16

Con el estándar ISO/IEC 9899:1999, el resultado es:

It's a float with value 16

El cambio de comportamiento se debe a la inclusión de números de punto flotante en notación hexadecimal sin requerir que esté presente un punto decimal o el exponente binario.
