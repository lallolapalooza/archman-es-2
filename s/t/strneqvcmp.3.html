strneqvcmp(3) Manual del programador strneqvcmp(3)

NOMBRE

strneqvcmp - compara dos cadenas con un mapeo de equivalencia

SINOPSIS

#include <tu-opts.h>
cc [...] -o archivo_salida archivo_entrada.c -lopts [...]

int strneqvcmp(char const * cadena1, char const * cadena2, int ct);

DESCRIPCIÓN

Usando un mapeo de caracteres, se comparan dos cadenas para "equivalencia". Cada carácter de entrada se mapea a un carácter de comparación y los caracteres mapeados se comparan para las dos cadenas de entrada terminadas en NUL. La comparación se limita a ct bytes. El nombre de esta función se mapea a option_strneqvcmp para no entrar en conflicto con el espacio de nombres POSIX.

cadena1
primera cadena
cadena2
segunda cadena
ct
longitud de comparación

VALOR DE RETORNO

la diferencia entre dos caracteres que difieren

ERRORES

ninguno verificado. El llamador es responsable de los fallos de segmentación.
