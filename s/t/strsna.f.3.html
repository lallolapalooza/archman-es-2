subrutina strsna (character job, character howmny, logical, dimension( * ) select, integer n, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, real, dimension( * ) s, real, dimension( * ) sep, integer mm, integer m, real, dimension( ldwork, * ) work, integer ldwork, integer, dimension( * ) iwork, integer info)

STRSNA

Propósito:

!>
!> STRSNA estima los números de condición recíprocos para valores propios y/o
!> vectores propios derechos especificados de una matriz real cuasi-triangular T
!> (o de cualquier matriz Q*T*Q**T con Q ortogonal).
!>
!> T debe estar en forma canónica de Schur (tal como la devuelve SHSEQR), es decir,
!> triangular superior por bloques con bloques diagonales de 1x1 y 2x2; cada
!> bloque diagonal de 2x2 tiene sus elementos diagonales iguales y sus
!> elementos fuera de la diagonal de signo opuesto.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          valores propios (S) o vectores propios (SEP):
!>          = 'E': solo para valores propios (S);
!>          = 'V': solo para vectores propios (SEP);
!>          = 'B': para ambos, valores propios y vectores propios (S y SEP).
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular números de condición para todos los pares propios;
!>          = 'S': calcular números de condición para pares propios seleccionados
!>                 especificados por el array SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, dimension (N)
!>          Si HOWMNY = 'S', SELECT especifica los pares propios para los que
!>          se requieren números de condición. Para seleccionar números de condición
!>          correspondientes a un valor propio real w(j),
!>          SELECT(j) debe establecerse a .TRUE.. Para seleccionar números de condición
!>          correspondientes a un par conjugado complejo de valores propios w(j)
!>          y w(j+1), SELECT(j) o SELECT(j+1) o ambos, deben
!>          establecerse a .TRUE..
!>          Si HOWMNY = 'A', SELECT no se referencia.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array REAL, dimension (LDT,N)
!>          La matriz cuasi-triangular superior T, en forma canónica de Schur.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array REAL, dimension (LDVL,M)
!>          Si JOB = 'E' o 'B', VL debe contener los vectores propios izquierdos de T
!>          (o de cualquier Q*T*Q**T con Q ortogonal), correspondientes a los
!>          pares propios especificados por HOWMNY y SELECT. Los vectores propios
!>          deben almacenarse en columnas consecutivas de VL, tal como los devuelve
!>          SHSEIN o STREVC.
!>          Si JOB = 'V', VL no se referencia.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.
!>          LDVL >= 1; y si JOB = 'E' o 'B', LDVL >= N.
!>

VR

!>          VR es un array REAL, dimension (LDVR,M)
!>          Si JOB = 'E' o 'B', VR debe contener los vectores propios derechos de T
!>          (o de cualquier Q*T*Q**T con Q ortogonal), correspondientes a los
!>          pares propios especificados por HOWMNY y SELECT. Los vectores propios
!>          deben almacenarse en columnas consecutivas de VR, tal como los devuelve
!>          SHSEIN o STREVC.
!>          Si JOB = 'V', VR no se referencia.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.
!>          LDVR >= 1; y si JOB = 'E' o 'B', LDVR >= N.
!>

S

!>          S es un array REAL, dimension (MM)
!>          Si JOB = 'E' o 'B', los números de condición recíprocos de los
!>          valores propios seleccionados, almacenados en elementos consecutivos del
!>          array. Para un par conjugado complejo de valores propios, dos
!>          elementos consecutivos de S se establecen al mismo valor. Por lo tanto,
!>          S(j), SEP(j), y las columnas j de VL y VR, todos
!>          corresponden al mismo par propio (pero no en general al
!>          j-ésimo par propio, a menos que se seleccionen todos los pares propios).
!>          Si JOB = 'V', S no se referencia.
!>

SEP

!>          SEP es un array REAL, dimension (MM)
!>          Si JOB = 'V' o 'B', los números de condición recíprocos estimados de los
!>          vectores propios seleccionados, almacenados en elementos consecutivos
!>          del array. Para un vector propio complejo, dos
!>          elementos consecutivos de SEP se establecen al mismo valor. Si
!>          los valores propios no pueden reordenarse para calcular SEP(j), SEP(j)
!>          se establece a 0; esto solo puede ocurrir cuando el valor real sería
!>          muy pequeño de todos modos.
!>          Si JOB = 'E', SEP no se referencia.
!>

MM

!>          MM es INTEGER
!>          El número de elementos en los arrays S (si JOB = 'E' o 'B')
!>           y/o SEP (si JOB = 'V' o 'B'). MM >= M.
!>

M

!>          M es INTEGER
!>          El número de elementos de los arrays S y/o SEP realmente
!>          utilizados para almacenar los números de condición estimados.
!>          Si HOWMNY = 'A', M se establece a N.
!>

WORK

!>          WORK es un array REAL, dimension (LDWORK,N+6)
!>          Si JOB = 'E', WORK no se referencia.
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          LDWORK >= 1; y si JOB = 'V' o 'B', LDWORK >= N.
!>

IWORK

!>          IWORK es un array INTEGER, dimension (2*(N-1))
!>          Si JOB = 'E', IWORK no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0: finalización exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

SYNOPSIS

 subroutine strsna( job, howmany, select, n, t, ldt, vl, ldvl, vr, ldvr,

Function/Subroutine Documentation

STRSNA estimates error bounds for the Schur vectors derived from the Schur decomposition of a triangular matrix T.

A Schur decomposition of a matrix A is an upper triangular matrix T and a unitary matrix Z such that

 A = Z * T * Z**H

where Z**H denotes the conjugate transpose of Z.

The Schur vectors are the columns of Z.

The function strsna is called by the LAPACK driver routines ZGEBAL, ZHESV, ZGESV, ZSTEDC, ZSYEV, ZSYGV, ZTGEVC, ZTGSV, ZTPSYV, ZTTRSV, ZTTRS, ZUNCSD, ZUNGES, ZUNGESV, ZUNGSV, ZUPGVD, ZUPGVX, ZUPSTEV, ZUPSTEVX, ZUPSYEV, ZUPSYEVX, ZUPTRSV, ZUPTRS.

Error estimates are computed for the Schur vectors computed by ZGEBAL (if job = 'N'), or for the left and right Schur vectors computed by ZGEBAL (if job = 'B'), or for the left Schur vectors computed by ZGEBAL (if job = 'L'), or for the right Schur vectors computed by ZGEBAL (if job = 'R').

The computation of the error bounds is based on the reciprocal condition numbers SEP(i).

Arguments:

character job
Indicates whether to estimate the error bounds for the left and/or right Schur vectors.
job = 'N': only reciprocal condition numbers for the right Schur vectors are computed.
job = 'B': reciprocal condition numbers for both left and right Schur vectors are computed.
job = 'L': only reciprocal condition numbers for the left Schur vectors are computed.
job = 'R': only reciprocal condition numbers for the right Schur vectors are computed.
character howmany
Indicates whether to estimate the error bounds for all Schur vectors or only for the selected ones.
howmany = 'A': estimate error bounds for all Schur vectors.
howmany = 'S': estimate error bounds for selected Schur vectors.
logical select( * )
Specifies the selected Schur vectors when howmany = 'S'.
integer n
The order of the upper triangular matrix T. n >= 0.
complex, dimension( ldt, * ) t
The upper triangular matrix T.
integer ldt
The leading dimension of the array T.
complex, dimension( ldvl, * ) vl
On entry, the left Schur vectors. On exit, the estimated error bounds for the left Schur vectors.
integer ldvl
The leading dimension of the array VL.
complex, dimension( ldvr, * ) vr
On entry, the right Schur vectors. On exit, the estimated error bounds for the right Schur vectors.
integer ldvr
The leading dimension of the array VR.
real eps
The machine precision of the computation.
real s( * )
On exit, the estimated error bounds for the Schur vectors.
real sep( * )
On exit, the reciprocal condition numbers for the Schur vectors.
complex work( * )
Workspace array.
integer info
0
Successful exit.
< 0
If info = -i, the i-th argument had an illegal value.

Approximate error bound for a computed right eigenvector VR(i) is given by

 EPS * norm(T) / SEP(i)
