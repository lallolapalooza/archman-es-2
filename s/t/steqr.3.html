subrutina csteqr (character compz, integer n, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer info)

CSTEQR

Propósito:

!>
!> CSTEQR calcula todos los valores propios y, opcionalmente, los vectores propios
!> de una matriz tridiagonal simétrica utilizando el método implícito QL o QR.
!> Los vectores propios de una matriz hermitiana completa o de banda también
!> pueden encontrarse si CHETRD o CHPTRD o CHBTRD se ha utilizado para reducir esta
!> matriz a forma tridiagonal.
!>

Parámetros

COMPZ 
!>          COMPZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios.
!>          = 'V':  Calcula los valores propios y los vectores propios de la
!>                  matriz hermitiana original. En la entrada, Z debe contener la
!>                  matriz unitaria utilizada para reducir la matriz original
!>                  a forma tridiagonal.
!>          = 'I':  Calcula los valores propios y los vectores propios de la
!>                  matriz tridiagonal. Z se inicializa a la matriz identidad.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array REAL, dimension (N)
!>          En la entrada, los elementos diagonales de la matriz tridiagonal.
!>          En la salida, si INFO = 0, los valores propios en orden ascendente.
!>

E

!>          E es un array REAL, dimension (N-1)
!>          En la entrada, los elementos subdiagonales (n-1) de la matriz tridiagonal.
!>          En la salida, E ha sido destruido.
!>

Z

!>          Z es un array COMPLEX, dimension (LDZ, N)
!>          En la entrada, si  COMPZ = 'V', entonces Z contiene la matriz
!>          unitaria utilizada en la reducción a forma tridiagonal.
!>          En la salida, si INFO = 0, entonces si COMPZ = 'V', Z contiene los
!>          vectores propios ortonormales de la matriz hermitiana original,
!>          y si COMPZ = 'I', Z contiene los vectores propios ortonormales
!>          de la matriz tridiagonal simétrica.
!>          Si COMPZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          se desean vectores propios, entonces  LDZ >= max(1,N).
!>

WORK

!>          WORK es un array REAL, dimension (max(1,2*N-2))
!>          Si COMPZ = 'N', entonces WORK no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  el algoritmo ha fallado en encontrar todos los valores propios en
!>                un total de 30*N iteraciones; si INFO = i, entonces i
!>                elementos de E no han convergido a cero; en la salida, D
!>                y E contienen los elementos de una matriz tridiagonal
!>                simétrica que es unitariamente similar a la matriz
!>                original.
!>

NAME

steqr, dsteqr, ssteqr, zsteqr — Computes all eigenvalues and, optionally, eigenvectors of a symmetric tridiagonal matrix

SYNOPSIS

      SUBROUTINE DSTEQR( COMPZ, N, D, E, Z, LDZ, WORK, INFO )

      SUBROUTINE SSTEQR( COMPZ, N, D, E, Z, LDZ, WORK, INFO )

      SUBROUTINE ZSTEQR( COMPZ, N, D, E, Z, LDZ, WORK, INFO )

      CHARACTER COMPZ
      INTEGER N
      REAL D( * ), E( * ), WORK( * )
      DOUBLE PRECISION D( * ), E( * ), WORK( * )
      COMPLEX*16 Z( LDZ, * )
      INTEGER LDZ, INFO

Detailed Description

The routines DSTEQR, SSTEQR, and ZSTEQR compute all eigenvalues and, optionally, eigenvectors of a symmetric tridiagonal matrix using the implicit QL or QR method. The eigenvectors of a full or band symmetric (or Hermitian) matrix can also be found if DSYTRD or SSPTRD or DSBTRD (for DSTEQR), SSYTRD or SSPTRD or SSBTRD (for SSTEQR), or ZHETRD or ZHPTRD or ZHBTRD (for ZSTEQR) has been used to reduce this matrix to tridiagonal form.

This is a wrapper for the Fortran routines.

subroutine dsteqr (character compz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer info)

DSTEQR

Purpose:

!>
!> DSTEQR computes all eigenvalues and, optionally, eigenvectors of a
!> symmetric tridiagonal matrix using the implicit QL or QR method.
!> The eigenvectors of a full or band symmetric matrix can also be found
!> if DSYTRD or DSPTRD or DSBTRD has been used to reduce this matrix to
!> tridiagonal form.
!>

Parameters

COMPZ 
!>          COMPZ is CHARACTER*1
!>          = 'N':  Compute eigenvalues only.
!>          = 'V':  Compute eigenvalues and eigenvectors of the original
!>                  symmetric matrix.  On entry, Z must contain the
!>                  orthogonal matrix used to reduce the original matrix
!>                  to tridiagonal form.
!>          = 'I':  Compute eigenvalues and eigenvectors of the
!>                  tridiagonal matrix.  Z is initialized to the identity
!>                  matrix.
!>

N

!>          N is INTEGER
!>          The order of the matrix.  N >= 0.
!>

D

!>          D is DOUBLE PRECISION array, dimension (N)
!>          On entry, the diagonal elements of the tridiagonal matrix.
!>          On exit, if INFO = 0, the eigenvalues in ascending order.
!>

E

!>          E is DOUBLE PRECISION array, dimension (N-1)
!>          On entry, the (n-1) subdiagonal elements of the tridiagonal
!>          matrix.
!>          On exit, E has been destroyed.
!>

Z

!>          Z is DOUBLE PRECISION array, dimension (LDZ, N)
!>          On entry, if  COMPZ = 'V', then Z contains the orthogonal
!>          matrix used in the reduction to tridiagonal form.
!>          On exit, if INFO = 0, then if  COMPZ = 'V', Z contains the
!>          orthonormal eigenvectors of the original symmetric matrix,
!>          and if COMPZ = 'I', Z contains the orthonormal eigenvectors
!>          of the symmetric tridiagonal matrix.
!>          If COMPZ = 'N', then Z is not referenced.
!>

LDZ

!>          LDZ is INTEGER
!>          The leading dimension of the array Z.  LDZ >= 1, and if
!>          eigenvectors are desired, then  LDZ >= max(1,N).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (max(1,2*N-2))
!>          If COMPZ = 'N', then WORK is not referenced.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  the algorithm has failed to find all the eigenvalues in
!>                a total of 30*N iterations; if INFO = i, then i
!>                elements of E have not converged to zero; on exit, D
!>                and E contain the elements of a symmetric tridiagonal
!>                matrix which is orthogonally similar to the original
!>                matrix.
!>
