class std::bitset< _Nb >::reference"Esto encapsula el concepto de un único bit. Una instancia de esta clase es un proxy para un bit real; de esta manera, las operaciones de bits individuales se realizan como instrucciones bitwise más rápidas del tamaño de palabra.

La mayoría de los usuarios nunca necesitarán usar esta clase directamente; las conversiones de y a bool son automáticas y deberían ser transparentes. Los operadores sobrecargados ayudan a preservar la ilusión.
