strfmon(3) Manual de funciones de biblioteca strfmon(3)

NOMBRE

strfmon, strfmon_l - convertir valor monetario a cadena

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <monetary.h>
ssize_t strfmon(size_t size;
                char s[restrict size], size_t size,
                const char *restrict format, ...);
ssize_t strfmon_l(size_t size;
                char s[restrict size], size_t size, locale_t l,
                const char *restrict format, ...);

DESCRIPCIÓN

La función strfmon() formatea la cantidad monetaria especificada según la configuración regional actual y la especificación de formato format y coloca el resultado en el array de caracteres s de size bytes.

La función strfmon_l() realiza la misma tarea, pero utiliza la configuración regional especificada por l. El comportamiento de strfmon_l() no está definido si l es el objeto de configuración regional especial LC_GLOBAL_LOCALE (ver duplocale(3)) o no es un manejador de objeto de configuración regional válido.

Los caracteres ordinarios en format se copian a s sin conversión. Los especificadores de conversión se introducen con un carácter '%'. Inmediatamente después, puede haber cero o más de las siguientes banderas:

=f
El carácter de un solo byte f se utiliza como carácter de relleno numérico (para usarse con una precisión izquierda, ver más abajo). Cuando no se especifica, se utiliza el carácter de espacio.
^
No utilizar ningún carácter de agrupación que pueda estar definido para la configuración regional actual. Por defecto, la agrupación está habilitada.
( o +
La bandera ( indica que las cantidades negativas deben ir entre paréntesis. La bandera + indica que los signos deben manejarse de la manera predeterminada, es decir, las cantidades van precedidas de la indicación de signo de la configuración regional, por ejemplo, nada para positivo, "-" para negativo.
!
Omitir el símbolo de la moneda.
-
Justificar a la izquierda todos los campos. La justificación a la derecha es la predeterminada.

A continuación, puede haber un ancho de campo: una cadena de dígitos que especifica un ancho de campo mínimo en bytes. El valor predeterminado es 0. Un resultado menor que este ancho se rellena con espacios (a la izquierda, a menos que se haya dado la bandera de justificación izquierda).

A continuación, puede haber una precisión izquierda de la forma "#" seguida de una cadena de dígitos. Si el número de dígitos a la izquierda del carácter de radix es menor que este, la representación se rellena a la izquierda con el carácter de relleno numérico. Los caracteres de agrupación no se cuentan en este ancho de campo.

A continuación, puede haber una precisión derecha de la forma "." seguida de una cadena de dígitos. La cantidad que se formatea se redondea al número especificado de dígitos antes de formatearla. El valor predeterminado se especifica en los elementos frac_digits e int_frac_digits de la configuración regional actual. Si la precisión derecha es 0, no se imprime ningún carácter de radix. (El carácter de radix aquí lo determina LC_MONETARY, y puede diferir del especificado por LC_NUMERIC).

Finalmente, la especificación de conversión debe terminar con un carácter de conversión. Los tres caracteres de conversión son

%
(En este caso, toda la especificación debe ser exactamente "%%".) Insertar un carácter '%' en la cadena de resultado.
i
Un argumento de tipo double se convierte utilizando el formato de moneda internacional de la configuración regional.
n
Un argumento de tipo double se convierte utilizando el formato de moneda nacional de la configuración regional.

VALOR DE RETORNO

La función strfmon() devuelve el número de caracteres colocados en el array s, sin incluir el byte nulo terminador, siempre que la cadena, incluido el byte nulo terminador, quepa. De lo contrario, establece errno en E2BIG, devuelve -1 y el contenido del array es indefinido.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

EJEMPLOS

La llamada


strfmon(buf, sizeof(buf), "[%^=*#6n] [%=*#6i]",
        1234.567, 1234.567);

genera la salida


[€ **1234,57] [EUR **1 234,57]

en la configuración regional nl_NL. Las configuraciones regionales de_DE, de_CH, en_AU y en_GB producen


[ **1234,57 €] [ **1.234,57 EUR]
[ Fr. **1234.57] [ CHF **1'234.57]
[ $**1234.57] [ AUD**1,234.57]
[ £**1234.57] [ GBP**1,234.57]
