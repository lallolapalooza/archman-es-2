STRCPY(3P) Manual de Programador POSIX STRCPY(3P)

PRÓLOGO

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

stpcpy, strcpy — copia una cadena y devuelve un puntero al final del resultado

SINOPSIS

#include <string.h>
char *stpcpy(char *restrict s1, const char *restrict s2);
char *strcpy(char *restrict s1, const char *restrict s2);

DESCRIPCIÓN

Para strcpy(): La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Las funciones stpcpy() y strcpy() copiarán la cadena apuntada por s2 (incluyendo el carácter NULO terminador) en la matriz apuntada por s1.

Si la copia se realiza entre objetos que se superponen, el comportamiento es indefinido.

VALOR DE RETORNO

La función stpcpy() devolverá un puntero al carácter NULO terminador copiado en el búfer s1.

La función strcpy() devolverá s1.

No se reservan valores de retorno para indicar un error.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Construcción de un Mensaje Multipartes en un Solo Búfer

#include <string.h>
#include <stdio.h>
int
main (void)
{
    char buffer [10];
    char *name = buffer;
    name = stpcpy (stpcpy (stpcpy (name, "hielo"),"-"), "crema");
    puts (buffer);
    return 0;
}

Inicialización de una Cadena

El siguiente ejemplo copia la cadena "----------" en la variable permstring.

#include <string.h>
...
static char permstring[11];
...
strcpy(permstring, "----------");
...

Almacenamiento de una Clave y Datos

El siguiente ejemplo reserva espacio para una clave usando malloc() y luego utiliza strcpy() para colocar la clave allí. Luego reserva espacio para datos usando malloc(), y utiliza strcpy() para colocar los datos allí. (La función definida por el usuario dbfree() libera memoria previamente asignada a una matriz de tipo struct element *.)

#include <string.h>
#include <stdlib.h>
#include <stdio.h>
...
/* Estructura utilizada para leer datos y almacenarlos. */
struct element {
    char *key;
    char *data;
};
struct element *tbl, *curtbl;
char *key, *data;
int count;
...
void dbfree(struct element *, int);
...
if ((curtbl->key = malloc(strlen(key) + 1)) == NULL) {
    perror("malloc"); dbfree(tbl, count); return NULL;
}
strcpy(curtbl->key, key);
if ((curtbl->data = malloc(strlen(data) + 1)) == NULL) {
    perror("malloc"); free(curtbl->key); dbfree(tbl, count); return NULL;
}
strcpy(curtbl->data, data);
...

USO EN APLICACIONES

El movimiento de caracteres se realiza de forma diferente en distintas implementaciones. Por lo tanto, los movimientos superpuestos pueden dar lugar a sorpresas.

Esta versión está alineada con el estándar ISO C; esto no afecta a la compatibilidad con aplicaciones XPG3. La detección fiable de errores por parte de esta función nunca estuvo garantizada.
