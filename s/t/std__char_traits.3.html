Nota

Para cualquier tipo de carácter real dado, esta definición probablemente sea incorrecta. Dado que esto es solo un envoltorio delgado alrededor de __gnu_cxx::char_traits, es posible lograr una definición más apropiada especializando __gnu_cxx::char_traits.

Ver https://gcc.gnu.org/onlinedocs/libstdc++/manual/strings.html#strings.string.character_types para obtener consejos sobre cómo usar esta clase para tipos de caracteres *inusuales*. Además, echa un vistazo a include/ext/pod_string.
