STRTOK(3P) Manual de Programador POSIX STRTOK(3P)

PRÓLOGO

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

strtok, strtok_r — dividir una cadena en tokens

SINOPSIS

#include <string.h>
char *strtok(char *restrict s, const char *restrict sep);
char *strtok_r(char *restrict s, const char *restrict sep,
    char **restrict state);

DESCRIPCIÓN

Para strtok(): la funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencionado. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Una secuencia de llamadas a strtok() divide la cadena apuntada por s en una secuencia de tokens, cada uno de los cuales está delimitado por un byte de la cadena apuntada por sep. La primera llamada de la secuencia tiene s como su primer argumento, y le siguen llamadas con un puntero nulo como su primer argumento. La cadena de separadores apuntada por sep puede ser diferente en cada llamada.

La primera llamada de la secuencia busca en la cadena apuntada por s el primer byte que no esté contenido en la cadena separadora actual apuntada por sep. Si no se encuentra dicho byte, entonces no hay tokens en la cadena apuntada por s y strtok() devolverá un puntero nulo. Si se encuentra dicho byte, es el inicio del primer token.

La función strtok() busca entonces a partir de ahí un byte que esté contenido en la cadena separadora actual. Si no se encuentra dicho byte, el token actual se extiende hasta el final de la cadena apuntada por s, y las búsquedas posteriores de un token devolverán un puntero nulo. Si se encuentra dicho byte, se sobrescribe con un carácter NUL, que termina el token actual. La función strtok() guarda un puntero al byte siguiente, desde el cual comenzará la siguiente búsqueda de un token.

Cada llamada subsiguiente, con un puntero nulo como valor del primer argumento, comienza la búsqueda desde el puntero guardado y se comporta como se describe anteriormente.

La implementación se comportará como si ninguna función definida en este volumen de POSIX.1‐2017 llamara a strtok().

La función strtok() no necesita ser segura para hilos.

La función strtok_r() será equivalente a strtok(), excepto que strtok_r() será segura para hilos y el argumento state apunta a un puntero proporcionado por el usuario que permite a strtok_r() mantener el estado entre llamadas que analizan la misma cadena. La aplicación garantizará que el puntero apuntado por state sea único para cada cadena (s) que se procese concurrentemente mediante llamadas a strtok_r(). La aplicación no necesita inicializar el puntero apuntado por state a ningún valor particular. La implementación no actualizará el puntero apuntado por state para que apunte (directa o indirectamente) a recursos, distintos de dentro de la cadena s, que deban ser liberados por el llamador.

VALOR DE RETORNO

Tras una finalización exitosa, strtok() devolverá un puntero al primer byte de un token. De lo contrario, si no hay ningún token, strtok() devolverá un puntero nulo.

La función strtok_r() devolverá un puntero al token encontrado, o un puntero nulo cuando no se encuentre ningún token.

ERRORES

No se definen errores.

EJEMPLOS

Búsqueda de separadores de palabras

El siguiente ejemplo busca tokens separados por caracteres de <espacio>.

#include <string.h>
...
char *token;
char line[] = "LINEA A SER SEPARADA";
char *search = " ";
/* Token apuntará a "LINEA". */
token = strtok(line, search);
/* Token apuntará a "A". */
token = strtok(NULL, search);

Encontrar los dos primeros campos en un búfer

El siguiente ejemplo utiliza strtok() para encontrar dos cadenas de caracteres (una clave y datos asociados a esa clave) separadas por cualquier combinación de caracteres de <espacio>, <tabulador> o <nueva línea> al principio del array de caracteres apuntado por buffer.

#include <string.h>
...
char    *buffer;
...
struct element {
    char *key;
    char *data;
} e;
...
// Cargar el búfer...
...
// Obtener la clave y sus datos...
e.key = strtok(buffer, " \t\n");
e.data = strtok(NULL, " \t\n");
// Procesar el resto del contenido del búfer...
...

USO DE LA APLICACIÓN

Tenga en cuenta que si sep es una cadena vacía, strtok() y strtok_r() devuelven un puntero al resto de la cadena que se está tokenizando.

La función strtok_r() es segura para hilos y almacena su estado en un búfer proporcionado por el usuario en lugar de utilizar posiblemente un área de datos estática que pueda ser sobrescrita por una llamada no relacionada desde otro hilo.

FUNDAMENTO

La función strtok() busca una cadena separadora dentro de una cadena más grande. Devuelve un puntero a la última subcadena entre cadenas separadoras. Esta función utiliza almacenamiento estático para llevar un registro de la posición actual de la cadena entre llamadas. La nueva función, strtok_r(), toma un argumento adicional, state, para llevar un registro de la posición actual en la cadena.
