NAME

__ctype_abstract_base — información de caracter y conversión

SYNOPSIS

#include <locale>

template<typename CharT> class __ctype_abstract_base;

Detailed Description

Interfaz de clase base abstracta para clases de categorización de caracteres.

La clase de localización std::ctype proporciona servicios para la clasificación y transformación de caracteres, basados en la configuración regional actual. La implementación específica para una localición dada hereda de std::ctype, la cual a su vez deriva de __ctype_abstract_base.

La clase __ctype_abstract_base declara la interfaz virtual pura que las clases concretas de categorización de caracteres deben implementar. Estos métodos incluyen:

  • do_isctype(): Devuelve si un carácter pertenece a una clase de caracteres dada (por ejemplo, alfanumérico, dígito, etc.).
  • do_tolower(): Convierte un carácter a minúsculas.
  • do_toupper(): Convierte un carácter a mayúsculas.
  • do_wint_type(): Devuelve una cadena de clasificación de tipo de ancho para un entero de caracteres.
  • do_scan_not(): Escanea una cadena buscando un carácter que no pertenezca a un conjunto específico.
  • do_scan(): Escanea una cadena buscando un carácter que pertenezca a un conjunto específico.

La clase std::ctype utiliza estos métodos para proporcionar la funcionalidad de categorización y conversión de caracteres a través de la interfaz de C++ estándar.

Member Typedef Documentation

Esta clase define varios tipos, como char_type, que es el tipo de carácter subyacente con el que opera la faceta de local. Para la mayoría de las implementaciones, esto será char.

Member Function Documentation

Los métodos virtuales puros do_...() son los que definen la interfaz principal para la categorización y conversión de caracteres. Las implementaciones concretas de esta clase deben proporcionar definiciones para estos métodos.

  • char_type do_tolower (char_type c) const
  • char_type do_toupper (char_type c) const
  • int do_wint_type (wint_t c) const
  • const char_type* do_scan_not (const char_type* first, const char_type* last, char_type c) const
