Descripción Detallada

template<typename _Tp, typename _Alloc>

class std::_Deque_base< _Tp, _Alloc >"Clase base Deque. Esta clase proporciona la interfaz unificada para la asignación del deque. El constructor y destructor de esta clase asignan y liberan (pero no inicializan) almacenamiento. Esto facilita la seguridad ante excepciones.

Nada en esta clase construye o destruye jamás un elemento Tp real. (Deque se encarga de eso por sí mismo). Aquí solo se realiza la gestión de memoria.
