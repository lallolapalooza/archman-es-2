Documentación de Función/Subrutina

subroutine strevc3 (character side, character howmny, logical, dimension( * ) select, integer n, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, real, dimension( * ) work, integer lwork, integer info)

STREVC3

Propósito:

!>
!> STREVC3 calcula algunos o todos los autovectores derechos y/o izquierdos de
!> una matriz T cuasi-triangular real.
!> Las matrices de este tipo son producidas por la factorización de Schur de
!> una matriz general real: A = Q*T*Q**T, como es calculada por SHSEQR.
!>
!> El autovector derecho x y el autovector izquierdo y de T correspondientes
!> a un autovalor w se definen por:
!>
!>    T*x = w*x,     (y**T)*T = w*(y**T)
!>
!> donde y**T denota la transpuesta del vector y.
!> Los autovalores no son una entrada para esta rutina, sino que se leen directamente
!> de los bloques diagonales de T.
!>
!> Esta rutina devuelve las matrices X y/o Y de autovectores derechos e izquierdos
!> de T, o los productos Q*X y/o Q*Y, donde Q es una matriz de entrada. Si Q es el factor ortogonal que reduce una matriz
!> A a la forma de Schur T, entonces Q*X y Q*Y son las matrices de autovectores derechos e izquierdos de A.
!>
!> Esto utiliza una versión de BLAS de Nivel 3 de la retrotransformación.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R':  calcular solo autovectores derechos;
!>          = 'L':  calcular solo autovectores izquierdos;
!>          = 'B':  calcular ambos autovectores derechos e izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A':  calcular todos los autovectores derechos y/o izquierdos;
!>          = 'B':  calcular todos los autovectores derechos y/o izquierdos,
!>                  retrotransformados por las matrices en VR y/o VL;
!>          = 'S':  calcular autovectores derechos y/o izquierdos seleccionados,
!>                  como se indica en el array lógico SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los autovectores a calcular.
!>          Si w(j) es un autovalor real, el autovector real correspondiente
!>          se calcula si SELECT(j) es .TRUE..
!>          Si w(j) y w(j+1) son las partes real e imaginaria de un
!>          autovalor complejo, el autovector complejo correspondiente se
!>          calcula si either SELECT(j) o SELECT(j+1) es .TRUE., y
!>          a la salida SELECT(j) se establece a .TRUE. y SELECT(j+1) se establece a
!>          .FALSE..
!>          No se referencia si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array REAL, de dimensión (LDT,N)
!>          La matriz cuasi-triangular superior T en forma canónica de Schur.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array REAL, de dimensión (LDVL,MM)
!>          A la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de N*N (usualmente la matriz ortogonal Q
!>          de vectores de Schur devuelta por SHSEQR).
!>          A la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de autovectores izquierdos de T;
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los autovectores izquierdos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VL, en el mismo orden que sus
!>                           autovalores.
!>          Un autovector complejo correspondiente a un autovalor complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real, y la segunda la imaginaria.
!>          No se referencia si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.
!>          LDVL >= 1, y si SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un array REAL, de dimensión (LDVR,MM)
!>          A la entrada, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Q de N*N (usualmente la matriz ortogonal Q
!>          de vectores de Schur devuelta por SHSEQR).
!>          A la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de autovectores derechos de T;
!>          si HOWMNY = 'B', la matriz Q*X;
!>          si HOWMNY = 'S', los autovectores derechos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VR, en el mismo orden que sus
!>                           autovalores.
!>          Un autovector complejo correspondiente a un autovalor complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real y la segunda la imaginaria.
!>          No se referencia si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.
!>          LDVR >= 1, y si SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizadas para almacenar los autovectores.
!>          Si HOWMNY = 'A' o 'B', M se establece a N.
!>          Cada autovector real seleccionado ocupa una columna y cada
!>          autovector complejo seleccionado ocupa dos columnas.
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,3*N).
!>          Para un rendimiento óptimo, LWORK >= N + 2*N*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y ningún mensaje de error
!>          relacionado con LWORK es emitido por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  El algoritmo utilizado en este programa es básicamente una sustitución hacia atrás (hacia adelante),
!>  con escalado para hacer que el código sea robusto contra
!>  posibles desbordamientos.
!>
!>  Cada autovector se normaliza para que el elemento de mayor
!>  magnitud tenga magnitud 1; aquí la magnitud de un número complejo
!>  (x,y) se toma como |x| + |y|.
!>
