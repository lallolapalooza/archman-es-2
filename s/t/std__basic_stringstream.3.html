Descripción detallada

template<typename _CharT, typename _Traits, typename _Alloc>

class std::basic_stringstream< _CharT, _Traits, _Alloc >

Controla la entrada y salida para `std::string`.

Parámetros de plantilla

_CharT Tipo de flujo de caracteres.
_Traits Rasgos para el tipo de carácter, por defecto `char_traits`<`_CharT`>.
_Alloc Tipo de asignador, por defecto `allocator`<`_CharT`>.

Esta clase soporta la lectura y escritura de objetos de tipo `std::basic_string`, utilizando las funciones heredadas de `std::basic_iostream`. Para controlar la secuencia asociada, se utiliza una instancia de `std::basic_stringbuf`, a la que esta página se refiere como `sb`.

Documentación de typedefs de miembros

typedef void(* std::ios_base::event_callback) (event __e, ios_base &__b, int __i) [inherited]

El tipo de una función de devolución de llamada de evento.

Parámetros

__e Uno de los miembros de la enumeración `event`.
__b Referencia al objeto `ios_base`.
__i El entero proporcionado cuando se registró la devolución de llamada.

Las devoluciones de llamada de eventos son funciones definidas por el usuario que se llaman durante varias funciones de `ios_base` y `basic_ios`, específicamente `imbue()`, `copyfmt()`, y `~ios()`.

typedef _Ios_Iostate std::ios_base::iostate [inherited]

Este es un tipo de máscara de bits. `_Ios_Iostate` es de implementación definida, pero es válido realizar operaciones bit a bit con estos valores y esperar que ocurra lo correcto. Los objetos definidos de tipo `iostate` son:

  • badbit
  • eofbit
  • failbit
  • goodbit

typedef _Ios_Openmode std::ios_base::openmode [inherited]

Este es un tipo de máscara de bits. `_Ios_Openmode` es de implementación definida, pero es válido realizar operaciones bit a bit con estos valores y esperar que ocurra lo correcto. Los objetos definidos de tipo `openmode` son:

  • app
  • ate
  • binary
  • in
  • out
  • trunc

typedef _Ios_Seekdir std::ios_base::seekdir [inherited]

Este es un tipo enumerado. `_Ios_Seekdir` es de implementación definida. Los valores definidos de tipo `seekdir` son:

  • beg
  • cur, equivalente a `SEEK_CUR` en la biblioteca estándar de C.
  • end, equivalente a `SEEK_END` en la biblioteca estándar de C.

Documentación de constructores y destructores

template<typename _CharT, typename _Traits, typename _Alloc> std::basic_stringstream< _CharT, _Traits, _Alloc >::basic_stringstream () [inline]

Constructor predeterminado que comienza con un búfer de cadena vacío. Inicializa `sb` utilizando el modo `in|out`, y pasa `&sb` al inicializador de la clase base. No asigna ningún búfer.

Eso es mentira. Inicializamos la clase base con NULL, porque la clase string gestiona su propia gestión de memoria.
