Documentación de Función/Subrutina

subroutine strrfs (character uplo, character trans, character diag, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

STRRFS

Propósito:

!>
!> STRRFS proporciona límites de error y estimaciones de error hacia atrás para la
!> solución de un sistema de ecuaciones lineales con una matriz de coeficiente
!> triangular.
!>
!> La matriz solución X debe ser calculada por STRTRS o algún otro
!> medio antes de entrar en esta rutina. STRRFS no realiza refinamiento iterativo
!> porque hacerlo no puede mejorar el error hacia atrás.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U': A es triangular superior;
!>          = 'L': A es triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N': A * X = B (Sin transposición)
!>          = 'T': A**T * X = B (Transpuesta)
!>          = 'C': A**H * X = B (Transpuesta conjugada = Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          = 'N': A es triangular no unitaria;
!>          = 'U': A es triangular unitaria.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

A

!>          A es un array REAL, dimension (LDA,N)
!>          La matriz triangular A. Si UPLO = 'U', la parte superior triangular
!>          de N por N de la matriz A contiene la matriz triangular superior,
!>          y la parte estrictamente triangular inferior de A no se referencia.
!>          Si UPLO = 'L', la parte inferior triangular de N por N de la matriz A
!>          contiene la matriz triangular inferior, y la parte estrictamente
!>          triangular superior de A no se referencia. Si DIAG = 'U', los
!>          elementos diagonales de A tampoco se referencian y se asumen como 1.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array REAL, dimension (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array REAL, dimension (LDX,NRHS)
!>          La matriz solución X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X. LDX >= max(1,N).
!>

FERR

!>          FERR es un array REAL, dimension (NRHS)
!>          El límite de error hacia adelante estimado para cada vector solución
!>          X(j) (la columna j de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande en X(j).
!>          La estimación es tan fiable como la estimación de RCOND, y es casi
!>          siempre un ligero sobreestimación del error real.
!>

BERR

!>          BERR es un array REAL, dimension (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector
!>          solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array REAL, dimension (3*N)
!>

IWORK

!>          IWORK es un array INTEGER, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>
