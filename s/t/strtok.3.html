strtok(3) Manual de Funciones de Biblioteca strtok(3)

NOMBRE

strtok, strtok_r - extraer tokens de cadenas

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <string.h>
char *strtok(char *_Nullable restrict str, const char *restrict delim);
char *strtok_r(char *_Nullable restrict str, const char *restrict delim,
               char **restrict saveptr);
Requisitos de Macro de Prueba de Características para glibc (ver feature_test_macros(7)):

strtok_r():

    _POSIX_C_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

La función strtok() divide una cadena en una secuencia de cero o más tokens no vacíos. En la primera llamada a strtok(), la cadena a analizar debe especificarse en str. En llamadas subsiguientes que deban analizar la misma cadena, str debe ser NULL.

El argumento delim especifica un conjunto de bytes que delimitan los tokens en la cadena analizada. El llamador puede especificar cadenas diferentes en delim en llamadas sucesivas que analicen la misma cadena.

Cada llamada a strtok() devuelve un puntero a una cadena terminada en nulo que contiene el siguiente token. Esta cadena no incluye el byte delimitador. Si no se encuentran más tokens, strtok() devuelve NULL.

Una secuencia de llamadas a strtok() que operan sobre la misma cadena mantiene un puntero que determina el punto desde el cual comenzar a buscar el siguiente token. La primera llamada a strtok() hace que este puntero apunte al primer byte de la cadena. El inicio del siguiente token se determina escaneando hacia adelante para encontrar el siguiente byte no delimitador en str. Si se encuentra dicho byte, se toma como el inicio del siguiente token. Si no se encuentra dicho byte, entonces no hay más tokens y strtok() devuelve NULL. (Una cadena que esté vacía o que contenga solo delimitadores hará que strtok() devuelva NULL en la primera llamada).

El final de cada token se encuentra escaneando hacia adelante hasta que se encuentra el siguiente byte delimitador o hasta que se encuentra el byte nulo de terminación ('\0'). Si se encuentra un byte delimitador, se sobrescribe con un byte nulo para terminar el token actual, y strtok() guarda un puntero al byte siguiente; ese puntero se usará como punto de partida al buscar el siguiente token. En este caso, strtok() devuelve un puntero al inicio del token encontrado.

De la descripción anterior, se deduce que una secuencia de dos o más bytes delimitadores contiguos en la cadena analizada se considera un solo delimitador, y los bytes delimitadores al principio o al final de la cadena se ignoran. Dicho de otra manera: los tokens devueltos por strtok() son siempre cadenas no vacías. Por lo tanto, por ejemplo, dada la cadena "aaa;;bbb,", las llamadas sucesivas a strtok() que especifiquen la cadena delimitadora ";," devolverían las cadenas "aaa" y "bbb", y luego un puntero nulo.

La función strtok_r() es una versión reentrante de strtok(). El argumento saveptr es un puntero a una variable de tipo char * que es utilizada internamente por strtok_r() para mantener el contexto entre llamadas sucesivas que analizan la misma cadena.

En la primera llamada a strtok_r(), str debe apuntar a la cadena que se va a analizar, y el valor de *saveptr se ignora (pero ver VERSIONES). En llamadas subsiguientes, str debe ser NULL, y saveptr (y el búfer al que apunta) deben ser inalterados desde la llamada anterior.

Se pueden analizar diferentes cadenas concurrentemente utilizando secuencias de llamadas a strtok_r() que especifiquen diferentes argumentos saveptr.

VALOR DE RETORNO

Las funciones strtok() y strtok_r() devuelven un puntero al siguiente token, o NULL si no hay más tokens.

ERRORES

Tenga cuidado al usar estas funciones. Si las utiliza, tenga en cuenta que:

•
Estas funciones modifican su primer argumento.
•
Estas funciones no se pueden usar en cadenas constantes.
•
Se pierde la identidad del byte delimitador.
•
La función strtok() utiliza un búfer estático mientras analiza, por lo que no es segura para hilos. Utilice strtok_r() si esto le importa.

EJEMPLOS

El programa a continuación utiliza bucles anidados que emplean strtok_r() para dividir una cadena en una jerarquía de dos niveles de tokens. El primer argumento de la línea de comandos especifica la cadena que se va a analizar. El segundo argumento especifica el byte o bytes delimitadores que se utilizarán para separar esa cadena en tokens "principales". El tercer argumento especifica el byte o bytes delimitadores que se utilizarán para separar los tokens "principales" en sub-tokens.

Un ejemplo de la salida producida por este programa es el siguiente:


$ ./a.out 'a/bbb///cc;xxx:yyy:' ':;' '/'
1: a/bbb///cc
         --> a
         --> bbb
         --> cc
2: xxx
         --> xxx
3: yyy
         --> yyy

Fuente del programa

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int
main(int argc, char *argv[])
{
    char *str1, *str2, *token, *subtoken;
    char *saveptr1, *saveptr2;
    int j;
    if (argc != 4) {
        fprintf(stderr, "Uso: %s cadena delim subdelim\n",
                argv[0]);
        exit(EXIT_FAILURE);
    }
    for (j = 1, str1 = argv[1]; ; j++, str1 = NULL) {
        token = strtok_r(str1, argv[2], &saveptr1);
        if (token == NULL)
            break;
        printf("%d: %s\n", j, token);
        for (str2 = token; ; str2 = NULL) {
            subtoken = strtok_r(str2, argv[3], &saveptr2);
            if (subtoken == NULL)
                break;
            printf("\t --> %s\n", subtoken);
        }
    }
    exit(EXIT_SUCCESS);
}

Otro programa de ejemplo que utiliza strtok() se puede encontrar en getaddrinfo_a(3).
