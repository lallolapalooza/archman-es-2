STAPBPF(8) Manual del Administrador del Sistema STAPBPF(8)

NOMBRE

stapbpf - tiempo de ejecución BPF de Systemtap

SINOPSIS

stapbpf [ OPCIONES ] MÓDULO

DESCRIPCIÓN

El programa stapbpf es el backend BPF de la herramienta Systemtap. Espera un archivo bpf-elf producido por la herramienta front-end stap, cuando se ejecuta con --runtime=bpf.

Dividir la herramienta systemtap en un front-end y un back-end permite a un usuario compilar un script de systemtap en una máquina de desarrollo que tenga la información de depuración necesaria para compilar el script y luego transferir el objeto compartido resultante a una máquina de producción que no tenga instaladas herramientas de desarrollo ni información de depuración.

Por favor, consulte stappaths(7) para el número de versión, o ejecute

$ rpm -q systemtap # (para Fedora/RHEL)
$ apt-get -v systemtap # (para Ubuntu)

OPCIONES

El programa stapbpf admite las siguientes opciones. Cualquier otra opción imprime una lista de opciones admitidas.

-v
Modo verboso.
-V
Imprime el número de versión y sale.
-w
Suprime advertencias del script.
-h
Imprime el mensaje de ayuda.
-x PID
La variable '_stp_target' se establecerá en PID.
-o ARCHIVO
Envía la salida al ARCHIVO.

ARGUMENTOS

MÓDULO es la ruta de un archivo bpf-elf producido por la herramienta front-end stap, cuando se ejecuta con --runtime=bpf.

EJEMPLOS

Aquí hay un ejemplo muy básico de cómo generar un módulo stapbpf. Primero, use stap para compilar un script. El programa stap informará el nombre del módulo resultante en el directorio de trabajo actual.

$ stap --runtime=bpf -p4 -e 'probe begin { printf("Hola Mundo!\n"); exit() }'
stap_28784.bo

Ejecute stapbpf con la ruta del módulo como argumento.

$ stapbpf ./stap_28784.bo
Hola Mundo!

Si se omite la opción -p4, stap invocará stapbpf automáticamente.

LIMITACIONES

Este tiempo de ejecución está en una etapa temprana de desarrollo y actualmente carece de soporte para una serie de características disponibles en el tiempo de ejecución predeterminado. Se admite un subconjunto de los siguientes puntos de sondeo:

begin
end
kernel.*
process.*
timer.*
perf.*
procfs.*

En general, se admiten los sondeos basados en las infraestructuras kprobes, uprobes, tracepoint y perf. Consulte stapprobes(3stap) para obtener más información sobre los puntos de sondeo y en qué infraestructuras de trazado se basan.

Los bucles for, foreach y while solo se pueden utilizar en los sondeos begin y end. Las sentencias try no se admiten.

Hay un soporte limitado para operaciones de cadenas. Las variables y literales de cadena están limitados a 64 caracteres, excepto las cadenas de formato de printf, que están limitadas a 256 caracteres.

Se dispone de un subconjunto de la funcionalidad de agregación estadística, con soporte solo para las funciones extractoras @count(), @sum() y @avg().

No se debe cambiar el nombre del archivo bpf-elf producido por la herramienta front-end stap.

SEGURIDAD Y PROTECCIÓN

Consulte la página del manual de stap(1) para obtener información adicional sobre seguridad y protección.
