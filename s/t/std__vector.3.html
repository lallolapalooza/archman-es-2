Detailed Description

template<typename _Tp, typename _Alloc = std::allocator<_Tp>>

class std::vector< _Tp, _Alloc >"A standard container which offers fixed time access to individual elements in any order.

Since

C++98

Template Parameters

_Tp Type of element.
_Alloc Allocator type, defaults to allocator<_Tp>.

Meets the requirements of a container, a reversible container, and a sequence, including the optional sequence requirements with the exception of push_front and pop_front.

In some terminology a vector can be described as a dynamic C-style array, it offers fast and efficient access to individual elements in any order and saves the user from worrying about memory and size allocation. Subscripting ( [] ) access is also provided as with C-style arrays.

Parámetros

__first Un iterador de entrada.
__last Un iterador de entrada.
__a Un asignador.

Crea un vector que consiste en copias de los elementos de [first,last).

Si los iteradores son forward, bidirectional o random-access, entonces esto llamará al constructor de copia de los elementos N veces (donde N es distance(first,last)) y no realizará ninguna realocación de memoria. Pero si solo se usan iteradores de entrada, entonces esto realizará como máximo 2N llamadas al constructor de copia y logN realocaciones de memoria.

Intenta preasignar suficiente memoria para el número especificado de elementos.

__n Número de elementos requeridos.

Excepciones

Esta función intenta reservar suficiente memoria para que el vector albergue el número especificado de elementos. Si el número solicitado es mayor que max_size(), se lanza length_error.

La ventaja de esta función es que si el código óptimo es una necesidad y el usuario puede determinar el número de elementos que se requerirán, el usuario puede reservar la memoria con anticipación y, por lo tanto, evitar una posible reasignación de memoria y copia de datos del vector.

NAME

std::vector - Vector

SYNOPSIS

template<typename _Tp, typename _Alloc = std::allocator<_Tp>> class std::vector< _Tp, _Alloc >

Detailed Description

A dynamic array.

A vector is a sequence container representing a contiguous sequence of objects. When the sequence exceeds its capacity, it is expanded by allocating a new block of memory and copying/moving existing elements to it. Vectors are typically implemented as dynamic arrays.

Template Parameters

_Tp Type of elements stored in the vector.

_Alloc Allocator type for memory management. Defaults to std::allocator<_Tp>.
