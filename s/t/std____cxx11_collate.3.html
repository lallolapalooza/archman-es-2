La plantilla collate utiliza funciones virtuales protegidas para proporcionar los resultados reales. Los accesores públicos reenvían la llamada a las funciones virtuales. Detailed Description

The objects of this class template provide collation (that is, dictionary-order) comparisons and transformations of character sequences, according to the character classification and conversion facets of the accessed locale.

The primary function is the comparison of two sequences, using the compare member function.

The transform member function provides a way to modify sequences so that they can be compared using the standard string comparison operators. This is primarily useful for implementing sort operations that are locale-aware.

The hash member function provides a hash value for a sequence, useful for implementing lookup operations.

Transform string to comparable form. This function is a wrapper for strxfrm functionality. It takes the input string and returns a modified string that can be directly compared to other transformed strings. In the C locale, this function just returns a copy of the input string. In some other locales, it may replace two chars with one, change a char for another, etc. It does so by returning collate::do_transform().
