Descripción Detallada

Datos de ordenación del formato de moneda.

Esta clase contiene una matriz ordenada de 4 campos para representar el patrón para dar formato a una cantidad de dinero. Cada campo puede contener una entrada de la enumeración part. symbol, sign y value deben estar presentes y el campo restante debe contener none o space.

Ver también

moneypunct::pos_format() y moneypunct::neg_format() para obtener detalles sobre cómo se interpretan estos campos.
