PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

stdio.h — entrada/salida en búfer estándar

SINOPSIS

#include <stdio.h>

DESCRIPCIÓN

Parte de la funcionalidad descrita en esta página de referencia extiende el estándar ISO C. Las aplicaciones definirán la macro de prueba de características apropiada (consulte el volumen de Interfaces del Sistema de POSIX.1‐2017, Sección 2.2, El Entorno de Compilación) para habilitar la visibilidad de estos símbolos en esta cabecera.

La cabecera <stdio.h> definirá los siguientes tipos de datos mediante typedef:

FILE
Una estructura que contiene información sobre un archivo.
fpos_t
Un tipo no-array que contiene toda la información necesaria para especificar únicamente cada posición dentro de un archivo.
off_t
Como se describe en <sys/types.h>.
size_t
Como se describe en <stddef.h>.
ssize_t
Como se describe en <sys/types.h>.
va_list
Como se describe en <stdarg.h>.

La cabecera <stdio.h> definirá las siguientes macros que se expandirán a expresiones constantes enteras:

BUFSIZ
Tamaño de los búferes de <stdio.h>. Esto se expandirá a un valor positivo.
L_ctermid
Tamaño máximo de un array de caracteres para contener la salida de ctermid().
L_tmpnam
Tamaño máximo de un array de caracteres para contener la salida de tmpnam().

La cabecera <stdio.h> definirá las siguientes macros que se expandirán a expresiones constantes enteras con valores distintos:

_IOFBF
Entrada/salida completamente en búfer.
_IOLBF
Entrada/salida en búfer de línea.
_IONBF
Entrada/salida sin búfer.

La cabecera <stdio.h> definirá las siguientes macros que se expandirán a expresiones constantes enteras con valores distintos:

SEEK_CUR
Búsqueda relativa a la posición actual.
SEEK_END
Búsqueda relativa al final del archivo.
SEEK_SET
Búsqueda relativa al inicio del archivo.

La cabecera <stdio.h> definirá las siguientes macros que se expandirán a expresiones constantes enteras que denotan límites de implementación:

{FILENAME_MAX}
Tamaño máximo en bytes del nombre de ruta más largo que la implementación garantiza que se puede abrir.
{FOPEN_MAX}
Número de flujos que la implementación garantiza que se pueden abrir simultáneamente. El valor es al menos ocho.
{TMP_MAX}
Número mínimo de nombres de archivo únicos generados por tmpnam(). Número máximo de veces que una aplicación puede llamar a tmpnam() de forma fiable. El valor de {TMP_MAX} es al menos 25.

En sistemas compatibles con XSI, el valor de {TMP_MAX} es al menos 10000.

La cabecera <stdio.h> definirá la siguiente macro que se expandirá a una expresión constante entera de tipo int y un valor negativo:

EOF
Valor de retorno de fin de archivo.

La cabecera <stdio.h> definirá NULL como se describe en <stddef.h>.

La cabecera <stdio.h> definirá la siguiente macro que se expandirá a una constante de cadena:

P_tmpdir
Prefijo de directorio predeterminado para tempnam().

La cabecera <stdio.h> definirá las siguientes macros que se expandirán a expresiones de tipo ``puntero a FILE'' que apuntan a los objetos FILE asociados, respectivamente, con los flujos de error estándar, entrada y salida:

stderr
Flujo de salida de error estándar.
stdin
Flujo de entrada estándar.
stdout
Flujo de salida estándar.

USO DE APLICACIÓN

Dado que las E/S estándar de flujos pueden usar un descriptor de archivo subyacente para acceder al archivo asociado con un flujo, los desarrolladores de aplicaciones deben tener en cuenta que {FOPEN_MAX} flujos pueden no estar disponibles si se utilizan descriptores de archivo para acceder a archivos que no están asociados con flujos.

NAME

stdio - standard input/output library functions

SYNOPSIS

#include <stdio.h>

DESCRIPTION

The stdio library provides functions for input and output operations. These include functions for reading from and writing to files, formatted input and output, and basic file manipulation.

The header file <stdio.h> defines various macros, types, and function prototypes for these operations. Some important definitions include:

  • FILE: A type representing a file stream.
  • stdin, stdout, stderr: Predefined file pointers for standard input, standard output, and standard error, respectively.
  • NULL: A null pointer.
  • EOF: End-of-file indicator.
  • BUFSIZ: Default buffer size.
  • TMP_MAX: Maximum number of temporary files that can be created.

Key functions include:

  • fopen(), fclose(): Opening and closing files.
  • fread(), fwrite(): Binary input and output.
  • fprintf(), fscanf(): Formatted output and input.
  • fgets(), fputs(): String input and output.
  • fseek(), rewind(), fsetpos(), fgetpos(): Positioning within a file stream.
  • fflush(): Flushing a stream's buffer.
  • clearerr(), feof(), ferror(): Checking stream status.
  • perror(): Printing system error messages.
  • tmpfile(), tmpnam(), tempnam(): Creating temporary files.

APPLICATION USAGE

Applications should include the <stdio.h> header file before using any of the standard I/O functions.

Care should be taken when using temporary file functions like tmpnam and tempnam, as they can be insecure if not used carefully. The function tmpfile is generally preferred for creating secure temporary files.

RATIONALE

There is a conflict between the ISO C standard and the POSIX definition of the {TMP_MAX} macro that is addressed by ISO/IEC 9899:1999 standard, Defect Report 336. The POSIX standard is in alignment with the public record of the response to the Defect Report. This change has not yet been published as part of the ISO C standard.
