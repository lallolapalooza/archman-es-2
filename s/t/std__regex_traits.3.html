class std::regex_traits< _Ch_type >"Describes aspects of a regular expression.

A regular expression traits class that satisfies the requirements of section [28.7].

The class regex is parameterized around a set of related types and functions used to complete the definition of its semantics. This class satisfies the requirements of such a traits class.

Parameters

Returns

an unspecified value that represents the character classification named by the character sequence designated by the iterator range [__first, __last). If icase is true, the returned mask identifies the classification regardless of the case of the characters to be matched (for example, [[:lower:]] is the same as [[:alpha:]]), otherwise a case-dependent classification is returned. The value returned shall be independent of the case of the characters in the character sequence. If the name is not recognized then returns a value that compares equal to 0.

At least the following names (or their wide-character equivalent) are supported.

  • alnum
  • alpha

  • cntrl
  • digit
  • graph
  • lower
  • print
  • punct

Description

The std::regex_traits class template provides a mechanism for adapting the regular expression library to different character types and different character encodings. It is used implicitly by the std::basic_regex class template and its member functions. The default std::regex_traits is used when no explicit traits class is specified.

The primary purpose of std::regex_traits is to provide locale-specific information to the regular expression engine. This includes information about character classes, character translations, and collation ordering.

The template parameter _Ch_type specifies the character type to be used (e.g., char or wchar_t).

Member Types

char_type
The character type used by the regular expression library. This is typically the same as the template parameter _Ch_type.
string_type
The string type used by the regular expression library. This is typically std::basic_string<_Ch_type>.
int_type
An integer type capable of representing all character values of char_type, plus at least one additional value (typically EOF). This is often int.
size_type
An unsigned integer type used for sizes and counts. This is typically std::basic_string<_Ch_type>::size_type.
regex_type
The type of the compiled regular expression. This is typically std::basic_regex<_Ch_type>.

Gets a sort key for a character sequence.

Parameters

__first beginning of the character sequence.
__last one-past-the-end of the character sequence.

Returns a sort key for the character sequence designated by the iterator range [F1, F2) such that if the character sequence [G1, G2) sorts before the character sequence [H1, H2) then v.transform(G1, G2) < v.transform(H1, H2).

What this really does is provide a more efficient way to compare a string to multiple other strings in locales with fancy collation rules and equivalence classes.

Returns
