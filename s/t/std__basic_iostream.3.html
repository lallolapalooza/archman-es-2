Extractores
Todas las funciones operator>> (también conocidas como funciones de entrada formateada) tienen un comportamiento común. Cada una comienza construyendo un objeto temporal de tipo std::basic_istream::sentry con el segundo argumento (noskipws) establecido en false. Esto tiene varios efectos, incluyendo el establecimiento de una bandera de estado; consulte la documentación de sentry para más detalles.

Si el estado del sentry es bueno, la función intenta extraer los datos apropiados para el tipo del argumento.

Si se lanza una excepción durante la extracción, ios_base::badbit se activará en el estado de error del stream (sin causar que se lance una ios_base::failure) y la excepción original se relanzará si badbit está activado en la máscara de excepciones.

DESCRIPTION

The class template basic_ios is the base class for the input stream class template basic_istream and the output stream class template basic_ostream. It manages the stream state, locale, buffer, and formatting flags.

Formatted Input Functions

These functions extract data from the input stream and convert it to the appropriate type. The extraction operators (`>>`) are overloaded for various built-in types, as well as for character arrays and pointers. They also handle the std::basic_streambuf argument.

Unformatted Input Functions

All the unformatted input functions have some common behavior. Each starts by constructing a temporary object of type std::basic_istream::sentry with the second argument (noskipws) set to true. This has several effects, concluding with the setting of a status flag; see the sentry documentation for more.

If the sentry status is good, the function tries to extract whatever data is appropriate for the type of the argument.

The number of characters extracted is stored for later retrieval by gcount().

If an exception is thrown during extraction, ios_base::badbit will be turned on in the stream's error state (without causing an ios_base::failure to be thrown) and the original exception will be rethrown if badbit is set in the exceptions mask.

    Detailed Description

    This class is essentially a combination of basic_istream and basic_ostream, inheriting from both.

    It requires the stream buffer to be accessible via both rdbuf(), and sync().

    Note that the inheritance is public. So this class can be used as a basic_istream and a basic_ostream simultaneously.

    The constructor initializes the base classes with the supplied stream buffer, if any.

    The destructor does not perform any action, the stream buffer is not affected.
