Descripción Detallada

template<typename _Container>

class std::front_insert_iterator< _Container >"Convierte la asignación en inserción.

Estos son iteradores de salida, construidos a partir de un contenedor-de-T. Asignar una T al iterador la antepone al contenedor usando push_front.

Consejo: Usar la función front_inserter para crear estos iteradores puede ahorrar escritura.

Parámetros

__value Una instancia de cualquier tipo que sea container_type::const_reference; presumiblemente una referencia a T constante para container<T>.

Retorna

Este iterador, para operaciones encadenadas.

Este tipo de iterador en realidad no tiene una posición en el contenedor (puedes pensar en la posición como si estuviera permanentemente al frente, si lo deseas). Asignar un valor al iterador siempre antepondrá el valor al frente del contenedor.
