Descripción Detallada

Espacio de nombres ISO C++ 2014 para sufijos de literales de chrono.

Estos sufijos se pueden usar para crear valores de chrono::duration con períodos de tick de horas, minutos, segundos, milisegundos, microsegundos o nanosegundos. Por ejemplo, std::chrono::seconds(5) se puede escribir como 5s después de hacer visible el sufijo en el ámbito actual. Los sufijos se pueden hacer visibles mediante una directiva using o una declaración using, como por ejemplo:

  • using namespace std::chrono_literals;
  • using namespace std::literals;
  • using namespace std::chrono;
  • using namespace std;
  • using std::chrono_literals::operator""s;

El resultado de estos sufijos en un literal entero es uno de los typedefs estándar como std::chrono::hours. El resultado en un literal de punto flotante es un tipo de duración con el período de tick especificado y una representación de punto flotante no especificada; por ejemplo, 1.5e2ms podría ser equivalente a chrono::duration<long double, chrono::milli>(1.5e2).
