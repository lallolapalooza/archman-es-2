Detailed Description

template<typename _CharT, typename _Traits>

class std::basic_fstream< _CharT, _Traits >

"Controlling input and output for files.

Template Parameters

_CharT Type of character stream.
_Traits Traits for character type, defaults to char_traits<_CharT>.

This class supports reading from and writing to named files, using the inherited functions from std::basic_iostream. To control the associated sequence, an instance of std::basic_filebuf is used, which this page refers to as sb.

DESCRIPCIÓN

La clase std::basic_ios es la clase base para las clases de flujo de entrada y salida de la biblioteca estándar de C++. Proporciona las instalaciones comunes para ambos tipos de flujo, incluyendo el manejo de banderas de formato (flags), el estado del flujo, la posición del flujo y el puntero a un objeto streambuf subyacente.

Las clases de flujo más comúnmente usadas son:

std::ios
Representa un flujo de caracteres de 8 bits (tipo `char`).
std::wios
Representa un flujo de caracteres anchos (tipo `wchar_t`).
std::fstream
Representa un flujo de entrada/salida de caracteres de 8 bits asociado a un archivo.
std::ifstream
Representa un flujo de entrada de caracteres de 8 bits asociado a un archivo.
std::ofstream
Representa un flujo de salida de caracteres de 8 bits asociado a un archivo.
std::stringstream
Representa un flujo de entrada/salida de caracteres de 8 bits asociado a una cadena en memoria.
std::istringstream
Representa un flujo de entrada de caracteres de 8 bits asociado a una cadena en memoria.
std::ostringstream
Representa un flujo de salida de caracteres de 8 bits asociado a una cadena en memoria.

Existen contrapartes para caracteres anchos (wchar_t) para la mayoría de estas clases (por ejemplo, std::wfstream, std::wstringstream).

El objeto streambuf subyacente es el que realmente maneja las operaciones de entrada/salida con la fuente o destino de datos subyacente. La clase basic_ios proporciona una interfaz para acceder y manipular este objeto.

La clase basic_ios proporciona una serie de miembros de datos protegidos y funciones miembro para interactuar con el estado del flujo. Estos están típicamente expuestos a través de las clases derivadas como basic_istream y basic_ostream.

EJEMPLOS

El siguiente ejemplo muestra cómo usar algunas de las banderas de formato:

#include <iostream>
#include <iomanip>
#include <string>

int main() {
    int num = 123;
    double pi = 3.14159;
    std::string text = "hello";

    // Salida decimal estándar
    std::cout << "Decimal: " << num << std::endl;

    // Salida hexadecimal con prefijo
    std::cout << std::showbase << std::hex << num << std::endl;

    // Salida octal con prefijo
    std::cout << std::oct << num << std::endl;

    // Restablecer a decimal
    std::cout << std::dec;

    // Salida de punto flotante estándar
    std::cout << "Pi: " << pi << std::endl;

    // Salida científica con precisión 4
    std::cout << std::scientific << std::setprecision(4) << pi << std::endl;

    // Salida de punto fijo con precisión 2
    std::cout << std::fixed << std::setprecision(2) << pi << std::endl;

    // Salida de cadena con alineación a la izquierda y ancho 10
    std::cout << std::left << std::setw(10) << text << "|" << std::endl;

    // Salida de cadena con alineación a la derecha y ancho 10
    std::cout << std::right << std::setw(10) << text << "|" << std::endl;

    // Salida de número positivo con signo '+'
    int positive_num = 42;
    std::cout << std::showpos << positive_num << std::endl;
    
    // Cancelar showpos
    std::cout << std::noshowpos << positive_num << std::endl;

    return 0;
}
