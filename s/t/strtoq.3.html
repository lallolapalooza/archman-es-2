strtol(3) Manual de Funciones de Biblioteca strtol(3)

NOMBRE

strtol, strtoll, strtoq - convertir una cadena a un entero largo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
long strtol(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
long long strtoll(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

strtoll():

    _ISOC99_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPCIÓN

La función strtol() convierte la parte inicial de la cadena en nptr a un valor de entero largo según la base dada, la cual debe estar entre 2 y 36 inclusive, o ser el valor especial 0.

La cadena puede comenzar con una cantidad arbitraria de espacios en blanco (según lo determinado por isspace(3)) seguida de un único signo opcional '+' o '-'. Si base es cero o 16, la cadena puede entonces incluir un prefijo "0x" o "0X", y el número se leerá en base 16; si base es cero o 2, la cadena puede entonces incluir un prefijo "0b" o "0B", y el número se leerá en base 2; de lo contrario, una base cero se toma como 10 (decimal) a menos que el siguiente carácter sea '0', en cuyo caso se toma como 8 (octal).

El resto de la cadena se convierte a un valor long de la manera obvia, deteniéndose en el primer carácter que no es un dígito válido en la base dada. (En bases superiores a 10, la letra 'A' en mayúscula o minúscula representa 10, 'B' representa 11, y así sucesivamente, con 'Z' representando 35).

Si endptr no es NULL, y la base es compatible, strtol() almacena la dirección del primer carácter inválido en *endptr. Si no hubo ningún dígito, strtol() almacena el valor original de nptr en *endptr (y devuelve 0). En particular, si *nptr no es '\0' pero **endptr es '\0' al regresar, toda la cadena es válida.

La función strtoll() funciona igual que la función strtol() pero devuelve un valor entero long long.

VALOR DE RETORNO

La función strtol() devuelve el resultado de la conversión, a menos que el valor sea inferior o superior al rango permitido. Si ocurre un desbordamiento inferior, strtol() devuelve LONG_MIN. Si ocurre un desbordamiento superior, strtol() devuelve LONG_MAX. En ambos casos, errno se establece en ERANGE. Exactamente lo mismo ocurre para strtoll() (con LLONG_MIN y LLONG_MAX en lugar de LONG_MIN y LONG_MAX).

ERRORES

Esta función no modifica errno en caso de éxito.

EINVAL
(no en C99) La base dada contiene un valor no compatible.
ERANGE
El valor resultante estaba fuera de rango.

La implementación también puede establecer errno a EINVAL en caso de que no se realizara ninguna conversión (no se encontraron dígitos y se devolvió 0).

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
strtol (), strtoll (), strtoq () Seguridad en hilos MT-Safe locale

VERSIONES

Según POSIX.1, en locales distintos de "C" y "POSIX", estas funciones pueden aceptar otras cadenas numéricas, definidas por la implementación.

BSD también tiene


quad_t strtoq(const char *nptr, char **endptr, int base);

con una definición completamente análoga. Dependiendo del tamaño de palabra de la arquitectura actual, esto puede ser equivalente a strtoll() o a strtol().

ESTÁNDARES

C23, POSIX.1-2024.

HISTORIA

ADVERTENCIAS

Comprobaciones de rango

Dado que strtol() puede devolver legítimamente 0, LONG_MAX o LONG_MIN (LLONG_MAX o LLONG_MIN para strtoll()) tanto en éxito como en fallo, el programa que llama debe establecer errno a 0 antes de la llamada, y luego determinar si ocurrió un error comprobando si errno == ERANGE después de la llamada.


errno = 0;
n = strtol(s, &end, base);
if (end == s)
	goto no_number;
if ((errno == ERANGE && n == LONG_MIN) || n < min)
	goto too_low;
if ((errno == ERANGE && n == LONG_MAX) || n > max)
	goto too_high;

base

Si la base necesita ser comprobada, debe ser comprobada en una llamada donde se sepa que la cadena tiene éxito. De lo contrario, es imposible diferenciar los errores de forma portable.


errno = 0;
strtol("0", NULL, base);
if (errno == EINVAL)
    goto unsupported_base;

ERRORES TÉCNICOS

Espacios en blanco

Estas funciones aceptan silenciosamente espacios en blanco iniciales. Para rechazar espacios en blanco, llame a isspace(3) antes de strtol().

strtoq(3) - Arch Linux man pages

NAME

strtoq - convert string to quad-precision number

LIBRARY

Standard C Library (libc, -lc)

SYNOPSIS

#include <stdlib.h>
long double strtoq(const char *restrict nptr, char **restrict endptr, int base);

DESCRIPTION

The strtoq() function converts the initial portion of the string pointed to by nptr to a long double value according to the given base.

The string may be represented in various forms, depending on the base. base must be either 0, or a value in the range [2, 36].

If base is 0, the base is determined by the (non-arbitrary) characters at the start of the string. The base is 16 if the string begins with "0x" or "0X", otherwise the base is 8 if the string begins with "0", otherwise the base is 10. (This is the same behavior as strtol(3).)

If base is 16, the string may begin with "0x" or "0X" and these characters will be consumed but not stored in the returned value.

If base is 8, the string may begin with "0" and this character will be consumed but not stored in the returned value.

The string is parsed from left to right. The first character that is not a valid digit in the given base terminates the scan, or if no valid digit is found, the scan terminates at the beginning of the string. Digits greater than 9 are represented by the letters 'a' through 'z' (case-insensitive).

If endptr is not NULL, strtoq() stores the address of the first invalid character in *endptr. If there were no conversion to be performed, the value of nptr is stored in *endptr.

If the converted value cannot be represented in a long double, an overflow or underflow occurs and ERANGE is set.

The behavior is undefined if nptr points to a string that contains embedded null characters.

RETURN VALUE

On success, strtoq() returns the converted value. If no (arbitrary) conversion could be performed, 0 is returned. If the correct value is outside the range representable by long double, plus or minus HUGE_VALL (as defined in <math.h>) is returned and errno is set to ERANGE. If the converted value would be too small to be represented as a non-zero value, 0.0 is returned and errno is set to ERANGE.

ERRORS

ERANGE
The converted value is out of range.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

+---------------------+---------------+
| Interface           | Attribute     |
+---------------------+---------------+
| strtoq()            | No-rewind,    |
|                     | thread-safe   |
+---------------------+---------------+

VERSIONS

The strtoq() function is available since glibc 2.3.

STANDARDS

C99, C11, C17, C23.

HISTORY

The strtoq() function first appeared in POSIX.1-2001.

CAVEATS

The POSIX standard specifies that if the value to be returned is too large to be represented, HUGE_VALL should be returned. However, glibc's implementation returns HUGE_VALL only if the input string represents a value greater than or equal to HUGE_VALL. If the input string represents a value smaller than -HUGE_VALL, it returns -HUGE_VALL. This is a subtle difference in the underflow case.

The standard requires that strtoq() set errno to ERANGE on overflow/underflow. glibc's implementation also sets errno to ERANGE.

BUGS

The behavior of strtoq() when the base argument is 0 is the same as strtol(3), which is often considered problematic. In particular, strings starting with '0' are parsed in base 8, and strings starting with '0x' or '0X' are parsed in base 16. This behavior can lead to unexpected results if the program relies on these non-decimal bases. For more predictable behavior, it is recommended to explicitly specify the base when calling strtoq().

EXAMPLES

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <math.h>

int
main(void)
{
    const char *s = "  -123.456e-789";
    char *endptr;
    long double val;

    errno = 0; /* To distinguish success/failure after calling: */
    val = strtoq(s, &endptr, 10);

    /* Check for error conditions */
    if ((base == 0 && (*s == '0' || (*s == '-' && *s+1 == '0') || (*s == '+' && *s+1 == '0')))
        || (base >= 2 && base <= 36)) {
        /* If the input string is valid for the given base,
           but the result is out of range, ERANGE will be set. */
        if (errno == ERANGE && (val == HUGE_VALL || val == -HUGE_VALL)) {
            printf("Conversion resulted in overflow/underflow\n");
        } else if (endptr == s) {
            printf("No digits were found\n");
        } else if (*endptr != '\0') {
            printf("Further characters after number: \"%s\"\n", endptr);
        } else {
            printf("Successfully converted value: %Lf\n", val);
        }
    } else {
        printf("Invalid base: %d\n", base);
    }

    /* Example with base 0 */
    s = "0x1AF";
    val = strtoq(s, &endptr, 0);
    if (errno == ERANGE && (val == HUGE_VALL || val == -HUGE_VALL)) {
        printf("Conversion resulted in overflow/underflow\n");
    } else if (endptr == s) {
        printf("No digits were found\n");
    } else if (*endptr != '\0') {
        printf("Further characters after number: \"%s\"\n", endptr);
    } else {
        printf("Successfully converted value (base 0): %Lf\n", val);
    }

    /* Example with explicit base 16 */
    s = "0x1AF";
    val = strtoq(s, &endptr, 16);
     if (errno == ERANGE && (val == HUGE_VALL || val == -HUGE_VALL)) {
        printf("Conversion resulted in overflow/underflow\n");
    } else if (endptr == s) {
        printf("No digits were found\n");
    } else if (*endptr != '\0') {
        printf("Further characters after number: \"%s\"\n", endptr);
    } else {
        printf("Successfully converted value (base 16): %Lf\n", val);
    }

    /* Example that demonstrates error handling */
    s = "xyz";
    val = strtoq(s, &endptr, 10);
    if (errno == ERANGE && (val == HUGE_VALL || val == -HUGE_VALL)) {
        printf("Conversion resulted in overflow/underflow\n");
    } else if (endptr == s) {
        printf("No digits were found\n");
    } else if (*endptr != '\0') {
        printf("Further characters after number: \"%s\"\n", endptr);
    } else {
        /* This part won't be reached for "xyz" */
        printf("Successfully converted value: %Lf\n", val);
    }

    /* Example demonstrating underflow */
    s = "1.23e-9999";
    val = strtoq(s, &endptr, 10);
    if (errno == ERANGE && (val == HUGE_VALL || val == -HUGE_VALL)) {
        printf("Conversion resulted in overflow/underflow\n");
    } else if (endptr == s) {
        printf("No digits were found\n");
    } else if (*endptr != '\0') {
        printf("Further characters after number: \"%s\"\n", endptr);
    } else {
        printf("Successfully converted value: %Lf\n", val);
    }

    return 0;
}
