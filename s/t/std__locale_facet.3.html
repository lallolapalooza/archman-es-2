Descripción detallada

Clase base de funcionalidad de localización.

La clase facet es la clase base para una característica de localización, como la impresión de dinero, tiempo y números. Proporciona soporte común para facets y gestión de referencias.

Los facets no pueden copiarse ni asignarse.

Constructor de facet. Este es el constructor proporcionado por el estándar. Si refs es 0, el facet se destruye cuando se destruye el último locale que lo referencia. De lo contrario, el facet nunca se destruirá.
