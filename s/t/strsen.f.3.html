Documentación de Función/Subrutina

subroutine strsen (character job, character compq, logical, dimension( * ) select, integer n, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldq, * ) q, integer ldq, real, dimension( * ) wr, real, dimension( * ) wi, integer m, real s, real sep, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

STRSEN

Propósito:

!>
!> STRSEN reordena la factorización de Schur real de una matriz real
!> A = Q*T*Q**T, de modo que un clúster seleccionado de autovalores aparezca
!> en los bloques diagonales principales de la matriz cuasi-triangular superior T,
!> y las columnas principales de Q formen una base ortonormal del subespacio
!> invariante derecho correspondiente.
!>
!> Opcionalmente, la rutina calcula los números de condición recíprocos de
!> el clúster de autovalores y/o el subespacio invariante.
!>
!> T debe estar en forma canónica de Schur (como la devuelta por SHSEQR), es decir,
!> es decir, triangular de bloque con bloques diagonales de 1x1 y 2x2; cada
!> bloque diagonal de 2x2 tiene sus elementos diagonales iguales y sus
!> elementos fuera de la diagonal de signo opuesto.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para el
!>          clúster de autovalores (S) o el subespacio invariante (SEP):
!>          = 'N': ninguno;
!>          = 'E': solo para autovalores (S);
!>          = 'V': solo para subespacio invariante (SEP);
!>          = 'B': para ambos autovalores y subespacio invariante (S y
!>                 SEP).
!>

COMPQ

!>          COMPQ es CHARACTER*1
!>          = 'V': actualizar la matriz Q de vectores de Schur;
!>          = 'N': no actualizar Q.
!>

SELECT

!>          SELECT es un array LOGICAL, dimension (N)
!>          SELECT especifica los autovalores en el clúster seleccionado. Para
!>          seleccionar un autovalor real w(j), SELECT(j) debe establecerse en
!>          .TRUE.. Para seleccionar un par conjugado complejo de autovalores
!>          w(j) y w(j+1), correspondiente a un bloque diagonal de 2x2,
!>          ya sea SELECT(j) o SELECT(j+1) o ambos deben establecerse en
!>          .TRUE.; un par conjugado complejo de autovalores debe ser
!>          ambos incluidos en el clúster o ambos excluidos.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array REAL, dimension (LDT,N)
!>          En la entrada, la matriz cuasi-triangular superior T, en forma canónica
!>          de Schur.
!>          En la salida, T se sobrescribe con la matriz reordenada T, nuevamente en
!>          forma canónica de Schur, con los autovalores seleccionados en los
!>          bloques diagonales principales.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

Q

!>          Q es un array REAL, dimension (LDQ,N)
!>          En la entrada, si COMPQ = 'V', la matriz Q de vectores de Schur.
!>          En la salida, si COMPQ = 'V', Q ha sido premultiplicado por la
!>          matriz de transformación ortogonal que reordena T; las
!>          columnas principales M de Q forman una base ortonormal para
!>          el subespacio invariante especificado.
!>          Si COMPQ = 'N', Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.
!>          LDQ >= 1; y si COMPQ = 'V', LDQ >= N.
!>

WR

!>          WR es un array REAL, dimension (N)
!>

WI

!>          WI es un array REAL, dimension (N)
!>
!>          Las partes real e imaginaria, respectivamente, de los autovalores
!>          reordenados de T. Los autovalores se almacenan en el mismo
!>          orden que en la diagonal de T, con WR(i) = T(i,i) y, si
!>          T(i:i+1,i:i+1) es un bloque diagonal de 2x2, WI(i) > 0 y
!>          WI(i+1) = -WI(i). Tenga en cuenta que si un autovalor complejo está
!>          suficientemente mal condicionado, su valor puede diferir
!>          significativamente de su valor antes de la reordenación.
!>

M

!>          M es INTEGER
!>          La dimensión del subespacio invariante especificado.
!>          0 < = M <= N.
!>

S

!>          S es REAL
!>          Si JOB = 'E' o 'B', S es un límite inferior del número de condición
!>          recíproco para el clúster seleccionado de autovalores.
!>          S no puede subestimar el número de condición recíproco verdadero
!>          en más de un factor de sqrt(N). Si M = 0 o N, S = 1.
!>          Si JOB = 'N' o 'V', S no se referencia.
!>

SEP

!>          SEP es REAL
!>          Si JOB = 'V' o 'B', SEP es el número de condición recíproco estimado
!>          del subespacio invariante especificado. Si
!>          M = 0 o N, SEP = norm(T).
!>          Si JOB = 'N' o 'E', SEP no se referencia.
!>

WORK

!>          WORK es un array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si JOB = 'N', LWORK >= max(1,N);
!>          si JOB = 'E', LWORK >= max(1,M*(N-M));
!>          si JOB = 'V' o 'B', LWORK >= max(1,2*M*(N-M)).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite ningún
!>          mensaje de error relacionado con LWORK por XERBLA.
!>

IWORK

!>          IWORK es un array INTEGER, dimension (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si JOB = 'N' o 'E', LIWORK >= 1;
!>          si JOB = 'V' o 'B', LIWORK >= max(1,M*(N-M)).
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array IWORK,
!>          devuelve este valor como la primera entrada del array IWORK, y
!>          no se emite ningún mensaje de error relacionado con LIWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i-ésimo tuvo un valor ilegal
!>          = 1: la reordenación de T falló porque algunos autovalores están demasiado
!>               cerca para separarse (el problema está muy mal condicionado);
!>               T puede haber sido reordenado parcialmente, y WR y WI
!>               contienen los autovalores en el mismo orden que en T; S y
!>               SEP (si se solicitaron) se establecen en cero.
!>

Detalles Adicionales:

!>
!>  STRSEN primero recopila los autovalores seleccionados calculando una
!>  transformación ortogonal Z para moverlos a la esquina superior izquierda de T.
!>  En otras palabras, los autovalores seleccionados son los autovalores de T11
!>  en:
!>
!>          Z**T * T * Z = ( T11 T12 ) n1
!>                         (  0  T22 ) n2
!>                            n1  n2
!>
!>  donde N = n1+n2 y Z**T significa la transpuesta de Z. Las primeras n1 columnas
!>  de Z abarcan el inv especificado

SYNOPSIS

    SUBROUTINE STRSEN( JOB, COMPQ, SELECT, N, T, LDT, WR, WI, VL, LDVL,
                       VR, LDVR, RNM, SEP, WORK, LWORK, INFO )

    REAL             T( LDT, * )
    REAL             WR( * ), WI( * )
    REAL             VL( LDVL, * ), VR( LDVR, * )
    REAL             RNM( * ), SEP( * )
    REAL             WORK( * )
    LOGICAL          SELECT( * )
    CHARACTER        JOB
    CHARACTER        COMPQ
    INTEGER          N, LDT, LDVL, LDVR, LWORK, INFO

Function/Subroutine Documentation

!> \brief \date Created 2008 from ZTRSEN.
!>
!> \details
!> This routine is deprecated. It is now superseded by strsen.f.
!>
!> This routine is deprecated. It is now superseded by strsen.f.
!>
!> Computes the Schur factorization of a triangular matrix.
!>
!> Details:
!> This routine is intended to be called after the first call to
!> strtri.f which overwrites T by its inverse.
!>
!> It is assumed that the matrix T is already in Schur canonical form, i.e.,
!> upper triangular.
!>
!> The function STRSEN reorders the Schur factorization of T to isolate
!> eigenvalues.
!>
!> Given an upper triangular matrix T, STRSEN reorders the eigenvalues on
!> the diagonal so that the selected eigenvalues are in the upper left
!> corner of T.
!>
!> T = ( T11  T12 )
!>     (  0   T22 )
!>
!> where T11 and T22 are upper triangular matrices.
!>
!> The selected eigenvalues of T11 are those for which SELECT(i) is
!> true. The reordered matrix still has the same eigenvalues, but T11
!> contains the selected ones.
!>
!> If JOB = 'V', the eigenvectors are computed.
!> If COMPQ = 'V', the matrix Q of Schur vectors is computed.
!> If COMPQ = 'I', the identity matrix is used for Q.
!>
!> \param[in] JOB
!>          JOB specifies the form of the reordered Schur factorization:
!>          = 'N': The triangular matrix T is overwritten by its
!>                 form with the selected eigenvalues in the top left
!>                 corner.
!>          = 'E': The triangular matrix T is overwritten by its
!>                 form with the selected eigenvalues in the top left
!>                 corner, and the corresponding eigenvalues are
!>                 returned in WR and WI.
!>          = 'V': The triangular matrix T is overwritten by its
!>                 form with the selected eigenvalues in the top left
!>                 corner, and the corresponding Schur vectors are
!>                 returned in VL and VR.
!>
!> \param[in] COMPQ
!>          COMPQ specifies the transformation matrix Q.
!>          = 'V': Q is computed and returned in the matrix Q (argument
!>                 not present in STRSEN).
!>          = 'I': Q is initialized to the identity matrix.
!>
!> \param[in] SELECT
!>          The array SELECT declares the set of eigenvalues to be
!>          selected. For i=1 to N, if SELECT(i) is true, then the
!>          i-th eigenvalue (and corresponding Schur vector if
!>          requested) is selected.
!>
!> \param[in] N
!>          The order of the upper triangular matrix T. N >= 0.
!>
!> \param[in,out] T
!>          T is N by N upper triangular matrix. The matrix T is
!>          overwritten by its reordered form.
!>
!> \param[in] LDT
!>          The leading dimension of the array T. LDT >= max(1, N).
!>
!> \param[out] WR
!>          WR and WI contain the real and imaginary parts of the
!>          eigenvalues of T.
!>
!> \param[out] WI
!>          WR and WI contain the real and imaginary parts of the
!>          eigenvalues of T.
!>
!> \param[out] VL
!>          VL is N by N if COMPQ = 'V'. VL contains the left
!>          Schur vectors, i.e. the transformation matrix VL such that
!>          VL*T*VL**T is block upper triangular with T11 in VL.
!>          If COMPQ = 'I', VL is not used.
!>
!> \param[in] LDVL
!>          The leading dimension of the array VL. LDVL >= max(1, N).
!>
!> \param[out] VR
!>          VR is N by N if COMPQ = 'V'. VR contains the right
!>          Schur vectors, i.e. the transformation matrix VR such that
!>          VR**T*T*VR is block upper triangular with T11 in VR.
!>          If COMPQ = 'I', VR is not used.
!>
!> \param[in] LDVR
!>          The leading dimension of the array VR. LDVR >= max(1, N).
!>
!> \param[out] RNM
!>          RNM contains the reciprocal condition number of the average
!>          of the eigenvalues of T11.
!>
!> \param[out] SEP
!>          SEP contains the reciprocal condition number of the right
!>          invariant subspace spanned by the first n1 columns of VR.
!>
!> \param[out] WORK
!>          WORK is a work array of size LWORK.
!>
!> \param[in] LWORK
!>          The dimension of the array WORK. LWORK must be at least
!>          max(1, N).
!>          If LWORK = -1, then a workspace query is assumed and the
!>          routine only calculates the optimal size of the WORK array.
!>          The optimal size is max(1, N).
!>
!> \param[out] INFO
!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>          > 0: if INFO = i, the i-th eigenvalue could not be brought
!>               into the top left corner of the matrix. This may
!>               happen if the matrix is too ill-conditioned.
!>
!> Details:
!> If T has been obtained from the real Schur factorization of a matrix
!> A = Q*T*Q**T, then the reordered real Schur factorization of A is given
!> by A = (Q*Z)*(Z**T*T*Z)*(Q*Z)**T, and the first n1 columns of Q*Z span
!> the corresponding invariant subspace of A.
!>
!> The reciprocal condition number of the average of the eigenvalues of
!> T11 may be returned in S. S lies between 0 (very badly conditioned)
!> and 1 (very well conditioned). It is computed as follows. First we
!> compute R so that
!>
!>                         P = ( I  R ) n1
!>                             ( 0  0 ) n2
!>                               n1 n2
!>
!> is the projector on the invariant subspace associated with T11.
!> R is the solution of the Sylvester equation:
!>
!>                        T11*R - R*T22 = T12.
!>
!> Let F-norm(M) denote the Frobenius-norm of M and 2-norm(M) denote
!> the two-norm of M. Then S is computed as the lower bound
!>
!>                      (1 + F-norm(R)**2)**(-1/2)
!>
!> on the reciprocal of 2-norm(P), the true reciprocal condition number.
!> S cannot underestimate 1 / 2-norm(P) by more than a factor of
!> sqrt(N).
!>
!> An approximate error bound for the computed average of the
!> eigenvalues of T11 is
!>
!>                         EPS * norm(T) / S
!>
!> where EPS is the machine precision.
!>
!> The reciprocal condition number of the right invariant subspace
!> spanned by the first n1 columns of Z (or of Q*Z) is returned in SEP.
!> SEP is defined as the separation of T11 and T22:
!>
!>                     sep( T11, T22 ) = sigma-min( C )
!>
!> where sigma-min(C) is the smallest singular value of the
!> n1*n2-by-n1*n2 matrix
!>
!>     C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )
!>
!> I(m) is an m by m identity matrix, and kprod denotes the Kronecker
!> product. We estimate sigma-min(C) by the reciprocal of an estimate of
!> the 1-norm of inverse(C). The true reciprocal 1-norm of inverse(C)
!> cannot differ from sigma-min(C) by more than a factor of sqrt(n1*n2).
!>
!> When SEP is small, small changes in T can cause large changes in
!> the invariant subspace. An approximate bound on the maximum angular
!> error in the computed right invariant subspace is
!>
!>                      EPS * norm(T) / SEP
!>
