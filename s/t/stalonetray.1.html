STALONETRAY(1) Comandos de usuario STALONETRAY(1)

NOMBRE

stalonetray - implementación de bandeja del sistema (área de notificación) *sta*nd-*alone*. Este documento cubre la versión 1.0.1 de stalonetray.

SINOPSIS


.HP 288u


stalonetray
[opción...]

DESCRIPCIÓN


.PP Stalonetray es una bandeja del sistema (área de notificación) independiente para el sistema de ventanas X Window System/X11 (por ejemplo, XOrg o XFree86). Tiene dependencias mínimas de compilación y ejecución: solo una biblioteca X11. El soporte completo de XEMBED está en desarrollo. Stalonetray funciona con prácticamente cualquier gestor de ventanas compatible con EWMH.


.PP El comportamiento y la apariencia de stalonetray se pueden configurar tanto a través de opciones de línea de comandos como de un archivo de configuración. Como de costumbre, las opciones de línea de comandos tienen precedencia sobre las opciones especificadas en el archivo de configuración.


.PP Los nombres de los parámetros de línea de comandos pueden tener dos variantes: corta (-o) y larga (--opción). Escriba -ovalor o -o valor para pasar un valor usando el nombre corto de un parámetro; para pasar un valor usando un nombre largo, escriba --opción valor o --opción=valor. Todos los parámetros tipo bandera tienen un valor booleano opcional que, si se omite, se asume que es "verdadero". Escriba "verdadero", "sí", "1" para valores booleanos positivos, y "falso", "no", "0" para los negativos.


.PP El archivo de configuración predeterminado es $HOME/.stalonetrayrc. Si no se encuentra, se busca en $XDG_CONFIG_HOME/stalonetrayrc. Un archivo de configuración contiene pares de palabra clave-argumento sin distinción de mayúsculas y minúsculas, uno por línea. Las líneas que comienzan con '#' y las líneas vacías se ignoran. Alternativamente, el archivo de configuración se puede especificar a través de las opciones de línea de comandos -c o --config.


.PP Stalonetray se puede configurar para escribir mensajes de registro de diagnóstico en el flujo de error estándar.


.PP A continuación se muestra la lista de posibles opciones de línea de comandos/archivo de configuración. Las opciones que comienzan con guiones son parámetros de línea de comandos, las demás son palabras clave del archivo de configuración. Las opciones nuevas en la versión 1.0.1 están marcadas con "NUEVO en 1.0.1".

OPCIONES


.PP -bg color, --background color, background color


Use color para el fondo de la bandeja. color se puede especificar como un triplete hexadecimal HTML o como un nombre de rgb.txt (tenga en cuenta que '#' debe ir entre comillas). Valor predeterminado: #777777.


.RE


.PP -c nombre_archivo, --config nombre_archivo


Lea la configuración del archivo nombre_archivo en lugar del predeterminado $HOME/.stalonetrayrc.


.RE


.PP -d espec_decoracion, --decorations espec_decoracion, decorations espec_decoracion


Especifique las decoraciones visibles de la ventana de la bandeja. Los valores posibles para espec_decoracion son: all, title, border, none (predeterminado).


.RE


.PP -display pantalla, display pantalla


Use la pantalla X pantalla.


.RE


.PP --dockapp-mode [modo], dockapp_mode [modo]


Establezca el modo dockapp, que puede ser simple para, por ejemplo, OpenBox, wmaker para WindowMaker, o none (predeterminado).


.RE


.PP -f [nivel], --fuzzy-edges [nivel], fuzzy_edges [nivel]


Habilite bordes difusos de la ventana de la bandeja y establezca el nivel de difuminado, que puede variar de 0 (deshabilitado, predeterminado) a 3. Si se omite, el valor de nivel es 2.


.RE


.PP --geometry espec_geometria, geometry espec_geometria


Establezca la geometría inicial de la bandeja a espec_geometria, especificada en la notación X estándar: anchoxalto[+x[+y]], donde el ancho y la altura se especifican en múltiplos de ranura de ícono. Valor predeterminado: 1x1+0-0.


.RE


.PP --grow-gravity gravedad, grow_gravity gravedad


Especifique la gravedad de posicionamiento de los íconos (ya sea N, S, W, E, NW, NE, SW, SE). La gravedad de crecimiento especifica las direcciones en las que la ventana de la bandeja puede crecer. Por ejemplo, si especifica NW, la ventana de la bandeja crecerá verticalmente hacia abajo y horizontalmente hacia la derecha (estos son los lados opuestos a la esquina superior izquierda o noroeste de la ventana); con W, la ventana de la bandeja crecerá horizontalmente solo hacia la izquierda, y verticalmente crecerá tanto hacia arriba como hacia abajo manteniendo la posición de su centro. Tenga en cuenta que este último comportamiento es nuevo en la versión 0.8. Valor predeterminado: NW.
.RE


.PP --icon-gravity gravedad, icon_gravity gravedad


Especifique la gravedad de posicionamiento de los íconos (ya sea NW, NE, SW, SE). Si especifica, por ejemplo, SW, los íconos aparecerán comenzando desde la esquina inferior izquierda de la ventana de la bandeja. Valor predeterminado: NW.


.RE


.PP -i n, --icon-size n, icon_size n


Establezca el tamaño predeterminado del ícono a n. Valor predeterminado: 24. Mínimo: 16.


.RE


.PP -h, --help


Mostrar mensaje de ayuda.


.RE


.PP ignore_classes clases


Establezca los nombres de clase de ventana X11 que stalonetray ignorará. Los nombres de clase son argumentos separados: clase1 clase2 ....


.RE


.PP --log-level nivel, log_level nivel


Establezca la cantidad de información que stalonetray emitirá a la salida estándar. Los valores posibles para nivel son: err (predeterminado), info y trace. Para que la opción trace esté disponible, stalonetray debe compilarse con --enable-debug.


.RE


.PP --kludges truco [,truco...]


Habilite trucos específicos para solucionar gestores de ventanas no conformes y/o errores de stalonetray. El argumento es una lista separada por comas de:

•fix_window_pos — corrige la posición de la ventana de la bandeja en movimientos erróneos por parte del WM
•force_icons_size — ignora los eventos de redimensionamiento en todos los íconos; fuerza su tamaño para que sea igual a icon_size
•use_icons_hints — usa las pistas de la ventana del ícono para determinar el tamaño del ícono
.sp


.RE


.PP --max-geometry espec_geometria, max_geometry espec_geometria


Establezca la geometría máxima de la bandeja a espec_geometria. Valor predeterminado: 0x0, sin límite.


.RE


.PP -m n, --monitor n, monitor n


Establezca el monitor de destino a n. Valor predeterminado: 0.


.RE


.PP --no-shrink, no_shrink [bool]


No encoger la ventana de la bandeja de nuevo después de eliminar un ícono. Útil cuando la bandeja es tragada por otra ventana como FvwmButtons. Valor predeterminado: false.


.RE


.PP -p, --parent-bg, parent_bg [bool]


Use la ventana del padre como fondo de la ventana de la bandeja. Valor predeterminado: false.


.RE


.PP --pixmap-bg ruta_a_xpm, pixmap_bg ruta_a_xpm


Use el pix

NAME

stalonetray — an absolutely unnecessary but absolutely functional tray

SYNOPSIS

stalonetray [-bcghKLmQsvw] [-a alignment] [-d daemon_timeout] [-e exclude] [-f font] [-F font_prio] [-i icon_size] [-p padding] [-P program] [-r name] [-R dir] [-S spart] [-W wpart] [-x xpm_file] [--icon-dirs dir1:dir2...] [--kludges kludge1:kludge2...] [--log-level level] [--max-geometry max_width[xmax_height]] [--remote-click-button n] [--remote-click-position xxy] [--remote-click-type type] [-s slot_size] [--scrollbars-highlight mode] [--scrollbars-size n] [--scrollbars-step n] [--tint-color color] [--tint-level level] [--window-layer layer] [--window-strut mode] [--window-type type] [--config file]

DESCRIPTION

The stalonetray is a small tray for status icons (like gkrellm, xmms, etc.). It is written in C and uses the X11 protocol, it does not use any toolkits like GTK or Qt. As a result, it is very lightweight.

The tray can be configured using command line arguments or a configuration file (~/.stalonetrayrc by default).

By default, stalonetray expects tray applications to connect to it via the SNL-IPC mechanism. If you want stalonetray to manage tray applications that do not implement this mechanism, you have to use the -P, --program option.

It is a dockapp, so it can be managed by standard dockapp managers like wmdockapp, stبار, etc.

OPTIONS

-a alignment, --alignment alignment

Set tray alignment. Possible values: left, center, right. Default value: right.

-b, --bidi

Enable bidirectional text processing. Useful for languages like Arabic or Hebrew. Default value: false.

-c, --config file

Use configuration file file. If this option is specified, then stalonetray will not try to read ~/.stalonetrayrc.

-d daemon_timeout, --daemon-timeout daemon_timeout

Set daemon timeout to daemon_timeout seconds. If stalonetray does not receive any icon requests within this time, it will exit. Default value: 0 (never exit).

-e exclude, --exclude exclude

Exclude specified window properties. For example, to exclude all windows that have a title starting with "Network", you can use -e title:Network*. See the section KLUDGES for more details.

-f font, --font font

Use font font for drawing window titles. By default, stalonetray tries to find a default font.

-g, --geometry

Parse the standard X11 geometry string (e.g. 800x600+0+0). This option can be used multiple times.

-h, --help

Show help message and exit.

-i icon_size, --icon-size icon_size

Set icon size to icon_size pixels. Default value: 24.

--icon-dirs dir1:dir2...

Use specified directories for icon lookup. Directories are separated by colons. If not specified, default icon search path is used.

-K, --kludges kludge1:kludge2...

Enable specified kludges. Kludges are workarounds for various non-standard behaviors of tray applications or window managers. For more details, see the file KLUDGES distributed with stalonetray.

-L, --log-level level

Set logging level. Possible values: error, warn, info, debug, trace. Default: info.

-m, --margin margin

Set tray margin to margin pixels. Default value: 0.

--max-geometry max_width[xmax_height]

Set maximum tray size. This is useful for systems with limited screen space.

-P program, --program program

Run program instead of trying to connect to the X server's root window. This is useful for running tray applications that do not implement the SNL-IPC protocol, such as older versions of xmms.

-p padding, --padding padding

Set icon padding to padding pixels. Default value: 0.

-Q, --quit-if-running

If another instance of stalonetray is already running, exit.

-R dir, --roots-dir dir

Set the directory to store the root pixmap. Default: ~/.stalonetray/roots.

-r name, --remote-click-icon name

Remote control/click. When this option is specified, stalonetray sends a fake click to the icon with a window named name and exits. The icon is searched for in the currently active tray for the current screen. By default, stalonetray sends a single click with the 1st mouse button to the center of the icon. See the options below for additional information on how to alter the defaults.

--remote-click-button n

Sets the remote click's button number to n (in the X11 numbering order).

--remote-click-position xxy

Sets the remote click's position.

--remote-click-type type

Sets the remote click's type. Possible values: single and double.

-S spart, --spart spart

Set the size of the space on the right side of the tray. Default: 0.

-s w[xb], --slot-size w[xb], slot_size w[xb]

Set grid slot width to w and height to b, both of which cannot be less than icon_size. By default, the slot size is the same as the icon size. If omitted, height is set to be same as width.

-t, --transparent, transparent [bool]

Enable root transparency. Default value: false.

-v, --vertical, vertical [bool]

Use vertical layout of icons (horizontal is used by default).

-W wpart, --wpart wpart

Set the size of the space on the left side of the tray. Default: 0.

--window-layer layer, window_layer layer

Sets the EWMH-compliant layer of tray`s window. Possible values for layer: bottom, normal, top. Default value: normal.

--window-strut mode, window_strut mode

Enable window struts for tray window (to avoid covering of tray window by maximized windows). Mode defines to which screen border tray window will be attached. It can be either top, bottom, left, right, none, or auto (default).

--window-type type, window_type type

Sets the EWMH-compliant type of tray`s window. Possible values for type: desktop, dock, normal, toolbar, utility. Default value: dock.

-x path_to_xpm, --xpm-file path_to_xpm

Use the specified XPM file as background for the tray's window. The pixmap will be tiled to fill the entire window.

--xsync, xsync [bool]

Operate on X server synchronously (SLOW, turned off by default).

--scrollbars mode, scrollbars mode

Set scrollbar mode. Possible values: vertical, horizontal, all, or none (default). Scrollbars appear as additional space at tray borders that can be clicked to scroll icon area. Mouse wheel also works.

--scrollbars-highlight mode, scrollbars_highlight mode

Set scrollbars highlight mode. Possible values: a color spec, or disable.

--scrollbars-size n, scrollbars_size n

Set scrollbar size to n pixels. By default, the size is 1/4 of slot_size.

--scrollbars-step n, scrollbars_step n

Set scrollbar step to n pixels. Default is 1/2 of slot_size.

--scroll-everywhere, scroll_everywhere [bool]

Enable scrolling outside of the scrollbars too. Default value: false.

--skip-taskbar, skip_taskbar [bool]

Hide tray`s window from the taskbar. Default value: false.

--sticky, sticky [bool]

Make tray`s window sticky across multiple desktops/pages. Default value: false.

--tint-color, tint_color [bool]

Set tinting color. Default value: white.

--tint-level, tint_level [level]

Set tinting level. Default value: 0 (tinting disabled).

-F font_prio, --font-prio font_prio

Use font priority font_prio. By default, stalonetray tries to use fonts in the following order: misc-fixed-medium-r-normal--14-130-75-75-m-70-iso10646-1, fixed.

-w, --withdrawn, withdrawn [bool]

Make tray window withdrawn. It will not be shown on the taskbar or by the window manager.

DEPRECATIONS

As of stalonetray 0.8, the following command line and configuration file parameters are deprecated:

--dbg-level, dbg_level

Please use --log-level instead.

--max-tray-width, --max-tray-height, max_tray_width, max_tray_height

Please use --max-geometry instead.

--respect-icon-hints, respect_icon_hints

Please use --kludges with use_icon_hints parameter instead.

-w, --withdrawn, withdrawn

Please use --dockapp-mode instead.

FILES

$HOME/.stalonetrayrc — default configuration file.

BUGS

There are some, definetly.

If you need support, the best way to get it is open an issue at the stalonetray github page[1] or to e-mail me directly at <busa_ru@users.sourceforge.net>.

If you have found a bug, please try to reproduce it with the log level set to trace and redirect standard error stream to a file. Then attach the file to a github issue or to an e-mail. If the issue is intermittent, attach two log files -- one with the good and one with the bad behavior. If you have installed stalonetray from a package repository, you can also file a bug in the respective bug tracking system.
