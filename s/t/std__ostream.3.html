DESCRIPTION

The sentry class is used to manage the setup and cleanup of output streams. When an output operation is performed, a sentry object is constructed. This object performs several actions, including checking the stream's state flags and potentially tying the stream to another stream. The constructed sentry object is then used to determine if the output operation should proceed.

If the stream's state flags indicate that the operation should proceed (i.e., the sentry status is good), the function attempts to generate the appropriate output for the given data type. If an exception is thrown during this process, the badbit flag is set in the stream's error state. If badbit is also set in the stream's exception mask, the exception is rethrown without completing its actions.

Parámetros

__except La nueva máscara de excepciones.

Por defecto, las marcas de error se establecen de forma silenciosa. Puede establecer una máscara de excepciones para cada flujo; si una marca en la máscara se establece en las marcas de error, se lanza una excepción de tipo std::ios_base::failure.

Si la marca de error ya está establecida cuando se añade la máscara de excepciones, la excepción se lanza inmediatamente. Intente ejecutar lo siguiente en GCC 3.1 o posterior:

#include <iostream>
#include <fstream>
#include <exception>
int main()
{
    std::set_terminate (__gnu_cxx::__verbose_terminate_handler);
    std::ifstream f ("/etc/motd");
    std::cerr << "Setting badbit\n";
    f.setstate (std::ios_base::badbit);
    std::cerr << "Setting exception mask\n";
    f.exceptions (std::ios_base::badbit);
}

Access to unique indices.

Returns

An integer different from all previous calls.

This function returns a unique integer every time it is called. It can be used for any purpose, but is primarily intended to be a unique index for the iword and pword functions. The expectation is that an application calls xalloc in order to obtain an index in the iword and pword arrays that can be used without fear of conflict.

The implementation maintains a static variable that is incremented and returned on each invocation. xalloc is guaranteed to return an index that is safe to use in the iword and pword arrays.

NAME

std::ios_base - The base class for all stream classes.

SYNOPSIS

#include <ios>

Detailed Description

The class std::ios_base is the base class for all stream classes. It holds information about the state of the stream, such as flags, width, precision, fill character, locale, and the stream buffer. It also defines enumeration types for stream state flags, stream formatting flags, and stream open modes.

This class is not intended to be instantiated directly. Instead, derived classes like std::basic_istream, std::basic_ostream, std::basic_iostream, std::basic_ifstream, std::basic_ofstream, and std::basic_fstream use it as a base class.

The following members are inherited from std::ios_base by stream classes.
