strcpy(3) Manual de Funciones de Biblioteca strcpy(3)

NOMBRE

stpcpy, strcpy, strcat - copiar o concatenar una cadena

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <string.h>
char *stpcpy(char *restrict dst, const char *restrict src);
char *strcpy(char *restrict dst, const char *restrict src);
char *strcat(char *restrict dst, const char *restrict src);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

stpcpy():

    Desde glibc 2.10:
        _POSIX_C_SOURCE >= 200809L
    Antes de glibc 2.10:
        _GNU_SOURCE

DESCRIPCIÓN

stpcpy()
strcpy()
Estas funciones copian la cadena apuntada por src a un búfer en la dirección apuntada por dst. El programador es responsable de asignar un búfer de destino lo suficientemente grande, es decir, strlen(src) + 1. Para la diferencia entre ambas funciones, ver VALOR DE RETORNO.
strcat()
Esta función concatena la cadena apuntada por src después de la cadena apuntada por dst (sobrescribiendo su byte nulo terminador). El programador es responsable de asignar un búfer de destino lo suficientemente grande, es decir, strlen(dst) + strlen(src) + 1.

Una implementación de estas funciones podría ser:


char *
stpcpy(char *restrict dst, const char *restrict src)
{
    char  *p;
    p = mempcpy(dst, src, strlen(src));
    *p = '\0';
    return p;
}
char *
strcpy(char *restrict dst, const char *restrict src)
{
    stpcpy(dst, src);
    return dst;
}
char *
strcat(char *restrict dst, const char *restrict src)
{
    stpcpy(dst + strlen(dst), src);
    return dst;
}

VALOR DE RETORNO

stpcpy()
Esta función devuelve un puntero al byte nulo terminador de la cadena copiada.
strcpy()
strcat()
Estas funciones devuelven dst.

ADVERTENCIAS

Las cadenas src y dst no deben solaparse.

Si el búfer de destino no es lo suficientemente grande, el comportamiento no está definido. Ver _FORTIFY_SOURCE en feature_test_macros(7).

strcat() puede ser muy ineficiente. Leer sobre Shlemiel the painter.

EJEMPLOS

#include <err.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int
main(void)
{
    char    *p;
    char    *buf1;
    char    *buf2;
    size_t  len, size;
    size = strlen("Hola ") + strlen("mundo") + strlen("!") + 1;
    buf1 = malloc(sizeof(*buf1) * size);
    if (buf1 == NULL)
        err(EXIT_FAILURE, "malloc()");
    buf2 = malloc(sizeof(*buf2) * size);
    if (buf2 == NULL)
        err(EXIT_FAILURE, "malloc()");
    p = buf1;
    p = stpcpy(p, "Hola ");
    p = stpcpy(p, "mundo");
    p = stpcpy(p, "!");
    len = p - buf1;
    printf("[len = %zu]: ", len);
    puts(buf1);  // "Hola mundo!"
    free(buf1);
    strcpy(buf2, "Hola ");
    strcat(buf2, "mundo");
    strcat(buf2, "!");
    len = strlen(buf2);
    printf("[len = %zu]: ", len);
    puts(buf2);  // "Hola mundo!"
    free(buf2);
    exit(EXIT_SUCCESS);
}

strcpy(3)

strcpy, strncpy - copiar cadenas de caracteres

Sintaxis

#include <string.h>

char *strcpy(char *dest, const char *src);
char *strncpy(char *dest, const char *src, size_t n);

Descripción

La función strcpy() copia la cadena apuntada por src (incluyendo el carácter nulo terminador) en la ubicación de memoria apuntada por dest. Las cadenas no deben superponerse, y el búfer de destino dest debe ser lo suficientemente grande como para contener la cadena.

La función strncpy() copia como máximo los primeros n caracteres de la cadena apuntada por src a la ubicación de memoria apuntada por dest. Si src es más corto que n, el resto de dest se rellena con caracteres nulos.

Tenga en cuenta que si la cadena src tiene una longitud de n o más, la cadena resultante en dest no estará terminada en nulo.

Valor de retorno

Tanto strcpy() como strncpy() devuelven un puntero al búfer de destino dest.

Errores

Estas funciones no establecen errno.

Atributos

Para obtener información sobre la semántica en distintos contextos, consulte attributes(7).

Conforme a

POSIX.1-2001, POSIX.1-2008, C89, C99, C11.

Notas

El uso de strcpy() es peligroso porque no hay forma de que la llamada determine si el búfer de destino es lo suficientemente grande como para contener el resultado. Si la cadena de origen es más larga que el búfer de destino, se producirá una desbordamiento del búfer. Por esta razón, strncpy() generalmente se prefiere a strcpy().

Sin embargo, incluso strncpy() puede ser inseguro si no se utiliza correctamente. Si n es menor que la longitud de src, la cadena resultante no estará terminada en nulo. Esto puede llevar a desbordamientos de búfer en llamadas posteriores que esperan una cadena terminada en nulo.

Para la copia de cadenas más segura, considere usar strlcpy() (si está disponible) o snprintf().

Ejemplos

#include <stdio.h>
#include <string.h>

int main() {
    char src[] = "Hola, mundo!";
    char dest[20];

    // Uso de strcpy
    strcpy(dest, src);
    printf("strcpy: %s\n", dest);

    // Uso de strncpy
    strncpy(dest, src, 10);
    dest[10] = '\0'; // Asegurar terminación nula
    printf("strncpy: %s\n", dest);

    return 0;
}
