NOMBRE

stringprep_profile - función API

SINOPSIS

#include <stringprep.h>

int stringprep_profile(const char * in, char ** out, const char * profile, Stringprep_profile_flags flags);

ARGUMENTOS

const char * in
cadena de entrada con terminación nula en UTF-8 para preparar.
char ** out
variable de salida con puntero a una cadena recién asignada.
const char * profile
nombre del perfil de stringprep a usar.
Stringprep_profile_flags flags
un valor de Stringprep_profile_flags, o 0.

DESCRIPCIÓN

Prepara la cadena de entrada terminada en cero y en UTF-8 según el perfil de stringprep, y devuelve el resultado en una variable recién asignada.

Tenga en cuenta que debe convertir las cadenas introducidas en la configuración regional del sistema a UTF-8 antes de usar esta función, vea stringprep_locale_to_utf8().

La variable de salida out debe ser liberada por el llamador.

Los flags son uno de los valores de Stringprep_profile_flags, o 0.

El profile especifica el nombre del perfil de stringprep a utilizar. Debe ser uno de los perfiles de stringprep soportados internamente.

Valor de retorno: Devuelve STRINGPREP_OK si tiene éxito, o un código de error.
