STARTFLUXBOX(1) Manual de Fluxbox STARTFLUXBOX(1)

NOMBRE

startfluxbox - iniciar una sesión de fluxbox

SINOPSIS

startfluxbox

DESCRIPCIÓN

startfluxbox es un script que ejecuta el archivo ~/.fluxbox/startup. Si no existe, será generado.

startfluxbox debe ser iniciado desde tu ~/.xinitrc si usas startx, o ~/.xsession si ejecutas un gestor de pantalla, como xdm.

ARCHIVOS

~/.fluxbox/startup

Este archivo contiene todos los comandos que deben ser ejecutados antes de iniciar fluxbox. El archivo inicial contiene comentarios útiles para principiantes. También inicia fluxbox.

EJEMPLOS

El ~/.fluxbox/startup predeterminado es el siguiente:

#!/bin/sh
#
# Script de inicio de fluxbox:
#
# Las líneas que comienzan con '#' se ignoran.
# Cambiar el mapa de teclas:
xmodmap "$HOME/.Xmodmap"
# Aplicaciones que deseas ejecutar con fluxbox.
# ASEGÚRATE DE QUE LAS APLICACIONES QUE PERMANECEN EN EJECUCIÓN TENGAN UN ''&'' AL FINAL.
#
# unclutter -idle 2 &
# wmnd &
# wmsmixer -w &
# idesk &
# Y por último, pero no menos importante, iniciamos fluxbox.
# Como es la última aplicación, debes ejecutarla con ''exec'' delante.
exec fluxbox
# o si quieres mantener un registro:
# exec fluxbox -log "$fluxdir/log"

Si necesitas iniciar aplicaciones después de fluxbox, puedes cambiar la línea exec fluxbox anterior por algo como esto:

exec fluxbox &
fbpid=$!
sleep 1
{
    xsetroot -cursor_name left_ptr -fg white -bg black &
    ipager &
    gkrellm2 &
} &
wait $fbpid

Así, xsetroot, ipager y gkrellm2 se iniciarán después de fluxbox, después de darle a fluxbox 1 segundo para iniciar.

Para más detalles sobre lo que puedes hacer en este script, consulta sh(1), o la documentación de tu shell.
