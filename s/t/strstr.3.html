strstr(3) Manual de funciones de biblioteca strstr(3)

NOMBRE

strstr, strcasestr - localizar una subcadena

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <string.h>
char *strstr(const char *haystack, const char *needle);
#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <string.h>
char *strcasestr(const char *haystack, const char *needle);

DESCRIPCIÓN

La función strstr() busca la primera ocurrencia de la subcadena needle en la cadena haystack. Los bytes nulos de terminación ('\0') no se comparan.

La función strcasestr() es similar a strstr(), pero ignora la mayúscula/minúscula de ambos argumentos.

VALOR DE RETORNO

Estas funciones devuelven un puntero al inicio de la subcadena localizada, o NULL si la subcadena no se encuentra.

Si needle es una cadena vacía, el valor de retorno es siempre haystack mismo.

AtRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).
