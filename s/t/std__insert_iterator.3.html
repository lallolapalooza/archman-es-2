Estos son iteradores de salida, construidos a partir de un contenedor de T. Asignar una T al iterador la inserta en el contenedor en la posición del iterador, en lugar de sobrescribir el valor en esa posición.

(Las secuencias insertarán realmente una copia del valor antes de la posición del iterador.)

Consejo: Usar la función inserter para crear estos iteradores puede ahorrar escritura.

Retorna

Este iterador, para operaciones encadenadas.

Este tipo de iterador mantiene su propia posición en el contenedor. Asignar un valor al iterador insertará el valor en el contenedor en el lugar anterior al iterador.

La posición se mantiene de tal manera que las asignaciones subsiguientes insertarán valores uno inmediatamente después del otro. Por ejemplo,

// el vector v contiene A y Z
insert_iterator i (v, ++v.begin());
i = 1;
i = 2;
i = 3;
// el vector v contiene A, 1, 2, 3 y Z

Resumen

Un iterador de inserción es un iterador de salida que inserta un elemento en una secuencia dada en una posición especificada. Si el contenedor subyacente es un adaptador de contenedor como std::map o std::set, la inserción se realiza mediante el método insert() del contenedor.

Sintaxis

template<class Container> class insert_iterator;

Descripción

Un iterador de inserción se utiliza para insertar elementos en un contenedor en una posición específica. El contenedor debe tener un método insert() que acepte un iterador y un valor. El iterador de inserción crea un objeto de iterador que apunta a una posición dentro de un contenedor. Cuando se asigna un valor al iterador de inserción, el valor se inserta en el contenedor en la posición especificada.

Ejemplo

#include <iostream>
#include <vector>
#include <iterator>
#include <algorithm>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    std::insert_iterator<std::vector<int>> it(vec, vec.begin() + 2);

    *it = 10; // Inserta 10 en la posición vec.begin() + 2

    for (int x : vec) {
        std::cout << x << " ";
    }
    std::cout << std::endl; // Salida: 1 2 10 3 4 5

    return 0;
}
