streqvcmp(3) Manual del programador streqvcmp(3)

NOMBRE

streqvcmp - compara dos cadenas con un mapeo de equivalencia

SINOPSIS

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

int streqvcmp(char const * str1, char const * str2);

DESCRIPCIÓN

Usando un mapeo de caracteres, se comparan dos cadenas para ver su "equivalencia". Cada carácter de entrada se mapea a un carácter de comparación y los caracteres mapeados se comparan para las dos cadenas de entrada terminadas en NUL. El nombre de esta función se mapea a option_streqvcmp para no entrar en conflicto con el espacio de nombres POSIX.

str1
primera cadena
str2
segunda cadena

VALOR DE RETORNO

la diferencia entre dos caracteres diferentes

ERRORES

no se comprueban. El llamador es responsable de los fallos de segmentación.
