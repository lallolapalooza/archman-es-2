NAME

std::istreambuf_iterator — Iterator for input stream buffer.

SYNOPSIS

#include <iterator>

Inherited from std::iterator

  template<typename _CharT, typename _Traits>
  class std::istreambuf_iterator : public std::iterator<
    input_iterator_tag, _CharT, typename _Traits::off_type, _CharT *, _CharT
    >

Detailed Description

An input stream buffer iterator is an iterator that iterates over the characters in an std::basic_streambuf.

A default-constructed istreambuf_iterator is an end-of-stream iterator. If s is an input stream, istreambuf_iterator<charT, traits>(s) gives an iterator pointing to the first character of the stream buffer associated with s. If sb is a pointer to a streambuf, istreambuf_iterator<charT, traits>(sb) gives an iterator pointing to the first character of the buffer *sb.

Two stream buffer iterators compare equal if they are both end-of-stream iterators, or if they both point to the same character.
