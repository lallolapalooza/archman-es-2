standards(7) Manual de Información Miscelánea standards(7)

NOMBRE

standards - Estándares C y UNIX

DESCRIPCIÓN

La sección STANDARDS que aparece en muchas páginas del manual identifica varios estándares a los que se adhiere la interfaz documentada. La siguiente lista describe brevemente estos estándares.

V7
UNIX Versión 7 (también conocido como Seventh Edition), lanzado por AT&T/Bell Labs en 1979. Después de este punto, los sistemas UNIX se dividieron en dos dialectos principales: BSD y System V.
4.2BSD
Este es un estándar de implementación definido por la versión 4.2 de la Berkeley Software Distribution, lanzada por la Universidad de California en Berkeley. Esta fue la primera versión de Berkeley que contenía una pila TCP/IP y la API de sockets. 4.2BSD se lanzó en 1983.
Las versiones anteriores importantes de BSD incluyeron 3BSD (1980), 4BSD (1980) y 4.1BSD (1981).
4.3BSD
El sucesor de 4.2BSD, lanzado en 1986.
4.4BSD
El sucesor de 4.3BSD, lanzado en 1993. Esta fue la última versión importante de Berkeley.
System V
Este es un estándar de implementación definido por la versión comercial de 1983 de AT&T, System V (cinco). La versión anterior importante de AT&T fue System III, lanzada en 1981.
System V release 2 (SVr2)
Esta fue la siguiente versión de System V, lanzada en 1985. El SVr2 fue descrito formalmente en la System V Interface Definition versión 1 (SVID 1) publicada en 1985.
System V release 3 (SVr3)
Este fue el sucesor de SVr2, lanzado en 1986. Esta versión fue descrita formalmente en la System V Interface Definition versión 2 (SVID 2).
System V release 4 (SVr4)
Este fue el sucesor de SVr3, lanzado en 1989. Esta versión de System V se describe en el "Programmer's Reference Manual: Operating System API (Intel processors)" (Prentice-Hall 1992, ISBN 0-13-951294-2). Esta versión se describió formalmente en la System V Interface Definition versión 3 (SVID 3), y se considera la versión definitiva de System V.
SVID 4
System V Interface Definition versión 4, publicada en 1995. Disponible en línea en http://www.sco.com/developers/devspecs/.
C89
Este fue el primer estándar del lenguaje C, ratificado por ANSI (American National Standards Institute) en 1989 (X3.159-1989). A veces se conoce como ANSI C, pero dado que C99 también es un estándar ANSI, este término es ambiguo. Este estándar también fue ratificado por ISO (International Standards Organization) en 1990 (ISO/IEC 9899:1990), y por lo tanto, ocasionalmente se hace referencia a él como ISO C90.
C99
Esta revisión del estándar del lenguaje C fue ratificada por ISO en 1999 (ISO/IEC 9899:1999). Disponible en línea en http://www.open-std.org/jtc1/sc22/wg14/www/standards.
C11
Esta revisión del estándar del lenguaje C fue ratificada por ISO en 2011 (ISO/IEC 9899:2011).
LFS
La especificación Large File Summit, completada en 1996. Esta especificación definió mecanismos que permitieron a los sistemas de 32 bits admitir el uso de archivos grandes (es decir, desplazamientos de archivo de 64 bits). Véase https://www.opengroup.org/platform/lfs.html.
POSIX.1-1988
Este fue el primer estándar POSIX, ratificado por IEEE como IEEE Std 1003.1-1988, y posteriormente adoptado (con revisiones menores) como un estándar ISO en 1990. El término "POSIX" fue acuñado por Richard Stallman.
POSIX.1-1990
"Portable Operating System Interface for Computing Environments". IEEE 1003.1-1990 parte 1, ratificada por ISO en 1990 (ISO/IEC 9945-1:1990).
POSIX.2
IEEE Std 1003.2-1992, que describe comandos y utilidades, ratificado por ISO en 1993 (ISO/IEC 9945-2:1993).
POSIX.1b (anteriormente conocido como POSIX.4)
IEEE Std 1003.1b-1993, que describe facilidades de tiempo real para sistemas operativos portátiles, ratificado por ISO en 1996 (ISO/IEC 9945-1:1996).
POSIX.1c (anteriormente conocido como POSIX.4a)
IEEE Std 1003.1c-1995, que describe las interfaces de hilos POSIX.
POSIX.1d
IEEE Std 1003.1d-1999, que describe extensiones de tiempo real adicionales.
POSIX.1g
IEEE Std 1003.1g-2000, que describe APIs de red (incluyendo sockets).
POSIX.1j
IEEE Std 1003.1j-2000, que describe extensiones avanzadas de tiempo real.
POSIX.1-1996
Una revisión de 1996 de POSIX.1 que incorporó POSIX.1b y POSIX.1c.
XPG3
Lanzada en 1989, esta fue la primera versión de la X/Open Portability Guide basada en un estándar POSIX (POSIX.1-1988). Esta guía de varios volúmenes fue desarrollada por el X/Open Group, un consorcio de múltiples proveedores.
XPG4
Una revisión de la X/Open Portability Guide, lanzada en 1992. Esta revisión incorporó POSIX.2.
XPG4v2
Una revisión de XPG4 de 1994. También se hace referencia a ella como Spec 1170, donde 1170 se refería al número de interfaces definidas por este estándar.
SUS (SUSv1)
Single UNIX Specification. Este fue un reenvasado de XPG4v2 y otros estándares de X/Open (X/Open Curses Issue 4 version 2, X/Open Networking Service (XNS) Issue 4). Los sistemas que cumplen con este estándar pueden ser etiquetados como UNIX 95.
SUSv2
Single UNIX Specification version 2. A veces también se hace referencia a ella (incorrectamente) como XPG5. Este estándar apareció en 1997. Los sistemas que cumplen con este estándar pueden ser etiquetados como UNIX 98. Véase también http://www.unix.org/version2/.)
POSIX.1-2001
SUSv3
Esta fue una revisión y consolidación de 2001 de los estándares POSIX.1, POSIX.2 y SUS en un único documento, realizada bajo los auspicios del Austin Group http://www.opengroup.org/austin/. El estándar está disponible en línea en http://www.unix.org/version3/.
El estándar define dos niveles de cumplimiento: Cumplimiento POSIX, que es un conjunto base de interfaces requerido para un sistema que cumple; y Cumplimiento XSI, que además exige un conjunto de interfaces (la "extensión XSI") que solo son opcionales para el cumplimiento POSIX. Los sistemas que cumplen con XSI pueden ser etiquetados como UNIX 03.
El documento POSIX.1-2001 se divide en cuatro partes:
XBD: Definiciones, términos y conceptos, especificaciones de archivos de cabecera.
XSH: Especificaciones de funciones (es decir, llamadas al sistema y funciones de biblioteca en implementaciones reales).
XCU: Especificaciones de comandos y utilidades (es decir, el área descrita anteriormente por POSIX.2).
XRAT: Texto informativo sobre las otras partes del estándar.
POSIX.1-2001 está alineado con C99, de modo que todas las funciones de biblioteca estandarizadas en C99

DESCRIPCIÓN

POSIX.1-2001 y SUSv3 se basan en POSIX.1-1996. Los principales cambios en esta revisión fueron la incorporación de la especificación de procesos de tiempo real de POSIX.1b y las especificaciones de tiempo real de POSIX.1c, así como la incorporación de algunas funcionalidades adicionales que también se estandarizaron en POSIX.1-2001.
La Single UNIX Specification versión 3 (SUSv3) comprende las Especificaciones Base que contienen XBD, XSH, XCU y XRAT como se mencionó anteriormente, además de X/Open Curses Issue 4 versión 2 como un volumen adicional que no está en POSIX.1-2001.
Han ocurrido dos Corrigendos Técnicos (arreglos y mejoras menores) del estándar original de 2001: TC1 en 2003 y TC2 en 2004.
POSIX.1-2008
SUSv4
El trabajo en la próxima revisión de POSIX.1/SUS se completó y ratificó en 2008. El estándar está disponible en línea en http://www.unix.org/version4/.
Los cambios en esta revisión no son tan grandes como los que ocurrieron para POSIX.1-2001/SUSv3, pero se agregan una serie de nuevas interfaces y se modifican varios detalles de las especificaciones existentes. Muchas de las interfaces que eran opcionales en POSIX.1-2001 se vuelven obligatorias en la revisión de 2008 del estándar. Algunas interfaces que están presentes en POSIX.1-2001 se marcan como obsoletas en POSIX.1-2008, o se eliminan del estándar por completo.
El estándar revisado está estructurado de la misma manera que su predecesor. La Single UNIX Specification versión 4 (SUSv4) comprende las Especificaciones Base que contienen XBD, XSH, XCU y XRAT, además de X/Open Curses Issue 7 como un volumen adicional que no está en POSIX.1-2008.
Nuevamente hay dos niveles de cumplimiento: el nivel base de Cumplimiento POSIX y el Cumplimiento XSI, que exige un conjunto adicional de interfaces más allá de las de la especificación base.
En general, donde la sección STANDARDS de una página de manual enumera POSIX.1-2001, se puede asumir que la interfaz también cumple con POSIX.1-2008, a menos que se indique lo contrario.
El Corrigendo Técnico 1 (arreglos y mejoras menores) de este estándar fue publicado en 2013.
El Corrigendo Técnico 2 de este estándar fue publicado en 2016.
Se puede encontrar más información en el sitio web de Austin Group, http://www.opengroup.org/austin/.
Edición 2016 de SUSv4
Esto es equivalente a POSIX.1-2008, con la adición de los Corrigendos Técnicos 1 y 2 y la especificación XCurses.
POSIX.1-2017
Esta revisión de POSIX es técnicamente idéntica a POSIX.1-2008 con los Corrigendos Técnicos 1 y 2 aplicados.
Edición 2018 de SUSv4
Esto es equivalente a POSIX.1-2017, con la adición de la especificación XCurses.

Las interfaces documentadas en POSIX.1/SUS están disponibles como páginas de manual en las secciones 0p (archivos de cabecera), 1p (comandos) y 3p (funciones); por lo tanto, se puede escribir "man 3p open".
