NOMBRE

storeid_file_rewrite - Ayuda basada en archivos para Store-ID para Squid

SINOPSIS

storeid_file_rewrite ruta_archivo

DESCRIPCIÓN

Este programa actúa como un programa de ayuda store_id, reescribiendo las URLs pasadas por Squid en store-ids que pueden ser usados para lograr un mejor almacenamiento en caché para sitios web que utilizan diferentes URLs para el mismo contenido.

Toma un archivo de texto con dos columnas separadas por tabulaciones. Columna 1: Expresión regular para coincidir con la URL Columna 2: Regla de reescritura para generar un Store-ID Ej: ^http:\/\/[^\.]+\.dl\.sourceforge\.net\/(.*) http://dl.sourceforge.net.squid.internal/$1

Las reglas de reescritura se comparan en el mismo orden en que aparecen en el archivo de reglas. Por lo tanto, para obtener el mejor rendimiento, ordénelo según la frecuencia de aparición.

Este programa detectará automáticamente la existencia de un ID de canal de concurrencia y se ajustará apropiadamente. Puede ser utilizado con cualquier valor de 0 o superior para el parámetro de concurrencia store_id_children=.

OPCIONES

El único parámetro de línea de comandos que acepta esta ayuda es el nombre del archivo de reglas regex.
