STEST(1) Manual de comandos generales STEST(1)

NOMBRE

stest - filtra una lista de archivos por propiedades

SINOPSIS

stest [-abcdefghlpqrsuwx] [-n archivo] [-o archivo] [archivo...]

DESCRIPCIÓN

stest toma una lista de archivos y los filtra por las propiedades de los archivos, análogamente a test(1). Los archivos que pasan todas las pruebas se imprimen en la salida estándar. Si no se proporcionan archivos, stest lee los archivos desde la entrada estándar.

OPCIONES

-a
Prueba archivos ocultos.
-b
Prueba que los archivos sean especiales de bloque.
-c
Prueba que los archivos sean especiales de carácter.
-d
Prueba que los archivos sean directorios.
-e
Prueba que los archivos existan.
-f
Prueba que los archivos sean archivos regulares.
-g
Prueba que los archivos tengan su bit set-group-ID activado.
-h
Prueba que los archivos sean enlaces simbólicos.
-l
Prueba el contenido de un directorio dado como argumento.
-n archivo
Prueba que los archivos sean más nuevos que archivo.
-o archivo
Prueba que los archivos sean más antiguos que archivo.
-p
Prueba que los archivos sean tuberías con nombre (FIFO).
-q
No se imprime ningún archivo, solo se devuelve el estado de salida.
-r
Prueba que los archivos sean legibles.
-s
Prueba que los archivos no estén vacíos.
-u
Prueba que los archivos tengan su bit set-user-ID activado.
-v
Invierte el sentido de las pruebas, solo los archivos fallidos pasan.
-w
Prueba que los archivos sean escribibles.
-x
Prueba que los archivos sean ejecutables.

ESTADO DE SALIDA

0
Al menos un archivo pasó todas las pruebas.
1
Ningún archivo pasó todas las pruebas.
2
Ocurrió un error.
