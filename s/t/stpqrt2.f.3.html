subrutina stpqrt2 (integer m, integer n, integer l, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldt, * ) t, integer ldt, integer info)

STPQRT2 calcula una factorización QR de una matriz real o compleja "triangular-pentagonal", que se compone de un bloque triangular y un bloque pentagonal, utilizando la representación WY compacta para Q.

Propósito:

!>
!> STPQRT2 calcula una factorización QR de una matriz real 
!> C, que se compone de un bloque triangular A y un bloque pentagonal B,
!> utilizando la representación WY compacta para Q.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número total de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz B, y el orden de
!>          la matriz triangular A.
!>          N >= 0.
!>

L

!>          L es ENTERO
!>          El número de filas de la parte superior trapezoidal de B.
!>          MIN(M,N) >= L >= 0. Véase Detalles Adicionales.
!>

A

!>          A es un array REAL, dimensionado (LDA,N)
!>          En la entrada, la matriz triangular superior N por N, A.
!>          En la salida, los elementos en y por encima de la diagonal del array
!>          contienen la matriz triangular superior R.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array REAL, dimensionado (LDB,N)
!>          En la entrada, la matriz pentagonal M por N, B. Las primeras M-L filas
!>          son rectangulares y las últimas L filas son trapezoidales superiores.
!>          En la salida, B contiene la matriz pentagonal V. Véase Detalles
!>          Adicionales.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B. LDB >= max(1,M).
!>

T

!>          T es un array REAL, dimensionado (LDT,N)
!>          El factor triangular superior N por N, T, del reflector de bloque.
!>          Véase Detalles Adicionales.
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal del array T. LDT >= max(1,N)
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  La matriz de entrada C es una matriz (N+M)-por-N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!>  donde A es una matriz triangular superior N-por-N, y B es una matriz
!>  pentagonal M-por-N que consiste en una matriz rectangular (M-L)-por-N,
!>  B1, en la parte superior de una matriz trapezoidal superior L-por-N, B2:
!>
!>               B = [ B1 ]  <- (M-L)-por-N rectangular
!>                   [ B2 ]  <-     L-por-N trapezoidal superior.
!>
!>  La matriz trapezoidal superior B2 consiste en las primeras L filas de una
!>  matriz triangular superior N-por-N, donde 0 <= L <= MIN(M,N). Si L=0,
!>  B es rectangular M-por-N; si M=L=N, B es triangular superior.
!>
!>  La matriz W almacena los reflectores elementales H(i) en la i-ésima columna
!>  debajo de la diagonal (de A) en la matriz de entrada C de (N+M)-por-N
!>
!>               C = [ A ]  <- triangular superior N-por-N
!>                   [ B ]  <- pentagonal M-por-N
!>
!>  de modo que W puede representarse como
!>
!>               W = [ I ]  <- identidad, N-por-N
!>                   [ V ]  <- M-por-N, misma forma que B.
!>
!>  Por lo tanto, toda la información necesaria para W está contenida en la salida
!>  en B, a la que llamamos V anteriormente. Nótese que V tiene la misma forma
!>  que B; es decir,
!>
!>               V = [ V1 ] <- (M-L)-por-N rectangular
!>                   [ V2 ] <-     L-por-N trapezoidal superior.
!>
!>  Las columnas de V representan los vectores que definen los H(i).
!>  El reflector de bloque H de (M+N)-por-(M+N) se da entonces por
!>
!>               H = I - W * T * W^H
!>
!>  donde W^H es la transpuesta conjugada de W y T es el factor triangular
!>  superior del reflector de bloque.
!>
