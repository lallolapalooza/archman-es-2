NOMBRE

statgrab - interfaz estilo sysctl para estadísticas del sistema

SINOPSIS


statgrab
[OPCIÓN]... [ESTAD]...

DESCRIPCIÓN

statgrab proporciona una interfaz estilo sysctl a todas las estadísticas del sistema disponibles a través de libstatgrab. Esto es útil para aplicaciones que no quieren hacer llamadas a la biblioteca, pero aún así quieren acceder a las estadísticas.

Un ejemplo de tal aplicación es mrtg, para la cual se proporcionan scripts para generar archivos de configuración.

OPCIONES

Se soportan las siguientes opciones.

-l
Salida estilo sysctl de Linux (por defecto)
-b
Salida estilo sysctl de BSD
-m
Salida compatible con MRTG
-u
Salida simple (solo mostrar valores)
-n
Mostrar estadísticas acumulativas una vez (por defecto)
-s
Mostrar diferencias de estadísticas repetidamente
-o
Mostrar diferencias de estadísticas una vez
-t RETRASO
Al repetir, esperar DELAY segundos entre actualizaciones (por defecto 1)
-p
Mostrar diferencias de uso de CPU como porcentajes en lugar de valores absolutos
-f FACTOR
Mostrar valores de punto flotante como enteros escalados por FACTOR
-K
Mostrar recuentos de bytes en kibibytes
-M
Mostrar recuentos de bytes en mebibytes
-G
Mostrar recuentos de bytes en gibibytes

Si no se proporcionan opciones ESTAD, se mostrarán todas. Especifique 'ESTAD.' para mostrar todas las estadísticas que comienzan con ese prefijo.
