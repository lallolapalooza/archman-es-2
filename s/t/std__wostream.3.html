std::basic_ostream

Inheritance diagram for std::basic_ostream

The basic_ostream class controls output to character sequences. The public members of this class are implemented in terms of functions and objects of the basic_ios class.

To make a complete output stream, a class derived from basic_ostream should be derived from a class derived from basic_streambuf. That derived class must then supply the stream buffer that the basic_ostream uses to perform output.

The basic_ostream constructor initializes its state from a basic_ios object. The constructor calls init. The default constructor initializes its state from a basic_ios object that has been initialized by means of a basic_streambuf.

The stream buffer object is accessed by means of a pointer to basic_streambuf. This pointer is initialized by the init member function. The stream buffer object referred to by this pointer may be changed by means of the set_rdbuf member function.

The public member functions of basic_ostream, and other standard classes, use a sentinel object of type std::basic_ostream::sentry. This has several effects, concluding with the setting of a status flag; see the sentry documentation for more.

If the sentry status is good, the function tries to generate whatever data is appropriate for the type of the argument.

If an exception is thrown during insertion, ios_base::badbit will be turned on in the stream's error state. If badbit is on in the stream's exceptions mask, the exception will be rethrown without completing its actions.

template<typename _CharT, typename _Traits> void std::basic_ios< _CharT, _Traits >::exceptions (iostate __except) [inline], [inherited]

Lanzamiento de excepciones por errores.

Parámetros

__except La nueva máscara de excepciones.

Por defecto, las banderas de error se establecen silenciosamente. Puede establecer una máscara de excepciones para cada flujo; si un bit en la máscara se establece en los indicadores de error, se lanza una excepción de tipo std::ios_base::failure.

Si el indicador de error ya está establecido cuando se agrega la máscara de excepciones, la excepción se lanza inmediatamente. Intente ejecutar lo siguiente en GCC 3.1 o posterior:

#include <iostream>
#include <fstream>
#include <exception>
int main()
{
    std::set_terminate (__gnu_cxx::__verbose_terminate_handler);
    std::ifstream f ("/etc/motd");
    std::cerr << "Setting badbit\n";
    f.setstate (std::ios_base::badbit);
    std::cerr << "Setting exception mask\n";
    f.exceptions (std::ios_base::badbit);
}

Extraer de otro streambuf.

Parámetros

__sb Un puntero a un streambuf

Esta función se comporta como uno de los extractores aritméticos básicos, en el sentido de que también construye un objeto sentry y tiene el mismo comportamiento de manejo de errores.

Si __sb es NULL, el stream establecerá failbit en su estado de error.

Los caracteres se extraen de __sb y se insertan en *this hasta que ocurre una de las siguientes condiciones:

  • el stream de entrada alcanza el fin de archivo,
  • la inserción en la secuencia de salida falla (en este caso, el carácter que se habría insertado no se extrae), o
  • ocurre una excepción al obtener un carácter de __sb, lo que establece failbit en el estado de error

Si la función no inserta ningún carácter, se establece failbit.

int std::ios_base::xalloc () [static], [inherited]

Access to unique indices.

Returns

An integer different from all previous calls.

This function returns a unique integer every time it is called. It can be used for any purpose, but is primarily intended to be a unique index for the iword and pword functions. The expectation is that an application calls xalloc in order to obtain an index in the iword and pword arrays that can be used without fear of conflict.

The implementation maintains a static variable that is incremented and returned on each invocation. xalloc is guaranteed to return an index that is safe to use in the iword and pword arrays.
