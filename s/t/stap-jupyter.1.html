STAP-JUPYTER-*(1) Manual de Comandos Generales STAP-JUPYTER-*(1)

NOMBRE

stap-jupyter-install - instala isystemtap localmente

stap-jupyter-container - administra una imagen de contenedor de isystemtap

SINOPSIS

stap-jupyter-install [--remove] [--container-install PREFIX]

stap-jupyter-container [--repo REPOSITORY] [--image IMAGE] [--tag TAG] [--keyname KEYNAME] --{run, pull, build, publish, remove}

DESCRIPCIÓN

ISystemtap es una interfaz interactiva de jupyter para la escritura y ejecución incremental de scripts de Systemtap.

El programa stap-jupyter-install se puede usar para instalar localmente el kernel de jupyter ISystemtap, el servidor de lenguaje y la extensión de jupyter-lab en ~/.systemtap/jupyter. Una vez instalado, el kernel puede ser utilizado con jupyter-lab.

Alternativamente, el programa stap-jupyter-container se puede utilizar para ejecutar ISystemtap dentro de un contenedor, evitando la necesidad de cualquier instalación local del kernel de jupyter.

OPCIONES DE INSTALACIÓN

Las siguientes opciones son compatibles con stap-jupyter-install. Cualquier otra opción imprime un mensaje de ayuda corto.

--remove
Desinstala los archivos locales de ISystemtap.
--container-install PREFIX
[Solo para mantenedores] Esto se utiliza para especificar el PREFIX del directorio de instalación para stap. Se llama dentro del proceso de construcción del contenedor y no debe usarse de otra manera.

OPCIONES DE CONTENEDOR

Las siguientes opciones son compatibles con stap-jupyter-container. Cualquier otra opción imprime un mensaje de ayuda corto.

--repo REPOSITORY
Especifica qué repositorio usar, por defecto es "quay.io".
--image IMAGE
Especifica el nombre de la imagen. Por defecto es "systemtap/isystemtap"
--tag TAG
Especifica la etiqueta de la imagen. Por defecto es "latest"
--keyname KEYNAME
Para que el contenedor pueda ejecutar stap, necesita hacer ssh al host. Requiere un par de claves ssh, y se especifica mediante KEYNAME, que por defecto es "id_rsa".

COMANDOS DE CONTENEDOR

Los siguientes comandos son reconocidos por stap-jupyter-container. Se requiere uno de los siguientes.

--run

Ejecuta la imagen. La descarga si aún no se ha hecho.
--pull

Descarga la imagen.
--build

Construye una copia local de la imagen. El repositorio será "localhost". Consulta podman images.
--remove

Elimina la imagen.
--publish

[Solo para mantenedores] Esto se utiliza para publicar la imagen construida. Requiere permisos de escritura en https://quay.io/systemtap/isystemtap.
