NOMBRE

stapref - referencia del lenguaje de systemtap

SINOPSIS

stapref

DESCRIPCIÓN

La referencia para el lenguaje de scripting de systemtap.

LENGUAJE

Palabras clave 

• break
• continue
• delete
• else
• exit
• foreach
• for
• function
• global
• private
• if
• in
• next
• probe
• return
• try/catch
• while

Tipos de datos y operadores 

Enteros
• var1 = 5
• global var2 = 10
Cadenas
• var1 = "cadena1"
• global var2 = "cadena2"
Arrays Asociativos
• global array1[]
• global array2[SIZE]
• array[index] = 5
Variables de Contexto
• $var
• $var$  (forma de cadena impresa de manera bonita)
Operadores numéricos binarios
• * / % + - << >> >>> & ^ | && ||
Operadores de cadena binarios
• . (concatenación de cadenas)
Operadores de asignación numérica
• = += -= *= /= %= >>= <<= &= ^= |= 
Operadores de asignación de cadenas
• = .= 
Operadores numéricos unarios
• + - ! ~ ++ -- 
Operadores de comparación numérica y de cadenas
• < > <= >= == != 
Operadores de coincidencia de expresiones regulares
• =~ !~ 
Operador ternario
• cond ? exp1 : exp2
Operador de agrupación
• ( expresión )
Operadores de arrays
• array[index] (lectura/escritura de array)
• [index] in array
Operador de agregación
• var <<< valor

Sentencias 

Sentencias de Salto
• continue
• break
• next  (retorno temprano de una sonda)
• return expresión (desde una función)
• try sentencia catch (mensaje) sentencia
Sentencias de Selección
• if (expresión) sentencia 
• else sentencia
Sentencias de Iteración
• foreach (variable in array) sentencia
• foreach ([var1,var2,...] in array) sentencia
• for (expresión; expresión; expresión) sentencia
• while (expresión) sentencia
Sentencias de Declaración
• function nombre (variable : tipo, ...) { sentencia }
• function nombre : tipo (variable : tipo, ...) { sentencia }
• function nombre : tipo (variable : tipo, ...) %{ sentencia_c %}
• probe punto_sonda { sentencia }
• probe etiqueta = punto_sonda { sentencia }

Estructura Léxica 

Comentarios
• # ... comentario
• // ... comentario
• /* ... comentario ... */
Preprocesador
• %( expresión %? tokens_verdaderos %: tokens_falsos %)
• @define etiqueta (variable, ...) %{ sentencia %}

Funciones Integradas 

Funciones de Agregación Integradas
• @avg (variable)
• @count (variable)
• @hist_linear (variable, N, N, N)
• @hist_log (variable)
• @max (variable)
• @min (variable)
• @sum (variable)
Funciones de Salida Integradas
• print (variable)
• printf (formato:cadena, variable, ...) 
  donde formato es de la forma: %[indicadores][ancho][.precision][longitud]especificador
• printd (delimitador:cadena, variable, ...)
• printdln (delimitador:cadena, variable, ...)
• println ()
• sprint:cadena (variable)
• sprintf:cadena (formato:cadena, variable, ...)
Funciones de Acceso a Variables Integradas
• @var ("nombre_var[@src/ARCHIVO.c]"[, "módulo"]) (estático o global)
• @cast (variable, "nombre_tipo"[, "módulo"])
• @defined (variable)
• @probewrite (variable)
