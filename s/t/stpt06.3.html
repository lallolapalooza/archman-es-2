Documentación de la función/subrutina

subrutina stpt06 (real rcond, real rcondc, character uplo, character diag, integer n, real, dimension( * ) ap, real, dimension( * ) work, real rat)

STPT06

Propósito

!>
!> STPT06 calcula una relación de prueba que compara RCOND (el recíproco
!> del número de condición de una matriz triangular A) y RCONDC, la estimación
!> calculada por STPCON. Se utiliza información sobre la matriz triangular A
!> si una estimación es cero y la otra no es cero para decidir si
!> el subdesbordamiento en la estimación está justificado.
!>

Parámetros

RCOND 
!>          RCOND es REAL
!>          La estimación del recíproco del número de condición obtenida al
!>          formar la inversa explícita de la matriz A y calcular
!>          RCOND = 1/( norma(A) * norma(inv(A)) ).
!>

RCONDC

!>          RCONDC es REAL
!>          La estimación del recíproco del número de condición calculada
!>          por STPCON.
!>

UPLO

!>          UPLO es CHARACTER
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

DIAG

!>          DIAG es CHARACTER
!>          Especifica si la matriz A es triangular unitaria o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array REAL, de dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por columnas en
!>          un array lineal. La columna j de A se almacena en el array
!>          AP como sigue:
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) para j<=i<=n.
!>

WORK

!>          WORK es un array REAL, de dimensión (N)
!>

RAT

!>          RAT es REAL
!>          La relación de prueba. Si ambos RCOND y RCONDC son distintos de cero,
!>             RAT = MAX( RCOND, RCONDC )/MIN( RCOND, RCONDC ) - 1.
!>          Si RAT = 0, las dos estimaciones son exactamente iguales.
!>
