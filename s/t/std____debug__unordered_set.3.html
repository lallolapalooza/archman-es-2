NAME

std::__debug::unordered_set - Class std::unordered_set with safety/checking/debug instrumentation.

SYNOPSIS

#include <unordered_set>

template<
    typename _Value,
    typename _Hash = std::hash<_Value>,
    typename _Pred = std::equal_to<_Value>,
    typename _Alloc = std::allocator<_Value>
>
class unordered_set : public std::__debug::unordered_set_base<
    _Value, _Hash, _Pred, _Alloc
>;

Detailed Description

This is a wrapper around std::unordered_set that adds debugging checks.

This class is part of the C++ Standard Library, specifically in the <unordered_set> header.

It provides the same interface as std::unordered_set but with additional checks and assertions to help catch programming errors during development. These checks are typically enabled when compiling with debug symbols or specific compiler flags.

The template parameters are:

_Value
The type of the elements stored in the set.
_Hash
A function object type that computes the hash value for elements of type _Value. Defaults to std::hash<_Value>.
_Pred
A binary predicate type that determines equality between elements of type _Value. Defaults to std::equal_to<_Value>.
_Alloc
The allocator type used for memory management. Defaults to std::allocator<_Value>.

The debug version of unordered_set is intended to be used during development to catch potential issues such as:

  • Out-of-bounds access.
  • Iterator invalidation errors.
  • Incorrect hashing or equality comparison logic.

When not in debug mode, the compiler will typically use the non-debug version of std::unordered_set directly.
