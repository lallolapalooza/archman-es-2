Documentación de la función/subrutina

subroutine stpqrt (integer m, integer n, integer l, integer nb, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldt, * ) t, integer ldt, real, dimension( * ) work, integer info)

STPQRT

Propósito:

!>
!> STPQRT calcula una factorización QR bloqueada de una matriz real
!>  C, que se compone de un bloque triangular A y un bloque pentagonal B,
!>  utilizando la representación compacta WY para Q.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B y el orden de la
!>          matriz triangular A.
!>          N >= 0.
!>

L

!>          L es INTEGER
!>          El número de filas de la parte trapezoidal superior de B.
!>          MIN(M,N) >= L >= 0.  Ver Detalles Adicionales.
!>

NB

!>          NB es INTEGER
!>          El tamaño del bloque a utilizar en la QR bloqueada.  N >= NB >= 1.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz N-por-N triangular superior A.
!>          En la salida, los elementos en y por encima de la diagonal de la
!>          matriz contienen la matriz triangular superior R.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array REAL, de dimensión (LDB,N)
!>          En la entrada, la matriz pentagonal M-por-N B. Las primeras M-L filas
!>          son rectangulares, y las últimas L filas son trapezoidales superiores.
!>          En la salida, B contiene la matriz pentagonal V. Ver Detalles Adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,M).
!>

T

!>          T es un array REAL, de dimensión (LDT,N)
!>          Los reflectores de bloque triangulares superiores almacenados en
!>          forma compacta como una secuencia de bloques triangulares superiores.
!>          Ver Detalles Adicionales.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.  LDT >= NB.
!>

WORK

!>          WORK es un array REAL, de dimensión (NB*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  La matriz de entrada C es una matriz de (N+M)-por-N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!>  donde A es una matriz N-por-N triangular superior, y B es una matriz
!>  pentagonal M-por-N que consta de una matriz rectangular B1 de (M-L)-por-N
!>  en la parte superior de una matriz trapezoidal superior B2 de L-por-N:
!>
!>               B = [ B1 ]  <- Matriz rectangular de (M-L)-por-N
!>                   [ B2 ]  <- Matriz trapezoidal superior de L-por-N.
!>
!>  La matriz trapezoidal superior B2 consta de las primeras L filas de una
!>  matriz triangular superior N-por-N, donde 0 <= L <= MIN(M,N). Si L=0,
!>  B es rectangular M-por-N; si M=L=N, B es triangular superior.
!>
!>  La matriz W almacena los reflectores elementales H(i) en la i-ésima columna
!>  debajo de la diagonal (de A) en la matriz de entrada C de (N+M)-por-N
!>
!>               C = [ A ]  <- Triangular superior N-por-N
!>                   [ B ]  <- Pentagonal M-por-N
!>
!>  tal que W se puede representar como
!>
!>               W = [ I ]  <- Identidad, N-por-N
!>                   [ V ]  <- M-por-N, misma forma que B.
!>
!>  Por lo tanto, toda la información necesaria para W se contiene en la salida
!>  en B, que llamamos V arriba. Tenga en cuenta que V tiene la misma forma que B;
!>  es decir,
!>
!>               V = [ V1 ] <- Rectangular de (M-L)-por-N
!>                   [ V2 ] <- Trapezoidal superior de L-por-N.
!>
!>  Las columnas de V representan los vectores que definen los H(i).
!>
!>  El número de bloques es B = techo(N/NB), donde cada
!>  bloque es de orden NB excepto el último bloque, que es de orden
!>  IB = N - (B-1)*NB. Para cada uno de los B bloques, se calcula un factor
!>  de reflector de bloque triangular superior: T1, T2, ..., TB. Los T de NB-por-NB
!>  (y IB-por-IB para el último bloque) se almacenan en la matriz T de NB-por-N como
!>
!>               T = [T1 T2 ... TB].
!>
