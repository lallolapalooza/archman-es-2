DSTEBZ

Propósito:

!>
!> DSTEBZ calcula los valores propios de una matriz tridiagonal simétrica
!> T. El usuario puede solicitar todos los valores propios, todos los valores
!> propios en el intervalo semiabierto (VL, VU], o los valores propios IL-ésimo
!> hasta el IU-ésimo.
!>
!> Para evitar desbordamientos, la matriz debe escalarse de modo que su
!> elemento más grande no supere overflow**(1/2) * underflow**(1/4) en valor
!> absoluto, y para obtener la máxima precisión, no debe ser mucho menor
!> que eso.
!>
!> Véase W. Kahan, Report CS41, Computer Science Dept., Stanford
!> University, 21 de julio de 1966.
!>

Parámetros

RANGE 
!>          RANGE es CHARACTER*1
!>          = 'A': ()   se encontrarán todos los valores propios.
!>          = 'V': () se encontrarán todos los valores propios en el intervalo
!>                           semiabierto (VL, VU].
!>          = 'I': () se encontrarán los valores propios IL-ésimo hasta el IU-ésimo
!>                           (de la matriz completa).
!>

ORDER

!>          ORDER es CHARACTER*1
!>          = 'B': () los valores propios se agruparán por
!>                              bloque separado (ver IBLOCK, ISPLIT) y
!>                              se ordenarán de menor a mayor dentro de
!>                              cada bloque.
!>          = 'E': ()
!>                              los valores propios de la matriz completa
!>                              se ordenarán de menor a mayor.
!>

N

!>          N es INTEGER
!>          El orden de la matriz tridiagonal T. N >= 0.
!>

VL

!>          VL es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite inferior del intervalo donde
!>          buscar los valores propios. Los valores propios menores o iguales
!>          a VL, o mayores que VU, no se devolverán. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite superior del intervalo donde
!>          buscar los valores propios. Los valores propios menores o iguales
!>          a VL, o mayores que VU, no se devolverán. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia absoluta para los valores propios. Un valor propio
!>          (o grupo) se considera localizado si se ha determinado que se
!>          encuentra en un intervalo cuyo ancho es ABSTOL o
!>          menor. Si ABSTOL es menor o igual a cero, se usará
!>          ULP*|T|, donde |T| significa la norma 1 de T.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'),
!>          no en cero.
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (N-1)
!>          Los n-1 elementos fuera de la diagonal de la matriz tridiagonal T.
!>

M

!>          M es INTEGER
!>          El número real de valores propios encontrados. 0 <= M <= N.
!>          (Ver también la descripción de INFO=2,3.)
!>

NSPLIT

!>          NSPLIT es INTEGER
!>          El número de bloques diagonales en la matriz T.
!>          1 <= NSPLIT <= N.
!>

W

!>          W es un array DOUBLE PRECISION, de dimensión (N)
!>          A la salida, los primeros M elementos de W contendrán los
!>          valores propios. (DSTEBZ puede usar los N-M elementos restantes como
!>          espacio de trabajo.)
!>

IBLOCK

!>          IBLOCK es un array INTEGER, de dimensión (N)
!>          En cada fila/columna j donde E(j) es cero o pequeño,
!>          la matriz T se considera dividida en una matriz diagonal por bloques.
!>          A la salida, si INFO = 0, IBLOCK(i) especifica a qué
!>          bloque (de 1 al número de bloques) pertenece el valor propio W(i).
!>          (DSTEBZ puede usar los N-M elementos restantes como
!>          espacio de trabajo.)
!>

ISPLIT

!>          ISPLIT es un array INTEGER, de dimensión (N)
!>          Los puntos de división, en los que T se divide en submatrices.
!>          La primera submatriz consta de las filas/columnas 1 a ISPLIT(1),
!>          la segunda de las filas/columnas ISPLIT(1)+1 hasta ISPLIT(2),
!>          etc., y la NSPLIT-ésima consta de las filas/columnas
!>          ISPLIT(NSPLIT-1)+1 hasta ISPLIT(NSPLIT)=N.
!>          (Solo se utilizarán los primeros NSPLIT elementos, pero
!>          como el usuario no puede saber de antemano qué valor tendrá NSPLIT,
!>          se deben reservar N palabras para ISPLIT.)
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (4*N)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (3*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  algunos o todos los valores propios no convergieron o
!>                no se calcularon:
!>                =1 o 3: La bisección falló en converger para algunos
!>                        valores propios; estos valores propios están marcados con un
!>                        número de bloque negativo. El efecto es que los
!>                        valores propios pueden no ser tan precisos como las
!>                        tolerancias absoluta y relativa. Esto es
!>                        generalmente causado por una aritmética inesperadamente imprecisa.
!>                =2 o 3: Solo RANGE='I': No se encontraron todos los valores propios
!>                        IL:IU.
!>                        Efecto: M < IU+1-IL
!>                        Causa:  aritmética no monótona, que hace que la
!>                                secuencia de Sturm no sea monótona.
!>                        Solución: recalcular, usando RANGE='A', y seleccionar
!>                                los valores propios IL:IU. En algunos casos,
!>                                aumentar el PARÁMETRO  puede

DSTEbz

Purpose:

!>
!> DSTEbz computes the eigenvalues of a symmetric tridiagonal
!> matrix T.  The user may ask for all eigenvalues, all eigenvalues
!> in the half-open interval (VL, VU], or the IL-th through IU-th
!> eigenvalues.
!>
!> To avoid overflow, the matrix must be scaled so that its
!> largest element is no greater than overflow**(1/2) * underflow**(1/4) in absolute value, and for greatest
!> accuracy, it should not be much smaller than that.
!>
!> See W. Kahan , Report CS41, Computer Science Dept., Stanford
!> University, July 21, 1966.
!>

Parameters

RANGE 
!>          RANGE is CHARACTER*1
!>          = 'A': ()   all eigenvalues will be found.
!>          = 'V': () all eigenvalues in the half-open interval
!>                           (VL, VU] will be found.
!>          = 'I': () the IL-th through IU-th eigenvalues (of the
!>                           entire matrix) will be found.
!>

ORDER

!>          ORDER is CHARACTER*1
!>          = 'B': () the eigenvalues will be grouped by
!>                              split-off block (see IBLOCK, ISPLIT) and
!>                              ordered from smallest to largest within
!>                              the block.
!>          = 'E': ()
!>                              the eigenvalues for the entire matrix
!>                              will be ordered from smallest to
!>                              largest.
!>

N

!>          N is INTEGER
!>          The order of the tridiagonal matrix T.  N >= 0.
!>

VL

!>          VL is REAL
!>
!>          If RANGE='V', the lower bound of the interval to
!>          be searched for eigenvalues.  Eigenvalues less than or equal
!>          to VL, or greater than VU, will not be returned.  VL < VU.
!>          Not referenced if RANGE = 'A' or 'I'.
!>

VU

!>          VU is REAL
!>
!>          If RANGE='V', the upper bound of the interval to
!>          be searched for eigenvalues.  Eigenvalues less than or equal
!>          to VL, or greater than VU, will not be returned.  VL < VU.
!>          Not referenced if RANGE = 'A' or 'I'.
!>

IL

!>          IL is INTEGER
!>
!>          If RANGE='I', the index of the
!>          smallest eigenvalue to be returned.
!>          1 <= IL <= IU <= N, if N > 0; IL = 1 and IU = 0 if N = 0.
!>          Not referenced if RANGE = 'A' or 'V'.
!>

IU

!>          IU is INTEGER
!>
!>          If RANGE='I', the index of the
!>          largest eigenvalue to be returned.
!>          1 <= IL <= IU <= N, if N > 0; IL = 1 and IU = 0 if N = 0.
!>          Not referenced if RANGE = 'A' or 'V'.
!>

ABSTOL

!>          ABSTOL is REAL
!>          The absolute tolerance for the eigenvalues.  An eigenvalue
!>          (or cluster) is considered to be located if it has been
!>          determined to lie in an interval whose width is ABSTOL or
!>          less.  If ABSTOL is less than or equal to zero, then ULP*|T|
!>          will be used, where |T| means the 1-norm of T.
!>
!>          Eigenvalues will be computed most accurately when ABSTOL is
!>          set to twice the underflow threshold 2*SLAMCH('S'), not zero.
!>

D

!>          D is REAL array, dimension (N)
!>          The n diagonal elements of the tridiagonal matrix T.
!>

E

!>          E is REAL array, dimension (N-1)
!>          The (n-1) off-diagonal elements of the tridiagonal matrix T.
!>

M

!>          M is INTEGER
!>          The actual number of eigenvalues found. 0 <= M <= N.
!>          (See also the description of INFO=2,3.)
!>

NSPLIT

!>          NSPLIT is INTEGER
!>          The number of diagonal blocks in the matrix T.
!>          1 <= NSPLIT <= N.
!>

W

!>          W is REAL array, dimension (N)
!>          On exit, the first M elements of W will contain the
!>          eigenvalues.  (DSTEbz may use the remaining N-M elements as
!>          workspace.)
!>

IBLOCK

!>          IBLOCK is INTEGER array, dimension (N)
!>          At each row/column j where E(j) is zero or small, the
!>          matrix T is considered to split into a block diagonal
!>          matrix.  On exit, if INFO = 0, IBLOCK(i) specifies to which
!>          block (from 1 to the number of blocks) the eigenvalue W(i)
!>          belongs.  (DSTEbz may use the remaining N-M elements as
!>          workspace.)
!>

ISPLIT

!>          ISPLIT is INTEGER array, dimension (N)
!>          The splitting points, at which T breaks up into submatrices.
!>          The first submatrix consists of rows/columns 1 to ISPLIT(1),
!>          the second of rows/columns ISPLIT(1)+1 through ISPLIT(2),
!>          etc., and the NSPLIT-th consists of rows/columns
!>          ISPLIT(NSPLIT-1)+1 through ISPLIT(NSPLIT)=N.
!>          (Only the first NSPLIT elements will actually be used, but
!>          since the user cannot know a priori what value NSPLIT will
!>          have, N words must be reserved for ISPLIT.)
!>

WORK

!>          WORK is REAL array, dimension (4*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (3*N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  some or all of the eigenvalues failed to converge or
!>                were not computed:
!>                =1 or 3: Bisection failed to converge for some
!>                        eigenvalues; these eigenvalues are flagged by a
!>                        negative block number.  The effect is that the
!>                        eigenvalues may not be as accurate as the
!>                        absolute and relative tolerances.  This is
!>                        generally caused by unexpectedly inaccurate
!>                        arithmetic.
!>                =2 or 3: RANGE='I' only: Not all of the eigenvalues
!>                        IL:IU were found.
!>                        Effect: M < IU+1-IL
!>                        Cause:  non-monotonic arithmetic, causing the
!>                                Sturm sequence to be non-monotonic.
!>                        Cure:   recalculate, using RANGE='A', and pick
!>                                out eigenvalues IL:IU.  In some cases,
!>                                increasing the PARAMETER  may
!>                                make things work.
!>                = 4:    RANGE='I', and the Gershgorin interval
!>                        initially used was too small.  No eigenvalues
!>                        were computed.
!>                        Probable cause: your machine has sloppy
!>                                        floating-point arithmetic.
!>                        Cure: Increase the PARAMETER ,
!>                              recompile, and try again.
!>

Internal Parameters:

!>  RELFAC  REAL, default = 2.0e0
!>          The relative tolerance.  An interval (a,b] lies within
!>           if  b-a < RELFAC*ulp*max(|a|,|b|),
!>          where  is the machine precision (distance from 1 to
!>          the next larger floating point number.)
!>
!>  FUDGE   REAL, default = 2
!>          A  to widen the Gershgorin intervals.  Ideally,
!>          a value of 1 should work, but on machines with sloppy
!>          arithmetic, this needs to be larger.  The default for
!>          publicly released versions should be large enough to handle
!>          the worst machine around.  Note that this has no effect
!>          on accuracy of the solution.
!>

!>          Eigenvalues will be computed most accurately when ABSTOL is
!>          set to twice the underflow threshold 2*SLAMCH('S'), not zero.
!>

!>          NSPLIT is INTEGER

!>          IBLOCK is INTEGER array, dimension (N)
!>          At each row/column j where E(j) is zero or small, the

!>          matrix.  On exit, if INFO = 0, IBLOCK(i) specifies to which
!>          block (from 1 to the number of blocks) the eigenvalue W(i)
!>          belongs.  (SSTEbz may use the remaining N-M elements as
!>          workspace.)
!>

!>          ISPLIT is INTEGER array, dimension (N)
!>          The splitting points, at which T breaks up into submatrices.
!>          The first submatrix consists of rows/columns 1 to ISPLIT(1),
!>          the second of rows/columns ISPLIT(1)+1 through ISPLIT(2),

!>          WORK is REAL array, dimension (4*N)

!>          IWORK is INTEGER array, dimension (3*N)

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  some or all of the eigenvalues failed to converge or
!>                were not computed:
!>                =1 or 3: Bisection failed to converge for some
!>                        eigenvalues; these eigenvalues are flagged by a
!>                        negative block number.  The effect is that the
!>                        eigenvalues may not be as accurate as the
!>                        absolute and relative tolerances.  This is
!>                        generally caused by unexpectedly inaccurate
!>                        arithmetic.
!>                =2 or 3: RANGE='I' only: Not all of the eigenvalues
!>                        IL:IU were found.
!>                        Effect: M < IU+1-IL
!>                        Cause:  non-monotonic arithmetic, causing the
!>                                Sturm sequence to be non-monotonic.
!>                        Cure:   recalculate, using RANGE='A', and pick
!>                                out eigenvalues IL:IU.  In some cases,
!>                                increasing the PARAMETER  may
!>                                make things work.
!>                = 4:    RANGE='I', and the Gershgorin interval
!>                        initially used was too small.  No eigenvalues
!>                        were computed.
!>                        Probable cause: your machine has sloppy
!>                                        floating-point arithmetic.
!>                        Cure: Increase the PARAMETER ,

!>          A  to widen the Gershgorin intervals.  Ideally,
!>          a value of 1 should work, but on machines with sloppy
!>          arithmetic, this needs to be larger.  The default for
!>          publicly released versions should be large enough to handle
!>          the worst machine around.  Note that this has no effect
!>          on accuracy of the solution.

stebz - computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.

Detailed Description

stebz computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix T.

Parameters

  • JOBZ (CHARACTER*1)
    • 'E': Compute all eigenvalues and eigenvectors.
    • 'V': Compute all eigenvalues and eigenvectors, and return them in Z.
    • 'N': Compute all eigenvalues only.
  • RANGE (CHARACTER*1)
    • 'A': All eigenvalues will be found.
    • 'V': All eigenvalues in the interval (VL, VU] will be found.
    • 'I': All eigenvalues in the index range [IL, IU] will be found.
  • N (INTEGER)

    The order of the matrix T. 0 <= N.

  • VL (REAL (KIND=4))

    The lower or upper boundary of the interval for the range 'V' search for eigenvalues.

  • VU (REAL (KIND=4))

    The upper or lower boundary of the interval for the range 'V' search for eigenvalues.

  • IL (INTEGER)

    The starting index for the range 'I' search for eigenvalues.

  • IU (INTEGER)

    The ending index for the range 'I' search for eigenvalues.

  • ABSTOL (REAL (KIND=4))

    The absolute tolerance for convergence. If ABSTOL <= 0, then the machine precision is used.

  • M (INTEGER)

    The number of eigenvalues found. 0 <= M <= N.

  • NZ (INTEGER)

    The number of eigenvectors computed. 0 <= NZ <= N.

  • D (REAL (KIND=4))

    On entry, the N diagonal elements of the tridiagonal matrix T. On exit, the N eigenvalues, sorted in increasing order.

  • Z (REAL (KIND=4))

    On exit, the N-by-M matrix Z of computed eigenvectors. If JOBZ = 'E', Z contains the eigenvectors in the columns. If JOBZ = 'N', Z is not used.

  • LDZ (INTEGER)

    The leading dimension of the array Z. LDZ >= max(1, N).

  • ISUPPZ (INTEGER)

    On exit, the support of the eigenvectors in Z. ISUPPZ(I) is the index of the first element of the subdiagonal block for the I-th eigenvector.

  • WORK (REAL (KIND=4))

    Work array.

  • INFO (INTEGER)

    • 0: successful exit
    • <0: if INFO = -i, the i-th argument had an illegal value
    • >0: if INFO = i, then the algorithm did not converge; i is the number of nonsymmetric eigenvalues.
