DESCRIPTION

This namespace is for features defined in ISO Technical Specifications.

fundamentals_v2

This namespace contains metaprogramming utilities and concepts similar to those found in the C++ standard library, often prefixed with is_, has_, or alignment_of_.

It also contains:

  • conjunction_v, disjunction_v, negation_v: Boolean meta-functions for combining type traits.
  • void_t: A template alias that yields void, useful for SFINAE techniques.
  • detected_or, detected_or_t, detected_t, is_detected, is_detected_exact, is_detected_convertible, is_detected_v, is_detected_exact_v, is_detected_convertible_v: Utilities for detecting whether a given expression is valid and has certain properties.
  • gcd, lcm: Functions for calculating the greatest common divisor and least common multiple, respectively.
  • get_deleter: Retrieves the deleter object from a std::shared_ptr.
  • not_fn: Creates a wrapper that negates the result of a callable object.
  • make_ostream_joiner: Creates an output iterator that joins elements with a delimiter when writing to an output stream.

fundamentals_v1

This namespace contains algorithm customization points, allowing users to provide their own search algorithms to standard library algorithms like std::find_first_of.

It includes:

  • make_boyer_moore_horspool_searcher: Creates a searcher object that implements the Boyer-Moore-Horspool string searching algorithm.
  • make_boyer_moore_searcher: Creates a searcher object that implements the Boyer-Moore string searching algorithm.
  • make_default_searcher: Creates a searcher object that uses the default search algorithm provided by the standard library.
