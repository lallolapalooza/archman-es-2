stpncpy(3) Manual de Funciones de Biblioteca stpncpy(3)

NOMBRE

stpncpy, strncpy - llenar un búfer de tamaño fijo con bytes no nulos de una cadena, rellenando con bytes nulos según sea necesario

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <string.h>
char *strncpy(size_t dsize;
              char dst[restrict dsize], const char *restrict src,
              size_t dsize);
char *stpncpy(size_t dsize;
              char dst[restrict dsize], const char *restrict src,
              size_t dsize);
Requisitos de Macro de Prueba de Características para glibc (ver feature_test_macros(7)):

stpncpy():

    Desde glibc 2.10:
        _POSIX_C_SOURCE >= 200809L
    Antes de glibc 2.10:
        _GNU_SOURCE

DESCRIPCIÓN

Estas funciones copian bytes no nulos de la cadena apuntada por src al array apuntado por dst. Si la fuente tiene suficientes bytes no nulos para llenar el destino, las funciones rellenan el destino con bytes nulos finales. Si el búfer de destino, limitado por su tamaño, no es lo suficientemente grande para contener la copia, la secuencia de caracteres resultante se trunca. Para ver la diferencia entre las dos funciones, consulte VALOR DE RETORNO.

Una implementación de estas funciones podría ser:


char *
strncpy(char *restrict dst, const char *restrict src, size_t dsize)
{
    stpncpy(dst, src, dsize);
    return dst;
}
char *
stpncpy(char *restrict dst, const char *restrict src, size_t dsize)
{
    size_t  dlen;
    dlen = strnlen(src, dsize);
    return memset(mempcpy(dst, src, dlen), 0, dsize - dlen);
}

VALOR DE RETORNO

strncpy()
devuelve dst.
stpncpy()
devuelve un puntero a un carácter después del último carácter ancho no nulo escrito, es decir, dest + strnlen(src, n).

ADVERTENCIAS

El nombre de estas funciones es confuso. Estas funciones producen una secuencia de caracteres rellenada con nulos, no una cadena (ver string_copying(7)). Por ejemplo:


strncpy(buf, "1", 5);       // { '1',   0,   0,   0,   0 }
strncpy(buf, "1234", 5);    // { '1', '2', '3', '4',   0 }
strncpy(buf, "12345", 5);   // { '1', '2', '3', '4', '5' }
strncpy(buf, "123456", 5);  // { '1', '2', '3', '4', '5' }

Es imposible distinguir el truncamiento por el resultado de la llamada de una secuencia de caracteres que simplemente encaja en el búfer de destino; el truncamiento debe detectarse comparando la longitud de la cadena de entrada con el tamaño del búfer de destino.

Si va a utilizar esta función en llamadas encadenadas, sería útil desarrollar una función similar que acepte un puntero al final (uno después del último elemento) del búfer de destino en lugar de su tamaño.

EJEMPLOS

#include <err.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int
main(void)
{
    char    *p;
    char    buf1[20];
    char    buf2[20];
    size_t  len;
    if (sizeof(buf2) < strlen("¡Hola mundo!"))
        errx("strncpy: truncando secuencia de caracteres");
    strncpy(buf2, "¡Hola mundo!", sizeof(buf2));
    len = strnlen(buf2, sizeof(buf2));
    printf("[len = %zu]: ", len);
    fwrite(buf2, 1, len, stdout);
    putchar('\n');
    if (sizeof(buf1) < strlen("¡Hola mundo!"))
        errx("stpncpy: truncando secuencia de caracteres");
    p = stpncpy(buf1, "¡Hola mundo!", sizeof(buf1));
    len = p - buf1;
    printf("[len = %zu]: ", len);
    fwrite(buf1, 1, len, stdout);
    putchar('\n');
    exit(EXIT_SUCCESS);
}
