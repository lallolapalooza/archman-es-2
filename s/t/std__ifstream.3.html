Todas las funciones operator>> (también conocidas como funciones de entrada formateada) tienen un comportamiento común. Cada una comienza construyendo un objeto temporal de tipo std::basic_istream::sentry con el segundo argumento (noskipws) establecido en false. Funciones de Entrada No Formateada
Todas las funciones de entrada no formateada tienen un comportamiento común. Cada una comienza construyendo un objeto temporal de tipo std::basic_istream::sentry con el segundo argumento (noskipws) establecido en true. Esto tiene varios efectos, concluyendo con el establecimiento de un indicador de estado; consulte la documentación de sentry para más detalles.

Si el estado de sentry es bueno, la función intenta extraer los datos apropiados para el tipo del argumento.

El número de caracteres extraídos se almacena para su posterior recuperación mediante gcount().

Si se lanza una excepción durante la extracción, ios_base::badbit se activará en el estado de error del flujo (sin causar que se lance una excepción ios_base::failure) y la excepción original se volverá a lanzar si badbit está establecido en la máscara de excepciones.

Parámetros de Plantilla

_CharT Tipo de flujo de caracteres.
_Traits Rasgos para el tipo de carácter, por defecto es char_traits<_CharT>.

Esta clase soporta la lectura de archivos con nombre, utilizando las funciones heredadas de std::basic_istream. Para controlar la secuencia asociada, se utiliza una instancia de std::basic_filebuf, a la que esta página se refiere como sb.

Detailed Description

These member functions override corresponding virtual functions of std::basic_streambuf. They are responsible for handling stream positioning and input/output operations for specific stream buffer types.

std::basic_stringbuf::seekpos()
This function repositions the get-position and put-position pointers of a basic_stringbuf to a specified position. It takes a pos_type representing the target position and an ios_base::openmode flag indicating whether the operation applies to input (ios_base::in), output (ios_base::out), or both. It returns the new position if successful, or pos_type(-1) on failure.
std::basic_filebuf::showmanyc()
This function returns the number of characters that can be read from the associated file without blocking. For file streams, this typically involves querying the underlying file system or operating system.
std::basic_stringbuf::showmanyc()
This function is part of the basic_stringbuf interface but typically returns 0, as string buffers are not designed for the same kind of non-blocking read guarantees as file streams.
std::basic_istream::tellg()
This function returns the current position of the get-position pointer of the input stream. This indicates how many characters have been read from the stream.
std::basic_filebuf::underflow()
This function attempts to read and return the next character from the input buffer associated with the basic_filebuf. If the buffer is empty, it may attempt to refill it from the underlying file. It returns the character read or traits_type::eof() on failure or end-of-file.
std::basic_stringbuf::underflow()
This function attempts to read and return the next character from the basic_stringbuf's internal buffer. It manages the get-position pointer within the string.
std::basic_filebuf::xsgetn()
This function reads up to n characters from the input buffer associated with the basic_filebuf into the character array pointed to by s. It returns the number of characters actually read.
