Detailed Description

Class std::unordered_multiset with safety/checking/debug instrumentation.

This class is a debug wrapper around std::unordered_multiset. It adds runtime checks and assertions to help catch errors during development.

The purpose of this wrapper is to ensure that the underlying container operations are used correctly and to detect potential issues such as iterator invalidation, memory corruption, or incorrect usage of the container's interface.

When using this class, you should include the <debug/unordered_multiset> header.

#include <debug/unordered_multiset>

std::unordered_multiset<int> my_set;
my_set.insert(10);

The available template parameters are:

_Value
The type of the elements stored in the multiset.
_Hash
A function object type that defines the hash function for the elements. Defaults to std::hash<_Value>.
_Pred
A function object type that defines the equality comparison for the elements. Defaults to std::equal_to<_Value>.
_Alloc
The allocator type used for memory management. Defaults to std::allocator<_Value>.

This class inherits from std::__debug_alloc_base, which provides additional debugging support for allocators.
