Detailed Description

template<typename _RealType = double> std::chi_squared_distribution

The class std::chi_squared_distribution models the $\chi^2$ distribution.

The template parameter _RealType determines the floating-point type used for the distribution.

And _Params is the type of the distribution's parameters.
