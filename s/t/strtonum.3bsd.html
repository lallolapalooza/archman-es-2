strtonum(3bsd)

Paquete: libbsd

Licencias: custom

strtonum(3bsd) 3bsd strtonum(3bsd)

NOMBRE

strtonum — convierte de forma fiable un valor de cadena a un entero

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <limits.h>
#include <stdlib.h> (Véase libbsd(7) para el uso de la inclusión.)
long long
strtonum(const char *nptr, long long minval, long long maxval, const char **errstr);

DESCRIPCIÓN

La función strtonum() convierte la cadena en nptr a un valor long long.

La cadena puede comenzar con una cantidad arbitraria de espacios en blanco (según lo determinado por isspace(3)) seguida de un único signo opcional de ‘+’ o ‘-’.

El resto de la cadena se convierte a un valor long long según la base 10.

El valor obtenido se verifica luego contra los límites minval y maxval proporcionados. Si errstr no es nulo, strtonum() almacena una cadena de error en *errstr que indica el fallo.

VALORES DE RETORNO

La función strtonum() devuelve el resultado de la conversión, a menos que el valor exceda los límites proporcionados o no sea válido. En caso de error, se devuelve 0, se establece errno y errstr apuntará a un mensaje de error. En caso de éxito, *errstr se establecerá en NULL; este hecho puede usarse para diferenciar un retorno exitoso de 0 de un error.

EJEMPLOS

Usar strtonum() correctamente está destinado a ser más simple que las funciones alternativas.

int iterations;
const char *errstr;

iterations = strtonum(optarg, 1, 64, &errstr);
if (errstr)
	errx(1, "el número de iteraciones es %s: %s", errstr, optarg);

El ejemplo anterior garantizará que el valor de las iteraciones esté entre 1 y 64 (inclusive).

ERRORES

[EINVAL]
La cadena dada no consistía únicamente en caracteres de dígito; o minval era mayor que maxval.
[ERANGE]
La cadena dada estaba fuera de rango.

Si ocurre un error, errstr se establecerá en una de las siguientes cadenas:

demasiado grande
El resultado fue mayor que el valor máximo proporcionado.
demasiado pequeño
El resultado fue menor que el valor mínimo proporcionado.
inválido
La cadena no consistía únicamente en caracteres de dígito.

VER TAMBIÉN

atof(3), atoi(3), atol(3), atoll(3), sscanf(3), strtod(3), strtoi(3bsd), strtol(3), strtoll(3), strtou(3bsd), strtoul(3), strtoull(3)

ESTÁNDARES

strtonum() es una extensión de BSD.

HISTORIA

La función strtonum() apareció por primera vez en OpenBSD 3.6. strtonum() fue rediseñada en NetBSD 8.0 como strtoi(3bsd) y strtou(3bsd).

ADVERTENCIAS

La función strtonum() fue diseñada para facilitar una programación segura y robusta y superar las deficiencias de la familia de interfaces atoi(3) y strtol(3), sin embargo, existen problemas con la API de strtonum():

  • devuelve 0 en caso de fallo; 0 podría no estar en rango, por lo que esto necesita una comprobación de error incluso si quieres evitarla
  • no diferencia las devoluciones 'ilegales', por lo que no podemos distinguir entre conversiones parciales y ninguna conversión
  • devuelve cadenas en inglés
  • no puede establecer la base, ni encontrar dónde terminó la conversión
  • codifica internamente el tipo de entero long long
Para superar las deficiencias de strtonum(), NetBSD proporciona strtou(3bsd) y strtoi(3bsd).
