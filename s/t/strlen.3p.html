STRLEN(3P) Manual del programador POSIX STRLEN(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

strlen, strnlen — obtener la longitud de una cadena de tamaño fijo

SINOPSIS

#include <string.h>
size_t strlen(const char *s);
size_t strnlen(const char *s, size_t maxlen);

DESCRIPCIÓN

Para strlen(): La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1-2017 remite al estándar ISO C.

La función strlen() calculará el número de bytes en la cadena a la que apunta s, sin incluir el carácter NUL de terminación.

La función strnlen() calculará el menor valor entre el número de bytes en el array al que apunta s, sin incluir ningún carácter NUL de terminación, o el valor del argumento maxlen. La función strnlen() nunca examinará más de maxlen bytes del array apuntado por s.

VALOR DE RETORNO

La función strlen() devolverá la longitud de s; no se reservará ningún valor de retorno para indicar un error.

La función strnlen() devolverá el número de bytes anteriores al primer byte nulo en el array al que apunta s, si s contiene un byte nulo dentro de los primeros maxlen bytes; de lo contrario, devolverá maxlen.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Obtener longitudes de cadena

El siguiente ejemplo establece la longitud máxima de key y data utilizando strlen() para obtener las longitudes de esas cadenas.

#include <string.h>
...
struct element {
    char *key;
    char *data;
};
...
char *key, *data;
int len;
*keylength = *datalength = 0;
...
if ((len = strlen(key)) > *keylength)
    *keylength = len;
if ((len = strlen(data)) > *datalength)
    *datalength = len;
...
