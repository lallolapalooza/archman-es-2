Template class basic_ios, virtual base class for all stream classes.

Template Parameters

_CharT

Type of character stream.

_Traits

Traits for character type, defaults to char_traits<_CharT>.

Most of the member functions called dispatched on stream objects (e.g., std::cout.foo(bar);) are consolidated in this class.

Throwing exceptions on errors.

Parameters

__except The new exceptions mask.

By default, error flags are set silently. You can set an exceptions mask for each stream; if a bit in the mask becomes set in the error flags, then an exception of type std::ios_base::failure is thrown.

If the error flag is already set when the exceptions mask is added, the exception is immediately thrown. Try running the following under GCC 3.1 or later:

#include <iostream>
#include <fstream>
#include <exception>

    std::ifstream f ("/etc/motd");

    f.setstate (std::ios_base::badbit);
    std::cerr << "Setting exception mask\n";
    f.exceptions (std::ios_base::badbit);
}

DESCRIPTION

The std::ios_base class is the base class for stream classes such as basic_istream, basic_ostream, basic_iostream, basic_ifstream, basic_ofstream, basic_fstream, basic_istringstream, basic_ostringstream, and basic_stringstream. It stores information that is common to all stream classes, such as stream state, formatting flags, manipulators, and stream buffer pointers.

The flags are members of the std::ios_base::fmtflags enumeration type:

adjustfield
Specifies the format adjustment. It is a bitmask composed of std::ios_base::left, std::ios_base::right, and std::ios_base::internal.
basefield
Specifies the numeric base for integer conversions. It is a bitmask composed of std::ios_base::oct, std::ios_base::dec, and std::ios_base::hex.
floatfield
Specifies the format for floating-point conversions. It is a bitmask composed of std::ios_base::scientific and std::ios_base::fixed.

The stream state flags are members of the std::ios_base::iostate enumeration type:

badbit
Indicates a serious error occurred, such as a failure in the stream buffer.
eofbit
Indicates that the end of the input stream was reached.
failbit
Indicates that an extraction operation failed.
goodbit
Indicates that no error flags are set.

The open mode flags are members of the std::ios_base::openmode enumeration type:

app
Append mode. All output operations are performed at the end of the stream.
binary
Binary mode. For files, this means data is read and written in binary mode. For strings, it means characters are not translated.
in
Input mode. Allows reading from the stream.
out
Output mode. Allows writing to the stream.
trunc
Truncate mode. If the file exists, its contents are discarded.
