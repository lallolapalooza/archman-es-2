NOMBRE

stap-report - Recopila información del sistema útil para depurar errores de systemtap

SINOPSIS

stap-report

DESCRIPCIÓN

El ejecutable stap-report recopila información del sistema que es útil para depurar errores de systemtap. Es una buena idea incluir dicho informe en los informes de errores, especialmente si los envía directamente al desarrollador principal. stap-report puede ejecutarse tanto como usuario normal como como root. El informe será más completo si stap-report se ejecuta como root.

EJEMPLOS

$ stap-report > reporte.txt
$ head reporte.txt
== id ==
uid=1000(usuario) gid=1000(usuario) groups=122(stapdev),123(stapusr),129(stapsys)
== stap -V ==
Traductor/controlador de Systemtap (versión 2.2.1/0.153, versión de Debian 2.2.1-1)
