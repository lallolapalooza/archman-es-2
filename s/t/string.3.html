string(3) Manual de Funciones de Biblioteca string(3)

NOMBRE

stpcpy, strcasecmp, strcat, strchr, strcmp, strcoll, strcpy, strcspn, strdup, strfry, strlen, strncat, strncmp, strncpy, strncasecmp, strpbrk, strrchr, strsep, strspn, strstr, strtok, strxfrm, index, rindex - operaciones de cadenas

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <strings.h>

strcasecmp(3)
Compara dos cadenas, ignorando mayúsculas y minúsculas.
strncasecmp(3)
Compara los primeros bytes de dos cadenas, ignorando mayúsculas y minúsculas.
index(3)
Idéntico a strchr(3).
rindex(3)
Idéntico a strrchr(3).

#include <string.h>

stpcpy(3)
Copia una cadena, devolviendo un puntero al final de la cadena resultante.
strcat(3)
Añade una cadena al final de otra existente.
strchr(3)
Busca la primera aparición de un carácter en una cadena.
strcmp(3)
Compara dos cadenas.
strcoll(3)
Compara dos cadenas, utilizando la configuración regional actual.
strcpy(3)
Copia una cadena.
strcspn(3)
Calcula la longitud del segmento inicial de una cadena que no contiene ninguno de los bytes rechazados.
strdup(3)
Duplica una cadena en memoria asignada usando malloc(3).
strfry(3)
Intercambia aleatoriamente los caracteres de una cadena.
strlen(3)
Devuelve la longitud de una cadena.
strncat(3)
Añade bytes no nulos de un array a una cadena y termina el resultado con un carácter nulo.
strncmp(3)
Compara los primeros bytes de dos cadenas.
strpbrk(3)
Busca la primera aparición en una cadena de uno de los bytes de los bytes aceptados.
strrchr(3)
Busca la última aparición de un carácter en una cadena.
strsep(3)
Extrae el campo inicial en una cadena que está delimitado por uno de los bytes delimitadores.
strspn(3)
Calcula la longitud del segmento inicial de una cadena que consiste enteramente en bytes aceptados.
strstr(3)
Busca la primera aparición de una subcadena en una cadena.
strtok(3)
Extrae tokens de una cadena que están delimitados por uno de los bytes delimitadores.
strxfrm(3)
Transforma una cadena a la configuración regional actual y copia los primeros bytes a un búfer.
strncpy(3)
Rellena un búfer de tamaño fijo con los primeros bytes no nulos de un array de origen, rellenando con bytes nulos según sea necesario.

DESCRIPCIÓN

Las funciones de cadena realizan operaciones sobre cadenas terminadas en nulo. Consulte las páginas de manual individuales para ver descripciones de cada función.
