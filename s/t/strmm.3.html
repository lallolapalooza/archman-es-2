Documentación de Función/Subrutina

subroutine strmm (character side, character uplo, character transa, character diag, integer m, integer n, real alpha, real, dimension(lda,*) a, integer lda, real, dimension(ldb,*) b, integer ldb)

STRMM

Propósito:

!>
!> STRMM  realiza una de las operaciones de matriz-matriz
!>
!>    B := alpha*op( A )*B,   o   B := alpha*B*op( A ),
!>
!> donde  alpha  es un escalar,  B  es una matriz de m por n,  A  es una
!> matriz triangular unitaria o no unitaria, superior o inferior, y  op( A )
!> es una de las siguientes:
!>
!>    op( A ) = A   o   op( A ) = A**T.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>           A la entrada,  SIDE especifica si  op( A )  multiplica a B por
!>           la izquierda o por la derecha, como se indica a continuación:
!>
!>              SIDE = 'L' o 'l'   B := alpha*op( A )*B.
!>
!>              SIDE = 'R' o 'r'   B := alpha*B*op( A ).
!>

UPLO

!>          UPLO es CHARACTER*1
!>           A la entrada, UPLO especifica si la matriz A es triangular
!>           superior o inferior, como se indica a continuación:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANSA

!>          TRANSA es CHARACTER*1
!>           A la entrada, TRANSA especifica la forma de op( A ) que se
!>           utilizará en la multiplicación de matrices, como se indica a
!>           continuación:
!>
!>              TRANSA = 'N' o 'n'   op( A ) = A.
!>
!>              TRANSA = 'T' o 't'   op( A ) = A**T.
!>
!>              TRANSA = 'C' o 'c'   op( A ) = A**T.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           A la entrada, DIAG especifica si A es unitriangular o no,
!>           como se indica a continuación:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es unitriangular.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitriangular.
!>

M

!>          M es INTEGER
!>           A la entrada, M especifica el número de filas de B. M debe
!>           ser al menos cero.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el número de columnas de B. N debe
!>           ser al menos cero.
!>

ALPHA

!>          ALPHA es REAL
!>           A la entrada,  ALPHA especifica el escalar  alpha. Cuando
!>           alpha es cero,  A no se referencia y  B no necesita ser
!>           establecido antes de la entrada.
!>

A

!>          A es un array REAL, de dimensión ( LDA, k ), donde k es m
!>           cuando  SIDE = 'L' o 'l'  y es  n  cuando  SIDE = 'R' o 'r'.
!>           Antes de la entrada, con  UPLO = 'U' o 'u',  la  parte
!>           superior triangular de k por k  del array  A debe contener la
!>           matriz triangular superior  y la parte estrictamente inferior
!>           triangular de  A no se referencia.
!>           Antes de la entrada, con  UPLO = 'L' o 'l',  la  parte
!>           inferior triangular de k por k  del array  A debe contener la
!>           matriz triangular inferior  y la parte estrictamente superior
!>           triangular de  A no se referencia.
!>           Tenga en cuenta que cuando  DIAG = 'U' o 'u',  los elementos
!>           diagonales de  A  tampoco se referencian,  sino que se asumen
!>           como unidad.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal como
!>           se declara en el programa (sub)llamador.  Cuando  SIDE = 'L' o 'l',
!>           LDA  debe ser al menos  max( 1, m ),  y cuando  SIDE = 'R' o 'r',
!>           LDA  debe ser al menos  max( 1, n ).
!>

B

!>          B es un array REAL, de dimensión ( LDB, N )
!>           Antes de la entrada, la parte de  m  por  n  del array  B debe
!>           contener la matriz  B,  y a la salida se sobrescribe con la
!>           matriz transformada.
!>

LDB

!>          LDB es INTEGER
!>           A la entrada, LDB especifica la primera dimensión de B tal como
!>           se declara en el programa (sub)llamador.  LDB  debe ser al
!>           menos  max( 1, m ).
!>
