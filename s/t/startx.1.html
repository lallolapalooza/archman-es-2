STARTX(1) Manual de comandos generales STARTX(1)

NOMBRE

startx - inicializa una sesión de X

SINOPSIS

startx [ [ cliente ] opciones ... ] [ -- [ servidor ] [ pantalla ] opciones ... ]

DESCRIPCIÓN

El script startx es una interfaz para xinit(1) que proporciona una interfaz de usuario algo más amigable para ejecutar una única sesión del sistema de ventanas X. A menudo se ejecuta sin argumentos.

Los argumentos que siguen inmediatamente al comando startx se utilizan para iniciar un cliente de la misma manera que xinit(1). El argumento especial '--' marca el final de los argumentos del cliente y el principio de las opciones del servidor. Puede ser conveniente especificar opciones del servidor con startx para cambiarlas por sesión. Algunos ejemplos de especificación de argumentos del servidor son los siguientes; consulte la página del manual de su servidor X para determinar qué argumentos son legales.

startx -- -depth 16

startx -- -dpi 100

startx -- -layout Multihead

Para determinar el cliente a ejecutar, startx comprueba primero la variable de entorno XINITRC en busca de un nombre de archivo. Si esa variable no está definida, o no contiene un nombre de archivo, busca un archivo llamado .xinitrc en el directorio personal del usuario. Si no lo encuentra, utiliza el archivo xinitrc en el directorio de la biblioteca de xinit. Si se proporcionan opciones de cliente en la línea de comandos, estas anulan este comportamiento y revierten al comportamiento de xinit(1). Para determinar el servidor a ejecutar, startx comprueba la variable de entorno XSERVERRC en busca de un nombre de archivo. Si esa variable no está definida, o no contiene un nombre de archivo, busca un archivo llamado .xserverrc en el directorio personal del usuario. Si no lo encuentra, utiliza el archivo xserverrc en el directorio de la biblioteca de xinit. Si se proporcionan opciones de servidor en la línea de comandos, estas anulan este comportamiento y revierten al comportamiento de xinit(1). Los usuarios rara vez necesitan proporcionar un archivo .xserverrc. Consulte la página del manual de xinit(1) para obtener más detalles sobre los argumentos.

Los archivos xinitrc y xserverrc de todo el sistema se encuentran en el directorio /etc/X11/xinit.

El .xinitrc es típicamente un script de shell que inicia muchos clientes según la preferencia del usuario. Cuando este script de shell finaliza, startx mata al servidor y realiza cualquier otra limpieza de sesión necesaria. La mayoría de los clientes iniciados por .xinitrc deben ejecutarse en segundo plano. El último cliente debe ejecutarse en primer plano; cuando finaliza, la sesión finaliza. A menudo se elige un gestor de sesiones, un gestor de ventanas o un xterm como el cliente ''mágico''.

EJEMPLO

A continuación se muestra un ejemplo de .xinitrc que inicia varias aplicaciones y deja el gestor de ventanas en ejecución como la ''última'' aplicación. Suponiendo que el gestor de ventanas ha sido configurado correctamente, el usuario elige entonces el elemento de menú ''Exit'' para apagar X.


xrdb -load $HOME/.Xresources
xsetroot -solid gray &
xbiff -geometry -430+5 &
oclock -geometry 75x75-0-0 &
xload -geometry -80-0 &
xterm -geometry +0+60 -ls &
xterm -geometry +0-100 &
xconsole -geometry -0+0 -fn 5x7 &
exec twm

VARIABLES DE ENTORNO

DISPLAY
Esta variable se establece para que sea el nombre de la pantalla a la que deben conectarse los clientes. Tenga en cuenta que esto se *establece*, no se lee.
XAUTHORITY
Esta variable, si aún no está definida, se establecerá en $(HOME)/.Xauthority. Esto es para evitar que el servidor X, si no se le proporciona el argumento -auth, configure automáticamente una autenticación insegura basada en host para la máquina local. Consulte las páginas del manual de Xserver(1) y Xsecurity(7) para obtener más información sobre la autenticación cliente/servidor X.
XINITRC
Esta variable debe contener la ubicación de un archivo xinitrc. Si no está definida, se utilizará $(HOME)/.xinitrc o /etc/X11/xinit/xinitrc.
XSERVERRC
Esta variable debe contener la ubicación de un archivo xserver. Si no está definida, se utilizará $(HOME)/.xserverrc o /etc/X11/xinit/xserverrc.

ARCHIVOS

$(HOME)/.xinitrc
Cliente a ejecutar. Típicamente un script de shell que ejecuta muchos programas en segundo plano.
$(HOME)/.xserverrc
Servidor a ejecutar. El valor predeterminado es X.
/etc/X11/xinit/xinitrc
Cliente a ejecutar si el usuario no tiene un archivo .xinitrc.
/etc/X11/xinit/xserverrc
Servidor a ejecutar si el usuario no tiene un archivo .xserverrc.
