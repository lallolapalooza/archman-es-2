Overview

The C++ standard library provides two iostream classes for output. They are derived from the class template std::basic_ostream.

std::ostream
This is a stream for writing data to standard output. It is instantiated from std::basic_ostream, using character type char and character traits std::char_traits<char>.
std::wostream
This is a stream for writing wide characters to standard output. It is instantiated from std::basic_ostream, using character type wchar_t and character traits std::char_traits<wchar_t>.

The class std::basic_ostream is a template class, not directly useful. You must specialize it for a particular character type and traits class.

basic_ios

The template class std::basic_ios is the base class for all input and output stream classes. It stores formatting flags, exception mask, state of the stream, etc. It also stores a pointer to the stream buffer, basic_streambuf, which it uses to perform actual input/output operations.
