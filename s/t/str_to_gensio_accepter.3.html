NOMBRE

str_to_gensio_accepter - Crear un aceptador gensio a partir de una cadena

SINOPSIS

#include <gensio/gensio.h>

int str_to_gensio_accepter(const char *str,

struct gensio_os_funcs *o,
gensio_accepter_event cb,
void *user_data,
struct gensio_accepter **acc);
int str_to_gensio_accepter_child(struct gensio_accepter *child,

const char *str,
struct gensio_os_funcs *o,
gensio_accepter_event cb,
void *user_data,
struct gensio_accepter **acc);
int gensio_terminal_acc_alloc(const char *gensiotype,

const void *gdata,
const char * const args[],
struct gensio_os_funcs *o,
gensio_accepter_event cb, void *user_data,
struct gensio_accepter **accepter);
int gensio_filter_acc_alloc(const char *gensiotype,

struct gensio_accepter *child,
const char * const args[],

gensio_accepter_event cb, void *user_data,
struct gensio_accepter **accepter);

DESCRIPCIÓN

str_to_gensio_accepter asigna una nueva pila de aceptadores gensio basada en la cadena dada str.

str_to_gensio_accepter_child asigna una nueva pila de aceptadores gensio basada en la cadena dada str y la apila sobre el aceptador hijo dado.

Para asignar un aceptador directamente, use gensio_terminal_acc_alloc o gensio_filter_acc_alloc. Un aceptador terminal es uno en la parte inferior de la pila. El parámetro gdata depende del gensio particular. Por ejemplo, para tcp es un puntero a una estructura gensio_addr. Para stdio es un array argv. Ver gensio.5 bajo "Asignación Directa" para el gensio particular de lo que es gdata.

Un aceptador de filtro es uno que tiene un hijo. Puede usar estas dos funciones para asignar una pila de aceptadores directamente, sin usar un formato de cadena.

Los parámetros cb y user_data establecen una función que se llamará cuando lleguen eventos al aceptador gensio. user_data no es utilizado por la pila gensio en sí, está ahí para el usuario y puede ser cualquier cosa que el usuario desee.

El nuevo aceptador gensio se devuelve en acc. Estará en el estado de apagado.

VALORES DE RETORNO

Se devuelve cero en caso de éxito, o un error de gensio en caso de fallo.
