SSTEVR calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para OTRAS matrices

Propósito:

SSTEVR calcula valores propios seleccionados y, opcionalmente, vectores propios
de una matriz tridiagonal simétrica real T. Los valores propios y
vectores propios se pueden seleccionar especificando un rango de valores
o un rango de índices para los valores propios deseados.

Siempre que sea posible, SSTEVR llama a SSTEMR para calcular el
espectro de valores propios utilizando Representaciones Relativamente Robustas.
SSTEMR calcula los valores propios mediante el algoritmo dqds, mientras que
los vectores propios ortogonales se calculan a partir de varias
representaciones L D L^T (también conocidas como Representaciones Relativamente Robustas). La ortogonalización de Gram-Schmidt
se evita tanto como sea posible. Más específicamente,
los diversos pasos del algoritmo son los siguientes. Para el i-ésimo
bloque no reducido de T,
   (a) Calcular T - sigma_i = L_i D_i L_i^T, tal que L_i D_i L_i^T
        es una representación relativamente robusta,
   (b) Calcular los valores propios, lambda_j, de L_i D_i L_i^T con alta
       precisión relativa mediante el algoritmo dqds,
   (c) Si hay un clúster de valores propios cercanos, sigma_i
       cercano al clúster, y pasar al paso (a),
   (d) Dado el valor propio aproximado lambda_j de L_i D_i L_i^T,
       calcular el vector propio correspondiente formando una
       factorización retorcida que revele el rango.
La precisión deseada de la salida se puede especificar mediante el parámetro de entrada
ABSTOL.

Para más detalles, ver , por Inderjit Dhillon,
Informe Técnico de la División de Ciencias de la Computación No. UCB//CSD-97-971,
UC Berkeley, Mayo 1997.


Nota 1: SSTEVR llama a SSTEMR cuando se solicita el espectro completo
en máquinas que cumplen el estándar de punto flotante ieee-754.
SSTEVR llama a SSTEBZ y SSTEIN en máquinas no ieee y
cuando se realizan solicitudes de espectro parcial.

La ejecución normal de SSTEMR puede crear NaNs e infinitos y
por lo tanto, puede abortar debido a una excepción de punto flotante en entornos
que no manejan NaNs e infinitos de la manera predeterminada del estándar ieee.

Detailed Description

This routine is part of the LAPACK routines for computing eigenvalues and eigenvectors of symmetric tridiagonal matrices.

It computes the eigenvalues and eigenvectors of a general symmetric tridiagonal matrix.

The matrix is represented by the diagonal entries D and the super-diagonal entries E.

The eigenvalues are computed by the QR algorithm, and the eigenvectors are computed by accumulated transformations.

The routine supports computation of all eigenvalues and eigenvectors, or only eigenvalues.

The routine also supports computation of eigenvectors for a specified range of eigenvalues.

The routine is implemented to work with single-precision floating point numbers.

The routine is optimized for performance and memory usage.

It is part of the LAPACK library, a widely used collection of subroutines for linear algebra computations.

SUBROUTINE SSTEVER( JOBZ, N, D, E, W, MATZ, LDZ, WORK, IWORK, INFO )

JOBZ

CHARACTER*1.

Specifies whether to compute only the eigenvalues or both the eigenvalues and the eigenvectors.

= 'N': Compute only the eigenvalues of D.

= 'V': Compute the eigenvalues and the corresponding eigenvectors of D.

= 'S': Compute the eigenvalues and the corresponding eigenvectors of D for a specified range.

N

INTEGER.

The order of the matrix D.

N >= 0.

If N = 0, SSTEVER does nothing.

D

REAL array, dimension (N).

On entry, the diagonal entries of the symmetric tridiagonal matrix.

On exit, if INFO = 0, the array D contains the computed eigenvalues, sorted in ascending order.

E

REAL array, dimension (N-1).

On entry, the subdiagonal entries of the symmetric tridiagonal matrix.

On exit, E may be overwritten.

W

REAL array, dimension (N).

On exit, W contains the computed eigenvalues, sorted in ascending order.

MATZ

REAL array, dimension (LDZ, N) if JOBZ = 'V' or JOBZ = 'S', and eigenvalues are not computed by means of QR algorithm. Otherwise, MATZ is not referenced.

On exit, if JOBZ = 'V' or JOBZ = 'S', then the columns of MATZ are the normalized eigenvectors, with the i-th column corresponding to the i-th eigenvalue in D.

If JOBZ = 'S', the eigenvectors corresponding to the range ( W(I), W(I+1) ) of eigenvalues are computed.

LDZ

INTEGER.

The leading dimension of the array MATZ.

LDZ >= 1

If JOBZ = 'V' or JOBZ = 'S', then LDZ >= max(1,N).

WORK

REAL array, dimension (MAX(1,LWORK)).

On exit, if INFO = 0, WORK(1) contains the optimal (and minimal) value of LWORK.

IWORK

INTEGER array, dimension (MAX(1,LIWORK)).

On exit, if INFO = 0, IWORK(1) contains the optimal (and minimal) value of LIWORK.

INFO

INTEGER.

= 0: successful exit
