NOMBRE

stellarium - Un planetario realista en tiempo real

SINOPSIS

stellarium [OPCIONES]

DESCRIPCIÓN

Stellarium es un software libre bajo licencia GPL que renderiza cielos realistas en tiempo real con OpenGL. Está disponible para Linux/Unix, Windows y MacOSX. Con Stellarium, realmente ves lo que puedes ver con tus ojos, binoculares o un pequeño telescopio.

OPCIONES

-v, --version
Imprime el nombre y la versión del programa y sale.
-h, --help
Imprime un breve resumen de las opciones del programa y sale.
-c, --config-file archivo
Usa archivo como nombre de archivo de configuración en lugar del predeterminado config.ini.
-u, --user-dir directorio
Usa directorio en lugar del directorio de datos de usuario predeterminado ($HOME/.stellarium/ en sistemas operativos *nix).
--verbose
Salida de diagnóstico aún más detallada en el archivo de registro (especialmente el manejo multimedia).
--scale-gui factor de escala
Escala la GUI de acuerdo con el factor de escala.
-d, --dump-opengl-details
Vuelca información sobre el soporte de OpenGL en el archivo de registro. Úsalo si tienes problemas gráficos y quieres enviar un informe de error.
-f, --full-screen sí|no
Con el argumento sí o no, anula la configuración de pantalla completa en el archivo de configuración. La configuración se guarda en el archivo de configuración y, como tal, será la predeterminada para las siguientes invocaciones de Stellarium.
--screenshot-dir directorio
Establece el directorio en el que se guardarán las capturas de pantalla a directorio, en lugar del predeterminado (que es $HOME en sistemas operativos *nix).
--startup-script script
Especifica el nombre del script de inicio.
--home-planet nombre-planeta
Especifica el planeta observador. nombre-planeta es un nombre en inglés y debe referirse a un objeto definido en el archivo ssystem.ini.
--altitude alt
Especifica la altitud inicial del observador, donde alt es la altitud en metros.
--longitude lon
Especifica la longitud inicial del observador, donde lon es la longitud. El formato se ilustra con este ejemplo: +4d16'12" que se refiere a 4 grados, 16 minutos y 12 segundos de arco Este. Las longitudes Oeste deben ir precedidas de "-".
--latitude lat
Especifica la latitud inicial del observador, donde lat es la latitud. El formato se ilustra con este ejemplo: +53d58'16.65" que se refiere a 53 grados, 58 minutos y 16.65 segundos de arco Norte. Las latitudes Sur deben ir precedidas de "-".
--list-landscapes
Imprime una lista de nombres de paisajes y sale.
--landscape nombre
Inicia Stellarium utilizando el paisaje nombre. Consulte --list-landscapes para ver los nombres posibles.
--sky-date fecha
Especifica la fecha del cielo en formato aaaammdd.
--sky-time hora
Especifica la hora del cielo en formato hh:mm:ss.
--fov fov
Especifica el campo de visión (fov grados).
--projection-type p
Especifica el tipo de proyección, p. Los valores permitidos para p son: equalarea, stereographic, fisheye, cylinder, mercator, perspective, y orthographic.
--restore-defaults
Elimina el config.ini existente y usa los valores predeterminados.

VALOR DE RETORNO

0
Completado con éxito.
no 0
Algún tipo de error.

ARCHIVOS

Nota: las ubicaciones de los archivos en sistemas operativos no-*nix (incluido OSX) pueden variar. Consulte la Guía del usuario de Stellarium para obtener más detalles, así como información sobre cómo personalizar los archivos de datos de Stellarium.

/usr/share/stellarium/
Este es el Directorio de Datos de Instalación establecido en el momento de la compilación.
$HOME/.stellarium/
Este es el Directorio de Datos del Usuario, que puede ser anulado usando la opción de línea de comandos -u. Contiene la configuración del usuario, paisajes adicionales, scripts y también puede usarse para anular archivos de datos que se proporcionan con la instalación predeterminada.
$HOME/.stellarium/config.ini
El archivo de configuración principal predeterminado es config.ini. Consulte -c arriba para usar un nombre de archivo diferente y -u para usar un Directorio de Datos de Usuario diferente.
$HOME/
El directorio predeterminado para capturas de pantalla. Consulte --screenshot-dir para usar una ruta diferente.
