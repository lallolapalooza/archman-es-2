Descripción detallada

La lista de objetos chrono::tzdb

El tiempo de ejecución de C++ construye un único objeto de este tipo, y se puede acceder a él llamando a chrono::get_tzdb_list().

El principio de la lista es el objeto tzdb actual y se puede acceder a él a través de chrono::get_tzdb_list().front() o chrono::get_tzdb() o *chronoget_tzdb_list().begin().

La función chrono::reload_tzdb() comprobará si hay una versión más reciente y, si la encuentra, la insertará al principio de la lista.

const_iterator std::chrono::tzdb_list::erase_after (const_iterator __p)

Elimina el objeto tzdb *después* de aquel al que apunta el iterador.

Llamar a esta función concurrentemente con cualquiera de front(), begin(), o end() no provoca una condición de carrera de datos, pero en general esta función no es segura para hilos. El comportamiento puede ser indefinido si se elimina un elemento de la lista mientras otro hilo llama a la misma función, o incrementa un iterador en la lista, o accede al elemento que se está eliminando (a menos que se acceda a él a través de un iterador).

Parámetros

__p Un iterador que se puede desreferenciar.

Retorna

Un iterador al elemento siguiente al que se eliminó (o end() si no existe tal elemento).
