NOMBRE

std::basic_ios< _CharT, _Traits > - Clase plantilla basic_ios, clase base virtual para todas las clases de flujo.

SINOPSIS

#include <ios>

Hereda de std::ios_base.

Heredada por std::basic_istream< char > [virtual], std::basic_istream< wchar_t > [virtual], std::basic_ostream< char > [virtual], std::basic_ostream< wchar_t > [virtual], std::basic_istream< _CharT, _Traits > [virtual], y std::basic_ostream< _CharT, _Traits > [virtual].

template<typename _CharT, typename _Traits>

class std::basic_ios< _CharT, _Traits >"Clase plantilla basic_ios, clase base virtual para todas las clases de flujo.

Parámetros de plantilla

_CharT Tipo de flujo de caracteres.
_Traits Rasgos para el tipo de carácter, por defecto es char_traits<_CharT>.

La mayoría de las funciones miembro llamadas en objetos de flujo (por ejemplo, std::cout.foo(bar);) se consolidan en esta clase.

Copia los campos de `__rhs` en este objeto.

Parámetros

__rhs Los valores de origen para las copias.

Devuelve

Referencia a este objeto.

Todos los campos de `__rhs` se copian en este objeto, excepto que `rdbuf()` y `rdstate()` permanecen sin cambios. Todos los valores en los arrays `pword` e `iword` se copian. Antes de copiar, cada devolución de llamada se invoca con `erase_event`. Después de copiar, cada (nueva) devolución de llamada se invoca con `copyfmt_event`. El paso final es copiar `exceptions()`.

template<typename _CharT, typename _Traits> void std::basic_ios< _CharT, _Traits >::exceptions (iostate __except) [inline]

Lanzamiento de excepciones por errores.

Parámetros

__except La nueva máscara de excepciones.

Por defecto, las banderas de error se establecen silenciosamente. Puede establecer una máscara de excepciones para cada flujo; si una bandera en la máscara se establece en las banderas de error, se lanza una excepción de tipo `std::ios_base::failure`.

Si la bandera de error ya está establecida cuando se añade la máscara de excepciones, la excepción se lanza inmediatamente. Intente ejecutar lo siguiente en GCC 3.1 o posterior:

#include <iostream>
#include <fstream>
#include <exception>
int main()
{
    std::set_terminate (__gnu_cxx::__verbose_terminate_handler);
    std::ifstream f ("/etc/motd");
    std::cerr << "Setting badbit\n";
    f.setstate (std::ios_base::badbit);
    std::cerr << "Setting exception mask\n";
    f.exceptions (std::ios_base::badbit);
}

int std::ios_base::xalloc () [static], [inherited]

Acceso a índices únicos.

Devuelve

Un entero diferente de todas las llamadas anteriores.

Esta función devuelve un entero único cada vez que se llama. Puede usarse para cualquier propósito, pero está principalmente destinado a ser un índice único para las funciones iword y pword. La expectativa es que una aplicación llame a xalloc para obtener un índice en las matrices iword y pword que se pueda usar sin temor a conflictos.

La implementación mantiene una variable estática que se incrementa y se devuelve en cada invocación. Se garantiza que xalloc devuelve un índice que es seguro de usar en las matrices iword y pword.
