NAME

std::ostream_iterator - Iterator for output to an output stream.

SYNOPSIS

#include <iterator>


template<typename _Tp, typename _CharT = char, typename _Traits = char_traits<_CharT>>
class ostream_iterator;

Detailed Description

An output stream iterator is an iterator that writes elements to an output stream. The elements are written using the stream's insertion operator (operator<<). The delimiter string is written after each element.

The std::ostream_iterator is defined in the <iterator> header.

Example:

#include <iostream>
#include <vector>
#include <iterator>
#include <algorithm>

int main() {
    std::vector<int> numbers = {1, 2, 3, 4, 5};
    std::ostream_iterator<int> out_it(std::cout, ", ");
    std::copy(numbers.begin(), numbers.end(), out_it);
    std::cout << std::endl;
    return 0;
}

Output:

1, 2, 3, 4, 5,
