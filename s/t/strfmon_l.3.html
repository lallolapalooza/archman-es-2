strfmon(3) Manual de Funciones de Biblioteca strfmon(3)

NOMBRE

strfmon, strfmon_l - convertir valor monetario a cadena

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <monetary.h>
ssize_t strfmon(size_t size;
                char s[restrict size], size_t size,
                const char *restrict format, ...);
ssize_t strfmon_l(size_t size;
                char s[restrict size], size_t size, locale_t l,
                const char *restrict format, ...);

DESCRIPCIÓN

La función strfmon() formatea el monto monetario especificado según la configuración regional actual y la especificación de formato format, y coloca el resultado en el array de caracteres s de size bytes.

La función strfmon_l() realiza la misma tarea, pero utiliza la configuración regional especificada por l. El comportamiento de strfmon_l() no está definido si l es el objeto de configuración regional especial LC_GLOBAL_LOCALE (ver duplocale(3)) o si no es un manejador de objeto de configuración regional válido.

Los caracteres ordinarios en format se copian a s sin conversión. Los especificadores de conversión se introducen con un carácter '%'. Inmediatamente después, puede haber cero o más de las siguientes banderas:

=f
El carácter de un solo byte f se utiliza como carácter de relleno numérico (para ser utilizado con una precisión izquierda, ver más abajo). Cuando no se especifica, se utiliza el carácter de espacio.
^
No utilice ningún carácter de agrupación que pueda estar definido para la configuración regional actual. Por defecto, la agrupación está habilitada.
( o +
La bandera ( indica que las cantidades negativas deben encerrarse entre paréntesis. La bandera + indica que los signos deben manejarse de la manera predeterminada, es decir, las cantidades van precedidas por la indicación de signo de la configuración regional, por ejemplo, nada para positivos, "-" para negativos.
!
Omita el símbolo de moneda.
-
Justifique a la izquierda todos los campos. La justificación por defecto es a la derecha.

A continuación, puede haber un ancho de campo: una cadena de dígitos decimales que especifica un ancho de campo mínimo en bytes. El valor predeterminado es 0. Un resultado más pequeño que este ancho se rellena con espacios (a la izquierda, a menos que se haya indicado la bandera de justificación a la izquierda).

A continuación, puede haber una precisión izquierda de la forma "#" seguida de una cadena de dígitos decimales. Si el número de dígitos a la izquierda del carácter separador decimal es menor que este, la representación se rellena a la izquierda con el carácter de relleno numérico. Los caracteres de agrupación no se cuentan en este ancho de campo.

A continuación, puede haber una precisión derecha de la forma "." seguida de una cadena de dígitos decimales. La cantidad que se está formateando se redondea al número especificado de dígitos antes de formatearla. El valor predeterminado lo especifican los elementos frac_digits e int_frac_digits de la configuración regional actual. Si la precisión derecha es 0, no se imprime ningún carácter separador decimal. (El carácter separador decimal aquí lo determina LC_MONETARY, y puede diferir del especificado por LC_NUMERIC).

Finalmente, la especificación de conversión debe terminar con un carácter de conversión. Los tres caracteres de conversión son

%
(En este caso, toda la especificación debe ser exactamente "%%".) Inserte un carácter '%' en la cadena resultante.
i
Se convierte un argumento de tipo double utilizando el formato de moneda internacional de la configuración regional.
n
Se convierte un argumento de tipo double utilizando el formato de moneda nacional de la configuración regional.

VALOR DE RETORNO

La función strfmon() devuelve el número de caracteres colocados en el array s, sin incluir el byte nulo de terminación, siempre que la cadena, incluido el byte nulo de terminación, quepa. En caso contrario, establece errno a E2BIG, devuelve -1, y el contenido del array no está definido.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
strfmon () Seguridad en hilos MT-Safe locale
strfmon_l () Seguridad en hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIAL

POSIX.1-2001.

EJEMPLOS

La llamada


strfmon(buf, sizeof(buf), "[%^=*#6n] [%=*#6i]",
        1234.567, 1234.567);

produce la salida


[€ **1234,57] [EUR **1 234,57]

en la configuración regional nl_NL. Las configuraciones regionales de_DE, de_CH, en_AU, y en_GB producen


[ **1234,57 €] [ **1.234,57 EUR]
[ Fr. **1234.57] [ CHF **1'234.57]
[ $**1234.57] [ AUD**1,234.57]
[ £**1234.57] [ GBP**1,234.57]
