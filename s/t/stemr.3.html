CSTEMR

Propósito:

!>
!> CSTEMR calcula autovalores seleccionados y, opcionalmente, autovectores
!> de una matriz tridiagonal simétrica real T. Cualquier matriz no reducida
!> de este tipo tiene un conjunto bien definido de autovalores reales
!> par a par diferentes, los autovectores reales correspondientes son par a par ortogonales.
!>
!> El espectro puede calcularse completa o parcialmente especificando
!> ya sea un intervalo (VL,VU] o un rango de índices IL:IU para los autovalores deseados.
!>
!> Dependiendo del número de autovalores deseados, estos se calculan ya sea
!> por bisección o por el algoritmo dqds. Los autovectores numéricamente ortogonales se
!> calculan mediante el uso de varias factorizaciones L D L^T adecuadas cerca de clusters
!> de autovalores cercanos (conocido como RRR, Representaciones Relativamente Robustas).
!> Un esbozo informal del algoritmo sigue:
!>
!> Para cada bloque no reducido (submatriz) de T,
!>    (a) Calcular T - sigma I = L D L^T, de modo que L y D
!>        definen todos los autovalores buscados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los autovalores y
!>        autovectores. La representación estándar (no factorizada) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcular los autovalores con precisión adecuada.
!>        Si se desean los autovectores, el algoritmo alcanza la precisión completa
!>        de los autovalores calculados solo justo antes de que
!>        los vectores correspondientes tengan que ser calculados, ver pasos c) y d).
!>    (c) Para cada cluster de autovalores cercanos, seleccionar un nuevo
!>        desplazamiento cercano al cluster, encontrar una nueva factorización y refinar
!>        los autovalores desplazados a precisión adecuada.
!>    (d) Para cada autovalor con una separación relativa suficientemente grande, calcular
!>        el autovector correspondiente formando una factorización retorcida que revela el rango.
!>        Volver a (c) para cualquier cluster que permanezca.
!>
!> Para más detalles, ver:
!> - Inderjit S. Dhillon y Beresford N. Parlett:
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, Agosto 2004.
!> - Inderjit Dhillon y Beresford Parlett: SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004. También Nota de Trabajo LAPACK 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, Mayo 1997.
!>
!> Detalles Adicionales
!> 1. CSTEMR solo funciona en máquinas que siguen el estándar de punto flotante
!> IEEE-754 en su manejo de infinitos y NaNs.
!> Esto permite el uso de bucles internos eficientes que evitan la comprobación de
!> divisores cero.
!>
!> 2. Las rutinas LAPACK pueden usarse para reducir una matriz Hermitiana compleja a
!> forma tridiagonal simétrica real.
!>
!> (Cualquier matriz tridiagonal Hermitiana compleja tiene valores reales en su diagonal
!> y potencialmente números complejos en sus subdiagonales. Al aplicar una
!> transformación de similitud con una matriz diagonal apropiada
!> diag(1,e^{i \phy_1}, ... , e^{i \phy_{n-1}}), la matriz Hermitiana
!> compleja puede transformarse en una matriz simétrica real y la aritmética compleja
!> puede evitarse por completo.)
!>
!> Mientras que los autovectores de la matriz tridiagonal simétrica real son reales,
!> los autovectores de la matriz Hermitiana compleja original tienen entradas complejas
!> en general.
!> Dado que los drivers LAPACK sobrescriben los datos de la matriz con los autovectores,
!> CSTEMR acepta espacio de trabajo complejo para facilitar la interoperabilidad
!> con CUNMTR o CUPMTR.
!>

!> \brief \brief DSTEMR computes selected eigenvalues and optionally eigenvectors of a
!> \brief real symmetric tridiagonal matrix.
!>
!> \details For an N-by-N real symmetric tridiagonal matrix T, DSTEMR computes
!>          selected eigenvalues and, optionally, eigenvectors, of T. Any such
!>          unreduced tridiagonal matrix has a well-defined set of pairwise
!>          different real eigenvalues, and the corresponding real eigenvectors
!>          are pairwise orthogonal.
!>
!>          The spectrum may be computed either completely or partially by
!>          specifying either an interval (VL, VU] or a range of indices IL:IU
!>          for the desired eigenvalues.
!>
!>          Depending on the number of desired eigenvalues, these are computed
!>          either by bisection or the dqds algorithm. Numerically orthogonal
!>          eigenvectors are computed by the use of various suitable LDL^T
!>          factorizations near clusters of close eigenvalues (referred to as
!>          RRRs, Relatively Robust Representations). An informal sketch of the
!>          algorithm follows.
!>
!>          For each unreduced block (submatrix) of T,
!>             (a) Compute T - sigma I = L D L^T, so that L and D
!>                 define all the wanted eigenvalues to high relative accuracy.
!>                 This means that small relative changes in the entries of D and L
!>                 cause only small relative changes in the eigenvalues and
!>                 eigenvectors. The standard (unfactored) representation of the
!>                 tridiagonal matrix T does not have this property in general.
!>             (b) Compute the eigenvalues to suitable accuracy.
!>                 If the eigenvectors are desired, the algorithm attains full
!>                 accuracy of the computed eigenvalues only right before
!>                 the corresponding vectors have to be computed, see steps c) and d).
!>             (c) For each cluster of close eigenvalues, select a new
!>                 shift close to the cluster, find a new factorization, and refine
!>                 the shifted eigenvalues to suitable accuracy.
!>             (d) For each eigenvalue with a large enough relative separation compute
!>                 the corresponding eigenvector by forming a rank revealing twisted
!>                 factorization. Go back to (c) for any clusters that remain.
!>
!>          For more details, see:
!>          - Inderjit S. Dhillon and Beresford N. Parlett:
!>            Linear Algebra and its Applications, 387(1), pp. 1-28, August 2004.
!>          - Inderjit Dhillon and Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>            2004.  Also LAPACK Working Note 154.
!>          - Inderjit Dhillon: ,
!>            Computer Science Division Technical Report No. UCB/CSD-97-971,
!>            UC Berkeley, May 1997.
!>
!>          Further Details
!>          1.DSTEMR works only on machines which follow IEEE-754
!>          floating-point standard in their handling of infinities and NaNs.
!>          This permits the use of efficient inner loops avoiding a check for
!>          zero divisors.
!>
!> \param[in] JOBZ JOBZ is CHARACTER*1
!>          = 'N':  Compute eigenvalues only;
!>          = 'V':  Compute eigenvalues and eigenvectors.
!>
!> \param[in] RANGE
!>          RANGE is CHARACTER*1
!>          = 'A': all eigenvalues will be found.
!>          = 'V': all eigenvalues in the half-open interval (VL,VU]
!>                 will be found.
!>          = 'I': the IL-th through IU-th eigenvalues will be found.
!>
!> \param[in] N
!>          N is INTEGER
!>          The order of the matrix.  N >= 0.
!>
!> \param[in,out] D
!>          D is DOUBLE PRECISION array, dimension (N)
!>          On entry, the N diagonal elements of the tridiagonal matrix
!>          T. On exit, D is overwritten.
!>
!> \param[in,out] E
!>          E is DOUBLE PRECISION array, dimension (N)
!>          On entry, the (N-1) subdiagonal elements of the tridiagonal
!>          matrix T in elements 1 to N-1 of E. E(N) need not be set on
!>          input, but is used internally as workspace.
!>          On exit, E is overwritten.
!>
!> \param[in] VL
!>          VL is DOUBLE PRECISION
!>
!>          If RANGE='V', the lower bound of the interval to
!>          be searched for eigenvalues. VL < VU.
!>          Not referenced if RANGE = 'A' or 'I'.
!>
!> \param[in] VU
!>          VU is DOUBLE PRECISION
!>
!>          If RANGE='V', the upper bound of the interval to
!>          be searched for eigenvalues. VL < VU.
!>          Not referenced if RANGE = 'A' or 'I'.
!>
!> \param[in] IL
!>          IL is INTEGER
!>
!>          If RANGE='I', the index of the
!>          smallest eigenvalue to be returned.
!>          1 <= IL <= IU <= N, if N > 0.
!>          Not referenced if RANGE = 'A' or 'V'.
!>
!> \param[in] IU
!>          IU is INTEGER
!>
!>          If RANGE='I', the index of the
!>          largest eigenvalue to be returned.
!>          1 <= IL <= IU <= N, if N > 0.
!>          Not referenced if RANGE = 'A' or 'V'.
!>
!> \param[out] M
!>          M is INTEGER
!>          The total number of eigenvalues found.  0 <= M <= N.
!>          If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.
!>
!> \param[out] W
!>          W is DOUBLE PRECISION array, dimension (N)
!>          On exit, the eigenvalues, sorted in increasing order.
!>
!> \param[out] Z
!>          Z is DOUBLE PRECISION array, dimension (LDZ, NZC)
!>          On exit, if JOBZ = 'V', the normalized eigenvectors,
!>          with the i-th column of Z holding the eigenvector
!>          corresponding to the i-th eigenvalue in W.
!>          If JOBZ = 'N', Z is not used.
!>
!> \param[in] LDZ
!>          LDZ is INTEGER
!>          The leading dimension of the array Z. LDZ >= 1, and if
!>          JOBZ = 'V', then LDZ >= max(1,N).
!>
!> \param[in,out] NZC
!>          NZC is INTEGER
!>          The number of eigenvectors to be held in the array Z.
!>          If RANGE = 'A', then NZC >= max(1,N).
!>          If RANGE = 'V', then NZC >= the number of eigenvalues in (VL,VU].
!>          If RANGE = 'I', then NZC >= IU-IL+1.
!>          If NZC = -1, then a workspace query is assumed; the
!>          routine calculates the number of columns of the array Z that
!>          are needed to hold the eigenvectors.
!>          This value is returned as the first entry of the Z array, and
!>          no error message related to NZC is issued by XERBLA.
!>
!> \param[out] ISUPPZ
!>          ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
!>          The support of the eigenvectors in Z, i.e., the indices
!>          indicating the nonzero elements in Z. The i-th computed eigenvector
!>          is nonzero only in elements ISUPPZ( 2*i-1 ) through
!>          ISUPPZ( 2*i ). This is relevant in the case when the matrix
!>          is split. ISUPPZ is only accessed when JOBZ is 'V' and N > 0.
!>
!> \param[in,out] TRYRAC
!>          TRYRAC is LOGICAL
!>          If TRYRAC = .TRUE., indicates that the code should check whether
!>          the tridiagonal matrix defines its eigenvalues to high relative
!>          accuracy.  If so, the code uses relative-accuracy preserving
!>          algorithms that might be (a bit) slower depending on the matrix.
!>          If the matrix does not define its eigenvalues to high relative
!>          accuracy, the code can uses possibly faster algorithms.
!>          If TRYRAC = .FALSE., the code is not required to guarantee
!>          relatively accurate eigenvalues and can use the fastest possible
!>          techniques.
!>          On exit, a .TRUE. TRYRAC will be set to .FALSE. if the matrix
!>          does not define its eigenvalues to high relative accuracy.
!>
!> \param[out] WORK
!>          WORK is DOUBLE PRECISION array, dimension (LWORK)
!>          On exit, if INFO = 0, WORK(1) returns the optimal
!>          (and minimal) LWORK.
!>
!> \param[in] LWORK
!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,18*N)
!>          if JOBZ = 'V', and LWORK >= max(1,12*N) if JOBZ = 'N'.
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>
!> \param[out] IWORK
!>          IWORK is INTEGER array, dimension (LIWORK)
!>          On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
!>
!> \param[in] LIWORK
!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.  LIWORK >= max(1,10*N)
!>          if the eigenvectors are desired, and LIWORK >= max(1,8*N)
!>          if only the eigenvalues are to be computed.
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal size of the IWORK array,
!>          returns this value as the first entry of the IWORK array, and
!>          no error message related to LIWORK is issued by XERBLA.
!>
!> \param[out] INFO
!>          INFO is INTEGER
!>          On exit, INFO
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = 1X, internal error in SLARRE,
!>                if INFO = 2X, internal error in CLARRV.
!>                Here, the digit X = ABS( IINFO ) < 10, where IINFO is
!>                the nonzero error code returned by SLARRE or

!>

        sstemr — Computes selected eigenvalues and eigenvectors of a real symmetric tridiagonal matrix
       

       
(Version 03.00.00)

       

        Univ. of Tennessee, Univ. of California Berkeley, Univ. of Colorado Denver, NAG Ltd.
       

       

        Contributors: Inderjit Dhillon, Beresford Parlett, Xiaoming Li, University of Texas, Austin, USA
       

       

        This routine computes selected eigenvalues and, optionally, eigenvectors
        of a real symmetric tridiagonal matrix T. Any such unreduced matrix has
        a well defined set of pairwise different real eigenvalues, the corresponding
        real eigenvectors are pairwise orthogonal.
       

       

        The spectrum may be computed either completely or partially by specifying
        either an interval (VL,VU] or a range of indices IL:IU for the desired
        eigenvalues.
       

       

        Depending on the number of desired eigenvalues, these are computed either
        by bisection or the dqds algorithm. Numerically orthogonal eigenvectors are
        computed by the use of various suitable L D L^T factorizations near clusters
        of close eigenvalues (referred to as RRRs, Relatively Robust
        Representations).
       

       

        For more details, see:
       

       
    
        
  • 
         Inderjit S. Dhillon and Beresford N. Parlett: Linear Algebra and its
         Applications, 387(1), pp. 1-28, August 2004.
        
    • 
        
  • 
         Inderjit Dhillon and Beresford Parlett: SIAM Journal on Matrix Analysis
         and Applications, Vol. 25, 2004. Also LAPACK Working Note 154.
        
    • 
        
  • 
         Inderjit Dhillon: LAPACK Working Note 154, University of Tennessee,
         September 1997.

        Further Details:

         SSTEMR works only on machines which follow IEEE-754
         floating-point standard in their handling of infinities and NaNs.
         This permits the use of efficient inner loops avoiding a check for

        Parameters
       

       

        

         JOBZ
         
          CHARACTER*1
         
        

        

         
    
          
  • 
           'N': Compute eigenvalues only
          
    • 
          
  • 
           'V': Compute eigenvalues and eigenvectors
          
    • 
         

        

        

         RANGE
         
          CHARACTER*1
         
        

        

         
    
          
  • 
           'A': all eigenvalues will be found
          
    • 
          
  • 
           'V': all eigenvalues in the half-open interval (VL,VU] will be found
          
    • 
          
  • 
           'I': the IL-th through IU-th eigenvalues will be found

         N
         
          INTEGER
         
        

        

         The order of the matrix. N >= 0.
        

        

         D
         
          REAL array, dimension (N)
         
        

        

         On entry, the N diagonal elements of the tridiagonal matrix T. On exit, D
         is overwritten.
        

        

         E
         
          REAL array, dimension (N)
         
        

        

         On entry, the (N-1) subdiagonal elements of the tridiagonal matrix T in
         elements 1 to N-1 of E. E(N) need not be set on input, but is used
         internally as workspace. On exit, E is overwritten.
        

        

         VL
         
          REAL
         
        

        

         If RANGE='V', the lower bound of the interval to be searched for
         eigenvalues. VL < VU. Not referenced if RANGE = 'A' or 'I'.
        

        

         VU
         
          REAL
         
        

        

         If RANGE='V', the upper bound of the interval to be searched for
         eigenvalues. VL < VU. Not referenced if RANGE = 'A' or 'I'.
        

        

         IL
         
          INTEGER
         
        

        

         If RANGE='I', the index of the smallest eigenvalue to be returned.
         1 <= IL <= IU <= N, if N > 0. Not referenced if RANGE = 'A' or 'V'.
        

        

         IU
         
          INTEGER
         
        

        

         If RANGE='I', the index of the largest eigenvalue to be returned.
         1 <= IL <= IU <= N, if N > 0. Not referenced if RANGE = 'A' or 'V'.
        

        

         M
         
          INTEGER
         
        

        

         The number of eigenvalues found.
        

        

         W
         
          REAL array, dimension (N)
         
        

        

         The first M elements of W contain the selected eigenvalues in ascending
         order.
        

        

         Z
         
          REAL array, dimension (LDZ, max(1,M) )
         
        

        

         

          If JOBZ = 'V', and if INFO = 0, then the first M columns of Z
          contain the orthonormal eigenvectors of the matrix T
          corresponding to the selected eigenvalues, with the i-th
          column of Z holding the eigenvector associated with W(i).
         

         

          If JOBZ = 'N', then Z is not referenced.
         

         

          Note: the user must ensure that at least max(1,M) columns are
          supplied in the array Z; if RANGE = 'V', the exact value of M
          is not known in advance and can be computed with a workspace
          query by setting NZC = -1, see below.
         

        

        

         LDZ
         
          INTEGER
         
        

        

         The leading dimension of the array Z. LDZ >= 1, and if
         JOBZ = 'V', then LDZ >= max(1,N).
        

        

         NZC
         
          INTEGER
         
        

        

         

          The number of eigenvectors to be held in the array Z.
         

         

          If RANGE = 'A', then NZC >= max(1,N).
         

         

          If RANGE = 'V', then NZC >= the number of eigenvalues in (VL,VU].
         

         

          If RANGE = 'I', then NZC >= IU-IL+1.
         

         

          If NZC = -1, then a workspace query is assumed; the
          routine calculates the number of columns of the array Z that
          are needed to hold the eigenvectors.
         

         

          This value is returned as the first entry of the Z array, and
          no error message related to NZC is issued by XERBLA.
         

        

        

         ISUPPZ
         
          INTEGER array, dimension ( 2*max(1,M) )
         
        

        

         The support of the eigenvectors in Z, i.e., the indices
         indicating the nonzero elements in Z. The i-th computed eigenvector
         is nonzero only in elements ISUPPZ( 2*i-1 ) through
         ISUPPZ( 2*i ). This is relevant in the case when the matrix
         is split. ISUPPZ is only accessed when JOBZ is 'V' and N > 0.
        

        

         TRYRAC
         
          LOGICAL
         
        

        

         

          If TRYRAC = .TRUE., indicates that the code should check whether
          the tridiagonal matrix defines its eigenvalues to high relative
          accuracy. If so, the code uses relative-accuracy preserving
          algorithms that might be (a bit) slower depending on the matrix.
          If the matrix does not define its eigenvalues to high relative
          accuracy, the code can uses possibly faster algorithms.
         

         

          If TRYRAC = .FALSE., the code is not required to guarantee
          relatively accurate eigenvalues and can use the fastest possible
          techniques.
         

         

          On exit, a .TRUE. TRYRAC will be set to .FALSE. if the matrix
          does not define its eigenvalues to high relative accuracy.
         

        

        

         WORK
         
          REAL array, dimension (LWORK)
         
        

        

         On exit, if INFO = 0, WORK(1) returns the optimal
         (and minimal) LWORK.
        

        

         LWORK
         
          INTEGER
         
        

        

         

          The dimension of the array WORK. LWORK >= max(1,18*N)
          if JOBZ = 'V', and LWORK >= max(1,12*N) if JOBZ = 'N'.
         

         

          If LWORK = -1, then a workspace query is assumed; the routine
          only calculates the optimal size of the WORK array, returns
          this value as the first entry of the WORK array, and no error
          message related to LWORK is issued by XERBLA.
         

        

        

         IWORK
         
          INTEGER array, dimension (LIWORK)
         
        

        

         On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
        

        

         LIWORK
         
          INTEGER
         
        

        

         

          The dimension of the array IWORK. LIWORK >= max(1,10*N)
          if the eigenvectors are desired, and LIWORK >= max(1,8*N)
          if only the eigenvalues are to be computed.
         

         

          If LIWORK = -1, then a workspace query is assumed; the
          routine only calculates the optimal size of the IWORK array,
          returns this value as the first entry of the IWORK array, and
          no error message related to LIWORK is issued by XERBLA.
         

        

        

         INFO
         
          INTEGER
         
        

        

         

          On exit, INFO
         

         
    
          
  • 
           = 0: successful exit
          
    • 
          
  • 
           < 0: if INFO = -i, the i-th argument had an illegal value
          
    • 
          
  • 
           > 0: if INFO = 1X, internal error in DLARRE,
             if INFO = 2X, internal error in DLARRV.
             Here, the digit X = ABS( IINFO ) < 10, where IINFO is
             the nonzero error code returned by DLARRE or
             DLARRV, respectively.

!>          Si NZC = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina calcula el número de columnas del array Z que
!>          son necesarias para almacenar los vectores propios.
!>          Este valor se devuelve en la primera entrada del array Z, y
!>          ningún mensaje de error relacionado con NZC es emitido por XERBLA.
!>

ISUPPZ

!>          ISUPPZ es array de ENTEROS, dimensión ( 2*max(1,M) )
!>          El soporte de los vectores propios en Z, es decir, los índices
!>          que indican los elementos distintos de cero en Z. El i-ésimo vector propio calculado
!>          es distinto de cero solo en los elementos ISUPPZ( 2*i-1 ) a
!>          ISUPPZ( 2*i ). Esto es relevante en el caso en que la matriz
!>          se divide. ISUPPZ solo se accede cuando JOBZ es 'V' y N > 0.
!>

TRYRAC

!>          TRYRAC es LÓGICO
!>          Si TRYRAC = .TRUE., indica que el código debe verificar si
!>          la matriz tridiagonal define sus valores propios con alta precisión relativa.
!>          Si es así, el código utiliza algoritmos que preservan la precisión relativa
!>          que podrían ser (un poco) más lentos dependiendo de la matriz.
!>          Si la matriz no define sus valores propios con alta precisión relativa,
!>          el código puede utilizar algoritmos posiblemente más rápidos.
!>          Si TRYRAC = .FALSE., no se requiere que el código garantice
!>          valores propios relativamente precisos y puede utilizar las técnicas más rápidas posibles.
!>          En la salida, un TRYRAC .TRUE. se establecerá a .FALSE. si la matriz
!>          no define sus valores propios con alta precisión relativa.
!>

WORK

!>          WORK es array de DOBLE PRECISION, dimensión (LWORK)
!>          En la salida, si INFO = 0, WORK(1) devuelve el óptimo
!>          (y mínimo) LWORK.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK. LWORK >= max(1,18*N)
!>          si JOBZ = 'V', y LWORK >= max(1,12*N) si JOBZ = 'N'.
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y ningún mensaje de error
!>          relacionado con LWORK es emitido por XERBLA.
!>

IWORK

!>          IWORK es array de ENTEROS, dimensión (LIWORK)
!>          En la salida, si INFO = 0, IWORK(1) devuelve el óptimo LIWORK.
!>

LIWORK

!>          LIWORK es ENTERO
!>          La dimensión del array IWORK.  LIWORK >= max(1,10*N)
!>          si se desean los vectores propios, y LIWORK >= max(1,8*N)
!>          si solo se van a calcular los valores propios.
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array IWORK,
!>          devuelve este valor como la primera entrada del array IWORK, y
!>          ningún mensaje de error relacionado con LIWORK es emitido por XERBLA.
!>

INFO

!>          INFO es ENTERO
!>          En la salida, INFO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = 1X, error interno en DLARRE,
!>                si INFO = 2X, error interno en ZLARRV.
!>                Aquí, el dígito X = ABS( IINFO ) < 10, donde IINFO es
!>                el código de error distinto de cero devuelto por DLARRE o
!>                ZLARRV, respectivamente.
!>
