NOMBRE

stringprep_unichar_to_utf8 - Función de API

SINOPSIS

#include <stringprep.h>

int stringprep_unichar_to_utf8(uint32_t c, char * outbuf);

ARGUMENTOS

uint32_t c
un código de carácter ISO10646
char * outbuf
búfer de salida, debe tener al menos 6 bytes de espacio. Si es NULL, se calculará y devolverá la longitud y no se escribirá nada en outbuf.

DESCRIPCIÓN

Convierte un solo carácter a UTF-8.

Valor de retorno: número de bytes escritos.
