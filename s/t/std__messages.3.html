Descripción Detallada

template<typename _CharT>

class std::messages< _CharT >"Plantilla de clase primaria messages.

Este facet encapsula el código para recuperar mensajes de catálogos de mensajes. Lo único definido por el estándar para este facet es la interfaz. Toda la funcionalidad subyacente depende de la implementación.

Esta biblioteca implementa actualmente 3 versiones del facet de mensajes. La primera versión (gnu) es un envoltorio alrededor de gettext, proporcionado por libintl. La segunda versión (ieee) es un envoltorio alrededor de catgets. La versión final (por defecto) no realiza ninguna traducción real. Estas implementaciones solo se proporcionan para las instanciaciones de char y wchar_t.

La plantilla messages utiliza funciones virtuales protegidas para proporcionar los resultados reales. Los accesores públicos reenían la llamada a las funciones virtuales. Estas funciones virtuales son ganchos para que los desarrolladores implementen el comportamiento que requieren del facet messages.
