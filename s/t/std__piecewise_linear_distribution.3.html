Detailed Description

The class template std::piecewise_linear_distribution generates random numbers according to a piecewise linear distribution. The simplest form of piecewise linear distribution is a uniform distribution. A piecewise linear distribution allows for arbitrary (piecewise) linear distributions to be specified. The implementation uses a sequence of intervals and associated linear functions on each interval. The total probability over all intervals is 1.

A `piecewise_linear_distribution` is constructed from a set of intervals and a set of corresponding probability density functions (PDFs) which are linear on each interval.

The result of the distribution is a value in the range [0, 1).
