strcoll(3) Manual de Funciones de Biblioteca strcoll(3)

NOMBRE

strcoll - compara dos cadenas usando la configuración regional actual

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <string.h>
int strcoll(const char *s1, const char *s2);

DESCRIPCIÓN

La función strcoll() compara las dos cadenas s1 y s2. Devuelve un entero menor que, igual a, o mayor que cero si s1 se encuentra, respectivamente, que es menor que, coincide con, o es mayor que s2. La comparación se basa en cadenas interpretadas según corresponda para la configuración regional actual del programa para la categoría LC_COLLATE. (Véase setlocale(3).)

VALOR DE RETORNO

La función strcoll() devuelve un entero menor que, igual a, o mayor que cero si s1 se encuentra, respectivamente, que es menor que, coincide con, o es mayor que s2, cuando ambas se interpretan según corresponda para la configuración regional actual.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
strcoll () Seguridad en hilos MT-Safe locale

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C89, SVr4, 4.3BSD.

NOTAS

En las configuraciones regionales POSIX o C, strcoll() es equivalente a strcmp(3).

VER TAMBIÉN

memcmp(3), setlocale(3), strcasecmp(3), strcmp(3), string(3), strxfrm(3)
