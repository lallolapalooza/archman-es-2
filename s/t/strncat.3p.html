STRNCAT(3P) Manual del programador POSIX STRNCAT(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

strncat — concatenar una cadena con parte de otra

SINOPSIS

#include <string.h>
char *strncat(char *restrict s1, const char *restrict s2, size_t n);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La función strncat() anexará no más de n bytes (un carácter NUL y los bytes que le siguen no se anexan) del arreglo apuntado por s2 al final de la cadena apuntada por s1. El byte inicial de s2 sobrescribe el carácter NUL al final de s1. Siempre se anexará un carácter NUL terminador al resultado. Si la copia se realiza entre objetos que se superponen, el comportamiento es indefinido.

VALOR DE RETORNO

La función strncat() devolverá s1; no se reservará ningún valor de retorno para indicar un error.

ERRORES

No se definen errores.
