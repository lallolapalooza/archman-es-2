Extractores
Todas las funciones operator>> (también conocidas como funciones de entrada formateada) tienen un comportamiento común. Cada una comienza construyendo un objeto temporal de tipo std::basic_istream::sentry con el segundo argumento (noskipws) establecido en false. Esto tiene varios efectos, culminando en el establecimiento de una bandera de estado; ver la documentación de sentry para más detalles.

Si el estado de sentry es bueno, la función intenta extraer los datos apropiados para el tipo del argumento.

Si se lanza una excepción durante la extracción, ios_base::badbit se activará en el estado de error del flujo (sin causar que se lance una excepción ios_base::failure) y la excepción original se volverá a lanzar si badbit está activado en la máscara de excepciones.
