Detailed Description

The class template exponential_distribution models the probability distribution of the inter-arrival times in a Poisson process.

In other words, the probability density function of a random variable X with exponential distribution is:

f(x; $\lambda$) = $\lambda$ e$^{-\lambda x}$

for x $\ge$ 0, and 0 for x < 0. The parameter $\lambda$ is called the rate parameter.

The mean of the distribution is 1/$\lambda$, and the variance is 1/$\lambda^2$.

In the C++ Standard Library, the parameter is called the mean. If the mean is denoted by m, then the rate parameter $\lambda$ = 1/m.
