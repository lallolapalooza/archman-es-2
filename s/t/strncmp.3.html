strcmp(3) Manual de funciones de la biblioteca strcmp(3)

NOMBRE

strcmp, strncmp - compara dos cadenas

BIBLIOTECA

Biblioteca estándar de C (libc, -lc)

SINOPSIS

#include <string.h>
int strcmp(const char *s1, const char *s2);
int strncmp(size_t n;
            const char s1[n], const char s2[n], size_t n);

DESCRIPCIÓN

La función strcmp() compara las dos cadenas s1 y s2. La configuración regional no se tiene en cuenta (para una comparación que tenga en cuenta la configuración regional, consulte strcoll(3)). La comparación se realiza utilizando caracteres sin signo.

strcmp() devuelve un entero que indica el resultado de la comparación, de la siguiente manera:

•
0, si s1 y s2 son iguales;
•
un valor negativo si s1 es menor que s2;
•
un valor positivo si s1 es mayor que s2.

La función strncmp() es similar, excepto que compara solo los primeros (como máximo) n bytes de s1 y s2.

VALOR DE RETORNO

Las funciones strcmp() y strncmp() devuelven un entero menor que, igual a, o mayor que cero si s1 (o los primeros n bytes de la misma) se encuentra, respectivamente, ser menor que, coincidir con, o ser mayor que s2.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
strcmp (), strncmp () Seguridad de hilos MT-Safe

VERSIÓNES

POSIX.1 solo especifica que:

El signo de un valor de retorno distinto de cero estará determinado por el signo de la diferencia entre los valores de los primeros pares de bytes (ambos interpretados como tipo unsigned char) que difieren en las cadenas que se comparan.

En glibc, al igual que en la mayoría de las otras implementaciones, el valor de retorno es el resultado aritmético de restar el último byte comparado en s2 del último byte comparado en s1. (Si los dos caracteres son iguales, esta diferencia es 0).

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C89, SVr4, 4.3BSD.

EJEMPLOS

El programa siguiente se puede utilizar para demostrar el funcionamiento de strcmp() (cuando se le dan dos argumentos) y strncmp() (cuando se le dan tres argumentos). Primero, algunos ejemplos usando strcmp():


$ ./string_comp ABC ABC;
<str1> y <str2> son iguales
$ ./string_comp ABC AB;      # 'C' es ASCII 67; 'C' - '\0' = 67
<str1> es mayor que <str2> (67)
$ ./string_comp ABA ABZ;     # 'A' es ASCII 65; 'Z' es ASCII 90
<str1> es menor que <str2> (-25)
$ ./string_comp ABJ ABC;
<str1> es mayor que <str2> (7)
$ ./string_comp $'\201' A;   # 0201 - 0101 = 0100 (o 64 decimal)
<str1> es mayor que <str2> (64)

El último ejemplo utiliza la sintaxis específica de bash(1) para producir una cadena que contiene un código ASCII de 8 bits; el resultado demuestra que la comparación de cadenas utiliza caracteres sin signo.

Y luego algunos ejemplos usando strncmp():


$ ./string_comp ABC AB 3;
<str1> es mayor que <str2> (67)
$ ./string_comp ABC AB 2;
<str1> y <str2> son iguales en los primeros 2 bytes

Código fuente del programa

/* string_comp.c
   Licenciado bajo GNU General Public License v2 o posterior.
*/
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int
main(int argc, char *argv[])
{
    int res;
    if (argc < 3) {
        fprintf(stderr, "Uso: %s <str1> <str2> [<n>]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    if (argc == 3)
        res = strcmp(argv[1], argv[2]);
    else
        res = strncmp(argv[1], argv[2], atoi(argv[3]));
    if (res == 0) {
        printf("<str1> y <str2> son iguales");
        if (argc > 3)
            printf(" en los primeros %d bytes\n", atoi(argv[3]));
        printf("\n");
    } else if (res < 0) {
        printf("<str1> es menor que <str2> (%d)\n", res);
    } else {
        printf("<str1> es mayor que <str2> (%d)\n", res);
    }
    exit(EXIT_SUCCESS);
}
