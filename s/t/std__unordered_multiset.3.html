NOMBRE

std::unordered_multiset< _Value, _Hash, _Pred, _Alloc > - Un contenedor estándar compuesto por claves equivalentes (posiblemente conteniendo múltiples de cada valor de clave) en el que las claves de los elementos son los elementos mismos.

SINOPSIS

#include <unordered_set>

template<typename _Value, typename _Hash = hash<_Value>, typename _Pred = equal_to<_Value>, typename _Alloc = allocator<_Value>>

class std::unordered_multiset< _Value, _Hash, _Pred, _Alloc >"Un contenedor estándar compuesto por claves equivalentes (posiblemente contiene múltiples instancias de cada valor de clave) en el que las claves de los elementos son los propios elementos.

Desde

C++11

Parámetros de plantilla

_Value Tipo de los objetos clave.
_Hash Tipo del objeto función de hash, por defecto hash<_Value>.
_Pred Tipo del objeto función predicado, por defecto equal_to<_Value>.
_Alloc Tipo del asignador, por defecto allocator<_Key>.

Cumple los requisitos de un contenedor y de un contenedor asociativo desordenado.

La base es _Hashtable, que se resuelve en tiempo de compilación a través del alias de plantilla __umset_hashtable.

NAME

std::unordered_multiset - Hash table-based container with duplicate keys.

SYNOPSIS

#include <unordered_set>

template<
    class _Value,
    class _Hash = std::hash<_Value>,
    class _Pred = std::equal_to<_Value>,
    class _Alloc = std::allocator<_Value>
> class unordered_multiset;

Description

unordered_multiset is a container that stores elements formed into a multiset where each element's key can be duplicated; that is, the container can store multiple elements with the same key.

The elements are not ordered. Internally, it uses a hash table to organize elements. Hash table complexity is average constant time (O(1)) for insertions and deletions, and average constant time (O(1)) for element lookups.

The hash table supports Rehashing , a process of restructuring the hash table when it grows. Rehashing preserves the contents of the container but invalidates all element iterators, except those of the element being inserted or removed.

The unordered_multiset is defined in the <unordered_set> header.
