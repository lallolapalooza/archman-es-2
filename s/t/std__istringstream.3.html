Las funciones de entrada formateada (también conocidas como funciones de entrada formateada) tienen un comportamiento común. Cada una comienza construyendo un objeto temporal de tipo `std::basic_istream::sentry` con el segundo argumento (`noskipws`) establecido en `false`. Esto tiene varios efectos, que concluyen con el establecimiento de una bandera de estado; consulte la documentación de `sentry` para más detalles.

Si el estado de `sentry` es bueno, la función intenta extraer los datos apropiados para el tipo del argumento.

Si se lanza una excepción durante la extracción, `ios_base::badbit` se activará en el estado de error del flujo (sin causar que se lance una `ios_base::failure`) y la excepción original se volverá a lanzar si `badbit` está establecido en la máscara de excepciones.

Esta clase soporta la lectura desde objetos de tipo std::basic_string, utilizando las funciones heredadas de std::basic_istream. Para controlar la secuencia asociada, se utiliza una instancia de std::basic_stringbuf, a la que esta página se refiere como sb.
