template<typename _Tp>

class std::__new_allocator< _Tp >"Un asignador que utiliza new global, según C++03 [20.4.1].

Este es precisamente el asignador definido en el Estándar C++.

  • todas las llamadas de asignación usan operator new
  • todas las llamadas de desasignación usan operator delete

Esta es la implementación base predeterminada de std::allocator, y es también la clase base de la extensión __gnu_cxx::new_allocator. Deberías usar std::allocator o __gnu_cxx::new_allocator en lugar de usar esto directamente.
