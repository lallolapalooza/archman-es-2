Documentación de Datos Miembro

int std::__numeric_limits_base::digits [static], [constexpr]

El número de dígitos de la base que pueden representarse sin cambio: para tipos enteros, el número de bits no de signo en la mantisa; para tipos de punto flotante, el número de dígitos de la base en la mantisa.

Referenciado por std::generate_canonical(), std::independent_bits_engine< _RandomNumberEngine, __w, _UIntType >::operator()(), std::operator<<(), y std::linear_congruential_engine< uint_fast32_t, 16807UL, 0UL, 2147483647UL >::seed().

int std::__numeric_limits_base::digits10 [static], [constexpr]

El número de dígitos en base 10 que se pueden representar sin cambio.

float_denorm_style std::__numeric_limits_base::has_denorm [static], [constexpr]

Ver std::float_denorm_style para más información.

bool std::__numeric_limits_base::has_denorm_loss [static], [constexpr]

Verdadero si la pérdida de precisión se detecta como una pérdida de desnormalización, en lugar de como un resultado inexacto.

bool std::__numeric_limits_base::has_infinity [static], [constexpr]

Verdadero si el tipo tiene una representación para infinito positivo.

bool std::__numeric_limits_base::has_quiet_NaN [static], [constexpr]

Verdadero si el tipo tiene una representación para un valor Silencioso (no de señal) No es un Número (Not a Number).

bool std::__numeric_limits_base::has_signaling_NaN [static], [constexpr]

Verdadero si el tipo tiene una representación para un número de señalización No es un Número (Not a Number).

bool std::__numeric_limits_base::is_bounded [static], [constexpr]

Verdadero si el conjunto de valores representables por el tipo es finito. Todos los tipos incorporados son acotados; este miembro sería falso para tipos de precisión arbitraria.

bool std::__numeric_limits_base::is_exact [static], [constexpr]

Verdadero si el tipo utiliza una representación exacta. Todos los tipos enteros son exactos, pero no todos los tipos exactos son enteros. Por ejemplo, las representaciones racionales y de exponente fijo son exactas pero no enteras.

bool std::__numeric_limits_base::is_iec559 [static], [constexpr]

Verdadero si y solo si el tipo se adhiere al estándar IEC 559, también conocido como IEEE 754. (Solo tiene sentido para tipos de punto flotante.)

bool std::__numeric_limits_base::is_integer [static], [constexpr]

Verdadero si el tipo es entero.

bool std::__numeric_limits_base::is_modulo [static], [constexpr]

Verdadero si el tipo es módulo. Un tipo es módulo si, para cualquier operación que involucre +, -, o * en valores de ese tipo cuyo resultado caiga fuera del rango [min(),max()], el valor devuelto difiere del valor verdadero por un múltiplo entero de max() - min() + 1. En la mayoría de las máquinas, esto es falso para tipos de punto flotante, verdadero para enteros sin signo y verdadero para enteros con signo. Ver PR22200 sobre enteros con signo.

bool std::__numeric_limits_base::is_signed [static], [constexpr]

Verdadero si el tipo tiene signo.

bool std::__numeric_limits_base::is_specialized [static], [constexpr]

Esto será verdadero para todos los tipos fundamentales (que tienen especializaciones), y falso para todo lo demás.

Detailed Description

This namespace provides constants that describe the properties of numeric types. The primary way to access these constants is through the std::numeric_limits struct.

Member Data Documentation

int std::__numeric_limits_base::digits [static], [constexpr]

The number of base radix digits that are necessary to uniquely represent each value of the numeric type.

int std::__numeric_limits_base::digits10 [static], [constexpr]

The number of base 10 digits that are necessary to uniquely represent each value of the numeric type.

float_denorm_style std::__numeric_limits_base::denorm_style [static], [constexpr]

The style of denormalization for floating-point types. Possible values are:

denorm_absent
Denormalized values are not supported.
denorm_finite
Denormalized values are supported and are finite.
denorm_present
Denormalized values are supported.

int std::__numeric_limits_base::max_digits10 [static], [constexpr]

The number of base 10 digits required to ensure that values which differ are always differentiated.

int std::__numeric_limits_base::max_exponent [static], [constexpr]

The maximum positive integer such that radix raised to the power of (one less than that integer) is a representable finite floating point number.

int std::__numeric_limits_base::max_exponent10 [static], [constexpr]

The maximum positive integer such that 10 raised to that power is in the range of representable finite floating point numbers.

int std::__numeric_limits_base::min_exponent [static], [constexpr]

The minimum negative integer such that radix raised to the power of (one less than that integer) is a normalized floating point number.

int std::__numeric_limits_base::min_exponent10 [static], [constexpr]

The minimum negative integer such that 10 raised to that power is in the range of normalized floating point numbers.

int std::__numeric_limits_base::radix [static], [constexpr]

For integer types, specifies the base of the representation. For floating types, specifies the base of the exponent representation.

float_round_style std::__numeric_limits_base::round_style [static], [constexpr]

See std::float_round_style for more information. This is only meaningful for floating types; integer types will all be round_toward_zero.

bool std::__numeric_limits_base::tinyness_before [static], [constexpr]

True if tininess is detected before rounding. (see IEC 559)
