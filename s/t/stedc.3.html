CSTEDC

Propósito:

!>
!> CSTEDC calcula todos los valores propios y, opcionalmente, los vectores propios de una
!> matriz tridiagonal simétrica utilizando el método de divide y conquista.
!> Los vectores propios de una matriz Hermítica completa o de banda también
!> pueden encontrarse si se ha utilizado CHETRD o CHPTRD o CHBTRD para reducir esta
!> matriz a forma tridiagonal.
!>
!>

Parámetros

COMPZ 
!>          COMPZ es CHARACTER*1
!>          = 'N':  Calcular solo valores propios.
!>          = 'I':  Calcular también los vectores propios de la matriz tridiagonal.
!>          = 'V':  Calcular también los vectores propios de la matriz Hermítica original.
!>                  En la entrada, Z contiene la matriz unitaria utilizada
!>                  para reducir la matriz original a forma tridiagonal.
!>

N

!>          N es ENTERO
!>          La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

D

!>          D es array REAL, dimensión (N)
!>          En la entrada, los elementos diagonales de la matriz tridiagonal.
!>          En la salida, si INFO = 0, los valores propios en orden ascendente.
!>

E

!>          E es array REAL, dimensión (N-1)
!>          En la entrada, los elementos subdiagonales de la matriz tridiagonal.
!>          En la salida, E ha sido destruido.
!>

Z

!>          Z es array COMPLEJO, dimensión (LDZ,N)
!>          En la entrada, si COMPZ = 'V', entonces Z contiene la matriz
!>          unitaria utilizada en la reducción a forma tridiagonal.
!>          En la salida, si INFO = 0, entonces si COMPZ = 'V', Z contiene los
!>          vectores propios ortonormales de la matriz Hermítica original,
!>          y si COMPZ = 'I', Z contiene los vectores propios ortonormales
!>          de la matriz tridiagonal simétrica.
!>          Si  COMPZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es ENTERO
!>          La dimensión principal del array Z.  LDZ >= 1.
!>          Si se desean vectores propios, entonces LDZ >= max(1,N).
!>

WORK

!>          WORK es array COMPLEJO, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>          Si COMPZ = 'N' o 'I', o N <= 1, LWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1, LWORK debe ser al menos N*N.
!>          Tenga en cuenta que para COMPZ = 'V', si N es menor o
!>          igual al tamaño mínimo de división, normalmente 25, entonces LWORK solo
!>          necesita ser 1.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es array REAL, dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es ENTERO
!>          La dimensión del array RWORK.
!>          Si COMPZ = 'N' o N <= 1, LRWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1, LRWORK debe ser al menos
!>                         1 + 3*N + 2*N*lg N + 4*N**2 ,
!>                         donde lg( N ) = el entero más pequeño k tal que
!>                         2**k >= N.
!>          Si COMPZ = 'I' y N > 1, LRWORK debe ser al menos
!>                         1 + 4*N + 2*N**2 .
!>          Tenga en cuenta que para COMPZ = 'I' o 'V', si N es menor o
!>          igual al tamaño mínimo de división, normalmente 25, entonces LRWORK
!>          solo necesita ser max(1,2*(N-1)).
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          y IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es array ENTERO, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es ENTERO
!>          La dimensión del array IWORK.
!>          Si COMPZ = 'N' o N <= 1, LIWORK debe ser al menos 1.
!>          Si COMPZ = 'V' o N > 1,  LIWORK debe ser al menos
!>                                    6 + 6*N + 5*N*lg N.
!>          Si COMPZ = 'I' o N > 1,  LIWORK debe ser al menos
!>                                    3 + 5*N .
!>          Tenga en cuenta que para COMPZ = 'I' o 'V', si N es menor o
!>          igual al tamaño mínimo de división, normalmente 25, entonces LIWORK
!>          solo necesita ser 1.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo no pudo calcular un valor propio mientras
!>                trabajaba en la submatriz ubicada en las filas y columnas
!>                INFO/(N+1) hasta mod(INFO,N+1).
!>

NAME

ZSTEDC

SYNOPSIS

 subroutine zstedc (character compz, integer n, double precision,
                     dimension( * ) d, double precision, dimension( * ) e,
                     complex*16, dimension( ldz, * ) z, integer ldz,
                     complex*16, dimension( * ) work, integer lwork,
                     double precision, dimension( * ) rwork, integer lrwork,
                     integer, dimension( * ) iwork, integer liwork,
                     integer info)

ZSTEDC

Detailed Description

Purpose:

!>
!> ZSTEDC computes all eigenvalues and, optionally, eigenvectors of a
!> symmetric tridiagonal matrix using the divide and conquer method.
!> The eigenvectors of a full or band complex Hermitian matrix can also
!> be found if ZHETRD or ZHPTRD or ZHBTRD has been used to reduce this
!> matrix to tridiagonal form.
!>
!>

Parameters

COMPZ 
!>          COMPZ is CHARACTER*1
!>          = 'N':  Compute eigenvalues only.
!>          = 'I':  Compute eigenvectors of tridiagonal matrix also.
!>          = 'V':  Compute eigenvectors of original Hermitian matrix
!>                  also.  On entry, Z contains the unitary matrix used
!>                  to reduce the original matrix to tridiagonal form.
!>

N

!>          N is INTEGER
!>          The dimension of the symmetric tridiagonal matrix.  N >= 0.
!>

D

!>          D is DOUBLE PRECISION array, dimension (N)
!>          On entry, the diagonal elements of the tridiagonal matrix.
!>          On exit, if INFO = 0, the eigenvalues in ascending order.
!>

E

!>          E is DOUBLE PRECISION array, dimension (N-1)
!>          On entry, the subdiagonal elements of the tridiagonal matrix.
!>          On exit, E has been destroyed.
!>

Z

!>          Z is COMPLEX*16 array, dimension (LDZ,N)
!>          On entry, if COMPZ = 'V', then Z contains the unitary
!>          matrix used in the reduction to tridiagonal form.
!>          On exit, if INFO = 0, then if COMPZ = 'V', Z contains the
!>          orthonormal eigenvectors of the original Hermitian matrix,
!>          and if COMPZ = 'I', Z contains the orthonormal eigenvectors
!>          of the symmetric tridiagonal matrix.
!>          If  COMPZ = 'N', then Z is not referenced.
!>

LDZ

!>          LDZ is INTEGER
!>          The leading dimension of the array Z.  LDZ >= 1.
!>          If eigenvectors are desired, then LDZ >= max(1,N).
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          If COMPZ = 'N' or 'I', or N <= 1, LWORK must be at least 1.
!>          If COMPZ = 'V' and N > 1, LWORK must be at least N*N.
!>          Note that for COMPZ = 'V', then if N is less than or
!>          equal to the minimum divide size, usually 25, then LWORK need
!>          only be 1.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal sizes of the WORK, RWORK and
!>          IWORK arrays, returns these values as the first entries of
!>          the WORK, RWORK and IWORK arrays, and no error message
!>          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (MAX(1,LRWORK))
!>          On exit, if INFO = 0, RWORK(1) returns the optimal LRWORK.
!>

LRWORK

!>          LRWORK is INTEGER
!>          The dimension of the array RWORK.
!>          If COMPZ = 'N' or N <= 1, LRWORK must be at least 1.
!>          If COMPZ = 'V' and N > 1, LRWORK must be at least
!>                         1 + 3*N + 2*N*lg N + 4*N**2 ,
!>                         where lg( N ) = smallest integer k such
!>                         that 2**k >= N.
!>          If COMPZ = 'I' and N > 1, LRWORK must be at least
!>                         1 + 4*N + 2*N**2 .
!>          Note that for COMPZ = 'I' or 'V', then if N is less than or
!>          equal to the minimum divide size, usually 25, then LRWORK
!>          need only be max(1,2*(N-1)).
!>
!>          If LRWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal sizes of the WORK, RWORK
!>          and IWORK arrays, returns these values as the first entries
!>          of the WORK, RWORK and IWORK arrays, and no error message
!>          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (MAX(1,LIWORK))
!>          On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.
!>          If COMPZ = 'N' or N <= 1, LIWORK must be at least 1.
!>          If COMPZ = 'V' or N > 1,  LIWORK must be at least
!>                                    6 + 6*N + 5*N*lg N.
!>          If COMPZ = 'I' or N > 1,  LIWORK must be at least
!>                                    3 + 5*N .
!>          Note that for COMPZ = 'I' or 'V', then if N is less than or
!>          equal to the minimum divide size, usually 25, then LIWORK
!>          need only be 1.
!>
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal sizes of the WORK, RWORK
!>          and IWORK arrays, returns these values as the first entries
!>          of the WORK, RWORK and IWORK arrays, and no error message
!>          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  The algorithm failed to compute an eigenvalue while
!>                working on the submatrix lying in rows and columns
!>                INFO/(N+1) through mod(INFO,N+1).
!>
