start_pes(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

START_PES(3) Open MPI START_PES(3)

shmem_init, start_pes - Asigna un bloque de memoria del heap simétrico.

SINOPSIS

C o C++:

void shmem_init(void)
void start_pes(int npes)

Fortran:

CALL SHMEM_INIT()
CALL START_PES(npes)

DESCRIPCIÓN

La rutina start_pes debe ser la primera declaración en un programa paralelo SHMEM.

La rutina start_pes acepta el siguiente argumento:

npes
No utilizado. Debe establecerse en 0.

Esta rutina inicializa la API SHMEM, por lo tanto, debe ser llamada antes de llamar a cualquier otra rutina SHMEM. Esta rutina es responsable, entre otras cosas, de configurar el heap simétrico en el PE que llama y la creación de los números de PE virtuales. Tras el retorno exitoso de esta rutina, el PE que llama podrá comunicarse y transferir datos a otros PEs.

No se permiten llamadas múltiples a esta función.

Para obtener una descripción general de la programación con rutinas de comunicación SHMEM, ejemplos de programas SHMEM e instrucciones para compilar programas SHMEM, consulte la página del manual intro_shmem(3).

EJEMPLOS

Este es un programa simple que llama a shmem_integer_put(3):

PROGRAM PUT
  INCLUDE "mpp/shmem.fh"
  INTEGER TARG, SRC, RECEIVER, BAR
  COMMON /T/ TARG
  PARAMETER (RECEIVER=1)
  CALL SHMEM_INIT()
  IF (MY_PE() .EQ. 0) THEN
    SRC = 33
    CALL SHMEM_INTEGER_PUT(TARG, SRC, 1, RECEIVER)
  ENDIF
  CALL SHMEM_BARRIER_ALL ! Sincroniza emisor y receptor
  IF (MY_PE() .EQ. RECEIVER) THEN
    PRINT *,'PE ', MY_PE(),' TARG=',TARG,' (esperando 33)'
  ENDIF
END

NOTAS

Si la llamada a start_pes no es la primera declaración en un programa, pueden producirse resultados inesperados en algunas arquitecturas.
