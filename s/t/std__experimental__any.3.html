NAME

std::experimental::any — Base class for polymorphic value types.

SYNOPSIS

#include <any>


namespace std {
namespace experimental {
class any;
} // namespace experimental
} // namespace std

Detailed Description

Base class for polymorphic value types.

An object of class any communicates the idea of a type-safe wrapper for arbitrary data.

The any class supports type-safe polymorphic value storage. Construction from an object of any copyable type is supported. Assignment of an object of any copyable type is supported.

The any class provides type-safe access to the contained object by throwing an exception if an invalid type is requested.
