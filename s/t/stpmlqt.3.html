Documentación de función/subrutina

subrutina stpmlqt (character side, character trans, integer m, integer n, integer k, integer l, integer mb, real, dimension( ldv, * ) v, integer ldv, real, dimension( ldt, * ) t, integer ldt, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) work, integer info)

STPMLQT

Propósito:

!>
!> STPMLQT aplica una matriz ortogonal real Q obtenida de un
!>  reflector de bloque real H a una matriz general
!> real C, que consiste en dos bloques A y B.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**T desde la Izquierda;
!>          = 'R': aplicar Q o Q**T desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transposición, aplicar Q;
!>          = 'T':  Transpuesta, aplicar Q**T.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz B. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>

L

!>          L es INTEGER
!>          El orden de la parte trapezoidal de V.
!>          K >= L >= 0.  Ver Detalles Adicionales.
!>

MB

!>          MB es INTEGER
!>          El tamaño del bloque utilizado para el almacenamiento de T.  K >= MB >= 1.
!>          Este debe ser el mismo valor de MB utilizado para generar T
!>          en STPLQT.
!>

V

!>          V es un array REAL, de dimensión (LDV,K)
!>          La i-ésima fila debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, como se devuelve por
!>          STPLQT en B.  Ver Detalles Adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= K.
!>

T

!>          T es un array REAL, de dimensión (LDT,K)
!>          Los factores triangulares superiores de los reflectores de bloque
!>          como se devuelven por STPLQT, almacenados como una matriz de MB por K.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.  LDT >= MB.
!>

A

!>          A es un array REAL, de dimensión
!>          (LDA,N) si SIDE = 'L' o
!>          (LDA,K) si SIDE = 'R'
!>          En la entrada, la matriz A de K por N o M por K.
!>          En la salida, A se sobrescribe con el bloque correspondiente de
!>          Q*C o Q**T*C o C*Q o C*Q**T.  Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,K);
!>          Si SIDE = 'R', LDA >= max(1,M).
!>

B

!>          B es un array REAL, de dimensión (LDB,N)
!>          En la entrada, la matriz B de M por N.
!>          En la salida, B se sobrescribe con el bloque correspondiente de
!>          Q*C o Q**T*C o C*Q o C*Q**T.  Ver Detalles Adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK es un array REAL. La dimensión de WORK es
!>           N*MB si SIDE = 'L', o  M*MB si SIDE = 'R'.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  Las columnas de la matriz pentagonal V contienen los reflectores elementales
!>  H(1), H(2), ..., H(K); V está compuesto por un bloque rectangular V1 y un
!>  bloque trapezoidal V2:
!>
!>        V = [V1] [V2].
!>
!>
!>  El tamaño del bloque trapezoidal V2 está determinado por el parámetro L,
!>  donde 0 <= L <= K; V2 es trapezoidal inferior, consistiendo en las primeras L
!>  filas de una matriz triangular superior KxK.  Si L=K, V2 es triangular inferior;
!!>  si L=0, no hay bloque trapezoidal, por lo tanto V = V1 es rectangular.
!>
!>  Si SIDE = 'L':  C = [A]  donde A es KxN,  B es MxN y V es KxM.
!>                      [B]
!>
!>  Si SIDE = 'R':  C = [A B]  donde A es MxK, B es MxN y V es KxN.
!>
!>  La matriz ortogonal real Q se forma a partir de V y T.
!>
!>  Si TRANS='N' y SIDE='L', C se reemplaza en la salida con Q * C.
!>
!>  Si TRANS='T' y SIDE='L', C se reemplaza en la salida con Q**T * C.
!>
!>  Si TRANS='N' y SIDE='R', C se reemplaza en la salida con C * Q.
!>
!>  Si TRANS='T' y SIDE='R', C se reemplaza en la salida con C * Q**T.
!>
