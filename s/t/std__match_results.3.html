class std::match_results< _Bi_iter, _Alloc >"Los resultados de una operación de coincidencia o búsqueda.

Una colección de secuencias de caracteres que representan el resultado de una coincidencia de expresiones regulares. El almacenamiento para la colección se asigna y libera según sea necesario mediante las funciones miembro de la plantilla de clase match_results.

Esta clase satisface los requisitos de Secuencia, con la excepción de que solo se admiten las operaciones definidas para una Secuencia calificada como const.

El objeto sub_match almacenado en el índice 0 representa la subexpresión 0, es decir, la coincidencia completa. En este caso, el miembro sub_match matched siempre es verdadero. El objeto sub_match almacenado en el índice n denota lo que coincidió con la subexpresión marcada n dentro de la expresión coincidente. Si la subexpresión n participó en una coincidencia de expresión regular, entonces el miembro sub_match matched se evalúa como verdadero, y los miembros first y second denotan el rango de caracteres [first, second) que formaron esa coincidencia. Detailed Description

The class template match_results describes the results of a match against a sequence.

It is a template for bidirectional iterators _Bi_iter and allocator _Alloc.

The type allocator_type is allocator<sub_match<_Bi_iter> >.

The type const_reference is allocator_traits<allocator_type>::const_reference.

The type reference is allocator_traits<allocator_type>::reference.

The type const_iterator is allocator_traits<allocator_type>::const_iterator.

The type iterator is allocator_traits<allocator_type>::iterator.

The type size_type is allocator_traits<allocator_type>::size_type.

The type difference_type is allocator_traits<allocator_type>::difference_type.

The type string_type is std::basic_string<char_type, char_traits, _Alloc>.

The type value_type is sub_match<_Bi_iter>.
