strncat(3) Manual de Funciones de Biblioteca strncat(3)

NOMBRE

strncat - anexa un número limitado de bytes no nulos de un arreglo de origen a una cadena, y termina el resultado con un nulo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <string.h>
char *strncat(size_t ssize;
              char *restrict dst, const char src[restrict ssize],
              size_t ssize);

DESCRIPCIÓN

Esta función anexa como máximo ssize bytes no nulos del arreglo al que apunta src, seguido de un carácter nulo, al final de la cadena a la que apunta dst. dst debe apuntar a una cadena contenida en un buffer que sea lo suficientemente grande, es decir, el tamaño del buffer debe ser al menos strlen(dst) + strnlen(src, ssize) + 1.

Una implementación de esta función podría ser:


char *
strncat(char *restrict dst, const char *restrict src, size_t ssize)
{
    #define strnul(s)  (s + strlen(s))
    stpcpy(mempcpy(strnul(dst), src, strnlen(src, ssize)), "");
    return dst;
}

VALOR DE RETORNO

strncat() devuelve dst.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
strncat () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C89, SVr4, 4.3BSD.

ADVERTENCIAS

El nombre de esta función es confuso; no tiene relación con strncpy(3).

Si el buffer de destino no contiene ya una cadena, o no es lo suficientemente grande, el comportamiento es indefinido. Consulte **_FORTIFY_SOURCE** en feature_test_macros(7).

ERRORES

Esta función puede ser muy ineficiente. Lea sobre Shlemiel the painter.

EJEMPLOS

#include <err.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define NITEMS(arr)  (sizeof((arr)) / sizeof((arr)[0]))
int
main(void)
{
    size_t  n;
    // Secuencias de caracteres de tamaño fijo rellenadas con nulos
    char    pre[4] = "pre.";
    char    new_post[50] = ".foo.bar";
    // Cadenas
    char    post[] = ".post";
    char    src[] = "some_long_body.post";
    char    *dest;
    n = NITEMS(pre) + strlen(src) - strlen(post) + NITEMS(new_post) + 1;
    dest = malloc(sizeof(*dest) * n);
    if (dest == NULL)
        err(EXIT_FAILURE, "malloc()");
    dest[0] = '\0';  // No hay función 'cpy' para este 'cat'.
    strncat(dest, pre, NITEMS(pre));
    strncat(dest, src, strlen(src) - strlen(post));
    strncat(dest, new_post, NITEMS(new_post));
    puts(dest);  // "pre.some_long_body.foo.bar"
    free(dest);
    exit(EXIT_SUCCESS);
}
