NOMBRE

startlxde - script de sesión X para preparar el entorno y ejecutar lxsession.

SINOPSIS

startlxde

DESCRIPCIÓN

startlxde se utiliza para iniciar la sesión de escritorio de LXDE. Por defecto, carga openbox, lxpanel, pcmanfm, dbus-launch y lxsession.
