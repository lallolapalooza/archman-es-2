stdio(3) Manual de funciones de biblioteca stdio(3)

NOMBRE

stdio - funciones de biblioteca de entrada/salida estándar

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
extern FILE  *stdin;
extern FILE  *stdout;
extern FILE  *stderr;

DESCRIPCIÓN

La biblioteca de E/S estándar proporciona una interfaz de E/S de flujo simples y eficientes con búfer. La entrada y salida se mapean en flujos de datos lógicos y las características físicas de E/S se ocultan. Las funciones y macros se enumeran a continuación; hay más información disponible en las páginas del manual individuales.

Un flujo se asocia con un archivo externo (que puede ser un dispositivo físico) al abrir un archivo, lo que puede implicar la creación de un nuevo archivo. La creación de un archivo existente provoca que su contenido anterior sea descartado. Si un archivo puede admitir solicitudes de posicionamiento (como un archivo en disco, en contraposición a una terminal), entonces un indicador de posición de archivo asociado con el flujo se coloca al principio del archivo (byte cero), a menos que el archivo se abra en modo de añadir. Si se usa el modo de añadir, no se especifica si el indicador de posición se colocará al principio o al final del archivo. El indicador de posición se mantiene mediante lecturas, escrituras y solicitudes de posicionamiento posteriores. Toda la entrada ocurre como si los caracteres fueran leídos por llamadas sucesivas a la función fgetc(3); toda la salida se realiza como si todos los caracteres fueran escritos por llamadas sucesivas a la función fputc(3).

Un archivo se desasocia de un flujo al cerrar el archivo. Los flujos de salida se vacían (cualquier contenido del búfer no escrito se transfiere al entorno del host) antes de que el flujo se desasocie del archivo. El valor de un puntero a un objeto FILE es indeterminado después de que se cierra un archivo (basura).

Un archivo puede volver a abrirse posteriormente, por la misma u otra ejecución del programa, y su contenido puede recuperarse o modificarse (si se puede reposicionar al principio). Si la función main devuelve el control a su llamador original, o si se llama a la función exit(3), todos los archivos abiertos se cierran (por lo tanto, todos los flujos de salida se vacían) antes de la terminación del programa. Otros métodos de terminación del programa, como abort(3), no se preocupan por cerrar los archivos correctamente.

Al inicio del programa, se predefinen tres flujos de texto que no necesitan ser abiertos explícitamente: entrada estándar (para leer la entrada convencional), salida estándar (para escribir la salida convencional) y error estándar (para escribir la salida de diagnóstico). Estos flujos se abrevian como stdin, stdout y stderr. Cuando se abren, el flujo de error estándar no está completamente con búfer; los flujos de entrada y salida estándar tienen búfer completo si y solo si los flujos no se refieren a un dispositivo interactivo.

Los flujos de salida que se refieren a dispositivos de terminal siempre tienen búfer de línea por defecto; la salida pendiente en dichos flujos se escribe automáticamente siempre que se lee un flujo de entrada que se refiere a un dispositivo de terminal. En los casos en que se realiza una gran cantidad de cálculo después de imprimir parte de una línea en una terminal de salida, es necesario llamar a fflush(3) en la salida estándar antes de ir y calcular, para que la salida aparezca.

La biblioteca stdio es parte de la biblioteca libc y las rutinas se cargan automáticamente según sea necesario mediante cc(1). Las secciones SINOPSIS de las siguientes páginas del manual indican qué archivos de inclusión se deben usar, cómo es la declaración del compilador para la función y qué variables externas son de interés.

Los siguientes se definen como macros; estos nombres no pueden ser reutilizados sin eliminar primero sus definiciones actuales con #undef: BUFSIZ, EOF, FILENAME_MAX, FOPEN_MAX, L_cuserid, L_ctermid, L_tmpnam, NULL, SEEK_END, SEEK_SET, SEEK_CUR, TMP_MAX, clearerr, feof, ferror, fileno, getc, getchar, putc, putchar, stderr, stdin, stdout. Las versiones de función de las macrofunciones feof, ferror, clearerr, fileno, getc, getchar, putc y putchar existen y se utilizarán si las definiciones de las macros se eliminan explícitamente.

DESCRIPCIÓN

Este manual describe las funciones de entrada/salida (E/S) de la biblioteca C estándar. Estas funciones proporcionan una forma de gestionar la entrada y salida de datos a través de flujos (streams).

Tipos de flujos:

  • stdin: Flujo de entrada estándar.
  • stdout: Flujo de salida estándar.
  • stderr: Flujo de error estándar.

Funciones de gestión de flujos:

  • fopen(): Abre un archivo y lo asocia con un flujo.
  • freopen(): Reasigna un flujo existente a un archivo diferente.
  • fdopen(): Asocia un flujo con un descriptor de archivo existente.
  • fmemopen(): Abre un flujo en una región de memoria.
  • open_memstream(): Crea un flujo de E/S en una región de memoria.
  • fclose(): Cierra un flujo.
  • fflush(): Vacía un flujo (escribe los datos en búfer).

Funciones de posicionamiento:

  • ftell(): Devuelve la posición actual en el flujo.
  • fseek(): Establece la posición de un flujo.
  • rewind(): Rebatea la posición de un flujo al principio.
  • fgetpos(): Obtiene la posición actual del flujo.
  • fsetpos(): Establece la posición del flujo.

Gestión de búferes:

  • setbuf(): Establece el búfer para un flujo.
  • setvbuf(): Establece el búfer para un flujo con más opciones.

Formato de E/S:

  • fprintf(), vfprintf(): Escritura formateada en un flujo.
  • fscanf(), vfscanf(): Lectura formateada desde un flujo.
  • printf(), vprintf(): Escritura formateada en stdout.
  • scanf(), vscanf(): Lectura formateada desde stdin.
  • sprintf(), vsprintf(): Escritura formateada en una cadena.
  • snprintf(), vsnprintf(): Escritura formateada en una cadena con límite de tamaño.
  • sscanf(), vsscanf(): Lectura formateada desde una cadena.

E/S de caracteres y cadenas:

  • fgetc(): Lee un carácter de un flujo.
  • ungetc(): Empuja un carácter de vuelta a un flujo.
  • fgets(): Lee una cadena de un flujo.
  • fputc(): Escribe un carácter en un flujo.
  • puts(): Escribe una cadena en stdout.
  • fputs(): Escribe una cadena en un flujo.

E/S de bloques:

  • fread(): Lee datos de un flujo en un bloque.
  • fwrite(): Escribe datos desde un bloque a un flujo.

Indicadores de error y fin de archivo:

  • clearerr(): Borra los indicadores de error y fin de archivo.
  • feof(): Comprueba si se ha alcanzado el fin del archivo.
  • ferror(): Comprueba si ha ocurrido un error de lectura/escritura.

Mensajes de error del sistema:

  • perror(): Imprime un mensaje de error del sistema.

Archivos temporales:

  • tmpfile(): Crea un archivo temporal que se elimina al cerrarse.
  • tmpnam(): Genera un nombre de archivo temporal único.
  • tempnam(): Genera un nombre de archivo temporal en un directorio específico.

Descriptor de archivo:

  • fileno(): Obtiene el descriptor de archivo asociado a un flujo.

Procesos:

  • popen(): Ejecuta un comando y crea un flujo para comunicarse con él.
  • pclose(): Cierra un flujo creado por popen() y espera a que el proceso termine.

Búferes de línea y bloqueados:

  • setlinebuf(): Establece el búfer de línea para un flujo.
  • flockfile(), ftrylockfile(), funlockfile(): Bloquean y desbloquean el acceso a un flujo para evitar condiciones de carrera en entornos multihilo.
  • getc_unlocked(), putc_unlocked(), getchar_unlocked(), putchar_unlocked(): Versiones no bloqueadas de las funciones de E/S de caracteres, para ser usadas con los mecanismos de bloqueo explícitos.
