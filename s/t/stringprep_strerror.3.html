stringprep_strerror(3)

Paquete: libidn

Licencias: GPL3, LGPL

stringprep_strerror(3) libidn stringprep_strerror(3)

NOMBRE

stringprep_strerror - función de la API

SINOPSIS

#include <stringprep.h>

const char * stringprep_strerror(Stringprep_rc rc);

ARGUMENTOS

Stringprep_rc rc
un código de retorno Stringprep_rc.

DESCRIPCIÓN

Convierte un entero de código de retorno a una cadena de texto. Esta cadena se puede usar para mostrar un mensaje de diagnóstico al usuario.

STRINGPREP_OK

Operación exitosa. Se garantiza que este valor siempre es cero, los restantes solo garantizan tener valores distintos de cero, para fines de comparación lógica.

STRINGPREP_CONTAINS_UNASSIGNED

La cadena contiene puntos de código no asignados, lo cual está prohibido por el perfil.

STRINGPREP_CONTAINS_PROHIBITED

La cadena contiene puntos de código prohibidos por el perfil.

STRINGPREP_BIDI_BOTH_L_AND_RAL

La cadena contiene puntos de código con categorías bidireccionales conflictivas.

STRINGPREP_BIDI_LEADTRAIL_NOT_RAL

El carácter inicial y final de la cadena no tiene la categoría bidireccional correcta.

STRINGPREP_BIDI_CONTAINS_PROHIBITED

Contiene puntos de código prohibidos detectados por el código bidireccional.

STRINGPREP_TOO_SMALL_BUFFER

El búfer proporcionado a la función era demasiado pequeño. Esto generalmente indica un problema en la aplicación que llama.

STRINGPREP_PROFILE_ERROR

El perfil de stringprep era inconsistente. Esto generalmente indica un error interno en la biblioteca.

STRINGPREP_FLAG_ERROR

La bandera proporcionada entró en conflicto con el perfil. Esto generalmente indica un problema en la aplicación que llama.

STRINGPREP_UNKNOWN_PROFILE

El nombre de perfil proporcionado no era conocido por la biblioteca.

STRINGPREP_ICONV_ERROR

Error de conversión de codificación de caracteres.

STRINGPREP_NFKC_FAILED

La operación Unicode NFKC falló. Esto generalmente indica un error interno en la biblioteca.

STRINGPREP_MALLOC_ERROR

malloc() se quedó sin memoria. Este es generalmente un error fatal.

Valor de retorno: Devuelve un puntero a una cadena asignada estáticamente que contiene una descripción del error con el código de retorno rc.
