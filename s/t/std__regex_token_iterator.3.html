DESCRIPCIÓN DETALLADA

template<typename _Bi_iter, typename _Ch_type = typename iterator_traits<_Bi_iter>::value_type, typename _Rx_traits = regex_traits<_Ch_type>>

class std::regex_token_iterator< _Bi_iter, _Ch_type, _Rx_traits >"Itera sobre subcoincidencias en un rango (o divide una cadena de texto).

El propósito de este iterador es enumerar todas, o las especificadas, coincidencias de una expresión regular dentro de un rango de texto. El valor desreferenciado de un iterador de esta clase es un objeto std::sub_match.

Construye por defecto un regex_token_iterator. Un regex_token_iterator construido por defecto es un iterador singular que comparará igual al valor siguiente al último para cualquier iterador del mismo tipo.

Referenciado por operator++(), operator=(), y operator==().

Parámetros

__a [IN] El inicio del texto a buscar.
__b [IN] Uno después del final del texto a buscar.
__re [IN] La expresión regular a buscar.
__submatch [IN] Qué subcoincidencia devolver. Hay algunos valores especiales para este parámetro:
  • -1 cada subexpresión enumerada NO coincide con la expresión regular (también conocido como división de campos)
  • 0 se devuelve toda la cadena que coincide con la subexpresión para cada coincidencia dentro del texto.
  • >0 enumera solo la subexpresión indicada de una coincidencia dentro del texto.

__m [IN] Banderas de política para las reglas de coincidencia.
