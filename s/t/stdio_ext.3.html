stdio_ext(3) Manual de Funciones de Biblioteca stdio_ext(3)

NOMBRE

__fbufsize, __flbf, __fpending, __fpurge, __freadable, __freading, __fsetlocking, __fwritable, __fwriting, _flushlbf - interfaces para la estructura FILE de stdio

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
#include <stdio_ext.h>
size_t __fbufsize(FILE *stream);
size_t __fpending(FILE *stream);
int __flbf(FILE *stream);
int __freadable(FILE *stream);
int __fwritable(FILE *stream);
int __freading(FILE *stream);
int __fwriting(FILE *stream);
int __fsetlocking(FILE *stream, int type);
void _flushlbf(void);
void __fpurge(FILE *stream);

DESCRIPCIÓN

Solaris introdujo rutinas para permitir el acceso portátil a los internos de la estructura FILE, y glibc también las implementó.

La función __fbufsize() devuelve el tamaño del búfer actualmente utilizado por el flujo dado.

La función __fpending() devuelve el número de caracteres en el búfer de salida. Para flujos orientados a caracteres anchos, la unidad son caracteres anchos. Esta función no está definida en búferes en modo de lectura o abiertos en solo lectura.

La función __flbf() devuelve un valor distinto de cero si el flujo tiene búfer de línea y cero en caso contrario.

La función __freadable() devuelve un valor distinto de cero si el flujo permite la lectura y cero en caso contrario.

La función __fwritable() devuelve un valor distinto de cero si el flujo permite la escritura y cero en caso contrario.

La función __freading() devuelve un valor distinto de cero si el flujo es de solo lectura, o si la última operación en el flujo fue una operación de lectura, y cero en caso contrario.

La función __fwriting() devuelve un valor distinto de cero si el flujo es de solo escritura (o solo anexión), o si la última operación en el flujo fue una operación de escritura, y cero en caso contrario.

La función __fsetlocking() se puede usar para seleccionar el tipo de bloqueo deseado en el flujo. Devuelve el tipo actual. El argumento type puede tomar los siguientes tres valores:

FSETLOCKING_INTERNAL
Realiza el bloqueo implícito alrededor de cada operación en el flujo dado (excepto para las *_unlocked). Este es el valor predeterminado.
FSETLOCKING_BYCALLER
El llamador se encargará del bloqueo (posiblemente usando flockfile(3) en caso de que haya más de un hilo), y las rutinas de stdio no realizarán el bloqueo hasta que el estado se restablezca a FSETLOCKING_INTERNAL.
FSETLOCKING_QUERY
No cambia el tipo de bloqueo. (Solo lo devuelve).

La función _flushlbf() vacía todos los flujos con búfer de línea. (Presumiblemente para forzar la salida a un terminal, por ejemplo, antes de leer la entrada del teclado).

La función __fpurge() descarta el contenido del búfer del flujo.
