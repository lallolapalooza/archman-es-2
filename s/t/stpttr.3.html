DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subroutine stpttr (character uplo, integer n, real, dimension( * ) ap, real, dimension( lda, * ) a, integer lda, integer info)

STPTTR copia una matriz triangular del formato empaquetado estándar (TP) al formato completo estándar (TR).

Propósito:

!>
!> STPTTR copia una matriz triangular A del formato empaquetado estándar (TP)
!> al formato completo estándar (TR).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior.
!>          = 'L':  A es triangular inferior.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

AP

!>          AP es array REAL, dimensión ( N*(N+1)/2 ),
!>          En la entrada, la matriz triangular superior o inferior A,
!>          empaquetada por columnas en un array lineal. La j-ésima columna
!>          de A se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

A

!>          A es array REAL, dimensión ( LDA, N )
!>          En la salida, la matriz triangular A. Si UPLO = 'U', la parte
!>          triangular superior superior de N-por-N de A contiene la parte
!>          triangular superior de la matriz A, y la parte triangular
!>          estrictamente inferior de A no se referencia. Si UPLO = 'L', la
!>          parte triangular inferior superior de N-por-N de A contiene la
!>          parte triangular inferior de la matriz A, y la parte triangular
!>          estrictamente superior de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
