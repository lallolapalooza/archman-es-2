NAME

std::subtract_with_carry_engine — subtract with carry random number generator

SYNOPSIS

#include <random>
template<typename   _UIntType, size_t __w, size_t __s, size_t __r>
class std::subtract_with_carry_engine;

Detailed Description

The % subtract_with_carry_engine random number generator engine is a generalisation of the Mersenne Twister.

It is defined as follows:

Let $ X_i $ be the sequence of values generated. The engine has a state consisting of a vector $ V $ of $ w $ unsigned integers, a scalar carry value $ c $, and an index $ k $.

The next state is generated as follows:

    value = V[k] - V[(k+s) % w] - c;
    c = (value >> __w) | ((-value) >> __w);
    V[k] = value & mask;
    k = (k + 1) % w;
where mask is $ 2^w - 1 $.

The engine uses $ r $ integers from the state vector as output for each generation. The values generated are $ X_i, X_{i+1}, \dots X_{i+r-1} $.

The engine has $ w $ unsigned integer state values, $ \text{size\_t} \_\_w $ each $ \text{UIntType} $ wide, and $ \text{size\_t} \_\_s $ and $ \text{size\_t} \_\_r $ other template parameters. The state vector has size $ w $, and consists of $ w $ values $ V_0, \dots, V_{w-1} $. The state also includes a carry value $ c $. The generation of each new value involves $ V_k $ and $ V_{(k+s)\%w} $, where $ k $ is the index of the next value to be overwritten. The engine produces $ r $ values per generation cycle.

The following member types are defined:

char_type
The underlying unsigned integer type. In this library, this is always taken to be `unsigned int` or `unsigned long long`, depending on the size requirement.
result_type
The type of the result of the engines. This is the same as the underlying unsigned integer type.

Constructor & Destructor Documentation

template<typename _UIntType, size_t __w, size_t __s, size_t __r> std::subtract_with_carry_engine (result_type __sd = 0u)

Constructs a % subtract_with_carry_engine random number generator. The argument __sd is used to seed the engine. If __sd is 0, the value 19780503 is used as the seed. Otherwise, __sd is used as the seed. The initial state is then generated using a linear congruential generator with parameters $ m_{lcg} = 2147483563, a_{lcg} = 40014, c_{lcg} = 0 $, and starting value $ lcg(0) = \text{__sd} $. The state vector $ V_{-r}, \dots, V_{-1} $ is set to $ lcg(1), \dots, lcg(r) $, respectively. The carry value $ c $ is initialized to 0 if $ V_{-1} \ne 0 $, and to 1 if $ V_{-1} = 0 $.
