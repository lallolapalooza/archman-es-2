NOMBRE

starfish - demostración gráfica de "hacking" de mapas de color radialmente simétrico y pulsante

SINOPSIS

starfish [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--mono] [--install] [--visual visual] [--delay usecs] [--delay2 secs] [--thickness pixels] [--rotation degrees] [--duration seconds] [--colors int] [--blob] [--no-blob] [--fps]

DESCRIPCIÓN

El programa starfish dibuja objetos radialmente simétricos, que se expanden, contraen, rotan y se invierten. Utiliza estas formas para crear un campo de colores suaves y luego rota el mapa de colores.

OPCIONES

starfish acepta las siguientes opciones:

--window
Dibujar en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibujar en la ventana raíz.
--window-id número
Dibujar en la ventana especificada.
--mono
Si está en una pantalla en color, simula estar en una pantalla monocromática.
--install
Instalar un mapa de colores privado para la ventana.
--visual visual
Especificar qué visual usar. Los valores legales son el nombre de una clase visual o el número de identificación (decimal o hexadecimal) de un visual específico.
--delay microsegundos
Cuánto retraso introducir entre los pasos de la animación. Predeterminado 10000, o aproximadamente 1/100 de segundo.
--thickness píxeles
Qué tan ancha debe ser cada banda de color. Predeterminado 0, lo que significa aleatorio (el valor elegido estará entre 0 y 15).
--rotation grados
Qué tan rápido deben rotar los objetos en cada paso. Predeterminado 0, lo que significa aleatorio (el valor elegido estará entre 0 y 12 grados).
--colors int
Cuántos colores usar. Predeterminado 200. Cuantos más colores, más suaves serán las transiciones y más bonitas serán las imágenes resultantes.
--duration segundos
Cuánto tiempo se ejecutará antes de elegir una nueva forma. Predeterminado 30 segundos.
--delay2 segundos
Cuando expira duration, cuánto esperar antes de comenzar una nueva ejecución. Predeterminado 5 segundos.
--blob
--no-blob
Si se especifica la opción blob, se mostrarán las formas sin procesar, en lugar de un campo de colores generado a partir de ellas.
--fps
Mostrar la tasa de fotogramas actual y la carga de la CPU.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.
