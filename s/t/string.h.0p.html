Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

string.h — operaciones de cadenas

SINOPSIS

#include <string.h>

DESCRIPCIÓN

Parte de la funcionalidad descrita en esta página de referencia amplía el estándar ISO C. Las aplicaciones deberán definir la macro de prueba de características apropiada (consulte el volumen de Interfaces del Sistema de POSIX.1‐2017, Sección 2.2, El Entorno de Compilación) para habilitar la visibilidad de estos símbolos en esta cabecera.

La cabecera <string.h> definirá NULL y size_t como se describe en <stddef.h>.

La cabecera <string.h> definirá el tipo locale_t como se describe en <locale.h>.

Se declararán como funciones y también podrán definirse como macros. Se proporcionarán prototipos de función para su uso con compiladores estándar ISO C.
