Descripción Detallada

Clase error_code

Esta clase es un tipo de valor que almacena un número de error entero y una categoría que da significado al número de error. Típicamente, esto se hace cerca del punto donde ocurre el error, para capturar el valor del error original.

Un objeto error_code puede usarse para almacenar el valor del error original emitido por algún subsistema, con una categoría relevante para el subsistema. Por ejemplo, los errores de las funciones de biblioteca POSIX pueden ser representados por un valor errno y la categoría "genérica", pero los errores de una biblioteca HTTP podrían ser representados por un código de estado de respuesta HTTP (por ejemplo, 404) y una categoría personalizada definida por la biblioteca.
