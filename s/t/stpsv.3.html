Documentación de la función/subrutina

subrutina stpsv (carácter uplo, carácter trans, carácter diag, entero n, real, dimensión(*) ap, real, dimensión(*) x, entero incx)

STPSV

Propósito:

!>
!> STPSV resuelve uno de los sistemas de ecuaciones
!>
!>    A*x = b,   o   A**T*x = b,
!>
!> donde b y x son vectores de n elementos y A es una matriz triangular
!> superior o inferior de n por n, unitaria o no unitaria, suministrada
!> en forma empaquetada.
!>
!> Esta rutina no incluye pruebas de singularidad o casi singularidad.
!> Dichas pruebas deben realizarse antes de llamar a esta rutina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           A la entrada, UPLO especifica si la matriz es superior o
!>           inferior de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           A la entrada, TRANS especifica las ecuaciones a resolver
!>           de la siguiente manera:
!>
!>              TRANS = 'N' o 'n'   A*x = b.
!>
!>              TRANS = 'T' o 't'   A**T*x = b.
!>
!>              TRANS = 'C' o 'c'   A**T*x = b.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           A la entrada, DIAG especifica si A es unitaria o no
!>           triangular de la siguiente manera:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es triangular unitaria.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es triangular
!>                                  unitaria.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

AP

!>          AP es un array REAL de dimensión al menos
!>           ( ( n*( n + 1 ) )/2 ).
!>           Antes de la entrada con UPLO = 'U' o 'u', el array AP debe
!>           contener la matriz triangular superior empaquetada secuencialmente,
!>           columna por columna, de modo que AP( 1 ) contenga a( 1, 1 ),
!>           AP( 2 ) y AP( 3 ) contengan a( 1, 2 ) y a( 2, 2 )
!>           respectivamente, y así sucesivamente.
!>           Antes de la entrada con UPLO = 'L' o 'l', el array AP debe
!>           contener la matriz triangular inferior empaquetada secuencialmente,
!>           columna por columna, de modo que AP( 1 ) contenga a( 1, 1 ),
!>           AP( 2 ) y AP( 3 ) contengan a( 2, 1 ) y a( 3, 1 )
!>           respectivamente, y así sucesivamente.
!>           Tenga en cuenta que cuando DIAG = 'U' o 'u', los elementos diagonales de
!>           A no se referencian, pero se asumen como unidad.
!>

X

!>          X es un array REAL de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector del lado derecho b de n elementos. A la salida, X se
!>           sobrescribe con el vector solución x.
!>

INCX

!>          INCX es INTEGER
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>
