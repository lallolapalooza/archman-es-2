Detailed Description

This module defines constants used by LAPACK routines. It distinguishes between single precision (sp) and double precision (dp) floating-point types.

The constants are defined for convenience and portability, ensuring that routines behave consistently across different systems and compilers.

The constants include:

  • Basic numerical values (zero, one, two, etc.).
  • Machine-dependent parameters related to floating-point representation, such as the smallest and largest representable numbers, machine epsilon, and the base (radix) of the floating-point system.
  • Derived constants used in numerical algorithms, like thresholds for underflow and overflow.
  • Prefix characters ('S' for single precision, 'D' for double precision, 'C' for single complex, 'Z' for double complex) used in routine names.

The definitions often rely on intrinsic Fortran functions like `epsilon`, `radix`, `minexponent`, `maxexponent`, and `digits` to obtain system-specific information.
