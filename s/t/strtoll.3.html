strtol(3) Manual de funciones de biblioteca strtol(3)

NOMBRE

strtol, strtoll, strtoq - convertir una cadena a un entero largo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
long strtol(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
long long strtoll(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

strtoll():

    _ISOC99_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPCIÓN

La función strtol() convierte la parte inicial de la cadena en nptr a un valor de entero largo según la base dada, que debe estar entre 2 y 36 inclusive, o ser el valor especial 0.

La cadena puede comenzar con una cantidad arbitraria de espacios en blanco (según lo determinado por isspace(3)) seguida de un único signo opcional '+' o '-'. Si base es cero o 16, la cadena puede incluir un prefijo "0x" o "0X", y el número se leerá en base 16; si base es cero o 2, la cadena puede incluir un prefijo "0b" o "0B", y el número se leerá en base 2; de lo contrario, una base cero se toma como 10 (decimal) a menos que el siguiente carácter sea '0', en cuyo caso se toma como 8 (octal).

El resto de la cadena se convierte a un valor long de la manera obvia, deteniéndose en el primer carácter que no sea un dígito válido en la base dada. (En bases superiores a 10, la letra 'A' en mayúsculas o minúsculas representa 10, 'B' representa 11, y así sucesivamente, con 'Z' representando 35.)

Si endptr no es NULL, y la base es compatible, strtol() almacena la dirección del primer carácter inválido en *endptr. Si no había ningún dígito, strtol() almacena el valor original de nptr en *endptr (y devuelve 0). En particular, si *nptr no es '\0' pero **endptr es '\0' al regresar, toda la cadena es válida.

La función strtoll() funciona igual que la función strtol() pero devuelve un valor de entero long long.

VALOR DE RETORNO

La función strtol() devuelve el resultado de la conversión, a menos que el valor se desborde inferior o superiormente. Si ocurre un desbordamiento inferior, strtol() devuelve LONG_MIN. Si ocurre un desbordamiento superior, strtol() devuelve LONG_MAX. En ambos casos, errno se establece en ERANGE. Exactamente lo mismo aplica para strtoll() (con LLONG_MIN y LLONG_MAX en lugar de LONG_MIN y LONG_MAX).

ERRORES

Esta función no modifica errno en caso de éxito.

EINVAL
(no en C99) La base dada contiene un valor no compatible.
ERANGE
El valor resultante estaba fuera de rango.

La implementación también puede establecer errno en EINVAL en caso de que no se realizara ninguna conversión (no se encontraron dígitos y se devolvió 0).

VERSIONES

Según POSIX.1, en locales distintas de "C" y "POSIX", estas funciones pueden aceptar otras cadenas numéricas definidas por la implementación.

BSD también tiene


quad_t strtoq(const char *nptr, char **endptr, int base);

con una definición completamente análoga. Dependiendo del tamaño de palabra de la arquitectura actual, esto puede ser equivalente a strtoll() o a strtol().

ADVERTENCIAS

Comprobaciones de rango

Dado que strtol() puede devolver legítimamente 0, LONG_MAX o LONG_MIN (LLONG_MAX o LLONG_MIN para strtoll()) tanto en éxito como en fallo, el programa que llama debe establecer errno a 0 antes de la llamada y luego determinar si ocurrió un error comprobando si errno == ERANGE después de la llamada.


errno = 0;
n = strtol(s, &end, base);
if (end == s)
	goto no_number;
if ((errno == ERANGE && n == LONG_MIN) || n < min)
	goto too_low;
if ((errno == ERANGE && n == LONG_MAX) || n > max)
	goto too_high;

base

Si la base necesita ser comprobada, debe ser comprobada en una llamada donde se sabe que la cadena tiene éxito. De lo contrario, es imposible diferenciar los errores de forma portable.


errno = 0;
strtol("0", NULL, base);
if (errno == EINVAL)
    goto unsupported_base;

ERRORES DE PROGRAMACIÓN

Espacios en blanco

Estas funciones aceptan silenciosamente espacios en blanco iniciales. Para rechazar espacios en blanco, llame a isspace(3) antes de strtol().

BUGS

En implementaciones anteriores de GNU, la comprobación de desbordamiento para el valor máximo de long se podría omitir si el argumento de entrada era un número mayor que LLONG_MAX o menor que LLONG_MIN. Esto era un error de seguridad que ahora ha sido corregido.

EJEMPLOS

En el siguiente ejemplo se muestra el uso de strtoll():

#include <stdlib.h>
 #include <stdio.h>
 #include <errno.h>

 int
 main(void)
 {
     char *endptr, *str;
     long val;
     str = "2147483647";

     errno = 0;    /* To distinguish success/failure after calling strtol() */
     val = strtol(str, &endptr, 10);

     /* Check for various possible errors */
     if (errno == ERANGE) {
         perror("strtol");
         exit(EXIT_FAILURE);
     }

     if (endptr == str) {
         fprintf(stderr, "No digits were found\n");
         exit(EXIT_FAILURE);
     }

     if (*endptr != '\0')        /* Not necessarily an error.  */
         printf("Further characters after number: \"%s\"\n", endptr);

     printf("strtol() returned %ld\n", val);

     exit(EXIT_SUCCESS);
 }
