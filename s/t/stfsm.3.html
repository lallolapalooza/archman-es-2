Funciones/Subrutinas


subrutina stfsm (transr, side, uplo, trans, diag, m, n, alpha, a, b, ldb)

STFSM resuelve una ecuación matricial (un operando es una matriz triangular en formato RFP).

Documentación de función/subrutina

subrutina stfsm (carácter transr, carácter side, carácter uplo, carácter trans, carácter diag, entero m, entero n, real alpha, real, dimensión( 0: * ) a, real, dimensión( 0: ldb-1, 0: * ) b, entero ldb)

STFSM resuelve una ecuación matricial (un operando es una matriz triangular en formato RFP).

Propósito:

!>
!> Rutina similar a BLAS de Nivel 3 para A en Formato RFP.
!>
!> STFSM resuelve la ecuación matricial
!>
!>    op( A )*X = alpha*B  o  X*op( A ) = alpha*B
!>
!> donde alpha es un escalar, X e B son matrices de m por n, A es una matriz
!> triangular unitaria o no unitaria, superior o inferior, y op( A ) es una de
!>
!>    op( A ) = A   o   op( A ) = A**T.
!>
!> A está en Formato Rectangular Full Packed (RFP).
!>
!> La matriz X se sobrescribe en B.
!>

Parámetros

TRANSR 
!>          TRANSR es CHARACTER*1
!>          = 'N':  Se almacena la Forma Normal de RFP A;
!>          = 'T':  Se almacena la Forma Transpuesta de RFP A.
!>

SIDE

!>          SIDE es CHARACTER*1
!>           Al entrar, SIDE especifica si op( A ) aparece a la izquierda
!>           o a la derecha de X como sigue:
!>
!>              SIDE = 'L' o 'l'   op( A )*X = alpha*B.
!>
!>              SIDE = 'R' o 'r'   X*op( A ) = alpha*B.
!>
!>           Sin cambios a la salida.
!>

UPLO

!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la matriz RFP A provino de
!>           una matriz triangular superior o inferior como sigue:
!>           UPLO = 'U' o 'u' RFP A provino de una matriz triangular superior
!>           UPLO = 'L' o 'l' RFP A provino de una matriz triangular inferior
!>
!>           Sin cambios a la salida.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           Al entrar, TRANS especifica la forma de op( A ) a usar
!>           en la multiplicación matricial como sigue:
!>
!>              TRANS  = 'N' o 'n'   op( A ) = A.
!>
!>              TRANS  = 'T' o 't'   op( A ) = A'.
!>
!>           Sin cambios a la salida.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           Al entrar, DIAG especifica si RFP A es unitaria o no
!>           triangular como sigue:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es triangular unitaria.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitaria
!>                                  triangular.
!>
!>           Sin cambios a la salida.
!>

M

!>          M es INTEGER
!>           Al entrar, M especifica el número de filas de B. M debe ser
!>           al menos cero.
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           Al entrar, N especifica el número de columnas de B. N debe ser
!>           al menos cero.
!>           Sin cambios a la salida.
!>

ALPHA

!>          ALPHA es REAL
!>           Al entrar, ALPHA especifica el escalar alpha. Cuando alpha es
!>           cero, A no se referencia y B no necesita estar definido antes
!>           de la entrada.
!>           Sin cambios a la salida.
!>

A

!>          A es un array REAL, dimensión (NT)
!>           NT = N*(N+1)/2 si SIDE='R' y NT = M*(M+1)/2 en caso contrario.
!>           Al entrar, la matriz A en formato RFP.
!>           El formato RFP se describe por TRANSR, UPLO y N como sigue:
!>           Si TRANSR='N' entonces la RFP A es (0:N,0:K-1) cuando N es par;
!>           K=N/2. RFP A es (0:N-1,0:K) cuando N es impar; K=N/2. Si
!>           TRANSR = 'T' entonces RFP es la transpuesta de RFP A tal como
!>           se define cuando TRANSR = 'N'. Los contenidos de RFP A se definen
!>           por UPLO como sigue: Si UPLO = 'U' la RFP A contiene los NT
!>           elementos de A empaquetada superior, ya sea en formato normal o
!>           transpuesto. Si UPLO = 'L' la RFP A contiene
!>           los NT elementos de A empaquetada inferior, ya sea en formato normal o
!>           transpuesto. El LDA de RFP A es (N+1)/2 cuando
!>           TRANSR = 'T'. Cuando TRANSR es 'N' el LDA es N+1 cuando N es
!>           par y es N cuando es impar.
!>           Ver la Nota a continuación para más detalles. Sin cambios a la salida.
!>

B

!>          B es un array REAL, dimensión (LDB,N)
!>           Antes de la entrada, la parte principal de m por n del array B debe
!>           contener la matriz del lado derecho B, y a la salida se
!>           sobrescribe con la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>           Al entrar, LDB especifica la primera dimensión de B tal como se declaró
!>           en el programa (sub)llamador. LDB debe ser
!>           al menos max( 1, m ).
!>           Sin cambios a la salida.
!>

NAME

STFSM - En la matriz de transformación de transformación de subespacios de LAPACK (STFSM) de LAPACK, un subprograma de ayuda para la transformación de transformación de subespacios.

SYNOPSIS

    SUBROUTINE STFSM(
        SIDE, TRANS, DIRECT, TRANSFORM, UPLO, DIAG,
        ROW, COL, M, N,
        A, LDA, B, LDB, WORK, LWORK, INFO
    )

Function/Subroutine Documentation

Esta subrutina se llama en la rutina de transformación de subespacios de LAPACK (STFSM). Es un subprograma de ayuda que permite a la rutina principal implementar de forma más limpia la transformación de transformación de subespacios.

El propósito de esta subrutina es aplicar una transformación de matriz triangular a una matriz. Está destinada a ser utilizada como subrutina de ayuda en el código de la transformación de subespacios de LAPACK.

SIDE
Indica si la matriz triangular está a la izquierda o a la derecha de la matriz de entrada.
TRANS
Indica si la matriz triangular se utiliza en su forma original o traspuesta.
DIRECT
Indica si la transformación es hacia adelante o hacia atrás.
TRANSFORM
Indica si se aplica una transformación de subespacios (por ejemplo, una transformación de Householder o Givens).
UPLO
Indica si la matriz triangular es superior o inferior.
DIAG
Indica si la matriz triangular es unitaria o no.
ROW
El número de filas de la matriz triangular.
COL
El número de columnas de la matriz triangular.
M
El número de filas de la matriz de entrada.
N
El número de columnas de la matriz de entrada.
A
La matriz triangular de entrada.
LDA
El tamaño de la primera dimensión de A.
B
La matriz de entrada a la que se aplicará la transformación.
LDB
El tamaño de la primera dimensión de B.
WORK
Un array de trabajo para almacenamiento intermedio.
LWORK
La longitud del array WORK.
INFO
Un entero que indica el estado de salida.
