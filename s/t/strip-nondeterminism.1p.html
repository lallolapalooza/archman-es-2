NOMBRE

strip-nondeterminism - elimina información no determinista de archivos

SINOPSIS

strip-nondeterminism [-t tipo_archivo] nombre_archivo ...

DESCRIPCIÓN

strip-nondeterminism es una herramienta para eliminar bits de información no determinista, como las marcas de tiempo, de los archivos. Se puede utilizar como un paso de postprocesamiento para hacer que una compilación sea reproducible, cuando el proceso de compilación en sí no se puede hacer determinista.

OPCIONES

-t tipo_archivo, --tipo tipo_archivo
Usa el normalizador para el tipo de archivo dado (ar, gzip, jar, zip). Si esta opción no se especifica, el tipo de archivo se detecta automáticamente basándose en la extensión del nombre del archivo.
-T segundos, --marca-de-tiempo segundos
En lugar de eliminar las marcas de tiempo de los archivos, las establece al número dado de segundos desde el 1 de enero de 1970.
--clamp-timestamp
Solo reemplaza las marcas de tiempo si son posteriores a la hora especificada con --timestamp. Puedes usar esta opción para asegurarte de que solo se reemplacen las marcas de tiempo introducidas como parte del proceso de compilación. AÚN NO IMPLEMENTADO PARA TODOS LOS FORMATOS DE ARCHIVO.
--normalizers SPEC
Habilita o deshabilita normalizadores específicos separados por una coma (ej. +foo,-bar. Los valores mágicos +all y -all habilitarán y deshabilitarán todos los normalizadores.
-h, --ayuda
Muestra este mensaje de ayuda.
-V, --version
Imprime solo la cadena de versión y luego sale.
