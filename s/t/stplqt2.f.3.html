Documentación de función/subrutina

subrutina stplqt2 (integer m, integer n, integer l, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldt, * ) t, integer ldt, integer info)

STPLQT2 calcula una factorización LQ de una matriz real o compleja "triangular-pentagonal", que está compuesta por un bloque triangular y un bloque pentagonal, utilizando la representación compacta WY para Q.

Propósito:

!>
!> STPLQT2 calcula una factorización LQ de una matriz real 
!> C, que está compuesta por un bloque triangular A y un bloque pentagonal B,
!> utilizando la representación compacta WY para Q.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número total de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz B, y el orden de
!>          la matriz triangular A.
!>          N >= 0.
!>

L

!>          L es ENTERO
!>          El número de filas de la parte trapezoidal inferior de B.
!>          MIN(M,N) >= L >= 0. Ver Detalles Adicionales.
!>

A

!>          A es un array REAL, dimensionado (LDA,M)
!>          En la entrada, la matriz triangular inferior A de M-por-M.
!>          En la salida, los elementos en y debajo de la diagonal del array
!>          contienen la matriz triangular inferior L.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array REAL, dimensionado (LDB,N)
!>          En la entrada, la matriz pentagonal B de M-por-N. Las primeras N-L columnas
!>          son rectangulares y las últimas L columnas son trapezoidales inferiores.
!>          En la salida, B contiene la matriz pentagonal V. Ver Detalles Adicionales.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B. LDB >= max(1,M).
!>

T

!>          T es un array REAL, dimensionado (LDT,M)
!>          El factor triangular superior T de N-por-N del reflector de bloque.
!>          Ver Detalles Adicionales.
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal del array T. LDT >= max(1,M)
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Detalles Adicionales:

!>
!>  La matriz de entrada C es una matriz M-por-(M+N)
!>
!>               C = [ A ][ B ]
!>
!>
!>  donde A es una matriz triangular inferior M-por-M, y B es una matriz pentagonal
!>  M-por-N que consiste en una matriz rectangular B1 de M-por-(N-L) a la izquierda de
!>  una matriz trapezoidal inferior B2 de M-por-L:
!>
!>               B = [ B1 ][ B2 ]
!>                   [ B1 ]  <-     rectangular M-por-(N-L)
!>                   [ B2 ]  <-     trapezoidal inferior M-por-L.
!>
!>  La matriz trapezoidal inferior B2 consiste en las primeras L columnas de una
!>  matriz triangular inferior N-por-N, donde 0 <= L <= MIN(M,N). Si L=0,
!>  B es rectangular M-por-N; si M=L=N, B es triangular inferior.
!>
!>  La matriz W almacena los reflectores elementales H(i) en la fila i
!>  por encima de la diagonal (de A) en la matriz de entrada C de M-por-(M+N)
!>
!>               C = [ A ][ B ]
!>                   [ A ]  <- triangular inferior M-por-M
!>                   [ B ]  <- pentagonal M-por-N
!>
!>  de modo que W pueda representarse como
!>
!>               W = [ I ][ V ]
!>                   [ I ]  <- identidad, M-por-M
!>                   [ V ]  <- M-por-N, misma forma que B.
!>
!>  Por lo tanto, toda la información necesaria para W está contenida en la salida en B,
!>  que llamamos V arriba. Nótese que V tiene la misma forma que B; es decir,
!>
!>               W = [ V1 ][ V2 ]
!>                   [ V1 ] <-     rectangular M-por-(N-L)
!>                   [ V2 ] <-     trapezoidal inferior M-por-L.
!>
!>  Las filas de V representan los vectores que definen los H(i).
!>  El reflector de bloque H de (M+N)-por-(M+N) está dado entonces por
!>
!>               H = I - W**T * T * W
!>
!>  donde W^H es la transpuesta conjugada de W y T es el factor triangular superior
!>  del reflector de bloque.
!>
