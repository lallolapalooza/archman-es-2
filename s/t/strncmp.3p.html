STRNCMP(3P) Manual de Programador de POSIX STRNCMP(3P)

PROLOG

Esta página del manual forma parte del Manual de Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

strncmp — compara parte de dos cadenas

SINOPSIS

#include <string.h>
int strncmp(const char *s1, const char *s2, size_t n);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La función strncmp() comparará no más de n bytes (los bytes que siguen a un carácter NUL no se comparan) del array apuntado por s1 con el array apuntado por s2.

El signo de un valor de retorno no nulo se determina por el signo de la diferencia entre los valores de los primeros pares de bytes (ambos interpretados como tipo unsigned char) que difieren en las cadenas que se comparan.

VALOR DE RETORNO

Al completarse con éxito, strncmp() devolverá un entero mayor que, igual a, o menor que 0, si el array posiblemente terminado en NUL apuntado por s1 es mayor que, igual a, o menor que el array posiblemente terminado en NUL apuntado por s2, respectivamente.

ERRORES

No se definen errores.
