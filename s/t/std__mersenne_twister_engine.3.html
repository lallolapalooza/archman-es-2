class std::mersenne_twister_engine< _UIntType, __w, __n, __m, __r, __a, __u, __d, __s, __b, __t, __c, __l, __f >"Un generador de números aleatorios de registro de desplazamiento de retroalimentación generalizado.

Este algoritmo evita la multiplicación y la división y está diseñado para ser compatible con una arquitectura de tuberías. Si los parámetros se eligen correctamente, este generador producirá números con un período muy largo y una entropía aparente bastante buena, aunque todavía no es criptográficamente fuerte.

La mejor manera de utilizar este generador es con la clase predefinida mt19937.

Este algoritmo fue inventado originalmente por Makoto Matsumoto y Takuji Nishimura.

Parámetros de plantilla

__w Tamaño de palabra, el número de bits en cada elemento del vector de estado.
__n El grado de recursión.
__m El parámetro de período.
__r El índice de bit del punto de separación.
__a La última fila de la matriz de torsión.
__u El primer parámetro de la matriz de templeo de desplazamiento a la derecha.
__d La primera máscara de la matriz de templeo de desplazamiento a la derecha.
__s El primer parámetro de la matriz de templeo de desplazamiento a la izquierda.

__t El segundo parámetro de la matriz de templeo de desplazamiento a la izquierda.

Description

The class template std::mersenne_twister_engine is a random number generator engine based on the Mersenne Twister algorithm. The algorithm was developed by Makoto Matsumoto and Takuji Nishimura in 1997. It has a very large period (219937-1) and good statistical properties.

The engine is parameterized by the following template parameters:

_UIntType
The unsigned integer type used for the state of the engine. Must be an unsigned integer type.
__w
The number of bits in each state word. Typically 32 or 64.
__n
The size of the state vector. The period of the generator is dependent on this value and is typically 2n-1.
__m
The degree of the Mersenne Twister recurrence. This value must be less than or equal to __n.
__r
The number of bits in the lower part of a state word after tempering. This value must be less than __w.
__a
The tempering mask a.
__u
The tempering shift u.
__d
The tempering mask d.
__s
The tempering shift s.
__b
The tempering mask b.
__t
The tempering shift t.
__c
The tempering mask c.
__l
The tempering shift l.
__f
The tempering mask f.

The standard library provides several instances of std::mersenne_twister_engine:
