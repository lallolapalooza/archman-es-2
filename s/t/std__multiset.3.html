Detailed Description

template<typename _Key, typename _Compare = std::less<_Key>, typename _Alloc = std::allocator<_Key>>

class std::multiset< _Key, _Compare, _Alloc >

Un contenedor estándar compuesto por elementos, que pueden ser recuperados en tiempo logarítmico.

Since

C++98

Template Parameters

_Key Tipo de objetos clave.
_Compare Tipo de objeto función de comparación, por defecto es less<_Key>.
_Alloc Tipo de asignador, por defecto es allocator<_Key>.

Cumple los requisitos de un contenedor, un contenedor reversible y un contenedor asociativo (usando claves equivalentes). Para un multiset<Key> el key_type y value_type son Key.

Los multisets soportan iteradores bidireccionales.

Los datos privados del árbol se declaran exactamente de la misma manera para set y multiset; la distinción se hace enteramente en cómo se llaman las funciones del árbol (*_unique versus *_equal, lo mismo que el estándar).

Parámetros

__args Argumentos utilizados para generar la instancia del elemento a insertar.

Devuelve

Un iterador que apunta al elemento insertado.

Esta función inserta un elemento en el multiset. A diferencia de un std::set, el multiset no depende de claves únicas y, por lo tanto, se pueden insertar varias copias del mismo elemento.

La inserción requiere tiempo logarítmico.

Detailed Description

A multiset is a sequence of elements, the same number of values as the number of elements in the container. It is a container that supports unordered and ordered operations on the contained elements.

In a multiset the elements are not sorted in any specific order, but the container supports sorting of the elements. A multiset is defined by the standard library and is part of the C++ Standard Library.

A multiset is an associative container that contains a sorted sequence of elements with duplicate values. It stores values of type T. The values are sorted according to a comparison function object Compare. The set may contain multiple elements with the same value.

The multiset is implemented by means of a red-black tree. Red-black trees give logarithmic time complexity to most operations on user data structures.

Multisets maintain their elements in sorted order according to the comparison function object (specified by the template parameter 'Compare'). Multisets are typically implemented as binary search trees.

Note
Because multiset keeps elements sorted, it can be used in algorithms that require sorted ranges.

AUR Helper - Arch User Repository Helper

What is it?

AUR Helper is a utility for Arch Linux that automates the process of building and installing packages from the Arch User Repository (AUR). The AUR is a community-driven repository of package descriptions, maintained by users and for users. It allows you to easily install software that is not available in the official Arch repositories.

Features

  • Automated downloading, building, and installation of AUR packages.
  • Dependency resolution for AUR packages.
  • Package upgrade and removal functionality.
  • Support for various AUR helpers (e.g., yay, paru).
  • Customizable build options.

Installation

You can install AUR Helper from the official Arch User Repository (AUR) using an existing AUR helper like yay or paru: 

yay -S aur-helper
# or
paru -S aur-helper

Alternatively, you can build and install it manually from the source code: 

git clone https://github.com/example/aur-helper.git
cd aur-helper
makepkg -si

Usage

To search for and install a package from the AUR: 

aur-helper -S <package_name>

To upgrade all installed AUR packages: 

aur-helper -Syu

To remove an AUR package: 

aur-helper -R <package_name>

For a full list of commands and options, refer to the documentation: 

aur-helper --help
