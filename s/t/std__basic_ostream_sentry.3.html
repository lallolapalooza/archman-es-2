class std::basic_ostream< _CharT, _Traits >::sentry"Realiza trabajos de preparación para flujos de salida.

Los objetos de esta clase se crean antes de que se ejecuten todos los insertores estándar. Es responsable de las operaciones de prefijo y sufijo seguras frente a excepciones.

Parámetros

__os El flujo de salida a proteger.

Si el estado del flujo es bueno (__os.good() es verdadero), entonces si el flujo está enlazado a otro flujo de salida, se llama a is.tie()->flush() para sincronizar las secuencias de salida.

Si el estado del flujo sigue siendo bueno, entonces el estado del sentry se vuelve verdadero (correcto).

Referencias a std::basic_ostream< _CharT, _Traits >::basic_ostream(), std::basic_ios< _CharT, _Traits >::bad(), std::ios_base::failbit, std::basic_ios< _CharT, _Traits >::good(), std::basic_ios< _CharT, _Traits >::setstate() y std::basic_ios< _CharT, _Traits >::tie().

template<typename _CharT, typename _Traits> std::basic_ostream< _CharT, _Traits >::sentry::~sentry () [inline]

Posiblemente vacía el flujo. Si ios_base::unitbuf está establecido en os.flags(), y std::uncaught_exception() es verdadero, el destructor del sentry vacía el flujo de salida.

Referencias a std::ios_base::badbit y std::ios_base::unitbuf.
