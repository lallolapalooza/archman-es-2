NOMBRE

SRC/stfsm.f

SINOPSIS

Funciones/Subrutinas


subrutina stfsm (transr, side, uplo, trans, diag, m, n, alpha, a, b, ldb)

STFSM resuelve una ecuación matricial (un operando es una matriz triangular en formato RFP).

Documentación de función/subrutina

subrutina stfsm (character transr, character side, character uplo, character trans, character diag, integer m, integer n, real alpha, real, dimension( 0: * ) a, real, dimension( 0: ldb-1, 0: * ) b, integer ldb)

STFSM resuelve una ecuación matricial (un operando es una matriz triangular en formato RFP).

Propósito:

!>
!> Rutina tipo BLAS de Nivel 3 para A en Formato RFP.
!>
!> STFSM resuelve la ecuación matricial
!>
!>    op( A )*X = alpha*B  o  X*op( A ) = alpha*B
!>
!> donde alpha es un escalar, X e B son matrices de m por n, A es una matriz
!> triangular unitaria o no unitaria, superior o inferior y op( A ) es una de
!>
!>    op( A ) = A   o   op( A ) = A**T.
!>
!> A está en Formato Rectangular Full Packed (RFP).
!>
!> La matriz X se sobrescribe en B.
!>

Parámetros

TRANSR 
!>          TRANSR es CHARACTER*1
!>          = 'N':  Se almacena la Forma Normal de RFP A;
!>          = 'T':  Se almacena la Forma Transpuesta de RFP A.
!>

SIDE

!>          SIDE es CHARACTER*1
!>           Al entrar, SIDE especifica si op( A ) aparece a la izquierda
!>           o a la derecha de X de la siguiente manera:
!>
!>              SIDE = 'L' o 'l'   op( A )*X = alpha*B.
!>
!>              SIDE = 'R' o 'r'   X*op( A ) = alpha*B.
!>
!>           Sin cambios al salir.
!>

UPLO

!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la matriz RFP A provino de
!>           una matriz triangular superior o inferior de la siguiente manera:
!>           UPLO = 'U' o 'u' RFP A provino de una matriz triangular superior
!>           UPLO = 'L' o 'l' RFP A provino de una matriz triangular inferior
!>
!>           Sin cambios al salir.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           Al entrar, TRANS especifica la forma de op( A ) a utilizar
!>           en la multiplicación de matrices de la siguiente manera:
!>
!>              TRANS  = 'N' o 'n'   op( A ) = A.
!>
!>              TRANS  = 'T' o 't'   op( A ) = A'.
!>
!>           Sin cambios al salir.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           Al entrar, DIAG especifica si RFP A es unitaria o no
!>           triangular de la siguiente manera:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es triangular unitaria.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitaria
!>                                  triangular.
!>
!>           Sin cambios al salir.
!>

M

!>          M es INTEGER
!>           Al entrar, M especifica el número de filas de B. M debe ser
!>           mayor o igual a cero.
!>           Sin cambios al salir.
!>

N

!>          N es INTEGER
!>           Al entrar, N especifica el número de columnas de B. N debe ser
!>           mayor o igual a cero.
!>           Sin cambios al salir.
!>

ALPHA

!>          ALPHA es REAL
!>           Al entrar, ALPHA especifica el escalar alpha. Cuando alpha es
!>           cero, A no se referencia y B no necesita ser establecida antes
!>           de la entrada.
!>           Sin cambios al salir.
!>

A

!>          A es un array REAL, dimension (NT)
!>           NT = N*(N+1)/2 si SIDE='R' y NT = M*(M+1)/2 en caso contrario.
!>           Al entrar, la matriz A en formato RFP.
!>           El formato RFP se describe mediante TRANSR, UPLO y N de la siguiente manera:
!>           Si TRANSR='N' entonces RFP A es (0:N,0:K-1) cuando N es par;
!>           K=N/2. RFP A es (0:N-1,0:K) cuando N es impar; K=N/2. Si
!>           TRANSR = 'T' entonces RFP es la transpuesta de RFP A tal como
!>           se define cuando TRANSR = 'N'. Los contenidos de RFP A están definidos
!>           por UPLO de la siguiente manera: Si UPLO = 'U' la RFP A contiene los NT
!>           elementos de A superior empaquetada ya sea en formato normal o
!>           transpuesto. Si UPLO = 'L' la RFP A contiene
!>           los NT elementos de A inferior empaquetada ya sea en formato normal o
!>           transpuesto. El LDA de RFP A es (N+1)/2 cuando
!>           TRANSR = 'T'. Cuando TRANSR es 'N' el LDA es N+1 cuando N es
!>           par y es N cuando es impar.
!>           Ver la Nota a continuación para más detalles. Sin cambios al salir.
!>

B

!>          B es un array REAL, dimension (LDB,N)
!>           Antes de entrar, la parte principal de m por n del array B debe
!>           contener la matriz del lado derecho B, y al salir se sobrescribe
!>           con la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>           Al entrar, LDB especifica la primera dimensión de B tal como se declaró
!>           en el programa (sub)llamador. LDB debe ser al menos
!>           max( 1, m ).
!>           Sin cambios al salir.
!>

Detalles adicionales:

!>
!>  Primero consideramos el Formato Rectangular Full Packed (RFP) cuando N es
!>  par. Damos un ejemplo donde N = 6.
!>
!>      AP es Superior             AP es Inferior
!>
!>   00 01 02 03 04 05       00
!>      11 12 13 14 15       10 11
!>         22 23 24 25       20 21 22
!>            33 34 35       30 31 32 33
!>               44 45       40 41 42 43 44
!>                  55       50 51 52 53 54 55
!>
!>
!>  Sea TRANSR = 'N'. RFP almacena AP de la siguiente manera:
!>  Para UPLO = 'U', el trapecio superior A(0:5,0:2) consta de las últimas
!>  tres columnas de AP superior. El triángulo inferior A(4:6,0:2) consta de
!>  la transpuesta de las primeras tres columnas de AP superior.
!>  Para UPLO = 'L', el trapecio inferior A(1:6,0:2) consta de las primeras
!>  tres columnas de AP inferior. El triángulo superior A(0:2,0:2) consta de
!>  la transpuesta de las últimas tres columnas de AP inferior.
!>  Esto cubre el caso N par y TRANSR = 'N'.
!>
!>         RFP A                   RFP A
!>
!>        03 04 05                33 43 53
!>        13 14 15                00 44 54
!>        23 24 25                10 11 55
!>        33 34 35                20 21 22
!>        00 44 45                30 31 32
!>        01 11 55                40 41 42
!>        02 12 22                50 51 52
!>
!>  Ahora, sea TRANSR = 'T'. RFP A en ambos casos UPLO es simplemente la
!>  transpuesta de RFP A anterior. Por lo tanto, se obtiene:
!>
!>
!>           RFP A                   RFP A
!>
!>     03 13 23 33 00 01 02    33 00 10 20 30 40 50
!>     04 14 24 34 44 11 12    43 44 11 21 31 41 51
!>     05 15 25 35 45 55 22    53 54 55 22 32 42 52
!>
!>
!>  Consideramos luego el Formato Rectangular Full Packed (RFP) cuando N es
!>  impar. Damos un ejemplo donde N = 5.
!>
!>     AP es Superior             AP es Inferior
!>
!>   00 01 02 03 04              00
!>      11 12 13 14              10 11
!>         22 23 24              20 21 22
!>            33 34              30 31 32 33
!>               44              40 41 42 43 44
!>
!>
!>  Sea TRANSR = 'N'. RFP almacena AP de la siguiente manera:
!>  Para UPLO = 'U', el trapecio superior A(0:4,0:2) consta de las últimas
!>  tres columnas de AP superior. El triángulo inferior A(3:4,0:1) consta de
!>  la transpuesta de las dos primeras columnas de AP superior.
!>  Para UPLO = 'L', el trapecio inferior A(0:4,0:2) consta de las primeras
!>  tres columnas de AP inferior. El triángulo superior A(0:1,1:2) consta de
!>  la transpuesta de las dos últimas columnas de AP inferior.
!>  Esto cubre el caso N impar y TRANSR = 'N'.
!>
!>         RFP A                   RFP A
!>
!>        02 03 04                00 33 43
!>        12 13 14                10 11 44
!>        22 23 24                20 21 22
!>        00 33 34                30 31 32
!>        01 11 44                40 41 42
!>
!>  Ahora, sea TRANSR = 'T'. RFP A en ambos casos UPLO es simplemente la
!>  transpuesta de RFP A anterior. Por lo tanto, se obtiene:
!>
!>
!>           RFP A                   RFP A
!>
!>     02 12 22 00 01    33 10 20 30 40
!>     03 13 23 33 11    43 11 21 31 41
!>     04 14 24 34 44    53 54 22 32 42

NAME


STFSM - Subroutine STFSM






SYNOPSIS


SUBROUTINE STFSM(
     TRANSAC, UPLO, TRANSA, DIAG, SIDE, M, N, ALPHA, A, LDA, B, LDB, INFO
   )
      REAL ALPHA
      INTEGER INFO, LDA, LDB, M, N
      CHARACTER*1 A( LDA, * ), ALPHA, B( LDB, * ), DIAG, SIDE, TRANSA,
     $           TRANSAC, UPLO







Function/Subroutine Documentation


 STFSM solves one of the matrix-matrix equations


    A * X = S * B,   or   X * A = S * B,



where A is a triangular matrix, X and B are M-by-N matrices,
    and S is a scalar. S is always 1.0 in this implementation.


Here, OP(A) is one of


    OP(A) = A       or   OP(A) = A**T



and


    A is an LDA-by-N or LDA-by-M triangular matrix.


A can be:


    UPLO = 'U'   Upper triangular
    UPLO = 'L'   Lower triangular



and triangularity is determined by the values of UPLO and TRANSA.


DIAG = 'U'   A is unit triangular


DIAG = 'N'   A is non-unit triangular


The arguments TRANSAC and TRANSA specify the form of the matrix A
    that is used in the computation. They are identical in function.


The argument SIDE specifies whether to solve:


    SIDE = 'L'   A * X = S * B
    SIDE = 'R'   X * A = S * B



The matrix X is overwritten on B.

Further Details:


Let G be the matrix A or A**T.


If SIDE = 'L', then the problem is to solve OP(A) * X = S * B.


If SIDE = 'R', then the problem is to solve X * OP(A) = S * B.


The computation is done, in general, without explicit
    forming of the triangular factor. Use


    TRANSA = 'N'



to denote that A is the triangular factor.


Use


    TRANSA = 'T'



to denote that A**T is the triangular factor.


The argument TRANSAC is for compatibility with the SGETRF
    routine and has no effect on the computation.


The argument DIAG has no effect on the computation.


Example:


Consider the system


      op(A) * x = b



where


      op(A) = A,   A is upper triangular,   DIAG = 'N',   SIDE = 'L',
      M = 4, N = 5,   LDA = 4, LDB = 4.


The input to the routine STFSM is:


      TRANSAC = 'N', UPLO = 'U', TRANSA = 'N', DIAG = 'N', SIDE = 'L',
      M = 4, N = 5, ALPHA = 1.0,
      A = [[ a11, a12, a13, a14, a15 ],
           [  0,  a22, a23, a24, a25 ],
           [  0,   0,  a33, a34, a35 ],
           [  0,   0,   0,  a44, a45 ]],
      B = [[ b11, b12, b13, b14, b15 ],
           [ b21, b22, b23, b24, b25 ],
           [ b31, b32, b33, b34, b35 ],
           [ b41, b42, b43, b44, b45 ]]



The output is:


      B = [[ x11, x12, x13, x14, x15 ],
           [ x21, x22, x23, x24, x25 ],
           [ x31, x32, x33, x34, x35 ],
           [ x41, x42, x43, x44, x45 ]]



where the vector x is computed by solving


      a11*x1j + a12*x2j + ... + a14*x4j = b1j,
      a22*x2j + a23*x3j + ... + a24*x4j = b2j,
      a33*x3j + a34*x4j                 = b3j,
      a44*x4j                         = b4j,



for j = 1, 2, 3, 4, 5.
