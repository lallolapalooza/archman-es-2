Formatea y muestra un valor monetario. Esta función formatea digits como un valor monetario de acuerdo con las facetas moneypunct y ctype recuperadas de io.getloc(), y escribe los caracteres resultantes en __s. Por ejemplo, la cadena 1001 en una configuración regional de EE. UU. escribiría $10.01 en __s.

Esta función es un gancho para que las clases derivadas cambien el valor devuelto.

Detailed Description

template<typename _CharT, typename _OutIter>
class std::money_put< _CharT, _OutIter >

This class is a locale facet that formats and outputs monetary values.

The facet is used by stream operators like std::put_money.

The primary function is put(), which formats a monetary value according to the locale's moneypunct and ctype facets, and writes the resulting characters to an output iterator.

Formats and outputs a monetary value. This function formats units as a monetary value according to moneypunct and ctype facets retrieved from __io.getloc(), and writes the resulting characters to __s. For example, the value 1001 in a US locale would write $10.01 to __s.

This function is a hook for derived classes to change the value returned.
