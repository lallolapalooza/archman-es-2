Extractores
Todas las funciones operator>> (también conocidas como *funciones de entrada con formato*) tienen un comportamiento común. Cada una comienza construyendo un objeto temporal de tipo std::basic_istream::sentry con el segundo argumento (noskipws) establecido en false. Esto tiene varios efectos, que concluyen con el establecimiento de una bandera de estado; consulte la documentación de sentry para obtener más información.

Si el estado de sentry es bueno, la función intenta extraer los datos apropiados para el tipo del argumento.

Si se lanza una excepción durante la extracción, ios_base::badbit se activará en el estado de error de la transmisión (sin provocar que se lance una ios_base::failure) y la excepción original se volverá a lanzar si badbit está activado en la máscara de excepciones.

Parámetros de Plantilla

Esta clase soporta la lectura y escritura de objetos de tipo std::basic_string, usando las funciones heredadas de std::basic_iostream. Para controlar la secuencia asociada, se utiliza una instancia de std::basic_stringbuf, a la que esta página se refiere como sb.

NAME

std::ios_base::fmtflags, std::ios_base::seekdir, std::ios_base::openmode - Flags de formato de stream

SYNOPSIS

Detailed Description

Las clases de stream de C++ (basic_istream, basic_ostream, basic_iostream) y sus especializaciones (istream, ostream, iostream, stringstream, wstringstream, fstream, ifstream, ofstream) utilizan flags para controlar varios aspectos de la E/S. Los flags se definen dentro de la clase base std::ios_base como enumeraciones públicas.

Los flags de formato principales se definen en la enumeración fmtflags.

Los flags de modo de búsqueda se definen en la enumeración seekdir.

Los flags de modo de apertura se definen en la enumeración openmode.

Todas estas enumeraciones se pueden combinar utilizando el operador bitwise OR (|) para configurar varios flags simultáneamente. Los flags se pueden borrar utilizando el operador bitwise XOR (^) o bitwise AND con la negación de un flag.
