strfromd(3) Manual de funciones de biblioteca strfromd(3)

NOMBRE

strfromd, strfromf, strfroml - convertir un valor de punto flotante a una cadena

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
int strfromd(size_t n;
             char str[restrict n], size_t n,
             const char *restrict format, double fp);
int strfromf(size_t n;
             char str[restrict n], size_t n,
             const char *restrict format, float fp);
int strfroml(size_t n;
             char str[restrict n], size_t n,
             const char *restrict format, long double fp);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

strfromd(), strfromf(), strfroml():

    __STDC_WANT_IEC_60559_BFP_EXT__

DESCRIPCIÓN

Estas funciones convierten un valor de punto flotante, fp, en una cadena de caracteres, str, con una cadena de format configurable. Se almacenan como máximo n caracteres en str.

El byte nulo terminador ('\0') se escribe si y sólo si n es suficientemente grande, de lo contrario, la cadena escrita se trunca en n caracteres.

Las funciones strfromd(), strfromf() y strfroml() son equivalentes a


snprintf(str, n, format, fp);

excepto por la cadena de format.

Formato de la cadena de formato

La cadena de format debe comenzar con el carácter '%'. Esto va seguido de una precisión opcional que comienza con el carácter punto (.), seguido de un entero decimal opcional. Si no se especifica ningún entero después del carácter punto, se utiliza una precisión de cero. Finalmente, la cadena de formato debe tener uno de los especificadores de conversión a, A, e, E, f, F, g o G.

El especificador de conversión se aplica según el tipo de punto flotante indicado por el sufijo de la función. Por lo tanto, a diferencia de snprintf(), la cadena de formato no tiene un carácter modificador de longitud. Ver snprintf(3) para una descripción detallada de estos especificadores de conversión.

La implementación se ajusta al estándar C99 en la conversión de valores NaN e infinito:

Si fp es un NaN, +NaN o -NaN, y f (o a, e, g) es el especificador de conversión, la conversión es a "nan", "nan" o "-nan", respectivamente. Si F (o A, E, G) es el especificador de conversión, la conversión es a "NAN" o "-NAN".

Igualmente, si fp es infinito, se convierte a [-]inf o [-]INF.

Una cadena de format mal formada resulta en un comportamiento indefinido.

VALOR DE RETORNO

Las funciones strfromd(), strfromf() y strfroml() devuelven el número de caracteres que se habrían escrito en str si n hubiera tenido suficiente espacio, sin contar el byte nulo terminador. Por lo tanto, un valor de retorno de n o mayor significa que la salida se truncó.

NOTAS

Estas funciones tienen en cuenta la categoría LC_NUMERIC de la localidad actual.

EJEMPLOS

Para convertir el valor 12.1 como tipo float a una cadena usando notación decimal, resultando en "12.100000":


#define __STDC_WANT_IEC_60559_BFP_EXT__
#include <stdlib.h>
int ssize = 10;
char s[ssize];
strfromf(s, ssize, "%f", 12.1);

Para convertir el valor 12.3456 como tipo float a una cadena usando notación decimal con dos dígitos de precisión, resultando en "12.35":


#define __STDC_WANT_IEC_60559_BFP_EXT__
#include <stdlib.h>
int ssize = 10;
char s[ssize];
strfromf(s, ssize, "%.2f", 12.3456);

Para convertir el valor 12.345e19 como tipo double a una cadena usando notación científica con cero dígitos de precisión, resultando en "1E+20":


#define __STDC_WANT_IEC_60559_BFP_EXT__
#include <stdlib.h>
int ssize = 10;
char s[ssize];
strfromd(s, ssize, "%.E", 12.345e19);
