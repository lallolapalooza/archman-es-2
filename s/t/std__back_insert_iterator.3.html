Descripción Detallada

template<typename _Container>

class std::back_insert_iterator< _Container >"Convierte la asignación en inserción.

Estos son iteradores de salida, construidos a partir de un contenedor de T. Asignar una T al iterador la añade al final del contenedor usando push_back.

Consejo: Usar la función back_inserter para crear estos iteradores puede ahorrar escritura.

Devuelve

Este iterador, para operaciones encadenadas.

Este tipo de iterador no tiene realmente una posición en el contenedor (puedes pensar que la posición está permanentemente al final, si quieres). Asignar un valor al iterador siempre añadirá el valor al final del contenedor.
