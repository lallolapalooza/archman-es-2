Documentación de Función/Subrutina

subrutina strsyl (character trana, character tranb, integer isgn, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldc, * ) c, integer ldc, real scale, integer info)

STRSYL

Propósito:

!>
!> STRSYL resuelve la ecuación matricial de Sylvester real:
!>
!>    op(A)*X + X*op(B) = scale*C o
!>    op(A)*X - X*op(B) = scale*C,
!>
!> donde op(A) = A o A**T, y A y B son ambas cuasi-
!> triangulares superiores. A es M por M y B es N por N; el lado derecho C y
!> la solución X son M por N; y scale es un factor de escala de salida, establecido
!> <= 1 para evitar desbordamiento en X.
!>
!> A y B deben estar en forma canónica de Schur (como la devuelta por SHSEQR), es decir,
!> triangular superior en bloques con bloques diagonales de 1x1 y 2x2;
!> cada bloque diagonal de 2x2 tiene sus elementos diagonales iguales y sus
!> elementos fuera de la diagonal de signo opuesto.
!>

Parámetros

TRANA 
!>          TRANA es CHARACTER*1
!>          Especifica la opción op(A):
!>          = 'N': op(A) = A    (Sin transposición)
!>          = 'T': op(A) = A**T (Transpuesta)
!>          = 'C': op(A) = A**H (Transpuesta conjugada = Transpuesta)
!>

TRANB

!>          TRANB es CHARACTER*1
!>          Especifica la opción op(B):
!>          = 'N': op(B) = B    (Sin transposición)
!>          = 'T': op(B) = B**T (Transpuesta)
!>          = 'C': op(B) = B**H (Transpuesta conjugada = Transpuesta)
!>

ISGN

!>          ISGN es INTEGER
!>          Especifica el signo en la ecuación:
!>          = +1: resuelve op(A)*X + X*op(B) = scale*C
!>          = -1: resuelve op(A)*X - X*op(B) = scale*C
!>

M

!>          M es INTEGER
!>          El orden de la matriz A, y el número de filas en las
!>          matrices X y C. M >= 0.
!>

N

!>          N es INTEGER
!>          El orden de la matriz B, y el número de columnas en las
!>          matrices X y C. N >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,M)
!>          La matriz cuasi-triangular superior A, en forma canónica de Schur.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array REAL, dimensión (LDB,N)
!>          La matriz cuasi-triangular superior B, en forma canónica de Schur.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

C

!>          C es un array REAL, dimensión (LDC,N)
!>          En la entrada, la matriz C del lado derecho de M por N.
!>          En la salida, C se sobrescribe con la matriz solución X.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M)
!>

SCALE

!>          SCALE es REAL
!>          El factor de escala, scale, establecido <= 1 para evitar desbordamiento en X.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          = 1: A y B tienen valores propios comunes o muy cercanos; se utilizaron
!>               valores perturbados para resolver la ecuación (pero las matrices
!>               A y B no se modifican).
!>
