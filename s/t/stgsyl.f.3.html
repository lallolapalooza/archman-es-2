STGSYL

Documentación de Función/Subrutina

subroutine stgsyl (character trans, integer ijob, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldc, * ) c, integer ldc, real, dimension( ldd, * ) d, integer ldd, real, dimension( lde, * ) e, integer lde, real, dimension( ldf, * ) f, integer ldf, real scale, real dif, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

STGSYL

Propósito:

!>
!> STGSYL resuelve la ecuación de Sylvester generalizada:
!>
!>             A * R - L * B = scale * C                 (1)
!>             D * R - L * E = scale * F
!>
!> donde R y L son matrices desconocidas de m x n, (A, D), (B, E) y
!> (C, F) son pares de matrices dadas de tamaño m x m, n x n y m x n,
!> respectivamente, con entradas reales. (A, D) y (B, E) deben estar en
!> forma canónica generalizada (real) de Schur, es decir, A, B son cuasi
!> triangulares superiores y D, E son triangulares superiores.
!>
!> La solución (R, L) sobrescribe (C, F). 0 <= SCALE <= 1 es un factor
!> de escala de salida elegido para evitar el desbordamiento.
!>
!> En notación matricial (1) es equivalente a resolver Zx = scale b, donde
!> Z se define como
!>
!>            Z = [ kron(In, A)  -kron(B**T, Im) ]         (2)
!>                [ kron(In, D)  -kron(E**T, Im) ].
!>
!> Aquí Ik es la matriz identidad de tamaño k y X**T es la transpuesta de
!> X. kron(X, Y) es el producto de Kronecker entre las matrices X e Y.
!>
!> Si TRANS = 'T', STGSYL resuelve el sistema transpuesto Z**T*y = scale*b,
!> que es equivalente a resolver para R y L en
!>
!>             A**T * R + D**T * L = scale * C           (3)
!>             R * B**T + L * E**T = scale * -F
!>
!> Este caso (TRANS = 'T') se utiliza para calcular una estimación basada
!> en la norma uno de Dif[(A,D), (B,E)], la separación entre los pares de
!> matrices (A,D) y (B,E), usando SLACON.
!>
!> Si IJOB >= 1, STGSYL calcula una estimación basada en la norma de
!> Frobenius de Dif[(A,D),(B,E)]. Es decir, la recíproca de un límite
!> inferior de la recíproca de la menor valor singular de Z. Ver [1-2] para
!> más información.
!>
!> Este es un algoritmo de BLAS de nivel 3.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': resuelve la ecuación de Sylvester generalizada (1).
!>          = 'T': resuelve el sistema 'transpuesto' (3).
!>

IJOB

!>          IJOB es INTEGER
!>          Especifica qué tipo de funcionalidad se va a realizar.
!>          = 0: solo resuelve (1).
!>          = 1: La funcionalidad de 0 y 3.
!>          = 2: La funcionalidad de 0 y 4.
!>          = 3: Solo se estima Dif[(A,D), (B,E)].
!>               (se utiliza la estrategia de mirada anticipada IJOB = 1).
!>          = 4: Solo se estima Dif[(A,D), (B,E)].
!>               (se utiliza SGECON en subsistemas).
!>          No se referencia si TRANS = 'T'.
!>

M

!>          M es INTEGER
!>          El orden de las matrices A y D, y la dimensión de filas de
!>          las matrices C, F, R y L.
!>

N

!>          N es INTEGER
!>          El orden de las matrices B y E, y la dimensión de columnas
!>          de las matrices C, F, R y L.
!>

A

!>          A es un array REAL, dimensión (LDA, M)
!>          La matriz cuasi triangular superior A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1, M).
!>

B

!>          B es un array REAL, dimensión (LDB, N)
!>          La matriz cuasi triangular superior B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1, N).
!>

C

!>          C es un array REAL, dimensión (LDC, N)
!>          En la entrada, C contiene el lado derecho de la primera matriz
!>          de la ecuación en (1) o (3).
!>          En la salida, si IJOB = 0, 1 o 2, C se ha sobrescrito con
!>          la solución R. Si IJOB = 3 o 4 y TRANS = 'N', C contiene R,
!>          la solución obtenida durante el cálculo de la estimación
!>          de Dif.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1, M).
!>

D

!>          D es un array REAL, dimensión (LDD, M)
!>          La matriz triangular superior D.
!>

LDD

!>          LDD es INTEGER
!>          La dimensión principal del array D. LDD >= max(1, M).
!>

E

!>          E es un array REAL, dimensión (LDE, N)
!>          La matriz triangular superior E.
!>

LDE

!>          LDE es INTEGER
!>          La dimensión principal del array E. LDE >= max(1, N).
!>

F

!>          F es un array REAL, dimensión (LDF, N)
!>          En la entrada, F contiene el lado derecho de la segunda matriz
!>          de la ecuación en (1) o (3).
!>          En la salida, si IJOB = 0, 1 o 2, F se ha sobrescrito con
!>          la solución L. Si IJOB = 3 o 4 y TRANS = 'N', F contiene L,
!>          la solución obtenida durante el cálculo de la estimación
!>          de Dif.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal del array F. LDF >= max(1, M).
!>

DIF

!>          DIF es REAL
!>          En la salida, DIF es la recíproca de un límite inferior de
!>          la recíproca de la función Dif, es decir, DIF es un límite
!>          superior de Dif[(A,D), (B,E)] = sigma_min(Z), donde Z como en (2).
!>          Si IJOB = 0 o TRANS = 'T', DIF no se modifica.
!>

SCALE

!>          SCALE es REAL
!>          En la salida, SCALE es el factor de escala en (1) o (3).
!>          Si 0 < SCALE < 1, C y F contienen las soluciones R y L, resp.,
!>          de un sistema ligeramente perturbado pero las matrices de entrada
!>          A, B, D y E no han sido modificadas. Si SCALE = 0, C y F
!>          contienen las soluciones R y L, respectivamente, del sistema
!>          homogéneo con C = F = 0. Normalmente, SCALE = 1.
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK > = 1.
!>          Si IJOB = 1 o 2 y TRANS = 'N', LWORK >= max(1,2*M*N).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA
!>          no emite ningún mensaje de error relacionado con LWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (M+N+6)
!>

INFO

!>          INFO es INTEGER
!>            =0: salida exitosa
!>            <0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>            >0: (A, D) y (B, E) tienen valores propios comunes o cercanos.
!>
