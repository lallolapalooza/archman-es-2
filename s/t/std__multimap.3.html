NOMBRE

std::multimap< _Key, _Tp, _Compare, _Alloc > - Un contenedor estándar compuesto por pares (clave, valor), que pueden ser recuperados basándose en una clave, en tiempo logarítmico.

Descripción Detallada

template<typename _Key, typename _Tp, typename _Compare = std::less<_Key>, typename _Alloc = std::allocator<std::pair<const _Key, _Tp> >>

class std::multimap< _Key, _Tp, _Compare, _Alloc >"Un contenedor estándar formado por pares (clave,valor), que pueden ser recuperados basándose en una clave, en tiempo logarítmico.

Desde

C++98

Parámetros de Plantilla

_Key Tipo de objetos clave.
_Tp Tipo de objetos mapeados.
_Compare Tipo de objeto de función de comparación, por defecto es less<_Key>.
_Alloc Tipo de asignador, por defecto es allocator<pair<const _Key, _Tp>.

Cumple los requisitos de un contenedor, un contenedor reversible y un contenedor asociativo (usando claves equivalentes). Para un multimap<Key,T> el key_type es Key, el mapped_type es T, y el value_type es std::pair<const Key,T>.

Los multimaps soportan iteradores bidireccionales.

Los datos del árbol privado se declaran exactamente igual para map y multimap; la distinción se hace completamente en cómo se llaman las funciones del árbol (*_unique versus *_equal, igual que en el estándar).

Esta función construye e inserta un par (clave, valor) en el multimapa. A diferencia de un std::map, el multimapa no se basa en claves únicas y, por lo tanto, se pueden insertar varios pares con la misma clave.

Esta función inserta un par (clave, valor) en el multimapa. A diferencia de un std::map, el multimapa no se basa en claves únicas y, por lo tanto, se pueden insertar varios pares con la misma clave. Detailed Description

The std::multimap is an associative container that stores elements formed by a combination of a key and a mapped value, following a specific order, and allowing duplicate keys.

The multimap is implemented as a red-black tree, which guarantees logarithmic time complexity for insertion, deletion, and search operations.

Constructor & Destructor Documentation

The constructors of std::multimap allow for flexible initialization of the container. You can create an empty multimap, initialize it with elements from a range of iterators, copy it from another multimap, or initialize it with a specific allocator and comparison object.

The default destructor, ~multimap(), is responsible for freeing any resources allocated by the multimap object.

Member Function Documentation

The member functions of std::multimap provide a wide range of operations for managing the container. These include:

  • Deletion functions: erase().
  • Access functions: find(), count(), lower_bound(), upper_bound(), equal_range().
  • Capacity functions: size(), empty().
  • Iterator functions: begin(), end(), rbegin(), rend().
  • Allocator functions: get_allocator().
