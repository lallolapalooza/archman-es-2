subroutine stgsy2 (character trans, integer ijob, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldc, * ) c, integer ldc, real, dimension( ldd, * ) d, integer ldd, real, dimension( lde, * ) e, integer lde, real, dimension( ldf, * ) f, integer ldf, real scale, real rdsum, real rdscal, integer, dimension( * ) iwork, integer pq, integer info)

STGSY2 resuelve la ecuación de Sylvester generalizada (algoritmo sin bloques).

Propósito:

!>
!> STGSY2 resuelve la ecuación de Sylvester generalizada:
!>
!>             A * R - L * B = scale * C                (1)
!>             D * R - L * E = scale * F,
!>
!> utilizando BLAS de Nivel 1 y 2. Donde R y L son matrices M-por-N desconocidas,
!> (A, D), (B, E) y (C, F) son pares de matrices dadas de tamaño M-por-M,
!> N-por-N y M-por-N, respectivamente, con entradas reales. (A, D) y (B, E)
!> deben estar en forma canónica de Schur generalizada, es decir, A, B son
!> superior cuasi triangulares y D, E son superior triangulares. La solución (R, L)
!> sobrescribe (C, F). 0 <= SCALE <= 1 es un factor de escala de salida
!> elegido para evitar desbordamientos.
!>
!> En notación matricial, resolver la ecuación (1) corresponde a resolver
!> Z*x = scale*b, donde Z se define como
!>
!>        Z = [ kron(In, A)  -kron(B**T, Im) ]             (2)
!>            [ kron(In, D)  -kron(E**T, Im) ],
!>
!> Ik es la matriz identidad de tamaño k y X**T es la transpuesta de X.
!> kron(X, Y) es el producto de Kronecker entre las matrices X e Y.
!> En el proceso de resolución de (1), resolvemos un número de tales sistemas
!> donde Dim(In), Dim(In) = 1 o 2.
!>
!> Si TRANS = 'T', resuelve el sistema transpuesto Z**T*y = scale*b para y,
!> lo que es equivalente a resolver para R y L en
!>
!>             A**T * R  + D**T * L   = scale * C           (3)
!>             R  * B**T + L  * E**T  = scale * -F
!>
!> Este caso se utiliza para calcular una estimación de Dif[(A, D), (B, E)] =
!> sigma_min(Z) utilizando comunicación inversa con SLACON.
!>
!> STGSY2 también (IJOB >= 1) contribuye al cálculo en STGSYL
!> de un límite superior para la separación entre dos pares de matrices. Entonces
!> las entradas (A, D), (B, E) son sub-polinomios del par de matrices en
!> STGSYL. Ver STGSYL para detalles.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': resuelve la ecuación de Sylvester generalizada (1).
!>          = 'T': resuelve el sistema 'transpuesto' (3).
!>

IJOB

!>          IJOB es INTEGER
!>          Especifica qué tipo de funcionalidad se va a realizar.
!>          = 0: resuelve solo (1).
!>          = 1: Se calcula una contribución de este subsistema a una estimación
!>               basada en la norma de Frobenius de la separación entre dos pares
!>               de matrices. (se utiliza la estrategia de mirada anticipada).
!>          = 2: Se calcula una contribución de este subsistema a una estimación
!>               basada en la norma de Frobenius de la separación entre dos pares
!>               de matrices. (se utiliza SGECON en subsistemas).
!>          No se hace referencia si TRANS = 'T'.
!>

M

!>          M es INTEGER
!>          En la entrada, M especifica el orden de A y D, y la dimensión
!>          fila de C, F, R y L.
!>

N

!>          N es INTEGER
!>          En la entrada, N especifica el orden de B y E, y la dimensión
!>          columna de C, F, R y L.
!>

A

!>          A es un array REAL, dimensión (LDA, M)
!>          En la entrada, A contiene una matriz superior cuasi triangular.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A. LDA >= max(1, M).
!>

B

!>          B es un array REAL, dimensión (LDB, N)
!>          En la entrada, B contiene una matriz superior cuasi triangular.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B. LDB >= max(1, N).
!>

C

!>          C es un array REAL, dimensión (LDC, N)
!>          En la entrada, C contiene el lado derecho de la primera matriz
!>          ecuación en (1).
!>          En la salida, si IJOB = 0, C se ha sobrescrito con la
!>          solución R.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal de la matriz C. LDC >= max(1, M).
!>

D

!>          D es un array REAL, dimensión (LDD, M)
!>          En la entrada, D contiene una matriz superior triangular.
!>

LDD

!>          LDD es INTEGER
!>          La dimensión principal de la matriz D. LDD >= max(1, M).
!>

E

!>          E es un array REAL, dimensión (LDE, N)
!>          En la entrada, E contiene una matriz superior triangular.
!>

LDE

!>          LDE es INTEGER
!>          La dimensión principal de la matriz E. LDE >= max(1, N).
!>

F

!>          F es un array REAL, dimensión (LDF, N)
!>          En la entrada, F contiene el lado derecho de la segunda matriz
!>          ecuación en (1).
!>          En la salida, si IJOB = 0, F se ha sobrescrito con la
!>          solución L.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal de la matriz F. LDF >= max(1, M).
!>

SCALE

!>          SCALE es REAL
!>          En la salida, 0 <= SCALE <= 1. Si 0 < SCALE < 1, las soluciones
!>          R y L (C y F en la entrada) contendrán las soluciones de un
!>          sistema ligeramente perturbado pero las matrices de entrada A, B, D y
!>          E no han sido modificadas. Si SCALE = 0, R y L contendrán las
!>          soluciones del sistema homogéneo con C = F = 0. Normalmente,
!>          SCALE = 1.
!>

RDSUM

!>          RDSUM es REAL
!>          En la entrada, la suma de cuadrados de las contribuciones calculadas a
!>          la estimación de Dif-calculada por STGSYL, donde el
!>          factor de escala RDSCAL (ver abajo) se ha extraído.
!>          En la salida, la suma correspondiente de cuadrados actualizada con las
!>          contribuciones del subsistema actual.
!>          Si TRANS = 'T', RDSUM no se modifica.
!>          NOTA: RDSUM solo tiene sentido cuando STGSY2 es llamado por STGSYL.
!>

RDSCAL

!>          RDSCAL es REAL
!>          En la entrada, factor de escala utilizado para prevenir el desbordamiento en RDSUM.
!>          En la salida, RDSCAL se actualiza con respecto a las contribuciones
!>          actuales en RDSUM.
!>          Si TRANS = 'T', RDSCAL no se modifica.
!>          NOTA: RDSCAL solo tiene sentido cuando STGSY2 es llamado por
!>                STGSYL.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (M+N+2)
!>

PQ

!>          PQ es INTEGER
!>          En la salida, el número de subsistemas (de tamaño 2x2, 4x4 y
!>          8x8) resueltos por esta rutina.
!>

INFO

!>          INFO es INTEGER
!>          En la salida, si INFO se establece en
!>            =0: Salida exitosa
!>            <0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>            >0: Los pares de matrices (A, D) y (B, E) tienen valores propios comunes o muy
!>                cercanos.
!>

NAME

stgsy2 - Solves the continuous-time generalized Sylvester equation

Function/Subroutine Documentation 

SUBROUTINE STGSY2( TRANS, EFACT, FFACT, ITRANS, JTRANS, A, LDA, B, LDB, C, LDC, D, LDD, E, LDE, F, LDF, X, LDX, SCALE, INFO )

STGSY2 solves the generalized Sylvester equation: A*X*E + B*X*F = C or A*X*E - B*X*F = C

where X is the unknown matrix, and A, B, C, D, E, F are pre-defined matrices. It is assumed that A and B are in generalized real Schur form. The matrices E and F are in upper triangular form.

Arguments

TRANS
CHARACTER*1. On entry, TRANS specifies the form of the generalized Sylvester equation to be solved:

If TRANS = 'N', solve A*X*E + B*X*F = C.

If TRANS = 'T', solve A**T*X*E**T + B**T*X*F**T = C.

If TRANS = 'C', solve A**C*X*E**C + B**C*X*F**C = C.

TRANS can also be 'L' for the transpose/conjugate transpose case, the same as 'T'/'C'.

EFACT
CHARACTER*1. On entry, EFACT specifies whether or not to use the matrix E:

If EFACT = 'U', E is upper triangular.

If EFACT = 'N', E is not used (implicitly the identity matrix).

FFACT
CHARACTER*1. On entry, FFACT specifies whether or not to use the matrix F:

If FFACT = 'U', F is upper triangular.

If FFACT = 'N', F is not used (implicitly the identity matrix).

ITRANS
LOGICAL. On entry, ITRANS specifies whether or not to use the transpose/conjugate transpose of A:

If ITRANS = .TRUE., use A**T (or A**C if TRANS = 'C').

If ITRANS = .FALSE., use A.

JTRANS
LOGICAL. On entry, JTRANS specifies whether or not to use the transpose/conjugate transpose of B:

If JTRANS = .TRUE., use B**T (or B**C if TRANS = 'C').

If JTRANS = .FALSE., use B.

A
REAL array, dimension (LDA,*)

On entry, the upper Hessenberg matrix A.

On exit, if ITRANS = .FALSE., A is overwritten by information about its Schur form.

LDA
INTEGER. The leading dimension of the array A.
B
REAL array, dimension (LDB,*)

On entry, the upper Hessenberg matrix B.

On exit, if JTRANS = .FALSE., B is overwritten by information about its Schur form.

LDB
INTEGER. The leading dimension of the array B.
C
REAL array, dimension (LDC,LDC)

On entry, the right hand side matrix C.

On exit, C is overwritten by the solution matrix X.

LDC
INTEGER. The leading dimension of the array C.

LDC must be at least max(N, M).

D
REAL array, dimension (LDD,*)

On entry, the matrix D, which is used when TRANS = 'C'.

On exit, D is overwritten.

LDD
INTEGER. The leading dimension of the array D.
E
REAL array, dimension (LDE,*)

On entry, the upper triangular matrix E. Only the elements above or on the diagonal are used if EFACT = 'U'.

On exit, E is overwritten.

LDE
INTEGER. The leading dimension of the array E.
F
REAL array, dimension (LDF,*)

On entry, the upper triangular matrix F. Only the elements above or on the diagonal are used if FFACT = 'U'.

On exit, F is overwritten.

LDF
INTEGER. The leading dimension of the array F.
X
REAL array, dimension (LDX,*)

On entry, the matrix X, which is used when TRANS = 'C'.

On exit, X is overwritten.

LDX
INTEGER. The leading dimension of the array X.
SCALE
REAL.

On exit, SCALE is an acceptance criterion for the solution X.

SCALE is output only. It is computed as the maximum absolute value of the computed residual matrix.

INFO
INTEGER.

On exit, INFO is:

0 indicates successful exit.

<0 indicates that the i-th argument had an invalid value.

>0 indicates that the i-th diagonal element of the generalized Schur form of A or B is zero. Therefore, the generalized Sylvester equation is singular or ill-conditioned.
