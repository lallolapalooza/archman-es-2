template<typename _CharT, bool _Intl> string std::moneypunct< _CharT, _Intl >::grouping () const [inline]

Devuelve la especificación de agrupación. Esta función devuelve una cadena que representa las agrupaciones para la parte entera de una cantidad. Las agrupaciones indican dónde se deben insertar los separadores de miles.

Cada carácter en la cadena devuelta se interpreta como un entero en lugar de un carácter. Estos números representan la cantidad de dígitos en un grupo. El primer carácter de la cadena representa la cantidad de dígitos en el grupo menos significativo. Si un carácter es negativo, indica un número ilimitado de dígitos para el grupo. Si se requieren más caracteres de la cadena para agrupar un número, el último carácter se usa repetidamente.

Por ejemplo, si grouping() devuelve \003\002 y se aplica al número 123456789, esto corresponde a 12,34,56,789. Tenga en cuenta que si la cadena fuera 32, esto pondría más de 50 dígitos en el grupo menos significativo si el conjunto de caracteres es ASCII.

La cadena se devuelve llamando a moneypunct<char_type>::do_grouping().

Devuelve

Cadena que representa la especificación de agrupación.

Referencias a do_grouping().

template<typename _CharT, bool _Intl> pattern std::moneypunct< _CharT, _Intl >::neg_format () const [inline]

Devuelve el patrón para valores monetarios. Esta función devuelve un patrón que describe el formato de una cantidad monetaria de valor positivo o negativo. Lo hace devolviendo moneypunct<char_type>::do_pos_format() o moneypunct<char_type>::do_neg_format().

El patrón tiene 4 campos que describen el orden del símbolo, el signo, el valor y la ausencia o espacio. Debe haber uno de cada uno en el patrón. Las enumeraciones none y space no pueden aparecer en el primer campo y space no puede aparecer en el último campo.

Las partes de una cadena monetaria deben aparecer en el orden indicado por los campos del patrón. El campo symbol indica que el valor de curr_symbol() puede estar presente. El campo sign indica que el valor de positive_sign() o negative_sign() debe estar presente. El campo value indica que el valor absoluto de la cantidad monetaria está presente. none indica 0 o más caracteres de espacio en blanco, excepto al final, donde no permite espacios en blanco. space indica que deben estar presentes uno o más caracteres de espacio en blanco.

Por ejemplo, para la configuración regional de EE. UU. y el patrón pos_format() {symbol,sign,value,none}, curr_symbol() == '$' positive_sign() == '+', y el valor 10.01, y las opciones configuradas para forzar el símbolo, la cadena correspondiente es $+10.01.

Patrón para valores monetarios.

Detailed Description

The class template std::moneypunct provides locale-specific information about the formatting of monetary values.

It is a facet of class std::locale.

The template parameter _Intl determines if the information is locale-specific or international. If _Intl is true, the information is locale-specific. Otherwise, it is international.

Derived classes from std::moneypunct must implement the virtual functions.

template<typename _CharT, bool _Intl> string_type std::moneypunct< _CharT, _Intl >::do_negative_pattern () const

Return pattern for negative money values. This function returns a pattern describing the formatting of a negative valued money amount. It does so by returning returning moneypunct<char_type>::do_negative_pattern().

The pattern has 4 fields describing the ordering of symbol, sign, value, and none or space. There must be one of each in the pattern. The none and space enums may not appear in the first field and space may not appear in the final field.

The parts of a money string must appear in the order indicated by the fields of the pattern. The symbol field indicates that the value of curr_symbol() may be present. The sign field indicates that the value of positive_sign() or negative_sign() must be present. The value field indicates that the absolute value of the money amount is present. none indicates 0 or more whitespace characters, except at the end, where it permits no whitespace. space indicates that 1 or more whitespace characters must be present.

For example, for the US locale and negative_pattern() pattern {sign,symbol,value,none}, curr_symbol() == '$' negative_sign() == '-' and value 10.01, and options set to force the symbol, the corresponding string is -$10.01.

Returns

Pattern for negative money values.

template<typename _CharT, bool _Intl> string_type std::moneypunct< _CharT, _Intl >::grouping () const [inline]

Return grouping string. This function returns a string_type to use as a grouping separator. It does so by returning returning moneypunct<char_type>::do_grouping().

The return value is a sequence of integers specifying the number of digits in each group of 3 digits from the right to the left. A value of zero means that all subsequent groups have the same size. A value of -1 means that the grouping is not used.

For example, for the US locale the value is "\x03\x02", meaning that the first group has 3 digits and the second group has 2 digits. The string 123,456,789 would be formatted as 123,45,67,89.

template<typename _CharT, bool _Intl> string_type std::moneypunct< _CharT, _Intl >::negative_pattern () const [inline]

Return pattern for negative money values. This function returns a pattern describing the formatting of a negative valued money amount. It does so by returning returning moneypunct<char_type>::do_negative_pattern().

The pattern has 4 fields describing the ordering of symbol, sign, value, and none or space. There must be one of each in the pattern. The none and space enums may not appear in the first field and space may not appear in the final field.

The parts of a money string must appear in the order indicated by the fields of the pattern. The symbol field indicates that the value of curr_symbol() may be present. The sign field indicates that the value of positive_sign() or negative_sign() must be present. The value field indicates that the absolute value of the money amount is present. none indicates 0 or more whitespace characters, except at the end, where it permits no whitespace. space indicates that 1 or more whitespace characters must be present.

For example, for the US locale and negative_pattern() pattern {sign,symbol,value,none}, curr_symbol() == '$' negative_sign() == '-' and value 10.01, and options set to force the symbol, the corresponding string is -$10.01.
