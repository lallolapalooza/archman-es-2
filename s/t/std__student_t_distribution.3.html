Detailed Description

The student_t_distribution class template produces random integers according to the Student t-distribution.

The Student t-distribution is a probability distribution that arises when estimating the mean of a normally distributed population in situations where the sample size is small and the population standard deviation is unknown. It is a generalization of the normal distribution, with heavier tails, meaning that extreme values are more likely to occur.

The class template takes a template parameter `_RealType`, which specifies the floating-point type used for the distribution's parameters and results. The default is `double`.

The distribution has two parameters:

mean (`__m`)
The mean of the distribution. Defaults to 0.0.
standard deviation (`__s`)
The standard deviation of the distribution. Defaults to 1.0.

Constructs a Student t-distribution from a range of values specified by `__first` and `__last`. This constructor is useful for initializing the distribution with empirical data.
