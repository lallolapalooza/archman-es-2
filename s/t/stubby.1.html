NOMBRE

stubby - un resolvedor stub local de privacidad DNS

SINOPSIS

stubby [-C archivo] [-ghilV] [-v nivel_de_registro]

DESCRIPCIÓN

stubby actúa como un resolvedor stub local de privacidad DNS, utilizando DNS-over-TLS. Stubby cifra las consultas DNS enviadas desde la máquina local a un resolvedor de privacidad DNS, aumentando la privacidad del usuario final.

stubby se encuentra en las primeras etapas de desarrollo pero es adecuado para usuarios técnicos/avanzados.

stubby proporciona privacidad DNS ejecutándose como un demonio que escucha en la dirección de loopback las consultas DNS y reenvía esas consultas a través de TLS. La configuración predeterminada proporciona Privacidad Estricta y utiliza un subconjunto de servidores de privacidad DNS disponibles. Consulte https://dnsprivacy.org/wiki/display/DP/DNS+Privacy+Test+Servers

OPCIONES

-C archivo
Lee la configuración del archivo archivo. Si esta opción no se proporciona, stubby busca un archivo de configuración en ~/.stubby.yml. Si este no está presente, stubby recurre al archivo de configuración global /etc/stubby/stubby.yml.
-g
Ejecuta stubby como un demonio.
-h
Imprime un mensaje de uso y sale.
-i
Lee la configuración, valida su contenido, lo imprime de forma legible en la salida estándar y sale.
-l
Habilita todos los registros. Equivalente a -v 7.
-v nivel_de_registro
Habilita el registro. Todos los mensajes de registro en o por debajo del nivel_de_registro se imprimen en la salida de error estándar:
0: EMERG
El sistema es inutilizable
1: ALERT
Se debe tomar medidas inmediatamente
2: CRIT
Condiciones críticas
3: ERROR
Condiciones de error
4: WARN
Condiciones de advertencia
5: NOTICE
Condiciones normales, pero significativas
6: INFO
Mensajes informativos
7: DEBUG
Mensajes de nivel de depuración
-V
Imprime la versión de stubby y sale.

CONFIGURACIÓN

El archivo de configuración está en YAML. Un ejemplo de configuración es:

resolution_type: GETDNS_RESOLUTION_STUB
dns_transport_list:
  - GETDNS_TRANSPORT_TLS
tls_authentication: GETDNS_AUTHENTICATION_REQUIRED
tls_query_padding_blocksize: 256
edns_client_subnet_private : 1
idle_timeout: 10000
listen_addresses:
  - 127.0.0.1
  -  0::1
round_robin_upstreams: 1
upstream_recursive_servers:
  - address_data: 145.100.185.15
    tls_auth_name: "dnsovertls.sinodun.com"
    tls_pubkey_pinset:
      - digest: "sha256"
        value: 62lKu9HsDVbyiPenApnc4sfmSYTHOVfFgL3pyB+cBL4=
  - address_data: 145.100.185.16
    tls_auth_name: "dnsovertls1.sinodun.com"
    tls_pubkey_pinset:
      - digest: "sha256"
        value: cE2ecALeE5B+urJhDrJlVFmf38cJLAvqekONvjvpqUA=
  - address_data: 185.49.141.37
    tls_auth_name: "getdnsapi.net"
    tls_pubkey_pinset:
      - digest: "sha256"
        value: foxZRnIh9gZpWnl+zEiKa0EJ2rdCGroMWm02gaxSc9Q=
  - address_data: 2001:610:1:40ba:145:100:185:15
    tls_auth_name: "dnsovertls.sinodun.com"
    tls_pubkey_pinset:

        value: 62lKu9HsDVbyiPenApnc4sfmSYTHOVfFgL3pyB+cBL4=
  - address_data: 2001:610:1:40ba:145:100:185:16

        value: cE2ecALeE5B+urJhDrJlVFmf38cJLAvqekONvjvpqUA=
  - address_data: 2a04:b900:0:100::38

Los elementos de configuración son los siguientes. Algunos toman valores constantes de la biblioteca getdns subyacente a stubby y una explicación adicional de sus valores puede encontrarse en la documentación de getdns o en http://www.getdnsapi.net

resolution_type resolución.
Esto debe establecerse en GETDNS_RESOLUTION_STUB por razones históricas. stubby saldrá con un error si se utiliza cualquier otra configuración.
dns_transport_list lista
Establece la lista de tipos de transporte a utilizar. Para Privacidad DNS, esto debe establecerse en GETDNS_TRANSPORT_TLS. Los transportes en texto plano son GETDNS_TRANSPORT_TCP y GETDNS_TRANSPORT_UDP
tls_authentication tipo
Establece el tipo de autenticación requerida. Para Privacidad Estricta, esto debe establecerse en GETDNS_AUTHENTICATION_REQUIRED. Para modo Oportunista, elimine esta configuración o establézcala en GETDNS_AUTHENTICATION_NONE. En modo Oportunista, no se requiere la autenticación del servidor de nombres y se permite la reversión a transportes en texto plano si están en dns_transport_list
tls_query_padding_blocksize tamaño_de_bloque
Utiliza la opción de relleno EDNS0 para rellenar las consultas DNS y ocultar su tamaño.
edns_client_subnet_private 0 o 1
Si es 1, utiliza la privacidad EDNS0 Client Subnet para que la subred del cliente no se envíe a los servidores autorizados.
idle_timeout tiempo_de_espera
Utiliza un tiempo de espera de inactividad EDNS0 Keepalive de tiempo_de_espera milisegundos, a menos que sea anulado por el servidor. Esto mantiene abiertas las conexiones TLS inactivas para evitar la sobrecarga de abrir una nueva conexión para cada consulta.
round_robin_upstreams 0 o 1
Si es 1, alterna las consultas entre todos los servidores upstream configurados. Sin esta opción, stubby utilizará cada servidor upstream secuencialmente hasta que deje de estar disponible y luego pasará al siguiente.
upstream_recursive_servers lista_de_servidores
Especifica los servidores upstream que stubby debe utilizar. Cada elemento de la lista contiene los siguientes elementos:
address_data dirección
Dirección IPv4 o IPv6 del servidor.
tls_auth_name nombre
Este es el nombre de dominio de autenticación que se verificará contra el certificado presentado.
tls_pubkey_pinset conjunto_de_pines
El conjunto de pines SPKI sha256 para el servidor. Esto también se verifica contra el certificado presentado. Contiene dos elementos:
digest tipo
El tipo de digest de clave.
value valor_clave
El valor de la clave.
