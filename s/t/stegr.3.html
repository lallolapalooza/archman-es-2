CSTEGR

Propósito:

!>
!> CSTEGR calcula autovalores seleccionados y, opcionalmente, autovectores
!> de una matriz tri-diagonal simétrica real T. Cualquier matriz no reducida de este tipo tiene
!> un conjunto bien definido de autovalores reales, que son diferentes por pares, los autovectores
!> reales correspondientes son ortogonales por pares.
!>
!> El espectro puede ser calculado completamente o parcialmente especificando
!> ya sea un intervalo (VL,VU] o un rango de índices IL:IU para los autovalores deseados.
!>
!> CSTEGR es una envoltura de compatibilidad sobre la rutina mejorada CSTEMR.
!> Ver SSTEMR para más detalles.
!>
!> Un cambio importante es que el parámetro ABSTOL ya no proporciona ningún
!> beneficio y, por lo tanto, ya no se utiliza.
!>
!> Nota: CSTEGR y CSTEMR solo funcionan en máquinas que siguen
!> el estándar de punto flotante IEEE-754 en su manejo de infinitos y
!> NaNs. La ejecución normal puede crear estos valores excepcionales y, por lo tanto,
!> puede abortar debido a una excepción de punto flotante en entornos que
!> no se ajustan al estándar IEEE-754.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los autovalores;
!>          = 'V':  Calcula autovalores y autovectores.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los autovalores.
!>          = 'V': se encontrarán todos los autovalores en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los autovalores del IL-ésimo al IU-ésimo.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es array REAL, dimensión (N)
!>          En la entrada, los N elementos diagonales de la matriz tri-diagonal
!>          T. En la salida, D se sobrescribe.
!>

E

!>          E es array REAL, dimensión (N)
!>          En la entrada, los (N-1) elementos subdiagonales de la matriz tri-diagonal
!>          T en los elementos 1 a N-1 de E. E(N) no necesita ser establecido en
!>          la entrada, pero se utiliza internamente como espacio de trabajo.
!>          En la salida, E se sobrescribe.
!>

VL

!>          VL es REAL
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los autovalores. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los autovalores. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          No utilizado. Era la tolerancia de error absoluta para los
!>          autovalores/autovectores en versiones anteriores.
!>

M

!>          M es INTEGER
!>          El número total de autovalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array REAL, dimensión (N)
!>          Los primeros M elementos contienen los autovalores seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es array COMPLEX, dimensión (LDZ, max(1,M) )
!>          Si JOBZ = 'V', y si INFO = 0, entonces las primeras M columnas de Z
!>          contienen los autovectores ortonormales de la matriz T
!>          correspondientes a los autovalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el autovector asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se hace referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>          Suministrar N columnas es siempre seguro.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', entonces LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ es array INTEGER, dimensión ( 2*max(1,M) )
!>          El soporte de los autovectores en Z, es decir, los índices
!>          que indican los elementos distintos de cero en Z. El i-ésimo autovector calculado
!>          es distinto de cero solo en los elementos ISUPPZ( 2*i-1 ) hasta
!>          ISUPPZ( 2*i ). Esto es relevante en el caso en que la matriz
!>          se divide. ISUPPZ solo se accede cuando JOBZ es 'V' y N > 0.
!>

WORK

!>          WORK es array REAL, dimensión (LWORK)
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo
!>          (y mínimo).
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,18*N)
!>          si JOBZ = 'V', y LWORK >= max(1,12*N) si JOBZ = 'N'.
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (LIWORK)
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.  LIWORK >= max(1,10*N)
!>          si se desean los autovectores, y LIWORK >= max(1,8*N)
!>          si solo se van a calcular los autovalores.
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array IWORK,
!>          devuelve este valor como la primera entrada del array IWORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          En la salida, INFO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = 1X, error interno en SLARRE,

subroutine cstegr (character jobz, character range, integer n, complex, dimension( * ) d, complex, dimension( * ) e, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, complex, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, complex, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

CSTEGR

Purpose:

!>
!> CSTEGR computes selected eigenvalues and, optionally, eigenvectors
!> of a real symmetric tridiagonal matrix T. Any such unreduced matrix has
!> a well defined set of pairwise different real eigenvalues, the corresponding
!> real eigenvectors are pairwise orthogonal.
!>
!> The spectrum may be computed either completely or partially by specifying
!> either an interval (VL,VU] or a range of indices IL:IU for the desired
!> eigenvalues.
!>
!> CSTEGR is a compatibility wrapper around the improved CSTEMR routine.
!> See CSTEMR for further details.
!>
!> One important change is that the ABSTOL parameter no longer provides any
!> benefit and hence is no longer used.
!>
!> Note : CSTEGR and CSTEMR work only on machines which follow
!> IEEE-754 floating-point standard in their handling of infinities and
!> NaNs.  Normal execution may create these exceptional values and hence
!> may abort due to a floating point exception in environments which
!> do not conform to the IEEE-754 standard.
!>

Parameters

JOBZ 
!>          JOBZ is CHARACTER*1
!>          = 'N':  Compute eigenvalues only;
!>          = 'V':  Compute eigenvalues and eigenvectors.
!>

RANGE

!>          RANGE is CHARACTER*1
!>          = 'A': all eigenvalues will be found.
!>          = 'V': all eigenvalues in the half-open interval (VL,VU]
!>                 will be found.
!>          = 'I': the IL-th through IU-th eigenvalues will be found.
!>

N

!>          N is INTEGER
!>          The order of the matrix.  N >= 0.
!>

D

!>          D is COMPLEX array, dimension (N)
!>          On entry, the N diagonal elements of the tridiagonal matrix
!>          T. On exit, D is overwritten.
!>

E

!>          E is COMPLEX array, dimension (N)
!>          On entry, the (N-1) subdiagonal elements of the tridiagonal
!>          matrix T in elements 1 to N-1 of E. E(N) need not be set on
!>          input, but is used internally as workspace.
!>          On exit, E is overwritten.
!>

VL

!>          VL is REAL
!>
!>          If RANGE='V', the lower bound of the interval to
!>          be searched for eigenvalues. VL < VU.
!>          Not referenced if RANGE = 'A' or 'I'.
!>

VU

!>          VU is REAL
!>
!>          If RANGE='V', the upper bound of the interval to
!>          be searched for eigenvalues. VL < VU.
!>          Not referenced if RANGE = 'A' or 'I'.
!>

IL

!>          IL is INTEGER
!>
!>          If RANGE='I', the index of the
!>          smallest eigenvalue to be returned.
!>          1 <= IL <= IU <= N, if N > 0.
!>          Not referenced if RANGE = 'A' or 'V'.
!>

IU

!>          IU is INTEGER
!>
!>          If RANGE='I', the index of the
!>          largest eigenvalue to be returned.
!>          1 <= IL <= IU <= N, if N > 0.
!>          Not referenced if RANGE = 'A' or 'V'.
!>

ABSTOL

!>          ABSTOL is REAL
!>          Unused.  Was the absolute error tolerance for the
!>          eigenvalues/eigenvectors in previous versions.
!>

M

!>          M is INTEGER
!>          The total number of eigenvalues found.  0 <= M <= N.
!>          If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.
!>

W

!>          W is REAL array, dimension (N)
!>          The first M elements contain the selected eigenvalues in
!>          ascending order.
!>

Z

!>          Z is COMPLEX array, dimension (LDZ, max(1,M) )
!>          If JOBZ = 'V', and if INFO = 0, then the first M columns of Z
!>          contain the orthonormal eigenvectors of the matrix T
!>          corresponding to the selected eigenvalues, with the i-th
!>          column of Z holding the eigenvector associated with W(i).
!>          If JOBZ = 'N', then Z is not referenced.
!>          Note: the user must ensure that at least max(1,M) columns are
!>          supplied in the array Z; if RANGE = 'V', the exact value of M
!>          is not known in advance and an upper bound must be used.
!>          Supplying N columns is always safe.
!>

LDZ

!>          LDZ is INTEGER
!>          The leading dimension of the array Z.  LDZ >= 1, and if
!>          JOBZ = 'V', then LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
!>          The support of the eigenvectors in Z, i.e., the indices
!>          indicating the nonzero elements in Z. The i-th computed eigenvector
!>          is nonzero only in elements ISUPPZ( 2*i-1 ) through
!>          ISUPPZ( 2*i ). This is relevant in the case when the matrix
!>          is split. ISUPPZ is only accessed when JOBZ is 'V' and N > 0.
!>

WORK

!>          WORK is COMPLEX array, dimension (LWORK)
!>          On exit, if INFO = 0, WORK(1) returns the optimal
!>          (and minimal) LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,18*N)
!>          if JOBZ = 'V', and LWORK >= max(1,12*N) if JOBZ = 'N'.
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (LIWORK)
!>          On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.  LIWORK >= max(1,10*N)
!>          if the eigenvectors are desired, and LIWORK >= max(1,8*N)
!>          if only the eigenvalues are to be computed.
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal size of the IWORK array,
!>          returns this value as the first entry of the IWORK array, and
!>          no error message related to LIWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          On exit, INFO
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = 1X, internal error in CLARRE,
!>                if INFO = 2X, internal error in CLARRV.
!>                Here, the digit X = ABS( IINFO ) < 10, where IINFO is
!>                the nonzero error code returned by CLARRE or
!>                CLARRV, respectively.
!>

DESCRIPTION

SSTEGR computes selected eigenvalues and, optionally, eigenvectors of a real symmetric tridiagonal matrix T. Any such unreduced matrix has a well defined set of pairwise different real eigenvalues, the corresponding real eigenvectors are pairwise orthogonal.

The spectrum may be computed either completely or partially by specifying either an interval (VL,VU] or a range of indices IL:IU for the desired eigenvalues.

SSTEGR is a compatibility wrapper around the improved SSTEMR routine. See SSTEMR for further details.

One important change is that the ABSTOL parameter no longer provides any benefit and hence is no longer used.

Note : SSTEGR and SSTEMR work only on machines which follow IEEE-754 floating-point standard in their handling of infinities and NaNs. Normal execution may create these exceptional values and hence may abort due to a floating point exception in environments which do not conform to the IEEE-754 standard.
