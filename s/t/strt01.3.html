subrutina strt01 (carácter uplo, carácter diag, entero n, real, dimensión( lda, * ) a, entero lda, real, dimensión( ldainv, * ) ainv, entero ldainv, real rcond, real, dimensión( * ) work, real resid)

STRT01

Propósito:

!>
!> STRT01 calcula el residuo para una matriz triangular A multiplicada por su
!> inversa:
!>    RESID = norma( A*AINV - I ) / ( N * norma(A) * norma(AINV) * EPS ),
!> donde EPS es la epsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitriangular o no.
!>          = 'N':  No unitriangular
!>          = 'U':  Unitriangular
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>          La matriz triangular A.  Si UPLO = 'U', la parte triangular
!>          superior principal de n por n del array A contiene la matriz
!>          triangular superior, y la parte triangular estrictamente inferior
!>          de A no se referencia.  Si UPLO = 'L', la parte triangular
!>          inferior principal de n por n del array A contiene la matriz
!>          triangular inferior, y la parte triangular estrictamente superior
!>          de A no se referencia.  Si DIAG = 'U', los elementos diagonales
!>          de A tampoco se referencian y se asumen como 1.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AINV

!>          AINV es array REAL, dimensión (LDAINV,N)
!>          A la entrada, la inversa (triangular) de la matriz A, en el
!>          mismo formato de almacenamiento que A.
!>          A la salida, el contenido de AINV se destruye.
!>

LDAINV

!>          LDAINV es ENTERO
!>          La dimensión principal del array AINV.  LDAINV >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          El número de condición recíproco de A, calculado como
!>          1/(norma(A) * norma(AINV)).
!>

WORK

!>          WORK es array REAL, dimensión (N)
!>

RESID

!>          RESID es REAL
!>          norma(A*AINV - I) / ( N * norma(A) * norma(AINV) * EPS )
!>
