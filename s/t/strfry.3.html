strfry(3) Manual de Funciones de Biblioteca strfry(3)

NOMBRE

strfry - aleatoriza una cadena

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <string.h>
char *strfry(char *string);

DESCRIPCIÓN

La función strfry() aleatoriza el contenido de string intercambiando aleatoriamente caracteres en la cadena. El resultado es un anagrama de string.

VALOR DE RETORNO

La función strfry() devuelve un puntero a la cadena aleatorizada.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).
