NOMBRE

statgrab-make-mrtg-config - genera configuración de MRTG

SINOPSIS


statgrab-make-mrtg-config
[OPCIÓN]...

DESCRIPCIÓN

statgrab-make-mrtg-config genera la configuración de MRTG a partir de la salida de statgrab y la escribe en la salida estándar.

OPCIONES

Se admiten las siguientes opciones.

--no-header
No imprimir opciones globales de MRTG; útil si desea incluir la salida de este script en otro archivo de configuración de MRTG
--workdir RUTA
Usar RUTA para la opción WorkDir de MRTG
--statgrab RUTA
Especificar la ubicación del binario statgrab (por defecto "statgrab")
--help
Mostrar ayuda y salir
