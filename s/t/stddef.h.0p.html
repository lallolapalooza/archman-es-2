stddef.h(0P) Manual del programador POSIX stddef.h(0P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

stddef.h — definiciones de tipos estándar

SINOPSIS

#include <stddef.h>

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencionado. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

El encabezado <stddef.h> definirá las siguientes macros:

NULL
Constante de puntero nulo. La macro se expandirá a una expresión constante entera con el valor 0 convertido a tipo void *.
offsetof(tipo, designador-miembro)

Expresión constante entera de tipo size_t, cuyo valor es el desplazamiento en bytes del miembro de la estructura (designador-miembro), desde el principio de su estructura (tipo).

El encabezado <stddef.h> definirá los siguientes tipos:

ptrdiff_t
Tipo entero con signo del resultado de restar dos punteros.
wchar_t
Tipo entero cuyo rango de valores puede representar códigos distintos para todos los miembros del conjunto de caracteres extendidos más grande especificado entre las localizaciones soportadas; el carácter nulo tendrá el valor de código cero. Cada miembro del conjunto de caracteres básico tendrá un valor de código igual a su valor cuando se use como el único carácter en una constante de carácter entera si una implementación no define __STDC_MB_MIGHT_NEQ_WC__.
size_t
Tipo entero sin signo del resultado del operador sizeof.

La implementación soportará uno o más entornos de programación en los que los anchos de ptrdiff_t, size_t y wchar_t no sean mayores que el ancho del tipo long. Los nombres de estos entornos de programación se pueden obtener usando la función confstr() o la utilidad getconf.

Las siguientes secciones son informativas.

USO DE APLICACIONES

Ninguno.

RACIONAMIENTO

El estándar ISO C no requiere que la macro NULL incluya la conversión al tipo void * y especifica que la macro NULL depende de la implementación. POSIX.1‐2008 requiere la conversión y, por lo tanto, no necesita depender de la implementación.
