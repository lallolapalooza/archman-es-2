STREVC3

Propósito:

!>
!> STREVC3 calcula algunos o todos los vectores propios derechos y/o izquierdos de
!> una matriz T real cuasi-triangular.
!> Las matrices de este tipo son producidas por la factorización de Schur de
!> una matriz general real:  A = Q*T*Q**T, como la calculada por SHSEQR.
!>
!> Los vectores propios derechos x e izquierdos y de T correspondientes
!> a un valor propio w se definen por:
!>
!>    T*x = w*x,     (y**T)*T = w*(y**T)
!>
!> donde y**T denota la transpuesta del vector y.
!> Los valores propios no se introducen a esta rutina, sino que se leen directamente
!> de los bloques diagonales de T.
!>
!> Esta rutina devuelve las matrices X y/o Y de vectores propios derechos e izquierdos
!> de T, o los productos Q*X y/o Q*Y, donde Q es una
!> matriz de entrada. Si Q es el factor ortogonal que reduce una matriz
!> A a la forma de Schur T, entonces Q*X y Q*Y son las matrices de vectores propios
!> derechos e izquierdos de A.
!>
!> Esto utiliza una versión BLAS Nivel 3 de la retrotransformación.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R':  calcular solo vectores propios derechos;
!>          = 'L':  calcular solo vectores propios izquierdos;
!>          = 'B':  calcular ambos, derechos e izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A':  calcular todos los vectores propios derechos y/o izquierdos;
!>          = 'B':  calcular todos los vectores propios derechos y/o izquierdos,
!>                  retrotransformados por las matrices en VR y/o VL;
!>          = 'S':  calcular vectores propios derechos y/o izquierdos seleccionados,
!>                  como se indica en el array lógico SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los vectores propios a calcular.
!>          Si w(j) es un valor propio real, el vector propio real
!>          correspondiente se calcula si SELECT(j) es .TRUE..
!>          Si w(j) y w(j+1) son las partes real e imaginaria de un
!>          valor propio complejo, el vector propio complejo
!>          correspondiente se calcula si cualquiera de SELECT(j) o SELECT(j+1) es .TRUE., y
!>          a la salida SELECT(j) se establece a .TRUE. y SELECT(j+1) se establece a
!>          .FALSE..
!>          No se hace referencia si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array REAL, dimensión (LDT,N)
!>          La matriz T cuasi-triangular superior en forma canónica de Schur.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array REAL, dimensión (LDVL,MM)
!>          A la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de N x N (generalmente la matriz ortogonal Q
!>          de vectores de Schur devuelta por SHSEQR).
!>          A la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de vectores propios izquierdos de T;
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los vectores propios izquierdos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VL, en el mismo orden que sus
!>                           valores propios.
!>          Un vector propio complejo correspondiente a un valor propio
!>          complejo se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real, y la segunda la parte imaginaria.
!>          No se hace referencia si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.
!>          LDVL >= 1, y si SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un array REAL, dimensión (LDVR,MM)
!>          A la entrada, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Q de N x N (generalmente la matriz ortogonal Q
!>          de vectores de Schur devuelta por SHSEQR).
!>          A la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de vectores propios derechos de T;
!>          si HOWMNY = 'B', la matriz Q*X;
!>          si HOWMNY = 'S', los vectores propios derechos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VR, en el mismo orden que sus
!>                           valores propios.
!>          Un vector propio complejo correspondiente a un valor propio
!>          complejo se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real y la segunda la parte imaginaria.
!>          No se hace referencia si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.
!>          LDVR >= 1, y si SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizadas para almacenar los vectores propios.
!>          Si HOWMNY = 'A' o 'B', M se establece a N.
!>          Cada vector propio real seleccionado ocupa una columna y cada
!>          vector propio complejo seleccionado ocupa dos columnas.
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK))
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,3*N).
!>          Para un rendimiento óptimo, LWORK >= N + 2*N*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tuvo un valor ilegal
!>

NOMBRE¶

strevc3 - Calcula los vectores propios de una matriz de Hessenberg.

SINOPSIS¶

Documentación de Función/Subrutina¶

strevc3 calcula los vectores propios del sistema de ecuaciones matriciales de Hessenberg de forma triangular: 

   A * x = lambda * x

donde A es una matriz de Hessenberg dada, A = T.

El argumento de entrada COMPQ indica si se deben calcular vectores propios por la izquierda y/o por la derecha.

El argumento de entrada JOB indica si se deben calcular todos los vectores propios o solo algunos de ellos.

El argumento de entrada N es el orden de la matriz T.

El argumento de entrada T es la matriz de Hessenberg.

El argumento de entrada LDT es la longitud de la fila de T.

El argumento de entrada WORK es un array de trabajo.

El argumento de entrada M es el número de vectores propios calculados.

El argumento de entrada VL es la matriz de vectores propios izquierdos.

El argumento de entrada LDVL es la longitud de la fila de VL.

El argumento de entrada VR es la matriz de vectores propios derechos.

El argumento de entrada LDVR es la longitud de la fila de VR.

El argumento de salida INFO es el código de retorno.

INFO = 0: ejecución correcta.

INFO < 0: uno de los argumentos de entrada no es válido.

INFO > 0: el algoritmo de reducción a forma de Hessenberg no convergió.
