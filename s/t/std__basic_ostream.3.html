Inserciones
Todas las funciones operator<< (también conocidas como *funciones de salida formateada*) tienen un comportamiento común. Cada una comienza construyendo un objeto temporal de tipo std::basic_ostream::sentry. Esto puede tener varios efectos, concluyendo con el establecimiento de una bandera de estado; consulte la documentación de sentry para más detalles.

Si el estado de sentry es bueno, la función intenta generar los datos apropiados para el tipo del argumento.

Si se lanza una excepción durante la inserción, ios_base::badbit se activará en el estado de error del flujo sin causar el lanzamiento de una excepción ios_base::failure. Luego, la excepción original se volverá a lanzar.

Detailed Description

template<typename _CharT, typename _Traits>
class std::basic_ostream< _CharT, _Traits >

Template class basic_ostream.

Template Parameters

_CharT Type of character stream.
_Traits Traits for character type, defaults to char_traits<_CharT>.

This is the base class for all output streams. It provides text formatting of all builtin types, and communicates with any class derived from basic_streambuf to do the actual output.

The `sentry` object created at the beginning of each insertion and extraction operation attempts to initialize the stream state. This has several effects, concluding with the setting of a status flag; see the sentry documentation for more.

If the sentry status is good, the function tries to generate whatever data is appropriate for the type of the argument.

If an exception is thrown during insertion, `ios_base::badbit` will be turned on in the stream's error state. If `badbit` is on in the stream's exceptions mask, the exception will be rethrown without completing its actions.

Detailed Description

Formato de salida de flujo.

Los flujos de salida se utilizan para escribir datos en un destino (como la consola o un archivo). La clase std::basic_ostream proporciona la funcionalidad básica para la salida de flujos en C++. Los tipos más comunes son std::ostream (para salida de caracteres de un byte) y std::wostream (para salida de caracteres anchos).

Los flujos de salida se pueden formatear utilizando indicadores de formato y manipuladores. Los indicadores de formato son valores de bits que controlan cómo se representan los datos en la salida. Los manipuladores son funciones o objetos que modifican el estado de un flujo de salida.
