Documentación de Función/Subrutina

subrutina strexc (carácter compq, entero n, real, dimensión( ldt, * ) t, entero ldt, real, dimensión( ldq, * ) q, entero ldq, entero ifst, entero ilst, real, dimensión( * ) work, entero info)

STREXC

Propósito:

!>
!> STREXC reordena la factorización de Schur real de una matriz real
!> A = Q*T*Q**T, de modo que el bloque diagonal de T con índice de fila IFST se
!> mueva a la fila ILST.
!>
!> La forma de Schur real T se reordena mediante una transformación de
!> similaridad ortogonal Z**T*T*Z, y opcionalmente la matriz Q de
!> vectores de Schur se actualiza multiplicándola por Z.
!>
!> T debe estar en forma canónica de Schur (como la devuelta por SHSEQR), es decir,
!> triangular superior por bloques con bloques diagonales de 1x1 y 2x2; cada
!> bloque diagonal de 2x2 tiene sus elementos diagonales iguales y sus
!> elementos fuera de la diagonal de signo opuesto.
!>

Parámetros

COMPQ 
!>          COMPQ es CHARACTER*1
!>          = 'V':  actualiza la matriz Q de vectores de Schur;
!>          = 'N':  no actualiza Q.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>          Si N == 0, los argumentos ILST e IFST pueden tener cualquier valor.
!>

T

!>          T es un array REAL, dimensión (LDT,N)
!>          En la entrada, la matriz T quasi-triangular superior, en forma
!>          canónica de Schur.
!>          En la salida, la matriz quasi-triangular superior reordenada, de nuevo
!>          en forma canónica de Schur.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

Q

!>          Q es un array REAL, dimensión (LDQ,N)
!>          En la entrada, si COMPQ = 'V', la matriz Q de vectores de Schur.
!>          En la salida, Q ha sido multiplicada por la matriz de
!>          transformación ortogonal Z que reordena T.
!>          Si COMPQ = 'N', Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= 1, y si
!>          COMPQ = 'V', LDQ >= max(1,N).
!>

IFST

!>          IFST es INTEGER
!>

ILST

!>          ILST es INTEGER
!>
!>          Especifica la reordenación de los bloques diagonales de T.
!>          El bloque con índice de fila IFST se mueve a la fila ILST, mediante una
!>          secuencia de transposiciones entre bloques adyacentes.
!>          En la salida, si IFST apuntaba en la entrada a la segunda fila de un
!>          bloque de 2x2, se cambia para apuntar a la primera fila; ILST
!>          siempre apunta a la primera fila del bloque en su posición final
!>          (que puede diferir de su valor de entrada en +1 o -1).
!>          1 <= IFST <= N; 1 <= ILST <= N.
!>

WORK

!>          WORK es un array REAL, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          = 1:  dos bloques adyacentes estaban demasiado cerca para intercambiarlos (el problema
!>                es muy mal condicionado); T puede haber sido reordenada parcialmente,
!>                y ILST apunta a la primera fila de la posición actual del bloque que se está moviendo.
!>
