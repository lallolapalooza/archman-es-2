Descripción detallada

Clase que define un subconjunto multidimensional de un array.

La clase slice representa un subconjunto multidimensional de un array, especificado por tres conjuntos de parámetros: desplazamiento inicial, array de tamaños y array de pasos. El desplazamiento inicial es el índice del primer elemento del array que forma parte del subconjunto. Los arrays de tamaño y paso describen cada dimensión del slice. El tamaño es el número de elementos en esa dimensión, y el paso es la distancia en el array entre elementos sucesivos en esa dimensión. El tamaño y el paso de cada dimensión se toman a partir de un elemento del array descrito por la dimensión anterior. Los arrays de tamaño y paso deben tener el mismo tamaño.

Por ejemplo, si tienes offset==3, stride[0]==11, size[1]==3, stride[1]==3, entonces slice[0,0]==array[3], slice[0,1]==array[6], slice[0,2]==array[9], slice[1,0]==array[14], slice[1,1]==array[17], slice[1,2]==array[20].
