STRINGS(1) Herramientas de desarrollo GNU STRINGS(1)

NOMBRE

strings - imprime las secuencias de caracteres imprimibles en archivos

SINOPSIS

strings [-afovV] [-longitud-mínima]
[-n longitud-mínima] [--bytes=longitud-mínima]
[-t base] [--radix=base]
[-e codificación] [--encoding=codificación]
[-U método] [--unicode=método]
[-] [--all] [--print-file-name]
[-T nombre-bfd] [--target=nombre-bfd]
[-w] [--include-all-whitespace]
[-s] [--output-separator cadena-separador]
[--help] [--version] archivo...

DESCRIPCIÓN

Para cada archivo dado, GNU strings imprime las secuencias de caracteres imprimibles que tienen al menos 4 caracteres de longitud (o el número dado con las opciones siguientes) y están seguidas por un carácter no imprimible.

Dependiendo de cómo se configuró el programa strings, por defecto mostrará todas las secuencias imprimibles que pueda encontrar en cada archivo, o solo aquellas secuencias que se encuentren en secciones de datos inicializadas y cargables. Si el tipo de archivo es irreconocible, o si strings está leyendo desde stdin, siempre mostrará todas las secuencias imprimibles que pueda encontrar.

Por compatibilidad hacia atrás, cualquier archivo que aparezca después de una opción de línea de comandos de solo - también será escaneado completamente, independientemente de la presencia de cualquier opción -d.

strings es principalmente útil para determinar el contenido de archivos no textuales.

OPCIONES

-a
--all
-
Escanea el archivo completo, independientemente de las secciones que contenga o de si esas secciones están cargadas o inicializadas. Normalmente este es el comportamiento por defecto, pero strings puede ser configurado para que -d sea el comportamiento por defecto.

La opción - depende de la posición y fuerza a strings a realizar escaneos completos de cualquier archivo que se mencione después del - en la línea de comandos, incluso si se ha especificado la opción -d.

-d
--data
Solo imprime cadenas de las secciones de datos inicializadas y cargadas en el archivo. Esto puede reducir la cantidad de basura en la salida, pero también expone el programa strings a posibles fallos de seguridad que puedan existir en la biblioteca BFD utilizada para escanear y cargar secciones. Strings puede ser configurado para que esta opción sea el comportamiento por defecto. En tales casos, la opción -a puede ser utilizada para evitar el uso de la biblioteca BFD e imprimir en su lugar todas las cadenas encontradas en el archivo.
-f
--print-file-name
Imprime el nombre del archivo antes de cada cadena.
--help
Imprime un resumen del uso del programa en la salida estándar y sale.
-longitud-mínima
-n longitud-mínima
--bytes=longitud-mínima
Imprime secuencias de caracteres visibles que tengan al menos longitud-mínima caracteres de longitud. Si no se especifica, se utiliza una longitud mínima por defecto de 4. La distinción entre caracteres visibles y no visibles depende de la configuración de las opciones -e y -U. Las secuencias siempre se terminan en caracteres de control como nueva línea y retorno de carro, pero no en el carácter de tabulación.
-o
Igual que -t o. Algunas otras versiones de strings tienen -o que actúa como -t d en su lugar. Dado que no podemos ser compatibles de ambas maneras, simplemente elegimos una.
-t base
--radix=base
Imprime el desplazamiento dentro del archivo antes de cada cadena. El argumento de un solo carácter especifica la base del desplazamiento: o para octal, x para hexadecimal, o d para decimal.
-e codificación
--encoding=codificación
Selecciona la codificación de caracteres de las cadenas que se van a encontrar. Los valores posibles para codificación son: s = caracteres de un solo byte de 7 bits (por defecto), S = caracteres de un solo byte de 8 bits, b = 16 bits bigendian, l = 16 bits littleendian, B = 32 bits bigendian, L = 32 bits littleendian. Útil para encontrar cadenas de caracteres anchos. (l y b se aplican, por ejemplo, a las codificaciones Unicode UTF-16/UCS-2).
-U [d|i|l|e|x|h]
--unicode=[default|invalid|locale|escape|hex|highlight]
Controla la visualización de caracteres multibyte codificados en UTF-8 en las cadenas. Por defecto (--unicode=default) no se les da ningún tratamiento especial, y en su lugar se basa en la configuración de la opción --encoding. Los otros valores para esta opción habilitan automáticamente --encoding=S.

La opción --unicode=invalid los trata como caracteres no gráficos y, por lo tanto, no forman parte de una cadena válida. Todas las opciones restantes los tratan como caracteres válidos de cadena.

La opción --unicode=locale los muestra en la configuración regional actual, que puede o no admitir la codificación UTF-8. La opción --unicode=hex los muestra como secuencias de bytes hexadecimales encerradas entre caracteres <>. La opción --unicode=escape los muestra como secuencias de escape (\uxxxx) y la opción --unicode=highlight los muestra como secuencias de escape resaltadas en rojo (si es compatible con el dispositivo de salida). El coloreado está destinado a llamar la atención sobre la presencia de secuencias unicode donde podrían no esperarse.

-T nombre-bfd
--target=nombre-bfd
Especifica un formato de código objeto diferente del formato predeterminado de su sistema.
-v
-V
--version
Imprime el número de versión del programa en la salida estándar y sale.
-w
--include-all-whitespace
Por defecto, los caracteres de tabulación y espacio se incluyen en las cadenas que se muestran, pero otros caracteres de espacio en blanco, como las nuevas líneas y los retornos de carro, no. La opción -w cambia esto para que todos los caracteres de espacio en blanco se consideren parte de una cadena.
-s
--output-separator
Por defecto, las cadenas de salida están delimitadas por una nueva línea. Esta opción le permite proporcionar cualquier cadena que se utilizará como separador de registros de salida. Útil con --include-all-whitespace, donde las cadenas pueden contener nuevas líneas internamente.
@archivo
Lee las opciones de la línea de comandos de archivo. Las opciones leídas se insertan en lugar de la opción @archivo original. Si archivo no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando t

strings(1) - Arch Linux

NAME

strings

muestra los caracteres imprimibles de un archivo

SYNOPSIS

strings [-a | -d] [-t format] [-e {s,S,l,b,B}] [--all] [--radix={d,o,x}] [-n length] [--bytes=length] [--encoding={s,S,l,b,B}] [--help] [--version] [infile...

DESCRIPTION

La utilidad strings encuentra y muestra las secuencias de caracteres imprimibles en un archivo. Una secuencia es un conjunto de cuatro o más caracteres imprimibles que terminan con un carácter nulo o un carácter de nueva línea.

Las secuencias de caracteres imprimibles son aquellas secuencias de bytes que son imprimibles en el juego de caracteres ASCII. Por defecto, strings considera los caracteres del código 0x20 al 0x7E como imprimibles.

Si no se especifica ningún archivo, strings leerá de la entrada estándar.

OPTIONS

-a, --all
Busca en todo el archivo, no solo en las secciones de datos inicializadas.
-d, --data
Busca solo en la sección de datos inicializada. Esta es la configuración predeterminada.
-n length, --bytes=length
Especifica la longitud mínima de la cadena a mostrar. El valor predeterminado es 4.
-t format
Imprime la ubicación de cada cadena encontrada. El format puede ser:
d
Decimal
o
Octal
x
Hexadecimal
-e {s,S,l,b,B}
Especifica el juego de caracteres a usar. El valor predeterminado es 's' (ASCII de 7 bits).
s
ASCII de 7 bits.
S
ASCII de 7 bits (idéntico a s).
l
UTF-16 Little Endian (por ejemplo, Windows).
b
UTF-16 Big Endian (por ejemplo, un sistema de orden de bytes original).
B
UTF-32 Big Endian.
L
UTF-32 Little Endian.
--help
Muestra un mensaje de ayuda y sale.
--version
Muestra la información de la versión y sale.
@file
Lee las opciones de la línea de comandos del archivo file. Las opciones en el archivo file se interpretan de la misma manera que las opciones en la línea de comandos. Las opciones que contienen espacios deben incluirse entre comillas simples o dobles. Cualquier carácter (incluido una barra invertida) puede incluirse prefijando el carácter a incluir con una barra invertida. El file puede contener a su vez opciones adicionales de @file; dichas opciones se procesarán recursivamente.
