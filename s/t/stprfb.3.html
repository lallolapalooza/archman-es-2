subroutine stprfb (character side, character trans, character direct, character storev, integer m, integer n, integer k, integer l, real, dimension( ldv, * ) v, integer ldv, real, dimension( ldt, * ) t, integer ldt, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldwork, * ) work, integer ldwork)

STPRFB aplica un reflector de bloque real "triangular-pentagonal" a una matriz real, que se compone de dos bloques.

Propósito:

!>
!> STPRFB aplica un reflector de bloque real H o su
!> traspuesta H**T a una matriz C real, que se compone de dos
!> bloques A y B, ya sea desde la izquierda o desde la derecha.
!>
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar H o H**T desde la Izquierda
!>          = 'R': aplicar H o H**T desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar H (Sin traspuesta)
!>          = 'T': aplicar H**T (Traspuesta)
!>

DIRECT

!>          DIRECT es CHARACTER*1
!>          Indica cómo se forma H a partir de un producto de
!>          reflectores elementales
!>          = 'F': H = H(1) H(2) . . . H(k) (Hacia adelante)
!>          = 'B': H = H(k) . . . H(2) H(1) (Hacia atrás)
!>

STOREV

!>          STOREV es CHARACTER*1
!>          Indica cómo se almacenan los vectores que definen los
!>          reflectores elementales:
!>          = 'C': Columnas
!>          = 'R': Filas
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B.
!>          N >= 0.
!>

K

!>          K es INTEGER
!>          El orden de la matriz T, es decir, el número de reflectores
!>          elementales cuyo producto define el reflector de bloque.
!>          K >= 0.
!>

L

!>          L es INTEGER
!>          El orden de la parte trapezoidal de V.
!>          K >= L >= 0. Ver Detalles Adicionales.
!>

V

!>          V es un array REAL, de dimensión
!>                                (LDV,K) si STOREV = 'C'
!>                                (LDV,M) si STOREV = 'R' y SIDE = 'L'
!>                                (LDV,N) si STOREV = 'R' y SIDE = 'R'
!>          La matriz pentagonal V, que contiene los reflectores
!>          elementales H(1), H(2), ..., H(K). Ver Detalles Adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si STOREV = 'C' y SIDE = 'L', LDV >= max(1,M);
!>          si STOREV = 'C' y SIDE = 'R', LDV >= max(1,N);
!>          Si STOREV = 'R', LDV >= K.
!>

T

!>          T es un array REAL, de dimensión (LDT,K)
!>          La matriz triangular K-por-K T en la representación del
!>          reflector de bloque.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.
!>          LDT >= K.
!>

A

!>          A es un array REAL, de dimensión
!>          (LDA,N) si SIDE = 'L' o (LDA,K) si SIDE = 'R'
!>          En la entrada, la matriz A de K-por-N o M-por-K.
!>          En la salida, A se sobrescribe con el bloque correspondiente de
!>          H*C o H**T*C o C*H o C*H**T. Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,K);
!>          Si SIDE = 'R', LDA >= max(1,M).
!>

B

!>          B es un array REAL, de dimensión (LDB,N)
!>          En la entrada, la matriz B de M-por-N.
!>          En la salida, B se sobrescribe con el bloque correspondiente de
!>          H*C o H**T*C o C*H o C*H**T. Ver Detalles Adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK es un array REAL, de dimensión
!>          (LDWORK,N) si SIDE = 'L',
!>          (LDWORK,K) si SIDE = 'R'.
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          Si SIDE = 'L', LDWORK >= K;
!>          si SIDE = 'R', LDWORK >= M.
!>

Detalles Adicionales:

!>
!>  La matriz C es una matriz compuesta formada a partir de los bloques A y B.
!>  El bloque B es de tamaño M-por-N; si SIDE = 'R', A es de tamaño M-por-K,
!>  y si SIDE = 'L', A es de tamaño K-por-N.
!>
!>  Si SIDE = 'R' y DIRECT = 'F', C = [A B].
!>
!>  Si SIDE = 'L' y DIRECT = 'F', C = [A]
!>                                      [B].
!>
!>  Si SIDE = 'R' y DIRECT = 'B', C = [B A].
!>
!>  Si SIDE = 'L' y DIRECT = 'B', C = [B]
!>                                      [A].
!>
!>  La matriz pentagonal V se compone de un bloque rectangular V1 y un
!>  bloque trapezoidal V2. El tamaño del bloque trapezoidal viene determinado
!>  por el parámetro L, donde 0<=L<=K. Si L=K, el bloque V2 de V es triangular;
!>  si L=0, no hay bloque trapezoidal, por lo tanto V = V1 es rectangular.
!>
!>  Si DIRECT = 'F' y STOREV = 'C':  V = [V1]
!>                                         [V2]
!>     - V2 es superior trapezoidal (primeras L filas de la triangular superior K-por-K)
!>
!>  Si DIRECT = 'F' y STOREV = 'R':  V = [V1 V2]
!>
!>     - V2 es inferior trapezoidal (primeras L columnas de la triangular inferior K-por-K)
!>
!>  Si DIRECT = 'B' y STOREV = 'C':  V = [V2]
!>                                         [V1]
!>     - V2 es inferior trapezoidal (últimas L filas de la triangular inferior K-por-K)
!>
!>  Si DIRECT = 'B' y STOREV = 'R':  V = [V2 V1]
!>
!>     - V2 es superior trapezoidal (últimas L columnas de la triangular superior K-por-K)
!>
!>  Si STOREV = 'C' y SIDE = 'L', V es M-por-K con V2 de L-por-K.
!>
!>  Si STOREV = 'C' y SIDE = 'R', V es N-por-K con V2 de L-por-K.
!>
!>  Si STOREV = 'R' y SIDE = 'L', V es K-por-M con V2 de K-por-L.
!>
!>  Si STOREV = 'R' y SIDE = 'R', V es K-por-N con V2 de K-por-L.
!>

Function/Subroutine Documentation

This subroutine is part of the LAPACK library, which provides routines for linear algebra computations. The description of the parameters and the functionality of the subroutine can be found in the LAPACK documentation.

Parameters

  • UPLO: Specifies whether the matrix is upper or lower triangular.
  • TRANS: Specifies whether to apply the transpose of the factorization.
  • DIAG: Specifies whether the diagonal elements are stored.
  • N: The order of the matrix.
  • KBL: The number of subdiagonals below the main diagonal.
  • KBR: The number of superdiagonals above the main diagonal.
  • FB: The array containing the band matrix.
  • LDFB: The leading dimension of the array FB.
  • IPIV: The array containing the pivot indices.
  • WORK: The work array.
  • LDWORK: The leading dimension of the array WORK.
  • INFO: On exit, INFO is an integer indicating the status of the computation.
