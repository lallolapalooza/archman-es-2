Documentación de función/subrutina

subroutine stpcon (character norm, character uplo, character diag, integer n, real, dimension( * ) ap, real rcond, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

STPCON

Propósito:

!>
!> STPCON estima el recíproco del número de condición de una matriz triangular empaquetada A,
!> en la norma 1 o en la norma infinito.
!>
!> Se calcula la norma de A y se obtiene una estimación de
!> norm(inv(A)), luego se calcula el recíproco del número de condición como
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica si se requiere el número de condición en norma 1 o en norma
!>          infinito:
!>          = '1' o 'O':  norma 1;
!>          = 'I':         norma infinito.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

DIAG

!>          DIAG es CHARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es array REAL, dimension (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por columnas en
!>          un array lineal. La j-ésima columna de A se almacena en el array
!>          AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Si DIAG = 'U', los elementos diagonales de A no se referencian
!>          y se asume que son 1.
!>

RCOND

!>          RCOND es REAL
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK es array REAL, dimension (3*N)
!>

IWORK

!>          IWORK es array INTEGER, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
