subroutine stzrqf (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, integer info)

STZRQF

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina STZRZF.
!>
!> STZRQF reduce la matriz A real superior trapezoidal M por N ( M<=N )
!> a forma triangular superior por medio de transformaciones ortogonales.
!>
!> La matriz superior trapezoidal A se factoriza como
!>
!>    A = ( R  0 ) * Z,
!>
!> donde Z es una matriz ortogonal N por N y R es una matriz triangular
!> superior M por M.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= M.
!>

A

!>          A es una matriz REAL, dimensión (LDA,N)
!>          A la entrada, la parte superior trapezoidal líder de M por N de la
!>          matriz A debe contener la matriz a factorizar.
!>          A la salida, la parte triangular superior líder de M por M de A
!>          contiene la matriz triangular superior R, y los elementos M+1 a
!>          N de las primeras M filas de A, junto con la matriz TAU, representan
!>          la matriz ortogonal Z como un producto de M transformaciones elementales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A.  LDA >= max(1,M).
!>

TAU

!>          TAU es una matriz REAL, dimensión (M)
!>          Los factores escalares de las transformaciones elementales.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Autor

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Detalles adicionales:

!>
!>  La factorización se obtiene por el método de Householder. La k-ésima
!>  matriz de transformación, Z( k ), que se usa para introducir ceros en
!>  la fila ( m - k + 1 ) de A, se da en la forma
!>
!>     Z( k ) = ( I     0   ),
!>              ( 0  T( k ) )
!>
!>  donde
!>
!>     T( k ) = I - tau*u( k )*u( k )**T,   u( k ) = (   1    ),
!>                                                   (   0    )
!>                                                   ( z( k ) )
!>
!>  tau y z( k ) se eligen para aniquilar los elementos de la k-ésima fila
!>  de X.
!>
!>  El escalar tau se devuelve en el k-ésimo elemento de TAU y el vector
!>  u( k ) en la k-ésima fila de A, de modo que los elementos de z( k )
!>  están en  a( k, m + 1 ), ..., a( k, n ). Los elementos de R se devuelven
!>  en la parte triangular superior de A.
!>
!>  Z se da por
!>
!>     Z =  Z( 1 ) * Z( 2 ) * ... * Z( m ).
!>
