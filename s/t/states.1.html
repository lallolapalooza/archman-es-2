STATES(1) STATES STATES(1)

NOMBRE

states - herramienta de procesamiento de texto similar a awk

SINOPSIS

states [-hvV] [-D var=val] [-f archivo] [-o archivo_salida] [-p ruta] [-s estado_inicial] [-W nivel] [archivo ...]

DESCRIPCIÓN

States es una herramienta de procesamiento de texto similar a awk con algunas extensiones de máquina de estados. Está diseñada para el resaltado de código fuente de programas y tareas similares donde la información de estado ayuda al procesamiento de entrada.

En un momento dado, States se encuentra en un estado; cada uno es muy similar al entorno de trabajo de awk. Tienen expresiones regulares que se comparan con la entrada y acciones que se ejecutan cuando se encuentra una coincidencia. Desde los bloques de acciones, states puede realizar transiciones de estado; puede pasar a otro estado desde el cual se continúa el procesamiento. Las transiciones de estado se registran para que states pueda volver al estado de llamada una vez que el estado actual haya finalizado.

La mayor diferencia entre states y awk, además de las extensiones de máquina de estados, es que states no está orientado a líneas. Compara tokens de expresiones regulares con la entrada y, una vez procesada una coincidencia, continúa el procesamiento desde la posición actual, no desde el principio de la siguiente línea de entrada.

OPCIONES

-D var=val, --define=var=val
Define la variable var para que tenga el valor de cadena val. Las definiciones de la línea de comandos sobrescriben las definiciones de variables encontradas en el archivo de configuración.
-f archivo, --file=archivo
Lee las definiciones de estado del archivo archivo. Por defecto, states intenta leer las definiciones de estado del archivo states.st en el directorio de trabajo actual.
-h, --help
Imprime un mensaje de ayuda corto y sale.
-o archivo, --output=archivo
Guarda la salida en el archivo archivo en lugar de imprimirla en stdout.
-p ruta, --path=ruta
Establece la ruta de carga a ruta. La ruta de carga por defecto es el directorio desde el cual se carga el archivo de definiciones de estado.
-s estado, --state=estado
Inicia la ejecución desde el estado estado. Esta definición sobrescribe el estado de inicio resuelto desde el bloque start.
-v, --verbose
Aumenta la verbosidad del programa.
-V, --version
Imprime la versión de states y sale.
-W nivel, --warning=nivel
Establece el nivel de advertencia a nivel. Los valores posibles para nivel son:
light
advertencias ligeras (por defecto)
all
todas las advertencias

ARCHIVOS DE PROGRAMA STATES

Los archivos de programa States pueden contener un bloque start, bloques startrules y namerules para especificar el estado inicial, definiciones de state y expressions.

El bloque start es el main() del programa states; se ejecuta al inicio del script para cada archivo de entrada y puede realizar cualquier inicialización que el script necesite. Normalmente, también llama a las primitivas check_startrules() y check_namerules(), que resuelven el estado inicial a partir del nombre del archivo de entrada o de los datos encontrados al principio del archivo de entrada. Aquí hay un ejemplo de bloque start que inicializa dos variables y realiza la resolución estándar del estado de inicio:

start
{
  a = 1;
  msg = "¡Hola, mundo!";
  check_startrules ();
  check_namerules ();
}

Una vez procesado el bloque start, el procesamiento de entrada continúa desde el estado inicial.

El estado inicial se resuelve mediante la información encontrada en los bloques startrules y namerules. Ambos bloques contienen pares de expresiones regulares y símbolos; cuando la expresión regular coincide con el nombre o con el principio del archivo de entrada, el estado inicial se nombra con el símbolo correspondiente. Por ejemplo, las siguientes reglas de inicio y nombre pueden distinguir archivos C y Fortran:

namerules
{
  /\.(c|h)$/    c;
  /\.[fF]$/     fortran;
}
startrules
{
  /-\*- [cC] -\*-/      c;
  /-\*- fortran -\*-/   fortran;
}

Si estas reglas se usan con el bloque de inicio mostrado anteriormente, states primero verifica el principio del archivo de entrada. Si tiene la cadena -*- c -*-, se asume que el archivo contiene código C y el procesamiento comienza en el estado llamado c. Si el principio del archivo de entrada tiene la cadena -*- fortran -*-, el estado inicial es fortran. Si ninguna de las reglas de inicio coincidió, el nombre del archivo de entrada se compara con las namerules. Si el nombre termina con el sufijo c o C, vamos al estado c. Si el sufijo es f o F, el estado inicial es fortran.

Si tanto las reglas de inicio como las de nombre no lograron resolver el estado de inicio, states simplemente copia la entrada a la salida sin modificar.

El estado de inicio también se puede especificar desde la línea de comandos con la opción -s, --state.

Las definiciones de estado tienen la siguiente sintaxis:

state { expr {sentencias} ... }

donde expr es: una expresión regular, una expresión especial o un símbolo, y sentencias es una lista de sentencias. Cuando la expresión expr coincide con la entrada, se ejecuta el bloque de sentencias. El bloque de sentencias puede llamar a las primitivas de states, subrutinas definidas por el usuario, llamar a otros estados, etc. Una vez ejecutado el bloque, el procesamiento de entrada continúa desde la posición actual de entrada (que podría haber cambiado si el bloque de sentencias llamó a otros estados).

Las expresiones especiales BEGIN y END se pueden usar en lugar de expr. La expresión BEGIN coincide con el principio del estado; su bloque se llama cuando se entra al estado. La expresión END coincide con el final del estado; su bloque se ejecuta cuando states abandona el estado.

Si expr es un símbolo, su valor se busca en el entorno global y, si es una expresión regular, se compara con la entrada; de lo contrario, esa regla se ignora.

El archivo del programa states también puede tener expresiones de nivel superior; estas se evalúan después de que se analiza el archivo del programa, pero antes de que se procesen los archivos de entrada o se evalúe el bloque start.

FUNCIONES PRIMITIVAS

call (símbolo)
Pasa al estado símbolo y continúa el procesamiento del archivo de entrada desde ese estado. La función devuelve lo que sea que devolviera la sentencia return del estado símbolo.
calln (nombre)
Similar a call, pero el argumento nombre se evalúa y su valor debe ser una cadena. Por ejemplo, esta función se puede usar para llamar a un estado cuyo nombre está almacenado en una variable.
check_namerules ()
Intenta resolver el estado de inicio desde las reglas de namerules. La función devuelve 1 si se resolvió el estado de inicio o 0 en caso contrario.
check_startrules ()
Intenta resolver el estado de inicio desde las reglas de startrules. La función devuelve 1 si se resolvió el estado de inicio o 0 en caso contrario.
concat (str, ...)
Concatena las cadenas de argumento y devuelve el resultado como una nueva cadena.
float (cualquiera)
Convierte el argumento a un número de punto flotante.
getenv (str)
Obtiene el valor

FUNCIONES PRIMITIVAS

assert (any, ...)
Verifica que los argumentos se evalúan a verdadero. Si no es así, informa un error.
call (string, ...)
Llama a la función externa especificada por el primer argumento de cadena. Los argumentos restantes se pasan a la función.
chomp (string)
Elimina el carácter de nueva línea final de la cadena de entrada si está presente.
chr (integer)
Devuelve el carácter correspondiente al valor ordinal entero dado.
delete (string, ...)
Elimina los caracteres especificados por los argumentos de cadena del primer argumento de cadena.
dump (any, ...)
Imprime los argumentos en la salida estándar y sale. Se utiliza para depurar.
eval (string)
Evalúa el argumento de cadena como un programa de estados.
exit (any, ...)
Sale del programa con el estado de salida dado. Si no se proporciona ninguno, se utiliza 0.
getenv (str)
Devuelve el valor de la variable de entorno str. Devuelve una cadena vacía si la variable var no está definida.
int (any)
Convierte el argumento en un número entero.
length (item, ...)
Cuenta la longitud de las cadenas o listas de argumentos.
list (any, ...)
Crea una nueva lista que contiene los elementos any, ...
panic (any, ...)
Informa de un error irrecuperable y sale con el estado 1. La función nunca devuelve.
print (any, ...)
Convierte los argumentos en cadenas y los imprime en la salida.
range (source, start, end)
Devuelve un subrango de source a partir de la posición start (inclusiva) hasta end (exclusiva). El argumento source puede ser una cadena o una lista.
regexp (string)
Convierte la cadena string en una nueva expresión regular.
regexp_syntax (char, syntax)
Modifica las sintaxis de los caracteres de la expresión regular asignando la nueva sintaxis syntax al carácter char. Los valores posibles para syntax son:
'w'
el carácter es un constituyente de palabra
' '
el carácter no es un constituyente de palabra
regmatch (string, regexp)
Comprueba si la cadena string coincide con la expresión regular regexp. La función devuelve un estado booleano de éxito y establece los registros de subexpresión $n.
regsub (string, regexp, subst)
Busca la expresión regular regexp en la cadena string y reemplaza la subcadena coincidente con la cadena subst. Devuelve la cadena resultante. La cadena de sustitución subst puede contener referencias $n a la n:ésima subexpresión entre paréntesis.
regsuball (string, regexp, subst)
Igual que regsub, pero reemplaza todas las coincidencias de la expresión regular regexp de la cadena string con la cadena subst.
require_state (symbol)
Comprueba que el estado symbol está definido. Si el estado requerido no está definido, la función intenta cargarlo automáticamente. Si la carga falla, el programa terminará con un mensaje de error.
split (regexp, string)
Divide la cadena string en una lista considerando las coincidencias de la expresión regular regexp como separador de elementos.
sprintf (fmt, ...)
Formatea los argumentos de acuerdo con fmt y devuelve el resultado como una cadena.
strcmp (str1, str2)
Realiza una comparación sensible a mayúsculas y minúsculas de las cadenas str1 y str2. La función devuelve un valor que es:
-1
la cadena str1 es menor que str2
0
las cadenas son iguales
1
la cadena str1 es mayor que str2
string (any)
Convierte el argumento en una cadena.
strncmp (str1, str2, num)
Realiza una comparación sensible a mayúsculas y minúsculas de las cadenas str1 y str2 comparando como máximo num caracteres.
substring (str, start, end)
Devuelve una subcadena de la cadena str a partir de la posición start (inclusiva) hasta end (exclusiva).

VARIABLES INTEGRADAS

$.
número de línea de entrada actual
$n
la n:ésima subexpresión regular entre paréntesis de la expresión regular del estado más reciente o del primitivo regmatch
$`
todo lo anterior a la coincidencia de la expresión regular. Esto es utilizable cuando se usa con el primitivo regmatch; el contenido de esta variable no está definido cuando se usa en bloques de acción para referirse a los datos anteriores a la expresión regular del bloque.
$B
un alias para $`
argv
lista de nombres de archivos de entrada
filename
nombre del archivo de entrada actual
program
nombre del programa (generalmente states)
version
cadena de la versión del programa
