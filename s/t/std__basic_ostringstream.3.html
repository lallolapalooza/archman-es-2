template<typename _CharT, typename _Traits> void std::basic_ios< _CharT, _Traits >::exceptions (iostate __except) [inline], [inherited]

Lanzamiento de excepciones ante errores.

Parámetros

__except La nueva máscara de excepciones.

Por defecto, las banderas de error se establecen silenciosamente. Puede establecer una máscara de excepciones para cada stream; si un bit en la máscara se establece en las banderas de error, se lanza una excepción de tipo std::ios_base::failure.

Si la bandera de error ya está establecida cuando se agrega la máscara de excepciones, la excepción se lanza inmediatamente. Intente ejecutar lo siguiente en GCC 3.1 o posterior:

#include <iostream>
#include <fstream>
#include <exception>
int main()
{
    std::set_terminate (__gnu_cxx::__verbose_terminate_handler);
    std::ifstream f ("/etc/motd");
    std::cerr << "Setting badbit\n";
    f.setstate (std::ios_base::badbit);
    std::cerr << "Setting exception mask\n";
    f.exceptions (std::ios_base::badbit);
}

template<typename _CharT, typename _Traits> bool std::basic_ios< _CharT, _Traits >::fail () const [inline], [nodiscard], [inherited]

Comprobación rápida de errores.

Retorna
