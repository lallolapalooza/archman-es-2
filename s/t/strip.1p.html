STRIP(1P) Manual del Programador POSIX STRIP(1P)

PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

strip — elimina información innecesaria de archivos eliminables (DESARROLLO)

SINÓPSIS

strip archivo...

DESCRIPCIÓN

Un archivo eliminable se define como un archivo relocalizable, objeto o ejecutable. En sistemas compatibles con XSI, un archivo eliminable también puede ser un archivo que contiene archivos objeto o relocalizables.

La utilidad strip eliminará de los archivos eliminables nombrados por los operandos archivo cualquier información que el implementador considere innecesaria para la ejecución de dichos archivos. La naturaleza de esa información no se especifica. El efecto de strip en archivos objeto y ejecutables será similar al uso de la opción -s de c99 o fort77. El efecto de strip en un archivo de archivos objeto será similar al uso de la opción -s de c99 o fort77 para cada archivo objeto en el archivo.

OPCIONES

Ninguna.

OPERANDOS

Se soportará el siguiente operando:

archivo
Una ruta de acceso que hace referencia a un archivo eliminable.

ENTRADA ESTÁNDAR

No se usa.

ARCHIVOS DE ENTRADA

Los archivos de entrada deberán estar en el formato de archivos eliminables producidos correctamente por cualquier compilador definido por este volumen de POSIX.1‐2017 o producidos al crear o actualizar un archivo de dichos archivos utilizando la utilidad ar.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de strip:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en una cadena de valor no vacía, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte en comparación con caracteres multibyte en argumentos).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en el error estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASÍNCRONOS

Predeterminado.

SALIDA ESTÁNDAR

No se usa.

ERROR ESTÁNDAR

El error estándar se utilizará solo para mensajes de diagnóstico.

ARCHIVOS DE SALIDA

La utilidad strip producirá archivos eliminables de formato no especificado.

ESTADO DE SALIDA

Se devolverán los siguientes valores de salida:

 0
Finalización exitosa.
>0
Ocurrió un error.

CONSECUENCIAS DE LOS ERRORES

Predeterminado.

Las siguientes secciones son informativas.

USO DE LA APLICACIÓN

Ninguno.

EJEMPLOS

Ninguno.

FUNDAMENTACIÓN

Históricamente, esta utilidad se ha utilizado para eliminar la tabla de símbolos de un archivo eliminable. Se incluyó porque se sabe que la cantidad de información simbólica puede ascender a varios megabytes; la capacidad de eliminarla de manera portable se consideró importante, especialmente para sistemas más pequeños.

Se dice que el comportamiento de strip en archivos objeto y ejecutables es el mismo que la opción -s de un compilador. Si bien el resultado final es esencialmente el mismo, no se requiere que sea idéntico.

Los sistemas compatibles con XSI admiten el uso de strip en archivos de archivo que contienen archivos objeto o archivos relocalizables.

strip(1)

PROLOG

NOMBRE

strip - Eliminar símbolos y otra información de archivos objeto

SINOPSIS

strip [-[aAbB][.][g...][-[sS][.][c][-x][.][R]] [--strip-debug] [--strip-unneeded] [--strip-symbols] [--only-keep-debug] [--wildcard] [-K RE] [-k RE] [--] [-g] [-s] [-x] [--] ARCHIVO...

DESCRIPCIÓN

strip elimina símbolos y otra información de los archivos objeto especificados. Esto puede ser útil para reducir el tamaño de los archivos ejecutables y de las bibliotecas compartidas.

strip puede eliminar lo siguiente:

  • Símbolos de depuración.
  • Símbolos de reubicación.
  • Tabla de cadenas.
  • Tabla de secciones.
  • Información de anotaciones.
  • Información de depuración de DWARF.

OPCIONES

Las opciones de strip se pueden agrupar. Por ejemplo, -s -x es lo mismo que -sx.

-[aAbB][.][g...][-[sS][.][c][-x][.][R]

Esta es una sintaxis abreviada para diversas opciones de strip. Por favor, consulte la documentación de strip para más detalles.

--strip-debug

Eliminar la información de depuración de los archivos objeto. Esto incluye símbolos de depuración, DWARF y otra información relacionada.

--strip-unneeded

Eliminar información que no es necesaria para la reubicación o la ejecución. Esto incluye símbolos de depuración y otros datos no esenciales.

--strip-symbols

Eliminar todos los símbolos del archivo objeto, excepto los símbolos necesarios para la vinculación (como los símbolos de la sección `.text` y `.data`).

--only-keep-debug

Conservar únicamente la información de depuración. Esto es útil para crear versiones de depuración de un programa que se pueden usar con herramientas de depuración.

--wildcard

Permite usar comodines en los nombres de los archivos objeto.

-K RE

Eliminar símbolos que coincidan con la expresión regular RE. Solo se conservan los símbolos de las secciones `.text` y `.data`.

-k RE

Eliminar símbolos que coincidan con la expresión regular RE.

--

Indica el final de las opciones.

-g
-s
-x

Estas son opciones abreviadas que corresponden a la eliminación de símbolos de depuración, símbolos y símbolos locales, respectivamente. Consulte la documentación de strip para obtener más detalles.

OPERANDOS

ARCHIVO

Uno o más archivos objeto de los que se eliminará la información.

ENTRADA ESTÁNDAR

No se utiliza la entrada estándar.

ARCHIVOS DE ENTRADA

Los archivos objeto especificados como ARCHIVO.

VARIABLES DE ENTORNO

No se utilizan variables de entorno.

EVENTOS ASÍNCRONOS

No se aplican eventos asíncronos.

SALIDA ESTÁNDAR

No se utiliza la salida estándar.

ERROR ESTÁNDAR

Se utiliza el error estándar para mostrar mensajes de error.

ARCHIVOS DE SALIDA

Los archivos objeto de entrada se modifican in situ.

DESCRIPCIÓN EXTENDIDA

strip es una herramienta de la GNU Binutils que se utiliza para eliminar información de depuración y otros símbolos de los archivos objeto. Esto puede reducir significativamente el tamaño de los archivos ejecutables y de las bibliotecas, lo que es beneficioso para el despliegue y el almacenamiento.

La eliminación de información de depuración no afecta al funcionamiento del programa, pero hace que sea más difícil depurar el programa si es necesario. La eliminación de otros símbolos puede afectar al rendimiento o a la capacidad de vincular el programa con otras bibliotecas.

strip opera sobre archivos objeto en varios formatos, incluyendo ELF, COFF y a.out.

ESTADO DE SALIDA

0 si todas las operaciones se completaron correctamente.

Mayor que 0 si se produjo algún error.

CONSECUENCIAS DE LOS ERRORES

Si strip no puede procesar un archivo objeto, mostrará un mensaje de error y continuará con el siguiente archivo. Si se produce un error durante el procesamiento de un archivo, el archivo puede quedar en un estado inconsistente.

USO DE LA APLICACIÓN

Generalmente, strip se utiliza después de compilar un programa para eliminar información innecesaria y reducir el tamaño del archivo.

Ejemplo:

strip mi_programa

Esto eliminará la información de depuración y los símbolos innecesarios de mi_programa.

EJEMPLOS

JUSTIFICACIÓN

La eliminación de información de depuración y símbolos innecesarios de los archivos objeto es una práctica común para optimizar el tamaño de las aplicaciones. Esto es especialmente importante en entornos con recursos limitados o cuando se distribuyen aplicaciones a usuarios finales. strip proporciona una forma sencilla y eficaz de realizar esta tarea.

DIRECCIONES FUTURAS

Se espera que strip siga siendo una herramienta fundamental para la optimización de archivos objeto. Las futuras mejoras podrían centrarse en un soporte más amplio para formatos de archivos emergentes y una mayor granularidad en la eliminación de información específica.
