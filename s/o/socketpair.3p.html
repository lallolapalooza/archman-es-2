SOCKETPAIR(3P) Manual del programador POSIX SOCKETPAIR(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

socketpair — crear un par de sockets conectados

SINOPSIS

#include <sys/socket.h>
int socketpair(int domain, int type, int protocol,
    int socket_vector[2]);

DESCRIPCIÓN

La función socketpair() crea un par de sockets conectados no enlazados en un dominio especificado, de un tipo especificado, bajo el protocolo opcionalmente especificado por el argumento protocol. Los dos sockets serán idénticos. Los descriptores de archivo utilizados para referenciar los sockets creados se devolverán en socket_vector[0] y socket_vector[1]. Los descriptores de archivo se asignarán según se describe en la Sección 2.14, Asignación de descriptores de archivo.

La función socketpair() toma los siguientes argumentos:

domain
Especifica el dominio de comunicaciones en el que se crearán los sockets.
type
Especifica el tipo de sockets que se crearán.
protocol
Especifica un protocolo particular que se utilizará con los sockets. Especificar un protocol de 0 hace que socketpair() use un protocolo predeterminado no especificado apropiado para el tipo de socket solicitado.
socket_vector
Especifica una matriz de 2 enteros para almacenar los descriptores de archivo del par de sockets creados.

El argumento type especifica el tipo de socket, que determina la semántica de las comunicaciones a través del socket. Los siguientes tipos de socket están definidos; las implementaciones pueden especificar tipos de socket adicionales:

SOCK_STREAM
Proporciona flujos de bytes secuenciados, fiables, bidireccionales y en modo de conexión, y puede proporcionar un mecanismo de transmisión para datos fuera de banda.
SOCK_DGRAM
Proporciona datagramas, que son mensajes no conectados y no fiables de longitud máxima fija.
SOCK_SEQPACKET
Proporciona vías de transmisión de registros secuenciadas, fiables, bidireccionales y en modo de conexión. Un registro se puede enviar usando una o más operaciones de salida y recibir usando una o más operaciones de entrada, pero una sola operación nunca transfiere parte de más de un registro. Los límites de registro son visibles para el receptor a través de la bandera MSG_EOR.

Si el argumento protocol es distinto de cero, especificará un protocolo compatible con la familia de direcciones. Si el argumento protocol es cero, se utilizará el protocolo predeterminado para esta familia de direcciones y tipo. Los protocolos compatibles con el sistema se definen según la implementación.

El proceso puede necesitar tener los privilegios apropiados para usar la función socketpair() o para crear algunos sockets.

VALOR DE RETORNO

Al completarse con éxito, esta función devolverá 0; de lo contrario, se devolverá -1 y se establecerá errno para indicar el error, no se asignarán descriptores de archivo y el contenido de socket_vector permanecerá sin modificar.

ERRORES

La función socketpair() fallará si:

EAFNOSUPPORT

La implementación no admite la familia de direcciones especificada.
EMFILE
Todos, o todos menos uno, de los descriptores de archivo disponibles para el proceso están actualmente abiertos.
ENFILE
No hay más descriptores de archivo disponibles para el sistema.
EOPNOTSUPP
El protocolo especificado no permite la creación de pares de sockets.
EPROTONOSUPPORT

El protocolo no es compatible con la familia de direcciones, o el protocolo no es compatible con la implementación.
EPROTOTYPE
El tipo de socket no es compatible con el protocolo.

La función socketpair() puede fallar si:

EACCES
El proceso no tiene los privilegios apropiados.
ENOBUFS
No había suficientes recursos disponibles en el sistema para realizar la operación.
ENOMEM
No había suficiente memoria disponible para satisfacer la solicitud.

USO DE LA APLICACIÓN

La documentación de las familias de direcciones específicas especifica qué protocolos admite cada familia de direcciones. La documentación de los protocolos específicos especifica qué tipos de socket admite cada protocolo.

La función socketpair() se utiliza principalmente con sockets de dominio UNIX y no es necesario que sea compatible con otros dominios.
