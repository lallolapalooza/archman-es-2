subrutina sorgrq (integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SORGRQ

Propósito:

!>
!> SORGRQ genera una matriz real M por N, Q, con filas ortonormales,
!> que se define como las últimas M filas de un producto de K
!>    reflejos elementales de orden N
!>
!>       Q  =  H(1) H(2) . . . H(k)
!>
!> tal como es devuelto por SGERQF.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz Q. N >= M.
!>

K

!>          K es ENTERO
!>          El número de reflejos elementales cuyo producto define la
!>          matriz Q. M >= K >= 0.
!>

A

!>          A es un array REAL, dimension (LDA,N)
!>          En la entrada, la fila (m-k+i) debe contener el vector que
!>          define el reflejo elemental H(i), para i = 1,2,...,k, tal
!>          como es devuelto por SGERQF en las últimas k filas de su
!>          argumento de array A.
!>          En la salida, la matriz M por N, Q.
!>

LDA

!>          LDA es ENTERO
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array REAL, dimension (K)
!>          TAU(i) debe contener el factor escalar del reflejo elemental
!>          H(i), tal como es devuelto por SGERQF.
!>

WORK

!>          WORK es un array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK. LWORK >= max(1,M).
!>          Para un rendimiento óptimo, LWORK >= M*NB, donde NB es el
!>          tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tiene un valor ilegal
!>
