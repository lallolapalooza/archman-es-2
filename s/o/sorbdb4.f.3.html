SORBDB4

Documentación de función/subrutina

subrutina sorbdb4 (m entero, p entero, q entero, real, dimensión(ldx11,*) x11, entero ldx11, real, dimensión(ldx21,*) x21, entero ldx21, real, dimensión(*) theta, real, dimensión(*) phi, real, dimensión(*) taup1, real, dimensión(*) taup2, real, dimensión(*) tauq1, real, dimensión(*) phantom, real, dimensión(*) work, entero lwork, entero info)

SORBDB4

Propósito:

!>
!> SORBDB4 bidiagonaliza simultáneamente los bloques de una matriz X alta y delgada
!> con columnas ortonormales:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 es P-por-Q, y X21 es (M-P)-por-Q. M-Q debe ser no mayor que P,
!> M-P, o Q. Las rutinas SORBDB1, SORBDB2 y SORBDB3 manejan casos en
!> los que M-Q no es la dimensión mínima.
!>
!> Las matrices ortogonales P1, P2 y Q1 son P-por-P, (M-P)-por-(M-P)
!> y (M-Q)-por-(M-Q), respectivamente. Se representan implícitamente por
!> vectores de Householder.
!>
!> B11 y B21 son matrices bidiagonales (M-Q)-por-(M-Q) representadas
!> implícitamente por ángulos THETA, PHI.
!>
!>

Parámetros

M 
!>          M es ENTERO
!>           El número de filas de X11 más el número de filas en X21.
!>

P

!>          P es ENTERO
!>           El número de filas en X11. 0 <= P <= M.
!>

Q

!>          Q es ENTERO
!>           El número de columnas en X11 y X21. 0 <= Q <= M y
!>           M-Q <= min(P,M-P,Q).
!>

X11

!>          X11 es un array REAL, dimensión (LDX11,Q)
!>           En la entrada, el bloque superior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X11) especifican los
!>           reflectores para P1 y las filas de triu(X11,1) especifican los
!>           reflectores para Q1.
!>

LDX11

!>          LDX11 es ENTERO
!>           La dimensión principal de X11. LDX11 >= P.
!>

X21

!>          X21 es un array REAL, dimensión (LDX21,Q)
!>           En la entrada, el bloque inferior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X21) especifican los
!>           reflectores para P2.
!>

LDX21

!>          LDX21 es ENTERO
!>           La dimensión principal de X21. LDX21 >= M-P.
!>

THETA

!>          THETA es un array REAL, dimensión (Q)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen por
!>           THETA y PHI. Ver Más detalles.
!>

PHI

!>          PHI es un array REAL, dimensión (Q-1)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen por
!>           THETA y PHI. Ver Más detalles.
!>

TAUP1

!>          TAUP1 es un array REAL, dimensión (M-Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           P1.
!>

TAUP2

!>          TAUP2 es un array REAL, dimensión (M-Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           P2.
!>

TAUQ1

!>          TAUQ1 es un array REAL, dimensión (Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           Q1.
!>

PHANTOM

!>          PHANTOM es un array REAL, dimensión (M)
!>           La rutina calcula un vector columna Y de M por 1 que es
!>           ortogonal a las columnas de [ X11; X21 ]. PHANTOM(1:P) y
!>           PHANTOM(P+1:M) contienen vectores de Householder para Y(1:P) y
!>           Y(P+1:M), respectivamente.
!>

WORK

!>          WORK es un array REAL, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>           La dimensión del array WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, entonces se asume una consulta de espacio de
!>           trabajo; la rutina solo calcula el tamaño óptimo del array
!>           WORK, devuelve este valor como la primera entrada del array
!>           WORK, y XERBLA no emite ningún mensaje de error relacionado con
!>           LWORK.
!>

INFO

!>          INFO es ENTERO
!>           = 0:  salida exitosa.
!>           < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Más detalles:

!>
!>  Los bloques superiores bidiagonales B11, B21 se representan implícitamente
!>  por los ángulos THETA(1), ..., THETA(Q) y PHI(1), ..., PHI(Q-1). Cada
!>  entrada en cada banda bidiagonal es un producto de un seno o coseno de
!>  un THETA con un seno o coseno de un PHI. Ver [1] o SORCSD para detalles.
!>
!>  P1, P2 y Q1 se representan como productos de reflectores elementales.
!>  Ver SORCSD2BY1 para detalles sobre cómo generar P1, P2 y Q1 usando
!>  SORGQR y SORGLQ.
!>

Referencias:
