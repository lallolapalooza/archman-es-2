SORBDB3

Documentación de Función/Subrutina

subrutina sorbdb3 (integer m, integer p, integer q, real, dimension(ldx11,*) x11, integer ldx11, real, dimension(ldx21,*) x21, integer ldx21, real, dimension(*) theta, real, dimension(*) phi, real, dimension(*) taup1, real, dimension(*) taup2, real, dimension(*) tauq1, real, dimension(*) work, integer lwork, integer info)

SORBDB3

Propósito:

!>
!> SORBDB3 bidiagonaliza simultáneamente los bloques de una matriz alta y delgada X
!> con columnas ortonormales:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 es P por Q, y X21 es (M-P) por Q. M-P debe ser no mayor que P,
!> Q o M-Q. Las rutinas SORBDB1, SORBDB2 y SORBDB4 manejan casos en
!> los que M-P no es la dimensión mínima.
!>
!> Las matrices ortogonales P1, P2 y Q1 son P-por-P, (M-P)-por-(M-P)
!> y (M-Q)-por-(M-Q), respectivamente. Se representan implícitamente por
!> vectores de Householder.
!>
!> B11 y B12 son matrices bidiagonales (M-P)-por-(M-P) representadas
!> implícitamente por los ángulos THETA, PHI.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>           El número de filas de X11 más el número de filas en X21.
!>

P

!>          P es INTEGER
!>           El número de filas en X11. 0 <= P <= M. M-P <= min(P,Q,M-Q).
!>

Q

!>          Q es INTEGER
!>           El número de columnas en X11 y X21. 0 <= Q <= M.
!>

X11

!>          X11 es un array REAL, dimension (LDX11,Q)
!>           En la entrada, el bloque superior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X11) especifican los
!>           refletores para P1 y las filas de triu(X11,1) especifican los
!>           refletores para Q1.
!>

LDX11

!>          LDX11 es INTEGER
!>           La dimensión principal de X11. LDX11 >= P.
!>

X21

!>          X21 es un array REAL, dimension (LDX21,Q)
!>           En la entrada, el bloque inferior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X21) especifican los
!>           refletores para P2.
!>

LDX21

!>          LDX21 es INTEGER
!>           La dimensión principal de X21. LDX21 >= M-P.
!>

THETA

!>          THETA es un array REAL, dimension (Q)
!>           Las entradas de los bloques bidiagonales B11, B21 están definidas por
!>           THETA y PHI. Ver Detalles Adicionales.
!>

PHI

!>          PHI es un array REAL, dimension (Q-1)
!>           Las entradas de los bloques bidiagonales B11, B21 están definidas por
!>           THETA y PHI. Ver Detalles Adicionales.
!>

TAUP1

!>          TAUP1 es un array REAL, dimension (P)
!>           Los factores escalares de los reflectores elementales que definen
!>           P1.
!>

TAUP2

!>          TAUP2 es un array REAL, dimension (M-P)
!>           Los factores escalares de los reflectores elementales que definen
!>           P2.
!>

TAUQ1

!>          TAUQ1 es un array REAL, dimension (Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           Q1.
!>

WORK

!>          WORK es un array REAL, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>           La dimensión del array WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, entonces se asume una consulta de espacio de
!>           trabajo; la rutina solo calcula el tamaño óptimo del array
!>           WORK, devuelve este valor como la primera entrada del array
!>           WORK, y XERBLA no emite ningún mensaje de error relacionado
!>           con LWORK.
!>

INFO

!>          INFO es INTEGER
!>           = 0: salida exitosa.
!>           < 0: si INFO = -i, el argumento i-ésimo tenía un valor ilegal.
!>

Detalles Adicionales:

!>
!> Los bloques bidiagonales superiores B11, B21 se representan implícitamente
!> por los ángulos THETA(1), ..., THETA(Q) y PHI(1), ..., PHI(Q-1). Cada
!> entrada en cada banda bidiagonal es un producto de un seno o coseno de
!> un THETA con un seno o coseno de un PHI. Ver [1] o SORCSD para
!> detalles.
!>
!> P1, P2 y Q1 se representan como productos de reflectores elementales.
!> Ver SORCSD2BY1 para detalles sobre la generación de P1, P2 y Q1 usando
!> SORGQR y SORGLQ.
!>

Referencias:
