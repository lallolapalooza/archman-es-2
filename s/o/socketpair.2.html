socketpair(2) Manual de Llamadas al Sistema socketpair(2)

NOMBRE

socketpair - crea un par de sockets conectados

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/socket.h>
int socketpair(int domain, int type, int protocol, int sv[2]);

DESCRIPCIÓN

La llamada socketpair() crea un par sin nombre de sockets conectados en el domain especificado, del type especificado y usando el protocol opcionalmente especificado. Para más detalles sobre estos argumentos, véase socket(2).

Los descriptores de archivo que se utilizan para referenciar los nuevos sockets se devuelven en sv[0] y sv[1]. Los dos sockets son indistinguibles.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1, se establece la variable errno para indicar el error y sv permanece sin cambios.

En Linux (y otros sistemas), socketpair() no modifica sv en caso de fallo. Un requisito que estandariza este comportamiento se añadió en POSIX.1-2008 TC2.

ERRORES

EAFNOSUPPORT
La familia de direcciones especificada no es compatible en esta máquina.
EFAULT
La dirección sv no especifica una parte válida del espacio de direcciones del proceso.
EMFILE
Se ha alcanzado el límite por proceso en el número de descriptores de archivo abiertos.
ENFILE
Se ha alcanzado el límite a nivel de sistema en el número total de archivos abiertos.
EOPNOTSUPP
El protocolo especificado no admite la creación de pares de sockets.
EPROTONOSUPPORT
El protocolo especificado no es compatible en esta máquina.

VERSIONES

En Linux, los únicos dominios compatibles para esta llamada son AF_UNIX (o de forma sinónima, AF_LOCAL) y AF_TIPC (desde Linux 4.12).

ESTANDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, 4.2BSD.

Generalmente es portable hacia/desde sistemas no-BSD que soportan clones de la capa de sockets BSD (incluyendo variantes System V).

SOCK_CLOEXEC
SOCK_NONBLOCK
POSIX.1-2024; Linux 2.6.27. (Véase socket(2).)

VER TAMBIÉN

pipe(2), read(2), socket(2), write(2), socket(7), unix(7)
