NOMBRE

sogrep - Buscar enlaces de bibliotecas compartidas en un repositorio de Arch Linux

SINOPSIS

sogrep [opciones] repo nombre_lib

DESCRIPCIÓN

Comprueba la base de datos de enlaces de sonames en los repositorios de Arch Linux que contienen paquetes enlazados a una biblioteca compartida dada. Si el repositorio especificado es "all", se buscarán todos los repositorios; de lo contrario, solo se buscará el repositorio nombrado.

Si la base de datos de enlaces no existe, se descargará primero.

OPCIONES

-v, --verbose

Proporciona una salida detallada que contiene los enlaces coincidentes para cada paquete, el repositorio del que proviene (en caso de que se estén buscando todos los repositorios) y, en combinación con -r, una barra de progreso para la descarga de la base de datos de enlaces.

-r, --refresh

Actualiza las bases de datos de enlaces

-h, --help

Muestra un texto de ayuda

VARIABLES DE ENTORNO

SOLINKS_MIRROR="https://mirror.foo.com" Espejo alternativo para usar en la descarga de la base de datos de enlaces de sonames.

SOCACHE_DIR="/ruta/al/directorio"

Directorio donde se almacena la base de datos de enlaces de sonames; anula el directorio predeterminado establecido por la variable de entorno XDG_CACHE_HOME o la variable de entorno HOME si XDG_CACHE_HOME no está configurada.
