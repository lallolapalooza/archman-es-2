socketcall(2) Manual de llamadas al sistema socketcall(2)

NOMBRE

socketcall - llamadas al sistema de sockets

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/net.h>        /* Definición de constantes SYS_* */
#include <sys/syscall.h>      /* Definición de SYS_socketcall */
#include <unistd.h>
int syscall(SYS_socketcall, int call, unsigned long *args);

Nota: glibc no proporciona un envoltorio para socketcall(), haciendo necesario el uso de syscall(2).

DESCRIPCIÓN

socketcall() es un punto de entrada común del kernel para las llamadas al sistema de sockets. call determina qué función de socket invocar. args apunta a un bloque que contiene los argumentos reales, los cuales se pasan a la llamada apropiada.

Los programas de usuario deben llamar a las funciones apropiadas por sus nombres habituales. Solo los implementadores de la biblioteca estándar y los programadores del kernel necesitan conocer socketcall().

VERSIÓNES

En algunas arquitecturas —por ejemplo, x86-64 y ARM— no existe la llamada al sistema socketcall(); en su lugar, socket(2), accept(2), bind(2), etc., se implementan realmente como llamadas al sistema separadas.

ESTÁNDARES

Linux.

En x86-32, socketcall() era históricamente el único punto de entrada para la API de sockets. Sin embargo, a partir de Linux 4.3, se proporcionan llamadas al sistema directas en x86-32 para la API de sockets. Esto facilita la creación de filtros seccomp(2) que filtran las llamadas al sistema de sockets (para binarios de espacio de usuario nuevos compilados para usar los nuevos puntos de entrada) y también proporciona una mejora de rendimiento (muy pequeña).
