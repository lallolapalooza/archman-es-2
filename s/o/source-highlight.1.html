SOURCE-HIGHLIGHT(1) Comandos de usuario SOURCE-HIGHLIGHT(1)

NOMBRE

Source-highlight - convierte código fuente a documento con resaltado de sintaxis

SINOPSIS

source-highlight [OPCIONES]... < ARCHIVO_ENTRADA > ARCHIVO_SALIDA

DESCRIPCIÓN

GNU GNU source-highlight 3.1.9

Resalta la sintaxis de un archivo fuente (ej. Java) a un formato específico (ej. HTML)

source-highlight [OPCIONES]... -i ARCHIVO_ENTRADA -o ARCHIVO_SALIDA source-highlight [OPCIONES]... [ARCHIVOS]...
-h, --help
Imprime la ayuda y sale
--detailed-help
Imprime la ayuda, incluyendo todos los detalles y opciones ocultas, y sale
-V, --version
Imprime la versión y sale
-i, --input=NOMBRE_ARCHIVO
Archivo de entrada (predeterminado=stdin)
-o, --output=NOMBRE_ARCHIVO
Archivo de salida (predeterminado=stdout, cuando se usa la tercera forma de invocación). Si se especifica 'STDOUT', la salida se dirige a la salida estándar

Puede simplemente especificar algunos archivos en la línea de comandos y también usar expresiones regulares (por ejemplo *.java). En este caso, el nombre para los archivos de salida se formará usando el nombre del archivo fuente con una extensión .EXT añadida, donde EXT es la extensión elegida según el formato de salida especificado (por ejemplo .html).

-s, --src-lang=CADENA
idioma fuente (use --lang-list para obtener la lista completa). Si no se especifica, el idioma fuente se adivinará a partir de la extensión del archivo.
--lang-list
lista todos los idiomas soportados y el archivo de definición de idioma asociado
--outlang-list
lista todos los idiomas de salida soportados y el archivo de definición de idioma asociado
-f, --out-format=CADENA
formato de salida (use --outlang-list para obtener la lista completa) (predeterminado=`html')
-d, --doc
crea un archivo de salida que puede ser utilizado como un documento independiente (ej. no ser incluido en otro)
--no-doc
cancela la opción --doc incluso si está implícita (ej. cuando se proporciona css)
-c, --css=NOMBRE_ARCHIVO
el nombre del archivo de hoja de estilo externa. Implica --doc
-T, --title=CADENA
asigna un título al documento de salida. Implica --doc
-t, --tab=INT
especifica la longitud de la tabulación. (predeterminado=`8')
-H, --header=NOMBRE_ARCHIVO
archivo a insertar como encabezado
-F, --footer=NOMBRE_ARCHIVO
archivo a insertar como pie de página
--style-file=NOMBRE_ARCHIVO
especifica el archivo que contiene las opciones de formato (predeterminado=`default.style')
--style-css-file=NOMBRE_ARCHIVO especifica el archivo que contiene las opciones de formato (en
sintaxis css)
--style-defaults=NOMBRE_ARCHIVO especifica el archivo que contiene los valores predeterminados para las opciones de formato
(predeterminado=`style.defaults')
--outlang-def=NOMBRE_ARCHIVO
archivo de definición de idioma de salida
--outlang-map=NOMBRE_ARCHIVO
archivo de mapa de idioma de salida (predeterminado=`outlang.map')
--data-dir=RUTA
directorio donde se buscan los archivos de definición de idioma y los mapas de idioma. Si no se especifica, estos archivos se buscan en el directorio actual y en el directorio de instalación de datos
--output-dir=RUTA
directorio de salida
--lang-def=NOMBRE_ARCHIVO
archivo de definición de idioma
--lang-map=NOMBRE_ARCHIVO
archivo de mapa de idioma (predeterminado=`lang.map')
--show-lang-elements=NOMBRE_ARCHIVO
imprime los elementos del idioma que están definidos
en el archivo de definición de idioma
--infer-lang
forzar la inferencia del idioma del script fuente (anulando la especificación del idioma dada)

Líneas:

-n, --line-number[=RELLENO]
numera todas las líneas de salida, usando el carácter de relleno especificado (predeterminado=`0')
--line-number-ref[=PREFIJO]
numera todas las líneas de salida y genera un ancla,
hecha del prefijo especificado + el número
de línea (predeterminado=`line')

Filtrado de salida:

Modo: rangos de línea
especificando rangos de línea
--line-range=CADENA
genera solo las líneas en el rango(s) especificado(s)
--range-separator=CADENA
el separador opcional a imprimir entre rangos (ej., "...")
--range-context=INT
número de líneas (de contexto) generadas incluso si no están en el rango
Modo: rangos de expresiones regulares
especificando rangos delimitados por expresiones regulares
--regex-range=CADENA
genera solo las líneas dentro de las expresiones regulares especificadas

generación de referencias:

--gen-references=CADENA
genera referencias (valores posibles="inline", "postline", "postdoc" predeterminado=`inline')
--ctags-file=NOMBRE_ARCHIVO
especifica el archivo generado por ctags que se usará para generar referencias (predeterminado=`tags')
--ctags=CMD
cómo ejecutar el comando ctags. Si esta opción no se especifica, ctags se ejecutará con el valor predeterminado. Si se especifica con una cadena vacía, ctags no se ejecutará en absoluto (predeterminado=`ctags --excmd=n --tag-relative=yes')

pruebas:

-v, --verbose
modo detallado activado
-q, --quiet
no imprime información de progreso
--binary-output
escribe los archivos de salida en modo binario
--statistics
imprime algunas estadísticas (ej. tiempo transcurrido)
--gen-version
inserta la versión de source-highlight en el archivo generado (predeterminado=activado)
--check-lang=NOMBRE_ARCHIVO
solo verifica la corrección de un archivo de definición de idioma
--check-outlang=NOMBRE_ARCHIVO
solo verifica la corrección de un archivo de definición de idioma de salida
--failsafe
si no se encuentra una definición de idioma para la entrada, simplemente se copia a la salida
-g, --debug-langdef[=TIPO]
depurar una definición de idioma. En modo volcado, simplemente vuelca todos los pasos; en modo interactivo, en cada paso, espera alguna entrada (presiona ENTER para avanzar) (valores posibles="interactivo", "volcado" por defecto=`volcado')
--show-regex=NOMBRE_ARCHIVO
mostrar el autómata de expresión regular correspondiente a un archivo de definición de idioma
