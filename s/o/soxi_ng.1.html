NOMBRE

SoXI_ng - Información de Sound eXchange, muestra metadatos de archivos de sonido

SINOPSIS

soxi_ng [-V[nivel]] [-T] [-t|-r|-c|-s|-d|-D|-b|-B|-p|-e|-a] archivo_entrada1 ...

DESCRIPCIÓN

Muestra información de la cabecera de uno o varios archivos de audio. Los tipos de archivos de audio soportados se listan y describen en soxformat_ng(7). Tenga en cuenta, sin embargo, que soxi_ng está diseñado para usarse solo con archivos de audio con una cabecera autoexplicativa.

Por defecto, se muestra tanta información como está disponible. Se puede dar una opción para seleccionar solo una pieza de información (quizás para usarla en un script o archivo por lotes).

OPCIONES

-V
Establece la verbosidad. Ver sox_ng(1) para detalles.
-T
Usado con múltiples archivos; cambia el comportamiento de -s, -d y -D para mostrar el total en todos los archivos dados. Tenga en cuenta que cuando se usa con -s con archivos con diferentes tasas de muestreo, esto tiene un valor cuestionable.
-t
Muestra el tipo de archivo detectado.
-r
Muestra la tasa de muestreo.
-c
Muestra el número de canales.
-s
Muestra el número de muestras (0 si no está disponible).
-d
Muestra la duración en horas, minutos y segundos (0 si no está disponible). Equivalente al número de muestras dividido por la tasa de muestreo.
-D
Muestra la duración en segundos (0 si no está disponible).
-b
Muestra el número de bits por muestra (0 si no aplica).
-B
Muestra la tasa de bits promediada sobre todo el archivo (0 si no está disponible).
-p
Muestra la precisión de muestra estimada en bits.
-e
Muestra el nombre de la codificación de audio.
-a
Muestra los comentarios del archivo (anotaciones) si están disponibles.
