Propósito:

!>
!> SORCSD calcula la descomposición CS de una matriz ortogonal particionada X de M por M:
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**T
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  S  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 es P por Q. Las matrices ortogonales U1, U2, V1 y V2 son P por P,
!> (M-P) por (M-P), Q por Q y (M-Q) por (M-Q) respectivamente. C y S son
!> matrices diagonales no negativas R por R que satisfacen C^2 + S^2 = I,
!> en las que R = MIN(P,M-P,Q,M-Q).
!>

!>          = 'Y':      Se calcula U1;
!>          de lo contrario:  No se calcula U1.
!>

!>          JOBU2 es CHARACTER
!>          = 'Y':      Se calcula U2;
!>          de lo contrario:  No se calcula U2.
!>

JOBV1T

!>          JOBV1T es CHARACTER
!>          = 'Y':      Se calcula V1T;
!>          de lo contrario:  No se calcula V1T.
!>

JOBV2T

!>                      principal (row-major);

sorcsd — Computes the complete CS decomposition of a general matrix pair.

Function/Subroutine Documentation

SORCSD computes the complete CS decomposition of a general matrix pair (A, B).

The matrix A is M-by-N and B is M-by-N.

This is a blocked version of the algorithm. For details of the algorithm and further information, see Sutton (2009).

The CS decomposition is defined as:

A = Q * [ A11 | A12 ] * ZH
          [  0  |  A22 ]

B = Q * [ B11 | B12 ] * ZH
          [  0  | B22 ]

where Q and Z are unitary matrices, and A11, A12, A22, B11, B12, B22 are matrices of appropriate dimensions.

The matrices A11, B11 and A22, B22 are upper triangular and lower triangular respectively. The diagonal elements of the diagonal blocks (A11, B11) and (A22, B22) are related by:

A11H A11 + B11H B11 = I
A22H A22 + B22H B22 = I

The function is defined as:

INTEGER FUNCTION SORCSD( JOBU, JOBV, M, N, A, LDA, B, LDB, RWORK, LDWORK,
                         Q, LDQ, Z, LDZ, INFO )

Arguments:

JOBU
INTEGER. Specifies whether to compute the matrix Q.
JOBU = 1: The unitary matrix Q is computed.
JOBU = 0: Q is not computed.
JOBV
INTEGER. Specifies whether to compute the matrix Z.
JOBV = 1: The unitary matrix Z is computed.
JOBV = 0: Z is not computed.
M
INTEGER. The number of rows of the matrices A and B.
N
INTEGER. The number of columns of the matrices A and B.
A
DOUBLE PRECISION array, dimension (LDA,N).
On entry, the M-by-N matrix A.
On exit, the upper trapezoidal matrix [A11 A12].
LDA
INTEGER. The leading dimension of the array A.
B
DOUBLE PRECISION array, dimension (LDB,N).
On entry, the M-by-N matrix B.
On exit, the upper trapezoidal matrix [B11 B12].
LDB
INTEGER. The leading dimension of the array B.
RWORK
DOUBLE PRECISION array, dimension (LDWORK, N).
On exit, RWORK contains the Schur indices, which form the CS decomposition.
LDWORK
INTEGER. The leading dimension of the array RWORK.
Q
DOUBLE PRECISION array, dimension (LDQ,M) if JOBU = 1.
On exit, if JOBU = 1, Q is an M-by-M unitary matrix such that
A*Z = Q*A' and B*Z = Q*B', where A' and B' are upper trapezoidal.
LDQ
INTEGER. The leading dimension of the array Q.
Z
DOUBLE PRECISION array, dimension (LDZ,N) if JOBV = 1.
On exit, if JOBV = 1, Z is an N-by-N unitary matrix.
LDZ
INTEGER. The leading dimension of the array Z.
INFO
INTEGER.
INFO = 0: successful exit.
INFO < 0: if INFO = -i, the i-th argument had an illegal value.
INFO > 0: SBBCSD did not converge. See the description of WORK above for details.

References:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
