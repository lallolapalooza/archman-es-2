source::encoding(3perl) Guía de referencia del programador de Perl source::encoding(3perl)

NOMBRE

source::encoding -- Declara la codificación del código fuente de Perl

SINOPSIS

use source::encoding 'ascii';
use source::encoding 'utf8';
no source::encoding;

DESCRIPCIÓN

Hoy en día, el código de Perl o bien contiene generalmente solo caracteres ASCII con escapes como "\x{}" y similares para representar caracteres no ASCII, o bien se usa "use utf8" para indicar que el código fuente en sí contiene caracteres codificados como UTF-8.

Eso significa que un carácter en el código fuente que no cumpla estos criterios suele ser un error tipográfico. Este pragma se usa para indicar a Perl que genere un error cuando esto ocurra.

"use source::encoding 'utf8'" es un sinónimo de "use utf8". Pueden ser usados indistintamente.

"use source::encoding 'ascii'" desactiva cualquier expectativa de UTF-8, y genera un error fatal si algún carácter dentro de su ámbito en el código fuente de entrada no es ASCII (o equivalente a ASCII en sistemas EBCDIC).

"no source::encoding" desactiva cualquier expectativa de UTF-8/ASCII para el resto de su ámbito. El significado de los caracteres no ASCII queda entonces indefinido.

"use source::encoding 'ascii'" se activa automáticamente dentro del ámbito léxico de un "use v5.41.0" o superior.
