SOCKLIST(8) Manual del sistema Linux SOCKLIST(8)

NOMBRE

socklist - muestra una lista de sockets abiertos

SINOPSIS

socklist

DESCRIPCIÓN

socklist es un script de Perl que te proporciona una lista de todos los sockets abiertos, enumerando tipos, puerto, inodo, uid, pid, fd y el programa al que pertenece.

OPCIONES

Ninguna.

ARCHIVOS

/proc/*/fd/*
Descriptores de archivo.
/proc/net/tcp
Lista de sockets TCP.
/proc/net/udp
Lista de sockets UDP.
/proc/net/raw
Lista de sockets raw.

ERRORES

Ninguno hasta ahora.

VER TAMBIÉN

procinfo(8), netstat(8).
