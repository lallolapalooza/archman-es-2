subrutina sorbdb (character trans, character signs, integer m, integer p, integer q, real, dimension( ldx11, * ) x11, integer ldx11, real, dimension( ldx12, * ) x12, integer ldx12, real, dimension( ldx21, * ) x21, integer ldx21, real, dimension( ldx22, * ) x22, integer ldx22, real, dimension( * ) theta, real, dimension( * ) phi, real, dimension( * ) taup1, real, dimension( * ) taup2, real, dimension( * ) tauq1, real, dimension( * ) tauq2, real, dimension( * ) work, integer lwork, integer info)

SORBDB

Propósito:

!>
!> SORBDB bidiagonaliza simultáneamente los bloques de una matriz ortogonal
!> X de M por M particionada:
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**T
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0  0  I ]
!>
!> X11 es P por Q. Q no debe ser mayor que P, M-P, o M-Q. (Si esto
!> no es el caso, entonces X debe ser transpuesta y/o permutada. Esto puede
!> hacerse en tiempo constante usando las opciones TRANS y SIGNS. Ver SORCSD
!> para más detalles.)
!>
!> Las matrices ortogonales P1, P2, Q1 y Q2 son P por P, (M-P) por
!> (M-P), Q por Q, y (M-Q) por (M-Q), respectivamente. Están
!> representadas implícitamente por vectores de Householder.
!>
!> B11, B12, B21 y B22 son matrices bidiagonales Q por Q representadas
!> implícitamente por los ángulos THETA, PHI.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER
!>          = 'T':      X, U1, U2, V1T, y V2T se almacenan en orden de fila;
!>          de lo contrario:  X, U1, U2, V1T, y V2T se almacenan en orden de columna.
!>

SIGNS

!>          SIGNS es CHARACTER
!>          = 'O':      El bloque inferior izquierdo se hace no positivo (la
!>                       convención);
!>          de lo contrario:  El bloque superior derecho se hace no positivo (la
!>                       convención).
!>

M

!>          M es INTEGER
!>          El número de filas y columnas en X.
!>

P

!>          P es INTEGER
!>          El número de filas en X11 y X12. 0 <= P <= M.
!>

Q

!>          Q es INTEGER
!>          El número de columnas en X11 y X21. 0 <= Q <=
!>          MIN(P,M-P,M-Q).
!>

X11

!>          X11 es un array REAL, de dimensión (LDX11,Q)
!>          En la entrada, el bloque superior izquierdo de la matriz ortogonal a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las columnas de tril(X11) especifican los reflectores para P1,
!>             las filas de triu(X11,1) especifican los reflectores para Q1;
!>          si no, TRANS = 'T', y
!>             las filas de triu(X11) especifican los reflectores para P1,
!>             las columnas de tril(X11,-1) especifican los reflectores para Q1.
!>

LDX11

!>          LDX11 es INTEGER
!>          La dimensión principal de X11. Si TRANS = 'N', entonces LDX11 >=
!>          P; si no, LDX11 >= Q.
!>

X12

!>          X12 es un array REAL, de dimensión (LDX12,M-Q)
!>          En la entrada, el bloque superior derecho de la matriz ortogonal a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las filas de triu(X12) especifican los primeros P reflectores para
!>             Q2;
!>          si no, TRANS = 'T', y
!>             las columnas de tril(X12) especifican los primeros P reflectores
!>             para Q2.
!>

LDX12

!>          LDX12 es INTEGER
!>          La dimensión principal de X12. Si TRANS = 'N', entonces LDX12 >=
!>          P; si no, LDX11 >= M-Q.
!>

X21

!>          X21 es un array REAL, de dimensión (LDX21,Q)
!>          En la entrada, el bloque inferior izquierdo de la matriz ortogonal a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las columnas de tril(X21) especifican los reflectores para P2;
!>          si no, TRANS = 'T', y
!>             las filas de triu(X21) especifican los reflectores para P2.
!>

LDX21

!>          LDX21 es INTEGER
!>          La dimensión principal de X21. Si TRANS = 'N', entonces LDX21 >=
!>          M-P; si no, LDX21 >= Q.
!>

X22

!>          X22 es un array REAL, de dimensión (LDX22,M-Q)
!>          En la entrada, el bloque inferior derecho de la matriz ortogonal a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las filas de triu(X22(Q+1:M-P,P+1:M-Q)) especifican los últimos
!>             M-P-Q reflectores para Q2,
!>          si no, TRANS = 'T', y
!>             las columnas de tril(X22(P+1:M-Q,Q+1:M-P)) especifican los últimos
!>             M-P-Q reflectores para P2.
!>

LDX22

!>          LDX22 es INTEGER
!>          La dimensión principal de X22. Si TRANS = 'N', entonces LDX22 >=
!>          M-P; si no, LDX22 >= M-Q.
!>

THETA

!>          THETA es un array REAL, de dimensión (Q)
!>          Las entradas de los bloques bidiagonales B11, B12, B21, B22 se pueden
!>          calcular a partir de los ángulos THETA y PHI. Ver Detalles Adicionales.
!>

PHI

!>          PHI es un array REAL, de dimensión (Q-1)
!>          Las entradas de los bloques bidiagonales B11, B12, B21, B22 se pueden
!>          calcular a partir de los ángulos THETA y PHI. Ver Detalles Adicionales.
!>

TAUP1

!>          TAUP1 es un array REAL, de dimensión (P)
!>          Los factores escalares de los reflectores elementales que definen
!>          P1.
!>

TAUP2

!>          TAUP2 es un array REAL, de dimensión (M-P)
!>          Los factores escalares de los reflectores elementales que definen
!>          P2.
!>

TAUQ1

!>          TAUQ1 es un array REAL, de dimensión (Q)
!>          Los factores escalares de los reflectores elementales que definen
!>          Q1.
!>

TAUQ2

!>          TAUQ2 es un array REAL, de dimensión (M-Q)
!>          Los factores escalares de los reflectores elementales que definen
!>          Q2.
!>

WORK

!>          WORK es un array REAL, de dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= M-Q.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y ningún mensaje de error
!>          relacionado con LWORK es emitido por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Function/Subroutine Documentation

sorbdb.f

  Purpose
  =======
  SORbdb computes the SVD of a bidiagonal matrix S. The bidiagonal
  matrix S is the matrix computed by the routine SBDSDC.

  Arguments
  =========
  M       (input) INTEGER
          The number of rows of the bidiagonal matrix S. M >= 0.

  N       (input) INTEGER
          The number of columns of the bidiagonal matrix S. N >= 0.

  K       (input) INTEGER
          The number of diagonal blocks. K = min(M,N).

  NB      (input) INTEGER
          The size of the blocks used for the SVD decomposition.
          NB is the block size for the subroutines that compute
          the SVD of a bidiagonal matrix.

  Q       (input) INTEGER
          The number of sweeps to be performed.

  THETA   (output) REAL array, dimension (K)
          The values of THETA(I) used in the computation of the
          bidiagonal blocks.

  PHI     (output) REAL array, dimension (K-1)
          The values of PHI(I) used in the computation of the
          bidiagonal blocks.

  XS      (output) REAL array, dimension (max(M,N))
          This array stores the diagonal elements of the bidiagonal
          matrix S.

  LWORK   (input) INTEGER
          The length of the work array WORK. LWORK >= max(1, K).

  WORK    (workspace) REAL array, dimension (LWORK)

  IWORK   (workspace) INTEGER array, dimension (max(1, K))

  INFO    (output) INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  if INFO = i, the SVD decomposition failed to converge
                on the i-th diagonal block.

  Details
  =======
  The bidiagonal blocks B11, B12, B21, and B22 are represented
  implicitly by angles THETA(1), ..., THETA(Q) and PHI(1), ...,
  PHI(Q-1). B11 and B21 are upper bidiagonal, while B21 and B22 are
  lower bidiagonal. Every entry in each bidiagonal band is a product
  of a sine or cosine of a THETA with a sine or cosine of a PHI. See
  [1] or SORCSD for details.

  P1, P2, Q1, and Q2 are represented as products of elementary
  reflectors. See SORCSD for details on generating P1, P2, Q1, and Q2
  using SORGQR and SORGLQ.

References:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
