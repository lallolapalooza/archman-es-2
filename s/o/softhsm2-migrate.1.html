SOFTHSM2-MIGRATE(1) Manual de comandos generales SOFTHSM2-MIGRATE(1)

NOMBRE

softhsm2-migrate - Herramienta de migración de SoftHSM v1

SINOPSIS

softhsm2-migrate --db ruta --token etiqueta [--pin PIN --no-public-key]

DESCRIPCIÓN

softhsm2-migrate es una herramienta que puede migrar bases de datos de SoftHSM v1 a PKCS#11. El HSM predeterminado es SoftHSM v2, pero puede utilizarse con otras bibliotecas PKCS#11 utilizando la opción --module

OPCIONES

--db ruta
La base de datos de SoftHSM v1 que se va a migrar. La ubicación de la base de datos del token se puede encontrar en el archivo de configuración de SoftHSM v1.
--help, -h
Mostrar la información de ayuda.
--module ruta
Usar otra biblioteca PKCS#11 que no sea SoftHSM.
--no-public-key
No migrar la clave pública.
--pin PIN
El PIN para el usuario normal.
--serial número
Usará el token con un número de serie coincidente.
--slot número
La base de datos se migrará a esta ranura.
--token etiqueta
Usará el token con una etiqueta de token coincidente.
--version, -v
Mostrar la información de la versión.

EJEMPLO

Una base de datos de token se puede migrar con el siguiente comando:

softhsm2-migrate --db /home/usuario/token.db --token mibanco
