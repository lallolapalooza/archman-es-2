SOFTHSM2-KEYCONV(1) Manual de Comandos Generales SOFTHSM2-KEYCONV(1)

NOMBRE

softhsm2-keyconv - conversión de BIND a formato de archivo de clave PKCS#8

SINOPSIS

softhsm2-keyconv --in ruta --out ruta [--pin PIN]

DESCRIPCIÓN

softhsm2-keyconv puede convertir archivos BIND .private-key al formato de archivo PKCS#8. Esto permite importar el archivo PKCS#8 a libsofthsm usando el comando softhsm2-util. Si tienes otro formato de archivo, entonces openssl probablemente pueda ayudarte a convertirlo al formato de archivo PKCS#8.

OPCIONES

--help, -h Muestra la pantalla de ayuda.

--in ruta
La ruta al archivo de entrada.
--out ruta
La ruta al archivo de salida.
--pin PIN
El PIN se usará para cifrar el archivo PKCS#8. Si no se proporciona, el archivo PKCS#8 no estará cifrado.
--version, -v
Muestra la información de la versión.

EJEMPLOS

El siguiente comando se puede usar para convertir un archivo BIND .private-key a un archivo PKCS#8:

softhsm2-keyconv --in Kexample.com.+007+05474.private \
--out rsa.pem
