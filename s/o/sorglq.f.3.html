DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine sorglq (integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SORGLQ

Propósito:

!>
!> SORGLQ genera una matriz real M-por-N, Q, con filas ortonormales,
!> que se define como las primeras M filas de un producto de K reflectores
!> elementales de orden N
!>
!>       Q  =  H(k) . . . H(2) H(1)
!>
!> tal como lo devuelve SGELQF.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz Q. N >= M.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. M >= K >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          A la entrada, la fila i debe contener el vector que define
!>          el reflector elemental H(i), para i = 1,2,...,k, tal como lo
!>          devuelve SGELQF en las primeras k filas de su array argumento A.
!>          A la salida, la matriz M-por-N, Q.
!>

LDA

!>          LDA es ENTERO
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array REAL, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como lo devuelve SGELQF.
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK. LWORK >= max(1,M).
!>          Para un rendimiento óptimo, LWORK >= M*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array
!>          WORK, devuelve este valor como la primera entrada del array
!>          WORK y XERBLA no emite ningún mensaje de error relacionado con
!>          LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i tiene un valor ilegal
!>
