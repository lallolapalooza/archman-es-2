SOCKD(8) Manual del Administrador del Sistema SOCKD(8)

NOMBRE

sockd - servidor proxy de red

SINOPSIS

sockd [-DLVdhnv] [-N número] [-f archivo] [-p archivo]

DESCRIPCIÓN

Dante implementa el estándar socks y puede funcionar como un firewall entre redes.

Dante reenvía TCP y UDP tanto desde fuera de la red como hacia adentro, y desde adentro hacia afuera.

Las opciones son las siguientes:

-D
Dante se desvinculará de la terminal de control y se ejecutará en segundo plano como un demonio del sistema.
-L
Muestra la licencia bajo la cual se distribuye Dante.
-Nnúmero
Dante creará número "servidores principales" al iniciar. Esto puede usarse para servidores muy ocupados, o para proporcionar una configuración de redundancia (muy) rudimentaria, ya que Dante intentará que estos "servidores principales" sean lo más independientes posible entre sí. Es poco probable que establecer este número a algo mayor que el número de CPUs mejore el rendimiento.
-V
Verifica el archivo de configuración y sale.
-dnúmero
Establece el nivel de depuración, cero para deshabilitar.
-farchivo
Dante leerá su configuración de archivo.
-h
Muestra las opciones válidas actualmente.
-n
Deshabilita los mensajes de keep-alive de TCP. Normalmente, Dante habilita los mensajes de keep-alive de TCP para que las conexiones de máquinas que han fallado o que por otras razones ya no son accesibles expiren. Tenga en cuenta que esto puede tardar varias horas. Vea también la opción "timeout" en sockd.conf(5).
-parchivo
Dante escribirá el PID del proceso principal en este archivo. archivo.
-v
Muestra la versión de Dante.

SEÑALES

SIGHUP
Recarga el archivo de configuración. También reabrirá los archivos de registro.
SIGINFO/SIGUSR1
Imprime información sobre el estado actual del servidor y los clientes.

ENTORNO

TMPDIR
Utiliza TMPDIR para archivos temporales. Dante utilizará este directorio para archivos de bloqueo y archivos mapeados en memoria. Se recomienda que TMPDIR se establezca en un sistema de archivos (local) con baja latencia. El directorio debe tener permisos de lectura/escritura/ejecución tanto para el ID de usuario privilegiado como para el no privilegiado (según se especifica en /etc/sockd.conf), pero no para otros usuarios no privilegiados.

ARCHIVOS

/etc/sockd.conf
Archivo de configuración del servidor Dante.
