NOMBRE

solv - gestor de paquetes de ejemplo basado en libsolv

SINOPSIS

solv install [OPCIONES] PKG...

solv erase [OPCIONES] PKG...

solv list [OPCIONES] PKG...

solv info [OPCIONES] PKG...

solv search [OPCIONES] STRING...

solv verify [OPCIONES] PKG...

solv update [OPCIONES] PKG...

solv dist-upgrade [OPCIONES] PKG...

solv repolist [OPCIONES]

DESCRIPCIÓN

La herramienta solv demuestra algunas características de la biblioteca libsolv. No está diseñada para reemplazar a un gestor de paquetes real, por ejemplo, no almacena en caché los paquetes descargados.

--root ROOTDIR

Instala paquetes usando ROOTDIR como raíz del sistema de archivos. Esto también significa que se utilizará la base de datos de paquetes de ROOTDIR.

--clean

Además, elimina los paquetes que ya no son necesarios al desinstalar, como las bibliotecas que eran utilizadas por los paquetes desinstalados.

--best

Fuerza el uso del mejor paquete (normalmente el de la versión más alta) para las operaciones de instalación y actualización.

--testcase

Escribe un caso de prueba después de resolver las dependencias.

Las siguientes opciones se pueden utilizar para filtrar los paquetes. Si se utiliza la misma opción varias veces, el resultado se combina con un operador OR.

-i

Limita los paquetes a los instalados.

-r REPO

Limita los paquetes al repositorio especificado.

--arch ARQUITECTURA

Limita los paquetes a la arquitectura de paquete especificada.

--type TIPO

Limita los paquetes al tipo de paquete especificado.
