softhsm2.conf(5) Manual de Formatos de Archivo softhsm2.conf(5)

NOMBRE

softhsm2.conf - Archivo de configuración de SoftHSM

SINOPSIS

softhsm2.conf

DESCRIPCIÓN

Este es el archivo de configuración para SoftHSM. Se puede encontrar en una ubicación predeterminada, pero también puede ser reubicado usando la variable de entorno. Cualquier configuración debe hacerse de acuerdo con el formato de archivo que se encuentra en este documento.

FORMATO DEL ARCHIVO

Cada opción de configuración es un par de nombre y valor separados por un signo de igualdad. La opción de configuración debe estar en una sola línea.

<nombre> = <valor>

También es posible agregar comentarios en el archivo usando el signo de almohadilla. Todo lo que esté después del signo de almohadilla será ignorado.

# Un comentario
Se ignorarán las líneas vacías o las líneas que no tengan el formato correcto.

DIRECTORIOS.TOKENDIR

La ubicación donde SoftHSM puede almacenar los tokens.

directories.tokendir = /var/lib/softhsm/tokens/

OBJECTSTORE.BACKEND

El backend a usar por SoftHSM para almacenar objetos de token. Se soporta "file" o "db". Para usar el backend "db", la compilación de SoftHSM debe configurarse con "configure --with-objectstore-backend-db"

objectstore.backend = file

LOG.LEVEL

El nivel de registro que se puede establecer en ERROR, WARNING, INFO o DEBUG.

log.level = INFO

SLOTS.REMOVABLE

Si se establece en true, CKF_REMOVABLE_DEVICE se establecerá en las banderas devueltas por C_GetSlotInfo. El valor predeterminado es false.

slots.removable = true

TOKEN.MECHANISMS

Permite habilitar y deshabilitar cualquiera de los mecanismos PKCS#11 informados en C_GetMechanismList(). La opción acepta un argumento de cadena que contiene la lista separada por comas de todos los algoritmos que deben ser habilitados (no olvides los mecanismos de generación de claves). La lista puede ir precedida por un signo menos "-" para listar solo los mecanismos deshabilitados. Además, la palabra clave especial ALL se puede usar para habilitar todos los mecanismos conocidos (predeterminado). Los mecanismos desconocidos se ignoran. Esta opción tiene mayor prioridad que el atributo CKA_ALLOWED_MECHANISMS en los objetos clave.

slots.mechanisms = ALL

LIBRARY.RESET_ON_FORK

Si se establece en true, la biblioteca reiniciará el estado al hacer fork. El valor predeterminado es false.

library.reset_on_fork = true

ENTORNO

SOFTHSM2_CONF
Cuando se define, el valor se usará como ruta al archivo de configuración.

ARCHIVOS

~/.config/softhsm2/softhsm2.conf
ubicación predeterminada específica del usuario del archivo de configuración de SoftHSM; si existe, anulará la configuración global del sistema
/etc/softhsm2.conf
ubicación predeterminada global del sistema del archivo de configuración de SoftHSM
/etc/softhsm2.conf.sample
un ejemplo de archivo de configuración de SoftHSM
