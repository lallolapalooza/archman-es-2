NOMBRE

source-highlight-settings - utilidad que puede ser utilizada para escribir un archivo de configuración para GNU Source-highlight (y su biblioteca)

SINOPSIS

source-highlight-settings

DESCRIPCIÓN

Desde la versión 3.0, GNU Source-highlight incluye también la utilidad source-highlight-settings, que puede ser utilizada para comprobar si source-highlight podrá encontrar sus archivos de definición de lenguajes, y otros archivos de configuración, y en caso afirmativo, para almacenar la configuración correcta en un archivo de configuración, en el directorio personal del usuario.

En particular, el archivo de configuración almacenado se llamará source-highlight.conf y se guardará en $HOME/.source-highlight/.

Por el momento, este archivo solo almacena el valor por defecto para la opción --data-dir.

Esta utilidad es parte de GNU Source-highlight, mantenida por:
Lorenzo Bettini http://www.lorenzobettini.it
