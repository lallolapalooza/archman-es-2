Documentación de Función/Subrutina

subrutina sorml2 (character side, character trans, integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer info)

SORML2 multiplica una matriz general por la matriz ortogonal de una factorización LQ determinada por sgelqf (algoritmo sin bloques).

Propósito:

!>
!> SORML2 sobrescribe la matriz C general real m por n con
!>
!>       Q * C  si SIDE = 'L' y TRANS = 'N', o
!>
!>       Q**T* C  si SIDE = 'L' y TRANS = 'T', o
!>
!>       C * Q  si SIDE = 'R' y TRANS = 'N', o
!>
!>       C * Q**T si SIDE = 'R' y TRANS = 'T',
!>
!> donde Q es una matriz ortogonal real definida como el producto de k
!> reflectores elementales
!>
!>       Q = H(k) . . . H(2) H(1)
!>
!> tal como es devuelto por SGELQF. Q es de orden m si SIDE = 'L' y de orden n
!> si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**T desde la Izquierda
!>          = 'R': aplicar Q o Q**T desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar Q  (Sin transposición)
!>          = 'T': aplicar Q**T (Transpuesta)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A es un array REAL, de dimensión
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ésima fila debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como es devuelto por
!>          SGELQF en las primeras k filas de su argumento array A.
!>          A es modificado por la subrutina pero restaurado a la salida.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,K).
!>

TAU

!>          TAU es un array REAL, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como es devuelto por SGELQF.
!>

C

!>          C es un array REAL, de dimensión (LDC,N)
!>          A la entrada, la matriz C de m por n.
!>          A la salida, C es sobrescrito por Q*C o Q**T*C o C*Q**T o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array REAL, de dimensión
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
