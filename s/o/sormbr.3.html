Documentación de Función/Subrutina

subroutine sormbr (character vect, character side, character trans, integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer lwork, integer info)

SORMBR

Propósito:

!>
!> Si VECT = 'Q', SORMBR sobrescribe la matriz real general M-por-N C
!> con
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>
!> Si VECT = 'P', SORMBR sobrescribe la matriz real general M-por-N C
!> con
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      P * C          C * P
!> TRANS = 'T':      P**T * C       C * P**T
!>
!> Aquí Q y P**T son las matrices ortogonales determinadas por SGEBRD al
!> reducir una matriz real A a forma bidiagonal: A = Q * B * P**T. Q y
!> P**T se definen como productos de reflectores elementales H(i) y G(i)
!> respectivamente.
!>
!> Sea nq = m si SIDE = 'L' y nq = n si SIDE = 'R'. Por lo tanto, nq es el
!> orden de la matriz ortogonal Q o P**T que se aplica.
!>
!> Si VECT = 'Q', se asume que A ha sido una matriz de NQ-por-K:
!> si nq >= k, Q = H(1) H(2) . . . H(k);
!> si nq < k, Q = H(1) H(2) . . . H(nq-1).
!>
!> Si VECT = 'P', se asume que A ha sido una matriz de K-por-NQ:
!> if k < nq, P = G(1) G(2) . . . G(k);
!> if k >= nq, P = G(1) G(2) . . . G(nq-1).
!>

Parámetros

VECT 
!>          VECT es CHARACTER*1
!>          = 'Q': aplicar Q o Q**T;
!>          = 'P': aplicar P o P**T.
!>

SIDE

!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q, Q**T, P o P**T desde la Izquierda;
!>          = 'R': aplicar Q, Q**T, P o P**T desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplicar Q  o P;
!>          = 'T':  Transpuesta, aplicar Q**T o P**T.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          Si VECT = 'Q', el número de columnas en la matriz original
!>          reducida por SGEBRD.
!>          Si VECT = 'P', el número de filas en la matriz original
!>          reducida por SGEBRD.
!>          K >= 0.
!>

A

!>          A es array REAL, de dimensión
!>                                (LDA,min(nq,K)) si VECT = 'Q'
!>                                (LDA,nq)        si VECT = 'P'
!>          Los vectores que definen los reflectores elementales H(i) y
!>          G(i), cuyos productos determinan las matrices Q y P, como
!>          devuelto por SGEBRD.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si VECT = 'Q', LDA >= max(1,nq);
!>          si VECT = 'P', LDA >= max(1,min(nq,K)).
!>

TAU

!>          TAU es array REAL, de dimensión (min(nq,K))
!>          TAU(i) debe contener el factor escalar del reflector elemental
!>          H(i) o G(i) que determina Q o P, como devuelto
!>          por SGEBRD en el argumento de array TAUQ o TAUP.
!>

C

!>          C es array REAL, de dimensión (LDC,N)
!>          En la entrada, la matriz C de M-por-N.
!>          En la salida, C se sobrescribe con Q*C o Q**T*C o C*Q**T o C*Q
!>          o P*C o P**T*C o C*P o C*P**T.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N);
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Para un rendimiento óptimo LWORK >= N*NB si SIDE = 'L', y
!>          LWORK >= M*NB si SIDE = 'R', donde NB es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>
