NOMBRE

socketmap_table - Cliente de consulta de tabla socketmap de Postfix

SINOPSIS

postmap -q "cadena" socketmap:inet:host:puerto:nombre
postmap -q "cadena" socketmap:unix:rutadeacceso:nombre
postmap -q - socketmap:inet:host:puerto:nombre <archivoentrada
postmap -q - socketmap:unix:rutadeacceso:nombre <archivoentrada

DESCRIPCIÓN


El sistema de correo Postfix utiliza tablas opcionales para la reescritura de direcciones, el enrutamiento de correo o la búsqueda de políticas.

El cliente socketmap de Postfix espera nombres de puntos finales TCP del tipo inet:host:puerto:nombre, o puntos finales de dominio UNIX del tipo unix:rutadeacceso:nombre. En ambos casos, nombre especifica el campo de nombre en una solicitud de cliente socketmap (ver "FORMATO DE SOLICITUD" abajo).

PROTOCOLO

Socketmaps utiliza un protocolo simple: el cliente envía una solicitud y el servidor envía una respuesta. Cada solicitud y cada respuesta se envían como un único objeto netstring.

FORMATO DE SOLICITUD

El protocolo socketmap solo admite la solicitud de búsqueda. La solicitud tiene el siguiente formato:

nombre <espacio> clave
Busca en el socketmap con nombre la clave especificada.

Postfix no generará claves de búsqueda parciales como nombres de dominio sin uno o más subdominios, direcciones de red sin uno o más octetos menos significativos, o direcciones de correo electrónico sin la parte local, la extensión de dirección o la porción de dominio. Este comportamiento también se encuentra con las tablas cidr:, pcre: y regexp:.

FORMATO DE RESPUESTA

Las respuestas deben tener el siguiente formato:

OK <espacio> datos
Se encontraron los datos solicitados.
NOTFOUND <espacio>
No se encontraron los datos solicitados.
TEMP <espacio> razón
TIMEOUT <espacio> razón
PERM <espacio> razón
La solicitud falló. La razón, si no está vacía, es texto descriptivo.

LIMITES DEL PROTOCOLO

El cliente socketmap de Postfix requiere que las respuestas no superen los 100000 bytes (sin incluir la encapsulación netstring). Este límite se puede cambiar con el parámetro de configuración socketmap_max_reply_size (Postfix 3.10 y posteriores).

El cliente socketmap de Postfix aplica un límite de tiempo de 100s para conectarse a un servidor socketmap, para enviar una solicitud y para recibir una respuesta. Cierra una conexión inactiva después de 10s y cierra una conexión activa después de 100s. Estos límites no son (todavía) configurables.

SEGURIDAD

Este mapa no se puede utilizar para información sensible de seguridad, ya que ni la conexión ni el servidor están autenticados.

PARAMETROS DE CONFIGURACIÓN

socketmap_max_reply_size (100000)
El tamaño máximo permitido de respuesta de un servidor socketmap, sin incluir la encapsulación netstring.
