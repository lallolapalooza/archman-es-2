Documentación de Función/Subrutina

subroutine sorgbr (character vect, integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SORGBR

Propósito:

!>
!> SORGBR genera una de las matrices ortogonales reales Q o P**T
!> determinadas por SGEBRD al reducir una matriz real A a su forma bidiagonal:
!> A = Q * B * P**T. Q y P**T se definen como productos de
!> reflectores elementales H(i) o G(i) respectivamente.
!>
!> Si VECT = 'Q', se asume que A ha sido una matriz M-por-K, y Q
!> es de orden M:
!> si m >= k, Q = H(1) H(2) . . . H(k) y SORGBR devuelve las primeras n
!> columnas de Q, donde m >= n >= k;
!> si m < k, Q = H(1) H(2) . . . H(m-1) y SORGBR devuelve Q como una
!> matriz M-por-M.
!>
!> Si VECT = 'P', se asume que A ha sido una matriz K-por-N, y P**T
!> es de orden N:
!> si k < n, P**T = G(k) . . . G(2) G(1) y SORGBR devuelve las primeras m
!> filas de P**T, donde n >= m >= k;
!> si k >= n, P**T = G(n-1) . . . G(2) G(1) y SORGBR devuelve P**T como
!> una matriz N-por-N.
!>

Parámetros

VECT 
!>          VECT es CHARACTER*1
!>          Especifica si se requiere la matriz Q o la matriz P**T,
!>          tal como se define en la transformación aplicada por SGEBRD:
!>          = 'Q':  generar Q;
!>          = 'P':  generar P**T.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz Q o P**T a devolver.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Q o P**T a devolver.
!>          N >= 0.
!>          Si VECT = 'Q', M >= N >= min(M,K);
!>          si VECT = 'P', N >= M >= min(N,K).
!>

K

!>          K es INTEGER
!>          Si VECT = 'Q', el número de columnas de la matriz original M-por-K
!>          reducida por SGEBRD.
!>          Si VECT = 'P', el número de filas de la matriz original K-por-N
!>          reducida por SGEBRD.
!>          K >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, los vectores que definen los reflectores elementales,
!>          tal como son devueltos por SGEBRD.
!>          En la salida, la matriz Q o P**T de M-por-N.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array REAL, de dimensión
!>                                (min(M,K)) si VECT = 'Q'
!>                                (min(N,K)) si VECT = 'P'
!>          TAU(i) debe contener el factor escalar del reflector elemental
!>          H(i) o G(i), que determina Q o P**T, tal como es devuelto
!>          por SGEBRD en su argumento de array TAUQ o TAUP.
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,min(M,N)).
!>          Para un rendimiento óptimo, LWORK >= min(M,N)*NB, donde NB
!>          es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y XERBLA
!>          no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
