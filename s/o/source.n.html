source(n) Comandos integrados de Tcl source(n)

NOMBRE

source - Evaluar un archivo o recurso como un script Tcl

SINOPSIS

source nombreArchivo

source -encoding nombreCodificacion nombreArchivo

DESCRIPCIÓN

Este comando toma el contenido del archivo o recurso especificado y lo pasa al intérprete Tcl como un script de texto. El valor de retorno de source es el valor de retorno del último comando ejecutado en el script. Si ocurre un error al evaluar el contenido del script, el comando source devolverá ese error. Si se invoca un comando return dentro del script, se omitirá el resto del archivo y el comando source retornará normalmente con el resultado del comando return.

El carácter de fin de archivo para los archivos es “\32” (^Z) para todas las plataformas. El comando source leerá archivos hasta este carácter. Esta restricción no existe para los comandos read o gets, lo que permite archivos que contienen segmentos de código y datos (documentos con scripts). Si requiere un “^Z” en el código para comparación de cadenas, puede usar “\032” o “\u001a”, que serán sustituidos de forma segura por el intérprete Tcl por “^Z”.

Una marca de orden de bytes (BOM) inicial contenida en el archivo se ignora para las codificaciones unicode (utf-8, unicode).

La opción -encoding se utiliza para especificar la codificación de los datos almacenados en nombreArchivo. Cuando se omite la opción -encoding, se asume la codificación del sistema.

EJEMPLO

Ejecutar el script en el archivo foo.tcl y luego el script en el archivo bar.tcl:

source foo.tcl
source bar.tcl

Alternativamente:

foreach scriptFile {foo.tcl bar.tcl} {
    source $scriptFile
}
