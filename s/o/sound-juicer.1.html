NOMBRE

sound-juicer - Lector de CDs para el escritorio GNOME y reproductor que utiliza GStreamer

SINOPSIS

sound-juicer [opción...]

DESCRIPCIÓN

sound-juicer es un lector de CDs y reproductor para GNOME que tiene como objetivo tener una interfaz simple, limpia y fácil de usar. sound-juicer soporta la codificación en varios formatos de audio populares como Ogg Vorbis y FLAC, se pueden añadir formatos adicionales a través de plugins de GStreamer.

Para documentación adicional sobre el uso interactivo de sound-juicer, seleccione la opción de menú Ayuda. Los menús permiten acceder a funciones no disponibles a través de las opciones de línea de comandos.

OPCIONES

-a, --iniciar-automáticamente
Comienza a extraer inmediatamente
-p, --reproducir
Comienza a reproducir inmediatamente
-d, --dispositivo=DISPOSITIVO
Qué dispositivo de CD leer
--display=DISPLAY
Pantalla X a usar
-?, --ayuda
Mostrar opciones de ayuda
--ayuda-todo
Mostrar todas las opciones de ayuda
--ayuda-gst
Mostrar Opciones de GStreamer
--ayuda-gtk
Mostrar Opciones de GTK+
--ayuda-activacion-bonobo
Mostrar opciones de Activación Bonobo
--ayuda-gnome
Mostrar opciones de GNOME
--ayuda-sesion-gnome
Mostrar opciones de gestión de sesión
--ayuda-ui-gnome
Mostrar opciones de GUI de GNOME
