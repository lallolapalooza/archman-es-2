FBB::SocketBase(3bobcat) Clase base para sockets FBB::SocketBase(3bobcat)

NOMBRE

FBB::SocketBase - Clase base para clases que construyen sockets

SINOPSIS

#include <bobcat/socketbase>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Esta clase es una clase base para las clases FBB::ServerSocket y FBB::ClientSocket. Dado que está diseñada como una clase base, todos sus constructores son protegidos.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

FBB::InetAddress

CONSTRUCTORES PROTEGIDOS

o
SocketBase(size_t port):
Este constructor crea un SocketBase para ser usado con objetos ServerSocket, escuchando en port.
o
SocketBase(std::string const &host, uint16_t port):
Este constructor crea un FBB::SocketBase para ser usado con un objeto ClientSocket, conectándose al hostname, en el puerto `port’.

Estos constructores lanzan una std::exception si no pueden completarse correctamente.

El constructor de copia y el operador de asignación de copia están disponibles. Ambos ofrecen derechos de acceso protegidos.

MIEMBRO PROTEGIDO

o
SocketBase makeBase(int socket, sockaddr_in const &address):
Este miembro devuelve un objeto FBB::SocketBase inicializando su socket y FBB::InetAddress a partir de los argumentos proporcionados.

FUNCIONES MIEMBRO

Todos los miembros de FBB::InetAddress están disponibles, ya que FBB::SocketBase hereda de esta clase.

o
bool debug() const:
Este accesor devuelve true si la opción de socket debug (SO_DEBUG) del socket está activa. Lanza una excepción FBB::Exception si el estado de la opción de depuración no pudo ser determinado;
o
bool reuse() const:
Este accesor devuelve true si la opción de socket reuse (SO_REUSEADDR) del socket está activa. Lanza una excepción FBB::Exception si el estado de la opción de reutilización no pudo ser determinado;
o
void setDebug(bool trueIsOn) const:
Este miembro puede ser utilizado para modificar la opción de socket debug (SO_DEBUG) del socket. Lanza una excepción FBB::Exception si la opción de depuración del socket no pudo ser modificada;
o
void setReuse(bool trueIsOn) const:
Este miembro puede ser utilizado para modificar la opción de socket reuse (SO_REUSEADDR) del socket. Lanza una excepción FBB::Exception si la opción de reutilización del socket no pudo ser modificada;
o
int socket() const:
Este accesor devuelve el valor del socket del FBB::SocketBase.

EJEMPLO

Las clases FBB::ClientSocket y FBB::ServerSocket se derivaron de SocketBase. Por ejemplo:

#ifndef INCLUDED_BOBCAT_CLIENTSOCKET_
#define INCLUDED_BOBCAT_CLIENTSOCKET_
#include <string>
#include <bobcat/socketbase>
#include <bobcat/exception>
namespace FBB
{
class ClientSocket: public SocketBase
{
    public:
                                // host puede ser dirección o nombre
        ClientSocket(std::string const &host, uint16_t port);
        int connect();          // devuelve el fd (socket) para hablar con el servidor
};
} // FBB
#endif

Ver la página del manual clientsocket(3bobcat) para un ejemplo que muestra cómo usar FBB::ClientSocket.
