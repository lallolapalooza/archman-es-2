solterm(1) Programa IPMI Serial over LAN solterm(1)

NOMBRE

solterm - Un programa IPMI Serial over LAN

SINOPSIS

solterm

<parámetros de conexión> [-e carácter_escape] [-notencrypted] [-notauthenticated] [-bitrate (9600|19200|38400|57600|115200)] [-alerts (succeed|defer|fail)] [-holdoff] [-ack-retries n] [-ack-timeout microsegundos] [-v] [-q]

DESCRIPCIÓN

El programa solterm permite a un usuario establecer una conexión serie remota a través de IPMI. Requiere que el sistema remoto sea compatible con IPMI 2.0 Serial Over LAN.

OPCIONES

<parámetros de conexión>
Los parámetros para la conexión dependen del tipo de conexión. Todos están descritos en openipmi_conparms (7)
-e carácter_escape
El carácter a utilizar para escapar, o salir del programa. Introducir este carácter justo después de una nueva línea hace que el programa entre en modo de comando. Un solo carácter después de esto realiza un comando. El carácter de escape predeterminado es "~" como se muestra a continuación. Los comandos soportados son:
~.
Terminar el programa
~B
Enviar un BREAK serie a través de la conexión
~F
Vaciar todos los búferes
~R
Asegurar la línea Ring Indicator (RI)
~r
Liberar la línea Ring Indicator (RI)
~D
Asegurar las líneas DCD y DSR
~d
Liberar las líneas DCD y DSR
~C
Pausar la salida usando CTS
~c
Poner CTS bajo control del BMC
~?
Ayuda sobre comandos de escape
~~
Introducir el carácter de escape dos veces para enviarlo.
-notencrypted
No cifrar los datos SOL que viajan por la conexión.
-notauthenticated
No realizar comprobaciones de integridad en los datos SOL que viajan por la conexión.
-bitrate
Establecer la velocidad de transmisión al valor dado. El valor predeterminado es el que tenga configurado el BMC.
-alerts
Esto especifica qué hacer si ocurre una alerta que requiere una llamada en la línea.
succeed
especifica que las alertas serie/módem deben tener éxito mientras SoL esté activo.
deferred
especifica que las alertas serie/módem deben ser aplazadas durante la duración de la sesión SoL.
fail
especifica que las alertas serie/módem fallan automáticamente durante la sesión SoL. Este es el valor predeterminado.
-holdoff
Especifica que CTS, DTR y DSR deben ser liberados al inicio de la sesión SoL para que la configuración pueda ser modificada antes de que se libere el handshake.
-v
Ser más detallado. Puede especificarse varias veces para más salida.
-q
Ser menos detallado. Puede especificarse varias veces para menos salida.
