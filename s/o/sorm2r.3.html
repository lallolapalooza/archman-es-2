subrutina sorm2r (side, trans, m, n, k, a, lda, tau, c, ldc, work, info)
SORM2R multiplica una matriz general por la matriz ortogonal de una factorización QR determinada por sgeqrf (algoritmo sin bloques).

Documentación de Función/Subrutina

subrutina sorm2r (character side, character trans, integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer info)

SORM2R multiplica una matriz general por la matriz ortogonal de una factorización QR determinada por sgeqrf (algoritmo sin bloques).

Propósito:

!>
!> SORM2R sobrescribe la matriz real general m por n C con
!>
!>       Q * C  si SIDE = 'L' y TRANS = 'N', o
!>
!>       Q**T* C  si SIDE = 'L' y TRANS = 'T', o
!>
!>       C * Q  si SIDE = 'R' y TRANS = 'N', o
!>
!>       C * Q**T si SIDE = 'R' y TRANS = 'T',
!>
!> donde Q es una matriz ortogonal real definida como el producto de k
!> reflectores elementales
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> tal como devuelve SGEQRF. Q es de orden m si SIDE = 'L' y de orden n
!> si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**T desde la Izquierda
!>          = 'R': aplicar Q o Q**T desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar Q  (Sin transposición)
!>          = 'T': aplicar Q**T (Transpuesta)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A es array REAL, dimension (LDA,K)
!>          La i-ésima columna debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como devuelve
!>          SGEQRF en las primeras k columnas de su array argumento A.
!>          A es modificado por la rutina pero restaurado a la salida.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU es array REAL, dimension (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como devuelve SGEQRF.
!>

C

!>          C es array REAL, dimension (LDC,N)
!>          En la entrada, la matriz m por n C.
!>          En la salida, C es sobrescrito por Q*C o Q**T*C o C*Q**T o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es array REAL, dimension
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
