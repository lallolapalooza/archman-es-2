NOMBRE

sozip - Genera un archivo optimizado para búsqueda (SOZip).

Añadido en la versión 3.7.

SINOPSIS

sozip [--ayuda] [--ayuda-general]
      [--silencioso|--verboso]
      [[-g|--crecer] | [--sobrescribir]]
      [-r|--recursivo-rutas]
      [-j|--descartar-rutas]
      [-l|--listar]
      [--optimizar-desde=<entrada.zip>]
      [--validar]
      [--habilitar-sozip={auto|si|no}]
      [--tamano-bloque-sozip=<valor>]
      [--tamano-min-archivo-sozip=<valor>]
      [--tipo-contenido=<valor>]
      <nombre_archivo_zip> [<nombre_archivo>]...

DESCRIPCIÓN

La utilidad sozip puede usarse para:

  • crear un archivo SOZip (ZIP Optimizado para Búsqueda)
  • añadir archivos a un archivo ZIP/SOZip existente
  • listar el contenido de un archivo ZIP/SOZip
  • validar un archivo SOZip
  • convertir un archivo Zip existente en uno optimizado SOZip
--ayuda
Mostrar este mensaje de ayuda y salir
--ayuda-general
Proporciona un breve mensaje de uso para las opciones de línea de comandos genéricas de GDAL y sale.
--silencioso
Modo silencioso. No se emiten mensajes de progreso en la salida estándar.
--verboso
Modo verboso.
-g
--crecer
Crecer un archivo zip existente con el contenido de los nombres de archivo especificados. Este es el modo predeterminado de la utilidad. Este interruptor está aquí para compatibilidad con la utilidad zip de Info-ZIP
--sobrescribir
Sobrescribir el archivo zip de destino si ya existe.
-l
--listar
Listar los archivos contenidos en el archivo zip en una salida similar a la utilidad unzip de Info-ZIP, pero con la adición de una columna que indica si cada archivo está optimizado para búsqueda.
--validar
Valida un archivo SOZip. La validación de línea base ZIP se realiza de forma ligera, limitada a poder navegar por los registros ZIP con el lector ZIP basado en InfoZIP utilizado por GDAL. Pero la validación de los aspectos específicos de SOZip se realiza de forma más exhaustiva.
-r
--recursivo-rutas
Recorre la estructura de directorios de los directorios especificados recursivamente.
-j
--descartar-rutas
Almacena solo el nombre de un archivo guardado (descarta la ruta) y no almacena los nombres de directorio. Por defecto, sozip almacenará la ruta completa (relativa al directorio actual).
--optimizar-desde=<entrada.zip>
Reprocesa {entrada.zip} para generar un .zip optimizado SOZip. Las opciones --habilitar-sozip, --tamano-bloque-sozip y --tamano-min-archivo-sozip pueden ser utilizadas en ese modo.
--habilitar-sozip={auto|si|no}
En modo auto, un archivo se optimiza para búsqueda solo si su tamaño es superior al valor de --tamano-min-archivo-sozip. En modo si, todos los archivos de entrada se optimizarán para búsqueda. En modo no, ningún archivo de entrada se optimizará para búsqueda.
--tamano-bloque-sozip=<valor>
Tamaño del bloque para un archivo optimizado para búsqueda. Por defecto son 32768 bytes. El valor se especifica en bytes, o se pueden usar los sufijos K y M para especificar un valor en kilo-bytes o mega-bytes, respectivamente.
--tamano-min-archivo-sozip=<valor>
Tamaño mínimo de archivo para decidir si un archivo debe ser optimizado para búsqueda, en el modo --habilitar-sozip=auto. Por defecto son 1 MB. El valor se especifica en bytes, o se pueden usar los sufijos K, M o G para especificar un valor en kilo-bytes, mega-bytes o giga-bytes, respectivamente.
--tipo-contenido=<valor>
Almacena el Tipo de Contenido del archivo que se está añadiendo como un par clave-valor en la extensión del campo extra 'KV' (0x564b) dedicada a almacenar metadatos de pares clave-valor.
<nombre_archivo_zip>
Nombre del archivo zip a crear/añadir/listar.
<nombre_archivo>
Nombre del archivo a añadir.

MULTIHILO

La opción de configuración GDAL_NUM_THREADS puede establecerse en ALL_CPUS o un valor entero para especificar el número de hilos a usar para archivos comprimidos con SOZip. Por defecto es ALL_CPUS.

API C

La funcionalidad de esta utilidad se puede realizar desde C con CPLAddFileInZip() o VSICopyFile().

EJEMPLOS

Crear un archivo ZIP, potencialmente optimizado para búsqueda, con el contenido de my.gpkg:

sozip my.gpkg.zip my.gpkg

Crear un archivo ZIP, potencialmente optimizado para búsqueda, desde el contenido de un directorio fuente:

sozip -r my.gpkg.zip source_dir/

Crear un archivo ZIP, potencialmente optimizado para búsqueda, a partir de un archivo ZIP existente.

sozip --optimizar-desde=entrada.zip salida.zip

Listar el contenido de un archivo ZIP y mostrar qué archivos están optimizados para búsqueda:

sozip -l my.gpkg.zip

Valida un archivo SOZip:

sozip --validar my.gpkg.zip
