DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subroutine sorgqr (integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SORGQR

Propósito:

!>
!> SORGQR genera una matriz real M-por-N, Q, con columnas ortonormales,
!> que se define como las primeras N columnas de un producto de K
!> reflectores elementales de orden M
!>
!>       Q  =  H(1) H(2) . . . H(k)
!>
!> tal como devuelve SGEQRF.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz Q. M >= N >= 0.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. N >= K >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          A la entrada, la i-ésima columna debe contener el vector que
!>          define el reflector elemental H(i), para i = 1,2,...,k, tal como
!>          devuelve SGEQRF en las primeras k columnas de su argumento de
!>          array A.
!>          A la salida, la matriz Q de M-por-N.
!>

LDA

!>          LDA es ENTERO
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array REAL, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como devuelve SGEQRF.
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK. LWORK >= max(1,N).
!>          Para un rendimiento óptimo LWORK >= N*NB, donde NB es el
!>          tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tiene un valor ilegal
!>
