SOFT(1) Un servidor Git auto-hospedado para la línea de comandos SOFT(1)

NOMBRE

soft - Un servidor Git auto-hospedado para la línea de comandos

SINOPSIS

soft [opciones...] [argumento...]

DESCRIPCIÓN

Soft Serve es un servidor Git auto-hospedado para la línea de comandos.

COMANDOS

admin
Administrar el servidor
COMANDOS
migrate
Migrar la base de datos a la última versión
rollback
Revertir la base de datos a la versión anterior
sync-hooks
Actualizar los hooks del repositorio
browse RUTA
Explorar un repositorio
help [comando]
Ayuda sobre cualquier comando
serve
Iniciar el servidor
OPCIONES
--sync-hooks sincronizar los hooks para todos los repositorios antes de ejecutar el servidor
