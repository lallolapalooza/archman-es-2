SYD-AES(1) Manual de Comandos Generales SYD-AES(1)

NOMBRE

syd-aes - Utilidad de cifrado y descifrado AES-CTR

SINOPSIS

syd-aes [-hv] -e|-d -k <serial-clave> -i <iv-hex>

DESCRIPCIÓN

La utilidad syd-aes utiliza la API de Criptografía del Kernel de Linux para cifrar y descifrar datos usando el modo AES-CTR, empleando keyrings(7) para seleccionar la clave de cifrado/descifrado a utilizar sin copiar el material de la clave al espacio de usuario. Soporta tanto operaciones de cifrado como de descifrado, con el serial de la clave proporcionado como un ID de 32 bits y el IV proporcionado como una cadena hexadecimal. Dados los datos de la entrada estándar, syd-aes realiza la operación especificada y genera el resultado en la salida estándar. syd-aes utiliza tuberías y splice(2) para transferir datos mediante copia cero, y por lo tanto, es capaz de cifrar/descifrar archivos de tamaño arbitrario.

OPCIONES

-h Muestra la ayuda.
-v Habilita el modo detallado. Si el error estándar es un terminal, muestra actualizaciones de progreso periódicamente, similar a dd(1).
-e Cifra los datos de entrada.
-d Descifra los datos de entrada.
-k <serial-clave> ID serial de la clave (entero de 32 bits).
La clave del kernel que syd-aes (a través de ALG_SET_KEY_BY_KEY_SERIAL) leerá debe otorgar al llamante permiso de búsqueda -- es decir, tener el(los) bit(s) de permiso KEY_(POS|USR|GRP|OTH)_SEARCH establecido(s) para que el kernel pueda localizar y copiar los datos de la clave a la API de cifrado; de lo contrario, la operación será denegada (EPERM: "Operación no permitida").
-i <iv> IV codificado en hexadecimal (128 bits).
