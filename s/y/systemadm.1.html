NOMBRE

systemadm - Interfaz gráfica para el gestor de sistema y servicios systemd

SINOPSIS

systemadm [OPCIONES...]

DESCRIPCIÓN

systemadm es una interfaz gráfica para el gestor de sistema y servicios systemd que permite la introspección y el control de systemd.

OPCIONES

Se reconocen las siguientes opciones:

--h, --help

Imprime un breve texto de ayuda y sale.

--system

Conecta con el gestor de sistema systemd. (Por defecto)

--user

Conecta con el gestor systemd del usuario que llama.

Además de esto, se admiten una serie de parámetros comunes a todos los programas Gtk+.

VER TAMBIÉN

systemd(1), systemctl(1)
