sys_time.h(0P) Manual del programador POSIX sys_time.h(0P)

PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sys/time.h — tipos de tiempo

SINOPSIS

#include <sys/time.h>

DESCRIPCIÓN

El archivo de cabecera <sys/time.h> definirá la estructura timeval, la cual contendrá al menos los siguientes miembros:

time_t         tv_sec      Segundos.
suseconds_t    tv_usec     Microsegundos.

El archivo de cabecera <sys/time.h> definirá la estructura itimerval, la cual contendrá al menos los siguientes miembros:

struct timeval it_interval Intervalo del temporizador.
struct timeval it_value    Valor actual.

El archivo de cabecera <sys/time.h> definirá los tipos time_t y suseconds_t como se describe en <sys/types.h>.

El archivo de cabecera <sys/time.h> definirá el tipo fd_set como se describe en <sys/select.h>.

El archivo de cabecera <sys/time.h> definirá las siguientes constantes simbólicas para el argumento which de getitimer() y setitimer():

ITIMER_REAL
Decrementa en tiempo real.
ITIMER_VIRTUAL
Decrementa en tiempo virtual del proceso.
ITIMER_PROF
Decrementa tanto en tiempo virtual del proceso como cuando el sistema se ejecuta en nombre del proceso.

El archivo de cabecera <sys/time.h> definirá, como se describe en <sys/select.h>: FD_CLR() FD_ISSET() FD_SET() FD_ZERO() FD_SETSIZE

Lo siguiente se declarará como funciones y también puede definirse como macros. Se proporcionarán prototipos de función.

int   getitimer(int, struct itimerval *);
int   gettimeofday(struct timeval *restrict, void *restrict);
int   setitimer(int, const struct itimerval *restrict,
          struct itimerval *restrict);
int   select(int, fd_set *restrict, fd_set *restrict, fd_set *restrict,
          struct timeval *restrict);
int   utimes(const char *, const struct timeval [2]);

La inclusión del archivo de cabecera <sys/time.h> puede hacer visibles todos los símbolos del archivo de cabecera <sys/select.h>.
