NOMBRE

syndaemon - un programa que monitoriza la actividad del teclado y deshabilita el panel táctil cuando se está usando el teclado.

SINOPSIS

syndaemon [-i tiempo-inactivo] [-m intervalo-sondeo] [-d] [-p archivo-pid] [-t] [-k] [-K] [-R]

DESCRIPCIÓN

Deshabilitar el panel táctil mientras se escribe evita movimientos no deseados del puntero que podrían dar el foco a la ventana incorrecta.

OPCIONES

-i <tiempo-inactivo>
Cuántos segundos esperar después de la última pulsación de tecla antes de habilitar el panel táctil. (el valor por defecto es 2.0s).
-m <intervalo-sondeo>
Cuántos milisegundos esperar entre dos intervalos de sondeo. Si este valor es demasiado bajo, causará despertares innecesarios. Si este valor es demasiado alto, algunas pulsaciones de teclas (pulsar y soltar ocurren entre dos intervalos) podrían no ser detectadas. Este interruptor no tiene efecto cuando se ejecuta con -R. El valor por defecto es 200ms.
-d
Iniciar como un demonio, es decir, en segundo plano.
-p <archivo-pid>
Crear un archivo pid con el nombre de archivo especificado. Un archivo pid solo se creará si el programa se inicia en modo demonio.
-t
Solo deshabilitar el toque y el desplazamiento, no los movimientos del ratón, en respuesta a la actividad del teclado.
-k
Ignorar las teclas modificadoras al monitorizar la actividad del teclado.
-K
Como -k pero también ignorar combinaciones de Modificador+Tecla.
-R
Usar la extensión XRecord para detectar la actividad del teclado en lugar de sondear el estado del teclado.
-?
Mostrar el mensaje de ayuda.

VARIABLES DE ENTORNO

DISPLAY
Especifica el servidor X a contactar.

CÓDIGOS DE SALIDA

Si syndaemon sale con un código de retorno distinto de 0, el error encontrado es el siguiente.

Código de salida 1
Argumento de línea de comandos inválido.
Código de salida 2
No se pudo establecer la conexión con el servidor X o no se encontró ningún dispositivo de panel táctil.
Código de salida 3
Falló la bifurcación al modo demonio o no se pudo crear el archivo pid.
Código de salida 4
Se solicitó XRECORD pero no está disponible o no se puede usar en el servidor.

OBSERVACIONES

No tiene mucho sentido conectarse a un servidor X remoto, porque el demonio monitorizará el servidor remoto para la actividad del teclado, pero deshabilitará el panel táctil en la máquina local.
