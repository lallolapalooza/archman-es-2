SYD-LS(1) Manual de comandos generales SYD-LS(1)

NOMBRE

syd-ls - Listar directorios inseguros, capacidades, llamadas al sistema, variables de entorno, solicitudes ioctl, personalidades y opciones prctl

SINOPSIS

syd-ls [conjunto]

DESCRIPCIÓN

La utilidad syd-ls imprime los nombres de las llamadas al sistema que pertenecen al conjunto dado. Los conjuntos disponibles son cpu, dead, deny, ebpf, futex, hook, nice, noop, pkey, ptrace, safe, setid, time y uring.

Si el conjunto es drop, syd-ls imprime la lista de capabilities(7) de Linux que se descartan al inicio.

Si el conjunto es env, syd-ls imprime la lista de variables de entorno inseguras.

Si el conjunto es ioctl, syd-ls imprime la lista de solicitudes ioctl permitidas.

Si el conjunto es prctl, syd-ls imprime la lista de opciones prctl permitidas.

Si el conjunto es personality, syd-ls imprime la lista de personalidades permitidas.

Si no se proporciona ningún conjunto, syd-ls lista todos los archivos en el directorio de trabajo actual. En este modo, se usa directamente getdents64(2). Úselo para listar archivos en directorios no confiables con un gran número de archivos. Los nombres de archivo se imprimen codificados en hexadecimal, delimitados por saltos de línea; use syd-hex(1) para decodificar. Vea la sección de EJEMPLOS para más información.
