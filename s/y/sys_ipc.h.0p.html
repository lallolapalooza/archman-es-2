NOMBRE

sys/ipc.h — estructura de acceso a la comunicación entre procesos XSI

SINOPSIS

#include <sys/ipc.h>

DESCRIPCIÓN

El encabezado <sys/ipc.h> se utiliza para tres mecanismos de comunicación entre procesos XSI (IPC): mensajes, semáforos y memoria compartida. Todos utilizan un tipo de estructura común, ipc_perm, para pasar información utilizada para determinar el permiso para realizar una operación IPC.

El encabezado <sys/ipc.h> definirá la estructura ipc_perm, que incluirá los siguientes miembros:

uid_t    uid    ID de usuario del propietario.
gid_t    gid    ID de grupo del propietario.
uid_t    cuid   ID de usuario del creador.
gid_t    cgid   ID de grupo del creador.
mode_t   mode   Permiso de lectura/escritura.

El encabezado <sys/ipc.h> definirá los tipos uid_t, gid_t, mode_t y key_t como se describe en <sys/types.h>.

El encabezado <sys/ipc.h> definirá las siguientes constantes simbólicas.

Bits de modo:

IPC_CREAT
Crear entrada si la clave no existe.
IPC_EXCL
Fallar si la clave existe.
IPC_NOWAIT
Error si la solicitud debe esperar.

Claves:

IPC_PRIVATE
Clave privada.

Comandos de control:

IPC_RMID
Eliminar identificador.
IPC_SET
Establecer opciones.
IPC_STAT
Obtener opciones.

Lo siguiente se declarará como una función y también puede definirse como una macro. Se proporcionará un prototipo de función.

key_t  ftok(const char *, int);
