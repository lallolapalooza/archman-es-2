NOMBRE

systemd-sysctl.service, systemd-sysctl - Configurar parámetros del kernel al arrancar

SINOPSIS

/usr/lib/systemd/systemd-sysctl [OPCIONES...] [ARCHIVO_CONFIG...]

systemd-sysctl.service

DESCRIPCIÓN

systemd-sysctl.service es un servicio de arranque temprano que configura parámetros del kernel de sysctl(8) invocando a /usr/lib/systemd/systemd-sysctl.

Cuando se invoca sin argumentos, /usr/lib/systemd/systemd-sysctl aplica todas las directivas de los archivos de configuración listados en sysctl.d(5). Si se pasan uno o más nombres de archivo en la línea de comandos, solo se aplicarán las directivas de esos archivos.

Además, se puede usar la opción --prefix= para limitar qué configuraciones de sysctl se aplican.

Ver sysctl.d(5) para información sobre la configuración de los ajustes de sysctl. Después de que la configuración de sysctl se cambie en el disco, debe escribirse en los archivos en /proc/sys/ antes de que surta efecto. Es posible actualizar configuraciones específicas, o simplemente recargar toda la configuración, ver Ejemplos abajo.

OPCIONES

--prefix=

Solo aplica reglas con el prefijo especificado.

Añadido en la versión 230.

--strict=

Siempre devuelve un código de salida distinto de cero en caso de error (incluyendo nombre de variable sysctl inválido y permisos insuficientes), a menos que el nombre de la variable sysctl esté prefijado con un carácter "-".

Añadido en la versión 252.

--cat-config

Copia el contenido de los archivos de configuración a la salida estándar. Antes de cada archivo, se imprime el nombre del archivo como un comentario.

--tldr

Copia el contenido de los archivos de configuración a la salida estándar. Solo se imprimen las partes "interesantes" de los archivos de configuración, se omiten los comentarios y las líneas vacías. Antes de cada archivo, se imprime el nombre del archivo como un comentario.

--no-pager

No canalizar la salida a un paginador.

-h, --help

Imprime un texto de ayuda corto y sale.

--version

Imprime una cadena de versión corta y sale.

CREDENCIALES

systemd-sysctl soporta la lógica de credenciales del servicio implementada por ImportCredential=/LoadCredential=/SetCredential= (ver systemd.exec(5) para detalles). Las siguientes credenciales se usan cuando se pasan:

sysctl.extra

El contenido de esta credencial puede contener líneas adicionales para operar. El contenido de la credencial debe seguir el mismo formato que cualquier otro archivo de configuración de sysctl.d/. Si se pasa esta credencial, se procesa después de todos los archivos de configuración leídos desde el sistema de archivos. Las configuraciones establecidas en la credencial, por lo tanto, tienen precedencia sobre las del sistema de archivos.

Añadido en la versión 252.

Tenga en cuenta que, por defecto, el archivo de unidad systemd-sysctl.service está configurado para heredar la credencial "sysctl.extra" del gestor del servicio.

EJEMPLOS

Ejemplo 1. Restablecer todas las configuraciones de sysctl

systemctl restart systemd-sysctl

Ejemplo 2. Ver la configuración del manejador de coredump

# sysctl kernel.core_pattern
kernel.core_pattern = |/usr/libexec/abrt-hook-ccpp %s %c %p %u %g %t %P %I

Ejemplo 3. Actualizar la configuración del manejador de coredump

# /usr/lib/systemd/systemd-sysctl --prefix kernel.core_pattern

Esto busca en todos los directorios listados en sysctl.d(5) archivos de configuración y escribe /proc/sys/kernel/core_pattern.

Ejemplo 4. Actualizar la configuración del manejador de coredump según un archivo específico

# /usr/lib/systemd/systemd-sysctl 50-coredump.conf

Esto aplica todas las configuraciones encontradas en 50-coredump.conf. Se utilizará /etc/sysctl.d/50-coredump.conf, o /run/sysctl.d/50-coredump.conf, o /usr/lib/sysctl.d/50-coredump.conf, en orden de preferencia.

Ver sysctl(8) para varias formas de aplicar directamente configuraciones de sysctl.
