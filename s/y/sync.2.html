sync(2) Manual de llamadas al sistema sync(2)

NOMBRE

sync, syncfs - confirmar las cachés del sistema de archivos en disco

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
void sync(void);
int syncfs(int fd);
Requisitos de las macro de prueba de características para glibc (ver feature_test_macros(7)):

sync():

    _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE

syncfs():

    _GNU_SOURCE

DESCRIPCIÓN

sync() hace que todas las modificaciones pendientes a los metadatos del sistema de archivos y a los datos de archivo en caché se escriban en los sistemas de archivos subyacentes.

syncfs() es como sync(), pero sincroniza solo el sistema de archivos que contiene el archivo al que se refiere el descriptor de archivo abierto fd.

VALOR DE RETORNO

syncfs() devuelve 0 si tiene éxito; en caso de error, devuelve -1 y establece errno para indicar el error.

ERRORES

sync() siempre tiene éxito.

syncfs() puede fallar por al menos las siguientes razones:

EBADF
fd no es un descriptor de archivo válido.
EIO
Ocurrió un error durante la sincronización. Este error puede estar relacionado con los datos escritos en cualquier archivo del sistema de archivos, o con metadatos relacionados con el propio sistema de archivos.
ENOSPC
Se agotó el espacio en disco durante la sincronización.
ENOSPC
EDQUOT
Los datos se escribieron en un archivo en NFS u otro sistema de archivos que no asigna espacio en el momento de una llamada al sistema write(2), y una escritura anterior falló debido a espacio de almacenamiento insuficiente.

VERSIONES

Según la especificación estándar (es decir, POSIX.1), sync() programa las escrituras, pero puede devolver antes de que se complete la escritura real. Sin embargo, Linux espera las finalizaciones de E/S, y por lo tanto sync() o syncfs() proporcionan las mismas garantías que fsync() llamado en cada archivo del sistema o del sistema de archivos respectivamente.

ESTÁNDARES

sync()
POSIX.1-2024.
syncfs()
Linux.

HISTORIA

sync()
POSIX.1-2001, SVr4, 4.3BSD.
syncfs()
Linux 2.6.39, glibc 2.14.

Desde glibc 2.2.2, el prototipo de Linux para sync() es el que se muestra arriba, siguiendo los diversos estándares. En glibc 2.2.1 y anteriores, era "int sync(void)", y sync() siempre devolvía 0.

En las versiones principales del kernel anteriores a Linux 5.8, syncfs() fallará solo cuando se le pase un descriptor de archivo inválido (EBADF). Desde Linux 5.8, syncfs() también informará un error si uno o más inodos fallaron en ser escritos desde la última llamada a syncfs().

ERRORES

Antes de Linux 1.3.20, Linux no esperaba a que se completara la E/S antes de devolver.

VER TAMBIÉN

sync(1), fdatasync(2), fsync(2)
