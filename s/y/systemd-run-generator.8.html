SYSTEMD-RUN-GENERATOR(8) systemd-run-generator SYSTEMD-RUN-GENERATOR(8)

NOMBRE

systemd-run-generator - Generador para invocar comandos especificados en la línea de comandos del kernel como servicio del sistema

SINOPSIS

/usr/lib/systemd/system-generators/systemd-run-generator

DESCRIPCIÓN

systemd-run-generator es un generador que lee la línea de comandos del kernel y entiende tres opciones:

Si se especifica la opción systemd.run= seguida de una línea de comandos, se genera una unidad llamada kernel-command-line.service para ella y se arranca. El servicio tiene configurado por defecto Type=oneshot, y SuccessAction=exit y FailureAction=exit, asegurando así que el sistema se apague tan pronto como el comando se complete. El estado de salida del comando se propaga al gestor de contenedores que lo invoca, si corresponde (lo que podría propagarlo más allá, al shell que lo llama — por ejemplo, systemd-nspawn(1) hace esto). Si esta opción se usa varias veces, el archivo de unidad contendrá múltiples líneas ExecStart=, para ejecutar todos los comandos en orden. El comando se inicia como un servicio regular, es decir, con DefaultDependencies= activado.

Use systemd.run_success_action= y systemd.run_failure_action= para ajustar cómo reaccionar a la finalización del proceso. En particular, asignar "none" dejará el sistema en ejecución después de que el comando se complete. Para más detalles sobre los argumentos soportados, ver systemd.unit(5).

systemd-run-generator implementa systemd.generator(7).

EJEMPLO

Use un comando como el siguiente para añadir un usuario a la base de datos de usuarios dentro de un contenedor ejecutado con systemd-nspawn(1):

# systemd-nspawn -D mycontainer -b systemd.run='"adduser test"'

(Tenga en cuenta el requisito de doble comilla en la línea de comandos anterior. El primer nivel de comillas ('') es procesado y eliminado por el shell de comandos utilizado para invocar systemd-nspawn. El segundo nivel de comillas ("") se propaga a la línea de comandos del kernel del contenedor y es procesado y eliminado por systemd-run-generator. Ambos juntos aseguran que ambas palabras de la línea de comandos especificada adduser test terminen juntas en el archivo de unidad generado y no sean divididas ni por el shell de comandos ni por el generador.)
