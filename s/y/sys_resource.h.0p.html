Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sys/resource.h — definiciones para operaciones de recursos XSI

SINOPSIS

#include <sys/resource.h>

DESCRIPCIÓN

El archivo de cabecera <sys/resource.h> definirá las siguientes constantes simbólicas como valores posibles del argumento which de getpriority() y setpriority():

PRIO_PROCESS
Identifica el argumento who como un ID de proceso.
PRIO_PGRP
Identifica el argumento who como un ID de grupo de procesos.
PRIO_USER
Identifica el argumento who como un ID de usuario.

El archivo de cabecera <sys/resource.h> definirá el siguiente tipo mediante typedef:

rlim_t
Tipo entero sin signo utilizado para valores de límite.

El archivo de cabecera <sys/resource.h> definirá las siguientes constantes simbólicas, que tendrán valores adecuados para su uso en directivas de preprocesamiento #if:

RLIM_INFINITY
Un valor de rlim_t que indica sin límite.
RLIM_SAVED_MAX
Un valor de tipo rlim_t que indica un límite estricto guardado no representable.
RLIM_SAVED_CUR
Un valor de tipo rlim_t que indica un límite blando guardado no representable.

En implementaciones donde todos los límites de recursos son representables en un objeto de tipo rlim_t, RLIM_SAVED_MAX y RLIM_SAVED_CUR no necesitan ser distintos de RLIM_INFINITY.

El archivo de cabecera <sys/resource.h> definirá las siguientes constantes simbólicas como valores posibles para el parámetro who de getrusage():

RUSAGE_SELF
Devuelve información sobre el proceso actual.
RUSAGE_CHILDREN
Devuelve información sobre los hijos del proceso actual.

El archivo de cabecera <sys/resource.h> definirá la estructura rlimit, que incluirá al menos los siguientes miembros:

rlim_t rlim_cur  El límite actual (blando).
rlim_t rlim_max  El límite estricto.

El archivo de cabecera <sys/resource.h> definirá la estructura rusage, que incluirá al menos los siguientes miembros:

struct timeval ru_utime  Tiempo de usuario utilizado.
struct timeval ru_stime  Tiempo de sistema utilizado.

El archivo de cabecera <sys/resource.h> definirá la estructura timeval como se describe en <sys/time.h>.

El archivo de cabecera <sys/resource.h> definirá las siguientes constantes simbólicas como valores posibles para el argumento resource de getrlimit() y setrlimit():

RLIMIT_CORE
Límite del tamaño del archivo core.
RLIMIT_CPU
Límite del tiempo de CPU por proceso.
RLIMIT_DATA
Límite del tamaño del segmento de datos.
RLIMIT_FSIZE
Límite del tamaño del archivo.
RLIMIT_NOFILE
Límite del número de archivos abiertos.
RLIMIT_STACK
Límite del tamaño de la pila.
RLIMIT_AS
Límite del tamaño del espacio de direcciones.

Las siguientes se declararán como funciones y también podrán definirse como macros. Se proporcionarán prototipos de función.

int  getpriority(int, id_t);
int  getrlimit(int, struct rlimit *);
int  getrusage(int, struct rusage *);
int  setpriority(int, id_t, int);
int  setrlimit(int, const struct rlimit *);

El archivo de cabecera <sys/resource.h> definirá el tipo id_t mediante typedef, como se describe en <sys/types.h>.

La inclusión del archivo de cabecera <sys/resource.h> también puede hacer visibles todos los símbolos de <sys/time.h>.

sys_resource.h(0p) — Arch manual pages

sys_resource.h(0p)

SYNOPSIS

#include <sys/resource.h>

DESCRIPTION

The sys/resource.h header file defines behavior for routines that get and set resource limits. Resources can be limited per-process or per-child process.

The following resource limits are defined:

RLIMIT_AS
The maximum size of the process's virtual address space in bytes.
RLIMIT_CORE
The maximum size of a core file in bytes that may be created by a process.
RLIMIT_CPU
The maximum amount of CPU time, in seconds, that may be consumed by a process.
RLIMIT_DATA
The maximum size of a process's data segment in bytes.
RLIMIT_FSIZE
The maximum size of a file in bytes that may be created by a process.
RLIMIT_MEMLOCK
The maximum number of bytes of memory that may be locked into RAM.
RLIMIT_MSGQUEUE
The maximum number of bytes that can be allocated for the message queue.
RLIMIT_NICE
The maximum value of the niceness, which determines process priority. The value is restricted to 0 or positive values.
RLIMIT_NOFILE
The maximum number of file descriptors that a process may have open at any given time.
RLIMIT_NPTS
The maximum number of pseudo-terminals (PTYs) that a process may open.
RLIMIT_NPROC
The maximum number of processes that may be created by a child process in the future.
RLIMIT_RSS
The maximum resident set size (physical memory) in bytes.
RLIMIT_RTPRIO
The maximum real-time priority that may be assigned to a process.
RLIMIT_RTTIME
The maximum amount of CPU time, in microseconds, that may be consumed by real-time scheduled processes.
RLIMIT_SIGPENDING
The maximum number of signals that may be pending for a process.
RLIMIT_STACK
The maximum size of the process stack in bytes.

Each resource limit is associated with two values:

rlim_cur
The "soft" limit, which is the value that the system enforces for the corresponding resource.
rlim_max
The "hard" limit, which is the maximum value to which a process can set its soft limit. Only a privileged process can increase the hard limit.

The structure rlimit is defined as:

typedef struct rlimit {
    rlim_t rlim_cur;
    rlim_t rlim_max;
} rlimit_t;

The following functions are provided:

getrlimit(int resource, struct rlimit *rlp)
Gets the resource limits of the calling process.
setrlimit(int resource, const struct rlimit *rlp)
Sets the resource limits of the calling process.

RETURN VALUE

On success, getrlimit() and setrlimit() return 0. On error, they return -1 and set errno to indicate the error.

ERRORS

EFAULT
rlp points outside of the accessible address space.
EINVAL
resource is an unknown resource limit or the soft limit is greater than the hard limit.
EPERM
A non-privileged process tried to increase a hard limit or to decrease a hard limit that was already set.

STANDARDS

The sys/resource.h header and the getrlimit() and setrlimit() functions conform to POSIX.1-2017.
