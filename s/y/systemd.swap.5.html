NOMBRE

systemd.swap - Configuración de unidades de swap

SINOPSIS

swap.swap

DESCRIPCIÓN

Un archivo de configuración de unidad cuyo nombre termina en ".swap" codifica información sobre un dispositivo o archivo de swap para paginación de memoria controlado y supervisado por systemd.

Esta página del manual enumera las opciones de configuración específicas de este tipo de unidad. Consulte systemd.unit(5) para ver las opciones comunes de todos los archivos de configuración de unidades. Los elementos de configuración comunes se configuran en las secciones genéricas [Unit] e [Install]. Las opciones de configuración específicas de swap se configuran en la sección [Swap].

Opciones adicionales se enumeran en systemd.exec(5), que definen el entorno de ejecución en el que se ejecuta el programa swapon(8), en systemd.kill(5), que definen la forma en que se terminan estos procesos, y en systemd.resource-control(5), que configuran los ajustes de control de recursos para estos procesos de la unidad.

Las unidades de swap deben tener nombres basados en los dispositivos o archivos que controlan. Por ejemplo: el dispositivo de swap /dev/sda5 debe configurarse en un archivo de unidad dev-sda5.swap. Para obtener detalles sobre la lógica de codificación utilizada para convertir una ruta de sistema de archivos a un nombre de unidad, consulte systemd.unit(5). Tenga en cuenta que las unidades de swap no se pueden parametrizar, ni es posible añadir nombres adicionales a una unidad de swap creando enlaces simbólicos adicionales a ella.

Tenga en cuenta que el soporte de swap en Linux es privilegiado, por lo tanto, las unidades de swap solo están disponibles en el gestor de servicios del sistema (y en el gestor de servicios del usuario root), pero no en el gestor de servicios de usuarios no privilegiados.

DEPENDENCIAS AUTOMÁTICAS

Dependencias Implícitas

Las siguientes dependencias se añaden implícitamente:

•Todas las unidades de swap obtienen automáticamente las dependencias Requires= y After= de las unidades de dispositivo o de las unidades de montaje de los archivos desde los que se activan.

Pueden añadirse dependencias implícitas adicionales como resultado de los parámetros de ejecución y control de recursos, como se documenta en systemd.exec(5) y systemd.resource-control(5).

Dependencias por Defecto

Las siguientes dependencias se añaden a menos que se establezca DefaultDependencies=no:

•Las unidades de swap adquieren automáticamente una dependencia Conflicts= y una dependencia Before= con umount.target para que se desactiven al apagar, así como una dependencia Before=swap.target.

FSTAB

Las unidades de swap pueden configurarse a través de archivos de unidad o de /etc/fstab (consulte fstab(5) para obtener detalles). Los swaps listados en /etc/fstab se convertirán dinámicamente en unidades nativas durante el arranque y cuando se recargue la configuración del gestor del sistema. Consulte systemd-fstab-generator(8) para obtener detalles sobre la conversión.

Si un dispositivo o archivo de swap se configura tanto en /etc/fstab como en un archivo de unidad, la configuración de este último tiene precedencia.

Al leer /etc/fstab, systemd entiende algunas opciones especiales que influyen en cómo se crean las dependencias para las unidades de swap.

noauto, auto

Con noauto, la unidad de swap no se añadirá como dependencia de swap.target. Esto significa que no se activará automáticamente durante el arranque, a menos que sea invocada por alguna otra unidad. La opción auto tiene el significado opuesto y es el valor por defecto.

Añadido en la versión 218.

nofail

Con nofail, la unidad de swap solo será deseada, no requerida por swap.target. Esto significa que el arranque continuará incluso si este dispositivo de swap no se activa correctamente.

Añadido en la versión 218.

x-systemd.device-timeout=

Configura cuánto tiempo esperará systemd a que aparezca un dispositivo antes de renunciar a una entrada de /etc/fstab. Especifique un tiempo en segundos o añada explícitamente una unidad como "s", "min", "h", "ms".

Tenga en cuenta que esta opción solo se puede usar en /etc/fstab y se ignorará cuando forme parte del ajuste Options= en un archivo de unidad.

Añadido en la versión 215.

x-systemd.makefs

La estructura de swap se inicializará en el dispositivo. Si el dispositivo no está "vacío", es decir, contiene alguna firma, la operación se omitirá. Por lo tanto, se espera que esta opción permanezca establecida incluso después de que el dispositivo haya sido inicializado.

Tenga en cuenta que esta opción solo se puede usar en /etc/fstab y se ignorará cuando forme parte del ajuste Options= en un archivo de unidad.

Consulte systemd-mkswap@.service(8) y la discusión de wipefs(8) en systemd.mount(5).

Añadido en la versión 240.

OPCIONES

Los archivos de unidad de swap pueden incluir secciones [Unit] e [Install], que se describen en systemd.unit(5).

Los archivos de unidad de swap deben incluir una sección [Swap], que contiene información sobre el dispositivo de swap que supervisa. Un número de opciones que pueden usarse en esta sección son compartidas con otros tipos de unidades. Estas opciones se documentan en systemd.exec(5), systemd.kill(5) y systemd.resource-control(5). Las opciones específicas de la sección [Swap] de las unidades de swap son las siguientes:

What=

Toma una ruta absoluta o un identificador estilo fstab de un nodo de dispositivo o archivo a utilizar para paginación. Consulte swapon(8) para más detalles. Si esto se refiere a un nodo de dispositivo, se crea automáticamente una dependencia con la unidad de dispositivo respectiva. (Consulte systemd.device(5) para más información.) Si esto se refiere a un archivo, se crea automáticamente una dependencia con la unidad de montaje respectiva. (Consulte systemd.mount(5) para más información.) Esta opción es obligatoria. Tenga en cuenta que se aplica la expansión de especificadores habitual a esta configuración, por lo tanto, los caracteres de porcentaje literales deben escribirse como "%%".

Priority=

Prioridad de swap a utilizar al activar el dispositivo o archivo de swap. Toma un entero. Este ajuste es opcional y se ignora cuando la prioridad la establece pri= en la clave Options=.

Options=

Puede contener una cadena de opciones para el dispositivo de swap. Esto puede usarse para controlar opciones de descarte, entre otras funcionalidades, si el dispositivo de respaldo de swap admite la operación de descarte o recorte. (Consulte swapon(8) para más información.) Tenga en cuenta que la expansión de especificadores habitual se aplica a esta configuración, por lo tanto, los caracteres de porcentaje literales deben escribirse como "%%".

Añadido en la versión 217.

TimeoutSec=

Configura el tiempo de espera para que el comando swapon termine. Si un comando no finaliza dentro del tiempo configurado, el swap se considerará fallido y se apagará de nuevo. Todos los comandos que aún se ejecuten se terminarán forzosamente mediante SIGTERM y, después de otro retraso de este tiempo, mediante SIGKILL. (Consulte KillMode= en systemd.kill(5).) Toma un valor sin unidad en segundos, o un valor de intervalo de tiempo como "5min 20s". Pase "0" para deshabilitar la lógica de tiempo de espera. El valor por defecto es DefaultTimeoutStartSec= del archivo de configuración del gestor (consulte systemd-system.conf(5)).

Consulte systemd.unit(5), systemd.exec(5) y systemd.kill(5) para más ajustes.

VER TAMBIÉN

systemd(1), swap.target.unit.

For example, an entry for “/swapfile” would result in the unit swap.target.unit. Alternatively, swap devices may be configured via individual unit files in systemd.unit(5) format.

AUTOMATIC DEPENDENCIES

The swap units implicitly created from fstab(5) will automatically acquire dependencies on devices they refer to. For example, a swap file on “/dev/disk/by-uuid/” or “/dev/sda1” will get a dependency on the corresponding systemd-fstab-generator(8) unit.

FSTAB

The following fields in fstab(5) are used:

fs_spec:
Device specification. This is used to find the corresponding device unit. See systemd.device(5) for details.
fs_file:
Mount point. For swap devices, this is typically “none”, and is used to determine the unit name.
fs_vfstype:
Filesystem type. Must be “swap” for swap devices.
fs_mntops:
Mount options. These are passed to the swapon(8) command. The “defaults” option is recognized and expanded. The “pri=” option is used to set the priority of the swap device. See swapon(8) for details.
fs_freq:
Used for dump. Always zero for swap devices.
fs_passno:
Used for fsck. Always zero for swap devices.

OPTIONS

The swap units created implicitly from fstab(5) support the same options as device units. See systemd.device(5) for details.

Additionally, the following options are supported for swap units:

Swap=:
Configures the swap device. This option can be used to specify a swap file or a swap partition. If used in a device unit, it is equivalent to the fstab(5) entry.
Priority=:
Configures the swap priority. This option is equivalent to the “pri=” option in fstab(5).
