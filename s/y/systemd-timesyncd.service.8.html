NOMBRE

systemd-timesyncd.service, systemd-timesyncd - Sincronización de hora en red

SINOPSIS

systemd-timesyncd.service

/usr/lib/systemd/systemd-timesyncd

DESCRIPCIÓN

systemd-timesyncd.service es un servicio del sistema que puede ser utilizado para sincronizar el reloj del sistema local con un servidor remoto del Protocolo de Tiempo de Red (NTP). También guarda la hora local en disco cada vez que el reloj ha sido sincronizado y lo utiliza para avanzar posiblemente el reloj de tiempo real del sistema en reinicios posteriores para asegurar que avanza (aproximadamente) de forma monótona incluso si el sistema carece de un chip RTC con batería.

El servicio systemd-timesyncd.service implementa solo SNTP. Este servicio minimalista ajustará el reloj del sistema para desfases grandes o lo ajustará lentamente para deltas más pequeños. Casos de uso complejos que requieren soporte NTP completo (y donde SNTP no es suficiente) no están cubiertos por systemd-timesyncd.service.

Los servidores NTP contactados se determinan a partir de la configuración global en timesyncd.conf(5), la configuración estática por enlace en archivos .network, y la configuración dinámica por enlace recibida a través de DHCP. Ver systemd.network(5) para más detalles.

El comando set-ntp de timedatectl(1) puede ser utilizado para habilitar e iniciar, o deshabilitar y detener este servicio.

El comando timesync-status o show-timesync de timedatectl(1) puede ser usado para mostrar el estado actual de este servicio.

La inicialización de systemd-timesyncd.service retrasa el inicio de unidades que están ordenadas después de time-set.target (ver systemd.special(7) para detalles) hasta que la hora local haya sido actualizada desde /var/lib/systemd/timesync/clock (ver abajo) para hacerla aproximadamente monótona. No retrasa otras unidades hasta que se alcance la sincronización con fuentes de tiempo de referencia precisas. Use systemd-time-wait-sync.service(8) para lograr eso, lo cual retrasará el inicio de unidades que están ordenadas después de time-sync.target hasta que se alcance la sincronización con un reloj de referencia preciso.

systemd y systemd-timesyncd avanzan el reloj del sistema a la "época" (la fecha más baja por encima de la cual se asume que la hora del reloj del sistema está configurada correctamente). Ver la sección "System clock epoch" en systemd(1) para detalles. systemd configurará el reloj al inicializar, pero /var/lib/systemd/timesync/clock podría no estar disponible aún en ese momento. systemd-timesyncd avanzará el reloj cuando se inicie y detecte que el reloj del sistema está antes de la hora de modificación de /var/lib/systemd/timesync/clock.

ARCHIVOS

/var/lib/systemd/timesync/clock

La hora de modificación ("mtime") de este archivo se actualiza en cada sincronización NTP exitosa o después de cada intervalo de tiempo SaveIntervalSec=, como se especifica en timesyncd.conf(5).

Si está presente, la hora de modificación de este archivo se usa para la época por systemd(1) y systemd-timesyncd.service.

Añadido en la versión 219.

/run/systemd/timesync/synchronized

Un archivo que se toca en cada sincronización exitosa para ayudar al servicio systemd-time-wait-sync.service(8) y otras aplicaciones a detectar la sincronización con un reloj de referencia preciso.

Añadido en la versión 239.
