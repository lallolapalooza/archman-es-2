SYSCTL.CONF(5) Manual de formatos de archivo SYSCTL.CONF(5)

NOMBRE

sysctl.conf - parámetros de configuración del kernel de Linux

DESCRIPCIÓN

sysctl.conf es un conjunto de archivos de configuración que contienen parámetros de configuración del kernel de Linux para ser leídos y establecidos por sysctl(8).

Esta página del manual describe los archivos de configuración para el sysctl de procps. Si está utilizando systemd-sysctl(8), consulte sysctl.d(5) y tenga en cuenta que no utilizará el archivo /etc/sysctl.conf.

Formato de configuración

Cada línea de un archivo leído por el sysctl de procps describe un parámetro del kernel en el siguiente formato.

token = valor

Las líneas en blanco y las líneas que comienzan con “#” o “;” se ignoran.

Si una línea comienza con un único “-”, un intento fallido de establecer el valor se ignora.

ARCHIVOS

El sysctl de procps, cuando se ejecuta con la opción --system, lee archivos de directorios en el orden que se muestra a continuación.

/etc/sysctl.d/*.conf
/run/sysctl.d/*.conf
/usr/local/lib/sysctl.d/*.conf
/usr/lib/sysctl.d/*.conf
/lib/sysctl.d/*.conf

Finalmente, el sysctl de procps lee /etc/sysctl.conf. Este archivo no es utilizado por systemd-sysctl, lo que significa que algunos parámetros del kernel no se establecen dependiendo de la implementación de sysctl que esté instalada.

ERRORES

La longitud máxima admitida de valor es de 4096 caracteres debido a una limitación en la longitud de la entrada de /proc en el kernel de Linux.

EJEMPLOS

#
#
kernel.domainname = example.com
; Un valor que contiene un espacio se escribe en el sysctl.
kernel.modprobe = /sbin/mod probe

VER TAMBIÉN

sysctl.d(5), sysctl(8), systemd-sysctl(8)
