SYD-EMACS(1) Manual de comandos generales SYD-EMACS(1)

NOMBRE

syd-emacs - Envoltorio de conveniencia para ejecutar Emacs bajo Syd

SINOPSIS

syd-emacs [opciones de línea de comandos] [archivos...]

DESCRIPCIÓN

syd-emacs es un envoltorio de conveniencia para ejecutar Emacs bajo Syd. Todos los argumentos de la línea de comandos se pasan directamente a emacs(1).

ARCHIVOS

/dev/syd.el Librería de la API de Syd syd(2) en Lisp para Emacs.
El acceso asume que el bloqueo del sandbox es accesible, es decir, "lock:off" o "lock:exec".
~/.emacs.d/init.syd-3 Perfil de Syd para Emacs; si este archivo no existe, se utiliza el perfil "lib" en su lugar.
Nota: el perfil "lib" desactiva todo el sandboxing y establece "lock:exec" para permitir el acceso al archivo virtual "/dev/syd.el".
Si no desea desactivar todo el sandboxing, se recomienda configurar un perfil con este archivo.
Asegúrese de añadir "lock:exec" al final para que el proceso inicial de emacs(1) pueda acceder al sandbox para cargar "/dev/syd.el".
Asegúrese de llamar a "(syd-lock :lock-on)" desde dentro de emacs(1) cuando haya terminado de configurar syd(1) usando la API de syd(2).
Si no desea permitir el acceso al bloqueo del sandbox, se recomienda llamar a syd(1) manualmente con emacs(1).
Esto es solo un envoltorio de conveniencia.
~/.emacs.d/syd.log Archivo de registro de Syd para Emacs; las violaciones de acceso se registran en este archivo.
syd-emacs(1) abre este archivo y establece la variable de entorno SYD_LOG_FD con el valor del descriptor de archivo.
El archivo se abre solo para creación y anexión.

VER TAMBIÉN

syd(1), syd(2), syd(5), emacs(1)
