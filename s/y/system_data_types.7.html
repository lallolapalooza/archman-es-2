system_data_types(7) Manual de Información Miscelánea system_data_types(7)

NOMBRE

system_data_types - descripción general de los tipos de datos del sistema

DESCRIPCIÓN

siginfo_t
Incluir: <signal.h>. Alternativamente, <sys/wait.h>. 
typedef struct {
    int      si_signo;  /* Número de señal */
    int      si_code;   /* Código de señal */
    pid_t    si_pid;    /* ID del proceso que envía */
    uid_t    si_uid;    /* ID de usuario real del proceso que envía */
    void    *si_addr;   /* Ubicación de memoria que causó el fallo */
    int      si_status; /* Valor de salida o señal */
    union sigval si_value;  /* Valor de la señal */
} siginfo_t;

Información asociada con una señal. Para más detalles sobre esta estructura (incluyendo campos adicionales específicos de Linux), ver sigaction(2).

Cumple con: POSIX.1-2001 y posterior.

Ver también: pidfd_send_signal(2), rt_sigqueueinfo(2), sigaction(2), sigwaitinfo(2), psiginfo(3)

sigset_t
Incluir: <signal.h>. Alternativamente, <spawn.h>, o <sys/select.h>.

Este es un tipo que representa un conjunto de señales. Según POSIX, debe ser un tipo entero o una estructura.

Cumple con: POSIX.1-2001 y posterior.

Ver también: epoll_pwait(2), ppoll(2), pselect(2), sigaction(2), signalfd(2), sigpending(2), sigprocmask(2), sigsuspend(2), sigwaitinfo(2), signal(7)

NOTAS

Las estructuras descritas en esta página del manual contendrán, como mínimo, los miembros que se muestran en su definición, sin ningún orden particular.

La mayoría de los tipos enteros descritos en esta página no tienen un modificador de longitud correspondiente para las familias de funciones printf(3) y scanf(3). Para imprimir un valor de un tipo entero que no tenga un modificador de longitud, se debe convertir a intmax_t o uintmax_t mediante un cast explícito. Para leer en una variable de un tipo entero que no tenga un modificador de longitud, se debe usar una variable temporal intermedia de tipo intmax_t o uintmax_t. Al copiar desde la variable temporal a la variable de destino, el valor podría desbordarse. Si el tipo tiene límites superior e inferior, el usuario debe verificar que el valor se encuentre dentro de esos límites, antes de copiar realmente el valor. El siguiente ejemplo muestra cómo deben hacerse estas conversiones.

Convenciones usadas en esta página

En "Cumple con" solo nos preocupamos por C99 y posterior, y POSIX.1-2001 y posterior. Algunos tipos pueden especificarse en versiones anteriores de uno de estos estándares, pero en aras de la simplicidad omitimos detalles de estándares anteriores.

En "Incluir", primero notamos la cabecera (s) "primaria (s)" que definen el tipo según los estándares C o POSIX.1. Debajo de "Alternativamente", notamos cabeceras adicionales que los estándares especifican que deben definir el tipo.

EJEMPLOS

El programa que se muestra a continuación lee de una cadena e imprime un valor almacenado en una variable de un tipo entero que no tiene un modificador de longitud. Se utilizan las conversiones apropiadas desde y hacia intmax_t, y las comprobaciones de rango apropiadas, como se explica en la sección de notas anterior.

#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
int
main (void)
{
    static const char *const str = "500000 us en medio segundo";
    suseconds_t us;
    intmax_t    tmp;
    /* Lee el número de la cadena en la variable temporal.  */
    sscanf(str, "%jd", &tmp);
    /* Comprueba que el valor está dentro del rango válido de suseconds_t.  */
    if (tmp < -1 || tmp > 1000000) {
        fprintf(stderr, "¡Valor leído fuera del rango válido!\n");
        exit(EXIT_FAILURE);
    }
    /* Copia el valor a la variable suseconds_t 'us'.  */
    us = tmp;
    /* Aunque suseconds_t puede contener el valor -1, este no es
       un número sensato de microsegundos.  */
    if (us < 0) {
        fprintf(stderr, "¡El valor leído no debería ser negativo!\n");
        exit(EXIT_FAILURE);
    }
    /* Imprime el valor.  */
    printf("Hay %jd microsegundos en medio segundo.\n",
            (intmax_t) us);
    exit(EXIT_SUCCESS);
}
