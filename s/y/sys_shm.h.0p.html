sys_shm.h(0P) Manual del programador POSIX sys_shm.h(0P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sys/shm.h — instalación de memoria compartida XSI

SINOPSIS

#include <sys/shm.h>

DESCRIPCIÓN

El archivo de cabecera <sys/shm.h> definirá las siguientes constantes simbólicas:

SHM_RDONLY
Adjuntar sólo lectura (de lo contrario, lectura-escritura).
SHM_RND
Redondear la dirección de adjunción al múltiplo de SHMLBA.
SHMLBA
Múltiplo del límite inferior de la dirección del segmento.

El archivo de cabecera <sys/shm.h> definirá el tipo de dato shmatt_t mediante typedef:

shmatt_t
Entero sin signo utilizado para el número de adjunciones actuales que debe ser capaz de almacenar valores tan grandes como un tipo unsigned short.

El archivo de cabecera <sys/shm.h> definirá la estructura shmid_ds, que incluirá los siguientes miembros:

struct ipc_perm shm_perm   Estructura de permisos de operación.
size_t          shm_segsz  Tamaño del segmento en bytes.
pid_t           shm_lpid   ID de proceso de la última operación de memoria compartida.
pid_t           shm_cpid   ID de proceso del creador.
shmatt_t        shm_nattch Número de adjunciones actuales.
time_t          shm_atime  Hora de la última llamada a shmat().
time_t          shm_dtime  Hora de la última llamada a shmdt().
time_t          shm_ctime  Hora del último cambio realizado por shmctl().

El archivo de cabecera <sys/shm.h> definirá los tipos pid_t, size_t y time_t como se describe en <sys/types.h>.

Los siguientes elementos se declararán como funciones y también podrán definirse como macros. Se proporcionarán prototipos de función.

void *shmat(int, const void *, int);
int   shmctl(int, int, struct shmid_ds *);
int   shmdt(const void *);
int   shmget(key_t, size_t, int);

Además, el archivo de cabecera <sys/shm.h> incluirá el archivo <sys/ipc.h>.
