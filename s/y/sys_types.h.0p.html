sys_types.h(0P) Manual del programador POSIX sys_types.h(0P)

PROLOGO

Esta página del manual es parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual correspondiente de Linux para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sys/types.h — tipos de datos

SINOPSIS

#include <sys/types.h>

DESCRIPCIÓN

El archivo de cabecera <sys/types.h> definirá al menos los siguientes tipos:

blkcnt_t
Utilizado para recuentos de bloques de archivos.
blksize_t
Utilizado para tamaños de bloque.
clock_t
Utilizado para tiempos del sistema en ticks de reloj o CLOCKS_PER_SEC; consulte <time.h>.
clockid_t
Utilizado para el tipo de ID de reloj en las funciones de reloj y temporizador.
dev_t
Utilizado para IDs de dispositivo.
fsblkcnt_t
Utilizado para recuentos de bloques del sistema de archivos.
fsfilcnt_t
Utilizado para recuentos de archivos del sistema de archivos.
gid_t
Utilizado para IDs de grupo.
id_t
Utilizado como identificador general; puede usarse para contener al menos un pid_t, uid_t o gid_t.
ino_t
Utilizado para números de serie de archivos.
key_t
Utilizado para comunicación entre procesos XSI.
mode_t
Utilizado para algunos atributos de archivo.
nlink_t
Utilizado para recuentos de enlaces.
off_t
Utilizado para tamaños de archivo.
pid_t
Utilizado para IDs de proceso y IDs de grupo de procesos.
pthread_attr_t
Utilizado para identificar un objeto de atributos de hilo.
pthread_barrier_t
Utilizado para identificar una barrera.
pthread_barrierattr_t
Utilizado para definir un objeto de atributos de barrera.
pthread_cond_t
Utilizado para variables de condición.
pthread_condattr_t
Utilizado para identificar un objeto de atributos de condición.
pthread_key_t
Utilizado para claves de datos específicas de hilo.
pthread_mutex_t
Utilizado para mutex.
pthread_mutexattr_t
Utilizado para identificar un objeto de atributos de mutex.
pthread_once_t
Utilizado para inicialización dinámica de paquetes.
pthread_rwlock_t
Utilizado para bloqueos de lectura-escritura.
pthread_rwlockattr_t
Utilizado para atributos de bloqueo de lectura-escritura.
pthread_spinlock_t
Utilizado para identificar un bloqueo de giro (spinlock).
pthread_t
Utilizado para identificar un hilo.
size_t
Utilizado para tamaños de objetos.
ssize_t
Utilizado para un recuento de bytes o una indicación de error.
suseconds_t
Utilizado para tiempo en microsegundos.
time_t
Utilizado para tiempo en segundos.
timer_t
Utilizado para el ID del temporizador devuelto por timer_create().
trace_attr_t
Utilizado para identificar un objeto de atributos de flujo de rastreo.
trace_event_id_t
Utilizado para identificar un tipo de evento de rastreo.
trace_event_set_t
Utilizado para identificar un conjunto de tipos de eventos de rastreo.
trace_id_t
Utilizado para identificar un flujo de rastreo.
uid_t
Utilizado para IDs de usuario.

Todos los tipos se definirán como tipos aritméticos de una longitud apropiada, con las siguientes excepciones:

pthread_attr_t
pthread_barrier_t
pthread_barrierattr_t
pthread_cond_t
pthread_condattr_t
pthread_key_t
pthread_mutex_t
pthread_mutexattr_t
pthread_once_t
pthread_rwlock_t
pthread_rwlockattr_t
pthread_spinlock_t
pthread_t
timer_t
trace_attr_t
trace_event_id_t
trace_event_set_t
trace_id_t

Adicionalmente:

*
mode_t será un tipo entero.
*
dev_t será un tipo entero.
*
nlink_t, uid_t, gid_t y id_t serán tipos enteros.
*
blkcnt_t y off_t serán tipos enteros con signo.
*
fsblkcnt_t, fsfilcnt_t e ino_t se definirán como tipos enteros sin signo.
*
size_t será un tipo entero sin signo.
*
blksize_t, pid_t y ssize_t serán tipos enteros con signo.
*
clock_t será un tipo entero o de punto flotante real. time_t será un tipo entero.

El tipo ssize_t será capaz de almacenar valores al menos en el rango [-1, {SSIZE_MAX}].

El tipo suseconds_t será un tipo entero con signo capaz de almacenar valores al menos en el rango [-1, 1000000].

La implementación admitirá uno o más entornos de programación en los que los anchos de blksize_t, pid_t, size_t, ssize_t y suseconds_t no serán mayores que el ancho del tipo long. Los nombres de estos entornos de programación se pueden obtener utilizando la función confstr() o la utilidad getconf.

No hay operadores de comparación o asignación definidos para los siguientes tipos:

pthread_attr_t
pthread_barrier_t
pthread_barrierattr_t
pthread_cond_t
pthread_condattr_t
pthread_mutex_t
pthread_mutexattr_t
pthread_rwlock_t
pthread_rwlockattr_t
pthread_spinlock_t
timer_t
trace_attr_t
