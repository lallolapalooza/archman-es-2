NOMBRE

systemd-time-wait-sync.service, systemd-time-wait-sync - Esperar hasta que la hora del kernel esté sincronizada

SINOPSIS

systemd-time-wait-sync.service

/usr/lib/systemd/systemd-time-wait-sync

DESCRIPCIÓN

systemd-time-wait-sync es un servicio del sistema que retrasa el inicio de unidades que se ordenan después de time-sync.target (ver systemd.special(7) para más detalles) hasta que la hora del sistema se haya sincronizado con una fuente de tiempo remota precisa por systemd-timesyncd.service.

systemd-timesyncd.service notifica a systemd-time-wait-sync sobre la sincronización exitosa. systemd-time-wait-sync también intenta detectar cuándo el kernel marca el reloj del sistema como sincronizado, pero esta detección no es fiable y está destinada solo como una solución alternativa para compatibilidad con servicios NTP alternativos que se pueden utilizar para sincronizar el tiempo (por ejemplo, ntpd, chronyd).

ARCHIVOS

/run/systemd/timesync/synchronized

La presencia de este archivo indica a este servicio que el reloj del sistema ha sido sincronizado.

Añadido en la versión 239.

VER TAMBIÉN

systemd(1), systemd.special(7), systemd-timesyncd.service(8)
