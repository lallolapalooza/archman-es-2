NOMBRE

system-config-printer - configurar un servidor CUPS

SINOPSIS

system-config-printer [(--show-jobs impresora) | --debug | --help]

DESCRIPCIÓN

system-config-printer configura un servidor CUPS. Utiliza la API de CUPS (unida a Python con pycups) para hacerlo. La comunicación con el servidor se realiza utilizando IPP. Como resultado, es igualmente capaz de configurar un servidor CUPS remoto como uno local.

OPCIONES

--help

Muestra un breve mensaje de uso.

--show-jobs impresora

Muestra la cola de impresión con nombre.

--debug

Habilita la salida de depuración.
