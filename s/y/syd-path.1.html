SYD-PATH(1) Manual de Comandos Generales SYD-PATH(1)

NOMBRE

syd-path - Escribe reglas de sandboxing Force para binarios y lista ejecutables bajo PATH

SINOPSIS

syd-path [-h1235cCeklmpsw]

DESCRIPCIÓN

Escribe reglas de sandboxing Force para binarios bajo PATH.

Si se especifica al menos una de las varias opciones -e, lista ejecutables con información especificada bajo PATH.

OPCIONES

-h Muestra la ayuda.
-c Calcula la suma de verificación CRC64 (inseguro).
-C Calcula la suma de verificación CRC32 (inseguro).
-m Calcula la suma de verificación MD5 (inseguro, compatible con vdb de portage/paludis).
-1 Calcula la suma de verificación SHA1 (inseguro).
-2 Calcula la suma de verificación SHA3-256.
-3 Calcula la suma de verificación SHA3-384.
-5 Calcula la suma de verificación SHA3-512 (predeterminado).
-k Usa la acción kill (predeterminado).
-w Usa la acción warn.
-l num Limita por número de entradas.
-p ruta Especifica una PATH alternativa.
-s Prefija las reglas con "/dev/syd/".
-e32 Lista ejecutables ELF de 32 bits bajo PATH (entra en conflicto con -e64).
-e64 Lista ejecutables ELF de 64 bits bajo PATH (entra en conflicto con -e32).
-ed Lista ejecutables ELF enlazados dinámicamente bajo PATH (entra en conflicto con -es).
-es Lista ejecutables ELF enlazados estáticamente bajo PATH (entra en conflicto con -ed).
-ep Lista ejecutables PIE bajo PATH (entra en conflicto con -eP).
-eP Lista ejecutables no-PIE bajo PATH (entra en conflicto con -ep).
-ex Lista scripts bajo PATH.
-eX Lista binarios con pila ejecutable bajo PATH.

ERRORES

Esta herramienta omitirá silenciosamente cualquier fallo.
