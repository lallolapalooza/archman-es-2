NOMBRE

sympow - Programa SYMPOW

SINOPSIS

sympow [opciones]

DESCRIPCIÓN

Paquete matemático para calcular valores especiales de las funciones L de las curvas elípticas SYMmetric POWer (hasta aproximadamente 64 dígitos de precisión).

OPCIONES

-bound #
un LÍMITE superior para cuántos ap calcular
-info [] []
solo informar información local para primos/sympows el primer argumento es el rango de primos, el segundo el rango de sympow
-local
solo informar información local (primos malos)
-curve []
introducir una curva en forma [a1,a2,a3,a4,a6]
-label []
asignar una etiqueta a la curva dada
-quiet
desactivar algunos mensajes: por defecto
-terse
activar algunos mensajes
-verbose
activar mensajes adicionales
-rootno #
calcular el número raíz de la potencia simétrica número #
-moddeg
calcular el grado modular
-analrank
calcular el rango analítico
-sloppy []
para usar con -analrank; tener X dígitos aproximados
-nocm
abortar si la curva tiene multiplicación compleja
-noqt
ignorar potencias pares de giros cuadráticos no mínimos
-noqdcheck
no verificar si funciona el material de doble cuadrado
-mdspeed []
velocidad para moddeg; 2.0 es el valor predeterminado, 0.0 es prueba
-hecke
calcular potencias simétricas de Hecke para una curva CM
-maxtable
establecer el tamaño máximo de las tablas de factores: 2^27 por defecto
-sp []
argumento para especificar qué potencias es una lista separada por comas en cada entrada, el primer dato es la potencia simétrica, luego podría venir b que activa Bloch-Kato, luego podría venir w# que especifica cuántas pruebas, luego podría venir s# que dice # dígitos aproximados, luego debe venir p# que especifica la precisión o P# que dice ignorar BOUND para esta potencia, luego debe venir d# que dice el límite de la derivada o D# que dice hacer solo esta derivada (ninguno de los dos necesita indicarse para potencias pares) el valor predeterminado es 2w3s1p32,3bp16d1,4p8
-new_data []
calculará la malla de la transformada de Mellin inversa para los datos dados: el formato es [sp]d[dv]{h,c} sp es la potencia simétrica, dv es la derivada, h indica potencias de Hecke, y c indica el caso CM d[dv] se da solo para potencias impares o de Hecke Ejemplos: 1d3 2 2d1h 3d2 4 4c 5d0 6 7d0h 11d1 12c NOTA: new_data ejecuta un script de shell que usa GP
-dump-endiantuple
muestra la tupla endian, utilizada como componente en las rutas de datos binarios, y sale

-dump-versiontuple muestra la tupla de versión (Mayor.menor.micro) y sale

-version
imprime la versión del programa y sale
-help
muestra esta ayuda y sale

Otras opciones se usan interna/recursivamente con -new_data
