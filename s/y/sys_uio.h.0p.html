PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sys/uio.h — definiciones para operaciones de E/S vectorizadas

SINOPSIS

#include <sys/uio.h>

DESCRIPCIÓN

La cabecera <sys/uio.h> definirá la estructura iovec, la cual incluirá al menos los siguientes miembros:

void   *iov_base  Dirección base de una región de memoria para entrada o salida.
size_t  iov_len   El tamaño de la memoria apuntada por iov_base.

La cabecera <sys/uio.h> usa la estructura iovec para E/S de dispersión/agrupación.

La cabecera <sys/uio.h> definirá los tipos ssize_t y size_t como se describe en <sys/types.h>.

Lo siguiente se declarará como funciones y también puede definirse como macros. Se proporcionarán prototipos de función.

ssize_t readv(int, const struct iovec *, int);
ssize_t writev(int, const struct iovec *, int);

Las siguientes secciones son informativas.

USO DE APLICACIONES

La implementación puede imponer un límite en el número de elementos de dispersión/agrupación que pueden procesarse en una sola llamada. El símbolo {IOV_MAX} definido en <limits.h> siempre debe usarse para conocer los límites en lugar de asumir un valor fijo.

RACIOCINIO

Tradicionalmente, el número máximo de elementos de dispersión/agrupación que el sistema puede procesar en una sola llamada se describía mediante el valor simbólico {UIO_MAXIOV}. En IEEE Std 1003.1‐2001, este valor se reemplaza por la constante {IOV_MAX} que se encuentra en <limits.h>.
