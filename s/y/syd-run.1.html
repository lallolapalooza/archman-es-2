SYD-RUN(1) Manual de comandos generales SYD-RUN(1)

NOMBRE

syd-run - Ejecuta un programa dentro de un contenedor con el ID de proceso dado

SINOPSIS

syd-run [-hvacimnptuU] pid {comando [arg...]}

DESCRIPCIÓN

La utilidad syd-run(2) ejecuta un programa dentro de un contenedor syd(1) con el ID de proceso dado. Esto requiere el uso de llamadas al sistema setns(2) y pidfd_open(2), que requieren Linux-5.8 o posterior. Tenga en cuenta que entrar en pid_namespaces(7) y time_namespaces(7) es una operación privilegiada, mientras que entrar en cgroup_namespaces(7), ipc_namespaces(7), mount_namespaces(7), network_namespaces(7) y uts_namespaces(7) no requiere privilegios cuando se combina con user_namespaces(7), siempre que el soporte para user_namespaces(7) no privilegiado esté habilitado en el kernel de Linux.

OPCIONES

-h Muestra la ayuda.
-v Sea verboso. Imprime mensajes informativos en la salida de error estándar.
-a Detecta automáticamente los namespaces a los que entrar. Los namespaces PID y Time están excluidos. Esta es la opción predeterminada.
-c Entrar en el namespace CGroup.
-i Entrar en el namespace IPC.
-m Entrar en el namespace de montaje.
-n Entrar en el namespace de red.
-p Entrar en el namespace PID.
-t Entrar en el namespace de tiempo.
-u Entrar en el namespace UTS.
-U Entrar en el namespace de usuario.

ESTADO DE SALIDA

En caso de salida limpia, syd-run(1) sale con el mismo código que el proceso hijo. En caso de terminación no limpia, el código de salida se establece en 128 más el número de señal. En caso de que la ejecución del proceso hijo falle, syd-run(1) sale con el número de errno(3).

VER TAMBIÉN
