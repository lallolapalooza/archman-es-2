NOMBRE

systemd-makefs@.service, systemd-mkswap@.service, systemd-growfs@.service, systemd-growfs-root.service, systemd-makefs, systemd-growfs - Creación y crecimiento de sistemas de archivos bajo demanda

SINOPSIS

systemd-makefs@dispositivo.service

systemd-mkswap@dispositivo.service

systemd-growfs@punto_montaje.service

systemd-growfs-root.service

/usr/lib/systemd/systemd-makefs

/usr/lib/systemd/systemd-growfs

DESCRIPCIÓN

systemd-makefs@.service, systemd-mkswap@.service, systemd-growfs@.service y systemd-growfs-root.service se utilizan para implementar las opciones x-systemd.makefs y x-systemd.growfs en fstab(5), ver systemd.mount(5). Se instancian para cada dispositivo para el que se necesita inicializar el sistema de archivos o la estructura de intercambio, y para cada punto de montaje donde se necesita crecer el sistema de archivos.

Estos servicios se inician al arrancar, ya sea justo antes o justo después de que se utilice el punto de montaje o el dispositivo de intercambio.

systemd-makefs sabe muy poco sobre sistemas de archivos y dispositivos de intercambio específicos y, después de verificar que el dispositivo de bloque no contiene ya un sistema de archivos u otro contenido, ejecutará binarios específicos para cada tipo de sistema de archivos (/sbin/mkfs.tipo o /sbin/mkswap). Para ciertos tipos de sistemas de archivos (actualmente ext2/ext3/ext4(5), btrfs(5), xfs(5), f2fs, vfat) y para dispositivos de intercambio, configurará valores predeterminados razonables y establecerá la etiqueta y la UUID del sistema de archivos basándose en el nombre del dispositivo.

systemd-growfs sabe muy poco sobre sistemas de archivos y dispositivos de intercambio específicos e indicará al kernel que crezca el sistema de archivos montado hasta el tamaño completo del dispositivo de bloque subyacente. No obstante, necesita conocer el número de ioctl(2) específico para cada sistema de archivos, por lo que solo se admiten ciertos tipos. Actualmente: ext4(5), btrfs(5), xfs(5) y particiones dm-Crypt (ver cryptsetup(8)).

Si falla la creación de un sistema de archivos o dispositivo de intercambio, el punto de montaje o intercambio también fallará. Si falla el crecimiento de un sistema de archivos, se emitirá una advertencia.
