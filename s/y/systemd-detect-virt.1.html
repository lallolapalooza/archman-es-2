NOMBRE

systemd-detect-virt - Detecta la ejecución en un entorno virtualizado

SINOPSIS

systemd-detect-virt [OPCIONES...]

DESCRIPCIÓN

systemd-detect-virt detecta la ejecución en un entorno virtualizado. Identifica la tecnología de virtualización y puede distinguir entre virtualización completa de máquinas y virtualización de contenedores. systemd-detect-virt sale con un valor de retorno de 0 (éxito) si se detecta una tecnología de virtualización y no cero (error) en caso contrario. Por defecto, se detecta cualquier tipo de virtualización, y las opciones --container y --vm se pueden usar para limitar qué tipos de virtualización se detectan.

Cuando se ejecuta sin --quiet, imprimirá un identificador corto para la tecnología de virtualización detectada. Las siguientes tecnologías se identifican actualmente:

powervm Hipervisor IBM PowerVM — viene como firmware con algunos servidores IBM POWER
xen Hipervisor Xen (solo domU, no dom0)
bochs Emulador Bochs
uml User-mode Linux
parallels Parallels Desktop, Parallels Server
bhyve bhyve, hipervisor de FreeBSD
qnx Hipervisor QNX

Si se utilizan múltiples soluciones de virtualización, solo se detecta e identifica la más "interna". Esto significa que si se utilizan conjuntamente virtualización de máquina y de contenedor, solo se identificará esta última (a menos que se pase --vm).

Windows Subsystem for Linux no es un contenedor Linux, sino un entorno para ejecutar aplicaciones de userspace Linux sobre el kernel de Windows usando una interfaz compatible con Linux. WSL se clasifica como un contenedor por razones prácticas. Múltiples entornos WSL comparten el mismo kernel y los servicios generalmente deberían comportarse como cuando se ejecutan en un contenedor.

Cuando se ejecuta con --cvm, en lugar de imprimir la tecnología de virtualización, mostrará la tecnología de máquina virtual confidencial, si la hay. Las siguientes tecnologías se identifican actualmente:

sev-snp AMD Secure Encrypted Virtualization - Secure Nested Paging
tdx Intel Trust Domain Extensions
s390x protvirt IBM Protected Virtualization (Secure Execution)
arm64 cca Arm Confidential Compute Architecture

OPCIONES

Se entienden las siguientes opciones:

-c, --container

Solo detecta virtualización de contenedores (es decir, virtualización de kernel compartido).

-v, --vm

Solo detecta virtualización de hardware.

-r, --chroot

Detecta si se invoca en un entorno chroot(2). En este modo, no se genera ninguna salida, pero el valor de retorno indica si el proceso fue invocado en un entorno chroot() o no.

Añadido en la versión 228.

--private-users

Detecta si se invoca en un espacio de nombres de usuario. En este modo, no se genera ninguna salida, pero el valor de retorno indica si el proceso fue invocado dentro de un espacio de nombres de usuario o no. Véase user_namespaces(7) para más información.

Añadido en la versión 232.

--cvm

Detecta si se invoca en una máquina virtual confidencial. El resultado de esta detección puede usarse para deshabilitar características que no deberían usarse en VMs confidenciales. No debe usarse para liberar información de seguridad sensible. Esto último solo debe liberarse tras la atestación del entorno confidencial.

Añadido en la versión 254.

-q, --quiet

Suprime la salida del identificador de la tecnología de virtualización.

--list

Muestra todos los entornos de contenedores y VM actualmente conocidos y detectables.

Añadido en la versión 239.

--list-cvm

Muestra todas las tecnologías de virtualización confidencial actualmente conocidas y detectables.

Añadido en la versión 254.

-h, --help

Imprime un breve texto de ayuda y sale.

--version

Imprime una breve cadena de versión y sale.

ESTADO DE SALIDA

Si se detecta una tecnología de virtualización, se devuelve 0, de lo contrario, un código distinto de cero.
