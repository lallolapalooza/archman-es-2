NOMBRE

systemd-networkd.service, systemd-networkd - Gestor de red

SINOPSIS

systemd-networkd.service

/usr/lib/systemd/systemd-networkd

DESCRIPCIÓN

systemd-networkd es un servicio del sistema que gestiona redes. Detecta y configura dispositivos de red a medida que aparecen, así como crea dispositivos de red virtuales.

Ciertas configuraciones de bajo nivel de dispositivos de red físicos (p. ej., nombres de dispositivos y alias) así como la creación de funciones virtuales SR-IOV en interfaces de red físicas pueden ser gestionadas por systemd-udevd(8) según el contenido de los archivos systemd.link(5).

systemd-networkd creará dispositivos de red "virtuales" (p. ej., puentes y túneles) basándose en la configuración de los archivos systemd.netdev(5), respetando las secciones [Match] en dichos archivos.

systemd-networkd gestionará las direcciones de red y las rutas para cualquier enlace para el que encuentre un archivo .network con una sección [Match] apropiada, véase systemd.network(5). Para esos enlaces, eliminará las direcciones de red y rutas existentes al activar el dispositivo (excepto cuando se indique lo contrario). Cualquier enlace no coincidente por uno de los archivos .network será ignorado. También es posible indicar explícitamente a systemd-networkd que ignore un enlace usando la opción Unmanaged=yes, véase systemd.network(5).

Cuando systemd-networkd sale, generalmente deja intactos los dispositivos de red y la configuración existente. Esto permite la transición desde el initrd y reiniciar el servicio sin interrumpir la conectividad. Esto también significa que cuando la configuración se actualiza y systemd-networkd se reinicia, las interfaces netdev para las que se eliminó la configuración no se eliminarán y pueden necesitar ser limpiadas manualmente.

systemd-networkd puede ser inspeccionado y controlado en tiempo de ejecución usando networkctl(1).

Véase org.freedesktop.network1(5) y org.freedesktop.LogControl1(5) para una descripción de la API D-Bus.

ARCHIVOS DE CONFIGURACIÓN

Los archivos de configuración se leen de los archivos ubicados en el directorio de red del sistema /usr/lib/systemd/network, el directorio de red volátil en tiempo de ejecución /run/systemd/network y el directorio de red de administración local /etc/systemd/network.

Las redes se configuran en archivos .network, véase systemd.network(5), y los dispositivos de red virtuales se configuran en archivos .netdev, véase systemd.netdev(5).
