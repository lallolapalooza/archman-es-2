SYSTEROID(8) Administración del Sistema SYSTEROID(8)

NOMBRE

systeroid - configurar parámetros del kernel en tiempo de ejecución

SINOPSIS

systeroid [opciones] [variable[=valor] ...] --load[=<archivo>]

DESCRIPCIÓN

systeroid se utiliza para modificar parámetros del kernel en tiempo de ejecución. Los parámetros disponibles son los listados en /proc/sys/. Procfs es necesario para que systeroid sea compatible con Linux. Puedes usar systeroid para leer y escribir datos sysctl.

PARÁMETROS

variable
El nombre de una clave para leer. Un ejemplo es kernel.ostype. El separador '/' también se acepta en lugar de un '.'.
variable=valor
Para establecer una clave, usa el formato variable=valor, donde variable es la clave y valor es el valor a establecer. Si el valor contiene comillas o caracteres que son analizados por el shell, puede que necesites encerrar el valor entre comillas dobles.
-a, --all
Muestra todas las variables actualmente disponibles. (-A,-X)
-T, --tree
Muestra las variables en un formato de árbol.
-J, --json
Muestra las variables en formato JSON.
--obsoleto
Incluye parámetros obsoletos en las listas de valores de --all.
-e, --ignore
Usa esta opción para ignorar errores sobre claves desconocidas.
-N, --names
Usa esta opción para imprimir solo los nombres. Puede ser útil con shells que tienen completado programable.
-n, --values
Usa esta opción para deshabilitar la impresión del nombre de la clave al imprimir valores.
-b, --binary
Imprime solo los valores de las variables sin nueva línea.
-p[ARCHIVO], --load[=ARCHIVO]
Carga la configuración sysctl desde el archivo especificado o desde /etc/sysctl.conf si no se proporciona ninguno. Especificar - como nombre de archivo significa leer datos de la entrada estándar.
-S, --system
Carga la configuración desde todos los archivos de configuración del sistema. Ver la sección CONFIGURACIÓN abajo.
-r, --pattern <expr>
Aplica solo la configuración que coincide con el patrón. El patrón utiliza la sintaxis de expresiones regulares extendidas.
-q, --quiet
Usa esta opción para no mostrar los valores establecidos en stdout.
-w, --write
Usa esta opción cuando todos los argumentos prescriben una clave a ser establecida.
-E, --explain
Usa esta opción para imprimir una explicación detallada de una variable.
-D, --docs <ruta>
Usa esta opción para establecer una ruta personalizada para la documentación del kernel.
-P, --no-pager
Usa esta opción para deshabilitar la paginación de la salida.
-v, --verbose
Usa esta opción para habilitar el registro detallado.
--tui
Usa esta opción para mostrar la interfaz de usuario en terminal. El binario systeroid-tui debería estar presente en $PATH. Ver systeroid-tui(8) para más información.
-h, --help
Muestra el texto de ayuda y sale. (-d)
-V, --version
Muestra la información de la versión y sale.

EJEMPLOS

systeroid -a
systeroid -t
systeroid vm user
systeroid -n kernel.hostname
systeroid kernel.domainname="example.com"
systeroid dmesg_restrict=0
systeroid -p /etc/sysctl.conf
systeroid -r 'net.ipv4.conf.(eth|wlan)0.arp'
systeroid --names --tree --pattern 'kernel.*_max$'
systeroid --explain oom_dump_tasks
systeroid -E user.max_user_namespaces --docs /usr/share/doc/linux
systeroid --no-pager -E kernel.ctrl-alt-del
systeroid --tui

PARÁMETROS OBSOLETOS

base_reachable_time y retrans_time están obsoletos. El comando systeroid no permite cambiar los valores de estos parámetros. Los usuarios que insistan en usar interfaces obsoletas del kernel deberían escribir valores en el sistema de archivos /proc por otros medios. Por ejemplo:

echo 256 > /proc/sys/net/ipv6/neigh/eth0/base_reachable_time

CONFIGURACIÓN

sysctl.conf es un archivo simple que contiene valores sysctl para ser leídos y establecidos por systeroid. La sintaxis es simplemente la siguiente:

# comentario
; comentario
token = valor

Ten en cuenta que las líneas en blanco se ignoran, y el espacio en blanco antes y después de un token o valor se ignora, aunque un valor puede contener espacios en blanco en su interior. Las líneas que comienzan con un # o ; se consideran comentarios y se ignoran.

Si una línea comienza con un solo -, cualquier intento de establecer el valor que falle será ignorado.

EJEMPLO

# Muestra sysctl.conf
#
  kernel.domainname = example.com
; ¡este tiene un espacio que se escribirá en el sysctl!
  kernel.modprobe = /sbin/mod probe

ARCHIVOS

Al usar la opción --system, systeroid leerá archivos de los directorios en la siguiente lista.

/etc/sysctl.d/*.conf
/run/sysctl.d/*.conf
/usr/local/lib/sysctl.d/*.conf
/usr/lib/sysctl.d/*.conf
/lib/sysctl.d/*.conf
/etc/sysctl.conf
