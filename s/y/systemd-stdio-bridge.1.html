NOMBRE

systemd-stdio-bridge - Proxy de D-Bus

SINOPSIS

systemd-stdio-bridge [OPCIONES...]

DESCRIPCIÓN

systemd-stdio-bridge implementa un proxy entre STDIN/STDOUT y un bus D-Bus. Espera recibir una conexión abierta a través de STDIN/STDOUT cuando se inicia, y creará una nueva conexión al bus especificado. Luego reenviará mensajes entre las dos conexiones. Este programa es adecuado para la activación por socket: la primera conexión puede ser una tubería o un socket y debe pasarse como entrada estándar, o como un descriptor de archivo abierto según el protocolo descrito en sd_listen_fds(3). La segunda conexión se realizará por defecto al bus del sistema local, pero esto se puede influenciar mediante las opciones --user, --system, --machine= y --bus-path= descritas a continuación.

sd-bus(3) utiliza systemd-stdio-bridge para reenviar conexiones D-Bus a través de ssh(1), o para conectarse al bus de otro usuario, véase sd_bus_set_address(3).

OPCIONES

Se reconocen las siguientes opciones:

--user

Hablar con el gestor de servicios del usuario que llama, en lugar de con el gestor de servicios del sistema.

--system

Hablar con el gestor de servicios del sistema. Este es el valor predeterminado implícito.

-M, --machine=

Ejecutar operación en un contenedor local. Especificar un nombre de contenedor al que conectarse, opcionalmente prefijado por un nombre de usuario al que conectarse y un carácter "@" separador. Si se utiliza la cadena especial ".host" en lugar del nombre del contenedor, se establece una conexión con el sistema local (lo cual es útil para conectarse al bus de usuario de un usuario específico: "--user --machine=lennart@.host"). Si no se utiliza la sintaxis "@", la conexión se realiza como usuario root. Si se utiliza la sintaxis "@", se puede omitir el lado izquierdo o el derecho (pero no ambos), en cuyo caso se implican el nombre de usuario local y ".host".

-p RUTA, --bus-path=RUTA

Ruta a la dirección del bus. Predeterminado: "unix:path=/run/dbus/system_bus_socket"

Añadido en la versión 251.

-h, --help

Imprimir un breve texto de ayuda y salir.

--version

Imprimir una breve cadena de versión y salir.

CÓDIGO DE SALIDA

En caso de éxito, se devuelve 0, en caso contrario, un código de error distinto de cero.
