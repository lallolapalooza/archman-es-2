NOMBRE

systemd-importd.service, systemd-importd - Servicio de importación y exportación de imágenes de VM y contenedores

SINOPSIS

systemd-importd.service

/usr/lib/systemd/systemd-importd

DESCRIPCIÓN

systemd-importd es un servicio del sistema que permite importar, exportar y descargar imágenes de disco. Proporciona la implementación para los comandos pull-raw, pull-tar, import-raw, import-tar, import-fs, export-raw y export-tar de importctl(1).

Consulte org.freedesktop.import1(5) y org.freedesktop.LogControl1(5) para una descripción de la API de D-Bus.

VER TAMBIÉN

systemd(1), importctl(1), systemd-machined.service(8), systemd-nspawn(1), org.freedesktop.import1(5)
