SYD-FD(1) Manual de comandos generales SYD-FD(1)

NOMBRE

syd-fd - Interactuar con descriptores de archivo remotos

SINOPSIS

syd-fd [-h] [-p pid] [-f fd_remoto[:fd_local]]... {comando [argumentos...]}

DESCRIPCIÓN

La utilidad syd-fd se puede utilizar para interactuar con descriptores de archivo remotos en sistemas Linux. Dado solo el argumento PID con -p, lista los archivos abiertos del proceso con el PID dado en formato JSON compacto orientado a líneas. Si no se da el argumento PID, lista los archivos abiertos del proceso actual. El argumento -f se puede usar para transferir descriptores de archivo remotos usando pidfd_getfd(2), que requiere Linux>=5.6. Opcionalmente, se puede especificar un descriptor de archivo local separado por dos puntos como descriptor de archivo de destino. Especifique rand como destino para duplicar el descriptor de archivo a una ranura de descriptor de archivo aleatoria disponible. Si se da un comando, se ejecuta y los descriptores de archivo se transfieren al proceso. Si no se da ningún comando, se ejecuta "/bin/sh".

OPCIONES

-h Muestra la ayuda.
-p pid Especifica el ID del proceso. Si no se da, lista los fd del proceso actual.
-f fd_remoto[:fd_local] Especifica el fd remoto a transferir. Opcionalmente, especifica el fd local separado por dos puntos como destino, o rand para un destino aleatorio.

CÓDIGOS DE SALIDA

syd-fd sale con el mismo código de salida que el comando.

VER TAMBIÉN

syd(1), syd(2), syd(5), syd-lock(1), syd-pds(1), pidfd_getfd(1)
