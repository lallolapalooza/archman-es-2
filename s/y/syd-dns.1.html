NOMBRE

syd-dns - Resuelve nombres de host en IPs usando el resolvedor DNS del sistema

SINOPSIS

syd-dns [-hr46] nombre_host

syd-dns [-R] dirección IPv4/6

DESCRIPCIÓN

Resuelve nombres de host en IPs usando el resolvedor DNS del sistema.

Dado -R, realiza una búsqueda DNS inversa para la dirección IPv4/6 dada usando el resolvedor DNS del sistema.

OPCIONES

-h Muestra la ayuda y sale.
-4 Imprime solo direcciones IPv4
-6 Imprime solo direcciones IPv6
-r Imprime una IP aleatoria seleccionada usando getrandom(2)
-R Realiza una búsqueda DNS inversa usando getnameinfo(3)

VER TAMBIÉN
