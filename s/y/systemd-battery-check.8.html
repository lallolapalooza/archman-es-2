NOMBRE

systemd-battery-check.service, systemd-battery-check - Comprueba el nivel de la batería para ver si tiene suficiente carga y apaga si no es así

SINOPSIS

systemd-battery-check.service

/usr/lib/systemd/systemd-battery-check [OPCIONES...]

DESCRIPCIÓN

Este servicio comprueba la presencia de una fuente de alimentación externa y el nivel de la batería durante la fase inicial de arranque para determinar si hay suficiente energía para continuar con el proceso de arranque.

systemd-battery-check devuelve éxito si el dispositivo está conectado a una fuente de alimentación de CA o si la carga de la batería es superior al 5%. Devuelve un error en caso contrario.

OPCIONES

Las siguientes opciones son entendidas por systemd-battery-check:

-h, --help

Imprime un breve texto de ayuda y sale.

--version

Imprime una breve cadena de versión y sale.

ESTADO DE SALIDA

En caso de éxito (funcionando con alimentación de CA o capacidad de batería superior al 5%), se devuelve 0, de lo contrario, un código de error distinto de cero.

LÍNEA DE COMANDOS DEL NÚCLEO

Se entienden las siguientes variables:

systemd.battery_check=BOOL

Toma un valor booleano. Si se especifica como falso, el comando systemd-battery-check devolverá inmediatamente con el estado de salida 0 sin comprobar la capacidad de la batería ni la existencia de alimentación de CA, y el servicio systemd-battery-check.service tendrá éxito. Esto puede ser útil cuando el comando detecta y reporta erróneamente el porcentaje de capacidad de la batería o la existencia de alimentación de CA, o cuando desea arrancar el sistema de forma forzada.

Añadido en la versión 254.
