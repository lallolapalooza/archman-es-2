NOMBRE

systemd-remount-fs.service, systemd-remount-fs - Remonta los sistemas de archivos raíz y del kernel

SINOPSIS

systemd-remount-fs.service

/usr/lib/systemd/systemd-remount-fs

DESCRIPCIÓN

systemd-remount-fs.service es un servicio de arranque temprano que aplica las opciones de montaje listadas en fstab(5), o recopiladas de la tabla de particiones (cuando systemd-gpt-auto-generator(8) está activo) al sistema de archivos raíz, al sistema de archivos /usr/, y a los sistemas de archivos de la API del kernel. Esto es necesario para que las opciones de montaje de estos sistemas de archivos —que son pre-montados por el kernel, el initrd, entornos de contenedores o código del gestor de sistema— se actualicen a las configuradas en /etc/fstab y otras fuentes. Este servicio ignora los sistemas de archivos normales y solo modifica el sistema de archivos raíz (es decir, /), /usr/, y los sistemas de archivos de la API del kernel como /proc/, /sys/ o /dev/. Este servicio no realiza ninguna operación si no se encuentra configuración (si /etc/fstab no existe o no lista entradas para los sistemas de archivos mencionados, o si la tabla de particiones no contiene entradas relevantes).

Para una discusión más detallada de los sistemas de archivos de la API del kernel, consulta Sistemas de Archivos API[1].

Nota: systemd-remount-fs.service generalmente es invocado por systemd-fstab-generator(8), por lo tanto, también se ve afectado por la opción de línea de comandos del kernel fstab=, que puede usarse para deshabilitar el generador. También puede ser invocado por systemd-gpt-auto-generator(8), que se ve afectado por systemd.gpt_auto y otras opciones.
