SYD-KEY(1) Manual de Comandos Generales SYD-KEY(1)

NOMBRE

syd-key - Utilidad para generar claves de cifrado y guardarlas en keyrings(7)

SINOPSIS

syd-key [-hpP] [-d keydesc] [-t keytype] [-k keyring]

DESCRIPCIÓN

La utilidad syd-key genera claves de cifrado aleatorias de 256 bits utilizando el generador de números aleatorios del Kernel de Linux. La clave se guarda en los keyrings(7) de Linux y el ID serial de la clave se imprime como un entero decimal de 32 bits en la salida estándar.

OPCIONES

-h Muestra la ayuda.
-p Lee la contraseña del TTY de control (NO de stdin(3)) y deriva el material de la clave.
syd-key se negará a leer la contraseña de stdin(3) por seguridad, a menos que se proporcione explícitamente -P. La contraseña se hashea usando SHA3-256; el digest resultante se almacena con la interfaz de keyrings(7). El búfer de la contraseña se pone a cero después de su uso. El ID serial de la clave se imprime en stdout(3).
Si no se proporciona ninguna de las opciones -pP, se genera una clave aleatoria usando getrandom(2) con la bandera GRND_RANDOM.
-P Lee la contraseña de stdin(3) y deriva el material de la clave.
Esta opción está destinada a un uso no interactivo (por ejemplo, enviando una contraseña desde un gestor de contraseñas). Úselo con precaución: leer una contraseña de stdin(3) puede ser menos seguro que leerla desde el TTY de control porque puede ser observable por otros procesos, registrada en construcciones del shell o filtrada de alguna otra manera por el entorno. La contraseña se hashea usando SHA3-256; el digest resultante se almacena con la interfaz de keyrings(7). El búfer de la contraseña se pone a cero después de su uso. El ID serial de la clave se imprime en stdout(3).
Si no se proporciona ninguna de las opciones -pP, se genera una clave aleatoria usando getrandom(2) con la bandera GRND_RANDOM.
-d kdesc Especifica una descripción alternativa de la clave. El valor predeterminado es SYD-3-CRYPT.
-t ktype Especifica un tipo de clave alternativo. El valor predeterminado es user.
-k kring Especifica un ID de keyring alternativo. El valor predeterminado es KEY_SPEC_USER_KEYRING. Puede ser exactamente uno de thread, process, session, user o user-session. También puede ser un número decimal de 32 bits que especifica un ID de keyring.

ADVERTENCIAS

Las claves en keyrings(7) se identifican por su par (tipo, descripción). Cuando syd-key invoca add_key(2) con un tipo/descripción que ya existe en el keyring de destino, el kernel actualizará la carga útil de la clave existente en lugar de crear una nueva clave. Para forzar la creación de una nueva clave, use una descripción única (por ejemplo, añadiendo un UUID o una marca de tiempo).
