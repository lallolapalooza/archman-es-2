sys_wait.h(0P) Manual del programador POSIX sys_wait.h(0P)

PROLOG

Esta página del manual es parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sys/wait.h — declaraciones para esperar

SINOPSIS

#include <sys/wait.h>

DESCRIPCIÓN

El encabezado <sys/wait.h> definirá las siguientes constantes simbólicas para su uso con waitpid():

WCONTINUED
Reportar el estado del proceso hijo continuado.
WNOHANG
No bloquear si no hay estado disponible; retornar inmediatamente.
WUNTRACED
Reportar el estado del proceso hijo detenido.

El encabezado <sys/wait.h> definirá las siguientes macros para el análisis de valores de estado de proceso:

WEXITSTATUS
Retornar el estado de salida.
WIFCONTINUED
Verdadero si el hijo ha sido continuado.
WIFEXITED
Verdadero si el hijo salió normalmente.
WIFSIGNALED
Verdadero si el hijo terminó debido a una señal no capturada.
WIFSTOPPED
Verdadero si el hijo está actualmente detenido.
WSTOPSIG
Retornar el número de señal que causó que el proceso se detuviera.
WTERMSIG
Retornar el número de señal que causó que el proceso terminara.

El encabezado <sys/wait.h> definirá las siguientes constantes simbólicas como valores posibles para el argumento options de waitid():

WEXITED
Esperar por procesos que han salido.
WNOWAIT
Mantener el proceso cuyo estado se retorna en infop en un estado esperable.
WSTOPPED
Se retorna el estado para cualquier hijo que se haya detenido al recibir una señal.

Las constantes WCONTINUED y WNOHANG, descritas anteriormente para waitpid(), también se pueden usar con waitid().

El tipo idtype_t se definirá como un tipo enumerado cuyos valores posibles incluirán al menos los siguientes: P_ALL P_PGID P_PID

El encabezado <sys/wait.h> definirá los tipos id_t y pid_t como se describe en <sys/types.h>.

El encabezado <sys/wait.h> definirá el tipo siginfo_t y la unión sigval como se describe en <signal.h>.

La inclusión del encabezado <sys/wait.h> puede también hacer visibles todos los símbolos de <signal.h>.

Se declararán las siguientes funciones y también pueden definirse como macros. Se proporcionarán prototipos de función.

pid_t  wait(int *);
int    waitid(idtype_t, id_t, siginfo_t *, int);
pid_t  waitpid(pid_t, int *, int);
