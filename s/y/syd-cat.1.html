SYD-CAT(1) Manual de Comandos Generales SYD-CAT(1)

NOMBRE

syd-cat - Herramienta para analizar, validar y mostrar la configuración de syd(5)

SINOPSIS

syd-cat [-hjJmM] [-p nombre] <ruta>...

DESCRIPCIÓN

Dada una lista de rutas, analiza y valida la configuración de syd(5).

Imprime la configuración en la salida estándar en caso de éxito.

Las extensiones de archivo de configuración admitidas son .ipset, .netset y .syd-3.

OPCIONES

-h Muestra la ayuda.
-j Muestra la configuración de Syd como JSON.
-J Muestra la configuración de Syd como JSON compacto.
-m mágica Ejecuta un comando mágico al inicializar, puede repetirse.
-M mágica Ejecuta un comando mágico al finalizar, puede repetirse.
-p nombre Muestra las reglas del perfil con el nombre dado. Usa list como nombre para mostrar la lista de perfiles.

VER TAMBIÉN

syd(1), syd(2), syd(5), syd(7)
