NOMBRE

syncsnoop.bt - Rastrea la variedad de llamadas syscalls sync(). Usa bpftrace/eBPF.

SINOPSIS

syncsnoop.bt

DESCRIPCIÓN

syncsnoop rastrea llamadas a syscalls sync() (sync(), fsync(), msync(), etc.), que vacían la caché del sistema de archivos y los búferes a los dispositivos de almacenamiento. Estas llamadas pueden causar perturbaciones en el rendimiento, y puede ser útil saber si ocurren, cuándo ocurren y con qué frecuencia.

Esto se logra rastreando la variedad de syscalls sync() a través de tracepoints.

Este programa es también un ejemplo básico de eBPF/bcc.

Dado que esto utiliza BPF, solo el usuario root puede usar esta herramienta.

REQUISITOS

CONFIG_BPF y bpftrace.

EJEMPLOS

Rastrear llamadas a syscalls sync():
# syncsnoop.bt

CAMPOS

HORA
Una marca de tiempo en la salida, en formato "HH:MM:SS".
PID
El ID del proceso que estuvo en CPU durante el evento.
COMM
El nombre del proceso que estuvo en CPU durante el evento.
EVENTO
El nombre del tracepoint para el evento sync.

SOBRECARGA

Esto rastrea las syscalls sync y imprime la salida para cada evento. Dado que se espera que la tasa sea generalmente baja (<< 100/s), se espera que la sobrecarga sea insignificante.

FUENTE

Esto es de bpftrace.

https://github.com/bpftrace/bpftrace
