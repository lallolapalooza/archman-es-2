NOMBRE

syslog2dlf - convierte archivos de registro syslog a DLF

SINOPSIS

syslog2dlf

DESCRIPCIÓN

Este script utiliza el módulo Lire::Syslog para crear una representación DLF de los archivos de registro syslog. Puede procesar todos los formatos de registro syslog soportados por dicho módulo.

EJEMPLOS

Para procesar un registro como el producido por syslog:

$ syslog2dlf < syslog.log

syslog2dlf rara vez se usará por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report syslog < /var/log/syslog.log

VER TAMBIÉN

Lire::Syslog(3pm)
