sysinfo(2) Manual de llamadas al sistema sysinfo(2)

NOMBRE

sysinfo - obtener información del sistema

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/sysinfo.h>
int sysinfo(struct sysinfo *info);

DESCRIPCIÓN

sysinfo() devuelve ciertas estadísticas sobre el uso de memoria y swap, así como la carga promedio.

Hasta Linux 2.3.16, sysinfo() devolvía información en la siguiente estructura:


struct sysinfo {
    long uptime;             /* Segundos desde el arranque */
    unsigned long loads[3];  /* Promedios de carga de 1, 5 y 15 minutos */
    unsigned long totalram;  /* Tamaño total de memoria principal utilizable */
    unsigned long freeram;   /* Tamaño de memoria disponible */
    unsigned long sharedram; /* Cantidad de memoria compartida */
    unsigned long bufferram; /* Memoria utilizada por buffers */
    unsigned long totalswap; /* Tamaño total del espacio de swap */
    unsigned long freeswap;  /* Espacio de swap aún disponible */
    unsigned short procs;    /* Número de procesos actuales */
    char _f[22];             /* Relleno para que la estructura tenga 64 bytes */
};

En la estructura anterior, los tamaños de los campos de memoria y swap se dan en bytes.

Desde Linux 2.3.23 (i386) y Linux 2.3.48 (todas las arquitecturas), la estructura es:


struct sysinfo {
    long uptime;             /* Segundos desde el arranque */
    unsigned long loads[3];  /* Promedios de carga de 1, 5 y 15 minutos */
    unsigned long totalram;  /* Tamaño total de memoria principal utilizable */
    unsigned long freeram;   /* Tamaño de memoria disponible */
    unsigned long sharedram; /* Cantidad de memoria compartida */
    unsigned long bufferram; /* Memoria utilizada por buffers */
    unsigned long totalswap; /* Tamaño total del espacio de swap */
    unsigned long freeswap;  /* Espacio de swap aún disponible */
    unsigned short procs;    /* Número de procesos actuales */
    unsigned long totalhigh; /* Tamaño total de memoria alta */
    unsigned long freehigh;  /* Tamaño de memoria alta disponible */
    unsigned int mem_unit;   /* Tamaño de la unidad de memoria en bytes */
    char _f[20-2*sizeof(long)-sizeof(int)];
                             /* Relleno hasta 64 bytes */
};

En la estructura anterior, los tamaños de los campos de memoria y swap se dan como múltiplos de mem_unit bytes.

VALOR DE RETORNO

En caso de éxito, sysinfo() devuelve cero. En caso de error, devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
info no es una dirección válida.

ESTÁNDARES

Linux.

HISTORIA

Linux 0.98.pl6.

NOTAS

Toda la información proporcionada por esta llamada al sistema está también disponible a través de /proc/meminfo y /proc/loadavg.
