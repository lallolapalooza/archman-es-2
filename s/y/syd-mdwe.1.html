SYD-MDWE(1) Manual de comandos generales SYD-MDWE(1)

NOMBRE

syd-mdwe - Ejecutar un programa bajo protecciones de Denegación-Escritura-Ejecución de Memoria

SINOPSIS

syd-mdwe [-hms] {comando [argumentos...]}

DESCRIPCIÓN

La utilidad syd-mdwe ejecuta un programa bajo protecciones de Denegación-Escritura-Ejecución de Memoria (MDWE). Las protecciones se pueden aplicar usando prctl(2) y seccomp(2). Estas protecciones son idénticas a las que Syd aplica por defecto.

OPCIONES

-h Mostrar ayuda.
-m Habilitar protecciones MDWE usando prctl(2) PR_SET_MDWE (por defecto: ambos).
-s Habilitar protecciones MDWE usando seccomp(2) (por defecto: ambos).

Ejecutar pax-test una vez de forma independiente y otra vez bajo syd-mdwe(1) en un kernel 6.8 obtenemos las siguientes diferencias:

ESTADO DE SALIDA

Al salir limpiamente, syd-mdwe sale con el mismo código que el proceso hijo. En caso de terminación inesperada, el código de salida se establece en 128 más el número de señal. Si falla la ejecución del proceso hijo, syd-mdwe sale con el número de errno(3).

ADVERTENCIAS

Por defecto, el error de prctl(2) al establecer PR_SET_MDWE(2const) no es fatal. Utilice la opción -m para que este error sea fatal. Esta utilidad no funciona en arquitecturas MIPS donde Linux requiere un stack ejecutable.
