NOMBRE

systemd-id128 - Genera e imprime identificadores sd-128

SINOPSIS

systemd-id128 [OPCIONES...] new

systemd-id128 [OPCIONES...] machine-id

systemd-id128 [OPCIONES...] boot-id

systemd-id128 [OPCIONES...] invocation-id

systemd-id128 [OPCIONES...] var-partition-uuid

systemd-id128 [OPCIONES...] show [NOMBRE|UUID...]

DESCRIPCIÓN

id128 puede ser utilizado para imprimir convenientemente UUIDs sd-id128(3). Qué identificador se imprime depende del verbo específico.

Con new, se generará un nuevo identificador aleatorio.

Con machine-id, se imprimirá el identificador de la máquina actual. Véase machine-id(5).

Con boot-id, se imprimirá el identificador del arranque actual.

Con invocation-id, se imprimirá el identificador de la invocación del servicio actual. Esto está disponible en los servicios de systemd. Véase systemd.exec(5).

Con show, se imprimirán IDs conocidos (por ahora, solo UUIDs de tipo de partición GPT), junto con breves cadenas de identificadores. Cuando no se especifican argumentos, se muestran todos los IDs conocidos. Cuando se especifican argumentos, pueden ser los identificadores o valores de ID de uno o más IDs conocidos, que luego se imprimirán con su nombre, o IDs arbitrarios, que luego se imprimirán con un nombre de marcador de posición. Combine con --uuid para listar los IDs en estilo UUID, es decir, la forma en que se muestran habitualmente los UUIDs de tipo de partición GPT.

machine-id, boot-id y show pueden combinarse con el modificador --app-specific=app-id para generar IDs específicos de la aplicación. Véase sd_id128_get_machine(3) para la discusión sobre cuándo esto es útil. El soporte para show --app-specific= se añadió en la versión 255.

var-partition-uuid imprime un UUID que, siguiendo la **Especificación de Particiones Descubribles**[1], debería usarse como el UUID de partición GPT para /var/, derivado del tipo de partición GPT, indexado por el /etc/machine-id local. Añadido en la versión 257.

OPCIONES

Se entienden las siguientes opciones:

-p, --pretty

Genera la salida como fragmentos de lenguaje de programación.

Añadido en la versión 240.

-P, --value

Solo imprime el valor. Puede combinarse con -u/--uuid.

Añadido en la versión 255.

-a app-id, --app-specific=app-id

Con esta opción, se imprimirán identificadores que son el resultado de hashear el identificador de aplicación app-id y otro ID. El argumento app-id debe ser una cadena sd-id128 válida que identifique la aplicación. Cuando se usa con machine-id, el otro ID será el ID de máquina como se describe en machine-id(5), cuando se usa con boot-id, el otro ID será el ID de arranque, y cuando se usa con show, el otro ID o IDs deben especificarse a través de los argumentos posicionales.

Añadido en la versión 240.

-u, --uuid

Genera la salida como un UUID formateado en la representación canónica", con cinco grupos de dígitos separados por guiones. Véase la entrada de Wikipedia para Identificadores Únicamente Universales[2] para más discusión.

Añadido en la versión 244.

--no-pager

No canalizar la salida a un paginador.

--no-legend

No imprimir la leyenda, es decir, las cabeceras de columna y el pie de página con pistas.

--json=MODE

Muestra la salida formateada como JSON. Espera uno de los modos "short" (para la salida más corta posible sin espacios en blanco redundantes ni saltos de línea), "pretty" (para una versión bonita de la misma, con indentación y saltos de línea) o "off" (para desactivar la salida JSON, el valor predeterminado).

-j

Equivalente a --json=pretty si se ejecuta en una terminal, y --json=short en caso contrario.

-h, --help

Imprime un texto de ayuda corto y sale.

--version

Imprime una cadena de versión corta y sale.

ESTADO DE SALIDA

En caso de éxito se devuelve 0, y un código de error distinto de cero en caso contrario.

EJEMPLOS

Ejemplo 1. Mostrar un UUID conocido

$ systemd-id128 show --value user-home
773f91ef66d449b5bd83d683bf40ad16
$ systemd-id128 show --value --uuid user-home
773f91ef-66d4-49b5-bd83-d683bf40ad16
$ systemd-id128 show 773f91ef-66d4-49b5-bd83-d683bf40ad16
NOMBRE      ID
user-home 773f91ef66d449b5bd83d683bf40ad16

Ejemplo 2. Generar un UUID específico de la aplicación

$ systemd-id128 machine-id -u
3a9d668b-4db7-4939-8a4a-5e78a03bffb7
$ systemd-id128 new -u
1fb8f24b-02df-458d-9659-cc8ace68e28a
$ systemd-id128 machine-id -u -a 1fb8f24b-02df-458d-9659-cc8ace68e28a
47b82cb1-5339-43da-b2a6-1c350aef1bd1
$ systemd-id128 -Pu show 3a9d668b-4db7-4939-8a4a-5e78a03bffb7 \
    -a 1fb8f24b-02df-458d-9659-cc8ace68e28a
47b82cb1-5339-43da-b2a6-1c350aef1bd1

En una máquina dada con el ID 3a9d668b-4db7-4939-8a4a-5e78a03bffb7, para la aplicación 1fb8f24b-02df-458d-9659-cc8ace68e28a, generamos un ID de máquina específico de la aplicación (47b82cb1-5339-43da-b2a6-1c350aef1bd1). Si queremos recrear posteriormente el mismo cálculo en una máquina diferente, necesitamos especificar ambos IDs explícitamente como parámetros para show.
