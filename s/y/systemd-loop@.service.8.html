NOMBRE

systemd-loop@.service - Adjuntar un dispositivo de bloque loopback

SINOPSIS

systemd-loop@ruta.service

DESCRIPCIÓN

systemd-loop@.service es un servicio plantilla que puede ser usado para adjuntar automáticamente un dispositivo de bloque loopback al inicio (o más tarde). Su cadena de instancia puede hacer referencia a una (escapada) ruta del sistema de archivos que apunte a una imagen de disco para ser adjuntada como dispositivo de bloque loopback. Utilice --path de systemd-escape(1) para escapar adecuadamente una ruta del sistema de archivos.

Esta unidad invoca a systemd-dissect --attach --quiet --loop-ref-auto sobre los archivos especificados; consulte systemd-dissect(1) para más detalles.

VER TAMBIÉN

systemd(1), systemd-dissect(1), systemd-import-generator(8)
