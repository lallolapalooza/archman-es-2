NOMBRE

synclient - utilidad de línea de comandos para consultar y modificar opciones del controlador Synaptics.

SINOPSIS

synclient [-lV?] [var1=valor1 [var2=valor2] ...]

DESCRIPCIÓN

Este programa te permite cambiar los parámetros del controlador Synaptics TouchPad para el servidor XOrg/XFree86 mientras X se está ejecutando.

OPCIONES

-l
Lista la configuración actual del usuario. Esta es la opción predeterminada si no se proporciona ninguna opción.
-V
Muestra el número de versión y sale.
-?
Muestra el mensaje de ayuda.
var=valor
Establece el parámetro de usuario var a valor.

ARCHIVOS

/etc/X11/xorg.conf

EJEMPLOS

Para deshabilitar EdgeMotionMinSpeed:

synclient EdgeMotionMinSpeed=0
