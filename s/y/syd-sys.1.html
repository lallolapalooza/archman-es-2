SYD-SYS(1) Manual de comandos generales SYD-SYS(1)

NOMBRE

syd-sys - Buscar llamadas al sistema, números de error (errnos), solicitudes ioctl, flags de open y señales por número o expresión regular

SINOPSIS

syd-sys [-heios] [-a arch] número|regex

syd-sys -a list

syd-sys [-uU]

DESCRIPCIÓN

Dado un número, syd-sys imprime el nombre de la llamada al sistema correspondiente.

Dado una expresión regular (regex), syd-sys imprime los nombres de las llamadas al sistema que coincidan, ignorando mayúsculas/minúsculas.

Utilice -e para consultar números de errno(3).

Utilice -i para consultar solicitudes de ioctl(2).

Utilice -o para consultar flags de open(2).

Utilice -s para consultar números de signal(7).

Utilice -u para listar inodos de sockets de dominio UNIX usando netlink(7).

Utilice -U para listar inodos de sockets de dominio UNIX usando proc_net(5).

OPCIONES

-h Muestra la ayuda.
-a Especifica una arquitectura alternativa, como x86, x86_64 y aarch64.
Utilice list para imprimir la lista de arquitecturas compatibles con libseccomp.
-e Consulta números de errno(3)
-i Consulta solicitudes de ioctl(2)
-o Consulta flags de open(2)
-s Consulta números de signal(7)
-u Lista inodos de sockets de dominio UNIX usando netlink(7)
-U Lista inodos de sockets de dominio UNIX usando proc_net(5)

VER TAMBIÉN
