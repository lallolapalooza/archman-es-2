sysctl(2) Manual de Llamadas al Sistema sysctl(2)

NOMBRE

sysctl - leer/escribir parámetros del sistema

SINOPSIS

#include <unistd.h>
#include <linux/sysctl.h>
[[deprecated]] int _sysctl(struct __sysctl_args *args);

DESCRIPCIÓN

¡Esta llamada al sistema ya no existe en los kernels actuales! Ver NOTAS.

La llamada _sysctl() lee y/o escribe parámetros del kernel. Por ejemplo, el nombre del host o el número máximo de archivos abiertos. El argumento tiene la forma


struct __sysctl_args {
    int    *name;    /* vector de enteros que describe la variable */
    int     nlen;    /* número de elementos de este vector */
    void   *oldval;  /* 0 o dirección donde almacenar el valor antiguo */
    size_t *oldlenp; /* espacio disponible para el valor antiguo,
                        sobrescrito por el tamaño real del valor antiguo */
    void   *newval;  /* 0 o dirección del nuevo valor */
    size_t  newlen;  /* tamaño del nuevo valor */
};

Esta llamada realiza una búsqueda en una estructura de árbol, que podría parecerse a un árbol de directorios bajo /proc/sys, y si el elemento solicitado se encuentra, llama a alguna rutina apropiada para leer o modificar el valor.

VALOR DE RETORNO

Al completarse con éxito, _sysctl() devuelve 0. De lo contrario, se devuelve un valor de -1 y se establece errno para indicar el error.

ERRORES

EACCES
EPERM
Sin permiso de búsqueda para uno de los "directorios" encontrados, o sin permiso de lectura donde oldval era distinto de NULL, o sin permiso de escritura donde newval era distinto de NULL.
EFAULT
La invocación solicitó el valor anterior estableciendo oldval distinto de NULL, pero permitiendo cero espacio en oldlenp.
ENOTDIR
No se encontró name.

ESTANDARES

Linux.

HISTORIA

Linux 1.3.57. Eliminado en Linux 5.5, glibc 2.32.

Se originó en 4.4BSD. Solo Linux tiene el espejo de /proc/sys, y los esquemas de nombres de objetos difieren entre Linux y 4.4BSD, pero la declaración de la función sysctl() es la misma en ambos.

NOTAS

El uso de esta llamada al sistema se desaconsejó durante mucho tiempo: desde Linux 2.6.24, los usos de esta llamada al sistema generan advertencias en el registro del kernel, y en Linux 5.5, la llamada al sistema finalmente se eliminó. Utilice la interfaz /proc/sys en su lugar.

Tenga en cuenta que en kernels más antiguos donde esta llamada al sistema todavía existe, solo está disponible si el kernel se configuró con la opción CONFIG_SYSCTL_SYSCALL. Además, glibc no proporciona un envoltorio para esta llamada al sistema, lo que requiere el uso de syscall(2).

ERRORES CONOCIDOS

Los nombres de los objetos varían entre las versiones del kernel, lo que hace que esta llamada al sistema sea inútil para las aplicaciones.

No todos los objetos disponibles están documentados correctamente.

Todavía no es posible cambiar el sistema operativo escribiendo en /proc/sys/kernel/ostype.

EJEMPLOS

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/syscall.h>
#include <unistd.h>
#include <linux/sysctl.h>
#define NITEMS(arr)  (sizeof(arr) / sizeof((arr)[0]))
int _sysctl(struct __sysctl_args *args);
#define OSNAMESZ 100
int
main(void)
{
    int                   name[] = { CTL_KERN, KERN_OSTYPE };
    char                  osname[OSNAMESZ];
    size_t                osnamelth;
    struct __sysctl_args  args;
    memset(&args, 0, sizeof(args));
    args.name = name;
    args.nlen = NITEMS(name);
    args.oldval = osname;
    args.oldlenp = &osnamelth;
    osnamelth = sizeof(osname);
    if (syscall(SYS__sysctl, &args) == -1) {
        perror("_sysctl");
        exit(EXIT_FAILURE);
    }
    printf("Esta máquina está ejecutando %*s\n", (int) osnamelth, osname);
    exit(EXIT_SUCCESS);
}
