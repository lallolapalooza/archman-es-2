NOMBRE

systemd-ask-password-console.service, systemd-ask-password-console.path, systemd-ask-password-wall.service, systemd-ask-password-wall.path - Consultar al usuario para contraseñas del sistema en la consola y a través de wall

SINOPSIS

systemd-ask-password-console.service
systemd-ask-password-console.path
systemd-ask-password-wall.service
systemd-ask-password-wall.path

DESCRIPCIÓN

systemd-ask-password-console.service es un servicio del sistema que consulta al usuario para contraseñas del sistema (como claves de cifrado de discos duros y contraseñas de certificados SSL) en la consola. Está diseñado para ser utilizado durante el arranque para asegurar el manejo adecuado de las contraseñas necesarias para el arranque. systemd-ask-password-wall.service es un servicio del sistema que informa a todos los usuarios conectados sobre las contraseñas del sistema a través de wall(1). Está diseñado para ser utilizado después del arranque para asegurar que los usuarios sean notificados adecuadamente.

Consulte la documentación para desarrolladores[1] para obtener más información sobre la lógica de contraseñas del sistema.

Tenga en cuenta que estos servicios invocan systemd-tty-ask-password-agent(1) con los parámetros de línea de comandos --watch --console o --watch --wall.

VER TAMBIÉN

systemd(1), systemd-tty-ask-password-agent(1), wall(1)
