NOMBRE

systemd-localed.service, systemd-localed - Mecanismo de bus de localización

SINOPSIS

systemd-localed.service

/usr/lib/systemd/systemd-localed

DESCRIPCIÓN

systemd-localed.service es un servicio del sistema que puede ser utilizado como mecanismo para cambiar la configuración de la localización del sistema, así como el mapeo de teclas de la consola y el mapeo de teclas predeterminado de X11. systemd-localed se activa automáticamente bajo demanda y se termina cuando no se utiliza.

La herramienta localectl(1) es un cliente de línea de comandos para este servicio.

Consulte org.freedesktop.locale1(5) y org.freedesktop.LogControl1(5) para una descripción de la API de D-Bus.

VER TAMBIÉN

systemd(1), locale.conf(5), vconsole.conf(5), localectl(1), loadkeys(1), org.freedesktop.locale1(5)
