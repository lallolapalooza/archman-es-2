NOMBRE

systemd-bsod.service, systemd-bsod - Muestra el mensaje de error de emergencia de arranque a pantalla completa

SINOPSIS

systemd-bsod.service

/usr/lib/systemd/systemd-bsod [OPCIONES...]

DESCRIPCIÓN

systemd-bsod.service se utiliza para mostrar una pantalla azul que contiene un mensaje relacionado con un fallo de arranque, incluyendo un código QR que puede ser escaneado para obtener información útil sobre el fallo.

OPCIONES

Las siguientes opciones son entendidas por systemd-bsod:

-h, --help

Imprime un breve texto de ayuda y sale.

--version

Imprime una cadena de versión corta y sale.

-c, --continuous

Cuando se especifica, systemd-bsod espera continuamente cambios en el journal si no encuentra ningún mensaje de emergencia en el intento inicial.

Añadido en la versión 255.

--tty=

Especifica la TTY a la que se debe dirigir la salida. Por defecto, systemd-bsod buscará automáticamente una VT libre para mostrar el mensaje. Si se especifica esta opción, se puede seleccionar una TTY explícitamente. Usa --tty=/dev/tty para dirigir la salida a la terminal en la que se invoca el comando.

Añadido en la versión 256.

CÓDIGO DE SALIDA

En caso de éxito (si se muestra el mensaje del journal correctamente), se devuelve 0; de lo contrario, un código de fallo distinto de cero.
