NOMBRE

systemd-logind.service, systemd-logind - Gestor de inicios de sesión

SINOPSIS

systemd-logind.service

/usr/lib/systemd/systemd-logind

DESCRIPCIÓN

systemd-logind es un servicio del sistema que gestiona los inicios de sesión de los usuarios. Es responsable de:

•Llevar un registro de los usuarios y sesiones, sus procesos y su estado de inactividad. Esto se implementa asignando una unidad de slice de systemd para cada usuario debajo de user.slice, y una unidad de scope debajo de ella para cada sesión concurrente de un usuario. Además, se inicia un gestor de servicios por usuario como una instancia de servicio del sistema de user@.service para cada usuario conectado.
•Generar y gestionar IDs de sesión. Si la auditoría está disponible y ya hay un ID de sesión de auditoría establecido para una sesión, entonces este ID se reutiliza como el ID de sesión. De lo contrario, se utiliza un contador de sesiones independiente.
•Proporcionar acceso basado en polkit[1] para los usuarios para operaciones como el apagado o suspensión del sistema.
•Implementar una lógica de inhibición de apagado/suspensión para las aplicaciones.
•Manejo de las teclas de hardware de encendido/suspensión.
•Gestión de múltiples asientos (multi-seat).
•Gestión de cambio de sesión.
•Gestión de acceso a dispositivos para los usuarios.
•Iniciación automática de inicios de sesión de texto (gettys) en la activación de la consola virtual y gestión del directorio de tiempo de ejecución del usuario.
•Apagado programado.
•Envío de mensajes "wall".

Las sesiones de usuario se registran en logind a través del módulo PAM pam_systemd(8).

Consulta logind.conf(5) para obtener información sobre la configuración de este servicio.

Consulta sd-login(3) para obtener información sobre los conceptos básicos de logind, como usuarios, sesiones y asientos.

Consulta org.freedesktop.login1(5) y org.freedesktop.LogControl1(5) para obtener información sobre las API de D-Bus que proporciona systemd-logind.

Para más información, consulta Bloqueos de Inhibición[2].

Si estás interesado en escribir un gestor de pantalla que utilice logind, por favor, echa un vistazo a Escribiendo Gestores de Pantalla[3]. Si estás interesado en escribir un entorno de escritorio que utilice logind, por favor, echa un vistazo a Escribiendo Entornos de Escritorio[4].
