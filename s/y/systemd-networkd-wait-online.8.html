SYSTEMD-NETWORKD-WAIT-ONLINE.SERVICE(8) systemd-networkd-wait-online.service SYSTEMD-NETWORKD-WAIT-ONLINE.SERVICE(8)

NOMBRE

systemd-networkd-wait-online.service, systemd-networkd-wait-online@.service, systemd-networkd-wait-online - Esperar a que la red esté en línea

SINOPSIS

systemd-networkd-wait-online.service

systemd-networkd-wait-online@.service

/usr/lib/systemd/systemd-networkd-wait-online

DESCRIPCIÓN

systemd-networkd-wait-online es un servicio del sistema de un solo disparo (ver systemd.service(5)), que espera a que la red esté configurada. Por defecto, esperará a que todos los enlaces que conoce y que son gestionados por systemd-networkd.service(8) estén completamente configurados o fallidos, y a que al menos un enlace esté en línea. Aquí, en línea significa que el estado operativo del enlace es igual o superior a "degradado". El umbral se puede configurar con la opción --operational-state=.

El servicio systemd-networkd-wait-online.service invoca systemd-networkd-wait-online sin opciones. Por lo tanto, espera a que todas las interfaces gestionadas se configuren o fallen, y a que al menos una esté en línea.

El servicio systemd-networkd-wait-online@.service toma un nombre de interfaz, e invoca systemd-networkd-wait-online con -i y el nombre de interfaz especificado. Por lo tanto, espera a que la interfaz especificada se configure y esté en línea. Por ejemplo, systemd-networkd-wait-online@eth0.service espera a que eth0 sea configurada por systemd-networkd y esté en línea.

OPCIONES

Se entienden las siguientes opciones:

-i INTERFACE[:MIN_OPERSTATE[:MAX_OPERSTATE]], --interface=INTERFAZ[:MIN_OPERSTATE[:MAX_OPERSTATE]]

Interfaz de red a esperar antes de decidir si el sistema está en línea. Esto es útil cuando un sistema tiene varias interfaces que se configurarán, pero una particular es necesaria para acceder a ciertos recursos de red. Cuando se usa, se ignoran todas las demás interfaces. Esta opción puede usarse varias veces para esperar a múltiples interfaces de red. Cuando esta opción se especifica varias veces, entonces systemd-networkd-wait-online espera a que todas las interfaces especificadas estén en línea. Opcionalmente, se pueden especificar los estados operativos mínimo y máximo requeridos después de dos puntos ":". Consulte networkctl(1) para ver los estados operativos posibles. Si el estado operativo no se especifica aquí, entonces se utiliza el valor de RequiredForOnline= en el archivo .network correspondiente si está presente, y "degradado" en caso contrario.

Añadido en la versión 213.

--ignore=INTERFAZ

Interfaces de red a ignorar al decidir si el sistema está en línea. Por defecto, solo se ignora la interfaz de bucle inverso. Esta opción puede usarse varias veces para ignorar múltiples interfaces de red.

Añadido en la versión 219.

-o MIN_OPERSTATE[:MAX_OPERSTATE], --operational-state=MIN_OPERSTATE[:MAX_OPERSTATE]

Toma un estado operativo mínimo y un estado operativo máximo opcional. Consulte networkctl(1) para ver los estados operativos posibles. Si se establece, el valor especificado anula la configuración de RequiredForOnline= en los archivos .network. Pero esto no anula los estados operativos especificados en la opción --interface=.

Añadido en la versión 242.

-4, --ipv4

Esperar a que se configure una dirección IPv4 de cada interfaz de red. Si esta opción se especifica con --any, entonces systemd-networkd-wait-online sale con éxito cuando al menos una interfaz se pone en línea y tiene una dirección IPv4. Si el estado operativo mínimo requerido está por debajo de "enrutable", entonces cada enlace (o al menos un enlace con --any) debe tener una dirección IPv4 de enlace local o enrutable. Si el estado operativo mínimo requerido es "enrutable", entonces cada enlace debe tener una dirección IPv4 enrutable.

Si no se especifica ni --ipv4 ni --ipv6, entonces se utiliza el valor de RequiredFamilyForOnline= en el archivo .network correspondiente si está presente.

Añadido en la versión 249.

-6, --ipv6

Esperar a que se configure una dirección IPv6 de cada interfaz de red. Si esta opción se especifica con --any, entonces systemd-networkd-wait-online sale con éxito cuando al menos una interfaz se pone en línea y tiene una dirección IPv6. Si el estado operativo mínimo requerido está por debajo de "enrutable", entonces cada enlace (o al menos un enlace con --any) debe tener una dirección IPv6 de enlace local o enrutable. Si el estado operativo mínimo requerido es "enrutable", entonces cada enlace debe tener una dirección IPv6 enrutable.

Si no se especifica ni --ipv4 ni --ipv6, entonces se utiliza el valor de RequiredFamilyForOnline= en el archivo .network correspondiente si está presente.

Añadido en la versión 249.

--dns

Esperar a que los servidores DNS sean accesibles en cada interfaz. Si esta opción se especifica con --any, entonces systemd-networkd-wait-online sale con éxito cuando al menos una interfaz se pone en línea y tiene un servidor DNS accesible.

Si un enlace tiene la propiedad DefaultRoute=yes (ya sea porque la propiedad de red DNSDefaultRoute= está configurada explícitamente, o porque el enlace no tiene dominios "solo enrutamiento"), o si se configura el dominio de búsqueda ".", entonces esperar a que los servidores DNS específicos del enlace sean accesibles. De lo contrario, permitir que los servidores DNS globales satisfagan la condición.

Añadido en la versión 258.

--any

Incluso si varias interfaces están en estado de configuración, systemd-networkd-wait-online sale con éxito cuando al menos una interfaz se pone en línea. Cuando esta opción se especifica con --interface=, entonces systemd-networkd-wait-online espera a que una de las interfaces especificadas esté en línea. Esta opción es útil cuando algunas interfaces pueden no tener portadora al arrancar.

Añadido en la versión 242.

--timeout=SECS

Falla el servicio si la red no está en línea antes de que transcurra el tiempo de espera. Un tiempo de espera de 0 deshabilita el tiempo de espera. Por defecto son 120 segundos.

Añadido en la versión 219.

-q, --quiet

Suprimir mensajes de registro.

Añadido en la versión 242.

-h, --help

Imprime un texto de ayuda corto y sale.

--version

Imprime una cadena de versión corta y sale.
