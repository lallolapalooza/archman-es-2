NOMBRE

systemd-delta - Buscar archivos de configuración sobreescritos

SINOPSIS

systemd-delta [OPCIONES...] [PREFIJO | PREFIJO/SUFIJO | SUFIJO...]

DESCRIPCIÓN

systemd-delta puede usarse para identificar y comparar archivos de configuración que sobreescriben otros archivos de configuración. Los archivos en /etc/ tienen la mayor prioridad, los archivos en /run/ tienen la segunda mayor prioridad, ..., los archivos en /usr/lib/ tienen la menor prioridad. Los archivos en un directorio con mayor prioridad sobreescriben archivos con el mismo nombre en directorios de menor prioridad. Además, ciertos archivos de configuración pueden tener directorios de ".d" que contienen archivos "drop-in" con fragmentos de configuración que aumentan el archivo de configuración principal. Los archivos "drop-in" pueden ser sobreescritos de la misma manera colocando archivos con el mismo nombre en un directorio de mayor prioridad (excepto que, en el caso de los archivos "drop-in", tanto el nombre del archivo "drop-in" como el nombre del directorio contenedor, que corresponde al nombre del archivo de configuración principal, deben coincidir). Para una explicación más completa, ver systemd.unit(5).

El argumento de la línea de comandos se dividirá en un prefijo y un sufijo. Cualquiera de ellos es opcional. El prefijo debe ser uno de los directorios que contienen archivos de configuración (/etc/, /run/, /usr/lib/, ...). Si se proporciona, solo se mostrarán los archivos sobreescritos contenidos en ese directorio. De lo contrario, se mostrarán todos los archivos sobreescritos. El sufijo debe ser el nombre de un subdirectorio que contiene archivos de configuración como tmpfiles.d, sysctl.d o systemd/system. Si se proporciona, solo se analizarán los archivos de configuración en ese subdirectorio (en todas las rutas de configuración). De lo contrario, se analizarán todos los archivos de configuración. Si el argumento de la línea de comandos no se proporciona en absoluto, se analizarán todos los archivos de configuración. Ver abajo algunos ejemplos.

OPCIONES

Se entienden las siguientes opciones:

-t, --type=

Al listar las diferencias, solo listar aquellas que se solicitan. La lista en sí es una lista separada por comas de los tipos de diferencia deseados.

Tipos reconocidos son:

masked

Mostrar archivos enmascarados

equivalent

Mostrar archivos sobreescritos que, aunque sobreescritos, no difieren en contenido.

redirected

Mostrar archivos que se redirigen a otro.

overridden

Mostrar archivos sobreescritos y modificados.

extended

Mostrar archivos *.conf en directorios drop-in para unidades.

Añadido en la versión 205.

unchanged

Mostrar también archivos sin modificar.

--diff=

Al mostrar archivos modificados, cuando un archivo es sobreescrito, mostrar también una diferencia. Esta opción toma un argumento booleano. Si se omite, se establece por defecto en true.

-h, --help

Imprimir un texto de ayuda corto y salir.

--version

Imprimir una cadena de versión corta y salir.

--no-pager

No redirigir la salida a un paginador.

EJEMPLOS

Para ver toda la configuración local:

systemd-delta

Para ver toda la configuración en tiempo de ejecución:

systemd-delta /run

Para ver todos los cambios de configuración de unidades del sistema:

systemd-delta systemd/system

Para ver todos los cambios de "drop-in" en tiempo de ejecución para unidades del sistema:

systemd-delta --type=extended /run/systemd/system

CÓDIGO DE SALIDA

En caso de éxito, se devuelve 0, y un código de error distinto de cero en caso contrario.
