SYSTOOL(1) Manual de Comandos Generales SYSTOOL(1)

NOMBRE

systool - ver información de dispositivos del sistema por bus, clase y topología

SINOPSIS

systool [opciones [dispositivo]]

DESCRIPCIÓN

Al llamar a systool sin parámetros se presentarán todos los tipos de bus, clases de dispositivos y dispositivos raíz disponibles.

Cuando se proporciona dispositivo, la información solicitada por las opciones solo se muestra para el dispositivo especificado, de lo contrario se mostrarán todos los dispositivos presentes.

systool utiliza las API proporcionadas por libsysfs para recopilar información. systool solo se ejecuta en sistemas Linux que ejecutan kernels 2.5 o posteriores, con el sistema de archivos sysfs montado.

OPCIONES

-a
Mostrar atributos del recurso solicitado.
-b bus
Mostrar información para un bus específico.
-c clase
Mostrar información para una clase específica.
-d
Mostrar solo dispositivos.
-h
Mostrar uso.
-m nombre_módulo
Mostrar información para un módulo específico.
-p
Mostrar la ruta sysfs absoluta al recurso.
-v
Mostrar todos los atributos con valores.
-A atributo
Mostrar el valor del atributo para el recurso solicitado.
-D
Mostrar solo controladores.
-P
Mostrar el padre del dispositivo.

VER TAMBIÉN

La página web de libsysfs en http://linux-diag.sourceforge.net/Sysfsutils.html.
