NOMBRE

systemd-timedated.service, systemd-timedated - Mecanismo de bus de hora y fecha

SINOPSIS

systemd-timedated.service

/usr/lib/systemd/systemd-timedated

DESCRIPCIÓN

systemd-timedated.service es un servicio del sistema que puede ser utilizado como mecanismo para cambiar el reloj y la zona horaria del sistema, así como para habilitar/deshabilitar la sincronización de hora con la red. systemd-timedated se activa automáticamente a petición y se termina cuando no se utiliza.

La herramienta timedatectl(1) es un cliente de línea de comandos para este servicio.

systemd-timedated actualmente ofrece acceso a las siguientes cuatro configuraciones:

•La hora del sistema
•La zona horaria del sistema
•Un booleano que controla si el RTC del sistema está en zona horaria local o UTC
•Si el servicio de sincronización de hora está habilitado/iniciado o deshabilitado/detenido, véase la siguiente sección.

Consulte org.freedesktop.timedate1(5) y org.freedesktop.LogControl1(5) para obtener información sobre la API de D-Bus.

LISTA DE SERVICIOS DE SINCRONIZACIÓN DE HORA CON LA RED

systemd-timedated buscará archivos con extensión ".list" en los directorios ntp-units.d/. Cada archivo se analiza como una lista de nombres de unidades, uno por línea. Las líneas vacías y las líneas con comentarios ("#") se ignoran. Los archivos se leen de /usr/lib/systemd/ntp-units.d/ y los directorios correspondientes bajo /etc/, /run/, /usr/local/lib/. Los archivos en /etc/ anulan los archivos con el mismo nombre en /run/, /usr/local/lib/, y /usr/lib/. Los archivos en /run/ anulan los archivos con el mismo nombre bajo /usr/. Los paquetes deben instalar sus archivos de configuración en /usr/lib/ (paquetes de distribución) o /usr/local/lib/ (instalaciones locales).

Ejemplo 1. Entrada de ntp-units.d/ para systemd-timesyncd

# /usr/lib/systemd/ntp-units.d/80-systemd-timesync.list
systemd-timesyncd.service

Si la variable de entorno $SYSTEMD_TIMEDATED_NTP_SERVICES está establecida, systemd-timedated analizará el contenido de esa variable como una lista de nombres de unidades separada por dos puntos. Cuando se establece, esta variable anula la lista basada en archivos descrita anteriormente.

Ejemplo 2. Una anulación que especifica que chronyd debe ser utilizado si está disponible

SYSTEMD_TIMEDATED_NTP_SERVICES=chronyd.service:systemd-timesyncd.service
