sys_msg.h(0P) Manual del programador POSIX sys_msg.h(0P)

PROLOG

Esta página del manual es parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sys/msg.h — estructuras de colas de mensajes XSI

SINOPSIS

#include <sys/msg.h>

DESCRIPCIÓN

La cabecera <sys/msg.h> definirá los siguientes tipos de datos a través de typedef:

msgqnum_t
Se utiliza para el número de mensajes en la cola de mensajes.
msglen_t
Se utiliza para el número de bytes permitidos en una cola de mensajes.

Estos tipos serán tipos de enteros sin signo que podrán almacenar valores al menos tan grandes como un tipo unsigned short.

La cabecera <sys/msg.h> definirá la siguiente constante simbólica como un indicador de operación de mensaje:

MSG_NOERROR
Sin error si el mensaje es grande.

La cabecera <sys/msg.h> definirá la estructura msqid_ds, que incluirá los siguientes miembros:

struct ipc_perm msg_perm   Estructura de permisos de operación.
msgqnum_t       msg_qnum   Número de mensajes actualmente en la cola.
msglen_t        msg_qbytes Número máximo de bytes permitidos en la cola.
pid_t           msg_lspid  ID del proceso de la última llamada a msgsnd().
pid_t           msg_lrpid  ID del proceso de la última llamada a msgrcv().
time_t          msg_stime  Hora de la última llamada a msgsnd().
time_t          msg_rtime  Hora de la última llamada a msgrcv().
time_t          msg_ctime  Hora del último cambio.

La cabecera <sys/msg.h> definirá los tipos pid_t, size_t, ssize_t y time_t como se describe en <sys/types.h>.

Los siguientes elementos se declararán como funciones y también podrían definirse como macros. Se proporcionarán prototipos de función.

int       msgctl(int, int, struct msqid_ds *);
int       msgget(key_t, int);
ssize_t   msgrcv(int, void *, size_t, long, int);
int       msgsnd(int, const void *, size_t, int);

Además, la cabecera <sys/msg.h> incluirá la cabecera <sys/ipc.h>.
