NOMBRE

systemd-makefs@.service, systemd-mkswap@.service, systemd-growfs@.service, systemd-growfs-root.service, systemd-makefs, systemd-growfs - Creación y expansión de sistemas de archivos bajo demanda

SINOPSIS

systemd-makefs@dispositivo.service

systemd-mkswap@dispositivo.service

systemd-growfs@punto-de-montaje.service

systemd-growfs-root.service

/usr/lib/systemd/systemd-makefs

/usr/lib/systemd/systemd-growfs

DESCRIPCIÓN

systemd-makefs@.service, systemd-mkswap@.service, systemd-growfs@.service, y systemd-growfs-root.service se utilizan para implementar las opciones x-systemd.makefs y x-systemd.growfs en fstab(5), véase systemd.mount(5). Se instancian para cada dispositivo para el cual se necesite inicializar el sistema de archivos o la estructura de swap, y para cada punto de montaje donde se necesite expandir el sistema de archivos.

Estos servicios se inician al arrancar, ya sea justo antes o justo después de que se utilice el punto de montaje o el dispositivo de swap.

systemd-makefs sabe muy poco sobre sistemas de archivos y dispositivos de swap específicos, y después de comprobar que el dispositivo de bloque no contiene ya un sistema de archivos u otro contenido, ejecutará binarios específicos para cada tipo de sistema de archivos (/sbin/mkfs.tipo o /sbin/mkswap). Para ciertos tipos de sistemas de archivos (actualmente ext2/ext3/ext4(5), btrfs(5), xfs(5), f2fs, vfat) y para dispositivos de swap, configurará valores predeterminados razonables y establecerá la etiqueta y la UUID del sistema de archivos basándose en el nombre del dispositivo.

systemd-growfs sabe muy poco sobre sistemas de archivos y dispositivos de swap específicos, e instruirá al kernel para que expanda el sistema de archivos montado al tamaño completo del dispositivo de bloque subyacente. Sin embargo, necesita conocer el número de ioctl(2) específico para cada sistema de archivos, por lo que solo se admiten ciertos tipos. Actualmente: ext4(5), btrfs(5), xfs(5), y particiones dm-crypt (véase cryptsetup(8)).

Si la creación de un sistema de archivos o dispositivo de swap falla, el punto de montaje o swap también falla. Si la expansión de un sistema de archivos falla, se emite una advertencia.
