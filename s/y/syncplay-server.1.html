NOMBRE

syncplay-server - servidor para alojar salas de syncplay

SINOPSIS

syncplay-server [opciones] [archivo] [opciones-del-reproductor]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando syncplay-server.

syncplay-server es un programa al que se conectan los clientes de syncplay y que aloja salas.

Para alojar salas para espectadores a través de internet, asegúrese de que el servidor sea accesible desde internet, es decir, que su puerto de escucha no esté bloqueado por un NAT o un cortafuegos.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que empiezan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-h, --ayuda
Muestra un resumen de las opciones.
--puerto [puerto]
Puerto TCP para escuchar conexiones.
--contraseña [contraseña]
Contraseña del servidor.
--aislar-salas
Indica si las salas deben aislarse.
--desactivar-listo
Desactiva la función de "listo".
--desactivar-chat
Desactiva la función de chat.
--sal [sal]
Cadena aleatoria utilizada para generar contraseñas de salas gestionadas.
--archivo-motd [archivo]
Ruta a un archivo desde el que se leerá el mensaje del día (motd).
--archivo-db-salas [archivo]
Habilita la persistencia de salas. La ruta es a donde se cargará/creará un archivo de base de datos donde se escribirán y leerán los datos de las salas. Esto permitirá que las salas persistan sin observadores y a través de reinicios. No funcionará si se utiliza --aislar-salas.
--archivo-salas-permanentes [archivo]
Especifica una lista de salas que aún se mostrarán aunque su lista de reproducción esté vacía. La ruta es a un archivo de texto con una sala por línea. Esto requerirá que las salas persistentes estén habilitadas.
--longitud-max-mensaje-chat [longitudMaximaMensajeChat]
Número máximo de caracteres en un mensaje de chat (por defecto es 150).
--longitud-max-nombre-usuario [longitudMaximaNombreUsuario]
Número máximo de caracteres en un nombre de usuario (por defecto es 150).
--archivo-db-estadisticas [archivo]
Habilita las estadísticas del servidor utilizando el archivo de base de datos SQLite.
--tls [ruta]
Habilita las conexiones TLS utilizando los archivos de certificado en la ruta.
