sys_sem.h(0P) Manual del programador POSIX sys_sem.h(0P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sys/sem.h — instalación de semáforos XSI

SINOPSIS

#include <sys/sem.h>

DESCRIPCIÓN

El archivo de cabecera <sys/sem.h> definirá la siguiente constante simbólica para su uso como indicador de operación de semáforo:

SEM_UNDO
Establecer entrada de ajuste al salir.

El archivo de cabecera <sys/sem.h> definirá las siguientes constantes simbólicas para su uso como comandos para la función semctl():

GETNCNT
Obtener semncnt.
GETPID
Obtener sempid.
GETVAL
Obtener semval.
GETALL
Obtener todos los casos de semval.
GETZCNT
Obtener semzcnt.
SETVAL
Establecer semval.
SETALL
Establecer todos los casos de semval.

El archivo de cabecera <sys/sem.h> definirá la estructura semid_ds, que incluirá los siguientes miembros:

struct ipc_perm  sem_perm  Estructura de permisos de operación.
unsigned short   sem_nsems Número de semáforos en el conjunto.
time_t           sem_otime Hora de la última operación semop().
time_t           sem_ctime Hora del último cambio por semctl().

El archivo de cabecera <sys/sem.h> definirá los tipos pid_t, size_t y time_t como se describe en <sys/types.h>.

Un semáforo se representará mediante una estructura anónima, que incluirá los siguientes miembros:

unsigned short  semval   Valor del semáforo.
pid_t           sempid   ID del proceso de la última operación.
unsigned short  semncnt  Número de procesos esperando a que semval
                         sea mayor que el valor actual.
unsigned short  semzcnt  Número de procesos esperando a que semval
                         sea 0.

El archivo de cabecera <sys/sem.h> definirá la estructura sembuf, que incluirá los siguientes miembros:

unsigned short  sem_num   Número de semáforo.
short           sem_op    Operación de semáforo.
short           sem_flg   Indicadores de operación.

Lo siguiente se declarará como funciones y también puede definirse como macros. Se proporcionarán prototipos de función.

int   semctl(int, int, int, ...);
int   semget(key_t, int, int);
int   semop(int, struct sembuf *, size_t);

Además, el archivo de cabecera <sys/sem.h> incluirá el archivo <sys/ipc.h>.
