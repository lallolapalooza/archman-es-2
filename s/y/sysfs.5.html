sysfs(5) Manual de Formatos de Archivo sysfs(5)

NOMBRE

sysfs - un sistema de archivos para exportar objetos del kernel

DESCRIPCIÓN

El sistema de archivos sysfs es un pseudo-sistema de archivos que proporciona una interfaz a las estructuras de datos del kernel. (Más precisamente, los archivos y directorios en sysfs proporcionan una vista de las estructuras kobject definidas internamente en el kernel.) Los archivos bajo sysfs proporcionan información sobre dispositivos, módulos del kernel, sistemas de archivos y otros componentes del kernel.

El sistema de archivos sysfs se monta comúnmente en /sys. Típicamente, se monta automáticamente por el sistema, pero también puede montarse manualmente usando un comando como:


mount -t sysfs sysfs /sys

Muchos de los archivos en el sistema de archivos sysfs son de solo lectura, pero algunos archivos son escribibles, permitiendo modificar variables del kernel. Para evitar redundancia, se utilizan enlaces simbólicos extensivamente para conectar entradas a través del árbol del sistema de archivos.

Archivos y directorios

La siguiente lista describe algunos de los archivos y directorios bajo la jerarquía de /sys.

/sys/block
Este subdirectorio contiene un enlace simbólico por cada dispositivo de bloque que se ha descubierto en el sistema. Los enlaces simbólicos apuntan a directorios correspondientes bajo /sys/devices.
/sys/bus
Este directorio contiene un subdirectorio por cada tipo de bus en el kernel. Dentro de cada uno de estos directorios hay dos subdirectorios:
dispositivos
Este subdirectorio contiene enlaces simbólicos a entradas en /sys/devices que corresponden a los dispositivos descubiertos en este bus.
controladores
Este subdirectorio contiene un subdirectorio por cada controlador de dispositivo que está cargado en este bus.
/sys/class
Este subdirectorio contiene una sola capa de subdirectorios adicionales para cada una de las clases de dispositivos que se han registrado en el sistema (por ejemplo, terminales, dispositivos de red, dispositivos de bloque, dispositivos gráficos, dispositivos de sonido, etc.). Dentro de cada uno de estos subdirectorios hay enlaces simbólicos para cada uno de los dispositivos de esta clase. Estos enlaces simbólicos hacen referencia a entradas en el directorio /sys/devices.
/sys/class/net
Cada una de las entradas en este directorio es un enlace simbólico que representa uno de los dispositivos de red reales o virtuales que son visibles en el espacio de nombres de red del proceso que está accediendo al directorio. Cada uno de estos enlaces simbólicos hace referencia a entradas en el directorio /sys/devices.
/sys/dev
Este directorio contiene dos subdirectorios, block/ y char/, que corresponden, respectivamente, a los dispositivos de bloque y de carácter del sistema. Dentro de cada uno de estos subdirectorios hay enlaces simbólicos con nombres de la forma ID-mayor:ID-menor, donde los valores de ID corresponden al ID mayor y menor de un dispositivo específico. Cada enlace simbólico apunta al directorio sysfs de un dispositivo. Los enlaces simbólicos dentro de /sys/dev proporcionan así una forma sencilla de buscar la interfaz sysfs usando los ID de dispositivo devueltos por una llamada a stat(2) (o similar).
La siguiente sesión de shell muestra un ejemplo de /sys/dev:

$ stat -c "%t %T" /dev/null;
1 3
$ readlink /sys/dev/char/1\:3;
../../devices/virtual/mem/null
$ ls -Fd /sys/devices/virtual/mem/null;
/sys/devices/virtual/mem/null/
$ ls -d1 /sys/devices/virtual/mem/null/*;
/sys/devices/virtual/mem/null/dev
/sys/devices/virtual/mem/null/power/
/sys/devices/virtual/mem/null/subsystem@
/sys/devices/virtual/mem/null/uevent

/sys/devices
Este es un directorio que contiene una representación en sistema de archivos del árbol de dispositivos del kernel, que es una jerarquía de estructuras de dispositivo dentro del kernel.
/sys/firmware
Este subdirectorio contiene interfaces para ver y manipular objetos y atributos específicos del firmware.
/sys/fs
Este directorio contiene subdirectorios para algunos sistemas de archivos. Un sistema de archivos tendrá un subdirectorio aquí solo si eligió crear explícitamente el subdirectorio.
/sys/fs/cgroup
Este directorio se utiliza convencionalmente como punto de montaje para un sistema de archivos tmpfs(5) que contiene puntos de montaje para sistemas de archivos cgroups(7).
/sys/fs/smackfs
El directorio contiene archivos de configuración para el LSM de SMACK. Consulte el archivo del código fuente del kernel Documentation/admin-guide/LSM/Smack.rst.

/sys/kernel
Este subdirectorio contiene varios archivos y subdirectorios que proporcionan información sobre el kernel en ejecución.
/sys/kernel/cgroup/
Para obtener información sobre los archivos en este directorio, consulte cgroups(7).
/sys/kernel/debug/tracing
Punto de montaje para el sistema de archivos tracefs utilizado por la instalación ftrace del kernel. (Para obtener información sobre ftrace, consulte el archivo del código fuente del kernel Documentation/trace/ftrace.txt.)
/sys/kernel/mm
Este subdirectorio contiene varios archivos y subdirectorios que proporcionan información sobre el subsistema de gestión de memoria del kernel.
/sys/kernel/mm/hugepages
Este subdirectorio contiene un subdirectorio para cada uno de los tamaños de página grande que el sistema soporta. El nombre del subdirectorio indica el tamaño de la página grande (por ejemplo, hugepages-2048kB). Dentro de cada uno de estos subdirectorios hay un conjunto de archivos que se pueden usar para ver y (en algunos casos) cambiar la configuración asociada con ese tamaño de página grande. Para más información, consulte el archivo del código fuente del kernel Documentation/admin-guide/mm/hugetlbpage.rst.
