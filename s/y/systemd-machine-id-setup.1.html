NOMBRE

systemd-machine-id-setup - Inicializa el ID de la máquina en /etc/machine-id

SINOPSIS

systemd-machine-id-setup

DESCRIPCIÓN

systemd-machine-id-setup puede ser utilizado por herramientas de instalación del sistema para inicializar el ID de la máquina almacenado en /etc/machine-id en el momento de la instalación, con un ID aprovisionado o generado aleatoriamente. Ver machine-id(5) para más información sobre este archivo.

Si la herramienta se invoca sin el modificador --commit, /etc/machine-id se inicializa con un ID de máquina válido y nuevo si está ausente o vacío. El nuevo ID de máquina se obtendrá de la siguiente manera:

1.Si un ID de máquina válido está almacenado en /run/machine-id, el ID de máquina se copia y se utiliza para inicializar el ID de máquina en /etc/machine-id. Este paso se omite si se especifica --root= o si se ejecuta en un entorno chroot.
2.Si un ID de máquina D-Bus válido ya está configurado para el sistema, el ID de máquina D-Bus se copia y se utiliza para inicializar el ID de máquina en /etc/machine-id.
3.Si se proporciona un ID de máquina válido a través de la credencial system.machine_id, el ID de máquina se copia y se utiliza para inicializar el ID de máquina en /etc/machine-id. Este paso se omite si se especifica --root= o si se ejecuta en un entorno chroot.
4.Si se ejecuta dentro de una máquina virtual KVM y se configura un UUID (mediante la opción -uuid), este UUID se utiliza para inicializar el ID de máquina. El llamante debe asegurarse de que el UUID proporcionado sea suficientemente único y diferente para cada instancia arrancada de la VM. Este paso se omite si se especifica --root= o si se ejecuta en un entorno chroot.
5.De manera similar, si se ejecuta dentro de un entorno de contenedor Linux y se configura un UUID para el contenedor, este se utiliza para inicializar el ID de máquina. Para más detalles, ver la documentación de la Interfaz de Contenedores[1]. Este paso se omite si se especifica --root= o si se ejecuta en un entorno chroot.
6.De lo contrario, se genera aleatoriamente un nuevo ID.

El modificador --commit puede ser utilizado para confirmar un ID de máquina transitorio en el disco, haciéndolo persistente. Para más detalles, ver abajo.

Utilice systemd-firstboot(1) para inicializar el ID de la máquina en imágenes de sistema montadas (pero no arrancadas).

OPCIONES

Se entienden las siguientes opciones:

--root=ruta

Toma una ruta de directorio como argumento. Todas las rutas operadas serán prefijadas con la ruta root alternativa dada, incluyendo la ruta para /etc/machine-id mismo.

Añadido en la versión 212.

--image=ruta

Toma una ruta a un nodo de dispositivo o archivo regular como argumento. Esto es similar a --root= como se describe arriba, pero opera en una imagen de disco en lugar de un árbol de directorios.

Añadido en la versión 249.

--image-policy=política

Toma una cadena de política de imagen como argumento, según systemd.image-policy(7). La política se aplica al operar en la imagen de disco especificada mediante --image=, ver arriba. Si no se especifica, se utiliza por defecto la política "*", es decir, se utilizan todos los sistemas de archivos reconocidos en la imagen.

--commit

Confirma un ID de máquina transitorio en el disco. Este comando puede ser utilizado para convertir un ID de máquina transitorio en uno persistente. Un archivo de ID de máquina transitorio es aquel que fue montado por enlace desde un sistema de archivos en memoria (generalmente "tmpfs") a /etc/machine-id durante la fase temprana del proceso de arranque. Esto puede ocurrir porque /etc/ es inicialmente de solo lectura y carecía de un archivo de ID de máquina válido en ese momento.

Este comando no ejecutará ninguna operación si /etc/machine-id no está montado desde un sistema de archivos en memoria, o si /etc/ es de solo lectura. El comando escribirá el ID de máquina transitorio actual en el disco y desmontará el punto de montaje /etc/machine-id de forma segura para garantizar que este archivo sea siempre válido y accesible para otros procesos.

Este comando es utilizado principalmente por el servicio de arranque temprano systemd-machine-id-commit.service(8).

Añadido en la versión 227.

--print

Imprime el ID de máquina generado o confirmado después de que la operación se complete.

Añadido en la versión 231.

-h, --help

Imprime un breve texto de ayuda y sale.

--version

Imprime una breve cadena de versión y sale.

ESTADO DE SALIDA

En caso de éxito, se devuelve 0, de lo contrario un código de error distinto de cero.
