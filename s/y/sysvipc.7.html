sysvipc(7) Manual de Información Miscelánea sysvipc(7)

NOMBRE

sysvipc - Mecanismos de comunicación entre procesos System V

DESCRIPCIÓN

IPC de System V es el nombre dado a tres mecanismos de comunicación entre procesos que están ampliamente disponibles en sistemas UNIX: colas de mensajes, semáforos y memoria compartida.

Colas de mensajes

Las colas de mensajes de System V permiten el intercambio de datos en unidades llamadas mensajes. Cada mensaje puede tener una prioridad asociada. Las colas de mensajes POSIX proporcionan una API alternativa para lograr el mismo resultado; véase mq_overview(7).

La API de colas de mensajes de System V consta de las siguientes llamadas al sistema:

msgget(2)
Crea una nueva cola de mensajes u obtiene el ID de una cola de mensajes existente. Esta llamada devuelve un identificador que se utiliza en el resto de las APIs.
msgsnd(2)
Añade un mensaje a una cola.
msgrcv(2)
Elimina un mensaje de una cola.
msgctl(2)
Realiza varias operaciones de control en una cola, incluida su eliminación.

Conjuntos de semáforos

Los semáforos de System V permiten a los procesos sincronizar sus acciones. Los semáforos de System V se asignan en grupos llamados conjuntos; cada semáforo en un conjunto es un semáforo contador. Los semáforos POSIX proporcionan una API alternativa para lograr el mismo resultado; véase sem_overview(7).

La API de semáforos de System V consta de las siguientes llamadas al sistema:

semget(2)
Crea un nuevo conjunto u obtiene el ID de un conjunto existente. Esta llamada devuelve un identificador que se utiliza en el resto de las APIs.
semop(2)
Realiza operaciones en los semáforos de un conjunto.
semctl(2)
Realiza varias operaciones de control en un conjunto, incluida su eliminación.

Segmentos de memoria compartida

La memoria compartida de System V permite a los procesos compartir una región de memoria (un "segmento"). La memoria compartida POSIX es una API alternativa para lograr el mismo resultado; véase shm_overview(7).

La API de memoria compartida de System V consta de las siguientes llamadas al sistema:

shmget(2)
Crea un nuevo segmento u obtiene el ID de un segmento existente. Esta llamada devuelve un identificador que se utiliza en el resto de las APIs.
shmat(2)
Adjunta un objeto de memoria compartida existente al espacio de direcciones del proceso que realiza la llamada.
shmdt(2)
Desconecta un segmento del espacio de direcciones del proceso que realiza la llamada.
shmctl(2)
Realiza varias operaciones de control en un segmento, incluida su eliminación.

Espacios de nombres IPC

Para una discusión sobre la interacción de los objetos IPC de System V y los espacios de nombres IPC, véase ipc_namespaces(7).
