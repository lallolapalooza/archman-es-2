PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sys/statvfs.h — Estructura de información del sistema de archivos VFS

SINOPSIS

#include <sys/statvfs.h>

DESCRIPCIÓN

El archivo de cabecera <sys/statvfs.h> definirá la estructura statvfs, que incluirá al menos los siguientes miembros:

unsigned long f_bsize    Tamaño del bloque del sistema de archivos.
unsigned long f_frsize   Tamaño del bloque fundamental del sistema de
                         archivos.
fsblkcnt_t    f_blocks   Número total de bloques en el sistema de archivos
                         en unidades de f_frsize.
fsblkcnt_t    f_bfree    Número total de bloques libres.
fsblkcnt_t    f_bavail   Número de bloques libres disponibles para
                         procesos no privilegiados.
fsfilcnt_t    f_files    Número total de números de serie de archivos.
fsfilcnt_t    f_ffree    Número total de números de serie de archivos libres.
fsfilcnt_t    f_favail   Número de números de serie de archivos disponibles
                         para procesos no privilegiados.
unsigned long f_fsid     ID del sistema de archivos.
unsigned long f_flag     Máscara de bits de valores de f_flag.
unsigned long f_namemax  Longitud máxima del nombre de archivo.

El archivo de cabecera <sys/statvfs.h> definirá los tipos fsblkcnt_t y fsfilcnt_t según se describe en <sys/types.h>.

El archivo de cabecera <sys/statvfs.h> definirá las siguientes constantes simbólicas para el miembro f_flag:

ST_RDONLY
Sistema de archivos de solo lectura.
ST_NOSUID
No admite la semántica de los bits de modo de archivo ST_ISUID y ST_ISGID.

Lo siguiente se declarará como funciones y también puede definirse como macros. Se proporcionarán prototipos de funciones.

int fstatvfs(int, struct statvfs *);
int statvfs(const char *restrict, struct statvfs *restrict);
