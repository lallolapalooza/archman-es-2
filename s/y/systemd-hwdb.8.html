SYSTEMD-HWDB(8) systemd-hwdb SYSTEMD-HWDB(8)

NOMBRE

systemd-hwdb - herramienta de gestión de la base de datos de hardware

SINOPSIS

systemd-hwdb [opciones] update

systemd-hwdb [opciones] query modalias

DESCRIPCIÓN

systemd-hwdb espera un comando y argumentos específicos del comando. Gestiona la base de datos binaria de hardware.

OPCIONES

--usr

Generar en /usr/lib/udev en lugar de /etc/udev.

Añadido en la versión 219.

-r, --root=RUTA

Ruta raíz alternativa en el sistema de archivos.

Añadido en la versión 219.

-s, --strict

Al actualizar, devuelve un valor de salida distinto de cero ante cualquier error de análisis.

Añadido en la versión 239.

-h, --help

Imprime un texto de ayuda corto y sale.

systemd-hwdb [opciones] update

Actualiza la base de datos binaria.

systemd-hwdb [opciones] query MODALIAS

Consulta la base de datos e imprime el resultado.

VER TAMBIÉN
