SYSCTL(8) Manual del Administrador del Sistema SYSCTL(8)

NOMBRE

sysctl - configura parámetros del kernel en tiempo de ejecución

SINOPSIS

sysctl [opción ...] variable[=valor] ...

sysctl -p archivo-o-expresión-regular ...

DESCRIPCIÓN

sysctl se utiliza para modificar parámetros del kernel en tiempo de ejecución. Los parámetros disponibles son los listados en /proc/sys/. Procfs es necesario para el soporte de sysctl en Linux. Puedes usar sysctl tanto para leer como para escribir datos de sysctl.

PARÁMETROS

variable
El nombre de una clave para leer. Un ejemplo es kernel.ostype. El separador '/' también se acepta en lugar de '.'.
variable=valor
Para establecer una clave, usa la forma variable=valor donde variable es la clave y valor es el valor que se le asigna. Si el valor contiene comillas o caracteres que son analizados por el shell, puede que necesites encerrar el valor entre comillas dobles.
-n, --values
Usa esta opción para deshabilitar la impresión del nombre de la clave al imprimir los valores.
-e, --ignore
Usa esta opción para ignorar errores sobre claves desconocidas.
-N, --names
Usa esta opción para imprimir solo los nombres. Puede ser útil con intérpretes de comandos que tienen completado programable.
-q, --quiet
Usa esta opción para no mostrar los valores establecidos en la salida estándar.
-w, --write
Forzar que todos los argumentos sean argumentos de escritura e imprimir un error si no pueden ser analizados de esta manera.
-p[ARCHIVO], --load[=ARCHIVO]
Cargar en la configuración de sysctl desde el archivo especificado o /etc/sysctl.conf si no se proporciona ninguno. Especificar - como nombre de archivo significa leer datos de la entrada estándar. Usar esta opción hará que los argumentos de sysctl sean archivos, los cuales se leen en el orden en que se especifican. El argumento del archivo puede ser especificado como una expresión regular.
-a, --all
Mostrar todos los valores actualmente disponibles, excepto los parámetros obsoletos y prohibidos.
--deprecated
Incluir parámetros obsoletos en la lista de valores de --all.
-b, --binary
Imprimir valor sin nueva línea.
--system
Cargar configuraciones de todos los archivos de configuración del sistema. Ver la sección PREFERENCIA DE ARCHIVOS DEL SISTEMA más abajo.
-r, --pattern patrón
Aplicar solo configuraciones que coincidan con patrón. El patrón usa la sintaxis de expresiones regulares extendidas.
-A
Alias de -a
-d
Alias de -h
-f
Alias de -p
-X
Alias de -a
-o
No hace nada, existe por compatibilidad con BSD.
-x
No hace nada, existe por compatibilidad con BSD.
-h, --help
Mostrar texto de ayuda y salir.
-V, --version
Mostrar información de versión y salir.

ARCHIVOS

/proc/sys
/etc/sysctl.d/*.conf
/run/sysctl.d/*.conf
/usr/local/lib/sysctl.d/*.conf
/usr/lib/sysctl.d/*.conf
/lib/sysctl.d/*.conf
/etc/sysctl.conf

NOTAS

Preferencia de archivos del sistema

Al usar la opción --system, sysctl leerá archivos de directorios en la siguiente lista en el orden dado de arriba a abajo. Una vez que un archivo con un nombre dado es cargado, cualquier archivo con el mismo nombre en directorios subsiguientes es ignorado.

/etc/sysctl.d/*.conf
/run/sysctl.d/*.conf
/usr/local/lib/sysctl.d/*.conf
/usr/lib/sysctl.d/*.conf
/lib/sysctl.d/*.conf

Todos los archivos de configuración se ordenan lexicográficamente, independientemente del directorio en el que residan. Los archivos de configuración pueden ser completamente reemplazados (al tener un nuevo archivo de configuración con el mismo nombre en un directorio de mayor prioridad) o parcialmente reemplazados (al tener un archivo de configuración que se ordena más tarde).

El archivo /etc/sysctl.conf se lee al final, lo que significa que puede reemplazar/sobrescribir cualquier parámetro previamente establecido en archivos de los directorios listados.

Parámetros obsoletos

Los parámetros base_reachable_time y retrans_time están obsoletos. El comando sysctl no permite cambiar los valores de estos parámetros. Los usuarios que insistan en usar interfaces del kernel obsoletas deberían enviar valores al sistema de archivos /proc por otros medios. Por ejemplo:

echo 256 > /proc/sys/net/ipv6/neigh/eth0/base_reachable_time

Parámetros prohibidos

Ciertos parámetros del kernel no deben ser leídos debido a efectos secundarios y serán omitidos por sysctl usando la opción --all.

stat_refresh
Este parámetro no devuelve ningún valor, pero actualiza las estadísticas de vm por núcleo.

EJEMPLOS

/sbin/sysctl -a
/sbin/sysctl -n kernel.hostname
/sbin/sysctl -w kernel.domainname="ejemplo.com"
/sbin/sysctl -p/etc/sysctl.conf
/sbin/sysctl -a --pattern forward
/sbin/sysctl -a --pattern forward$
/sbin/sysctl -a --pattern 'net.ipv4.conf.(eth|wlan)0.arp'
/sbin/sysctl --pattern '^net.ipv6' --system

VER TAMBIÉN

proc(5), sysctl.conf(5), regex(7)
