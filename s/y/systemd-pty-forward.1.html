NOMBRE

systemd-pty-forward - Ejecuta un comando con un color de fondo de terminal o título personalizado

SINOPSIS

systemd-pty-forward [OPCIONES...] {COMANDO}

DESCRIPCIÓN

systemd-pty-forward puede usarse para ejecutar un comando con un color de fondo de terminal o título personalizado.

OPCIONES

Se entienden las siguientes opciones:

--background=COLOR

Cambia el color de fondo de la terminal al color ANSI especificado mientras se ejecuta el comando. El color especificado debe ser un color de fondo SGR de ANSI X3.64, es decir, cadenas como "40", "41", ..., "47", "48;2;...", "48;5;...". Consulte ANSI Escape Code (Wikipedia)[1] para más detalles.

Ejemplo: "--background=44" para un fondo azul.

Añadido en la versión 258.

--title=TÍTULO

Cambia el título de la terminal a la cadena especificada mientras se ejecuta el comando.

Añadido en la versión 258.

--quiet, -q

Suprime la salida de información adicional mientras se ejecuta.

Añadido en la versión 258.

--read-only

No acepta ninguna entrada del usuario en la entrada estándar.

Añadido en la versión 258.

-h, --help

Imprime un breve texto de ayuda y sale.

--version

Imprime una breve cadena de versión y sale.
