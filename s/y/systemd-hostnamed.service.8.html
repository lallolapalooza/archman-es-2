NOMBRE

systemd-hostnamed.service, systemd-hostnamed - Demonio para controlar el nombre de host del sistema desde programas

SINOPSIS

systemd-hostnamed.service

/usr/lib/systemd/systemd-hostnamed

DESCRIPCIÓN

systemd-hostnamed.service es un servicio del sistema que puede ser utilizado para cambiar el nombre de host del sistema y metadatos relacionados de la máquina desde programas de usuario. Se activa automáticamente bajo petición y se termina cuando no está en uso.

Actualmente ofrece acceso a cinco variables:

•El nombre de host actual (Ejemplo: "dhcp-192-168-47-11")
•El nombre de host estático (configurado) (Ejemplo: "lennarts-computer")
•El nombre de host bonito (Ejemplo: "El Ordenador de Lennart")
•Un nombre de icono adecuado para el host local (Ejemplo: "computer-laptop")
•Un tipo de chasis (Ejemplo: "tablet")

El nombre de host estático se almacena en /etc/hostname, consulte hostname(5) para más información. El nombre de host bonito, el tipo de chasis y el nombre del icono se almacenan en /etc/machine-info, consulte machine-info(5).

La herramienta hostnamectl(1) es un cliente de línea de comandos para este servicio.

Consulte org.freedesktop.hostname1(5) y org.freedesktop.LogControl1(5) para una descripción de la API de D-Bus.

VER TAMBIÉN

systemd(1), hostname(5), machine-info(5), hostnamectl(1), sethostname(2), org.freedesktop.hostname1(5)
