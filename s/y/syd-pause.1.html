SYD-PAUSE(1) Manual de Comandos Generales SYD-PAUSE(1)

NOMBRE

syd-pause - Bloquear para siempre (hasta ser señalado), ignorando opcionalmente señales seleccionadas

SINOPSIS

syd-pause [ -t ] [ -h ] [ -a ] [ -q ] [ -b ] [ -i ] [ -p señales ]

DESCRIPCIÓN

syd-pause es un proceso diminuto y de larga duración que simplemente espera hasta ser terminado por una señal. Por defecto, respeta todas las señales de terminación estándar; las opciones permiten ignorar señales específicas para que el proceso continúe ejecutándose cuando estas sean entregadas. Esto es útil como un marcador de posición mínimo, objetivo de supervisión o centinela de sincronización en canalizaciones de servicio y sandboxes.

OPCIONES

--help Mostrar ayuda.
-t Ignorar SIGTERM.
-h Ignorar SIGHUP.
-a Ignorar SIGALRM.
-q Ignorar SIGQUIT.
-b Ignorar SIGABRT.
-i Ignorar SIGINT.
-p señales Ignorar la lista de números de señal separados por comas dada en señales (ej. -p 1,2,3,15).
Los números deben ser válidos según signal(7). Esta bandera puede combinarse con las banderas cortas anteriores.

ESTADO DE SALIDA

En caso de terminación normal por una señal, syd-pause sale con 0. En caso de errores, syd-pause sale con el valor errno(3) correspondiente.
