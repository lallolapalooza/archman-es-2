NOMBRE

systemd-network-generator.service, systemd-network-generator - Genera la configuración de red a partir de la línea de comandos del kernel

SINOPSIS

systemd-network-generator.service

/usr/lib/systemd/systemd-network-generator

DESCRIPCIÓN

systemd-network-generator.service es un servicio del sistema que traduce las opciones ip= y relacionadas en la línea de comandos del kernel (ver abajo) a archivos de configuración de systemd.network(5), systemd.netdev(5) y systemd.link(5) entendidos por systemd-networkd.service(8) y systemd-udevd.service(8).

Los archivos se generan en /run/systemd/network/.

Nota: a pesar del nombre, este generador se ejecuta como un servicio normal de systemd y *no* es una implementación del concepto de systemd.generator(7).

OPCIONES DE LÍNEA DE COMANDOS DEL KERNEL

Esta herramienta entiende las siguientes opciones:

ip=, nameserver=, rd.route=, rd.peerdns=

Traducidas a archivos de systemd.network(5).

Además de los parámetros que dracut.cmdline(7) define, la opción ip= acepta el valor especial "link-local". Si se selecciona, las interfaces de red se configurarán solo para direccionamiento de enlace local (IPv4LL, IPv6LL), no se habilitarán DHCP ni IPv6RA.

Añadido en la versión 245.

ifname=, net.ifname_policy=

Traducidas a archivos de systemd.link(5).

Añadido en la versión 245.

vlan=, bond=, bridge=, bootdev=

Traducidas a archivos de systemd.netdev(5).

Añadido en la versión 245.

Ver dracut.cmdline(7) y systemd-udevd.service(8) para la sintaxis y detalles de las opciones.

CREDENCIALES

systemd-network-generator soporta la lógica de credenciales del servicio implementada por ImportCredential=/LoadCredential=/SetCredential= (ver systemd.exec(5) para detalles). Las siguientes credenciales se utilizan cuando se pasan:

network.conf.*, network.link.*, network.netdev.*, network.network.*

Estas credenciales deben contener datos de configuración válidos de networkd.conf(5), systemd.link(5), systemd.netdev(5), systemd.network(5). De cada credencial coincidente se creará un archivo separado. Ejemplo: una credencial pasada network.link.50-foobar se copiará a un archivo de configuración 50-foobar.link.

Tenga en cuenta que los archivos resultantes se crean legibles para todos, por lo que se recomienda no incluir secretos en estas credenciales, sino proporcionarlos a través de credenciales separadas directamente a systemd-networkd.service(8).

Añadido en la versión 256.

Tenga en cuenta que, por defecto, el servicio systemd-networkd.service(8) está configurado para heredar estas credenciales del gestor de servicios.
