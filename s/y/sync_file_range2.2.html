sync_file_range(2) Manual de Llamadas al Sistema sync_file_range(2)

NOMBRE

sync_file_range - sincroniza un segmento de archivo con el disco

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#define _FILE_OFFSET_BITS 64
#include <fcntl.h>
int sync_file_range(int fd, off_t offset, off_t nbytes,
                    unsigned int flags);

DESCRIPCIÓN

sync_file_range() permite un control fino al sincronizar el archivo abierto al que se refiere el descriptor de archivo fd con el disco.

offset es el byte inicial del rango del archivo a sincronizar. nbytes especifica la longitud del rango a sincronizar, en bytes; si nbytes es cero, entonces todos los bytes desde offset hasta el final del archivo se sincronizan. La sincronización se realiza en unidades del tamaño de página del sistema: offset se redondea hacia abajo hasta un límite de página; (offset+nbytes-1) se redondea hacia arriba hasta un límite de página.

El argumento de máscara de bits flags puede incluir cualquiera de los siguientes valores:

SYNC_FILE_RANGE_WAIT_BEFORE
Espera la escritura de todas las páginas del rango especificado que ya se han enviado al controlador del dispositivo para su escritura antes de realizar cualquier escritura.
SYNC_FILE_RANGE_WRITE
Inicia la escritura de todas las páginas sucias del rango especificado que actualmente no están enviadas a escritura. Ten en cuenta que incluso esto puede bloquearse si intentas escribir más que el tamaño de la cola de solicitudes.
SYNC_FILE_RANGE_WAIT_AFTER
Espera la escritura de todas las páginas del rango después de realizar cualquier escritura.

Se permite especificar flags como 0, lo que no hace nada.

Advertencia

Esta llamada al sistema es extremadamente peligrosa y no debe utilizarse en programas portátiles. Ninguna de estas operaciones escribe los metadatos del archivo. Por lo tanto, a menos que la aplicación esté estrictamente sobrescribiendo bloques de disco ya existentes, no hay garantías de que los datos estarán disponibles después de un fallo. No hay interfaz de usuario para saber si una escritura es puramente una sobrescritura. En sistemas de archivos que utilizan semánticas de copia en escritura (por ejemplo, btrfs) es imposible sobrescribir bloques asignados existentes. Al escribir en un espacio preasignado, muchos sistemas de archivos también requieren llamadas al asignador de bloques, que esta llamada al sistema no sincroniza con el disco. Esta llamada al sistema no descarga las cachés de escritura del disco y, por lo tanto, no proporciona ninguna integridad de datos en sistemas con cachés de escritura de disco volátiles.

Algunos detalles

SYNC_FILE_RANGE_WAIT_BEFORE y SYNC_FILE_RANGE_WAIT_AFTER detectarán cualquier error de E/S o condiciones ENOSPC y los devolverán al llamador.

Combinaciones útiles de los bits de flags son:

SYNC_FILE_RANGE_WAIT_BEFORE | SYNC_FILE_RANGE_WRITE
Asegura que todas las páginas del rango especificado que estaban sucias cuando se llamó a sync_file_range() se envían a escritura. Esta es una operación de inicio-de-escritura-para-integridad-de-datos.
SYNC_FILE_RANGE_WRITE
Inicia la escritura de todas las páginas sucias del rango especificado que actualmente no están en proceso de escritura. Esta es una operación de descarga-a-disco asíncrona. No es adecuada para operaciones de integridad de datos.
SYNC_FILE_RANGE_WAIT_BEFORE (o SYNC_FILE_RANGE_WAIT_AFTER)
Espera la finalización de la escritura de todas las páginas del rango especificado. Esto se puede usar después de una operación anterior de SYNC_FILE_RANGE_WAIT_BEFORE | SYNC_FILE_RANGE_WRITE para esperar la finalización de esa operación y obtener su resultado.
SYNC_FILE_RANGE_WAIT_BEFORE | SYNC_FILE_RANGE_WRITE | SYNC_FILE_RANGE_WAIT_AFTER
Esta es una operación de escritura-para-integridad-de-datos que asegurará que todas las páginas del rango especificado que estaban sucias cuando se llamó a sync_file_range() se han confirmado en el disco.

VALOR DE RETORNO

En caso de éxito, sync_file_range() devuelve 0; en caso de error, devuelve -1 y se establece errno para indicar el error.

ERRORES

EBADF
fd no es un descriptor de archivo válido.
EINVAL
flags especifica un bit inválido; o offset o nbytes son inválidos.
EIO
Error de E/S.
ENOMEM
Memoria agotada.
ENOSPC
Espacio en disco agotado.
ESPIPE
fd se refiere a algo que no es un archivo regular, un dispositivo de bloque o un directorio.

VERSIÓNES

sync_file_range2()

Algunas arquitecturas (por ejemplo, PowerPC, ARM) necesitan que los argumentos de 64 bits estén alineados en un par de registros adecuado. En dichas arquitecturas, la firma de llamada de sync_file_range() mostrada en la SINOPSIS forzaría a desperdiciar un registro como relleno entre los argumentos fd y offset. (Ver syscall(2) para detalles.) Por lo tanto, estas arquitecturas definen una llamada al sistema diferente que ordena los argumentos adecuadamente:


int sync_file_range2(int fd, unsigned int flags,
                     off_t offset, off_t nbytes);

El comportamiento de esta llamada al sistema es, por lo demás, exactamente el mismo que sync_file_range().

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.17.

sync_file_range2()

Una llamada al sistema con esta firma apareció por primera vez en la arquitectura ARM en Linux 2.6.20, con el nombre arm_sync_file_range(). Fue renombrada en Linux 2.6.22, cuando se agregó la llamada al sistema análoga para PowerPC. En arquitecturas donde se proporciona soporte de glibc, glibc envuelve transparentemente sync_file_range2() bajo el nombre sync_file_range().

NOTAS

_FILE_OFFSET_BITS debe definirse como 64 en el código que toma la dirección de sync_file_range, si el código está destinado a ser portable a plataformas tradicionales x86 y ARM de 32 bits donde el ancho de off_t tiene un valor predeterminado de 32 bits.

VER TAMBIÉN

fdatasync(2), fsync(2), msync(2), sync(2)

NOMBRE

sync_file_range2 - sincroniza un rango de un archivo abierto con el almacenamiento persistente

LIBRERÍA

API del sistema (función del sistema)

SINOPSIS

#include <fcntl.h>

int sync_file_range2(int fd, unsigned int flags, off64_t offset, off64_t nbytes);

DESCRIPCIÓN

La llamada al sistema sync_file_range2() sincroniza un rango de datos y/o metadatos de un archivo abierto con el almacenamiento persistente. El archivo se especifica mediante el descriptor de archivo fd. El rango a sincronizar se especifica mediante offset y nbytes.

El argumento flags controla el comportamiento de la sincronización. Los siguientes valores de flags están definidos:

SYNC_FILE_RANGE_WAIT_BEFORE
Espera a que se complete la escritura de los datos en el rango especificado antes de devolver. Si no se especifica, esta operación se realiza de forma asíncrona.
SYNC_FILE_RANGE_WRITE
Escribe los datos del rango especificado en el almacenamiento subyacente, pero no necesariamente sincroniza los metadatos del archivo.
SYNC_FILE_RANGE_COPY
Implica que el rango especificado está siendo utilizado como fuente o destino de una operación de copia de datos (por ejemplo, a través de sendfile(2) o splice(2)). La operación de sincronización se optimiza para evitar escrituras innecesarias de bloques que ya están en la caché del sistema de archivos.
SYNC_FILE_RANGE_NOFLUSH
No intenta vaciar el rango especificado. Esto puede ser útil para aplicaciones que gestionan su propia caché de datos y solo necesitan asegurarse de que los metadatos estén sincronizados.

Si nbytes es 0, el rango se extiende desde offset hasta el final del archivo.

Si offset es 0 y nbytes es 0, se sincroniza todo el archivo, incluyendo los metadatos. Sin embargo, para sincronizar todo el archivo, es más recomendable usar sync(2) o fsync(2).

VALOR DE RETORNO

En caso de éxito, sync_file_range2() devuelve 0. En caso de error, devuelve -1 y establece errno para indicar el error.

ERRORES

EBADF
fd no es un descriptor de archivo válido.
EINVAL
Se especificó un valor de flags no válido, o el valor de offset o nbytes es negativo, o la combinación de offset y nbytes excede el tamaño del archivo.
EIO
Ocurrió un error de E/S.
EISDIR
fd se refiere a un directorio.
ENODATA
El rango especificado no contiene datos que necesiten ser sincronizados (esto puede ocurrir con SYNC_FILE_RANGE_COPY).
ENOTSUP
El sistema de archivos no soporta esta operación, o el dispositivo subyacente no puede realizar esta operación.
EROFS
El archivo está en un sistema de archivos de solo lectura.

VERSIÓNES

La llamada al sistema sync_file_range2() está disponible desde el kernel Linux 2.6.16.

ESTÁNDARES

La llamada al sistema sync_file_range2() no es parte de ningún estándar POSIX. Es una extensión específica de Linux.

HISTORIA

sync_file_range2() apareció por primera vez en el kernel Linux 2.6.16.

NOTAS

El uso de sync_file_range2() es un tema avanzado. La mayoría de las aplicaciones no necesitan llamar directamente a esta primitiva. Para la mayoría de los propósitos, fsync(2) es suficiente para asegurar que los datos se escriban en el disco de forma segura.

La llamada sync_file_range2() no garantiza que los datos se escriban en el medio físico de almacenamiento, sino que se colocan en la caché del sistema de archivos y se programan para su escritura.

Tenga cuidado al usar los flags SYNC_FILE_RANGE_WAIT_BEFORE y SYNC_FILE_RANGE_WRITE juntos, ya que pueden causar bloqueos prolongados en aplicaciones sensibles al rendimiento.

VER TAMBIÉN

fsync(2), sync(2), sync_file_range(2)
