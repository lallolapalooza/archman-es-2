NOMBRE

systemd-machine-id-commit.service - Confirma un ID de máquina transitorio en disco

SINOPSIS

systemd-machine-id-commit.service

DESCRIPCIÓN

systemd-machine-id-commit.service es un servicio de inicio temprano responsable de confirmar los archivos temporales de /etc/machine-id en un sistema de archivos de disco grabable. Consulte machine-id(5) para obtener más información sobre los IDs de máquina.

Este servicio se inicia después de local-fs.target en caso de que /etc/machine-id sea un punto de montaje propio (generalmente de un sistema de archivos en memoria como "tmpfs") y /etc sea grabable. El servicio invocará a systemd-machine-id-setup --commit, que escribe el ID de máquina transitorio actual en disco y desmonta el archivo /etc/machine-id de manera segura para garantizar que el archivo sea siempre válido y accesible para otros procesos. Consulte systemd-machine-id-setup(1) para obtener más detalles.

El caso de uso principal de este servicio son los sistemas donde /etc/machine-id es de solo lectura y no está inicializado inicialmente. En este caso, el gestor del sistema generará un archivo de ID de máquina transitorio en un sistema de archivos en memoria, y lo montará sobre /etc/machine-id, durante la fase temprana de inicio. Este servicio se invoca luego en una fase de inicio posterior, tan pronto como /etc/ se haya vuelto a montar como grabable y, por lo tanto, el ID pueda ser confirmado en disco para hacerlo permanente.

VER TAMBIÉN

systemd(1), systemd-machine-id-setup(1), machine-id(5), systemd-firstboot(1)
