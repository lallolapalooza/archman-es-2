NOMBRE

system-config-printer-applet - gestor de trabajos de impresión

SINOPSIS

system-config-printer-applet [--help] [--version] [--debug]

DESCRIPCIÓN

system-config-printer-applet es un gestor de trabajos de impresión para CUPS. Normalmente, mostrará un icono de impresora en el área de notificación, atenuado cuando no hay trabajos de impresión para el usuario actual. Hacer clic en el icono muestra un gestor de trabajos de impresión sencillo para cancelar o reimprimir trabajos.

Para ahorrar memoria, el applet espera primero hasta que el usuario haya impreso un trabajo antes de colocar el icono en el área de notificación. Para invocar el gestor de trabajos de impresión antes de que se haya impreso un trabajo, ejecute el applet con la opción --no-tray-icon: se proporciona un archivo de escritorio para esto, de modo que debería aparecer en el menú del sistema.

Además de mostrar un icono de impresora en el área de notificación, el applet también proporciona un servidor D-BUS para la interfaz com.redhat.PrintDriverSelection, para ayudar a configurar una nueva impresora cuando se conecta.

OPCIONES

--help

Muestra un mensaje de uso corto.

--version

Muestra la versión del applet.

--debug

Muestra información de depuración.
