sysconf(3) Manual de funciones de biblioteca sysconf(3)

NOMBRE

sysconf - obtener información de configuración en tiempo de ejecución

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
long sysconf(int name);

DESCRIPCIÓN

POSIX permite a una aplicación verificar en tiempo de compilación o ejecución si se admiten ciertas opciones, o cuál es el valor de ciertas constantes o límites configurables.

En tiempo de compilación, esto se hace incluyendo <unistd.h> y/o <limits.h> y comprobando el valor de ciertas macros.

En tiempo de ejecución, se pueden solicitar valores numéricos usando la presente función sysconf(). Se pueden solicitar valores numéricos que puedan depender del sistema de archivos en el que reside un archivo usando fpathconf(3) y pathconf(3). Se pueden solicitar valores de cadena usando confstr(3).

Los valores obtenidos de estas funciones son constantes de configuración del sistema. No cambian durante la vida útil de un proceso.

Para las opciones, normalmente, hay una constante _POSIX_FOO que puede definirse en <unistd.h>. Si no está definida, se debe consultar en tiempo de ejecución. Si está definida como -1, entonces la opción no es compatible. Si está definida como 0, entonces las funciones y encabezados relevantes existen, pero se debe consultar en tiempo de ejecución qué grado de soporte está disponible. Si está definida a un valor distinto de -1 o 0, entonces la opción es compatible. Normalmente el valor (como 200112L) indica el año y mes de la revisión POSIX que describe la opción. glibc usa el valor 1 para indicar soporte mientras no se publique la revisión POSIX. El argumento de sysconf() será _SC_FOO. Para una lista de opciones, vea posixoptions(7).

Para variables o límites, normalmente, hay una constante _FOO, quizás definida en <limits.h>, o _POSIX_FOO, quizás definida en <unistd.h>. La constante no se definirá si el límite no está especificado. Si la constante está definida, proporciona un valor garantizado, y un valor mayor podría ser realmente compatible. Si una aplicación quiere aprovechar valores que pueden cambiar entre sistemas, se puede hacer una llamada a sysconf(). El argumento de sysconf() será _SC_FOO.

variables POSIX.1

Damos el nombre de la variable, el nombre del argumento de sysconf() utilizado para consultar su valor, y una breve descripción.

Primero, los valores compatibles con POSIX.1.

ARG_MAX - _SC_ARG_MAX
La longitud máxima de los argumentos para la familia de funciones exec(3). No debe ser menor que _POSIX_ARG_MAX (4096).
CHILD_MAX - _SC_CHILD_MAX
El número máximo de procesos simultáneos por ID de usuario. No debe ser menor que _POSIX_CHILD_MAX (25).
HOST_NAME_MAX - _SC_HOST_NAME_MAX
Longitud máxima de un nombre de host, sin incluir el byte nulo de terminación, tal como lo devuelve gethostname(2). No debe ser menor que _POSIX_HOST_NAME_MAX (255).
LOGIN_NAME_MAX - _SC_LOGIN_NAME_MAX
Longitud máxima de un nombre de inicio de sesión, incluyendo el byte nulo de terminación. No debe ser menor que _POSIX_LOGIN_NAME_MAX (9).
NGROUPS_MAX - _SC_NGROUPS_MAX
Número máximo de IDs de grupo suplementarios.
ticks de reloj - _SC_CLK_TCK
El número de ticks de reloj por segundo. La variable correspondiente está obsoleta. Se llamaba por supuesto CLK_TCK. (Nota: la macro CLOCKS_PER_SEC no da información: debe ser igual a 1000000.)
OPEN_MAX - _SC_OPEN_MAX
El número máximo de archivos que un proceso puede tener abiertos en un momento dado. No debe ser menor que _POSIX_OPEN_MAX (20).
PAGESIZE - _SC_PAGESIZE
Tamaño de una página en bytes. No debe ser menor que 1.
PAGE_SIZE - _SC_PAGE_SIZE
Un sinónimo de PAGESIZE/_SC_PAGESIZE. (Tanto PAGESIZE como PAGE_SIZE están especificados en POSIX.)
RE_DUP_MAX - _SC_RE_DUP_MAX
El número de repeticiones de una BRE permitidas por regexec(3) y regcomp(3). No debe ser menor que _POSIX2_RE_DUP_MAX (255).
STREAM_MAX - _SC_STREAM_MAX
El número máximo de flujos que un proceso puede tener abiertos en un momento dado. Si está definido, tiene el mismo valor que la macro C estándar FOPEN_MAX. No debe ser menor que _POSIX_STREAM_MAX (8).
SYMLOOP_MAX - _SC_SYMLOOP_MAX
El número máximo de enlaces simbólicos vistos en una ruta antes de que la resolución devuelva ELOOP. No debe ser menor que _POSIX_SYMLOOP_MAX (8).
TTY_NAME_MAX - _SC_TTY_NAME_MAX
La longitud máxima del nombre del dispositivo de terminal, incluyendo el byte nulo de terminación. No debe ser menor que _POSIX_TTY_NAME_MAX (9).
TZNAME_MAX - _SC_TZNAME_MAX
El número máximo de bytes en un nombre de zona horaria. No debe ser menor que _POSIX_TZNAME_MAX (6).
_POSIX_VERSION - _SC_VERSION
indica el año y mes en que se aprobó el estándar POSIX.1 en el formato YYYYMML; el valor 199009L indica la revisión de septiembre de 1990.

NOMBRE

sysconf - obtener valores de configuración de tiempo de ejecución del sistema

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>

long sysconf(int name);

DESCRIPCIÓN

La función sysconf() obtiene valores de configuración del tiempo de ejecución del sistema para las opciones especificadas por name. Los valores solicitados pueden depender de la configuración del sistema actual.

Si el valor de una opción es indeterminado, sysconf() devuelve -1 y errno no se modifica. Para distinguir un valor indeterminado de un error, establezca errno a cero antes de llamar a sysconf(), y luego verifique si errno no es cero cuando sysconf() devuelve -1.

Las siguientes constantes están definidas en <unistd.h> para ser usadas como el argumento name. Los valores predeterminados son los mínimos requeridos por POSIX.1-2008.

_SC_ARG_MAX
El número máximo de bytes que se pueden reservar para los argumentos de un proceso, incluido el entorno. El valor devuelto es la suma de la longitud de la línea de comandos y la longitud del entorno.
_SC_CHILD_MAX
El número máximo de procesos que un solo usuario puede poseer simultáneamente.
_SC_CLK_TCK
El número de tics por segundo en el reloj del sistema. Este valor se utiliza para la división de la carga para calcular el uso de CPU.
_SC_COLLECTIONS
Si se admiten las colecciones de bases de datos de nombres de objetos XFN.
_SC_HOST_NAME_MAX
La longitud máxima de bytes (excluyendo el terminador nulo) de un nombre de host que este sistema puede almacenar o usar.
_SC_LOGIN_NAME_MAX
La longitud máxima de bytes (excluyendo el terminador nulo) del nombre de inicio de sesión que este sistema puede almacenar o usar.
_SC_NGROUPS_MAX
El número máximo de grupos que puede pertenecer un usuario.
_SC_OPEN_MAX
El número máximo de descriptores de archivo que un proceso puede tener abiertos simultáneamente. Esto es una limitación por proceso. El valor real para un proceso dado puede ser mayor, consulte fpathconf(3).
_SC_PAGESIZE
El número de bytes en una página de memoria del sistema. Consulte también getpagesize(3).
_SC_PAGE_SIZE
Lo mismo que _SC_PAGESIZE.
_SC_2_CHAR_MAX
El número máximo de caracteres en un conjunto de caracteres.
_SC_2_C_BIND
Indica si se admiten las facilidades de enlace de compilación POSIX.2.
_SC_2_C_DEV
Indica si se admiten las facilidades de desarrollo del lenguaje C POSIX.2.
_SC_2_C_VER
Indica la versión de las facilidades de desarrollo del lenguaje C POSIX.2.
_SC_2_FORT_DEV
Indica si se admiten las utilidades de desarrollo FORTRAN POSIX.2.
_SC_2_FORT_RUN
Indica si se admiten las utilidades de tiempo de ejecución FORTRAN POSIX.2.
_SC_2_LOCALEDEF
Indica si se admite la creación de locales POSIX.2 a través de localedef(1).
_SC_2_SW_DEV
Indica si se admite la opción de utilidades de desarrollo de software POSIX.2.
_SC_2_SYMLINKS
Indica si se admiten los enlaces simbólicos POSIX.2.
_SC_2_VERSION
Indica la versión del estándar POSIX.2 en el formato YYYYMML.
POSIX2_VERSION - _SC_2_VERSION
indica la versión del estándar POSIX.2 en el formato de YYYYMML.
POSIX2_C_DEV - _SC_2_C_DEV
indica si se admiten las facilidades de desarrollo del lenguaje C POSIX.2.
POSIX2_FORT_DEV - _SC_2_FORT_DEV
indica si se admiten las utilidades de desarrollo FORTRAN POSIX.2.
POSIX2_FORT_RUN - _SC_2_FORT_RUN
indica si se admiten las utilidades de tiempo de ejecución FORTRAN POSIX.2.
_POSIX2_LOCALEDEF - _SC_2_LOCALEDEF
indica si se admite la creación de locales POSIX.2 a través de localedef(1).
POSIX2_SW_DEV - _SC_2_SW_DEV
indica si se admite la opción de utilidades de desarrollo de software POSIX.2.

Estos valores también existen, pero pueden no ser estándar.

- _SC_PHYS_PAGES
El número de páginas de memoria física. Tenga en cuenta que es posible que el producto de este valor y el valor de _SC_PAGESIZE desborde.
- _SC_AVPHYS_PAGES
El número de páginas de memoria física actualmente disponibles.
- _SC_NPROCESSORS_CONF
El número de procesadores configurados. Consulte también get_nprocs_conf(3).
- _SC_NPROCESSORS_ONLN
El número de procesadores actualmente en línea (disponibles). Consulte también get_nprocs_conf(3).

VALOR DE RETORNO

El valor de retorno de sysconf() es uno de los siguientes:

•
En caso de error, se devuelve -1 y errno se establece para indicar el error (por ejemplo, EINVAL, que indica que name es inválido).
•
Si name corresponde a un límite máximo o mínimo, y ese límite es indeterminado, se devuelve -1 y errno no se modifica. (Para distinguir un límite indeterminado de un error, establezca errno a cero antes de la llamada, y luego verifique si errno no es cero cuando se devuelve -1).
•
Si name corresponde a una opción, se devuelve un valor positivo si la opción es compatible, y se devuelve -1 si la opción no es compatible.
•
De lo contrario, se devuelve el valor actual de la opción o límite. Este valor no será más restrictivo que el valor correspondiente que se describió a la aplicación en <unistd.h> o <limits.h> cuando la aplicación fue compilada.

ERRORES

EINVAL
name es inválido.

ERRORES DE PROGRAMACIÓN

Es difícil usar ARG_MAX porque no se especifica cuánto del espacio de argumentos para exec(3) es consumido por las variables de entorno del usuario.

Algunos valores devueltos pueden ser enormes; no son adecuados para asignar memoria.
