SYD-ENV(1) Manual de Comandos Generales SYD-ENV(1)

NOMBRE

syd-env - Ejecuta un comando con el entorno del proceso con el PID dado

SINOPSIS

syd-env pid [-i] [nombre=valor]... {comando [argumentos...]}

syd-env -e <cadena-evaluación>

DESCRIPCIÓN

La utilidad syd-env ejecuta un comando con el entorno del proceso con el PID dado. Es similar a la utilidad env(1), excepto que permite elegir el entorno de un proceso arbitrario.

Dado "-e" con un argumento de cadena, syd-env realiza la expansión de entorno y la sustitución de comandos utilizando wordexp(3).

SEGURIDAD

El proceso hijo de wordexp(3) se ejecuta en un entorno confinado con un tiempo de espera de 3 segundos. El confinamiento se realiza utilizando Landlock, namespaces y seccomp.

VER TAMBIÉN
