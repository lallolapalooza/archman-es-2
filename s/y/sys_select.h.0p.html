sys_select.h(0P) Manual del programador POSIX sys_select.h(0P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sys/select.h — tipos de select

SINOPSIS

#include <sys/select.h>

DESCRIPCIÓN

El archivo de cabecera <sys/select.h> definirá la estructura timeval, que incluirá al menos los siguientes miembros:

time_t         tv_sec      Segundos.
suseconds_t    tv_usec     Microsegundos.

El archivo de cabecera <sys/select.h> definirá los tipos time_t y suseconds_t tal como se describe en <sys/types.h>.

El archivo de cabecera <sys/select.h> definirá el tipo sigset_t tal como se describe en <signal.h>.

El archivo de cabecera <sys/select.h> definirá la estructura timespec tal como se describe en <time.h>.

El archivo de cabecera <sys/select.h> definirá el tipo fd_set como una estructura.

El archivo de cabecera <sys/select.h> definirá la siguiente constante simbólica, que tendrá un valor adecuado para su uso en directivas de preprocesamiento #if:

FD_SETSIZE
Número máximo de descriptores de archivo en una estructura fd_set.

Lo siguiente se declarará como funciones, se definirá como macros, o ambas cosas. Si se declaran funciones, se proporcionarán prototipos de función.

void FD_CLR(int, fd_set *);
int  FD_ISSET(int, fd_set *);
void FD_SET(int, fd_set *);
void FD_ZERO(fd_set *);

Si se implementan como macros, estas pueden evaluar sus argumentos más de una vez, por lo que las aplicaciones deben asegurarse de que los argumentos que proporcionan nunca sean expresiones con efectos secundarios.

Lo siguiente se declarará como funciones y también puede definirse como macros. Se proporcionarán prototipos de función.

int  pselect(int, fd_set *restrict, fd_set *restrict, fd_set *restrict,
         const struct timespec *restrict, const sigset_t *restrict);
int  select(int, fd_set *restrict, fd_set *restrict, fd_set *restrict,
         struct timeval *restrict);

La inclusión del archivo de cabecera <sys/select.h> puede hacer visibles todos los símbolos de los archivos de cabecera <signal.h> y <time.h>.
