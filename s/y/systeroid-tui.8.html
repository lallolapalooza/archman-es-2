SYSTEROID-TUI(8) Administración del Sistema SYSTEROID-TUI(8)

NOMBRE

systeroid-tui - administrar parámetros del kernel con una interfaz de usuario de terminal

SINOPSIS

systeroid-tui [opciones]

DESCRIPCIÓN

systeroid-tui se utiliza para configurar y ver los parámetros del kernel con una interfaz de usuario de terminal.

PARÁMETROS

-t, --tick-rate <ms>
Use esta opción para establecer la tasa de ticks de la terminal. [predeterminado: 250]
-D, --docs <ruta>
Use esta opción para establecer una ruta personalizada para la documentación del kernel.
--save-path <ruta>
Use esta opción para establecer la ruta para guardar los parámetros modificados.
-l, --log-file <ruta>
Use esta opción para establecer el archivo donde se guardarán los registros.
-s, --section <sección>
Use esta opción para establecer la sección para filtrar.

-q, --query <consulta> establece la consulta para buscar.

--bg-color <color>
Use esta opción para establecer el color de fondo. [predeterminado: negro]
--fg-color <color>
Use esta opción para establecer el color de primer plano. [predeterminado: blanco]
-n, --no-docs
No mostrar la documentación del kernel.
--deprecated
Incluir variables obsoletas al listar.
-h, --help
Mostrar texto de ayuda y salir.
-V, --version
Mostrar información de la versión y salir.

EJEMPLOS

systeroid-tui -t 500
systeroid-tui -s kernel
systeroid-tui -q "fs.quota"
systeroid-tui --fg-color blue
systeroid-tui --bg-color ffff99 --fg-color 003366
systeroid-tui -D /usr/share/doc/linux
systeroid-tui --save-path 99-local.conf
systeroid-tui --log-file systeroid.log
systeroid-tui -n
