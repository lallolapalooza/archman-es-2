PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sys/utsname.h — estructura del nombre del sistema

SINOPSIS

#include <sys/utsname.h>

DESCRIPCION

El archivo de cabecera <sys/utsname.h> definirá la estructura utsname que incluirá al menos los siguientes miembros:

char  sysname[]  Nombre de esta implementación del sistema operativo.
char  nodename[] Nombre de este nodo dentro de la red de
                 comunicaciones a la que está conectado este nodo, si lo hay.
char  release[]  Nivel de lanzamiento actual de esta implementación.
char  version[]  Nivel de versión actual de este lanzamiento.
char  machine[]  Nombre del tipo de hardware en el que se está ejecutando el sistema.

Los arreglos de caracteres son de tamaño no especificado, pero los datos almacenados en ellos estarán terminados por un byte nulo.

La siguiente función será declarada y también podrá definirse como una macro:

int uname(struct utsname *);
