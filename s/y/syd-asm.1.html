NOMBRE

syd-asm - Desensambla instrucciones de CPU crudas de la entrada estándar

SINOPSIS

syd-asm [-h] [-a arch]

syd-asm [-h] -a list

DESCRIPCIÓN

syd-asm lee instrucciones de CPU como bytes crudos o codificados en hexadecimal desde la entrada estándar y las desensambla. Las instrucciones desensambladas se imprimen en formato JSON, una instrucción por línea. El desensamblaje se realiza de forma nativa para las arquitecturas x86, x86_64, x32, arm, aarch64 y riscv64, y recurre a GNU objdump(1) para otras arquitecturas. Todavía no hay soporte para LLVM objdump(1).

OPCIONES

-h Muestra la ayuda.
-a Especifica la arquitectura alternativa, como x86, x86_64 y aarch64.
Usa list para imprimir la lista de arquitecturas compatibles con libseccomp.

VER TAMBIÉN

syd(1), syd(2), syd(5), syd(7), objdump(1)
