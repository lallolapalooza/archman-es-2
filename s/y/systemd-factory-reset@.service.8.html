SYSTEMD-FACTORY-RESET(8) systemd-factory-reset SYSTEMD-FACTORY-RESET(8)

NOMBRE

systemd-factory-reset, systemd-factory-reset-request.service, systemd-factory-reset-complete.service, systemd-factory-reset.socket, systemd-factory-reset@.service - Solicitar o completar una operación de restablecimiento de fábrica, o consultar el modo actual de restablecimiento de fábrica

SINOPSIS

/usr/lib/systemd/systemd-factory-reset

systemd-factory-reset-request.service

systemd-factory-reset-complete.service

systemd-factory-reset.socket

systemd-factory-reset@.service

DESCRIPCIÓN

systemd-factory-reset es una herramienta que puede consultar el estado actual de restablecimiento de fábrica, solicitar operaciones de restablecimiento de fábrica o completarlas.

Parte de la funcionalidad también está disponible a través del servicio Varlink /run/systemd/io.systemd.FactoryReset (implementado a través de las unidades systemd-factory-reset.socket/systemd-factory-reset@.service).

Ver Factory Reset[1] para una visión general de la lógica de restablecimiento de fábrica.

COMANDOS

El ejecutable /usr/lib/systemd/systemd-factory-reset también puede invocarse desde la línea de comandos, tomando uno de los siguientes argumentos de comando:

status

Informa sobre el estado actual de restablecimiento de fábrica. Informa uno de los siguientes: "unsupported" (si el SO no admite una lógica de restablecimiento de fábrica), "unspecified" (si no se solicitó ningún restablecimiento de fábrica, pero tampoco se desactivó explícitamente), "off" (si la lógica de restablecimiento de fábrica se desactivó explícitamente a través de la opción de línea de comandos del kernel), "on" (si el restablecimiento de fábrica está actualmente habilitado y ejecutándose), "complete" (si la lógica de restablecimiento de fábrica se ejecutó durante el arranque actual pero ya está completa), "pending" (si se solicitó un restablecimiento de fábrica para el próximo arranque).

Devuelve un código de salida de 0 si el mecanismo de restablecimiento de fábrica no está actualmente en efecto, 10 si se está ejecutando un restablecimiento de fábrica, o 11 si está pendiente para el próximo arranque.

Añadido en la versión 258.

request

Solicita que se ejecute una operación de restablecimiento de fábrica en el próximo arranque.

Tenga en cuenta que esta es una operación de bajo nivel. La interfaz principal para solicitar una operación de restablecimiento de fábrica es iniciando la unidad factory-reset.target.

Esto establece la variable EFI FactoryResetRequest, ver más abajo.

Esta operación se ejecuta cuando se inicia la unidad systemd-factory-reset-request.service (que suele ser uno de los servicios conectados y ordenados antes de factory-reset.target).

Añadido en la versión 258.

cancel

Cancela cualquier operación de restablecimiento de fábrica solicitada previamente (pero aún no ejecutada).

Añadido en la versión 258.

complete

Marca una operación de restablecimiento de fábrica en curso como completada.

Esta operación se ejecuta cuando se inicia la unidad systemd-factory-reset-complete.service (que suele ser uno de los servicios conectados y ordenados después de factory-reset-now.target).

Añadido en la versión 258.

OPCIONES

Se admiten las siguientes opciones:

--retrigger

Cuando se usa con el comando complete, re-activará todos los dispositivos de bloque, lo que podría hacer que los dispositivos descubiertos automáticamente sean utilizables cuando antes no lo eran porque la lógica de restablecimiento de fábrica estaba activa.

Añadido en la versión 258.

--quiet, -q

Suprime la salida del estado de status, pero todavía establece el estado de salida como se documenta.

Añadido en la versión 258.

-h, --help

Imprime un texto de ayuda corto y sale.

--version

Imprime una cadena de versión corta y sale.

VARIABLES EFI

La siguiente variable EFI es establecida y leída por systemd-factory-reset, bajo el UUID del proveedor "8cf2644b-4b0b-428f-9387-6d876050dc67", para la comunicación entre este arranque y el siguiente.

FactoryResetRequest

Se establece cada vez que se solicita un restablecimiento de fábrica para el próximo arranque, se elimina una vez que el restablecimiento de fábrica se ha completado. Contiene datos JSON que describen el SO solicitante, para evitar confusiones en sistemas de arranque múltiple.

Añadido en la versión 258.
