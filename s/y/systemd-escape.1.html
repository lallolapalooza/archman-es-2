NOMBRE

systemd-escape - Escapa cadenas para su uso en nombres de unidades de systemd

SINOPSIS

systemd-escape [OPCIONES...] [CADENA...])

DESCRIPCIÓN

systemd-escape se puede usar para escapar cadenas para su inclusión en nombres de unidades de systemd. El comando puede usarse para escapar y deshacer el escape de cadenas.

El comando toma cualquier número de cadenas en la línea de comandos, y las procesará individualmente, una tras otra. Las mostrará separadas por espacios en la salida estándar.

Por defecto, este comando escapará las cadenas pasadas, a menos que se pase --unescape, que resulta en la operación inversa. Si se da --mangle, se aplica un modo especial de escape en su lugar, que asume que la cadena ya está escapada pero escapará todo lo que parezca obviamente no escapado.

Para obtener detalles sobre los algoritmos de escape y desescape, consulte la sección relevante de systemd.unit(5).

OPCIONES

Se entienden las siguientes opciones:

--suffix=

Añade el sufijo de tipo de unidad especificado a la cadena escapada. Toma uno de los tipos de unidad compatibles con systemd, como "service" o "mount". No se puede usar en conjunción con --template=, --unescape o --mangle.

Añadido en la versión 216.

--template=

Inserta las cadenas escapadas en una plantilla de nombre de unidad. Toma una plantilla de nombre de unidad como foobar@.service. Con --unescape, espera nombres de unidades instanciados para esta plantilla y extrae y escapa solo la parte de instancia. No se puede usar en conjunción con --suffix=, --instance o --mangle.

Añadido en la versión 216.

--path, -p

Al escapar o desescapar una cadena, asuma que se refiere a una ruta del sistema de archivos. Esto simplifica la ruta (se eliminan los caracteres "/" iniciales, finales y duplicados, se eliminan los componentes de ruta "." que no hacen nada, y para las rutas absolutas, se eliminan los componentes ".." iniciales). Después de la simplificación, la ruta no debe contener "..".

Esto es particularmente útil para generar cadenas adecuadas para ser desescapadas con el especificador "%f" en los archivos de unidad, véase systemd.unit(5).

Añadido en la versión 216.

--unescape, -u

En lugar de escapar las cadenas especificadas, deshace el escape, invirtiendo la operación. No se puede usar en conjunción con --suffix= o --mangle.

Añadido en la versión 216.

--mangle, -m

Similar a --escape, pero solo escapa caracteres que obviamente no están escapados todavía, y posiblemente añade automáticamente un sufijo de tipo de unidad apropiado a la cadena. No se puede usar en conjunción con --suffix=, --template= o --unescape.

Añadido en la versión 216.

--instance

Con --unescape, desescape e imprime solo la parte de instancia de un nombre de unidad plantilla instanciado. Resulta en un error para una plantilla no instanciada como ssh@.service o un nombre que no sea plantilla como ssh.service. Debe usarse en conjunción con --unescape y no puede usarse en conjunción con --template.

Añadido en la versión 240.

-h, --help

Imprime un texto de ayuda breve y sale.

--version

Imprime una cadena de versión breve y sale.

EJEMPLOS

Para escapar una sola cadena:

$ systemd-escape 'Hallöchen, Meister'
Hall\xc3\xb6chen\x2c\x20Meister

Para deshacer el escape de una sola cadena:

$ systemd-escape -u 'Hall\xc3\xb6chen\x2c\x20Meister'
Hallöchen, Meister

Para generar la unidad de montaje para una ruta:

$ systemd-escape -p --suffix=mount "/tmp//waldi/foobar/"
tmp-waldi-foobar.mount

Para generar nombres de instancia de tres cadenas:

$ systemd-escape --template=systemd-nspawn@.service 'Mi Contenedor 1' 'contenedorb' 'contenedor/III'
systemd-nspawn@My\x20Container\x201.service systemd-nspawn@containerb.service systemd-nspawn@container-III.service

Para extraer la parte de instancia de una unidad:

$ systemd-escape -u --instance 'systemd-nspawn@My\x20Container\x201.service'
My Container 1

Para extraer la parte de instancia de una instancia de una plantilla particular:

$ systemd-escape -u --template=systemd-nspawn@.service 'systemd-nspawn@My\x20Container\x201.service'
My Container 1

ESTADO DE SALIDA

En caso de éxito, se devuelve 0, de lo contrario un código de fallo distinto de cero.
