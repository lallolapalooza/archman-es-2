PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sys/un.h — definiciones para sockets de dominio UNIX

SINOPSIS

#include <sys/un.h>

DESCRIPCIÓN

El archivo de cabecera <sys/un.h> definirá la estructura sockaddr_un, que contendrá al menos los siguientes miembros:

sa_family_t  sun_family  Familia de direcciones.
char         sun_path[]  Ruta del socket.

La estructura sockaddr_un se utiliza para almacenar direcciones de sockets de dominio UNIX. Las aplicaciones, para su uso con funciones de socket, harán un casting de los punteros a este tipo a struct sockaddr *.

El archivo de cabecera <sys/un.h> definirá el tipo sa_family_t tal como se describe en <sys/socket.h>.

Las siguientes secciones son informativas.

USO EN APLICACIONES

El tamaño de sun_path se ha dejado intencionalmente sin definir. Esto se debe a que diferentes implementaciones utilizan tamaños diferentes. Por ejemplo, 4.3 BSD utiliza un tamaño de 108, y 4.4 BSD utiliza un tamaño de 104. Dado que la mayoría de las implementaciones se originan en versiones BSD, el tamaño suele estar en el rango de 92 a 108.

Las aplicaciones no deben asumir una longitud particular para sun_path ni asumir que puede contener {_POSIX_PATH_MAX} bytes (256).

Aunque las aplicaciones deben inicializar todos los miembros (incluidos los no estándar) de una estructura sockaddr_in6 (ver <netinet_in.h>), no se requiere lo mismo para la estructura sockaddr_un, ya que históricamente muchas aplicaciones solo inicializaban los miembros estándar. A pesar de esto, se anima a las aplicaciones a inicializar las estructuras sockaddr_un de una manera similar a la inicialización requerida de las estructuras sockaddr_in6.
