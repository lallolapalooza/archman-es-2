NOMBRE

systemd-cgtop - Mostrar los grupos de control principales por su uso de recursos

SINOPSIS

systemd-cgtop [OPCIONES...] [GRUPO]

DESCRIPCIÓN

systemd-cgtop muestra los grupos de control principales de la jerarquía de grupos de control de Linux local, ordenados por su carga de CPU, memoria o E/S de disco. La pantalla se actualiza a intervalos regulares (por defecto cada 1s), con un estilo similar a top(1). Si se especifica una ruta de grupo de control, solo se muestran los servicios del grupo de control especificado.

Si systemd-cgtop no está conectado a una tty, no se imprimen encabezados de columna y el valor predeterminado es ejecutar solo una iteración. El argumento --iterations=, si se proporciona, se respeta. Este modo es adecuado para scripting.

El uso de recursos solo se contabiliza para grupos de control con los controladores apropiados activados: el controlador "memory" para el uso de memoria y el controlador "io" para el consumo de E/S de disco. Si se requiere monitorización de recursos para estos recursos, se recomienda agregar la configuración MemoryAccounting=1 y IOAccounting=1 en los archivos de unidad en cuestión. Ver systemd.resource-control(5) para más detalles.

El valor de carga de la CPU puede estar entre 0 y 100 veces el número de procesadores que tiene el sistema. Por ejemplo, si el sistema tiene 8 procesadores, el valor de carga de la CPU estará entre el 0% y el 800%. El número de procesadores se puede encontrar en "/proc/cpuinfo".

Para enfatizar: a menos que "MemoryAccounting=1" y "IOAccounting=1" estén habilitados para los servicios en cuestión, no habrá contabilidad de recursos para los servicios del sistema y los datos mostrados por systemd-cgtop estarán incompletos.

OPCIONES

Se entienden las siguientes opciones:

-p, --order=path

Ordenar por nombre de ruta del grupo de control.

-t, --order=tasks

Ordenar por número de tareas/procesos en el grupo de control.

-c, --order=cpu

Ordenar por carga de CPU.

-m, --order=memory

Ordenar por uso de memoria.

-i, --order=io

Ordenar por carga de E/S de disco.

-b, --batch

Ejecutar en modo "batch": no aceptar entrada y ejecutar hasta que se agote el límite de iteraciones establecido con --iterations= o hasta que se mate el proceso. Este modo podría ser útil para enviar la salida de systemd-cgtop a otros programas o a un archivo.

Añadido en la versión 188.

-r, --raw

Formatear los recuentos de bytes (como en el uso de memoria y las métricas de E/S) y el tiempo de CPU con valores numéricos sin formatear en lugar de números legibles por humanos.

Añadido en la versión 221.

--cpu=percentage, --cpu=time

Controla si el uso de CPU se muestra como porcentaje o tiempo. Por defecto, el uso de CPU se muestra como porcentaje. Esta configuración también se puede alternar en tiempo de ejecución presionando la tecla %.

Añadido en la versión 226.

-P

Contar solo procesos de espacio de usuario en lugar de todas las tareas. Por defecto, se cuentan todas las tareas: cada hilo del kernel y cada hilo del espacio de usuario individualmente. Con esta configuración, los hilos del kernel se excluyen del recuento y cada proceso del espacio de usuario solo cuenta como una tarea, independientemente de cuántos hilos contenga. Esta configuración tampoco se puede combinar con -k.

Añadido en la versión 227.

-k

Contar solo procesos de espacio de usuario e hilos del kernel en lugar de todas las tareas. Por defecto, se cuentan todas las tareas: cada hilo del kernel y cada hilo del espacio de usuario individualmente. Con esta configuración, los hilos del kernel se incluyen en el recuento y cada proceso del espacio de usuario solo cuenta como una tarea, independientemente de cuántos hilos contenga. Esta configuración tampoco se puede combinar con -P.

Añadido en la versión 226.

--recursive=

Controla si el número de procesos que se muestran para un grupo de control debe incluir todos los procesos que están contenidos en cualquiera de los grupos de control hijos también. Toma un argumento booleano, que por defecto es "yes". Si está habilitado, se incluyen los procesos en los grupos de control hijos, si está deshabilitado, solo se cuentan los procesos en el grupo de control en sí. Esta configuración también se puede alternar en tiempo de ejecución presionando la tecla r. Tenga en cuenta que esta configuración solo se aplica al recuento de procesos, es decir, cuando se usan las opciones -P o -k. No tiene ningún efecto si se cuentan todas las tareas, en cuyo caso el recuento siempre es recursivo.

Añadido en la versión 226.

-n, --iterations=

Realizar solo este número de iteraciones. Un valor de 0 indica que el programa debe ejecutarse indefinidamente.

Añadido en la versión 188.

-1

Un atajo para --iterations=1.

Añadido en la versión 238.

-d, --delay=

Especificar el retraso de actualización en segundos (o si se especifica una de las unidades "ms", "us", "min" en esta unidad de tiempo). Esta configuración también se puede aumentar y disminuir en tiempo de ejecución presionando las teclas + y -.

--depth=

Profundidad máxima de recorrido del árbol de grupos de control. Especifica cuán profundo debe systemd-cgtop recorrer las jerarquías de grupos de control. Si se especifica 0, solo se monitoriza el grupo raíz. Para 1, solo se monitoriza el primer nivel de grupos de control, y así sucesivamente. El valor predeterminado es 3.

-M MÁQUINA, --machine=MÁQUINA

Limitar los grupos de control que se muestran a la parte correspondiente al contenedor MÁQUINA. Esta opción no se puede usar cuando se especifica una ruta de grupo de control.

Añadido en la versión 227.

-h, --help

Imprimir un texto de ayuda corto y salir.

--version

Imprimir una cadena de versión corta y salir.

TECLAS

systemd-cgtop es una herramienta interactiva y puede ser controlada mediante la entrada del usuario utilizando las siguientes teclas:

h

Muestra un texto de ayuda corto.

Espacio

Actualizar la salida inmediatamente.

Añadido en la versión 226.

q

Terminar el programa.

p, t, c, m, i

Ordenar los grupos de control por ruta, número de tareas, carga de CPU, uso de memoria o carga de E/S, respectivamente. Esta configuración también se puede controlar usando el modificador de línea de comandos --order=.

%

Alternar entre mostrar el tiempo de CPU como tiempo o porcentaje. Esta configuración también se puede controlar usando el modificador de línea de comandos --cpu=.

Añadido en la versión 201.

+, -

Aumentar o disminuir el retraso de actualización, respectivamente. Esta configuración también se puede controlar usando el modificador de línea de comandos --delay=.

P

Alternar entre contar todas las tareas o solo procesos de espacio de usuario. Esta configuración también se puede controlar usando el modificador de línea de comandos -P (ver arriba).

Añadido en la versión 227.

k

Alternar entre contar todas las tareas o solo procesos de espacio de usuario e hilos del kernel. Esta configuración también se puede controlar usando el modificador de línea de comandos -k (ver arriba).

Añadido en la versión 226.

r

Alternar entre incluir o excluir recursivamente los procesos en grupos de control hijos en los recuentos de procesos de los grupos de control. Esta configuración también se puede controlar usando el modificador de línea de comandos --recursive=. Esta tecla no está disponible si se cuentan todas las tareas, solo está disponible si se cuentan los procesos, como se habilita con las teclas P o k.

Añadido en la versión 226.

ESTADO DE SALIDA

En caso de éxito, se devuelve 0, de lo contrario, un código de error distinto de cero.

VER TAMBIÉN

systemd(1), systemctl(1), s

NAME

systemd-cgtop - Show systemd control groups and their resource usage

SYNOPSIS

systemd-cgtop [OPTIONS...]

DESCRIPTION

systemd-cgtop displays a list of running control groups and their resource usage, similar to the top utility. It lists control groups ordered by their total CPU usage. The display is updated periodically.

The listed control groups correspond to the hierarchy of systemd control groups. The root control group is /. Services, units, and other systemd constructs are organized in sub-control groups, usually under system.slice or user.slice.

systemd-cgtop operates on the cgroup v2 hierarchy by default. If cgroup v1 is used, it will display information from the cgroup v1 hierarchy.

Use the same keybindings as in top to interact with the display.

OPTIONS

The following options are understood:

-h, --help

Print a short help text and exit.

-V, --version

Print a short version string and exit.

-k, --kill

Send a signal to one or more processes in a control group. This option is only useful when running interactively, as it will prompt for the PID and signal to send.

-r, --recursive

Recursively list all control groups and their resource usage. By default, only the top-level control groups are shown.

-i, --indexed

Add a column with the index number to the output. This is useful for easily selecting items when using keyboard shortcuts.

-n, --iterations=N

Exit after N updates. If N is 0, loop indefinitely.

-d, --delay=SECS

Set the delay between screen updates to SECS seconds. The default is 1.5 seconds.

-w, --wide

Do not cut lines that are wider than the screen width. The output will be at most the width of the terminal. This is useful for viewing long control group names.

KEYS

systemd-cgtop supports the following interactive commands, inspired by top:

k

Send a signal to a process.

s

Change the update delay.

l

Toggle recursive listing.

1

Toggle between showing CPU, Memory, or Block I/O usage.

c

Toggle between showing absolute values or percentages.

q

Quit.

EXIT STATUS

systemd-cgtop exits with status 0 on success, and non-zero otherwise.
