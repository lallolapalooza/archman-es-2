SYSTEMD-TPM2-GENERATOR(8) systemd-tpm2-generator SYSTEMD-TPM2-GENERATOR(8)

NOMBRE

systemd-tpm2-generator - Generador para insertar un punto de sincronización TPM2 en el proceso de arranque

SINOPSIS

/usr/lib/systemd/system-generators/systemd-tpm2-generator

DESCRIPCIÓN

systemd-tpm2-generator es un generador que añade una dependencia Wants= de sysinit.target a tpm2.target cuando detecta que el firmware descubrió un dispositivo TPM2 pero el kernel del sistema operativo hasta ahora no lo ha hecho. tpm2.target está destinado a actuar como un punto de sincronización para todos los servicios que requieren acceso al dispositivo TPM2. Consulte systemd.special(7) para obtener más detalles.

La opción de línea de comandos del kernel systemd.tpm2_wait= puede ser utilizada para anular el comportamiento del generador. Acepta un valor booleano: si es verdadero, tpm2.target se añadirá como punto de sincronización incluso si el firmware no ha detectado un dispositivo TPM2. Si es falso, el objetivo no se insertará incluso si el firmware reportó un dispositivo pero el kernel del sistema operativo aún no expone un dispositivo para él. Esto último podría ser útil en entornos donde no hay un controlador TPM2 adecuado para el hardware disponible.

systemd-tpm2-generator implementa systemd.generator(7).

VER TAMBIÉN

systemd(1), systemd.special(7), kernel-command-line(7)
