SYD-FORK(1) Manual de Comandos Generales SYD-FORK(1)

NOMBRE

syd-fork - Crea procesos de forma rápida en un bucle infinito.

SINOPSIS

syd-fork [-h]

DESCRIPCIÓN

Si no se proporcionan argumentos, el programa creará rápidamente un número infinito de procesos hijos mediante fork. Esto se implementa usando ensamblador en línea en arquitecturas x86, x86_64, arm y aarch64, lo que lo hace significativamente más rápido y eficiente que la bomba de fork de bash.

Cuando se pasa la bandera -h, se mostrará un mensaje de advertencia indicando que este programa está destinado a probar el limitador de pids y no debe usarse para ningún otro propósito. No está pensado para ser usado como una broma y debe usarse con precaución. El uso del programa es bajo el riesgo del usuario. Para probar el limitador de pids, ejecute el programa sin argumentos. El programa creará rápidamente un número infinito de procesos hijos mediante fork y alcanzará rápidamente el número máximo de procesos que el sistema puede manejar.

OPCIONES

-h Muestra la ayuda.

EJEMPLOS

Para ejecutar syd-fork el 1 de abril a las 8:00 AM UTC, puede usar el comando at(1). Esto es útil para programar la ejecución del programa en un momento específico para pruebas o demostraciones. Asegúrese de que el demonio at(1) esté en ejecución en su sistema y que tenga permiso para programar trabajos con at(1).

$ echo "syd-fork" | at 08:00 April 1

NOTAS

Se recomienda a los mantenedores de la distribución que hagan un ln(1) de "syd-fork" a "syd-fuck" bajo una opción NSFW para ayudar a tratar problemas de ira.
