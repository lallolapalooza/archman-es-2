NOMBRE

systemd-path - Listar y consultar rutas del sistema y de usuario

SINOPSIS

systemd-path [OPCIONES...] [NOMBRE...]

DESCRIPCIÓN

systemd-path puede usarse para consultar rutas del sistema y de usuario. La herramienta hace accesibles muchas de las rutas descritas en file-hierarchy(7) para su consulta.

Cuando se invoca sin argumentos, se muestra una lista de las rutas conocidas y sus valores actuales. Cuando se pasa al menos un argumento, se consulta la ruta con este nombre y se muestra su valor. Las variables cuyos nombres comienzan con "search-" no se refieren a rutas individuales, sino a una lista de rutas de búsqueda separadas por dos puntos, en orden de precedencia.

Tenga en cuenta que las rutas que dependen de variables de entorno se calculan con el entorno invocado de systemd-path, y no con el entorno del gestor del sistema o de usuario. Como tal, la salida de systemd-path puede no reflejar el comportamiento de los procesos gestores.

OPCIONES

Se entienden las siguientes opciones:

--suffix=

Las rutas impresas se sufijan con la cadena especificada.

Añadido en la versión 215.

--no-pager

No usar paginador para la salida.

-h, --help

Imprimir un texto de ayuda corto y salir.

--version

Imprimir una cadena de versión corta y salir.

CÓDIGO DE SALIDA

En caso de éxito, se devuelve 0, de lo contrario un código de error distinto de cero.

VER TAMBIÉN
