NOMBRE

systemd-nsresourced.service, systemd-nsresourced - Servicio de Delegación de Recursos de Espacio de Nombres de Usuario

SINOPSIS

systemd-nsresourced.service

/usr/lib/systemd/systemd-nsresourced

DESCRIPCIÓN

systemd-nsresourced es un servicio del sistema que permite la delegación transitoria de un rango de UID/GID a un espacio de nombres de usuario (ver user_namespaces(7)) asignado por un cliente, a través de una API IPC de Varlink.

Los clientes sin privilegios pueden asignar un espacio de nombres de usuario y luego solicitar que se le asigne un rango de UID/GID a través de este servicio. El espacio de nombres de usuario puede usarse para ejecutar contenedores y otros entornos aislados, y/o aplicarse a un montaje id-mapped (mapeado por ID).

Las asignaciones de UIDs/GIDs de esta manera son transitorias: cuando un espacio de nombres de usuario desaparece, su rango de UID/GID se devuelve al grupo de rangos disponibles. Para garantizar que los clientes no puedan obtener persistencia en su rango de UID/GID transitorio, se aplica una política basada en BPF-LSM que garantiza que los espacios de nombres de usuario configurados de esta manera solo puedan escribir en sistemas de archivos que ellos mismos asignen o que estén explícitamente permitidos a través de systemd-nsresourced.

systemd-nsresourced se asegura automáticamente de que todos los rangos de UID registrados aparezcan en la base de datos NSS del sistema a través de la API de Búsqueda de Registros de Usuario/Grupo a través de Varlink[1].

Actualmente, con este servicio solo se pueden registrar rangos de UID/GID que consistan en exactamente 1 o exactamente 65536 UIDs/GIDs. Además, los UIDs y GIDs siempre se asignan juntos y simétricamente.

El servicio proporciona llamadas a la API para permitir montajes (referenciados por sus descriptores de archivo de montaje según la API fsmount() de Linux), para pasar la propiedad de un subárbol de cgroup al espacio de nombres de usuario y para delegar un par de dispositivos Ethernet virtuales al espacio de nombres de usuario. Cuando se utiliza en combinación, esto es suficiente para implementar entornos de contenedores completamente sin privilegios, como implementa systemd-nspawn(1), o herramientas de imagen de disco completamente sin privilegios como systemd-dissect(1).

Este servicio proporciona un servicio de Varlink[2]: io.systemd.NamespaceResource permite registrar espacios de nombres de usuario y asignarles montajes, cgroups e interfaces de red.
