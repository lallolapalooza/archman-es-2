NOMBRE

syd-sha - Calcular el checksum SHA3-512 del archivo dado o entrada estándar

SINOPSIS

syd-sha [-bcChmx1235] <archivo|->

DESCRIPCIÓN

Dado un archivo, calcular el checksum del archivo.

Si no se proporcionan argumentos posicionales o se proporciona "-" como argumento, calcular el checksum de la entrada estándar.

Use -b para imprimir salida binaria en lugar de una cadena codificada en hexadecimal.

OPCIONES

-h Mostrar ayuda.
-b Salida binaria.
-x Salida hexadecimal (por defecto).
-c Calcular checksum CRC64 (inseguro).
-C Calcular checksum CRC32 (inseguro).
-m Calcular checksum MD5 (inseguro, compatible con vdb de portage/paludis).
-1 Calcular checksum SHA1 (inseguro).
-2 Calcular checksum SHA3-256.
-3 Calcular checksum SHA3-384.
-5 Calcular checksum SHA3-512 (por defecto).
