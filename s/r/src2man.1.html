NOMBRE

src2man - extrae páginas del manual de archivos fuente.

SINOPSIS

src2man [-n][-d fecha][-v volumen][-r lanzamiento] [archivo_fuente ...]

DESCRIPCIÓN

src2man escanea el archivo fuente archivo_fuente. Por ahora, solo se admiten archivos fuente en C. Los bloques de comentarios que comienzan con "/** num", donde num es un número de sección, se convierten en un archivo de manual, utilizando txt2man(1).

La primera línea del bloque de comentarios debe contener el nombre de la página del manual, generalmente el nombre de la función, seguido de un "-" y una breve descripción. Las líneas siguientes son el contenido de la sección "DESCRIPCIÓN", excepto si están en mayúsculas, en cuyo caso definen una nueva sección.

Si la línea siguiente a un bloque de comentarios está vacía, entonces no se generará ninguna sección "SINOPSIS". De lo contrario, src2man buscará en las siguientes líneas de código una declaración de función o una definición de tipo (struct, union, typedef, ...) que coincida con el nombre de la página del manual, y la incluirá en una sección "SINOPSIS". Esto evita duplicar el tipo o la declaración de función en el bloque de comentarios.

El mejor lugar para la documentación del código es en el archivo fuente, donde se implementa el cuerpo, no en el archivo de encabezado que solo contiene la declaración. src2man busca automáticamente la presencia de una declaración en el archivo de encabezado correspondiente, y si se encuentra, imprimirá una directiva "#include" en la sinopsis.

OPCIONES

-d fecha
Establece la fecha de las páginas del manual. Por defecto, la fecha actual.
-n
No se crea ninguna página del manual. Se imprimen los nombres de las páginas del manual que se crearían.
-v volumen
Especifica el nombre del volumen que se imprimirá en el encabezado central de las páginas del manual generadas.
-r lanzamiento
Especifica el nombre del proyecto y el número de lanzamiento para la página del manual generada.

ENTORNO

SOURCE_DATE_EPOCH
Marca de tiempo de Unix que se utiliza para la fecha en el encabezado en lugar de la fecha actual.

EJEMPLO

El siguiente ejemplo muestra código C y comentarios para generar una página del manual foobar.3:

/** 3

  • foobar - una función dummy de ejemplo
  • Esta línea es ahora la primera de la sección de descripción.
  • Observe que los parámetros de la función parm1 y parm2 se resaltan
  • en la página del manual generada.

*/

int foobar(char *parm1, int parm2)

{

...

return 0;

}
