subroutine srotg (real(wp) a, real(wp) b, real(wp) c, real(wp) s)

SROTG

Propósito:

!>
!> SROTG construye una rotación de plano
!>    [  c  s ] [ a ] = [ r ]
!>    [ -s  c ] [ b ]   [ 0 ]
!> satisfaciendo c**2 + s**2 = 1.
!>
!> El cálculo utiliza las fórmulas
!>    sigma = sgn(a)    si |a| >  |b|
!>          = sgn(b)    si |b| >= |a|
!>    r = sigma*sqrt( a**2 + b**2 )
!>    c = 1; s = 0      si r = 0
!>    c = a/r; s = b/r  si r != 0
!> La subrutina también calcula
!>    z = s    si |a| > |b|,
!>      = 1/c  si |b| >= |a| y c != 0
!>      = 1    si c = 0
!> Esto permite que c y s se reconstruyan a partir de z de la siguiente manera:
!>    Si z = 1, establecer c = 0, s = 1.
!>    Si |z| < 1, establecer c = sqrt(1 - z**2) y s = z.
!>    Si |z| > 1, establecer c = 1/z y s = sqrt( 1 - c**2).
!>
!>
