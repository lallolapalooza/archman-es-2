SRCREDACT(1) Herramientas de texto SRCREDACT(1)

NOMBRE

srcredact - un programa para el redactado de archivos de texto

SINOPSIS

srcredact [OPCIONES] -e audiencia [archivo_completo]

srcredact [OPCIONES] -u audiencia archivo_completo [archivo_redactado]

srcredact -l [archivo_completo]

srcredact -h|-v

DESCRIPCIÓN

srcredact es el programa para extraer versiones ``redactadas'' del archivo maestro (opción -e) o para incorporar los cambios en las versiones redactadas al archivo maestro (``des-redactar'', opción -u).

El archivo maestro consiste en bloques destinados a diferentes audiencias. Cada audiencia tiene un nombre, por ejemplo "clasificado", "no_clasificado", "experto" etc. Los bloques se inician y terminan con líneas de guarda. Cada línea de guarda tiene el formato (para la sintaxis TeX por defecto)

%<*nombre1|nombre2|...>

o

%</nombre1|nombre2|...>

En los primeros casos, el texto que sigue a la guarda se incluye para las audiencias "nombre1", "nombre2", .... En el segundo caso se excluye para estas audiencias.

Existe una audiencia especial "ALL": un comodín para todas las audiencias. Por lo tanto, el modismo

%</ALL>
%<*clasificado>

significa que el bloque se excluye para todas las audiencias excepto "clasificado".

Exactamente una de las opciones -e (extraer) o -u (des-extraer) debe estar presente. En el modo de extracción, el argumento no opcional es el nombre del archivo completo. Si está ausente, o es "-", se utiliza la entrada estándar. En el modo de des-extracción, el primer argumento no opcional

OPCIONES

-c lista de patrones de comentarios
Utiliza el patrón dado para las líneas de comentarios para buscar guardas en lugar del patrón "TeX" por defecto. Los patrones reconocidos son:
c
/*<guarda>*/
cpp
//<guarda>
fortran
C<guarda>
shell
#<guarda>
TeX
%<guarda>

Los nombres de los patrones deben separarse por comas, y la lista puede encerrarse entre comillas para evitar la expansión del shell, por ejemplo:

-c "TeX, c, shell"
-d
Modo de depuración activado.
-e audiencia
Extrae el contenido para la audiencia actual en el archivo archivo. La audiencia actual se infiere del nombre del archivo, si este tiene la estructura base-audiencia.extensión, por ejemplo "informe-no_clasificado.tex". La clave -a anula esta inferencia y debe usarse si el nombre del archivo no sigue este patrón. El nombre de archivo "-" significa la salida estándar.
-h
Imprime la información de ayuda y sale.
-l
Lista todas las audiencias establecidas en el archivo (una por línea) y sale.
-u audiencia
Toma un archivo editado destinado a la audiencia (el segundo argumento no opcional) e incorpora los cambios de este en el archivo completo (el primer argumento no opcional). Si el segundo argumento falta, se utiliza la entrada estándar en su lugar. Como siempre, "-" también significa entrada estándar. Tenga en cuenta que solo uno de los dos argumentos de archivo en este caso puede ser la entrada estándar.
-v
Imprime la información de la versión y sale.
-w on|off|1|0|true|false
Si es "on", 1 o "true" (el valor por defecto), envuelve implícitamente el documento completo en las guardas 
%<*ALL>
...
%</ALL>

VALOR DE RETORNO

El programa devuelve 0 si tiene éxito, 1 si se encontraron conflictos en el modo "des-extraer" y 2 en caso de problemas.

CONFLICTOS EN MODO DESEXTRAER

Al igual que la herramienta estándar diff3(1), el programa puede encontrar conflictos entre la versión completa y la editada en el modo -u. Entonces, el archivo resultante delimita los conflictos de la manera habitual, por ejemplo:

<<<<<<< /tmp/BrjXo0hMOB/completo
%</nobonos>
Cuarenta y cinco toneladas de bonos del gobierno viejos y secos, adecuados
para horno, oro
7 por ciento, 1864, preferentes.
%<*nobonos>
||||||| /tmp/BrjXo0hMOB/extraido
Cuarenta y cinco toneladas de bonos del gobierno viejos y secos, adecuados
para horno, oro
7 por ciento, 1864, preferentes.
=======
>>>>>>> /tmp/BrjXo0hMOB/nuevo

Aquí "completo" es el documento completo, "extraido" es el archivo extraído para la audiencia dada, "nuevo" es el archivo editado.
