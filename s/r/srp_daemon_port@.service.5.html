SRP_DAEMON_PORT@.SERVICE(5) srp_daemon_port@.service SRP_DAEMON_PORT@.SERVICE(5)

NOMBRE

srp_daemon_port@.service - servicio de systemd srp_daemon_port@ que controla un único puerto

SINOPSIS

srp_daemon_port@.service

DESCRIPCIÓN

El servicio srp_daemon_port@.service controla si un proceso srp_daemon está monitorizando el puerto RDMA especificado como argumento de plantilla. El formato para el nombre del puerto RDMA es dev:port donde dev es el nombre de un dispositivo RDMA y port es un número de puerto que comienza desde uno. Iniciar una instancia de esta plantilla iniciará un proceso srp_daemon. Detener una instancia de esta plantilla detendrá el proceso srp_daemon para el puerto especificado. Se puede evitar que srp_daemon se inicie para un puerto determinado enmascarando el servicio systemd correspondiente, por ejemplo, systemctl mask srp_daemon_port@mlx4_0:1.

Una lista de todos los pares de dispositivos RDMA y números de puerto se puede obtener, por ejemplo, de la siguiente manera:

$ (cd /sys/class/infiniband >&/dev/null && for p in */ports/*; do
   [ -e "$p" ] && echo "${p/\/ports\//:}"; done)
mlx4_0:1
mlx4_0:2
mlx4_1:1
mlx4_1:2
