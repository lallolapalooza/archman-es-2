rand(3) Manual de funciones de biblioteca rand(3)

NOMBRE

rand, rand_r, srand - generador de números pseudoaleatorios

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <stdlib.h>
int rand(void);
void srand(unsigned int seed);
[[deprecated]] int rand_r(unsigned int *seedp);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

rand_r():

    Desde glibc 2.24:
        _POSIX_C_SOURCE >= 199506L
    glibc 2.23 y anteriores
        _POSIX_C_SOURCE

DESCRIPCIÓN

La función rand() devuelve un entero pseudoaleatorio en el rango de 0 a RAND_MAX inclusive (es decir, el rango matemático [0, RAND_MAX]).

La función srand() establece su argumento como la semilla para una nueva secuencia de enteros pseudoaleatorios a ser devueltos por rand(). Estas secuencias pueden ser reproducidas llamando a srand() con el mismo valor de semilla.

Si no se proporciona ningún valor de semilla, la función rand() se siembra automáticamente con un valor de 1.

La función rand() no es reentrable, ya que utiliza un estado oculto que se modifica en cada llamada. Esto podría ser solo el valor de la semilla a utilizar en la próxima llamada, o podría ser algo más complejo. Para obtener un comportamiento reproducible en una aplicación con hilos, este estado debe hacerse explícito; esto se puede lograr usando la función reentrable rand_r().

Al igual que rand(), rand_r() devuelve un entero pseudoaleatorio en el rango [0, RAND_MAX]. El argumento seedp es un puntero a un unsigned int que se utiliza para almacenar el estado entre llamadas. Si se llama a rand_r() con el mismo valor inicial para el entero apuntado por seedp, y ese valor no se modifica entre llamadas, se obtendrá la misma secuencia pseudoaleatoria.

El valor apuntado por el argumento seedp de rand_r() proporciona solo una cantidad muy pequeña de estado, por lo que esta función será un generador pseudoaleatorio débil. Intente usar drand48_r(3) en su lugar.

VALOR DE RETORNO

Las funciones rand() y rand_r() devuelven un valor entre 0 y RAND_MAX (inclusive). La función srand() no devuelve ningún valor.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
rand (), rand_r (), srand () Seguridad en hilos MT-Safe

VERSIONES

Las versiones de rand() y srand() en la Biblioteca C de Linux utilizan el mismo generador de números aleatorios que random(3) y srandom(3), por lo que los bits de orden inferior deberían ser tan aleatorios como los bits de orden superior. Sin embargo, en implementaciones anteriores de rand(), y en implementaciones actuales en diferentes sistemas, los bits de orden inferior son mucho menos aleatorios que los bits de orden superior. No use esta función en aplicaciones destinadas a ser portables cuando se necesite buena aleatoriedad. (Use random(3) en su lugar).

EJEMPLOS

POSIX.1-2001 proporciona el siguiente ejemplo de implementación de rand() y srand(), posiblemente útil cuando se necesita la misma secuencia en dos máquinas diferentes.


static unsigned long next = 1;
/* Se asume que RAND_MAX es 32767 */
int myrand(void) {
    next = next * 1103515245 + 12345;
    return((unsigned) (next/65536) % 32768);
}
void mysrand(unsigned int seed) {
    next = seed;
}

El siguiente programa se puede utilizar para mostrar la secuencia pseudoaleatoria producida por rand() cuando se le da una semilla particular. Cuando la semilla es -1, el programa utiliza una semilla aleatoria.


#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    int           r;
    unsigned int  seed, nloops;
    if (argc != 3) {
        fprintf(stderr, "Uso: %s <semilla> <nloops>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    seed = atoi(argv[1]);
    nloops = atoi(argv[2]);
    if (seed == -1) {
        seed = arc4random();
        printf("semilla: %u\n", seed);
    }
    srand(seed);
    for (unsigned int j = 0; j < nloops; j++) {
        r =  rand();
        printf("%d\n", r);
    }
    exit(EXIT_SUCCESS);
}
