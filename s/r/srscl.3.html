Documentación de la función/subrutina

subrutina srscl (integer n, real sa, real, dimension( * ) sx, integer incx)

SRSCL multiplica un vector real de n elementos por el escalar real 1/a. Esto se hace sin desbordamiento ni subdesbordamiento mientras el resultado final x/a no se desborde o subdesborde.

Propósito:

!>
!> SRSCL multiplica un vector real x de n elementos por el escalar real 1/a.
!> Esto se hace sin desbordamiento ni subdesbordamiento mientras
!> el resultado final x/a no se desborde o subdesborde.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de componentes del vector x.
!>

SA

!>          SA es REAL
!>          El escalar a que se utiliza para dividir cada componente de x.
!>          SA debe ser >= 0, o la subrutina dividirá por cero.
!>

SX

!>          SX es un array REAL, de dimensión
!>                         (1+(N-1)*abs(INCX))
!>          El vector x de n elementos.
!>

INCX

!>          INCX es INTEGER
!>          El incremento entre valores sucesivos de SX.
!>          > 0:  SX(1) = X(1) y SX(1+(i-1)*INCX) = x(i),     1< i<= n
!>
