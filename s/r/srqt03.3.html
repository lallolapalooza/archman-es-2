SRQT03

Propósito:

!>
!> SRQT03 prueba SORMRQ, que calcula Q*C, Q'*C, C*Q o C*Q'.
!>
!> SRQT03 compara los resultados de una llamada a SORMRQ con los resultados de
!> formar Q explícitamente mediante una llamada a SORGRQ y luego realizar
!> la multiplicación de matrices mediante una llamada a SGEMM.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas o columnas de la matriz C; C es n-por-m si
!>          Q se aplica desde la izquierda, o m-por-n si Q se aplica desde
!>          la derecha.  M >= 0.
!>

N

!>          N es ENTERO
!>          El orden de la matriz ortogonal Q.  N >= 0.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define la
!>          matriz ortogonal Q.  N >= K >= 0.
!>

AF

!>          AF es un array REAL, dimensión (LDA,N)
!>          Detalles de la factorización RQ de una matriz m-por-n, tal como
!>          devuelto por SGERQF. Ver SGERQF para más detalles.
!>

C

!>          C es un array REAL, dimensión (LDA,N)
!>

CC

!>          CC es un array REAL, dimensión (LDA,N)
!>

Q

!>          Q es un array REAL, dimensión (LDA,N)
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays AF, C, CC y Q.
!>

TAU

!>          TAU es un array REAL, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales correspondientes
!>          a la factorización RQ en AF.
!>

WORK

!>          WORK es un array REAL, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La longitud de WORK.  LWORK debe ser al menos M, y debería ser
!>          M*NB, donde NB es el tamaño del bloque para este entorno.
!>

RWORK

!>          RWORK es un array REAL, dimensión (M)
!>

RESULT

!>          RESULT es un array REAL, dimensión (4)
!>          Las razones de prueba comparan dos técnicas para multiplicar una
!>          matriz aleatoria C por una matriz ortogonal n-por-n Q.
!>          RESULT(1) = norm( Q*C - Q*C )  / ( N * norm(C) * EPS )
!>          RESULT(2) = norm( C*Q - C*Q )  / ( N * norm(C) * EPS )
!>          RESULT(3) = norm( Q'*C - Q'*C )/ ( N * norm(C) * EPS )
!>          RESULT(4) = norm( C*Q' - C*Q' )/ ( N * norm(C) * EPS )
!>
