sradixsort(3bsd)

Paquete: libbsd

Licencias: custom

radixsort(3bsd) 3bsd radixsort(3bsd)

NOMBRE

radixsort, sradixsort — ordenación por radix

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <limits.h>
#include <stdlib.h> (Ver libbsd(7) para el uso de incluye.)
int
radixsort(const unsigned char **base, int nmemb, const unsigned char *table, unsigned endbyte);

int
sradixsort(const unsigned char **base, int nmemb, const unsigned char *table, unsigned endbyte);

DESCRIPCIÓN

Las funciones radixsort() y sradixsort() son implementaciones de la ordenación por radix.

Estas funciones ordenan un array de nmemb elementos de punteros a cadenas de bytes, cuyo miembro inicial está referenciado por base. Las cadenas de bytes pueden contener cualquier valor. El final de las cadenas se denota por un carácter que tiene el mismo peso que el valor especificado por el usuario endbyte. endbyte debe estar entre 0 y 255.

Las aplicaciones pueden especificar un orden de ordenación proporcionando el argumento table. Si no es NULL, table debe referenciar un array de UCHAR_MAX + 1 bytes que contenga el peso de ordenación de cada valor de byte posible. El byte de fin de cadena debe tener un peso de ordenación de 0 o 255 (para ordenar en orden inverso). Más de un byte puede tener el mismo peso de ordenación. El argumento table es útil para aplicaciones que deseen ordenar caracteres diferentes de forma igual, por ejemplo, proporcionar una tabla con los mismos pesos para A-Z que para a-z resultará en una ordenación insensible a mayúsculas y minúsculas. Si table es NULL, el contenido del array se ordena en orden ascendente según el orden ASCII de las cadenas de bytes que referencian y endbyte tiene un peso de ordenación de 0.

La función sradixsort() es estable, es decir, si dos elementos se comparan como iguales, su orden en el array ordenado no cambia. La función sradixsort() utiliza memoria adicional suficiente para contener nmemb punteros.

La función radixsort() no es estable, pero no utiliza memoria adicional.

Estas funciones son variantes de la ordenación por radix de byte más significativo; en particular, ver el Algoritmo R de D.E. Knuth y la sección 5.2.5, ejercicio 10. Toman tiempo lineal en relación con el número de bytes en las cadenas.

VALORES DE RETORNO

La función radixsort() devuelve el valor 0 si tiene éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

[EINVAL]
El valor del elemento endbyte de table no es 0 ni 255.

Adicionalmente, la función sradixsort() puede fallar y establecer errno por cualquiera de los errores especificados para la rutina de biblioteca malloc(3).

VER TAMBIÉN
