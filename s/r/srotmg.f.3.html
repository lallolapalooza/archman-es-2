subrutina srotmg (real sd1, real sd2, real sx1, real sy1, real, dimension(5) sparam)

SROTMG

Propósito:

!>
!>    CONSTRUYE LA MATRIZ DE TRANSFORMACIÓN DE GIVENS MODIFICADA H QUE
!>    ANULA EL SEGUNDO COMPONENTE DEL VECTOR 2 (SQRT(SD1)*SX1, SQRT(SD2)*>    SY2)**T.
!>    CON SPARAM(1)=SFLAG, H TIENE UNA DE LAS SIGUIENTES FORMAS..
!>
!>    SFLAG=-1.E0     SFLAG=0.E0        SFLAG=1.E0     SFLAG=-2.E0
!>
!>      (SH11  SH12)    (1.E0  SH12)    (SH11  1.E0)    (1.E0  0.E0)
!>    H=(          )    (          )    (          )    (          )
!>      (SH21  SH22),   (SH21  1.E0),   (-1.E0 SH22),   (0.E0  1.E0).
!>    LAS POSICIONES 2-4 DE SPARAM CONTIENEN SH11, SH21, SH12 Y SH22
!>    RESPECTIVAMENTE. (LOS VALORES DE 1.E0, -1.E0 O 0.E0 IMPLICADOS POR EL
!>    VALOR DE SPARAM(1) NO SE ALMACENAN EN SPARAM.)
!>
!>    LOS VALORES DE GAMSQ Y RGAMSQ ESTABLECIDOS EN LA DECLARACIÓN DE DATOS PUEDEN SER
!>    INEXACTOS. ESTO ESTÁ BIEN YA QUE SOLO SE UTILIZAN PARA PROBAR EL TAMAÑO
!>    DE SD1 Y SD2. TODA LA ESCALADA REAL DE DATOS SE HACE USANDO GAM.
!>
!>

Parámetros

SD1 
!>          SD1 es REAL
!>

SD2

!>          SD2 es REAL
!>

SX1

!>          SX1 es REAL
!>

SY1

!>          SY1 es REAL
!>

SPARAM

!>          SPARAM es un array REAL, de dimensión (5)
!>     SPARAM(1)=SFLAG
!>     SPARAM(2)=SH11
!>     SPARAM(3)=SH21
!>     SPARAM(4)=SH12
!>     SPARAM(5)=SH22
!>
