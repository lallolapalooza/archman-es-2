SRZT02

Propósito:

!>
!> SRZT02 devuelve
!>      || I - Q'*Q || / ( M * eps)
!> donde la matriz Q está definida por las transformaciones de Householder
!> generadas por STZRZF.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz AF.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz AF.
!>

AF

!>          AF es un array REAL, dimensión (LDA,N)
!>          La salida de STZRZF.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array AF.
!>

TAU

!>          TAU es un array REAL, dimensión (M)
!>          Detalles de las transformaciones de Householder devueltas por
!>          STZRZF.
!>

WORK

!>          WORK es un array REAL, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          longitud del array WORK. LWORK >= N*N+N*NB.
!>
