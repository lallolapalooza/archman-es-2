random(3) Manual de funciones de biblioteca random(3)

NOMBRE

random, srandom, initstate, setstate - generador de números aleatorios

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
long random(void);
void srandom(unsigned int seed);
char *initstate(size_t n;
                unsigned int seed, char state[n], size_t n);
char *setstate(char *state);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

random(), srandom(), initstate(), setstate():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPCIÓN

La función random() utiliza un generador de números aleatorios de retroalimentación aditiva no lineal que emplea una tabla predeterminada de 31 enteros largos para devolver números pseudoaleatorios sucesivos en el rango de 0 a 2^31 - 1. El período de este generador de números aleatorios es muy grande, aproximadamente 16 * ((2^31) - 1).

La función srandom() establece su argumento como la semilla para una nueva secuencia de enteros pseudoaleatorios que serán devueltos por random(). Estas secuencias se pueden repetir llamando a srandom() con el mismo valor de semilla. Si no se proporciona ningún valor de semilla, la función random() se siembra automáticamente con el valor 1.

La función initstate() permite inicializar un array de estado state para su uso por random(). El tamaño del array de estado n es utilizado por initstate() para decidir qué tan sofisticado será el generador de números aleatorios que utilizará: cuanto mayor sea el array de estado, mejores serán los números aleatorios. Los valores actuales "óptimos" para el tamaño del array de estado n son 8, 32, 64, 128 y 256 bytes; otras cantidades se redondearán hacia abajo a la cantidad conocida más cercana. El uso de menos de 8 bytes resulta en un error. seed es la semilla para la inicialización, que especifica un punto de partida para la secuencia de números aleatorios y permite reiniciar en el mismo punto.

La función setstate() cambia el array de estado utilizado por la función random(). El array de estado state se utiliza para la generación de números aleatorios hasta la próxima llamada a initstate() o setstate(). state debe haber sido inicializado previamente usando initstate() o ser el resultado de una llamada anterior a setstate().

VALOR DE RETORNO

La función random() devuelve un valor entre 0 y (2^31) - 1. La función srandom() no devuelve ningún valor.

La función initstate() devuelve un puntero al array de estado anterior. En caso de fallo, devuelve NULL y se establece errno para indicar el error.

En caso de éxito, setstate() devuelve un puntero al array de estado anterior. En caso de fallo, devuelve NULL y se establece errno para indicar el error.

ERRORES

EINVAL
El argumento state proporcionado a setstate() era NULL.
EINVAL
Se especificó un array de estado de menos de 8 bytes a initstate().

NOTAS

La generación de números aleatorios es un tema complejo. Numerical Recipes in C: The Art of Scientific Computing (William H. Press, Brian P. Flannery, Saul A. Teukolsky, William T. Vetterling; Nueva York: Cambridge University Press, 2007, 3ª ed.) proporciona una excelente discusión sobre cuestiones prácticas de generación de números aleatorios en el Capítulo 7 (Números Aleatorios).

Para una discusión más teórica que también cubre muchos problemas prácticos en profundidad, consulte el Capítulo 3 (Números Aleatorios) en The Art of Computer Programming de Donald E. Knuth, volumen 2 (Algoritmos Seminúmericos), 2ª ed.; Reading, Massachusetts: Addison-Wesley Publishing Company, 1981.

ADVERTENCIAS

La función random() no debe utilizarse en programas multihilo donde se requiera un comportamiento reproducible. Utilice random_r(3) para ese propósito.

ERRORES DE PROGRAMACIÓN

Según POSIX, initstate() debería devolver NULL en caso de error. En la implementación de glibc, errno se establece (como se especifica) en caso de error, pero la función no devuelve NULL.
