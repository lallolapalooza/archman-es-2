SRZT01

Propósito:

!>
!> SRZT01 devuelve
!>      || A - R*Q || / ( M * eps * ||A|| )
!> para una A trapezoidal superior que se factorizó con STZRZF.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de las matrices A y AF.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices A y AF.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          La matriz original trapezoidal superior M por N, A.
!>

AF

!>          AF es un array REAL, dimensión (LDA,N)
!>          La salida de STZRZF para la matriz de entrada A.
!>          El triángulo inferior no se referencia.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A y AF.
!>

TAU

!>          TAU es un array REAL, dimensión (M)
!>          Detalles de las transformaciones de Householder devueltas por
!>          STZRZF.
!>

WORK

!>          WORK es un array REAL, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La longitud del array WORK.  LWORK >= m*n + m*nb.
!>
