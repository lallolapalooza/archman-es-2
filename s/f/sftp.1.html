NOMBRE

sftp — Transferencia segura de archivos de OpenSSH

SINOPSIS

sftp [-46AaCfNpqrv] [-B tamaño_buffer] [-b archivo_batch] [-c cifrado] [-D comando_servidor_sftp] [-F config_ssh] [-i archivo_identidad] [-J destino] [-l limite] [-o opcion_ssh] [-P puerto] [-R num_solicitudes] [-S programa] [-s subsistema | servidor_sftp] [-X opcion_sftp] destino

DESCRIPCIÓN

sftp es un programa de transferencia de archivos, similar a ftp(1), que realiza todas las operaciones a través de un transporte ssh(1) cifrado. También puede utilizar muchas características de ssh, como la autenticación de clave pública y la compresión.

El destino puede especificarse como [usuario@]host[:ruta] o como una URI en la forma sftp://[usuario@]host[:puerto][/ruta].

Si el destino incluye una ruta y no es un directorio, sftp recuperará los archivos automáticamente si se utiliza un método de autenticación no interactivo; de lo contrario, lo hará después de una autenticación interactiva exitosa.

Si no se especifica ninguna ruta, o si la ruta es un directorio, sftp iniciará sesión en el host especificado y entrará en el modo de comandos interactivo, cambiando al directorio remoto si se especificó uno. Se puede usar una barra inclinada final opcional para forzar que la ruta se interprete como un directorio.

Dado que los formatos de destino utilizan caracteres de dos puntos para delimitar los nombres de host de las rutas o los números de puerto, las direcciones IPv6 deben encerrarse entre corchetes para evitar ambigüedades.

Las opciones son las siguientes:

-4
Fuerza a sftp a usar solo direcciones IPv4.
-6
Fuerza a sftp a usar solo direcciones IPv6.
-A
Permite el reenvío de ssh-agent(1) al sistema remoto. Por defecto, no se reenvía un agente de autenticación.
-a
Intenta continuar las transferencias interrumpidas en lugar de sobrescribir las copias parciales o completas existentes de los archivos. Si los contenidos parciales difieren de los que se están transfiriendo, es probable que el archivo resultante esté corrupto.
-B tamaño_buffer
Especifica el tamaño del buffer que utiliza sftp al transferir archivos. Buffers más grandes requieren menos viajes de ida y vuelta a costa de un mayor consumo de memoria. El valor predeterminado es 32768 bytes.
-b archivo_batch
El modo batch lee una serie de comandos de un archivo_batch de entrada en lugar de stdin. Dado que carece de interacción con el usuario, debe usarse junto con la autenticación no interactiva para evitar la necesidad de introducir una contraseña en el momento de la conexión (consulte sshd(8) y ssh-keygen(1) para obtener detalles).

Un archivo_batch de ‘-’ puede usarse para indicar la entrada estándar. sftp abortará si alguno de los siguientes comandos falla: get, put, reget, reput, rename, ln, rm, mkdir, chdir, ls, lchdir, copy, cp, chmod, chown, chgrp, lpwd, df, symlink, y lmkdir.

La terminación por error puede suprimirse comando por comando anteponiendo al comando un carácter ‘-’ (por ejemplo, -rm /tmp/blah*). El eco del comando puede suprimirse anteponiendo al comando un carácter ‘@’. Estos dos prefijos pueden combinarse en cualquier orden, por ejemplo -@ls /bsd.

-C
Habilita la compresión (a través de la bandera -C de ssh).
-c cifrado
Selecciona el cifrado a utilizar para cifrar las transferencias de datos. Esta opción se pasa directamente a ssh(1).
-D comando_servidor_sftp
Conéctate directamente a un servidor sftp local (en lugar de a través de ssh(1)). Se puede especificar un comando y sus argumentos, por ejemplo "/path/sftp-server -el debug3". Esta opción puede ser útil para depurar el cliente y el servidor.
-F config_ssh
Especifica un archivo de configuración alternativo por usuario para ssh(1). Esta opción se pasa directamente a ssh(1).
-f
Solicita que los archivos se vacíen al disco inmediatamente después de la transferencia. Al subir archivos, esta función solo se habilita si el servidor implementa la extensión "fsync@openssh.com".
-i archivo_identidad
Selecciona el archivo del que se leerá la identidad (clave privada) para la autenticación de clave pública. Esta opción se pasa directamente a ssh(1).
-J destino
Conéctate al host de destino estableciendo primero una conexión sftp al host de salto descrito por destino y luego estableciendo un reenvío TCP desde allí al destino final. Se pueden especificar varios saltos separados por comas. Esta es una forma abreviada de especificar una directiva de configuración ProxyJump. Esta opción se pasa directamente a ssh(1).
-l limite
Limita el ancho de banda utilizado, especificado en Kbit/s.
-N
Deshabilita el modo silencioso, por ejemplo, para anular el modo silencioso implícito establecido por la bandera -b.
-o opcion_ssh
Se puede utilizar para pasar opciones a ssh en el formato utilizado en ssh_config(5). Esto es útil para especificar opciones para

SYNOPSIS

sftp [options] [user@]host [file ...]

sftp [options] sftp://user[:password]@host[:port]/[file ...]

DESCRIPTION

The sftp utility is a file transfer program, which communicates with the sftp-server subsystem of sshd(8). It invokes sshd to establish an SSH2 connection to a remote host. All tty, command, port forwarding, and environment controls are as with ssh(1).

The options listed below are interpreted by sftp and may also be passed to the underlying SSH connection.

There are two pseudo-commands, `quit` and `help`.

All other arguments are treated as remote files to be transferred to the local host.

The available options are:

-1
Force protocol version 1. See ssh(1).
-2
Force protocol version 2. See ssh(1).
-4
Force IPv4 address resolution. See ssh(1).
-6
Force IPv6 address resolution. See ssh(1).
-A
Always ask for a passphrase, even if one is not needed. See ssh(1).
-a
Connect to the given host on the given port, and use all local wildcard characters recognised by the ssh_config(5) (5) configuration file. See ssh(1).
-b bind_address
Use bind_address when raising a local, remote, or dynamic port forward. See ssh(1).
-C
Enable compression. See ssh(1).
-c cipher_spec
Select the cipher specification. See ssh(1).
-D port
Specifies a local, dynamic application-level port forwarding.
-e escape_char
Sets the escape character for terminal mode sessions. The default is ‘~’. See ssh(1).
-F configfile
Specifies the name of the file to be used for client configuration.
-f
Requests ssh to go to background just before command execution. This is useful if you want to run ssh on a background transcript. See ssh(1).
-G
Causes sftp to print the values of all granted port forwarding directives and then exit.
-g
Allows remote hosts to connect to locally forwarded ports. See ssh(1).
-h
Help text. See ssh(1).
-i identity_file
Selects a file from which the identity (private key) for public key authentication is read. See ssh(1).
-K sftp_option
Specify an option that controls aspects of SFTP protocol behaviour. The valid options are:
nrequests=value
Controls how many concurrent SFTP read or write requests may be in progress at any point in time during a download or upload. By default 64 requests may be active concurrently.
buffer=value
Controls the maximum buffer size for a single SFTP read/write operation used during download or upload. By default a 32KB buffer is used.
Note that many ssh_config(5) options are not directly supported by sftp and require the -o flag. For example, to specify an alternate port use: sftp -oPort=24. For full details of the options listed below, and their possible values, see ssh_config(5).

-P port
Specifies the port to connect to on the remote host.
-p
Preserves modification times, access times, and modes from the original files transferred.
-q
Quiet mode: disables the progress meter as well as warning and diagnostic messages from ssh(1).
-R num_requests
Specify how many requests may be outstanding at any one time. Increasing this may slightly improve file transfer speed but will increase memory usage. The default is 64 outstanding requests.
-r
Recursively copy entire directories when uploading and downloading. Note that sftp does not follow symbolic links encountered in the tree traversal.
-S program
Name of the program to use for the encrypted connection. The program must understand ssh(1) options.
-s subsystem | sftp_server
Specifies the SSH2 subsystem or the path for an sftp server on the remote host. A path is useful when the remote sshd(8) does not have an sftp subsystem configured.
-v
Raise logging level. This option is also passed to ssh.
-X sftp_option
Specify an option that controls aspects of SFTP protocol behaviour. The valid options are:
nrequests=value
Controls how many concurrent SFTP read or write requests may be in progress at any point in time during a download or upload. By default 64 requests may be active concurrently.
buffer=value
Controls the maximum buffer size for a single SFTP read/write operation used during download or upload. By default a 32KB buffer is used.

INTERACTIVE COMMANDS

Once in interactive mode, sftp understands a set of commands similar to those of ftp(1). Commands are case insensitive. Pathnames that contain spaces must be enclosed in quotes. Any special characters contained within pathnames that are recognized by glob(3) must be escaped with backslashes (‘\’).

bye
Quit sftp.
cd [path]
Change remote directory to path. If path is not specified, then change directory to the one the session started i
n.
chgrp [-h] grp path
Cambia el grupo del archivo path a grp. path puede contener caracteres glob(7) y puede coincidir con varios archivos. grp debe ser un GID numérico.

Si se especifica la opción -h, los enlaces simbólicos no se seguirán. Tenga en cuenta que esto solo es compatible con servidores que implementan la extensión "lsetstat@openssh.com".

chmod [-h] mode path
Cambia los permisos del archivo path a mode. path puede contener caracteres glob(7) y puede coincidir con varios archivos.

Si se especifica la opción -h, los enlaces simbólicos no se seguirán. Tenga en cuenta que esto solo es compatible con servidores que implementan la extensión "lsetstat@openssh.com".

chown [-h] own path
Cambia el propietario del archivo path a own. path puede contener caracteres glob(7) y puede coincidir con varios archivos. own debe ser un UID numérico.

Si se especifica la opción -h, los enlaces simbólicos no se seguirán. Tenga en cuenta que esto solo es compatible con servidores que implementan la extensión "lsetstat@openssh.com".

copy oldpath newpath
Copia un archivo remoto de oldpath a newpath.

Tenga en cuenta que esto solo es compatible con servidores que implementan la extensión "copy-data".

cp oldpath newpath
Alias del comando copy.
df [-hi] [path]
Muestra información de uso del sistema de archivos que contiene el directorio actual (o path si se especifica). Si se especifica la opción -h, la información de capacidad se mostrará utilizando sufijos "legibles por humanos". La opción -i solicita la visualización de información de inodos además de la información de capacidad. Este comando solo se admite en servidores que implementan la extensión “statvfs@openssh.com”.
exit
Sale de sftp.
get [-afpR] remote-path [local-path]
Recupera remote-path y lo almacena en la máquina local. Si no se especifica el nombre de la ruta local, se le asigna el mismo nombre que tiene en la máquina remota. remote-path puede contener caracteres glob(7) y puede coincidir con varios archivos. Si es así y se especifica local-path, entonces local-path debe especificar un directorio.

Si se especifica la opción -a, se intentará reanudar transferencias parciales de archivos existentes. Tenga en cuenta que la reanudación asume que cualquier copia parcial del archivo local coincide con la copia remota. Si el contenido del archivo remoto difiere de la copia local parcial, el archivo resultante probablemente estará corrupto.

Si se especifica la opción -f, se llamará a fsync(2) después de que la transferencia del archivo se haya completado para volcar el archivo al disco.

Si se especifica la opción -p, también se copiarán los permisos completos del archivo y los tiempos de acceso.

Si se especifica la opción -R, los directorios se copiarán recursivamente. Tenga en cuenta que sftp no sigue los enlaces simbólicos al realizar transferencias recursivas.

help
Muestra el texto de ayuda.
lcd [path]
Cambia el directorio local a path. Si no se especifica path, cambia al directorio de inicio del usuario local.
lls [ls-options [path]]
Muestra la lista del directorio local de path o del directorio actual si no se especifica path. ls-options puede contener cualquier bandera admitida por el comando ls(1) del sistema local. path puede contener caracteres glob(7) y puede coincidir con varios archivos.
lmkdir path
Crea el directorio local especificado por path.
ln [-s] oldpath newpath
Crea un enlace de oldpath a newpath. Si se especifica la opción -s, el enlace creado es un enlace simbólico; de lo contrario, es un enlace físico.
lpwd
Imprime el directorio de trabajo local.
ls [-1afhlnrSt] [path]
Muestra una lista del directorio remoto de path o del directorio actual si no se especifica path. path puede contener caracteres glob(7) y puede coincidir con varios archivos.

Se reconocen las siguientes opciones y alteran el comportamiento de ls en consecuencia:

-1
Produce una salida de columna única.
-a
Lista archivos que comienzan con un punto (‘.’).
-f
No ordena la lista. El orden de clasificación predeterminado es lexicográfico.
-h
Cuando se usa con una opción de formato largo, utiliza sufijos de unidad: Byte, Kilobyte, Megabyte, Gigabyte, Terabyte, Petabyte y Exabyte para reducir el número de dígitos a cuatro o menos utilizando potencias de 2 para los tamaños (K=1024, M=1048576, etc.).
-l
Muestra detalles adicionales, incluida la información de permisos y propiedad.
-n
Produce una lista larga con la información de usuario y grupo presentada numéricamente.
-r
Invierte el orden de clasificación de la lista.
-S
Clasifica la lista por tamaño de archivo.
-t
Clasifica la lista por la hora de la última modificación.
lumask umask
Establece la máscara de creación de archivos local a umask.

Crea el directorio remoto especificado por path.

Si no se especifica el nombre de la ruta remota, se le asigna el mismo nombre que tiene en la máquina local. local-path puede contener caracteres glob(7) y puede coincidir con varios archivos. Si es así y se especifica remote-path, entonces remote-path debe especificar un directorio.

Si se especifica la opción -a, se intentará reanudar transferencias parciales de archivos existentes. Tenga en cuenta que la reanudación asume que cualquier copia parcial del archivo remoto coincide con la copia local. Si el contenido del archivo local difiere de la copia local remota, el archivo resultante probablemente estará corrupto.

Si se especifica la opción -f, se enviará una solicitud al servidor para que llame a fsync(2) después de que el archivo se haya transferido. Tenga en cuenta que esto solo es compatible con servidores que implementan la extensión "fsync@openssh.com".

Si se especifica la opción -p, también se copiarán los permisos completos del archivo y los tiempos de acceso.

Si se especifica la opción -R, los directorios se copiarán recursivamente. Tenga en cuenta que sftp no sigue los enlaces simbólicos al realizar transferencias recursivas.
