NOMBRE

sfizz_jack - Inicia una instancia de sfizz como cliente JACK

SINOPSIS

sfizz_jack [ARCHIVO] [OPCIONES...]

DESCRIPCIÓN

sfizz_jack envuelve la biblioteca sfizz SFZ en un cliente JACK que puede ser controlado por una interfaz de texto.

OPCIONES

ARCHIVO
Nombre opcional de un archivo SFZ para cargar al principio
--nombre_cliente
Nombre para el cliente JACK
--num_voces NÚMERO
Cambia la polifonía máxima
--tamano_precarga NÚMERO
Bytes a precargar en la caché para las muestras
--estado
Muestra el estado en el bucle JACK
--autoconexion_jack
Autoconecta las salidas JACK

INTERFAZ DE TEXTO

Es posible interactuar con el cliente JACK a través de la entrada estándar. Los comandos posibles son

cargar_instrumento ARCHIVO
Carga un instrumento
establecer_tamano_precarga NÚMERO
Establece el número de bytes a precargar en la caché para las muestras
establecer_voces NÚMERO
Cambia la polifonía máxima
salir
Salir
