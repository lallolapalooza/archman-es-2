NOMBRE

sfparse - analizar archivo de cadenas

SINOPSIS

sfparse [ --utf8 | --unicode ] nombre_archivo

DESCRIPCIÓN

Esta herramienta tiene dos funciones diferentes. Cuando se invoca solo con un nombre de archivo como argumento, verifica que un archivo sea un strings-file válido, lo que básicamente equivale a ver si el archivo está en el formato serializado correcto de NSDictionary (ver tipo "defaults plist" para más información al respecto).

Por otro lado, si se proporciona alguna de las dos opciones, no se realiza ninguna comprobación de este tipo, pero el archivo SE CONVIERTE a la codificación especificada.

OPCIONES

--unicode - convertir un archivo ASCII o UTF8 a Unicode

--utf8 - convertir un archivo ASCII o Unicode a UTF8
