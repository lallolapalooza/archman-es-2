SFTP-SERVER(8) Manual del Administrador del Sistema SFTP-SERVER(8)

NOMBRE

sftp-server — Subsistema SFTP del servidor OpenSSH

SINOPSIS

sftp-server [-ehR] [-d directorio_inicio] [-f instalacion_log] [-l nivel_log] [-P solicitudes_denegadas] [-p solicitudes_permitidas] [-u umask]

sftp-server -Q caracteristica_protocolo

DESCRIPCIÓN

sftp-server es un programa que habla el lado del servidor del protocolo SFTP a stdout y espera las solicitudes del cliente desde stdin. sftp-server no está destinado a ser llamado directamente, sino desde sshd(8) usando la opción Subsystem.

Las banderas de la línea de comandos para sftp-server deben especificarse en la declaración Subsystem. Consulte sshd_config(5) para obtener más información.

Las opciones válidas son:

-d directorio_inicio
Especifica un directorio de inicio alternativo para los usuarios. La ruta puede contener los siguientes tokens que se expanden en tiempo de ejecución: %% se reemplaza por un '%' literal, %d se reemplaza por el directorio personal del usuario que se está autenticando, y %u se reemplaza por el nombre de usuario de dicho usuario. El valor predeterminado es usar el directorio personal del usuario. Esta opción es útil en conjunción con la opción ChrootDirectory de sshd_config(5).
-e
Hace que sftp-server imprima información de registro en stderr en lugar de syslog para depuración.
-f instalacion_log
Especifica el código de instalación que se utiliza al registrar mensajes de sftp-server. Los valores posibles son: DAEMON, USER, AUTH, LOCAL0, LOCAL1, LOCAL2, LOCAL3, LOCAL4, LOCAL5, LOCAL6, LOCAL7. El valor predeterminado es AUTH.
-h
Muestra la información de uso de sftp-server.
-l nivel_log
Especifica qué mensajes registrará sftp-server. Los valores posibles son: QUIET, FATAL, ERROR, INFO, VERBOSE, DEBUG, DEBUG1, DEBUG2 y DEBUG3. INFO y VERBOSE registran transacciones que sftp-server realiza en nombre del cliente. DEBUG y DEBUG1 son equivalentes. DEBUG2 y DEBUG3 especifican niveles más altos de salida de depuración. El valor predeterminado es ERROR.
-P solicitudes_denegadas
Especifica una lista separada por comas de solicitudes del protocolo SFTP que están prohibidas por el servidor. sftp-server responderá a cualquier solicitud denegada con un fallo. La bandera -Q se puede utilizar para determinar los tipos de solicitud compatibles. Si se especifican tanto la lista denegada como la permitida, la lista denegada se aplica antes que la lista permitida.
-p solicitudes_permitidas
Especifica una lista separada por comas de solicitudes del protocolo SFTP que están permitidas por el servidor. Todos los tipos de solicitud que no estén en la lista permitida se registrarán y se responderán con un mensaje de fallo.

Se debe tener cuidado al usar esta función para asegurarse de que se permiten las solicitudes realizadas implícitamente por los clientes SFTP.

-Q caracteristica_protocolo
Consulta las características del protocolo compatibles con sftp-server. Actualmente, la única característica que se puede consultar es "requests", que se puede utilizar para denegar o permitir solicitudes específicas (banderas -P y -p respectivamente).
-R
Coloca esta instancia de sftp-server en modo de solo lectura. Los intentos de abrir archivos para escritura, así como otras operaciones que cambian el estado del sistema de archivos, serán denegados.
-u umask
Establece una umask(2) explícita que se aplicará a los archivos y directorios recién creados, en lugar de la máscara predeterminada del usuario.

En algunos sistemas, sftp-server debe poder acceder a /dev/log para que el registro funcione, y el uso de sftp-server en una configuración chroot, por lo tanto, requiere que syslogd(8) establezca un socket de registro dentro del directorio chroot.
