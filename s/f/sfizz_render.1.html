NOMBRE

sfizz_render - Renderiza un archivo MIDI como un archivo WAV usando una descripción de instrumento SFZ.

SINOPSIS

sfizz_render --sfz ARCHIVO --wav ARCHIVO --midi ARCHIVO [OPCIONES...]

DESCRIPCIÓN

sfizz_render envuelve la biblioteca sfizz SFZ y puede usarse para renderizar archivos MIDI como archivos de sonido utilizando un archivo de descripción SFZ y sus muestras asociadas.

OPCIONES

-b, --blocksize NÚMERO
Tamaño del bloque para las devoluciones de llamada de sfizz
-s, --samplerate NÚMERO
Frecuencia de muestreo de salida
-q, --quality NÚMERO
Calidad de remuestreo, como el opcode SFZ sample_quality. Un valor de 1 usará una interpolación lineal de las muestras de origen, mientras que un valor más alto usará algoritmos cada vez mejores.
-p, --polyphony NÚMERO
Polifonía máxima
-v, --verbose
Salida detallada
--log PREFIJO
Generar registros
--use-eot
Finalizar la renderización en el último mensaje Midi End of Track
-h, --help
Mostrar ayuda
