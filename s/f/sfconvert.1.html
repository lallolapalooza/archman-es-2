NOMBRE

sfconvert - convierte archivos de audio

SINOPSIS

sfconvert archivo_entrada archivo_salida [opciones_salida]

DESCRIPCIÓN

El comando sfconvert convierte un archivo de audio a otro formato de archivo o formato de datos.

OPCIONES

Las siguientes palabras clave especifican el formato del archivo de sonido de salida:

formato f

Formato del archivo de salida. f debe ser uno de los siguientes:
aiff Audio Interchange File Format
aifc AIFF-C
next Formato NeXT/Sun .snd/.au
wave MS RIFF WAVE
bicsf Formato de Archivo de Sonido Berkeley/IRCAM/CARL
smp Formato Sample Vision
voc Formato de Archivo de Voz Creative
nist Formato NIST SPHERE
caf Formato Core Audio
flac FLAC

compresión c

ulaw G.711 mu-law
alaw G.711 A-law
ima IMA ADPCM
msadpcm Microsoft ADPCM
flac FLAC
alac Apple Lossless Audio Codec

orden_bytes e

Orden de bytes de salida. e puede ser big (mayor) o little (menor).

canales n

Número de canales de salida. n es 1 para mono y 2 para estéreo.

entero n s

Convertir a datos de audio enteros. n indica el ancho de bits de la muestra de salida. s especifica el formato de la muestra y puede ser 2scomp para datos con signo en complemento a 2 o unsigned para datos sin signo.

flotante m

Convertir a datos de audio de punto flotante con una amplitud máxima de m (generalmente 1.0). Las opciones entero y flotante se excluyen mutuamente.

Las siguientes opciones no toman argumentos adicionales:

--ayuda, -h

Imprimir mensaje de ayuda.

--version, -v

Imprimir información de la versión.
