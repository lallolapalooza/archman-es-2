NOMBRE

sfinfo - muestra información sobre archivos de audio

SINOPSIS

sfinfo [opciones] archivos de audio...

DESCRIPCIÓN

sfinfo imprime información sobre los archivos de audio especificados, incluyendo el formato del archivo, la frecuencia de muestreo, la duración y el formato de los datos de audio.

Por defecto, sfinfo muestra la información en un formato largo de varias líneas; especificar la opción --short o -s produce un resumen corto de una sola línea.

Cualquier archivo que no sea reconocido como un archivo de audio válido será ignorado a menos que se proporcione la opción --reporterror o -r. Los formatos de archivo actualmente soportados por sfinfo son AIFF, AIFF-C, NeXT/Sun .snd/.au, WAVE, Berkeley/IRCAM/CARL Sound File, AVR, Amiga IFF/8SVX, Sample Vision, Creative Voice File, NIST SPHERE y Core Audio Format.

OPCIONES

--short, -s

Imprime un resumen corto de una sola línea de cada archivo de audio reconocido.

--reporterror, -r

Imprime un mensaje de error si alguno de los archivos especificados no es reconocido como un archivo de audio válido.

--help, -h

Imprime el mensaje de ayuda.

--version, -v

Imprime la información de la versión.

EJEMPLOS

Mostrar un resumen de un archivo de audio:

% sfinfo drum.aiff
File Name      drum.aiff
File Format    Audio Interchange File Format (aiff)
Data Format    16-bit integer (2's complement, big endian)
Audio Data     1569972 bytes begins at offset 54 (36 hex)
               2 channels, 392493 frames
Sampling Rate  44100.00 Hz
Duration       8.900 seconds

Listar todos los archivos de audio reconocidos en el directorio actual usando el formato de salida corto:

% sfinfo -s *
    9.60s 44100.00 aiff  1ch 16b -- bass.aiff
    8.90s 44100.00 aiff  2ch 16b -- drum.aiff
