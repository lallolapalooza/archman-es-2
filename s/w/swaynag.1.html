NOMBRE

swaynag - Muestra un mensaje de advertencia o error con botones

SINOPSIS

swaynag [opciones...]

OPCIONES

-b, --button <texto> <acción>

Crea un botón con el texto texto que ejecuta acción cuando se presiona. Si la variable de entorno TERMINAL está definida, acción se ejecutará dentro de la terminal. De lo contrario, recurrirá a la ejecución directa. Se pueden definir múltiples botones proporcionando la bandera varias veces.

-B, --button-no-terminal <texto> <acción>

Crea un botón con el texto texto que ejecuta acción cuando se presiona. acción se ejecutará directamente en lugar de en una terminal. Se pueden definir múltiples botones proporcionando la bandera varias veces.

-z, --button-dismiss <texto> <acción>

Crea un botón con el texto texto que ejecuta acción cuando se presiona, y cierra swaynag. Si la variable de entorno TERMINAL está definida, acción se ejecutará dentro de la terminal. De lo contrario, recurrirá a la ejecución directa. Se pueden definir múltiples botones proporcionando la bandera varias veces.

-Z, --button-dismiss-no-terminal <texto> <acción>

Crea un botón con el texto texto que ejecuta acción cuando se presiona, y cierra swaynag. acción se ejecutará directamente en lugar de en una terminal. Se pueden definir múltiples botones proporcionando la bandera varias veces.

-c, --config <ruta>

El archivo de configuración a usar. Por defecto, se verifican las siguientes rutas: $HOME/.swaynag/config, $XDG_CONFIG_HOME/swaynag/config, y SYSCONFDIR/swaynag/config. Todas las banderas, aparte de esta y debug, son opciones válidas en el archivo de configuración con el formato opción-larga=valor. Se deben omitir todos los guiones iniciales y el signo igual es obligatorio. Consulte swaynag(5) para más información.

-d, --debug

Habilita la depuración.

-e, --edge top|bottom

Establece el borde a usar.

-y, --layer overlay|top|bottom|background

Establece la capa a usar.

-f, --font <fuente>

Establece la fuente a usar.

-h, --help

Muestra el mensaje de ayuda y sale.

-l, --detailed-message

Lee un mensaje detallado desde la entrada estándar. Se añadirá un botón para alternar detalles. Los detalles se muestran en un área de texto multilínea desplazable.

-L, --detailed-button <texto>

Establece el texto para el botón que alterna los detalles. Esto no tiene efecto si no hay un mensaje detallado. El valor por defecto es Alternar detalles.

-m, --message <mensaje>

Establece el texto del mensaje.

-o, --output <salida>

Establece la salida a usar. Este debe ser el nombre de un xdg_output.

-s, --dismiss-button <texto>

Establece el texto para el botón de cerrar el nagbar. El valor por defecto es X.

-t, --type <tipo>

Establece el tipo de mensaje. Por defecto, se crean dos tipos: error y warning. Se pueden definir tipos personalizados en el archivo de configuración. Consulte --config y swaynag(5) para más detalles. Ambos tipos predeterminados pueden ser sobrescritos en el archivo de configuración.

-v, --version

Muestra el número de versión y sale.

OPCIONES DE APARIENCIA

--background <RRGGBB[AA]>

Establece el color del fondo.

--border <RRGGBB[AA]>

Establece el color del borde.

--border-bottom <RRGGBB[AA]>

Establece el color del borde inferior.

--button-background <RRGGBB[AA]>

Establece el color del fondo para los botones.

--text <RRGGBB[AA]>

Establece el color del texto.

--button-text <RRGGBB[AA]>

Establece el color del texto del botón.

--border-bottom-size <tamaño>

Establece el grosor del borde inferior.

--message-padding <relleno>

Establece el relleno del mensaje.

--details-background <RRGGBB[AA]>

Establece el color del fondo para los detalles.

--details-border-size <tamaño>

Establece el grosor del borde de los detalles.

--button-border-size <tamaño>

Establece el grosor del borde del botón.

--button-gap <espacio>

Establece el tamaño del espacio entre botones.

--button-dismiss-gap <espacio>

Establece el tamaño del espacio entre el botón de cierre y otro botón.

--button-margin-right <margen>

Establece el margen desde la derecha del botón de cierre hasta el borde.

--button-padding <relleno>

Establece el relleno del texto del botón.
