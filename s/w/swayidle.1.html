NOMBRE

swayidle - Gestor de inactividad para Wayland

SINOPSIS

swayidle [opciones] [eventos...]

OPCIONES

-C <ruta>

El archivo de configuración a usar. Por defecto, las siguientes rutas se comprueban en el siguiente orden: $XDG_CONFIG_HOME/swayidle/config, $HOME/.swayidle/config. Las entradas del archivo de configuración son eventos como se describe en la sección EVENTOS. Especificar eventos en el archivo de configuración y como argumentos no es mutuamente excluyente.

-h

Mostrar mensaje de ayuda y salir.

-d

Habilitar salida de depuración.

-w

Esperar a que el comando termine de ejecutarse antes de continuar, útil para asegurar que un comando before-sleep ha terminado antes de que el sistema se suspenda.

Nota: usar esta opción hace que swayidle se bloquee hasta que el comando finalice.

-S <nombre-asiento>

Especificar qué asiento usar. Por defecto, si no se especifica ningún nombre, se elegirá un asiento arbitrario.

DESCRIPCIÓN

swayidle escucha la actividad de inactividad en tu compositor Wayland y ejecuta tareas en varios eventos relacionados con la inactividad. Puedes especificar cualquier número de eventos en la línea de comandos y en el archivo de configuración.

EVENTOS

timeout <tiempo_espera> <comando_tiempo_espera> [reanudar <comando_reanudar>]

Ejecutar comando_tiempo_espera si no hay actividad durante <tiempo_espera> segundos.

Si especificas "reanudar <comando_reanudar>", comando_reanudar se ejecutará cuando haya actividad de nuevo.

before-sleep <comando>

Si se compila con soporte para systemd, ejecuta comando antes de que systemd suspenda el ordenador.

Nota: esto solo retrasa la suspensión hasta el límite establecido en logind.conf(5) por la opción InhibitDelayMaxSec. Un comando que no haya terminado para entonces continuará ejecutándose después de reanudar la suspensión.

after-resume <comando>

Si se compila con soporte para systemd, ejecuta comando después de que logind señale que el ordenador se ha reanudado de la suspensión.

lock <comando>

Si se compila con soporte para systemd, ejecuta comando cuando logind señale que la sesión debe ser bloqueada.

unlock <comando>

Si se compila con soporte para systemd, ejecuta comando cuando logind señale que la sesión debe ser desbloqueada.

idlehint <tiempo_espera>

Si se compila con soporte para systemd, establece IdleHint para indicar una sesión inactiva de logind/elogind después de <tiempo_espera> segundos. Añadir un evento idlehint también hará que swayidle llame a SetIdleHint(false) al ejecutarse, al reanudar, desbloquear, etc.

Todos los comandos se ejecutan en un shell.

SEÑALES

swayidle responde a las siguientes señales:

SIGTERM, SIGINT

Ejecutar todos los comandos de reanudación pendientes. Cuando termine, swayidle terminará.

SIGUSR1

Entrar inmediatamente en estado de inactividad.

EJEMPLO

swayidle -w \
	timeout 300 'swaylock -f -c 000000' \
	timeout 600 'swaymsg "output * power off"' \
		resume 'swaymsg "output * power on"' \
	before-sleep 'swaylock -f -c 000000'

Esto bloqueará tu pantalla después de 300 segundos de inactividad, luego apagará tus pantallas después de otros 300 segundos, y encenderá tus pantallas de nuevo al reanudar. También bloqueará tu pantalla antes de que tu ordenador se suspenda.

Para asegurar que swayidle espera a que swaylock bloquee la pantalla antes de liberar el bloqueo de inhibición, se usa la opción -w en swayidle, y -f en swaylock.
