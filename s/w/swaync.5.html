swaync(5) Manual de Formatos de Archivo swaync(5)

NOMBRE

swaync - Archivo de configuración

CONFIGURACIÓN

Se recomienda utilizar un editor de texto con un servidor de lenguaje JSON al editar el archivo de configuración para poder detectar errores de configuración.

ignore-gtk-theme
tipo: booleano
por defecto: true
descripción: Desestablece la variable de entorno GTK_THEME, solucionando muchos
problemas con los temas GTK que arruinan los temas CSS personalizados del usuario.

positionX
tipo: cadena
por defecto: right
valores: left, right, center
descripción: Posición horizontal del centro de control y la ventana de notificación.

positionY
tipo: cadena
por defecto: top
valores: top, center, bottom
descripción: Posición vertical del centro de control y la ventana de notificación.

layer
tipo: cadena
por defecto: overlay
valores: background, bottom, top, overlay
descripción: Capa de la ventana de notificación relativa a las ventanas normales.
background está por debajo de todas las ventanas, overlay está por encima de todas las ventanas.

layer-shell
tipo: booleano
por defecto: true
descripción: Si las ventanas deben abrirse como superficies de layer-shell
o no. Nota: Requiere reiniciar swaync para aplicar.

cssPriority
tipo: cadena
por defecto: application
valores: application, user
descripción: Qué prioridad GTK se debe usar al cargar los archivos CSS predeterminados y de usuario.
Seleccione "user" para sobrescribir XDG_CONFIG_HOME/gtk-3.0/gtk.css

control-center-positionX
tipo: cadena
por defecto: right
valores: left, right, center
descripción: Opcional: Posición horizontal del centro de control.
Anula positionX si no se establece en `none`.

control-center-positionY
tipo: cadena
por defecto: top
valores: top, center, bottom
descripción: Opcional: Posición vertical del centro de control.
Anula positionY si no se establece en `none`.

control-center-margin-top
tipo: entero
por defecto: 0
descripción: El margen (en píxeles) en la parte superior del centro de notificación. 0 para deshabilitar.

control-center-margin-bottom
tipo: entero
por defecto: 0
descripción: El margen (en píxeles) en la parte inferior del centro de notificación. 0 para deshabilitar.

control-center-margin-right
tipo: entero
por defecto: 0
descripción: El margen (en píxeles) a la derecha del centro de notificación. 0 para deshabilitar.

control-center-margin-left
tipo: entero
por defecto: 0
descripción: El margen (en píxeles) a la izquierda del centro de notificación. 0 para deshabilitar.

control-center-layer
tipo: cadena
por defecto: top
valores: background, bottom, top, overlay
descripción: Capa de la ventana del centro de control relativa a las ventanas normales.
background está por debajo de todas las ventanas, overlay está por encima de todas las ventanas.

control-center-exclusive-zone
tipo: booleano
por defecto: true
descripción: Si el centro de control debe seguir las
zonas exclusivas del compositor o no. Un ejemplo sería establecerlo en
`false` para cubrir su panel/dock.

notification-2fa-action
tipo: booleano
por defecto: true
descripción: Si cada notificación debe mostrar una acción 'COPIAR "1234"'

timeout
tipo: entero
por defecto: 10
descripción: El tiempo de espera de la notificación para notificaciones con prioridad normal.

timeout-low
tipo: entero
por defecto: 5
descripción: El tiempo de espera de la notificación para notificaciones con baja prioridad.

timeout-critical
tipo: entero
por defecto: 0
descripción: El tiempo de espera de la notificación para notificaciones con prioridad crítica. 0 para deshabilitar.

notification-window-width
tipo: entero
por defecto: 500
descripción: Ancho de la notificación en píxeles.

notification-window-height
tipo: entero
por defecto: -1
descripción: Altura máxima de la notificación en píxeles. -1 para usar
la cantidad total de espacio proporcionado por el compositor.

notification-window-preferred-output
tipo: cadena
por defecto: ""
descripción: La salida preferida para abrir la ventana de notificación
(notificaciones emergentes). Puede ser el nombre del conector del monitor
(ej: "DP-1"), o el nombre completo, modelo del fabricante, serie
(ej: "Acer Technologies XV272U V 503023B314202").
Si no se encuentra la salida, se elige la que está enfocada actualmente.

keyboard-shortcuts
tipo: booleano
por defecto: true
descripción: Si el centro de control debe usar atajos de teclado.

notification-grouping
tipo: booleano
por defecto: true
descripción: Si las notificaciones deben agruparse por nombre de aplicación.

image-visibility
tipo: cadena
por defecto: always
valores: always, when-available, never
descripción: Una explicación sobre el propósito de esta instancia.

transition-time
tipo: entero
por defecto: 200
descripción: La duración de la animación de la notificación. 0 para deshabilitar.

hide-on-clear
tipo: booleano
por defecto: false
descripción: Oculta el centro de control después de presionar "Borrar todo".

hide-on-action
tipo: booleano
por defecto: true
descripción: Oculta el centro de control al hacer clic en la acción de la notificación.

text-empty
tipo: cadena
por defecto: "No Notifications"
descripción: Texto que aparece cuando no hay notificaciones para mostrar.

fit-to-screen
tipo: booleano
por defecto: true
descripción: Si el centro de control debe expandirse verticalmente para llenar la pantalla.

relative-timestamps
tipo: booleano
por defecto: true
descripción: Muestra las marcas de tiempo de las notificaciones relativas al momento actual, por ejemplo, "hace 26 minutos".
Si es falso, se muestra una marca de tiempo absoluta en formato iso8601 local.

control-center-height
tipo: entero
por defecto: 500
descripción: Altura del centro de control en píxeles.
Un valor de -1 significa que se ajustará al contenido.
Se ignora cuando 'fit-to-screen' está establecido en 'true'.
También se limita a la altura del monitor, a menos que
'layer-shell-cover-screen' esté establecido en falso.

control-center-width
tipo: entero
por defecto: 500
descripción: El ancho del centro de control en píxeles.

control-center-preferred-output
tipo: cadena
por defecto: ""
descripción: La salida preferida para abrir el centro de control. Puede ser
el nombre del conector del monitor (ej: "DP-1"), o
el nombre completo, modelo del fabricante, serie
(ej: "Acer Technologies XV272U V 503023B314202"). Si no
se encuentra la salida, se elige la que está enfocada actualmente.

notification-action-filter
tipo: objeto
propiedades del objeto de visibilidad:
use-regex
tipo: booleano
opcional: true
por defecto: false
descripción: Indica si todos los campos siguientes deben usar
expresiones regulares o no.
app-name
tipo: cadena
opcional: true
descripción: El nombre de la aplicación.
desktop-entry
tipo: cadena
opcional: true
descripción: La entrada de escritorio.
id-matcher
tipo: cadena
opcional: true (se necesita al menos un matcher)
descripción: Coincide con el identificador de las acciones. Se puede encontrar
leyendo la salida de swaync cuando se ejecuta con la variable de
entorno G_MESSAGES_DEBUG=all.
text-matcher
tipo: cadena
opcional: true (se necesita al menos un matcher)
descripción: Coincide con el texto de las acciones visible en la notificación.
descripción: Oculta la(s) acción(es) que coinciden de las notificaciones que coinciden.
Si la notificación no incluye una de las propiedades, esa
propiedad se ignorará. Si todas las propiedades coinciden con la
notificación dada, las acciones coincidentes se ocultarán.
ejemplo:

{
  "notification-action-filter": {
    "app-name": "firefox",
    "id-matcher": "cancel-download",
    "use-regex": false
  }
}

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

{ "notification-action-filter": { "hide-chromium-settings": { "desktop-entry": "chromium-browser", "use-regex": false, "id-matcher": "settings", "text-matcher": "Settings" } } } ```

notification-visibility
tipo: objeto
propiedades del objeto de visibilidad:
state
tipo: cadena
opcional: falso
valor predeterminado: habilitado
valores: ignorado, silenciado, transitorio, habilitado
descripción: El estado de visibilidad de la notificación.
override-urgency
tipo: cadena
opcional: verdadero
valor predeterminado: sin configurar
valores: sin configurar, bajo, normal, crítico
descripción: La nueva urgencia para la notificación si se establece.
app-name
tipo: cadena
opcional: verdadero
descripción: El nombre de la aplicación. Usa expresiones regulares.
desktop-entry
tipo: cadena
opcional: verdadero
descripción: La entrada de escritorio. Usa expresiones regulares.
summary
tipo: cadena
opcional: verdadero
descripción: El resumen de la notificación. Usa expresiones regulares.
body
tipo: cadena
opcional: verdadero
descripción: El cuerpo de la notificación. Usa expresiones regulares.
urgency
tipo: cadena
opcional: verdadero
valor predeterminado: Normal
valores: Bajo, Normal, Crítico
descripción: La urgencia de la notificación.
category
tipo: cadena
opcional: verdadero
descripción: A qué categoría pertenece la notificación. Usa expresiones regulares.
descripción: Establece la visibilidad o la urgencia de cada notificación entrante.
Si la notificación no incluye una de las propiedades, esa
propiedad se ignorará. Todas las propiedades (excepto el estado) usan
expresiones regulares. Si todas las propiedades coinciden con la notificación dada, la
notificación seguirá el estado proporcionado.
Solo se utilizará el primer objeto coincidente.
ejemplo:

{
	"notification-visibility": {
		"example-name": {
			"state": "El estado de la notificación",
			"app-name": "Regex del nombre de la app de notificación",
			"summary": "Regex del resumen de la notificación",
			"body": "Regex del cuerpo de la notificación",
			"urgency": "Bajo o Normal o Crítico",
			"category": "Regex de la categoría de notificación"
		}
	}
}

widgets
tipo: array
Valores predeterminados: ["title", "dnd", "notifications"]
Valores válidos de array (ver widget-config para más información):
notifications
requerido: verdadero
opcional: falso

opcional: verdadero

opcional: verdadero

opcional: verdadero

opcional: verdadero

opcional: verdadero
buttons-grid
opcional: verdadero
slider
opcional: verdadero
volume
opcional: verdadero
backlight
opcional: verdadero
inhibitors
opcional: verdadero
descripción:
En qué orden y qué widgets mostrar.
Si el widget "notifications" no se especifica, se colocará
en la parte inferior.
múltiples del mismo widget:
Agrega un # con cualquier valor al final del nombre del widget.
Ejemplo: "title#TheMainTitle"
Para dirigir este widget específicamente en el archivo CSS, usa la clase CSS .TheMainTitle
ejemplo:

{
	"widgets": [
		"inhibitors",
		"title",
		"dnd",
		"notifications"
	]
}

SWAYNC.5

5

NAME

swaync

- configuration file for swaynotificationcenter

CONFIGURATION

The configuration file is located at $HOME/.config/swaync/config.mk
For more information, see Configuration Wiki .

Scripts

scripts

Set a path to a directory containing scripts to run when a notification is received. Scripts can be used to trigger actions based on notification content.

Each script can be configured with the following options:

exec

This is the only property that does not use regex. It defines the shell command or script to execute. The path must be absolute, or it must be found in your $PATH.

app-name

A regex to match against the notification's app-name.

summary

A regex to match against the notification's summary.

body

A regex to match against the notification's body.

category

A regex to match against the notification's category.

urgency

Matches the notification's urgency. Can be one of: Low, Normal, or Critical.

run-on

Whether to run this action when the notification is received, or when an action is taken on it.

Type: string

Optional: true

Values: action, receive

Default: receive

The scripts listed under the scripts key will be checked and potentially run for every notification. If the notification doesn't include one of the properties, that property will be ignored. All properties (except for exec) use regex. If all properties match the given notification, the script will be run. Only the first matching script will be run.

The sound name the notification requested. Uses Regex.
