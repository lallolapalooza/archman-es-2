SWITCHEROOCTL(1) Comandos de usuario SWITCHEROOCTL(1)

NOMBRE

switcherooctl - Lanza un comando en una GPU específica

SINOPSIS

switcherooctl help [COMANDO]

switcherooctl version

switcherooctl list

switcherooctl launch [OPCIÓN] COMANDO...

DESCRIPCIÓN

switcherooctl es una utilidad para lanzar un comando específico en una GPU específica.

COMANDOS

help [COMANDO]

Muestra un breve resumen de los comandos disponibles o proporciona ayuda detallada sobre un comando específico.

version

Imprime la versión de switcheroo-control a la que pertenece switcherooctl.

list

Lista las GPUs conocidas. El número de dispositivo se puede usar para especificar la GPU en la que lanzar el comando de lanzamiento. Este es el comando predeterminado si no se pasan comandos a switcherooctl.

launch [OPCIÓN] COMANDO...

Lanza COMANDO en una GPU específica. Si no se especifican GPUs, se utiliza la primera GPU discreta (no predeterminada), o la GPU predeterminada si no hay GPU discreta.

Opciones

-g --gpu=GPU

La GPU en la que lanzar. El identificador de la GPU se puede obtener usando el comando list.

CÓDIGO DE SALIDA

En caso de éxito se devuelve 0, de lo contrario un código de error distinto de cero.
