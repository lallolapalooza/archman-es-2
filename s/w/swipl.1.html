NOMBRE

swipl - SWI-Prolog 10.0.0

SINOPSIS

swipl [--help|--version|--arch|--dump-runtime-variables]
swipl [opciones] archivo-prolog ... [--] [arg ...]
swipl [opciones] [-o salida] -c archivo ...
swipl [opciones] [-o salida] -b archivo-inicial ...

La primera versión proporciona información sobre el sistema y sale inmediatamente. La segunda versión es la forma principal de llamar a Prolog sobre uno o más archivos fuente de Prolog y proporcionar argumentos a la aplicación que se pueden solicitar utilizando current_prolog_flag(argv, Argv). La tercera versión se utiliza para crear un estado guardado mientras que la última versión se utiliza para la compilación de arranque de las partes de Prolog del sistema.

DESCRIPCIÓN

SWI-Prolog es una implementación completa y estable del lenguaje Prolog con un gran conjunto de bibliotecas. Entre sus características distintivas se encuentran el soporte maduro para multi-threading, una madura biblioteca de servidor web integrada, herramientas de desarrollo gráfico (depurador, perfilador, referenciador cruzado, editor), un eficiente almacén RDF integrado, soporte para XML/SGML/HTML y Unicode. Las características con mayor soporte incluyen soporte para programación de restricciones, recolección de basura de átomos, interfaces a bases de datos (ODBC), C, C++ y Java (JPL).

SWI-Prolog implementa el estándar principal ISO. Muchas de sus extensiones son en gran medida compatibles con YAP y SICStus Prolog.

Esta página del manual solo enumera las opciones de la línea de comandos. La documentación completa está disponible en línea, así como en formato HTML y PDF en la página principal de la WWW en http://www.swi-prolog.org

OPCIONES

--help
Proporciona un resumen de las opciones más importantes.
--version
Muestra información de versión y arquitectura.
--abi-version
Muestra la clave de la versión ABI. Esta clave indica la compatibilidad binaria de varias interfaces.
--arch
Imprime el identificador de arquitectura.
--dump-runtime-variables[=formato]
Exporta información que es generalmente útil para scripts de instalación en un formato definido por formato. Los formatos definidos son sh (por defecto, shell Bourne) y cmd (Windows CMD). Esta opción es utilizada por swipl-ld (1) para obtener la información necesaria sobre Prolog. Normalmente se invoca como eval `swipl --dump-runtime-variables`, lo que asigna las siguientes variables de shell:
CC
El compilador C utilizado para compilar SWI-Prolog.
PLBASE
El directorio base de SWI-Prolog. Este es el mismo valor que devuelve el flag current_prolog_flag home.
PLARCH
El identificador de arquitectura utilizado. Junto con PLBASE define la ubicación de varios componentes. Por ejemplo, la biblioteca para incrustar se encuentra en $PLBASE/lib/$PLARCH/libswipl.a
PLBITS
Bits de dirección para la VM. Ya sea 32 o 64.
PLLIB
Identificador de CC para enlazar con SWI-Prolog. Típicamente -lswipl
PLLIBSWIPL
Nombre de ruta completo del objeto compartido (DLL) que proporciona el núcleo de Prolog.
PLLIBS
Bibliotecas adicionales necesarias para enlazar PLLIB
PLCFLAGS
Flags que deben pasarse al compilador C para generar código compatible.
PLLDFLAGS
Flags que deben pasarse al enlazador C para enlazar ejecutables incrustados.
PLSOEXT
Extensión utilizada por el sistema operativo anfitrión para objetos compartidos. En la mayoría de los sistemas Unix es "so"; en MS-Windows es "dll". AIX usa "o", HPUX "sl".
PLSOPATH
Variable de entorno utilizada por el sistema operativo anfitrión para extender la ruta de búsqueda de objetos compartidos. Por ejemplo, en sistemas ELF es "LD_LIBRARY_PATH" y en MS-Windows es "PATH".
PLVERSION
Representación numérica de la versión de SWI-Prolog.
PLVERSIONTAG
Si está presente, una etiqueta de versión como "rc1".
PLSHARED
Tiene el valor yes si Prolog soporta el enlace de bibliotecas compartidas usando load_foreign_library/[1,2] y no en caso contrario.
PLTHREADS
Tiene el valor yes si Prolog se compiló para multi-threading y no en caso contrario.
--home=DIR
Usa DIR como directorio base.
--stack-limit=tamaño[bkmg]
Establece el límite de pila combinado a tamaño bytes. El sufijo no distingue entre mayúsculas y minúsculas y define la unidad como b (bytes), k (Kbytes), m (Mbytes) o g (Gbytes).
--table-space=tamaño[bkmg]
Establece el límite de espacio de tabla para la resolución SLG (tabling) a tamaño bytes. Los sufijos son los mismos que para la opción --stack-limit.
--shared-table-space=tamaño[bkmg]
Establece el límite de espacio de tabla para tabling compartido a tamaño bytes. Los sufijos son los mismos que para la opción --stack-limit.
-O
Compilación optimizada. Consulte set_prolog_flag/2 en el Manual de Referencia de SWI-Prolog.
-b archivo-inicial ... -c archivo ...
Compilación de arranque. archivo-inicial ... son compilados por el compilador de arranque escrito en C, archivo ... por el compilador normal de Prolog a un archivo de código intermedio. Esta opción es para mantenimiento del sistema y se proporciona solo como referencia.
-c archivo ...
Compila archivo ... en un archivo de código intermedio.
-d nivel
Establece el nivel de depuración a nivel. Esta opción es para mantenimiento del sistema y se proporciona solo como referencia.
--packs[=booleano]
Deshabilita la adjunción de paquetes de extensión (complementos).
--pce[=booleano]
Deshabilita el subsistema GUI de XPCE.
--pldoc[=puerto]
Inicia el sistema de documentación PlDoc en un puerto de red libre y abre el navegador del usuario en http://localhost:puerto. Si se especifica puerto, el servidor se inicia en el puerto dado pero el navegador no se inicia.
-f archivo
Usa archivo como archivo de inicialización en lugar de `init.pl'. `-f none' detiene a SWI-Prolog de buscar un archivo de inicialización.
-F archivo
Selecciona el script de inicio del directorio base de SWI-Prolog. archivo Especifica el nombre base del script. La extensión es .rc. El script por defecto se deduce del nombre base del ejecutable, tomando todas las letras alfanuméricas (letras, dígitos y guión bajo) iniciales del nombre del programa. Por lo tanto, si el programa se llama swi-2.0 intentará cargar el archivo swi.rc del directorio base de SWI-Prolog. Si el archivo no existe, o el usuario no tiene acceso de lectura a él, el script no se carga silenciosamente.
-s archivo
Carga archivo
