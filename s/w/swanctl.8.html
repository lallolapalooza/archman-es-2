NOMBRE

swanctl - Interfaz de línea de comandos para configuración, control y monitorización de strongSwan.

SINOPSIS

swanctl comando [opción ...]
swanctl -h | --help

DESCRIPCIÓN

swanctl es una utilidad de línea de comandos multiplataforma para configurar, controlar y monitorizar el demonio IKE de strongSwan. Es un reemplazo de las antiguas herramientas starter, ipsec y stroke.

swanctl utiliza un archivo de configuración llamado swanctl.conf(5) para interpretar configuraciones y credenciales. Las claves privadas, certificados y otras credenciales relacionadas con PKI se leen de directorios específicos.

Para comunicarse con el demonio IKE, swanctl utiliza el protocolo VICI, la Interfaz de Configuración IKE Versátil. Esta interfaz estable es utilizable por otras herramientas y a menudo es preferible a la automatización de scripts de swanctl y al análisis de su salida.

COMANDOS

-i, --initiate
iniciar una conexión
-t, --terminate
terminar una conexión
-R, --rekey
renovar una SA
-d, --redirect
redirigir una IKE_SA
-p, --install
instalar una política de trampa o desvío
-u, --uninstall
desinstalar una política de trampa o desvío
-l, --list-sas
listar IKE_SAs activas actualmente
-P, --list-pols
listar políticas instaladas actualmente
-b, --load-authorities
cargar (o recargar) información de autoridades de certificación
-L, --list-conns
listar configuraciones cargadas
-B, --list-authorities
listar información de autoridades de certificación cargadas
-x, --list-certs
listar certificados almacenados
-A, --list-pools
listar configuraciones de pool cargadas
-g, --list-algs
listar algoritmos cargados y su implementación
-q, --load-all
cargar (o recargar) credenciales, pools, autoridades y conexiones
-c, --load-conns
cargar (o recargar) configuración de conexión
-s, --load-creds
cargar (o recargar) credenciales
-a, --load-pools
cargar (o recargar) configuración de pool
-T, --log
rastrear la salida de registro (solo niveles 0 y 1)
-S, --stats
mostrar información y estadísticas del demonio
-f, --flush-certs
vaciar certificados en caché
-r, --reload-settings
recargar la configuración de strongswan.conf(5)
-v, --version
mostrar información de la versión del demonio
-h, --help
mostrar información de uso
