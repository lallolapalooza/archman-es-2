NOMBRE

swtpm-localca.conf - Archivo de configuración para swtpm_localca

DESCRIPCIÓN

El archivo /etc/swtpm-localca.conf contiene variables de configuración para el programa swtpm_localca.

Las entradas pueden contener variables de entorno que serán resueltas. Todas las variables de entorno deben tener este formato: '${nombre_variable}'.

Los usuarios pueden escribir su propia configuración en ${XDG_CONFIG_HOME}/swtpm-localca.conf o si XDG_CONFIG_HOME no está establecido, puede estar en ${HOME}/.config/swtpm-localca.conf.

Las siguientes variables de configuración son compatibles:

statedir
El nombre de un directorio donde almacenar datos. Se creará un bloqueo en este directorio.
signinkey
El archivo que contiene la clave utilizada para firmar los certificados. Proporcione una clave en formato PEM o una URI pkcs11.
signingkey_password
La contraseña a utilizar para la clave de firma.
issuercert
El archivo que contiene el certificado para esta CA. Proporcione un certificado en formato PEM.
certserial
El nombre del archivo que contiene el número de serie para el próximo certificado.

El número de serie debe ser un número decimal y debe ser representable con 20 bytes o menos. Una vez que se utilicen 21 bytes, se creará un nuevo número de serie aleatorio con 20 dígitos decimales.

TSS_TCSD_HOSTNAME
Esta variable puede establecerse al host donde se está ejecutando tcsd en caso de que la clave de firma sea una clave GnuTLS TPM 1.2. Por defecto se usará localhost.
TSS_TCSD_PORT
Esta variable puede establecerse al puerto en el que tcsd está escuchando conexiones. Por defecto se usará el puerto 30003.
env:<nombre_variable_de_entorno=<valor>>
Las variables de entorno, que son necesarias para los módulos pkcs11, se pueden establecer utilizando este formato. Un ejemplo de tal variable de entorno podría ser: 
env:MY_MODULE_PKCS11_CONFIG = /tmp/mymodule-pkcs11.conf

La línea no debe contener espacios al final.

EJEMPLO

Un archivo swtpm-localca.conf de ejemplo podría verse así:

statedir = /var/lib/swtpm_localca
signingkey = /var/lib/swtpm_localca/signkey.pem
issuercert = /var/lib/swtpm_localca/issuercert.pem
certserial = /var/lib/swtpm_localca/certserial

Con una URI PKCS11 podría verse así:

statedir = /var/lib/swtpm-localca
signingkey = pkcs11:model=SoftHSM%20v2;manufacturer=SoftHSM%20project;serial=891b99c169e41301;token=mylabel;id=%00;object=mykey;type=public
issuercert = /var/lib/swtpm-localca/swtpm-localca-tpmca-cert.pem
certserial = /var/lib/swtpm-localca/certserial
SWTPM_PKCS11_PIN = 1234
