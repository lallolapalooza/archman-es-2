swww-restore(1) Manual de Comandos Generales swww-restore(1)

NOMBRE

swww-restore

SINOPSIS

swww restore

OPCIONES

-a,--all

Envía este comando a todos los espacios de nombres `swww-daemon` activos.

-n,--namespace <espacio de nombres>

A qué espacio de nombres de Wayland se enviará este comando.

Puede especificar esta opción varias veces para enviar comandos a varios espacios de nombres a la vez: `swww restore -n <espacio de nombres1> -n <espacio de nombres 2>`.

Esto afecta el nombre del socket `swww-daemon` que utilizaremos para comunicarnos. Específicamente, nuestro nombre de socket es ${WAYLAND_DISPLAY}-swww-daemon.<espacio de nombres especificado>.socket.

Algunos compositores pueden tener varios fondos de pantalla por salida. Esto le permite diferenciarlos. La mayoría de los usuarios probablemente no tendrán que configurar nada en esta opción.

-o, --outputs

Lista separada por comas de las salidas a restaurar. Usa swww query para saber qué salidas se están utilizando actualmente.

Si no se establece, se restaurarán todas las salidas.

-h, --help

Imprime la ayuda (ver un resumen con '-h')

DESCRIPCIÓN

Restaura la última imagen mostrada en las salidas especificadas.

Esto se puede utilizar para dividir la inicialización (con `swww init --no-daemon`) y la carga de la caché en diferentes pasos, para evitar trampas de condiciones de carrera.

También puede usar este comando para restaurar la última imagen mostrada al reconectar un monitor.

VER TAMBIÉN

swww-clear-cache(1)
