NOMBRE

swift - Herramienta cliente de OpenStack Swift

SINOPSIS

swift [opciones] <comando> [argumentos]

DESCRIPCIÓN

La herramienta swift es una utilidad de línea de comandos para comunicarse con un entorno de Almacenamiento de Objetos de OpenStack (Swift). Permite realizar varios tipos de operaciones.

COMANDOS

stat [opciones-de-comando] [contenedor] [objeto]

Muestra información para la cuenta, contenedor u objeto, dependiendo de los argumentos proporcionados (si los hay). En modo detallado, también se muestran la URL de almacenamiento y el token de autenticación. La opción --lh informa los tamaños en formato legible por humanos, similar a ls -lh.

list [opciones-de-comando] [contenedor]

Lista los contenedores de la cuenta o los objetos de un contenedor. La opción -p <prefijo> o --prefix <prefijo> solo listará elementos que comiencen con ese prefijo. La opción -d <delimitador> o --delimiter <delimitador> (solo para listados de contenedores) agrupará elementos con el delimitador dado (ver la documentación general de OpenStack Swift para saber qué significa esto).

Las opciones -l o --long y --lh proporcionan más detalles, similares a ls -l y ls -lh, siendo que esta última proporciona tamaños en formato legible por humanos (ej. 3K, 12M, etc.). Estas dos últimas opciones consumen más recursos para obtener esos detalles, lo cual es directamente proporcional al número de contenedores u objetos que se listan. Con la opción -t o --total solo informan los totales.

upload [opciones-de-comando] contenedor archivo_o_directorio [archivo_o_directorio] [...]

Sube al contenedor dado los archivos y directorios especificados por los argumentos restantes. La opción -c o --changed solo subirá archivos que hayan cambiado desde la última subida. La opción --object-name <nombre-objeto> subirá un archivo y nombrará el objeto como <nombre-objeto>, o subirá un directorio y usará <nombre-objeto> como prefijo del objeto. Si el nombre del archivo es "-", lee el contenido de la entrada estándar. En este caso, --object-name es obligatorio y no se pueden proporcionar otros archivos. Las opciones -S <tamaño> o --segment-size <tamaño> y --leave-segments, entre otras, también están disponibles (ver swift upload --help para más información).

post [opciones-de-comando] [contenedor] [objeto]

Actualiza la meta-información de la cuenta, contenedor u objeto, dependiendo de los argumentos proporcionados. Si el contenedor no se encuentra, se creará automáticamente; pero esto no es cierto para cuentas y objetos. Los contenedores también permiten las opciones -r (o --read-acl) y -w (o --write-acl). La opción -m o --meta está permitida en todos y se usa para definir los elementos de metadatos de usuario a establecer en el formato Nombre:Valor. Esta opción se puede repetir. Para más detalles y opciones, ver swift post --help. Ejemplo: post -m Color:Azul -m Tamaño:Grande

copy [opciones-de-comando] contenedor objeto

Copia un objeto a un nuevo destino o agrega metadatos de usuario al objeto (los metadatos de usuario actuales se conservarán, a diferencia del comando post) dependiendo de los argumentos proporcionados. La opción --destination establece el destino en el formato /contenedor/objeto. Si no se establece, el objeto se copiará sobre sí mismo, lo que es útil para agregar metadatos. La opción -M o --fresh-metadata copia el objeto sin los metadatos de usuario existentes. La opción -m o --meta siempre está permitida y se usa para definir los elementos de metadatos de usuario a establecer en el formato Nombre:Valor (esta opción se puede repetir). Para más detalles y opciones, ver swift copy --help.

download [opciones-de-comando] [contenedor] [objeto] [objeto] [...]

Descarga todo en la cuenta (con --all), o todo en un contenedor, o una lista de objetos dependiendo de los argumentos proporcionados. Para la descarga de un solo objeto, puedes usar la opción -o [--output] <nombre-archivo> para redirigir la salida a un archivo específico, o si es "-", redirigirla a stdout, o con --no-download realmente no escribir nada en disco. La opción --ignore-checksum desactiva la validación de suma de verificación. Puedes especificar encabezados opcionales con la opción repetible similar a cURL -H [--header]. Para más detalles y opciones, ver swift download --help. La opción --ignore-mtime ignora la entrada de metadatos x-object-meta-mtime en el objeto (si está presente) y en su lugar crea los archivos descargados con valores de atime y mtime nuevos.

delete [opciones-de-comando] [contenedor] [objeto] [objeto] [...]

Elimina todo en la cuenta (con --all), o todo en un contenedor, o todos los objetos en un contenedor que comiencen con una cadena dada (proporcionada por --prefix), o una lista de objetos dependiendo de los argumentos proporcionados. Los segmentos de objetos manifiestos también se eliminarán, a menos que especifiques la opción --leave-segments. Para más detalles y opciones, ver swift delete --help.

capabilities [opciones-de-comando] [proxy-url]

Muestra las capacidades del clúster. Si no se proporciona la opción proxy-url, se utiliza la URL de almacenamiento recuperada después de la autenticación como proxy-url.

Por defecto, la salida incluye la lista de middlewares de Swift activados así como las opciones relevantes para cada uno. Adicionalmente, el comando muestra las opciones relevantes para el núcleo de Swift.

La opción --json imprimirá una representación JSON de las capacidades del clúster. Esto es típicamente más adecuado para ser consumido por otros programas, como jq.

Ejemplo: capabilities https://swift.example.com
capabilities --json

tempurl [opción-de-comando] método tiempo ruta clave

Genera una URL temporal que permite el acceso no autenticado al objeto de Swift en la ruta dada, utilizando el método HTTP dado, durante el tiempo dado, usando la clave TempURL dada.

El tiempo se puede especificar ya sea como un entero que denota la cantidad de segundos que la URL temporal es válida, o como una marca de tiempo ISO 8601 en uno de los siguientes formatos: Fecha completa: YYYY-MM-DD (ej. 1997-07-16), fecha completa más horas, minutos y segundos: YYYY-MM-DDThh:mm:ss (ej. 1997-07-16T19:20:30) o fecha completa más horas, minutos y segundos con designador UTC: YYYY-MM-DDThh:mm:ssZ (ej. 1997-07-16T19:20:30Z). Ten en cuenta que si no utilizas el último formato, la marca de tiempo se genera usando la zona horaria de tu configuración local. Si se utiliza el primer formato, la parte de la hora utilizada será igual a 00:00:00.

Con la opción --prefix-based se genera una URL basada en prefijo.

La opción --iso8601 proporciona marcas de tiempo ISO 8601 UTC en lugar de marcas de tiempo Unix dentro de la URL generada.

Si se proporciona el argumento opcional --absolute y el argumento de tiempo se especifica en segundos, los segundos se interpretan como una marca de tiempo Unix en la que la URL expirará.

Ejemplo: tempurl GET $(date -d "1 de enero de 2016" +%s) /v1/AUTH_foo/bar_container/quux.md mi_clave_secreta_tempurl --absolute

auth

Muestra las variables de autenticación relacionadas con la autenticación en un formato amigable para el shell. Para ejemplos, ver swift auth --help.

OPCIONES

--version Muestra el número de versión del programa y sale
-h, --help Muestra este mensaje de ayuda (o el de cualquier subcomando si va después del comando) y sale
-s, --snet Usa la red interna SERVICENET
-v, --verbose Imprime más información
-q, --quiet Suprime la salida de estado
-A AUTH, --auth=AUTH URL para obtener un token de autenticación
-U USUARIO, --user=USUARIO Nombre de usuario para obtener un token de autenticación
-V 1|2, --auth-version=VERSIÓN Versión del protocolo de autenticación
-K CLAVE, --key=CLAVE Clave para obtener un token de autenticación
--os-storage-url=URL Usa esto en lugar de la URL devuelta por la autenticación
--os-help Muestra todas las opciones de autenticación de OpenStack
Para más opciones, consulta swift --help y swift --os-help.

EJEMPLO

swift -A https://127.0.0.1:443/auth/v1.0 -U swiftops:swiftops -K swift stat
