SWAPON(8) System Administration SWAPON(8)

NOMBRE

swapon, swapoff - habilitar/deshabilitar dispositivos y archivos para paginación e intercambio

SINOPSIS

swapon [opciones] [archivo_especial...]

swapoff [-va] [archivo_especial...]

DESCRIPCIÓN

swapon se utiliza para especificar dispositivos en los que se realizará la paginación y el intercambio.

El dispositivo o archivo utilizado se indica mediante el parámetro archivo_especial. Puede ser de la forma -L etiqueta o -U uuid para indicar un dispositivo por etiqueta o uuid.

Las llamadas a swapon normalmente ocurren en los scripts de arranque del sistema, haciendo que todos los dispositivos de intercambio estén disponibles, de modo que la actividad de paginación e intercambio se intercale entre varios dispositivos y archivos.

swapoff deshabilita el intercambio en los dispositivos y archivos especificados. Cuando se proporciona la bandera -a, se deshabilita el intercambio en todos los dispositivos y archivos de intercambio conocidos (según se encuentran en /proc/swaps o /etc/fstab).

OPCIONES

-a, --all

Todos los dispositivos marcados como "swap" en /etc/fstab se ponen a disposición, excepto aquellos con la opción "noauto". Los dispositivos que ya se utilizan como intercambio se omiten silenciosamente.

-T, --fstab ruta

Especifica un archivo fstab alternativo para compatibilidad con mount(8). Si ruta es un directorio, entonces los archivos en el directorio se ordenan por strverscmp(3); los archivos que comienzan con "." o sin extensión .fstab se ignoran. La opción se puede especificar más de una vez. Esta opción está diseñada principalmente para scripts de initramfs o chroot donde se especifica una configuración adicional más allá de la configuración estándar del sistema.

-d, --discard[=política]

Habilita los descartes de intercambio, si el dispositivo de respaldo de intercambio soporta la operación de descarte o trim. Esto puede mejorar el rendimiento en algunos Dispositivos de Estado Sólido, pero a menudo no lo hace. La opción permite seleccionar entre dos políticas de descarte de intercambio disponibles:

--discard=once

para realizar una operación de descarte de una sola vez para toda el área de intercambio en swapon; o

--discard=pages

para descartar asincrónicamente las páginas de intercambio liberadas antes de que estén disponibles para su reutilización.

Si no se selecciona ninguna política, el comportamiento predeterminado es habilitar ambos tipos de descarte. Las opciones de montaje de /etc/fstab discard, discard=once o discard=pages también se pueden utilizar para habilitar las banderas de descarte.

-e, --ifexists

Omite silenciosamente los dispositivos que no existen. La opción de montaje nofail de /etc/fstab también se puede utilizar para omitir dispositivos inexistentes.

-f, --fixpgsz

Reinicializa (ejecuta mkswap) el espacio de intercambio si su tamaño de página no coincide con el del kernel en ejecución actual. mkswap(8) inicializa todo el dispositivo y no comprueba los bloques defectuosos.

-L etiqueta

Utiliza la partición que tiene la etiqueta especificada. (Para esto, se necesita acceso a /proc/partitions.)

-o, --options opts

Especifica opciones de intercambio mediante una cadena separada por comas compatible con fstab. Por ejemplo:

swapon -o pri=1,discard=pages,nofail /dev/sda2

La cadena opts se evalúa al final y anula todas las demás opciones de línea de comandos.

-p, --priority prioridad

Especifica la prioridad del dispositivo de intercambio. prioridad es un valor entre 0 y 32767. Los números más altos indican una mayor prioridad. Consulte swapon(2) para una descripción completa de las prioridades de intercambio. Añada pri=valor al campo de opciones de /etc/fstab para usar con swapon -a. Cuando no se define ninguna prioridad, el kernel de Linux utiliza valores negativos por defecto.

-s, --summary

Muestra un resumen del uso de intercambio por dispositivo. Equivalente a cat /proc/swaps. Este formato de salida está OBSOLETO en favor de --show, que proporciona un mejor control sobre los datos de salida.

--show[=columna...]

Muestra una tabla definible de áreas de intercambio. Consulte la salida de --help para obtener una lista de columnas disponibles.

--output-all

Muestra todas las columnas disponibles.

--noheadings

No imprime encabezados al mostrar la salida de --show.

--raw

Muestra la salida de --show sin alinear las columnas de la tabla.

--bytes

Muestra el tamaño del intercambio en bytes en la salida de --show en lugar de en unidades amigables para el usuario.

-U uuid

Utiliza la partición que tiene el uuid especificado.

-v, --verbose

Sea verboso.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

ESTADO DE SALIDA

swapoff tiene los siguientes valores de estado de salida desde v2.36:

0

éxito

2

el sistema tiene memoria insuficiente para detener el intercambio (OOM)

4

la llamada al sistema swapoff(2) falló por otro motivo

8

error del sistema no relacionado con la llamada swapoff(2) (sin memoria, ...)

16

error de uso o sintaxis

32

todos los swapoff fallaron en --all

64

algunos swapoff tuvieron éxito en --all

El comando swapoff --all devuelve 0 (todos tuvieron éxito), 32 (todos fallaron) o 64 (algunos fallaron, algunos tuvieron éxito).

+ Las versiones anteriores a v2.36 no tienen estado de salida documentado, 0 significa éxito en todas las versiones.

NOTAS

Archivos con agujeros

La implementación del archivo de intercambio en el kernel espera poder escribir directamente en el archivo, sin la ayuda del sistema de archivos. Esto es un problema en archivos con agujeros o en archivos copy-on-write en sistemas de archivos como Btrfs.

Comandos como cp(1) o truncate(1) crean archivos con agujeros. Estos archivos serán rechazados por swapon.

Los archivos preasignados creados por fallocate(1) pueden interpretarse como archivos con agujeros también dependiendo del sistema de archivos. Los archivos de intercambio preasignados son compatibles con XFS desde Linux 4.18.

La solución más portátil para crear un archivo de intercambio es usar dd(1) y /dev/zero.

Btrfs

Los archivos de intercambio en Btrfs son compatibles desde Linux 5.0 en archivos con el atributo nocow. Consulte la página del manual de btrfs(5) para más detalles.

Desde la versión 2.41, el comando mkswap --file puede crear un nuevo archivo de intercambio con el atributo nocow.

NFS

El intercambio sobre NFS puede no funcionar.

Suspensión

Se recomienda encarecidamente no utilizar un archivo o partición de intercambio para suspender en sistemas con un solo dispositivo de intercambio. Si la suspensión se completa correctamente, el dispositivo de intercambio puede no estar disponible después de reanudar. Se recomienda encarecidamente no utilizar dispositivos de intercambio de archivos para la suspensión.

NOTES

swapon detecta y reescribe automáticamente una firma de espacio de intercambio con datos de suspensión de software antiguos (por ejemplo, S1SUSPEND, S2SUSPEND, ...). El problema es que si no lo hacemos, obtenemos corrupción de datos la próxima vez que se intente una suspensión inversa.

HISTORIA

El comando swapon apareció en 4.0BSD.
