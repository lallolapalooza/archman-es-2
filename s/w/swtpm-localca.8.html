NOMBRE

swtpm_localca - CA local para crear certificados EK y de plataforma para swtpm

SINOPSIS

swtpm_localca [OPCIONES]

DESCRIPCIÓN

swtpm_localca es una herramienta para crear claves de respaldo (EK) y certificados de plataforma en el host. Utiliza el programa swtpm_cert para crear los certificados.

El programa normalmente será invocado por el programa swtpm_setup que utiliza el archivo de configuración /etc/swtpm_setup.conf donde se debe establecer una variable que apunte a este programa. Implementa opciones de línea de comandos que el programa swtpm_setup utiliza para proporcionarle los parámetros necesarios.

swtpm_localca intentará automáticamente crear la clave de firma y el certificado si la configuración apunta a una clave de firma faltante. Dado que este certificado debe ser firmado por una CA, también se creará una autoridad de certificación raíz que firmará este certificado. La clave privada y el certificado de la CA raíz estarán ubicados en el mismo directorio que la clave de firma y tendrán los nombres swtpm-localca-rootca-privkey.pem y swtpm-localca-rootca-cert.pem respectivamente. La variable de entorno SWTPM_ROOTCA_PASSWORD puede ser establecida para la contraseña de la clave privada de la CA raíz.

Nota: Debido a las limitaciones de 'certtool', las contraseñas posibles utilizadas para proteger la clave privada de la CA raíz y la clave privada de la CA intermedia tienen que pasarse a través de la línea de comandos y, por lo tanto, serán visibles para otros en el sistema. Si está preocupado por esto, debería crear las CA en otro lugar y copiarlas al sistema de destino.

Se soportan las siguientes opciones:

--type tipo
Este parámetro indica el tipo de certificado a crear. El parámetro de tipo puede ser uno de los siguientes: ek, o platform
--dir dir
Este parámetro indica el directorio en el cual se debe almacenar el certificado. El certificado EK se almacena en este directorio bajo el nombre ek.cert y el certificado de plataforma bajo el nombre platform.cert.
--ek ek o --key clave
Este parámetro indica el módulo de la clave pública de la clave de respaldo (EK). La clave pública se proporciona como una secuencia de dígitos hexadecimales ASCII.

La opción --key es un alias para --ek y debe usarse si se pasan parámetros de clave para otra clave que no sea una clave de respaldo.

En caso de que se utilicen claves ECC (criptografía de curva elíptica), el parámetro debe tener el formato --ek x=<dígitos hexadecimales>,y=<dígitos hexadecimales>,id=<id de curva>. La parte id=<id de curva> es opcional y solo es necesaria para curvas ECC distintas de secp256r1.

--vmid ID
Este parámetro indica el ID de la VM para la cual se debe crear el certificado.
--logfile <archivo de registro>
El archivo de registro al que registrar la salida; por defecto, el registro va a stdout y stderr en la consola.
--configfile <archivo de configuración>
El archivo de configuración a utilizar. Si se omite, se utilizará el archivo de configuración por defecto /etc/swtpm-localca.conf.
--optsfile <archivo de opciones>
El archivo de opciones a utilizar. Si se omite, se utilizará el archivo de opciones por defecto /etc/swtpm-localca.options.
--tpm-spec-family, --tpm-spec-revision, --tpm-spec-level
Parámetros de la familia, revisión y nivel de especificación del TPM que describen la especificación que se siguió para la implementación del TPM. Los parámetros se pasarán a swtpm_cert para la creación del certificado EK.
--tpm2
Crear certificados compatibles con TPM 2.
--allow-signing
Crear un EK que también pueda ser utilizado para firmar. Sin esta opción, el EK solo puede ser utilizado para cifrado de claves. Esta opción requiere --tpm2.
--decryption
Si se pasa --allow-signing y el EK también debe ser utilizable para el cifrado de claves, se debe pasar esta opción. De lo contrario, el cifrado de claves es el predeterminado. Esta opción requiere --tpm2.
