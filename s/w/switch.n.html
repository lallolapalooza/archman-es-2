Paquete: tcl

Licencias: TCL

switch(n) Comandos integrados de Tcl switch(n)

NOMBRE

switch - Evalúa uno de varios scripts, dependiendo de un valor dado

SINOPSIS

switch ?opciones? cadena patrón cuerpo ?patrón cuerpo ...?

switch ?opciones? cadena {patrón cuerpo ?patrón cuerpo ...?}

DESCRIPCIÓN

El comando switch compara su argumento cadena con cada uno de los argumentos patrón en orden. Tan pronto como encuentra un patrón que coincide con cadena, evalúa el argumento cuerpo siguiente pasándolo recursivamente al intérprete Tcl y devuelve el resultado de esa evaluación. Si el último argumento patrón es default, entonces coincide con cualquier cosa. Si ningún argumento patrón coincide con cadena y no se proporciona un valor por defecto, el comando switch devuelve una cadena vacía.

Si los argumentos iniciales de switch comienzan con - entonces se tratan como opciones, a menos que haya exactamente dos argumentos para switch (en cuyo caso el primero debe ser la cadena y el segundo debe ser la lista patrón/cuerpo). Las siguientes opciones son compatibles actualmente:

-exacto
Usa coincidencia exacta al comparar cadena con un patrón. Este es el valor predeterminado.
-glob
Al comparar cadena con los patrones, usa coincidencia de estilo glob (es decir, la misma que implementa el comando string match).
-regexp
Al comparar cadena con los patrones, usa coincidencia de expresiones regulares (como se describe en la página de referencia re_syntax).
-nocase
Hace que las comparaciones se manejen de forma insensible a mayúsculas y minúsculas.
-matchvar nombreVar
Esta opción (solo legal cuando -regexp también está especificado) especifica el nombre de una variable en la que se escribirá la lista de coincidencias encontradas por el motor de expresiones regulares. El primer elemento de la lista escrita será la subcadena general de la cadena de entrada (es decir, el argumento cadena de switch) que coincide, el segundo elemento de la lista será la subcadena coincidente con el primer grupo de captura en la expresión regular que coincide, y así sucesivamente. Cuando se toma una rama default, la variable tendrá la lista vacía escrita en ella. Esta opción puede especificarse al mismo tiempo que la opción -indexvar.
-indexvar nombreVar
Esta opción (solo legal cuando -regexp también está especificado) especifica el nombre de una variable en la que se escribirá la lista de índices que se refieren a subcadenas coincidentes encontradas por el motor de expresiones regulares. El primer elemento de la lista escrita será una lista de dos elementos que especifica el índice de inicio y el índice del primer carácter después del final de la subcadena general de la cadena de entrada (es decir, el argumento cadena de switch) que coincide, de manera similar a la opción -indices del comando regexp. De manera similar, el segundo elemento de la lista se refiere al primer grupo de captura en la expresión regular que coincide, y así sucesivamente. Cuando se toma una rama default, la variable tendrá la lista vacía escrita en ella. Esta opción puede especificarse al mismo tiempo que la opción -matchvar.
--
Marca el final de las opciones. El argumento que sigue a este se tratará como cadena incluso si comienza con un -. Esto no es necesario cuando los patrones de coincidencia y los cuerpos se agrupan en un solo argumento.

Se proporcionan dos sintaxis para los argumentos patrón y cuerpo. La primera usa un argumento separado para cada uno de los patrones y comandos; esta forma es conveniente si se desean sustituciones en algunos de los patrones o comandos. La segunda forma agrupa todos los patrones y comandos en un solo argumento; el argumento debe tener una estructura de lista adecuada, con los elementos de la lista siendo los patrones y comandos. La segunda forma facilita la construcción de comandos switch de varias líneas, ya que las llaves alrededor de toda la lista hacen innecesario incluir una barra invertida al final de cada línea. Dado que los argumentos patrón están entre llaves en la segunda forma, no se les realizan sustituciones de comandos o variables; esto hace que el comportamiento de la segunda forma sea diferente a la primera en algunos casos.

Si un cuerpo se especifica como “-” significa que el cuerpo del siguiente patrón también debe usarse como el cuerpo para este patrón (si el siguiente patrón también tiene un cuerpo de “-”, entonces se usa el cuerpo posterior, y así sucesivamente). Esta característica hace posible compartir un solo cuerpo entre varios patrones.

Tenga cuidado con la colocación de comentarios en los comandos switch. Los comentarios solo deben colocarse dentro del cuerpo de ejecución de uno de los patrones, y no mezclados con los patrones.

EJEMPLOS

El comando switch puede coincidir con variables y no solo con literales, como se muestra aquí (el resultado es 2):

set foo "abc"
switch abc a - b {expr {1}} $foo {expr {2}} default {expr {3}}

Usar coincidencia glob y el cuerpo de "caída" es una alternativa a escribir expresiones regulares con alternancias, como se puede ver aquí (esto devuelve 1):

switch -glob aaab {
    a*b     -
    b       {expr {1}}
    a*      {expr {2}}
    default {expr {3}}
}

Cuando nada coincide, se toma la cláusula default (que debe ser la última). Este ejemplo tiene un resultado de 3:

switch xyz {
    a -
    b {
        # Colocación correcta del comentario
        expr {1}
    }
    c {
        expr {2}
    }
    default {
        expr {3}
    }
}

Al coincidir con expresiones regulares, la información sobre lo que exactamente coincidió se obtiene fácilmente utilizando la opción -matchvar:

switch -regexp -matchvar foo -- $bar {
    a(b*)c {
        puts "Encontrado [string length [lindex $foo 1]] 'b's"
    }
    d(e*)f(g*)h {
        puts "Encontrado [string length [lindex $foo 1]] 'e's y\
                [string length [lindex $foo 2]] 'g's"
    }
}
