NOMBRE

swtpm_bios - herramienta de simulación de BIOS para swtpm

SINOPSIS

swtpm_bios [OPCIONES]

DESCRIPCIÓN

swtpm_bios es una herramienta que puede enviar comandos al TPM (programa swtpm) que normalmente usa la BIOS para inicializar el TPM. El usuario puede elegir entre varias opciones de línea de comandos para seleccionar el estado al que se debe configurar el TPM.

Este comando requiere que la variable de entorno TCSD_USE_TCP_DEVICE esté configurada para la comunicación a través de TCP. De lo contrario, utilizará el dispositivo establecido en la variable de entorno TPM_DEVICE o recurrirá a usar /dev/tpm0 para enviar los comandos. En modo TCP, la variable de entorno TCSD_TCP_DEVICE_HOSTNAME se utiliza para indicar el host al que se enviarán los comandos. Por defecto se asume localhost. El puerto TCP predeterminado es 6545 a menos que la variable de entorno TCSD_TCP_DEVICE_PORT indique otro puerto.

En caso de éxito se devolverá 0. En caso de encontrar un error en el TPM, el código de retorno será 128. En caso de fallo de comunicación se devolverá 255. En caso de que el TPM necesite ser reiniciado para activarse, se devolverá 129.

Este comando enviará la siguiente secuencia de comandos al TPM:

TPM_Startup(modo elegido) -- iniciar TPM
TSC_PhysicalPresence(0x20) -- Habilitar CMD de Presencia Física
TSC_PhysicalPresence(0x08) -- activar presencia física
TPM_GetCapability -- obtener banderas permanentes
TPM_PhysicalEnable -- habilitar el TPM
TPM_PhysicalSetDeactivated(0x0) -- activar TPM
TPM_ContinueSelfTest -- continuar autoevaluación
TSC_PhysicalPresence(0x20) -- Habilitar CMD de Presencia Física
TSC_PhysicalPresence(0x14) -- desactivar presencia física y bloquearla

Las siguientes opciones son compatibles:

--tpm-device <dispositivo>
Usar el dispositivo dado en lugar del predeterminado /dev/tpm0. Esta opción anula la variable de entorno TPM_DEVICE.
--tcp <servidor>:<puerto>
Conectarse al servidor y puerto dados; si no se proporciona servidor, se utiliza 127.0.0.1; si no se proporciona puerto, se utiliza el puerto predeterminado 6545.
--unix <ruta>
Conectarse a la ruta UnixIO dada.
-tpm2
El dispositivo es un TPM 2.
-c
Enviar TPM_Startup(ST_CLEAR) (predeterminado). Esto instruye al TPM para que inicie con estado limpio.
-s
Enviar TPM_Startup(ST_STATE). Esto instruye al TPM para que inicie restaurando el estado previamente guardado.
-d
Enviar TPM_Startup(ST_DEACTIVATED). Esto instruye al TPM para que inicie en modo desactivado. Esta opción no tiene efecto en un TPM 2.
-n
No enviar un comando TPM_Startup.
-o
Solo enviar el comando de inicio y nada más.
-ea
Asegurarse de que el TPM esté activado; si el TPM requiere un reinicio, el programa saldrá y devolverá un código de retorno de 129.
-cs
Enviar un comando TPM_ContinueSelfTest a un TPM 1.2 y un comando TPM2_IncrementalSelfTest a un TPM 2.
-u
Renunciar a la presencia física en un TPM 1.2. En el caso de un TPM 2, establecer la jerarquía de plataforma con una contraseña aleatoria.
-v
Mostrar la versión y salir.
-h
Mostrar la pantalla de ayuda y salir.
