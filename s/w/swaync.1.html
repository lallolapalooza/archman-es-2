swaync(1) Manual de Comandos Generales swaync(1)

NOMBRE

swaync - Un demonio de notificación simple con una GUI GTK para notificaciones y el centro de control

USO

swaync [opción]

OPCIONES

-h, --help

Muestra las opciones de ayuda

-v, --version

Imprime la versión

-s, --style <archivo CSS>

Usa un archivo de Hoja de Estilos personalizado

--skip-system-css

Omite el intento de analizar el archivo de Hoja de Estilos empaquetado. Útil para depuración de CSS

-c, --config <archivo de configuración>

Usa un archivo de configuración personalizado

Atajos de teclado del Centro de Control

Arriba/Abajo: Navegar por las notificaciones

Inicio: Navegar a la notificación más reciente

Fin: Navegar a la notificación más antigua

Escape/Bloq Mayús: Cerrar el panel de notificaciones

Intro: Ejecutar acción predeterminada o cerrar notificación si no hay ninguna

Supr/Retroceso: Cerrar notificación

Mayús+C: Cerrar todas las notificaciones

Mayús+D: Activar/Desactivar No Molestar

Teclas 1-9: Ejecutar acciones alternativas

Botón izquierdo del ratón / acciones: Activar acción de notificación

Clic central/derecho en notificación: Cerrar notificación

CONFIGURACIÓN

El archivo de configuración principal se encuentra en /etc/xdg/swaync/config.json. Cópialo a tu carpeta ~/.config/swaync/ para personalizarlo sin necesidad de acceso root.

Para recargar la configuración, necesitarás ejecutar swaync-client --reload-config

Para obtener información sobre el formato del archivo de configuración, consulta swaync(5)

Scripting

Reglas y lógica de scripting:

1.
Solo un script puede ejecutarse por notificación
2.
Cada script requiere `exec` y al menos una de las otras propiedades
3.
Todas las propiedades listadas deben coincidir con la notificación para que el script se ejecute
4.
Si alguna de las propiedades no coincide, el script se omitirá
5.
Si una notificación no incluye una de las propiedades, esa propiedad se omitirá

La información de la notificación se puede imprimir en una terminal ejecutando G_MESSAGES_DEBUG=all swaync (cuando aparece una notificación).

Propiedades de configuración:

{
	"scripts": {
		"ejemplo-script": {
			"exec": "Tu comando de shell o script aquí...",
			"app-name": "Regex del nombre de la app de la notificación",
			"summary": "Regex del resumen de la notificación",
			"body": "Regex del cuerpo de la notificación",
			"urgency": "Baja o Normal o Crítica",
			"category": "Regex de la categoría de la notificación"
		}
	}
	otras propiedades no de scripting...
}

Ejemplo de config.json:

{
	"scripts": {
		// Este script solo se ejecutará cuando Spotify envíe una notificación que contenga
		// ese resumen y cuerpo exactos
		"ejemplo-script": {
			"exec": "~/.config/swaync/miScriptRickRoll.sh",
			"app-name": "Spotify"
			"summary": "Never Gonna Give You Up",
			"body": "Rick Astley - Whenever You Need Somebody"
		}
	}
	otras propiedades no de scripting...
}

Desactivar scripting

Para desactivar completamente el scripting, el proyecto debe compilarse de la siguiente manera:

meson build -Dscripting=false
ninja -C build
meson install -C build

Ejemplo de Waybar

Este ejemplo requiere NotoSansMono Nerd Font para que los iconos se vean correctamente

Configuración de Waybar

"custom/notification": {
	"tooltip": false,
	"format": "{icon}",
	"format-icons": {
		"notification": "<span foreground='red'><sup></sup></span>",
		"none": "",
		"dnd-notification": "<span foreground='red'><sup></sup></span>",
		"dnd-none": "",
		"inhibited-notification": "<span foreground='red'><sup></sup></span>",
		"inhibited-none": "",
		"dnd-inhibited-notification": "<span foreground='red'><sup></sup></span>",
		"dnd-inhibited-none": ""
	},
	"return-type": "json",
	"exec-if": "which swaync-client",
	"exec": "swaync-client -swb",
	"on-click": "swaync-client -t -sw",
	"on-click-right": "swaync-client -d -sw",
	"escape": true
},

Archivo CSS de Waybar

#custom-notification {
	font-family: "NotoSansMono Nerd Font";
}
