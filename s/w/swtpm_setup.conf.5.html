NOMBRE

swtpm_setup.conf - Archivo de configuración para swtpm_setup

DESCRIPCIÓN

El archivo /etc/swtpm_setup.conf contiene información de configuración para swtpm_setup. Debe contener solo una palabra clave de configuración por línea, seguida de un signo igual (=) y luego la información de configuración apropiada. Un comentario al final de la línea puede ser introducido por un signo de almohadilla (#).

Los usuarios pueden escribir su propia configuración en ${XDG_CONFIG_HOME}/swtpm_setup.conf o, si XDG_CONFIG_HOME no está configurado, puede estar en ${HOME}/.config/swtpm_setup.conf.

Las siguientes palabras clave son reconocidas:

create_certs_tool
Esta palabra clave debe ir seguida del nombre de un ejecutable o script ejecutable utilizado para crear varios certificados TPM. La herramienta se llamará con las siguientes opciones
--type tipo
Este parámetro indica el tipo de certificado a crear. El parámetro tipo puede ser uno de los siguientes: ek o platform.
--dir dir
Este parámetro indica el directorio en el que se debe almacenar el certificado. Se espera que el certificado EK se almacene en este directorio bajo el nombre ek.cert y el certificado de plataforma bajo el nombre platform.cert.
--ek ek
Este parámetro indica el módulo de la clave pública de la clave de respaldo (EK). La clave pública se proporciona como una secuencia de dígitos hexadecimales ASCII.
--vmid ID
Este parámetro indica el ID de la VM para la que se creará el certificado.
--logfile <archivo de registro>
El archivo de registro al que se enviará la salida; por defecto, el registro va a stdout y stderr en la consola.
--configfile <archivo de configuración>
El archivo de configuración a usar. Este archivo típicamente contiene información de configuración para el programa invocado. Si se omite, el programa debe usar su archivo de configuración predeterminado.
--optsfile <archivo de opciones>
El archivo de opciones a usar. Este archivo típicamente contiene opciones que utiliza el programa invocado. Si se omite, el programa debe usar su archivo de opciones predeterminado.
--tpm-spec-family <familia>, --tpm-spec-level <nivel>, --tpm-spec-revision <revisión>
Estas 3 opciones describen la especificación TPM que se siguió para la implementación del TPM y formarán parte del certificado EK.
--tpm2
Esta opción se pasa en caso de que se deba crear un certificado compatible con TPM 2.
create_certs_tool_config
Esta palabra clave debe ir seguida del nombre de un archivo de configuración que se pasará al programa invocado mediante la opción --configfile descrita anteriormente. Si se omite, el programa invocado utilizará el archivo de configuración predeterminado.
create_certs_tool_options
Esta palabra clave debe ir seguida del nombre de un archivo de opciones que se pasará al programa invocado mediante la opción --optsfile descrita anteriormente. Si se omite, el programa invocado utilizará el archivo de opciones predeterminado.
active_pcr_banks (desde v0.7)
Esta palabra clave debe ir seguida de una lista separada por comas de nombres de bancos PCR. La lista no debe contener espacios. Los nombres de bancos PCR válidos son sha1, sha256, sha384 y sha512.
rsa_keysize (desde v0.10)
Esta palabra clave permite especificar el tamaño de clave RSA predeterminado a utilizar si no se proporciona con una opción de línea de comandos para swtpm_setup. Cualquier valor que se pueda pasar a swtpm_setup también es válido aquí, como 2048 o 'max'. Los tamaños de clave admitidos dependen de la versión de libtpms.
profile (desde v0.10)
Esta palabra clave permite especificar el nombre de un perfil o un mapa JSON que describe el perfil, como 'profile = {"Name": "default-v1"}'. Consulte también la descripción de la opción --profile para swtpm_setup.
profile_file (desde v0.10)
Esta palabra clave permite especificar un archivo de perfil predeterminado.
local_profiles_dir (desde v0.10)
Esta palabra clave permite establecer un directorio de perfiles que contenga perfiles escritos por usuarios del sistema.
