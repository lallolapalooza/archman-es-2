sway(1) Manual de Comandos Generales sway(1)

NOMBRE

sway - Compositor de Wayland compatible con i3

SINOPSIS

sway [opciones...] [comando]

OPCIONES

-h, --help

Muestra el mensaje de ayuda y sale.

-c, --config <config>

Especifica un archivo de configuración.

-C, --validate

Comprueba la validez del archivo de configuración y sale.

-d, --debug

Habilita el registro completo, incluida la información de depuración.

-v, --version

Muestra el número de versión y sale.

-V, --verbose

Habilita un registro más detallado.

--get-socketpath

Obtiene la ruta del socket IPC y la imprime, luego sale.

DESCRIPCIÓN

sway se creó para satisfacer la necesidad de un gestor de ventanas tipo i3 para Wayland. Los desarrolladores de i3 de upstream no tienen intención de portar i3 a Wayland, y los proyectos propuestos por otros terminaron siendo vaporware. Muchas gracias a la gente de i3 por proporcionar un software tan genial, tan bueno que sus usuarios prefieren escribir un gestor de ventanas completamente nuevo desde cero que se comportara *exactamente* como i3 en lugar de cambiar a otra cosa.

Puedes ejecutar sway directamente desde una tty, o a través de un gestor de inicio de sesión compatible con Wayland.

CONFIGURACIÓN

sway busca un archivo de configuración en las siguientes ubicaciones, en este orden:

1.
~/.sway/config
2.
$XDG_CONFIG_HOME/sway/config (ubicación sugerida)
3.
~/.i3/config
4.
$XDG_CONFIG_HOME/i3/config
5.
/etc/sway/config
6.
/etc/i3/config

Si no está definida, $XDG_CONFIG_HOME se establece por defecto en ~/.config.

Se genera un error cuando no se encuentra ningún archivo de configuración. La configuración predeterminada recomendada suele estar instalada en /etc/sway/config; te animamos a copiarla a ~/.config/sway/config y editarla a partir de ahí.

Para obtener información sobre el formato del archivo de configuración, consulta sway(5).

COMANDOS IPC

Aunque generalmente se prefiere swaymsg(1), puedes ejecutar sway comando para enviar comando a la instancia en ejecución de sway. También puedes emitir comandos con i3-msg(1) o incluso con i3(1).

ENTORNO

Las siguientes variables de entorno tienen un efecto en sway:

SWAYSOCK

Especifica la ruta al socket IPC de sway.

XKB_DEFAULT_RULES, XKB_DEFAULT_MODEL, XKB_DEFAULT_LAYOUT, XKB_DEFAULT_VARIANT, XKB_DEFAULT_OPTIONS

Configura los ajustes del teclado xkb. Consulta xkeyboard-config(7). La forma preferida de configurar el teclado es a través del archivo de configuración, consulta sway-input(5).

Las siguientes variables de entorno son establecidas por sway:

DISPLAY

Si se compila con soporte para Xwayland y Xwayland no está deshabilitado por la configuración, se establecerá en el nombre de la pantalla X utilizada para Xwayland.

I3SOCK

Para compatibilidad con i3, especifica la ruta al socket IPC de sway.

SWAYSOCK

Especifica la ruta al socket IPC de sway.

WAYLAND_DISPLAY

Especifica el nombre de la pantalla Wayland en la que se está ejecutando sway.

XCURSOR_SIZE

Especifica el tamaño del cursor configurado.

XCURSOR_THEME

Especifica el tema del cursor configurado.
