NOMBRE

swaybg - Fondo de pantalla para Wayland

SINOPSIS

swaybg [opciones...]

Muestra una imagen de fondo en todas las salidas de tu sesión Wayland.

Sin una salida especificada, las opciones de apariencia se aplican a todas las salidas. Las opciones de apariencia por salida se pueden establecer pasando -o, --output seguido de estas opciones.

OPCIONES

-c, --color <[#]rrggbb>

Establece el color de fondo.

-h, --help

Muestra el mensaje de ayuda y sale.

-i, --image <ruta>

Establece la imagen de fondo.

-m, --mode <modo>

Modo de escalado para imágenes: stretch, fill, fit, center o tile. Utiliza el modo adicional solid_color para mostrar solo el color de fondo, incluso si se especifica una imagen de fondo.

-o, --output <nombre>

Selecciona una salida para configurar. Las opciones de apariencia posteriores solo se aplicarán a esta salida. El valor especial * selecciona todas las salidas.

-v, --version

Muestra el número de versión y sale.
