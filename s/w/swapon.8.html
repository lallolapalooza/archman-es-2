SWAPON(8) Administración del Sistema SWAPON(8)

NOMBRE

swapon, swapoff - habilitar/deshabilitar dispositivos y archivos para paginación e intercambio

SINOPSIS

swapon [opciones] [archivoespecial...]

swapoff [-va] [archivoespecial...]

DESCRIPCIÓN

swapon se utiliza para especificar dispositivos en los que se debe realizar la paginación y el intercambio.

El dispositivo o archivo utilizado se indica mediante el parámetro archivoespecial. Puede tener el formato -L etiqueta o -U uuid para indicar un dispositivo por etiqueta o uuid.

Las llamadas a swapon normalmente ocurren en los scripts de arranque del sistema, haciendo que todos los dispositivos de intercambio estén disponibles, de modo que la actividad de paginación e intercambio se intercale entre varios dispositivos y archivos.

swapoff deshabilita el intercambio en los dispositivos y archivos especificados. Cuando se proporciona la bandera -a, el intercambio se deshabilita en todos los dispositivos y archivos de intercambio conocidos (tal como se encuentran en /proc/swaps o /etc/fstab).

OPCIONES

-a, --all

Se ponen a disposición todos los dispositivos marcados como "swap" en /etc/fstab, excepto aquellos con la opción "noauto". Los dispositivos que ya se utilizan como swap se omiten silenciosamente.

-T, --fstab ruta

Especifica un archivo fstab alternativo para compatibilidad con mount(8). Si ruta es un directorio, entonces los archivos del directorio se ordenan por strverscmp(3); los archivos que comienzan con "." o sin una extensión .fstab se ignoran. La opción se puede especificar más de una vez. Esta opción está diseñada principalmente para scripts initramfs o chroot donde se especifican configuraciones adicionales más allá de la configuración estándar del sistema.

-d, --discard[=política]

Habilita los descartes de swap, si el dispositivo de respaldo de swap admite la operación de descarte o recorte (trim). Esto puede mejorar el rendimiento en algunos dispositivos de estado sólido, pero a menudo no lo hace. La opción permite seleccionar entre dos políticas de descarte de swap disponibles:

--discard=once

para realizar una operación de descarte de una sola vez para toda el área de swap en swapon; o

--discard=pages

para descartar asíncronamente las páginas de swap liberadas antes de que estén disponibles para su reutilización.

Si no se selecciona ninguna política, el comportamiento predeterminado es habilitar ambos tipos de descarte. Las opciones de montaje de /etc/fstab discard, discard=once o discard=pages también se pueden usar para habilitar las banderas de descarte.

-e, --ifexists

Omite silenciosamente los dispositivos que no existen. La opción de montaje nofail de /etc/fstab también se puede usar para omitir dispositivos no existentes.

-f, --fixpgsz

Reinicializa (ejecuta mkswap) el espacio de swap si su tamaño de página no coincide con el del kernel en ejecución actual. mkswap(8) inicializa todo el dispositivo y no comprueba los bloques defectuosos.

-L etiqueta

Utiliza la partición que tiene la etiqueta especificada. (Para esto, se necesita acceso a /proc/partitions.)

-o, --options opts

Especifica las opciones de swap mediante una cadena separada por comas compatible con fstab. Por ejemplo:

swapon -o pri=1,discard=pages,nofail /dev/sda2

La cadena opts se evalúa al final y anula todas las demás opciones de la línea de comandos.

-p, --priority prioridad

Especifica la prioridad del dispositivo de swap. prioridad es un valor entre 0 y 32767. Los números más altos indican mayor prioridad. Consulte swapon(2) para obtener una descripción completa de las prioridades de swap. Agregue pri=valor al campo de opciones de /etc/fstab para usarlo con swapon -a. Cuando no se define ninguna prioridad, los valores predeterminados del kernel de Linux son números negativos.

-s, --summary

Muestra un resumen del uso de swap por dispositivo. Equivalente a cat /proc/swaps. Este formato de salida está OBSOLETO en favor de --show, que proporciona un mejor control sobre los datos de salida.

--show[=columna...]

Muestra una tabla definible de áreas de swap. Consulte la salida de --help para obtener una lista de las columnas disponibles.

--output-all

Muestra todas las columnas disponibles.

--noheadings

No imprime encabezados al mostrar la salida de --show.

--raw

Muestra la salida de --show sin alinear las columnas de la tabla.

--bytes

Muestra el tamaño del swap en bytes en la salida de --show en lugar de en unidades fáciles de usar.

-U uuid

Utiliza la partición que tiene el uuid especificado.

-v, --verbose

Sea detallado.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

ESTADO DE SALIDA

swapoff tiene los siguientes valores de estado de salida desde v2.36:

0

éxito

2

el sistema tiene memoria insuficiente para detener el intercambio (OOM)

4

la llamada al sistema swapoff(2) falló por otra razón

8

error del sistema no relacionado con la llamada al sistema swapoff(2) (falta de memoria, ...)

16

error de uso o sintaxis

32

todos los swapoff fallaron en --all

64

algunos swapoff tuvieron éxito en --all

+ El comando swapoff --all devuelve 0 (todos tuvieron éxito), 32 (todos fallaron) o 64 (algunos fallaron, algunos tuvieron éxito).

+ Las versiones antiguas anteriores a v2.36 no tienen un estado de salida documentado; 0 significa éxito en todas las versiones.

NOTAS

Archivos con agujeros

La implementación del archivo de intercambio en el kernel espera poder escribir directamente en el archivo, sin la ayuda del sistema de archivos. Este es un problema en archivos con agujeros o en archivos de copia en escritura (copy-on-write) en sistemas de archivos como Btrfs.

Comandos como cp(1) o truncate(1) crean archivos con agujeros. Estos archivos serán rechazados por swapon.

Los archivos preasignados creados por fallocate(1) también pueden ser interpretados como archivos con agujeros dependiendo del sistema de archivos. Los archivos de intercambio preasignados son compatibles con XFS desde Linux 4.18.

La solución más portátil para crear un archivo de intercambio es usar dd(1) y /dev/zero.

Btrfs

Los archivos de intercambio en Btrfs son compatibles desde Linux 5.0 en archivos con el atributo nocow. Consulte la página del manual de btrfs(5) para obtener más detalles.

NAME

swapon, swapoff - habilitar/deshabilitar dispositivos de intercambio

SYNOPSIS

swapon [-a] [-R] [-s] [-d] [-f] [-p] [-v] [-t type] [device...]
swapoff [-a] [-R] [-v] [device...]
swapon [-h | -V]

DESCRIPTION

swapon y swapoff se utilizan para habilitar y deshabilitar dispositivos de intercambio (archivos o particiones de intercambio) para el paginamiento de memoria virtual. El kernel de Linux mantiene el recuento de cuántas páginas de intercambio están en uso. El administrador del sistema es responsable de crear el área de intercambio (por ejemplo, con mkswap(8)) y usar swapon para empezar a usarla.

Si no se especifican argumentos, swapon habilita todas las áreas de intercambio que se enumeran en el archivo fstab(5) y que no estén marcadas con la opción noauto. swapoff, si no se le dan argumentos, deshabilita todas las áreas de intercambio.

La opción -a hace que swapon y swapoff habiliten o deshabiliten todas las áreas de intercambio que se enumeran en fstab(5). Esto es útil para que las áreas de intercambio se establezcan al arrancar el sistema, por ejemplo, desde el script de inicialización del sistema.

La opción -R permite la relectura de la tabla de particiones GPT (GUID Partition Table) antes de procesar las opciones.

La opción -s hace que swapon y swapoff muestren un resumen conciso del espacio de intercambio total, utilizado y libre. La salida tiene el formato:

Filename				Type		Size		Used		Priority

La opción -d hace que swapon deshabilite el dispositivo de intercambio especificado.

La opción -f hace que swapon desactive la detección de firmas del dispositivo de intercambio y use el dispositivo tal cual. Esto puede ser útil si la firma del dispositivo de intercambio se ha dañado.

La opción -p muestra la prioridad del dispositivo de intercambio especificado.

La opción -t type limita el comando a un tipo de dispositivo de intercambio específico (por ejemplo, -t partition). La lista de tipos de dispositivo de intercambio conocidos se puede encontrar en el código fuente de util-linux.

La opción -v hace que swapon y swapoff sean más detallados.

OPTIONS

Las opciones de línea de comandos disponibles para swapon y swapoff son las siguientes:

-a, --all
Habilita o deshabilita todas las áreas de intercambio que se enumeran en fstab(5). Solo se consideran las entradas que no tengan la opción noauto.
-d, --discard
Deshabilita el dispositivo de intercambio especificado (solo para swapon).
-f, --force
Ignora la comprobación de firmas del dispositivo de intercambio. Útil si la firma del dispositivo de intercambio se ha dañado.
-h, --help
Muestra un mensaje de ayuda y sale.
-p, --show-priority
Muestra la prioridad del dispositivo de intercambio especificado.
-R, --rescan
Relee la tabla de particiones GPT.
-s, --summary
Muestra un resumen conciso de todo el espacio de intercambio (tipo, tamaño, utilizado y prioridad).
-t, --type type
Especifica el tipo de dispositivo de intercambio a habilitar o deshabilitar. La lista de tipos conocidos se puede encontrar en el código fuente de util-linux.
-v, --verbose
Genera una salida detallada.
-V, --version
Muestra información sobre la versión y sale.

EXIT STATUS

Los códigos de salida son los siguientes:

0
Éxito.
1
Error.
2
Error de sintaxis en la línea de comandos.
4
Error operativo (por ejemplo, el dispositivo no se encuentra).
8
Error interno del sistema (por ejemplo, no se pudo asignar memoria).

ENVIRONMENT

Las variables HOME, PATH, PWD, SHELL, y USER se utilizan para obtener la ubicación del archivo de área de intercambio y los directorios del sistema.

FILES


/etc/fstab archivo de configuración del sistema; lista las áreas de intercambio que se deben habilitar al arrancar el sistema.

NOTES

En util-linux versión 2.41, el comando mkswap --file puede crear un nuevo archivo de intercambio con el atributo nocow.

NFS

El intercambio sobre NFS puede no funcionar.

Suspend

swapon detecta y reescribe automáticamente una firma de espacio de intercambio con datos de suspensión de software antiguos (por ejemplo, S1SUSPEND, S2SUSPEND, ...). El problema es que si no lo hacemos, entonces obtenemos corrupción de datos la próxima vez que se intente la desactivación de la suspensión.

HISTORY

El comando swapon apareció en 4.0BSD.
