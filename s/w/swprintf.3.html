wprintf(3) Manual de funciones de biblioteca wprintf(3)

NOMBRE

wprintf, fwprintf, swprintf, vwprintf, vfwprintf, vswprintf - conversión de salida formateada de caracteres anchos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
#include <wchar.h>
int wprintf(const wchar_t *restrict format, ...);
int fwprintf(FILE *restrict stream,
             const wchar_t *restrict format, ...);
int swprintf(size_t n;
             wchar_t wcs[restrict n], size_t n,
             const wchar_t *restrict format, ...);
int vwprintf(const wchar_t *restrict format, va_list args);
int vfwprintf(FILE *restrict stream,
             const wchar_t *restrict format, va_list args);
int vswprintf(size_t n;
             wchar_t wcs[restrict n], size_t n,
             const wchar_t *restrict format, va_list args);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

Todas las funciones mostradas arriba:

    _XOPEN_SOURCE >= 500 || _ISOC99_SOURCE
        || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

La familia de funciones wprintf() es el equivalente en caracteres anchos de la familia de funciones printf(3). Realiza la salida formateada de caracteres anchos.

Las funciones wprintf() y vwprintf() realizan salida de caracteres anchos a stdout. stdout no debe estar orientado a bytes; ver fwide(3) para más información.

Las funciones fwprintf() y vfwprintf() realizan salida de caracteres anchos a stream. stream no debe estar orientado a bytes; ver fwide(3) para más información.

Las funciones swprintf() y vswprintf() realizan salida de caracteres anchos a un array de caracteres anchos. El programador debe asegurarse de que haya espacio para al menos n caracteres anchos en wcs.

Estas funciones son como las funciones printf(3), vprintf(3), fprintf(3), vfprintf(3), sprintf(3), vsprintf(3) excepto por las siguientes diferencias:

•
La cadena format es una cadena de caracteres anchos.
•
La salida consiste en caracteres anchos, no bytes.
•
swprintf() y vswprintf() toman un argumento n, mientras que sprintf(3) y vsprintf(3) no lo hacen. (snprintf(3) y vsnprintf(3) toman un argumento n, pero estas funciones no devuelven -1 ante un desbordamiento de búfer en Linux).

El tratamiento de los caracteres de conversión c y s es diferente:

c
Si no hay un modificador l presente, el argumento int se convierte a un carácter ancho mediante una llamada a la función btowc(3), y se escribe el carácter ancho resultante. Si hay un modificador l presente, se escribe el argumento wint_t (carácter ancho).
s
Si no hay un modificador l presente: se espera que el argumento const char * sea un puntero a un array de tipo carácter (puntero a una cadena) que contiene una secuencia de caracteres multibyte comenzando en el estado de cambio inicial. Los caracteres del array se convierten a caracteres anchos (cada uno mediante una llamada a la función mbrtowc(3) con un estado de conversión comenzando en el estado inicial antes del primer byte). Los caracteres anchos resultantes se escriben hasta el carácter ancho nulo terminador (L'\0') (sin incluirlo). Si se especifica una precisión, no se escribirán más caracteres anchos que el número especificado. Tenga en cuenta que la precisión determina el número de caracteres anchos escritos, no el número de bytes o posiciones de pantalla. El array debe contener un byte nulo terminador ('\0'), a menos que se dé una precisión y sea tan pequeña que el número de caracteres anchos convertidos la alcance antes de que se alcance el final del array. Si hay un modificador l presente: se espera que el argumento const wchar_t * sea un puntero a un array de caracteres anchos. Los caracteres anchos del array se escriben hasta un carácter ancho nulo terminador (sin incluirlo). Si se especifica una precisión, no se escribirán más que el número especificado. El array debe contener un carácter ancho nulo terminador, a menos que se dé una precisión y esta sea menor o igual al número de caracteres anchos en el array.

VALOR DE RETORNO

Las funciones devuelven el número de caracteres anchos escritos, excluyendo el carácter ancho nulo terminador en el caso de las funciones swprintf() y vswprintf(). En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

Ver write(2) y putwc(3). Adicionalmente, pueden ocurrir los siguientes errores:

EOVERFLOW
El valor a devolver es mayor que INT_MAX.

Las funciones fwprintf() y wprintf() pueden fallar adicionalmente si:

ENOMEM
No hay suficiente espacio de almacenamiento disponible.

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C99.

NOTAS

El comportamiento de wprintf() y similares depende de la categoría LC_CTYPE de la configuración regional actual.

Si la cadena format contiene caracteres anchos no ASCII, el programa funcionará correctamente solo si la categoría LC_CTYPE de la configuración regional actual en tiempo de ejecución es la misma que la categoría LC_CTYPE de la configuración regional actual en tiempo de compilación. Esto se debe a que la representación de wchar_t depende de la plataforma y la configuración regional. (glibc representa los caracteres anchos utilizando su punto de código Unicode (ISO/IEC 10646), pero otras plataformas no lo hacen. Además, el uso de nombres de caracteres universales de C99 de la forma \unnnn no resuelve este problema). Por lo tanto, en programas internacionalizados, la cadena format debe constar solo de caracteres anchos ASCII, o debe construirse en tiempo de ejecución de manera internacionalizada (por ejemplo, utilizando gettext(3) o iconv(3), seguido de mbstowcs(3)).

VER TAMBIÉN

swprintf

**swprintf**, **swprintf_s** – dar formato y escribir un array ancho de caracteres a un array ancho de caracteres

NOMBRE

swprintf, swprintf_s – dar formato y escribir un array ancho de caracteres a un array ancho de caracteres

BIBLIOTECA

Formato de escritura estándar (libc, del sistema base)

SINOPSIS

#include <stdio.h>
#include <wchar.h>

int swprintf(wchar_t *restrict wcs, size_t maxlen,
             const wchar_t *restrict format, ...);
int swprintf_s(wchar_t *restrict wcs, size_t n,
               const wchar_t *restrict format, ...);

DESCRIPCION

La función swprintf escribe una secuencia de caracteres anchos y caracteres nulos finales en el array ancho de caracteres que apunta wcs, basándose en la cadena de formato format suministrada. Las conversiones posteriores, si las hay, se generan a partir de los argumentos subsiguientes, según lo especificado por el especificador de conversión en la cadena de formato.

La función swprintf_s es una versión alternativa de swprintf, que se define en C11 Annex K. Para cada llamada a swprintf_s, la cadena de formato se procesa normalmente, pero se proporciona protección contra desbordamientos. La cadena de resultado, incluida la terminación nula, no puede exceder n caracteres anchos.

La cadena de formato format es una cadena ancha que consta de cero o más secuencias, que se interpretan como se describe en la función printf. La diferencia de printf es que los argumentos se pasan en la pila. Las conversiones se aplican a los argumentos de tipo de carácter ancho.

A diferencia de sprintf, swprintf requiere un argumento adicional, maxlen, que es el tamaño máximo del buffer de destino wcs, incluido el carácter nulo final. Si la cadena resultante excede este tamaño, la función devuelve un valor negativo, y el contenido de wcs es indeterminado.

La función swprintf_s es una versión más segura que swprintf. La llamada swprintf_s se utiliza para escribir en el array ancho de caracteres que apunta wcs. El argumento n es el tamaño del array ancho de caracteres. La cadena de resultado, incluido el carácter nulo final, no debe exceder n caracteres anchos. Si n es cero o si wcs es un puntero nulo, se llamará a la función de manejo de parámetros no válidos. Si se produce un error de codificación, se llamará a la función de manejo de parámetros no válidos. Si la longitud de la cadena de salida es mayor o igual que n, se llamará a la función de manejo de parámetros no válidos. Después de que la función de manejo de parámetros no válidos regrese, swprintf_s devolverá un valor negativo.

VALOR DE RETORNO

Las funciones swprintf y swprintf_s devuelven el número de caracteres anchos escritos en el array de destino, sin incluir el carácter nulo de terminación. Si ocurre un error de codificación o si el tamaño del buffer de destino es insuficiente, las funciones devuelven un valor negativo.

ERRORES

No se definen errores específicos para estas funciones.

ATRIBUTOS

Para obtener una explicación de esta sección, consulte attributes(7).

+------------------------------------+-----------------------------+
| Identificador                      | Atributo                    |
+------------------------------------+-----------------------------+
| swprintf, swprintf_s               | Thread safety, async-signal-safe |
+------------------------------------+-----------------------------+

ESTANDARES

La función swprintf está definida por la norma C99 y POSIX.1-2001. La función swprintf_s está definida por la norma C11 Annex K (Seguridad de la biblioteca).

HISTORIA

La función swprintf apareció en el sistema operativo Windows NT.

NOTAS

Estas funciones son el equivalente de carácter ancho de printf y sprintf.

El comportamiento de swprintf en caso de desbordamiento del buffer es inseguro. Se recomienda utilizar swprintf_s siempre que sea posible.
