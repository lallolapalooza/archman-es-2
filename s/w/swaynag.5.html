NOMBRE

swaynag - Archivo de configuración de swaynag

SINOPSIS

$HOME/.swaynag/config, $XDG_CONFIG_HOME/swaynag/config, SYSCONFDIR/swaynag/config

ARCHIVO DE CONFIGURACIÓN

Al principio del archivo de configuración, las opciones de swaynag pueden establecerse usando el formato opción-larga=valor. Estos se usarán como valores predeterminados si a swaynag no se le proporciona la opción. Esto puede ser útil para establecer una fuente, salida y borde preferidos.

Debajo de las opciones, se pueden definir tipos personalizados. Para definir un tipo, usa el siguiente formato:

[nombre-del-tipo]
opción=valor

Todos los colores pueden darse en formato RRGGBB o RRGGBBAA. Los siguientes colores pueden establecerse:

fondo=<color>

El color de fondo para swaynag.

borde=<color>

El color a usar para los bordes de los botones.

borde-inferior=<color>

El color de la línea de borde en la parte inferior de swaynag.

fondo-botón=<color>

El color de fondo para los botones.

texto=<color>

El color del texto.

texto-botón=<color>

El color del texto del botón.

Las siguientes opciones de tamaño también pueden establecerse:

tamaño-borde-inferior=<tamaño>

Establece el grosor del borde inferior.

relleno-mensaje=<relleno>

Establece el relleno para el mensaje.

fondo-detalles=<color>

El color de fondo para los detalles.

tamaño-borde-detalles=<tamaño>

Establece el grosor del borde de los detalles.

tamaño-borde-botón=<tamaño>

Establece el grosor del borde del botón.

espacio-botón=<espacio>

Establece el tamaño del espacio entre botones.

espacio-botón-descartar=<espacio>

Establece el tamaño del espacio entre el botón de descartar y otro botón.

margen-derecho-botón=<margen>

Establece el margen desde el lado derecho del botón de descartar hasta el borde.

relleno-botón=<relleno>

Establece el relleno para el texto del botón.

Adicionalmente, las siguientes opciones pueden asignarse como predeterminadas por tipo:

borde=arriba|abajo

Establece el borde a usar.

capa=overlay|top|bottom|background

Establece la capa a usar.

fuente=<fuente>

Establece la fuente a usar.

salida=<salida>

Establece la salida a usar. Este debe ser el nombre de un xdg_output.

EJEMPLO

fuente=Monospace 12
borde=abajo
[verde]
borde=arriba
fondo=00AA00
borde-color=006600
borde-inferior=004400
texto=FFFFFF
fondo-botón=00CC00
relleno-mensaje=10
