SWAB(3P) Manual del Programador POSIX SWAB(3P)

PRÓLOGO

Esta página de manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página de manual correspondiente de Linux para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

swab — intercambiar bytes

SINOPSIS

#include <unistd.h>
void swab(const void *restrict src, void *restrict dest,
    ssize_t nbytes);

DESCRIPCIÓN

La función swab() copiará nbytes bytes, apuntados por src, al objeto apuntado por dest, intercambiando bytes adyacentes. El argumento nbytes debe ser par. Si nbytes es impar, swab() copiará e intercambiará nbytes-1 bytes y la disposición del último byte no se especifica. Si la copia se realiza entre objetos que se superponen, el comportamiento es indefinido. Si nbytes es negativo, swab() no hace nada.

Ninguno.
