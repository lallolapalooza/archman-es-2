NOMBRE

swtpm_cert - Herramienta para crear certificados EK y de plataforma para swtpm (1.2 & 2.0)

SINOPSIS

swtpm_cert [OPCIONES]

DESCRIPCIÓN

swtpm_cert es una herramienta de CA local para crear certificados X.509v3 para la Clave de Respaldo (Endorsement Key) del TPM. La razón de esta herramienta específica es que funciona sin acceso a la clave privada de la Clave de Respaldo. Típicamente, las herramientas requieren una solicitud de certificado autofirmado o acceso a la clave privada para emitir un certificado. Esta herramienta funciona solo con la parte de la clave pública.

Las siguientes opciones son compatibles:

--type {ek|platform}
El tipo de certificado a crear; por defecto se crea un certificado EK.
--pubkey <nombre_archivo>
La clave pública (EK) en formato PEM.
--modulus <dígitos hexadecimales>
El módulo de la clave pública como una cadena de dígitos hexadecimales. Esta opción se puede usar en lugar de la opción --pubkey.
--ecc-x <dígitos hexadecimales>
El parámetro x de la curva elíptica como una cadena de dígitos hexadecimales.
--ecc-y <dígitos hexadecimales>
El parámetro y de la curva elíptica como una cadena de dígitos hexadecimales.
--ecc-curveid <id_curva>
El ID de la curva elíptica. Se admiten secp256r1, secp384r1 y secp521r1. Si esta opción no se proporciona, se asume secp256r1.
--exponent <exponente>
El exponente de la clave pública. Por defecto se asume 0x10001.
--signkey <nombre_archivo>
La clave utilizada para firmar el certificado. El archivo debe estar en formato PEM.
--signkey-password <contraseña>
Contraseña opcional para la clave de firma.
--signkey-pwd <pwd>
Esta es una opción alternativa para pasar la contraseña de la clave de firma. Los siguientes formatos son compatibles para pwd: 
- <contraseña>                   : contraseña directa
- pass:<contraseña>              : contraseña directa
- file:<nombre_archivo>              : contraseña en archivo
- fd:<descriptor_archivo>         : leer contraseña de descriptor de archivo
- env:<variable_entorno>   : leer contraseña de variable de entorno

Todas las contraseñas leídas de archivos y descriptores de archivo deben tener un máximo de 255 bytes (más un byte para el byte NUL terminador).

--parentkey-password <contraseña>
Contraseña opcional para una clave padre. En caso de que se utilice una clave TPM para firmar, esta sería la contraseña de la clave raíz de almacenamiento (SRK) del TPM.
--parentkey-pwd <pwd>
Esta es una opción alternativa para pasar la contraseña de la clave padre. Consulte la descripción anterior para ver los formatos de pwd compatibles.
--issuercert <nombre_archivo>
El certificado X.509 de este firmante que asume el rol de una CA local.
--out-cert <nombre_archivo>
El nombre del archivo donde se escribirá el certificado X.509v3. La salida estará en formato PEM.
--serial <número_serie>
Número de serie opcional de 32 bits para el certificado.
--days <número>
El número de días que el certificado es válido; por defecto es válido por 365 días.
--pem
Escribir el certificado resultante en formato PEM; el formato DER es el predeterminado.
--tpm-manufacturer <nombre>
El nombre del fabricante del TPM.
--tpm-model <modelo>
El modelo del TPM (número de pieza).
--tpm-version <versión>
La versión del firmware del TPM.
--platform-manufacturer <nombre>
El nombre del fabricante de la plataforma.
--platform-model <modelo>
El modelo de la plataforma.
--platform-version <versión>
La versión de la plataforma.
--subject <sujeto>
Sujeto para, por ejemplo, proporcionar la ubicación del TPM en formato C=<país>,ST=<estado>,L=<ubicación>. Tenga en cuenta que la ubicación no debe contener espacios.
--tpm2
Emitir certificados compatibles con TPM 2.
--allow-signing
Crear una EK que también se pueda usar para firmar. Sin esta opción, la EK solo se puede usar para cifrado de claves. Esta opción requiere --tpm2.
--decryption
Si se pasa --allow-signing y la EK también debe ser utilizable para el cifrado de claves, se debe pasar esta opción. De lo contrario, el cifrado de claves es el predeterminado. Esta opción requiere --tpm2.
--print-capabilities (desde v0.3)
Imprimir las capacidades que se añadieron a swtpm_cert después de la versión 0.2. La salida puede contener lo siguiente: 
{
  "type": "swtpm_cert",
  "features": [
    "cmdarg-signkey-pwd",
    "cmdarg-parentkey-pwd"
  ],
  "version": "0.7.0"
}

El campo de versión está disponible desde la versión 0.7.

El significado de los verbos de características es el siguiente:

cmdarg-signkey-pwd
La opción --signkey-pwd es compatible.
cmdarg-parentkey-pwd
La opción --parentkey-pwd es compatible.
--help, -h
Mostrar la pantalla de ayuda
