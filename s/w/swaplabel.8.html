SWAPLABEL(8) Administración del Sistema SWAPLABEL(8)

NOMBRE

swaplabel - mostrar o cambiar la etiqueta o UUID de un área de intercambio

SINOPSIS

swaplabel [-L etiqueta] [-U UUID] dispositivo

DESCRIPCIÓN

swaplabel mostrará o cambiará la etiqueta o el UUID de una partición de intercambio ubicada en dispositivo (o archivo regular).

Si no se proporcionan los argumentos opcionales -L y -U, swaplabel simplemente mostrará la etiqueta y el UUID actuales del área de intercambio de dispositivo.

Si se proporciona un argumento opcional, swaplabel cambiará el valor apropiado en dispositivo. Estos valores también se pueden establecer durante la creación del intercambio usando mkswap(8). La utilidad swaplabel permite cambiar la etiqueta o el UUID en un dispositivo de intercambio activamente utilizado.

OPCIONES

-L, --label etiqueta

Especifica una nueva etiqueta para el dispositivo. Las etiquetas de las particiones de intercambio pueden tener como máximo 16 caracteres. Si etiqueta tiene más de 16 caracteres, swaplabel la truncará y mostrará un mensaje de advertencia.

-U, --uuid UUID

Especifica un nuevo UUID para el dispositivo. El UUID debe estar en el formato estándar de 8-4-4-4-12 caracteres, como el que genera uuidgen(1).

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

AMBIENTE

LIBBLKID_DEBUG=all

Habilita la salida de depuración de libblkid.
