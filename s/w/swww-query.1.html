swww-query(1) Manual de Comandos Generales swww-query(1)

NOMBRE

swww-query

SINOPSIS

swww query

OPCIONES

-a,--all

Envía este comando a todos los espacios de nombres de `swww-daemon` activos.

-n,--namespace <espacio de nombres>

Qué espacio de nombres de Wayland para enviar este comando.

Puedes especificar esta opción varias veces para enviar comandos a múltiples espacios de nombres a la vez: `swww query -n <espacio de nombres1> -n <espacio de nombres 2>`.

Esto afecta el nombre del socket de `swww-daemon` que usaremos para comunicarnos. Específicamente, el nombre de nuestro socket es ${WAYLAND_DISPLAY}-swww-daemon.<espacio de nombres especificado>.socket.

Algunos compositores pueden tener varios fondos de pantalla por salida. Esto te permite diferenciar entre ellos. La mayoría de los usuarios probablemente no tendrán que configurar nada en esta opción.

-h, --help

Imprime la ayuda (ver un resumen con '-h')

DESCRIPCIÓN

Pregunta al demonio para que imprima información de salida (nombres y dimensiones).

Puedes usar esto para descubrir valores válidos para la opción <swww-img --outputs>. Si quieres información más detallada sobre tus salidas, te recomiendo probar algo como wlr-randr.

FORMATO DE SALIDA

Actualmente, swww query imprime información en el siguiente formato:

SALIDA: TAMAÑO, escala: ESCALA, mostrando actualmente: IMAGEN_O_COLOR

donde TAMAÑO está en formato AxA (ej.: 1920x1080), ESCALA en "escala: NÚMERO", y IMAGEN_O_COLOR en

  • "imagen: NOMBRE_IMAGEN", si es una imagen; o
  • "color: RGB", si es un color
