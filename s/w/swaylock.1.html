NOMBRE

swaylock - Bloqueador de pantalla para Wayland

SINOPSIS

swaylock [opciones...]

Bloquea tu sesión Wayland.

OPCIONES

-C, --config <ruta>

El archivo de configuración a usar. Por defecto, se comprueban las siguientes rutas: $HOME/.swaylock/config, $XDG_CONFIG_HOME/swaylock/config y SYSCONFDIR/swaylock/config. Todas las opciones, excepto esta, son opciones válidas en el archivo de configuración usando el formato opcion-larga=valor. Para opciones como ignore-empty-password, simplemente proporcione la opcion-larga. Se deben omitir todos los guiones iniciales y el signo igual es obligatorio para las opciones que toman un argumento.

-d, --debug

Habilita la salida de depuración.

-e, --ignore-empty-password

Cuando se proporciona una contraseña vacía, no la valides.

-F, --show-failed-attempts

Muestra el recuento actual de intentos de autenticación fallidos.

-f, --daemonize

Desconéctate del terminal de control después de bloquear.

Nota: este es el comportamiento predeterminado de i3lock.

-R, --ready-fd <fd>

Descriptor de archivo al que enviar notificaciones de listo.

Cuando la sesión se ha bloqueado, se escribe una sola nueva línea en el FD. En este momento, el compositor garantiza que no hay contenido sensible a la seguridad visible en pantalla.

-h, --help

Muestra el mensaje de ayuda y sale.

-v, --version

Muestra el número de versión y sale.

APARIENCIA

-u, --no-unlock-indicator

Deshabilita el indicador de desbloqueo.

-i, --image [[<salida>]:]<ruta>

Muestra la imagen dada, opcionalmente solo en la salida dada. Usa -c para establecer un color de fondo. Si la ruta contiene potencialmente un ':', prefíjala con otro ':' para evitar interpretar parte de ella como <salida>.

-k, --show-keyboard-layout

Muestra la disposición del teclado xkb actual al escribir.

-K, --hide-keyboard-layout

Fuerza ocultar la disposición del teclado xkb actual al escribir, incluso si hay más de una disposición configurada o si la opción show-keyboard-layout está establecida.

-L, --disable-caps-lock-text

Deshabilita el texto de Bloq Mayús.

-l, --indicator-caps-lock

Muestra el estado actual de Bloq Mayús también en el indicador.

-s, --scaling

Modo de escalado de imagen: stretch, fill, fit, center, tile, solid_color. Usa solid_color para mostrar solo el color de fondo, incluso si se especifica una imagen de fondo.

-t, --tiling

Igual que --scaling=tile.

-c, --color <rrggbb[aa]>

Convierte la pantalla al color dado en lugar de gris claro. Si se usa -i, esto establece el fondo de la imagen al color dado. Predeterminado: gris claro (A3A3A3).

--bs-hl-color <rrggbb[aa]>

Establece el color de los segmentos de resaltado de retroceso.

--caps-lock-bs-hl-color <rrggbb[aa]>

Establece el color de los segmentos de resaltado de retroceso cuando Bloq Mayús está activo.

--caps-lock-key-hl-color <rrggbb[aa]>

Establece el color de los segmentos de resaltado de pulsación de tecla cuando Bloq Mayús está activo.

--font <fuente>

Establece la fuente del texto.

--font-size <tamaño>

Establece un tamaño de fuente fijo para el texto del indicador.

--indicator-idle-visible

Establece que el indicador se muestre incluso si está inactivo.

--indicator-radius <radio>

Establece el radio del indicador. El valor predeterminado es 50.

--indicator-thickness <grosor>

Establece el grosor del indicador. El valor predeterminado es 10.

--indicator-x-position <x>

Establece la posición horizontal del indicador.

--indicator-y-position <y>

Establece la posición vertical del indicador.

--inside-color <rrggbb[aa]>

Establece el color del interior del indicador.

--inside-clear-color <rrggbb[aa]>

Establece el color del interior del indicador cuando se ha borrado.

--inside-caps-lock-color <rrggbb[aa]>

Establece el color del interior del indicador cuando Bloq Mayús está activo.

--inside-ver-color <rrggbb[aa]>

Establece el color del interior del indicador cuando se está verificando.

--inside-wrong-color <rrggbb[aa]>

Establece el color del interior del indicador cuando es inválido.

--key-hl-color <rrggbb[aa]>

Establece el color de los segmentos de resaltado de pulsación de tecla.

--layout-bg-color <rrggbb[aa]>

Establece el color de fondo de la caja que contiene el texto de la disposición del teclado.

--layout-border-color <rrggbb[aa]>

Establece el color del borde de la caja que contiene el texto de la disposición del teclado.

--layout-text-color <rrggbb[aa]>

Establece el color del texto de la disposición del teclado.

--line-color <rrggbb[aa]>

Establece el color de la línea entre el interior y el anillo.

--line-clear-color <rrggbb[aa]>

Establece el color de la línea entre el interior y el anillo cuando se ha borrado.

--line-caps-lock-color <rrggbb[aa]>

Establece el color de la línea entre el interior y el anillo cuando Bloq Mayús está activo.

--line-ver-color <rrggbb[aa]>

Establece el color de la línea entre el interior y el anillo cuando se está verificando.

--line-wrong-color <rrggbb[aa]>

Establece el color de la línea entre el interior y el anillo cuando es inválido.

-n, --line-uses-inside

Usa el color interior para la línea entre el interior y el anillo.

-r, --line-uses-ring

Usa el color del anillo para la línea entre el interior y el anillo.

--ring-color <rrggbb[aa]>

Establece el color del anillo del indicador cuando se escribe o está inactivo.

--ring-clear-color <rrggbb[aa]>

Establece el color del anillo del indicador cuando se ha borrado.

--ring-caps-lock-color <rrggbb[aa]>

Establece el color del anillo del indicador cuando Bloq Mayús está activo.

--ring-ver-color <rrggbb[aa]>

Establece el color del anillo del indicador cuando se está verificando.

--ring-wrong-color <rrggbb[aa]>

Establece el color del anillo del indicador cuando es inválido.

--separator-color <rrggbb[aa]>

Establece el color de las líneas que separan los segmentos de resaltado.

--text-color <rrggbb[aa]>

Establece el color del texto.

--text-clear-color <rrggbb[aa]>

Establece el color del texto cuando se ha borrado.

--text-caps-lock-color <rrggbb[aa]>

Establece el color del texto cuando Bloq Mayús está activo.

--text-ver-color <rrggbb[aa]>

Establece el color del texto cuando se está verificando.

--text-wrong-color <rrggbb[aa]>

Establece el color del texto cuando es inválido.

SEÑALES

SIGUSR1

Desbloquea la pantalla y sale.
