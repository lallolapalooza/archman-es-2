NOMBRE

swappy - capturar y editar instantáneas sobre la marcha de un compositor Wayland

SINOPSIS

swappy [opciones...]

DESCRIPCIÓN

swappy es una utilidad de línea de comandos para tomar y editar capturas de pantalla de escritorios Wayland. Funciona muy bien con grim, slurp y sway. Pero puede funcionar fácilmente con otras herramientas de copia de pantalla que pueden generar una imagen final en stdout.

swappy guardará las imágenes anotadas en el directorio de configuración save_dir, véase más abajo.

Si está ausente, entonces intentará usar por defecto una carpeta Escritorio siguiendo este patrón: $XDG_DESKTOP_DIR. Si esta variable no está configurada, recurrirá a: $XDG_CONFIG_HOME/Escritorio. Si $XDG_CONFIG_HOME no está configurada, recurrirá a: $HOME/Escritorio.

OPCIONES

-h, --help

Muestra el mensaje de ayuda y sale.

-v, --version

Muestra la versión y sale.

-f, --file <archivo>

Un archivo de imagen para cargar para editar.

Si se establece en -, lee el archivo de la entrada estándar en su lugar. Esto es amigable con grim.

-o, --output-file <archivo>

Imprime la superficie final en <archivo> al salir de la aplicación.

Si se establece en -, imprime la superficie final en stdout.

Tenga en cuenta que el botón Guardar guardará la imagen en el parámetro save_dir de la configuración, como se describe en la sección DESCRIPCIÓN.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración se encuentra en $XDG_CONFIG_HOME/swappy/config o en $HOME/.config/swappy/config. El archivo sigue el formato conf de GLib.

[Sección]
clave=valor

Las siguientes líneas pueden usarse como predeterminadas de swappy:

[Por defecto]
save_dir=$HOME/Escritorio
save_filename_format=swappy-%Y%m%d-%H%M%S.png
show_panel=false
line_size=5
text_size=20
text_font=sans-serif
paint_mode=brush
early_exit=false
fill_shape=false
auto_save=false
custom_color=rgba(192,125,17,1)
transparent=false
transparency=50
  • save_dir es donde se guardarán las capturas, puede contener variables de entorno; cuando no existe, swappy intenta crearlo primero, pero no falla si la creación del directorio falla
  • save_filename_format es la plantilla del nombre de archivo; si contiene un formato de fecha, se analizará en una marca de tiempo. El formato se detalla en strftime(3). Si falta este formato de fecha, el nombre de archivo no tendrá marca de tiempo
  • show_panel se usa para activar o desactivar el panel de dibujo al iniciar
  • line_size es el tamaño de línea predeterminado (debe estar entre 1 y 50)
  • text_size es el tamaño de texto predeterminado (debe estar entre 10 y 50)
  • text_font es la fuente utilizada para renderizar texto, su formato es compatible con pango
  • paint_mode es el modo activado al inicio de la aplicación (debe ser uno de: brush|text|rectangle|ellipse|arrow|blur, la coincidencia no distingue mayúsculas y minúsculas)
  • early_exit se utiliza para hacer que la aplicación salga después de guardar la imagen o copiarla al portapapeles
  • fill_shape se utiliza para activar o desactivar el relleno de formas (para las herramientas de rectángulo y elipse) al iniciar
  • auto_save se utiliza para activar o desactivar el guardado automático del buffer final en save_dir al salir
  • custom_color se utiliza para establecer un valor predeterminado para el color personalizado. Los formatos aceptados son: nombre estándar (uno de: https://github.com/rgb-x/system/blob/master/root/etc/X11/rgb.txt), #rgb, #rrggbb, #rrrgggbbb, #rrrrggggbbbb, rgb(r,b,g), rgba(r,g,b,a)
  • transparency se utiliza para establecer la transparencia de todo lo que se dibuja al inicio
  • transparent se utiliza para activar o desactivar la transparencia al inicio

ATAJOS DE TECLADO

DISEÑO

•
Ctrl+b: Alternar Panel de Dibujo

MODO DE PINTURA

  • b: Cambiar a Pincel
  • `e` `t`: Cambiar a Texto (Editor)
  • `r` `s`: Cambiar a Rectángulo (Cuadrado)
  • `c` `o`: Cambiar a Elipse (Círculo)
  • a: Cambiar a Flecha
  • d: Cambiar a Desenfoque (d significa gota)
  • R: Usar Color Rojo
  • G: Usar Color Verde
  • B: Usar Color Azul
  • C: Usar Color Personalizado
  • Menos: Reducir Tamaño de Trazo
  • Más: Aumentar Tamaño de Trazo
  • Igual: Restablecer Tamaño de Trazo
  • f: Alternar Relleno de Forma
  • T: Alternar Transparencia
  • `x` `k`: Limpiar Dibujos (no se puede deshacer)

MODIFICADORES

•
Ctrl: Centrar Forma (Rectángulo y Elipse) basándose en el inicio del dibujo

BARRA SUPERIOR

  • Ctrl+z: Deshacer
  • Ctrl+Shift+z o Ctrl+y: Rehacer
  • Ctrl+s: Guardar en archivo (ver página del manual)
  • Ctrl+c: Copiar al portapapeles
  • Escape o q o Ctrl+w: Salir de swappy
