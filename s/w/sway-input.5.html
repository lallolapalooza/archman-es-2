NOMBRE

sway-input - archivo de configuración de entrada y comandos

DESCRIPCIÓN

Sway permite la configuración de dispositivos dentro del archivo de configuración de sway. Para obtener una lista de identificadores de dispositivo disponibles, ejecuta swaymsg -t get_inputs. Las configuraciones también se pueden aplicar a todos los dispositivos de entrada usando el comodín, *, en lugar de <identificador> en los comandos a continuación. Además, las configuraciones se pueden aplicar a un tipo de dispositivo, usando type:<tipo_entrada> en lugar de <identificador>.

En el archivo de configuración, las configuraciones con un selector más específico tienen precedencia sobre las más generales: <identificador> > type:<tipo_entrada> > *. Sin embargo, al ejecutar comandos de entrada, las configuraciones se aplican a todos los dispositivos de entrada que coinciden. Esto significa que type:<tipo_entrada> puede anular configuraciones de <identificador> establecidas previamente, aunque en un archivo de configuración tengan precedencia. De manera similar, * puede anular configuraciones de <identificador> y type:<tipo_entrada>, si se aplica más tarde.

Consejo: Si las configuraciones no parecen surtir efecto, puedes intentar usar * en lugar de <identificador>. Si funciona con el comodín, intenta usar un identificador diferente de swaymsg -t get_inputs hasta que encuentres el dispositivo de entrada correcto.

Los tipos de entrada actualmente disponibles son:

  • touchpad
  • pointer
  • keyboard
  • touch
  • tablet_tool
  • tablet_pad
  • switch

Nota: Las configuraciones de tipo se aplican a medida que aparecen los dispositivos y se aplican encima de las configuraciones de dispositivo existentes.

COMANDOS DE ENTRADA

CONFIGURACIÓN DE TECLADO

input <identificador> repeat_delay <milisegundos>

Establece el tiempo que debe mantenerse presionada una tecla antes de que comience a repetirse.

input <identificador> repeat_rate <caracteres por segundo>

Establece la frecuencia de repetición de teclas una vez que ha pasado el repeat_delay.

Para obtener más información sobre estas opciones de configuración de xkb, consulta xkeyboard-config(7).

input <identificador> xkb_file <nombre_archivo>

Establece todas las configuraciones de xkb desde un archivo .xkb completo. Este archivo se puede volcar desde xkbcomp $DISPLAY keymap.xkb. Esta configuración anula las configuraciones xkb_layout, xkb_model, xkb_options, xkb_rules y xkb_variant.

input <identificador> xkb_layout <nombre_layout>

Establece el diseño del teclado, como us o de.

Se pueden especificar varios diseños separándolos con comas.

input <identificador> xkb_model <nombre_modelo>

Establece el modelo del teclado. Esto influye en algunas teclas adicionales que pueda tener tu teclado.

input <identificador> xkb_options <opciones>

Establece opciones de configuración adicionales de xkb para el teclado.

Se pueden especificar varias opciones separándolas con comas.

input <identificador> xkb_rules <reglas>

Establece archivos de reglas que se utilizarán para la composición del mapeo del teclado.

input <identificador> xkb_switch_layout <índice>|siguiente|anterior

Cambia el diseño de teclado activo al <índice> contando desde cero o al siguiente o anterior diseño de la lista. Si no hay un siguiente o anterior diseño, este comando salta al otro extremo de la lista.

Esto se puede usar cuando hay varios diseños configurados con xkb_layout. Se puede obtener una lista de diseños entre los que cambiar con swaymsg -t get_inputs.

input <identificador> xkb_variant <variante>

Establece la variante del teclado, como dvorak o colemak.

Los siguientes comandos solo se pueden usar en el archivo de configuración.

input <identificador> xkb_capslock activado|desactivado

Activa o desactiva inicialmente Bloq Mayús al inicio, por defecto está desactivado.

input <identificador> xkb_numlock activado|desactivado

Activa o desactiva inicialmente Bloq Num al inicio, por defecto está desactivado.

CONFIGURACIÓN DE TABLET

input <identificador> tool_mode <herramienta> <absoluto|relativo>

Establece si el movimiento de una herramienta de tableta debe tratarse como absoluto o relativo; por defecto es absoluto.

Los valores válidos para <herramienta> son actualmente "pen", "eraser", "brush", "pencil", "airbrush", y el comodín *, que coincide con todas las herramientas.

Las herramientas de ratón y lente ignoran esta configuración y siempre se tratan como relativas.

CONFIGURACIÓN DE MAPEO

input <identificador> map_to_output <identificador>

Mapea las entradas de este dispositivo a la salida especificada. Solo es significativo si el dispositivo es un puntero, táctil o dispositivo de tableta gráfica.

El comodín * se puede usar para mapear el dispositivo de entrada a todo el diseño del escritorio.

input <identificador> map_to_region <X> <Y> <ancho> <alto>

Mapea las entradas de este dispositivo a la región especificada del diseño de salida global. Solo es significativo si el dispositivo es un puntero, táctil o dispositivo de tableta gráfica.

input <identificador> map_from_region <X1xY1> <X2xY2>

Ignora las entradas de este dispositivo que no ocurran dentro de la región especificada. Puede ser en milímetros (por ejemplo, 10x20mm 20x40mm) o la fracción del espacio total disponible en términos de 0..1 (por ejemplo, 0.5x0.5 0.7x0.7). No todos los dispositivos admiten milímetros. Solo es significativo si el dispositivo no es un teclado y proporciona eventos en términos absolutos (como una tableta gráfica o una pantalla táctil; la mayoría de los punteros proporcionan eventos relativos al fotograma anterior).

Comúnmente se usa para mantener la relación de aspecto del dispositivo de entrada y la pantalla. Recortar una región de entrada 16:10 para que coincida con una pantalla 16:9 puede usar 0x0 1x0.9 como argumento.

CONFIGURACIÓN DE LIBINPUT

input <identificador> accel_profile adaptativo|plano

Establece el perfil de aceleración del puntero para el dispositivo de entrada especificado.

input <identificador> calibration_matrix <6 valores de punto flotante separados por espacios>

Establece la matriz de calibración.

input <identificador> click_method ninguno|area_clic|dedo_clic

Cambia el método de clic para el dispositivo especificado.

input <identificador> clickfinger_button_map lrm|lmr

Especifica qué mapeo de botones usar para clickfinger. lrm trata 1 dedo como clic izquierdo, 2 dedos como clic derecho y 3 dedos como clic central. lmr trata 1 dedo como clic izquierdo, 2 dedos como clic central y 3 dedos como clic derecho.

input <identificador> drag activado|desactivado

Activa o desactiva el arrastrar y soltar (tap-and-drag) para el dispositivo de entrada especificado.

input <identificador> drag_lock activado|desactivado|activado_adhesivo

Activa o desactiva el bloqueo de arrastre para el dispositivo de entrada especificado. Por defecto es activado_adhesivo.

input <identificador> dwt activado|desactivado

Activa o desactiva disable-while-typing para el dispositivo de entrada especificado.

input <identificador> dwtp activado|desactivado

Activa o desactiva disable-while-trackpointing para el dispositivo de entrada especificado.

input <identificador> events activado|desactivado|desactivado_en_raton_externo|toggle [<modos_toggle>]

Activa o desactiva send_events para el dispositivo de entrada especificado. Desactivar send_events desactiva el dispositivo de entrada.

La opción toggle no se puede usar en la configuración. Si no se enumeran modos de alternancia, se iterará a través de todos los modos admitidos para el dispositivo en el orden: activado, desactivado_en_raton_externo

NAME

sway-input - input configuration

DESCRIPTION

Input devices are configured in the input section of the configuration file. The configuration is grouped by input device identifier.

The identifier can be obtained using the libinput debug-events command or the sway-msg(1) command. For example, to list all input devices, run: sway-msg -t get_inputs.

The wildcard character, *, can also be used in place of <identifier> to change settings for all input devices.

Note: Sway does not support all configuration options available in libinput(1). Some options may be ignored.

INPUT COMMANDS

input <identifier> accel_enabled enabled|disabled

Enables or disables acceleration for the specified input device.

input <identifier> accel_profile <profile>

Sets the acceleration profile for the specified input device. Valid profiles are flat, adaptive, and custom.

input <identifier> click_method double|button

Sets the click method for the specified input device. double enables standard double-click behavior. button enables clicking by pressing the button.

input <identifier> drag_lock enabled|disabled

Enables or disables drag lock for the specified input device.

input <identifier> dragging_threshold <distance>

Sets the distance in pixels a pointer must be moved before a drag is initiated.

input <identifier> events enabled|disabled|disabled-on-external-mouse

Enables or disables events for the specified input device.

input <identifier> flat_buttons button[1-3,8,9]|<event-code-or-name>

input <identifier> left_handed enabled|disabled

Enables or disables left handed mode for specified input device.

input <identifier> middle_emulation enabled|disabled

Enables or disables middle click emulation.

input <identifier> natural_scroll enabled|disabled

Enables or disables natural (inverted) scrolling for the specified input device.

input <identifier> pointer_accel [<-1|1>]

Changes the pointer acceleration for the specified input device.

input <identifier> rotation_angle <angle>

Sets the rotation angle of the device to the given clockwise angle in degrees. The angle must be between 0.0 (inclusive) and 360.0 (exclusive).

input <identifier> scroll_button disable|button[1-3,8,9]|<event-code-or-name>

Sets the button used for scroll_method on_button_down. The button can be given as an event name or code, which can be obtained from libinput debug-events, or as a x11 mouse button (button[1-3,8,9]). If set to disable, it disables the scroll_method on_button_down.

input <identifier> scroll_factor <floating point value>

input <identifier> tap enabled|disabled

Enables or disables tap for specified input device.

input <identifier> tap_button_map lrm|lmr
