NOMBRE

sway-bar - archivo de configuración y comandos de la barra

DESCRIPCIÓN

Sway permite configurar swaybar en el archivo de configuración de sway.

COMANDOS

Los siguientes comandos solo pueden usarse en el archivo de configuración.

id <id_barra>

Establece el ID de la barra.

swaybar_command <comando>

Ejecuta un comando de barra personalizado. El valor predeterminado es swaybar.

Los siguientes comandos pueden usarse tanto en el archivo de configuración como en tiempo de ejecución.

bindcode [--release] <código-evento> <comando>

Ejecuta comando cuando se ha presionado el botón del ratón (o si se proporciona released, cuando se ha soltado el botón). Los botones se pueden proporcionar como un código de evento, que se puede obtener de libinput debug-events. Para deshabilitar el comportamiento predeterminado para un botón, usa el comando nop.

bindsym [--release] button[1-9]|<nombre-evento> <comando>

Ejecuta comando cuando se ha presionado el botón del ratón (o si se proporciona released, cuando se ha soltado el botón). Los botones se pueden proporcionar como un número de botón de x11 o un nombre de evento, que se puede obtener de libinput debug-events. Para deshabilitar el comportamiento predeterminado para un botón, usa el comando nop.

binding_mode_indicator sí|no

Habilita o deshabilita el indicador de modo de enlace. El valor predeterminado es sí.

font <fuente>

Especifica la fuente que se utilizará en la barra. fuente debe especificarse como una descripción de fuente pango. Para obtener más información sobre las descripciones de fuentes pango, consulta https://docs.gtk.org/Pango/type_func.FontDescription.from_string.html#description

gaps <todos> | <horizontal> <vertical> | <superior> <derecha> <inferior> <izquierda>

Establece los márgenes desde el borde de la pantalla para la barra. Los márgenes se pueden establecer a la vez, por dirección o por lado. Ten en cuenta que solo los lados que tocan un borde de la pantalla pueden tener márgenes. Para el lado que no toca un borde de la pantalla, los márgenes exteriores por lado para los espacios de trabajo pueden ser útiles.

height <altura>

Establece la altura de la barra. La altura predeterminada (0) coincidirá con el tamaño de la fuente.

hidden_state hide|show [<id-barra>]

Especifica el comportamiento de la barra cuando está en modo hide. Cuando el estado oculto es hide, normalmente está oculto y solo se muestra al presionar la tecla modificadora o en caso de indicadores de urgencia. Cuando el estado oculto es show, está permanentemente visible, dibujado encima del espacio de trabajo visible actualmente. El valor predeterminado es hide.

Para compatibilidad con i3, se admite la sintaxis bar hidden_state hide|show [<id-barra>] junto con la sintaxis exclusiva de sway bar <id-barra> hidden_state hide|show. Al usar la sintaxis de i3, si se omite id-barra, el estado oculto se cambiará para todas las barras. Intentar usar bar <id-barra1> hidden_state hide|show <id-barra2> generará un error debido a la contradicción de los IDs de barra.

mode dock|hide|invisible|overlay [<id-barra>]

Especifica la visibilidad de la barra. En modo dock, está permanentemente visible en un borde de la pantalla. En modo hide, está oculta a menos que se presione la tecla modificadora, aunque este comportamiento depende del estado oculto. En modo invisible, está permanentemente oculta. En modo overlay, está permanentemente visible encima de otras ventanas. (En modo overlay, la barra es transparente a los eventos de entrada). El valor predeterminado es dock.

Para compatibilidad con i3, se admite la sintaxis bar mode <modo> [<id-barra>] junto con la sintaxis exclusiva de sway bar <id-barra> mode <modo>. Al usar la sintaxis de i3, si se omite id-barra, el modo se cambiará para todas las barras. Intentar usar bar <id-barra1> mode <modo> <id-barra2> generará un error debido a la contradicción de los IDs de barra.

modifier <Modificador>|none

Especifica la tecla modificadora que muestra una barra oculta. El valor predeterminado es Mod4.

output <salida>|*

Restringe la barra a una salida determinada, se puede especificar varias veces. Si se omite el comando de salida, la barra se mostrará en todas las salidas. * se puede proporcionar en cualquier momento para restablecerlo a todas las salidas.

pango_markup enabled|disabled

Habilita o deshabilita el marcado Pango para las líneas de estado. Esto no tiene ningún efecto en las líneas de estado que utilizan el protocolo JSON de i3bar.

position top|bottom

Establece la posición de la barra. El valor predeterminado es bottom.

separator_symbol <símbolo>

Especifica el símbolo separador para separar los bloques en la barra.

status_command <comando de estado>

Ejecuta el comando de estado de la barra con sh -c. Cada línea de texto impresa en la salida estándar de este comando se mostrará en el área de estado de la barra. También puedes usar el protocolo de línea de estado JSON de swaybar. Consulta swaybar-protocol(7) para obtener más información sobre el protocolo.

Si ejecutas este comando a través de IPC, puedes deshabilitar un comando de estado en ejecución estableciendo el comando en un solo guion: swaybar bar bar-0 status_command -

status_edge_padding <relleno>

Establece el relleno que se utiliza cuando la línea de estado está en el borde derecho de la barra. Este valor se multiplicará por la escala de salida. El valor predeterminado es 3.

status_padding <relleno>

Establece el relleno vertical que se utiliza para la línea de estado. El valor predeterminado es 1. Si relleno es 0, los bloques podrán ocupar toda la altura de la barra. Este valor se multiplicará por la escala de salida.

strip_workspace_name sí|no

Si se establece en sí, los nombres de los espacios de trabajo se omitirán del botón del espacio de trabajo y solo se mostrará el número personalizado. El valor predeterminado es no.

strip_workspace_numbers sí|no

Si se establece en sí, los números de los espacios de trabajo se omitirán del botón del espacio de trabajo y solo se mostrará el nombre personalizado. El valor predeterminado es no.

unbindcode [--release] <código-evento>

Elimina el enlace con el <código-evento> dado.

unbindsym [--release] button[1-9]|<nombre-evento>

Elimina el enlace con el <botón> o <nombre-evento> dado.

wrap_scroll sí|no

Habilita o deshabilita el ajuste al desplazarse por los espacios de trabajo con la rueda del ratón. El valor predeterminado es no.

workspace_buttons sí|no

Habilita o deshabilita los botones de espacio de trabajo en la barra. El valor predeterminado es sí.

workspace_min_width <px> [px]

Especifica el ancho mínimo para los botones de espacio de trabajo en la barra. El valor predeterminado es 0.

Esta configuración también se aplica al indicador del modo de enlace actual.

Los siguientes comandos solo pueden usarse en tiempo de ejecución.

mode toggle [<id-barra>]

Cambia el modo actual entre hide y dock. Cualquier otro modo se trata como hide.

BANDEJA

Swaybar proporciona una bandeja del sistema donde las aplicaciones de terceros pueden colocar iconos. Los siguientes comandos configuran la bandeja.

tray_bindcode <código-evento> ContextMenu|Activate|SecondaryActivate|ScrollDown|ScrollLeft|ScrollRight|ScrollUp|nop

Ejecuta la acción cuando se presiona el botón del ratón. Los botones se pueden proporcionar como un código de evento, que se puede obtener de libinput debug-events. Para deshabilitar el comportamiento predeterminado para un botón, usa el comando nop.

tray_bindsym button[1-9]|<nombre-evento> ContextMenu|Activate|SecondaryActivate|ScrollDown|ScrollLeft|ScrollRight|ScrollUp|nop

Ejecuta la acción cuando se presiona el botón del ratón. Los botones se pueden proporcionar como un número de botón de x11 o un nombre de evento, que se puede obtener de libinput debug-events. Usa el comando nop para deshabilitar la acción predeterminada (Activate para button1, ContextMenu para button2 y SecondaryActivate para button3).

tray_padding <px> [px]

Establece el relleno de píxeles de la bandeja del sistema. Este relleno rodeará la bandeja por todos lados y entre cada elemento. El valor predeterminado para px es 2.

tray_output none|<salida>|*

Restringe la bandeja a una salida específica, se puede especificar múltiples veces. Si se omite, la bandeja se mostrará en todas las salidas. A diferencia de i3bar, swaybar puede mostrar iconos en cualquier número de barras y salidas sin condiciones de carrera. * se puede dar en cualquier momento para restablecerlo a la visualización en todas las salidas.

icon_theme <nombre>

Establece el tema de iconos que sway buscará para los iconos de elementos. Esta opción no tiene un valor predeterminado, ya que sway siempre recurrirá al tema de respaldo, hicolor.

COLORES

Los colores se definen dentro de un bloque colors { } dentro de un bloque bar { }. Los colores deben definirse en hexadecimal: #RRGGBB o #RRGGBBAA.

background <color>

Color de fondo de la barra.

statusline <color>

Color de texto que se utilizará para la línea de estado.

separator <color>

Color de texto que se utilizará para el separador.

focused_background <color>

Color de fondo de la barra en la salida del monitor actualmente enfocada. Si no se utiliza, el color se tomará de background.

focused_statusline <color>

Color de texto que se utilizará para la línea de estado en la salida del monitor actualmente enfocada. Si no se utiliza, el color se tomará de statusline.

focused_separator <color>

Color de texto que se utilizará para el separador en la salida del monitor actualmente enfocada. Si no se utiliza, el color se tomará de separator.

focused_workspace <border> <background> <text>

Color de borde, fondo y texto para un botón de espacio de trabajo cuando el espacio de trabajo tiene el foco.

active_workspace <border> <background> <text>

Color de borde, fondo y texto para un botón de espacio de trabajo cuando el espacio de trabajo está activo (visible) en alguna salida, pero el foco está en otra. Solo puedes diferenciar esto del espacio de trabajo enfocado cuando estás usando varios monitores.

inactive_workspace <border> <background> <text>

Color de borde, fondo y texto para un botón de espacio de trabajo cuando el espacio de trabajo no tiene el foco y no está activo (visible) en ninguna salida. Este será el caso de la mayoría de los espacios de trabajo.

urgent_workspace <border> <background> <text>

Color de borde, fondo y texto para un botón de espacio de trabajo cuando el espacio de trabajo contiene una ventana con la indicación de urgencia establecida.

binding_mode <border> <background> <text>

Color de borde, fondo y texto para el indicador del modo de enlace. Si no se utiliza, los colores se tomarán de urgent_workspace.
