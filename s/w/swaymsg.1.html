swaymsg(1) Manual de Comandos Generales swaymsg(1)

NOMBRE

swaymsg - Envía mensajes a una instancia en ejecución de sway a través del socket IPC.

SINOPSIS

swaymsg [opciones...] [mensaje]

OPCIONES

-h, --help

Muestra el mensaje de ayuda y sale.

-m, --monitor

Monitoriza las respuestas hasta que se mate en lugar de salir después de la primera respuesta. Esto solo se puede usar con el tipo de mensaje IPC subscribe. Si hay una respuesta mal formada o se solicitó un tipo de evento inválido, swaymsg dejará de monitorizar y saldrá.

-p, --pretty

Utiliza salida formateada ("pretty") incluso cuando no se usa una tty. No disponible para todos los tipos de mensajes.

-q, --quiet

Envía el mensaje IPC pero no imprime la respuesta de sway.

-r, --raw

Utiliza salida JSON sin formato ("raw") incluso si se usa una tty.

-s, --socket <ruta>

Utiliza la ruta del socket especificada. De lo contrario, swaymsg preguntará a sway dónde está el socket (que es el valor de $SWAYSOCK, y luego de $I3SOCK).

-t, --type <tipo>

Especifica el tipo de mensaje IPC. Ver más abajo.

-v, --version

Imprime la versión (de swaymsg) y sale.

TIPOS DE MENSAJE IPC

<comando>

El mensaje es un comando de sway (los mismos comandos que puedes vincular a atajos de teclado en tu archivo de configuración de sway). Se ejecutará inmediatamente.

Consulta sway(5) para ver una lista de comandos.

swaymsg puede devolver una salida formateada ("pretty") (predeterminada independiente) o con formato JSON (--raw). Para obtener documentación detallada sobre los datos JSON devueltos de cada tipo de mensaje que se enumera a continuación, consulta sway-ipc(7). El formato JSON puede contener más información que la salida formateada ("pretty").

Consejos:

  • La expansión de comandos se realiza dos veces: una vez por swaymsg y otra por sway. Si has entrecomillado cadenas de varias palabras en tu comando, encierra el comando completo entre comillas simples. Por ejemplo, usa swaymsg 'output "Pantalla Foobar" enable' en lugar de swaymsg output "Pantalla Foobar" enable. Además, ten en cuenta que las opciones separadas por comas también cuentan como cadenas de varias palabras, ya que las comas se pueden usar para ejecutar comandos en la misma línea.
  • Si estás proporcionando un comando que contiene un guion inicial (-), inserta dos guiones (--) antes del comando para indicar a swaymsg que no analice nada más allá de ese punto como una opción. Por ejemplo, usa swaymsg -- mark --add test en lugar de swaymsg mark --add test.

get_workspaces

Obtiene una lista de espacios de trabajo y su estado.

get_inputs

Obtiene una lista de las entradas actuales.

get_outputs

Obtiene una lista de las salidas actuales.

get_tree

Obtiene un árbol de diseño codificado en JSON de todas las ventanas abiertas, contenedores, salidas, espacios de trabajo, etc.

get_seats

Obtiene una lista de todos los asientos, sus propiedades y todos los dispositivos asignados.

get_marks

Obtiene una lista de marcas codificada en JSON.

get_bar_config

Obtiene la configuración codificada en JSON para swaybar.

get_version

Obtiene información de la versión de la instancia en ejecución de sway.

get_binding_modes

Obtiene una lista de modos de enlace actualmente configurados, codificada en JSON.

get_binding_state

Obtiene información codificada en JSON sobre el estado actual de los enlaces.

get_config

Obtiene una copia de la configuración actual. No expande las inclusiones.

send_tick

Envía un evento tick a todos los clientes suscritos.

subscribe

Suscríbete a una lista de tipos de eventos. El argumento para este tipo debe proporcionarse en forma de una matriz JSON válida. Si alguno de los tipos no es válido o no se proporciona una matriz JSON válida, esto resultará en un fallo. Para obtener una lista de tipos de eventos válidos y los datos devueltos con ellos, consulta sway-ipc(7).

CÓDIGOS DE RETORNO

0

Éxito

1

Errores de swaymsg, como sintaxis inválida, incapacidad para conectarse al socket ipc o incapacidad para analizar la respuesta de sway

2

Sway devolvió un error al procesar el comando (por ejemplo, comando inválido, comando fallido, solicitud de suscripción inválida)
