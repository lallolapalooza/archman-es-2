s2i_ASN1_IA5STRING(3ssl)

Paquete: openssl

Licencias: Apache-2.0

S2I_ASN1_IA5STRING(3ssl) OpenSSL S2I_ASN1_IA5STRING(3ssl)

NOMBRE

i2s_ASN1_IA5STRING, s2i_ASN1_IA5STRING, i2s_ASN1_INTEGER, s2i_ASN1_INTEGER, i2s_ASN1_OCTET_STRING, s2i_ASN1_OCTET_STRING, i2s_ASN1_ENUMERATED, i2s_ASN1_ENUMERATED_TABLE, i2s_ASN1_UTF8STRING, s2i_ASN1_UTF8STRING - convertir objetos desde/a representación ASN.1/cadena

SINOPSIS

#include <openssl/x509v3.h>
char *i2s_ASN1_IA5STRING(X509V3_EXT_METHOD *method, ASN1_IA5STRING *ia5);
ASN1_IA5STRING *s2i_ASN1_IA5STRING(X509V3_EXT_METHOD *method,
                                  X509V3_CTX *ctx, const char *str);
char *i2s_ASN1_INTEGER(X509V3_EXT_METHOD *method, const ASN1_INTEGER *a);
ASN1_INTEGER *s2i_ASN1_INTEGER(X509V3_EXT_METHOD *method, const char *value);
char *i2s_ASN1_OCTET_STRING(X509V3_EXT_METHOD *method,
                           const ASN1_OCTET_STRING *oct);
ASN1_OCTET_STRING *s2i_ASN1_OCTET_STRING(X509V3_EXT_METHOD *method,
                                        X509V3_CTX *ctx, const char *str);
char *i2s_ASN1_ENUMERATED(X509V3_EXT_METHOD *method, const ASN1_ENUMERATED *a);
char *i2s_ASN1_ENUMERATED_TABLE(X509V3_EXT_METHOD *method,
                               const ASN1_ENUMERATED *e);
char *i2s_ASN1_UTF8STRING(X509V3_EXT_METHOD *method,
                          ASN1_UTF8STRING *utf8);
ASN1_UTF8STRING *s2i_ASN1_UTF8STRING(X509V3_EXT_METHOD *method,
                                     X509V3_CTX *ctx, const char *str);

DESCRIPCIÓN

Estas funciones convierten objetos OpenSSL a y desde su representación ASN.1/cadena. Estas funciones se utilizan para extensiones de X509v3.

NOTAS

Las letras i y s en i2s y s2i significan "interno" (es decir, una estructura C interna) y cadena respectivamente. Por lo tanto, i2s_ASN1_IA5STRING() convierte de interno a cadena.

Es responsabilidad del llamador liberar la cadena devuelta. En la función i2s_ASN1_IA5STRING() la cadena se copia y la propiedad de la cadena original permanece con el llamador.

VALORES DE RETORNO

i2s_ASN1_IA5STRING() devuelve un puntero a una cadena IA5 o NULL si ocurre un error.

s2i_ASN1_IA5STRING() devuelve una estructura ASN1_IA5STRING válida o NULL si ocurre un error.

i2s_ASN1_INTEGER() devuelve una cadena válida o NULL si ocurre un error.

s2i_ASN1_INTEGER() devuelve un puntero a una estructura ASN1_INTEGER o NULL si ocurre un error.

i2s_ASN1_OCTET_STRING() devuelve un puntero a una cadena OCTET_STRING o NULL si ocurre un error.

s2i_ASN1_OCTET_STRING() devuelve una estructura ASN1_OCTET_STRING válida o NULL si ocurre un error.

i2s_ASN1_ENUMERATED() devuelve una cadena válida o NULL si ocurre un error.

s2i_ASN1_ENUMERATED() devuelve un puntero a una estructura ASN1_ENUMERATED o NULL si ocurre un error.

s2i_ASN1_UTF8STRING() devuelve una estructura ASN1_UTF8STRING válida o NULL si ocurre un error.

i2s_ASN1_UTF8STRING() devuelve un puntero a una cadena UTF-8 o NULL si ocurre un error.

HISTORIAL

i2s_ASN1_UTF8STRING() y s2i_ASN1_UTF8STRING() se hicieron públicas en OpenSSL 3.0.
