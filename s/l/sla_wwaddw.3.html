subrutina sla_wwaddw (n, x, y, w)
SLA_WWADDW agrega un vector a un vector de doble precisión.

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina sla_wwaddw (integer n, real, dimension( * ) x, real, dimension( * ) y, real, dimension( * ) w)

SLA_WWADDW agrega un vector W a un vector de doble precisión (X, Y).

Propósito:

!>
!>    SLA_WWADDW agrega un vector W a un vector de doble precisión (X, Y).
!>
!>    Esto funciona para toda la aritmética de punto flotante hexadecimal y binaria existente en IBM,
!>    pero no para la decimal.
!>

Parámetros

N 
!>          N es ENTERO
!>            La longitud de los vectores X, Y y W.
!>

X

!>          X es un array REAL, dimension (N)
!>            La primera parte del vector de acumulación de doble precisión.
!>

Y

!>          Y es un array REAL, dimension (N)
!>            La segunda parte del vector de acumulación de doble precisión.
!>

W

!>          W es un array REAL, dimension (N)
!>            El vector que se va a agregar.
!>
