SLAPD-PASSWD(5) Manual de Formatos de Archivo SLAPD-PASSWD(5)

NOMBRE

slapd-passwd - backend de /etc/passwd para slapd

SINOPSIS

/etc/openldap/slapd.conf

DESCRIPCIÓN

El backend PASSWD de slapd(8) sirve la información de cuentas de usuario listada en el archivo passwd(5) del sistema. Este backend se proporciona solo para fines de demostración. El DN de cada entrada es "uid=<nombredeusuario>,<sufijo>". Tenga en cuenta que las búsquedas que no son de base escanean todo el archivo passwd, y son más adecuadas para hosts con archivos passwd pequeños.

CONFIGURACIÓN

Esta opción de slapd.conf se aplica a la base de datos del backend PASSWD. Es decir, debe seguir una línea "database passwd" y aparecer antes de cualquier línea posterior de "backend" o "database". Otras opciones de base de datos se describen en el manual de slapd.conf(5).

archivo <nombre_archivo>
Especifica un archivo passwd alternativo a utilizar. El predeterminado es /etc/passwd.

CONTROL DE ACCESO

El backend passwd no respeta ninguna de las semánticas de control de acceso descritas en slapd.access(5). Solo se respeta el acceso de lectura (=r) al pseudo-atributo entry y a los valores de otros atributos de las entradas devueltas por la operación search, que es realizada por el frontend.

ARCHIVOS

/etc/openldap/slapd.conf
archivo de configuración predeterminado de slapd
/etc/passwd
información de cuentas de usuario

VER TAMBIÉN

slapd.conf(5), slapd(8), passwd(5).
