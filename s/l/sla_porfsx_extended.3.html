SLA_PORFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices simétricas o Hermitianas definidas positivas realizando un refinamiento iterativo de precisión extra y proporciona límites de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!> SLA_PORFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión extra
!> y proporciona límites de error y estimaciones de error hacia atrás para la
!> solución.
!> Esta subrutina es llamada por SPORFSX para realizar el refinamiento iterativo.
!> Además del límite de error normwise, el código proporciona el límite de error
!> máximo por componentes si es posible. Véase los comentarios para
!> ERR_BNDS_NORM y ERR_BNDS_COMP para detalles de los límites de error.
!> Tenga en cuenta que esta subrutina solo es responsable de establecer los
!> segundos campos de ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a ser utilizada en el refinamiento.
!>     El valor está definido por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array REAL, dimensión (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, tal como fue calculado por SPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces la equilibración de columnas se realizó en A antes de
!>     llamar a esta rutina. Esto es necesario para calcular la solución y los
!>     límites de error correctamente.
!>

C

!>          C es array REAL, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si se ingresa C, cada elemento de C debe ser una potencia
!>     de la base para asegurar una solución y estimaciones de error fiables.
!>     La escala por potencias de la base no causa errores de redondeo a menos
!>     que el resultado sea un subdesbordamiento o desbordamiento. Los errores
!>     de redondeo durante la escala conducen a un refinamiento con una matriz
!>     que no es equivalente a la matriz de entrada, produciendo estimaciones
!>     de error que pueden no ser fiables.
!>

B

!>          B es array REAL, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es array REAL, dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como fue calculada por SPOTRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es array REAL, dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error relativo residual por
!>     componentes para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto por componentes de la matriz
!>     o vector Z. Esto es calculado por SLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué límites de error devolver (ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve límites de error normwise.
!>     Si N_NORMS >= 2 devuelve límites de error por componentes.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error tal como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confía en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error
!>              verdadero, siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimado normwise
!>              número de condición recíproco. Comparado con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la estimación de
!>              error es. Estos números de condición recíprocos son
!>              1 / (norm(Z^{-1},inf) * norm(Z,inf)) para s

NAME

SLA_PORFSX_EXTENDED —

SYNOPSIS

Use the following subroutines in each of the other supported languages:

Fortran:

    SUBROUTINE SLA_PORFSX_EXTENDED( UPLO, N, NRHS, A, LDA, AFAC, LDAFAC,
                                    IPIV, B, LDB, X, LDX, FERR, BERR,
                                    INFO, RPARM, CWARN )

Function/Subroutine Documentation

SLA_PORFSX_EXTENDED uses the decomposition of A in AFAC to compute an error estimate for each solution to a linear system

    A*X = B

where A is a real upper or lower triangular matrix and X and B are real matrices. The estimates are computed for the componentwise error bounds:

    infinity-norm( abs(A*X - B) ) / infinity-norm( B )

and

    infinity-norm( abs(A*X - B) ) / ( infinity-norm( A )*infinity-norm( X ) )

The solution X is computed by repeatedly calling the subroutine SLA_PORFS.

Parameters:

UPLO
CHARACTER*1.

= 'U': A is upper triangular.

= 'L': A is lower triangular.

N
INTEGER.

The order of the matrix A. N >= 0.

NRHS
INTEGER.

The number of columns of the matrices B, X, FERR, and BERR. NRHS >= 1.

A
REAL array, dimension (LDA,N).

The original upper or lower triangular matrix A.

LDA
INTEGER.

The leading dimension of the array A. LDA >= max(1, N).

AFAC
REAL array, dimension (LDAFAC,N).

The factors of A, as computed by SPOTRF.

LDAFAC
INTEGER.

The leading dimension of the array AFAC. LDAFAC >= max(1, N).

IPIV
INTEGER array, dimension (N).

The pivot indices from the factorization. Only an upper triangular matrix is stored in AFAC.

B
REAL array, dimension (LDB,NRHS).

The right-hand side matrix B.

LDB
INTEGER.

The leading dimension of the array B. LDB >= max(1, N).

X
REAL array, dimension (LDX,NRHS).

On entry, the solution matrix X, as computed by SPOTRS. On exit, the solution matrix X will be overwritten by the improved solution matrix.

LDX
INTEGER.

The leading dimension of the array X. LDX >= max(1, N).

FERR
REAL array, dimension (NRHS).

On exit, FERR(j) contains an estimate of the relative error in the j-th solution X. It is the upper bound on the relative error between X and XTRUE, and is computed by:

FERR(j) = inf-norm( abs(AX-B) ) / inf-norm( B )

where inf-norm( Z ) = max_i( sum_j( abs(Z_ij) ) ).

This error bound is only computed if PARAMS(3) = 1.0. Otherwise, FERR is not accessed.

BERR
REAL array, dimension (NRHS).

On exit, BERR(j) contains the relative error in the j-th solution X in the 1-norm.

BERR(j) = inf-norm( abs(AX-B) ) / ( inf-norm( A ) * inf-norm( X ) )

This error bound is only computed if PARAMS(3) = 1.0. Otherwise, BERR is not accessed.

INFO
INTEGER.

= 0: Successful exit.

< 0: If INFO = -i, then the i-th argument to the subroutine was illegal.

RPARM
REAL array, dimension (N_RPARM).

Optional parameters. N_RPARM is the dimension of the array.

Currently, the following parameters are supported:

RPARM(1): Threshold for componentwise error bound. If 0.0, componentwise error bounds are not computed.

RPARM(2): Threshold for reciprocal condition number. If 0.0, reciprocal condition numbers are not computed.

RPARM(3): Controls equilibration. If 0.0, equilibration is not performed. If 1.0, equilibration is performed.

RPARM(4): Threshold for equilibration. If the maximum absolute row sum is greater than this value, equilibration is performed.

RPARM(5): Tolerance for the componentwise error bound. If 0.0, the default value of 0.25 is used.

RPARM(6): Tolerance for the reciprocal condition number. If 0.0, the default value of sqrt(N) * slamch('Epsilon') is used.

RPARM(7): Tolerance for the reciprocal scaled condition number. If 0.0, the default value of sqrt(N) * slamch('Epsilon') is used.

RPARM(8): Tolerance for the forward error estimate. If 0.0, the default value of 10.0 is used.

RPARM(9): Maximum number of iterative refinement steps. If 0.0, the default value of 10 is used.

RPARM(10): Threshold for stopping iterative refinement. If 0.0, the default value of 0.5 is used.

RPARM(11): Threshold for componentwise convergence. If 0.0, the default value of 0.25 is used.

RPARM(12): Controls whether to ignore componentwise convergence. If 1.0, componentwise convergence is ignored. If 0.0, it is considered.

CWARN
REAL array, dimension (NRHS).

On exit, CWARN(j) contains a warning flag for the j-th solution. The possible values are:

0.0: The solution is not significantly inaccurate.

1.0: The solution is significantly inaccurate.

This flag is computed based on the reciprocal condition number and the forward error estimate.
