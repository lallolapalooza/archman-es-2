NOMBRE

slapd-collations.conf - Contiene las etiquetas de idioma y OID utilizadas en 389 Directory Server.

SINOPSIS

/etc/dirsrv/config/slapd-collations.conf

DESCRIPCIÓN

slapd-collations.conf

Este archivo contiene todas las reglas de ordenación (etiquetas y OID) que utiliza el Directorio del Servidor.

SINTAXIS

collation
Este parámetro se presenta de la siguiente manera: idioma, país, variante, fuerza, descomposición, oid, oid ...

EJEMPLO

collation "" "" "" 1 3 2.16.840.1.113730.3.3.2.0.1 default
collation ar "" "" 1 3 2.16.840.1.113730.3.3.2.1.1 ar
collation be "" "" 1 3 2.16.840.1.113730.3.3.2.2.1 be be-BY
...
...
