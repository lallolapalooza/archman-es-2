Documentación de la Función/Subrutina

subrutina slarnv (integer idist, integer, dimension( 4 ) iseed, integer n, real, dimension( * ) x)

SLARNV devuelve un vector de números reales aleatorios de una distribución uniforme o normal.

Propósito:

!>
!> SLARNV devuelve un vector de n números reales aleatorios de una distribución
!> uniforme o normal.
!>

Parámetros

IDIST 
!>          IDIST es INTEGER
!>          Especifica la distribución de los números aleatorios:
!>          = 1:  uniforme (0,1)
!>          = 2:  uniforme (-1,1)
!>          = 3:  normal (0,1)
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios; los
!>          elementos del array deben estar entre 0 y 4095, e ISEED(4) debe
!>          ser impar.
!>          En la salida, la semilla se actualiza.
!>

N

!>          N es INTEGER
!>          El número de números aleatorios a generar.
!>

X

!>          X es un array REAL, dimensión (N)
!>          Los números aleatorios generados.
!>

Univ. de Tennessee

Univ. de California Berkeley

Univ. de Colorado Denver

Detalles adicionales:

!>
!>  Esta rutina llama a la rutina auxiliar SLARUV para generar números
!>  reales aleatorios de una distribución uniforme (0,1), en lotes de hasta
!>  128 utilizando código vectorizable. El método de Box-Muller se utiliza para
!>  transformar números de una distribución uniforme a una normal.
!>
