subroutine slatbs (character uplo, character trans, character diag, character normin, integer n, integer kd, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) x, real scale, real, dimension( * ) cnorm, integer info)

SLATBS resuelve un sistema triangular de ecuaciones de banda.

Propósito:

!>
!> SLATBS resuelve uno de los sistemas triangulares
!>
!>    A *x = s*b  o  A**T*x = s*b
!>
!> con escalado para prevenir desbordamientos, donde A es una matriz de banda
!> triangular superior o inferior. Aquí A**T denota la transpuesta de A, x e b
!> son vectores de n elementos, y s es un factor de escalado, usualmente menor
!> o igual a 1, elegido de modo que los componentes de x sean menores que
!> el umbral de desbordamiento. Si el problema no escalado no causa
!> desbordamiento, se llama a la rutina BLAS de nivel 2 STBSV. Si la matriz A
!> es singular (A(j,j) = 0 para algún j), entonces s se establece a 0 y se
!> devuelve una solución no trivial para A*x = 0.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resolver A * x = s*b  (Sin transpuesta)
!>          = 'T':  Resolver A**T* x = s*b  (Transpuesta)
!>          = 'C':  Resolver A**T* x = s*b  (Transpuesta conjugada = Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

NORMIN

!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM ha sido establecido o no.
!>          = 'Y':  CNORM contiene las normas de las columnas en la entrada
!>          = 'N':  CNORM no está establecido en la entrada. A la salida, las normas
!>                  serán calculadas y almacenadas en CNORM.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de subdiagonales o superdiagonales en la
!>          matriz triangular A.  KD >= 0.
!>

AB

!>          AB es array REAL, dimension (LDAB,N)
!>          La matriz de banda triangular superior o inferior A, almacenada en las
!>          primeras KD+1 filas del array. La j-ésima columna de A se almacena
!>          en la j-ésima columna del array AB como sigue:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd) <= i <= j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j <= i <= min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

X

!>          X es array REAL, dimension (N)
!>          En la entrada, el lado derecho b del sistema triangular.
!>          A la salida, X se sobrescribe con el vector solución x.
!>

SCALE

!>          SCALE es REAL
!>          El factor de escalado s para el sistema triangular
!>             A * x = s*b  o  A**T* x = s*b.
!>          Si SCALE = 0, la matriz A es singular o mal escalada, y
!>          el vector x es una solución exacta o aproximada de A*x = 0.
!>

CNORM

!>          CNORM es array REAL, dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene las normas de la parte no diagonal de la j-ésima columna
!>          de A. Si TRANS = 'N', CNORM(j) debe ser mayor o igual a la norma
!>          del infinito, y si TRANS = 'T' o 'C', CNORM(j)
!>          debe ser mayor o igual a la norma 1.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la norma 1 de la parte no diagonal de la j-ésima columna
!>          de A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>

Detalles adicionales:

!>
!> Se calcula un límite aproximado para x; si es menor que el desbordamiento,
!> se llama a STBSV, de lo contrario, se utiliza un código específico que
!> comprueba si hay posibles desbordamientos o divisiones por cero en cada
!> operación.
!>
!> Se utiliza un esquema columna a columna para resolver A*x = b. El algoritmo
!> básico si A es triangular inferior es
!>
!>       x[1:n] := b[1:n]
!>       para j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!> Definimos límites para los componentes de x después de j iteraciones del bucle:
!>     M(j) = límite para x[1:j]
!>     G(j) = límite para x[j+1:n]
!> Inicialmente, sea M(0) = 0 y G(0) = max{x(i), i=1,...,n}.
!>
!> Entonces para la iteración j+1 tenemos
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> donde CNORM(j+1) es mayor o igual a la norma del infinito de la
!> columna j+1 de A, sin contar la diagonal. Por lo tanto
!>
!>     G(j) <= G(0) producto ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> y
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) producto ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> Como |x(j)| <= M(j), usamos la rutina BLAS de nivel 2 STBSV si el
!> recíproco del M(j) más grande, j=1,..,n, es mayor que
!> max(underflow, 1/overflow).
!>
!> El límite para x(j) también se usa para determinar cuándo se puede realizar
!> un paso en el método columna a columna sin temor a desbordamientos. Si
!> el límite calculado es mayor que una constante grande, x se escala para
!> prevenir desbordamientos, pero si el límite causa desbordamiento, x se
!> establece a 0, x(j) a 1, y scale a 0, y se encuentra una solución no
!> trivial para A*x = 0.
!>
!> De manera similar, se utiliza un esquema fila a fila para resolver A**T*x = b. El
!> algoritmo básico para A triangular superior es
!>
!>       para j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]**T * x[1:j-1] ) / A(j,j)
!>       fin
!>
!> Calculamos simultáneamente dos límites
!>       G(j) = límite para ( b(i) - A[1:i-1,i]**T * x[1:i-1] ), 1<=i<=j
!>       M(j) = límite para x(i), 1<=i<=j
!>
!> Los valores iniciales son G(0) = 0, M(0) = max{b(i), i=1,..,n}, y añadimos la
!> restricción G(j) >= G(j-1) y M(j) >= M(j-1) para j >= 1.
!> Entonces el límite para x(j) es
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * producto ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> y podemos llamar de forma segura a STBSV si 1/M(n) y 1/G(n) son ambos mayores
!> que max(underflow, 1/overflow).
!>
