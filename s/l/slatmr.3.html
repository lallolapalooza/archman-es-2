subrutina slatmr (entero m, entero n, carácter dist, entero, dimensión( 4 ) iseed, carácter sym, real, dimensión( * ) d, entero mode, real cond, real dmax, carácter rsign, carácter grade, real, dimensión( * ) dl, entero model, real condl, real, dimensión( * ) dr, entero moder, real condr, carácter pivtng, entero, dimensión( * ) ipivot, entero kl, entero ku, real sparse, real anorm, carácter pack, real, dimensión( lda, * ) a, entero lda, entero, dimensión( * ) iwork, entero info)

SLATMR

Propósito:

!>
!>    SLATMR genera matrices aleatorias de varios tipos para probar
!>    programas LAPACK.
!>
!>    SLATMR opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Generar una matriz A con entradas aleatorias de distribución DIST
!>         que es simétrica si SYM='S', y no simétrica
!>         si SYM='N'.
!>
!>      Establecer la diagonal a D, donde D puede ser de entrada o
!>         calculada según MODE, COND, DMAX y RSIGN
!>         como se describe a continuación.
!>
!>      Calificar la matriz, si se desea, desde la izquierda y/o derecha
!>         como se especifica en GRADE. Las entradas DL, MODEL, CONDL, DR,
!>         MODER y CONDR también determinan la calificación como se describe
!>         a continuación.
!>
!>      Permutar, si se desea, las filas y/o columnas como se especifica en
!>         PIVTNG e IPIVOT.
!>
!>      Establecer entradas aleatorias a cero, si se desea, para obtener una matriz aleatoria dispersa
!>         como se especifica en SPARSE.
!>
!>      Hacer que A sea una matriz de banda, si se desea, poniendo a cero la matriz
!>         fuera de una banda de ancho inferior KL y ancho superior KU.
!>
!>      Escalar A, si se desea, para que tenga una entrada máxima ANORM.
!>
!>      Empaquetar la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetado
!>         poner a cero la mitad superior (si es simétrica)
!>         poner a cero la mitad inferior (si es simétrica)
!>         almacenar la mitad superior columna a columna (si es simétrica o
!>             triangular superior cuadrada)
!>         almacenar la mitad inferior columna a columna (si es simétrica o
!>             triangular inferior cuadrada)
!>             igual que la mitad superior fila a fila si es simétrica
!>         almacenar el triángulo inferior en formato de banda (si es simétrica)
!>         almacenar el triángulo superior en formato de banda (si es simétrica)
!>         almacenar toda la matriz en formato de banda
!>
!>    Nota: Si dos llamadas a SLATMR difieren solo en el parámetro PACK,
!>          generarán matrices matemáticamente equivalentes.
!>
!>          Si dos llamadas a SLATMR tienen ambas ancho de banda completo (KL = M-1
!>          y KU = N-1), y difieren solo en los parámetros PIVTNG y PACK,
!>          entonces las matrices generadas diferirán solo
!>          en el orden de las filas y/o columnas, y por lo demás
!>          contendrán los mismos datos. Esta consistencia no se mantiene
!>          con un ancho de banda menor al completo y no se pretende mantener.
!>

Parámetros

M 
!>          M es ENTERO
!>           Número de filas de A. No modificado.
!>

N

!>          N es ENTERO
!>           Número de columnas de A. No modificado.
!>

DIST

!>          DIST es CARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución a utilizar
!>           para generar una matriz aleatoria.
!>           'U' => UNIFORME( 0, 1 )  ( 'U' para uniforme )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' para simétrica )
!>           'N' => NORMAL( 0, 1 )   ( 'N' para normal )
!>           No modificado.
!>

ISEED

!>          ISEED es un array de ENTEROS, dimensión (4)
!>           En la entrada, ISEED especifica la semilla del generador de números
!>           aleatorios. Deberían estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números
!>           aleatorios utiliza una secuencia congruencial lineal limitada a enteros
!>           pequeños, y por lo tanto debería producir números aleatorios independientes de la máquina.
!>           Los valores de ISEED se modifican al salir, y pueden ser utilizados en la siguiente llamada
!>           a SLATMR para continuar la misma secuencia de números aleatorios.
!>           Modificado al salir.
!>

SYM

!>          SYM es CARACTER*1
!>           Si SYM='S' o 'H', la matriz generada es simétrica.
!>           Si SYM='N', la matriz generada es no simétrica.
!>           No modificado.
!>

D

!>          D es un array de REALES, dimensión (min(M,N))
!>           En la entrada, este array especifica las entradas de la diagonal
!>           de la diagonal de A. D puede ser especificada
!>           en la entrada, o establecida según MODE y COND como se describe
!>           a continuación. Puede ser modificado a la salida si MODE es distinto de cero.
!>

MODE

!>          MODE es ENTERO
!>           En la entrada describe cómo se usará D:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           No modificado.
!>

COND

!>          COND es REAL
!>           En la entrada, se usa como se describe en MODE arriba.
!>           Si se usa, debe ser >= 1. No modificado.
!>

DMAX

!>          DMAX es REAL
!>           Si MODE no es -6, 0 ni 6, la diagonal se escala por
!>           DMAX / max(abs(D(i))), de modo que la entrada absoluta máxima
!>           de la diagonal sea abs(DMAX). Si DMAX es negativo (o cero),
!>           la diagonal se escalará por un número negativo (o cero).
!>

RSIGN

!>          RSIGN es CARACTER*1
!>           Si MODE no es -6, 0 ni 6, especifica el signo de la diagonal
!>           como sigue:
!>           'T' => las entradas de la diagonal se multiplican por 1 o -1
!>                  con probabilidad 0.5
!>           'F' => diagonal sin cambios
!>           No modificado.
!>

GRADE

!>          GRADE es CARACTER*1
!>           Especifica la calificación de la matriz como sigue:
!>           'N'  => sin calificación
!>           'L'  => matriz premultiplicada por diag( DL )
!>                   (solo si la matriz es no simétrica)
!>           'R'  => matriz postmultiplicada por diag( DR )
!>                   (solo si la matriz es no simétrica)
!>           'B'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>                   (solo si la matriz es no simétrica)
!>           'S' o 'H'  => matriz premultiplicada por diag( DL ) y
!>                          postmultiplicada por diag( DL )
!>                          ('S' para simétrica, o 'H' para Hermitiana)
!>           'E'  => matriz premultiplicada por diag( DL ) y
!>

NAME

SLATMR - Generates a standard test matrix in the JLAPACK convention.

SYNOPSIS

SUBROUTINE SLATMR(
    M, N, DIST, D, DL, MODEL, CONDL, DR, MODER, CONDR, GRADE, PIVTNG,
    IPIVOT, KL, KU, SPARSE, ANORM, PACK, A, LDA, IWORK, INFO
    )
M
INTEGER. Number of rows of the matrix A.
N
INTEGER. Number of columns of the matrix A.
DIST
CHARACTER*1. Specifies the distribution to be used for the singular values or eigenvalues.
D
REAL array, dimension (min(M,N)). On entry, specifies the diagonal entries of a diagonal matrix used for singular values or eigenvalues. On exit, these values may be modified according to MODE and COND.
DL
REAL array, dimension (M). On entry, specifies the diagonal entries of a diagonal matrix used for scaling.
MODEL
INTEGER. Specifies how the diagonal array DL is to be computed.
CONDL
REAL. Specifies the condition number of the computed DL.
DR
REAL array, dimension (N). On entry, specifies the diagonal entries of a diagonal matrix used for scaling.
MODER
INTEGER. Specifies how the diagonal array DR is to be computed.
CONDR
REAL. Specifies the condition number of the computed DR.
GRADE
CHARACTER*1. Specifies the grade of the matrix to be generated.
PIVTNG
CHARACTER*1. Specifies pivoting permutations.
IPIVOT
INTEGER array, dimension (N or M). Specifies the permutation used.
KL
INTEGER. Specifies the lower bandwidth of the matrix.
KU
INTEGER. Specifies the upper bandwidth of the matrix.
SPARSE
REAL. Specifies the sparsity of the matrix.
ANORM
REAL. Specifies the maximum absolute entry of the output matrix.
PACK
CHARACTER*1. Specifies the packing of the matrix.
A
REAL array, dimension (LDA,N). On exit, A is the desired test matrix.
LDA
INTEGER. Specifies the first dimension of A.
IWORK
INTEGER array, dimension (N or M). Workspace.
INFO
INTEGER. Error parameter on exit.

PURPOSE

SLATMR generates a standard test matrix A(M,N) in the JLAPACK convention. It is intended to be used primarily by the LAPACK test routines. The generated matrix has properties that can be controlled by the user, such as:

  • Singular values or eigenvalues (DIST, D, MODE, COND)
  • Condition number (COND)
  • Bandwidth (KL, KU)
  • Sparsity (SPARSE)
  • Norm (ANORM)
  • Packing format (PACK)
  • Pivoting (PIVTNG, IPIVOT)
  • Grade of the matrix (GRADE, DL, MODEL, CONDL, DR, MODER, CONDR)

ARGUMENTS

M

INTEGER

       Number of rows of the matrix A.
N

INTEGER

       Number of columns of the matrix A.
DIST

CHARACTER*1

       Specifies the distribution to be used for the singular values
       or eigenvalues.
       'U' => Uniform distribution
       'S' => Sine distribution
       'E' => Exponential distribution
       'D' => Diagonal matrix (Singular values or eigenvalues are D)
       'N' => Not used
       Not modified.
D

REAL array, dimension (min(M,N))

       On entry, specifies the diagonal entries of a diagonal matrix
       used for singular values or eigenvalues.
       If DIST = 'D', then D is used to set the singular values or
       eigenvalues.
       If DIST is not 'D', then D is used as a template for generating
       the singular values or eigenvalues according to DIST, MODE, and
       COND. The generation is analogous to the generation of DL and
       DR.
       If GRADE = 'E', then D cannot have zero entries.
DL

REAL array, dimension (M)

       If MODEL=0, then on entry this array specifies the diagonal
       entries of a diagonal matrix used as described under GRADE
       above. If MODEL is not zero, then DL will be set according
       to MODEL and CONDL, analogous to the way D is set according
       to MODE and COND (except there is no DMAX parameter for DL).
       If GRADE='E', then DL cannot have zero entries.
       Not referenced if GRADE = 'N' or 'R'. Changed on exit.
MODEL

INTEGER

       This specifies how the diagonal array DL is to be computed,
       just as MODE specifies how D is to be computed.
       Not modified.
CONDL

REAL

       When MODEL is not zero, this specifies the condition number
       of the computed DL. Not modified.
DR

REAL array, dimension (N)

       If MODER=0, then on entry this array specifies the diagonal
       entries of a diagonal matrix used as described under GRADE
       above. If MODER is not zero, then DR will be set according
       to MODER and CONDR, analogous to the way D is set according
       to MODE and COND (except there is no DMAX parameter for DR).
       Not referenced if GRADE = 'N', 'L', 'H', 'S' or 'E'.
       Changed on exit.
MODER

INTEGER

       This specifies how the diagonal array DR is to be computed,
       just as MODE specifies how D is to be computed.
       Not modified.
CONDR

REAL

       When MODER is not zero, this specifies the condition number
       of the computed DR. Not modified.
GRADE

CHARACTER*1

       Specifies the grade of the matrix to be generated.
       'N' => None (matrix generated by DIST, D, MODE, COND)
       'L' => Lower triangular matrix (generated from DL, MODEL, CONDL)
       'R' => Upper triangular matrix (generated from DR, MODER, CONDR)
       'B' => Both lower and upper triangular (generated from DL, DR)
       'H' => The matrix A is generated by applying DL and DR to the
              diagonal of a matrix that has been generated by DIST,
              D, MODE, COND.
       'S' => The matrix A is generated by applying DL and DR to the
              diagonal of a matrix that has been generated by DIST,
              D, MODE, COND, and then postmultiplied by inv( diag( DL ) )
              ( 'E' for eigenvalue invariance)
              (only if matrix nonsymmetric)
              Note: if GRADE='E', then M must equal N.
              Not modified.
PIVTNG

CHARACTER*1

       On entry specifies pivoting permutations as follows:
       'N' or ' ' => none.
       'L' => left or row pivoting (matrix must be nonsymmetric).
       'R' => right or column pivoting (matrix must be
              nonsymmetric).
       'B' or 'F' => both or full pivoting, i.e., on both sides.
                     In this case, M must equal N
       If two calls to SLATMR both have full bandwidth (KL = M-1
       and KU = N-1), and differ only in the PIVTNG and PACK
       parameters, then the matrices generated will differ only
       in the order of the rows and/or columns, and otherwise
       contain the same data. This consistency cannot be
       maintained with less than full bandwidth.
IPIVOT

INTEGER array, dimension (N or M)

       This array specifies the permutation used. After the
       basic matrix is generated, the rows, columns, or both
       are permuted. If, say, row pivoting is selected, SLATMR
       starts with the *last* row and interchanges the M-th and
       IPIVOT(M)-th rows, then moves to the next-to-last row,
       interchanging the (M-1)-th and the IPIVOT(M-1)-th rows,
       and so on. In terms of , the permutation is
       (1 IPIVOT(1)) (2 IPIVOT(2)) ... (M IPIVOT(M))
       where the rightmost cycle is applied first. This is the
       *inverse* of the effect of pivoting in LINPACK. The idea
       is that factoring (with pivoting) an identity matrix
       which has been inverse-pivoted in this way should
       result in a pivot vector identical to IPIVOT.
       Not referenced if PIVTNG = 'N'. Not modified.
KL

INTEGER

       On entry specifies the lower bandwidth of the matrix. For
       example, KL=0 implies upper triangular, KL=1 implies upper
       Hessenberg, and KL at least M-1 implies the matrix is not
       banded. Must equal KU if matrix is symmetric.
       Not modified.
KU

INTEGER

       On entry specifies the upper bandwidth of the matrix. For
       example, KU=0 implies lower triangular, KU=1 implies lower
       Hessenberg, and KU at least N-1 implies the matrix is not
       banded. Must equal KL if matrix is symmetric.
       Not modified.
SPARSE

REAL

       On entry specifies the sparsity of the matrix if a sparse
       matrix is to be generated. SPARSE should lie between
       0 and 1. To generate a sparse matrix, for each matrix entry
       a uniform ( 0, 1 ) random number x is generated and
       compared to SPARSE; if x is larger the matrix entry
       is unchanged and if x is smaller the entry is set
       to zero. Thus on the average a fraction SPARSE of the
       entries will be set to zero.
       Not modified.
ANORM

REAL

       On entry specifies maximum entry of output matrix
       (output matrix will by multiplied by a constant so that
       its largest absolute entry equal ANORM)
       if ANORM is nonnegative. If ANORM is negative no scaling
       is done. Not modified.
PACK

CHARACTER*1

       On entry specifies packing of matrix as follows:
       'N' => no packing
       'U' => zero out all subdiagonal entries (if symmetric)
       'L' => zero out all superdiagonal entries (if symmetric)
       'C' => store the upper triangle columnwise
              (only if matrix symmetric or square upper triangular)
       'R' => store the lower triangle columnwise
              (only if matrix symmetric or square lower triangular)
              (same as upper half rowwise if symmetric)
       'B' => store the lower triangle in band storage scheme
              (only if matrix symmetric)
       'Q' => store the upper triangle in band storage scheme
              (only if matrix symmetric)
       'Z' => store the entire matrix in band storage scheme
                  (pivoting can be provided for by using this
                  option to store A in the trailing rows of
                  the allocated storage)
       Using these options, the various LAPACK packed and banded
       storage schemes can be obtained:
       GB               - use 'Z'
       PB, SB or TB     - use 'B' or 'Q'
       PP, SP or TP     - use 'C' or 'R'
       If two calls to SLATMR differ only in the PACK parameter,
       they will generate mathematically equivalent matrices.
       Not modified.
A

REAL array, dimension (LDA,N)

       On exit A is the desired test matrix. Only those
       entries of A which are significant on output
       will be referenced (even if A is in packed or band
       storage format). The 'unoccupied corners' of A in
       band format will be zeroed out.
LDA

INTEGER

       on entry LDA specifies the first dimension of A as
       declared in the calling program.
       If PACK='N', 'U' or 'L', LDA must be at least max ( 1, M ).
       If PACK='C' or 'R', LDA must be at least 1.
       If PACK='B', or 'Q', LDA must be MIN ( KU+1, N )
       If PACK='Z', LDA must be at least KUU+KLL+1, where
       KUU = MIN ( KU, N-1 ) and KLL = MIN ( KL, M-1 )
       Not modified.
IWORK

INTEGER array, dimension ( N or M)

       Workspace. Not referenced if PIVTNG = 'N'. Changed on exit.
INFO

INTEGER

       Error parameter on exit:
         0 => normal return
        -1 => M negative or unequal to N and SYM='S' or 'H'
        -2 => N negative
        -3 => DIST illegal string
        -5 => SYM illegal string
        -7 => MODE not in range -6 to 6
        -8 => COND less than 1.0, and MODE neither -6, 0 nor 6
       -10 => MODE neither -6, 0 nor 6 and RSIGN illegal string
       -11 => GRADE illegal string, or GRADE='E' and
              M not equal to N, or GRADE='L', 'R', 'B' or 'E' and
              SYM = 'S' or 'H'
       -12 => GRADE = 'E' and DL contains zero
       -13 => MODEL not in range -6 to 6 and GRADE= 'L', 'B', 'H',
              'S' or 'E'
       -14 => CONDL less than 1.0, GRADE='L', 'B', 'H', 'S' or 'E',
              and MODEL neither -6, 0 nor 6
       -16 => MODER not in range -6 to 6 and GRADE= 'R' or 'B'
       -17 => CONDR less than 1.0, GRADE='R' or 'B', and
              MODER neither -6, 0 nor 6
       -18 => PIVTNG illegal string, or PIVTNG='B' or 'F' and
              M not equal to N, or PIVTNG='L' or 'R' and SYM='S'
              or 'H'
       -19 => IPIVOT contains out of range number and
              PIVTNG not equal to 'N'
       -20 => KL negative
       -21 => KU negative, or SYM='S' or 'H' and KU not equal to KL
       -22 => SPARSE not in range 0. to 1.
       -24 => PACK illegal string, or PACK='U', 'L', 'B' or 'Q'
              and SYM='N', or PACK='C' and SYM='N' and either KL
              not equal to 0 or N not equal to M, or PACK='R' and
              SYM='N', and either KU not equal to 0 or N not
              equal to M
       -26 => LDA too small
         1 => Error return from SLATM1 (computing D)
         2 => Cannot scale diagonal to DMAX (max. entry is 0)
         3 => Error return from SLATM1 (computing DL)
         4 => Error return from SLATM1 (computing DR)
         5 => ANORM is positive, but matrix constructed prior to
              attempting to scale it to have norm ANORM, is zero
