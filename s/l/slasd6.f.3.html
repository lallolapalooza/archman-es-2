subroutine slasd6 (integer icompq, integer nl, integer nr, integer sqre, real, dimension( * ) d, real, dimension( * ) vf, real, dimension( * ) vl, real alpha, real beta, integer, dimension( * ) idxq, integer, dimension( * ) perm, integer givptr, integer, dimension( ldgcol, * ) givcol, integer ldgcol, real, dimension( ldgnum, * ) givnum, integer ldgnum, real, dimension( ldgnum, * ) poles, real, dimension( * ) difl, real, dimension( * ) difr, real, dimension( * ) z, integer k, real c, real s, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLASD6 calcula la SVD de una matriz bidiagonal superior actualizada obtenida al fusionar dos más pequeñas añadiendo una fila. Utilizada por sbdsdc.

Propósito:

!>
!> SLASD6 calcula la SVD de una matriz bidiagonal superior actualizada B
!> obtenida al fusionar dos más pequeñas añadiendo una fila. Esta
!> subrutina se utiliza solo para el problema que requiere todos los valores
!> singulares y opcionalmente las matrices de vectores singulares en forma factorizada.
!> B es una matriz N por M con N = NL + NR + 1 y M = N + SQRE.
!> Una subrutina relacionada, SLASD1, maneja el caso en el que se desean todos los valores
!> singulares y vectores singulares de la matriz bidiagonal.
!>
!> SLASD6 calcula la SVD de la siguiente manera:
!>
!>               ( D1(in)    0    0       0 )
!>   B = U(in) * (   Z1**T   a   Z2**T    b ) * VT(in)
!>               (   0       0   D2(in)   0 )
!>
!>     = U(out) * ( D(out) 0) * VT(out)
!>
!> donde Z**T = (Z1**T a Z2**T b) = u**T VT**T, y u es un vector de dimensión M
!> con ALPHA y BETA en las entradas NL+1 y NL+2 y ceros
!> en otras partes; y la entrada b está vacía si SQRE = 0.
!>
!> Los valores singulares de B se pueden calcular utilizando D1, D2, los primeros
!> componentes de todos los vectores singulares derechos del bloque inferior, y
!> los últimos componentes de todos los vectores singulares derechos del bloque superior.
!> Estos componentes se almacenan y actualizan en VF y VL,
!> respectivamente, en SLASD6. Por lo tanto, U y VT no se referencian explícitamente.
!>
!> Los valores singulares se almacenan en D. El algoritmo consta de dos
!> etapas:
!>
!>       La primera etapa consiste en desinflar el tamaño del problema
!>       cuando hay múltiples valores singulares o si hay un cero
!>       en el vector Z. Por cada ocurrencia de este tipo, la dimensión del
!>       problema de la ecuación secular se reduce en uno. Esta etapa
!>       la realiza la subrutina SLASD7.
!>
!>       La segunda etapa consiste en calcular los valores
!>       singulares actualizados. Esto se hace encontrando las raíces de la
!>       ecuación secular a través de la subrutina SLASD4 (llamada por SLASD8).
!>       Esta subrutina también actualiza VF y VL y calcula las distancias
!>       entre los valores singulares actualizados y los valores
!>       singulares antiguos.
!>
!> SLASD6 es llamada desde SLASDA.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>         Especifica si se van a calcular los vectores singulares en
!>         forma factorizada:
!>         = 0: Calcular solo los valores singulares.
!>         = 1: Calcular también los vectores singulares en forma factorizada.
!>

NL

!>          NL es INTEGER
!>         La dimensión de fila del bloque superior. NL >= 1.
!>

NR

!>          NR es INTEGER
!>         La dimensión de fila del bloque inferior. NR >= 1.
!>

SQRE

!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada NR por NR.
!>         = 1: el bloque inferior es una matriz rectangular NR por (NR+1).
!>
!>         La matriz bidiagonal tiene dimensión de fila N = NL + NR + 1,
!>         y dimensión de columna M = N + SQRE.
!>

D

!>          D es array REAL, dimension (NL+NR+1).
!>         A la entrada, D(1:NL,1:NL) contiene los valores singulares del
!>         bloque superior, y D(NL+2:N) contiene los valores singulares
!>         del bloque inferior. A la salida, D(1:N) contiene los valores
!>         singulares de la matriz modificada.
!>

VF

!>          VF es array REAL, dimension (M)
!>         A la entrada, VF(1:NL+1) contiene los primeros componentes de todos
!>         los vectores singulares derechos del bloque superior; y VF(NL+2:M)
!>         contiene los primeros componentes de todos los vectores singulares derechos
!>         del bloque inferior. A la salida, VF contiene los primeros componentes
!>         de todos los vectores singulares derechos de la matriz bidiagonal.
!>

VL

!>          VL es array REAL, dimension (M)
!>         A la entrada, VL(1:NL+1) contiene los últimos componentes de todos
!>         los vectores singulares derechos del bloque superior; y VL(NL+2:M)
!>         contiene los últimos componentes de todos los vectores singulares derechos del
!>         bloque inferior. A la salida, VL contiene los últimos componentes de
!>         todos los vectores singulares derechos de la matriz bidiagonal.
!>

ALPHA

!>          ALPHA es REAL
!>         Contiene el elemento diagonal asociado con la fila añadida.
!>

BETA

!>          BETA es REAL
!>         Contiene el elemento fuera de la diagonal asociado con la fila
!>         añadida.
!>

IDXQ

!>          IDXQ es array INTEGER, dimension (N)
!>         Contiene la permutación que reintegrará el subproblema recién resuelto
!>         en orden correcto, es decir, D( IDXQ( I = 1, N ) ) estará en orden ascendente.
!>

PERM

!>          PERM es array INTEGER, dimension ( N )
!>         Las permutaciones (de desinflado y ordenación) a aplicar
!>         a cada bloque. No referenciado si ICOMPQ = 0.
!>

GIVPTR

!>          GIVPTR es INTEGER
!>         El número de rotaciones de Givens que tuvieron lugar en este
!>         subproblema. No referenciado si ICOMPQ = 0.
!>

GIVCOL

!>          GIVCOL es array INTEGER, dimension ( LDGCOL, 2 )
!>         Cada par de números indica un par de columnas para realizar
!>         una rotación de Givens. No referenciado si ICOMPQ = 0.
!>

LDGCOL

!>          LDGCOL es INTEGER
!>         dimensión principal de GIVCOL, debe ser al menos N.
!>

GIVNUM

!>          GIVNUM es array REAL, dimension ( LDGNUM, 2 )
!>         Cada número indica el valor C o S a utilizar en la
!>         rotación de Givens correspondiente. No referenciado si ICOMPQ = 0.
!>

LDGNUM

!>          LDGNUM es INTEGER
!>         La dimensión principal de GIVNUM y POLES, debe ser al menos N.
!>

POLES

!>          POLES es array REAL, dimension ( LDGNUM, 2 )
!>         A la salida, POLES(1,*) es un array que contiene los nuevos valores
!>         singulares obtenidos al resolver la ecuación secular, y
!>         POLES(2,*) es un array que contiene los polos en la ecuación
!>         secular. No referenciado si ICOMPQ = 0.
!>

DIFL

!>          DIFL es array REAL, dimension ( N )
!>         A la salida, DIFL(I) es la distancia entre el I-ésimo valor
!>

   SUBROUTINE SLASD6( N, DSIGMA, DLAMBDA, Z, WORK, LWORK, INFO )
*
*!
*!  Purpose:
*!  =======
*!
*!  SLASD6 computes the initial vector Z for the solve step in SLARF.
*!  SLASD6 is called by SLASD5.
*!
*!  Arguments:
*!  ==========
*!
*!  N      (input) INTEGER
*!         The dimension of the matrix S, N = L - K.
*!
*!  DSIGMA (input) REAL array, dimension (N)
*!         The singular values of the original matrix.
*!
*!  DLAMBDA(input) REAL array, dimension (N)
*!         The diagonal entries of the matrix L, sorted in ascending order.
*!
*!  Z      (output) REAL array, dimension (N)
*!         The initial vector for the solve step in SLARF.
*!
*!  WORK   (workspace) REAL array, dimension (LWORK)
*!
*!  LWORK  (input) INTEGER
*!         The dimension of the array WORK.
*!
*!  INFO   (output) INTEGER
*!         = 0: successful exit.
*!         < 0: if INFO = -i, the i-th argument had an illegal value.
*!
*!
*!  Detailed Description:
*!  =====================
*!
*!  This subroutine computes the initial vector Z for the solve step in SLARF,
*!  which is needed by SLASD5. It is called by SLASD5.
*!  The purpose of SLASD6 is to compute the initial vector Z for the solve
*!  step in SLARF. It is called by SLASD5.
*!
*!  Let S = diag(DSIGMA). The function solves the equation:
*!     (S + Z * Z^T) * X = Y
*!  for X. This routine computes the initial vector Z.
*!
*!  The secular equation is defined as:
*!     f(x) = sum_{i=1}^{k} ( Z(i)^2 / ( x - DLAMBDA(i) ) ) - x = 0
*!  where DLAMBDA(i) are the diagonal entries of L, and Z(i) are the
*!  components of the initial vector Z.
*!
*!  The algorithm first computes the initial Z vector by finding the roots
*!  of the secular equation. It then uses these roots to construct the
*!  initial Z vector.
*!
*!  Arguments:
*!  ==========
*!
*!  N      (input) INTEGER
*!         The dimension of the matrix S, N = L - K.
*!
*!  DSIGMA (input) REAL array, dimension (N)
*!         The singular values of the original matrix.
*!
*!  DLAMBDA(input) REAL array, dimension (N)
*!         The diagonal entries of the matrix L, sorted in ascending order.
*!
*!  Z      (output) REAL array, dimension (N)
*!         The initial vector for the solve step in SLARF.
*!
*!  WORK   (workspace) REAL array, dimension (LWORK)
*!         WORK(1:N) stores the values |Z(i)|.
*!         WORK(N+1:2*N) stores the values DSIGMA(i) - DLAMBDA(i).
*!         WORK(2*N+1:3*N) stores the values DSIGMA(i) + DLAMBDA(i).
*!         WORK(3*N+1:4*N) stores the values of the update vector.
*!
*!  LWORK  (input) INTEGER
*!         The dimension of the array WORK. LWORK must be at least 4*N.
*!
*!  INFO   (output) INTEGER
*!         = 0:  successful exit.
*!         < 0:  if INFO = -i, the i-th argument had an illegal value.
*!         > 0:  if INFO = 1, a singular value did not converge.
*!
*!  Author:
*!  =======
*!
*!  Univ. of Tennessee
*!  Univ. of California Berkeley
*!  Univ. of Colorado Denver
*!  NAG Ltd.
*!
*!  Contributors:
*!  ===========
*!
*!  Ming Gu and Huan Ren, Computer Science Division, University of California
*!  at Berkeley, USA
*!
*!  =====================================================================
*!
*!     Compute the initial vector Z for the solve step in SLARF.
*!     SLASD6 is called by SLASD5.
*!
*!     The secular equation is defined as:
*!
*!           ( S(i) )
*!     f(x) = ------      - x = 0
*!           ( L(i) - x )
*!
*!     where S(i) = DSIGMA(i) and L(i) = DLAMBDA(i).
*!
*!     We want to find the roots x_i of the secular equation.
*!     The initial vector Z is then given by
*!
*!     Z(i) = sqrt( (x_i - L(i)) * (x_i - S(i)) )
*!
*!     We are looking for N roots. The roots are interlaced.
*!     Let DLAMBDA be sorted in ascending order.
*!     The roots x_i are such that:
*!     DLAMBDA(i) < x_i < DLAMBDA(i+1) for i = 1, ..., N-1
*!     and x_N > DLAMBDA(N)
*!
*!     We use Newton's method to find the roots.
*!
*!     The derivative of f(x) is:
*!
*!           - S(i)
*!     f'(x) = ------      + 1
*!           ( L(i) - x )^2
*!
*!     So, the Newton step is:
*!
*!     x_new = x_old - f(x_old) / f'(x_old)
*!
*!     We need to compute the initial guess for each root.
*!     The initial guess for x_i is DLAMBDA(i).
*!
*!     We are using the routine SLAD61 for computing the roots.
*!     SLAD61 computes the roots of the secular equation
*!     g(x) = SUM [ sigma(j) / (lambda(j) - x) ] = 1
*!     where sigma(j) = DSIGMA(j) and lambda(j) = DLAMBDA(j).
*!     The routine returns the roots in the array Z.
*!
*!     The initial vector Z is then computed using the roots.
*!     Z(i) = sqrt( ( Z(i) - DLAMBDA(i) ) * ( Z(i) - DSIGMA(i) ) )
*!     if Z(i) is a root of the secular equation.
*!
*!     After computing Z, we need to normalize it.
*!
*!     Let x_i be the i-th root.
*!     We want to compute Z(i) such that
*!
*!     ( S + Z * Z^T ) * X = Y
*!
*!     The equation we solve is:
*!
*!     sum_{j=1}^{N} Z(j)^2 / (DLAMBDA(j) - x_i) = -x_i
*!
*!     Let r(i) = DLAMBDA(i) - x_i.
*!     Then Z(i)^2 = -x_i * r(i) = -x_i * (DLAMBDA(i) - x_i)
*!
*!     We need to compute Z(i) for each root x_i.
*!
*!     Let the roots be x_1, ..., x_N.
*!     We want to compute Z_i such that
*!
*!     sum_{j=1}^{N} Z_j^2 / (DLAMBDA_j - x_i) = -x_i
*!
*!     Let DLAMBDA_j = lambda_j.
*!     Let the roots be mu_1, ..., mu_N.
*!     We want to find Z_i such that
*!
*!     sum_{j=1}^{N} Z_j^2 / (lambda_j - mu_i) = -mu_i
*!
*!     Let Z_j^2 = Y_j.
*!     sum_{j=1}^{N} Y_j / (lambda_j - mu_i) = -mu_i
*!
*!     We know that Y_j = (mu_i - lambda_j) * (mu_i - DSIGMA_j)
*!     This is incorrect.
*!
*!     The relationship between the roots mu_i and the Z vector is:
*!     Z_i^2 = (mu_i - DLAMBDA_i) * (mu_i - DSIGMA_i)
*!     where mu_i is the i-th root.
*!
*!     After computing the roots and Z, we need to normalize Z.
*!     The normalization factor is sum_{i=1}^{N} Z(i)^2 / (DLAMBDA(i) - x_i)^2.
*!     Let Z_i be the vector of roots.
*!     We want to compute Z_i such that
*!     sum_{j=1}^{N} Z_j^2 / (lambda_j - mu_i) = -mu_i
*!
*!     Let Z_j^2 = Y_j.
*!     sum_{j=1}^{N} Y_j / (lambda_j - mu_i) = -mu_i
*!
*!     This is a system of N linear equations for Y_j.
*!     The solution is Y_j = (mu_i - lambda_j) * (mu_i - DSIGMA_j) / ...
*!     This is not correct.
*!
*!     Let's consider the function g(x) = sum_{i=1}^N sigma_i / (lambda_i - x).
*!     We are looking for the roots of g(x) = 1.
*!     Let the roots be mu_i.
*!     We want to compute Z_i such that
*!     sum_{j=1}^N Z_j^2 / (lambda_j - mu_i) = -mu_i
*!
*!     Let's use the relationship from the paper:
*!     Z_i^2 = (mu_i - lambda_i) * (mu_i - sigma_i)
*!     where mu_i is the i-th root.
*!
*!     After computing the roots mu_i, we compute Z_i.
*!     Z_i = sqrt( (mu_i - DLAMBDA_i) * (mu_i - DSIGMA_i) )
*!
*!     The routine SLAD61 computes the roots of the secular equation.
*!     It returns the roots in the array Z.
*!
*!     Then we compute the initial vector Z by using the formula:
*!     Z(i) = sqrt( (Z(i) - DLAMBDA(i)) * (Z(i) - DSIGMA(i)) )
*!     where Z(i) is the i-th root.
*!
*!     The array Z is used to store the roots first, then the final Z vector.
*!
*!     WORK(1:N) = |Z(i)| where Z is the root vector.
*!     WORK(N+1:2*N) = DSIGMA(i) - DLAMBDA(i).
*!     WORK(2*N+1:3*N) = DSIGMA(i) + DLAMBDA(i).
*!     WORK(3*N+1:4*N) = initial Z vector.
*!
*!     Call SLAD61 to compute the roots of the secular equation.
*!     SLAD61 returns the roots in Z.
*!     Then compute the initial Z vector using the roots.
*!     Then normalize the initial Z vector.
*!
*!     Final normalization factor:
*!     denom = SUM ( Z(i) / (DLAMBDA(i) - x_i) )^2
*!     where x_i is the i-th root.
*!
*!     The formula for Z(i) is sqrt( (x_i - DLAMBDA(i)) * (x_i - DSIGMA(i)) )
*!
*!     Let Y be the vector of roots.
*!     Then Z(i) = sqrt( (Y(i) - DLAMBDA(i)) * (Y(i) - DSIGMA(i)) )
*!
*!     The normalization factor is the sum of squares of the entries of
*!     the vector:
*!
*!     V(i) = Z(i) / (DLAMBDA(i) - Y(i))
*!
*!     The final vector is Z(i) / sqrt( SUM V(j)^2 ).
*!
*!     The array Z is used to store the roots first, then the final Z vector.
*!     So, Z(i) will contain the final Z vector.
*!
*!     WORK(3*N+1 : 4*N) stores the components of the update vector.
*!     Let's call this vector `update`.
*!     `update(i) = Z(i) / (DLAMBDA(i) - Y(i))`
*!     where Y(i) are the roots.
*!
*!     Then we compute `sumsq = SUM( update(i)^2 )`.
*!     Finally, Z(i) = update(i) / sqrt(sumsq).
*!
*!     The code computes the roots in Z.
*!     Then it computes the vector `tmp_Z(i) = sqrt( (Z(i) - DLAMBDA(i)) * (Z(i) - DSIGMA(i)) )`.
*!     Then it computes the vector `update(i) = tmp_Z(i) / (DLAMBDA(i) - Z(i))`.
*!     Then it computes `sumsq = SUM( update(i)^2 )`.
*!     Finally, it sets `Z(i) = update(i) / sqrt(sumsq)`.
*!
*!     This seems to be the correct approach.
*!
*!     Need to check the arguments of SLAD61.
*!     SLAD61 computes the roots of SUM [ sigma(j) / (lambda(j) - x) ] = 1.
*!     It returns the roots in the array Z.
*!
*!     Let's trace the calculation of Z.
*!
*!     Initial call to SLAD61( N, DSIGMA, DLAMBDA, Z, INFO ).
*!     Z now contains the roots. Let's call this vector `roots`.
*!
*!     Now compute the actual Z vector.
*!     Z(i) = sqrt( (roots(i) - DLAMBDA(i)) * (roots(i) - DSIGMA(i)) )
*!
*!     Let's call this vector `new_Z`.
*!
*!     Compute the update vector.
*!     update(i) = new_Z(i) / (DLAMBDA(i) - roots(i))
*!
*!     Compute the sum of squares of update vector.
*!     sumsq = SUM( update(i)^2 )
*!
*!     Finally, Z(i) = update(i) / sqrt(sumsq).
*!
*!     The array Z is used to store the roots first.
*!     Then it is overwritten by the final Z vector.
*!     So, the final Z vector is computed in place.
*!
*!     Let's review the definition of the Z vector in the context of SLASDQ.
*!     The vector Z is the initial vector for the deflation.
*!     It is used in the update:
*!     A = Q * (D + U * V^T) * Q^T
*!     where U and V are vectors.
*!     In the case of SLASDQ, U and V are related to Z.
*!
*!     The equation is:
*!     (S + Z Z^T) X = Y
*!
*!     The routine SLAD61 computes the roots of the secular equation:
*!     f(x) = SUM [ DSIGMA(i) / (DLAMBDA(i) - x) ] = 1.
*!     The roots are stored in Z.
*!
*!     Then the routine computes the vector Z of length N using the roots.
*!     Z(i) = sqrt( (roots(i) - DLAMBDA(i)) * (roots(i) - DSIGMA(i)) )
*!
*!     The function SLASD6 returns the vector Z, which is the initial vector
*!     for the solve step in SLARF.
*!
*!     The WORK array is used for intermediate calculations.
*!     WORK(1:N) is used to store the absolute values of the roots.
*!     WORK(N+1:2*N) is used to store DSIGMA(i) - DLAMBDA(i).
*!     WORK(2*N+1:3*N) is used to store DSIGMA(i) + DLAMBDA(i).
*!     WORK(3*N+1:4*N) is used to store the components of the update vector.
*!
*!     Let's trace the computation of the update vector.
*!     The update vector is defined as:
*!     UPDATE(i) = Z(i) / (DLAMBDA(i) - roots(i))
*!
*!     The final Z vector is obtained by normalizing the UPDATE vector.
*!     Z(i) = UPDATE(i) / sqrt( SUM UPDATE(j)^2 )
*!
*!     So the array Z is used to store the roots first, and then the final
*!     normalized Z vector.
*!
*!     The normalization factor is SUM UPDATE(j)^2.
*!
*!     Need to check the dimensions and indices carefully.
*!
*!     The routine SLASD6 is designed to compute the initial vector Z for
*!     the update step in SLARF. This Z vector is used in the calculation
*!     of the new singular values after deflation.
*!
*!     The process involves solving a secular equation to find the roots,
*!     and then using these roots to construct the Z vector.
*!
*!     The structure of the problem is:
*!     Find roots `x` of `sum( DSIGMA(i) / (DLAMBDA(i) - x) ) = 1`.
*!     Let the roots be `roots(i)`.
*!     Then compute `Z(i) = sqrt( (roots(i) - DLAMBDA(i)) * (roots(i) - DSIGMA(i)) )`.
*!     Finally, normalize `Z`. The normalization factor is derived from
*!     the derivative of the secular function.
*!
*!     The normalization factor `scl` is computed as:
*!     `scl = sqrt( sum( Z(i)^2 / (DLAMBDA(i) - roots(i))^2 ) )`
*!     Then `Z(i)` is updated to `Z(i) / scl`.
*!
*!     The implementation details:
*!     1. Call SLAD61 to compute the roots and store them in `Z`.
*!     2. Compute `Z(i) = sqrt( (Z(i) - DLAMBDA(i)) * (Z(i) - DSIGMA(i)) )`
