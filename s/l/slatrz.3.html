Documentación de Función/Subrutina

subrutina slatrz (integer m, integer n, integer l, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work)

SLATRZ factoriza una matriz trapezoidal superior mediante transformaciones ortogonales.

Propósito:

!>
!> SLATRZ factoriza la matriz real trapezoidal superior M-por-(M+L)
!> [ A1 A2 ] = [ A(1:M,1:M) A(1:M,N-L+1:N) ] como ( R  0 ) * Z, mediante
!> transformaciones ortogonales. Z es una matriz ortogonal (M+L)-por-(M+L)
!> y, R y A1 son matrices triangulares superiores M-por-M.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

L

!>          L es INTEGER
!>          El número de columnas de la matriz A que contienen la
!>          parte significativa de los vectores de Householder. N-M >= L >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la parte trapezoidal superior M-por-N principal de
!>          la matriz A debe contener la matriz a factorizar.
!>          En la salida, la parte triangular superior M-por-M principal de A
!>          contiene la matriz triangular superior R, y los elementos N-L+1 a
!>          N de las primeras M filas de A, junto con el array TAU, representan
!>          la matriz ortogonal Z como un producto de M reflectores elementales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array REAL, de dimensión (M)
!>          Los factores escalares de los reflectores elementales.
!>

WORK

!>          WORK es un array REAL, de dimensión (M)
!>

Detalles adicionales:

!>
!> La factorización se obtiene por el método de Householder. La k-ésima
!> matriz de transformación, Z( k ), que se usa para introducir ceros en
!> la fila ( m - k + 1 ) de A, se da en la forma
!>
!>    Z( k ) = ( I     0   ),
!>             ( 0  T( k ) )
!>
!> donde
!>
!>    T( k ) = I - tau*u( k )*u( k )**T,   u( k ) = (   1    ),
!>                                              (   0    )
!>                                              ( z( k ) )
!>
!> tau es un escalar y z( k ) es un vector de longitud l. tau y z( k )
!> se eligen para aniquilar los elementos de la k-ésima fila de A2.
!>
!> El escalar tau se devuelve en el k-ésimo elemento de TAU y el vector
!> u( k ) en la k-ésima fila de A2, de tal manera que los elementos de z( k )
!> se encuentran en  a( k, l + 1 ), ..., a( k, n ). Los elementos de R se
!> devuelven en la parte triangular superior de A1.
!>
!> Z se da por
!>
!>    Z =  Z( 1 ) * Z( 2 ) * ... * Z( m ).
!>
