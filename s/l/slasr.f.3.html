subrutina slasr (side, pivot, direct, m, n, c, s, a, lda)
SLASR aplica una secuencia de rotaciones de plano a una matriz general.

Documentación de Función/Subrutina

subrutina slasr (carácter side, carácter pivot, carácter direct, entero m, entero n, real, dimensión( * ) c, real, dimensión( * ) s, real, dimensión( lda, * ) a, entero lda)

SLASR aplica una secuencia de rotaciones de plano a una matriz real A, desde la izquierda o la derecha.

Propósito:

!>
!> SLASR aplica una secuencia de rotaciones de plano a una matriz real A,
!> desde la izquierda o la derecha.
!>
!> Cuando SIDE = 'L', la transformación toma la forma
!>
!>    A := P*A
!>
!> y cuando SIDE = 'R', la transformación toma la forma
!>
!>    A := A*P**T
!>
!> donde P es una matriz ortogonal que consiste en una secuencia de z rotaciones
!> de plano, con z = M cuando SIDE = 'L' y z = N cuando SIDE = 'R',
!> y P**T es la transpuesta de P.
!>
!> Cuando DIRECT = 'F' (secuencia Forward), entonces
!>
!>    P = P(z-1) * ... * P(2) * P(1)
!>
!> y cuando DIRECT = 'B' (secuencia Backward), entonces
!>
!>    P = P(1) * P(2) * ... * P(z-1)
!>
!> donde P(k) es una matriz de rotación de plano definida por la rotación de
!> 2 por 2
!>
!>    R(k) = (  c(k)  s(k) )
!>         = ( -s(k)  c(k) ).
!>
!> Cuando PIVOT = 'V' (pivote variable), la rotación se realiza
!> para el plano (k,k+1), es decir, P(k) tiene la forma
!>
!>    P(k) = (  1                                            )
!>           (       ...                                     )
!>           (              1                                )
!>           (                   c(k)  s(k)                  )
!>           (                  -s(k)  c(k)                  )
!>           (                                1              )
!>           (                                     ...       )
!>           (                                            1  )
!>
!> donde R(k) aparece como una modificación de rango 2 a la matriz identidad
!> en las filas y columnas k y k+1.
!>
!> Cuando PIVOT = 'T' (pivote superior), la rotación se realiza para el
!> plano (1,k+1), por lo que P(k) tiene la forma
!>
!>    P(k) = (  c(k)                    s(k)                 )
!>           (         1                                     )
!>           (              ...                              )
!>           (                     1                         )
!>           ( -s(k)                    c(k)                 )
!>           (                                 1             )
!>           (                                      ...      )
!>           (                                             1 )
!>
!> donde R(k) aparece en las filas y columnas 1 y k+1.
!> De manera similar, cuando PIVOT = 'B' (pivote inferior), la rotación
!> se realiza para el plano (k,z), dando a P(k) la forma
!>
!>    P(k) = ( 1                                             )
!>           (      ...                                      )
!>           (             1                                 )
!>           (                  c(k)                    s(k) )
!>           (                         1                     )
!>           (                              ...              )
!>           (                                     1         )
!>           (                 -s(k)                    c(k) )
!>
!> donde R(k) aparece en las filas y columnas k y z. Las rotaciones se
!> realizan sin formar explícitamente P(k).
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          Especifica si la matriz de rotación de plano P se aplica a
!>          A por la izquierda o por la derecha.
!>          = 'L':  Izquierda, calcular A := P*A
!>          = 'R':  Derecha, calcular A:= A*P**T
!>

PIVOT

!>          PIVOT es CHARACTER*1
!>          Especifica el plano para el cual P(k) es una matriz de rotación
!>          de plano.
!>          = 'V':  Pivote variable, el plano (k,k+1)
!>          = 'T':  Pivote superior, el plano (1,k+1)
!>          = 'B':  Pivote inferior, el plano (k,z)
!>

DIRECT

!>          DIRECT es CHARACTER*1
!>          Especifica si P es una secuencia forward o backward de
!>          rotaciones de plano.
!>          = 'F':  Forward, P = P(z-1)*...*P(2)*P(1)
!>          = 'B':  Backward, P = P(1)*P(2)*...*P(z-1)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A. Si m <= 1, se retorna
!>          inmediatamente.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. Si n <= 1, se retorna
!>          inmediatamente.
!>

C

!>          C es array REAL, dimensión
!>                  (M-1) si SIDE = 'L'
!>                  (N-1) si SIDE = 'R'
!>          Los cosenos c(k) de las rotaciones de plano.
!>

S

!>          S es array REAL, dimensión
!>                  (M-1) si SIDE = 'L'
!>                  (N-1) si SIDE = 'R'
!>          Los senos s(k) de las rotaciones de plano. La parte de rotación
!>          de plano de 2 por 2 de la matriz P(k), R(k), tiene la forma
!>          R(k) = (  c(k)  s(k) )
!>                 ( -s(k)  c(k) ).
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>          La matriz A de M por N. A la salida, A se sobrescribe con P*A si
!>          SIDE = 'R' o con A*P**T si SIDE = 'L'.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>
