función real slansb (norm, uplo, n, k, ab, ldab, work)
SLANSB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz banda simétrica.

Documentación de función/subrutina

real función slansb (carácter norm, carácter uplo, entero n, entero k, real, dimensión( ldab, * ) ab, entero ldab, real, dimensión( * ) work)

SLANSB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz banda simétrica.

Propósito:

!>
!> SLANSB  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el elemento de  mayor valor absoluto de una
!> matriz banda simétrica A de n por n,  con k super-diagonales.
!>

Devuelve

SLANSB 
!>
!>    SLANSB = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en SLANSB como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se proporciona la parte triangular superior o inferior
!>          de la matriz banda A.
!>          = 'U':  Se proporciona la parte triangular superior
!>          = 'L':  Se proporciona la parte triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, SLANSB se
!>          establece a cero.
!>

K

!>          K es INTEGER
!>          El número de super-diagonales o sub-diagonales de la
!>          matriz banda A.  K >= 0.
!>

AB

!>          AB es un array REAL, dimensión (LDAB,N)
!>          La parte triangular superior o inferior de la matriz banda simétrica A,
!>          almacenada en las K+1 primeras filas de AB. La j-ésima columna de A
!>          se almacena en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(k+1+i-j,j) = A(i,j) para max(1,j-k)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)   = A(i,j) para j<=i<=min(n,j+k).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= K+1.
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' o '1' o 'O'; de lo contrario,
!>          WORK no se referencia.
!>
