NOMBRE

slapo-sssvlv - Superposición de ordenación del lado del servidor (Server Side Sorting) y Vistas de Lista Virtual (Virtual List View) para slapd

SINOPSIS

/etc/openldap/slapd.conf

DESCRIPCIÓN

Esta superposición implementa el control de Ordenación del Lado del Servidor LDAP (RFC2891) así como el control de Vista de Lista Virtual. También reemplaza la implementación predeterminada del control de Resultados Paginados LDAP (RFC2696) para asegurar que funcione con la Ordenación. La superposición se puede usar con cualquier backend o globalmente para todos los backends.

Dado que un conjunto completo de resultados debe generarse en memoria antes de que se pueda realizar la ordenación, el procesamiento de las solicitudes de ordenación puede tener un gran impacto en el uso de memoria del servidor. Como tal, cada conexión se limita a tener solo un número limitado de solicitudes de ordenación activas a la vez. Se pueden configurar límites adicionales como se describe a continuación.

CONFIGURACIÓN

Estas opciones de slapd.conf se aplican a la superposición SSSVLV. Deben aparecer después de la directiva overlay.

sssvlv-max <num>
Establece el número máximo de solicitudes de ordenación concurrentes permitidas en todas las conexiones. El valor predeterminado es la mitad del número de hilos del servidor.
sssvlv-maxkeys <num>
Establece el número máximo de claves permitidas en una solicitud de ordenación. El valor predeterminado es 5.
sssvlv-maxperconn <num>
Establece el número máximo de solicitudes de búsqueda paginada concurrentes por conexión. El valor predeterminado es 5. El número de solicitudes concurrentes sigue limitado por sssvlv-max.
