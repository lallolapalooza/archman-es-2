Documentación de la Función/Subrutina

subroutine slascl (character type, integer kl, integer ku, real cfrom, real cto, integer m, integer n, real, dimension( lda, * ) a, integer lda, integer info)

SLASCL multiplica la matriz real M por N, A, por el escalar real CTO/CFROM. Esto se hace sin desbordamiento superior/inferior siempre que el resultado final CTO*A(I,J)/CFROM no se desborde.

Propósito:

!>
!> SLASCL multiplica la matriz real M por N, A, por el escalar real
!> CTO/CFROM. Esto se hace sin desbordamiento superior/inferior siempre que
!> el resultado final CTO*A(I,J)/CFROM no se desborde. TYPE especifica que
!> A puede ser completa, triangular superior, triangular inferior,
!> Hessenberg superior o de banda.
!>

Parámetros

TYPE 
!>          TYPE es CHARACTER*1
!>          TYPE indica el tipo de almacenamiento de la matriz de entrada.
!>          = 'G':  A es una matriz completa.
!>          = 'L':  A es una matriz triangular inferior.
!>          = 'U':  A es una matriz triangular superior.
!>          = 'H':  A es una matriz Hessenberg superior.
!>          = 'B':  A es una matriz de banda simétrica con ancho de banda
!>                  inferior KL y ancho de banda superior KU, y solo se
!>                  almacena la mitad inferior.
!>          = 'Q':  A es una matriz de banda simétrica con ancho de banda
!>                  inferior KL y ancho de banda superior KU, y solo se
!>                  almacena la mitad superior.
!>          = 'Z':  A es una matriz de banda con ancho de banda inferior KL
!>                  y ancho de banda superior KU. Ver SGBTRF para detalles
!>                  de almacenamiento.
!>

KL

!>          KL es INTEGER
!>          El ancho de banda inferior de A. Se referencia solo si TYPE = 'B',
!>          'Q' o 'Z'.
!>

KU

!>          KU es INTEGER
!>          El ancho de banda superior de A. Se referencia solo si TYPE = 'B',
!>          'Q' o 'Z'.
!>

CFROM

!>          CFROM es REAL
!>

CTO

!>          CTO es REAL
!>
!>          La matriz A se multiplica por CTO/CFROM. A(I,J) se calcula
!>          sin desbordamiento superior/inferior si el resultado final
!>          CTO*A(I,J)/CFROM puede ser representado sin desbordamiento
!>          superior/inferior. CFROM debe ser distinto de cero.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

A

!>          A es un array REAL, dimension (LDA,N)
!>          La matriz a multiplicar por CTO/CFROM. Ver TYPE para el tipo
!>          de almacenamiento.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si TYPE = 'G', 'L', 'U', 'H', LDA >= max(1,M);
!>             TYPE = 'B', LDA >= KL+1;
!>             TYPE = 'Q', LDA >= KU+1;
!>             TYPE = 'Z', LDA >= 2*KL+KU+1.
!>

INFO

!>          INFO es INTEGER
!>          0 - salida exitosa
!>          <0 - si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
