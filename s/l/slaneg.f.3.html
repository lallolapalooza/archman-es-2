Documentación de Función/Subrutina

función entera slaneg (entero n, real, dimensión( * ) d, real, dimensión( * ) lld, real sigma, real pivmin, entero r)

SLANEG calcula el conteo de Sturm.

Propósito:

!>
!> SLANEG calcula el conteo de Sturm, el número de pivotes negativos
!> encontrados al factorizar el tridiagonal T - sigma I = L D L^T.
!> Esta implementación trabaja directamente sobre los factores sin formar
!> la matriz tridiagonal T. El conteo de Sturm es también el número de
!> autovalores de T menores que sigma.
!>
!> Esta rutina es llamada desde SLARRB.
!>
!> La rutina actual no utiliza el parámetro PIVMIN sino que
!> requiere propagación IEEE-754 de Infinitos y NaNs. Esta
!> rutina tampoco tiene restricciones de rango de entrada, pero sí requiere
!> el manejo de excepciones por defecto de modo que x/0 produzca Inf cuando x es
!> distinto de cero, y Inf/Inf produzca NaN. Para más información, ver:
!>
!>   Marques, Riedy, y Voemel, SIAM Journal on
!>   Scientific Computing, v28, n5, 2006. DOI 10.1137/050641624
!>   (Versión de informe técnico en LAWN 172 con el mismo título.)
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz.
!>

D

!>          D es array REAL, dimensión (N)
!>          Los N elementos diagonales de la matriz diagonal D.
!>

LLD

!>          LLD es array REAL, dimensión (N-1)
!>          Los (N-1) elementos L(i)*L(i)*D(i).
!>

SIGMA

!>          SIGMA es REAL
!>          Valor de desplazamiento en T - sigma I = L D L^T.
!>

PIVMIN

!>          PIVMIN es REAL
!>          El pivote mínimo en la secuencia de Sturm. Puede ser usado
!>          cuando se encuentran pivotes cero en arquitecturas no IEEE-754.
!>

R

!>          R es ENTERO
!>          El índice de giro para la factorización girada que se utiliza
!>          para el negcount.
!>
