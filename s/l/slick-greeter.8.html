SLICK-GREETER(8) Comandos de administración del sistema SLICK-GREETER(8)

NOMBRE

slick-greeter - GDM agnóstico para LightDM

SINOPSIS

slick-greeter [ OPCIONES ]

DESCRIPCIÓN

Slick Greeter es un greeter de LightDM para todos los escritorios. Es ejecutado por el demonio LightDM si está configurado en lightdm.conf. Normalmente no lo ejecuta un usuario, pero puede ejecutarse en modo de prueba con la opción --test-mode. Esto permite probar la interfaz sin instalar una versión actualizada.

OPCIONES

-v, --version
Muestra la versión de lanzamiento.
--test-mode
Ejecuta el greeter en modo de prueba dentro de la sesión X actual.
-?, --help
Muestra las opciones de ayuda.

Formato de archivo de configuración

/etc/lightdm/slick-greeter.conf
Opciones de configuración disponibles se enumeran a continuación.
fondo=
Archivo de fondo a utilizar, ya sea una ruta de imagen o un color (por ejemplo, #772953)
color-de-fondo=
Color de fondo (por ejemplo, #772953), establecido antes de que se vea el fondo de pantalla.
dibujar-fondos-de-usuario=
Si dibujar fondos de usuario (verdadero o falso).
dibujar-cuadrícula=
Si dibujar una cuadrícula superpuesta (verdadero o falso).
mostrar-nombre-host=
Si mostrar el nombre del host en la barra de menú (verdadero o falso).
mostrar-teclado=
Si mostrar el indicador del teclado en la barra de menú (verdadero o falso).
mostrar-a11y=
Si mostrar las opciones de accesibilidad en la barra de menú (verdadero o falso).
mostrar-energía=
Si mostrar el indicador de energía en la barra de menú (verdadero o falso).
mostrar-reloj=
Si mostrar el reloj en la barra de menú (verdadero o falso).
mostrar-salir=
Si mostrar el menú de salida en la barra de menú (verdadero o falso).
logo=
Archivo de logo a utilizar.
logo-otros-monitores=
Archivo de logo a utilizar para otros monitores.
nombre-tema=
Tema GTK+ a utilizar.
nombre-tema-iconos=
Tema de iconos a utilizar.
nombre-fuente=
Fuente a utilizar.
xft-antialias=
Si aplicar anti-aliasing a fuentes Xft (verdadero o falso).
xft-dpi=
Resolución para Xft en puntos por pulgada.
xft-hintstyle=
Qué grado de hinting usar (hintnone/hintslight/hintmedium/hintfull)
xft-rgba=
Tipo de anti-aliasing de subpíxeles (none/rgb/bgr/vrgb/vbgr)
teclado-en-pantalla=
Si habilitar el teclado en pantalla (verdadero o falso).
alto-contraste=
Si usar un tema de alto contraste (verdadero o falso).
lector-de-pantalla=
Si habilitar el lector de pantalla (verdadero o falso).
reproducir-sonido-listo=
Un archivo de sonido para reproducir cuando el greeter esté listo.
usuarios-ocultos=
Lista de nombres de usuario que están ocultos hasta que se presiona una combinación de teclas especial.
filtro-grupo=
Lista de grupos a los que los usuarios deben pertenecer para ser mostrados (lista vacía muestra todos los usuarios).
habilitar-hidpi=
Si habilitar soporte HiDPI (on/off/auto).
solo-en-monitor=
Establece el monitor en el que mostrar la ventana de inicio de sesión, -1 significa "seguir el ratón".
