DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine slasd4 (integer n, integer i, real, dimension( * ) d, real, dimension( * ) z, real, dimension( * ) delta, real rho, real sigma, real, dimension( * ) work, integer info)

SLASD4 calcula la raíz cuadrada del i-ésimo valor propio actualizado de una modificación simétrica de rango uno positiva a una matriz diagonal positiva. Usado por sbdsdc.

Propósito:

!>
!> Esta subrutina calcula la raíz cuadrada del I-ésimo valor propio
!> actualizado de una modificación simétrica de rango uno positiva a
!> una matriz diagonal positiva cuyas entradas se dan como los cuadrados
!> de las entradas correspondientes en el array d, y que
!>
!>        0 <= D(i) < D(j)  para  i < j
!>
!> y que RHO > 0. Esto es organizado por la rutina que llama, y no es
!> una pérdida de generalidad. El sistema modificado de rango uno es
!> por lo tanto
!>
!>        diag( D ) * diag( D ) +  RHO * Z * Z_transpose.
!>
!> donde asumimos que la norma euclidiana de Z es 1.
!>
!> El método consiste en aproximar las funciones racionales en la
!> ecuación secular mediante funciones racionales interpolantes más simples.
!>

Parámetros

N 
!>          N es ENTERO
!>         La longitud de todos los arrays.
!>

I

!>          I es ENTERO
!>         El índice del valor propio a calcular.  1 <= I <= N.
!>

D

!>          D es array REAL, dimension ( N )
!>         Los valores propios originales. Se asume que están en
!>         orden, 0 <= D(I) < D(J)  para I < J.
!>

Z

!>          Z es array REAL, dimension ( N )
!>         Los componentes del vector de actualización.
!>

DELTA

!>          DELTA es array REAL, dimension ( N )
!>         Si N .ne. 1, DELTA contiene (D(j) - sigma_I) en su j-ésimo
!>         componente.  Si N = 1, entonces DELTA(1) = 1.  El vector DELTA
!>         contiene la información necesaria para construir los
!>         vectores propios (singulares).
!>

RHO

!>          RHO es REAL
!>         El escalar en la fórmula de actualización simétrica.
!>

SIGMA

!>          SIGMA es REAL
!>         El sigma_I calculado, el I-ésimo valor propio actualizado.
!>

WORK

!>          WORK es array REAL, dimension ( N )
!>         Si N .ne. 1, WORK contiene (D(j) + sigma_I) en su j-ésimo
!>         componente.  Si N = 1, entonces WORK( 1 ) = 1.
!>

INFO

!>          INFO es ENTERO
!>         = 0:  salida exitosa
!>         > 0:  si INFO = 1, el proceso de actualización falló.
!>

Parámetros Internos:

!>  La variable lógica ORGATI (origin-at-i?) se usa para distinguir
!>  si D(i) o D(i+1) se trata como el origen.
!>
!>            ORGATI = .true.    origen en i
!>            ORGATI = .false.   origen en i+1
!>
!>  La variable lógica SWTCH3 (switch-for-3-poles?) es para notar
!>  si estamos trabajando con TRES polos!
!>
!>  MAXIT es el número máximo de iteraciones permitidas para cada
!>  valor propio.
!>
