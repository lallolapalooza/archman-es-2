función real sla_porpvgrw (uplo, ncols, a, lda, af, ldaf, work)
SLA_PORPVGRW calcula el factor de crecimiento del pivote recíproco norm(A)/norm(U) para una matriz simétrica o Hermítica definida positiva.

Documentación de Función/Subrutina

función real sla_porpvgrw (character*1 uplo, integer ncols, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, real, dimension( * ) work)

SLA_PORPVGRW calcula el factor de crecimiento del pivote recíproco norm(A)/norm(U) para una matriz simétrica o Hermítica definida positiva.

Propósito:

!>
!>
!> SLA_PORPVGRW calcula el factor de crecimiento del pivote recíproco
!> norm(A)/norm(U). Se utiliza la norma . Si esto es
!> mucho menor que 1, la estabilidad de la factorización LU de la
!> matriz (equilibrada) A podría ser pobre. Esto también significa que la
!> solución X, los números de condición estimados y los límites de error podrían
!> no ser fiables.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

NCOLS

!>          NCOLS es INTEGER
!>     El número de columnas de la matriz A. NCOLS >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>     En la entrada, la matriz N por N, A.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array REAL, dimension (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, tal como es calculada por SPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

WORK

!>          WORK es array REAL, dimension (2*N)
!>
