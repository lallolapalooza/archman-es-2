subrutina slatm5 (prtype entero, m entero, n entero, real, dimensión( lda, * ) a, lda entero, real, dimensión( ldb, * ) b, ldb entero, real, dimensión( ldc, * ) c, ldc entero, real, dimensión( ldd, * ) d, ldd entero, real, dimensión( lde, * ) e, lde entero, real, dimensión( ldf, * ) f, ldf entero, real, dimensión( ldr, * ) r, ldr entero, real, dimensión( ldl, * ) l, ldl entero, real alpha, qblcka entero, qblckb entero)

SLATM5

Propósito:

!>
!> SLATM5 genera matrices involucradas en la ecuación de Sylvester
!> Generalizada:
!>
!>     A * R - L * B = C
!>     D * R - L * E = F
!>
!> También satisfacen (la condición de diagonalización)
!>
!>  [ I -L ] ( [ A  -C ], [ D -F ] ) [ I  R ] = ( [ A    ], [ D    ] )
!>  [    I ] ( [     B ]  [    E ] ) [    I ]   ( [    B ]  [    E ] )
!>
!>

Parámetros

PRTYPE 
!>          PRTYPE es ENTERO
!>           a un cierto tipo de las matrices a generar
!>          (ver más detalles).
!>

M

!>          M es ENTERO
!>          Especifica el orden de A y D y el número de filas en
!>          C, F, R y L.
!>

N

!>          N es ENTERO
!>          Especifica el orden de B y E y el número de columnas en
!>          C, F, R y L.
!>

A

!>          A es un array REAL, dimensión (LDA, M).
!>          A la salida A M-por-M se inicializa según PRTYPE.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de A.
!>

B

!>          B es un array REAL, dimensión (LDB, N).
!>          A la salida B N-por-N se inicializa según PRTYPE.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal de B.
!>

C

!>          C es un array REAL, dimensión (LDC, N).
!>          A la salida C M-por-N se inicializa según PRTYPE.
!>

LDC

!>          LDC es ENTERO
!>          La dimensión principal de C.
!>

D

!>          D es un array REAL, dimensión (LDD, M).
!>          A la salida D M-por-M se inicializa según PRTYPE.
!>

LDD

!>          LDD es ENTERO
!>          La dimensión principal de D.
!>

E

!>          E es un array REAL, dimensión (LDE, N).
!>          A la salida E N-por-N se inicializa según PRTYPE.
!>

LDE

!>          LDE es ENTERO
!>          La dimensión principal de E.
!>

F

!>          F es un array REAL, dimensión (LDF, N).
!>          A la salida F M-por-N se inicializa según PRTYPE.
!>

LDF

!>          LDF es ENTERO
!>          La dimensión principal de F.
!>

R

!>          R es un array REAL, dimensión (LDR, N).
!>          A la salida R M-por-N se inicializa según PRTYPE.
!>

LDR

!>          LDR es ENTERO
!>          La dimensión principal de R.
!>

L

!>          L es un array REAL, dimensión (LDL, N).
!>          A la salida L M-por-N se inicializa según PRTYPE.
!>

LDL

!>          LDL es ENTERO
!>          La dimensión principal de L.
!>

ALPHA

!>          ALPHA es REAL
!>          Parámetro utilizado en la generación de matrices PRTYPE = 1 y 5.
!>

QBLCKA

!>          QBLCKA es ENTERO
!>          Cuando PRTYPE = 3, especifica la distancia entre bloques de 2x2
!>          en la diagonal de A. De lo contrario, QBLCKA no se
!>          referencia. QBLCKA > 1.
!>

QBLCKB

!>          QBLCKB es ENTERO
!>          Cuando PRTYPE = 3, especifica la distancia entre bloques de 2x2
!>          en la diagonal de B. De lo contrario, QBLCKB no se
!>          referencia. QBLCKB > 1.
!>

Detalles Adicionales:

!>
!>  PRTYPE = 1: A y B son bloques de Jordan, D y E son matrices identidad
!>
!>             A : si (i == j) entonces A(i, j) = 1.0
!>                 si (j == i + 1) entonces A(i, j) = -1.0
!>                 else A(i, j) = 0.0,            i, j = 1...M
!>
!>             B : si (i == j) entonces B(i, j) = 1.0 - ALPHA
!>                 si (j == i + 1) entonces B(i, j) = 1.0
!>                 else B(i, j) = 0.0,            i, j = 1...N
!>
!>             D : si (i == j) entonces D(i, j) = 1.0
!>                 else D(i, j) = 0.0,            i, j = 1...M
!>
!>             E : si (i == j) entonces E(i, j) = 1.0
!>                 else E(i, j) = 0.0,            i, j = 1...N
!>
!>             L =  R se eligen de [-10...10],
!>                  lo que especifica los lados derechos (C, F).
!>
!>  PRTYPE = 2 o 3: Triangulares y/o cuasi-triangulares.
!>
!>             A : si (i <= j) entonces A(i, j) = [-1...1]
!>                 else A(i, j) = 0.0,             i, j = 1...M
!>
!>                 si (PRTYPE = 3) entonces
!>                    A(k + 1, k + 1) = A(k, k)
!>                    A(k + 1, k) = [-1...1]
!>                    sign(A(k, k + 1) = -(sin(A(k + 1, k))
!>                        k = 1, M - 1, QBLCKA
!>
!>             B : si (i <= j) entonces B(i, j) = [-1...1]
!>                 else B(i, j) = 0.0,            i, j = 1...N
!>
!>                 si (PRTYPE = 3) entonces
!>                    B(k + 1, k + 1) = B(k, k)
!>                    B(k + 1, k) = [-1...1]
!>                    sign(B(k, k + 1) = -(sign(B(k + 1, k))
!>                        k = 1, N - 1, QBLCKB
!>
!>             D : si (i <= j) entonces D(i, j) = [-1...1].
!>                 else D(i, j) = 0.0,            i, j = 1...M
!>
!>
!>             E : si (i <= j) entonces D(i, j) = [-1...1]
!>                 else E(i, j) = 0.0,            i, j = 1...N
!>
!>                 L, R se eligen de [-10...10],
!>                 lo que especifica los lados derechos (C, F).
!>
!>  PRTYPE = 4 Completa
!>             A(i, j) = [-10...10]
!>             D(i, j) = [-1...1]    i,j = 1...M
!>             B(i, j) = [-10...10]
!>             E(i, j) = [-1...1]    i,j = 1...N
!>             R(i, j) = [-10...10]
!>             L(i, j) = [-1...1]    i = 1..M ,j = 1...N
!>
!>             L, R especifican los lados derechos (C, F).
!>
!>  PRTYPE = 5 caso especial valores propios comunes y/o cercanos.
!>
