NOMBRE

slapd-wt - Backend WiredTiger para slapd

SINOPSIS

/etc/openldap/slapd.conf

DESCRIPCIÓN

El backend wt de slapd(8) utiliza la biblioteca de base de datos WiredTiger para almacenar datos.

El backend wt es un módulo experimental que tiene un potencial de alto rendimiento de escritura y alta concurrencia. Este backend aún no tiene algunas funciones básicas. Haga una copia de seguridad de los datos usando slapcat antes de actualizar el módulo.

CONFIGURACIÓN

Estas opciones de slapd.conf se aplican a la base de datos del backend wt. Es decir, deben seguir una línea "database wt" y preceder a cualquier línea posterior de "backend" o "database". Otras opciones de base de datos se describen en la página del manual slapd.conf(5).

directorio <directorio>
Especifique el directorio principal de WiredTiger que contiene esta base de datos y los índices asociados. Se debe especificar un directorio separado para cada base de datos. El valor predeterminado es /var/lib/openldap/openldap-data.
idlcache <booleano>
Utilizar el idlcache en memoria. El valor predeterminado es verdadero.
indice {<lista_atributos>|por defecto} [pres,eq,approx,sub,<especial>]
Especifique los índices que se mantendrán para el atributo dado (o lista de atributos). Algunos atributos solo admiten un subconjunto de índices. Si solo se proporciona un <atributo>, se mantendrán los índices especificados para por defecto. Tenga en cuenta que establecer un valor predeterminado no implica que todos los atributos se indexarán. Además, para un rendimiento óptimo, siempre se debe configurar un índice eq para el atributo objectClass.
modo <entero>
back-wt no admite la opción de modo. utilice umask en su lugar.
wtconfig {crear,tamaño_cache=512M,asincrono=(habilitado)}
Especifique la configuración para wiredtiger, este parámetro se pasa a wiredtiger_open(3).
crear
crear la base de datos si no existe.
tamaño_cache
memoria máxima del heap a asignar para la caché.
asincrono
opciones de configuración de operaciones asíncronas. deshabilitado por defecto.

CONTROL DE ACCESO

El backend wt respeta la semántica de control de acceso tal como se indica en slapd.access(5).

ARCHIVOS

archivo de configuración predeterminado de slapd
