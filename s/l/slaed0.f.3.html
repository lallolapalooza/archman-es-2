subroutine slaed0 (integer icompq, integer qsiz, integer n, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldq, * ) q, integer ldq, real, dimension( ldqs, * ) qstore, integer ldqs, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLAED0 usado por SSTEDC. Calcula todos los valores propios y los vectores propios correspondientes de una matriz tridiagonal simétrica no reducida usando el método de divide y vencerás.

Propósito:

!>
!> SLAED0 calcula todos los valores propios y los vectores propios correspondientes
!> de una matriz tridiagonal simétrica utilizando el método de divide y
!> vencerás.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>          = 0:  Calcular solo los valores propios.
!>          = 1:  Calcular también los vectores propios de la matriz simétrica
!>                densa original. En la entrada, Q contiene la matriz ortogonal
!>                utilizada para reducir la matriz original a forma tridiagonal.
!>          = 2:  Calcular los valores propios y los vectores propios de la
!>                matriz tridiagonal.
!>

QSIZ

!>          QSIZ es INTEGER
!>         La dimensión de la matriz ortogonal utilizada para reducir la
!>         matriz completa a forma tridiagonal. QSIZ >= N si ICOMPQ = 1.
!>

N

!>          N es INTEGER
!>         La dimensión de la matriz tridiagonal simétrica. N >= 0.
!>

D

!>          D es array REAL, dimensión (N)
!>         En la entrada, la diagonal principal de la matriz tridiagonal.
!>         En la salida, sus valores propios.
!>

E

!>          E es array REAL, dimensión (N-1)
!>         Los elementos fuera de la diagonal de la matriz tridiagonal.
!>         En la salida, E ha sido destruido.
!>

Q

!>          Q es array REAL, dimensión (LDQ, N)
!>         En la entrada, Q debe contener una matriz ortogonal N x N.
!>         Si ICOMPQ = 0    Q no se referencia.
!>         Si ICOMPQ = 1    En la entrada, Q es un subconjunto de las columnas de la
!>                          matriz ortogonal utilizada para reducir la
!>                          matriz completa a forma tridiagonal, correspondiente
!>                          al subconjunto de la matriz completa que se está
!>                          descomponiendo en este momento.
!>         Si ICOMPQ = 2    En la entrada, Q será la matriz identidad.
!>                          En la salida, Q contiene los vectores propios de la
!>                          matriz tridiagonal.
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q. Si se desean vectores propios,
!>         entonces LDQ >= max(1,N). En cualquier caso, LDQ >= 1.
!>

QSTORE

!>          QSTORE es array REAL, dimensión (LDQS, N)
!>         Se referencia solo cuando ICOMPQ = 1. Se utiliza para almacenar
!>         partes de la matriz de vectores propios cuando se producen
!>         multiplicaciones de matrices de actualización.
!>

LDQS

!>          LDQS es INTEGER
!>         La dimensión principal del array QSTORE. Si ICOMPQ = 1,
!>         entonces LDQS >= max(1,N). En cualquier caso, LDQS >= 1.
!>

WORK

!>          WORK es array REAL,
!>         Si ICOMPQ = 0 o 1, la dimensión de WORK debe ser al menos
!>                     1 + 3*N + 2*N*lg N + 3*N**2
!>                     ( lg( N ) = entero más pequeño k
!>                                 tal que 2^k >= N )
!>         Si ICOMPQ = 2, la dimensión de WORK debe ser al menos
!>                     4*N + N**2.
!>

IWORK

!>          IWORK es array INTEGER,
!>         Si ICOMPQ = 0 o 1, la dimensión de IWORK debe ser al menos
!>                        6 + 6*N + 5*N*lg N.
!>                        ( lg( N ) = entero más pequeño k
!>                                    tal que 2^k >= N )
!>         Si ICOMPQ = 2, la dimensión de IWORK debe ser al menos
!>                        3 + 5*N.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo no pudo calcular un valor propio mientras
!>                trabajaba en la submatriz ubicada en las filas y columnas
!>                INFO/(N+1) hasta mod(INFO,N+1).
!>
