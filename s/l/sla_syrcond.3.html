real función sla_syrcond (character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, integer cmode, real, dimension( * ) c, integer info, real, dimension( * ) work, integer, dimension( * ) iwork)

SLA_SYRCOND estima el número de condición de Skeel para una matriz simétrica indefinida.

Propósito:

!>
!>    SLA_SYRCOND estima el número de condición de Skeel de op(A) * op2(C)
!>    donde op2 está determinado por CMODE de la siguiente manera:
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    El número de condición de Skeel cond(A) = norminf( |inv(A)||A| )
!>    se calcula calculando factores de escala R tales que
!>    diag(R)*A*op2(C) está equilibrado por filas y calculando el número
!>    de condición de norma infinito estándar.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array REAL, dimensión (LDAF,N)
!>     La matriz diagonal de bloques D y los multiplicadores utilizados para
!>     obtener U o L como se calculó por SSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     como se determinó por SSYTRF.
!>

CMODE

!>          CMODE es INTEGER
!>     Determina op2(C) en la fórmula op(A) * op2(C) de la siguiente manera:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C es array REAL, dimensión (N)
!>     El vector C en la fórmula op(A) * op2(C).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es array REAL, dimensión (3*N).
!>     Espacio de trabajo.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (N).
!>     Espacio de trabajo.
!>
