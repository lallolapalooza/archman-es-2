subroutine slaqr3 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, real, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, real, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, real, dimension( * ) sr, real, dimension( * ) si, real, dimension( ldv, * ) v, integer ldv, integer nh, real, dimension( ldt, * ) t, integer ldt, integer nv, real, dimension( ldwv, * ) wv, integer ldwv, real, dimension( * ) work, integer lwork)

SLAQR3 realiza la transformación de similitud ortogonal de una matriz de Hessenberg para detectar y reducir autovalores completamente convergidos de una submatriz principal (reducción temprana agresiva).

Propósito:

!>
!>    Reducción temprana agresiva:
!>
!>    SLAQR3 acepta como entrada una matriz de Hessenberg superior
!>    H y realiza una transformación de similitud ortogonal
!>    diseñada para detectar y reducir autovalores completamente convergidos de
!>    una submatriz principal final. En la salida, H ha sido
!>    sobrescrita por una nueva matriz de Hessenberg que es una perturbación de
!>    una transformación de similitud ortogonal de H. Se espera
!>    que la versión final de H tenga muchas entradas subdiagonales cero.
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>          Si .TRUE., entonces la matriz de Hessenberg H se actualiza completamente
!>          para que el factor de Schur cuasi-triangular pueda ser
!>          calculado (en cooperación con la subrutina llamante).
!>          Si .FALSE., entonces solo se actualiza suficiente de H para preservar
!>          los autovalores.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          Si .TRUE., entonces la matriz ortogonal Z se actualiza para
!>          que el factor de Schur ortogonal pueda ser calculado
!>          (en cooperación con la subrutina llamante).
!>          Si .FALSE., entonces Z no se referencia.
!>

N

!>          N es INTEGER
!>          El orden de la matriz H y (si WANTZ es .TRUE.) el
!>          orden de la matriz ortogonal Z.
!>

KTOP

!>          KTOP es INTEGER
!>          Se asume que KTOP = 1 o H(KTOP,KTOP-1)=0.
!>          KBOT y KTOP juntos determinan un bloque aislado
!>          a lo largo de la diagonal de la matriz de Hessenberg.
!>

KBOT

!>          KBOT es INTEGER
!>          Se asume sin verificación que KBOT = N o H(KBOT+1,KBOT)=0.
!>          KBOT y KTOP juntos determinan un bloque aislado a lo largo de la
!>          diagonal de la matriz de Hessenberg.
!>

NW

!>          NW es INTEGER
!>          Tamaño de la ventana de reducción.  1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H es un array REAL, dimension (LDH,N)
!>          En la entrada, la sección N-por-N inicial de H almacena la
!>          matriz de Hessenberg que está siendo sometida a reducción temprana agresiva.
!>          En la salida, H ha sido transformada por una transformación de similitud
!>          ortogonal, perturbada, y devuelta
!>          a forma de Hessenberg que (se espera) tiene algunas
!>          entradas subdiagonales cero.
!>

LDH

!>          LDH es INTEGER
!>          Dimensión principal de H tal como se declara en la subrutina
!>          llamante.  N <= LDH
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>          Especifican las filas de Z a las que se deben aplicar las transformaciones
!>          si WANTZ es .TRUE.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z es un array REAL, dimension (LDZ,N)
!>          SI WANTZ es .TRUE., entonces en la salida, la transformación de similitud
!>          ortogonal mencionada anteriormente ha sido
!>          acumulada en Z(ILOZ:IHIZ,ILOZ:IHIZ) desde la derecha.
!>          Si WANTZ es .FALSE., entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal de Z tal como se declara en la
!>          subrutina llamante.  1 <= LDZ.
!>

NS

!>          NS es INTEGER
!>          El número de autovalores no convergidos (es decir, aproximados)
!>          devueltos en SR y SI que pueden ser utilizados como desplazamientos por la
!>          subrutina llamante.
!>

ND

!>          ND es INTEGER
!>          El número de autovalores convergidos descubiertos por esta
!>          subrutina.
!>

SR

!>          SR es un array REAL, dimension (KBOT)
!>

SI

!>          SI es un array REAL, dimension (KBOT)
!>          En la salida, las partes real e imaginaria de los autovalores aproximados
!>          que pueden ser utilizados para desplazamientos se almacenan en
!>          SR(KBOT-ND-NS+1) hasta SR(KBOT-ND) y
!>          SI(KBOT-ND-NS+1) hasta SI(KBOT-ND), respectivamente.
!>          Las partes real e imaginaria de los autovalores convergidos
!>          se almacenan en SR(KBOT-ND+1) hasta SR(KBOT) y
!>          SI(KBOT-ND+1) hasta SI(KBOT), respectivamente.
!>

V

!>          V es un array REAL, dimension (LDV,NW)
!>          Un array de trabajo NW-por-NW.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de V tal como se declara en la
!>          subrutina llamante.  NW <= LDV
!>

NH

!>          NH es INTEGER
!>          El número de columnas de T.  NH >= NW.
!>

T

!>          T es un array REAL, dimension (LDT,NW)
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal de T tal como se declara en la
!>          subrutina llamante.  NW <= LDT
!>

NV

!>          NV es INTEGER
!>          El número de filas del array de trabajo WV disponibles para
!>          espacio de trabajo.  NV >= NW.
!>

WV

!>          WV es un array REAL, dimension (LDWV,NW)
!>

LDWV

!>          LDWV es INTEGER
!>          La dimensión principal de W tal como se declara en la
!>          subrutina llamante.  NW <= LDV
!>

WORK

!>          WORK es un array REAL, dimension (LWORK)
!>          En la salida, WORK(1) se establece en una estimación del valor óptimo
!>          de LWORK para los valores dados de N, NW, KTOP y KBOT.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array de trabajo WORK.  LWORK = 2*NW
!>          es suficiente, pero una mayor eficiencia puede resultar de valores
!>          más grandes de LWORK.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; SLAQR3
!>          solo estima el tamaño óptimo del espacio de trabajo para los valores
!>          dados de N, NW, KTOP y KBOT.  La estimación se devuelve
!>          en WORK(1).  XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>          Ni H ni Z se acceden.
!>
