NOMBRE

slapd-pw-sha2 - módulo de contraseña SHA-2 para slapd

SINOPSIS

ETCDIR/slapd.conf

moduleload pw-sha2

DESCRIPCIÓN

El módulo pw-sha2 para slapd(8) proporciona soporte para el uso de SSHA-512, SSHA-384, SSHA-256, SHA-512, SHA-384 y SHA-256 de la familia de funciones hash SHA-2 (FIPS 180-2) en contraseñas hasheadas en OpenLDAP.

Lo hace proporcionando los siguientes esquemas de contraseña adicionales para su uso en slapd:

{SSHA256}
SHA-256 con sal, dando valores hash de 256 bits de longitud
{SHA256}
SHA-256 simple, dando valores hash de 256 bits de longitud
{SSHA384}
SHA-384 con sal, dando valores hash de 384 bits de longitud
{SHA384}
SHA-384 simple, dando valores hash de 384 bits de longitud
{SSHA512}
SHA-512 con sal, dando valores hash de 512 bits de longitud
{SHA512}
SHA-512 simple, dando valores hash de 512 bits de longitud

CONFIGURACIÓN

El módulo pw-sha2 no necesita ninguna configuración.

Después de cargar el módulo, los esquemas de contraseña {SSHA256}, {SSHA384}, {SSHA512}, {SSHA256}, {SHA384} y {SHA512} serán reconocidos en los valores del atributo userPassword.

Entonces puede indicar a OpenLDAP que utilice estos esquemas al procesar las operaciones extendidas de modificación de contraseña LDAPv3 (RFC 3062) utilizando la opción password-hash en slapd.conf(5).

NOTAS

Si desea utilizar los esquemas descritos aquí con slappasswd(8), no olvide cargar el módulo usando sus opciones de línea de comandos. La opción/valor relevante es:

-o module-load=pw-sha2

Dependiendo de la ubicación de pw-sha2, también puede necesitar:

-o module-path=rutaespecificada

EJEMPLOS

Todos los atributos LDAP userPassword a continuación codifican la contraseña 'secret'.

userPassword: {SHA512}vSsar3708Jvp9Szi2NWZZ02Bqp1qRCFpbcTZPdBhnWgs5WtNZKnvCXdhztmeD2cmW192CF5bDufKRpayrW/isg==
userPassword: {SHA384}WKd1ukESvjAFrkQHznV9iP2nHUBJe7gCbsrFTU4//HIyzo3jq1rLMK45dg/ufFPt
userPassword: {SHA256}K7gNU3sdo+OL0wNhqoVWhr3g6s1xYv72ol/pe/Unols=

Para que {SSHA512} sea el hash de contraseña utilizado en las operaciones extendidas de modificación de contraseña, simplemente establezca esta línea en slapd.conf(5):

password-hash   {SSHA512}
