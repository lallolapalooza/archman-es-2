Documentación de la Función/Subrutina

subrutina slaruv (integer, dimension( 4 ) iseed, integer n, real, dimension( n ) x)

SLARUV devuelve un vector de n números reales aleatorios de una distribución uniforme.

Propósito:

!>
!> SLARUV devuelve un vector de n números reales aleatorios de una distribución
!> uniforme (0,1) (n <= 128).
!>
!> Esta es una subrutina auxiliar llamada por SLARNV y CLARNV.
!>

Parámetros

ISEED 
!>          ISEED es un array INTEGER, de dimensión (4)
!>          A la entrada, la semilla del generador de números aleatorios; los
!>          elementos del array deben estar entre 0 y 4095, y ISEED(4) debe
!>          ser impar.
!>          A la salida, la semilla se actualiza.
!>

N

!>          N es INTEGER
!>          El número de números aleatorios a generar. N <= 128.
!>

X

!>          X es un array REAL, de dimensión (N)
!>          Los números aleatorios generados.
!>

Detalles adicionales:

!>
!>  Esta subrutina utiliza un método congruencial multiplicativo con módulo
!>  2**48 y multiplicador 33952834046453 (ver G.S.Fishman,
!>  'Multiplicative congruential random number generators with modulus
!>  2**b: an exhaustive analysis for b = 32 and a partial analysis for
!>  b = 48', Math. Comp. 189, pp 331-344, 1990).
!>
!>  Los enteros de 48 bits se almacenan en 4 elementos de array de enteros con
!>  12 bits por elemento. Por lo tanto, la subrutina es portable en máquinas
!>  con enteros de 32 bits o más.
!>
