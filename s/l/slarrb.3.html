subrutina slarrb (integer n, real, dimension( * ) d, real, dimension( * ) lld, integer ifirst, integer ilast, real rtol1, real rtol2, integer offset, real, dimension( * ) w, real, dimension( * ) wgap, real, dimension( * ) werr, real, dimension( * ) work, integer, dimension( * ) iwork, real pivmin, real spdiam, integer twist, integer info)

SLARRB proporciona bisección limitada para localizar valores propios con mayor precisión.

Propósito:

!>
!> Dada la representación relativamente robusta (RRR) L D L^T, SLARRB
!> realiza bisección para refinar los valores propios de L D L^T,
!> W( IFIRST-OFFSET ) a W( ILAST-OFFSET ), con mayor precisión. Las
!> estimaciones iniciales para estos valores propios se introducen en W,
!> las estimaciones correspondientes del error en estas estimaciones y
!> sus brechas se introducen en WERR y WGAP, respectivamente. Durante la
!> bisección, los intervalos [left, right] se mantienen almacenando sus
!> puntos medios y semiamplitudes en los arrays W y WERR,
!> respectivamente.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz.
!>

D

!>          D es array REAL, dimension (N)
!>          Los N elementos diagonales de la matriz diagonal D.
!>

LLD

!>          LLD es array REAL, dimension (N-1)
!>          Los (N-1) elementos L(i)*L(i)*D(i).
!>

IFIRST

!>          IFIRST es INTEGER
!>          El índice del primer valor propio a calcular.
!>

ILAST

!>          ILAST es INTEGER
!>          El índice del último valor propio a calcular.
!>

RTOL1

!>          RTOL1 es REAL
!>

RTOL2

!>          RTOL2 es REAL
!>          Tolerancia para la convergencia de los intervalos de bisección.
!>          Un intervalo [LEFT,RIGHT] ha convergido si
!>          RIGHT-LEFT < MAX( RTOL1*GAP, RTOL2*MAX(|LEFT|,|RIGHT|) )
!>          donde GAP es la distancia (estimada) al valor propio más
!>          cercano.
!>

OFFSET

!>          OFFSET es INTEGER
!>          Desplazamiento para los arrays W, WGAP y WERR, es decir, se
!>          utilizarán los elementos IFIRST-OFFSET a ILAST-OFFSET de estos
!>          arrays.
!>

W

!>          W es array REAL, dimension (N)
!>          En la entrada, W( IFIRST-OFFSET ) a W( ILAST-OFFSET ) son
!>          estimaciones de los valores propios de L D L^T indexados IFIRST
!>          a ILAST.
!>          En la salida, estas estimaciones se refinan.
!>

WGAP

!>          WGAP es array REAL, dimension (N-1)
!>          En la entrada, las brechas (estimadas) entre valores propios
!>          consecutivos de L D L^T, es decir, WGAP(I-OFFSET) es la brecha
!>          entre los valores propios I e I+1. Tenga en cuenta que si
!>          IFIRST = ILAST, entonces WGAP(IFIRST-OFFSET) debe
!>          establecerse a CERO.
!>          En la salida, estas brechas se refinan.
!>

WERR

!>          WERR es array REAL, dimension (N)
!>          En la entrada, WERR( IFIRST-OFFSET ) a WERR( ILAST-OFFSET ) son
!>          los errores en las estimaciones de los elementos correspondientes
!>          en W.
!>          En la salida, estos errores se refinan.
!>

WORK

!>          WORK es array REAL, dimension (2*N)
!>          Espacio de trabajo.
!>

IWORK

!>          IWORK es array INTEGER, dimension (2*N)
!>          Espacio de trabajo.
!>

PIVMIN

!>          PIVMIN es REAL
!>          El pivote mínimo en la secuencia de Sturm.
!>

SPDIAM

!>          SPDIAM es REAL
!>          El diámetro espectral de la matriz.
!>

TWIST

!>          TWIST es INTEGER
!>          El índice de giro para la factorización girada que se utiliza
!>          para el negcount.
!>          TWIST = N: Calcula negcount de L D L^T - LAMBDA I = L+ D+ L+^T
!>          TWIST = 1: Calcula negcount de L D L^T - LAMBDA I = U- D- U-^T
!>          TWIST = R: Calcula negcount de L D L^T - LAMBDA I = N(r) D(r) N(r)
!>

INFO

!>          INFO es INTEGER
!>          Indicador de error.
!>
