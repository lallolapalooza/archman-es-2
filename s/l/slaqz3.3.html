ALPHAR

!>          ALPHAR es un array REAL, de dimensión (N)
!>          Las partes reales de cada escalar alpha que define un valor propio
!>          de GNEP.
!>

ALPHAI

!>          ALPHAI es un array REAL, de dimensión (N)
!>          Las partes imaginarias de cada escalar alpha que define un
!>          valor propio de GNEP.
!>          Si ALPHAI(j) es cero, entonces el j-ésimo valor propio es real; si
!>          es positivo, entonces el j-ésimo y (j+1)-ésimo valores propios son un
!>          par conjugado complejo, con ALPHAI(j+1) = -ALPHAI(j).
!>

BETA

!>          BETA es un array REAL, de dimensión (N)
!>          Los escalares beta que definen los valores propios de GNEP.
!>          Juntos, las cantidades alpha = (ALPHAR(j),ALPHAI(j)) y
!>          beta = BETA(j) representan el j-ésimo valor propio del par de matrices
!>          (A,B), en una de las formas lambda = alpha/beta o
!>          mu = beta/alpha. Como lambda o mu pueden desbordarse,
!>          no deben, en general, ser calculados.

!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal

LAPACK slaqz3(3)

NOMBRE

slaqz3 - Esta subrutina es parte de LAPACK.

SINOPSIS

subroutine slaqz3(n, k, zl, icompz, alpha, beta, t, ldt, b, ldb, q, ldq, z, ldz, work, info)

Documentación de Función/Subrutina

slaqz3 calcula los bloques de Schur de una matriz triangular superior generalizada (generalizada A*z = lambda*B*z). Los resultados se devuelven en la matriz triangular superior generalizada T.

Argumentos:

  • n: (entrada) entero. El orden de las matrices T y B.
  • k: (entrada) entero. El número de pares de valores propios deseados.
  • zl: (entrada) real de precisión simple de tamaño (N, N). Matriz de entrada triangular superior izquierda.
  • icompz: (entrada) entero. Indica si se deben calcular o no los vectores propios de Z.
  • alpha: (salida) real de precisión simple de tamaño (N).
  • beta: (salida) real de precisión simple de tamaño (N).
  • t: (salida) real de precisión simple de tamaño (LDT, N).
  • ldt: (entrada) entero. El primer de las dimensiones de T.
  • b: (salida) real de precisión simple de tamaño (LDB, N).
  • ldb: (entrada) entero. El primer de las dimensiones de B.
  • q: (salida) real de precisión simple de tamaño (LDQ, N).
  • ldq: (entrada) entero. El primer de las dimensiones de Q.
  • z: (salida) real de precisión simple de tamaño (LDZ, N).
  • ldz: (entrada) entero. El primer de las dimensiones de Z.
  • work: (salida) real de precisión simple de tamaño (N*N).
  • info: (salida) entero.
