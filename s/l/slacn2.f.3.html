Documentación de función/subrutina

subrutina slacn2 (integer n, real, dimension( * ) v, real, dimension( * ) x, integer, dimension( * ) isgn, real est, integer kase, integer, dimension( 3 ) isave)

SLACN2 estima la norma 1 de una matriz cuadrada real, utilizando comunicación inversa para evaluar productos matriz-vector.

Propósito:

!>
!> SLACN2 estima la norma 1 de una matriz cuadrada real A.
!> Se utiliza comunicación inversa para evaluar productos matriz-vector.
!>

Parámetros

N 
!>          N es ENTERO
!>         El orden de la matriz.  N >= 1.
!>

V

!>          V es un array REAL, dimensión (N)
!>         En el retorno final, V = A*W,  donde  EST = norm(V)/norm(W)
!>         (W no se devuelve).
!>

X

!>          X es un array REAL, dimensión (N)
!>         En un retorno intermedio, X debe ser sobrescrito por
!>               A * X,   si KASE=1,
!>               A**T * X,  si KASE=2,
!>         y SLACN2 debe ser llamado de nuevo con todos los demás parámetros
!>         sin cambios.
!>

ISGN

!>          ISGN es un array ENTERO, dimensión (N)
!>

EST

!>          EST es REAL
!>         Al ingresar con KASE = 1 o 2 e ISAVE(1) = 3, EST debe ser
!>         sin cambios desde la llamada anterior a SLACN2.
!>         Al salir, EST es una estimación (un límite inferior) para norm(A).
!>

KASE

!>          KASE es ENTERO
!>         En la llamada inicial a SLACN2, KASE debe ser 0.
!>         En un retorno intermedio, KASE será 1 o 2, indicando
!>         si X debe ser sobrescrito por A * X  o A**T * X.
!>         En el retorno final desde SLACN2, KASE volverá a ser 0.
!>

ISAVE

!>          ISAVE es un array ENTERO, dimensión (3)
!>         ISAVE se usa para guardar variables entre llamadas a SLACN2
!>
