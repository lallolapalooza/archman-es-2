Documentación de Función/Subrutina

subrutina slarrj (integer n, real, dimension( * ) d, real, dimension( * ) e2, integer ifirst, integer ilast, real rtol, integer offset, real, dimension( * ) w, real, dimension( * ) werr, real, dimension( * ) work, integer, dimension( * ) iwork, real pivmin, real spdiam, integer info)

SLARRJ realiza el refinamiento de las estimaciones iniciales de los autovalores de la matriz T.

Propósito:

!>
!> Dados las aproximaciones iniciales de autovalores de T, SLARRJ
!> realiza bisección para refinar los autovalores de T,
!> W( IFIRST-OFFSET ) hasta W( ILAST-OFFSET ), a mayor precisión. Las
!> suposiciones iniciales para estos autovalores se introducen en W, la
!> estimación correspondiente del error en estas suposiciones en WERR.
!> Durante la bisección, se mantienen intervalos [left, right] almacenando
!> sus puntos medios y semi-anchuras en los arrays W y WERR respectivamente.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz.
!>

D

!>          D es array REAL, dimension (N)
!>          Los N elementos diagonales de T.
!>

E2

!>          E2 es array REAL, dimension (N-1)
!>          Los cuadrados de los (N-1) elementos subdiagonales de T.
!>

IFIRST

!>          IFIRST es INTEGER
!>          El índice del primer autovalor a calcular.
!>

ILAST

!>          ILAST es INTEGER
!>          El índice del último autovalor a calcular.
!>

RTOL

!>          RTOL es REAL
!>          Tolerancia para la convergencia de los intervalos de bisección.
!>          Un intervalo [LEFT,RIGHT] ha convergido si
!>          RIGHT-LEFT < RTOL*MAX(|LEFT|,|RIGHT|).
!>

OFFSET

!>          OFFSET es INTEGER
!>          Desplazamiento para los arrays W y WERR, es decir, se usarán los
!>          elementos IFIRST-OFFSET a ILAST-OFFSET de estos arrays.
!>

W

!>          W es array REAL, dimension (N)
!>          En la entrada, W( IFIRST-OFFSET ) a W( ILAST-OFFSET ) son
!>          estimaciones de los autovalores de L D L^T indexados IFIRST a
!>          ILAST.
!>          En la salida, estas estimaciones son refinadas.
!>

WERR

!>          WERR es array REAL, dimension (N)
!>          En la entrada, WERR( IFIRST-OFFSET ) a WERR( ILAST-OFFSET ) son
!>          los errores en las estimaciones de los elementos correspondientes
!>          en W.
!>          En la salida, estos errores son refinados.
!>

WORK

!>          WORK es array REAL, dimension (2*N)
!>          Espacio de trabajo.
!>

IWORK

!>          IWORK es array INTEGER, dimension (2*N)
!>          Espacio de trabajo.
!>

PIVMIN

!>          PIVMIN es REAL
!>          El pivote mínimo en la secuencia de Sturm para T.
!>

SPDIAM

!>          SPDIAM es REAL
!>          El diámetro espectral de T.
!>

INFO

!>          INFO es INTEGER
!>          Indicador de error.
!>
