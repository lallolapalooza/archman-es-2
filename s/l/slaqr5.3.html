SLAQR5 realiza un único barrido QR de QR de múltiples saltos de burbuja pequeña.

Propósito:

!>
!>    SLAQR5, llamado por SLAQR0, realiza un
!>    único barrido QR de QR de múltiples saltos de burbuja pequeña.
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>             WANTT = .true. si se está calculando el factor de Schur
!>             casi-triangular.  WANTT se establece en .false. en caso contrario.
!>

WANTZ

!>          WANTZ es LOGICAL
!>             WANTZ = .true. si se está calculando el factor de Schur
!>             ortogonal.  WANTZ se establece en .false. en caso contrario.
!>

KACC22

!>          KACC22 es INTEGER con valor 0, 1 o 2.
!>             Especifica el modo de cálculo de las actualizaciones ortogonales
!>             lejanas a la diagonal.
!>        = 0: SLAQR5 no acumula reflexiones y no utiliza la multiplicación
!>             matriz-matriz para actualizar las entradas de la matriz
!>             lejanas a la diagonal.
!>        = 1: SLAQR5 acumula reflexiones y utiliza la multiplicación
!>             matriz-matriz para actualizar las entradas de la matriz
!>             lejanas a la diagonal.
!>        = 2: Igual que KACC22 = 1. Esta opción se usaba para permitir
!>             explotar la estructura 2x2 durante las multiplicaciones de
!>             matrices, pero esto ya no es compatible.
!>

N

!>          N es INTEGER
!>             N es el orden de la matriz de Hessenberg H sobre la que opera
!>             esta subrutina.
!>

KTOP

!>          KTOP es INTEGER
!>

KBOT

!>          KBOT es INTEGER
!>             Estas son las filas y columnas primera y última de un bloque
!>             diagonal aislado sobre el que se aplicará el barrido QR.
!>             Se asume sin comprobación que
!>                       o bien KTOP = 1  o   H(KTOP,KTOP-1) = 0
!>             y
!>                       o bien KBOT = N  o   H(KBOT+1,KBOT) = 0.
!>

NSHFTS

!>          NSHFTS es INTEGER
!>             NSHFTS indica el número de saltos simultáneos. NSHFTS debe
!>             ser positivo y par.
!>

SR

!>          SR es un array REAL, dimension (NSHFTS)
!>

SI

!>          SI es un array REAL, dimension (NSHFTS)
!>             SR contiene las partes reales y SI contiene las partes
!>             imaginarias de los NSHFTS saltos de origen que definen el
!>             barrido QR de múltiples saltos. A la salida, SR y SI pueden
!>             estar reordenados.
!>

H

!>          H es un array REAL, dimension (LDH,N)
!>             A la entrada, H contiene una matriz de Hessenberg. A la
!>             salida, se aplica un barrido QR de múltiples saltos con
!>             saltos SR(J)+i*SI(J) al bloque diagonal aislado en las
!>             filas y columnas KTOP hasta KBOT.
!>

LDH

!>          LDH es INTEGER
!>             LDH es la dimensión principal de H tal como se declara en
!>             el procedimiento de llamada. LDH >= MAX(1,N).
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>             Especifican las filas de Z a las que se deben aplicar
!>             transformaciones si WANTZ es .TRUE.. 1 <= ILOZ <= IHIZ <= N
!>

Z

!>          Z es un array REAL, dimension (LDZ,IHIZ)
!>             Si WANTZ = .TRUE., entonces la transformación de semejanza
!>             ortogonal del barrido QR se acumula en
!>             Z(ILOZ:IHIZ,ILOZ:IHIZ) desde la derecha.
!>             Si WANTZ = .FALSE., entonces Z no se utiliza.
!>

LDZ

!>          LDZ es INTEGER
!>             LDA es la dimensión principal de Z tal como se declara en
!>             el procedimiento de llamada. LDZ >= N.
!>

V

!>          V es un array REAL, dimension (LDV,NSHFTS/2)
!>

LDV

!>          LDV es INTEGER
!>             LDV es la dimensión principal de V tal como se declara en
!>             el procedimiento de llamada. LDV >= 3.
!>

U

!>          U es un array REAL, dimension (LDU,2*NSHFTS)
!>

LDU

!>          LDU es INTEGER
!>             LDU es la dimensión principal de U tal como se declara en
!>             la subrutina de llamada. LDU >= 2*NSHFTS.
!>

NV

!>          NV es INTEGER
!>             NV es el número de filas en WV disponibles para espacio de
!>             trabajo. NV >= 1.
!>

WV

!>          WV es un array REAL, dimension (LDWV,2*NSHFTS)
!>

LDWV

!>          LDWV es INTEGER
!>             LDWV es la dimensión principal de WV tal como se declara en
!>             la subrutina de llamada. LDWV >= NV.
!>

NH

!>          NH es INTEGER
!>             NH es el número de columnas en el array WH disponibles para
!>             espacio de trabajo. NH >= 1.
!>

WH

!>          WH es un array REAL, dimension (LDWH,NH)
!>

LDWH

!>          LDWH es INTEGER
!>             Dimensión principal de WH tal como se declara en el
!>             procedimiento de llamada. LDWH >= 2*NSHFTS.
!>

NOMBRE

slaqr5 - esta rutina invoca la fase de deflación de un algoritmo de Divide y Vencerás para calcular los valores propios de una matriz Hessenberg bidiagonal casi triangular.

SINOPSIS

SUBROUTINE SLAQR5( N, KNT, EXC, NMAT, SL, SR, LDX, X, LDX, TOL, NL, NR, NDIV )

    IMPLICIT NONE

    INTEGER :: EXC, KNT, N, NMAT
    REAL, DIMENSION( * ) :: SL, SR
    REAL :: TOL
    INTEGER :: LDX, NL, NR, NDIV
    REAL, DIMENSION( * ) :: X

Documentación de Funciones/Subrutinas

SLAQR5 (N, KNT, EXC, NMAT, SL, SR, LDX, X, LDX, TOL, NL, NR, NDIV)

  • Argumentos de entrada:

    • N: el orden de la matriz de Hessenberg.
    • KNT: el número de valores propios que se computarán.
    • EXC: una bandera que indica si los valores propios de interés son los menores o los mayores.
    • NMAT: el número de matrices de Hessenberg a las que se aplica la rutina.
    • SL: el valor propio más pequeño de la submatriz superior.
    • SR: el valor propio más grande de la submatriz inferior.
    • TOL: una tolerancia utilizada para decidir cuándo se puede ignorar un valor propio.
    • X: la matriz de Hessenberg.
    • LDX: el tamaño de la fila de X.

  • Argumentos de salida:

    • NL: el número de valores propios de la submatriz superior que son menores o iguales a SL.
    • NR: el número de valores propios de la submatriz inferior que son mayores o iguales a SR.
    • NDIV: el número de divisiones que se producen durante la deflación.
