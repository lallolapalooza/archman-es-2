Documentación de Función/Subrutina

subrutina recursiva slarft (character direct, character storev, integer n, integer k, real, dimension( ldv, * ) v, integer ldv, real, dimension( * ) tau, real, dimension( ldt, * ) t, integer ldt)

SLARFT forma el factor triangular T de un reflector de bloque real H.

Propósito:

!>
!> SLARFT forma el factor triangular T de un reflector de bloque real H
!> de orden n, que se define como un producto de k reflectores elementales.
!>
!> Si DIRECT = 'F', H = H(1) H(2) . . . H(k) y T es triangular superior;
!>
!> Si DIRECT = 'B', H = H(k) . . . H(2) H(1) y T es triangular inferior.
!>
!> Si STOREV = 'C', el vector que define el reflector elemental
!> H(i) se almacena en la i-ésima columna de la matriz V, y
!>
!>    H  =  I - V * T * V**T
!>
!> Si STOREV = 'R', el vector que define el reflector elemental
!> H(i) se almacena en la i-ésima fila de la matriz V, y
!>
!>    H  =  I - V**T * T * V
!>

Parámetros

DIRECT 
!>          DIRECT es CHARACTER*1
!>          Especifica el orden en el que se multiplican los reflectores elementales
!>          para formar el reflector de bloque:
!>          = 'F': H = H(1) H(2) . . . H(k) (Adelante)
!>          = 'B': H = H(k) . . . H(2) H(1) (Atrás)
!>

STOREV

!>          STOREV es CHARACTER*1
!>          Especifica cómo se almacenan los vectores que definen los reflectores
!>          elementales (ver también Detalles adicionales):
!>          = 'C': por columnas
!>          = 'R': por filas
!>

N

!>          N es INTEGER
!>          El orden del reflector de bloque H. N >= 0.
!>

K

!>          K es INTEGER
!>          El orden del factor triangular T (= el número de
!>          reflectores elementales). K >= 1.
!>

V

!>          V es una matriz REAL, de dimensión
!>                               (LDV,K) si STOREV = 'C'
!>                               (LDV,N) si STOREV = 'R'
!>          La matriz V. Ver detalles adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de la matriz V.
!>          Si STOREV = 'C', LDV >= max(1,N); si STOREV = 'R', LDV >= K.
!>

TAU

!>          TAU es una matriz REAL, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector elemental
!>          H(i).
!>

T

!>          T es una matriz REAL, de dimensión (LDT,K)
!>          El factor triangular T de k por k del reflector de bloque.
!>          Si DIRECT = 'F', T es triangular superior; si DIRECT = 'B', T es
!>          triangular inferior. El resto de la matriz no se utiliza.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal de la matriz T. LDT >= K.
!>

Detalles adicionales:

!>
!>  La forma de la matriz V y el almacenamiento de los vectores que definen
!>  los H(i) se ilustran mejor con el siguiente ejemplo con n = 5 y
!>  k = 3. Los elementos iguales a 1 no se almacenan.
!>
!>  DIRECT = 'F' y STOREV = 'C':         DIRECT = 'F' y STOREV = 'R':
!>
!>               V = (  1       )                 V = (  1 v1 v1 v1 v1 )
!>                   ( v1  1    )                     (     1 v2 v2 v2 )
!>                   ( v1 v2  1 )                     (        1 v3 v3 )
!>                   ( v1 v2 v3 )
!>                   ( v1 v2 v3 )
!>
!>  DIRECT = 'B' y STOREV = 'C':         DIRECT = 'B' y STOREV = 'R':
!>
!>               V = ( v1 v2 v3 )                 V = ( v1 v1  1       )
!>                   ( v1 v2 v3 )                     ( v2 v2 v2  1    )
!>                   (  1 v2 v3 )                     ( v3 v3 v3 v3  1 )
!>                   (     1 v3 )
!>                   (        1 )
!>
