Documentación de función/subrutina

subrutina slartgp (real f, real g, real cs, real sn, real r)

SLARTGP genera una rotación de plano para que la diagonal sea no negativa.

Propósito:

!>
!> SLARTGP genera una rotación de plano tal que
!>
!>    [  CS  SN  ]  .  [ F ]  =  [ R ]   donde CS**2 + SN**2 = 1.
!>    [ -SN  CS  ]     [ G ]     [ 0 ]
!>
!> Esta es una versión más lenta y precisa de la rutina SROTG de BLAS Nivel 1,
!> con las siguientes otras diferencias:
!>    F y G no se modifican al regresar.
!>    Si G=0, entonces CS=(+/-)1 y SN=0.
!>    Si F=0 y (G .ne. 0), entonces CS=0 y SN=(+/-)1.
!>
!> El signo se elige de manera que R >= 0.
!>

Parámetros

F 
!>          F es REAL
!>          El primer componente del vector a rotar.
!>

G

!>          G es REAL
!>          El segundo componente del vector a rotar.
!>

CS

!>          CS es REAL
!>          El coseno de la rotación.
!>

SN

!>          SN es REAL
!>          El seno de la rotación.
!>

R

!>          R es REAL
!>          El componente no nulo del vector rotado.
!>
!>  Esta versión tiene algunas sentencias comentadas para seguridad de hilos
!>  (los parámetros de máquina se calculan en cada entrada). 10 feb 03, SJH.
!>
