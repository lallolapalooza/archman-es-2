subroutine sla_syrfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, real, dimension( * ) c, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldy, * ) y, integer ldy, real, dimension( * ) berr_out, integer n_norms, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, real, dimension( * ) res, real, dimension( * ) ayb, real, dimension( * ) dy, real, dimension( * ) y_tail, real rcond, integer ithresh, real rthresh, real dz_ub, logical ignore_cwise, integer info)

SLA_SYRFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices simétricas indefinidas realizando un refinamiento iterativo de precisión extra y proporciona cotas de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!>
!> SLA_SYRFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión extra
!> y proporciona cotas de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por SSYRFSX para realizar el refinamiento iterativo.
!> Además de la cota de error normwise, el código proporciona la cota de error
!> componente a componente máxima si es posible. Ver los comentarios para ERR_BNDS_NORM
!> y ERR_BNDS_COMP para detalles de las cotas de error. Tener en cuenta que esta
!> subrutina solo es responsable de establecer los segundos campos de
!> ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a ser utilizada en el refinamiento.
!>     El valor está definido por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>     En la entrada, la matriz N-por-N A.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array REAL, dimensión (LDAF,N)
!>     La matriz de bloques diagonales D y los multiplicadores utilizados para
!>     obtener la factor U o L como fue calculado por SSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     como fue determinada por SSYTRF.
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó una   equilibración de columnas en A antes de llamar
!>     a esta rutina. Esto es necesario para calcular la solución y las cotas de error
!>     correctamente.
!>

C

!>          C es array REAL, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE.,
!>     C no se accede. Si se introduce C, cada elemento de C debe ser una potencia
!>     de la base para asegurar una solución y estimaciones de error confiables.
!>     La escala por potencias de la base no causa errores de redondeo a menos
!>     que el resultado sea subdesbordamiento o desbordamiento. Los errores de redondeo durante el escalado
!>     llevan a refinar con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     confiables.
!>

B

!>          B es array REAL, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es array REAL, dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, como fue calculada por SSYTRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es array REAL, dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error hacia atrás relativo
!>     componente a componente para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto componente a componente de la matriz
!>     o vector Z. Esto es calculado por SLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué cotas de error devolver (ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve cotas de error normwise.
!>     Si N_NORMS >= 2 devuelve cotas de error componente a componente.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  cota de error: El error hacia adelante estimado,
!>              casi con seguridad dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Esta cota de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimado normwise
!>

sla_syrfsx_extended(3)

NAME

sla_syrfsx_extended -sla_syrfsx_extended

SYNOPSIS

   SUBROUTINE SLA_SYRFSX_EXTENDED(
      UPLO, N, NRHS, A, LDA, AF, LDAF, IPIV, B, LDB, X, LDX,
      ERR_BNDS_NORM, ERR_BNDS_COMP, RES, AYB, DY, Y_TAIL, RCOND,
      ITHRESH, RTHRESH, DZ_UB, IGNORE_CWISE, INFO
   )

Function/Subroutine Documentation

SLA_SYRFSX_EXTENDED routines refine solutions to a system of linear equations in a scaled, componentwise fashion.

This subroutine has been replaced by the SLA_SYRFSX routine. Users should migrate to SLA_SYRFSX. The routine is designed to provide more accuracy than SLA_SYRFS.

The purpose of SLA_SYRFSX_EXTENDED is to compute error bounds and estimate the reciprocal condition number for a solution to a system of linear equations where the matrix is symmetric or Hermitian.

This routine is part of the LAPACK driver routines for solving systems of linear equations.

Arguments

UPLO
CHARACTER*1.

Specifies whether the following matrices are upper or lower triangular.

= 'U': Upper triangle of A and AF are stored.

= 'L': Lower triangle of A and AF are stored.

N
INTEGER.

The number of linear equations, i.e., the dimension of the matrix A. N >= 0.

NRHS
INTEGER.

The number of right hand sides, i.e., the number of columns of the matrices B, X, RES, AYB, DY, Y_TAIL. NRHS >= 0.

A
REAL array, dimension (LDA,N).

The original coefficient matrix A. Only the UPLO part of A is accessed.

LDA
INTEGER.

The leading dimension of the array A. LDA >= max(1,N).

AF
REAL array, dimension (LDAF,N).

The factored coefficient matrix A, as returned by SLA_SYTF. Only the UPLO part of AF is accessed.

LDAF
INTEGER.

The leading dimension of the array AF. LDAF >= max(1,N).

IPIV
INTEGER array, dimension (N).

The pivot indices, as returned by SLA_SYTF.

B
REAL array, dimension (LDB,NRHS).

The original right hand side matrix B.

LDB
INTEGER.

The leading dimension of the array B. LDB >= max(1,N).

X
REAL array, dimension (LDX,NRHS).

On entry, the solution matrix X, as returned by SLA_SYTRS.

LDX
INTEGER.

The leading dimension of the array X. LDX >= max(1,N).

ERR_BNDS_NORM
REAL array, dimension (NRHS, N_ERR_BNDS).

For each right-hand side, this array contains information about various error bounds and condition numbers corresponding to the normwise relative error, which is defined as follows:

Normwise relative error in the solution:

norm(XTRUE - X, inf) / norm(X, inf)

The array is indexed by the right-hand side i (on which the normwise relative error depends), and the type of error information as described below. There currently are up to three pieces of information returned for each right-hand side. If normwise accuracy is not requested (PARAMS(1) = 0.0), then ERR_BNDS_NORM is not accessed. If N_ERR_BNDS < 3, then at most the first (:,N_ERR_BNDS) entries are returned.

The first index in ERR_BNDS_NORM(i,:) corresponds to the ith right-hand side.

The second index in ERR_BNDS_NORM(:,err) contains the following three fields:

err = 1 boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').

err = 2 error bound: The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.

err = 3 Reciprocal condition number: Estimated scaled reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z. Let Z = S*A, where S scales each row by a power of the radix so all absolute row sums of Z are approximately 1.

This subroutine is only responsible for setting the second field above.

See Lapack Working Note 165 for further details and extra cautions.

ERR_BNDS_COMP
REAL array, dimension (NRHS, N_ERR_BNDS)

For each right-hand side, this array contains information about various error bounds and condition numbers corresponding to the componentwise relative error, which is defined as follows:

Componentwise relative error in the ith solution vector:

abs(XTRUE(j,i) - X(j,i))

max_j ----------------------

abs(X(j,i))

The array is indexed by the right-hand side i (on which the componentwise relative error depends), and the type of error information as described below. There currently are up to three pieces of information returned for each right-hand side. If componentwise accuracy is not requested (PARAMS(3) = 0.0), then ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most the first (:,N_ERR_BNDS) entries are returned.

The first index in ERR_BNDS_COMP(i,:) corresponds to the ith right-hand side.

The second index in ERR_BNDS_COMP(:,err) contains the following three fields:

err = 1 boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').

err = 2 error bound: The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.

err = 3 Reciprocal condition number: Estimated componentwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z. Let Z = S*(A*diag(x)), where x is the solution for the current right-hand side and S scales each row of A*diag(x) by a power of the radix so all absolute row sums of Z are approximately 1.

This subroutine is only responsible for setting the second field above.

See Lapack Working Note 165 for further details and extra cautions.

RES
REAL array, dimension (N)

Workspace to hold the intermediate residual.

AYB
REAL array, dimension (N)

Workspace. This can be the same workspace passed for Y_TAIL.

DY
REAL array, dimension (N)

Workspace to hold the intermediate solution.

Y_TAIL
REAL array, dimension (N)

Workspace to hold the trailing bits of the intermediate solution.

RCOND
REAL

Reciprocal scaled condition number. This is an estimate of the reciprocal Skeel condition number of the matrix A after equilibration (if done). If this is less than the machine precision (in particular, if it is zero), the matrix is singular to working precision. Note that the error may still be small even if this number is very small and the matrix appears ill-conditioned.

ITHRESH
INTEGER

The maximum number of residual computations allowed for refinement. The default is 10. For 'aggressive' set to 100 to permit convergence using approximate factorizations or factorizations other than LU. If the factorization uses a technique other than Gaussian elimination, the guarantees in ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be trustworthy.

RTHRESH
REAL

Determines when to stop refinement if the error estimate stops decreasing. Refinement will stop when the next solution no longer satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The default value is 0.5. For 'aggressive' set to 0.9 to permit convergence on extremely ill- conditioned matrices. See LAWN 165 for more details.

DZ_UB
REAL

Determines when to start considering componentwise convergence. Componentwise convergence is only considered after each component of the solution Y is stable, which we define as the relative change in each component being less than DZ_UB. The default value is 0.25, requiring the first bit to be stable. See LAWN 165 for more details.

IGNORE_CWISE
LOGICAL

If .TRUE. then ignore componentwise convergence. Default value is .FALSE..

INFO
INTEGER.

= 0: Successful exit.

< 0: if INFO = -i, the ith argument to SLA_SYRFSX_EXTENDED had an illegal value
