SLEEP(1P) Manual del programador POSIX SLEEP(1P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sleep — suspender la ejecución por un intervalo

SINOPSIS

sleep tiempo

DESCRIPCIÓN

La utilidad sleep suspenderá la ejecución durante al menos el número integral de segundos especificado por el operando tiempo.

OPCIONES

Ninguna.

OPERANDOS

Se soportará el siguiente operando:

tiempo
Un entero decimal no negativo que especifica el número de segundos durante los cuales se suspenderá la ejecución.

ENTRADA ESTÁNDAR

No se utiliza.

ARCHIVOS DE ENTRADA

Ninguno.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de sleep:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en una cadena de valor no vacía, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en los argumentos).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en la salida estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASINCRONOS

Si la utilidad sleep recibe una señal SIGALRM, se tomará una de las siguientes acciones:

1.
Terminar normalmente con un estado de salida cero.
2.
Ignorar efectivamente la señal.
3.
Proporcionar el comportamiento predeterminado para las señales descrito en la sección EVENTOS ASINCRONOS de Sección 1.4, Valores Predeterminados de la Descripción de Utilidades. Esto podría incluir terminar con un estado de salida distinto de cero.

La utilidad sleep tomará la acción estándar para todas las demás señales.

SALIDA ESTÁNDAR

No se utiliza.

ERROR ESTÁNDAR

El error estándar se utilizará solo para mensajes de diagnóstico.

ARCHIVOS DE SALIDA

Ninguno.

DESCRIPCIÓN EXTENDIDA

Ninguna.

ESTADO DE SALIDA

Se devolverán los siguientes valores de salida:

 0
La ejecución se suspendió con éxito durante al menos tiempo segundos, o se recibió una señal SIGALRM. Consulte la sección EVENTOS ASINCRONOS.
>0
Ocurrió un error.

CONSECUENCIAS DE ERRORES

Predeterminado.

USO DE APLICACIONES

Ninguno.

EJEMPLOS

La utilidad sleep se puede usar para ejecutar un comando después de un cierto tiempo, como en:

(sleep 105; comando) &

o para ejecutar un comando de vez en cuando, como en:

while true
do
    comando
    sleep 37
done

RACIONALE

Se permite que el estado de salida sea cero cuando sleep es interrumpido por la señal SIGALRM porque la mayoría de las implementaciones de esta utilidad dependen de la llegada de esa señal para notificarles que el tiempo de finalización solicitado se ha alcanzado con éxito. Dichas implementaciones, por lo tanto, no distinguen esta situación del caso de finalización exitosa. Se permite que otras implementaciones capturen la señal y vuelvan a dormir hasta que expire el tiempo solicitado o proporcionen los procedimientos normales de terminación de señales.

Al igual que con todas las demás utilidades que toman operandos enteros y no especifican subrangos de valores permitidos, sleep está obligada por este volumen de POSIX.1‐2017 a tratar las solicitudes de tiempo de hasta 2147483647 segundos. Esto puede significar que algunas implementaciones tengan que realizar múltiples llamadas al mecanismo de retardo del sistema operativo subyacente si su rango de argumentos es menor que este.
