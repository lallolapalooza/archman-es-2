Documentación de la función/subrutina

subrutina slartg (real(wp) f, real(wp) g, real(wp) c, real(wp) s, real(wp) r)

SLARTG genera una rotación de plano con coseno real y seno real.

Propósito:

!>
!> SLARTG genera una rotación de plano tal que
!>
!>    [  C  S  ]  .  [ F ]  =  [ R ]
!>    [ -S  C  ]     [ G ]     [ 0 ]
!>
!> donde C**2 + S**2 = 1.
!>
!> Las fórmulas matemáticas utilizadas para C y S son
!>    R = sign(F) * sqrt(F**2 + G**2)
!>    C = F / R
!>    S = G / R
!> Por lo tanto C >= 0. El algoritmo utilizado para calcular estas cantidades
!> incorpora escalado para evitar desbordamiento o subdesbordamiento al calcular
!> la raíz cuadrada de la suma de cuadrados.
!>
!> Esta versión es discontinua en R en F = 0 pero devuelve la misma
!> C y S que CLARTG para entradas complejas (F,0) y (G,0).
!>
!> Esta es una versión más precisa de la rutina SROTG de BLAS1,
!> con las siguientes diferencias adicionales:
!>    F y G no se modifican al regresar.
!>    Si G=0, entonces C=1 y S=0.
!>    Si F=0 y (G .ne. 0), entonces C=0 y S=sign(1,G) sin realizar ninguna
!>       operación de punto flotante (ahorra trabajo en SBDSQR cuando
!>       hay ceros en la diagonal).
!>
!> Abajo, wp=>sp significa precisión simple del módulo LA_CONSTANTS.
!>

Parámetros

F 
!>          F es REAL(wp)
!>          El primer componente del vector a rotar.
!>

G

!>          G es REAL(wp)
!>          El segundo componente del vector a rotar.
!>

C

!>          C es REAL(wp)
!>          El coseno de la rotación.
!>

S

!>          S es REAL(wp)
!>          El seno de la rotación.
!>

R

!>          R es REAL(wp)
!>          El componente no nulo del vector rotado.
!>
