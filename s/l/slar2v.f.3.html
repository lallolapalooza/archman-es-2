Funciones/Subrutinas


subrutina slar2v (n, x, y, z, incx, c, s, incc)
SLAR2V aplica un vector de rotaciones de plano con cosenos reales y senos reales por ambos lados a una secuencia de matrices simétricas/hermitianas de 2x2.

Documentación de la función/subrutina

subrutina slar2v (integer n, real, dimension( * ) x, real, dimension( * ) y, real, dimension( * ) z, integer incx, real, dimension( * ) c, real, dimension( * ) s, integer incc)

SLAR2V aplica un vector de rotaciones de plano con cosenos reales y senos reales por ambos lados a una secuencia de matrices simétricas/hermitianas de 2x2.

Propósito:

!>
!> SLAR2V aplica un vector de rotaciones de plano reales por ambos lados a
!> una secuencia de matrices reales simétricas de 2x2, definidas por los
!> elementos de los vectores x, y y z. Para i = 1,2,...,n
!>
!>    ( x(i)  z(i) ) := (  c(i)  s(i) ) ( x(i)  z(i) ) ( c(i) -s(i) )
!>    ( z(i)  y(i) )    ( -s(i)  c(i) ) ( z(i)  y(i) ) ( s(i)  c(i) )
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de rotaciones de plano a aplicar.
!>

X

!>          X es un array REAL,
!>                         dimension (1+(N-1)*INCX)
!>          El vector x.
!>

Y

!>          Y es un array REAL,
!>                         dimension (1+(N-1)*INCX)
!>          El vector y.
!>

Z

!>          Z es un array REAL,
!>                         dimension (1+(N-1)*INCX)
!>          El vector z.
!>

INCX

!>          INCX es INTEGER
!>          El incremento entre elementos de X, Y y Z. INCX > 0.
!>

C

!>          C es un array REAL, dimension (1+(N-1)*INCC)
!>          Los cosenos de las rotaciones de plano.
!>

S

!>          S es un array REAL, dimension (1+(N-1)*INCC)
!>          Los senos de las rotaciones de plano.
!>

INCC

!>          INCC es INTEGER
!>          El incremento entre elementos de C y S. INCC > 0.
!>
