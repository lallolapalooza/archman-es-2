subrutina slarzb (side, trans, direct, storev, m, n, k, l, v, ldv, t, ldt, c, ldc, work, ldwork)
SLARZB aplica un reflector de bloque o su transpuesta a una matriz general.

Documentación de la función/subrutina

subrutina slarzb (character side, character trans, character direct, character storev, integer m, integer n, integer k, integer l, real, dimension( ldv, * ) v, integer ldv, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldc, * ) c, integer ldc, real, dimension( ldwork, * ) work, integer ldwork)

SLARZB aplica un reflector de bloque real H o su transpuesta H**T a una matriz general real distribuida C de M por N, desde la izquierda o la derecha.

Propósito:

!>
!> SLARZB aplica un reflector de bloque real H o su transpuesta H**T a
!> una matriz general real distribuida C de M-por-N desde la izquierda o la derecha.
!>
!> Actualmente, solo se soportan STOREV = 'R' y DIRECT = 'B'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar H o H**T desde la izquierda
!>          = 'R': aplicar H o H**T desde la derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar H (sin transpuesta)
!>          = 'C': aplicar H**T (transpuesta)
!>

DIRECT

!>          DIRECT es CHARACTER*1
!>          Indica cómo se forma H a partir de un producto de reflectores
!>          elementales.
!>          = 'F': H = H(1) H(2) . . . H(k) (Adelante, todavía no soportado)
!>          = 'B': H = H(k) . . . H(2) H(1) (Atrás)
!>

STOREV

!>          STOREV es CHARACTER*1
!>          Indica cómo se almacenan los vectores que definen los reflectores
!>          elementales:
!>          = 'C': Por columnas (todavía no soportado)
!>          = 'R': Por filas
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

K

!>          K es INTEGER
!>          El orden de la matriz T (= el número de reflectores
!>          elementales cuyo producto define el reflector de bloque).
!>

L

!>          L es INTEGER
!>          El número de columnas de la matriz V que contienen la
!>          parte significativa de los reflectores de Householder.
!>          Si SIDE = 'L', M >= L >= 0; si SIDE = 'R', N >= L >= 0.
!>

V

!>          V es un array REAL, dimension (LDV,NV).
!>          Si STOREV = 'C', NV = K; si STOREV = 'R', NV = L.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si STOREV = 'C', LDV >= L; si STOREV = 'R', LDV >= K.
!>

T

!>          T es un array REAL, dimension (LDT,K)
!>          La matriz triangular K-por-K T en la representación del
!>          reflector de bloque.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= K.
!>

C

!>          C es un array REAL, dimension (LDC,N)
!>          En la entrada, la matriz C de M por N.
!>          En la salida, C se sobrescribe con H*C o H**T*C o C*H o C*H**T.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array REAL, dimension (LDWORK,K)
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N);
!>          si SIDE = 'R', LDWORK >= max(1,M).
!>
