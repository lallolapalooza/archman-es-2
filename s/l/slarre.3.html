Documentación de función/subrutina

subrutina slarre (character range, integer n, real vl, real vu, integer il, integer iu, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) e2, real rtol1, real rtol2, real spltol, integer nsplit, integer, dimension( * ) isplit, integer m, real, dimension( * ) w, real, dimension( * ) werr, real, dimension( * ) wgap, integer, dimension( * ) iblock, integer, dimension( * ) indexw, real, dimension( * ) gers, real pivmin, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLARRE dada la matriz tridiagonal T, establece elementos fuera de la diagonal pequeños a cero y para cada bloque no reducido Ti, encuentra representaciones base y valores propios.

Propósito:

!>
!> Para encontrar los valores propios deseados de una matriz tridiagonal
!> simétrica real dada T, SLARRE establece cualquier elemento fuera de la
!> diagonal a cero, y para cada bloque no reducido T_i, encuentra
!> (a) un desplazamiento adecuado en un extremo del espectro del bloque,
!> (b) la representación base, T_i - sigma_i I = L_i D_i L_i^T, y
!> (c) los valores propios de cada L_i D_i L_i^T.
!> Las representaciones y valores propios encontrados son luego utilizados por
!> SSTEMR para calcular los vectores propios de T.
!> La precisión varía dependiendo de si se utiliza la bisección para
!> encontrar unos pocos valores propios o el algoritmo dqds (subrutina SLASQ2) para
!> calcular todos y luego descartar los no deseados.
!> Como beneficio adicional, SLARRE también produce los N
!> intervalos de Gerschgorin para las matrices L_i D_i L_i^T.
!>

Parámetros

RANGE 
!>          RANGE es CHARACTER*1
!>          = 'A': ()   se encontrarán todos los valores propios.
!>          = 'V': () se encontrarán todos los valores propios en el intervalo semiabierto
!>                           (VL, VU]
!>          = 'I': () se encontrarán los valores propios del IL-ésimo al IU-ésimo (de la
!>                           matriz completa).
!>

N

!>          N es INTEGER
!>          El orden de la matriz. N > 0.
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior para los valores propios.
!>          Los valores propios menores o iguales a VL, o mayores que VU,
!>          no serán devueltos.  VL < VU.
!>          Si RANGE='I' o ='A', SLARRE calcula límites en la parte deseada
!>          del espectro.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior para los valores propios.
!>          Los valores propios menores o iguales a VL, o mayores que VU,
!>          no serán devueltos.  VL < VU.
!>          Si RANGE='I' o ='A', SLARRE calcula límites en la parte deseada
!>          del espectro.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N.
!>

D

!>          D es array REAL, dimension (N)
!>          En la entrada, los N elementos diagonales de la matriz
!>          tridiagonal T.
!>          En la salida, los N elementos diagonales de las matrices
!>          diagonales D_i.
!>

E

!>          E es array REAL, dimension (N)
!>          En la entrada, las primeras (N-1) entradas contienen los elementos
!>          subdiagonales de la matriz tridiagonal T; E(N) no necesita estar
!>          definido.
!>          En la salida, E contiene los elementos subdiagonales de las matrices
!>          bidiagonales unitarias L_i. Las entradas E( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, contienen los puntos base sigma_i en la salida.
!>

E2

!>          E2 es array REAL, dimension (N)
!>          En la entrada, las primeras (N-1) entradas contienen los CUADRADOS de los
!>          elementos subdiagonales de la matriz tridiagonal T;
!>          E2(N) no necesita estar definido.
!>          En la salida, las entradas E2( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, han sido establecidas a cero.
!>

RTOL1

!>          RTOL1 es REAL
!>

RTOL2

!>          RTOL2 es REAL
!>           Parámetros para la bisección.
!>           Un intervalo [IZQ,DER] ha convergido si
!>           DER-IZQ < MAX( RTOL1*GAP, RTOL2*MAX(|IZQ|,|DER|) )
!>

SPLTOL

!>          SPLTOL es REAL
!>          El umbral para la división.
!>

NSPLIT

!>          NSPLIT es INTEGER
!>          El número de bloques en los que se divide T. 1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT es array INTEGER, dimension (N)
!>          Los puntos de división, en los que T se divide en bloques.
!>          El primer bloque consiste en las filas/columnas 1 a ISPLIT(1),
!>          el segundo en las filas/columnas ISPLIT(1)+1 hasta ISPLIT(2),
!>          etc., y el NSPLIT-ésimo consiste en las filas/columnas
!>          ISPLIT(NSPLIT-1)+1 hasta ISPLIT(NSPLIT)=N.
!>

M

!>          M es INTEGER
!>          El número total de valores propios (de todos los L_i D_i L_i^T)
!>          encontrados.
!>

W

!>          W es array REAL, dimension (N)
!>          Las primeras M entradas contienen los valores propios. Los
!>          valores propios de cada uno de los bloques, L_i D_i L_i^T, están
!>          ordenados en orden ascendente (SLARRE puede usar las
!>          restantes N-M entradas como espacio de trabajo).
!>

WERR

!>          WERR es array REAL, dimension (N)
!>          El límite de error en el valor propio correspondiente en W.
!>

WGAP

!>          WGAP es array REAL, dimension (N)
!>          La separación del valor propio vecino derecho en W.
!>          La brecha solo existe con respecto a los valores propios del mismo
!>          bloque, ya que cada bloque tiene su propio árbol de representación.
!>          Excepción: en el extremo derecho de un bloque almacenamos la brecha izquierda.
!>

IBLOCK

!>          IBLOCK es array INTEGER, dimension (N)
!>          Los índices de los bloques (submatrices) asociados con los
!>          valores propios correspondientes en W; IBLOCK(i)=1 si el valor propio
!>          W(i) pertenece al primer bloque desde arriba, =2 si W(i)
!>          pertenece al segundo bloque, etc.
!>

INDEXW

!>          INDEXW es array INTEGER, dimension (N)
!>          Los índices de los valores propios dentro de cada bloque (submatriz);
!>          por ejemplo, INDEXW(i)= 10 e IBLOCK(i)=2 implican que el
!>          i-ésimo valor propio W(i) es el décimo valor propio en el bloque 2.
!>

GERS

!>          GERS es array REAL, dimension (2*N)
!>          Los N intervalos de Gerschgorin (el i-ésimo intervalo de
!>          Gerschgorin es (GERS(2*i-1), GERS(2*i))).
!>

PIVMIN

!>          PIVMIN es REAL
!>          El pivote mínimo en la secuencia de Sturm para T.
!>

WORK

!>          WORK es array REAL, dimension (6*N)
!>          Espacio de trabajo.
!>

IWORK

!>          IWORK es array INTEGER, dimension (N)
!>          Espacio de trabajo.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida correcta.
!>          < 0:  si INFO = -i, entonces el i-ésimo argumento tuvo un valor
!>                ilegal.
!>          > 0:  si INFO = k, entonces k = 1 representa un problema de
!>                bisección y k = 2 representa un problema de ordenación.
!>

NAME

slarre - SLARRE computes the desired part of the spectrum of a general band matrix.

SYNOPSIS

    SUBROUTINE SLARRE(
        N, VL, VU, IL, IU, ABSTOL, W, Z, LDZ, WORK, LWORK, IWORK, INFO
    )
    INTEGER N
    REAL VL, VU, ABSTOL
    INTEGER IL, IU
    REAL W( * )
    REAL Z( LDZ, * )
    INTEGER LDZ
    REAL WORK( * )
    INTEGER LWORK
    INTEGER IWORK( * )
    INTEGER INFO

Function/Subroutine Documentation

Purpose

    SLARRE computes the desired part of the spectrum of a general
    band matrix A, where the desired part is determined by the specified
    eigenvalues. The eigenvectors are computed by the routine SLARRE.
    This routine is used to approximate the eigenvalues and eigenvectors
    of a general band matrix by finding the eigenvalues and eigenvectors
    of a smaller, well-conditioned diagonal matrix.

Arguments

N
INTEGER
          The order of the matrix A.
VL
REAL
          The lower bound of the interval (VL, VU) for the desired
          eigenvalues. If IL = 1, VL is not used.
VU
REAL
          The upper bound of the interval (VL, VU) for the desired
          eigenvalues. If IU = N, VU is not used.
IL
INTEGER
          The index of the first desired eigenvalue, when sorted in
          increasing order. If IL = 1, the routine computes the eigenvalues
          from the lower end of the spectrum up to the eigenvalue index IU.
IU
INTEGER
          The index of the last desired eigenvalue, when sorted in
          increasing order. If IU = N, the routine computes the eigenvalues
          from the eigenvalue index IL up to the upper end of the spectrum.
ABSTOL
REAL
          The absolute tolerance for selecting the eigenvalues. Eigenvalues
          lambda satisfying |lambda - sigma| <= ABSTOL for some sigma in
          the chosen interval are selected.
W
REAL array, dimension (N)
          On exit, W contains the eigenvalues in ascending order. Only
          the eigenvalues in the desired range [IL, IU] are returned.
Z
REAL array, dimension (LDZ, K)
          Where K is the number of eigenvalues selected. On exit, Z contains
          the corresponding eigenvectors. The eigenvectors are normalized
          so that the 2-norm is 1.
LDZ
INTEGER
          The leading dimension of the array Z. LDZ >= max(1, N).
WORK
REAL array, dimension (LWORK)
          Local workspace array.
LWORK
INTEGER
          The dimension of the array WORK. LWORK >= max(1, 5*N).
IWORK
INTEGER array, dimension (5*N)
          Workspace.
INFO
INTEGER
          = 0:  successful exit
          > 0:  A problem occurred in SLARRE.
          < 0:  One of the called subroutines signaled an internal problem.
                Needs inspection of the corresponding parameter IINFO
                for further information.

          =-1:  Problem in SLARRD.
          = 2:  No base representation could be found in MAXTRY iterations.
                Increasing MAXTRY and recompilation might be a remedy.
          =-3:  Problem in SLARRB when computing the refined root
                representation for SLASQ2.
          =-4:  Problem in SLARRB when preforming bisection on the
                desired part of the spectrum.
          =-5:  Problem in SLASQ2.
          =-6:  Problem in SLASQ2.

Further Details:

    The base representations are required to suffer very little
    element growth and consequently define all their eigenvalues to
    high relative accuracy.
