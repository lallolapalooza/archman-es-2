SLATM5

Propósito:

!>
!> SLATM5 genera matrices involucradas en la ecuación de Sylvester
!> Generalizada:
!>
!>     A * R - L * B = C
!>     D * R - L * E = F
!>
!> También satisfacen (la condición de diagonalización)
!>
!>  [ I -L ] ( [ A  -C ], [ D -F ] ) [ I  R ] = ( [ A    ], [ D    ] )
!>  [    I ] ( [     B ]  [    E ] ) [    I ]   ( [    B ]  [    E ] )
!>
!>

Parámetros

PRTYPE 
!>          PRTYPE es ENTERO
!>           a un cierto tipo de matrices a generar
!>          (ver más detalles).
!>

M

!>          M es ENTERO
!>          Especifica el orden de A y D y el número de filas en
!>          C, F, R y L.
!>

N

!>          N es ENTERO
!>          Especifica el orden de B y E y el número de columnas en
!>          C, F, R y L.
!>

A

!>          A es un arreglo REAL, dimensión (LDA, M).
!>          Al salir A M-por-M está inicializado de acuerdo a PRTYPE.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de A.
!>

B

!>          B es un arreglo REAL, dimensión (LDB, N).
!>          Al salir B N-por-N está inicializado de acuerdo a PRTYPE.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal de B.
!>

C

!>          C es un arreglo REAL, dimensión (LDC, N).
!>          Al salir C M-por-N está inicializado de acuerdo a PRTYPE.
!>

LDC

!>          LDC es ENTERO
!>          La dimensión principal de C.
!>

D

!>          D es un arreglo REAL, dimensión (LDD, M).
!>          Al salir D M-por-M está inicializado de acuerdo a PRTYPE.
!>

LDD

!>          LDD es ENTERO
!>          La dimensión principal de D.
!>

E

!>          E es un arreglo REAL, dimensión (LDE, N).
!>          Al salir E N-por-N está inicializado de acuerdo a PRTYPE.
!>

LDE

!>          LDE es ENTERO
!>          La dimensión principal de E.
!>

F

!>          F es un arreglo REAL, dimensión (LDF, N).
!>          Al salir F M-por-N está inicializado de acuerdo a PRTYPE.
!>

LDF

!>          LDF es ENTERO
!>          La dimensión principal de F.
!>

R

!>          R es un arreglo REAL, dimensión (LDR, N).
!>          Al salir R M-por-N está inicializado de acuerdo a PRTYPE.
!>

LDR

!>          LDR es ENTERO
!>          La dimensión principal de R.
!>

L

!>          L es un arreglo REAL, dimensión (LDL, N).
!>          Al salir L M-por-N está inicializado de acuerdo a PRTYPE.
!>

LDL

!>          LDL es ENTERO
!>          La dimensión principal de L.
!>

ALPHA

!>          ALPHA es REAL
!>          Parámetro utilizado en la generación de matrices PRTYPE = 1 y 5.
!>

QBLCKA

!>          QBLCKA es ENTERO
!>          Cuando PRTYPE = 3, especifica la distancia entre bloques de
!>          2x2 en la diagonal de A. De lo contrario, QBLCKA no se
!>          referencia. QBLCKA > 1.
!>

QBLCKB

!>          QBLCKB es ENTERO
!>          Cuando PRTYPE = 3, especifica la distancia entre bloques de
!>          2x2 en la diagonal de B. De lo contrario, QBLCKB no se
!>          referencia. QBLCKB > 1.
!>

Detalles Adicionales:

!>
!>  PRTYPE = 1: A y B son bloques de Jordan, D y E son matrices identidad
!>
!>             A : si (i == j) entonces A(i, j) = 1.0
!>                 si (j == i + 1) entonces A(i, j) = -1.0
!>                 si no A(i, j) = 0.0,            i, j = 1...M
!>
!>             B : si (i == j) entonces B(i, j) = 1.0 - ALPHA
!>                 si (j == i + 1) entonces B(i, j) = 1.0
!>                 si no B(i, j) = 0.0,            i, j = 1...N
!>
!>             D : si (i == j) entonces D(i, j) = 1.0
!>                 si no D(i, j) = 0.0,            i, j = 1...M
!>
!>             E : si (i == j) entonces E(i, j) = 1.0
!>                 si no E(i, j) = 0.0,            i, j = 1...N
!>
!>             L =  R se eligen de [-10...10],
!>                  lo cual especifica los lados derechos (C, F).
!>
!>  PRTYPE = 2 o 3: Triangular y/o cuasi-triangular.
!>
!>             A : si (i <= j) entonces A(i, j) = [-1...1]
!>                 si no A(i, j) = 0.0,             i, j = 1...M
!>
!>                 si (PRTYPE = 3) entonces
!>                    A(k + 1, k + 1) = A(k, k)
!>                    A(k + 1, k) = [-1...1]
!>                    signo(A(k, k + 1) = -(sin(A(k + 1, k))
!>                        k = 1, M - 1, QBLCKA
!>
!>             B : si (i <= j) entonces B(i, j) = [-1...1]
!>                 si no B(i, j) = 0.0,            i, j = 1...N
!>
!>                 si (PRTYPE = 3) entonces
!>                    B(k + 1, k + 1) = B(k, k)
!>                    B(k + 1, k) = [-1...1]
!>                    signo(B(k, k + 1) = -(signo(B(k + 1, k))
!>                        k = 1, N - 1, QBLCKB
!>
!>             D : si (i <= j) entonces D(i, j) = [-1...1].
!>                 si no D(i, j) = 0.0,            i, j = 1...M
!>
!>
!>             E : si (i <= j) entonces D(i, j) = [-1...1]
!>                 si no E(i, j) = 0.0,            i, j = 1...N
!>
!>                 L, R se eligen de [-10...10],
!!>                 lo cual especifica los lados derechos (C, F).
!>
!>  PRTYPE = 4 Completa
!>             A(i, j) = [-10...10]
!>             D(i, j) = [-1...1]    i,j = 1...M
!>             B(i, j) = [-10...10]
!>             E(i, j) = [-1...1]    i,j = 1...N
!>             R(i, j) = [-10...10]
!>             L(i, j) = [-1...1]    i = 1..M ,j = 1...N
!>
!>             L, R especifican los lados derechos (C, F).
!>
!>  PRTYPE = 5 caso especial eigs comunes y/o cercanas.
!>
