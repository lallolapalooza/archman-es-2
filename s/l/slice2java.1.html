NOMBRE

slice2java - El compilador de Slice a Java.

SINOPSIS

slice2java [opciones] [archivos]

DESCRIPCIÓN

slice2java compila archivos Slice a Java. El macro __SLICE2JAVA__ se define durante esta compilación.

La documentación completa para slice2java está disponible en línea en:
https://doc.zeroc.com/ice/3.7/language-mappings/java-mapping/client-side-slice-to-java-mapping/slice2java-command-line-options

OPCIONES

-h, --help

Muestra un mensaje de ayuda.
-v, --version
Muestra la versión del compilador.
-DNAME

Define el símbolo preprocesador NAME.
-DNAME=DEF

Define el símbolo preprocesador NAME con el valor DEF.
-UNAME

Anula la definición del símbolo preprocesador NAME.
-IDIR

Agrega el directorio DIR a la ruta de búsqueda para directivas #include.
-E

Imprime la salida del preprocesador en stdout.
--output-dir DIR

Coloca los archivos generados en el directorio DIR.
-d, --debug

Imprime información de depuración que muestra el funcionamiento del analizador Slice.
--depend

Imprime información de dependencias en la salida estándar por defecto, o en el archivo especificado por la opción --depend-file. No se genera código cuando se especifica esta opción.
--depend-xml

Imprime información de dependencias en formato XML en la salida estándar por defecto, o en el archivo especificado por la opción --depend-file. No se genera código cuando se especifica esta opción.
--depend-file FILE

Dirige la información de dependencias al archivo especificado. El formato de salida depende de si --depend o --depend-xml también se especifican.
--validate

Verifica la corrección de las opciones de línea de comandos proporcionadas y no genera ningún código.
--compat

Genera código para el mapeo de Java Compat. Cuando se especifica esta opción, el macro __SLICE2JAVA_COMPAT__ se define durante la compilación. Si esta opción no se especifica, el comportamiento por defecto es generar código para el mapeo de Java.
--tie

Genera clases de "tie". (Solo Java Compat)
--impl

Genera archivos de implementación de ejemplo. Esta opción no sobrescribirá un archivo existente.
--impl-tie

Genera archivos de implementación de ejemplo utilizando clases de "tie". Esta opción no sobrescribirá un archivo existente. (Solo Java Compat)
--checksum CLASS

Genera sumas de verificación para definiciones Slice en la clase CLASS. El nombre de clase dado puede contener opcionalmente un especificador de paquete. La clase generada contiene sumas de verificación para todos los archivos Slice que se están traduciendo en esta invocación del compilador.
--meta META

Define la directiva de metadatos de archivo META. Usar esta opción es equivalente a definir los metadatos de archivo META en cada archivo Slice nombrado, así como en cualquier archivo incluido por un archivo Slice nombrado. Los metadatos de archivo especificados con --meta anulan cualquier directiva de metadatos de archivo correspondiente en los archivos que se compilan.
--list-generated

Emite una lista de archivos generados en formato XML.
