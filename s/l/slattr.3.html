Documentación de la función/subrutina

subroutine slattr (integer imat, character uplo, character trans, character diag, integer, dimension( 4 ) iseed, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) b, real, dimension( * ) work, integer info)

SLATTR

Propósito:

!>
!> SLATTR genera una matriz de prueba triangular.
!> IMAT y UPLO especifican de forma única las propiedades de la matriz de
!> prueba, que se devuelve en el array A.
!>

Parámetros

IMAT 
!>          IMAT es INTEGER
!>          Una clave entera que describe qué matriz generar para esta
!>          ruta.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A será triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica si se utilizará la matriz o su transpuesta.
!>          = 'N':  Sin transponer
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada (= Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es triangular unitaria o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          El vector semilla para el generador de números aleatorios (usado en
!>          SLATMS). Modificado a la salida.
!>

N

!>          N es INTEGER
!>          El orden de la matriz a generar.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          La matriz triangular A. Si UPLO = 'U', la parte triangular superior
!>          de n por n en la cabecera del array A contiene la matriz triangular
!>          superior, y la parte triangular estrictamente inferior de A no se
!>          referencia. Si UPLO = 'L', la parte triangular inferior de n por n
!>          en la cabecera del array A contiene la matriz triangular inferior,
!>          y la parte triangular estrictamente superior de A no se referencia.
!>          Si DIAG = 'U', los elementos diagonales de A se establecen de forma
!>          que A(k,k) = k para 1 <= k <= n.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array REAL, dimensión (N)
!>          El vector del lado derecho, si IMAT > 10.
!>

WORK

!>          WORK es un array REAL, dimensión (3*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0: si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
