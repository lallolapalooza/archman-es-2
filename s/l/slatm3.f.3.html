Documentación de la Función/Subrutina

función real slatm3 (entero m, entero n, entero i, entero j, entero isub, entero jsub, entero kl, entero ku, entero idist, entero, dimensión( 4 ) iseed, real, dimensión( * ) d, entero igrade, real, dimensión( * ) dl, real, dimensión( * ) dr, entero ipvtng, entero, dimensión( * ) iwork, real sparse)

SLATM3

Propósito

!>
!>    SLATM3 devuelve la entrada (ISUB,JSUB) de una matriz aleatoria de
!>    dimensión (M, N) descrita por los otros parámetros. (ISUB,JSUB)
!>    es la posición final de la entrada (I,J) después de pivotar
!>    según IPVTNG y IWORK. SLATM3 es llamada por la
!>    rutina SLATMR para construir matrices de prueba aleatorias. No se
!>    realiza ninguna comprobación de errores en los parámetros, ya que esta
!>    rutina es llamada en un bucle ajustado por SLATMR, que ya ha comprobado
!>    los parámetros.
!>
!>    El uso de SLATM3 difiere de SLATM2 en el orden en que se llama al
!>    generador de números aleatorios para rellenar las entradas de la matriz
!>    aleatoria.
!>    Con SLATM2, el generador se llama para rellenar la matriz pivotada
!>    columna por columna. Con SLATM3, el generador se llama para rellenar la
!>    matriz columna por columna, después de lo cual se pivota. Por lo tanto,
!>    SLATM3 se puede utilizar para construir matrices aleatorias que difieren
!>    únicamente en el orden de sus filas y/o columnas. SLATM2 se utiliza para
!>    construir matrices de banda, evitando llamar al generador de números
!>    aleatorios para entradas fuera de la banda (y, por lo tanto, generando
!>    números aleatorios en órdenes diferentes para diferentes órdenes de pivote).
!>
!>    La matriz cuya entrada (ISUB,JSUB) se devuelve se construye de la
!>    siguiente manera (esta rutina solo calcula una entrada):
!>
!>      Si ISUB está fuera de (1..M) o JSUB está fuera de (1..N), devolver cero
!>         (esto es conveniente para generar matrices en formato de banda).
!>
!>      Generar una matriz A con entradas aleatorias de distribución IDIST.
!>
!>      Establecer la diagonal a D.
!>
!>      Calificar la matriz, si se desea, desde la izquierda (por DL) y/o
!>         desde la derecha (por DR o DL) según lo especificado por IGRADE.
!>
!>      Permutar, si se desea, las filas y/o columnas según lo especificado
!>         por IPVTNG y IWORK.
!>
!>      Bandear la matriz para que tenga un ancho de banda inferior KL y un
!>         ancho de banda superior KU.
!>
!>      Establecer entradas aleatorias a cero según lo especificado por SPARSE.
!>

Parámetros

M 
!>          M es ENTERO
!>           Número de filas de la matriz. No modificado.
!>

N

!>          N es ENTERO
!>           Número de columnas de la matriz. No modificado.
!>

I

!>          I es ENTERO
!>           Fila de la entrada sin pivotar que se va a devolver. No modificado.
!>

J

!>          J es ENTERO
!>           Columna de la entrada sin pivotar que se va a devolver. No modificado.
!>

ISUB

!>          ISUB es ENTERO
!>           Fila de la entrada pivotada que se va a devolver. Cambiado en la salida.
!>

JSUB

!>          JSUB es ENTERO
!>           Columna de la entrada pivotada que se va a devolver. Cambiado en la salida.
!>

KL

!>          KL es ENTERO
!>           Ancho de banda inferior. No modificado.
!>

KU

!>          KU es ENTERO
!>           Ancho de banda superior. No modificado.
!>

IDIST

!>          IDIST es ENTERO
!>           En la entrada, IDIST especifica el tipo de distribución a utilizar
!>           para generar una matriz aleatoria.
!>           1 => UNIFORME( 0, 1 )
!>           2 => UNIFORME( -1, 1 )
!>           3 => NORMAL( 0, 1 )
!>           No modificado.
!>

ISEED

!>          ISEED es array de ENTEROS de dimensión ( 4 )
!>           Semilla para el generador de números aleatorios.
!>           Cambiado en la salida.
!>

D

!>          D es array de REALES de dimensión ( MIN( I , J ) )
!>           Entradas diagonales de la matriz. No modificado.
!>

IGRADE

!>          IGRADE es ENTERO
!>           Especifica la calificación de la matriz de la siguiente manera:
!>           0  => sin calificación
!>           1  => matriz premultiplicada por diag( DL )
!>           2  => matriz postmultiplicada por diag( DR )
!>           3  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>           4  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>           5  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>           No modificado.
!>

DL

!>          DL es array de REALES ( I o J, según corresponda )
!>           Factores de escala izquierdos para calificar la matriz. No modificado.
!>

DR

!>          DR es array de REALES ( I o J, según corresponda )
!>           Factores de escala derechos para calificar la matriz. No modificado.
!>

IPVTNG

!>          IPVTNG es ENTERO
!>           En la entrada especifica las permutaciones de pivote de la siguiente manera:
!>           0 => ninguna.
!>           1 => pivoteo de filas.
!>           2 => pivoteo de columnas.
!>           3 => pivoteo completo, es decir, en ambos lados.
!>           No modificado.
!>

IWORK

!>          IWORK es array de ENTEROS ( I o J, según corresponda )
!>           Este array especifica la permutación utilizada. La
!>           fila (o columna) originalmente en la posición K está en
!>           la posición IWORK( K ) después del pivoteo.
!>           Esto difiere de IWORK para SLATM2. No modificado.
!>

SPARSE

!>          SPARSE es REAL entre 0. y 1.
!>           En la entrada especifica la dispersión de la matriz
!>           si se va a generar una matriz dispersa.
!>           SPARSE debe estar entre 0 y 1.
!>           Se genera un número aleatorio uniforme ( 0, 1 ) x y
!>           se compara con SPARSE; si x es mayor, la entrada de la matriz
!>           no se modifica y si x es menor, la entrada se establece
!>           a cero. Por lo tanto, en promedio, una fracción SPARSE de las
!>           entradas se establecerá a cero.
!>           No modificado.
!>
