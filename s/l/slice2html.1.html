NOMBRE

slice2html - La herramienta de documentación Slice a HTML.

SINOPSIS

slice2html [opciones] [archivos]

DESCRIPCIÓN

slice2html genera documentación HTML a partir de archivos Slice. La macro __SLICE2HTML__ se define durante esta compilación.

La documentación completa para slice2html está disponible en línea en:
https://doc.zeroc.com/ice/3.7/the-slice-language/generating-slice-documentation

slice2html está obsoleto; Doxygen es ahora la forma preferida de generar referencias de API de Slice, véase:
https://doc.zeroc.com/api/ice/3.7/slice/

OPCIONES

-h, --help

Muestra el mensaje de ayuda.
-v, --version
Muestra la versión del compilador.
-DNAME

Define el símbolo preprocesador NOMBRE.
-DNAME=DEF

Define el símbolo preprocesador NOMBRE con el valor DEF.
-UNAME

Anula la definición del símbolo preprocesador NOMBRE.
-IDIR

Añade el directorio DIR a la ruta de búsqueda para las directivas #include.
-E

Imprime la salida del preprocesador en stdout.
--output-dir DIR

Coloca los archivos generados en el directorio DIR.
-d, --debug

Imprime información de depuración que muestra el funcionamiento del analizador Slice.
--hdr ARCHIVO

Antepone ARCHIVO a cada archivo HTML generado (excepto _sindex.html). Esto le permite reemplazar la cabecera HTML y otra información preliminar con una versión personalizada, de modo que pueda conectar hojas de estilo a las páginas generadas. El archivo especificado debe incluir la etiqueta <body> (pero no es necesario que termine con una etiqueta <body>). Se espera que ARCHIVO contenga la cadena TITLE en una línea por sí sola, comenzando en la columna uno. slice2html reemplaza la cadena TITLE con el nombre completamente calificado del símbolo Slice que se documenta en la página correspondiente.
--ftr ARCHIVO

Añade ARCHIVO al final de cada archivo HTML generado (excepto _sindex.html). Esto le permite añadir, por ejemplo, un pie de página personalizado a cada página generada. ARCHIVO debe terminar con una etiqueta </body>.
--indexhdr ARCHIVO

slice2html genera un archivo _sindex.html que contiene una tabla de contenidos de todos los símbolos Slice que enlazan a la página correspondiente. Esta opción le permite reemplazar la cabecera estándar con una cabecera personalizada, por ejemplo, para adjuntar un JavaScript. El archivo especificado debe incluir la etiqueta <body> (pero no es necesario que termine con una etiqueta <body>). El valor por defecto es la configuración de --hdr (si la hay).
--indexftr ARCHIVO

Añade ARCHIVO al final de la página sindex.html generada. Esto le permite añadir, por ejemplo, un pie de página personalizado a la tabla de contenidos, o invocar un JavaScript. ARCHIVO debe terminar con una etiqueta </body>. El valor por defecto es la configuración de --ftr (si la hay).
--image-dir DIR

Con esta opción, slice2html busca en el directorio especificado imágenes para utilizar en los hipervínculos de navegación generados. (Sin esta opción, se utilizan enlaces de texto en su lugar). Por favor, consulte el HTML generado para ver los nombres de los diversos archivos de imagen. (Son fáciles de encontrar buscando elementos img.)
--logo-url URL

Utiliza la URL especificada como hipervínculo para el logotipo de la empresa que se añade a cada página (si se especifica --image-dir). Se espera que el logotipo de la empresa esté en <directorio_imagenes>/logo.gif.
--search ACCIÓN

Si se especifica esta opción, las páginas generadas contienen un cuadro de búsqueda que le permite conectar las páginas generadas con un motor de búsqueda. Al pulsar el botón "Search" (Buscar), se realiza la ACCIÓN especificada.
--index NUM

slice2html genera subíndices para varios símbolos Slice. Esta opción controla cuántas entradas deben estar presentes antes de generar un subíndice. Por ejemplo, si NUM se establece en 3, se generará un subíndice solo si hay tres o más símbolos que aparezcan en ese índice. La configuración por defecto es 1, lo que significa que siempre se genera un subíndice. Para deshabilitar los subíndices por completo, establezca NUM a 0.
--summary NUM

Si esta opción está configurada, las oraciones de resumen que excedan NUM caracteres generarán una advertencia.
