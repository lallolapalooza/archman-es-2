Documentación de Función/Subrutina

función lógica slaisnan (real, intent(in) sin1, real, intent(in) sin2)

SLAISNAN comprueba si la entrada es NaN comparando dos argumentos de desigualdad.

Propósito:

!>
!> Esta rutina no es para uso general. Existe únicamente para evitar
!> la sobreoptimización en SISNAN.
!>
!> SLAISNAN comprueba si hay NaNs comparando sus dos argumentos de
!> desigualdad. NaN es el único valor de punto flotante donde NaN != NaN
!> devuelve .TRUE. Para comprobar si hay NaNs, pasa la misma variable como ambos
!> argumentos.
!>
!> Un compilador debe asumir que los dos argumentos no son
!> la misma variable, y la prueba no será optimizada.
!> La optimización interprocedural o de programa completo puede eliminar esta
!> prueba. Las funciones ISNAN se reemplazarán por la intrínseca Fortran 03
!> correcta una vez que la intrínseca esté ampliamente disponible.
!>

Parámetros

SIN1 
!>          SIN1 es REAL
!>

SIN2

!>          SIN2 es REAL
!>          Dos números para comparar por desigualdad.
!>
