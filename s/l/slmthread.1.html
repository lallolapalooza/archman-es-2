SLMTHREAD(1) Documentación de Perl aportada por el usuario SLMTHREAD(1)

NOMBRE

slmthread - procesa el modelo de lenguaje por hilos

SINOPSIS

slmthread slm_primitivo slm_con_hilos

DESCRIPCIÓN

slmthread añade un estado de retroceso para cada nodo slm en el slm_primitivo. También comprime la representación de flotante de 32 bits a 16 bits. Estos procesamientos aceleran la búsqueda.

El slm_primitivo siempre se genera con slmprune. Y el slm_con_hilos se puede utilizar para alimentar slmseg como referencia para segmentar texto chino.

VER TAMBIÉN
