SLASD7 fusiona los dos conjuntos de valores singulares en un único conjunto ordenado. Luego, intenta reducir el tamaño del problema. Utilizado por SLASD6.

Propósito:

!>
!> SLASD7 fusiona los dos conjuntos de valores singulares en un único
!> conjunto ordenado. Luego, intenta reducir el tamaño del problema. Hay
!> dos formas en que puede ocurrir la reducción: cuando dos o más valores
!> singulares están muy juntos o si hay una entrada diminuta en el vector
!> Z. Por cada ocurrencia de este tipo, el orden del problema de la ecuación
!> secular relacionada se reduce en uno.
!>
!> SLASD7 es llamado desde SLASD6.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>          Especifica si los vectores singulares deben calcularse
!>          en forma compacta, de la siguiente manera:
!>          = 0: Calcular solo los valores singulares.
!>          = 1: Calcular los vectores singulares de la matriz
!>               bidiagonal superior en forma compacta.
!>

NL

!>          NL es INTEGER
!>         La dimensión de fila del bloque superior. NL >= 1.
!>

NR

!>          NR es INTEGER
!>         La dimensión de fila del bloque inferior. NR >= 1.
!>

SQRE

!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada de NR por NR.
!>         = 1: el bloque inferior es una matriz rectangular de NR por (NR+1).
!>
!>         La matriz bidiagonal tiene
!>         N = NL + NR + 1 filas y
!>         M = N + SQRE >= N columnas.
!>

K

!>          K es INTEGER
!>         Contiene la dimensión de la matriz no reducida, este es
!>         el orden de la ecuación secular relacionada. 1 <= K <=N.
!>

D

!>          D es array REAL, dimension ( N )
!>         En la entrada D contiene los valores singulares de las dos submatrices
!>         a combinar. En la salida D contiene los valores singulares actualizados
!>         del final (N-K) (aquellos que fueron reducidos) ordenados en
!>         orden creciente.
!>

Z

!>          Z es array REAL, dimension ( M )
!>         En la salida Z contiene el vector fila de actualización en la ecuación
!>         secular.
!>

ZW

!>          ZW es array REAL, dimension ( M )
!>         Espacio de trabajo para Z.
!>

VF

!>          VF es array REAL, dimension ( M )
!>         En la entrada, VF(1:NL+1) contiene los primeros componentes de todos
!>         los vectores singulares derechos de la matriz superior; y VF(NL+2:M)
!>         contiene los primeros componentes de todos los vectores singulares
!>         derechos de la matriz inferior. En la salida, VF contiene los primeros
!>         componentes de todos los vectores singulares derechos de la matriz
!>         bidiagonal.
!>

VFW

!>          VFW es array REAL, dimension ( M )
!>         Espacio de trabajo para VF.
!>

VL

!>          VL es array REAL, dimension ( M )
!>         En la entrada, VL(1:NL+1) contiene los componentes finales de todos
!>         los vectores singulares derechos de la matriz superior; y VL(NL+2:M)
!>         contiene los componentes finales de todos los vectores singulares
!>         derechos de la matriz inferior. En la salida, VL contiene los componentes
!>         finales de todos los vectores singulares derechos de la matriz
!>         bidiagonal.
!>

VLW

!>          VLW es array REAL, dimension ( M )
!>         Espacio de trabajo para VL.
!>

ALPHA

!>          ALPHA es REAL
!>         Contiene el elemento diagonal asociado con la fila añadida.
!>

BETA

!>          BETA es REAL
!>         Contiene el elemento fuera de la diagonal asociado con la fila
!>         añadida.
!>

DSIGMA

!>          DSIGMA es array REAL, dimension ( N )
!>         Contiene una copia de los elementos diagonales (K-1 valores singulares
!>         y un cero) en la ecuación secular.
!>

IDX

!>          IDX es array INTEGER, dimension ( N )
!>         Contendrá la permutación utilizada para ordenar el contenido de
!>         D en orden ascendente.
!>

IDXP

!>          IDXP es array INTEGER, dimension ( N )
!>         Contendrá la permutación utilizada para colocar los valores
!>         reducidos de D al final del array. En la salida IDXP(2:K)
!>         apunta a los valores D no reducidos y IDXP(K+1:N)
!>         apunta a los valores singulares reducidos.
!>

IDXQ

!>          IDXQ es array INTEGER, dimension ( N )
!>         Contiene la permutación que ordena por separado los dos
!>         subproblemas en D en orden ascendente. Note que las entradas en
!>         la primera mitad de esta permutación deben moverse primero una
!>         posición hacia atrás; y las entradas en la segunda mitad
!>         deben tener primero NL+1 añadido a sus valores.
!>

PERM

!>          PERM es array INTEGER, dimension ( N )
!>         Las permutaciones (de reducción y ordenación) que se aplicarán
!>         a cada bloque singular. No referenciado si ICOMPQ = 0.
!>

GIVPTR

!>          GIVPTR es INTEGER
!>         El número de rotaciones de Givens que tuvieron lugar en este
!>         subproblema. No referenciado si ICOMPQ = 0.
!>

GIVCOL

!>          GIVCOL es array INTEGER, dimension ( LDGCOL, 2 )
!>         Cada par de números indica un par de columnas para realizar
!>         una rotación de Givens. No referenciado si ICOMPQ = 0.
!>

LDGCOL

!>          LDGCOL es INTEGER
!>         La dimensión principal de GIVCOL, debe ser al menos N.
!>

GIVNUM

!>          GIVNUM es array REAL, dimension ( LDGNUM, 2 )
!>         Cada número indica el valor C o S a usar en la
!>         rotación de Givens correspondiente. No referenciado si ICOMPQ = 0.
!>

LDGNUM

!>          LDGNUM es INTEGER
!>         La dimensión principal de GIVNUM, debe ser al menos N.
!>

C

!>          C es REAL
!>         C contiene basura si SQRE = 0 y el valor C de una rotación
!>         de Givens relacionada con el espacio nulo derecho si SQRE = 1.
!>

S

!>          S es REAL
!>         S contiene basura si SQRE = 0 y el valor S de una rotación
!>         de Givens relacionada con el espacio nulo derecho si SQRE

slasd7.f(3) — LAPACK

NAME

slasd7.f

SYNOPSIS

This subroutine is part of the LAPACK routines for computing the singular value decomposition (SVD) of a bidiagonal matrix.

The calling sequence is:

CALL SLASD7(
     ICON,       N,            NL,           NR,
     SQRE,       NRWORK,       ALPHA,        BETA,
     D,            Z,            IZ,           WORK,
     INFO )

where:

ICON is INTEGER
     (input) ICON indicates whether the I-th row follows the (I-1) row.
     = 1: the I-th row follows the (I-1) row.
     = 2: the I-th row does not follow the (I-1) row.
     N is INTEGER
     (input) The dimension of the bidiagonal matrix.
     NL is INTEGER
     (input) The number of elements in the left part of the matrix.
     NR is INTEGER
     (input) The number of elements in the right part of the matrix.
     SQRE is INTEGER
     (input) It is 1 if SQRE = 100*N + I, and 0 otherwise.
     NRWORK is INTEGER
     (input) The number of elements in WORK.
     ALPHA is REAL
     (input)
     BETA is REAL
     (input)
     D is REAL array, dimension at least (N)
     (output) The diagonal entries of the bidiagonal matrix.
     Z is REAL array, dimension at least (N)
     (output) The subdiagonal entries of the bidiagonal matrix.
     IZ is INTEGER
     (input) The starting position of the array Z.
     WORK is REAL array, dimension at least (NRWORK)
     (workspace)
     INFO is INTEGER
     (output) >= 0: successful exit,
              < 0: if INFO = -i, then the i-th argument had an illegal value.
