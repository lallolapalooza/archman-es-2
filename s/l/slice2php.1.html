slice2php(1) Manual de comandos generales slice2php(1)

NOMBRE

slice2php - El compilador de Slice a PHP.

SINOPSIS

slice2php [opciones] [archivos]

DESCRIPCIÓN

slice2php compila archivos Slice a PHP. La macro __SLICE2PHP__ se define durante esta compilación.

La documentación completa para slice2php está disponible en línea en:
https://doc.zeroc.com/ice/3.7/language-mappings/php-mapping/client-side-slice-to-php-mapping/slice2php-command-line-options

OPCIONES

-h, --help

Muestra un mensaje de ayuda.
-v, --version
Muestra la versión del compilador.
-DNAME

Define el símbolo preprocesador NAME.
-DNAME=DEF

Define el símbolo preprocesador NAME con el valor DEF.
-UNAME

Anula la definición del símbolo preprocesador NAME.
-IDIR

Añade el directorio DIR a la ruta de búsqueda para las directivas #include.
-E

Imprime la salida del preprocesador en stdout.
--output-dir DIR

Coloca los archivos generados en el directorio DIR.
-d, --debug

Imprime información de depuración que muestra el funcionamiento del analizador Slice.
--depend

Imprime información de dependencia en la salida estándar por defecto, o en el archivo especificado por la opción --depend-file. No se genera código cuando se especifica esta opción.
--depend-xml

Imprime información de dependencia en formato XML en la salida estándar por defecto, o en el archivo especificado por la opción --depend-file. No se genera código cuando se especifica esta opción.
--depend-file FILE

Dirige la información de dependencia al archivo especificado. El formato de salida depende de si también se especificó --depend o --depend-xml.
--validate

Comprueba la corrección de las opciones de línea de comandos proporcionadas y no genera ningún código.
--all

Genera código para todas las definiciones de Slice, incluidas las de los archivos incluidos.
--no-namespace

Genera código sin soporte para namespaces de PHP (obsoleto).
--checksum CLASS

Genera sumas de verificación para definiciones de Slice.
--php5 CLASS

Genera código compatible con PHP5.
