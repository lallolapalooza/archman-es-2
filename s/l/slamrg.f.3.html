Documentación de función/subrutina

subrutina slamrg (integer n1, integer n2, real, dimension( * ) a, integer strd1, integer strd2, integer, dimension( * ) index)

SLAMRG crea una lista de permutación para fusionar las entradas de dos conjuntos ordenados independientemente en un único conjunto ordenado en orden ascendente.

Propósito:

!>
!> SLAMRG creará una lista de permutación que fusionará los elementos
!> de A (que se compone de dos conjuntos ordenados independientemente) en un
!> único conjunto que está ordenado en orden ascendente.
!>

Parámetros

N1 
!>          N1 es INTEGER
!>

N2

!>          N2 es INTEGER
!>         Estos argumentos contienen las longitudes respectivas de las dos
!>         listas ordenadas a fusionar.
!>

A

!>          A es un array REAL, dimension (N1+N2)
!>         Los primeros N1 elementos de A contienen una lista de números
!>         que están ordenados en orden ascendente o descendente.  Igualmente
!>         para los últimos N2 elementos.
!>

STRD1

!>          STRD1 es INTEGER
!>

STRD2

!>          STRD2 es INTEGER
!>         Estos son los pasos a seguir a través del array A.
!>         Los pasos permitidos son 1 y -1.  Indican si un subconjunto de A
!>         está ordenado en orden ascendente (STRDx = 1) o descendente
!>         (STRDx = -1).
!>

INDEX

!>          INDEX es un array INTEGER, dimension (N1+N2)
!>         Al salir, este array contendrá una permutación tal que
!>         si B( I ) = A( INDEX( I ) ) para I=1,N1+N2, entonces B estará
!>         ordenado en orden ascendente.
!>
