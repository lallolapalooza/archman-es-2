NOMBRE

slapo-dyngroup - Overlay de Grupos Dinámicos para slapd

SINOPSIS

/etc/openldap/slapd.conf

DESCRIPCIÓN

El overlay de Grupos Dinámicos permite a los clientes utilizar operaciones LDAP Compare para probar la pertenencia a un grupo dinámico de la misma manera que lo harían para un grupo estático. Las operaciones Compare dirigidas al atributo de miembro estático de un grupo serán interceptadas y probadas contra el atributo URL del grupo dinámico configurado.

Tenga en cuenta que esta interceptación solo ocurre si la operación Compare real no devuelve un resultado LDAP_COMPARE_TRUE. Por lo tanto, si un grupo tiene miembros tanto estáticos como dinámicos, se verificará primero la lista de miembros estáticos.

CONFIGURACIÓN

Esta opción de slapd.conf se aplica al overlay de Grupos Dinámicos. Debería aparecer después de la directiva overlay.

attrpair <memberAttr> <URLattr>
Especifica los atributos a comparar. Una operación de comparación sobre el memberAttr hará que el URLattr sea evaluado para el resultado.

EJEMPLOS

  database mdb
  ...
  overlay dyngroup
  attrpair member memberURL

ARCHIVOS

/etc/openldap/slapd.conf
archivo de configuración predeterminado de slapd

COMPATIBILIDAD RETROACTIVA

El overlay dyngroup ha sido rediseñado con la versión 2.5 para utilizar un espacio de nombres coherente como con otros overlays. Como efecto secundario, los siguientes parámetros de cn=config están obsoletos y se eliminarán en una futura versión: olcDGAttrPair se reemplaza con olcDynGroupAttrPair olcDGConfig se reemplaza con olcDynGroupConfig

VER TAMBIÉN

slapd.conf(5), slapd-config(5).
