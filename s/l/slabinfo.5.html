slabinfo(5) Manual de formatos de archivo slabinfo(5)

NOMBRE

slabinfo - estadísticas del asignador slab del kernel

SINOPSIS

cat /proc/slabinfo

DESCRIPCIÓN

Los objetos de uso frecuente en el kernel de Linux (cabeceras de búfer, inodos, dentries, etc.) tienen su propia caché. El archivo /proc/slabinfo proporciona estadísticas sobre estas cachés. La siguiente salida (editada) muestra un ejemplo del contenido de este archivo:

$ sudo cat /proc/slabinfo;
slabinfo - version: 2.1
# name    <active_objs> <num_objs> <objsize> <objperslab> <pagesperslab> ...
sigqueue      100  100  160   25  1 : tunables  0  0  0 : slabdata   4   4  0
sighand_cache 355   405 2112  15  8 : tunables  0  0  0 : slabdata  27  27  0
kmalloc-8192   96   96  8192   4  8 : tunables  0  0  0 : slabdata  24  24  0
...

La primera línea de la salida incluye un número de versión, que permite a una aplicación que lee el archivo manejar cambios en el formato del archivo. (Ver VERSIONES, abajo). La siguiente línea enumera los nombres de las columnas en las líneas restantes.

Cada una de las líneas restantes muestra información sobre una caché especificada. Después del nombre de la caché, la salida que se muestra en cada línea presenta tres componentes para cada caché:

•
estadísticas
•
ajustables
•
slabdata

Las estadísticas son las siguientes:

active_objs
El número de objetos que están actualmente activos (es decir, en uso).
num_objs
El número total de objetos asignados (es decir, objetos que están en uso y no en uso).
objsize
El tamaño de los objetos en esta slab, en bytes.
objperslab
El número de objetos almacenados en cada slab.
pagesperslab
El número de páginas asignadas para cada slab.

Las entradas tunables (ajustables) en cada línea muestran parámetros ajustables para la caché correspondiente. Al usar el asignador SLUB predeterminado, no hay parámetros ajustables, el archivo /proc/slabinfo no es escribible y el valor 0 se muestra en estos campos. Al usar el asignador SLAB más antiguo, los parámetros ajustables para una caché determinada se pueden establecer escribiendo líneas de la siguiente forma en /proc/slabinfo:


# echo 'name limit batchcount sharedfactor' > /proc/slabinfo;

Aquí, name es el nombre de la caché, y limit, batchcount y sharedfactor son enteros que definen nuevos valores para los parámetros ajustables correspondientes. El valor limit debe ser un valor positivo, batchcount debe ser un valor positivo menor o igual a limit, y sharedfactor debe ser no negativo. Si alguno de los valores especificados no es válido, la configuración de la caché se deja sin cambios.

Las entradas tunables en cada línea contienen los siguientes campos:

limit
El número máximo de objetos que se almacenarán en caché.
batchcount
En sistemas SMP, esto especifica el número de objetos a transferir a la vez al rellenar la lista de objetos disponibles.
sharedfactor
[Pendiente de documentar]

Las entradas slabdata en cada línea contienen los siguientes campos:

active_slabs
El número de slabs activas.
nums_slabs
El número total de slabs.
sharedavail
[Pendiente de documentar]

Tenga en cuenta que debido a la alineación de objetos y la sobrecarga de la caché de slabs, los objetos normalmente no se empaquetan de forma ajustada en páginas. Las páginas con incluso un objeto en uso se consideran en uso y no se pueden liberar.

Los kernels configurados con CONFIG_DEBUG_SLAB también tendrán campos de estadísticas adicionales en cada línea, y la primera línea del archivo contendrá la cadena "(statistics)". El campo de estadísticas incluye: la marca de agua alta de objetos activos; el número de veces que se han asignado objetos; el número de veces que la caché ha crecido (se han añadido nuevas páginas a esta caché); el número de veces que la caché se ha reducido (se han eliminado páginas no utilizadas de esta caché); y el número de veces que ha habido un error al asignar nuevas páginas a esta caché.

VERSIÓNES

El archivo /proc/slabinfo apareció por primera vez en Linux 2.1.23. El archivo está versionado y, con el tiempo, ha habido varias versiones con diferentes diseños:

1.0
Presente durante toda la serie de kernels Linux 2.2.x.
1.1
Presente en la serie de kernels Linux 2.4.x.
1.2
Un formato que estuvo brevemente presente en la serie de desarrollo de Linux 2.5.
2.0
Presente en los kernels Linux 2.6.x hasta e incluyendo Linux 2.6.9.
2.1
El formato actual, que apareció por primera vez en Linux 2.6.10.

NOTAS

Solo root puede leer y (si el kernel fue configurado con CONFIG_SLAB) escribir en el archivo /proc/slabinfo.

La cantidad total de memoria asignada a la caché SLAB/SLUB se muestra en el campo Slab de /proc/meminfo.
