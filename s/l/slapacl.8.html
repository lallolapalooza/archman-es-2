NOMBRE

slapacl - Comprueba el acceso a una lista de atributos.

SINOPSIS

/usr/bin/slapacl -b DN [-d nivel-depuracion] [-D DN-autenticacion | -U ID-autenticacion] [-f slapd.conf] [-F directorio-config] [-o opcion[=valor]] [-u] [-v] [-X ID-autorizacion | -o  DN-autorizacion=DN] [atributo[/acceso][:valor]] [...]

DESCRIPCIÓN

slapacl se utiliza para comprobar el comportamiento de slapd(8) verificando el acceso a los datos del directorio de acuerdo con las directivas de la lista de control de acceso definidas en su configuración. Abre el archivo de configuración slapd.conf(5) o el backend de slapd-config(5), lee las directivas access/olcAccess, y luego analiza la lista de atributo dada en la línea de comandos; si no se proporciona ninguna, se prueba el acceso al pseudo-atributo entry.

OPCIONES

-b DN
especifica el DN al que se solicita acceso; la entrada correspondiente se recupera de la base de datos, por lo tanto, debe existir. El DN también se utiliza para determinar qué reglas se aplican; por lo tanto, debe estar en el contexto de nomenclatura de una base de datos configurada. Por defecto, se utiliza la primera base de datos que admite la operación solicitada. Consulte también -u.
-d nivel-depuracion
habilita mensajes de depuración según lo definido por el nivel-depuracion especificado; consulte slapd(8) para obtener detalles.
-D DN-autenticacion
especifica un DN que se utilizará como identidad durante la sesión de prueba al seleccionar las cláusulas <by> apropiadas en las listas de acceso.
-f slapd.conf
especifica un archivo slapd.conf(5) alternativo.
-F directorio-config
especifica un directorio de configuración. Si se especifican tanto -f como -F, se leerá el archivo de configuración y se convertirá al formato de directorio de configuración y se escribirá en el directorio especificado. Si no se especifica ninguna de las opciones, se intentará leer el directorio de configuración predeterminado antes de intentar usar el archivo de configuración predeterminado. Si existe un directorio de configuración válido, se ignorará el archivo de configuración predeterminado.
-o opcion[=valor]
especifica una opción con un (opcional) valor. Las opciones/valores genéricos posibles son:
              syslog=<subsistemas>  (ver `-s' en slapd(8))
              syslog-level=<nivel> (ver `-S' en slapd(8))
              syslog-user=<usuario>   (ver `-l' en slapd(8))
Las opciones/valores posibles específicos de slapacl son:
              authzDN
              domain
              peername
              sasl_ssf
              sockname
              sockurl
              ssf
              tls_ssf
              transport_ssf
Consulte los campos relacionados en slapd.access(5) para obtener detalles.
-u
habilita el modo de prueba (dry-run). No recupera ninguna entrada de la base de datos. En este caso, se utiliza una entrada ficticia con el DN dado con la opción -b, sin atributos. Como consecuencia, las reglas que dependen del contenido del objeto de destino o de cualquier otro objeto de la base de datos no se comportarán como con el objeto real. El DN dado con la opción -b todavía se utiliza para seleccionar qué reglas se aplican; por lo tanto, debe estar en el contexto de nomenclatura de una base de datos configurada. Consulte también -b.
-U ID-autenticacion
especifica una ID que se mapeará a un DN como mediante reglas authz-regexp o authz-rewrite (consulte slapd.conf(5) para obtener detalles); mutuamente exclusiva con -D.
-v
habilita el modo detallado (verbose).
-X ID-autorizacion
especifica una ID de autorización que se mapeará a un DN como mediante reglas authz-regexp o authz-rewrite (consulte slapd.conf(5) para obtener detalles); mutuamente exclusiva con -o DN-autorizacion=DN.

EJEMPLOS

El comando

	/usr/bin/slapacl -f /etc/openldap/slapd.conf -v \
            -U bjorn -b "o=University of Michigan,c=US" \
	    "o/read:University of Michigan"
prueba si el usuario bjorn puede acceder al atributo o de la entrada o=University of Michigan,c=US a nivel de lectura.
