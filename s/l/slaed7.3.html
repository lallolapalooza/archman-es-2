SLAED7 utilizado por SSTEDC. Calcula el sistema de ecuaciones autovalores-autovectores actualizado de una matriz diagonal después de la modificación por una matriz simétrica de rango uno. Utilizado cuando la matriz original es densa.

Propósito:

!>
!> SLAED7 calcula el sistema de ecuaciones autovalores-autovectores actualizado de una
!> matriz diagonal después de la modificación por una matriz simétrica de rango uno.
!> Esta subrutina se utiliza solo para el problema de autovalores que requiere todos
!> los autovalores y opcionalmente los autovectores de una matriz simétrica densa
!> que ha sido reducida a forma tridiagonal. SLAED1 maneja el caso en el que se desean
!> todos los autovalores y autovectores de una matriz tridiagonal simétrica.
!>
!>   T = Q(in) ( D(in) + RHO * Z*Z**T ) Q**T(in) = Q(out) * D(out) * Q**T(out)
!>
!>    donde Z = Q**Tu, u es un vector de longitud N con unos en los elementos
!>    CUTPNT y CUTPNT + 1 y ceros en el resto.
!>
!>    Los autovectores de la matriz original se almacenan en Q, y los
!>    autovalores están en D. El algoritmo consta de tres etapas:
!>
!>       La primera etapa consiste en desinflar el tamaño del problema
!>       cuando hay autovalores múltiples o si hay un cero en
!>       el vector Z. Por cada ocurrencia de este tipo, la dimensión del
!>       problema de la ecuación secular se reduce en uno. Esta etapa
!>       es realizada por la subrutina SLAED8.
!>
!>       La segunda etapa consiste en calcular los autovalores
!>       actualizados. Esto se hace encontrando las raíces de la ecuación
!>       secular a través de la subrutina SLAED4 (llamada por SLAED9).
!>       Esta subrutina también calcula los autovectores del problema actual.
!>
!>       La etapa final consiste en calcular directamente los autovectores
!>       actualizados utilizando los autovalores actualizados. Los autovectores
!>       para el problema actual se multiplican con los autovectores del
!>       problema general.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>          = 0:  Calcula solo los autovalores.
!>          = 1:  Calcula también los autovectores de la matriz simétrica densa original.
!>                En la entrada, Q contiene la matriz ortogonal utilizada
!>                para reducir la matriz original a forma tridiagonal.
!>

N

!>          N es INTEGER
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

QSIZ

!>          QSIZ es INTEGER
!>         La dimensión de la matriz ortogonal utilizada para reducir
!>         la matriz completa a forma tridiagonal.  QSIZ >= N si ICOMPQ = 1.
!>

TLVLS

!>          TLVLS es INTEGER
!>         El número total de niveles de fusión en el árbol general de
!>         divide y vencerás.
!>

CURLVL

!>          CURLVL es INTEGER
!>         El nivel actual en la subrutina de fusión general,
!>         0 <= CURLVL <= TLVLS.
!>

CURPBM

!>          CURPBM es INTEGER
!>         El problema actual en el nivel actual de la subrutina de
!>         fusión general (contando desde la esquina superior izquierda hasta
!>         la inferior derecha).
!>

D

!>          D es array REAL, dimension (N)
!>         En la entrada, los autovalores de la matriz perturbada por rango 1.
!>         En la salida, los autovalores de la matriz reparada.
!>

Q

!>          Q es array REAL, dimension (LDQ, N)
!>         En la entrada, los autovectores de la matriz perturbada por rango 1.
!>         En la salida, los autovectores de la matriz tridiagonal reparada.
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q.  LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ es array INTEGER, dimension (N)
!>         La permutación que reintegrará el subproblema recién resuelto
!>         en orden ordenado, es decir, D( INDXQ( I = 1, N ) )
!>         estará en orden ascendente.
!>

RHO

!>          RHO es REAL
!>         El elemento subdiagonal utilizado para crear la modificación
!>         de rango 1.
!>

CUTPNT

!>          CUTPNT es INTEGER
!>         Contiene la ubicación del último autovalor en la submatriz
!>         principal.  min(1,N) <= CUTPNT <= N.
!>

QSTORE

!>          QSTORE es array REAL, dimension (N**2+1)
!>         Almacena autovectores de submatrices encontradas durante
!>         el divide y vencerás, empaquetados juntos. QPTR apunta al
!>         principio de las submatrices.
!>

QPTR

!>          QPTR es array INTEGER, dimension (N+2)
!>         Lista de índices que apuntan al principio de las submatrices almacenadas
!>         en QSTORE. Las submatrices se numeran comenzando desde la
!>         esquina inferior izquierda del árbol de divide y vencerás, de
!>         izquierda a derecha y de abajo hacia arriba.
!>

PRMPTR

!>          PRMPTR es array INTEGER, dimension (N lg N)
!>         Contiene una lista de punteros que indican dónde en PERM se
!>         almacena la permutación de un nivel. PRMPTR(i+1) - PRMPTR(i)
!>         indica el tamaño de la permutación y también el tamaño del
!>         problema completo, sin desinflar.
!>

PERM

!>          PERM es array INTEGER, dimension (N lg N)
!>         Contiene las permutaciones (de la desinflación y ordenación) que se
!>         aplicarán a cada bloque de autovalores.
!>

GIVPTR

!>          GIVPTR es array INTEGER, dimension (N lg N)
!>         Contiene una lista de punteros que indican dónde en GIVCOL se
!>         almacenan las rotaciones de Givens de un nivel. GIVPTR(i+1) - GIVPTR(i)
!>         indica el número de rotaciones de Givens.
!>

GIVCOL

!>          GIVCOL es array INTEGER, dimension (2, N lg N)
!>         Cada par de números indica un par de columnas para realizar
!>         una rotación de Givens.
!>

GIVNUM

!>          GIVNUM es array REAL, dimension (2, N lg N)
!>         Cada número indica el valor S que se utilizará en la
!>         rotación de Givens correspondiente.
!>

WORK

!>          WORK es array REAL, dimension (3*N+2*QSIZ*N)
!>

IWORK

!>          IWORK es array INTEGER, dimension (4*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = 1, un autovalor no convergió.
!>
