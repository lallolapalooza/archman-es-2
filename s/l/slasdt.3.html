subrutina slasdt (n, lvl, nd, inode, ndiml, ndimr, msub)

SLASDT crea un árbol de subproblemas para el método de conquista por división bidiagonal. Usado por sbdsdc.

Documentación de Función/Subrutina

subroutine slasdt (integer n, integer lvl, integer nd, integer, dimension( * ) inode, integer, dimension( * ) ndiml, integer, dimension( * ) ndimr, integer msub)

SLASDT crea un árbol de subproblemas para el método de conquista por división bidiagonal. Usado por sbdsdc.

Propósito:

!>
!> SLASDT crea un árbol de subproblemas para la conquista por división
!> bidiagonal.
!>

Parámetros

N 
!>          N es ENTERO
!>          En la entrada, el número de elementos diagonales de la
!>          matriz bidiagonal.
!>

LVL

!>          LVL es ENTERO
!>          En la salida, el número de niveles en el árbol de cómputo.
!>

ND

!>          ND es ENTERO
!>          En la salida, el número de nodos en el árbol.
!>

INODE

!>          INODE es un array ENTERO, dimensión ( N )
!>          En la salida, centros de subproblemas.
!>

NDIML

!>          NDIML es un array ENTERO, dimensión ( N )
!>          En la salida, dimensiones de fila de los hijos izquierdos.
!>

NDIMR

!>          NDIMR es un array ENTERO, dimensión ( N )
!>          En la salida, dimensiones de fila de los hijos derechos.
!>

MSUB

!>          MSUB es ENTERO
!>          En la entrada, la dimensión de fila máxima que puede tener cada
!>          subproblema en la parte inferior del árbol.
!>
