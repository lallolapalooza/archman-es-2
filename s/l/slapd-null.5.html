NOMBRE

slapd-null - Backend nulo para slapd

SINOPSIS

/etc/openldap/slapd.conf

DESCRIPCIÓN

El backend nulo para slapd(8) es, sin duda, la parte más útil de slapd:
- Las búsquedas devuelven éxito pero sin entradas.
- Las comparaciones devuelven compareFalse.
- Las actualizaciones devuelven éxito (a menos que readonly esté activado) pero no hacen nada.
- Las vinculaciones que no sean como rootdn fallan a menos que se proporcione la opción de base de datos "bind on".
- Las herramientas slapadd(8) y slapcat(8) son igualmente emocionantes.
Inspirado por el dispositivo /dev/null.

CONFIGURACIÓN

Esta opción de slapd.conf se aplica a la base de datos del backend NULL. Es decir, debe seguir una línea "database null" y preceder a cualquier línea "database" subsiguiente. Otras opciones de base de datos se describen en la página del manual de slapd.conf(5).

bind <on/off>
Permite vinculaciones como cualquier DN en el sufijo de esta base de datos, con cualquier contraseña. El valor predeterminado es "off".
dosearch <on/off>
Si está habilitado, se devolverá una única entrada en todas las solicitudes de búsqueda. El DN de la entrada será el mismo que el sufijo de la base de datos. El valor predeterminado es "off".

EJEMPLO

Aquí hay un extracto posible de slapd.conf que utiliza el backend Nulo:

database null
suffix   "cn=Nada"
bind     on

CONTROL DE ACCESO

El backend null no respeta ninguna de las semánticas de control de acceso descritas en slapd.access(5).

ARCHIVOS

/etc/openldap/slapd.conf
archivo de configuración predeterminado de slapd

VER TAMBIÉN

slapd.conf(5), slapd(8), slapadd(8), slapcat(8).
