función real slantb (norm, uplo, diag, n, k, ab, ldab, work)

SLANTB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz triangular de banda.

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

real function slantb (character norm, character uplo, character diag, integer n, integer k, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) work)

SLANTB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz triangular de banda.

Propósito:

!>
!> SLANTB  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el elemento de mayor valor absoluto de una matriz
!> triangular de banda A de n por n,  con ( k + 1 ) diagonales.
!>

Devuelve

SLANTB 
!>
!>    SLANTB = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columnas),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de filas) y
!> normF  denota la  norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Nótese que  max(abs(A(i,j)))  no es una norma de matriz consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en SLANTB como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es superior o inferior triangular.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria o no.
!>          = 'N':  No unitaria
!>          = 'U':  Unitaria
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, SLANTB se
!>          establece a cero.
!>

K

!>          K es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales de la matriz A si UPLO = 'L'.
!>          K >= 0.
!>

AB

!>          AB es array REAL, dimension (LDAB,N)
!>          La matriz triangular de banda superior o inferior A, almacenada en
!>          las primeras k+1 filas de AB.  La j-ésima columna de A se almacena
!>          en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(k+1+i-j,j) = A(i,j) para max(1,j-k)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)   = A(i,j) para j<=i<=min(n,j+k).
!>          Nótese que cuando DIAG = 'U', los elementos del array AB
!>          correspondientes a los elementos diagonales de la matriz A no
!>          se referencian, pero se asumen como uno.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= K+1.
!>

WORK

!>          WORK es array REAL, dimension (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I'; de lo contrario, WORK no
!>          se referencia.
!>
