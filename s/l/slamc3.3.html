real función slamch (character cmach)

SLAMCH

Propósito:

!>
!> SLAMCH determina los parámetros de máquina de precisión simple.
!>

Parámetros

CMACH 
!>          CMACH es CHARACTER*1
!>          Especifica el valor a ser devuelto por SLAMCH:
!>          = 'E' o 'e',   SLAMCH := eps
!>          = 'S' o 's',   SLAMCH := sfmin
!>          = 'B' o 'b',   SLAMCH := base
!>          = 'P' o 'p',   SLAMCH := eps*base
!>          = 'N' o 'n',   SLAMCH := t
!>          = 'R' o 'r',   SLAMCH := rnd
!>          = 'M' o 'm',   SLAMCH := emin
!>          = 'U' o 'u',   SLAMCH := rmin
!>          = 'L' o 'l',   SLAMCH := emax
!>          = 'O' o 'o',   SLAMCH := rmax
!>          donde
!>          eps   = precisión relativa de la máquina
!>          sfmin = mínimo seguro, tal que 1/sfmin no desborde
!>          base  = base de la máquina
!>          prec  = eps*base
!>          t     = número de dígitos (de base) en el mantisa
!>          rnd   = 1.0 cuando ocurre redondeo en la suma, 0.0 en caso contrario
!>          emin  = exponente mínimo antes de la subdesbordamiento (gradual)
!>          rmin  = umbral de subdesbordamiento - base**(emin-1)
!>          emax  = exponente más grande antes del desbordamiento
!>          rmax  = umbral de desbordamiento  - (base**emax)*(1-eps)
!>
