NOMBRE

slapauth - Comprobar una lista de IDs representadas como cadenas para autenticación/autorización LDAP

SINOPSIS

/usr/bin/slapauth [-d nivel-depuracion] [-f slapd.conf] [-F dir-config] [-M mecanismo] [-o opcion[=valor]] [-R dominio] [-U ID-autenticacion] [-v] [-X ID-autorizacion] ID [...]

DESCRIPCIÓN

Slapauth se utiliza para comprobar el comportamiento de slapd en el mapeo de identidades para fines de autenticación y autorización, tal como se especifica en slapd.conf(5). Abre el archivo de configuración slapd.conf(5) o el backend de slapd-config(5), lee las directivas authz-policy/olcAuthzPolicy y authz-regexp/olcAuthzRegexp, y luego analiza la lista de ID dada en la línea de comandos.

OPCIONES

-d nivel-depuracion
habilita mensajes de depuración según lo definido por el nivel-depuracion especificado; ver slapd(8) para más detalles.
-f slapd.conf
especifica un archivo slapd.conf(5) alternativo.
-F dir-config
especifica un directorio de configuración. Si se especifican tanto -f como -F, el archivo de configuración se leerá y se convertirá al formato de directorio de configuración y se escribirá en el directorio especificado. Si no se especifica ninguna opción, se intentará leer el directorio de configuración predeterminado antes de intentar utilizar el archivo de configuración predeterminado. Si existe un directorio de configuración válido, se ignora el archivo de configuración predeterminado.
-M mecanismo
especifica un mecanismo.
-o opcion[=valor]
especifica una opcion con un (opcional) valor. Las posibles opciones/valores genéricos son:
              syslog=<subsistemas>  (ver `-s' en slapd(8))
              syslog-level=<nivel> (ver `-S' en slapd(8))
              syslog-user=<usuario>   (ver `-l' en slapd(8))
-R dominio
especifica un dominio.
-U ID-autenticacion
especifica un ID a utilizar como ID-autenticacion durante la sesión de prueba. Si está presente, y si no se proporciona ningún ID-autorizacion, los IDs de la lista de IDs se tratan como ID-autorizacion.
-X ID-autorizacion
especifica un ID a utilizar como ID-autorizacion durante la sesión de prueba. Si está presente, y si no se proporciona ningún ID-autenticacion, los IDs de la lista de IDs se tratan como ID-autenticacion. Si se proporcionan tanto ID-autenticacion como ID-autorizacion a través de un interruptor de línea de comandos, no se puede presentar la lista de IDs.
-v
habilita el modo detallado.

EJEMPLOS

El comando

	/usr/bin/slapauth -f //etc/openldap/slapd.conf -v \
            -U bjorn -X u:bjensen
prueba si el usuario bjorn puede asumir la identidad del usuario bjensen siempre que las directivas 
authz-policy from
authz-regexp "^uid=([^,]+).*,cn=auth$"
	"ldap:///dc=example,dc=net??sub?uid=$1"
se definen en slapd.conf(5).
