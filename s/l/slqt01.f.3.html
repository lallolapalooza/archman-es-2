Documentación de Función/Subrutina

subrutina slqt01 (integer m, integer n, real, dimension( lda, * ) a, real, dimension( lda, * ) af, real, dimension( lda, * ) q, real, dimension( lda, * ) l, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

SLQT01

Propósito

!>
!> SLQT01 prueba SGELQF, que calcula la factorización LQ de una matriz m por n
!> A, y prueba parcialmente SORGLQ que forma la matriz ortogonal n por n
!> Q.
!>
!> SLQT01 compara L con A*Q', y verifica que Q es ortogonal.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A. N >= 0.
!>

A

!>          A es arreglo REAL, dimensión (LDA,N)
!>          La matriz m por n A.
!>

AF

!>          AF es arreglo REAL, dimensión (LDA,N)
!>          Detalles de la factorización LQ de A, devueltos por SGELQF.
!>          Consultar SGELQF para más detalles.
!>

Q

!>          Q es arreglo REAL, dimensión (LDA,N)
!>          La matriz ortogonal n por n Q.
!>

L

!>          L es arreglo REAL, dimensión (LDA,max(M,N))
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arreglos A, AF, Q y L.
!>          LDA >= max(M,N).
!>

TAU

!>          TAU es arreglo REAL, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales, devueltos
!>          por SGELQF.
!>

WORK

!>          WORK es arreglo REAL, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del arreglo WORK.
!>

RWORK

!>          RWORK es arreglo REAL, dimensión (max(M,N))
!>

RESULT

!>          RESULT es arreglo REAL, dimensión (2)
!>          Las razones de prueba:
!>          RESULT(1) = norm( L - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
