NOMBRE

slapo-lastbind - overlay lastbind para slapd

SINOPSIS

ETCDIR/slapd.conf

DESCRIPCIÓN

El overlay lastbind para slapd(8) permite registrar la marca de tiempo de la última autenticación (bind) exitosa a las entradas en el directorio, en el atributo authTimestamp. El overlay se puede configurar para actualizar esta marca de tiempo solo si es más antigua que un valor dado, evitando así un gran número de operaciones de escritura que penalicen el rendimiento. Un uso de ejemplo para este overlay sería detectar cuentas no utilizadas.

Ahora que OpenLDAP tiene soporte nativo para la mayoría de esta funcionalidad, almacenando el valor en pwdLastSuccess para interactuar mejor con el borrador 10 de la Política de Contraseñas de Behera. A menos que requiera lastbind_forward_updates, debería considerar usar eso en su lugar.

CONFIGURACIÓN

Las directivas de configuración específicas del overlay lastbind deben ir prefijadas por lastbind-, para evitar conflictos potenciales con directivas específicas de la base de datos subyacente o de otros overlays apilados.

overlay lastbind
Esta directiva añade el overlay lastbind a la base de datos actual, ver slapd.conf(5) para más detalles.

Esta opción de configuración de slapd.conf está definida para el overlay lastbind. Debe aparecer después de la directiva overlay:

lastbind-precision <segundos>
El valor <segundos> es el número de segundos después del cual se actualizará el atributo authTimestamp en una entrada. Si el valor existente de authTimestamp tiene menos de <segundos> de antigüedad, no se modificará. Si esta opción de configuración se omite, el atributo authTimestamp se actualiza en cada operación de bind exitosa.
lastbind_forward_updates
Especifica que las actualizaciones del atributo authTimestamp en un consumidor se deban reenviar a un proveedor en lugar de escribirse directamente en la base de datos local del consumidor. Esta configuración solo es útil en un consumidor de replicación, y también requiere que la configuración updateref y el overlay chain estén configurados apropiadamente.

EJEMPLO

Este ejemplo configura el overlay lastbind para almacenar authTimestamp en todas las entradas de una base de datos, con una precisión de 1 semana. Añada lo siguiente a slapd.conf(5):

    database <database>
    # ...
    overlay lastbind
    lastbind-precision 604800

slapd también debe cargar lastbind.la, si se compila como módulo en tiempo de ejecución;

ARCHIVOS

ETCDIR/slapd.conf
archivo de configuración por defecto de slapd

VER TAMBIÉN

slapd.conf(5), slapd(8).

Propuesta de política de contraseñas LDAP de la IETF por P. Behera, L. Poitou y J. Sermersheim: documentada en el documento de la IETF "draft-behera-ldap-password-policy-10.txt".

El overlay slapo-lastbind(5) soporta la configuración dinámica a través de back-config.
