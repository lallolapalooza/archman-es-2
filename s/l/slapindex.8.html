NOMBRE

slapindex - Reindexar entradas en una base de datos SLAPD

SINOPSIS

/usr/bin/slapindex [-b sufijo] [-c] [-d nivel-depuracion] [-f slapd.conf] [-F directorio-conf] [-g] [-n num-bd] [-o opcion[=valor]] [-q] [-t] [-v] [atributo[...]]

DESCRIPCIÓN

Slapindex se utiliza para regenerar los índices de slapd(8) basándose en el contenido actual de una base de datos. Abre la base de datos especificada, determinada por el número de base de datos o el sufijo, y actualiza los índices de todos los valores de todos los atributos de todas las entradas. Si se proporciona una lista de atributos específicos en la línea de comandos, solo se regenerarán los índices para esos atributos. Las bases de datos configuradas como subordinadas de esta también se reindexarán, a menos que se especifique -g.

Todos los archivos creados eventualmente por slapindex pertenecerán a la identidad con la que se ejecute slapindex, así que asegúrese de ejecutar slapindex con la misma identidad con la que se ejecutará slapd(8) (ver opción -u en slapd(8)), o cambie la propiedad del archivo antes de ejecutar slapd(8).

OPCIONES

-b sufijo
Usa el sufijo especificado para determinar para qué base de datos generar la salida. Por defecto, se usa la primera base de datos que admite la operación solicitada. La opción -b no se puede usar junto con la opción -n.
-c
habilita el modo de continuación (ignorar errores).
-d nivel-depuracion
habilita mensajes de depuración según lo definido por el nivel-depuracion especificado; ver slapd(8) para detalles.
-f slapd.conf
especifica un archivo slapd.conf(5) alternativo.
-F directorio-conf
especifica un directorio de configuración. Si se especifican tanto -f como -F, se leerá el archivo de configuración y se convertirá al formato de directorio de configuración y se escribirá en el directorio especificado. Si no se especifica ninguna opción, se intentará leer el directorio de configuración predeterminado antes de intentar usar el archivo de configuración predeterminado. Si existe un directorio de configuración válido, se ignorará el archivo de configuración predeterminado.
-g
deshabilita la unión subordinada. Solo se procesará la base de datos especificada, y no sus subordinados unidos (si los hay).
-n num-bd
Genera salida para la num-bd-ésima base de datos listada en el archivo de configuración. La base de datos de configuración slapd-config(5), es siempre la primera base de datos, así que use -n 0.

La opción -n no se puede usar junto con la opción -b.

-o opcion[=valor]
Especifica una opción con un valor (opcional). Las posibles opciones/valores genéricos son:
              syslog=<subsistemas>  (ver `-s' en slapd(8))
              syslog-level=<nivel> (ver `-S' en slapd(8))
              syslog-user=<usuario>   (ver `-l' en slapd(8))
-q
habilita el modo rápido (menos comprobaciones de integridad). No realiza comprobaciones de consistencia al escribir la base de datos. Mejora el tiempo de indexación, sin embargo, la base de datos probablemente será inutilizable si ocurren errores o interrupciones.
-t
habilita el modo de truncamiento. Trunca (vacía) una base de datos de índice antes de indexar cualquier entrada. Solo se puede usar con back-mdb.
-v
habilita el modo detallado.

LIMITACIONES

Su slapd(8) no debería estar ejecutándose (al menos, no en modo de lectura/escritura) cuando haga esto para asegurar la consistencia de la base de datos.

Este comando ofrece amplias oportunidades para que el usuario obtenga y beba su bebida favorita.

EJEMPLOS

Para reindexar su base de datos SLAPD, ejecute el comando:

/usr/bin/slapindex
Para regenerar el índice de solo un atributo específico, por ejemplo, "uid", ejecute el comando: 
/usr/bin/slapindex uid
