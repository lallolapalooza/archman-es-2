SLASD6 calcula la SVD de una matriz bidiagonal superior actualizada B obtenida al fusionar dos más pequeñas añadiendo una fila. Utilizado por sbdsdc.

Propósito:

!>
!> SLASD6 calcula la SVD de una matriz bidiagonal superior actualizada B
!> obtenida al fusionar dos más pequeñas añadiendo una fila. Esta
!> subrutina se utiliza solo para el problema que requiere todos los valores
!> singulares y opcionalmente las matrices de vectores singulares en forma
!> factorizada.
!> B es una matriz de N por M con N = NL + NR + 1 y M = N + SQRE.
!> Una subrutina relacionada, SLASD1, maneja el caso en el que se desean
!> todos los valores singulares y vectores singulares de la matriz bidiagonal.
!>
!> SLASD6 calcula la SVD de la siguiente manera:
!>
!>               ( D1(en)    0    0       0 )
!>   B = U(en) * (   Z1**T   a   Z2**T    b ) * VT(en)
!>               (   0       0   D2(en)   0 )
!>
!>     = U(salida) * ( D(salida) 0) * VT(salida)
!>
!> donde Z**T = (Z1**T a Z2**T b) = u**T VT**T, y u es un vector de dimensión M
!> con ALPHA y BETA en las entradas NL+1 y NL+2 y ceros
!> en otros lugares; y la entrada b está vacía si SQRE = 0.
!>
!> Los valores singulares de B se pueden calcular utilizando D1, D2, los primeros
!> componentes de todos los vectores singulares derechos del bloque inferior, y
!> los últimos componentes de todos los vectores singulares derechos del bloque
!> superior. Estos componentes se almacenan y actualizan en VF y VL,
!> respectivamente, en SLASD6. Por lo tanto, U y VT no se referencian explícitamente.
!>
!> Los valores singulares se almacenan en D. El algoritmo consta de dos
!> etapas:
!>
!>       La primera etapa consiste en desinflar el tamaño del problema
!>       cuando hay múltiples valores singulares o si hay un cero
!>       en el vector Z. Por cada ocurrencia de este tipo, la dimensión del
!>       problema de la ecuación secular se reduce en uno. Esta etapa es
!>       realizada por la subrutina SLASD7.
!>
!>       La segunda etapa consiste en calcular los valores singulares
!>       actualizados. Esto se hace encontrando las raíces de la
!>       ecuación secular a través de la subrutina SLASD4 (como es llamada por SLASD8).
!>       Esta subrutina también actualiza VF y VL y calcula las distancias
!>       entre los valores singulares actualizados y los valores singulares
!>       antiguos.
!>
!> SLASD6 es llamada desde SLASDA.
!>

ICOMPQ 
!>          ICOMPQ es INTEGER
!>         Especifica si se deben calcular los vectores singulares en
!>         forma factorizada:
!>         = 0: Calcular solo los valores singulares.
!>         = 1: Calcular también los vectores singulares en forma factorizada.
!>

NL

!>          NL es INTEGER
!>         La dimensión de fila del bloque superior.  NL >= 1.
!>

NR

!>          NR es INTEGER
!>         La dimensión de fila del bloque inferior.  NR >= 1.
!>

SQRE

!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada de NR por NR.
!>         = 1: el bloque inferior es una matriz rectangular de NR por (NR+1).
!>
!>         La matriz bidiagonal tiene dimensión de fila N = NL + NR + 1,
!>         y dimensión de columna M = N + SQRE.
!>

D

!>          D es un array REAL, de dimensión (NL+NR+1).
!>         En la entrada, D(1:NL) contiene los valores singulares del
!>         bloque superior, y D(NL+2:N) contiene los valores singulares
!>         del bloque inferior. En la salida, D(1:N) contiene los valores
!>         singulares de la matriz modificada.
!>

VF

!>          VF es un array REAL, de dimensión (M)
!>         En la entrada, VF(1:NL+1) contiene los primeros componentes de todos
!>         los vectores singulares derechos del bloque superior; y VF(NL+2:M)
!>         contiene los primeros componentes de todos los vectores singulares
!>         derechos del bloque inferior. En la salida, VF contiene los primeros componentes
!>         de todos los vectores singulares derechos de la matriz bidiagonal.
!>

VL

!>          VL es un array REAL, de dimensión (M)
!>         En la entrada, VL(1:NL+1) contiene los últimos componentes de todos
!>         los vectores singulares derechos del bloque superior; y VL(NL+2:M)
!>         contiene los últimos componentes de todos los vectores singulares derechos de
!>         el bloque inferior. En la salida, VL contiene los últimos componentes de
!>         todos los vectores singulares derechos de la matriz bidiagonal.
!>

ALPHA

!>          ALPHA es REAL
!>         Contiene el elemento diagonal asociado con la fila añadida.
!>

BETA

!>          BETA es REAL
!>         Contiene el elemento fuera de la diagonal asociado con la fila
!>         añadida.
!>

IDXQ

!>          IDXQ es un array INTEGER, de dimensión (N)
!>         Contiene la permutación que reintegrará el subproblema recién resuelto
!>         en orden ordenado, es decir, D( IDXQ( I = 1, N ) ) estará en orden

PERM

!>          PERM es un array INTEGER, de dimensión ( N )

GIVPTR

!>          GIVPTR es INTEGER
!>         El número de rotaciones de Givens que tuvieron lugar en este

GIVCOL

!>          GIVCOL es un array INTEGER, de dimensión ( LDGCOL, 2 )

!>         en una rotación de Givens. No se referencia si ICOMPQ = 0.

LDGCOL

!>          LDGCOL es INTEGER
!>         Dimensión principal de GIVCOL, debe ser al menos N.

GIVNUM

LDGNUM

!>          LDGNUM es INTEGER

  Purpose
  =======
     SLASD6 computes the SQRT(N) of the I-th singular value of the
     trapezoidal matrix T, where T is the N-by-N upper triangular
     submatrix of the matrix A after removing the rows and columns
     of the first K singular values.

     It computes the I-th singular value using the related secular
     equation.

     For the definition of the Secular Equation, please refer to
     Section 4.7 of the report "A hierarchical representations of
     matrices" by Wesley, Peter, and Nicholas.

     A related problem is to compute the I-th singular value of the
     matrix A (1=I=K), where A is a N x N upper triangular matrix
     such that

     diag(SQRT(N)) = diag(1/SQRT(N)) * A = A.

     Let A = K x N and the first K singular values of A are removed.
     Then the remaining N-K singular values of A are computed.

     The purpose of SLASD6 is to compute the I-th singular value
     of the matrix A after removing the first K singular values.
