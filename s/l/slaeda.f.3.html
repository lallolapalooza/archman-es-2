subroutine slaeda (integer n, integer tlvls, integer curlvl, integer curpbm, integer, dimension( * ) prmptr, integer, dimension( * ) perm, integer, dimension( * ) givptr, integer, dimension( 2, * ) givcol, real, dimension( 2, * ) givnum, real, dimension( * ) q, integer, dimension( * ) qptr, real, dimension( * ) z, real, dimension( * ) ztemp, integer info)

SLAEDA usado por SSTEDC. Calcula el vector Z que determina la modificación de rango uno de la matriz diagonal. Usado cuando la matriz original es densa.

Propósito:

!>
!> SLAEDA calcula el vector Z correspondiente al paso de fusión en el
!> paso CURLVL de la rutina de fusión general con TLVLS pasos para el problema CURPBM.
!>

Parámetros

N 
!>          N es INTEGER
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

TLVLS

!>          TLVLS es INTEGER
!>         El número total de niveles de fusión en el árbol de divide y vencer general.
!>

CURLVL

!>          CURLVL es INTEGER
!>         El nivel actual en la rutina de fusión general,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM es INTEGER
!>         El problema actual en el nivel actual de la rutina de fusión general
!>         (contando de arriba a la izquierda a abajo a la derecha).
!>

PRMPTR

!>          PRMPTR es un array INTEGER, dimension (N lg N)
!>         Contiene una lista de punteros que indican dónde en PERM se almacena
!>         la permutación de un nivel.  PRMPTR(i+1) - PRMPTR(i)
!>         indica el tamaño de la permutación y, de forma incidental, el
!>         tamaño del problema completo, no desdeflado.
!>

PERM

!>          PERM es un array INTEGER, dimension (N lg N)
!>         Contiene las permutaciones (de desdeflación y ordenación) a aplicar
!>         a cada sub-bloque de eigenvalores.
!>

GIVPTR

!>          GIVPTR es un array INTEGER, dimension (N lg N)
!>         Contiene una lista de punteros que indican dónde en GIVCOL se almacenan
!>         las rotaciones de Givens de un nivel.  GIVPTR(i+1) - GIVPTR(i)
!>         indica el número de rotaciones de Givens.
!>

GIVCOL

!>          GIVCOL es un array INTEGER, dimension (2, N lg N)
!>         Cada par de números indica un par de columnas para realizar
!>         una rotación de Givens.
!>

GIVNUM

!>          GIVNUM es un array REAL, dimension (2, N lg N)
!>         Cada número indica el valor S a usar en la rotación de Givens
!>         correspondiente.
!>

Q

!>          Q es un array REAL, dimension (N**2)
!>         Contiene los sub-bloques de eigenvalores cuadrados de niveles anteriores,
!>         las posiciones iniciales de los bloques están dadas por QPTR.
!>

QPTR

!>          QPTR es un array INTEGER, dimension (N+2)
!>         Contiene una lista de punteros que indican dónde en Q está almacenado
!>         un sub-bloque de eigenvalores.  SQRT( QPTR(i+1) - QPTR(i) ) indica
!>         el tamaño del bloque.
!>

Z

!>          Z es un array REAL, dimension (N)
!>         En la salida, este vector contiene el vector de actualización (la última
!>         fila de la primera matriz de sub-vectores propios y la primera fila de
!>         la segunda matriz de sub-vectores propios).
!>

ZTEMP

!>          ZTEMP es un array REAL, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
