subroutine slags2 (logical upper, real a1, real a2, real a3, real b1, real b2, real b3, real csu, real snu, real csv, real snv, real csq, real snq)

SLAGS2 calcula matrices ortogonales 2x2 U, V y Q, y las aplica a las matrices A y B de tal manera que las filas de A y B transformadas sean paralelas.

Propósito:

!>
!> SLAGS2 calcula matrices ortogonales 2x2 U, V y Q, tales
!> que si ( UPPER ) entonces
!>
!>           U**T *A*Q = U**T *( A1 A2 )*Q = ( x  0  )
!>                             ( 0  A3 )     ( x  x  )
!> y
!>           V**T*B*Q = V**T *( B1 B2 )*Q = ( x  0  )
!>                            ( 0  B3 )     ( x  x  )
!>
!> o si ( .NOT.UPPER ) entonces
!>
!>           U**T *A*Q = U**T *( A1 0  )*Q = ( x  x  )
!>                             ( A2 A3 )     ( 0  x  )
!> y
!>           V**T*B*Q = V**T*( B1 0  )*Q = ( x  x  )
!>                           ( B2 B3 )     ( 0  x  )
!>
!> Las filas de A y B transformadas son paralelas, donde
!>
!>   U = (  CSU  SNU ), V = (  CSV SNV ), Q = (  CSQ   SNQ )
!>       ( -SNU  CSU )      ( -SNV CSV )      ( -SNQ   CSQ )
!>
!> Z**T denota la transpuesta de Z.
!>
!>

Parámetros

UPPER 
!>          UPPER es LOGICAL
!>          = .TRUE.: las matrices de entrada A y B son triangulares superiores.
!>          = .FALSE.: las matrices de entrada A y B son triangulares inferiores.
!>

A1

!>          A1 es REAL
!>

A2

!>          A2 es REAL
!>

A3

!>          A3 es REAL
!>          En la entrada, A1, A2 y A3 son elementos de la matriz triangular
!>          superior (inferior) 2x2 de entrada A.
!>

B1

!>          B1 es REAL
!>

B2

!>          B2 es REAL
!>

B3

!>          B3 es REAL
!>          En la entrada, B1, B2 y B3 son elementos de la matriz triangular
!>          superior (inferior) 2x2 de entrada B.
!>

CSU

!>          CSU es REAL
!>

SNU

!>          SNU es REAL
!>          La matriz ortogonal deseada U.
!>

CSV

!>          CSV es REAL
!>

SNV

!>          SNV es REAL
!>          La matriz ortogonal deseada V.
!>

CSQ

!>          CSQ es REAL
!>

SNQ

!>          SNQ es REAL
!>          La matriz ortogonal deseada Q.
!>
