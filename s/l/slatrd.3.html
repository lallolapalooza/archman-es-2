Funciones/Subrutinas


subrutina slatrd (uplo, n, nb, a, lda, e, tau, w, ldw)
SLATRD reduce las primeras nb filas y columnas de una matriz simétrica/hermitiana A a la forma tridiagonal real mediante una transformación de similitud ortogonal.

Documentación de Función/Subrutina

subrutina slatrd (carácter uplo, entero n, entero nb, real, dimensión( lda, * ) a, entero lda, real, dimensión( * ) e, real, dimensión( * ) tau, real, dimensión( ldw, * ) w, entero ldw)

SLATRD reduce las primeras nb filas y columnas de una matriz simétrica/hermitiana A a la forma tridiagonal real mediante una transformación de similitud ortogonal.

Propósito:

!>
!> SLATRD reduce NB filas y columnas de una matriz simétrica real A a
!> forma tridiagonal simétrica mediante una transformación de similitud ortogonal
!> Q**T * A * Q, y devuelve las matrices V y W que son
!> necesarias para aplicar la transformación a la parte no reducida de A.
!>
!> Si UPLO = 'U', SLATRD reduce las últimas NB filas y columnas de una
!> matriz, de la cual se suministra el triángulo superior;
!> si UPLO = 'L', SLATRD reduce las primeras NB filas y columnas de una
!> matriz, de la cual se suministra el triángulo inferior.
!>
!> Esta es una subrutina auxiliar llamada por SSYTRD.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U': Triangular superior
!>          = 'L': Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.
!>

NB

!>          NB es INTEGER
!>          El número de filas y columnas a reducir.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la parte
!>          superior izquierda n por n de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente triangular inferior de A no se referencia. Si UPLO = 'L', la parte
!>          inferior izquierda n por n de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>          En la salida:
!>          si UPLO = 'U', las últimas NB columnas se han reducido a
!>            forma tridiagonal, con los elementos diagonales sobrescribiendo
!>            los elementos diagonales de A; los elementos por encima de la diagonal
!>            con el array TAU, representan la matriz ortogonal Q como un
!>            producto de reflectores elementales;
!>          si UPLO = 'L', las primeras NB columnas se han reducido a
!>            forma tridiagonal, con los elementos diagonales sobrescribiendo
!>            los elementos diagonales de A; los elementos por debajo de la diagonal
!>            con el array TAU, representan la matriz ortogonal Q como un
!>            producto de reflectores elementales.
!>          Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= (1,N).
!>

E

!>          E es un array REAL, dimensión (N-1)
!>          Si UPLO = 'U', E(n-nb:n-1) contiene los elementos superdiagonales
!>          de las últimas NB columnas de la matriz reducida;
!>          si UPLO = 'L', E(1:nb) contiene los elementos subdiagonales de
!>          las primeras NB columnas de la matriz reducida.
!>

TAU

!>          TAU es un array REAL, dimensión (N-1)
!>          Los factores escalares de los reflectores elementales, almacenados en
!>          TAU(n-nb:n-1) si UPLO = 'U', y en TAU(1:nb) si UPLO = 'L'.
!>          Ver Detalles Adicionales.
!>

W

!>          W es un array REAL, dimensión (LDW,NB)
!>          La matriz W de n por nb necesaria para actualizar la parte no reducida
!>          de A.
!>

LDW

!>          LDW es INTEGER
!>          La dimensión principal del array W. LDW >= max(1,N).
!>

Detalles Adicionales:

!>
!>  Si UPLO = 'U', la matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(n) H(n-1) . . . H(n-nb+1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real, y v es un vector real con
!>  v(i:n) = 0 y v(i-1) = 1; v(1:i-1) se almacena en la salida en A(1:i-1,i),
!>  y tau en TAU(i-1).
!>
!>  Si UPLO = 'L', la matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(nb).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real, y v es un vector real con
!>  v(1:i) = 0 y v(i+1) = 1; v(i+1:n) se almacena en la salida en A(i+1:n,i),
!>  y tau en TAU(i).
!>
!>  Los elementos de los vectores v forman conjuntamente la matriz V de n x nb
!>  que se necesita, con W, para aplicar la transformación a la parte no reducida
!>  de la matriz, utilizando una actualización simétrica de rango 2k de la forma:
!>  A := A - V*W**T - W*V**T.
!>
!>  Los contenidos de A en la salida se ilustran con los siguientes ejemplos
!>  con n = 5 y nb = 2:
!>
!>  si UPLO = 'U':                       si UPLO = 'L':
!>
!>    (  a   a   a   v4  v5 )              (  d                  )
!>    (      a   a   v4  v5 )              (  1   d              )
!>    (          a   1   v5 )              (  v1  1   a          )
!>    (              d   1  )              (  v1  v2  a   a      )
!>    (                  d  )              (  v1  v2  a   a   a  )
!>
!>  donde d denota un elemento diagonal de la matriz reducida, a denota
!>  un elemento de la matriz original que no ha cambiado, y vi denota
!>  un elemento del vector que define H(i).
!>
