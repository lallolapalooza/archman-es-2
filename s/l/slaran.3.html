Documentación de Función/Subrutina

real function slaran (integer, dimension( 4 ) iseed)

SLARAN

Propósito:

!>
!> SLARAN devuelve un número real aleatorio de una distribución uniforme (0,1)
!>

Parámetros

ISEED 
!>          ISEED es un array ENTERO, de dimensión (4)
!>          A la entrada, la semilla del generador de números aleatorios; los elementos
!>          del array deben estar entre 0 y 4095, y ISEED(4) debe ser impar.
!>          A la salida, la semilla se actualiza.
!>

Univ. de California Berkeley

Univ. de Colorado Denver

NAG Ltd.

Detalles adicionales:

!>
!>  Esta rutina utiliza un método congruencial multiplicativo con módulo
!>  2**48 y multiplicador 33952834046453 (ver G.S.Fishman,
!>  'Multiplicative congruential random number generators with modulus
!>  2**b: an exhaustive analysis for b = 32 and a partial analysis for
!>  b = 48', Math. Comp. 189, pp 331-344, 1990).
!>
!>  Los enteros de 48 bits se almacenan en 4 elementos de array enteros con 12 bits
!>  por elemento. Por lo tanto, la rutina es portable entre máquinas con
!>  enteros de 32 bits o más.
!>
