subrutina slarfb (side, trans, direct, storev, m, n, k, v, ldv, t, ldt, c, ldc, work, ldwork)
SLARFB aplica un reflector de bloque o su transpuesta a una matriz rectangular general.

Documentación de la función/subrutina

subroutine slarfb (character side, character trans, character direct, character storev, integer m, integer n, integer k, real, dimension( ldv, * ) v, integer ldv, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldc, * ) c, integer ldc, real, dimension( ldwork, * ) work, integer ldwork)

SLARFB aplica un reflector de bloque real H o su transpuesta H**T a una matriz real m por n C, desde la izquierda o desde la derecha.

Propósito:

!>
!> SLARFB aplica un reflector de bloque real H o su transpuesta H**T a una
!> matriz real m por n C, desde la izquierda o desde la derecha.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar H o H**T desde la Izquierda
!>          = 'R': aplicar H o H**T desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar H (Sin transpuesta)
!>          = 'T': aplicar H**T (Transpuesta)
!>

DIRECT

!>          DIRECT es CHARACTER*1
!>          Indica cómo se forma H a partir de un producto de reflectores
!>          elementales
!>          = 'F': H = H(1) H(2) . . . H(k) (Adelante)
!>          = 'B': H = H(k) . . . H(2) H(1) (Atrás)
!>

STOREV

!>          STOREV es CHARACTER*1
!>          Indica cómo se almacenan los vectores que definen los reflectores
!>          elementales:
!>          = 'C': Por columnas
!>          = 'R': Por filas
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

K

!>          K es INTEGER
!>          El orden de la matriz T (= el número de reflectores elementales
!>          cuyo producto define el reflector de bloque).
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

V

!>          V es un array REAL, de dimensión
!>                                (LDV,K) si STOREV = 'C'
!>                                (LDV,M) si STOREV = 'R' y SIDE = 'L'
!>                                (LDV,N) si STOREV = 'R' y SIDE = 'R'
!>          La matriz V. Ver Detalles adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si STOREV = 'C' y SIDE = 'L', LDV >= max(1,M);
!>          si STOREV = 'C' y SIDE = 'R', LDV >= max(1,N);
!>          si STOREV = 'R', LDV >= K.
!>

T

!>          T es un array REAL, de dimensión (LDT,K)
!>          La matriz triangular k por k T en la representación del
!>          reflector de bloque.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= K.
!>

C

!>          C es un array REAL, de dimensión (LDC,N)
!>          A la entrada, la matriz C de m por n.
!>          A la salida, C se sobrescribe con H*C o H**T*C o C*H o C*H**T.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array REAL, de dimensión (LDWORK,K)
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N);
!>          si SIDE = 'R', LDWORK >= max(1,M).
!>
