subrutina slattp (entero imat, carácter uplo, carácter trans, carácter diag, entero, dimensión( 4 ) iseed, entero n, real, dimensión( * ) a, real, dimensión( * ) b, real, dimensión( * ) work, entero info)

SLATTP

Propósito:

!>
!> SLATTP genera una matriz de prueba triangular en almacenamiento empaquetado.
!> IMAT y UPLO especifican de forma única las propiedades de la matriz de
!> prueba, que se devuelve en el array AP.
!>

Parámetros

IMAT 
!>          IMAT es ENTERO
!>          Una clave entera que describe qué matriz generar para esta
!>          ruta.
!>

UPLO

!>          UPLO es CARACTER*1
!>          Especifica si la matriz A será triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CARACTER*1
!>          Especifica si se usará la matriz o su transpuesta.
!>          = 'N':  Sin transpuesta
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada (= Transpuesta)
!>

DIAG

!>          DIAG es CARACTER*1
!>          Especifica si la matriz A es triangular unitaria o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

ISEED

!>          ISEED es un array de ENTEROS, dimensión (4)
!>          El vector semilla para el generador de números aleatorios (usado
!>          en SLATMS). Modificado a la salida.
!>

N

!>          N es ENTERO
!>          El orden de la matriz a generar.
!>

A

!>          A es un array de REALES, dimensión (N*(N+1)/2)
!>          La matriz triangular A superior o inferior, empaquetada por
!>          columnas en un array lineal. La j-ésima columna de A se almacena
!>          en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) para j<=i<=n.
!>

B

!>          B es un array de REALES, dimensión (N)
!>          El vector del lado derecho, si IMAT > 10.
!>

WORK

!>          WORK es un array de REALES, dimensión (3*N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0: si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>
