Documentación de función/subrutina

subrutina slarfgp (integer n, real alpha, real, dimension( * ) x, integer incx, real tau)

SLARFGP genera un reflector elemental real (matriz de Householder) con beta no negativo.

Propósito:

!>
!> SLARFGP genera un reflector elemental real H de orden n, tal que
!>
!>       H * ( alpha ) = ( beta ),   H**T * H = I.
!>           (   x   )   (   0  )
!>
!> donde alpha y beta son escalares, beta es no negativo, y x es un
!> vector real de (n-1) elementos. H se representa en la forma
!>
!>       H = I - tau * ( 1 ) * ( 1 v**T ) ,
!>                     ( v )
!>
!> donde tau es un escalar real y v es un vector real de (n-1)
!> elementos.
!>
!> Si los elementos de x son todos cero, entonces tau = 0 y H se toma
!> como la matriz unidad.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden del reflector elemental.
!>

ALPHA

!>          ALPHA es REAL
!>          En la entrada, el valor alpha.
!>          En la salida, se sobrescribe con el valor beta.
!>

X

!>          X es un array REAL, de dimensión
!>                         (1+(N-2)*abs(INCX))
!>          En la entrada, el vector x.
!>          En la salida, se sobrescribe con el vector v.
!>

INCX

!>          INCX es INTEGER
!>          El incremento entre los elementos de X. INCX > 0.
!>

TAU

!>          TAU es REAL
!>          El valor tau.
!>
