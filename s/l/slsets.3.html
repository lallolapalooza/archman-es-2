subrutina slsets (integer m, integer p, integer n, real, dimension( lda, * ) a, real, dimension( lda, * ) af, integer lda, real, dimension( ldb, * ) b, real, dimension( ldb, * ) bf, integer ldb, real, dimension( * ) c, real, dimension( * ) cf, real, dimension( * ) d, real, dimension( * ) df, real, dimension( * ) x, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( 2 ) result)

SLSETS

Propósito:

!>
!> SLSETS prueba SGGLSE - una subrutina para resolver el problema de mínimos
!> cuadrados lineales con restricciones de igualdad (LSE).
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es ENTERO
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices A y B.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>          La matriz A de M por N.
!>

AF

!>          AF es array REAL, dimensión (LDA,N)
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A, AF, Q y R.
!>          LDA >= max(M,N).
!>

B

!>          B es array REAL, dimensión (LDB,N)
!>          La matriz A de P por N.
!>

BF

!>          BF es array REAL, dimensión (LDB,N)
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal de los arrays B, BF, V y S.
!>          LDB >= max(P,N).
!>

C

!>          C es array REAL, dimensión( M )
!>          el vector C en el problema LSE.
!>

CF

!>          CF es array REAL, dimensión( M )
!>

D

!>          D es array REAL, dimensión( P )
!>          el vector D en el problema LSE.
!>

DF

!>          DF es array REAL, dimensión( P )
!>

X

!>          X es array REAL, dimensión( N )
!>          vector solución X en el problema LSE.
!>

WORK

!>          WORK es array REAL, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es array REAL, dimensión (M)
!>

RESULT

!>          RESULT es array REAL, dimensión (2)
!>          Las razones de prueba:
!>            RESULT(1) = norm( A*x - c )/ norm(A)*norm(X)*EPS
!>            RESULT(2) = norm( B*x - d )/ norm(B)*norm(X)*EPS
!>
