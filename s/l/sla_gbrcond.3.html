real función sla_gbrcond (carácter trans, entero n, entero kl, entero ku, real, dimensión( ldab, * ) ab, entero ldab, real, dimensión( ldafb, * ) afb, entero ldafb, entero, dimensión( * ) ipiv, entero cmode, real, dimensión( * ) c, entero info, real, dimensión( * ) work, entero, dimensión( * ) iwork)

SLA_GBRCOND estima el número de condición de Skeel para una matriz banda general.

Propósito:

!>
!>    SLA_GBRCOND Estima el número de condición de Skeel de  op(A) * op2(C)
!>    donde op2 está determinado por CMODE de la siguiente manera:
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    El número de condición de Skeel  cond(A) = norminf( |inv(A)||A| )
!>    se calcula calculando factores de escala R tales que
!>    diag(R)*A*op2(C) esté equilibrado por filas y calculando el número
!>    de condición de norma infinito estándar.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transpuesta)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

AB

!>          AB es array REAL, dimensión (LDAB,N)
!>     En la entrada, la matriz A en almacenamiento de banda, en las filas 1
!>     a KL+KU+1.
!>     La j-ésima columna de A se almacena en la j-ésima columna de la
!>     matriz AB como sigue:
!>     AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU) <= i <= min(N,j+kl)
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal de la matriz AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array REAL, dimensión (LDAFB,N)
!>     Detalles de la factorización LU de la matriz banda A, como
!>     calculado por SGBTRF.  U se almacena como una matriz triangular
!>     superior de banda con KL+KU superdiagonales en las filas 1 a
!>     KL+KU+1, y los multiplicadores utilizados durante la
!>     factorización se almacenan en las filas KL+KU+2 a 2*KL+KU+1.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal de la matriz AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     como se calculó por SGBTRF; la fila i de la matriz se intercambió
!>     con la fila IPIV(i).
!>

CMODE

!>          CMODE es INTEGER
!>     Determina op2(C) en la fórmula op(A) * op2(C) de la siguiente manera:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C es array REAL, dimensión (N)
!>     El vector C en la fórmula op(A) * op2(C).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es array REAL, dimensión (5*N).
!>     Espacio de trabajo.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (N).
!>     Espacio de trabajo.
!>
