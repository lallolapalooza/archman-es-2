Documentación de Función/Subrutina

subroutine slarf (character side, integer m, integer n, real, dimension( * ) v, integer incv, real tau, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work)

SLARF aplica un reflector elemental real H a una matriz rectangular real m por n C, desde la izquierda o desde la derecha. H se representa en la forma

Propósito:

!>
!> SLARF aplica un reflector elemental real H a una matriz rectangular real
!> m por n C, desde la izquierda o desde la derecha. H se representa en la forma
!>
!>       H = I - tau * v * v**T
!>
!> donde tau es un escalar real y v es un vector real.
!>
!> Si tau = 0, entonces H se considera la matriz unidad.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': forma  H * C
!>          = 'R': forma  C * H
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

V

!>          V es array REAL, dimensión
!>                     (1 + (M-1)*abs(INCV)) si SIDE = 'L'
!>                  o (1 + (N-1)*abs(INCV)) si SIDE = 'R'
!>          El vector v en la representación de H. V no se usa si
!>          TAU = 0.
!>

INCV

!>          INCV es INTEGER
!>          El incremento entre elementos de v. INCV <> 0.
!>

TAU

!>          TAU es REAL
!>          El valor tau en la representación de H.
!>

C

!>          C es array REAL, dimensión (LDC,N)
!>          En la entrada, la matriz C de m por n.
!>          En la salida, C se sobrescribe con la matriz H * C si SIDE = 'L',
!>          o C * H si SIDE = 'R'.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es array REAL, dimensión
!>                         (N) si SIDE = 'L'
!>                      o (M) si SIDE = 'R'
!>
