subroutine slasd1 (nl, nr, sqre, d, alpha, beta, u, ldu, vt, ldvt, idxq, iwork, work, info)
SLASD1 calcula la SVD de una matriz bidiagonal superior B del tamaño especificado. Utilizada por sbdsdc.

Documentación de Función/Subrutina

subrutina slasd1 (integer nl, integer nr, integer sqre, real, dimension( * ) d, real alpha, real beta, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldvt, * ) vt, integer ldvt, integer, dimension( * ) idxq, integer, dimension( * ) iwork, real, dimension( * ) work, integer info)

SLASD1 calcula la SVD de una matriz bidiagonal superior N-por-M B, donde N = NL + NR + 1 y M = N + SQRE. SLASD1 es llamada desde SLASD0.

Propósito:

!>
!> SLASD1 calcula la SVD de una matriz B bidiagonal superior N-por-M,
!> donde N = NL + NR + 1 y M = N + SQRE. SLASD1 es llamada desde SLASD0.
!>
!> Una subrutina relacionada, SLASD7, maneja el caso en el que se desean
!> los valores singulares (y los vectores singulares en forma factorizada).
!>
!> SLASD1 calcula la SVD de la siguiente manera:
!>
!>               ( D1(entrada)    0    0       0 )
!>   B = U(entrada) * (   Z1**T   a   Z2**T    b ) * VT(entrada)
!>               (   0       0   D2(entrada)   0 )
!>
!>     = U(salida) * ( D(salida) 0) * VT(salida)
!>
!> donde Z**T = (Z1**T a Z2**T b) = u**T VT**T, y u es un vector de dimensión M
!> con ALPHA y BETA en las entradas NL+1 y NL+2 y ceros
!> en otros lugares; y la entrada b está vacía si SQRE = 0.
!>
!> Los vectores singulares izquierdos de la matriz original se almacenan en U, y
!> la transpuesta de los vectores singulares derechos se almacenan en VT, y
!> los valores singulares están en D. El algoritmo consta de tres etapas:
!>
!>    La primera etapa consiste en desinflar el tamaño del problema
!>    cuando hay múltiples valores singulares o cuando hay ceros en
!>    el vector Z. Por cada ocurrencia de este tipo, la dimensión del
!>    problema de la ecuación secular se reduce en uno. Esta etapa
!>    se realiza mediante la rutina SLASD2.
!>
!>    La segunda etapa consiste en calcular los valores singulares
!>    actualizados. Esto se hace encontrando las raíces cuadradas de las
!>    raíces de la ecuación secular a través de la rutina SLASD4 (llamada
!>    por SLASD3). Esta rutina también calcula los vectores singulares
!>    del problema actual.
!>
!>    La etapa final consiste en calcular directamente los vectores singulares
!>    actualizados utilizando los valores singulares actualizados. Los vectores
!>    singulares del problema actual se multiplican con los vectores singulares
!>    del problema general.
!>

Parámetros

NL 
!>          NL es INTEGER
!>         La dimensión de fila del bloque superior. NL >= 1.
!>

NR

!>          NR es INTEGER
!>         La dimensión de fila del bloque inferior. NR >= 1.
!>

SQRE

!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada NR-por-NR.
!>         = 1: el bloque inferior es una matriz rectangular NR-por-(NR+1).
!>
!>         La matriz bidiagonal tiene dimensión de fila N = NL + NR + 1,
!>         y dimensión de columna M = N + SQRE.
!>

D

!>          D es array REAL, dimensión (NL+NR+1).
!>         N = NL+NR+1
!>         En la entrada D(1:NL,1:NL) contiene los valores singulares del
!>         bloque superior; y D(NL+2:N) contiene los valores singulares de
!>         el bloque inferior. En la salida D(1:N) contiene los valores singulares
!>         de la matriz modificada.
!>

ALPHA

!>          ALPHA es REAL
!>         Contiene el elemento diagonal asociado con la fila añadida.
!>

BETA

!>          BETA es REAL
!>         Contiene el elemento fuera de la diagonal asociado con la fila añadida.
!>

U

!>          U es array REAL, dimensión (LDU,N)
!>         En la entrada U(1:NL, 1:NL) contiene los vectores singulares izquierdos del
!>         bloque superior; U(NL+2:N, NL+2:N) contiene los vectores singulares
!>         izquierdos del bloque inferior. En la salida U contiene los vectores
!>         singulares izquierdos de la matriz bidiagonal.
!>

LDU

!>          LDU es INTEGER
!>         La dimensión principal del array U. LDU >= max( 1, N ).
!>

VT

!>          VT es array REAL, dimensión (LDVT,M)
!>         donde M = N + SQRE.
!>         En la entrada VT(1:NL+1, 1:NL+1)**T contiene los vectores singulares
!>         derechos del bloque superior; VT(NL+2:M, NL+2:M)**T contiene
!>         los vectores singulares derechos del bloque inferior. En la salida
!>         VT**T contiene los vectores singulares derechos de la
!>         matriz bidiagonal.
!>

LDVT

!>          LDVT es INTEGER
!>         La dimensión principal del array VT. LDVT >= max( 1, M ).
!>

IDXQ

!>          IDXQ es array INTEGER, dimensión (N)
!>         Contiene la permutación que reintegrará el subproblema recién resuelto
!>         de nuevo en orden ascendente, es decir, D( IDXQ( I = 1, N ) ) estará
!>         en orden ascendente.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (4*N)
!>

WORK

!>          WORK es array REAL, dimensión (3*M**2+2*M)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa.
!>          < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          > 0: si INFO = 1, un valor singular no convergió.
!>
