NOMBRE

slapd-dnssrv - backend de referencias DNS SRV para slapd

SINOPSIS

/etc/openldap/slapd.conf

DESCRIPCIÓN

El backend DNSSRV de slapd(8) sirve referencias basadas en registros de recursos SRV almacenados en el Sistema de Nombres de Dominio.

Este backend es experimental.

CONFIGURACIÓN

El backend DNSSRV no tiene opciones específicas del backend ni de la base de datos. Se configura simplemente con "database dnssrv" seguido de una directiva suffix, por ejemplo, suffix "".

CONTROL DE ACCESO

El backend dnssrv no respeta todas las semánticas de ACL tal como se describen en slapd.access(5). De hecho, este backend solo implementa la operación de búsqueda cuando se utiliza el control manageDSAit (RFC 3296); de lo contrario, para cada operación se devuelve una referencia, siempre que sea apropiado, o un error. Actualmente, no hay forma de condicionar la devolución de la referencia mediante ACLs; no se implementa ningún control de acceso, excepto el acceso de lectura (=r) a las entradas devueltas, que en realidad es proporcionado por el frontend. Tenga en cuenta, sin embargo, que la información devuelta por este backend se recopila a través de DNS, por lo que es pública por definición.

ARCHIVOS

/etc/openldap/slapd.conf
archivo de configuración predeterminado de slapd
