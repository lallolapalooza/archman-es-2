SLAPO-MEMBEROF(5) Manual de formatos de archivo SLAPO-MEMBEROF(5)

NOMBRE

slapo-memberof - Overlay de membresía de grupo inversa para slapd

SINOPSIS

/etc/openldap/slapd.conf

DESCRIPCIÓN

El overlay memberof para slapd(8) permite el mantenimiento automático de membresía de grupo inversa. Cada vez que se modifica una entrada de grupo, sus miembros se modifican según corresponda para mantener actualizado un atributo DN-valorado de "es miembro de" con el DN del grupo.

Tenga en cuenta que el overlay dynlist también puede proporcionar esta funcionalidad y puede ser adecuado para entornos menos exigentes.

CONFIGURACIÓN

Las directivas de configuración que son específicas del overlay memberof deben ir precedidas de memberof-, para evitar posibles conflictos con directivas específicas de la base de datos subyacente o de otros overlays apilados.

overlay memberof
Esta directiva añade el overlay memberof a la base de datos actual; consulte slapd.conf(5) para más detalles.

Las siguientes opciones de configuración de slapd.conf están definidas para el overlay memberof.

memberof-group-oc <group-oc>
El valor <group-oc> es el nombre de la objectClass que desencadena la actualización de membresía de grupo inversa. Por defecto es groupOfNames.
memberof-member-ad <member-ad>
El valor <member-ad> es el nombre del atributo que contiene los nombres de los miembros en los objetos de grupo; debe ser DN-valorado. Por defecto es member.
memberof-memberof-ad <memberof-ad>
El valor <memberof-ad> es el nombre del atributo que contiene los nombres de los grupos de los que una entrada es miembro; debe ser DN-valorado. Sus contenidos son actualizados automáticamente por el overlay. Por defecto es memberOf.
memberof-dn <dn>
El valor <dn> contiene el DN que se utiliza como modifiersName para las modificaciones internas realizadas para actualizar la membresía de grupo inversa. Por defecto es el rootdn de la base de datos subyacente.
memberof-dangling {ignore, drop, error}
Esta opción determina el comportamiento del overlay cuando, durante una modificación, encuentra referencias colgantes. Por defecto es ignore, lo que puede dejar referencias colgantes. Otras opciones son drop, que descarta aquellas modificaciones que resultarían en referencias colgantes, y error, que hace que fallen las modificaciones que resultarían en referencias colgantes.
memberof-dangling-error <error-code>
Si memberof-dangling se establece en error, este parámetro de configuración puede utilizarse para modificar el código de respuesta devuelto en caso de violación. Por defecto es "constraint violation", pero se sabe que otras implementaciones devuelven "no such object" en su lugar.
memberof-refint {true|FALSE}
Esta opción determina si el overlay intentará preservar la integridad referencial o no. Si se establece en TRUE, cuando se modifica una entrada que contiene valores del atributo "es miembro de", los grupos correspondientes también se modifican.
memberof-addcheck {true|FALSE}
Esta opción determina si el overlay comprobará las nuevas entradas añadidas en busca de membresía en grupos existentes. Esta comprobación es útil si se crean grupos poblados en el directorio antes que las entradas a las que hacen referencia. La situación ocurre a menudo durante la replicación, que puede replicar entradas en orden aleatorio. Si se establece en TRUE, cada operación Add buscará grupos que hagan referencia a la entrada añadida y poblará su atributo memberof con los DN de los grupos. Tenga en cuenta que memberof-dangling debe dejarse en su configuración predeterminada de ignore para que esta opción funcione.

El overlay memberof puede usarse con cualquier backend que proporcione funcionalidad completa de lectura-escritura, pero está diseñado principalmente para su uso con backends de almacenamiento local. Las operaciones de mantenimiento que realiza son internas al servidor en el que está configurado el overlay y nunca se replican. Los servidores consumidores deben configurarse con sus propias instancias del overlay memberOf si se desea mantener estos atributos memberOf en los consumidores. Los consumidores también deben configurarse para excluir el atributo memberof de la replicación. (Consulte la opción exattrs en la configuración del consumidor.)

ARCHIVOS

/etc/openldap/slapd.conf
archivo de configuración predeterminado de slapd

COMPATIBILIDAD ANTERIOR

El overlay memberof ha sido rehecho con la versión 2.5 para utilizar un espacio de nombres coherente como con otros overlays. Como efecto secundario, los siguientes parámetros de cn=config están obsoletos y se eliminarán en una futura versión: olcMemberOf se reemplaza por olcMemberOfConfig

VER TAMBIÉN

slapo-dynlist(5), slapd.conf(5), slapd-config(5), slapd(8). El overlay slapo-memberof(5) soporta la configuración dinámica a través de back-config.
