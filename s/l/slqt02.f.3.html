subrutina slqt02 (integer m, integer n, integer k, real, dimension( lda, * ) a, real, dimension( lda, * ) af, real, dimension( lda, * ) q, real, dimension( lda, * ) l, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

SLQT02

Propósito:

!>
!> SLQT02 prueba SORGLQ, que genera una matriz m-por-n Q con
!> filas ortonormales que se define como el producto de k
!> reflectores elementales.
!>
!> Dada la factorización LQ de una matriz m-por-n A, SLQT02 genera
!> la matriz ortogonal Q definida por la factorización de las primeras k
!> filas de A; compara L(1:k,1:m) con A(1:k,1:n)*Q(1:m,1:n)', y
!> comprueba que las filas de Q sean ortonormales.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz Q a generar.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz Q a generar.
!>          N >= M >= 0.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. M >= K >= 0.
!>

A

!>          A es matriz REAL, dimension (LDA,N)
!>          La matriz m-por-n A que fue factorizada por SLQT01.
!>

AF

!>          AF es matriz REAL, dimension (LDA,N)
!>          Detalles de la factorización LQ de A, según lo devuelto por SGELQF.
!>          Consulte SGELQF para más detalles.
!>

Q

!>          Q es matriz REAL, dimension (LDA,N)
!>

L

!>          L es matriz REAL, dimension (LDA,M)
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de las matrices A, AF, Q y L. LDA >= N.
!>

TAU

!>          TAU es matriz REAL, dimension (M)
!>          Los factores escalares de los reflectores elementales correspondientes
!>          a la factorización LQ en AF.
!>

WORK

!>          WORK es matriz REAL, dimension (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión de la matriz WORK.
!>

RWORK

!>          RWORK es matriz REAL, dimension (M)
!>

RESULT

!>          RESULT es matriz REAL, dimension (2)
!>          Las relaciones de prueba:
!>          RESULT(1) = norm( L - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
