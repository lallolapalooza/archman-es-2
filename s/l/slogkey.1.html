NOMBRE

slogkey --- Gestiona las claves criptográficas para su uso en el entorno de registro seguro de {{ site.product.short_name }}.

SINOPSIS

slogkey [opciones] [argumentos]

DESCRIPCIÓN

La utilidad slogkey se utiliza para gestionar claves criptográficas para su uso con el módulo de registro seguro de syslog-ng OSE. Utilice esta utilidad para crear una clave maestra, derivar una clave de host que será utilizada por una configuración de registro seguro y para mostrar el contador de secuencia actual de una clave. Las opciones determinan el modo de operación y son mutuamente excluyentes.

ARGUMENTOS

Los argumentos dependen del modo de operación.

•
Generación de clave maestra

Secuencia de llamada: slogkey --master-key <nombre_archivo>

<nombre_archivo>: El nombre del archivo al que se escribe la clave maestra.

•
Derivación de clave de host

Secuencia de llamada: slogkey --derive-key <archivo_clave_maestra> <dirección_MAC_host> <número_serie_host> <archivo_clave_host>

  • <archivo_clave_maestra>: La clave maestra de la cual se deriva la clave de host.
  • <dirección_MAC_host>: La dirección MAC del host en el que se utilizará la clave. En lugar de la dirección MAC, se puede proporcionar cualquier otra cadena que identifique de forma única un host, por ejemplo, el número de inventario de la empresa.
  • <número_serie_host>: El número de serie del host en el que se utilizará la clave. En lugar del número de serie, se puede proporcionar cualquier otra cadena que identifique de forma única un host, por ejemplo, el número de inventario de la empresa.
  • <archivo_clave_host>: El nombre del archivo al que se escribe la clave de host.
NOTA: La clave de host recién creada tiene su contador establecido en 0, lo que indica que representa la clave de host inicial k0). Esta clave de host debe mantenerse en secreto y no ser divulgada a terceros. Es necesaria para descifrar y verificar con éxito los archivos de registro procesados por el entorno de registro seguro. Dado que cada entrada de registro se cifra con su propia clave, se crea una nueva clave de host después del procesamiento exitoso de una entrada de registro y reemplaza la clave anterior. Por lo tanto, la clave de host inicial debe almacenarse en un lugar seguro antes de iniciar el entorno de registro seguro, ya que se elimina del host de registro después del procesamiento de la primera entrada de registro.
•
Visualización del contador de secuencia

OPCIONES

•
--master-key o -m

Genera una nueva clave maestra. <nombre_archivo> es el nombre del archivo que almacena la clave maestra recién generada.

•
--derive-key o -d

Deriva una clave de host utilizando una clave maestra generada previamente.

•
--counter o -c

Muestra el contador de secuencia de registro actual de una clave.

•
--help o -h

Muestra un mensaje de ayuda.
