SLASWP realiza una serie de intercambios de filas en una matriz rectangular general.

Documentación de función/subrutina

subrutina slaswp (integer n, real, dimension( lda, * ) a, integer lda, integer k1, integer k2, integer, dimension( * ) ipiv, integer incx)

SLASWP realiza una serie de intercambios de filas en una matriz rectangular general.

Propósito:

!>
!> SLASWP realiza una serie de intercambios de filas en la matriz A.
!> Se inicia un intercambio de filas por cada una de las filas K1 a K2 de A.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de columnas de la matriz A.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, la matriz de dimensión de columna N a la que se
!>          aplicarán los intercambios de filas.
!>          En la salida, la matriz permutada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>

K1

!>          K1 es INTEGER
!>          El primer elemento de IPIV para el cual se realizará un
!>          intercambio de filas.
!>

K2

!>          K2 es INTEGER
!>          (K2-K1+1) es el número de elementos de IPIV para los cuales se
!>          realizará un intercambio de filas.
!>

IPIV

!>          IPIV es array INTEGER, dimension (K1+(K2-K1)*abs(INCX))
!>          El vector de índices de pivote. Solo se accede a los elementos
!>          en las posiciones K1 a K1+(K2-K1)*abs(INCX) de IPIV.
!>          IPIV(K1+(K-K1)*abs(INCX)) = L implica que las filas K y L se
!>          intercambiarán.
!>

INCX

!>          INCX es INTEGER
!>          El incremento entre valores sucesivos de IPIV. Si INCX
!>          es negativo, los pivotes se aplican en orden inverso.
!>
