NOMBRE

slim - Simple LogIn Manager

SINOPSIS

slim [opciones] [<argumentos>]

DESCRIPCIÓN

SLiM es un gestor de inicio de sesión ligero para X11, que permite la inicialización de una sesión gráfica mediante la introducción de nombre de usuario y contraseña en una pantalla de inicio de sesión. Es independiente del entorno de escritorio y debería funcionar (con la configuración adecuada) con cualquier estilo de sesión.

OPCIONES

-c /ruta/al/archivo/de/configuracion
selecciona un archivo de configuración no estándar en lugar de /etc/slim.conf
-d
ejecutar como demonio
-n
NO ejecutar como demonio
-s
ser compatible con systemd deshabilitando el soporte de consolekit. Esta opción no hace nada si el soporte de consolekit no ha sido compilado.
-p /ruta/al/tema
mostrar una vista previa del tema. Se requiere una sesión X11 ya en ejecución para la vista previa del tema.
-w <ancho>x<alto>
establecer el tamaño de la ventana utilizada para la vista previa del tema. Esta opción solo es válida después de una opción -p
-h
mostrar un breve mensaje de ayuda
-v
mostrar información de la versión

EJEMPLOS

slim -d
ejecutar slim en modo demonio
slim -p /usr/share/slim/themes/default -w 800x600
vista previa del tema predeterminado a baja resolución

INICIAR SLIM AL ARRANCAR

Por favor, consulta la documentación de tu Sistema Operativo para que slim se inicie automáticamente después de que el sistema arranque. En particular, el método es muy diferente entre los procesos de inicio SysV, OpenRC, runit y systemd.

CONFIGURACIÓN

La configuración global se almacena en el archivo /etc/slim.conf. Consulta los comentarios dentro del archivo para una explicación detallada de las opciones.

USO Y NOMBRES DE USUARIO ESPECIALES

Al iniciarse, slim mostrará un panel de inicio de sesión; introduce el nombre de usuario y la contraseña del usuario con el que deseas iniciar sesión.

Nombres de usuario especiales:

console
abrir una consola de inicio de sesión xterm. No se necesita contraseña
exit
salir de slim. No se necesita contraseña. Consulta la nota en ERRORES.
halt
apagar la máquina
reboot
reiniciar la máquina
suspend
suspender la máquina

Consulta el archivo de configuración para personalizar los comandos anteriores. Los comandos 'halt' y 'reboot' requieren la contraseña de root, y por lo tanto, pueden no funcionar en sistemas donde el inicio de sesión de root está deshabilitado.

Atajos:

F11
ejecuta un comando personalizado (por defecto toma una captura de pantalla)
F1
elige el tipo de sesión de la lista de sesiones.

ERRORES

Cuando se ejecuta como demonio desde OpenRC (y posiblemente otros sistemas de inicio), hacer que SLiM se cierre a veces puede resultar en una pantalla en blanco y un ordenador que no responde. Esto incluye el uso del nombre de usuario especial "exit".

Probablemente todavía haya algunos más, pero estoy trabajando en ellos.
