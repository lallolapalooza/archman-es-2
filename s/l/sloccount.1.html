NOMBRE

sloccount - contar líneas de código fuente (SLOC)

SINOPSIS

sloccount [--version] [--cached] [--append] [ --datadir directorio ] [--follow] [--duplicates] [--crossdups] [--autogen] [--multiproject] [--filecount] [--wide] [--details] [ --effort F E ] [ --schedule F E ] [ --personcost costo ] [ --overhead sobrecosto ] [ --addlang idioma ] [ --addlangall ] [--] directorios

DESCRIPCIÓN

sloccount cuenta las líneas físicas de código fuente (SLOC) contenidas en los descendientes de los conjuntos de directorios especificados. Determina automáticamente qué archivos son archivos de código fuente y qué idioma de programación se utiliza en cada archivo. Por defecto, resume los resultados de SLOC y presenta varias estimaciones (como esfuerzo y costo de desarrollo), pero su salida puede controlarse mediante varias opciones.

Si le proporciona a sloccount una lista de dos o más directorios, los recuentos se desglosarán según esa lista. Existe una limitación importante: los nombres base de los directorios dados como parámetros deben ser diferentes, ya que esos nombres se utilizan para agrupar información resumida. Por lo tanto, no puede ejecutar "sloccount /usr/src/hello /usr/local/src/hello". Esta limitación solo se aplica a los parámetros de sloccount; los subdirectorios descendientes de los directorios principales pueden tener el mismo nombre base.

Si le proporciona a sloccount un solo directorio, sloccount intenta encontrar automáticamente un desglose razonable para fines de informe (por lo que producirá un informe útil). En este caso, si el directorio tiene al menos dos subdirectorios, esos subdirectorios se utilizarán como desglose. Si el directorio único contiene archivos además de directorios (o si proporciona algunos archivos como parámetros a sloccount), esos archivos se asignarán al directorio "top_dir" para que pueda distinguirlos del resto del contenido. Finalmente, si hay un subdirectorio llamado "src", ese subdirectorio se desglosa nuevamente, con todos los subdirectorios posteriores precedidos por "src_". Por lo tanto, si el directorio "X" tiene un subdirectorio "src", que contiene el subdirectorio "modules", sloccount informará un recuento separado para "src_modules".

sloccount normalmente considera a todos los descendientes de estos directorios, aunque a menos que se indique lo contrario, ignora los enlaces simbólicos.

sloccount es el front-end habitual del paquete de herramientas llamado "SLOCCount". Tenga en cuenta que el nombre de todo el paquete tiene letras mayúsculas, mientras que el nombre de este programa front-end no las tiene.

sloccount normalmente informará estimaciones de tiempo de programación, esfuerzo y costo, y para proyectos individuales también estima el número promedio de desarrolladores activos. Estas son meras estimaciones, no están grabadas en piedra; puede modificar los parámetros utilizados para mejorar las estimaciones.

OPCIONES

--version
Informa el número de versión de SLOCCount y sale inmediatamente. Esta opción no se puede combinar de manera útil con ninguna otra opción.
--cached
No recalcular; en su lugar, utiliza resultados en caché de una ejecución anterior. Sin la opción --cached o --append, sloccount elimina automáticamente el directorio de datos y lo recrea.
--append
No elimine los cálculos anteriores del directorio de datos; en su lugar, agregue el análisis al contenido actual del directorio de datos.
--datadir directorio
Almacene o utilice datos en caché en el directorio de datos proporcionado; el valor predeterminado es "~/.slocdata".
--follow
Sigue enlaces simbólicos.
--duplicates
Cuenta todos los duplicados. Normalmente, si los archivos tienen contenido igual (según se determina mediante valores hash MD5), solo se cuenta uno.
--crossdups
Cuenta duplicados si ocurren en diferentes partes del desglose. Por lo tanto, si el directorio principal contiene muchos proyectos diferentes y desea que los duplicados en diferentes proyectos se cuenten en cada proyecto, elija esta opción.
--autogen
Cuenta archivos de código fuente que parecen ser generados automáticamente. Normalmente se excluyen.
--multiproject
Los diferentes directorios representan proyectos diferentes; de lo contrario, se asume que todo el código fuente pertenece a un solo proyecto. Esto no cambia el número total de archivos o los valores SLOC, pero sí afecta las estimaciones de esfuerzo y programación. Dada esta opción, el esfuerzo se calcula por separado para cada proyecto (y luego se suma), y la programación es la programación estimada del proyecto más grande.
--filecount
Muestra recuentos de archivos en lugar de SLOC.
--wide
Muestra en formato "ancho" (separado por tabulaciones).
--details
Muestra detalles, es decir, resultados para cada archivo de código fuente.
--effort F E
Cambia el factor y el exponente para el modelo de esfuerzo. El esfuerzo (en meses-persona) se calcula como F*(SLOC/1000)^E.
--schedule F E
Cambia el factor y el exponente para el modelo de programación. La programación (en meses) se calcula como F*(esfuerzo)^E.
--personcost costo
Cambia el salario anual promedio a costo.
--overhead sobrecosto
Cambia el valor de sobrecosto a sobrecosto. El costo estimado se calcula como esfuerzo * personcosto * sobrecosto.
--addlang idioma
Agrega un idioma que no se considera por defecto un ``idioma'' a ser reportado. Actualmente, los únicos valores legales para idioma son "makefile", "sql" y "html". Estos archivos normalmente no se incluyen en los recuentos de SLOC, aunque sus SLOCs se calculan internamente y se muestran en los recuentos de archivos. Si desea incluir más de un idioma de este tipo, hágalo pasando --addlang varias veces, por ejemplo, --addlang makefile --addlang sql.
--addlangall
Agrega todos los idiomas que normalmente no se incluyen en los informes finales.

NOTAS

Al igual que con muchos otros programas que utilizan opciones tipo Unix, los directorios cuyos nombres comienzan con un guion (``-'') pueden ser malinterpretados como opciones. Si los directorios a analizar podrían comenzar con un guion, use el doble guion (``- -'') para indicar el final de la lista de opciones antes de enumerar los directorios.

ERRORES

Los nombres de archivo con saltos de línea incrustados (en los directorios o sus descendientes) no se manejarán correctamente; se interpretarán como nombres de archivo separados donde se insertan los saltos de línea. Un atacante podría impedir que sloccount funcione creando nombres de archivo del tipo /normal/directorio ... NUEVALINEA/dev/zero. Dichos nombres de archivo son extremadamente raros en el código fuente, ya que también son difíciles de manejar con otras herramientas. Las versiones futuras de sloccount pueden usar internamente nombres de archivo separados por NUL (como el comando -print0 de GNU find) para solucionar esto.

Hay muchos más idiomas que SLOCCount aún no maneja.

SLOCCount solo informa líneas físicas de código fuente. Sería muy útil si también pudiera informar líneas lógicas de código, y quizás otras métricas comunes como las medidas de complejidad de McCabe y la densidad de complejidad (complejidad/SLOC para cada función o procedimiento).

sloccount(1)

NAME

sloccount

Count source lines of code

SYNOPSIS

sloccount

[options] [file/directory ...]

DESCRIPTION

SLOCCount (Source Line Of Code Counter) is a tool to count source lines of code. It supports many languages and is designed to be extensible.

OPTIONS

SLOCCount has a variety of options to customize its behavior. Some of the common options include:

-a, --add-source-file FILE
Add a file to be analyzed.
-b, --binary
Include binary files in the analysis.
-c, --comment-style STYLE
Specify the comment style to use. Supported styles include 'C', 'Lisp', 'Ada', 'Python', 'Shell', 'Verilog', 'VHDL', and 'none'.
-d, --debug
Enable debug output.
-e, --exclude PATTERN
Exclude files or directories matching the given pattern.
-f, --force
Force analysis of files even if they are not recognized by their extension.
-h, --help
Display a help message and exit.
-i, --include PATTERN
Include only files matching the given pattern.
-l, --list-languages
List all supported languages and exit.
-o, --output FILE
Write the output to the specified file.
-p, --project-name NAME
Set the project name for the output.
-q, --quiet
Suppress all output except for errors.
-r, --recursive
Recursively scan directories.
-v, --verbose
Enable verbose output.
-V, --version
Display version information and exit.

NOTES

SLOCCount's results can be influenced by the chosen comment styles and language definitions. It's recommended to consult the official documentation for detailed information on language support and configuration.

See the SLOCCount website at http://www.dwheeler.com/sloccount. Note that more detailed documentation is available both on the website and with the SLOCCount package.
