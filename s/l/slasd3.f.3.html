SLASD3 encuentra todas las raíces cuadradas de las raíces de la ecuación secular, tal como se definen por los valores en D y Z, y luego actualiza los vectores singulares mediante multiplicación matricial. Usado por sbdsdc.

subroutine slasd3 (integer nl, integer nr, integer sqre, integer k, real, dimension( * ) d, real, dimension( ldq, * ) q, integer ldq, real, dimension( * ) dsigma, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldu2, * ) u2, integer ldu2, real, dimension( ldvt, * ) vt, integer ldvt, real, dimension( ldvt2, * ) vt2, integer ldvt2, integer, dimension( * ) idxc, integer, dimension( * ) ctot, real, dimension( * ) z, integer info)

SLASD3 encuentra todas las raíces cuadradas de las raíces de la ecuación secular, tal como se definen por los valores en D y Z, y luego actualiza los vectores singulares mediante multiplicación matricial. Usado por sbdsdc.

Propósito:

!>
!> SLASD3 encuentra todas las raíces cuadradas de las raíces de la ecuación
!> secular, tal como se definen por los valores en D y Z. Realiza las
!> llamadas apropiadas a SLASD4 y luego actualiza los vectores singulares
!> mediante multiplicación matricial.
!>
!> SLASD3 es llamada desde SLASD1.
!>

Parámetros

NL 
!>          NL es INTEGER
!>         La dimensión de fila del bloque superior. NL >= 1.
!>

NR

!>          NR es INTEGER
!>         La dimensión de fila del bloque inferior. NR >= 1.
!>

SQRE

!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada de NR x NR.
!>         = 1: el bloque inferior es una matriz rectangular de NR x (NR+1).
!>
!>         La matriz bidiagonal tiene N = NL + NR + 1 filas y
!>         M = N + SQRE >= N columnas.
!>

K

!>          K es INTEGER
!>         El tamaño de la ecuación secular, 1 <= K <= N.
!>

D

!>          D es array REAL, dimension(K)
!>         A la salida, las raíces cuadradas de las raíces de la ecuación
!>         secular, en orden ascendente.
!>

Q

!>          Q es array REAL, dimension (LDQ,K)
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q. LDQ >= K.
!>

DSIGMA

!>          DSIGMA es array REAL, dimension(K)
!>         Los primeros K elementos de este array contienen las raíces antiguas
!>         del problema de actualización desdeflado. Estos son los polos
!>         de la ecuación secular.
!>

U

!>          U es array REAL, dimension (LDU, N)
!>         Las últimas N - K columnas de esta matriz contienen los vectores
!>         singulares izquierdos desdeflados.
!>

LDU

!>          LDU es INTEGER
!>         La dimensión principal del array U. LDU >= N.
!>

U2

!>          U2 es array REAL, dimension (LDU2, N)
!>         Las primeras K columnas de esta matriz contienen los vectores
!>         singulares izquierdos no desdeflados para el problema dividido.
!>

LDU2

!>          LDU2 es INTEGER
!>         La dimensión principal del array U2. LDU2 >= N.
!>

VT

!>          VT es array REAL, dimension (LDVT, M)
!>         Las últimas M - K columnas de VT**T contienen los vectores
!>         singulares derechos desdeflados.
!>

LDVT

!>          LDVT es INTEGER
!>         La dimensión principal del array VT. LDVT >= N.
!>

VT2

!>          VT2 es array REAL, dimension (LDVT2, N)
!>         Las primeras K columnas de VT2**T contienen los vectores
!>         singulares derechos no desdeflados para el problema dividido.
!>

LDVT2

!>          LDVT2 es INTEGER
!>         La dimensión principal del array VT2. LDVT2 >= N.
!>

IDXC

!>          IDXC es array INTEGER, dimension (N)
!>         La permutación utilizada para organizar las columnas de U (y filas de
!>         VT) en tres grupos: el primer grupo contiene entradas no nulas
!>         solo en o por encima (o antes) de NL +1; el segundo
!>         contiene entradas no nulas solo en o por debajo (o después) de NL+2;
!>         y el tercero es denso. La primera columna de U y la fila de
!>         VT se tratan por separado, sin embargo.
!>
!>         Las filas de los vectores singulares encontrados por SLASD4
!>         deben ser permutadas de manera similar antes de que puedan tener
!>         lugar las multiplicaciones matriciales.
!>

CTOT

!>          CTOT es array INTEGER, dimension (4)
!>         Un recuento del número total de varios tipos de columnas
!>         en U (o filas en VT), como se describe en IDXC. El cuarto tipo de
!>         columna son aquellas columnas que han sido desdefladas.
!>

Z

!>          Z es array REAL, dimension (K)
!>         Los primeros K elementos de este array contienen los componentes
!>         del vector de fila de actualización ajustado por desdeflación.
!>

INFO

!>          INFO es INTEGER
!>         = 0:  salida exitosa.
!>         < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>         > 0:  si INFO = 1, un valor singular no convergió
!>
