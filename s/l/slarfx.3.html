subrutina slarfx (side, m, n, v, tau, c, ldc, work)
SLARFX aplica un reflector elemental a una matriz rectangular general, con desenrollado de bucles cuando el reflector tiene orden ≤ 10.

Documentación de Función/Subrutina

subrutina slarfx (character side, integer m, integer n, real, dimension( * ) v, real tau, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work)

SLARFX aplica un reflector elemental real H a una matriz real C de m por n, por la izquierda o por la derecha. H se representa en la forma



H = I - tau * v * v**T

donde tau es un escalar real y v es un vector real.

Si tau = 0, entonces H se toma como la matriz identidad.

Esta versión utiliza código en línea si H tiene orden < 11.

Propósito:

!>
!> SLARFX aplica un reflector elemental real H a una matriz real C
!> de m por n, por la izquierda o por la derecha. H se representa en la
!> forma
!>
!>       H = I - tau * v * v**T
!>
!> donde tau es un escalar real y v es un vector real.
!>
!> Si tau = 0, entonces H se toma como la matriz unidad
!>
!> Esta versión utiliza código en línea si H tiene orden < 11.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': forma  H * C
!>          = 'R': forma  C * H
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

V

!>          V es array REAL, dimensión (M) si SIDE = 'L'
!>                                     o (N) si SIDE = 'R'
!>          El vector v en la representación de H.
!>

TAU

!>          TAU es REAL
!>          El valor tau en la representación de H.
!>

C

!>          C es array REAL, dimensión (LDC,N)
!>          En la entrada, la matriz C de m por n.
!>          En la salida, C se sobrescribe con la matriz H * C si SIDE = 'L',
!>          o C * H si SIDE = 'R'.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= (1,M).
!>

WORK

!>          WORK es array REAL, dimensión
!>                      (N) si SIDE = 'L'
!>                      o (M) si SIDE = 'R'
!>          WORK no se referencia si H tiene orden < 11.
!>
