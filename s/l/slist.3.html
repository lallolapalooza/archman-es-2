SLIST(3) Manual de funciones de biblioteca SLIST(3)

NOMBRE

SLIST_EMPTY, SLIST_ENTRY, SLIST_FIRST, SLIST_FOREACH, SLIST_HEAD, SLIST_HEAD_INITIALIZER, SLIST_INIT, SLIST_INSERT_AFTER, SLIST_INSERT_HEAD, SLIST_NEXT, SLIST_REMOVE, SLIST_REMOVE_HEAD - implementación de una lista simplemente enlazada

BIBLIOTECA

Biblioteca estándar de C (libc, -lc)

SINOPSIS

#include <sys/queue.h>
SLIST_ENTRY(TIPO);
SLIST_HEAD(NOMBRE_CABEZA, TIPO);
SLIST_HEAD NOMBRE_CABEZA SLIST_HEAD_INITIALIZER(SLIST_HEAD cabeza);
void SLIST_INIT(SLIST_HEAD *cabeza);
int SLIST_EMPTY(SLIST_HEAD *cabeza);
void SLIST_INSERT_HEAD(SLIST_HEAD *cabeza,
                        struct TIPO *elem, SLIST_ENTRY NOMBRE);
void SLIST_INSERT_AFTER(struct TIPO *listelm,
                        struct TIPO *elem, SLIST_ENTRY NOMBRE);
struct TIPO *SLIST_FIRST(SLIST_HEAD *cabeza);
struct TIPO *SLIST_NEXT(struct TIPO *elem, SLIST_ENTRY NOMBRE);
SLIST_FOREACH(struct TIPO *var, SLIST_HEAD *cabeza, SLIST_ENTRY NOMBRE);
void SLIST_REMOVE(SLIST_HEAD *cabeza, struct TIPO *elem, TIPO,
                        SLIST_ENTRY NOMBRE);
void SLIST_REMOVE_HEAD(SLIST_HEAD *cabeza,
                        SLIST_ENTRY NOMBRE);

DESCRIPCIÓN

Estas macros definen y operan sobre listas simplemente enlazadas.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo SLIST_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABEZA es el nombre de una estructura definida por el usuario que debe declararse utilizando la macro SLIST_HEAD().

Creación

Una lista simplemente enlazada está encabezada por una estructura definida por la macro SLIST_HEAD(). Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados simplemente para una sobrecarga mínima de espacio y manipulación de punteros a expensas de una eliminación O(n) para elementos arbitrarios. Se pueden agregar nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:


SLIST_HEAD(NOMBRE_CABEZA, TIPO) cabeza;

donde struct NOMBRE_CABEZA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la lista. Un puntero a la cabeza de la lista se puede declarar posteriormente como:


struct NOMBRE_CABEZA *cabezap;

(Los nombres cabeza y cabezap son seleccionables por el usuario.)

SLIST_ENTRY() declara una estructura que conecta los elementos de la lista.

SLIST_HEAD_INITIALIZER() se evalúa como un inicializador para la lista cabeza.

SLIST_INIT() inicializa la lista referenciada por cabeza.

SLIST_EMPTY() se evalúa como verdadero si no hay elementos en la lista.

Inserción

SLIST_INSERT_HEAD() inserta el nuevo elemento elem al principio de la lista.

SLIST_INSERT_AFTER() inserta el nuevo elemento elem después del elemento listelm.

Recorrido

SLIST_FIRST() devuelve el primer elemento de la lista, o NULL si la lista está vacía.

SLIST_NEXT() devuelve el siguiente elemento de la lista.

SLIST_FOREACH() recorre la lista referenciada por cabeza en la dirección hacia adelante, asignando cada elemento en turno a var.

Eliminación

SLIST_REMOVE() elimina el elemento elem de la lista.

SLIST_REMOVE_HEAD() elimina el elemento elem del principio de la lista. Para una eficiencia óptima, los elementos que se eliminan del principio de la lista deben utilizar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE().

VALOR DE RETORNO

SLIST_EMPTY() devuelve un valor distinto de cero si la lista está vacía, y cero si la lista contiene al menos una entrada.

SLIST_FIRST() y SLIST_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

SLIST_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la lista cabeza.

ESTANDARES

BSD.

HISTORIA

4.4BSD.

ERRORES

SLIST_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. SLIST_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    SLIST_ENTRY(entry) entries;             /* Lista simplemente enlazada */
};
SLIST_HEAD(slisthead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct slisthead head;                  /* Cabeza de lista simplemente
                                               enlazada */
    SLIST_INIT(&head);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al principio */
    SLIST_INSERT_HEAD(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    SLIST_INSERT_AFTER(n1, n2, entries);
    SLIST_REMOVE(&head, n2, entry, entries);/* Eliminación */
    free(n2);
    n3 = SLIST_FIRST(&head);
    SLIST_REMOVE_HEAD(&head, entries);      /* Eliminación del principio */
    free(n3);
    for (unsigned int i = 0; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        SLIST_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }
                                            /* Recorrido hacia adelante */
    SLIST_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
    while (!SLIST_EMPTY(&head)) {           /* Eliminación de la lista */
        n1 = SLIST_FIRST(&head);
        SLIST_REMOVE_HEAD(&head, entries);
        free(n1);
    }
    SLIST_INIT(&head);
    exit(EXIT_SUCCESS);
}
