subroutine slaqr0 (logical wantt, logical wantz, integer n, integer ilo, integer ihi, real, dimension( ldh, * ) h, integer ldh, real, dimension( * ) wr, real, dimension( * ) wi, integer iloz, integer ihiz, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer info)

SLAQR0 calcula los valores propios de una matriz de Hessenberg, y opcionalmente las matrices de la descomposición de Schur.

Propósito:

!>
!>    SLAQR0 calcula los valores propios de una matriz de Hessenberg H
!>    y, opcionalmente, las matrices T y Z de la descomposición de Schur
!>    H = Z T Z**T, donde T es una matriz cuasi-triangular superior (la
!>    forma de Schur), y Z es la matriz ortogonal de vectores de Schur.
!>
!>    Opcionalmente, Z puede ser postmultiplicada en una matriz ortogonal
!>    de entrada Q para que esta subrutina pueda dar la factorización de Schur
!>    de una matriz A que ha sido reducida a la forma de Hessenberg H
!>    por la matriz ortogonal Q:  A = Q*H*Q**T = (QZ)*T*(QZ)**T.
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>          = .TRUE. : se requiere la forma de Schur completa T;
!>          = .FALSE.: solo se requieren los valores propios.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          = .TRUE. : se requiere la matriz de vectores de Schur Z;
!>          = .FALSE.: no se requieren vectores de Schur.
!>

N

!>          N es INTEGER
!>           El orden de la matriz H.  N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>           Se asume que H ya es triangular superior en las filas
!>           y columnas 1:ILO-1 y IHI+1:N y, si ILO > 1,
!>           H(ILO,ILO-1) es cero. ILO e IHI son normalmente establecidos por una
!>           llamada previa a SGEBAL, y luego pasados a SGEHRD cuando la
!>           matriz de salida de SGEBAL se reduce a la forma de Hessenberg.
!>           De lo contrario, ILO e IHI deben ser establecidos a 1 y N,
!>           respectivamente.  Si N > 0, entonces 1 <= ILO <= IHI <= N.
!>           Si N = 0, entonces ILO = 1 e IHI = 0.
!>

H

!>          H es array REAL, dimension (LDH,N)
!>           En la entrada, la matriz de Hessenberg superior H.
!>           En la salida, si INFO = 0 y WANTT es .TRUE., entonces H contiene
!>           la matriz cuasi-triangular superior T de la descomposición
!>           de Schur (la forma de Schur); los bloques diagonales de 2x2
!>           (correspondientes a pares de valores propios complejos conjugados)
!>           se devuelven en forma estándar, con H(i,i) = H(i+1,i+1)
!>           y H(i+1,i)*H(i,i+1) < 0. Si INFO = 0 y WANTT es
!>           .FALSE., entonces el contenido de H no está especificado en la salida.
!>           (El valor de salida de H cuando INFO > 0 se describe en la
!>           descripción de INFO a continuación.)
!>
!>           Esta subrutina puede establecer explícitamente H(i,j) = 0 para i > j y
!>           j = 1, 2, ... ILO-1 o j = IHI+1, IHI+2, ... N.
!>

LDH

!>          LDH es INTEGER
!>           La dimensión principal del array H. LDH >= max(1,N).
!>

WR

!>          WR es array REAL, dimension (IHI)
!>

WI

!>          WI es array REAL, dimension (IHI)
!>           Las partes real e imaginaria, respectivamente, de los valores
!>           propios calculados de H(ILO:IHI,ILO:IHI) se almacenan en WR(ILO:IHI)
!>           y WI(ILO:IHI). Si dos valores propios se calculan como un par
!>           complejo conjugado, se almacenan en elementos consecutivos
!>           de WR y WI, digamos el i-ésimo y (i+1)-ésimo, con
!>           WI(i) > 0 y WI(i+1) < 0. Si WANTT es .TRUE., entonces
!>           los valores propios se almacenan en el mismo orden que en la
!>           diagonal de la forma de Schur devuelta en H, con
!>           WR(i) = H(i,i) y, si H(i:i+1,i:i+1) es un bloque diagonal de 2x2,
!>           WI(i) = sqrt(-H(i+1,i)*H(i,i+1)) y
!>           WI(i+1) = -WI(i).
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>           Especifican las filas de Z a las que se deben aplicar las
!>           transformaciones si WANTZ es .TRUE..
!>           1 <= ILOZ <= ILO; IHI <= IHIZ <= N.
!>

Z

!>          Z es array REAL, dimension (LDZ,IHI)
!>           Si WANTZ es .FALSE., Z no se referencia.
!>           Si WANTZ es .TRUE., entonces Z(ILO:IHI,ILOZ:IHIZ) se
!>           reemplaza por Z(ILO:IHI,ILOZ:IHIZ)*U donde U es el
!>           factor de Schur ortogonal de H(ILO:IHI,ILO:IHI).
!>           (El valor de salida de Z cuando INFO > 0 se describe en
!>           la descripción de INFO a continuación.)
!>

LDZ

!>          LDZ es INTEGER
!>           La dimensión principal del array Z. Si WANTZ es .TRUE.
!>           entonces LDZ >= MAX(1,IHIZ). De lo contrario, LDZ >= 1.
!>

WORK

!>          WORK es array REAL, dimension LWORK
!>           En la salida, si LWORK = -1, WORK(1) devuelve una estimación de
!>           el valor óptimo para LWORK.
!>

LWORK

!>          LWORK es INTEGER
!>           La dimensión del array WORK. LWORK >= max(1,N)
!>           es suficiente, pero LWORK típicamente hasta 6*N puede
!>           ser necesario para un rendimiento óptimo. Se recomienda
!>           una consulta de espacio de trabajo para determinar el tamaño
!>           óptimo del espacio de trabajo.
!>
!>           Si LWORK = -1, SLAQR0 realiza una consulta de espacio de trabajo.
!>           En este caso, SLAQR0 comprueba los parámetros de entrada y
!>           estima el tamaño óptimo del espacio de trabajo para los
!>           valores dados de N, ILO y IHI. La estimación se devuelve
!>           en WORK(1). XERBLA no emite ningún mensaje de error relacionado
!>           con LWORK. Ni H ni Z son accedidos.
!>

INFO

!>          INFO es INTEGER
!>             = 0:  salida exitosa
!>             > 0:  si INFO = i, SLAQR0 no pudo calcular todos los
!>                valores propios. Los elementos 1:ilo-1 e i+1:n de WR
!>                y WI contienen los valores propios que se han
!>                calculado con éxito. (Los fallos son raros.)
!>
!>                Si INFO > 0 y WANT es .FALSE., entonces en la salida,
!>                los valores propios no convergentes restantes son los
!>                valores propios de las filas y columnas de Hessenberg
!>                de la matriz de Hessenberg superior ILO a INFO del
!>                valor final de H en la salida.
!>
!>                Si INFO > 0 y WANTT es .TRUE., entonces en la salida
!>
!>           (*)  (valor inicial de H)*U  = U*(valor final de H)
!>
!>                donde U es una matriz ortogonal. El valor final de H
!>                es de Hessenberg superior y cuasi-triangular
!>                en las filas y columnas INFO+1 a IHI.
!>
!>                Si INFO > 0 y WANTZ es .TRUE., entonces en la salida
!>
!>                  (valor final de Z(ILO:IHI,ILOZ:IHIZ)
!>                   =  (valor inicial de Z(ILO:IHI,ILOZ:IHIZ)*U
!>
!>                donde U es la matriz ortogonal en (*) (independientemente
!>                del valor de WANTT.)
!>
!>                Si INFO > 0 y WANTZ es .FALSE., entonces Z no se
!>                accede.
!>
