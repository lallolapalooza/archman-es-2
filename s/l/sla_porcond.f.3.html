función real sla_porcond (character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, integer cmode, real, dimension( * ) c, integer info, real, dimension( * ) work, integer, dimension( * ) iwork)

SLA_PORCOND estima el número de condición de Skeel para una matriz simétrica definida positiva.

Propósito:

!>
!>    SLA_PORCOND Estima el número de condición de Skeel de  op(A) * op2(C)
!>    donde op2 está determinado por CMODE de la siguiente manera:
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    El número de condición de Skeel  cond(A) = norminf( |inv(A)||A| )
!>    se calcula calculando factores de escala R tales que
!>    diag(R)*A*op2(C) sea equilibrada por filas y calculando el número
!>    de condición estándar de la norma infinito.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es una matriz REAL, dimensión (LDA,N)
!>     En la entrada, la matriz N-por-N A.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

AF

!>          AF es una matriz REAL, dimensión (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, tal como se calcula por SPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal de la matriz AF.  LDAF >= max(1,N).
!>

CMODE

!>          CMODE es INTEGER
!>     Determina op2(C) en la fórmula op(A) * op2(C) de la siguiente manera:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C es una matriz REAL, dimensión (N)
!>     El vector C en la fórmula op(A) * op2(C).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es una matriz REAL, dimensión (3*N).
!>     Espacio de trabajo.
!>

IWORK

!>          IWORK es una matriz INTEGER, dimensión (N).
!>     Espacio de trabajo.
!>
