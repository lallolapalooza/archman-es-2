SLARTV aplica un vector de rotaciones planas con cosenos reales y senos reales a los elementos de un par de vectores.

Documentación de Función/Subrutina

subroutine slartv (integer n, real, dimension( * ) x, integer incx, real, dimension( * ) y, integer incy, real, dimension( * ) c, real, dimension( * ) s, integer incc)

SLARTV aplica un vector de rotaciones planas reales a los elementos de los vectores reales x e y.

Propósito:

!>
!> SLARTV aplica un vector de rotaciones planas reales a los elementos de
!> los vectores reales x e y. Para i = 1,2,...,n
!>
!>    ( x(i) ) := (  c(i)  s(i) ) ( x(i) )
!>    ( y(i) )    ( -s(i)  c(i) ) ( y(i) )
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de rotaciones planas a aplicar.
!>

X

!>          X es un array REAL,
!>                         dimensión (1+(N-1)*INCX)
!>          El vector x.
!>

INCX

!>          INCX es ENTERO
!>          El incremento entre los elementos de X. INCX > 0.
!>

Y

!>          Y es un array REAL,
!>                         dimensión (1+(N-1)*INCY)
!>          El vector y.
!>

INCY

!>          INCY es ENTERO
!>          El incremento entre los elementos de Y. INCY > 0.
!>

C

!>          C es un array REAL, dimensión (1+(N-1)*INCC)
!>          Los cosenos de las rotaciones planas.
!>

S

!>          S es un array REAL, dimensión (1+(N-1)*INCC)
!>          Los senos de las rotaciones planas.
!>

INCC

!>          INCC es ENTERO
!>          El incremento entre los elementos de C y S. INCC > 0.
!>
