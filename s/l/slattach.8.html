SLATTACH(8) Manual de Administración del Sistema Linux SLATTACH(8)

NOMBRE

slattach - adjuntar una interfaz de red a una línea serie

SINOPSIS

slattach [-dehlLmnqv] [-c comando] [-p protocolo] [-s velocidad] [tty]

DESCRIPCIÓN

Slattach es un pequeño programa que se puede usar para poner una línea de terminal normal ("serie") en uno de varios modos de "red", permitiendo así usarla para enlaces punto a punto a otros ordenadores.

OPCIONES

tty
Ruta a un dispositivo serie como /dev/ttyS*, /dev/cua* o /dev/ptmx para generar un nuevo tty pseudo. El tty se debe abrir en modo no bloqueante, por lo que slattach debería poder ser utilizado para configurar una línea serie para SLIP, CSLIP o PPP.
[-c comando]
Ejecuta comando cuando se cuelga la línea. Esto se puede usar para ejecutar scripts o restablecer conexiones cuando un enlace se cae.
[-d]
Habilita la salida de depuración. Útil para determinar por qué una configuración dada no funciona.
[-h]
Sale cuando se pierde el portador (carrier). Esto funciona tanto en dispositivos /dev/tty como /dev/cua monitorizando directamente el estado del portador cada 15 segundos.
[-v]
Habilita la salida detallada. Útil en scripts de shell.
[-q]
Opera en modo silencioso - ningún mensaje en absoluto.
[-l]
Crea un archivo de bloqueo estilo UUCP para el dispositivo en /var/lock.
[-n]
Equivalente al comando "mesg n".
[-m]
No inicializa la línea en modo raw de 8 bits.
[-e]
Sale justo después de inicializar el dispositivo, en lugar de esperar a que la línea se cuelgue.
[-L]
Habilita la operación de 3 hilos. El terminal se pone en modo CLOCAL, se deshabilita la monitorización del portador.
[-p protocolo]
Establece un tipo de protocolo específico a usar en la línea. El valor por defecto se establece a cslip, es decir, SLIP comprimido. Otros valores posibles son slip (SLIP normal), adaptive (CSLIP/SLIP adaptativo), ppp (Protocolo Punto a Punto) y kiss (un protocolo usado para comunicarse con controladores de terminales de radio AX.25). El argumento especial tty se puede usar para devolver el dispositivo a la operación serie normal. El uso del modo 'ppp' normalmente no es útil ya que ppp requiere un demonio ppp adicional pppd activo en la línea. Para conexiones kiss se debe usar el programa kissattach.
[-s velocidad]
Establece una velocidad de línea específica, distinta de la predeterminada.

Si no se proporcionan argumentos, se utiliza la línea de terminal actual (generalmente: el dispositivo de inicio de sesión). De lo contrario, se intenta reclamar el puerto de terminal indicado, bloquearlo y abrirlo.

ARCHIVOS

/dev/cua* /var/lock/LCK.* /dev/ttyS* /dev/ptmx

ERRORES

Ninguno conocido.

VER TAMBIÉN
