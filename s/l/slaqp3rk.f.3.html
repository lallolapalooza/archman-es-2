Documentación de la función/subrutina

subrutina slaqp3rk (integer m, integer n, integer nrhs, integer ioffset, integer nb, real abstol, real reltol, integer kp1, real maxc2nrm, real, dimension( lda, * ) a, integer lda, logical done, integer kb, real maxc2nrmk, real relmaxc2nrmk, integer, dimension( * ) jpiv, real, dimension( * ) tau, real, dimension( * ) vn1, real, dimension( * ) vn2, real, dimension( * ) auxv, real, dimension( ldf, * ) f, integer ldf, integer, dimension( * ) iwork, integer info)

SLAQP3RK calcula un paso de factorización QR truncada con pivoteo de columnas de una matriz real m por n A utilizando BLAS de Nivel 3 y sobrescribe una matriz real m por nrhs B con Q**T * B.

Propósito:

!>
!> SLAQP3RK calcula un paso de factorización QR truncada con pivoteo de
!> columnas de una matriz real M-por-N A en el bloque A(IOFFSET+1:M,1:N)
!> utilizando BLAS de Nivel 3 como
!>
!>   A * P(KB) = Q(KB) * R(KB).
!>
!> La subrutina intenta factorizar NB columnas de A a partir de la fila
!> IOFFSET+1 y actualiza la matriz residual con BLAS 3 xGEMM. El número
!> de columnas efectivamente factorizadas se devuelve como menor que NB.
!>
!> El bloque A(1:IOFFSET,1:N) se pivota en consecuencia, pero no se
!> factoriza.
!>
!> La subrutina también sobrescribe la matriz de lados derechos B almacenada
!> en A(IOFFSET+1:M,1:N+1:N+NRHS) con Q(KB)**T * B.
!>
!> Casos en los que el número de columnas factorizadas KB < NB:
!>
!> (1) En algunos casos, debido a cancelaciones catastróficas, no puede
!> factorizar todas las NB columnas y necesita actualizar la matriz residual.
!> Por lo tanto, el número real de columnas factorizadas en el bloque
!> devuelto en KB es menor que NB. El valor lógico DONE se devuelve como
!> FALSE. La factorización de la matriz original completa A_orig debe
!> continuar con el siguiente bloque.
!>
!> (2) Siempre que se satisface el criterio de parada ABSTOL o RELTOL,
!> la factorización de la matriz original completa A_orig se detiene,
!> el valor lógico DONE se devuelve como TRUE. El número de columnas
!> factorizadas, que es menor que NB, se devuelve en KB.
!>
!> (3) En caso de que ambos criterios de parada ABSTOL o RELTOL no se
!> utilicen, y cuando la matriz residual es una matriz cero en algún
!> paso de factorización KB, la factorización de la matriz original
!> completa A_orig se detiene, el valor lógico DONE se devuelve como
!> TRUE. El número de columnas factorizadas, que es menor que NB, se
!> devuelve en KB.
!>
!> (4) Siempre que se detecta NaN en la matriz A o en el array TAU,
!> la factorización de la matriz original completa A_orig se detiene,
!> el valor lógico DONE se devuelve como TRUE. El número de columnas
!> factorizadas, que es menor que NB, se devuelve en KB. El parámetro
!> INFO se establece en el índice de la columna de la primera
!> ocurrencia de NaN.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de
!>          columnas de la matriz B. NRHS >= 0.
!>

IOFFSET

!>          IOFFSET es INTEGER
!>          El número de filas de la matriz A que deben pivotarse
!>          pero no factorizarse. IOFFSET >= 0.
!>
!>          IOFFSET también representa el número de columnas de la matriz
!>          original completa A_orig que se han factorizado
!>          en los pasos anteriores.
!>

NB

!>          NB es INTEGER
!>          Tamaño del bloque de factorización, es decir, el número de columnas
!>          a factorizar en la matriz A. 0 <= NB
!>
!>          Si NB = 0, entonces la subrutina sale inmediatamente.
!>             Esto significa que la factorización no se realiza,
!>             las matrices A y B y los arrays TAU, IPIV
!>             no se modifican.
!>

ABSTOL

!>          ABSTOL es REAL, no puede ser NaN.
!>
!>          La tolerancia absoluta (umbral de parada) para la
!>          norma 2 máxima de columna de la matriz residual.
!>          El algoritmo converge (detiene la factorización) cuando
!>          la norma 2 máxima de columna de la matriz residual
!>          es menor o igual que ABSTOL.
!>
!>          a) Si ABSTOL < 0.0, entonces este criterio de parada no se
!>                utiliza, la subrutina factoriza columnas dependiendo
!>                de NB y RELTOL.
!>                Esto incluye el caso ABSTOL = -Inf.
!>
!>          b) Si 0.0 <= ABSTOL entonces el valor de entrada
!>                de ABSTOL se utiliza.
!>

RELTOL

!>          RELTOL es REAL, no puede ser NaN.
!>
!>          La tolerancia (umbral de parada) para la relación de la
!>          norma 2 máxima de columna de la matriz residual con la
!>          norma 2 máxima de columna de la matriz original A_orig.
!>          El algoritmo converge (detiene la factorización) cuando esta
!>          relación es menor o igual que RELTOL.
!>
!>          a) Si RELTOL < 0.0, entonces este criterio de parada no se
!>                utiliza, la subrutina factoriza columnas dependiendo
!>                de NB y ABSTOL.
!>                Esto incluye el caso RELTOL = -Inf.
!>
!>          d) Si 0.0 <= RELTOL entonces el valor de entrada de RELTOL
!>                se utiliza.
!>

KP1

!>          KP1 es INTEGER
!>          El índice de la columna con la norma 2 máxima en
!>          la matriz original completa A_orig determinada en
!>          la subrutina principal SGEQP3RK. 1 <= KP1 <= N_orig.
!>

MAXC2NRM

!>          MAXC2NRM es REAL
!>          La norma 2 máxima de columna de la matriz original
!>          completa A_orig calculada en la subrutina principal SGEQP3RK.
!>          MAXC2NRM >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N+NRHS)
!>          En la entrada:
!>              la matriz A de M por N y la matriz B de M por NRHS, como en
!>
!>                                  N     NRHS
!>              array_A   =   M  [ mat_A, mat_B ]
!>
!>          En la salida:
!>          1. Los elementos en el bloque A(IOFFSET+1:M,1:KB) debajo
!>             de la diagonal junto con el array TAU representan
!>             la matriz ortogonal Q(KB) como un producto de
!>             reflectores elementales.
!>          2. El bloque triangular superior de la matriz A almacenado
!>             en A(IOFFSET+1:M,1:KB) es el factor triangular obtenido.
!>          3. El bloque de la matriz A almacenado en A(1:IOFFSET,1:N)
!>             ha sido pivoteado en consecuencia, pero no factorizado.
!>          4. El resto del array A, bloque A(IOFFSET+1:M,KB+1:N+NRHS).
!>             La parte izquierda A(IOFFSET+1:M,KB+1:N) de este bloque
!>             contiene el residual de la matriz A, y,
!>             si NRHS > 0, la parte derecha del bloque
!>             A(IOFFSET+1:M,N+1:N+NRHS) contiene el bloque de
!>             la matriz de lados derechos B. Ambos bloques han sido
!>             actualizados por multiplicación desde la izquierda por Q(KB)**T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

DONE

!>          DONE es LOGICAL
!>          En la salida: DONE = .TRUE. si el criterio de parada ABSTOL o RELTOL
!>          se ha cumplido, o si se detecta NaN, o si la matriz residual
!>          es una matriz cero, o si se ha alcanzado el final de la matriz A
!>          (es decir, KB = N).
!>          En la salida: DONE = .FALSE. si la factorización continua
!>          necesita ser realizada en el siguiente paso (es decir, KB < NB
!>          debido a la cancelación catastrófica).
!>

KB

!>          KB es INTEGER
!>          En la salida: El número de columnas de A que se han factorizado
!>          en este paso. 0 <= KB <= NB.
!>          Si la subrutina sale debido a un error (por ejemplo, NaN),
!>          entonces KB es el índice de la columna de la primera
!>          ocurrencia de NaN.
!>

MAXC2NRMK

!>          MAXC2NRMK es REAL
!>          En la salida: La norma 2 máxima de columna en el bloque
!>          A(IOFFSET+1:M,KB+1:N) de la matriz residual.
!>          Si KB = 0, MAXC2NRMK = MAXC2NRM.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK es REAL
!>          En la salida: La norma 2 máxima de columna en el bloque
!>          A(IOFFSET+1:M,KB+1:N) de la matriz residual, dividida por
!>          MAXC2NRM.
!>          Si KB = 0, RELMAXC2NRMK = 1.0.
!>

JPIV

!>          JPIV es INTEGER, dimension (*)
!>          En la salida: Array de permutaciones de columnas. JPIV(I)
!>          es el índice de la columna que se coloca en la columna I.
!>          Solo los elementos JPIV(IOFFSET+1:KB) son significativos.
!>

TAU

!>          TAU es REAL, dimension (*)
!>          En la salida: Los coeficientes de las transformaciones de
!>          Householder. Solo los elementos TAU(IOFFSET+1:KB) son
!>          significativos.
!>

VN1

!>          VN1 es REAL, dimension (*)
!>          En la salida: Array que almacena las normas 2 de las columnas
!>          de A. Solo los elementos VN1(1:N) son significativos.
!>

VN2

!>          VN2 es REAL, dimension (*)
!>          En la salida: Array que almacena las normas 2 de las columnas
!>          de A. Solo los elementos VN2(1:N) son significativos.
!>

AUXV

!>          AUXV es REAL, dimension (*)
!>          Vector auxiliar utilizado en el cálculo de la norma 2 de
!>          las columnas. Debe ser de tamaño al menos max(M, N).
!>

F

!>          F es REAL array, dimension (LDF, N)
!>          En la entrada: La matriz A.
!>          En la salida: La matriz A factorizada.
!>          Solo los elementos F(1:M,1:N) son significativos.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal del array F. LDF >= max(1,M).
!>

IWORK

!>          IWORK es INTEGER, dimension (*)
!>          Array de trabajo utilizado en el pivoteo de columnas.
!>          Debe ser de tamaño al menos N.
!>

INFO

!>          INFO es INTEGER
!>          En la salida: INFO = 0, operación completada.
!>          Si INFO < 0, significa que el parámetro de entrada
!>          --INFO tiene un valor inválido.
!>          Si INFO > 0, entonces INFO es el índice de la columna de la
!>          primera ocurrencia de NaN en la matriz A o en el array TAU.
!>

NAME

slaqp3rk - SLAQP3RK computes the rank-revealing QR factorization of a real matrix A, and solves a system of linear equations.

SYNOPSIS

    SUBROUTINE SLAQP3RK(
       M, N, NB, A, LDA, Q, LDQ, WORK, LWORK, IWORK,
       LWORK_INT,TAU, VN1, VN2, B, LDB, X, LDX, Y, LDY,
       Z, LDZ, C, LDC, INFO )

    INTEGER M, N, NB, LDA, LWORK, LDB, LDX, LDY, LDZ, LDC, INFO
    REAL A( LDA, * ), Q( LDQ, * ), WORK( * ), TAU( * ),
         VN1( * ), VN2( * ), B( LDB, * ), X( LDX, * ),
         Y( LDY, * ), Z( LDZ, * ), C( LDC, * )
    INTEGER LWORK_INT( * )

Function/Subroutine Documentation

SLAQP3RK computes the rank-revealing QR factorization of a real matrix A, and solves a system of linear equations.

This subroutine is an interface to the recursive implementation of the rank-revealing QR factorization.

The factorization is of the form

    A * P = Q * R

where P is a permutation matrix, Q is an orthogonal matrix, and R is upper trapezoidal.

The routine also solves the linear system

    A * X = B

for a given right-hand side matrix B.

Arguments

M

INTEGER

The number of rows of the matrix A. M >= 0.

N

INTEGER

The number of columns of the matrix A. N >= 0.

NB

INTEGER

The block size for the recursive factorization. NB >= 1.

A

REAL array, dimension (LDA, N)

On entry, the M-by-N matrix A to be factorized.

On exit, the elements of A above the leading k subdiagonals contain the factors of the upper trapezoidal matrix R.

LDA

INTEGER

The leading dimension of the array A. LDA >= max(1,M).

Q

REAL array, dimension (LDQ, min(M,N))

On exit, the M-by-k matrix Q containing the orthogonal factor. The columns of Q are the Householder vectors.

LDQ

INTEGER

The leading dimension of the array Q. LDQ >= max(1,M).

WORK

REAL array, dimension (LWORK)

Workspace array. On exit, WORK(1:LWORK_INT(2)) contains information about the block factorization.

LWORK

INTEGER

The dimension of the workspace array WORK. LWORK >= max(1, 2*N, M).

IWORK

INTEGER array, dimension (N)

Workspace array.

LWORK_INT

INTEGER array, dimension (N)

Workspace array.

TAU

REAL array, dimension (min(M,N))

On exit, the scalar factors of the elementary reflectors.

VN1

REAL array, dimension (N)

On exit, the vector with the partial column norms.

VN2

REAL array, dimension (N)

On exit, the vector with the exact column norms.

B

REAL array, dimension (LDB, NRHS)

On entry, the M-by-NRHS matrix of right-hand sides.

On exit, B is overwritten by the solution X.

LDB

INTEGER

The leading dimension of the array B. LDB >= max(1,M).

X

REAL array, dimension (LDX, NRHS)

On exit, the N-by-NRHS solution matrix X to the system A*X = B.

LDX

INTEGER

The leading dimension of the array X. LDX >= max(1,N).

Y

REAL array, dimension (LDY, NRHS)

Workspace array.

LDY

INTEGER

The leading dimension of the array Y. LDY >= max(1,N).

Z

REAL array, dimension (LDZ, NRHS)

Workspace array.

LDZ

INTEGER

The leading dimension of the array Z. LDZ >= max(1,N).

C

REAL array, dimension (LDC, NB)

Workspace array.

LDC

INTEGER

The leading dimension of the array C. LDC >= max(1,M).

INFO

INTEGER


= 0: successful exit.


> 0: If INFO = j, then the J-th column of A was determined to be zero during the factorization. The factorization has been completed but the computed rank is less than J.


< 0: If INFO = -k, the k-th argument had an illegal value.
