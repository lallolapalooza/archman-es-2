SLALSA calcula la SVD de la matriz de coeficientes en forma compacta. Usado por sgelsd.

Propósito:

!>
!> SLALSA es un paso intermedio para resolver el problema de mínimos cuadrados
!> calculando la SVD de la matriz de coeficientes en forma compacta (los
!> vectores singulares se calculan como productos de matrices ortogonales simples.).
!>
!> Si ICOMPQ = 0, SLALSA aplica la inversa de la matriz de vectores singulares
!> izquierdos de una matriz bidiagonal superior al lado derecho; y si
!> ICOMPQ = 1, SLALSA aplica la matriz de vectores singulares derechos al
!> lado derecho. Las matrices de vectores singulares fueron generadas en
!> forma compacta por SLALSA.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>         Especifica si la matriz de vectores singulares izquierdos o derechos
!>         está involucrada.
!>         = 0: Matriz de vectores singulares izquierdos
!>         = 1: Matriz de vectores singulares derechos
!>

SMLSIZ

!>          SMLSIZ es INTEGER
!>         El tamaño máximo de los subproblemas en la parte inferior del
!>         árbol de cálculo.
!>

N

!>          N es INTEGER
!>         Las dimensiones de fila y columna de la matriz bidiagonal superior.
!>

NRHS

!>          NRHS es INTEGER
!>         El número de columnas de B y BX. NRHS debe ser al menos 1.
!>

B

!>          B es un array REAL, dimensión ( LDB, NRHS )
!>         En la entrada, B contiene los lados derechos del problema de
!>         mínimos cuadrados en las filas 1 a M.
!>         En la salida, B contiene la solución X en las filas 1 a N.
!>

LDB

!>          LDB es INTEGER
!>         La dimensión principal de B en el subprograma que llama.
!>         LDB debe ser al menos max(1,MAX( M, N ) ).
!>

BX

!>          BX es un array REAL, dimensión ( LDBX, NRHS )
!>         A la salida, el resultado de aplicar la matriz de vectores singulares
!>         izquierdos o derechos a B.
!>

LDBX

!>          LDBX es INTEGER
!>         La dimensión principal de BX.
!>

U

!>          U es un array REAL, dimensión ( LDU, SMLSIZ ).
!>         En la entrada, U contiene las matrices de vectores singulares
!>         izquierdos de todos los subproblemas en el nivel inferior.
!>

LDU

!>          LDU es INTEGER, LDU = > N.
!>         La dimensión principal de los arrays U, VT, DIFL, DIFR,
!>         POLES, GIVNUM y Z.
!>

VT

!>          VT es un array REAL, dimensión ( LDU, SMLSIZ+1 ).
!>         En la entrada, VT**T contiene las matrices de vectores singulares
!>         derechos de todos los subproblemas en el nivel inferior.
!>

K

!>          K es un array INTEGER, dimensión ( N ).
!>

DIFL

!>          DIFL es un array REAL, dimensión ( LDU, NLVL ).
!>         donde NLVL = INT(log_2 (N/(SMLSIZ+1))) + 1.
!>

DIFR

!>          DIFR es un array REAL, dimensión ( LDU, 2 * NLVL ).
!>         En la entrada, DIFL(*, I) y DIFR(*, 2 * I -1) registran
!>         las distancias entre los valores singulares en el nivel I y
!>         los valores singulares en el nivel (I -1), y DIFR(*, 2 * I)
!>         registran los factores de normalización de las matrices de
!>         vectores singulares derechos de los subproblemas en el nivel I.
!>

Z

!>          Z es un array REAL, dimensión ( LDU, NLVL ).
!>         En la entrada, Z(1, I) contiene los componentes del vector de
!>         fila de actualización ajustado por deflación para los
!>         subproblemas en el nivel I.
!>

POLES

!>          POLES es un array REAL, dimensión ( LDU, 2 * NLVL ).
!>         En la entrada, POLES(*, 2 * I -1: 2 * I) contiene los valores
!>         singulares nuevos y antiguos involucrados en las ecuaciones
!>         seculares en el nivel I.
!>

GIVPTR

!>          GIVPTR es un array INTEGER, dimensión ( N ).
!>         En la entrada, GIVPTR( I ) registra el número de rotaciones
!>         de Givens realizadas en el problema I en el árbol de cálculo.
!>

GIVCOL

!>          GIVCOL es un array INTEGER, dimensión ( LDGCOL, 2 * NLVL ).
!>         En la entrada, para cada I, GIVCOL(*, 2 * I - 1: 2 * I) registra
!>         las ubicaciones de las rotaciones de Givens realizadas en el
!>         nivel I en el árbol de cálculo.
!>

LDGCOL

!>          LDGCOL es INTEGER, LDGCOL = > N.
!>         La dimensión principal de los arrays GIVCOL y PERM.
!>

PERM

!>          PERM es un array INTEGER, dimensión ( LDGCOL, NLVL ).
!>         En la entrada, PERM(*, I) registra las permutaciones
!>         realizadas en el nivel I del árbol de cálculo.
!>

GIVNUM

!>          GIVNUM es un array REAL, dimensión ( LDU, 2 * NLVL ).
!>         En la entrada, GIVNUM(*, 2 *I -1 : 2 * I) registra los
!>         valores C y S de las rotaciones de Givens realizadas en el
!>         nivel I en el árbol de cálculo.
!>

C

!>          C es un array REAL, dimensión ( N ).
!>         En la entrada, si el subproblema I no es cuadrado,
!>         C( I ) contiene el valor C de una rotación de Givens relacionada
!>         con el espacio nulo derecho del subproblema I.
!>

S

!>          S es un array REAL, dimensión ( N ).
!>         En la entrada, si el subproblema I no es cuadrado,
!>         S( I ) contiene el valor S de una rotación de Givens relacionada
!>         con el espacio nulo derecho del subproblema I.
!>

WORK

!>          WORK es un array REAL, dimensión (N)
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (3*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

NOMBRE

SLALSA - El subtipo de esta función es SLALSA.

SINOPSIS

    SUBROUTINE SLALSA(
               N, A, LDA, B, LDB, RWORK, LRWORK, IWORK, LIWORK, INFO
            )
    INTEGER
               INFO
    INTEGER
               LDA, LDB, LIWORK, LRWORK
    REAL (KIND=SKP)
               A( LDA, * ), B( LDB, * ), RWORK( * )
    INTEGER
               IWORK( * )

DESCRIPCIÓN

SLALSA calcula una solución a R = B - A*X.

ARGUMENTOS

N

Orden de la matriz. N >= 0.

A

Matriz de dimensión (LDA, N).

LDA

Dimensión de la matriz A. LDA >= max(1, N).

B

Matriz de dimensión (LDB, N).

LDB

Dimensión de la matriz B. LDB >= max(1, N).

RWORK

Vector de trabajo de dimensión (LRWORK).

LRWORK

Longitud del vector de trabajo RWORK. LRWORK >= N*N + 3*N.

IWORK

Vector de trabajo de dimensión (LIWORK).

LIWORK

Longitud del vector de trabajo IWORK. LIWORK >= 2*N.

INFO

= 0: Éxito.

< 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal. Así mismo, si INFO = -6, entonces LRWORK < N*N + 3*N, o si INFO = -8, entonces LIWORK < 2*N.
