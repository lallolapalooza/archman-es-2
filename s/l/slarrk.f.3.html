Documentación de Función/Subrutina

subrutina slarrk (integer n, integer iw, real gl, real gu, real, dimension( * ) d, real, dimension( * ) e2, real pivmin, real reltol, real w, real werr, integer info)

SLARRK calcula un valor propio de una matriz tridiagonal simétrica con la precisión adecuada.

Propósito:

!>
!> SLARRK calcula un valor propio de una matriz tridiagonal
!> simétrica con la precisión adecuada. Este es un código auxiliar
!> para ser llamado desde SSTEMR.
!>
!> Para evitar desbordamiento, la matriz debe ser escalada para que
!> su elemento más grande no exceda overflow**(1/2) * underflow**(1/4)
!> en valor absoluto, y para la mayor precisión, no debe ser mucho
!> menor que eso.
!>
!> Véase W. Kahan , Report CS41, Computer Science Dept., Stanford
!> University, 21 de julio de 1966.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz tridiagonal T.  N >= 0.
!>

IW

!>          IW es INTEGER
!>          El índice del valor propio a devolver.
!>

GL

!>          GL es REAL
!>

GU

!>          GU es REAL
!>          Un límite superior y uno inferior en el valor propio.
!>

D

!>          D es array REAL, dimension (N)
!>          Los n elementos diagonales de la matriz tridiagonal T.
!>

E2

!>          E2 es array REAL, dimension (N-1)
!>          Los (n-1) elementos fuera de la diagonal al cuadrado de la
!>          matriz tridiagonal T.
!>

PIVMIN

!>          PIVMIN es REAL
!>          El pivote mínimo permitido en la secuencia de Sturm para T.
!>

RELTOL

!>          RELTOL es REAL
!>          El ancho relativo mínimo de un intervalo. Cuando un intervalo
!>          es más estrecho que RELTOL veces el punto final más
!>          grande (en magnitud), entonces se considera suficientemente
!>          pequeño, es decir, convergido. Nota: esto siempre debe
!>          ser al menos radix*epsilon de máquina.
!>

W

!>          W es REAL
!>

WERR

!>          WERR es REAL
!>          El límite de error en la aproximación del valor propio
!>          correspondiente en W.
!>

INFO

!>          INFO es INTEGER
!>          = 0:       Valor propio convergido
!>          = -1:      Valor propio NO convergió
!>

Parámetros Internos:

!>  FUDGE   REAL            , default = 2
!>          Para ampliar los intervalos de Gershgorin.
!>
