subroutine slagv2 (real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( 2 ) alphar, real, dimension( 2 ) alphai, real, dimension( 2 ) beta, real csl, real snl, real csr, real snr)

SLAGV2 calcula la factorización de Schur Generalizada de una matriz lápiz real de 2x2 (A,B) donde B es triangular superior.

Propósito:

!>
!> SLAGV2 calcula la factorización de Schur Generalizada de una matriz
!> lápiz real de 2x2 (A,B) donde B es triangular superior. Esta rutina
!> calcula matrices ortogonales (de rotación) dadas por CSL, SNL y CSR,
!> SNR tales que
!>
!> 1) si el lápiz (A,B) tiene dos valores propios reales (incluyendo tipos
!>    0/0 o 1/0), entonces
!>
!>    [ a11 a12 ] := [  CSL  SNL ] [ a11 a12 ] [  CSR -SNR ]
!>    [  0  a22 ]    [ -SNL  CSL ] [ a21 a22 ] [  SNR  CSR ]
!>
!>    [ b11 b12 ] := [  CSL  SNL ] [ b11 b12 ] [  CSR -SNR ]
!>    [  0  b22 ]    [ -SNL  CSL ] [  0  b22 ] [  SNR  CSR ],
!>
!> 2) si el lápiz (A,B) tiene un par de valores propios conjugados complejos,
!>    entonces
!>
!>    [ a11 a12 ] := [  CSL  SNL ] [ a11 a12 ] [  CSR -SNR ]
!>    [ a21 a22 ]    [ -SNL  CSL ] [ a21 a22 ] [  SNR  CSR ]
!>
!>    [ b11  0  ] := [  CSL  SNL ] [ b11 b12 ] [  CSR -SNR ]
!>    [  0  b22 ]    [ -SNL  CSL ] [  0  b22 ] [  SNR  CSR ]
!>
!>    donde b11 >= b22 > 0.
!>
!>

Parámetros

A 
!>          A es un array REAL, dimension (LDA, 2)
!>          En la entrada, la matriz A de 2x2.
!>          En la salida, A se sobrescribe con la "parte A" de la
!>          forma de Schur generalizada.
!>

LDA

!>          LDA es un INTEGER
!>          La dimensión principal del array A. LDA >= 2.
!>

B

!>          B es un array REAL, dimension (LDB, 2)
!>          En la entrada, la matriz B de 2x2 triangular superior.
!>          En la salida, B se sobrescribe con la "parte B" de la
!>          forma de Schur generalizada.
!>

LDB

!>          LDB es un INTEGER
!>          La dimensión principal del array B. LDB >= 2.
!>

ALPHAR

!>          ALPHAR es un array REAL, dimension (2)
!>

ALPHAI

!>          ALPHAI es un array REAL, dimension (2)
!>

BETA

!>          BETA es un array REAL, dimension (2)
!>          (ALPHAR(k)+i*ALPHAI(k))/BETA(k) son los valores propios del
!>          lápiz (A,B), k=1,2, i = sqrt(-1). Note que BETA(k) puede
!>          ser cero.
!>

CSL

!>          CSL es REAL
!>          El coseno de la matriz de rotación izquierda.
!>

SNL

!>          SNL es REAL
!>          El seno de la matriz de rotación izquierda.
!>

CSR

!>          CSR es REAL
!>          El coseno de la matriz de rotación derecha.
!>

SNR

!>          SNR es REAL
!>          El seno de la matriz de rotación derecha.
!>
