NOMBRE

slmprune - podar el modelo de lenguaje de retroceso a un tamaño razonable

SINOPSIS

slmprune slm_entrada slm_resultado opcion_corte num...

DESCRIPCIÓN

Este programa utiliza un método basado en entropía para podar el tamaño del modelo de lenguaje de retroceso 'slm_entrada' a un tamaño específico y escribirlo en 'slm_resultado'.

El tercer parámetro opcion_corte puede ser [R|C]. Significa que los siguientes números son el número para (R)eservar o (C)ortar. Si es (C)ortar, num[k] significa cuántos elementos en el nivel K se cortarán. Si es (R)eservar, num[k] significa cuántos elementos se reservarán en el nivel k.

Tenga en cuenta que no garantizamos que durante el proceso de poda se corten o reserven exactamente el número dado de elementos, porque algunos elementos pueden contener hijos de nivel superior y, por lo tanto, no pueden cortarse.

También es su responsabilidad proporcionar el número correcto de argumentos según 'slm_entrada'.

NOTA

Para obtener información sobre el modelo de lenguaje de retroceso, intente con 'slminfo'.
