SLAEDA utilizado por SSTEDC. Calcula el vector Z que determina la modificación de rango uno de la matriz diagonal. Utilizado cuando la matriz original es densa.

SLAEDA utilizado por SSTEDC. Calcula el vector Z que determina la modificación de rango uno de la matriz diagonal. Utilizado cuando la matriz original es densa.

Propósito:

!>
!> SLAEDA calcula el vector Z correspondiente al paso de fusión en el
!> paso CURLVL de la fusión de los TLVLS pasos para el problema CURPBM.
!>

Parámetros

N 
!>          N es ENTERO
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

TLVLS

!>          TLVLS es ENTERO
!>         El número total de niveles de fusión en el árbol de divide y
!>         vencer general.
!>

CURLVL

!>          CURLVL es ENTERO
!>         El nivel actual en la rutina de fusión general,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM es ENTERO
!>         El problema actual en el nivel actual de la rutina de fusión
!>         general (contando desde la parte superior izquierda hasta la
!>         parte inferior derecha).
!>

PRMPTR

!>          PRMPTR es un array de ENTEROS, dimensión (N lg N)
!>         Contiene una lista de punteros que indican dónde en PERM se
!>         almacena la permutación de un nivel.  PRMPTR(i+1) - PRMPTR(i)
!>         indica el tamaño de la permutación y, por casualidad, el
!>         tamaño del problema completo, sin deflación.
!>

PERM

!>          PERM es un array de ENTEROS, dimensión (N lg N)
!>         Contiene las permutaciones (de deflación y ordenamiento) que
!>         se aplicarán a cada subbloque de eigenvalores.
!>

GIVPTR

!>          GIVPTR es un array de ENTEROS, dimensión (N lg N)
!>         Contiene una lista de punteros que indican dónde en GIVCOL se
!>         almacenan las rotaciones de Givens de un nivel.  GIVPTR(i+1) -
!>         GIVPTR(i) indica el número de rotaciones de Givens.
!>

GIVCOL

!>          GIVCOL es un array de ENTEROS, dimensión (2, N lg N)
!>         Cada par de números indica un par de columnas para tomar parte
!>         en una rotación de Givens.
!>

GIVNUM

!>          GIVNUM es un array de REAL, dimensión (2, N lg N)
!>         Cada número indica el valor S que se utilizará en la rotación
!>         de Givens correspondiente.
!>

Q

!>          Q es un array de REAL, dimensión (N**2)
!>         Contiene los subbloques de eigenvalores al cuadrado de niveles
!>         anteriores, las posiciones de inicio de los bloques están dadas
!>         por QPTR.
!>

QPTR

!>          QPTR es un array de ENTEROS, dimensión (N+2)
!>         Contiene una lista de punteros que indican dónde en Q se
!>         almacena un subbloque de eigenvalores.  SQRT( QPTR(i+1) -
!>         QPTR(i) ) indica el tamaño del bloque.
!>

Z

!>          Z es un array de REAL, dimensión (N)
!>         En la salida, este vector contiene el vector de actualización
!>         (la última fila de la primera matriz de sub-eigenvectores y la
!>         primera fila de la segunda matriz de sub-eigenvectores).
!>

ZTEMP

!>          ZTEMP es un array de REAL, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor
!>                ilegal.
!>
