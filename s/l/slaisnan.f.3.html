DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

función lógica slaisnan (real, intent(in) sin1, real, intent(in) sin2)

SLAISNAN comprueba si la entrada es NaN comparando dos argumentos para desigualdad.

Propósito:

!>
!> Esta rutina no es para uso general. Existe únicamente para evitar
!> una sobre-optimización en SISNAN.
!>
!> SLAISNAN comprueba NaN comparando sus dos argumentos para
!> desigualdad. NaN es el único valor de punto flotante para el cual NaN != NaN
!> devuelve .TRUE. Para comprobar NaN, pase la misma variable como ambos
!> argumentos.
!>
!> Un compilador debe asumir que los dos argumentos no son
!> la misma variable, y la prueba no se optimizará.
!> La optimización interprocedural o de programa completo puede eliminar esta
!> prueba. Las funciones ISNAN se reemplazarán por la intrínseca de
!> Fortran 03 correcta una vez que la intrínseca esté ampliamente disponible.
!>

Parámetros

SIN1 
!>          SIN1 es REAL
!>

SIN2

!>          SIN2 es REAL
!>          Dos números para comparar por desigualdad.
!>
