Documentación de la función/subrutina

subroutine slagge (integer m, integer n, integer kl, integer ku, real, dimension( * ) d, real, dimension( lda, * ) a, integer lda, integer, dimension( 4 ) iseed, real, dimension( * ) work, integer info)

SLAGGE

Propósito:

!>
!> SLAGGE genera una matriz real general A de m por n, pre- y post-
!> multiplicando una matriz diagonal real D con matrices ortogonales aleatorias:
!> A = U*D*V. Las bandas inferior y superior pueden entonces reducirse a
!> kl y ku mediante transformaciones ortogonales adicionales.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

KL

!>          KL es ENTERO
!>          El número de subdiagonales distintas de cero dentro de la banda de A.
!>          0 <= KL <= M-1.
!>

KU

!>          KU es ENTERO
!>          El número de superdiagonales distintas de cero dentro de la banda de A.
!>          0 <= KU <= N-1.
!>

D

!>          D es un array REAL, dimension (min(M,N))
!>          Los elementos diagonales de la matriz diagonal D.
!>

A

!>          A es un array REAL, dimension (LDA,N)
!>          La matriz A generada de m por n.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= M.
!>

ISEED

!>          ISEED es un array ENTERO, dimension (4)
!>          A la entrada, la semilla del generador de números aleatorios; los
!>          elementos del array deben estar entre 0 y 4095, y ISEED(4) debe
!>          ser impar.
!>          A la salida, la semilla se actualiza.
!>

WORK

!>          WORK es un array REAL, dimension (M+N)
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
