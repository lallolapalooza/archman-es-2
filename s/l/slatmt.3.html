SLATMT

Propósito:

!>
!>    SLATMT genera matrices aleatorias con valores singulares especificados
!>    (o simétricas/hermitianas con valores propios especificados)
!>    para probar programas LAPACK.
!>
!>    SLATMT opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Establece la diagonal a D, donde D puede ser de entrada o
!>         calculada según MODE, COND, DMAX y SYM
!>         como se describe a continuación.
!>
!>      Genera una matriz con la estructura de banda apropiada, mediante uno
!>         de dos métodos:
!>
!>      Método A:
!>          Genera una matriz densa M x N multiplicando D a la izquierda
!>              y a la derecha por matrices unitarias aleatorias, y luego:
!>
!>          Reduce el ancho de banda según KL y KU, utilizando
!>          transformaciones de Householder.
!>
!>      Método B:
!>          Convierte la matriz de ancho de banda 0 (es decir, diagonal) a una
!>              matriz de ancho de banda 1 usando rotaciones de Givens,
!>              llevando los elementos fuera de banda de vuelta, de manera similar a QR; luego
!>              convierte la de ancho de banda 1 a una de ancho de banda 2, etc.
!>              Tenga en cuenta que para anchos de banda razonablemente pequeños (en relación con
!>              M y N) esto requiere menos almacenamiento, ya que no se genera una matriz densa.
!>              Además, para matrices simétricas, solo se genera un triángulo.
!>
!>      Se elige el Método A si el ancho de banda es una fracción grande del
!>          orden de la matriz, y LDA es al menos M (para que se pueda almacenar una matriz
!>          densa). Se elige el Método B si el ancho de banda
!>          es pequeño (< 1/2 N para simétricas, < .3 N+M para
!>          no simétricas), o LDA es menor que M y no menor que el
!>          ancho de banda.
!>
!>      Empaqueta la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetar
!>         poner a cero la mitad superior (si es simétrica)
!>         poner a cero la mitad inferior (si es simétrica)
!>         almacenar la mitad superior por columnas (si es simétrica o triangular superior)
!>         almacenar la mitad inferior por columnas (si es simétrica o triangular inferior)
!>         almacenar el triángulo inferior en formato de banda (si es simétrica
!>               o triangular inferior)
!>         almacenar el triángulo superior en formato de banda (si es simétrica
!>               o triangular superior)
!>         almacenar toda la matriz en formato de banda
!>      Si se elige el Método B, y se especifica el formato de banda, entonces la
!>         matriz se generará en formato de banda, por lo que no será necesario
!>         volver a empaquetarla.
!>

Parámetros

M 
!>          M es ENTERO
!>           El número de filas de A. No se modifica.
!>

N

!>          N es ENTERO
!>           El número de columnas de A. No se modifica.
!>

DIST

!>          DIST es CARACTER*1
!>           A la entrada, DIST especifica el tipo de distribución que se utilizará
!>           para generar los valores propios/singulares aleatorios.
!>           'U' => UNIFORME( 0, 1 )  ( 'U' para uniforme )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' para simétrica )
!>           'N' => NORMAL( 0, 1 )   ( 'N' para normal )
!>           No se modifica.
!>

ISEED

!>          ISEED es un array ENTERO, dimensión ( 4 )
!>           A la entrada, ISEED especifica la semilla del generador de números
!>           aleatorios. Deben estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           utiliza una secuencia congruencial lineal limitada a enteros
!>           pequeños, y por lo tanto debe producir números aleatorios independientes de la máquina.
!>           Los valores de ISEED se cambian a la salida y se pueden usar en la siguiente llamada
!>           a SLATMT para continuar la misma secuencia de números aleatorios.
!>           Modificado a la salida.
!>

SYM

!>          SYM es CARACTER*1
!>           Si SYM='S' o 'H', la matriz generada es simétrica, con
!>             valores propios especificados por D, COND, MODE y DMAX; pueden
!>             ser positivos, negativos o cero.
!>           Si SYM='P', la matriz generada es simétrica, con
!>             valores propios (= valores singulares) especificados por D, COND,
!>             MODE y DMAX; no serán negativos.
!>           Si SYM='N', la matriz generada es no simétrica, con
!>             valores singulares especificados por D, COND, MODE y DMAX;
!>             no serán negativos.
!>           No se modifica.
!>

D

!>          D es un array REAL, dimensión ( MIN( M , N ) )
!>           Este array se utiliza para especificar los valores singulares o
!>           valores propios de A (ver SYM, arriba). Si MODE=0, entonces D
!>           se asume que contiene los valores singulares/propios, de lo contrario
!>           se calcularán según MODE, COND y DMAX,
!>           y se colocarán en D.
!>           Modificado si MODE es distinto de cero.
!>

MODE

!>          MODE es ENTERO
!>           A la entrada, esto describe cómo se especificarán los valores singulares/propios:
!>           MODE = 0 significa usar D como entrada
!>
!>           MODE = 1 establece D(1)=1 y D(2:RANK)=1.0/COND
!>           MODE = 2 establece D(1:RANK-1)=1 y D(RANK)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(RANK-1))
!>
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           Si SYM='S' o 'H', y MODE no es 0, 6 ni -6, entonces
!>              los elementos de D también se multiplicarán por un signo aleatorio (es decir, +1 o -1).
!>           No se modifica.
!>

COND

!>          COND es REAL
!>           A la entrada, se utiliza como se describe en MODE arriba.
!>           Si se utiliza, debe ser >= 1. No se modifica.
!>

DMAX

!>          DMAX es REAL
!>           Si MODE no es -6, 0 ni 6, los contenidos de D, como
!>           se calculan según MODE y COND, se escalarán por
!>           DMAX / max(abs(D(i))); por lo tanto, el valor propio o
!>           singular máximo absoluto (es decir, la norma) será abs(DMAX).
!>           Tenga en cuenta que DMAX no tiene por qué ser positivo: si DMAX es negativo
!>           (o cero), D se escalará por un número negativo (o cero).
!>           No se modifica.
!>

RANK

!>          RANK es ENTERO
!>           El rango de la matriz a generar para los modos 1, 2, 3 solamente.
!>           D( RANK+1:N ) = 0.
!>           No se modifica.
!>

KL

!>          KL es ENTERO
!>           Esto especifica el ancho de banda inferior de la matriz. Por
!>           ejemplo, KL=0 implica triangular superior, KL=1 implica Hessenberg
!>           superior, y KL siendo al menos M-1 significa que la matriz
!>           tiene ancho de banda inferior completo. KL debe ser igual a KU si la matriz
!>           es simétrica.
!>           No se modifica.
!>

KU

!>          KU

NAME

slatmt - SLATMT generates a standard test matrix in the packed or banded storage format

SYNOPSIS 

 SUBROUTINE SLATMT(
  N, M, DIST,       &
  D,                  &
  K,                  &
  SYM,                &
  MODE,               &
  COND,               &
  MAX,                &
  MIN,                &
  KL, KU,             &
  PACK,               &
  A, LDA,             &
  WORK, INFO )

CHARACTER*1 :: DIST, SYM, PACK INTEGER :: N, M, K, MODE, KL, KU, LDA, INFO REAL :: D, COND, MAX, MIN REAL :: A( LDA, * ) REAL :: WORK( * )

Function/Subroutine Documentation

SLATMT generates a standard test matrix in the packed or banded storage format.

Arguments 

!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!>          Not modified.
!> 
!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!>          If SYM is 'S', 'H', or 'P', then M must equal N.
!>          Not modified.
!> 
!>          DIST is CHARACTER*1
!>          Specifies the form of the distribution of the matrix A.
!>          'U' => Undistributed matrix, A = FL*I.
!>          'R' => Randomly distributed matrix.
!>          'L' => Lower triangular matrix.
!>          'U' => Upper triangular matrix.
!>          'S' => Symmetric matrix.
!>          'H' => Lower Hessian matrix.
!>          'P' => Positive definite matrix.
!>          Not modified.
!> 
!>          D is REAL
!>          The value of the diagonal elements of the matrix.
!>          Not modified.
!> 
!>          K is INTEGER
!>          The number of nonzero subdiagonals below the main diagonal in
!>          the generated matrix.
!>          Not modified.
!> 
!>          SYM is CHARACTER*1
!>          Specifies the form of the matrix A.
!>          'N' => Not symmetric
!>          'S' => Symmetric
!>          'H' => Lower triangular and upper triangular (Hessenberg)
!>          'P' => Lower triangular and upper triangular (Positive definite)
!>          Not modified.
!> 
!>          MODE is INTEGER
!>          Specifies the structure of the matrix.
!>          MODE = -1 => Diagonal matrix
!>          MODE =  0 => Default values
!>          MODE =  1 => Random values
!>          MODE =  2 => Upper triangular
!>          MODE =  3 => Lower triangular
!>          MODE =  4 => Symmetric
!>          MODE =  5 => Skew-symmetric
!>          MODE =  6 => Full matrix
!>          Not modified.
!> 
!>          COND is REAL
!>          The condition number of the matrix.  COND is used only if
!>          MODE = 6.  If MODE is not 6, then COND is not used.
!>          Not modified.
!> 
!>          MAX is REAL
!>          The maximum value of the matrix elements.  MAX is used only if
!>          MODE = 6.  If MODE is not 6, then MAX is not used.
!>          Not modified.
!> 
!>          MIN is REAL
!>          The minimum value of the matrix elements. MIN is used only if
!>          MODE = 6. If MODE is not 6, then MIN is not used.
!>          Not modified.
!> 
!>          KU is INTEGER
!>          This specifies the upper bandwidth of the matrix. For
!>          example, KU=0 implies lower triangular, KU=1 implies lower
!>          Hessenberg, and KU being at least N-1 means that the matrix
!>          has full upper bandwidth. KL must equal KU if the matrix
!>          is symmetric.
!>          Not modified.
!> 
!>          PACK is CHARACTER*1
!>          This specifies packing of matrix as follows:
!>          'N' => no packing
!>          'U' => zero out all subdiagonal entries (if symmetric)
!>          'L' => zero out all superdiagonal entries (if symmetric)
!>          'C' => store the upper triangle columnwise
!>                 (only if the matrix is symmetric or upper triangular)
!>          'R' => store the lower triangle columnwise
!>                 (only if the matrix is symmetric or lower triangular)
!>          'B' => store the lower triangle in band storage scheme
!>                 (only if matrix symmetric or lower triangular)
!>          'Q' => store the upper triangle in band storage scheme
!>                 (only if matrix symmetric or upper triangular)
!>          'Z' => store the entire matrix in band storage scheme
!>                     (pivoting can be provided for by using this
!>                     option to store A in the trailing rows of
!>                     the allocated storage)
!>
!>          Using these options, the various LAPACK packed and banded
!>          storage schemes can be obtained:
!>          GB               - use 'Z'
!>          PB, SB or TB     - use 'B' or 'Q'
!>          PP, SP or TP     - use 'C' or 'R'
!>
!>          If two calls to SLATMT differ only in the PACK parameter,
!>          they will generate mathematically equivalent matrices.
!>          Not modified.
!> 
!>          A is REAL array, dimension ( LDA, N )
!>          On exit A is the desired test matrix.  A is first generated
!>          in full (unpacked) form, and then packed, if so specified
!>          by PACK.  Thus, the first M elements of the first N
!>          columns will always be modified.  If PACK specifies a
!>          packed or banded storage scheme, all LDA elements of the
!>          first N columns will be modified; the elements of the
!>          array which do not correspond to elements of the generated
!>          matrix are set to zero.
!>          Modified.
!> 
!>          LDA is INTEGER
!>          LDA specifies the first dimension of A as declared in the
!>          calling program.  If PACK='N', 'U', 'L', 'C', or 'R', then
!>          LDA must be at least M.  If PACK='B' or 'Q', then LDA must
!>          be at least MIN( KL, M-1) (which is equal to MIN(KU,N-1)).
!>          If PACK='Z', LDA must be large enough to hold the packed
!>          array: MIN( KU, N-1) + MIN( KL, M-1) + 1.
!>          Not modified.
!> 
!>          WORK is REAL array, dimension ( 3*MAX( N , M ) )
!>          Workspace.
!>          Modified.
!> 
!>          INFO is INTEGER
!>          Error code.  On exit, INFO will be set to one of the
!>          following values:
!>            0 => normal return
!>           -1 => M negative or unequal to N and SYM='S', 'H', or 'P'
!>           -2 => N negative
!>           -3 => DIST illegal string
!>           -5 => SYM illegal string
!>           -7 => MODE not in range -6 to 6
!>           -8 => COND less than 1.0, and MODE neither -6, 0 nor 6
!>          -10 => KL negative
!>          -11 => KU negative, or SYM='S' or 'H' and KU not equal to KL
!>          -12 => PACK illegal string, or PACK='U' or 'L', and SYM='N';
!>                 or PACK='C' or 'Q' and SYM='N' and KL is not zero;
!>                 or PACK='R' or 'B' and SYM='N' and KU is not zero;
!>                 or PACK='U', 'L', 'C', 'R', 'B', or 'Q', and M is not
!>                 N.
!>          -14 => LDA is less than M, or PACK='Z' and LDA is less than
!>                 MIN(KU,N-1) + MIN(KL,M-1) + 1.
!>           1  => Error return from SLATM7
!>           2  => Cannot scale to DMAX (max. sing. value is 0)
!>           3  => Error return from SLAGGE or SLAGSY
!>
