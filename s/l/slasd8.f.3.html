Documentación de Función/Subrutina

subroutine slasd8 (integer icompq, integer k, real, dimension( * ) d, real, dimension( * ) z, real, dimension( * ) vf, real, dimension( * ) vl, real, dimension( * ) difl, real, dimension( lddifr, * ) difr, integer lddifr, real, dimension( * ) dsigma, real, dimension( * ) work, integer info)

SLASD8 encuentra las raíces cuadradas de las raíces de la ecuación secular, y almacena, para cada elemento en D, la distancia a sus dos polos más cercanos. Usado por sbdsdc.

Propósito:

!>
!> SLASD8 encuentra las raíces cuadradas de las raíces de la ecuación
!> secular, según lo definido por los valores en DSIGMA y Z. Realiza las
!> llamadas apropiadas a SLASD4, y almacena, para cada elemento en D, la
!> distancia a sus dos polos más cercanos (elementos en DSIGMA). También
!> actualiza los arrays VF y VL, los componentes primero y último de todos
!> los vectores singulares derechos de la matriz bidiagonal original.
!>
!> SLASD8 es llamado desde SLASD6.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>          Especifica si los vectores singulares deben calcularse en
!>          forma factorizada en la rutina de llamada:
!>          = 0: Calcular solo los valores singulares.
!>          = 1: Calcular también los vectores singulares en forma factorizada.
!>

K

!>          K es INTEGER
!>          El número de términos en la función racional a ser resuelta
!>          por SLASD4. K >= 1.
!>

D

!>          D es un array REAL, dimension ( K )
!>          En la salida, D contiene los valores singulares actualizados.
!>

Z

!>          Z es un array REAL, dimension ( K )
!>          En la entrada, los primeros K elementos de este array contienen los
!>          componentes del vector de fila de actualización ajustado por
!>          deflación.
!>          En la salida, Z se actualiza.
!>

VF

!>          VF es un array REAL, dimension ( K )
!>          En la entrada, VF contiene información pasada a través de
!>          DBEDE8.
!>          En la salida, VF contiene los primeros K componentes de los
!>          primeros componentes de todos los vectores singulares derechos
!>          de la matriz bidiagonal.
!>

VL

!>          VL es un array REAL, dimension ( K )
!>          En la entrada, VL contiene información pasada a través de
!>          DBEDE8.
!>          En la salida, VL contiene los primeros K componentes de los
!>          últimos componentes de todos los vectores singulares derechos
!>          de la matriz bidiagonal.
!>

DIFL

!>          DIFL es un array REAL, dimension ( K )
!>          En la salida, DIFL(I) = D(I) - DSIGMA(I).
!>

DIFR

!>          DIFR es un array REAL,
!>                   dimension ( LDDIFR, 2 ) si ICOMPQ = 1 y
!>                   dimension ( K ) si ICOMPQ = 0.
!>          En la salida, DIFR(I,1) = D(I) - DSIGMA(I+1), DIFR(K,1) no está
!>          definido y no será referenciado.
!>
!>          Si ICOMPQ = 1, DIFR(1:K,2) es un array que contiene los
!>          factores de normalización para la matriz de vectores singulares
!>          derechos.
!>

LDDIFR

!>          LDDIFR es INTEGER
!>          La dimensión líder de DIFR, debe ser al menos K.
!>

DSIGMA

!>          DSIGMA es un array REAL, dimension ( K )
!>          En la entrada, los primeros K elementos de este array contienen las
!>          raíces antiguas del problema de actualización desdeflado. Estos
!>          son los polos de la ecuación secular.
!>

WORK

!>          WORK es un array REAL, dimension (3*K)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = 1, un valor singular no convergió
!>
