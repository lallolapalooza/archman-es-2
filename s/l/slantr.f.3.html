función real slantr (norm, uplo, diag, m, n, a, lda, work)
SLANTR devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz trapezoidal o triangular.

Documentación de Función/Subrutina

real función slantr (character norm, character uplo, character diag, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) work)

SLANTR devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz trapezoidal o triangular.

Propósito:

!>
!> SLANTR  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma  del infinito,  o el  elemento de  mayor valor absoluto de
!> una matriz trapezoidal o triangular A.
!>

Devuelve

SLANTR 
!>
!>    SLANTR = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma del infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma de matriz consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en SLANTR como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es trapezoidal superior o inferior.
!>          = 'U':  Trapezoidal superior
!>          = 'L':  Trapezoidal inferior
!>          Tenga en cuenta que A es triangular en lugar de trapezoidal si M = N.
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A tiene o no una diagonal unitaria.
!>          = 'N':  Diagonal no unitaria
!>          = 'U':  Diagonal unitaria
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0, y si
!>          UPLO = 'U', M <= N.  Cuando M = 0, SLANTR se establece en cero.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0, y si
!>          UPLO = 'L', N <= M.  Cuando N = 0, SLANTR se establece en cero.
!>

A

!>          A es una matriz REAL, de dimensión (LDA,N)
!>          La matriz trapezoidal A (A es triangular si M = N).
!>          Si UPLO = 'U', la parte trapezoidal superior m por n principal de
!>          la matriz A contiene la matriz trapezoidal superior, y la
!>          parte triangular estrictamente inferior de A no se referencia.
!>          Si UPLO = 'L', la parte trapezoidal inferior m por n principal de
!>          la matriz A contiene la matriz trapezoidal inferior, y la
!>          parte triangular estrictamente superior de A no se referencia.  Tenga
!>          en cuenta que cuando DIAG = 'U', los elementos diagonales de A no
!>          se referencian y se asumen como uno.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(M,1).
!>

WORK

!>          WORK es una matriz REAL, de dimensión (MAX(1,LWORK)),
!>          donde LWORK >= M cuando NORM = 'I'; en caso contrario, WORK no se
!>          referencia.
!>
