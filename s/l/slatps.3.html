Documentación de la Función/Subrutina

subrutina slatps (character uplo, character trans, character diag, character normin, integer n, real, dimension( * ) ap, real, dimension( * ) x, real scale, real, dimension( * ) cnorm, integer info)

SLATPS resuelve un sistema triangular de ecuaciones con la matriz en almacenamiento empaquetado.

Propósito:

!>
!> SLATPS resuelve uno de los sistemas triangulares
!>
!>    A *x = s*b  o  A**T*x = s*b
!>
!> con escalado para prevenir desbordamiento, donde A es una matriz
!> triangular superior o inferior almacenada en forma empaquetada. Aquí
!> A**T denota la transpuesta de A, x y b son vectores de n elementos, y s
!> es un factor de escalado, usualmente menor o igual a 1, elegido para
!> que los componentes de x sean menores que el umbral de desbordamiento.
!> Si el problema no escalado no causará desbordamiento, se llama a la
!> rutina BLAS de Nivel 2 STPSV. Si la matriz A es singular (A(j,j) = 0
!> para algún j), entonces s se establece en 0 y se devuelve una solución
!> no trivial para A*x = 0.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resolver A * x = s*b  (Sin transpuesta)
!>          = 'T':  Resolver A**T* x = s*b  (Transpuesta)
!>          = 'C':  Resolver A**T* x = s*b  (Transpuesta conjugada = Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria o no.
!>          = 'N':  No unitaria
!>          = 'U':  Unitaria
!>

NORMIN

!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM se ha establecido o no.
!>          = 'Y':  CNORM contiene las normas de columna en la entrada
!>          = 'N':  CNORM no está establecido en la entrada. En la salida,
!>                  se calcularán las normas y se almacenarán en CNORM.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es array REAL, dimension (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada
!>          columna a columna en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

X

!>          X es array REAL, dimension (N)
!>          En la entrada, el lado derecho b del sistema triangular.
!>          En la salida, X se sobrescribe con el vector solución x.
!>

SCALE

!>          SCALE es REAL
!>          El factor de escalado s para el sistema triangular
!>             A * x = s*b  o  A**T* x = s*b.
!>          Si SCALE = 0, la matriz A es singular o está mal escalada, y
!>          el vector x es una solución exacta o aproximada a A*x = 0.
!>

CNORM

!>          CNORM es array REAL, dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene la norma de la parte no diagonal de la j-ésima columna
!>          de A. Si TRANS = 'N', CNORM(j) debe ser mayor o igual a la
!>          norma infinito, y si TRANS = 'T' o 'C', CNORM(j)
!>          debe ser mayor o igual a la norma 1.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la norma 1 de la parte no diagonal de la j-ésima columna
!>          de A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>

Detalles Adicionales:

!>
!> Se calcula un límite aproximado para x; si este es menor que el
!> desbordamiento, se llama a STPSV, de lo contrario, se utiliza un código
!> específico que verifica posibles desbordamientos o divisiones por cero
!> en cada operación.
!>
!> Se utiliza un esquema columna a columna para resolver A*x = b. El
!> algoritmo básico si A es triangular inferior es
!>
!>       x[1:n] := b[1:n]
!>       para j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!> Definir límites para los componentes de x después de j iteraciones del
!> bucle:
!>     M(j) = límite para x[1:j]
!>     G(j) = límite para x[j+1:n]
!> Inicialmente, sea M(0) = 0 y G(0) = max{x(i), i=1,...,n}.
!>
!> Luego, para la iteración j+1, tenemos
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> donde CNORM(j+1) es mayor o igual a la norma infinito de la columna
!> j+1 de A, sin contar la diagonal. Por lo tanto
!>
!>     G(j) <= G(0) producto ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> y
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) producto ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> Dado que |x(j)| <= M(j), usamos la rutina BLAS de Nivel 2 STPSV si el
!> recíproco del M(j) máximo, j=1,..,n, es mayor que
!> max(underflow, 1/overflow).
!>
!> El límite para x(j) también se usa para determinar cuándo se puede
!> realizar un paso en el método columna a columna sin temor a
!> desbordamiento. Si el límite calculado es mayor que una constante grande,
!> x se escala para prevenir desbordamiento, pero si el límite se
!> desborda, x se establece en 0, x(j) en 1, y scale en 0, y se encuentra
!> una solución no trivial para A*x = 0.
!>
!> De manera similar, se utiliza un esquema fila a fila para resolver
!> A**T*x = b. El algoritmo básico para A triangular superior es
!>
!>       para j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]**T * x[1:j-1] ) / A(j,j)
!>       fin
!>
!> Calculamos simultáneamente dos límites
!>       G(j) = límite para ( b(i) - A[1:i-1,i]**T * x[1:i-1] ), 1<=i<=j
!>       M(j) = límite para x(i), 1<=i<=j
!>
!> Los valores iniciales son G(0) = 0, M(0) = max{b(i), i=1,..,n}, y
!> añadimos la restricción G(j) >= G(j-1) y M(j) >= M(j-1) para j >= 1.
!> Entonces, el límite para x(j) es
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * producto ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> y podemos llamar de forma segura a STPSV si 1/M(n) y 1/G(n) son ambos
!> mayores que max(underflow, 1/overflow).
!>
