subrutina slatrz (m, n, l, a, lda, tau, work)
SLATRZ factoriza una matriz trapezoidal superior mediante transformaciones ortogonales.

Documentación de función/subrutina

subrutina slatrz (entero m, entero n, entero l, real, dimensión( lda, * ) a, entero lda, real, dimensión( * ) tau, real, dimensión( * ) work)

SLATRZ factoriza la matriz trapezoidal superior real M-por-(M+L) como [ A1 A2 ] = [ A(1:M,1:M) A(1:M,N-L+1:N) ] como ( R 0 ) * Z, mediante transformaciones ortogonales. Z es una matriz ortogonal (M+L)-por-(M+L) y R y A1 son matrices triangulares superiores M-por-M.

Propósito:

!>
!> SLATRZ factoriza la matriz trapezoidal superior real M-por-(M+L)
!> [ A1 A2 ] = [ A(1:M,1:M) A(1:M,N-L+1:N) ] como ( R  0 ) * Z, mediante
!> transformaciones ortogonales. Z es una matriz ortogonal (M+L)-por-(M+L) y
!> R y A1 son matrices triangulares superiores M-por-M.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A. N >= 0.
!>

L

!>          L es ENTERO
!>          El número de columnas de la matriz A que contienen la
!>          parte significativa de los vectores de Householder. N-M >= L >= 0.
!>

A

!>          A es arreglo REAL, dimensión (LDA,N)
!>          En la entrada, la parte trapezoidal superior M-por-N principal
!>          del arreglo A debe contener la matriz a factorizar.
!>          En la salida, la parte triangular superior M-por-M principal
!>          contiene la matriz triangular superior R, y los elementos N-L+1 a
!>          N de las primeras M filas de A, junto con el arreglo TAU,
!>          representan la matriz ortogonal Z como un producto de M
!>          reflejos elementales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del arreglo A. LDA >= max(1,M).
!>

TAU

!>          TAU es arreglo REAL, dimensión (M)
!>          Los factores escalares de los reflejos elementales.
!>

WORK

!>          WORK es arreglo REAL, dimensión (M)
!>

Detalles adicionales:

!>
!> La factorización se obtiene por el método de Householder. La k-ésima
!> matriz de transformación, Z( k ), que se utiliza para introducir ceros en
!> la fila ( m - k + 1 ) de A, se da en la forma
!>
!>    Z( k ) = ( I     0   ),
!>             ( 0  T( k ) )
!>
!> donde
!>
!>    T( k ) = I - tau*u( k )*u( k )**T,   u( k ) = (   1    ),
!>                                              (   0    )
!>                                              ( z( k ) )
!>
!> tau es un escalar y z( k ) es un vector de longitud l. tau y z( k )
!> se eligen para aniquilar los elementos de la k-ésima fila de A2.
!>
!> El escalar tau se devuelve en el k-ésimo elemento de TAU y el vector
!> u( k ) en la k-ésima fila de A2, de manera que los elementos de z( k )
!> están en a( k, l + 1 ), ..., a( k, n ). Los elementos de R se devuelven en
!> la parte triangular superior de A1.
!>
!> Z se da por
!>
!>    Z =  Z( 1 ) * Z( 2 ) * ... * Z( m ).
!>
