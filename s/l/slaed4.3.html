subroutine slaed4 (integer n, integer i, real, dimension( * ) d, real, dimension( * ) z, real, dimension( * ) delta, real rho, real dlam, integer info)

SLAED4 usado por SSTEDC. Encuentra una única raíz de la ecuación secular.

Propósito:

!>
!> Esta subrutina calcula el I-ésimo valor propio actualizado de una modificación
!> simétrica de rango uno a una matriz diagonal cuyos elementos se dan en el
!> array d, y tal que
!>
!>            D(i) < D(j)  para  i < j
!>
!> y tal que RHO > 0. Esto es organizado por la rutina que llama, y no supone
!> pérdida de generalidad. El sistema modificado de rango uno es, por tanto,
!>
!>            diag( D )  +  RHO * Z * Z_transpose.
!>
!> donde asumimos que la norma euclidiana de Z es 1.
!>
!> El método consiste en aproximar las funciones racionales en la ecuación secular
!> por funciones racionales interpolantes más sencillas.
!>

Parámetros

N 
!>          N es INTEGER
!>         La longitud de todos los arrays.
!>

I

!>          I es INTEGER
!>         El índice del valor propio a calcular.  1 <= I <= N.
!>

D

!>          D es un array REAL, de dimensión (N)
!>         Los valores propios originales. Se asume que están ordenados,
!>         D(I) < D(J)  para I < J.
!>

Z

!>          Z es un array REAL, de dimensión (N)
!>         Los componentes del vector de actualización.
!>

DELTA

!>          DELTA es un array REAL, de dimensión (N)
!>         Si N > 2, DELTA contiene (D(j) - lambda_I) en su j-ésimo
!>         componente. Si N = 1, entonces DELTA(1) = 1. Si N = 2, véase SLAED5
!>         para más detalles. El vector DELTA contiene la información necesaria
!>         para construir los vectores propios mediante SLAED3 y SLAED9.
!>

RHO

!>          RHO es REAL
!>         El escalar en la fórmula de actualización simétrica.
!>

DLAM

!>          DLAM es REAL
!>         El lambda_I calculado, el I-ésimo valor propio actualizado.
!>

INFO

!>          INFO es INTEGER
!>         = 0:  salida exitosa
!>         > 0:  si INFO = 1, el proceso de actualización falló.
!>

Parámetros Internos:

!>  La variable lógica ORGATI (origin-at-i?) se utiliza para distinguir
!>  si D(i) o D(i+1) se tratan como el origen.
!>
!>            ORGATI = .true.    origen en i
!>            ORGATI = .false.   origen en i+1
!>
!>   La variable lógica SWTCH3 (switch-for-3-poles?) sirve para indicar
!>   si estamos trabajando con TRES polos.
!>
!>   MAXIT es el número máximo de iteraciones permitidas para cada
!>   valor propio.
!>
