NOMBRE

slice2js - El compilador de Slice a JavaScript.

SINOPSIS

slice2js [opciones] [archivos]

DESCRIPCIÓN

slice2js compila archivos Slice a JavaScript. La macro __SLICE2JS__ se define durante esta compilación.

La documentación completa para slice2js está disponible en línea en:
https://doc.zeroc.com/ice/3.7/language-mappings/javascript-mapping/client-side-slice-to-javascript-mapping/slice2js-command-line-options

OPCIONES

-h, --help

Muestra el mensaje de ayuda.
-v, --version
Muestra la versión del compilador.
-DNOMBRE

Define el símbolo preprocesador NOMBRE.
-D NOMBRE=DEF

Define el símbolo preprocesador NOMBRE con el valor DEF.
-UNOMBRE

Anula la definición del símbolo preprocesador NOMBRE.
-IDIR

Añade el directorio DIR a la ruta de búsqueda para las directivas #include.
-E

Imprime la salida del preprocesador en stdout.
--output-dir DIR

Coloca los archivos generados en el directorio DIR.
-d, --debug

Imprime información de depuración que muestra el funcionamiento del analizador Slice.
--depend

Imprime información de dependencias en la salida estándar por defecto, o en el archivo especificado por la opción --depend-file. No se genera código cuando se especifica esta opción.
--depend-xml

Imprime información de dependencias en formato XML en la salida estándar por defecto, o en el archivo especificado por la opción --depend-file. No se genera código cuando se especifica esta opción.
--depend-file ARCHIVO

Dirige la información de dependencias al archivo especificado. El formato de salida depende de si también se especifican --depend o --depend-xml.
--depend-json

Imprime información de dependencias en formato JSON en la salida estándar por defecto, o en el archivo especificado por la opción --depend-file. No se genera código cuando se especifica esta opción.
--validate

Comprueba la corrección de las opciones de línea de comandos proporcionadas y no genera ningún código.
--stdout

Imprime el código generado en la salida estándar.
--typescript

Genera archivos de declaración de TypeScript.
