NOMBRE

slice2objc - El compilador de Slice a Objective-C.

SINOPSIS

slice2objc [opciones] [archivos]

DESCRIPCIÓN

slice2objc compila archivos Slice a Objective-C. El macro __SLICE2OBJC__ se define durante esta compilación.

La documentación completa para slice2objc está disponible en línea en:
https://doc.zeroc.com/ice/latest/language-mappings/objective-c-mapping/client-side-slice-to-objective-c-mapping/slice2objc-command-line-options

OPCIONES

-h, --help

Muestra el mensaje de ayuda.
-v, --version
Muestra la versión del compilador.
-DNAME

Define el símbolo del preprocesador NAME.
-DNAME=DEF

Define el símbolo del preprocesador NAME con el valor DEF.
-UNAME

Anula la definición del símbolo del preprocesador NAME.
-IDIR

Agrega el directorio DIR a la ruta de búsqueda para las directivas #include.
-E

Imprime la salida del preprocesador en la salida estándar.
--output-dir DIR

Coloca los archivos generados en el directorio DIR.
-d, --debug

Imprime información de depuración que muestra el funcionamiento del analizador de Slice.
--depend

Imprime la información de dependencias en la salida estándar por defecto, o en el archivo especificado por la opción --depend-file. No se genera código cuando se especifica esta opción.
--depend-xml

Imprime la información de dependencias en formato XML en la salida estándar por defecto, o en el archivo especificado por la opción --depend-file. No se genera código cuando se especifica esta opción.
--depend-file FILE

Dirige la información de dependencias al archivo especificado. El formato de salida depende de si también se especifica --depend o --depend-xml.
--validate

Verifica la corrección de las opciones de línea de comandos proporcionadas y no genera ningún código.
--include-dir DIR

Modifica las directivas #include en los archivos fuente para anteponer el nombre de ruta de cada archivo de encabezado con el directorio DIR.
