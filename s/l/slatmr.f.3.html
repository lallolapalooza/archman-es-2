subroutine slatmr (m entero, n entero, dist carácter, iseed entero, dimensión(4), sym carácter, d real, dimensión(*) d, mode entero, cond real, dmax real, rsign carácter, grade carácter, dl real, dimensión(*) dl, model entero, condl real, dr real, dimensión(*) dr, moder entero, condr real, pivtng carácter, ipivot entero, dimensión(*) ipivot, kl entero, ku entero, sparse real, anorm real, pack carácter, a real, dimensión(lda,*) a, lda entero, iwork entero, dimensión(*) iwork, info entero)

SLATMR

Propósito:

!>
!>    SLATMR genera matrices aleatorias de varios tipos para probar
!>    programas LAPACK.
!>
!>    SLATMR opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Generar una matriz A con entradas de distribución DIST
!>         que es simétrica si SYM='S', y no simétrica
!>         si SYM='N'.
!>
!>      Establecer la diagonal a D, donde D puede ser de entrada o
!>         calculada según MODE, COND, DMAX y RSIGN
!>         como se describe a continuación.
!>
!>      Calibrar la matriz, si se desea, desde la izquierda y/o derecha
!>         según lo especificado por GRADE. Las entradas DL, MODEL, CONDL, DR,
!>         MODER y CONDR también determinan la calibración como se describe
!>         a continuación.
!>
!>      Permutar, si se desea, las filas y/o columnas según lo especificado por
!>         PIVTNG e IPIVOT.
!>
!>      Establecer entradas aleatorias a cero, si se desea, para obtener una matriz
!>         aleatoria dispersa según lo especificado por SPARSE.
!>
!>      Hacer de A una matriz de banda, si se desea, poniendo a cero la matriz
!>         fuera de una banda de ancho inferior KL y ancho superior KU.
!>
!>      Escalar A, si se desea, para que tenga una entrada máxima ANORM.
!>
!>      Empaquetar la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetar
!>         poner a cero la mitad superior (si es simétrica)
!>         poner a cero la mitad inferior (si es simétrica)
!>         almacenar la mitad superior por columnas (si es simétrica o
!>             triangular superior cuadrada)
!>         almacenar la mitad inferior por columnas (si es simétrica o
!>             triangular inferior cuadrada)
!>             igual que la mitad superior por filas si es simétrica
!>         almacenar el triángulo inferior en formato de banda (si es simétrica)
!>         almacenar el triángulo superior en formato de banda (si es simétrica)
!>         almacenar toda la matriz en formato de banda
!>
!>    Nota: Si dos llamadas a SLATMR difieren solo en el parámetro PACK,
!>          generarán matrices matemáticamente equivalentes.
!>
!>          Si dos llamadas a SLATMR tienen ambas ancho de banda completo (KL = M-1
!>          y KU = N-1), y difieren solo en los parámetros PIVTNG y PACK,
!>          entonces las matrices generadas diferirán solo
!>          en el orden de las filas y/o columnas, y de lo contrario
!>          contendrán los mismos datos. Esta consistencia no se mantiene
!>          con un ancho de banda menor al completo.
!>

Parámetros

M 
!>          M es ENTERO
!>           Número de filas de A. No modificado.
!>

N

!>          N es ENTERO
!>           Número de columnas de A. No modificado.
!>

DIST

!>          DIST es CARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución que se utilizará
!>           para generar una matriz aleatoria.
!>           'U' => UNIFORME( 0, 1 )  ('U' para uniforme)
!>           'S' => UNIFORME( -1, 1 ) ('S' para simétrica)
!>           'N' => NORMAL( 0, 1 )   ('N' para normal)
!>           No modificado.
!>

ISEED

!>          ISEED es un array ENTERO, dimensión (4)
!>           En la entrada, ISEED especifica la semilla del generador de números
!>           aleatorios. Deben estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           utiliza una secuencia congruencial lineal limitada a enteros pequeños,
!>           y por lo tanto debe producir números aleatorios independientes de la máquina.
!>           Los valores de ISEED se modifican al salir, y pueden usarse en la siguiente llamada
!>           a SLATMR para continuar la misma secuencia de números aleatorios.
!>           Modificado al salir.
!>

SYM

!>          SYM es CARACTER*1
!>           Si SYM='S' o 'H', la matriz generada es simétrica.
!>           Si SYM='N', la matriz generada no es simétrica.
!>           No modificado.
!>

D

!>          D es un array REAL, dimensión (min(M,N))
!>           En la entrada, este array especifica las entradas diagonales
!>           de la diagonal de A. D puede ser especificado
!>           en la entrada, o establecido según MODE y COND como se describe
!>           a continuación. Puede modificarse al salir si MODE es distinto de cero.
!>

MODE

!>          MODE es ENTERO
!>           En la entrada describe cómo se utilizará D:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1.
!>           No modificado.
!>

COND

!>          COND es REAL
!>           En la entrada, se utiliza como se describe en MODE arriba.
!>           Si se utiliza, debe ser >= 1. No modificado.
!>

DMAX

!>          DMAX es REAL
!>           Si MODE no es -6, 0 ni 6, la diagonal se escala por
!>           DMAX / max(abs(D(i))), de modo que la entrada máxima absoluta
!>           de la diagonal sea abs(DMAX). Si DMAX es negativo (o cero),
!>           la diagonal se escalará por un número negativo (o cero).
!>

RSIGN

!>          RSIGN es CARACTER*1
!>           Si MODE no es -6, 0 ni 6, especifica el signo de la diagonal
!>           de la siguiente manera:
!>           'T' => las entradas diagonales se multiplican por 1 o -1
!>                  con probabilidad 0.5
!>           'F' => diagonal sin cambios
!>           No modificado.
!>

GRADE

!>          GRADE es CARACTER*1
!>           Especifica la calibración de la matriz de la siguiente manera:
!>           'N'  => sin calibración
!>           'L'  => la matriz se premultiplica por diag( DL )
!>                   (solo si la matriz no es simétrica)
!>           'R'  => la matriz se postmultiplica por diag( DR )
!>                   (solo si la matriz no es simétrica)
!>           'B'  => la matriz se premultiplica por diag( DL ) y
!>                         se postmultiplica por diag( DR )
!>                   (solo si la matriz no es simétrica)
!>           'S' o 'H'  => la matriz se premultiplica por diag( DL ) y
!>                          se postmultiplica por diag( DL )
!>                          ('S' para simétrica, o 'H' para Hermitiana)
!>           'E'  => la matriz se premultiplica por diag( DL ) y
!>

postmultiplied by inv( diag( DL ) ) !> ( 'E' para invarianza del valor propio) !> (solo si la matriz no es simétrica) !> Nota: si GRADE='E', entonces M debe ser igual a N. !> No modificado. !>

DL

!>          DL es un array REAL, de dimensión (M)
!>           Si MODEL=0, entonces a la entrada, este array especifica las
!>           entradas diagonales de una matriz diagonal utilizada como se
!>           describe anteriormente bajo GRADE. Si MODEL no es cero, entonces
!>           DL se establecerá de acuerdo con MODEL y CONDL, de forma
!>           análoga a cómo D se establece de acuerdo con MODE y COND
!>           (excepto que no hay parámetro DMAX para DL).
!>           Si GRADE='E', entonces DL no puede tener entradas cero.
!>           No referenciado si GRADE = 'N' o 'R'. Modificado a la salida.
!>

MODEL

!>          MODEL es un INTEGER
!>           Esto especifica cómo se va a calcular el array diagonal DL,
!>           tal como MODE especifica cómo se va a calcular D.
!>           No modificado.
!>

CONDL

!>          CONDL es un REAL
!>           Cuando MODEL no es cero, esto especifica el número de
!>           condicionamiento de DL calculado. No modificado.
!>

DR

!>          DR es un array REAL, de dimensión (N)
!>           Si MODER=0, entonces a la entrada, este array especifica las
!>           entradas diagonales de una matriz diagonal utilizada como se
!>           describe anteriormente bajo GRADE. Si MODER no es cero, entonces
!>           DR se establecerá de acuerdo con MODER y CONDR, de forma
!>           análoga a cómo D se establece de acuerdo con MODE y COND
!>           (excepto que no hay parámetro DMAX para DR).
!>           No referenciado si GRADE = 'N', 'L', 'H', 'S' o 'E'.
!>           Modificado a la salida.
!>

MODER

!>          MODER es un INTEGER
!>           Esto especifica cómo se va a calcular el array diagonal DR,
!>           tal como MODE especifica cómo se va a calcular D.
!>           No modificado.
!>

CONDR

!>          CONDR es un REAL
!>           Cuando MODER no es cero, esto especifica el número de
!>           condicionamiento de DR calculado. No modificado.
!>

PIVTNG

!>          PIVTNG es CHARACTER*1
!>           A la entrada especifica las permutaciones de pivote como sigue:
!>           'N' o ' ' => ninguna.
!>           'L' => pivote izquierdo o de fila (la matriz debe ser no
!>                  simétrica).
!>           'R' => pivote derecho o de columna (la matriz debe ser
!>                  no simétrica).
!>           'B' o 'F' => ambos o pivote completo, es decir, en ambos lados.
!>                         En este caso, M debe ser igual a N
!>
!>           Si dos llamadas a SLATMR tienen ambos ancho de banda completo
!>           (KL = M-1 y KU = N-1), y difieren solo en los parámetros PIVTNG y
!>           PACK, entonces las matrices generadas diferirán solo en el orden
!>           de las filas y/o columnas, y de lo contrario contendrán los mismos
!>           datos. Esta consistencia no se puede mantener con un ancho de
!>           banda menor que el completo.
!>

IPIVOT

!>          IPIVOT es un array INTEGER, de dimensión (N o M)
!>           Este array especifica la permutación utilizada. Después de
!>           generar la matriz básica, las filas, columnas o ambas se
!>           permutan. Si, por ejemplo, se selecciona el pivote de fila,
!>           SLATMR comienza con la *última* fila e intercambia la M-ésima
!>           y la IPIVOT(M)-ésima fila, luego pasa a la penúltima fila,
!>           intercambiando la (M-1)-ésima y la IPIVOT(M-1)-ésima fila,
!>           y así sucesivamente. En términos de , la permutación es
!>           (1 IPIVOT(1)) (2 IPIVOT(2)) ... (M IPIVOT(M))
!>           donde el ciclo más a la derecha se aplica primero. Este es el
!>           *inverso* del efecto del pivote en LINPACK. La idea es que
!>           factorizar (con pivote) una matriz identidad que ha sido
!>           inverse-pivoted de esta manera debería resultar en un vector
!>           pivote idéntico a IPIVOT.
!>           No referenciado si PIVTNG = 'N'. No modificado.
!>

KL

!>          KL es un INTEGER
!>           A la entrada, especifica el ancho de banda inferior de la
!>           matriz. Por ejemplo, KL=0 implica triangular superior,
!>           KL=1 implica Hessenberg superior, y KL al menos M-1 implica
!>           que la matriz no tiene banda. Debe ser igual a KU si la
!>           matriz es simétrica.
!>           No modificado.
!>

KU

!>          KU es un INTEGER
!>           A la entrada, especifica el ancho de banda superior de la
!>           matriz. Por ejemplo, KU=0 implica triangular inferior,
!>           KU=1 implica Hessenberg inferior, y KU al menos N-1 implica
!>           que la matriz no tiene banda. Debe ser igual a KL si la
!>           matriz es simétrica.
!>           No modificado.
!>

SPARSE

!>          SPARSE es un REAL
!>           A la entrada, especifica la dispersión de la matriz si se va
!>           a generar una matriz dispersa. SPARSE debe estar entre 0 y
!>           1. Para generar una matriz dispersa, para cada entrada de la
!>           matriz, se genera un número aleatorio uniforme (0, 1), x, y
!>           se compara con SPARSE; si x es mayor, la entrada de la matriz
!>           no se modifica y si x es menor, la entrada se establece en
!>           cero. Por lo tanto, en promedio, una fracción SPARSE de las
!>           entradas se establecerá en cero.
!>           No modificado.
!>

ANORM

!>          ANORM es un REAL
!>           A la entrada, especifica la entrada máxima de la matriz de
!>           salida (la matriz de salida se multiplicará por una constante
!>           para que su entrada de valor absoluto más grande sea igual a
!>           ANORM) si ANORM es no negativo. Si ANORM es negativo, no se
!>           realiza ningún escalado. No modificado.
!>

PACK

!>          PACK es CHARACTER*1
!>           A la entrada, especifica el empaquetado de la matriz como
!>           sigue:
!>           'N' => sin empaquetado
!>           'U' => poner a cero todas las entradas subdiagonales (si es
!>                  simétrica)
!>           'L' => poner a cero todas las entradas superdiagonales (si es
!>                  simétrica)
!>           'C' => almacenar el triángulo superior por columnas
!>                  (solo si la matriz es simétrica o triangular superior
!>                  cuadrada)
!>           'R' => almacenar el triángulo inferior por columnas
!>                  (solo si la matriz es simétrica o triangular inferior
!>                  cuadrada)
!>                  (igual que la mitad superior por filas si es simétrica)
!>           'B' => almacenar el triángulo inferior en el esquema de
!>                  almacenamiento de banda (solo si la matriz es simétrica)
!>           'Q' => almacenar el triángulo superior en el esquema de
!>                  almacenamiento de banda (solo si la matriz es simétrica)
!>           'Z' => almacenar toda la matriz en el esquema de
!>                  almacenamiento de banda
!>                      (el pivote puede ser proporcionado utilizando esta
!>                      opción para almacenar A en las filas finales del
!>                      almacenamiento asignado)
!>
!>           Utilizando estas opciones, se pueden obtener los diversos esquemas
!>           de almacenamiento empaquetado y de banda de LAPACK:
!>           GB               - usar 'Z'
!>           PB, SB o TB     - usar 'B' o 'Q'
!>           PP, SP o TP     - usar 'C' o 'R'
!>
!>           Si dos llamadas a SLATMR difieren solo en el parámetro PACK,
!>           generarán matrices matemáticamente equivalentes.
!>           No modificado.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>           A la salida, A es la matriz de prueba deseada. Solo aquellas
!>           entradas de A que son significativas a la salida serán
!>           referenciadas (incluso si A está en formato de almacenamiento
!>           empaquetado o de banda). Las 'esquinas no ocupadas' de A en
!>           formato de banda se pondrán a cero.
!>

LDA

!>          LDA es un INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal como
!>           se declaró en el programa llamante.
!>           Si PACK='N', 'U' o 'L', LDA debe ser al menos max ( 1, M ).
!>           Si PACK='C' o 'R', LDA debe ser al menos 1.
!>           Si PACK='B' o 'Q', LDA debe ser MIN ( KU+1, N )
!>           Si PACK='Z', LDA debe ser al menos KUU+KLL+1, donde
!>           KUU = MIN ( KU, N-1 ) y KLL = MIN ( KL, M-1 )
!>           No modificado.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión ( N o M)
!>           Espacio de trabajo. No referenciado si PIVTNG = 'N'. Modificado a
!>           la salida.
!>

INFO

!>          INFO es un INTEGER
!>           Parámetro de error a la salida:
!>             0 => retorno normal
!>            -1 => M negativo o desigual a N y SYM='S' o 'H'
!>            -2 => N negativo
!>            -3 => DIST cadena ilegal
!>            -5 => SYM cadena ilegal
!>            -7 => MODE no está en el rango -6 a 6
!>            -8 => COND menor que 1.0, y MODE no es -6, 0 ni 6
!>           -10 => MODE no es -6, 0 ni 6 y RSIGN cadena ilegal
!>           -11 => GRADE cadena ilegal, o GRADE='E' y
!>                  M no es igual a N, o GRADE='L', 'R', 'B' o 'E' y
!>                  SYM = 'S' o 'H'
!>           -12 => GRADE = 'E' y DL contiene cero
!>           -13 => MODEL no está en el rango -6 a 6 y GRADE= 'L', 'B', 'H',
!>                  'S' o 'E'
!>           -14 => CONDL menor que 1.0, GRADE='L', 'B', 'H', 'S' o 'E',
!>                  y MODEL no es -6, 0 ni 6
!>           -16 => MODER no está en el rango -6 a 6 y GRADE= 'R' o 'B'
!>           -17 => CONDR menor que 1.0, GRADE='R' o 'B', y
!>                  MODER no es -6, 0 ni 6
!>           -18 => PIVTNG cadena ilegal, o PIVTNG='B' o 'F' y
!>                  M no es igual a N, o PIVTNG='L' o 'R' y SYM='S'
!>                  o 'H'
!>           -19 => IPIVOT contiene número fuera de rango y
!>                  PIVTNG no es igual a 'N'
!>           -20 => KL negativo
!>           -21 => KU negativo, o SYM='S' o 'H' y KU no es igual a KL
!>           -22 => SPARSE no está en el rango 0. a 1.
!>           -24 => PACK cadena ilegal, o PACK='U', 'L', 'B' o 'Q'
!>                  y SYM='N', o PACK='C' y SYM='N' y ya sea KL
!>                  no es igual a 0 o N no es igual a M, o PACK='R' y
!>                  SYM='N', y ya sea KU no es igual a 0 o N no es
!>                  igual a M
!>           -26 => LDA es demasiado pequeño
!>             1 => Retorno de error de SLATM1 (cálculo de D)
!>             2 => No se puede escalar la diagonal a DMAX (la entrada máxima es 0)
!>             3 => Retorno de error de SLATM1 (cálculo de DL)
!>             4 => Retorno de error de SLATM1 (cálculo de DR)
!>             5 => ANORM es positivo, pero la matriz construida antes de
!>                  intentar escalarla para que tenga norma ANORM, es cero
!>
