función real slantp (norma, uplo, diag, n, ap, trabajo)
SLANTP devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz triangular suministrada en forma empaquetada.

Documentación de Función/Subrutina

función real slantp (carácter norma, carácter uplo, carácter diag, entero n, real, dimensión( * ) ap, real, dimensión( * ) trabajo)

SLANTP devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz triangular suministrada en forma empaquetada.

Propósito:

!>
!> SLANTP  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma  infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz triangular A, suministrada en forma empaquetada.
!>

Devuelve

SLANTP 
!>
!>    SLANTP = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma  infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORMA 
!>          NORMA es CARACTER*1
!>          Especifica el valor que se devolverá en SLANTP como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

DIAG

!>          DIAG es CARACTER*1
!>          Especifica si la matriz A es unitaria o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, SLANTP se
!>          establece a cero.
!>

AP

!>          AP es arreglo REAL, dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por
!>          columnas en un arreglo lineal.  La j-ésima columna de A se
!>          almacena en el arreglo AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Tenga en cuenta que cuando DIAG = 'U', los elementos del arreglo AP
!>          correspondientes a los elementos diagonales de la matriz A
!>          no se referencian, sino que se asumen como uno.
!>

TRABAJO

!>          TRABAJO es arreglo REAL, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORMA = 'I'; de lo contrario, TRABAJO no
!>          se referencia.
!>
