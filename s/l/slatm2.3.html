real function slatm2 (integer m, integer n, integer i, integer j, integer kl, integer ku, integer idist, integer, dimension( 4 ) iseed, real, dimension( * ) d, integer igrade, real, dimension( * ) dl, real, dimension( * ) dr, integer ipvtng, integer, dimension( * ) iwork, real sparse)

SLATM2

Propósito:

!>
!>    SLATM2 devuelve la entrada (I,J) de una matriz aleatoria descrita
!>    por los otros parámetros. Es llamada por la rutina SLATMR para construir
!>    matrices de prueba aleatorias. No se realiza comprobación de errores
!>    en los parámetros, ya que esta rutina es llamada en un bucle ajustado
!>    por SLATMR, que ya ha comprobado los parámetros.
!>
!>    El uso de SLATM2 difiere de SLATM3 en el orden en que se llama al
!>    generador de números aleatorios para rellenar las entradas de la
!>    matriz aleatoria. Con SLATM2, el generador se llama para rellenar
!>    la matriz pivotada columna a columna. Con SLATM3, el generador se
!>    llama para rellenar la matriz columna a columna, después de lo cual
!>    se pivota. Por lo tanto, SLATM3 puede usarse para construir matrices
!>    aleatorias que solo difieren en el orden de sus filas y/o columnas.
!>    SLATM2 se usa para construir matrices de banda evitando llamar al
!>    generador de números aleatorios para las entradas fuera de la banda
!>    (y, por lo tanto, generando números aleatorios
!>
!>    La matriz cuya entrada (I,J) se devuelve se construye de la siguiente
!>    manera (esta rutina solo calcula una entrada):
!>
!>      Si I está fuera de (1..M) o J está fuera de (1..N), devuelve cero
!>         (esto es conveniente para generar matrices en formato de banda).
!>
!>      Genera una matriz A con entradas aleatorias de distribución IDIST.
!>
!>      Establece la diagonal a D.
!>
!>      Califica la matriz, si se desea, desde la izquierda (por DL) y/o
!>         desde la derecha (por DR o DL) según lo especificado por IGRADE.
!>
!>      Permuta, si se desea, las filas y/o columnas según lo especificado
!>         por IPVTNG y IWORK.
!>
!>      Pone la matriz en formato de banda para tener un ancho de banda inferior
!>         KL y un ancho de banda superior KU.
!>
!>      Establece entradas aleatorias a cero según lo especificado por SPARSE.
!>

Parámetros

M 
!>          M is INTEGER
!>           Número de filas de la matriz. No modificado.
!>

N

!>          N is INTEGER
!>           Número de columnas de la matriz. No modificado.
!>

I

!>          I is INTEGER
!>           Fila de la entrada a devolver. No modificado.
!>

J

!>          J is INTEGER
!>           Columna de la entrada a devolver. No modificado.
!>

KL

!>          KL is INTEGER
!>           Ancho de banda inferior. No modificado.
!>

KU

!>          KU is INTEGER
!>           Ancho de banda superior. No modificado.
!>

IDIST

!>          IDIST is INTEGER
!>           En la entrada, IDIST especifica el tipo de distribución a
!>           utilizar para generar una matriz aleatoria.
!>           1 => UNIFORME( 0, 1 )
!>           2 => UNIFORME( -1, 1 )
!>           3 => NORMAL( 0, 1 )
!>           No modificado.
!>

ISEED

!>          ISEED is INTEGER array of dimension ( 4 )
!>           Semilla para el generador de números aleatorios.
!>           Cambiado en la salida.
!>

D

!>          D is REAL array of dimension ( MIN( I , J ) )
!>           Entradas de la diagonal de la matriz. No modificado.
!>

IGRADE

!>          IGRADE is INTEGER
!>           Especifica la calificación de la matriz de la siguiente manera:
!>           0  => sin calificación
!>           1  => matriz premultiplicada por diag( DL )
!>           2  => matriz postmultiplicada por diag( DR )
!>           3  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>           4  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>           5  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>           No modificado.
!>

DL

!>          DL is REAL array ( I or J, según corresponda )
!>           Factores de escala izquierdos para la calificación de la matriz. No
!>           modificado.
!>

DR

!>          DR is REAL array ( I or J, según corresponda )
!>           Factores de escala derechos para la calificación de la matriz. No
!>           modificado.
!>

IPVTNG

!>          IPVTNG is INTEGER
!>           En la entrada, especifica las permutaciones de pivoteo de la
!>           siguiente manera:
!>           0 => ninguna.
!>           1 => pivoteo de filas.
!>           2 => pivoteo de columnas.
!>           3 => pivoteo completo, es decir, en ambos lados.
!>           No modificado.
!>

IWORK

!>          IWORK is INTEGER array ( I or J, según corresponda )
!>           Esta matriz especifica la permutación utilizada. La fila
!>           (o columna) en la posición K estaba originalmente en la posición
!>           IWORK( K ).
!>           Esto difiere de IWORK para SLATM3. No modificado.
!>

SPARSE

!>          SPARSE is REAL entre 0. y 1.
!>           En la entrada, especifica la escasez de la matriz si se va a
!>           generar una matriz dispersa. SPARSE debe estar entre 0 y 1.
!>           Se genera un número aleatorio uniforme (0, 1), x, y se compara
!>           con SPARSE; si x es mayor, la entrada de la matriz no cambia, y
!>           si x es menor, la entrada se establece a cero. Por lo tanto, en
!>           promedio, una fracción SPARSE de las entradas se establecerá a
!>           cero.
!>           No modificado.
!>
