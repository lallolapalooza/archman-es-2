NOMBRE

slapdn - Comprueba una lista de DN de LDAP representados en cadena basándose en la sintaxis del esquema

SINOPSIS

/usr/bin/slapdn [-d nivel-debug] [-f slapd.conf] [-F confdir] [-N|-P] [-o opción[=valor]] [-v] DN [...]

DESCRIPCIÓN

Slapdn se utiliza para comprobar la conformidad de un DN basándose en el esquema definido en slapd(8) y en el cargado a través de slapd.conf(5). Abre el archivo de configuración slapd.conf(5) o el backend slapd-config(5), lee las definiciones del esquema y luego analiza la lista de DN proporcionada en la línea de comandos.

OPCIONES

-d nivel-debug
habilita los mensajes de depuración definidos por el nivel-debug especificado; consulta slapd(8) para más detalles.
-f slapd.conf
especifica un archivo slapd.conf(5) alternativo.
-F confdir
especifica un directorio de configuración. Si se especifican tanto -f como -F, se leerá el archivo de configuración y se convertirá al formato de directorio de configuración y se escribirá en el directorio especificado. Si no se especifica ninguna de las opciones, se intentará leer el directorio de configuración predeterminado antes de intentar utilizar el archivo de configuración predeterminado. Si existe un directorio de configuración válido, se ignorará el archivo de configuración predeterminado.
-N
solo produce una forma normalizada del DN, adecuada para ser utilizada en una herramienta de normalización; incompatible con -P.
-o opción[=valor]
especifica una opción con un valor (opcional). Las opciones/valores genéricos posibles son:
              syslog=<subsistemas>  (ver `-s' en slapd(8))
              syslog-level=<nivel> (ver `-S' en slapd(8))
              syslog-user=<usuario>   (ver `-l' en slapd(8))
-P
solo produce una forma "prettified" (formateada para ser legible) del DN, adecuada para ser utilizada en una herramienta de comprobación y embellecimiento; incompatible con -N.
-v
habilita el modo detallado (verbose).

EJEMPLOS

Para comprobar un DN, introduce el comando:

/usr/bin/slapdn -f //etc/openldap/slapd.conf -v DN
