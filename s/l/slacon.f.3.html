Documentación de función/subrutina

subrutina slacon (integer n, real, dimension( * ) v, real, dimension( * ) x, integer, dimension( * ) isgn, real est, integer kase)

SLACON estima la 1-norma de una matriz cuadrada y real, utilizando comunicación inversa para evaluar productos matriz-vector.

Propósito:

!>
!> SLACON estima la 1-norma de una matriz cuadrada real A.
!> Se utiliza comunicación inversa para evaluar productos matriz-vector.
!>

Parámetros

N 
!>          N es INTEGER
!>         El orden de la matriz.  N >= 1.
!>

V

!>          V es un array REAL, dimension (N)
!>         En el retorno final, V = A*W,  donde  EST = norm(V)/norm(W)
!>         (W no se retorna).
!>

X

!>          X es un array REAL, dimension (N)
!>         En un retorno intermedio, X debe ser sobrescrito por
!>               A * X,   si KASE=1,
!>               A**T * X,  si KASE=2,
!>         y SLACON debe ser llamado de nuevo con todos los demás parámetros
!>         sin cambios.
!>

ISGN

!>          ISGN es un array INTEGER, dimension (N)
!>

EST

!>          EST es REAL
!>         Al entrar con KASE = 1 o 2 y JUMP = 3, EST debe ser
!>         sin cambios desde la llamada anterior a SLACON.
!>         Al salir, EST es una estimación (un límite inferior) para norm(A).
!>

KASE

!>          KASE es INTEGER
!>         En la llamada inicial a SLACON, KASE debe ser 0.
!>         En un retorno intermedio, KASE será 1 o 2, indicando
!>         si X debe ser sobrescrito por A * X  o A**T * X.
!>         En el retorno final desde SLACON, KASE volverá a ser 0.
!>
