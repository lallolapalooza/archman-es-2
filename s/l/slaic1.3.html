subroutine slaic1 (integer job, integer j, real, dimension( j ) x, real sest, real, dimension( j ) w, real gamma, real sestpr, real s, real c)

SLAIC1 aplica un paso de estimación incremental de la condición.

Propósito:

!>
!> SLAIC1 aplica un paso de estimación incremental de la condición en
!> su versión más simple:
!>
!> Sea x, twonorm(x) = 1, un vector singular aproximado de una matriz L
!> triangular inferior j por j, tal que
!>          twonorm(L*x) = sest
!> Entonces SLAIC1 computa sestpr, s, c tales que
!> el vector
!>                 [ s*x ]
!>          xhat = [  c  ]
!> es un vector singular aproximado de
!>                 [ L      0  ]
!>          Lhat = [ w**T gamma ]
!> en el sentido de que
!>          twonorm(Lhat*xhat) = sestpr.
!>
!> Dependiendo de JOB, se estima el valor singular más grande o más pequeño.
!>
!> Nótese que [s c]**T y sestpr**2 es un par propio del sistema
!>
!>     diag(sest*sest, 0) + [alpha  gamma] * [ alpha ]
!>                                           [ gamma ]
!>
!> donde  alpha =  x**T*w.
!>

Parámetros

JOB 
!>          JOB es INTEGER
!>          = 1: se estima el valor singular más grande.
!>          = 2: se estima el valor singular más pequeño.
!>

J

!>          J es INTEGER
!>          Longitud de X y W
!>

X

!>          X es un array REAL, dimensión (J)
!>          El vector j x.
!>

SEST

!>          SEST es REAL
!>          Valor singular estimado de la matriz L de j por j
!>

W

!>          W es un array REAL, dimensión (J)
!>          El vector j w.
!>

GAMMA

!>          GAMMA es REAL
!>          El elemento diagonal gamma.
!>

SESTPR

!>          SESTPR es REAL
!>          Valor singular estimado de la matriz Lhat de (j+1) por (j+1).
!>

S

!>          S es REAL
!>          Seno necesario para formar xhat.
!>

C

!>          C es REAL
!>          Coseno necesario para formar xhat.
!>
