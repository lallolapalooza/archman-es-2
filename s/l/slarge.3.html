Documentación de la función/subrutina

subrutina slarge (entero n, real, dimensión( lda, * ) a, entero lda, entero, dimensión( 4 ) iseed, real, dimensión( * ) work, entero info)

SLARGE

Propósito:

!>
!> SLARGE pre y post-multiplica una matriz real general n por n A
!> con una matriz ortogonal aleatoria: A = U*D*U'.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz original A de n por n.
!>          En la salida, A es sobrescrito por U*A*U' para alguna matriz
!>          ortogonal aleatoria U.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= N.
!>

ISEED

!>          ISEED es un array ENTERO, dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios; los elementos
!>          del array deben estar entre 0 y 4095, e ISEED(4) debe ser impar.
!>          En la salida, la semilla se actualiza.
!>

WORK

!>          WORK es un array REAL, dimensión (2*N)
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
