SLAPPW-ARGON2(5) Manual de Formatos de Archivo SLAPPW-ARGON2(5)

NOMBRE

slappw-argon2 - Módulo de contraseña Argon2 para slapd

SINOPSIS

/etc/openldap/slapd.conf

moduleload argon2 [<parámetros>]

DESCRIPCIÓN

El módulo argon2 para slapd(8) proporciona soporte para el uso de la función de derivación de clave Argon2, que fue seleccionada como ganadora de la Competición de Hashing de Contraseñas en julio de 2015, en contraseñas hasheadas en OpenLDAP.

Lo hace proporcionando el esquema de contraseña adicional {ARGON2} para su uso en slapd.

CONFIGURACIÓN

El módulo argon2 no necesita configuración, pero puede ser configurado proporcionando los siguientes parámetros:

m=<memoria>
Establece el uso de memoria a <memoria> kiB.
p=<paralelismo>
Establece el paralelismo a <paralelismo> hilos. Actualmente soportado solo cuando se enlaza con libargon2.
t=<iteraciones>
Establece el número de iteraciones a <iteraciones>.

Estos reemplazan los valores predeterminados al preparar hashes para nuevas contraseñas cuando sea posible.

Después de cargar el módulo, el esquema de contraseña {ARGON2} será reconocido en los valores del atributo userPassword.

Puedes instruir a OpenLDAP para que use este esquema al procesar las operaciones extendidas de Modificación de Contraseña LDAPv3 (RFC 3062) usando la opción password-hash en slapd.conf(5):

password-hash {ARGON2}

NOTAS

Si deseas usar el esquema descrito aquí con slappasswd(8), recuerda cargar el módulo usando sus opciones de línea de comandos. La opción/valor relevante es:

-o module-load=argon2

O si se requieren parámetros no predeterminados:

-o module-load="argon2 [<param>...]"

Dependiendo de la ubicación de argon2, también podrías necesitar:

-o module-path=spec_ruta

EJEMPLOS

Ambos atributos de usuario de contraseña LDAP a continuación codifican la contraseña 'secret' usando diferentes sales:

userPassword: {ARGON2}$argon2i$v=19$m=4096,t=3,p=1$c2FsdHNhbHQ$DKlexoEJUoZTmkAAC3SaMWk30El9/RvVhlqGo6afIng
userPassword: {ARGON2}$argon2i$v=19$m=4096,t=3,p=1$c2FsdHNhbHRzYWx0$qOCkx9nMeFlaGOO4DUmPDgrlUbgMMuO9T1+vQCFuyzw
