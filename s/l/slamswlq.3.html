Documentación de Función/Subrutina

subroutine slamswlq (character side, character trans, integer m, integer n, integer k, integer mb, integer nb, real, dimension( lda, * ) a, integer lda, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer lwork, integer info)

SLAMSWLQ

Propósito

!>
!>    SLAMSWLQ sobrescribe la matriz real general M por N, C, con
!>
!>
!>                    SIDE = 'L'     SIDE = 'R'
!>    TRANS = 'N':      Q * C          C * Q
!>    TRANS = 'T':      Q**T * C       C * Q**T
!>    donde Q es una matriz ortogonal real definida como el producto de
!>    reflectores elementales en bloque calculados por la factorización LQ
!>    de ancho corto (SLASWLQ).
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplica Q o Q**T desde la Izquierda;
!>          = 'R': aplica Q o Q**T desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplica Q;
!>          = 'T':  Transpuesta, aplica Q**T.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.  M >=0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          M >= K >= 0;
!>
!>

MB

!>          MB es INTEGER
!>          El tamaño del bloque de filas a usar en la LQ en bloque.
!>          M >= MB >= 1
!>

NB

!>          NB es INTEGER
!>          El tamaño del bloque de columnas a usar en la LQ en bloque.
!>          NB > M.
!>

A

!>          A es array REAL, dimensión
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ésima fila debe contener el vector que define el reflector
!>          elemental en bloque H(i), para i = 1,2,...,k, como lo devuelve
!>          SLASWLQ en las primeras k filas de su array argumento A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,K).
!>

T

!>          T es array REAL, dimensión
!>          ( M * Number of blocks(CEIL(N-K/NB-K)),
!>          Los reflectores de bloque triangulares superiores en bloque almacenados
!>          en forma compacta como una secuencia de bloques triangulares superiores.
!>          Ver más abajo para más detalles.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.  LDT >= MB.
!>

C

!>          C es array REAL, dimensión (LDC,N)
!>          A la entrada, la matriz C de M por N.
!>          A la salida, C se sobrescribe con Q*C o Q**T*C o C*Q**T o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          (espacio de trabajo) array REAL, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK mínimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>
!>          Si MIN(M,N,K) = 0, LWORK >= 1.
!>          Si SIDE = 'L', LWORK >= max(1,NB*MB).
!>          Si SIDE = 'R', LWORK >= max(1,M*MB).
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño mínimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales

!> La Factorización LQ de Ancho Corto (SWLQ) realiza LQ mediante una secuencia de
!> transformaciones ortogonales, representando Q como un producto de otras matrices
!> ortogonales
!>   Q = Q(1) * Q(2) * . . . * Q(k)
!> donde cada Q(i) pone a cero las entradas de la superdiagonal de un bloque de NB filas de A:
!>   Q(1) pone a cero las entradas de la superdiagonal de las filas 1:NB de A
!>   Q(2) pone a cero las filas inferiores MB-N de las filas [1:M,NB+1:2*NB-M] de A
!>   Q(3) pone a cero las filas inferiores MB-N de las filas [1:M,2*NB-M+1:3*NB-2*M] de A
!>   . . .
!>
!> Q(1) se calcula mediante GELQT, que representa Q(1) por vectores de Householder
!> almacenados bajo la diagonal de las filas 1:MB de A, y por reflectores de bloque
!> triangulares superiores, almacenados en el array T(1:LDT,1:N).
!> Para más información ver Detalles Adicionales en GELQT.
!>
!> Q(i) para i>1 se calcula mediante TPLQT, que representa Q(i) por vectores de Householder
!> almacenados en las columnas [(i-1)*(NB-M)+M+1:i*(NB-M)+M] de A, y por reflectores de bloque
!> triangulares superiores, almacenados en el array T(1:LDT,(i-1)*M+1:i*M).
!> La última Q(k) puede usar menos filas.
!> Para más información ver Detalles Adicionales en TPLQT.
!>
!> Para más detalles del algoritmo general, ver la descripción de
!> TSQR Secuencial en la Sección 2.2 de [1].
!>
!> [1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
!>     J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
!>     SIAM J. Sci. Comput, vol. 34, no. 1, 2012
!>
