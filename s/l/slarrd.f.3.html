SLARRD calcula los valores propios de una matriz tridiagonal simétrica con la precisión adecuada.

Documentación de Función/Subrutina

subrutina slarrd (carácter range, carácter order, entero n, real vl, real vu, entero il, entero iu, real, dimension( * ) gers, real reltol, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) e2, real pivmin, entero nsplit, entero, dimension( * ) isplit, entero m, real, dimension( * ) w, real, dimension( * ) werr, real wl, real wu, entero, dimension( * ) iblock, entero, dimension( * ) indexw, real, dimension( * ) work, entero, dimension( * ) iwork, entero info)

SLARRD calcula los valores propios de una matriz tridiagonal simétrica con la precisión adecuada. Esta es una rutina auxiliar que se llama desde SSTEMR. El usuario puede solicitar todos los valores propios, todos los valores propios en el intervalo semiabierto (VL, VU], o los valores propios del IL-ésimo al IU-ésimo. Para evitar desbordamientos, la matriz debe ser escalada de modo que su elemento más grande no sea mayor que overflow**(1/2) * underflow**(1/4) en valor absoluto, y para la máxima precisión, no debe ser mucho menor que eso. Véase W. Kahan, Report CS41, Departamento de Ciencias de la Computación, Universidad de Stanford, 21 de julio de 1966.

Parámetros

RANGE 
!>          RANGE es CHARACTER*1
!>          = 'A': ()   se encontrarán todos los valores propios.
!>          = 'V': () se encontrarán todos los valores propios en el intervalo semiabierto
!>                           (VL, VU].
!>          = 'I': () se encontrarán los valores propios del IL-ésimo al IU-ésimo (de
!>                           la matriz completa).
!>

ORDER

!>          ORDER es CHARACTER*1
!>          = 'B': () los valores propios se agruparán por
!>                              bloque de separación (ver IBLOCK, ISPLIT) y
!>                              se ordenarán de menor a mayor dentro de
!>                              cada bloque.
!>          = 'E': ()
!>                              los valores propios de la matriz completa
!>                              se ordenarán de menor a
!>                              mayor.
!>

N

!>          N es INTEGER
!>          El orden de la matriz tridiagonal T.  N >= 0.
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios.  Los valores propios menores o iguales
!>          a VL, o mayores que VU, no se devolverán.  VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios.  Los valores propios menores o iguales
!>          a VL, o mayores que VU, no se devolverán.  VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

GERS

!>          GERS es array REAL, dimension (2*N)
!>          Los N intervalos de Gerschgorin (el i-ésimo intervalo
!>          de Gerschgorin es (GERS(2*i-1), GERS(2*i)).
!>

RELTOL

!>          RELTOL es REAL
!>          El ancho relativo mínimo de un intervalo. Cuando un intervalo
!>          es más estrecho que RELTOL multiplicado por el extremo más
!>          grande (en magnitud), entonces se considera
!>          suficientemente pequeño, es decir, convergido. Nota: esto siempre
!>          debería ser al menos epsilon_maquina * radix.
!>

D

!>          D es array REAL, dimension (N)
!>          Los N elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es array REAL, dimension (N-1)
!>          Los N-1 elementos fuera de la diagonal de la matriz tridiagonal T.
!>

E2

!>          E2 es array REAL, dimension (N-1)
!>          Los N-1 elementos fuera de la diagonal al cuadrado de la matriz tridiagonal T.
!>

PIVMIN

!>          PIVMIN es REAL
!>          El pivote mínimo permitido en la secuencia de Sturm para T.
!>

NSPLIT

!>          NSPLIT es INTEGER
!>          El número de bloques diagonales en la matriz T.
!>          1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT es array INTEGER, dimension (N)
!>          Los puntos de división, en los que T se descompone en submatrices.
!>          La primera submatriz consta de las filas/columnas 1 a ISPLIT(1),
!>          la segunda de las filas/columnas ISPLIT(1)+1 a ISPLIT(2),
!>          etc., y la NSPLIT-ésima consta de las filas/columnas
!>          ISPLIT(NSPLIT-1)+1 a ISPLIT(NSPLIT)=N.
!>          (Solo los primeros NSPLIT elementos se usarán realmente, pero
!>          como el usuario no puede saber de antemano qué valor tendrá NSPLIT,

!>

M

!>          M es INTEGER

!>          (Ver también la descripción de INFO=2,3.)
!>

W

!>          W es array REAL, dimension (N)
!>          A la salida, los primeros M elementos de W contendrán las
!>          aproximaciones de los valores propios. SLARRD calcula un intervalo
!>          I_j = (a_j, b_j] que incluye el valor propio j. La aproximación

!>          W(j)= ( a_j + b_j)/2. El error correspondiente está acotado por
!>          WERR(j) = abs( a_j - b_j)/2

WERR

!>          WERR es array REAL, dimension (N)
!>          El límite de error en la aproximación del valor propio correspondiente
!>          en W.
!>

WL

!>          WL es REAL
!>

WU

NAME

slarrd - this subroutine computes the eigenvalues of a symmetric tridiagonal matrix T.

SYNOPSIS

SUBROUTINE SLARRD(
    RCOND,     <-- REAL
    NRB,       <-- INTEGER
    NLVL,      <-- INTEGER
    SSE,       <-- REAL
    LDSCL,     <-- REAL
    D,         <-- REAL
    Z,         <-- REAL
    IAMBDA,    <-- REAL
    WORK,      <-- REAL
    IWORK,     <-- INTEGER
    INFO       <-- INTEGER
)

    IMPLICIT NONE
    REAL :: RCOND, SSE, LDSCL
    INTEGER :: NRB, NLVL, INFO
    REAL, DIMENSION(*) :: D, Z, Ilambda, WORK
    INTEGER, DIMENSION(*) :: IWORK

Function/Subroutine Documentation

This subroutine computes the eigenvalues of a symmetric tridiagonal matrix T. The eigenvalues are computed in the following ways:

  • If the matrix T is split into blocks, the eigenvalues are computed independently for each block.

  • If the matrix T is not split, the eigenvalues are computed for the whole matrix.

The matrix T is represented by the diagonal entries D and the subdiagonal entries Z. The eigenvalues are returned in the array Ilambda.

The subroutine takes the following arguments:

RCOND

REAL. Upper bound on the reciprocal of the condition number of the matrix T. This is used to determine whether a block should be further split.

NRB

INTEGER. The number of blocks the matrix T is split into.

NLVL

INTEGER. The number of levels of splitting. This is related to the recursion depth.

SSE

REAL. The shift value applied to the diagonal entries of T.

LDSCL

REAL. The scaling factor applied to the diagonal entries of T.

D

REAL array, dimension (N). Contains the diagonal entries of the tridiagonal matrix T.

Z

REAL array, dimension (N). Contains the subdiagonal entries of the tridiagonal matrix T. Z(i) is the subdiagonal entry between D(i) and D(i+1).

IAMBDA

REAL array, dimension (N). On output, this array contains the computed eigenvalues of T in ascending order.

WORK

REAL array, dimension (4*N). A workspace array used for intermediate computations.

IWORK

INTEGER array, dimension (3*N). A workspace array used for integer data.

INFO

INTEGER. On output, INFO indicates the status of the computation:

  • 0: Successful completion.
  • < 0: An illegal value was detected in the i-th argument (INFO = -i).
  • > 0: Some or all of the eigenvalues failed to converge or were not computed.
    • 1 or 3: Bisection failed to converge for some eigenvalues. These eigenvalues might have reduced accuracy and are flagged by a negative block number. This is usually due to inaccurate arithmetic.
    • 2 or 3: If RANGE = 'I', not all eigenvalues between IL and IU were found. The effect is that M < IU + 1 - IL. This can be caused by non-monotonic arithmetic. A cure is to recompute using RANGE = 'A' and select the desired eigenvalues, or possibly increase the parameter FUDGE.
    • 4: If RANGE = 'I', the Gershgorin interval was initially too small, and no eigenvalues were computed. This might indicate imprecise floating-point arithmetic. Increasing the parameter FUDGE and recompiling might help.

Internal Parameters:

FUDGE   REAL, default = 2
                        A value used to widen the Gershgorin intervals. Ideally, a value of 1 should suffice, but on machines with less precise arithmetic, a larger value might be necessary. The default is set to handle potentially problematic machines. This parameter does not affect the accuracy of the computed eigenvalues.
