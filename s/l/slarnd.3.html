Documentación de Función/Subrutina

real function slarnd (integer idist, integer, dimension( 4 ) iseed)

SLARND

Propósito:

!>
!> SLARND devuelve un número real aleatorio de una distribución uniforme o normal.
!>

Parámetros

IDIST 
!>          IDIST es INTEGER
!>          Especifica la distribución de los números aleatorios:
!>          = 1:  uniforme (0,1)
!>          = 2:  uniforme (-1,1)
!>          = 3:  normal (0,1)
!>

ISEED

!>          ISEED es un array INTEGER, de dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios; los
!>          elementos del array deben estar entre 0 y 4095, y ISEED(4) debe
!>          ser impar.
!>          En la salida, la semilla se actualiza.
!>

Univ. of Tennessee

Detalles Adicionales:

!>
!>  Esta rutina llama a la rutina auxiliar SLARAN para generar un número real
!>  aleatorio de una distribución uniforme (0,1). El método de Box-Muller se
!>  utiliza para transformar números de una distribución uniforme a una normal.
!>
