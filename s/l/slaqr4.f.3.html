Documentación de la función/subrutina

subroutine slaqr4 (logical wantt, logical wantz, integer n, integer ilo, integer ihi, real, dimension( ldh, * ) h, integer ldh, real, dimension( * ) wr, real, dimension( * ) wi, integer iloz, integer ihiz, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer info)

SLAQR4 calcula los valores propios de una matriz de Hessenberg, y opcionalmente las matrices de la descomposición de Schur.

Propósito:

!>
!>    SLAQR4 implementa un nivel de recursión para SLAQR0.
!>    Es una implementación completa del algoritmo QR multi-nivel con "bullicio" pequeño.
!>    Puede ser llamada por SLAQR0 y, para un tamaño de ventana de deflación suficientemente grande,
!>    puede ser llamada por SLAQR3. Esta subrutina es idéntica a SLAQR0 excepto que llama a SLAQR2
!>    en lugar de SLAQR3.
!>
!>    SLAQR4 calcula los valores propios de una matriz de Hessenberg H
!>    y, opcionalmente, las matrices T y Z de la descomposición de Schur
!>    H = Z T Z**T, donde T es una matriz cuasi-triangular superior (la
!>    forma de Schur), y Z es la matriz ortogonal de vectores de Schur.
!>
!>    Opcionalmente, Z puede ser post-multiplicada por una matriz ortogonal
!>    de entrada Q de modo que esta rutina pueda dar la factorización de Schur
!>    de una matriz A que ha sido reducida a la forma de Hessenberg H
!>    por la matriz ortogonal Q:  A = Q*H*Q**T = (QZ)*T*(QZ)**T.
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>          = .TRUE. : se requiere la forma completa de Schur T;
!>          = .FALSE.: solo se requieren los valores propios.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          = .TRUE. : se requiere la matriz de vectores de Schur Z;
!>          = .FALSE.: no se requieren vectores de Schur.
!>

N

!>          N es INTEGER
!>           El orden de la matriz H.  N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>           Se asume que H ya es triangular superior en las filas
!>           y columnas 1:ILO-1 e IHI+1:N y, si ILO > 1,
!>           H(ILO,ILO-1) es cero. ILO e IHI son normalmente establecidos por una
!>           llamada previa a SGEBAL, y luego pasados a SGEHRD cuando la
!>           matriz de salida de SGEBAL se reduce a la forma de Hessenberg.
!>           De lo contrario, ILO e IHI deben ser establecidos a 1 y N,
!>           respectivamente.  Si N > 0, entonces 1 <= ILO <= IHI <= N.
!>           Si N = 0, entonces ILO = 1 e IHI = 0.
!>

H

!>          H es array REAL, dimension (LDH,N)
!>           En la entrada, la matriz de Hessenberg superior H.
!>           En la salida, si INFO = 0 y WANTT es .TRUE., entonces H contiene
!>           la matriz cuasi-triangular superior T de la descomposición
!>           de Schur (la forma de Schur); los bloques diagonales de 2x2
!>           (correspondientes a pares de valores propios conjugados complejos)
!>           se devuelven en forma estándar, con H(i,i) = H(i+1,i+1)
!>           y H(i+1,i)*H(i,i+1) < 0. Si INFO = 0 y WANTT es
!>           .FALSE., entonces el contenido de H no está especificado en la salida.
!>           (El valor de salida de H cuando INFO > 0 se da en la
!>           descripción de INFO abajo.)
!>
!>           Esta subrutina puede establecer explícitamente H(i,j) = 0 para i > j y
!>           j = 1, 2, ... ILO-1 o j = IHI+1, IHI+2, ... N.
!>

LDH

!>          LDH es INTEGER
!>           La dimensión principal del array H. LDH >= max(1,N).
!>

WR

!>          WR es array REAL, dimension (IHI)
!>

WI

!>          WI es array REAL, dimension (IHI)
!>           Las partes real e imaginaria, respectivamente, de los valores
!>           propios calculados de H(ILO:IHI,ILO:IHI) se almacenan en WR(ILO:IHI)
!>           y WI(ILO:IHI). Si dos valores propios se calculan como un
!>           par conjugado complejo, se almacenan en elementos consecutivos
!>           de WR y WI, digamos el i-ésimo y (i+1)-ésimo, con
!>           WI(i) > 0 y WI(i+1) < 0. Si WANTT es .TRUE., entonces
!>           los valores propios se almacenan en el mismo orden que en la
!>           diagonal de la forma de Schur devuelta en H, con
!>           WR(i) = H(i,i) y, si H(i:i+1,i:i+1) es un bloque diagonal de 2x2,
!>           WI(i) = sqrt(-H(i+1,i)*H(i,i+1)) y
!>           WI(i+1) = -WI(i).
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>           Especifican las filas de Z a las que deben aplicarse las transformaciones
!>           si WANTZ es .TRUE..
!>           1 <= ILOZ <= ILO; IHI <= IHIZ <= N.
!>

Z

!>          Z es array REAL, dimension (LDZ,IHI)
!>           Si WANTZ es .FALSE., entonces Z no se referencia.
!>           Si WANTZ es .TRUE., entonces Z(ILO:IHI,ILOZ:IHIZ) se
!>           reemplaza por Z(ILO:IHI,ILOZ:IHIZ)*U donde U es el
!>           factor de Schur ortogonal de H(ILO:IHI,ILO:IHI).
!>           (El valor de salida de Z cuando INFO > 0 se da en la
!>           descripción de INFO abajo.)
!>

LDZ

!>          LDZ es INTEGER
!>           La dimensión principal del array Z.  Si WANTZ es .TRUE.
!>           entonces LDZ >= MAX(1,IHIZ).  De lo contrario, LDZ >= 1.
!>

WORK

!>          WORK es array REAL, dimension LWORK
!>           En la salida, si LWORK = -1, WORK(1) devuelve una estimación de
!>           el valor óptimo para LWORK.
!>

LWORK

!>          LWORK es INTEGER
!>           La dimensión del array WORK.  LWORK >= max(1,N)
!>           es suficiente, pero LWORK típicamente tan grande como 6*N puede
!>           ser requerido para un rendimiento óptimo.  Se recomienda una consulta
!>           de espacio de trabajo para determinar el tamaño óptimo del espacio de trabajo.
!>
!>           Si LWORK = -1, entonces SLAQR4 realiza una consulta de espacio de trabajo.
!>           En este caso, SLAQR4 verifica los parámetros de entrada y
!>           estima el tamaño óptimo del espacio de trabajo para los valores
!>           dados de N, ILO e IHI.  La estimación se devuelve
!>           en WORK(1).  XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>           Ni H ni Z son accedidos.
!>

NAME

slaqr4 - Routine Returns the eigenvalues of a bidiagonal matrix J (in an ORBAN matrix).

SYNOPSIS

 SUBROUTINE SLAQR4(wantt, wantz, n, knt, skip, iwork, work, lwork, info)

 IMPLICIT NONE

 LOGICAL :: wantt, wantz
 INTEGER :: n, knt, skip, lwork, info
 REAL :: work( * )
 INTEGER :: iwork( * )

Function/Subroutine Documentation

Purpose:

This routine returns the eigenvalues of a bidiagonal matrix J (in an ORBAN matrix). J is an ORBAN matrix of order N which is partitioned at row KNT into a top (KNT) by (KNT) triangular block and a bottom (N-KNT) by (N-KNT) triangular block.

This routine is the fourth of the four routines SLQR0, SLQR1, SLQR2, SLQR3, SLQR4 that implement the implicit QL algorithm for computing the eigenvalues of an ORBAN matrix.

SLQR0 computes the ORBAN matrix J.

SLQR1 checks the ORBAN matrix for possible deflations.

SLQR2 applies one iteration of the implicit QL algorithm to the ORBAN matrix.

SLQR3 applies one iteration of the implicit QL algorithm to the ORBAN matrix.

SLQR4 computes the eigenvalues of the deflation-free ORBAN matrix.

The ORBAN matrix J is assumed to be in the ORBAN matrix representation of a matrix A in the form

          Z * J * Z**T = A

where Z is an orthogonal matrix.

Arguments:

wantt
LOGICAL
Input. If true, the ORBAN matrix J will be made triangular.
wantz
LOGICAL
Input. If true, the ORBAN matrix Z will be made triangular.
n
INTEGER
Input. The order of the ORBAN matrix J.
knt
INTEGER
Input. The position of the subdiagonal where the ORBAN matrix is partitioned.
skip
INTEGER
Input. The number of eigenvalues to be skipped.
iwork
INTEGER
Workspace array of dimension at least
N.
work
REAL
Workspace array of dimension at least
max(N, 2*N).
lwork
INTEGER
Input. The dimension of the array WORK.
info
INTEGER
Output. Set to 0 if successful.
If it is negative, the routine failed to converge.
