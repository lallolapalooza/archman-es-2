stringlist(3bsd) 3bsd stringlist(3bsd)

NOMBRE

stringlist, sl_init, sl_add, sl_free, sl_find, sl_delete — funciones de manipulación de listas de cadenas

BIBLIOTECA

biblioteca «libbsd»

SINOPSIS

#include <stringlist.h> (Ver libbsd(7) para el uso de include.)
StringList *
sl_init(void);

int
sl_add(StringList *sl, char *item);

void
sl_free(StringList *sl, int freeall);

char *
sl_find(StringList *sl, const char *item);

int
sl_delete(StringList *sl, const char *item, int freeit);

DESCRIPCIÓN

Las funciones stringlist manipulan listas de cadenas, que son listas de cadenas que se extienden automáticamente si es necesario.

La estructura StringList tiene la siguiente definición:

typedef struct _stringlist {
	char	**sl_str;
	size_t	  sl_max;
	size_t	  sl_cur;
} StringList;

donde:

sl_str
es un puntero a la base del array que contiene la lista,
sl_max
es el tamaño de sl_str, y
sl_cur
es el índice en sl_str del elemento actual.

Las siguientes funciones de manipulación de listas de cadenas están disponibles:

sl_init()
Crea una lista de cadenas. Devuelve un puntero a un StringList, o NULL en caso de fallo.
sl_free()
Libera la memoria ocupada por sl y el array sl->sl_str. Si freeall es distinto de cero, entonces cada uno de los elementos dentro de sl->sl_str también se libera.
sl_add()
Añade item a sl->sl_str en sl->sl_cur, extendiendo el tamaño de sl->sl_str. Devuelve cero en caso de éxito, -1 en caso de fallo.
sl_find()
Busca item en sl, devolviendo NULL si no se encuentra.
sl_delete()
Elimina item de la lista. Si freeit es distinto de cero, la cadena se libera. Devuelve 0 si se encuentra el nombre y -1 si no se encuentra el nombre.

VER TAMBIÉN

free(3), malloc(3)

HISTORIA

Las funciones stringlist aparecieron en FreeBSD 2.2.6 y NetBSD 1.3.
