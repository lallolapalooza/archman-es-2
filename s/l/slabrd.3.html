subrutina slabrd (m, n, nb, a, lda, d, e, tauq, taup, x, ldx, y, ldy)
SLABRD reduce las primeras nb filas y columnas de una matriz general a forma bidiagonal.

Documentación de función/subrutina

subrutina slabrd (integer m, integer n, integer nb, real, dimension( lda, * ) a, integer lda, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) tauq, real, dimension( * ) taup, real, dimension( ldx, * ) x, integer ldx, real, dimension( ldy, * ) y, integer ldy)

SLABRD reduce las primeras nb filas y columnas de una matriz general a forma bidiagonal.

Propósito

!>
!> SLABRD reduce las primeras NB filas y columnas de una matriz general real
!> m por n A a forma bidiagonal superior o inferior mediante una
!> transformación ortogonal Q**T * A * P, y devuelve las matrices X e Y que
!> son necesarias para aplicar la transformación a la parte no reducida de A.
!>
!> Si m >= n, A se reduce a forma bidiagonal superior; si m < n, a forma bidiagonal
!> inferior.
!>
!> Esta es una subrutina auxiliar llamada por SGEBRD
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.
!>

NB

!>          NB es INTEGER
!>          El número de filas y columnas principales de A a reducir.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, la matriz general m por n a reducir.
!>          En la salida, las primeras NB filas y columnas de la matriz se
!>          sobrescriben; el resto del array permanece sin cambios.
!>          Si m >= n, los elementos en y debajo de la diagonal en las primeras NB
!>            columnas, con el array TAUQ, representan la matriz ortogonal
!>            Q como un producto de reflectores elementales; y
!>            los elementos por encima de la diagonal en las primeras NB filas, con
!>            el array TAUP, representan la matriz ortogonal P como un producto
!>            de reflectores elementales.
!>          Si m < n, los elementos debajo de la diagonal en las primeras NB
!>            columnas, con el array TAUQ, representan la matriz ortogonal
!>            Q como un producto de reflectores elementales, y
!>            los elementos en y por encima de la diagonal en las primeras NB filas,
!>            con el array TAUP, representan la matriz ortogonal P como
!>            un producto de reflectores elementales.
!>          Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

D

!>          D es array REAL, dimension (NB)
!>          Los elementos diagonales de las primeras NB filas y columnas de
!>          la matriz reducida.  D(i) = A(i,i).
!>

E

!>          E es array REAL, dimension (NB)
!>          Los elementos fuera de la diagonal de las primeras NB filas y columnas de
!>          la matriz reducida.
!>

TAUQ

!>          TAUQ es array REAL, dimension (NB)
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz ortogonal Q. Ver Detalles Adicionales.
!>

TAUP

!>          TAUP es array REAL, dimension (NB)
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz ortogonal P. Ver Detalles Adicionales.
!>

X

!>          X es array REAL, dimension (LDX,NB)
!>          La matriz X m-por-nb necesaria para actualizar la parte no reducida
!>          de A.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X. LDX >= max(1,M).
!>

Y

!>          Y es array REAL, dimension (LDY,NB)
!>          La matriz Y n-por-nb necesaria para actualizar la parte no reducida
!>          de A.
!>

LDY

!>          LDY es INTEGER
!>          La dimensión principal del array Y. LDY >= max(1,N).
!>

Detalles adicionales

!>
!>  Las matrices Q y P se representan como productos de reflectores
!>  elementales:
!>
!>     Q = H(1) H(2) . . . H(nb)  y  P = G(1) G(2) . . . G(nb)
!>
!>  Cada H(i) y G(i) tiene la forma:
!>
!>     H(i) = I - tauq * v * v**T  y G(i) = I - taup * u * u**T
!>
!>  donde tauq y taup son escalares reales, y v y u son vectores reales.
!>
!>  Si m >= n, v(1:i-1) = 0, v(i) = 1, y v(i:m) se almacena en la salida en
!>  A(i:m,i); u(1:i) = 0, u(i+1) = 1, y u(i+1:n) se almacena en la salida en
!>  A(i,i+1:n); tauq se almacena en TAUQ(i) y taup en TAUP(i).
!>
!>  Si m < n, v(1:i) = 0, v(i+1) = 1, y v(i+1:m) se almacena en la salida en
!>  A(i+2:m,i); u(1:i-1) = 0, u(i) = 1, y u(i:n) se almacena en la salida en
!>  A(i,i+1:n); tauq se almacena en TAUQ(i) y taup en TAUP(i).
!>
!>  Los elementos de los vectores v y u juntos forman la matriz m-por-nb
!>  V y la matriz nb-por-n U**T que se necesitan, con X e Y, para aplicar
!>  la transformación a la parte no reducida de la matriz, usando una
!>  actualización de bloque de la forma:  A := A - V*Y**T - X*U**T.
!>
!>  El contenido de A en la salida se ilustra con los siguientes ejemplos
!>  con nb = 2:
!>
!>  m = 6 y n = 5 (m > n):          m = 5 y n = 6 (m < n):
!>
!>    (  1   1   u1  u1  u1 )           (  1   u1  u1  u1  u1  u1 )
!>    (  v1  1   1   u2  u2 )           (  1   1   u2  u2  u2  u2 )
!>    (  v1  v2  a   a   a  )           (  v1  1   a   a   a   a  )
!>    (  v1  v2  a   a   a  )           (  v1  v2  a   a   a   a  )
!>    (  v1  v2  a   a   a  )           (  v1  v2  a   a   a   a  )
!>    (  v1  v2  a   a   a  )
!>
!>  donde a denota un elemento de la matriz original que no ha cambiado,
!>  vi denota un elemento del vector que define H(i), y ui un elemento
!>  del vector que define G(i).
!>

SLABRD(3) Sección 3 SLABRD(3)

NOMBRE

slabrd - Establece el tamaño y el equilibrio de los bloques de deslizamiento.

SINOPSIS

SUBROUTINE SLABRD(
        N, NB, LDAB, AB, LDAB, BMAT, LDU, U, LDU,
        LDVT, VT, LDVT, D, E )
    
    INTEGER            N
    INTEGER            NB
    INTEGER            LDAB
    REAL               AB( LDAB, NB )
    CHARACTER*( 1 )    BMAT
    INTEGER            LDU
    REAL               U( LDU, NB )
    INTEGER            LDVT
    REAL               VT( LDVT, NB )
    REAL               D( * )
    REAL               E( * )

DESCRIPCIÓN

SLABRD establece los primeros NB elementos de cada columna de la matriz A (en la submatriz AB) y los primeros NB elementos de cada fila de la matriz A (en la submatriz AB) para que sean cero.

La submatriz de A se representa en AB, y se espera que sea la esquina superior izquierda de la matriz entera A, tal como se pasa a un algoritmo de reducción de valores singulares bidimensional (SVD).

En otras palabras, si A es una matriz m por n, SLABRD la reforma en 

  [  T   U2 ]
    [  0   A2 ]
    [  0   A3 ]

donde T es una matriz nb por nb.

También se espera que las matrices U y VT contengan las matrices ortogonales U y VT, que transforman A: 

  A = U * B * V^T

donde B es la matriz de destino, es decir, 

  [  D   0  ]
    [  0   S ]
    [  0   0  ]

donde D es una matriz diagonal.

SLABRD realiza la reducción bidimensional de A en una matriz de Hessenberg ortogonal de banda (OBH), que se representa en AB.

ARGUMENTOS

N

INTEGER. El orden de la submatriz A.

NB

INTEGER. El tamaño del bloque.

LDAB

INTEGER. El ancho de la submatriz AB.

AB

REAL. La submatriz de A que se está procesando.

BMAT

CHARACTER*( 1 ). Especifica la estructura de la matriz B.

'S'

B es una matriz simétrica.

'H'

B es una matriz hermítica.

'G'

B es una matriz general.

LDU

INTEGER. El ancho de la matriz U.

U

REAL. La matriz ortogonal de la izquierda.

LDVT

INTEGER. El ancho de la matriz VT.

VT

REAL. La matriz ortogonal de la derecha.

D

REAL. El vector de la diagonal de la matriz B.

E

REAL. El vector de la subdiagonal de la matriz B.
