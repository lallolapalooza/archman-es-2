subroutine slarre (character range, integer n, real vl, real vu, integer il, integer iu, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) e2, real rtol1, real rtol2, real spltol, integer nsplit, integer, dimension( * ) isplit, integer m, real, dimension( * ) w, real, dimension( * ) werr, real, dimension( * ) wgap, integer, dimension( * ) iblock, integer, dimension( * ) indexw, real, dimension( * ) gers, real pivmin, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLARRE dada la matriz tridiagonal T, establece pequeños elementos fuera de la diagonal a cero y para cada bloque no reducido Ti, encuentra representaciones base y valores propios.

Propósito:

!>
!> Para encontrar los valores propios deseados de una matriz
!> tridiagonal real simétrica dada T, SLARRE establece cualquier
!> elemento fuera de la diagonal a cero, y para cada bloque no reducido T_i,
!> encuentra (a) un desplazamiento adecuado en un extremo del espectro del
!> bloque, (b) la representación base, T_i - sigma_i I = L_i D_i L_i^T, y
!> (c) los valores propios de cada L_i D_i L_i^T.
!> Las representaciones y valores propios encontrados son utilizados por
!> SSTEMR para calcular los vectores propios de T.
!> La precisión varía dependiendo de si se usa bisección para
!> encontrar unos pocos valores propios o el algoritmo dqds (subrutina SLASQ2)
!> para calcular todos y luego descartar los no deseados.
!> Como beneficio adicional, SLARRE también produce los n
!> intervalos de Gerschgorin para las matrices L_i D_i L_i^T.
!>

Parámetros

RANGE 
!>          RANGE es CHARACTER*1
!>          = 'A': ()   se encontrarán todos los valores propios.
!>          = 'V': () se encontrarán todos los valores propios en el intervalo semiabierto
!>                           (VL, VU]
!>          = 'I': () se encontrarán los valores propios del IL-ésimo al IU-ésimo (de la
!>                           matriz completa)
!>

N

!>          N es INTEGER
!>          El orden de la matriz. N > 0.
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior para los valores propios.
!>          Los valores propios menores o iguales a VL, o mayores que VU,
!>          no serán devueltos.  VL < VU.
!>          Si RANGE='I' o ='A', SLARRE calcula límites en la parte deseada
!>          del espectro.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior para los valores propios.
!>          Los valores propios menores o iguales a VL, o mayores que VU,
!>          no serán devueltos.  VL < VU.
!>          Si RANGE='I' o ='A', SLARRE calcula límites en la parte deseada
!>          del espectro.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N.
!>

D

!>          D es array REAL, dimensión (N)
!>          En la entrada, los N elementos diagonales de la matriz
!>          tridiagonal T.
!>          En la salida, los N elementos diagonales de las matrices
!>          diagonales D_i.
!>

E

!>          E es array REAL, dimensión (N)
!>          En la entrada, las primeras (N-1) entradas contienen los elementos
!>          subdiagonales de la matriz tridiagonal T; E(N) no necesita ser
!>          establecido.
!>          En la salida, E contiene los elementos subdiagonales de las matrices
!>          bidiagonales unitarias L_i. Las entradas E( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, contienen los puntos base sigma_i en la salida.
!>

E2

!>          E2 es array REAL, dimensión (N)
!>          En la entrada, las primeras (N-1) entradas contienen los CUADRADOS de los
!>          elementos subdiagonales de la matriz tridiagonal T;
!>          E2(N) no necesita ser establecido.
!>          En la salida, las entradas E2( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, han sido establecidas a cero.
!>

RTOL1

!>          RTOL1 es REAL
!>

RTOL2

!>          RTOL2 es REAL
!>           Parámetros para bisección.
!>           Un intervalo [IZQ,DER] ha convergido si
!>           DER-IZQ < MAX( RTOL1*GAP, RTOL2*MAX(|IZQ|,|DER|) )
!>

SPLTOL

!>          SPLTOL es REAL
!>          El umbral para la división.
!>

NSPLIT

!>          NSPLIT es INTEGER
!>          El número de bloques en los que T se divide. 1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT es array INTEGER, dimensión (N)
!>          Los puntos de división, en los que T se descompone en bloques.
!>          El primer bloque consiste en las filas/columnas 1 a ISPLIT(1),
!>          el segundo en las filas/columnas ISPLIT(1)+1 hasta ISPLIT(2),
!>          etc., y el NSPLIT-ésimo consiste en las filas/columnas
!>          ISPLIT(NSPLIT-1)+1 hasta ISPLIT(NSPLIT)=N.
!>

M

!>          M es INTEGER
!>          El número total de valores propios (de todos los L_i D_i L_i^T)
!>          encontrados.
!>

W

!>          W es array REAL, dimensión (N)
!>          Las primeras M entradas contienen los valores propios. Los
!>          valores propios de cada uno de los bloques, L_i D_i L_i^T, están
!>          ordenados en orden ascendente ( SLARRE puede usar las
!>          restantes N-M entradas como espacio de trabajo).
!>

WERR

!>          WERR es array REAL, dimensión (N)
!>          El límite de error en el valor propio correspondiente en W.
!>

WGAP

!>          WGAP es array REAL, dimensión (N)
!>          La separación del siguiente valor propio a la derecha en W.
!>          El hueco es solo con respecto a los valores propios del mismo bloque
!>          ya que cada bloque tiene su propio árbol de representación.
!>          Excepción: en el extremo derecho de un bloque almacenamos el hueco
!>          izquierdo.
!>

IBLOCK

!>          IBLOCK es array INTEGER, dimensión (N)
!>          Los índices de los bloques (submatrices) asociados con los
!>          valores propios correspondientes en W; IBLOCK(i)=1 si el valor propio
!>          W(i) pertenece al primer bloque desde arriba, =2 si W(i)
!>          pertenece al segundo bloque, etc.
!>

INDEXW

!>          INDEXW es array INTEGER, dimensión (N)
!>          Los índices de los valores propios dentro de cada bloque (submatriz);
!>          por ejemplo, INDEXW(i)= 10 e IBLOCK(i)=2 implican que el
!>          i-ésimo valor propio W(i) es el décimo valor propio en el bloque 2.
!>

GERS

!>          GERS es array REAL, dimensión (2*N)
!>          Los N intervalos de Gerschgorin (el i-ésimo intervalo
!>          de Gerschgorin es (GERS(2*i-1), GERS(2*i))).
!>

PIVMIN

!>          PIVMIN es REAL
!>          El pivote mínimo en la secuencia de Sturm para T.
!>

WORK

!>          WORK es array REAL, dimensión (6*N)
!>          Espacio de trabajo.
!>

IWORK

  REAL    V(*)

  INTEGER IWORK(*)

Function/Subroutine Documentation

PURPOSE

  The primary purpose of SLARRE is to find the base representations of
  the irreducible invariant subspaces of a symmetric tridiagonal matrix T.
  These representations are the standard basis vectors of the spaces spanned
  by the eigenvectors of T corresponding to eigenvalues in the interval
  [a, b].

ARGUMENTS

N (input)

  INTEGER
  The order of the matrix T.

V (input)

  REAL array, dimension (N)
  Contains the entries of the bidiagonal matrix T.

TOL (input)

  REAL
  Tolerance for splitting the matrix.

LL (input)

  INTEGER
  The dimension of the workspace array SUBSR.

L (output)

  INTEGER
  The number of invariant subspaces found.

R (output)

  REAL array, dimension (LL, *)
  Stores the base representations of the invariant subspaces.

KAPC (output)

  INTEGER array, dimension (N)
  Stores the indices of the cluster representatives.

KDIAG (output)

  INTEGER array, dimension (N)
  Stores the indices of the diagonal elements corresponding to the cluster
  representatives.

SUBSR (workspace)

  REAL array, dimension (LL, N)
  Workspace for storing intermediate results.

IWORK (workspace)

  INTEGER array, dimension (5*N)
  Workspace.

INFO (output)

  INTEGER
  = 0:  successful exit
  > 0:  A problem occurred in SLARRE.
  < 0:  One of the called subroutines signaled an internal problem.
        Needs inspection of the corresponding parameter IINFO
        for further information.
  =-1:  Problem in SLARRD.
  = 2:  No base representation could be found in MAXTRY iterations.
        Increasing MAXTRY and recompilation might be a remedy.
  =-3:  Problem in SLARRB when computing the refined root
        representation for SLASQ2.
  =-4:  Problem in SLARRB when preforming bisection on the
        desired part of the spectrum.
  =-5:  Problem in SLASQ2.
  =-6:  Problem in SLASQ2.

Further Details:

  The base representations are required to suffer very little
  element growth and consequently define all their eigenvalues to
  high relative accuracy.
