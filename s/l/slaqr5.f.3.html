SLAQR5 realiza un barrido QR multi-instancia de pequeño bulto.

Propósito:

!>
!>    SLAQR5, llamado por SLAQR0, realiza un
!>    barrido QR multi-instancia de pequeño bulto.
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>             WANTT = .true. si se está calculando el factor de Schur cuasi-triangular.
!>             WANTT se establece en .false. en caso contrario.
!>

WANTZ

!>          WANTZ es LOGICAL
!>             WANTZ = .true. si se está calculando el factor de Schur ortogonal.
!>             WANTZ se establece en .false. en caso contrario.
!>

KACC22

!>          KACC22 es INTEGER con valor 0, 1 o 2.
!>             Especifica el modo de cálculo de las actualizaciones ortogonales
!>             lejanas a la diagonal.
!>        = 0: SLAQR5 no acumula reflexiones y no utiliza
!>             multiplicación matriz-matriz para actualizar las entradas
!>             de la matriz lejana a la diagonal.
!>        = 1: SLAQR5 acumula reflexiones y utiliza multiplicación
!>             matriz-matriz para actualizar las entradas de la matriz
!>             lejana a la diagonal.
!>        = 2: Igual que KACC22 = 1. Esta opción se usaba para explotar
!>             la estructura de 2x2 durante las multiplicaciones de matrices,
!>             pero esto ya no se soporta.
!>

N

!>          N es INTEGER
!>             N es el orden de la matriz de Hessenberg H sobre la que opera
!>             esta subrutina.
!>

KTOP

!>          KTOP es INTEGER
!>

KBOT

!>          KBOT es INTEGER
!>             Estas son las filas y columnas primera y última de un
!>             bloque diagonal aislado sobre el que se aplicará el barrido QR.
!>             Se asume sin comprobación que
!>                       o KTOP = 1  o   H(KTOP,KTOP-1) = 0
!>             y
!>                       o KBOT = N  o   H(KBOT+1,KBOT) = 0.
!>

NSHFTS

!>          NSHFTS es INTEGER
!>             NSHFTS da el número de instancias simultáneas. NSHFTS
!>             debe ser positivo y par.
!>

SR

!>          SR es array REAL, dimension (NSHFTS)
!>

SI

!>          SI es array REAL, dimension (NSHFTS)
!>             SR contiene las partes reales y SI contiene las partes imaginarias
!>             de las NSHFTS instancias de origen que definen el barrido QR
!>             multi-instancia. En la salida, SR y SI pueden ser
!>             reordenados.
!>

H

!>          H es array REAL, dimension (LDH,N)
!>             En la entrada, H contiene una matriz de Hessenberg. En la salida,
!>             se aplica un barrido QR multi-instancia con instancias SR(J)+i*SI(J)
!>             al bloque diagonal aislado en las filas y columnas KTOP
!>             a KBOT.
!>

LDH

!>          LDH es INTEGER
!>             LDH es la dimensión principal de H tal como se declara en el
!>             procedimiento de llamada. LDH >= MAX(1,N).
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>             Especifican las filas de Z a las que se deben aplicar las
!>             transformaciones si WANTZ es .TRUE.. 1 <= ILOZ <= IHIZ <= N
!>

Z

!>          Z es array REAL, dimension (LDZ,IHIZ)
!>             Si WANTZ = .TRUE., entonces la transformación de similitud
!>             ortogonal del barrido QR se acumula en
!>             Z(ILOZ:IHIZ,ILOZ:IHIZ) desde la derecha.
!>             Si WANTZ = .FALSE., Z no se utiliza.
!>

LDZ

!>          LDZ es INTEGER
!>             LDA es la dimensión principal de Z tal como se declara en
!>             el procedimiento de llamada. LDZ >= N.
!>

V

!>          V es array REAL, dimension (LDV,NSHFTS/2)
!>

LDV

!>          LDV es INTEGER
!>             LDV es la dimensión principal de V tal como se declara en
!>             el procedimiento de llamada. LDV >= 3.
!>

U

!>          U es array REAL, dimension (LDU,2*NSHFTS)
!>

LDU

!>          LDU es INTEGER
!>             LDU es la dimensión principal de U tal como se declara en
!>             el subprograma de llamada. LDU >= 2*NSHFTS.
!>

NV

!>          NV es INTEGER
!>             NV es el número de filas en WV disponibles para espacio de trabajo.
!>             NV >= 1.
!>

WV

!>          WV es array REAL, dimension (LDWV,2*NSHFTS)
!>

LDWV

!>          LDWV es INTEGER
!>             LDWV es la dimensión principal de WV tal como se declara en
!>             el subprograma de llamada. LDWV >= NV.
!>

NH

!>          NH es INTEGER
!>             NH es el número de columnas en el array WH disponibles para
!>             espacio de trabajo. NH >= 1.
!>

WH

!>          WH es array REAL, dimension (LDWH,NH)
!>

LDWH

!>          LDWH es INTEGER
!>             Dimensión principal de WH tal como se declara en
!>             el procedimiento de llamada. LDWH >= 2*NSHFTS.
!>

NAME

slaqr5 - Esta rutina se utiliza para actualizar los valores propios de una matriz de Hessenberg.

SINOPSIS

SUBROUTINE SLAQR5( N, KNT, Z, LDZ, VF, TRI, WORK, LWORK, INFO )

  LOGICAL VF(*)
  INTEGER KNT, N, LDZ, LWORK, INFO
  REAL WORK(*)
  COMPLEX Z(*)
  LOGICAL TRI(*)

Function/Subroutine Documentation

SLAQR5 se utiliza en el algoritmo QR para calcular los valores propios de una matriz de Hessenberg no simétrica. Principalmente, se enfoca en la actualización de los valores propios de una submatriz de Hessenberg de tamaño N x N.

Argumentos:

  • N: El orden de la matriz de Hessenberg.
  • KNT: El número de iteraciones realizadas.
  • Z: Matriz de Hessenberg de entrada. Al salir, contiene la matriz actualizada.
  • LDZ: Longitud de la línea de Z.
  • VF: Vector de vectores propios.
  • TRI: Tipo de transformación de Hessenberg.
  • WORK: Espacio de trabajo para cálculos intermedios.
  • LWORK: Longitud del espacio de trabajo.
  • INFO: Indicador de información. 0 si es exitoso, negativo si hay un error.

La rutina es una parte fundamental del algoritmo de cálculo de valores propios de Hessenberg y se llama repetidamente para refinar los valores propios hasta que se alcanzan las tolerancias deseadas.
