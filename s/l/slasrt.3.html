subrutina slasrt (caracter id, entero n, real, dimensión( * ) d, entero info)

SLASRT ordena números en orden creciente o decreciente.

Propósito:

!>
!> Ordena los números en D en orden creciente (si ID = 'I') o
!> en orden decreciente (si ID = 'D').
!>
!> Utiliza Quick Sort, recurriendo a Insertion sort en arrays de
!> tamaño <= 20. La dimensión de STACK limita N a aproximadamente 2**32.
!>

Parámetros

ID 
!>          ID es CHARACTER*1
!>          = 'I': ordenar D en orden creciente;
!>          = 'D': ordenar D en orden decreciente.
!>

N

!>          N es INTEGER
!>          La longitud del array D.
!>

D

!>          D es un array REAL, dimensión (N)
!>          A la entrada, el array a ordenar.
!>          A la salida, D se ha ordenado en orden creciente
!>          (D(1) <= ... <= D(N)) o en orden decreciente
!>          (D(1) >= ... >= D(N)), dependiendo de ID.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
