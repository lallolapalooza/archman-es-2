slurmdbd(8) Daemon de Slurm slurmdbd(8)

NOMBRE

slurmdbd - Demonio de la Base de Datos de Slurm.

SINOPSIS

slurmdbd [OPCIONES...]

DESCRIPCIÓN

slurmdbd proporciona una interfaz segura a nivel empresarial a una base de datos para Slurm. Esto es particularmente útil para archivar registros de contabilidad.

OPCIONES

-D
Ejecuta slurmdbd en primer plano con el registro copiado a stdout.
-h
Ayuda; imprime un breve resumen de las opciones del comando.
-n <valor>
Establece el valor de nice del demonio al valor especificado, típicamente un número negativo.
-s
Cambia el directorio de trabajo de slurmdbd a la ruta de LogFile si es posible, o a /var/tmp en caso contrario.
-u
Solo muestra la versión de la Base de Datos de Slurm y si es necesaria la conversión, y sale sin tomar el control. Si no se necesita conversión, se retorna 0, si se necesita conversión, se retorna 1.
-v
Operación detallada. Se pueden especificar varias v, y cada 'v' adicional aumenta la verbosidad, hasta 6 veces (es decir, -vvvvvv).
-V
Imprime información de la versión y sale.

VARIABLES DE ENTORNO

Las siguientes variables de entorno pueden usarse para anular configuraciones compiladas en slurmdbd.

ABORT_ON_FATAL
Cuando se detecta un error fatal, usa abort() en lugar de exit() para terminar el proceso. Esto permite capturar volcados de memoria sin recompilar Slurm.

UBICACIÓN DEL ARCHIVO CORE

Si slurmdbd se inicia con la opción -D, el archivo core se escribirá en el directorio de trabajo actual. De lo contrario, si LogFile en "slurmdbd.conf" es un nombre de ruta completo (comenzando con una barra), el archivo core se escribirá en el mismo directorio que el archivo de registro, siempre que SlurmUser tenga permiso de escritura en el directorio. De lo contrario, el archivo core se escribirá en "/var/tmp/" como último recurso. Si ninguno de los directorios anteriores tiene permisos de escritura para SlurmUser, no se producirá ningún archivo core.

SEÑALES

SIGTERM SIGINT SIGQUIT
slurmdbd se cerrará limpiamente, esperando a que finalicen los procesos de consolidación en curso.
SIGABRT
slurmdbd realizará un volcado de memoria (core dump) y luego saldrá. Las operaciones en curso se abortarán.
SIGHUP
Recarga los archivos de configuración de slurm, similar a 'scontrol reconfigure'.
SIGTSTP
Detiene el proceso desde una terminal.
SIGUSR2
Vuelve a leer el nivel de registro de las configuraciones y luego vuelve a abrir el archivo de registro. Esto debe usarse al configurar logrotate(8).
SIGCHLD SIGUSR1 SIGXCPU SIGPIPE SIGALRM
Estas señales se ignoran explícitamente.

NOTAS

Puede ser útil experimentar con diferentes parámetros de configuración específicos de slurmctld utilizando un archivo de configuración distinto (por ejemplo, tiempos de espera). Sin embargo, este archivo de configuración especial no será utilizado por el demonio slurmd ni por los programas de Slurm, a menos que se les indique específicamente que lo usen. Si desea cambiar los puertos de comunicación, la ubicación del sistema de archivos temporal o otros parámetros utilizados por otros componentes de Slurm, modifique el archivo de configuración común, slurm.conf.
