NOMBRE

slogencrypt --- Cifra archivos de registro de texto plano existentes utilizando el entorno de registro seguro de {{ site.product.short_name }}.

SINOPSIS

slogencrypt [opciones] [argumentos]

DESCRIPCIÓN

La utilidad slogencrypt cifra archivos de registro de texto plano utilizando un entorno de registro seguro existente. Usando esta utilidad, los archivos de registro obtenidos de una instalación previa de syslog-ng OSE u otro sistema de registro pueden ser transferidos a un entorno de registro seguro. Se preserva el orden de las entradas del registro. Para cifrar archivos de registro de texto plano utilizando un entorno de registro seguro existente, se requiere la clave de cifrado actual para mantener la consistencia.

EJEMPLO: una secuencia general de llamada

slogencrypt -k <archivo clave> -m <archivo MAC> <nuevo archivo clave> <nuevo archivo MAC> <registro de texto plano> <archivo de salida> [contador]

ARGUMENTOS

•
<nuevo archivo clave>

El archivo que contiene la nueva clave de cifrado después de un cifrado exitoso.

•
<nuevo archivo MAC>

El archivo que recibe el nuevo código de autenticación de mensaje (MAC) del destino seguro cifrado después del cifrado. En caso de que se proporcione un archivo existente, se añadirán nuevas entradas.

•
<archivo de registro de entrada>

El archivo de registro de texto plano que se cifra utilizando el entorno de registro seguro.

•
<archivo de registro de salida>

El archivo que contiene las entradas de registro cifradas del archivo de registro de texto plano proporcionado después del cifrado.

•
contador

El contador de entradas de registro actual del destino seguro cifrado después del cifrado. Esto es necesario si las entradas de registro a cifrar se añaden a un destino seguro cifrado existente.

OPCIONES

•
--key-file o -k

La clave de host actual del sistema donde se realiza el cifrado.

•
--mac-file o -m

El archivo MAC actual del sistema donde se realiza el cifrado.

•
--help o -h

Muestra un mensaje de ayuda.
