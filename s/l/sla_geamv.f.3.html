subrutina sla_geamv (trans, m, n, alpha, a, lda, x, incx, beta, y, incy)


SLA_GEAMV calcula el producto de una matriz por un vector utilizando una matriz general para calcular límites de error.

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina sla_geamv (integer trans, integer m, integer n, real alpha, real, dimension( lda, * ) a, integer lda, real, dimension( * ) x, integer incx, real beta, real, dimension( * ) y, integer incy)

SLA_GEAMV calcula el producto de una matriz por un vector utilizando una matriz general para calcular límites de error.

Propósito:

!>
!> SLA_GEAMV  realiza una de las operaciones de matriz por vector
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>    o    y := alpha*abs(A)**T*abs(x) + beta*abs(y),
!>
!> donde alpha y beta son escalares, x e y son vectores y A es una
!> matriz de m por n.
!>
!> Esta función se usa principalmente para calcular límites de error.
!> Para protegerse contra el subdesbordamiento durante la evaluación,
!> los componentes del vector resultante se perturban lejos de cero
!> por (N+1) veces el umbral de subdesbordamiento. Para evitar errores
!> innecesariamente grandes para la estructura de bloque incrustada
!> en matrices generales, los componentes cero no se perturban. Un
!> componente cero se considera si todas las multiplicaciones
!> involucradas en el cálculo de ese componente tienen al menos un
!> multiplicando cero.
!>

Parámetros

TRANS 
!>          TRANS es INTEGER
!>           A la entrada, TRANS especifica la operación a realizar como
!>           sigue:
!>
!>             BLAS_NO_TRANS      y := alpha*abs(A)*abs(x) + beta*abs(y)
!>             BLAS_TRANS         y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>             BLAS_CONJ_TRANS    y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>
!>           No modificado a la salida.
!>

M

!>          M es INTEGER
!>           A la entrada, M especifica el número de filas de la matriz A.
!>           M debe ser al menos cero.
!>           No modificado a la salida.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el número de columnas de la matriz A.
!>           N debe ser al menos cero.
!>           No modificado a la salida.
!>

ALPHA

!>          ALPHA es REAL
!>           A la entrada, ALPHA especifica el escalar alpha.
!>           No modificado a la salida.
!>

A

!>          A es un array REAL, dimensión ( LDA, n )
!>           Antes de la entrada, la parte principal de m por n del array A
!>           debe contener la matriz de coeficientes.
!>           No modificado a la salida.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A según
!>           se declara en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, m ).
!>           No modificado a la salida.
!>

X

!>          X es un array REAL, dimensión
!>           ( 1 + ( n - 1 )*abs( INCX ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( m - 1 )*abs( INCX ) ) en caso contrario.
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x.
!>           No modificado a la salida.
!>

INCX

!>          INCX es INTEGER
!>           A la entrada, INCX especifica el incremento para los elementos
!>           de X. INCX no debe ser cero.
!>           No modificado a la salida.
!>

BETA

!>          BETA es REAL
!>           A la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           proporciona como cero, Y no necesita estar configurado a la entrada.
!>           No modificado a la salida.
!>

Y

!>          Y es un array REAL,
!>           dimensión al menos
!>           ( 1 + ( m - 1 )*abs( INCY ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ) en caso contrario.
!>           Antes de la entrada con BETA distinto de cero, el array Y
!>           incrementado debe contener el vector y. A la salida, Y se
!>           sobrescribe con el vector y actualizado.
!>           Si m o n es cero, entonces Y no se referencia y la función
!>           realiza un retorno rápido.
!>

INCY

!>          INCY es INTEGER
!>           A la entrada, INCY especifica el incremento para los elementos
!>           de Y. INCY no debe ser cero.
!>           No modificado a la salida.
!>
!>  Rutina Blas de Nivel 2.
!>
