subrutina slaev2 (real a, real b, real c, real rt1, real rt2, real cs1, real sn1)

SLAEV2 calcula los valores y vectores propios de una matriz simétrica/hermitiana de 2x2.

Propósito:

!>
!> SLAEV2 calcula la descomposicion en valores propios de una matriz simétrica de 2x2
!>    [  A   B  ]
!>    [  B   C  ].
!> Al regresar, RT1 es el valor propio de mayor valor absoluto, RT2 es el
!> valor propio de menor valor absoluto, y (CS1,SN1) es el vector propio derecho unitario
!> para RT1, dando la descomposición
!>
!>    [ CS1  SN1 ] [  A   B  ] [ CS1 -SN1 ]  =  [ RT1  0  ]
!>    [-SN1  CS1 ] [  B   C  ] [ SN1  CS1 ]     [  0  RT2 ].
!>

Parámetros

A 
!>          A es REAL
!>          El elemento (1,1) de la matriz de 2x2.
!>

B

!>          B es REAL
!>          El elemento (1,2) y el conjugado del elemento (2,1) de
!>          la matriz de 2x2.
!>

C

!>          C es REAL
!>          El elemento (2,2) de la matriz de 2x2.
!>

RT1

!>          RT1 es REAL
!>          El valor propio de mayor valor absoluto.
!>

RT2

!>          RT2 es REAL
!>          El valor propio de menor valor absoluto.
!>

CS1

!>          CS1 es REAL
!>

SN1

!>          SN1 es REAL
!>          El vector (CS1, SN1) es un vector propio derecho unitario para RT1.
!>

Detalles Adicionales:

!>
!>  RT1 es preciso hasta unos pocos ulps, salvo desbordamiento/subdesbordamiento.
!>
!>  RT2 puede ser impreciso si hay cancelación masiva en el
!>  determinante A*C-B*B; se necesitaría aritmética de mayor precisión o redondeada
!>  correctamente o truncada correctamente para calcular RT2
!>  con precisión en todos los casos.
!>
!>  CS1 y SN1 son precisos hasta unos pocos ulps, salvo desbordamiento/subdesbordamiento.
!>
!>  El desbordamiento solo es posible si RT1 está dentro de un factor de 5 del desbordamiento.
!>  El subdesbordamiento es inofensivo si los datos de entrada son 0 o exceden
!>     underflow_threshold / macheps.
!>
