Documentación de función/subrutina

subroutine slatm1 (integer mode, real cond, integer irsign, integer idist, integer, dimension( 4 ) iseed, real, dimension( * ) d, integer n, integer info)

SLATM1

Propósito:

!>
!>    SLATM1 calcula las entradas de D(1..N) según lo especificado por
!>    MODE, COND e IRSIGN. IDIST e ISEED determinan la generación
!>    de números aleatorios. SLATM1 es llamada por SLATMR para generar
!>    matrices de prueba aleatorias para programas LAPACK.
!>

Parámetros

MODE 
!>          MODE es INTEGER
!>           En la entrada, describe cómo se debe calcular D:
!>           MODE = 0 significa no cambiar D.
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    están distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           No modificado.
!>

COND

!>          COND es REAL
!>           En la entrada, se utiliza según lo descrito bajo MODE arriba.
!>           Si se utiliza, debe ser >= 1. No modificado.
!>

IRSIGN

!>          IRSIGN es INTEGER
!>           En la entrada, si MODE no es -6, 0 ni 6, determina el signo de
!>           las entradas de D
!>           0 => deja las entradas de D sin cambios
!>           1 => multiplica cada entrada de D por 1 o -1 con probabilidad .5
!>

IDIST

!>          IDIST es INTEGER
!>           En la entrada, IDIST especifica el tipo de distribución a utilizar
!>           para generar una matriz aleatoria.
!>           1 => UNIFORM( 0, 1 )
!>           2 => UNIFORM( -1, 1 )
!>           3 => NORMAL( 0, 1 )
!>           No modificado.
!>

ISEED

!>          ISEED es array INTEGER, dimension ( 4 )
!>           En la entrada, ISEED especifica la semilla del generador de
!>           números aleatorios. El generador de números aleatorios utiliza una
!>           secuencia congruencial lineal limitada a enteros pequeños,
!>           y por lo tanto debe producir números aleatorios independientes
!>           de la máquina. Los valores de ISEED se cambian al salir,
!>           y se pueden usar en la siguiente llamada a SLATM1
!>           para continuar la misma secuencia de números aleatorios.
!>           Cambiado al salir.
!>

D

!>          D es array REAL, dimension ( N )
!>           Array a calcular según MODE, COND e IRSIGN.
!>           Puede ser modificado al salir si MODE es distinto de cero.
!>

N

!>          N es INTEGER
!>           Número de entradas de D. No modificado.
!>

INFO

!>          INFO es INTEGER
!>            0  => terminación normal
!>           -1  => si MODE no está en el rango -6 a 6
!>           -2  => si MODE no es -6, 0 ni 6, e
!>                  IRSIGN no es 0 ni 1
!>           -3  => si MODE no es -6, 0 ni 6 y COND es menor que 1
!>           -4  => si MODE es igual a 6 o -6 e IDIST no está en el rango 1 a 3
!>           -7  => si N es negativo
!>
