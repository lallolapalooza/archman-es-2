subroutine slaqsy (character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real scond, real amax, character equed)

SLAQSY escala una matriz simétrica/hermitiana, utilizando factores de escala calculados por spoequ.

Propósito:

!>
!> SLAQSY equilibra una matriz simétrica A utilizando los factores de
!> escala en el vector S.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior n por n principal de A contiene la parte triangular
!>          superior de la matriz A, y la parte estrictamente triangular
!>          inferior de A no se referencia.  Si UPLO = 'L', la parte
!>          inferior n por n principal de A contiene la parte triangular
!>          inferior de la matriz A, y la parte estrictamente triangular
!>          superior de A no se referencia.
!>
!>          En la salida, si EQUED = 'Y', la matriz equilibrada:
!>          diag(S) * A * diag(S).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(N,1).
!>

S

!>          S es un array REAL, de dimensión (N)
!>          Los factores de escala para A.
!>

SCOND

!>          SCOND es REAL
!>          Relación del S(i) más pequeño con el S(i) más grande.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto de la entrada de matriz más grande.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica si se realizó o no el equilibrado.
!>          = 'N':  No se realizó equilibrado.
!>          = 'Y':  Se realizó el equilibrado, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>

Parámetros internos:

!>  THRESH es un valor umbral utilizado para decidir si se debe realizar
!>  el escalado basándose en la relación de los factores de escala.
!>  Si SCOND < THRESH, se realiza el escalado.
!>
!>  LARGE y SMALL son valores umbral utilizados para decidir si se debe
!>  realizar el escalado basándose en el tamaño absoluto del elemento
!>  de matriz más grande.
!>  Si AMAX > LARGE o AMAX < SMALL, se realiza el escalado.
!>
