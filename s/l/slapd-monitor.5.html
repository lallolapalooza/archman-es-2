NOMBRE

slapd-monitor - Backend de monitorización para slapd

SINOPSIS

/etc/openldap/slapd.conf

DESCRIPCIÓN

El backend monitor de slapd(8) no es una base de datos real; si se habilita, se genera automáticamente y se mantiene dinámicamente por slapd con información sobre el estado de ejecución del demonio.

Para inspeccionar toda la información de monitorización, realice una búsqueda de subárbol con la base cn=Monitor, solicitando que se devuelvan los atributos "+" y "*". El backend de monitorización produce principalmente atributos operacionales, y LDAP solo devuelve atributos operacionales que se solicitan explícitamente. Solicitar el atributo "+" es una extensión que solicita todos los atributos operacionales.

CONFIGURACIÓN

Estas opciones de slapd.conf se aplican a la base de datos del backend monitor. Es decir, deben seguir una línea "database monitor" y preceder a cualquier línea posterior de "backend" o "database".

A diferencia de la mayoría de las bases de datos, la base de datos monitor solo puede instanciarse una vez, es decir, solo puede haber una ocurrencia de "database monitor" en el archivo slapd.conf(5). Además, el sufijo de la base de datos no se puede establecer explícitamente mediante la directiva suffix. El sufijo se establece automáticamente en "cn=Monitor".

La base de datos monitor respeta las directivas rootdn y rootpw, y las directivas ACL habituales, por ejemplo, la directiva access.

Otras opciones de base de datos se describen en la página del manual de slapd.conf(5).

USO

El uso es:

1) habilitar el backend monitor en la configuración:
configure --enable-monitor
2) activar la base de datos monitor en el archivo slapd.conf(5):
database monitor
3) añadir ACLs como se detalla en slapd.access(5) para controlar el acceso a la base de datos, por ejemplo:
access to dn.subtree="cn=Monitor"
	by dn.exact="uid=Admin,dc=my,dc=org" write
	by users read
	by * none
4) asegurarse de que se carga el archivo core.schema.
El backend monitor depende de algunos types de atributos de seguimiento estándar que deben estar definidos cuando se inicia el backend.

CONTROL DE ACCESO

El backend monitor respeta la semántica de control de acceso indicada en slapd.access(5), incluido el privilegio de acceso disclose, en todas las operaciones implementadas actualmente.

LIMITACIONES CONOCIDAS

El backend monitor no respeta los límites de tamaño/tiempo en las operaciones de búsqueda.

ARCHIVOS

/etc/openldap/slapd.conf
archivo de configuración predeterminado de slapd

VER TAMBIÉN

slapd.conf(5), slapd-config(5), slapd.access(5), slapd(8), ldap(3).
