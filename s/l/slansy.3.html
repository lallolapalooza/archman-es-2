función real slansy (norm, uplo, n, a, lda, work)

SLANSY devuelve el valor de la norma 1, o la norma de Frobenius, o la norma del infinito, o el elemento de mayor valor absoluto de una matriz simétrica real.

Documentación de la función/subrutina

real función slansy (character norm, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) work)

SLANSY devuelve el valor de la norma 1, o la norma de Frobenius, o la norma del infinito, o el elemento de mayor valor absoluto de una matriz simétrica real.

Propósito:

!>
!> SLANSY  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma del infinito,  o el elemento de mayor valor absoluto de una
!> matriz simétrica real A.
!>

Devuelve

SLANSY 
!>
!>    SLANSY = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columnas),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de filas) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma
!> de los cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en SLANSY como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se hace referencia a la parte triangular superior o inferior de
!>          la matriz simétrica A.
!>          = 'U':  Se hace referencia a la parte triangular superior de A
!>          = 'L':  Se hace referencia a la parte triangular inferior de A
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, SLANSY se
!>          establece a cero.
!>

A

!>          A es un array REAL, con dimensión (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte triangular superior
!>          de n por n de A contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior de A
!>          no se referencia.  Si UPLO = 'L', la parte triangular inferior
!>          de n por n de A contiene la parte triangular inferior
!>          de la matriz A, y la parte estrictamente triangular superior de A
!>          no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(N,1).
!>

WORK

!>          WORK es un array REAL, con dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' or '1' or 'O'; de lo contrario,
!>          WORK no se referencia.
!>
