SLARRD calcula los valores propios de una matriz tridiagonal simétrica con la precisión adecuada.

Documentación de función/subrutina

subrutina slarrd (character range, character order, integer n, real vl, real vu, integer il, integer iu, real, dimension( * ) gers, real reltol, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) e2, real pivmin, integer nsplit, integer, dimension( * ) isplit, integer m, real, dimension( * ) w, real, dimension( * ) werr, real wl, real wu, integer, dimension( * ) iblock, integer, dimension( * ) indexw, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLARRD calcula los valores propios de una matriz tridiagonal simétrica con la precisión adecuada. Esta es una rutina auxiliar que se llamará desde SSTEMR. El usuario puede solicitar todos los valores propios, todos los valores propios en el intervalo semiabierto (VL, VU], o los valores propios del IL-ésimo al IU-ésimo. Para evitar desbordamientos, la matriz debe escalarse de modo que su elemento más grande no exceda overflow**(1/2) * underflow**(1/4) en valor absoluto, y para máxima precisión, no debe ser mucho menor que eso. Véase W. Kahan, Report CS41, Computer Science Dept., Stanford University, 21 de julio de 1966.

Parámetros

RANGE 
!>          RANGE es CHARACTER*1
!>          = 'A': ()   se encontrarán todos los valores propios.
!>          = 'V': () se encontrarán todos los valores propios en el
!>                           intervalo semiabierto (VL, VU].
!>          = 'I': () se encontrarán los valores propios del IL-ésimo al IU-ésimo
!>                           (de la matriz completa).
!>

ORDER

!>          ORDER es CHARACTER*1
!>          = 'B': () los valores propios se agruparán por
!>                              bloque de separación (ver IBLOCK, ISPLIT) y
!>                              se ordenarán de menor a mayor dentro de
!>                              cada bloque.
!>          = 'E': ()
!>                              los valores propios para la matriz completa
!>                              se ordenarán de menor a
!>                              mayor.
!>

N

!>          N es INTEGER
!>          El orden de la matriz tridiagonal T.  N >= 0.
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. Los valores propios menores o
!>          iguales a VL, o mayores que VU, no se devolverán. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. Los valores propios menores o
!>          iguales a VL, o mayores que VU, no se devolverán. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

GERS

!>          GERS es array REAL, dimension (2*N)
!>          Los N intervalos de Gerschgorin (el i-ésimo intervalo de
!>          Gerschgorin es (GERS(2*i-1), GERS(2*i)).
!>

RELTOL

!>          RELTOL es REAL
!>          El ancho relativo mínimo de un intervalo. Cuando un intervalo
!>          es más estrecho que RELTOL veces el extremo más grande (en
!>          magnitud), se considera suficientemente pequeño, es decir,
!>          convergido. Nota: esto siempre debe ser al menos epsilon*máquina.
!>

D

!>          D es array REAL, dimension (N)
!>          Los N elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es array REAL, dimension (N-1)
!>          Los N-1 elementos fuera de la diagonal de la matriz tridiagonal T.
!>

E2

!>          E2 es array REAL, dimension (N-1)
!>          Los N-1 elementos fuera de la diagonal al cuadrado de la matriz
!>          tridiagonal T.
!>

PIVMIN

!>          PIVMIN es REAL
!>          El pivote mínimo permitido en la secuencia de Sturm para T.
!>

NSPLIT

!>          NSPLIT es INTEGER
!>          El número de bloques diagonales en la matriz T.
!>          1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT es array INTEGER, dimension (N)
!>          Los puntos de separación, en los que T se divide en submatrices.
!>          La primera submatriz consta de las filas/columnas 1 a ISPLIT(1),
!>          la segunda de las filas/columnas ISPLIT(1)+1 a ISPLIT(2),
!>          etc., y la NSPLIT-ésima consta de las filas/columnas
!>          ISPLIT(NSPLIT-1)+1 a ISPLIT(NSPLIT)=N.
!>          (Solo se utilizarán los primeros NSPLIT elementos, pero
!>          como el usuario no puede saber de antemano qué valor tendrá NSPLIT,
!>          se deben reservar N palabras para ISPLIT.)
!>

M

!>          M es INTEGER
!>          El número real de valores propios encontrados. 0 <= M <= N.
!>          (Ver también la descripción de INFO=2,3).
!>

W

!>          W es array REAL, dimension (N)
!>          A la salida, los primeros M elementos de W contendrán las
!>          aproximaciones de los valores propios. SLARRD calcula un intervalo
!>          I_j = (a_j, b_j] que incluye el valor propio j. La aproximación
!>          del valor propio se da como el punto medio del intervalo
!>          W(j)= ( a_j + b_j)/2. El error correspondiente está acotado por
!>          WERR(j) = abs( a_j - b_j)/2
!>

WERR

!>          WERR es array REAL, dimension (N)
!>          El límite de error en la aproximación del valor propio

!>

WL

!>          WL es REAL

NAME


slarrd


real general tridiagonal matrix eigenvalue problem






SYNOPSIS


    SUBROUTINE SLARRD( N, VL, VU, IL, IU, ABSTOL, W, Z, IZ, WORK, IWORK, INFO )

        INTEGER            IL, INFO, IU, IZ, N
        REAL               ABSTOL, VL, VU
        REAL               W( * ), Z( * )
        INTEGER            IWORK( * )
        REAL               WORK( * )







Function/Subroutine Documentation


SLARRD is a real general tridiagonal matrix eigenvalue problem.


This subroutine computes the eigenvalues of a real general tridiagonal matrix T. T is assumed to be the matrix F*A where A is a real symmetric tridiagonal matrix and F is a real diagonal matrix with positive entries.


Description:




This routine computes the desired eigenvalues of the matrix A = inv(F)*T,
where F is a real diagonal matrix with positive entries and T is a real
general tridiagonal matrix.
    Let T = diag(F_i) * ( D + subdiag(E) + supdiag(E) )
where F_i are entries of a real diagonal matrix F with F_i > 0.
Let A = inv(F) * T = D + inv(F) * subdiag(E) + inv(F) * supdiag(E).
Let D = diag(D_i)
Let E be a real vector of length N-1.
Let subdiag(E) be the subdiagonal matrix with entries E_i.
Let supdiag(E) be the superdiagonal matrix with entries E_i.
Then A is a real symmetric tridiagonal matrix.





Parameters:




N




INTEGER. (Input)


The order of the matrix A. N >= 0.




VL




REAL. (Input)


If RANGE = 'A' or 'V', VL is the lower bound of the
    eigenvalues to be computed.




VU




REAL. (Input)


If RANGE = 'A' or 'V', VU is the upper bound of the
    eigenvalues to be computed.




IL




INTEGER. (Input)


If RANGE = 'I', IL is the index of the smallest
    eigenvalue to be computed.




IU




INTEGER. (Input)


If RANGE = 'I', IU is the index of the largest
    eigenvalue to be computed.




ABSTOL




REAL. (Input)


The absolute tolerance to use for convergence. See
    description below.




W




REAL array, dimension (N).


The computed eigenvalues, in ascending order. If
    INFO = 0 and RANGE = 'I', then the values IL to IU are the
    indices of the eigenvalues found.




Z




REAL array, dimension (IZ, M).


The computed eigenvectors, with the k-th column of Z
    being the eigenvector corresponding to the k-th eigenvalue
    in W. The eigenvectors are normalized so that the largest
    component has absolute value 1.




IZ




INTEGER.


The number of rows in the array Z. IZ >= 1.




WORK




REAL array, dimension (4*N).


On exit:




WORK(1:N) contains the diagonal entries of the matrix A.
WORK(N+1:2*N) contains the subdiagonal entries of the matrix A, with WORK(N)
              being unused.
WORK(2*N+1:3*N) contains the superdiagonal entries of the matrix A, with
                WORK(2*N) being unused.







IWORK




INTEGER array, dimension (3*N).


On exit:




IWORK(1:N) contains the indices of the eigenvalues within each block (submatrix);
            for example, INDEXW(i)= j and IBLOCK(i)=k imply that the
            i-th eigenvalue W(i) is the j-th eigenvalue in block k.







INFO




INTEGER.


= 0: successful exit


< 0: if INFO = -i, the i-th argument had an illegal value


> 0: some or all of the eigenvalues failed to converge or
    were not computed:




=1 or 3: Bisection failed to converge for some
                        eigenvalues; these eigenvalues are flagged by a
                        negative block number.  The effect is that the
                        eigenvalues may not be as accurate as the
                        absolute and relative tolerances.  This is
                        generally caused by unexpectedly inaccurate
                        arithmetic.
                =2 or 3: RANGE='I' only: Not all of the eigenvalues
                        IL:IU were found.
                        Effect: M < IU+1-IL
                        Cause:  non-monotonic arithmetic, causing the
                                Sturm sequence to be non-monotonic.
                        Cure:   recalculate, using RANGE='A', and pick
                                out eigenvalues IL:IU.  In some cases,
                                increasing the PARAMETER  may
                                make things work.
                =4:    RANGE='I', and the Gershgorin interval
                        initially used was too small.  No eigenvalues
                        were computed.
                        Probable cause: your machine has sloppy
                                        floating-point arithmetic.
                        Cure: Increase the PARAMETER ,
                              recompile, and try again.









Internal Parameters:




 FUDGE   REAL, default = 2
          A  to widen the Gershgorin intervals.  Ideally,
          a value of 1 should work, but on machines with sloppy
          arithmetic, this needs to be larger.  The default for
          publicly released versions should be large enough to handle
          the worst machine around.  Note that this has no effect
          on accuracy of the solution.
