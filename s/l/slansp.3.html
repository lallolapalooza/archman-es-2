función real slansp (norm, uplo, n, ap, work)
SLANSP devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz simétrica suministrada en forma empaquetada.

Documentación de la Función/Subrutina

real función slansp (carácter norm, carácter uplo, entero n, real, dimensión(* ) ap, real, dimensión(* ) work)

SLANSP devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz simétrica suministrada en forma empaquetada.

Propósito:

!>
!> SLANSP  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma  infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz simétrica real A,  suministrada en forma empaquetada.
!>

Devuelve

SLANSP 
!>
!>    SLANSP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columnas),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de filas) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM is CHARACTER*1
!>          Especifica el valor que se devolverá en SLANSP como se describe
!>          arriba.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          Especifica si se suministra la parte triangular superior o inferior de
!>          la matriz simétrica A.
!>          = 'U':  Se suministra la parte triangular superior de A
!>          = 'L':  Se suministra la parte triangular inferior de A
!>

N

!>          N is INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, SLANSP se
!>          establece en cero.
!>

AP

!>          AP is REAL array, dimension (N*(N+1)/2)
!>          La parte triangular superior o inferior de la matriz simétrica A, empaquetada
!>          columna a columna en un array lineal.  La j-ésima columna de A se almacena
!>          en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' o '1' o 'O'; de lo contrario,
!>          WORK no se referencia.
!>
