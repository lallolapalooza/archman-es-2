NOMBRE

slapo-pbind - overlay de proxy bind para slapd

SINOPSIS

/etc/openldap/slapd.conf

DESCRIPCIÓN

El overlay pbind para slapd(8) reenvía los Binds Simples en una base de datos local a un servidor LDAP remoto en lugar de procesarlos localmente. La conexión remota se gestiona utilizando una instancia del backend ldap.

El overlay pbind utiliza un subconjunto de las directivas de configuración del backend ldap. Se describen con más detalle en slapd-ldap(5).

Nota: este overlay está integrado en el backend ldap; no es un módulo separado.

overlay pbind
Esta directiva añade el overlay de proxy bind al backend actual. El overlay de proxy bind puede utilizarse con cualquier backend, pero está principalmente pensado para su uso con backends de almacenamiento local.
uri <ldapurl>
Servidor LDAP a utilizar.
tls <parámetros TLS>
Especifica el uso de TLS.
network-timeout <tiempo>
Establece el tiempo de espera de red.
quarantine <parámetros de cuarentena>
Activa la cuarentena de URIs que devolvieron LDAP_UNAVAILABLE.

ARCHIVOS

/etc/openldap/slapd.conf
archivo de configuración predeterminado de slapd

VER TAMBIÉN

slapd.conf(5), slapd-config(5), slapd-ldap(5), slapd(8).
