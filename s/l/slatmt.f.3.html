SLATMT

Documentación de Función/Subrutina

subroutine slatmt (integer m, integer n, character dist, integer, dimension( 4 ) iseed, character sym, real, dimension( * ) d, integer mode, real cond, real dmax, integer rank, integer kl, integer ku, character pack, real, dimension( lda, * ) a, integer lda, real, dimension( * ) work, integer info)

SLATMT

Propósito:

!>
!>    SLATMT genera matrices aleatorias con valores singulares especificados
!>    (o matrices simétricas/hermitianas con valores propios especificados)
!>    para probar programas LAPACK.
!>
!>    SLATMT opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Establecer la diagonal en D, donde D puede ser de entrada o
!>         calculada según MODE, COND, DMAX y SYM
!>         como se describe a continuación.
!>
!>      Generar una matriz con la estructura de banda apropiada, mediante uno
!>         de dos métodos:
!>
!>      Método A:
!>          Generar una matriz densa M x N multiplicando D por izquierda
!>              y por derecha por matrices unitarias aleatorias, y luego:
!>
!>          Reducir el ancho de banda según KL y KU, usando
!>          transformaciones de Householder.
!>
!>      Método B:
!>          Convertir una matriz de ancho de banda cero (es decir, diagonal) a una
!>              matriz de ancho de banda uno usando rotaciones de Givens,
!>              llevando los elementos fuera de banda hacia atrás, de forma similar a QR; luego
!>              convertir de ancho de banda uno a ancho de banda dos, etc.
!>              Nótese que para anchos de banda razonablemente pequeños (en relación con
!>              M y N) esto requiere menos almacenamiento, ya que no se genera una matriz densa.
!>              Además, para matrices simétricas, solo se genera un triángulo.
!>
!>      Se elige el Método A si el ancho de banda es una fracción grande del
!>          orden de la matriz, y LDA es al menos M (para poder almacenar una matriz
!>          densa). Se elige el Método B si el ancho de banda
!>          es pequeño (< 1/2 N para simétrica, < .3 N+M para
!>          no simétrica), o LDA es menor que M y no menor que el
!>          ancho de banda.
!>
!>      Empaquetar la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetar
!>         poner a cero la mitad superior (si es simétrica)
!>         poner a cero la mitad inferior (si es simétrica)
!>         almacenar la mitad superior columna por columna (si es simétrica o
!>               triangular superior)
!>         almacenar la mitad inferior columna por columna (si es simétrica o
!>               triangular inferior)
!>         almacenar el triángulo inferior en formato de banda (si es simétrica o
!>               triangular inferior)
!>         almacenar el triángulo superior en formato de banda (si es simétrica o
!>               triangular superior)
!>         almacenar toda la matriz en formato de banda
!>      Si se elige el Método B, y se especifica el formato de banda, entonces la
!>         matriz se generará en formato de banda, por lo que no será necesario
!>         reempaquetar.
!>

Parámetros

M 
!>          M es INTEGER
!>           El número de filas de A. No modificado.
!>

N

!>          N es INTEGER
!>           El número de columnas de A. No modificado.
!>

DIST

!>          DIST es CHARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución que se utilizará
!>           para generar los valores propios/singulares aleatorios.
!>           'U' => UNIFORME( 0, 1 )  ( 'U' para uniforme )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' para simétrico )
!>           'N' => NORMAL( 0, 1 )   ( 'N' para normal )
!>           No modificado.
!>

ISEED

!>          ISEED es un array INTEGER, de dimensión ( 4 )
!>           En la entrada, ISEED especifica la semilla del generador de números
!>           aleatorios. Deben estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números
!>           aleatorios utiliza una secuencia congruencial lineal limitada a enteros
!>           pequeños, y por lo tanto debería producir números aleatorios independientes de la máquina.
!>           Los valores de ISEED se modifican a la salida y pueden usarse en la siguiente llamada
!>           a SLATMT para continuar la misma secuencia de números aleatorios.
!>           Modificado a la salida.
!>

SYM

!>          SYM es CHARACTER*1
!>           Si SYM='S' o 'H', la matriz generada es simétrica, con
!>             valores propios especificados por D, COND, MODE y DMAX; pueden
!>             ser positivos, negativos o cero.
!>           Si SYM='P', la matriz generada es simétrica, con
!>             valores propios (= valores singulares) especificados por D, COND,
!>             MODE y DMAX; no serán negativos.
!>           Si SYM='N', la matriz generada es no simétrica, con
!>             valores singulares especificados por D, COND, MODE y DMAX;
!>             no serán negativos.
!>           No modificado.
!>

D

!>          D es un array REAL, de dimensión ( MIN( M , N ) )
!>           Este array se utiliza para especificar los valores singulares o
!>           valores propios de A (ver SYM, arriba.) Si MODE=0, entonces D
!>           se asume que contiene los valores propios/singulares, de lo contrario
!>           se calcularán según MODE, COND y DMAX,
!>           y se colocarán en D.
!>           Modificado si MODE es distinto de cero.
!>

MODE

!>          MODE es INTEGER
!>           En la entrada, esto describe cómo se especificarán los valores propios/singulares:
!>           MODE = 0 significa usar D como entrada
!>
!>           MODE = 1 establece D(1)=1 y D(2:RANK)=1.0/COND
!>           MODE = 2 establece D(1:RANK-1)=1 y D(RANK)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(RANK-1))
!>
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que van de
!>              1 a 1/COND, si es negativo, de 1/COND a 1,
!>           Si SYM='S' o 'H', y MODE no es 0, 6 ni -6, entonces
!>              los elementos de D también se multiplicarán por un signo aleatorio
!>              (es decir, +1 o -1.)
!>           No modificado.
!>

COND

!>          COND es REAL
!>           En la entrada, se usa como se describe en MODE arriba.
!>           Si se usa, debe ser >= 1. No modificado.
!>

DMAX

!>          DMAX es REAL
!>           Si MODE no es -6, 0 ni 6, los contenidos de D, como se
!>           calculan según MODE y COND, se escalarán por
!>           DMAX / max(abs(D(i))); por lo tanto, el valor propio o singular
!>           máximo en valor absoluto será abs(DMAX).
!>           Nótese que DMAX no tiene por qué ser positivo: si DMAX es negativo
!>           (o cero), D se escalará por un número negativo (o cero).
!>           No modificado.
!>

RANK

!>          RANK es INTEGER
!>           El rango de la matriz a generar para los modos 1, 2, 3 únicamente.
!>           D( RANK+1:N ) = 0.
!>           No modificado.
!>

KL

!>          KL es INTEGER
!>           Esto especifica el ancho de banda inferior de la matriz. Por ejemplo,
!>           KL=0 implica triangular superior, KL=1 implica Hessenberg superior,
!>           y KL siendo al menos M-1 significa que la matriz tiene ancho de banda
!>           inferior completo. KL debe ser igual a KU si la matriz es simétrica.
!>           No modificado.
!>

KU

!>
KU es ENTERO !> Esto especifica el ancho de banda superior de la matriz. Por !> ejemplo, KU=0 implica triangular inferior, KU=1 implica !> Hessenberg inferior, y KU siendo al menos N-1 significa que !> la matriz tiene ancho de banda superior completo. KL debe ser !> igual a KU si la matriz es simétrica. !> No modificado. !>

PACK

!>          PACK es CARACTER*1
!>           Esto especifica el empaquetado de la matriz de la siguiente manera:
!>           'N' => sin empaquetado
!>           'U' => poner a cero todas las entradas subdiagonales (si es simétrica)
!>           'L' => poner a cero todas las entradas superdiagonales (si es simétrica)
!>           'C' => almacenar el triángulo superior columna por columna
!>                  (solo si la matriz es simétrica o triangular superior)
!>           'R' => almacenar el triángulo inferior columna por columna
!>                  (solo si la matriz es simétrica o triangular inferior)
!>           'B' => almacenar el triángulo inferior en el esquema de almacenamiento de banda
!>                  (solo si la matriz es simétrica o triangular inferior)
!>           'Q' => almacenar el triángulo superior en el esquema de almacenamiento de banda
!>                  (solo si la matriz es simétrica o triangular superior)
!>           'Z' => almacenar la matriz completa en el esquema de almacenamiento de banda
!>                      (el pivoteo puede proporcionarse utilizando esta
!>                      opción para almacenar A en las filas finales del
!>                      almacenamiento asignado)
!>
!>           Usando estas opciones, se pueden obtener los diversos esquemas
!>           de almacenamiento empaquetados y de banda de LAPACK:
!>           GB               - usar 'Z'
!>           PB, SB o TB     - usar 'B' o 'Q'
!>           PP, SP o TP     - usar 'C' o 'R'
!>
!>           Si dos llamadas a SLATMT difieren solo en el parámetro PACK,
!>           generarán matrices matemáticamente equivalentes.
!>           No modificado.
!>

A

!>          A es un array REAL, de dimensión ( LDA, N )
!>           A la salida, A es la matriz de prueba deseada. A se genera primero
!>           en forma completa (desempaquetada) y luego se empaqueta, si así se especifica
!>           por PACK. Por lo tanto, los primeros M elementos de las primeras N
!>           columnas se modificarán siempre. Si PACK especifica un esquema de
!>           almacenamiento empaquetado o de banda, se modificarán todos los elementos LDA de las
!>           primeras N columnas; los elementos del array que no corresponden a elementos de la
!>           matriz generada se pondrán a cero.
!>           Modificado.
!>

LDA

!>          LDA es ENTERO
!>           LDA especifica la primera dimensión de A tal como se declaró en el
!>           programa de llamada. Si PACK='N', 'U', 'L', 'C', o 'R', entonces
!>           LDA debe ser al menos M. Si PACK='B' o 'Q', entonces LDA debe
!>           ser al menos MIN( KL, M-1) (que es igual a MIN(KU,N-1)).
!>           Si PACK='Z', LDA debe ser lo suficientemente grande para contener el
!>           array empaquetado: MIN( KU, N-1) + MIN( KL, M-1) + 1.
!>           No modificado.
!>

WORK

!>          WORK es un array REAL, de dimensión ( 3*MAX( N , M ) )
!>           Espacio de trabajo.
!>           Modificado.
!>

INFO

!>          INFO es ENTERO
!>           Código de error. A la salida, INFO se establecerá a uno de los
!>           siguientes valores:
!>             0 => retorno normal
!>            -1 => M negativo o desigual a N y SYM='S', 'H', o 'P'
!>            -2 => N negativo
!>            -3 => DIST cadena ilegal
!>            -5 => SYM cadena ilegal
!>            -7 => MODE no está en el rango -6 a 6
!>            -8 => COND menor que 1.0, y MODE ni -6, 0 ni 6
!>           -10 => KL negativo
!>           -11 => KU negativo, o SYM='S' o 'H' y KU no es igual a KL
!>           -12 => PACK cadena ilegal, o PACK='U' o 'L', y SYM='N';
!>                  o PACK='C' o 'Q' y SYM='N' y KL no es cero;
!>                  o PACK='R' o 'B' y SYM='N' y KU no es cero;
!>                  o PACK='U', 'L', 'C', 'R', 'B', o 'Q', y M no es
!>                  N.
!>           -14 => LDA es menor que M, o PACK='Z' y LDA es menor que
!>                  MIN(KU,N-1) + MIN(KL,M-1) + 1.
!>            1  => Retorno de error de SLATM7
!>            2  => No se puede escalar a DMAX (el valor singular máximo es 0)
!>            3  => Retorno de error de SLAGGE o SLAGSY
!>
