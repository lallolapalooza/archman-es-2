subroutine slals0 (integer icompq, integer nl, integer nr, integer sqre, integer nrhs, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldbx, * ) bx, integer ldbx, integer, dimension( * ) perm, integer givptr, integer, dimension( ldgcol, * ) givcol, integer ldgcol, real, dimension( ldgnum, * ) givnum, integer ldgnum, real, dimension( ldgnum, * ) poles, real, dimension( * ) difl, real, dimension( ldgnum, * ) difr, real, dimension( * ) z, integer k, real c, real s, real, dimension( * ) work, integer info)

SLALS0 aplica multiplicadores de retroceso de la matriz singular izquierda o derecha de una matriz diagonal a la que se le añade una fila a la matriz del lado derecho B al resolver el problema de mínimos cuadrados usando el enfoque SVD de divide y vencerás.

Propósito:

!>
!> SLALS0 aplica los multiplicadores de retroceso de la matriz singular
!> izquierda o derecha de una matriz diagonal a la que se le añade una fila
!> a la matriz del lado derecho B al resolver el problema de mínimos
!> cuadrados usando el enfoque SVD de divide y vencerás.
!>
!> Para la matriz singular izquierda, se involucran tres tipos de matrices
!> ortogonales:
!>
!> (1L) Rotaciones de Givens: el número de tales rotaciones es GIVPTR; los
!> pares de columnas/filas a los que se aplicaron están almacenados en
!> GIVCOL; y los valores C y S de estas rotaciones están almacenados en
!> GIVNUM.
!>
!> (2L) Permutación. La fila (NL+1) de B se moverá a la primera fila, y
!> para J=2:N, la fila PERM(J) de B se moverá a la J-ésima fila.
!>
!> (3L) La matriz singular izquierda de la matriz restante.
!>
!> Para la matriz singular derecha, se involucran cuatro tipos de matrices
!> ortogonales:
!>
!> (1R) La matriz singular derecha de la matriz restante.
!>
!> (2R) Si SQRE = 1, una rotación de Givens adicional para generar el
!> espacio nulo derecho.
!>
!> (3R) La transformación inversa de (2L).
!>
!> (4R) La transformación inversa de (1L).
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>         Especifica si se van a calcular los vectores singulares en
!>         forma factorizada:
!>         = 0: Matriz singular izquierda.
!>         = 1: Matriz singular derecha.
!>

NL

!>          NL es INTEGER
!>         La dimensión de fila del bloque superior. NL >= 1.
!>

NR

!>          NR es INTEGER
!>         La dimensión de fila del bloque inferior. NR >= 1.
!>

SQRE

!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada de NRxNR.
!>         = 1: el bloque inferior es una matriz rectangular de NRx(NR+1).
!>
!>         La matriz bidiagonal tiene dimensión de fila N = NL + NR + 1,
!>         y dimensión de columna M = N + SQRE.
!>

NRHS

!>          NRHS es INTEGER
!>         El número de columnas de B y BX. NRHS debe ser al menos 1.
!>

B

!>          B es array REAL, dimension ( LDB, NRHS )
!>         En la entrada, B contiene los lados derechos del problema de
!>         mínimos cuadrados en las filas 1 a M. En la salida, B contiene
!>         la solución X en las filas 1 a N.
!>

LDB

!>          LDB es INTEGER
!>         La dimensión principal de B. LDB debe ser al menos
!>         max(1,MAX( M, N ) ).
!>

BX

!>          BX es array REAL, dimension ( LDBX, NRHS )
!>

LDBX

!>          LDBX es INTEGER
!>         La dimensión principal de BX.
!>

PERM

!>          PERM es array INTEGER, dimension ( N )
!>         Las permutaciones (de deflación y ordenamiento) aplicadas
!>         a los dos bloques.
!>

GIVPTR

!>          GIVPTR es INTEGER
!>         El número de rotaciones de Givens que ocurrieron en este
!>         subproblema.
!>

GIVCOL

!>          GIVCOL es array INTEGER, dimension ( LDGCOL, 2 )
!>         Cada par de números indica un par de filas/columnas
!>         involucradas en una rotación de Givens.
!>

LDGCOL

!>          LDGCOL es INTEGER
!>         La dimensión principal de GIVCOL, debe ser al menos N.
!>

GIVNUM

!>          GIVNUM es array REAL, dimension ( LDGNUM, 2 )
!>         Cada número indica el valor C o S utilizado en la
!>         rotación de Givens correspondiente.
!>

LDGNUM

!>          LDGNUM es INTEGER
!>         La dimensión principal de los arrays DIFR, POLES y
!>         GIVNUM, debe ser al menos K.
!>

POLES

!>          POLES es array REAL, dimension ( LDGNUM, 2 )
!>         En la entrada, POLES(1:K, 1) contiene los nuevos valores
!>         singulares obtenidos al resolver la ecuación secular, y
!>         POLES(1:K, 2) es un array que contiene los polos en la
!>         ecuación secular.
!>

DIFL

!>          DIFL es array REAL, dimension ( K ).
!>         En la entrada, DIFL(I) es la distancia entre el I-ésimo valor
!>         singular actualizado (no desdeflado) y el I-ésimo valor
!>         singular antiguo (no desdeflado).
!>

DIFR

!>          DIFR es array REAL, dimension ( LDGNUM, 2 ).
!>         En la entrada, DIFR(I, 1) contiene las distancias entre el I-ésimo
!>         valor singular actualizado (no desdeflado) y el (I+1)-ésimo
!>         valor singular antiguo (no desdeflado). Y DIFR(I, 2) es el
!>         factor de normalización para el I-ésimo vector singular
!>         derecho.
!>

Z

!>          Z es array REAL, dimension ( K )
!>         Contiene los componentes del vector de fila de actualización
!>         ajustado por deflación.
!>

K

!>          K es INTEGER
!>         Contiene la dimensión de la matriz no desdeflada,
!>         este es el orden de la ecuación secular relacionada. 1 <= K <=N.
!>

C

!>          C es REAL
!>         C contiene basura si SQRE = 0 y el valor C de una rotación
!>         de Givens relacionada con el espacio nulo derecho si SQRE = 1.
!>

S

!>          S es REAL
!>         S contiene basura si SQRE = 0 y el valor S de una rotación
!>         de Givens relacionada con el espacio nulo derecho si SQRE = 1.
!>

WORK

!>          WORK es array REAL, dimension ( K )
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Este procedimiento devuelve la norma de la submatriz de una matriz general, que es una de las normas matriciales de uso más común. La norma es

|| A ||1 = maxj ( Σi | aij | )

y la norma de Frobenius es

|| A ||F = ( Σi Σj | aij |2 )1/2

El procedimiento solo puede calcular una norma de matriz si el tipo de máquina está disponibles y se puede calcular la subrutina de la norma de matriz a través de la entrada XERBLA.

Los valores de entrada no válidos son los argumentos que violan alguna de las siguientes condiciones:

  • [A] y [B] son las matrices

  • [X] y [Y] son los vectores

  • M y N se deben ser > 0.

  • LDX y LDY deben ser > 0.

  • [X] y [Y] deben ser matrices y las filas y columnas deben ser

code.
