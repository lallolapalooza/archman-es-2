subroutine slafts (character*3 type, integer m, integer n, integer imat, integer ntests, real, dimension( * ) result, integer, dimension( 4 ) iseed, real thresh, integer iounit, integer ie)

SLAFTS

Propósito:

!>
!>    SLAFTS comprueba el vector de resultado contra el valor umbral para ver
!>    qué pruebas para este tipo de matriz no superaron el umbral.
!>    La salida va al archivo dado por la unidad IOUNIT.
!> 
!>  TYPE   - CHARACTER*3
!>           A la entrada, TYPE especifica el tipo de matriz a utilizar en los
!>           mensajes impresos.
!>           No modificado.
!>
!>  N      - INTEGER
!>           A la entrada, N especifica el orden de la matriz de prueba.
!>           No modificado.
!>
!>  IMAT   - INTEGER
!>           A la entrada, IMAT especifica el tipo de la matriz de prueba.
!>           Una lista de los diferentes tipos es impresa por SLAHD2
!>           en el archivo de salida si una prueba no supera el umbral.
!>           No modificado.
!>
!>  NTESTS - INTEGER
!>           A la entrada, NTESTS es el número de pruebas realizadas en las
!>           subrutinas en la ruta dada por TYPE.
!>           No modificado.
!>
!>  RESULT - REAL               array de dimensión( NTESTS )
!>           A la entrada, RESULT contiene las relaciones de prueba de las pruebas
!>           realizadas en el programa de llamada.
!>           No modificado.
!>
!>  ISEED  - INTEGER            array de dimensión( 4 )
!>           Contiene la semilla aleatoria que generó la matriz utilizada
!>           para las pruebas cuyas relaciones están en RESULT.
!>           No modificado.
!>
!>  THRESH - REAL
!>           A la entrada, THRESH especifica el umbral aceptable de las
!>           relaciones de prueba. Si RESULT( K ) > THRESH, entonces la K-ésima prueba
!>           no superó el umbral y se imprimirá un mensaje.
!>           No modificado.
!>
!>  IOUNIT - INTEGER
!>           A la entrada, IOUNIT especifica el número de unidad del archivo
!>           al que se imprimen los mensajes.
!>           No modificado.
!>
!>  IE     - INTEGER
!>           A la entrada, IE contiene el número de pruebas que han
!>           fallado en superar el umbral hasta ahora.
!>           Se actualiza a la salida si alguna de las relaciones en RESULT también falla.
!>
