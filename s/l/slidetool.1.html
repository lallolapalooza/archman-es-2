SLIDETOOL(1) Comandos de usuario SLIDETOOL(1)

NOMBRE

slidetool - Recuperar datos de imágenes de portaobjetos completos

SINOPSIS

slidetool [--ayuda] [--versión]
slidetool assoc icc leer nombre-archivo [archivo-salida]
slidetool assoc listar archivo...
slidetool assoc leer nombre-archivo [archivo-salida]
slidetool prop obtener propiedad archivo...
slidetool prop listar [--nombres] archivo...
slidetool region icc leer archivo [archivo-salida]
slidetool region leer archivo x y nivel ancho alto [archivo-salida]
slidetool slide abrir archivo...
slidetool slide quickhash1 archivo...
slidetool slide proveedor archivo...

DESCRIPCIÓN

slidetool utiliza OpenSlide para recuperar datos de imágenes de portaobjetos completos, también conocidas como archivos de imagen virtual.

slidetool assoc icc leer

Escribe el perfil de color ICC de la imagen asociada en archivo-salida si se especifica, y de lo contrario a la salida estándar. Si no hay un perfil de color ICC disponible, falla.

slidetool assoc listar

Lista las imágenes asociadas para uno o más portaobjetos. Las imágenes asociadas son imágenes pequeñas no piramidales que contienen información adicional sobre el portaobjeto, como su etiqueta.

slidetool assoc leer

Escribe la imagen asociada con el nombre especificado en una imagen PNG. Si no se especifica archivo-salida, la imagen se escribirá en la salida estándar.

slidetool prop obtener

Imprime el valor de una única propiedad de OpenSlide para uno o más portaobjetos. Las propiedades son piezas individuales de metadatos textuales sobre el portaobjeto. Las propiedades prefijadas con openslide. están definidas por OpenSlide; otras están definidas por el formato individual del portaobjeto.

slidetool prop listar

Imprime todas las propiedades de OpenSlide para uno o más portaobjetos.

slidetool region icc leer

Escribe el perfil de color ICC del portaobjeto en archivo-salida si se especifica, y de lo contrario a la salida estándar. Si no hay un perfil de color ICC disponible, falla.

slidetool region leer

Escribe una región del nivel especificado de un portaobjeto en una imagen PNG. x e y son coordenadas de píxeles en el nivel 0, el nivel de portaobjeto de mayor resolución. ancho y alto son dimensiones de píxeles en el nivel especificado. Si no se especifica archivo-salida, la imagen se escribirá en la salida estándar.

Las dimensiones de cada nivel de un portaobjeto se pueden obtener con slidetool prop listar.

slidetool slide abrir

Comprueba si OpenSlide puede abrir uno o más archivos de portaobjetos.

slidetool slide quickhash1

Imprime las sumas de verificación quickhash-1 de OpenSlide para uno o más portaobjetos, en un formato similar a sha256sum(1).

quickhash-1 es un hash no criptográfico de 256 bits de un subconjunto de los datos de un portaobjeto. Identifica de forma única un portaobjeto en particular, pero no puede utilizarse para detectar corrupción o modificación del archivo del portaobjeto.

quickhash-1 no está definido para todos los archivos de portaobjetos compatibles con OpenSlide. Si un portaobjeto no tiene un quickhash-1, se imprimirá "No quickhash-1 disponible".

slidetool slide proveedor

Informa del nombre del proveedor de OpenSlide detectado para uno o más archivos de portaobjetos.

OPCIONES

--ayuda
Muestra el resumen de uso.
--nombres
Para slidetool prop listar, omite los valores de las propiedades.
--versión
Muestra la información de versión y derechos de autor.

ESTADO DE SALIDA

slidetool devuelve 0 si tiene éxito, 1 si no se pudo leer un archivo de portaobjeto, o 2 si los argumentos son inválidos.
