Documentación de Función/Subrutina

subrutina slagsy (integer n, integer k, real, dimension( * ) d, real, dimension( lda, * ) a, integer lda, integer, dimension( 4 ) iseed, real, dimension( * ) work, integer info)

SLAGSY

Propósito:

!>
!> SLAGSY genera una matriz simétrica real A, pre- y post-multiplicando
!> una matriz diagonal real D con una matriz ortogonal aleatoria:
!> A = U*D*U'. El semi-ancho de banda puede reducirse luego a k mediante
!> transformaciones ortogonales adicionales.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

K

!>          K es ENTERO
!>          El número de subdiagonales no nulas dentro de la banda de A.
!>          0 <= K <= N-1.
!>

D

!>          D es array REAL, dimension (N)
!>          Los elementos diagonales de la matriz diagonal D.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          La matriz simétrica generada A de n por n (se almacena la matriz
!>          completa).
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= N.
!>

ISEED

!>          ISEED es array ENTERO, dimension (4)
!>          A la entrada, la semilla del generador de números aleatorios; los
!>          elementos del array deben estar entre 0 y 4095, y ISEED(4) debe
!>          ser impar.
!>          A la salida, la semilla se actualiza.
!>

WORK

!>          WORK es array REAL, dimension (2*N)
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
