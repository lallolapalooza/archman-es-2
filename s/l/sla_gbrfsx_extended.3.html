subroutine sla_gbrfsx_extended (integer prec_type, integer trans_type, integer n, integer kl, integer ku, integer nrhs, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, logical colequ, real, dimension( * ) c, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldy, * ) y, integer ldy, real, dimension(*) berr_out, integer n_norms, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, real, dimension(*) res, real, dimension(*) ayb, real, dimension(*) dy, real, dimension(*) y_tail, real rcond, integer ithresh, real rthresh, real dz_ub, logical ignore_cwise, integer info)

SLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices generales de banda, realizando un refinamiento iterativo de precisión extra y proporcionando cotas de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!> SLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales mediante un refinamiento iterativo de precisión extra
!> y proporciona cotas de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por SGBRFSX para realizar el refinamiento iterativo.
!> Además de la cota de error normwise, el código proporciona la cota de error
!> máxima por componentes si es posible. Ver los comentarios para ERR_BNDS_NORM
!> y ERR_BNDS_COMP para detalles de las cotas de error. Nótese que esta
!> subrutina solo es responsable de establecer los segundos campos de
!> ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a utilizar en el refinamiento.
!>     El valor se define por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

TRANS_TYPE

!>          TRANS_TYPE es INTEGER
!>     Especifica la operación de transposición en A.
!>     El valor se define por ILATRANS(T) donde T es un CHARACTER y T
!>          = 'N':  Sin transposición
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

AB

!>          AB es array REAL, dimension (LDAB,N)
!>     En la entrada, la matriz AB de N-por-N.
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal del array AB.  LDAB >= max(1,N).
!>

AFB

!>          AFB es array REAL, dimension (LDAFB,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U tal como se calcula por SGBTRF.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del array AF.  LDAFB >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     tal como se calcula por SGBTRF; la fila i de la matriz fue
!>     intercambiada con la fila IPIV(i).
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si .TRUE. entonces se realizó la   equilibración de columnas en A antes de llamar
!>     a esta subrutina. Esto es necesario para calcular la solución y las cotas
!>     de error correctamente.
!>

C

!>          C es array REAL, dimension (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE.,
!>     C no se accede. Si C se introduce, cada elemento de C debe ser una potencia
!>     de la base para asegurar una solución y estimaciones de error fiables.
!>     La escala por potencias de la base no causa errores de redondeo a menos
!>     que el resultado sea subdesbordado o desbordado. Los errores de redondeo
!>     durante la escala conducen a un refinamiento con una matriz que no es
!>     equivalente a la matriz de entrada, produciendo estimaciones de error
!>     que pueden no ser fiables.
!>

B

!>          B es array REAL, dimension (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es array REAL, dimension (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como se calculó por SGBTRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es array REAL, dimension (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error relativo hacia atrás por
!>     componentes para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto por componentes de la matriz
!>     o vector Z. Esto se calcula por SLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué cotas de error se devuelven (ver
!>     ERR_BNDS_NORM y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 se devuelven cotas de error normwise.
!>     Si N_NORMS >= 2 se devuelven cotas de error por componentes.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es array REAL, dimension (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     La matriz está indexada por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confía en la respuesta si el
!>
el número de condición recíproco es menor que el umbral !> sqrt(n) * slamch('Epsilon'). !> !> err = 2 límite de error: El error directo estimado, !> casi con toda seguridad dentro de un factor de 10 del error verdadero !> siempre que la siguiente entrada sea mayor que el umbral !> sqrt(n) * slamch('Epsilon'). Este límite de error solo debe !> ser confiable si el booleano anterior es verdadero. !> !> err = 3 Número de condición recíproco: Estimación del número de condición !> recíproco normwise. Comparado con el umbral !> sqrt(n) * slamch('Epsilon') para determinar si la estimación del error !> es . Estos números de condición recíprocos !> son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna !> matriz Z adecuadamente escalada. !> Sea Z = S*A, donde S escala cada fila por una potencia de la !> base para que todas las sumas de filas absolutas de Z sean aproximadamente 1. !> !> Esta subrutina solo es responsable de establecer el segundo campo !> arriba. !> Consulte la Nota de Trabajo 165 de Lapack para más detalles y precauciones adicionales. !>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array REAL, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada mano derecha, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define de la siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array está indexado por la mano derecha i (de la cual depende el
!>     error relativo componente a componente), y el tipo de información de error
!>     como se describe a continuación. Actualmente hay hasta tres
!>     piezas de información devueltas para cada mano derecha. Si
!>     la precisión componente a componente no se solicita (PARAMS(3) = 0.0),
!>     entonces ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces como máximo
!>     las primeras (:,N_ERR_BNDS) entradas son devueltas.
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde a la i-ésima
!>     mano derecha.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con toda seguridad dentro de un factor de 10 del error verdadero
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo debe
!>              ser confiable si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición recíproco
!>              componente a componente estimado. Comparado con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la estimación del error
!>              es . Estos números de condición recíprocos
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z adecuadamente escalada.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para la
!>              mano derecha actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas las sumas de
!>              filas absolutas de Z sean aproximadamente 1.
!>
!>     Esta subrutina solo es responsable de establecer el segundo campo
!>     arriba.
!>     Consulte la Nota de Trabajo 165 de Lapack para más detalles y precauciones adicionales.
!>

RES

!>          RES es un array REAL, de dimensión (N)
!>     Espacio de trabajo para contener el residuo intermedio.
!>

AYB

!>          AYB es un array REAL, de dimensión (N)
!>     Espacio de trabajo. Este puede ser el mismo espacio de trabajo que se pasa para Y_TAIL.

DY

Y_TAIL
