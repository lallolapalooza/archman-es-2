DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subrutina slaebz (integer ijob, integer nitmax, integer n, integer mmax, integer minp, integer nbmin, real abstol, real reltol, real pivmin, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) e2, integer, dimension( * ) nval, real, dimension( mmax, * ) ab, real, dimension( * ) c, integer mout, integer, dimension( mmax, * ) nab, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLAEBZ calcula el número de valores propios de una matriz tridiagonal simétrica real que son menores o iguales a un valor dado, y realiza otras tareas requeridas por la subrutina sstebz.

Propósito:

!>
!> SLAEBZ contiene los bucles de iteración que calculan y utilizan la
!> función N(w), que es el recuento de valores propios de una matriz
!> tridiagonal simétrica T menor o igual a su argumento w.
!> Realiza una elección de dos tipos de bucles:
!>
!> IJOB=1, seguido por
!> IJOB=2: Toma como entrada una lista de intervalos y devuelve una lista de
!>         intervalos suficientemente pequeños cuya unión contiene los mismos
!>         valores propios que la unión de los intervalos originales.
!>         Los intervalos de entrada son (AB(j,1),AB(j,2)], j=1,...,MINP.
!>         El intervalo de salida (AB(j,1),AB(j,2)] contendrá
!>         valores propios NAB(j,1)+1,...,NAB(j,2), donde 1 <= j <= MOUT.
!>
!> IJOB=3: Realiza una búsqueda binaria en cada intervalo de entrada
!>         (AB(j,1),AB(j,2)] para un punto w(j) tal que
!>         N(w(j))=NVAL(j), y utiliza C(j) como punto de partida de
!>         la búsqueda. Si se encuentra tal w(j), entonces en la salida
!>         AB(j,1)=AB(j,2)=w. Si no se encuentra tal w(j), entonces en la salida
!>         (AB(j,1),AB(j,2)] será un intervalo pequeño que contiene el
!>         punto donde N(w) salta a través de NVAL(j), a menos que ese punto
!>         esté fuera del intervalo inicial.
!>
!> Tenga en cuenta que los intervalos son en todos los casos intervalos
!> semiabiertos, es decir, de la forma (a,b], que incluye b pero no a.
!>
!> Para evitar el desbordamiento, la matriz debe escalarse de modo que su
!> elemento más grande no sea superior a overflow**(1/2) *
!> underflow**(1/4) en valor absoluto. Para asegurar el cálculo más
!> preciso de valores propios pequeños, la matriz debe escalarse para
!> que no sea mucho más pequeña que eso.
!>
!> Ver W. Kahan, Report CS41, Computer Science Dept., Stanford
!> University, 21 de julio de 1966
!>
!> Nota: los argumentos, en general, *no* se verifican en busca de
!> valores irrazonables.
!>

Parámetros

IJOB 
!>          IJOB es INTEGER
!>          Especifica qué se debe hacer:
!>          = 1: Calcular NAB para los intervalos iniciales.
!>          = 2: Realizar iteraciones de bisección para encontrar valores
!>               propios de T.
!>          = 3: Realizar iteraciones de bisección para invertir N(w), es decir,
!>               para encontrar un punto que tenga un número especificado
!>               de valores propios de T a su izquierda.
!>          Otros valores harán que SLAEBZ devuelva con INFO=-1.
!>

NITMAX

!>          NITMAX es INTEGER
!>          El número máximo de iteraciones de bisección a realizar, es
!>          decir, un intervalo de ancho W no se hará más pequeño que
!>          2^(-NITMAX) * W. Si no todos los intervalos han convergido
!>          después de NITMAX iteraciones, entonces INFO se establece en el
!>          número de intervalos no convergentes.
!>

N

!>          N es INTEGER
!>          La dimensión n de la matriz tridiagonal T. Debe ser al menos 1.
!>

MMAX

!>          MMAX es INTEGER
!>          El número máximo de intervalos. Si se generan más de MMAX
!>          intervalos, entonces SLAEBZ saldrá con INFO=MMAX+1.
!>

MINP

!>          MINP es INTEGER
!>          El número inicial de intervalos. No puede ser mayor que MMAX.
!>

NBMIN

!>          NBMIN es INTEGER
!>          El número mínimo de intervalos que deben procesarse utilizando
!>          un bucle vectorial. Si es cero, solo se utilizará el bucle
!>          escalar.
!>

ABSTOL

!>          ABSTOL es REAL
!>          El ancho mínimo (absoluto) de un intervalo. Cuando un intervalo
!>          es más estrecho que ABSTOL, o que RELTOL multiplicado por el
!>          punto final más grande (en magnitud), entonces se considera
!>          suficientemente pequeño, es decir, convergido. Debe ser al menos
!>          cero.
!>

RELTOL

!>          RELTOL es REAL
!>          El ancho relativo mínimo de un intervalo. Cuando un intervalo
!>          es más estrecho que ABSTOL, o que RELTOL multiplicado por el
!>          punto final más grande (en magnitud), entonces se considera
!>          suficientemente pequeño, es decir, convergido. Nota: esto
!>          siempre debe ser al menos epsilon_maquina * radix.
!>

PIVMIN

!>          PIVMIN es REAL
!>          El valor absoluto mínimo de un pivote en el bucle de secuencia
!>          de Sturm.
!>          Debe ser al menos max |e(j)**2|*safe_min y al menos
!>          safe_min, donde safe_min es al menos el número más pequeño
!>          que puede dividir uno sin desbordamiento.
!>

D

!>          D es un array REAL, dimensión (N)
!>          Los elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es un array REAL, dimensión (N)
!>          Los elementos fuera de la diagonal de la matriz tridiagonal T
!>          en las posiciones 1 a N-1. E(N) es arbitrario.
!>

E2

!>          E2 es un array REAL, dimensión (N)
!>          Los cuadrados de los elementos fuera de la diagonal de la matriz
!>          tridiagonal T. E2(N) se ignora.
!>

NVAL

!>          NVAL es un array INTEGER, dimensión (MINP)
!>          Si IJOB=1 o 2, no se referencia.
!>          Si IJOB=3, los valores deseados de N(w). Los elementos de NVAL
!>          se reordenarán para corresponder con los intervalos en AB.
!>          Por lo tanto, NVAL(j) en la salida no será, en general, el mismo
!>          que NVAL(j) en la entrada, pero corresponderá con el intervalo
!>          (AB(j,1),AB(j,2)] en la salida.
!>

AB

!>          AB es un array REAL, dimensión (MMAX,2)
!>          Los puntos finales de los intervalos. AB(j,1) es a(j), el punto
!>          final izquierdo del j-ésimo intervalo, y AB(j,2) es b(j), el
!>          punto final derecho del j-ésimo intervalo. Los intervalos de
!>          entrada se modificarán, dividirán y reordenarán en general
!>          mediante el cálculo.
!>

C

!>          C es un array REAL, dimensión (MMAX)
!>          Si IJOB=1, se ignora.
!>          Si IJOB=2, espacio de trabajo.
!>          Si IJOB=3, entonces en la entrada C(j) debe inicializarse al
!>          primer punto de búsqueda en la búsqueda binaria.
!>

MOUT

!>          MOUT es INTEGER
!>          Si IJOB=1, el número de valores propios en los intervalos.
!>          Si IJOB=2 o 3, el número de intervalos de salida.
!>          Si IJOB=3, MOUT será igual a MINP.
!>

NAB

!>          NAB es un array INTEGER, dimensión (MMAX,2)
!>          Si IJOB=1, entonces en la salida NAB(i,j) se establecerá en
!>          N(AB(i,j)).
!>          Si IJOB=2, entonces en la entrada, NAB(i,j) debe ser establecido.
!>          Debe satisfacer la condición:
!&g

Function/Subroutine Documentation

subroutine slaebz(ijob, n, jb, cfrom, cto, kfrom, kto, fom, tol, nval, ab, cob, dib, zbuf, w, matz, iwork, work, info)

SLAEBZ finds an interval (a', b'] that contains a specified number of eigenvalues of a symmetric tridiagonal matrix T. The eigenvalues are computed by sorting the diagonal elements of the matrix T. The number of eigenvalues is counted using a divide and conquer approach, which is described in the references.

SLAEBZ is a single subroutine that computes information about the eigenvalues of a tridiagonal matrix T. It can be used to determine bounds for the eigenvalues, count the number of eigenvalues within a given interval, or to compute the eigenvalues themselves. The subroutine uses a divide and conquer approach to count the eigenvalues, which is more efficient than simply sorting the diagonal elements of T.

Arguments:

IJOB

INTEGER. Specifies the operation to be performed.

IJOB = 1: Compute the number of eigenvalues in each interval (AB(i,1), AB(i,2)]. Initialize NAB(i,1) and NAB(i,2) to the number of eigenvalues in the interval (CFROM, CTO].

IJOB = 2: Compute approximate eigenvalues in each interval (AB(i,1), AB(i,2)]. Initialize NAB(i,1) and NAB(i,2) to the number of eigenvalues in the interval (CFROM, CTO].

IJOB = 3: Compute an interval (a', b'] containing a specified number of eigenvalues. Initialize AB to be a single interval (CFROM, CTO]. Initialize NVAL to the desired number of eigenvalues. Initialize NAB to be -1 or N+1.

N

INTEGER. The order of the matrix T.

JB

INTEGER. The number of intervals to be generated.

CFROM

REAL. The lower bound of the initial interval.

CTO

REAL. The upper bound of the initial interval.

KFROM

INTEGER. The index of the first eigenvalue to be considered.

KTO

INTEGER. The index of the last eigenvalue to be considered.

FOM

REAL. The desired relative accuracy for the eigenvalues.

TOL

REAL. The desired absolute accuracy for the eigenvalues.

NVAL

INTEGER array, dimension (JB). On input, specifies the number of eigenvalues in each interval. On output, contains the number of eigenvalues found in each interval.

AB

REAL array, dimension (JB, 2). On input, specifies the intervals to be considered. On output, contains the intervals containing the eigenvalues.

COB

REAL array, dimension (JB). On output, contains the approximate eigenvalues in each interval.

DIB

REAL array, dimension (JB). On output, contains the absolute error bounds for the eigenvalues in each interval.

ZBUF

REAL array, dimension (N). Workspace.

W

REAL array, dimension (N). Contains the eigenvalues of T.

MATZ

LOGICAL. If .TRUE., then the eigenvectors are computed.

IWORK

INTEGER array, dimension (N). Workspace.

WORK

REAL array, dimension (N). Workspace.

INFO

INTEGER. Error flag.

INFO = 0: Success.

INFO < 0: An illegal value was returned for INFO.

INFO > 0: The number of eigenvalues in the interval (AB(i,1), AB(i,2)] is greater than the number of intervals generated.

SLAEBZ computes eigenvalues of a symmetric tridiagonal matrix. It can be used to find all eigenvalues, or a subset of them. The subroutine uses a divide and conquer approach to count the number of eigenvalues in each interval, which is more efficient than simply sorting the diagonal elements.

On input, NAB is an array of integers that specifies the number of eigenvalues in each interval. On output, NAB is updated to contain the number of eigenvalues found in each interval.

If IJOB = 1, then NAB(i,1) and NAB(i,2) are set to the number of eigenvalues in the interval (AB(i,1), AB(i,2)]. This is done by counting the number of eigenvalues of T that lie in the interval.

If IJOB = 2, then NAB(i,1) and NAB(i,2) are set to the number of eigenvalues in the interval (AB(i,1), AB(i,2)]. The eigenvalues are then approximated by the midpoints of the intervals, and the absolute error bounds are computed.

If IJOB = 3, then NAB(i,1) and NAB(i,2) are used to specify the desired number of eigenvalues. The subroutine then computes an interval (AB(i,1), AB(i,2)] that contains the desired number of eigenvalues.

The arguments WORK and IWORK are workspace arrays that are used by the subroutine to store intermediate results. The size of these arrays depends on the size of the matrix T.

The argument INFO is an integer that indicates whether the subroutine completed successfully. If INFO = 0, then the subroutine completed successfully. If INFO > 0, then the subroutine encountered an error.

Example usage:

SUBROUTINE SLAEBZ( IJOB, N, JB, CFROM, CTO, KFROM, KTO, FOM, TOL,
                   NVAL, AB, COB, DIB, ZBUF, W, MATZ, IWORK, WORK, INFO )

Here, IJOB specifies the operation to be performed, and N is the order of the matrix T. JB is the number of intervals to be generated. CFROM and CTO are the lower and upper bounds of the initial interval. KFROM and KTO specify the range of eigenvalues to be considered. FOM and TOL specify the desired accuracy. NVAL, AB, COB, and DIB are output arrays. ZBUF, W, MATZ, IWORK, and WORK are workspace arrays. INFO is the error flag.
