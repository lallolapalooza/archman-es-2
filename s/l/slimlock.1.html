NOMBRE

slimlock - Bloqueador de pantalla impío

SINOPSIS

slimlock [-v]

DESCRIPCIÓN

El monstruo de Frankenstein de los bloqueadores de pantalla. Unir SLiM y slock da como resultado sangre, lágrimas y pantallas bloqueadas.

OPCIONES

-v
mostrar información de la versión

CONFIGURACIÓN

Slimlock lee los mismos archivos de configuración que utilizas para SLiM. Busca en CFGDIR/slim.conf y CFGDIR/slimlock.conf, donde CFGDIR se define al compilar, normalmente /etc. Las opciones que se leen de slim.conf son hidecursor, current_theme, background_color y background_style, screenshot_cmd y welcome_msg. Consulta la documentación de SLiM para obtener más información.

slimlock.conf contiene los siguientes ajustes:

dpms_standby_timeout
segundos de inactividad antes de que la pantalla se apague. Por defecto: 60
dpms_off_timeout
segundos de inactividad antes de que la pantalla se apague por completo. Por defecto: 600
wrong_passwd_timeout
retraso en segundos después de introducir una contraseña incorrecta. Por defecto: 2
passwd_feedback_msg
mensaje que se muestra después de un intento de autenticación fallido. Por defecto: Authentication failed
passwd_feedback_capslock
mensaje que se muestra después de un intento de autenticación fallido si la tecla Bloq Mayús está activada. Por defecto: Authentication failed (CapsLock is on)
show_username
1 para mostrar el nombre de usuario en temas con un solo campo de entrada; 0 para deshabilitarlo. Por defecto: 1
show_welcome_msg
1 para mostrar el mensaje de bienvenida de SLiM; 0 para deshabilitarlo. Por defecto: 0
tty_lock
1 para denegar el cambio de terminales virtuales; 0 para permitirlo. Por defecto: 1
bell
1 para habilitar el timbre en caso de fallo de autenticación; 0 para deshabilitarlo. Por defecto: 1

BUGS

Donde el tema define un mensaje de bienvenida o un aviso de contraseña, slimlock los muestra en el lugar equivocado.

Usar el mismo tema que slim asume que el tema es apropiado. La mayoría de los temas disponibles (incluidos los predeterminados) muestran la palabra "Login" en el panel, lo cual no es del todo correcto para un bloqueo de pantalla.

Para aliviar ambos problemas, puedes especificar un tema diferente en CFGDIR/slimlock.conf, que anulará la configuración en CFGDIR/slim.conf, pero aún así necesitas encontrar (o crear) un tema de bloqueo adecuado.
