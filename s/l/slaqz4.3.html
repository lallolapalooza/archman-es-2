SLAQZ4

Propósito:

!>
!> SLAQZ4 Ejecuta un barrido QZ multishift único
!>

Parámetros

ILSCHUR 
!>          ILSCHUR es LOGICO
!>              Determina si se actualiza o no la forma Schur completa
!>

ILQ

!>          ILQ es LOGICO
!>              Determina si se actualiza o no la matriz Q
!>

ILZ

!>          ILZ es LOGICO
!>              Determina si se actualiza o no la matriz Z
!>

N

!>          N es ENTERO
!>          El orden de las matrices A, B, Q y Z.  N >= 0.
!>

ILO

!>          ILO es ENTERO
!>

IHI

!>          IHI es ENTERO
!>

NSHIFTS

!>          NSHIFTS es ENTERO
!>          El número deseado de shifts a utilizar
!>

NBLOCK_DESIRED

!>          NBLOCK_DESIRED es ENTERO
!>          El tamaño deseado de las ventanas computacionales
!>

SR

!>          SR es array REAL. SR contiene
!>          las partes reales de los shifts a utilizar.
!>

SI

!>          SI es array REAL. SI contiene
!>          las partes imaginarias de los shifts a utilizar.
!>

SS

!>          SS es array REAL. SS contiene
!>          la escala de los shifts a utilizar.
!>

A

!>          A es array REAL, dimension (LDA, N)
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max( 1, N ).
!>

B

!>          B es array REAL, dimension (LDB, N)
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max( 1, N ).
!>

Q

!>          Q es array REAL, dimension (LDQ, N)
!>

LDQ

!>          LDQ es ENTERO
!>

Z

!>          Z es array REAL, dimension (LDZ, N)
!>

LDZ

!>          LDZ es ENTERO
!>

QC

!>          QC es array REAL, dimension (LDQC, NBLOCK_DESIRED)
!>

LDQC

!>          LDQC es ENTERO
!>

ZC

!>          ZC es array REAL, dimension (LDZC, NBLOCK_DESIRED)
!>

LDZC

!>          LDZ es ENTERO
!>

WORK

!>          WORK es array REAL, dimension (MAX(1,LWORK))
!>          A la salida, si INFO >= 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.  LWORK >= max(1,N).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y ninguna
!>          XERBLA emitirá un mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
