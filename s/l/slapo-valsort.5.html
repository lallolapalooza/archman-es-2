NOMBRE

slapo-valsort - Overlay de ordenación de valores para slapd

SINOPSIS

/etc/openldap/slapd.conf

DESCRIPCIÓN

El overlay de Ordenación de Valores (Value Sorting) se puede usar con una base de datos backend para ordenar los valores de atributos multivaluados específicos dentro de un subárbol. La ordenación se produce cada vez que los atributos se devuelven en una respuesta de búsqueda.

La ordenación se puede especificar en orden ascendente o descendente, utilizando métodos de ordenación numéricos o alfanuméricos. Adicionalmente, se puede especificar una ordenación "ponderada", que utiliza un peso numérico antepuesto a los valores del atributo. La ordenación ponderada siempre se realiza en orden ascendente, pero puede combinarse con otros métodos para valores que tengan pesos iguales. El peso se especifica anteponiendo un factor de peso entero {<peso>} delante de cada valor del atributo para el cual se desea ordenación ponderada. Este factor de ponderación se elimina y no se devuelve en los resultados de búsqueda a menos que se especifique el control valsort (1.3.6.1.4.1.4203.666.5.14).

El control valsort requiere un valor que consiste en una Secuencia que contiene un indicador booleano. El factor de ponderación solo se devuelve si el valor booleano es VERDADERO. En formato lber-encode(3), el valor requerido debe cumplir la sintaxis "{b}".

CONFIGURACIÓN

Estas opciones de slapd.conf se aplican al overlay de Ordenación de Valores. Deben aparecer después de la directiva overlay.

valsort-attr <atributo> <DNbase> (<método-ordenación> | ponderado [<método-ordenación>])
Configura un método de ordenación para el atributo especificado en el subárbol con raíz en DNbase. El método-ordenación puede ser uno de alpha-ascend, alpha-descend, numeric-ascend o numeric-descend. Si se especifica el método especial ponderado, también se puede especificar un método-ordenación secundario. Es un error especificar un método de ordenación alfanumérico para un atributo con sintaxis Integer o NumericString, y es un error especificar un método de ordenación numérico para un atributo con una sintaxis distinta a Integer o NumericString.

EJEMPLOS

database mdb
suffix dc=example,dc=com
...
overlay valsort
valsort-attr member ou=groups,dc=example,dc=com alpha-ascend

Para invocar ldapsearch(1) con el control valsort, el valor del control debe configurarse adecuadamente. Los siguientes octetos representan la codificación "{b}" deseada:

0x30 0x03 0x01 0x01 0xff

El control se puede enviar desde la línea de comandos utilizando la codificación base64 del valor:

ldapsearch -E 1.3.6.1.4.1.4203.666.5.14=::MAMBAf8=

ARCHIVOS

/etc/openldap/slapd.conf
archivo de configuración por defecto de slapd

VER TAMBIÉN

slapd.conf(5), slapd-config(5).
