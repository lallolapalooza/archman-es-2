NOMBRE

slapo-syncprov - Superposición de Proveedor de Sincronización para slapd

SINOPSIS

/etc/openldap/slapd.conf

DESCRIPCIÓN

La superposición Sync Provider implementa el soporte del lado del proveedor para la Sincronización de Contenido LDAP (RFC4533) así como el soporte de replicación syncrepl. La superposición puede ser utilizada con cualquier backend que mantenga los atributos entryCSN y entryUUID para sus entradas. También crea un atributo contextCSN en la entrada raíz de la base de datos.

El contextCSN se actualiza por cada operación de escritura realizada contra la base de datos. Para reducir la contención de la base de datos, el contextCSN solo se actualiza en memoria. El valor se escribe en la base de datos al apagar el servidor y se lee en memoria al iniciar, y se mantiene en memoria a partir de entonces. Se pueden configurar puntos de control para escribir el contextCSN en la base de datos subyacente para minimizar el tiempo de recuperación después de un apagado inesperado.

En bases de datos que soportan indexación de desigualdad, se recomienda encarecidamente establecer un índice de igualdad (eq index) en el atributo entryCSN al usar esta superposición.

CONFIGURACIÓN

Estas opciones de slapd.conf se aplican a la superposición Sync Provider. Deben aparecer después de la directiva overlay.

syncprov-checkpoint <ops> <minutos>
Después de que una operación de escritura haya tenido éxito, escribe el contextCSN en la base de datos subyacente si se han transcurrido <ops> operaciones de escritura o más de <minutos> tiempo desde el último punto de control. La creación de puntos de control está deshabilitada por defecto.
syncprov-sessionlog <ops>
Configura un registro de sesión en memoria para grabar información sobre las operaciones de escritura realizadas en la base de datos. <ops> especifica el número de operaciones que se registran en el log. Todas las operaciones de escritura (excepto los Añadidos) se registran en el log. Al usar el registro de sesión, es útil establecer un índice de igualdad (eq index) en el atributo entryUUID en la base de datos subyacente.
syncprov-sessionlog-source <dn>
No debe establecerse cuando se establece syncprov-sessionlog y viceversa.

Cuando el accesslog para esta base de datos está configurado y está registrando en este sufijo, puede ser utilizado como fuente de registro de sesión en lugar del registro de sesión en memoria mencionado anteriormente. Este log tiene la ventaja de no empezar de nuevo cada vez que se reinicia el servidor.

syncprov-nopresent TRUE | FALSE
Especifica que se debe omitir la fase de Presentación del refresco. Este valor solo debe establecerse en TRUE para una instancia de syncprov sobre una base de datos de log (como la gestionada por la superposición accesslog). El valor por defecto es FALSE.
syncprov-reloadhint TRUE | FALSE
Especifica que la superposición debe respetar el indicador reloadHint en el Control de Sincronización. Debe establecerse en TRUE cuando se utiliza la superposición accesslog para el soporte de replicación syncrepl basada en delta. El valor por defecto es FALSE.

ARCHIVOS

/etc/openldap/slapd.conf
archivo de configuración predeterminado de slapd
