NOMBRE

slapadd - Añadir entradas a una base de datos de SLAPD

SINOPSIS

/usr/bin/slapadd [-b sufijo] [-c] [-d nivel-depuracion] [-f slapd.conf] [-F directorio-conf] [-g] [-j num-linea] [-l archivo-ldif] [-n num-db] [-o opcion[=valor]] [-q] [-s] [-S SID] [-u] [-v] [-w]

DESCRIPCIÓN

Slapadd se utiliza para añadir entradas especificadas en el formato LDIF (LDAP Data Interchange Format) a una base de datos de slapd(8). Abre la base de datos dada, determinada por el número de base de datos o el sufijo, y añade entradas correspondientes al LDIF proporcionado a la base de datos. Las bases de datos configuradas como subordinadas a esta también se actualizan, a menos que se especifique -g. La entrada LDIF se lee desde la entrada estándar o desde el archivo especificado.

Todos los archivos creados finalmente por slapadd pertenecerán a la identidad con la que se ejecute slapadd, así que asegúrate de ejecutar slapadd con la misma identidad con la que se ejecutará slapd(8) (ver la opción -u en slapd(8)), o cambia la propiedad del archivo antes de ejecutar slapd(8).

Nota: slapadd también realizará la indexación relevante al añadir la base de datos si hay alguna configurada. Para detalles específicos, por favor, consulta slapindex(8).

OPCIONES

-b sufijo
Utiliza el sufijo especificado para determinar a qué base de datos añadir las entradas. Por defecto, se utiliza la primera base de datos que soporta la operación solicitada. La opción -b no puede usarse junto con la opción -n.
-c
Habilita el modo de continuación (ignorar errores).
-d nivel-depuracion
Habilita mensajes de depuración según lo definido por el nivel-depuracion especificado; consulta slapd(8) para detalles.
-f slapd.conf
Especifica un archivo slapd.conf(5) alternativo.
-F directorio-conf
Especifica un directorio de configuración. Si se especifican tanto -f como -F, el archivo de configuración se leerá y se convertirá al formato de directorio de configuración y se escribirá en el directorio especificado. Si no se especifica ninguna opción, se intentará leer el directorio de configuración predeterminado antes de intentar usar el archivo de configuración predeterminado. Si existe un directorio de configuración válido, se ignora el archivo de configuración predeterminado. Si también se especifica el modo de ejecución en seco, no se realizará ninguna conversión.
-g
Deshabilita la pegada subordinada. Solo se procesará la base de datos especificada, y no sus subordinadas pegadas (si las hubiera).
-j num-linea
Salta a la línea especificada en el archivo LDIF antes de procesar cualquier entrada. Esto permite que una carga que fue abortada debido a errores en el LDIF de entrada se reanude después de corregir los errores.
-l archivo-ldif
Lee LDIF desde el archivo especificado en lugar de la entrada estándar.
-n num-db
Añade entradas a la num-db-ésima base de datos listada en el archivo de configuración. La opción -n no puede usarse junto con la opción -b. Para poblar la base de datos de configuración slapd-config(5), usa -n 0 ya que siempre es la primera base de datos. Sin embargo, debe existir físicamente en el sistema de archivos antes de esto.
-o opcion[=valor]
Especifica una opción con un valor (opcional). Las posibles opciones/valores genéricos son:
              syslog=<subsistemas>  (ver `-s' en slapd(8))
              syslog-level=<nivel> (ver `-S' en slapd(8))
              syslog-user=<usuario>   (ver `-l' en slapd(8))
              schema-check={yes|no}
              value-check={yes|no}
La opción schema-check activa/desactiva la verificación del esquema (activada por defecto);
la opción value-check activa/desactiva la verificación de valores (desactivada por defecto).
Esta última es incompatible con -q.
-q
habilita el modo rápido (menos comprobaciones de integridad). Realiza menos
comprobaciones de consistencia en los datos de entrada, y ninguna comprobación
de consistencia al escribir la base de datos.
Mejora el tiempo de carga pero si ocurren errores o interrupciones, la base de datos
resultante será inutilizable.
-s
deshabilita la verificación del esquema. Esta opción está pensada para usarse al
cargar bases de datos que contienen objetos especiales, como objetos fraccionarios
en un consumidor parcial.
Cargar objetos normales que no se ajustan al esquema puede resultar en un comportamiento
inesperado y erróneo.
-S SID
ID del servidor a usar en entryCSN generado. También se usa para contextCSN
si también se establece -w. Por defecto es 0.
-u
habilita el modo de ejecución en seco (no escribir en el backend).
-v
habilita el modo detallado.
-w
escribe información de contexto syncrepl.
Después de añadir todas las entradas, contextCSN se actualizará con el CSN más grande
en la base de datos.

LIMITACIONES

Tu slapd(8) no debe estar ejecutándose cuando hagas esto para asegurar la consistencia de la base de datos.

slapadd puede no proporcionar comprobaciones de nombres o de esquema. Es recomendable usar ldapadd(1) al añadir nuevas entradas a un directorio existente.

EJEMPLOS

Para importar las entradas especificadas en el archivo ldif a tu base de datos de slapd(8), ejecuta el comando:

/usr/bin/slapadd -l ldif
