función real slatm3 (integer m, integer n, integer i, integer j, integer isub, integer jsub, integer kl, integer ku, integer idist, integer, dimension( 4 ) iseed, real, dimension( * ) d, integer igrade, real, dimension( * ) dl, real, dimension( * ) dr, integer ipvtng, integer, dimension( * ) iwork, real sparse)

SLATM3

Propósito:

!>
!>    SLATM3 devuelve la entrada (ISUB,JSUB) de una matriz aleatoria
!>    descrita por los otros parámetros. (ISUB,JSUB) es la posición
!>    final de la entrada (I,J) después de la pivoteación según IPVTNG
!>    e IWORK. SLATM3 es llamada por la rutina SLATMR para construir
!>    matrices de prueba aleatorias. No se realiza ninguna comprobación
!>    de errores en los parámetros, ya que esta rutina es llamada en un
!>    bucle ajustado por SLATMR que ya ha comprobado los parámetros.
!>
!>    El uso de SLATM3 difiere de SLATM2 en el orden en que se llama al
!>    generador de números aleatorios para rellenar las entradas de la
!>    matriz aleatoria. Con SLATM2, el generador se llama para rellenar
!>    la matriz pivoteada por columnas. Con SLATM3, el generador se llama
!>    para rellenar la matriz por columnas, después de lo cual se pivota.
!>    Por lo tanto, SLATM3 puede usarse para construir matrices aleatorias
!>    que difieren solo en el orden de sus filas y/o columnas. SLATM2 se
!>    usa para construir matrices de banda, evitando llamar al generador de
!>    números aleatorios para entradas fuera de la banda (y por lo tanto
!>    generando números aleatorios en órdenes diferentes para órdenes de
!>    pivoteo diferentes).
!>
!>    La matriz cuya entrada (ISUB,JSUB) se devuelve se construye de la
!>    siguiente manera (esta rutina solo calcula una entrada):
!>
!>      Si ISUB está fuera de (1..M) o JSUB está fuera de (1..N), devuelve cero
!>         (esto es conveniente para generar matrices en formato de banda).
!>
!>      Genera una matriz A con entradas aleatorias de distribución IDIST.
!>
!>      Establece la diagonal a D.
!>
!>      Califica la matriz, si se desea, desde la izquierda (por DL) y/o
!>         desde la derecha (por DR o DL) según lo especificado por IGRADE.
!>
!>      Permuta, si se desea, las filas y/o columnas según lo especificado
!>         por IPVTNG y IWORK.
!>
!>      Banda la matriz para tener un ancho de banda inferior KL y un ancho
!>         de banda superior KU.
!>
!>      Establece entradas aleatorias a cero según lo especificado por
!>         SPARSE.
!>

Parámetros

M 
!>          M es INTEGER
!>           Número de filas de la matriz. No modificado.
!>

N

!>          N es INTEGER
!>           Número de columnas de la matriz. No modificado.
!>

I

!>          I es INTEGER
!>           Fila de la entrada sin pivotar a devolver. No modificado.
!>

J

!>          J es INTEGER
!>           Columna de la entrada sin pivotar a devolver. No modificado.
!>

ISUB

!>          ISUB es INTEGER
!>           Fila de la entrada pivoteada a devolver. Cambiado en la salida.
!>

JSUB

!>          JSUB es INTEGER
!>           Columna de la entrada pivoteada a devolver. Cambiado en la salida.
!>

KL

!>          KL es INTEGER
!>           Ancho de banda inferior. No modificado.
!>

KU

!>          KU es INTEGER
!>           Ancho de banda superior. No modificado.
!>

IDIST

!>          IDIST es INTEGER
!>           En la entrada, IDIST especifica el tipo de distribución que se
!>           utilizará para generar una matriz aleatoria.
!>           1 => UNIFORME( 0, 1 )
!>           2 => UNIFORME( -1, 1 )
!>           3 => NORMAL( 0, 1 )
!>           No modificado.
!>

ISEED

!>          ISEED es un array INTEGER de dimensión ( 4 )
!>           Semilla para el generador de números aleatorios.
!>           Cambiado en la salida.
!>

D

!>          D es un array REAL de dimensión ( MIN( I , J ) )
!>           Entradas diagonales de la matriz. No modificado.
!>

IGRADE

!>          IGRADE es INTEGER
!>           Especifica la calificación de la matriz de la siguiente manera:
!>           0  => sin calificación
!>           1  => matriz premultiplicada por diag( DL )
!>           2  => matriz postmultiplicada por diag( DR )
!>           3  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>           4  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>           5  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>           No modificado.
!>

DL

!>          DL es un array REAL ( I o J, según corresponda )
!>           Factores de escala izquierda para calificar la matriz. No modificado.
!>

DR

!>          DR es un array REAL ( I o J, según corresponda )
!>           Factores de escala derecha para calificar la matriz. No modificado.
!>

IPVTNG

!>          IPVTNG es INTEGER
!>           En la entrada especifica las permutaciones de pivoteo de la
!>           siguiente manera:
!>           0 => ninguna.
!>           1 => pivoteo de filas.
!>           2 => pivoteo de columnas.
!>           3 => pivoteo completo, es decir, en ambos lados.
!>           No modificado.
!>

IWORK

!>          IWORK es un array INTEGER ( I o J, según corresponda )
!>           Este array especifica la permutación utilizada. La fila
!>           (o columna) originalmente en la posición K está en la
!>           posición IWORK( K ) después de la pivoteación.
!>           Esto difiere de IWORK para SLATM2. No modificado.
!>

SPARSE

!>          SPARSE es REAL entre 0. y 1.
!>           En la entrada especifica la dispersión de la matriz
!>           si se va a generar una matriz dispersa.
!>           SPARSE debe estar entre 0 y 1.
!>           Se genera un número aleatorio uniforme ( 0, 1 ) x y se
!>           compara con SPARSE; si x es mayor, la entrada de la matriz
!>           no cambia y si x es menor, la entrada se establece a
!>           cero. Por lo tanto, en promedio, una fracción SPARSE de las
!>           entradas se establecerá a cero.
!>           No modificado.
!>
