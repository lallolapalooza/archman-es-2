Documentación de la Función/Subrutina

subrutina slarrf (integer n, real, dimension( * ) d, real, dimension( * ) l, real, dimension( * ) ld, integer clstrt, integer clend, real, dimension( * ) w, real, dimension( * ) wgap, real, dimension( * ) werr, real spdiam, real clgapl, real clgapr, real pivmin, real sigma, real, dimension( * ) dplus, real, dimension( * ) lplus, real, dimension( * ) work, integer info)

SLARRF encuentra una nueva representación relativamente robusta tal que al menos uno de los valores propios esté relativamente aislado.

Propósito:

!>
!> Dada la representación inicial L D L^T y su clúster de valores
!> propios cercanos (en una medida relativa), W( CLSTRT ), W( CLSTRT+1 ), ...
!> W( CLEND ), SLARRF encuentra una nueva representación relativamente
!> robusta L D L^T - SIGMA I = L(+) D(+) L(+)^T tal que al menos uno de los
!> valores propios de L(+) D(+) L(+)^T esté relativamente aislado.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz (subbloque, si la matriz está dividida).
!>

D

!>          D es un array REAL, de dimensión (N)
!>          Los N elementos diagonales de la matriz diagonal D.
!>

L

!>          L es un array REAL, de dimensión (N-1)
!>          Los N-1 elementos subdiagonales de la matriz bidiagonal unitaria
!>          L.
!>

LD

!>          LD es un array REAL, de dimensión (N-1)
!>          Los N-1 elementos L(i)*D(i).
!>

CLSTRT

!>          CLSTRT es INTEGER
!>          El índice del primer valor propio en el clúster.
!>

CLEND

!>          CLEND es INTEGER
!>          El índice del último valor propio en el clúster.
!>

W

!>          W es un array REAL, de dimensión
!>          dimensión es >=  (CLEND-CLSTRT+1)
!>          Las APROXIMACIONES de los valores propios de L D L^T en orden
!>          ascendente.
!>          W( CLSTRT ) hasta W( CLEND ) forman el clúster de valores
!>          propios relativamente cercanos.
!>

WGAP

!>          WGAP es un array REAL, de dimensión
!>          dimensión es >=  (CLEND-CLSTRT+1)
!>          La separación del siguiente valor propio a la derecha en W.
!>

WERR

!>          WERR es un array REAL, de dimensión
!>          dimensión es >=  (CLEND-CLSTRT+1)
!>          WERR contiene la semiamplitud del intervalo de incertidumbre
!>          de la APROXIMACIÓN del valor propio correspondiente en W.
!>

SPDIAM

!>          SPDIAM es REAL
!>          estimación del diámetro espectral obtenido de los
!>          intervalos de Gerschgorin.
!>

CLGAPL

!>          CLGAPL es REAL
!>

CLGAPR

!>          CLGAPR es REAL
!>          brecha absoluta en cada extremo del clúster.
!>          Establecido por la rutina de llamada para proteger contra
!>          desplazamientos demasiado cercanos a valores propios fuera del
!>          clúster.
!>

PIVMIN

!>          PIVMIN es REAL
!>          El pivote mínimo permitido en la secuencia de Sturm.
!>

SIGMA

!>          SIGMA es REAL
!>          El desplazamiento utilizado para formar L(+) D(+) L(+)^T.
!>

DPLUS

!>          DPLUS es un array REAL, de dimensión (N)
!>          Los N elementos diagonales de la matriz diagonal D(+).
!>

LPLUS

!>          LPLUS es un array REAL, de dimensión (N-1)
!>          Los primeros (N-1) elementos de LPLUS contienen los elementos
!>          subdiagonales de la matriz bidiagonal unitaria L(+).
!>

WORK

!>          WORK es un array REAL, de dimensión (2*N)
!>          Espacio de trabajo.
!>

INFO

!>          INFO es INTEGER
!>          Indica procesamiento OK (=0) o fallo (=1).
!>
