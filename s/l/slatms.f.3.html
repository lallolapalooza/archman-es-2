Documentación de Función/Subrutina

subroutine slatms (integer m, integer n, character dist, integer, dimension( 4 ) iseed, character sym, real, dimension( * ) d, integer mode, real cond, real dmax, integer kl, integer ku, character pack, real, dimension( lda, * ) a, integer lda, real, dimension( * ) work, integer info)

SLATMS

Propósito:

!>
!>    SLATMS genera matrices aleatorias con valores singulares especificados
!>    (o simétricas/hermitianas con valores propios especificados)
!>    para probar programas LAPACK.
!>
!>    SLATMS opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Establece la diagonal en D, donde D puede ser de entrada o
!>         calculada según MODE, COND, DMAX y SYM
!>         como se describe a continuación.
!>
!>      Genera una matriz con la estructura de banda apropiada, mediante uno
!>         de dos métodos:
!>
!>      Método A:
!>          Genera una matriz densa M x N multiplicando D a la izquierda
!>              y a la derecha por matrices unitarias aleatorias, luego:
!>
!>          Reduce el ancho de banda según KL y KU, usando
!>          transformaciones de Householder.
!>
!>      Método B:
!>          Convierte una matriz de ancho de banda 0 (es decir, diagonal) a una
!>              matriz de ancho de banda 1 usando rotaciones de Givens,
!>              elementos fuera de banda hacia atrás, de manera similar a QR; luego
!>              convierte de ancho de banda 1 a ancho de banda 2, etc.
!>              Tenga en cuenta que para anchos de banda razonablemente pequeños (en relación con
!>              M y N) esto requiere menos almacenamiento, ya que no se genera una matriz densa.
!>              Además, para matrices simétricas, solo se genera un triángulo.
!>
!>      Se elige el Método A si el ancho de banda es una fracción grande del
!>          orden de la matriz, y LDA es al menos M (para que se pueda almacenar
!>          una matriz densa). Se elige el Método B si el ancho de banda
!>          es pequeño (< 1/2 N para simétricas, < .3 N+M para
!>          no simétricas), o LDA es menor que M y no menor que el
!>          ancho de banda.
!>
!>      Empaqueta la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetar
!>         poner a cero la mitad superior (si es simétrica)
!>         poner a cero la mitad inferior (si es simétrica)
!>         almacenar la mitad superior columna por columna (si es simétrica o
!>               triangular superior)
!>         almacenar la mitad inferior columna por columna (si es simétrica o
!>               triangular inferior)
!>         almacenar el triángulo inferior en formato de banda (si es simétrica o
!>               triangular inferior)
!>         almacenar el triángulo superior en formato de banda (si es simétrica o
!>               triangular superior)
!>         almacenar toda la matriz en formato de banda
!>      Si se elige el Método B, y se especifica el formato de banda, entonces la
!>         matriz se generará en formato de banda, por lo que no será necesario
!>         reempaquetarla.
!>

Parámetros

M 
!>          M es INTEGER
!>           El número de filas de A. No modificado.
!>

N

!>          N es INTEGER
!>           El número de columnas de A. No modificado.
!>

DIST

!>          DIST es CHARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución a utilizar
!>           para generar los valores propios/singulares aleatorios.
!>           'U' => UNIFORME( 0, 1 )  ('U' para uniforme)
!>           'S' => UNIFORME( -1, 1 ) ('S' para simétrico)
!>           'N' => NORMAL( 0, 1 )   ('N' para normal)
!>           No modificado.
!>

ISEED

!>          ISEED es un array INTEGER, de dimensión ( 4 )
!>           En la entrada, ISEED especifica la semilla del generador de números
!>           aleatorios. Debería estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           utiliza una secuencia congruencial lineal limitada a enteros pequeños,
!>           y por lo tanto debería producir números aleatorios independientes de la máquina.
!>           Los valores de ISEED se modifican al salir, y pueden usarse en la siguiente llamada a SLATMS
!>           para continuar la misma secuencia de números aleatorios.
!>           Modificado al salir.
!>

SYM

!>          SYM es CHARACTER*1
!>           Si SYM='S' o 'H', la matriz generada es simétrica, con
!>             valores propios especificados por D, COND, MODE y DMAX; pueden
!>             ser positivos, negativos o cero.
!>           Si SYM='P', la matriz generada es simétrica, con
!>             valores propios (= valores singulares) especificados por D, COND,
!>             MODE y DMAX; no serán negativos.
!>           Si SYM='N', la matriz generada es no simétrica, con
!>             valores singulares especificados por D, COND, MODE y DMAX;
!>             no serán negativos.
!>           No modificado.
!>

D

!>          D es un array REAL, de dimensión ( MIN( M , N ) )
!>           Este array se utiliza para especificar los valores singulares o
!>           valores propios de A (ver SYM, arriba). Si MODE=0, entonces D se
!>           asume que contiene los valores singulares/propios, de lo contrario
!>           se calcularán según MODE, COND y DMAX,
!>           y se colocarán en D.
!>           Modificado si MODE es distinto de cero.
!>

MODE

!>          MODE es INTEGER
!>           En la entrada, esto describe cómo se especificarán los valores propios/singulares:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1.
!>           Si SYM='S' o 'H', y MODE no es 0, 6 ni -6, entonces
!>              los elementos de D también se multiplicarán por un signo aleatorio (es decir, +1 o -1).
!>           No modificado.
!>

COND

!>          COND es REAL
!>           En la entrada, se usa como se describe en MODE arriba.
!>           Si se usa, debe ser >= 1. No modificado.
!>

DMAX

!>          DMAX es REAL
!>           Si MODE no es -6, 0 ni 6, el contenido de D, tal como se
!>           calcula según MODE y COND, se escalará por
!>           DMAX / max(abs(D(i))); por lo tanto, el valor propio o singular
!>           máximo absoluto (es decir, la norma) será abs(DMAX).
!>           Tenga en cuenta que DMAX no tiene por qué ser positivo: si DMAX es negativo
!>           (o cero), D se escalará por un número negativo (o cero).
!>           No modificado.
!>

KL

!>          KL es INTEGER
!>           Esto especifica el ancho de banda inferior de la matriz. Por
!>           ejemplo, KL=0 implica triangular superior, KL=1 implica Hessenberg
!>           superior, y KL siendo al menos M-1 significa que la matriz
!>           tiene ancho de banda inferior completo. KL debe ser igual a KU si la matriz
!>           es simétrica.
!>           No modificado.
!>

KU

!>          KU es INTEGER
!>           Esto especifica el ancho de banda superior de la matriz. Por
!>           ejemplo, KU=0 implica triangular inferior, KU=1 implica Hessenberg
!>           inferior, y KU siendo al menos N-1 significa que la matriz
