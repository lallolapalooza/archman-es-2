SLAPO-AUDITLOG(5) Manual de formatos de archivo SLAPO-AUDITLOG(5)

NOMBRE

slapo-auditlog - Superposición de registro de auditoría para slapd

SINOPSIS

/etc/openldap/slapd.conf

/etc/openldap/slapd.d

DESCRIPCIÓN

La superposición de registro de auditoría se puede utilizar para registrar todos los cambios en una base de datos backend dada a un archivo de registro especificado. Los cambios se registran como LDIF estándar, con una cabecera de comentario adicional que proporciona seis campos de información sobre el cambio. Se agrega una segunda cabecera de comentario al final de la operación para indicar la terminación del cambio.

Para las operaciones de Añadir y Modificar, la identidad proviene de modifiersName asociado con la operación. Esto suele ser lo mismo que la identidad del solicitante, pero puede ser establecido por otras superposiciones para reflejar otros valores.

CONFIGURACIÓN

Esta opción de slapd.conf se aplica a la superposición de registro de auditoría. Debería aparecer después de la directiva overlay.

auditlog <nombre_archivo>
Especifica la ruta completa para el archivo de registro.
olcAuditlogFile <nombre_archivo>
Para usar con cn=config

INFORMACIÓN DEL CAMPO DE COMENTARIO

El primer campo es el tipo de operación.
El segundo campo es la marca de tiempo de la operación en segundos desde la época.
El tercer campo es el sufijo de la base de datos.
El cuarto campo es el modifiersName registrado.
El quinto campo es la dirección IP y el puerto de origen.
El sexto campo es el número de conexión. Un número de conexión de -1 indica una operación interna de slapd.

EJEMPLO

El siguiente LDIF se podría usar para agregar esta superposición a cn=config (ajustar según sea necesario)

dn: olcOverlay=auditlog,olcDatabase={1}mdb,cn=config
changetype: add
objectClass: olcOverlayConfig
objectClass: olcAuditLogConfig
olcOverlay: auditlog
olcAuditlogFile: /tmp/auditlog.ldif

EJEMPLO DE REGISTRO DE CAMBIOS

# modify 1614223245 dc=example,dc=com cn=admin,dc=example,dc=com IP=[::1]:47270 conn=1002
dn: uid=joepublic,ou=people,dc=example,dc=com
changetype: modify
replace: displayName
displayName: Joe Public
-
replace: entryCSN
entryCSN: 20210225032045.045229Z#000000#001#000000
-
replace: modifiersName
modifiersName: cn=admin,dc=example,dc=com
-
replace: modifyTimestamp
modifyTimestamp: 20210225032045Z
-
# end modify 1614223245
