subroutine slaed5 (integer i, real, dimension( 2 ) d, real, dimension( 2 ) z, real, dimension( 2 ) delta, real rho, real dlam)

SLAED5 utilizada por SSTEDC. Resuelve la ecuación secular de 2x2.

Propósito:

!>
!> Esta subrutina calcula el I-ésimo valor propio de una modificación
!> simétrica de rango uno de una matriz diagonal de 2x2
!>
!>            diag( D )  +  RHO * Z * transpuesta(Z) .
!>
!> Se asume que los elementos diagonales en el array D satisfacen
!>
!>            D(i) < D(j)  para  i < j .
!>
!> También asumimos que RHO > 0 y que la norma euclidiana del vector
!> Z es uno.
!>

Parámetros

I 
!>          I es ENTERO
!>         El índice del valor propio a calcular.  I = 1 o I = 2.
!>

D

!>          D es array REAL, dimension (2)
!>         Los valores propios originales.  Asumimos D(1) < D(2).
!>

Z

!>          Z es array REAL, dimension (2)
!>         Los componentes del vector de actualización.
!>

DELTA

!>          DELTA es array REAL, dimension (2)
!>         El vector DELTA contiene la información necesaria
!>         para construir los vectores propios.
!>

RHO

!>          RHO es REAL
!>         El escalar en la fórmula de actualización simétrica.
!>

DLAM

!>          DLAM es REAL
!>         El lambda_I calculado, el I-ésimo valor propio actualizado.
!>
