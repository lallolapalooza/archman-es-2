NOMBRE

slaptest - Comprueba la idoneidad de la configuración slapd de OpenLDAP

SINOPSIS

/usr/bin/slaptest [-d nivel-depuración] [-f slapd.conf] [-F directorio-conf] [-nnum-bd] [-o opción[=valor]] [-Q] [-u] [-v]

DESCRIPCIÓN

Slaptest se utiliza para comprobar la conformidad de la configuración de slapd(8). Abre el archivo de configuración slapd.conf(5) o el backend de slapd-config(5), y lo analiza según las reglas generales y específicas del backend, comprobando su integridad.

OPCIONES

-d nivel-depuración
habilita los mensajes de depuración definidos por el nivel-depuración especificado; véase slapd(8) para más detalles.
-f slapd.conf
especifica un archivo slapd.conf(5) alternativo.
-F directorio-conf
especifica un directorio de configuración. Si se especifican tanto -f como -F, el archivo de configuración se leerá y se convertirá al formato de directorio de configuración y se escribirá en el directorio especificado. Si no se especifica ninguna de las opciones, slaptest intentará leer el directorio de configuración predeterminado antes de intentar utilizar el archivo de configuración predeterminado. Si existe un directorio de configuración válido, se ignorará el archivo de configuración predeterminado. Si también se especifica el modo de solo lectura, no se realizará ninguna conversión.
-n num-bd
Simplemente abre y prueba la num-bd-ésima base de datos listada en el archivo de configuración. Para probar solo la base de datos de configuración slapd-config(5), use -n 0 ya que siempre es la primera base de datos.
-o opción[=valor]
Especifica una opción con un valor (opcional). Las posibles opciones/valores genéricos son:
              syslog=<subsistemas>  (ver `-s' en slapd(8))
              syslog-level=<nivel> (ver `-S' en slapd(8))
              syslog-user=<usuario>   (ver `-l' en slapd(8))
-Q
Sé extremadamente silencioso: solo el código de salida indica éxito (0) o no (cualquier otro valor).
-u
habilita el modo de solo lectura (es decir, no falla si las bases de datos no se pueden abrir, pero la configuración está bien).
-v
habilita el modo detallado.

EJEMPLOS

Para comprobar un slapd.conf(5), ejecute el comando:

/usr/bin/slaptest -f //etc/openldap/slapd.conf -v
