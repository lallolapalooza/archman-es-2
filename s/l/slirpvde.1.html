SLIRPVDE(1) Manual de Comandos Generales SLIRPVDE(1)

NOMBRE

slirpvde - Interfaz Ethernet Distribuida Virtual-Slirp

SINOPSIS

slirpvde OPCIONES [ directorio_socket ]

DESCRIPCIÓN

slirpvde es una interfaz slirp para una red VDE.

Slirpvde conecta todas las unidades (máquinas virtuales o reales) a la red del host donde se ejecuta slirpvde como si fuera un router NAT/Masquerading. La ruta por defecto es el nodo 2 (10.0.2.2 en la configuración de red por defecto) y el DNS se re-mapea en el nodo 3 (10.0.2.3).

Slirpvde se ejecuta utilizando privilegios de usuario estándar (no necesita acceso root): todas las conexiones son regeneradas por el propio slirpvde.

Solo IPv4. IPv6 aún no es compatible (será compatible cuando slirpvde sea reescrito utilizando la pila de red LWIPv6).

OPCIONES

-s, --sock, --socket, --vdesock, --unix directorio
especifica el directorio del switch VDE (por defecto /var/run/vde.ctl). El directorio del switch VDE también se puede especificar al final del comando, como se ilustra con el parámetro opcional directorio_socket en la sección de sinopsis, más arriba. Cuando se usa '-' en lugar del directorio del switch VDE, slirpvde funciona como un plug (ver vde_plug(1)). El comando:

dpipe vde_plug = ssh remote.machine.org slirpvde -

que es lo mismo que:

dpipe vde_plug = ssh remote.machine.org slirpvde -s -

conecta el switch local por defecto a un slirpvde remoto.
-p, --pidfile nombre_archivo
especifica el nombre del archivo que contiene el PID de slirpvde.
-g, --group grupo
especifica el grupo UNIX para el socket de comunicación VDE.
-m, --mod modo
especifica los permisos UNIX octales para el socket de comunicación VDE.
-P, --port puerto
especifica el puerto del switch vde al que slirpvde debe conectarse.
-d, --daemon
se separa de la terminal y ejecuta slirpvde en segundo plano.
-H, --host dirección [ / longitud_máscara ]
especifica la dirección del host (por defecto 10.0.2.2/24). Esta opción define automáticamente la red. por ejemplo:
-H 192.168.55.1
o:
--host 10.1.2.3/16
El valor por defecto para longitud_máscara es 24. Si la parte del host de la dirección es cero, esta opción define solo la red. La dirección host por defecto es la dirección 2, el proxy DNS por defecto es la 3. por ejemplo:
-H 10.1.0.0/16
define solo la red. La dirección host es 10.1.0.2 y el proxy DNS 10.1.0.3.
-n, --network dirección [ / longitud_máscara ]
especifica la dirección de red (por defecto 10.0.2.0/24). Obsoleto, se ha incluido solo por compatibilidad. Es un alias de -H, --host.
-N, --dns dirección
Especifica la dirección del servidor DNS. Si es una dirección dentro de la red slirp, slirvde actúa como un proxy DNS en esa dirección. El servidor DHCP de slirpvde envía esta dirección DNS a los clientes. Por defecto es el número de host 3 en la red slirpvde. Usando la red por defecto es 10.0.2.3. Advertencia: no use la misma dirección para host y DNS.
-D, --dhcp
activa el servidor DHCP para la autoconfiguración de red de todas las unidades conectadas al VDE. Es posible especificar la dirección de inicio asignada por el servidor DHCP de la siguiente manera:
--dhcp=10.1.1.44
DHCP asigna direcciones a partir del número de host 15 por defecto. Usando la red por defecto, comienza desde 10.0.2.15
-L puerto:host_vde:puerto_host_vde
especifica un reenvío de puerto TCP. Todos los paquetes TCP recibidos por el host que ejecuta slirpvde en el puerto puerto se reenviarán a host_vde en el puerto puerto_host_vde.
-U puerto:host_vde:puerto_host_vde
especifica un reenvío de puerto UDP. Todos los paquetes UDP recibidos por el host que ejecuta slirpvde en el puerto puerto se reenviarán a host_vde en el puerto puerto_host_vde.
-X host_vde[:display.[screen]]i
redirige una pantalla de ventana X de una máquina virtual. Slirpvde obtiene la primera pantalla X no utilizada en el host que ejecuta slirpvde y redirige todas las solicitudes a host_vde. display y screen] deben especificarse cuando son diferentes de :0.0.
-x puerto:ruta_socket_unix]
redirige un puerto del router virtual (normalmente 10.0.2.2) a un socket de flujo unix. Se utiliza, por ejemplo, para redirigir una pantalla X del ordenador anfitrión a la red virtual. ej. -x6000:/tmp/.X11-unix/X0. (Se requiere una configuración adecuada de xhost (ej. 'xhost local:').
-t, --tftp ruta_directorio
slirpvde habilita el intercambio de un servidor tftp (solo lectura) del directorio en ruta_directorio.
-q, --quiet
Silencioso; no escriba nada en la salida estándar.
