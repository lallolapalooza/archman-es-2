sleep(3) Manual de funciones de biblioteca sleep(3)

NOMBRE

sleep - dormir durante un número especificado de segundos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
unsigned int sleep(unsigned int seconds);

DESCRIPCIÓN

sleep() hace que el hilo que llama duerma hasta que hayan transcurrido el número de segundos de tiempo real especificado en seconds o hasta que llegue una señal que no sea ignorada.

VALOR DE RETORNO

Cero si el tiempo solicitado ha transcurrido, o el número de segundos restantes para dormir, si la llamada fue interrumpida por un manejador de señales.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
sleep () Seguridad de hilos MT-Unsafe sig:SIGCHLD/linux

VERSIÓNES

En Linux, sleep() se implementa a través de nanosleep(2). Consulte la página del manual de nanosleep(2) para una discusión sobre el reloj utilizado.

En algunos sistemas, sleep() puede implementarse utilizando alarm(2) y SIGALRM (POSIX.1 lo permite); mezclar llamadas a alarm(2) y sleep() es una mala idea.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

ADVERTENCIAS

El uso de longjmp(3) desde un manejador de señales o la modificación del manejo de SIGALRM mientras se duerme provocará resultados indefinidos.

VER TAMBIÉN

sleep(1), alarm(2), nanosleep(2), signal(2), signal(7)
