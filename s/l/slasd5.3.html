Documentación de Función/Subrutina

subrutina slasd5 (integer i, real, dimension( 2 ) d, real, dimension( 2 ) z, real, dimension( 2 ) delta, real rho, real dsigma, real, dimension( 2 ) work)

SLASD5 calcula la raíz cuadrada de la i-ésima eigenvalue de una modificación simétrica de rango uno de una matriz diagonal de 2x2 positiva. Usado por sbdsdc.

Propósito:

!>
!> Esta subrutina calcula la raíz cuadrada de la I-ésima eigenvalue
!> de una modificación simétrica de rango uno positiva de una matriz diagonal
!> de 2x2
!>
!>            diag( D ) * diag( D ) +  RHO * Z * transpose(Z) .
!>
!> Se asume que las entradas diagonales en el array D satisfacen
!>
!>            0 <= D(i) < D(j)  para  i < j .
!>
!> También asumimos que RHO > 0 y que la norma euclidiana del vector
!> Z es uno.
!>

Parámetros

I 
!>          I es INTEGER
!>         El índice de la eigenvalue a calcular.  I = 1 o I = 2.
!>

D

!>          D es un array REAL, dimensión (2)
!>         Las eigenvalues originales. Asumimos 0 <= D(1) < D(2).
!>

Z

!>          Z es un array REAL, dimensión (2)
!>         Los componentes del vector de actualización.
!>

DELTA

!>          DELTA es un array REAL, dimensión (2)
!>         Contiene (D(j) - sigma_I) en su j-ésimo componente.
!>         El vector DELTA contiene la información necesaria
!>         para construir los eigenvectores.
!>

RHO

!>          RHO es REAL
!>         El escalar en la fórmula de actualización simétrica.
!>

DSIGMA

!>          DSIGMA es REAL
!>         El sigma_I calculado, la I-ésima eigenvalue actualizada.
!>

WORK

!>          WORK es un array REAL, dimensión (2)
!>         WORK contiene (D(j) + sigma_I) en su j-ésimo componente.
!>
