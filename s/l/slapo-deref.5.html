NOMBRE

slapo-deref - Superposición de control de Dereference para slapd

SINOPSIS

/etc/openldap/slapd.conf

/etc/openldap/slapd.d

DESCRIPCIÓN

Esta superposición implementa el control de Dereference propuesto. La superposición se puede usar con cualquier backend o globalmente para todos los backends.

EJEMPLOS

  database mdb
  ...
  overlay deref

Dados estos registros:

  dn: cn=Howard Chu,ou=people,dc=example,dc=org
  objectClass: inetOrgPerson
  cn: Howard Chu
  sn: Chu
  uid: hyc
  dn: cn=Pierangelo Masarati,ou=people,dc=example,dc=org
  objectClass: inetOrgPerson
  cn: Pierangelo Masarati
  sn: Masarati
  uid: ando
  dn: cn=Test Group,ou=groups,dc=example,dc=org
  objectClass: groupOfNames
  cn: Test Group
  member: cn=Howard Chu,ou=people,dc=example,dc=org
  member: cn=Pierangelo Masarati,ou=people,dc=example,dc=org

Se podría realizar una búsqueda con un control de solicitud de Dereference especificado como

  { member, uid }

Es decir,

  ldapsearch -x -b dc=example,dc=org -E 'deref=member:uid'

y el registro "cn=Test Group" se devolvería con el valor de control de respuesta

  { { member, cn=Howard Chu,ou=people,dc=example,dc=org,
      { { uid, [hyc] } } },
    { member, cn=Pierangelo Masarati,ou=people,dc=example,dc=org,
      { { uid, [ando] } } } }

ARCHIVOS

/etc/openldap/slapd.conf
archivo de configuración predeterminado de slapd
/etc/openldap/slapd.d
directorio de configuración predeterminado de slapd

VER TAMBIÉN

slapd.conf(5), slapd-config(5).

"Guía del Administrador de OpenLDAP" (http://www.OpenLDAP.org/doc/admin/)

Propuesta de control de Dereference LDAP de IETF por P. Masarati, H. Chu, en el documento de IETF "draft-masarati-ldap-deref-00.txt".
