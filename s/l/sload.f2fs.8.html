SLOAD.F2FS(8) Manual del Administrador del Sistema SLOAD.F2FS(8)

NOMBRE

sload.f2fs - carga directorios y archivos directamente en el dispositivo

SINOPSIS

sload.f2fs [ -f ruta-directorio-origen ] [ -t punto-montaje ] [ -d nivel-depuracion ] [ -P ] [ -c [ -L log-bloques-por-cluster ] [ -a algoritmo-compresion ] [ -x extension-archivo-excluir-compresion | -i extension-archivo-incluir-compresion ] [ -m min-bloques-comprimidos-por-cluster ] [ -r ] ] dispositivo

DESCRIPCION

sload.f2fs se utiliza para cargar directorios y archivos en una partición de disco, o un archivo de imagen F2FS. dispositivo podría ser un archivo especial correspondiente al dispositivo (por ejemplo, /dev/sdXX), o un archivo de imagen F2FS.

El código de salida devuelto por sload.f2fs es 0 en caso de éxito y -1 en caso de fallo.

OPCIONES

-f ruta-directorio-origen
Especifica la ruta del directorio de origen a cargar.
-t ruta-punto-montaje
Especifica la ruta del punto de montaje en la partición a cargar.
-d nivel-depuracion
Especifica el nivel de opciones de depuración. El número por defecto es 0, que muestra mensajes básicos de depuración.
-P
Preservar propietario: usuario y grupo. Se tendrán en cuenta el usuario y el grupo de los archivos de origen.
-c
Habilita la compresión de archivos basada en clústeres. El archivo se troceará en clústeres, y cada clúster se comprimirá independientemente.
-L log-bloques-por-cluster
Especifica el tamaño del clúster en potencias de dos bloques. El valor mínimo es 2 (4 bloques, por defecto). El valor máximo es 8 (256 bloques). Tenga en cuenta que un bloque contiene 4096 bytes. Esta opción debe usarse con la opción -c.
-a algoritmo-compresion
Elige el algoritmo de compresión. Las opciones disponibles son: lzo, lz4 (por defecto). Esta opción debe usarse con la opción -c.
-i extension-archivo-incluir-compresion
Especifica una extensión de archivo a incluir para la compresión. Para especificar múltiples extensiones de archivo, use múltiples opciones -i. Los archivos que tengan una de las extensiones listadas serán comprimidos. Esta opción debe usarse con la opción -c.
-x extension-archivo-excluir-compresion
Especifica una extensión de archivo a excluir de la compresión. Para especificar múltiples extensiones de archivo, use múltiples opciones -x. Los archivos que tengan una de las extensiones listadas no serán comprimidos. Esta opción debe usarse con la opción -c.
-m min-bloques-comprimidos-por-cluster
Especifica un número mínimo de bloques ahorrados (mediante compresión) por clúster. El valor mínimo es 1 (por defecto). El valor máximo es el tamaño del clúster en bloques menos 1. Si la compresión de un clúster no logra ahorrar al menos el número mínimo de bloques comprimidos dado por la opción, el clúster no se comprimirá. Esta opción debe usarse con la opción -c.
-r
Especifica el indicador de solo lectura para los archivos comprimidos. Permite al sistema de archivos liberar espacio comprimido a los usuarios, ya que, sin esta opción, el sistema de archivos debería conservar el espacio para futuras actualizaciones de archivos. Esta opción debe usarse con la opción -c.

NOTAS

Si no se utiliza ni -i ni -x, todos los archivos se comprimirán. Obviamente, las opciones -i y -x no se pueden usar juntas.
