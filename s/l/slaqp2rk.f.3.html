Documentación de la Función/Subrutina

subrutina slaqp2rk (integer m, integer n, integer nrhs, integer ioffset, integer kmax, real abstol, real reltol, integer kp1, real maxc2nrm, real, dimension( lda, * ) a, integer lda, integer k, real maxc2nrmk, real relmaxc2nrmk, integer, dimension( * ) jpiv, real, dimension( * ) tau, real, dimension( * ) vn1, real, dimension( * ) vn2, real, dimension( * ) work, integer info)

SLAQP2RK calcula la factorización QR truncada con pivoteo de columnas de un bloque de matriz real usando BLAS de Nivel 2 y sobrescribe una matriz real B de m-por-nrhs con Q**T * B.

Propósito:

!>
!> SLAQP2RK calcula una factorización Householder QR truncada (de rango K) o de rango completo
!> con pivoteo de columnas de un bloque de matriz real
!> A(IOFFSET+1:M,1:N) como
!>
!>   A * P(K) = Q(K) * R(K).
!>
!> La subrutina utiliza BLAS de Nivel 2. El bloque A(1:IOFFSET,1:N)
!> se pivotea en consecuencia, pero no se factoriza.
!>
!> La subrutina también sobrescribe el bloque de matriz de los lados derechos B
!> almacenado en A(IOFFSET+1:M,N+1:N+NRHS) con Q(K)**T * B.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de
!>          columnas de la matriz B. NRHS >= 0.
!>

IOFFSET

!>          IOFFSET es INTEGER
!>          El número de filas de la matriz A que deben pivotarse
!>          pero no factorizarse. IOFFSET >= 0.
!>
!>          IOFFSET también representa el número de columnas de la matriz
!>          A_orig completa que se han factorizado
!>          en los pasos anteriores.
!>

KMAX

!>          KMAX es INTEGER
!>
!>          El primer criterio de parada de la factorización. KMAX >= 0.
!>
!>          El número máximo de columnas de la matriz A a factorizar,
!>          es decir, el rango máximo de factorización.
!>
!>          a) Si KMAX >= min(M-IOFFSET,N), entonces este criterio de parada
!>                no se usa, las columnas se factorizan
!>                dependiendo de ABSTOL y RELTOL.
!>
!>          b) Si KMAX = 0, entonces este criterio de parada se
!>             satisface en la entrada y la subrutina sale inmediatamente.
!>             Esto significa que la factorización no se realiza,
!>             las matrices A y B y los arrays TAU, IPIV
!>             no se modifican.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION, no puede ser NaN.
!>
!>          El segundo criterio de parada de la factorización.
!>
!>          La tolerancia absoluta (umbral de parada) para
!>          la norma 2 máxima de columna de la matriz residual.
!>          El algoritmo converge (detiene la factorización) cuando
!>          la norma 2 máxima de columna de la matriz residual
!>          es menor o igual que ABSTOL.
!>
!>          a) Si ABSTOL < 0.0, entonces este criterio de parada no se
!>                usa, la subrutina factoriza columnas dependiendo
!>                de KMAX y RELTOL.
!>                Esto incluye el caso ABSTOL = -Inf.
!>
!>          b) Si 0.0 <= ABSTOL entonces se usa el valor de entrada
!>                de ABSTOL.
!>

RELTOL

!>          RELTOL es DOUBLE PRECISION, no puede ser NaN.
!>
!>          El tercer criterio de parada de la factorización.
!>
!>          La tolerancia (umbral de parada) para la relación entre la
!>          norma 2 máxima de columna de la matriz residual y la norma 2
!>          máxima de columna de la matriz original A_orig. El algoritmo
!>          converge (detiene la factorización) cuando esta relación
!>          es menor o igual que RELTOL.
!>
!>          a) Si RELTOL < 0.0, entonces este criterio de parada no se
!>                usa, la subrutina factoriza columnas dependiendo
!>                de KMAX y ABSTOL.
!>                Esto incluye el caso RELTOL = -Inf.
!>
!>          d) Si 0.0 <= RELTOL entonces se usa el valor de entrada de RELTOL
!>                .
!>

KP1

!>          KP1 es INTEGER
!>          El índice de la columna con la norma 2 máxima en
!>          la matriz original A_orig completa determinada en
!>          la subrutina principal SGEQP3RK. 1 <= KP1 <= N_orig_mat.
!>

MAXC2NRM

!>          MAXC2NRM es DOUBLE PRECISION
!>          La norma 2 máxima de columna de la matriz original
!>          A_orig completa calculada en la subrutina principal SGEQP3RK.
!>          MAXC2NRM >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N+NRHS)
!>          En la entrada:
!>              la matriz A de M por N y la matriz B de M por NRHS, como en
!>
!>                                  N     NRHS
!>              array_A   =   M  [ mat_A, mat_B ]
!>
!>          En la salida:
!>          1. Los elementos en el bloque A(IOFFSET+1:M,1:K) debajo
!>             de la diagonal junto con el array TAU representan
!>             la matriz ortogonal Q(K) como un producto de
!>             reflectores elementales.
!>          2. El bloque triangular de la matriz A almacenado
!>             en A(IOFFSET+1:M,1:K) es el factor triangular obtenido.
!>          3. El bloque de la matriz A almacenado en A(1:IOFFSET,1:N)
!>             ha sido pivotado en consecuencia, pero no factorizado.
!>          4. El resto del array A, bloque A(IOFFSET+1:M,K+1:N+NRHS).
!>             La parte izquierda A(IOFFSET+1:M,K+1:N) de este bloque
!>             contiene el residuo de la matriz A y,
!>             si NRHS > 0, la parte derecha del bloque
!>             A(IOFFSET+1:M,N+1:N+NRHS) contiene el bloque de
!>             la matriz del lado derecho B. Ambos bloques han sido
!>             actualizados por multiplicación desde la izquierda por Q(K)**T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

K

!>          K es INTEGER
!>          Rango de factorización de la matriz A, es decir, el rango
!>          del factor R, que es lo mismo que el número de filas no cero
!>          de R. 0 <= K <= min(M-IOFFSET,KMAX,N).
!>
!>          K también representa el número de vectores de Householder no nulos.
!>

MAXC2NRMK

!>          MAXC2NRMK es DOUBLE PRECISION
!>          La norma 2 máxima de columna de la matriz residual,
!>          cuando la factorización se detuvo en el rango K. MAXC2NRMK >= 0.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK es DOUBLE PRECISION
!>          La relación MAXC2NRMK / MAXC2NRM de la norma 2 máxima de columna
!>          de la matriz residual (cuando la factorización
!>          se detuvo en el rango K) con la norma 2 máxima de columna de la
!>          matriz original A completa. RELMAXC2NRMK >= 0.
!>

JPIV

!>          JPIV es array INTEGER, dimension (N)
!>          Índices de pivote de columna, para 1 <= j <= N, la columna j

!>

TAU

NAME

slaqp2rk

Real rank-revealing QR factorization of a general rectangular matrix

SYNOPSIS

SUBROUTINE SLAQP2RK(
     M, N, K, A, LDA, Q, LDQ, TAU, VN1, VN2, WORK, INFO
    )
  INTEGER :: M, N, K, LDA, LDQ, INFO
  REAL :: A( LDA, * ), Q( LDQ, * ), TAU( * ), VN1( * ), VN2( * ), WORK( * )

Function/Subroutine Documentation

SLAQP2RK performs a rank-revealing QR factorization of an M-by-N matrix A. The factorization is computed in the form

A*Q = P*[(R); (0)]

where Q is an N-by-N orthogonal matrix, P is an M-by-M permutation matrix, and R is K-by-N upper trapezoidal.

The subroutine SLAQP2RK computes the factorization

A = [X] * Q

where Q is an orthogonal matrix and X is M-by-N upper trapezoidal, such that X = [ R ]

[ 0 ]

R is K-by-N upper trapezoidal, and the diagonal entries of R are increasing in magnitude.

The matrix Q is represented as a product of elementary reflectors

Q = Q_1 * Q_2 * ... * Q_K

where each Q_i is a rank-1 update to the identity matrix.

The factorization is intended to identify the rank K of the matrix A.

Arguments:

M

!>          M is INTEGER
!>          The number of rows of the matrix A. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A. N >= 0.
!>

K

!>          K is INTEGER
!>          The rank of the matrix A. K >= 0 and K <= min(M,N).
!>          On exit, K is the rank determined by the algorithm.
!>

A

!>          A is REAL array, dimension (LDA, N)
!>          On entry, the M-by-N matrix A whose factorization is to be
!>          computed.
!>          On exit, A is overwritten by the factors R.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!>

Q

!>          Q is REAL array, dimension (LDQ, N)
!>          On exit, the N-by-N orthogonal matrix Q. Q = Q_1 * Q_2 * ... * Q_K
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of the array Q. LDQ >= max(1,N).
!>

TAU

!>          TAU is REAL array, dimension (min(M,N))
!>          The scalar factors of the elementary reflectors.
!>

VN1

!>          VN1 is REAL array, dimension (N)
!>          The vector with the partial column norms.
!>

VN2

!>          VN2 is REAL array, dimension (N)
!>          The vector with the exact column norms.
!>

WORK

!>          WORK is REAL array, dimension (N-1)
!>          Used in SLARF1F subroutine to apply an elementary
!>          reflector from the left.
!>

INFO

!>          INFO is INTEGER
!>          1) INFO = 0: successful exit.
!>          2) If INFO = j_1, where 1 <= j_1 <= N, then NaN was
!>             detected and the routine stops the computation.
!>             The j_1-th column of the matrix A or the j_1-th
!>             element of array TAU contains the first occurrence
!>             of NaN in the factorization step K+1 ( when K columns
!>             have been factorized ).
!>
!>             On exit:
!>             K                  is set to the number of
!>                                   factorized columns without
!>                                   exception.
!>             MAXC2NRMK          is set to NaN.
!>             RELMAXC2NRMK       is set to NaN.
!>             TAU(K+1:min(M,N))  is not set and contains undefined
!>                                   elements. If j_1=K+1, TAU(K+1)
!>                                   may contain NaN.
!>          3) If INFO = j_2, where N+1 <= j_2 <= 2*N, then no NaN
!>             was detected, but +Inf (or -Inf) was detected and
!>             the routine continues the computation until completion.
!>             The (j_2-N)-th column of the matrix A contains the first
!>             occurrence of +Inf (or -Inf) in the factorization
!>             step K+1 ( when K columns have been factorized ).
!>
