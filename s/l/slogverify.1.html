NOMBRE

slogverify --- Verifica registros asegurados criptográficamente.

SINOPSIS

slogverify [opciones] [argumentos]

DESCRIPCIÓN

La utilidad slogverify se utiliza para verificar la integridad de los registros asegurados criptográficamente y para descifrar las entradas de registro producidas en un entorno de registro seguro de syslog-ng OSE.

  • Modo normal: slogverify -k <archivo clave host> -m <archivo MAC de entrada> <archivo de entrada> <archivo de salida> [buffers]
  • Modo iterativo: slogverify -i -p <clave host anterior> -r <MAC anterior> -m <MAC actual> <archivo de entrada> <archivo de salida> [buffers]

ARGUMENTOS

•
archivo de entrada

Un archivo de registro cifrado del entorno de registro seguro de syslog-ng OSE que se verifica.

•
archivo de salida

El archivo que contiene las entradas de registro en texto plano después de descifrarlas y verificarlas.

•
buffers

Número opcional de buffers de entrada. El número de buffers se puede utilizar para ajustar el rendimiento en caso de que el archivo de registro a verificar sea muy grande y no se pueda procesar de una sola vez. Es un número positivo de entradas de registro que se pueden mantener en memoria durante la verificación. El número mínimo es 10 y el número máximo es 4294967295. Si no se proporciona este argumento, se utiliza el valor predeterminado de 1000.

OPCIONES

•
--iterative o -i

Modo iterativo. Esto es útil en caso de que los archivos de registro se copien periódicamente del sistema en el que se generaron a un colector central. Dado que la rotación de registros, es decir, la sobrescritura de archivos de registro para preservar espacio, no se puede hacer en un entorno de registro seguro, se puede usar el modo iterativo en su lugar. Esto funciona de la siguiente manera: si se alcanza un cierto límite de almacenamiento, el archivo de registro junto con la clave del host y el archivo MAC se copian a una nueva ubicación y el archivo antiguo se elimina. La verificación se realiza en iteraciones, es decir, por separado para cada archivo que se recuperó del host de registro. Para que esto funcione, es importante recuperar siempre los archivos de clave del host y MAC correspondientes. El proceso se puede automatizar, por ejemplo, llamando a slogverify en modo iterativo desde un script.

•
--key-file o -k

La clave inicial del host (k0). Esta opción solo se utiliza en modo normal.

•
--mac-file o -m

El archivo MAC actual utilizado.

•
--prev-key-file o -p

La clave del host correspondiente al archivo de registro anterior. Esta opción solo se puede usar en modo iterativo. En teoría, esta puede ser la clave inicial del host (k0), pero usar esta clave podría generar advertencias, ya que la brecha entre la primera entrada de registro de siempre (entrada de registro 0) y la primera entrada de registro del archivo de registro actual podría ser grande.

•
--prev-mac-file o -r

El archivo MAC del archivo de registro anterior. Esta opción solo se puede usar en modo iterativo.

•
--help o -h

Muestra un mensaje de ayuda.
