NOMBRE

slapd.backends - backends para slapd, el demonio LDAP autónomo

DESCRIPCIÓN

El demonio slapd(8) puede utilizar una variedad de backends diferentes para servir solicitudes LDAP. Los backends pueden compilarse estáticamente en slapd, o cuando se habilita el soporte de módulos, pueden cargarse dinámicamente. Se pueden configurar múltiples instancias de un backend, para servir bases de datos separadas desde el mismo servidor slapd.

Las opciones de configuración para cada backend se documentan por separado en las páginas del manual slapd-<backend>(5) correspondientes.

asyncmeta
Este backend realiza proxy LDAP básico con respecto a un conjunto de servidores LDAP remotos. Es una mejora del backend ldap que opera asincrónicamente, para evitar bloquear hilos de slapd mientras se espera que las operaciones se completen.
config
Este backend se utiliza para gestionar la configuración de slapd en tiempo de ejecución. A diferencia de otros backends, solo puede definirse una única instancia del backend config. También se instancia automáticamente, por lo que siempre está presente aunque no se defina explícitamente en el archivo slapd.conf(5).
dnssrv
Este backend es experimental. Sirve referencias basadas en registros de recursos SRV almacenados en el Sistema de Nombres de Dominio.
ldap
Este backend actúa como un proxy para reenviar las solicitudes entrantes a otro servidor LDAP.
ldif
Esta base de datos utiliza el sistema de archivos para construir la estructura de árbol de la base de datos, utilizando archivos de texto plano para almacenar datos. Su uso debe limitarse a bases de datos muy simples, donde el rendimiento no es un requisito. Este backend también admite renombrar subárboles.
mdb
Este es el backend principal recomendado. Este backend utiliza la biblioteca de base de datos transaccional MDB propia de OpenLDAP. Este backend también admite renombrar subárboles.
meta
Este backend realiza proxy LDAP básico con respecto a un conjunto de servidores LDAP remotos. Es una mejora del backend ldap.
monitor
Este backend proporciona información sobre el estado de ejecución del demonio slapd. Solo puede definirse una única instancia del backend monitor.
null
Las operaciones en este backend tienen éxito pero no hacen nada.
passwd
Este backend se proporciona solo con fines de demostración. Sirve información de cuentas de usuario del archivo del sistema passwd(5).
perl
Este backend incrusta un intérprete perl(1) en slapd. Ejecuta subrutinas Perl para implementar operaciones LDAP. Este backend está obsoleto.
relay
Este backend es experimental. Redirige operaciones LDAP a otra base de datos en el mismo servidor, basándose en el contexto de nombres de la solicitud. Su uso requiere la superposición rwm (ver slapo-rwm(5) para detalles) para reescribir el contexto de nombres de la solicitud. Está destinado principalmente a implementar vistas virtuales sobre bases de datos que realmente almacenan datos.
sql
Este backend es experimental y obsoleto. Sirve solicitudes LDAP desde una base de datos SQL.
wiredtiger
Este backend es experimental. Sirve solicitudes LDAP desde una base de datos wiredtiger.
