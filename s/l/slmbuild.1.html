NOMBRE

slmbuild - genera un modelo de lenguaje a partir de un archivo idngram

SINOPSIS

slmbuild [opción]... archivo_idngram...

DESCRIPCIÓN

slmbuild genera un modelo de lenguaje de suavizado de retroceso a partir de un archivo idngram dado. Generalmente, el archivo_idngram es creado por ids2ngram.

OPCIONES Todas las siguientes opciones son obligatorias.

-n,--NMax N
1 para unigrama, 2 para bigrama, 3 para trigrama. Cualquier número fuera del rango 1..3 no es válido.
-o, --out archivo_salida
Especifica el nombre del archivo de salida xfilei.
-l, --log
usando -log(pr), usa pr directamente por defecto.
-w, --wordcount N
Tamaño del léxico, número de palabras diferentes.
-b, --brk id...
Establece los ids que deben ser tratados como separadores.
-e, --e id...
Establece los ids que no deben ser incluidos en el LM.
-c, --cut c...
Se eliminan los k-gramas cuya frecuencia es <= c[k].
-d, --discount método, param...
El k-ésimo parámetro -d especifica el método de descuento.

Para k-gramas, los valores posibles para método/parámetro son:

B<GT>,I<R>,I<dis>  : Descuento B<GT> para r E<lt>= I<R>, r es la frecuencia de un ngram.
            Descuento lineal para aquellos r E<gt> I<R>, es decir, r'=r*dis
            0 E<lt>E<lt> dis E<lt> 1.0, por ejemplo 0.999 
B<ABS>,[I<dis>] : Descuento absoluto r'=r-I<dis>. Y I<dis> es opcional
            0 E<lt>E<lt> I<dis> E<lt> cut[k]+1.0, normalmente I<dis> E<lt> 1.0.
LIN,[I<dis>] : Descuento lineal r'=r*dis. Y dis es opcional
            0 E<lt> dis E<lt> 1.0

NOTA

-n debe proporcionarse antes que -c y -b. Y -c debe dar el número correcto de cortes, además los -d deben aparecer exactamente N veces especificando los descuentos para 1-grama, 2-grama..., respectivamente.

Los IDs de SEPARADOR podrían ser Tokens de Oración o Tokens de Párrafo. Conceptualmente, estos ids no tienen significado cuando aparecen en medio de un n-grama.

Los IDs a EXCLUIR podrían ser ids ambiguos. Conceptualmente, los n-gramas que contienen esos ids no tienen sentido.

No podemos eliminar n-gramas según los IDs de SEPARADOR y los IDs de EXCLUSIÓN directamente del archivo IDNGRAM, porque cierta información de bajo nivel todavía es útil en él.

EJEMPLO

El siguiente ejemplo lee 'all.id3gram' y escribe el modelo trigrama 'all.slm'.

A nivel de 1-grama, usa descuento Good-Turing con corte 0, i<R>=8, dis=0.9995. A nivel de 2-grama, usa descuento Absoluto con corte 3, dis auto-calculado. A nivel de 3-grama, usa descuento Absoluto con corte 2, dis auto-calculado. El ID de palabra 10,11,12 son separadores (separador de oración/párrafo/papel, etc.). El ID a excluir es 9. El léxico contiene 200000 palabras. El modelo de lenguaje resultante usa -log(pr).

slmbuild -l -n 3 -o all.slm -w 200000 -c 0,3,2 -d GT,8,0.9995 -d ABS -d ABS -b 10,11,12 -e 9 all.id3gram
