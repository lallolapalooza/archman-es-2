NOMBRE

slice2cpp - El compilador de Slice a C++.

SINOPSIS

slice2cpp [opciones] [archivos]

DESCRIPCIÓN

slice2cpp compila archivos Slice a C++. El macro __SLICE2CPP__ se define durante esta compilación.

La documentación completa para slice2cpp está disponible en línea en:
https://doc.zeroc.com/ice/latest/language-mappings/c++11-mapping/slice2cpp-command-line-options

OPCIONES

-h, --help

Muestra el mensaje de ayuda.
-v, --version
Muestra la versión del compilador.
-DNAME

Define el símbolo del preprocesador NAME.
-DNAME=DEF

Define el símbolo del preprocesador NAME con el valor DEF.
-UNAME

Anula la definición del símbolo del preprocesador NAME.
-IDIR

Agrega el directorio DIR a la ruta de búsqueda para las directivas #include.
-E

Imprime la salida del preprocesador en stdout.
--output-dir DIR

Coloca los archivos generados en el directorio DIR.
-d, --debug

Imprime información de depuración que muestra el funcionamiento del analizador Slice.
--depend

Imprime la información de dependencias en la salida estándar por defecto, o en el archivo especificado por la opción --depend-file. No se genera código cuando se especifica esta opción.
--depend-xml

Imprime la información de dependencias en formato XML en la salida estándar por defecto, o en el archivo especificado por la opción --depend-file. No se genera código cuando se especifica esta opción.
--depend-file FILE

Dirige la información de dependencias al archivo especificado. El formato de salida depende de si también se especificó --depend o --depend-xml.
--validate

Verifica la corrección de las opciones de línea de comandos proporcionadas y no genera ningún código.
--header-ext EXT

Cambia la extensión de archivo para los archivos de encabezado generados de h (por defecto) a EXT.
--source-ext EXT

Cambia la extensión de archivo para los archivos fuente generados de cpp (por defecto) a EXT.
--add-header HDR[,GUARD]

Esta opción agrega una directiva include para el encabezado especificado al principio del archivo fuente generado (antes de cualquier otra directiva include). Si se especifica GUARD, la directiva include está protegida por el guardia especificado.
--include-dir DIR

Modifica las directivas #include en los archivos fuente para anteponer el nombre de ruta de cada archivo de encabezado con el directorio DIR.
--impl-c++11

Genera archivos de implementación de ejemplo para el mapeo C++11. Esta opción no sobrescribirá un archivo existente.
--impl-c++98

Genera archivos de implementación de ejemplo para el mapeo C++98. Esta opción no sobrescribirá un archivo existente.
--checksum

Genera sumas de verificación para las definiciones de Slice.
