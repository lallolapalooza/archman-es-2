función real sla_gercond (trans, n, a, lda, af, ldaf, ipiv, cmode, c, info, work, iwork)
SLA_GERCOND estima el número de condición de Skeel para una matriz general.

DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

función real sla_gercond (carácter trans, entero n, real, dimensión( lda, * ) a, entero lda, real, dimensión( ldaf, * ) af, entero ldaf, entero, dimensión( * ) ipiv, entero cmode, real, dimensión( * ) c, entero info, real, dimensión( * ) work, entero, dimensión( * ) iwork)

SLA_GERCOND estima el número de condición de Skeel de op(A) * op2(C) donde op2 se determina por CMODE de la siguiente manera: CMODE = 1 op2(C) = C CMODE = 0 op2(C) = I CMODE = -1 op2(C) = inv(C) El número de condición de Skeel cond(A) = norminf( |inv(A)||A| ) se calcula calculando factores de escala R tales que diag(R)*A*op2(C) sea equilibrado por filas y calculando el número de condición de la norma infinito estándar.

Propósito:

!>
!>    SLA_GERCOND estima el número de condición de Skeel de op(A) * op2(C)
!>    donde op2 está determinado por CMODE como sigue:
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    El número de condición de Skeel cond(A) = norminf( |inv(A)||A| )
!>    se calcula calculando factores de escala R tales que
!>    diag(R)*A*op2(C) sea equilibrado por filas y calculando el número de condición
!>    estándar de la norma infinito.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es ENTERO
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>     En la entrada, la matriz N-por-N A.
!>

LDA

!>          LDA es ENTERO
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array REAL, dimensión (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U tal como lo calcula SGETRF.
!>

LDAF

!>          LDAF es ENTERO
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array ENTERO, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     tal como lo calcula SGETRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>

CMODE

!>          CMODE es ENTERO
!>     Determina op2(C) en la fórmula op(A) * op2(C) como sigue:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C es un array REAL, dimensión (N)
!>     El vector C en la fórmula op(A) * op2(C).
!>

INFO

!>          INFO es ENTERO
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es un array REAL, dimensión (3*N).
!>     Espacio de trabajo.
!>

IWORK

!>          IWORK es un array ENTERO, dimensión (N).
!>     Espacio de trabajo.2
!>
