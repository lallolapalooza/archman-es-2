subrutina slattb (integer imat, character uplo, character trans, character diag, integer, dimension( 4 ) iseed, integer n, integer kd, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) b, real, dimension( * ) work, integer info)

SLATTB

Propósito:

!>
!> SLATTB genera una matriz de prueba triangular en almacenamiento
!> bidimensional. IMAT y UPLO especifican de forma única las propiedades de
!> la matriz de prueba, que se devuelve en la matriz A.
!>

Parámetros

IMAT 
!>          IMAT es INTEGER
!>          Una clave entera que describe qué matriz generar para esta
!>          ruta.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A será triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica si se utilizará la matriz o su transpuesta.
!>          = 'N':  Sin transpuesta
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada (= transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Unitaria triangular
!>

ISEED

!>          ISEED es un array INTEGER, dimension (4)
!>          El vector semilla para el generador de números aleatorios (usado
!>          en SLATMS). Modificado a la salida.
!>

N

!>          N es INTEGER
!>          El orden de la matriz a generar.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales o subdiagonales de la matriz
!>          triangular de banda A. KD >= 0.
!>

AB

!>          AB es un array REAL, dimension (LDAB,N)
!>          La matriz triangular superior o inferior de banda A, almacenada
!>          en las primeras KD+1 filas de AB. Sea j una columna de A,
!>          1<=j<=n.
!>          Si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j.
!>          Si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB. LDAB >= KD+1.
!>

B

!>          B es un array REAL, dimension (N)
!>

WORK

!>          WORK es un array REAL, dimension (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0: si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
