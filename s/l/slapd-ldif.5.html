NOMBRE

slapd-ldif - backend LDIF para slapd

SINOPSIS

/etc/openldap/slapd.conf

DESCRIPCIÓN

El backend LDIF de slapd(8) es un backend de almacenamiento básico que guarda entradas en archivos de texto en formato LDIF, y explota el sistema de archivos para crear la estructura de árbol de la base de datos. Está diseñado como un backend económico, de bajo rendimiento y fácil de usar, y es explotado por estructuras internas de nivel superior para proporcionar un almacenamiento permanente.

CONFIGURACIÓN

Estas opciones de slapd.conf se aplican a la base de datos del backend LDIF. Es decir, deben seguir una línea "database ldif" y preceder a cualquier línea subsiguiente de "backend" o "database". Otras opciones de base de datos se describen en la página del manual de slapd.conf(5).

directory <dir>
Especifica el directorio donde comienza el árbol de la base de datos. El directorio debe existir y otorgar los permisos apropiados (rwx) a la identidad con la que se está ejecutando slapd.

CONTROL DE ACCESO

El backend LDIF no respeta ninguna de las semánticas de control de acceso descritas en slapd.access(5). Solo se respeta el acceso de lectura (=r) al pseudo-atributo entry y a los demás valores de atributos de las entradas devueltas por la operación search, la cual es realizada por el frontend.

ARCHIVOS

/etc/openldap/slapd.conf
archivo de configuración predeterminado de slapd

VER TAMBIÉN

slapd.conf(5), slapd-config(5), slapd(8), ldif(5).
