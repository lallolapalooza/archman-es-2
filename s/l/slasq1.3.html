Documentación de la función/subrutina

subrutina slasq1 (integer n, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) work, integer info)

SLASQ1 calcula los valores singulares de una matriz bidiagonal cuadrada real. Utilizada por sbdsqr.

Propósito:

!>
!> SLASQ1 calcula los valores singulares de una matriz bidiagonal real NxN
!> con diagonal D y subdiagonal E. Los valores singulares se calculan con
!> alta precisión relativa, en ausencia de desnormalización, desbordamiento
!> inferior y superior. El algoritmo se presentó por primera vez en
!>
!>  por K. V.
!> Fernando y B. N. Parlett, Numer. Math., Vol-67, No. 2, pp. 191-230,
!> 1994,
!>
!> y la implementación actual se describe en , Nota de Trabajo LAPACK.
!>

Parámetros

N 
!>          N es INTEGER
!>        El número de filas y columnas de la matriz. N >= 0.
!>

D

!>          D es un array REAL, de dimensión (N)
!>        En la entrada, D contiene los elementos diagonales de la
!>        matriz bidiagonal cuya SVD se desea. En la salida normal,
!>        D contiene los valores singulares en orden decreciente.
!>

E

!>          E es un array REAL, de dimensión (N)
!>        En la entrada, los elementos E(1:N-1) contienen los elementos
!>        fuera de la diagonal de la matriz bidiagonal cuya SVD se desea.
!>        En la salida, E se sobrescribe.
!>

WORK

!>          WORK es un array REAL, de dimensión (4*N)
!>

INFO

!>          INFO es INTEGER
!>        = 0: salida exitosa
!>        < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>        > 0: el algoritmo falló
!>             = 1, una división se marcó con un valor positivo en E
!>             = 2, el bloque actual de Z no se diagonalizó después de 100*N
!>                  iteraciones (en el bucle while interno) En la salida, D y E
!>                  representan una matriz con los mismos valores singulares
!>                  que la subrutina de llamada podría usar para finalizar el
!>                  cálculo, o incluso realimentar a SLASQ1
!>             = 3, el criterio de terminación del bucle while externo no se cumplió
!>                  (el programa creó más de N bloques no reducidos)
!>
