subrutina slaqtr (ltran, lreal, n, t, ldt, b, w, scale, x, work, info)
SLAQTR resuelve un sistema cuasi-triangular real, o un sistema cuasi-triangular complejo de forma especial, en aritmética real.

Documentación de Función/Subrutina

subrutina slaqtr (logical ltran, logical lreal, integer n, real, dimension( ldt, * ) t, integer ldt, real, dimension( * ) b, real w, real scale, real, dimension( * ) x, real, dimension( * ) work, integer info)

SLAQTR resuelve un sistema cuasi-triangular real, o un sistema cuasi-triangular complejo de forma especial, en aritmética real.

Propósito:

!>
!> SLAQTR resuelve el sistema cuasi-triangular real
!>
!>              op(T)*p = scale*c,               si LREAL = .TRUE.
!>
!> o los sistemas cuasi-triangulares complejos
!>
!>            op(T + iB)*(p+iq) = scale*(c+id),  si LREAL = .FALSE.
!>
!> en aritmética real, donde T es cuasi-triangular superior.
!> Si LREAL = .FALSE., entonces el primer bloque diagonal de T debe ser
!> de 1 por 1, B es la matriz de estructura especial
!>
!>                B = [ b(1) b(2) ... b(n) ]
!>                    [       w            ]
!>                    [           w        ]
!>                    [              .     ]
!>                    [                 w  ]
!>
!> op(A) = A o A**T, A**T denota la transpuesta de
!> la matriz A.
!>
!> En la entrada, X = [ c ]. En la salida, X = [ p ].
!>               [ d ]                  [ q ]
!>
!> Esta subrutina está diseñada para la estimación del número de
!> condición en la rutina STRSNA.
!>

Parámetros

LTRAN 
!>          LTRAN es LOGICAL
!>          En la entrada, LTRAN especifica la opción de transpuesta conjugada:
!>             = .FALSE.,    op(T+i*B) = T+i*B,
!>             = .TRUE.,     op(T+i*B) = (T+i*B)**T.
!>

LREAL

!>          LREAL es LOGICAL
!>          En la entrada, LREAL especifica la estructura de la matriz de entrada:
!>             = .FALSE.,    la entrada es compleja
!>             = .TRUE.,     la entrada es real
!>

N

!>          N es INTEGER
!>          En la entrada, N especifica el orden de T+i*B. N >= 0.
!>

T

!>          T es array REAL, dimension (LDT,N)
!>          En la entrada, T contiene una matriz en forma canónica de Schur.
!>          Si LREAL = .FALSE., entonces el primer bloque diagonal de T debe
!>          ser de 1 por 1.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal de la matriz T. LDT >= max(1,N).
!>

B

!>          B es array REAL, dimension (N)
!>          En la entrada, B contiene los elementos para formar la matriz
!>          B como se describe arriba.
!>          Si LREAL = .TRUE., B no se referencia.
!>

W

!>          W es REAL
!>          En la entrada, W es el elemento diagonal de la matriz B.
!>          Si LREAL = .TRUE., W no se referencia.
!>

SCALE

!>          SCALE es REAL
!>          En la salida, SCALE es el factor de escala.
!>

X

!>          X es array REAL, dimension (2*N)
!>          En la entrada, X contiene el lado derecho del sistema.
!>          En la salida, X se sobrescribe con la solución.
!>

WORK

!>          WORK es array REAL, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          En la salida, INFO se establece en
!>             0: salida exitosa.
!>               1: algún bloque diagonal de 1x1 ha sido perturbado por
!>                  un número pequeño SMIN para mantener la no singularidad.
!>               2: algún bloque diagonal de 2x2 ha sido perturbado por
!>                  un número pequeño en SLALN2 para mantener la no singularidad.
!>          NOTA: Por motivos de velocidad, esta subrutina no
!>                comprueba los errores de entrada.
!>
