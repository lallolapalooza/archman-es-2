SLASDA calcula la descomposición de valores singulares (SVD) de una matriz bidiagonal superior real con diagonales d y fuera de diagonal e. Usado por sbdsdc.

Propósito:

!>
!> Usando un enfoque de divide y vencerás, SLASDA calcula la descomposición
!> de valores singulares (SVD) de una matriz B bidiagonal superior real
!> N por M con diagonal D y fuera de diagonal E, donde M = N + SQRE. El
!> algoritmo calcula los valores singulares en la SVD B = U * S * VT.
!> Las matrices ortogonales U y VT se computan opcionalmente en
!> forma compacta.
!>
!> Una subrutina relacionada, SLASD0, calcula los valores singulares y
!> los vectores singulares en forma explícita.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>         Especifica si los vectores singulares se van a computar
!>         en forma compacta, como sigue:
!>         = 0: Computar solo los valores singulares.
!>         = 1: Computar los vectores singulares de la matriz bidiagonal
!>              superior en forma compacta.
!>

SMLSIZ

!>          SMLSIZ es INTEGER
!>         El tamaño máximo de los subproblemas en la parte inferior del
!>         árbol de computación.
!>

N

!>          N es INTEGER
!>         La dimensión de fila de la matriz bidiagonal. Esta es
!>         también la dimensión del array de la diagonal principal D.
!>

SQRE

!>          SQRE es INTEGER
!>         Especifica la dimensión de columna de la matriz bidiagonal.
!>         = 0: La matriz bidiagonal tiene dimensión de columna M = N;
!>         = 1: La matriz bidiagonal tiene dimensión de columna M = N + 1.
!>

D

!>          D es array REAL, dimension ( N )
!>         En la entrada, D contiene la diagonal principal de la matriz
!>         bidiagonal. En la salida, D, si INFO = 0, contiene sus valores singulares.
!>

E

!>          E es array REAL, dimension ( M-1 )
!>         Contiene las entradas subdiagonales de la matriz bidiagonal.
!>         En la salida, E ha sido destruido.
!>

U

!>          U es array REAL,
!>         dimension ( LDU, SMLSIZ ) si ICOMPQ = 1, y no referenciado
!>         si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, U contiene las matrices
!>         de vectores singulares izquierdos de todos los subproblemas en
!>         el nivel inferior.
!>

LDU

!>          LDU es INTEGER, LDU = > N.
!>         La dimensión principal de los arrays U, VT, DIFL, DIFR, POLES,
!>         GIVNUM y Z.
!>

VT

!>          VT es array REAL,
!>         dimension ( LDU, SMLSIZ+1 ) si ICOMPQ = 1, y no referenciado
!>         si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, VT**T contiene las matrices
!>         de vectores singulares derechos de todos los subproblemas en
!>         el nivel inferior.
!>

K

!>          K es array INTEGER, dimension ( N )
!>         si ICOMPQ = 1 y dimension 1 si ICOMPQ = 0.
!>         Si ICOMPQ = 1, en la salida, K(I) es la dimensión de la I-ésima
!>         ecuación secular en el árbol de computación.
!>

DIFL

!>          DIFL es array REAL, dimension ( LDU, NLVL ),
!>         donde NLVL = floor(log_2 (N/SMLSIZ))).
!>

DIFR

!>          DIFR es array REAL,
!>                  dimension ( LDU, 2 * NLVL ) si ICOMPQ = 1 y
!>                  dimension ( N ) si ICOMPQ = 0.
!>         Si ICOMPQ = 1, en la salida, DIFL(1:N, I) y DIFR(1:N, 2 * I - 1)
!>         registran las distancias entre los valores singulares en el nivel I
!>         y los valores singulares en el nivel (I -1), y
!>         DIFR(1:N, 2 * I ) contiene los factores de normalización para
!>         la matriz de vectores singulares derechos. Ver SLASD8 para detalles.
!>

Z

!>          Z es array REAL,
!>                  dimension ( LDU, NLVL ) si ICOMPQ = 1 y
!>                  dimension ( N ) si ICOMPQ = 0.
!>         Los primeros K elementos de Z(1, I) contienen los componentes de
!>         la fila del vector de actualización ajustado por deflación para subproblemas
!>         en el nivel I.
!>

POLES

!>          POLES es array REAL,
!>         dimension ( LDU, 2 * NLVL ) si ICOMPQ = 1, y no referenciado
!>         si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, POLES(1, 2*I - 1) y
!>         POLES(1, 2*I) contienen los valores singulares nuevos y antiguos
!>         involucrados en las ecuaciones seculares en el nivel I.
!>

GIVPTR

!>          GIVPTR es array INTEGER,
!>         dimension ( N ) si ICOMPQ = 1, y no referenciado si
!>         ICOMPQ = 0. Si ICOMPQ = 1, en la salida, GIVPTR( I ) registra
!>         el número de rotaciones de Givens realizadas en el I-ésimo
!>         problema en el árbol de computación.
!>

GIVCOL

!>          GIVCOL es array INTEGER,
!>         dimension ( LDGCOL, 2 * NLVL ) si ICOMPQ = 1, y no
!>         referenciado si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, para cada I,
!>         GIVCOL(1, 2 *I - 1) y GIVCOL(1, 2 *I) registran las ubicaciones
!>         de las rotaciones de Givens realizadas en el nivel I en
!>         el árbol de computación.
!>

LDGCOL

!>          LDGCOL es INTEGER, LDGCOL = > N.
!>         La dimensión principal de los arrays GIVCOL y PERM.
!>

PERM

!>          PERM es array INTEGER, dimension ( LDGCOL, NLVL )
!>         si ICOMPQ = 1, y no referenciado
!>         si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, PERM(1, I) registra
!>         las permutaciones realizadas en el nivel I del árbol de computación.
!>

GIVNUM

!>          GIVNUM es array REAL,
!>         dimension ( LDU,  2 * NLVL ) si ICOMPQ = 1, y no
!>         referenciado si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, para cada I,
!>         GIVNUM(1, 2 *I - 1) y GIVNUM(1, 2 *I) registran los valores C y S
!>         de las rotaciones de Givens realizadas en el nivel I en
!>         el árbol de computación.
!>

C

!>          C es array REAL,
!>         dimension ( N ) si ICOMPQ = 1, y dimension 1 si ICOMPQ = 0.
!>         Si ICOMPQ = 1 y el I-ésimo subproblema no es cuadrado, en la salida,
!>         C( I ) contiene el valor C de una rotación de Givens relacionada con
!>         el espacio nulo derecho del I-ésimo subproblema.
!>

S

!>          S es array REAL, dimension ( N ) si
!>

NAME

slasda - approximate computations for the singular values of a submatrix of a general matrix.

SYNOPSIS

 subroutine slasda(ICHOL, MU, NL, NR, SQRE, NLVL, NSE, SUML, SUMR, INTL, INTR,
                  ZINY, PREC, SUBP, WORK, IWORK, INFO)

 logical*4 ICOLQ
 real*4 MU, NL, NR, SQRE, NLVL, NSE, SUML, SUMR, ZINY, PREC, SUBP
 integer*4 NL, NR, INTL, INTR, IWORK

 real*4 S( * ), WORK( * )
 integer*4 IWORK( * )

 logical*4 ICOLQ
 real*4 MU, NL, NR, SQRE, NLVL, NSE, SUML, SUMR, ZINY, PREC, SUBP
 integer*4 NL, NR, INTL, INTR, INFO
 real*4 S( * ), WORK( * )
 integer*4 IWORK( * )

Function/Subroutine Documentation

This subroutine approximates the singular values of a submatrix of a general matrix.

Arguments

ICHOL (output) logical.

SQRE (output) logical.

NLVL (output) integer.

NSE (output) integer.

SUML (output) real.

SUMR (output) real.

ZINY (output) real.

PREC (output) real.

SUBP (output) real.

INTL (output) integer.

INTR (output) integer.

MU (output) real.

NL (output) integer.

NR (output) integer.

S (output) real array

!>          S is REAL array, dimension ( 2*ML + 2 ).
!>          On exit, S contains the computed singular values.
!>

WORK (workspace)

!>          WORK is REAL array, dimension (6 * N + (SMLSIZ + 1)*(SMLSIZ + 1)).
!>

IWORK (workspace)

!>          IWORK is INTEGER array, dimension (7*N).
!>

INFO (output) integer

!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if INFO = 1, a singular value did not converge
!>

Additional Description

ICOMPQ = 1, and dimension 1 if ICOMPQ = 0. If ICOMPQ = 1 and the I-th subproblem is not square, on exit, S( I ) contains the S-value of a Givens rotation related to the right null space of the I-th subproblem.

WORK

!>          WORK is REAL array, dimension
!>         (6 * N + (SMLSIZ + 1)*(SMLSIZ + 1)).
!>

IWORK

!>          IWORK is INTEGER array, dimension (7*N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if INFO = 1, a singular value did not converge
!>
