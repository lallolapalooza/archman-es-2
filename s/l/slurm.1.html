NOMBRE

Slurm - Resumen del Gestor de Carga de Trabajo Slurm.

DESCRIPCIÓN

El Gestor de Carga de Trabajo Slurm es un sistema de gestión y planificación de trabajos de clúster de código abierto, tolerante a fallos y altamente escalable para clústeres Linux grandes y pequeños. Slurm no requiere modificaciones del kernel para su funcionamiento y es relativamente autocontenido. Como gestor de recursos del clúster, Slurm tiene tres funciones clave. En primer lugar, asigna acceso exclusivo y/o no exclusivo a recursos (nodos de cómputo) a los usuarios durante un período de tiempo para que puedan realizar trabajo. En segundo lugar, proporciona un marco para iniciar, ejecutar y supervisar trabajos (normalmente un trabajo paralelo) en el conjunto de nodos asignados. Finalmente, arbitra la contención de recursos gestionando una cola de trabajos pendientes. Se pueden utilizar plugins opcionales para contabilidad, reservas avanzadas, planificación de gangs (tiempo compartido para trabajos paralelos), planificación de backfill, límites de recursos por usuario o cuenta y algoritmos sofisticados de priorización de trabajos multifactorial.

Slurm tiene un gestor centralizado, slurmctld, para supervisar recursos y trabajo. Puede haber también un gestor de respaldo para asumir esas responsabilidades en caso de fallo. Cada servidor de cómputo (nodo) tiene un demonio slurmd, que puede compararse con un shell remoto: espera trabajo, ejecuta ese trabajo, devuelve el estado y espera más trabajo. Un slurmdbd (Slurm DataBase Daemon) opcional puede ser usado con fines de contabilidad y para mantener información sobre límites de recursos.

Las herramientas básicas para el usuario incluyen srun para iniciar trabajos, scancel para terminar trabajos en cola o en ejecución, sinfo para informar sobre el estado del sistema y squeue para informar sobre el estado de los trabajos. También hay una herramienta administrativa scontrol disponible para supervisar y/o modificar información de configuración y estado. Hay APIs disponibles para todas las funciones.

La configuración de Slurm se mantiene en el archivo slurm.conf.

Hay páginas de manual disponibles para todos los comandos de Slurm, demonios, APIs, además del archivo slurm.conf. También hay documentación extensa disponible en Internet en https://slurm.schedmd.com/.
