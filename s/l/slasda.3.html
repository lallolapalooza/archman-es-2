SLASDA calcula la descomposición en valores singulares (SVD) de una matriz real superior bidiagonal con diagonal d y fuera de diagonal e. Usado por sbdsdc.

Propósito:

!>
!> Usando un enfoque de divide y vencerás, SLASDA calcula la
!> descomposición en valores singulares (SVD) de una matriz N-por-M
!> bidiagonal superior real B con diagonal D y fuera de diagonal E,
!> donde M = N + SQRE. El algoritmo calcula los valores singulares
!> en la SVD B = U * S * VT. Las matrices ortogonales U y VT se calculan
!> opcionalmente en forma compacta.
!>
!> Una subrutina relacionada, SLASD0, calcula los valores singulares
!> y los vectores singulares en forma explícita.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>         Especifica si se deben calcular los vectores singulares
!>         en forma compacta, como sigue:
!>         = 0: Calcular solo los valores singulares.
!>         = 1: Calcular los vectores singulares de la matriz
!>              bidiagonal superior en forma compacta.
!>

SMLSIZ

!>          SMLSIZ es INTEGER
!>         El tamaño máximo de los subproblemas en la parte inferior del
!>         árbol de cómputo.
!>

N

!>          N es INTEGER
!>         La dimensión de fila de la matriz bidiagonal superior. Esta
!>         es también la dimensión del array diagonal principal D.
!>

SQRE

!>          SQRE es INTEGER
!>         Especifica la dimensión de columna de la matriz bidiagonal.
!>         = 0: La matriz bidiagonal tiene dimensión de columna M = N;
!>         = 1: La matriz bidiagonal tiene dimensión de columna M = N + 1.
!>

D

!>          D es array REAL, dimension ( N )
!>         En la entrada, D contiene la diagonal principal de la matriz
!>         bidiagonal. En la salida, D, si INFO = 0, contiene sus
!>         valores singulares.
!>

E

!>          E es array REAL, dimension ( M-1 )
!>         Contiene las entradas subdiagonales de la matriz bidiagonal.
!>         En la salida, E ha sido destruido.
!>

U

!>          U es array REAL,
!>         dimension ( LDU, SMLSIZ ) si ICOMPQ = 1, y no referenciado
!>         si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, U contiene las
!>         matrices de vectores singulares izquierdos de todos los
!>         subproblemas en el nivel inferior.
!>

LDU

!>          LDU es INTEGER, LDU = > N.
!>         La dimensión principal de los arrays U, VT, DIFL, DIFR, POLES,
!>         GIVNUM y Z.
!>

VT

!>          VT es array REAL,
!>         dimension ( LDU, SMLSIZ+1 ) si ICOMPQ = 1, y no referenciado
!>         si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, VT**T contiene las
!>         matrices de vectores singulares derechos de todos los
!>         subproblemas en el nivel inferior.
!>

K

!>          K es array INTEGER, dimension ( N )
!>         si ICOMPQ = 1 y dimensión 1 si ICOMPQ = 0.
!>         Si ICOMPQ = 1, en la salida, K(I) es la dimensión de la I-ésima
!>         ecuación secular en el árbol de cómputo.
!>

DIFL

!>          DIFL es array REAL, dimension ( LDU, NLVL ),
!>         donde NLVL = floor(log_2 (N/SMLSIZ))).
!>

DIFR

!>          DIFR es array REAL,
!>                  dimension ( LDU, 2 * NLVL ) si ICOMPQ = 1 y
!>                  dimension ( N ) si ICOMPQ = 0.
!>         Si ICOMPQ = 1, en la salida, DIFL(1:N, I) y DIFR(1:N, 2 * I - 1)
!>         registran las distancias entre los valores singulares en el nivel I
!>         y los valores singulares en el nivel (I -1), y
!>         DIFR(1:N, 2 * I ) contiene los factores de normalización para
!>         la matriz de vectores singulares derechos. Ver SLASD8 para detalles.
!>

Z

!>          Z es array REAL,
!>                  dimension ( LDU, NLVL ) si ICOMPQ = 1 y
!>                  dimension ( N ) si ICOMPQ = 0.
!>         Los primeros K elementos de Z(1, I) contienen los componentes de
!>         la fila de actualización ajustada por deflación para subproblemas
!>         en el nivel I.
!>

POLES

!>          POLES es array REAL,
!>         dimension ( LDU, 2 * NLVL ) si ICOMPQ = 1, y no referenciado
!>         si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, POLES(1, 2*I - 1) y
!>         POLES(1, 2*I) contienen los valores singulares nuevos y antiguos
!>         involucrados en las ecuaciones secular en el nivel I.
!>

GIVPTR

!>          GIVPTR es array INTEGER,
!>         dimension ( N ) si ICOMPQ = 1, y no referenciado si
!>         ICOMPQ = 0. Si ICOMPQ = 1, en la salida, GIVPTR( I ) registra
!>         el número de rotaciones de Givens realizadas en el I-ésimo
!>         problema en el árbol de cómputo.
!>

GIVCOL

!>         referenciado si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, para cada I,
!>         GIVCOL(1, 2 *I - 1) y GIVCOL(1, 2 *I) registran las ubicaciones
!>         de las rotaciones de Givens realizadas en el nivel I en el
!>         árbol de cómputo.
!>

LDGCOL

!>          LDGCOL es INTEGER, LDGCOL = > N.
!>         La dimensión principal de los arrays GIVCOL y PERM.
!>

PERM

!>          PERM es array INTEGER, dimension ( LDGCOL, NLVL )
!>         si ICOMPQ = 1, y no referenciado
!>         si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, PERM(1, I) registra
!>         las permutaciones realizadas en el nivel I del árbol de cómputo.
!>

GIVNUM

!>          GIVNUM es array REAL,
!>         dimension ( LDU,  2 * NLVL ) si ICOMPQ = 1, y no
!>         referenciado si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, para cada I,
!>         GIVNUM(1, 2 *I - 1) y GIVNUM(1, 2 *I) registran los valores C y S
!>         de las rotaciones de Givens realizadas en el nivel I en el
!>         árbol de cómputo.

C

NAME

slasda — Singular value decomposition of a general matrix

SYNOPSIS

      SUBROUTINE SLASDA( F, S, EQ, COLSPC, RSVD, TOL, NB, WORK, IWORK, INFO )
          REAL               F( * )
          REAL               S( * )
          LOGICAL            EQ( * )
          REAL               COLSPC( * )
          REAL               RSVD( * )
          REAL               TOL
          INTEGER            NB
          REAL               WORK( * )
          INTEGER            IWORK( * )
          INTEGER            INFO

Languages: C, Fortran

Subroutines: slasda

Library: LAPACK

Function/Subroutine Documentation

This subroutine is the interface to the SVD routines. It is called by slasq0 and slasq1.

This subroutine computes the singular values of a general matrix A. The matrix A is split into subproblems of size NB x NB. The singular values of A are computed by first computing the singular values of the subproblems, and then merging them together.

Arguments:

F

!>          F is REAL array, dimension (N).
!>          F contains the diagonal entries of the matrix A.
!>

S

!>          S is REAL array, dimension (N).
!>          On exit, S contains the singular values of A.
!>

EQ

!>          EQ is LOGICAL array, dimension (N).
!>          EQ(I) = .TRUE. if the I-th subproblem is square.
!>

COLSPC

!>          COLSPC is REAL array, dimension (N).
!>          COLSPC(I) contains the column space information for the I-th
!>          subproblem.
!>

RSVD

!>          RSVD is REAL array, dimension (N).
!>          RSVD(I) contains the row space information for the I-th
!>          subproblem.
!>

TOL

!>          TOL is REAL
!>          TOL is the tolerance used in determining the rank of the
!>          subproblems.
!>

NB

!>          NB is INTEGER
!>          NB is the blocking size used in splitting the matrix A into
!>          subproblems.
!>

WORK

!>          WORK is REAL array, dimension (6*N + (SMLSIZ+1)*(SMLSIZ+1))
!>          SMLSIZ is the size of the smallest subproblem that is
!>          solved directly.
!>

IWORK

!>          IWORK is INTEGER array, dimension (7*N).
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit.
!>          < 0: if INFO = -i, the i-th argument had an illegal value.
!>          > 0: if INFO = 1, a singular value did not converge.
!>

The singular values are computed by first computing the singular values of the subproblems. The subproblems are of size NB x NB. If the subproblem is not square, then the singular values related to the right null space are computed.

The singular values are computed by merging the singular values of the subproblems. The merging process involves computing the roots of a secular equation. The secular equation is solved using an iterative method.

The tolerance TOL is used to determine the rank of the subproblems. If a singular value is smaller than TOL, it is considered to be zero.

The blocking size NB is used to split the matrix A into subproblems of size NB x NB. The blocking size affects the performance of the algorithm. A larger blocking size can lead to better performance, but it can also lead to larger memory usage.

The workspace array WORK is used to store intermediate results. The size of the workspace array depends on the blocking size NB and the size of the smallest subproblem SMLSIZ.

The integer array IWORK is used to store integer information, such as the indices of the singular values.

The integer INFO is used to return the status of the computation. If INFO is 0, the computation was successful. If INFO is negative, it indicates an error in the input arguments. If INFO is positive, it indicates that a singular value did not converge.

Example Usage:

      REAL F(N), S(N), COLSPC(N), RSVD(N), WORK(6*N + (SMLSIZ+1)*(SMLSIZ+1))
      LOGICAL EQ(N)
      INTEGER IWORK(7*N), NB, TOL, INFO
      ...
      CALL SLASDA(F, S, EQ, COLSPC, RSVD, TOL, NB, WORK, IWORK, INFO)

In the above example, N is the dimension of the matrix A. SMLSIZ is the size of the smallest subproblem that is solved directly. NB is the blocking size used in splitting the matrix A into subproblems.

NOTE:

!>         On exit, if ICOMPQ = 0, S(I) contains the I-th singular value.
!>         If ICOMPQ = 1, S(I) contains the I-th singular value if the
!>         I-th subproblem is square. If the I-th subproblem is not
!>         square, on exit, S( I ) contains the S-value of a Givens
!>         rotation related to the right null space of the I-th
!>         subproblem.
!>

WORK

!>          WORK is REAL array, dimension
!>         (6 * N + (SMLSIZ + 1)*(SMLSIZ + 1)).
!>

IWORK

!>          IWORK is INTEGER array, dimension (7*N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if INFO = 1, a singular value did not converge
!>
