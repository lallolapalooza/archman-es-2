NOMBRE

slock — bloqueador de pantalla X simple

SINOPSIS

slock [-v] [cmd [arg ...]]

DESCRIPCIÓN

slock es un bloqueador de pantalla X simple. Si se proporciona, cmd se ejecutará después de que la pantalla haya sido bloqueada.

Las opciones son las siguientes:

-v
Imprime información de la versión en la salida estándar y sale.

ESTADO DE SALIDA

La utilidad slock sale con 0 en caso de éxito, y >0 si ocurre un error.

EJEMPLOS

$ slock /usr/sbin/s2ram

CONSIDERACIONES DE SEGURIDAD

Para asegurarse de que una pantalla bloqueada no pueda ser eludida cambiando de VT o matando el servidor X con Ctrl+Alt+Retroceso, se recomienda deshabilitar ambas en xorg.conf(5) para máxima seguridad:

Section "ServerFlags"
	Option "DontVTSwitch" "True"
	Option "DontZap"      "True"
EndSection

PERSONALIZACIÓN

slock puede ser personalizado creando un config.h personalizado a partir de config.def.h y (re)compilando el código fuente. Esto lo mantiene rápido, seguro y simple.
