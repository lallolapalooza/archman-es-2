función real slanst (norm, n, d, e)
SLANST devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz simétrica tridiagonal real.

Documentación de Función/Subrutina

real function slanst (character norm, integer n, real, dimension( * ) d, real, dimension( * ) e)

SLANST devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz simétrica tridiagonal real.

Propósito:

!>
!> SLANST  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma  infinito,  o el  elemento de  mayor valor absoluto de  una
!> matriz simétrica tridiagonal real A.
!>

Devuelve

SLANST 
!>
!>    SLANST = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de
    columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de
    fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de
    la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma
    de matriz consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor a devolver en SLANST como se describe
!>          arriba.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, SLANST se
!>          establece a cero.
!>

D

!>          D es un array REAL, dimension (N)
!>          Los elementos diagonales de A.
!>

E

!>          E es un array REAL, dimension (N-1)
!>          Los elementos sub-diagonales o super-diagonales (n-1) de A.
!>
