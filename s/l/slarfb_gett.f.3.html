Documentación de la función/subrutina

subrutina slarfb_gett (character ident, integer m, integer n, integer k, real, dimension( ldt, * ) t, integer ldt, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldwork, * ) work, integer ldwork)

SLARFB_GETT

Propósito:

!>
!> SLARFB_GETT aplica un reflector de bloque Householder real H desde la
!> izquierda a una matriz real (K+M)-por-N
!> compuesta por dos matrices de bloque: una matriz K-por-N en forma
!> trapezoidal superior A almacenada en el array A, y una matriz M-por-(N-K)
!> rectangular B, almacenada en el array B. El reflector de bloque H se
!> almacena en una representación compacta WY, donde los reflectores
!> elementales están en los arrays A, B y T. Ver la sección Detalles
!> adicionales.
!>

Parámetros

IDENT 
!>          IDENT es CHARACTER*1
!>          Si IDENT = no 'I', o no 'i', entonces V1 es unitaria
!>             triangular inferior y se almacena en el bloque K-por-K
!>             izquierdo de la matriz de entrada A,
!>          Si IDENT = 'I' o 'i', entonces V1 es una matriz identidad y
!>             no se almacena.
!>          Ver la sección Detalles adicionales.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.
!>          N >= 0.
!>

K

!>          K es INTEGER
!>          El número o filas de la matriz A.
!>          K es también el orden de la matriz T, es decir, el número de
!>          reflectores elementales cuyo producto define el reflector
!>          de bloque. 0 <= K <= N.
!>

T

!>          T es REAL array, dimension (LDT,K)
!>          La matriz triangular superior K-por-K T en la representación
!>          del reflector de bloque.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= K.
!>

A

!>          A es REAL array, dimension (LDA,N)
!>
!>          En la entrada:
!>           a) En la parte trapezoidal superior K-por-N A: matriz de entrada A.
!>           b) En las columnas debajo de la diagonal: columnas de V1
!>              (los unos no se almacenan en la diagonal).
!>
!>          En la salida:
!>            A se sobrescribe con el producto rectangular K-por-N H*A.
!>
!>          Ver la sección Detalles adicionales.
!>

LDA

!>          LDB es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,K).
!>

B

!>          B es REAL array, dimension (LDB,N)
!>
!>          En la entrada:
!>            a) En el bloque derecho M-por-(N-K): matriz de entrada B.
!>            b) En el bloque izquierdo M-por-N: columnas de V2.
!>
!>          En la salida:
!>            B se sobrescribe con el producto rectangular M-por-N H*B.
!>
!>          Ver la sección Detalles adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,M).
!>

WORK

!>          WORK es REAL array,
!>          dimension (LDWORK,max(K,N-K))
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK. LDWORK>=max(1,K).
!>
!>

Detalles adicionales:

!>
!>    (1) Descripción de la Operación Algebraica.
!>
!>    La matriz A es una matriz K-por-N compuesta por dos matrices de
!>    bloque de columnas, A1, que es K-por-K, y A2, que es K-por-(N-K):
!>    A = ( A1, A2 ).
!>    La matriz B es una matriz M-por-N compuesta por dos matrices de
!>    bloque de columnas, B1, que es M-por-K, y B2, que es M-por-(N-K):
!>    B = ( B1, B2 ).
!>
!>    Realiza la operación:
!>
!>       ( A_salida ) := H * ( A_entrada ) = ( I - V * T * V**T ) * ( A_entrada ) =
!>       ( B_salida )        ( B_entrada )                          ( B_entrada )
!>                  = ( I - ( V1 ) * T * ( V1**T, V2**T ) ) * ( A_entrada )
!>                          ( V2 )                            ( B_entrada )
!>     En la entrada:
!>
!>    a) ( A_entrada ) consiste en dos bloques de columnas:
!>       ( B_entrada )
!>
!>       ( A_entrada ) = (( A1_entrada ) ( A2_entrada )) = (( A1_entrada ) ( A2_entrada ))
!>       ( B_entrada )   (( B1_entrada ) ( B2_entrada ))   ((     0 ) ( B2_entrada )),
!>
!>       donde los bloques de columnas son:
!>
!>       (  A1_entrada )  es una matriz superior-triangular K-por-K almacenada en
!>                        la parte triangular superior del array A(1:K,1:K).
!>       (  B1_entrada )  es una matriz CERO rectangular M-por-K y no se almacena.
!>
!>       ( A2_entrada )  es una matriz rectangular K-por-(N-K) almacenada
!>                       en el array A(1:K,K+1:N).
!>       ( B2_entrada )  es una matriz rectangular M-por-(N-K) almacenada
!>                       en el array B(1:M,K+1:N).
!>
!>    b) V = ( V1 )
!>           ( V2 )
!>
!>       donde:
!>       1) si IDENT == 'I', V1 es una matriz identidad K-por-K, no almacenada;
!>       2) si IDENT != 'I', V1 es una matriz triangular inferior unitaria K-por-K,
!>          almacenada en la parte triangular inferior del array
!>          A(1:K,1:K) (los unos no se almacenan),
!>       y V2 es una matriz rectangular M-por-K almacenada en el array
!>       B(1:M,1:K), (porque en la entrada B1_entrada es una matriz cero
!>       rectangular que no se almacena y el espacio se usa para almacenar V2).
!>
!>    c) T es una matriz triangular superior K-por-K almacenada
!>       en el array T(1:K,1:K).
!>
!>    En la salida:
!>
!>    a) ( A_salida ) consiste en dos bloques de columnas:
!>       ( B_salida )
!>
!>       ( A_salida ) = (( A1_salida ) ( A2_salida ))
!>       ( B_salida )   (( B1_salida ) ( B2_salida )),
!>
!>       donde los bloques de columnas son:
!>
!>       ( A1_salida )  es una matriz cuadrada K-por-K, o una matriz
!>                      triangular superior K-por-K, si V1 es una
!>                      matriz identidad. AiSalida se almacena en
!>                      el array A(1:K,1:K).
!>       ( B1_salida )  es una matriz rectangular M-por-K almacenada
!>                      en el array B(1:M,K:N).
!>
!>       ( A2_salida )  es una matriz rectangular K-por-(N-K) almacenada
!>                      en el array A(1:K,K+1:N).
!>       ( B2_salida )  es una matriz rectangular M-por-(N-K) almacenada
!>                      en el array B(1:M,K+1:N).
!>
!>
!>    La operación anterior se puede representar como la misma operación
!>    en cada bloque de columna:
!>
!>       ( A1_salida ) := H * ( A1_entrada ) = ( I - V * T * V**T ) * ( A1_entrada )
!>       ( B1_salida )        (     0 )                          (     0 )
!>
!>       ( A2_salida ) := H * ( A2_entrada ) = ( I - V * T * V**T ) * ( A2_entrada )
!>       ( B2_salida )        ( B2_entrada )                          ( B2_entrada )
!>
!>    Si IDENT != 'I':
!>
!>       El cálculo para el bloque de columna 1:
!>
!>       A1_salida: = A1_entrada - V1*T*(V1**T)*A1_entrada
!>
!>       B1_salida: = - V2*T*(V1**T)*A1_entrada
!>
!>       El cálculo para el bloque de columna 2, que existe si N > K:
!>
!>       A2_salida: = A2_entrada - V1*T*( (V1**T)*A2_entrada + (V2**T)*B2_entrada )
!>
!>       B2_salida: = B2_entrada - V2*T*( (V1**T)*A2_entrada + (V2**T)*B2_entrada )
!>
!>    Si IDENT == 'I':
!>
!>       La operación para el bloque de columna 1:
!>
!>       A1_salida: = A1_entrada - V1*T**A1_entrada
!>
!>       B1_salida: = - V2*T**A1_entrada
!>
!>       El cálculo para el bloque de columna 2, que existe si N > K:
!>
!>       A2_salida: = A2_entrada - T*( A2_entrada + (V2**T)*B2_entrada )
!>
!>       B2_salida: = B2_entrada - V2*T*(

NAME

slarfb_gett - Computes the required workspace information for sgb_rec.f

SYNOPSIS

CALL slarfb_gett( N, K, IDENT, A1, LDA1, B1, LDB1, A2, LDA2, B2, LDB2, T, LDT, V1, LDV1, V2, LDV2, WORK, LDWORK, INFO )

Function/Subroutine Documentation

!>
!>    This routine computes the workspace requirement for the recursive
!>    routines sgb_rec.f and sgbtrf.f. It returns the minimal size of
!>    the workspace array WORK that is needed to perform the matrix
!>    operations in the recursive routine.
!>
!>    The recursive routine requires two workspace matrices, W1 and W2,
!>    of the following sizes:
!>
!>    - W2: K-by-(N-K) (used in the first step when N > K)
!>    - W1: K-by-K   (used in the second step when N <= K)
!>
!>    The dimensions of the input matrices are:
!>
!>    - A1: K-by-K
!>    - B1: K-by-K
!>    - A2: K-by-(N-K)
!>    - B2: K-by-(N-K)
!>    - T:  K-by-K (trapezoidal matrix)
!>    - V1: K-by-K (unit lower triangular or identity)
!>    - V2: K-by-(N-K)
!>
!>    The dimensions of the workspace matrices W1 and W2 are:
!>
!>    - W1: K-by-K
!>    - W2: K-by-(N-K)
!>
!>    The routine needs to store both W1 and W2 in the workspace array
!>    WORK. Therefore, the required size of WORK is
!>    max(K, N-K) -by- K.
!>
!>    The algorithm first computes the column block 2 (A2 and B2) and
!>    then the column block 1 (A1 and B1).
!>
!>    (1) The computation involves the following matrix updates:
!>
!>    Case (A): V1 is unit lower-triangular.
!>        if ( N > K ) then
!>          (First Step - column block 2)
!>          W2 = A2
!>          W2 = (V1**T) * W2
!>          W2 = W2 + (V2**T) * B2
!>          W2 = T * W2
!>          B2 = B2 - V2 * W2
!>          W2 = V1 * W2
!>          A2 = A2 - W2
!>        else
!>          (Second Step - column block 1)
!>          W1 = A1
!>          W1 = (V1**T) * W1
!>          W1 = T * W1
!>          B1 = - V2 * W1
!>          W1 = V1 * W1
!>          A1 = A1 - W1
!>        end if
!>
!>    Case (B): V1 is an identity matrix.
!>        if ( N > K ) then
!>          (First Step - column block 2)
!>          W2 = A2
!>          W2 = W2 + (V2**T) * B2
!>          W2 = T * W2
!>          B2 = B2 - V2 * W2
!>          A2 = A2 - W2
!>        else
!>          (Second Step - column block 1)
!>          W1 = A1
!>          W1 = T * W1
!>          B1 = - V2 * W1
!>          A1 = A1 - W1  (only upper triangular part is updated)
!>        end if
!>
!>    (2) Description of the Algorithmic Computation.
!>
!>    In the first step, we compute column block 2, i.e. A2 and B2.
!>    Here, we need to use the K-by-(N-K) rectangular workspace
!>    matrix W2 that is of the same size as the matrix A2.
!>    W2 is stored in the array WORK(1:K,1:(N-K)).
!>
!>    In the second step, we compute column block 1, i.e. A1 and B1.
!>    Here, we need to use the K-by-K square workspace matrix W1
!>    that is of the same size as the as the matrix A1.
!>    W1 is stored in the array WORK(1:K,1:K).
!>
!>    NOTE: Hence, in this routine, we need the workspace array WORK
!>    only of size WORK(1:K,1:max(K,N-K)) so it can hold both W2 from
!>    the first step and W1 from the second step.
!>
!>    Case (A), when V1 is unit lower-triangular, i.e. IDENT != 'I',
!>    more computations than in the Case (B).
!>
!>    if( IDENT != 'I' ) then
!>     if ( N > K ) then
!>       (First Step - column block 2)
!>       col2_(1) W2: = A2
!>       col2_(2) W2: = (V1**T) * W2 = (unit_lower_tr_of_(A1)**T) * W2
!>       col2_(3) W2: = W2 + (V2**T) * B2 = W2 + (B1**T) * B2
!>       col2_(4) W2: = T * W2
!>       col2_(5) B2: = B2 - V2 * W2 = B2 - B1 * W2
!>       col2_(6) W2: = V1 * W2 = unit_lower_tr_of_(A1) * W2
!>       col2_(7) A2: = A2 - W2
!>     else
!>       (Second Step - column block 1)
!>       col1_(1) W1: = A1
!>       col1_(2) W1: = (V1**T) * W1 = (unit_lower_tr_of_(A1)**T) * W1
!>       col1_(3) W1: = T * W1
!>       col1_(4) B1: = - V2 * W1 = - B1 * W1
!>       col1_(5) square W1: = V1 * W1 = unit_lower_tr_of_(A1) * W1
!>       col1_(6) square A1: = A1 - W1
!>     end if
!>    end if
!>
!>    Case (B), when V1 is an identity matrix, i.e. IDENT == 'I',
!>    less computations than in the Case (A)
!>
!>    if( IDENT == 'I' ) then
!>     if ( N > K ) then
!>       (First Step - column block 2)
!>       col2_(1) W2: = A2
!>       col2_(3) W2: = W2 + (V2**T) * B2 = W2 + (B1**T) * B2
!>       col2_(4) W2: = T * W2
!>       col2_(5) B2: = B2 - V2 * W2 = B2 - B1 * W2
!>       col2_(7) A2: = A2 - W2
!>     else
!>       (Second Step - column block 1)
!>       col1_(1) W1: = A1
!>       col1_(3) W1: = T * W1
!>       col1_(4) B1: = - V2 * W1 = - B1 * W1
!>       col1_(6) upper-triangular_of_(A1): = A1 - W1
!>     end if
!>    end if
!>
!>    Combine these cases (A) and (B) together, this is the resulting
!>    algorithm:
!>
!>    if ( N > K ) then
!>
!>      (First Step - column block 2)
!>
!>      col2_(1)  W2: = A2
!>      if( IDENT != 'I' ) then
!>        col2_(2)  W2: = (V1**T) * W2
!>                      = (unit_lower_tr_of_(A1)**T) * W2
!>      end if
!>      col2_(3)  W2: = W2 + (V2**T) * B2 = W2 + (B1**T) * B2]
!>      col2_(4)  W2: = T * W2
!>      col2_(5)  B2: = B2 - V2 * W2 = B2 - B1 * W2
!>      if( IDENT != 'I' ) then
!>        col2_(6)    W2: = V1 * W2 = unit_lower_tr_of_(A1) * W2
!>      end if
!>      col2_(7) A2: = A2 - W2
!>
!>    else
!>
!>    (Second Step - column block 1)
!>
!>      col1_(1) W1: = A1
!>      if( IDENT != 'I' ) then
!>        col1_(2) W1: = (V1**T) * W1
!>                    = (unit_lower_tr_of_(A1)**T) * W1
!>      end if
!>      col1_(3) W1: = T * W1
!>      col1_(4) B1: = - V2 * W1 = - B1 * W1
!>      if( IDENT != 'I' ) then
!>        col1_(5) square W1: = V1 * W1 = unit_lower_tr_of_(A1) * W1
!>        col1_(6_a) below_diag_of_(A1): =  - below_diag_of_(W1)
!>      end if
!>      col1_(6_b) up_tr_of_(A1): = up_tr_of_(A1) - up_tr_of_(W1)
!>
!>    end if
!>
!>
