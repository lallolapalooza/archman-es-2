subrutina slaein (logical rightv, logical noinit, integer n, real, dimension( ldh, * ) h, integer ldh, real wr, real wi, real, dimension( * ) vr, real, dimension( * ) vi, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) work, real eps3, real smlnum, real bignum, integer info)

SLAEIN calcula un vector propio derecho o izquierdo especificado de una matriz de Hessenberg superior mediante iteración inversa.

Propósito

!>
!> SLAEIN usa iteración inversa para encontrar un vector propio derecho o
!> izquierdo correspondiente al valor propio (WR,WI) de una matriz de
!> Hessenberg superior real H.
!>

Parámetros

RIGHTV 
!>          RIGHTV es LOGICAL
!>          = .TRUE. : calcular vector propio derecho;
!>          = .FALSE.: calcular vector propio izquierdo.
!>

NOINIT

!>          NOINIT es LOGICAL
!>          = .TRUE. : no se suministra vector inicial en (VR,VI).
!>          = .FALSE.: se suministra vector inicial en (VR,VI).
!>

N

!>          N es INTEGER
!>          El orden de la matriz H.  N >= 0.
!>

H

!>          H es array REAL, dimension (LDH,N)
!>          La matriz de Hessenberg superior H.
!>

LDH

!>          LDH es INTEGER
!>          La dimensión principal del array H.  LDH >= max(1,N).
!>

WR

!>          WR es REAL
!>

WI

!>          WI es REAL
!>          Las partes real e imaginaria del valor propio de H cuyo
!>          vector propio derecho o izquierdo correspondiente se va a
!>          calcular.
!>

VR

!>          VR es array REAL, dimension (N)
!>

VI

!>          VI es array REAL, dimension (N)
!>          En la entrada, si NOINIT = .FALSE. y WI = 0.0, VR debe
!>          contener un vector de inicio real para la iteración inversa
!>          usando el valor propio real WR; si NOINIT = .FALSE. y WI.ne.0.0,
!>          VR y VI deben contener las partes real e imaginaria de un
!>          vector de inicio complejo para la iteración inversa usando
!>          el valor propio complejo (WR,WI); de lo contrario, VR y VI
!>          no necesitan ser establecidos.
!>          En la salida, si WI = 0.0 (valor propio real), VR contiene el
!>          vector propio real calculado; si WI.ne.0.0 (valor propio
!>          complejo), VR y VI contienen las partes real e imaginaria
!>          del vector propio complejo calculado. El vector propio se
!>          normaliza de modo que el componente de mayor magnitud tenga
!>          magnitud 1; aquí la magnitud de un número complejo (x,y) se
!>          toma como |x| + |y|.
!>          VI no se referencia si WI = 0.0.
!>

B

!>          B es array REAL, dimension (LDB,N)
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= N+1.
!>

WORK

!>          WORK es array REAL, dimension (N)
!>

EPS3

!>          EPS3 es REAL
!>          Un valor pequeño dependiente de la máquina que se utiliza para
!>          perturbar valores propios cercanos y para reemplazar pivotes
!>          cero.
!>

SMLNUM

!>          SMLNUM es REAL
!>          Un valor dependiente de la máquina cercano al umbral de
!>          subdesbordamiento.
!>

BIGNUM

!>          BIGNUM es REAL
!>          Un valor dependiente de la máquina cercano al umbral de
!>          desbordamiento.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          = 1:  la iteración inversa no convergió; VR se establece en el
!>                último iterado, y también VI si WI.ne.0.0.
!>
