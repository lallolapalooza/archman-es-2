Documentación de función/subrutina

subroutine slagts (integer job, integer n, real, dimension( * ) a, real, dimension( * ) b, real, dimension( * ) c, real, dimension( * ) d, integer, dimension( * ) in, real, dimension( * ) y, real tol, integer info)

SLAGTS resuelve el sistema de ecuaciones (T-λI)x = y o (T-λI)^Tx = y, donde T es una matriz tridiagonal general y λ un escalar, utilizando la factorización LU calculada por slagtf.

Propósito:

!>
!> SLAGTS puede usarse para resolver uno de los sistemas de ecuaciones
!>
!>    (T - lambda*I)*x = y   o   (T - lambda*I)**T*x = y,
!>
!> donde T es una matriz tridiagonal n x n, para x, después de la
!> factorización de (T - lambda*I) como
!>
!>    (T - lambda*I) = P*L*U ,
!>
!> por la rutina SLAGTF. La elección de la ecuación a resolver se
!> controla por el argumento JOB, y en cada caso hay una opción
!> para perturbar los elementos diagonales de U, cero o muy pequeños,
!> siendo esta opción para su uso en aplicaciones como la iteración inversa.
!>

Parámetros

JOB 
!>          JOB es INTEGER
!>          Especifica la tarea a realizar por SLAGTS de la siguiente manera:
!>          =  1: Se deben resolver las ecuaciones (T - lambda*I)x = y,
!>                pero los elementos diagonales de U no deben perturbarse.
!>          = -1: Se deben resolver las ecuaciones (T - lambda*I)x = y
!>                y, si de otro modo ocurriera un desbordamiento, los elementos
!>                diagonales de U deben perturbarse. Ver el argumento TOL
!>                más abajo.
!>          =  2: Se deben resolver las ecuaciones (T - lambda*I)**Tx = y,
!>                pero los elementos diagonales de U no deben perturbarse.
!>          = -2: Se deben resolver las ecuaciones (T - lambda*I)**Tx = y
!>                y, si de otro modo ocurriera un desbordamiento, los elementos
!>                diagonales de U deben perturbarse. Ver el argumento TOL
!>                más abajo.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T.
!>

A

!>          A es array REAL, dimension (N)
!>          En la entrada, A debe contener los elementos diagonales de U tal
!>          como devueltos por SLAGTF.
!>

B

!>          B es array REAL, dimension (N-1)
!>          En la entrada, B debe contener los elementos superdiagonales
!>          primeros de U tal como fueron devueltos por SLAGTF.
!>

C

!>          C es array REAL, dimension (N-1)
!>          En la entrada, C debe contener los elementos subdiagonales
!>          de L tal como fueron devueltos por SLAGTF.
!>

D

!>          D es array REAL, dimension (N-2)
!>          En la entrada, D debe contener los elementos superdiagonales
!>          segundos de U tal como fueron devueltos por SLAGTF.
!>

IN

!>          IN es array INTEGER, dimension (N)
!>          En la entrada, IN debe contener detalles de la matriz P tal
!>          como fueron devueltos por SLAGTF.
!>

Y

!>          Y es array REAL, dimension (N)
!>          En la entrada, el vector del lado derecho y.
!>          En la salida, Y se sobrescribe con el vector solución x.
!>

TOL

!>          TOL es REAL
!>          En la entrada, con JOB < 0, TOL debe ser la perturbación mínima
!>          a realizar en los elementos diagonales de U muy pequeños.
!>          TOL debe elegirse normalmente como aproximadamente eps*norm(U),
!>          donde eps es la precisión relativa de la máquina, pero si TOL se
!>          proporciona como no positivo, se restablece a eps*max( abs( u(i,j) ) ).
!>          Si JOB > 0 entonces TOL no se referencia.
!>
!>          En la salida, TOL se cambia como se describe anteriormente, solo si
!>          TOL es no positivo en la entrada. De lo contrario, TOL no cambia.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i-ésimo tuvo un valor ilegal
!>          > 0: ocurriría un desbordamiento al calcular el elemento INFO
!>               del vector solución x. Esto solo puede ocurrir cuando
!>               JOB se proporciona como positivo y significa que un
!>               elemento diagonal de U es muy pequeño, o que los
!>               elementos del vector del lado derecho y son muy grandes.
!>
