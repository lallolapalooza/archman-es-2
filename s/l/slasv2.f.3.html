subroutine slasv2 (real f, real g, real h, real ssmin, real ssmax, real snr, real csr, real snl, real csl)

SLASV2 calcula la descomposición de valores singulares de una matriz triangular de 2x2.

Propósito:

!>
!> SLASV2 calcula la descomposición de valores singulares de una matriz triangular
!> de 2x2
!>    [  F   G  ]
!>    [  0   H  ].
!> Al regresar, abs(SSMAX) es el valor singular mayor, abs(SSMIN) es el
!> valor singular menor, y (CSL,SNL) y (CSR,SNR) son los vectores singulares
!> izquierdo y derecho para abs(SSMAX), dando la descomposición
!>
!>    [ CSL  SNL ] [  F   G  ] [ CSR -SNR ]  =  [ SSMAX   0   ]
!>    [-SNL  CSL ] [  0   H  ] [ SNR  CSR ]     [  0    SSMIN ].
!>

Parámetros

F 
!>          F es REAL
!>          El elemento (1,1) de la matriz de 2x2.
!>

G

!>          G es REAL
!>          El elemento (1,2) de la matriz de 2x2.
!>

H

!>          H es REAL
!>          El elemento (2,2) de la matriz de 2x2.
!>

SSMIN

!>          SSMIN es REAL
!>          abs(SSMIN) es el valor singular menor.
!>

SSMAX

!>          SSMAX es REAL
!>          abs(SSMAX) es el valor singular mayor.
!>

SNL

!>          SNL es REAL
!>

CSL

!>          CSL es REAL
!>          El vector (CSL, SNL) es un vector singular izquierdo unitario para el
!>          valor singular abs(SSMAX).
!>

SNR

!>          SNR es REAL
!>

CSR

!>          CSR es REAL
!>          El vector (CSR, SNR) es un vector singular derecho unitario para el
!>          valor singular abs(SSMAX).
!>

Detalles adicionales:

!>
!>  Cualquier parámetro de entrada puede ser aliased con cualquier parámetro de salida.
!>
!>  Excluyendo desbordamientos/subdesbordamientos y asumiendo un dígito de guardia en la resta,
!>  todas las cantidades de salida son correctas dentro de unas pocas unidades en el último
!>  lugar (ulps).
!>
!>  En aritmética IEEE, el código funciona correctamente si un elemento de la matriz es
!>  infinito.
!>
!>  El desbordamiento no ocurrirá a menos que el valor singular más grande en sí mismo
!>  se desborde o esté a unas pocas ulps del desbordamiento.
!>
!>  El subdesbordamiento es inofensivo si es gradual. De lo contrario, los resultados
!>  pueden corresponder a una matriz modificada por perturbaciones de tamaño cercano
!>  al umbral de subdesbordamiento.
!>
