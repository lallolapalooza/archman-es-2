DOCUMENTACIÓN DE LA Función/Subrutina

subrutina slasd5 (integer i, real, dimension( 2 ) d, real, dimension( 2 ) z, real, dimension( 2 ) delta, real rho, real dsigma, real, dimension( 2 ) work)

SLASD5 calcula la raíz cuadrada del i-ésimo valor propio de una matriz diagonal positiva simétrica modificada de rango uno de 2x2. Utilizada por sbdsdc.

Propósito:

!>
!> Esta subrutina calcula la raíz cuadrada del I-ésimo valor propio
!> de una matriz diagonal positiva simétrica modificada de rango uno de 2x2
!>
!>            diag( D ) * diag( D ) +  RHO * Z * transpuesta(Z) .
!>
!> Se asume que las entradas diagonales en el array D satisfacen
!>
!>            0 <= D(i) < D(j)  para  i < j .
!>
!> También asumimos que RHO > 0 y que la norma euclidiana del vector
!> Z es uno.
!>

Parámetros

I 
!>          I es INTEGER
!>         El índice del valor propio a calcular.  I = 1 o I = 2.
!>

D

!>          D es array REAL, dimension (2)
!>         Los valores propios originales.  Asumimos 0 <= D(1) < D(2).
!>

Z

!>          Z es array REAL, dimension (2)
!>         Los componentes del vector de actualización.
!>

DELTA

!>          DELTA es array REAL, dimension (2)
!>         Contiene (D(j) - sigma_I) en su  j-ésimo componente.
!>         El vector DELTA contiene la información necesaria
!>         para construir los vectores propios.
!>

RHO

!>          RHO es REAL
!>         El escalar en la fórmula de actualización simétrica.
!>

DSIGMA

!>          DSIGMA es REAL
!>         El sigma_I calculado, el I-ésimo valor propio actualizado.
!>

WORK

!>          WORK es array REAL, dimension (2)
!>         WORK contiene (D(j) + sigma_I) en su  j-ésimo componente.
!>
