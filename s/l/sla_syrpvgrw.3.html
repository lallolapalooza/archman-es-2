función real sla_syrpvgrw (uplo, n, info, a, lda, af, ldaf, ipiv, work)
SLA_SYRPVGRW calcula el factor de crecimiento del pivote recíproco norm(A)/norm(U) para una matriz indefinida simétrica.

Documentación de la función/subrutina

real function sla_syrpvgrw (character*1 uplo, integer n, integer info, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, real, dimension( * ) work)

SLA_SYRPVGRW calcula el factor de crecimiento del pivote recíproco norm(A)/norm(U) para una matriz indefinida simétrica.

Propósito:

!>
!>
!> SLA_SYRPVGRW calcula el factor de crecimiento del pivote recíproco
!> norm(A)/norm(U). Se utiliza la norma . Si esto es
!> mucho menor que 1, la estabilidad de la factorización LU de la
!> matriz A (equilibrada) podría ser pobre. Esto también significa que
!> la solución X, los números de condición estimados y los límites de error podrían
!> no ser fiables.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

INFO

!>          INFO es INTEGER
!>     El valor de INFO devuelto por SSYTRF, es decir, el pivote en
!>     la columna INFO es exactamente 0.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>     En la entrada, la matriz N por N A.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array REAL, dimensión (LDAF,N)
!>     La matriz diagonal de bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L según lo calculado por SSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     según lo determinado por SSYTRF.
!>

WORK

!>          WORK es array REAL, dimensión (2*N)
!>
