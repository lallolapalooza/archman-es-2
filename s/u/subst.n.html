subst(n) Comandos integrados de Tcl subst(n)

NOMBRE

subst - Realiza sustituciones de barras invertidas, comandos y variables

SINOPSIS

subst ?-nobackslashes? ?-nocommands? ?-novariables? cadena

DESCRIPCIÓN

Este comando realiza sustituciones de variables, sustituciones de comandos y sustituciones de barras invertidas en su argumento cadena y devuelve el resultado completamente sustituido. Las sustituciones se realizan exactamente de la misma manera que para los comandos Tcl. Como resultado, el argumento cadena se sustituye realmente dos veces, una por el analizador de Tcl de la forma habitual para los comandos Tcl y otra por el comando subst.

Si se especifica alguna de las opciones -nobackslashes, -nocommands o -novariables, las sustituciones correspondientes no se realizan. Por ejemplo, si se especifica -nocommands, la sustitución de comandos no se realiza: los corchetes de apertura y cierre se tratan como caracteres ordinarios sin interpretación especial.

Tenga en cuenta que la sustitución de un tipo puede incluir la sustitución de otros tipos. Por ejemplo, incluso cuando se especifica la opción -novariables, la sustitución de comandos se realiza sin restricciones. Esto significa que cualquier sustitución de variable necesaria para completar el comando sustituido todavía tendrá lugar. De manera similar, cualquier sustitución de comando necesaria para completar una sustitución de variable tendrá lugar, incluso cuando se especifica -nocommands. Vea los **EJEMPLOS** a continuación.

Si ocurre un error durante la sustitución, subst devolverá ese error. Si ocurre una excepción de interrupción (`break`) durante la sustitución de comandos o variables, el resultado de toda la sustitución será la cadena (tal como se sustituyó) hasta el inicio de la sustitución que generó la excepción. Si ocurre una excepción de continuación (`continue`) durante la evaluación de una sustitución de comando o variable, se sustituirá una cadena vacía para ese comando o sustitución de variable completa (siempre que sea un Tcl bien formado). Si ocurre una excepción de retorno (`return`), o se devuelve cualquier otro código de retorno durante la sustitución de comandos o variables, el valor devuelto se sustituye por esa sustitución. Vea los **EJEMPLOS** a continuación. De esta manera, todos los códigos de retorno excepcionales son "capturados" por subst. El comando subst en sí mismo devolverá un error o completará con éxito.

EJEMPLOS

Cuando realiza sus sustituciones, subst no da ningún tratamiento especial a las comillas dobles o a las llaves (excepto dentro de las sustituciones de comandos), por lo que el script

set a 44
subst {xyz {$a}}

devuelve “xyz {44}”, no “xyz {$a}” y el script

set a "p\} q \{r"
subst {xyz {$a}}

devuelve “xyz {p} q {r}”, no “xyz {p\} q \{r}”.

Cuando se realiza la sustitución de comandos, incluye cualquier sustitución de variable necesaria para evaluar el script.

set a 44
subst -novariables {$a [format $a]}

devuelve “$a 44”, no “$a $a”. De manera similar, cuando se realiza la sustitución de variables, incluye cualquier sustitución de comando necesaria para recuperar el valor de la variable.

proc b {} {return c}
array set a {c c [b] tricky}
subst -nocommands {[b] $a([b])}

devuelve “[b] c”, no “[b] tricky”.

Las excepciones de continuación y de interrupción permiten a las sustituciones de comandos evitar la sustitución del resto de la sustitución del comando y del resto de cadena respectivamente, dando a los autores de scripts más opciones al procesar texto usando subst. Por ejemplo, el script

subst {abc,[break],def}

devuelve “abc,”, no “abc,,def” y el script

subst {abc,[continue;expr {1+2}],def}

devuelve “abc,,def”, no “abc,3,def”.

Otros códigos de retorno excepcionales sustituyen el valor devuelto

subst {abc,[return foo;expr {1+2}],def}

devuelve “abc,foo,def”, no “abc,3,def” y

subst {abc,[return -code 10 foo;expr {1+2}],def}

también devuelve “abc,foo,def”, no “abc,3,def”.
