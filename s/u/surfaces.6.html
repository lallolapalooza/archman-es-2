NOMBRE

surfaces - Dibuja algunas superficies paramétricas 3D interesantes.

SINOPSIS

surfaces [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id numero] [--speed numero] [--rand] [--spin] [--wander] [--fps] [--surface nombre-superficie] [--random-surface] [--dini] [--enneper] [--kuen] [--moebius] [--seashell] [--swallowtail] [--bohemian] [--whitney] [--pluecker] [--henneberg] [--catalan] [--corkscrew] [--mode modo-visualizacion] [--random-mode] [--points] [--lines] [--line-loops]

DESCRIPCIÓN

Esto dibuja una de varias superficies paramétricas tridimensionales.

OPCIONES

--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de id (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor por defecto.
--root
Dibuja en la ventana raíz.
--window-id numero
Dibuja en la ventana especificada.
--delay numero
Retraso por fotograma, en microsegundos. Por defecto: 20000 (0.02 segundos).
--speed numero
Número de fotogramas antes de cambiar de forma. Por defecto: 1000.
--surface random (Atajo: --random-surface)
Muestra una superficie aleatoria. Este es el valor por defecto.
--surface dini (Atajo: --dini)
Muestra la superficie de Dini.
--surface enneper (Atajo: --enneper)
Muestra la superficie mínima de Enneper.
--surface kuen (Atajo: --kuen)
Muestra la superficie de Kuen.
--surface moebius (Atajo: --moebius)
Muestra la banda de Moebius.
--surface seashell (Atajo: --seashell)
Muestra la superficie de concha marina.
--surface swallowtail (Atajo: --swallowtail)
Muestra la catástrofe del rabo de golondrina.
--surface bohemian (Atajo: --bohemian)
Muestra la cúpula bohemia.
--surface whitney (Atajo: --whitney)
Muestra el paraguas de Whitney.
--surface pluecker (Atajo: --pluecker)
Muestra el conoide de Pluecker.
--surface henneberg (Atajo: --henneberg)
Muestra la superficie mínima de Henneberg.
--surface catalan (Atajo: --catalan)
Muestra la superficie mínima de Catalan.
--surface corkscrew (Atajo: --corkscrew)
Muestra la superficie de sacacorchos.
--mode random (Atajo: --random-mode)
Usa primitivas OpenGL aleatorias para mostrar la superficie. Este es el valor por defecto.
--mode points (Atajo: --points)
Usa puntos OpenGL para mostrar la superficie.
--mode lines (Atajo: --lines)
Usa líneas OpenGL para mostrar la superficie.
--mode line-loops (Atajo: --line-loops)
Usa bucles de línea OpenGL para mostrar la superficie.
--wander | --no-wander
Si deambular por la pantalla.
--spin | --no-spin
Si rotar alrededor del centro de la figura.
--fps
Muestra la velocidad de fotogramas actual, la carga de CPU y el número de polígonos.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
