SULOGIN(8) Administración del Sistema SULOGIN(8)

NOMBRE

sulogin - inicio de sesión en modo usuario único

SINOPSIS

sulogin [opciones] [tty]

DESCRIPCIÓN

sulogin es invocado por init cuando el sistema entra en modo de usuario único.

Se le pide al usuario:

Introduce la contraseña de root para mantenimiento del sistema (o pulsa Control-D para inicio normal):

Si la cuenta de root está bloqueada y se especifica --force, no se requiere contraseña.

sulogin estará conectado al terminal actual, o al dispositivo tty opcional que se puede especificar en la línea de comandos (típicamente /dev/console).

Cuando el usuario sale del shell de usuario único, o pulsa control-D en el prompt, el sistema continuará el arranque.

OPCIONES

-e, --force

Si el método predeterminado para obtener la contraseña de root del sistema a través de getpwnam(3) falla, entonces examina /etc/passwd y /etc/shadow para obtener la contraseña. Si estos archivos están dañados o no existen, o cuando la cuenta de root está bloqueada por '!' o '*' al principio de la contraseña, sulogin iniciará un shell de root sin pedir contraseña.

Utiliza la opción -e solo si estás seguro de que la consola está físicamente protegida contra el acceso no autorizado.

-p, --login-shell

Especificar esta opción hace que sulogin inicie el proceso de shell como un shell de inicio de sesión.

-t, --timeout segundos

Especifica el tiempo máximo de espera para la entrada del usuario. Por defecto, sulogin esperará indefinidamente.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

ENTORNO

sulogin busca la variable de entorno SUSHELL o sushell para determinar qué shell iniciar. Si la variable de entorno no está establecida, intentará ejecutar el shell de root de /etc/passwd. Si eso falla, recurrirá a /bin/sh.

AUTORES

sulogin fue escrito por Miquel van Smoorenburg para sysvinit y posteriormente portado a util-linux por Dave Reisner y Karel Zak.
