SURFRAW-UPDATE-PATH(1) Documentación Perl contribuida por el usuario SURFRAW-UPDATE-PATH(1)

NOMBRE

surfraw-update-path - actualiza PATH en los archivos de configuración del shell

SINOPSIS

surfraw-update-path [-add] [-remove] [-check] [-sys] [-all] [-help] [-shell=SHELL]

DESCRIPCIÓN

surfraw-update-path agrega el directorio de elvi de surfraw (/usr/lib/surfraw) a tu PATH en el archivo de configuración de tu shell.

Actualmente soporta bash, sh, csh, tcsh, ash, dash, ksh, pdksh, zsh, rc y es

No olvides iniciar sesión de nuevo o hacer un `source` de tus archivos de inicio de sesión para que surta efecto.

OPCIONES

-check
Comprueba si el código de configuración de surfraw está presente. Esta es la opción predeterminada.
-add
Agrega el código de configuración de surfraw.
-remove
Elimina el código de configuración de surfraw
-sys
Actualiza la configuración del shell a nivel de sistema en lugar de la del usuario. Debe ejecutarse como root.
-shell=SHELL
Selecciona el shell a configurar. Por defecto, toma el valor de la variable de entorno $SHELL.

Los shells actualmente soportados son:

sh, ash, bash, dash, csh, tcsh, ksh, pdksh, zsh, rc y es.

-all
Intenta configurar los archivos de inicio para todos los shells conocidos
-help
Muestra un mensaje de uso

VALOR DE RETORNO

-check devuelve 0 si el código de surfraw está presente en el archivo, 1 si no se encuentra, o 2 si hay un error.

Todas las demás opciones devuelven 0 en caso de éxito, o 2 en caso de error.

ENTORNO

SHELL
Se utiliza para determinar qué shell configurar, si no se proporciona -shell.
HOME
Se utiliza para encontrar los archivos de configuración del usuario.
ENV
Utilizado por shells compatibles con POSIX para especificar un archivo de inicio rc.
ZDOTDIR
Se utiliza para encontrar los archivos de configuración del usuario para zsh. Si no está establecido, por defecto es HOME.

VER TAMBIÉN

surfraw(1), sh(1), ash(1), bash(1), dash(1), csh(1), tcsh(1), ksh(1), pdksh(1), zsh(1), rc(1), es(1)
