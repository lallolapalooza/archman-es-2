SU(1) sudo-rs SU(1)

NOMBRE

su - ejecutar un shell o comando como otro usuario

SINOPSIS

su opciones [-] [<usuario> [<argumento>...]]

OPCIONES

-c comando, --command=comando
Pasa un solo comando al shell con -c.
-g grupo, --group=grupo
Especifica el grupo primario
-G grupo, --supp-group=grupo
Especifica un grupo suplementario
-h, --help
Muestra un mensaje de ayuda.
-, -l, --login
Convierte el shell en un shell de inicio de sesión
-m, -p, --preserve-environment
No restablecer las variables de entorno
-P, --pty
Crea una nueva pseudo-terminal al ejecutar el shell.
-w lista, --whitelist-environment=lista
No restablecer las variables de entorno especificadas por la lista. Se pueden separar múltiples variables por comas.
-s shell, --shell=shell
Ejecuta shell si /etc/shells permite la ejecución como ese shell en lugar del shell predeterminado para el usuario.
-V, --version
Muestra la versión del programa.
