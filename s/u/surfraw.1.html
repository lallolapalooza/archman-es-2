SURFRAW(1) Manual de Comandos Generales SURFRAW(1)

NOMBRE

surfraw - una interfaz de línea de comandos rápida de Unix para servicios de la WWW

SINOPSIS

surfraw nombre_elvi [opciones] palabras_de_búsqueda ...
sr nombre_elvi [opciones] palabras_de_búsqueda ...
sr -elvi
sr [opciones] marcador [palabras_de_búsqueda]

DESCRIPCIÓN

Surfraw proporciona una interfaz de línea de comandos rápida de Unix a una variedad de motores de búsqueda populares de la WWW y otros artefactos de poder. Recupera google, altavista, deja news, freshmeat, research index, slashdot y muchos otros de las tierras paganas infestadas de pox, de formularios html, colocando estas maravillas donde pertenecen, en el corazón del sistema Unix, como extensiones de shell que aman a Dios.

Surfraw consiste en una colección de elvi, cada uno de los cuales sabe cómo buscar en un sitio web específico. Para ver la lista de elvi, escriba:


surfraw -elvi

Tenga en cuenta que sr es un alias de surfraw, por lo que podría ser igualmente:


sr -elvi

Para buscar usando un elvi, use:


sr nombre_elvi [opciones] términos_de_búsqueda..

Por ejemplo, para buscar en Google información sobre puertos de Debian, usando la opción "Me siento afortunado":


sr google -l puertos de debian

Añadir los elvi a tu ruta de comandos

Si usas surfraw con regularidad, probablemente te cansarás de escribir sr o surfraw cada vez. Puedes recuperar el comportamiento anterior de ejecutar los elvi directamente agregando el directorio de elvi (/usr/lib/surfraw) a tu ruta de comandos, ya sea manualmente o usando surfraw-update-path(1).

Marcadores

Surfraw soporta marcadores. Para añadir un marcador, añádelo a /etc/xdg/surfraw/bookmarks o $HOME/.config/surfraw/bookmarks

El formato del archivo de marcadores es simple, cada marcador está en una línea separada, con el marcador y la URL separados por espacios en blanco, por ejemplo:


ntk http://www.ntk.net/

Si la URL contiene la cadena %s, puedes especificar un argumento opcional para el marcador. Sin argumento, solo se devolverá el dominio. Con argumentos, %s será reemplazado por los argumentos. Esto evita la necesidad de crear elvi para sitios con opciones de búsqueda muy simples.

Para invocar un marcador, usa "surfraw bookmark" o "sr bookmark", y si no existe un elvi de ese nombre, buscará un marcador de ese nombre en su lugar.

Hay algunos marcadores de ejemplo en /etc/xdg/surfraw/bookmarks

OPCIONES

Usa sr nombre_elvi -local-help para ver las opciones específicas del elvi.

Las siguientes opciones funcionan con todos los elvi.

-help
Muestra un resumen de las opciones (incluyendo las opciones específicas del elvi).
-local-help
Muestra las opciones específicas del elvi.
-version
Muestra la versión del programa.
-navegador=EJECUTABLE
Establece el navegador (por defecto: sensible-browser).
-elvi
Muestra una lista de otros mecanismos de Surfraw para conquistar el mal.
-escapar-url-args=sí|no
Aplica el escape de URL a los argumentos (por defecto: sí)
-q|-comillas
Encierra todos los argumentos entre comillas ("") (por defecto: no). Ten en cuenta que ahora puedes poner comillas alrededor de los argumentos, por lo que puedes hacer, por ejemplo:


sr google foo "bar baz" bam

y las comillas se pasan al motor de búsqueda.

EJEMPLOS


$ sr preguntar por qué jeeves es gay?
$ surfraw google -resultados=100 RMS, GNU, ¿cuál es el pecador, cuál es el pecado?
$ sr austlii -metodo=frase perro gusta
$ /usr/lib/surfraw/rhyme -metodo=perfecto Julian

CONFIGURACIÓN

Surfraw utiliza la especificación XDG basedir (http://standards.freedesktop.org/basedir-spec/basedir-spec-0.6.html) para localizar archivos de configuración. Las ubicaciones por defecto se muestran a continuación, pero se pueden modificar estableciendo las variables de entorno $XDG_CONFIG_HOME y $XDG_CONFIG_DIRS. Consulta la especificación para más detalles.

Surfraw obtiene su configuración de tres fuentes, en orden:

1.
Variables de entorno
2.
/etc/xdg/surfraw/conf
3.
$HOME/.config/surfraw/conf

/etc/xdg/surfraw.conf y $HOME/.config/surfraw/conf son fragmentos de scripts de shell al estilo bourne.

/etc/xdg/surfraw.conf debe usar def y defyn para definir variables. Estas funciones establecen variables a menos que ya estén establecidas por el entorno. defyn se usa para variables de configuración booleanas, def para todas las demás. Por ejemplo:


def SURFRAW_text_browser /usr/bin/lynx
defyn SURFRAW_graphical no

$HOME/.config/surfraw/conf debe usar entradas al estilo sh, por ejemplo:


SURFRAW_text_browser=/usr/bin/lynx
SURFRAW_graphical=no

Esto se debe a que quieres que anulen las variables de entorno incondicionalmente.

VARIABLES DE CONFIGURACIÓN

SURFRAW_global_conf
Ubicación del archivo de configuración global.

Por defecto:


def SURFRAW_global_conf /etc/xdg/surfraw/conf

SURFRAW_conf
Ubicación del archivo de configuración por usuario.

Por defecto:


def SURFRAW_conf $HOME/.config/surfraw/conf

SURFRAW_graphical
Si se debe usar un navegador gráfico.

Por defecto:

defyn SURFRAW_graphical no

SURFRAW_text_browser
Nombre/ruta del ejecutable del navegador de texto. ej. links, lynx, w3m

Por defecto:

def SURFRAW_text_browser sensible-browser

SURFRAW_graphical_browser
Nombre/ruta del ejecutable del navegador gráfico. ej. mozilla, netscape etc.

Por defecto:


def SURFRAW_graphical_browser sensible-browser

SURFRAW_text_browser_args
Argumentos del navegador de texto, o "none".

Por defecto:


def SURFRAW_text_browser_args none

SURFRAW_graphical_browser_args
Argumentos del navegador gráfico, o "none".

Por defecto:


def SURFRAW_graphical_browser_args none

SURFRAW_graphical_remote
Si se debe usar "-remote openURL" para el navegador gráfico.

Por defecto:


defyn SURFRAW_graphical_remote yes

SURFRAW_new_window
Cuando se usa SURFRAW_graphical_remote, ¿abrir una nueva ventana?

Por defecto:


defyn SURFRAW_new_window no
