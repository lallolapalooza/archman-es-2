NOMBRE

suexec - Cambia de usuario antes de ejecutar programas externos

SINOPSIS

suexec -V

RESUMEN

suexec es utilizado por el servidor HTTP Apache para cambiar a otro usuario antes de ejecutar programas CGI. Para lograr esto, debe ejecutarse como root. Dado que el demonio HTTP normalmente no se ejecuta como root, el ejecutable suexec necesita tener el bit setuid establecido y debe ser propiedad de root. Nunca debe ser escribible por ninguna otra persona que no sea root.

Para más información sobre los conceptos y el modelo de seguridad de suexec, consulte la documentación de suexec (http://httpd.apache.org/docs/2.4/suexec.html).

OPCIONES

-V
Si usted es root, esta opción muestra las opciones de compilación de suexec. Por razones de seguridad, todas las opciones de configuración son modificables solo en tiempo de compilación.
