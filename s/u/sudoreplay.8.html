SUDOREPLAY(8) Manual del Administrador del Sistema SUDOREPLAY(8)

NOMBRE

sudoreplay — reproduce registros de sesiones de sudo

SINOPSIS

sudoreplay [-FhnRS] [-d directorio] [-f filtro] [-m num] [-s num] ID[@desplazamiento]

sudoreplay [-h] [-d directorio] -l [expresión de búsqueda]

DESCRIPCIÓN

sudoreplay reproduce o lista los registros de salida creados por sudo. Al reproducir, sudoreplay puede reproducir la sesión en tiempo real, o la velocidad de reproducción puede ajustarse (más rápido o más lento) según las opciones de línea de comandos.

El ID debe ser una secuencia de seis caracteres de dígitos y letras mayúsculas, por ejemplo, “0100A5”, o un nombre de ruta. El ID puede incluir un sufijo opcional @desplazamiento que se puede usar para comenzar la reproducción en un desplazamiento de tiempo específico. El @desplazamiento se especifica como un número en segundos desde el inicio de la sesión con una fracción decimal opcional.

Los nombres de ruta pueden ser relativos al directorio de registro de E/S /var/log/sudo-io (a menos que se anule con la opción -d) o completamente calificados, comenzando con un carácter ‘/’. Cuando un comando se ejecuta a través de sudo con salida_registro habilitada en el archivo sudoers, una cadena “TSID=ID” se registra a través de syslog(3) o en el archivo de registro de sudo. El ID también se puede determinar utilizando el modo de lista de sudoreplay.

En modo de lista, sudoreplay se puede usar para encontrar el ID de una sesión según varios criterios como el usuario, tty o el comando ejecutado.

En modo de reproducción, si la entrada y salida estándar están conectadas a un terminal y la opción -n no está especificada, sudoreplay operará de forma interactiva. En modo interactivo, sudoreplay intentará ajustar el tamaño del terminal para que coincida con el de la sesión y escribirá directamente en el terminal (no todos los terminales soportan esto). Además, sondeará el teclado y actuará sobre las siguientes teclas:

‘\n’ o ‘\r’
Saltar al siguiente evento de reproducción; útil para pausas largas.
‘ ’ (espacio)
Pausar la salida; presiona cualquier tecla para reanudar.
‘<’
Reducir la velocidad de reproducción a la mitad.
‘>’
Duplicar la velocidad de reproducción.

La sesión se puede interrumpir con control-C. Cuando la sesión haya finalizado, el terminal se restaurará a su tamaño original si se modificó durante la reproducción.

Las opciones son las siguientes:

-d directorio, --directorio=directorio
Almacena los registros de sesión en directorio en lugar del predeterminado, /var/log/sudo-io.
-f filtro, --filtro=filtro
Selecciona qué tipo(s) de E/S mostrar. Por defecto, sudoreplay mostrará la salida estándar, el error estándar y la salida del tty del comando. El argumento filtro es una lista separada por comas, que consta de uno o más de los siguientes: stdin, stdout, stderr, ttyin, y ttyout.
-F, --seguir
Habilita el modo “seguir”. Al reproducir una sesión, sudoreplay ignorará el fin de archivo y continuará reproduciendo hasta que el registro esté completo. Esto se puede usar para reproducir una sesión que aún está en curso, similar a “tail -f”. Un archivo de registro de E/S se considera completo cuando los bits de escritura se han eliminado del archivo de temporización de la sesión. Las versiones de sudo anteriores a la 1.9.1 no eliminan los bits de escritura al finalizar.
-h, --ayuda
Muestra un breve mensaje de ayuda en la salida estándar y sale.
-l, --listar [expresión de búsqueda]
Habilita el modo “listar”. En este modo, sudoreplay listará las sesiones disponibles en un formato similar al formato del archivo de registro de sudo, ordenado por nombre de archivo (o número de secuencia). Cualquier carácter de control presente en los datos del registro se formatea en octal con un carácter ‘#’ delante. Por ejemplo, una tabulación horizontal se muestra como ‘#011’ y un retorno de carro incrustado se muestra como ‘#015’. Los caracteres de espacio en el nombre del comando y sus argumentos también se formatean en octal.

Si se especifica una expresión de búsqueda, se utilizará para restringir los ID que se muestran. Una expresión se compone de los siguientes predicados:

comando patrón
Se evalúa como verdadero si el comando ejecutado coincide con la expresión regular extendida POSIX patrón.
cwd directorio
Se evalúa como verdadero si el comando se ejecutó con el directorio de trabajo actual especificado.
desdedate fecha
Se evalúa como verdadero si el comando se ejecutó en o después de la fecha. Ver Formato de fecha y hora para una descripción de los formatos de fecha y hora admitidos.
grupo grupo_de_ejecución
Se evalúa como verdadero si el comando se ejecutó con el grupo_de_ejecución especificado. A menos que se especificara explícitamente un grupo_de_ejecución cuando se ejecutó sudo, este campo estará vacío en el registro.
host nombre_host
Se evalúa como verdadero si el comando se ejecutó en el nombre_host especificado.
runas usuario_de_ejecución
Se evalúa como verdadero si el comando se ejecutó como el usuario_de_ejecución especificado. Por defecto, sudo ejecuta comandos como el usuario root.
hastadate fecha
Se evalúa como verdadero si el comando se ejecutó en o antes de la fecha. Ver Formato de fecha y hora para una descripción de los formatos de fecha y hora admitidos.
tty nombre_tty
Se evalúa como verdadero si el comando se ejecutó en el dispositivo de terminal especificado. El nombre_tty debe especificarse sin el prefijo /dev/, por ejemplo, tty01 en lugar de /dev/tty01.
usuario nombre_usuario
Se evalúa como verdadero si el ID coincide con un comando ejecutado por nombre_usuario.

Los predicados pueden abreviarse a la cadena única más corta.

Los predicados se pueden combinar usando los operadores and, or y ! así como los paréntesis ‘(’ y ‘)’ para agrupar expresiones. El operador and tiene la precedencia más alta, seguido de or y luego !.

Por ejemplo, para buscar sesiones ejecutadas por el usuario “root” entre las 10:00 AM y las 11:00 AM, usaría:

sudoreplay -l 'user root and fromdate 10:00 todate 11:00'

Para listar todas las sesiones ejecutadas en un tty:

sudoreplay -l tty

-m num, --maxlen=num
Muestra hasta num bytes de datos de salida para cada evento de entrada/salida. Por defecto, se muestra toda la salida.
-n, --nonblock
No bloquear. Si el terminal no admite reproducción interactiva, sudoreplay saldrá en lugar de intentar reproducir interactivamente.
-R, --readahead
Habilita el modo “readahead”. Esto hace que sudoreplay lea la sesión completa de E/S en memoria antes de reproducirla. Esto puede ser útil para sesiones que involucran muchos datos de entrada/salida que de otra manera podrían hacer que la reproducción sea entrecortada.
-s num, --speed=num
Establece la velocidad de reproducción en num. El valor predeterminado es 1. Por ejemplo, un valor de 2 hará que la sesión se reproduzca el doble de rápido, mientras que un valor de 0.5 la hará la mitad de rápido.

FECHA Y HORA

Las fechas se pueden especificar en el siguiente formato: MMDDhhmm[[CC]YY][.ss], donde:

MM
Mes (01-12)
DD
Día del mes (01-31)
hh
Hora (00-23)
mm
Minuto (00-59)
CC
Siglo (por ejemplo, 20)
YY
Año (00-99)
ss
Segundo (00-59)

Esto es similar al formato utilizado por el comando touch. Las fechas se pueden especificar con signo (por ejemplo, +5 minutos, -1 hora, next\ Monday).

VER TAMBIÉN

sudo(8), sudoers(5)

sudoreplay — Reproduce una sesión de sudo enregistrada

NOMBRE

sudoreplay — Reproduce una sesión de sudo enregistrada

SINOPSIS

sudoreplay [-a] [-l] [-q] [-d timestamp_file] [-s session_dir] [timestamp_file]

DESCRIPCIÓN

sudoreplay reproduce una sesión enregistrada por sudo con la opción -l activada. Las sesiones s'enregistrent dans le répertoire spécifié par la variable d'environnement SUDO_SESSION_DATA_DIR ou, par défaut, dans ~/.sudo_session.

Se utiliza un fichier d'horodatage pour spécifier la session à lire. Ce fichier est généralement créé par sudoedit lorsque la commande est exécutée avec l'option -l.

FICHEROS

/etc/sudoers
Archivo de configuración principal de sudo.
~/.sudo_session
Directorio por defecto para almacenar las sesiones enregistrées.

EJEMPLOS

Pour reproduire une session enregistrée dans le fichier /var/log/sessions/2023-10-27T10:00:00.log :

sudoreplay /var/log/sessions/2023-10-27T10:00:00.log

sudo(8), sudoedit(8), sudoers(5)
