NOMBRE

subscriptions.conf - archivo de configuración de suscripción para cups

DESCRIPCIÓN

El archivo subscriptions.conf define las suscripciones locales de notificación de eventos que están activas. Normalmente se encuentra en el directorio /etc/cups y es mantenido por el programa cupsd(8). Este archivo no está pensado para ser editado o gestionado manualmente.

NOTAS

El nombre, la ubicación y el formato de este archivo son un detalle de implementación que cambiará en futuras versiones de CUPS.
