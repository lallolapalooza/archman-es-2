NOMBRE

subuid - la configuración de los IDs de usuario subordinados

DESCRIPCIÓN

Subuid autoriza a un ID de usuario a mapear rangos de IDs de usuario desde su espacio de nombres a espacios de nombres hijos.

La delegación de los uids subordinados puede configurarse a través del campo subid en el archivo /etc/nsswitch.conf. Solo un valor puede ser establecido como fuente de delegación. Establecer este campo en files configura la delegación de uids a /etc/subuid. Establecer cualquier otro valor trata la delegación como un plugin con un nombre de la forma libsubid_$valor.so. Si el valor o el plugin faltan, la delegación subordinada de uid vuelve a files.

Tenga en cuenta que newusers, useradd y usermod solo crearán entradas en /etc/subuid si la delegación de subid se gestiona a través de archivos de subid.

DELEGACIÓN LOCAL DE SUBORDINADOS

Cada línea en /etc/subuid contiene un nombre de usuario y un rango de IDs de usuario subordinados que ese usuario puede usar. Esto se especifica con tres campos delimitados por dos puntos (“:”). Estos campos son:

•nombre de inicio de sesión o UID
•ID de usuario subordinado numérico
•conteo numérico del ID de usuario subordinado

Este archivo especifica los IDs de usuario que los usuarios ordinarios pueden usar, con el comando newuidmap, para configurar el mapeo de uid en un espacio de nombres de usuario.

Se pueden especificar múltiples rangos por usuario.

Cuando se definen un gran número de entradas (10000-100000 o más) en /etc/subuid, la penalización de rendimiento del análisis se volverá notable. En este caso, se recomienda usar UIDs en lugar de nombres de inicio de sesión. Las pruebas comparativas han mostrado mejoras de hasta 20 veces.

ARCHIVOS

/etc/subuid

IDs de usuario subordinados por usuario.

/etc/subuid-

Archivo de copia de seguridad para /etc/subuid.
