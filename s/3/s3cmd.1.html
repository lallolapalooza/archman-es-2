s3cmd(1) Manual de comandos generales s3cmd(1)

NOMBRE

s3cmd - herramienta para gestionar el espacio de almacenamiento de Amazon S3 y la red de entrega de contenido Amazon CloudFront

SINOPSIS

s3cmd [OPCIONES] COMANDO [PARÁMETROS]

DESCRIPCIÓN

s3cmd es un cliente de línea de comandos para copiar archivos hacia/desde Amazon S3 (Simple Storage Service) y realizar otras tareas relacionadas, como crear y eliminar buckets, listar objetos, etc.

COMANDOS

s3cmd puede realizar varias acciones especificadas por los siguientes comandos.

s3cmd mb s3://BUCKET
Crear bucket
s3cmd rb s3://BUCKET
Eliminar bucket
s3cmd ls [s3://BUCKET[/PREFIJO]]
Listar objetos o buckets
s3cmd la
Listar todos los objetos en todos los buckets
s3cmd put ARCHIVO [ARCHIVO...] s3://BUCKET[/PREFIJO]
Poner archivo en bucket
s3cmd get s3://BUCKET/OBJETO ARCHIVO_LOCAL
Obtener archivo del bucket
s3cmd del s3://BUCKET/OBJETO
Eliminar archivo del bucket
s3cmd rm s3://BUCKET/OBJETO
Eliminar archivo del bucket (alias de del)
s3cmd restore s3://BUCKET/OBJETO
Restaurar archivo desde almacenamiento Glacier
s3cmd sync DIRECTORIO_LOCAL s3://BUCKET[/PREFIJO] o s3://BUCKET[/PREFIJO] DIRECTORIO_LOCAL o s3://BUCKET[/PREFIJO] s3://BUCKET[/PREFIJO]
Sincronizar un árbol de directorios a S3 (comprueba la frescura de los archivos utilizando el tamaño y la suma de verificación md5, a menos que se anule mediante opciones, véase más abajo)
s3cmd du [s3://BUCKET[/PREFIJO]]
Uso del disco por buckets
s3cmd info s3://BUCKET[/OBJETO]
Obtener diversa información sobre Buckets o Archivos
s3cmd cp s3://BUCKET1/OBJETO1 s3://BUCKET2[/OBJETO2]
Copiar objeto
s3cmd modify s3://BUCKET1/OBJETO
Modificar metadatos del objeto
s3cmd mv s3://BUCKET1/OBJETO1 s3://BUCKET2[/OBJETO2]
Mover objeto
s3cmd setacl s3://BUCKET[/OBJETO]
Modificar la lista de control de acceso para Bucket o Archivos
s3cmd setversioning s3://BUCKET habilitar|deshabilitar
Modificar el versionado del Bucket
s3cmd setownership s3://BUCKET BucketOwnerPreferred|BucketOwnerEnforced|ObjectWriter
Modificar la propiedad de objetos del Bucket
s3cmd setblockpublicaccess s3://BUCKET BlockPublicAcls,IgnorePublicAcls,BlockPublicPolicy,RestrictPublicBuckets
Modificar las reglas de bloqueo de acceso público
s3cmd setobjectlegalhold ESTADO s3://BUCKET/OBJETO
Modificar la retención legal del objeto
s3cmd setobjectretention MODO FECHA_HASTA_RETENCION s3://BUCKET/OBJETO
Modificar la retención del objeto
s3cmd setpolicy ARCHIVO s3://BUCKET
Modificar la política del Bucket
s3cmd delpolicy s3://BUCKET
Eliminar la política del Bucket
s3cmd setcors ARCHIVO s3://BUCKET
Modificar CORS del Bucket
s3cmd delcors s3://BUCKET
Eliminar CORS del Bucket
s3cmd payer s3://BUCKET
Modificar la política de pago del solicitante del Bucket
s3cmd multipart s3://BUCKET [Id]
Mostrar cargas multipartes
s3cmd abortmp s3://BUCKET/OBJETO Id
Abortar una carga multipart
s3cmd listmp s3://BUCKET/OBJETO Id
Listar partes de una carga multipart
s3cmd accesslog s3://BUCKET
Habilitar/deshabilitar el registro de acceso al bucket
s3cmd sign CADENA-A-FIRMAR
Firmar una cadena arbitraria usando la clave secreta
s3cmd signurl s3://BUCKET/OBJETO <epoch_expiración|+offset_expiración>
Firmar una URL de S3 para proporcionar acceso público limitado con expiración
s3cmd fixbucket s3://BUCKET[/PREFIJO]
Corregir nombres de archivo inválidos en un bucket
s3cmd settagging s3://BUCKET[/OBJETO] "CLAVE=VALOR[&CLAVE=VALOR ...]"
Modificar el etiquetado para Bucket o Archivos
s3cmd gettagging s3://BUCKET[/OBJETO]
Obtener el etiquetado para Bucket o Archivos
s3cmd deltagging s3://BUCKET[/OBJETO]
Eliminar el etiquetado para Bucket o Archivos
s3cmd expire s3://BUCKET
Establecer o eliminar la regla de expiración para el bucket
s3cmd setlifecycle ARCHIVO s3://BUCKET
Subir una política de ciclo de vida para el bucket
s3cmd getlifecycle s3://BUCKET
Obtener una política de ciclo de vida para el bucket
s3cmd dellifecycle s3://BUCKET
Eliminar una política de ciclo de vida para el bucket
s3cmd setnotification ARCHIVO s3://BUCKET
Subir una política de notificación para el bucket
s3cmd getnotification s3://BUCKET
Obtener una política de notificación para el bucket
s3cmd delnotification s3://BUCKET
Eliminar una política de notificación para el bucket

Comandos para la configuración de sitios web estáticos

s3cmd ws-create s3://BUCKET
Crear sitio web desde el bucket
s3cmd ws-delete s3://BUCKET
Eliminar sitio web
s3cmd ws-info s3://BUCKET
Información sobre el sitio web

Comandos para la gestión de CloudFront

s3cmd cflist
Listar puntos de distribución de CloudFront
s3cmd cfinfo [cf://ID_DIST]
Mostrar parámetros del punto de distribución de CloudFront
s3cmd cfcreate s3://BUCKET
Crear punto de distribución de CloudFront
s3cmd cfdelete cf://ID_DIST
Eliminar punto de distribución de CloudFront
s3cmd cfmodify cf://ID_DIST
Cambiar parámetros del punto de distribución de CloudFront
s3cmd cfinval s3://BUCKET/OBJETO [s3://BUCKET/
Invalidar objeto en CloudFront

EJEMPLOS

Uno de los comandos más potentes de s3cmd es s3cmd sync utilizado para sincronizar árboles de directorios completos hacia o desde el almacenamiento remoto S3. Hasta cierto punto s3cmd put y s3cmd get comparten un comportamiento similar con sync.

El uso básico común en escenarios de copia de seguridad es tan simple como:

s3cmd sync /ruta/local/ s3://cubo-prueba/copia_seguridad/

Este comando encontrará todos los archivos bajo el directorio /ruta/local/ y los copiará a las rutas correspondientes bajo s3://cubo-prueba/copia_seguridad/ en el lado remoto. Por ejemplo:

/ruta/local/archivo1.ext         ->  s3://cubo/copia_seguridad/archivo1.ext
/ruta/local/dir123/archivo2.bin  ->  s3://cubo/copia_seguridad/dir123/archivo2.bin

Sin embargo, si la ruta local no termina con una barra, el nombre del último directorio se utiliza también en el lado remoto. Compare esto con el ejemplo anterior:

s3cmd sync /ruta/local s3://cubo-prueba/copia_seguridad/
sincronizará: 
/local/ruta/archivo1.ext         ->  s3://cubo/copia_seguridad/ruta/archivo1.ext
/local/ruta/dir123/archivo2.bin  ->  s3://cubo/copia_seguridad/ruta/dir123/archivo2.bin

Para recuperar los archivos de S3, use la sintaxis invertida:

s3cmd sync s3://cubo-prueba/copia_seguridad/ ~/restaurar/
lo que descargará los archivos como: 
s3://cubo/copia_seguridad/archivo1.ext         ->  ~/restaurar/archivo1.ext
s3://cubo/copia_seguridad/dir123/archivo2.bin  ->  ~/restaurar/dir123/archivo2.bin

Sin la barra final en la fuente, el comportamiento es similar a lo que se ha demostrado con la carga:

s3cmd sync s3://cubo-prueba/copia_seguridad ~/restaurar/
descargará los archivos como: 
s3://cubo/copia_seguridad/archivo1.ext         ->  ~/restaurar/copia_seguridad/archivo1.ext
s3://cubo/copia_seguridad/dir123/archivo2.bin  ->  ~/restaurar/copia_seguridad/dir123/archivo2.bin

Todos los nombres de archivo de origen, los que están en negrita arriba, se comparan con las reglas exclude y luego se vuelven a verificar contra las reglas include para ver si deben ser excluidos o mantenidos en la lista de origen.

A efectos de la comparación --exclude y --include, solo se utilizan los nombres de archivo en negrita anteriores. Por ejemplo, solo se prueba ruta/archivo1.ext contra los patrones, no /local/ruta/archivo1.ext

Tanto --exclude como --include funcionan con comodines de estilo shell (también conocidos como GLOB). Para una mayor flexibilidad, s3cmd proporciona versiones de expresiones regulares de los

Hay dos opciones de exclusión llamadas `--rexclude` y `--rinclude`. Las opciones con el sufijo `...-from` (por ejemplo, `--rinclude-from`) esperan un nombre de archivo como argumento. Cada línea de dicho archivo se trata como un patrón.

Solo hay un conjunto de patrones construido a partir de todas las opciones `--(r)exclude(-from)` y de forma similar para la variante include. Cualquier archivo excluido con, por ejemplo, `--exclude` puede ser reintroducido con un patrón encontrado en la lista `--rinclude-from`.

Ejecuta s3cmd con `--dry-run` para verificar que tus reglas funcionan como se espera. Úsalo junto con `--debug` para obtener información detallada sobre la coincidencia de nombres de archivo con las reglas de exclusión e inclusión.

Por ejemplo, para excluir todos los archivos con la extensión ".jpg" excepto aquellos que comienzan con un número, usa:

`--exclude '*.jpg' --rinclude '[0-9].*.jpg'`

Para excluir todos los archivos excepto los de extensión "*.jpg", usa:

`--exclude '*' --include '*.jpg'`

Para excluir el directorio local 'somedir', asegúrate de usar una barra diagonal inclinada final, así:

`--exclude 'somedir/'`
