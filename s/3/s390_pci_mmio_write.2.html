s390_pci_mmio_write(2) Manual de llamadas al sistema s390_pci_mmio_write(2)

NOMBRE

s390_pci_mmio_write, s390_pci_mmio_read - transferir datos a/desde página de memoria MMIO PCI

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/syscall.h>      /* Definición de constantes SYS_* */
#include <unistd.h>
int syscall(size_t longitud;
            SYS_s390_pci_mmio_write, unsigned long dirección_mmio,
            const void buffer_usuario[longitud], size_t longitud);
int syscall(size_t longitud;
            SYS_s390_pci_mmio_read, unsigned long dirección_mmio,
            void buffer_usuario[longitud], size_t longitud);

Nota: glibc no proporciona envolturas para estas llamadas al sistema, lo que hace necesario el uso de syscall(2).

DESCRIPCIÓN

La llamada al sistema s390_pci_mmio_write() escribe longitud bytes de datos del búfer de espacio de usuario buffer_usuario a la ubicación de memoria MMIO PCI especificada por dirección_mmio. La llamada al sistema s390_pci_mmio_read() lee longitud bytes de datos de la ubicación de memoria MMIO PCI especificada por dirección_mmio al búfer de espacio de usuario buffer_usuario.

Estas llamadas al sistema deben usarse en lugar de la simple asignación o las operaciones de transferencia de datos que se utilizan para acceder a las áreas de memoria MMIO PCI mapeadas al espacio de usuario en la plataforma Linux System z. La dirección especificada por dirección_mmio debe pertenecer a un mapeo de página de memoria MMIO PCI en el espacio de direcciones del llamador, y los datos que se escriben o leen no deben cruzar un límite de página. El valor de longitud no puede ser mayor que el tamaño de página del sistema.

VALOR DE RETORNO

En caso de éxito, s390_pci_mmio_write() y s390_pci_mmio_read() devuelven 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
La dirección en dirección_mmio es inválida.
EFAULT
buffer_usuario no apunta a una ubicación válida en el espacio de direcciones del llamador.
EINVAL
Argumento longitud inválido.
ENODEV
El soporte PCI no está habilitado.
ENOMEM
Memoria insuficiente.

ESTÁNDARES

Linux en s390.

HISTORIA

Linux 3.19. System z EC12.
