s390_sthyi(2) Manual de llamadas al sistema s390_sthyi(2)

NOMBRE

s390_sthyi - emular la instrucción STHYI

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/sthyi.h>        /* Definición de constantes STHYI_* */
#include <sys/syscall.h>      /* Definición de constantes SYS_* */
#include <unistd.h>
int syscall(SYS_s390_sthyi, unsigned long codigo_funcion,
            void *buffer_respuesta, uint64_t *codigo_retorno,
            unsigned long flags);

Nota: glibc no proporciona un envoltorio para s390_sthyi(), lo que hace necesario el uso de syscall(2).

DESCRIPCIÓN

La llamada al sistema s390_sthyi() emula la instrucción STHYI (Store Hypervisor Information). Proporciona información de recursos de hardware para la máquina y sus niveles de virtualización. Esto incluye el tipo y la capacidad de la CPU, así como el modelo de la máquina y otras métricas.

El argumento codigo_funcion indica qué función realizar. Los siguientes códigos son compatibles:

STHYI_FC_CP_IFL_CAP
Devolver información de capacidad de CP (Procesador Central) e IFL (Integrated Facility for Linux).

El argumento buffer_respuesta especifica la dirección de un buffer de respuesta. Cuando el codigo_funcion es STHYI_FC_CP_IFL_CAP, el buffer debe tener el tamaño de una página (4K). Si la llamada al sistema devuelve 0, el buffer de respuesta se llenará con información de capacidad de CPU. De lo contrario, el contenido del buffer de respuesta no cambia.

El argumento codigo_retorno almacena el código de retorno de la instrucción STHYI, utilizando uno de los siguientes valores:

0
Éxito.
4
Código de función no admitido.

Para más detalles sobre codigo_retorno, codigo_funcion y buffer_respuesta, consulte la referencia en NOTAS.

El argumento flags se proporciona para permitir futuras extensiones y actualmente debe establecerse en 0.

VALOR DE RETORNO

En caso de éxito (es decir: la emulación fue exitosa), el valor de retorno de s390_sthyi() coincide con el código de condición de las instrucciones STHYI, que es un valor en el rango [0..3]. Un valor de retorno de 0 indica que la información de capacidad de la CPU está almacenada en *buffer_respuesta. Un valor de retorno de 3 indica "código de función no admitido" y el contenido de *buffer_respuesta no cambia. Los valores de retorno 1 y 2 están reservados.

En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EFAULT
El valor especificado en buffer_respuesta o codigo_retorno no es una dirección válida.
EINVAL
El valor especificado en flags no es cero.
ENOMEM
Falló la asignación de memoria para el manejo de la información de capacidad de CPU.
EOPNOTSUPP
El valor especificado en codigo_funcion no es válido.

ESTÁNDARES

Linux en s390.

HISTORIA

Linux 4.15.

NOTAS

Para detalles de la instrucción STHYI, consulte la página de documentación.

Cuando se utiliza la interfaz de llamada al sistema, el buffer de respuesta no tiene que cumplir los requisitos de alineación descritos en la definición de la instrucción STHYI.

El kernel almacena en caché la respuesta (hasta un segundo, a partir de Linux 4.16). Las invocaciones posteriores de llamada al sistema pueden devolver la respuesta almacenada en caché.
