s390_runtime_instr(2) Manual de Llamadas al Sistema s390_runtime_instr(2)

NOMBRE

s390_runtime_instr - habilitar/deshabilitar la instrumentación en tiempo de ejecución de la CPU s390

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/runtime_instr.h> /* Definición de constantes S390_* */
#include <sys/syscall.h>       /* Definición de constantes SYS_* */
#include <unistd.h>
int syscall(SYS_s390_runtime_instr, int comando, int signum);

Nota: glibc no proporciona un envoltorio para s390_runtime_instr(), lo que requiere el uso de syscall(2).

DESCRIPCIÓN

La llamada al sistema s390_runtime_instr() inicia o detiene la instrumentación en tiempo de ejecución de la CPU para el hilo que la llama.

El argumento comando controla si la instrumentación en tiempo de ejecución se inicia (S390_RUNTIME_INSTR_START, 1) o se detiene (S390_RUNTIME_INSTR_STOP, 2) para el hilo que la llama.

El argumento signum especifica el número de una señal en tiempo real. Este argumento se utilizaba para especificar un número de señal que debía entregarse al hilo si el búfer de instrumentación en tiempo de ejecución estaba lleno o si se había producido la interrupción de instrumentación en tiempo de ejecución detenida. Esta característica nunca se utilizó y, en Linux 4.4, se eliminó el soporte para esta característica; por lo tanto, en los kernels actuales, este argumento se ignora.

VALOR DE RETORNO

Si la operación se realiza correctamente, s390_runtime_instr() devuelve 0 y habilita el hilo para la instrumentación en tiempo de ejecución asignándole un bloque de control de instrumentación en tiempo de ejecución predeterminado. A continuación, el llamador puede leer y modificar el bloque de control e iniciar la instrumentación en tiempo de ejecución. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
El valor especificado en comando no es un comando válido.
EINVAL
El valor especificado en signum no es un número de señal en tiempo real. A partir de Linux 4.4, el argumento signum no tiene efecto, por lo que un número de señal no válido no resultará en un error.
ENOMEM
Falló la asignación de memoria para el bloque de control de instrumentación en tiempo de ejecución.
EOPNOTSUPP
La instalación de instrumentación en tiempo de ejecución no está disponible.

ESTÁNDARES

Linux en s390.

HISTORIA

Linux 3.7. System z EC12.

NOTAS

El archivo de cabecera asm/runtime_instr.h está disponible desde Linux 4.16.

A partir de Linux 4.4, se eliminó el soporte para la señalización, así como la comprobación de si signum es una señal en tiempo real válida. Para mantener la compatibilidad con kernels anteriores, se recomienda pasar un número de señal en tiempo real válido en signum e instalar un manejador para esa señal.

VER TAMBIÉN

syscall(2), signal(7)
