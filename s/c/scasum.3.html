real function scasum (integer n, complex, dimension(*) cx, integer incx)

SCASUM

Propósito:

!>
!>    SCASUM toma la suma de los (|Re(.)| + |Im(.)|) de un vector complejo y
!>    devuelve un resultado de precisión simple.
!>

Parámetros

N 
!>          N es ENTERO
!>         número de elementos en el(los) vector(es) de entrada
!>

CX

!>          CX es un arreglo COMPLEJO, dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX es ENTERO
!>         espaciado de almacenamiento entre elementos de SX
!>
