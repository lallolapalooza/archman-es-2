NOMBRE

sctp_send - Envía un mensaje desde un socket SCTP.

SINOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_send(int sd, const void * msg, size_t len,
                 const struct sctp_sndrcvinfo *sinfo,
                 uint32_t flags);

DESCRIPCIÓN

sctp_send es una función de la biblioteca de envoltura que puede ser utilizada para enviar un mensaje desde un socket sin el uso de las estructuras de cabecera CMSG. sd es el descriptor del socket desde el cual se envía el mensaje apuntado por msg de longitud len. sinfo es un puntero a una estructura sctp_sndrcvinfo. El parámetro flags se compone de un OR a nivel de bits de las banderas que pueden ser pasadas como el tercer argumento de una llamada estándar sendmsg().

VALOR DE RETORNO

En caso de éxito, sctp_sendmsg devuelve el número de bytes enviados o -1 si ocurrió un error.
