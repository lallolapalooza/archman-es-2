SCTP_GETLADDRS(3) Manual del programador de Linux SCTP_GETLADDRS(3)

NOMBRE

sctp_getladdrs - Devuelve todas las direcciones locales enlazadas en un socket.

SINOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_getladdrs(int sd, sctp_assoc_t assoc_id,
                   struct sockaddr **addrs);

void sctp_freeladdrs(struct sockaddr *addrs);

DESCRIPCIÓN

sctp_getladdrs devuelve todas las direcciones locales enlazadas en un socket. Al regresar, addrs apuntará a un array empaquetado asignado dinámicamente de estructuras sockaddr del tipo apropiado para cada dirección local. El llamador debe usar sctp_freeladdrs para liberar la memoria. Tenga en cuenta que el parámetro de entrada/salida addrs no debe ser NULL.

Si sd es un socket IPv4, las direcciones devueltas serán todas las direcciones IPv4. Si sd es un socket IPv6, las direcciones devueltas pueden ser una mezcla de direcciones IPv4 o IPv6.

Para sockets de estilo uno-a-muchos, id especifica la asociación a consultar. Para sockets de estilo uno-a-uno, id se ignora.

Si el campo id se establece en 0, entonces se devuelven las direcciones locales enlazadas sin tener en cuenta ninguna asociación particular.

sctp_freeladdrs libera todos los recursos asignados por sctp_getladdrs

VALOR DE RETORNO

En caso de éxito, sctp_getladdrs devuelve el número de direcciones locales enlazadas al socket. Si el socket no está enlazado, se devuelve 0 y el valor de *addrs no está definido. En caso de error, sctp_getladdrs devuelve -1 y el valor de *addrs no está definido.
