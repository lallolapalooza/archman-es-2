NOMBRE

Scratch - Un entorno de programación interactivo fácil de usar para mayores de 8 años.

DESCRIPCIÓN

Scratch es un entorno de programación fácil, interactivo y colaborativo diseñado para la creación de historias interactivas, animaciones, juegos, música y arte, y para compartirlos en la web. Scratch está diseñado para ayudar a los jóvenes (mayores de 8 años) a desarrollar habilidades de aprendizaje del siglo XXI. Mientras crean proyectos de Scratch, los jóvenes aprenden ideas matemáticas y computacionales importantes, al mismo tiempo que obtienen una comprensión más profunda del proceso de diseño. Esta página del manual contiene información básica sobre Scratch. Para obtener información adicional, consulte el sitio web de Scratch en http://scratch.mit.edu.

OPCIONES

Las opciones se establecen a través del archivo .scratch.ini en el directorio de inicio del usuario. Para obtener instrucciones sobre cómo editar este archivo, consulte http://info.scratch.mit.edu/Network_Installation.

ERRORES

Por favor, informe de los errores al mantenedor del paquete. Para obtener la versión más reciente de este paquete, consulte http://info.scratch.mit.edu/Linux_installer

ARCHIVOS

/usr/bin/scratch - script de inicio de scratch
/usr/lib/scratch/ - Contiene Scratch.image (imagen Squeak que contiene código de Scratch) y el archivo scratch.ini
/usr/share/scratch/- Contiene subdirectorios con la biblioteca de medios de Scratch, proyectos de ejemplo y archivos de idioma.
