NOMBRE

schroot-script-config - configuración de scripts de configuración de chroot de schroot

DESCRIPCIÓN

schroot utiliza scripts para configurar y luego limpiar el entorno chroot. Estos scripts pueden personalizarse utilizando la clave script-config en /etc/schroot/schroot.conf. Esta clave especifica un archivo que los scripts de configuración cargarán cuando se ejecuten. El archivo es un script de Bourne shell y, en consecuencia, puede contener cualquier código shell válido, además de asignaciones de variables simples. Esto permitirá, por ejemplo, personalizar el comportamiento según el tipo o nombre específico del chroot.

Este archivo está obsoleto, pero todavía se utiliza si está presente; será obsoleto y eliminado en una futura versión. Todos los ajustes de este archivo ahora se pueden establecer utilizando claves de configuración en schroot.conf, como se detalla a continuación. La configuración existente debe modificarse para utilizar estas claves en lugar de este archivo.

ENTORNO

El entorno es el mismo que para todos los scripts de configuración, descrito en schroot-setup(5).

VARIABLES

Las siguientes variables pueden establecerse para configurar el comportamiento de los scripts de configuración. Tenga en cuenta que pueden agregarse nuevas variables en futuras versiones. Las extensiones de terceros para schroot que agregan sus propios scripts de configuración pueden agregar variables adicionales que no se documentan aquí; consulte la documentación de la extensión para obtener más detalles.

SETUP_COPYFILES
Un archivo que contiene una lista de archivos para copiar al chroot (un archivo por línea). El archivo tendrá la misma ubicación absoluta dentro del chroot. Tenga en cuenta que esto se puede establecer utilizando la clave setup.copyfiles.
SETUP_FSTAB
El archivo de tabla de sistemas de archivos que se utilizará para montar sistemas de archivos dentro del chroot. El formato de este archivo es el mismo que para /etc/fstab, documentado en fstab(5). La única diferencia es que la ruta del punto de montaje fs_dir es relativa al chroot, en lugar de a la raíz. Tenga en cuenta que esto se puede establecer utilizando la clave setup.fstab. Tenga en cuenta también que los puntos de montaje se canonizan en el host, lo que garantizará que los enlaces simbólicos absolutos apunten dentro del chroot, pero las rutas complejas que contienen varios enlaces simbólicos pueden resolverse incorrectamente; se recomienda no utilizar enlaces simbólicos anidados como puntos de montaje.
SETUP_NSSDATABASES
Un archivo que enumera las bases de datos del sistema para copiar al chroot. Las bases de datos predeterminadas son ‘passwd’, ‘shadow’, ‘group’, ‘services’, ‘protocols’, ‘networks’ y ‘hosts’. ‘gshadow’ aún no se copia por defecto, debido a que no es compatible con todas las versiones excepto las más recientes de la biblioteca C de GNU. Las bases de datos se copian utilizando getent(1), por lo que todas las fuentes de bases de datos enumeradas en /etc/nsswitch.conf se utilizarán para cada base de datos. Tenga en cuenta que esto se puede establecer utilizando la clave setup.nssdatabases.
