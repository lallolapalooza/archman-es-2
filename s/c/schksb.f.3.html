DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subroutine schksb (integer nsizes, integer, dimension( * ) nn, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, real, dimension( lda, * ) a, integer lda, real, dimension( * ) sd, real, dimension( * ) se, real, dimension( ldu, * ) u, integer ldu, real, dimension( * ) work, integer lwork, real, dimension( * ) result, integer info)

SCHKSB

Propósito:

!>
!> SCHKSB prueba la reducción de una matriz de banda simétrica a forma tridiagonal,
!> utilizada con el problema de valores propios simétricos.
!>
!> SSBTRD factoriza una matriz simétrica de banda A como U S U', donde ' significa
!> transpuesta, S es simétrica tridiagonal y U es ortogonal.
!> SSBTRD puede usar solo el triángulo inferior o solo el triángulo superior
!> de A; SCHKSB verifica ambos casos.
!>
!> Cuando se llama a SCHKSB, se especifican un número de tamaños de matriz (),
!> un número de anchos de banda () y un número de tipos de matriz. Para cada
!> tamaño (), cada ancho de banda () menor o igual que , y cada tipo de matriz,
!> se generará y utilizará una matriz para probar la rutina de reducción simétrica
!> de banda. Para cada matriz, se realizarán un número de pruebas:
!>
!> (1)     | A - V S V' | / ( |A| n ulp )  calculado por SSBTRD con
!>                                         UPLO='U'
!>
!> (2)     | I - UU' | / ( n ulp )
!>
!> (3)     | A - V S V' | / ( |A| n ulp )  calculado por SSBTRD con
!>                                         UPLO='L'
!>
!> (4)     | I - UU' | / ( n ulp )
!>
!> Los  se especifican mediante un array NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>      1, ..., ULP  y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1)
!> (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>      1, ..., ULP  y signos aleatorios.
!> (5)  Una matriz diagonal con entradas  1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!> (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (8)  Una matriz de la forma U' D U, donde U es ortogonal y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (9)  Una matriz de la forma U' D U, donde U es ortogonal y
!>      D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (10) Una matriz de la forma U' D U, donde U es ortogonal y
!>      D tiene entradas  1, ULP,..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          SCHKSB no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es un array INTEGER, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>

NWDTHS

!>          NWDTHS es INTEGER
!>          El número de anchos de banda a utilizar. Si es cero,
!>          SCHKSB no hace nada. Debe ser al menos cero.
!>

KK

!>          KK es un array INTEGER, dimension (NWDTHS)
!>          Un array que contiene los anchos de banda a utilizar para las
!>          matrices de banda. Los valores deben ser al menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SCHKSB
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar la matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          se ignorarán.
!>

ISEED

!>          ISEED es un array INTEGER, dimension (4)
!>          En la entrada ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no lo están, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debe producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED cambian a la salida y pueden usarse en la
!>          siguiente llamada a SCHKSB para continuar la misma secuencia de números
!>          aleatorios.
!>

THRESH

!>          THRESH es REAL
!>          Una prueba se contará como  si el , calculado como
!>          se describe anteriormente, excede THRESH. Tenga en cuenta que el error
!>          se escala para ser O(1), por lo que THRESH debe ser un múltiplo razonablemente
!>          pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple o doble)
!>          o del tamaño de la matriz. Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0.)
!>

A

!>          A es un array REAL, dimension
!>                            (LDA, max(NN))
!>          Se utiliza para contener la matriz cuyos valores propios se van a
!>          calcular.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. Debe ser al menos 2 (¡no 1!)
!>          y al menos max( KK )+1.
!>

SD

!>          SD es un array REAL, dimension (max(NN))
!>          Se utiliza para contener la diagonal de la matriz tridiagonal calculada
!>          por SSBTRD.
!>

SE

!>          SE es un array REAL, dimension (max(NN))
!>          Se utiliza para contener los fuera de la diagonal de la matriz
!>          tridiagonal calculada por SSBTRD.
!>

U

!>          U es un array REAL, dimension (LDU, max(NN))
!>          Se utiliza para contener la matriz ortogonal calculada por SSBTRD.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U. Debe ser al menos 1
!>          y al menos max( NN ).
!>

WORK

!>          WORK es un array REAL, dimension (LWORK)
!>

NAME

schksp

!> SUBROUTINE SCHKSP(
!>          ALOOP, BLOOP, CLOOP, DLOOP, RLOOP, WHER
!> )

Function/Subroutine Documentation

Purpose:

  SCHKSP es una rutina de soporte para el programa de prueba de LAPACK
  que se utiliza para probar las rutinas de LAPACK para la solución de
  sistemas lineales con matrices simétricas o hermíticas (SYGSV,
  SYGSS, SSYEV, CHESV, CHES, CHEEV).

Parameters:

ALOOP
!>          ALOOP is INTEGER
!>          Indicates whether to test routines that perform LU decomposition
!>          with a symmetric/Hermitian matrix.
!>          If ALOOP = 1, LU routines are tested.
!>          If ALOOP = 0, LU routines are not tested.
BLOOP
!>          BLOOP is INTEGER
!>          Indicates whether to test routines that solve general linear
!>          systems with a symmetric/Hermitian matrix and a right-hand side
!>          vector.
!>          If BLOOP = 1, general SYGSV routines are tested.
!>          If BLOOP = 0, general SYGSV routines are not tested.
CLOOP
!>          CLOOP is INTEGER
!>          Indicates whether to test routines that solve general linear
!>          systems with a symmetric/Hermitian matrix and a right-hand side
!>          matrix.
!>          If CLOOP = 1, general SYGSV routines are tested.
!>          If CLOOP = 0, general SYGSV routines are not tested.
DLOOP
!>          DLOOP is INTEGER
!>          Indicates whether to test routines that compute eigenvalues and
!>          eigenvectors for a symmetric/Hermitian matrix.
!>          If DLOOP = 1, EIGEN routines are tested.
!>          If DLOOP = 0, EIGEN routines are not tested.
RLOOP
!>          RLOOP is INTEGER
!>          Indicates whether to test routines that reduce a symmetric/Hermitian
!>          matrix to tridiagonal form.
!>          If RLOOP = 1, REDUCTION routines are tested.
!>          If RLOOP = 0, REDUCTION routines are not tested.
WHER
!>          WHER is INTEGER
!>          Specifies the type of problem to be tested.
!>          If WHER = 1, general symmetric/Hermitian matrix problems are tested.
!>          If WHER = 2, banded symmetric/Hermitian matrix problems are tested.
!>          If WHER = 3, sparse symmetric/Hermitian matrix problems are tested.
!>          If WHER = 4, general tridiagonal matrix problems are tested.
!>          If WHER = 5, banded tridiagonal matrix problems are tested.
!>          If WHER = 6, sparse tridiagonal matrix problems are tested.

Description:

  SCHKSP llama a las subrutinas de prueba apropiadas basándose en los
  valores de los parámetros de entrada. Controla qué tipos de problemas
  de matrices simétricas/hermíticas se prueban y qué subrutinas se invocan.
