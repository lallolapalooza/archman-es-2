sched_getcpu(3) Manual de funciones de biblioteca sched_getcpu(3)

NOMBRE

sched_getcpu - determinar la CPU en la que se está ejecutando el hilo que llama

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sched.h>
int sched_getcpu(void);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

sched_getcpu():

    Desde glibc 2.14:
        _GNU_SOURCE
    Antes de glibc 2.14:
        _BSD_SOURCE || _SVID_SOURCE
            /* _GNU_SOURCE también es suficiente */

DESCRIPCIÓN

sched_getcpu() devuelve el número de la CPU en la que se está ejecutando actualmente el hilo que llama.

VALOR DE RETORNO

En caso de éxito, sched_getcpu() devuelve un número de CPU no negativo. En caso de error, devuelve -1 y se establece errno para indicar el error.

ERRORES

ENOSYS
Este kernel no implementa getcpu(2).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
sched_getcpu () Seguridad de hilos MT-Safe

ESTÁNDARES

GNU.

HISTORIA

glibc 2.6.

NOTAS

La llamada


cpu = sched_getcpu();

es equivalente a la siguiente llamada a getcpu(2):


int c, s;
s = getcpu(&c, NULL);
cpu = (s == -1) ? s : c;

VER TAMBIÉN

getcpu(2), sched(7)
