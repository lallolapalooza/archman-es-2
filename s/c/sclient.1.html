SCLIENT(1) MIT Kerberos SCLIENT(1)

NOMBRE

sclient - cliente de ejemplo de Kerberos versión 5

SINOPSIS

sclient servidorremoto

DESCRIPCIÓN

sclient es una aplicación de ejemplo, útil principalmente para fines de prueba. Se contacta con un servidor de ejemplo sserver(8) y se autentica en él utilizando tickets de Kerberos versión 5, y luego muestra la respuesta del servidor.

AMBIENTE

Consulte kerberos(7) para una descripción de las variables de entorno de Kerberos.

VER TAMBIÉN

kinit(1), sserver(8), kerberos(7)
