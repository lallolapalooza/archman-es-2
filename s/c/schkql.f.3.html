SCHKQL

Propósito

!>
!> SCHKQL prueba SGEQLF, SORGQL y SORMQL.
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array lógico, dimensión (NTIPOS)
!>          Los tipos de matrices a utilizar para las pruebas. Las matrices
!>          de tipo j (para 1 <= j <= NTYPES) se usan para pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se usa.
!>

NM

!>          NM es ENTERO
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array ENTERO, dimensión (NM)
!>          Los valores de la dimensión de fila de la matriz M.
!>

NN

!>          NN es ENTERO
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array ENTERO, dimensión (NN)
!>          Los valores de la dimensión de columna de la matriz N.
!>

NNB

!>          NNB es ENTERO
!>          El número de valores de NB y NX contenidos en los
!>          vectores NBVAL y NXVAL. Los parámetros de bloqueo se usan
!>          en pares (NB,NX).
!>

NBVAL

!>          NBVAL es un array ENTERO, dimensión (NNB)
!>          Los valores del tamaño de bloque NB.
!>

NXVAL

!>          NXVAL es un array ENTERO, dimensión (NNB)
!>          Los valores del punto de cruce NX.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de vectores del lado derecho a generar para
!>          cada sistema lineal.
!>

THRESH

!>          THRESH es REAL
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          todas las relaciones de prueba se impriman, use THRESH = 0.
!>

TSTERR

!>          TSTERR es LÓGICO
!>          Indicador que señala si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es ENTERO
!>          El valor máximo permitido para M o N, usado en la
!>          dimensionamiento de los arrays de trabajo.
!>

A

!>          A es un array REAL, dimensión (NMAX*NMAX)
!>

AF

!>          AF es un array REAL, dimensión (NMAX*NMAX)
!>

AQ

!>          AQ es un array REAL, dimensión (NMAX*NMAX)
!>

AL

!>          AL es un array REAL, dimensión (NMAX*NMAX)
!>

AC

!>          AC es un array REAL, dimensión (NMAX*NMAX)
!>

B

!>          B es un array REAL, dimensión (NMAX*NRHS)
!>

X

!>          X es un array REAL, dimensión (NMAX*NRHS)
!>

XACT

!>          XACT es un array REAL, dimensión (NMAX*NRHS)
!>

TAU

!>          TAU es un array REAL, dimensión (NMAX)
!>

WORK

!>          WORK es un array REAL, dimensión (NMAX*NMAX)
!>

RWORK

!>          RWORK es un array REAL, dimensión (NMAX)
!>

NOUT

!>          NOUT es ENTERO
!>          El número de unidad para la salida.
!>
