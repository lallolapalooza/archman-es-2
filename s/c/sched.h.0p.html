sched.h(0P) Manual del programador POSIX sched.h(0P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación en Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sched.h — planificación de la ejecución

SINOPSIS

#include <sched.h>

DESCRIPCIÓN

El archivo de cabecera <sched.h> definirá el tipo pid_t como se describe en <sys/types.h>.

El archivo de cabecera <sched.h> definirá el tipo time_t como se describe en <sys/types.h>.

El archivo de cabecera <sched.h> definirá la estructura timespec como se describe en <time.h>.

El archivo de cabecera <sched.h> definirá la estructura sched_param, que incluirá los parámetros de planificación necesarios para la implementación de cada política de planificación soportada. Esta estructura incluirá como mínimo el siguiente miembro:

int       sched_priority        Prioridad de planificación de la ejecución
                                del proceso o hilo.

La estructura sched_param definida en <sched.h> incluirá los siguientes miembros además de los especificados anteriormente:

int             sched_ss_low_priority Prioridad de planificación baja para
                                      el servidor esporádico.
struct timespec sched_ss_repl_period  Período de reposición para el
                                      servidor esporádico.
struct timespec sched_ss_init_budget  Presupuesto inicial para el servidor esporádico.
int             sched_ss_max_repl     Reposiciones pendientes máximas para el
                                      servidor esporádico.

Cada proceso o hilo está controlado por una política de planificación y una prioridad asociadas. Asociada a cada política hay un rango de prioridad. Cada definición de política especifica el rango de prioridad mínimo para esa política. Los rangos de prioridad para cada política pueden solaparse con los rangos de prioridad de otras políticas.

Se definen cuatro políticas de planificación; otras pueden ser definidas por la implementación. Las cuatro políticas estándar se indican mediante los valores de las siguientes constantes simbólicas:

SCHED_FIFO
Política de planificación de tipo "primero en entrar, primero en salir" (FIFO).
SCHED_RR
Política de planificación de tipo "round robin" (redondeo).
SCHED_SPORADIC
Política de planificación de servidor esporádico.
SCHED_OTHER
Otra política de planificación.

Los valores de estas constantes son distintos.

Las siguientes se declararán como funciones y también pueden definirse como macros. Se proporcionarán prototipos de función.

int    sched_get_priority_max(int);
int    sched_get_priority_min(int);
int    sched_getparam(pid_t, struct sched_param *);
int    sched_getscheduler(pid_t);
int    sched_rr_get_interval(pid_t, struct timespec *);
int    sched_setparam(pid_t, const struct sched_param *);
int    sched_setscheduler(pid_t, int, const struct sched_param *);
int    sched_yield(void);

La inclusión del archivo de cabecera <sched.h> puede hacer visibles todos los símbolos del archivo de cabecera <time.h>.
