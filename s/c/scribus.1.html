scribus(1) Manual de Comandos Generales scribus(1)

NOMBRE

scribus - aplicación de autoedición de escritorio multiplataforma WYSIWYG

SINOPSIS

scribus [-h|--help] [-v|--version] [-l|--lang idioma] [-la|--langs-available] [-f|--file|--] [nombre_archivo]

DESCRIPCIÓN

Scribus es un programa de autoedición de código abierto. Proporciona edición WYSIWYG real, excelentes opciones de exportación a PDF y una amplia gama de otras opciones de entrada y salida.

Por favor, consulta la documentación de scribus en http://docs.scribus.net/ o la ayuda integrada del programa para obtener documentación más completa y actualizada.

Esta página del manual solo proporciona resúmenes de algunos aspectos del uso del programa. Su propósito principal es asegurar que puedas encontrar la documentación completa de forma rápida y sencilla.

OPCIONES

Las opciones definitivas se encuentran en la declaración de uso del programa. Ejecuta: scribus --help para ver la declaración de uso.

-l, --lang xx
Anula la configuración regional del sistema y ejecuta Scribus en el idioma xx. El idioma se especifica con los mismos códigos de idioma POSIX que se usan en las variables de entorno LANG y LC_ALL. Por ejemplo, el inglés se puede seleccionar con 'en' (inglés genérico), 'en_GB' (inglés británico), 'en_US' (inglés estadounidense), etc. De manera similar, el alemán se puede seleccionar con 'de' o 'de_DE'.
-la, --langs-available
Imprime una lista de los idiomas para los que hay traducciones de la interfaz de usuario disponibles. Para usar ese idioma, ejecuta Scribus como 'scribus -l xx' donde xx es el código corto del idioma, o configura las variables de entorno de configuración regional como se describe a continuación.
-v, --version
Imprime el número de versión de Scribus y sale.
-f, --file
Abre el archivo especificado. Es posible simplemente pasar el nombre del archivo como un argumento no cualificado en lugar de usar esta opción, aunque si el nombre comienza con un - necesitarás usar --, por ejemplo, 'scribus -- -miarchivo.sla'.
-h, --help
Imprime un breve resumen de uso.
-fi, --font-info
Muestra la lista de archivos de fuentes cuando Scribus se inicia. Esto se puede usar para diagnosticar glifos faltantes en las fuentes o posibles archivos de fuentes corruptos.
-pi, --profile-info
Muestra la lista de perfiles de color que Scribus puede usar. Esto se puede usar para diagnosticar perfiles de color faltantes o corruptos.
-pr, --prefs <nombre_archivo>
Utiliza nombre_archivo como ruta para las preferencias dadas por el usuario.
-py, --python-script <script> [argumentos ...]
Ejecuta script en Python [con argumentos opcionales]. Esta opción debe ser la última opción utilizada.
-ns, --no-splash
Suprime la visualización de la pantalla de presentación durante el inicio de Scribus.
-nns, --never-splash
Detiene la visualización de la pantalla de presentación al iniciar. Escribe un archivo vacío llamado .neversplash en ~/.config/scribus.
-sb, --swap-buttons
Usa el orden de botones del diálogo de derecha a izquierda (por ejemplo, Cancelar/No/Sí en lugar de Sí/No/Cancelar).
-u, --upgradecheck
Descarga un archivo de nuestro servidor de scribus que indica las últimas versiones disponibles.

ENTORNO

Scribus respeta las variables de entorno de configuración regional estándar. Pueden usarse otras a través de bibliotecas subyacentes, como Qt, o por programas utilizados por Scribus. http://docs.scribus.net/ y la documentación dentro del programa pueden mencionar otras variables de entorno utilizadas por Scribus o los programas y bibliotecas que utiliza.

LC_ALL, LC_MESSAGES, LANG
Configuración regional POSIX. Ver locale(1). Scribus utiliza estas tres variables de entorno, en el orden de precedencia indicado, para seleccionar el idioma (incluida la traducción de la interfaz de usuario) a utilizar. Si ninguna está configurada, recurrirá a la configuración regional establecida por la biblioteca Qt subyacente.
PATH
Scribus puede buscar en el PATH herramientas externas si sus rutas no están especificadas de forma absoluta. Actualmente, esto es más probable que te afecte si tienes varias copias de gs(1) instaladas. Puedes establecer una ruta absoluta a la versión correcta de gs(1) en tus preferencias de Scribus y omitir la búsqueda en PATH.

Aquí se resumen algunas variables de entorno importantes de otros programas para mayor comodidad, aunque deberías consultar la documentación del programa original si tienes problemas.

GS_FONTPATH
Ruta de fuentes de GhostScript. Afecta la ruta de búsqueda de fuentes de GhostScript, un componente que Scribus utiliza para algunas operaciones de PostScript. Añade nuevos directorios que contengan fuentes a esta lista separada por dos puntos para ayudar a GhostScript a encontrar fuentes en ubicaciones no estándar. Consulta gs(1) y la documentación HTML de GhostScript para obtener más información.
GS_LIB
Ruta de la biblioteca de GhostScript. GhostScript busca en esta ruta los archivos Fontmap. Al igual que GS_FONTPATH, es una lista de directorios separada por dos puntos. Normalmente querrás usar GS_FONTPATH en su lugar, aunque construir un archivo Fontmap y usar GS_LIB puede acelerar las cosas si tienes *muchas* fuentes. Consulta gs(1) y la documentación HTML de GhostScript para obtener más información.

ARCHIVOS

$HOME/.config/scribus/
Las preferencias del usuario se almacenan en $HOME/.config/scribus/ en Unix o Linux. La mayoría de las otras rutas son configurables desde las preferencias de Scribus. Las preferencias de Scribus 1.5 son separadas de las de Scribus 1.3.x. Las preferencias de usuario para Mac OS X, OS/2 y Windows se documentan en la ayuda (F1) de Scribus. $HOME/.config/scribus/scribus150.rc Archivo de preferencias de Scribus - formateado en un esquema XML personalizado. Eventualmente puede ser retirado en favor de un archivo de preferencias de nuevo formato. $HOME/.config/scribus/prefs150.xml Las preferencias de Scribus 1.5.x son separadas de las de Scribus 1.3.x
$HOME/.fonts/
$HOME/.fonts.conf
/etc/fonts
Fontconfig, la biblioteca utilizada por Scribus para localizar fuentes, normalmente se configura con archivos en /etc/fonts, principalmente /etc/fonts/fonts.conf y /etc/fonts/local.conf. También puede usar un archivo de configuración $HOME/.fonts.conf y fuentes en $HOME/.fonts/. Consulta fonts.conf(5) y la documentación de fontconfig para obtener más información. Ten en cuenta que Scribus también puede usar su ruta de fuentes interna para localizar más fuentes; consulta el diálogo de Preferencias y la ayuda de scribus.
