SCRIPTREPLAY(1) Comandos de usuario SCRIPTREPLAY(1)

NOMBRE

scriptreplay - reproduce capturas de pantalla, usando información de temporización

SINOPSIS

scriptreplay [opciones] archivo_de_temporización [captura_de_pantalla [divisor]]

DESCRIPCIÓN

Este programa reproduce una captura de pantalla, utilizando información de temporización para asegurarse de que la salida ocurra al mismo ritmo que apareció originalmente cuando se grabó el script.

La reproducción simplemente muestra la información de nuevo; los programas que se ejecutaron cuando se grabó la captura de pantalla no se ejecutan de nuevo. Dado que la misma información simplemente se está mostrando, scriptreplay solo garantiza que funcione correctamente si se ejecuta en el mismo tipo de terminal en el que se grabó la captura de pantalla. De lo contrario, cualquier carácter de escape en la captura de pantalla puede ser interpretado de manera diferente por el terminal al que scriptreplay está enviando su salida.

La información de temporización es lo que script(1) genera en el archivo especificado por --log-timing.

Por defecto, se asume que el archivo de captura_de_pantalla se llama typescript, pero se pueden especificar otros nombres de archivo, como segundo parámetro o con la opción --log-out.

Si se especifica el tercer parámetro o --divisor, se utiliza como multiplicador de aceleración. Por ejemplo, una aceleración de 2 hace que scriptreplay vaya el doble de rápido, y una desaceleración de 0.1 hace que vaya diez veces más lento que la sesión original.

Durante la reproducción, puede acelerar, ralentizar o pausar interactivamente la reproducción utilizando las teclas Arriba, Abajo y Espacio.

OPCIONES

-I, --log-in archivo

Archivo que contiene la entrada de terminal de script.

-O, --log-out archivo

Archivo que contiene la salida de terminal de script.

-B, --log-io archivo

Archivo que contiene la salida y entrada de terminal de script.

-t, --timing archivo

Archivo que contiene la salida de temporización de script. Esta opción reemplaza el argumento posicional archivo_de_temporización.

-T, --log-timing archivo

Este es un alias de -t, mantenido por compatibilidad con las opciones de línea de comandos de script(1).

-s, --typescript archivo

Alias obsoleto de --log-out.

-c, --cr-mode modo

Especifica cómo manejar el carácter CR (retorno de carro, 0x0D) de los archivos de registro. El modo predeterminado es auto, en cuyo caso CR se reemplaza con un salto de línea para el registro de stdin, ya que de lo contrario scriptreplay sobrescribiría la misma línea. Los otros modos son never y always.

-d, --divisor número

Acelera la reproducción mostrando este número de veces. El argumento es un número de punto flotante. Se llama divisor porque divide los tiempos por este factor. Esta opción anula los argumentos de estilo antiguo.

-m, --maxdelay número

Establece el retraso máximo entre actualizaciones en número de segundos. El argumento es un número de punto flotante. Esto se puede utilizar para evitar pausas largas en la reproducción de la captura de pantalla.

--summary

Muestra detalles sobre la sesión grabada en el archivo de temporización especificado y sale. La sesión debe haber sido grabada usando el formato advanced (ver la opción --logging-format de script(1) para más detalles).

-x, --stream tipo

Fuerza a scriptreplay a imprimir solo el flujo especificado. Los tipos de flujo compatibles son in, out, signal e info. Esta opción se recomienda para registros de múltiples flujos (creados con --log-io) para imprimir solo los datos deseados.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

EJEMPLOS

% script --log-timing file.tm --log-out script.out
Script started, file is script.out
% ls
<etc, etc>
% exit
Script done, file is script.out
% scriptreplay --log-timing file.tm --log-out script.out

ASIGNACIONES DE TECLAS

Las siguientes teclas controlan la reproducción del script:

•Espacio: Alterna entre pausa y reanudación. Presiona esta tecla para pausar la reproducción, y vuelve a presionarla para reanudarla.
•Flecha Arriba: Aumenta la velocidad de reproducción. Cada pulsación de esta tecla hará que el script se reproduzca un 0.1 veces más rápido.
•Flecha Abajo: Disminuye la velocidad de reproducción. Cada pulsación de esta tecla hará que el script se reproduzca un 0.1 veces más lento.

NAME

scriptreplay - Reproducir una grabación de `script`

SYNOPSIS

scriptreplay [-a] [-t timefile] [scriptfile]

DESCRIPTION

scriptreplay reproduce una grabación hecha por el comando `script`. Toma el archivo de registro de tiempo generado por `script` (normalmente llamado `typescript.time` o similar) y lo utiliza para reproducir la grabación al ritmo correcto.

Si no se especifica un archivo de registro de tiempo, scriptreplay buscará un archivo llamado `typescript.time` en el directorio actual.

Si no se especifica un archivo de grabación, scriptreplay lo leerá de la entrada estándar.

La opción -a hace que la reproducción se detenga al final del archivo de entrada, en lugar de esperarse a que se presione una tecla.

OPTIONS

-a
Termina la reproducción al final de la grabación.
-t timefile
Especifica el archivo de registro de tiempo a utilizar.
