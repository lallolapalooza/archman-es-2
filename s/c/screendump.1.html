SCREENDUMP(1) Manual de comandos generales SCREENDUMP(1)

NOMBRE

screendump - volcar el contenido de una consola virtual a stdout

SINOPSIS

screendump [opciones] [N]

DESCRIPCIÓN

El comando screendump vuelca el contenido de la consola virtual N, (o la consola actual si se omite N) a la salida estándar.

Simplemente ejecutar

cat /dev/vcsN
tiene un efecto similar.

OPCIONES

-V, --version
imprimir el número de versión.
-h, --help
imprimir este mensaje de uso.

NOTAS

Por razones de seguridad, screendump utiliza los dispositivos de Linux de "pantalla de consola virtual" y "pantalla de consola virtual con atributos" para dar acceso a screendump.

Asegúrese de que estos archivos existan, usando

cd /dev for i in 0 1 2 3 ...; do
mknod vcs$i c 7 $i
mknod vcsa$i c 7 `expr 128 + $i`
done

(rellenando los puntos suspensivos) y dé a los archivos de dispositivo los permisos apropiados, o ejecute screendump como root.
