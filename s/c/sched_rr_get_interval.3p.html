PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux) o la interfaz puede no estar implementada en Linux.

NOMBRE

sched_rr_get_interval — obtener límites de tiempo de ejecución (REALTIME)

SINOPSIS

#include <sched.h>
int sched_rr_get_interval(pid_t pid, struct timespec *interval);

DESCRIPCIÓN

La función sched_rr_get_interval() actualizará la estructura timespec a la que se refiere el argumento interval para que contenga el límite de tiempo de ejecución actual (es decir, quantum de tiempo) para el proceso especificado por pid. Si pid es cero, se devolverá el límite de tiempo de ejecución actual del proceso que llama.

VALOR DE RETORNO

Si tiene éxito, la función sched_rr_get_interval() devolverá cero. De lo contrario, devolverá un valor de -1 y establecerá errno para indicar el error.

ERRORES

La función sched_rr_get_interval() fallará si:

ESRCH
No se puede encontrar ningún proceso que corresponda al especificado por pid.
