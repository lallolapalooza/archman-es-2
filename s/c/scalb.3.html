scalb(3) Manual de funciones de biblioteca scalb(3)

NOMBRE

scalb, scalbf, scalbl - escalar por una potencia entera de la base (OBSOLETO)

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
[[deprecated]] double scalb(double x, double e);
[[deprecated]] float scalbf(float x, float e);
[[deprecated]] long double scalbl(long double x, long double e);
Requisitos de Macro de Prueba de Funcionalidades para glibc (véase feature_test_macros(7)):

scalb():

    _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

scalbf(), scalbl():

    _XOPEN_SOURCE >= 600
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones multiplican su primer argumento x por FLT_RADIX (probablemente 2) elevado a la potencia e, es decir:

    x * FLT_RADIX ** e

La definición de FLT_RADIX se puede obtener incluyendo <float.h>.

VALOR DEVUELTO

En caso de éxito, estas funciones devuelven x * FLT_RADIX ** e.

Si x o e es un NaN, se devuelve un NaN.

Si x es infinito positivo (infinito negativo) y e no es infinito negativo (infinito positivo), se devuelve infinito positivo (infinito negativo).

Si x es +0 (-0) y e no es infinito positivo, se devuelve +0 (-0).

Si x es cero y e es infinito positivo, ocurre un error de dominio y se devuelve un NaN.

Si x es un infinito y e es un infinito negativo, ocurre un error de dominio y se devuelve un NaN.

Si el resultado desborda, ocurre un error de rango y las funciones devuelven HUGE_VAL, HUGE_VALF o HUGE_VALL, respectivamente, con un signo igual al de x.

Si el resultado cae por debajo del rango, ocurre un error de rango y las funciones devuelven cero, con un signo igual al de x.

ERRORES

Véase math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es 0 y e es infinito positivo, o x es infinito positivo y e es infinito negativo y el otro argumento no es un NaN
errno se establece en EDOM. Se genera una excepción de punto flotante inválida (FE_INVALID).
Error de rango, desbordamiento
errno se establece en ERANGE. Se genera una excepción de punto flotante por desbordamiento (FE_OVERFLOW).
Error de rango, caída por debajo del rango
errno se establece en ERANGE. Se genera una excepción de punto flotante por caída por debajo del rango (FE_UNDERFLOW).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, véase attributes(7).

Interfaz Atributo Valor
scalb (), scalbf (), scalbl () Seguridad en hilos MT-Safe

ESTÁNDARES

Ninguno.

HISTORIA

scalb()
4.3BSD. Obsoleto en POSIX.1-2001; Eliminado en POSIX.1-2008, recomendando el uso de scalbln(3), scalblnf(3) o scalblnl(3) en su lugar.

ERRORES

Antes de glibc 2.20, estas funciones no establecían errno para errores de dominio y rango.

VEASE TAMBIÉN

ldexp(3), scalbln(3)
