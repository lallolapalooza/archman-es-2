SCUMMVM(6) Manual de Juegos SCUMMVM(6)

NOMBRE

scummvm — intérprete de juegos de aventuras y rol

SINOPSIS

scummvm [OPCIONES] [JUEGO]

DESCRIPCIÓN

scummvm es un intérprete que reproducirá numerosos juegos de aventuras y rol basados en una variedad de motores de juego.

JUEGO es un nombre corto del juego a cargar. Este puede ser un gameid incorporado (como el proporcionado por --list-games) o un destino configurado por el usuario (como el proporcionado por --list-targets).

OPCIONES

El significado de la mayoría de las opciones largas (es decir, aquellas opciones que comienzan con doble guion) se puede invertir prefijándolas con no-. Por ejemplo, --no-aspect-ratio desactivará la corrección de relación de aspecto. Esto es útil si desea anular una configuración en el archivo de configuración.

-a | --add
Añade todos los juegos del directorio actual o especificado (con --path=RUTA). Si se pasa --game=ID, solo se añadirá el juego con el id ID.

Ver también --detect.

windows
Secuenciador MIDI incorporado de Windows (Windows).

-s | --sfx-volume=NÚM
Establecer el volumen de SFX, 0–255 (por defecto: 192).
-t | --list-targets
Mostrar la lista de objetivos de juego configurados por el usuario y salir.
-u | --dump-scripts
Habilitar la volcado de scripts si existe un directorio llamado dumps en el directorio actual.
-v | --version
Mostrar información de la versión de ScummVM y salir.
-x | --save-slot[=SLOT]
Establecer la ranura de guardado a cargar (por defecto: 0 = autoguardado).
-z | --list-games
Mostrar la lista de juegos compatibles y salir.
--[no-]alt-intro
Alternar la introducción alternativa para las versiones en CD de Beneath a Steel Sky y Flight of the Amazon Queen (por defecto: deshabilitado).
--[no-]aspect-ratio
Alternar la corrección de la relación de aspecto.
--auto-detect
Mostrar una lista de juegos del directorio actual o especificado y comenzar el primero. Utilice --path=PATH para especificar un directorio.
--cdrom=UNIDAD
Establecer la unidad desde la que reproducir audio de CD; puede ser una unidad, una ruta o un índice numérico (por defecto: 0 = la mejor unidad elegida).
--[no-]copy-protection
Habilitar la protección contra copia en los juegos, cuando ScummVM la deshabilita por defecto.
--[no-]dirtyrects
Alternar la optimización de rectángulos sucios en el renderizador de software (por defecto: habilitado).
--debug-channels-only
Mostrar solo los canales de depuración especificados.
--debugflags=FLAGS
Habilitar banderas de depuración específicas del motor (separadas por comas).
--[no-]demo-mode
Alternar el modo de demostración de Maniac Mansion o The 7th Guest (por defecto: deshabilitado).
--detect
Mostrar una lista de juegos con su ID desde el directorio actual o especificado sin añadirlo al archivo de configuración. Utilice --path=PATH para especificar un directorio.
--dump-midi
Volcar eventos MIDI a dump.mid (sobrescribiéndolo), hasta salir del juego.
--enable-gs
Habilitar mapeos de parches para emular un MT-32 en un dispositivo Roland GS para la reproducción MIDI.
--engine=ID
En combinación con --list-games, --list-all-games, --list-targets, o --stats, listar solo juegos para este motor. Se pueden listar múltiples motores separados por una coma.
--engine-speed=NÚM
Establecer el límite de fotogramas por segundo (0–100) para juegos 3D, 0 = sin límite (por defecto: 60).
--[no-]exit
En combinación con comandos que salen después de ejecutarse, como --add o --list-engines, alternar la apertura del lanzador en lugar de salir.
--extrapath=PATH
Establecer la ruta adicional para datos de juegos y ScummVM adicionales.
--[no-]filtering
Forzar el modo gráfico filtrado/no filtrado. El modo gráfico filtrado utiliza interpolación bilineal mientras que el modo gráfico no filtrado utiliza vecino más cercano.
--game=ID
En combinación con --add o --detect, solo añadir o intentar detectar el juego con ID ID.
--gui-theme=THEME
Seleccionar un tema de GUI, según lo proporcionado por --list-themes.
--joystick[=NÚM]
Habilitar la entrada de joystick (por defecto: 0 = primer joystick).
--iconspath=PATH
Establecer la ruta a iconos adicionales para la vista de cuadrícula del lanzador.
--list-all-debugflags
Mostrar la lista de todas las banderas de depuración del motor y salir.
--list-all-engines
Mostrar la lista de todos los motores de detección y salir.
--list-all-games
Mostrar la lista de todos los juegos detectados y salir.
--list-audio-devices
Listar todos los dispositivos de audio disponibles y salir.
--list-debugflags[=ENGINE]
Mostrar la lista de banderas de depuración especificadas por el motor y salir. Si el argumento ENGINE es "global" o si no se especifica, listar las banderas de depuración globales.
--list-engines
Mostrar la lista de motores compatibles y salir.
--list-saves
Mostrar una lista de juegos guardados para el objetivo especificado con --game=TARGET, o todos los objetivos si no se especifica ninguno, y salir.
--list-themes
Mostrar la lista de todos los temas de GUI utilizables y salir.
--md5
Mostrar el hash MD5 del archivo dado por --md5-path=PATH. Si se pasa --md5-length=NÚM, mostrar el hash MD5 de los primeros (si es positivo) o últimos (si es negativo) NÚM bytes del archivo dado por PATH. Si se pasa --md5-engine=ENGINE_ID, recuperar la longitud MD5 automáticamente, anulando --md5-length.
--md5mac
Similar a --md5, pero para archivos antiguos de Macintosh. Mostrar el hash MD5 tanto para la bifurcación de recursos como para la bifurcación de datos del archivo.
--midi-gain=NÚM
Establecer la ganancia para la reproducción MIDI, 0–1000 (por defecto: 100). Solo es compatible con algunos controladores MIDI.
--multi-midi
Habilitar la combinación de AdLib y MIDI nativo.
--native-mt32
Indicar a ScummVM que el dispositivo MIDI es un Roland MT-32 real o un dispositivo compatible. Esto deshabilita cualquier emulación GM.
--opl-driver=DRIVER
Seleccionar el emulador AdLib (OPL) (alsa, db, mame, nuked, opl2lpt).
--output-channels=RATE
Establecer el número de canales de salida (por ejemplo, 2 para estéreo).
--output-rate=RATE
Establecer la frecuencia de muestreo de salida en Hz (por ejemplo, 22050).
--platform=PLATAFORMA
Especificar la plataforma del juego (2gs, 3do, acorn, amiga, android, apple2, atari, atari8, beos, c64, cdi, coco, coco3, cpc, fmtowns, ios, linux, macintosh, macintosh2, megadrive, nes, os2, pc, pc98, pce, pippin, playstation, playstation2, ppc, saturn, segacd, shockwave, ti994, wii, windows, xbox, zx).
--random-seed=NÚM

OPTIONS

--seed=NUM
Establece el número de semilla aleatoria utilizado para inicializar la entropía.
--[no-]recursive
En combinación con --add o --detect, recurre en todos los subdirectorios (por defecto: deshabilitado).
--render-mode=MODO
Habilita modos de renderizado adicionales (2gs, amiga, atari, c64, cga, cgaBW, cgaComp, cpc, ega, fmtowns, hercAmber, hercGreen, macintosh, macintoshbw, pc9801, pc9821, vga, zx).
--renderer=RENDERIZADOR
Selecciona el renderizador 3D (opengl, opengl_shaders, software).
--savepath=RUTA
Especifica dónde se almacenan las partidas guardadas.
--scale-factor=FACTOR
Establece el factor por el cual se escalarán los gráficos.
--scaler=MODO
Selecciona el escalador de gráficos (normal, hq, edge, advmame, sai, supersai, supereagle, pm, dotmatrix, tv2x).
--screenshotpath=RUTA
Especifica la ruta donde se crearán los archivos de captura de pantalla.
--[no-]show-fps
Alterna la información de FPS en juegos 3D.
--soundfont=ARCHIVO
Selecciona la SoundFont para la reproducción MIDI (solo compatible con algunos controladores MIDI).
--start-movie=NOMBRE@NUM
Inicia la película en un fotograma específico para Director. Cualquiera de los dos argumentos se puede especificar sin el otro.
--stats
Muestra estadísticas sobre motores y juegos, y sale.
--stretch-mode=MODO
Selecciona el modo de estiramiento (center, even-pixels, fit, fit_force_aspect, pixel-perfect, stretch).
--talkspeed=NUM
Establece el retraso al hablar para juegos SCUMM, o la velocidad al hablar para otros juegos.
--tempo=NUM
Establece el tempo de la música (en porcentaje, 50-200) para juegos SCUMM (por defecto: 100).
--themepath=RUTA
Establece la ruta a los temas de la interfaz gráfica.
--window-size=A,H
Establece el tamaño de la ventana a las dimensiones especificadas (solo OpenGL).

ENTORNO

SCUMMVM_MIDI
El dispositivo secuenciador a utilizar con el controlador MIDI ‘seq’.
SCUMMVM_MIDIPORT
El número del secuenciador a utilizar cuando se usa el controlador MIDI ‘seq’.
SCUMMVM_PORT
El puerto ALSA a abrir para salida cuando se utiliza el controlador MIDI ‘alsa’.
SCUMMVM_SAVEPATH
Anula la ruta de guardado predeterminada (sistemas POSIX).

ARCHIVOS

$HOME/.config/scummvm/scummvm.ini
Archivo de configuración en la mayoría de los sistemas Unix. Las variables de entorno XDG tienen precedencia, si se definen.
$HOME/Library/Preferences/ScummVM Preferences
Archivo de configuración en macOS.

EJEMPLOS

Ejecutando el lanzador de juegos incorporado:

$ scummvm

Ejecutando Day of the Tentacle, especificando la ruta:

$ scummvm -p /usr/local/share/games/tentacle scumm:tentacle

Ejecutando The Dig con el filtro advmame2x y subtítulos (con el objetivo dig-steam ya definido en el archivo de configuración):

$ scummvm --scaler=advmame --scale-factor=2 -n dig-steam

Ejecutando la versión italiana de Maniac Mansion en pantalla completa, desde el contenido del directorio actual:

$ scummvm -q it -f scumm:maniac
