SCTP_BINDX(3) Manual del Programador de Linux SCTP_BINDX(3)

NOMBRE

sctp_bindx - Añadir o eliminar direcciones de enlace en un socket.

SINOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_bindx(int sd, struct sockaddr * addrs, int addrcnt,
               int flags);

DESCRIPCIÓN

sctp_bindx añade o elimina un conjunto de direcciones de enlace pasadas en el array addrs al/del socket sd. addrcnt es el número de direcciones en el array y el parámetro flags indica si las direcciones necesitan ser añadidas o eliminadas.

Si sd es un socket IPv4, las direcciones pasadas deben ser direcciones IPv4. Si sd es un socket IPv6, las direcciones pasadas pueden ser direcciones IPv4 o IPv6.

addrs es un puntero a un array de una o más direcciones de socket. Cada dirección está contenida en su estructura apropiada (es decir, struct sockaddr_in o struct sockaddr_in6). La familia del tipo de dirección debe usarse para distinguir la longitud de la dirección. El llamador especifica el número de direcciones en el array con addrcnt.

El parámetro flags puede ser SCTP_BINDX_ADD_ADDR o SCTP_BINDX_REM_ADDR. Una aplicación puede usar SCTP_BINDX_ADD_ADDR para asociar direcciones adicionales con un endpoint después de llamar a bind(2). SCTP_BINDX_REM_ADDR dirige a SCTP a eliminar las direcciones dadas de la asociación. Un llamador no puede eliminar todas las direcciones de una asociación. Fallará con EINVAL.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de fallo, se devuelve -1 y errno se establece apropiadamente.

ERRORES

EBADF
sd no es un descriptor válido.
ENOTSOCK
sd es un descriptor de un archivo, no de un socket.
EFAULT
Error al copiar dentro o fuera del espacio de direcciones del usuario.
EINVAL
Puerto o dirección inválido o intento de eliminar todas las direcciones de una asociación.
EACCES
La dirección está protegida y el usuario no es el superusuario.
