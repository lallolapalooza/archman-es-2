scalbnl(3) Manual de funciones de biblioteca scalbnl(3)

NOMBRE

scalbn, scalbnf, scalbnl, scalbln, scalblnf, scalblnl - escalar por una potencia entera de la base

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double scalbln(double x, long e);
float scalblnf(float x, long e);
long double scalblnl(long double x, long e);
double scalbn(double x, int e);
float scalbnf(float x, int e);
long double scalbnl(long double x, int e);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

scalbln(), scalblnf(), scalblnl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE

scalbn(), scalbnf(), scalbnl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones multiplican su primer argumento x por FLT_RADIX (probablemente 2) elevado a la potencia de e, es decir:

    x * FLT_RADIX ** e

La definición de FLT_RADIX se puede obtener incluyendo <float.h>.

VALOR DEVUELTO

En caso de éxito, estas funciones devuelven x * FLT_RADIX ** e.

Si x es un NaN, se devuelve un NaN.

Si x es infinito positivo (infinito negativo), se devuelve infinito positivo (infinito negativo).

Si x es +0 (-0), se devuelve +0 (-0).

Si el resultado excede los límites, ocurre un error de rango y las funciones devuelven HUGE_VAL, HUGE_VALF o HUGE_VALL, respectivamente, con un signo igual al de x.

Si el resultado cae fuera de los límites (underflow), ocurre un error de rango y las funciones devuelven cero, con un signo igual al de x.

ERRORES

Consulte math_error(7) para obtener información sobre cómo determinar si se ha producido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de rango, desbordamiento
Se eleva una excepción de punto flotante por desbordamiento (FE_OVERFLOW).
Error de rango, subdesbordamiento
errno se establece en ERANGE. Se eleva una excepción de punto flotante por subdesbordamiento (FE_UNDERFLOW).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
scalbn (), scalbnf (), scalbnl (), scalbln (), scalblnf (), scalblnl () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIAL

glibc 2.1. C99, POSIX.1-2001.

HISTORIAL

Estas funciones difieren de las funciones obsoletas descritas en scalb(3) en el tipo de su segundo argumento. Las funciones descritas en esta página tienen un segundo argumento de tipo integral, mientras que las de scalb(3) tienen un segundo argumento de tipo double.

NOTAS

Si FLT_RADIX es igual a 2 (lo cual es habitual), entonces scalbn() es equivalente a ldexp(3).

ERRORES

Antes de glibc 2.20, estas funciones no establecían errno para errores de rango.

VER TAMBIÉN

ldexp(3), scalb(3)
