SCHKST

Propósito:

!>
!> SCHKST  comprueba las rutinas del problema de valores propios simétricos.
!>
!>    SSYTRD factoriza A como  U S U' , donde ' significa transpuesta,
!>    S es simétrica tridiagonal, y U es ortogonal.
!>    SSYTRD puede usar solo la parte triangular inferior o solo la superior
!>    de A; SCHKST comprueba ambos casos.
!>    U se representa como un producto de transformaciones de Householder,
!>    cuyos vectores se almacenan en las primeras n-1 columnas de V, y cuyos
!!    factores de escala están en TAU.
!>
!>    SSPTRD hace lo mismo que SSYTRD, excepto que A y V se almacenan
!>    en formato  .
!>
!>    SORGTR construye la matriz U a partir del contenido de V y TAU.
!>
!>    SOPGTR construye la matriz U a partir del contenido de VP y TAU.
!>
!>    SSTEQR factoriza S como  Z D1 Z' , donde Z es la matriz ortogonal
!>    de los vectores propios y D1 es una matriz diagonal con los valores
!>    propios en la diagonal.  D2 es la matriz de valores propios calculada
!>    cuando no se calcula Z.
!>
!>    SSTERF calcula D3, la matriz de valores propios, mediante el
!>    método PWK, que no produce vectores propios.
!>
!>    SPTEQR factoriza S como  Z4 D4 Z4' , para una
!>    matriz tridiagonal simétrica definida positiva.
!>    D5 es la matriz de valores propios calculada cuando no se calcula Z.
!>
!>    SSTEBZ calcula valores propios seleccionados.  WA1, WA2, y
!>    WA3 denotarán valores propios calculados con alta
!>    precisión absoluta, con diferentes opciones de rango.
!>    WR denotará valores propios calculados con alta precisión relativa.
!>
!>    SSTEIN calcula Y, los vectores propios de S, dados los
!>    valores propios.
!>
!>    SSTEDC factoriza S como Z D1 Z' , donde Z es la matriz ortogonal
!>    de vectores propios y D1 es una matriz diagonal con los valores
!>    propios en la diagonal (opción 'I'). También puede actualizar
!>    una matriz ortogonal de entrada, usualmente la salida
!>    de SSYTRD/SORGTR o SSPTRD/SOPGTR (opción 'V'). También puede
!>    solo calcular valores propios (opción 'N').
!>
!>    SSTEMR factoriza S como Z D1 Z' , donde Z es la matriz ortogonal
!>    de vectores propios y D1 es una matriz diagonal con los valores
!>    propios en la diagonal (opción 'I'). SSTEMR usa la
!>    Representación Relativamente Robusta siempre que es posible.
!>
!> Cuando se llama a SCHKST, se especifica un número de tamaños de matriz
!> () y un número de tipos de matriz. Para cada tamaño ()
!> y cada tipo de matriz, se generará y utilizará una matriz
!> para probar las rutinas de valores propios simétricos. Para cada matriz,
!> se realizarán una serie de pruebas:
!>
!> (1)     | A - V S V' | / ( |A| n ulp ) SSYTRD( UPLO='U', ... )
!>
!> (2)     | I - UV' | / ( n ulp )        SORGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V' | / ( |A| n ulp ) SSYTRD( UPLO='L', ... )
!>
!> (4)     | I - UV' | / ( n ulp )        SORGTR( UPLO='L', ... )
!>
!> (5-8)   Igual que 1-4, pero para SSPTRD y SOPGTR.
!>
!> (9)     | S - Z D Z' | / ( |S| n ulp ) SSTEQR('V',...)
!>
!> (10)    | I - ZZ' | / ( n ulp )        SSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        SSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        SSTERF
!>
!> (13)    0 si los valores propios verdaderos (calculados por conteo de sturm)
!>         de S están dentro de THRESH de
!>         aquellos en D1.  2*THRESH si no lo están. (Probado usando
!>         SSTECH)
!>
!> Para S definida positiva,
!>
!> (14)    | S - Z4 D4 Z4' | / ( |S| n ulp ) SPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4' | / ( n ulp )        SPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       SPTEQR('N',...)
!>
!> Cuando S también es dominante por la diagonal en el factor gamma < 1,
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              SSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          SSTEBZ( 'A', 'E', ...)
!>
!> (19)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>                                              SSTEBZ( 'I', 'E', ...)
!>
!> (20)    | S - Y WA1 Y' | / ( |S| n ulp )  SSTEBZ, SSTEIN
!>
!> (21)    | I - Y Y' | / ( n ulp )          SSTEBZ, SSTEIN
!>
!> (22)    | S - Z D Z' | / ( |S| n ulp )    SSTEDC('I')
!>
!> (23)    | I - ZZ' | / ( n ulp )           SSTEDC('I')
!>
!> (24)    | S - Z D Z' | / ( |S| n ulp )    SSTEDC('V')
!>
!> (25)    | I - ZZ' | / ( n ulp )           SSTEDC('V')
!>
!> (26)    | D1 - D2 | / ( |D1| ulp )           SSTEDC('V') y
!>                                              SSTEDC('N')
!>
!> La prueba 27 está deshabilitada en este momento porque SSTEMR no
!> garantiza alta precisión relativa.
!>
!> (27)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              SSTEMR('V', 'A')
!>
!> (28)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              SSTEMR('V', 'I')
!>
!> Las pruebas 29 a 34 están deshabilitadas actualmente porque SSTEMR
!> no maneja solicitudes de espectro parcial.

!> (30)    | I - ZZ' | / ( n ulp )           SSTEMR('V', 'I')

!>            i     j

!> (32)    | S - Z D Z' | / ( |S| n ulp )    SSTEMR('V', 'V')
!>
!> (33)    | I - ZZ' | / ( n ulp )           SSTEMR('V', 'V')

!>            i     j

!>

!>
!> (36)    | I - ZZ' | / ( n ulp )           SSTEMR('V', 'A')
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          SCHKST no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es un arreglo INTEGER, de dimensión (NSIZES)
!>          Un arreglo que contiene los tamaños que se utilizarán para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SCHKST
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que consiste en usar la matriz que esté en A. Esto
!>          sólo es útil si DOTYPE(1:MAXTYP) es .FALSO. y
!>          DOTYPE(MAXTYP+1) es .VERDADERO. .
!>

DOTYPE

!>          DOTYPE es un arreglo LOGICAL, de dimensión (NTYPES)
!>          Si DOTYPE(j) es .VERDADERO., entonces para cada tamaño en NN, se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          se ignorarán.
!>

ISEED

!>          ISEED es un arreglo INTEGER, de dimensión (4)
!>          A la entrada, ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del arreglo deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto,
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican a la salida y pueden usarse en la
!>          siguiente llamada a SCHKST para continuar la misma secuencia de números
!>          aleatorios.
!>

THRESH

!>          THRESH es REAL
!>          Una prueba se considerará como si el , calculado como
!>          se describe anteriormente, excede THRESH. Tenga en cuenta que el error
!>          se escala para ser O(1), por lo que THRESH debe ser un múltiplo razonablemente
!>          pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple o doble)
!>          ni del tamaño de la matriz. Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0.)

NAME

SCHKST — Checks the subroutine STEST.

SYNOPSIS

 SUBROUTINE SCHKST(
  NMAX, NN, NSIZES, NTYPES, THRESH, A, LDA, U, LDU, IWORK, LWORK, RESULT,
  INFO )
 CHARACTER(LEN=*) :: NN(*)
 INTEGER :: NMAX, NSIZES, NTYPES, LDA, LDU, LWORK, INFO
 REAL :: THRESH, A( LDA, * ), U( LDU, * ), RESULT( * )
 INTEGER :: IWORK( * )

Function/Subroutine Documentation

Purpose:

 SCHKST checks the subroutine STEST.

Arguments:

  NMAX    (input) INTEGER
          The maximum value in NN.
          NMAX must be at least 1.
          NMAX must be large enough that NMAX = max( NN(j) ) for
          all j.
          NMAX must be large enough to test the routines.
          In particular, if some NN(j) requires a matrix of
          dimension N, then NMAX >= N.
          NMAX can be 0 if NSIZES = 0.
          NMAX is computed from NN and must satisfy
          NMAX >= 1.

  NN      (input) CHARACTER array, dimension (NSIZES)
          The sizes of the matrices to be generated.
          NN(j) contains the size of the j-th matrix to be generated.
          The value of NN(j) is either an integer (e.g. '100') or
          'max'. If NN(j) = 'max', the matrix size is NMAX.
          NN(j) must be non-negative.

  NSIZES  (input) INTEGER
          The number of matrix sizes to be generated.
          NSIZES must be non-negative.

  NTYPES  (input) INTEGER
          The number of matrix types to be generated.
          NTYPES must be non-negative.

  THRESH  (input) REAL
          A threshold for the test ratios. A test ratio is accepted
          if it is less than or equal to THRESH, and ignored otherwise.
          The test ratio is defined as the computed error divided by
          the expected error.
          THRESH must be non-negative.

  A       (workspace) REAL array, dimension (LDA, NMAX)
          This is the matrix whose eigenvalues are to be computed.

  LDA     (input) INTEGER
          The leading dimension of the array A.
          LDA must be at least 1 and at least NMAX.

  U       (workspace) REAL array, dimension (LDU, NMAX)
          This array is used for the orthogonal matrix Q.

  LDU     (input) INTEGER
          The leading dimension of the array U.
          LDU must be at least 1 and at least NMAX.

  IWORK   (workspace) INTEGER array, dimension (LWORK)
          The size of IWORK must be at least
          6 + 6*Nmax + 5 * Nmax * lg Nmax
          where Nmax = max( NN(j), 2 ) and lg = log base 2.

  LWORK   (input) INTEGER
          The size of the work array IWORK. This must be at least
          6 + 6*Nmax + 5 * Nmax * lg Nmax
          where Nmax = max( NN(j), 2 ) and lg = log base 2.

  RESULT  (output) REAL array, dimension (26)
          The values computed by the tests described above.
          The values are currently limited to 1/ulp, to avoid
          overflow.

  INFO    (output) INTEGER
          If 0, then everything ran OK.
           -1: NSIZES < 0
           -2: Some NN(j) < 0
           -3: NTYPES < 0
           -5: THRESH < 0
           -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ).
          -23: LDU < 1 or LDU < NMAX.
          -29: LWORK too small.
          If  SLATMR, SLATMS, SSYTRD, SORGTR, SSTEQR, SSTERF,
              or SORMC2 returns an error code, the
              absolute value of it is returned.
