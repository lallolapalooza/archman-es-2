sched_rr_get_interval(2) Manual de llamadas al sistema sched_rr_get_interval(2)

NOMBRE

sched_rr_get_interval - obtener el intervalo SCHED_RR para el proceso nombrado

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sched.h>
int sched_rr_get_interval(pid_t pid, struct timespec *tp);

DESCRIPCIÓN

sched_rr_get_interval() escribe en la estructura timespec(3) apuntada por tp el quantum de tiempo round-robin para el proceso identificado por pid. El proceso especificado debe estar ejecutándose bajo la política de planificación SCHED_RR.

Si pid es cero, el quantum de tiempo para el proceso que llama se escribe en *tp.

VALOR DE RETORNO

En caso de éxito, sched_rr_get_interval() devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
Problema con la copia de información al espacio de usuario.
EINVAL
pid inválido.
ENOSYS
La llamada al sistema aún no está implementada (solo en kernels bastante antiguos).
ESRCH
No se pudo encontrar un proceso con el ID pid.

VERSIONES

Linux

Linux 3.9 añadió un nuevo mecanismo para ajustar (y ver) el quantum de SCHED_RR: el archivo /proc/sys/kernel/sched_rr_timeslice_ms expone el quantum como un valor en milisegundos, cuyo valor predeterminado es 100. Escribir 0 en este archivo restablece el quantum al valor predeterminado.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.

Linux

POSIX no especifica ningún mecanismo para controlar el tamaño del quantum de tiempo round-robin. Los kernels de Linux anteriores proporcionan un método (no portátil) para hacerlo. El quantum se puede controlar ajustando el valor de "nice" del proceso (ver setpriority(2)). Asignar un valor de "nice" negativo (es decir, alto) resulta en un quantum más largo; asignar un valor de "nice" positivo (es decir, bajo) resulta en un quantum más corto. El quantum predeterminado es 0.1 segundos; el grado en que cambiar el valor de "nice" afecta al quantum ha variado algo en las diferentes versiones del kernel. Este método de ajustar el quantum se eliminó a partir de Linux 2.6.24.

NOTAS

Los sistemas POSIX en los que está disponible sched_rr_get_interval() definen _POSIX_PRIORITY_SCHEDULING en <unistd.h>.

VéASE TAMBIÉN
