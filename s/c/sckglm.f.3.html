Documentación de la Función/Subrutina

subroutine sckglm (integer nn, integer, dimension( * ) mval, integer, dimension( * ) pval, integer, dimension( * ) nval, integer nmats, integer, dimension( 4 ) iseed, real thresh, integer nmax, real, dimension( * ) a, real, dimension( * ) af, real, dimension( * ) b, real, dimension( * ) bf, real, dimension( * ) x, real, dimension( * ) work, real, dimension( * ) rwork, integer nin, integer nout, integer info)

SCKGLM

Propósito:

!>
!> SCKGLM prueba SGGGLM - subrutina para resolver el problema del modelo
!> lineal generalizado.
!>

Parámetros

NN 
!>          NN es INTEGER
!>          El número de valores de N, M y P contenidos en los vectores
!>          NVAL, MVAL y PVAL.
!>

MVAL

!>          MVAL es un array INTEGER, dimension (NN)
!>          Los valores de la dimensión M de las columnas de la matriz.
!>

PVAL

!>          PVAL es un array INTEGER, dimension (NN)
!>          Los valores de la dimensión P de las columnas de la matriz.
!>

NVAL

!>          NVAL es un array INTEGER, dimension (NN)
!>          Los valores de la dimensión N de las filas de la matriz.
!>

NMATS

!>          NMATS es INTEGER
!>          El número de tipos de matrices a probar para cada combinación
!>          de dimensiones de matriz. Si NMATS >= NTYPES (el número máximo
!>          de tipos de matrices), entonces se generan todos los tipos
!>          diferentes para la prueba. Si NMATS < NTYPES, se lee otra línea
!>          de entrada para obtener los números de los tipos de matrices a
!>          utilizar.
!>

ISEED

!>          ISEED es un array INTEGER, dimension (4)
!>          En la entrada, la semilla del generador de números aleatorios. Los
!>          elementos del array deben estar entre 0 y 4095, de lo contrario se
!>          reducirán módulo 4096, y ISEED(4) debe ser impar.
!>          En la salida, la siguiente semilla en la secuencia de números
!>          aleatorios después de que todas las matrices de prueba se hayan
!>          generado.
!>

THRESH

!>          THRESH es REAL
!>          El valor umbral para las ratios de prueba. Un resultado se
!>          incluye en el archivo de salida si RESID >= THRESH. Para que
!>          cada ratio de prueba se imprima, use THRESH = 0.
!>

NMAX

!>          NMAX es INTEGER
!>          El valor máximo permitido para M o N, utilizado en la
!>          dimensionamiento de los arrays de trabajo.
!>

A

!>          A es un array REAL, dimension (NMAX*NMAX)
!>

AF

!>          AF es un array REAL, dimension (NMAX*NMAX)
!>

B

!>          B es un array REAL, dimension (NMAX*NMAX)
!>

BF

!>          BF es un array REAL, dimension (NMAX*NMAX)
!>

X

!>          X es un array REAL, dimension (4*NMAX)
!>

RWORK

!>          RWORK es un array REAL, dimension (NMAX)
!>

WORK

!>          WORK es un array REAL, dimension (NMAX*NMAX)
!>

NIN

!>          NIN es INTEGER
!>          El número de unidad para la entrada.
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>

INFO

!>          INFO es INTEGER
!>          = 0 :  salida exitosa
!>          > 0 :  Si SLATMS devuelve un código de error, se devuelve su
!>                 valor absoluto.
!>
