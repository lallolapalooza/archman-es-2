subroutine scsdts (integer m, integer p, integer q, real, dimension( ldx, * ) x, real, dimension( ldx, * ) xf, integer ldx, real, dimension( ldu1, * ) u1, integer ldu1, real, dimension( ldu2, * ) u2, integer ldu2, real, dimension( ldv1t, * ) v1t, integer ldv1t, real, dimension( ldv2t, * ) v2t, integer ldv2t, real, dimension( * ) theta, integer, dimension( * ) iwork, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( 15 ) result)

SCSDTS

Propósito:

!>
!> SCSDTS prueba SORCSD, que, dada una matriz ortogonal particionada X de M por M
!>       Q  M-Q
!>       X = [ X11 X12 ] P   ,
!>           [ X21 X22 ] M-P
!>
!> calcula la CSD (Canonical Synoptic Decomposition)
!>
!>       [ U1    ]**T * [ X11 X12 ] * [ V1    ]
!>       [    U2 ]      [ X21 X22 ]   [    V2 ]
!>
!>                             [  I  0  0 |  0  0  0 ]
!>                             [  0  C  0 |  0 -S  0 ]
!>                             [  0  0  0 |  0  0 -I ]
!>                           = [---------------------] = [ D11 D12 ] .
!>                             [  0  0  0 |  I  0  0 ]   [ D21 D22 ]
!>                             [  0  S  0 |  0  C  0 ]
!>                             [  0  0  I |  0  0  0 ]
!>
!> y también SORCSD2BY1, que, dada
!>          Q
!>       [ X11 ] P   ,
!>       [ X21 ] M-P
!>
!> calcula la CSD 2x1
!>
!>                                     [  I  0  0 ]
!>                                     [  0  C  0 ]
!>                                     [  0  0  0 ]
!>       [ U1    ]**T * [ X11 ] * V1 = [----------] = [ D11 ] ,
!>       [    U2 ]      [ X21 ]        [  0  0  0 ]   [ D21 ]
!>                                     [  0  S  0 ]
!>                                     [  0  0  I ]
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz X.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz X11.  P >= 0.
!>

Q

!>          Q es INTEGER
!>          El número de columnas de la matriz X11.  Q >= 0.
!>

X

!>          X es array REAL, dimension (LDX,M)
!>          La matriz X de M por M.
!>

XF

!>          XF es array REAL, dimension (LDX,M)
!>          Detalles de la CSD de X, como la devuelve SORCSD;
!>          ver SORCSD para más detalles.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal de los arrays X y XF.
!>          LDX >= max( 1,M ).
!>

U1

!>          U1 es array REAL, dimension(LDU1,P)
!>          La matriz ortogonal U1 de P por P.
!>

LDU1

!>          LDU1 es INTEGER
!>          La dimensión principal del array U1. LDU >= max(1,P).
!>

U2

!>          U2 es array REAL, dimension(LDU2,M-P)
!>          La matriz ortogonal U2 de (M-P) por (M-P).
!>

LDU2

!>          LDU2 es INTEGER
!>          La dimensión principal del array U2. LDU >= max(1,M-P).
!>

V1T

!>          V1T es array REAL, dimension(LDV1T,Q)
!>          La matriz ortogonal V1T de Q por Q.
!>

LDV1T

!>          LDV1T es INTEGER
!>          La dimensión principal del array V1T. LDV1T >=
!>          max(1,Q).
!>

V2T

!>          V2T es array REAL, dimension(LDV2T,M-Q)
!>          La matriz ortogonal V2T de (M-Q) por (M-Q).
!>

LDV2T

!>          LDV2T es INTEGER
!>          La dimensión principal del array V2T. LDV2T >=
!>          max(1,M-Q).
!>

THETA

!>          THETA es array REAL, dimension MIN(P,M-P,Q,M-Q)
!>          Los valores CS de X; las matrices diagonales esenciales C y
!>          S se construyen a partir de THETA; ver la subrutina SORCSD para
!>          detalles.
!>

IWORK

!>          IWORK es array INTEGER, dimension (M)
!>

WORK

!>          WORK es array REAL, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK
!>

RWORK

!>          RWORK es array REAL
!>

RESULT

!>          RESULT es array REAL, dimension (15)
!>          Las razones de prueba:
!>          Primero, la CSD 2x2:
!>          RESULT(1) = norm( U1'*X11*V1 - D11 ) / ( MAX(1,P,Q)*EPS2 )
!>          RESULT(2) = norm( U1'*X12*V2 - D12 ) / ( MAX(1,P,M-Q)*EPS2 )
!>          RESULT(3) = norm( U2'*X21*V1 - D21 ) / ( MAX(1,M-P,Q)*EPS2 )
!>          RESULT(4) = norm( U2'*X22*V2 - D22 ) / ( MAX(1,M-P,M-Q)*EPS2 )
!>          RESULT(5) = norm( I - U1'*U1 ) / ( MAX(1,P)*ULP )
!>          RESULT(6) = norm( I - U2'*U2 ) / ( MAX(1,M-P)*ULP )
!>          RESULT(7) = norm( I - V1T'*V1T ) / ( MAX(1,Q)*ULP )
!>          RESULT(8) = norm( I - V2T'*V2T ) / ( MAX(1,M-Q)*ULP )
!>          RESULT(9) = 0        si THETA está en orden creciente y
!>                               todos los ángulos están en [0,pi/2]
!>                    = ULPINV   en caso contrario.
!>          Luego, la CSD 2x1:
!>          RESULT(10) = norm( U1'*X11*V1 - D11 ) / ( MAX(1,P,Q)*EPS2 )
!>          RESULT(11) = norm( U2'*X21*V1 - D21 ) / ( MAX(1,M-P,Q)*EPS2 )
!>          RESULT(12) = norm( I - U1'*U1 ) / ( MAX(1,P)*ULP )
!>          RESULT(13) = norm( I - U2'*U2 ) / ( MAX(1,M-P)*ULP )
!>          RESULT(14) = norm( I - V1T'*V1T ) / ( MAX(1,Q)*ULP )
!>          RESULT(15) = 0        si THETA está en orden creciente y
!>                               todos los ángulos están en [0,pi/2]
!>                     = ULPINV   en caso contrario.
!>          ( EPS2 = MAX( norm( I - X'*X ) / M, ULP ). )
!>

NAME

scsdts - SCMDRV - Mover para el controlador de disco de 16 bits en tiempo real de Scicos/Scilab

SYNOPSIS

void scsdts(int id, double *u, double *y, double *w, int neq, int t_mode)

Function/Subroutine Documentation

Esta subrutina es parte del controlador de disco de 16 bits en tiempo real de Scicos/Scilab.

Parámetros:

  • id: Un entero que representa el identificador único del bloque Scicos.
  • u: Un puntero a un arreglo de doubles que contiene las entradas del bloque.
  • y: Un puntero a un arreglo de doubles que contendrá las salidas del bloque.
  • w: Un puntero a un arreglo de doubles que contiene las variables de estado del bloque (variables de trabajo).
  • neq: Un entero que representa el número de ecuaciones diferenciales que el bloque está resolviendo (generalmente 0 para este tipo de bloque).
  • t_mode: Un entero que indica el modo de tiempo. Puede ser 0 para tiempo discreto o 1 para tiempo continuo.

Descripción:

La subrutina scsdts es el corazón del controlador de disco de 16 bits en tiempo real. Implementa la lógica para leer datos del disco y escribirlos en un buffer, y viceversa. Las entradas (u) típicamente representan comandos de control o datos a escribir, mientras que las salidas (y) representan el estado del disco, datos leídos o códigos de error.

Las variables de estado (w) se utilizan para mantener información interna del controlador, como punteros de archivo, estados de operaciones, contadores, etc. El parámetro id es crucial para que Scicos/Scilab pueda rastrear y actualizar correctamente el estado del bloque en el modelo.

El parámetro t_mode ayuda a la subrutina a adaptar su comportamiento según si el modelo se está ejecutando en un entorno de tiempo discreto o continuo, aunque para operaciones de E/S de disco, el comportamiento principal suele ser discreto.

La implementación específica de la lectura/escritura de disco, manejo de errores y comunicación con el hardware subyacente se realiza dentro de esta subrutina, basándose en las APIs del sistema operativo o bibliotecas específicas para el acceso al hardware de disco de 16 bits en tiempo real.
