SCHKLQ

Propósito:

!>
!> SCHKLQ prueba SGELQF, SORGLQ y SORMLQ.
!>

Parámetros

DOTYPE 
!>          DOTYPE es una matriz LOGICAL, dimensión (NTYPES)
!>          Los tipos de matriz a utilizar para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se utilizan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se utiliza.
!>

NM

!>          NM es INTEGER
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es una matriz INTEGER, dimensión (NM)
!>          Los valores de la dimensión de fila de la matriz M.
!>

NN

!>          NN es INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es una matriz INTEGER, dimensión (NN)
!>          Los valores de la dimensión de columna de la matriz N.
!>

NNB

!>          NNB es INTEGER
!>          El número de valores de NB y NX contenidos en los
!>          vectores NBVAL y NXVAL. Los parámetros de bloqueo se utilizan
!>          en pares (NB,NX).
!>

NBVAL

!>          NBVAL es una matriz INTEGER, dimensión (NNB)
!>          Los valores del tamaño de bloque NB.
!>

NXVAL

!>          NXVAL es una matriz INTEGER, dimensión (NNB)
!>          Los valores del punto de cruce NX.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de vectores del lado derecho a generar para
!>          cada sistema lineal.
!>

THRESH

!>          THRESH es REAL
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para tener
!>          cada relación de prueba impresa, use THRESH = 0.
!>

TSTERR

!>          TSTERR es LOGICAL
!>          Indicador que señala si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es INTEGER
!>          El valor máximo permitido para M o N, utilizado en la
!>          dimensionamiento de las matrices de trabajo.
!>

A

!>          A es una matriz REAL, dimensión (NMAX*NMAX)
!>

AF

!>          AF es una matriz REAL, dimensión (NMAX*NMAX)
!>

AQ

!>          AQ es una matriz REAL, dimensión (NMAX*NMAX)
!>

AL

!>          AL es una matriz REAL, dimensión (NMAX*NMAX)
!>

AC

!>          AC es una matriz REAL, dimensión (NMAX*NMAX)
!>

B

!>          B es una matriz REAL, dimensión (NMAX*NRHS)
!>

X

!>          X es una matriz REAL, dimensión (NMAX*NRHS)
!>

XACT

!>          XACT es una matriz REAL, dimensión (NMAX*NRHS)
!>

TAU

!>          TAU es una matriz REAL, dimensión (NMAX)
!>

WORK

!>          WORK es una matriz REAL, dimensión (NMAX*NMAX)
!>

RWORK

!>          RWORK es una matriz REAL, dimensión (NMAX)
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>
