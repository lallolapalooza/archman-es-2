ZSCAL scalara

NAME

zscal - scales a general complex vector by a general complex scalar.

SYNOPSIS

   SUBROUTINE ZSCAL(N, ZA, ZX, INCX)

N

N is INTEGER

on entry: N specifies the number of elements of the array ZX to be scaled.

Unchanged on exit.

ZA

ZA is COMPLEX*16

On entry: ZA specifies the scalar alpha.

ZX

ZX is COMPLEX*16 array, dimension ( 1 + ( N - 1 )*abs( INCX ) )

On entry: the vector ZX of dimension N.

On exit: the array ZX has been scaled by the scalar alpha.

INCX

INCX is INTEGER

On entry: INCX specifies the storage spacing between elements of ZX.

Unchanged on exit.

Detailed Description

zscal.f:77 This routine scales a general complex vector by a general complex scalar.

ZA

ZX

INCX

!>         storage spacing between elements of ZX
