NOMBRE

sconsign - imprime información del archivo de firma de SCons

SINOPSIS

sconsign [opciones...] [archivo...]

DESCRIPCIÓN

Muestra el contenido de uno o más archivos sconsign, la base de datos de firmas/dependencias utilizada por la herramienta de compilación SCons. La base de datos contiene todos los Nodos que son conocidos por la compilación, ya sea por declaración en la configuración de compilación, producidos como efectos secundarios o detectados por inspección.

Por defecto, sconsign vuelca todo el contenido de los archivos sconsign. Sin opciones, las entradas de dependencia individuales se imprimen en el siguiente formato:

archivo-dep: firma-contenido fecha longitud
        dependencia-implícita-1: firma-contenido fecha longitud
        dependencia-implícita-2: firma-contenido fecha longitud
        ...
        firma-compilacion [cadena-acción]

firma-contenido es el hash del contenido del archivo (csig) y firma-compilacion es el hash de la línea de comandos u otra acción de compilación utilizada para compilar un objetivo (bactsig). Si se proporciona, cadena-acción es la cadena de acción sin expandir o la función llamada. Se imprime None en lugar de cualquier fecha, csig o valor de bactsig faltante para cualquier entrada o cualquiera de sus dependencias. Si la entrada no tiene dependencias implícitas, o ninguna acción de compilación, las líneas correspondientes se omiten.

Se imprime una línea indicadora para cada directorio, ya que los directorios no tienen firmas en la base de datos y, por lo tanto, no se mostrarían de otra manera.

Por defecto, sconsign asume que cualquier argumento de archivo que termine con el sufijo .dblite contiene entradas de firma para más de un directorio (es decir, fue especificado por la función SCons SConsignFile). Se asume que cualquier argumento de archivo que no tenga sufijo es un archivo sconsign de estilo antiguo (obsoleto) que contiene las entradas de firma para un solo directorio. Si ninguna de esas condiciones se cumple, sconsign intenta adivinar el formato. Si eso no funciona, se puede especificar un formato explícito usando las opciones -f o --format=.

Si no hay argumentos de archivo, se asume el nombre .sconsign.dblite por defecto.

OPCIONES

Varias opciones controlan qué información se imprime y el formato:

-a, --act, --action

Imprime solo la información de la acción de compilación para todas las entradas o las entradas especificadas.

-c, --csig

Imprime solo la información de la firma de contenido (csig) para todas las entradas o las entradas especificadas.

-d DIRECTORIO, --dir=DIRECTORIO

Cuando las firmas se leen de un archivo .dblite, o se usan las opciones -f dblite o --format=dblite, imprime información solo sobre las firmas de las entradas en el DIRECTORIO especificado.

-e ENTRADA, --entry=ENTRADA

Imprime información solo sobre la ENTRADA especificada. Se pueden usar múltiples opciones -e, en cuyo caso se imprime información sobre cada ENTRADA en el orden en que se especifican las opciones en la línea de comandos.

-f FORMATO, --format=FORMATO

Los archivos que se imprimirán están en el FORMATO especificado. Los valores legales son dblite (el formato SCons.dblite usado por defecto, así como cuando se llama a la función SConsignFile, excepto cuando se da un argumento de nombre de archivo de None) y sconsign (el formato utilizado para un archivo .sconsign individual en cada directorio).

-h, --help

Imprime un mensaje de ayuda y sale.

-i, --implicit

Imprime la lista de dependencias implícitas almacenadas en caché para todas las entradas o para las entradas especificadas.

--raw

Imprime una representación formateada de forma legible del diccionario Python sin procesar que contiene información de compilación sobre entradas individuales (tanto la entrada en sí como sus dependencias implícitas). La acción de compilación de una entrada todavía se imprime en su formato habitual.

-r, --readable

Imprime las marcas de tiempo en una cadena legible por humanos, entre comillas simples.

-t, --timestamp

Imprime la información de la marca de tiempo para todas las entradas o las entradas especificadas.

-v, --verbose

Imprime etiquetas que identifican cada campo que se está imprimiendo.

AMBIENTE

SCONS_LIB_DIR

Especifica el directorio que contiene el directorio del módulo Python de SCons (por ejemplo, /home/aroach/scons-src/SCons).
