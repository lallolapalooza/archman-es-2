NOMBRE

scsi_stop - detiene (desacelera) uno o más discos SCSI

SINOPSIS

scsi_stop [--ayuda] [--verboso] [--esperar] DISPOSITIVO [DISPOSITIVO]*

DESCRIPCIÓN

Este script de shell bash llama a la utilidad sg_start en cada DISPOSITIVO dado. El propósito es desacelerar (detener) cada DISPOSITIVO dado.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-a, --ayuda
imprime el mensaje de uso y luego sale.
-v, --verboso
aumenta el nivel de verbosidad.
-e, --esperar
espera a que se complete la detención (desaceleración) en cada DISPOSITIVO dado. La acción predeterminada es realizar cada detención en modo inmediato.

NOTAS

La utilidad sg_start llama al comando SCSI START STOP UNIT y puede iniciar (acelerar) o detener (desacelerar) un disco SCSI dependiendo de las opciones de línea de comandos dadas.

ESTADO DE SALIDA

El estado de salida de este script es 0 cuando tiene éxito. De lo contrario, el estado de salida es el de la última utilidad sg_start llamada. Consulte la página del manual de sg3_utils(8).
