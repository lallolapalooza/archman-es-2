NOMBRE

scsi_start - inicia uno o más discos SCSI

SINOPSIS

scsi_start [--ayuda] [--verboso] [--esperar] DISPOSITIVO [DISPOSITIVO]*

DESCRIPCIÓN

Este script de shell bash llama a la utilidad sg_start en cada DISPOSITIVO dado. El propósito es poner en marcha (iniciar) cada DISPOSITIVO dado.

OPCIONES

Los argumentos para las opciones largas son obligatorios para las opciones cortas también.

-h, --ayuda
imprime el mensaje de uso y luego sale.
-v, --verboso
aumenta el nivel de verbosidad.
-w, --esperar
espera a que la puesta en marcha (inicio) en cada DISPOSITIVO dado se complete. La acción predeterminada es realizar cada inicio en modo inmediato.

NOTAS

Si se ponen en marcha un gran número de discos al mismo tiempo (es decir, sin la opción --esperar), la fuente de alimentación podría sobrecargarse.

ESTADO DE SALIDA

El estado de salida de este script es 0 cuando tiene éxito. De lo contrario, el estado de salida es el de la última utilidad sg_start llamada. Consulte la página del manual de sg3_utils(8).
