SCHKBD

Propósito:

!>
!> SCHKBD comprueba las rutinas de descomposición en valores singulares (SVD).
!>
!> SGEBRD reduce una matriz real general m por n, A, a forma bidiagonal superior o inferior B por una transformación ortogonal: Q' * A * P = B
!> (o A = Q * B * P'). La matriz B es bidiagonal superior si m >= n
!> y bidiagonal inferior si m < n.
!>
!> SORGBR genera las matrices ortogonales Q y P' de SGEBRD.
!> Nótese que Q y P no son necesariamente cuadradas.
!>
!> SBDSQR calcula la descomposición en valores singulares de la matriz bidiagonal
!> B como B = U S V'. Se llama tres veces para calcular
!>    1)  B = U S1 V', donde S1 es la matriz diagonal de valores singulares
!>        y las columnas de las matrices U y V son los vectores singulares izquierdos
!>        y derechos, respectivamente, de B.
!>    2)  Igual que 1), pero los valores singulares se almacenan en S2 y los
!>        vectores singulares no se calculan.
!>    3)  A = (UQ) S (P'V'), la SVD de la matriz original A.
!> Además, SBDSQR tiene una opción para aplicar la matriz ortogonal izquierda
!> U a una matriz X, útil en aplicaciones de mínimos cuadrados.
!>
!> SBDSDC calcula la descomposición en valores singulares de la matriz bidiagonal
!> B como B = U S V' usando divide y vencerás. Se llama dos veces para calcular
!>    1) B = U S1 V', donde S1 es la matriz diagonal de valores singulares
!>        y las columnas de las matrices U y V son los vectores singulares izquierdos
!>        y derechos, respectivamente, de B.
!>    2) Igual que 1), pero los valores singulares se almacenan en S2 y los
!>        vectores singulares no se calculan.
!>
!> SBDSVDX calcula la descomposición en valores singulares de la matriz bidiagonal
!> B como B = U S V' usando bisección e iteración inversa. Se llama seis veces para calcular
!>    1) B = U S1 V', RANGE='A', donde S1 es la matriz diagonal de valores singulares
!>        y las columnas de las matrices U y V son los vectores singulares izquierdos
!>        y derechos, respectivamente, de B.
!>    2) Igual que 1), pero los valores singulares se almacenan en S2 y los
!>        vectores singulares no se calculan.
!>    3) B = U S1 V', RANGE='I', donde S1 es la matriz diagonal de valores singulares
!>        y las columnas de las matrices U y V son los vectores singulares izquierdos
!>        y derechos, respectivamente, de B
!>    4) Igual que 3), pero los valores singulares se almacenan en S2 y los
!>        vectores singulares no se calculan.
!>    5) B = U S1 V', RANGE='V', donde S1 es la matriz diagonal de valores singulares
!>        y las columnas de las matrices U y V son los vectores singulares izquierdos
!>        y derechos, respectivamente, de B
!>    6) Igual que 5), pero los valores singulares se almacenan en S2 y los
!>        vectores singulares no se calculan.
!>
!> Para cada par de dimensiones de matriz (M,N) y cada tipo de matriz seleccionado,
!> se generan una matriz A de m por n y una matriz X de m por NRHS.
!> Las dimensiones del problema son las siguientes
!>    A:          M x N
!>    Q:          M x min(M,N) (pero M x M si NRHS > 0)
!>    P:          min(M,N) x N
!>    B:          min(M,N) x min(M,N)
!>    U, V:       min(M,N) x min(M,N)
!>    S1, S2      diagonal, orden min(M,N)
!>    X:          M x NRHS
!>
!> Para cada matriz generada, se realizan 14 pruebas:
!>
!> Prueba SGEBRD y SORGBR
!>
!> (1)   | A - Q B PT | / ( |A| max(M,N) ulp ), PT = P'
!>
!> (2)   | I - Q' Q | / ( M ulp )
!>
!> (3)   | I - PT PT' | / ( N ulp )
!>
!> Prueba SBDSQR en la matriz bidiagonal B
!>
!> (4)   | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!> (5)   | Y - U Z | / ( |Y| max(min(M,N),k) ulp ), donde Y = Q' X
!>                                                  y   Z = U' Y.
!> (6)   | I - U' U | / ( min(M,N) ulp )
!>
!> (7)   | I - VT VT' | / ( min(M,N) ulp )
!>
!> (8)   S1 contiene min(M,N) valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (9)   | S1 - S2 | / ( |S1| ulp ), donde S2 se calcula sin
!>                                   calcular U y V.
!>
!> (10)  0 si los verdaderos valores singulares de B están dentro de THRESH de
!>       aquellos en S1.  2*THRESH si no lo están.  (Comprobado usando
!>       SSVDCH)
!>
!> Prueba SBDSQR en la matriz A
!>
!> (11)  | A - (QU) S (VT PT) | / ( |A| max(M,N) ulp )
!>
!> (12)  | X - (QU) Z | / ( |X| max(M,k) ulp )
!>
!> (13)  | I - (QU)'(QU) | / ( M ulp )
!>
!> (14)  | I - (VT PT) (PT'VT') | / ( N ulp )
!>
!> Prueba SBDSDC en la matriz bidiagonal B
!>
!> (15)  | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!> (16)  | I - U' U | / ( min(M,N) ulp )
!>
!> (17)  | I - VT VT' | / ( min(M,N) ulp )
!>
!> (18)  S1 contiene min(M,N) valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (19)  | S1 - S2 | / ( |S1| ulp ), donde S2 se calcula sin
!>                                   calcular U y V.
!>  Prueba SBDSVDX en la matriz bidiagonal B
!>
!>  (20)  | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!>  (21)  | I - U' U | / ( min(M,N) ulp )
!>
!>  (22)  | I - VT VT' | / ( min(M,N) ulp )
!>
!>  (23)  S1 contiene min(M,N) valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!>  (24)  | S1 - S2 | / ( |S1| ulp ), donde S2 se calcula sin
!>                                    calcular U y V.
!>
!>  (25)  | S1 - U' B VT' | / ( |S| n ulp )    SBDSVDX('V', 'I')
!>
!>  (26)  | I - U' U | / ( min(M,N) ulp )
!>
!>  (27)  | I - VT VT' | / ( min(M,N) ulp )
!>
!>  (28)  S1 contiene min(M,N) valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!>  (29)  | S1 - S2 | / ( |S1| ulp ), donde S2 se calcula sin
!>                                    calcular U y V.
!>
!>  (30)  | S1 - U' B VT' | / ( |S1| n ulp )   SBDSVDX('V', 'V')
!>
!>  (31)  | I - U' U | / ( min(M,N) ulp )
!>
!>  (32)  | I - VT VT' | / ( min(M,N) ulp )
!>
!>  (33)  S1 contiene min(M,N) valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!>  (34)  | S1 - S2 | / ( |S1| ulp ), donde S2 se calcula sin
!>                                    calcular U y V.
!>
!> Los tipos de matriz posibles son
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>      1, ..., ULP  y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4)  Una matriz diago

SCHKBD

SCHKBD - checks the nonsymmetric reduction routines SBDSQR and

SYNOPSIS

SUBROUTINE SCHKBD(
   NSIZES, MVAL, NVAL, NTYPES, DOTYPE, NRHS, ISEED, THRESH,
   A, LDA, BD, BE, S1, S2, X, LDX, Y, Z, Q, LDQ, PT, LDPT, U, VT,
   WORK, LWORK, IWORK, NOUT, INFO )

Parameters

NSIZES

NSIZES is INTEGER
The number of values of M and N contained in the vectors
MVAL and NVAL. The matrix sizes are used in pairs (M,N).

MVAL

MVAL is INTEGER array, dimension (NM)
The values of the matrix row dimension M.

NVAL

NVAL is INTEGER array, dimension (NM)
The values of the matrix column dimension N.

NTYPES

NTYPES is INTEGER
The number of elements in DOTYPE. If it is zero, SCHKBD
does nothing. It must be at least zero. If it is MAXTYP+1
and NSIZES is 1, then an additional type, MAXTYP+1 is
defined, which is to use whatever matrices are in A and B.
This is only useful if DOTYPE(1:MAXTYP) is .FALSE. and
DOTYPE(MAXTYP+1) is .TRUE. .

DOTYPE

DOTYPE is LOGICAL array, dimension (NTYPES)
If DOTYPE(j) is .TRUE., then for each size (m,n), a matrix
of type j will be generated. If NTYPES is smaller than the
maximum number of types defined (PARAMETER MAXTYP), then
types NTYPES+1 through MAXTYP will not be generated. If
NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through
DOTYPE(NTYPES) will be ignored.

NRHS

NRHS is INTEGER
The number of columns in the matrices X, Y, and Z, used in
testing SBDSQR. If NRHS = 0, then the operations on the
right-hand side will not be tested. NRHS must be at least 0.

ISEED

ISEED is INTEGER array, dimension (4)
On entry ISEED specifies the seed of the random number
generator. The array elements should be between 0 and 4095;
if not they will be reduced mod 4096. Also, ISEED(4) must
be odd. The values of ISEED are changed on exit, and can be
used in the next call to SCHKBD to continue the same random
number sequence.

THRESH

THRESH is REAL
The threshold value for the test ratios. A result is
included in the output file if RESULT >= THRESH. To have
every test ratio printed, use THRESH = 0. Note that the
expected value of the test ratios is O(1), so THRESH should
be a reasonably small multiple of 1, e.g., 10 or 100.

A

A is REAL array, dimension (LDA,NMAX)
where NMAX is the maximum value of N in NVAL.

LDA

LDA is INTEGER
The leading dimension of the array A. LDA >= max(1,MMAX),
where MMAX is the maximum value of M in MVAL.

BD

BD is REAL array, dimension
(max(min(MVAL(j),NVAL(j))))

BE

BE is REAL array, dimension
(max(min(MVAL(j),NVAL(j))))

S1

S1 is REAL array, dimension
(max(min(MVAL(j),NVAL(j))))

S2

S2 is REAL array, dimension
(max(min(MVAL(j),NVAL(j))))

X

X is REAL array, dimension (LDX,NRHS)

LDX

LDX is INTEGER
The leading dimension of the arrays X, Y, and Z.
LDX >= max(1,MMAX)

Y

Y is REAL array, dimension (LDX,NRHS)

Z

Z is REAL array, dimension (LDX,NRHS)

Q

Q is REAL array, dimension (LDQ,MMAX)

LDQ

LDQ is INTEGER
The leading dimension of the array Q. LDQ >= max(1,MMAX).

PT

PT is REAL array, dimension (LDPT,NMAX)

LDPT

LDPT is INTEGER
The leading dimension of the arrays PT, U, and V.
LDPT >= max(1, max(min(MVAL(j),NVAL(j)))).

U

U is REAL array, dimension
(LDPT,max(min(MVAL(j),NVAL(j))))

VT

VT is REAL array, dimension
(LDPT,max(min(MVAL(j),NVAL(j))))

WORK

WORK is REAL array, dimension (LWORK)

LWORK

LWORK is INTEGER
The number of entries in WORK. This must be at least
3(M+N) and M(M + max(M,N,k) + 1) + N*min(M,N) for all
pairs (M,N)=(MM(j),NN(j))

IWORK

IWORK is INTEGER array, dimension at least 8*min(M,N)

NOUT

NOUT is INTEGER
The FORTRAN unit number for printing out error messages
(e.g., if a routine returns IINFO not equal to 0.)

INFO

INFO is INTEGER
If 0, then everything ran OK.
-1: NSIZES < 0
-2: Some MM(j) < 0
-3: Some NN(j) < 0
-4: NTYPES < 0
-6: NRHS  < 0
-8: THRESH < 0
-11: LDA < 1 or LDA < MMAX, where MMAX is max( MM(j) ).
-17: LDB < 1 or LDB < MMAX.
-21: LDQ < 1 or LDQ < MMAX.
-23: LDPT< 1 or LDPT< MNMAX.
-27: LWORK too small.
If SLATMR, SLATMS, SGEBRD, SORGBR, or SBDSQR,
returns an error code, the
absolute value of it is returned.

schkbd(3)

schkbd - Configura la tabla de códigos de teclado.

SINOPSIS

#include <kbd.h>

int schkbd(struct keyboard *kb);

DESCRIPCIÓN

La función schkbd establece la tabla de códigos de teclado proporcionada por kb.

VALOR DE RETORNO

En caso de éxito, schkbd devuelve 0. En caso de error, devuelve -1 y establece errno apropiadamente.

ERRORES

EINVAL
El argumento kb no es válido.
