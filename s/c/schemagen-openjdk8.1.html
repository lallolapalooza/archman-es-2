NOMBRE

schemagen - Genera un esquema para cada espacio de nombres que se referencia en tus clases Java.

SINOPSIS

schemagen [ opciones ] archivos-java
opciones
Las opciones de la línea de comandos. Ver Opciones.
archivos-java
Los archivos de clase Java a procesar.

DESCRIPCIÓN

El generador de esquemas crea un archivo de esquema para cada espacio de nombres referenciado en tus clases Java. Actualmente, no puedes controlar el nombre de los archivos de esquema generados. Para controlar los nombres de los archivos de esquema, consulta Usando SchemaGen con Ant en http://jaxb.java.net/nonav/2.2.3u1/docs/schemagenTask.html

Inicia el generador de esquemas con el script de shell schemagen apropiado en el directorio bin para tu plataforma. El generador de esquemas actual puede procesar archivos fuente de Java o archivos de clase.

schemagen.sh Foo.java Bar.java ...
Nota: Escribiendo schema1.xsd

Si tus archivos Java referencian otras clases, entonces esas clases deben ser accesibles en la variable de entorno CLASSPATH de tu sistema, o deben especificarse en la línea de comandos de schemagen con las opciones de ruta de clases. Ver Opciones. Si los archivos referenciados no son accesibles o no se especifican, obtendrás errores al generar el esquema.

OPCIONES

-d ruta

La ubicación donde el comando schemagen coloca los archivos de clase generados por el procesador y por javac.
-cp ruta

La ubicación donde el comando schemagen coloca los archivos especificados por el usuario.
-classpath ruta

La ubicación donde el comando schemagen coloca los archivos especificados por el usuario.
-encoding codificación

Especifica la codificación a usar para las invocaciones del comando apt o javac.
-episode archivo

Genera un archivo de episodio para compilación separada.
-version

Muestra información de la versión.
-help

Muestra un mensaje de ayuda.
