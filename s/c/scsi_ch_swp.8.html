SCSI_CH_SWP(8) SDPARM SCSI_CH_SWP(8)

NOMBRE

scsi_ch_swp - cambiar la protección contra escritura por software (SWP) de SCSI y la configuración del dispositivo de bloque

SINOPSIS

scsi_ch_swp [--help] [--set 0|1] [--verbose] [--wr] BLK_DEVICE

DESCRIPCIÓN

Este script de shell bash intenta leer o cambiar el bit de Protección contra Escritura por Software (SWP) en la página de modo de Control utilizando la utilidad sdparm. Si ese cambio es exitoso, utiliza la utilidad blockdev para cambiar la configuración de lectura/escritura o solo lectura de BLK_DEVICE en simpatía. Este script solo está disponible en Linux ya que la utilidad blockdev es específica de Linux.

Si el cambio del bit SWP es compatible, establecer el bit SWP hace que BLK_DEVICE sea de solo lectura en el propio dispositivo (disco). Borrar el bit SWP hace que BLK_DEVICE sea de lectura/escritura, que suele ser la configuración predeterminada al encender el dispositivo (disco).

Si no se proporcionan opciones, se imprime el estado actual del bit SWP (usando sdparm) junto con el bit RO de blockdev. Si ambos son 1, entonces BLK_DEVICE está en modo de solo lectura; si ambos son 0, entonces BLK_DEVICE está en modo de lectura/escritura.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-h, --help
imprime el mensaje de uso y luego sale.
-s, --set 0|1
cuando se proporciona 0, se borra el bit SWP en la página de modo de Control (es decir, se establece ese bit a 0) usando sdparm; y se usa blockdev para establecer BLK_DEVICE en modo de lectura/escritura. Cuando se proporciona 1, se establece el bit SWP en la página de modo de Control usando sdparm; y se usa blockdev para establecer BLK_DEVICE en modo de solo lectura. El valor predeterminado (es decir, cuando esta opción no se proporciona) es leer el estado del bit SWP y el modo de solo lectura de BLK_DEVICE e imprimir esos valores.
-v, --verbose
aumenta el nivel de verbosidad.
-w, --wr
cuando BLK_DEVICE está en modo de solo lectura, Linux normalmente no permitirá que BLK_DEVICE se abra en modo lectura/escritura por sdparm, por lo que la acción predeterminada de este script es usar la opción --readonly de sdparm cuando se ha invocado --set 0. Es posible que BLK_DEVICE sea un dispositivo genérico (por ejemplo, /dev/sg3) que tenga una interpretación diferente de la bandera de apertura de solo lectura y pueda fallar. Para esos casos raros, la opción --wr hace que sdparm abra BLK_DEVICE en modo lectura/escritura cuando se invoca --set 0.

CÓDIGO DE SALIDA

El código de salida de este script es 0 cuando tiene éxito. De lo contrario, el código de salida será el de la utilidad sdparm o blockdev, la que se llame por última vez. Consulte la página del manual de sdparm(8).
