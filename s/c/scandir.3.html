scandir(3) Manual de Funciones de Biblioteca scandir(3)

NOMBRE

scandir, scandirat, alphasort, versionsort - escanear un directorio en busca de entradas coincidentes

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <dirent.h>
int scandir(const char *restrict dirp,
            struct dirent ***restrict namelist,
            typeof(int (const struct dirent *)) *filter,
            typeof(int (const struct dirent **, const struct dirent **))
                *compar);
int alphasort(const struct dirent **a, const struct dirent **b);
int versionsort(const struct dirent **a, const struct dirent **b);
#include <fcntl.h>          /* Definición de constantes AT_* */
#include <dirent.h>
int scandirat(int dirfd, const char *restrict dirp,
            struct dirent ***restrict namelist,
            typeof(int (const struct dirent *)) *filter,
            typeof(int (const struct dirent **, const struct dirent **))
                *compar);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

scandir(), alphasort():

    /* Desde glibc 2.10: */ _POSIX_C_SOURCE >= 200809L
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

versionsort():

    _GNU_SOURCE

scandirat():

    _GNU_SOURCE

DESCRIPCIÓN

La función scandir() escanea el directorio dirp, llamando a filter() en cada entrada del directorio. Las entradas para las cuales filter() devuelve un valor distinto de cero se almacenan en cadenas asignadas con malloc(3), se ordenan usando qsort(3) con la función de comparación compar(), y se recopilan en el array namelist que se asigna con malloc(3). Si filter es NULL, se seleccionan todas las entradas.

Las funciones alphasort() y versionsort() se pueden usar como la función de comparación compar(). La primera ordena las entradas del directorio usando strcoll(3), la segunda usando strverscmp(3) en las cadenas (*a)->d_name y (*b)->d_name.

scandirat()

La función scandirat() opera exactamente de la misma manera que scandir(), excepto por las diferencias que se describen aquí.

Si dirp es relativo, entonces se interpreta en relación con el directorio al que se refiere el descriptor de archivo dirfd (en lugar de en relación con el directorio de trabajo actual del proceso llamador, como lo hace scandir() para una ruta relativa).

Si dirp es relativo y dirfd es el valor especial AT_FDCWD, entonces dirp se interpreta en relación con el directorio de trabajo actual del proceso llamador (como scandir()).

Si dirp es absoluto, entonces se ignora dirfd.

Ver openat(2) para una explicación de la necesidad de scandirat().

VALOR DE RETORNO

La función scandir() devuelve el número de entradas de directorio seleccionadas. En caso de error, devuelve -1, con errno establecido para indicar el error.

Las funciones alphasort() y versionsort() devuelven un entero menor que, igual a, o mayor que cero si el primer argumento se considera respectivamente menor que, igual a, o mayor que el segundo.

ERRORES

EBADF
(scandirat()) dirp es relativo pero dirfd no es ni AT_FDCWD ni un descriptor de archivo válido.
ENOENT
La ruta en dirp no existe.
ENOMEM
Memoria insuficiente para completar la operación.
ENOTDIR
La ruta en dirp no es un directorio.
ENOTDIR
(scandirat()) dirp es relativo y dirfd es un descriptor de archivo que hace referencia a un archivo distinto de un directorio.

NOTAS

Desde glibc 2.1, alphasort() llama a strcoll(3); anteriormente usaba strcmp(3).

Antes de glibc 2.10, los dos argumentos de alphasort() y versionsort() estaban tipificados como const void *. Cuando alphasort() se estandarizó en POSIX.1-2008, el tipo de argumento se especificó como el tipo seguro const struct dirent **, y glibc 2.10 cambió la definición de alphasort() (y el no estándar versionsort()) para que coincidiera con el estándar.

EJEMPLOS

El siguiente programa imprime una lista de los archivos en el directorio actual en orden inverso.

Código fuente del programa

#define _DEFAULT_SOURCE
#include <dirent.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    struct dirent **namelist;
    int n;
    n = scandir(".", &namelist, NULL, alphasort);
    if (n == -1) {
        perror("scandir");
        exit(EXIT_FAILURE);
    }
    while (n--) {
        printf("%s\n", namelist[n]->d_name);
        free(namelist[n]);
    }
    free(namelist);
    exit(EXIT_SUCCESS);
}
