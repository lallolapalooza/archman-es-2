NOMBRE

scsi_readcap - ejecuta el comando SCSI READ CAPACITY en discos

SINOPSIS

scsi_readcap [--brief] [--help] [--long] [--verbose] DISPOSITIVO [DISPOSITIVO]*

DESCRIPCIÓN

Este script de shell bash llama a la utilidad sg_readcap en cada DISPOSITIVO proporcionado. Esto enviará un comando SCSI READ CAPACITY a cada DISPOSITIVO.

La acción predeterminada de este script es enviar el comando READ CAPACITY(10) con cdb de 10 bytes a cada DISPOSITIVO. Si una respuesta indica que el número de bloques es mayor o igual a '2**32 - 1', entonces se envía READ CAPACITY(16) y se muestra su respuesta.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-b, --brief
acorta la salida a dos números hexadecimales, ambos precedidos por '0x'. El primer número es el número de bloques disponibles y el segundo es el tamaño de cada bloque en bytes (por ejemplo, '0x12a19eb0 0x200'). Si se detecta un error, se muestra '0x0 0x0' y el script continúa si hay más DISPOSITIVOs.
-h, --help
imprime el mensaje de uso y luego sale.
-l, --long
por defecto, se envía el comando READ CAPACITY(10) (es decir, la variante de cdb de 10 bytes). Cuando se proporciona esta opción, se envía el comando READ CAPACITY(16). Este último comando produce más información en su respuesta.
-v, --verbose
aumenta el nivel de verbosidad.

ESTADO DE SALIDA

El estado de salida de este script es 0 cuando tiene éxito. De lo contrario, el estado de salida es el de la última utilidad sg_readcap llamada. Consulte la página del manual sg3_utils(8).
