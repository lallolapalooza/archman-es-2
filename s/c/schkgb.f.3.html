SCHKGB

Propósito:

!>
!> SCHKGB prueba SGBTRF, -TRS, -RFS y -CON
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Los tipos de matrices a usar para las pruebas. Las matrices del tipo j
!>          (para 1 <= j <= NTYPES) se usan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se usa.
!>

NM

!>          NM es INTEGER
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array INTEGER, de dimensión (NM)
!>          Los valores de la dimensión de fila M de la matriz.
!>

NN

!>          NN es INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, de dimensión (NN)
!>          Los valores de la dimensión de columna N de la matriz.
!>

NNB

!>          NNB es INTEGER
!>          El número de valores de NB contenidos en el vector NBVAL.
!>

NBVAL

!>          NBVAL es un array INTEGER, de dimensión (NNB)
!>          Los valores del tamaño de bloque NB.
!>

NNS

!>          NNS es INTEGER
!>          El número de valores de NRHS contenidos en el vector NSVAL.
!>

NSVAL

!>          NSVAL es un array INTEGER, de dimensión (NNS)
!>          Los valores del número de lados derechos NRHS.
!>

THRESH

!>          THRESH es REAL
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          cada relación de prueba se imprima, use THRESH = 0.
!>

TSTERR

!>          TSTERR es LOGICAL
!>          Indicador que señala si se deben probar las salidas de error.
!>

A

!>          A es un array REAL, de dimensión (LA)
!>

LA

!>          LA es INTEGER
!>          La longitud del array A. LA >= (KLMAX+KUMAX+1)*NMAX
!>          donde KLMAX es la mayor entrada en el array local KLVAL,
!>                KUMAX es la mayor entrada en el array local KUVAL y
!>                NMAX es la mayor entrada en el array de entrada NVAL.
!>

AFAC

!>          AFAC es un array REAL, de dimensión (LAFAC)
!>

LAFAC

!>          LAFAC es INTEGER
!>          La longitud del array AFAC. LAFAC >= (2*KLMAX+KUMAX+1)*NMAX
!>          donde KLMAX es la mayor entrada en el array local KLVAL,
!>                KUMAX es la mayor entrada en el array local KUVAL y
!>                NMAX es la mayor entrada en el array de entrada NVAL.
!>

B

!>          B es un array REAL, de dimensión (NMAX*NSMAX)
!>          donde NSMAX es la mayor entrada en NSVAL.
!>

X

!>          X es un array REAL, de dimensión (NMAX*NSMAX)
!>

XACT

!>          XACT es un array REAL, de dimensión (NMAX*NSMAX)
!>

WORK

!>          WORK es un array REAL, de dimensión
!>                      (NMAX*max(3,NSMAX,NMAX))
!>

RWORK

!>          RWORK es un array REAL, de dimensión
!>                      (NMAX+2*NSMAX)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (2*NMAX)
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>
