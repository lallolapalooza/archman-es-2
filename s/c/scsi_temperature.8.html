NOMBRE

scsi_temperature - obtener la temperatura de un dispositivo SCSI

SINOPSIS

scsi_temperature [--ayuda] [--verboso] DISPOSITIVO [DISPOSITIVO]*

DESCRIPCIÓN

Este script de shell bash llama a la utilidad sg_logs en cada DISPOSITIVO dado para encontrar la temperatura del dispositivo. Primero se comprueba la página de registro de Temperatura y si no está disponible, se comprueba la página de registro de Excepciones de Información.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-h, --ayuda
imprime el mensaje de uso y sale.
-v, --verboso
aumenta el nivel de verbosidad.

ESTADO DE SALIDA

El estado de salida de este script es 0 cuando tiene éxito. De lo contrario, el estado de salida es el de la última utilidad sg_logs llamada. Consulte la página del manual de sg3_utils(8).
