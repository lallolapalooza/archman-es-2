SCHED_GETPARAM(3P) Manual del programador POSIX SCHED_GETPARAM(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sched_getparam — obtener parámetros de planificación (REALTIME)

SINOPSIS

#include <sched.h>
int sched_getparam(pid_t pid, struct sched_param *param);

DESCRIPCIÓN

La función sched_getparam() devolverá los parámetros de planificación de un proceso especificado por pid en la estructura sched_param apuntada por param.

Si existe un proceso especificado por pid, y si el proceso que realiza la llamada tiene permiso, se devolverán los parámetros de planificación del proceso cuyo ID de proceso sea igual a pid.

Si pid es cero, se devolverán los parámetros de planificación del proceso que realiza la llamada. El comportamiento de la función sched_getparam() no está especificado si el valor de pid es negativo.

VALOR DE RETORNO

Al completarse con éxito, la función sched_getparam() devolverá cero. Si la llamada a sched_getparam() no tiene éxito, la función devolverá un valor de -1 y establecerá errno para indicar el error.

ERRORES

La función sched_getparam() fallará si:

EPERM
El proceso solicitante no tiene permiso para obtener los parámetros de planificación del proceso especificado.
ESRCH
No se puede encontrar ningún proceso que corresponda al especificado por pid.
