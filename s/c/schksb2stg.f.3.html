SCHKSB2STG

Propósito:

!>
!> SCHKSB2STG prueba la reducción de una matriz de banda simétrica a forma tridiagonal,
!> utilizada con el problema de valores propios simétricos.
!>
!> SSBTRD factoriza una matriz de banda simétrica A como U S U', donde ' significa
!> transpuesta, S es tridiagonal simétrica y U es ortogonal.
!> SSBTRD puede usar solo la parte triangular inferior o solo la parte triangular
!> superior de A; SCHKSB2STG verifica ambos casos.
!>
!> SSYTRD_SB2ST factoriza una matriz de banda simétrica A como U S U',
!> donde ' significa transpuesta, S es tridiagonal simétrica y U es
!> ortogonal. SSYTRD_SB2ST puede usar solo la parte triangular inferior o solo la
!> parte triangular superior de A; SCHKSB2STG verifica ambos casos.
!>
!> SSTEQR factoriza S como Z D1 Z'.
!> D1 es la matriz de valores propios calculados cuando Z no se calcula
!> y a partir de S resultante de SSBTRD (utilizada como referencia para SSYTRD_SB2ST)
!> D2 es la matriz de valores propios calculados cuando Z no se calcula
!> y a partir de S resultante de SSYTRD_SB2ST.
!> D3 es la matriz de valores propios calculados cuando Z no se calcula
!> y a partir de S resultante de SSYTRD_SB2ST.
!>
!> Cuando se llama a SCHKSB2STG, se especifica un número de tamaños de matriz (),
!> un número de anchos de banda () y un número de tipos de matriz.
!> Para cada tamaño (), cada ancho de banda () menor o igual a , y cada tipo de matriz,
!> se generará una matriz y se utilizará para probar la rutina de reducción de banda
!> simétrica. Para cada matriz, se realizarán una serie de pruebas:
!>
!> (1)     | A - V S V' | / ( |A| n ulp )  calculado por SSBTRD con
!>                                         UPLO='U'
!>
!> (2)     | I - UU' | / ( n ulp )
!>
!> (3)     | A - V S V' | / ( |A| n ulp )  calculado por SSBTRD con
!>                                         UPLO='L'
!>
!> (4)     | I - UU' | / ( n ulp )
!>
!> (5)     | D1 - D2 | / ( |D1| ulp )      donde D1 es calculado por
!>                                         SSBTRD con UPLO='U' y
!>                                         D2 es calculado por
!>                                         SSYTRD_SB2ST con UPLO='U'
!>
!> (6)     | D1 - D3 | / ( |D1| ulp )      donde D1 es calculado por
!>                                         SSBTRD con UPLO='U' y
!>                                         D3 es calculado por
!>                                         SSYTRD_SB2ST con UPLO='L'
!>
!> Los tamaños se especifican mediante un array NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los tipos de matriz se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>      1, ..., ULP y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1)
!> (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>      1, ..., ULP y signos aleatorios.
!> (5)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!> (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (8)  Una matriz de la forma U' D U, donde U es ortogonal y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (9)  Una matriz de la forma U' D U, donde U es ortogonal y
!>      D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (10) Una matriz de la forma U' D U, donde U es ortogonal y
!>      D tiene entradas 1, ULP,..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>

!>          El número de tamaños de matrices a utilizar. Si es cero,

!>          NWDTHS es INTEGER
!>          El número de anchos de banda a utilizar. Si es cero,
!>          SCHKSB2STG no hace nada. Debe ser al menos cero.
!>

KK

!>          KK es INTEGER array, dimension (NWDTHS)
!>          Un array que contiene los anchos de banda a utilizar para las matrices
!>          de banda. Los valores deben ser al menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SCHKSB2STG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es utilizar cualquier matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es LOGICAL array, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es INTEGER array, dimension (4)
