SCP(1) Manual de Comandos Generales SCP(1)

NOMBRE

scp — copia segura de archivos OpenSSH

SINOPSIS

scp [-346ABCOpqRrsTv] [-c cifrado] [-D ruta_servidor_sftp] [-F config_ssh] [-i archivo_identidad] [-J destino] [-l límite] [-o opción_ssh] [-P puerto] [-S programa] [-X opción_sftp] fuente ... objetivo

DESCRIPCIÓN

scp copia archivos entre hosts en una red.

scp utiliza el protocolo SFTP a través de una conexión ssh(1) para la transferencia de datos, y utiliza la misma autenticación y proporciona la misma seguridad que una sesión de inicio de sesión.

scp pedirá contraseñas o frases de contraseña si son necesarias para la autenticación.

Las fuente y objetivo pueden especificarse como una ruta de archivo local, un host remoto con ruta opcional en el formato [usuario@]host:[ruta], o una URI en el formato scp://[usuario@]host[:puerto][/ruta]. Los nombres de archivo locales pueden hacerse explícitos utilizando rutas absolutas o relativas para evitar que scp trate los nombres de archivo que contienen ‘:’ como especificadores de host.

Al copiar entre dos hosts remotos, si se utiliza el formato URI, no se puede especificar un puerto en el objetivo si se utiliza la opción -R.

Las opciones son las siguientes:

-3
Las copias entre dos hosts remotos se transfieren a través del host local. Este modo es el predeterminado, pero vea también la opción -R para copiar datos directamente entre dos hosts remotos. Tenga en cuenta que al usar el protocolo SCP heredado (a través de la bandera -O), esta opción selecciona el modo por lotes para el segundo host, ya que scp no puede solicitar contraseñas o frases de contraseña para ambos hosts.
-4
Fuerza a scp a usar solo direcciones IPv4.
-6
Fuerza a scp a usar solo direcciones IPv6.
-A
Permite el reenvío de ssh-agent(1) al sistema remoto. La opción predeterminada es no reenviar un agente de autenticación.
-B
Selecciona el modo por lotes (evita solicitar contraseñas o frases de contraseña).
-C
Habilita compresión. Pasa la bandera -C a ssh(1) para habilitar la compresión.
-c cifrado
Selecciona el cifrado a utilizar para encriptar la transferencia de datos. Esta opción se pasa directamente a ssh(1).
-D ruta_servidor_sftp
Conéctate directamente a un programa servidor SFTP local en lugar de uno remoto a través de ssh(1). Esta opción puede ser útil para depurar el cliente y el servidor.
-F config_ssh
Especifica un archivo de configuración alternativo por usuario para ssh. Esta opción se pasa directamente a ssh(1).
-i archivo_identidad
Selecciona el archivo del cual se lee la identidad (clave privada) para la autenticación de clave pública. Esta opción se pasa directamente a ssh(1).
-J destino
Conéctate al host de destino estableciendo primero una conexión scp al host de salto descrito por destino y luego estableciendo un reenvío TCP al destino final desde allí. Se pueden especificar varios saltos separando por comas. Esto es un atajo para especificar una directiva de configuración ProxyJump. Esta opción se pasa directamente a ssh(1).
-l límite
Limita el ancho de banda utilizado, especificado en Kbit/s.
-O
Utiliza el protocolo SCP heredado para las transferencias de archivos en lugar del protocolo SFTP. Forzar el uso del protocolo SCP puede ser necesario para servidores que no implementan SFTP, por compatibilidad hacia atrás con patrones de comodín de nombres de archivo particulares y para expandir rutas con un prefijo ‘~’ para servidores SFTP más antiguos.
-o opción_ssh
Se puede usar para pasar opciones a ssh en el formato utilizado en ssh_config(5). Esto es útil para especificar opciones para las cuales no hay un flag de comando scp separado. Para detalles completos de las opciones listadas a continuación, y sus posibles valores, consulte ssh_config(5).

-P puerto
Especifica el puerto al que conectarse en el host remoto. Tenga en cuenta que esta opción se escribe con una ‘P’ mayúscula, ya que -p ya está reservada para preservar los tiempos y los bits de modo del archivo.
-p
Preserva los tiempos de modificación, los tiempos de acceso y los bits de modo de archivo del archivo de origen.
-q
Modo silencioso: deshabilita el medidor de progreso, así como los mensajes de advertencia y diagnóstico de ssh(1).
-R
Las copias entre dos hosts remotos se transfieren a través del host local por defecto. Esta opción, en cambio, copia entre dos hosts remotos conectándose al host de origen y ejecutando scp allí. Esto requiere que scp ejecutándose en el host de origen pueda autenticarse en el host de destino sin requerir una contraseña.
-r
Copia recursivamente directorios completos. Tenga en cuenta que scp sigue los enlaces simbólicos que se encuentran en el recorrido del árbol.
-S programa
Nombre del programa a utilizar para la conexión cifrada. El programa debe entender las opciones de ssh(1).
-T
Deshabilita la comprobación estricta de nombres de archivo. Por defecto, al copiar archivos de un host remoto a un directorio local, scp comprueba que los nombres de archivo recibidos coincidan con los solicitados en la línea de comandos para evitar que el extremo remoto envíe archivos inesperados o no deseados. Debido a las diferencias en cómo diversos sistemas operativos y shells interpretan los comodines de nombres de archivo, estas comprobaciones pueden hacer que los archivos deseados sean rechazados. Esta opción deshabilita estas comprobaciones a costa de confiar plenamente en que el servidor no enviará nombres de archivo inesperados.
-v
Modo detallado. Hace que scp y ssh(1) impriman mensajes de depuración sobre su progreso. Esto es útil para depurar problemas de conexión, autenticación y configuración.
-X opción_sftp
Especifica una opción que controla aspectos del comportamiento del protocolo SFTP. Las opciones válidas son:
nrequests=valor
Controla cuántas solicitudes de lectura o escritura SFTP concurrentes pueden estar activas en cualquier momento durante una descarga o subida. Por defecto, 64 solicitudes pueden estar activas concurrentemente.
buffer=valor
Controla el tamaño máximo del búfer para una única operación de lectura/escritura SFTP utilizada durante la descarga o subida. Por defecto, se utiliza un búfer de 32 KB.

ESTADO DE SALIDA

La utilidad scp sale con código 0 en caso de éxito, y >0 si ocurre un error.

VER TAMBIÉN

sftp(1), ssh(1), ssh-add(1), ssh-agent(1), ssh-keygen(1), ssh_config(5), sftp-server(8), sshd(8)

HISTORIA

scp se basa en el programa rcp del código fuente de BSD de los Regentes de la Universidad de California.

Desde OpenSSH 9.0, scp utiliza el protocolo SFTP para las transferencias por defecto.

ADVERTENCIAS

El protocolo SCP heredado (seleccionado con la opción -O) requiere la ejecución del shell del usuario remoto para realizar la coincidencia de patrones de glob(3). Esto requiere una cuidadosa cotización de cualquier carácter que tenga un significado especial para el shell remoto, como los caracteres de cita.

NOMBRE

scp - copia segura (programa de copia de archivos remotos)

SINOPSIS

scp [OPCIONES] ruta_fuente ... ruta_destino

scp [OPCIONES] -r ruta_fuente ... ruta_destino

DESCRIPCIÓN

scp copia archivos entre hosts en una red. Utiliza ssh para la transferencia de datos y la autenticación, por lo que el tráfico está cifrado y se beneficia de todas las características de autenticación de ssh.

scp opera de manera similar a cp. La ruta de origen y destino pueden ser archivos o directorios. Cuando se usa el argumento -r, scp copia recursivamente los directorios.

scp soporta las siguientes opciones:

  • -1: Fuerza a usar el protocolo de versión 1 de SSH.
  • -2: Fuerza a usar el protocolo de versión 2 de SSH.
  • -3: Copia entre dos hosts remotos directamente, sin copiar a la máquina local primero.
  • -4: Fuerza a usar IPv4.
  • -6: Fuerza a usar IPv6.
  • -A: Permite la autenticación de agente.
  • -B: Modo batch (desactiva la solicitud de contraseña).
  • -C: Compresión de datos.
  • -F archivo_conf: Especifica el archivo de configuración del cliente para ssh.
  • -h: Muestra el resumen de ayuda.
  • -i archivo_clave: Selecciona la clave privada para la autenticación.
  • -l límite: Limita el ancho de banda de red en Kbit/s.
  • -o opción: Permite opciones pasadas directamente a ssh.
  • -P puerto: Puerto en el que se conecta el servidor remoto.
  • -q: Modo silencioso.
  • -r: Copia recursivamente los directorios.
  • -S programa: Programa a utilizar para la comunicación cifrada (por defecto es ssh).
  • -v: Modo detallado.

Los formatos de ruta son los siguientes:

  • [user@]host:ruta: Especifica un archivo en un host remoto.
  • ruta: Especifica un archivo local.

Si se omite el usuario, se asume el nombre de usuario local.

ESTADO DE SALIDA

scp devuelve 0 si tiene éxito, y un valor distinto de cero si falla.

VER TAMBIÉN

ssh(1), sftp(1), cp(1)

HISTORIA

El comando scp apareció por primera vez en el sistema operativo SunOS.

AUTORES

scp es parte del paquete OpenSSH, desarrollado por la OpenSSH team.

ADVERTENCIAS

scp no soporta la copia de archivos a través de tuberías ni la copia entre múltiples fuentes y destinos. Para esas funcionalidades, considere usar rsync o sftp.
