NOMBRE

scomes - herramienta para observar recursos del sistema

SINOPSIS

scomes -c "binario [argumentos del binario ...]" [temporizador]

DESCRIPCIÓN

scomes es un script simple de systemtap para observar la actividad de un proceso. Se miden el recuento de llamadas al sistema, los ciclos en el espacio de usuario y en el espacio del kernel, los bytes leídos y escritos, los bytes transmitidos y recibidos, y las llamadas al sistema de sondeo.

binario
Archivo binario a ejecutar. Este proceso será observado.
temporizador
Establecer esta opción hace que el script imprima estadísticas cada N segundos. Si no se proporciona, las estadísticas se imprimen solo cuando el proceso observado termina.

VER TAMBIÉN

tuned(8) diskdevstat(8) netdevstat(8) varnetload(8) stap(1)
