sched_get_priority_max(2) Manual de llamadas al sistema sched_get_priority_max(2)

NOMBRE

sched_get_priority_max, sched_get_priority_min - obtener el rango de prioridad estática

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sched.h>
int sched_get_priority_max(int policy);
int sched_get_priority_min(int policy);

DESCRIPCIÓN

sched_get_priority_max() devuelve el valor de prioridad máximo que se puede usar con el algoritmo de planificación identificado por policy. sched_get_priority_min() devuelve el valor de prioridad mínimo que se puede usar con el algoritmo de planificación identificado por policy. Los valores de policy admitidos son SCHED_FIFO, SCHED_RR, SCHED_OTHER, SCHED_BATCH, SCHED_IDLE y SCHED_DEADLINE. Puede encontrar más detalles sobre estas políticas en sched(7).

Los procesos con valores de prioridad numéricamente más altos se planifican antes que los procesos con valores de prioridad numéricamente más bajos. Por lo tanto, el valor devuelto por sched_get_priority_max() será mayor que el valor devuelto por sched_get_priority_min().

Linux permite el rango de prioridades estáticas de 1 a 99 para las políticas SCHED_FIFO y SCHED_RR, y la prioridad 0 para las políticas restantes. Los rangos de prioridad de planificación para las diversas políticas no son alterables.

Los sistemas POSIX en los que están disponibles sched_get_priority_max() y sched_get_priority_min() definen _POSIX_PRIORITY_SCHEDULING en <unistd.h>.

VALOR DE RETORNO

En caso de éxito, sched_get_priority_max() y sched_get_priority_min() devuelven el valor de prioridad máximo/mínimo para la política de planificación nombrada. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EINVAL
El argumento policy no identifica una política de planificación definida.

ESTANDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.
