NAME

caca-config

prints information about the installed libcaca library

SYNOPSIS

caca-config [OPTION]...

Description

caca-config is a tool that prints information about the installed libcaca library, such as the include paths and library paths.

This command is useful when you want to compile or link applications against libcaca.

Options

--cflags
Print the compiler flags that are necessary to compile a program that uses libcaca.
--libs
Print the linker flags that are necessary to link a program that uses libcaca.
--version
Print the installed version of libcaca and exit.
-h, --help
Print a help message and exit.

Example

To compile and link a C program named hello.c against libcaca, you can use the following command:

    gcc hello.c -o hello $(caca-config --cflags --libs)
