NOMBRE

scriptor - Script de Perl para enviar comandos a una tarjeta inteligente

SINOPSIS

scriptor [-h] [-r lector] [-p protocolo] [-u] [archivo]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando scriptor.

scriptor es un programa que envía comandos a una tarjeta inteligente utilizando un archivo por lotes o la entrada estándar.

OPCIONES

A continuación se incluye una descripción de las opciones.

-h
Muestra un resumen de las opciones.
-r lector
Utiliza el lector indicado. Por defecto se utiliza el primer lector PC/SC disponible.
-p protocolo
Utiliza el protocolo indicado. Los valores aceptados son T=0 y T=1. Por defecto se utiliza T=0.
-u
Utiliza la salida estándar sin búfer.
archivo
Utiliza el archivo en lugar de la entrada estándar para leer comandos (APDUs).

Los comandos tienen el siguiente formato:
CLA INS P1 P2 Lc [datos] [le]
reset
# comentario

Ejemplo:


# Reinicia la tarjeta
reset


# Selecciona MF 3F00
A0 A4 00 00 02 3F 00


# Obtener Respuesta
# 17 es el valor del segundo SW del comando anterior
A0 C0 00 00 17


# Selecciona DF Telecom (7F10)
A0 A4 00 00 02 7F 10


# Obtener Respuesta
A0 C0 00 00 17


# Selecciona EF_ADN (6F3A) (Números de Marcación Abreviada)
A0 A4 00 00 02 6F 3A


# Obtener Respuesta
A0 C0 00 00 0F
