scale(n) Comandos integrados de Tk scale(n)

NOMBRE

scale - Crea y manipula widgets deslizantes controlados por valores de tipo 'scale'

SINOPSIS

scale rutaNombre ?opciones?

OPCIONES ESTÁNDAR

-activebackground	-foreground	-relief
-background	-highlightbackground	-repeatdelay
-borderwidth	-highlightcolor	-repeatinterval
-cursor	-highlightthickness	-takefocus
-font	-orient	-troughcolor

Consulte la entrada del manual de options para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre en la línea de comandos:	-bigincrement
Nombre en la base de datos:	bigIncrement
Clase de la base de datos:	BigIncrement
Algunas interacciones con la escala provocan que su valor cambie en incrementos "grandes"; esta opción especifica el tamaño de los incrementos grandes. Si se especifica como 0, los incrementos grandes por defecto son 1/10 del rango de la escala.
Nombre en la línea de comandos:	-command
Nombre en la base de datos:	command
Clase de la base de datos:	Command
Especifica el prefijo de un comando Tcl a invocar cada vez que el valor de la escala se cambie a través de un comando del widget. El comando real consiste en esta opción seguida de un espacio y un número real que indica el nuevo valor de la escala.
Nombre en la línea de comandos:	-digits
Nombre en la base de datos:	digits
Clase de la base de datos:	Digits
Un entero que especifica cuántos dígitos significativos se deben conservar al convertir el valor de la escala a una cadena. Si el número es menor o igual a cero, entonces la escala elige el valor más pequeño que garantiza que cada posición posible del deslizador se imprima como una cadena diferente.
Nombre en la línea de comandos:	-from
Nombre en la base de datos:	from
Clase de la base de datos:	From
Un valor real correspondiente al extremo izquierdo o superior de la escala.
Nombre en la línea de comandos:	-label
Nombre en la base de datos:	label
Clase de la base de datos:	Label
Una cadena para mostrar como etiqueta de la escala. Para escalas verticales, la etiqueta se muestra justo a la derecha del extremo superior de la escala. Para escalas horizontales, la etiqueta se muestra justo encima del extremo izquierdo de la escala. Si la opción se especifica como una cadena vacía, no se muestra ninguna etiqueta.
Nombre en la línea de comandos:	-length
Nombre en la base de datos:	length
Clase de la base de datos:	Length
Especifica la dimensión larga deseada de la escala en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels). Para escalas verticales, esta es la altura de la escala; para escalas horizontales, es el ancho de la escala.
Nombre en la línea de comandos:	-resolution
Nombre en la base de datos:	resolution
Clase de la base de datos:	Resolution
Un valor real que especifica la resolución de la escala. Si este valor es mayor que cero, el valor de la escala siempre se redondeará a un múltiplo par de este valor, al igual que los extremos de la escala. Si el valor es menor que cero, no se realizará ningún redondeo. Por defecto es 1 (es decir, el valor será entero).
Nombre en la línea de comandos:	-showvalue
Nombre en la base de datos:	showValue
Clase de la base de datos:	ShowValue
Especifica un valor booleano que indica si se va a mostrar o no el valor actual de la escala.
Nombre en la línea de comandos:	-sliderlength
Nombre en la base de datos:	sliderLength
Clase de la base de datos:	SliderLength
Especifica el tamaño del deslizador, medido en unidades de pantalla a lo largo de la dimensión larga del deslizador. El valor puede especificarse en cualquiera de las formas aceptables para Tk_GetPixels.
Nombre en la línea de comandos:	-sliderrelief
Nombre en la base de datos:	sliderRelief
Clase de la base de datos:	SliderRelief
Especifica el relieve a usar al dibujar el deslizador, como raised (elevado) o sunken (hundido).
Nombre en la línea de comandos:	-state
Nombre en la base de datos:	state
Clase de la base de datos:	State
Especifica uno de los tres estados para la escala: normal, active (activo) o disabled (desactivado). Si la escala está desactivada, el valor no se puede cambiar y la escala no se activará. Si la escala está activa, el deslizador se muestra utilizando el color especificado por la opción -activebackground.
Nombre en la línea de comandos:	-tickinterval
Nombre en la base de datos:	tickInterval
Clase de la base de datos:	TickInterval
Debe ser un valor real. Determina el espaciado entre las marcas numéricas que se muestran debajo o a la izquierda del deslizador. Todos los valores se mostrarán con el mismo número de decimales, que será suficiente para garantizar que todos sean precisos dentro del 20% de un intervalo de marca. Si es 0, no se mostrarán marcas.
Nombre en la línea de comandos:	-to
Nombre en la base de datos:	to
Clase de la base de datos:	To
Especifica un valor real correspondiente al extremo derecho o inferior de la escala. Este valor puede ser menor o mayor que la opción -from.
Nombre en la línea de comandos:	-variable
Nombre en la base de datos:	variable
Clase de la base de datos:	Variable
Especifica el nombre de una variable global para vincular con la escala. Cada vez que cambie el valor de la variable, la escala se actualizará para reflejar este valor. Cada vez que se manipule la escala de forma interactiva, la variable se modificará para reflejar el nuevo valor de la escala.
Nombre en la línea de comandos:	-width
Nombre en la base de datos:	width
Clase de la base de datos:	Width
Especifica la dimensión estrecha deseada de la escala en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels). Para escalas verticales, este es el ancho de la escala; para escalas horizontales, esta es la altura de la escala.

DESCRIPCIÓN

El comando scale crea una nueva ventana (dada por el argumento rutaNombre) y la convierte en un widget de escala. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos de la escala, como sus colores, orientación y relieve. El comando scale devuelve su argumento rutaNombre. En el momento en que se invoca este comando, no debe existir una ventana llamada rutaNombre, pero el padre de rutaNombre debe existir.

Una escala es un widget que muestra un *canal* rectangular y un pequeño *deslizador*. El canal corresponde a un rango de valores reales (determinado por las opciones -from, -to y -resolution), y la posición del deslizador selecciona un valor real particular. La posición del deslizador (y, por lo tanto, el valor de la escala) se puede ajustar con el ratón o el teclado como se describe en la sección BINDINGS más abajo. Cada vez que se cambia el valor de la escala, se invoca un comando Tcl (utilizando la opción -command) para notificar a otros widgets interesados del cambio. Además, el valor de la escala puede vincularse a una variable Tcl (utilizando la opción -variable), de modo que los cambios en cualquiera de ellas se reflejen en la otra.

Se pueden mostrar tres anotaciones en un widget de escala: una etiqueta que aparece en la parte superior derecha del widget (superior izquierda para escalas horizontales), un número mostrado justo a la izquierda del deslizador (justo encima del deslizador para escalas horizontales) y una colección de marcas numéricas justo a la izquierda del valor actual (justo debajo del canal para escalas horizontales). Cada una de estas tres anotaciones puede habilitarse o deshabilitarse utilizando las opciones de configuración.

COMANDO DEL WIDGET

El comando scale crea un nuevo comando Tcl cuyo nombre es rutaNombre. Este comando puede usarse para invocar varias operaciones en el widget. Tiene la siguiente forma general:

rutaNombre opción ?arg arg ...?
Opción y los args determinan el comportamiento exacto del comando. Los siguientes comandos son posibles para los widgets de escala:
rutaNombre cget opción
Devuelve el valor actual de la opción de configuración dada por opción. Opción puede tener cualquiera de los valores aceptados por el comando scale.
rutaNombre configure ?opción? ? scale(n) — Tk manuals

NAME

scale - create and manipulate scale widgets

SYNOPSIS


?commonOption value? ...
?option value? ...

STANDARD OPTIONS

See tkoptions for a list of standard options that apply to the scale widget.

WIDGET-SPECIFIC OPTIONS

-bigincrement value
Specifies a value that is added to or subtracted from the scale's current value when the page up/page down keys or control-arrow keys are used. The default is 10.
-command script
Specifies a script to be called whenever the scale's value changes. The script is called with two arguments: the current value of the scale. This option may be specified any number of times.
-digits numDigits
Specifies the number of digits to display for the scale's current value. The default is 0.
-from value
Specifies the lower bound of the scale's range. The default is 0.
-gradient value
Specifies the value between -from and -to that corresponds to the center of the slider. The default is 0.
-height value
Specifies the desired height of the window in screen units (like pixels). The default value is 100.
-increment value
Specifies the value that is added to or subtracted from the scale's current value when the up/down or left/right arrow keys are used. The default is 1.
-label string
Specifies a text string to be displayed along the edge of the scale. See the -orient option for information on where the label is placed.
-length value
Specifies the desired length of the scale in screen units (like pixels). The default value is 100.
-orient orientation
Specifies the orientation of the scale, which can be vertical or horizontal. The default is vertical.
-resolution value
Specifies the smallest increment for the scale. When the scale's value is changed by user interaction, it is rounded to the nearest multiple of this value. The default is 1.
-showvalue boolean
Specifies whether or not to display the scale's current value as text. The default is true.
-sliderrelief relief
Specifies the relief for the slider, which can be flat, raised, sunken, groove, or ridge. The default is raised.
-sliderthickness value
Specifies the thickness of the slider in screen units. For horizontal scales, this is the height of the slider; for vertical scales, it is the width. The default is 15.
-state state
Specifies one of the following states: normal or disabled. The default is normal.
-tickinterval value
Specifies an interval for displaying tick marks along the scale. If this option is non-zero, tick marks will be drawn at multiples of this value. The default is 0.
-to value
Specifies the upper bound of the scale's range. The default is 100.
-variable varName
Specifies that the scale's value should be linked to the Tk variable named varName. Whenever the variable changes, the scale's value is updated, and whenever the scale's value changes, the variable is updated. If varName is empty, the scale is unlinked.
-width value
Specifies the desired width of the widget in screen units. For horizontal scales, this is the width of the trough; for vertical scales, it is the width of the trough. The default value is 2.

DESCRIPTION

The scale command creates a new window containing a scale widget. The widget consists of a trough and a slider that can be moved back and forth within the trough. The scale displays a range of numerical values, and the position of the slider indicates the current value within that range. The scale can be oriented horizontally or vertically. A text label may also be displayed along one edge of the scale. The widget may also display tick marks and the current value numerically.

Scales are typically used to provide a graphical way to adjust a numerical value.

WIDGET COMMAND

The command for a scale widget can be used to invoke various operations on the widget after it has been created. The subcommands for the scale widget are described below. The available values for option and value depend on the subcommand.

pathName cget option
Returns the current value of the given widget option for the specified pathName; the value returned will be in the canonical form for that option. Option may have any of the values accepted by the scale command.
pathName configure ?option value? ?option value ...?
Query or modify the configuration options of the widget. If no option is specified, returns a list describing all of the available options for pathName (see Tk_ConfigureInfo for information on the format of this list). If option is specified with no value, then the command returns a list describing the one named option (this list will be identical to the corresponding sublist of the value returned if no option is specified). If one or more option-value pairs are specified, then the command modifies the given widget option(s) to have the given value(s); in this case the command returns an empty string. Option may have any of the values accepted by the scale command.
pathName coords ?value?
Returns a list whose elements are the x and y coordinates of the point along the centerline of the trough that corresponds to value. If value is omitted then the scale's current value is used.
pathName get ?x y?
If x and y are omitted, returns the current value of the scale. If x and y are specified, they give pixel coordinates within the widget; the command returns the scale value corresponding to the given pixel. Only one of x or y is used: for horizontal scales y is ignored, and for vertical scales x is ignored.
pathName identify x y
Returns a string indicating what part of the scale lies under the coordinates given by x and y. A return value of slider means that the point is over the slider; trough1 means that the point is over the portion of the slider above or to the left of the slider; and trough2 means that the point is over the portion of the slider below or to the right of the slider. If the point is not over one of these elements, an empty string is returned.
pathName set value
This command is invoked to change the current value of the scale, and hence the position at which the slider is displayed. Value gives the new value for the scale. The command has no effect if the scale is disabled.

BINDINGS

Tk automatically creates class bindings for scales that give them the following default behavior. Where the behavior is different for vertical and horizontal scales, the horizontal behavior is described in parentheses.

[1]
If button 1 is pressed in the trough, the scale's value will be incremented or decremented by the value of the -resolution option so that the slider moves in the direction of the cursor. If the button is held down, the action auto-repeats.
[2]
If button 1 is pressed over the slider, the slider can be dragged with the mouse.
[3]
If button 1 is pressed in the trough with the Control key down, the slider moves all the way to the end of its range, in the direction towards the mouse cursor.
[4]
If button 2 is pressed, the scale's value is set to the mouse position. If the mouse is dragged with button 2 down, the scale's value changes with the drag.
[5]
The Up and Left keys move the slider up (left) by the value of the -resolution option.
[6]
The Down and Right keys move the slider down (right) by the value of the -resolution option.
[7]
Control-Up and Control-Left move the slider up (left) by the value of the -bigincrement option.
[8]
Control-Down and Control-Right move the slider down (right) by the value of the -bigincrement option.
[9]
Home moves the slider to the top (left) end of its range.
[10]
End moves the slider to the bottom (right) end of its range.

If the scale is disabled using the -state option then none of the above bindings have any effect.

The behavior of scales can be changed by defining new bindings for individual widgets or by redefining the class bindings.
