Propósito:

!>
!> SCHKST verifica las rutinas del problema de valores propios simétricos.
!>
!> SSYTRD factoriza A como U S U' , donde ' significa transpuesta,
!> S es simétrica tridiagonal y U es ortogonal.
!> SSYTRD puede usar solo el triángulo inferior o solo el triángulo
!> superior de A; SCHKST verifica ambos casos.
!> U se representa como un producto de transformaciones de Householder,
!> cuyos vectores se almacenan en las primeras n-1 columnas de V,
!> y cuyos factores de escala están en TAU.
!>
!> SSPTRD hace lo mismo que SSYTRD, excepto que A y V se almacenan
!> en formato .
!>
!> SORGTR construye la matriz U a partir del contenido de V y TAU.
!>
!> SOPGTR construye la matriz U a partir del contenido de VP y TAU.
!>
!> SSTEQR factoriza S como Z D1 Z' , donde Z es la matriz ortogonal
!> de autovectores y D1 es una matriz diagonal con los autovalores
!> en la diagonal. D2 es la matriz de autovalores calculada cuando
!> no se calcula Z.
!>
!> SSTERF calcula D3, la matriz de autovalores, por el método
!> PWK, que no produce autovectores.
!>
!> SPTEQR factoriza S como Z4 D4 Z4' , para una
!> matriz tridiagonal simétrica definida positiva.
!> D5 es la matriz de autovalores calculada cuando no se calcula Z.
!>
!> SSTEBZ calcula autovalores seleccionados. WA1, WA2 y
!> WA3 denotarán autovalores calculados con alta
!> precisión absoluta, con diferentes opciones de rango.
!> WR denotará autovalores calculados con alta precisión relativa.
!>
!> SSTEIN calcula Y, los autovectores de S, dados los
!> autovalores.
!>
!> SSTEDC factoriza S como Z D1 Z' , donde Z es la matriz ortogonal
!> de autovectores y D1 es una matriz diagonal con
!> los autovalores en la diagonal (opción 'I'). También
!> puede actualizar una matriz ortogonal de entrada, generalmente la salida
!> de SSYTRD/SORGTR o SSPTRD/SOPGTR (opción 'V'). También
!> solo puede calcular autovalores (opción 'N').
!>
!> SSTEMR factoriza S como Z D1 Z' , donde Z es la matriz ortogonal
!> de autovectores y D1 es una matriz diagonal con
!> los autovalores en la diagonal (opción 'I'). SSTEMR
!> usa la Representación Relativamente Robusta siempre que sea posible.
!>
!> Cuando se llama a SCHKST, se especifican un número de tamaños de matriz ()
!> y un número de tipos de matriz. Para cada tamaño ()
!> y cada tipo de matriz, se generará y utilizará una matriz
!> para probar las rutinas de autovalores simétricos. Para cada matriz,
!> se realizarán una serie de pruebas:
!>
!> (1) | A - V S V' | / ( |A| n ulp ) SSYTRD( UPLO='U', ... )
!>
!> (2) | I - UV' | / ( n ulp ) SORGTR( UPLO='U', ... )
!>
!> (3) | A - V S V' | / ( |A| n ulp ) SSYTRD( UPLO='L', ... )
!>
!> (4) | I - UV' | / ( n ulp ) SORGTR( UPLO='L', ... )
!>
!> (5-8) Lo mismo que 1-4, pero para SSPTRD y SOPGTR.
!>
!> (9) | S - Z D Z' | / ( |S| n ulp ) SSTEQR('V',...)
!>
!> (10) | I - ZZ' | / ( n ulp ) SSTEQR('V',...)
!>
!> (11) | D1 - D2 | / ( |D1| ulp ) SSTEQR('N',...)
!>
!> (12) | D1 - D3 | / ( |D1| ulp ) SSTERF
!>
!> (13) 0 si los autovalores verdaderos (calculados por conteo de Sturm)
!> de S están dentro de THRESH de
!> los de D1. 2*THRESH si no lo están. (Probado usando
!> SSTECH)
!>
!> Para S definida positiva,
!>
!> (14) | S - Z4 D4 Z4' | / ( |S| n ulp ) SPTEQR('V',...)

!> (15) | I - Z4 Z4' | / ( n ulp ) SPTEQR('V',...)

Parámetros

NSIZES 
!>          NSIZES es ENTERO
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          SCHKST no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es array ENTERO, dimensión (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es ENTERO
!>          El número de elementos en DOTYPE. Si es cero, SCHKST
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar cualquier matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es array LÓGICO, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará una
!>          matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 a
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) a DOTYPE(NTYPES)
!>          se ignorarán.
!>

ISEED

!>          ISEED es array ENTERO, dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños y, por lo tanto,
!>          debe producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED cambian a la salida y se pueden utilizar en la
!>          siguiente llamada a SCHKST para continuar la misma secuencia de números
!>          aleatorios.
!>

THRESH

!>          THRESH es REAL
!>          Una prueba se contará como  si el , calculado como
!>          se describe anteriormente, excede THRESH. Tenga en cuenta que el error
!>          está escalado para ser O(1), por lo que THRESH debe ser un múltiplo
!>          razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple o doble)
!>          ni del tamaño de la matriz. Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es ENTERO
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0).
!>

A

!>          A es array REAL de
!>                                  dimensión ( LDA , max(NN) )
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular. A la salida, A contiene la última matriz utilizada realmente.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de A. Debe ser al
!>          menos 1 y al menos max( NN ).
!>

AP

!>          AP es array REAL de
!>                      dimensión( max(NN)*max(NN+1)/2 )
!>          La matriz A almacenada en formato empaquetado.
!>

SD

!>          SD es array REAL de
!>                             dimensión( max(NN) )
!>          La diagonal de la matriz tridiagonal calculada por SSYTRD.
!>          A la salida, SD y SE contienen la forma tridiagonal de
!>          la matriz en A.
!>

SE

!>          SE es array REAL de
!>                             dimensión( max(NN) )
!>          La subdiagonal de la matriz tridiagonal calculada por
!>          SSYTRD. A la salida, SD y SE contienen la forma tridiagonal de
!>          la matriz en A.
!>

D1

!>          D1 es array REAL de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por SSTEQR simultáneamente
!>          con Z. A la salida, los valores propios en D1 corresponden con la
!>          matriz en A.
!>

D2

!>          D2 es array REAL de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por SSTEQR si Z no se
!>          calcula. A la salida, los valores propios en D2 corresponden con la
!>          matriz en A.
!>

D3

!>          D3 es array REAL de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por SSTERF. A la salida, los
!>          valores propios en D3 corresponden con la matriz en A.
!>

D4

!>          D4 es array REAL de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por SPTEQR(V).
!>          ZPTEQR factoriza S como  Z4 D4 Z4*
!>          A la salida, los valores propios en D4 corresponden con la matriz en A.

D5

!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por SPTEQR(N)
!>          cuando Z no se calcula. A la salida, los
!>          valores propios en D4 corresponden con la matriz en A.
!>

WA1

!>          WA1 es array REAL de
!>                             dimensión( max(NN) )
!>          Todos los valores propios de A, calculados con alta

WA2

!>          WA2 es array REAL de
!>                             dimensión( max(NN) )
!>          Valores propios seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          calculados por SSTEBZ.
!>          Elija valores aleatorios para IL y IU, y solicite los
!>          valores propios del IL al IU.
!>

WA3

!>          WA3 es array REAL de
!>                             dimensión( max(NN) )
!>          Valores propios seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          calculados por SSTEBZ.
!>          Determine los valores VL y VU de los valores propios IL e IU
!>          y solicite todos los valores propios en este rango.
!>

WR

!>          WR es array REAL de
!>                             dimensión( max(NN) )
!>          Todos los valores propios de A, calculados con alta
!>          precisión absoluta, con diferentes opciones.
!>          calculados por SSTEBZ.
!>

U

!>          U es array REAL de
!>                             dimensión( LDU, max(NN) ).
!>          La matriz ortogonal calculada por SSYTRD + SORGTR.
!>

LDU

!>          LDU es ENTERO
!>          La dimensión principal de U, Z e V. Debe ser al menos 1
!>          y al menos max( NN ).
!>

V

!>          V es array REAL de
!>                             dimensión( LDU, max(NN) ).
!>          Los vectores de Householder calculados por SSYTRD al reducir A
!>          a forma tridiagonal. Los vectores calculados con UPLO='U' están
!>          en el triángulo superior, y los vectores calculados con UPLO='L'
!>          están en el triángulo inferior. (Como se describe en SSYTRD, la
!>          sub- y superdiagonal no se establecen en 1, aunque el
!>          vector de Householder real tiene un 1 en esa posición. Las
!>          rutinas que usan V, como SORGTR, establecen esas entradas a
!>          1 antes de usarlas, y luego las restauran más tarde).
!>

VP

!>          VP es array REAL de
!>                      dimensión( max(NN)*max(NN+1)/2 )
!>          La matriz V almacenada en formato empaquetado.
!>

TAU

!>          TAU es array REAL de
!>                             dimensión( max(NN) )
!>          Los factores de Householder calculados por SSYTRD al reducir A
!>          a forma tridiagonal.
!>

Z

!>          Z es array REAL de
!>                             dimensión( LDU, max(NN) ).
!>          La matriz ortogonal de vectores propios calculada por SSTEQR,
!>          SPTEQR y SSTEIN.
!>

WORK

!>          WORK es array REAL de
!>                      dimensión( LWORK )
!>

LWORK

!>          LWORK es ENTERO
!>          El número de elementos en WORK. Debe ser al menos

IWORK

!>          IWORK es array ENTERO,
!>          Espacio de trabajo.

LIWORK
