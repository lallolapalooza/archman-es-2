SCALBLN(3P) Manual del programador de POSIX SCALBLN(3P)

PROLOG

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

scalbln, scalblnf, scalblnl, scalbn, scalbnf, scalbnl — calcular el exponente usando FLT_RADIX

SINOPSIS

#include <math.h>
double scalbln(double x, long n);
float scalblnf(float x, long n);
long double scalblnl(long double x, long n);
double scalbn(double x, int n);
float scalbnf(float x, int n);
long double scalbnl(long double x, int n);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones calcularán x * FLT_RADIXn de manera eficiente, normalmente sin calcular explícitamente FLT_RADIXn.

Una aplicación que desee verificar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno es distinto de cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) es distinto de cero, ha ocurrido un error.

VALOR DEVUELTO

Al completarse con éxito, estas funciones devolverán x * FLT_RADIXn.

Si el resultado causara un desbordamiento, ocurrirá un error de rango y estas funciones devolverán ±HUGE_VAL, ±HUGE_VALF y ±HUGE_VALL (según el signo de x) según corresponda al tipo de retorno de la función.

Si el valor correcto causara un subdesbordamiento, y no es representable, puede ocurrir un error de rango y scalbln(), scalblnf(), scalblnl(), scalbn(), scalbnf() y scalbnl() devolverán 0.0, o (si no se soporta el punto flotante IEC 60559) un valor definido por la implementación no mayor en magnitud que DBL_MIN, FLT_MIN, LDBL_MIN, DBL_MIN, FLT_MIN y LDBL_MIN, respectivamente.

Si x es NaN, se devolverá un NaN.

Si x es ±0 o ±Inf, se devolverá x.

Si n es 0, se devolverá x.

Si el valor correcto causara un subdesbordamiento, y es representable, puede ocurrir un error de rango y se devolverá el valor correcto.

ERRORES

Estas funciones fallarán si:

Error de Rango
El resultado se desborda.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se activará la excepción de punto flotante de desbordamiento.

Estas funciones pueden fallar si:

Error de Rango
El resultado subdesborda.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se activará la excepción de punto flotante de subdesbordamiento.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO POR APLICACIONES

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.

FUNDAMENTO

Estas funciones se nombran para evitar conflictos con la definición histórica de la función scalb() de la Single UNIX Specification. La diferencia es que la función scalb() tiene un segundo argumento de double en lugar de int. La función scalb() no forma parte del estándar ISO C. Las tres funciones cuyo segundo tipo es long se proporcionan porque el factor necesario para escalar desde el valor de punto flotante positivo más pequeño hasta el valor finito más grande, en muchas implementaciones, es demasiado grande para representarlo en el formato int de ancho mínimo.
