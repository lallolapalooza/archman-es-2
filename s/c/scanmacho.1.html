SCANMACHO(1) Documentación de pax-utils SCANMACHO(1)

NOMBRE

scanmacho - utilidad de espacio de usuario para escanear archivos Mach-O

SINOPSIS

scanmacho [opciones] Mach-Os o directorios

DESCRIPCIÓN

scanmacho es una utilidad de espacio de usuario para escanear rápidamente los Mach-Os, directorios o rutas del sistema dadas para obtener diferentes informaciones. Esto puede incluir tipos de Mach-O, sus install_names, etc...

Debido a que los archivos Mach-O pueden ser "fat" (gordos), es posible que un solo archivo devuelva múltiples líneas. Cada línea representa una arquitectura única, contenida en el archivo fat (universal). Si bien no hay restricciones reales, en la práctica, las entradas se pueden distinguir por su tipo de arquitectura, por ejemplo, ppc, ppc64, i386, x86_64, arm, ...

OPCIONES

-A, --archives

Escanear archivos (.a)

-a, --all

Imprimir toda la información útil/simple

-B, --nobanner

No mostrar la cabecera

-b, --bind

Imprimir las banderas del mach_header

-D, --endian

Imprimir el endianness del Mach-O

-E, --etype filetype

Imprimir solo archivos Mach-O que coincidan con el etype especificado (como MH_EXECUTABLE, MH_DYLIB, etc.)

-F, --format FORMATO

Usar el formato especificado para la salida; ver la sección FORMATO para más información.

-f, --from ARCHIVO

Leer el flujo de entrada del nombre de archivo especificado

-g, --gmatch

Usar strncmp para comparar bibliotecas (usar con -N). O regexp con comparación de símbolos

-h, --help

Mostrar uso condensado y salir

-i, --interp

Imprimir la información del intérprete (LC_LOAD_DYLINKER)

-M, --bits BITS

Imprimir solo archivos Mach-O que coincidan con los bits numéricos especificados (como 32/64)

-m, --mount

No cruzar recursivamente los puntos de montaje

-N, --lib INSTALLNAME

Encontrar Mach-Os que necesiten el INSTALL_NAME especificado

-n, --needed

Imprimir las bibliotecas contra las que está enlazado el Mach-O (LC_LOAD_DYLIB).

-O, --perms PERMISOS

Imprimir solo archivos Mach-O con los bits octales especificados coincidentes (como 755).

-o, --file ARCHIVO

Escribir el flujo de salida en el nombre de archivo especificado.

-p, --path

Escanear todos los directorios en la variable de entorno PATH.

-q, --quiet

Solo generar salida de cosas 'malas'.

-R, --recursive

Escanear directorios recursivamente

-r, --rpath

Imprimir RPATH codificado en el Mach-O (LC_RPATH)

-S, --soname

Imprimir el nombre de la biblioteca compartida del Mach-O (install_name).

-V, --version

Imprimir versión y salir

-v, --verbose

Ser verboso (se puede usar más de una vez)

-y, --symlink

No escanear enlaces simbólicos

-Z, --size TAMAÑO

Imprimir el tamaño del archivo Mach-O

FORMATO

La cadena de formato es muy similar a una cadena de printf, en el sentido de que es una cadena literal con indicadores que solicitan diferentes informaciones. Por ejemplo, podrías usar una cadena de formato y esperar los siguientes resultados.

  # scanmacho -BF "archivo %f necesita %n; hora rara" /bin/bash
  archivo bash necesita /usr/lib/libncurses.5.4.dylib,/usr/lib/libSystem.B.dylib; hora rara

Tenga en cuenta que cuando usa una cadena de formato, generalmente se deben omitir las opciones relacionadas con la información. Es decir, no querrá intentar solicitar la salida de NECESARIOS (-n) e intentar especificar una salida de formato al mismo tiempo, ya que estas operaciones son mutuamente excluyentes. Cada opción relacionada con la información tiene un especificador de conversión equivalente, así que úselos en su lugar. Por supuesto, puede seguir utilizando opciones no relacionadas con la información (como --verbose).

Hay tres caracteres que introducen especificadores de conversión.

• % - reemplazar con información

•
# - coincidencia booleana silenciosa
•
+ - coincidencia verbosa

Y hay una serie de especificadores de conversión. Intentamos que el especificador coincida con la opción correspondiente.

• a - tipo de arquitectura

•
b - banderas del mach_header
•
D - endianness
•
F - nombre de archivo largo
•
f - nombre de archivo corto
•
i - dyld
•
M - clase CPU_TYPE
•
N - necesitado especificado
•
n - bibliotecas necesarias
•
p - nombre de archivo (sin búsqueda)
•
o - tipo mh
•
O - permisos
•
r - rpaths
•
S - install_name

TIPOS DE ARCHIVO MACH-O

Puedes acotar tu búsqueda especificando el tipo de archivo objeto Mach-O. La opción de línea de comandos toma el nombre simbólico del tipo. Se pueden pasar varios valores separados por comas. Ejemplo: -E MH_EXECUTE,MH_DYLIB

Aquí está la lista normal disponible para tu disfrute.

• MH_OBJECT - archivo objeto intermedio (.o)

•
MH_EXECUTE - programa ejecutable estándar
•
MH_BUNDLE - plugin dlopen (.bundle)
•
MH_DYLIB - biblioteca dinámica compartida (.dylib)
•
MH_PRELOAD - ejecutable no cargado por el kernel de Mac OS X (ROM)
•
MH_CORE - archivo de volcado de núcleo del programa
•
MH_DYLINKER - biblioteca compartida del enlazador dinámico (dyld)
•
MH_DYLIB_STUB - stub de biblioteca compartida solo para estática, sin secciones
•
MH_DSYM - archivo de símbolos de depuración (en directorio .dSYM)

BITS MACH-O

También puedes acotar tu búsqueda especificando el tamaño en bits del Mach-O. Especifica el valor numérico.

• 32 - mach_header de 32 bits

•
64 - mach_header_64 de 64 bits
