NOMBRE

scsi_ready - realizar TEST UNIT READY de SCSI en dispositivos

SINOPSIS

scsi_ready [--brief] [--help] [--verbose] DISPOSITIVO [DISPOSITIVO]*

DESCRIPCIÓN

Este script de shell bash llama a la utilidad sg_turs en cada DISPOSITIVO proporcionado. Esto enviará un comando TEST UNIT READY de SCSI a cada DISPOSITIVO. Discos duros, unidades de cinta y reproductores de DVD/BD, entre otros, pueden responder a este comando SCSI.

OPCIONES

Los argumentos de las opciones largas son obligatorios también para las opciones cortas.

-b, --brief
para cada DISPOSITIVO dado, imprimir una línea que contenga ' listo' o ' dispositivo no listo'. Si el DISPOSITIVO no se encuentra o hay otro error grave, aparecerá un mensaje de error en su lugar.
-h, --help
imprimir el mensaje de uso y salir.
-v, --verbose
aumentar el nivel de verbosidad.

ESTADO DE SALIDA

El estado de salida de este script es 0 cuando es exitoso. De lo contrario, el estado de salida es el de la última utilidad sg_turs llamada. Ver la página del manual sg3_utils(8).
