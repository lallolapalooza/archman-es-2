subroutine schkec (real thresh, logical tsterr, integer nin, integer nout)

SCHKEC

Propósito:

!>
!> SCHKEC prueba las rutinas de estimación de condición de autovalores
!>        SLALN2, SLASY2, SLANV2, SLAQTR, SLAEXC,
!>        STRSYL, STREXC, STRSNA, STRSEN, STGEXC
!>
!> En todos los casos, la rutina recorre un conjunto fijo de ejemplos numéricos,
!> los somete a varias pruebas y compara los resultados de las pruebas con un
!> umbral THRESH. Además, STREXC, STRSNA y STRSEN se prueban leyendo ejemplos
!> precalculados de un archivo (en la unidad de entrada NIN). La salida se
!> escribe en la unidad de salida NOUT.
!>

Parámetros

THRESH 
!>          THRESH es REAL
!>          Umbral para pruebas de residuos. Una relación de prueba calculada
!>          pasa el umbral si es menor que THRESH.
!>

TSTERR

!>          TSTERR es LOGICAL
!>          Indicador que señala si se deben probar las salidas de error.
!>

NIN

!>          NIN es INTEGER
!>          El número de unidad lógica para la entrada.
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad lógica para la salida.
!>
