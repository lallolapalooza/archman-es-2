SCHKSB2STG

Propósito:

!>
!> SCHKSB2STG prueba la reducción de una matriz banda simétrica a forma tridiagonal,
!> utilizada con el problema de valores propios simétricos.
!>
!> SSBTRD factoriza una matriz banda simétrica A como  U S U' , donde ' significa
!> transpuesta, S es tridiagonal simétrica y U es ortogonal.
!> SSBTRD puede usar solo el triángulo inferior o solo el triángulo superior
!> de A; SCHKSB2STG verifica ambos casos.
!>
!> SSYTRD_SB2ST factoriza una matriz banda simétrica A como  U S U' ,
!> donde ' significa transpuesta, S es tridiagonal simétrica y U es
!> ortogonal. SSYTRD_SB2ST puede usar solo el triángulo inferior o solo
!> el triángulo superior de A; SCHKSB2STG verifica ambos casos.
!>
!> SSTEQR factoriza S como  Z D1 Z'.
!> D1 es la matriz de valores propios calculados cuando Z no se calcula
!> y a partir de S resultante de SSBTRD  (usada como referencia para SSYTRD_SB2ST)
!> D2 es la matriz de valores propios calculados cuando Z no se calcula
!> y a partir de S resultante de SSYTRD_SB2ST .
!> D3 es la matriz de valores propios calculados cuando Z no se calcula
!> y a partir de S resultante de SSYTRD_SB2ST .
!>
!> Cuando se llama a SCHKSB2STG, se especifican un número de tamaños de matriz  (),
!> un número de anchos de banda () y un número de tipos de matriz.
!> Para cada tamaño (), cada ancho de banda () menor o igual que , y cada tipo de matriz,
!> se generará y usará una matriz para probar la rutina de reducción banda simétrica.
!> Para cada matriz, se realizarán una serie de pruebas:
!>
!> (1)     | A - V S V' | / ( |A| n ulp )  calculado por SSBTRD con
!>                                         UPLO='U'
!>
!> (2)     | I - UU' | / ( n ulp )
!>
!> (3)     | A - V S V' | / ( |A| n ulp )  calculado por SSBTRD con
!>                                         UPLO='L'
!>
!> (4)     | I - UU' | / ( n ulp )
!>
!> (5)     | D1 - D2 | / ( |D1| ulp )      donde D1 se calcula por
!>                                         SSBTRD con UPLO='U' y
!>                                         D2 se calcula por
!>                                         SSYTRD_SB2ST con UPLO='U'
!>
!> (6)     | D1 - D3 | / ( |D1| ulp )      donde D1 se calcula por
!>                                         SSBTRD con UPLO='U' y
!>                                         D3 se calcula por
!>                                         SSYTRD_SB2ST con UPLO='L'
!>
!> Los  se especifican mediante un array NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo  .
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>      1, ..., ULP  y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>      1, ..., ULP  y signos aleatorios.
!> (5)  Una matriz diagonal con entradas  1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!> (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (8)  Una matriz de la forma  U' D U, donde U es ortogonal y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (9)  Una matriz de la forma  U' D U, donde U es ortogonal y
!>      D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (10) Una matriz de la forma  U' D U, donde U es ortogonal y
!>      D tiene entradas  1, ULP,..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SCHKSB2STG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,

!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un array INTEGER, dimension (4)
!>          A la entrada ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina.
!>          Los valores de ISEED se modifican a la salida y pueden usarse en la
!>          siguiente llamada a SCHKSB2STG para continuar la misma secuencia de
!>          números aleatorios.
!>

THRESH

!>          razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple o doble) ni del tamaño de

NAME

schksb2stg - Calculates the eigenvalues and eigenvectors of a symmetric tridiagonal matrix.

Function/Subroutine Documentation

This subroutine tests the driver subroutine SSBTRD and the non-symmetric tridiagonal eigenvalue routines SBDSVD, SBDSIM, SBDSLR, SBDSCL, SBDSMN, and SBDSMP.

It generates random symmetric block circulant matrices and checks if the computed eigenvalues and eigenvectors satisfy the required properties.

The tests performed are:

  1. Check if the computed eigenvalues are real and in the correct range.

  2. Check if the computed eigenvectors are orthogonal.

  3. Check if the computed eigenvalues and eigenvectors satisfy the eigenvalue equation A*V = Lambda*V.

The subroutine uses the following parameters:

  • N: The order of the matrix.

  • NM: The maximum order of the matrix.

  • KD: The number of diagonals of the matrix (usually 1 for tridiagonal).

  • M: The number of eigenvalues and eigenvectors to be computed.

  • NB: The block size for blocking the computation.

  • ISEED: The seed for the random number generator.

  • THRESH: The threshold for testing the error bounds. If an error is greater than THRESH times the machine precision, it is considered significant.

  • NOUNIT: The FORTRAN unit number for printing error messages.

  • A: The input matrix.

  • LDA: The leading dimension of the array A.

  • SD: The diagonal of the tridiagonal matrix computed by SSBTRD.

  • SE: The off-diagonal of the tridiagonal matrix computed by SSBTRD.

  • D1, D2, D3: Auxiliary arrays used in the computation.

  • U: The orthogonal matrix computed by SSBTRD.

  • LDU: The leading dimension of the array U.

  • WORK: A work array used for intermediate computations.

  • LWORK: The size of the work array. It must be at least max( LDA+1, max(NN)+1 )*max(NN).

  • RESULT: An array of size 4 containing the computed test values.

  • INFO: An integer flag indicating the success of the computation. 0 indicates success.

Local variables and parameters:

  • ZERO, ONE: Real constants 0 and 1.

  • MAXTYP: The number of matrix types defined.

  • NTEST: The number of tests performed for the current matrix.

  • NTESTT: The total number of tests performed so far.

  • NMAX: The largest value in NN.

  • NMATS: The number of matrices generated so far.

  • NERRS: The number of tests that have exceeded THRESH.

  • COND, IMODE: Values passed to the matrix generators.

  • ANORM: Norm of A; passed to the matrix generators.

  • OVFL, UNFL: Overflow and underflow thresholds.

  • ULP, ULPINV: Finest relative precision and its inverse.

  • RTOVFL, RTUNFL: Square roots of the previous two values.

  • KTYPE(j): The general type (1-10) for type j.

  • KMODE(j): The MODE value passed to the matrix generator for type j.

  • KMAGN(j): The order of magnitude ( O(1), O(overflow^(1/2) ), O(underflow^(1/2) ) ).

The condition for the leading dimension LDA of A is that it must be at least 2 (not 1!) and at least max( KK )+1. The condition for the leading dimension LDU of U is that it must be at least 1 and at least max( NN ).

The size of the WORK array LWORK must be at least max( LDA+1, max(NN)+1 )*max(NN).

The values in the RESULT array are limited to 1/ulp to avoid overflow.
