sctp_connectx(3)

SCTP_CONNECTX(3) Manual del programador de Linux SCTP_CONNECTX(3)

NOMBRE

sctp_connectx - inicia una conexión en un socket SCTP utilizando múltiples direcciones de destino.

SINOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_connectx(int sd, struct sockaddr * addrs, int addrcnt,
                  sctp_assoc_t  * id);

DESCRIPCIÓN

sctp_connectx inicia una conexión a un conjunto de direcciones pasadas en el array addrs desde/hacia el socket sd. addrcnt es el número de direcciones en el array.

Si sd es un socket IPv4, las direcciones pasadas deben ser direcciones IPv4. Si sd es un socket IPv6, las direcciones pasadas pueden ser direcciones IPv4 o IPv6.

addrs es un puntero a un array de una o más direcciones de socket. Cada dirección está contenida en su estructura apropiada (es decir, struct sockaddr_in o struct sockaddr_in6). La familia del tipo de dirección debe usarse para distinguir la longitud de la dirección. El llamador especifica el número de direcciones en el array con addrcnt.

id es un puntero al identificador de la asociación y, si se proporciona, se establecerá en el identificador de la asociación recién creada.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de fallo, se devuelve -1 y se establece errno apropiadamente.

ERRORES

EBADF
sd no es un descriptor válido.
ENOTSOCK
sd es un descriptor de un archivo, no de un socket.
EFAULT
Error al copiar desde o hacia el espacio de direcciones del usuario.
EINVAL
Puerto o dirección inválidos.
EACCES
La dirección está protegida y el usuario no es el superusuario.
EISCONN
El socket ya está conectado.
ECONNREFUSED
Nadie está escuchando en la dirección remota.
ETIMEDOUT
Tiempo de espera agotado al intentar la conexión. El servidor puede estar demasiado ocupado para aceptar nuevas conexiones. Tenga en cuenta que para los sockets IP, el tiempo de espera puede ser muy largo cuando se habilitan las syncookies en el servidor.
ENETUNREACH
La red es inalcanzable.
EADDRINUSE
La dirección local ya está en uso.
EINPROGRESS
El socket no está bloqueado y la conexión no se puede completar inmediatamente. Es posible usar select(2) o poll(2) para la finalización seleccionando el socket para escritura. Después de que select indique que está listo para escribir, use getsockopt(2) para leer la opción SO_ERROR en el nivel SOL_SOCKET para determinar si connect se completó con éxito (SO_ERROR es cero) o con un error (SO_ERROR es uno de los códigos de error habituales enumerados aquí, que explican el motivo del fallo).
EALREADY
El socket no está bloqueado y un intento de conexión anterior aún no se ha completado.
EAGAIN
No quedan puertos locales libres o no hay suficientes entradas en la caché de enrutamiento. Para PF_INET, consulte el sysctl net.ipv4.ip_local_port_range en ip(7) sobre cómo aumentar el número de puertos locales.
EAFNOSUPPORT
La dirección pasada no tenía la familia de direcciones correcta en su campo sa_family.
EACCES, EPERM
El usuario intentó conectarse a una dirección de broadcast sin tener habilitada la bandera de broadcast del socket o la solicitud de conexión falló debido a una regla de firewall local.
