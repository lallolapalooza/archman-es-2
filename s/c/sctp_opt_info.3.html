SCTP_OPT_INFO(3) Manual del programador de Linux SCTP_OPT_INFO(3)

NOMBRE

sctp_opt_info - Obtener opciones en un socket SCTP.

SINOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_opt_info(int sd, sctp_assoc_t id, int opt,
                  void * arg, socklen_t * size);

DESCRIPCIÓN

sctp_opt_info es una función de biblioteca envoltorio que puede utilizarse para obtener opciones de nivel SCTP en un socket. sd es el descriptor del socket para el que se solicita la opción. Para sockets de estilo uno a muchos, id especifica la asociación a consultar. Para sockets de estilo uno a uno, id se ignora. opt especifica la opción del socket SCTP a obtener. arg es un búfer de estructura específico de la opción proporcionado por el llamante. size es un parámetro de valor-resultado, que inicialmente contiene el tamaño del búfer apuntado por arg y se modifica al devolver para indicar el tamaño real del valor devuelto.

VALOR DE RETORNO

En caso de éxito, sctp_opt_info devuelve 0 y en caso de fallo, -1 se devuelve con errno establecido en el código de error apropiado.
