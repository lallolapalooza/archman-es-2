scanimage(1) Acceso Sencillo a Escáneres SANE scanimage(1)

NOMBRE

scanimage - escanear una imagen

SINOPSIS

scanimage [-d dev] [--format=formato-salida] [-i perfil] [-L] [-f formato-dispositivo] [-b [formato]] [--batch-start=inicio] [--batch-count=conteo] [--batch-increment=incremento] [--batch-double] [--accept-md5-only] [-p] [-o ruta] [-n] [-T] [-A] [-h] [-v] [-B tamaño] [-V] [opciones-especificas-del-dispositivo]

DESCRIPCIÓN

scanimage es una interfaz de línea de comandos para controlar dispositivos de adquisición de imágenes como escáneres planos o cámaras. El dispositivo se controla mediante opciones de línea de comandos. Después del procesamiento de la línea de comandos, scanimage normalmente procede a adquirir una imagen. Los datos de la imagen se escriben en la salida estándar en uno de los formatos PNM (portable aNyMaP) (PBM para imágenes en blanco y negro, PGM para imágenes en escala de grises y PPM para imágenes en color), formato TIFF (blanco y negro, escala de grises o color), formato PNG o formato JPEG (nivel de compresión 75). scanimage accede a los dispositivos de adquisición de imágenes a través de la interfaz SANE (Scanner Access Now Easy) y, por lo tanto, puede admitir cualquier dispositivo para el que exista un backend de SANE (intente apropos sane- para obtener una lista de backends disponibles).

EJEMPLOS

Para obtener una lista de dispositivos:


scanimage -L

Para escanear con la configuración predeterminada al archivo image.pnm:


scanimage >image.pnm

Para escanear 100x100 mm al archivo image.tiff ( -x y -y pueden no estar disponibles con todos los dispositivos):


scanimage -x 100 -y 100 --format=tiff >image.tiff

Para imprimir todas las opciones disponibles:


scanimage -h

OPCIONES

Hay dos conjuntos de opciones disponibles al ejecutar scanimage.

Las opciones proporcionadas por el propio scanimage se enumeran a continuación. Además, cada backend ofrece su propio conjunto de opciones y estas también se pueden especificar. Tenga en cuenta que las opciones disponibles del backend pueden variar según el dispositivo de escaneo que se seleccione.

A menudo, las opciones que son similares en función pueden implementarse de manera diferente entre los backends. Un ejemplo de esta diferencia es --mode Gray y --mode Grayscale. Esto puede deberse a las preferencias variables de los autores de los backends. En otras ocasiones, las opciones son definidas por el propio dispositivo de escaneo y, por lo tanto, están fuera del control del código del backend.

Los parámetros están separados por un espacio de las opciones de un solo carácter (por ejemplo, -d epson) y por un "=" de las opciones de varios caracteres (por ejemplo, --device-name=epson).

-d dev, --device-name=dev
especifica el dispositivo al que acceder y debe ir seguido de un nombre de dispositivo SANE como `epson:/dev/sg0' o `hp:/dev/usbscanner0'. Una lista (parcial) de los dispositivos disponibles se puede obtener con la opción --list-devices (ver más abajo). Si no se especifica explícitamente un nombre de dispositivo, scanimage lee un nombre de dispositivo de la variable de entorno SANE_DEFAULT_DEVICE. Si esta variable no está configurada, scanimage intentará abrir el primer dispositivo disponible.
--format=formato-salida
selecciona cómo se escriben los datos de la imagen en la salida estándar o en el archivo especificado por la opción --output-file. formato-salida puede ser pnm, tiff, png o jpeg. Si no se especifica --format, se escribe PNM por defecto.
-i perfil, --icc-profile=perfil
se utiliza para incluir un perfil ICC en un archivo TIFF.
-L, --list-devices
solicita una lista (parcial) de los dispositivos que están disponibles. La lista puede no estar completa, ya que algunos dispositivos pueden estar disponibles pero no listados en ninguno de los archivos de configuración (que generalmente se almacenan en el directorio /etc/sane.d). Este es particularmente el caso al acceder a escáneres a través de la red. Si un dispositivo no está listado en un archivo de configuración, la única forma de acceder a él es mediante su nombre de dispositivo completo. Puede que necesite consultar a su administrador del sistema para averiguar los nombres de dichos dispositivos.
-f formato, --formatted-device-list=formato-dispositivo
funciona de manera similar a --list-devices, pero requiere una cadena de formato. scanimage reemplaza los marcadores %d %v %m %t %i %n con el nombre del dispositivo, nombre del proveedor, nombre del modelo, tipo de escáner, un número de índice y un salto de línea respectivamente. El comando
scanimage -f “ escáner número %i dispositivo %d es un %t, modelo %m, producido por %v ”

producirá algo como:

escáner número 0 dispositivo sharp:/dev/sg1 es un escáner plano, modelo JX250 SCSI, producido por SHARP

Las opciones --batch* proporcionan funciones para escanear documentos utilizando alimentadores de documentos.

-b [formato], --batch=[formato]
se utiliza para especificar el formato del nombre de archivo en el que se escribirá cada página. Cada página se escribe en un solo archivo. Si no se especifica formato, se usará el predeterminado out%d.pnm (o out%d.tif para --format tiff, out%d.png para --format png o out%d.jpg para --format jpeg). Esta opción es incompatible con la opción --output-path. formato se proporciona como una cadena de estilo printf con un parámetro entero.
--batch-start=inicio
selecciona el número de página con el que se comenzará a nombrar los archivos. Si no se proporciona esta opción, el contador comenzará en 1.
--batch-count=conteo
especifica el número de páginas que se intentarán escanear. Si no se proporciona, scanimage continuará escaneando hasta que el escáner devuelva un estado diferente de OK. No todos los escáneres con alimentadores de documentos señalan cuándo el ADF está vacío. Utilice esta opción para solucionar problemas con ellos.
--batch-increment=incremento
establece la cantidad en la que se incrementa el número en el nombre de archivo. Generalmente, esto se usa cuando se escanean documentos a doble cara en un alimentador de documentos a una sola cara. --batch-double es un comando específico proporcionado para ayudar con esto.
--batch-double
establecerá automáticamente el incremento en 2. Equivale a --batch-increment=2.
--batch-prompt
pedirá presionar RETURN antes de escanear una página. Esto se puede usar para escanear múltiples páginas sin un alimentador automático de documentos.
--accept-md5-only
solo acepta solicitudes de autorización de usuario que admitan seguridad MD5. El demonio de red SANE saned(8) es capaz de realizar dichas solicitudes.
-p, --progress
solicita que scanimage imprima un contador de progreso. Muestra cuántos datos de imagen de la imagen actual ya se han recibido (en porcentaje).
-o ruta, --output-file=ruta
solicita que scanimage guarde la salida del escaneo en la ruta dada. Esta opción es incompatible con la opción --batch. El programa intentará adivinar --format a partir del nombre del archivo. Si eso no es posible, imprimirá un mensaje de error y saldrá.
