programa sblat2

SBLAT2

Propósito:

!>
!> Programa de prueba para el Nivel 2 REAL de BLAS.
!>
!> El programa debe ser controlado por un archivo de datos corto. Los primeros 18 registros
!> del archivo se leen usando entrada de lista dirigida, los últimos 16 registros
!> se leen usando el formato ( A6, L2 ). Un ejemplo anotado de un archivo de datos
!> se puede obtener eliminando los primeros 3 caracteres de las siguientes 34 líneas:
!> 'sblat2.out'      NOMBRE DEL ARCHIVO DE SALIDA DE RESUMEN
!> 6                 NÚMERO DE UNIDAD DEL ARCHIVO DE RESUMEN
!> 'SBLAT2.SNAP'     NOMBRE DEL ARCHIVO DE SALIDA DE INSTANTÁNEA
!> -1                NÚMERO DE UNIDAD DEL ARCHIVO DE INSTANTÁNEA (NO USADO SI .LT. 0)
!> F        BANDERA LÓGICA, T PARA REBOBINAR EL ARCHIVO DE INSTANTÁNEA DESPUÉS DE CADA REGISTRO.
!> F        BANDERA LÓGICA, T PARA DETENERSE EN CASOS DE FALLO.
!> T        BANDERA LÓGICA, T PARA PROBAR LAS SALIDAS DE ERROR.
!> 16.0     VALOR UMBRAL DE LA RELACIÓN DE PRUEBA
!> 6                 NÚMERO DE VALORES DE N
!> 0 1 2 3 5 9       VALORES DE N
!> 4                 NÚMERO DE VALORES DE K
!> 0 1 2 4           VALORES DE K
!> 4                 NÚMERO DE VALORES DE INCX E INCY
!> 1 2 -1 -2         VALORES DE INCX E INCY
!> 3                 NÚMERO DE VALORES DE ALPHA
!> 0.0 1.0 0.7       VALORES DE ALPHA
!> 3                 NÚMERO DE VALORES DE BETA
!> 0.0 1.0 0.9       VALORES DE BETA
!> SGEMV  T PONE F PARA NO PROBAR. MISMAS COLUMNAS.
!> SGBMV  T PONE F PARA NO PROBAR. MISMAS COLUMNAS.
!> SSYMV  T PONE F PARA NO PROBAR. MISMAS COLUMNAS.
!> SSBMV  T PONE F PARA NO PROBAR. MISMAS COLUMNAS.
!> SSPMV  T PONE F PARA NO PROBAR. MISMAS COLUMNAS.
!> STRMV  T PONE F PARA NO PROBAR. MISMAS COLUMNAS.
!> STBMV  T PONE F PARA NO PROBAR. MISMAS COLUMNAS.

!> STRSV  T PONE F PARA NO PROBAR. MISMAS COLUMNAS.
!> STBSV  T PONE F PARA NO PROBAR. MISMAS COLUMNAS.
