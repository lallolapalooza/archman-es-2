scalb(3) Manual de funciones de biblioteca scalb(3)

NOMBRE

scalb, scalbf, scalbl — escalar por una potencia entera de la base (OBSOLETO)

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
[[deprecated]] double scalb(double x, double e);
[[deprecated]] float scalbf(float x, float e);
[[deprecated]] long double scalbl(long double x, long double e);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

scalb():

    _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

scalbf(), scalbl():

    _XOPEN_SOURCE >= 600
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones multiplican su primer argumento x por FLT_RADIX (probablemente 2) elevado a la potencia e, es decir:

    x * FLT_RADIX ** e

La definición de FLT_RADIX se puede obtener incluyendo <float.h>.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven x * FLT_RADIX ** e.

Si x o e es un NaN, se devuelve un NaN.

Si x es infinito positivo (infinito negativo) y e no es infinito negativo, se devuelve infinito positivo (infinito negativo).

Si x es +0 (-0) y e no es infinito positivo, se devuelve +0 (-0).

Si x es cero y e es infinito positivo, se produce un error de dominio y se devuelve un NaN.

Si x es un infinito y e es infinito negativo, se produce un error de dominio y se devuelve un NaN.

Si el resultado desborda, se produce un error de rango y las funciones devuelven HUGE_VAL, HUGE_VALF o HUGE_VALL, respectivamente, con un signo igual al de x.

Si el resultado subdesborda, se produce un error de rango y las funciones devuelven cero, con un signo igual al de x.

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si se ha producido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es 0 y e es infinito positivo, o x es infinito positivo y e es infinito negativo y el otro argumento no es un NaN
errno se establece en EDOM. Se genera una excepción de punto flotante no válida (FE_INVALID).
Error de rango, desbordamiento
errno se establece en ERANGE. Se genera una excepción de punto flotante por desbordamiento (FE_OVERFLOW).
Error de rango, subdesbordamiento
errno se establece en ERANGE. Se genera una excepción de punto flotante por subdesbordamiento (FE_UNDERFLOW).

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
scalb (), scalbf (), scalbl () Seguridad en hilos MT-Safe

ESTÁNDARES

Ninguno.

HISTORIA

scalb()
4.3BSD. Obsoleto en POSIX.1-2001; Eliminado en POSIX.1-2008, recomendando el uso de scalbln(3), scalblnf(3) o scalblnl(3) en su lugar.

ERRORES DE PROGRAMACIÓN

Antes de glibc 2.20, estas funciones no establecían errno para errores de dominio y rango.

VER TAMBIÉN

ldexp(3), scalbln(3)
