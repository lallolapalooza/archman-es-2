NOMBRE

sctp_recvv - Recibe un mensaje de un socket SCTP de forma extensible.

SINOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_recvv(int sd, const struct iovec * iov, int iovlen,
               struct sockaddr * from, socklen_t * fromlen, void * info,
               socklen_t * infolen, unsigned int * infotype, int * flags);

DESCRIPCIÓN

sctp_recvv proporciona una forma extensible para que la pila SCTP pase diferentes atributos SCTP asociados con un mensaje recibido a una aplicación. Hay dos tipos de atributos que pueden ser devueltos por esta llamada: el atributo del mensaje recibido y el atributo del siguiente mensaje en el búfer de recepción. El llamador habilita las opciones de socket SCTP_RECVRCVINFO y SCTP_RECVNXTINFO, respectivamente, para recibir estos atributos. Los atributos del mensaje recibido se devuelven en struct sctp_rcvinfo, y los atributos del siguiente mensaje se devuelven en struct sctp_nxtinfo. Si ambas opciones están habilitadas, ambos atributos se devuelven usando la siguiente estructura.


struct sctp_recvv_rn {
struct sctp_rcvinfo recvv_rcvinfo;
struct sctp_nxtinfo recvv_nxtinfo;
};

sd es el descriptor del socket. iov es el búfer de dispersión, y solo se devuelve un mensaje de usuario en este búfer. iovlen es el número de elementos en iov. from es un puntero a un búfer para ser llenado con la dirección del remitente del mensaje recibido. fromlen es un parámetro de entrada/salida que describe la longitud de origen. info es un puntero al búfer para almacenar los atributos del mensaje recibido, el tipo de estructura de info está determinado por el parámetro info_type. infolen es un parámetro de entrada/salida que describe el tamaño del búfer de info. Al regresar, infotype se establece en el tipo del búfer de info, y los valores definidos actualmente son los siguientes:

SCTP_RECVV_NOINFO
Si las opciones SCTP_RECVRCVINFO ni SCTP_RECVNXTINFO están habilitadas, no se devolverá ningún atributo. Si solo la opción SCTP_RECVNXTINFO está habilitada pero no hay un siguiente mensaje en el búfer, no se devolverá ningún atributo. En estos casos, *info_type se establecerá en SCTP_RECVV_NOINFO.
SCTP_RECVV_RCVINFO
El tipo de info es struct sctp_rcvinfo, y el atributo se relaciona con el mensaje recibido.
SCTP_RECVV_NXTINFO
El tipo de info es struct sctp_nxtinfo, y el atributo se relaciona con el siguiente mensaje en el búfer de recepción. Este es el caso cuando solo la opción SCTP_RECVNXTINFO está habilitada y hay un siguiente mensaje en el búfer.
SCTP_RECVV_RN
El tipo de info es struct sctp_recvv_rn. El campo recvv_rcvinfo es el atributo del mensaje recibido, y el campo recvv_nxtinfo es el atributo del siguiente mensaje en el búfer. Este es el caso cuando ambas opciones SCTP_RECVRCVINFO y SCTP_RECVNXTINFO están habilitadas y hay un siguiente mensaje en el búfer de recepción.

flags es un puntero a un entero que se llenará con cualquier bandera de mensaje (por ejemplo, MSG_NOTIFICATION).

VALOR DE RETORNO

Al tener éxito, sctp_recvv devuelve el número de bytes recibidos o -1 si ocurrió un error.
