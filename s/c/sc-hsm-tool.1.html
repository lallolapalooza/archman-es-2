NOMBRE

sc-hsm-tool - utilidad de tarjeta inteligente para SmartCard-HSM

SINOPSIS

sc-hsm-tool [OPCIONES]

La utilidad sc-hsm-tool se puede usar desde la línea de comandos para realizar tareas de mantenimiento extendidas no disponibles a través de PKCS#11 u otras herramientas del paquete OpenSC. Se puede utilizar para consultar el estado de un SmartCard-HSM, inicializar un dispositivo, generar e importar fragmentos de clave de cifrado de dispositivo (DKEK) y para envolver y desenvolver claves.

OPCIONES

--initialize, -X

Inicializa el token, eliminando todas las claves, certificados y archivos existentes.

Utilice --so-pin para definir el SO-PIN para la primera inicialización o para verificar en inicializaciones posteriores.

Utilice --pin para definir el valor inicial del PIN de usuario.

Utilice --pin-retry para definir el número máximo de intentos de PIN de usuario incorrectos.

Úselo con --dkek-shares para habilitar el cifrado/descifrado de claves.

Úselo con --label para definir una etiqueta de token.

Úselo con --public-key-auth y --required-pub-keys para requerir autenticación de clave pública para el inicio de sesión.

--create-dkek-share nombre_archivo, -C nombre_archivo

Crea un fragmento de DKEK cifrado con una contraseña y lo guarda en el archivo especificado como parámetro.

Utilice --password para proporcionar una contraseña para el cifrado en lugar de solicitarla.

Utilice --pwd-shares-threshold y --pwd-shares-total para generar aleatoriamente una contraseña y dividirla utilizando un esquema de umbral (t, n).

--import-dkek-share nombre_archivo, -I nombre_archivo

Solicita la contraseña del usuario, lee y descifra el fragmento de DKEK y lo importa al SmartCard-HSM.

Utilice --password para proporcionar una contraseña para el descifrado en lugar de solicitarla.

Utilice --pwd-shares-total para especificar el número de fragmentos que deben ingresarse para reconstruir la contraseña.

--wrap-key nombre_archivo, -W nombre_archivo

Envuelve la clave referenciada en --key-reference y la guarda junto con la descripción de la clave y el certificado en el archivo dado.

Utilice --pin para proporcionar el PIN de usuario en la línea de comandos.

--unwrap-key nombre_archivo, -U nombre_archivo

Lee la clave envuelta, la descripción y el certificado del archivo y los importa al SmartCard-HSM bajo la referencia de clave dada en --key-reference.

Determine la referencia de la clave utilizando la salida de pkcs15-tool -D.

Utilice --pin para proporcionar un PIN de usuario en la línea de comandos.

Utilice --force para eliminar cualquier clave, descripción de clave o certificado que se interponga.

--dkek-shares número_de_fragmentos, -s número_de_fragmentos

Define el número de fragmentos de DKEK a utilizar para recrear el DKEK.

Este es un parámetro opcional. Usar --initialize sin --dkek-shares deshabilitará completamente el DKEK.

Usar --dkek-shares con 0 fragmentos solicita al SmartCard-HSM que genere un DKEK aleatorio. Las claves envueltas con este DKEK solo se pueden desenvolver en el mismo SmartCard-HSM.

Después de usar --initialize con uno o más fragmentos de DKEK, el SmartCard-HSM permanecerá en el estado inicializado hasta que se importen todos los fragmentos de DKEK. Durante esta fase, no se pueden generar ni importar nuevas claves.

--pin pin, --so-pin sopin,

Estas opciones se pueden utilizar para especificar los valores de PIN en la línea de comandos. Si el valor se establece en env:VARIABLE, se utiliza el valor de la variable de entorno especificada. Por defecto, se solicita el código en la línea de comandos si es necesario.

Tenga en cuenta que en la mayoría de los sistemas operativos, cualquier usuario puede ver la línea de comandos de cualquier proceso en el sistema utilizando utilidades como ps(1). Por lo tanto, debería preferir pasar los códigos a través de una variable de entorno en un sistema no seguro.

--pin-retry valor

Define el número de reintentos de PIN para el PIN de usuario durante la inicialización. El valor predeterminado es 3.

--bio-server1 valor

El AID hexadecimal del servidor biométrico para la plantilla 1. Activa el uso del PIN de usuario como PIN de sesión.

--bio-server2 valor

El AID hexadecimal del servidor biométrico para la plantilla 2. Activa el uso del PIN de usuario como PIN de sesión.

--password valor

Define la contraseña para el cifrado de fragmentos de DKEK. Si se establece en env:VARIABLE, se utiliza el valor de la variable de entorno VARIABLE.

--pwd-shares-threshold valor

Define el umbral para el número de fragmentos de contraseña requeridos para la reconstrucción.

--pwd-shares-total valor

Define el número de fragmentos de contraseña.

--force

Fuerza la eliminación de la clave, descripción y certificado existentes.

--label etiqueta, -l etiqueta

Define la etiqueta del token a utilizar en --initialize.

--reader arg, -r arg

Número del lector a utilizar. Por defecto, se utiliza el primer lector con una tarjeta insertada. Si arg es un ATR, se elegirá el lector con una tarjeta coincidente.

--public-key-auth número_total_de_claves_públicas, -K número_total_de_claves_públicas

Define el número total de claves públicas a utilizar para la autenticación de clave pública al usar --initialize. --public-key-auth es opcional, pero si está presente, debe usarse con --required-pub-keys.

Cuando el SmartCard-HSM se inicializa con estas opciones, requerirá la autenticación de clave pública M de N, donde --required-pub-keys establece el M y --public-key-auth establece el N. Después de la inicialización, el usuario debe usar --register-public-key para registrar las N claves públicas antes de que el SmartCard-HSM pueda ser utilizado.

--required-pub-keys número_requerido_de_claves_públicas, -n número_requerido_de_claves_públicas

Define el número requerido de claves públicas a utilizar para la autenticación de clave pública al usar --initialize. Este es el M en la autenticación de clave pública M de N. Consulte --public-key-auth para obtener más información.

--register-public-key archivo_clave_pública_entrada, -g archivo_clave_pública_entrada

Registra una clave pública para ser utilizada en la autenticación de clave pública M de N. El archivo se puede exportar desde un SmartCard-HSM diferente con --export-for-pub-key-auth. Esto solo se puede usar cuando el SmartCard-HSM se ha inicializado con --public-key-auth y --required-pub-keys y se han registrado menos de N claves públicas. Utilice --public-key-auth-status para verificar cuántas claves públicas se han registrado.

--export-for-pub-key-auth archivo_clave_pública_salida, -e archivo_clave_pública_salida

Exporta una clave pública para ser utilizada en la autenticación de clave pública M de N. Esto debe usarse con --key-reference para elegir la clave a exportar. El archivo debe registrarse en otro SmartCard-HSM usando --register-public-key.

--public-key-auth-status -S

Imprime el estado de autenticación de clave pública. Esto solo es válido si el SmartCard-HSM se inicializó para usar autenticación de clave pública M de N.

--wait, -w

Espera a que se inserte una tarjeta.

--verbose, -v

Hace que sc-hsm-tool sea más detallado. Especifique este indicador varias veces para habilitar la salida de depuración en la biblioteca opensc.

EJEMPLOS

Crear un fragmento de DKEK:

sc-hsm-tool --create-dkek-share dkek-share-1.pbe

Crear un fragmento de DKEK con contraseña aleatoria dividida usando un esquema de umbral (3, 5):

sc-hsm-tool --create-dkek-share dkek-share-1.pbe --pwd-shares-threshold 3 --pwd-shares-total 5

Inicializar SmartCard-HSM para usar un único fragmento de DKEK:

sc-hsm-tool --initialize --so-pin 3537363231383830 --pin 648219 --dkek-shares 1 --label mi-token

Importar fragmento de DKEK:

sc-hsm-tool --import-dkek-share dkek-share-1.pbe

EJEMPLOS

Importar una parte de DKEK utilizando una contraseña dividida en un esquema de umbral (3, 5) para cifrado:

sc-hsm-tool --import-dkek-share dkek-share-1.pbe --pwd-shares-total 3

Envolver clave, descripción y certificado referenciados:

sc-hsm-tool --wrap-key wrap-key.bin --key-reference 1 --pin 648219

Desenvolver clave en la misma u otra SmartCard-HSM con el mismo DKEK:

sc-hsm-tool --unwrap-key wrap-key.bin --key-reference 10 --pin 648219 --force

Inicializar SmartCard-HSM para usar autenticación de clave pública M-de-N con M=2 y N=5

sc-hsm-tool --initialize --required-pub-keys 2 --public-key-auth 5

Exportar una clave pública para autenticación de clave pública M-de-N a un archivo

sc-hsm-tool --key-reference 1 --export-for-pub-key-auth ./public_key1.asn1

Registrar una clave pública para autenticación de clave pública M-de-N desde un archivo

sc-hsm-tool --register-public-key ./public_key1.asn1
