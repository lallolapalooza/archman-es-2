SCHKLQ

Propósito

!>
!> SCHKLQ prueba SGELQF, SORGLQ y SORMLQ.
!>

Parámetros

DOTYPE 
!>          DOTYPE es una matriz LOGICAL, dimensionada (NTYPES)
!>          Los tipos de matriz a utilizar para las pruebas. Las matrices del tipo j
!>          (para 1 <= j <= NTYPES) se utilizan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se utiliza.
!>

NM

!>          NM es un INTEGER
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es una matriz INTEGER, dimensionada (NM)
!>          Los valores de la dimensión de fila de la matriz M.
!>

NN

!>          NN es un INTEGER
!>          El número de valores de N contenidos en los vectores NVAL.
!>

NVAL

!>          NVAL es una matriz INTEGER, dimensionada (NN)
!>          Los valores de la dimensión de columna de la matriz N.
!>

NNB

!>          NNB es un INTEGER
!>          El número de valores de NB y NX contenidos en los
!>          vectores NBVAL y NXVAL. Los parámetros de bloqueo se utilizan
!>          en pares (NB,NX).
!>

NBVAL

!>          NBVAL es una matriz INTEGER, dimensionada (NNB)
!>          Los valores del tamaño de bloque NB.
!>

NXVAL

!>          NXVAL es una matriz INTEGER, dimensionada (NNB)
!>          Los valores del punto de cruce NX.
!>

NRHS

!>          NRHS es un INTEGER
!>          El número de vectores del lado derecho a generar para
!>          cada sistema lineal.
!>

THRESH

!>          THRESH es un REAL
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          se imprima cada relación de prueba, use THRESH = 0.
!>

TSTERR

!>          TSTERR es un LOGICAL
!>          Bandera que indica si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es un INTEGER
!>          El valor máximo permitido para M o N, utilizado para dimensionar
!>          las matrices de trabajo.
!>

A

!>          A es una matriz REAL, dimensionada (NMAX*NMAX)
!>

AF

!>          AF es una matriz REAL, dimensionada (NMAX*NMAX)
!>

AQ

!>          AQ es una matriz REAL, dimensionada (NMAX*NMAX)
!>

AL

!>          AL es una matriz REAL, dimensionada (NMAX*NMAX)
!>

AC

!>          AC es una matriz REAL, dimensionada (NMAX*NMAX)
!>

B

!>          B es una matriz REAL, dimensionada (NMAX*NRHS)
!>

X

!>          X es una matriz REAL, dimensionada (NMAX*NRHS)
!>

XACT

!>          XACT es una matriz REAL, dimensionada (NMAX*NRHS)
!>

TAU

!>          TAU es una matriz REAL, dimensionada (NMAX)
!>

WORK

!>          WORK es una matriz REAL, dimensionada (NMAX*NMAX)
!>

RWORK

!>          RWORK es una matriz REAL, dimensionada (NMAX)
!>

NOUT

!>          NOUT es un INTEGER
!>          El número de unidad para la salida.
!>
