NOMBRE

sctp_sendmsg - Envía un mensaje desde un socket SCTP.

SINOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_sendmsg(int sd, const void * msg, size_t len,
                 struct sockaddr *to, socklen_t tolen,
                 uint32_t ppid, uint32_t flags,
                 uint16_t stream_no, uint32_t timetolive,
                 uint32_t context);

DESCRIPCIÓN

sctp_sendmsg es una función de la biblioteca wrapper que puede utilizarse para enviar un mensaje desde un socket mientras se utilizan las características avanzadas de SCTP. sd es el descriptor del socket desde el cual se envía el mensaje apuntado por msg de longitud len. to es la dirección de destino del mensaje y tolen es la longitud de la dirección de destino. stream_no identifica el número de flujo al que la aplicación desea enviar este mensaje. El parámetro flags se compone de una operación OR a nivel de bits de los siguientes valores.

SCTP_UNORDERED
Esta bandera solicita la entrega desordenada del mensaje.
SCTP_ADDR_OVER
Esta bandera, en el estilo uno a muchos, solicita que la pila SCTP anule la dirección de destino principal con la dirección especificada en to.
SCTP_ABORT
Establecer esta bandera hace que la asociación especificada se aborte enviando un mensaje ABORT al par (solo estilo uno a muchos). El fragmento ABORT contendrá una causa de error 'User Initiated Abort' con el código de causa 12. La información específica de la causa de este error se proporciona en msg.
SCTP_EOF
Establecer esta bandera invoca el procedimiento de cierre ordenado de SCTP en la asociación específica (solo estilo uno a muchos).
SCTP_SENDALL
Esta bandera, si está establecida, hará que un socket de estilo uno a muchos envíe el mensaje a todas las asociaciones que estén actualmente establecidas en este socket. Para un socket de estilo uno a uno, esta bandera no tiene efecto.
SCTP_SACK_IMMEDIATELY
Esta bandera permite a la aplicación establecer el bit I del último fragmento DATA al enviar cada mensaje de usuario para asegurar que el SACK correspondiente pueda ser enviado por el par sin demora.
SCTP_PR_SCTP_{TTL|RTX|PRIO}
Una de estas 3 políticas pr_policies puede ser utilizada a través de esta bandera con su pr_value establecido en el parámetro timetolive para este mensaje. Tenga en cuenta que sctp_sendv(3) con infotype SCTP_SENDV_PRINFO también funciona para PR-SCTP.

timetolive especifica la duración en milisegundos. El lado que envía cancelará el mensaje si no se ha enviado al par dentro de este período de tiempo. Un valor de 0 indica que no debería haber tiempo de espera para este mensaje. También funciona como pr_value si el parámetro flags se establece en pr_policy. ppid es un valor sin signo opaco que se pasa al extremo remoto junto con el mensaje. context es un valor opaco de 32 bits que se devuelve a la capa superior junto con el mensaje no entregado si ocurre un error al enviar el mensaje.

VALOR DE RETORNO

En caso de éxito, sctp_sendmsg devuelve el número de bytes enviados o -1 si ocurrió un error.
