SCHISMTRACKER(1) Manual de comandos generales SCHISMTRACKER(1)

NOMBRE

schismtracker - editor de música en formato tracker basado en Impulse Tracker

SINOPSIS

schismtracker [opciones] [directorio] [archivo]

DESCRIPCIÓN

schismtracker es un editor de módulos de música en formato tracker que tiene como objetivo imitar la apariencia y la sensación de Impulse Tracker lo más fielmente posible. Puede cargar la mayoría de los formatos de tracker comunes, soporta guardar en formato IT y S3M, y también puede exportar a WAV y AIFF.

OPCIONES

-a, --driver-audio=DRIVER[:DISPOSITIVO]
Configuración del dispositivo de audio. driver es el controlador SDL a usar, por ejemplo alsa (ALSA), dma o dsp (OSS); dispositivo es el nombre del dispositivo en sí, por ejemplo hw:2 o /dev/dsp1.
-v, --driver-video=DRIVER
Controlador de video SDL, como x11, dga o fbcon. Tenga en cuenta que esto es diferente de la configuración del controlador de video dentro del programa, y es poco probable que sea útil.
--network, --no-network
Habilitar/deshabilitar la red (activada por defecto). Se utiliza para MIDI sobre IP.
--classic, --no-classic
Iniciar Schism Tracker en modo "clásico", o no. Esto es principalmente cosmético, aunque cambia ligeramente el comportamiento del programa en algunos lugares.
-f, -F, --pantalla-completa, --no-pantalla-completa
Habilitar/deshabilitar el modo de pantalla completa al inicio.
-p, -P, --reproducir, --no-reproducir
Iniciar la reproducción después de cargar la canción en la línea de comandos.
--diskwrite=NOMBRE_ARCHIVO
Renderizar la salida a un archivo y luego salir. El escritor WAV o AIFF se selecciona automáticamente según la extensión del archivo. Incluya %c en algún lugar del nombre para escribir cada canal por separado. Esto no tiene sentido si no se proporciona un nombre de archivo inicial.
--headless
Ejecutar en modo no interactivo para renderizado automatizado. Requiere que se especifiquen tanto --diskwrite como un archivo de canción de entrada. Útil para la conversión por lotes de canciones a archivos de audio.
--editor-fuentes, --no-editor-fuentes
Ejecutar el editor de fuentes (itf). También se puede acceder a él presionando Shift-F12.
--hooks, --no-hooks
Ejecutar hooks. Habilitado por defecto.
--version
Mostrar información de la versión y fecha de compilación.
-h, --ayuda
Imprimir un resumen de las opciones disponibles.

Un nombre de archivo proporcionado en la línea de comandos se cargará al inicio. Además, si se proporciona un nombre de archivo o directorio, las rutas predeterminadas de módulos, muestras e instrumentos se configurarán en consecuencia.

USO

Una discusión detallada sobre cómo usar Schism Tracker está mucho más allá del alcance de este documento, pero aquí hay un resumen muy breve de lo básico. La ayuda sensible al contexto se puede acceder en cualquier momento mientras se ejecuta el programa presionando F1.

La tecla F3 te llevará a la lista de muestras. Presiona Enter aquí para abrir un explorador de archivos, navega en la lista usando las teclas de flecha arriba/abajo, y presiona Enter de nuevo para cargar una muestra. Probablemente querrás obtener algunas muestras para trabajar. También puedes "extraer" de módulos existentes; consulta por ejemplo http://www.modarchive.org/ para una selección muy amplia de módulos. (¡Ten en cuenta, sin embargo, que a algunos autores no les gusta que se extraigan sus muestras!)

Ahora que has cargado una muestra, presiona F2 para ir al editor de patrones. Aquí es donde tiene lugar la mayor parte de la composición. En resumen, la canción se organiza verticalmente, con cada fila representando una nota de 1/16; para reproducir múltiples notas simultáneamente, se colocan en diferentes canales. Las cuatro sub-columnas de cada canal son la nota, el número de muestra, el volumen y el efecto. Una lista de efectos está disponible en la ayuda del editor de patrones, pero puedes ignorar esa columna por ahora. Asumiendo un mapeo de teclado estadounidense, las notas se ingresan con el teclado de la siguiente manera:
(Nota) C# D# F# G# A# C# D#
| | || | | | || || | | | || | |
| | || | | | || || | | | || | |
(Lo que | |S||D| | |G||H||J| | |2||3| | |5||6||7| | |9||0| |
escribes) | '-''-' | '-''-''-' | '-''-' | '-''-''-' | '-''-' |
| Z| X| C| V| B| N| M| Q| W| E| R| T| Y| U| I| O| P|
'--'--'--'--'--'--'--'--'--'--'--'--'--'--'--'--'--'
(Nota) C D E F G A B C D E F G A B C D E
(Octava 0) (Octava 1) (Octava 2)

Las teclas "/" y "*" del teclado numérico cambian las octavas, y la octava actual se muestra cerca de la parte superior de la pantalla. Intenta escribir "qwerty" en el patrón - esto ingresará una secuencia de notas ascendentes, y escucharás las notas a medida que se ingresan. (¡por supuesto, asumiendo que cargaste una muestra!) Presiona F6 para reproducir tu patrón, y F8 para detener.

Otras teclas importantes para el editor de patrones incluyen Ins/Del para subir y bajar notas dentro de un canal, Shift-Flechas para marcar un bloque, Alt-C/Alt-P para copiar y pegar, y Alt-U para borrar la marca. Hay más de cien combinaciones de teclas para el editor de patrones; vale la pena el esfuerzo aprenderlas todas eventualmente.

Ahora que tienes algo en tu patrón, necesitarás configurar una lista de órdenes. Presiona F11 para cambiar a la página de lista de órdenes, y escribe 0 para agregar el patrón que creaste. Ahora presiona F5 para empezar a reproducir. La canción comenzará en la primera orden, buscará el número de patrón y reproducirá ese patrón, luego avanzará a la siguiente orden, y así sucesivamente.

Es posible que desees darle un título a tu canción; presiona F12 y escribe un nombre en el cuadro de la parte superior. También puedes ajustar el tempo y una serie de otras configuraciones en esta página, pero por ahora, la mayoría de ellas están bien en sus valores predeterminados.

Para guardar tu nueva canción, presiona F10, escribe un nombre de archivo y presiona Enter. Puedes cargarlo de nuevo más tarde presionando F9.

Este tutorial ha omitido deliberadamente el editor de instrumentos (en F4), por cuestiones de brevedad y simplicidad. Es posible que desees experimentar con él una vez que tengas una idea de cómo funciona el programa. (Selecciona "instrumentos" en F12 para habilitar el modo de instrumentos.)

HISTORIAL

Storlek comenzó a estudiar el diseño de Impulse Tracker en 2002, notando detalles sutiles del diseño y la implementación. Las publicaciones en los foros de Modplug sobre la reescritura de Impulse Tracker fueron recibidas con ridículo y burla. "No se puede hacer", decían.

Schism Tracker v0.031a fue lanzado en julio de 2003, aunque muy poco funcionaba en ese momento, y era más un reproductor con capacidades de edición primitivas. El guardado de archivos estaba codificado para escribir en "test.it" en el directorio actual, y no había forma de cargar una muestra.

La primera versión que fue más o menos utilizable fue la 0.15a, de diciembre de 2004.

Desde 2005 hasta 2009, la Sra. Brisby realizó la mayor parte del desarrollo, e implementó toneladas de funciones, incluido el soporte MIDI, el soporte del ratón y la escritura en disco.

Storlek "retomó" el desarrollo nuevamente en 2009, y reescribió incrementalmente gran parte del código hasta 2015.

En 2016, Schism Tracker se trasladó a GitHub bajo mantenimiento compartido. Desde entonces, muchas personas han contribuido con mejoras y correcciones de errores al código base.

ARCHIVOS

~/.schism/config
Configuración del programa, almacenada en un formato estilo INI. La mayoría de las opciones son accesibles desde la interfaz de Schism Tracker, pero hay algunas opciones "ocultas".
~/

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

FILES

~/.schism/startup-hook, ~/.schism/exit-hook, ~/.schism/diskwriter-hook
Archivos opcionales a ejecutar en ciertos eventos. (Deben ser ejecutables)
~/.schism/fonts/
font.cfg, y cualquier archivo .itf que se encuentre en este directorio, se muestran en el explorador de archivos del editor de fuentes.

Schism Tracker puede guardar módulos en formato IT y S3M, datos de muestra como ITS, S3I, AIFF, AU, WAV y RAW, e instrumentos como ITI. Además, puede renderizar a WAV y AIFF (opcionalmente escribiendo cada canal en un archivo separado) y puede exportar archivos MID.
