NOMBRE

scandeps.pl - Escanear prerrequisitos de archivo

SINOPSIS

% scandeps.pl *.pm          # Imprimir la sección PREREQ_PM para *.pm
% scandeps.pl -e 'CADENA'   # Escanear un one-liner
% scandeps.pl -B *.pm       # Incluir módulos principales
% scandeps.pl -V *.pm       # Mostrar archivos de carga automática/compartidos/datos
% scandeps.pl -R *.pm       # No recursar
% scandeps.pl -C ARCHIVO_CACHE  # Usar ARCHIVO_CACHE para almacenar en caché las dependencias

DESCRIPCIÓN

scandeps.pl es una utilidad simple que imprime la sección "PREREQ_PM" necesaria para los módulos.

Si se especifica la opción "-T" y tienes CPANPLUS instalado, los módulos que forman parte de la distribución de un módulo anterior se indicarán con "S"; los módulos sin nombre de distribución en CPAN se marcarán con "?".

Además, si se especifica la opción "-B", los módulos que pertenecen a una distribución de perl en CPAN (y por lo tanto no se pueden desinstalar con "CPAN.pm" o "CPANPLUS.pm") se marcarán con "C".

Finalmente, los módulos que tienen archivos de objeto compartido cargables (generalmente requieren un compilador para instalarse) se marcarán con "X"; con la bandera "-V", esos archivos (y todos los demás archivos encontrados) se listarán antes de la salida principal. Adicionalmente, se listan todos los archivos de módulo de los que depende el código escaneado pero que no se encontraron (y por lo tanto no se escanearon recursivamente). Estos pueden incluir módulos genuinamente faltantes o falsos positivos. Eso significa, módulos de los que tu código no depende (en esta plataforma particular) pero que fueron recogidos por la heurística de todos modos.

OPCIONES

-e, --eval=CADENA
Escanea CADENA como una cadena que contiene código perl.
-c, --compile
Compila el código e inspecciona su %INC, además del escaneo estático.
-x, --execute
Ejecuta el código e inspecciona su %INC, además del escaneo estático. Puedes usar --xargs para especificar @ARGV al ejecutar el código.
--xargs=CADENA
Si se proporciona -x, divide la "CADENA" usando la función "shellwords" de Text::ParseWords y pasa el resultado como @ARGV al ejecutar el código.
-B, --bundle
Incluye módulos principales en la salida y en la lista de búsqueda recursiva.
-R, --no-recurse
Solo muestra las dependencias encontradas en los archivos listados y no recursar.
-V, --verbose
Modo detallado: Muestra todos los archivos encontrados durante el proceso; muestra las dependencias entre módulos y su disponibilidad.

Adicionalmente, advierte sobre cualquier dependencia faltante. Si encuentras dependencias faltantes que en realidad no lo son, probablemente has encontrado falsos positivos.

-C, --cachedeps=ARCHIVO_CACHE
Usa ARCHIVO_CACHE para acelerar el proceso de escaneo almacenando en caché las dependencias. Crea ARCHIVO_CACHE si aún no existe.
-T, --modtree
Recupera información del módulo de CPAN si tienes CPANPLUS instalado.
