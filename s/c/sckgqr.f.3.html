SCKGQR

Propósito:

!>
!> SCKGQR prueba
!> SGGQRF: Factorización GQR para la matriz A de N por M y la matriz B de N por P,
!> SGGRQF: Factorización GRQ para la matriz A de M por N y la matriz B de P por N.
!>

Parámetros

NM 
!>          NM es ENTERO
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array de ENTEROS, de dimensión (NM)
!>          Los valores de la dimensión fila(columna) de la matriz M.
!>

NP

!>          NP es ENTERO
!>          El número de valores de P contenidos en el vector PVAL.
!>

PVAL

!>          PVAL es un array de ENTEROS, de dimensión (NP)
!>          Los valores de la dimensión fila(columna) de la matriz P.
!>

NN

!>          NN es ENTERO
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array de ENTEROS, de dimensión (NN)
!>          Los valores de la dimensión columna(fila) de la matriz N.
!>

NMATS

!>          NMATS es ENTERO
!>          El número de tipos de matrices a probar para cada combinación
!>          de dimensiones de matriz. Si NMATS >= NTYPES (el número
!>          máximo de tipos de matrices), entonces se generan todos los tipos
!>          diferentes para la prueba. Si NMATS < NTYPES, se lee otra línea
!>          de entrada para obtener los números de los tipos de matrices a usar.
!>

ISEED

!>          ISEED es un array de ENTEROS, de dimensión (4)
!>          A la entrada, la semilla del generador de números aleatorios. Los elementos
!>          del array deben estar entre 0 y 4095, de lo contrario se reducirán
!>          módulo 4096, y ISEED(4) debe ser impar.
!>          A la salida, la siguiente semilla en la secuencia de números aleatorios
!>          después de que se hayan generado todas las matrices de prueba.
!>

THRESH

!>          THRESH es REAL
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          se imprima cada relación de prueba, use THRESH = 0.
!>

NMAX

!>          NMAX es ENTERO
!>          El valor máximo permitido para M o N, utilizado en la dimensionamiento
!>          de los arrays de trabajo.
!>

A

!>          A es un array REAL, de dimensión (NMAX*NMAX)
!>

AF

!>          AF es un array REAL, de dimensión (NMAX*NMAX)
!>

AQ

!>          AQ es un array REAL, de dimensión (NMAX*NMAX)
!>

AR

!>          AR es un array REAL, de dimensión (NMAX*NMAX)
!>

TAUA

!>          TAUA es un array REAL, de dimensión (NMAX)
!>

B

!>          B es un array REAL, de dimensión (NMAX*NMAX)
!>

BF

!>          BF es un array REAL, de dimensión (NMAX*NMAX)
!>

BZ

!>          BZ es un array REAL, de dimensión (NMAX*NMAX)
!>

BT

!>          BT es un array REAL, de dimensión (NMAX*NMAX)
!>

BWK

!>          BWK es un array REAL, de dimensión (NMAX*NMAX)
!>

TAUB

!>          TAUB es un array REAL, de dimensión (NMAX)
!>

WORK

!>          WORK es un array REAL, de dimensión (NMAX*NMAX)
!>

RWORK

!>          RWORK es un array REAL, de dimensión (NMAX)
!>

NIN

!>          NIN es ENTERO
!>          La unidad de número para la entrada.
!>

NOUT

!>          NOUT es ENTERO
!>          La unidad de número para la salida.
!>

INFO

!>          INFO es ENTERO
!>          = 0 :  salida exitosa
!>          > 0 :  Si SLATMS devuelve un código de error, se devuelve su valor absoluto.
!>
