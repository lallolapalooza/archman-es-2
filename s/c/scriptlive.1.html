SCRIPTLIVE(1) Comandos de usuario SCRIPTLIVE(1)

NOMBRE

scriptlive - volver a ejecutar transcripciones de sesiones, utilizando información de temporización

SINOPSIS

scriptlive [opciones] archivo_de_temporizacion transcripcion

DESCRIPCIÓN

Este programa vuelve a ejecutar una transcripción, utilizando la transcripción de entrada estándar y la información de temporización para asegurar que la entrada ocurra al mismo ritmo que apareció originalmente cuando se grabó el script.

La sesión se ejecuta en un pseudoterminal recién creado con el $SHELL del usuario (o por defecto /bin/bash).

¡Ten cuidado! La transcripción puede contener comandos arbitrarios. Se recomienda usar "scriptreplay --stream in --log-in typescript" (o con --log-io en lugar de --log-in) para verificar la transcripción antes de que se ejecute con scriptlive.

La información de temporización es lo que script(1) produce en el archivo especificado por --log-timing. La transcripción debe contener información de entrada estándar, y es lo que script(1) produce en el archivo especificado por --log-in o --log-io.

OPCIONES

-I, --log-in archivo

Archivo que contiene la entrada de terminal de script.

-B, --log-io archivo

Archivo que contiene la salida y entrada de terminal de script.

-E, --echo cuándo

Esta opción controla el flag ECHO para el extremo esclavo del pseudoterminal de la sesión. Los modos soportados son always, never, y auto.

El valor por defecto es auto; en cuyo caso ECHO está habilitado. Este comportamiento por defecto está sujeto a cambios.

-t, --timing archivo

Archivo que contiene la salida de temporización de script. Esta opción reemplaza el argumento posicional archivo_de_temporizacion.

-T, --log-timing archivo

Un alias para -t; mantenido para compatibilidad con las opciones de línea de comandos de script(1).

-d, --divisor número

Acelera la reproducción mostrando este número de veces. El argumento es un número de punto flotante. Se llama divisor porque divide los tiempos por este factor. Esta opción anula los argumentos de estilo antiguo.

-m, --maxdelay número

Establece el retardo máximo entre actualizaciones a número de segundos. El argumento es un número de punto flotante. Esto puede ser usado para evitar pausas largas en la reproducción de la transcripción.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

EJEMPLOS

% script --log-timing file.tm --log-in script.in
Script started, file is script.out
% date
<etc, etc>
% exit
Script done, file is script.out
% scriptlive --log-timing file.tm --log-in script.in
