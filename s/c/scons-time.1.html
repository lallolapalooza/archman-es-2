NOMBRE

scons-time - generar y mostrar información de tiempo de SCons

SINOPSIS

scons-time subcomando [opciones...] [argumentos...]

GENERANDO INFORMACIÓN DE TIEMPO

scons-time run [-hnqv] [-f ARCHIVO] [--number=NÚMERO] [--outdir=DIR_SALIDA] [-p CADENA] [--python=PYTHON] [-s DIR] [--scons=SCONS] [--svn=URL] [ARGUMENTOS]

Extrayendo Tiempos de Funciones

scons-time func [-h] [--chdir=DIR] [-f ARCHIVO] [--fmt=FORMATO] [--func=NOMBRE] [-p CADENA] [-t NÚMERO] [--title= TÍTULO] [ARGUMENTOS]

Extrayendo Estadísticas de Memoria

scons-time mem [-h] [--chdir=DIR] [-f ARCHIVO] [--fmt=FORMATO] [-p CADENA] [--stage=ETAPA] [-t NÚMERO] [--title=TÍTULO] [ARGUMENTOS]

Extrayendo Recuentos de Objetos

scons-time obj [-h] [--chdir=DIR] [-f ARCHIVO] [--fmt=FORMATO] [-p CADENA] [--stage=ETAPA] [-t NÚMERO] [--title=TÍTULO] [ARGUMENTOS]

Extrayendo Tiempos de Ejecución

scons-time time [-h] [--chdir=DIR] [-f ARCHIVO] [--fmt=FORMATO] [-p CADENA] [-t NÚMERO] [--title=TÍTULO] [--which=CUÁL] [ARGUMENTOS]

Texto de Ayuda

scons-time help SUBCOMANDO [...]

DESCRIPCIÓN

El comando scons-time ejecuta una configuración de SCons a través de un conjunto estándar de tiempos de perfil y puede extraer y graficar información de los perfiles resultantes y los archivos de registro de esos tiempos. La acción a realizar por el script scons-time se especifica mediante un subcomando, el primer argumento en la línea de comandos. Vea la sección SUBCOMANDOS para obtener información sobre el funcionamiento de los subcomandos específicos.

La forma básica de usar scons-time es ejecutar el subcomando scons-time run (posiblemente varias veces) para generar la salida de perfiles y archivos de registro, y luego usar uno de los otros subcomandos para mostrar los resultados capturados en los perfiles y archivos de registro para un tipo particular de información: tiempos de funciones (el subcomando scons-time func), memoria total utilizada (el subcomando scons-time mem), recuentos de objetos (el subcomando scons-time obj) y tiempo total de ejecución (el subcomando scons-time time). Existen opciones para colocar y encontrar los perfiles y archivos de registro en directorios separados, para generar la salida en un formato adecuado para graficar con el programa gnuplot(1), etc.

Hay dos formas básicas en que se pretende utilizar el subcomando scons-time run para recopilar estadísticas de tiempo para una configuración. Una es usar la opción --svn= para probar una configuración contra una lista de revisiones del repositorio Subversion de SCons. Esto generará un perfil y un archivo de registro de tiempos para cada revisión listada con la opción --number=, y puede usarse para ver el impacto de los cambios confirmados en la base de código de SCons en una configuración particular a lo largo del tiempo.

La otra forma es perfilar cambios incrementales en una base de código local de SCons durante un ciclo de desarrollo; es decir, para ver el impacto del rendimiento de los cambios que estás haciendo en el árbol local. En este modo, ejecutas el subcomando scons-time run *sin* la opción --svn=, en cuyo caso simplemente busca en el directorio de salida de perfiles/registros (el directorio actual por defecto) y calcula automáticamente el *siguiente* número de ejecución para el perfil de salida y el archivo de registro. Usado de esta manera, el ciclo de desarrollo va algo así: haz un cambio en SCons; ejecuta scons-time run para perfilarlo contra una configuración específica; haz otro cambio en SCons; ejecuta scons-time run de nuevo para perfilarlo; etc.

OPCIONES

El comando scons-time solo admite unas pocas opciones globales:

-h, --help

Muestra el texto de ayuda global y sale, idéntico al subcomando scons-time help.

-V, --version

Muestra la versión de scons-time y sale.

La mayor parte de la funcionalidad se controla mediante opciones para los subcomandos individuales. Vea la siguiente sección para obtener información sobre las opciones de los subcomandos individuales.

SUBCOMANDOS

El comando scons-time admite los siguientes subcomandos individuales.

El Subcomando func

scons-time func [-h] [--chdir=DIR] [-f ARCHIVO] [--fmt=FORMATO] [--func=NOMBRE] [-p CADENA] [-t NÚMERO] [--title= TÍTULO] [ARGUMENTOS]

El subcomando scons-time func muestra información de tiempo para una función Python específica dentro de SCons. Por defecto, extrae información sobre la función _main(), que incluye el tiempo del perfilador de Python para todo SCons.

El subcomando scons-time func extrae información de tiempo de funciones de todos los archivos especificados como argumentos, que deberían ser archivos de salida del perfilador de Python. (Normalmente, estos serían archivos *.prof generados por el subcomando scons-time run, pero pueden ser generados por cualquier invocación del perfilador de Python). Todos los nombres de archivo se expandirán mediante comodines a archivos en disco.

Si no se especifican argumentos, se extraerá información de tiempo de funciones de todos los archivos *.prof, o del subconjunto de ellos con un prefijo especificado por la opción -p.

Las opciones incluyen:

-C DIRECTORIO, --chdir=DIRECTORIO

Cambia al DIRECTORIO especificado antes de buscar los archivos especificados (o archivos que coincidan con los patrones especificados).

-f ARCHIVO, --file=ARCHIVO

Lee la información de configuración del ARCHIVO especificado.

-fmt=FORMATO, --format=FORMATO

Informa la salida en el FORMATO especificado. Los formatos actualmente compatibles son ascii (el predeterminado) y gnuplot.

--func=NOMBRE

Extrae los tiempos para la función NOMBRE especificada. El predeterminado es informar los tiempos acumulados para la función _main(), que contiene toda la ejecución de SCons.

-h, --help

Muestra el texto de ayuda para el subcomando scons-time func.

-p CADENA, --prefix=CADENA

Especifica la cadena de prefijo para los perfiles de los cuales extraer información de tiempo de funciones. Esto se usará para buscar perfiles si no se especifican argumentos en la línea de comandos.

-t NÚMERO, --tail=NÚMERO

Solo extrae los tiempos de funciones de los últimos NÚMERO archivos.

El Subcomando help

scons-time help SUBCOMANDO [...] El subcomando help imprime texto de ayuda para cualquier otro subcomando listado como argumentos posteriores en la línea de comandos.

El Subcomando run

scons-time run [-hnqv] [-f ARCHIVO] [--number=NÚMERO] [--outdir=DIR_SALIDA] [-p CADENA] [--python=PYTHON] [-s DIR] [--scons=SCONS] [--svn=URL] [ARGUMENTOS]

El subcomando scons-time run ejecuta una configuración de SCons y recopila información de perfil y registro sobre su ejecución. La salida se escribe en un conjunto de archivos de perfil y registro cuyos nombres se basan en el número de ejecución.

Las opciones incluyen:

-C DIRECTORIO, --chdir=DIRECTORIO

Cambia al DIRECTORIO especificado antes de buscar los archivos especificados (o archivos que coincidan con los patrones especificados).

-f ARCHIVO, --file=ARCHIVO

Lee la configuración del proyecto SConstruct/SConscript del ARCHIVO especificado.

-h, --help

Muestra el texto de ayuda para el subcomando scons-time run.

-n, --dry-run

Imprime los comandos que se ejecutarían sin ejecutarlos realmente.

--number=NÚMERO

Especifica el número de ejecución. Si no se especifica, se asumirá el siguiente número disponible en el directorio de salida. Esto se usa principalmente con la opción --svn.

-o DIR_SALIDA, --outdir=DIR_SALIDA

Escribe los archivos de perfil y registro en el DIR_SALIDA especificado. Por defecto, se escribirán en el directorio actual.

-p CADENA, --prefix=CADENA

Especifica una CADENA de prefijo para los nombres de los archivos de perfil y registro. El prefijo predeterminado es "scons".

-q, --quiet

Suprime la mayor parte de la salida normal.

-s DIRECTORIO, --srcdir=DIRECTORIO

Busca el SConstruct/SConscript en el DIRECTORIO especificado.

--scons=SCONS

Ejecuta el script SCons especificado (el valor predeterminado es "scons").

-t NÚMERO, --tail=NÚMERO

Solo extrae información de tiempo de los últimos NÚMERO archivos.

-v, --verbose

Aumenta la verbosidad de la salida.

--svn=URL

Ejecuta SCons contra la revisión especificada de la URL de Subversion proporcionada. Se usará para determinar el número de ejecución si no se proporciona la opción --number.

--python=PYTHON

Ejecuta SCons usando el intérprete Python especificado. El valor predeterminado es el que está siendo utilizado para ejecutar el script scons-time.

The mem Subcommand

scons-time mem [-h] [--chdir=DIR] [-f FILE] [--fmt=FORMAT] [-p STRING] [--stage=STAGE] [-t NUMBER] [ARGUMENTS]

The scons-time mem subcommand displays how much memory SCons uses.

The scons-time mem subcommand extracts memory use information from all the specified file arguments, which should be files containing output from running SCons with the --debug=memory option. (Normally, these would be *.log files generated by the scons-time run subcommand.) All file name arguments will be globbed for on-disk files.

If no arguments are specified, then memory information will be extracted from all *.log files, or the subset of them with a prefix specified by the -p option.

-C DIR, --chdir=DIR

Cambia al DIRECTORIO especificado antes de buscar los archivos especificados (o archivos que coinciden con los patrones especificados).

-f FILE, --file=FILE

Lee información de configuración del ARCHIVO especificado.

-fmt=FORMAT, --format=FORMAT

Informa la salida en el FORMATO especificado. Los formatos actualmente soportados son ascii (el predeterminado) y gnuplot.

-h, --help

Muestra el texto de ayuda para el subcomando scons-time mem.

-p STRING, --prefix=STRING

Especifica la cadena de prefijo para los archivos de registro de los cuales extraer información de uso de memoria. Esto se utilizará para buscar archivos de registro si no se especifican argumentos en la línea de comandos.

--stage=STAGE

Imprime la memoria utilizada al final de la ETAPA especificada: pre-read (antes de que se lean los archivos SConscript), post-read (después de que se lean los archivos SConscript), pre-build (antes de que se construyan los objetivos) o post-build (después de que se construyan los objetivos). Si no se especifica la opción --stage, el comportamiento predeterminado es post-build, que informa la cantidad final de memoria utilizada por SCons durante cada ejecución.

-t NUMBER, --tail=NUMBER

Solo informa estadísticas de memoria de los últimos NÚMERO de archivos.

The run Subcommand

scons-time run [-hnqv] [-f FILE] [--number=NUMBER] [--outdir=OUTDIR] [-p STRING] [--python=PYTHON] [-s DIR] [--scons=SCONS] [--svn=URL] [ARGUMENTS] El subcomando scons-time run es el subcomando básico para perfilar una configuración específica contra una versión de SCons.

La configuración que se probará se especifica como una lista de archivos o directorios que se descomprimirán o copiarán en un directorio temporal en el cual se invocará SCons. El subcomando scons-time run entiende sufijos de archivo como .tar, .tar.gz, .tgz y .zip y descomprimirá su contenido en un directorio temporal. Si se especifica más de un argumento, cada uno se descomprimirá o copiará en el directorio temporal "encima de" los archivos o directorios anteriores, por lo que la expectativa es que múltiples archivos especificados compartan la misma estructura de directorios.

Una vez que los argumentos de archivo o directorio se descomprimen o copian en el directorio temporal, el subcomando scons-time run ejecuta la versión solicitada de SCons contra la configuración tres veces:

Inicio

SCons se ejecuta con la opción --help para que solo se lean los archivos SConscript, y luego se imprime el texto de ayuda predeterminado. Esto perfila solo la "sobrecarga" percibida de iniciar SCons y procesar los archivos SConscript.

Compilación completa

SCons se ejecuta para construir todo lo especificado en la configuración. Los objetivos específicos a pasar en la línea de comandos pueden ser especificados por la palabra clave targets en un archivo de configuración; consulte a continuación para más detalles.

Recompilación

SCons se ejecuta nuevamente en el mismo directorio recién compilado. Si las dependencias en la configuración de SCons son correctas, esta debería ser una recompilación actualizada, que "no hace nada".

Cada invocación captura el archivo de registro de salida y un perfil.

El subcomando scons-time run soporta las siguientes opciones:

-f FILE, --file=FILE

Lee información de configuración del ARCHIVO especificado. Esto a menudo proporciona una forma más conveniente de especificar y recopilar parámetros asociados con una configuración de tiempo específica que especificarlos en la línea de comandos. Consulte la sección ARCHIVO DE CONFIGURACIÓN a continuación para obtener información sobre los parámetros del archivo de configuración.

-h, --help

Muestra el texto de ayuda para el subcomando scons-time run.

-n, --no-exec

No ejecute comandos, solo imprima los equivalentes de línea de comandos de lo que se ejecutaría. Tenga en cuenta que el script scons-time en realidad ejecuta sus acciones en Python, siempre que sea posible, para la portabilidad. Los comandos que se muestran son equivalentes en UNIX de lo que está haciendo.

--number=NUMBER

Especifica el número de ejecución a utilizar en los nombres de los archivos de registro y las salidas de perfil generadas por esta ejecución.

Cuando se utiliza junto con la opción --svn=URL, NÚMERO especifica uno o más números de revisión de Subversion separados por comas que se recuperarán automáticamente del repositorio de Subversion en la URL especificada. Se pueden especificar rangos de números de revisión o delta separando dos números con un guion (-).

Ejemplo:

% scons-time run --svn=http://scons.tigris.org/svn/trunk --num=1247,1249-1252 .

-p STRING, --prefix=STRING

Especifica la cadena de prefijo que se utilizará para todos los archivos de registro y perfiles generados por esta ejecución. El valor predeterminado se deriva del primer argumento especificado: si el primer argumento es un directorio, el prefijo predeterminado es el nombre del directorio; si el primer argumento es un archivo (tar o zip), el prefijo predeterminado es el nombre base del archivo, es decir, lo que queda después de eliminar el sufijo del archivo (.tgz, .tar.gz o .zip).

--python=PYTHON

Especifica una ruta al ejecutable de Python que se utilizará para las ejecuciones de tiempo. El valor predeterminado es utilizar el mismo ejecutable de Python que está ejecutando el comando scons-time.

-q, --quiet

Suprime la visualización de las líneas de comandos que se están ejecutando.

-s DIR, --subdir=DIR

Especifica el nombre del directorio o subdirectorio desde el cual se deben ejecutar los comandos. El valor predeterminado es XXX

--scons=SCONS

Especifica una ruta al script SCons que se utilizará para las ejecuciones de tiempo. El valor predeterminado es XXX

--svn=URL, --subversion=URL

Especifica la URL del repositorio de Subversion desde la cual se extraerán la(s) versión(es) de scons que se están cronometrando. Cuando se especifica --svn, la opción --number=NUMBER especifica los números de revisión que se probarán. La salida de cada ejecución se colocará en nombres de archivo que coincidan con los números de revisión de Subversion. Si no se especifica la opción --number=, el comportamiento predeterminado es cronometrar la HEAD de la URL especificada.

-v, --verbose

Muestra la salida de comandos individuales en la pantalla (además de capturar la salida en archivos de registro).

The time Subcommand

scons-time time [-h] [--chdir=DIR] [-f FILE] [--fmt=FORMAT] [-p STRING] [-t NUMBER] [--title=TITLE] [--which=WHICH] [ARGUMENTS]

El subcomando scons-time time muestra los tiempos de ejecución de SCons según lo informado por la opción scons --debug=time.

El subcomando scons-time time extrae los tiempos de SCons de todos los archivos de argumentos especificados, que deben ser archivos que contienen la salida de ejecutar SCons con la opción --debug=time. (Normalmente, estos serían archivos *.log generados por el subcomando scons-time run.) Todos los nombres de archivo se expandirán para archivos en el disco.

Si no se especifican argumentos, los tiempos de ejecución se extraerán de todos los archivos *.log, o del subconjunto de ellos con un prefijo especificado por la opción -p.

-C DIR, --chdir=DIR

Cambia al DIRECTORIO especificado antes de buscar los archivos especificados (o archivos que coinciden con los patrones especificados).

-f FILE, --file=FILE

Lee información de configuración del ARCHIVO especificado.

-fmt=FORMAT, --format=FORMAT

Informa la salida en el FORMATO especificado. Los formatos actualmente soportados son ascii (el predeterminado) y gnuplot.

-h, --help

Muestra el texto de ayuda para el subcomando scons-time time.

-p STRING, --prefix=STRING

Especifica la cadena de prefijo para los archivos de registro de los cuales extraer tiempos de ejecución. Esto se utilizará para buscar archivos de registro si no se especifican argumentos en la línea de comandos.

-t NUMBER, --tail=NUMBER

Solo informa tiempos de ejecución de los últimos NÚMERO de archivos.

--title=TITLE

Especifica un título para la tabla o gráfico de salida.

--which=WHICH

Especifica qué tiempo de ejecución se desea informar. Las opciones válidas son startup, build, rebuild y all (el valor predeterminado).

NOMBRE

scons-time - tiempo de ejecución de SCons

SINOPSIS

scons-time [-h] [-f FILE] [-p STRING] [-t NUMBER] [--chdir=DIR] [--format=FORMAT] [--prefix=STRING] [--tail=NUMBER] [--which=WHICH] [ARGUMENTS...]

DESCRIPCIÓN

El script scons-time se utiliza para ejecutar SCons en una variedad de configuraciones (por ejemplo, diferentes versiones de SCons, diferentes árboles de SCons fuente) y para informar sobre el tiempo de ejecución de esas ejecuciones. También puede utilizarse para extraer la información de tiempo de ejecución de archivos de registro que ya han sido generados por SCons.

EJECUCIÓN

Cuando se ejecuta sin argumentos, scons-time genera un conjunto de archivos de registro y perfiles de tiempo de ejecución en el directorio temporal en el que invoca SCons. Luego, estos archivos se copian al directorio actual y se les antepone la cadena especificada por la opción -p o --prefix. Finalmente, se elimina el directorio temporal.

Cuando se ejecuta con el argumento --which, scons-time extrae información de los archivos de registro generados previamente en el directorio de trabajo actual. Por defecto, se extrae el tiempo total de ejecución.

OPCIONES

A continuación se describen las opciones de la línea de comandos para scons-time:

OPCIONES

-C DIR, --chdir=DIR

Cambia al DIRECTORIO especificado antes de buscar los archivos especificados (o archivos que coincidan con los patrones especificados).

-f FILE, --file=FILE

Lee la información de configuración del ARCHIVO especificado.

-fmt=FORMAT, --format=FORMAT

Informa la salida en el FORMATO especificado. Los formatos actualmente soportados son ascii (el valor predeterminado) y gnuplot.

-h, --help

Muestra el texto de ayuda para el subcomando scons-time time.

-p STRING, --prefix=STRING

Especifica la cadena de prefijo para los archivos de registro de los que extraer los tiempos de ejecución. Esto se utilizará para buscar archivos de registro si no se especifican argumentos en la línea de comandos.

-t NUMBER, --tail=NUMBER

Solo informa el recuento de objetos de los últimos NUMBER archivos.

--which=WHICH

Imprime el tiempo de ejecución para el valor WHICH especificado: total (el tiempo total de ejecución), SConscripts (tiempo total de ejecución de los propios archivos SConscript), SCons (tiempo de ejecución en el propio código de SCons) o commands (tiempo de ejecución de los comandos y otras acciones utilizadas para construir los objetivos). Si no se especifica la opción --which, el comportamiento predeterminado es total, que informa el tiempo total de ejecución por cada ejecución.

ARCHIVO DE CONFIGURACIÓN

Varios subcomandos de scons-time pueden leer información de un archivo de configuración especificado cuando se les pasa las opciones -f o --file. El archivo de configuración se ejecuta realmente como un script de Python. Establecer variables de Python en el archivo de configuración controla el comportamiento del script scons-time de manera más conveniente que tener que especificar opciones o argumentos de línea de comandos para cada ejecución, y proporciona una forma útil de "encapsular" la información necesaria para producir (e informar) ejecuciones de tiempo consistentes para una configuración dada.

archive_list

Una lista de archivos (archivos o directorios) que se copiarán al directorio temporal en el que se invocará SCons. Los archivos .tar, .tar.gz, .tgz y .zip tendrán su contenido desempaquetado en el directorio temporal. Los árboles de directorios y los archivos se copiarán tal cual.

initial_commands

Una lista de comandos que se ejecutarán antes de las ejecuciones reales de scons cronometradas. Esto se puede utilizar para comandos que son necesarios para preparar el árbol fuente; por ejemplo, crear un archivo de configuración que no debe formar parte de la ejecución cronometrada.

key_location

La ubicación de la clave en la información gráfica de Gnuplot generada con la opción --format=gnuplot. El valor predeterminado es bottom left (abajo a la izquierda).

prefix

El prefijo del nombre de archivo que se utilizará al ejecutar o extraer tiempos para esta configuración.

python

El nombre de ruta del ejecutable de Python que se utilizará al ejecutar o extraer información para esta configuración. El valor predeterminado es la misma versión de Python utilizada para ejecutar SCons.

scons

El nombre de ruta del script SCons que se utilizará al ejecutar o extraer información para esta configuración. El valor predeterminado es simplemente scons.

scons_flags

Las banderas de scons utilizadas al ejecutar SCons para recopilar información de tiempo. El valor predeterminado es --debug=count --debug=memory --debug=time --debug=memoizer.

scons_lib_dir, scons_wrapper, startup_targets, subdir

El subdirectorio del proyecto en el que el script scons-time debe cambiarse antes de ejecutar los comandos de SCons a cronometrar.

subversion_url

La URL de Subversion desde

svn

El ejecutable de subversión utilizado para descargar revisiones de SCons a cronometrar. El valor predeterminado es simplemente svn.

svn_co_flag, tar, targets

Una cadena que contiene los objetivos que deben agregarse a la línea de comandos de cada ejecución cronometrada de scons. Esto se puede utilizar para restringir lo que se está cronometrando a un subconjunto de la compilación completa para la configuración.

targets0, targets1, targets2, title, unzip, verbose, vertical_bars

Ejemplo

Aquí hay un archivo de configuración de ejemplo de scons-time para un proyecto hipotético de muestra:

# El proyecto no utiliza SCons de forma nativa (todavía), así que estamos
# cronometrando un conjunto separado de archivos SConscript que colocamos
# encima del archivo tarball del proyecto descomprimido.
arguments = ['project-1.2.tgz', 'project-SConscripts.tar']
# El nombre del subdirectorio contiene el número de versión del proyecto,
# así que indicamos a scons-time que cambie allí antes de compilar.
subdir = 'project-1.2'
# Establecer el prefijo, para que los archivos de registro de salida y los perfiles se nombren:
#     project-000-[012].{log,prof}
#     project-001-[012].{log,prof}
# etc.
prefix = 'project'
# Los archivos SConscript que se están probando no realizan ninguna configuración de SConf,
# así que ejecutamos su script ./configure normal antes de invocar SCons.
initial_commands = [
    './configure',
]
# Solo cronometrar la compilación del ejecutable bin/project.
targets = 'bin/project'
# Cronometrar contra revisiones de SCons de las ramas/rama principal (branches/core)
subversion_url = 'http://scons.tigris.org/svn/scons/branches/core'
