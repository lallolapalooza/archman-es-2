NOMBRE

scor2prt - programa de separación de partes de partitura para pmx, un preprocesador de MusiXTeX

SINOPSIS

scor2prt nombre_base[.pmx]

DESCRIPCIÓN

scor2prt es parte de pmx(1), un preprocesador para MusiXTeX. Puede crear automáticamente partes a partir de una partitura generando un conjunto de archivos .pmx, uno para cada parte, a partir de un único archivo .pmx para la partitura. La apariencia de las partes se puede controlar mediante comandos especiales en el archivo principal. Lea el Manual de PMX para obtener más información al respecto.

VER TAMBIÉN

pmx(1), pmxab(1), musixtex(1), Manual de PMX
