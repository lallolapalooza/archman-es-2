SCHED_SETPARAM(3P) Manual de Programador POSIX SCHED_SETPARAM(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sched_setparam — establecer parámetros de planificación (TIEMPO REAL)

SINOPSIS

#include <sched.h>
int sched_setparam(pid_t pid, const struct sched_param *param);

DESCRIPCIÓN

La función sched_setparam() establecerá los parámetros de planificación del proceso especificado por pid a los valores especificados por la estructura sched_param apuntada por param. El valor del miembro sched_priority en la estructura sched_param será cualquier entero dentro del rango de prioridad inclusivo para la política de planificación actual del proceso especificado por pid. Valores numéricos más altos para la prioridad representan prioridades más altas. Si el valor de pid es negativo, el comportamiento de la función sched_setparam() no está especificado.

Si existe un proceso especificado por pid, y si el proceso llamante tiene permiso, los parámetros de planificación se establecerán para el proceso cuyo ID de proceso sea igual a pid.

Si pid es cero, los parámetros de planificación se establecerán para el proceso llamante.

Las condiciones bajo las cuales un proceso tiene permiso para cambiar los parámetros de planificación de otro proceso son definidas por la implementación.

Las implementaciones pueden requerir que el proceso solicitante tenga los privilegios apropiados para establecer sus propios parámetros de planificación o los de otro proceso.

Consulte Políticas de Planificación para una descripción de cómo esta función afecta la planificación de los hilos dentro del proceso objetivo.

Si la política de planificación actual para el proceso objetivo no es SCHED_FIFO, SCHED_RR o SCHED_SPORADIC, el resultado está definido por la implementación; este caso incluye la política SCHED_OTHER.

El período sched_ss_repl_period especificado deberá ser mayor o igual que el presupuesto inicial sched_ss_init_budget especificado para que la función tenga éxito; si no es así, la función fallará.

El valor de sched_ss_max_repl deberá estar dentro del rango inclusivo [1,{SS_REPL_MAX}] para que la función tenga éxito; si no es así, la función fallará. No está especificado si los valores de sched_ss_repl_period y sched_ss_init_budget se almacenan tal como los proporciona esta función o si se redondean para alinearse con la resolución del reloj que se está utilizando.

Esta función no es atómica con respecto a otros hilos en el proceso. Los hilos pueden continuar ejecutándose mientras esta llamada a función esté en proceso de cambiar la política de planificación para las entidades subyacentes planificadas por el kernel utilizadas por los hilos con ámbito de contención del proceso.

VALOR DE RETORNO

Si tiene éxito, la función sched_setparam() devolverá cero.

Si la llamada a sched_setparam() no tiene éxito, la prioridad permanecerá sin cambios y la función devolverá un valor de -1 y establecerá errno para indicar el error.

ERRORES

La función sched_setparam() fallará si:

EINVAL
Uno o más de los parámetros de planificación solicitados está fuera del rango definido para la política de planificación del pid especificado.
EPERM
El proceso solicitante no tiene permiso para establecer los parámetros de planificación para el proceso especificado, o no tiene los privilegios apropiados para invocar sched_setparam().
ESRCH
No se puede encontrar ningún proceso que corresponda al especificado por pid.
