sctp_recvmsg(3)

SCTP_RECVMSG(3) Manual del programador de Linux SCTP_RECVMSG(3)

NOMBRE

sctp_recvmsg - Recibe un mensaje de un socket SCTP.

SINOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_recvmsg(int sd, void * msg, size_t len,
                 struct sockaddr * from, socklen_t * fromlen,
                 struct sctp_sndrcvinfo * sinfo, int * msg_flags);

DESCRIPCIÓN

sctp_recvmsg es una función de la biblioteca que se puede utilizar para recibir un mensaje de un socket utilizando las características avanzadas de SCTP. sd es el descriptor del socket en el que se recibe el mensaje apuntado por msg de longitud len.

Si from no es NULL, se rellena la dirección de origen del mensaje. El argumento fromlen es un parámetro de valor-resultado, inicializado al tamaño del búfer asociado con from, y modificado al retornar para indicar el tamaño real de la dirección almacenada.

sinfo es un puntero a una estructura sctp_sndrcvinfo que se rellenará al recibir el mensaje. msg_flags es un puntero a un entero que se rellena con cualesquiera banderas de mensaje como MSG_NOTIFICATION o MSG_EOR. El valor del puntero msg_flags debe inicializarse a 0 para evitar un comportamiento inesperado; msg_flags también se utiliza como argumento de entrada flags para la función recvmsg.

VALOR DE RETORNO

En caso de éxito, sctp_recvmsg devuelve el número de bytes recibidos o -1 si ocurrió un error.
