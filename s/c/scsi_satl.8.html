NOMBRE

scsi_satl - comprueba la compatibilidad del dispositivo de Traducción SCSI a ATA (SAT)

SINOPSIS

scsi_satl [--ayuda] [--log] [--silencioso] [--verboso] DISPOSITIVO

DESCRIPCIÓN

Este script de shell bash llama a varios comandos SCSI en el DISPOSITIVO dado, que se asume que es un dispositivo ATA detrás de una capa de Traducción SCSI a ATA (SATL). Se muestran los resultados de cada prueba y un recuento de aprobados/fallos.

OPCIONES

Los argumentos de las opciones largas son obligatorios también para las opciones cortas.

-h, --ayuda
imprime el mensaje de uso y sale.
-L, --log
la salida a stderr (de cada comando SCSI ejecutado) se añade a un archivo llamado 'scsi_satl.err' en el directorio de trabajo actual.
-q, --silencioso
la cantidad de salida se reduce y normalmente solo se muestra el recuento de aprobados/fallos.
-v, --verboso
aumenta el nivel de verbosidad.

ESTADO DE SALIDA

El estado de salida de este script es el número de errores "malos" encontrados. Por lo tanto, un estado de salida de 0 significa que todos los comandos SCSI obligatorios funcionaron como se esperaba.
