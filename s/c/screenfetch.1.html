NOMBRE

screenFetch - La herramienta de información de capturas de pantalla de Bash

SINOPSIS

screenfetch [OPCIONES OPCIONALES]

DESCRIPCIÓN

Este práctico script de Bash puede ser utilizado para generar una de esas agradables informaciones de temas de terminal + logos de distribución en ASCII que se ven en las capturas de pantalla de todos hoy en día. Detectará automáticamente tu distribución y mostrará una versión en ASCII del logo de esa distribución y alguna información valiosa a la derecha. Hay opciones para especificar sin arte ASCII, colores, tomar una captura de pantalla al mostrar información e incluso personalizar el comando de captura de pantalla. Este script es muy fácil de ampliar y puede extenderse fácilmente.

OPCIONES

-v
Salida detallada.
-o 'OPCIONES'
Permite establecer variables del script en la línea de comandos. Debe estar en el siguiente formato: 'OPCION1="ARGUMENTO OPCION1";OPCION2="ARGUMENTO OPCION2"'
-d '+var;-var;var'
Permite establecer qué información se muestra en la línea de comandos. Puedes añadir visualizaciones con +var,var. Puedes eliminar visualizaciones con -var,var. Establecer sin + o - fijará la visualización a esa combinación explícita. Las declaraciones de añadir y eliminar pueden usarse en conjunto colocando un ; entre ellas, así: +var,var,var;-var,var.
-n
No mostrar el logo de la distribución en ASCII.
-L
Mostrar solo el logo de la distribución en ASCII.
-N
Eliminar todo el color de la salida.
-w
Ajustar líneas largas.
-t
Truncar la salida basándose en el ancho de la terminal (¡Experimental!).
-p
Salida en modo retrato, con el logo encima de la información.
-s [-u IMGHOST]
Usar esta bandera le dice al script que quieres que tome una captura de pantalla. Usa la bandera -u si quieres subir las capturas de pantalla a una de las ubicaciones preconfiguradas. Estas incluyen: teknik, imgur, mediacrush y hmp.
-c cadena
Puedes cambiar los colores de salida con -c. El formato es el siguiente: [0-9][0-9],[0-9][0-9]. El primer argumento controla los colores del logo ASCII y los colores de las etiquetas. El segundo argumento controla los colores de la información encontrada. Se puede usar un argumento sin el otro.
-a 'RUTA'
Puedes especificar un arte ASCII personalizado pasando la ruta a un script Bash, definiendo las variables startline y fulloutput, y opcionalmente labelcolor y textcolor. Consulta la función asciiText en el código fuente para más información sobre el formato de las variables.
-S 'COMANDO'
Aquí puedes especificar un comando de captura de pantalla personalizado para que el script lo ejecute. Se requieren comillas envolventes.
-D 'DISTRO'
Aquí puedes especificar tu distribución para que el script la use. Se requieren comillas envolventes.
-A 'DISTRO'
Aquí puedes especificar el arte de la distribución que quieres mostrar. Esto es para cuando quieres que se detecte tu distro pero quieres mostrar un logo diferente.
-E
Suprimir la salida de errores.
-V, --version
Mostrar la versión actual del script.
-h, --help
Mostrar esta ayuda.
