Propósito:

!>
!> SCHKST2STG comprueba las rutinas del problema de valores propios simétricos
!> utilizando técnicas de reducción de 2 etapas. Dado que la generación
!> de Q o los vectores no está disponible en esta versión, solo
!> comparamos el valor propio resultante al usar la reducción de 2 etapas con
!> la considerada como referencia utilizando la reducción estándar de 1 etapa
!> SSYTRD. Para ello, llamamos a SSYTRD estándar y calculamos D1 usando
!> SSTEQR, luego llamamos a SSYTRD_2STAGE de 2 etapas con Superior e Inferior
!> y calculamos D2 y D3 usando SSTEQR y luego reemplazamos las pruebas
!> 3 y 4 por las pruebas 11 y 12. Las pruebas 1 y 2 permanecen para verificar que
!> los resultados de 1 etapa están OK y son confiables.
!> Esta rutina de prueba convergerá a SCHKST en la próxima
!> versión cuando se implementen los vectores y la generación de Q.
!>
!>    SSYTRD factoriza A como  U S U' , donde ' significa transpuesta,
!>    S es simétrica tridiagonal y U es ortogonal.
!>    SSYTRD puede usar solo el triángulo inferior o solo el superior
!>    de A; SCHKST2STG verifica ambos casos.
!>    U se representa como un producto de transformaciones de Householder
!>    cuyos vectores se almacenan en las primeras
!>    n-1 columnas de V y cuyos factores de escala están en TAU.
!>
!>    SSPTRD hace lo mismo que SSYTRD, excepto que A y V se almacenan
!>    en formato .
!>
!>    SORGTR construye la matriz U a partir del contenido de V y TAU.
!>
!>    SOPGTR construye la matriz U a partir del contenido de VP y TAU.
!>
!>    SSTEQR factoriza S como  Z D1 Z' , donde Z es la matriz ortogonal
!>    de vectores propios y D1 es una matriz diagonal con
!>    los valores propios en la diagonal.  D2 es la matriz de
!>    valores propios calculados cuando Z no se calcula.
!>
!>    SSTERF calcula D3, la matriz de valores propios, mediante el
!>    método PWK, que no produce vectores propios.
!>
!>    SPTEQR factoriza S como  Z4 D4 Z4' , para una
!>    matriz tridiagonal simétrica definida positiva.
!>    D5 es la matriz de valores propios calculada cuando Z no se
!>    calcula.
!>
!>    SSTEBZ calcula valores propios seleccionados.  WA1, WA2 y
!>    WA3 denotarán los valores propios calculados con alta
!>    precisión absoluta, con diferentes opciones de rango.
!>    WR denotará los valores propios calculados con alta
!>    precisión relativa.
!>
!>    SSTEIN calcula Y, los vectores propios de S, dados los
!>    valores propios.
!>
!>    SSTEDC factoriza S como Z D1 Z' , donde Z es la matriz ortogonal
!>    de vectores propios y D1 es una matriz diagonal con
!>    los valores propios en la diagonal (opción 'I'). También
!>    puede actualizar una matriz ortogonal de entrada, generalmente la salida
!>    de SSYTRD/SORGTR o SSPTRD/SOPGTR (opción 'V'). También
!>    puede calcular solo valores propios (opción 'N').
!>
!>    SSTEMR factoriza S como Z D1 Z' , donde Z es la matriz ortogonal
!>    de vectores propios y D1 es una matriz diagonal con
!>    los valores propios en la diagonal (opción 'I').  SSTEMR
!>    utiliza la Representación Relativamente Robusta siempre que sea posible.
!>
!> Cuando se llama a SCHKST2STG, se especifican un número de matrices () y un
!> número de matrices . Para cada tamaño ()
!> y cada tipo de matriz, se generará una matriz y se utilizará
!> para probar las rutinas de valores propios simétricos. Para cada matriz, se
!> realizarán una serie de pruebas:
!>
!> (1)     | A - V S V' | / ( |A| n ulp ) SSYTRD( UPLO='U', ... )
!>
!> (2)     | I - UV' | / ( n ulp )        SORGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V' | / ( |A| n ulp ) SSYTRD( UPLO='L', ... )
!>         reemplazado por | D1 - D2 | / ( |D1| ulp ) donde D1 es la
!>         matriz de valores propios calculada usando S y D2 es la
!>         matriz de valores propios calculada usando S_2stage la salida de
!>         SSYTRD_2STAGE(, ,....). D1 y D2 se calculan
!>         vía SSTEQR('N',...)
!>
!> (4)     | I - UV' | / ( n ulp )        SORGTR( UPLO='L', ... )
!>         reemplazado por | D1 - D3 | / ( |D1| ulp ) donde D1 es la
!>         matriz de valores propios calculada usando S y D3 es la
!>         matriz de valores propios calculada usando S_2stage la salida de
!>         SSYTRD_2STAGE(, ,....). D1 y D3 se calculan
!>         vía SSTEQR('N',...)
!>
!> (5-8)   Igual que 1-4, pero para SSPTRD y SOPGTR.
!>
!> (9)     | S - Z D Z' | / ( |S| n ulp ) SSTEQR('V',...)
!>
!> (10)    | I - ZZ' | / ( n ulp )        SSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        SSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        SSTERF
!>
!> (13)    0 si los valores propios verdaderos (calculados por conteo de Sturm)
!>         de S están dentro de THRESH de
!>         los de D1.  2*THRESH si no lo están.  (Probado usando

NAME

schkst2stg - checks the subroutine SSYTRD, SORGTR, SSTEQR, SPTEQR, SSTEIN, SSTERF and SORMC2.

SYNOPSIS

 SUBROUTINE SCHKST2STG(NN, NSIZES, NTYPES, THRESH, A, LDA, Z, LDU,
                        VP, TAU, WORK, LWORK, IWORK, LIWORK, RESULT, INFO)

Function/Subroutine Documentation

This subroutine checks the routines SSYTRD, SORGTR, SSTEQR, SPTEQR, SSTEIN, SSTERF and SORMC2.

NN (INTEGER, dimension(NSIZES)) An array of dimension NSIZES. NN(j) contains the number of problems to be generated for the j-th matrix size. The maximum value in NN will be used to dimension arrays like Z and VP.

NSIZES (INTEGER) The number of values of N to be tested. For each j from 1 to NSIZES, NN(j) problems of dimension NN(j) will be generated.

NTYPES (INTEGER) The number of matrix types to be tested. For each j from 1 to NTYPES, TYPE(j) problems will be generated.

THRESH (REAL) A threshold to determine convergence of iterative methods. A test will be between 1 and THRESH if the test ratio is less than or equal to THRESH, and between THRESH and 1/ulp if the test ratio is greater than THRESH. A value of 1.0 is recommended.

A (REAL array, dimension (LDA, max(NN))) The matrix A on which all the computations are performed.

LDA (INTEGER) The leading dimension of A.

Z (REAL array, dimension (LDU, max(NN))) The orthogonal matrix of eigenvectors computed by SSTEQR, SPTEQR, and SSTEIN.

LDU (INTEGER) The leading dimension of Z.

VP (REAL array, dimension (max(NN)*max(NN+1)/2)) The matrix V stored in packed format.

TAU (REAL array, dimension (max(NN))) The Householder factors computed by SSYTRD in reducing A to tridiagonal form.

WORK (REAL array, dimension (LWORK))

LWORK (INTEGER) The number of entries in WORK. This must be at least 1 + 4 * Nmax + 2 * Nmax * lg Nmax + 3 * Nmax**2 where Nmax = max( NN(j), 2 ) and lg = log base 2.

IWORK (INTEGER array, Workspace.
