Paquete: tk

Licencias: TCL

scrollbar(n) Comandos integrados de Tk scrollbar(n)

NOMBRE

scrollbar - Crea y manipula widgets de control de desplazamiento e indicador 'scrollbar'

SINOPSIS

scrollbar nombreVentana ?opciones?

OPCIONES ESTÁNDAR

-activebackground	-highlightcolor	-repeatdelay
-background	-highlightthickness	-repeatinterval
-borderwidth	-jump	-takefocus
-cursor	-orient	-troughcolor
-highlightbackground	-relief

Consulte la entrada del manual de options para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-activerelief
Nombre de base de datos:	activeRelief
Clase de base de datos:	ActiveRelief
Especifica el relieve a usar al mostrar el elemento que está activo, si lo hay. Los elementos distintos del elemento activo siempre se muestran con un relieve elevado.
Nombre de línea de comandos:	-command
Nombre de base de datos:	command
Clase de base de datos:	Command
Especifica el prefijo de un comando Tcl a invocar para cambiar la vista en el widget asociado con la barra de desplazamiento. Cuando un usuario solicita un cambio de vista manipulando la barra de desplazamiento, se invoca un comando Tcl. El comando real consiste en esta opción seguida de información adicional según se describe más adelante. Esta opción casi siempre tiene un valor como .t xview o .t yview, que consiste en el nombre de un widget y ya sea xview (si la barra de desplazamiento es para desplazamiento horizontal) o yview (para desplazamiento vertical). Todos los widgets desplazables tienen comandos xview y yview que toman exactamente los argumentos adicionales agregados por la barra de desplazamiento, como se describe en COMANDOS DE DESPLAZAMIENTO a continuación.
Nombre de línea de comandos:	-elementborderwidth
Nombre de base de datos:	elementBorderWidth
Clase de base de datos:	BorderWidth
Especifica el ancho de los bordes dibujados alrededor de los elementos internos de la barra de desplazamiento (las dos flechas y el deslizador). El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels. Si este valor es menor que cero, se utilizará en su lugar el valor de la opción -borderwidth.
Nombre de línea de comandos:	-width
Nombre de base de datos:	width
Clase de base de datos:	Width
Especifica la dimensión estrecha deseada de la ventana de la barra de desplazamiento, sin incluir el borde 3D, si lo hay. Para las barras de desplazamiento verticales, este será el ancho y para las barras de desplazamiento horizontales, esta será la altura. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels.

DESCRIPCIÓN

El comando scrollbar crea una nueva ventana (dada por el argumento nombreVentana) y la convierte en un widget de barra de desplazamiento. Se pueden especificar opciones adicionales, descritas anteriormente, en la línea de comandos o en la base de datos de opciones para configurar aspectos de la barra de desplazamiento, como sus colores, orientación y relieve. El comando scrollbar devuelve su argumento nombreVentana. En el momento en que se invoca este comando, no debe existir una ventana llamada nombreVentana, pero el padre de nombreVentana debe existir.

Una barra de desplazamiento es un widget que muestra dos flechas, una en cada extremo de la barra de desplazamiento, y un deslizador en la porción central de la barra de desplazamiento. Proporciona información sobre lo que es visible en una ventana asociada que muestra un documento de algún tipo (como un archivo que se está editando o un dibujo). La posición y el tamaño del deslizador indican qué porción del documento es visible en la ventana asociada. Por ejemplo, si el deslizador en una barra de desplazamiento vertical cubre el tercio superior del área entre las dos flechas, significa que la ventana asociada muestra el tercio superior de su documento.

Las barras de desplazamiento se pueden usar para ajustar la vista en la ventana asociada haciendo clic o arrastrando con el ratón. Consulte la sección ENLACES a continuación para obtener detalles.

ELEMENTOS

Una barra de desplazamiento muestra cinco elementos, a los que se hace referencia en los comandos del widget para la barra de desplazamiento:

flecha1
La flecha superior o izquierda en la barra de desplazamiento.
canal1
La región entre el deslizador y flecha1.
deslizador
El rectángulo que indica lo que es visible en el widget asociado.
canal2
La región entre el deslizador y flecha2.
flecha2
La flecha inferior o derecha en la barra de desplazamiento.

COMANDO DEL WIDGET

El comando scrollbar crea un nuevo comando Tcl cuyo nombre es nombreVentana. Este comando se puede utilizar para invocar varias operaciones en el widget. Tiene la siguiente forma general:

nombreVentana opcion ?arg ...?
Opcion y los args determinan el comportamiento exacto del comando. Los siguientes comandos son posibles para los widgets de barra de desplazamiento:
nombreVentana activate ?elemento?
Marca el elemento indicado por elemento como activo, lo que hace que se muestre según lo especificado por las opciones -activebackground y -activerelief. Los únicos valores de elemento que entiende este comando son flecha1, deslizador o flecha2. Si se especifica cualquier otro valor, ningún elemento de la barra de desplazamiento estará activo. Si no se especifica elemento, el comando devuelve el nombre del elemento que está actualmente activo, o una cadena vacía si no hay ningún elemento activo.
nombreVentana cget opcion
Devuelve el valor actual de la opción de configuración dada por opcion. Opcion puede tener cualquiera de los valores aceptados por el comando scrollbar.
nombreVentana configure ?opcion? ?valor opcion valor ...?
Consulta o modifica las opciones de configuración del widget. Si no se especifica ninguna opcion, devuelve una lista que describe todas las opciones disponibles para nombreVentana (consulte Tk_ConfigureInfo para obtener información sobre el formato de esta lista). Si se especifica opcion sin valor, el comando devuelve una lista que describe la opción nombrada (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica opcion). Si se especifican uno o más pares opción-valor, el comando modifica la(s) opción(es) del widget dada(s) para tener el(los) valor(es) dado(s); en este caso, el comando devuelve una cadena vacía. Opcion puede tener cualquiera de los valores aceptados por el comando scrollbar.
nombreVentana delta deltaX deltaY
Devuelve un número real que indica el cambio fraccional en la configuración de la barra de desplazamiento que corresponde a un cambio dado en la posición del deslizador. Por ejemplo, si la barra de desplazamiento es horizontal, el resultado indica cuánto debe cambiar la configuración de la barra de desplazamiento para mover el deslizador deltaX píxeles hacia la derecha (deltaY se ignora en este caso). Si la barra de desplazamiento es vertical, el resultado indica cuánto debe cambiar la configuración de la barra de desplazamiento para mover el deslizador deltaY píxeles hacia abajo. Los argumentos y el resultado pueden ser cero o negativos.
nombreVentana fraction x y
Devuelve un número real entre 0 y 1 que indica dónde se encuentra el punto dado por x e y en el área del canal de la barra de desplazamiento. El valor 0 corresponde a la parte superior o izquierda del canal, el valor 1 corresponde a la parte inferior o derecha, 0.5 corresponde al medio, y así sucesivamente. X e y deben ser coordenadas de píxeles relativas al widget de la barra de desplazamiento. Si x e y se refieren a un punto fuera del canal, se utiliza el punto más cercano del canal.
nombreVentana get
Devuelve la configuración de la barra de desplazamiento en forma de una lista cuyos elementos son los argumentos del comando set más reciente.
nombreVentana set first last
Establece la configuración de la barra de desplazamiento. First y last son cadenas que representan números reales. Estos números especifican el rango de la barra de desplazamiento que está visible en el widget asociado. Por ejemplo, si la barra de desplazamiento es vertical y el widget asociado muestra el rango de datos de 0 a 100, y la porción visible actualmente va de 20 a 40, entonces los comandos correspondientes serían set 0.2 0.4. Si los valores de first y last están fuera del rango [0, 1], se ajustan a los límites más cercanos. Si first es mayor que last, se invierten. Los comandos set se utilizan normalmente para actualizar la barra de desplazamiento cuando el contenido del widget asociado se desplaza o cambia de tamaño de forma programática.

DESPLAZAMIENTO DE COMANDOS

Cuando un usuario manipula una barra de desplazamiento, se llama al comando especificado por la opción -command. El comando se llama con argumentos adicionales que indican la acción deseada por el usuario. Los argumentos pueden ser:

Units direction
Mover el deslizador en la dirección indicada por direction (que es -1 para arriba o izquierda, o +1 para abajo o derecha). El número de unidades que se desplaza está determinado por el tamaño del deslizador. Por ejemplo, si el deslizador tiene un tercio del tamaño del canal, se moverá un tercio del rango de datos por cada unidad de desplazamiento.
Pixels deltaX ?deltaY?
Mover el deslizador el número especificado de píxeles en la dirección X (deltaX) o Y (deltaY). Si la barra de desplazamiento es vertical, solo se utiliza deltaY; si es horizontal, solo se utiliza deltaX. Los valores pueden ser positivos o negativos.
Page direction
Mover el deslizador el tamaño completo de la página en la dirección especificada por direction (que es -1 para arriba o izquierda, o +1 para abajo o derecha). El tamaño de la página se determina mediante la relación entre el tamaño del deslizador y el tamaño del canal. Por ejemplo, si el deslizador ocupa la mitad del canal, se moverá la mitad del rango de datos.
Scroll fraction
Mover el deslizador a la posición especificada por fraction, que es un número real entre 0 y 1. El valor 0 corresponde a la parte superior o izquierda del canal, y el valor 1 corresponde a la parte inferior o derecha.
Movement x y
Mover el deslizador a la posición de píxeles dada por x e y. El comando calcula qué fracción del canal corresponde a esa posición y luego llama al comando con el argumento Scroll.

El widget asociado, en respuesta a estos comandos, debe ajustar su vista y luego llamar al comando scrollbar set para actualizar la posición del deslizador. El comando scrollbar set se llama típicamente con el rango de valores visibles en el widget asociado.

ENLACES

El sistema de Tk proporciona enlaces de teclado y ratón predeterminados para la mayoría de los widgets. Estos enlaces permiten al usuario manipular la barra de desplazamiento de forma interactiva. Los enlaces predeterminados para las barras de desplazamiento son:

Botón 1 presionado en flecha1
Desplaza hacia arriba una unidad.
Botón 1 liberado en flecha1
Detiene el desplazamiento.
Botón 1 presionado en flecha2
Desplaza hacia abajo una unidad.
Botón 1 liberado en flecha2
Detiene el desplazamiento.
Botón 1 presionado en canal1
Desplaza hacia arriba una página.
Botón 1 presionado en canal2
Desplaza hacia abajo una página.
Botón 1 presionado en deslizador
Arrastra el deslizador a la posición del puntero del ratón.
Movimiento del ratón con Botón 1 presionado en deslizador
Arrastra el deslizador a la posición del puntero del ratón.
Rueda del ratón (si está disponible)
Desplaza hacia arriba o hacia abajo, dependiendo de la dirección de la rueda del ratón.

Estos enlaces pueden modificarse o eliminarse utilizando el comando bind.

EJEMPLOS

Crear una barra de desplazamiento vertical asociada con un widget de texto llamado .t:

pack .t -side left
scrollbar .s -orient vertical -command {.t yview}
.t configure -yscrollcommand {.s set}

Crear una barra de desplazamiento horizontal asociada con un widget de texto llamado .t:

pack .t -side top
scrollbar .s -orient horizontal -command {.t xview}
.t configure -xscrollcommand {.s set}

NOMBRES

scrollbar - widget de barra de desplazamiento

SINOPSIS

scrollbar ?pathName? ?options...?

ESTANDAR OPCIONES

El widget scrollbar soporta las opciones estandar de Tk, asi como las siguientes:

-activebackground ?color?
Especifica el color de fondo para las flechas y el control deslizante cuando el cursor esta sobre ellos.
-activeforeground ?color?
Especifica el color del primer plano para las flechas y el control deslizante cuando el cursor esta sobre ellos.
-background ?color?
Especifica el color de fondo para el canal (la parte del scrollbar donde no esta el control deslizante).
-bg ?color?
Ver -background.
-borderwidth ?num?
Especifica el ancho del borde alrededor del widget scrollbar. El valor de num debe ser una cantidad de longitud en puntos de pantalla. Ver la opcion -borderwidth de widget estandar para mas detalles.
-bw ?num?
Ver -borderwidth.
-command ?cmd?
Especifica un comando Tcl que sera invocado cada vez que el usuario interactue con el scrollbar. El comando se forma concatenando el valor de la opcion -command con uno de los argumentos de la sintaxis del comando del widget (ver mas abajo). Este comando es usado para notificar a un widget asociado (como un widget text o canvas) que debe cambiar su vista. Ver la seccion COMANDOS DE DESPLAZAMIENTO para mas detalles.
-cursor ?cursor?
Especifica el cursor que se mostrara cuando el puntero del raton este sobre el scrollbar. Ver la opcion -cursor de widget estandar para mas detalles.
-elementborderwidth ?num?
Especifica el ancho del borde alrededor de los elementos individuales del scrollbar (flechas, canal, control deslizante). El valor de num debe ser una cantidad de longitud en puntos de pantalla. El valor predeterminado es 1.
-exportselection ?boolean?
Especifica si el contenido del scrollbar debe ser exportado a la seleccion del sistema. Ver la opcion -exportselection de widget estandar para mas detalles.
-foreground ?color?
Especifica el color del primer plano para el scrollbar. Ver la opcion -foreground de widget estandar para mas detalles.
-height ?num?
Especifica el numero deseado de unidades de altura para el scrollbar. Ver la opcion -height de widget estandar para mas detalles.
-highlightbackground ?color?
Ver la opcion -highlightbackground de widget estandar.
-highlightcolor ?color?
Ver la opcion -highlightcolor de widget estandar.
-highlightthickness ?num?
Ver la opcion -highlightthickness de widget estandar.
-jump ?boolean?
Si es verdadero, entonces el control deslizante del scrollbar no se movera con el puntero del raton mientras se arrastra el boton 1. El cambio de vista solo se aplicara cuando se suelte el boton del raton. Si es falso, el control deslizante seguira al puntero del raton mientras se arrastra. El valor predeterminado es falso.
-orient ?orientacion?
Especifica la orientacion del scrollbar. El valor de orientacion puede ser vertical o horizontal. El valor predeterminado es vertical.
-relief ?relevacion?
Especifica el estilo del borde del widget. Ver la opcion -relief de widget estandar para mas detalles.
-takefocus ?boolean?
Ver la opcion -takefocus de widget estandar.
-visibleamount ?num?
Especifica la cantidad de unidades del objeto que son visibles en la ventana del widget asociado. Este valor se usa internamente para calcular el tamano del control deslizante. Ver la opcion set para mas detalles.
-width ?num?
Especifica el numero deseado de unidades de ancho para el scrollbar. Ver la opcion -width de widget estandar para mas detalles.

DESCRIPCION

Los widgets scrollbar proporcionan controles deslizantes que permiten al usuario desplazar el contenido de otro widget, como un widget text o canvas. Los scrollbars pueden ser verticales u horizontales. Son widgets de bajo nivel que se usan tipicamente en conjuncion con otros widgets para proporcionar funcionalidad de desplazamiento. El widget scrollbar no hace nada por si mismo; invoca comandos Tcl (especificados por la opcion -command) para notificar a un widget asociado sobre los cambios en el estado del scrollbar, y tambien responde a comandos de un widget asociado para actualizar su estado.

ELEMENTOS

Un widget scrollbar se compone de varios elementos geometricos que el usuario puede interactuar. Estos elementos son los siguientes:

arrow1
La flecha en un extremo del scrollbar (la flecha superior para un scrollbar vertical, la flecha izquierda para uno horizontal).
arrow2
La flecha en el otro extremo del scrollbar (la flecha inferior para un scrollbar vertical, la flecha derecha para uno horizontal).
trough1
El canal adyacente a arrow1 (el canal superior para un scrollbar vertical, el canal izquierdo para uno horizontal).
trough2
El canal adyacente a arrow2 (el canal inferior para un scrollbar vertical, el canal derecho para uno horizontal).
slider
La parte movible del scrollbar que indica la posicion actual de la vista dentro del contenido completo.

El nombre del elemento bajo una coordenada dada puede ser determinado usando el comando identify.

COMANDO DEL WIDGET

El comando pathName asociado con un widget scrollbar puede ser invocado con los siguientes comandos de configuracion y consulta:

pathName identify x y
Devuelve el nombre del elemento debajo del punto dado por x e y (como arrow1), o una cadena vacia si el punto no se encuentra en ningun elemento del scrollbar. X e y deben ser coordenadas de pixel relativas al widget scrollbar.
pathName set first last
Este comando es invocado por el widget asociado al scrollbar para informarle sobre la vista actual en el widget. El comando toma dos argumentos, cada uno de los cuales es una fraccion real entre 0 y 1. Las fracciones describen el rango del documento que es visible en el widget asociado. Por ejemplo, si first es 0.2 y last es 0.4, significa que la primera parte del documento visible en la ventana esta al 20% del documento, y la ultima parte visible esta al 40% del mismo.

COMANDOS DE DESPLAZAMIENTO

Cuando el usuario interactua con el scrollbar, por ejemplo, arrastrando el control deslizante, el scrollbar notifica al widget asociado que debe cambiar su vista. El scrollbar realiza la notificacion evaluando un comando Tcl generado a partir de la opcion -command del scrollbar. El comando puede tomar cualquiera de las siguientes formas. En cada caso, prefix es el contenido de la opcion -command, que generalmente tiene un formato como “.t yview”.

prefix moveto fraction
Fraction es un numero real entre 0 y 1. El widget debe ajustar su vista para que el punto dado por fraction aparezca al principio del widget. Si fraction es 0, se refiere al principio del documento. 1.0 se refiere al final del documento, 0.333 se refiere a un punto a un tercio del camino a traves del documento, y asi sucesivamente.
prefix scroll number units
El widget debe ajustar su vista en number unidades. Las unidades se definen de la manera que tenga sentido para el widget, como caracteres o lineas en un widget de texto. Number es 1, lo que significa que una unidad debe salir de la parte superior o izquierda de la ventana, o -1, lo que significa que una unidad debe salir de la parte inferior o derecha de la ventana.
prefix scroll number pages
El widget debe ajustar su vista en number paginas. Depende del widget definir el significado de una pagina; normalmente es ligeramente menos de lo que cabe en la ventana, de modo que haya una ligera superposicion entre las vistas antigua y nueva. Number es 1, lo que significa que la siguiente pagina debe ser visible, o -1, lo que significa que la pagina anterior debe ser visible.

SINTAXIS DE COMANDO ANTIGUA

En versiones de Tk anteriores a la 4.0, los comandos del widget set y get usaban un formato diferente. Este formato todavia se admite por compatibilidad con versiones anteriores, pero esta obsoleto. En la sintaxis de comando antigua, el comando del widget set tiene el siguiente formato:

pathName set totalUnits windowUnits firstUnit lastUnit
En esta forma, los argumentos son todos enteros. TotalUnits da el tamano total del objeto que se esta mostrando en el widget asociado. El significado de una unidad depende del widget asociado; por ejemplo, en un widget editor de texto, las unidades podrian corresponder a lineas de texto. WindowUnits indica el numero total de unidades que caben en la ventana asociada a la vez. FirstUnit y lastUnit dan los indices de las primeras y ultimas unidades actualmente visibles en la ventana asociada (cero corresponde a la primera unidad del objeto).

Bajo la sintaxis antigua, el comando del widget get devuelve una lista de cuatro enteros, que consisten en los valores totalUnits, windowUnits, firstUnit y lastUnit del ultimo comando del widget set.

Los comandos generados por los scrollbars tambien tienen un formato diferente cuando se utiliza la sintaxis antigua:

prefix unit
Unit es un entero que indica lo que debe aparecer en la parte superior o izquierda de la ventana del widget asociado. Tiene el mismo significado que los argumentos firstUnit y lastUnit del comando del widget set.

El ultimo comando del widget set determina si se utiliza o no la sintaxis antigua. Si se le dan dos argumentos reales, se utilizara la nueva sintaxis en el futuro, y si se le dan cuatro argumentos enteros, se utilizara la sintaxis antigua.

ENLACES

Tk crea automaticamente enlaces de clase para los scrollbars que les dan el siguiente comportamiento predeterminado. Si el comportamiento es diferente para los scrollbars verticales y horizontales, el comportamiento horizontal se describe entre parentesis.

[1]
Presionar el boton 1 sobre arrow1 hace que la vista en el widget asociado se desplace hacia arriba (izquierda) en una unidad, de modo que el documento parezca moverse hacia abajo (derecha) una unidad. Si se mantiene presionado el boton, la accion se repite automaticamente.
[2]
Presionar el boton 1 sobre trough1 hace que la vista en el widget asociado se desplace hacia arriba (izquierda) en una pantalla completa, de modo que el documento parezca moverse hacia abajo (derecha) una pantalla completa. Si se mantiene presionado el boton, la accion se repite automaticamente.
[3]
Presionar el boton 1 sobre el control deslizante y arrastrarlo hace que la vista siga al control deslizante. Si la opcion jump es verdadera, entonces la vista no sigue al control deslizante; solo cambia cuando se suelta el boton del raton.
[4]
Presionar el boton 1 sobre trough2 hace que la vista en el widget asociado se desplace hacia abajo (derecha) en una pantalla completa, de modo que el documento parezca moverse hacia arriba (izquierda) una pantalla completa. Si se mantiene presionado el boton, la accion se repite automaticamente.
[5]
Presionar el boton 1 sobre arrow2 hace que la vista en el widget asociado se desplace hacia abajo (derecha) en una unidad, de modo que el documento parezca moverse hacia arriba (izquierda) una unidad. Si se mantiene presionado el boton, la accion se repite automaticamente.
[6]
Si se presiona el boton 2 sobre el canal o el control deslizante, se establece la vista para que corresponda a la posicion del raton; arrastrar el raton con el boton 2 presionado hace que la vista siga al raton. Si se presiona el boton 2 sobre una de las flechas, se produce el mismo comportamiento que al presionar el boton 1.
[7]
Si se presiona el boton 1 con la tecla Control presionada, entonces si el raton esta sobre arrow1 o trough1, la vista cambia al principio (extremo izquierdo) del documento; si el raton esta sobre arrow2 o trough2, la vista cambia al final (extremo derecho) del documento; si el raton esta en cualquier otro lugar, la pulsacion del boton no tiene ningun efecto.
[8]
En los scrollbars verticales, las teclas Arriba y Abajo tienen el mismo comportamiento que los clics del raton sobre arrow1 y arrow2, respectivamente. En los scrollbars horizontales, estas teclas no tienen ningun efecto.
[9]
En los scrollbars verticales, Control-Arriba y Control-Abajo tienen el mismo comportamiento que los clics del raton sobre trough1 y trough2, respectivamente. En los scrollbars horizontales, estas teclas no tienen ningun efecto.
[10]
En los scrollbars horizontales, las teclas Arriba y Abajo tienen el mismo comportamiento que los clics del raton sobre arrow1 y arrow2, respectivamente. En los scrollbars verticales, estas teclas no tienen ningun efecto.
[11]
En los scrollbars horizontales, Control-Arriba y Control-Abajo tienen el mismo comportamiento que los clics del raton sobre trough1 y trough2, respectivamente. En los scrollbars verticales, estas teclas no tienen ningun efecto.
[12]
Las teclas AvPag y RePag tienen el mismo comportamiento que los clics del raton sobre trough1 y trough2, respectivamente.
[13]
La tecla Inicio ajusta la vista al principio (borde izquierdo) del documento.
[14]
La tecla Fin ajusta la vista al final (borde derecho) del documento.

EJEMPLO

Crea una ventana con un widget text desplazable:

toplevel .tl
text .tl.t -yscrollcommand {.tl.s set}
scrollbar .tl.s -command {.tl.t yview}
grid .tl.t .tl.s -sticky nsew
grid columnconfigure .tl 0 -weight 1
grid rowconfigure .tl 0 -weight 1

NOMBRE

scrollbar.n - Describe el widget scrollbar.

DESCRIPCIÓN

El widget scrollbar es un widget de widget que puede ser usado para hacer que un widget tenga barras de desplazamiento. El widget scrollbar no contiene un área para dibujar, pero se usa como un elemento para obtener información sobre los desplazamientos. Un widget puede tener hasta dos barras de desplazamiento (una horizontal y una vertical).

Los siguientes eventos son generados por el widget scrollbar:

  • SCROLLBAR_EVENT_SCROLL: Ocurre cuando el widget contiene un área para dibujar y el usuario intenta desplazarla.

EJEMPLO

El siguiente código crea un widget scrollbar y lo adjunta a un widget de área de dibujo:


widget_t *swin = widget_create(WIDGET_SCROLLBAR);
widget_t *area = widget_create(WIDGET_DRAWING_AREA);

scrollbar_attach(swin, area);

widget_show(swin);
widget_show(area);
