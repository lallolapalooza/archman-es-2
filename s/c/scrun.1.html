NOMBRE

scrun - un proxy de tiempo de ejecución OCI para Slurm.

SINOPSIS

OPERACIÓN DE CREACIÓN

scrun [OPCIONES GLOBALES...] create [OPCIONES DE CREACIÓN] <id-contenedor>

Prepara un nuevo contenedor con id-contenedor en el directorio de trabajo actual.

OPERACIÓN DE INICIO

scrun [OPCIONES GLOBALES...] start <id-contenedor>

Solicita iniciar y ejecutar el contenedor en el trabajo.

OPERACIÓN DE CONSULTA DE ESTADO

scrun [OPCIONES GLOBALES...] state <id-contenedor>

Muestra el estado JSON del contenedor definido por OCI.

OPERACIÓN DE FINALIZACIÓN

scrun [OPCIONES GLOBALES...] kill <id-contenedor> [señal]

Envía una señal (por defecto: SIGTERM) al contenedor.

OPERACIÓN DE ELIMINACIÓN

scrun [OPCIONES GLOBALES...] delete [OPCIONES DE ELIMINACIÓN] <id-contenedor>

Libera cualquier recurso que el contenedor posea localmente y remotamente.

Realiza operaciones de tiempo de ejecución OCI contra id-contenedor según:
https://github.com/opencontainers/runtime-spec/blob/main/runtime.md

scrun intenta imitar el comportamiento de la línea de comandos lo más fielmente posible a crun y runc para mantener la compatibilidad de reemplazo en el lugar con DOCKER y podman. Se aceptarán todos los argumentos de línea de comandos para crun y runc por compatibilidad, pero pueden ser ignorados dependiendo de su aplicabilidad.

DESCRIPCIÓN

scrun es un proxy de tiempo de ejecución OCI para Slurm. Actúa como una interfaz común para DOCKER o podman para permitir que las operaciones del contenedor se ejecuten bajo Slurm como trabajos. scrun aceptará todos los comandos como un tiempo de ejecución compatible con OCI, pero redirigirá el contenedor y toda la E/S estándar a Slurm para su programación y ejecución. Los contenedores se ejecutarán de forma remota en los nodos de cómputo de Slurm según la configuración en oci.conf(5).

scrun requiere que todos los contenedores cumplan con la especificación de imagen OCI según:
https://github.com/opencontainers/image-spec/blob/main/spec.md

VALOR DE RETORNO

En caso de operación exitosa, scrun devolverá 0. Para cualquier otra condición, scrun devolverá cualquier número distinto de cero para denotar un error.

OPCIONES GLOBALES

--cgroup-manager
Ignorado.
--debug
Activa el registro a nivel de depuración.
-f <ruta_slurm_conf>
Utiliza el slurm.conf especificado para la configuración.
Por defecto: sysconfdir de configure durante la compilación
--usage
Muestra ayuda rápida sobre cómo llamar a scrun
--log-format=<json|text>
Selecciona opcionalmente el formato para el registro. Puede ser "json" o "text".
Por defecto: text
--root=<ruta_root>
Ruta al directorio de almacenamiento temporal para sockets de comunicación y directorios y archivos temporales. Esto debería ser un tmpfs y se borrará al reiniciar.
Por defecto: /run/user/{id_usuario}/scrun/
--rootless
Ignorado. Todos los comandos de scrun son siempre sin raíz (rootless).
--systemd-cgroup
Ignorado.
-v
Aumenta la verbosidad del registro. Múltiples -v aumentan la verbosidad.
-V, --version
Imprime la información de la versión y sale.

OPCIONES DE CREACIÓN

-b <ruta_bundle>, --bundle=<ruta_bundle>
Ruta a la raíz del directorio del bundle.
Por defecto: directorio de trabajo del llamante
--console-socket=<ruta_socket_consola>
Ruta opcional a un socket AF_UNIX que recibirá un descriptor de archivo que hace referencia al extremo maestro del pseudoterminal de la consola.
Por defecto: ignorado
--no-pivot
Ignorado.
--no-new-keyring
Ignorado.
--pid-file=<ruta_archivo_pid>
Especifica el archivo a bloquear y poblar con el ID del proceso.
Por defecto: ignorado
--preserve-fds
Ignorado.

OPCIONES DE ELIMINACIÓN

--force
Ignorado. Todas las solicitudes de eliminación son forzadas y matarán cualquier trabajo en ejecución.

SLURM_TASKS_PER_NODE
Número de tareas que se iniciarán en cada nodo. Los valores están separados por comas y en el mismo orden que SLURM_JOB_NODELIST. Si dos o más nodos consecutivos tienen el mismo recuento de tareas, ese recuento va seguido de "(x#)" donde "#" es el recuento de repetición. Por ejemplo, "SLURM_TASKS_PER_NODE=2(x3),1" indica que los tres primeros nodos ejecutarán cada uno dos tareas y el cuarto nodo ejecutará una tarea.
SLURM_THREADS_PER_CORE
Esto solo se establece si se especificaron --threads-per-core o SCRUN_THREADS_PER_CORE. El valor se establecerá en el valor especificado por --threads-per-core o SCRUN_THREADS_PER_CORE. Esto lo utilizan las llamadas posteriores a srun dentro de la asignación del trabajo.
SLURM_TRES_PER_TASK
Establecido en el valor de --tres-per-task. Si se especifican --cpus-per-task o --gpus-per-task, también se establece en SLURM_TRES_PER_TASK como si se hubiera especificado en --tres-per-task.

slurm_scrun_stage_in

slurm_scrun_stage_in(id, bundle, spool_dir, config_file, job_id, user_id, group_id, job_env)
Stages in the container root filesystem and configuration for a given job. This involves creating a directory structure in the scratch space, copying the root filesystem using rsync, and modifying the OCI configuration (e.g., setting user namespaces, removing cgroups, handling mounts).
ile(path, contents)
	local file = open(path, "wb")
	if not file then return nil end
	file:write(contents)
	file:close()
	return
end
function slurm_scrun_stage_in(id, bundle, spool_dir, config_file, job_id, user_id, group_id, job_env)
	slurm.log_debug(string.format("stage_in(%s, %s, %s, %s, %d, %d, %d)",
		       id, bundle, spool_dir, config_file, job_id, user_id, group_id))
	local status, output, user, rc
	local config = json.decode(read_file(config_file))
	local src_rootfs = config["root"]["path"]
	rc, user = slurm.allocator_command(string.format("id -un %d", user_id))
	user = string.gsub(user, "%s+", "")
	local root = scratch_path..math.floor(user_id).."/slurm/scrun/"
	local dst_bundle = root.."/"..id.."/"
	local dst_config = root.."/"..id.."/config.json"
	local dst_rootfs = root.."/"..id.."/rootfs/"
	if string.sub(src_rootfs, 1, 1) ~= "/"
	then
		-- always use absolute path
		src_rootfs = string.format("%s/%s", bundle, src_rootfs)
	end
	status, output = slurm.allocator_command("mkdir -p "..dst_rootfs)
	if (status ~= 0)
	then
		slurm.log_info(string.format("mkdir(%s) failed %u: %s",
			       dst_rootfs, status, output))
		return slurm.ERROR
	end
	status, output = slurm.allocator_command(string.format("/usr/bin/env rsync --exclude sys --exclude proc --numeric-ids --delete-after --ignore-errors --stats -a -- %s/ %s/", src_rootfs, dst_rootfs))
	if (status ~= 0)
	then
		-- rsync can fail due to permissions which may not matter
		slurm.log_info(string.format("WARNING: rsync failed: %s", output))
	end
	slurm.set_bundle_path(dst_bundle)
	slurm.set_root_path(dst_rootfs)
	config["root"]["path"] = dst_rootfs
	-- Always force user namespace support in container or runc will reject
	local process_user_id = 0
	local process_group_id = 0
	if ((config["process"] ~= nil) and (config["process"]["user"] ~= nil))
	then
		-- resolve out user in the container
		if (config["process"]["user"]["uid"] ~= nil)
		then
			process_user_id=config["process"]["user"]["uid"]
		else
			process_user_id=0
		end
		-- resolve out group in the container
		if (config["process"]["user"]["gid"] ~= nil)
		then
			process_group_id=config["process"]["user"]["gid"]
		else
			process_group_id=0
		end
		-- purge additionalGids as they are not supported in rootless
		if (config["process"]["user"]["additionalGids"] ~= nil)
		then
			config["process"]["user"]["additionalGids"] = nil
		end
	end
	if (config["linux"] ~= nil)
	then
		-- force user namespace to always be defined for rootless mode
		local found = false
		if (config["linux"]["namespaces"] == nil)
		then
			config["linux"]["namespaces"] = {}
		else
			for _, namespace in ipairs(config["linux"]["namespaces"]) do
				if (namespace["type"] == "user")
				then
					found=true
					break
				end
			end
		end
		if (found == false)
		then
			table.insert(config["linux"]["namespaces"], {type= "user"})
		end
		-- Provide default user map as root if one not provided
		if (true or config["linux"]["uidMappings"] == nil)
		then
			config["linux"]["uidMappings"] =
				{{containerID=process_user_id, hostID=math.floor(user_id), size=1}}
		end
		-- Provide default group map as root if one not provided
		-- mappings fail with build???
		if (true or config["linux"]["gidMappings"] == nil)
		then
			config["linux"]["gidMappings"] =
				{{containerID=process_group_id, hostID=math.floor(group_id), size=1}}
		end
		-- disable trying to use a specific cgroup
		config["linux"]["cgroupsPath"] = nil
	end
	if (config["mounts"] ~= nil)
	then
		-- Find and remove any user/group settings in mounts
		for _, mount in ipairs(config["mounts"]) do
			local opts = {}
			if (mount["options"] ~= nil)
			then
				for _, opt in ipairs(mount["options"]) do
					if ((string.sub(opt, 1, 4) ~= "gid=") and (string.sub(opt, 1, 4) ~= "uid="))
					then
						table.insert(opts, opt)
					end
				end
			end
			if (opts ~= nil and #opts > 0)
			then
				mount["options"] = opts
			else
				mount["options"] = nil
			end
		end
		-- Remove all bind mounts by copying files into rootfs
		local mounts = {}
		for i, mount in ipairs(config["mounts"]) do
			if ((mount["type"] ~= nil) and (mount["type"] == "bind") and (string.sub(mount["source"], 1, 4) ~= "/sys") and (string.sub(mount["source"], 1, 5) ~= "/proc"))
			then
				status, output = slurm.allocator_command(string.format("/usr/bin/env rsync --numeric-ids --ignore-errors --stats -a -- %s %s", mount["source"], dst_rootfs..mount["destination"]))
				if (status ~= 0)
				then
					-- rsync can fail due to permissions which may not matter
					slurm.log_info("rsync failed")
				end
			else
				table.insert(mounts, mount)
			end
		end
		config["mounts"] = mounts
	end
	-- Force version to one compatible with older runc/crun at risk of new features silently failing
	config["ociVersion"] = "1.0.0"
	-- Merge in Job environment into container -- this is optional!
	if (config["process"]["env"] == nil)
	then
		config["process"]["env"] = {}
	end
	for _, env in ipairs(job_env) do
		table.insert(config["process"]["env"], env)
	end
	-- Remove all prestart hooks to squash any networking attempts
	if ((config["hooks"] ~= nil) and (config["hooks"]["prestart"] ~= nil))
	then
		config["hooks"]["prestart"] = nil
	end
	-- Remove all rlimits
	if ((config["process"] ~= nil) and (config["process"]["rlimits"] ~= nil))
	then
		config["process"]["rlimits"] = nil
	end
	write_file(dst_config, json.encode(config))
	slurm.log_info("created: "..dst_config)
	return slurm.SUCCESS
end

slurm_scrun_stage_out

slurm_scrun_stage_out(id, bundle, orig_bundle, root_path, orig_root_path, spool_dir, config_file, jobid, user_id, group_id)
Stages out the container root filesystem changes back to the original location. It uses rsync to copy data back and then cleans up the temporary container directory.
function slurm_scrun_stage_out(id, bundle, orig_bundle, root_path, orig_root_path, spool_dir, config_file, jobid, user_id, group_id)
	if (root_path == nil)
	then
		root_path = ""
	end
	slurm.log_debug(string.format("stage_out(%s, %s, %s, %s, %s, %s, %s, %d, %d, %d)",
		       id, bundle, orig_bundle, root_path, orig_root_path, spool_dir, config_file, jobid, user_id, group_id))
	if (bundle == orig_bundle)
	then
		slurm.log_info(string.format("skipping stage_out as bundle=orig_bundle=%s", bundle))
		return slurm.SUCCESS
	end
	status, output = slurm.allocator_command(string.format("/usr/bin/env rsync --numeric-ids --delete-after --ignore-errors --stats -a -- %s/ %s/", root_path, orig_root_path))
	if (status ~= 0)
	then
		-- rsync can fail due to permissions which may not matter
		slurm.log_info("rsync failed")
	else
		-- cleanup temporary after they have been synced backed to source
		slurm.allocator_command(string.format("/usr/bin/rm --preserve-root=all --one-file-system -dr -- %s", bundle))
	end
	return slurm.SUCCESS
end
