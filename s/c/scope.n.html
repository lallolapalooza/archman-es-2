scope(n)

Paquete: tcl

Licencias: TCL

scope(n) [incr Tcl] scope(n)

NOMBRE

itcl::scope - captura el contexto del espacio de nombres para una variable

SINOPSIS

itcl::scope nombre

DESCRIPCIÓN

Crea un valor con ámbito para el nombre especificado, que debe ser el nombre de una variable. Si el nombre es una variable de instancia, entonces el comando scope devuelve un nombre que se resolverá en cualquier contexto como una variable de instancia perteneciente a objeto. El formato preciso de este nombre es un detalle interno de Itcl. El uso de dicho valor con ámbito hace posible utilizar variables de instancia junto con widgets. Por ejemplo, si tienes un objeto con una variable privada x, y puedes usar x junto con la opción -textvariable de un widget entry. Antes de itcl3.0, solo se podían usar variables comunes de esta manera.

Si el nombre no es una variable de instancia, entonces debe ser una variable común o una variable global. En ese caso, el comando scope devuelve el nombre completamente calificado de la variable, por ejemplo, ::foo::bar::x.

Si el nombre no se reconoce como una variable, el comando scope devuelve un error.

Los nombres de variables ordinarios se refieren a variables en el espacio de nombres global. Un valor con ámbito captura un nombre de variable junto con su contexto de espacio de nombres de una manera que permite referenciarlo correctamente más tarde. Es necesario, por ejemplo, para agrupar nombres de variables cuando se utiliza un widget Tk dentro de un espacio de nombres:

namespace foo {
    private variable mode 1
    radiobutton .rb1 -text "Modo #1"         -variable [scope mode] -value 1
    pack .rb1
    radiobutton .rb2 -text "Modo #2"         -variable [scope mode] -value 2
    pack .rb2
}
Los radiobuttons .rb1 y .rb2 interactúan a través de la variable "mode" contenida en el espacio de nombres "foo". El comando scope garantiza esto devolviendo el nombre de variable completamente calificado ::foo::mode.

Nunca debes intentar crear tus propios nombres de variables con ámbito, incluso si crees que has melakukan la ingeniería inversa de la codificación de manera impecable. En su lugar, siempre debes usar el comando scope para generar el nombre de la variable dinámicamente. Luego, puedes pasar ese nombre a un widget o a cualquier otro fragmento de código en tu programa.
