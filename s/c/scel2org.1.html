CREATEPYMB(1) Manual de Comandos Generales CREATEPYMB(1)

NOMBRE

createPYMB, readPYBase, readPYMB, mb2org, scel2org - herramientas relacionadas con Pinyin de fcitx

SINOPSIS

createPYMB <ArchivoPinyin> <ArchivoFrase>

readPYBase [-b <ArchivoMB Pinyin>] [-h]

readPYMB [-f <ArchivoMB Frase>] [-s] [-h]

mb2org [-b <ArchivoMB Pinyin>] [-f <ArchivoMB Frase>] [-s] [-h]

scel2org [-o <Archivo de Frase>] [-h]

DESCRIPCIÓN

-b <ArchivoMB Pinyin>
Si no se especifica, leerá el pybase.mb predeterminado del sistema.
-f <ArchivoMB Frase>
Si no se especifica, leerá el ArchivoMBFrase predeterminado del usuario, que es ~/.config/fcitx/pyusrphrase.mb.
-s
Si se especifica, leerá PhraseMBFile en formato de sistema, de lo contrario lo leerá en formato de usuario.
-h
muestra la ayuda y sale
Archivo de Pinyin
El Archivo de Pinyin es un archivo con pinyin y un carácter por línea, separados por espacios. Un archivo disponible está en la fuente de fcitx, llamado gbkpy.org.
Archivo de Frase
El Archivo de Frase es un archivo con pinyin completo separado por ' y la frase correspondiente. El archivo de frase predeterminado de fcitx se puede descargar en http://fcitx.googlecode.com/files/pinyin.tar.gz.
Archivo MB de Pinyin
El Archivo MB de Pinyin es el formato binario del Archivo de Pinyin.
Archivo MB de Frase
El Archivo MB de Frase es el formato binario del Archivo de Pinyin, el archivo mb de frases históricas del usuario es ~/.config/fcitx/pyuserphrase.mb. Hay dos formatos diferentes, uno es el formato de sistema que solo puede ser generado por createPYMB, y el otro es el formato de usuario que solo puede ser generado al escribir con el IM Pinyin de fcitx.
La salida de createPYMB será pybase.mb, que es el Archivo MB de Pinyin, y pyphrase.mb, que es el Archivo MB de Frase.
La salida de mb2org, readPYBase y readPYMB será stdout. readPYBase y readPYMB están diseñados para generar más mensajes de depuración del Archivo MB de Pinyin y del Archivo MB de Frase. mb2org generará la salida en el formato del Archivo de Frase.
scel2org se utiliza para transformar el Archivo Scel de Sogou al Archivo de Frase de fcitx. La salida de scel2org será stdout si no se usa -o.
