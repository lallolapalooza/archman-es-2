Documentación de la función/subrutina

subroutine schksb (integer nsizes, integer, dimension( * ) nn, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, real, dimension( lda, * ) a, integer lda, real, dimension( * ) sd, real, dimension( * ) se, real, dimension( ldu, * ) u, integer ldu, real, dimension( * ) work, integer lwork, real, dimension( * ) result, integer info)

SCHKSB

Propósito:

!>
!> SCHKSB prueba la reducción de una matriz banda simétrica a forma tridiagonal,
!> utilizada con el problema de valores propios simétricos.
!>
!> SSBTRD factoriza una matriz banda simétrica A como U S U', donde ' significa
!> transpuesta, S es tridiagonal simétrica y U es ortogonal.
!> SSBTRD puede usar solo el triángulo inferior o solo el triángulo superior
!> de A; SCHKSB verifica ambos casos.
!>
!> Cuando se llama a SCHKSB, se especifican un número de tamaños de matriz (),
!> un número de anchos de banda () y un número de tipos de matriz. Por cada
!> tamaño (), cada ancho de banda () menor o igual a , y cada tipo de matriz,
!> se generará una matriz y se usará para probar la rutina de reducción
!> de bandas simétricas. Para cada matriz, se realizarán varias pruebas:
!>
!> (1)     | A - V S V' | / ( |A| n ulp )  calculado por SSBTRD con
!>                                         UPLO='U'
!>
!> (2)     | I - UU' | / ( n ulp )
!>
!> (3)     | A - V S V' | / ( |A| n ulp )  calculado por SSBTRD con
!>                                         UPLO='L'
!>
!> (4)     | I - UU' | / ( n ulp )
!>
!> Los  se especifican mediante un array NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo .
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>      1, ..., ULP y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1)
!> (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>      1, ..., ULP y signos aleatorios.
!> (5)  Una matriz diagonal con  entradas 1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento )
!> (7)  Igual que (4), pero multiplicada por SQRT( umbral de subdesbordamiento )
!>
!> (8)  Una matriz de la forma U' D U, donde U es ortogonal y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (9)  Una matriz de la forma U' D U, donde U es ortogonal y
!>      D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (10) Una matriz de la forma U' D U, donde U es ortogonal y
!>      D tiene entradas 1, ULP,..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicada por SQRT( umbral de subdesbordamiento )
!>
!> (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicada por SQRT( umbral de subdesbordamiento )
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          SCHKSB no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es un array INTEGER, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero serán omitidos. Los valores deben ser al menos
!>          cero.
!>

NWDTHS

!>          NWDTHS es INTEGER
!>          El número de anchos de banda a utilizar. Si es cero,
!>          SCHKSB no hace nada. Debe ser al menos cero.
!>

KK

!>          KK es un array INTEGER, dimension (NWDTHS)
!>          Un array que contiene los anchos de banda a utilizar para las
!>          matrices de banda. Los valores deben ser al menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SCHKSB
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar la matriz que esté en A. Esto solo es útil
!>          si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE..
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un array INTEGER, dimension (4)
!>          A la entrada, ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debe producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican a la salida y pueden usarse en la
!>          siguiente llamada a SCHKSB para continuar la misma secuencia de
!>          números aleatorios.
!>

THRESH

!>          THRESH es REAL
!>          Una prueba se contará como  si el , calculado como
!>          se describe arriba, excede THRESH. Tenga en cuenta que el error
!>          se escala para que sea O(1), por lo que THRESH debería ser un múltiplo
!>          razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          o del tamaño de la matriz. Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0.)
!>

A

!>          A es un array REAL, dimension
!>                            (LDA, max(NN))
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. Debe ser al menos 2 (¡no 1!)
!>          y al menos max( KK )+1.
!>

SD

!>          SD es un array REAL, dimension (max(NN))
!>          Se utiliza para almacenar la diagonal de la matriz tridiagonal calculada
!>          por SSBTRD.
!>

SE

!>          SE es un array REAL, dimension (max(NN))
!>          Se utiliza para almacenar los subdiagonales de la matriz tridiagonal
!>          calculada por SSBTRD.
!>

U

!>          U es un array REAL, dimension (LDU, max(NN))
!>          Se utiliza para almacenar la matriz ortogonal calculada por SSBTRD.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U. Debe ser al menos 1
!>          y al menos max( NN ).
!>

WORK

!>          WORK es un array REAL, dimension (LWORK)
!>

schksb.3.en

NAME

schksb - Schur decomposition check routine

SYNOPSIS

SUBROUTINE SCHKSB( JAKARTA, JERR, NP, NINFO, NTESTS, RESULT, INFO )

INTEGER JAKARTA, JERR, NP, NINFO, NTESTS, INFO

REAL RESULT( 4 )

Function/Subroutine Documentation

SCHKSB is a subroutine that checks the Schur decomposition routines in LAPACK.

The following is a description of the parameters:

JAKARTA

!>          JAKARTA is INTEGER
!>          The number of types of matrices to be tested.
!>          This is the number of columns in the array
!>          KTYPE, KMODE, and KMAGN.
!>

JERR

!>          JERR is INTEGER
!>          The JERR-th test is the first test to be performed.
!>          If JERR=0, then all tests are performed.
!>

NP

!>          NP is INTEGER
!>          The number of sizes of matrices to be tested.
!>          This is the number of rows in the array NN.
!>

NINFO

!>          NINFO is INTEGER
!>          The number of elements in the array INFO. NINFO must be at
!>          least NP.
!>

NTESTS

!>          NTESTS is INTEGER
!>          The number of tests performed or to be performed.
!>

LWORK

!>          LWORK is INTEGER
!>          The number of entries in WORK. This must be at least
!>          max( LDA+1, max(NN)+1 )*max(NN).
!>

RESULT

!>          RESULT is REAL array, dimension (4)
!>          The values computed by the tests described above.
!>          The values are currently limited to 1/ulp, to avoid
!>          overflow.
!>

INFO

!>          INFO is INTEGER
!>          If 0, then everything ran OK.
!>
!>-----------------------------------------------------------------------
!>
!>       Some Local Variables and Parameters:
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Real 0 and 1.
!>       MAXTYP          The number of types defined.
!>       NTEST           The number of tests performed, or which can
!>                       be performed so far, for the current matrix.
!>       NTESTT          The total number of tests performed so far.
!>       NMAX            Largest value in NN.
!>       NMATS           The number of matrices generated so far.
!>       NERRS           The number of tests which have exceeded THRESH
!>                       so far.
!>       COND, IMODE     Values to be passed to the matrix generators.
!>       ANORM           Norm of A; passed to matrix generators.
!>
!>       OVFL, UNFL      Overflow and underflow thresholds.
!>       ULP, ULPINV     Finest relative precision and its inverse.
!>       RTOVFL, RTUNFL  Square roots of the previous 2 values.
!>               The following four arrays decode JTYPE:
!>       KTYPE(j)        The general type (1-10) for type .
!>       KMODE(j)        The MODE value to be passed to the matrix
!>                       generator for type .
!>       KMAGN(j)        The order of magnitude ( O(1),
!>                       O(overflow^(1/2) ), O(underflow^(1/2) )
!>
