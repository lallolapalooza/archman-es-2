SCHKQR

Propósito:

!>
!> SCHKQR prueba SGEQRF, SORGQR y SORMQR.
!>

Parámetros

DOTYPE 
!>          DOTYPE es una matriz LOGICAL, dimension (NTYPES)
!>          Los tipos de matrices a usar para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se usan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se usa.
!>

NM

!>          NM es INTEGER
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es una matriz INTEGER, dimension (NM)
!>          Los valores de la dimensión de fila de la matriz M.
!>

NN

!>          NN es INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es una matriz INTEGER, dimension (NN)
!>          Los valores de la dimensión de columna de la matriz N.
!>

NNB

!>          NNB es INTEGER
!>          El número de valores de NB y NX contenidos en los
!>          vectores NBVAL y NXVAL. Los parámetros de bloqueo se usan
!>          en pares (NB,NX).
!>

NBVAL

!>          NBVAL es una matriz INTEGER, dimension (NNB)
!>          Los valores del tamaño del bloque NB.
!>

NXVAL

!>          NXVAL es una matriz INTEGER, dimension (NNB)
!>          Los valores del punto de cruce NX.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de vectores del lado derecho a generar para
!>          cada sistema lineal.
!>

THRESH

!>          THRESH es REAL
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para tener
!>          cada relación de prueba impresa, use THRESH = 0.
!>

TSTERR

!>          TSTERR es LOGICAL
!>          Indicador que señala si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es INTEGER
!>          El valor máximo permitido para M o N, usado para dimensionar
!>          las matrices de trabajo.
!>

A

!>          A es una matriz REAL, dimension (NMAX*NMAX)
!>

AF

!>          AF es una matriz REAL, dimension (NMAX*NMAX)
!>

AQ

!>          AQ es una matriz REAL, dimension (NMAX*NMAX)
!>

AR

!>          AR es una matriz REAL, dimension (NMAX*NMAX)
!>

AC

!>          AC es una matriz REAL, dimension (NMAX*NMAX)
!>

B

!>          B es una matriz REAL, dimension (NMAX*NRHS)
!>

X

!>          X es una matriz REAL, dimension (NMAX*NRHS)
!>

XACT

!>          XACT es una matriz REAL, dimension (NMAX*NRHS)
!>

TAU

!>          TAU es una matriz REAL, dimension (NMAX)
!>

WORK

!>          WORK es una matriz REAL, dimension (NMAX*NMAX)
!>

RWORK

!>          RWORK es una matriz REAL, dimension (NMAX)
!>

IWORK

!>          IWORK es una matriz INTEGER, dimension (NMAX)
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>
