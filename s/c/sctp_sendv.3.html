sctp_sendv(3)

Paquete: lksctp-tools

Licencias: GPL-2.0-or-later, LGPL-2.1-only

SCTP_SENDV(3) Linux SCTP_SENDV(3)

NOMBRE

sctp_sendv - Envía mensajes desde un socket SCTP de forma extensible.

SINOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_sendv(int sd, const struct iovec * iov, int iovcnt,
               struct sockaddr *addrs, int addrcnt, void * info,
               socklen_t infolen, unsigned int infotype, int flags);

DESCRIPCIÓN

sctp_sendv proporciona una forma extensible para que una aplicación comunique diferentes atributos de envío a la pila SCTP al enviar un mensaje. Hay tres tipos de atributos que se pueden usar para describir un mensaje a enviar. Son las estructuras sctp_sndinfo, sctp_prinfo y sctp_authinfo. La siguiente estructura, sctp_sendv_spa, se define para ser utilizada cuando se necesitan más de uno de los atributos anteriores para describir un mensaje a enviar.


struct sctp_sendv_spa {
uint32_t sendv_flags;
struct sctp_sndinfo sendv_sndinfo;
struct sctp_prinfo sendv_prinfo;
struct sctp_authinfo sendv_authinfo;
};

El campo sendv_flags contiene un OR a nivel de bits de SCTP_SEND_SNDINFO_VALID, SCTP_SEND_PRINFO_VALID y SCTP_SEND_AUTHINFO_VALID indicando si los campos sendv_sndinfo/sendv_prinfo/sendv_authinfo contienen información válida.

sd es el descriptor del socket. iov es el búfer de recopilación, los datos en el búfer se tratan como un único mensaje de usuario. iovcnt es el número de elementos en iov. addrs es una matriz de direcciones a utilizar para establecer una asociación o una única dirección a utilizar para enviar el mensaje, y se pasa NULL si el llamante no desea establecer una asociación ni enviar el mensaje a una dirección específica. addrcnt es el número de direcciones en la matriz addrs. info es un puntero al búfer que contiene el atributo asociado con el mensaje a enviar, y el tipo se indica mediante el parámetro info_type. infolen es la longitud de info, en bytes. infotype identifica el tipo de la información proporcionada en info, y los valores definidos actualmente son los siguientes:

SCTP_SENDV_NOINFO
No se proporciona información. El parámetro info es un puntero NULL y infolen es 0.
SCTP_SENDV_SNDINFO
El parámetro info apunta a una struct sctp_sndinfo.
SCTP_SENDV_PRINFO
El parámetro info apunta a una struct sctp_prinfo.
SCTP_SENDV_AUTHINFO
El parámetro info apunta a una struct sctp_authinfo.
SCTP_SENDV_SPA
El parámetro info apunta a una struct sctp_sendv_spa.

flags Las mismas banderas que se usan en las banderas de la llamada sendmsg() (por ejemplo, MSG_DONTROUTE).

VALOR DE RETORNO

En caso de éxito, sctp_sendv devuelve el número de bytes enviados o -1 si ocurrió un error.
