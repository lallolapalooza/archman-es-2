NOMBRE

schroot-setup - scripts de configuración de chroot de schroot

DESCRIPCIÓN

schroot utiliza scripts para configurar y luego limpiar el entorno chroot. El directorio /etc/schroot/setup.d contiene scripts que se ejecutan al crear y destruir un chroot. Varias variables de entorno se establecen mientras se ejecutan los scripts, lo que permite personalizar su comportamiento, dependiendo, por ejemplo, del tipo de chroot en uso.

Los scripts se ejecutan en orden de nombre, como los que ejecuta init(8), utilizando el mismo estilo de ejecución que run-parts(8).

Los scripts de configuración se invocan todos con dos opciones:

1
La acción a realizar.
Cuando se inicia una sesión por primera vez, el chroot se configura ejecutando los scripts en /etc/schroot/setup.d con la opción ‘setup-start’. Cuando la sesión finaliza, los scripts en /etc/schroot/setup.d se ejecutan en orden inverso con la opción ‘setup-stop’.
2
El estado del chroot.
Este es ‘ok’ si no hay problemas, o ‘fail’ si algo salió mal. Por ejemplo, ciertas acciones pueden omitirse en caso de fallo.

Tenga en cuenta que los scripts deben ser idempotentes. Deben ser idempotentes durante la fase ‘setup-stop’, ya que pueden ejecutarse más de una vez, por ejemplo, en caso de fallo.

ENTORNO

Variables generales

AUTH_USER
El nombre de usuario con el que se ejecutará el comando en el chroot.
CHROOT_NAME
El nombre del chroot. Tenga en cuenta que este es el nombre del chroot original antes de la creación de la sesión; probablemente quieras SESSION_ID.
LIBEXEC_DIR
El directorio bajo el cual se encuentran los programas auxiliares.
MOUNT_DIR
El directorio bajo el cual se montan los chroots que no son sistemas de archivos (por ejemplo, dispositivos de bloques y instantáneas LVM).
PID
El ID del proceso del proceso schroot.
PLATFORM
La plataforma del sistema operativo sobre la que se está ejecutando schroot. Esto se puede usar para introducir comportamiento específico de la plataforma en los scripts de configuración cuando sea necesario. Tenga en cuenta que las variables HOST son probablemente lo que se requiere. En el contexto de schroot, la plataforma es la configuración y el comportamiento soportados para una arquitectura dada, y puede ser idéntica entre diferentes arquitecturas.
SESSION_ID
El identificador de la sesión.
VERBOSE
Establecido en ‘quiet’ si solo se deben imprimir mensajes de error, ‘normal’ si también se pueden imprimir otros mensajes, y ‘verbose’ si se pueden imprimir todos los mensajes. Anteriormente llamado AUTH_VERBOSITY.
CHROOT_SESSION_CREATE
Establecido en ‘true’ si se creará una sesión, de lo contrario ‘false’.
CHROOT_SESSION_CLONE
Establecido en ‘true’ si se clonará una sesión, de lo contrario ‘false’.
CHROOT_SESSION_PURGE
Establecido en ‘true’ si se purgará una sesión, de lo contrario ‘false’.
CHROOT_SESSION_SOURCE
Establecido en ‘true’ si una sesión se creará a partir de un chroot de origen, de lo contrario ‘false’.
CHROOT_TYPE
El tipo de chroot. Esto es útil para restringir una tarea de configuración a tipos particulares de chroot (por ejemplo, solo dispositivos de bloques o instantáneas LVM).
CHROOT_NAME
El nombre del chroot. Esto es útil para restringir una tarea de configuración a un chroot en particular, o un conjunto de chroots.
CHROOT_ALIAS
El nombre del alias utilizado para seleccionar el chroot. Esto es útil para especializar una tarea de configuración basándose en uno de sus nombres alias alternativos, o el nombre chroot predeterminado. Por ejemplo, podría usarse para especificar fuentes adicionales en /etc/apt/sources.list, como un alias stable-security para un chroot estable, o un alias experimental para un chroot inestable.
CHROOT_DESCRIPTION
La descripción del chroot.
CHROOT_MOUNT_LOCATION
La ubicación donde montar el chroot. Se utiliza para la creación y el montaje del punto de montaje.
CHROOT_LOCATION
La ubicación del chroot dentro del punto de montaje. Esto permite la existencia de múltiples chroots en un solo sistema de archivos. Establecido para todos los tipos de chroot montables.
CHROOT_PATH
La ruta absoluta al chroot. Esto es típicamente CHROOT_MOUNT_LOCATION concatenado con CHROOT_LOCATION. Esta es la ruta que se debe usar para acceder a los chroots.

Variables de chroot simples y de directorio

Estos tipos de chroot utilizan solo variables generales.

Variables de archivo

CHROOT_FILE
El archivo que contiene los archivos del chroot.
CHROOT_FILE_REPACK
Establecido en ‘true’ para volver a empaquetar el chroot en un archivo de archivo al finalizar una sesión, de lo contrario ‘false’.

Variables de chroot montables

Estas variables solo se establecen para tipos de chroot directamente montables.

CHROOT_MOUNT_DEVICE
El dispositivo a montar que contiene el chroot.
CHROOT_MOUNT_OPTIONS
Opciones para pasar a mount(8).
CHROOT_LOCATION
La ubicación del chroot dentro del punto de montaje. Esto permite la existencia de múltiples chroots en un solo sistema de archivos.

Variables de unión de sistema de archivos

CHROOT_UNION_TYPE
Tipo de sistema de archivos de unión.
CHROOT_UNION_MOUNT_OPTIONS
Opciones de montaje del sistema de archivos de unión.
CHROOT_UNION_OVERLAY_DIRECTORY
Directorio de superposición del sistema de archivos de unión (grabable).
CHROOT_UNION_UNDERLAY_DIRECTORY
Directorio subyacente del sistema de archivos de unión (solo lectura).

NOMBRE

schroot-setup - scripts para la configuración de chroot

DESCRIPCIÓN

El paquete schroot incluye una colección de scripts que se pueden utilizar para configurar un chroot. Estos scripts se ejecutan en orden por el programa run-parts(8). La ejecución de los scripts se controla por el valor de la clave setup-sources en schroot.conf(5). Para la configuración por defecto, los scripts se encuentran en /etc/schroot/default/.

En el caso de que se utilice LVM, se puede configurar un LVM snapshot del volumen lógico original para ser montado. Por ejemplo, para un snapshot LVM este será el volumen lógico original.

variables de snapshot LVM

CHROOT_LVM_SNAPSHOT_NAME
Nombre del snapshot a pasar a lvcreate(8).
CHROOT_LVM_SNAPSHOT_DEVICE
El nombre del dispositivo snapshot LVM.
CHROOT_LVM_SNAPSHOT_OPTIONS
Opciones a pasar a lvcreate(8).

variables Personalizadas

Las claves personalizadas establecidas en schroot.conf se convertirán a mayúsculas y se establecerán en el entorno como se describe en schroot.conf(5).

ARCHIVOS

configuración del script de configuración

El directorio /etc/schroot/default contiene la configuración por defecto utilizada por los scripts de configuración.

config
Archivo de configuración principal leído por los scripts de configuración. El formato de este archivo se describe en schroot-script-config(5). Este es el valor por defecto para la clave script-config. Tenga en cuenta que anteriormente se llamaba /etc/schroot/script-defaults. Los siguientes archivos son referenciados por defecto:
copyfiles
Una lista de archivos a copiar al chroot desde el sistema host. Tenga en cuenta que anteriormente se llamaba /etc/schroot/copyfiles-defaults.
fstab
Un archivo en el formato descrito en fstab(5), utilizado para montar sistemas de archivos dentro del chroot. La ubicación de montaje es relativa a la raíz del chroot. Tenga en cuenta que anteriormente se llamaba /etc/schroot/mount-defaults.
nssdatabases
Bases de datos del sistema (como se describe en /etc/nsswitch.conf en sistemas GNU/Linux) a copiar al chroot desde el host. Tenga en cuenta que anteriormente se llamaba /etc/schroot/nssdatabases-defaults.

scripts de configuración

El directorio /etc/schroot/setup.d contiene los scripts de configuración del chroot.

00check
Imprime diagnósticos de depuración y realiza comprobaciones básicas de cordura.
05file
Descomprime, limpia y vuelve a empaquetar chroots basados en archivos.
05fsunion
Crea y elimina sistemas de archivos de unión.
05lvm
Crea y elimina snapshots LVM.
10mount
Monta y desmonta sistemas de archivos.
15binfmt
Configura el emulador de usuario QEMU utilizando binfmt-support. Esto permite utilizar un chroot para una arquitectura de CPU diferente de forma transparente, proporcionando una alternativa a la compilación cruzada o a la emulación de máquina completa.
15killprocs
Termina los procesos que aún se están ejecutando dentro del chroot al finalizar una sesión, lo que podría impedir el desmontaje de los sistemas de archivos y la limpieza de cualquier otro recurso.
20copyfiles
Copia archivos desde el sistema host al chroot. Configura la red copiando hosts y resolv.conf, por ejemplo.
20nssdatabases
Configura las bases de datos del sistema copiando passwd, shadow, group, etc. al chroot.
50chrootname
Establece el nombre del chroot (/etc/debian_chroot) en el chroot. Esto puede ser utilizado por el prompt de la shell para mostrar el chroot actual.
