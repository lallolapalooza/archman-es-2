subrutina schkhs (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, real, dimension( lda, * ) a, integer lda, real, dimension( lda, * ) h, real, dimension( lda, * ) t1, real, dimension( lda, * ) t2, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldu, * ) z, real, dimension( ldu, * ) uz, real, dimension( * ) wr1, real, dimension( * ) wi1, real, dimension( * ) wr2, real, dimension( * ) wi2, real, dimension( * ) wr3, real, dimension( * ) wi3, real, dimension( ldu, * ) evectl, real, dimension( ldu, * ) evectr, real, dimension( ldu, * ) evecty, real, dimension( ldu, * ) evectx, real, dimension( ldu, * ) uu, real, dimension( * ) tau, real, dimension( * ) work, integer nwork, integer, dimension( * ) iwork, logical, dimension( * ) select, real, dimension( 16 ) result, integer info)

SCHKHS

Propósito:

!>
!>    SCHKHS  verifica las rutinas del problema de valores propios no simétricos.
!>
!>            SGEHRD descompone A como  U H U' , donde ' significa transpuesta,
!>            H es de Hessenberg y U es una matriz ortogonal.
!>
!>            SORGHR genera la matriz ortogonal U.
!>
!>            SORMHR multiplica una matriz por la matriz ortogonal U.
!>
!>            SHSEQR descompone H como  Z T Z' , donde Z es ortogonal y
!>            T es , y el vector de valores propios W.
!>
!>            STREVC calcula las matrices de vectores propios izquierdos y derechos
!>            L y R para T.
!>
!>            SHSEIN calcula las matrices de vectores propios izquierdos y derechos
!>            Y y X para H, utilizando iteración inversa.
!>
!>            STREVC3 calcula las matrices de vectores propios izquierdos y derechos
!>            a partir de una matriz de Schur T y las retrotransforma con Z
!>            a matrices de vectores propios L y R para A. L y R son
!>            matrices GE.
!>
!>    Cuando se llama a SCHKHS, se especifican un número de tamaños de matriz () y un
!>    número de tipos de matriz. Para cada tamaño ()
!>    y cada tipo de matriz, se generará y utilizará una matriz
!>    para probar las rutinas de valores propios no simétricos. Para cada matriz, se realizarán 16
!>    pruebas:
!>
!>    (1)     | A - U H U**T | / ( |A| n ulp )
!>
!>    (2)     | I - UU**T | / ( n ulp )
!>
!>    (3)     | H - Z T Z**T | / ( |H| n ulp )
!>
!>    (4)     | I - ZZ**T | / ( n ulp )
!>
!>    (5)     | A - UZ H (UZ)**T | / ( |A| n ulp )
!>
!>    (6)     | I - UZ (UZ)**T | / ( n ulp )
!>
!>    (7)     | T(Z calculado) - T(Z no calculado) | / ( |T| ulp )
!>
!>    (8)     | W(Z calculado) - W(Z no calculado) | / ( |W| ulp )
!>
!>    (9)     | TR - RW | / ( |T| |R| ulp )
!>
!>    (10)    | L**H T - W**H L | / ( |T| |L| ulp )
!>
!>    (11)    | HX - XW | / ( |H| |X| ulp )
!>
!>    (12)    | Y**H H - W**H Y | / ( |H| |Y| ulp )
!>
!>    (13)    | AX - XW | / ( |A| |X| ulp )
!>
!>    (14)    | Y**H A - W**H Y | / ( |A| |Y| ulp )
!>
!>    (15)    | AR - RW | / ( |A| |R| ulp )
!>
!>    (16)    | LA - WL | / ( |A| |L| ulp )
!>
!>    Los   se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los   se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., se generará la matriz de tipo .
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1s en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP  y signos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP  y signos aleatorios.
!>    (6)  Una matriz diagonal con entradas  1, ULP, ..., ULP
!>         y signos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>    (8)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>    (9)  Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>         en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (10) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>         en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (11) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene entradas  1, ULP,..., ULP con signos aleatorios
!>         en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (12) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene valores propios reales o pares conjugados complejos elegidos aleatoriamente de ( ULP, 1 ) y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (13) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con signos aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (14) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con signos aleatorios en la diagonal y entradas
!>         O(1) aleatorias en el triángulo superior.
!>
!>    (15) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas  1, ULP,..., ULP con signos aleatorios
!>         en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (16) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene valores propios reales o pares conjugados complejos
!>         elegidos aleatoriamente de ( ULP, 1 ) y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (17) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )
!>    (18) Igual que (16), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de (-1,1).
!>    (20) Igual que (19), pero multiplicado por SQRT( umbral de desbordamiento )
!>    (21) Igual que (19), pero multiplicado por SQRT( umbral de subdesbordamiento )
!> 
!>  NSIZES - INTEGER
!>           El número de tamaños de matrices a utilizar. Si es cero,
!>           SCHKHS no hace nada. Debe ser al menos cero.
!>           No modificado.
!>
!>  NN     - INTEGER array, dimension (NSIZES)
!>           Un array que contiene los tamaños a utilizar para las matrices.
!>           Los valores cero se omitirán. Los valores deben ser al menos
!>           cero.
!>           No modificado.
!>
!>  NTYPES - INTEGER
!>           El número de elementos en DOTYPE.

Esto solo es útil si !> DOTYPE(1:MAXTYP) es .FALSE. y DOTYPE(MAXTYP+1) es .TRUE. . !> No modificado. !> !> DOTYPE - Arreglo LOGICAL, de dimensión (NTYPES) !> Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará !> una matriz de ese tamaño y de tipo j. Los elementos del arreglo deben estar entre 0 y 4095; !> si no, se reducirán módulo 4096. Además, ISEED(4) debe ser impar. !> El generador de números aleatorios utiliza una secuencia congruencial !> lineal limitada a enteros pequeños y, por lo tanto, debería producir !> números aleatorios independientes de la máquina. Los valores de ISEED !> se cambian a la salida y pueden usarse en la siguiente llamada a !> SCHKHS para continuar la misma secuencia de números aleatorios. !> Modificado. !> !> THRESH - REAL !> Una prueba se considerará si, calculada como !> se describe anteriormente, excede THRESH. Tenga en cuenta que el error !> se escala para que sea O(1), por lo que THRESH debería ser un múltiplo !> razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular, !> no debe depender de la precisión (simple o doble) !> o del tamaño de la matriz. Debe ser como mínimo cero. !> No modificado. !> !> NOUNIT - INTEGER !> El número de unidad FORTRAN para imprimir mensajes de error !> (por ejemplo, si una rutina devuelve IINFO distinto de 0). !> No modificado. !> !> A - Arreglo REAL, de dimensión (LDA,max(NN)) !> Se utiliza para mantener la matriz cuyos valores propios se van a !> calcular. A la salida, A contiene la última matriz utilizada. !> Modificado. !> !> LDA - INTEGER !> La dimensión principal de A, H, T1 y T2. Debe ser !> como mínimo 1 y como mínimo max( NN ). !> No modificado. !> !> H - Arreglo REAL, de dimensión (LDA,max(NN)) !> La matriz de Hessenberg superior calculada por SGEHRD. A la salida, !> H contiene la forma de Hessenberg de la matriz en A. !> Modificado. !> !> T1 - Arreglo REAL, de dimensión (LDA,max(NN)) !> La matriz de Schur (=) calculada por SHSEQR !> si se calcula Z. A la salida, T1 contiene la forma de Schur de !> la matriz en A. !> Modificado. !> !> T2 - Arreglo REAL, de dimensión (LDA,max(NN)) !> La matriz de Schur calculada por SHSEQR cuando Z no se calcula. !> Debería ser idéntica a T1. !> Modificado. !> !> LDU - INTEGER !> La dimensión principal de U, Z, UZ y UU. Para pares conjugados complejos, la parte real !> se almacena en una fila y la parte imaginaria en la siguiente. !> Modificado. !> !> EVECTR - Arreglo REAL, de dimensión (LDU,max(NN)) !> La matriz de vectores propios derechos (triangular superior) para la !> matriz en T1. Para pares conjugados complejos, la parte real !> se almacena en una columna y la parte imaginaria en la siguiente. !> Modificado. !> !> EVECTY - Arreglo REAL, de dimensión (LDU,max(NN)) !> La matriz de vectores propios izquierdos para la !> matriz en H. Para pares conjugados complejos, la parte real !> se almacena en una fila y la parte imaginaria en la siguiente. !> Modificado. !> !> EVECTX - Arreglo REAL, de dimensión (LDU,max(NN)) !> La matriz de vectores propios derechos para la !> matriz en H. Para pares conjugados complejos, la parte real !> se almacena en una columna y la parte imaginaria en la siguiente. !> Modificado. !> !> UU - Arreglo REAL, de dimensión (LDU,max(NN)) !> Detalles de la matriz ortogonal calculada por SGEHRD. !> Modificado. !> !> TAU - Arreglo REAL, de dimensión(max(NN)) !> Detalles adicionales de la matriz ortogonal calculada por SGEHRD. !> Modificado. !> !> WORK - Arreglo REAL, de dimensión (NWORK) !> Espacio de trabajo. !> Modificado. !> !> NWORK - INTEGER !> El número de entradas en WORK.
