Documentación de la Función/Subrutina

real(wp) función scnrm2 (integer n, complex(wp), dimension(*) x, integer incx)

SCNRM2

Propósito:

!>
!> SCNRM2 devuelve la norma euclidiana de un vector a través del nombre de la función,
!> de modo que
!>
!>    SCNRM2 := sqrt( x**H*x )
!>

Parámetros

N 
!>          N es INTEGER
!>         número de elementos en el/los vector(es) de entrada
!>

X

!>          X es array COMPLEX, dimension (N)
!>         vector complejo con N elementos
!>

INCX

!>          INCX es INTEGER, espaciado de almacenamiento entre elementos de X
!>          Si INCX > 0, X(1+(i-1)*INCX) = x(i) para 1 <= i <= n
!>          Si INCX < 0, X(1-(n-i)*INCX) = x(i) para 1 <= i <= n
!>          Si INCX = 0, x no es un vector, por lo que no es necesario llamar
!>          a esta subrutina. Si la llama de todos modos, contará x(1)
!>          en la norma del vector N veces.
!>
