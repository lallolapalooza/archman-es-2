Parámetros

DOTYPE 
!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Los tipos de matrices a utilizar para las pruebas. Matrices de tipo j
!>          (para 1 <= j <= NTYPES) se utilizan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se utiliza.
!>

NM

!>          NM es un INTEGER
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array INTEGER, de dimensión (NM)
!>          Los valores de la dimensión de fila M de la matriz.
!>

NN

!>          NN es un INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, de dimensión (NN)
!>          Los valores de la dimensión de columna N de la matriz.
!>

NNB

!>          NNB es un INTEGER
!>          El número de valores de NB y NX contenidos en los
!>          vectores NBVAL y NXVAL. Los parámetros de bloqueo se utilizan
!>          en pares (NB,NX).
!>

NBVAL

!>          NBVAL es un array INTEGER, de dimensión (NNB)
!>          Los valores del tamaño de bloque NB.
!>

NXVAL

!>          NXVAL es un array INTEGER, de dimensión (NNB)
!>          Los valores del punto de cruce NX.
!>

THRESH

!>          THRESH es REAL
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          se imprima cada relación de prueba, utilice THRESH = 0.
!>

A

!>          A es un array REAL, de dimensión (MMAX*NMAX)
!>          donde MMAX es el valor máximo de M en MVAL y NMAX es el
!>          valor máximo de N en NVAL.
!>

COPYA

!>          COPYA es un array REAL, de dimensión (MMAX*NMAX)
!>

S

!>          S es un array REAL, de dimensión
!>                      (min(MMAX,NMAX))
!>

TAU

!>          TAU es un array REAL, de dimensión (MMAX)
!>

WORK

!>          WORK es un array REAL, de dimensión
!>                      (MMAX*NMAX + 4*NMAX + MMAX)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (2*NMAX)
!>

NOUT

!>          NOUT es un INTEGER
!>          El número de unidad para la salida.
!>
