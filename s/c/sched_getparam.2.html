sched_setparam(2) Manual de llamadas al sistema sched_setparam(2)

NOMBRE

sched_setparam, sched_getparam - establecer y obtener parámetros de planificación

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sched.h>
int sched_setparam(pid_t pid, const struct sched_param *param);
int sched_getparam(pid_t pid, struct sched_param *param);
struct sched_param {
    ...
    int sched_priority;
    ...
};

DESCRIPCIÓN

sched_setparam() establece los parámetros de planificación asociados con la política de planificación para el hilo cuyo ID de hilo se especifica en pid. Si pid es cero, entonces se establecen los parámetros del hilo que realiza la llamada.

La interpretación del argumento param depende de la política de planificación del hilo identificado por pid. Consulte sched(7) para una descripción de las políticas de planificación admitidas en Linux.

sched_getparam() recupera los parámetros de planificación para el hilo identificado por pid. Si pid es cero, entonces se recuperan los parámetros del hilo que realiza la llamada.

sched_setparam() comprueba la validez de param para la política de planificación del hilo. El valor param->sched_priority debe estar dentro del rango dado por sched_get_priority_min(2) y sched_get_priority_max(2).

Para una discusión de los privilegios y límites de recursos relacionados con la prioridad y la política de planificación, consulte sched(7).

Los sistemas POSIX en los que están disponibles sched_setparam() y sched_getparam() definen _POSIX_PRIORITY_SCHEDULING en <unistd.h>.

VALOR DE RETORNO

En caso de éxito, sched_setparam() y sched_getparam() devuelven 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
Argumentos no válidos: param es NULL o pid es negativo.
EINVAL
(sched_setparam()) El argumento param no tiene sentido para la política de planificación actual.
EPERM
(sched_setparam()) El llamador no tiene los privilegios adecuados (Linux: no tiene la capacidad CAP_SYS_NICE).
ESRCH
No se pudo encontrar el hilo cuyo ID es pid.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.
