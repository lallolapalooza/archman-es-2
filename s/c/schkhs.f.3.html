subroutine schkhs (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, real, dimension( lda, * ) a, integer lda, real, dimension( lda, * ) h, real, dimension( lda, * ) t1, real, dimension( lda, * ) t2, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldu, * ) z, real, dimension( ldu, * ) uz, real, dimension( * ) wr1, real, dimension( * ) wi1, real, dimension( * ) wr2, real, dimension( * ) wi2, real, dimension( * ) wr3, real, dimension( * ) wi3, real, dimension( ldu, * ) evectl, real, dimension( ldu, * ) evectr, real, dimension( ldu, * ) evecty, real, dimension( ldu, * ) evectx, real, dimension( ldu, * ) uu, real, dimension( * ) tau, real, dimension( * ) work, integer nwork, integer, dimension( * ) iwork, logical, dimension( * ) select, real, dimension( 16 ) result, integer info)

SCHKHS

Propósito:

!>
!>    SCHKHS  verifica las rutinas del problema de valores propios no simétricos.
!>
!>            SGEHRD factoriza A como  U H U' , donde ' significa transpuesta,
!>            H es de Hessenberg, y U es una matriz ortogonal.
!>
!>            SORGHR genera la matriz ortogonal U.
!>
!>            SORMHR multiplica una matriz por la matriz ortogonal U.
!>
!>            SHSEQR factoriza H como  Z T Z' , donde Z es ortogonal y
!>            T es , y el vector de valores propios W.
!>
!>            STREVC calcula las matrices de vectores propios izquierdos y derechos
!>            L y R para T.
!>
!>            SHSEIN calcula las matrices de vectores propios izquierdos y derechos
!>            Y y X para H, usando iteración inversa.
!>
!>            STREVC3 calcula matrices de vectores propios izquierdos y derechos
!>            a partir de una matriz de Schur T y las retrotransforma con Z
!>            a matrices de vectores propios L y R para A. L y R son
!>            matrices GE.
!>
!>    Cuando se llama a SCHKHS, se especifica un número de tamaños de matriz  () y un
!>    número de tipos de matriz. Para cada tamaño ()
!>    y cada tipo de matriz, se generará y utilizará una matriz
!>    para probar las rutinas de valores propios no simétricos. Para cada matriz, se realizarán 16
!>    pruebas:
!>
!>    (1)     | A - U H U**T | / ( |A| n ulp )
!>
!>    (2)     | I - UU**T | / ( n ulp )
!>
!>    (3)     | H - Z T Z**T | / ( |H| n ulp )
!>
!>    (4)     | I - ZZ**T | / ( n ulp )
!>
!>    (5)     | A - UZ H (UZ)**T | / ( |A| n ulp )
!>
!>    (6)     | I - UZ (UZ)**T | / ( n ulp )
!>
!>    (7)     | T(Z calculado) - T(Z no calculado) | / ( |T| ulp )
!>
!>    (8)     | W(Z calculado) - W(Z no calculado) | / ( |W| ulp )
!>
!>    (9)     | TR - RW | / ( |T| |R| ulp )
!>
!>    (10)    | L**H T - W**H L | / ( |T| |L| ulp )
!>
!>    (11)    | HX - XW | / ( |H| |X| ulp )
!>
!>    (12)    | Y**H H - W**H Y | / ( |H| |Y| ulp )
!>
!>    (13)    | AX - XW | / ( |A| |X| ulp )
!>
!>    (14)    | Y**H A - W**H Y | / ( |A| |Y| ulp )
!>
!>    (15)    | AR - RW | / ( |A| |R| ulp )
!>
!>    (16)    | LA - WL | / ( |A| |L| ulp )
!>
!>    Los  se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo .
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1 en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP  y signos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP  y signos aleatorios.
!>    (6)  Una matriz diagonal con entradas  1, ULP, ..., ULP
!>         y signos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>    (8)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>    (9)  Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>         en la diagonal y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (10) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>         en la diagonal y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (11) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene entradas  1, ULP,..., ULP con signos aleatorios
!>         en la diagonal y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (12) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene valores propios reales o de pares conjugados elegidos aleatoriamente de ( ULP, 1 ) y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (13) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con signos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (14) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con signos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (15) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas  1, ULP,..., ULP con signos aleatorios
!>         en la diagonal y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (16) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene valores propios reales o de pares conjugados elegidos aleatoriamente de ( ULP, 1 ) y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (17) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )
!>    (18) Igual que (16), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de (-1,1).
!>    (20) Igual que (19), pero multiplicado por SQRT( umbral de desbordamiento )
!>    (21) Igual que (19), pero multiplicado por SQRT( umbral de subdesbordamiento )
!> 
!>  NSIZES - INTEGER
!>           El número de tamaños de matrices a usar. Si es cero,
!>           SCHKHS no hace nada. Debe ser como mínimo cero.
!>           No modificado.
!>
!>  NN     - INTEGER array, dimension (NSIZES)
!>           Un array que contiene los tamaños a usar para las matrices.
!>           Los valores cero se omitirán. Los valores deben ser como mínimo
!>           cero.
!>           No modificado.
!>
!>  NTYPES - INTEGER
!>           El número de elementos en DOTYPE.
Si es cero, SCHKHS !> no hace nada. Debe ser al menos cero. Si es MAXTYP+1 !> y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1, !> que consiste en usar la matriz que esté en A. Esto !> solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y !> DOTYPE(MAXTYP+1) es .TRUE. . !> No modificado. !> !> DOTYPE - Array LOGICAL, dimensión (NTYPES) !> Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se !> generará una matriz de ese tamaño y de tipo j. !> Si NTYPES es menor que el número máximo de tipos !> definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 hasta !> MAXTYP no se generarán. Si NTYPES es mayor !> que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES) !> se ignorarán. !> No modificado. !> !> ISEED - Array INTEGER, dimensión (4) !> A la entrada ISEED especifica la semilla del generador de números !> aleatorios. Los elementos del array deben estar entre 0 y 4095; !> si no, se reducirán módulo 4096. Además, ISEED(4) debe !> ser impar. El generador de números aleatorios utiliza una secuencia !> congruencial lineal limitada a enteros pequeños y, por lo tanto, !> debería producir números aleatorios independientes de la máquina. Los !> valores de ISEED se cambian a la salida y pueden usarse en la !> siguiente llamada a SCHKHS para continuar la misma secuencia de números !> aleatorios. !> Modificado. !> !> THRESH - REAL !> Una prueba se considerará como si el , calculado como !> se describe anteriormente, excede THRESH. Tenga en cuenta que el error !> está escalado para ser O(1), por lo que THRESH debe ser un múltiplo !> razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular, !> no debe depender de la precisión (simple vs. doble) !> o del tamaño de la matriz. Debe ser al menos cero. !> No modificado. !> !> NOUNIT - INTEGER !> El número de unidad FORTRAN para imprimir mensajes de error !> (por ejemplo, si una rutina devuelve IINFO distinto de 0). !> No modificado. !> !> A - Array REAL, dimensión (LDA,max(NN)) !> Se utiliza para almacenar la matriz cuyos valores propios se van a !> calcular. A la salida, A contiene la última matriz utilizada. !> Modificado. !> !> LDA - INTEGER !> La dimensión principal de A, H, T1 y T2. Debe ser !> al menos 1 y al menos max( NN ). !> No modificado. !> !> H - Array REAL, dimensión (LDA,max(NN)) !> La matriz de Hessenberg superior calculada por SGEHRD. A la salida, !> H contiene la forma de Hessenberg de la matriz en A. !> Modificado. !> !> T1 - Array REAL, dimensión (LDA,max(NN)) !> La matriz de Schur (=) calculada por SHSEQR !> si se calcula Z. A la salida, T1 contiene la forma de Schur de !> la matriz en A. !> Modificado. !> !> T2 - Array REAL, dimensión (LDA,max(NN)) !> La matriz de Schur calculada por SHSEQR cuando Z no se calcula. !> Debería ser idéntica a T1. !> Modificado. !> !> LDU - INTEGER !> La dimensión principal de U, Z, UZ y UU. Debe ser !> al menos 1 y al menos max( NN ). !> No modificado. !> !> U - Array REAL, dimensión (LDU,max(NN)) !> La matriz ortogonal calculada por SGEHRD. !> Modificado. !> !> Z - Array REAL, dimensión (LDU,max(NN)) !> La matriz ortogonal calculada por SHSEQR. !> Modificado. !> !> UZ - Array REAL, dimensión (LDU,max(NN)) !> El producto de U por Z. !> Modificado. !> !> WR1 - Array REAL, dimensión (max(NN)) !> WI1 - Array REAL, dimensión (max(NN)) !> Las partes real e imaginaria de los valores propios de A, !> calculadas cuando se calcula Z. !> A la salida, WR1 + WI1*i son los valores propios de la matriz en A. !> Modificado. !> !> WR2 - Array REAL, dimensión (max(NN)) !> WI2 - Array REAL, dimensión (max(NN)) !> Las partes real e imaginaria de los valores propios de A, !> calculadas cuando se calcula T pero no Z. !> A la salida, WR2 + WI2*i son los valores propios de la matriz en A. !> Modificado. !> !> WR3 - Array REAL, dimensión (max(NN)) !> WI3 - Array REAL, dimensión (max(NN)) !> Similar a WR1, WI1, estos arrays contienen los valores propios de A, !> pero calculados cuando SHSEQR solo calcula los !> valores propios, es decir, no los vectores de Schur ni más de !> la forma de Schur de lo necesario para calcular los !> valores propios. !> Modificado. !> !> EVECTL - Array REAL, dimensión (LDU,max(NN)) !> La matriz de vectores propios izquierdos (triangular superior) para la !> matriz en T1. Para pares conjugados complejos, la parte real !> se almacena en una fila y la parte imaginaria en la siguiente. !> Modificado. !> !> EVECTR - Array REAL, dimensión (LDU,max(NN)) !> La matriz de vectores propios derechos (triangular superior) para la !> matriz en T1. Para pares conjugados complejos, la parte real !> se almacena en una columna y la parte imaginaria en la siguiente. !> Modificado. !> !> EVECTY - Array REAL, dimensión (LDU,max(NN)) !> La matriz de vectores propios izquierdos para la !> matriz en H. Para pares conjugados complejos, la parte real !> se almacena en una fila y la parte imaginaria en la siguiente. !> Modificado. !> !> EVECTX - Array REAL, dimensión (LDU,max(NN)) !> La matriz de vectores propios derechos para la !> matriz en H. Para pares conjugados complejos, la parte real !> se almacena en una columna y la parte imaginaria en la siguiente. !> Modificado. !> !> UU - Array REAL, dimensión (LDU,max(NN)) !> Detalles de la matriz ortogonal calculada por SGEHRD. !> Modificado. !> !> TAU - Array REAL, dimensión(max(NN)) !> Detalles adicionales de la matriz ortogonal calculada por SGEHRD. !> Modificado. !> !> WORK - Array REAL, dimensión (NWORK) !> Espacio de trabajo. !> Modificado. !> !> NWORK - INTEGER !> El número de entradas en WORK. NWORK >= 4*NN(j)*NN(j) + 2. !> !> IWORK - Array INTEGER, dimensión (max(NN)) !> Espacio de trabajo. !> Modificado. !> !> SELECT - Array LOGICAL, dimensión (max(NN)) !> Espacio de trabajo. !> Modificado. !> !> RESULT - Array REAL, dimensión (16) !> Los valores calculados por las catorce pruebas descritas anteriormente. !> Los valores están actualmente limitados a 1/ulp, para evitar !> desbordamiento. !> Modificado. !> !> INFO - INTEGER !> Si es 0, todo se ejecutó correctamente. !> -1: NSIZES < 0 !> -2: Algún NN(j) < 0 !> -3: NTYPES < 0 !> -6: THRESH < 0 !> -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ). !> -14: LDU < 1 o LDU < NMAX. !> -28: NWORK demasiado pequeño. !> Si SLATMR, SLATMS o SLATME devuelven un código de error, el !> valor absoluto de este se devuelve. !> Si es 1, SHSEQR no pudo encontrar todos los desplazamientos. !> Si es 2, el código EISPACK (para bloques pequeños) falló. !> Si es >2, no fueron suficientes 30*N iteraciones para encontrar un !> valor propio o para descomponer el problema. !> Modificado. !> !>----------------------------------------------------------------------- !> !> Algunas Variables Locales y Parámetros: !> ---- ----- --------- --- ---------- !> !> ZERO, ONE Reales 0 y 1. !> MAXTYP El número de tipos definidos. !> MTEST El número de pruebas definidas: se debe tener cuidado !> de que (1) el tamaño de RESULT, (2) el número de !> pruebas realizadas, y (3) MTEST coincidan. !> NTEST El número de pruebas realizadas en esta matriz !> hasta ahora. Debe ser menor que MTEST, y !> igual a él en la última prueba. Será menor !> si alguna de las rutinas probadas indica !> que no pudo calcular las matrices que !> serían probadas. !> NMAX Valor más grande en NN. !> NMATS El número de matrices generadas hasta ahora. !> NERRS El número de pruebas que han excedido THRESH !> hasta ahora (calculado por SLAFTS). !> COND, CONDS, !> IMODE Valores a pasar a los generadores de matrices. !> ANORM Norma de A; pasada a los generadores de matrices. !> !> OVFL, UNFL Umbrales de desbordamiento y subdesbordamiento. !> ULP, ULPINV Precisión relativa más fina y su inversa. !> RTOVFL, RTUNFL, !> RTULP, RTULPI Raíces cuadradas de los 4 valores anteriores. !> !> Los siguientes cuatro arrays decodifican JTYPE: !> KTYPE(j) El tipo general (1-10) para el tipo . !> KMODE(j) El valor MODE a pasar al generador de matrices para el tipo . !> KMAGN(j) El orden de magnitud ( O(1), !> O(overflow^(1/2) ), O(underflow^(1/2) ) !!> KCONDS(j) Selecciona si CONDS debe ser 1 o !> 1/sqrt(ulp). (0 significa irrelevante.) !>
