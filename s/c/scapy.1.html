SCAPY(1) Manual de Comandos Generales SCAPY(1)

NOMBRE

scapy - Herramienta interactiva de manipulación de paquetes

SINOPSIS

scapy [opciones]

DESCRIPCIÓN

Esta página del manual documenta brevemente la herramienta Scapy.

Scapy es una potente herramienta interactiva de manipulación de paquetes, generador de paquetes, escáner de red, descubrimiento de red, analizador de paquetes, etc. Actualmente puede reemplazar a hping, partes de nmap, arpspoof, arp-sk, arping, tcpdump, tshark, p0f, ...

Scapy utiliza el intérprete de Python como tablero de comandos. Esto significa que puedes usar directamente el lenguaje Python (asignar variables, usar bucles, definir funciones, etc.). Si le das un archivo como parámetro al ejecutar Scapy, tu sesión (variables, funciones, instancias, ...) se guardará al salir del intérprete y se restaurará la próxima vez que inicies Scapy.

La idea es simple. Este tipo de herramientas hacen dos cosas: enviar paquetes y recibir respuestas. Eso es lo que hace Scapy: defines un conjunto de paquetes, los envía, recibe respuestas, empareja solicitudes con respuestas y devuelve una lista de parejas de paquetes (solicitud, respuesta) y una lista de paquetes no emparejados. Esto tiene la gran ventaja sobre herramientas como nmap o hping de que una respuesta no se reduce a (abierto/cerrado/filtrado), sino que es el paquete completo.

Sobre esto se pueden construir funciones de nivel superior, por ejemplo, una que haga traceroutes y dé como resultado solo el TTL inicial de la solicitud y la IP de origen de la respuesta. Una que haga ping a una red completa y devuelva la lista de máquinas que responden. Una que haga un escaneo de puertos y devuelva un informe LaTeX.

OPCIONES

Las opciones para Scapy son:

-h
muestra la ayuda
-H
modo sin encabezado, también reduce la verbosidad.
-d
aumenta la verbosidad del registro. Se puede usar varias veces.
-s ARCHIVO
usa ARCHIVO para guardar/cargar valores de sesión (variables, funciones, instancias, ...)
-p ARCHIVO_PREARRANQUE
usa ARCHIVO_PREARRANQUE en lugar de $HOME/.config/scapy/prestart.py como archivo de pre-arranque
-P
no ejecuta el archivo de pre-arranque
-c ARCHIVO_ARRANQUE
usa ARCHIVO_ARRANQUE en lugar de $HOME/.config/scapy/startup.py como archivo de arranque
-C
no ejecuta el archivo de arranque

COMANDOS

Solo se enumeran aquí los comandos vitales para empezar por el momento.

ls()
lista las capas de protocolo compatibles. Si se da una capa de protocolo como parámetro, lista sus campos y tipos de campos. Si se da una cadena como parámetro, se utiliza para filtrar las capas.
lsc()
lista los comandos principales de usuario de scapy.
conf
este objeto contiene la configuración.

ARCHIVOS

$HOME/.config/scapy/prestart.py Este archivo se ejecuta antes de que se cargue el núcleo de Scapy. Solo el objeto conf está disponible. Este archivo se puede utilizar para configurar la CLI, configurar parámetros como la lista conf.load_layers para elegir qué capas se cargarán, o cambiar el nivel de registro (por ejemplo):

conf.interactive_shell = "bpython"
log_loading.setLevel(logging.WARNING)
conf.load_layers.remove("bluetooth")
conf.load_layers.append("new_layer")

$HOME/.config/scapy/startup.py Este archivo se ejecuta después de que se cargue Scapy. Se puede utilizar para configurar más comportamientos de Scapy, como anular el registro de capas:

conf.prog.pdfreader = "xpdf"
split_layers(UDP,DNS)

EJEMPLOS

Hay ejemplos más detallados en la documentación en https://scapy.readthedocs.io/. Simplemente ejecute scapy y pruebe los siguientes comandos en el intérprete.

Prueba la robustez de una pila de red con paquetes inválidos:

sr(IP(dst="172.16.1.1", ihl=2, options=["verb$2"], version=3)/ICMP(), timeout=2)

Análisis y captura de paquetes (con un filtro bpf o salida tipo tshark):

a=sniff(filter="tcp port 110")
a=sniff(prn = lambda x: x.show)

Reemisión de paquetes capturados:

a=sniff(filter="tcp port 110")
sendp(a)

Reemisión de paquetes de un archivo pcap:

sendp(rdpcap("file.cap"))

Traceroute TCP manual:

sr(IP(dst="www.google.com", ttl=(1,30))/TCP(seq=RandInt(), sport=RandShort(), dport=dport)

Escaneo de protocolos:

sr(IP(dst="172.16.1.28", proto=(1,254)))

Ping ARP:

srp(Ether(dst="ff:ff:ff:ff:ff:ff")/ARP(pdst="172.16.1.1/24"))

Escaneo ACK:

sr(IP(dst="172.16.1.28")/TCP(dport=(1,1024), flags="A"))

Identificación de sistema operativo pasiva:

sniff(prn=prnp0f)

Identificación de sistema operativo activa:

nmap_fp("172.16.1.232")

Envenenamiento de caché ARP:

sendp(Ether(dst=tmac)/ARP(op="who-has", psrc=victim, pdst=target))

Informes:

report_ports("192.168.2.34", (20,30))

ERRORES

No proporciona la IP de origen correcta para rutas que utilizan alias de interfaz.

Puede perder paquetes bajo carga pesada. Esto es una restricción del propio python

El guardado de sesiones está limitado por la capacidad de Python para serializar objetos. Como consecuencia, las funciones lambda y los generadores no se pueden guardar, lo que reduce seriamente la utilidad de esta característica.

Los filtros BPF no funcionan en interfaces punto a punto.
