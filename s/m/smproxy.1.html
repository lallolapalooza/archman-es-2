NOMBRE

smproxy - Proxy del gestor de sesiones

SINOPSIS

smproxy [-clientId id] [-restore archivoGuardado] [-version]

OPCIONES

-clientId id
Especifica el ID de sesión utilizado por smproxy en la sesión anterior.
-restore archivoGuardado
Especifica el archivo utilizado por smproxy para guardar el estado en la sesión anterior.
-version
Imprime la versión del programa y sale.

DESCRIPCIÓN

smproxy permite que las aplicaciones X que no admiten la gestión de sesiones X11R6 participen en una sesión X11R6.

Para que smproxy actúe como proxy para una aplicación X, debe cumplirse una de las siguientes condiciones:

–
La aplicación mapea una ventana de nivel superior que contiene la propiedad WM_CLIENT_LEADER. Esta propiedad proporciona un puntero a la ventana líder del cliente que contiene las propiedades WM_CLASS, WM_NAME, WM_COMMAND y WM_CLIENT_MACHINE.

o

–
La aplicación mapea una ventana de nivel superior que no contiene la propiedad WM_CLIENT_LEADER. Sin embargo, esta ventana de nivel superior contiene las propiedades WM_CLASS, WM_NAME, WM_COMMAND y WM_CLIENT_MACHINE.

Una aplicación que admita el protocolo WM_SAVE_YOURSELF recibirá un mensaje de cliente WM_SAVE_YOURSELF cada vez que el gestor de sesiones emita un punto de control o un apagado. Esto permite a la aplicación guardar su estado. Si una aplicación no admite el protocolo WM_SAVE_YOURSELF, el proxy proporcionará suficiente información al gestor de sesiones para reiniciar la aplicación (utilizando WM_COMMAND), pero no se restaurará ningún estado.
