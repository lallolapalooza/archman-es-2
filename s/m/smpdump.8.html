smpdump(8) Diagnósticos de Open IB smpdump(8)

Nombre

smpdump - volcar atributos de gestión de subred InfiniBand

SINÓPSIS

smpdump [opciones] <dlid|dr_path> <atributo> [modificador_atributo]

DESCRIPCIÓN

smpdump es una utilidad SMP de propósito general que obtiene atributos SM de una SMA especificada. El resultado se vuelca en hexadecimal por defecto.

OPCIONES

dlid|drpath
LID o ruta DR a SMA
atributo
ID de atributo IBA para el atributo SM
modificador_atributo
Modificador IBA para el atributo SM
-s, --string
Imprimir cadenas en el paquete si es posible

Banderas de Direccionamiento

-D, --Direct La dirección especificada es una ruta dirigida

Ejemplos:
   [opciones] -D [opciones] "0"          # puerto propio
   [opciones] -D [opciones] "0,1,2,1,4"  # salida por el puerto 1, luego 2, ...
   (Nota que el segundo número en la ruta especificada debe coincidir con el puerto
   que se está utilizando. Esto se puede especificar usando la bandera de selección de puerto '-P' o el
   puerto encontrado a través del proceso de selección automática.)

-L, --Lid La dirección especificada es un LID

Banderas de Selección de Puerto

-C, --Ca <nombre_ca> usa el nombre_ca especificado.

-P, --Port <puerto_ca> usa el puerto_ca especificado.

Selección de Puerto Local

Soporte Múltiple Puerto/Múltiple CA: cuando no se especifica ningún dispositivo o puerto IB (ver los "parámetros umad locales" a continuación), la biblioteca libibumad selecciona el puerto a utilizar según los siguientes criterios:

1.
el primer puerto que está ACTIVO.
2.
si no se encuentra, el primer puerto que está ARRIBA (enlace físico arriba).

Si se especifica un nombre de puerto y/o CA, la biblioteca libibumad intenta cumplir la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                 # usa el primer puerto (criterio #1 arriba)
ibaddr -C mthca1       # elige el mejor puerto solo de "mthca1".
ibaddr -P 2            # usa el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usa solo el puerto especificado.

Banderas de Depuración

-d
aumenta el nivel de depuración de IB. Puede usarse varias veces (-ddd o -d -d -d).
-e
muestra errores de envío y recepción (tiempos de espera y otros)

-h, --help muestra el mensaje de uso

-v, --verbose
aumenta el nivel de verbosidad de la aplicación. Puede usarse varias veces (-vv o -v -v -v)

-V, --version muestra la información de la versión.

Banderas de Configuración

-t, --timeout <timeout_ms> anula el tiempo de espera predeterminado para los mads solicitados.

--config, -z <archivo_config> Especificar archivo de configuración alternativo.

Predeterminado: /etc/infiniband-diags/ibdiag.conf

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener detalles.

EJEMPLOS

Ejemplos de Ruta Dirigida

smpdump -D 0,1,2,3,5 16 # DESCRIPCIÓN DEL NODO
smpdump -D 0,1,2 0x15 2 # INFORMACIÓN DEL PUERTO, puerto 2

Ejemplos de Ruta LID

smpdump 3 0x15 2        # INFORMACIÓN DEL PUERTO, lid 3 puerto 2
smpdump 0xa0 0x11       # INFORMACIÓN DEL NODO, lid 0xa0
