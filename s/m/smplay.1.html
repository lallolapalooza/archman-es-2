NOMBRE

smplay - Programa para reproducir un modelo SpectMorph

SINOPSIS

smplay [OPCIONES] Archivo-SM|Archivo-SMSet

DESCRIPCIÓN

smplay es un reproductor basado en línea de comandos para modelos SpectMorph (que se pueden crear usando smenc). La reproducción puede usar la tarjeta de audio, de modo que el modelo se escuche directamente, o crear un archivo wav en su lugar si se usa la opción --export.

Dado que el modelo SpectMorph consta de ondas sinusoidales y ruido, existen opciones para deshabilitar uno de estos componentes.

OPCIONES

smplay sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones ('-').

-h, --help
Muestra un breve mensaje de ayuda.
-v, --version
Imprime la versión de smplay.
--rate <frecuencia de muestreo>
Establece la frecuencia de reproducción manualmente; también es útil para especificar la frecuencia deseada del archivo wav, si se usa --export.
--no-noise
Deshabilita el decodificador de ruido, de modo que solo se decodifique la parte de onda sinusoidal de la señal.
--no-sines
Deshabilita el decodificador de senos, de modo que solo se decodifique la parte de ruido de la señal.
--det-random
Utiliza un generador aleatorio determinista; esto producirá componentes de ruido idénticos si el mismo archivo se decodifica dos veces, haciendo que la salida de audio sea exactamente la misma.
--export <nombre de archivo wav>
En lugar de reproducir el archivo, escribe la salida en un archivo wav.
-m, --midi-note <nota>
Selecciona la nota midi a reproducir, en caso de que se haya especificado un Archivo-SMSet como archivo de entrada.
