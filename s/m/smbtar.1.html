SMBTAR(1) Comandos de usuario SMBTAR(1)

NOMBRE

smbtar - script de shell para hacer copias de seguridad de recursos SMB/CIFS directamente en unidades de cinta UNIX

SINOPSIS

smbtar [-r] [-i] [-a] [-v] {-s servidor} [-p contraseña] [-x servicios] [-X] [-N nombrearchivo] [-b tamañobloque] [-d directorio] [-l nivellog] [-u usuario] [-t cinta] {nombresarchivos}

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de herramientas de samba(7).

smbtar es un script de shell muy pequeño que utiliza smbclient(1) para volcar recursos SMB directamente en cinta.

OPCIONES

-s servidor

El servidor SMB/CIFS en el que reside el recurso.

-x servicio

El nombre del recurso en el servidor al que conectarse. El valor predeterminado es "backup".

-X

Modo de exclusión. Excluir nombres de archivo... de la creación o restauración de tar.

-d directorio

Cambiar al directorio inicial antes de restaurar / hacer copias de seguridad de los archivos.

-v

Modo detallado.

-p contraseña

La contraseña que se utilizará para acceder a un recurso. Predeterminado: ninguna.

-u usuario

El ID de usuario con el que conectarse. Predeterminado: nombre de inicio de sesión de UNIX.

-a

Restablecer el modo del bit de archivo de DOS para indicar que el archivo ha sido archivado.

-t cinta

Dispositivo de cinta. Puede ser un archivo regular o un dispositivo de cinta. Predeterminado: la variable ambiental $TAPE; si no está establecida, un archivo llamado tar.out.

-b tamañobloque

Factor de bloqueo. Predeterminado: 20. Consulte tar(1) para una explicación más completa.

-N nombrearchivo

Hacer copia de seguridad solo de los archivos más recientes que nombrearchivo. Podría usarse (por ejemplo) en un archivo de registro para implementar copias de seguridad incrementales.

-i

Modo incremental; los archivos de tar solo se copian si tienen el bit de archivo establecido. El bit de archivo se restablece después de leer cada archivo.

-r

Restaurar. Los archivos se restauran en el recurso desde el archivo tar.

-l nivel de registro

Nivel de registro (depuración). Corresponde a la bandera -d de smbclient(1).

VARIABLES DE ENTORNO

La variable $TAPE especifica el dispositivo de cinta predeterminado al que escribir. Puede ser anulada con la opción -t.

ERRORES

El script smbtar tiene opciones diferentes a las de tar normal y al comando tar de smbclient.

ADVERTENCIAS

A los sitios que son más cuidadosos con la seguridad puede no gustarles la forma en que el script maneja las contraseñas de PC. La copia de seguridad y la restauración funcionan en recursos completos; deberían funcionar en listas de archivos. smbtar funciona mejor con GNU tar y puede que no funcione bien con otras versiones.

DIAGNÓSTICOS

Consulte la sección DIAGNÓSTICOS del comando smbclient(1).
