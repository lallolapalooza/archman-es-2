NOMBRE

sminspector - programa para visualizar contenidos de instrumentos SpectMorph

SINOPSIS

sminspector [OPCIONES] Archivo-SMIndex

DESCRIPCIÓN

sminspector es una aplicación gráfica que se puede usar para visualizar modelos SpectMorph. Se debe pasar como primer argumento un archivo de entrada que contenga una lista de instrumentos para abrir. Este archivo es un archivo de texto, que consiste en los comandos listados a continuación, y especifica un conjunto de instrumentos con los que trabajar.

COMANDOS DEL ARCHIVO ÍNDICE

smset_dir "directorio"
Establece el directorio que contiene los archivos smset.
smset "instrumento.smset"
Añade un instrumento smset.
