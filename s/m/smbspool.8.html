SMBSPOOL(8) Herramientas de administración del sistema SMBSPOOL(8)

NOMBRE

smbspool - enviar un archivo de impresión a una impresora SMB

SINOPSIS

smbspool {trabajo} {usuario} {título} {copias} {opciones} [nombre_archivo]

DESCRIPCIÓN

Esta herramienta es parte de la suite samba(7).

smbspool es un programa de cola de impresión muy pequeño que envía un archivo de impresión a una impresora SMB. Los argumentos de la línea de comandos son dependientes de la posición para la compatibilidad con el sistema de impresión de la API de UNIX común (CUPS), pero puedes usar smbspool con cualquier sistema de impresión o desde un programa o script.

URI_DISPOSITIVO

smbspool especifica el destino usando un Identificador Uniforme de Recurso ("URI") con un método de "smb". Esta cadena puede tener varias formas:

•smb://servidor[:puerto]/impresora
•smb://grupo_trabajo/servidor[:puerto]/impresora
•smb://usuario:contraseña@servidor[:puerto]/impresora
•smb://usuario:contraseña@grupo_trabajo/servidor[:puerto]/impresora

smbspool intenta obtener el URI de la variable de entorno DEVICE_URI. Si DEVICE_URI no está presente, smbspool usará argv[0] si este comienza con "smb://" o argv[1] si no es el caso.

Los programas que usan las funciones exec(2) pueden pasar el URI en argv[0], mientras que los scripts de shell deben establecer la variable de entorno DEVICE_URI antes de ejecutar smbspool.

OPCIONES

•El argumento job (argv[1]) contiene el número de ID del trabajo y actualmente no es utilizado por smbspool.
•El argumento user (argv[2]) contiene el nombre del usuario de impresión y actualmente no es utilizado por smbspool, excepto en entornos Kerberos para acceder a la caché de tickets del usuario.
•El argumento title (argv[3]) contiene la cadena del título del trabajo y se pasa como el nombre del archivo remoto al enviar el trabajo de impresión.
•El argumento copies (argv[4]) contiene el número de copias a imprimir del archivo nombrado. Si no se proporciona nombre de archivo, este argumento no es utilizado por smbspool.
•El argumento options (argv[5]) contiene las opciones de impresión en una sola cadena y actualmente no es utilizado por smbspool.
•El argumento filename (argv[6]) contiene el nombre del archivo a imprimir. Si este argumento no se especifica, el archivo de impresión se lee de la entrada estándar.
