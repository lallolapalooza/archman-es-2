SMTPCTL(8) Manual del administrador del sistema SMTPCTL(8)

NOMBRE

smtpctl, mailq — controlar el demonio SMTP

SINOPSIS

smtpctl comando [argumento ...]

mailq

DESCRIPCIÓN

El programa smtpctl controla smtpd(8). Los comandos pueden ser abreviados hasta el prefijo inequívoco mínimo; por ejemplo, sh ro para show routes.

El comando mailq se proporciona por compatibilidad con otros MTA y es simplemente un atajo para show queue.

Los siguientes comandos están disponibles:

discover id-sobre | id-mensaje
Programar un sobre individual, o todos los sobres con el mismo ID de mensaje que fueron movidos manualmente a la cola.
encrypt [cadena]
Encriptar la contraseña cadena a una representación adecuada para credenciales de usuario e imprimirla en la salida estándar. Si no se proporciona cadena, las contraseñas en texto plano se leen de la entrada estándar.

Se aconseja evitar proporcionar la contraseña como parámetro, ya que será visible en la salida de top(1) y ps(1).

log brief
Deshabilitar el registro detallado de depuración.
log verbose
Habilitar el registro detallado de depuración.
monitor
Mostrar actualizaciones de algunos contadores internos de smtpd(8) en intervalos de un segundo. Cada línea informa el incremento de todos los contadores desde la última actualización, excepto para algunos contadores que son siempre valores absolutos. La primera línea informa el valor actual de cada contador. Los campos son:
  • Número actual de clientes SMTP activos (valor absoluto).
  • Nuevos clientes SMTP.
  • Clientes desconectados.
  • Número actual de sobres en la cola (valor absoluto).
  • Sobres encolados recientemente.
  • Sobres desencolados.
  • Entregas exitosas.
  • Fallos temporales.
  • Fallos permanentes.
  • Bucles de mensajes.
  • Sobres expirados.
  • Sobres eliminados por el administrador.
  • Rebotes generados.
pause envelope id-sobre | id-mensaje | all
Suspender temporalmente la programación para el sobre con el ID dado, sobres con el ID de mensaje dado, o todos los sobres.
pause mda
Detener temporalmente las entregas a usuarios locales.
pause mta
Detener temporalmente el reenvío y las entregas a usuarios remotos.
pause smtp
Dejar de aceptar temporalmente sesiones entrantes.
profile subsistema
Habilita el perfilado en tiempo real del subsistema. Los subsistemas admitidos son:
  • queue, para perfilar el costo de E/S de la cola
  • imsg, para perfilar el costo de los manejadores de eventos
remove id-sobre | id-mensaje | all
Eliminar un sobre individual, sobres con el ID de mensaje dado, o todos los sobres.
resume envelope id-sobre | id-mensaje | all
Reanudar la programación para el sobre con el ID dado, sobres con el ID de mensaje dado, o todos los sobres.
resume mda
Reanudar las entregas a usuarios locales.
resume mta
Reanudar el reenvío y las entregas a usuarios remotos.
resume route id-ruta
Reanudar el enrutamiento en la ruta deshabilitada id-ruta.
resume smtp
Reanudar la aceptación de sesiones entrantes.
schedule id-sobre | id-mensaje | all
Marcar como listo para entrega inmediata un sobre individual, sobres con el ID de mensaje dado, o todos los sobres.
show envelope id-sobre
Mostrar el contenido del sobre para el ID dado.
show hosts
Mostrar la lista de hosts MX remotos conocidos. Para cada uno de ellos, muestra la dirección IP, el nombre de host canónico, un contador de referencias, el número de conexiones activas a este host y el tiempo transcurrido desde la última conexión.
show hoststats
Mostrar el estado de la última entrega para dominios que han estado activos en las últimas 4 horas. Consiste en los siguientes campos, separados por un "|":
  • Dominio.
  • Marca de tiempo UNIX de la última entrega.
  • Estado de la última entrega.
show message id-sobre
Mostrar el contenido del mensaje para el ID dado.
show queue
Mostrar información relativa a los sobres que se encuentran actualmente en la cola. Cada línea de salida describe un solo sobre. Consiste en los siguientes campos, separados por un "|":
  • ID del sobre.
  • Familia de direcciones del cliente que encoló el correo.
  • Tipo de entrega: uno de "mta", "mda" o "bounce".
  • Varias banderas en el sobre.
  • Dirección del remitente (ruta de retorno).
  • La dirección del destinatario original.
  • La dirección de destino.
  • Hora de creación.
  • Hora de expiración.
  • Hora del último intento de entrega o reenvío.
  • Número de intentos de entrega o reenvío.
  • Estado actual de ejecución: "pending" (pendiente) o "inflight" (en curso) si smtpd(8) está ejecutándose, o "offline" (desconectado) de lo contrario.
  • Retraso en segundos antes del próximo intento si está pendiente, o tiempo transcurrido si se está ejecutando. Este campo estará en blanco si smtpd(8) no está ejecutándose.
  • Cadena de error para el último intento fallido de entrega o reenvío.
show relays
Mostrar la lista de retransmisores actualmente activos y los conectores asociados. Para cada retransmisor, muestra un número de contadores e información sobre su estado interno en una sola línea. Luego viene la lista de conectores (direcciones de origen para conectarse desde este retransmisor).
show routes
Mostrar el estado de las rutas actualmente conocidas por smtpd(8).
smtpctl(8) — OpenSMTPD

NAME

smtpctl — control utility for smtpd(8)

SYNOPSIS

smtpctl [-mn] [-m type] [-L logpath] command [args...]

DESCRIPTION

The smtpctl utility is used to interact with a running smtpd(8) daemon. It allows you to view its status, statistics, routing tables, and to configure it dynamically.

The following commands are available:

add route address next-hop [via] [tag...]
Adds a route for the given address which specifies that mail for this address should be sent to next-hop. If via is specified, the next hop will be reached through the specified interface. The optional tag allows to assign a tag to the route.
add table name file [tag...]
Adds a mapping table named name loaded from file. The optional tag allows to assign a tag to the table.
del route [-C] [-c count] [-f file] [-r regex]
Deletes routes matching the given criteria. Without any criteria, it deletes all routes. -C: Clear all routes. -c: Delete only count matching routes. -f: Delete routes defined in file. -r: Delete routes matching the given regex.
del table [-f file] [-r regex] name
Deletes a mapping table named name. Without any criteria, it deletes all tables. -f: Delete tables defined in file. -r: Delete tables matching the given regex.
flush [queue]
Flushes the mail queue or a specific queue. Without arguments, it flushes all queues.
gentags
Generates new tags for the routing table.
grep pattern
Searches the mail queue for messages matching pattern.
info
Displays general information about the smtpd(8) daemon, including the version, uptime, and number of running processes.
log show [-f file] [-n number]
Shows the last lines of the smtpd(8) log file. Without arguments, it shows the last 20 lines. -f: Use file as log file. -n: Show number lines.
profile subsystem
Enables real-time profiling of subsystem. Supported subsystems are:
  • imsg
  • io
  • smtp (incoming sessions)
  • filters
  • mta (outgoing sessions)
  • bounce
  • scheduler
  • expand (aliases/virtual/forward expansion)
  • lookup (user/credentials lookups)
  • stat
  • rules (matched by incoming sessions)
  • mproc
  • all
queue [subsystem]
Displays the current state of the mail queue or a specific queue. Without arguments, it shows all queues.
remove route [-r regex]
Removes a route from the routing table. Without arguments, it removes all routes. -r: Removes routes matching the given regex.
remove table [-r regex] name
Removes a mapping table. Without arguments, it removes all tables. -r: Removes tables matching the given regex.
restart
Restarts the smtpd(8) daemon.
resume [subsystem]
Resumes a paused subsystem. Without arguments, resumes all subsystems.
route [-v]
Displays the current routing table. The -v option shows more details.
show connection
Shows active connections.
show config
Shows the current configuration of smtpd(8).
show daemon
Shows information about the running smtpd(8) daemons.
show filter [filtername]
Shows information about the configured filters.
show host
Shows host information.
show log [-f file] [-n number]
Shows the smtpd(8) log file. Without arguments, it shows the last 20 lines. -f: Use file as log file. -n: Show number lines.
show queue [queue]
Each line consists of a route number, a source address, a destination address, a set of flags, the number of connections on this route, the current penalty level which determines the amount of time the route is disabled if an error occurs, and the delay before it gets reactivated. The following flags are defined:
D
The route is currently disabled.
N
The route is new. No SMTP session has been established yet.
Q
The route has a timeout registered to lower its penalty level and possibly reactivate or discard it.
show stats
Displays runtime statistics concerning smtpd(8).
show status
Shows if MTA, MDA and SMTP systems are currently running or paused.
spf walk
Recursively look up SPF records for the domains read from stdin. For example: 
$ smtpctl spf walk < domains.txt

SPF records may contain macros which cannot be included in a static list and must be resolved dynamically at connection time. spf walk cannot provide full results in these cases.

trace subsystem
Enables real-time tracing of subsystem. Supported subsystems are:
  • imsg
  • io
  • smtp (incoming sessions)
  • filters
  • mta (outgoing sessions)
  • bounce
  • scheduler
  • expand (aliases/virtual/forward expansion)
  • lookup (user/credentials lookups)
  • stat
  • rules (matched by incoming sessions)
  • mproc
  • all
unprofile subsystem
Disables real-time profiling of subsystem.
untrace subsystem
Disables real-time tracing of subsystem.
update table name
Updates the contents of table name, for tables using the “file” backend.

When smtpd receives a message, it generates a message-id for the message, and one envelope-id per recipient. The message-id is a 32-bit random identifier that is guaranteed to be unique on the host system. The envelope-id is a 64-bit unique identifier that encodes the message-id in the 32 upper bits and a random envelope identifier in the 32 lower bits.

A command which specifies a message-id applies to all recipients of a message; a command which specifies an envelope-id applies to a specific recipient of a message.

FILES

/run/smtpd.sock
UNIX-domain socket used for communication with smtpd(8).
