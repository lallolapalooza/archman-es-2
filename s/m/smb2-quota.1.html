SMB2-QUOTA(1) Manual de comandos generales SMB2-QUOTA(1)

NOMBRE

smb2-quota - Programa auxiliar de espacio de usuario para mostrar información de cuotas para el sistema de archivos del cliente SMB de Linux (CIFS)

SINOPSIS

smb2-quota [-h] {opciones} {objeto del sistema de archivos}

DESCRIPCIÓN

Esta herramienta forma parte del conjunto cifs-utils.

smb2-quota es un programa auxiliar de espacio de usuario para el sistema de archivos del cliente SMB de Linux (CIFS).

Esta herramienta funciona realizando una llamada IOCTL CIFS_QUERY_INFO al cliente SMB de Linux, que a su vez emite una solicitud SMB Query Info y devuelve el resultado.

OPCIONES

--help/-h: Imprime la ayuda que explica las opciones de la línea de comandos.

--tabular/-t: Imprime la información de cuotas para el volumen en formato tabular. Cantidad utilizada | Límite de cuota | Nivel de advertencia | Porcentaje utilizado | Estado | SID

--csv/-c: Imprime la información de cuotas para el volumen en formato csv. SID,Cantidad utilizada,Límite de cuota,Nivel de advertencia

--list/-l: Imprime la información de cuotas para el volumen en formato raw. - SID - Cuota utilizada - Umbral de cuota - Límite de cuota

--tabular/-t es la acción predeterminada si no se especifica ninguna.

NOTAS

El soporte del kernel para smb2-quota requiere el IOCTL CIFS_QUERY_INFO, que se introdujo inicialmente en el kernel 4.20 y solo está implementado para puntos de montaje que utilizan SMB2 o superior (consulte la opción vers de mount.cifs(8)).
