smpquery(8) Diagnósticos de InfiniBand smpquery(8)

Nombre

smpquery - consultar atributos de gestión de subred InfiniBand

SINOPSIS

smpquery [opciones] <operación> <ruta_dr_destino|lid|guid> [parámetros de operación]

DESCRIPCIÓN

smpquery permite un subconjunto básico de consultas SMP estándar que incluyen: información del nodo, descripción del nodo, información del conmutador, información del puerto. Los campos se muestran en formato legible por humanos.

OPCIONES

Operaciones actualmente soportadas (sin distinción de mayúsculas y minúsculas) y sus parámetros:

Nodeinfo (NI) <dirección>
Nodedesc (ND) <dirección>
Portinfo (PI) <dirección> [<número_puerto>]     # el puerto predeterminado es cero
PortInfoExtended (PIE) <dirección> [<número_puerto>]
Switchinfo (SI) <dirección>
PKeyTable (PKeys) <dirección> [<número_puerto>]
SL2VLTable (SL2VL) <dirección> [<número_puerto>]
VLArbitration (VLArb) <dirección> [<número_puerto>]
GUIDInfo (GI) <dirección>
MlnxExtPortInfo (MEPI) <dirección> [<número_puerto>]  # el puerto predeterminado es cero
-c, --combinado
Usar el argumento de dirección de ruta combinada <lid> <Ruta_DR>
-x, --extendido
Establecer el bit 31 de SMSupportsExtendedSpeeds en AttributeModifier (solo afecta a las consultas de PortInfo).
-K, --mostrar_claves
mostrar claves de seguridad (mkey, smkey, etc.) asociadas con la solicitud.

Indicadores de Direccionamiento

-D, --Directo La dirección especificada es una ruta directa

Ejemplos:
   [opciones] -D [opciones] "0"          # puerto propio
   [opciones] -D [opciones] "0,1,2,1,4"  # salida por el puerto 1, luego 2, ...
   (Tenga en cuenta que el segundo número en la ruta especificada debe coincidir con el puerto que se
   está utilizando. Esto se puede especificar usando el indicador de selección de puerto '-P' o el
   puerto encontrado a través del proceso de selección automática.)

-G, --Guid La dirección especificada es un GUID de puerto

-L, --Lid La dirección especificada es un LID

-s, --puerto_sm <smlid> usar 'smlid' como el lid de destino para las consultas SA.

Indicadores de Selección de Puerto

-C, --Ca <nombre_ca> usar el nombre_ca especificado.

-P, --Puerto <puerto_ca> usar el puerto_ca especificado.

Selección de puerto local

Soporte para múltiples puertos/múltiples CA: cuando no se especifica ningún dispositivo o puerto IB (ver los "parámetros umad locales" a continuación), la biblioteca libibumad selecciona el puerto a utilizar según los siguientes criterios:

1.
el primer puerto que está ACTIVO.
2.
si no se encuentra, el primer puerto que está ARRIBA (enlace físico activo).

Si se especifica un nombre de puerto y/o CA, la biblioteca libibumad intenta cumplir la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                 # usar el primer puerto (criterio #1 anterior)
ibaddr -C mthca1       # seleccionar el mejor puerto solo de "mthca1".
ibaddr -P 2            # usar el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usar solo el puerto especificado.

Indicadores de Depuración

-d
aumentar el nivel de depuración de IB. Puede usarse varias veces (-ddd o -d -d -d).
-e
mostrar errores de envío y recepción (tiempos de espera y otros)

-h, --ayuda mostrar el mensaje de uso

-v, --verboso
aumentar el nivel de verbosidad de la aplicación. Puede usarse varias veces (-vv o -v -v -v)

-V, --version mostrar información de la versión.

Indicadores de Configuración

-t, --tiempo_espera <tiempo_espera_ms> anular el tiempo de espera predeterminado para los mads solicitados.

--mapa-nombres-nodo <mapa-nombres-nodo> Especificar un mapa de nombres de nodo.

Este archivo mapea GUIDs a nombres más amigables. Ver la sección ARCHIVOS.
-y, --m_key <clave>
usar la M_key especificada para las solicitudes. Si se especifica un valor no numérico (como 'x'), se solicitará un valor.

--config, -z <archivo_config> Especificar archivo de configuración alternativo.

Predeterminado: /etc/infiniband-diags/ibdiag.conf

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Ver el archivo de configuración proporcionado para más detalles.

FORMATO DEL ARCHIVO DE MAPA DE NOMBRES DE NODOS

El mapa de nombres de nodo se utiliza para especificar nombres amigables para los nodos en la salida. Los GUID se utilizan para realizar la búsqueda.

Esta funcionalidad es proporcionada por el paquete opensm-libs. Consulte opensm(8) para la ubicación del archivo en su instalación.

Genéricamente:

# comentario
<guid> "<nombre>"

Ejemplo:

# IB1
# Tarjetas de línea
0x0008f104003f125c "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f125d "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10d2 "IB1 (Rack 11 slot 2   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10d3 "IB1 (Rack 11 slot 2   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10bf "IB1 (Rack 11 slot 12  ) ISR9288/ISR9096 Voltaire sLB-24D"
# Spines
0x0008f10400400e2d "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2e "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2f "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e31 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e32 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
# GUID   Node Name
0x0008f10400411a08 "SW1  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f10400411a28 "SW2  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f10400411a34 "SW3  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f104004119d0 "SW4  (Rack  3) ISR9024 Voltaire 9024D"

EJEMPLOS

smpquery portinfo 3 1                     # portinfo por lid, con modificador de puerto
smpquery -G switchinfo 0x2C9000100D051 1  # switchinfo por guid
smpquery -D nodeinfo 0                    # nodeinfo por ruta directa
smpquery -c nodeinfo 6 0,12               # nodeinfo por ruta combinada
