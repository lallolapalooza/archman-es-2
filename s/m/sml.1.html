NOMBRE

sml - el sistema interactivo Standard ML de New Jersey

SINOPSIS

sml [OPCIONES-SML] [OPCIONES] [ARCHIVOS]

DESCRIPCIÓN

Standard ML of New Jersey es un compilador incremental e interactivo que acepta declaraciones y expresiones de SML para ser evaluadas desde la entrada estándar.

OPCIONES

-32

ejecuta la versión de 32 bits del sistema SML/NJ (actualmente la predeterminada).

-64

ejecuta la versión de 64 bits del sistema SML/NJ. Esta opción solo se aplica a la arquitectura x86-64 (también conocida como amd64).

@SMLwordsize

imprime el tamaño de palabra (es decir, 32 o 64) del sistema en la salida estándar y luego sale. (Esta opción se agregó en la versión 110.97).

@SMLversion

imprime el nombre del comando y la versión de SML/NJ (por ejemplo, "sml 110.99.9") en la salida estándar y luego sale.

@SMLload=IMAGEN

especifica el nombre del archivo de imagen de montón (heap) a cargar. Se puede omitir el sufijo del montón siempre que no haya un archivo con el mismo nombre.

@SMLcmdname=NOMBRE

establece el nombre del comando; este es el valor devuelto por CommandLine.name().

@SMLsuffix

imprime el sufijo del montón para el sistema en la salida estándar y luego sale.

@SMLalloc=TAMAÑO

especifica el tamaño preferido del área de asignación.

@SMLrun=TIEMPO DE EJECUCIÓN

especifica el sistema de tiempo de ejecución.

@SMLquiet

carga la imagen de montón silenciosamente (predeterminado).

@SMLverbose

muestra el progreso de carga de la imagen de montón.

@SMLobjects

muestra la lista de objetos ejecutables.

@SMLdebug=ARCHIVO

escribe información de depuración en el archivo.

-Ccontrol=valor

establece el parámetro de control control a valor.

-Dnombre=valor

define la variable CM nombre para que tenga el valor dado.

-D'nombre

define la variable CM nombre para que tenga el valor 1.

-Unombre

elimina cualquier definición de la variable CM nombre.

-H

produce una lista de ayuda completa.

-h

produce una lista de ayuda mínima.

-hnivel

ayuda con un límite de oscuridad.

-S

enumera todos los controles junto con su valor predeterminado.

-snivel

imprime una lista limitada de configuraciones. El número de niveles de la jerarquía de control está controlado por nivel, y 0 imprime solo la raíz de la jerarquía.

-E

enumera todos los controles junto con sus variables de entorno correspondientes.

-enivel

imprime una lista limitada de variables de entorno; El número de niveles de la jerarquía de control está controlado por nivel, y 0 imprime solo la raíz de la jerarquía.

-m

cambia a CM.make.

-a

cambia a CM.autoload; predeterminado.

archivo.cm

ejecuta CM.make o CM.autoload en archivo.cm y luego regresa al prompt de SML. Qué comando se ejecuta se determina por las banderas -m y -a.

archivo.sig

ejecuta use archivo.sig antes de ingresar al bucle principal de SML.

archivo.sml

(usar) ejecuta use archivo.sml antes de ingresar al bucle principal de SML.

archivo.fun

(usar) ejecuta use archivo.fun antes de ingresar al bucle principal de SML.

AUTOR
