SMBCONTROL(1) Comandos de usuario SMBCONTROL(1)

NOMBRE

smbcontrol - enviar mensajes a procesos smbd, nmbd o winbindd

SINOPSIS

smbcontrol [-?|--help] [--usage] [-t|--timeout] [-d|--debuglevel=NIVELDEPURACION] [--debug-stdout] [--configfile=ARCHIVO_CONFIGURACION] [--option=nombre=valor] [-l|--log-basename=BASE_ARCHIVO_LOG] [--leak-report] [--leak-report-full]

smbcontrol [destino] [tipo-mensaje] [parametro]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de herramientas de samba(7).

smbcontrol es un programa muy pequeño que envía mensajes a un demonio smbd(8), nmbd(8) o winbindd(8) que se esté ejecutando en el sistema.

OPCIONES

-t|--timeout

Establece el tiempo de espera en segundos.

destino

Uno de nmbd, smbd, winbindd o un ID de proceso.

El destino all hace que el mensaje se "difunda" a todos los demonios en ejecución, incluyendo nmbd y winbind. Esto es un cambio con respecto a Samba 3.3; antes de esta versión, el parámetro smbd hacía esto.

El destino smbd hace que el mensaje se envíe al demonio smbd especificado en el archivo smbd.pid.

El destino nmbd hace que el mensaje se envíe al demonio nmbd especificado en el archivo nmbd.pid.

El destino winbindd hace que el mensaje se envíe al demonio winbind especificado en el archivo winbindd.pid.

Si se proporciona un ID de proceso único, el mensaje se enviará solo a ese proceso.

tipo-mensaje

Tipo de mensaje a enviar. Consulte la sección TIPOS-DE-MENSAJE para obtener más detalles.

parámetros

Cualquier parámetro requerido para el tipo-mensaje

-?|--help

Imprime un resumen de las opciones de la línea de comandos.

--usage

Muestra un breve mensaje de uso.

-d|--debuglevel=nivel

nivel es un entero de 0 a 10. El valor predeterminado si no se especifica este parámetro es 1 para las aplicaciones cliente.

Cuanto mayor sea este valor, más detalles se registrarán en los archivos de registro sobre las actividades del servidor. En el nivel 0, solo se registrarán errores críticos y advertencias serias. El nivel 1 es un nivel razonable para el uso diario, ya que genera una pequeña cantidad de información sobre las operaciones realizadas.

Los niveles superiores a 1 generarán una cantidad considerable de datos de registro y solo deben usarse al investigar un problema. Los niveles superiores a 3 están diseñados solo para desarrolladores y generan una ENORME cantidad de datos de registro, la mayoría de los cuales son extremadamente crípticos.

Tenga en cuenta que especificar este parámetro aquí anulará el parámetro log level en el archivo /etc/samba/smb.conf.

--debug-stdout

Esto redirigirá la salida de depuración a STDOUT. Por defecto, todos los clientes registran en STDERR.

--configfile=<archivo de configuración>

El archivo especificado contiene los detalles de configuración requeridos por el cliente. La información de este archivo puede ser general para el cliente y el servidor o solo proporcionar opciones específicas del cliente, como client smb encrypt. Consulte /etc/samba/smb.conf para obtener más información. El nombre del archivo de configuración predeterminado se determina en el momento de la compilación.

--option=<nombre>=<valor>

Establece la opción smb.conf(5) "<nombre>" al valor "<valor>" desde la línea de comandos. Esto anula los valores predeterminados compilados y las opciones leídas del archivo de configuración. Si un nombre o un valor incluyen un espacio, envuelva todo --option=nombre=valor entre comillas.

-l|--log-basename=directorio_log

Directorio base para los archivos de registro/depuración. Se añadirá la extensión ".nombreprograma" (por ejemplo, log.smbclient, log.smbd, etc.). El cliente nunca elimina el archivo de registro.

--leak-report

Habilita el informe de fugas de talloc al salir.

--leak-report-full

Habilita el informe completo de fugas de talloc al salir.

-V|--version

Imprime el número de versión del programa.

TIPOS-DE-MENSAJE

Los tipos de mensaje disponibles son:

close-share

Ordena a smbd que cierre las conexiones del cliente a la red compartida especificada. Tenga en cuenta que esto no afecta a las conexiones de los clientes a ninguna otra red compartida. Este tipo de mensaje toma como argumento el nombre de la red compartida para la cual se cerrarán las conexiones del cliente, o el carácter "*" que cerrará todas las redes compartidas abiertas actualmente. Esto puede ser útil si ha realizado cambios en los controles de acceso a la red compartida. Este mensaje solo se puede enviar a smbd.

close-denied-share

Se comporta como close-share, pero no desconecta a los usuarios que todavía tienen permiso para acceder a la red compartida. Se puede enviar de forma segura a todos los smbd después de cambiar los controles de acceso a la red compartida. Solo afectará a los usuarios a los que se les haya denegado el acceso desde que se conectaron inicialmente. Este mensaje solo se puede enviar a smbd.

debug

Establece el nivel de depuración al valor especificado por el parámetro. Esto se puede enviar a cualquiera de los destinos. Si este mensaje se envía a los demonios smbd o winbindd, el proceso padre reenviará el mensaje a todos los procesos hijos, cambiando el nivel de depuración en cada uno.

kill-client-ip

Ordena a smbd que cierre las conexiones del cliente desde una dirección IP dada. Este tipo de mensaje toma como argumento la dirección IP desde la cual se cerrarán las conexiones del cliente. Este mensaje solo se puede enviar a smbd.

force-election

Este mensaje hace que el demonio nmbd fuerce una nueva elección de browse master.

ping

Envía el número especificado de mensajes "ping" y espera el mismo número de mensajes de respuesta "pong". Esto se puede enviar a cualquiera de los destinos.

profile

Cambia la configuración del perfil de un demonio, según el parámetro. El parámetro puede ser "on" para habilitar la recopilación de estadísticas de perfil, "off" para deshabilitar la recopilación de estadísticas de perfil, "count" para habilitar solo la recopilación de estadísticas de conteo (las estadísticas de tiempo están deshabilitadas), y "flush" para poner a cero las estadísticas de perfil actuales. Esto se puede enviar a cualquier destino smbd o nmbd.

debuglevel

Solicita el nivel de depuración de un demonio determinado y lo escribe en la salida estándar. Esto se puede enviar a cualquiera de los destinos.

profilelevel

Solicita el nivel de perfil de un demonio determinado y lo escribe en la salida estándar. Esto se puede enviar a cualquier destino smbd o nmbd.

printnotify

Ordena a smbd que envíe un mensaje de notificación de impresora a cualquier cliente de Windows NT conectado a una impresora. Este tipo de mensaje toma los siguientes argumentos:

queuepause nombre_impresora

Envía un mensaje de notificación de cambio de pausa de cola a la impresora especificada.

queueresume nombre_impresora

Envía un mensaje de notificación de reanudación de cola para la impresora especificada.

jobpause nombre_impresora id_trabajo_unix

Envía un mensaje de notificación de pausa de trabajo para la impresora y el ID de trabajo de Unix especificados.

jobresume nombre_impresora id_trabajo_unix

Envía un mensaje de notificación de reanudación de trabajo para la impresora y el ID de trabajo de Unix especificados.

jobdelete nombre_impresora id_trabajo_unix

Envía un mensaje de notificación de eliminación de trabajo para la impresora y el ID de trabajo de Unix especificados.

Tenga en cuenta que este mensaje solo envía la notificación de que ha ocurrido un evento. No causa que el evento ocurra realmente.

Este mensaje solo se puede enviar a smbd.

dmalloc-mark

Establece una marca para dmalloc. Se puede enviar tanto a smbd como a nmbd. Solo disponible si samba está compilado con soporte dmalloc.

dmalloc-log-changed

Registra los punteros que han cambiado desde la marca establecida por dmalloc-mark. Se puede enviar tanto a smbd como a nmbd. Solo disponible si samba está compilado con soporte dmalloc.

shutdown

Apaga el demonio especificado. Se puede enviar tanto a smbd como a nmbd.

pool-usage

Imprime una descripción legible por humanos de toda la memoria talloc(pool) utilizada por los demonios. Esto se puede enviar a cualquier destino smbd o nmbd.

el demonio/proceso especificado. Disponible tanto para smbd como para nmbd.

ringbuf-log

Recupera e imprime el registro ringbuf. Requiere logging = ringbuf. Disponible para smbd, winbindd y nmbd.

drvupgrade

Fuerza a los clientes de impresoras que utilizan el controlador especificado a actualizar su versión local del controlador. Solo se puede enviar a smbd.

reload-config

Fuerza al demonio a recargar el archivo de configuración smb.conf. Se puede enviar a smbd, nmbd o winbindd.

reload-printers

Fuerza a smbd a recargar las impresoras. Solo se puede enviar a smbd.

idmap

Notifica sobre cambios en el mapeo de IDs. Se puede enviar a smbd o (aún no implementado) winbindd.

flush [uid|gid]

Vacía las cachés de mapeo sid <-> gid y/o sid <-> uid.

delete <ID>

Elimina un mapeo de la caché. El mapeo se da por <ID>, que puede ser un sid: S-x-..., un gid: "número GID" o un uid: "número UID".

kill <ID>

Elimina un mapeo de la caché. Termina smbd si el ID se está utilizando actualmente.

num-children

Consulta el número de procesos hijos de smbd. Este mensaje solo se puede enviar a smbd.

reload-certs

Instruye al servidor LDAP de un DC de Samba AD a recargar los certificados TLS que protegen las conexiones ldaps://. Este mensaje solo se puede enviar a ldap_server.
