SMBTREE(1) Comandos de Usuario SMBTREE(1)

NOMBRE

smbtree - Un explorador de red smb basado en texto

SINOPSIS

smbtree [-D|--domains] [-S|--servers] [-?|--help] [--usage] [-d|--debuglevel=NIVELDEBUG] [--debug-stdout] [--configfile=ARCHIVO] [--option=nombre=valor] [-l|--log-basename=ARCHIVOBASELOG] [--leak-report] [--leak-report-full] [-U|--user=[DOMINIO/]USUARIO[%CONTRASEÑA]] [-N|--no-pass] [--password=CADENA] [--pw-nt-hash] [-A|--authentication-file=ARCHIVO] [-P|--machine-pass] [--simple-bind-dn=DN] [--use-kerberos=deseado|requerido|apagado] [--use-krb5-ccache=CCACHE] [--use-winbind-ccache] [--client-protection=sign|encrypt|off] [-V|--version]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto samba(7).

smbtree es un programa explorador de smb en modo texto. Es similar al "Neighborhood de Red" que se encuentra en las computadoras Windows. Imprime un árbol con todos los dominios conocidos, los servidores en esos dominios y los recursos compartidos en los servidores.

OPCIONES

-D|--domains

Solo imprime una lista de todos los dominios conocidos en difusión o por el navegador maestro.

-S|--servers

Solo imprime una lista de todos los dominios y servidores que responden en difusión o conocidos por el navegador maestro.

-?|--help

Imprime un resumen de las opciones de línea de comandos.

--usage

Muestra un mensaje de uso breve.

-d|--debuglevel=nivel

nivel es un entero de 0 a 10. El valor por defecto si este parámetro no se especifica es 1 para las aplicaciones cliente.

Cuanto mayor sea este valor, más detalles se registrarán en los archivos de registro sobre las actividades del servidor. En el nivel 0, solo se registrarán errores críticos y advertencias serias. El nivel 1 es un nivel razonable para el uso diario: genera una pequeña cantidad de información sobre las operaciones realizadas.

Los niveles superiores a 1 generarán una cantidad considerable de datos de registro y solo deben usarse al investigar un problema. Los niveles superiores a 3 están diseñados para ser utilizados solo por desarrolladores y generan ENORMES cantidades de datos de registro, la mayoría de los cuales son extremadamente crípticos.

Tenga en cuenta que especificar este parámetro aquí anulará el parámetro log level en el archivo /etc/samba/smb.conf.

--debug-stdout

Esto redirigirá la salida de depuración a STDOUT. Por defecto, todos los clientes registran en STDERR.

--configfile=<archivo de configuración>

El archivo especificado contiene los detalles de configuración requeridos por el cliente. La información en este archivo puede ser general para cliente y servidor o proporcionar solo opciones específicas del cliente como client smb encrypt. Consulte /etc/samba/smb.conf para más información. El nombre del archivo de configuración por defecto se determina en tiempo de compilación.

--option=<nombre>=<valor>

Establece la opción smb.conf(5) "<nombre>" al valor "<valor>" desde la línea de comandos. Esto anula los valores predeterminados compilados y las opciones leídas del archivo de configuración. Si un nombre o valor incluye un espacio, envuelva todo --option=nombre=valor entre comillas.

-l|--log-basename=directorio_log

Nombre base del directorio para archivos de registro/depuración. La extensión ".progname" se añadirá (por ejemplo, log.smbclient, log.smbd, etc.). El cliente nunca elimina el archivo de registro.

--leak-report

Habilita el informe de fugas de talloc al salir.

--leak-report-full

Habilita el informe completo de fugas de talloc al salir.

-V|--version

Imprime el número de versión del programa.

-U|--user=[DOMINIO\]USUARIO[%CONTRASEÑA]

Establece el nombre de usuario SMB o el nombre de usuario y contraseña.

Si no se especifica %CONTRASEÑA, se le pedirá al usuario. El cliente comprobará primero la variable de entorno USER (a la que también se le permite contener la contraseña separada por un %), luego la variable LOGNAME (a la que no se le permite contener una contraseña) y si alguna existe, se utilizará el valor. Si estas variables de entorno no se encuentran, se puede utilizar el nombre de usuario encontrado en una caché de credenciales de Kerberos.

Una tercera opción es utilizar un archivo de credenciales que contiene la contraseña en texto plano del nombre de usuario y la contraseña. Esta opción se proporciona principalmente para scripts donde el administrador no desea pasar las credenciales en la línea de comandos o a través de variables de entorno. Si se utiliza este método, asegúrese de que los permisos del archivo restrinjan el acceso a usuarios no deseados. Consulte la opción -A para obtener más detalles.

Tenga cuidado al incluir contraseñas en scripts o al pasar valores proporcionados por el usuario en la línea de comandos. Por seguridad, es mejor dejar que la herramienta cliente de Samba solicite la contraseña si es necesario, u obtenga la contraseña una vez con kinit.

Mientras que Samba intentará limpiar la contraseña del título del proceso (como se ve en ps), esto es después del inicio y está sujeto a una condición de carrera.

-N|--no-pass

Si se especifica, este parámetro suprime el prompt de contraseña normal del cliente al usuario. Esto es útil cuando se accede a un servicio que no requiere contraseña.

A menos que se especifique una contraseña en la línea de comandos o se especifique este parámetro, el cliente solicitará una contraseña.

Si se especifica una contraseña en la línea de comandos y esta opción también está definida, la contraseña en la línea de comandos será ignorada silenciosamente y no se utilizará ninguna contraseña.

--password

Especifica la contraseña en la línea de comandos.

Tenga cuidado al incluir contraseñas en scripts o al pasar valores proporcionados por el usuario en la línea de comandos. Por seguridad, es mejor dejar que la herramienta cliente de Samba solicite la contraseña si es necesario, u obtenga la contraseña una vez con kinit.

Si no se especifica --password, la herramienta comprobará la variable de entorno PASSWD, seguida de PASSWD_FD que se espera que contenga un descriptor de archivo (FD) abierto.

Finalmente, comprobará PASSWD_FILE (que contiene una ruta de archivo a abrir). El archivo solo debe contener la contraseña. ¡Asegúrese de que los permisos del archivo restrinjan el acceso a usuarios no deseados!

Mientras que Samba intentará limpiar la contraseña del título del proceso (como se ve en ps), esto es después del inicio y está sujeto a una condición de carrera.

--pw-nt-hash

La contraseña proporcionada es el hash NT.

-A|--authentication-file=nombrearchivo

Esta opción le permite especificar un archivo del que leer el nombre de usuario y la contraseña utilizados en la conexión. El formato del archivo es: 
username = <valor>
password = <valor>
domain   = <valor>

¡Asegúrese de que los permisos del archivo restrinjan el acceso a usuarios no deseados!

-P|--machine-pass

Utiliza la contraseña de cuenta de máquina almacenada.

--simple-bind-dn=DN

DN a usar para un enlace simple.

--use-kerberos=deseado|requerido|apagado

Este parámetro determina si las herramientas cliente de Samba intentarán autenticarse usando Kerberos. Para la autenticación Kerberos, debería usar nombres DNS en lugar de direcciones IP al conectarse a un servicio. Por defecto, las herramientas cliente de Samba intentarán usar la caché de credenciales Kerberos por defecto (ccache). En caso de que la ccache no exista o se haya especificado la opción -U|--user, los clientes pedirán introducir una contraseña y obtendrán un ticket Kerberos (kinit) por usted. Si desea utilizar una caché de credenciales Kerberos alternativa, utilice la opción --use-krb5-ccache.

Tenga en cuenta que especificar este parámetro aquí anulará el parámetro client use kerberos en el archivo /etc/samba/smb.conf.

--use-krb5-ccache=CCACHE

Especifica la ubicación de la caché de credenciales para la autenticación Kerberos.

Esto forzará --use-kerberos=requerido.

--use-winbind-ccache

Intenta usar la caché de credenciales de winbind.

--client-protection=sign|encrypt|off

Establece la protección de conexión que debe usar la herramienta cliente.

Tenga en cuenta que especificar este parámetro aquí anulará el parámetro client protection en el archivo /etc/samba/smb.conf.

En caso de que necesite un control más detallado, puede usar: --option=clientsmbencrypt=OPCIÓN, --option=clientipcsigning=OPCIÓN, --option=clientsigning=OPCIÓN.
