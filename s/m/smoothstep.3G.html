NOMBRE

smoothstep - realiza interpolación de Hermite entre dos valores

DECLARACIÓN

genType smoothstep(genType edge0, genType edge1, genType x);

genType smoothstep(float edge0, float edge1, genType x);

genDType smoothstep(genDType edge0, genDType edge1, genDType x);

genDType smoothstep(double edge0, double edge1, genDType x);

PARÁMETROS

edge0

Especifica el valor del borde inferior de la función de Hermite.

edge1

Especifica el valor del borde superior de la función de Hermite.

x

Especifica el valor de origen para la interpolación.

DESCRIPCIÓN

smoothstep realiza una interpolación suave de Hermite entre 0 y 1 cuando edge0 < x < edge1. Esto es útil en casos donde se desea una función de umbral con una transición suave. smoothstep es equivalente a:

    genType t;  /* O genDType t; */
    t = clamp((x - edge0) / (edge1 - edge0), 0.0, 1.0);
    return t * t * (3.0 - 2.0 * t);

Los resultados no están definidos si edge0 ≥ edge1.
