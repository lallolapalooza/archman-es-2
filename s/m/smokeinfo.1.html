NOMBRE

smokeinfo - sondear el sitio smokeping para obtener información numérica

SINOPSIS

smokeinfo ruta/a/config.cfg [opciones]

--start x                     hora de inicio del gráfico rrd. (por defecto ahora-24h)

--end y                       hora de fin del gráfico rrd. (por defecto ahora)
--filter pattern              patrón de búsqueda para la selección de nodos
--mode plain (por defecto)        cómo usar el patrón
                              - plain
                              - recursive
                              - regexp
--separator ; (por defecto)
--format %le (por defecto)
--no-head                      no imprimir encabezado
--man                          mostrar página man y salir
-h, --help                     mostrar esta ayuda y salir
--version                      mostrar información de la versión y salir

DESCRIPCIÓN

SmokeInfo es un front-end simple para el módulo Smokeping::Info. Proporciona acceso a datos numéricos almacenados en los archivos rrd.

Tenga en cuenta que --start y --end se pasan directamente a rrd graph. Esto significa que funcionan con la misma sintaxis.

Ejemplos

Obtener todos los datos de todos los nodos

smokeinfo etc/config

Mostrar solo nodos directamente bajo /Customers

smokeinfo --filter=/Customers/ etc/config

Mostrar todos los nodos bajo /Customers

smokeinfo --mode=recursive --filter=/Customers/ etc/config

Mostrar todos los nodos con '_wlan_' en el nombre

smokeinfo --mode=regexp --filter=_wlan_ etc/config
