NOMBRE

smsfimport - programa para crear modelos SpectMorph a partir de presets SoundFont

SINOPSIS

smsfimport <comando> <ArchivoSoundFont> [OPCIONES] [<argumentos específicos del comando>...]

DESCRIPCIÓN

smsfimport se puede usar para convertir presets SoundFont (formato .sf2) a instrumentos SpectMorph (formato .smset). Dado que no implementa toda la funcionalidad proporcionada por SoundFonts, los archivos resultantes pueden sonar diferentes al SoundFont original, y en algunos casos la importación fallará por completo.

OPCIONES

smsfimport sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones ('-').

-h, --help
Muestra un breve mensaje de ayuda.
-v, --version
Imprime la versión de smsfimport.

COMANDOS

list <ArchivoSoundFont>
Muestra todos los presets contenidos en el ArchivoSoundFont.
dump <ArchivoSoundFont> [ <NombrePreset> ]
Muestra una vista detallada de los parámetros especificados para un preset (o para todos los presets).
import <ArchivoSoundFont> <NombrePreset>
Importa un preset, creando un archivo *.smset. Para el preset "Grand Piano", la salida resultante sería "grand_piano.smset".
