NOMBRE

sminstbuilder - programa para construir instrumentos .smset a partir de muestras

SINOPSIS

sminstbuilder Directorio...

DESCRIPCIÓN

sminstbuilder es un script que realiza automáticamente todos los pasos necesarios para construir un instrumento .smset (para ser usado con planes de morphing de SpectMorph) a partir de muestras. Es posible realizar todos los pasos que hace sminstbuilder manualmente, usando smenc, smwavset, smtool, imiscutter y smsampleedit, pero sminstbuilder hace que el proceso de construir un instrumento sea mucho más conveniente.

La idea principal es tener un directorio por instrumento, y en cada directorio un archivo llamado "config". Todo lo que sminstbuilder necesita saber sobre el instrumento va en el archivo "config". Los comandos se documentan a continuación en la sección CONFIG.

OPCIONES

sminstbuilder toma una lista de uno o más directorios de instrumentos como entrada. Cada instrumento necesita tener un archivo "config".

CONFIGURACIÓN DEL CONSTRUCTOR

sminstbuilder lee el archivo "sminstbuilder.cfg" al inicio. Este archivo contiene opciones no específicas del instrumento. Estas son:

caché 0/1
Mientras se construyen instrumentos, puede ser necesario codificar la misma muestra una y otra vez (mientras se cambian otros parámetros). Dado que smenc es lento, esto puede llevar mucho tiempo. Si caché está configurado en 1, sminstbuilder usará smenccache para codificar, y si la misma muestra fue codificada previamente, el resultado se tomará de ~/.smenccache, lo cual es mucho más rápido que volver a ejecutar smenc.
trabajos n_trabajos
Dado que la codificación es costosa, distribuir los trabajos del codificador en CPUs multinúcleo suele ser deseable. Si tienes una CPU multinúcleo, configura n_trabajos al número de núcleos (es decir, 1 para un solo núcleo, 2 para doble núcleo, ...)
dir-salida directorio
Después de construir un instrumento con éxito, sminstbuilder copiará el instrumento a este directorio. Debe especificarse usando una ruta absoluta (no una ruta relativa).

CONFIG

bucle-automatico <porcentaje>
Establece un bucle de un fotograma que comienza y termina en el mismo punto (dado por <porcentaje>).
afinacion-automatica
Afinar el instrumento usando los datos del (40%..60%) para extraer la frecuencia real.
volumen-automatico <porcentaje>
Normalizar el volumen del audio, usando el volumen alrededor de <porcentaje> como referencia.
volumen-automatico-desde-bucle
Normalizar el volumen del audio, usando el volumen de la parte en bucle como referencia.
cortar
dir
Establecer el directorio de datos relativo al directorio del instrumento.
muestra <nota-midi> <nombre-archivo>
Añadir una muestra del archivo <nombre-archivo> al instrumento. La <nota-midi> debe configurarse a la nota que se grabó, como un número entre 0 y 127.
muestras <nota-midi-inicio> <nota-midi-fin>
Añadir un conjunto de muestras al instrumento. Los archivos de muestra deben llamarse nota-<N>.wav, donde <N> es la nota midi, contando desde <nota-midi-inicio> hasta <nota-midi-fin>.
establecer-marcadores
Establecer marcadores desde el archivo de marcadores.
afinar-todos-los-fotogramas
Afinar cada fotograma del instrumento. Esto descartará cambios mínimos en la frecuencia que son normales para la mayoría de los instrumentos, por lo que podría sonar artificial.
