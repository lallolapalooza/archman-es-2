SMFREC(1) Manual de Comandos Generales SMFREC(1)

NOMBRE

smfrec — grabar un archivo MIDI estándar

SINOPSIS

smfrec [-amxy] [-g compás] [-d nombre_dispositivo] [-i nombre_dispositivo] archivo_midi

DESCRIPCIÓN

La utilidad smfrec graba un archivo MIDI. Puede añadir eventos grabados encima de un archivo MIDI existente. Para detener la ejecución, envíe una señal de interrupción a smfrec (por ejemplo, presionando control ^C en la terminal). Las opciones son las siguientes:

-a
Modo añadir. Reproduce el archivo MIDI dado y le añade una nueva pista que contiene los eventos grabados.
-m
Usar metrónomo.
-x
Sincronizar con el dispositivo midi(4) predeterminado en lugar de usar una fuente de reloj interna.
-y
Enviar información de temporización MIDI al dispositivo predeterminado. Útil si es un secuenciador MIDI esclavo.
-g compás
Iniciar la reproducción y grabación en el número de compás dado.
-d nombre_archivo
Dispositivo midi(4) predeterminado desde el cual grabar y al cual enviar eventos MIDI. Si no se especifica, se utilizará el contenido de la variable de entorno MIDIDEV en su lugar.
-i nombre_archivo
Dispositivo midi(4) de entrada alternativo. Los eventos de voz (notas, controladores, etc.) recibidos en el dispositivo de entrada se grabarán y se enviarán tal cual al dispositivo predeterminado. Sin esta bandera, se utilizará el dispositivo predeterminado para la entrada.

La utilidad smfrec es una interfaz para midish(1). Si se necesitan funcionalidades más específicas, el usuario puede considerar usar midish(1).

EJEMPLOS

Lo siguiente reproducirá mysong.mid y le añadirá eventos grabados desde el dispositivo /dev/rmidi4; se usará el metrónomo.

$ smfrec -a -m -d /dev/rmidi4 mysong.mid
