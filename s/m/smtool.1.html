NOMBRE

smtool - herramienta para mostrar/cambiar datos de SpectMorph desde archivos .sm/.smset

SINOPSIS

smtool <archivo_sm>|<archivo_smset> <comando> [ <argumentos_específicos_del_comando> ]

DESCRIPCIÓN

smtool es un programa de propósito general que puede realizar operaciones en archivos .sm/.smset. Algunas de las operaciones extraen datos (como size), otras modifican datos (como auto-tune). Si se proporciona un archivo .smset como argumento, la operación se realiza en los archivos .sm individuales que se encuentran en el archivo .smset.

OPCIONES

Las opciones de smtool dependen del comando utilizado, los argumentos específicos del comando se enumeran a continuación.

COMANDOS

volumen <porcentaje>
Calcula la energía promedio de los datos de audio alrededor del <porcentaje>.
frecuencia-fundamental
Muestra la frecuencia fundamental de los datos de audio.
frecuencia-mezcla
Muestra la frecuencia de mezcla (tasa de muestreo) de los datos de audio.
valores-cero-al-inicio
Muestra la propiedad zero-values-at-start de los datos de audio.
ataque
Muestra los parámetros de ataque de los datos de audio.
tamaño
Muestra un resumen del tamaño en bytes de las diferentes partes de los datos de audio.
parámetros-bucle
Muestra los parámetros de bucle de los datos de audio.
parámetros-ruido <numero_frame>
Muestra el componente de ruido de un frame de los datos de audio.
frame <numero_frame>
Muestra las muestras originales y las muestras reconstruidas para un frame de los datos de audio.
parámetros-frame <numero_frame>
Muestra las frecuencias/magnitudes de un frame de los datos de audio.
ruido-total
Suma todos los parámetros de ruido de todos los frames de los datos de audio.
prueba-nan
Verifica el contenido de todos los datos de los frames en busca de NaNs.
muestras-originales
Muestra las muestras originales de los datos de audio.
freq <freq_min> <freq_max>
Muestra todas las entradas de frecuencia de los datos de audio en el rango especificado.
espectro <numero_frame>
Compara el espectro original y reconstruido para un frame dado.
bucle-auto <porcentaje>
Establece un bucle de un frame que comienza y termina en el mismo punto (dado por <porcentaje>).
bucle-cola
Repite los datos de audio al final utilizando un bucle de un frame.
sintonizacion-auto
Ajusta el instrumento utilizando los datos (40%..60%) para extraer la frecuencia real.
sintonizar-todos-los-frames
Ajusta cada frame del instrumento. Esto descartará cambios mínimos en la frecuencia que son normales en la mayoría de los instrumentos, por lo que podría sonar artificial.
volumen-auto <porcentaje>
Normaliza el volumen del audio, utilizando el volumen alrededor del <porcentaje> como referencia.
volumen-auto-desde-bucle
Normaliza el volumen del audio, utilizando el volumen de la parte en bucle como referencia.
