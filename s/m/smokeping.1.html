NOMBRE

smokeping - Herramienta de línea de comandos para SmokePing

SINOPSIS

smokeping [ --email | --makepod | --version | --restart ]

Opciones:
--man[=x]    Mostrar la página man del programa (o de la sonda x, si se especifica)
--help       Ayuda :-)
--email      Enviar Agentes SmokePing a todos los Destinos marcados como DYNAMIC
--config=x   Usar un archivo de configuración diferente al predeterminado
--check      Solo verificar la sintaxis del archivo de configuración, no iniciar el demonio
--makepod[=x] Crear documentación POD en el archivo de configuración (o para la sonda x, si se especifica)
--version    Mostrar la versión de SmokePing
--debug      Ejecutar solo una vez y no bifurcar
--debug-daemon Iniciar el demonio con la depuración activada
--restart    Reiniciar SmokePing
--reload     Recargar la configuración en el proceso en ejecución sin interrumpir
             ninguna sonda
--nodaemon    No demonizar el proceso (no bifurcar)
--filter=x   Solo medir las entradas que pasan el filtro x
--logfile=x    Añadir advertencias al archivo de registro x.
--static[=x] Genera un sitio web estático en el directorio x. Si x se omite,
             se usa pagedir de la configuración.
--nosleep    Para depuración, puede que desees ejecutar SmokePing sin intervalo de espera
--gen-examples Generar el documento smokeping_examples y archivos de configuración de ejemplo
               (para ser usado al construir dentro de la distribución de smokeping)
               Con --check : verificar la sintaxis de los ejemplos generados.
--master-url=s Ejecutar smokeping en modo esclavo. Conectarse al maestro para la configuración.
--slave-name=s Por defecto, el esclavo usará lo que crea que es su nombre
               al comunicarse con su maestro. En algunos casos, probablemente
               desearás anular esto.
--shared-secret=s Archivo que contiene el secreto compartido para comunicarse con el servidor.
--cache-dir=s Directorio para el almacenamiento temporal de datos al ejecutarse en modo esclavo.
--pid-dir=s Directorio para el archivo PID al ejecutarse en modo esclavo.
            (opcional, por defecto es --cache-dir)

DESCRIPCIÓN

La herramienta smokeping es la parte de línea de comandos del sistema SmokePing. Su función principal es ejecutarse como un demonio y enviar pings a todos los Destinos que hayas especificado en el archivo de Configuración. Cuando llamas a smokeping sin argumentos, se iniciará como un demonio y hará su trabajo.

Si se llama con un argumento, se pueden activar funciones adicionales, como se ve en la Sinopsis anterior. La función --email se explica en la documentación del archivo de configuración.

La opción --filter te permite ejecutar el demonio con un archivo de configuración grande, pero con el archivo de configuración filtrado y solo midiendo las entradas que pasan el filtro. Esto es útil para mediciones remotas. Ejecuta Smokeping con dos filtros exclusivos en dos ubicaciones y haz rsync de los rrds de vuelta al servidor web donde ejecutas el cgi. Los filtros actúan sobre los nombres de sección en el archivo de configuración. Múltiples nombres de sección se concatenan con / como nombres de ruta:

*** targets ***
+ A
....
+ B
...
++ C

Esto da

/A

y

/B, /B/C

Si quiero monitorear /A, mi filtro se vería así:

--filter=/A

Los filtros siguen la sintaxis de expresiones regulares. Siempre están anclados en la punta de la cadena. Añadiendo un ! al principio de la cadena del filtro lo niegas. Las entradas coincidentes se excluirán del monitoreo. Se pueden usar múltiples argumentos --filter para ensamblar filtros complejos:

--filter=/A --filter=/B

incluiría todos los destinos

--filter=/A --filter=/B --filter=!/B/C

incluiría todo excepto /B/C.

--makepod se utiliza internamente para producir la documentación del archivo de configuración de SmokePing.

Por favor, consulta el documento de instalación para obtener instrucciones detalladas de configuración.

INSTALACIÓN

Al instalar SmokePing, este archivo debe ajustarse a tu sistema local. Se deben introducir tres rutas.

Una que apunte a tu instalación de rrdtool

use lib qw(/usr/pack/rrdtool-1.0.33-to/lib/perl);

Una que apunte al lugar donde has instalado las bibliotecas de SmokePing

use lib qw(/home/oetiker/public_html/smokeping/lib);

La tercera ruta es el argumento para el comando Smokeping::main. Apunta al archivo de configuración de SmokePing.

use Smokeping;
Smokeping::main("/home/oetiker/.smokeping/config");
