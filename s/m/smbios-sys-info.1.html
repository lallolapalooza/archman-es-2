Paquete: libsmbios

Licencias: GPL, custom

SMBIOS-SYS-INFO(1) Comandos de usuario SMBIOS-SYS-INFO(1)

NOMBRE

smbios-sys-info - ../src/bin/smbios-sys-info

SINOPSIS

smbios-sys-info

OPCIONES

--version
muestra el número de versión del programa y sale
-h, --help
muestra este mensaje de ayuda y sale
--service-tag
Muestra o establece la etiqueta de servicio
--asset-tag
Muestra o establece la etiqueta de activo
--property-tag
Muestra o establece la etiqueta de propiedad
--set=SET
Establece la etiqueta especificada a un nuevo valor
-v, --verbose
Muestra una salida más detallada.
-q, --quiet
Minimiza la salida del programa. Solo se muestran errores y advertencias.
--trace
Habilita el rastreo detallado de funciones.
--logconfig=LOGCONFIG
Especifica un registro de configuración alternativo.
--password=PASSWORD
Contraseña de configuración de la BIOS para operaciones de establecimiento/activación.
-r, --rawpassword
No convierte automáticamente la contraseña a códigos de escaneo.
--memory-dat=MEMORY_DAT
Ruta a un archivo de volcado de memoria para usar en lugar de la RAM real
--cmos-dat=CMOS_DAT
Ruta a un archivo de volcado de CMOS para usar en lugar del CMOS real

VER TAMBIÉN

La documentación completa de smbios-sys-info se mantiene como un manual de Texinfo. Si los programas info y smbios-sys-info están correctamente instalados en su sitio, el comando

info smbios-sys-info

debería darle acceso al manual completo.
