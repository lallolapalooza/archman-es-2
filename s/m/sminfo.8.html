sminfo(8) Diagnósticos de Open IB sminfo(8)

Nombre

sminfo - consultar el atributo SMInfo de InfiniBand

SINOPSIS

sminfo [opciones] sm_lid | sm_dr_path [modificador]

DESCRIPCIÓN

Opcionalmente, establece y muestra la salida de una consulta sminfo en formato legible para humanos. La SM de destino es la que aparece en la información del puerto local, o la SM especificada por el lid SM opcional o por la ruta de enrutamiento directo de la SM.

Nota: utilizar sminfo para cualquier propósito que no sea una consulta simple puede ser muy peligroso y resultar en un mal funcionamiento de la SM de destino.

OPCIONES

-s, --state <estado> establece el estado de la SM
0 inactivo

1 descubriendo

2 en espera

3 maestro

-p, --priority <prioridad> establece la prioridad (0-15)

-a, --activity <valor> establece el contador de actividad

Banderas de dirección

-D, --Direct La dirección especificada es una ruta directa

Ejemplos:
   [opciones] -D [opciones] "0"          # puerto propio
   [opciones] -D [opciones] "0,1,2,1,4"  # salida a través del puerto 1, luego 2, ...
   (Nota: el segundo número en la ruta especificada debe coincidir con el puerto que se
   está utilizando. Esto se puede especificar usando la bandera de selección de puerto '-P' o el
   puerto encontrado a través del proceso de selección automática.)

-G, --Guid La dirección especificada es un GUID de puerto

-L, --Lid La dirección especificada es un LID

Banderas de selección de puerto

-C, --Ca <nombre_ca> usa el nombre_ca especificado.

-P, --Port <puerto_ca> usa el puerto_ca especificado.

Selección de puerto local

Soporte de múltiples puertos/múltiples CA: cuando no se especifica ningún dispositivo o puerto IB (ver los "parámetros umad locales" a continuación), la biblioteca libibumad selecciona el puerto a utilizar según los siguientes criterios:

1.
el primer puerto que está ACTIVO.
2.
si no se encuentra, el primer puerto que está ARRIBA (enlace físico activo).

Si se especifica un nombre de puerto y/o CA, la biblioteca libibumad intenta cumplir la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                 # usa el primer puerto (criterio n.º 1 anterior)
ibaddr -C mthca1       # elige el mejor puerto solo de "mthca1".
ibaddr -P 2            # usa el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usa solo el puerto especificado.

Banderas de depuración

-d
aumenta el nivel de depuración de IB. Se puede usar varias veces (-ddd o -d -d -d).
-e
muestra errores de envío y recepción (tiempos de espera y otros)

-h, --help muestra el mensaje de uso

-v, --verbose
aumenta el nivel de verbosidad de la aplicación. Se puede usar varias veces (-vv o -v -v -v)

-V, --version muestra la información de la versión.

Banderas de configuración

-t, --timeout <tiempo_espera_ms> anula el tiempo de espera predeterminado para los mad solicitados.

-y, --m_key <clave>
usa la M_key especificada para las solicitudes. Si se especifica un valor no numérico (como 'x'), se pedirá un valor.

--config, -z <archivo_config> Especifica un archivo de configuración alternativo.

Predeterminado: /etc/infiniband-diags/ibdiag.conf

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener más detalles.

EJEMPLOS

sminfo                  # sminfo del puerto local
sminfo 32               # muestra sminfo del lid 32
sminfo  -G 0x8f1040023  # igual pero usando dirección guid
