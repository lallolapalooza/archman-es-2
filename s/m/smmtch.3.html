programa sblat3

SBLAT3

Propósito:

!>
!> Programa de prueba para las BLAS de Nivel 3 REAL.
!>
!> El programa debe ser controlado por un archivo de datos corto. Los primeros 14 registros
!> del archivo se leen usando entrada de lista dirigida, los últimos 7 registros
!> se leen usando el formato ( A7, L2 ). Un ejemplo anotado de un archivo de datos
!> se puede obtener eliminando los primeros 3 caracteres de las siguientes 20 líneas:
!> 'sblat3.out'      NOMBRE DEL ARCHIVO DE RESUMEN DE SALIDA
!> 6                 NÚMERO DE UNIDAD DEL ARCHIVO DE RESUMEN
!> 'SBLAT3.SNAP'     NOMBRE DEL ARCHIVO DE SALIDA DE INSTANTÁNEA
!> -1                NÚMERO DE UNIDAD DEL ARCHIVO DE INSTANTÁNEA (NO USADO SI .LT. 0)
!> F        INDICADOR LÓGICO, T PARA REBOBINAR EL ARCHIVO DE INSTANTÁNEA DESPUÉS DE CADA REGISTRO.
!> F        INDICADOR LÓGICO, T PARA DETENERSE ANTE FALLOS.
!> T        INDICADOR LÓGICO, T PARA PROBAR LAS SALIDAS DE ERROR.
!> 16.0     VALOR UMBRAL DE LA RELACIÓN DE PRUEBA
!> 6                 NÚMERO DE VALORES DE N
!> 0 1 2 3 5 9       VALORES DE N
!> 3                 NÚMERO DE VALORES DE ALPHA
!> 0.0 1.0 0.7       VALORES DE ALPHA
!> 3                 NÚMERO DE VALORES DE BETA
!> 0.0 1.0 1.3       VALORES DE BETA
!> SGEMM  T PARA NO PROBAR. MISMAS COLUMNAS.
!> SSYMM  T PARA NO PROBAR. MISMAS COLUMNAS.
!> STRMM  T PARA NO PROBAR. MISMAS COLUMNAS.
!> STRSM  T PARA NO PROBAR. MISMAS COLUMNAS.
!> SSYRK  T PARA NO PROBAR. MISMAS COLUMNAS.
!> SSYR2K T PARA NO PROBAR. MISMAS COLUMNAS.
!> SGEMMTR T PARA NO PROBAR. MISMAS COLUMNAS.
!>
!> Detalles Adicionales
!> ===================
!>
