NOMBRE

smokeping_cgi - Interfaz web de SmokePing

DESCRIPCIÓN GENERAL

Este script actúa como un "sitio web" para tu operación de monitoreo SmokePing. Presenta los objetivos que estás supervisando en una estructura de árbol y dibuja gráficos según lo requieren las personas que visitan las páginas.

DESCRIPCIÓN

Para poner en funcionamiento smokeping_cgi, necesitas un servidor web que te permita ejecutar scripts CGI o, mejor aún, FastCGI. El sistema debe configurarse de manera que al proceso cgi se le permita escribir en el área de caché de imágenes definida en el archivo de configuración.

Este script funciona bien como un CGI normal, PERO parecerá muy lento, porque realiza muchas acciones al iniciarse. Por lo tanto, si el script tiene que iniciarse desde cero en cada clic, esto es lento y exigente para tu servidor web. Por ello, recomiendo encarecidamente el uso de FastCGI.

Consulta el documento de instalación para obtener instrucciones detalladas de configuración.

CONFIGURACIÓN

Hay un directorio de ejemplo htdocs en la raíz de tu instalación de smokeping. Copia su contenido al lugar donde tu servidor web espera sus archivos. El script fcgi muestra el método preferido para ejecutar smokeping. También puedes ejecutar smokeping como un cgi. Pero asegúrate de utilizar el script envoltorio, ya que exponer ARGV al servidor web representa una vulnerabilidad de seguridad con la que es mejor no tener que lidiar.

Ajusta las rutas en el script y deberías estar listo para empezar.
