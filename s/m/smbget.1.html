SMBGET(1) Comandos de usuario SMBGET(1)

NOMBRE

smbget - utilidad similar a wget para descargar archivos a través de SMB

SINOPSIS

smbget [-a, --guest] [-r, --resume] [--recursive] [-D, --dots] [-o, --outputfile] [-q, --quiet] [-v, --verbose] [-b, --blocksize] [-O, --stdout] [-u, --update] [-e, --encrypt] [--limit-rate=INT] [-?|--help] [--usage] [-d|--debuglevel=DEBUGLEVEL] [--debug-stdout] [-s|--configfile=CONFIGFILE] [--option=name=value] [-l|--log-basename=LOGFILEBASE] [--leak-report] [--leak-report-full] [-R|--name-resolve=NAME-RESOLVE-ORDER] [-O|--socket-options=SOCKETOPTIONS] [-m|--max-protocol=MAXPROTOCOL] [-n|--netbiosname=NETBIOSNAME] [--netbios-scope=SCOPE] [-W|--workgroup=WORKGROUP] [--realm=REALM] [-U|--user=[DOMAIN/]USERNAME%[PASSWORD]] [-N|--no-pass] [--password=STRING] [--pw-nt-hash] [-A|--authentication-file=FILE] [-P|--machine-pass] [--simple-bind-dn=DN] [--use-kerberos=desired|required|off] [--use-krb5-ccache=CCACHE] [--use-winbind-ccache] [--client-protection=sign|encrypt|off] [-V|--version] {smb://host/share/path/to/file} [smb://url2/] [...]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de herramientas samba(7).

smbget es una utilidad simple con semántica similar a wget, que puede descargar archivos desde servidores SMB. Puede especificar los archivos que desea descargar en la línea de comandos.

Los archivos deben seguir el estándar de URL SMB, por ejemplo, utilice smb://host/share/file para la ruta UNC \\\\HOST\\SHARE\\file.

OPCIONES

-a, --guest

Actuar como usuario invitado

-r, --resume

Reanudar automáticamente los archivos abortados

--recursive

Descargar archivos recursivamente

-D, --dots

Mostrar puntos como indicación de progreso

-o, --outputfile

Escribir el archivo que se está descargando en el archivo especificado. No se puede usar junto con -R.

--stdout

Escribir el archivo que se está descargando en la salida estándar.

-q, --quiet

Ser silencioso

-v, --verbose

Ser detallado

-b, --blocksize

Número de bytes a descargar en un bloque. Por defecto es 64000.

-u, --update

Descargar solo cuando el archivo remoto es más reciente que el archivo local o el archivo local falta.

-e, --encrypt

Habilitar cifrado SMB.

--limit-rate=INT

Limitar la velocidad de descarga a esta cantidad de KB/s.

-?|--help

Imprimir un resumen de las opciones de la línea de comandos.

--usage

Mostrar un mensaje de uso breve.

-d|--debuglevel=level

level es un entero de 0 a 10. El valor por defecto si no se especifica este parámetro es 1 para aplicaciones cliente.

Cuanto mayor sea este valor, más detalles se registrarán en los archivos de registro sobre las actividades del servidor. En el nivel 0, solo se registrarán errores críticos y advertencias graves. El nivel 1 es un nivel razonable para el uso diario: genera una pequeña cantidad de información sobre las operaciones realizadas.

Los niveles superiores a 1 generarán una cantidad considerable de datos de registro y solo deben usarse al investigar un problema. Los niveles superiores a 3 están diseñados para ser utilizados únicamente por desarrolladores y generan ENORMES cantidades de datos de registro, la mayor parte de los cuales es extremadamente críptica.

Tenga en cuenta que especificar este parámetro aquí anulará el parámetro log level en el archivo /etc/samba/smb.conf.

--debug-stdout

Esto redirigirá la salida de depuración a STDOUT. Por defecto, todos los clientes registran en STDERR.

--configfile=<archivo de configuración>

El archivo especificado contiene los detalles de configuración requeridos por el cliente. La información de este archivo puede ser general para cliente y servidor o solo proporcionar opciones específicas del cliente, como client smb encrypt. Consulte /etc/samba/smb.conf para más información. El nombre del archivo de configuración por defecto se determina en el momento de la compilación.

--option=<nombre>=<valor>

Establezca la opción smb.conf(5) "<nombre>" con el valor "<valor>" desde la línea de comandos. Esto anula los valores predeterminados compilados y las opciones leídas del archivo de configuración. Si un nombre o valor incluye un espacio, envuelva todo --option=name=value entre comillas.

-l|--log-basename=directorio de registro

Nombre base del directorio para los archivos de registro/depuración. La extensión ".progname" se añadirá (por ejemplo, log.smbclient, log.smbd, etc.). El cliente nunca elimina el archivo de registro.

--leak-report

Habilitar el informe de fugas de talloc al salir.

--leak-report-full

Habilitar el informe completo de fugas de talloc al salir.

-V|--version

Imprime el número de versión del programa.

-R|--name-resolve=ORDEN-RESOLUCION-NOMBRES

Esta opción se utiliza para determinar qué servicios de nombres y en qué orden resolver nombres de host a direcciones IP. La opción toma una cadena separada por espacios de diferentes opciones de resolución de nombres. Lo mejor es envolver todo --name-resolve=ORDEN-RESOLUCION-NOMBRES entre comillas.

Las opciones son: "lmhosts", "host", "wins" y "bcast". Hacen que los nombres se resuelvan de la siguiente manera:

•lmhosts: Busca una dirección IP en el archivo lmhosts de Samba. Si la línea en lmhosts no tiene un tipo de nombre asociado al nombre NetBIOS (consulte lmhosts(5) para más detalles), entonces cualquier tipo de nombre coincide para la búsqueda.
•host: Realiza una resolución estándar de nombre de host a dirección IP, utilizando las búsquedas del sistema /etc/hosts, NIS o DNS. Este método de resolución de nombres depende del sistema operativo, por ejemplo, en IRIX o Solaris puede ser controlado por el archivo /etc/nsswitch.conf). Tenga en cuenta que este método solo se usa si el tipo de nombre NetBIOS que se consulta es el tipo de nombre 0x20 (servidor), de lo contrario se ignora.
•wins: Consulta un nombre con la dirección IP listada en el parámetro wins server. Si no se ha especificado ningún servidor WINS, este método se ignorará.
•bcast: Realiza una transmisión en cada una de las interfaces locales conocidas listadas en el parámetro interfaces. Este es el menos confiable de los métodos de resolución de nombres, ya que depende de que el host de destino esté en una subred conectada localmente.
Si este parámetro no se establece, se utilizará el orden de resolución de nombres definido en el parámetro del archivo /etc/samba/smb.conf (name resolve order).

El orden por defecto es lmhosts, host, wins, bcast. Sin este parámetro o cualquier entrada en el parámetro name resolve order del archivo /etc/samba/smb.conf, los métodos de resolución de nombres se intentarán en este orden.

-O|--socket-options=SOCKETOPTIONS

Opciones de socket TCP para establecer en el socket del cliente. Consulte el parámetro de opciones de socket en la página del manual de /etc/samba/smb.conf para ver la lista de opciones válidas.

-m|--max-protocol=MAXPROTOCOL

El valor del parámetro (una cadena) es el nivel de protocolo más alto que será admitido por el cliente.

Tenga en cuenta que especificar este parámetro aquí anulará el parámetro client max protocol en el archivo /etc/samba/smb.conf.

-n|--netbiosname=NETBIOSNAME

Esta opción permite anular el nombre NetBIOS que Samba utiliza para sí mismo. Esto es idéntico a establecer el parámetro netbios name en el archivo /etc/samba/smb.conf. Sin embargo, una configuración en la línea de comandos tendrá prioridad sobre la configuración en /etc/samba/smb.conf.

--netbios-scope=SCOPE

Esto especifica un ámbito NetBIOS que nmblookup utilizará para comunicarse al generar nombres NetBIOS. Para obtener detalles sobre el uso de ámbitos NetBIOS, consulte rfc1001.txt y rfc1002.txt. Los ámbitos NetBIOS se utilizan *muy* raramente, solo establezca este parámetro si usted es el administrador del sistema a cargo de todos los sistemas NetBIOS con los que se comunica.

-W|--workgroup=WORKGROUP

Establece el dominio SMB del nombre de usuario. Esto anula el dominio por defecto, que es el dominio definido en smb.conf. Si el dominio especificado es el mismo que el nombre NetBIOS del servidor, hace que el cliente inicie sesión utilizando el SAM local del servidor (en contraposición al SAM de Dominio).

smbget(1) — Arch Linux man pages

NAME

smbget — command line client to retrieve files from an SMB server

SYNOPSIS

smbget [-a|--append] [-r|--recursive] [-R|--rescan] [-f|--force] [-n|--no-traverse] [-p|--progress] [-R|--resume] [-v|--verbose] [-w|--wait] [-h|--help] [-V|--version] [-l|--list] [-t|--traverse] [-O|--offset] [-u|--subdirs] [-b|--blocksize BLOCKSIZE] [-N|--no-pass] [--password PASSWORD] [--pw-nt-hash] [-U|--user [DOMAIN\\]USERNAME[%PASSWORD]] [-r|--realm REALM] [-A|--authentication-file FILENAME] [-P|--machine-pass] [--simple-bind-dn DN] [--use-kerberos desired|required|off] [--use-krb5-ccache CCACHE] [--use-winbind-ccache] [--client-protection sign|encrypt|off] URL...

DESCRIPTION

smbget is a command line client to retrieve files from an SMB server.

It supports the following transfer modes:

--progress
Shows progress during transfer.
--resume
Resume interrupted transfers.
--recursive
Recursively copy directories.
--no-traverse
Do not traverse directories.
--wait
Wait for connection.
--list
List files. If a directory is specified, then the contents of the directory will be listed. If a file is specified, then the file will be listed.
--traverse
Traverse directories.
--subdirs
Traverse subdirectories.

OPTIONS

-a|--append

Append to existing files.

-r|--recursive

Recursively copy directories.

-R|--rescan

Rescan files.

-f|--force

Overwrite existing files without prompting.

-n|--no-traverse

Do not traverse directories.

-p|--progress

Show progress indicator.

-R|--resume

Resume interrupted transfers.

-v|--verbose

Turn on verbosity.

-w|--wait

Wait for connection.

-h|--help

Print a summary of options.

-V|--version

Print Samba version.

-l|--list

List files.

-t|--traverse

Traverse directories.

-O|--offset

Seek to offset.

-u|--subdirs

Traverse subdirectories.

-b|--blocksize BLOCKSIZE

Set blocksize.

-r|--realm=REALM

Set the realm for the domain.

Note that specifying this parameter here will override the realm parameter in the /etc/samba/smb.conf file.

-U|--user=[DOMAIN\]USERNAME[%PASSWORD]

Sets the SMB username or username and password.

If %PASSWORD is not specified, the user will be prompted. The client will first check the USER environment variable (which is also permitted to also contain the password separated by a %), then the LOGNAME variable (which is not permitted to contain a password) and if either exists, the value is used. If these environmental variables are not found, the username found in a Kerberos Credentials cache may be used.

A third option is to use a credentials file which contains the plaintext of the username and password. This option is mainly provided for scripts where the admin does not wish to pass the credentials on the command line or via environment variables. If this method is used, make certain that the permissions on the file restrict access from unwanted users. See the -A for more details.

Be cautious about including passwords in scripts or passing user-supplied values onto the command line. For security it is better to let the Samba client tool ask for the password if needed, or obtain the password once with kinit.

While Samba will attempt to scrub the password from the process title (as seen in ps), this is after startup and so is subject to a race.

-N|--no-pass

If specified, this parameter suppresses the normal password prompt from the client to the user. This is useful when accessing a service that does not require a password.

Unless a password is specified on the command line or this parameter is specified, the client will request a password.

If a password is specified on the command line and this option is also defined the password on the command line will be silently ignored and no password will be used.

--password

Specify the password on the commandline.

Be cautious about including passwords in scripts or passing user-supplied values onto the command line. For security it is better to let the Samba client tool ask for the password if needed, or obtain the password once with kinit.

If --password is not specified, the tool will check the PASSWD environment variable, followed by PASSWD_FD which is expected to contain an open file descriptor (FD) number.

Finally it will check PASSWD_FILE (containing a file path to be opened). The file should only contain the password. Make certain that the permissions on the file restrict access from unwanted users!

While Samba will attempt to scrub the password from the process title (as seen in ps), this is after startup and so is subject to a race.

--pw-nt-hash

The supplied password is the NT hash.

-A|--authentication-file=filename

This option allows you to specify a file from which to read the username and password used in the connection. The format of the file is: 
username = <value>
password = <value>
domain   = <value>

Make certain that the permissions on the file restrict access from unwanted users!

-P|--machine-pass

Use stored machine account password.

--simple-bind-dn=DN

DN to use for a simple bind.

--use-kerberos=desired|required|off

This parameter determines whether Samba client tools will try to authenticate using Kerberos. For Kerberos authentication you should use DNS names instead of IP addresses when connecting to a service. By default Samba client tools will try to use the default Kerberos credential cache (ccache). In case the ccache does not exist or -U|--user option was specified, clients will ask to enter a password and will obtain a Kerberos ticket (kinit) for you. If you want to use an alternative Kerberos credentical cache, use the --use-krb5-ccache option.

Note that specifying this parameter here will override the client use kerberos parameter in the /etc/samba/smb.conf file.

--use-krb5-ccache=CCACHE

Specifies the credential cache location for Kerberos authentication.

This will enforce --use-kerberos=required.

--use-winbind-ccache

Try to use the credential cache by winbind.

--client-protection=sign|encrypt|off

Sets the connection protection the client tool should use.

Note that specifying this parameter here will override the client protection parameter in the /etc/samba/smb.conf file.

In case you need more fine grained control you can use: --option=clientsmbencrypt=OPTION, --option=clientipcsigning=OPTION, --option=clientsigning=OPTION.

SMB URLS

SMB URL's should be specified in the following format:

smb://[[[domain;]user[:password@]]server[/share[/path[/file]]]]
smb:// means all the workgroups
smb://name/ means, if name is a workgroup, all the servers in this workgroup, or if name is a server, all the shares on this server.

EXAMPLES

# Recursively download 'src' directory
smbget --recursive smb://rhonwyn/jelmer/src
# Download FreeBSD ISO and enable resuming
smbget --resume smb://rhonwyn/isos/FreeBSD5.1.iso
# Recursively download all ISOs
smbget --recursive --resume smb://rhonwyn/isos
# Backup my data on rhonwyn
smbget --recursive -resume smb://rhonwyn/

BUGS

Permission denied is returned in some cases where the cause of the error is unknown (such as an illegally formatted smb:// url or trying to get a directory without --resursive turned on).
