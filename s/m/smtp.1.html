SMTP(1) Manual de comandos generales SMTP(1)

NOMBRE

smtp — Cliente del Protocolo Simple de Transferencia de Correo

SINOPSIS

smtp [-Chnv] [-a archivo_autenticacion] [-F remitente] [-H helo] [-s servidor] [-T parametros] [destinatario ...]

DESCRIPCIÓN

La utilidad smtp es un cliente del Protocolo Simple de Transferencia de Correo (SMTP) que puede usarse para ejecutar una transacción SMTP contra un servidor SMTP.

Por defecto, smtp lee el contenido del correo de la entrada estándar, establece una sesión SMTP y ejecuta una transacción SMTP para todos los destinatarios especificados. El contenido se envía sin alteraciones como datos de correo.

Las opciones son las siguientes:

-a archivo_autenticacion
Realiza un inicio de sesión antes de enviar el mensaje. El nombre de usuario y la contraseña se leen de archivo_autenticacion y deben estar en la primera y segunda línea respectivamente. Esta opción requiere un servidor servidor con TLS o STARTTLS.
-C
No se requiere que el certificado del servidor sea válido. Esta opción está obsoleta. Use “-T noverify” en su lugar.
-F remitente
Establece la ruta de retorno (MAIL FROM) para la transacción SMTP. Por defecto, usa el nombre de usuario actual.
-H helo
Define el nombre del host a anunciar (HELO) al establecer la sesión SMTP.
-h
Muestra la ayuda.
-n
No ejecuta realmente una transacción, solo intenta establecer una sesión SMTP y salir. Cuando se proporciona esta opción, no se lee ningún mensaje de la entrada estándar.
-s servidor
Especifica el servidor al que conectarse y los parámetros de conexión. El formato es [proto://[usuario:contraseña@]]host[:puerto]. Los siguientes protocolos están disponibles:
smtp
Sesión SMTP normal con STARTTLS opcional.
smtp+tls
Sesión SMTP normal con STARTTLS obligatorio.
smtp+notls
Sesión SMTP de texto plano sin TLS.
lmtp
Sesión LMTP con STARTTLS opcional.
lmtp+tls
Sesión LMTP con STARTTLS obligatorio.
lmtp+notls
Sesión LMTP de texto plano sin TLS.
smtps
Sesión SMTP con TLS forzado en la conexión.

Por defecto es “smtp://localhost:25”.

-T parametros
Establece parámetros específicos para sesiones TLS. La cadena parametros es una lista de opciones separada por comas o espacios. Las opciones disponibles son:
cafile=nombre_archivo
Usa nombre_archivo como archivo de certificados raíz en lugar del predeterminado del sistema.
ciphers=valor
Especifica los cifrados permitidos. Consulte tls_config_set_ciphers(3) para valor.
nosni
Deshabilita la Indicación de Nombre de Servidor (SNI).
noverify
No se requiere que el certificado del servidor sea válido.
protocols=valor
Especifica los protocolos a usar. Consulte tls_config_parse_protocols(3) para valor.
servername=valor
Usa valor para la Indicación de Nombre de Servidor (SNI). Por defecto, usa el nombre de host del servidor especificado.
-v
Sé más detallado. Esta opción se puede especificar varias veces.
