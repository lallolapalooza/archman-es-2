SMTPD(8) Manual del Administrador del Sistema SMTPD(8)

NOMBRE

smtpd — Demonio del Protocolo Simple de Transferencia de Correo (SMTP)

SINOPSIS

smtpd [-dFhnv] [-D macro=valor] [-f archivo] [-P sistema] [-T traza]

DESCRIPCIÓN

smtpd es un demonio del Protocolo Simple de Transferencia de Correo (SMTP) que puede ser utilizado como el sistema de correo principal de una máquina. smtpd puede escuchar en una interfaz de red y manejar transacciones SMTP; también puede recibir mensajes a través de la interfaz estándar de sendmail(8). Puede retransmitir mensajes a través de agentes de transferencia de correo remotos o almacenarlos localmente utilizando el formato mbox o maildir. Esta implementación soporta SMTP tal como se define en RFC 5321, así como varias extensiones. Un smtpd en ejecución puede ser controlado a través de smtpctl(8).

Las opciones son las siguientes:

-D macro=valor
Define que macro se establezca en valor en la línea de comandos. Anula la definición de macro en el archivo de configuración.
-d
No demonizar. Si se especifica esta opción, smtpd se ejecutará en primer plano y registrará en stderr.
-F
No demonizar. Si se especifica esta opción, smtpd se ejecutará en primer plano y registrará en syslogd(8).
-f archivo
Especificar un archivo de configuración alternativo.
-h
Mostrar versión e información de uso.
-n
Modo de prueba de configuración. Solo verificar la validez del archivo de configuración.
-P sistema
Pausar un subsistema específico al inicio. La operación normal se puede reanudar utilizando smtpctl(8). Esta opción se puede usar varias veces. Los valores aceptados son:
mda
No programar entregas locales.
mta
No programar transferencias remotas.
smtp
No escuchar en los sockets SMTP.
-T traza
Activar trazado en tiempo real al inicio. La operación normal se puede reanudar utilizando smtpctl(8). Esta opción se puede usar varias veces. Los valores aceptados son:
  • imsg
  • io
  • smtp (sesiones entrantes)
  • filters
  • transfer (sesiones salientes)
  • bounce
  • scheduler
  • expand (expansión de alias/virtual/forward)
  • lookup (búsquedas de usuario/credenciales)
  • stat
  • rules (coincididas por sesiones entrantes)
  • mproc
  • all
-v
Producir una salida más detallada.

ARCHIVOS

/etc/smtpd/mailname
Nombre alternativo del servidor a usar.
/etc/smtpd/smtpd.conf
Archivo de configuración predeterminado de smtpd.
/run/smtpd.sock
Socket de dominio UNIX utilizado para la comunicación con smtpctl(8).
/var/spool/smtpd/
Directorios de cola para el correo durante el procesamiento.
~/.forward
Información de reenvío de correo del usuario.

VER TAMBIÉN

forward(5), smtpd.conf(5), mailwrapper(8), smtpctl(8)

ESTÁNDARES

J. Klensin, Simple Mail Transfer Protocol, RFC 5321, Octubre 2008.
