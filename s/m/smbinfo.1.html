SMBINFO(1) Manual de Comandos Generales SMBINFO(1)

NOMBRE

smbinfo - Utilidad del espacio de usuario para mostrar información de archivos específica de SMB para el sistema de archivos del cliente SMB de Linux (CIFS)

SINOPSIS

smbinfo [-v] [-h] [-V] {comando} {objeto del sistema de archivos}

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de utilidades cifs-utils.

smbinfo es un programa auxiliar del espacio de usuario para el sistema de archivos del cliente SMB de Linux (CIFS). Su propósito es mostrar información de archivos específica de SMB, como Descriptores de Seguridad y Cuotas.

Esta herramienta funciona realizando una llamada IOCTL CIFS_QUERY_INFO al cliente SMB de Linux, que a su vez emite una solicitud SMB Query Info y devuelve el resultado. Esto difiere de getcifsacl, que utiliza atributos extendidos de archivos.

OPCIONES

-v
Imprime el número de versión y sale.
-V
Salida detallada.
-h
Imprime la ayuda que explica las opciones de la línea de comandos.

COMANDO

fileaccessinfo: Imprime la clase FileAccessInformation

filealigninfo: Imprime la clase FileAlignmentInformation

fileallinfo: Imprime la clase FileAllInformation

filebasicinfo: Imprime la clase FileBasicInformation

fileeainfo: Imprime la clase FileEaInformation

filefsfullsizeinfo: Imprime la clase FileFsFullSizeInformation

fileinternalinfo: Imprime la clase FileInternalInformation

filemodeinfo: Imprime la clase FileModeInformation

filepositioninfo: Imprime la clase FilePositionInformation

filestandardinfo: Imprime la clase FileStandardInformation

filestreaminfo: Imprime la clase FileStreamInformation

fsctl-getobjid: Imprime el ObjectID

getcompression: Imprime la configuración de compresión del archivo.

setcompression -c <no|default|lznt1>: Establece la configuración de compresión para el archivo.

list-snapshots: Enumera las versiones anteriores del volumen que soporta este archivo

quota: Imprime la cuota del volumen en el formato - SID Longitud - Hora de Cambio - Usado de Cuota - Umbral de Cuota - Límite de Cuota - SID

secdesc: Imprime el descriptor de seguridad en el formato - Revisión - Control - SID del Propietario - SID del Grupo - ACL - Tipos de Archivo - Banderas de Archivo

keys: Descarga el ID de sesión, las claves de cifrado y las claves de descifrado para que el tráfico SMB3 de este montaje pueda ser descifrado, por ejemplo, a través de wireshark (requiere root).

gettconinfo: Imprime tanto el ID TCON como el ID de Sesión para un archivo cifs.

NOTAS

El soporte del kernel para las utilidades smbinfo requiere la llamada IOCTL CIFS_QUERY_INFO, que se introdujo inicialmente en el kernel 4.20 y solo está implementada para puntos de montaje que utilizan SMB2 o superior (ver la opción vers en mount.cifs(8)).

VER TAMBIÉN

mount.cifs(8), getcifsacl(1)
