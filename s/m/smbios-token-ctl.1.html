Paquete: libsmbios

Licencias: GPL, custom

SMBIOS-TOKEN-CTL(1) Comandos de usuario SMBIOS-TOKEN-CTL(1)

NOMBRE

smbios-token-ctl - ../src/bin/smbios-token-ctl

SINOPSIS

smbios-token-ctl

OPCIONES

--version
mostrar la versión del programa y salir
-h, --help
mostrar este mensaje de ayuda y salir
-d, --dump-tokens
Acción: volcar tabla de tokens
--dump-tokens-csv
Acción: volcar tabla de tokens en formato CSV
--import-token-settings-csv
Acción: restaurar ajustes de tokens desde el volcado de tabla CSV
--is-string
Acción: devolver verdadero si el token especificado es una cadena.
--is-bool
Acción: devolver verdadero si el token especificado es booleano.
--is-active
Acción: devolver verdadero si el token booleano especificado está activo.
--get-string
Acción: obtener el valor del token de cadena.
--activate
Acción: activar el token booleano especificado.
--set-string
Acción: establecer el valor del token de cadena.
-i ID_TOKEN, --token-id=ID_TOKEN, --token=ID_TOKEN
Filtrar solo el token con ID.
-n NOMBRE_TOKEN, --token-name=NOMBRE_TOKEN
Filtrar solo el token con nombre.
-s AJUSTE_TOKEN, --token-setting=AJUSTE_TOKEN
Filtrar solo el token con ajuste.
--token-csv=TOKEN_CSV
ruta al archivo token.csv.
--token-blacklist-csv=TOKEN_BLACKLIST_CSV
Ruta al archivo de lista negra de tokens.
-v, --verbose
Mostrar salida más detallada.
-q, --quiet
Minimizar la salida del programa. Solo se muestran errores y advertencias.
--trace
Habilitar rastreo detallado de funciones.
--logconfig=LOGCONFIG
Especificar configuración de registro alternativa.
--password=CONTRASEÑA
Contraseña de configuración de BIOS para operaciones de ajuste/activación.
-r, --rawpassword
No convertir automáticamente la contraseña a códigos de escaneo.
--memory-dat=MEMORY_DAT
Ruta a un archivo de volcado de memoria para usar en lugar de la RAM real
--cmos-dat=CMOS_DAT
Ruta a un archivo de volcado de CMOS para usar en lugar del CMOS real

VER TAMBIÉN

La documentación completa de smbios-token-ctl se mantiene como un manual de Texinfo. Si los programas info y smbios-token-ctl están instalados correctamente en su sitio, el comando

info smbios-token-ctl

debería darle acceso al manual completo.
