NOMBRE

smfsh - Shell SMF

SINOPSIS

smfsh [ -V ] [ archivo ]

OPCIONES

-V
Imprime la versión de libsmf y sale.
archivo
Carga el archivo.

DESCRIPCIÓN

smfsh, un "shell SMF", es un frontend interactivo basado en comandos para libsmf, útil para modificar archivos MIDI manualmente. Se originó como una ayuda de depuración para libsmf.

Hay cuatro grupos de comandos: nivel SMF, nivel de pista, nivel de evento y otros.

COMANDOS DE NIVEL SMF

Los comandos de nivel SMF muestran o cambian las propiedades de smf (es decir, el archivo MIDI) en su conjunto.

save archivo
Guarda un archivo. Si no se proporciona el nombre del archivo, se utiliza el último nombre de archivo.

Tenga en cuenta que esto no pedirá confirmación.

load archivo
Carga un archivo. Si no se proporciona el nombre del archivo, se utiliza el último nombre de archivo.

En lugar de usar "load", puede pasar el nombre del archivo en la línea de comandos.

ppqn nuevo-ppqn
Muestra (si se usa sin parámetro) o cambia PPQN (Pulsos por Nota de Corchea, también conocido como División).
format nuevo-formato
Muestra (si se usa sin parámetro) o cambia el formato.
tempo
Muestra el mapa de tempo. El mapa de tempo se calcula automáticamente a partir del contenido del SMF; para modificar un tempo, simplemente agregue un evento de cambio de tempo usando el comando "add".
length
Muestra la longitud total de la canción. Al igual que el mapa de tempo, la longitud del archivo se calcula a partir del contenido del SMF.

COMANDOS DE NIVEL DE PISTA

Los comandos de nivel de pista muestran o cambian las propiedades de las pistas. SMF puede contener una o más pistas.

tracks
Muestra la lista de pistas en el SMF.
track número-de-pista
Muestra detalles de una pista (si se llama sin parámetro), o selecciona la pista con un número dado; por ejemplo, para mostrar los eventos que contiene ("events").
trackadd
Crea una nueva pista.
trackrm número-de-pista
Elimina la pista. Si no se proporciona el número de pista, se eliminará la pista actualmente seleccionada.

COMANDOS DE NIVEL DE EVENTO

Los comandos de nivel de evento muestran o cambian las propiedades de los eventos. Los eventos se agrupan en pistas. Una pista puede contener cualquier número de eventos, incluido cero.

events
Muestra la lista de eventos en la pista actual.
event número-de-evento
Muestra información sobre un evento actual (si se usa sin parámetro) o selecciona el evento.
add tiempo-en-segundos mensaje-midi-en-hex
Agrega un nuevo evento a la pista actualmente seleccionada.
rm número-de-evento
Elimina el evento. Si no se proporciona el número de evento, se eliminará el evento actualmente seleccionado.

OTROS COMANDOS

Hay tres comandos en la categoría "otros": "help", "version" y "exit". Su significado debería ser autoexplicativo.
