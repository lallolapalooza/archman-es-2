NOMBRE

smime_keys - Utilidad para añadir certificados S/MIME a la base de datos interna utilizada por neomutt

SINTAXIS

smime_keys <operación> [archivo(s) | ID de clave [archivo(s)]]

DESCRIPCIÓN

El propósito de esta herramienta es manipular la base de datos interna de certificados S/MIME utilizada por neomutt para firmar mensajes de correo que se enviarán o para verificar mensajes de correo recibidos y firmados con S/MIME.

OPCIONES

init
no se necesitan archivos, inicializa la estructura de directorios.
refresh
no se necesitan archivos. actualiza los archivos de índice, incluyendo la bandera de confianza/expiración.
list
lista los certificados almacenados en la base de datos.
label
se requiere ID de clave. cambia/elimina/añade una etiqueta.
remove
se requiere ID de clave.
verify
1=ID de clave y opcionalmente 2=CRL. Verifica la cadena de certificados y, opcionalmente, si este certificado está incluido en la CRL proporcionada (formato PEM). Nota: para verificar todos los certificados al mismo tiempo, reemplace ID de clave con "all".
add_cert
se requiere certificado.
add_chain
se requieren tres archivos: 1=Clave, 2=certificado más 3=certificado(s) intermedio(s).
add_p12
se requiere un archivo. Añade el par de claves a la base de datos. el archivo es PKCS12 (por ejemplo, exportado desde netscape).
add_pem
se requiere un archivo. Añade el par de claves a la base de datos. (el archivo se convirtió desde, por ejemplo, PKCS12).
add_root
se requiere un archivo. Añade el certificado raíz PEM a la ubicación especificada dentro de muttrc (comando smime_verify_*).
