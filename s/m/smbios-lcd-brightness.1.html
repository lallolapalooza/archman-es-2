SMBIOS-LCD-BRIGHTNESS(1) Comandos de usuario SMBIOS-LCD-BRIGHTNESS(1)

NOMBRE

smbios-lcd-brightness - ../src/bin/smbios-lcd-brightness

SINOPSIS

smbios-lcd-brightness

OPCIONES

--version
muestra el número de versión del programa y sale
-h, --help
muestra este mensaje de ayuda y sale
-v, --verbose
Muestra una salida más detallada.
-q, --quiet
Minimiza la salida del programa. Solo se muestran errores y advertencias.
--trace
Habilita el rastreo detallado de funciones.
--logconfig=LOGCONFIG
Especifica un registro de configuración alternativo.
--security-key=CLAVE_SEGURIDAD
Clave de seguridad precalculada de la BIOS.
--password=CONTRASEÑA
Contraseña de configuración de la BIOS para operaciones de configuración/activación.
-r, --rawpassword
No convertir automáticamente la contraseña a códigos de escaneo.
--memory-dat=DATOS_MEMORIA
Ruta a un archivo de volcado de memoria para usar en lugar de la RAM real
--cmos-dat=DATOS_CMOS
Ruta a un archivo de volcado de CMOS para usar en lugar del CMOS real
--value=VALOR
Establece el nuevo valor
-b, --battery
Establece el nuevo valor a usar mientras se ejecuta con la batería
-a, --ac
Establece el nuevo valor a usar mientras se ejecuta con corriente alterna
