SMTP-SOURCE(1) Manual de Comandos Generales SMTP-SOURCE(1)

NOMBRE

smtp-source - Generador de pruebas SMTP/LMTP paralelizado

SINOPSIS

smtp-source [opciones] [inet:]host[:puerto]

smtp-source [opciones] unix:ruta_acceso

DESCRIPCIÓN


smtp-source se conecta al host y puerto TCP (por defecto: puerto 25) especificados y le envía uno o más mensajes, ya sea secuencialmente o en paralelo. El programa habla tanto SMTP (por defecto) como LMTP. Las conexiones pueden realizarse a servidores de dominio UNIX e IPv4 o IPv6. IPv4 e IPv6 son las opciones por defecto.

Nota: este es un programa de prueba no soportado. No se hace ningún intento de mantener la compatibilidad entre versiones sucesivas.

Argumentos:

-4
Conéctate al servidor con IPv4. Esta opción no tiene ningún efecto cuando Postfix está compilado sin soporte IPv6.
-6
Conéctate al servidor con IPv6. Esta opción no está disponible cuando Postfix está compilado sin soporte IPv6.
-A
No abortar cuando el servidor envíe algo que no sea el código de respuesta positivo esperado.
-c
Muestra un contador en ejecución que se incrementa cada vez que se completa un comando SMTP DATA.
-C cuenta
Cuando un host envía RESET en lugar de SYN|ACK, intente cuenta veces antes de rendirse. El valor predeterminado de la cuenta es 1. Especifique un valor mayor para solucionar un problema con pilas TCP/IP que envían RESET cuando la cola de escucha está llena.
-d
No desconectar después de enviar un mensaje; envía el siguiente mensaje a través de la misma conexión.
-f remitente
Utiliza la dirección del remitente especificada (por defecto: <foo@mi-hostname>).
-F archivo
Envía la cabecera y el cuerpo del mensaje preformateados en el archivo especificado, mientras antepone '.' a las líneas que comienzan con '.', y mientras añade CRLF después de cada línea.
-l longitud
Envía longitud bytes como carga útil del mensaje. La longitud no incluye las cabeceras del mensaje.
-L
Habla LMTP en lugar de SMTP.
-m cuenta_mensaje
Envía el número especificado de mensajes (por defecto: 1).
-M mi-hostname
Utiliza el nombre de host o [dirección] especificado en el comando HELO y en las direcciones predeterminadas del remitente y destinatario, en lugar del nombre de host de la máquina.
-N
Genera cada dirección de destinatario añadiendo un número (un contador de destinatarios por proceso) a la parte local de la dirección del destinatario especificada con la opción -t.

Nota: para usar el número como una extensión de dirección, especifique un delimitador de dirección explícito al final de la parte local del destinatario, como en "-t part_local+@dominio" o "-t part_local+", donde "+" es un delimitador de dirección de destinatario de Postfix.

Beneficios:

  • Una dirección de destinatario no constante evita una tasa de aciertos de caché poco realista del 100% en los clientes del servicio trivial-rewrite de Postfix, aproximando mejor el rendimiento bajo cargas de trabajo reales.
  • Una parte local de dirección de destinatario fija con una extensión de dirección no constante evita la necesidad de configurar un gran número de direcciones de destinatario válidas en el servidor Postfix receptor.
-o
Modo antiguo: no envía HELO, y no envía cabeceras de mensaje.
-r cuenta_destinatario
Envía el número especificado de destinatarios por transacción (por defecto: 1), y genera direcciones de destinatario como se describe en la opción -N.
-R intervalo
Espera un tiempo aleatorio (0 <= n <= intervalo) entre mensajes. Suspender un hilo no afecta a otros hilos de entrega.
-s cuenta_sesion
Ejecuta el número especificado de sesiones SMTP en paralelo (por defecto: 1).
-S asunto
Envía correo con la línea de asunto especificada (por defecto: ninguna).
-t a
Utiliza la dirección del destinatario especificada (por defecto: <foo@mi-hostname>).
-T tamaño_ventana
Anula el tamaño de ventana TCP predeterminado. Para solucionar problemas de implementaciones de escalado de ventana TCP defectuosas, especifique un valor > 0 y < 65536.
-v
Hace que el programa sea más verboso, para fines de depuración.
-w intervalo
Espera un tiempo fijo entre mensajes. Suspender un hilo no afecta a otros hilos de entrega.
[inet:]host[:puerto]
Conéctate vía TCP al host host, puerto puerto. El puerto predeterminado es smtp.
unix:ruta_acceso
Conéctate al socket de dominio UNIX en ruta_acceso.

ERRORES


Sin soporte para pipelining de comandos SMTP.

VER TAMBIÉN
