NOMBRE

smokeping_install - Cómo instalar SmokePing

DESCRIPCIÓN GENERAL

Este documento explica cómo configurar SmokePing en tu sitio.

DESCRIPCIÓN

Prerrequisitos

SmokePing no funciona de forma independiente. Depende de varias otras herramientas y servicios. Además de un sistema operativo Unix y una instalación de Perl funcional, necesitas los siguientes componentes:

RRDtool 1.2.x o posterior
Smokeping utiliza RRDtool para registrar y graficar. Si tu distribución de Linux proporciona un paquete de rrdtool con soporte para Perl, úsalo. Si quieres obtener la última versión, compílala tú mismo: http://oss.oetiker.ch/rrdtool/

Ubuntu:

sudo apt install rrdtool librrds-perl libssl-dev

RedHat:

sudo yum install rrdtool perl-rrdtool openssl-devel
FPing (opcional)
Ve a http://www.fping.org/ para descargar una copia.

Ten en cuenta que fping debe estar instalado con el bit setuid root. Parece que las versiones antiguas de fping reportan tiempos de ida y vuelta en 0.1 milisegundos en lugar de 1 milisegundo como se anuncia... SmokePing intenta averiguarlo. Te lo dirá cuando empiece... hazme saber si se equivoca.

EchoPing (Opcional)
https://github.com/bortzmeyer/echoping/

Necesitas esto para ejecutar las sondas EchoPing

Curl (Opcional)
http://curl.haxx.se/

Necesitas esto para la sonda Curl.

dig (Opcional)
http://www.isc.org/sw/bind/

Necesitas esto para la sonda DNS.

SSH (Opcional)
http://www.openssh.org/

Necesitas esto para la sonda SSH.

Servidor Web
http://httpd.apache.org/

Bueno, no me extenderé mucho en esto. Lo importante es tener un servidor web que te permita ejecutar scripts CGI y preferiblemente FastCGI. Si usas Apache, recomiendo encarecidamente usar el sistema suexec para ejecutar scripts CGI como un usuario particular.

Consulta http://httpd.apache.org/mod_fcgid/mod/mod_fcgid.html y http://httpd.apache.org/docs/2.2/mod/mod_suexec.html para más información sobre esto.

Perl 5.10.1 o posterior.
Si todavía tienes una versión anterior, quizás deberías mirar perlbrew.

Ubuntu:

sudo apt install perl

RedHat:

sudo yum install perl-core

Instalación

Una vez que las herramientas mencionadas anteriormente estén en su lugar, puedes empezar a configurar SmokePing. Descomprime el archivo tar y ejecuta el script de configuración incluido:

./configure --prefix=/opt/smokeping

Configure verificará que todos los módulos de Perl requeridos estén disponibles. Si falta alguno, te indicará que ejecutes el script de construcción del módulo. Simplemente sigue las instrucciones en pantalla y luego vuelve a ejecutar configure. Una vez que complete, puedes ejecutar

make install

para finalizar tu configuración.

Configuración

Utiliza el archivo etc/config.dist como plantilla para crear tu propio archivo de configuración de smokeping. Consulta smokeping_config para más detalles.

Instalación de la interfaz web
Copia el contenido del directorio PREFIX/htdocs al lugar donde tu servidor web espera sus datos. Quizás a /var/www/smokeping.

Edita el script smokeping.fcgi para que apunte a tu script smokeping_cgi.

Si no tienes soporte FastCGI en tu servidor web, es posible que desees usar el script smokeping.cgi.

etc/basepage.html
Edita la plantilla HTML a tu gusto. Por favor, no elimines el enlace al contador de SmokePing y mi nombre de la plantilla. El contenido de la plantilla será renderizado por smokeping.cgi. Esto significa que todos los enlaces incrustados deben ser relativos a smokeping.cgi. Si estás usando autenticación HTTP, entonces la variable de plantilla "authuser" se poblará a partir de la variable de entorno $ENV{REMOTE_USER}.
etc/smokemail
Si vas a usar el soporte de IP DINÁMICO, personaliza el contenido de este archivo.

Inicio del Demonio SmokePing

Con toda la estructura en su lugar, ahora puedes iniciar el demonio smokeping y hacer que recopile datos para ti. Primero, puede que quieras ejecutarlo en modo de depuración para ver qué está haciendo

./bin/smokeping --config=/opt/smokeping/etc/config --debug

una vez que todo esté bien, inícialo como demonio. Te recomiendo que habilites la opción de archivo de registro para que puedas ver si encuentra algún problema.

./bin/smokeping --config=/opt/smokeping/etc/config --logfile=smoke.log

Una vez que el sistema funcione, es posible que quieras poner un script de inicio de SmokePing en tu árbol /etc/init.d. Consulta smokeping para obtener más información.

Ahora puedes abrir la página web smokeping.cgi para ver tus datos.

Consulta la documentación de smokeping_cgi sobre cómo configurar la interfaz web de smokeping.
