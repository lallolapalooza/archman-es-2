smbios-wireless-ctl(1)

Paquete: libsmbios

Licencias: GPL, custom

SMBIOS-WIRELESS-CTL(1) Comandos de usuario SMBIOS-WIRELESS-CTL(1)

NOMBRE

smbios-wireless-ctl - ../src/bin/smbios-wireless-ctl

SINOPSIS

smbios-wireless-ctl

OPCIONES

--version
muestra el número de versión del programa y sale
-h, --help
muestra este mensaje de ayuda y sale
--info
Muestra la configuración inalámbrica (por defecto)
--boot
Establece la configuración de arranque de la BIOS.
--no-boot
No establece la configuración de arranque de la BIOS.
--runtime
Establece la configuración en tiempo de ejecución de la BIOS (por defecto).
--no-runtime, --boot-only, --boot_only
No establece la configuración en tiempo de ejecución de la BIOS.
--wlan=WLAN
Establece el estado de la radio en tiempo de ejecución para LAN inalámbrica
--bt=BT
Establece el estado de la radio en tiempo de ejecución para Bluetooth
--wwan=WWAN
Establece el estado de la radio en tiempo de ejecución para celular (WAN inalámbrica)
--uwb=UWB
Establece el estado de la radio en tiempo de ejecución para UWB
--wigig=WIGIG
Establece el estado de la radio en tiempo de ejecución para WiGig
--sw_wlan=SW_WLAN
Establece el interruptor de hardware para que controle la radio de LAN inalámbrica
--sw_bt=SW_BT
Establece el interruptor de hardware para que controle la radio de Bluetooth
--sw_wwan=SW_WWAN
Establece el interruptor de hardware para que controle la radio de celular (WAN inalámbrica)
--sw_uwb=SW_UWB
Establece el interruptor de hardware para que controle la radio de UWB
--sw_wigig=SW_WIGIG
Establece el interruptor de hardware para que controle la radio de WiGig
--sw_locator=SW_LOCATOR
Habilita o deshabilita el interruptor localizador WIFI
--st_wlan
Obtiene el estado de la LAN inalámbrica. 0 = habilitado. 1 = deshabilitado. 2 = no presente. 3 = no soportado. 4 = desconocido.
--st_bt
Obtiene el estado de Bluetooth. 0 = habilitado. 1 = deshabilitado. 2 = no presente. 3 = no soportado. 4 = desconocido.
--st_wwan
Obtiene el estado de celular (WAN inalámbrica). 0 = habilitado. 1 = deshabilitado. 2 = no presente. 3 = no soportado. 4 = desconocido.
--st_uwb
Obtiene el estado de UWB. 0 = habilitado. 1 = deshabilitado. 2 = no presente. 3 = no soportado. 4 = desconocido.
--st_wigig
Obtiene el estado de WiGig. 0 = habilitado. 1 = deshabilitado. 2 = no presente. 3 = no soportado. 4 = desconocido.
--st_locator=ST_LOCATOR
Obtiene el estado del interruptor localizador
-v, --verbose
Muestra una salida más detallada.
-q, --quiet
Minimiza la salida del programa. Solo se muestran errores y advertencias.
--trace
Habilita el seguimiento detallado de funciones.
--logconfig=LOGCONFIG
Especifica un registro de configuración alternativo.
--security-key=SECURITY_KEY
Clave de seguridad precalculada por la BIOS.
--password=PASSWORD
Contraseña de configuración de la BIOS para operaciones de establecimiento/activación.
-r, --rawpassword
No convertir automáticamente la contraseña a códigos de escaneo.
--memory-dat=MEMORY_DAT
Ruta a un archivo de volcado de memoria para usar en lugar de la RAM real
--cmos-dat=CMOS_DAT
Ruta a un archivo de volcado de CMOS para usar en lugar del CMOS real
