SMBTORTURE(1) Suite de pruebas SMBTORTURE(1)

NOMBRE

smbtorture - Ejecutar una serie de pruebas contra un servidor SMB

SINOPSIS

smbtorture {//servidor/recurso_compartido} [-d nivel_depuracion] [-U usuario%contraseña] [-k] [-N num_procesos] [-n nombre_netbios] [-W grupo_trabajo] [-e num archivos(entradas)] [-O opciones_socket] [-m protocolo_maximo] [-L] [-c CLIENT.TXT] [-t tiempo_limite] [-C nombre_archivo] [-A] [-p puerto] [-s semilla] [-f fallos_maximos] [-X] {CADENA_ENLACE|UNC} {PRUEBA1} [PRUEBA2] [...]

DESCRIPCIÓN

smbtorture es una suite de pruebas que ejecuta varias pruebas contra un servidor SMB. Todas las pruebas tienen éxito contra un servidor Windows 2003 (?). El objetivo principal de Smbtorture es encontrar diferencias en las implementaciones del protocolo SMB y probar servidores SMB.

Se puede especificar cualquier número de pruebas en la línea de comandos. Si no se especifican pruebas, se ejecutan todas las pruebas.

Si no se especifican argumentos en absoluto, se listan todas las opciones y pruebas disponibles.

Formato de la cadena de enlace

El formato de la cadena de enlace es:

TRANSPORTE:host[indicadores]

Donde TRANSPORTE es ncacn_np para SMB, ncacn_ip_tcp para RPC/TCP o ncalrpc para conexiones locales.

'host' es una IP o nombre de host o nombre netbios. Si la cadena de enlace identifica el lado del servidor de un punto final, 'host' puede ser una cadena vacía.

'indicadores' pueden incluir un nombre de tubería SMB si se usa el transporte ncacn_np o un número de puerto TCP si se usa el transporte ncacn_ip_tcp, de lo contrario se determinarán automáticamente.

Otros indicadores reconocidos son:

sign

habilita la firma ntlmssp

seal

habilita el cifrado ntlmssp

connect

habilita la autenticación de nivel de conexión rpc (autenticación, pero sin firma ni cifrado)

validate

habilita el validador NDR

print

habilita la depuración de los paquetes

bigendian

usa RPC bigendian

padcheck

comprueba que los datos de respuesta no contengan bytes de relleno distintos de cero

Por ejemplo, todas estas conexiones a la tubería samr:

•ncacn_np:myservidor
•ncacn_np:myservidor[samr]
•ncacn_np:myservidor[\\pipe\\samr]
•ncacn_np:myservidor[/pipe/samr]
•ncacn_np:myservidor[samr,sign,print]
•ncacn_np:myservidor[\\pipe\\samr,sign,seal,bigendian]
•ncacn_np:myservidor[/pipe/samr,seal,validate]
•ncacn_np:
•ncacn_np:[/pipe/samr]
•ncacn_ip_tcp:myservidor
•ncacn_ip_tcp:myservidor[1024]
•ncacn_ip_tcp:myservidor[1024,sign,seal]
•ncalrpc:

Formato UNC

El formato UNC es:

//servidor/recurso_compartido

OPCIONES

-d nivel_depuracion

Usa el nivel de depuración de Samba especificado. Un nivel de depuración más alto significa más salida.

-U usuario%contraseña

Usa la combinación de nombre de usuario/contraseña especificada al iniciar sesión en un servidor remoto.

-k

Usa Kerberos al autenticarse.

-W grupo_trabajo

Usa el nombre especificado como nuestro nombre de grupo de trabajo.

-n nombre_netbios

Usa el nombre especificado como nuestro nombre NetBIOS.

-O opciones_socket

Usa las opciones de socket especificadas, equivalente a la opción smb.conf "socket options". Consulta la página del manual de smb.conf(5) para obtener más detalles.

-m protocolo_maximo

Especifica el dialecto SMB máximo que se debe usar. Los valores posibles son: CORE, COREPLUS, LANMAN1, LANMAN2, NT1

-s semilla

Inicializa el generador de números aleatorios usando semilla como semilla.

-L

Usa oplocks.

-X

Habilita pruebas peligrosas. ¡Úsalo con precaución! Esto podría bloquear tu servidor...

-t tiempo_limite

Especifica el límite de tiempo de NBENCH en segundos. El valor predeterminado es 600.

-p puertos

Especifica los puertos a los que conectarse.

-c archivo

Lee comandos NBENCH desde archivo en lugar de CLIENT.TXT.

-A

Muestra no solo OK o FALLIDO, sino una salida más detallada. Usado solo por la prueba DENY en este momento.

-C nombre_archivo

Carga una lista de nombres UNC desde el nombre de archivo especificado. Las instancias de Smbtorture se conectarán a un host aleatorio de esta lista.

-N num_procesos

Especifica el número de procesos smbtorture a lanzar.

-e num_archivos

Número de entradas a usar en ciertas pruebas (como crear X archivos) (predeterminado: 1000).

-f fallos_maximos

Número de fallos antes de abortar una prueba (predeterminado: 1).
