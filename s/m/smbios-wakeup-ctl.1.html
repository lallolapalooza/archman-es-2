SMBIOS-WAKEUP-CTL(1) Comandos de usuario SMBIOS-WAKEUP-CTL(1)

NOMBRE

smbios-wakeup-ctl - ../src/bin/smbios-wakeup-ctl

SINOPSIS

smbios-wakeup-ctl

OPCIONES

--version
muestra el número de versión del programa y sale
-h, --help
muestra este mensaje de ayuda y sale
--hour=HORA
Establece la hora de despertar. Debe ser de 0 a 23
--minute=MINUTO
Establece el minuto de despertar. Debe ser de 0 a 59
--everyday
Establece el despertar para todos los días
--weekday
Establece el despertar solo para días laborables
--disable
Desactiva los despertares
-v, --verbose
Muestra una salida más detallada.
-q, --quiet
Minimiza la salida del programa. Solo se muestran errores y advertencias.
--trace
Habilita el rastreo detallado de funciones.
--logconfig=CONFIGURACION_DEL_REGISTRO
Especifica un registro de configuración alternativo.
--password=CONTRASENA
Contraseña de configuración de la BIOS para operaciones de establecer/activar.
-r, --rawpassword
No convertir automáticamente la contraseña a códigos de escaneo.
--memory-dat=DATOS_MEMORIA
Ruta a un archivo de volcado de memoria para usar en lugar de la RAM real
--cmos-dat=DATOS_CMOS
Ruta a un archivo de volcado de CMOS para usar en lugar del CMOS real

VER TAMBIÉN

La documentación completa para smbios-wakeup-ctl se mantiene como un manual de Texinfo. Si los programas info y smbios-wakeup-ctl están instalados correctamente en su sitio, el comando

debería darle acceso al manual completo.
