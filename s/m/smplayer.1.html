NOMBRE

SMPlayer - La mejor interfaz gráfica para MPlayer

SINOPSIS

smplayer [-minigui] [-mpcgui] [-defaultgui] [-config-path <directorio>] [-send-action <nombre_accion>] [-actions <lista_acciones>] [[-no]-close-at-end] [[-no]-fullscreen] [-sub <archivo_subtitulos>] [-pos <x> <y>] [-size <ancho> <alto>] [-add-to-playlist] [-disable-server] [-help|--help|-h|-?] [<media1>] [<media2>]...

DESCRIPCIÓN

SMPlayer es un reproductor multimedia GUI basado en Qt, que utiliza mplayer(1) como backend.

OPCIONES

-minigui
Abre la GUI mini en lugar de la predeterminada.
-mpcgui
Abre la GUI mpc en lugar de la predeterminada.
-defaultgui
Abre la GUI predeterminada.
-config-path <directorio>
Especifica el directorio para los archivos de configuración (smplayer.ini, smplayer_files.ini...).
-send-action <nombre_accion>
Intenta establecer una conexión con otra instancia en ejecución y le envía la acción especificada.
Ejemplo: smplayer -send-action pause
El resto de las opciones (si las hay) se ignorarán y la aplicación se cerrará. Devolverá 0 en caso de éxito o -1 en caso de error.
-actions <lista_acciones>
<lista_acciones> es una lista de acciones separadas por espacios. Las acciones se ejecutarán justo después de cargar el archivo (si lo hay) en el mismo orden de entrada. Para acciones conmutables puedes pasar true o false como parámetro.
Ejemplo: smplayer -actions.br "fullscreen compact true"
Las comillas son necesarias en caso de que pases más de una acción.
-close-at-end
Cierra la ventana principal cuando el archivo/lista de reproducción termine.
-no-close-at-end
No cierra la ventana principal cuando el archivo/lista de reproducción termine.
-fullscreen
Reproduce el video en modo pantalla completa.
-no-fullscreen
Reproduce el video en modo ventana.
-sub
Especifica el archivo de subtítulos a cargar (solo para el primer video).
-pos <x> <y>
Especifica las coordenadas donde se mostrará la ventana principal.
-size <ancho> <alto>
Especifica el tamaño de la ventana principal.
-h, -help, --help, -?
Muestra el mensaje de ayuda y sale.
-add-to-playlist
Si hay otra instancia ejecutándose, los medios se añadirán a la lista de reproducción de esa instancia. Si no hay otra instancia, esta opción se ignorará y los archivos se abrirán en una nueva instancia.
-disable-server
Desactiva el servidor utilizado para comunicarse con otras instancias. Esto también desactiva la posibilidad de usar una única instancia.
<media1> <media2> ...
Cualquier tipo de archivo que SMPlayer pueda abrir. Puede ser un archivo local, un DVD (ej: dvd://1), una transmisión por Internet (ej: mms://....) o una lista de reproducción local en formato m3u o pls.
