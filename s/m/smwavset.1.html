NOMBRE

smwavset - Programa para gestionar archivos multiwave de spectmorph

SINOPSIS

smwavset <comando> [OPCIONES] [ <argumentos específicos del comando>... ]

DESCRIPCIÓN

smwavset es una herramienta de línea de comandos para gestionar archivos multiwave para SpectMorph. Normalmente, un archivo multiwave se inicializa primero (usando el comando init), luego se añaden diferentes archivos wave usando el comando add. Después de haber hecho esto, la codificación de todas las waves se puede hacer con un solo comando, al igual que la decodificación de todas las waves.

OPCIONES

smwavset sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones ('-').

-h, --help
Muestra un breve mensaje de ayuda.
-v, --version
Imprime la versión de smwavset.
--args <argumentos>
Especifica argumentos adicionales para pasar a smenc/smplay. Esto podría ser --args "-O1" para codificar, o --args "--no-sines" para decodificar.
-d, --data-dir
Para codificar/decodificar, esto establece un directorio de datos donde se almacenan los archivos .wav o una lista de archivos .wav (o .sm). Es importante que diferentes conjuntos de waves almacenen sus archivos en directorios diferentes (de lo contrario, sobrescribirán los archivos wav que pertenecen a un conjunto de waves diferente). Por lo tanto, especificar un directorio de datos adecuado y diferente para cada conjunto de waves suele ser necesario. El valor predeterminado es /tmp, que solo es apropiado para pruebas; debes asegurarte de que los scripts establezcan un valor diferente.
--format <campo1>,<campo2>,<campo3>,...,<campoN>
Establece el formato de salida para el comando list.
-j <trabajos>
Usa <trabajos> trabajos paralelos para la codificación (para sistemas con más de un procesador).

COMANDOS

init [ <opciones> ] <conjunto_de_waves>...
Inicializa un nuevo conjunto de waves; también puede inicializar más de un conjunto de waves especificado en la línea de comandos.
add [ <opciones> ] <conjunto_de_waves> <nota_midi> <ruta>
Añade un archivo wave al conjunto de waves, donde nota_midi es la nota midi para la que se ha grabado el archivo wave.
list [ <opciones> ] <conjunto_de_waves>
Lista los archivos wave que están contenidos en el conjunto de waves. El formato de salida para el comando list se puede especificar usando la opción format (campos separados por comas). Ver la sección CAMPOS para una lista de campos válidos.
encode [ <opciones> ] <nombre_archivo_wset> <nombre_archivo_smset>
Codifica un conjunto de waves usando smenc.
decode [ <opciones> ] <nombre_archivo_smset> <nombre_archivo_wset>
Decodifica un conjunto de waves usando smplay.
delta [ <opciones> ] <nombre_archivo_wset1>...<nombre_archivo_wsetN>
Calcula la diferencia entre muchos conjuntos de waves. La diferencia entre el primer y el segundo conjunto de waves es la referencia, que es el 100%. Los otros conjuntos de waves se miden contra esa referencia.
link <smset>
Este comando incluye todos los archivos .sm a los que hace referencia el smset en un solo archivo grande. Esto es útil como paso final al construir instrumentos.

CAMPOS

Para el comando list, los campos válidos son:

nota-midi
Nota midi de la entrada de audio (0-127)
canal
Canal para la entrada de audio (0 es el primer canal)
nombre_archivo
Nombre del archivo de audio
velocidad-min
Velocidad mínima de la entrada de audio (0-127)
velocidad-max
Velocidad máxima de la entrada de audio (0-127)
