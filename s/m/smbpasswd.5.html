SMBPASSWD(5) Formatos de archivo y convenciones SMBPASSWD(5)

NOMBRE

smbpasswd - El archivo de contraseñas cifradas de Samba

SINOPSIS

smbpasswd

DESCRIPCIÓN

Esta herramienta es parte de la suite de samba(7).

smbpasswd es el archivo de contraseñas cifradas de Samba. Contiene el nombre de usuario, el ID de usuario de Unix y las contraseñas hasheadas de SMB del usuario, así como información de las banderas de la cuenta y la hora en que se cambió la contraseña por última vez. Este formato de archivo ha ido evolucionando con Samba y ha tenido varios formatos diferentes en el pasado.

FORMATO DE ARCHIVO

El formato del archivo smbpasswd utilizado por Samba 2.2 es muy similar al archivo passwd(5) familiar de Unix. Es un archivo ASCII que contiene una línea por cada usuario. Cada campo dentro de cada línea está separado del siguiente por dos puntos. Cualquier entrada que comience con '#' se ignora. El archivo smbpasswd contiene la siguiente información para cada usuario:

nombre

Este es el nombre de usuario. Debe ser un nombre que ya exista en el archivo passwd estándar de UNIX.

uid

Este es el uid de UNIX. Debe coincidir con el campo uid para la misma entrada de usuario en el archivo passwd estándar de UNIX. Si esto no coincide, Samba se negará a reconocer esta entrada del archivo smbpasswd como válida para un usuario.

Hash de contraseña Lanman

Este es el hash LANMAN de la contraseña del usuario, codificado como 32 dígitos hexadecimales. El hash LANMAN se crea cifrando con DES una cadena bien conocida con la contraseña del usuario como clave DES. Esta es la misma contraseña utilizada por las máquinas Windows 95/98. Tenga en cuenta que esta contraseña hash se considera débil, ya que es vulnerable a ataques de diccionario y si dos usuarios eligen la misma contraseña, esta entrada será idéntica (es decir, la contraseña no está "salada" como lo está la contraseña UNIX). Si el usuario tiene una contraseña nula, este campo contendrá los caracteres "NO PASSWORD" al principio de la cadena hexadecimal. Si la cadena hexadecimal es igual a 32 caracteres 'X', la cuenta del usuario se marca como deshabilitada y el usuario no podrá iniciar sesión en el servidor Samba.

¡¡ADVERTENCIA!! Tenga en cuenta que, debido a la naturaleza de desafío-respuesta del protocolo de autenticación SMB/CIFS, cualquiera que tenga conocimiento de este hash de contraseña podrá suplantar al usuario en la red. Por esta razón, estos hashes se conocen como equivalentes a texto plano y NO deben ser accesibles para nadie más que el usuario root. Para proteger estas contraseñas, el archivo smbpasswd se coloca en un directorio con acceso de solo lectura y traversa solo para el usuario root, y el propio archivo smbpasswd debe configurarse para que solo root pueda leerlo/escribirlo, sin ningún otro acceso.

Hash de contraseña NT

Este es el hash de Windows NT de la contraseña del usuario, codificado como 32 dígitos hexadecimales. El hash de Windows NT se crea tomando la contraseña del usuario representada en UNICODE de 16 bits y poco endian, y luego aplicándole el algoritmo de hash MD4 (rfc1321 de Internet).

Este hash de contraseña se considera más seguro que el hash de contraseña LANMAN, ya que preserva la capitalización de la contraseña y utiliza un algoritmo de hash de mucha mayor calidad. Sin embargo, sigue siendo el caso que si dos usuarios eligen la misma contraseña, esta entrada será idéntica (es decir, la contraseña no está "salada" como lo está la contraseña UNIX).

¡¡ADVERTENCIA!! Tenga en cuenta que, debido a la naturaleza de desafío-respuesta del protocolo de autenticación SMB/CIFS, cualquiera que tenga conocimiento de este hash de contraseña podrá suplantar al usuario en la red. Por esta razón, estos hashes se conocen como equivalentes a texto plano y NO deben ser accesibles para nadie más que el usuario root. Para proteger estas contraseñas, el archivo smbpasswd se coloca en un directorio con acceso de solo lectura y traversa solo para el usuario root, y el propio archivo smbpasswd debe configurarse para que solo root pueda leerlo/escribirlo, sin ningún otro acceso.

Banderas de cuenta

Esta sección contiene banderas que describen los atributos de la cuenta del usuario. Este campo está delimitado por los caracteres '[' y ']' y siempre tiene una longitud de 13 caracteres (incluidos los caracteres '[' y ']'). El contenido de este campo puede ser cualquiera de los siguientes caracteres:
•U - Esto significa que es una cuenta de "Usuario", es decir, un usuario ordinario.
•N - Esto significa que la cuenta no tiene contraseña (las contraseñas en los campos Hash de contraseña LANMAN y Hash de contraseña NT se ignoran). Tenga en cuenta que esto solo permitirá a los usuarios iniciar sesión sin contraseña si el parámetro null passwords está configurado en el archivo de configuración smb.conf(5).
•D - Esto significa que la cuenta está deshabilitada y no se permitirán inicios de sesión SMB/CIFS para este usuario.
•X - Esto significa que la contraseña no expira.
•W - Esto significa que esta cuenta es una cuenta de "Confianza de Estación de Trabajo". Este tipo de cuenta se utiliza en el flujo de código PDC de Samba para permitir que las Estaciones de Trabajo y Servidores Windows NT se unan a un Dominio alojado por un PDC de Samba.
Se pueden añadir otras banderas a medida que el código se extienda en el futuro. El resto del espacio de este campo se rellena con espacios. Para obtener más información sobre las banderas admitidas, consulte la página del manual del comando pdbedit.

Hora del último cambio

Este campo consiste en la hora en que se modificó la cuenta por última vez. Consiste en los caracteres 'LCT-' (que significa "Last Change Time", Hora del último cambio) seguidos de una codificación numérica del tiempo UNIX en segundos desde la época (1970) en que se realizó el último cambio.

Todos los demás campos separados por dos puntos se ignoran en este momento.
