SMBSTATUS(1) Comandos de usuario SMBSTATUS(1)

NOMBRE

smbstatus - informa sobre las conexiones actuales de Samba

SINOPSIS

smbstatus [-p|--processes] [-v|--verbose] [-L|--locks] [-S|--shares] [-N|--notify] [-u|--user=CADENA] [-b|--brief] [-P|--profile] [-R|--profile-rates] [-B|--byterange] [-n|--numeric] [-f|--fast] [-j|--json] [--resolve-uids] [-?|--help] [--usage] [-d|--debuglevel=NIVEL_DE_DEBUG] [--debug-stdout] [--configfile=ARCHIVO_CONFIG] [--option=nombre=valor] [-l|--log-basename=BASE_ARCHIVO_LOG] [--leak-report] [--leak-report-full]

DESCRIPCIÓN

Esta herramienta forma parte de la suite samba(7).

smbstatus es un programa muy simple para listar las conexiones actuales de Samba.

OPCIONES

-P|--profile

Si samba ha sido compilado con la opción de perfilado, imprime solo el contenido del área de memoria compartida de perfilado.

-R|--profile-rates

Si samba ha sido compilado con la opción de perfilado, imprime el contenido del área de memoria compartida de perfilado y las tasas de llamadas.

-b|--brief

produce una salida breve.

-v|--verbose

produce una salida detallada.

-L|--locks

hace que smbstatus solo liste los bloqueos.

-B|--byterange

hace que smbstatus incluya los bloqueos de rango de bytes.

-p|--processes

imprime una lista de procesos de smbd(8) y sale. Útil para scripts.

-S|--shares

hace que smbstatus solo liste los recursos compartidos.

-N|--notify

hace que smbstatus muestre las notificaciones de archivo registradas

-f|--fast

hace que smbstatus no verifique si los datos de estado son válidos comprobando si los procesos a los que se refieren los datos de estado todavía existen. Esto acelera la ejecución en sistemas ocupados y clústeres, pero podría mostrar datos obsoletos de procesos que murieron sin una limpieza adecuada.

-u|--user=<nombre de usuario>

selecciona solo la información relevante para nombre de usuario.

-n|--numeric

hace que smbstatus muestre UID y GID numéricos en lugar de resolverlos a nombres.

-?|--help

Imprime un resumen de las opciones de la línea de comandos.

--usage

Muestra un mensaje de uso breve.

-d|--debuglevel=nivel

nivel es un entero de 0 a 10. El valor predeterminado si no se especifica este parámetro es 1 para las aplicaciones cliente.

Cuanto mayor sea este valor, más detalles se registrarán en los archivos de registro sobre las actividades del servidor. En el nivel 0, solo se registrarán errores críticos y advertencias serias. El nivel 1 es un nivel razonable para el uso diario: genera una pequeña cantidad de información sobre las operaciones realizadas.

Los niveles superiores a 1 generarán una cantidad considerable de datos de registro y solo deben usarse cuando se investigue un problema. Los niveles superiores a 3 están diseñados para ser utilizados solo por desarrolladores y generan ENORMES cantidades de datos de registro, la mayor parte de los cuales es extremadamente críptica.

Tenga en cuenta que especificar este parámetro aquí anulará el parámetro log level en el archivo /etc/samba/smb.conf.

--debug-stdout

Esto redirigirá la salida de depuración a STDOUT. Por defecto, todos los clientes registran en STDERR.

--configfile=<archivo de configuración>

El archivo especificado contiene los detalles de configuración requeridos por el cliente. La información de este archivo puede ser general para cliente y servidor o solo proporcionar opciones específicas del cliente, como client smb encrypt. Consulte /etc/samba/smb.conf para obtener más información. El nombre del archivo de configuración predeterminado se determina en tiempo de compilación.

--option=<nombre>=<valor>

Establece la opción de smb.conf(5) "<nombre>" al valor "<valor>" desde la línea de comandos. Esto anula los valores predeterminados compilados y las opciones leídas del archivo de configuración. Si un nombre o un valor incluyen un espacio, envuelva todo --option=nombre=valor entre comillas.

-l|--log-basename=directorio de registro

Nombre base del directorio para archivos de registro/depuración. Se añadirá la extensión ".progname" (por ejemplo, log.smbclient, log.smbd, etc...). El cliente nunca elimina el archivo de registro.

--leak-report

Habilita el informe de fugas de talloc al salir.

--leak-report-full

Habilita el informe completo de fugas de talloc al salir.

-V|--version

Imprime el número de versión del programa.
