NOMBRE

smime_keys - Utilidad para añadir certificados S/MIME a la base de datos interna utilizada por mutt

SINOPSIS

smime_keys <operación> [archivo(s) | IDclave [archivo(s)]]

DESCRIPCIÓN

El propósito de esta herramienta es manipular la base de datos interna de certificados S/MIME utilizada por mutt para firmar mensajes de correo que se enviarán o para verificar mensajes de correo recibidos y firmados con S/MIME.

OPCIONES

init
no se necesitan archivos, inicializa la estructura del directorio.
refresh
no se necesitan archivos. actualiza los archivos de índice, incluyendo el indicador de confianza/expiración.
list
enumera los certificados almacenados en la base de datos.
label
se requiere IDclave. cambia/elimina/añade una etiqueta.
remove
se requiere IDclave.
verify
1=IDclave y opcionalmente 2=CRL. Verifica la cadena de certificados y, opcionalmente, si este certificado está incluido en el CRL proporcionado (formato PEM). Nota: para verificar todos los certificados al mismo tiempo, reemplace IDclave con "all".
add_cert
se requiere certificado.
add_chain
se requieren tres archivos: 1=Clave, 2=certificado más 3=certificado(s) intermedio(s).
add_p12
se requiere un archivo. Añade par clave-certificado a la base de datos. el archivo es PKCS12 (por ejemplo, exportación de netscape).
add_pem
se requiere un archivo. Añade par clave-certificado a la base de datos. (el archivo se convirtió desde, por ejemplo, PKCS12).
add_root
se requiere un archivo. Añade un certificado raíz PEM a la ubicación especificada dentro de muttrc (comando smime_verify_*).
