subroutine sspgvx (integer itype, character jobz, character range, character uplo, integer n, real, dimension( * ) ap, real, dimension( * ) bp, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

SSPGVX

Propósito:

!>
!> SSPGVX calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de un problema de valores propios general simétrico-definido real, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x. Aquí A
!> y B se suponen simétricas, almacenadas en almacenamiento empaquetado, y B
!> es también positiva definida. Los valores propios y vectores propios pueden ser
!> seleccionados especificando un rango de valores o un rango de índices
!> para los valores propios deseados.
!>

Parámetros

ITYPE 
!>          ITYPE es ENTERO
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios desde el índice IL hasta el IU.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A y B;
!>          = 'L':  Se almacena el triángulo inferior de A y B.
!>

N

!>          N es ENTERO
!>          El orden del par de matrices (A,B).  N >= 0.
!>

AP

!>          AP es array REAL, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          A, empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, el contenido de AP se destruye.
!>

BP

!>          BP es array REAL, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          B, empaquetado por columnas en un array lineal. La j-ésima columna de B
!>          se almacena en el array BP como sigue:
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) para 1<=i<=j;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) para j<=i<=n.
!>
!>          En la salida, el factor triangular U o L de la factorización de Cholesky
!>          B = U**T*U o B = L*L**T, en el mismo formato de almacenamiento
!>          que B.
!>

VL

!>          VL es REAL
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es ENTERO
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es ENTERO
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que se encuentra en un intervalo [a,b]
!>          de ancho menor o igual que
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*SLAMCH('S'), no en cero.
!>          Si esta rutina devuelve INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*SLAMCH('S').
!>

M

!>          M es ENTERO
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array REAL, dimensión (N)
!>          En caso de salida normal, los primeros M elementos contienen los valores propios
!>          seleccionados en orden ascendente.
!>

Z

!>          Z es array REAL, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Los vectores propios se normalizan como sigue:
!>          si ITYPE = 1 o 2, Z**T*B*Z = I;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>
!>          Si un vector propio no converge, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es ENTERO
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array REAL, dimensión (8*N)
!>

IWORK

!>          IWORK es array ENTERO, dimensión (5*N)
!>

IFAIL

!>          IFAIL es array ENTERO, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero.  Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que fallaron en converger.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  SPPTRF o SSPEVX devolvieron un código de error:
!>             <= N:  si INFO = i, SSPEVX falló en converger;
!>                    i vectores propios fallaron en converger. Sus índices
!>                    se almacenan en el array IFAIL.
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el principal
!>

NAME

sspgvx - Compute the eigenvalues and eigenvectors of a symmetric (or general) positive definite generalized eigenvalue problem of the form A*x = lambda*B*x, A*x = lambda*B*x, or A*x = lambda*B*x where A and B are symmetric and positive definite.

Function/Subroutine Documentation

sspgvx computes the eigenvalues and eigenvectors of a real generalized eigenvalue problem A*x = lambda*B*x, where A and B are symmetric positive definite matrices. The problem is:

  ITYPE = 1: A*x = lambda*B*x
  ITYPE = 2: A*S*x = lambda*x, where S is upper triangular of B
  ITYPE = 3: S'*S*x = lambda*B*x, where S is upper triangular of A

Here A is represented by its lower or upper triangular part in the array AP and B is represented by its lower or upper triangular part in the array BP.

Routines related to sspgvx include:

s*:
routines for general matrices
s*:
routines for real symmetric matrices
p*:
routines for the generalized eigenvalue problem

The problem is solved using the

  Schur decomposition of real matrices.

Parameters:

ITYPE:
Must be 1, 2, or 3.
JOBZ:

'E' compute all eigenvalues and eigenvectors.

'N' compute all eigenvalues only.

RANGE:

'A' All eigenvalues to be computed.

'V' All eigenvalues in the interval (VL, VU) will be returned.

'I' All eigenvalues in the index range [IL, IU] will be computed.

UPLO:

'U' Upper triangle of A and B are used.

'L' Lower triangle of A and B are used.

N:
The order of the matrices A and B. N >= 0.
AP:
The upper or lower triangular part of the symmetric matrix A, stored packed column-wise. Size N*(N+1)/2.
BP:
The upper or lower triangular part of the symmetric positive definite matrix B, stored packed column-wise. Size N*(N+1)/2.
VL:
If RANGE='V', the lower bound of the eigenvalue range.
VU:
If RANGE='V', the upper bound of the eigenvalue range.
IL:
If RANGE='I', the lower bound of the index range.
IU:
If RANGE='I', the upper bound of the index range.
ABSTOL:
Minimum absolute difference between distinct eigenvalues.
M:
The total number of eigenvalues found.
W:
The computed eigenvalues, sorted in increasing order. Size N.
Z:
If JOBZ='E', Z contains the computed eigenvectors. Size LDZ*N.
LDZ:
The leading dimension of the array Z. LDZ >= max(1, N).
WORK:
Real workspace array. Size 12*N.
IWORK:
Integer workspace array. Size 10*N.
INFO:

0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: If INFO = i, the algorithm failed to converge; i off-diagonal

elements of an intermediate tridiagonal matrix did not have

positive values. The minor of order i of B is not positive.

The factorization of B could not be completed and

no eigenvalues or eigenvectors were computed.
