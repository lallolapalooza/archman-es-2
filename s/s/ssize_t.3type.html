size_t(3type) size_t(3type)

NOMBRE

size_t, ssize_t - recuento de bytes

BIBLIOTECA

Biblioteca estándar de C (libc)

SINOPSIS

#include <stddef.h>
typedef /* ... */  size_t;
#include <sys/types.h>
typedef /* ... */  ssize_t;

DESCRIPCIÓN

size_t
Se utiliza para un recuento de bytes. Es el resultado del operador sizeof(). Es un tipo entero sin signo capaz de almacenar valores en el rango [0, SIZE_MAX].
ssize_t
Se utiliza para un recuento de bytes o una indicación de error. Es un tipo entero con signo capaz de almacenar valores al menos en el rango [-1, SSIZE_MAX].

Uso con printf(3) y scanf(3)

size_t
El modificador de longitud para size_t para las familias de funciones printf(3) y scanf(3) es z, resultando comúnmente en %zu o %zx para imprimir valores de size_t.
ssize_t
glibc y la mayoría de las otras implementaciones proporcionan un modificador de longitud para ssize_t para las familias de funciones printf(3) y scanf(3), que es z; resultando comúnmente en %zd o %zi para imprimir valores de ssize_t. Aunque z funciona para ssize_t en la mayoría de las implementaciones, los programas POSIX portátiles deben evitar su uso; por ejemplo, convirtiendo el valor a intmax_t y utilizando su modificador de longitud (j).
