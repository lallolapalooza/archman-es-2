función real ssxt1 (integer ijob, real, dimension( * ) d1, integer n1, real, dimension( * ) d2, integer n2, real abstol, real ulp, real unfl)

SSXT1

Propósito:

!>
!> SSXT1 calcula la diferencia entre un conjunto de valores propios.
!> El resultado se devuelve como el valor de la función.
!>
!> IJOB = 1: Calcula max { min | D1(i)-D2(j) | }
!>                         i     j
!>
!> IJOB = 2: Calcula max { min | D1(i)-D2(j) | /
!>                         i     j
!>                              ( ABSTOL + |D1(i)|*ULP ) }
!>

Parámetros

IJOB 
!>          IJOB es INTEGER
!>          Especifica el tipo de pruebas a realizar. (Ver arriba.)
!>

D1

!>          D1 es un array REAL, dimension (N1)
!>          El primer array. D1 debe estar en orden creciente, es decir,
!>          D1(j) <= D1(j+1).
!>

N1

!>          N1 es INTEGER
!>          La longitud de D1.
!>

D2

!>          D2 es un array REAL, dimension (N2)
!>          El segundo array. D2 debe estar en orden creciente, es decir,
!>          D2(j) <= D2(j+1).
!>

N2

!>          N2 es INTEGER
!>          La longitud de D2.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia absoluta, utilizada como medida del error.
!>

ULP

!>          ULP es REAL
!>          Precisión de la máquina.
!>

UNFL

!>          UNFL es REAL
!>          El número positivo más pequeño cuya inversa no provoca
!>          desbordamiento.
!>
