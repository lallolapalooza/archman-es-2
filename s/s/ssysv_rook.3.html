subrutina ssysv_rook (uplo, n, nrhs, a, lda, ipiv, b, ldb, work, lwork, info)

SSYSV_ROOK calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Documentación de la Función/Subrutina

subrutina ssysv_rook (character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) work, integer lwork, integer info)

SSYSV_ROOK calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> SSYSV_ROOK calcula la solución a un sistema de ecuaciones lineales real
!>    A * X = B,
!> donde A es una matriz simétrica N-por-N y X y B son matrices N-por-NRHS.
!>
!> Se utiliza el método de pivoteo diagonal para factorizar A como
!>    A = U * D * U**T,  si UPLO = 'U', o
!>    A = L * D * L**T,  si UPLO = 'L',
!> donde U (o L) es un producto de matrices de permutación y triangulares unitarias
!> superiores (inferiores), y D es simétrica y de bloques diagonales con
!> bloques diagonales de 1x1 y 2x2.
!>
!> Se llama a SSYTRF_ROOK para calcular la factorización de una matriz simétrica real
!> A utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman ().
!>
!> La forma factorizada de A se utiliza luego para resolver el sistema
!> de ecuaciones A * X = B llamando a SSYTRS_ROOK.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular N-por-N de A contiene la parte superior
!>          triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia.  Si UPLO = 'L', la parte
!>          inferior triangular N-por-N de A contiene la parte inferior
!>          triangular de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>
!>          En la salida, si INFO = 0, la matriz de bloques diagonales D y los
!>          multiplicadores utilizados para obtener el factor U o L de la
!>          factorización A = U*D*U**T o A = L*D*L**T calculada por
!>          SSYTRF_ROOK.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D,
!>          según lo determinado por SSYTRF_ROOK.
!>
!>          Si UPLO = 'U':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>               Si IPIV(k) < 0 e IPIV(k-1) < 0, entonces las filas y
!>               columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>               columnas k-1 e -IPIV(k-1) fueron intercambiadas,
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>               Si IPIV(k) < 0 e IPIV(k+1) < 0, entonces las filas y
!>               columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>               columnas k+1 e -IPIV(k+1) fueron intercambiadas,
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>

B

!>          B es un array REAL, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho N-por-NRHS.
!>          En la salida, si INFO = 0, la matriz solución X N-por-NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1, y para un rendimiento óptimo
!>          LWORK >= max(1,N*NB), donde NB es el tamaño de bloque óptimo para
!>          SSYTRF_ROOK.
!>
!>          TRS se realizará con BLAS de Nivel 2.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i tuvo un valor ilegal
!>          > 0: si INFO = i, D(i,i) es exactamente cero. La factorización
!>               se ha completado, pero la matriz de bloques diagonales D es
!>               exactamente singular, por lo que la solución no se pudo calcular.
!>
