subrutina ssycon_3 (character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) e, integer, dimension( * ) ipiv, real anorm, real rcond, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SSYCON_3

Propósito:

!> SSYCON_3 estima el recíproco del número de condición (en la
!> norma 1) de una matriz simétrica real A utilizando la factorización
!> calculada por DSYTRF_RK o DSYTRF_BK:
!>
!>    A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz triangular unitaria superior (o inferior),
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es simétrica y de bloques diagonales
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Se obtiene una estimación de norm(inv(A)) y se calcula el recíproco
!> del número de condición como RCOND = 1 / (ANORM * norm(inv(A))).
!> Esta rutina utiliza el solvedor BLAS3 SSYTRS_3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se
!>          almacenan como una matriz triangular superior o inferior:
!>          = 'U':  Triangular superior, la forma es A = P*U*D*(U**T)*(P**T);
!>          = 'L':  Triangular inferior, la forma es A = P*L*D*(L**T)*(P**T).
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>          La diagonal de la matriz de bloques diagonales D y los factores U o L
!>          calculados por SSYTRF_RK y SSYTRF_BK:
!>            a) SÓLO los elementos diagonales de la matriz de bloques diagonales
!>               simétrica D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos supradiagonales (o subdiagonales) de D
!>                deben proporcionarse en la entrada en el array E), y
!>            b) Si UPLO = 'U': el factor U en la parte supradiagonal de A.
!>               Si UPLO = 'L': el factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es array REAL, dimensión (N)
!>          En la entrada, contiene los elementos supradiagonales (o subdiagonales)
!>          de la matriz de bloques diagonales simétrica D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) no se referencia;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) no se referencia.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) no se referencia en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como se determinaron por SSYTRF_RK o SSYTRF_BK.
!>

ANORM

!>          ANORM es REAL
!>          La norma 1 de la matriz original A.
!>

RCOND

!>          RCOND es REAL
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es array REAL, dimensión (2*N)
!>

IWORK

!>          IWORK es array INTEGER, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
