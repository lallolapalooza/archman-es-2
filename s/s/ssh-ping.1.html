SSH-PING(1) Comandos de usuario SSH-PING(1)

NOMBRE

ssh-ping

SINOPSIS

ssh-ping [OPCIONES] [usuario@]hostname

DESCRIPCIÓN

comprueba si el host es accesible usando ssh_config

OPCIONES

-4
Usar solo IPv4
-6
Usar solo IPv6
-c número
Detenerse después de enviar <número> paquetes de solicitud
-C
Conectar tan pronto como el host responda
y tratar de reconectar después de que finalice una sesión SSH (p. ej., reinicios).
Útil también para dispositivos IDRAC, IPMI, ILO, Switches, etc...
que no tienen un entorno de shell completo.
CTRL+C detiene los intentos de reconexión.
-E
Salir inmediatamente después del primer ping exitoso
(se puede usar para activar una tarea posterior como rsync)
-F archivo_configuración
Especifica un archivo de configuración alternativo por usuario.
Si se proporciona un archivo de configuración en la línea de comandos,
se ignorará el archivo de configuración a nivel del sistema ( /etc/ssh/ssh_config ).
El valor predeterminado para el archivo de configuración por usuario es ~/.ssh/config.
-h
Mostrar este mensaje
-i intervalo
Esperar <intervalo> segundos entre el envío de cada solicitud.
El valor predeterminado es 1 segundo.
-l usuario
Intentar iniciar sesión con <usuario> como nombre de usuario. El valor predeterminado es el valor actual de $USER.
-D
Imprimir marca de tiempo (tiempo unix + microsegundos como en gettimeofday) antes de cada línea
-H
Imprimir marca de tiempo (legible por humanos) antes de cada línea
-W tiempo_espera
Tiempo para esperar una respuesta, en segundos
-p puerto
Puerto al que conectarse en el host remoto.
Esto se puede especificar por host en el archivo de configuración.
-q
Salida silenciosa.
No se muestra nada excepto las líneas de resumen al inicio y al finalizar
-n
Sin colores.
(p. ej., para terminales de blanco sobre negro)
-v
Salida detallada
--version
mostrar información de versión

COMPLETADO CON TABULADOR

Ubuntu (y quizás otras distribuciones) ya envían
completado de shell para ssh que se puede usar:

Bash
complete -F _known_hosts ssh-ping
Zsh
compdef _ssh_hosts ssh-ping
Fish
complete -c ssh-ping -a "(__fish_print_hostnames)"

ENTORNO

SSH_PING_NO_COLORS
si está establecido, no se muestran colores (como -n)

CÓDIGOS DE SALIDA

0
Ninguna solicitud perdida
1
Más de 1 solicitud perdida
2
Todas las solicitudes perdidas

EJEMPLOS

ssh-ping -E hostname && echo "Primer ping exitoso. Iniciando rsync..."
ssh-ping -q -c 1 hostname >/dev/null && echo "¡Host en línea!"
ssh-ping -q -c 1 hostname >/dev/null || echo "¡Host caído!"
SSH_PING_NO_COLORS=true ssh-ping -c 1 hostname
