SSH-SIG(1) Comandos de Usuario SSH-SIG(1)

NOMBRE

ssh-sig

SINOPSIS

ssh-sig COMANDO OPCION

DESCRIPCIÓN

simplifica ssh-keygen -Y

OPCIONES

-h --help

  --version

COMANDOS

sign
crear firma
check
verificar firma

AYUDA

sign
--help
check
--help

EJEMPLOS

ssh-sig sign archivo.txt
ssh-sig check -s archivo.txt.sig < archivo.txt

cat archivo.txt | ssh-sig sign > archivo.txt.sig
cat archivo.txt | ssh-sig check -s archivo.txt.sig

# Firmar múltiples archivos
ssh-sig sign archivo1.txt archivo2.txt [...]

# Usar otra clave para firmar
ssh-sig sign -f ~/.ssh/id_rsa archivo.txt

# Usar una clave pública. La clave privada para firmar proviene de ssh-agent
ssh-sig sign -f ~/.ssh/id_rsa.pub archivo.txt
