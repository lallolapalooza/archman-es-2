Documentación de Función/Subrutina

subrutina sspr (carácter uplo, entero n, real alpha, real, dimensión(*) x, entero incx, real, dimensión(*) ap)

SSPR

Propósito:

!>
!> SSPR    realiza la operación simétrica de rango 1
!>
!>    A := alpha*x*x**T + A,
!>
!> donde alpha es un escalar real, x es un vector de n elementos y A es una
!> matriz simétrica de n por n, proporcionada en forma empaquetada.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si la parte triangular superior o inferior
!>           de la matriz A se proporciona en el array empaquetado
!>           AP de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   La parte triangular superior de A se
!>                                  proporciona en AP.
!>
!>              UPLO = 'L' o 'l'   La parte triangular inferior de A se
!>                                  proporciona en AP.
!>

N

!>          N es ENTERO
!>           En la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

ALPHA

!>          ALPHA es REAL
!>           En la entrada, ALPHA especifica el escalar alpha.
!>

X

!>          X es un array REAL, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el vector
!>           x de n elementos.
!>

INCX

!>          INCX es ENTERO
!>           En la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>

AP

!>          AP es un array REAL, de dimensión al menos
!>           ( ( n*( n + 1 ) )/2 ).
!>           Antes de la entrada con  UPLO = 'U' o 'u', el array AP debe
!>           contener la parte triangular superior de la matriz simétrica
!>           empaquetada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contenga a( 1, 1 ), AP( 2 ) y AP( 3 ) contengan a( 1, 2 )
!>           y a( 2, 2 ) respectivamente, y así sucesivamente. En la salida, el array
!>           AP se sobrescribe con la parte triangular superior de la
!>           matriz actualizada.
!>           Antes de la entrada con UPLO = 'L' o 'l', el array AP debe
!>           contener la parte triangular inferior de la matriz simétrica
!>           empaquetada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contenga a( 1, 1 ), AP( 2 ) y AP( 3 ) contengan a( 2, 1 )
!>           y a( 3, 1 ) respectivamente, y así sucesivamente. En la salida, el array
!>           AP se sobrescribe con la parte triangular inferior de la
!>           matriz actualizada.
!>
