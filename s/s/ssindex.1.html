NOMBRE

ssindex - generar datos de índice para archivos de hoja de cálculo

SINOPSIS

ssindex [OPCIONES] [ARCHIVOS]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando ssindex.

ssindex es una utilidad de línea de comandos para generar datos de índice para varios formatos de archivo de hoja de cálculo. Es utilizado principalmente por el subsistema de indexación y el agregador de búsqueda de Beagle.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones de una sola letra que comienzan con un guión (`-') y opciones más largas que comienzan con dos guiones (`--').

Opciones principales

-E, --import-encoding=CODIFICACIÓN
Especificar una codificación para el contenido importado
-i, --index
Indexar los archivos dados
-m, --list-mime-types
Listar los tipos MIME que ssindex es capaz de leer

Opciones de ayuda

-v, --version
Mostrar la versión de ssindex
-?, --help
Mostrar las opciones soportadas
--usage
Mostrar un breve mensaje de uso
