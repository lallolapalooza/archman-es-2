subrutina sstemr (character jobz, character range, integer n, real, dimension( * ) d, real, dimension( * ) e, real vl, real vu, integer il, integer iu, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, integer nzc, integer, dimension( * ) isuppz, logical tryrac, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSTEMR

Propósito:

!>
!> SSTEMR calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de una matriz tridiagonal simétrica real T. Cualquier matriz irreducida de este tipo tiene
!> un conjunto bien definido de valores propios reales, distintos por pares, los vectores propios
!> reales correspondientes son ortogonales por pares.
!>
!> El espectro puede ser calculado ya sea completamente o parcialmente especificando
!> ya sea un intervalo (VL,VU] o un rango de índices IL:IU para los valores propios deseados.
!>
!> Dependiendo del número de valores propios deseados, estos se calculan ya sea
!> por bisección o por el algoritmo dqds. Los vectores propios ortogonales numéricamente
!> se calculan mediante el uso de varias factorizaciones L D L^T adecuadas cerca de cúmulos
!> de valores propios cercanos (denominados RRR, Representaciones Relativamente Robustas). Un esquema informal del algoritmo es el siguiente.
!>
!> Para cada bloque irreducible (submatriz) de T,
!>    (a) Calcula T - sigma I  = L D L^T, de modo que L y D
!>        definen todos los valores propios deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los valores propios y
!>        vectores propios. La representación estándar (no factorizada) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcula los valores propios con precisión adecuada.
!>        Si se desean los vectores propios, el algoritmo alcanza la precisión completa
!>        de los valores propios calculados justo antes de
!>        que los vectores correspondientes tengan que ser calculados, ver pasos c) y d).
!>    (c) Para cada cúmulo de valores propios cercanos, selecciona un nuevo
!>        desplazamiento cercano al cúmulo, encuentra una nueva factorización, y refina
!>        los valores propios desplazados a la precisión adecuada.
!>    (d) Para cada valor propio con una separación relativa suficientemente grande, calcula
!>        el vector propio correspondiente formando una factorización retorcida que revela el rango. Vuelve a (c) para los cúmulos que queden.
!>
!> Para más detalles, ver:
!> - Inderjit S. Dhillon y Beresford N. Parlett: 
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, Agosto 2004.
!> - Inderjit Dhillon y Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004. También Nota de Trabajo de LAPACK 154.
!> - Inderjit Dhillon: ,
!>   Informe Técnico de la División de Ciencias de la Computación No. UCB/CSD-97-971,
!>   UC Berkeley, Mayo 1997.
!>
!> Detalles Adicionales
!> 1.SSTEMR solo funciona en máquinas que siguen el estándar de punto flotante IEEE-754
!> en su manejo de infinitos y NaNs.
!> Esto permite el uso de bucles internos eficientes que evitan la comprobación de
!> divisores cero.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Solo calcula los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios desde el índice IL hasta IU.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es array REAL, dimension (N)
!>          En la entrada, los N elementos diagonales de la matriz tridiagonal
!>          T. En la salida, D se sobrescribe.
!>

E

!>          E es array REAL, dimension (N)
!>          En la entrada, los N-1 elementos subdiagonales de la matriz
!>          tridiagonal T en los elementos 1 a N-1 de E. E(N) no necesita ser establecida en
!>          la entrada, pero se utiliza internamente como espacio de trabajo.
!>          En la salida, E se sobrescribe.
!>

VL

!>          VL es REAL
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a ser devuelto.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a ser devuelto.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array REAL, dimension (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es array REAL, dimension (LDZ, max(1,M) )
!>          Si JOBZ = 'V', y si INFO = 0, entonces las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz T
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y puede ser calculado con una consulta de espacio de
!>          trabajo estableciendo NZC = -1, ver más abajo.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión líder del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', entonces LDZ >= max(1,N).
!>

NZC

!>          NZC es INTEGER
!>          El número de vectores propios a mantener en el array Z.
!>          Si RANGE = 'A', entonces NZC >= max(1,N).
!>          Si RANGE = 'V', entonces NZC >= el número de valores propios en (VL,VU].
!>          Si RANGE = 'I', entonces NZC >= IU-IL+1.
!>          Si NZC = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina calcula el número de columnas del array Z que
!>          se necesitan para almacenar los vectores propios.
!>          Este valor se devuelve como la primera entrada del array Z, y
!>          no se emite ningún mensaje de error relacionado con NZC por XERBLA.
!>

ISUPPZ

!>          ISUPPZ es array INTEGER, dimension ( 2*max(1,M) )
!>          El soporte de los vectores propios en Z, es decir, los índices
!>          que indican los elementos distintos de cero en Z. El i-ésimo vector propio
!>          calculado es distinto de cero solo en los elementos ISUPPZ( 2*i-1 ) hasta
!>          ISUPPZ( 2*i ). Esto es relevante en el caso en que la matriz
!>          se divide. ISUPPZ solo se accede cuando JOBZ es 'V' y N > 0.
!>

TRYRAC

!>          TRYRAC es LOGICAL
!>          Si TRYRAC = .TRUE., en
!>
!>          La subrutina puede decidir tomar atajos y elegir el algoritmo de bisección
!>          para todos los valores propios en el caso de que se agoten los recursos de CPU.
!>          Si TRYRAC = .FALSE., la subrutina siempre se ejecutará en el intento de
!>          obtener todos los valores propios y vectores propios en la mayor precisión posible.
!>          El uso de la opción TRYRAC = .TRUE. puede ser útil para la verificación de resultados.
!>

WORK

!>          WORK es array REAL, dimension (LWORK)
!>          En la salida, WORK(1) contiene el tamaño de trabajo requerido si LWORK = -1.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si LWORK = -1, entonces se realiza una consulta de tamaño de trabajo y
!>          la subrutina devuelve el tamaño de trabajo requerido en WORK(1).
!>          El valor mínimo requerido para LWORK es N.
!>

IWORK

!>          IWORK es array INTEGER, dimension (LIWORK)
!>          En la salida, IWORK(1) contiene el tamaño de trabajo requerido si LIWORK = -1.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si LIWORK = -1, entonces se realiza una consulta de tamaño de trabajo y
!>          la subrutina devuelve el tamaño de trabajo requerido en IWORK(1).
!>          El valor mínimo requerido para LIWORK es N.
!>

INFO

!>          INFO es INTEGER
!>          INFO = 0:  éxito en la ejecución.
!>          INFO < 0:  si INFO = -i, entonces el i-ésimo argumento tenía un valor inválido.
!>          En particular, argument número 12 (NZC) a menudo causa un error.
!>          INFO > 0:  si INFO = k, entonces la Búsqueda k-ésima no convergió; k=1,2,3,4.
!>                   El valor propio k-ésimo se calcula con la precisión estándar
!>                   y los vectores propios k-ésimos se calculan de forma limitada.
!>

dicta que el código debe verificar si la matriz tridiagonal define sus valores propios con alta precisión relativa. Si es así, el código utiliza algoritmos que conservan la precisión relativa que pueden ser (un poco) más lentos dependiendo de la matriz. Si la matriz no define sus valores propios con alta precisión relativa, el código puede utilizar algoritmos posiblemente más rápidos. Si TRYRAC = .FALSE., el código no está obligado a garantizar valores propios relativamente precisos y puede utilizar las técnicas más rápidas posibles. A la salida, un TRYRAC .TRUE. se establecerá en .FALSE. si la matriz no define sus valores propios con alta precisión relativa.

WORK

!> WORK es un array REAL, de dimensión (LWORK)
!> A la salida, si INFO = 0, WORK(1) devuelve el tamaño óptimo
!> (y mínimo) de LWORK.

LWORK

!> LWORK es un INTEGER
!> La dimensión del array WORK. LWORK >= max(1,18*N)
!> si JOBZ = 'V', y LWORK >= max(1,12*N) si JOBZ = 'N'.
!> Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!> solo calcula el tamaño óptimo del array WORK, devuelve
!> este valor como la primera entrada del array WORK, y ninguna
!> mensaje de error relacionado con LWORK es emitido por XERBLA.

IWORK

!> IWORK es un array INTEGER, de dimensión (LIWORK)
!> A la salida, si INFO = 0, IWORK(1) devuelve el tamaño óptimo de LIWORK.

LIWORK

!> LIWORK es un INTEGER
!> La dimensión del array IWORK. LIWORK >= max(1,10*N)
!> si se desean los vectores propios, y LIWORK >= max(1,8*N)
!> si solo se van a calcular los valores propios.
!> Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!> rutina solo calcula el tamaño óptimo del array IWORK,
!> devuelve este valor como la primera entrada del array IWORK, y
!> ningún mensaje de error relacionado con LIWORK es emitido por XERBLA.

INFO

!> INFO es un INTEGER
!> A la salida, INFO
!> = 0: salida exitosa
!> < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!> > 0: si INFO = 1X, error interno en SLARRE,
!> si INFO = 2X, error interno en SLARRV.
!> Aquí, el dígito X = ABS( IINFO ) < 10, donde IINFO es
!> el código de error distinto de cero devuelto por SLARRE o
!> SLARRV, respectivamente.
