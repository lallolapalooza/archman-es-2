SSBEVX_2STAGE calcula los valores y, opcionalmente, los vectores propios izquierdos y/o derechos para OTRAS matrices

DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subrutina ssbevx_2stage (carácter jobz, carácter range, carácter uplo, entero n, entero kd, real, dimensión( ldab, * ) ab, entero ldab, real, dimensión( ldq, * ) q, entero ldq, real vl, real vu, entero il, entero iu, real abstol, entero m, real, dimensión( * ) w, real, dimensión( ldz, * ) z, entero ldz, real, dimensión( * ) work, entero lwork, entero, dimensión( * ) iwork, entero, dimensión( * ) ifail, entero info)

SSBEVX_2STAGE calcula los valores y, opcionalmente, los vectores propios para matrices de banda simétricas reales utilizando la técnica de 2 etapas para la reducción a tridiagonal. Los valores y vectores propios se pueden seleccionar especificando un rango de valores o un rango de índices para los valores propios deseados.

Propósito:

!>
!> SSBEVX_2STAGE calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de una matriz de banda simétrica real A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal. Los valores y vectores propios se pueden
!> seleccionar especificando ya sea un rango de valores o un rango de
!> índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios;
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 ;
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es ENTERO
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es un array REAL, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda simétrica
!>          A, almacenado en las primeras KD+1 filas del array. La
!>          columna j de A se almacena en la columna j del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd) <= i <= j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j <= i <= min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la primera
!>          superdiagonal y la diagonal de la matriz tridiagonal T
!>          se devuelven en las filas KD y KD+1 de AB, y si UPLO = 'L',
!>          la diagonal y la primera subdiagonal de T se devuelven en las
!>          primeras dos filas de AB.
!>

LDAB

!>          LDAB es ENTERO
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!>

Q

!>          Q es un array REAL, dimensión (LDQ, N)
!>          Si JOBZ = 'V', la matriz ortogonal N por N utilizada en la
!>                         reducción a forma tridiagonal.
!>          Si JOBZ = 'N', el array Q no se referencia.
!>

LDQ

!>          LDQ es ENTERO
!>          La dimensión principal del array Q. Si JOBZ = 'V', entonces
!>          LDQ >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es ENTERO
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es ENTERO
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de anchura menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir AB a forma tridiagonal.
!>
!>          Los valores propios se calcularán de forma más precisa cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*SLAMCH('S'), no cero.
!>          Si esta rutina devuelve con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*SLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, Nota de trabajo de LAPACK #3.
!>

M

!>          M es ENTERO
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array REAL, dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es un array REAL, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es ENTERO
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array REAL, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, 7*N, dimensión) donde
!>                                   dimensión = (2KD+1)*N + KD*NTHREADS + 2*N
!>                                   donde KD es el tamaño de la banda.
!>

SYNOPSIS

 SUBROUTINE SSBEVX_2STAGE(
     UPLO, JOBZ, N, KD, AB, LDAB, RB, LDRB,
     VP, D, Z, LDZ, Zdots, VL, RCOND, IFAIL,
     WORK, LWORK, IWORK, INFO )

     CHARACTER(LEN=1) :: UPLO, JOBZ
     INTEGER :: N, KD, LDAB, LDRB, LDZ, LWORK, INFO
     REAL(4) :: AB( LDAB, * ), RB( LDRB, * ), VP( * ), D( * ),
                Z( LDZ, * ), Zdots( * ), VL( * ), RCOND, WORK( * )
     INTEGER :: IFAIL( * ), IWORK( * )

SSBEVX_2STAGE

  Purpose
  =======
  SSBEVX_2STAGE computes the eigenvalues and eigenvectors of a real
  symmetric tridiagonal matrix S. Eigenvectors are computed for
  each selected eigenvalue.

  SSBEVX_2STAGE uses the QR algorithm with shifted and inverted
  operators for the first stage to reduce the matrix to bidiagonal
  form and then applies the QR algorithm again to reduce the matrix
  to tridiagonal form.

  The eigenvalue decomposition is computed in the second stage using
  the MRRR algorithm.

  Arguments
  =========
  UPLO    (input) CHARACTER*1
          = 'U':  Upper triangle of A is stored and will be used.
          = 'L':  Lower triangle of A is stored and will be used.

  JOBZ    (input) CHARACTER*1
          = 'N':  Compute only the eigenvalues of A.
          = 'V':  Compute the eigenvalues and eigenvectors of A.

  N       (input) INTEGER
          The order of the matrix A. N >= 0.

  KD      (input) INTEGER
          The number of super- or sub-diagonals of the symmetric
          tridiagonal matrix A. KD >= 0.

  AB      (input) REAL for SGBTRF/SGBTRS
          On entry, the upper or lower triangle of the symmetric banded
          matrix AB.
          On exit, AB is overwritten by values generated during the
          computation of the eigenvalues.

  LDAB    (input) INTEGER
          The leading dimension of the array AB. LDAB >= max(1,KD+1).

  RB      (input) REAL for SGBTRF/SGBTRS
          On entry, the upper or lower triangle of the symmetric banded
          matrix RB.
          On exit, RB is overwritten by values generated during the
          computation of the eigenvalues.

  LDRB    (input) INTEGER
          The leading dimension of the array RB. LDRB >= max(1,KD+1).

  VP      (output) REAL for SGBTRF/SGBTRS
          On exit, the block vectors VP.

  D       (output) REAL for SGBTRF/SGBTRS
          On exit, the diagonal entries of the bidiagonal matrix.

  Z       (output) REAL for SGBTRF/SGBTRS
          On exit, if JOBZ = 'V', then the columns of Z are the
          normalized eigenvectors, with the i-th column of Z holding the
          eigenvector corresponding to the i-th diagonal entry in D.
          If JOBZ = 'N', then Z is not accessed.

  LDZ     (input) INTEGER
          The leading dimension of the array Z.
          If JOBZ = 'V', then LDZ >= max(1,N).

  Zdots   (output) REAL for SGBTRF/SGBTRS
          On exit, the squares of the components of the eigenvectors.

  VL      (input) REAL for SGBTRF/SGBTRS
          On entry, the lower bidiagonal matrix.

  RCOND   (output) REAL for SGBTRF/SGBTRS
          The reciprocal condition number of A.

  IFAIL   (output) INTEGER
          If JOBZ = 'V', then if INFO = 0, the first M elements of
          IFAIL are zero. If INFO > 0, then IFAIL contains the
          indices of the eigenvectors that failed to converge.
          If JOBZ = 'N', then IFAIL is not referenced.

  WORK    (workspace) REAL for SGBTRF/SGBTRS
          On exit, if LWORK > 0, WORK(1) contains the optimal
          (and minimal) length of the array WORK required to perform the
          scaling and shifting.

  LWORK   (input) INTEGER
          The dimension of the array WORK.
          If LWORK = -1, then a workspace query is assumed; the routine
          only calculates the optimal size of the WORK array, returns
          this value as the first entry of the WORK array, and no error
          message related to LWORK is issued by XERBLA.

          NTHREADS is the number of threads used when
          openMP compilation is enabled, otherwise =1.
          If JOBZ = 'V' and N > 1, LWORK must be queried. Not yet available

          If LWORK = -1, then a workspace query is assumed; the routine
          only calculates the optimal size of the WORK array, returns
          this value as the first entry of the WORK array, and no error
          message related to LWORK is issued by XERBLA.

  IWORK   (workspace) INTEGER
          If JOBZ = 'V', then if INFO = 0, the first M elements of
          IFAIL are zero.  If INFO > 0, then IFAIL contains the
          indices of the eigenvectors that failed to converge.
          If JOBZ = 'N', then IFAIL is not referenced.

  INFO    (output) INTEGER
          = 0:  successful exit.
          < 0:  if INFO = -i, the i-th argument had an illegal value.
          > 0:  if INFO = i, then i eigenvectors failed to converge.
                Their indices are stored in array IFAIL.
