NOMBRE

sshare - Herramienta para listar las acciones compartidas (shares) de las asociaciones a un clúster.

SINOPSIS

sshare [OPCIONES...]

DESCRIPCIÓN

sshare se utiliza para ver información de acciones compartidas (shares) de Slurm. Este comando solo es viable cuando se ejecuta con el plugin priority/multifactor. La información de sshare se deriva de una base de datos con la interfaz proporcionada por slurmdbd (Slurm Database daemon), que es leída por slurmctld y utilizada para procesar las acciones compartidas disponibles para una asociación dada. sshare proporciona información de acciones compartidas de Slurm sobre Cuentas, Usuarios, Acciones Compartidas Crudas (Raw Shares), Acciones Compartidas Normalizadas (Normalized Shares), Uso Crudo (Raw Usage), Uso Normalizado (Normalized Usage), Uso Efectivo (Effective Usage), el factor de reparto equitativo (Fair-share), el límite GrpTRESMins, Particiones y los minutos TRES actualmente en ejecución acumulados para cada asociación.

OPCIONES

-A, --accounts=<cuenta>
Muestra información para cuentas específicas (lista separada por comas).
-a, --all
Muestra información para todos los usuarios.
-M, --clusters=<cadena>
Clústeres a los que emitir comandos. Tenga en cuenta que slurmdbd debe estar en funcionamiento para que esta opción funcione correctamente, a menos que se ejecute en una federación con FederationParameters=fed_display configurado.
-o, --format=<formato_salida>
Lista de campos separados por comas (use "--helpformat" para obtener una lista de campos disponibles).
--help
Muestra una descripción de las opciones y comandos de sshare.
-l, --long
Listado largo: incluye la información de uso normalizado.
--json, --json=lista, --json=<analizador_datos>
Vuelca la información como JSON utilizando el plugin analizador_datos por defecto o un analizador_datos explícito con parámetros. Los argumentos de ordenación y formato se ignorarán.
-n, --noheader
No se añadirá ninguna cabecera al principio de la salida.
-p, --parsable
La salida estará delimitada por '|' con un '|' al final.
-P, --parsable2
La salida estará delimitada por '|' sin un '|' al final.
-m, --partition
Si existen particiones basadas en asociaciones en el sistema, imprime sus nombres.
--usage
Muestra una descripción de las opciones y comandos de sshare.
-u, --users=<lista_usuarios>
Muestra información para usuarios específicos (lista separada por comas).
-U, --Users
Si se especifica, solo se imprimirán los datos de los usuarios; no se mostrarán los padres ni los ancestros.
-v, --verbose
Muestra más información sobre las opciones especificadas.
-V, --version
Muestra el número de versión de sshare.
--yaml, --yaml=lista, --yaml=<analizador_datos>
Vuelca la información como YAML utilizando el plugin analizador_datos por defecto o un analizador_datos explícito con parámetros. Los argumentos de ordenación y formato se ignorarán.

CAMPOS DE SALIDA SSHARE

Cuenta
La cuenta.
Usuario
El usuario.
Acciones Compartidas Crudas
Las acciones compartidas asignadas al usuario o cuenta.
Acciones Compartidas Normalizadas
Las acciones compartidas asignadas al usuario o cuenta normalizadas respecto al número total de acciones compartidas asignadas.
Uso Crudo
El número de segundos-tres (segundos-cpu si TRESBillingWeights no está definido) de todos los trabajos cargados a la cuenta o usuario. Este número decaerá con el tiempo si se define PriorityDecayHalfLife.
Uso Normalizado (solo aparece con la opción sshare -l)
El Uso Crudo normalizado respecto al número total de segundos-tres de todos los trabajos ejecutados en el clúster, sujeto a la decadencia de PriorityDecayHalfLife cuando se define.
Uso Efectivo
El Uso Efectivo aumenta el uso normalizado para tener en cuenta el uso de cuentas hermanas.
Reparto Equitativo
El factor de reparto equitativo, basado en las acciones compartidas asignadas de un usuario o cuenta y el uso efectivo que se le imputa a ellos o a sus cuentas.
GrpTRESMinutos
El límite de minutos TRES establecido en la cuenta. El número total de minutos de CPU que pueden ser utilizados por trabajos pasados, presentes y futuros que se ejecuten desde esta cuenta y sus hijos.
GrpTRESBruto
El uso bruto de TRES que ha sido utilizado por trabajos que se ejecutan desde esta cuenta y sus hijos.
Minutos TRES Ejecución
El número de minutos TRES asignados por trabajos que se ejecutan actualmente contra la cuenta. Se utiliza para limitar el número total combinado de minutos TRES utilizados por todos los trabajos que se ejecutan con esta cuenta y sus hijos. Esto tiene en cuenta el límite de tiempo de los trabajos en ejecución y lo consume; si se alcanza el límite, no se iniciarán nuevos trabajos hasta que otros trabajos finalicen para permitir que el tiempo se libere.

SSHARE OUTPUT FIELDS

The fields described below are added to the standard sshare(1) output when the Fair Tree configuration parameters are enabled. The exact calculations are done differently. As a result, the following fields are added or modified:

Norm Shares
Las acciones asignadas al usuario o cuenta normalizadas al número total de acciones asignadas dentro del nivel.
Effectv Usage
Effectv Usage es el uso de la asociación normalizado con su padre.
Level FS (solo aparece con la opción sshare -l)
Este es el valor de fairshare de la asociación en comparación con sus hermanos, calculado como Norm Shares / Effectv Usage. Si una asociación está sobreservida, el valor está entre 0 y 1. Si una asociación está subservida, el valor es mayor que 1. Las asociaciones sin uso reciben el valor más alto posible, infinito.

Se puede encontrar más información sobre Fair Tree en doc/html/fair_tree.html o en https://slurm.schedmd.com/fair_tree.html

RENDIMIENTO

La ejecución de sshare envía una llamada a procedimiento remoto a slurmctld. Si llegan demasiadas llamadas de sshare u otros comandos cliente de Slurm que envían llamadas a procedimiento remoto al daemon slurmctld a la vez, puede resultar en una degradación del rendimiento del daemon slurmctld, lo que podría resultar en una denegación de servicio.

No ejecute sshare u otros comandos cliente de Slurm que envíen llamadas a procedimiento remoto a slurmctld desde bucles en scripts de shell u otros programas. Asegúrese de que los programas limiten las llamadas a sshare al mínimo necesario para la información que intenta recopilar.

VARIABLES DE ENTORNO

Algunas opciones de sshare pueden configurarse a través de variables de entorno. Estas variables de entorno, junto con sus opciones correspondientes, se enumeran a continuación. (Nota: Las opciones de línea de comandos siempre tendrán prioridad sobre estas configuraciones.)

SLURM_CONF
La ubicación del archivo de configuración de Slurm.
SLURM_DEBUG_FLAGS
Especifica las banderas de depuración que debe usar sshare. Consulte DebugFlags en la página del manual slurm.conf(5) para ver una lista completa de banderas. La variable de entorno tiene prioridad sobre la configuración en slurm.conf.
SLURM_JSON
Controla la serialización JSON:
compact
Salida JSON lo más compacta posible.
pretty
Salida JSON en formato "pretty" para que sea más legible.
SLURM_YAML
Controla la serialización YAML:
compact Salida YAML lo más compacta posible.
pretty Salida YAML en formato "pretty" para que sea más legible.

EJEMPLOS

Muestra información sobre los usuarios de una cuenta en particular:
$ sshare -A <Cuenta>
Muestra información sobre un usuario específico en un formato analizable:
$ sshare --parsable --users=<Usuario>
