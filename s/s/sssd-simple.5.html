NOMBRE

sssd-simple - archivo de configuración para el proveedor de control de acceso 'simple' de SSSD

DESCRIPCIÓN

Esta página del manual describe la configuración del proveedor de control de acceso simple para sssd(8). Para una referencia detallada de la sintaxis, consulte la sección “FORMATO DEL ARCHIVO” de la página del manual de sssd.conf(5).

El proveedor de acceso simple otorga o deniega el acceso basándose en una lista de acceso o denegación de nombres de usuario o grupo.

Los grupos de otros dominios configurados en sssd.conf, incluso si el proveedor de acceso simple también se usa allí, y los grupos administrados fuera de SSSD no se evalúan.

Se aplican las siguientes reglas:

•No se recomienda dejar una opción vacía, podría causar errores. Si desea permitir a todos los usuarios, no especifique `simple_allow_users` ni `simple_allow_groups`.
•Si se proporciona alguna lista, el orden de evaluación es: permitir → denegar. Esto significa que cualquier regla de denegación coincidente anulará cualquier regla de permiso coincidente.
•Si se proporcionan una o ambas listas de "permitir", se denegará el acceso a todos los usuarios a menos que aparezcan en al menos una de estas listas (condición OR).
•Si se proporcionan una o ambas listas de "denegar", se concederá acceso a todos los usuarios a menos que aparezcan en al menos una de estas listas (condición OR).

OPCIONES DE CONFIGURACIÓN

Consulte la sección “SECCIONES DE DOMINIO” de la página del manual de sssd.conf(5) para obtener detalles sobre la configuración de un dominio SSSD.

simple_allow_users (cadena)

Lista separada por comas de usuarios a los que se les permite iniciar sesión. Si se especifica esta opción, se denegará el acceso a todos los demás usuarios a menos que sean miembros de los grupos que figuran en `simple_allow_groups`.

simple_deny_users (cadena)

Lista separada por comas de usuarios a los que se les deniega explícitamente el acceso. Si se especifica esta opción, se denegará el acceso a estos usuarios independientemente de si aparecen en `simple_allow_users` o `simple_allow_groups`.

Se aplica lógica OR: Se denegará el acceso a un usuario si figura en `simple_deny_users` o si es miembro de un grupo en `simple_deny_groups`.

simple_allow_groups (cadena)

Lista separada por comas de grupos a los que se les permite iniciar sesión. Si se especifica esta opción, se denegará el acceso a todos los demás usuarios a menos que figuren explícitamente en `simple_allow_users`.

Se aplica lógica OR: Un usuario podrá iniciar sesión si figura en `simple_allow_users` o si pertenece a un grupo en `simple_allow_groups`.

Esto solo se aplica a los grupos dentro de este dominio SSSD. Los grupos locales no se evalúan.

simple_deny_groups (cadena)

Lista separada por comas de grupos a los que se les deniega explícitamente el acceso. Esto solo se aplica a los grupos dentro de este dominio SSSD. Los grupos locales no se evalúan.

Se aplica lógica OR: Se denegará el acceso a un usuario si figura en `simple_deny_users` o si es miembro de cualquier grupo en `simple_deny_groups`.

Esto solo se aplica a los grupos dentro de este dominio SSSD. Los grupos locales no se evalúan.

Especificar ningún valor para ninguna de las listas equivale a omitirla por completo. Tenga cuidado con esto al generar parámetros para el proveedor simple mediante scripts automatizados.

EJEMPLO

El siguiente ejemplo asume que SSSD está configurado correctamente y que example.com es uno de los dominios en la sección [sssd]. Este ejemplo muestra solo las opciones específicas del proveedor de acceso simple.

[domain/example.com]
access_provider = simple
simple_allow_users = user1, user2
simple_deny_users = user3, user4
simple_allow_groups = allowed_group1
simple_deny_groups = denied_group1

NOTAS

La jerarquía completa de membresía de grupos se resuelve antes de la comprobación de acceso, por lo tanto, incluso los grupos anidados pueden incluirse en las listas de acceso. Tenga en cuenta que la opción “ldap_group_nesting_level” puede afectar los resultados y debe establecerse en un valor suficiente. (Opción sssd-ldap(5)).
