SSHDIG(1)   SSHDIG(1)

NOMBRE

sshdig - Proporciona interfaces para capturar llamadas al sistema de un host remoto a través de SSH utilizando un binario de captura remoto.

SINOPSIS

sshdig [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interfaz> ] [ --extcap-config ] [ --extcap-capture-filter=<filtro de captura> ] [ --capture ] [ --fifo=<ruta al archivo o tubería> ] [ --remote-host=<dirección IP> ] [ --remote-port=<puerto TCP> ] [ --remote-username=<nombre_de_usuario> ] [ --remote-password=<contraseña> ] [ --sshkey=<ruta_a_clave_privada> ] [ --sshkey-passphrase=<frase_contraseña_clave_privada> ] [ --proxycommand=<comando_proxy_SSH> ] [ --remote-capture-command-select=<selección_comando_captura_remota> ] [ --remote-capture-command=<comando_captura_remota> ] [ --remote-priv=<selección_comando_elevación_privilegios> ] [ --remote-priv-user=<nombre_usuario_privilegiado> ] [ --remote-filter=<filtro_captura_remota> ] [ --remote-count=<número> ] [ --remote-modern-bpf ] [ --remote-io-snaplen=<longitud_instantánea> ]

sshdig --extcap-interfaces

sshdig --extcap-interface=<interfaz> --extcap-dlts

sshdig --extcap-interface=<interfaz> --extcap-config

sshdig --extcap-interface=<interfaz> --fifo=<ruta al archivo o tubería> --capture --remote-host=mihostremoto --remote-port=22 --remote-username=usuario --remote-capture-command='sysdig --unbuffered --write=-'

DESCRIPCIÓN

Sshdig es una herramienta extcap que permite capturar llamadas al sistema a través de una conexión SSH. Debes tener permiso para capturar llamadas al sistema en el sistema remoto.

La funcionalidad es equivalente a:

$ ssh usuario_remoto@host_remoto -p 22222 'sysdig --unbuffered -w -' > ARCHIVO &
$ stratoshark ARCHIVO

Normalmente sshdig no se invoca directamente. En su lugar, puede configurarse a través de la interfaz gráfica de usuario de Stratoshark o su línea de comandos. Lo siguiente iniciará Stratoshark y comenzará a capturar del host host_remoto:

$ stratoshark '-oextcap.sshdig.remotehost:myserver.home.arpa' -i sshdig -k

Interfaces soportadas:

1.sshdig

OPCIONES

--help

Imprime los argumentos del programa.

--version

Imprime la versión del programa.

--extcap-interfaces

Lista las interfaces disponibles.

--extcap-interface=<interfaz>

Usa las interfaces especificadas.

--extcap-dlts

Lista los DLT de la interfaz especificada.

--extcap-config

Lista las opciones de configuración de la interfaz especificada.

--extcap-capture-filter=<filtro de captura>

El filtro de captura. Corresponde al valor proporcionado a través de la opción tshark -f, y al campo Filtro de Captura junto a la lista de interfaces en la interfaz de Stratoshark.

--capture

Comienza la captura desde la interfaz especificada y escribe los datos de paquetes sin procesar en la ubicación especificada por --fifo.

--fifo=<ruta al archivo o tubería>

Guarda el paquete capturado en un archivo o lo envía a través de una tubería.

--remote-host=<host remoto>

La dirección del host remoto para la captura.

--remote-port=<puerto remoto>

El puerto SSH del host remoto.

--remote-username=<nombre_de_usuario>

El nombre de usuario para la autenticación SSH.

--remote-password=<contraseña>

La contraseña a utilizar (si no se usan ssh-agent y pubkey). ADVERTENCIA: las contraseñas se almacenan en texto plano y son visibles para todos los usuarios de este sistema. Se recomienda usar archivos de clave con un agente SSH.

--sshkey=<ruta a la clave privada SSH>

La ruta a una clave privada para la autenticación. NOTA: Solo se soporta el formato de clave/valor de OPENSSH.

--sshkey-passphrase=<frase contraseña clave privada SSH>

La frase contraseña para la clave privada para la autenticación.

--proxycommand=<comando proxy>

El comando a usar como proxy para la conexión SSH.

--remote-capture-command-select=<selección de comando de captura>

El comando a ejecutar en el sistema remoto. Puede ser sysdig para un comando de captura remota usando sysdig, u other, donde el comando de captura remota debe proporcionarse con la opción --remote-capture-command.

--remote-capture-command=<comando de captura>

Un comando de captura remoto personalizado que produce la corriente remota que se muestra en Stratoshark. El comando debe ser capaz de producir una corriente .scap escrita en STDOUT.

--remote-priv=<selección de comando de elevación de privilegios>

El comando a utilizar para lograr la elevación de privilegios para capturar en el host remoto. Puede ser none, sudo o doas.

--remote-priv-user=<nombre de usuario privilegiado>

Si un comando se usa para lograr la elevación de privilegios para capturar en el host remoto y requiere un nombre de usuario, se puede proporcionar aquí.

--remote-filter=<filtro de captura>

El filtro de captura remoto. Esto se pasa al programa de captura remoto y debe cumplir con sus reglas de sintaxis.

--remote-count=<número>

El número de eventos a capturar.

--remote-modern-bpf

Captura usando una sonda eBPF en lugar del módulo del kernel.

--remote-io-snaplen=<longitud de instantánea>

El número de bytes a capturar en cada evento de E/S.

sshdig(8)

NAME

sshdig

capture network traffic from a remote host over SSH

SYNOPSIS

sshdig [–extcap-interface interface] [–fifo fifo] [–capture] [–remote-host host] [–remote-username user] [–remote-port port] [–remote-key key] [–ssh-sha1] [–remote-capture-command-select capture-command] [–remote-capture-command command] [–remote-priv priv] [–remote-priv-user user] [–remote-count count] [–log-level level] [–log-file file]

DESCRIPTION

The sshdig program is an external capture tool for Stratoshark. It allows you to capture network traffic from a remote host over SSH. It works by executing a capture command on the remote host via SSH and piping the output back to Stratoshark.

OPTIONS

The sshdig utility accepts the following options:

–extcap-interface interface
The name of the capture interface. This is typically set by Stratoshark itself.
–fifo fifo
The path to the FIFO (named pipe) where the captured data will be written. Stratoshark will read from this FIFO.
–capture
Start capturing network traffic.
–remote-host host
The hostname or IP address of the remote host to capture traffic from.
–remote-username user
The username to use for the SSH connection.
–remote-port port
The port number to use for the SSH connection (default is 22).
–remote-key key
The path to the SSH private key file to use for authentication.
–ssh-sha1
Support keys and key exchange algorithms using SHA-1 (deprecated).
–remote-capture-command-select capture-command
The remote capture command to build a command line for.
–remote-capture-command command
The remote command used to capture.
–remote-priv priv
Optionally prepend the capture command with sudo or doas on the remote machine.
–remote-priv-user user
User name of privileged user to execute the capture command on the remote machine.
–remote-count count
The number of remote packets to capture. (Default: inf)
–log-level level
Set the log level. Options are: message, info, debug, noisy.
–log-file file
Set a file where log messages are written.

EXAMPLES

To capture:

sshdig --extcap-interface=sshdig --fifo=/tmp/ssh.scap --capture --remote-host 192.168.1.10 \
--remote-username user

Note

CTRL + C should be used to stop the capture in order to ensure clean termination.

The sshdig binary can be renamed to support multiple instances. For instance if we want sshdig to show up twice in Stratoshark (for instance to handle multiple profiles), we can copy sshdig to sshdig-host1 and sshdig-host2. Each binary will show up an interface name same as the executable name. Those executables not being "sshdig" will show up as "custom version" in the capture source description.
