SSYSV_ROOK calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Documentación de Función/Subrutina

subroutine ssysv_rook (character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) work, integer lwork, integer info)

SSYSV_ROOK calcula la solución a un sistema real de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> SSYSV_ROOK calcula la solución a un sistema real de ecuaciones
!> lineales
!>    A * X = B,
!> donde A es una matriz simétrica de N por N y X y B son matrices de N
!> por NRHS.
!>
!> Se utiliza el método de pivoteo diagonal para factorizar A como
!>    A = U * D * U**T,  si UPLO = 'U', o
!>    A = L * D * L**T,  si UPLO = 'L',
!> donde U (o L) es un producto de permutaciones y matrices triangulares
!> unitarias superiores (inferiores), y D es simétrica y diagonal por
!> bloques con bloques diagonales de 1x1 y 2x2.
!>
!> Se llama a SSYTRF_ROOK para calcular la factorización de una matriz
!> simétrica real A utilizando el método de pivoteo diagonal acotado de
!> Bunch-Kaufman ().
!>
!> La forma factorizada de A se utiliza luego para resolver el sistema
!> de ecuaciones A * X = B llamando a SSYTRS_ROOK.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior de N por N de A contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior
!>          de A no se referencia.  Si UPLO = 'L', la parte inferior de
!>          N por N de A contiene la parte triangular inferior de la matriz
!>          A, y la parte estrictamente triangular superior de A no se
!>          referencia.
!>
!>          En la salida, si INFO = 0, la matriz diagonal por bloques D y
!>          los multiplicadores utilizados para obtener el factor U o L de
!>          la factorización A = U*D*U**T o A = L*D*L**T tal como lo calcula
!>          SSYTRF_ROOK.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D,
!>          tal como los determina SSYTRF_ROOK.
!>
!>          Si UPLO = 'U':
!>               Si IPIV(k) > 0, entonces las filas y columnas k y IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>               Si IPIV(k) < 0 y IPIV(k-1) < 0, entonces las filas y
!>               columnas k y -IPIV(k) fueron intercambiadas y las filas y
!>               columnas k-1 y -IPIV(k-1) fueron intercambiadas,
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>               Si IPIV(k) > 0, entonces las filas y columnas k y IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>               Si IPIV(k) < 0 y IPIV(k+1) < 0, entonces las filas y
!>               columnas k y -IPIV(k) fueron intercambiadas y las filas y
!>               columnas k+1 y -IPIV(k+1) fueron intercambiadas,
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>

B

!>          B es un array REAL, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B de N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1, y para el mejor rendimiento
!>          LWORK >= max(1,N*NB), donde NB es el tamaño de bloque óptimo para
!>          SSYTRF_ROOK.
!>
!>          TRS se realizará con BLAS de Nivel 2
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) es exactamente cero. La factorización
!>               se ha completado, pero la matriz diagonal por bloques D es
!>               exactamente singular, por lo que la solución no pudo ser
!>               calculada.
!>
