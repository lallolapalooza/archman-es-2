Documentación de Función/Subrutina

subroutine ssytri_3 (character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) e, integer, dimension( * ) ipiv, real, dimension( * ) work, integer lwork, integer info)

SSYTRI_3

Propósito:

!> SSYTRI_3 calcula la inversa de una matriz indefinida real simétrica
!> A utilizando la factorización calculada por SSYTRF_RK o SSYTRF_BK:
!>
!>     A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es simétrica y diagonal por bloques con
!> bloques diagonales de 1x1 y 2x2.
!>
!> SSYTRI_3 establece la dimensión líder del espacio de trabajo antes de
!> llamar a SSYTRI_3X, que realmente calcula la inversa. Esta es la versión
!> en bloques del algoritmo, llamando a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se
!>          almacenan como una matriz triangular superior o inferior.
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la diagonal de la matriz diagonal por bloques D y
!>          los factores U o L calculados por SSYTRF_RK y SSYTRF_BK:
!>            a) SÓLO los elementos diagonales de la matriz diagonal por bloques
!>               simétrica D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos de la supradiagonal (o subdiagonal) de D
!>                deben proporcionarse en la entrada en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte supradiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>
!>          En la salida, si INFO = 0, la inversa simétrica de la matriz
!>          original.
!>             Si UPLO = 'U': se forma la parte triangular superior de la inversa
!>             y la parte de A debajo de la diagonal no se referencia;
!>             Si UPLO = 'L': se forma la parte triangular inferior de la inversa
!>             y la parte de A por encima de la diagonal no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

E

!>          E es un array REAL, de dimensión (N)
!>          En la entrada, contiene los elementos supradiagonales (o subdiagonales)
!>          de la matriz diagonal por bloques simétrica D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i),i=2:N, E(1) no se referencia;
!>          Si UPLO = 'L': E(i) = D(i+1,i),i=1:N-1, E(N) no se referencia.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) no se referencia en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como fueron determinados por SSYTRF_RK o SSYTRF_BK.
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK)).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.
!>          Si N = 0, LWORK >= 1, de lo contrario LWORK >= (N+NB+1)*(NB+3).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del tamaño
!>          óptimo del array WORK, devuelve este valor como la primera
!>          entrada del array WORK, y XERBLA no emite ningún mensaje de
!>          error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) = 0; la matriz es singular y su
!>               inversa no pudo ser calculada.
!>
