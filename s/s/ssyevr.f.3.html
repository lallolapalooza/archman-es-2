Documentación de Función/Subrutina

subrutina ssyevr (character jobz, character range, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSYEVR calcula los valores propios seleccionados y, opcionalmente, los vectores propios de una matriz simétrica real A. Los valores y vectores propios pueden seleccionarse especificando un rango de valores o un rango de índices para los valores propios deseados. Las invocaciones con diferentes elecciones para estos parámetros pueden resultar en el cálculo de valores propios y/o vectores propios ligeramente diferentes para la misma matriz. La razón de este comportamiento es que existe una variedad de algoritmos (cada uno funcionando mejor para un conjunto particular de opciones) y SSYEVR intenta seleccionar el mejor basándose en varios parámetros. En todos los casos, los valores calculados son precisos dentro de los límites de la aritmética de precisión finita.

SSYEVR reduce primero la matriz A a la forma tridiagonal T con una llamada a SSYTRD. Luego, siempre que sea posible, SSYEVR llama a SSTEMR para calcular el espectro propio utilizando Representaciones Relativamente Robustas. SSTEMR calcula los valores propios mediante el algoritmo dqds, mientras que los vectores propios ortogonales se calculan a partir de varias representaciones L D L^T (también conocidas como Representaciones Relativamente Robustas). La ortogonalización de Gram-Schmidt se evita tanto como sea posible. Más específicamente, los diversos pasos del algoritmo son los siguientes.

Para cada bloque no reducido (submatriz) de T,

   (a) Calcular T - sigma I  = L D L^T, de modo que L y D
       definen todos los valores propios deseados con alta precisión relativa.
       Esto significa que pequeños cambios relativos en las entradas de D y L
       causan solo pequeños cambios relativos en los valores propios y
       vectores propios. La representación estándar (no factorizada) de la
       matriz tridiagonal T no tiene esta propiedad en general.
   (b) Calcular los valores propios con precisión adecuada.
       Si se desean los vectores propios, el algoritmo alcanza la precisión
       completa de los valores propios calculados solo justo antes de que
       los vectores correspondientes deban calcularse, ver pasos c) y d).
   (c) Para cada clúster de valores propios cercanos, seleccionar un nuevo
       desplazamiento cercano al clúster, encontrar una nueva factorización
       y refinar los valores propios desplazados con precisión adecuada.
   (d) Para cada valor propio con una separación relativa suficientemente grande,
       calcular el vector propio correspondiente formando una factorización retorcida
       que revele rangos. Volver a c) para cualquier clúster que quede.

La precisión deseada de la salida se puede especificar mediante el parámetro de entrada ABSTOL.

Para más detalles, ver la documentación de SSTEMR y:

Inderjit S. Dhillon y Beresford N. Parlett: Linear Algebra and its Applications, 387(1), pp. 1-28, Agosto 2004.

Inderjit Dhillon y Beresford Parlett: SIAM Journal on Matrix Analysis and Applications, Vol. 25, 2004. También Nota de Trabajo LAPACK 154.

Inderjit Dhillon: , Informe Técnico de la División de Ciencias de la Computación No. UCB/CSD-97-971, UC Berkeley, Mayo 1997.

Nota 1: SSYEVR llama a SSTEMR cuando se solicita el espectro completo en máquinas que cumplen el estándar de punto flotante ieee-754. SSYEVR llama a SSTEBZ y SSTEIN en máquinas no ieee y cuando se realizan solicitudes de espectro parcial.

La ejecución normal de SSTEMR puede crear NaNs e infinitos y por lo tanto puede abortar debido a una excepción de punto flotante en entornos que no manejan NaNs e infinitos de la manera predeterminada estándar de ieee.

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular los valores propios y los vectores propios.
!>
!>          Este parámetro influye en la elección del algoritmo y
!>          puede alterar los valores calculados.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 (VL,VU].
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>          Para RANGE = 'V' o 'I' y IU - IL < N - 1, se llaman SSTEBZ y
!>          SSTEIN.
!>
!>          Este parámetro influye en la elección del algoritmo y
!>          puede alterar los valores calculados.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  el triángulo superior de A se almacena;
!>          = 'L':  el triángulo inferior de A se almacena.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la
!>          parte triangular superior de N x N que contiene A almacena
!>          la parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior de N x N que contiene A almacena
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, se
!>          destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

NAME

ssyevr - Calcula los autovalores y, opcionalmente, los autovectores de una matriz simétrica o Hermítica.

SYNOPSIS

 CALL SSYEVR(
     JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU, ABSTOL, M, W, Z, LDZ,
     ISUPPZ, WORK, LWORK, IWORK, LIWORK, INFO
 )

Function/Subroutine Documentation

SSYEVR calcula los autovalores y, opcionalmente, los autovectores de una matriz simétrica o Hermítica.

Cada uno de los siguientes argumentos es una variable descrita a continuación.

JOBZ

!>          JOBZ is CHARACTER*1
!>          = 'N':  Compute only the eigenvalues of A.
!>          = 'V':  Compute the eigenvalues and eigenvectors of A.
!>

RANGE

!>          RANGE is CHARACTER*1
!>          = 'A': all the eigenvalues will be found.
!>          = 'V': all eigenvalues W(i) satisfying VL <= W(i) <= VU will be
!>                 found.
!>          = 'I': all eigenvalues I-th through I+M-1 will be found.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the symmetric or Hermitian matrix A.
!>          If UPLO = 'U', only the upper-left part of the array A is
!>          accessed.
!>          If UPLO = 'L', only the lower-left part of the array A is
!>          accessed.
!>
!>          On exit, if JOBZ = 'V', the lower triangle of A may be
!>          overwritten by lower triangle of array AF.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!>

VL

!>          VL is REAL
!>          If RANGE='V' and UPLO='U', the lower bound of the interval for
!>          the desired eigenvalues.
!>          Not referenced if RANGE = 'A' or 'I'.
!>

VU

!>          VU is REAL
!>          If RANGE='V' and UPLO='U', the upper bound of the interval for
!>          the desired eigenvalues.
!>          Not referenced if RANGE = 'A' or 'I'.
!>

IL

!>          IL is INTEGER
!>          If RANGE='I', the index of the first desired eigenvalue when
!>          sequenced in increasing order.
!>          Not referenced if RANGE = 'A' or 'V'.
!>

IU

!>          IU is INTEGER
!>          If RANGE='I', the index of the last desired eigenvalue when
!>          sequenced in increasing order.
!>          Not referenced if RANGE = 'A' or 'V'.
!>

ABSTOL

!>          ABSTOL is REAL
!>          The absolute tolerance for the eigenvalues. The eigenvalues
!>          selected will be computed within the accuracy specified by ABSTOL.
!>          If ABSTOL is set to the default value of the negative of the
!>          run time overflow, the routine will use SLAMCH('Safe minimum').
!>          Doing so will guarantee that eigenvalues are computed to high
!>          relative accuracy when possible in future releases. The current
!>          code does not make any guarantees about high relative accuracy,
!>          but future releases will. See J. Barlow and J. Demmel,
!>          , LAPACK Working Note #7, for a discussion
!>          of which matrices define their eigenvalues to high relative
!>          accuracy.
!>

M

!>          M is INTEGER
!>          The total number of eigenvalues found.  0 <= M <= N.
!>          If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.
!>

W

!>          W is REAL array, dimension (N)
!>          The first M elements contain the selected eigenvalues in
!>          ascending order.
!>

Z

!>          Z is REAL array, dimension (LDZ, max(1,M))
!>          If JOBZ = 'V', then if INFO = 0, the first M columns of Z
!>          contain the orthonormal eigenvectors of the matrix A
!>          corresponding to the selected eigenvalues, with the i-th
!>          column of Z holding the eigenvector associated with W(i).
!>          If JOBZ = 'N', then Z is not referenced.
!>          Note: the user must ensure that at least max(1,M) columns are
!>          supplied in the array Z; if RANGE = 'V', the exact value of M
!>          is not known in advance and an upper bound must be used.
!>          Supplying N columns is always safe.
!>

LDZ

!>          LDZ is INTEGER
!>          The leading dimension of the array Z. LDZ >= 1, and if
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
!>          The support of the eigenvectors in Z, i.e., the indices
!>          indicating the nonzero elements in Z. The i-th eigenvector
!>          is nonzero only in elements ISUPPZ( 2*i-1 ) through
!>          ISUPPZ( 2*i ). This is an output of SSTEMR (tridiagonal
!>          matrix). The support of the eigenvectors of A is typically
!>          1:N because of the orthogonal transformations applied by SORMTR.
!>          Implemented only for RANGE = 'A' or 'I' and IU - IL = N - 1
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          If N <= 1, LWORK >= 1, else LWORK >= 26*N.
!>          For optimal efficiency, LWORK >= (NB+6)*N,
!>          where NB is the max of the blocksize for SSYTRD and SORMTR
!>          returned by ILAENV.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal sizes of the WORK and IWORK
!>          arrays, returns these values as the first entries of the WORK
!>          and IWORK arrays, and no error message related to LWORK or
!>          LIWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (MAX(1,LIWORK))
!>          On exit, if INFO = 0, IWORK(1) returns the optimal LWORK.
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.
!>          If N <= 1, LIWORK >= 1, else LIWORK >= 10*N.
!>
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal sizes of the WORK and
!>          IWORK arrays, returns these values as the first entries of
!>          the WORK and IWORK arrays, and no error message related to
!>          LWORK or LIWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  Internal error
!>
