SSCONVERT(1) GNOME SSCONVERT(1)

NOMBRE

ssconvert - un conversor de formatos de hoja de cálculo de línea de comandos

SINOPSIS

ssconvert [OPCIONES] archivo_entrada archivo_salida

ssconvert [OPCIONES] --merge-to archivo_salida archivo_entrada1 archivo_entrada2 ...

DESCRIPCIÓN

ssconvert es una utilidad de línea de comandos para convertir archivos de hoja de cálculo entre varios formatos de archivo de hoja de cálculo. Es una utilidad complementaria a Gnumeric, el potente programa de hoja de cálculo creado por el proyecto GNOME.

ssconvert acepta nombres de archivo o URIs como archivo_entrada archivo_salida. Las URIs especiales fd://0 y fd://1 pueden usarse para la entrada estándar y la salida estándar respectivamente.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones de una sola letra que comienzan con un guion (`-') y opciones más largas que comienzan con dos guiones (`--').

Opciones principales

--recalc
Recalcula todas las celdas antes de escribir el resultado.
--set CELDA=CONTENIDO
Establece el valor de CELDA a CONTENIDO. Para poner una expresión en una celda, añade un signo igual adicional, por ejemplo --set "A11==A10+1". Esta opción puede repetirse tantas veces como sea necesario. El libro de trabajo se recalculará después de que todas las celdas hayan sido establecidas, siempre que el libro de trabajo esté configurado para recálculo automático. Si no es así, el recálculo puede forzarse con --recalc.
-v, --verbose
Sé un poco más detallado sobre lo que está sucediendo.
--list-exporters
Lista los exportadores disponibles (formatos de archivo que se pueden escribir).
-T, --export-type=ID
Especifica qué exportador usar; véase abajo para una lista. Esto solo es necesario cuando el formato correcto no se deduce del nombre del archivo de salida. La lista de formatos de exportación disponibles se puede generar usando la opción --list-exporters. Sin embargo, cuando se solicita la exportación de imágenes usando la opción --export-graphs, la lista de formatos de imagen debe ser consultada en su lugar. Esa lista se puede generar usando la opción --list-image-formats.
-O, --export-options=cadena_opciones
Especifica parámetros para el exportador elegido. cadena_opciones es una lista de pares parámetro=valor, separados por espacios. Los nombres de los parámetros y los valores permitidos son específicos del exportador y se documentan a continuación. Se pueden especificar varios parámetros.
--export-graphs
Exporta los gráficos (o diagramas) dentro de la hoja de cálculo de entrada a archivos de imagen numerados (SVG por defecto). La lista de formatos de imagen disponibles se puede imprimir con --list-image-formats
--list-importers
Lista los importadores disponibles (formatos de archivo que se pueden leer). -I, --import-type=ID Especifica qué importador usar; véase abajo para una lista. Esto solo es necesario cuando el formato correcto no se deduce del nombre del archivo de entrada.
--list-image-formats
Lista los formatos de imagen disponibles para la exportación de gráficos
-E, --import-encoding=CADENA
Especifica una codificación para el contenido importado.
-M, --merge-to=NOMBRE_ARCHIVO
Fusiona una colección de libros de trabajo en uno solo. El tamaño de la hoja se expandirá al máximo de todos los libros de trabajo. Los nombres en el ámbito de los libros de trabajo individuales terminarán en el ámbito del libro de trabajo fusionado. La fusión se abortará si hay conflictos de nombres.
-S, --export-file-per-sheet
Exporta un archivo por cada hoja si el exportador solo soporta una hoja a la vez. El nombre del archivo de salida se trata como una plantilla en la que el número de hoja se sustituye por %n, el nombre de la hoja se sustituye por %s, y el nombre del objeto de hoja se sustituye por %o en caso de exportación de gráficos. Si no hay sustituciones, se añade un valor por defecto de ".%n".

Opciones de ayuda

--version
Muestra la versión de ssconvert.
-h, --help, --usage
Muestra un breve mensaje de uso.
--help-all
Muestra todas las opciones de ayuda.
--help-libspreadsheet
Muestra las opciones de Gnumeric.

OPCIONES PARA EL EXPORTADOR DE FORMATO DE DOCUMENTO PORTÁTIL (*.pdf)

sheet
Nombre de la hoja del libro de trabajo sobre la que operar. Puedes especificar varias hojas repitiendo esta opción. Se ignora si se proporciona la opción object.
active-sheet
Selecciona la hoja activa sobre la que operar. El valor de esta opción es irrelevante, pero el signo igual es obligatorio.
object
Nombre del objeto de la hoja a imprimir. Si se proporciona esta opción, se ignorará cualquier opción sheet. Solo se exportará el primer object proporcionado.
paper
Tamaño del papel. Los valores válidos incluyen "A4" para ISO A4 y "na_letter_8.5x11in" para US Letter. Si se especifica un gráfico individual a través de la opción object, un tamaño de papel de "fit" reducirá el tamaño del papel al tamaño del gráfico.

OPCIONES PARA EL EXPORTADOR DE TEXTO CONFIGURABLE (*.txt)

sheet
Nombre de la hoja del libro de trabajo sobre la que operar. Puedes especificar varias hojas repitiendo esta opción.
active-sheet
Selecciona la hoja activa sobre la que operar. El valor de esta opción es irrelevante, pero el signo igual es obligatorio.
eol
Convención de fin de línea; cómo se terminan las líneas. "unix" para salto de línea, "mac" para retorno de carro; "windows" para retorno de carro más salto de línea.
charset
La codificación de caracteres de la salida. Por defecto es UTF-8.
locale
La configuración regional a utilizar para el formato de números y fechas. Por defecto es la configuración regional actual según lo informado por locale(1). Consulta la salida de locale -a para ver los valores aceptables.
quote
El carácter o cadena utilizado para citar campos. Por defecto es "\"" (comilla doble).
separator
La cadena utilizada para separar campos. Por defecto es espacio.
format
Cómo deben formatearse las celdas. Los valores aceptables son: "automatic" (aplicar formato automático; por defecto), "raw" (salida de datos en bruto, sin formato), o "preserve" (conservar el formato del documento original).

Esto aborda la diferencia entre el contenido de una celda y la forma en que se formatea ese contenido.

Considera una celda en un documento de entrada de Gnumeric que se introdujo como "4/19/73" en una configuración regional de EE. UU., con un formato establecido en "d-mmm-yyyy" y, por lo tanto, formateado como "19-Apr-1973".

Con la configuración predeterminada format de "automatic", se exportará como "1973/04/19". Con "preserve", se conservará el formato y se exportará como "19-Apr-1973". Con "raw", se exportará como "26773" (la representación interna de Gnumeric: días desde una época).

transliterate-mode
Cómo manejar caracteres no representables, es decir, caracteres que no se pueden representar en el conjunto de caracteres de salida elegido. Los valores aceptables son: "transliterate" o "escape". El primero reescribirá los caracteres que no se puedan representar en el conjunto de caracteres de salida en una aproximación con uno o más caracteres que sí se puedan. Consulta iconv(1) para obtener más detalles. El valor predeterminado es "escape", que reemplazará un carácter no representable con una secuencia de escape que identifica el punto de código unicode.
quoting-mode
¿Cuándo se necesitan comillas para los datos? "never", "auto" (pone comillas donde se necesitan) o "always". Por defecto es "auto".
quoting-on-whitespace
Controla si los espacios en blanco iniciales o finales fuerzan el uso de comillas. Por defecto es TRUE.

EJEMPLO

Para convertir el archivo Gnumeric foo.gnumeric a un archivo en formato Microsoft Excel (TM) foo.xls:

ssconvert foo.gnumeric foo.xls

El formato de exportación se puede especificar explícitamente, para anular el valor predeterminado (que se basa en la extensión del archivo):

ssconvert --export-type=Gnumeric_stf:stf_csv foo.xls foo.txt

Para convertir un archivo en formato Excel statfuns.xls a un archivo de texto, especificando el punto y coma como carácter separador:

ssconvert -O 'separator=; format=raw' samples/excel/statfuns.xls statfuns.txt

Para exportar los gráficos del archivo de entrada input.gnumeric a archivos SVG numerados:

ssconvert --export-graphs input.gnumeric 'output.%n.svg'

Para exportar los gráficos del archivo de entrada input.gnumeric a archivos PNG numerados:

ssconvert --export-type=png --export-graphs input.gnumeric 'output.%n.png'
