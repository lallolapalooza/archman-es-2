DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine ssytrd_sy2sb (character uplo, integer n, integer kd, real, dimension( lda, * ) a, integer lda, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SSYTRD_SY2SB

Propósito:

!>
!> SSYTRD_SY2SB reduce una matriz simétrica real A a una forma de banda
!> diagonal simétrica real AB mediante una transformación de similitud
!> ortogonal: Q**T * A * Q = AB.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A se almacena;
!>          = 'L':  El triángulo inferior de A se almacena.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz reducida si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>          La matriz reducida se almacena en el array AB.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular N-por-N líder contiene la parte superior
!>          triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia.  Si UPLO = 'L', la parte
!>          inferior triangular N-por-N líder contiene la parte inferior
!>          triangular de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>          En la salida, si UPLO = 'U', la diagonal y la primera superdiagonal
!>          de A se sobrescriben con los elementos correspondientes de la
!>          matriz tridiagonal T, y los elementos por encima de la primera
!>          superdiagonal, con el array TAU, representan la matriz ortogonal
!>          Q como un producto de reflectores elementales; si UPLO
!>          = 'L', la diagonal y la primera subdiagonal de A se
!>          sobrescriben con los elementos correspondientes de la matriz
!>          tridiagonal T, y los elementos por debajo de la primera
!>          subdiagonal, con el array TAU, representan la matriz ortogonal
!>          Q como un producto de reflectores elementales. Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

AB

!>          AB es array REAL, dimension (LDAB,N)
!>          En la salida, el triángulo superior o inferior de la matriz de
!>          banda simétrica A, almacenada en las primeras KD+1 filas del
!>          array. La j-ésima columna de A se almacena en la j-ésima
!>          columna del array AB como sigue:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión líder del array AB.  LDAB >= KD+1.
!>

TAU

!>          TAU es array REAL, dimension (N-KD)
!>          Los factores escalares de los reflectores elementales (ver
!>          Detalles Adicionales).
!>

WORK

!>          WORK es array REAL, dimension (LWORK)
!>          En la salida, si INFO = 0, o si LWORK = -1,
!>          WORK(1) devuelve el tamaño de LWORK.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK que debe ser calculada
!>          mediante una consulta de espacio de trabajo.
!>          Si N <= KD+1, LWORK >= 1, de lo contrario LWORK = MAX(1, LWORK_QUERY)
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y ninguna
!>          mensaje de error relacionado con LWORK es emitido por XERBLA.
!>          LWORK_QUERY = N*KD + N*max(KD,FACTOPTNB) + 2*KD*KD
!>          donde FACTOPTNB es el bloqueo utilizado por el algoritmo QR o LQ
!>          (generalmente FACTOPTNB=128 es una buena opción, de lo contrario
!>          poner LWORK=-1 proporcionará el tamaño de WORK).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  Implementado por Azzam Haidar.
!>
!>  Todos los detalles están disponibles en el informe técnico, SC11, SC13 papers.
!>
!>  Azzam Haidar, Hatem Ltaief, y Jack Dongarra.
!>  Reducción paralela a formas condensadas para problemas de valores propios simétricos
!>  utilizando kernels agregados de grano fino y conscientes de la memoria. En Proceedings
!>  de la Conferencia Internacional de 2011 para Computación de Alto Rendimiento,
!>  Redes, Almacenamiento y Análisis (SC '11), Nueva York, NY, EE. UU.,
!>  Artículo 8, 11 páginas.
!>  http://doi.acm.org/10.1145/2063384.2063394
!>
!>  A. Haidar, J. Kurzak, P. Luszczek, 2013.
!>  Un algoritmo de valores singulares paralelos mejorado y su implementación
!>  para hardware multinúcleo, En Proceedings de la Conferencia Internacional de 2013
!>  para Computación de Alto Rendimiento, Redes, Almacenamiento y Análisis (SC '13).
!>  Denver, Colorado, EE. UU., 2013.
!>  Artículo 90, 12 páginas.
!>  http://doi.acm.org/10.1145/2503210.2503292
!>
!>  A. Haidar, R. Solca, S. Tomov, T. Schulthess y J. Dongarra.
!>  Un novedoso solucionador de autovalores generalizado híbrido CPU-GPU
!>  basado en tareas de grano fino conscientes de la memoria.
!>  International Journal of High Performance Computing Applications.
!>  Volumen 28 Número 2, Páginas 196-209, Mayo de 2014.
!>  http://hpc.sagepub.com/content/28/2/196
!>
!> 
!>
!>  Si UPLO = 'U', la matriz Q se representa como un producto de reflectores
!>  elementales
!>
!>     Q = H(k)**T . . . H(2)**T H(1)**T, donde k = n-kd.
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real, y v es un vector real con
!>  v(1:i+kd-1) = 0 y v(i+kd) = 1; conjg(v(i+kd+1:n)) se almacena en la salida en
!>  A(i,i+kd+1:n), y tau en TAU(i).
!>
!>  Si UPLO = 'L', la matriz Q se representa como un producto de reflectores
!>  elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = n-kd.
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real, y v es un vector real con
!>  v(kd+1:i) = 0 y v(i+kd+1) = 1; v(i+kd+2:n) se almacena en la salida en
!>  A(i+kd+2:n,i), y tau en TAU(i).
!>
!>  El contenido de A en la salida se ilustra con los siguientes ejemplos
!>  con n = 5:
!>
!>  si UPLO = 'U':                       si UPLO = 'L':
!>
!>    (  ab  ab/v1  v1      v1     v1    )              (  ab                            )
!>    (      ab     ab/v2   v2     v2    )              (  ab/v1  ab                     )
!>    (             ab      ab/v3  v3    )              (  v1     ab/v2  ab              )
!>    (                     ab     ab/v4 )              (  v1     v2     ab/v3  ab       )
!>    (                            ab    )              (  v1     v2     v3     ab/v4 ab )
!>
!>  donde d y e denotan elementos diagonales y fuera de la diagonal de T, y vi
!>  denota un elemento del vector que define H(i).
!> .fi
