SSGREP(1) GNOME SSGREP(1)

NOMBRE

ssgrep - buscar cadenas en hojas de cálculo

SINOPSIS

ssgrep [OPCIONES] [ARCHIVOS]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando ssgrep.

ssgrep es una utilidad de línea de comandos para buscar cadenas en hojas de cálculo de cualquier formato compatible con gnumeric. Sin opciones que modifiquen la salida, ssgrep imprime una línea por cada coincidencia. Una coincidencia consiste en el contenido coincidente de una celda o, si se proporciona la opción -R, el resultado de la expresión coincidente de una celda.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones de una sola letra que comienzan con un guion (`-') y opciones más largas que comienzan con dos guiones (`--').

Opciones que controlan el manejo de archivos de entrada

--recalcular
Recalcular todas las celdas

Opciones que controlan los patrones y la coincidencia de patrones

-a, --archivo-palabras-clave=ARCHIVO
La ruta a un archivo de texto que contiene una palabra clave por línea
-i, --ignorar-mayusculas-minusculas
Ignorar las diferencias en mayúsculas y minúsculas
-p, --palabra-completa
Coincidir solo con palabras completas
-F, --cadenas-fijas
El patrón es un conjunto de cadenas fijas
-R, --resultados-busqueda
Buscar también los resultados de las expresiones
-v, --invertir-coincidencia
Buscar celdas que no coinciden

Opciones que controlan la salida en general

-c, --contar
Solo imprimir un recuento de coincidencias por archivo
-L, --archivos-sin-coincidencias
Imprimir nombres de archivo sin coincidencias
-l, --archivos-con-coincidencias
Imprimir nombres de archivo con coincidencias
-q, --silencioso
Suprimir toda la salida normal
-H, --con-nombre-archivo
Imprimir el nombre de archivo para cada coincidencia
-h, --sin-nombre-archivo
No imprimir el nombre de archivo para cada coincidencia
-n, --imprimir-lugar
Imprimir la ubicación de cada coincidencia
-T, --imprimir-tipo
Imprimir el tipo de ubicación de cada coincidencia

Opciones de ayuda

-V, --version
Mostrar la versión de ssgrep
-?, --help
Mostrar las opciones compatibles
--uso
Mostrar un breve mensaje de uso

EJEMPLO

Para buscar la cadena "SUM" en el archivo foo.gnumeric:

ssgrep SUM foo.gnumeric

Para buscar las cadenas del archivo keywords en la hoja de cálculo foo.xls:

ssgrep --archivo-palabras-clave=keywords foo.xls
