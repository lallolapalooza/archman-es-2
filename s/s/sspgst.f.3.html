subrutina sspgst (entero itype, carácter uplo, entero n, real, dimensión( * ) ap, real, dimensión( * ) bp, entero info)

SSPGST

Propósito:

!>
!> SSPGST reduce un problema generalizado de valores propios simétrico-definido real
!> a la forma estándar, usando almacenamiento empaquetado.
!>
!> Si ITYPE = 1, el problema es A*x = lambda*B*x,
!> y A se sobrescribe con inv(U**T)*A*inv(U) o inv(L)*A*inv(L**T)
!>
!> Si ITYPE = 2 o 3, el problema es A*B*x = lambda*x o
!> B*A*x = lambda*x, y A se sobrescribe con U*A*U**T o L**T*A*L.
!>
!> B debe haber sido previamente factorizado como U**T*U o L*L**T por SPPTRF.
!>

Parámetros

ITYPE 
!>          ITYPE es ENTERO
!>          = 1: calcular inv(U**T)*A*inv(U) o inv(L)*A*inv(L**T);
!>          = 2 o 3: calcular U*A*U**T o L**T*A*L.
!>

UPLO

!>          UPLO es CARÁCTER*1
!>          = 'U':  El triángulo superior de A se almacena y B se factoriza como
!>                  U**T*U;
!>          = 'L':  El triángulo inferior de A se almacena y B se factoriza como
!>                  L*L**T.
!>

N

!>          N es ENTERO
!>          El orden de las matrices A y B.  N >= 0.
!>

AP

!>          AP es array REAL, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          A, empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, si INFO = 0, la matriz transformada, almacenada en el
!>          mismo formato que A.
!>

BP

!>          BP es array REAL, dimensión (N*(N+1)/2)
!>          El factor triangular de la factorización de Cholesky de B,
!>          almacenado en el mismo formato que A, tal como lo devuelve SPPTRF.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
