SSYTRS

Propósito:

!>
!> SSYTRS resuelve un sistema de ecuaciones lineales A*X = B con una matriz
!> simétrica real A utilizando la factorización A = U*D*U**T o
!> A = L*D*L**T calculada por SSYTRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, forma es A = U*D*U**T;
!>          = 'L':  Triangular inferior, forma es A = L*D*L**T.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          La matriz diagonal por bloques D y los multiplicadores usados para
!>          obtener el factor U o L tal como fue calculado por SSYTRF.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array ENTERO, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como fue determinada por SSYTRF.
!>

B

!>          B es un array REAL, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
