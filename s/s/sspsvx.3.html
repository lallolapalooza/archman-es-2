subrutina sspsvx (character fact, character uplo, integer n, integer nrhs, real, dimension( * ) ap, real, dimension( * ) afp, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SSPSVX calcula la solución del sistema de ecuaciones lineales A * X = B para matrices OTHER

Propósito:

!>
!> SSPSVX utiliza la factorización por pivoteo diagonal A = U*D*U**T o
!> A = L*D*L**T para calcular la solución de un sistema real de ecuaciones
!> lineales A * X = B, donde A es una matriz simétrica de N por N almacenada
!> en formato empaquetado y X e B son matrices de N por NRHS.
!>
!> También se proporcionan límites de error para la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza el método de pivoteo diagonal para factorizar A como
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices triangulares superiores (inferiores)
!>    unitarias y de permutación, y D es simétrica y diagonal por bloques con
!>    bloques diagonales de 1x1 y 2x2.
!>
!> 2. Si algún D(i,i)=0, de modo que D sea exactamente singular, la subrutina
!>    finaliza con INFO = i. De lo contrario, se utiliza la forma factorizada de A
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la subrutina continúa
!>    resolviendo para X y calculando los límites de error como se describe a
!>    continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular los límites de error y las estimaciones de error hacia atrás
!>    para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A se ha proporcionado o no
!>          en la entrada.
!>          = 'F':  En la entrada, AFP e IPIV contienen la forma factorizada de
!>                  A.  AP, AFP e IPIV no se modificarán.
!>          = 'N':  La matriz A se copiará en AFP y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es array REAL, dimensión (N*(N+1)/2)
!>          El triángulo superior o inferior de la matriz simétrica A,
!>          empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más abajo para más detalles.
!>

AFP

!>          AFP es array REAL, dimensión (N*(N+1)/2)
!>          Si FACT = 'F', entonces AFP es un argumento de entrada y en la entrada
!>          contiene la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T calculada por SSPTRF, almacenada como
!>          una matriz triangular empaquetada en el mismo formato de
!>          almacenamiento que A.
!>
!>          Si FACT = 'N', entonces AFP es un argumento de salida y en la salida
!>          contiene la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T calculada por SSPTRF, almacenada como
!>          una matriz triangular empaquetada en el mismo formato de
!>          almacenamiento que A.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, según lo determinado por SSPTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' y IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2. Si UPLO = 'L' y IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 y -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, según lo determinado por SSPTRF.
!>

B

!>          B es array REAL, dimensión (LDB,NRHS)
!>          La matriz B del lado derecho de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array REAL, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La estimación del número de condición recíproco de la matriz
!>          A.  Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular con precisión
!>          de trabajo.  Esta condición se indica con un código de retorno
!>          de INFO > 0.
!>

FERR

!>          FERR es array REAL, dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento más
!>          grande en X(j).  La estimación es tan confiable como la estimación
!>          para RCOND, y es casi siempre una ligera sobreestimación del error
!>          verdadero.
!>

BERR

!>          BERR es array REAL, dimensión (NRHS)
!>          El error relativo componente a componente hacia atrás de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace que X(j) sea una solución exacta).
!>

WORK

!>          WORK es array REAL, dimensión (3*N)
!>

IWORK

!>          IWORK es array INTEGER, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, e i es
!>                <= N:  D(i,i) es exactamente cero. La factorización
!>                       se ha completado pero el factor D es exactamente
!>                       singular, por lo que la solución y los límites de error

Function/Subroutine Documentation




!> \brief Solves a real symmetric positive-definite tridiagonal system of linear equations.
!>
!> Solves the system of linear equations A*X = B,
!> where A is a real symmetric positive-definite tridiagonal matrix, and X and B
!> are n x k matrices, with iterative refinement provided.
!>
!> The matrix A is stored in packed format.
!>
!> \param FACTOR Specifies whether to factorize the matrix.
!>        Possible values:
!>        - 'N': The LU decomposition is not computed and is assumed to have
!>               been computed by previous calls to SSPSFA.
!>        - 'F': The LU decomposition is computed and stored in AFP.
!> \param UPLO Specifies whether A is upper or lower triangular.
!>        Possible values:
!>        - 'U': Upper triangular.
!>        - 'L': Lower triangular.
!> \param N Number of linear equations, i.e., the order of the matrix A. N >= 0.
!> \param NRHS Number of right-hand sides, i.e., the number of columns in
!>        matrices B and X. NRHS >= 0.
!> \param AP Real array of dimension (N*(N+1))/2.
!>        Contains the packed upper or lower triangular part of the symmetric
!>        matrix A.
!> \param AFP Real array of dimension (N*(N+1))/2.
!>        Contains the packed factored form of the matrix A. If FACTOR = 'N',
!>        AFP is an output argument and contains the factored form.
!> \param LDA The leading dimension of the array AFP. LDA >= max(1, N).
!> \param IPIV Integer array of dimension N.
!>        Contains the pivot indices.
!> \param B Real array of dimension LDB x NRHS.
!>        The right-hand side matrix.
!> \param LDB The leading dimension of the array B. LDB >= max(1, N).
!> \param X Real array of dimension LDX x NRHS.
!>        The solution matrix.
!> \param LDX The leading dimension of the array X. LDX >= max(1, N).
!> \param RCOND Estimate of the reciprocal of the condition number of A.
!>        On exit, RCOND is an estimate of the reciprocal of the condition
!>        number of the matrix A. The estimate is computed by calling SGECO.
!> \param FER Real array of dimension NRHS.
!>        The forward error estimate for each solution vector.
!> \param INFO Integer
!>        = 0: successful exit
!>        < 0: if INFO = -i, the i-th argument had an illegal value
!>        > 0: if INFO = i, and i <= N, the LU decomposition failed.
!>               The diagonal element of the factor is zero. If INFO = i,
!>               and i > N, then RCOND is less than machine epsilon.
!>        = N+1: D is nonsingular, but RCOND is less than machine
!>               precision, meaning that the matrix is singular
!>               to working precision.  Nevertheless, the
!>               solution and error bounds are computed because
!>               there are a number of situations where the
!>               computed solution can be more accurate than the
!>               value of RCOND would suggest.
!>
