NOMBRE

sslsplit.conf - Archivo de configuración para SSLsplit

DESCRIPCIÓN

El archivo sslsplit.conf configura SSLsplit, sslsplit(1).

FORMATO DEL ARCHIVO

El archivo consiste en comentarios y opciones con argumentos. Cada línea que comienza con un símbolo de almohadilla (#) es ignorada por el analizador. Las opciones y los argumentos tienen el formato Opción Argumento. Los argumentos son de los siguientes tipos:

BOOL
Valor booleano (sí/no).
STRING
Cadena de texto.

DIRECTIVAS

Cuando una opción no se utiliza (comentada o no existe en el archivo de configuración) sslsplit toma una acción por defecto. Si una opción no tiene un equivalente en la línea de comandos, se puede usar la opción -o opt=val para anularla en la línea de comandos.

CACert STRING
Utiliza el certificado (y la clave) de la CA para firmar certificados falsificados. Equivalente a la opción de línea de comandos -c.
CAKey STRING
Utiliza la clave (y el certificado) de la CA para firmar certificados falsificados. Equivalente a la opción de línea de comandos -k.
ClientCert STRING
Utiliza el certificado del archivo pem cuando el destino solicita certificados de cliente. Equivalente a la opción de línea de comandos -a.
ClientKey STRING
Utiliza la clave del archivo pem cuando el destino solicita certificados de cliente. Equivalente a la opción de línea de comandos -b.
CAChain STRING
Utiliza la cadena de certificados de la CA del archivo pem (certificados de CA intermedios y raíz). Equivalente a la opción de línea de comandos -C.
LeafKey STRING
Utiliza la clave del archivo pem para generar certificados hoja. Equivalente a la opción de línea de comandos -K.
Por defecto: generar
LeafCRLURL STRING
Utiliza la URL como punto de distribución de la CRL para todos los certificados hoja falsificados. Equivalente a la opción de línea de comandos -q.
LeafCertDir STRING
Utiliza archivos PEM de certificado+cadena+clave del directorio de certificados para todos los sitios que coincidan con los nombres comunes (no coincidentes: generar si hay CA). Equivalente a la opción de línea de comandos -t.
DefaultLeafCert STRING
Utiliza el certificado+cadena+clave del archivo PEM para los certificados hoja si no hay coincidencia en LeafCertDir. Equivalente a la opción de línea de comandos -A.
WriteGenCertsDir STRING
Escribe la clave hoja y solo los certificados generados en el directorio de generación. Equivalente a la opción de línea de comandos -w.
WriteAllCertsDir STRING
Escribe la clave hoja y todos los certificados en el directorio de generación. Equivalente a la opción de línea de comandos -W.
DenyOCSP BOOL
Niega todas las solicitudes OCSP en todos los proxyspecs. Equivalente a la opción de línea de comandos -O.
Passthrough BOOL
Pasa las conexiones SSL si no se pueden dividir debido a la autenticación de certificado de cliente o a la falta de certificado coincidente y CA. Equivalente a la opción de línea de comandos -P.
Por defecto: descartar
DHGroupParams STRING
Utiliza parámetros de grupo DH del archivo pem. Equivalente a la opción de línea de comandos -g.
Por defecto: keyfiles o auto
ECDHCurve STRING
Utiliza la curva nombrada ECDH. Equivalente a la opción de línea de comandos -G.
Por defecto: prime256v1
SSLCompression BOOL
Habilita/deshabilita la compresión SSL/TLS en todas las conexiones. Equivalente a la opción de línea de comandos -Z.
ForceSSLProto STRING
Fuerza solo la versión del protocolo SSL/TLS. Equivalente a la opción de línea de comandos -r.
Por defecto: all
DisableSSLProto STRING
Deshabilita la versión del protocolo SSL/TLS. Equivalente a la opción de línea de comandos -R.
Por defecto: none
Ciphers STRING
Utiliza la especificación de suite de cifrado OpenSSL dada. Equivalente a la opción de línea de comandos -s.
Por defecto: ALL:-aNULL
OpenSSLEngine STRING
El motor OpenSSL a activar, ya sea el ID o la ruta completa a la biblioteca compartida que implementa el motor. Si se proporciona un ID, el motor debe ser conocido por la configuración de OpenSSL de todo el sistema. Solo disponible si está compilado contra una versión de OpenSSL con soporte para motores. Equivalente a la opción de línea de comandos -x.
NATEngine STRING
Especifica el motor NAT por defecto a utilizar. Equivalente a la opción de línea de comandos -e.
User STRING
Reduce privilegios al usuario. Equivalente a la opción de línea de comandos -u.
Por defecto: nobody, si se ejecuta como root
Group STRING
Reduce privilegios al grupo. Equivalente a la opción de línea de comandos -m.
Por defecto: Grupo primario del usuario
Chroot STRING
chroot() al directorio de la cárcel (afecta a los proxyspecs sni, ver sslsplit(1)). Equivalente a la opción de línea de comandos -j.
PidFile STRING
Escribe el pid al archivo. Equivalente a la opción de línea de comandos -p.
ConnectLog STRING
Registro de conexión: registra un resumen de una línea por conexión en el archivo de registro. Equivalente a la opción de línea de comandos -l.
ContentLog STRING
Registro de contenido: datos completos a archivo o tubería con nombre (excluye ContentLogDir/ContentLogPathSpec). Equivalente a la opción de línea de comandos -L.
ContentLogDir STRING
Registro de contenido: datos completos a archivos separados en el directorio (excluye ContentLog/ContentLogPathSpec). Equivalente a la opción de línea de comandos -S.
ContentLogPathSpec STRING
Registro de contenido: datos completos a archivos separados con sustitución de % (excluye ContentLog/ContentLogDir). Equivalente a la opción de línea de comandos -F.
LogProcInfo BOOL
Busca el proceso local propietario de cada conexión para registrarla. Equivalente a la opción de línea de comandos -i.
PcapLog STRING
Registro Pcap: paquetes al archivo pcap (excluye PcapLogDir/PcapLogPathSpec). Equivalente a la opción de línea de comandos -X.
PcapLogDir STRING
Registro Pcap: paquetes a archivos separados en el directorio (excluye PcapLog/PcapLogPathSpec). Equivalente a la opción de línea de comandos -Y.
PcapLogPathSpec STRING
Registro Pcap: paquetes a archivos separados con sustitución de % (excluye PcapLog/PcapLogDir). Equivalente a la opción de línea de comandos -y.
MirrorIf STRING
Duplica paquetes a la interfaz. Equivalente a la opción de línea de comandos -I.
MirrorTarget STRING
Duplica paquetes a la dirección de destino (usado con MirrorIf). Equivalente a la opción de línea de comandos -T.
MasterKeyLog STRING
Registra las claves maestras en el archivo de registro en formato SSLKEYLOGFILE. Equivalente a la opción de línea de comandos -M.
Daemon BOOL
Modo Demonio: ejecuta en segundo plano, registra mensajes de error en syslog. Equivalente a la opción de línea de comandos -d.
Debug BOOL
Modo Depuración: ejecuta en primer plano, registra

NAME

sslsplit.conf

configuration file for sslsplit

DESCRIPTION

The sslsplit configuration file allows the user to control the behavior of sslsplit.

Directives are processed in order. Directives can be specified multiple times if allowed by the directive itself.

Empty lines and lines starting with a # character are ignored.

FILE FORMAT

Each line in the configuration file consists of a directive name followed by its arguments, separated by spaces. Directives are case sensitive.

DIRECTIVES

verbose
Enable verbose debug messages on stderr. Equivalent to the -v command line option.
debug
Enable very verbose debug messages on stderr. Equivalent to the -D command line option.
VerifyPeer BOOL
Verify peer using default certificates.
Default: no
AddSNIToCertificate BOOL
When disabled, never add the SNI to forged certificates, even if the SNI provided by the client does not match the server certificate's CN/SAN. Helps pass the wrong.host test at https://badssl.com.
Default: yes
ProxySpec STRING
Proxy specification: type listenaddr+port [natengine|targetaddr+port|"sni"+port]. Multiple specs are allowed, one on each line.

FILES

/etc/sslsplit/sslsplit.conf
