Documentación de función/subrutina

subrutina ssysvxx (character fact, character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, real, dimension( * ) s, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real rpvgrw, real, dimension( * ) berr, integer n_err_bnds, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, integer nparams, real, dimension( * ) params, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SSYSVXX

Propósito:

!>
!>    SSYSVXX utiliza la factorización de pivoteo diagonal para calcular la
!>    solución a un sistema real de ecuaciones lineales A * X = B, donde A
!>    es una matriz simétrica de N por N y X y B son matrices de N por NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto a nivel de norma
!>    como de componente máxima. SSYSVXX devolverá una solución con un error
!>    garantizado pequeño (O(eps) donde eps es la precisión de la máquina de
!>    trabajo) a menos que la matriz esté muy mal condicionada, en cuyo
!>    caso se devuelve una advertencia. También se calculan y devuelven los
!>    números de condición relevantes.
!>
!>    SSYSVXX acepta factorizaciones y factores de equilibrado proporcionados
!>    por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada
!>    anterior a SSYSVXX también producirá una solución con errores O(eps)
!>    o advertencias, pero no podemos afirmar eso para factorizaciones y
!>    factores de equilibrado proporcionados por el usuario en general si
!>    difieren de lo que SSYSVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    El hecho de que el sistema se equilibre o no dependerá del
!>    escalado de la matriz A, pero si se utiliza el equilibrado, A se
!>    sobrescribe con diag(S)*A*diag(S) y B con diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>
!>    donde U (o L) es un producto de matrices triangulares unitarias superiores
!>    (inferiores) y de permutación, y D es simétrica y diagonal por bloques con
!>    bloques diagonales de 1x1 y 2x2.
!>
!>    3. Si algún D(i,i)=0, de modo que D sea exactamente singular, entonces la
!>    subrutina sale con INFO = i. De lo contrario, se utiliza la forma factorizada
!>    de A para estimar el número de condición de la matriz A (ver
!>    argumento RCOND). Si la inversa del número de condición es
!>    menor que la precisión de la máquina, la subrutina continúa resolviendo
!>    para X y calculando límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la subrutina utilizará el refinamiento iterativo para intentar obtener un
!>    error y límites de error pequeños. El refinamiento calcula el residual
!>    con al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(R) para que resuelva el sistema original antes del
!>    equilibrado.
!> 
!>     Algunos parámetros opcionales se agrupan en el array PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo los
!>     valores predeterminados son aceptables. Si los valores predeterminados son
!>     aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que el
!>     código fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     suministra o no en la entrada, y si no, si la matriz A debe
!>     equilibrarse antes de factorizarse.
!>       = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con los factores de escala dados por S.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará en AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará en AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A se almacena;
!>       = 'L':  El triángulo inferior de A se almacena.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array REAL, dimension (LDA,N)
!>     La matriz simétrica A.  Si UPLO = 'U', la parte triangular
!>     superior principal N por N de A contiene la parte triangular
!>     superior de la matriz A, y la parte estrictamente triangular
!>     inferior de A no se referencia.  Si UPLO = 'L', la parte triangular
!>     inferior principal N por N de A contiene la parte triangular
!>     inferior de la matriz A, y la parte estrictamente triangular
!>     superior de A no se referencia.
!>
!>     En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array REAL, dimension (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene la matriz diagonal por bloques D y los multiplicadores
!>     utilizados para obtener el factor U o L de la factorización A =
!>     U*D*U**T o A = L*D*L**T tal como se calculó con SSYTRF.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>     devuelve la matriz diagonal por bloques D y los multiplicadores
!>     utilizados para obtener el factor U o L de la factorización A =
!>     U*D*U**T o A = L*D*L**T.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimension (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>     contiene detalles de los intercambios y la estructura de bloques
!>     de D, tal como se determinó con SSYTRF. Si IPIV(k) > 0,
!>     entonces las filas y columnas k e IPIV(k) se intercambiaron y
!>     D(k,k) es un bloque diagonal de 1x1. Si UPLO = 'U' y
!>     IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas k-1 y
!>     -IPIV(k) se intercambiaron y D(k-1:k,k-1:k) es un bloque diagonal
!>     de 2x2. Si UPLO = 'L' y IPIV(k) = IPIV(k+1) < 0,
!>     entonces las filas y columnas k+1 y -IPIV(k) se intercambiaron
!>     y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>
!>     Si FACT = 'N', entonces IPIV es un argumento de salida
t argumento y a la salida
!>     contiene detalles de los intercambios y la estructura de bloques
!>     de D, según lo determinado por SSYTRF.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó.
!>       = 'N':  Ningún equilibrado (siempre verdadero si FACT = 'N').
!>       = 'Y':  Equilibrado de filas y columnas, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario,
!>     es un argumento de salida.
!>

S

!>          S es un array REAL, de dimensión (N)
!>     Los factores de escala para A. Si EQUED = 'Y', A se multiplica a
!>     la izquierda y a la derecha por diag(S). S es un argumento de
!>     entrada si FACT = 'F'; de lo contrario, S es un argumento de
!>     salida. Si FACT = 'F' y EQUED = 'Y', cada elemento de S debe
!>     ser positivo. Si S es salida, cada elemento de S es una potencia
!>     de la base. Si S es entrada, cada elemento de S debe ser una
!>     potencia de la base para asegurar una solución y estimaciones de
!>     error fiables. El escalado por potencias de la base no causa
!>     errores de redondeo a menos que el resultado se desborde (overflow
!>     o underflow). Los errores de redondeo durante el escalado conducen
!>     a un refinamiento con una matriz que no es equivalente a la matriz
!>     de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es un array REAL, de dimensión (LDB,NRHS)
!>     A la entrada, la matriz B de mano derecha de N por NRHS.
!>     A la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si EQUED = 'Y', B se sobrescribe por diag(S)*B;
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array REAL, de dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz solución X de N por NRHS del sistema original
!>     de ecuaciones. Tenga en cuenta que A y B se modifican a la salida
!>     si EQUED .ne. 'N', y la solución del sistema equilibrado es
!>     inv(diag(S))*X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Número de condición escalado recíproco. Esta es una estimación del
!>     número de condición de Skeel recíproco de la matriz A después del
!>     equilibrado (si se realizó). Si este es menor que la precisión de
!>     la máquina (en particular, si es cero), la matriz es singular
!>     con precisión de trabajo. Tenga en cuenta que el error aún puede
!>     ser pequeño incluso si este número es muy pequeño y la matriz
!>     parece mal condicionada.
!>

RPVGRW

!>          RPVGRW es REAL
!>     Crecimiento de pivote recíproco. A la salida, esto contiene el
!>     factor de crecimiento de pivote recíproco norm(A)/norm(U). Se utiliza
!>     la norma de la Frobenius. Si esto es mucho menor que 1, entonces la
!>     estabilidad de la factorización LU de la matriz A (equilibrada)
!>     podría ser pobre. Esto también significa que la solución X, los
!>     números de condición estimados y los límites de error podrían no ser
!>     fiables. Si la factorización falla con 0<INFO<=N, entonces esto
!>     contiene el factor de crecimiento de pivote recíproco para las
!>     columnas INFO principales de A.
!>

BERR

!>          BERR es un array REAL, de dimensión (NRHS)
!>     Error relativo de retroceso componente a componente. Este es el
!>     error relativo de retroceso componente a componente de cada vector
!>     solución X(j) (es decir, el cambio relativo más pequeño en cualquier
!>     elemento de A o B que haga de X(j) una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada mano derecha
!>     y cada tipo (normwise o componentewise). Ver ERR_BNDS_NORM y
!>     ERR_BNDS_COMP abajo.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array REAL, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada mano derecha, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define como sigue:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array se indexa por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde a la i-ésima
!>     mano derecha.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error
!>              verdadero siempre que la siguiente entrada sea mayor que
!>              el umbral sqrt(n) * slamch('Epsilon'). Este límite de
!>              error solo debe confiarse si el booleano anterior es
!>              verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco normwise estimado. Comparado con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la estimación
!>              del error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z apropiadamente escalada.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de
!>              la base para que todas las sumas de filas absolutas de Z
!>              sean aproximadamente 1.
!>
!>     Ver Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array REAL, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada mano derecha, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define como sigue:
!>
!>     Error relativo componente a componente en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array se indexa por la mano derecha i (de la que depende el
!>     error relativo componente a componente), y el tipo de información
!>     de error como se describe a continuación. Actualmente hay hasta tres
!>     piezas de información devueltas para cada mano derecha. Si no se
!>     solicita precisión componente a componente (PARAMS(3) = 0.0),
!>     entonces ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces
!>     solo se devuelven las primeras (:,N_ERR_BNDS) entradas.
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde a la i-ésima
!>     mano derecha.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error
!>              verdadero siempre que la siguiente entrada sea mayor que
!>              el umbral sqrt(n) * slamch('Epsilon'). Este límite de
!>              error solo debe confiarse si el booleano anterior es
!>              verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco componente a componente estimado. Comparado con
!>              el umbral sqrt(n) * slamch('Epsilon') para determinar si
!>              la estimación del error es . Estos números de
!>              condición recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf))
!>              para alguna matriz Z apropiadamente escalada.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para la
!>              mano derecha actual y S escala cada fila de A*diag(x)
!>              por una potencia de la base para que todas las sumas de
!>              filas absolutas de Z sean aproximadamente 1.
!>
!>     Ver Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!>

NPARAMS

!>          NPARAMS es INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS. Si <= 0,
!>     el array PARAMS nunca se accede y se utilizan los valores por
!>     defecto.
!>

PARAMS

!>          PARAMS es un array REAL, de dimensión NPARAMS
!>     Especifica los parámetros del algoritmo. Si una entrada es < 0.0,
!>     esa entrada se rellenará con el valor por defecto utilizado para
!>     ese parámetro. Solo se acceden las posiciones hasta NPARAMS; se
!>     utilizan valores por defecto para parámetros de mayor número.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Si realizar o no el refinamiento
!>            iterativo.
!>         Por defecto: 1.0
!>            = 0.0:  No se realiza refinamiento, ni se calculan límites
!>                    de error.
!>            = 1.0:  Utiliza el algoritmo de refinamiento de doble
!>                    precisión, posiblemente con cálculos de simple
!>                    doble si el entorno de compilación no admite
!>                    DOUBLE PRECISION.
!>              (otros valores están reservados para uso futuro)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Número máximo de cálculos de
!>            residual permitidos para el refinamiento.
!>         Por defecto: 10
!>         Agresivo: Se establece en 100 para permitir la convergencia
!>                     utilizando factorizaciones aproximadas o
!>                     factorizaciones distintas de LU. Si la
!>                     factorización utiliza una técnica distinta de la
!>                     eliminación gaussiana, las garantías en
!>                     err_bnds_norm y err_bnds_comp pueden dejar de ser
!>                     fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Indicador que determina si el
!>            código intentará encontrar una solución con un error relativo
!>            componente a componente pequeño en el algoritmo de doble
!>            precisión. Positivo es verdadero, 0.0 es falso.
!>         Por defecto: 1.0 (intentar convergencia componente a componente)
!>

WORK

!>          WORK es un array REAL, de dimensión (4*N)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa. La solución para cada mano derecha está
!>         garantizada.
!>       < 0:  Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>       > 0 y <= N:  U(INFO,INFO) es exactamente cero. La factorización
!>         se ha completado, pero el factor U es exactamente singular, por
!>         lo que la solución y los límites de error no pudieron calcularse.
!>         Se devuelve RCOND = 0.
!>       = N+J: La solución correspondiente a la J-ésima mano derecha
!>         no está garantizada. Las soluciones correspondientes a otras
!>         manos derechas K con K > J tampoco pueden estar garantizadas,
!>         pero solo se informa de la primera mano derecha de este tipo.
!>         Si no se solicita un error componente a componente pequeño
!>         (PARAMS(3) = 0.0), entonces la J-ésima mano derecha es la

NAME


ssysvxx


routine for solving a general system of linear equations $Ax = b$ with iterative refinement






SYNOPSIS


  SUBROUTINE SSYSVXX(
     FACT, TRANS, N, NRHS, A, LDA, AF, LDAF, IPIV, B, LDB, X, LDX, RCOND,
     FERR, BERR, INFO, PARAMS
  )
  CHARACTER(LEN=1) :: FACT, TRANS
  INTEGER :: N, NRHS, LDA, LDAF, LDB, LDX, INFO
  REAL :: A(LDA, *), AF(LDAF, *), B(LDB, *), X(LDX, *), RCOND,
   FERR(*), BERR(*), PARAMS(*)
  INTEGER :: IPIV(*)







Function/Subroutine Documentation


This subroutine solves a general system of linear equations $Ax = b$ with
    iterative refinement. The subroutine is called only once.


Arguments



  
FACT

  
CHARACTER*1.Input.

  
Specifies whether or not the factorisation of the matrix A is supplied.

  
'F': In this case, AF and IPIV contain the factorisation of A.

  
'N': In this case, the routine must first compute the
      factorisation of A.

  
'C': In this case, AF and IPIV contain the factorisation of A and
      the routine checks that A = A'.

  

  
TRANS

  
CHARACTER*1.Input.

  
Specifies the form of the system of equations.

  
'N': Solve $Ax = b$ (No transpose).

  
'T': Solve $A^T x = b$ (Transpose).

  
'C': Solve $A^H x = b$ (Conjugate transpose).

  

  
N

  
INTEGER.Input.

  
The order of the matrix A. N >= 0.

  

  
NRHS

  
INTEGER.Input.

  
The number of right hand sides, i.e. the number of systems to be solved.

  
NRHS >= 0.

  

  
A

  
REAL.Input.

  
The original $N \times N$ matrix $A$. If FACT = 'F'
      or 'C', A must be updated with the results of the decomposition
      of AF.

  

  
LDA

  
INTEGER.Input.

  
The leading dimension of the array A. LDA >= max(1, N).

  

  
AF

  
REAL.Input/Output.

  
AF. If FACT = 'F' or 'C',
      AF contains the L-infinite factorization of A. If FACT
      = 'N', AF is an input/output argument that contains
      the factorisation of A on exit.

  

  
LDAF

  
INTEGER.Input.

  
The leading dimension of the array AF. LDAF >= max(1, N).

  

  
IPIV

  
INTEGER.Input/Output.

  
Details of the interchanges on the factorisation. It is an integer
      array of dimension at least N.

  

  
B

  
REAL.Input/Output.

  
On entry, the $N \times NRHS$ right hand side matrix $B$.

  
On exit, $B$ is overwritten by the solution matrix $X$.

  

  
LDB

  
INTEGER.Input.

  
The leading dimension of the array B. LDB >= max(1, N).

  

  
X

  
REAL.Output.

  
The $N \times NRHS$ solution matrix $X$.

  

  
LDX

  
INTEGER.Input.

  
The leading dimension of the array X. LDX >= max(1, N).

  

  
RCOND

  
REAL.Output.

  
The reciprocal of the condition number of A. The matrix A is singular if
      RCOND < eps, where eps is
      the machine epsilon.

  

  
FERR

  
REAL.Output.

  
FERR(J) is an estimated forward error bound for the $J$-th
      solution vector, that is, the relative error in the $J$-th solution $X(:,J)$
      in the infinity norm. If X is the true solution and
      X(:,J) is the $J$-th column of the computed solution matrix,
      then the computed error is:

  
norm(X - X(:,J)) / norm(X(:,J)).

  

  
BERR

  
REAL.Output.

  
BERR(J) is the backward error vector for the $J$-th solution
      vector $X(:,J)$.

  

  
INFO

  
INTEGER.Output.

  
INFO = 0: successful exit.

  
INFO < 0: if INFO = -i, then the
      $i$-th argument had an illegal value.

  
INFO > 0: if INFO = i, then
      U(i,i) is exactly zero. The factorisation has been completed,
      but the basic solution could not be computed.

  

  
PARAMS

  
REAL.Input.

  
Array of parameters. PARAMS(1) is not used.

  






PARAMS(2): The threshold for the normwise error bound. If
    PARAMS(2) is not used, then the default value is 1.0.


PARAMS(3): The threshold for the componentwise error bound. If
    PARAMS(3) is not used, then the default value is 1.0.


PARAMS(4): The threshold for the normwise error bound for
    all the right hand sides. If PARAMS(4) is not used, then the
    default value is 1.0.


PARAMS(5): The threshold for the componentwise error bound for
    all the right hand sides. If PARAMS(5) is not used, then the
    default value is 1.0.


The values of PARAMS(2), PARAMS(3),
    PARAMS(4) and PARAMS(5) must be greater than or equal
    to 1.0. If any of these values are less than 1.0, the value 1.0 is used in
    place of the invalid value. This routine computes the normwise and componentwise
    error bounds for the system $Ax = b$. The following definitions are used:


ERR_BNDS_NORM(J, 1): The normwise error bound for the $J$-th
    solution.


ERR_BNDS_COMP(J, 1): The componentwise error bound for the $J$-th
    solution.


The condition number is estimated by RCOND. If RCOND
    is close to machine epsilon, then the matrix $A$ is close to singular and the
    solution $X$ is not guaranteed to be accurate.


If PARAMS(2) = 1.0 (default), the $J$-th right-hand side
    is the first with a normwise error bound that is not guaranteed (the smallest
    $J$ such that ERR_BNDS_NORM(J, 1) = 0.0).


If PARAMS(3) = 1.0 (default), the $J$-th right-hand side
    is the first with a componentwise error bound that is not guaranteed (the smallest
    $J$ such that ERR_BNDS_COMP(J, 1) = 0.0).


By default (PARAMS(3) = 1.0), the $J$-th right-hand
    side is the first with either a normwise or componentwise error bound that
    is not guaranteed (the smallest $J$ such that either
    ERR_BNDS_NORM(J, 1) = 0.0 or ERR_BNDS_COMP(J, 1)
    = 0.0). See the definition of ERR_BNDS_NORM(:, 1) and
    ERR_BNDS_COMP(:, 1). To get information about all of the
    right-hand sides check ERR_BNDS_NORM or
    ERR_BNDS_COMP.
