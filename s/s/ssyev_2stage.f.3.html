Funciones/Subrutinas


subrutina ssyev_2stage (jobz, uplo, n, a, lda, w, work, lwork, info)
SSYEV_2STAGE calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices SY

Documentación de función/subrutina

subrutina ssyev_2stage (character jobz, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) w, real, dimension( * ) work, integer lwork, integer info)

SSYEV_2STAGE calcula los valores propios y, opcionalmente, los vectores propios de matrices SY utilizando la técnica de 2 etapas

Propósito:

!>
!> SSYEV_2STAGE calcula todos los valores propios y, opcionalmente, los vectores
!> propios de una matriz simétrica real A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>                  No disponible en esta versión.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la
!>          parte triangular superior N-por-N líder de A contiene la
!>          parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior N-por-N líder de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene los
!>          vectores propios ortonormales de la matriz A.
!>          Si JOBZ = 'N', entonces en la salida el triángulo inferior (si UPLO='L')
!>          o el triángulo superior (si UPLO='U') de A, incluyendo la
!>          diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

W

!>          W es array REAL, dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

WORK

!>          WORK es array REAL, dimensión LWORK
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          en caso contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimension) donde
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + 2*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 2*N
!>                                   donde KD es el tamaño del bloque de la reducción,
!>                                   FACTOPTNB es el bloqueo utilizado por el algoritmo
!>                                   QR o LQ, normalmente FACTOPTNB=128 es una buena opción
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   la compilación openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Aún no disponible.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el algoritmo falló en converger; i
!>                elementos fuera de la diagonal de una forma tridiagonal intermedia
!>                no convergieron a cero.
!>
