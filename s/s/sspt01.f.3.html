subrutina sspt01 (carácter uplo, entero n, real, dimensión( * ) a, real, dimensión( * ) afac, entero, dimensión( * ) ipiv, real, dimensión( ldc, * ) c, entero ldc, real, dimensión( * ) rwork, real resid)

SSPT01

Propósito:

!>
!> SSPT01 reconstruye una matriz simétrica indefinida empaquetada A a partir de su
!> factorización L*D*L' o U*D*U' y calcula la norma residual
!> norm( C - A ) / ( N * norm(A) * EPS ),
!> donde C es la matriz reconstruida y EPS es la epsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es ENTERO
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, dimensión (N*(N+1)/2)
!>          La matriz simétrica original A, almacenada como una matriz
!>          triangular empaquetada.
!>

AFAC

!>          AFAC es un array REAL, dimensión (N*(N+1)/2)
!>          La forma factorizada de la matriz A, almacenada como una matriz
!>          triangular empaquetada.  AFAC contiene la matriz diagonal de bloques D
!>          y los multiplicadores utilizados para obtener el factor L o U de la
!>          factorización de bloques L*D*L' o U*D*U' tal como la calcula SSPTRF.
!>

IPIV

!>          IPIV es un array ENTERO, dimensión (N)
!>          Los índices de pivote de SSPTRF.
!>

C

!>          C es un array REAL, dimensión (LDC,N)
!>

LDC

!>          LDC es ENTERO
!>          La dimensión principal del array C.  LDC >= max(1,N).
!>

RWORK

!>          RWORK es un array REAL, dimensión (N)
!>

RESID

!>          RESID es REAL
!>          Si UPLO = 'L', norm(L*D*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U*D*U' - A) / ( N * norm(A) * EPS )
!>
