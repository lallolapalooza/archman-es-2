SSPT21

Documentación de Función/Subrutina

subrutina sspt21 (integer itype, character uplo, integer n, integer kband, real, dimension( * ) ap, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldu, * ) u, integer ldu, real, dimension( * ) vp, real, dimension( * ) tau, real, dimension( * ) work, real, dimension( 2 ) result)

SSPT21

Propósito:

!>
!> SSPT21 comprueba generalmente una descomposición de la forma
!>
!>         A = U S U**T
!>
!> donde **T significa transpuesta, A es simétrica (almacenada en formato empaquetado), U
!> es ortogonal, y S es diagonal (si KBAND=0) o simétrica
!> tridiagonal (si KBAND=1). Si ITYPE=1, entonces U se representa como una
!> matriz densa, de lo contrario, U se expresa como un producto de
!> transformaciones de Householder, cuyos vectores se almacenan en el array
!>  y cuyas constantes de escala están en  
 utilizaremos
!> la letra  para referirnos al producto de transformaciones de Householder
!> (que debería ser igual a U).
!>
!> Específicamente, si ITYPE=1, entonces:
!>
!>         RESULT(1) = | A - U S U**T | / ( |A| n ulp ) y
!>         RESULT(2) = | I - U U**T | / ( n ulp )
!>
!> Si ITYPE=2, entonces:
!>
!>         RESULT(1) = | A - V S V**T | / ( |A| n ulp )
!>
!> Si ITYPE=3, entonces:
!>
!>         RESULT(1) = | I - V U**T | / ( n ulp )
!>
!> Almacenamiento empaquetado significa que, por ejemplo, si UPLO='U', los
!> elementos de la parte triangular superior de A se almacenan uno tras otro,
!> de modo que A(1,j+1) sigue inmediatamente a A(j,j) en el array AP.
!> Del mismo modo, si UPLO='L', los elementos de la parte triangular
!> inferior de A se almacenan uno tras otro en AP, de modo que A(j+1,j+1)
!> sigue inmediatamente a A(n,j) en el array AP.
!> Esto significa que A(i,j) se almacena en:
!>
!>    AP( i + j*(j-1)/2 )                 si UPLO='U'
!>
!>    AP( i + (2*n-j)*(j-1)/2 )           si UPLO='L'
!>
!> El array VP tiene la misma relación con la matriz V que A tiene con
!> AP.
!>
!> Para ITYPE > 1, la transformación U se expresa como un producto
!> de transformaciones de Householder:
!>
!>    Si UPLO='U', entonces V = H(n-1)...H(1), donde
!>
!>        H(j) = I  -  tau(j) v(j) v(j)**T
!>
!>    y los primeros j-1 elementos de v(j) se almacenan en V(1:j-1,j+1),
!>    (es decir, VP( j*(j+1)/2 + 1 : j*(j+1)/2 + j-1 ) ),
!>    el j-ésimo elemento es 1, y los últimos n-j elementos son 0.
!>
!>    Si UPLO='L', entonces V = H(1)...H(n-1), donde
!>
!>        H(j) = I  -  tau(j) v(j) v(j)**T
!>
!>    y los primeros j elementos de v(j) son 0, el (j+1)-ésimo es 1, y los
!>    elementos del (j+2)-ésimo al n-ésimo se almacenan en V(j+2:n,j) (es decir,
!>    en VP( (2*n-j)*(j-1)/2 + j+2 : (2*n-j)*(j-1)/2 + n ) .)
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de pruebas a realizar.
!>          1: U expresada como una matriz ortogonal densa:
!>             RESULT(1) = | A - U S U**T | / ( |A| n ulp ) y
!>             RESULT(2) = | I - U U**T | / ( n ulp )
!>
!>          2: U expresada como un producto V de transformaciones de Housholder:
!>             RESULT(1) = | A - V S V**T | / ( |A| n ulp )
!>
!>          3: U expresada tanto como una matriz ortogonal densa y
!>             como un producto de transformaciones de Housholder:
!>             RESULT(1) = | I - V U**T | / ( n ulp )
!>

UPLO

!>          UPLO es CHARACTER
!>          Si UPLO='U', AP y VP se consideran que contienen la parte triangular
!>          superior de A y V.
!>          Si UPLO='L', AP y VP se consideran que contienen la parte triangular
!>          inferior de A y V.
!>

N

!>          N es INTEGER
!>          El tamaño de la matriz. Si es cero, SSPT21 no hace nada.
!>          Debe ser al menos cero.
!>

KBAND

!>          KBAND es INTEGER
!>          El ancho de banda de la matriz. Solo puede ser cero o uno.
!>          Si es cero, S es diagonal y E no se referencia. Si
!>          es uno, S es simétrica tridiagonal.
!>

AP

!>          AP es array REAL, dimension (N*(N+1)/2)
!>          La matriz original (no factorizada). Se asume que es
!>          simétrica y contiene las columnas solo de la parte triangular
!>          superior (UPLO='U') o solo de la parte triangular inferior (UPLO='L'),
!>          empaquetadas una tras otra.
!>

D

!>          D es array REAL, dimension (N)
!>          La diagonal de la matriz (simétrica tri-) diagonal.
!>

E

!>          E es array REAL, dimension (N-1)
!>          La subdiagonal de la matriz (simétrica tri-) diagonal.
!>          E(1) es el elemento (1,2) y (2,1), E(2) es el elemento (2,3) y
!>          (3,2), etc.
!>          No se referencia si KBAND=0.
!>

U

!>          U es array REAL, dimension (LDU, N)
!>          Si ITYPE=1 o 3, contiene la matriz ortogonal en
!>          la descomposición, expresada como una matriz densa. Si ITYPE=2,
!>          no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U. LDU debe ser al menos N y
!>          al menos 1.
!>

VP

!>          VP es array REAL, dimension (N*(N+1)/2)
!>          Si ITYPE=2 o 3, las columnas de este array contienen los
!>          vectores de Householder utilizados para describir la matriz
!>          ortogonal en la descomposición, como se describe en el propósito.
!>          *NOTA* Si ITYPE=2 o 3, V se modifica y se restaura. La
!>          subdiagonal (si UPLO='L') o la supradiagonal (si UPLO='U')
!>          se establece en uno, y posteriormente se restaura a su valor original,
!>          durante el curso del cálculo.
!>          Si ITYPE=1, no se referencia ni se modifica.
!>

TAU

!>          TAU es array REAL, dimension (N)
!>          Si ITYPE >= 2, entonces TAU(j) es el factor escalar de
!>          v(j) v(j)**T en la transformación de Householder H(j) del
!>          producto U = H(1)...H(n-2)
!>          Si ITYPE < 2, entonces TAU no se referencia.
!>

WORK

!>          WORK es array REAL, dimension (N**2+N)
!>          Espacio de trabajo.
!>

RESULT

!>          RESULT es array REAL, dimension (2)
!>          Los valores calculados por las dos pruebas descritas anteriormente.
!>          Los valores se limitan actualmente a 1/ulp, para evitar
!>          desbordamientos.
!>          RESULT(1) siempre se modifica. RESULT(2) se modifica solo
!>          si ITYPE=1.
!>
