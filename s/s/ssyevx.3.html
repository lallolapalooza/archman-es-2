Documentación de Función/Subrutina

subrutina ssyevx (character jobz, character range, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

SSYEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices SY

Propósito:

!>
!> SSYEVX calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de una matriz simétrica real A. Los valores propios y vectores propios pueden ser
!> seleccionados especificando un rango de valores o un rango de índices
!> para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 que se está buscando.
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la
!>          parte triangular superior N-por-N principal de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior N-por-N principal de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que se encuentra en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o
!>          igual a cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*SLAMCH('S'), no en cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*SLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, Nota de trabajo LAPACK #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array REAL, dimensión (N)
!>          En salida normal, los primeros M elementos contienen los valores propios
!>          seleccionados en orden ascendente.
!>

Z

!>          Z es un array REAL, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Si un vector propio no converge, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministren al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK))
!>          En salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.  LWORK >= 1, cuando N <= 1;
!>          de lo contrario 8*N.
!>          Para una eficiencia óptima, LWORK >= (NB+3)*N,
!>          donde NB es el máximo del tamaño de bloque para SSYTRD y SORMTR
!>          devuelto por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y ninguna
!>          mensaje de error relacionado con LWORK es emitido por XERBLA.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (5*N)
!>

IFAIL

!>          IFAIL es un array INTEGER, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero.  Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que fallaron en converger.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, entonces i vectores propios fallaron en converger.
!>                Sus índices se almacenan en el array IFAIL.
!>

ssyevx(3)

The purpose of this manual page is to describe the functionality of the LAPACK routines.

NAME

ssyevx

general band matrix eigenvalues and eigenvectors

SYNOPSIS

CALL ssyevx(
   JOBZ, UPLO, N, A, LDA, VL, VU, IL, IU, ABSTOL, MATZ, Z, LDZ, WORK,
   IWORK, INFO )

Function/Subroutine Documentation

ssyevx compute eigenvalues and eigenvectors of a real symmetric (or complex Hermitian) band matrix A.

Description: 

                The routine computes the eigenvalues and eigenvectors of a real
                symmetric band matrix A of order N. Eigenvalues are computed
                selectively, that is, if requested, only those lying within a
                given range [VL, VU] are computed. Eigenvectors are computed
                for all eigenvalues, or for selected eigenvalues only.

Parameters:

JOBZ

CHARACTER*1

='N': Compute only the eigenvalues of A.

='V': Compute the eigenvalues and eigenvectors of A.

UPLO

CHARACTER*1

='U': Upper triangle of A, or A is upper triangular.

='L': Lower triangle of A, or A is lower triangular.

N

INTEGER

The order of the matrix A. N >= 0.

A

REAL

array, dimension (LDA, N)

On entry, the n-by-n band matrix A.

LDA

INTEGER

The leading dimension of the array A. LDA >= max(1, K+1), where K is the number of super- or sub-diagonals of the matrix.

VL

REAL

If JOBZ = 'V' and MATZ = 'A', VL, VU and ABSTOL are not used.

If JOBZ = 'V' and MATZ = 'S', VL and VU define the range of interest, and ABSTOL is a tolerance used in the "க்கிய" selection criterion.

See below for further details.

VU

REAL

IL

INTEGER

IU

INTEGER

ABSTOL

REAL

MATZ

CHARACTER*1

='A': all eigenvalues and eigenvectors are computed.

='S': all eigenvalues and eigenvectors will be computed, unless they are outside the range [VL, VU].

Z

REAL

array, dimension (LDZ, N) if JOBZ = 'V', and N is the number of columns in Z.

If JOBZ = 'N', Z is not referenced.

On exit, the eigenvectors v(i) are stored in the columns v(i), i.e. the i-th column of Z if JOBZ = 'V'.

LDZ

INTEGER

The leading dimension of the array Z. LDA >= max(1, N).

WORK

REAL

workspace array, dimension (LWORK)

IWORK

INTEGER

workspace array, dimension (LIWORK)

INFO

INTEGER

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

> 0: if INFO = k, and k <= N, then k eigenvectors failed to converge, and only the first k eigenvalues are correct.

if INFO = N+k, then k eigenvectors corresponding to eigenvalues outside the range [VL, VU] failed to converge.
