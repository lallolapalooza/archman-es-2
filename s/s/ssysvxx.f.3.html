SSYSVXX

Propósito:

!>
!>    SSYSVXX utiliza la factorización de pivoteo diagonal para calcular la
!>    solución a un sistema real de ecuaciones lineales A * X = B, donde A
!>    es una matriz simétrica de N por N y X y B son matrices de N por NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normados como de
!>    componente máxima. SSYSVXX devolverá una solución con un pequeño
!>    error garantizado (O(eps) donde eps es la precisión de la máquina de trabajo)
!>    a menos que la matriz sea muy mal condicionada, en cuyo caso se devuelve
!>    una advertencia. También se calculan y devuelven los números de condición
!>    relevantes.
!>
!>    SSYSVXX acepta factorizaciones y factores de

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para
!>    equilibrar el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se equilibrará o no dependerá del escalado de la
!>    matriz A, pero si se utiliza el equilibrado, A se sobrescribe
!>    con diag(S)*A*diag(S) y B con diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para
!>    factorizar la matriz A (después de equilibrar si FACT = 'E') como
!>
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>
!>    donde U (o L) es un producto de matrices de permutación y
!>    triangulares unitarias superiores (inferiores), y D es simétrica y
!>    diagonal por bloques con bloques diagonales de 1x1 y 2x2.
!>
!>    3. Si algún D(i,i)=0, de modo que D sea exactamente singular, la
!>    rutina sale con INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz A
!>    (ver argumento RCOND). Si el recíproco del número de condición
!>    es menor que la precisión de la máquina, la rutina continúa
!>    resolviendo X y calculando los límites de error como se describe a
!>    continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca
!>    en cero), la rutina utilizará refinamiento iterativo para intentar
!>    obtener un error pequeño y límites de error. El refinamiento
!>    calcula el residuo con al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(R) para que resuelva el sistema original antes del
!>    equilibrado.
!> 
!>     Algunos parámetros opcionales se agrupan en el array PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores
!>     predeterminados son aceptables, los usuarios pueden pasar NPARAMS = 0
!>     lo que evita que el código fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT is CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona en la entrada, y si no, si la matriz A debe
!>     equilibrarse antes de factorizarla.
!>       = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con factores de escala dados por S.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará a AF y se factorizará.
!>

UPLO

!>          UPLO is CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N is INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>     La matriz simétrica A. Si UPLO = 'U', la parte superior
!>     triangular principal de N por N de A contiene la parte
!>     triangular superior de la matriz A, y la parte estrictamente
!>     triangular inferior de A no se referencia. Si UPLO = 'L', la
!>     parte inferior triangular principal de N por N de A contiene la
!>     parte triangular inferior de la matriz A, y la parte estrictamente
!>     triangular superior de A no se referencia.
!>
!>     En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA is INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF is REAL array, dimension (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la
!>     entrada contiene la matriz diagonal por bloques D y los
!>     multiplicadores utilizados para obtener el factor U o L de la
!>     factorización A = U*D*U**T o A = L*D*L**T tal como la calcula SSYTRF.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la
!>     salida devuelve la matriz diagonal por bloques D y los
!>     multiplicadores utilizados para obtener el factor U o L de la
!>     factorización A = U*D*U**T o A = L*D*L**T.
!>

LDAF

!>          LDAF is INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la
!>     entrada contiene detalles de los intercambios y la estructura de
!>     bloques de D, tal como la determina SSYTRF. Si IPIV(k) > 0,
!>     entonces las filas y columnas k y IPIV(k) se intercambiaron y
!>     D(k,k) es un bloque diagonal de 1x1. Si UPLO = 'U' y
!>     IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas k-1 y
!!>     -IPIV(k) se intercambiaron y D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>     Si UPLO = 'L' y IPIV(k) = IPIV(k+1) < 0, entonces las filas y
!>     columnas k+1 y -IPIV(k) se intercambiaron y D(k:k+1,k:k+1) es un
!>     bloque diagonal de 2x2.
!>
!>     Si FACT = 'N', entonces IPIV es un argumento de salida y en la
!>     salida devuelve los detalles de los intercambios y la estructura
!>     de bloques de D.
!>

EQUED

!>          EQUED is CHARACTER*1
!>     Specifies whether or not the system was equilibrated before
!>     being factorized. Used only if FACT = 'F'.
!>       = 'N': No equilibration was previously performed. S is not
!>              accessed.
!>       = 'S': Scale factors S are provided in S.
!>       = 'Y': Matrix A was supplied already equilibrated, and the
!>              scale factors S are provided in S.
!>

S

!>          S is REAL array, dimension (N)
!>     If FACT = 'F' and EQUED = 'S' or 'Y', S contains the scaling
!>     factors used to equilibrate the system A. Only diagonal
!>     elements of S are accessed.
!>
!>     If FACT = 'E' and/or some diagonal element of A is negative,
!>     S is an output argument and contains the scaling factors, if
!>     any, that were applied to the matrix A. If EQUED is not 'N',
!>     the array S is updated.
!>

B

!>          B is REAL array, dimension (LDB,NRHS)
!>     On entry, the N-by-NRHS matrix B.
!>     On exit, if FACT = 'E' and EQUED = 'Y', B is overwritten by
!>     diag(S)*B.
!>

LDB

!>          LDB is INTEGER
!>     The leading dimension of the array B. LDB >= max(1,N).
!>

X

!>          X is REAL array, dimension (LDX,NRHS)
!>     On exit, the N-by-NRHS matrix X, the solution to the system
!>     A * X = B.  If FACT = 'E' and EQUED = 'Y', X is overwritten by
!>     diag(S)*X.
!>

LDX

!>          LDX is INTEGER
!>     The leading dimension of the array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND is REAL
!>     On exit, an estimate of the reciprocal condition number of the
!>     matrix A (the same quantity as computed by SSYCON).
!>

RPVGRW

!>          RPVGRW is REAL
!>     On exit, the rijndael block size.
!>

BERR

!>          BERR is REAL array, dimension (NRHS)
!>     On exit, the estimated componentwise forward error in the
!>     solution matrix X for each of the NRHS right hand sides in
!>     the current matrix X.  If NERR_BNDS > 0, then BERR(j)
!>     contains the normwise backward error for the j-th solution X(:,j),
!>     i.e. the value of norm( B - A*X(:,j) ) / ( norm(A) * norm(X(:,j)) ).
!>

N_ERR_BNDS

!>          N_ERR_BNDS is INTEGER
!>     The number of error bounds computed for each right hand side.
!>     If N_ERR_BNDS = 0, then no error bounds are computed.
!>     If N_ERR_BNDS = 1, then a normwise error bound is computed.
!>     If N_ERR_BNDS = 2, then a normwise and a componentwise error
!>     bound are computed.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM is REAL array, dimension (NRHS)
!>     If N_ERR_BNDS >= 1, ERR_BNDS_NORM(j) contains the computed
!>     normwise error bound for the j-th solution, optimized for the
!>     case when the solution has tiny errors.

!>          ERR_BNDS_COMP is REAL array, dimension (NRHS)
!>     If N_ERR_BNDS = 2, ERR_BNDS_COMP(j) contains the computed

!>     the case when the solution has tiny errors.

!>          NPARAMS is INTEGER
!>     The number of parameters in the PARAMS array. If NPARAMS = 0,

PARAMS

!>          PARAMS is REAL array, dimension (NPARAMS)

NAME
    CGESVX - CGESVX

SYNOPSIS
    call cgesvx(FACT, TRANS, EQUED, N, NRHS, A, LDA, AF, LDAF, IPIV, B, LDB, X, LDX, RCOND, BERR, N_ERR_BNDS, ERR_BNDS_NORM, ERR_BNDS_COMP, WORK, RWORK, INFO)

PURPOSE
    CGESVX uses the LU factorization of C to compute the solution to a set of
    right and/or left systems of linear equations:

        A * X = B,   A**T * X = B,   or   A**H * X = B

    where A**T is the transpose of A, and A**H is the conjugate transpose of
    A.

    A is an N-by-N complex matrix and X and B are N-by-NRHS complex matrices.
    Various facilitating routines are used to achieve high accuracy.

    The option to perturb the most sensitive elements of M during LU
    factorization is provided in an attempt to allow the solution to be
    computed.

    The equilibria of rows and columns are computed and applied if the matrix
    is singular.

    The reciprocal condition number and componentwise error bounds are
    computed in an attempt to answer the question of how well conditioned the
    problem is.

ARGUMENTS
    FACT     (CHARACTER*1)
             Specifies the form of the factorization and equilibration
             of the system of equations.
             = 'E':  The roundings of A have been computed by equilibration.
                     The equilibrated matrix is given in AF.
             = 'N':  The LU factorization of A is supplied.
             = 'F':  The LU factorization of A is supplied in AF.
             If FACT = 'E', then A is overwritten by diag(S)*A*diag(S) and
             the equilibrated matrix is given in AF.
             If FACT = 'N', then AF = A.
             If FACT = 'F', then AF is the LU factorization of A.

    TRANS    (CHARACTER*1)
             Specifies the form of the system of equations to be solved.
             = 'N':  A * X = B      (No transpose)
             = 'T':  A**T * X = B   (Transpose)
             = 'C':  A**H * X = B   (Conjugate transpose)

             Specifies the form of equilibration that was applied to A.
             = 'N':  No equilibration (always true if FACT = 'N').
             = 'S':  Both row and column equilibration, i.e., A has been
                     replaced by diag(S) * A * diag(S).
             = 'R':  Row equilibration, i.e., A has been replaced by
                     diag(S) * A.
             = 'C':  Column equilibration, i.e., A has been replaced by
                     A * diag(S).
             EQUED is an input argument if FACT = 'F'; otherwise, it is an
             output argument.

    N        (INTEGER)
             The order of the matrix A.  N >= 0.

    NRHS     (INTEGER)
             The number of right hand sides, i.e., the number of columns of
             the matrices B and X. NRHS >= 0.

    A        (COMPLEX array, dimension (LDA,N))

             as returned by CGETRF.

             equilibrated matrix A.
