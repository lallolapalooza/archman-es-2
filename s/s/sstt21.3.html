subrutina sstt21 (integer n, integer kband, real, dimension( * ) ad, real, dimension( * ) ae, real, dimension( * ) sd, real, dimension( * ) se, real, dimension( ldu, * ) u, integer ldu, real, dimension( * ) work, real, dimension( 2 ) result)

SSTT21

Propósito:

!>
!> SSTT21 comprueba una descomposición de la forma
!>
!>    A = U S U'
!>
!> donde ' significa transpuesta, A es tridiagonal simétrica, U es ortogonal,
!> y S es diagonal (si KBAND=0) o tridiagonal simétrica (si KBAND=1).
!> Se realizan dos pruebas:
!>
!>    RESULT(1) = | A - U S U' | / ( |A| n ulp )
!>
!>    RESULT(2) = | I - UU' | / ( n ulp )
!>

Parámetros

N 
!>          N es ENTERO
!>          El tamaño de la matriz. Si es cero, SSTT21 no hace nada.
!>          Debe ser al menos cero.
!>

KBAND

!>          KBAND es ENTERO
!>          El ancho de banda de la matriz S. Solo puede ser cero o uno.
!>          Si es cero, entonces S es diagonal, y SE no se referencia. Si
!>          es uno, entonces S es tridiagonal simétrica.
!>

AD

!>          AD es un array REAL, dimension (N)
!>          La diagonal de la matriz A original (no factorizada). Se
!>          asume que A es tridiagonal simétrica.
!>

AE

!>          AE es un array REAL, dimension (N-1)
!>          La subdiagonal de la matriz A original (no factorizada). Se
!>          asume que A es tridiagonal simétrica. AE(1) es el elemento
!>          (1,2) y (2,1), AE(2) es el elemento (2,3) y (3,2), etc.
!>

SD

!>          SD es un array REAL, dimension (N)
!>          La diagonal de la matriz S (tridiagonal simétrica).
!>

SE

!>          SE es un array REAL, dimension (N-1)
!>          La subdiagonal de la matriz S (tridiagonal simétrica).
!>          No se referencia si KBSND=0. Si KBAND=1, entonces AE(1) es el
!>          elemento (1,2) y (2,1), SE(2) es el elemento (2,3) y (3,2),
!>          etc.
!>

U

!>          U es un array REAL, dimension (LDU, N)
!>          La matriz ortogonal en la descomposición.
!>

LDU

!>          LDU es ENTERO
!>          La dimensión principal de U. LDU debe ser al menos N.
!>

WORK

!>          WORK es un array REAL, dimension (N*(N+1))
!>

RESULT

!>          RESULT es un array REAL, dimension (2)
!>          Los valores calculados por las dos pruebas descritas anteriormente.
!>          Actualmente, los valores se limitan a 1/ulp para evitar
!>          desbordamientos. RESULT(1) siempre se modifica.
!>
