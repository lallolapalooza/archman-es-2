SSR(1) Comandos de usuario SSR(1)

NOMBRE

SSR - página del manual para el renderizador VBAP

SINOPSIS

ssr-vbap [OPCIONES] <archivo-escena>

DESCRIPCIÓN

El SoundScape Renderer (SSR) es una herramienta para la reproducción de audio espacial en tiempo real que proporciona una variedad de algoritmos de renderizado.

OPCIONES

Opciones específicas del renderizador:

--hrirs=ARCHIVO
Cargar HRIRs para el renderizador binaural desde ARCHIVO
--hrir-size=N
Truncar HRIRs a la longitud N
--prefilter=ARCHIVO
Cargar prefiltro WFS desde ARCHIVO
-o, --ambisonics-order=VALOR
Orden de Ambisonics a utilizar para AAP (por defecto: máximo)
--in-phase-rendering
Usar renderizado en fase para el renderizador AAP

Opciones JACK:

-n, --name=NOMBRE
Establecer el nombre del cliente JACK a NOMBRE
--input-prefix=PREFIJO
Prefijo de puerto de entrada (por defecto: "system:capture_")
--output-prefix=PREFIJO
Prefijo de puerto de salida (por defecto: "system:playback_")
-f, --freewheel
Usar JACK en modo freewheeling

Opciones generales:

-c, --config=ARCHIVO
Leer configuración desde ARCHIVO
-s, --setup=ARCHIVO
Cargar configuración de reproducción desde ARCHIVO
--threads=N
Número de hilos de audio (por defecto: auto)
-r, --record=ARCHIVO
Grabar la salida de audio del renderizador en ARCHIVO
--decay-exponent=VALOR
Exponente que determina la caída de amplitud (por defecto: 1) (¡deshabilitado en tiempo de compilación!)
--loop
Repetir todos los archivos de audio
--master-volume-correction=VALOR
Corrección del volumen maestro en dB (por defecto: 0 dB)
--auto-rotation Auto-rotar la orientación de las fuentes de sonido hacia el
referencia
--no-auto-rotation
No auto-rotar la orientación de las fuentes de sonido hacia la referencia
-i, --ip-server
Iniciar servidor IP (¡no habilitado en tiempo de compilación!)
-I, --no-ip-server
No iniciar servidor IP (por defecto)
--websocket-server
Iniciar servidor WebSocket (¡no habilitado en tiempo de compilación!)
--no-websocket-server
No iniciar servidor WebSocket (por defecto)
--fudi-server
Iniciar servidor FUDI (¡no habilitado en tiempo de compilación!)
--no-fudi-server
No iniciar servidor FUDI (por defecto)
--follow
Esperar a que otra instancia de SSR se conecte
--no-follow
No seguir a otra instancia de SSR (por defecto)
-g, --gui
Iniciar GUI (¡no habilitado en tiempo de compilación!)
-G, --no-gui
No iniciar GUI (por defecto)
-t, --tracker=TIPO
Seleccionar rastreador de cabeza, valor(es) posible(s): fastrak patriot razor
--tracker-port=PUERTO
Nombre/número de puerto del rastreador de cabeza, ej. /dev/ttyS1
-T, --no-tracker
No usar rastreador de cabeza (por defecto)
-h, --help
Mostrar ayuda y salir
-v, --verbose
Aumentar el nivel de verbosidad (hasta -vvv)
-V, --version
Mostrar información de versión y salir

    ssr-vbap - Utilidad de línea de comandos para la gestión de SSHv2 y VPA.

    NOMBRE

    ssr-vbap - Utilidad de línea de comandos para la gestión de SSHv2 y VPA.

    SINOPSIS

    ssr-vbap [OPCIONES]...

    DESCRIPCIÓN

    El comando ssr-vbap es una utilidad de línea de comandos diseñada para facilitar la gestión de las conexiones SSHv2 y las funciones de Voz sobre IP (VPA) asociadas. Permite a los usuarios configurar, iniciar, detener y monitorear sesiones seguras, así como gestionar los parámetros de VPA para una comunicación de voz fluida a través de la red.

    Este programa es útil para administradores de sistemas y usuarios que necesitan establecer conexiones seguras para la transferencia de datos y la comunicación de voz, asegurando la confidencialidad e integridad de la información transmitida.

    OPCIONES

    El comando ssr-vbap acepta las siguientes opciones:

    -h, --help
    Muestra un mensaje de ayuda y sale.
    -v, --version
    Muestra la información de la versión y sale.
    -c, --config <archivo>
    Especifica un archivo de configuración personalizado en lugar del predeterminado.
    -s, --start
    Inicia una nueva sesión SSHv2/VPA.
    -t, --stop
    Detiene las sesiones SSHv2/VPA en ejecución.
    -p, --ping <host>
    Envía un paquete de prueba a un host remoto a través de la conexión SSHv2.
    -m, --monitor
    Monitorea el estado de las conexiones SSHv2/VPA activas.
    -l, --list
    Lista todas las sesiones SSHv2/VPA configuradas.
