NOMBRE

sssctl - Utilidad de control y estado de SSSD

SINOPSIS

sssctl COMANDO [opciones]

DESCRIPCIÓN

sssctl proporciona una forma sencilla y unificada de obtener información sobre el estado de SSSD, como servidores activos, servidores autodescubiertos, dominios y objetos en caché. Además, puede gestionar archivos de datos de SSSD para la solución de problemas de una manera que es segura de manipular mientras SSSD está en ejecución.

COMANDOS DISPONIBLES

Para listar todos los comandos disponibles, ejecute sssctl sin parámetros. Para imprimir la ayuda de un comando seleccionado, ejecute sssctl COMANDO --help.

OPCIONES COMUNES

Estas opciones están disponibles con todos los comandos.

--debug NIVEL

SSSD admite dos representaciones para especificar el nivel de depuración. La más sencilla es especificar un valor decimal de 0 a 9, que representa la activación de ese nivel y todos los mensajes de depuración de niveles inferiores. La opción más completa es especificar una máscara de bits hexadecimal para habilitar o deshabilitar niveles específicos (por ejemplo, si desea suprimir un nivel).

Niveles de depuración admitidos actualmente:

0, 0x0010: Fallos fatales. Cualquier cosa que impida que SSSD se inicie o provoque que deje de ejecutarse.

1, 0x0020: Fallos críticos. Un error que no mata a SSSD, pero uno que indica que al menos una característica importante no funcionará correctamente.

2, 0x0040: Fallos graves. Un error que anuncia que una solicitud u operación en particular ha fallado.

3, 0x0080: Fallos menores. Estos son los errores que llegarían a causar el fallo de operación de 2.

4, 0x0100: Configuraciones.

5, 0x0200: Datos de función.

6, 0x0400: Mensajes de rastreo para funciones de operación.

7, 0x1000: Mensajes de rastreo para funciones de control internas.

8, 0x2000: Contenidos de variables internas de función que pueden ser interesantes.

9, 0x4000: Información de rastreo de nivel extremadamente bajo.

10, 0x10000: Información de rastreo de libldb de nivel aún más bajo. Casi nunca es realmente necesario.

Para registrar los niveles de depuración de máscara de bits requeridos, simplemente sume sus números como se muestra en los siguientes ejemplos:

Ejemplo: Para registrar fallos fatales, fallos críticos, fallos graves y datos de función, use 0x0270.

Ejemplo: Para registrar fallos fatales, configuraciones, datos de función, mensajes de rastreo para funciones de control internas, use 0x1310.

Nota: El formato de máscara de bits de los niveles de depuración se introdujo en la versión 1.7.0.

Predeterminado: 0x0070 (es decir, fallos fatales, críticos y graves; corresponde a la configuración 2 en notación decimal)
