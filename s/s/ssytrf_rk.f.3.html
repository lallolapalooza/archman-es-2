Documentación de Función/Subrutina

subroutine ssytrf_rk (character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) e, integer, dimension( * ) ipiv, real, dimension( * ) work, integer lwork, integer info)

SSYTRF_RK calcula la factorización de una matriz real simétrica indefinida utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook) (algoritmo bloqueado BLAS3).

Propósito:

!> SSYTRF_RK calcula la factorización de una matriz simétrica real A
!> utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook):
!>
!>    A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es una matriz simétrica y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!> Para más información, véase la sección Detalles Adicionales.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte triangular superior N-por-N principal
!>            de A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no se
!>            referencia.
!>
!>            Si UPLO = 'L': la parte triangular inferior N-por-N principal
!>            de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no se
!>            referencia.
!>
!>          En la salida, contiene:
!>            a) SÓLO los elementos diagonales de la matriz simétrica por bloques
!>               diagonal D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos de la supradiagonal (o subdiagonal) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte supradiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es array REAL, dimensión (N)
!>          En la salida, contiene los elementos de la supradiagonal (o subdiagonal)
!>          de la matriz simétrica por bloques diagonal D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 tanto en
!>          el caso UPLO = 'U' como en el caso UPLO = 'L'.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiadas con la fila y columna k. El valor de UPLO
!>          describe el orden en que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura por bloques
!>          de la matriz simétrica por bloques diagonal D con bloques
!>          de 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización. Para más información, véase la sección
!>          Detalles Adicionales.
!>
!>          Si UPLO = 'U',
!>          ( en orden de factorización, k disminuye de N a 1 ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N);
!>               Si IPIV(k) = k, no hubo intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k e -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no hubo intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 e -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k-1) = k-1, no hubo intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre NO NULA en la salida.
!>
!>          Si UPLO = 'L',
!>          ( en orden de factorización, k aumenta de 1 a N ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N).
!>               Si IPIV(k) = k, no hubo intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k e -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no hubo intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k+1 e -IPIV(k+1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k+1) = k+1, no hubo intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre NO NULA en la salida.
!>

WORK

!>          WORK es array REAL, dimensión (MAX(1,LWORK)).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1.  Para un rendimiento óptimo
!>          LWORK >= N*NB, donde NB es el tamaño de bloque devuelto
!>          por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, porque:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto, D(k,k) es exactamente cero, y los elementos
!>               supradiagonales de la columna k de U (o elementos subdiagonales
!>               de la columna k de L) son todos ceros. La factorización ha
!>               sido completada, pero la matriz diagonal por bloques D
!>               es exactamente singular, y ocurrirá una división por cero si
!>               se utiliza para resolver un sistem

NAME

ssytrf_rk.f(3)

SSTRF_RK computes the factorization of a real symmetric tridiagonal matrix

SYNOPSIS

 subroutine ssytrf_rk(uplo, n, ab, ldab, di, igf, iwk, l, info)
  character uplo
  integer n
  real    ab(ldab,*)
  integer ldab
  real    di(*)
  integer igf(*)
  integer iwk(*)
  integer l
  integer info

Function/Subroutine Documentation

This routine is part of the LAPACK routines that compute the factorizations of real symmetric tridiagonal matrices.

This routine is used to compute the factorization of a real symmetric tridiagonal matrix of the form:

 A = P * D * P^T

where P is a permutation matrix, D is a block diagonal matrix, and P^T is the transpose of P.

The routine computes the factorization using the method described in

 S. Hammarling, O. Gusdorf, and D. J. Higham, “Fast and Robust Factorization of
 Real Symmetric Tridiagonal Matrices,” ACM Trans. Math. Softw. 44, 1 (Jan. 2018),
 Article 7, 10 pages. DOI: https://doi.org/10.1145/3133903

The routine works by computing the factorization of A in block form, where the blocks are of size L.

The factorization is computed in place, meaning that the input matrix AB is overwritten with the factorization.

The routine returns the following information:

 uplo
     Specifies whether the matrix is upper or lower triangular.
     'U' or 'u' indicates upper triangular.
     'L' or 'l' indicates lower triangular.

 n
     The order of the matrix AB.

 ab
     On entry, the tridiagonal matrix AB.
     On exit, the factored matrix.

 ldab
     The leading dimension of the array AB.

 di
     On exit, the diagonal elements of the block diagonal matrix D.

 igf
     On exit, integer array of size N, the “left” vector for the
     permutation matrix P.

The following are optional arguments and are only used when L is not equal to 1:

 iwk
     Integer work array of size N.

 l
     The size of the blocks into which the matrix is factored.
     If L=1, the routine computes the Bunch-Kaufman factorization.
     Otherwise, the routine computes the block factorization.

 info
     = 0: successful exit
     > 0: if info = k, then the L-th diagonal element of the block
          diagonal matrix D is zero. If info > 0, then the
          factorization is completed, but the block is not
          inverted. This indicates that the matrix is singular.
          The factorization is still completed, but the routine
          does not invert the L-th diagonal element of the block
          diagonal matrix D.

 NOTE: INFO only stores the first occurrence of
 a singularity, any subsequent occurrence of singularity
 is not stored in INFO even though the factorization
 always completes.
