Documentación de la Función/Subrutina

subrutina sspr2 (carácter uplo, entero n, real alpha, real, dimensión(*) x, entero incx, real, dimensión(*) y, entero incy, real, dimensión(*) ap)

SSPR2

Propósito:

!>
!> SSPR2 realiza la operación simétrica de rango 2
!>
!>    A := alpha*x*y**T + alpha*y*x**T + A,
!>
!> donde alpha es un escalar, x e y son vectores de n elementos y A es una
!> matriz simétrica de n por n, suministrada en forma empaquetada.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>           A la entrada, UPLO especifica si la parte triangular superior o inferior
!>           de la matriz A se suministra en el array empaquetado
!>           AP de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   La parte triangular superior de A se
!>                                  suministra en AP.
!>
!>              UPLO = 'L' o 'l'   La parte triangular inferior de A se
!>                                  suministra en AP.
!>

N

!>          N es ENTERO
!>           A la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

ALPHA

!>          ALPHA es REAL
!>           A la entrada, ALPHA especifica el escalar alpha.
!>

X

!>          X es un array REAL, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array incrementado X debe contener el vector
!>           x de n elementos.
!>

INCX

!>          INCX es ENTERO
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>

Y

!>          Y es un array REAL, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array incrementado Y debe contener el vector
!>           y de n elementos.
!>

INCY

!>          INCY es ENTERO
!>           A la entrada, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>

AP

!>          AP es un array REAL, de dimensión al menos
!>           ( ( n*( n + 1 ) )/2 ).
!>           Antes de la entrada con UPLO = 'U' o 'u', el array AP debe
!>           contener la parte triangular superior de la matriz simétrica
!>           empaquetada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contenga a( 1, 1 ), AP( 2 ) y AP( 3 ) contengan a( 1, 2 )
!>           y a( 2, 2 ) respectivamente, y así sucesivamente. A la salida, el array
!>           AP se sobrescribe con la parte triangular superior de la
!>           matriz actualizada.
!>           Antes de la entrada con UPLO = 'L' o 'l', el array AP debe
!>           contener la parte triangular inferior de la matriz simétrica
!>           empaquetada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contenga a( 1, 1 ), AP( 2 ) y AP( 3 ) contengan a( 2, 1 )
!>           y a( 3, 1 ) respectivamente, y así sucesivamente. A la salida, el array
!>           AP se sobrescribe con la parte triangular inferior de la
!>           matriz actualizada.
!>
