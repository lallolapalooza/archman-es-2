SSR(1) Comandos de usuario SSR(1)

NOMBRE

SSR - página del manual para el renderizador AAP

SINOPSIS

ssr-aap [OPCIONES] <archivo-escena>

DESCRIPCIÓN

El SoundScape Renderer (SSR) es una herramienta para la reproducción de audio espacial en tiempo real que proporciona una variedad de algoritmos de renderizado.

OPCIONES

Opciones específicas del renderizador:

--hrirs=ARCHIVO
Carga HRIRs para el renderizador binaural desde ARCHIVO
--hrir-size=N
Trunca HRIRs a la longitud N
--prefilter=ARCHIVO
Carga el prefiltro de WFS desde ARCHIVO
-o, --ambisonics-order=VALOR
Orden de ambisonics a utilizar para AAP (por defecto: máximo)
--in-phase-rendering
Utiliza renderizado en fase para el renderizador AAP

Opciones JACK:

-n, --name=NOMBRE
Establece el nombre del cliente JACK a NOMBRE
--input-prefix=PREFIJO
Prefijo de puerto de entrada (por defecto: "system:capture_")
--output-prefix=PREFIJO
Prefijo de puerto de salida (por defecto: "system:playback_")
-f, --freewheel
Utiliza JACK en modo freewheeling

Opciones generales:

-c, --config=ARCHIVO
Lee la configuración desde ARCHIVO
-s, --setup=ARCHIVO
Carga la configuración de reproducción desde ARCHIVO
--threads=N
Número de hilos de audio (por defecto: automático)
-r, --record=ARCHIVO
Graba la salida de audio del renderizador en ARCHIVO
--decay-exponent=VALOR
Exponente que determina la atenuación de la amplitud (por defecto: 1) (¡desactivado en tiempo de compilación!)
--loop
Bucle para todos los archivos de audio
--master-volume-correction=VALOR
Corrección del volumen maestro en dB (por defecto: 0 dB)
--auto-rotation Rota automáticamente la orientación de las fuentes de sonido hacia la
referencia
--no-auto-rotation
No rota automáticamente la orientación de las fuentes de sonido hacia la referencia
-i, --ip-server
Inicia el servidor IP (¡no habilitado en tiempo de compilación!)
-I, --no-ip-server
No inicia el servidor IP (por defecto)
--websocket-server
Inicia el servidor WebSocket (¡no habilitado en tiempo de compilación!)
--no-websocket-server
No inicia el servidor WebSocket (por defecto)
--fudi-server
Inicia el servidor FUDI (¡no habilitado en tiempo de compilación!)
--no-fudi-server
No inicia el servidor FUDI (por defecto)
--follow
Espera a que otra instancia de SSR se conecte
--no-follow
No sigue a otra instancia de SSR (por defecto)
-g, --gui
Inicia la GUI (¡no habilitada en tiempo de compilación!)
-G, --no-gui
No inicia la GUI (por defecto)
-t, --tracker=TIPO
Selecciona el rastreador de cabeza, posible(s) valor(es): fastrak patriot razor
--tracker-port=PUERTO
Nombre/número del puerto del rastreador de cabeza, ej. /dev/ttyS1
-T, --no-tracker
No utiliza un rastreador de cabeza (por defecto)
-h, --help
Muestra la ayuda y sale
-v, --verbose
Aumenta el nivel de verbosidad (hasta -vvv)
-V, --version
Muestra la información de la versión y sale
