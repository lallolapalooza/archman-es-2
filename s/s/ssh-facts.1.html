SSH-FACTS(1) Comandos de usuario SSH-FACTS(1)

NOMBRE

ssh-facts

SINOPSIS

ssh-facts [usuario@]hostname

DESCRIPCIÓN

obtener algunos datos sobre el sistema remoto

Para un procesamiento adicional de los datos
puedes usar herramientas estándar de shell como awk, grep, sed
o convertirlo a JSON con jo y luego pasarlo a jq

EJEMPLOS

ssh-facts 127.0.0.1
ssh-facts 127.0.0.1 | grep ^OS_VERSION | awk -F'=' '{ print $2 }'
ssh-facts 127.0.0.1 | jo -p
ssh-facts 127.0.0.1 | jo | jq
ssh-facts 127.0.0.1 | jo | jq .OS_VERSION
