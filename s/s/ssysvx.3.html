subroutine ssysvx (character fact, character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

SSYSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> SSYSVX utiliza la factorización de pivoteo diagonal para calcular la
!> solución a un sistema real de ecuaciones lineales A * X = B,
!> donde A es una matriz simétrica N por N y X y B son matrices N por NRHS.
!>
!> También se proporcionan estimaciones de los límites de error de la solución y una estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza el método de pivoteo diagonal para factorizar A.
!>    La forma de la factorización es
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices de permutación y triangulares superiores (inferiores) unitarias, y D es simétrica y diagonal por bloques con
!>    bloques diagonales de 1x1 y 2x2.
!>
!> 2. Si algún D(i,i)=0, de modo que D sea exactamente singular, la rutina
!>    devuelve INFO = i. De lo contrario, la forma factorizada de A se utiliza
!>    para estimar el número de condición de la matriz A. Si la
!>    recíproca del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina continúa
!>    resolviendo para X y calculando los límites de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    matriz y calcular los límites de error y las estimaciones de error hacia atrás
!>    para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A se ha suministrado
!>          en la entrada o no.
!>          = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de
!>                  A. AF e IPIV no se modificarán.
!>          = 'N':  La matriz A se copiará en AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte superior N por N
!>          principal de A contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior de A
!>          no se referencia.  Si UPLO = 'L', la parte inferior N por N
!>          principal de A contiene la parte triangular inferior
!>          de la matriz A, y la parte estrictamente triangular superior de A
!>          no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array REAL, de dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>          contiene la matriz diagonal por bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T, tal como fue calculado por SSYTRF.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>          devuelve la matriz diagonal por bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T.
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, tal como fueron determinados por SSYTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2. Si UPLO = 'L' e IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 y -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, tal como fueron determinados por SSYTRF.
!>

B

!>          B es un array REAL, de dimensión (LDB,NRHS)
!>          La matriz del lado derecho B, de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array REAL, de dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X, de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La estimación de la recíproca del número de condición de la matriz
!>          A.  Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular a la precisión de trabajo.
!>          Esta condición se indica con un código de retorno de
!>          INFO > 0.
!>

FERR

!>          FERR es un array REAL, de dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array REAL, de dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= max(1,3*N), y

ssysvx(3) - LAPACK documentation

NAME

ssysvx - factorize a real symmetric matrix A in the split form A=(U-P)*D*(U-P)^T and solve a linear system and estimate the error bounds

SYNOPSIS

CALL SSYSVX(FACT, UPLO, N, NRHS, A, LDA, AF, LDAF, IPIV, B, LDB, X, LDX,
             RCOND, FERR, BERR, WORK, IWORK, INFO)

Parameters

FACT
CHARACTER*1.
  =‘N’: The LU decomposition of A is not performed by this routine,
  but must have been previously computed by SSYTRF.
  =‘F’: The LU decomposition of A is computed by this routine.
  =‘E’: The LU decomposition of A is computed by this routine.   In this case, RCOND is used to check whether the computed factor AF is
  a good approximation of the factors of the original matrix A. If the
  check fails, the LU decomposition is recomputed by SSYTRF.
  =‘N’ and ‘E’ are not supported.
UPLO
CHARACTER*1.
  =‘U’: Upper triangle of A is stored and will be used in
  computational.
  =‘L’: Lower triangle of A is stored and will be used in
  computational.
N
INTEGER.
  The order of the matrix A. N >= 0.
NRHS
INTEGER.
  The number of right hand side vectors, i.e. the number of columns
  in the arrays B and X. NRHS >= 0.
A
REAL array, dimension (LDA,N).
  On entry, the original symmetric matrix A.
  If FACT = ‘F’ or FACT = ‘E’, the matrix A is not required to be
  stored.
  If FACT = ‘N’, the factor U or L from the factorization of A is
  stored in the upper or lower triangle respectively. See AF.
LDA
INTEGER.
  The leading dimension of the array A. LDA >= max(1,N).
AF
REAL array, dimension (LDAF,N).
  If FACT = ‘F’, AF contains the block LU factorization of A.
  If FACT = ‘N’, AF contains the factors U or L from the
  factorization of A. See also the description of A.
LDAF
INTEGER.
  The leading dimension of the array AF. LDAF >= max(1,N).
IPIV
INTEGER array, dimension (N).
  Details of the interchanges in the factorization.
  If UPLO = ‘U’, pivot information is for the upper triangle.
  If UPLO = ‘L’, pivot information is for the lower triangle.
B
REAL array, dimension (LDB,NRHS).
  The right hand side matrix A*X and matrix of right hand side
  vectors, B. The unused portions of the array B are not
  modified.
LDB
INTEGER.
  The leading dimension of the array B. LDB >= max(1,N).
X
REAL array, dimension (LDX,NRHS).
  If successful, the solution matrix X to the system A*X = B.
LDX
INTEGER.
  The leading dimension of the array X. LDX >= max(1,N).
RCOND
REAL.
  On exit, an estimate of the reciprocal of the condition number of
  the matrix A. Equals the value RCOND computed by SSYCON.
FERR
REAL array, dimension (NRHS).
  On exit, the estimated forward error bound for each respective
  column of X, and for the solutions of the systems
  A*X = B.
BERR
REAL array, dimension (NRHS).
  On exit, the componentwise backward error bound for each
  respective column of X. BERR(i) is an estimate for the relative
  reduction in the matrix A and on the right hand side B in the
  i-th column of B and X.
WORK
REAL array, dimension (LWORK).
  On exit, WORK(1) contains the optimal LWORK.
LWORK
INTEGER.
  The dimension of the array WORK.
  For best performance when FACT = ‘F’, we have
  LWORK >= max(1,3*N,N*NB), where NB is the optimal blocksize for SSYTRF.
  If LWORK = -1, then a workspace query is assumed; the routine
  only calculates the optimal size of the WORK array, returns
  this value as the first entry of the WORK array, and no error
  message related to LWORK is issued by XERBLA.
 
IWORK
INTEGER array, dimension (N)
 
INFO
INTEGER.
  = 0: successful exit
 < 0: if INFO = -i, the i-th argument had an illegal value
 > 0: if INFO = i, and i is
    <= N: D(i,i) is exactly zero. The factorization
    has been completed but the factor D is exactly
    singular, so the solution and error bounds could
    not be computed. RCOND = 0 is returned.
   = N+1: D is nonsingular, but RCOND is less than machine
   precision, meaning that the matrix is singular
   to working precision. Nevertheless, the
   solution and error bounds are computed because
   there are a number of situations where the
   computed solution can be more accurate than the
   value of RCOND would suggest.
