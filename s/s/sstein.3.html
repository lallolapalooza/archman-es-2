Documentación de la Función/Subrutina

subrutina sstein (integer n, real, dimension( * ) d, real, dimension( * ) e, integer m, real, dimension( * ) w, integer, dimension( * ) iblock, integer, dimension( * ) isplit, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

SSTEIN

Propósito:

!>
!> SSTEIN calcula los vectores propios de una matriz tridiagonal simétrica
!> real T correspondientes a los valores propios especificados, utilizando
!> la iteración inversa.
!>
!> El número máximo de iteraciones permitidas para cada vector propio se
!> especifica mediante un parámetro interno MAXITS (actualmente establecido en 5).
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array REAL, dimension (N)
!>          Los n elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es un array REAL, dimension (N-1)
!>          Los (n-1) elementos subdiagonales de la matriz
!>          tridiagonal T, en los elementos 1 a N-1.
!>

M

!>          M es INTEGER
!>          El número de vectores propios a encontrar.  0 <= M <= N.
!>

W

!>          W es un array REAL, dimension (N)
!>          Los primeros M elementos de W contienen los valores propios para
!>          los cuales se van a calcular los vectores propios.  Los valores propios
!>          deben agruparse por bloque dividido y ordenarse de menor a
!>          mayor dentro del bloque.  ( Se espera el array de salida
!>          W de SSTEBZ con ORDER = 'B' aquí. )
!>

IBLOCK

!>          IBLOCK es un array INTEGER, dimension (N)
!>          Los índices de submatriz asociados con los valores propios
!>          correspondientes en W; IBLOCK(i)=1 si el valor propio W(i) pertenece
!>          a la primera submatriz desde arriba, =2 si W(i) pertenece
!>          a la segunda submatriz, etc.  ( Se espera el array de salida
!>          IBLOCK de SSTEBZ aquí. )
!>

ISPLIT

!>          ISPLIT es un array INTEGER, dimension (N)
!>          Los puntos de división, en los que T se descompone en submatrices.
!>          La primera submatriz consta de las filas/columnas 1 a
!>          ISPLIT( 1 ), la segunda de las filas/columnas ISPLIT( 1 )+1
!>          a ISPLIT( 2 ), etc.
!>          ( Se espera el array de salida
!>          ISPLIT de SSTEBZ aquí. )
!>

Z

!>          Z es un array REAL, dimension (LDZ, M)
!>          Los vectores propios calculados.  El vector propio asociado
!>          con el valor propio W(i) se almacena en la i-ésima columna de
!>          Z.  Cualquier vector que no converja se establece en su
!>          iteración actual después de MAXITS iteraciones.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= max(1,N).
!>

WORK

!>          WORK es un array REAL, dimension (5*N)
!>

IWORK

!>          IWORK es un array INTEGER, dimension (N)
!>

IFAIL

!>          IFAIL es un array INTEGER, dimension (M)
!>          En la salida normal, todos los elementos de IFAIL son cero.
!>          Si uno o más vectores propios no convergen después de
!>          MAXITS iteraciones, sus índices se almacenan en
!>          el array IFAIL.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa.
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, entonces i vectores propios no convergieron
!>               en MAXITS iteraciones. Sus índices se almacenan en
!>               el array IFAIL.
!>

Parámetros internos:

!>  MAXITS  INTEGER, por defecto = 5
!>          El número máximo de iteraciones realizadas.
!>
!>  EXTRA   INTEGER, por defecto = 2
!>          El número de iteraciones realizadas después de que se
!>          satisface el criterio de crecimiento de la norma, debe ser al
!>          menos 1.
!>
