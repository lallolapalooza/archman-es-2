NOMBRE

sssd-ldap-attributes - Proveedor LDAP de SSSD: Mapeo de atributos

DESCRIPCIÓN

Esta página del manual describe los atributos de mapeo del proveedor LDAP de SSSD sssd-ldap(5). Consulte la página del manual de sssd-ldap(5) para obtener detalles completos sobre las opciones de configuración del proveedor LDAP de SSSD.

ATRIBUTOS DE USUARIO

ldap_user_object_class (string)

La clase de objeto de una entrada de usuario en LDAP.

Por defecto: posixAccount

ldap_user_name (string)

El atributo LDAP que corresponde al nombre de inicio de sesión del usuario.

Por defecto: uid (rfc2307, rfc2307bis e IPA), sAMAccountName (AD)

ldap_user_uid_number (string)

El atributo LDAP que corresponde al id del usuario.

Por defecto: uidNumber

ldap_user_gid_number (string)

El atributo LDAP que corresponde al id del grupo principal del usuario.

Por defecto: gidNumber

ldap_user_primary_group (string)

Atributo del grupo principal de Active Directory para el mapeo de IDs. Tenga en cuenta que este atributo solo debe configurarse manualmente si está ejecutando el proveedor “ldap” con mapeo de IDs.

Por defecto: no establecido (LDAP), primaryGroupID (AD)

ldap_user_gecos (string)

El atributo LDAP que corresponde al campo gecos del usuario.

Por defecto: gecos

ldap_user_home_directory (string)

El atributo LDAP que contiene el nombre del directorio principal del usuario.

Por defecto: homeDirectory (LDAP e IPA), unixHomeDirectory (AD)

ldap_user_shell (string)

El atributo LDAP que contiene la ruta al shell predeterminado del usuario.

Por defecto: loginShell

ldap_user_uuid (string)

El atributo LDAP que contiene el UUID/GUID de un objeto de usuario LDAP.

Por defecto: no establecido en el caso general, objectGUID para AD e ipaUniqueID para IPA

ldap_user_objectsid (string)

El atributo LDAP que contiene el objectSID de un objeto de usuario LDAP. Esto suele ser necesario solo para servidores de Active Directory.

Por defecto: objectSid para ActiveDirectory, no establecido para otros servidores.

ldap_user_modify_timestamp (string)

El atributo LDAP que contiene la marca de tiempo de la última modificación del objeto padre.

Por defecto: modifyTimestamp

ldap_user_shadow_last_change (string)

Cuando se utiliza ldap_pwd_policy=shadow, este parámetro contiene el nombre de un atributo LDAP que corresponde a su contraparte de shadow(5) (fecha del último cambio de contraseña).

Por defecto: shadowLastChange

ldap_user_shadow_min (string)

Cuando se utiliza ldap_pwd_policy=shadow, este parámetro contiene el nombre de un atributo LDAP que corresponde a su contraparte de shadow(5) (edad mínima de la contraseña).

Por defecto: shadowMin

ldap_user_shadow_max (string)

Cuando se utiliza ldap_pwd_policy=shadow, este parámetro contiene el nombre de un atributo LDAP que corresponde a su contraparte de shadow(5) (edad máxima de la contraseña).

Por defecto: shadowMax

ldap_user_shadow_warning (string)

Cuando se utiliza ldap_pwd_policy=shadow, este parámetro contiene el nombre de un atributo LDAP que corresponde a su contraparte de shadow(5) (período de advertencia de contraseña).

Por defecto: shadowWarning

ldap_user_shadow_inactive (string)

Cuando se utiliza ldap_pwd_policy=shadow, este parámetro contiene el nombre de un atributo LDAP que corresponde a su contraparte de shadow(5) (período de inactividad de la contraseña).

Por defecto: shadowInactive

ldap_user_shadow_expire (string)

Cuando se utiliza ldap_pwd_policy=shadow o ldap_account_expire_policy=shadow, este parámetro contiene el nombre de un atributo LDAP que corresponde a su contraparte de shadow(5) (fecha de expiración de la cuenta).

Por defecto: shadowExpire

ldap_user_krb_last_pwd_change (string)

Cuando se utiliza ldap_pwd_policy=mit_kerberos, este parámetro contiene el nombre de un atributo LDAP que almacena la fecha y hora del último cambio de contraseña en kerberos.

Por defecto: krbLastPwdChange

ldap_user_krb_password_expiration (string)

Cuando se utiliza ldap_pwd_policy=mit_kerberos, este parámetro contiene el nombre de un atributo LDAP que almacena la fecha y hora en que expira la contraseña actual.

Por defecto: krbPasswordExpiration

ldap_user_ad_account_expires (string)

Cuando se utiliza ldap_account_expire_policy=ad, este parámetro contiene el nombre de un atributo LDAP que almacena la hora de expiración de la cuenta.

Por defecto: accountExpires

ldap_user_ad_user_account_control (string)

Cuando se utiliza ldap_account_expire_policy=ad, este parámetro contiene el nombre de un atributo LDAP que almacena el campo de bits de control de cuenta de usuario.

Por defecto: userAccountControl

ldap_ns_account_lock (string)

Cuando se utiliza ldap_account_expire_policy=rhds o equivalente, este parámetro determina si se permite el acceso o no.

Por defecto: nsAccountLock

ldap_user_nds_login_disabled (string)

Cuando se utiliza ldap_account_expire_policy=nds, este atributo determina si se permite el acceso o no.

Por defecto: loginDisabled

ldap_user_nds_login_expiration_time (string)

Cuando se utiliza ldap_account_expire_policy=nds, este atributo determina hasta qué fecha se concede el acceso.

Por defecto: loginDisabled

ldap_user_nds_login_allowed_time_map (string)

Cuando se utiliza ldap_account_expire_policy=nds, este atributo determina las horas del día de la semana en las que se concede el acceso.

Por defecto: loginAllowedTimeMap

ldap_user_principal (string)

El atributo LDAP que contiene el Nombre Principal de Usuario (UPN) Kerberos del usuario.

Por defecto: krbPrincipalName

ldap_user_extra_attrs (string)

Lista separada por comas de atributos LDAP que SSSD recuperaría junto con el conjunto habitual de atributos de usuario.

La lista puede contener solo nombres de atributos LDAP, o tuplas separadas por dos puntos de nombre de atributo SSSD y nombre de atributo LDAP. En caso de que solo se especifique el nombre del atributo LDAP, el atributo se guarda en la caché tal cual. Puede ser necesario utilizar un nombre de atributo SSSD personalizado en entornos que configuran varios dominios SSSD con diferentes esquemas LDAP.

Tenga en cuenta que varios nombres de atributos están reservados por SSSD, en particular el atributo “name”. SSSD informará de un error si se utiliza alguno de los nombres de atributos reservados como nombre de atributo adicional.

Ejemplos:

ldap_user_extra_attrs = telephoneNumber

Guarda el atributo “telephoneNumber” de LDAP como “telephoneNumber” en la caché.

ldap_user_extra_attrs = phone:telephoneNumber

Guarda el atributo “telephoneNumber” de LDAP como “phone” en la caché.

Por defecto: no establecido

ldap_user_ssh_public_key (string)

El atributo LDAP que contiene las claves públicas SSH del usuario.

Por defecto: sshPublicKey

ldap_user_fullname (string)

El atributo LDAP que corresponde al nombre completo del usuario.

Por defecto: cn

ldap_user_member_of (string)

El atributo LDAP que enumera las pertenencias a grupos del usuario.

Por defecto: memberOf

ldap_user_authorized_service (string)

If access_provider=ldap and ldap_access_order=authorized_service, SSSD will use the presence of the authorizedService attribute in the user's LDAP entry to determine access privilege.

An explicit deny (!authorizedService) is resolved first. Second, SSSD searches for explicit allow (authorizedService) and finally for allow_all (*).

Please note that the ldap_access_order configuration option must include “authorized_service” in order for the ldap_user_authorized_service option to work.

Some distributions (such as Fedora-29+ or RHEL-8) always include the “systemd-user” PAM service as part of the login process. Therefore when using service-based access control, the “systemd-user” service might need to be added to the list of allowed services.

Default: authorizedService

ldap_user_authorized_host (string)

If access_provider=ldap and ldap_access_order=host, SSSD will use the presence of the host attribute in the user's LDAP entry to determine access privilege.

An explicit deny (!host) is resolved first. Second, SSSD searches for explicit allow (host) and finally for allow_all (*).

Please note that the ldap_access_order configuration option must include “host” in order for the ldap_user_authorized_host option to work.

Default: host

ldap_user_authorized_rhost (string)

If access_provider=ldap and ldap_access_order=rhost, SSSD will use the presence of the rhost attribute in the user's LDAP entry to determine access privilege. Similarly to host verification process.

An explicit deny (!rhost) is resolved first. Second, SSSD searches for explicit allow (rhost) and finally for allow_all (*).

Please note that the ldap_access_order configuration option must include “rhost” in order for the ldap_user_authorized_rhost option to work.

Default: rhost

ldap_user_certificate (string)

Name of the LDAP attribute containing the X509 certificate of the user.

Default: userCertificate;binary

ldap_user_email (string)

Name of the LDAP attribute containing the email address of the user.

Note: If an email address of a user conflicts with an email address or fully qualified name of another user, then SSSD will not be able to serve those users properly. This option allows users to login by (1) username, and (2) e-mail address. If for some reason several users need to share the same email address then set this option to a nonexistent attribute name in order to disable user lookup/login by email.

Default: mail

ldap_user_passkey (string)

Name of the LDAP attribute containing the passkey mapping data of the user.

Default: passkey (LDAP), ipaPassKey (IPA), altSecurityIdentities (AD)

ADVANCED OPTIONS

ldap_chase_referrals (boolean)

This option controls whether SSSD follows referrals when searching LDAP servers.

Default: true

ldap_referrals (boolean)

This option controls whether SSSD sends referrals to the client.

Default: true

ldap_require_cert (boolean)

This option controls whether SSSD requires a certificate from the LDAP server when using TLS/SSL.

Possible values: true, false, demand, allow, try

Default: allow

ldap_tls_reqcert (string)

This option controls the certificate verification behavior for LDAP over TLS/SSL connections. The possible values are:

none: Do not check the server certificate.

allow: Check the server certificate only if the server provides one.

try: Check the server certificate if the server provides one; otherwise, do not check.

demand: Always check the server certificate. This is the default and recommended value for secure environments.

hard: Same as demand, but fail the connection if the certificate is invalid.

soft: Same as demand, but do not fail the connection if the certificate is invalid. This is useful for testing.

Default: demand

ldap_uri (uri)

The URI of the LDAP server. This option can be specified multiple times to provide a list of servers.
