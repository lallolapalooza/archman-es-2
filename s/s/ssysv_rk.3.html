subrutina ssysv_rk (uplo, n, nrhs, a, lda, e, ipiv, b, ldb, work, lwork, info)
SSYSV_RK calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina ssysv_rk (character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( * ) e, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) work, integer lwork, integer info)

SSYSV_RK calcula la solución a un sistema de ecuaciones lineales real A * X = B, donde A es una matriz simétrica N por N y X y B son matrices N por NRHS.

Propósito:

!> SSYSV_RK calcula la solución a un sistema de ecuaciones lineales real
!> de ecuaciones A * X = B, donde A es una matriz simétrica N por N
!> y X y B son matrices N por NRHS.
!>
!> Se utiliza el método de pivoteo diagonal acotado de Bunch-Kaufman (rook)
!> para factorizar A como
!>    A = P*U*D*(U**T)*(P**T),  si UPLO = 'U', o
!>    A = P*L*D*(L**T)*(P**T),  si UPLO = 'L',
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es simétrica y diagonal por bloques con
!> bloques diagonales de 1x1 y 2x2.
!>
!> Se llama a SSYTRF_RK para calcular la factorización de una matriz
!> simétrica real. Luego, la forma factorizada de A se utiliza para resolver
!> el sistema de ecuaciones A * X = B llamando a la rutina BLAS3 SSYTRS_3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es una matriz REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte triangular superior N por N principal
!>            de A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no se
!>            referencia.
!>
!>            Si UPLO = 'L': la parte triangular inferior N por N principal
!>            de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no se
!>            referencia.
!>
!>          En la salida, si INFO = 0, el diagonal de la matriz diagonal
!>          por bloques D y los factores U o L, tal como se calculan por
!>          SSYTRF_RK:
!>            a) SOLO los elementos diagonales de la matriz diagonal
!>               por bloques simétrica D en la diagonal de A, es decir,
!>               D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': el factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': el factor L en la parte subdiagonal de A.
!>
!>          Para más información, ver la descripción de la rutina DSYTRF_RK.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es una matriz REAL, de dimensión (N)
!>          En la salida, contiene la salida calculada por la rutina de
!>          factorización DSYTRF_RK, es decir, los elementos superdiagonales
!>          (o subdiagonales) de la matriz diagonal por bloques simétrica D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece en 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece en 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece en 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>
!>          Para más información, ver la descripción de la rutina DSYTRF_RK.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D,
!>          tal como determina SSYTRF_RK.
!>
!>          Para más información, ver la descripción de la rutina DSYTRF_RK.
!>

B

!>          B es una matriz REAL, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B de N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un array REAL, de dimensión ( MAX(1,LWORK) ).
!>          Array de trabajo utilizado en la etapa de factorización.
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1. Para un rendimiento óptimo
!>          de la etapa de factorización, LWORK >= max(1,N*NB), donde NB es
!>          el tamaño de bloque óptimo para DSYTRF_RK.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK
!>          para la etapa de factorización, devuelve este valor como
!>          la primera entrada del array WORK, y XERBLA no emite ningún
!>          mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal.
!>
!>          > 0: Si INFO = k, la matriz A es singular, debido a que:
!>                 Si UPLO = 'U': la columna k en la parte triangular
!>                 superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte triangular
!>                 inferior de A contiene todos ceros.
!>
!>               Por lo tanto, D(k,k) es exactamente cero, y los elementos
!>               superdiagonales de la columna k de U (o los elementos
!>               subdiagonales de la columna k de L) son todos ceros. La
!>               factorización se ha completado, pero la matriz diagonal
!>               por bloques D es exactamente singular, y se producirá una
!>               división por cero si se utiliza para resolver un sistema
!>               de ecuaciones.
!>
!>               NOTA: INFO solo almacena la primera ocurrencia
!>               de una singularidad, cualquier ocurrencia posterior de
!>               singularidad no se almacena en INFO, aunque la
!>               factorización siempre se completa.
!>
