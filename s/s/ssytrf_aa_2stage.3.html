Documentación de Función/Subrutina

subroutine ssytrf_aa_2stage (character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tb, integer ltb, integer, dimension( * ) ipiv, integer, dimension( * ) ipiv2, real, dimension( * ) work, integer lwork, integer info)

SSYTRF_AA_2STAGE

Propósito:

!>
!> SSYTRF_AA_2STAGE calcula la factorización de una matriz real simétrica A
!> utilizando el algoritmo de Aasen. La forma de la factorización es
!>
!>    A = U**T*T*U  o  A = L*T*L**T
!>
!> donde U (o L) es un producto de matrices de permutación y triangulares unitarias superiores (inferiores), y T es una matriz simétrica de banda con el
!> ancho de banda NB (NB se selecciona internamente y se almacena en TB( 1 ), y T se factoriza LU con pivoteo parcial).
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular N por N de A contiene la parte superior
!>          triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia. Si UPLO = 'L', la parte
!>          inferior triangular N por N de A contiene la parte inferior
!>          triangular de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>
!>          En la salida, L se almacena debajo (o encima) de los bloques subdiagonales,
!>          cuando UPLO  es 'L' (o 'U').
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

TB

!>          TB es un array REAL, de dimensión (LTB)
!>          En la salida, detalles de la factorización LU de la matriz de banda.
!>

LTB

!>          LTB es INTEGER
!>          El tamaño del array TB. LTB >= MAX(1,4*N), utilizado internamente
!>          para seleccionar NB tal que LTB >= (3*NB+1)*N.
!>
!>          Si LTB = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo de LTB,
!>          lo devuelve como la primera entrada de TB, y
!>          XERBLA no emite ningún mensaje de error relacionado con LTB.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A se intercambiaron con la
!>          fila y columna IPIV(k).
!>

IPIV2

!>          IPIV2 es un array INTEGER, de dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de T se intercambiaron con la
!>          fila y columna IPIV(k).
!>

WORK

!>          WORK es un espacio de trabajo REAL de tamaño (MAX(1,LWORK))
!>

LWORK

!>          LWORK es INTEGER
!>          El tamaño de WORK. LWORK >= MAX(1,N), utilizado internamente para
!>          seleccionar NB tal que LWORK >= N*NB.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array WORK,
!>          lo devuelve como la primera entrada del array WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, la factorización LU de banda falló en la i-ésima columna
!>
