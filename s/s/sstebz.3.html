Documentación de Función/Subrutina

subroutine sstebz (character range, character order, integer n, real vl, real vu, integer il, integer iu, real abstol, real, dimension( * ) d, real, dimension( * ) e, integer m, integer nsplit, real, dimension( * ) w, integer, dimension( * ) iblock, integer, dimension( * ) isplit, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SSTEBZ

Propósito:

!>
!> SSTEBZ calcula los valores propios de una matriz tridiagonal simétrica
!> T. El usuario puede solicitar todos los valores propios, todos los valores propios
!> en el intervalo semiabierto (VL, VU], o los valores propios IL-ésimo hasta IU-ésimo.
!>
!> Para evitar desbordamiento, la matriz debe ser escalada de tal manera que su
!> elemento más grande no exceda overflow**(1/2) * underflow**(1/4) en valor absoluto, y para máxima
!> precisión, no debe ser mucho menor que eso.
!>
!> Véase W. Kahan, Report CS41, Computer Science Dept., Stanford
!> University, 21 de julio de 1966.
!>

Parámetros

RANGE 
!>          RANGE es CHARACTER*1
!>          = 'A': ()   se encontrarán todos los valores propios.
!>          = 'V': () se encontrarán todos los valores propios en el intervalo
!>                           semiabierto (VL, VU].
!>          = 'I': () se encontrarán los valores propios IL-ésimo hasta IU-ésimo (de
!>                           la matriz completa).
!>

ORDER

!>          ORDER es CHARACTER*1
!>          = 'B': () los valores propios se agruparán por
!>                              bloque de separación (ver IBLOCK, ISPLIT) y
!>                              se ordenarán de menor a mayor dentro del
!>                              bloque.
!>          = 'E': ()
!>                              los valores propios de la matriz completa
!>                              se ordenarán de menor a
!>                              mayor.
!>

N

!>          N es INTEGER
!>          El orden de la matriz tridiagonal T. N >= 0.
!>

VL

!>          VL es REAL
!>
!>          Si RANGE='V', el límite inferior del intervalo que
!>          se buscará para los valores propios. Los valores propios menores o iguales
!>          a VL, o mayores que VU, no serán devueltos. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>
!>          Si RANGE='V', el límite superior del intervalo que
!>          se buscará para los valores propios. Los valores propios menores o iguales
!>          a VL, o mayores que VU, no serán devueltos. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia absoluta para los valores propios. Un valor propio
!>          (o clúster) se considera localizado si se ha determinado que yace
!>          en un intervalo cuyo ancho es ABSTOL o
!>          menor. Si ABSTOL es menor o igual a cero, entonces se usará ULP*|T|
!>          donde |T| significa la norma 1 de T.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL se
!>          establezca en el doble del umbral de desbordamiento 2*SLAMCH('S'), no cero.
!>

D

!>          D es array REAL, dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es array REAL, dimensión (N-1)
!>          Los n-1 elementos fuera de la diagonal de la matriz tridiagonal T.
!>

M

!>          M es INTEGER
!>          El número real de valores propios encontrados. 0 <= M <= N.
!>          (Ver también la descripción de INFO=2,3.)
!>

NSPLIT

!>          NSPLIT es INTEGER
!>          El número de bloques diagonales en la matriz T.
!>          1 <= NSPLIT <= N.
!>

W

!>          W es array REAL, dimensión (N)
!>          A la salida, los primeros M elementos de W contendrán los
!>          valores propios. (SSTEBZ puede usar los N-M elementos restantes como
!>          espacio de trabajo.)
!>

IBLOCK

!>          IBLOCK es array INTEGER, dimensión (N)
!>          En cada fila/columna j donde E(j) es cero o pequeño, la
!>          matriz T se considera dividida en una matriz diagonal por bloques.
!>          A la salida, si INFO = 0, IBLOCK(i) especifica a qué
!>          bloque (de 1 al número de bloques) pertenece el valor propio W(i).
!>          (SSTEBZ puede usar los N-M elementos restantes como
!>          espacio de trabajo.)
!>

ISPLIT

!>          ISPLIT es array INTEGER, dimensión (N)
!>          Los puntos de división, en los que T se divide en submatrices.
!>          La primera submatriz consta de las filas/columnas 1 a ISPLIT(1),
!>          la segunda de las filas/columnas ISPLIT(1)+1 hasta ISPLIT(2),
!>          etc., y la NSPLIT-ésima consta de las filas/columnas
!>          ISPLIT(NSPLIT-1)+1 hasta ISPLIT(NSPLIT)=N.
!>          (Solo se usarán los primeros NSPLIT elementos, pero
!>          como el usuario no puede saber a priori qué valor tendrá NSPLIT,
!>          se deben reservar N palabras para ISPLIT.)
!>

WORK

!>          WORK es array REAL, dimensión (4*N)
!>

IWORK

!>          IWORK es array INTEGER, dimensión (3*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  algunos o todos los valores propios no convergieron o
!>                no fueron calculados:
!>                =1 o 3: La bisección no convergió para algunos
!>                        valores propios; estos valores propios están marcados con un
!>                        número de bloque negativo. El efecto es que los
!>                        valores propios pueden no ser tan precisos como las
!>                        tolerancias absoluta y relativa. Esto es
!>                        generalmente causado por aritmética inesperadamente imprecisa.
!>                =2 o 3: Solo RANGE='I': No se encontraron todos los valores propios
!>                        IL:IU.
!>                        Efecto: M < IU+1-IL
!>                        Causa: aritmética no monotónica, que causa que la
!>                               secuencia de Sturm no sea monotónica.
!>                        Solución: recalcular, usando RANGE='A', y extraer
!>                               los valores propios IL:IU. En algunos casos,
!>                               incrementar el PARAMETER puede
!>                               solucionar el problema.
!>                = 4:    RANGE='I', y el intervalo de Gershgorin
!>                        utilizado inicialmente era demasiado pequeño. No se calcularon valores propios.
!>                        Causa probable: su máquina tiene aritmética
!>                                        de punto flotante imprecisa.
!>                        Solución: Incrementar el PARAMETER,
!>                                  recompilar e intentarlo de nuevo.
!>

Parámetros internos:

> 
!>  RELFAC  REAL, default = 2.0e0
!>          La tolerancia relativa. Un intervalo (a,b] está dentro
!>           si  b-a < RELFAC*ulp*max(|a|,|b|),
!>          donde  es la precisión de la máquina (distancia de 1 al
!>          próximo número de punto flotante mayor.)
!>
!>  FUDGE   REAL, default = 2
!>          Un  para ampliar los intervalos de Gershgorin. Idealmente,
!>          un valor de 1 debería funcionar, pero en máquinas con
!>          aritmética descuidada, esto necesita ser mayor. El valor por defecto para
!>          las versiones publicadas públicamente debería ser lo suficientemente grande como para manejar
!>          la peor máquina. Tenga en cuenta que esto no tiene ningún efecto
!>          en la precisión de la solución.
!>
