subrutina ssptri (carácter uplo, entero n, real, dimensión( * ) ap, entero, dimensión( * ) ipiv, real, dimensión( * ) work, entero info)

SSPTRI

Propósito

!>
!> SSPTRI calcula la inversa de una matriz real simétrica indefinida
!> A en almacenamiento empaquetado utilizando la factorización A = U*D*U**T o
!> A = L*D*L**T calculada por SSPTRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, la forma es A = U*D*U**T;
!>          = 'L':  Triangular inferior, la forma es A = L*D*L**T.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array REAL, dimensión (N*(N+1)/2)
!>          En la entrada, la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L calculados por SSPTRF,
!>          almacenados como una matriz triangular empaquetada.
!>
!>          En la salida, si INFO = 0, la inversa (simétrica) de la matriz original,
!>          almacenada como una matriz triangular empaquetada. La columna j-ésima
!>          de inv(A) se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = inv(A)(i,j) para 1<=i<=j;
!>          si UPLO = 'L',
!>             AP(i + (j-1)*(2n-j)/2) = inv(A)(i,j) para j<=i<=n.
!>

IPIV

!>          IPIV es un array ENTERO, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          determinados por SSPTRF.
!>

WORK

!>          WORK es un array REAL, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) = 0; la matriz es singular y su
!>               inversa no pudo ser calculada.
!>
