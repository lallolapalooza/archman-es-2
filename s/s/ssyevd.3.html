subrutina ssyevd (jobz, uplo, n, a, lda, w, work, lwork, iwork, liwork, info)

SSYEVD calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices SY

Documentación de función/subrutina

subrutina ssyevd (character jobz, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) w, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSYEVD calcula los valores propios y, opcionalmente, los vectores propios para matrices SY

Propósito:

!>
!> SSYEVD calcula todos los valores propios y, opcionalmente, los vectores
!> propios de una matriz real simétrica A. Si se desean vectores propios,
!> utiliza un algoritmo de divide y vencerás.
!>
!> Debido al gran uso de BLAS de nivel 3, SSYEVD necesita N**2 de espacio de
!> trabajo más que SSYEVX.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, dimension (LDA, N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la
!>          parte triangular superior N por N principal de A contiene la
!>          parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior N por N principal de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene los
!>          vectores propios ortonormales de la matriz A.
!>          Si JOBZ = 'N', entonces en la salida el triángulo inferior (si UPLO='L')
!>          o el triángulo superior (si UPLO='U') de A, incluyendo la
!>          diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

W

!>          W es un array REAL, dimension (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

WORK

!>          WORK es un array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK debe ser al menos 1.
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser al menos 2*N+1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser al menos
!>                                                1 + 6*N + 2*N**2.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula los tamaños óptimos de los arrays WORK e
!>          IWORK, devuelve estos valores como las primeras entradas de los
!>          arrays WORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimension (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si N <= 1,                LIWORK debe ser al menos 1.
!>          Si JOBZ  = 'N' y N > 1, LIWORK debe ser al menos 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK debe ser al menos 3 + 5*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula los tamaños óptimos de los arrays WORK e
!>          IWORK, devuelve estos valores como las primeras entradas de los
!>          arrays WORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tuvo un valor ilegal
!>          > 0:  si INFO = i y JOBZ = 'N', entonces el algoritmo falló
!>                en converger; i elementos fuera de la diagonal de una forma
!>                tridiagonal intermedia no convergieron a cero;
!>                si INFO = i y JOBZ = 'V', entonces el algoritmo falló
!>                en calcular un valor propio mientras trabajaba en la submatriz
!>                situada en las filas y columnas INFO/(N+1) hasta
!>                mod(INFO,N+1).
!>
