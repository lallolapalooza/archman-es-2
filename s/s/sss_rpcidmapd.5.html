NOMBRE

sss_rpcidmapd - directivas de configuración del plugin sss para rpc.idmapd

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración de rpc.idmapd se encuentra normalmente en /etc/idmapd.conf. Consulte idmapd.conf(5) para obtener más información.

EXTENSIÓN DE CONFIGURACIÓN SSS

Habilitar plugin SSS

En la sección “[Translation]”, modifique/establezca el atributo “Method” para que contenga sss.

[sss] sección de configuración

Para cambiar el valor predeterminado de uno de los atributos de configuración del plugin sss que se enumeran a continuación, deberá crear una sección de configuración para él, denominada “[sss]”.

Atributos de configuración

memcache (bool)

Indica si se utiliza o no la técnica de optimización de memcache.

Predeterminado: True

INTEGRACIÓN SSSD

El plugin sss requiere que el NSS Responder esté habilitado en sssd.

El atributo “use_fully_qualified_names” debe estar habilitado en todos los dominios (los clientes NFSv4 esperan que se envíe un nombre totalmente cualificado en la red).

EJEMPLO

El siguiente ejemplo muestra un idmapd.conf mínimo que utiliza el plugin sss.

[General]
Verbosity = 2
# domain must be synced between NFSv4 server and clients
# Solaris/Illumos/AIX use "localdomain" as default!
Domain = default
[Mapping]
Nobody-User = nfsnobody
Nobody-Group = nfsnobody
[Translation]
Method = sss
