SSH-AUTHORIZED-KEYS(1) Comandos de usuario SSH-AUTHORIZED-KEYS(1)

NOMBRE

ssh-authorized-keys

SINOPSIS

ssh-authorized-keys [OPCIÓN] [<archivo> ...]

DESCRIPCIÓN

Recopila información de los archivos authorized_keys de cada usuario que puede encontrar

OPCIONES

-j --json
salida JSON
-J --jsonl
salida JSONLINES
-r --rec
salida RECUTILS
-x --xml
salida XML
-y --yaml
salida YAML
  --version
mostrar información de la versión

ARGUMENTOS

archivo
archivo authorized_keys
