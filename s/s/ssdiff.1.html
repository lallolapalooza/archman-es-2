SSDIFF(1) GNOME SSDIFF(1)

NOMBRE

ssdiff - compara dos hojas de cálculo

SINOPSIS

ssdiff [OPCIONES] ARCHIVO_VIEJO ARCHIVO_NUEVO

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando ssdiff.

ssdiff es una utilidad de línea de comandos para comparar dos hojas de cálculo y listar sus diferencias

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones de una sola letra que comienzan con un guion (`-') y opciones más largas que comienzan con dos guiones (`--').

Opciones de salida

-x, --xml
Muestra las diferencias en formato xml

Opciones de ayuda

-V, --version
Muestra la versión de ssdiff
-?, --help
Muestra las opciones soportadas

EJEMPLO

Para comparar una versión antigua de un archivo con un archivo más nuevo, ejecuta:

ssdiff viejo.gnumeric nuevo.gnumeric

El código de salida será 0 si no se encontraron diferencias, 1 si se encontraron diferencias y 2 en caso de problemas.
