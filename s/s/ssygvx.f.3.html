Documentación de la función/subrutina

subrutina ssygvx (integer itype, character jobz, character range, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

SSYGVX

Propósito

!>
!> SSYGVX calcula los valores propios seleccionados y, opcionalmente, los
!> vectores propios de un problema de valores propios generalizado
!> simétrico real, de la forma A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o
!> B*A*x=(lambda)*x. Aquí A y B se asumen simétricos y B es también
!> definida positiva. Los valores propios y los vectores propios pueden
!> seleccionarse especificando un rango de valores o un rango de índices
!> para los valores propios deseados.
!>

Parámetros

ITYPE 
!>          ITYPE es ENTERO
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular los valores propios y los vectores propios.
!>

RANGE

!>          RANGE es CARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo
!>                 semiabierto (VL,VU].
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>

UPLO

!>          UPLO es CARACTER*1
!>          = 'U':  El triángulo superior de A y B están almacenados;
!>          = 'L':  El triángulo inferior de A y B están almacenados.
!>

N

!>          N es ENTERO
!>          El orden del lápiz de matrices (A,B).  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la
!>          parte superior triangular N por N de A contiene la parte
!>          superior triangular de la matriz A. Si UPLO = 'L', la
!>          parte inferior triangular N por N de A contiene la parte
!>          inferior triangular de la matriz A.
!>
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, se
!>          destruye.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es array REAL, dimensión (LDB, N)
!>          En la entrada, la matriz simétrica B. Si UPLO = 'U', la
!>          parte superior triangular N por N de B contiene la parte
!>          superior triangular de la matriz B. Si UPLO = 'L', la
!>          parte inferior triangular N por N de B contiene la parte
!>          inferior triangular de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz
!>          se sobrescribe con el factor triangular U o L de la
!>          factorización de Cholesky B = U**T*U o B = L*L**T.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es ENTERO
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es ENTERO
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir C a forma tridiagonal, donde C es la matriz simétrica
!>          del problema simétrico estándar al que se transforma el
!>          problema generalizado.
!>
!>          Los valores propios se calcularán con mayor precisión cuando
!>          ABSTOL se establezca en el doble del umbral de subdesbordamiento
!>          2*DLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL a
!>          2*SLAMCH('S').
!>

M

!>          M es ENTERO
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array REAL, dimensión (N)
!>          En la salida normal, los primeros M elementos contienen los
!>          valores propios seleccionados en orden ascendente.
!>

Z

!>          Z es array REAL, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Los vectores propios se normalizan de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**T*B*Z = I;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Nota: el usuario debe asegurarse de que se proporcionan al menos
!>          max(1,M) columnas en el array Z; si RANGE = 'V', el valor exacto
!>          de M no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es ENTERO
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La longitud del array WORK.  LWORK >= max(1,8*N).
!>          Para una eficiencia óptima, LWORK >= (NB+3)*N,
!>          donde NB es el tamaño del bloque para SSYTRD devuelto por ILAENV.
!>
!>          Si LWORK = -1, entonces se realiza una consulta del espacio de trabajo
se asume; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por XERBLA.
!>

IWORK

!>          IWORK es un array de ENTEROS, de dimensión (5*N)
!>

IFAIL

!>          IFAIL es un array de ENTEROS, de dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
!>          índices de los autovectores que no han convergido.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

INFO

!>          INFO es un ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  SPOTRF o SSYEVX devolvieron un código de error:
!>             <= N:  si INFO = i, SSYEVX no ha convergido;
!>                    i autovectores no han convergido. Sus índices
!>                    están almacenados en el array IFAIL.
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el menor
!>                    principal principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon autovalores ni autovectores.
!>
