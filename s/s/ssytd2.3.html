subrutina ssytd2 (uplo, n, a, lda, d, e, tau, info)
SSYTD2 reduce una matriz simétrica a forma tridiagonal simétrica real mediante una transformación de similitud ortogonal (algoritmo sin bloques).

Documentación de función/subrutina

subrutina ssytd2 (carácter uplo, entero n, real, dimensión( lda, * ) a, entero lda, real, dimensión( * ) d, real, dimensión( * ) e, real, dimensión( * ) tau, entero info)

SSYTD2 reduce una matriz simétrica real a forma tridiagonal simétrica mediante una transformación de similitud ortogonal (algoritmo sin bloques).

Propósito:

!>
!> SSYTD2 reduce una matriz simétrica real A a forma tridiagonal simétrica T
!> mediante una transformación de similitud ortogonal: Q**T * A * Q = T.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si se almacena la parte triangular superior o inferior
!>          de la matriz simétrica A:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          triangular superior n-por-n principal de A contiene la parte
!>          triangular superior de la matriz A, y la parte triangular
!>          estrictamente inferior de A no se referencia. Si UPLO = 'L', la
!>          parte triangular inferior n-por-n principal de A contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular
!>          estrictamente superior de A no se referencia.
!>          En la salida, si UPLO = 'U', la diagonal y la primera supradiagonal
!>          de A se sobrescriben con los elementos correspondientes de la
!>          matriz tridiagonal T, y los elementos por encima de la primera
!>          supradiagonal, junto con el array TAU, representan la matriz
!>          ortogonal Q como un producto de reflejos elementales; si UPLO
!>          = 'L', la diagonal y la primera subdiagonal de A se sobrescriben
!>          con los elementos correspondientes de la matriz tridiagonal
!>          T, y los elementos por debajo de la primera subdiagonal, junto
!>          con el array TAU, representan la matriz ortogonal Q como un
!>          producto de reflejos elementales. Ver Detalles adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

D

!>          D es array REAL, dimensión (N)
!>          Los elementos diagonales de la matriz tridiagonal T:
!>          D(i) = A(i,i).
!>

E

!>          E es array REAL, dimensión (N-1)
!>          Los elementos fuera de la diagonal de la matriz tridiagonal T:
!>          E(i) = A(i,i+1) si UPLO = 'U', E(i) = A(i+1,i) si UPLO = 'L'.
!>

TAU

!>          TAU es array REAL, dimensión (N-1)
!>          Los factores escalares de los reflejos elementales (ver Detalles
!>          adicionales).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles adicionales:

!>
!>  Si UPLO = 'U', la matriz Q se representa como un producto de reflejos
!>  elementales
!>
!>     Q = H(n-1) . . . H(2) H(1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real, y v es un vector real con
!>  v(i+1:n) = 0 y v(i) = 1; v(1:i-1) se almacena en la salida en
!>  A(1:i-1,i+1), y tau en TAU(i).
!>
!>  Si UPLO = 'L', la matriz Q se representa como un producto de reflejos
!>  elementales
!>
!>     Q = H(1) H(2) . . . H(n-1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real, y v es un vector real con
!>  v(1:i) = 0 y v(i+1) = 1; v(i+2:n) se almacena en la salida en A(i+2:n,i),
!>  y tau en TAU(i).
!>
!>  El contenido de A en la salida se ilustra con los siguientes ejemplos
!>  con n = 5:
!>
!>  si UPLO = 'U':                       si UPLO = 'L':
!>
!>    (  d   e   v2  v3  v4 )              (  d                  )
!>    (      d   e   v3  v4 )              (  e   d              )
!>    (          d   e   v4 )              (  v1  e   d          )
!>    (              d   e  )              (  v1  v2  e   d      )
!>    (                  d  )              (  v1  v2  v3  e   d  )
!>
!>  donde d y e denotan elementos diagonales y fuera de la diagonal de T, y vi
!>  denota un elemento del vector que define H(i).
!>
