subrutina ssygvx (integer itype, character jobz, character range, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

SSYGVX

Propósito:

!>
!> SSYGVX calcula autovalores seleccionados, y opcionalmente, autovectores
!> de un problema de autovalores generalizado y simétrico definido real,
!> de la forma A*x=(lambda)*B*x, A*Bx=(lambda)*x, o B*A*x=(lambda)*x. Aquí A
!> y B se asumen simétricos y B también es definida positiva.
!> Los autovalores y autovectores pueden ser seleccionados especificando
!> un rango de valores o un rango de índices para los autovalores deseados.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Solo calcular autovalores;
!>          = 'V':  Calcular autovalores y autovectores.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los autovalores.
!>          = 'V': se encontrarán todos los autovalores en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los autovalores desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A y B;
!>          = 'L':  Se almacena el triángulo inferior de A y B.
!>

N

!>          N es INTEGER
!>          El orden del lápiz de matrices (A,B).  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la
!>          parte superior triangular N por N de A contiene la
!>          parte superior triangular de la matriz A. Si UPLO = 'L',
!>          la parte inferior triangular N por N de A contiene
!>          la parte inferior triangular de la matriz A.
!>
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array REAL, de dimensión (LDB, N)
!>          En la entrada, la matriz simétrica B. Si UPLO = 'U', la
!>          parte superior triangular N por N de B contiene la
!>          parte superior triangular de la matriz B. Si UPLO = 'L',
!>          la parte inferior triangular N por N de B contiene
!>          la parte inferior triangular de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz se
!>          sobrescribe con el factor triangular U o L de la factorización de
!>          Cholesky B = U**T*U o B = L*L**T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para autovalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para autovalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          autovalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          autovalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluta para los autovalores.
!>          Un autovalor aproximado se acepta como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual que
!>
!>          ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir C a forma tridiagonal, donde C es la matriz simétrica
!>          del problema simétrico estándar al que se transforma
!>          el problema generalizado.
!>
!>          Los autovalores se calcularán con la mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'),
!>          no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          autovectores no convergieron, intente establecer ABSTOL en
!>          2*SLAMCH('S').
!>

M

!>          M es INTEGER
!>          El número total de autovalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array REAL, de dimensión (N)
!>          En la salida normal, los primeros M elementos contienen los
!>          autovalores seleccionados en orden ascendente.
!>

Z

!>          Z es un array REAL, de dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los autovectores ortonormales de la matriz A
!>          correspondientes a los autovalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el autovector asociado a W(i).
!>          Los autovectores se normalizan así:
!>          si ITYPE = 1 o 2, Z**T*B*Z = I;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>
!>          Si un autovector falla en converger, entonces esa columna de Z
!>          contiene la aproximación más reciente al autovector, y el
!>          índice del autovector se retorna en IFAIL.
!>          Nota: el usuario debe asegurarse de que se suministran al menos
!>          max(1,M) columnas en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) retorna el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.  LWORK >= max(1,8*N).
!>          Para una eficiencia óptima, LWORK >= (NB+3)*N,
!>          donde NB es el tamaño del bloque para SSYTRD retornado por ILAENV.
!>
!>          Si LWORK = -1, entonces se realiza una consulta de espacio de

Function/Subroutine Documentation

SSYGVX

SSYGVX realiza la siguiente computación:

   if ITYPE = 1,     A * x = lambda * B * x
   if ITYPE = 2,     A * B * x = lambda * x
   if ITYPE = 3,     B * A * x = lambda * x

donde A y B son matrices simétricas y reales. A se utiliza para la descomposición de Cholesky de B.

Argumentos

ITYPE

          ITYPE is INTEGER
          Specifies the equation to be solved:
          = 1:  A*x = lambda*B*x
          = 2:  A*B*x = lambda*x
          = 3:  B*A*x = lambda*x

JOBZ

          JOBZ is CHARACTER*1
          = 'N':  Compute only the eigenvalues and eigenvectors of the
                  Schur.
          = 'V':  Compute the eigenvalues and eigenvectors of the Schur.

RANGE

          RANGE is CHARACTER*1
          = 'A':  all eigenvalues will be found.
          = 'V':  all eigenvalues between VL and VU will be found.
          = 'I':  the IL-th to IU-th eigenvalues will be found.

UPLO

          UPLO is CHARACTER*1
          = 'U':  Upper triangle of A and B are used.
          = 'L':  Lower triangle of A and B are used.

N

          N is INTEGER
          The order of the matrices A and B.  N >= 0.

A

          A is REAL array, dimension (LDA, N)
          On entry, the symmetric matrix A.
          On exit, the contents of A are destroyed.

LDA

          LDA is INTEGER
          The leading dimension of the array A. LDA >= max(1, N).

B

          B is REAL array, dimension (LDB, N)
          On entry, the symmetric matrix B.
          On exit, if INFO = 0 and ITYPE = 1, the factorization
          B = U*T*U**T is available.
          On exit, if INFO = 0 and ITYPE = 2 or 3, the factorization
          B = U*U**T is available.
          The lower triangle of B is not referenced when UPLO = 'U',
          and the upper triangle of B is not referenced when UPLO = 'L'.

LDB

          LDB is INTEGER
          The leading dimension of the array B. LDB >= max(1, N).

VL

          VL is REAL
          If RANGE='V', the lower bound of the interval for the desired
          eigenvalues.

VU

          VU is REAL
          If RANGE='V', the upper bound of the interval for the desired
          eigenvalues.

IL

          IL is INTEGER
          If RANGE='I', the index of the smallest eigenvalue to be
          returned.

IU

          IU is INTEGER
          If RANGE='I', the index of the largest eigenvalue to be
          returned.

ABSTOL

          ABSTOL is REAL
          The absolute tolerance for the eigenvalues.  An eigenvalue lambda is
          considered to be within the interval [VL, VU] if
          max(VL, lambda) <= min(VU, lambda)
          An eigenvalue lambda is considered to be the IL-th to the IU-th
          eigenvalue if abs(lambda-lambda_i) <= ABSTOL, where lambda_i are
          the sorted eigenvalues.

M

          M is INTEGER
          The total number of eigenvalues found.
          If RANGE='A', M = N.
          If RANGE='V', M = number of eigenvalues between VL and VU.
          If RANGE='I', M = IU - IL + 1.

W

          W is REAL array, dimension (N)
          On exit, the computed eigenvalues, sorted in increasing order.
          Only the first M elements are necessarily set.

Z

          Z is REAL array, dimension (LDZ, N)
          On exit, the computed eigenvectors, with the k-th column
          representing the eigenvector of the k-th eigenvalue in the array W.
          The eigenvectors are normalized.
          Only the first M columns are necessarily set.
          The column Z(*, k) is the eigenvector corresponding to the eigenvalue
          W(k).

LDZ

          LDZ is INTEGER
          The leading dimension of the array Z. LDZ >= max(1, N).

WORK

          WORK is REAL array, dimension (LWORK)
          On exit, WORK(1) contains the optimal LWORK.

LWORK

          LWORK is INTEGER
          The dimension of the array WORK. LWORK >= max(1, 2*N).
          For optimal efficiency, dimension is max(1, 2*N, 2*NB), where
          NB is the block size for QR factorization.
          If LWORK = -1, then the optimal dimension is calculated and
          stored in WORK(1), and no computation is performed.
          This is assumed; the routine
          only calculates the optimal size of the WORK array, returns
          this value as the first entry of the WORK array, and no error
          message related to LWORK is issued by XERBLA.

IWORK

          IWORK is INTEGER array, dimension (5*N)

IFAIL

          IFAIL is INTEGER array, dimension (N)
          If JOBZ = 'V', then if INFO = 0, the first M elements of
          IFAIL are zero.  If INFO > 0, then IFAIL contains the
          indices of the eigenvectors that failed to converge.
          If JOBZ = 'N', then IFAIL is not referenced.

INFO

          INFO is INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  SPOTRF or SSYEVX returned an error code:
             <= N:  if INFO = i, SSYEVX failed to converge;
                    i eigenvectors failed to converge.  Their indices
                    are stored in array IFAIL.
             > N:   if INFO = N + i, for 1 <= i <= N, then the leading
                    principal minor of order i of B is not positive.
                    The factorization of B could not be completed and
                    no eigenvalues or eigenvectors were computed.
