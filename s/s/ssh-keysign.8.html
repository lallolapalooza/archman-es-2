SSH-KEYSIGN(8) Manual del Administrador del Sistema SSH-KEYSIGN(8)

NOMBRE

ssh-keysign — Ayudante de OpenSSH para la autenticación basada en host

SINOPSIS

ssh-keysign

DESCRIPCIÓN

ssh-keysign es utilizado por ssh(1) para acceder a las claves del host local y generar la firma digital requerida durante la autenticación basada en host.

ssh-keysign está deshabilitado por defecto y solo puede habilitarse en el archivo de configuración global del cliente /etc/ssh/ssh_config estableciendo EnableSSHKeysign a “yes”.

ssh-keysign no está diseñado para ser invocado por el usuario, sino desde ssh(1). Consulte ssh(1) y sshd(8) para obtener más información sobre la autenticación basada en host.

ARCHIVOS

/etc/ssh/ssh_config
Controla si ssh-keysign está habilitado.
/etc/ssh/ssh_host_ecdsa_key
 
/etc/ssh/ssh_host_ed25519_key
 
/etc/ssh/ssh_host_rsa_key
Estos archivos contienen las partes privadas de las claves del host utilizadas para generar la firma digital. Deben ser propiedad de root, legibles solo por root y no accesibles por otros. Dado que solo son legibles por root, ssh-keysign debe ser set-uid root si se utiliza la autenticación basada en host.
/etc/ssh/ssh_host_ecdsa_key-cert.pub
 
/etc/ssh/ssh_host_ed25519_key-cert.pub
 
/etc/ssh/ssh_host_rsa_key-cert.pub
Si existen estos archivos, se asume que contienen información de certificado público correspondiente a las claves privadas anteriores.

VER TAMBIÉN

ssh(1), ssh-keygen(1), ssh_config(5), sshd(8)

HISTORIA

ssh-keysign apareció por primera vez en OpenBSD 3.2.
