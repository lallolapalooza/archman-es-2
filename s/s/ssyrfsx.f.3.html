SSYRFSX

Propósito:

!>
!>    SSYRFSX mejora la solución computada de un sistema de ecuaciones
!>    lineales cuando la matriz de coeficientes es simétrica indefinida, y
!>    proporciona cotas de error y estimaciones de error hacia atrás para la
!>    solución. Además de la cota de error normwise, el código proporciona
!>    la cota de error componente a componente máxima si es posible. Ver comentarios para
!>    ERR_BNDS_NORM y ERR_BNDS_COMP para detalles de las cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta rutina, como se describe en los
!>    argumentos EQUED y S a continuación. En este caso, la solución y las
!>    cotas de error devueltas son para el sistema original no equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en la matriz PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados son
!>     aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que el código
!>     fuente acceda al argumento PARAMS.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó a A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y las cotas de error correctamente.
!>       = 'N':  No se realizó equilibrado
!>       = 'Y':  Equilibrado de filas y columnas, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>               El lado derecho B ha sido modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es una matriz REAL, dimensión (LDA,N)
!>     La matriz simétrica A.  Si UPLO = 'U', la parte superior
!>     triangular N por N de A contiene la parte triangular superior
!>     de la matriz A, y la parte estrictamente inferior triangular
!>     de A no se referencia. Si UPLO = 'L', la parte inferior
!>     triangular N por N de A contiene la parte triangular inferior
!>     de la matriz A, y la parte estrictamente superior triangular
!>     de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es una matriz REAL, dimensión (LDAF,N)
!>     La forma factorizada de la matriz A.  AF contiene la matriz
!>     diagonal por bloques D y los multiplicadores utilizados para
!>     obtener U o L de la factorización A = U*D*U**T o A =
!>     L*D*L**T calculada por SSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     según lo determinado por SSYTRF.
!>

S

!>          S es un array REAL, dimensión (N)
!>     Los factores de escala para A. Si EQUED = 'Y', A se multiplica por
!>     la izquierda y la derecha por diag(S). S es un argumento de entrada si FACT =
!>     'F'; de lo contrario, S es un argumento de salida. Si FACT = 'F' y EQUED
!>     = 'Y', cada elemento de S debe ser positivo. Si S es una salida, cada
!>     elemento de S es una potencia de la base. Si S es una entrada, cada
!>     elemento de S debe ser una potencia de la base para garantizar una solución
!>     confiable y estimaciones de error. El escalado por potencias de la base no
!>     causa errores de redondeo a menos que el resultado subdesborde o desborde.
!>     Los errores de redondeo durante el escalado dan lugar a un refinamiento con una matriz que
!>     no es equivalente a la matriz de entrada, produciendo estimaciones de error
!>     que pueden no ser confiables.
!>

B

!>          B es una matriz REAL, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es una matriz REAL, dimensión (LDX,NRHS)
!>     En la entrada, la matriz solución X, como fue calculada por SGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Condición recíproca escalada. Esta es una estimación de la
!>     condición recíproca de Skeel de la matriz A después del
!>     equilibrado (si se realizó). Si esto es menor que la precisión de la
!>     máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error puede seguir siendo pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.
!>

BERR

!>          BERR es un array REAL, dimensión (NRHS)
!>     Error relativo componente a componente hacia atrás. Este es el
!>     error relativo componente a componente de cada vector solución X(j)
!>     (es decir, el menor cambio relativo en cualquier elemento de A o B que
!>     haga que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de cotas de error a devolver para cada lado derecho
!>     y cada tipo (normwise o componente a componente). Ver ERR_BNDS_NORM y
!>     ERR_BNDS_COMP a continuación.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     La matriz se indexa por el tipo de información de error según se describe
!>     a continuación. Actualmente hay hasta tres campos de información
!>     devueltos.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta

NAME

ssyrfsx

real routines for solving a real symmetric system of linear equations A*X = B with condition estimation and refinement

SYNOPSIS

 SUBROUTINE SSYRFSX(
                UPLO, N, NRHS, A, LDA, AF, LDAF, IPIV, EQUED,
                RHSISZERO, SR, LIBSREX, ERR_BNDS_NORM,
                ERR_BNDS_COMP, NPARAMS, PARAMS, WORK, IWORK, INFO)
 CHARACTER(LEN=1) UPLO
 INTEGER N, NRHS, LDA, LDAF, INFO, NPARAMS
 INTEGER IPIV( * ), LIBSREX( * )
 REAL A( LDA, * ), AF( LDAF, * ), SR( * )
 REAL ERR_BNDS_NORM( NRHS, * ), ERR_BNDS_COMP( NRHS, * )
 REAL PARAMS( * ), WORK( * )
 INTEGER IWORK( * )
 CHARACTER EQUED, RHSISZERO

Function/Subroutine Documentation

UPLO

 !>          UPLO is CHARACTER*1
 !>     On entry, UPLO specifies whether the upper or lower triangular
 !>     part of the array A is to be referred to as follows:
 !>
 !>        UPLO = 'U' => Upper triangular part
 !>        UPLO = 'L' => Lower triangular part
 !>
 !>     On exit, EQUED is changed to UPLO.

N

 !>          N is INTEGER
 !>     The number of linear equations, i.e., the order of the matrix A.
 !>     N >= 0.

NRHS

 !>          NRHS is INTEGER
 !>     The number of right-hand sides, i.e., the number of columns of the
 !>     matrices A, B, X, AFE, and SR. NRHS >= 0.

A

 !>          A is REAL array, dimension (LDA, N)
 !>     On entry, the original N x N symmetric matrix A.
 !>     On exit, the N x N symmetric matrix A, unless EQUED is not 'N'.
 !>     See further details under EQUED.

LDA

 !>          LDA is INTEGER
 !>     The leading dimension of the array A. LDA >= max(1, N).

AF

 !>          AF is REAL array, dimension (LDAF, N)
 !>     On entry, the factored form of the matrix A, as returned by
 !>     SSYTRF.
 !>     On exit, AF is overwritten by the corresponding results of
 !>     iterative refinement.

LDAF

 !>          LDAF is INTEGER
 !>     The leading dimension of the array AF. LDAF >= max(1, N).

IPIV

 !>          IPIV is INTEGER array, dimension (min(N + 6, N))
 !>     On entry, details of the factorization of A. See SSYTRF for
 !>     further details.
 !>     On exit, IPIV is overwritten by the corresponding results of
 !>     iterative refinement.

EQUED

 !>          EQUED is CHARACTER*1
 !>     On exit:
 !>     = 'N': No equilibration was performed, nor is EQUED accessed.
 !>     = 'S': Symmetric equilibration was performed, and equilibration
 !>            constants were not stored.
 !>     = 'L': Lower triangular (or triangular) equilibration was
 !>            performed and the diagonal elements of the scale factors
 !>            are not stored.
 !>     = 'B': Both upper and lower triangular (or triangular)
 !>            equilibration was performed and then reversed and restored.
 !>            A.
 !>     = 'U': Upper triangular equilibration was performed and then
 !>            reversed and restored. A.

RHSISZERO

 !>          RHSISZERO is CHARACTER*1
 !>     On entry, RHSISZERO specifies whether B is the zero vector.
 !>     = 'T': B is the zero vector. In this case, X is returned as the
 !>            zero vector, and no refinement is performed.
 !>     = 'F': B is not the zero vector.

SR

 !>          SR is REAL array, dimension (NRHS)
 !>     On exit, if RHSISZERO = 'F', SR contains the componentwise
 !>     relative error in the corresponding solution vector X.
 !>     On exit, if RHSISZERO = 'T', SR contains the normwise
 !>     reciprocal condition number in the corresponding solution vector X.

LIBSREX

 !>          LIBSREX is INTEGER array, dimension (NRHS)
 !>     On exit, LIBSREX(i) contains the iteration count for the
 !>     corresponding RHS vector i.

ERR_BNDS_NORM

!>          ERR_BNDS_NORM is REAL array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     normwise relative error, which is defined as follows:
!>
!>     Normwise relative error in the ith solution vector:
!>                   norm(XTRUE - X, inf)
!>             --------------------------
!>                       norm(X, inf)
!>
!>     The array is indexed by the right-hand side i (on which the
!>     normwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_NORM is not accessed. If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_NORM(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated normwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*A, where S scales each row by a power of the
!>              radix so all absolute row sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP is REAL array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the ith solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*(A*diag(x)), where x is the solution for the
!>              current right-hand side and S scales each row of
!>              A*diag(x) by a power of the radix so all absolute row
!>              sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

NPARAMS

!>          NPARAMS is INTEGER
!>     Specifies the number of parameters set in PARAMS.  If <= 0, the
!>     PARAMS array is never referenced and default values are used.
!>

PARAMS

!>          PARAMS is REAL array, dimension NPARAMS
!>     Specifies algorithm parameters.  If an entry is < 0.0, then
!>     that entry will be filled with default value used for that
!>     parameter.  Only positions up to NPARAMS are accessed; defaults
!>     are used for higher-numbered parameters.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
!>            refinement or not.
!>         Default: 1.0
!>            = 0.0:  No refinement is performed, and no error bounds are
!>                    computed.
!>            = 1.0:  Use the double-precision refinement algorithm,
!>                    possibly with doubled-single computations if the
!>                    compilation environment does not support DOUBLE
!>                    PRECISION.
!>              (other values are reserved for future use)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
!>            computations allowed for refinement.
!>         Default: 10
!>         Aggressive: Set to 100 to permit convergence using approximate
!>                     factorizations or factorizations other than LU. If
!>                     the factorization uses a technique other than
!>                     Gaussian elimination, the guarantees in
!>                     err_bnds_norm and err_bnds_comp may no longer be
!>                     trustworthy.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
!>            will attempt to find a solution with small componentwise
!>            relative error in the double-precision algorithm.  Positive
!>            is true, 0.0 is false.
!>         Default: 1.0 (attempt componentwise convergence)
!>

WORK

!>          WORK is REAL array, dimension (4*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>       = 0:  Successful exit. The solution to every right-hand side is
!>         guaranteed.
!>       < 0:  If INFO = -i, the i-th argument had an illegal value
!>       > 0 and <= N:  U(INFO,INFO) is exactly zero.  The factorization
!>         has been completed, but the factor U is exactly singular, so
!>         the solution and error bounds could not be computed. RCOND = 0
!>         is returned.
!>       = N+J: The solution corresponding to the Jth right-hand side is
!>         not guaranteed. The solutions corresponding to other right-
!>         hand sides K with K > J may not be guaranteed as well, but
!>         only the first such right-hand side is reported. If a small
!>         componentwise error is not requested (PARAMS(3) = 0.0) then
!>         the Jth right-hand side is the first with a normwise error
!>         bound that is not guaranteed (the smallest J such
!>         that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
!>         the Jth right-hand side is the first with either a normwise or
!>         componentwise error bound that is not guaranteed (the smallest
!>         J such that either ERR_BNDS_NORM(J,1) = 0.0 or
!>         ERR_BNDS_COMP(J,1) = 0.0). See the definition of
!>         ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
!>         about all of the right-hand sides check ERR_BNDS_NORM or
!>         ERR_BNDS_COMP.
!>
