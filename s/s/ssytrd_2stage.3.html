Documentación de Función/Subrutina

subroutine ssytrd_2stage (character vect, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) tau, real, dimension( * ) hous2, integer lhous2, real, dimension( * ) work, integer lwork, integer info)

SSYTRD_2STAGE

Propósito:

!>
!> SSYTRD_2STAGE reduce una matriz real simétrica A a forma tridiagonal real simétrica
!> T mediante una transformación de similitud ortogonal:
!> Q1**T Q2**T* A * Q2 * Q1 = T.
!>

Parámetros

VECT 
!>          VECT es CHARACTER*1
!>          = 'N':  No se necesita la representación de Householder,
!>                  en particular para la segunda etapa (Banda a
!>                  tridiagonal) y por lo tanto LHOUS2 es de tamaño max(1, 4*N);
!>          = 'V':  se necesita la representación de Householder para
!>                  generar Q1 Q2 o aplicar Q1 Q2,
!>                  entonces LHOUS2 debe consultarse y calcularse.
!>                  (NO DISPONIBLE EN ESTA VERSIÓN).
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, dimension (LDA,N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la parte
!>          superior triangular N por N de A contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente inferior triangular de A no se referencia.
!>          Si UPLO = 'L', la parte inferior triangular N por N de A contiene la parte triangular inferior
!>          de la matriz A, y la parte estrictamente superior triangular de A no se referencia.
!>          En la salida, si UPLO = 'U', la superdiagonal de banda
!>          de A se sobrescribe con los elementos correspondientes de la
!>          matriz de banda interna AB, y los elementos por encima de
!>          la KD superdiagonal, con el array TAU, representan la matriz ortogonal
!>          Q1 como un producto de reflectores elementales; si UPLO
!>          = 'L', la diagonal y la subdiagonal de banda de A se sobrescriben
!>          con los elementos correspondientes de la matriz de banda interna
!>          AB, y los elementos por debajo de la subdiagonal KD, con
!>          el array TAU, representan la matriz ortogonal
!>          Q1 como un producto de reflectores elementales. Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

D

!>          D es un array REAL, dimension (N)
!>          Los elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es un array REAL, dimension (N-1)
!>          Los elementos fuera de la diagonal de la matriz tridiagonal T.
!>

TAU

!>          TAU es un array REAL, dimension (N-KD)
!>          Los factores escalares de los reflectores elementales de
!>          la primera etapa (ver Detalles Adicionales).
!>

HOUS2

!>          HOUS2 es un array REAL, dimension (MAX(1,LHOUS2))
!>          Almacena la representación de Householder de la segunda etapa
!>          banda a tridiagonal.
!>

LHOUS2

!>          LHOUS2 es INTEGER
!>          La dimensión del array HOUS2.
!>          LHOUS2 >= 1.
!>
!>          Si LWORK = -1, o LHOUS2 = -1,
!>          entonces se asume una consulta; la rutina
!>          solo calcula el tamaño óptimo del array HOUS2, devuelve
!>          este valor como la primera entrada del array HOUS2, y no se emite ningún mensaje de error
!>          relacionado con LHOUS2 por XERBLA.
!>          Si VECT='N', LHOUS2 = max(1, 4*n);
!>          si VECT='V', opción aún no disponible.
!>

WORK

!>          WORK es un array REAL, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N = 0, LWORK >= 1, de lo contrario LWORK = MAX(1, dimension).
!>
!>          Si LWORK = -1, o LHOUS2 = -1,
!>          entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK por XERBLA.
!>          LWORK = MAX(1, dimension) donde
!>          dimension   = max(stage1,stage2) + (KD+1)*N
!>                      = N*KD + N*max(KD+1,FACTOPTNB)
!>                        + max(2*KD*KD, KD*NTHREADS)
!>                        + (KD+1)*N
!>          donde KD es el tamaño del bloque de la reducción,
!>          FACTOPTNB es el tamaño del bloque utilizado por el algoritmo QR o LQ
!>          generalmente FACTOPTNB=128 es una buena opción
!>          NTHREADS es el número de hilos utilizados cuando
!>          la compilación openMP está habilitada, de lo contrario =1.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
