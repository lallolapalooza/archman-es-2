NOMBRE

sssd_krb5_locator_plugin - Plugin localizador Kerberos

DESCRIPCIÓN

El plugin localizador Kerberos sssd_krb5_locator_plugin es utilizado por libkrb5 para encontrar KDCs para un reino Kerberos dado. SSSD proporciona dicho plugin para guiar a todos los clientes Kerberos del sistema hacia un único KDC. En general, no debería importar con qué KDC se comunica un proceso cliente. Pero hay casos, por ejemplo, después de un cambio de contraseña, donde no todos los KDCs están en el mismo estado porque los nuevos datos tienen que ser replicados primero. Para evitar fallos de autenticación inesperados y quizás incluso bloqueos de cuenta, sería bueno comunicarse con un único KDC durante el mayor tiempo posible.

libkrb5 buscará el plugin localizador en el subdirectorio libkrb5 del directorio de plugins de Kerberos; consulta plugin_base_dir en krb5.conf(5) para más detalles. El plugin solo se puede deshabilitar eliminando el archivo del plugin. No hay ninguna opción en la configuración de Kerberos para deshabilitarlo. Pero la variable de entorno SSSD_KRB5_LOCATOR_DISABLE se puede usar para deshabilitar el plugin para comandos individuales. Alternativamente, la opción SSSD krb5_use_kdcinfo=False se puede usar para no generar los datos necesarios para el plugin. Con esto, el plugin todavía se llama pero no proporcionará datos al llamador, de modo que libkrb5 pueda recurrir a otros métodos definidos en krb5.conf.

El plugin lee la información sobre los KDCs de un reino dado de un archivo llamado kdcinfo.REALM. El archivo debe contener uno o más nombres DNS o direcciones IP, ya sea en notación decimal punto IPv4 o en notación hexadecimal IPv6. Se puede añadir un número de puerto opcional al final, separado por dos puntos; la dirección IPv6 debe encerrarse entre corchetes en este caso, como de costumbre. Las entradas válidas son:

•kdc.example.com
•kdc.example.com:321
•1.2.3.4
•5.6.7.8:99
•2001:db8:85a3::8a2e:370:7334
•[2001:db8:85a3::8a2e:370:7334]:321

El proveedor de autenticación krb5 de SSSD, que también es utilizado por los proveedores IPA y AD, añade la dirección del KDC o controlador de dominio actual que SSSD está utilizando a este archivo.

En entornos con KDCs de solo lectura y de lectura/escritura donde se espera que los clientes utilicen las instancias de solo lectura para las operaciones generales y solo el KDC de lectura/escritura para cambios de configuración como cambios de contraseña, también se utiliza un kpasswdinfo.REALM para identificar KDCs de lectura/escritura. Si este archivo existe para el reino dado, el contenido será utilizado por el plugin para responder a las solicitudes de un servidor kpasswd o kadmin o para el KDC maestro específico de MIT Kerberos. Si la dirección contiene un número de puerto, se utilizará el puerto KDC predeterminado 88 para este último.

NOTAS

No todas las implementaciones de Kerberos admiten el uso de plugins. Si sssd_krb5_locator_plugin no está disponible en tu sistema, deberás editar /etc/krb5.conf para reflejar tu configuración de Kerberos.

Si la variable de entorno SSSD_KRB5_LOCATOR_DEBUG se establece en cualquier valor, se enviarán mensajes de depuración a stderr.

Si la variable de entorno SSSD_KRB5_LOCATOR_DISABLE se establece en cualquier valor, el plugin se deshabilita y simplemente devolverá KRB5_PLUGIN_NO_HANDLE al llamador.

Si la variable de entorno SSSD_KRB5_LOCATOR_IGNORE_DNS_FAILURES se establece en cualquier valor, el plugin intentará resolver todos los nombres DNS en el archivo kdcinfo. Por defecto, el plugin devuelve KRB5_PLUGIN_NO_HANDLE al llamador inmediatamente al primer fallo de resolución DNS.
