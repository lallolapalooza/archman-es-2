SSYTRF_ROOK

Documentación de la función/subrutina

subrutina ssytrf_rook (character uplo, integer n, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, real, dimension( * ) work, integer lwork, integer info)

SSYTRF_ROOK

Propósito:

!>
!> SSYTRF_ROOK calcula la factorización de una matriz simétrica real A
!> usando el método de pivoteo diagonal acotado de Bunch-Kaufman ().
!> La forma de la factorización es
!>
!>    A = U*D*U**T  o  A = L*D*L**T
!>
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> unitarias superiores (inferiores), y D es simétrica y de bloques diagonales
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión en bloques del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A se almacena;
!>          = 'L':  El triángulo inferior de A se almacena.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular de N por N de A contiene la parte triangular
!>          superior de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia.  Si UPLO = 'L', la parte
!>          inferior triangular de N por N de A contiene la parte triangular
!>          inferior de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>
!>          En la salida, la matriz diagonal de bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L (ver más abajo para más
!>          detalles).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D.
!>
!>          Si UPLO = 'U':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               se intercambiaron y D(k,k) es un bloque diagonal de 1x1.
!>
!>               Si IPIV(k) < 0 y IPIV(k-1) < 0, entonces las filas y
!>               columnas k e IPIV(k) se intercambiaron y las filas y
!>               columnas k-1 e IPIV(k-1) se intercambiaron,
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               se intercambiaron y D(k,k) es un bloque diagonal de 1x1.
!>
!>               Si IPIV(k) < 0 y IPIV(k+1) < 0, entonces las filas y
!>               columnas k e IPIV(k) se intercambiaron y las filas y
!>               columnas k+1 e IPIV(k+1) se intercambiaron,
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK)).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1.  Para un rendimiento óptimo
!>          LWORK >= N*NB, donde NB es el tamaño del bloque devuelto por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, D(i,i) es exactamente cero. La factorización
!>                se ha completado, pero la matriz diagonal de bloques D es
!>                exactamente singular, y ocurrirá una división por cero si
!>                se utiliza para resolver un sistema de ecuaciones.
!>

Detalles adicionales:

!>
!>  Si UPLO = 'U', entonces A = U*D*U**T, donde
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  es decir, U es un producto de términos P(k)*U(k), donde k disminuye de n a
!>  1 en pasos de 1 o 2, y D es una matriz diagonal de bloques con bloques
!>  diagonales de 1x1 y 2x2 D(k). P(k) es una matriz de permutación como
!>  se define por IPIV(k), y U(k) es una matriz triangular unitaria superior, tal
!>  que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(1:k-1,k).
!>  Si s = 2, el triángulo superior de D(k) sobrescribe A(k-1,k-1), A(k-1,k),
!>  y A(k,k), y v sobrescribe A(1:k-2,k-1:k).
!>
!>  Si UPLO = 'L', entonces A = L*D*L**T, donde
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  es decir, L es un producto de términos P(k)*L(k), donde k aumenta de 1 a
!>  n en pasos de 1 o 2, y D es una matriz diagonal de bloques con bloques
!>  diagonales de 1x1 y 2x2 D(k). P(k) es una matriz de permutación como
!>  se define por IPIV(k), y L(k) es una matriz triangular unitaria inferior, tal
!>  que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(k+1:n,k).
!>  Si s = 2, el triángulo inferior de D(k) sobrescribe A(k,k), A(k+1,k),
!>  y A(k+1,k+1), y v sobrescribe A(k+2:n,k:k+1).
!>
