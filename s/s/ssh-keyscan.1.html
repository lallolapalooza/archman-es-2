SSH-KEYSCAN(1) Manual de Comandos Generales SSH-KEYSCAN(1)

NOMBRE

ssh-keyscan — recopila claves públicas SSH de servidores

SINOPSIS

ssh-keyscan [-46cDHqv] [-f archivo] [-O opción] [-p puerto] [-T tiempo de espera] [-t tipo] [host | lista de direcciones y nombres]

DESCRIPCIÓN

ssh-keyscan es una utilidad para recopilar las claves de host SSH públicas de un número de hosts. Fue diseñado para ayudar en la construcción y verificación de archivos ssh_known_hosts, cuyo formato se documenta en sshd(8). ssh-keyscan proporciona una interfaz mínima adecuada para su uso por scripts de shell y perl.

ssh-keyscan utiliza E/S de socket no bloqueante para contactar tantos hosts como sea posible en paralelo, por lo que es muy eficiente. Las claves de un dominio de 1.000 hosts se pueden recopilar en decenas de segundos, incluso cuando algunos de esos hosts están caídos o no ejecutan sshd(8). Para el escaneo, no se necesita acceso de inicio de sesión a las máquinas que se están escaneando, ni el proceso de escaneo implica ningún cifrado.

Los hosts a escanear pueden especificarse por nombre de host, dirección o por rango de red CIDR (por ejemplo, 192.168.16/28). Si se especifica un rango de red, se escanearán todas las direcciones de ese rango.

Las opciones son las siguientes:

-4
Forzar a ssh-keyscan a usar solo direcciones IPv4.
-6
Forzar a ssh-keyscan a usar solo direcciones IPv6.
-c
Solicitar certificados a los hosts de destino en lugar de claves normales.
-D
Imprimir las claves encontradas como registros DNS SSHFP. Por defecto, se imprimen las claves en un formato utilizable como un archivo ssh(1) known_hosts.
-f archivo
Leer hosts o pares de “lista de direcciones lista de nombres” desde el archivo, uno por línea. Si se suministra ‘-’ en lugar de un nombre de archivo, ssh-keyscan leerá de la entrada estándar. Los nombres leídos de un archivo deben comenzar con una dirección, nombre de host o rango de red CIDR a escanear. Las direcciones y los nombres de host pueden ir seguidos opcionalmente por alias de nombres o direcciones separados por comas que se copiarán a la salida. Por ejemplo: 
192.168.11.0/24
10.20.1.1
happy.example.org
10.0.0.1,sad.example.org
-H
Hashear todos los nombres de host y direcciones en la salida. Los nombres hasheados pueden ser utilizados normalmente por ssh(1) y sshd(8), pero no revelan información de identificación en caso de que el contenido del archivo se divulgue.
-O opción
Especificar una opción clave/valor. Actualmente, solo se admite una opción:
hashalg=algoritmo
Selecciona un algoritmo de hash a utilizar al imprimir registros SSHFP usando la bandera -D. Los algoritmos válidos son “sha1” y “sha256”. Por defecto, se imprimen ambos.
-p puerto
Conectarse al puerto en el host remoto.
-q
Modo silencioso: no imprimir el nombre del servidor y los banners en los comentarios.
-T tiempo de espera
Establecer el tiempo de espera para los intentos de conexión. Si han transcurrido tiempo de espera segundos desde que se inició una conexión a un host o desde la última vez que se leyó algo de ese host, la conexión se cierra y el host en cuestión se considera no disponible. El valor predeterminado es 5 segundos.
-t tipo
Especificar el tipo de clave a obtener de los hosts escaneados. Los valores posibles son “ecdsa”, “ed25519”, “ecdsa-sk”, “ed25519-sk” o “rsa”. Se pueden especificar varios valores separándolos con comas. Por defecto, se obtienen todos los tipos de clave anteriores.
-v
Modo detallado: imprimir mensajes de depuración sobre el progreso.

Si se construye un archivo ssh_known_hosts utilizando ssh-keyscan sin verificar las claves, los usuarios serán vulnerables a ataques de hombre en el medio. Por otro lado, si el modelo de seguridad permite dicho riesgo, ssh-keyscan puede ayudar a detectar archivos de clave manipulados o ataques de hombre en el medio que hayan comenzado después de que se creara el archivo ssh_known_hosts.

ARCHIVOS

/etc/ssh/ssh_known_hosts

EJEMPLOS

Imprimir la clave de host RSA de la máquina hostname:

$ ssh-keyscan -t rsa hostname

Buscar en un rango de red, imprimiendo todos los tipos de clave soportados:

$ ssh-keyscan 192.168.0.64/25

Encontrar todos los hosts del archivo ssh_hosts que tengan claves nuevas o diferentes de las del archivo ordenado ssh_known_hosts:

$ ssh-keyscan -t rsa,ecdsa,ed25519 -f ssh_hosts | \
	sort -u - ssh_known_hosts | diff ssh_known_hosts -
