subrutina ssytri_rook (character uplo, integer n, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, real, dimension( * ) work, integer info)

SSYTRI_ROOK

Propósito:

!>
!> SSYTRI_ROOK calcula la inversa de una matriz real simétrica
!> A utilizando la factorización A = U*D*U**T o A = L*D*L**T
!> calculada por SSYTRF_ROOK.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, forma es A = U*D*U**T;
!>          = 'L':  Triangular inferior, forma es A = L*D*L**T.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L calculados por SSYTRF_ROOK.
!>
!>          En la salida, si INFO = 0, la inversa (simétrica) de la matriz
!>          original. Si UPLO = 'U', la parte triangular superior de la
!>          inversa se forma y la parte de A debajo de la diagonal no
!>          se referencia; si UPLO = 'L', la parte triangular inferior de la
!>          inversa se forma y la parte de A encima de la diagonal no
!>          se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como lo determinó SSYTRF_ROOK.
!>

WORK

!>          WORK es array REAL, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) = 0; la matriz es singular y su
!>               inversa no pudo ser calculada.
!>
