SSH-LAST(1) Comandos de usuario SSH-LAST(1)

NOMBRE

ssh-last - listar últimas sesiones SSH

SINOPSIS

           ssh-last [OPCIONES]
ssh_logs | ssh-last [OPCIONES]

Opciones

-a  mostrar todas las sesiones                           (mostrar datos que están ocultos por el archivo 'ignored')
-c  salida coloreada                              (resaltar sesiones SSH activas)
-d  debug
-f  forzar la visualización de huellas digitales                  (sin mapeo del archivo 'known')
-h  mostrar este mensaje de ayuda
-i  forzar la visualización de IDs de certificado               (sin mapeo del archivo 'known', no junto con -f)
-l  intentar usar archivos de registro en lugar de journalctl   (puede ser incluso más rápido en algunos sistemas)
-n  mostrar host/ip en texto plano                   (sin mapeo del archivo 'known')
-w  mostrar solo sesiones SSH activas
-?  mostrar manual completo con información más detallada
    (normalmente requiere tener instalado perl-doc para funcionar correctamente)
--version    mostrar información de la versión

Ejemplos

ssh-last
ssh-last -c | more
ssh-last -c | less -R   # mantiene la salida coloreada en less
ssh-last -cw
# Registros de ayer
LC_TIME=C journalctl _COMM=sshd -g 'Accepted|Disconnected' --since yesterday               | ssh-last
# Registros de hace tres días
LC_TIME=C journalctl _COMM=sshd -g 'Accepted|Disconnected' --since -3d --until -2d         | ssh-last
# Registros de la última hora
LC_TIME=C journalctl _COMM=sshd -g 'Accepted|Disconnected' --since -1h                     | ssh-last
# Registros hasta una fecha específica
LC_TIME=C journalctl _COMM=sshd -g 'Accepted|Disconnected' --until "2022-03-12 07:00:00"   | ssh-last
# Desde archivos de registro (el orden debe ser de más antiguo a más reciente)
zgrep -hE 'Accepted|Disconnected' auth.log.2.gz  auth.log.1  auth.log                      | ssh-last
zgrep -hE 'Accepted|Disconnected' $(ls /var/log/auth.log* --sort=time --reverse)           | ssh-last
zgrep -hE 'Accepted|Disconnected' $(ls /var/log/messages* --sort=time --reverse)           | ssh-last
zgrep -hE 'Accepted|Disconnected' $(ls /var/log/secure*   --sort=time --reverse)           | ssh-last

DESCRIPCIÓN

ssh-last es como last pero para sesiones SSH

Banderas de salida

+--------------------------------------------------------------------------+
|                                                                          |
| AUTH_ID                                                                  |
|                                                                          |
| (C) inicio de sesión autorizado de sshd a través de (c)ertificado                              |
| (K) inicio de sesión autorizado de sshd a través de (k)ey público                                |
| (?) inicio de sesión autorizado de sshd a través de algún otro tipo (contraseña, pam)            |
|                                                                          |
+--------------------------------------------------------------------------+

Algoritmo

Procesando registros de sshd en orden cronológico:
1) Encontrar líneas de inicio de sesión (Accepted) y cierre de sesión (Disconnected).
2) Almacenar información de las líneas como nombre de usuario, tipo de autenticación, huella digital, ...
3) Usar el puerto de red utilizado para comprobar sesiones activas
   y unir sesiones antiguas recordando los puertos de red registrados.
4) Usar principalmente /etc/os-release para adaptarse a diferentes sistemas
   que difieren en nombres de archivos de registro, patrones de registro, etc...

ERRORES Y LIMITACIONES

JumpHosts

El uso de un JumpHost con ProxyCommand o ProxyJump,
a menudo puede resultar en una desconexión no limpia sin registro,
por lo que LOGOUT y DURATION no se pueden mostrar.

Usuarios no privilegiados

Si es posible, ejecute ssh-last como root o a través de sudo
1) Los archivos de registro y el journal de systemd generalmente no pueden ser leídos por un usuario normal
2) ssh-last -w solo funciona de manera confiable como root,
   ya que ss y netstat no muestran información de procesos cuando se invocan como usuario normal.
3) ssh-last intenta mapear la huella digital del archivo authorized_keys de un usuario
   pero los usuarios generalmente no tienen permitido mirar los archivos de los demás

Actualizaciones del SO

Si realiza una actualización in situ como dist-upgrade en Debian/Ubuntu,
dependiendo de la diferencia de versión,
puede suceder que sshd registre de manera diferente a partir de ese momento
y es posible que tenga una mezcla de registros en formato nuevo y antiguo
lo que hace que ssh-last muestre solo los más recientes correctamente

Inconsistencia de registro

He visto casos en los que faltaban algunos mensajes de registro de "Disconnect" de sshd
en el journal de systemd pero existían en /var/log/auth.log.
Por lo tanto, si ssh-last no muestra un cierre de sesión y una duración
pero las líneas de registro existen en el archivo de registro, verifique si el mensaje de registro
realmente llegó al journal de systemd, ya que ssh-last utiliza journald por defecto.

ssh-last(1) — SSH-TOOLS

NAME

ssh-last

list recent SSH logins

SYNOPSIS

ssh-last [-c|-i|-n|-p|-u] [host]

DESCRIPTION

The ssh-last utility displays a list of recent SSH logins. By default, it displays all successful logins from the last 24 hours, sorted by date. It parses the output of journalctl for messages from the sshd service.

Options:

-c
Sort by hostname.
-i
Sort by IP address.
-n
Sort by username.
-p
Sort by port number.
-u
Sort by uptime (most recent first).

If a host is specified, only logins from that host are displayed.

FILES

/

BUGS AND LIMITATIONS

This utility relies on the system's logging configuration. If SSH log messages are not stored in a standard location or format, it may not function correctly.

The default time frame for log analysis is 24 hours. This can be adjusted by modifying the journalctl command within the script.

NOTES

For convenience you can create little wrapper scripts like the following which avoids parsing too many logs by limiting the data only to the last week

my-ssh-last
+--------------------------------------------------------------------------+
| #!/usr/bin/env bash                                                      |
|                                                                          |
| LC_TIME=C journalctl _COMM=sshd --since -1week \                         |
| | grep -E 'Accepted|Disconnected'              \                         |
| | ssh-last "$@"                                                          |
|                                                                          |
+--------------------------------------------------------------------------+
