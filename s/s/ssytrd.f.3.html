Documentación de la función/subrutina

subroutine ssytrd (character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SSYTRD

Propósito:

!>
!> SSYTRD reduce una matriz simétrica real A a la forma tridiagonal simétrica real T
!> mediante una transformación de similitud ortogonal:
!> Q**T * A * Q = T.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          A la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          triangular superior de N por N de A contiene la parte
!>          triangular superior de la matriz A, y la parte triangular estrictamente
!>          inferior de A no se referencia. Si UPLO = 'L', la parte triangular
!>          inferior de N por N de A contiene la parte triangular inferior de la
!>          matriz A, y la parte triangular estrictamente superior de A no se referencia.
!>          A la salida, si UPLO = 'U', la diagonal y la superdiagonal principal
!>          de A se sobrescriben con los elementos correspondientes de la
!>          matriz tridiagonal T, y los elementos por encima de la superdiagonal
!>          principal, junto con el array TAU, representan la matriz ortogonal
!>          Q como un producto de reflectores elementales; si UPLO
!>          = 'L', la diagonal y la subdiagonal principal de A se sobrescriben
!>          con los elementos correspondientes de la matriz tridiagonal
!>          T, y los elementos por debajo de la subdiagonal principal, junto con
!>          el array TAU, representan la matriz ortogonal Q como un producto
!>          de reflectores elementales. Véase Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

D

!>          D es un array REAL, de dimensión (N)
!>          Los elementos diagonales de la matriz tridiagonal T:
!>          D(i) = A(i,i).
!>

E

!>          E es un array REAL, de dimensión (N-1)
!>          Los elementos fuera de la diagonal de la matriz tridiagonal T:
!>          E(i) = A(i,i+1) si UPLO = 'U', E(i) = A(i+1,i) si UPLO = 'L'.
!>

TAU

!>          TAU es un array REAL, de dimensión (N-1)
!>          Los factores escalares de los reflectores elementales (ver Detalles
!>          Adicionales).
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= 1.
!>          Para un rendimiento óptimo LWORK >= N*NB, donde NB es el
!>          tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  Si UPLO = 'U', la matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(n-1) . . . H(2) H(1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real y v es un vector real con
!>  v(i+1:n) = 0 y v(i) = 1; v(1:i-1) se almacena a la salida en
!>  A(1:i-1,i+1), y tau en TAU(i).
!>
!>  Si UPLO = 'L', la matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(n-1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real y v es un vector real con
!>  v(1:i) = 0 y v(i+1) = 1; v(i+2:n) se almacena a la salida en A(i+2:n,i),
!>  y tau en TAU(i).
!>
!>  El contenido de A a la salida se ilustra con los siguientes ejemplos
!>  con n = 5:
!>
!>  si UPLO = 'U':                       si UPLO = 'L':
!>
!>    (  d   e   v2  v3  v4 )              (  d                  )
!>    (      d   e   v3  v4 )              (  e   d              )
!>    (          d   e   v4 )              (  v1  e   d          )
!>    (              d   e  )              (  v1  v2  e   d      )
!>    (                  d  )              (  v1  v2  v3  e   d  )
!>
!>  donde d y e denotan los elementos diagonales y fuera de la diagonal de T, y vi
!>  denota un elemento del vector que define H(i).
!>
