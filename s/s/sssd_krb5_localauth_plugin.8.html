NOMBRE

sssd_krb5_localauth_plugin - Plugin de autorización local Kerberos

DESCRIPCIÓN

El plugin de autorización local Kerberos sssd_krb5_localauth_plugin es utilizado por libkrb5 para encontrar el nombre local de un principal Kerberos dado o para verificar si un nombre local dado y un principal Kerberos dado se relacionan entre sí.

SSSD maneja los nombres locales de usuarios de una fuente remota y también puede leer el nombre del principal de usuario Kerberos de la fuente remota. Con esta información, SSSD puede manejar fácilmente los mapeos mencionados anteriormente, incluso si el nombre local y el principal Kerberos difieren considerablemente.

Adicionalmente, con la información leída de la fuente remota, SSSD puede ayudar a prevenir mapeos inesperados o no deseados en caso de que la parte del usuario del principal Kerberos corresponda accidentalmente al nombre local de otro usuario. Por defecto, libkrb5 podría simplemente eliminar la parte del realm del principal Kerberos para obtener el nombre local, lo que conduciría a mapeos incorrectos en este caso.

CONFIGURACIÓN

El plugin de autorización local Kerberos debe ser habilitado explícitamente en la configuración Kerberos, ver krb5.conf(5). SSSD creará un fragmento de configuración con contenido como, por ejemplo:

[plugins]
 localauth = {
  module = sssd:/usr/lib64/sssd/modules/sssd_krb5_localauth_plugin.so
 }

automáticamente en el directorio de fragmentos de configuración públicos de Kerberos de SSSD. Si este directorio está incluido en la configuración local de Kerberos, el plugin se habilitará automáticamente.
