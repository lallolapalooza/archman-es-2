NOMBRE

ssh-tpm-agent - ssh-agent para claves TPM 2.0

SINOPSIS

ssh-tpm-agent [OPCIONES]

ssh-tpm-agent --print-socket

ssh-tpm-agent --install-user-units

DESCRIPCIÓN

ssh-tpm-agent es un programa que crea claves utilizando un Módulo de Plataforma Confiable (TPM) para habilitar claves privadas cifradas para la autenticación por clave pública.

OPCIONES

-l RUTA

Ruta del socket UNIX a abrir

Por defecto es $XDG_RUNTIME_DIR/ssh-tpm-agent.sock.

-A RUTA

Sockets ssh-agent de respaldo para la búsqueda adicional de claves.

--print-socket

Imprime el socket en STDOUT.

--key-dir RUTA

Ruta del directorio donde buscar claves cifradas por TPM.

Por defecto es ~/.ssh.

--no-load

No cargar claves cifradas por TPM de ~/.ssh por defecto.

-o, --owner-password

Preguntar por la contraseña del propietario.

--no-cache

El agente no almacenará en caché las contraseñas de las claves.

--hierarchy HIERARQUIA

Pre-cargar claves de jerarquía en el agente.

Ver Claves de Jerarquía para más información.

Jerarquías disponibles:

•propietario, p
•respaldo, r
•nulo, n
•plataforma, l

-d

Habilitar registro de depuración.

--install-user-units

Instala unidades del sistema systemd y configuraciones de sshd para usar ssh-tpm-agent como agente de claves de host.

--swtpm

Almacena claves dentro de una instancia de swtpm en lugar del TPM real. Esto no es una característica de seguridad y sus claves no se almacenan de forma segura.

También se puede habilitar con la variable de entorno SSH_TPM_AGENT_SWTPM.

EJEMPLOS

Uso normal del agente

ssh-tpm-agent puede ser utilizado como un reemplazo directo de ssh-agent y funciona de la misma manera.

$ ssh-tpm-keygen
# Añadir ~/.ssh/id_ecdsa.pub a tus cuentas de Github
$ ssh-tpm-agent &
$ export SSH_AUTH_SOCK=$(ssh-tpm-agent --print-socket)
$ ssh git@github.com

Ver ssh-tpm-keygen(1) para el uso de keygen.

Soporte de respaldo del agente

ssh-tpm-agent soporta el respaldo a diferentes ssh-agent. Los agentes pueden ser añadidos con el modificador -A. Esto hará que ssh-tpm-agent se expanda a todos los agentes disponibles para obtener claves.

Esto es práctico si tienes múltiples claves de diferentes implementaciones de agente pero quieres depender de un solo socket.

# Iniciar el ssh-agent habitual
$ eval $(ssh-agent)
# Crear una clave RSA fuerte
$ ssh-keygen -t rsa -b 4096 -f id_rsa -C ssh-agent
...
La huella digital de la clave es:
SHA256:zLSeyU/6NKHGEvyZLA866S1jGqwdwdAxRFff8Z2N1i0 ssh-agent
$ ssh-add id_rsa
Identidad añadida: id_rsa (ssh-agent)
# Imprimir clave larga
$ ssh-add -L
ssh-rsa AAAAB3NzaC1yc[...]8TWynQ== ssh-agent
# Crear clave en el TPM
$ ssh-tpm-keygen -C ssh-tpm-agent
Generando un par de claves pública/privada ECDSA cifradas por TPM.
Introduce el archivo donde guardar la clave (/home/usuario/.ssh/id_ecdsa):
Introduce la contraseña (vacía para ninguna contraseña):
Confirma la contraseña:
Tu identificación ha sido guardada en /home/usuario/.ssh/id_ecdsa.tpm

La huella digital de la clave es:

La imagen randomart de la clave es del color de la televisión, sintonizada a un canal muerto.
# Iniciar ssh-tpm-agent con un socket proxy
$ ssh-tpm-agent -A "${SSH_AUTH_SOCK}" &
$ export SSH_AUTH_SOCK="$(ssh-tpm-agent --print-socket)"
# ssh-tpm-agent está actuando como proxy de las claves de ssh-agent
$ ssh-add -L
ssh-rsa AAAAB3NzaC1yc[...]8TWynQ== ssh-agent
ecdsa-sha2-nistp256 AAAAE2VjZHNhLXNo[...]q4whro= ssh-tpm-agent

Uso de claves de host

ssh-tpm-agent también puede ser utilizado para servir claves de host para un servidor ssh. ssh-tpm-hostkeys tiene modificadores convenientes para ayudar a instalar configuraciones y servicios de systemd en el sistema. Esto creará un socket del sistema para ssh-tpm-agent bajo /var/tmp/ssh-tpm-agent.sock.

$ sudo ssh-tpm-keygen -A
2023/09/03 17:03:08 INFO Generando nueva clave de host ECDSA
2023/09/03 17:03:08 INFO Escribió /etc/ssh/ssh_tpm_host_ecdsa_key.tpm
2023/09/03 17:03:08 INFO Generando nueva clave de host RSA
2023/09/03 17:03:15 INFO Escribió /etc/ssh/ssh_tpm_host_rsa_key.tpm
$ sudo ssh-tpm-hostkeys --install-system-units
Instalado /usr/lib/systemd/system/ssh-tpm-agent.service
Instalado /usr/lib/systemd/system/ssh-tpm-agent.socket
Instalado /usr/lib/systemd/system/ssh-tpm-genkeys.service
Habilitar con: systemctl enable --now ssh-tpm-agent.socket
$ sudo ssh-tpm-hostkeys --install-sshd-config
Instalado /etc/ssh/sshd_config.d/10-ssh-tpm-agent.conf
Reiniciar sshd: systemd restart sshd
$ systemctl enable --now ssh-tpm-agent.socket
$ systemd restart sshd
$ sudo ssh-tpm-hostkeys
ecdsa-sha2-nistp256 AAAAE2V[...]YNwqWY0= root@localhost
ssh-rsa AAAAB3NzaC1ycA[...]N1Jg3fLQKSe7f root@localhost
$ ssh-keyscan -t ecdsa localhost
# localhost:22 SSH-2.0-OpenSSH_9.4
localhost ecdsa-sha2-nistp256 AAAAE2V[...]YNwqWY0=

Alternativamente, se puede omitir los modificadores de instalación incrustados y simplemente incluir una configuración de drop-in para sshd en /etc/ssh/sshd_config.d con el siguiente contenido.

HostKeyAgent /var/tmp/ssh-tpm-agent.sock
HostKey /etc/ssh/ssh_tpm_host_ecdsa_key.pub
HostKey /etc/ssh/ssh_tpm_host_rsa_key.pub

Claves de Jerarquía

Los TPMs son capaces de crear claves estáticas utilizando las jerarquías de nivel superior. Esto permite al usuario crear claves que están disponibles durante la vida útil del dispositivo, para el propietario actual del dispositivo, o la sesión actual del dispositivo. Estas claves no salen del TPM, al igual que otras claves creadas por ssh-tpm-keygen, y siempre pueden ser recreadas.

Estas claves pueden ser pre-cargadas en ssh-tpm-agent.

$ ssh-tpm-agent --hierarchy owner &
$ export SSH_AUTH_SOCK="$(ssh-tpm-agent --print-socket)"
$ ssh-add -l
2048 SHA256:yt7A20tcRnzgaD2ATgAXSNWy9sP6wznysp3SkoK3Gj8 Clave de jerarquía del propietario (RSA)
256 SHA256:PmEsMeh/DwFP04iUaWLNeX4maMR6r1vfqw1BbbdFjIg Clave de jerarquía del propietario (ECDSA)

Para su uso con sshd, la parte pública de estas claves puede ser creada combinando -A con --hierarchy.

$ ssh-tpm-keygen -A --hierarchy owner
2025/03/10 21:57:08 INFO Generando nueva clave de host de jerarquía algorithm=RSA hierarchy=owner
2025/03/10 21:57:10 INFO Escribió el nombre de archivo de clave pública=/etc/ssh/ssh_tpm_host_rsa_key.pub
2025/03/10 21:57:10 INFO Generando nueva clave de host de jerarquía algorithm=ECDSA hierarchy=owner
2025/03/10 21:57:10 INFO Escribió el nombre de archivo de clave pública=/etc/ssh/ssh_tpm_host_ecdsa_key.pub

Estos archivos pueden ser usados con HostKey como normal en ssh_config.

Las diferentes jerarquías de claves tienen diferentes propiedades y ciclos de vida.

La jerarquía de respaldo almacena claves creadas para la vida útil del dispositivo. Esta jerarquía no debería cambiar durante la vida útil del dispositivo.

La jerarquía de propietario almacena claves creadas para el propietario del dispositivo. Estas claves serán rotadas cuando se emita tpm2_clear(1) en la plataforma, lo que debería hacerse cuando el dispositivo reciba un nuevo propietario.

La jerarquía nula almacena claves creadas para la sesión actual. La sesión debería ser un ciclo de energía de los dispositivos.

NOMBRE

ssh-tpm-agent - Agente SSH para TPM

SINOPSIS

ssh-tpm-agent [-D] [-f] [-l] [-s] [-t] [-U path]

DESCRIPCIÓN

ssh-tpm-agent es un agente SSH que almacena las claves privadas SSH en un Módulo de Plataforma Confiable (TPM).

Utiliza el socket de agente SSH estándar para comunicarse con otros programas SSH. Para su uso, se requiere un TPM 2.0.

Esta función es experimental.

ssh-tpm-agent mantiene cargados los objetos del TPM mientras se ejecuta. Algunos dispositivos TPM se quedan sin memoria si intentas usar las claves de jerarquía con las claves habituales creadas por ssh-tpm-keygen.

OPCIONES

-D
No te separes del terminal (modo foreground).
-f
Ejecutar en primer plano. Similar a -D.
-l
Registra la actividad en el sistema de registro de depuración del kernel. El registro en el kernel está habilitado si el TPM está configurado para ello.
-s
Inicia el agente en modo de shell. Imprime los comandos de inicialización del shell a la salida estándar.
-t
Intentar mantener las claves cargadas en el TPM por más tiempo. Deshabilitado por defecto.
-U path
Especifica el archivo de socket UNIX alternativo. El valor predeterminado es $SSH_TPM_AUTH_SOCK si está establecido, de lo contrario, es /var/tmp/ssh-tpm-agent.sock.

EJEMPLOS

Iniciar el agente en segundo plano y obtener los comandos de inicialización para bash:

$ ssh-tpm-agent -s
export SSH_AUTH_SOCK="/var/tmp/ssh-tpm-agent.sock";
export SSH_AGENT_PID="$(pgrep ssh-tpm-agent)";

Iniciar el agente en primer plano para depuración:

$ ssh-tpm-agent -D

AMBIENTE

SSH_TPM_AUTH_SOCK

Identifica la ruta de un socket de dominio UNIX para la comunicación con el agente.

Por defecto es /var/tmp/ssh-tpm-agent.sock.

SSH_ASKPASS

Si ssh-tpm-agent, y otros binarios, necesitan leer una contraseña, usarán el terminal por defecto si es posible. Si no hay un terminal disponible, recurrirán a llamar al binario indicado por SSH_ASKPASS.

Consulta ssh(1) bajo AMBIENTE para más información.

SSH_ASKPASS_REQUIRE

Permite controlar el uso del programa askpass. Los valores válidos son:
•never asegura que ssh nunca intentará usar el programa askpass.
•prefer preferirá usar el programa askpass.
•force asegurará que todas las entradas de frase de contraseña usarán el programa askpass.

Consulta ssh(1) bajo AMBIENTE para más información.

SSH_TPM_AGENT_SWTPM

Especifica si ssh-tpm-agent debe usar el backend swtpm o no. Acepta cualquier valor no vacío como verdadero.

SSH_TPM_LANDLOCK

Si está establecido, entonces ssh-tpm-agent, y los otros binarios, impondrán el sandbox landlock donde sea aplicable.

Deshabilitado por defecto.

Consulta landlock(7) para más información.

ARCHIVOS

~/ssh/id_rsa.tpm, ~/ssh/id_ecdsa.tpm

Contiene las claves privadas SSH utilizadas por ssh-tpm-agent. Son archivos de clave TSS TPM 2.0 y están cifrados de forma segura por el TPM. Pueden ser compartidos públicamente ya que solo pueden ser utilizados por el TPM en el que se crearon. Sin embargo, probablemente sea mejor no hacerlo.

~/ssh/id_rsa.pub, ~/ssh/id_ecdsa.pub

Contiene las claves públicas SSH. Estas pueden ser compartidas públicamente y tienen el mismo formato que las creadas por ssh-keygen(1).

/run/user/$UID/ssh-tpm-agent.sock

La ruta predeterminada del socket UNIX de ssh-tpm-agent para el usuario. Utilizado por usuarios individuales.

/var/tmp/ssh-tpm-agent.sock

La ruta predeterminada del socket UNIX de ssh-tpm-agent del sistema. Utilizado para claves de host y el sistema.
