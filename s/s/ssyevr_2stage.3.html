subroutine ssyevr_2stage (character jobz, character range, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSYEVR_2STAGE calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices SY

Propósito:

!>
!> SSYEVR_2STAGE calcula valores propios seleccionados y, opcionalmente,
!> vectores propios de una matriz simétrica real A utilizando la técnica de
!> dos etapas para la reducción a tridiagonal. Los valores propios y vectores
!> propios se pueden seleccionar especificando un rango de valores o un
!> rango de índices para los valores propios deseados.
!>
!> SSYEVR_2STAGE primero reduce la matriz A a la forma tridiagonal T con una
!> llamada a SSYTRD. Luego, siempre que sea posible, SSYEVR_2STAGE llama a
!> SSTEMR para calcular el espectro propio utilizando Representaciones
!> Relativamente Robustas. SSTEMR calcula los valores propios mediante el
!> algoritmo dqds, mientras que los vectores propios ortogonales se calculan
!> a partir de varias representaciones L D L^T (también conocidas como
!> Representaciones Relativamente Robustas). La ortogonalización de Gram-Schmidt
!> se evita tanto como sea posible. Más específicamente, los diversos pasos
!> del algoritmo son los siguientes:
!>
!> Para cada bloque no reducido (submatriz) de T,
!>    (a) Calcular T - sigma I  = L D L^T, de modo que L y D
!>        definan todos los valores propios deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los valores propios y
!>        vectores propios. La representación estándar (no factorizada) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcular los valores propios con la precisión adecuada.
!>        Si se desean los vectores propios, el algoritmo alcanza la precisión
!>        completa de los valores propios calculados solo justo antes de que
!>        los vectores correspondientes tengan que ser calculados, ver pasos c) y d).
!>    (c) Para cada clúster de valores propios cercanos, seleccionar un nuevo
!>        desplazamiento cercano al clúster, encontrar una nueva factorización y
!>        refinar los valores propios desplazados a la precisión adecuada.
!>    (d) Para cada valor propio con una separación relativa suficientemente grande,
!>        calcular el vector propio correspondiente formando una factorización retorcida
!>        que revele rangos. Volver a (c) para cualquier clúster que permanezca.
!>
!> La precisión deseada de la salida se puede especificar mediante el parámetro
!> de entrada ABSTOL.
!>
!> Para más detalles, ver la documentación de SSTEMR y:
!> - Inderjit S. Dhillon y Beresford N. Parlett:
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, agosto de 2004.
!> - Inderjit Dhillon y Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004. También LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mayo de 1997.
!>
!>
!> Nota 1: SSYEVR_2STAGE llama a SSTEMR cuando se solicita el espectro completo
!> en máquinas que cumplen el estándar de punto flotante ieee-754.
!> SSYEVR_2STAGE llama a SSTEBZ y SSTEIN en máquinas no ieee y
!> cuando se realizan solicitudes de espectro parcial.
!>
!> La ejecución normal de SSTEMR puede crear NaNs e infinitos y
!> por lo tanto, puede abortar debido a una excepción de punto flotante en entornos
!> que no manejan NaNs e infinitos en la forma predeterminada estándar de ieee.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Solo se calculan los valores propios;
!>          = 'V':  Se calculan los valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>          Para RANGE = 'V' o 'I' y IU - IL < N - 1, se llaman SSTEBZ y
!>          SSTEIN.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  se almacena el triángulo superior de A;
!>          = 'L':  se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array REAL, dimension (LDA, N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la
!>          parte triangular superior N-por-N de A contiene la
!>          parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior N-por-N de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluida la diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Ver por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si la alta precisión relativa es importante, establezca ABSTOL a
!>          SLAMCH( 'Safe minimum' ). Hacer esto garantizará que
!>          los valores propios se calculen con alta precisión relativa cuando
!>          sea posible en futuras versiones. El código actual no
!>          hace ninguna garantía sobre alta precisión relativa, pero
!>          las futuras versiones sí lo harán. Ver J. Barlow y J. Demmel,
!>          , LAPACK Working Note #7, para una discusión
!>          sobre qué matrices definen sus valores propios con alta precisión relativa.
!>

SSYEVR_2STAGE

SSYEVR_2STAGE compute the eigenvalues and eigenvectors of a real symmetric matrix.

NAME

ssyevr - computes the eigenvalues and eigenvectors of a real symmetric matrix.

SYNOPSIS

SUBROUTINE SSYEVR(
   JOBZ  CHARACTER(*),
   RANGE CHARACTER(*),
   UPLO  CHARACTER(*),
   N     INTEGER,
   A     REAL array, dimension (LDA,*)
   LDA   INTEGER,
   VL    REAL,
   VU    REAL,
   IL    INTEGER,
   IU    INTEGER,
   KEY   REAL,
   M     INTEGER,
   W     REAL array, dimension (N),
   Z     REAL array, dimension (LDZ,*)
   LDZ   INTEGER,
   ISUPPZ INTEGER array, dimension ( 2*max(1,N) ),
   WORK  REAL array, dimension (MAX(1,LWORK)),
   LWORK INTEGER,
   IWORK INTEGER array, dimension (MAX(1,LIWORK)),
   LIWORK INTEGER,
   INFO  INTEGER )

Function/Subroutine Documentation

JOBZ

!>          JOBZ is CHARACTER*1
!>          = 'N':  Compute only the eigenvalues of A.
!>          = 'V':  Compute the eigenvalues and eigenvectors of A.
!>

RANGE

!>          RANGE is CHARACTER*1
!>          = 'A': all eigenvalues will be found.
!>          = 'V': all eigenvalues in the interval (VL,VU] will be found.
!>          = 'I': all eigenvalues in the range [IL, IU], IL and IU are
!>                 given in the range [1,N], will be found.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the symmetric matrix A.  The only means to compute
!>          eigenvalues and eigenvectors, and is only accessed when
!>          JOBZ = 'E' or JOBZ = 'V'.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!>

VL

!>          VL is REAL
!>          If RANGE='V' and OPT='i', the lower bound of the interval for
!>          the desired eigenvalues.
!>

VU

!>          VU is REAL
!>          If RANGE='V' and OPT='i', the upper bound of the interval for
!>          the desired eigenvalues.
!>

IL

!>          IL is INTEGER
!>          If RANGE='I', the index of the smallest eigenvalue to be
!>          returned.
!>

IU

!>          IU is INTEGER
!>          If RANGE='I', the index of the largest eigenvalue to be
!>          returned.
!>

KEY

!>          KEY is REAL
!>          - If RANGE='U', KEY specifies the ordering.
!>          = KEY    : Eigenvalues in the interval (VL,VU]
!>          = VL     : Eigenvalues in the interval (VL,VU]
!>          = VU     : Eigenvalues in the interval (VL,VU]
!>

M

!>          M is INTEGER
!>          The total number of eigenvalues found.  0 <= M <= N.
!>          If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.
!>

W

!>          W is REAL array, dimension (N)
!>          The first M elements contain the selected eigenvalues in
!>          ascending order.
!>

Z

!>          Z is REAL array, dimension (LDZ, max(1,M))
!>          If JOBZ = 'V', then if INFO = 0, the first M columns of Z
!>          contain the orthonormal eigenvectors of the matrix A
!>          corresponding to the selected eigenvalues, with the i-th
!>          column of Z holding the eigenvector associated with W(i).
!>          If JOBZ = 'N', then Z is not referenced.
!>          Note: the user must ensure that at least max(1,M) columns are
!>          supplied in the array Z; if RANGE = 'V', the exact value of M
!>          is not known in advance and an upper bound must be used.
!>          Supplying N columns is always safe.
!>

LDZ

!>          LDZ is INTEGER
!>          The leading dimension of the array Z. LDZ >= 1, and if
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
!>          The support of the eigenvectors in Z, i.e., the indices
!>          indicating the nonzero elements in Z. The i-th eigenvector
!>          is nonzero only in elements ISUPPZ( 2*i-1 ) through
!>          ISUPPZ( 2*i ). This is an output of SSTEMR (tridiagonal
!>          matrix). The support of the eigenvectors of A is typically
!>          1:N because of the orthogonal transformations applied by SORMTR.
!>          Implemented only for RANGE = 'A' or 'I' and IU - IL = N - 1
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          If N <= 1,               LWORK must be at least 1.
!>          If JOBZ = 'N' and N > 1, LWORK must be queried.
!>                                   LWORK = MAX(1, 26*N, dimension) where
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + 5*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 5*N
!>                                   where KD is the blocking size of the reduction,
!>                                   FACTOPTNB is the blocking used by the QR or LQ
!>                                   algorithm, usually FACTOPTNB=128 is a good choice
!>                                   NTHREADS is the number of threads used when
!>                                   openMP compilation is enabled, otherwise =1.
!>          If JOBZ = 'V' and N > 1, LWORK must be queried. Not yet available
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (MAX(1,LIWORK))
!>          On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.
!>          If N <= 1, LIWORK >= 1, else LIWORK >= 10*N.
!>
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal size of the IWORK array,
!>          returns this value as the first entry of the IWORK array, and
!>          no error message related to LIWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  Internal error
!>
