SINOPSIS

Funciones/Subrutinas


subrutina ssbevd_2stage (jobz, uplo, n, kd, ab, ldab, w, z, ldz, work, lwork, iwork, liwork, info)

SSBEVD_2STAGE calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para MATRICES DE OTRO TIPO

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina ssbevd_2stage (character jobz, character uplo, integer n, integer kd, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSBEVD_2STAGE calcula todos los valores propios y, opcionalmente, los vectores propios de una matriz de banda simétrica real A utilizando la técnica de 2 etapas para la reducción a tridiagonal. Si se desean vectores propios, utiliza un algoritmo de divide y vencerás.

Propósito:

!>
!> SSBEVD_2STAGE calcula todos los valores propios y, opcionalmente, los vectores propios de
!> una matriz de banda simétrica real A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal. Si se desean vectores propios, utiliza
!> un algoritmo de divide y vencerás.
!>
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>                  No disponible en esta versión.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es array REAL, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda simétrica
!>          A, almacenado en las primeras KD+1 filas del array. La
!>          columna j de A se almacena en la columna j del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la primera
!>          superdiagonal y la diagonal de la matriz tridiagonal T
!>          se devuelven en las filas KD y KD+1 de AB, y si UPLO = 'L',
!>          la diagonal y la primera subdiagonal de T se devuelven en las
!>          primeras dos filas de AB.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!>

W

!>          W es array REAL, dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es array REAL, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los
!>          vectores propios ortonormales de la matriz A, con la columna i de Z
!>          conteniendo el vector propio asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se utiliza.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array REAL, dimensión LWORK
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimensión) donde
!>                                   dimensión = (2KD+1)*N + KD*NTHREADS + N
!>                                   donde KD es el tamaño de la banda.
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   la compilación openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Aún no disponible.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK y IWORK,
!>          devuelve estos valores como las primeras entradas de los
!>          arrays WORK e IWORK, y no se emite ningún mensaje de error relacionado con LWORK o
!>          LIWORK por XERBLA.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si JOBZ  = 'N' o N <= 1, LIWORK debe ser al menos 1.
!>          Si JOBZ  = 'V' y N > 2, LIWORK debe ser al menos 3 + 5*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK e IWORK, y no se emite ningún mensaje de error relacionado con
!>          LWORK o LIWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i tuvo un valor ilegal
!>          > 0:  si INFO = i, el algoritmo no convergió; i
!>                elementos fuera de la diagonal de una forma tridiagonal intermedia
!>                no convergieron a cero.
!>
