subrutina ssyt01_aa (character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldafac, * ) afac, integer ldafac, integer, dimension( * ) ipiv, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) rwork, real resid)

SSYT01_AA

Propósito:

!>
!> SSYT01_AA reconstruye una matriz simétrica indefinida A a partir de su
!> factorización de L*D*L' o U*D*U' en bloques y calcula la norma residual
!> de norm( C - A ) / ( N * norm(A) * EPS ),
!> donde C es la matriz reconstruida y EPS es la epsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          La matriz simétrica original A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N)
!>

AFAC

!>          AFAC es un array REAL, de dimensión (LDAFAC,N)
!>          La forma factorizada de la matriz A.  AFAC contiene la matriz
!>          de bloques diagonales D y los multiplicadores utilizados para
!>          obtener L o U de la factorización L*D*L' o U*D*U' en bloques
!>          tal como fue calculada por SSYTRF.
!>

LDAFAC

!>          LDAFAC es INTEGER
!>          La dimensión principal del array AFAC.  LDAFAC >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Los índices de pivote de SSYTRF.
!>

C

!>          C es un array REAL, de dimensión (LDC,N)
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C.  LDC >= max(1,N).
!>

RWORK

!>          RWORK es un array REAL, de dimensión (N)
!>

RESID

!>          RESID es REAL
!>          Si UPLO = 'L', norm(L*D*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U*D*U' - A) / ( N * norm(A) * EPS )
!>
