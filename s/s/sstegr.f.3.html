Documentación de Funciones/Subrutinas

subroutine sstegr (character jobz, character range, integer n, real, dimension( * ) d, real, dimension( * ) e, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSTEGR

Propósito:

!>
!> SSTEGR calcula autovalores seleccionados y, opcionalmente, autovectores
!> de una matriz tridiagonal simétrica real T. Cualquier matriz de este tipo
!> no reducida tiene un conjunto bien definido de autovalores reales
!> distintos por pares, los autovectores reales correspondientes son
!> ortogonales por pares.
!>
!> El espectro puede calcularse de forma completa o parcial especificando
!> ya sea un intervalo (VL,VU] o un rango de índices IL:IU para los
!> autovalores deseados.
!>
!> SSTEGR es un envoltorio de compatibilidad alrededor de la rutina mejorada
!> SSTEMR. Consulte SSTEMR para más detalles.
!>
!> Un cambio importante es que el parámetro ABSTOL ya no proporciona ningún
!> beneficio y por lo tanto ya no se utiliza.
!>
!> Nota: SSTEGR y SSTEMR funcionan solo en máquinas que siguen el estándar
!> de punto flotante IEEE-754 en su manejo de infinitos y NaN. La ejecución
!> normal puede crear estos valores excepcionales y por lo tanto puede
!> abortar debido a una excepción de punto flotante en entornos que no
!> cumplen con el estándar IEEE-754.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo autovalores;
!>          = 'V':  Calcular autovalores y autovectores.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los autovalores.
!>          = 'V': se encontrarán todos los autovalores en el intervalo
!>                 semiabierto (VL,VU].
!>          = 'I': se encontrarán los autovalores desde el IL-ésimo hasta
!>                 el IU-ésimo.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un arreglo REAL, dimensión (N)
!>          Al entrar, los N elementos diagonales de la matriz tridiagonal
!>          T. Al salir, D se sobrescribe.
!>

E

!>          E es un arreglo REAL, dimensión (N)
!>          Al entrar, los (N-1) elementos subdiagonales de la matriz
!>          tridiagonal T en los elementos 1 a N-1 de E. E(N) no necesita
!>          establecerse en la entrada, pero se usa internamente como
!>          espacio de trabajo.
!>          Al salir, E se sobrescribe.
!>

VL

!>          VL es REAL
!>
!>          Si RANGE='V', el límite inferior del intervalo en el que
!>          buscar autovalores. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>
!>          Si RANGE='V', el límite superior del intervalo en el que
!>          buscar autovalores. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          Sin uso. Era la tolerancia de error absoluto para los
!>          autovalores/autovectores en versiones anteriores.
!>

M

!>          M es INTEGER
!>          El número total de autovalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un arreglo REAL, dimensión (N)
!>          Los primeros M elementos contienen los autovalores
!>          seleccionados en orden ascendente.
!>

Z

!>          Z es un arreglo REAL, dimensión (LDZ, max(1,M) )
!>          Si JOBZ = 'V', y si INFO = 0, entonces las primeras M columnas
!>          de Z contienen los autovectores ortonormales de la matriz T
!>          correspondientes a los autovalores seleccionados, con la
!>          i-ésima columna de Z conteniendo el autovector asociado con W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos
!>          max(1,M) columnas en el arreglo Z; si RANGE = 'V', el valor
!>          exacto de M no se conoce de antemano y debe usarse una cota
!>          superior. Proporcionar N columnas siempre es seguro.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del arreglo Z.  LDZ >= 1, y si
!>          JOBZ = 'V', entonces LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ es un arreglo INTEGER, dimensión ( 2*max(1,M) )
!>          El soporte de los autovectores en Z, es decir, los índices
!>          que indican los elementos distintos de cero en Z. El i-ésimo
!>          autovector calculado es distinto de cero solo en los elementos
!>          ISUPPZ( 2*i-1 ) hasta ISUPPZ( 2*i ). Esto es relevante en el
!>          caso en que la matriz está dividida. ISUPPZ solo se accede
!>          cuando JOBZ es 'V' y N > 0.
!>

WORK

!>          WORK es un arreglo REAL, dimensión (LWORK)
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo
!>          (y mínimo).
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK >= max(1,18*N)
!>          si JOBZ = 'V', y LWORK >= max(1,12*N) si JOBZ = 'N'.
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del arreglo
!>          WORK, devuelve este valor como la primera entrada del arreglo
!>          WORK, y XERBLA no emite ningún mensaje de error relacionado
!>          con LWORK.
!>

IWORK

!>          IWORK es un arreglo INTEGER, dimensión (LIWORK)
!>          Al salir, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del arreglo IWORK.  LIWORK >= max(1,10*N)
!>          si se desean los autovectores, y LIWORK >= max(1,8*N)
!>          si solo se van a calcular los autovalores.
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del arreglo
!>          IWORK, devuelve este valor como la primera entrada del arreglo
!>          IWORK, y XERBLA no emite ningún mensaje de error relacionado
!>          con LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          Al salir, INFO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = 1X, error interno en SLARRE,
!>                si INFO = 2X, error interno en SLARRV.
!>                Aquí, el dígito X = ABS( IINFO ) < 10, donde IINFO es
!>                el código de error distinto de cero devuelto por SLARRE o
!>                SLARRV, respectivamente.
!>
