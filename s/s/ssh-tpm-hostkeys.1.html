SSH-TPM-HOSTKEYS(1) Manual de ssh-tpm-hostkeys SSH-TPM-HOSTKEYS(1)

NOMBRE

ssh-tpm-hostkeys - utilidad de claves de host de ssh-tpm-agent

SINOPSIS

ssh-tpm-hostkeys

ssh-tpm-hostkeys --install-system-units

ssh-tpm-hostkeys --install-sshd-config

DESCRIPCIÓN

ssh-tpm-hostkeys muestra las claves de host del sistema y puede instalar unidades systemd relevantes y configuración de sshd para usar claves de host respaldadas por TPM.

OPCIONES

--install-system-units

Instala unidades de sistema systemd para usar ssh-tpm-agent como agente de claves de host.

--install-sshd-config

Instala la configuración de sshd para el socket de ssh-tpm-agent.

VER TAMBIÉN
