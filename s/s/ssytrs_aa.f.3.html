Documentación de función/subrutina

subrutina ssytrs_aa (character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) work, integer lwork, integer info)

SSYTRS_AA

Propósito:

!>
!> SSYTRS_AA resuelve un sistema de ecuaciones lineales A*X = B con una matriz simétrica
!> real A utilizando la factorización A = U**T*T*U o A = L*T*L**T calculada por SSYTRF_AA.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, la forma es A = U**T*T*U;
!>          = 'L':  Triangular inferior, la forma es A = L*T*L**T.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es una matriz REAL, dimensión (LDA,N)
!>          Detalles de los factores calculados por SSYTRF_AA.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es una matriz INTEGER, dimensión (N)
!>          Detalles de los intercambios calculados por SSYTRF_AA.
!>

B

!>          B es una matriz REAL, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, la matriz de solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B.  LDB >= max(1,N).
!>

WORK

!>          WORK es una matriz REAL, dimensión (MAX(1,LWORK))
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión de la matriz WORK.
!>          Si MIN(N,NRHS) = 0, LWORK >= 1, de lo contrario LWORK >= 3*N-2.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño mínimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje
!>          de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
