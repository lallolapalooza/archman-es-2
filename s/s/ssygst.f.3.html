Documentación de la Función/Subrutina

subrutina ssygst (integer itype, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, integer info)

SSYGST

Propósito:

!>
!> SSYGST reduce un problema de valores propios generalizado simétrico-definido real
!> a la forma estándar.
!>
!> Si ITYPE = 1, el problema es A*x = lambda*B*x,
!> y A se sobrescribe con inv(U**T)*A*inv(U) o inv(L)*A*inv(L**T)
!>
!> Si ITYPE = 2 o 3, el problema es A*B*x = lambda*x o
!> B*A*x = lambda*x, y A se sobrescribe con U*A*U**T o L**T*A*L.
!>
!> B debe haber sido previamente factorizado como U**T*U o L*L**T por SPOTRF.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          = 1: calcula inv(U**T)*A*inv(U) o inv(L)*A*inv(L**T);
!>          = 2 o 3: calcula U*A*U**T o L**T*A*L.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  el triángulo superior de A se almacena y B se factoriza como
!>                  U**T*U;
!>          = 'L':  el triángulo inferior de A se almacena y B se factoriza como
!>                  L*L**T.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

A

!>          A es una matriz REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular N-por-N principal de A contiene la parte
!>          superior triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia.  Si UPLO = 'L', la parte
!>          inferior triangular N-por-N principal de A contiene la parte
!>          inferior triangular de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>
!>          En la salida, si INFO = 0, la matriz transformada, almacenada en el
!>          mismo formato que A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es una matriz REAL, de dimensión (LDB,N)
!>          El factor triangular de la factorización de Cholesky de B,
!>          tal como es devuelto por SPOTRF.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
