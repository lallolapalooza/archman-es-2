subrutina sstevr (carácter jobz, carácter range, entero n, real, dimensión( * ) d, real, dimensión( * ) e, real vl, real vu, entero il, entero iu, real abstol, entero m, real, dimensión( * ) w, real, dimensión( ldz, * ) z, entero ldz, entero, dimensión( * ) isuppz, real, dimensión( * ) work, entero lwork, entero, dimensión( * ) iwork, entero liwork, entero info)

SSTEVR calcula los valores y, opcionalmente, los vectores propios izquierdos y/o derechos para OTRAS matrices

Propósito:

!>
!> SSTEVR calcula los valores propios seleccionados y, opcionalmente, los vectores
!> propios de una matriz tridiagonal simétrica real T.  Los valores y
!> vectores propios se pueden seleccionar especificando ya sea un rango de valores
!> o un rango de índices para los valores propios deseados.
!>
!> Siempre que sea posible, SSTEVR llama a SSTEMR para calcular el
!> espectro propio utilizando Representaciones Relativamente Robustas. SSTEMR
!> calcula los valores propios mediante el algoritmo dqds, mientras que los vectores
!> propios ortogonales se calculan a partir de varias representaciones L D L^T
!> (también conocidas como Representaciones Relativamente Robustas). La
!> ortogonalización de Gram-Schmidt se evita en la medida de lo posible. Más
!> específicamente, los diversos pasos del algoritmo son los siguientes. Para el i-ésimo
!> bloque no reducido de T,
!>    (a) Calcular T - sigma_i = L_i D_i L_i^T, de modo que L_i D_i L_i^T
!>         sea una representación relativamente robusta,
!>    (b) Calcular los valores propios, lambda_j, de L_i D_i L_i^T con alta
!>         precisión relativa mediante el algoritmo dqds,
!>    (c) Si hay un clúster de valores propios cercanos, sigma_i
!>         cercano al clúster, y se va al paso (a),
!>    (d) Dado el valor propio aproximado lambda_j de L_i D_i L_i^T,
!>         calcular el vector propio correspondiente formando una
!>         factorización retorcida de rango-revelador.
!> La precisión deseada de la salida se puede especificar mediante el parámetro
!> de entrada ABSTOL.
!>
!> Para más detalles, ver , de Inderjit Dhillon,
!> Informe Técnico No. UCB//CSD-97-971 de la División de Ciencias de la Computación,
!> UC Berkeley, mayo de 1997.
!>
!>
!> Nota 1: SSTEVR llama a SSTEBZ y SSTEIN en máquinas no-ieee y
!> cuando se solicitan espectros parciales.
!>
!> La ejecución normal de SSTEMR puede crear NaNs e infinitos y
!> por lo tanto puede abortar debido a una excepción de punto flotante en entornos
!> que no manejan NaNs e infinitos de la manera predeterminada estándar de ieee.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular los valores propios y los vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>          Para RANGE = 'V' o 'I' y IU - IL < N - 1, se llaman SSTEBZ y
!>          SSTEIN
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es array REAL, dimensión (N)
!>          En la entrada, los n elementos diagonales de la matriz tridiagonal
!>          A.
!>          En la salida, D puede ser multiplicado por un factor constante elegido
!>          para evitar desbordamiento/subdesbordamiento al calcular los valores propios.
!>

E

!>          E es array REAL, dimensión (max(1,N-1))
!>          En la entrada, los (n-1) elementos subdiagonales de la matriz
!>          tridiagonal A en los elementos de 1 a N-1 de E.
!>          En la salida, E puede ser multiplicado por un factor constante elegido
!>          para evitar desbordamiento/subdesbordamiento al calcular los valores propios.
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de anchura menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Ver por Demmel y
!>          Kahan, Nota de Trabajo de LAPACK #3.
!>
!>          Si la alta precisión relativa es importante, establezca ABSTOL a
!>          SLAMCH( 'Safe minimum' ). Hacer esto garantizará que
!>          los valores propios se calculen con alta precisión relativa cuando
!>          sea posible en futuras versiones. El código actual no
!>          hace ninguna garantía sobre la alta precisión relativa, pero
!>          las futuras versiones sí lo harán. Ver J. Barlow y J. Demmel,
!>          , Nota de Trabajo de LAPACK #7, para una discusión
!>          sobre qué matrices definen sus valores propios con alta precisión relativa.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array REAL, dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es array REAL, dimensión (LDZ, max(1,M) )
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ es array INTEGER, dimensión ( 2*max(1,M) )
!>          El soporte de los vectores propios en Z, es decir, los índices
!>          que indican los elementos distintos de cero en Z. El i-ésimo vector propio
!>          es distinto de cero solo en los elementos ISUPPZ( 2*i-1 )

SSTEVR(3) LAPACK SSTEVR(3)

NAME

SSTEVR — Computes the eigenvalues and, optionally, eigenvectors of a real symmetric tridiagonal matrix.

SYNOPSIS

CALL SSTEVR( JOBZ, RANGE, N, D, E, VL, VU, IL, IU, ABSTOL, M, NZ,
             Z, LDZ, ISUPPZ, WORK, LWORK, IWORK, LIWORK, INFO )

Function/Subroutine Documentation

This subroutine computes the eigenvalues and, optionally, eigenvectors of a real symmetric tridiagonal matrix. It can be used to find all eigenvalues, a subset of the eigenvalues within a given range, or the eigenvalues that correspond to the I-th through J-th smallest eigenvalues.

Parameters:

JOBZ
CHARACTER*1. Required argument.
  • 'N': Compute only the eigenvalues of A.
  • 'V': Compute the eigenvalues and eigenvectors of A.
RANGE
CHARACTER*1. Required argument.
  • 'A': All eigenvalues will be found.
  • 'V': All eigenvalues in the interval (VL, VU] will be found.
  • 'I': The IL-th through IU-th eigenvalues will be found.
N
INTEGER. Required argument.

The order of the matrix A. N >= 0.

D
REAL array, dimension (N). Required argument.

The diagonal entries of the tridiagonal matrix A.

E
REAL array, dimension (N-1). Optional argument.

The off-diagonal entries of the tridiagonal matrix A. E(i) stores the element between D(i) and D(i+1).

VL
REAL. Optional argument.

If RANGE='V', the lower bound of the eigenvalue interval.

VU
REAL. Optional argument.

If RANGE='V', the upper bound of the eigenvalue interval.

IL
INTEGER. Optional argument.

If RANGE='I', the index of the smallest eigenvalue to be computed.

IU
INTEGER. Optional argument.

If RANGE='I', the index of the largest eigenvalue to be computed.

ABSTOL
REAL. Required argument.

The absolute tolerance for the eigenvalues. See further description below.

M
INTEGER. Output.

The total number of eigenvalues found. 0 <= M <= N.

NZ
INTEGER. Output.

The number of eigenvectors computed. If JOBZ='N', NZ=0.

Z
REAL array, dimension (LDZ, N). Output.

If JOBZ='V', the computed eigenvectors. The general entry Z(i,j) is the eigenvector corresponding to the J-th eigenvalue (in the order returned by the routine) of the matrix A. The eigenvectors are normalized so that the 1-norm is 1.

LDZ
INTEGER. Required argument.

The leading dimension of the array Z. LDZ >= max(1, N).

ISUPPZ
INTEGER array, dimension (2*N). Output.

The support of the eigenvectors in Z. More precisely, the non-zero entries of Z(i,j) are in the rows ISUPPZ(2*j-1) to ISUPPZ(2*j). Applied only when U' = U.

WORK
REAL array, dimension (MAX(1,LWORK)).

On exit, if INFO = 0, WORK(1) returns the optimal (and minimal) LWORK.

LWORK
INTEGER.

The dimension of the array WORK. LWORK >= 20*N. If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal sizes of the WORK and IWORK arrays, returns these values as the first entries of the WORK and IWORK arrays, and no error message related to LWORK or LIWORK is issued by XERBLA.

IWORK
INTEGER array, dimension (MAX(1,LIWORK)).

On exit, if INFO = 0, IWORK(1) returns the optimal (and minimal) LIWORK.

LIWORK
INTEGER.

The dimension of the array IWORK. LIWORK >= 10*N. If LIWORK = -1, then a workspace query is assumed; the routine only calculates the optimal sizes of the WORK and IWORK arrays, returns these values as the first entries of the WORK and IWORK arrays, and no error message related to LWORK or LIWORK is issued by XERBLA.

INFO
INTEGER.
  • = 0: successful exit
  • < 0: if INFO = -i, the i-th argument had an illegal value
  • > 0: Internal error
