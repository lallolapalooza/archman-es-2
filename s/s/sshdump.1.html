SSHDUMP(1)   SSHDUMP(1)

NOMBRE

sshdump - Proporciona interfaces para capturar paquetes de un host remoto a través de SSH utilizando un binario de captura remoto.

SINOPSIS

sshdump [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interfaz> ] [ --extcap-config ] [ --extcap-capture-filter=<filtro de captura> ] [ --capture ] [ --fifo=<ruta al archivo o tubería> ] [ --remote-host=<dirección IP> ] [ --remote-port=<puerto TCP> ] [ --remote-username=<nombre de usuario> ] [ --remote-password=<contraseña> ] [ --sshkey=<ruta a clave privada SSH> ] [ --sshkey-passphrase=<frase de contraseña de clave privada> ] [ --proxycommand=<comando proxy SSH> ] [ --remote-interface=<interfaz> ] [ --remote-capture-command-select=<selección de comando de captura> ] [ --remote-capture-command=<comando de captura> ] [ --remote-priv=<selección de comando de elevación de privilegios> ] [ --remote-priv-user=<nombre de usuario privilegiado> ] [ --remote-noprom ] [ --remote-filter=<filtro de captura remoto> ] [ --remote-count=<número> ]

sshdump --extcap-interfaces

sshdump --extcap-interface=<interfaz> --extcap-dlts

sshdump --extcap-interface=<interfaz> --extcap-config

sshdump --extcap-interface=<interfaz> --fifo=<ruta al archivo o tubería> --capture --remote-host=mihostremoto --remote-port=22 --remote-username=usuario --remote-interface=eth2 --remote-capture-command='tcpdump -U -i eth0 -w-'

DESCRIPCIÓN

Sshdump es una herramienta extcap que permite ejecutar una herramienta de captura remota a través de una conexión SSH. El requisito es que el ejecutable de captura debe tener las capacidades para capturar desde la interfaz deseada.

La funcionalidad es equivalente a ejecutar comandos como:

$ ssh usuario_remoto@host_remoto -p 22222 'tcpdump -U -i INTERFAZ -w -' &
$ wireshark ARCHIVO
$ ssh usuario_remoto@host_remoto '/sbin/dumpcap -i INTERFAZ -P -w - -f "not port 22"' > ARCHIVO &
$ wireshark ARCHIVO
$ ssh algunhost dumpcap -P -w - -f udp | tshark -i -

Normalmente, sshdump no se invoca directamente. En su lugar, se puede configurar a través de la interfaz gráfica de usuario de Wireshark o su línea de comandos. Lo siguiente iniciará Wireshark y comenzará a capturar desde el host hostremoto:

$ wireshark '-oextcap.sshdump.remotehost:"hostremoto"' -i sshdump -k

Para controlar explícitamente el comando de captura remoto:

$ wireshark '-oextcap.sshdump.remotehost:"hostremoto"' \
            '-oextcap.sshdump.remotecapturecommand:"tcpdump -i eth0 -Uw- not port 22"' \
            -i sshdump -k

Interfaces soportadas:

1.sshdump

OPCIONES

--help

Imprime los argumentos del programa.

--version

Imprime la versión del programa.

--extcap-interfaces

Lista las interfaces disponibles.

--extcap-interface=<interfaz>

Usa las interfaces especificadas.

--extcap-dlts

Lista los DLT de la interfaz especificada.

--extcap-config

Lista las opciones de configuración de la interfaz especificada.

--extcap-capture-filter=<filtro de captura>

El filtro de captura. Corresponde al valor proporcionado a través de la opción tshark -f, y al campo Filtro de captura junto a la lista de interfaces en la interfaz de Wireshark.

--capture

Inicia la captura desde la interfaz especificada y escribe los datos brutos de los paquetes en la ubicación especificada por --fifo.

--fifo=<ruta al archivo o tubería>

Guarda los paquetes capturados en un archivo o los envía a través de una tubería.

--remote-host=<host remoto>

La dirección del host remoto para la captura.

--remote-port=<puerto remoto>

El puerto SSH del host remoto.

--remote-username=<nombre de usuario>

El nombre de usuario para la autenticación SSH.

--remote-password=<contraseña>

La contraseña a utilizar (si no se utilizan ssh-agent y pubkey). ADVERTENCIA: las contraseñas se almacenan en texto plano y son visibles para todos los usuarios de este sistema. Se recomienda utilizar archivos de clave con un agente SSH.

--sshkey=<ruta a la clave privada SSH>

La ruta a una clave privada para autenticación. NOTA: Solo se soporta el formato de par clave/valor de OPENSSH.

--sshkey-passphrase=<frase de contraseña de clave privada SSH>

La frase de contraseña para la clave privada de autenticación.

--proxycommand=<comando proxy>

El comando a utilizar como proxy para la conexión SSH.

--remote-interface=<interfaz remota>

La interfaz de red remota desde la cual capturar.

--remote-capture-command-select=<selección de comando de captura>

La selección del soporte incorporado para comandos de captura remotos. Ya sea dumpcap para un comando de captura remoto que utiliza dumpcap, tcpdump para un comando de captura remoto que utiliza tcpdump, o other, donde el comando de captura remoto se debe proporcionar con la opción --remote-capture-command.

Tenga en cuenta que seleccionar dumpcap permite especificar múltiples interfaces de captura como una lista separada por espacios, mientras que tcpdump no.

--remote-capture-command=<comando de captura>

Un comando de captura remoto personalizado que produce el flujo remoto que se muestra en Wireshark. El comando debe ser capaz de producir un flujo PCAP escrito en STDOUT. Vea abajo para más ejemplos.

Si utiliza tcpdump, utilice la opción -w- para asegurar que los paquetes se escriban en la salida estándar (stdout). Incluya la opción -U para escribir los paquetes tan pronto como se reciban.

Cuando se especifica, este comando se utilizará tal cual; las opciones como el filtro de captura (--extcap-capture-filter) no se añadirán.

--remote-priv=<selección de comando de elevación de privilegios>

El comando a utilizar para lograr la elevación de privilegios para capturar en el host remoto. Ninguno, sudo o doas.

--remote-priv-user=<nombre de usuario privilegiado>

Si se utiliza un comando para lograr la elevación de privilegios para capturar en el host remoto, esto puede requerir un nombre de usuario. Si es necesario, utilice esta opción para proporcionar ese nombre de usuario.

--remote-filter=<filtro de captura>

El filtro de captura remoto. Corresponde al valor proporcionado a través de la opción tshark -f, y al campo Filtro de captura junto a la lista de interfaces en la interfaz de Wireshark.

--remote-count=<número>

El número de paquetes a capturar.

EJEMPLOS

Para ver los argumentos del programa:

sshdump --help

Para ver la versión del programa:

sshdump --version

Para ver las interfaces:

sshdump --extcap-interfaces

Solo se soporta una interfaz (sshdump).

Salida de ejemplo

interface {value=sshdump}{display=Captura remota SSH}

Para ver los DLT de la interfaz:

sshdump --extcap-interface=sshdump --extcap-dlts

Salida de ejemplo

dlt {number=147}{name=sshdump}{display=DLT dependiente de captura remota}

Para capturar:

sshdump --extcap-interface=sshdump --fifo=/tmp/ssh.pcap --capture --remote-host 192.168.1.10
--remote-username user --remote-filter "not port 22"

Para usar diferentes binarios de captura:

sshdump --extcap-interface=sshdump --fifo=/tmp/ssh.pcap --capture --remote-host 192.168.1.10
--remote-username user --remote-priv sudo --remote-capture-command-select tcpdump
--remote-interface eth0 --remote-noprom
sshdump --extcap-interface=sshdump --fifo=/tmp/ssh.pcap --capture --remote-host 192.168.1.10
--remote-capture-command='dumpcap -i eth0 -P -w -'
sshdump --extcap-interface=sshdump --fifo=/tmp/ssh.pcap --capture --remote-host 192.168.1.10
--remote-capture-command='sudo tcpdump -i eth0 -U -w -'

Nota

Para detener la captura, presione CTRL+C o mate/termine la aplicación.

El binario sshdump se puede renombrar para admitir múltiples instancias. Por ejemplo, si queremos que sshdump aparezca dos veces en wireshark (para manejar múltiples perfiles, por ejemplo), podemos copiar sshdump a sshdump-host1 y sshdump-host2. Cada binario mostrará un nombre de interfaz igual al nombre del ejecutable. Estos ejecutables, al no ser "sshdump", aparecerán como "versión personalizada" en la descripción de la interfaz.
