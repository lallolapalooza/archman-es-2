Documentación de Función/Subrutina

subroutine ssymv (character uplo, integer n, real alpha, real, dimension(lda,*) a, integer lda, real, dimension(*) x, integer incx, real beta, real, dimension(*) y, integer incy)

SSYMV

Propósito:

!>
!> SSYMV  realiza la operación matriz-vector
!>
!>    y := alpha*A*x + beta*y,
!>
!> donde alpha y beta son escalares, x e y son vectores de n elementos y
!> A es una matriz simétrica de n por n.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la parte triangular superior o inferior
!>           de la matriz A se va a referenciar como sigue:
!>
!>              UPLO = 'U' o 'u'   Solo se referenciará la parte triangular superior de A.
!>
!>              UPLO = 'L' o 'l'   Solo se referenciará la parte triangular inferior de A.
!>

N

!>          N es INTEGER
!>           Al entrar, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

ALPHA

!>          ALPHA es REAL
!>           Al entrar, ALPHA especifica el escalar alpha.
!>

A

!>          A es una matriz REAL, dimensión ( LDA, N )
!>           Antes de entrar con UPLO = 'U' o 'u', la parte superior de n por n
!>           de la matriz A debe contener la parte triangular superior de la matriz
!>           simétrica y la parte triangular estrictamente inferior de A no se referencia.
!>           Antes de entrar con UPLO = 'L' o 'l', la parte inferior de n por n
!>           de la matriz A debe contener la parte triangular inferior de la matriz
!>           simétrica y la parte triangular estrictamente superior de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A tal como se declara
!>           en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, n ).
!>

X

!>          X es una matriz REAL, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de entrar, la matriz X incrementada debe contener el vector
!>           de n elementos x.
!>

INCX

!>          INCX es INTEGER
!>           Al entrar, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>

BETA

!>          BETA es REAL
!>           Al entrar, BETA especifica el escalar beta. Cuando BETA se
!>           suministra como cero, Y no necesita ser establecido al entrar.
!>

Y

!>          Y es una matriz REAL, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ).
!>           Antes de entrar, la matriz Y incrementada debe contener el vector
!>           de n elementos y. Al salir, Y se sobrescribe con el vector
!>           actualizado y.
!>

INCY

!>          INCY es INTEGER
!>           Al entrar, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>
