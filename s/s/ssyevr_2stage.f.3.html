SINOPSIS

Funciones/Subrutinas


subrutina ssyevr_2stage (jobz, range, uplo, n, a, lda, vl, vu, il, iu, abstol, m, w, z, ldz, isuppz, work, lwork, iwork, liwork, info)
SSYEVR_2STAGE calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices SY

Documentación de la Función/Subrutina

subrutina ssyevr_2stage (carácter jobz, carácter range, carácter uplo, entero n, real, dimensión( lda, * ) a, entero lda, real vl, real vu, entero il, entero iu, real abstol, entero m, real, dimensión( * ) w, real, dimensión( ldz, * ) z, entero ldz, entero, dimensión( * ) isuppz, real, dimensión( * ) work, entero lwork, entero, dimensión( * ) iwork, entero liwork, entero info)

SSYEVR_2STAGE calcula los valores propios seleccionados y, opcionalmente, los vectores propios de matrices simétricas reales A utilizando la técnica de 2 etapas para la reducción a tridiagonal. Los valores y vectores propios pueden seleccionarse especificando un rango de valores o un rango de índices para los valores propios deseados.

Propósito:

!>
!> SSYEVR_2STAGE calcula los valores propios seleccionados y, opcionalmente, los vectores propios
!> de una matriz simétrica real A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal. Calcula los valores y vectores propios mediante llamadas a SSYTRD
!> y SSTEMR. SSTEMR calcula los valores propios mediante el algoritmo dqds, mientras que los
!> vectores propios ortogonales se calculan a partir de varias representaciones L D L^T
!> (también conocidas como Representaciones Relativamente Robustas). La
!> ortogonalización de Gram-Schmidt se evita tanto como sea posible. Más específicamente,
!> los distintos pasos del algoritmo son los siguientes:
!>
!> Para cada bloque no reducido (submatriz) de T,
!>    (a) Calcula T - sigma I  = L D L^T, de modo que L y D
!>        definen todos los valores propios deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los valores y vectores propios.
!>        La representación estándar (no factorizada) de la matriz tridiagonal
!>        T no tiene esta propiedad en general.
!>    (b) Calcula los valores propios con la precisión adecuada.
!>        Si se desean los vectores propios, el algoritmo alcanza la precisión completa de
!>        los valores propios calculados justo antes de que tengan que calcularse los
!>        vectores correspondientes, véanse los pasos c) y d).
!>    (c) Para cada clúster de valores propios cercanos, selecciona un nuevo
!>        desplazamiento cercano al clúster, encuentra una nueva factorización y refina
!>        los valores propios desplazados con la precisión adecuada.
!>    (d) Para cada valor propio con una separación relativa suficientemente grande, calcula
!>        el vector propio correspondiente formando una factorización retorcida que revele el rango.
!>        Vuelve a (c) para los clústeres que queden.
!>
!> La precisión deseada de la salida puede especificarse mediante el parámetro de entrada
!> ABSTOL.
!>
!> Para más detalles, véase la documentación de SSTEMR y:
!> - Inderjit S. Dhillon y Beresford N. Parlett:
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, agosto de 2004.
!> - Inderjit Dhillon y Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, vol. 25,
!>   2004. También LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mayo de 1997.
!>
!>
!> Nota 1: SSYEVR_2STAGE llama a SSTEMR cuando se solicita el espectro completo
!> en máquinas que cumplen el estándar de punto flotante ieee-754.
!> SSYEVR_2STAGE llama a SSTEBZ y SSTEIN en máquinas no ieee y
!> cuando se realizan solicitudes de espectro parcial.
!>
!> La ejecución normal de SSTEMR puede crear NaNs e infinitos y
!> por lo tanto, puede abortar debido a una excepción de punto flotante en entornos
!> que no manejan NaNs e infinitos de la manera predeterminada estándar ieee.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Solo se calculan los valores propios;
!>          = 'V':  Se calculan los valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>          Para RANGE = 'V' o 'I' y IU - IL < N - 1, se llaman SSTEBZ y
!>          SSTEIN
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la
!>          parte triangular superior N-por-N que lidera contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior N-por-N que lidera contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluida la diagonal, se destruye.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es ENTERO
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es ENTERO
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergido
!>          cuando se determina que se encuentra en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o
!>          igual a cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Véase  de Demmel y
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si se desea alta precisión relativa, establezca ABSTOL a
!>          SLAMCH( 'Safe minimum' ). Hacer esto garantizará que
!>          los valores propios se calculen con alta precisión relativa cuando
!>          sea posible en futuras versiones. El código actual no
!>          hace ninguna garantía sobre alta precisión relativa, pero
!>          las futuras versiones lo harán. Véase J. Barlow y J. Demmel,
!>          , LAPACK Working Note #7, para una discusión
!>          sobre qué matrices definen sus valores propios con alta precisión relativa.
!>

M

!>          M es un ENTERO
!>          El número total de valores propios encontrados. 0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array REAL de dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es un array REAL de dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>          Suministrar N columnas siempre es seguro.
!>

LDZ

!>          LDZ es un ENTERO
!>          La dimensión principal del array Z. LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ es un array de ENTEROS de dimensión ( 2*max(1,M) )
!>          El soporte de los vectores propios en Z, es decir, los índices
!>          que indican los elementos distintos de cero en Z. El i-ésimo vector propio
!>          es distinto de cero solo en los elementos ISUPPZ( 2*i-1 ) hasta
!>          ISUPPZ( 2*i ). Esta es una salida de SSTEMR (matriz tridiagonal).
!>          El soporte de los vectores propios de A es típicamente
!>          1:N debido a las transformaciones ortogonales aplicadas por SORMTR.
!>          Implementado solo para RANGE = 'A' o 'I' e IU - IL = N - 1
!>

WORK

!>          WORK es un array REAL de dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es un ENTERO
!>          La dimensión del array WORK.
!>          Si N <= 1, LWORK debe ser al menos 1.
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, 26*N, dimension) donde
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + 5*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 5*N
!>                                   donde KD es el tamaño del bloque de la reducción,
!>                                   FACTOPTNB es el tamaño del bloque utilizado por el algoritmo QR o LQ,
!>                                   normalmente FACTOPTNB=128 es una buena elección
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   la compilación openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Todavía no disponible.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

IWORK

!>          IWORK es un array de ENTEROS de dimensión (MAX(1,LIWORK))
!>          Al salir, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es un ENTERO
!>          La dimensión del array IWORK.
!>          Si N <= 1, LIWORK >= 1, de lo contrario LIWORK >= 10*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array IWORK,
!>          devuelve este valor como la primera entrada del array IWORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LIWORK.
!>

INFO

!>          INFO es un ENTERO
!>          = 0: Salida exitosa
!>          < 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: Error interno
!>
