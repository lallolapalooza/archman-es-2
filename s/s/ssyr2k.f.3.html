Documentación de función/subrutina

subroutine ssyr2k (character uplo, character trans, integer n, integer k, real alpha, real, dimension(lda,*) a, integer lda, real, dimension(ldb,*) b, integer ldb, real beta, real, dimension(ldc,*) c, integer ldc)

SSYR2K

Propósito:

!>
!> SSYR2K  realiza una de las operaciones simétricas de rango 2k
!>
!>    C := alpha*A*B**T + alpha*B*A**T + beta*C,
!>
!> o
!>
!>    C := alpha*A**T*B + alpha*B**T*A + beta*C,
!>
!> donde  alpha y beta  son escalares, C es una  matriz simétrica de  n por n
!> y  A y B  son  matrices de  n por k  en el  primer  caso y  matrices de k por n
!> en el segundo caso.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar,   UPLO  especifica  si  la parte  triangular  superior  o inferior
!>           de la  matriz  C  debe  ser referenciada  como  sigue:
!>
!>              UPLO = 'U' o 'u'   Sólo se hace referencia a la parte triangular superior de C.
!>
!>              UPLO = 'L' o 'l'   Sólo se hace referencia a la parte triangular inferior de C.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           Al entrar,  TRANS  especifica la operación a realizar de la siguiente manera:
!>
!>              TRANS = 'N' o 'n'   C := alpha*A*B**T + alpha*B*A**T +
!>                                        beta*C.
!>
!>              TRANS = 'T' o 't'   C := alpha*A**T*B + alpha*B**T*A +
!>                                        beta*C.
!>
!>              TRANS = 'C' o 'c'   C := alpha*A**T*B + alpha*B**T*A +
!>                                        beta*C.
!>

N

!>          N es INTEGER
!>           Al entrar,  N  especifica el orden de la matriz C.  N debe ser
!>           al menos cero.
!>

K

!>          K es INTEGER
!>           Al entrar con  TRANS = 'N' o 'n',  K  especifica el número
!>           de  columnas  de las  matrices  A y B,  y al  entrar con
!>           TRANS = 'T' o 't' o 'C' o 'c',  K  especifica el número
!>           de  filas  de las  matrices  A y B.  K debe ser  al menos  cero.
!>

ALPHA

!>          ALPHA es REAL
!>           Al entrar, ALPHA especifica el escalar alpha.
!>

A

!>          A es matriz REAL, dimension ( LDA, ka ), donde ka es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de entrar con  TRANS = 'N' o 'n',  la  parte principal de  n por k
!>           de la matriz  A  debe contener la matriz  A,  en caso contrario,
!>           la parte principal de  k por n  de la matriz  A  debe contener la
!>           matriz A.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A tal como se declara
!>           en  el  programa  (sub)llamador.   Cuando  TRANS = 'N' o 'n'
!>           entonces  LDA debe ser al menos  max( 1, n ), en caso contrario  LDA debe
!>           ser al menos  max( 1, k ).
!>

B

!>          B es matriz REAL, dimension ( LDB, kb ), donde kb es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de entrar con  TRANS = 'N' o 'n',  la  parte principal de  n por k
!>           de la matriz  B  debe contener la matriz  B,  en caso contrario,
!>           la parte principal de  k por n  de la matriz  B  debe contener la
!>           matriz B.
!>

LDB

!>          LDB es INTEGER
!>           Al entrar, LDB especifica la primera dimensión de B tal como se declara
!>           en  el  programa  (sub)llamador.   Cuando  TRANS = 'N' o 'n'
!>           entonces  LDB debe ser al menos  max( 1, n ), en caso contrario  LDB debe
!>           ser al menos  max( 1, k ).
!>

BETA

!>          BETA es REAL
!>           Al entrar, BETA especifica el escalar beta.
!>

C

!>          C es matriz REAL, dimension ( LDC, N )
!>           Antes de entrar con  UPLO = 'U' o 'u',  la parte principal de  n por n
!>           superior triangular de la matriz C debe contener la parte
!>           triangular superior  de la matriz simétrica  y la parte triangular
!>           estrictamente inferior de C no se referencia.  Al salir, la
!>           parte triangular superior de la matriz  C se sobrescribe con la
!>           parte triangular superior de la matriz actualizada.
!>           Antes de entrar con  UPLO = 'L' o 'l',  la parte principal de  n por n
!>           inferior triangular de la matriz C debe contener la parte
!>           triangular inferior  de la matriz simétrica  y la parte triangular
!>           estrictamente superior de C no se referencia.  Al salir, la
!>           parte triangular inferior de la matriz  C se sobrescribe con la
!>           parte triangular inferior de la matriz actualizada.
!>

LDC

!>          LDC es INTEGER
!>           Al entrar, LDC especifica la primera dimensión de C tal como se declara
!>           en  el  programa  (sub)llamador.   LDC  debe  ser  al menos
!>           max( 1, n ).
!>
