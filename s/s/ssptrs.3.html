subrutina ssptrs (character uplo, integer n, integer nrhs, real, dimension( * ) ap, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, integer info)

SSPTRS

Propósito

!>
!> SSPTRS resuelve un sistema de ecuaciones lineales A*X = B con una matriz A
!> real simétrica almacenada en formato empaquetado utilizando la factorización
!> A = U*D*U**T o A = L*D*L**T calculada por SSPTRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, la forma es A = U*D*U**T;
!>          = 'L':  Triangular inferior, la forma es A = L*D*L**T.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AP

!>          AP es array REAL, dimension (N*(N+1)/2)
!>          La matriz diagonal por bloques D y los multiplicadores utilizados para
!>          obtener el factor U o L calculados por SSPTRF, almacenados como
!>          una matriz triangular empaquetada.
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como fueron determinados por SSPTRF.
!>

B

!>          B es array REAL, dimension (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
