SSBGVX

Propósito:

!>
!> SSBGVX calcula los valores propios seleccionados, y opcionalmente, los vectores propios
!> de un problema de valores propios generalizado simétrico-definido real y de banda,
!> de la forma A*x=(lambda)*B*x. Aquí A y B se suponen simétricas
!> y de banda, y B también es definida positiva. Los valores propios y
!> los vectores propios se pueden seleccionar especificando todos los valores propios,
!> un rango de valores o un rango de índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

KA

!>          KA es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KA >= 0.
!>

KB

!>          KB es INTEGER
!>          El número de superdiagonales de la matriz B si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KB >= 0.
!>

AB

!>          AB es un array REAL, de dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda simétrica
!>          A, almacenado en las primeras ka+1 filas del array. La
!>          columna j de A se almacena en la columna j del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) para max(1,j-ka)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+ka).
!>
!>          En la salida, el contenido de AB se destruye.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KA+1.
!>

BB

!>          BB es un array REAL, de dimensión (LDBB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda simétrica
!>          B, almacenado en las primeras kb+1 filas del array. La
!>          columna j de B se almacena en la columna j del array BB
!>          de la siguiente manera:
!>          si UPLO = 'U', BB(ka+1+i-j,j) = B(i,j) para max(1,j-kb)<=i<=j;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) para j<=i<=min(n,j+kb).
!>
!>          En la salida, el factor S de la factorización Cholesky dividida
!>          B = S**T*S, tal como es devuelto por SPBSTF.
!>

LDBB

!>          LDBB es INTEGER
!>          La dimensión principal del array BB.  LDBB >= KB+1.
!>

Q

!>          Q es un array REAL, de dimensión (LDQ, N)
!>          Si JOBZ = 'V', la matriz n x n utilizada en la reducción de
!>          A*x = (lambda)*B*x a la forma estándar, es decir, C*x = (lambda)*x,
!>          y en consecuencia C a la forma tridiagonal.
!>          Si JOBZ = 'N', el array Q no se utiliza.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.  Si JOBZ = 'N',
!>          LDQ >= 1. Si JOBZ = 'V', LDQ >= max(1,N).
!>

VL

!>          VL es REAL
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se utiliza si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se utiliza si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se utiliza si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se utiliza si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluta para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de anchura menor o igual que
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual que cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL se
!>          establezca en el doble del umbral de subdesbordamiento 2*SLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*SLAMCH('S').
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array REAL, de dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es un array REAL, de dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
!>          vectores propios, con la i-ésima columna de Z conteniendo el
!>          vector propio asociado a W(i). Los vectores propios están
!>          normalizados de forma que Z**T*B*Z = I.
!>          Si JOBZ = 'N', entonces Z no se utiliza.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array REAL, de dimensión (7*N)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (5*N)
!>

IFAIL

!>          IFAIL es un array INTEGER, de dimensión (M)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero.  Si INFO > 0, entonces IFAIL contiene los
!>

C

Function/Subroutine Documentation

SSBGVX computes the eigenvalues and, optionally, eigenvectors of a real general banded matrix A in the same location as the banded Cholesky factor of a real general positive definite banded matrix B.

Arguments

JOBZ (CHARACTER*1).
On entry, JOBZ specifies whether the eigenvectors are to be computed:

    = 'N':  Compute only the eigenvalues.
    = 'V':  Compute the eigenvalues and eigenvectors.

RANGE (CHARACTER*1).
On entry, RANGE specifies the range of eigenvalues to be computed:

    = 'A':  All eigenvalues will be computed.
    = 'V':  All eigenvalues in the half-open interval (VL, VU] will be
            computed, in this case VL and VU must be set.
    = 'I':  The IL-th and IU-th eigenvalues, in ascending order, will be
            computed. In this case IL and IU must be set.

UPLO (CHARACTER*1).
On entry, UPLO specifies whether B is an upper or lower banded matrix:

    = 'U':  B is upper banded.
    = 'L':  B is lower banded.

N (INTEGER).
On entry, N is the order of the matrices A and B. N >= 0.

M (INTEGER).
On exit, M is the number of eigenvalues found in the specified range.

NB (INTEGER).
On entry, NB is the bandwidth of matrix A. NB >= 0.

AB (REAL).
On entry, AB is a two-dimensional array, dimension (LDAB,K), where K=2*NB+1.

LDAB (INTEGER).
On entry, LDAB is the leading dimension of the array AB. LDAB >= K.

PB (REAL).
On entry, PB is a two-dimensional array, dimension (LDPB,K), where K=2*NB+1.

LDPB (INTEGER).
On entry, LDPB is the leading dimension of the array PB. LDPB >= K.

Q (REAL).
On exit, Q is a two-dimensional array, dimension (LDQ,M). If JOBZ = 'V', the columns of Q are the eigenvectors of A corresponding to the selected eigenvalues in the array G. The eigenvectors are normalized so that their left and right eigenvectors (in the generalized eigenvalue problem A*x = lambda*B*x) both have Euclidean norm equal to 1.

LDQ (INTEGER).
On entry, LDQ is the leading dimension of the array Q. If JOBZ = 'V', then LDQ >= N.

VL (REAL).
On entry, if RANGE = 'V', VL and VU specify the lower and upper bounds of the interval to be searched for eigenvalues.

VU (REAL).
On entry, if RANGE = 'V', VL and VU specify the lower and upper bounds of the interval to be searched for eigenvalues.

IL (INTEGER).
On entry, if RANGE = 'I', IL specifies the selection of the lower bound for the range of eigenvalues to be computed.

IU (INTEGER).
On entry, if RANGE = 'I', IU specifies the selection of the upper bound for the range of eigenvalues to be computed.

OFFG (REAL).
On entry, OFFG is the scalar offset to be added to the matrix G.

G (REAL).
On entry, G is a two-dimensional array, dimension (LDG,K), where K=2*NB+1. The matrix G = B*inv(A) + OFFG*I. G must be banded with the same bandwidth as A and B.

LDG (INTEGER).
On entry, LDG is the leading dimension of the array G. LDG >= K.

WORK (REAL).
On exit, WORK(1) is the minimum required dimension of WORK.

IWORK (INTEGER).
On exit, IWORK(1) is the minimum required dimension of IWORK.

INFO (INTEGER).
= 0: successful exit
< 0: if INFO = -i, then the i-th argument had an illegal value.
> 0: if INFO = i, then i eigenvectors failed to converge. Their indices are stored in IFAIL.
