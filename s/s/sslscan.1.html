SSLSCAN(1) Manual de comandos generales SSLSCAN(1)

NOMBRE

sslscan - Escáner SSL/TLS rápido

SINOPSIS

sslscan [opciones] [host:puerto | host]

DESCRIPCIÓN

sslscan consulta servicios SSL/TLS (como HTTPS) e informa sobre las versiones de protocolo, conjuntos de cifrado, intercambios de claves, algoritmos de firma y certificados en uso. Esto ayuda al usuario a comprender qué parámetros son débiles desde el punto de vista de la seguridad. sslscan también puede exportar los resultados a un archivo XML para que sean fácilmente consumidos por programas externos.

La salida de terminal está codificada por colores de la siguiente manera:

Fondo Rojo Cifrados NULL (sin cifrado) o cifrados anónimos (sin verificación del par)
Rojo Cifrados y algoritmos con vulnerabilidades demostradas, o que generalmente se consideran no confiables.
Amarillo Cifrados y algoritmos con debilidades conocidas o que todavía son demasiado nuevos para ser ampliamente confiables, pero que no se consideran generalmente explotables (incluso según los estándares de vulnerabilidades de TLS).
Verde Cifrados y algoritmos que se alinean con las mejores prácticas actuales recomendadas.

OPCIONES

--help

Muestra un resumen de las opciones
--targets=<archivo>
Un archivo que contiene una lista de hosts para verificar. Los hosts pueden suministrarse con puertos (es decir, host:puerto). Un objetivo por línea.
--sni-name=<nombre>
Usar un nombre de host diferente para SNI
--ipv4, -4

Forzar la resolución DNS IPv4. Por defecto, intenta IPv4 y, si falla, recurre a IPv6.
--ipv6, -6

Forzar la resolución DNS IPv6. Por defecto, intenta IPv4 y, si falla, recurre a IPv6.
--show-certificate
Mostrar información del certificado.
--show-certificates
Mostrar la cadena de certificados completa.
--no-check-certificate
--no-check-certificate No marcar certificados firmados con algoritmos débiles (MD5 y SHA-1) o claves RSA cortas (<2048 bits).
--show-client-cas
Mostrar una lista de las CA que el servidor permite para autenticación de cliente. Estará en blanco para servidores IIS/Schannel.
--show-ciphers
Mostrar una lista completa de cifrados compatibles con sslscan.
--show-cipher-ids
Imprimir los IDs de cifrado hexadecimales.
--iana-names
Usar nombres de cifrado de IANA/RFC en lugar de los de OpenSSL.
--show-times
Mostrar el tiempo empleado en cada handshake en milisegundos. Tenga en cuenta que solo se realiza una solicitud con cada cifrado, y que el tamaño del ClientHello no es constante, por lo que esto no debe usarse para pruebas de rendimiento o benchmarking adecuadas.

Es posible que también desee utilizar --no-cipher-details para que la salida sea un poco más clara.

--ssl2

Solo verificar si SSLv2 está habilitado.
--ssl3

Solo verificar si SSLv3 está habilitado.
--tls10

Solo verificar cifrados TLS 1.0.
--tls11

Solo verificar cifrados TLS 1.1.
--tls12

Solo verificar cifrados TLS 1.2.
--tls13

Solo verificar cifrados TLS 1.3.
--tlsall

Solo verificar cifrados TLS (versiones 1.0, 1.1, 1.2 y 1.3).
--ocsp

Mostrar estado OCSP.
--pk=<archivo>
Un archivo que contiene la clave privada o un archivo PKCS#12 que contiene un par de clave privada/certificado (producido por MSIE y Netscape).
--pkpass=<contraseña>
La contraseña para la clave privada o el archivo PKCS#12.
--certs=<archivo>
Un archivo que contiene certificados de cliente en formato PEM/ASN1.
--no-ciphersuites
No buscar conjuntos de cifrado compatibles.
--no-fallback
No verificar el valor del conjunto de cifrado de señal de caída TLS (fallback).
--no-renegotiation
No verificar la renegociación TLS segura.
--no-compression
No verificar la compresión TLS (CRIME).
--no-heartbleed
No verificar OpenSSL Heartbleed (CVE-2014-0160).
--no-groups
No enumerar grupos de intercambio de claves.
--show-sigs
Enumerar algoritmos de firma.
--starttls-ftp
Configuración STARTTLS para FTP.
--starttls-imap
Configuración STARTTLS para IMAP.
--starttls-irc
Configuración STARTTLS para IRC.
--starttls-ldap
Configuración STARTTLS para LDAP.
--starttls-pop3
Configuración STARTTLS para POP3.
--starttls-smtp
Configuración STARTTLS para SMTP.
--starttls-mysql
Configuración STARTTLS para MySQL.
--starttls-xmpp
Configuración STARTTLS para XMPP.
--starttls-psql
Configuración STARTTLS para PostgreSQL.
--xmpp-server
Realizar una conexión XMPP de servidor a servidor. Intente esto si --starttls-xmpp está fallando.
--rdp

Enviar preámbulo RDP antes de iniciar el escaneo.
--bugs

Habilita soluciones alternativas para fallos de SSL.
--timeout=<seg>

Establecer tiempo de espera del socket. Útil para hosts que no responden a cifrados que no entienden. Por defecto es 3s.
--connect-timeout=<seg>

Establecer tiempo de espera de conexión inicial. Útil para hosts que responden lentamente a la conexión inicial(). Por defecto es 75s.
--sleep=<ms>

Pausa entre conexiones. Útil en servicios SMTP STARTTLS, o cualquier otra cosa que esté realizando limitación de velocidad. Por defecto está deshabilitado.
--xml=<archivo>

Exportar resultados a un archivo XML. - puede ser usado para significar stdout.
--version
Mostrar la versión del programa.
--verbose
Mostrar salida detallada.
--no-cipher-details

Ocultar el nombre de la curva EC de NIST y la longitud de la clave EDH/RSA.
--no-colour

Deshabilitar la salida con color.

EJEMPLOS

Escanear un servidor HTTPS local

sslscan localhost
sslscan 127.0.0.1
sslscan 127.0.0.1:443
sslscan [::1]
sslscan [::1]:443
