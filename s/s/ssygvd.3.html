Documentación de la Función/Subrutina

subrutina ssygvd (integer itype, character jobz, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) w, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSYGVD

Propósito:

!>
!> SSYGVD calcula todos los valores propios, y opcionalmente, los vectores propios
!> de un problema de autovalores generalizado simétrico-definido real, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x. Aquí A y
!> B se asumen simétricas y B también es definida positiva.
!> Si se desean vectores propios, utiliza un algoritmo de divide y vencerás.
!>
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la
!>          parte triangular superior N-por-N líder de A contiene la
!>          parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior N-por-N líder de A contiene
!>          la parte triangular inferior de la matriz A.
!>
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene la
!>          matriz Z de vectores propios. Los vectores propios están normalizados
!>          de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**T*B*Z = I;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces en la salida el triángulo superior (si UPLO='U')
!>          o el triángulo inferior (si UPLO='L') de A, incluyendo la
!>          diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

B

!>          B es array REAL, dimensión (LDB, N)
!>          En la entrada, la matriz simétrica B. Si UPLO = 'U', la
!>          parte triangular superior N-por-N líder de B contiene la
!>          parte triangular superior de la matriz B. Si UPLO = 'L',
!>          la parte triangular inferior N-por-N líder de B contiene
!>          la parte triangular inferior de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz se
!>          sobrescribe con el factor triangular U o L de la factorización de Cholesky
!>          B = U**T*U o B = L*L**T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder del array B.  LDB >= max(1,N).
!>

W

!>          W es array REAL, dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

WORK

!>          WORK es array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK >= 1.
!>          Si JOBZ = 'N' y N > 1, LWORK >= 2*N+1.
!>          Si JOBZ = 'V' y N > 1, LWORK >= 1 + 6*N + 2*N**2.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK y IWORK,
!>          devuelve estos valores como las primeras entradas de los arrays WORK
!>          y IWORK, y XERBLA no emite ningún mensaje de error relacionado con LWORK o
!>          LIWORK.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si N <= 1,                LIWORK >= 1.
!>          Si JOBZ  = 'N' y N > 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK y IWORK, y XERBLA no emite ningún mensaje de error relacionado con
!>          LWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  SPOTRF o SSYEVD devolvieron un código de error:
!>             <= N:  si INFO = i y JOBZ = 'N', entonces el algoritmo
!>                    no convergió; i elementos fuera de la diagonal de una
!>                    forma tridiagonal intermedia no convergió a
!>                    cero;
!>                    si INFO = i y JOBZ = 'V', entonces el algoritmo
!>                    no pudo calcular un valor propio mientras trabajaba en
!>                    la submatriz situada en las filas y columnas INFO/(N+1)
!>                    hasta mod(INFO,N+1);
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el menor
!>                    principal líder de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon valores ni vectores propios.
!>

Documentación de función/subrutina

SSYGVD y DSYGVD calculan los valores propios y, opcionalmente, los vectores propios de una pareja generalizada de matrices simétricas/hermitianas definidas positivas definidas por el usuario y definidas por el usuario.

ITYPE: Especifica el tipo de problema de valores propios:

  • 1: $A \cdot v = \lambda B \cdot v$
  • 2: $A B \cdot v = \lambda v$
  • 3: $B A \cdot v = \lambda v$

JOBZ: Especifica si se calculan los vectores propios:

  • 'N': Solo se calculan los valores propios.
  • 'V': Se calculan los valores propios y los vectores propios.

UPLO: Especifica si la parte superior o inferior de las matrices se almacena:

  • 'U': La parte superior de A y B está almacenada.
  • 'L': La parte inferior de A y B está almacenada.

N: El orden de las matrices A y B.

A: La matriz de entrada de tamaño N x N.

LDA: El ancho de la matriz A.

B: La matriz de entrada de tamaño N x N.

LDB: El ancho de la matriz B.

W: En la salida, un vector que contiene los valores propios de tamaño N.

WORK: Un buffer de trabajo. Su tamaño se determina durante la ejecución.

LWORK: La longitud del buffer WORK.

IWORK: Un buffer de trabajo entero. Su tamaño se determina durante la ejecución.

LIWORK: La longitud del buffer IWORK.

INFO: Indica el estado de la ejecución:

  • 0: Éxito.
  • < 0: Se encontró un error en el parámetro de entrada.
  • > 0: El algoritmo de convergencia falló al calcular los valores propios.
