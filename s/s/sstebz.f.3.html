Documentación de Función/Subrutina

subroutine sstebz (character range, character order, integer n, real vl, real vu, integer il, integer iu, real abstol, real, dimension( * ) d, real, dimension( * ) e, integer m, integer nsplit, real, dimension( * ) w, integer, dimension( * ) iblock, integer, dimension( * ) isplit, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SSTEBZ

Propósito:

!>
!> SSTEBZ calcula los valores propios de una matriz tridiagonal simétrica
!> T. El usuario puede solicitar todos los valores propios, todos los valores propios
!> en el intervalo semiabierto (VL, VU], o los valores propios IL-ésimo a IU-ésimo.
!>
!> Para evitar el desbordamiento, la matriz debe ser escalada de modo que su
!> elemento más grande no exceda overflow**(1/2) * underflow**(1/4) en valor absoluto, y para mayor
!> precisión, no debe ser mucho menor que eso.
!>
!> Ver W. Kahan, Informe CS41, Departamento de Ciencias de la Computación, Universidad de Stanford, 21 de julio de 1966.
!>

Parámetros

RANGE 
!>          RANGE es CHARACTER*1
!>          = 'A': ()   se encontrarán todos los valores propios.
!>          = 'V': () se encontrarán todos los valores propios en el intervalo
!>                           semiabierto (VL, VU].
!>          = 'I': () se encontrarán los valores propios IL-ésimo a IU-ésimo (de la
!>                           matriz completa).
!>

ORDER

!>          ORDER es CHARACTER*1
!>          = 'B': () los valores propios se agruparán por
!>                              bloque descompuesto (ver IBLOCK, ISPLIT) y
!>                              se ordenarán de menor a mayor dentro del
!>                              bloque.
!>          = 'E': ()
!>                              los valores propios de la matriz completa
!>                              se ordenarán de menor a mayor.
!>

N

!>          N es INTEGER
!>          El orden de la matriz tridiagonal T.  N >= 0.
!>

VL

!>          VL es REAL
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. Los valores propios menores o iguales
!>          a VL, o mayores que VU, no serán devueltos. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. Los valores propios menores o iguales
!>          a VL, o mayores que VU, no serán devueltos. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia absoluta para los valores propios. Un valor propio
!>          (o un grupo) se considera localizado si se ha determinado que yace en un
!>          intervalo cuyo ancho es ABSTOL o menor. Si ABSTOL es menor o igual a cero,
!>          entonces se usará ULP*|T|, donde |T| significa la norma 1 de T.
!>
!>          Los valores propios se computarán de manera más precisa cuando ABSTOL
!>          se establezca en el doble del umbral de desbordamiento 2*SLAMCH('S'), no en cero.
!>

D

!>          D es array REAL, dimension (N)
!>          Los n elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es array REAL, dimension (N-1)
!>          Los (n-1) elementos fuera de la diagonal de la matriz tridiagonal T.
!>

M

!>          M es INTEGER
!>          El número real de valores propios encontrados. 0 <= M <= N.
!>          (Ver también la descripción de INFO=2,3).
!>

NSPLIT

!>          NSPLIT es INTEGER
!>          El número de bloques diagonales en la matriz T.
!>          1 <= NSPLIT <= N.
!>

W

!>          W es array REAL, dimension (N)
!>          A la salida, los primeros M elementos de W contendrán los
!>          valores propios. (SSTEBZ puede usar los N-M elementos restantes como
!>          espacio de trabajo).
!>

IBLOCK

!>          IBLOCK es array INTEGER, dimension (N)
!>          En cada fila/columna j donde E(j) es cero o pequeño, la
!>          matriz T se considera descompuesta en una matriz diagonal por bloques.
!>          A la salida, si INFO = 0, IBLOCK(i) especifica a qué
!>          bloque (de 1 al número de bloques) pertenece el valor propio W(i).
!>          (SSTEBZ puede usar los N-M elementos restantes como
!>          espacio de trabajo).
!>

ISPLIT

!>          ISPLIT es array INTEGER, dimension (N)
!>          Los puntos de división, en los que T se descompone en submatrices.
!>          La primera submatriz consta de las filas/columnas 1 a ISPLIT(1),
!>          la segunda de las filas/columnas ISPLIT(1)+1 hasta ISPLIT(2),
!>          etc., y la NSPLIT-ésima consta de las filas/columnas
!>          ISPLIT(NSPLIT-1)+1 hasta ISPLIT(NSPLIT)=N.
!>          (Solo se utilizarán los primeros NSPLIT elementos, pero
!>          como el usuario no puede saber de antemano qué valor tendrá NSPLIT,
!>          se deben reservar N palabras para ISPLIT).
!>

WORK

!>          WORK es array REAL, dimension (4*N)
!>

IWORK

!>          IWORK es array INTEGER, dimension (3*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  algunos o todos los valores propios no han convergido o
!>                no fueron calculados:
!>                =1 o 3: La bisección falló en converger para algunos
!>                        valores propios; estos valores propios están marcados con un
!>                        número de bloque negativo. El efecto es que los
!>                        valores propios pueden no ser tan precisos como las
!>                        tolerancias absolutas y relativas. Esto es
!>                        generalmente causado por una aritmética inesperadamente imprecisa.
!>                =2 o 3: Solo RANGE='I': No se encontraron todos los valores propios
!>                        IL:IU.
!>                        Efecto: M < IU+1-IL
!>                        Causa:  aritmética no monótona, causando que la
!>                                secuencia de Sturm no sea monótona.
!>                        Solución: recalcular, usando RANGE='A', y seleccionar
!>                                los valores propios IL:IU. En algunos casos,
!>                                aumentar el PARÁMETRO puede hacer que funcione.
!>                =4:    RANGE='I', y el intervalo de Gershgorin
!>                        utilizado inicialmente fue demasiado pequeño. No se calcularon valores propios.
!>                        Causa probable: tu máquina tiene una aritmética de punto flotante descuidada.
!>                        Solución: Aumenta el PARÁMETRO, recompila e inténtalo de nuevo.
!>

Parámetros internos:

/p> 
!>  RELFAC  REAL, por defecto = 2.0e0
!>          La tolerancia relativa. Un intervalo (a,b] está dentro
!>           si  b-a < RELFAC*ulp*max(|a|,|b|),
!>          donde  es la precisión de la máquina (distancia de 1 a
!>          la siguiente mayor precisión de punto flotante).
!>
!>  FUDGE   REAL, por defecto = 2
!>          Un  para ampliar los intervalos de Gershgorin. Idealmente,
!>          un valor de 1 debería funcionar, pero en máquinas con aritmética
!>          imprecisa, este valor necesita ser mayor. El valor por defecto para
!>          las versiones publicadas públicamente debe ser lo suficientemente grande para manejar
!>          la peor máquina existente. Nótese que esto no tiene efecto
!>          en la precisión de la solución.
!>
