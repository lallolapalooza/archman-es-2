SSHMITM(8) Manual del Administrador del Sistema SSHMITM(8)

NOMBRE

sshmitm - SSH hombre en el medio

SINOPSIS

sshmitm [-d] [-I] [-p puerto] host [puerto]

DESCRIPCIÓN


sshmitm actúa como proxy y espía el tráfico SSH redirigido por dnsspoof(8), capturando inicios de sesión con contraseña SSH y, opcionalmente, secuestrando sesiones interactivas. Solo el protocolo SSH versión 1 es (o será alguna vez) compatible; este programa ya es demasiado malvado.

OPCIONES

-d
Habilita la salida de depuración detallada.
-I
Monitoriza / secuestra una sesión interactiva.
-p puerto
Especifica el puerto local en el que escuchar.
host
Especifica el host remoto al que redirigir las conexiones.
puerto
Especifica el puerto remoto al que redirigir las conexiones.

VER TAMBIÉN

dsniff(8), dnsspoof(8)
