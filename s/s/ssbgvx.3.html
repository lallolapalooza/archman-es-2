SSBGVX

Propósito:

!>
!> SSBGVX calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de un problema de valores propios generalizado simétrico-definido real y bandeado,
!> de la forma A*x=(lambda)*B*x. Aquí A y B se asumen simétricos y bandeados,
!> y B también es definido positivo. Los valores propios y vectores propios
!> pueden seleccionarse especificando todos los valores propios, un rango de valores
!> o un rango de índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ is CHARACTER*1
!>          = 'N':  Solo calcular valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

RANGE

!>          RANGE is CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N is INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

KA

!>          KA is INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KA >= 0.
!>

KB

!>          KB is INTEGER
!>          El número de superdiagonales de la matriz B si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KB >= 0.
!>

AB

!>          AB is REAL array, dimension (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          bandeada A, almacenado en las primeras ka+1 filas de la matriz. La
!>          columna j-ésima de A se almacena en la columna j-ésima de la matriz AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) para max(1,j-ka)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+ka).
!>
!>          En la salida, el contenido de AB se destruye.
!>

LDAB

!>          LDAB is INTEGER
!>          La dimensión principal de la matriz AB.  LDAB >= KA+1.
!>

BB

!>          BB is REAL array, dimension (LDBB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          bandeada B, almacenado en las primeras kb+1 filas de la matriz. La
!>          columna j-ésima de B se almacena en la columna j-ésima de la matriz BB
!>          de la siguiente manera:
!>          si UPLO = 'U', BB(ka+1+i-j,j) = B(i,j) para max(1,j-kb)<=i<=j;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) para j<=i<=min(n,j+kb).
!>
!>          En la salida, el factor S de la factorización Cholesky descompuesta
!>          B = S**T*S, devuelto por SPBSTF.
!>

LDBB

!>          LDBB is INTEGER
!>          La dimensión principal de la matriz BB.  LDBB >= KB+1.
!>

Q

!>          Q is REAL array, dimension (LDQ, N)
!>          Si JOBZ = 'V', la matriz n-por-n utilizada en la reducción de
!>          A*x = (lambda)*B*x a forma estándar, es decir, C*x = (lambda)*x,
!>          y consecuentemente C a forma tridiagonal.
!>          Si JOBZ = 'N', la matriz Q no se referencia.
!>

LDQ

!>          LDQ is INTEGER
!>          La dimensión principal de la matriz Q.  Si JOBZ = 'N',
!>          LDQ >= 1. Si JOBZ = 'V', LDQ >= max(1,N).
!>

VL

!>          VL is REAL
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU is REAL
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL is INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU is INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL is REAL
!>          La tolerancia de error absoluta para los valores propios.
!>          Un valor propio aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual que
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL se
!>          establezca en el doble del umbral de subdesbordamiento 2*SLAMCH('S'), no cero.
!>          Si esta rutina devuelve con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*SLAMCH('S').
!>

M

!>          M is INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W is REAL array, dimension (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z is REAL array, dimension (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
!>          vectores propios, con la columna i-ésima de Z conteniendo el
!>          vector propio asociado con W(i). Los vectores propios están
!>          normalizados de forma que Z**T*B*Z = I.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ is INTEGER
!>          La dimensión principal de la matriz Z. LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK is REAL array, dimension (7*N)
!>

!>

IFAIL

!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los

Function/Subroutine Documentation

SSBGVX computes the eigenvalues and eigenvectors of a real symmetric band matrix A = inv(U)*B*inv(L) or A = inv(L)*B*inv(U), where B is a real symmetric band matrix and L is a real lower triangular band matrix with non-unit diagonal entries, and U is a real upper triangular band matrix with non-unit diagonal entries.

If JOBZ = 'V', SSBGVX computes the eigenvalues and eigenvectors of a symmetric band matrix A = inv(U)*B*inv(L) or A = inv(L)*B*inv(U), where B is a symmetric band matrix and L is a lower triangular band matrix with non-unit diagonal entries, and U is an upper triangular band matrix with non-unit diagonal entries.

A is formed implicitly by the input arguments B, L, and U.

The eigenvalues are computed using the QR algorithm.

Arguments:

JOBZ (input) CHARACTER*1

= 'N': Compute only the eigenvalues of A.

= 'V': Compute the eigenvalues and eigenvectors of A.

RANGE (input) CHARACTER*1

= 'A': all eigenvalues will be found.

= 'V': all eigenvalues in the half-open interval (VL, VU] will be found.

= 'I': all eigenvalues in the open interval (IL, IU] will be found.

UPLO (input) CHARACTER*1

= 'U': Upper triangle of AB and QD is used.

= 'L': Lower triangle of AB and QD is used.

N (input) INTEGER

The order of the matrix A. N >= 0.

To compute non-trivial eigenvalues and eigenvectors, N > 0.

KD (input) INTEGER

The number of super- or sub-diagonals of the band matrix B. Kd >= 0.

AB (input) REAL array, dimension (LDAB, N)

On entry, the numbers of the upper or lower triangle of the symmetric band matrix B. The k-th super- or sub-diagonal is stored in the k-th row of AB. See the Description of the Band Storage Format.

LDAB (input) INTEGER

The leading dimension of the array AB. LDAB >= KD + 1.

Q (output) REAL array, dimension (LDQ, N)

If JOBZ = 'V', Q contains the orthogonal matrix of eigenvectors, with the i-th column (i.e., Q(i)) of Q representing the eigenvector corresponding to the i-th eigenvalue of A.

If JOBZ = 'N', Q is unused.

LDQ (input) INTEGER

The leading dimension of the array Q. If JOBZ = 'V', then LDQ >= max(1, N).

VL (input) REAL

If RANGE = 'V', the lower bound of the interval for the desired eigenvalues.

VU (input) REAL

If RANGE = 'V', the upper bound of the interval for the desired eigenvalues.

IL (input) INTEGER

If RANGE = 'I', the rank of the lowest eigenvalue in the open interval (IL, IU] for the search. The eigenvalues are ordered from smallest to largest. IL >= 1.

IU (input) INTEGER

If RANGE = 'I', the rank of the highest eigenvalue in the open interval (IL, IU] for the search. The eigenvalues are ordered from smallest to largest. IU <= N, IL <= IU.

KEY (input) CHARACTER*1

= 'G': find all eigenvalues in the range.

= 'L': find the IL smallest eigenvalues.

= 'U': find the IU largest eigenvalues.

KMAX (input) INTEGER

The maximum number of eigenvalues to be returned in JWORK.

If KEY = 'G', KMAX >= N.

If KEY = 'L', KMAX >= IL.

If KEY = 'U', KMAX >= N - IU + 1.

WORK (workspace) REAL array, dimension (MAX(1, LWORK))

lwork is the dimension of the array WORK.

If JOBZ = 'N',

lwork must be at least max(2*N, N+KD+1).

If JOBZ = 'V',

lwork must be at least max(2*N, N+KD+1).

lwork >= 1.

RWORK (workspace) REAL array, dimension (LRWORK)

lrwork is the dimension of the array RWORK.

If JOBZ = 'N',

lrwork must be at least max(5*N, 2*N+KD+1).

If JOBZ = 'V',

lrwork must be at least max(5*N, N+KD+1).

lrwork >= 1.

IWORK (workspace) INTEGER array, dimension (LIWORK)

liwork is the dimension of the array IWORK.

liwork must be at least N.

JWORK (workspace) INTEGER array, dimension (KJWORK)

kjwork is the dimension of the array JWORK.

If JOBZ = 'N', kjwork must be at least N.

If JOBZ = 'V', kjwork must be at least N.

INFO (output) INTEGER

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

> 0: if INFO = i, then i eigenvectors failed to converge.

Their indices are stored in IFAIL.
