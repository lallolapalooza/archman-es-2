Documentación de función/subrutina

subrutina ssyevx_2stage (character jobz, character range, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

SSYEVX_2STAGE calcula valores propios seleccionados y, opcionalmente, vectores propios de una matriz real simétrica A usando la técnica de 2 etapas para la reducción a tridiagonal. Los valores y vectores propios pueden ser seleccionados especificando un rango de valores o un rango de índices para los valores propios deseados.

Propósito:

!>
!> SSYEVX_2STAGE calcula valores propios seleccionados y, opcionalmente,
!> vectores propios de una matriz real simétrica A usando la técnica de
!> 2 etapas para la reducción a tridiagonal. Los valores propios y vectores
!> propios pueden ser seleccionados especificando un rango de valores o un
!> rango de índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo
!>                 semiabierto (VL,VU].
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array REAL, dimension (LDA, N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la parte
!>          triangular superior de N por N de A contiene la parte triangular
!>          superior de la matriz A. Si UPLO = 'L', la parte triangular
!>          inferior de N por N de A contiene la parte triangular inferior
!>          de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor
!>          o igual a cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*SLAMCH('S'),
!>          no cero.
!>          Si esta rutina regresa con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL a
!>          2*SLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, Nota de trabajo de LAPACK #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array REAL, dimension (N)
!>          En la salida normal, los primeros M elementos contienen los
!>          valores propios seleccionados en orden ascendente.
!>

Z

!>          Z es array REAL, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación del vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos
!>          max(1,M) columnas en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, 8*N, dimension) donde
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + 3*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 3*N
!>                                   donde KD es el tamaño del bloque de la reducción,
!>                                   FACTOPTNB es el tamaño del bloque utilizado por el
!>                                   algoritmo QR o LQ, usualmente FACTOPTNB=128 es una
!>                                   buena opción.
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   la compilación openMP está habilitada, de lo
!>                                   contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Todavía no disponible.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y ningún mensaje
!>          de error relacionado con LWORK es emitido por XERBLA.
!>

IWORK

!>          IWORK es array INTEGER, dimension (5*N)
!>

NAME

ssyevx_2stage - SSYEVX computes the eigenvalues and eigenvectors of a real symmetric generalized definite banded matrix of the form A * v = lambda * B * v

SYNOPSIS

   SUBROUTINE SSYEVX_2STAGE(
      JOBZ, RANGE, UPLO, N, ALPHAJ, BETAJ, A, LDA, Q, LDQ, Z, LDZ, WORK, LWORK,
      IWORK, INFO)

Function/Subroutine Documentation

   SUBROUTINE SSYEVX_2STAGE(
      JOBZ   CHARACTER*1,
      RANGE  CHARACTER*1,
      UPLO   CHARACTER*1,
      N      INTEGER,
      ALPHAJ REAL,
      BETAJ  REAL,
      A      REAL,
      LDA    INTEGER,
      Q      REAL,
      LDQ    INTEGER,
      Z      REAL,
      LDZ    INTEGER,
      WORK   REAL,
      LWORK  INTEGER,
      IWORK  INTEGER,
      INFO   INTEGER)

Parameters

JOBZ

CHARACTER*1.

Specifies whether to compute the eigenvectors.’

  • ’N’: only the eigenvalues are computed.

  • ’V’: the eigenvalues and eigenvectors of the symmetric generalized eigenvalue problem A*v = lambda*B*v are computed.

RANGE

CHARACTER*1.

Specifies whether all eigenvalues or a range of eigenvalues are to be computed.

  • ’A’: all eigenvalues will be computed.

  • ’V’: the eigenvalues in the interval (ALPHAJ, BETAJ) will be computed.

  • ’I’: the eigenvalues with indices in the interval (IL, IU) will be computed.

UPLO

CHARACTER*1.

Specifies whether A or B (or both) are upper or lower triangular. ’U’: Upper triangular

  • ’L’: Lower triangular

N

INTEGER.

The order of the matrices A and B. N >= 0.

ALPHAJ

REAL.

If RANGE = ’V’, the lower bound of the interval for the desired eigenvalues.

BETAJ

REAL.

If RANGE = ’V’, the upper bound of the interval for the desired eigenvalues.

A

REAL array, dimension (LDA, N).

On entry, the upper or lower triangular part of the symmetric matrix A, plus potentially some levels of diagonals.

On exit, if JOBZ = ’V’, the lower triangle of A contains information about the eigenvectors.

LDA

INTEGER.

The leading dimension of A. LDA >= max(1, N).

Q

REAL array, dimension (LDQ, M).

(Optional output)

If JOBZ = ’V’, Q contains the orthogonal matrix Q that reduces A to tridiagonal form: Q**T*A*Q = T.

LDQ

INTEGER.

The leading dimension of Q. LDQ >= max(1, N).

Z

REAL array, dimension (LDZ, N).

On exit, if JOBZ = ’V’, Z contains the eigenvectors of the generalized eigenvalue problem A*v = lambda*B*v, with the i-th column of Z holding the eigenvector corresponding to the i-th eigenvalue in the returned array ALPHA.

LDZ

INTEGER.

The leading dimension of Z. LDZ >= max(1, N).

WORK

REAL array, dimension (LWORK).

On exit, WORK(1) contains the optimal value of LWORK.

LWORK

INTEGER.

The dimension of the array WORK. LWORK >= max(1, 2*N).

For optimum performance, LWORK >= max(1, 2*N + N*NB), where NB is the block size for the routines QR and QRD.

If LWORK = -1 only, then LWORK is an input and WORK is not ascribed. The optimal value of LWORK is returned in WORK(1).

IWORK

INTEGER array, dimension (N).

If JOBZ = ’V’, then if INFO = 0, the first M elements of IFAIL are zero. If INFO > 0, then IFAIL contains the indices of the eigenvectors that failed to converge. If JOBZ = ’N’, then IFAIL is not referenced.

INFO

INTEGER.

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

> 0: if INFO = i, then i eigenvectors failed to converge. Their indices are stored in array IFAIL.
