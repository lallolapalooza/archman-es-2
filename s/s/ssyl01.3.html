subroutine ssyl01 (real thresh, integer, dimension( 3 ) nfail, real, dimension( 2 ) rmax, integer, dimension( 2 ) ninfo, integer knt)

SSYL01

Propósito:

!>
!> SSYL01 prueba STRSYL y STRSYL3, rutinas para resolver la ecuación matricial de Sylvester
!>
!>    op(A)*X + ISGN*X*op(B) = scale*C,
!>
!> Se asume que A y B están en forma canónica de Schur, op() representa una
!> transposición opcional, e ISGN puede ser -1 o +1. Scale es una salida
!> menor o igual a 1, elegida para evitar desbordamiento en X.
!>
!> El código de prueba verifica que el siguiente residuo no exceda
!> el umbral proporcionado:
!>
!>    norm(op(A)*X + ISGN*X*op(B) - scale*C) /
!>        (EPS*max(norm(A),norm(B))*norm(X))
!>
!> Esta rutina complementa a SGET35 probando con matrices aleatorias más grandes,
!> algunas de las cuales requieren reescalado de X para evitar desbordamiento.
!>
!>

Parámetros

THRESH 
!>          THRESH es REAL
!>          Una prueba contará como si el residuo, calculado como
!>          se describe arriba, excede THRESH.
!>

NFAIL

!>          NFAIL es un array de ENTEROS, dimension (3)
!>          NFAIL(1) = Nº de veces que el residuo STRSYL excede el umbral THRESH
!>          NFAIL(2) = Nº de veces que el residuo STRSYL3 excede el umbral THRESH
!>          NFAIL(3) = Nº de veces que STRSYL3 y STRSYL difieren
!>

RMAX

!>          RMAX es REAL, dimension (2)
!>          RMAX(1) = Valor de la mayor razón de prueba de STRSYL
!>          RMAX(2) = Valor de la mayor razón de prueba de STRSYL3
!>

NINFO

!>          NINFO es un array de ENTEROS, dimension (2)
!>          NINFO(1) = Nº de veces que STRSYL devuelve una INFO esperada
!>          NINFO(2) = Nº de veces que STRSYL3 devuelve una INFO esperada
!>

KNT

!>          KNT es ENTERO
!>          Número total de ejemplos probados.
!>
