NOMBRE

sss_seed - sembrar la caché de SSSD con un usuario

SINOPSIS

sss_seed [opciones] -D DOMINIO -n USUARIO

DESCRIPCIÓN

sss_seed siembra la caché de SSSD con una entrada de usuario y una contraseña temporal. Si una entrada de usuario ya está presente en la caché de SSSD, la entrada se actualiza con la contraseña temporal.

OPCIONES

-D,--dominio DOMINIO

Proporciona el nombre del dominio al que pertenece el usuario. El dominio también se utiliza para recuperar la información del usuario. El dominio debe estar configurado en sssd.conf. La opción DOMINIO debe proporcionarse. La información recuperada del dominio anula lo proporcionado en las opciones.

-n,--nombre-usuario USUARIO

El nombre de usuario de la entrada que se va a crear o modificar en la caché. La opción USUARIO debe proporcionarse.

-u,--uid UID

Establece el UID del usuario a UID.

-g,--gid GID

Establece el GID del usuario a GID.

-c,--gecos COMENTARIO

Cualquier cadena de texto que describa al usuario. A menudo se utiliza como campo para el nombre completo del usuario.

-h,--home DIRECTORIO_HOME

Establece el directorio de inicio del usuario a DIRECTORIO_HOME.

-s,--shell SHELL

Establece el shell de inicio de sesión del usuario a SHELL.

-i,--interactivo

Modo interactivo para introducir la información del usuario. Esta opción solo solicitará información no proporcionada en las opciones o recuperada del dominio.

-p,--archivo-contraseña ARCHIVO_PASS

Especifica el archivo del que leer la contraseña del usuario. (si no se especifica, se solicita la contraseña)

-?,--ayuda

Muestra el mensaje de ayuda y sale.

NOTAS

La longitud de la contraseña (o el tamaño del archivo especificado con la opción -p o --archivo-contraseña) debe ser menor o igual a PASS_MAX bytes (64 bytes en sistemas sin un valor PASS_MAX definido globalmente).
