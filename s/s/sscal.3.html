SSCAL

Propósito:

!>
!>    SSCAL escala un vector por una constante.
!>    utiliza bucles desenrollados para incrementos iguales a 1.
!>

Parámetros

N 
!>          N es ENTERO
!>         número de elementos en el vector(es) de entrada
!>

SA

!>          SA es REAL
!>           A la entrada, SA especifica el escalar alfa.
!>

SX

!>          SX es un array REAL, de dimensión ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX es ENTERO
!>         espaciado de almacenamiento entre elementos de SX
!>
