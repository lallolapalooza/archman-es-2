SSBGVD

Propósito:

!>
!> SSBGVD calcula todos los valores propios, y opcionalmente, los vectores propios
!> de un problema de valores propios general de banda simétrica definida real,
!> de la forma A*x=(lambda)*B*x. Aquí se asume que A y B son simétricas y
!> de banda, y B también es positiva definida. Si se desean vectores propios,
!> utiliza un algoritmo de divide y vencerás.
!>
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

KA

!>          KA es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KA >= 0.
!>

KB

!>          KB es INTEGER
!>          El número de superdiagonales de la matriz B si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KB >= 0.
!>

AB

!>          AB es array REAL, dimension (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de
!>          banda simétrica A, almacenado en las primeras ka+1 filas del array.
!>          La j-ésima columna de A se almacena en la j-ésima columna del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) para max(1,j-ka)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+ka).
!>
!>          En la salida, el contenido de AB se destruye.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KA+1.
!>

BB

!>          BB es array REAL, dimension (LDBB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de
!>          banda simétrica B, almacenado en las primeras kb+1 filas del array.
!>          La j-ésima columna de B se almacena en la j-ésima columna del array BB
!>          de la siguiente manera:
!>          si UPLO = 'U', BB(ka+1+i-j,j) = B(i,j) para max(1,j-kb)<=i<=j;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) para j<=i<=min(n,j+kb).
!>
!>          En la salida, el factor S de la factorización Cholesky dividida
!>          B = S**T*S, tal como es devuelto por SPBSTF.
!>

LDBB

!>          LDBB es INTEGER
!>          La dimensión principal del array BB.  LDBB >= KB+1.
!>

W

!>          W es array REAL, dimension (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es array REAL, dimension (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
!>          vectores propios, con la i-ésima columna de Z conteniendo el
!>          vector propio asociado a W(i). Los vectores propios se normalizan
!>          para que Z**T*B*Z = I.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK >= 1.
!>          Si JOBZ = 'N' y N > 1, LWORK >= 3*N.
!>          Si JOBZ = 'V' y N > 1, LWORK >= 1 + 5*N + 2*N**2.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la subrutina solo calcula los tamaños óptimos de los arrays WORK
!>          y IWORK, devuelve estos valores como las primeras entradas de los
!>          arrays WORK y IWORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK o LIWORK por XERBLA.
!>

IWORK

!>          IWORK es array INTEGER, dimension (MAX(1,LIWORK))
!>          En la salida, si LIWORK > 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si JOBZ  = 'N' o N <= 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la subrutina solo calcula los tamaños óptimos de los arrays WORK
!>          y IWORK, devuelve estos valores como las primeras entradas de los
!>          arrays WORK y IWORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK o LIWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es:
!>             <= N:  el algoritmo no convergió:
!>                    i elementos fuera de la diagonal de una forma
!>                    tridiagonal intermedia no convergieron a cero;
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces SPBSTF
!>                    devolvió INFO = i: B no es positiva definida.
!>                    La factorización de B no se pudo completar y
!>                    no se calcularon valores propios ni vectores propios.
!>
