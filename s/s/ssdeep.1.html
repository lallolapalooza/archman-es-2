NOMBRE

ssdeep - Calcula hash segmentados activados por contexto (hashes difusos)

SINOPSIS

ssdeep [-m <archivo>] [-k <archivo>] [-vdprgsblcxa] [-t valor] [ARCHIVOS]
ssdeep [-V|h]

DESCRIPCIÓN

Calcula una firma basada en hash segmentados activados por contexto para cada archivo de entrada, también llamado hash difuso. Si se solicita, el programa compara estas firmas con un archivo de firmas conocidas e informa de cualquier coincidencia posible. También puede examinar uno o más archivos de firmas y encontrar cualquier coincidencia en esos archivos. La salida se escribe en la salida estándar y los errores en la salida de error estándar.

-m <archivo>
Carga el archivo especificado de hashes conocidos para ser utilizado en la comparación. Este archivo debe ser una salida previa del programa. El programa luego calcula el hash de cada entrada en ARCHIVOS y compara estas firmas con las firmas conocidas. Se muestran todas las coincidencias que puntúan por encima del umbral. Esta opción se puede usar varias veces para cargar más firmas conocidas. Esta opción no se puede usar con las opciones -k o -x.
-k <archivo>
Carga el archivo especificado de hashes conocidos para ser utilizado en la comparación. Este archivo debe ser una salida previa del programa. El programa luego trata cada entrada en ARCHIVOS como un conjunto de hashes conocidos también. Los hashes en estos ARCHIVOS se comparan con los hashes conocidos de este archivo. Se muestran las coincidencias que puntúan por encima del umbral. Tanto el archivo especificado aquí como los ARCHIVOS de entrada deben contener hashes difusos. Esta opción se puede usar varias veces para cargar más firmas conocidas. Esta opción no se puede usar con las opciones -m, -d o -p.
-v
Modo detallado. Se imprime el nombre de cada archivo en la salida de error estándar a medida que se calcula su hash.
-d
Calcula una firma para cada entrada en los ARCHIVOS y la compara con el conjunto de firmas conocidas. Se muestran las coincidencias que puntúan por encima del umbral. La firma calculada se añade luego al conjunto de firmas conocidas. Esta opción no se puede usar con las opciones -k o -x.
-p
Funciona como la opción -d, pero muestra todas las coincidencias para cada archivo. Es decir, para dos archivos A y B que coinciden con una puntuación superior al umbral, muestra "A coincide con B" y "B coincide con A". Esta opción no se puede usar con las opciones -k o -x.
-r
Habilita el modo recursivo. Se recorren todos los subdirectorios. Tenga en cuenta que el modo recursivo no se puede utilizar para examinar todos los archivos de una determinada extensión de archivo. Por ejemplo, invocar el programa con -r *.txt examinará todos los archivos en los directorios que terminen en .txt. Si desea procesar todos los archivos en un árbol de directorios con el sufijo .txt, intente usar el comando find(1).
-g
Los archivos similares se agrupan en clústeres. Esto puede ser útil para encontrar archivos más similares. Es decir, si está buscando el archivo A, que coincide con B, cualquier cosa que coincida con B también se incluirá en el clúster.
-s
Modo silencioso. Se suprimen todos los mensajes de error.
-b
Habilita el modo básico. Elimina cualquier información de directorio inicial de los nombres de archivo mostrados. Esta opción no se puede usar junto con la opción -l.
-l
Habilita rutas de archivo relativas. En lugar de imprimir la ruta absoluta para cada archivo, muestra la ruta de archivo relativa tal como se indica en la línea de comandos. Esta opción no se puede usar junto con la opción -b.
-c
Habilita el modo de salida separada por comas. En cualquiera de los modos de comparación -d, -p o -m, muestra los resultados como archivo de entrada, archivo conocido, puntuación de coincidencia.
-x
Comparación de archivos de firma. Cada entrada en ARCHIVOS debe contener firmas generadas por una salida previa del programa. Cada firma se carga y se compara con el conjunto de hashes conocidos. Se muestran las puntuaciones de coincidencia por encima del umbral. Cada firma se añade luego al conjunto de los conocidos. Esta opción no se puede usar con las opciones -m, -d o -p.
-a
Muestra todas las coincidencias en cualquiera de los modos de comparación, independientemente de la puntuación. El uso de la opción -a muestra todos los resultados, incluso si la puntuación de coincidencia es cero.
-t <valor>
En cualquiera de los modos de comparación, solo muestra coincidencias cuando la puntuación de coincidencia es mayor que el valor dado. El valor umbral predeterminado es cero.
-h
Muestra una pantalla de ayuda y sale.
-V
Muestra el número de versión y sale.

VALOR DE RETORNO

Devuelve 0 en caso de éxito, 1 si hay un problema. Los errores de lectura, el permiso denegado y la aparición de directorios sin estar en modo recursivo todavía se consideran éxitos. Los problemas son cosas como no poder cargar el archivo de comparación, especificar rutas básicas y relativas, etc.
