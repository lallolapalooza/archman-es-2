SSH_FILTER_BTRBK(1) Manual de Btrbk SSH_FILTER_BTRBK(1)

NOMBRE

ssh_filter_btrbk - script de filtro de comandos ssh para btrbk

SINOPSIS

ssh_filter_btrbk.sh [-s|--source] [-t|--target] [-d|--delete]
    [-i|--info] [--snapshot] [--send] [--receive]
    [-p|--restrict-path <ruta>] [-l|--log] [--sudo]

DESCRIPCIÓN

ssh_filter_btrbk.sh restringe los comandos SSH a los comandos utilizados por btrbk. Examina la variable de entorno SSH_ORIGINAL_COMMAND (establecida por sshd) y la ejecuta solo si contiene comandos utilizados por btrbk.

Los comandos aceptados se especifican mediante las opciones "--source", "--target", "--delete" y "--info".

Los siguientes comandos están siempre permitidos:

•"btrfs subvolume show" (no afectado por "--restrict-path")
•"btrfs subvolume list" (no afectado por "--restrict-path")
•"readlink"
•"test -d" (solo si la opción de configuración "compat busybox" está establecida)
•"cat /proc/self/mountinfo"
•tuberías a través de "gzip", "pigz", "bzip2", "pbzip2", "bzip3", "xz", "lzop", "lz4", "zstd" (stream_compress)
•tuberías a través de "mbuffer" (stream_buffer, rate_limit)

Ejemplo de línea en /root/.ssh/authorized_keys en un host de destino de copia de seguridad:

command="ssh_filter_btrbk.sh --target --delete --restrict-path /mnt/btr_backup",restrict ssh-rsa AAAAB3NzaC1...hwumXFRQBL btrbk@example.org

OPCIONES

-s, --source

Permite comandos para la fuente de copia de seguridad: "btrfs subvolume snapshot", "btrfs send". Equivalente a "--snapshot --send".

-t, --target

Permite comandos para destino de copia de seguridad y archivo: "btrfs receive", "mkdir".

-d, --delete

Permite comandos para la eliminación de subvolúmenes: "btrfs subvolume delete". Esto se utiliza para la fuente de copia de seguridad si snapshot_preserve_daily no está establecido en “all”, y para destinos de copia de seguridad si target_preserve_daily no está establecido en “all”.

-i, --info

Permite comandos informativos: "btrfs subvolume find-new", "btrfs filesystem usage". Esto es utilizado por los comandos info y diff de btrbk.

--snapshot

Permite el comando btrfs snapshot: "btrfs subvolume snapshot".

--send

Permite el comando btrfs send: "btrfs send".

--receive

Permite el comando btrfs receive: "btrfs receive".

-p, --restrict-path <ruta>

Restringe los comandos a <ruta>. Tenga en cuenta que "btrfs subvolume show", "btrfs subvolume list" NO se ven afectados por esta opción.

No es posible restringir comandos a nombres de subvolúmenes exactos, ya que btrfs-receive(8) toma una <ruta> como argumento (directorio, sin incluir el nombre del archivo de subvolumen a crear, esto está codificado en el stream de envío).

-l, --log

Registra los mensajes ACCEPT y REJECT en el registro del sistema.

--sudo

Permite que los comandos btrfs se llamen a través de sudo. Habilite esto si tiene "backend btrfs-progs-sudo" en su archivo de configuración de btrbk.

DISPONIBILIDAD

Por favor, consulte la página del proyecto btrbk https://digint.ch/btrbk/para más detalles.

VER TAMBIÉN

btrbk(1), btrbk.conf(5), btrfs(8)
