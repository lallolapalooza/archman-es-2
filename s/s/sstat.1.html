sstat(1) Comandos de Slurm sstat(1)

NOMBRE

sstat - Muestra la información de estado de un trabajo/paso en ejecución.

SINOPSIS

sstat [OPCIONES...]

DESCRIPCIÓN

Información de estado para trabajos en ejecución invocados con Slurm.

El comando sstat muestra información de estado del trabajo para tu análisis. El comando sstat muestra información relacionada con CPU, Tarea, Nodo, Tamaño de Conjunto Residente (RSS) y Memoria Virtual (VM). Puedes adaptar la salida con el uso de la opción --fields= para especificar los campos que se mostrarán.

Para el usuario root, el comando sstat muestra datos de estado del trabajo para cualquier trabajo que se esté ejecutando en el sistema.

Para el usuario no root, la salida de sstat se limita a los trabajos del usuario.

NOTA: El comando sstat requiere que el plugin jobacct_gather esté instalado y operativo.

NOTA: La disponibilidad de las métricas depende del plugin jobacct_gather utilizado. Por ejemplo, jobacct_gather/cgroup en combinación con cgroup/v2 no proporciona métricas de Memoria Virtual debido a limitaciones en las interfaces cgroups del kernel y mostrará un 0 para los campos relacionados.

OPCIONES

-a, --allsteps
Imprime todos los pasos para el(los) trabajo(s) dados cuando no se especifica ningún paso.
-o, --format, --fields
Lista de campos separados por comas. (usa '--helpformat' para una lista de campos disponibles).

NOTA: Al usar la opción de formato para listar varios campos, puedes añadir un %NÚMERO después para especificar cuántos caracteres se deben imprimir.

ej. format=name%30 imprimirá 30 caracteres del campo nombre justificado a la derecha. Un -30 imprimirá 30 caracteres justificado a la izquierda.

-h, --help
Muestra un mensaje de ayuda general.
-e, --helpformat
Imprime una lista de campos que se pueden especificar con la opción '--format'.
-j, --jobs
El formato es <trabajo(.paso)>. Muestra este paso de trabajo o una lista separada por comas de pasos de trabajo. Esta opción es obligatoria. La porción de paso por defecto será el paso en ejecución con el número más bajo (no batch, extern, etc) si no se especifica, a menos que se establezca la bandera --allsteps, donde no especificar un paso resultará en la visualización de todos los pasos en ejecución. NOTA: Un ID de paso 'batch' mostrará la información sobre el paso batch. NOTA: Un ID de paso 'extern' mostrará la información sobre el paso extern. Este paso solo está disponible cuando se usa PrologFlags=contain
--noconvert
No conviertas las unidades de su tipo original (por ejemplo, 2048M no se convertirá a 2G).
-n, --noheader
No se añadirá ninguna cabecera a la salida. La acción predeterminada es mostrar una cabecera.
-p, --parsable
La salida estará delimitada por '|' con un '|' al final.
-P, --parsable2
La salida estará delimitada por '|' sin un '|' al final.
-i, --pidformat
Formato predefinido para mostrar los PIDs en ejecución para cada paso de trabajo. (ID de Trabajo, Nodos, PIDs)
--usage
Muestra un resumen del uso del comando.
-v, --verbose
Principalmente para fines de depuración, informa el estado de varias variables durante el procesamiento.
-V, --version
Imprime la versión.

CAMPOS DE ESTADO DEL TRABAJO

Las descripciones de cada opción de campo se encuentran a continuación. Tenga en cuenta que los campos de contabilidad Ave*, Max* y Min* analizan los valores de todas las tareas de cada paso de un trabajo y devuelven los valores promedio, máximo o mínimo de la tarea para ese paso de trabajo. Por ejemplo, para MaxRSS, el valor devuelto es el consumo máximo de memoria visto por una de las tareas del paso, y MaxRSSTask muestra cuál es esa tarea.

AllocTRES
TRES asignados de todas las tareas en el trabajo.
AveCPU
Tiempo promedio (sistema + usuario) de CPU de todas las tareas en el trabajo.
AveCPUFreq
Frecuencia promedio ponderada de CPU de todas las tareas en el trabajo, en kHz.
AveDiskRead
Número promedio de bytes leídos por todas las tareas en el trabajo.
AveDiskWrite
Número promedio de bytes escritos por todas las tareas en el trabajo.
AvePages
Número promedio de fallos de página de todas las tareas en el trabajo.
AveRSS
Tamaño residente promedio de todas las tareas en el trabajo.
AveVMSize
Tamaño promedio de memoria virtual de todas las tareas en el trabajo.
ConsumedEnergy
Energía total consumida por todas las tareas en el trabajo, en julios. Nota: Solo en caso de asignación de trabajo exclusiva, este valor refleja el consumo real de energía del trabajo.
JobID
El número del trabajo o paso de trabajo. Tiene el formato: trabajo.pasodetrabajo
MaxDiskRead
Número máximo de bytes leídos por todas las tareas en el trabajo.
MaxDiskReadNode
El nodo en el que ocurrió maxdiskread.
MaxDiskReadTask
La ID de tarea donde ocurrió maxdiskread.
MaxDiskWrite
Número máximo de bytes escritos por todas las tareas en el trabajo.

OPTIONS

MaxDiskWriteNode
El nodo en el que ocurrió la escritura máxima en disco.
MaxDiskWriteTask
El ID de la tarea donde ocurrió la escritura máxima en disco.
MaxPages
Número máximo de fallos de página de todas las tareas del trabajo.
MaxPagesNode
El nodo en el que ocurrió el máximo de páginas.
MaxPagesTask
El ID de la tarea donde ocurrió el máximo de páginas.
MaxRSS
Tamaño máximo del conjunto residente de todas las tareas del trabajo.
MaxRSSNode
El nodo en el que ocurrió el máximo RSS.
MaxRSSTask
El ID de la tarea donde ocurrió el máximo RSS.
MaxVMSize
Tamaño máximo de memoria virtual de todas las tareas del trabajo.
MaxVMSizeNode
El nodo en el que ocurrió el tamaño máximo de VM.
MaxVMSizeTask
El ID de la tarea donde ocurrió el tamaño máximo de VM.
MinCPU
Tiempo de CPU mínimo (sistema + usuario) de todas las tareas del trabajo.
MinCPUNode
El nodo en el que ocurrió el CPU mínimo.
MinCPUTask
El ID de la tarea donde ocurrió el CPU mínimo.
NTasks
Número total de tareas en un trabajo o paso.
ReqCPUFreq
Frecuencia de CPU solicitada para el paso, en kHz.
TresUsageInAve
Uso promedio de Tres in por todas las tareas del trabajo. NOTA: Si TresUsageInMaxTask correspondiente es -1, la métrica es centrada en el nodo en lugar de en la tarea.
TresUsageInMax
Uso máximo de Tres in por todas las tareas del trabajo. NOTA: Si TresUsageInMaxTask correspondiente es -1, la métrica es centrada en el nodo en lugar de en la tarea.
TresUsageInMaxNode
Nodo para el cual ocurrió cada uso máximo de TRES.
TresUsageInMaxTask
Tarea para la cual ocurrió cada uso máximo de TRES.
TresUsageOutAve
Uso promedio de Tres out por todas las tareas del trabajo. NOTA: Si TresUsageOutMaxTask correspondiente es -1, la métrica es centrada en el nodo en lugar de en la tarea.
TresUsageOutMax
Uso máximo de Tres out por todas las tareas del trabajo. NOTA: Si TresUsageOutMaxTask correspondiente es -1, la métrica es centrada en el nodo en lugar de en la tarea.
TresUsageOutMaxNode
Nodo para el cual ocurrió cada uso máximo de TRES.
TresUsageOutMaxTask
Tarea para la cual ocurrió cada uso máximo de TRES.

RENDIMIENTO

Ejecutar sstat envía una llamada de procedimiento remoto a slurmctld. Si llegan suficientes llamadas de sstat u otros comandos cliente de Slurm que envían llamadas de procedimiento remoto al demonio slurmctld a la vez, puede resultar en una degradación del rendimiento del demonio slurmctld, posiblemente resultando en una denegación de servicio.

No ejecute sstat u otros comandos cliente de Slurm que envíen llamadas de procedimiento remoto a slurmctld desde bucles en scripts de shell u otros programas. Asegúrese de que los programas limiten las llamadas a sstat al mínimo necesario para la información que intenta recopilar.

VARIABLES DE ENTORNO

Algunas opciones de sstat pueden configurarse a través de variables de entorno. Estas variables de entorno, junto con sus opciones correspondientes, se enumeran a continuación. (Nota: Las opciones de línea de comandos siempre tendrán prioridad sobre estas configuraciones).

SLURM_CONF
La ubicación del archivo de configuración de Slurm.
SLURM_DEBUG_FLAGS
Especifica las banderas de depuración que debe usar sstat. Consulte DebugFlags en la página del manual slurm.conf(5) para obtener una lista completa de banderas. La variable de entorno tiene prioridad sobre la configuración en slurm.conf.

EJEMPLOS

Mostrar información del paso de trabajo para el trabajo 11 con los campos especificados:
$ sstat --format=AveCPU,AvePages,AveRSS,AveVMSize,JobID -j 11
25:02.000  0K         1.37M      5.93M      9.0
Mostrar información del paso de trabajo para el trabajo 11 con los campos especificados en un formato analizable:
$ sstat -p --format=AveCPU,AvePages,AveRSS,AveVMSize,JobID -j 11
25:02.000|0K|1.37M|5.93M|9.0|
