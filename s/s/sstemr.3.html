Propósito:

!>
!> SSTEMR calcula valores propios y, opcionalmente, vectores propios
!> seleccionados de una matriz tridiagonal simétrica real T. Cualquier matriz no reducida
!> tiene un conjunto bien definido de valores propios reales distintos por pares, los vectores
!> propios reales correspondientes son ortogonales por pares.
!>
!> El espectro puede calcularse de forma completa o parcial especificando
!> ya sea un intervalo (VL,VU] o un rango de índices IL:IU para los valores
!> propios deseados.
!>
!> Dependiendo del número de valores propios deseados, estos se calculan
!> mediante bisección o el algoritmo dqds. Los vectores propios numéricamente ortogonales
!> se calculan mediante el uso de varias factorizaciones L D L^T adecuadas cerca de clústeres
!> de valores propios cercanos (denominados RRR, Representaciones Relativamente Robustas).
!> Un esquema informal del algoritmo sigue:
!>
!> Para cada bloque no reducido (submatriz) de T,
!>    (a) Calcular T - sigma I  = L D L^T, de modo que L y D
!>        definen todos los valores propios deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los valores propios y
!>        vectores propios. La representación estándar (no factorizada) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcular los valores propios con la precisión adecuada.
!>        Si se desean los vectores propios, el algoritmo alcanza la precisión completa
!>        de los valores propios calculados solo justo antes
!>        de que los vectores correspondientes tengan que ser calculados, ver pasos c) y d).
!>    (c) Para cada clúster de valores propios cercanos, seleccionar un nuevo
!>        desplazamiento cercano al clúster, encontrar una nueva factorización y refinar
!>        los valores propios desplazados con la precisión adecuada.
!>    (d) Para cada valor propio con una separación relativa suficientemente grande, calcular
!>        el vector propio correspondiente formando una factorización retorcida que revele el rango.
!>        Volver a (c) para cualquier clúster que quede.
!>
!> Para más detalles, ver:
!> - Inderjit S. Dhillon y Beresford N. Parlett: 
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, agosto de 2004.
!> - Inderjit Dhillon y Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004.  También LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mayo de 1997.
!>
!> Más detalles
!> 1. SSTEMR solo funciona en máquinas que siguen el estándar de punto flotante
!>    IEEE-754 en su manejo de infinitos y NaNs.
!> Esto permite el uso de bucles internos eficientes que evitan la comprobación de
!> divisores cero.
!>

NAME

sstemr - SSTEMR computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.

SYNOPSIS

    )

    CHARACTER          *1 RANGE

    REAL               D( * )
    REAL               E( * )
    REAL               VL

Function/Subroutine Documentation

This subroutine computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.

The eigenvectors are normalized so the squared Euclidean norm is 1.

A problem reducing the tridiagonal matrix to bidiagonal form and then applying QR/QL reduction is applied to the bidiagonal matrix. Eigenvectors are computed via divide and conquer in SLARRE and SLARRV.

Arguments

JOBZ

CHARACTER*1. Default: 'N'.

Specifies whether to compute the eigenvectors.

  • 'N': Compute only the eigenvalues of T.
  • 'V': Compute the eigenvalues and eigenvectors of T.
RANGE

CHARACTER*1. Default: 'A'.

Specifies whether all eigenvalues and eigenvectors are computed.

  • 'A': All eigenvalues and eigenvectors will be found.
  • 'V': All eigenvalues and eigenvectors in the interval (VL, VU) will be found.

    If RANGE='V', then VL and VU must be set.

  • 'I': All eigenvalues and eigenvectors in the range (IL, IU) will be found.

    If RANGE='I', then IL and IU must be set.

N

INTEGER.

The order of the matrix T. N >= 0.

D

REAL array, dimension (N).

On entry, the diagonal elements of T.

On exit, the computed eigenvalues, sorted in ascending order.

E

REAL array, dimension (N-1).

On entry, the subdiagonal elements of T.

On exit, E is overwritten.

VL

REAL.

If RANGE='V', the lower bound of the interval.

VU

REAL.

If RANGE='V', the upper bound of the interval.

IL

INTEGER.

If RANGE='I', the lower index of the eigenvalues to be computed.

IU

INTEGER.

If RANGE='I', the upper index of the eigenvalues to be computed.

M

INTEGER.

The number of computed eigenvalues and eigenvectors.

0 <= M <= N.

WORK

REAL array, dimension (LWORK).

On exit, if INFO = 0, WORK(1) returns the optimal (and minimal) LWORK.

LWORK

INTEGER.

The dimension of the array WORK. LWORK >= max(1,18*N) if JOBZ = 'V', and LWORK >= max(1,12*N) if JOBZ = 'N'. If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

IWORK

INTEGER array, dimension (LIWORK).

On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.

LIWORK

INTEGER.

The dimension of the array IWORK. LIWORK >= max(1,10*N) if the eigenvectors are desired, and LIWORK >= max(1,8*N) if only the eigenvalues are to be computed. If LIWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the IWORK array, returns this value as the first entry of the IWORK array, and no error message related to LIWORK is issued by XERBLA.

TRYRAC

LOGICAL.

TRYRAC is the input argument that controls whether the routine should try to compute the eigenvalues to high relative accuracy. If TRYRAC = .TRUE., the routine tries to preserve the relative accuracy of the eigenvalues. This may lead to a slower execution time. If TRYRAC = .FALSE., the routine is not required to guarantee the relative accuracy of the eigenvalues and can use faster algorithms.

This argument indicates that the code should check whether the tridiagonal matrix defines its eigenvalues to high relative accuracy. If so, the code uses relative-accuracy preserving algorithms that might be (a bit) slower depending on the matrix. If the matrix does not define its eigenvalues to high relative accuracy, the code can uses possibly faster algorithms. If TRYRAC = .FALSE., the code is not required to guarantee relatively accurate eigenvalues and can use the fastest possible techniques. On exit, a .TRUE. TRYRAC will be set to .FALSE. if the matrix does not define its eigenvalues to high relative accuracy.

INFO

INTEGER.

On exit, INFO

  • = 0: successful exit
  • < 0: if INFO = -i, the i-th argument had an illegal value
  • > 0: if INFO = 1X, internal error in SLARRE, if INFO = 2X, internal error in SLARRV. Here, the digit X = ABS( IINFO ) < 10, where IINFO is the nonzero error code returned by SLARRE or SLARRV, respectively.
