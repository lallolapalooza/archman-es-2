SSBEVX calcula los valores y, opcionalmente, los vectores propios izquierdos y/o derechos para OTROS matrices

Propósito:

!>
!> SSBEVX calcula los valores y, opcionalmente, los vectores propios seleccionados
!> de una matriz de banda simétrica real A. Los valores y vectores propios pueden
!> ser seleccionados especificando un rango de valores o un rango de
!> índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores y vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios;
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 que se esté buscando;
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es array REAL, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda
!>          simétrica A, almacenado en las primeras KD+1 filas del array. El
!>          j-ésimo elemento de la columna de A se almacena en el j-ésimo elemento
!>          de la columna del array AB:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la primera
!>          superdiagonal y la diagonal de la matriz tridiagonal T
!>          se devuelven en las filas KD y KD+1 de AB, y si UPLO = 'L',
!>          la diagonal y la primera subdiagonal de T se devuelven en las
!>          primeras dos filas de AB.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!>

Q

!>          Q es array REAL, dimensión (LDQ, N)
!>          Si JOBZ = 'V', la matriz ortogonal N por N utilizada en la
!>                         reducción a forma tridiagonal.
!>          Si JOBZ = 'N', el array Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.  Si JOBZ = 'V', entonces
!>          LDQ >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de anchura menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual que cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir AB a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*SLAMCH('S'), no cero.
!>          Si esta rutina devuelve INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*SLAMCH('S').
!>
!>          Ver por Demmel y
!>          Kahan, Nota de Trabajo LAPACK #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array REAL, dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es array REAL, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se proporcionan al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array REAL, dimensión (7*N)
!>

IWORK

!>          IWORK es array INTEGER, dimensión (5*N)
!>

IFAIL

!>          IFAIL es array INTEGER, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que fallaron en converger.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.

Function/Subroutine Documentation

Purpose

   SSBEVX computes the eigenvalues and, optionally, eigenvectors of a real
   symmetric tridiagonal matrix A in band storage.


   A band storage is most efficient for matrices where the number of
   subdiagonals and superdiagonals is small. In this case, the       
   number of columns of AB is equal to KD + 1.                          
                                                                       
   This subroutine calls the algorithms that use packed storage for the
   subvectors of the eigenvectors.

Arguments

CHARACTER(LEN=1) :: FACT

Specifies whether to compute the eigenvalues and eigenvectors. See below.

CHARACTER(LEN=1) :: UPLO

Specifies whether the upper or lower triangular part of the band matrix A is supplied.

          = 'U': Upper triangle of A is supplied
          = 'L': Lower triangle of A is supplied
INTEGER :: N

The order of the matrix A. This is also the number of eigenvalues and eigenvectors, and the number of rows and columns of the matrix Q.

INTEGER :: KD

The number of superdiagonals (or subdiagonals) in the symmetric band matrix A. Its value is.

          = 0: for a diagonal matrix
          = 1: for a tridiagonal matrix
          >= 1: for a general band matrix
REAL, INTENT(INOUT) :: AB( LDAB, * )

On entry, the upper or lower triangular part of the symmetric band matrix A, stored column by column.

The k-th superdiagonal is stored in the k-th column above the main diagonal, and the k-th subdiagonal is stored in the k-th column below the main diagonal.

The main diagonal is stored in the first column of the array AB. The first superdiagonal is stored in the second column of AB, and so on.

More precisely, if UPLO = 'U', the elements AB(i, k+1) correspond to the elements A(i, i+k) for i = 1, ..., N-k and k = 0, ..., KD.

If UPLO = 'L', the elements AB(i, kd-i+j+1) correspond to the elements A(i, j) for j = 1, ..., i and i = 1, ..., N.

On exit, AB is overwritten by values generated during the computation and no longer represents the input matrix A.

INTEGER :: LDAB

The leading dimension of the array AB. LDAB >= LDAB.

REAL, INTENT(OUT) :: AP( * )

On exit, if FACT = 'E', AP contains the eigenvalues, sorted in ascending order. If FACT = 'N', AP is unchanged.

REAL, INTENT(OUT) :: SDP( * )

On exit, if FACT = 'E', SDP contains the square roots of the reciprocals of the non-zero diagonal elements of the upper triangular factor of U*DU**T. If FACT = 'N', SDP is unchanged.

REAL, INTENT(OUT) :: Q( LDQ, * )

On exit, if eigenvectors are requested, the orthogonal matrix Q whose columns are the eigenvectors. If FACT = 'N', Q is unchanged.

INTEGER :: LDQ

The leading dimension of the array Q. If eigenvectors are requested, LDQ >= max(1, N).

REAL, INTENT(OUT) :: Z( LDZ, * )

On exit, Z contains the eigenvectors in packed storage. If eigenvectors are requested, Z contains the eigenvectors of A in the order corresponding to the eigenvalues in AP. The eigenvectors are normalized so that the first element of each vector is 1.

On exit, Z contains the computed eigenvectors in packed storage. If FACT = 'N', Z is unchanged.

INTEGER :: LDZ

The leading dimension of the array Z. LDZ >= max(1, N).

REAL, INTENT(OUT) :: WORK( * )

On exit, if FACT = 'E', WORK(1) contains the maximum value of the absolute value of the computed relative residual eigenvalues. If FACT = 'N', WORK is unchanged.

INTEGER, INTENT(OUT) :: INFO

= 0: success return

< 0: if INFO = -i, the i-th argument had an illegal value

> 0: if INFO = i, and i <= N, the algorithm failed to converge; i off-diagonal elements of an intermediate tridiagonal matrix remain non-zero, and the diagonal elements of the corresponding eigenvectors do not necessarily converge to zero.

> N: if INFO = N + i, then the algorithm failed to converge; i off-diagonal elements of an intermediate tridiagonal matrix remain non-zero, and the diagonal elements of the corresponding eigenvectors do not necessarily converge to zero.
