subrutina ssytf2_rk (uplo, n, a, lda, e, ipiv, info)
SSYTF2_RK calcula la factorización de una matriz simétrica indefinida real utilizando el método de pivoteo diagonal Bunch-Kaufman acotado (método sin bloqueo BLAS2).

Documentación de Función/Subrutina

subrutina ssytf2_rk (carácter uplo, entero n, real, dimensión( lda, * ) a, entero lda, real, dimensión( * ) e, entero, dimensión( * ) ipiv, entero info)

SSYTF2_RK calcula la factorización de una matriz simétrica indefinida real utilizando el método de pivoteo diagonal Bunch-Kaufman acotado (método sin bloqueo BLAS2).

Propósito:

!> SSYTF2_RK calcula la factorización de una matriz simétrica real A
!> utilizando el método de pivoteo diagonal Bunch-Kaufman acotado (rook):
!>
!>    A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz triangular unitaria superior (o inferior),
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es simétrica y de bloques diagonales
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión sin bloqueo del algoritmo, que llama a BLAS de Nivel 2.
!> Para más información, véase la sección Detalles Adicionales.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte superior triangular de N por N
!>            de A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no
!>            se referencia.
!>
!>            Si UPLO = 'L': la parte inferior triangular de N por N
!>            de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no
!>            se referencia.
!>
!>          En la salida, contiene:
!>            a) SÓLO los elementos diagonales de la matriz simétrica
!>               diagonal de bloques D en la diagonal de A, es decir,
!>               D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es un array REAL, de dimensión (N)
!>          En la salida, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz simétrica diagonal de bloques D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece en 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece en 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece en 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiadas con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloques
!>          de la matriz simétrica diagonal de bloques D con bloques
!>          diagonales de 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización. Para más información, véase la
!>          sección Detalles Adicionales.
!>
!>          Si UPLO = 'U',
!>          (en orden de factorización, k disminuye de N a 1):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>
!>          Si UPLO = 'L',
!>          (en orden de factorización, k aumenta de 1 a N):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, debido a que:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto, D(k,k) es exactamente cero, y los elementos
!>               superdiagonales de la columna k de U (o los elementos
!>               subdiagonales de la columna k de L) son todos ceros.
!>               La factorización se ha completado, pero la matriz diagonal
!>               de bloques D es exactamente singular, y ocurrirá una división
!>               por cero si se utiliza para resolver un sistema de ecuaciones.
!>
!>               NOTA: INFO solo almacena la primera ocurrencia de
!>               una singularidad, cualquier ocurrencia posterior de singularidad
!>               no se almacena en INFO aunque la factorización
!>               siempre se completa.
!>

NAME

ssytf2_rk - ssytf2_rk computes a decomposition of a real symmetric tridiagonal matrix.

SYNOPSIS

  SUBROUTINE SSYTF2_RK( UPLO, N, A, LDA, D, E, TAU, INFO )
  CHARACTER * 1 UPLO
  INTEGER N, LDA, INFO
  REAL    A( LDA, * ), D( * ), E( * ), TAU( * )

Function/Subroutine Documentation

  UPLO
        (input) CHARACTER*1
        Specifies whether the matrix A is upper or lower triangular.
        UPLO = 'U'   A is upper triangular.
        UPLO = 'L'   A is lower triangular.

  N
        (input) INTEGER
        The order of the matrix A.  N >= 0.

  A
        (input/output) REAL for A( LDA, * )
        On entry, the symmetric tridiagonal matrix A, stored in the
        upper or lower triangle of the array A. The diagonal elements are
        in A(i,i), and the super-diagonal elements are in A(i,i+1)
        for UPLO = 'U', and the sub-diagonal elements are in A(i+1,i)
        for UPLO = 'L'.
        On exit, the transformed tridiagonal matrix A.

  LDA
        (input) INTEGER
        The leading dimension of the array A. LDA >= max(1,N).

  D
        (output) REAL for D( * )
        On exit, the vector D contains the diagonal elements of the
        transformed tridiagonal matrix.

  E
        (output) REAL for E( * )
        On exit, the vector E contains the off-diagonal elements of the
        transformed tridiagonal matrix. E(i) stores the element E(i) in
        the notation used in the LAPACK User's Guide.

  TAU
        (output) REAL for TAU( * )
        On exit, the vector TAU contains the scalar factors of the
        elementary reflectors.

  INFO
        (output) INTEGER
        = 0:  successful exit
        < 0:  if INFO = -i, the i-th argument had an illegal value.
        > 0:  if INFO = i, the decomposition failed and the least
              rank number is i.
