NOMBRE

sscg - Herramienta para generar certificados x.509

SINOPSIS

sscg [OPCIÓN...]

DESCRIPCIÓN

-V, --version
Muestra el número de versión y sale.
-f, --force
Sobrescribe cualquier archivo preexistente en las ubicaciones solicitadas. PELIGRO: ¡Probablemente no querrás usar esto!

Opciones de ayuda:

-?, --help
Muestra este mensaje de ayuda
--usage
Muestra un breve mensaje de uso

Opciones de verbosidad

-q, --quiet
No muestra ninguna salida a menos que haya un error.
-v, --verbose
Muestra mensajes de progreso.
-d, --debug
Habilita el registro de mensajes de depuración. Implica verboso. ¡Advertencia! ¡Esto mostrará información de clave privada en la pantalla!

Opciones del Sujeto del Certificado

--lifetime=1-3650
Vida útil del certificado (días). (por defecto: 398)
--country=ES, MX, etc.
DN del certificado: País (C). (por defecto: "ES")
--state=Madrid, Andalucía, etc.
DN del certificado: Estado o Provincia (ST).
--locality=Madrid, Barcelona, etc.
DN del certificado: Localidad (L).
--organization=Mi Empresa
DN del certificado: Organización (O). (por defecto: "No especificado")
--organizational-unit=Ingenieria, etc.
DN del certificado: Unidad Organizacional (OU).
--email=mi_nombre@ejemplo.com
DN del certificado: Dirección de correo electrónico (Email).
--hostname=servidor.ejemplo.com
El nombre de host válido del certificado. Debe ser un FQDN. (por defecto: FQDN del sistema actual)
--subject-alt-name alt.ejemplo.com
Nombres de host adicionales válidos opcionales para el certificado. Además de los nombres de host, esta opción también acepta valores explícitos soportados por RFC 5280, como IP:xxx.xxx.xxx.xxx. Se puede especificar múltiples veces.

Opciones de Criptografía de Clave del Certificado

--key-type={rsa,ecdsa,mldsa}
Tipo de clave a utilizar para las claves privadas del certificado. (por defecto: rsa)
--key-strength=2048 o mayor
Fuerza de las claves privadas del certificado en bits. Este argumento solo es válido si --key-type está establecido a rsa. (por defecto: 2048)
--ec-curve={secp224r1,secp256r1,secp384r1,secp521r1}
Curva EC a utilizar para las claves privadas del certificado. Este argumento solo es válido si --key-type está establecido a ecdsa.
--mldsa-nist-level={2,3,5}
Nivel NIST a utilizar para la clave ML-DSA. Este argumento solo es válido si --key-type está establecido a mldsa. (por defecto: 2)
--hash-alg={sha256,sha384,sha512}
Algoritmo de hashing a utilizar para firmar claves RSA y ECDSA. Este argumento solo es válido si --key-type es rsa o ecdsa. (por defecto: "sha256")
--cipher-alg={des-ede3-cbc,aes-256-cbc}
Cifrado a utilizar para encriptar archivos de clave. (por defecto: "aes-256-cbc")

Opciones de Archivo de Autoridad Certificadora

--ca-file=CADENA
Ruta donde se almacenará el certificado público de la CA. (por defecto: "./ca.crt")
--ca-mode=0644
Modo de archivo del certificado de CA creado.
--ca-key-file=CADENA
Ruta donde se almacenará la clave privada de la CA. Si no se especifica, la clave se destruirá en lugar de escribirse en el disco.
--ca-key-mode=0600
Modo de archivo de la clave de CA creada.
--ca-key-password=CADENA
Proporciona una contraseña para el archivo de clave de CA. Ten en cuenta que será visible en la tabla de procesos para todos los usuarios, por lo que solo debe usarse con fines de prueba. Usa --ca-keypassfile o --ca-key-password-prompt para una entrada segura de contraseña.
--ca-key-passfile=CADENA
Un archivo que contiene la contraseña para encriptar el archivo de clave de CA.
-C, --ca-key-password-prompt
Solicita introducir una contraseña para el archivo de clave de CA.

Opciones de Archivo de Lista de Revocación de Certificados

--crl-file=CADENA
Ruta donde se creará un archivo de Lista de Revocación de Certificados (vacío), para aplicaciones que esperan que dicho archivo exista. Si no se especifica, no se creará dicho archivo.
--crl-mode=0644
Modo de archivo de la Lista de Revocación de Certificados creada.

Opciones de Archivo de Certificado de Servicio

--cert-file=CADENA
Ruta donde se almacenará el certificado público del servicio. (por defecto "./service.pem")
--cert-mode=0644
Modo de archivo del certificado creado.
--cert-key-file=CADENA
Ruta donde se almacenará la clave privada del servicio. (por defecto "service-key.pem")
--cert-key-mode=0600
Modo de archivo de la clave del certificado creada.
-p, --cert-key-password=CADENA
Proporciona una contraseña para el archivo de clave del servicio. Ten en cuenta que será visible en la tabla de procesos para todos los usuarios, por lo que esta opción solo debe usarse con fines de prueba. Usa --cert-keypassfile o --cert-key-password-prompt para una entrada segura de contraseña.
--cert-key-passfile=CADENA
Un archivo que contiene la contraseña para encriptar el archivo de clave del servicio.
-P, --cert-key-password-prompt
Solicita introducir una contraseña para el archivo de clave del servicio.

Opciones de Archivo de Certificado de Autenticación de Cliente

--client-file=CADENA
Ruta donde se almacenará un certificado de autenticación de cliente.
--client-mode=0644
Modo de archivo del certificado creado.
--client-key-file=CADENA
Ruta donde se almacenará la clave privada del cliente. (por defecto es el archivo-cliente)
--client-key-mode=0600
Modo de archivo de la clave del certificado creada.
--client-key-password=CADENA
Proporciona una contraseña para el archivo de clave del cliente. Ten en cuenta que será visible en la tabla de procesos para todos los usuarios, por lo que esta opción solo debe usarse con fines de prueba. Usa --client-keypassfile o --client-key-password-prompt para una entrada segura de contraseña.
--client-key-passfile=CADENA
Un archivo que contiene la contraseña para encriptar el archivo de clave del cliente.
--client-key-passwo
Solicita introducir una contraseña para el archivo de clave del cliente.

sscg - Tool for generating signed certificate chains.

NAME

sscg - Tool for generating signed certificate chains.

SYNOPSIS

sscg [OPTIONS] [SUBCOMMAND]

DESCRIPTION

sscg is a tool for generating signed certificate chains. It can be used to create self-signed certificates, certificate authorities, and end-entity certificates.

The following options are available:

--config-file=STRING
Load configuration from the specified file.
--key-file=STRING
The path to the client private key file.
--key-password-file=STRING
Prompt to enter a password for the client key file.

Diffie-Hellman Parameter File Options

--dhparams-file=STRING
A file to contain a set of Diffie-Hellman parameters. (Default: not created)
--dhparams-named-group=STRING
Output well-known DH parameters. The available named groups are: ffdhe2048, ffdhe3072, ffdhe4096, ffdhe6144, ffdhe8192, modp_2048, modp_3072, modp_4096, modp_6144, modp_8192, modp_1536, dh_1024_160, dh_2048_224, dh_2048_256. (Default: "ffdhe4096")
--dhparams-generator={2,3,5}
The generator value for dhparams. (default: 2)
