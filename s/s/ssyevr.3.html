SSYEVR calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices SY

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina ssyevr (character jobz, character range, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSYEVR calcula valores propios seleccionados y, opcionalmente, vectores propios de una matriz simétrica real A. Los valores propios y vectores propios pueden ser seleccionados especificando un rango de valores o un rango de índices para los valores propios deseados. Las invocaciones con diferentes opciones para estos parámetros pueden resultar en el cálculo de valores propios y/o vectores propios ligeramente diferentes para la misma matriz. La razón de este comportamiento es que existe una variedad de algoritmos (cada uno funcionando mejor para un conjunto particular de opciones) con SSYEVR intentando seleccionar el mejor basado en los varios parámetros. En todos los casos, los valores calculados son precisos dentro de los límites de la aritmética de precisión finita.

Propósito:

!>
!> SSYEVR calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de una matriz simétrica real A. Los valores propios y vectores propios pueden ser
!> seleccionados especificando ya sea un rango de valores o un rango de índices
!> para los valores propios deseados. Las invocaciones con diferentes opciones para
!> estos parámetros pueden resultar en el cálculo de valores propios y/o vectores propios
!> ligeramente diferentes para la misma matriz. La razón de este comportamiento es
!> que existe una variedad de algoritmos (cada uno funcionando mejor para un conjunto
!> particular de opciones) con SSYEVR intentando seleccionar el mejor basado en los
!> varios parámetros. En todos los casos, los valores calculados son precisos dentro de los límites de la aritmética de precisión finita.
!>
!> SSYEVR primero reduce la matriz A a forma tridiagonal T con una llamada
!> a SSYTRD. Luego, siempre que sea posible, SSYEVR llama a SSTEMR para calcular
!> el espectro de valores propios utilizando Representaciones Relativamente Robustas.
!> SSTEMR calcula los valores propios mediante el algoritmo dqds, mientras que los
!> vectores propios ortogonales se calculan a partir de varias representaciones L D L^T
!> (también conocidas como Representaciones Relativamente Robustas). La
!> ortogonalización de Gram-Schmidt se evita tanto como sea posible. Más específicamente,
!> los varios pasos del algoritmo son los siguientes:
!>
!> Para cada bloque no reducido (submatriz) de T,
!>    (a) Calcula T - sigma I = L D L^T, de modo que L y D
!>        definen todos los valores propios deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los valores propios y
!>        vectores propios. La representación estándar (no factorizada) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcula los valores propios con precisión adecuada.
!>        Si se desean los vectores propios, el algoritmo alcanza la precisión completa
!>        de los valores propios calculados solo justo antes de que los
!>        vectores correspondientes tengan que ser calculados, ver pasos c) y d).
!>    (c) Para cada cluster de valores propios cercanos, selecciona un nuevo
!>        desplazamiento cercano al cluster, encuentra una nueva factorización y refina
!>        los valores propios desplazados con precisión adecuada.
!>    (d) Para cada valor propio con una separación relativa suficientemente grande, calcula
!>        el vector propio correspondiente formando una factorización torcida que revela el rango. Vuelve al paso c) para cualquier cluster que permanezca.
!>
!> La precisión deseada de la salida puede ser especificada por el parámetro de
!> entrada ABSTOL.
!>
!> Para más detalles, ver la documentación de SSTEMR y:
!> - Inderjit S. Dhillon y Beresford N. Parlett:
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, Agosto 2004.
!> - Inderjit Dhillon y Beresford Parlett: SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004. También LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, Mayo 1997.
!>
!>
!> Nota 1: SSYEVR llama a SSTEMR cuando se solicita el espectro completo
!> en máquinas que cumplen con el estándar de punto flotante ieee-754.
!> SSYEVR llama a SSTEBZ y SSTEIN en máquinas no ieee y
!> cuando se solicitan espectros parciales.
!>
!> La ejecución normal de SSTEMR puede crear NaNs e infinitos y
!> por lo tanto puede abortar debido a una excepción de punto flotante en entornos
!> que no manejan NaNs e infinitos en la forma predeterminada estándar de ieee.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>
!>          Este parámetro influye en la elección del algoritmo y
!>          puede alterar los valores calculados.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>          Para RANGE = 'V' o 'I' y IU - IL < N - 1, se llaman SSTEBZ y
!>          SSTEIN
!>
!>          Este parámetro influye en la elección del algoritmo y
!>          puede alterar los valores calculados.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la
!>          parte triangular superior N-por-N principal de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior N-por-N principal de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, se
!>          destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o igual a
!>          cero, entonces EPS*|T| se usará en su lugar,
!!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Ver  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si la alta precisión relativa es importante, establezca ABSTOL a
!>

M

!>          M es INTEGER
!>          El número de valores propios encontrados.
!>          Si RANGE = 'A' o 'V', M es el número de valores propios en el
!>          intervalo (VL, VU] respectivamente.
!>          Si RANGE = 'I', M es igual a IU - IL + 1.
!>

W

!>          W es REAL array, dimensión (N)
!>          Si JOBZ = 'N', W almacena los valores propios de A en orden
!>          ascendente.
!>          Si JOBZ = 'V', W almacena los valores propios de A en orden
!>          ascendente, y la información relativa a los vectores propios
!>          se almacena en Z.
!>          Sólo se devuelven los valores propios calculados.
!>

Z

!>          Z es REAL array, dimensión (LDZ, N)
!>          Si JOBZ = 'V', Z contiene los vectores propios correspondientes a
!>          los valores propios en W.  Los vectores propios se normalizan
!>          de tal manera que la norma euclidiana de cada columna es 1.
!>          Si JOBZ = 'N', Z no se utiliza.
!>          Los vectores propios se calculan de forma que las columnas correspondientes
!>          a los valores propios cercanos se calculan con la misma precisión.
!>          En este caso, las columnas correspondientes a los valores propios
!>          cercanos pueden no ser ortogonales entre sí.
!>          Si RANGE = 'V' o 'I', los vectores propios solo se calculan para
!>          los valores propios que satisfacen las condiciones especificadas.
!>          Si se requieren todos los vectores propios, el algoritmo intenta
!>          calcularlos todos.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ es INTEGER array, dimensión (N)
!>          Los índices de soporte de los vectores propios. Cada entrada
!>          ISUPPZ(i) especifica el primer índice no nulo del vector propio
!>          correspondiente a W(i). La información se calcula para los
!>          vectores propios correspondientes a los valores propios en el
!>          rango especificado por RANGE, y se almacena en las columnas
!>          correspondientes de Z.
!>          Por ejemplo, si W(i) está en el rango y el vector propio
!>          correspondiente Z(:,i) tiene entradas nulas, entonces ISUPPZ(i)
!>          será el índice de la primera entrada no nula. Si no hay entradas
!>          nulas, ISUPPZ(i) será 1.
!>          Si JOBZ = 'N', ISUPPZ no se utiliza.
!>

WORK

!>          WORK es REAL array, dimensión (LWORK)
!>          En la salida, WORK(1) contiene el tamaño mínimo de LWORK.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>          Para la correcta operatividad, LWORK debe ser al menos
!>          max(1, 2*N).
!>          Si LWORK = -1, entonces se reserva espacio y se devuelve el
!>          tamaño mínimo requerido.
!>

IWORK

!>          IWORK es INTEGER array, dimensión (LIWORK)
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK. LIWORK >= 1.
!>          Para la correcta operatividad, LIWORK debe ser al menos
!>          max(1, 3*N).
!>          Si LIWORK = -1, entonces se reserva espacio y se devuelve el
!>          tamaño mínimo requerido.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  ejecución correcta.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor inválido.
!>          > 0:  el algoritmo de convergencia del algoritmo de búsqueda de
!>                intervalos falló en converger. Nadie encontró un valor propio.
!>                Tanto IL como IU están establecidos al valor de INFO.
!>                 Consulte el registro de depuración para obtener más detalles.
!>

NAME

ssyevr - computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.

SYNOPSIS

    SUBROUTINE SSYEVR( JOBZ, RANGE, UPLO, N, D, E, VL, VU, IL, IU, ABSTOL,
                          M, W, Z, LDZ, ISUPPZ, WORK, LWORK, IWORK, LIWORK,
                          INFO )
        CHARACTER * 1  JOBZ, RANGE, UPLO
        INTEGER        IL, IU, INFO, LDZ, LIWORK, LWORK, M, N
        REAL           ABSTOL
        REAL           D( * ), E( * ), VL, VU, W( * ), WORK( * )
        INTEGER        ISUPPZ( * )
        REAL           Z( LDA, * )

Function/Subroutine Documentation

SSYEVR computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.

Arguments

JOBZ

!> JOBZ is CHARACTER*1
!> = 'N':  Compute only the eigenvalues of A.
!> = 'V':  Compute the eigenvalues and eigenvectors of A.
!>

RANGE

!> RANGE is CHARACTER*1
!> = 'A': all eigenvalues will be found.
!> = 'V': all eigenvalues in the half-open interval (VL, VU] will be
!>         found.
!> = 'I': all eigenvalues in the open interval (IL, IU), in terms of
!>         indices in the sorted order, will be found.
!>

UPLO

!> UPLO is CHARACTER*1
!> = 'U':  Upper triangle of A is used.
!> = 'L':  Lower triangle of A is used.
!>

N

!> N is INTEGER
!> The order of the matrix T.  N >= 0.
!>

D

!> D is REAL array, dimension (N)
!> On entry, the N diagonal elements of the tridiagonal matrix T.
!> On exit, D contains the eigenvalues of T in ascending order.
!>

E

!> E is REAL array, dimension (N)
!> On entry, the (N-1) subdiagonal elements of the tridiagonal matrix T.
!> On exit, E has been modified.
!>

VL

!> VL is REAL
!> If RANGE = 'V', the lower bound of the interval for the desired
!> eigenvalues.
!>

VU

!> VU is REAL
!> If RANGE = 'V', the upper bound of the interval for the desired
!> eigenvalues.
!>

IL

!> IL is INTEGER
!> If RANGE = 'I', the index of the lowest eigenvalue in the sorted
!> order.
!>

IU

!> IU is INTEGER
!> If RANGE = 'I', the index of the highest eigenvalue in the sorted
!> order.
!>

ABSTOL

!> ABSTOL is REAL
!> The desired tolerance for the eigenvalues.
!> If ABSTOL <= 0, then ABSTOL = eps* (max(|d_i|,|e_i|))
!> where eps is the machine epsilon of the datatype.
!> Note that if ABSTOL is very small, the corresponding eigenvectors may
!> not be computed accurately.
!> It is recommended that ABSTOL be set to SLAMCH('Safe minimum'). Doing so
!> will guarantee that eigenvalues are computed to high relative accuracy when
!> possible in future releases. The current code does not make any guarantees
!> about high relative accuracy, but future releases will. See J. Barlow and J.
!> Demmel, , LAPACK Working Note #7, for a discussion of which matrices define
!> their eigenvalues to high relative accuracy.
!>

M

!> M is INTEGER
!> The total number of eigenvalues found.  0 <= M <= N.
!> If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.
!>

W

!> W is REAL array, dimension (N)
!> If RANGE = 'A', W contains the eigenvalues in ascending order.
!> If RANGE = 'V', W contains the eigenvalues in the interval (VL, VU] in
!> ascending order.
!> If RANGE = 'I', W contains the eigenvalues in the interval (IL, IU] in
!> ascending order.
!>

Z

!> Z is REAL array, dimension (LDZ, max(1,N))
!> If JOBZ = 'V', then if INFO = 0, the columns of Z are the normalized
!> eigenvectors, given the eigenvalue W(I) in the i-th column.
!> If JOBZ = 'N', then Z is not referenced.
!> Note: the user must ensure that at least max(1,M) columns are supplied
!> in the array Z; if RANGE = 'V', the exact value of M is not known in
!> advance and an upper bound must be used. Supplying N columns is always
!> safe.
!>

LDZ

!> LDZ is INTEGER
!> The leading dimension of the array Z. LDZ >= 1, and if JOBZ = 'V',
!> LDZ >= max(1,N).
!>

ISUPPZ

!> ISUPPZ is INTEGER array, dimension ( 2*max(1,N) )
!> The support of the eigenvectors in Z, i.e., the indices indicating the
!> nonzero elements in Z. The i-th eigenvector is nonzero only in elements
!> ISUPPZ( 2*i-1 ) through ISUPPZ( 2*i ). This is an output of SSTEMR
!> (tridiagonal matrix). The support of the eigenvectors of A is typically
!> 1:N because of the orthogonal transformations applied by SORMTR.
!> Implemented only for RANGE = 'A' or 'I' and IU - IL = N - 1
!>

WORK

!> WORK is REAL array, dimension (MAX(1,LWORK))
!> On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!> LWORK is INTEGER
!> The dimension of the array WORK.
!> If N <= 1, LWORK >= 1, else LWORK >= 26*N.
!> For optimal efficiency, LWORK >= (NB+6)*N,
!> where NB is the max of the blocksize for SSYTRD and SORMTR
!> returned by ILAENV.
!>
!> If LWORK = -1, then a workspace query is assumed; the routine
!> only calculates the optimal sizes of the WORK and IWORK
!> arrays, returns these values as the first entries of the WORK
!> and IWORK arrays, and no error message related to LWORK or
!> LIWORK is issued by XERBLA.
!>

IWORK

!> IWORK is INTEGER array, dimension (MAX(1,LIWORK))
!> On exit, if INFO = 0, IWORK(1) returns the optimal LWORK.
!>

LIWORK

!> LIWORK is INTEGER
!> The dimension of the array IWORK.
!> If N <= 1, LIWORK >= 1, else LIWORK >= 10*N.
!>
!> If LIWORK = -1, then a workspace query is assumed; the
!> routine only calculates the optimal sizes of the WORK and
!> IWORK arrays, returns these values as the first entries of
!> the WORK and IWORK arrays, and no error message related to
!> LWORK or LIWORK is issued by XERBLA.
!>

INFO

!> INFO is INTEGER
!> = 0:  successful exit
!> < 0:  if INFO = -i, the i-th argument had an illegal value
!> > 0:  Internal error
!>
