subroutine ssysvx (character fact, character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

SSYSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> SSYSVX utiliza la factorización por pivoteo diagonal para calcular la
!> solución a un sistema real de ecuaciones lineales A * X = B,
!> donde A es una matriz simétrica de N por N y X y B son matrices de N por NRHS.
!>
!> También se proporcionan cotas de error para la solución y una estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza el método de pivoteo diagonal para factorizar A.
!>    La forma de la factorización es
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices de permutación y triangulares superiores (inferiores) unitarias, y D es simétrica y diagonal por bloques con
!>    bloques diagonales de 1x1 y 2x2.
!>
!> 2. Si algún D(i,i)=0, de modo que D sea exactamente singular, entonces la rutina
!>    retorna con INFO = i. De lo contrario, se utiliza la forma factorizada de A
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina continúa
!>    resolviendo para X y calculando cotas de error como se describe a continuación.
!>
!> 3. Se resuelve el sistema de ecuaciones para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    matriz y calcular cotas de error y estimaciones de error hacia atrás
!>    para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A se ha proporcionado
!>          en la entrada o no.
!>          = 'F':  En la entrada, AF y IPIV contienen la forma factorizada de
!>                  A. AF e IPIV no se modificarán.
!>          = 'N':  La matriz A se copiará a AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

A

!>          A es una matriz REAL, de dimensión (LDA,N)
!>          La matriz simétrica A. Si UPLO = 'U', la parte superior triangular
!>          N por N de A contiene la parte superior triangular de
!>          la matriz A, y la parte estrictamente inferior triangular de A
!>          no se referencia. Si UPLO = 'L', la parte inferior triangular
!>          N por N de A contiene la parte inferior triangular de
!>          la matriz A, y la parte estrictamente superior triangular de A
!>          no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A. LDA >= max(1,N).
!>

AF

!>          AF es una matriz REAL, de dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>          contiene la matriz diagonal por bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T tal como lo calcula SSYTRF.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>          devuelve la matriz diagonal por bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T.
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal de la matriz AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV es una matriz INTEGER, de dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, según lo determinado por SSYTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2. Si UPLO = 'L' e IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 y -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, según lo determinado por SSYTRF.
!>

B

!>          B es una matriz REAL, de dimensión (LDB,NRHS)
!>          La matriz del lado derecho B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B. LDB >= max(1,N).
!>

X

!>          X es una matriz REAL, de dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal de la matriz X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La estimación del número de condición recíproco de la matriz
!>          A. Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular con precisión de trabajo.
!>          Esta condición se indica con un código de retorno de
!>          INFO > 0.
!>

FERR

!>          FERR es una matriz REAL, de dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error real.
!>

BERR

!>          BERR es una matriz REAL, de dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

NAME

ssysvx - ssysvx

SYNOPSIS

 Subroutine ssysvx (FACT, UPLO, N, NRHS, A, LDA, AF, LDAF, IPIV, B, LDB, X, LDX, RCOND, SRCOND, WORK, IWORK, INFO)

Double precision elements are used.

Function/Subroutine Documentation

Esta es la documentación de la rutina ssysvx.

Argumentos

FACT
CHARACTER*1. Debe ser 'F' o 'N'.
UPLO
CHARACTER*1. Debe ser 'U' o 'L'.
N
INTEGER. El orden de la matriz A.
NRHS
INTEGER. El número de columnas de B y X.
A
REAL. Matriz de entrada, dimensión (LDA, N).
LDA
INTEGER. Longitud de las filas de A.
AF
REAL. Descomposición LU de la matriz A, dimensión (LDAF, N).
LDAF
INTEGER. Longitud de las filas de AF.
IPIV
INTEGER. Pivotes de la descomposición LU, dimensión (N).
B
REAL. Matriz de lado derecho, dimensión (LDB, NRHS).
LDB
INTEGER. Longitud de las filas de B.
X
REAL. Solución de la variable, dimensión (LDX, NRHS).
LDX
INTEGER. Longitud de las filas de X.
RCOND
REAL. Estimación del recíproco del número de condición.
SRCOND
REAL. Estimación del recíproco del número de condición.
WORK
REAL. Array de trabajo.
IWORK
INTEGER. Array de trabajo.
INFO
INTEGER. Información de salida.

Detalles

FACT

 If FACT = 'F', then A is assumed to be already factorizado as computed by SSYTRF.
 If FACT = 'N', then the factorisation of A is computed and then used in the
          call to SSSV.
 Use FACT = 'F' when the factorised form of A is needed in more than
          one call to sssvx.
 The only arrays that are not modified are A and B.

UPLO

 If UPLO = 'U', Upper triangle of A is used.
 If UPLO = 'L', Lower triangle of A is used.

WORK

 If LWORK < 0, then the workspace needed by the called routines is computed
          and stored in the first entry of the array WORK, and no further
          processing is done.
 For best performance, when FACT = 'N', LWORK >= max(1,3*N,N*NB), where
          NB is the optimal blocksize for SSYTRF.
 If LWORK = -1, then a workspace query is assumed; the routine
          only calculates the optimal size of the WORK array, returns
          this value as the first entry of the WORK array, and no error
          message related to LWORK is issued by XERBLA.

IWORK

 IWORK is INTEGER array, dimension (N)

INFO

 INFO is INTEGER
 = 0: successful exit
 < 0: if INFO = -i, the i-th argument had an illegal value
 > 0: if INFO = i, and i is
                <= N:  D(i,i) is exactly zero.  The factorization
                       has been completed but the factor D is exactly
                       singular, so the solution and error bounds could
                       not be computed. RCOND = 0 is returned.
                = N+1: D is nonsingular, but RCOND is less than machine
                       precision, meaning that the matrix is singular
                       to working precision.  Nevertheless, the
                       solution and error bounds are computed because
                       there are a number of situations where the
                       computed solution can be more accurate than the
                       value of RCOND would suggest.
