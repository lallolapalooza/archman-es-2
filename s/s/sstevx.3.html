SSTEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para OTRAS matrices

Documentación de Función/Subrutina

subrutina sstevx (carácter jobz, carácter range, entero n, real, dimensión( * ) d, real, dimensión( * ) e, real vl, real vu, entero il, entero iu, real abstol, entero m, real, dimensión( * ) w, real, dimensión( ldz, * ) z, entero ldz, real, dimensión( * ) work, entero, dimensión( * ) iwork, entero, dimensión( * ) ifail, entero info)

SSTEVX calcula los valores propios seleccionados y, opcionalmente, los vectores propios de una matriz tridiagonal simétrica real A. Los valores propios y los vectores propios se pueden seleccionar especificando un rango de valores o un rango de índices para los valores propios deseados.

Propósito:

!>
!> SSTEVX calcula los valores propios seleccionados y, opcionalmente, los vectores propios
!> de una matriz tridiagonal simétrica real A.  Los valores propios y
!> los vectores propios pueden ser seleccionados especificando ya sea un rango de valores
!> o un rango de índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Solo se calculan los valores propios;
!>          = 'V':  Se calculan los valores propios y los vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 se encontrarán.
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es array REAL, dimensión (N)
!>          En la entrada, los n elementos diagonales de la matriz tridiagonal
!>          A.
!>          En la salida, D puede ser multiplicado por un factor constante elegido
!>          para evitar desbordamiento superior/inferior al calcular los valores propios.
!>

E

!>          E es array REAL, dimensión (max(1,N-1))
!>          En la entrada, los (n-1) elementos subdiagonales de la matriz tridiagonal
!>          A en los elementos 1 a N-1 de E.
!>          En la salida, E puede ser multiplicado por un factor constante elegido
!>          para evitar desbordamiento superior/inferior al calcular los valores propios.
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          ser buscado para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          ser buscado para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a ser devuelto.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a ser devuelto.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor
!>          o igual a cero, entonces se usará EPS*|T| en
!>          su lugar, donde |T| es la norma 1 de la matriz tridiagonal.
!>
!>          Los valores propios se calcularán con la mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de desbordamiento inferior 2*SLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*SLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, Nota de trabajo de LAPACK #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array REAL, dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es array REAL, dimensión (LDZ, max(1,M) )
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Si un vector propio falla en converger (INFO > 0), entonces esa
!>          columna de Z contiene la última aproximación al
!>          vector propio, y el índice del vector propio se devuelve
!>          en IFAIL. Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión líder del array Z. LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array REAL, dimensión (5*N)
!>

IWORK

!>          IWORK es array INTEGER, dimensión (5*N)
!>

IFAIL

!>          IFAIL es array INTEGER, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que fallaron en converger.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, entonces el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, entonces i vectores propios fallaron en converger.
!>                Sus índices se almacenan en el array IFAIL.
!>
