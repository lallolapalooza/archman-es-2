Documentación de Función/Subrutina

subroutine ssytrs_3 (character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( * ) e, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, integer info)

SSYTRS_3

Propósito:

!> SSYTRS_3 resuelve un sistema de ecuaciones lineales A * X = B con una matriz
!> simétrica real A utilizando la factorización calculada
!> por SSYTRF_RK o SSYTRF_BK:
!>
!>    A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz triangular unitaria superior (o inferior),
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es simétrica y de bloques diagonales
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Este algoritmo utiliza BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se
!>          almacenan como una matriz triangular superior o inferior:
!>          = 'U':  Triangular superior, forma es A = P*U*D*(U**T)*(P**T);
!>          = 'L':  Triangular inferior, forma es A = P*L*D*(L**T)*(P**T).
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>          Diagonal de la matriz diagonal de bloques D y factores U o L
!>          tal como fue calculada por SSYTRF_RK y SSYTRF_BK:
!>            a) SÓLO los elementos diagonales de la matriz simétrica diagonal
!>               de bloques D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                deben proporcionarse en la entrada en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es array REAL, dimensión (N)
!>          En la entrada, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz simétrica diagonal de bloques D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i),i=2:N, E(1) no referenciado;
!>          Si UPLO = 'L': E(i) = D(i+1,i),i=1:N-1, E(N) no referenciado.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) no se referencia en ambos
!>          casos de UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como fueron determinados por SSYTRF_RK o SSYTRF_BK.
!>

B

!>          B es array REAL, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
