Documentación de Función/Subrutina

subrutina ssysv_aa (character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) work, integer lwork, integer info)

SSYSV_AA calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> SSYSV calcula la solución a un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz simétrica N por N y X y B son matrices N por NRHS.
!>
!> Se utiliza el algoritmo de Aasen para factorizar A como
!>    A = U**T * T * U,  si UPLO = 'U', o
!>    A = L * T * L**T,  si UPLO = 'L',
!> donde U (o L) es un producto de matrices de permutación y unitarias triangulares
!> superiores (inferiores), y T es simétrica tridiagonal. La forma factorizada
!> de A se utiliza luego para resolver el sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array REAL, dimension (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular N por N líder de A contiene la parte
!>          superior triangular de la matriz A, y la parte estrictamente
!>          inferior triangular de A no se referencia.  Si UPLO = 'L', la parte
!>          inferior triangular N por N líder de A contiene la parte
!>          inferior triangular de la matriz A, y la parte estrictamente
!>          superior triangular de A no se referencia.
!>
!>          En la salida, si INFO = 0, la matriz tridiagonal T y los
!>          multiplicadores utilizados para obtener el factor U o L del
!>          factorización A = U**T*T*U o A = L*T*L**T según lo calculado por
!>          SSYTRF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimension (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A se intercambiaron con la
!>          fila y columna IPIV(k).
!>

B

!>          B es un array REAL, dimension (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= MAX(1,2*N,3*N-2), y para
!>          el mejor rendimiento, LWORK >= MAX(1,N*NB), donde NB es
!>          el tamaño de bloque óptimo para SSYTRF_AA.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0: si INFO = i, D(i,i) es exactamente cero. La factorización
!>               se ha completado, pero la matriz diagonal por bloques D es
!>               exactamente singular, por lo que la solución no pudo ser calculada.
!>
