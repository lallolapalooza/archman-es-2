Documentación de la Función/Subrutina

subroutine sstedc (character compz, integer n, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

SSTEDC

Propósito:

!>
!> SSTEDC calcula todos los valores propios y, opcionalmente, los vectores propios
!> de una matriz tridiagonal simétrica utilizando el método de divide y vencerás.
!> Los vectores propios de una matriz simétrica completa o de banda también pueden
!> encontrarse si se ha utilizado SSYTRD o SSPTRD o SSBTRD para reducir esta
!> matriz a forma tridiagonal.
!>
!>

Parámetros

COMPZ 
!>          COMPZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios.
!>          = 'I':  Calcular también los vectores propios de la matriz tridiagonal.
!>          = 'V':  Calcular también los vectores propios de la matriz simétrica original
!>                  completa. En la entrada, Z contiene la matriz ortogonal
!>                  utilizada para reducir la matriz original a
!>                  forma tridiagonal.
!>

N

!>          N es INTEGER
!>          La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

D

!>          D es un array REAL, dimensión (N)
!>          En la entrada, los elementos diagonales de la matriz tridiagonal.
!>          En la salida, si INFO = 0, los valores propios en orden ascendente.
!>

E

!>          E es un array REAL, dimensión (N-1)
!>          En la entrada, los elementos subdiagonales de la matriz tridiagonal.
!>          En la salida, E ha sido destruido.
!>

Z

!>          Z es un array REAL, dimensión (LDZ,N)
!>          En la entrada, si COMPZ = 'V', entonces Z contiene la matriz
!>          ortogonal utilizada en la reducción a forma tridiagonal.
!>          En la salida, si INFO = 0, entonces si COMPZ = 'V', Z contiene los
!>          vectores propios ortonormales de la matriz simétrica original,
!>          y si COMPZ = 'I', Z contiene los vectores propios ortonormales
!>          de la matriz tridiagonal simétrica.
!>          Si  COMPZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1.
!>          Si se desean vectores propios, entonces LDZ >= max(1,N).
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si COMPZ = 'N' o N <= 1 entonces LWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1 entonces LWORK debe ser al menos
!>                         ( 1 + 3*N + 2*N*lg N + 4*N**2 ),
!>                         donde lg( N ) = el entero más pequeño k tal
!>                         que 2**k >= N.
!>          Si COMPZ = 'I' y N > 1 entonces LWORK debe ser al menos
!>                         ( 1 + 4*N + N**2 ).
!>          Tenga en cuenta que para COMPZ = 'I' o 'V', si N es menor o
!>          igual al tamaño mínimo de división, generalmente 25, entonces LWORK solo
!>          necesita ser max(1,2*(N-1)).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor en la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si COMPZ = 'N' o N <= 1 entonces LIWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1 entonces LIWORK debe ser al menos
!>                         ( 6 + 6*N + 5*N*lg N ).
!>          Si COMPZ = 'I' y N > 1 entonces LIWORK debe ser al menos
!>                         ( 3 + 5*N ).
!>          Tenga en cuenta que para COMPZ = 'I' o 'V', si N es menor o
!>          igual al tamaño mínimo de división, generalmente 25, entonces LIWORK
!>          solo necesita ser 1.
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array IWORK,
!>          devuelve este valor en la primera entrada del array IWORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo no pudo calcular un valor propio mientras
!>                trabajaba en la submatriz ubicada en las filas y columnas
!>                INFO/(N+1) hasta mod(INFO,N+1).
!>
