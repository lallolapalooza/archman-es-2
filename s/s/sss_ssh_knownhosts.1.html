NOMBRE

sss_ssh_knownhosts - obtener claves públicas de known hosts de OpenSSH

SINOPSIS

sss_ssh_knownhosts [opciones] HOST

DESCRIPCIÓN

sss_ssh_knownhosts adquiere las claves públicas SSH para el host HOST y las muestra en el formato de clave known_hosts de OpenSSH (ver la sección "FORMATO DE ARCHIVO SSH_KNOWN_HOSTS" de sshd(8) para más información).

ssh(1) puede configurarse para usar sss_ssh_knownhosts para la autenticación de clave pública de host usando la opción "KnownHostsCommand":

                KnownHostsCommand /usr/bin/sss_ssh_knownhosts %H

Por favor, consulte la página del manual de ssh_config(5) para más detalles sobre esta opción.

Esta herramienta requiere que el servicio ssh de SSSD esté habilitado para funcionar correctamente.

OPCIONES

-d,--domain DOMINIO

Busca las claves públicas del host en el dominio SSSD DOMINIO.

-o,--only-host-name

Cuando las claves recuperadas del backend no incluyen el nombre de host, esta herramienta añadirá el nombre de host sin modificar tal como lo proporcionó el llamante. Si esta bandera está activada, solo se añadirá el nombre de host (sin número de puerto) a las claves.

-?,--help

Muestra el mensaje de ayuda y sale.

RECUPERACIÓN DE CLAVES

Se espera que las líneas de clave recuperadas del backend respeten el formato de clave descrito en la sección "FORMATO DE ARCHIVO SSH_KNOWN_HOSTS" de sshd(8). Sin embargo, se tolera que se devuelva solo el tipo de clave y la clave misma, en cuyo caso, el nombre de host recibido como parámetro se añadirá antes del tipo de clave para generar una línea con formato correcto. El nombre de host se añadirá sin modificar o solo el nombre de host (sin número de puerto), dependiendo de si se proporcionó la opción -o,--only-host-name.

Cuando el servidor SSH está escuchando en un puerto no predeterminado, el backend DEBE proporcionar el nombre de host, incluyendo el número de puerto, en el formato y posición correctos como parte de la línea de clave. Por ejemplo, la línea de clave mínima sería:

                [nombre.de.host.canónico]:2222 <tipo-clave> <clave-codificada-en-base64>

ESTADO DE SALIDA

En caso de ejecución exitosa, incluso si no se encontró ninguna clave para ese host o si no se pudo contactar al respondedor ssh, se devuelve 0. Se devuelve 1 en caso de cualquier otro error.
