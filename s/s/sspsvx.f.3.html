subroutine sspsvx (character fact, character uplo, integer n, integer nrhs, real, dimension( * ) ap, real, dimension( * ) afp, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SSPSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices OTROS

Propósito:

!>
!> SSPSVX utiliza la factorización de pivoteo diagonal A = U*D*U**T o
!> A = L*D*L**T para calcular la solución a un sistema real de ecuaciones lineales
!> A * X = B, donde A es una matriz simétrica de N por N almacenada
!> en formato empaquetado y X y B son matrices de N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza el método de pivoteo diagonal para factorizar A como
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices de permutación y triangulares superiores (inferiores) unitarias
!>    y D es simétrica y de bloques diagonales con bloques diagonales de 1x1 y 2x2.
!>
!> 2. Si algún D(i,i)=0, de modo que D sea exactamente singular, entonces la rutina
!>    retorna con INFO = i. De lo contrario, la forma factorizada de A se utiliza
!>    para estimar el número de condición de la matriz A. Si la
!>    recíproca del número de condición es menor que la precisión de la máquina,
!>    se retorna INFO = N+1 como advertencia, pero la rutina aún procede
!>    a resolver para X y calcular los límites de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    matriz y calcular límites de error y estimaciones de error hacia atrás
!>    para la misma.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A ha sido
!>          suministrada en la entrada o no.
!>          = 'F':  En la entrada, AFP y IPIV contienen la forma factorizada de
!>                  A.  AP, AFP e IPIV no serán modificados.
!>          = 'N':  La matriz A se copiará a AFP y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es array REAL, dimensión (N*(N+1)/2)
!>          El triángulo superior o inferior de la matriz simétrica A, empaquetado
!>          por columnas en un array lineal.  La columna j de A se almacena
!>          en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más detalles abajo.
!>

AFP

!>          AFP es array REAL, dimensión (N*(N+1)/2)
!>          Si FACT = 'F', entonces AFP es un argumento de entrada y en la entrada
!>          contiene la matriz de bloques diagonales D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T tal como la calcula SSPTRF, almacenado como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>
!>          Si FACT = 'N', entonces AFP es un argumento de salida y en la salida
!>          contiene la matriz de bloques diagonales D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T tal como la calcula SSPTRF, almacenado como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, tal como la determina SSPTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' y IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2. Si UPLO = 'L' y IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 y -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, tal como la determina SSPTRF.
!>

B

!>          B es array REAL, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array REAL, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La estimación de la recíproca del número de condición de la matriz
!>          A.  Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular con precisión de trabajo.
!>          Esta condición se indica con un código de retorno de
!>          INFO > 0.
!>

FERR

!>          FERR es array REAL, dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector solución
!>          X(j) (la columna j de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j).  La estimación es tan fiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es array REAL, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga de X(j) una solución exacta).
!>

WORK

!>          WORK es array REAL, dimensión (3*N)
!>

IWORK

!>          IWORK es array INTEGER, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  D(i,i) es exactamente cero.  La factorización
!>                       se ha completado pero el factor D es exactamente
!>                       singular, por lo que la solución y los límites de error

SSPSVX — Singular value decomposition of a real symmetric tridiagonal matrix

Function/Subroutine Documentation

SSPSVX

    Purpose
    =======

    SSPSVX uses the		singular value decomposition (SVD) of a
    real symmetric tridiagonal matrix to solve	 a system of linear
    equations.

Parameters

    --
    --

Return values

    >= 0: Success. The value is the number of successful	 iterations.
    < 0: Failure.
        =-1: The	 matrix	 D is zero,	 so	 RCOND	 could not be
                        computed. RCOND = 0 is returned.
        =-2: The matrix is singular to working precision.
        =-3: The matrix is not positive definite.
        =-4: The input array argument AP is invalid.
        =-5: The input array argument D is invalid.

Author

Univ. of Tennessee Univ. of California Berkeley Univ. of Colorado Denver NAG Ltd.

Further Details

    The packed storage scheme is illustrated by the following example
    when N = 4, UPLO = 'U':

    Two-dimensional storage of the symmetric matrix A:

       a11 a12 a13 a14
           a22 a23 a24
               a33 a34     (aij = aji)
                   a44

    Packed storage of the upper triangle of A:

    AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
