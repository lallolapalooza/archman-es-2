Documentación de función/subrutina

subrutina sspev (character jobz, character uplo, integer n, real, dimension( * ) ap, real, dimension( * ) w, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer info)

SSPEV calcula los valores propios y, opcionalmente, los vectores propios para otras matrices

Propósito:

!>
!> SSPEV calcula todos los valores propios y, opcionalmente, los vectores propios
!> de una matriz real simétrica A en almacenamiento empaquetado.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array REAL, de dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          A, empaquetado por columnas en un array lineal.  La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, AP se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la diagonal
!>          y la primera superdiagonal de la matriz tridiagonal T sobrescriben
!>          los elementos correspondientes de A, y si UPLO = 'L', la
!>          diagonal y la primera subdiagonal de T sobrescriben los
!>          elementos correspondientes de A.
!>

W

!>          W es un array REAL, de dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es un array REAL, de dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los vectores propios
!>          ortonormales de la matriz A, con la i-ésima columna de Z
!>          conteniendo el vector propio asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array REAL, de dimensión (3*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Salida exitosa.
!>          < 0:  Si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          > 0:  Si INFO = i, el algoritmo no convergió; los
!>                elementos fuera de la diagonal de una forma tridiagonal
!>                intermedia no convergieron a cero.
!>
