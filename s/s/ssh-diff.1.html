SSH-DIFF(1) Comandos de usuario SSH-DIFF(1)

NOMBRE

ssh-diff

SINOPSIS

ssh-diff [OPCIONES] ARCHIVO [usuario@]hostname[:ARCHIVO]

DESCRIPCIÓN

diff un archivo a través de SSH

Hay una ronda adicional de comunicación con el sistema remoto
para comprobar la existencia del archivo a comparar.
Por lo tanto, si no estás usando claves SSH
es posible que se te pida la contraseña dos veces.

Usa "CHECK_REMOTE_FILE_EXISTS=NO ssh-diff" para deshabilitar ese comportamiento.

OPCIONES DE DIFF

Todas las opciones que soporta tu comando diff local (excepto '-r').
Consulta 'man diff' y 'diff --help' para más información.

OPCIONES DE SSH

-4
Usar solo IPv4
-6
Usar solo IPv6
-p puerto
Puerto al que conectarse en el host remoto.
Esto se puede especificar por host en el archivo de configuración.

ENTORNO

CHECK_REMOTE_FILE_EXISTS NO|YES comprobación de archivo remoto

EJEMPLOS

# Predeterminado
ssh-diff /etc/hosts 192.168.1.10
ssh-diff /etc/hosts root@192.168.1.10
ssh-diff /etc/hosts root@192.168.1.10:/etc/hosts.old
# Lado a lado
ssh-diff -y /etc/hosts 192.168.1.10
ssh-diff -y /etc/hosts root@192.168.1.10
ssh-diff -y /etc/hosts root@192.168.1.10:/etc/hosts.old
# Unificado
ssh-diff -u /etc/hosts 192.168.1.10
ssh-diff -u /etc/hosts root@192.168.1.10
ssh-diff -u /etc/hosts root@192.168.1.10:/etc/hosts.old
