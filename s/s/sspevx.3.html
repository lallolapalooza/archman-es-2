subrutina sspevx (carácter jobz, carácter range, carácter uplo, entero n, real, dimensión( * ) ap, real vl, real vu, entero il, entero iu, real abstol, entero m, real, dimensión( * ) w, real, dimensión( ldz, * ) z, entero ldz, real, dimensión( * ) work, entero, dimensión( * ) iwork, entero, dimensión( * ) ifail, entero info)

SSPEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para MATRICES APILADAS

Propósito:

!>
!> SSPEVX calcula valores propios y, opcionalmente, vectores propios
!> seleccionados de una matriz simétrica real A en almacenamiento apilado.
!> Los valores/vectores propios pueden ser seleccionados especificando un
!> rango de valores o un rango de índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios;
!>          = 'V': se encontrarán todos los valores propios en el intervalo
!>                 semiabierto (VL,VU];
!>          = 'I': se encontrarán los valores propios desde el índice IL
!>                 hasta IU.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  el triángulo superior de A está almacenado;
!>          = 'L':  el triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es array REAL, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          simétrica A, apilado por columnas en un array lineal. La j-ésima
!>          columna de A se almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, AP se sobrescribe con valores generados durante
!>          la reducción a forma tridiagonal. Si UPLO = 'U', la diagonal
!>          y la primera superdiagonal de la matriz tridiagonal T
!>          sobrescriben los elementos correspondientes de A, y si UPLO = 'L',
!>          la diagonal y la primera subdiagonal de T sobrescriben los
!>          elementos correspondientes de A.
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de anchura menor o igual que
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual que cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir AP a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento
!>          2*SLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*SLAMCH('S').
!>
!>          Ver por Demmel y
!>          Kahan, Nota de Trabajo de LAPACK #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array REAL, dimensión (N)
!>          Si INFO = 0, los valores propios seleccionados en orden ascendente.
!>

Z

!>          Z es array REAL, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se retorna en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos
!>          max(1,M) columnas en el array Z; si RANGE = 'V', el valor exacto
!>          de M no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array REAL, dimensión (8*N)
!>

IWORK

!>          IWORK es array INTEGER, dimensión (5*N)
!>

IFAIL

!>          IFAIL es array INTEGER, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que fallaron en converger.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, entonces i vectores propios fallaron en converger.
!>                Sus índices se almacenan en el array IFAIL.
!>

sspevx(3)

NOMBRE

sspevx - SSPEVX calcula los autovalores y autovectores propios de una matriz simétrica de Hessenberg real particionada.

SINOPSIS

SUBROUTINE SSPEVX(
     CHARACTER*1          FACT,
     CHARACTER*1          JOBZ,
     CHARACTER*1          UPLO,
     INTEGER              N,
     REAL, DIMENSION( N )  AP,
     REAL, DIMENSION( N )  Q,
     INTEGER              LDA,
     REAL, DIMENSION( N )  Z,
     INTEGER              LDZ,
     REAL                 RCOND,
     INTEGER              INFO )

Documentación de Funciones/Subrutinas

Esta sección contendría la documentación detallada de la subrutina sspevx, incluyendo descripciones de los parámetros de entrada y salida, y el propósito de la subrutina.

Parámetros:

  • FACT: Carácter. Indica si se deben calcular o no los autovectores propios.
  • JOBZ: Carácter. Indica si se deben calcular solo los autovalores o ambos, autovalores y autovectores propios.
  • UPLO: Carácter. Indica si la matriz A es triangular superior o inferior.
  • N: Entero. Orden de la matriz A.
  • AP: Real, Dimensión(N). Representa la matriz simétrica de Hessenberg particionada.
  • Q: Real, Dimensión(LDA, N). Matriz ortogonal que contiene los autovectores propios.
  • LDA: Entero. Longitud de la primera dimensión de Q.
  • Z: Real, Dimensión(LDZ, N). Matriz ortogonal que contiene los autovectores propios.
  • LDZ: Entero. Longitud de la primera dimensión de Z.
  • RCOND: Real. Condición recíproca estimada del problema de autovalores.
  • INFO: Entero. Indica el estado de la salida.
