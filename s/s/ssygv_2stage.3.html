Documentación de Función/Subrutina

subrutina ssygv_2stage (integer itype, character jobz, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) w, real, dimension( * ) work, integer lwork, integer info)

SSYGV_2STAGE

Propósito:

!>
!> SSYGV_2STAGE calcula todos los valores propios, y opcionalmente, los vectores propios
!> de un problema de autovalores generalizado simétrico-definido real, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.
!> Aquí, se asume que A y B son simétricas y B también es
!> positiva definida.
!> Esta rutina utiliza la técnica de 2 etapas para la reducción a tridiagonal
!> que ha demostrado un mayor rendimiento en arquitecturas recientes y para
!> tamaños grandes N>2000.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la
!>          parte triangular superior N-por-N principal de A contiene la
!>          parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior N-por-N principal de A contiene
!>          la parte triangular inferior de la matriz A.
!>
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene la
!>          matriz Z de los vectores propios. Los vectores propios están normalizados
!>          como sigue:
!>          si ITYPE = 1 o 2, Z**T*B*Z = I;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces en la salida el triángulo superior (si UPLO='U')
!>          o el triángulo inferior (si UPLO='L') de A, incluyendo la
!>          diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array REAL, de dimensión (LDB, N)
!>          En la entrada, la matriz simétrica positiva definida B.
!>          Si UPLO = 'U', la parte triangular superior N-por-N principal de B
!>          contiene la parte triangular superior de la matriz B.
!>          Si UPLO = 'L', la parte triangular inferior N-por-N principal de B
!>          contiene la parte triangular inferior de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz se
!>          sobrescribe con el factor triangular U o L de la factorización de Cholesky
!>          B = U**T*U o B = L*L**T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

W

!>          W es un array REAL, de dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          en caso contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimension) donde
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + 2*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 2*N
!>                                   donde KD es el tamaño de bloqueo de la reducción,
!>                                   FACTOPTNB es el bloqueo utilizado por el algoritmo QR o LQ
!>                                   generalmente FACTOPTNB=128 es una buena elección
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   la compilación openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Aún no disponible.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje
!>          de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  finalización exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  SPOTRF o SSYEV devolvieron un código de error:
!>             <= N:  si INFO = i, SSYEV no convergió;
!>                    i elementos fuera de la diagonal de una forma tridiagonal intermedia
!>                    no convergieron a cero;
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el menor
!>                    principal líder de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon valores ni vectores propios.
!>

ssygv_2stage(3)

NOMBRE

ssygv_2stage - Resuelve uno de los problemas de valores propios generalizados simétricos y definidos positivamente:

  A*x = lambda*B*x,
o
  A*B*x = lambda*x,

donde A y B son tipos simétricos y B está definido positivamente.

      real    a(lda,n), b(ldb,n), w(n), vl, vu, abstol

Documentación de Función/Subrutina

ssygv_2stage (y sus variantes de doble precisión/complejas) resuelve el problema de valores propios generalizado.

Parámetros

  • itype: Tipo de problema de valores propios generalizado.
    • 1: A*x = lambda*B*x
    • 2: A*B*x = lambda*x
  • jobz: Indica si se calcularán los valores propios y/o los vectores propios.
    • 'N': Solo se calculan los valores propios.
    • 'V': Se calculan los valores propios y los vectores propios.
  • uplo: Indica si la matriz A es triangular superior o inferior.
    • 'U': Triangular superior
    • 'L': Triangular inferior
  • n: Orden de las matrices A y B.
  • a: Matriz simétrica (o triangular superior/inferior).
  • lda: Longitud de la línea de la matriz A.
  • b: Matriz simétrica definida positivamente (o triangular superior/inferior).
  • ldb: Longitud de la línea de la matriz B.
  • w: Vector de salida que contiene los valores propios ordenados en orden ascendente.
  • vl, vu: Rangos para el cálculo de valores propios. Solo se utilizan si se especifica un rango.
  • il, iu: Índices de los valores propios más pequeños y más grandes para el cálculo de rangos.
  • abstol: Tolerancia absoluta para la convergencia de los valores propios.
  • m: El número de valores propios encontrados.
  • work: Vector de trabajo para la subrutina.
  • lwork: Longitud del vector de trabajo.
  • info: Indicador de error. 0 si es exitoso, negativo si hay un error.
