SSPGVX

Propósito:

!>
!> SSPGVX calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de un problema de valores propios generalizado simétrico-definido real, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x. Aquí A
!> y B se asumen simétricos, almacenados en almacenamiento empaquetado, y B
!> también es definido positivo. Los valores propios y vectores propios pueden ser
!> seleccionados especificando un rango de valores o un rango de índices
!> para los valores propios deseados.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios desde el índice IL hasta el IU.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superior de A y B;
!>          = 'L':  Se almacenan los triángulos inferior de A y B.
!>

N

!>          N es INTEGER
!>          El orden del lápiz de matrices (A,B).  N >= 0.
!>

AP

!>          AP es array REAL, dimension (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          A, empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, el contenido de AP se destruye.
!>

BP

!>          BP es array REAL, dimension (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          B, empaquetado por columnas en un array lineal. La j-ésima columna de B
!>          se almacena en el array BP de la siguiente manera:
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) para 1<=i<=j;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) para j<=i<=n.
!>
!>          En la salida, el factor triangular U o L de la factorización de
!>          Cholesky B = U**T*U o B = L*L**T, en el mismo formato de
!>          almacenamiento que B.
!>

VL

!>          VL es REAL
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o igual
!>          que cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*SLAMCH('S'), no en cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*SLAMCH('S').
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array REAL, dimension (N)
!>          En salida normal, los primeros M elementos contienen los valores propios
!>          seleccionados en orden ascendente.
!>

Z

!>          Z es array REAL, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'N', entonces Z no se hace referencia.
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Los vectores propios se normalizan de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**T*B*Z = I;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación del vector propio, y
!>          el índice del vector propio se devuelve en IFAIL.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array REAL, dimension (8*N)
!>

IWORK

!>          IWORK es array INTEGER, dimension (5*N)
!>

IFAIL

!>          IFAIL es array INTEGER, dimension (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero.  Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que fallaron en converger.
!>          Si JOBZ = 'N', entonces IFAIL no se hace referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  SPPTRF o SSPEVX devolvieron un código de error:
!>             <= N:  si INFO = i, SSPEVX falló en converger;
!>                    fallaron en converger i vectores propios. Sus índices
!>                    se almacenan en el array IFAIL.
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el principal m

NAME

sspgvx - Computes the eigenvalues and eigenvectors of a complex general matrix.

SYNOPSIS

`SUBROUTINE sspgvx( ITYPE, JOBZ, RANGE, UPLO, N, AP, BP, VL, VU, IL, IU, ABSTOL, M, NZ, V, LDV, WORK, IWORK, INFO )`

`INTEGER ITYPE`
`CHARACTER RANGE`
`CHARACTER JOBZ`
`CHARACTER UPLO`
`INTEGER N`
`REAL AP( * )`
`REAL BP( * )`
`REAL VL`
`REAL VU`
`INTEGER IL`
`INTEGER IU`
`REAL ABSTOL`
`INTEGER M`
`INTEGER NZ`
`REAL V( LDV, * )`
`INTEGER LDV`
`REAL WORK( * )`
`INTEGER IWORK( * )`
`INTEGER INFO`

Function/Subroutine Documentation

sspgvx computes the eigenvalues and eigenvectors of a complex general matrix.

Parameters:
ITYPE
(input) INTEGER

Specifies the type of generalized eigenvalue problem:

= 1: Solve $A Z = \lambda B Z$ where A and B are symmetric and B is positive definite.

= 2: Solve $A \lambda M^{T} = \lambda B M^{T}$ where A is symmetric and B is symmetric positive definite.

= 3: Solve $A B Z = \lambda Z$ where A is symmetric positive definite and B is symmetric.

JOBZ
(input) CHARACTER*1

Specifies whether to compute the eigenvectors:

= 'N': Only compute the eigenvalues of the symmetric, but possibly indefinite, generalized (A,B)-pair.

= 'V': Compute the eigenvalues and eigenvectors of the symmetric, but possibly indefinite, generalized (A,B)-pair.

Constraint:JOBZ = 'N' or 'V'.

RANGE
(input) CHARACTER*1

Specifies the range of eigenvalues to be computed:

= 'A': All eigenvalues will be computed.

= 'V': All eigenvalues $\lambda$ in the open interval $(\texttt{VL}, \texttt{VU})$ will be computed.

= 'I': The $\texttt{IL}$-th through the $\texttt{IU}$-th eigenvalues will be computed.

UPLO
(input) CHARACTER*1

= 'U': Upper triangle of A and B will be used.

= 'L': Lower triangle of A and B will be used.

Since the matrices A and B are symmetric, the same storage scheme must be used for both.

N
(input) INTEGER

The order of the matrices A and B. N >= 0.

AP
(input) REAL array, dimension (?)

The upper or lower triangle of the symmetric matrix A, according to UPLO.

The dimension of AP is N*(N+1)/2.

BP
(input) REAL array, dimension (?)

The upper or lower triangle of the symmetric matrix B, according to UPLO.

The dimension of BP is N*(N+1)/2.

VL
(input) REAL

If `RANGE` = 'V', the lower bound of the interval for the desired eigenvalues.

VU
(input) REAL

If `RANGE` = 'V', the upper bound of the interval for the desired eigenvalues.

IL
(input) INTEGER

If `RANGE` = 'I', the index of the smallest eigenvalue in the selection set.

1 <= IL <= IU, and the number of eigenvalues is IU-IL+1.

IU
(input) INTEGER

If `RANGE` = 'I', the index of the largest eigenvalue in the selection set.

1 <= IL <= IU <= N.

ABSTOL
(input) REAL

The tolerance for determining which eigenvectors are to be computed. If

RANGE = 'A', then ABSTOL is set to XSTLTS *eps, where eps is the machine precision.

If `RANGE` = 'V' or 'I', then ABSTOL specifies the tolerance

in the same units as the eigenvalues. Eigenvectors with eigenvalues within the range [VL, VU] will be computed.

See “Further Details”.

ABSTOL must be greater than or equal to zero.

M
(output) INTEGER

The total number of eigenvalues found.

If `RANGE` = 'A', M = N.

If `RANGE` = 'V' or 'I', M = number of eigenvalues in the interval.

NZ
(output) INTEGER

The number of eigenvectors computed.

V
(output) REAL array, dimension (LDV, N)

If `JOBZ` = 'V', V contains the eigenvectors of the generalized eigenvalue problem $A Z = \lambda B Z$. The vectors are stored column-wise in the array V. If an eigenvector is associated with a generalized eigenvalue 0, it is not returned.

If `JOBZ` = 'N', the array V is not used.

The column V(i,j) is the eigenvector corresponding to the eigenvalue M(j), and may be scaled so that

|| V(j) ||$_2$ = 1.

LDV
(input) INTEGER

The dimension of the array V. LDV >= max(1, N).

WORK
(workspace) REAL array, dimension (MAX(1,LWORK))
IWORK
(workspace) INTEGER array, dimension (MAX(1,LIWORK))
INFO
(output) INTEGER

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: The algorithm failed to compute all the eigenvalues and eigenvectors. The eigenvalues are in AP and the eigenvectors are in V, and INFO specifies the number of non-converged eigenvalues.

> N: If INFO = N + i, then the Jacobi algorithm did not converge. i is the number of eigenvalues which did not converge.

< 0: If INFO = -i, then the i-th argument had an illegal value.

> 0: The algorithm failed to compute all the eigenvalues and eigenvectors. The eigenvalues are in AP and the eigenvectors are in V, and INFO specifies the number of non-converged eigenvalues.

= N+1: The triangular factorization of a diagonal block of B failed to be positive definite. The eigenvalue of order i of B is not positive.

The factorization of B could not be completed and no eigenvalues or eigenvectors were computed.
