SNAPPERD(8) Gestión de instantáneas del sistema de archivos SNAPPERD(8)

NOMBRE

snapperd - demonio DBus para snapper

SINOPSIS

snapperd

DESCRIPCIÓN

Snapperd es un demonio DBus para snapper y no para uso directo por el usuario.

OPCIONES

--logger-type tipo

Establece el tipo de registrador. Los valores posibles son none, stdout, logfile y syslog.

--debug

Activa la depuración.
