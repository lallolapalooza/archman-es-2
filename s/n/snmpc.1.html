NOMBRE

snmpc - Frontal del compilador SNMP MIB

SINOPSIS

snmpc [opciones] archivo.mib | archivo.bin

DESCRIPCIÓN

El programa snmpc proporciona una forma de ejecutar el compilador SNMP MIB del sistema Erlang.

snmpc compila un archivo MIB SNMP. Consulte compile/1,2 para obtener más información.

También puede utilizarse para generar un archivo de cabecera (.hrl) con definiciones de constantes de Erlang para los objetos en el MIB. Consulte mib_to_hrl/1.

Opciones del compilador

Las siguientes opciones son compatibles (tenga en cuenta que la mayoría de ellas se relacionan con la compilación del archivo MIB):

--help

Imprime información de ayuda.

--version

Imprime la versión de la aplicación y del formato mib.

--verbosity verbosity

Imprime información de depuración.

verbosity = trace | debug | log | info | silence

Por defecto es silence.

--warnings | --W

Imprime mensajes de advertencia.

--wae | --Werror

Advertencias como errores. Indica que las advertencias deben tratarse como errores.

--o directorio

El directorio donde el compilador debe colocar los archivos de salida. Si no se especifica, los archivos de salida se colocarán en el directorio de trabajo actual.

--i Directorio

Especifica la ruta para buscar archivos MIB importados (compilados). Por defecto, el directorio de trabajo actual siempre se incluye.

Esta opción puede aparecer varias veces, especificando cada vez *un* camino.

--il Directorio

Esta opción (include_lib), especifica una lista de directorios para buscar MIB importados. Asume que el primer elemento del nombre del directorio corresponde a una aplicación OTP. El compilador encontrará la versión instalada actual. Por ejemplo, el valor ["snmp/mibs/"] se reemplazará por ["snmp-3.1.1/mibs/"] (o la versión actual que pueda estar en el sistema). El directorio actual y el "snmp-home"/priv/mibs/ siempre se listan al final de la ruta de inclusión.

--sgc

Esta opción (skip group check), si está presente, deshabilita la comprobación de grupo del compilador mib. Es decir, si las macros OBJECT-GROUP y NOTIFICATION-GROUP se comprobarán o no para su corrección.

--dep

Mantener definiciones obsoletas. Si no se especifica, el compilador ignorará las definiciones obsoletas.

--desc

Se incluirá el campo DESCRIPTION.

--ref

Se incluirá el campo REFERENCE.

--imp

Se incluirá el campo IMPORTS.

--mi

Se incluirá el campo MODULE-IDENTITY.

--mc

Se incluirá el campo MODULE-COMPLIANCE.

--ac

Se incluirá el campo AGENT-CAPABILITIES.

--mod module

El módulo que implementa todas las funciones de instrumentación.

El nombre de todas las funciones de instrumentación debe ser el mismo que el del objeto administrado correspondiente que implementan.

--nd

Las funciones de instrumentación predeterminadas *no* se usarán si un objeto administrado no tiene una función de instrumentación. En su lugar, esto se informará como un error y la compilación se abortará.

--rrnac

Esta opción, si está presente, especifica que la comprobación de asignación de nombres de fila no se realizará estrictamente de acuerdo con SMI (que solo permite el valor 1).

Con esta opción, se permiten todos los valores mayores que cero (>= 1). Esto significa que el error se convertirá en una advertencia.

Por defecto no está incluido, pero si esta opción está presente, lo estará.
