SNDFILE-INFO(1) Manual de Comandos Generales SNDFILE-INFO(1)

NOMBRE

sndfile-info — muestra información sobre archivos de sonido

SINOPSIS

sndfile-info [--broadcast] [--cart] [--channel-map] [--instrument] archivo ...

DESCRIPCIÓN

sndfile-info muestra información básica sobre archivos de sonido como formato, número de canales, frecuencia de muestreo y duración. Se reconocen las siguientes opciones:

--broadcast
Muestra información de broadcast (BWF).
--cart
Muestra el chunk 'cart' de un archivo WAV (o similar).
--channel-map
Muestra el mapa de canales.
--instrument
Muestra información del instrumento: nota base, ganancia, velocidad, clave y puntos de loop.

VER TAMBIÉN

http://libsndfile.github.io/libsndfile/
