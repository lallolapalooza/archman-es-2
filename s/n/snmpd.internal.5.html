NOMBRE

snmpd.internal - configuración interna del agente Net-SNMP

DESCRIPCIÓN

La página del manual de snmpd.conf(5) define la sintaxis y el comportamiento de las directivas de configuración principales que se pueden utilizar para controlar el funcionamiento del agente Net-SNMP y la información de gestión que proporciona.

Sin embargo, existen varias directivas de configuración adicionales (muchas de las cuales, aunque no todas, comienzan con un guion bajo) que son reconocidas por el agente. Estas se utilizan típicamente para retener la configuración entre reinicios del agente y no están destinadas al acceso directo del usuario. Esta página del manual enumera estas directivas, indicando brevemente dónde se utilizan. Para obtener detalles completos, consulte los archivos fuente relevantes. Si no puede seguir esa fuente, ¡probablemente no debería estar modificando estas directivas!

COMPORTAMIENTO DEL AGENTE

quit

CONTROL DE ACCESO

Configuración VACM

vacmView / vacmGroup / vacmAccess
Estas directivas se utilizan para retener la configuración de control de acceso configurada dinámicamente.

INFORMACIÓN DEL SISTEMA

Grupo System

setSerialNo
Esta directiva se utiliza para implementar el objeto de bloqueo de asesoramiento snmpSetSerialNo.
psyslocation / psyscontact / psysname
Estas directivas se utilizan para retener la configuración del sistema configurada dinámicamente. Serán anuladas por las directivas correspondientes sysLocation, sysContact y sysName.

MONITOREO ACTIVO

Manejo de Notificaciones

pauthtrapenable
Esta directiva se utiliza para retener la configuración dinámica de si el agente debe generar trampas de authenticationFailure. Será anulada por la directiva correspondiente authtrapenable.
snmpNotify*Table
targetAddr / targetParams
Estas directivas se utilizan para retener la configuración dinámica de los destinos de notificación.

MIB de Eventos DisMan

_mteE*Table, _mteOTable, _mteT*Table
Estas directivas se utilizan para retener la configuración dinámica de eventos, objetos y disparadores de monitorización.
mteObjectsTable / mteTriggerTable
Estas directivas son para compatibilidad con la implementación anterior de disman/event-mib.

MIB de Programación DisMan

_schedTable
Esta directiva se utiliza para retener eventos programados configurados dinámicamente.

EXTENSIÓN DE FUNCIONALIDAD DEL AGENTE

Comandos de Extensión Arbitraria

extend-sh
exec2 / sh2 / execFix2
Estas directivas se definieron por analogía con las directivas equivalentes en la implementación anterior de ucd-snmp/extensible. Están obsoletas y no deben utilizarse.

ARCHIVOS

/etc/snmp/snmpd.conf
