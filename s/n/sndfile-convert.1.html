SNDFILE-CONVERT(1) Manual de comandos generales SNDFILE-CONVERT(1)

NOMBRE

sndfile-convert — convierte archivos de sonido de un formato a otro

SINOPSIS

sndfile-convert [-override-sample-rate=tasa] [-endian=little | big | cpu] [-normalize] [codificación] entrada salida

DESCRIPCIÓN

sndfile-convert convierte archivos de sonido de un formato de audio a otro. El archivo de salida se sobrescribe si ya existe.

Formatos

El formato del archivo de salida se determina por la extensión del nombre de archivo. Los siguientes formatos de archivo se reconocen actualmente:

wav
WAV (Microsoft)
aif
AIFF (Apple/SGI)
au
AU (Sun/NeXT)
snd
AU (Sun/NeXT)
raw
RAW (sin encabezado)
gsm
RAW (sin encabezado)
vox
RAW (sin encabezado)
paf
PAF (Ensoniq PARIS, big-endian)
fap
PAF (Ensoniq PARIS, little-endian)
svx
IFF (Amiga IFF/SVX8/SV16)
nist
SPHERE (NIST SPeech HEader Resources)
sph
SPHERE (NIST SPeech HEader Resources)
voc
VOC (Creative Labs)
ircam
SF (Berkeley/IRCAM/CARL)
sf
SF (Berkeley/IRCAM/CARL)
w64
W64 (SoundFoundry WAVE 64)
mat
MAT4 (GNU Octave 2.0 / Matlab 4.2)
mat4
MAT4 (GNU Octave 2.0 / Matlab 4.2)
mat5
MAT5 (GNU Octave 2.1 / Matlab 5.0)
pvf
PVF (Portable Voice Format)
xi
XI (FastTracker 2)
htk
HTK (HMM Tool Kit)
sds
SDS (Midi Sample Dump Standard)
avr
AVR (Audio Visual Research)
wavex
WAVEX (MS WAVE con WAVEFORMATEX)
sd2
SD2 (Sound Designer II)
flac
FLAC (FLAC Lossless Audio Codec)
caf
CAF (Apple Core Audio File)
wve
WVE (Psion Series 3)
prc
WVE (Psion Series 3)
ogg
OGG (OGG Container format)
oga
OGG (OGG Container format)
mpc
MPC (Akai MPC 2k)
rf64
RF64 (RIFF 64)

Opciones

Se reconocen las siguientes opciones:

-override-sample-rate=tasa
Hace que la entrada use la frecuencia de muestreo de tasa Hz.
-endian=little
Hace que el archivo de salida use datos little endian.
-endian=big
Hace que el archivo de salida use datos big endian.
-endian=cpu
Hace que el archivo de salida use la endianeidad de la CPU.
-normalize
Normaliza los datos de audio en el archivo de salida.

Codificaciones

El parámetro opcional codificación permite establecer la codificación de datos para el archivo de salida. Las siguientes codificaciones son compatibles actualmente:

-pcms8
pcm de 8 bits con signo
-pcmu8
pcm de 8 bits sin signo
-pcm16
pcm de 16 bits
-pcm24
pcm de 24 bits
-pcm32
pcm de 32 bits
-float32
punto flotante de 32 bits
-ulaw
ULAW
-alaw
ALAW
-ima-adpcm
IMA ADPCM (solo WAV)
-ms-adpcm
MS ADPCM (solo WAV)
-gsm610
GSM6.10 (solo WAV)
-dwvw12
DWVW de 12 bits (solo AIFF)
-dwvw16
DWVW de 16 bits (solo AIFF)
-dwvw24
DWVW de 24 bits (solo AIFF)
-vorbis
Vorbis (solo OGG)

Si no se especifica ninguna codificación para el archivo de salida, sndfile-convert intentará utilizar la codificación del archivo de entrada. Esto no siempre funcionará ya que la mayoría de los formatos de contenedor (por ejemplo, WAV, AIFF, etc.) solo admiten un pequeño subconjunto de codificaciones (por ejemplo, PCM de 16 bits, a-law, Vorbis, etc.).

ESTADO DE SALIDA

La utilidad sndfile-convert sale con 0 en caso de éxito, y >0 si ocurre un error.
