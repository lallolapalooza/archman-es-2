NOMBRE

sndio — descriptores de dispositivos de audio y MIDI

DESCRIPCIÓN

Los programas acceden al hardware de audio y MIDI utilizando la biblioteca sndio. Permite el acceso tanto a través del servidor sndiod(8) como el acceso directo al hardware. El dispositivo de audio o el puerto MIDI, así como el método de acceso, se designan mediante el descriptor sndio. Lo proporciona el usuario con el método de selección de dispositivo del programa, o con las variables de entorno AUDIODEVICE y MIDIDEVICE si no hay método de selección de dispositivo.

Por lo general, los programas acceden al hardware a través del servidor sndiod(8), ya que el acceso directo al hardware es exclusivo y requiere privilegios adicionales. El servidor sndiod(8) admite múltiples conexiones a la vez, lo que permite que varios programas utilicen el hardware de forma concurrente. Realiza el procesamiento de audio necesario sobre la marcha para superar cualquier incompatibilidad entre el software y el hardware. Las conexiones a sndiod(8) también pueden establecerse a través de la red, incluso desde máquinas virtuales.

El servidor sndiod(8) expone puertos MIDI thru, lo que permite que un programa envíe datos MIDI a otros programas, por ejemplo, para permitir que un secuenciador envíe eventos a un sintetizador.

Además, sndiod(8) expone un puerto MIDI utilizado para controlar programas de audio utilizando mensajes estándar MIDI Machine Control (MMC), MIDI Time Code (MTC) y volumen maestro.

Descriptores de dispositivos del servidor

Desde la perspectiva del usuario, cada dispositivo de audio o puerto MIDI expuesto por sndiod(8) tiene un descriptor de la forma:

tipo[@nombre_host][,num_servidor]/[num_disp_o_opción]

La información se utiliza en los programas para determinar cómo acceder al dispositivo de audio o al puerto MIDI.

tipo
El tipo de dispositivo de audio o puerto MIDI. Los valores posibles son:
snd
Dispositivo de audio expuesto por sndiod(8).
midithru
Puerto MIDI thru creado con sndiod(8).
midi
Puerto MIDI expuesto por sndiod(8).
nombre_host
El nombre de host o dirección donde se está ejecutando el servidor sndiod(8) remoto al que conectarse.
num_servidor
El número del servidor sndiod(8) al que conectarse, correspondiente al entero especificado con la opción -U de sndiod(8). Útil solo si se ejecutan múltiples servidores sndiod(8) en el mismo sistema.
num_disp
Número de dispositivo. Corresponde al número de la opción -f o -q correspondiente en la línea de comandos de sndiod(8).
opción
Corresponde a la cadena de subdispositivo registrada utilizando la opción -s de sndiod(8).

Descriptores de dispositivos directos

Cada dispositivo de audio o puerto MIDI directo tiene un descriptor de la forma:

tipo/num_disp

El tipo puede ser rsnd o rmidi. El descriptor de dispositivo rsnd/0 accede al dispositivo /dev/audio0, rsnd/1 accede a /dev/audio1, y así sucesivamente. De manera similar, rmidi/0 accede a /dev/rmidi0 y así sucesivamente.

Dispositivos de audio y MIDI predeterminados

Cuando no se proporciona ningún descriptor de dispositivo de audio a un programa o cuando se utiliza la palabra reservada default como dispositivo de audio, el programa utilizará el especificado en las variables de entorno AUDIODEVICE, AUDIOPLAYDEVICE y/o AUDIORECDEVICE. Si no están establecidas, el programa primero intenta conectarse a snd/default. Si falla, intenta usar rsnd/0.

De manera similar, si no se proporciona ningún descriptor MIDI a un programa o cuando se pasa la palabra reservada default como descriptor de dispositivo, el programa utiliza el especificado en la variable de entorno MIDIDEVICE. Si no está establecida, el programa primero intenta conectarse a midithru/0. Si falla, intenta usar rmidi/0. Siempre que sndiod(8) esté en ejecución, esto permite que los programas intercambien datos MIDI en máquinas sin hardware MIDI por defecto, por ejemplo, un reproductor MIDI podría usar un sintetizador de software sin configuración manual requerida.

Autenticación

Por razones de privacidad, solo un usuario puede tener conexiones a sndiod(8) en un momento dado. Los usuarios se identifican mediante su cookie de sesión, que se genera automáticamente al conectarse por primera vez al servidor desde programas de audio o MIDI. La cookie se almacena en $HOME/.sndio/cookie y contiene 128 bits de datos aleatorios brutos.

Si una sesión necesita ser compartida entre varios usuarios, pueden conectarse al servidor utilizando la misma cookie.

AMBIENTE

AUDIODEVICE
Descriptor del dispositivo de audio a usar cuando no se especifica explícitamente un descriptor a un programa.
AUDIOPLAYDEVICE
Descriptor del dispositivo de audio a usar para modo de solo reproducción cuando no se especifica explícitamente un descriptor a un programa. Anula AUDIODEVICE.
AUDIORECDEVICE
Descriptor del dispositivo de audio a usar para modo de solo grabación cuando no se especifica explícitamente un descriptor a un programa. Anula AUDIODEVICE.
MIDIDEVICE
Descriptor del puerto MIDI a usar cuando no se especifica explícitamente un descriptor a un programa.

Estas variables de entorno son ignoradas por sndio si el programa tiene establecidos los bits de set-user-ID o set-group-ID.

ARCHIVOS

~/.sndio/cookie
Cookie de autenticación de sesión del usuario.
/dev/audioN
Dispositivos de audio directos.
/dev/rmidiN
Puertos MIDI directos.

EJEMPLOS

snd/0
Dispositivo de audio al que se refiere la primera opción -f de sndiod(8).
snd/rear
Subdispositivo registrado con “-s rear”.

NAME

sndio

simple audio and MIDI library API

DESCRIPTION

The sndio library provides a simple API for implementing audio and MIDI applications. It abstracts the underlying audio hardware and allows applications to interact with it in a consistent way. The library supports various audio devices, including direct hardware access, network audio servers, and simulated devices.

ENVIRONMENT

LSND_PATH
Specifies the path to the sndiod configuration file. If not set, ~/.sndiod.conf is used.
SNDIO_DEBUG
Enables debugging output. The value can be a bitmask of debug flags.

FILES

~/.sndiod.conf Default configuration file for sndiod.

EXAMPLES

The following examples demonstrate common usage of the sndio library:

aout/0
First audio output device.
ain/0
First audio input device.
outhd/0
First audio output hardware device.
inhd/0
First audio input hardware device.
midi/0
First MIDI input/output device.
ithru/0
First MIDI thru port created with sndiod(8).
default
Default audio or MIDI device.
rsnd/0
Direct hardware access to /dev/audio0.
rmidi/5
Direct hardware access to /dev/rmidi5.
