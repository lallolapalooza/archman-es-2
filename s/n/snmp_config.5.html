NOMBRE

snmp_config - manejo de archivos de configuración de Net-SNMP

DESCRIPCIÓN

El paquete Net-SNMP utiliza varios archivos de configuración para configurar sus aplicaciones. Esta página del manual describe la naturaleza general de los mismos, para que las otras páginas del manual no tengan que hacerlo.

DIRECTORIOS BUSCADOS

En primer lugar, hay numerosos lugares donde se pueden encontrar y leer los archivos de configuración. Por defecto, las aplicaciones buscan archivos de configuración en los siguientes 4 directorios, en orden: /etc/snmp, /usr/share/snmp, /usr/lib/snmp y $HOME/.snmp. En cada uno de estos directorios, busca los archivos snmp.conf, snmpd.conf y/o snmptrapd.conf, así como snmp.local.conf, snmpd.local.conf y/o snmptrapd.local.conf. Los *.local.conf se leen siempre al final. De esta manera, hay 8 lugares por defecto donde puede existir un archivo de configuración para cualquier tipo de archivo de configuración dado.

Además, la ruta de búsqueda por defecto mencionada anteriormente puede ser anulada estableciendo la variable de entorno SNMPCONFPATH a una lista de directorios separados por dos puntos para buscar. La ruta para los datos persistentes debe incluirse al ejecutar aplicaciones que utilizan almacenamiento persistente, como snmpd.

Las aplicaciones leerán los archivos de configuración persistentes en el siguiente orden de preferencia:

archivo en la variable de entorno SNMP_PERSISTENT_FILE
directorios en la variable de entorno SNMPCONFPATH
directorio definido por la variable snmp.conf persistentDir
directorio en la variable de entorno SNMP_PERSISTENT_DIR
directorio por defecto /var/net-snmp

Finalmente, las aplicaciones escribirán archivos de configuración persistentes en el siguiente orden de preferencia:

archivo en la variable de entorno SNMP_PERSISTENT_FILE
directorio definido por la variable snmp.conf persistentDir
directorio en la variable de entorno SNMP_PERSISTENT_DIR
directorio por defecto /var/net-snmp

Nota: Al usar SNMP_PERSISTENT_FILE, el nombre del archivo debe coincidir con el nombre de la aplicación. Por ejemplo, /var/net-snmp/snmpd.conf.

TIPOS DE ARCHIVOS DE CONFIGURACIÓN

Cada aplicación puede utilizar varios archivos de configuración, que configurarán diferentes aspectos de la aplicación. Por ejemplo, el agente SNMP (snmpd) sabe cómo entender las directivas de configuración en los archivos snmpd.conf y snmp.conf. De hecho, la mayoría de las aplicaciones saben cómo leer el contenido de los archivos snmp.conf. Tenga en cuenta, sin embargo, que las directivas de configuración entendidas en un archivo pueden no ser entendidas en otro archivo. Para más información, lea la página del manual asociada con cada tipo de archivo de configuración. Además, la mayoría de las aplicaciones soportan un interruptor -H en la línea de comandos que listará los archivos de configuración que buscará y las directivas que entiende en cada uno de ellos.

El archivo de configuración snmp.conf está destinado a ser un archivo de configuración para toda la suite de aplicaciones que soporta directivas útiles para controlar la naturaleza fundamental de todas las aplicaciones SNMP, como la forma en que manipulan y analizan los archivos MIB textuales de SNMP.

CAMBIAR LOS TIPOS DE CONFIGURACIÓN EN MEDIO DEL ARCHIVO

Es posible cambiar en medio del archivo el tipo de configuración que el analizador debe leer. Dado que esa frase no tiene mucho sentido, demosle un ejemplo: supongamos que quiere activar la salida de volcado de paquetes para el agente por defecto, pero no quiere hacer eso para el resto de las aplicaciones (es decir, snmpget, snmpwalk, ...). Normalmente, para activar el volcado de paquetes en el archivo de configuración necesitaría poner una línea como:

dumpPacket true

en el archivo snmp.conf. Pero esto lo activaría para todas las aplicaciones. Así que, en su lugar, puede poner la misma línea en el archivo snmpd.conf para que solo se aplique al demonio snmpd. Sin embargo, debe indicarle al analizador que espere esta línea. Lo hace colocando un token de especificación de tipo especial dentro de un conjunto de []. En otras palabras, dentro de su archivo snmpd.conf podría poner la directiva snmp.conf anterior añadiendo una línea como esta:

[snmp] dumpPacket true

Esto le dice al analizador que analice la línea anterior como si estuviera dentro de un archivo snmp.conf en lugar de un archivo snmpd.conf. Si quiere analizar un conjunto de líneas en lugar de solo una, puede hacer que el cambio de contexto se aplique al resto del archivo o hasta el próximo directiva de cambio de contexto colocando el token especial en una línea por sí solo:

# hacer que este archivo maneje tokens de snmp.conf:
[snmp]
dumpPacket true
logTimestamp true
# volver a nuestros tokens originales de snmpd.conf:
[snmpd]
rocommunity mypublic

El mismo enfoque se puede utilizar para establecer directivas de configuración para una aplicación cliente particular (o grupo de aplicaciones). Por ejemplo, cualquier programa que utilice la llamada 'snmp_parse_args()' para manejar argumentos de línea de comandos (incluidas las herramientas de línea de comandos estándar distribuidas con las distribuciones de Net-SNMP) leerá automáticamente el archivo de configuración 'snmpapp.conf'. Para establecer configuraciones a nivel de biblioteca para estas aplicaciones (pero no para otras herramientas más específicas), utilice configuraciones como la siguiente:

[snmp] defCommunity myCommunity

para una directiva única, o

# hacer que este archivo maneje tokens de snmp.conf:
[snmp]
defCommunity myCommunity
defVersion   2c
# volver a nuestros tokens originales de snmpapp.conf:
[snmpapp]

para configuraciones múltiples. De manera similar para cualquier otro token de aplicación (pasado a init_snmp()).

COMENTARIOS

Las líneas que comienzan con el carácter '#' en los archivos de configuración se tratan como un comentario y no se analizan.

INCLUIR OTROS ARCHIVOS DE CONFIGURACIÓN

Es posible incluir otros archivos de configuración para su procesamiento durante el procesamiento normal de los archivos de configuración:

# incluir configuración específica del sitio
includeFile site.conf
Esto cargará el archivo de configuración especificado. La ruta
al archivo debe ser absoluta, comenzando con '/',
o relativa. La ruta relativa es entonces relativa al directorio
donde reside el archivo padre con la directiva 'includeFile'.
El nombre del archivo incluido no necesita tener el sufijo '.conf'.
# incluir todos los archivos *.conf en un directorio
includeDir /etc/snmp/config.d
Esto buscará en el directorio especificado todos los archivos con
sufijo '.conf' y los procesará como si hubieran sido incluidos
usando la directiva includeFile. Los archivos de configuración
no se procesan en ningún orden particular.
El directorio especificado debe ser una ruta de directorio absoluta.

INTERFAZ API

La información sobre cómo escribir código C que utilice este sistema, ya sea en los módulos MIB del agente o en aplicaciones, se puede encontrar en la página del manual netsnmp_config_api(3).
