NOMBRE

SNIProxy - proxy TLS y HTTP transparente basado en sesiones

SINOPSIS

sniproxy [ -c config ] [ -f ] [ -n límite-de-descriptores-de-archivo ] [ -V ]

DESCRIPCIÓN

Proxifica conexiones HTTP y TLS entrantes basándose en el nombre de host contenido en la solicitud inicial de la sesión TCP. Esto permite el hosting virtual basado en nombres HTTPS para separar servidores backend sin instalar la clave privada en la máquina proxy.

OPCIONES

-c config
Especifica el archivo de configuración a usar. El valor predeterminado es /etc/sniproxy.conf.
-f
No demonizar y ejecutar en primer plano.
-n límite-de-descriptores-de-archivo
Especifica el límite máximo de recursos para descriptores de archivo. SNIProxy intentará establecer el límite máximo de descriptores de archivo al valor especificado.
-V
Imprime la versión de SNIProxy y sale.
