SNDFILE-PLAY(1) Manual de Comandos Generales SNDFILE-PLAY(1)

NOMBRE

sndfile-play — reproduce un archivo de sonido

SINOPSIS

sndfile-play archivo ...

DESCRIPCIÓN

sndfile-play reproduce uno o varios archivos de sonido en varios sistemas operativos utilizando APIs de salida de audio estándar. La siguiente tabla resume qué API de audio se utiliza en cada caso:

Linux
ALSA u OSS
OpenBSD
sndio
FreeBSD
/dev/dsp (OSS)
NetBSD
/dev/audio
Solaris
/dev/audio
MacOSX 10.6
CoreAudio
MacOSX 10.7
AudioToolbox
Win32
waveOut

VER TAMBIÉN

http://libsndfile.github.io/libsndfile/
