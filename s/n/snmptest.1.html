snmptest(1)

Paquete: net-snmp

Licencias: BSD

SNMPTEST(1) Net-SNMP SNMPTEST(1)

NOMBRE

snmptest - se comunica con una entidad de red utilizando solicitudes SNMP

SINOPSIS

snmptest [OPCIONES COMUNES] AGENTE

DESCRIPCIÓN

snmptest es una aplicación SNMP flexible que puede monitorizar y gestionar información en una entidad de red.

Después de invocar el programa, un intérprete de línea de comandos procede a aceptar comandos. Este intérprete permite al usuario enviar diferentes tipos de solicitudes SNMP a los agentes de destino.

AGENTE identifica un agente SNMP de destino, que está instrumentado para monitorizar los objetos dados. En su forma más simple, la especificación del AGENTE consistirá en un nombre de host o una dirección IPv4. En esta situación, el comando intentará la comunicación con el agente, utilizando UDP/IPv4 al puerto 161 del host de destino dado. Consulte snmpcmd(1) para obtener una lista completa de los formatos posibles para AGENTE.

Una vez invocado snmptest, el intérprete de línea de comandos mostrará el siguiente indicador:

Variable:

En este punto, puede introducir uno o más nombres de variables, uno por línea. Una línea en blanco finaliza la entrada de parámetros y enviará la solicitud (variables introducidas) en un solo paquete, a la entidad remota. Cada nombre de variable se proporciona en el formato especificado en variables(5). Por ejemplo:

snmptest -c public -v 1 zeus
Variable: system.sysDescr.0
Variable:

devolverá información sobre los paquetes de solicitud y respuesta, así como la información:

requestid 0x5992478A errstat 0x0 errindex 0x0
system.sysDescr.0 = STRING: "Unix 4.3BSD"

El valor errstatus muestra el código de estado de error para la llamada. Los valores posibles para errstat se encuentran en el archivo de cabecera snmp.h. El valor errindex identifica la variable que tiene el error dado. Los valores de índice se asignan a todas las variables introducidas en el indicador "Variable". Al primer valor se le asigna un índice de 1.

Al inicio, el programa por defecto envía un paquete de solicitud GET. El tipo de solicitud se puede cambiar escribiendo uno de los siguientes comandos en el indicador "Variable:":

$G - enviar una solicitud GET
$N - enviar una solicitud GETNEXT
$S - enviar una solicitud SET
$B - enviar una solicitud GETBULK
     Nota: GETBULK no está disponible en SNMPv1
$I - enviar una solicitud Inform
$T - enviar una solicitud de Trap SNMPv2

Otros valores que se pueden introducir en el indicador "Variable:" son:

$D - alternar la volcadura de cada paquete enviado y recibido
$QP - alternar una forma de salida más rápida y menos detallada
$Q - Salir del programa

Tipos de Solicitud:

Solicitud GET:

Cuando está en el modo "Solicitud GET" ($G o por defecto), el usuario puede introducir un OID en el indicador "Variable:". El usuario puede introducir varios OID, uno por indicador. El usuario introduce una línea en blanco para enviar la solicitud GET.

Solicitud GETNEXT:

El modo "Solicitud GETNEXT" ($N) es similar al modo "Solicitud Get", descrito anteriormente.

Solicitud SET:

Cuando está en el modo "Solicitud SET" ($S), se solicita más información en el indicador para cada variable. El indicador:

Tipo [i|s|x|d|n|o|t|a]:
solicita que se introduzca el tipo de la variable. Dependiendo del tipo de valor que desee establecer, puede escribir uno de los siguientes:

i - entero
u - entero sin signo
s - cadena de octetos en ASCII
x - cadena de octetos en bytes hexadecimales, separados por espacios
d - cadena de octetos como bytes decimales, separados por espacios
a - dirección IP en notación IP de puntos
o - identificador de objeto
n - nulo
t - timeticks
En este punto se solicitará un valor:

Valor:

Si es un valor entero, simplemente escriba el entero (en decimal). Si es una cadena decimal, escriba números decimales separados por espacios, uno por byte de la cadena. De nuevo, escriba una línea en blanco en el indicador para el nombre de la variable para enviar el paquete.

Solicitud GETBULK:

El modo "Solicitud GETBULK" ($B) es similar al modo "Solicitud Set". Sin embargo, GETBULK no está disponible en SNMPv1.

Solicitud Inform:

El modo "Solicitud Inform" ($I) es similar al modo "Solicitud Set". Sin embargo, este tipo de solicitud no está disponible en SNMPv1. Además, el _agente_ especificado en el comando snmptest debe corresponder al agente snmptrapd de destino.

Solicitud de Trap SNMPv2:

El modo "Solicitud de Trap SNMPv2" ($T) es similar al modo "Solicitud Set". Sin embargo, este tipo de solicitud no está disponible en SNMPv1. Además, el _agente_ especificado en el comando snmptest debe corresponder al agente snmptrapd de destino.

OPCIONES

snmptest toma las opciones comunes descritas en la página del manual de snmpcmd(1).

EJEMPLOS

El siguiente es un ejemplo de envío de una solicitud GET para dos OID:

% snmptest -v 2c -c public testhost:9999

Variable: system.sysDescr.0
Variable: system.sysContact.0
Variable:

requestid 0x7D9FCD63 errstat 0x0 errindex 0x0
SNMPv2-MIB::sysDescr.0 = STRING: SunOS testhost 5.9 Generic_112233-02 sun4u
SNMPv2-MIB::sysContact.0 = STRING: x1111

El siguiente es un ejemplo de envío de una solicitud GETNEXT:

Variable: SNMPv2-MIB::sysORUpTime
Variable:
Received Get Response from 128.2.56.220
requestid 0x7D9FCD64 errstat 0x0 errindex 0x0
SNMPv2-MIB::sysORUpTime.1 = Timeticks: (6) 0:00:00.06
Variable:

El siguiente es un ejemplo de envío de una solicitud SET:

SNMPv2-MIB::sysLocation.0 = STRING: building A
Variable:
