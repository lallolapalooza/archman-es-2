Paquete: net-snmp

SNMPSTATUS(1) Net-SNMP SNMPSTATUS(1)

NOMBRE

snmpstatus - recupera un conjunto fijo de información de gestión de una entidad de red

SINOPSIS

snmpstatus [OPCIONES COMUNES] [-Cf] AGENTE

DESCRIPCIÓN

snmpstatus es una aplicación SNMP que recupera varias estadísticas importantes de una entidad de red.

AGENTE identifica un agente SNMP de destino, que está instrumentado para monitorizar los objetos dados. En su forma más simple, la especificación de AGENTE consistirá en un nombre de host o una dirección IPv4. En esta situación, el comando intentará comunicarse con el agente, utilizando UDP/IPv4 al puerto 161 del host de destino dado.

Consulte la página del manual de snmpcmd(1) para obtener una lista completa de los posibles formatos para AGENTE.

La información devuelta es:

La dirección IP de la entidad.
Una descripción textual de la entidad (sysDescr.0)
El tiempo de actividad del agente SNMP de la entidad (sysUpTime.0)
La suma de paquetes recibidos en todas las interfaces (ifInUCastPkts.* + ifInNUCastPkts.*)
La suma de paquetes transmitidos en todas las interfaces (ifOutUCastPkts.* + ifOutNUCastPkts.*)
El número de paquetes de entrada IP (ipInReceives.0)
El número de paquetes de salida IP (ipOutRequests.0)

Por ejemplo:

snmpstatus -c public -v 1 netdev-kbox.cc.cmu.edu

producirá una salida similar a la siguiente:

[128.2.56.220]=>[Kinetics FastPath2] Arriba: 1 día, 4:43:31
Interfaces: 1, Paquetes recibidos/transmitidos: 262874/39867 | IP: 31603/15805

snmpstatus también comprueba el estado operativo de todas las interfaces (ifOperStatus.*), y si encuentra alguna que no esté en ejecución, informará de una manera similar a esta:

¡2 interfaces están caídas!

Si la entidad de red tiene un error al procesar el paquete de solicitud, se devolverá un paquete de error y se mostrará un mensaje, lo que ayudará a determinar de qué manera la solicitud estaba mal formada. snmpstatus intentará reformar su solicitud para eliminar la variable mal formada (a menos que se proporcione la opción -Cf, véase abajo), pero esta variable faltará entonces en los datos mostrados.

OPCIONES

OPCIONES COMUNES
Consulte snmpcmd(1) para obtener una lista de los valores posibles para OPCIONES COMUNES, así como sus descripciones.
-Cf
Por defecto, snmpstatus intentará corregir los errores devueltos por el agente y reintentará una solicitud. En esta situación, el comando mostrará los datos que pueda. Si se especifica la opción -Cf, entonces snmpstatus no intentará corregir los errores, y el error hará que el comando termine.

VEASE TAMBIÉN

snmpcmd(1), snmpget(1)
