Paquete: net-snmp

Licencias: BSD

NETSNMP_SESS_API(3) Net-SNMP NETSNMP_SESS_API(3)

NAME

snmp_sess_init, snmp_sess_open, snmp_sess_session, snmp_sess_send, snmp_sess_async_send, snmp_sess_select_info, snmp_sess_read, snmp_sess_timeout, snmp_sess_synch_response, snmp_sess_close, snmp_sess_error - functions de sesión

SYNOPSIS

#include <net-snmp/session_api.h>

void snmp_sess_init(struct snmp_session *session);

void *snmp_sess_open(struct snmp_session *session);

struct snmp_session *snmp_sess_session(void *handle);

int snmp_sess_send(void *handle, struct snmp_pdu *pdu);

int snmp_sess_async_send(void *handle,
struct snmp_pdu *pdu,
snmp_callback callback,
void *callbackData);

int snmp_sess_select_info(void *handle,
int *numfds, fd_set *fdset,
struct timeval *timeout,
int *block);

int snmp_sess_read(void *handle, fd_set *fdset);

void snmp_sess_timeout(void *handle);

int snmp_sess_synch_response ( void *handle,

netsnmp_pdu *pdu,
netsnmp_pdu **response);

int snmp_sess_close(void *handle);

void snmp_sess_error(void *handle, int *pcliberr,
int *psnmperr, char **pperrstring);

DESCRIPTION

Estas funciones definen un subconjunto de la API que se puede utilizar para gestionar sesiones SNMP individuales en una aplicación multihilo. Excepto por snmp_sess_session(), estas funciones son versiones de sesión única de la API tradicional de la biblioteca SNMP.

Tenga en cuenta que estas funciones utilizan un puntero opaco (handle en los prototipos anteriores) para identificar una sesión individual en lugar de un puntero session (como en la API tradicional).

snmp_sess_init() prepara una estructura snmp_session que fuente las características de transporte y la información común que se utilizará para un conjunto de transacciones SNMP. Después de que esta estructura se pasa a snmp_sess_open() para crear una sesión SNMP, la estructura ya no se utiliza. En su lugar, el puntero opaco devuelto por snmp_sess_open() se utiliza para referirse a esa sesión en adelante.

Las sesiones SNMP que se crean con snmp_sess_open() no se ven afectadas por, y NO DEBEN UTILIZARSE CON, snmp_select_info(), snmp_read(), snmp_timeout() ni snmp_close(). En su lugar, se deben utilizar las funciones equivalentes de sesión única descritas aquí.

snmp_sess_init() y snmp_sess_open() toman cada una como entrada un puntero a un objeto de estructura snmp_session. Esta estructura contiene información para un conjunto de transacciones que compartirán características de transporte similares. snmp_sess_session() toma el identificador de sesión opaco y devuelve un puntero a su estructura snmp_session asociada.

snmp_sess_send() y snmp_sess_async_send() toman cada una un parámetro pdu, que apunta a un objeto de estructura snmp_pdu que contiene información que describe una transacción que se realizará a través de una sesión abierta.

Consulte snmp_api.h para ver las definiciones de estas estructuras.

Con la llamada snmp_sess_async_send(), snmp_sess_read invocará la función de devolución de llamada especificada cuando se reciba la respuesta.

snmp_sess_select_info(), snmp_sess_read() y snmp_sess_timeout() proporcionan una interfaz para el uso de la llamada al sistema select(2) para que las transacciones SNMP de una sesión individual puedan ocurrir de forma asíncrona.

A snmp_sess_select_info() se le pasa la información que se habría pasado a select(2) en ausencia de SNMP. Por ejemplo, esto podría incluir descriptores de archivo asociados con el bucle principal de una aplicación gráfica. Esta información se modifica para que SNMP obtenga el servicio que requiere de la llamada a select(2). En este caso, numfds, fdset y timeout corresponden a los argumentos nfds, readfds y timeout de select(2) respectivamente. La única excepción es que timeout DEBE apuntar SIEMPRE a una struct timeval asignada (pero quizás no inicializada) (no puede ser NULL como para select(2)). Si timeout se hubiera pasado como NULL, block se establecería en verdadero y timeout se trataría como indefinido. La misma regla se aplica al regresar de snmp_select_info().

Después de llamar a snmp_sess_select_info(), se debe llamar a select(2) con los datos devueltos. Cuando regrese, se debe llamar a snmp_sess_read() con el fd_set devuelto por select(2). Esto leerá cualquier entrada del socket SNMP de esta sesión. Si select(2) excede el tiempo de espera (es decir, devuelve cero), se debe llamar a snmp_sess_timeout() para ver si ha ocurrido un tiempo de espera en la sesión SNMP.

snmp_sess_synch_response es una rutina de conveniencia que enviará la solicitud, esperará la respuesta y la procesará antes de regresar. Consulte las descripciones de snmp_sess_send , snmp_sess_read, etc. para obtener detalles.

DIAGNOSTICS

El estado de retorno de error de snmp_sess_open() se indica con la devolución de un puntero NULL. El estado de retorno de error de snmp_sess_close() y snmp_sess_send() se indica con un valor de retorno de 0. Un estado exitoso devolverá 1.

Se puede obtener más información utilizando snmp_sess_error() para ver qué tipo de error ha ocurrido. Esta función devuelve la variable SNMP snmp_errno, el valor de la variable del sistema errno y una interpretación de cadena de ambas variables. La cadena debe ser liberada después de su uso por el llamador.

Para errores devueltos por snmp_sess_open(), use la función correspondiente snmp_error() en lugar de snmp_sess_error().

Consulte snmp_api.h para ver el conjunto completo de valores de error de la biblioteca SNMP. El valor de error de la biblioteca SNMP snmperr puede ser uno de los siguientes valores:

SNMPERR_GENERR
Ocurrió un error genérico.
SNMPERR_BAD_LOCPORT
El puerto local era incorrecto porque ya se había asignado o se denegó el permiso.
SNMPERR_BAD_ADDRESS
El nombre de host o la dirección proporcionada no era utilizable.
SNMPERR_BAD_SESSION
La sesión especificada no estaba abierta.
SNMPERR_TOO_LONG
SNMPERR_NO_SOCKET
SNMPERR_V2_IN_V1
SNMPERR_V1_IN_V2
SNMPERR_BAD_REPEATERS

NAME

snmp_sess_error, snmp_sess_error_str - functions for handling SNMP session errors.

SYNOPSIS

#include <net-snmp/session.h>
                    
int snmp_sess_error(void *session);
const char *snmp_sess_error_str(void *session);

DESCRIPTION

The snmp_sess_error and snmp_sess_error_str functions retrieve the last SNMP session error code and its string representation, respectively.

The argument session is a pointer to an snmp_session structure, as returned by snmp_open.

The snmp_sess_error function returns an integer error code. The snmp_sess_error_str function returns a C string describing the error.

If no error has occurred, snmp_sess_error returns SNMPERR_SUCCESS and snmp_sess_error_str returns NULL.

Possible error codes include:

SNMPERR_SUCCESS
No error.
SNMPERR_BAD_ADDRESS
The specified network address is not valid.
SNMPERR_BAD_PORT
The specified port number is not valid.
SNMPERR_BAD_SESSION
The provided session pointer is invalid.
SNMPERR_DLOPEN
Failed to load a required shared library.
SNMPERR_ENCRYPTION
An error occurred during encryption/decryption.
SNMPERR_FINDROOTKEY
Failed to find the root key for SNMPv3 encryption.
SNMPERR_GENERIC
An unspecified generic error occurred.
SNMPERR_GET_UNSIGNED_LONG
Failed to retrieve an unsigned long value.
SNMPERR_GET_LONG
Failed to retrieve a long value.
SNMPERR_GET_STRING
Failed to retrieve a string value.
SNMPERR_GET_INT
Failed to retrieve an integer value.
SNMPERR_GET_USHORT
Failed to retrieve an unsigned short value.
SNMPERR_GET_SHORT
Failed to retrieve a short value.
SNMPERR_GET_IPADDR
Failed to retrieve an IP address value.
SNMPERR_GET_TIMETICKS
Failed to retrieve a Timeticks value.
SNMPERR_GET_OPAQUE
Failed to retrieve an Opaque value.
SNMPERR_GET_NULL
Failed to retrieve a NULL value.
SNMPERR_GET_OBJECT_ID
Failed to retrieve an Object ID value.
SNMPERR_GET_BITSTRING
Failed to retrieve a Bitstring value.
SNMPERR_GET_NSAPADDRESS
Failed to retrieve an NSAP Address value.
SNMPERR_GET_COUNTER64
Failed to retrieve a Counter64 value.
SNMPERR_GET_UNSIGNED_32
Failed to retrieve an Unsigned32 value.
SNMPERR_GET_INTEGER_32
Failed to retrieve an Integer32 value.
SNMPERR_GET_UNSIGNED_64
Failed to retrieve an Unsigned64 value.
SNMPERR_GET_INTEGER_64
Failed to retrieve an Integer64 value.
SNMPERR_BAD_PACKET
The received SNMP packet is malformed.
SNMPERR_NOMEM
Out of memory.
SNMPERR_NOTOPEN
The session is not currently open.
SNMPERR_NORESPONSE
No response received from the remote host.
SNMPERR_REMOTE_ERROR
The remote SNMP agent returned an error.
SNMPERR_SEC_INIT
Failed to initialize security subsystem.
SNMPERR_SEC_MODEL_NX
Security model not supported.
SNMPERR_SEC_PARAM_NX
Security parameter not supported.
SNMPERR_SEC_TOKEN_NX
Security token not found.
SNMPERR_SYNTAX
SNMP PDU syntax error.
SNMPERR_UNABLE_TO_CREATE_SOCK
Unable to create a network socket.
SNMPERR_UNSUPPORTED_VERSION
Unsupported SNMP version.
SNMPERR_UNKNOWN_PDU
SNMPERR_TIMEOUT
