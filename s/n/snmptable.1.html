snmptable(1)

Paquete: net-snmp

Licencias: BSD

SNMPTABLE(1) Net-SNMP SNMPTABLE(1)

NOMBRE

snmptable - recuperar una tabla SNMP y mostrarla en formato tabular

SINOPSIS

snmptable [OPCIONES COMUNES] [-Cb] [-CB] [-Ch] [-CH] [-Ci] [-Cf CADENA] [-Cw ANCHO] AGENTE OID-TABLA

DESCRIPCIÓN

snmptable es una aplicación SNMP que utiliza repetidamente las solicitudes SNMP GETNEXT o GETBULK para consultar información sobre una entidad de red. El parámetro OID-TABLA debe especificar una tabla SNMP.

AGENTE identifica un agente SNMP de destino, que está instrumentado para monitorizar los objetos dados. En su forma más simple, la especificación de AGENTE consistirá en un nombre de host o una dirección IPv4. En esta situación, el comando intentará la comunicación con el agente, utilizando UDP/IPv4 al puerto 161 del host de destino dado. Consulte snmpcmd(1) para ver una lista completa de los posibles formatos para AGENTE.

OPCIONES

OPCIONES COMUNES
Consulte snmpcmd(1) para obtener una lista de valores posibles para OPCIONES COMUNES, así como sus descripciones.
-Cb
Mostrar solo un encabezado breve. Se eliminará cualquier prefijo común de los nombres de los campos de la tabla.
-CB
No utilizar solicitudes GETBULK para recuperar datos, solo GETNEXT.
-Cc CARACTERES
Imprimir tabla en columnas de ancho CARACTERES.
-Cf CADENA
La cadena CADENA se utiliza para separar las columnas de la tabla. Con esta opción, cada entrada de la tabla se imprimirá en formato compacto, solo con la cadena dada para separar las columnas (útil si desea importarla en una base de datos). De lo contrario, se imprimirá en columnas bien alineadas.
-Ch
Mostrar solo los encabezados de las columnas.
-CH
No mostrar los encabezados de las columnas.
-Ci
Esta opción antepone el índice de la entrada a todas las líneas impresas.
-Cl
Alinear los datos a la izquierda en cada columna.
-Cr REPETIDORES
Para solicitudes GETBULK, REPETIDORES especifica el valor max-repeaters a utilizar. Para solicitudes GETNEXT, REPETIDORES especifica el número de entradas a recuperar a la vez.
-Cw ANCHO
Especifica el ancho de las líneas al imprimir la tabla. Si las líneas son más largas, la tabla se imprimirá en secciones de un máximo de ANCHO caracteres. Si ANCHO es menor que la longitud del contenido de una sola columna, esa columna individual aún se imprimirá.

Tenga en cuenta que snmptable REQUIERE un argumento que especifique el agente a consultar y exactamente un argumento OID, como se describe en la página del manual de snmpcmd(1). Este OID **debe** ser el de un objeto de tabla MIB.

EJEMPLOS

$ snmptable -v 2c -c public localhost at.atTable

Tabla SNMP: at.atTable RFC1213-MIB::atTable

atIfIndex atPhysAddress atNetAddress
1 8:0:20:20:0:ab 130.225.243.33

$ snmptable -v 2c -c public -Cf + localhost at.atTable

Tabla SNMP: at.atTable

atIfIndex+atPhysAddress+atNetAddress 1+8:0:20:20:0:ab+130.225.243.33

ERRORES

La prueba para determinar si OID-TABLA realmente especifica una tabla es más bien heurística. Tenga en cuenta también que la prueba requiere que el archivo MIB definitorio esté cargado.
