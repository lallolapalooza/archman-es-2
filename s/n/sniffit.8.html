sniffit(8)

Paquete: sniffit

Licencias: BSD

SNIFFIT(8) Manual del Administrador del Sistema SNIFFIT(8)

NOMBRE

sniffit - herramienta de monitoreo y captura de paquetes

SINOPSIS

sniffit [-xdabvnN] [-P proto ] [-A car ] [-p puerto ] [(-r|-R) archivo_registro ] [-l longitud_captura ] [-L parametro_log ] [-F dispositivo_captura ] [-D tty ] [-M plugin ] [(-t IP_Destino | -s IP_Origen ) | (-i|-I) | -c archivo_config ]

DESCRIPCIÓN

sniffit es un capturador de paquetes TCP/UDP/ICMP. sniffit es capaz de proporcionarle información técnica muy detallada sobre estos paquetes (SEQ, ACK, TTL, Ventana, ...) pero también el contenido de los paquetes en diferentes formatos (hexadecimal o texto plano, ...).

Por defecto, sniffit puede manejar dispositivos ethernet y PPP, pero se le puede forzar fácilmente a usar otros dispositivos (lea los archivos README.FIRST y sn_config.h sobre este tema).

El capturador se puede configurar fácilmente para "filtrar" los paquetes entrantes (para que los resultados de la captura sean más fáciles de estudiar). El archivo de configuración (ver sniffit(5) ) le permite ser muy específico sobre los paquetes a procesar.

sniffit también tiene un modo interactivo para monitoreo activo, y también puede ser usado para monitoreo continuo en diferentes niveles.

NOTA

Esta página del manual está pensada para ser un manual de referencia. Así que por favor lea README.FIRST primero, y use esta solo para una mejor comprensión o para una verificación rápida del uso de sniffit

OPCIONES

-v
Muestra la versión de sniffit que está ejecutando y sale (anula todo)
-t IP_Destino
Solo procesa paquetes HACIA IP_Destino. Si IP_Destino está en notación punto-número, ´x' se permite como comodín. (ej. '-t 157.193.x', '-t x', ...) (NO compatible con: '-s' '-i' '-I' '-c' '-v' '-L')
-s IP_Origen
Similar a '-t', solo procesa paquetes DESDE IP_Origen. (NO compatible con: '-t' '-i' '-I' '-c' '-v' '-L')
-b
Modo 'ambos', junto con '-s' o '-t', solo procesa DESDE/HACIA la IP especificada por '-s' o '-t' (NO compatible con: '-t' '-i' '-I' '-c' '-v' '-L')
-c archivo_config
Usa archivo_config para el filtrado de paquetes. Esto le permite ser muy específico sobre los paquetes a procesar (ver sniffit(5) para detalles sobre el formato). (NO compatible con: '-t' '-s' '-i' '-I' '-v' '-L')
-i
Inicia la interfaz ncurses para monitoreo activo ('modo interactivo'). (NO disponible si compiló sin soporte INTERACTIVO, ver sn_config.h y README.FIRST ) (se requiere una de las opciones '-t' '-s' '-i' '-I' '-c') (NO compatible con: '-t' '-s' '-c' '-v' '-L')
-I
Igual que '-i', pero proporciona más información. (se requiere una de las opciones '-t' '-s' '-i' '-I' '-c') (NO compatible con: '-t' '-s' '-c' '-v' '-L')
-R <archivo>
Registra todo el tráfico en <archivo> Este archivo puede luego ser alimentado a Sniffit con la opción '-r'. (Necesita un parámetro de selección como '-c' '-t' '-s') (NO compatible con '-i' '-I' '-v' '-L' '-r')
-r <archivo>
Esta opción alimenta el <archivo> registrado a sniffit. Requiere la opción '-F' con el dispositivo correcto. Suponga que registra un archivo en una máquina con 'eth0'. Al alimentar el archivo registrado a sniffit , necesitará agregar '-F eth0' o '-F eth' a la línea de comandos. No necesita mucha explicación que usar '-i' o '-I' en combinación con '-r' no tiene sentido (en este momento). (requiere '-F', NO compatible con '-R' '-i' '-I')
-n
Desactiva la verificación de suma de control IP. Esto puede mostrarle paquetes falsos. (tenga en cuenta que ARP, RARP, otros paquetes no IP también aparecerán como falsos) (compatible con TODAS las opciones)
-N
No realiza ninguna de las funciones integradas de Sniffit. Útil para ejecutar solo un Plugin. (compatible con TODAS las opciones)
-x
Imprime información extendida sobre paquetes TCP a la salida estándar (SEQ, ACK, Flags, etc.) Interesante para rastrear suplantaciones, pérdida de paquetes y otras tareas de depuración/verificación de red reales. (si desea registrar esto, redirija la salida estándar a un archivo) (NO compatible con: '-i' 'I' '-v')
-d
Modo 'volcado', muestra los paquetes en la pantalla (salida estándar) en lugar de registrarlos en archivos (por defecto). Los datos se imprimen en bytes (hexadecimal). (NO compatible con: '-i' 'I' '-v' '-L')
-a
Modo 'volcado', igual que '-d' pero produce salida ASCII. Los caracteres no imprimibles se reemplazan por '.'. ('-d' y '-a' se mezclan sin ningún problema) (NO compatible con: '-i' '-I' '-v' '-L')
-P proto
Especifica los protocolos que deben procesarse (TCP por defecto). Las opciones posibles actualmente son: IP, TCP, ICMP, UDP. Se pueden combinar. La información de IP, ICMP, UDP se vuelca a la salida estándar. IP proporciona información ADICIONAL sobre el envoltorio IP alrededor de otros paquetes, no es necesario especificar IP para el registro de paquetes TCP. Los paquetes IP, ICMP no se filtran (los paquetes UDP sí desde la versión 0.3.4). (NO compatible con: '-i' '-I' '-v' '-L')
-A car
Cuando está en 'modo normal' (no '-d', '-a', '-i', '-I', '-L'), todos los caracteres no imprimibles serán reemplazados por car (NO compatible con: '-a' '-d' '-i' '-I' '-v' '-L')
-p puerto
Solo verifica paquetes que van HACIA (!!) el puerto puerto , 0 significa todos los puertos, por defecto es 0 (todos). (NO compatible con: '-c' '-i' '-I' '-v' '-L')
-l longitud_captura
Cantidad de datos a registrar (por defecto 300 bytes) en 'modo normal'. Los primeros longitud_captura bytes de cada conexión se registran. Una longitud de 0 significa todo. (¡cuidado con el espacio en disco!) (NO compatible con: '-i' '-I' '-v' '-L')
-F dispositivo_captura
Fuerza a sniffit a usar un dispositivo de red específico. dispositivo_captura se puede encontrar con ifconfig (ver ifconfig(8) ). sniffit soporta ethernet y PPP por defecto. Lea README.FIRST para obtener información sobre cómo forzar el uso de otros dispositivos. (compatible con TODAS las opciones)
-D tty
Toda la salida de registro se enviará a ese dispositivo. (SOLO funciona con '-i' y '-I')
-M plugin
Activa el Plugin número Plugin , para una lista de todos los plugins compilados en su versión, simplemente escriba ' sniffit '. Lea todo sobre los Plugins en el PLUGIN-HOWTO (¡LÉALO!) (NO compatible con: '-i' '-I' '-v')
-L parametro_log
Usa sniffit como una herramienta de monitoreo y habilita diferentes modos de registro ( parametro_log ) El archivo para el registro puede especificarse en el archivo de configuración (ver sniffit(5) ) pero es sniffit.log por defecto. Se pueden combinar diferentes parametro_log . (SOLO funciona con '-c')

MODO NORMAL

Un conjunto de bytes iniciales longitud_captura (por defecto 300) de cada conexión se registra en un archivo x.x.x.x.p-y.y.y.y.o donde 'x.x.x.x' es el host de origen (puerto 'p') y 'y.y.y.y' el host de destino (puerto 'o').

MODO VOLCADO ('-d' y/o '-a')

La salida se vuelca a la salida estándar, el contenido del paquete se muestra en su forma desplegada (el paquete IP completo).

MODO INTERACTIVO ('-i' o '-I')

Para cada paquete que coincide con sus criterios, verá un resumen en la pantalla. Si presiona una tecla, puede ver el paquete completo, en modo hexadecimal y ASCII.
