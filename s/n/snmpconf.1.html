SNMPCONF(1) Net-SNMP SNMPCONF(1)

NOMBRE

snmpconf - crea y modifica archivos de configuración SNMP

SINOPSIS

snmpconf [OPCIONES] [archivoACrear]

Iniciar con:
snmpconf -g basic_setup
O incluso simplemente:
snmpconf

DESCRIPCIÓN

snmpconf es un script simple de Perl que te guía paso a paso en la configuración de un archivo de configuración. Debería ser bastante fácil de usar. Simplemente ejecútalo y responde a sus preguntas.

En su modo de operación por defecto, pregunta al usuario con menús que muestran secciones de los diversos archivos de configuración que conoce. Cuando el usuario selecciona una sección, se muestra un submenú con las descripciones de los tokens que se pueden crear en esa sección. Cuando se selecciona una descripción, se le pide al usuario preguntas que construyen la línea de configuración en cuestión.

Finalmente, cuando el usuario sale del programa, cualquier archivo de configuración que haya sido editado por el usuario se guarda en el directorio local, completamente comentado.

Una opción particularmente útil es el modificador -g, que guía al usuario a través de un conjunto específico de preguntas de configuración. Ejecuta:

snmpconf -g basic_setup

como ejemplo.

OPCIONES

-f
Fuerza la sobrescritura de archivos existentes en el directorio actual sin preguntar al usuario si esto es algo deseado.
-i
Al terminar, instala los archivos en la ubicación donde los comandos globales del sistema esperan encontrarlos.
-p
Al terminar, instala los archivos en el subdirectorio .snmp del directorio home del usuario (donde las aplicaciones también buscarán archivos de configuración).
-I DIRECTORIO
Al terminar, instala los archivos en el directorio DIRECTORIO.
-a
No hacer preguntas. Simplemente lee los diversos archivos de configuración conocidos y los vuelve a escribir. Esto tiene el efecto de "auto-comentar" los archivos de configuración por ti. Ver la sección TRUCOS GENIALES a continuación.
-rtodo|ninguno
Lee todos o ninguno de los archivos de configuración encontrados. Normalmente, snmpconf te pregunta qué archivos deseas leer. Leer estos archivos de configuración fusionará estos archivos con los resultados de las preguntas que te haga.
-R ARCHIVO,...
Lee una lista específica de archivos de configuración.
-g NOMBREGRUPO
Se pueden crear grupos de entradas de configuración que se pueden utilizar para guiar a un usuario a través de una serie de preguntas para crear un archivo de configuración inicial. No hay menús que navegar, solo una lista de preguntas. Ejecuta:

snmpconf -g basic_setup

para un buen ejemplo.

-G
Lista todos los grupos conocidos.
-c DIRECTORIOCONFIG
snmpconf utiliza un directorio de información de configuración para aprender sobre los archivos y preguntas que debe hacer. Esta opción le dice a snmpconf que use una ubicación diferente para configurarse a sí mismo.
-q
Ejecuta un poco más silenciosamente. Dado que es un programa interactivo, no recomiendo esta opción ya que solo elimina información de la salida que está diseñada para ayudarte.
-d
Activa mucha salida de depuración.
-D
Añade aún más salida de depuración en forma de volcados de variables de Perl.

TRUCOS GENIALES

snmpconf -g basic_setup
¿He mencionado ya lo suficiente este comando? Está diseñado para guiar a alguien a través de una configuración inicial para el demonio snmpd(8). De verdad, deberías probarlo.
snmpconf -R /usr/local/snmp/snmpd.conf -a -f snmpd.conf
Lee automáticamente un archivo snmpd.conf (por ejemplo) y añade comentarios que describen lo que hace cada token. Pruébalo. Es genial.

NOTAS

snmpconf es en realidad una utilidad muy genérica que podría configurarse fácilmente para ayudar a construir casi cualquier tipo de archivo de configuración. Su conjunto de archivos de configuración por defecto está basado en SNMP.

VER TAMBIÉN

snmpd(8), snmp_config(5), snmp.conf(5), snmpd.conf(5)
