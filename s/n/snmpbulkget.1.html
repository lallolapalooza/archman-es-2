Paquete: net-snmp

SNMPBULKGET(1) Net-SNMP SNMPBULKGET(1)

NOMBRE

snmpbulkget - se comunica con una entidad de red utilizando solicitudes SNMP GETBULK.

SINOPSIS

snmpbulkget [OPCIONES COMUNES] [-Cn <num>] [-Cr <NUM>] AGENTE OID [OID]...

DESCRIPCIÓN

snmpbulkget es una aplicación SNMP que utiliza la solicitud SNMP GETBULK para consultar eficientemente una entidad de red en busca de información. Se puede proporcionar uno o más identificadores de objeto (OID) como argumentos en la línea de comandos. Cada nombre de variable se da en el formato especificado en variables(5).

Si la entidad de red tiene un error al procesar el paquete de solicitud, se devolverá un paquete de error y se mostrará un mensaje, lo que ayudará a identificar por qué la solicitud estaba mal formada.

OPCIONES

-Cn<NUM>
Establece el campo non-repeaters en la PDU GETBULK. Esto especifica el número de variables suministradas que no deben iterarse. El valor predeterminado es 0.
-Cr<NUM>
Establece el campo max-repetitions en la PDU GETBULK. Esto especifica el número máximo de iteraciones sobre las variables repetitivas. El valor predeterminado es 10.

Además de estas opciones, snmpbulkget toma las opciones comunes descritas en la página del manual snmpcmd(1). Tenga en cuenta que snmpbulkget REQUIERE un argumento que especifique el agente a consultar y al menos un argumento OID, como se describe allí.

EJEMPLO

El comando:

snmpbulkget -v2c -Cn1 -Cr5 -Os -c public zeus system ifTable

recuperará la variable system.sysDescr.0 (que es el objeto lexicográficamente siguiente a system) y los primeros 5 objetos de ifTable:

sysDescr.0 = STRING: "SunOS zeus.net.cmu.edu 4.1.3_U1 1 sun4m"
ifIndex.1 = INTEGER: 1
ifIndex.2 = INTEGER: 2
ifDescr.1 = STRING: "lo0"
etcétera.

NOTA

Como su nombre indica, snmpbulkget utiliza el mensaje SNMP GETBULK, que no está disponible en SNMPv1.

VER TAMBIÉN

snmpcmd(1), variables(5), RFC 1905.
