DESCRIPCIÓN

Las funciones que manejan las asignaciones de variables se dividen en cuatro grupos: manejo de la creación, establecimiento de valores, salida y eliminación de varbinds.

Creación

snmp_pdu_add_variable creará una nueva estructura varbind, inicializada con el nombre ( objid, objidlen ), sintaxis ( type ) y valor ( value , len ) proporcionados. Esta varbind se añade al final de la lista de varbinds en la PDU dada.

snmp_varlist_add_variable es similar, pero añade la nueva varbind al final de la lista de varbinds proporcionada. Al añadir la primera varbind a una lista vacía, simplemente pase la dirección de la cabeza de la lista:


netsnmp_variable_list *vl = NULL;
snmp_varlist_add_variable(
&vl, name1, name1_len,
ASN_TYPE, &val1, val1_len);
snmp_varlist_add_variable(
&vl, name2, name2_len,
ASN_TYPE, &val2, val2_len);

En ambos casos, la rutina devolverá un puntero a la nueva estructura varbind (o NULL si la creación de la varbind falla).

snmp_add_null_var es una función de conveniencia para añadir una varbind vacía a la PDU, sin necesidad de especificar explícitamente el valor NULL. Este es el mecanismo normal para construir una solicitud de recuperación de información GET (o similar).
Nuevamente, esto devuelve un puntero a la nueva varbind, o NULL.

snmp_clone_varbind crea una copia de cada varbind en la lista especificada, devolviendo un puntero a la cabeza de la nueva lista (o NULL si la clonación falla).

Establecimiento de valores

snmp_set_var_objid establece el nombre de la estructura varbind al OID especificado.
snmp_set_var_typed_value establece el tipo de sintaxis y el valor de la estructura varbind.
snmp_set_var_value establece el valor de la estructura varbind, dejando el tipo de sintaxis sin cambios.
snmp_set_var_typed_integer es una función de conveniencia para establecer el tipo de sintaxis y el valor para una varbind basada en enteros de 32 bits.

Las cuatro funciones devuelven 0 si la asignación es exitosa, o 1 si no lo es.

Salida

print_variable tomará un identificador de objeto (como el devuelto por read_objid, snmp_parse_oid o get_module_node) y una instancia de dicha variable, e imprimirá en la salida estándar la forma textual del identificador de objeto junto con el valor de la variable.

fprint_variable hace lo mismo, pero imprime en el puntero FILE especificado por el parámetro inicial.

snprint_variable imprime la misma información en el buffer apuntado por buf, que tiene una longitud de len. Devuelve el número de caracteres impresos, o -1 si el buffer no era lo suficientemente grande. En este último caso, buf típicamente contendrá una versión truncada de la información (pero este comportamiento no está garantizado). Esta función reemplaza la función obsoleta sprint_variable.

print_value, fprint_value, y snprint_value hacen lo mismo que las rutinas print_variable equivalentes, pero solo mostrando el valor de la variable, sin el identificador de objeto correspondiente.

Para mostrar el OID de una varbind, consulte netsnmp_mib_api(3).

Eliminación

snmp_free_var libera toda la memoria utilizada por la estructura varbind dada.
snmp_free_varbind libera toda la memoria utilizada por cada estructura varbind en la lista de varbinds proporcionada.
