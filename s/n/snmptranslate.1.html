snmptranslate(1)

Paquete: net-snmp

Licencias: BSD

SNMPTRANSLATE(1) Net-SNMP SNMPTRANSLATE(1)

NOMBRE

snmptranslate - traduce nombres de OID SNMP entre formas numéricas y textuales

SINOPSIS

snmptranslate [OPCIONES] OID [OID]...
snmptranslate [OPCIONES] -

DESCRIPCIÓN

snmptranslate es una aplicación que traduce uno o más valores de identificador de objeto SNMP desde sus formas simbólicas (textuales) a sus formas numéricas (o viceversa).

OID es un identificador de objeto numérico o textual.

El argumento especial - se utiliza para traducir múltiples OID en una sola ejecución. La entrada se toma de stdin y la salida se escribe en stdout. El formato de entrada puede ser un único OID por línea, o puede ser la salida de snmpwalk o snmpget.

OPCIONES

-D[TOKEN[,...]]
Activa la salida de depuración para el(los) TOKEN dado(s). Intenta con ALL para una salida extremadamente detallada.
-h
Muestra un breve mensaje de uso y luego sale.
-m LISTA_MIB
Especifica una lista de módulos MIB separados por dos puntos para cargar para esta aplicación. Esto anula la variable de entorno MIBS.
La palabra clave especial ALL se utiliza para especificar todos los módulos en todos los directorios al buscar archivos MIB. Cada archivo cuyo nombre no comience con "." se analizará como si fuera un archivo MIB.
-M LISTA_DIR
Especifica una lista de directorios separados por dos puntos para buscar MIBs. Esto anula la variable de entorno MIBDIRS.
-T OPCIONES_TRANS
Proporciona control sobre la traducción de los valores OID. Las siguientes OPCIONES_TRANS están disponibles:
-TB
Imprime todos los objetos coincidentes para una búsqueda de expresiones regulares.
-Td
Imprime detalles completos del OID especificado.
-Tp
Imprime un árbol gráfico, enraizado en el OID especificado.
-Ta
Descarga el MIB cargado en un formato trivial.
-Tl
Descarga un formato etiquetado de todos los objetos.
-To
Descarga un formato numérico de todos los objetos.
-Ts
Descarga un formato simbólico de todos los objetos.
-Tt
Descarga un formato de árbol de los MIBs cargados (principalmente útil para depuración).
-Tz
Descarga un formato numérico y etiquetado de todos los objetos (compatible con el formato MIB2SCHEMA).
-V
Muestra información de la versión de la aplicación y luego sale.
-w ANCHO
Especifica el ancho de la salida de -Tp y -Td. El valor predeterminado es muy grande.

Además de las opciones anteriores, snmptranslate toma las opciones de entrada OID (-I), análisis de MIB (-M) y salida OID (-O) descritas en las secciones OPCIONES DE ENTRADA, OPCIONES DE ANÁLISIS DE MIB y OPCIONES DE SALIDA de la página del manual snmpcmd(1).

EJEMPLOS

•
snmptranslate -On -IR sysDescr
traducirá "sysDescr" a una forma más calificada:
system.sysDescr
•
snmptranslate -Onf -IR sysDescr
traducirá "sysDecr" a:
.iso.org.dod.internet.mgmt.mib-2.system.sysDescr
•
snmptranslate -Td -OS system.sysDescr
traducirá "sysDecr" a:
SNMPv2-MIB::sysDescr
sysDescr OBJECT-TYPE
  -- FROM SNMPv2-MIB
  -- TEXTUAL CONVENTION DisplayString
  SYNTAX OCTET STRING (0..255)
  DISPLAY-HINT "255a"
  MAX-ACCESS read-only
  STATUS current
  DESCRIPTION "A textual description of the entity. This
               value should include the full name and
               version identification of the system's
               hardware type, software operating-system,
               and networking software."
::= { iso(1) org(3) dod(6) internet(1) mgmt(2) mib-2(1) system(1) 1 }
•
snmptranslate -Tp -OS system
imprimirá el siguiente árbol:
+--system(1)
   |
   +-- -R-- String    sysDescr(1)
   |        Textual Convention: DisplayString
   |        Size: 0..255
   +-- -R-- ObjID     sysObjectID(2)
   +-- -R-- TimeTicks sysUpTime(3)
   +-- -RW- String    sysContact(4)
   |        Textual Convention: DisplayString
   |        Size: 0..255
   +-- -RW- String    sysName(5)
   |        Textual Convention: DisplayString
   |        Size: 0..255
   +-- -RW- String    sysLocation(6)
   |        Textual Convention: DisplayString
   |        Size: 0..255
   +-- -R-- Integer   sysServices(7)
   +-- -R-- TimeTicks sysORLastChange(8)
   |        Textual Convention: TimeStamp
   |
   +--sysORTable(9)
      |
      +--sysOREntry(1)
         |
         +-- ---- Integer   sysORIndex(1)
         +-- -R-- ObjID     sysORID(2)
         +-- -R-- String    sysORDescr(3)
         |        Textual Convention: DisplayString
         |        Size: 0..255
         +-- -R-- TimeTicks sysORUpTime(4)
                  Textual Convention: TimeStamp
•
snmptranslate -Ta | head
producirá la siguiente descarga:
