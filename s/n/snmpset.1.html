SNMPSET(1) Net-SNMP SNMPSET(1)

NOMBRE

snmpset - se comunica con una entidad de red utilizando peticiones SNMP SET

SINOPSIS

snmpset [OPCIONES COMUNES] AGENTE OID TIPO VALOR [OID TIPO VALOR]...

DESCRIPCIÓN

snmpset es una aplicación SNMP que utiliza la petición SNMP SET para establecer información en una entidad de red. Se deben proporcionar uno o más identificadores de objeto (OID) como argumentos en la línea de comandos. Un tipo y un valor a establecer deben acompañar a cada identificador de objeto. Cada nombre de variable se proporciona en el formato especificado en variables(5).

El TIPO es un solo carácter, uno de:

i
INTEGER
u
UNSIGNED
s
STRING
x
HEX STRING
d
DECIMAL STRING
n
NULLOBJ
o
OBJID
t
TIMETICKS
a
IPADDRESS
b
BITS
La mayoría de estos usarán el tipo ASN.1 correspondiente obvio. 's', 'x', 'd' y 'b' son todas formas diferentes de especificar un valor OCTET STRING, y el tipo unsigned 'u' también se utiliza para manejar valores Gauge32.

Si tiene cargado el archivo MIB adecuado, en la mayoría de los casos puede reemplazar el tipo por un signo '='. Para un objeto de tipo OCTET STRING, esto asumirá una cadena como la notación de tipo 's'. Para otros tipos, hará "lo correcto".

Por ejemplo:

snmpset -c private -v 1 test-hub system.sysContact.0 s dpz@noc.rutgers.edu ip.ipforwarding.0 = 2

establecerá las variables sysContact.0 e ipForwarding.0:

system.sysContact.0 = STRING: "dpz@noc.rutgers.edu"
ip.ipForwarding.0 = INTEGER: not-forwarding(2)

Si la entidad de red tiene un error al procesar el paquete de petición, se devolverá un paquete de error y se mostrará un mensaje, ayudando a identificar en qué forma se malformó la petición.

OPCIONES

snmpset toma las opciones comunes descritas en la página del manual snmpcmd(1). Tenga en cuenta que snmpset REQUIERE un argumento que especifique el agente a consultar y al menos un conjunto de argumentos OID/tipo/valor, como se describe allí.

VER TAMBIÉN

snmpcmd(1), variables(5).
