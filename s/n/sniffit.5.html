SNIFFIT(5) Manual de formatos de archivo SNIFFIT(5)

NOMBRE

sniffit - archivo de configuración para sniffit (nombre arbitrario)

DESCRIPCIÓN

Esta página describe el formato del archivo de configuración para sniffit (ver sniffit(8) ). Este archivo permite especificar con gran detalle qué paquetes deben ser procesados por sniffit. Este archivo también controla (o controlará) algunas funciones para el registro continuo (opción '-L').

Un archivo de configuración de sniffit podría verse así (¡Asegúrate de que termine con una línea en BLANCO!):

# Archivo de configuración de ejemplo de Sniffit -- Brecht Claerhout
logfile /var/log/sniffit.today.log
# ¡Primero selecciona todos los paquetes!
select both mhosts 1
select both mhosts 2
# Ahora deselecciona todos los paquetes de/hacia esos malditos 'surfistas'
deselect both port 80
deselect both port 8001

Esto le indicará a sniffit que procese todos los paquetes de la subred excepto aquellos DESDE/HACIA los puertos 80 y 8001 (así no queremos registros de esas conexiones masivas de WWW que vuelven nuestros registros ilegibles).

FORMATO GLOBAL

El archivo consta de líneas, las líneas se forman por campos, los campos se separan con ESPACIOS (SIN TABULADORES). Se permiten líneas de comentario de Unix (que comienzan con '#'). Así que esto nos da:

<campo1> <campo2> <campo3> <campo4> <campo5>

FORMATO DE CAMPO

<campo1>
select - Sniffit buscará paquetes que coincidan con la siguiente descripción (otros campos)
deselect - Sniffit ignorará los paquetes que coincidan con la descripción
logfile - cambia el nombre del archivo de registro a <campo2> en lugar del predeterminado 'sniffit.log'
<campo2>
from - Se consideran los paquetes DESDE el host que coincide con la siguiente descripción.
to - similar, Paquetes HACIA el....
both - similar, Paquetes DESDE o HACIA el....
a filename - como argumento de 'logfile' en <campo1>
<campo3>
host - Los criterios de (des)selección involucran un nombre de host.
port - similar, ... un número de puerto
mhosts - Los criterios de (des)selección involucran múltiples hosts, como con los comodines en 0.3.0, pero sin la 'x'
<campo4>
Ya sea un nombre de host, un número de puerto, un nombre de servicio o una notación parcial de número-punto que indica múltiples hosts dependiendo de <campo3> (los nombres de servicio como 'ftp' se resuelven como los servicios disponibles presentes en el host que ejecuta Sniffit, y se traducen a un número de puerto)
<campo5>
Un número de puerto, si <campo3> era 'host' o 'mhosts' (opcional, si no se rellena, todos los puertos serán (des)seleccionados)

INTERPRETACIÓN DEL ARCHIVO

El archivo de configuración se interpreta SECUENCIALMENTE, así que ten cuidado, no mezcles líneas en un archivo. Ejemplo:

      select both mhosts 100.100.12.
      deselect both port 80
      select both host 100.100.12.2
Este archivo te dará los paquetes:
      a) Enviados por los hosts '100.100.12.*'
      b) EXCEPTO los paquetes WWW
      c) PERO mostrando los paquetes WWW relacionados con
         100.100.12.2
      select both mhosts 100.100.12.
      select both host 100.100.12.2
      deselect both port 80
Te dará los paquetes (probablemente un resultado no deseado):
      a) Enviados por los hosts '100.100.12.*'
      b) Enviados desde/hacia 100.100.12.2 (línea inútil)
      c) deseleccionando todos los paquetes WWW de la subred
