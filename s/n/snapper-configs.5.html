SNAPPER-CONFIGS(5) Gestión de instantáneas del sistema de archivos SNAPPER-CONFIGS(5)

NOMBRE

snapper-configs - Archivos de configuración para las configuraciones de snapper

DESCRIPCIÓN

Cada archivo /etc/snapper/configs/* describe una configuración de snapper.

VARIABLES

La siguiente es una lista de variables que pueden estar presentes en el archivo de configuración. Los valores booleanos deben ser "yes" o "no".

SUBVOLUME=ruta

Ruta del subvolumen o punto de montaje.

No hay un valor predeterminado. El valor siempre debe especificarse.

FSTYPE=valor

Tipo de sistema de archivos para el subvolumen.

El valor predeterminado es "btrfs", pero se recomienda especificar siempre el tipo de sistema de archivos.

QGROUP=qgroup

El grupo de cuotas de btrfs utilizado para los algoritmos de limpieza sensibles al espacio.

Solo compatible con btrfs.

SPACE_LIMIT=float o tamaño

Umbral para el espacio máximo que las instantáneas deben usar en el sistema de archivos. Cuando las instantáneas exceden este límite (ya sea como una fracción del sistema de archivos completo o un valor absoluto), snapper eliminará las instantáneas más antiguas durante las operaciones de limpieza. Un valor absoluto debe usar la configuración regional C.

Solo compatible con btrfs.

El valor predeterminado es "0.5" (50% del sistema de archivos).

Nuevo en la versión 0.3.0, valor absoluto nuevo en la versión 0.9.0.

FREE_LIMIT=float o tamaño

Umbral para el espacio libre mínimo que debe quedar en el sistema de archivos. Cuando el espacio libre cae por debajo de este límite (ya sea como una fracción del sistema de archivos completo o un valor absoluto), snapper eliminará las instantáneas más antiguas durante las operaciones de limpieza para recuperar espacio. Un valor absoluto debe usar la configuración regional C.

Solo compatible con btrfs.

El valor predeterminado es "0.2" (20% del sistema de archivos).

Nuevo en la versión 0.8.0, valor absoluto nuevo en la versión 0.9.0.

ALLOW_USERS=usuarios

Lista de usuarios permitidos para operar con la configuración. Los nombres de usuario deben estar separados por espacios. Los espacios en los nombres de usuario se pueden escapar con una "\".

Consulte también la sección PERMISSIONS en snapper(8).

Se debe evitar el uso de usuarios de red, ya que puede romper la mayoría de los comandos, incluido el rollback, cuando la red no funciona.

El valor predeterminado es "", pero "root" siempre se incluye implícitamente.

ALLOW_GROUPS=grupos

Lista de grupos permitidos para operar con la configuración. Los nombres de grupo deben estar separados por espacios. Los espacios en los nombres de grupo se pueden escapar con una "\".

Consulte también la sección PERMISSIONS en snapper(8).

Se debe evitar el uso de grupos de red, ya que puede romper la mayoría de los comandos, incluido el rollback, cuando la red no funciona.

El valor predeterminado es "".

SYNC_ACL=booleano

Define si snapper sincronizará los usuarios y grupos de ALLOW_USERS y ALLOW_GROUPS con la ACL del directorio .snapshots.

Consulte también la sección PERMISSIONS en snapper(8).

El valor predeterminado es "no".

Nuevo en la versión 0.2.0.

BACKGROUND_COMPARISON=booleano

Define si las instantáneas pre y post deben compararse en segundo plano después de la creación.

El valor predeterminado es "yes".

COMPRESSION=algoritmo

Define el algoritmo de compresión utilizado para guardar la lista de archivos. Los valores permitidos son "none" y "gzip". Dependiendo de las bibliotecas instaladas, es posible que algunos algoritmos de compresión no estén disponibles.

El valor predeterminado es "gzip".

Nuevo en la versión 0.10.1.

NUMBER_CLEANUP=booleano

Define si se debe ejecutar el algoritmo de limpieza por número para la configuración.

El valor predeterminado es "no".

NUMBER_MIN_AGE=segundos

Edad mínima para que las instantáneas sean eliminadas por el algoritmo de limpieza por número.

El valor predeterminado es "3600".

NUMBER_LIMIT=número o rango

Define cuántas instantáneas debe conservar el algoritmo de limpieza por número. Se conservarán las instantáneas más recientes.

El valor predeterminado es "50".

NUMBER_LIMIT_IMPORTANT=número o rango

Define cuántas instantáneas importantes debe conservar el algoritmo de limpieza por número. Las instantáneas importantes tienen important=yes en los datos de usuario. Se conservarán las instantáneas importantes más recientes.

El número de instantáneas normales e importantes se cuentan de forma independiente.

El valor predeterminado es "10".

Nuevo en la versión 0.1.8.

TIMELINE_CREATE=booleano

Define si se deben crear instantáneas por hora.

Junto con el algoritmo de limpieza de línea de tiempo, esto creará una colección de instantáneas con más instantáneas en el pasado reciente y menos instantáneas en el pasado lejano.

El valor predeterminado es "no".

TIMELINE_CLEANUP=booleano

Define si se debe ejecutar el algoritmo de limpieza de línea de tiempo para la configuración.

El valor predeterminado es "no".

TIMELINE_MIN_AGE=segundos

Edad mínima para que las instantáneas sean eliminadas por el algoritmo de limpieza de línea de tiempo.

El valor predeterminado es "3600".

TIMELINE_LIMIT_HOURLY=número o rango

Define cuántas instantáneas horarias debe conservar el algoritmo de limpieza de línea de tiempo. Una instantánea horaria es la primera instantánea de una hora. Se conservarán las instantáneas horarias más recientes.

El valor predeterminado es "10".

TIMELINE_LIMIT_DAILY=número o rango

Define cuántas instantáneas diarias debe conservar el algoritmo de limpieza de línea de tiempo. Una instantánea diaria es la primera instantánea de un día. Se conservarán las instantáneas diarias más recientes.

El valor predeterminado es "10".

TIMELINE_LIMIT_WEEKLY=número o rango

Define cuántas instantáneas semanales debe conservar el algoritmo de limpieza de línea de tiempo. Una instantánea semanal es la primera instantánea de una semana. Se conservarán las instantáneas semanales más recientes. De acuerdo con ISO 8601, las semanas comienzan los lunes.

El valor predeterminado es "0".

TIMELINE_LIMIT_MONTHLY=número o rango

Define cuántas instantáneas mensuales debe conservar el algoritmo de limpieza de línea de tiempo. Una instantánea mensual es la primera instantánea de un mes. Se conservarán las instantáneas mensuales más recientes.

El valor predeterminado es "10".

TIMELINE_LIMIT_QUARTERLY=número o rango

Define cuántas instantáneas trimestrales debe conservar el algoritmo de limpieza de línea de tiempo. Una instantánea trimestral es la primera instantánea de un trimestre. Se conservarán las instantáneas trimestrales más recientes.

El valor predeterminado es "0".

TIMELINE_LIMIT_YEARLY=número o rango

Define cuántas instantáneas anuales debe conservar el algoritmo de limpieza de línea de tiempo. Una instantánea anual es la primera instantánea de un año. Se conservarán las instantáneas anuales más recientes.

El valor predeterminado es "10".

EMPTY_PRE_POST_CLEANUP=booleano

Define si el algoritmo de limpieza empty-pre-post debe ejecutarse para la configuración.

El valor predeterminado es "no".

EMPTY_PRE_POST_MIN_AGE=segundos

Edad mínima para que las instantáneas sean eliminadas por el algoritmo de limpieza empty-pre-post.

El valor predeterminado es "3600".

TIPOS

Algunos de los tipos utilizados para las variables merecen una explicación.

rango

Un rango de números dado como valor-mínimo-valor-máximo, por ejemplo, "10-20".

NAME

snapper-configs(5)

configuration file for snapper

DESCRIPTION

The snapper configuration files are used to configure how snapper works. The configuration files are stored in /etc/snapper/configs/ and are named by the snapshotting target. For example, the configuration for the root file system is usually stored in /etc/snapper/configs/root.

The configuration file uses a simple name=value syntax. Sections are introduced with square brackets. The most common section is [General].

VARIABLES

The following variables can be set in the [General] section:

ALLOW_USERS
A space separated list of users who are allowed to use snapper. By default, only root is allowed.
ALLOW_GROUPS
A space separated list of groups who are allowed to use snapper. By default, only root group is allowed.
ALLOW_EMPTY_LOGS
If set to yes, snapper will allow to create snapshots of empty directories or snapshot directories that don't contain any files. Default is "no".
NUMBER_CLEANUP_ALGORITHMS
A space separated list of cleanup algorithms that will be used to clean snapshots. See snapper-cleanup(8) for more information. The algorithms are executed in the specified order.
NUMBER_LIMIT_IMPORTANT
The maximum number of snapshots to keep for each important snapshot. See snapper-cleanup(8) for more information.
NUMBER_LIMIT_CLEAN
The maximum number of snapshots to keep for each clean snapshot. See snapper-cleanup(8) for more information.
NUMBER_LIMIT_PRESERVE_MINUTES
The minimum number of minutes to keep snapshots. See snapper-cleanup(8) for more information.
NUMBER_LIMIT_PRESERVE_HOURS
The minimum number of hours to keep snapshots. See snapper-cleanup(8) for more information.
NUMBER_LIMIT_PRESERVE_DAYS
The minimum number of days to keep snapshots. See snapper-cleanup(8) for more information.
NUMBER_LIMIT_PRESERVE_WEEKS
The minimum number of weeks to keep snapshots. See snapper-cleanup(8) for more information.
TIMELINE_CREATE
If set to yes, timeline snapshots will be created. Default is "no".
TIMELINE_LIMIT_HOURLY
The maximum number of hourly snapshots to keep. Default is 10.
TIMELINE_LIMIT_DAILY
The maximum number of daily snapshots to keep. Default is 10.
TIMELINE_LIMIT_WEEKLY
The maximum number of weekly snapshots to keep. Default is 10.
TIMELINE_LIMIT_MONTHLY
The maximum number of monthly snapshots to keep. Default is 10.
TIMELINE_LIMIT_YEARLY
The maximum number of yearly snapshots to keep. Default is 10.
EMPTY_LOG_DIR_CLEANUP
If set to yes, empty log directories are removed. Default is "no".
SYNC_ACL
If set to yes, ACLs are synchronized between snapshots. Default is "yes".
SYNC_XATTR
If set to yes, extended attributes are synchronized between snapshots. Default is "yes".
QGROUP
Set the qgroup for the snapshot. The format is <parent_qgroup>/<qgroup_id>. Example: 1/0. This variable is only relevant for btrfs snapshots.

TYPES

The qgroup variable must be in the standard form level-id, e.g. "1/0".

NOTES

The default values stated here are the values snapper uses when the entry is missing in the configuration file. Some are not identical to the values from the configuration file template.
