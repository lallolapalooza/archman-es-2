NOMBRE

snmp-ups - Driver Multi-MIB para equipos UPS SNMP

SINOPSIS

snmp-ups -h

snmp-ups -a NOMBRE_UPS [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas de hardware del driver snmp-ups. Para obtener información sobre el driver principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

El driver snmp-ups detecta y soporta automáticamente una amplia gama de dispositivos cargando varias MIBs, como:

ietf

UPS que cumplen con RFC 1628 (UPS MIB), p. ej., MGE UPS SYSTEMS, Liebert, quizás otros (por defecto)

mge

Dispositivos MGE UPS SYSTEMS y MGE Office Protection Systems con tarjetas SNMP (ref 66062, 66045, 66074 y 66244)

apcc

Tarjetas de gestión de red APC AP9605, AP9606, AP9617 y AP9618, así como cualquier otra que soporte la MIB APC POWERNET

netvision

UPS Sicon de Socomec con tarjeta/caja externa de gestión Web/SNMP Netvision

eaton_pw_nm2

Dispositivos Powerware con tarjetas SNMP ConnectUPS, así como UPS con tarjetas Gigabit Network de Eaton (Network-M2) (renombrado de pw)

eaton_pxg_ups

Dispositivos Eaton con tarjeta UPS Power Xpert Gateway (renombrado de pxgx_ups)

aphel_genesisII

Eaton Powerware ePDU Monitoreado

aphel_revelation

Eaton Powerware ePDU Gestionado

raritan

Varios PDU de Raritan (Dominion PX, PM, RPC)

raritan-px2

Varios PDU de Raritan (Dominion PX2)

baytech

Varios PDU de BayTech

cpqpower

Tarjeta de gestión HP/Compaq AF401A, quizás otras

cyberpower

Cyberpower RMCARD201. También debería soportar RMCARD100 (versión de red), RMCARD202 y RMCARD301

huawei

Huawei UPS5000-E, quizás otros

tripplite

UPS TrippLite; en este momento es el mapeo de la MIB IETF con solo el OID de punto de entrada Tripplite para verificar el proveedor del dispositivo, y una configuración específica de hardware se agregará en el desarrollo futuro.

Para obtener una lista completa y actualizada, puede consultar el driver pasando el argumento mibs=--list (ver más abajo).

ARGUMENTOS ADICIONALES

Este driver soporta las siguientes configuraciones opcionales en el ups.conf(5):

port=nombre_host[:puerto]

Establece el nombre de host SNMP, o la dirección IP, y el número de puerto del agente SNMP par. No hay un valor predeterminado para el nombre de host, pero el puerto predeterminado es 161.

mibs=--list

Una opción especial que permite listar los mapeos MIB-a-NUT conocidos actualmente y salir del binario del driver, destinado a un uso en línea de comandos como este: 
:; snmp-ups -a snmp-test -x mibs=--list

mibs=nombre

Establece la conformidad de la MIB (por defecto=auto, entradas permitidas: consulte HARDWARE SOPORTADO arriba).

Con "auto", el driver intentará un conjunto selecto de objetos SNMP hasta que encuentre uno al que el dispositivo responda.

Tenga en cuenta que desde NUT 2.6.2, snmp-ups tiene un nuevo método que utiliza sysObjectID (que es un puntero a la MIB preferida del dispositivo) para detectar dispositivos compatibles. Esto invalida el requisito de usar la opción "mibs".

community=nombre

Establece el nombre de comunidad (por defecto es public) para conexiones SNMPv1 y SNMPv2c. Tenga en cuenta que se requiere un nombre de comunidad capaz de lectura/escritura (RW) para cambiar la configuración de la UPS y enviar comandos (como para un apagado).

snmp_version=version

Establece la versión SNMP (por defecto = v1, permitidas: v2c, v3)

snmp_retries=intentos

Especifica el número de reintentos de Net-SNMP que se utilizarán en las solicitudes (por defecto=5)

snmp_timeout=tiempo_espera

Especifica el tiempo de espera de Net-SNMP en segundos entre reintentos (por defecto=1)

symmetrathreephase

Habilita las peculiaridades de la Symmetra trifásica de APCC (usar en Symmetras trifásicas de APCC): Convierte el voltaje de línea a línea trifásico a voltaje de línea a neutro (por defecto: no habilitado)

pollfreq=num

Establece el intervalo de sondeo para actualizaciones completas, en segundos, para reducir el tráfico de red SNMP en relación con las actualizaciones rápidas realizadas cada "pollinterval" (esta última opción se describe en ups.conf(5)). El valor predeterminado es 30 (en segundos).

notransferoids

Deshabilita el monitoreo de los OIDs de transferencia de alto y bajo voltaje en el hardware. Esto eliminará input.transfer.low y input.transfer.high de la lista de variables. Esto solo debe usarse en equipos Symmetra de APCC que tienen rarezas en la notificación de energía trifásica.

secLevel=valor

Establece el nivel de seguridad (securityLevel) utilizado para mensajes SNMPv3 (por defecto=noAuthNoPriv, permitidos: authNoPriv, authPriv) Este parámetro es obligatorio si utiliza autenticación no trivial.

secName=valor

Establece el nombre de seguridad (securityName) utilizado para mensajes SNMPv3 autenticados (sin valor predeterminado)

authPassword=valor

Establece la frase de contraseña de autenticación utilizada para mensajes SNMPv3 autenticados (sin valor predeterminado)

privPassword=valor

Establece la frase de contraseña de privacidad utilizada para mensajes SNMPv3 encriptados (sin valor predeterminado)

authProtocol=valor

Establece el protocolo de autenticación (MD5, SHA, SHA256, SHA384 o SHA512) utilizado para mensajes SNMPv3 autenticados (por defecto=MD5). Tenga en cuenta que la lista exacta de protocolos depende de las capacidades de la biblioteca Net-SNMP; consulte la ayuda del programa binario snmp-ups para obtener la lista soportada en tiempo de ejecución.

privProtocol=valor

Establece el protocolo de privacidad (DES, AES, AES192 o AES256) utilizado para mensajes SNMPv3 encriptados (por defecto=DES). Tenga en cuenta que la lista exacta de protocolos depende de las capacidades de la biblioteca Net-SNMP; consulte la ayuda del programa binario snmp-ups para obtener la lista soportada en tiempo de ejecución.

REQUISITOS

Deberá instalar el paquete Net-SNMP de http://www.net-snmp.org/ antes de compilar este driver.

SNMP v3 también requiere soporte de OpenSSL de http://www.openssl.org.

LIMITACIONES

Apagado

La secuencia de apagado debe ser probada antes de confiar en que NUT envíe un comando de apagado a la UPS. El problema es que la pila de red del host puede haber sido desmantelada para cuando se invoca al driver para enviar el comando de apagado. El driver intenta enviar los comandos shutdown.return, shutdown.reboot y load.off.delay a la UPS en secuencia, deteniéndose después del primer comando soportado.

Uso de nombres de host para la NMC de la UPS

A una tarjeta de gestión de red de una UPS se le puede asignar una dirección IP fija/estática o una dinámica (por ejemplo, mediante DHCP) en su red. Debido a esto, es posible que desee o necesite utilizar un servicio de nombres dinámicos para acceder a la UPS. Tenga en cuenta que esto puede convertirse en un problema, especialmente durante cortes de energía importantes y apagados, cuando su servidor DHCP/DNS ya puede haber caído mientras el driver necesita resolver el nombre involucrado (especialmente durante los hooks de apagado tardío, cuando una nueva instancia del programa driver podría iniciarse solo para indicar a la UPS que se apague o que se reinicie).

Puede ser prudente asegurarse de que el cliente del servicio de nombres de su sistema operativo pueda almacenar en caché el nombre de la UPS durante el tiempo suficiente, o utilizar direccionamiento IP fijo (y una entrada en /etc/hosts para estar seguro, de modo que solo tenga un lugar para reconfigurar esto eventualmente).

snmp-ups(8)

NAME

snmp-ups - Driver for UPSes supporting the SNMP protocol

SYNOPSIS

snmp-ups

SUPPORTED HARDWARE

All UPS devices that support the SNMP (Simple Network Management Protocol) protocol.

This driver is an SNMP client. It uses the Net-SNMP library (http://www.net-snmp.org/) to communicate with the UPS.

Please consult the NUT Supported Devices list for specific models and MIBs (Management Information Bases) that have been tested.

However, if your device implements the RFC 1628 UPS MIB, this driver should work out of the box.

You can specify MIBs to be loaded on a per-device basis by using the mibdirs and mibs configuration directives.

EXTRA ARGUMENTS

This driver supports the following extra arguments in ups.conf(5):

  • mibdirs: A comma-separated list of directories to search for MIB files. These directories are searched in addition to the default Net-SNMP search paths.
  • mibs: A comma-separated list of MIB file names to load.
  • community: The SNMP community string to use for communicating with the UPS (for SNMPv1 and v2c). Defaults to "public".
  • snmp_version: The SNMP protocol version to use. Valid values are "v1", "v2c", and "v3". Defaults to "v1".
  • secLevel: The security level for SNMPv3. Valid values are "noAuthNoPriv", "authNoPriv", and "authPriv".
  • secName: The security name for SNMPv3.
  • authPassword: The authentication password for SNMPv3.
  • privPassword: The privacy (encryption) password for SNMPv3.
  • authProto: The authentication protocol for SNMPv3. Valid values are "MD5" and "SHA" (case-insensitive). Defaults to "MD5".
  • privProto: The privacy protocol for SNMPv3. Valid values are "DES" and "AES" (case-insensitive). Defaults to "DES".
  • pollfreq: The interval (in seconds) between polls of the UPS. Defaults to 60 seconds.
  • updatetime: The interval (in seconds) between polls of the UPS when it is on battery. Defaults to 15 seconds.
  • desc: A descriptive string for the UPS.

REQUIREMENTS

This driver requires the Net-SNMP development files to be present at configuration time.

LIMITATIONS

This driver relies on the Net-SNMP library for SNMP communication. If Net-SNMP does not support your device's SNMP implementation, this driver may not work.

The driver queries a standard set of OIDs (Object Identifiers) for UPS information. If your device uses non-standard OIDs, you may need to modify the driver or use a custom MIB file.

INSTALLATION

This driver is only built if the Net-SNMP development files are present at configuration time. You can also force it to be built by using configure --with-snmp=yes before calling make.

EXAMPLES

The hostname of the UPS is specified with the "port" value in ups.conf, and may include a non-standard (161) remote peer port:

        [snmpv1]
                driver = snmp-ups
                port = snmp-ups.example.com
                community = public
                snmp_version = v1
                pollfreq = 15
                desc = "Example SNMP v1 device"
        [snmpv3]
                driver = snmp-ups
                port = 166.99.224.132:170
                snmp_version = v3
                secLevel = authPriv
                secName = mysecurityname
                authPassword = myauthenticationpassphrase
                privPassword = myprivatepassphrase
                desc = "Example SNMP v3 device, with the highest security level"
