Paquete: net-snmp

Licencias: BSD

SNMPDELTA(1) Net-SNMP SNMPDELTA(1)

NOMBRE

snmpdelta - Monitorizar diferencias delta en valores de contador SNMP

SINOPSIS

snmpdelta [ OPCIONES COMUNES ] [-Cf] [ -Ct ] [ -Cs ] [ -CS ] [ -Cm ] [ -CF archivo_config ] [ -Cl ] [ -Cp periodo ] [ -CP Picos ] [ -Ck ] [ -CT ] AGENTE OID [ OID ... ]

DESCRIPCIÓN

snmpdelta monitorizará los OID de valor entero especificados y reportará los cambios a lo largo del tiempo.

AGENTE identifica un agente SNMP de destino, que está instrumentado para monitorizar los objetos dados. En su forma más simple, la especificación de AGENTE consistirá en un nombre de host o una dirección IPv4. En esta situación, el comando intentará la comunicación con el agente, utilizando UDP/IPv4 al puerto 161 del host de destino dado. Consulte snmpcmd(1) para obtener una lista completa de los posibles formatos para AGENTE.

OID es un identificador de objeto que identifica de forma única el tipo de objeto dentro de una MIB. Se pueden especificar múltiples OID en un único comando snmpdelta.

OPCIONES

OPCIONES COMUNES
Consulte snmpcmd(1) para obtener una lista de los posibles valores para OPCIONES COMUNES, así como sus descripciones.
-Cf
No corrija errores y reintente la solicitud. Sin esta opción, si se han especificado múltiples OID para una sola solicitud y si la solicitud para uno o más de los OID falla, snmpdelta reintentará la solicitud para que los datos de los OID distintos de los que fallaron aún se devuelvan. Especificar -Cf le indica a snmpdelta que no reintente una solicitud, incluso si hay múltiples OID especificados.
-Ct
La bandera determinará el intervalo de tiempo de la entidad monitorizada.
-Cs
La bandera mostrará una marca de tiempo.
-CS
Genera un "contador de suma" además de los contadores individuales. El "contador de suma" es el total de todas las deltas individuales para cada período de tiempo.
-Cm
Imprime el valor máximo alcanzado alguna vez.
-CF archivo_config
Indica a snmpdelta que lea su configuración del archivo especificado. Esta opción permite que la entrada se configure de antemano en lugar de tener que especificarse en la línea de comandos.
-Cl
Indica a snmpdelta que escriba su configuración en archivos cuyos nombres correspondan a las instancias MIB monitorizadas. Por ejemplo, snmpdelta -Cl localhost ifInOctets.1 creará un archivo "localhost-ifInOctets.1".
-Cp
Especifica el número de segundos entre períodos de sondeo. El sondeo constituye el envío de una solicitud al agente. El período de sondeo por defecto es de un segundo.
-CP picos
Especifica el período de reporte en número de períodos de sondeo. Si se especifica esta opción, snmpdelta sondea al agente picos número de veces antes de reportar los resultados. El resultado reportado incluye el valor promedio durante el período de reporte. Además, se muestra el valor más alto sondeado dentro del período de reporte.
-Ck
Cuando el período de sondeo (-Cp) es un incremento de 60 segundos y la marca de tiempo se muestra en la salida (-Cs), la visualización por defecto muestra la marca de tiempo en el formato hh:mm mm/dd. Esta opción hace que el formato de la marca de tiempo sea hh:mm:ss mm/dd.
-CT
Hace que snmpdelta imprima su salida en forma tabular.
-Cv vars/pkt
Especifica el número máximo de OID permitidos para ser empaquetados en una única PDU. Se pueden crear múltiples PDU en una única solicitud. El valor por defecto de variables por paquete es 60. Esta opción es útil si una respuesta de solicitud resulta en un error porque el paquete es demasiado grande.

Tenga en cuenta que snmpdelta REQUIERE un argumento que especifique el agente a consultar y al menos un argumento OID, como se describe en la página del manual snmpcmd(1).

El siguiente ejemplo utiliza varias opciones. Dado que se especifica la opción Cl, la salida se envía a un archivo y no a la pantalla.

$ snmpdelta -c public -v 1 -Ct -Cs -CS -Cm -Cl -Cp 60 -CP 60
  interlink.sw.net.cmu.edu .1.3.6.1.2.1.2.2.1.16.3 .1.3.6.1.2.1.2.2.1.16.4
