SNDFILE-INTERLEAVE(1) Manual de comandos generales SNDFILE-INTERLEAVE(1)

NOMBRE

sndfile-interleave, sndfile-deinterleave — convertir archivos mono en un archivo multicanal y viceversa

SINOPSIS

sndfile-interleave entrada1 entrada2 ... -o salida

sndfile-deinterleave archivo

DESCRIPCIÓN

sndfile-interleave crea un archivo multicanal tomando datos de audio de dos o más archivos mono como canales individuales. El formato del archivo de salida se determina por el sufijo de su nombre. Los parámetros de audio del archivo de salida se ajustarán para poder albergar cada una de las entradas mono; por ejemplo, la frecuencia de muestreo será la frecuencia máxima de muestreo entre las entradas. El archivo de salida se sobrescribirá si ya existe.

sndfile-deinterleave crea dos o más archivos mono a partir de un archivo de audio multicanal, que contienen los datos de los canales individuales. Los nombres de los archivos mono resultantes tienen el formato "nombre_XY.suf" donde nombre y suf son el nombre base y el sufijo del archivo original. Si algún archivo con ese nombre ya existe, se sobrescribirá. Aparte del número de canales, el formato de audio de los archivos mono resultantes es el mismo que el del archivo original.

ESTADO DE SALIDA

La utilidad sndfile-interleave sale con 0 en caso de éxito y >0 si ocurre un error.

EJEMPLOS

Fusionar un archivo mono OGG y un archivo mono FLAC en un archivo estéreo WAV:

$ sndfile-interleave left.ogg right.flac -o stereo.wav

Separar un archivo multicanal en archivos mono individuales:

$ sndfile-deinterleave multi.wav
Archivo de entrada : multi
Archivos de salida :
    multi_00.wav
    multi_01.wav
    multi_02.wav
    multi_03.wav
