SNAPPER-BACKUP-CONFIGS(5) Gestión de instantáneas del sistema de archivos SNAPPER-BACKUP-CONFIGS(5)

NOMBRE

snapper-backup-configs - Archivos de configuración para las configuraciones de copia de seguridad de snapper

DESCRIPCIÓN

Cada archivo en /etc/snapper/backup-configs/*.json describe una configuración de copia de seguridad de snapper.

El archivo utiliza sintaxis JSON que contiene un único objeto con pares clave-valor.

PARES CLAVE VALOR

La siguiente es una lista de claves que pueden estar presentes en el archivo de configuración.

config

Nombre de la configuración de snapper.

target-mode

Either local or ssh-push.

source-path

Ruta del subvolumen de origen. Esto debe coincidir con el subvolumen de la configuración de snapper correspondiente.

target-path

Ruta del subvolumen o punto de montaje de destino.

automatic

Booleano para habilitar la transferencia y eliminación automática para la configuración de copia de seguridad utilizando un servicio de temporizador systemd.

ssh-host

Nombre del host de destino. Requerido para el modo target ssh-push.

ssh-port

Puerto del host de destino. Opcional para el modo target ssh-push.

ssh-user

Usuario en el host de destino. Opcional para el modo target ssh-push.

ssh-identity

Una identidad ssh para acceder al host sin requerir contraseña o frase de contraseña. Opcional para el modo target ssh-push.

target-btrfs-bin

Ubicación del binario btrfs en el destino. También se puede usar para instalar scripts de envoltura. Opcional.

target-findmnt-bin

Ubicación del binario findmnt en el destino. También se puede usar para instalar scripts de envoltura. Opcional.

target-mkdir-bin

Ubicación del binario mkdir en el destino. También se puede usar para instalar scripts de envoltura. Opcional.

target-realpath-bin

Ubicación del binario realpath en el destino. También se puede usar para instalar scripts de envoltura. Opcional.

target-rm-bin

Ubicación del binario rm en el destino. También se puede usar para instalar scripts de envoltura. Opcional.

target-rmdir-bin

Ubicación del binario rmdir en el destino. También se puede usar para instalar scripts de envoltura. Opcional.

EJEMPLOS

Un ejemplo de configuración de copia de seguridad para copias de seguridad locales:

{
    "config": "root",
    "target-mode": "local",
    "automatic": true,
    "source-path": "/",
    "target-path": "/backups/root"
}

Un ejemplo de configuración de copia de seguridad para copias de seguridad remotas a través de ssh-push:

{
    "config": "root",
    "target-mode": "ssh-push",
    "automatic": false,
    "source-path": "/",
    "target-path": "/backups/eberich/root",
    "ssh-host": "backups.example.com",
    "ssh-identity": "/etc/snapper/certs/id_ecdsa"
}
