snmptop(1)

Paquete: net-snmp

Licencias: BSD

SNMPPS(1) Net-SNMP SNMPPS(1)

NOMBRE

snmpps - muestra la tabla de procesos en una entidad de red a través de SNMP

SINOPSIS

snmpps [OPCIONES COMUNES] [-Cp] [-Ca] [-C n | m | t ] AGENTE

snmptop [OPCIONES COMUNES] [-Cp] [-Ca] [-C n | m | t ] AGENTE

DESCRIPCIÓN

snmpps es una versión en red de un simple comando ps. Verifica los procesos en la máquina remota examinando la tabla hrSWRunTable y la tabla hrSWRunPerfTable del HOST-RESOURCES-MIB.

AGENTE identifica un agente SNMP de destino, que está instrumentado para monitorear los objetos dados. En su forma más simple, la especificación de AGENTE consistirá en un nombre de host o una dirección IPv4. En esta situación, el comando intentará la comunicación con el agente, utilizando UDP/IPv4 al puerto 161 del host de destino dado. Consulte la página del manual de snmpcmd(1) para obtener una lista completa de los formatos posibles para AGENTE.

snmptop emula el comando top utilizando SNMP. Mientras se ejecuta, las entradas de teclado 'c', 'n', 'm', 't' cambian la clasificación entre uso de CPU, pid, memoria o tiempo total de ejecución. Escribir 'i' alterna la ocultación de procesos inactivos, mientras que 'o' alterna la ocultación de procesos de Os. Escribir 'a' alterna la visualización de hrSWRunParameters, 'p' alterna la visualización de hrSWRunPath.

OPCIONES

OPCIONES COMUNES
Por favor, consulte snmpcmd(1) para obtener una lista de los valores posibles para OPCIONES COMUNES, así como sus descripciones.
-Cp
Mostrar hrSWRunPath además de hrSWRunName
-Ca
Mostrar hrSWRunParameters además de hrSWRunName
-Ct
Ordenar la visualización por uso total de CPU
-Cm
Ordenar la visualización por uso de memoria
-Cn
Ordenar la visualización numéricamente por PID
