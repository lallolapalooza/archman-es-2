Paquete: net-snmp

SNMPNETSTAT(1) Net-SNMP SNMPNETSTAT(1)

NOMBRE

snmpnetstat - muestra el estado de la red y la información de configuración de una entidad de red a través de SNMP

SINOPSIS

snmpnetstat [OPCIONES COMUNES] [-Ca] [-Cn] [-Cv] [-Cf familia_direccion] AGENTE
snmpnetstat [OPCIONES COMUNES] [-Cr] [-Cn] [-Cv] [-Cf familia_direccion] AGENTE
snmpnetstat [OPCIONES COMUNES] [-Ci] [-C o | b | d] [-Cn] [-Cv] [-CI interfaz] [-Cw intervalo] AGENTE
snmpnetstat [OPCIONES COMUNES] [-Cs[s]] [-Cp protocolo] AGENTE

DESCRIPCIÓN

El comando snmpnetstat muestra simbólicamente los valores de diversa información relacionada con la red recuperada de un sistema remoto utilizando el protocolo SNMP. Hay una serie de formatos de salida, dependiendo de las opciones para la información presentada. La primera forma del comando muestra una lista de sockets activos. La segunda forma presenta los valores de otra información relacionada con la red según la opción seleccionada. Utilizando la tercera forma, con un intervalo especificado, snmpnetstat mostrará continuamente la información relacionada con el tráfico de paquetes en las interfaces de red configuradas. La cuarta forma muestra estadísticas sobre el protocolo nombrado.

snmpnetstat emitirá solicitudes GETBULK para consultar información si se utiliza al menos la versión de protocolo v2.

AGENTE identifica un agente SNMP objetivo, que está instrumentado para monitorizar los objetos dados. En su forma más simple, la especificación de AGENTE consistirá en un nombre de host o una dirección IPv4. En esta situación, el comando intentará la comunicación con el agente, utilizando UDP/IPv4 al puerto 161 del host objetivo dado. Consulte snmpcmd(1) para obtener una lista completa de los posibles formatos para AGENTE.

OPCIONES

Las opciones tienen el siguiente significado:

OPCIONES COMUNES
Consulte snmpcmd(1) para obtener una lista de valores posibles para las opciones comunes, así como sus descripciones.

-CL utiliza los elementos MIB SNMP heredados, no las tablas modernas independientes de la versión IP. snmpnetstat retrocederá automáticamente a las tablas heredadas si las modernas no están disponibles.

-Ca Con la visualización predeterminada, muestra el estado de todos los sockets; normalmente no se muestran los sockets utilizados por procesos de servidor.

-Cf familia_direccion Muestra solo las entradas para la familia de direcciones seleccionada (inet, inet6)

-Ci Muestra el estado de todas las interfaces de red. La visualización de interfaces proporciona una tabla de estadísticas acumuladas relacionadas con los paquetes transferidos, errores y colisiones. También se muestran las direcciones de red de la interfaz y la unidad de transmisión máxima (``mtu'').

-Cd Añade paquetes descartados a la visualización de interfaces.

-Cb Muestra un estado de interfaz extendido, proporcionando octetos además de paquetes.

-Co Muestra un estado de interfaz abreviado, proporcionando octetos en lugar de paquetes. Esto es útil al consultar interfaces virtuales (como circuitos Frame-Relay) en un enrutador.

-CI interfaz Muestra información solo sobre esta interfaz; se usa con un intervalo como se describe a continuación.

-Cn Muestra las direcciones de red como números (normalmente snmpnetstat interpreta las direcciones e intenta mostrarlas simbólicamente). Esta opción se puede usar con cualquiera de los formatos de visualización.

-Cv Permite que los nombres de host o servicio largos rompan la salida columnar. Esta opción se puede usar con cualquiera de los formatos de visualización.

-Cp protocolo Muestra estadísticas sobre el protocolo, que es un nombre conocido para un protocolo o un alias para él. Algunos nombres de protocolo y alias se enumeran en el archivo /etc/protocols. Una respuesta nula generalmente significa que no hay números interesantes que informar. El programa se quejará si el protocolo es desconocido o si no hay una rutina de estadísticas para él.

-Cs Muestra estadísticas por protocolo. Si se duplica (-Css) se suprimirán las entradas de estadísticas que sean cero.

-Cr Muestra las tablas de enrutamiento.

-CR repetidores Para las solicitudes GETBULK, repetidores especifica el valor max-repeaters a usar.

Cuando snmpnetstat se invoca con un argumento de intervalo, muestra un recuento continuo de estadísticas relacionadas con las interfaces de red. intervalo son los segundos entre la notificación de estadísticas.

La visualización de Sockets Activos (predeterminada)

La visualización predeterminada, para sockets activos, muestra las direcciones locales y remotas, el protocolo y el estado interno del protocolo. Los formatos de dirección son de la forma ``host.puerto'' o ``red.puerto'' si la dirección de un socket especifica una red pero no una dirección de host específica. Cuando se conocen, las direcciones de host y red se muestran simbólicamente de acuerdo con las bases de datos /etc/hosts y /etc/networks, respectivamente. Si se desconoce un nombre simbólico para una dirección, o si se especifica la opción -Cn, la dirección se imprime numéricamente, de acuerdo con la familia de direcciones. Para más información sobre el formato ``punto'' de Internet, consulte inet(3N). Las direcciones y puertos no especificados, o ``comodín'', aparecen como ``*''.

La visualización de Interfaces

La visualización de interfaces proporciona una tabla de estadísticas acumuladas relacionadas con los paquetes transferidos, errores y colisiones. También se muestran las direcciones de red de la interfaz y la unidad de transmisión máxima (``mtu'').

La visualización de la Tabla de Enrutamiento

La visualización de la tabla de enrutamiento indica las rutas disponibles y su estado. Cada ruta consta de un host o red de destino y una puerta de enlace a utilizar para reenviar paquetes. El campo de banderas muestra el estado de la ruta (``U'' si ``arriba''), si la ruta es a una puerta de enlace (``G''), si la ruta se creó dinámicamente mediante una redirección (``D'') y si la ruta ha sido modificada por una redirección (``M''). Las rutas directas se crean para cada interfaz conectada al host local; el campo de puerta de enlace para tales entradas muestra la dirección de la interfaz de salida. La entrada de interfaz indica la interfaz de red utilizada para la ruta.

La visualización de Interfaces con un Intervalo

Cuando se invoca snmpnetstat con un argumento de intervalo, muestra un recuento continuo de estadísticas relacionadas con las interfaces de red. Esta visualización consta de una columna para la interfaz principal y una columna que resume la información para todas las interfaces. La interfaz principal puede ser reemplazada por otra interfaz con la opción -CI. La primera línea de cada pantalla de información contiene un resumen desde que el sistema fue reiniciado por última vez. Las líneas de salida subsiguientes muestran los valores acumulados durante el intervalo anterior.

La visualización de Sockets Activos para un Solo Protocolo

Cuando se especifica un protocolo con la opción -Cp, la información mostrada es similar a la de la visualización predeterminada de sockets activos, excepto que la visualización se limita al protocolo dado.
