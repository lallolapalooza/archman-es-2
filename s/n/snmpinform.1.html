snmpinform(1)

Paquete: net-snmp

Licencias: BSD

SNMPTRAP(1) Net-SNMP SNMPTRAP(1)

NOMBRE

snmptrap, snmpinform - envía una notificación SNMP a un gestor

SINOPSIS

snmptrap -v 1 [OPCIONES COMUNES] AGENTE oid-empresa dirección-agente trampa-genérica trampa-específica tiempo-de-actividad [OID TIPO VALOR]...

snmptrap -v [2c|3] [OPCIONES COMUNES] [-Ci] AGENTE tiempo-de-actividad oid-trampa [OID TIPO VALOR]...

snmpinform -v [2c|3] [OPCIONES COMUNES] AGENTE tiempo-de-actividad oid-trampa [OID TIPO VALOR]...

DESCRIPCIÓN

snmptrap es una aplicación SNMP que utiliza la operación TRAP SNMP para enviar información a un gestor de red. Se puede proporcionar uno o más identificadores de objeto (OID) como argumentos en la línea de comandos. Un tipo y un valor deben acompañar a cada identificador de objeto. Cada nombre de variable se proporciona en el formato especificado en variables(5).

Cuando se invoca como snmpinform, o cuando se añade -Ci a las opciones de línea de comandos de snmptrap, envía un INFORM-PDU, esperando una respuesta del receptor de trampas, retransmitiendo si es necesario. De lo contrario, envía un TRAP-PDU o TRAP2-PDU.

Si alguno de los parámetros requeridos de la versión 1, oid-empresa, dirección-agente y tiempo-de-actividad se especifica como vacío, toma por defecto 1.3.6.1.4.1.3.1.1 (enterprises.cmu.1.1), hostname y host-uptime respectivamente.

El TIPO es un solo carácter, uno de:

i
INTEGER
u
UNSIGNED
c
COUNTER32
s
STRING
x
HEX STRING
d
DECIMAL STRING
n
NULLOBJ
o
OBJID
t
TIMETICKS
a
IPADDRESS
b
BITS
que se manejan de la misma manera que el comando snmpset.

El argumento AGENTE solo se incrusta en los PDUs TRAP SNMP, pero no en los PDUs INFORM SNMP. Si AGENTE no es una cadena vacía, debe ser una dirección IPv4. Esta limitación proviene de RFC 1157, en la que el campo de dirección del agente se define como sigue:

agent-addr NetworkAddress, -- dirección del objeto que genera la trampa

De RFC 1155:

NetworkAddress ::=
CHOICE {
internet IpAddress
}
[ ... ]
IpAddress ::=
[APPLICATION 0] -- en orden de bytes de red
IMPLICIT OCTET STRING (SIZE (4))

Un ejemplo de cómo usar snmptrap:

snmptrap -v 1 -c public gestor enterprises.spider hub-prueba 3 0 '' interfaces.iftable.ifentry.ifindex.1 i 1

enviará una trampa genérica linkUp al gestor, para la interfaz 1.

OPCIONES

snmptrap toma las opciones comunes descritas en la página del manual snmpcmd(1) además de la opción -Ci descrita anteriormente. Tenga en cuenta que snmptrap REQUIERE un argumento que especifique el agente a consultar, como se describe allí.

VER TAMBIÉN

snmpcmd(1), snmpset(1), variables(5).
