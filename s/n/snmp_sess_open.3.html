snmp_sess_open(3)

Paquete: net-snmp

Licencias: BSD

DESCRIPCIÓN

Estas funciones definen un subconjunto de la API que puede utilizarse para gestionar sesiones SNMP individuales en una aplicación multihilo. Excepto snmp_sess_session(), estas funciones son versiones de sesión única de la API tradicional de la biblioteca SNMP.

Tenga en cuenta que estas funciones utilizan un puntero opaco (handle en los prototipos anteriores) para identificar una sesión individual en lugar de un puntero session (como en la API tradicional).

snmp_sess_init() prepara una estructura snmp_session que contiene las características de transporte e información común que se utilizará para un conjunto de transacciones SNMP. Después de que esta estructura se pasa a snmp_sess_open() para crear una sesión SNMP, la estructura ya no se utiliza. En su lugar, el puntero opaco devuelto por snmp_sess_open() se utiliza para referirse a esa sesión a partir de entonces.

Las sesiones SNMP que se crean con snmp_sess_open() no se ven afectadas por, y NO DEBEN UTILIZARSE CON, snmp_select_info(), snmp_read(), snmp_timeout() ni snmp_close(). En su lugar, deben utilizarse las funciones equivalentes de sesión única aquí descritas.

snmp_sess_init() y snmp_sess_open() toman cada una como entrada un puntero a un objeto struct snmp_session. Esta estructura contiene información para un conjunto de transacciones que compartirán características de transporte similares. snmp_sess_session() toma el manejador de sesión opaco y devuelve un puntero a su struct snmp_session asociado.

snmp_sess_send() y snmp_sess_async_send() toman cada una un parámetro pdu, que apunta a un objeto struct snmp_pdu que contiene información que describe una transacción que se realizará sobre una sesión abierta.

Consulte snmp_api.h para las definiciones de estas estructuras.

Con la llamada a snmp_sess_async_send(), snmp_sess_read invocará la función de devolución de llamada especificada cuando se reciba la respuesta.

snmp_sess_select_info(), snmp_sess_read() y snmp_sess_timeout() proporcionan una interfaz para el uso de la llamada al sistema select(2) para que las transacciones SNMP de una sola sesión puedan ocurrir de forma asíncrona.

A snmp_sess_select_info() se le pasa la información que se habría pasado a select(2) en ausencia de SNMP. Por ejemplo, esto podría incluir descriptores de archivo asociados con el bucle principal de una aplicación gráfica. Esta información se modifica para que SNMP obtenga el servicio que requiere de la llamada a select(2). En este caso, numfds, fdset y timeout corresponden a los argumentos nfds, readfds y timeout de select(2) respectivamente. La única excepción es que timeout debe apuntar SIEMPRE a una struct timeval asignada (pero quizás no inicializada) (no puede ser NULL como para select(2)). Si timeout se hubiera pasado como NULL, block se establece en true y timeout se trata como indefinido. La misma regla se aplica al regresar de snmp_select_info().

Después de llamar a snmp_sess_select_info(), se debe llamar a select(2) con los datos devueltos. Cuando regrese, se debe llamar a snmp_sess_read() con el fd_set devuelto por select(2). Esto leerá cualquier entrada del socket SNMP de esta sesión. Si select(2) excede el tiempo de espera (es decir, devuelve cero), se debe llamar a snmp_sess_timeout() para ver si ha ocurrido un tiempo de espera en la sesión SNMP.

snmp_sess_synch_response es una rutina de conveniencia que enviará la solicitud, esperará la respuesta y la procesará antes de regresar. Consulte las descripciones de snmp_sess_send , snmp_sess_read etc para obtener más detalles.

DIAGNÓSTICOS

El estado de retorno de error de snmp_sess_open() se indica con la devolución de un puntero NULL. El estado de retorno de error de snmp_sess_close() y snmp_sess_send() se indica con un valor de retorno de 0. Un estado exitoso devolverá 1.

Se puede obtener más información utilizando snmp_sess_error() para ver qué tipo de error ha ocurrido. Esta función devuelve la variable snmp_errno de SNMP, el valor de la variable errno del sistema y una interpretación en cadena de ambas variables. La cadena debe ser liberada después de su uso por el llamador.

Para los errores devueltos por snmp_sess_open(), utilice la función correspondiente snmp_error() en lugar de snmp_sess_error().

Consulte snmp_api.h para el conjunto completo de valores de error de la biblioteca SNMP. El valor de error de la biblioteca SNMP snmperr puede ser uno de los siguientes valores:

SNMPERR_GENERR
Ocurrió un error genérico.
SNMPERR_BAD_LOCPORT
El puerto local era incorrecto porque ya se había asignado o se denegó el permiso.
SNMPERR_BAD_ADDRESS
El nombre de host o la dirección proporcionados no eran utilizables.
SNMPERR_BAD_SESSION
La sesión especificada no estaba abierta.
SNMPERR_TOO_LONG

DESCRIPTION

This section is not yet written. The goal is to provide a comprehensive description of the functions listed in the SYNOPSIS.

The net-snmp library provides a high-level API for interacting with SNMP agents and managers. The functions described here deal with the management of SNMP sessions.

A struct snmp_session represents an SNMP session. It contains configuration information such as the remote host, community string, SNMP version, etc. The session structure is initialized and passed to various functions to establish, use, and close the session.

snmp_sess_open() establishes a new SNMP session based on the parameters in the provided snmp_session structure. It returns a pointer to the session structure if successful, or NULL otherwise.

snmp_sess_session() returns a pointer to the session structure associated with the given session.

snmp_sess_close() closes an existing SNMP session and frees any associated resources.

snmp_sess_error() retrieves the error code and an error message string for the last operation performed on the session.

snmp_sess_send() sends an SNMP PDU (Protocol Data Unit) to the remote agent.

snmp_sess_next() is used for walking an MIB tree. It sends a GETNEXT request and returns the next variable binding.

snmp_sess_get_next() is similar to snmp_sess_next() but returns a pointer to the SNMP PDU containing the next variable binding.

snmp_sess_read() reads incoming SNMP messages from the network. It typically blocks until a message is received or a timeout occurs.

snmp_sess_write() writes an SNMP PDU to the network. This function is used for operations like SET requests.

snmp_sess_trap() sends an SNMP TRAP message.

snmp_sess_realchain() returns a pointer to the actual session structure used by the library, which may differ from the user-provided structure in some cases (e.g., when using callbacks).

The functions return specific values or set error codes/messages to indicate success or failure. Refer to the individual function documentation for detailed error conditions.
