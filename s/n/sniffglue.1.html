sniffglue(1) Manual de Comandos Generales sniffglue(1)

NOMBRE

sniffglue - espía de paquetes multihilo seguro

SINOPSIS

sniffglue [-vrpVh] [-n <hilos>] dispositivo

DESCRIPCIÓN

sniffglue es un espía de red escrito en rust. Los paquetes de red se analizan de forma concurrente utilizando un grupo de hilos para aprovechar todos los núcleos de la CPU. Los objetivos del proyecto son que puedas ejecutar sniffglue de forma segura en redes no confiables y que no se bloquee al procesar paquetes. La salida debe ser lo más útil posible por defecto.

OPCIONES

-v, --verbose

Aumenta la sensibilidad del filtro para mostrar más paquetes (posiblemente menos útiles). El valor predeterminado solo muestra pocos paquetes, esta bandera se puede especificar varias veces. (máximo: 4)

-h, --help

Imprime información de ayuda.

-p, --promisc

Establece dispositivo en modo promiscuo.

-r, --read

Abre dispositivo como un archivo pcap.

-n, --threads hilos

Especifica el número de hilos.

-V, --version

Imprime información de la versión. Si se especificó -r, abre como un archivo pcap en su lugar.

EJEMPLOS

Espiar con filtros predeterminados (dhcp, dns, tls, http) desde enp0s25:

sniffglue enp0s25

Aumentar la sensibilidad del filtro (arp):

sniffglue -v enp0s25

Aumentar la sensibilidad del filtro (cjdns, ssdp, dropbox, paquetes con utf8 válido)

sniffglue -vv enp0s25

Casi todo

sniffglue -vvv enp0s25

Todo

sniffglue -vvvv enp0s25

Leer un volcado de sniff.pcap, con mayor sensibilidad de filtro y decodificar paquetes con 1 hilo:

sniffglue -vvrn1 sniff.pcap

PROTOCOLOS

ethernet, ipv4, ipv6, arp, tcp, udp, http, tls, dns, dhcp, balizas cjdns eth, ssdp, balizas dropbox

SEGURIDAD

Para informar sobre un problema de seguridad, póngase en contacto con kpcyrd en ircs://irc.hackint.org.

SECCOMP

Para garantizar que un proceso comprometido no comprometa el sistema, sniffglue utiliza seccomp para restringir las llamadas al sistema que se pueden usar después de que el proceso haya comenzado. Esto se hace en dos etapas, primero al principio (directamente después de que se inicialice env_logger) y una vez después de que se configure el espía, pero antes de que se lean los paquetes de la red.

ENDURECIMIENTO

Durante la segunda etapa, también se aplica un endurecimiento general antes de que se deshabiliten finalmente todas las llamadas al sistema innecesarias. Estas son específicas del sistema, por lo que se lee un archivo de configuración de /etc/sniffglue.conf. Este archivo de configuración especifica un directorio vacío para chroot y una cuenta sin privilegios en user que se utiliza para eliminar los privilegios de root.

FUZZING

El procesamiento de paquetes de sniffglue se puede probar con cargo-fuzz. Todo lo que necesites se proporciona en el directorio fuzz/ que se distribuye junto con su código fuente. Ten en cuenta que este programa se vincula a libpcap, que no está incluido en la configuración actual de fuzzing.

VER TAMBIÉN

pcap(3PCAP), seccomp(2)
