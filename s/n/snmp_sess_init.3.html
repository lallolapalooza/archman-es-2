NOMBRE

snmp_sess_init, snmp_sess_open, snmp_sess_session, snmp_sess_send, snmp_sess_async_send, snmp_sess_select_info, snmp_sess_read, snmp_sess_timeout, snmp_sess_synch_response, snmp_sess_close, snmp_sess_error - funciones de sesión

SINOPSIS

#include <net-snmp/session_api.h>

void snmp_sess_init(struct snmp_session *session);

void *snmp_sess_open(struct snmp_session *session);

struct snmp_session *snmp_sess_session(void *handle);

int snmp_sess_send(void *handle, struct snmp_pdu *pdu);

int snmp_sess_async_send(void *handle,
struct snmp_pdu *pdu,
snmp_callback callback,
void *callbackData);

int snmp_sess_select_info(void *handle,
int *numfds, fd_set *fdset,
struct timeval *timeout,
int *block);

int snmp_sess_read(void *handle, fd_set *fdset);

void snmp_sess_timeout(void *handle);

int snmp_sess_synch_response ( void *handle,

netsnmp_pdu *pdu,
netsnmp_pdu **response);

int snmp_sess_close(void *handle);

void snmp_sess_error(void *handle, int *pcliberr,
int *psnmperr, char **pperrstring);

DESCRIPCIÓN

Estas funciones definen un subconjunto de la API que se puede utilizar para gestionar sesiones SNMP individuales en una aplicación multihilo. Excepto por snmp_sess_session(), estas funciones son versiones de sesión única de la API tradicional de la biblioteca SNMP.

Tenga en cuenta que estas funciones utilizan un puntero opaco (handle en los prototipos anteriores) para identificar una sesión individual en lugar de un puntero session (como en la API tradicional).

snmp_sess_init() prepara una estructura snmp_session que contiene las características del transporte y la información común que se utilizará para un conjunto de transacciones SNMP. Después de que esta estructura se pasa a snmp_sess_open() para crear una sesión SNMP, la estructura ya no se utiliza. En su lugar, se utiliza el puntero opaco devuelto por snmp_sess_open() para referirse a esa sesión en adelante.

Las sesiones SNMP que se crean con snmp_sess_open() no se ven afectadas por, y NO DEBEN SER UTILIZADAS CON, snmp_select_info(), snmp_read(), snmp_timeout() ni snmp_close(). En su lugar, se deben utilizar las funciones equivalentes de sesión única descritas aquí.

snmp_sess_init() y snmp_sess_open() toman como entrada un puntero a un objeto de estructura snmp_session. Esta estructura contiene información para un conjunto de transacciones que compartirán características de transporte similares. snmp_sess_session() toma el identificador de sesión opaco y devuelve un puntero a su estructura snmp_session asociada.

snmp_sess_send() y snmp_sess_async_send() toman cada una un parámetro pdu, que apunta a un objeto de estructura snmp_pdu que contiene información que describe una transacción que se realizará a través de una sesión abierta.

Consulte snmp_api.h para conocer las definiciones de estas estructuras.

Con la llamada snmp_sess_async_send(), snmp_sess_read invocará la función de devolución de llamada especificada cuando se reciba la respuesta.

snmp_sess_select_info(), snmp_sess_read() y snmp_sess_timeout() proporcionan una interfaz para el uso de la llamada al sistema select(2) para que las transacciones SNMP de una sesión individual puedan ocurrir de forma asíncrona.

A snmp_sess_select_info() se le pasa la información que se habría pasado a select(2) en ausencia de SNMP. Por ejemplo, esto podría incluir descriptores de archivo asociados con el bucle principal de una aplicación gráfica. Esta información se modifica para que SNMP obtenga el servicio que requiere de la llamada a select(2). En este caso, numfds, fdset y timeout corresponden a los argumentos nfds, readfds y timeout de select(2), respectivamente. La única excepción es que timeout SIEMPRE debe apuntar a una estructura struct timeval asignada (pero quizás no inicializada) (no puede ser NULL como para select(2)). Si timeout se hubiera pasado como NULL, block se establecerá en verdadero y timeout se tratará como indefinido. Esta misma regla se aplica al regresar de snmp_select_info().

Después de llamar a snmp_sess_select_info(), se debe llamar a select(2) con los datos devueltos. Cuando regrese, snmp_sess_read() debe ser llamada con el fd_set devuelto por select(2). Esto leerá cualquier entrada del socket SNMP de esta sesión. Si select(2) agota el tiempo de espera (es decir, devuelve cero), se debe llamar a snmp_sess_timeout() para ver si ha ocurrido un tiempo de espera en la sesión SNMP.

snmp_sess_synch_response es una rutina de conveniencia que enviará la solicitud, esperará la respuesta y la procesará antes de regresar. Consulte las descripciones de snmp_sess_send , snmp_sess_read etc para obtener más detalles.

DIAGNÓSTICO

El estado de retorno de error de snmp_sess_open() se indica mediante la devolución de un puntero NULL. El estado de retorno de error de snmp_sess_close() y snmp_sess_send() se indica mediante un valor de retorno de 0. Un estado exitoso devolverá 1.

Se puede obtener más información utilizando snmp_sess_error() para ver qué tipo de error ha ocurrido. Esta función devuelve la variable SNMP snmp_errno, el valor de la variable errno del sistema y una interpretación en cadena de ambas variables. La cadena debe ser liberada después de su uso por el llamador.

Para los errores devueltos por snmp_sess_open(), utilice la función correspondiente snmp_error() en lugar de snmp_sess_error().

Consulte snmp_api.h para obtener el conjunto completo de valores de error de la biblioteca SNMP. El valor de error de la biblioteca SNMP snmperr puede ser uno de los siguientes valores:

SNMPERR_GENERR
Ocurrió un error genérico.
SNMPERR_BAD_LOCPORT
El puerto local estaba mal porque ya había sido asignado o se denegó el permiso.
SNMPERR_BAD_ADDRESS
El nombre o la dirección del host proporcionado no era utilizable.
SNMPERR_BAD_SESSION
La sesión especificada no estaba abierta.
SNMPERR_TOO_LONG
SNMPERR_NO_SOCKET

NAME

snmp_sess_init, snmp_sess_session, snmp_sess_error, snmp_sess_close — initialize and manage an SNMP session

SYNOPSIS

#include <net-snmp/net-snmp-includes.h>

void
snmp_sess_init(
    struct snmp_session *session
);

struct snmp_session *
snmp_sess_session(
    void *sessp
);

int
snmp_sess_error(
    void *sessp,
    char *error_msg,
    size_t *error_msg_len
);

void
snmp_sess_close(
    void *sessp
);

DESCRIPTION

The Net-SNMP library provides a set of functions for managing SNMP sessions. These functions allow applications to initialize, retrieve, query for errors, and close SNMP sessions.

snmp_sess_init initializes a snmp_session structure pointed to by session. This structure should be filled with the desired SNMP session parameters (e.g., agent address, community string, SNMP version) before calling this function.

snmp_sess_session takes a pointer to a session pointer (sessp) and returns a pointer to the underlying snmp_session structure. This can be useful for accessing session-specific information not directly exposed by the session management functions.

snmp_sess_error retrieves the last error message associated with the SNMP session pointed to by sessp. The error message is copied into the buffer pointed to by error_msg, with a maximum length specified by error_msg_len. The error_msg_len will be updated to reflect the actual length of the copied message. It returns 0 on success and -1 on failure.

snmp_sess_close closes the SNMP session pointed to by sessp and frees any associated resources. It is important to call this function when an SNMP session is no longer needed to prevent resource leaks.

DIAGNOSTICS

The following error codes may be returned by functions related to SNMP session management:

SNMPERR_UNKNOWN_PDU
SNMPERR_TIMEOUT
