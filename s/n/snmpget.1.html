Paquete: net-snmp

Licencias: BSD

SNMPGET(1) Net-SNMP SNMPGET(1)

NOMBRE

snmpget - se comunica con una entidad de red utilizando solicitudes GET SNMP

SINOPSIS

snmpget [OPCIONES COMUNES] [-Cf] AGENTE OID [OID]...

DESCRIPCIÓN

snmpget es una aplicación SNMP que utiliza la solicitud GET SNMP para consultar información sobre una entidad de red. Se pueden proporcionar uno o más identificadores de objeto (OID) como argumentos en la línea de comandos. Cada nombre de variable se proporciona en el formato especificado en variables(5).

OPCIONES

-Cf
Si -Cf no se especifica, algunas aplicaciones (snmpdelta, snmpget, snmpgetnext y snmpstatus) intentarán corregir errores devueltos por el agente con el que se estaba comunicando y reenviarán la solicitud. La única vez que esto es realmente útil es si especificaste un OID que no existía en tu solicitud y estás usando SNMPv1, que requiere solicitudes de tipo "todo o nada".

Además de esta opción, snmpget toma las opciones comunes descritas en la página del manual snmpcmd(1). Ten en cuenta que snmpget REQUIERE un argumento que especifique el agente a consultar y al menos un argumento OID, como se describe allí.

EJEMPLOS

El comando:


snmpget -c public zeus system.sysDescr.0

recuperará la variable system.sysDescr.0 del host zeus utilizando la cadena de comunidad public:


system.sysDescr.0 = "SunOS zeus.net.cmu.edu 4.1.3_U1 1 sun4m"

Si la entidad de red tiene un error al procesar el paquete de solicitud, se devolverá un paquete de error y se mostrará un mensaje, lo que ayudará a precisar en qué sentido se malformó la solicitud. Si había otras variables en la solicitud, la solicitud se reenviará sin la variable incorrecta.

Aquí hay otro ejemplo. Las opciones -c y -v se definen en la página del manual snmpcmd(1). (Ten en cuenta que system.sysUpTime es un OID incompleto, ya que necesita el índice .0 añadido):

    snmpget -v1 -Cf -c public localhost system.sysUpTime system.sysContact.0

Este ejemplo devolverá lo siguiente:

    Error in packet
    Reason: (noSuchName) There is no such variable name in this MIB.
    This name doesn't exist: system.sysUpTime

De manera similar, el comando:

    snmpget -v1 -c public localhost system.sysUpTime system.sysContact.0

Devolverá:

    Error in packet
    Reason: (noSuchName) There is no such variable name in this MIB.
    This name doesn't exist: system.sysUpTime
    system.sysContact.0 = STRING: root@localhost

Con la bandera -Cf especificada, la aplicación no intentará corregir el PDU por ti.

VER TAMBIÉN

snmpcmd(1), snmpwalk(1), variables(5).
