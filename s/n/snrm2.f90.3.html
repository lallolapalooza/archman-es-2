Documentación de Función/Subrutina

real(wp) función snrm2 (integer n, real(wp), dimension(*) x, integer incx)

SNRM2

Propósito:

!>
!> SNRM2 devuelve la norma euclidiana de un vector a través del nombre
!> de la función, de modo que
!>
!>    SNRM2 := sqrt( x'*x ).
!>

Parámetros

N 
!>          N es INTEGER
!>         número de elementos en el(los) vector(es) de entrada
!>

X

!>          X es un array REAL, de dimensión ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX es INTEGER, espaciado de almacenamiento entre elementos de X
!>          Si INCX > 0, X(1+(i-1)*INCX) = x(i) para 1 <= i <= n
!>          Si INCX < 0, X(1-(n-i)*INCX) = x(i) para 1 <= i <= n
!>          Si INCX = 0, x no es un vector, por lo que no hay necesidad de llamar
!>          a esta subrutina. Si la llama de todos modos, contará x(1)
!>          en la norma del vector N veces.
!>
