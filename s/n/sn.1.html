NOMBRE

sn - Firma/verifica/compara digitalmente strongnames en ensamblajes CLR.

SINOPSIS

sn [-q | -quiet] [opciones] [parámetros]

DESCRIPCIÓN

Firma, verifica o compara digitalmente ensamblajes CLR usando strongnames.

Puede usar el comando sn para crear "archivos snk" usando la opción -k descrita a continuación.

OPCIONES DE CONFIGURACIÓN

Las opciones de configuración se almacenan en el archivo de configuración machine.config bajo /configuration/strongNames.

-c proveedor
Cambia el CSP (Proveedor de Servicios de Criptografía) predeterminado. Actualmente no soportado en Mono.
-m [s|n]
Usa un contenedor de claves de máquina [s] o un contenedor de claves de usuario [n]. Actualmente no soportado en Mono.
-Vl
Lista las opciones de verificación. La lista se mantiene en /configuration/ strongNames/verificationSettings en machine.config.
-Vr ensamblado [lista_usuarios]
Excluye el ensamblado especificado de la verificación para la lista de usuarios especificada. Actualmente no soportado por sn. Debe editar machine.config manualmente si requiere esto.
-Vu ensamblado
Elimina la entrada de exclusión para el ensamblado especificado. Actualmente no soportado por sn, debe editar machine.config manualmente si requiere esto.
-Vx
Elimina todas las entradas de exclusión. Actualmente no soportado por sn, debe editar machine.config manualmente si requiere esto.

OPCIONES RELACIONADAS CON CSP

-d contenedor
Elimina el par de claves presente en el contenedor de claves especificado.
-i par_claves.snk contenedor
Importa el archivo strongname especificado al contenedor especificado.
-pc contenedor clave_publica
Exporta la clave pública del contenedor CSP especificado al archivo especificado.

OPCIONES DE CONVERSIÓN

-e ensamblado salida.pub
Exporta la clave pública del ensamblado al archivo de salida especificado.
-p par_claves.snk salida.pub
Exporta la clave pública desde el archivo de clave strongname especificado (SNK) o desde un archivo protegido con contraseña PKCS#12/PFX al archivo de salida especificado.
-o entrada salida.txt
Convierte el archivo de entrada a un archivo CSV (usando decimal).
-oh entrada salida.txt
Convierte el archivo de entrada a un archivo CSV (usando hexadecimal).

OPCIONES DE FIRMA STRONGNAME

-D ensamblado1 ensamblado2
Compara si ensamblado1 y ensamblado2 son iguales excepto por su firma. Esto se hace comparando el hash de los metadatos de ambos ensamblados.
-k [tamaño] par_claves.snk
Crea un nuevo par de claves strongname en el archivo especificado. La longitud de clave predeterminada es de 1024 bits y DEBE USARSE SIEMPRE al firmar ensamblados 1.x. Cualquier valor de 384 a 16384 bits (en incrementos de 8 bits) es una longitud de clave válida para firmar ensamblados 2.x. Para garantizar la máxima compatibilidad, es posible que desee seguir utilizando claves de 1024 bits. Tenga en cuenta que no hay una buena razón, incluso si es posible, para usar una longitud inferior a 1024 bits.
-R ensamblado par_claves.snk
Vuelve a firmar el ensamblado especificado usando el archivo de par de claves strongname especificado (SNK) o un archivo protegido con contraseña PKCS#12/PFX. Solo puede firmar un ensamblado con la clave privada que coincide con la clave pública dentro del ensamblado (a menos que su token de clave pública se haya reasignado en machine.config).
-Rc ensamblado contenedor
Vuelve a firmar el ensamblado especificado usando el contenedor strongname especificado.
-t archivo
Muestra el token de clave pública del archivo especificado.
-tp archivo
Muestra la clave pública y el token de clave pública del archivo especificado.
-T ensamblado
Muestra el token de clave pública del ensamblado especificado.
-Tp ensamblado
Muestra la clave pública y el token de clave pública del ensamblado especificado.
-v ensamblado
Verifica la firma del ensamblado especificado.
-vf ensamblado
Verifica la firma del ensamblado especificado (incluso si está deshabilitada).

OPCIONES DE AYUDA

-h , -?
Muestra ayuda básica sobre esta herramienta.
-h config , -? config
Muestra ayuda relacionada con la configuración de esta herramienta.
-h csp , -? csp
Muestra ayuda relacionada con el Proveedor de Servicios de Criptografía de esta herramienta.
-h convert , -? convert
Muestra ayuda relacionada con la conversión de esta herramienta.
-h sn , -? sn
Muestra ayuda relacionada con strongname de esta herramienta.

ARCHIVO DE CONFIGURACIÓN

La configuración de Strongnames se mantiene en el archivo "machine.config". Actualmente se pueden configurar dos
características.
/configuration/strongNames/pubTokenMapping
Este mecanismo permite a Mono reasignar un token de clave pública, como el token ECMA, a otra clave pública para la verificación. Esto es útil en dos escenarios. Primero, los ensamblados firmados con la "clave ECMA" necesitan ser verificados por la clave del "runtime" (ya que la clave ECMA no es una clave pública). Segundo, muchos ensamblados están firmados con claves privadas que Mono no puede usar (por ejemplo, el ensamblado System.Security.dll). No se puede usar una clave nueva porque cambiaría el strongname (un nuevo par de claves tendría una nueva clave pública que produciría un nuevo token). La reasignación de tokens de clave pública es la solución para ambos problemas. Cada token debe configurarse en una entrada "map" similar a esta: <map Token="b77a5c561934e089" PublicKey="00..." />
/configuration/strongNames/verificationSettings
A menudo es útil durante el desarrollo utilizar ensamblados firmados retrasadamente (delay signed). Normalmente* el runtime no permitiría que los ensamblados firmados retrasadamente se cargaran. Esta característica permite que algunos ensamblados firmados retrasadamente (basados en su token de clave pública, opcionalmente nombre del ensamblado y nombre de usuario) se utilicen como si fueran ensamblados firmados completamente. [*] Tenga en cuenta que el "runtime" de Mono 1.0 no valida firmas strongname, por lo que esta opción no debería ser necesaria en la mayoría de los escenarios.
