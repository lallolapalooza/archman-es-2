Añadir algo al alcance (scope)

Probablemente querrá separar sus investigaciones, así que debería seleccionar un espacio de trabajo donde irán sus resultados:

[sn0int][default] > workspace demo
[+] Conectando a la base de datos
[sn0int][demo] >

A continuación, tenemos que empezar por algún sitio y añadir la primera entidad a nuestro alcance:

[sn0int][demo] > add domain
Domain: example.com
[sn0int][demo] >

NOTA:

Existe un concepto de dominio frente a subdominio. Nos referimos a un dominio como todo lo que es un subdominio de un sufijo público. Por ejemplo, .com es un sufijo público, lo que hace que example.com sea un dominio en términos de sn0int. Cualquier subdominio de este, como www.example.com, se denomina subdominio.

Tenga en cuenta que example.com también se puede añadir como subdominio ya que puede contener registros. En ese caso, example.com es tanto el nombre de la zona dns como una entidad dentro de esa zona.

Puede confirmarlo ejecutando una selección de los dominios que tenemos ahora:

[sn0int][demo] > select domains
#1, "example.com"
[sn0int][demo] >

Algo que no necesitamos ahora, pero que será útil más adelante, es la capacidad de filtrar sus entidades:

[sn0int][demo] > select domains where id=1
#1, "example.com"
[sn0int][demo] >
[sn0int][demo] > select domains where value like %.com
#1, "example.com"
[sn0int][demo] >
[sn0int][demo] > select domains where ( value like e% and value like %m ) or false
#1, "example.com"
[sn0int][demo] >

NOTA:

Casi todas las entidades tienen una columna value que contiene el valor principal de la entidad.

Desvinculación de entidades

Algo con lo que se encontrará es que los módulos son demasiado voraces y añaden cosas al ámbito que no nos interesan. Puede eliminarlas usando el comando delete, pero es probable que vuelvan a ser capturadas por un módulo.

Lo que puede hacer en su lugar es establecer un indicador en una entidad que la elimine de nuestro ámbito. Esto se hace usando el comando noscope:

[sn0int][demo] > use ctlogs
[sn0int][demo][kpcyrd/ctlogs] > target
#1, "example.com"
[sn0int][demo][kpcyrd/ctlogs] > add domain
Domain: google.com
[sn0int][demo][kpcyrd/ctlogs] > target
#1, "example.com"
#2, "google.com"
[sn0int][demo][kpcyrd/ctlogs] > noscope domains where value=google.com
[+] Updated 1 rows
[sn0int][demo][kpcyrd/ctlogs] > target
#1, "example.com"
[sn0int][demo][kpcyrd/ctlogs] >

Las entidades que están fuera de ámbito son ignoradas automáticamente por todos los módulos.

Puede revertir esto usando el comando scope:

[sn0int][demo][kpcyrd/ctlogs] > target
#1, "example.com"
[sn0int][demo][kpcyrd/ctlogs] > scope domains where true
[+] Updated 2 rows
[sn0int][demo][kpcyrd/ctlogs] > target
#1, "example.com"
#2, "google.com"
[sn0int][demo][kpcyrd/ctlogs] >

PISTA:

Todas las entidades tienen este campo, puede referirse a él en las consultas usando unscoped=1.

CONFIGURACIÓN

Esta sección documenta el archivo de configuración. Por defecto, este archivo no existe y se utiliza una configuración predeterminada en su lugar.

Linux/BSD
~/.config/sn0int.toml
OSX
~/Library/Preferences/sn0int.toml
Windows
%APPDATA%/sn0int.toml

[core]

registry
Configure el registro que desea utilizar. Por defecto es https://sn0int.com.
no-autoupdate
sn0int comprobará si sus módulos están desactualizados al iniciar una vez por semana. Establezca esta opción en true para deshabilitarla.

[namespaces]

Por defecto, los módulos de sn0int se asumen instalados desde el registro. Es posible que desee mantener un directorio local con módulos privados, especialmente durante el desarrollo. Puede configurar una carpeta que contenga módulos que no son gestionados por sn0int añadiendo una sección de namespace al archivo de configuración:

[namespaces]
foo = "/opt/sn0int/foo"
bar = "~/repos/a/b/c/sn0int-modules"

Esto cargará módulos de estas dos carpetas y los registrará en el espacio de nombres foo y bar.

Tenga en cuenta que sn0int también asumirá que los enlaces simbólicos en ~/.local/share/sn0int/modules y las carpetas que contienen una carpeta .git son gestionados externamente.

[network]

Para habilitar un proxy, agregue lo siguiente a su archivo de configuración:

[network]
proxy = "127.0.0.1:9050"

Esto fuerza todo a través de tor (o cualquier otro proxy socks5) y restringe todas las demás funciones que dependen de la red. Por ejemplo, la función dns se deshabilita por completo si se configura un proxy.

REFERENCIA DE FUNCIONES

asn_lookup

Ejecuta una búsqueda ASN para una dirección IP dada. La función devuelve asn y as_org. Esta función puede fallar.

lookup = asn_lookup('1.1.1.1')
if last_err() then return end

base64_decode

Decodifica una cadena base64 con el alfabeto y relleno por defecto.

base64_decode("ww==")

base64_encode

Codifica un array binario con base64 y el alfabeto y relleno por defecto.

base64_encode("\x00\xff")

base64_custom_decode

Decodifica una cadena base64 con alfabeto y relleno personalizados.

-- base64
base64_custom_decode('b2hhaQ==', 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/', '=')
-- base64 sin relleno
base64_custom_decode('b2hhaQ', 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/', '')
-- base64 url safe
base64_custom_decode('b2hhaQ==', 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-_', '=')

base64_custom_encode

Codifica un array binario con base64 y alfabeto y relleno personalizados.

-- base64
base64_custom_encode('ohai', 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/', '=')
-- base64 sin relleno
base64_custom_encode('ohai', 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/', '')
-- base64 url safe
base64_custom_encode('ohai', 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-_', '=')

base32_custom_decode

Decodifica una cadena base32 con alfabeto y relleno personalizados.

-- rfc-4648 base32
base32_custom_decode('N5UGC2I=', 'ABCDEFGHIJKLMNOPQRSTUVWXYZ234567', '=')
-- z-base-32
base32_custom_decode('p7wgn4e', 'ybndrfg8ejkmcpqxot1uwisza345h769', '')

base32_custom_encode

Codifica un array binario con base32 y alfabeto y relleno personalizados.

-- rfc-4648 base32
x = base32_custom_encode('ohai', 'ABCDEFGHIJKLMNOPQRSTUVWXYZ234567', '=')
-- z-base-32
x = base32_custom_encode('ohai', 'ybndrfg8ejkmcpqxot1uwisza345h769', '')

clear_err

Borra el último error registrado del estado interno. Ver también last_err.

if last_err() then
    -- ignorar este error
    clear_err()
end

create_blob

Introduce un array de bytes en un almacenamiento de blobs persistente. Esto permite pasar esos bytes a funciones que operan en el almacenamiento de blobs. Devuelve un identificador de blob que es determinista basado en el contenido del blob. Los blobs son inmutables.

blob = create_blob("algunos bytes")
debug(blob)

datetime

Devuelve la hora actual en UTC. Esta función es adecuada para determinar fechas y horas para campos de base de datos DATETIME.

now = datetime()

NOTA:

Este formato es específico de sn0int, para obtener la hora actual para scripting use time_unix en su lugar.

ADVERTENCIA:

Esta función será deprecada en algún momento. Prefiera sn0int_time para scripts nuevos.

db_add

Agrega una entidad a la base de datos o la actualiza si ya existe. Esta función puede fallar o devolver nil. Ver db_add para detalles.

domain_id = db_add('domain', {
    value='example.com',
})

db_add_ttl

Agrega una entidad temporal a la base de datos. Esto se usa comúnmente para insertar enlaces temporales que caducan automáticamente con el tiempo. Si la entidad ya existe y también está marcada como temporal, la nueva ttl reemplazará la antigua. Si la entidad ya existe pero nunca caduca, no agregaremos una ttl.

-- este enlace es válido por 2 minutos
domain_id = db_add_ttl('network-device', {
    network_id=1,
    device_id=13,
}, 120)

db_activity

Registra un evento de actividad. Un evento básico se ve así:

db_activity({
    topic='harness/activity-ping
:dummy', time=sn0int_time(), content={ a='b', foo={ bar=1337, }, msg='ohai', }, })

Esta función se explica en detalle en la sección activity.

db_select

Comprueba si un objetivo está en el ámbito. Si se devuelve un valor no nulo, esta entidad está en el ámbito. Esta función puede fallar. Consulte db_select para obtener más detalles.

domain_id = db_select('domain', 'example.com')
if domain_id ~= nil then
    -- haz algo
end

db_update

Actualiza una entidad en la base de datos. Esta función puede fallar. Consulte db_update para obtener más detalles.

db_update('ipaddr', arg, {
    asn=lookup['asn'],
    as_org=lookup['as_org'],
})

dns

Resuelve un registro DNS. Si la consulta DNS fue exitosa y la respuesta DNS es NoError, entonces x['error'] es nil. Los registros de la respuesta están en x['answers']. Esta función puede fallar.

Esta función acepta las siguientes opciones:

record
El query_type, puede ser cualquiera de A, AAAA, MX, AXFR, etc.
nameserver
El servidor que debe usarse para la consulta. Por defecto es el resolvedor del sistema.
tcp
Si la consulta debe usar TCP, true/false.
timeout
El tiempo hasta que la consulta expire en milisegundos.
records = dns('example.com', {
    record='A',
})
if last_err() then return end
if records['error'] ~= nil then return end
records = records['answers']

NOTA:

Las respuestas DNS con un código de error establecido no provocan un cambio en last_err(). Tienes que comprobarlo explícitamente.

NOTA:

Esta función no está disponible si hay configurado un proxy socks5.

error

Registra un error en la terminal.

error('ohai')

geoip_lookup

Realiza una consulta geoip para una dirección IP dada. La función devuelve:

  • continente
  • continent_code
  • country
  • country_code
  • city
  • latitude
  • longitude

Esta función puede fallar.

lookup = geoip_lookup('1.1.1.1')
if last_err() then return end

hex

Codifica en hexadecimal una lista de bytes.

hex("\x6F\x68\x61\x69\x0A\x00")

hmac_md5

Calcula un hmac con md5. Devuelve un array binario.

hmac_md5("secret", "my authenticated message")

hmac_sha1

Calcula un hmac con sha1. Devuelve un array binario.

hmac_sha1("secret", "my authenticated message")

hmac_sha2_256

Calcula un hmac con sha2_256. Devuelve un array binario.

hmac_sha2_256("secret", "my authenticated message")

hmac_sha2_512

Calcula un hmac con sha2_512. Devuelve un array binario.

hmac_sha2_512("secret", "my authenticated message")

hmac_sha3_256

Calcula un hmac con sha3_256. Devuelve un array binario.

hmac_sha3_256("secret", "my authenticated message")

hmac_sha3_512

Calcula un hmac con sha3_512. Devuelve un array binario.

hmac_sha3_512("secret", "my authenticated message")

html_select

Analiza un documento HTML y devuelve el primer elemento que coincide con el selector CSS. El valor de retorno es una tabla con text que es el texto interno y attrs que es una tabla de los atributos del elemento.

csrf = html_select(html, 'input[name="csrf"]')
token = csrf["attrs"]["value"]

html_select_list

Igual que html_select pero devuelve todas las coincidencias en lugar de la primera.

html_select_list(html, 'input[name="csrf"]')

http_mksession

Crea un objeto de sesión. Es similar a requests.Session en python-requests y realiza un seguimiento de las cookies.

session = http_mksession()

http_request

Prepara una solicitud HTTP. El primer argumento es la referencia de la sesión y las cookies de esa sesión se copian en la solicitud. Después de que la solicitud se ha enviado, las cookies de la respuesta se copian de nuevo en la sesión.

Los siguientes argumentos son el method, la url y opciones adicionales. Tenga en cuenta que todavía necesita especificar una tabla vacía {} incluso si no hay opciones establecidas. Las siguientes opciones están disponibles:

query
Un mapa de parámetros de consulta que deben establecerse en la URL.
headers
Un mapa de encabezados que deben establecerse.
basic_auth
Configura el encabezado de autenticación básica con {"user, "password"}.
user_agent
Sobrescribe el agente de usuario predeterminado con una cadena.
json
El cuerpo de la solicitud que debe ser codificado en JSON.
form
El cuerpo de la solicitud que debe ser codificado como formulario.
follow_redirects
Sigue automáticamente las redirecciones, hasta el número especificado. Si se establece en 1, solo se seguirá una redirección. Por defecto es 0, por lo que no se siguen las redirecciones.
body
El cuerpo de la solicitud sin procesar como cadena.
into_blob
Si es verdadero, el cuerpo de la respuesta se almacena en almacenamiento de blobs y se devuelve una referencia de blob como blob en lugar del cuerpo completo.
proxy
Utiliza un proxy socks5 en el formato 127.0.0.1:9050. Esta opción solo funciona si no entra en conflicto con la configuración global del proxy.
binary
Establezca en true para obtener la respuesta HTTP como bytes sin procesar.

Esta función puede fallar.

req = http_request(session, 'POST', 'https://httpbin.org/post', {
    json={
        user=user,
        password=password,
    }
})
resp = http_send(req)
if last_err() then return end
if resp['status'] ~= 200 then return 'http status error: ' .. resp['status'] end

http_send

Envía la solicitud que se ha construido con http_request. Devuelve una tabla con las siguientes claves:

status
El código de estado HTTP
headers
Una tabla de encabezados
text
El cuerpo de la respuesta como cadena
binary
El cuerpo de la respuesta como bytes (si binary=true)
blob
Si into_blob se habilitó para la solicitud, el cuerpo se descarga en almacenamiento de blobs con una referencia al cuerpo en este campo.
req = http_request(session, 'POST', 'https://httpbin.org/post', {
    json={
        user=user,
        password=password,
    }
})
resp = http_send(req)
if last_err() then return end
if resp['status'] ~= 200 then return 'http status error: ' .. resp['status'] end

http_fetch

Esto realiza un http_send y también valida automáticamente el código de estado.

NOTA:

Casi siempre querrá esto al configurar la opción into_blob, ya que esta función valida
dates the status code antes de insertar el cuerpo de la respuesta en el almacenamiento de blobs.
-- forma corta
data = http_fetch(req)
if last_err() then return end
-- forma larga
resp = http_send(req)
if last_err() then return end
if resp['status'] ~= 200 then return 'error de estado http: ' .. resp['status'] end

http_fetch_json

Idéntico a http_fetch pero también analiza automáticamente el cuerpo de la respuesta como json.

-- forma corta
data = http_fetch_json(req)
if last_err() then return end
-- forma larga
resp = http_send(req)
if last_err() then return end
if resp['status'] ~= 200 then return 'error de estado http: ' .. resp['status'] end
data = json_decode(resp['text'])
if last_err() then return end

img_load

Intenta decodificar un blob como una imagen y devuelve metadatos básicos como el tipo mime, la altura y el ancho.

img = img_load(blob)
if last_err() then return end
debug(img)

img_exif

Extrae metadatos exif de una imagen.

exif = img_exif(blob)
if last_err() then return end
debug(exif)

img_ahash

Calcula el hash perceptual de Media (aHash).

hash = img_ahash(blob)
if last_err() then return end
debug(hash)

img_dhash

Calcula el hash perceptual de Gradiente (dHash).

sock_connect

Crea una conexión tcp.

Las siguientes opciones están disponibles:

tls
Establecer en true para habilitar tls (se validan los certificados)
sni_value
En lugar del argumento host, usa una cadena personalizada para la extensión sni.
disable_tls_verify
Peligro: deshabilita la verificación tls. Esto deshabilita toda la seguridad en la conexión. Ten en cuenta que sn0int sigue siendo bastante estricto, encontrarás problemas si necesitas soporte para cifrados inseguros.
proxy
Usa un proxy socks5 en el formato 127.0.0.1:9050. Esta opción solo funciona si no entra en conflicto con la configuración global del proxy.
connect_timeout
Aborta los intentos de conexión tcp después de n segundos.
read_timeout
Aborta los intentos de lectura después de n segundos. Esto se puede usar para despertar conexiones periódicamente.
write_timeout
Aborta los intentos de escritura después de n segundos.
sock = sock_connect("127.0.0.1", 1337, {
    tls=true,
})

sock_upgrade_tls

Toma una conexión tcp existente y comienza un handshake tls. Las opciones son las mismas que las de sock_connect, pero el valor de tls siempre se asume que es true.

El valor sni debe establecerse específicamente, de lo contrario, la extensión sni se deshabilita.

El uso de esta función devuelve específicamente información adicional que se descarta al usar sock_connect directamente con tls=true.

sock = sock_connect("127.0.0.1", 1337, {})
if last_err() then return end
tls = sock_upgrade_tls(sock, {
    sni_value='example.com',
})
if last_err() then return end
info(tls)

sock_options(sock, {
    read_timeout=3,

Envía una cadena al socket. Se agrega automáticamente una nueva línea a la cadena.

Recibe una línea del socket. La línea incluye la nueva línea.

Recibe todos los datos del socket hasta EOF.

Recibe líneas del servidor hasta que una línea contenga la aguja, luego devuelve esta línea.

Recibe líneas del servidor hasta que una línea coincida con la expresión regular, luego devuelve esta línea.

Recibe exactamente n bytes del socket.

x = sock_recvn(sock, 4)

sock_recvuntil

Recibe hasta encontrar la aguja, luego devuelve todos los datos incluyendo la aguja.

x = sock_recvuntil(sock, needle)

sock_sendafter

Recibe hasta encontrar la aguja, luego escribe los datos en el socket.

sock_sendafter(sock, needle, data)

sock_newline

Sobrescribe el salto de línea por defecto \n.

sodium_secretbox_open

Utiliza criptografía simétrica autenticada para descifrar un mensaje dado.

Internamente es crypto_secretbox_xsalsa20poly1305.

La clave debe tener 32 bytes; consulta key_trunc_pad si es necesario.

Se espera que los primeros 24 bytes del mensaje cifrado sean el nonce.

plain = sodium_secretbox_open(encrypted, key)
if last_err() then return end
txt = utf8_decode(plain)
if last_err() then return end
info(txt)

url_decode

Analiza una cadena de consulta en un mapa. Para la decodificación porcentual sin procesar, consulta url_unescape.

Codifica un mapa en una cadena de consulta. Para la codificación porcentual sin procesar, consulta url_escape.

Aplica codificación URL a una cadena.

url_join

Une un enlace relativo a un enlace absoluto. Si ambos enlaces son absolutos, simplemente devolvemos el primero:

url_parse

Analiza una URL en sus componentes. Se devuelven los siguientes componentes:

  • host
  • port
  • path
  • query
  • fragment
  • params

print(url['host'] == 'example.com')
print(url['path'] == '/')
