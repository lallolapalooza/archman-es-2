NOMBRE

sane-ricoh - Backend SANE para escáneres planos Ricoh

DESCRIPCIÓN

La biblioteca sane-ricoh implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a los siguientes escáneres planos Ricoh:

IS50
IS60

NOMBRES DE DISPOSITIVO

Este backend espera nombres de dispositivo del tipo:

especial

Donde especial es la ruta del nombre del dispositivo especial que corresponde a un escáner SCSI. El nombre del dispositivo especial debe ser un dispositivo SCSI genérico o un enlace simbólico a dicho dispositivo. El programa sane-find-scanner(1) ayuda a averiguar el dispositivo correcto. En Linux, un nombre de dispositivo de este tipo podría ser /dev/sga o /dev/sge, por ejemplo. Consulte sane-scsi(5) para obtener más detalles.

ARCHIVOS

/etc/sane.d/ricoh.conf
El archivo de configuración del backend (consulte también la descripción de SANE_CONFIG_DIR más abajo).
/usr/lib/sane/libsane-ricoh.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-ricoh.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por punto y coma (`;'). Si esta variable no está establecida, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorios, entonces los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, establecer SANE_CONFIG_DIR a "/tmp/config:" resultaría en la búsqueda de los directorios tmp/config, . y /etc/sane.d (en este orden).
SANE_DEBUG_RICOH
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Los niveles de depuración más altos aumentan la verbosidad de la salida.

Ejemplo: export SANE_DEBUG_RICOH=4

VER TAMBIÉN

sane(7), sane-scsi(5), sane-find-scanner(1)
