NOMBRE

sane-qcam - Backend de SANE para cámaras Connectix QuickCam

DESCRIPCIÓN

La biblioteca sane-qcam implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a las cámaras Connectix QuickCam.

NOMBRES DE DISPOSITIVO

Este backend espera nombres de dispositivo del tipo:

puerto

donde puerto es la dirección del puerto de E/S en la que reside el dispositivo. Esta dirección se especifica normalmente en hexadecimal utilizando sintaxis C (por ejemplo, 0x37b) y puede ir precedida de la letra "u" (por ejemplo, u0x37b) para forzar al backend a acceder a la cámara en modo unidireccional.

CONFIGURACIÓN

El contenido del archivo qcam.conf es una lista de direcciones de puerto que pueden estar conectadas a una Connectix QuickCam. Las líneas vacías y todo lo que empieza por un signo de almohadilla (#) hasta el final de la línea se ignoran. A continuación se muestra un ejemplo de archivo de configuración:

0x37b # /dev/lp0
0x378 # /dev/lp1
u0x278 # /dev/lp2 forzado en modo unidireccional
0x3bc # /dev/lp0 (dirección alternativa)

En general, lo más seguro es listar solo las direcciones de puerto que realmente corresponden a una QuickCam. Por ejemplo, si una de las direcciones listadas se conecta realmente a una impresora, al iniciar este backend la impresora realizará un reinicio del dispositivo (lo cual es generalmente indeseable).

ARCHIVOS

/etc/sane.d/qcam.conf
El archivo de configuración del backend (ver también la descripción de SANE_CONFIG_DIR a continuación).
/usr/lib/sane/libsane-qcam.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-qcam.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:') y en OS/2, están separados por un punto y coma (`;'). Si esta variable no está establecida, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorio, los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, establecer SANE_CONFIG_DIR a "/tmp/config:" resultaría en que se buscaran los directorios tmp/config, ., y /etc/sane.d (en este orden).
SANE_DEBUG_QCAM
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Los niveles más bajos reducen la verbosidad.

AUTOR

David Mosberger

ERRORES

El soporte se limita actualmente a la versión a color de la QuickCam. La cámara en blanco y negro también está empezando a funcionar, pero no creo que funcione en todos los casos todavía. Según se informa, la adquisición de imágenes de ciertos tamaños funciona bien, pero otras resultan en imágenes desplazadas (parece un problema debido al relleno de bytes).

El programa necesita privilegios de root, ya que necesita poder acceder a los puertos de E/S de la cámara.
