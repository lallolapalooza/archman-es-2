NOMBRE

sas_disk_blink - hacer parpadear el LED de un disco SAS

SINOPSIS

sas_disk_blink [--help] [--set NUM] [--verbose] DISPOSITIVO

DESCRIPCIÓN

Este script de shell bash intenta hacer parpadear el LED del disco SAS al que se refiere DISPOSITIVO. Por defecto, el LED parpadeará durante 30 segundos. Esto está diseñado para ayudar a identificar qué disco corresponde a un DISPOSITIVO dado.

El script utiliza la utilidad sdparm y manipula el campo "Ready LED Meaning" (RLM) en la página de modo específica del protocolo para hacer parpadear el LED.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-h, --help
imprimir el mensaje de uso y salir.
-s, --set NUM
cuando NUM es 0, se borra el campo RLM. Cuando NUM es 1, se establece el campo RLM. Cuando NUM > 1, se hace que el LED del disco SAS parpadee durante NUM segundos. Si no se proporciona esta opción, el LED del disco SAS parpadeará durante 30 segundos.
-v, --verbose
aumentar el nivel de verbosidad.

ESTADO DE SALIDA

El estado de salida de este script es 0 cuando tiene éxito. De lo contrario, el estado de salida es el de la última utilidad sdparm llamada. Ver la página del manual de sdparm(8).
