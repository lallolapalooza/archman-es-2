NOMBRE

sa-awl - examinar y manipular la base de datos de lista de bienvenida automática (auto-welcomelist) de SpamAssassin

SINOPSIS

sa-awl [--clean] [--dry-run] [--min n] [archivo_db]

DESCRIPCIÓN

Comprueba o limpia un archivo de base de datos de lista de bienvenida automática (AWL) de SpamAssassin.

El nombre del archivo se especifica después de cualquier opción, como "archivo_db". El valor predeterminado es "$HOME/.spamassassin/auto-welcomelist".

OPCIONES

--clean
Limpia las entradas de AWL utilizadas con poca frecuencia. El interruptor "--min" se puede usar para seleccionar el umbral en el que se conservan o eliminan las entradas.
--dry-run
Cuando se especifica con la opción "--clean" muestra las entradas de AWL utilizadas con poca frecuencia que se eliminarán. El interruptor "--min" se puede usar para seleccionar el umbral en el que se conservan o eliminan las entradas.
--min n
Selecciona el umbral en el que se conservan o eliminan las entradas cuando se usa "--clean". El valor predeterminado es 2, por lo que se eliminan las entradas que solo se han visto una vez.

SALIDA

La salida se ve así:

AVG  (TOTSCORE/COUNT)  --  EMAIL|ip=IPBASE

Por ejemplo:

 0.0         (0.0/7)  --  dawson@example.com|ip=208.192
21.8        (43.7/2)  --  mcdaniel_2s2000@example.com|ip=200.106

"AVG" es la puntuación media; "TOTSCORE" es la puntuación total de todos los correos vistos hasta ahora; "COUNT" es el número de mensajes vistos de ese remitente; "EMAIL" es la dirección de correo electrónico del remitente, y "IPBASE" es la **dirección IP base de AWL**.

**Dirección IP base de AWL** es una forma de identificar la dirección IP desde la que el remitente envía con frecuencia, de forma aproximada, pero que sigue siendo difícil de falsificar para los spammers. El algoritmo es el siguiente:

- tomar la última cabecera Received que contiene una dirección IP pública, es decir,
  una que no esté en el espacio IP privado o no enrutado.
- cortar los dos últimos octetos, asumiendo que el usuario puede estar en la
  dirección IP dinámica del ISP.
