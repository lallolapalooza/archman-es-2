NOMBRE

sane-kodak - Backend SANE para escáneres planos y ADF grandes de Kodak

DESCRIPCIÓN

La biblioteca sane-kodak implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a escáneres planos y ADF grandes de Kodak.

Este documento describe la versión 7 del backend, que se incluyó con SANE 1.0.21.

HARDWARE SOPORTADO

Esta versión debería soportar modelos que utilizan los protocolos SCSI y Firewire de Kodak. El i1860 se usó para desarrollar el backend, pero otros modelos pueden funcionar con modificaciones mínimas. Consulte la lista en http://www.sane-project.org/sane-supported-devices.html para obtener una lista actualizada.

Si tiene una máquina que no está en esa lista, o se informa como 'no probada': la mejor manera de determinar el nivel de soporte es probar el escáner directamente, o recopilar un rastreo del controlador de Windows en acción. Póngase en contacto con el autor para obtener ayuda o con los resultados de las pruebas.

HARDWARE NO SOPORTADO

La mayoría de las máquinas recientes de nivel consumidor o de grupo de trabajo de Kodak se basan en otros chipsets y no son compatibles con este backend. Algunos de estos escáneres pueden ser compatibles con otro backend.

OPCIONES

Se han realizado esfuerzos para exponer las opciones básicas del hardware, incluyendo:

--source s

Selecciona la fuente para el escaneo. Las opciones pueden incluir "Flatbed", "ADF Front", "ADF Back", "ADF Duplex".

--mode m

Selecciona el modo para el escaneo. Las opciones pueden incluir "Lineart", "Halftone", "Gray" y "Color".

--resolution

Controla la resolución del escaneo. Las opciones disponibles pueden estar limitadas por el modo.

--tl-x, --tl-y, --br-x, --br-y

Establece las coordenadas superior izquierda e inferior derecha del área de escaneo. Estos son renombrados a -t, -l, -x, -y por algunos frontends.

--page-width, --page-height

Establece el tamaño del papel. Usado por el escáner para determinar el centrado de las coordenadas de escaneo al usar el ADF (Alimentador Automático de Documentos) y para detectar errores de doble alimentación.

Otras opciones estarán disponibles en función de las capacidades del escáner. Utilice scanimage --help para obtener una lista, pero tenga en cuenta que algunas opciones solo se pueden establecer cuando se ha establecido otra opción, y que las opciones avanzadas pueden estar ocultas por algunos programas frontend.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración kodak.conf se utiliza para indicar al backend cómo buscar escáneres y proporcionar opciones que controlen el funcionamiento del backend. Este archivo se lee cada vez que el frontend solicita al backend una lista de escáneres, generalmente solo cuando se inicia el frontend. Si el archivo de configuración no está presente, el backend utilizará un conjunto de valores predeterminados compilados, que son idénticos al archivo de configuración predeterminado que se incluye con SANE.

Los escáneres se pueden especificar en el archivo de configuración de 2 maneras:

"scsi KODAK"

Solicita al backend que busque en todos los buses SCSI del sistema un dispositivo que se informe como un escáner fabricado por 'KODAK'.

"scsi /dev/sg0" (u otro archivo de dispositivo SCSI)

Solicita al backend que abra el dispositivo SCSI nombrado. Solo útil si tiene varios escáneres compatibles conectados a su sistema y necesita especificar uno. Probablemente no debería usarse con la otra línea "scsi" anterior.

La única opción de configuración admitida es "buffer-size=xxx", que le permite establecer el número de bytes en el búfer de datos a algo diferente del valor predeterminado compilado, 32768 (32K). Algunos usuarios informan que su escáner se "congela" a mitad de página, o no transmite la imagen si el búfer no es lo suficientemente grande.

Nota: Esta opción puede aparecer varias veces en el archivo de configuración. Solo se aplica a los escáneres descubiertos por las líneas 'scsi/usb' que siguen a esta opción.

Nota: El backend no impone un límite superior a este valor, ya que algunos usuarios lo requerían bastante grande. No se recomiendan valores superiores al predeterminado, y pueden bloquear su sistema operativo o el controlador de su tarjeta SCSI. Usted ha sido advertido.

ENTORNO

El backend utiliza una única variable de entorno, SANE_DEBUG_KODAK, que habilita la salida de depuración en stderr. Los valores válidos son:

5 Errores
10 Rastreo de funciones
15 Detalle de funciones
20 Comandos de opciones
25 Rastreo SCSI
30 Detalle SCSI
35 Ruido inútil

PROBLEMAS CONOCIDOS

La mayoría de las opciones de hardware no son compatibles o no están expuestas para el control del usuario, incluyendo: detección de alimentación múltiple, compresión de imagen, recorte automático, validador, umbralización, multi-stream, etc.

CRÉDITOS

Los diversos autores del backend sane-fujitsu(5) proporcionaron código útil.
Kodak proporcionó acceso a hardware, documentación y personal.
