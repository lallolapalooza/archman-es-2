sane-pieusb(5) SANE Scanner Access Now Easy sane-pieusb(5)

NOMBRE

sane-pieusb - Backend SANE para escáneres de diapositivas PIE PowerSlide y Reflecta DigitDia/CrystalScan/ProScan conectados por USB.

DESCRIPCIÓN

La biblioteca sane-pieusb implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a escáneres de diapositivas PIE y Reflecta conectados por USB.
Actualmente, los siguientes escáneres deberían funcionar con este backend:

Modelo:                    Estado
------------------------- ------
PIE PowerSlide 3600       No probado
PIE PowerSlide 3650       No probado
PIE PowerSlide 4000       No probado
PIE PowerSlide 5000       No probado
Reflecta CrystalScan 7200 No probado
Reflecta ProScan 4000     No probado
Reflecta ProScan 7200     No probado
Reflecta DigitDia 3600    No probado
Reflecta DigitDia 4000    No probado
Reflecta DigitDia 5000    No probado
Reflecta DigitDia 6000    Ok

MÚLTIPLES DIAPOSITIVAS

El soporte para escáneres de múltiples diapositivas (como la serie PowerSlide o DigitDia) se realiza mediante el avance automático ('Advance slide' configuración) de la diapositiva después de cada escaneo.

Sin embargo, para obtener mejores resultados, se recomienda hacer una vista previa para cada diapositiva, ya que esto establece gamma, brillo y contraste a valores óptimos.

Atención: SANE no tiene detección y reorientación automática de paisaje/retrato al escanear múltiples diapositivas. ¡Debes colocar todas las diapositivas en una sola orientación primero!

ELIMINACIÓN DE SUCIEDAD

Si está disponible, sane-pieusb admite escaneos infrarrojos para la detección y eliminación de suciedad. Esto debe habilitarse a través de la configuración 'Clean image'.

PROBLEMAS CONOCIDOS

El backend sane-pieusb admite la eliminación de suciedad basada en información de escaneo infrarrojo. Dado que SANE no proporciona post-procesamiento en el backend, sane-pieusb realiza el escaneo y la eliminación de suciedad durante la fase de configuración. La fase de 'escaneo' solo se utiliza para transferir la imagen completada. Por lo tanto, sane-pieusb no utiliza subprocesos múltiples, lo que hace que una interfaz típica parezca 'bloqueada'. Las solicitudes de cancelación solo se atienden entre escaneos.

ENTORNO

SANE_DEBUG_PIEUSB
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad. 
nivel   salida de depuración
------- ------------------------------
 0       nada
 1       errores
 2       advertencias y errores menores
 5       información adicional
 7       llamadas a la API de SANE
 9       funciones del backend
11       funciones del escáner
13       funciones usb
15       funciones del buffer de imagen

ARCHIVOS

/etc/sane.d/pieusb.conf
El archivo de configuración del backend
/usr/lib/sane/libsane-pieusb.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-pieusb.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).
