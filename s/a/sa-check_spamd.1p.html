NOMBRE

sa-check_spamd - script de monitorización de spamd para usar con Nagios, etc.

SINOPSIS

sa-check_spamd [opciones]

Opciones:

-c secs, --critical=secs          Umbral de respuesta de ping crítico
-h, -?, --help                    Imprimir mensaje de uso
-H hostname, --hostname=hostname  Nombre de host del servicio spamd a pingear
-p port, --port=port              Puerto del servicio spamd a pingear
--socketpath=path                 Conectar al socket de dominio UNIX dado
-t secs, --timeout=secs           Tiempo máximo de espera para la respuesta del ping
-v, --verbose                     Salida de depuración detallada
-V, --version                     Información de versión de salida
-w secs, --warning=secs           Umbral de respuesta de ping de advertencia

DESCRIPCIÓN

El propósito de este programa es proporcionar una herramienta para monitorizar el estado de los procesos del servidor "spamd". spamd es la versión daemonizada del ejecutable spamassassin, ambos proporcionados en la distribución SpamAssassin.

Este programa está diseñado para ser utilizado, como un plugin, con el software de monitorización de servicios Nagios disponible en http://nagios.org. Puede ser compatible con otros paquetes de monitorización de servicios. También es útil como una utilidad de línea de comandos o como un componente de un script de shell personalizado.

OPCIONES

Las opciones de la forma larga pueden ser acortadas siempre que permanezcan sin ambigüedades (es decir, se puede usar --host en lugar de --hostname).

-c secs, --critical=secs
Umbral crítico de respuesta del ping en segundos. Si la respuesta del ping de spamd tarda más que el valor especificado (en segundos), el programa saldrá con un valor de 2 para indicar el estado crítico.

Este valor debe ser al menos tan largo como el valor especificado para warning y menor que el valor especificado para timeout.

-h, -?, --help
Imprime este mensaje de uso y sale.
-H hostname, --hostname=hostname
El nombre de host o la dirección IP del servicio spamd a pingear. Por defecto, se utiliza el nombre de host localhost. Si se establece --socketpath, este valor se ignorará.
-p port, --port=port
El puerto del servicio spamd a pingear. Por defecto, se utiliza el puerto 783 (el número de puerto predeterminado de spamd). Si se establece --socketpath, este valor se ignorará.
--socketpath=path
Conectar al socket de dominio UNIX dado. Usar en lugar de un nombre de host y un puerto TCP. Cuando se establece, se ignorarán cualquier nombre de host y puerto TCP especificados.
-t secs, --timeout=secs
El tiempo máximo de espera para la respuesta del ping. Una vez excedido, el programa saldrá con un valor de 2 para indicar el estado crítico. El valor de tiempo de espera predeterminado es de 45 segundos. El tiempo de espera no debe ser inferior a 1 segundo.

Este valor debe ser mayor que los valores especificados tanto para critical como para warning.

-v, --verbose
Mostrar salida de depuración detallada en STDOUT.
-V, --version
Mostrar información de versión en STDOUT.
-w secs, --warning=secs
Umbral de advertencia de respuesta del ping en segundos. Si la respuesta del ping de spamd tarda más que el valor especificado (en segundos), y no excede el valor del umbral critical, el programa saldrá con un valor de 1 para indicar el estado de advertencia.

Este valor no debe ser más largo que el valor especificado para critical y menor que el valor especificado para timeout.

CÓDIGOS DE SALIDA

El programa indicará el estado del proceso spamd que se está monitorizando saliendo con uno de estos valores:

0
OK: Se recibió una respuesta del ping de spamd dentro de todos los tiempos umbrales.
1
ADVERTENCIA: Una respuesta del ping de spamd excedió el umbral de advertencia pero no el umbral crítico.
2
CRÍTICO: Una respuesta del ping de spamd excedió el umbral crítico o el valor de tiempo de espera.
3
DESCONOCIDO: Ocurrió un error en el programa sa-check_spamd, probablemente causado por una dependencia faltante o un parámetro de configuración inválido.
