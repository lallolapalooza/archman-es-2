sackd(8) Daemon del quiosco de autenticación y credenciales de Slurm sackd(8)

NOMBRE

sackd - Daemon del quiosco de autenticación y credenciales de Slurm.

SINOPSIS

sackd [OPCIONES...]

DESCRIPCIÓN

sackd es el Daemon del quiosco de autenticación y credenciales de Slurm. Puede usarse en nodos de inicio de sesión que no estén ejecutando daemons slurmd para permitir la autenticación en el clúster. El programa se ejecutará como SlurmdUser. Cuando se ejecuta en el modo "sin configuración" de Slurm, en cuyo caso los archivos de configuración se recuperan y escriben en el directorio /run/slurm/conf (a menos que se establezca RUNTIME_DIRECTORY).

OPCIONES

--ca-cert-file <archivo>
Ruta absoluta al certificado CA utilizado para obtener la configuración cuando se ejecuta sin configuración en un clúster habilitado para TLS.
--conf-server host[:puerto]
Recuperar configuraciones de slurmctld ejecutándose en host[:puerto]. Requiere soporte de slurmctld proporcionado al establecer enable_configless en SlurmctldParameters.
-D
Ejecutar sackd en primer plano con el registro copiado a stderr.
--disable-reconfig
Obtener configuraciones en modo sin configuración una vez, pero no registrarse con slurmctld para futuras actualizaciones de reconfiguración.
-f archivo
Leer la configuración del archivo especificado.
-h
Ayuda; imprime un breve resumen de las opciones del comando.
--jwks-file <archivo>
Leer la información de autenticación/Slurm JWKS del archivo especificado. El valor predeterminado es slurm.jwks ubicado en el mismo directorio que slurm.conf.
--key-file <archivo>
Leer la clave de autenticación de autenticación/Slurm del archivo especificado. El valor predeterminado es slurm.key ubicado en el mismo directorio que slurm.conf.
--port numero
Número de puerto del socket para escuchar las actualizaciones de reconfiguración. Esto puede ser útil cuando coexisten varios sackds en el mismo nodo de inicio de sesión. El valor predeterminado es SlurmdPort.
--systemd
Para ser utilizado cuando se inicia desde un archivo de unidad systemd.
-v
Modo detallado. Múltiples -v aumentan la verbosidad.

VARIABLES DE ENTORNO

Las siguientes variables de entorno pueden usarse para anular la configuración compilada en sackd.

ABORT_ON_FATAL
Cuando se detecta un error fatal, usa abort() en lugar de exit() para terminar el proceso. Esto permite capturar rastreos sin recompilar Slurm.
RUNTIME_DIRECTORY
Ruta absoluta que rige la ubicación tanto de la caché de configuración que sackd mantiene, como del socket Unix sack.socket utilizado para proporcionar servicios de autenticación.

Si se necesitan iniciar varios sackds en el mismo nodo de inicio de sesión, la opción de unidad systemd RuntimeDirectory debe establecerse en slurm-<nombre_del_clúster>. Systemd v240+ establece automáticamente RUNTIME_DIRECTORY en /run/$RuntimeDirectory para cada servicio sackd, de lo contrario, requiere una configuración manual (es decir, a través de la opción de unidad EnvironmentFile).

Si esto no está configurado, el valor predeterminado es /run/slurm/.

SACKD_DEBUG
Establece explícitamente el nivel de depuración para syslog y stderr. Los valores válidos son 0-9, o los mismos valores de cadena que las opciones de depuración como SlurmctldDebug en slurm.conf(5).
SACKD_DISABLE_RECONFIG
Igual que --disable-reconfig.
SACKD_PORT
Igual que --port.
SACKD_STDERR_DEBUG
Establece explícitamente el nivel de depuración para stderr. Los valores válidos son 0-9, o los mismos valores de cadena que las opciones de depuración como SlurmctldDebug en slurm.conf(5).
SACKD_SYSLOG_DEBUG
Establece explícitamente el nivel de depuración para syslog. Los valores válidos son 0-9, o los mismos valores de cadena que las opciones de depuración como SlurmctldDebug en slurm.conf(5).
SLURM_CONF
La ubicación del archivo de configuración de Slurm.
SLURM_DEBUG_FLAGS
Especifica las banderas de depuración que sackd debe usar. Consulte DebugFlags en la página del manual de slurm.conf(5) para obtener una lista completa de banderas. La variable de entorno tiene precedencia sobre la configuración en slurm.conf.

SEÑALES

SIGINT
sackd se cerrará limpiamente.
SIGHUP
sackd se reconfigurará.
SIGUSR2 SIGPIPE
Esta señal se ignora explícitamente.
