NOMBRE

sane-epson2 - Backend SANE para escáneres EPSON

DESCRIPCIÓN

La biblioteca sane-epson2 implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a escáneres planos Epson. Esta biblioteca soporta un conjunto similar de escáneres que el controlador sane-epson, pero fue desarrollada para soportar una gama más amplia de conexiones al escáner, incluyendo acceso por red.

Debido a que los controladores sane-epson y sane-epson2 soportan muchos de los mismos dispositivos, si un controlador te da problemas, puedes intentar deshabilitarlo para probar el otro. Esto se puede hacer eliminando el nombre del controlador de dll.conf o quizás comentando las opciones en epson.conf o epson2.conf.

OPCIONES

Las opciones que soporta el backend se pueden seleccionar a través de opciones de línea de comandos en programas como scanimage(1) o a través de elementos de la interfaz gráfica en programas como xscanimage(1) o xsane(1).

Las opciones válidas de línea de comandos y su sintaxis se pueden listar usando

scanimage --help -d epson2

No todos los dispositivos soportan todas las opciones.

Modo de escaneo
El conmutador --mode selecciona el modo básico de operación del escáner. Las opciones válidas son Binario, Escala de grises y Color. El modo Binario es solo blanco y negro, Escala de grises producirá 256 niveles de gris o más dependiendo del escáner, y Color significa modo de color de 24 bits o más dependiendo del escáner. Algunos escáneres usarán internamente color de 36 bits, pero su interfaz externa puede soportar solo 24 bits.

La opción --depth selecciona la profundidad de bits que está utilizando el escáner. Esta opción solo está disponible para escáneres que soportan más de una profundidad de bits. Escáneres más antiguos transferirán siempre la imagen en modo de 8 bits. Escáneres más nuevos permiten seleccionar 8 bits, 12 o 14 bits por canal de color. Para un escaneo en color, esto significa una profundidad de color efectiva de 36 o 42 bits en los tres canales. Las opciones válidas dependen del modelo de escáner.

El conmutador --halftoning selecciona el modo que se utiliza en modo Binario. Las opciones válidas son "None", "Halftone A (Hard Tone)", "Halftone B (Soft Tone)", "Halftone C (Net Screen)", "Dither A (4x4 Bayer)", "Dither B (4x4 Spiral)", "Dither C (4x4 Net Screen)", "Dither D (8x4 Net Screen)", "Text Enhanced Technology", "Download pattern A" y "Download pattern B".

El conmutador --dropout selecciona el llamado color de descarte. Las opciones válidas son Ninguno, Rojo, Verde y Azul. El valor predeterminado es Ninguno. El color de descarte se utiliza para escaneo monocromo y selecciona el color que no se escanea. Esto se puede usar para, por ejemplo, escanear un original con fondo de color.

El conmutador --brightness controla el brillo del escaneo. Las opciones válidas son valores enteros de -3 a 3. El valor predeterminado es 0. Cuanto mayor sea el valor de brillo, más brillante será la imagen. Si se selecciona una tabla definida por el usuario para la corrección gamma, el parámetro de brillo no está disponible.

El conmutador --sharpness establece la nitidez de los datos de la imagen. Las opciones válidas son valores enteros de -2 a 2, donde -2 significa "Desenfoque", -1 "Desenfoque ligero", 0 "Normal", 1 "Nitidez ligera" y 2 "Nitidez".

El conmutador --gamma-correction controla la función de corrección gamma interna del escáner. Las opciones válidas son "Default", "User defined", "High density printing" "Low density printing" y "High contrast printing".

El conmutador --color-correction controla la función de corrección de color interna del escáner. Las opciones válidas son "No Correction", "Impact-dot printers", "Thermal printers", "Ink-jet printers" y "CRT monitors". El valor predeterminado es "CRT monitors".

El conmutador --resolution selecciona la resolución para un escaneo. Algunos escáneres EPSON escanean en cualquier resolución entre el valor más bajo y el más alto posible. La lista reportada por el escáner se puede mostrar usando los parámetros "--help -d epson" para scanimage(1).

El conmutador --threshold selecciona el brillo mínimo para obtener un punto blanco.

La opción --mirror controla la forma en que se escanea la imagen. Leyendo los datos de la imagen de derecha a izquierda, la imagen se invierte. Las opciones válidas son "yes" y "no". El valor predeterminado es "no".

El conmutador --auto-area-segmentation activa la segmentación automática de áreas para escaneos monocromos. El escáner intentará determinar qué áreas son texto y cuáles contienen imágenes. Las áreas de imagen se reticularán y el texto se mejorará. Las opciones válidas son "yes" y "no". El valor predeterminado es "yes".

El parámetro --red-gamma-table se puede usar para descargar una tabla gamma definida por el usuario para el canal rojo. Las opciones válidas son las mismas que para --gamma-table.

El parámetro --green-gamma-table se puede usar para descargar una tabla gamma definida por el usuario para el canal verde. Las opciones válidas son las mismas que para --gamma-table.

El parámetro --blue-gamma-table se puede usar para descargar una tabla gamma definida por el usuario para el canal azul. Las opciones válidas son las mismas que para --gamma-table.

El parámetro --wait-for-button se puede usar para esperar hasta que se presione el botón del escáner para comenzar el proceso de escaneo.

Los coeficientes de corrección de color --cct-1 --cct-2 --cct-3 ... --cct-9 instalarán coeficientes de corrección de color para la corrección de color definida por el usuario. Los valores se especifican como enteros en el rango -127..127.

OPCIONES

Las siguientes opciones son soportadas por el backend epson2:

--depth {1,8,24}
Establece la profundidad de bits por píxel. Los valores válidos son 1 (blanco y negro), 8 (escala de grises) y 24 (color).
--mode {color,grayscale,lineart}
Establece el modo de escaneo. Los valores válidos son 'color', 'grayscale' (escala de grises) y 'lineart' (arte lineal, que es escaneo binario de alto contraste).
--resolution N
Establece la resolución de escaneo a N ppp (puntos por pulgada). El valor predeterminado es 100 ppp.
--all-events
Habilita la notificación de todos los eventos de SANE. Por ejemplo, el frontend de software selecciona automáticamente una baja resolución. Las opciones válidas son "sí" y "no". El valor predeterminado es "no".
-l N, -t N, -x N, -y N
Las opciones de geometría -l -t -x -y controlan el área de escaneo: -l establece la coordenada x de la esquina superior izquierda, -t la coordenada y de la esquina superior izquierda, -x selecciona el ancho y -y la altura del área de escaneo. Todos los parámetros se especifican en milímetros.
--source {Flatbed,Transparency Unit,Document Feeder}
La opción --source selecciona la fuente de escaneo. Las opciones válidas dependen de las opciones instaladas. El valor predeterminado es "Flatbed".
--auto-eject
La opción --auto-eject expulsará una página después de escanear desde el alimentador de documentos.
--film-type {Negative Film,Positive Film}
La opción --film-type seleccionará el tipo de película para escaneos con la unidad de transparencia. Esta opción solo se activa si la Unidad de Transparencia se selecciona como fuente de escaneo. Las opciones válidas son "Negative Film" (Película Negativa) y "Positive Film" (Película Positiva).
--focus-position {Focus 2.5mm above glass,Focus on glass}
La opción --focus-position selecciona la posición de enfoque para todos los escaneos. Las opciones válidas son "Focus 2.5mm above glass" (Enfoque 2.5mm sobre el cristal) y "Focus on glass" (Enfoque en el cristal). El enfoque en el punto de 2.5 mm sobre el cristal es necesario para escaneos con la unidad de transparencia, de modo que el escáner pueda enfocar la película si se utiliza uno de los soportes para películas. Esta opción solo es funcional para escáneres seleccionados, todos los demás escáneres ignorarán esta opción.
--bay N
La opción --bay selecciona qué compartimento escanear.
--eject
La opción --eject expulsa la hoja en el ADF.
--adf-mode {simplex,duplex}
La opción --adf-mode selecciona el modo ADF (simplex/dúplex).

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/epson2.conf especifica los dispositivos que utilizará el backend. Los tipos de conexión posibles son:

SCSI
Este es el valor predeterminado, y si no se especifica nada más, el software backend abrirá una ruta dada como dispositivo SCSI. Puede encontrar más información sobre la sintaxis válida para dispositivos SCSI en sane-scsi(5).
Normalmente, los escáneres SCSI se configuran con una línea "scsi EPSON" en este archivo. En algunos casos, puede ser necesario usar solo la cadena "scsi" (por ejemplo, para el GT-6500).
PIO - Interfaz Paralela
La interfaz paralela se puede configurar de dos maneras: un valor entero que comienza al principio de una línea se interpretará como la dirección de E/S del puerto paralelo. Para que quede más claro que una dirección de E/S configurada es un puerto paralelo, la dirección del puerto puede ir precedida por la cadena "PIO". La conexión PIO no utiliza un archivo de dispositivo especial en el directorio /dev. La dirección de E/S se puede especificar en modo hexadecimal (precedida por "0x").
USB
Para los escáneres USB que no se detectan automáticamente, sus ID de VENDOR y PRODUCT se pueden especificar manualmente en el archivo de configuración. Puede encontrar más información sobre la sintaxis válida para dispositivos USB en sane-usb(5).
Network
Los escáneres de red pueden ser descubiertos automáticamente si se especifica autodiscovery después de la palabra clave net. También se puede utilizar una dirección IP para conectarse.

ENTORNO

SANE_DEBUG_EPSON2
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Valores más pequeños reducen la verbosidad.
SANE_DEBUG_EPSON2_SCSI
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración relacionado con SCSI para este backend. Solo se admite un valor de 2.
SANE_DEBUG_EPSON2_NET
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración relacionado con la red para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Valores más pequeños reducen la verbosidad.
SANE_EPSON2_CMD_LVL
Esto permite anular la función o el nivel de comando que utiliza el backend para comunicarse con el escáner. El nivel de función que admite un escáner se determina durante la inicialización del dispositivo. Si el backend no reconoce el nivel de función informado por el escáner, utilizará por defecto el nivel de función B3. Los niveles de función válidos son A1, A2, B1, B2, B3, B4, B5, B6, B7, B8, D1 y F5. ¡Use esta función solo si sabe lo que está haciendo!

DISPOSITIVOS NO SOPORTADOS

El backend puede usarse con escáneres Epson que aún no están listados en la lista de dispositivos compatibles. Un escáner que no se reconoce puede usar por defecto el nivel de función B3, lo que significa que no todas las funciones de las que el escáner puede ser capaz son accesibles.

Si el escáner ni siquiera se reconoce como un escáner Epson, esto se debe probablemente a que el nombre del dispositivo informado por el escáner no está en el formato correcto. Por favor, envíe esta información al mantenedor del backend (la dirección de correo electrónico está en la sección AUTOR de esta página de manual o en el archivo AUTHORS de la distribución SANE).
