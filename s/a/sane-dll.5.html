sane-dll(5) SANE Scanner Access Now Easy sane-dll(5)

NOMBRE

sane-dll - Cargador dinámico de backends SANE

DESCRIPCIÓN

La biblioteca sane-dll implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a un número arbitrario de otros backends SANE. Estos backends pueden ser precargados en el momento en que se compila la biblioteca sane-dll o, en sistemas que soportan la carga dinámica de bibliotecas compartidas, los backends pueden ser cargados en tiempo de ejecución. En este último caso, añadir soporte para un nuevo backend simplemente implica instalar la biblioteca relevante en /usr/lib/sane y añadir una entrada al archivo de configuración dll.conf. En otras palabras, ninguna aplicación necesita ser modificada o recompilada para añadir soporte a nuevos dispositivos.

NOMBRES DE DISPOSITIVO

Este backend espera nombres de dispositivo del tipo:

backend:dispositivo

Donde backend es el nombre del backend y dispositivo es el nombre del dispositivo en este backend al que se debe acceder. Si el nombre del dispositivo no contiene dos puntos (:), entonces la cadena entera se trata como la cadena dispositivo para el backend por defecto. El backend por defecto es el backend listado en último lugar en el archivo de configuración (ver más abajo) o el primer backend precargado (si lo hay).

CONFIGURACIÓN

El contenido del archivo dll.conf es una lista de nombres de backends que pueden ser cargados dinámicamente bajo demanda. Las líneas vacías se ignoran, así como todo lo que siga a un signo de almohadilla (#). A continuación se muestra un archivo de configuración de ejemplo:

net
# este es un comentario
pnm
mustek

También es posible añadir un archivo en /etc/sane.d/dll.d que contenga la lista de backends a añadir. Los backends mencionados en un archivo incluido en este directorio se añadirán antes que cualquier backend listado en dll.conf. Los archivos en /etc/sane.d/dll.d pueden tener nombres libremente. Deben seguir las convenciones de formato que se aplican para dll.conf.

Tenga en cuenta que los backends que fueron precargados al construir esta biblioteca no tienen que ser listados en este archivo de configuración. Es decir, si un backend fue precargado, entonces ese backend siempre estará presente, independientemente de si está o no listado en el archivo de configuración.

La lista de backends precargados está determinada por la macro PRELOADABLE_BACKENDS en el archivo backend/Makefile.in de la distribución del código fuente de SANE. Después de cambiar el valor de esta macro, es necesario reconfigurar, reconstruir y reinstalar SANE para que el cambio tenga efecto.

Los alias se definen en el archivo de configuración dll.aliases. Puede contener entradas del tipo


alias SomeName SaneDeviceName
alias "Some Name" SaneDeviceName
hide SaneDeviceName

Por ejemplo:


alias Epson net:somehost:epson:/dev/sgX
alias "Siemens ST400" st400:/dev/sgY
hide net:somehost:pnm:0
hide net:somehost:pnm:1
alias "Leer de archivo" pnm:0
hide pnm:1

Los nombres de dispositivo alias se ocultan automáticamente.

La idea es que los usuarios no tengan que lidiar con nombres de dispositivo complicados (especialmente para dispositivos en red), y para ocultar otros dispositivos exportados que podrían confundirlos. Tenga en cuenta que un dispositivo oculto aún puede ser accedido si se conoce su nombre, simplemente no aparece en la lista.

ARCHIVOS

/etc/sane.d/dll.aliases
La lista de backends alias u ocultos.
/etc/sane.d/dll.conf
El archivo de configuración del backend (ver también la descripción de SANE_CONFIG_DIR más abajo).
/usr/lib/sane/libsane-dll.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-dll.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios se separan por dos puntos (`:'), bajo OS/2, se separan por punto y coma (`;'). Si esta variable no está establecida, el archivo de configuración se busca en dos directorios por defecto: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorios, entonces los directorios por defecto se buscan después de los directorios especificados explícitamente. Por ejemplo, establecer SANE_CONFIG_DIR a "/tmp/config:" resultaría en la búsqueda de los directorios tmp/config, ., y /etc/sane.d (en este orden).
SANE_DEBUG_DLL
Si la biblioteca fue compilada con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad. 
Valor  Descripción
0      imprimir solo errores graves
1      imprimir errores normales y mensajes importantes
2      imprimir mensajes normales
3      imprimir mensajes de depuración
4      imprimir todo

Ejemplo: exportar SANE_DEBUG_DLL=3
