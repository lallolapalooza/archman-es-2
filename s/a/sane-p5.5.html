sane-p5(5) Acceso fácil a escáneres SANE sane-p5(5)

NOMBRE

sane-p5 - Backend SANE para el Primax PagePartner

DESCRIPCIÓN

La biblioteca sane-p5 implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso al escáner de alimentación de hojas Primax PagePartner del puerto paralelo.

Este backend maneja resoluciones de escaneo de 100, 150, 200, 300 y 600 dpi, en modos de color y escala de grises. El 600 dpi es en realidad 300x600 con líneas ampliadas para igualar la resolución vertical.

SOLO MODOS EPP/ECP La versión actual del backend solo usa el modo EPP o ECP para comunicarse con el escáner. Se recomienda configurar el puerto paralelo en EPP en la BIOS con la versión actual de este backend. ECPEPP solo funcionará si usa un kernel 2.4 o 2.6 con soporte para el dispositivo de caracteres ppdev.

NOMBRES DE DISPOSITIVO

Este backend espera nombres de dispositivo del tipo:

puerto valor

Donde valor es:

auto
autodetecta todos los puertos paralelos y los sondea en busca de escáner.
/dev/parport0
usa el dispositivo ppdev de Linux; dependiendo del número de puertos paralelos disponibles, puede que tenga que usar /dev/parport1, /dev/parport2, ...

Puede renombrar cualquier dispositivo usando la opción


nombre_opcion mi_nombre

Esta opción se aplica a la última opción de puerto.

CONFIGURACIÓN

Asegúrese de editar dll.conf antes de usar el backend, ya que este backend no está habilitado por defecto.

ARCHIVOS

/etc/sane.d/p5.conf
El archivo de configuración del backend (ver también la descripción de SANE_CONFIG_DIR más abajo).
/usr/lib/sane/libsane-p5.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-p5.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por un punto y coma (`;'). Si esta variable no está establecida, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorio, entonces los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, establecer SANE_CONFIG_DIR a "/tmp/config:" resultaría en la búsqueda de los directorios tmp/config, . y /etc/sane.d (en este orden).
SANE_DEBUG_P5
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 255 solicita que se imprima toda la salida de depuración. Niveles más pequeños reducen la verbosidad.
nivel   salida de depuración
------- ------------------------------
 0       errores críticos
 1       errores
 2       advertencias y errores menores
 4       mensajes informativos
 8       inicio/fin de funciones
 16      mensajes de rastreo
 32      funciones de E/S
 64      funciones de E/S con rastreos
 128     datos escaneados/de calibración

INFORMES DE ERRORES

Si algo no funciona, envía un correo a sane-devel@alioth-lists.debian.net o envía un problema a través de https://gitlab.com/sane-project/backends/issues/new con la etiqueta backend/p5. Por favor, proporciona la mayor cantidad de información posible.

versión de SANE
ejecuta "scanimage -V" para determinarla.
la versión del backend y el hardware de tu escáner
ejecuta SANE_DEBUG_P5=255 scanimage -L 2>log como root. Si no obtienes ninguna salida del backend p5, asegúrate de que una línea "p5" esté incluida en tu /etc/sane.d/dll.conf. Si tu escáner no es detectado, asegúrate de haber definido la dirección de puerto correcta, o el dispositivo correcto en tu archivo p5.conf.
el nombre de tu escáner/vendedor
información también valiosa. Por favor, incluye también la resolución óptica y el tipo de lámpara de tu escáner, ambos se pueden encontrar en el manual de tu escáner.
comentarios adicionales
si tienes comentarios sobre la documentación (qué podría hacerse mejor), o crees que debería saber algo, por favor inclúyelo.
