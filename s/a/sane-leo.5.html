sane-leo(5) Acceso Sane al Easy del Escáner sane-leo(5)

NOMBRE

sane-leo - Backend SANE para escáneres LEO Technologies

DESCRIPCIÓN

La biblioteca sane-leo implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a algunos escáneres planos SCSI LEO. ¡Este backend debe considerarse software de calidad beta! Los escáneres LEO también se vendieron bajo la marca Across Technologies.

Los escáneres que deberían funcionar con este backend son:

   Fabricante Modelo         estado
----------------------  -----------
  Across FS-1130          probado
  LEO S3                  probado

Las opciones que admite el backend se pueden seleccionar a través de opciones de línea de comandos para programas como scanimage(1) o a través de elementos GUI en xscanimage(1) o xsane(1).

Si experimenta algún comportamiento extraño, por favor, infórmelo al mantenedor del backend o a la lista de correo de SANE.

Las opciones válidas de línea de comandos y su sintaxis se pueden listar usando

scanimage --help -d leo
Modo de escaneo
--modo
selecciona el modo básico de operación del escáner. Las opciones válidas son Blanco y Negro, Escala de Grises y Color. El modo Blanco y Negro es solo blanco y negro (1 bit). El modo Escala de Grises producirá 256 niveles de gris (8 bits). El modo Color producirá una imagen a color de 24 bits.
--resolución
selecciona la resolución para un escaneo. El escáner puede hacer todas las resoluciones entre 1 y 300, en incrementos de 1.
Opciones de geometría
-l -t -x -y
controlan el área de escaneo: -l establece la coordenada x superior izquierda, -t la coordenada y superior izquierda, -x selecciona el ancho y -y la altura del área de escaneo. Todos los parámetros se especifican en milímetros por defecto.
Opciones de mejora
--gamma-personalizada
(solo modo escala de grises y color) permite al usuario especificar una tabla gamma (ver los siguientes 3 parámetros).
--tabla-gamma-roja
(solo modo color) se puede usar para descargar una tabla gamma definida por el usuario para el canal rojo. La tabla debe tener 256 bytes de longitud.
--tabla-gamma-verde
(solo modo color) se puede usar para descargar una tabla gamma definida por el usuario para el canal verde. La tabla debe tener 256 bytes de longitud.
--tabla-gamma-azul
(solo modo color) se puede usar para descargar una tabla gamma definida por el usuario para el canal azul. La tabla debe tener 256 bytes de longitud.
--tramado
(solo Blanco y Negro) selecciona la máscara de tramado a usar. Los valores posibles son Diamante, Tramado Grueso 8x8, Tramado Fino 8x8, Bayer 8x8 y Línea Vertical 8x8.
--vista-previa
solicita un escaneo de vista previa. La resolución utilizada para ese escaneo es de 28 dpi y el área de escaneo es la máxima permitida. El modo de escaneo es seleccionado por el usuario. El valor por defecto es "no".

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/leo.conf solo admite una información: el nombre del dispositivo a usar (ej. /dev/scanner).

ARCHIVOS

/usr/lib/sane/libsane-leo.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-leo.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_DEBUG_LEO
Si la biblioteca fue compilada con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.

LIMITACIONES

El controlador TWAIN de Windows tiene muchas más opciones que este backend SANE. Sin embargo, solo son ajustes de software. Este backend solo implementa lo que el escáner puede soportar.

ERRORES

Ninguno conocido.
