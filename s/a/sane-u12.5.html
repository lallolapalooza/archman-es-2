NOMBRE

sane-u12 - backend de SANE para escáneres planos USB Plustek, basado en diseños antiguos de puerto paralelo

DESCRIPCIÓN

La biblioteca sane-u12 implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a escáneres planos USB Plustek basados en el ASIC 98003 (ASIC de puerto paralelo) de Plustek y un chip puente USB-paralelo de GeneSys Logics.

DISPOSITIVOS SOPORTADOS

El backend es capaz de soportar algunos escáneres USB Plustek tempranos que basaron su antiguo diseño de puerto paralelo en el ASIC 98003 y otros dispositivos Plustek reetiquetados. Las siguientes tablas le darán una breve descripción general.

Si su escáner Plustek tiene otro ID de producto, entonces el dispositivo NO es compatible con este backend.

Fabricante Plustek - ID: 0x07B3 

----------------------------------------------------------
Modelo:                  ID Fabricante:   ID Producto:
----------------------------------------------------------
OpticPro U12             0x07B3           0x0001
OpticPro U1212           0x07B3           0x0001
OpticPro UT12            0x07B3           0x0001

Fabricante KYE/Genius 

--------------------------------------------------------
Modelo USB:              ID Fabricante:   ID Producto:
--------------------------------------------------------
ColorPage Vivid III USB  0x07B3           0x0001
ColorPage HR6 V1         0x0458           0x0458

CONFIGURACIÓN

Para usar su escáner con este backend, necesita al menos dos entradas en el archivo de configuración /etc/sane.d/u12.conf

[usb] id-fabricante id-producto
dispositivo /dev/usbscanner

[usb] le dice al backend que el nombre de dispositivo siguiente (aquí /dev/usbscanner) debe interpretarse como un dispositivo escáner USB. Si el ID del fabricante y el ID del producto no se han especificado, el backend intenta detectarlos por sí mismo. Si el dispositivo está configurado como auto, se utiliza el siguiente dispositivo coincidente.

Las Opciones:

opción warmup t

t especifica el período de calentamiento en segundos

opción lampOff t

t es el tiempo en segundos para apagar las lámparas en modo de espera

opción lOffonEnd b

b especifica el comportamiento al cerrar el backend, 1 --> apagar las lámparas, 0 --> no cambiar el estado de las lámparas

Consulte el archivo u12.conf para ver ejemplos.

Nota: Debe asegurarse de que el subsistema USB esté cargado correctamente y tenga acceso al nodo del dispositivo. Para más detalles, consulte la página del manual sane-usb(5). Puede usar sane-find-scanner(1) para verificar que tiene acceso a su dispositivo.

Nota:
Si no hay archivo de configuración, el backend usa por defecto dispositivo auto

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), bajo OS/2, están separados por un punto y coma (`;'). Si esta variable no está establecida, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorios, entonces los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, establecer SANE_CONFIG_DIR a "/tmp/config:" resultaría en que los directorios tmp/config, ., y /etc/sane.d sean buscados (en este orden).
SANE_DEBUG_U12
Si la biblioteca fue compilada con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Niveles de depuración más altos incrementan la verbosidad de la salida.

Ejemplo: exportar SANE_DEBUG_U12=10

CONTACTO Y ERRORES

Por favor, envíe cualquier información e informe de errores a:
Lista de Correo de SANE

Puede obtener información adicional y consejos del archivo de nuestra lista de correo en: http://www.sane-project.org/mailing-lists.html.

Para obtener mensajes de depuración del backend, configure la variable de entorno SANE_DEBUG_U12 antes de llamar a su frontend SANE favorito (por ejemplo, xscanimage(1)):

exportar SANE_DEBUG_U12=20 ; xscanimage

El valor controla la verbosidad del backend.

BUGS CONOCIDOS Y RESTRICCIONES

* El controlador está en estado alfa, ¡¡¡así que por favor no espere demasiado!!!

* Al usar libusb, es posible que el backend se cuelgue. En ese caso, vuelva a conectar el escáner.
