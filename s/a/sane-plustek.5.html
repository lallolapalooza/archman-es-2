NOMBRE

sane-plustek - Backend de SANE para escáneres planos USB basados en LM983[1/2/3]

DESCRIPCIÓN

La biblioteca sane-plustek implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a escáneres planos USB basados en los chipsets Merlin de National Semiconductor (LM9831, 9832 y 9833). Si está buscando soporte para puertos paralelos para escáneres Plustek, consulte el backend sane-plustek_pp(5).

DISPOSITIVOS SOPORTADOS

El backend puede soportar escáneres USB basados en los chipsets LM9831, LM9832 y LM9833 de National Semiconductor. OTROS ESCÁNERES PLUSTEK

Para soporte de dispositivos de puerto paralelo, consulte el backend sane-plustek_pp(5).
El escáner SCSI OpticPro 19200S es un escáner Artec AM12S reetiquetado y es soportado por el backend sane-artec(5).
Solo los dispositivos Plustek basados en National Semiconductor LM983[1/2/] son soportados por este backend. Las versiones anteriores del U12, el UT12, el U1212 y el U1248 (chipset GrandTech) no son soportadas.

CONFIGURACIÓN

Para usar su escáner con este backend, necesita al menos dos entradas en el archivo de configuración /etc/sane.d/plustek.conf

[usb] id-proveedor id-producto
dispositivo /dev/usbscanner

[usb] le dice al backend que el nombre de dispositivo siguiente (aquí /dev/usbscanner) tiene que ser interpretado como dispositivo de escáner USB. Si el ID de proveedor y producto no se han especificado, el backend intenta detectarlos por sí mismo. Si el dispositivo está configurado como auto, se usará el siguiente dispositivo coincidente.
Las siguientes opciones pueden ser usadas para una configuración por defecto de su dispositivo. La mayoría de ellas también están disponibles a través del frontend.

Las Opciones:

opcion warmup t

t especifica el período de calentamiento en segundos; si se establece en -1, se utilizará la función automática de calentamiento.

opcion lampOff t

t es el tiempo en segundos para apagar las lámparas en modo de espera.

opcion lOffonEnd b

b especifica el comportamiento al cerrar el backend: 1 --> apagar las lámparas, 0 --> no cambiar el estado de las lámparas.

opcion mov m

m es el modificador de modelo. Solo funciona con dispositivos Mustek BearPaw. 
m/PID |    0x1000    |    0x1001
------+--------------+--------------
  0   | BearPaw 1200 | BearPaw 2400
  1   |  sin función | BearPaw 1200

opcion invertNegatives b

b 0 --> no invertir la imagen durante escaneos de negativos,
1 --> invertir imagen.

opcion cacheCalData b

b 0 --> no guardar los resultados de calibración,
1 --> guardar los resultados de calibración en el directorio ~/.sane/.

opcion altCalibration b

b 0 --> usar rutinas de calibración estándar,
1 --> usar calibración alternativa (solo dispositivos no Plustek, estándar para dispositivos CIS).

opcion skipFine b

b 0 --> realizar calibración fina,
1 --> omitir.

CONFIGURATION

El archivo de configuración permite al usuario ajustar algunos parámetros del backend. El archivo de configuración se llama plustek.conf y reside en el directorio /etc/sane.d. Si el archivo no existe, se utiliza la configuración predeterminada. Todas las opciones de configuración son opcionales. Los valores predeterminados se utilizan para cualquier opción que no esté presente en el archivo de configuración.

El formato del archivo de configuración es una opción por línea, y cada línea puede contener una opción y un argumento. Las líneas que comienzan con un carácter `#` se tratan como comentarios.

Las siguientes opciones de configuración están disponibles:

option device
option device-name

device /dev/scanner
device-name 0x0703:0x0007

Especifica el dispositivo a utilizar. Puede ser un nombre de dispositivo o un par de ID de producto/vendor en formato hexadecimal.

option buffer-size

buffer-size 1048576

Establece el tamaño del búfer USB para transferencias de datos. El valor predeterminado es 1 MB.

option swap-endian

swap-endian 0 o 1

Si se establece en 1, intercambia el orden de los bytes de los datos del sensor. Esto puede ser necesario para algunos escáneres.

option skip-calibration

skip-calibration 0 o 1

Si se establece en 1, omite el proceso de calibración. Esto puede ser útil si la calibración está fallando o si desea acelerar el proceso de escaneo. Sin embargo, es posible que la calidad de la imagen se vea afectada.

option fine-calibration

fine-calibration 0 o 1

Si se establece en 0, realiza una calibración fina. Si se establece en 1, omite la calibración fina (solo dispositivos no Plustek).

option skipFineWhite b

b 0 --> realizar calibración blanca fina,
1 --> omitir calibración blanca fina (solo dispositivos no Plustek)

option skipDarkStrip b

b 0 --> realizar calibración oscura, con lámpara activada utilizando la tira de calibración oscura del escáner. Si el escáner no tiene dicha tira, la forma alternativa es apagar la lámpara durante este paso.
1 --> apagar siempre la lámpara para la calibración oscura, incluso si hay una tira negra disponible

option skipCalibration b

b 0 --> realizar calibración,
1 --> omitir calibración (solo dispositivos no Plustek)

option enableTPA b

b 0 --> comportamiento predeterminado, especificado por las tablas internas,
1 --> anular las tablas internas y permitir el modo TPA (solo EPSON/UMAX)

option posOffX x
option posOffY y
option tpaOffX x
option tpaOffY y
option negOffX x
option negOffY y

x y Usando estas configuraciones, el usuario puede ajustar las posiciones de imagen dadas. Tenga en cuenta que no hay ninguna verificación de rango interna para esta función.

option posShadingY p
option tpaShadingY p
option negShadingY p

p anula la posición de sombreado interna. Los valores están en pasos. Tenga en cuenta que no hay ninguna verificación de rango interna para esta función.

option redGamma r
option greenGamma g
option blueGamma b
option grayGamma gr

r g b gr
Usando estos valores, la tabla gamma lineal interna (r,g,b,gr = 1.0) puede ser ajustada.

option red_gain r
option red_offset ro
option green_gain g
option green_offset go
option blue_gain b
option blue_offset bo

r g b ro go bo Estos valores se pueden utilizar para establecer los valores de ganancia y desplazamiento del AFE para cada canal. El rango está entre 0 y 63. -1 significa autocaliibración.

Vea el archivo plustek.conf para ver ejemplos.

Nota:
Debe asegurarse de que el subsistema USB esté cargado correctamente y de que tenga acceso al nodo del dispositivo. Para más detalles, consulte la página del manual sane-usb(5). Es posible que desee utilizar sane-find-scanner(1) para comprobar que tiene acceso a su dispositivo.

Nota:
Si no hay ningún archivo de configuración, el backend utiliza el valor predeterminado device auto

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por un punto y coma (`;'). Si esta variable no está establecida, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (`.'') y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorio, entonces los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, establecer SANE_CONFIG_DIR en "/tmp/config:" resultaría en los directorios tmp/config, ., y /etc/sane.d que se buscarían (en este orden).
SANE_DEBUG_PLUSTEK
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Niveles de depuración más altos aumentan la verbosidad de la salida.

Ejemplo: export SANE_DEBUG_PLUSTEK=10

CONTACTO Y REPORTES DE ERRORES

Por favor, envíe cualquier información y reporte de errores a:
Lista de Correo de SANE

Información adicional y pistas se pueden obtener de nuestro archivo de lista de correo en: http://www.sane-project.org/mailing-lists.html.

Para obtener mensajes de depuración del backend, establezca la variable de entorno SANE_DEBUG_PLUSTEK antes de llamar a su frontend SANE favorito (por ejemplo, scanimage(1)):

export SANE_DEBUG_PLUSTEK=20 ; scanimage

El valor controla la verbosidad de la salida. Tenga en cuenta que los valores mayores que 24 fuerzan al backend a generar archivos de datos sin procesar que podrían ser bastante grandes. El sufijo de estos archivos es ".raw". Para reportes de problemas, debería ser suficiente establecer la verbosidad en 13.

ERRORES CONOCIDOS Y RESTRICCIONES

* El controlador no soporta estas escaladas maniáticas hasta 16 veces la resolución física. La única escalada se realiza en resoluciones entre la resolución física del sensor CCD/CIS y el motor paso a paso, es decir, tiene un escáner de 600x1200 dpi y está escaneando usando 800 dpi, por lo que la escalada es necesaria, ya que el sensor solo proporciona 600 dpi pero el motor es capaz de realizar pasos de 1200 dpi.

* La política de modelos de Plustek es algo inconsistente. Venden dispositivos técnicamente diferentes bajo el mismo nombre de producto. Por lo tanto, es posible que algunos dispositivos como UT12 o U12 no funcionen; consulte la lista de modelos anterior y compare el ID del producto con el que tiene su dispositivo.

* La calidad de escaneo de negativos/diapositivas es pobre.
