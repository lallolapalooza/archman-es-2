sane-niash(5) SANE Scanner Access Now Easy sane-niash(5)

NOMBRE

sane-niash - Backend de SANE para escáneres basados en el chipset NIASH

DESCRIPCIÓN

El sane-niash implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a escáneres basados en el chipset NIASH. Este backend intentará soportar los siguientes modelos:

FABRICANTE:      MODELO:           ID USB:
---------------  ----------------  ---------
Agfa             Snapscan Touch    06BD-0100 (1)(a)
Trust            Office Scan 19200 047B-1000 (1)(a)
Hewlett-Packard  Scanjet 3300c     03F0-0205 (1)(a)(b)
Hewlett-Packard  Scanjet 3400c     03F0-0405 (2)(b)
Hewlett-Packard  Scanjet 4300c     03F0-0305 (2)(a)
Silitek          ScanJet 4300c     047B-1002 (2)(b)

ASIC: (1) - NIASH00012/00013/00014 / (2) - NIASH00019
FRONT-END ANALÓGICO: (a) - ESIC ES8100QA / (b) - WM8143-12

CONFIGURACIÓN

El archivo niash.conf está destinado a futuras opciones de configuración. Las líneas vacías y las líneas que comienzan con un signo de almohadilla (#) se ignoran. Actualmente no existen opciones de configuración.

ARCHIVOS

/usr/lib/sane/libsane-niash.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-niash.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ADVERTENCIAS

Si usa un
Hewlett-Packard Scanjet 3400c o
Hewlett-Packard Scanjet 4300c
junto con el kernel de Linux 2.6, se requiere la versión del kernel 2.6.8 o superior.

ENTORNO

SANE_DEBUG_NIASH
Si la biblioteca se compiló con el soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Niveles de depuración más altos aumentan la verbosidad de la salida.

Ejemplo: export SANE_DEBUG_NIASH=255
