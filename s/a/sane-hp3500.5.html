NOMBRE

sane-hp3500 - Backend de SANE para escáneres Hewlett-Packard ScanJet serie 3500

DESCRIPCIÓN

La biblioteca sane-hp3500 implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a los siguientes escáneres planos USB de Hewlett-Packard:

ScanJet 3500C
ScanJet 3530C
ScanJet 3570C

Si posee un escáner que no sea uno de los enumerados anteriormente que funcione con este backend, por favor háganoslo saber enviándonos el nombre exacto del modelo del escáner y los IDs de proveedor y dispositivo USB (por ejemplo, de /proc/bus/usb/devices, sane-find-scanner (1) o syslog). Incluso si el nombre del escáner es solo ligeramente diferente de los modelos mencionados anteriormente, por favor háganoslo saber.

CONFIGURACIÓN

No se requiere ninguna.

ARCHIVOS

/usr/lib/sane/libsane-hp3500.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-hp3500.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_DEBUG_HP3500 Si la biblioteca fue compilada con soporte de depuración activado, esta variable de entorno controla el nivel de depuración para este backend. Niveles de depuración más altos aumentan la verborrea de la salida.

Ejemplo: export SANE_DEBUG_HP3500=4
