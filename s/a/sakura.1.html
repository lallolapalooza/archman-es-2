NOMBRE

sakura - Un emulador de terminal simple pero potente basado en libvte.

SINOPSIS

sakura [opciones...]

DESCRIPCIÓN

sakura es un emulador de terminal basado en GTK+ y VTE. Es un emulador de terminal con pocas dependencias, por lo que no necesitas un escritorio GNOME completo instalado para tener un emulador de terminal decente.

OPCIONES DE AYUDA

Mostrar opciones de ayuda.
--help-all
Mostrar todas las opciones de ayuda

SOPORTE DE COMBINACIONES DE TECLAS

sakura soporta combinaciones de teclas. Son configurables estableciendo las siguientes propiedades en tu archivo de configuración de sakura (~/.config/sakura/sakura.conf).

ACELERADORES

Los aceleradores se pueden establecer a cualquier valor de máscara del GdkModifierType en gdktypes.h; ver:

http://gtk.php.net/manual/en/html/gdk/gdk.enum.modifiertype.html

Los valores de máscara se pueden combinar mediante OR.

Por ejemplo, para establecer el acelerador de eliminar pestaña a Ctrl + Shift:

del_tab_accelerator=5

ya que GDK_SHIFT_MASK tiene un valor de 1 (1 << 0), y GDK_CONTROL_MASK tiene un valor de 4 (1 << 2); combinándolos, obtienes 5.

Me doy cuenta de que esta configuración no es muy amigable para los no programadores, pero es un comienzo. :)

TECLAS

Por ejemplo, para establecer la tecla de agregar pestaña a 'T':

add_tab_key=T

Antes sakura usaba códigos de tecla en lugar de cadenas. Todavía son válidos.

VALORES PREDETERMINADOS

Ctrl + Shift + T                 -> Nueva pestaña
Ctrl + Shift + W                 -> Cerrar pestaña actual
Ctrl + Shift + C                 -> Copiar texto seleccionado
Ctrl + Shift + V                 -> Pegar texto seleccionado
Flecha izquierda + Ctrl          -> Pestaña anterior
Flecha derecha + Ctrl            -> Pestaña siguiente
Ctrl + [1-9]                     -> Cambiar a la pestaña N (1-9)
Ctrl + Shift + S                 -> Alternar barra de desplazamiento
Ctrl + Shift + Botón izquierdo del ratón -> Abrir enlace
F11                              -> Pantalla completa
Shift + Re Pág                   -> Mover hacia arriba en el historial por página
Shift + Av Pág                   -> Mover hacia abajo en el historial por página
Ctrl + Shift + Arriba            -> Mover hacia arriba en el historial por línea
Ctrl + Shift + Abajo             -> Mover hacia abajo en el historial por línea

También puedes aumentar y disminuir el tamaño de la fuente de la forma estándar de GTK+ (no configurable):

Ctrl + '+'                       -> Aumentar tamaño de fuente
Ctrl + '-'                       -> Disminuir tamaño de fuente
