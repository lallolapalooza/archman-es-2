NOMBRE

sattach - Adjuntar a un paso de trabajo de Slurm.

SINOPSIS

sattach [opciones] <jobid.stepid>

DESCRIPCIÓN

sattach se adjunta a un paso de trabajo de Slurm en ejecución. Al adjuntarse, hace disponibles las secuencias de E/S de todas las tareas de un paso de trabajo de Slurm en ejecución. También es adecuado para su uso con un depurador paralelo como TotalView. No se puede utilizar para adjuntarse directamente a pasos extern o batch, ya que los canales de E/S de estos pasos no se establecen ni se reenvían directamente a un archivo.

OPCIONES

--error-filter[=]<número de tarea>
Transmite solo la entrada estándar a una única tarea, o imprime la salida estándar o el error estándar de una única tarea. El filtrado se realiza localmente en sattach.
-h, --help
Muestra la información de ayuda y sale.
--input-filter[=]<número de tarea>
Transmite solo la entrada estándar a una única tarea, o imprime la salida estándar o el error estándar de una única tarea. El filtrado se realiza localmente en sattach.
-l, --label
Antepone a cada línea de salida estándar o error estándar de la tarea el número de la tarea de su origen.
--layout
Contacta con slurmctld para obtener la información de distribución de tareas para el paso de trabajo, imprime la información de distribución de tareas y luego sale sin adjuntarse al paso de trabajo.
--output-filter[=]<número de tarea>
Transmite solo la entrada estándar a una única tarea, o imprime la salida estándar o el error estándar de una única tarea. El filtrado se realiza localmente en sattach.
--pty
Ejecuta la tarea cero en una pseudo-terminal. No es compatible con las opciones --input-filter, --output-filter o --error-filter. Notas: sattach ignora el tamaño de la terminal y los eventos de redimensionamiento. El funcionamiento correcto requiere que el paso de trabajo se inicie con srun utilizando la opción --pty.
-Q, --quiet
Suprime los mensajes informativos de sattach. Los errores seguirán mostrándose.
-u, --usage
Muestra un breve mensaje de uso y sale.
-V, --version
Muestra el número de versión de Slurm y sale.
-v, --verbose
Aumenta la verbosidad de los mensajes informativos de sattach. Múltiples

RENDIMIENTO

Ejecutar sattach envía una llamada de procedimiento remoto a slurmctld. Si llegan a la vez suficientes llamadas de sattach u otros comandos cliente de Slurm que envían llamadas de procedimiento remoto al demonio slurmctld, puede resultar en una degradación del rendimiento del demonio slurmctld, lo que podría provocar una denegación de servicio.

No ejecute sattach u otros comandos cliente de Slurm que envíen llamadas de procedimiento remoto a slurmctld desde bucles en scripts de shell u otros programas. Asegúrese de que los programas limiten las llamadas a sattach al mínimo necesario para la información que intenta recopilar.

VARIABLES DE ENTORNO DE ENTRADA

Al inicio, salloc leerá y manejará las opciones establecidas en las siguientes variables de entorno. Nota: Las opciones de la línea de comandos siempre anulan la configuración de las variables de entorno.

SLURM_CONF
La ubicación del archivo de configuración de Slurm.
SLURM_DEBUG_FLAGS
Especifica las banderas de depuración que utilizará sattach. Consulte DebugFlags en la página del manual de slurm.conf(5) para obtener una lista completa de banderas. La variable de entorno tiene precedencia sobre la configuración en slurm.conf.
SLURM_EXIT_ERROR
Especifica el código de salida generado cuando ocurre un error de Slurm (por ejemplo, opciones no válidas). Esto puede ser utilizado por un script para distinguir los códigos de salida de la aplicación de varias condiciones de error de Slurm.

EJEMPLOS

Adjuntar al trabajo 15, paso 0:
$ sattach 15.0
Limitar la salida a la 5ª tarea del trabajo 65386, paso 15:
$ sattach --output-filter 5 65386.15

slurm-llnl - SLURM workload manager

NAME
slurm-llnl - SLURM workload manager
SYNOPSIS
sattach [OPTIONS] <job_id> [OPTIONS]
DESCRIPTION
The sattach command is used to attach to the standard input, output, and error streams of a running SLURM job. This command is useful for interactive debugging or for retrieving output from jobs that have not yet completed.
OPTIONS
-i, --input
Attach to the standard input stream of the job.
-o, --output
Attach to the standard output stream of the job.
-e, --error
Attach to the standard error stream of the job.
-a, --all
Attach to all streams (input, output, and error).
-t, --timeout <seconds>
Set a timeout for the attachment in seconds. If the attachment is not successful within the specified time, the command will exit.
-v, --verbose
Enable verbose output.
-h, --help
Display a help message and exit.
PERFORMANCE
The performance of sattach depends on the network connectivity and the SLURM configuration. For optimal performance, ensure that the client and the SLURM daemons are on the same network.
INPUT ENVIRONMENT VARIABLES
The following environment variables can affect the behavior of sattach:
SLURM_CONF
Path to the SLURM configuration file.
EXAMPLES
Attach to the standard output and error streams of job 12345:
sattach -o -e 12345
Attach to all streams of job 67890 with a timeout of 30 seconds:
sattach -a -t 30 67890
