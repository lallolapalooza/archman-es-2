saquery(8) Diagnósticos Open IB saquery(8)

Nombre

saquery - consultar atributos de administración de subred InfiniBand

SINOPSIS

saquery [opciones] [<nombre> | <lid> | <guid>]

DESCRIPCIÓN

saquery emite la consulta SA seleccionada. Se consultan registros de nodos de forma predeterminada.

OPCIONES

-p
obtener información de PathRecord
-N
obtener información de NodeRecord
-D, --list
obtener solo las Descripciones de Nodos de las CA
-S
obtener información de ServiceRecord
-I
obtener información de InformInfoRecord (suscripción)
-L
devolver los Lids del nombre especificado
-l
devolver el Lid único del nombre especificado
-G
devolver los Guids del nombre especificado
-O
devolver el nombre para el Lid especificado
-U
devolver el nombre para el Guid especificado
-c
obtener información del puerto de clase de la SA
-s
devolver los PortInfoRecords con el bit de máscara de capacidad isSM o isSMdisabled activado
-g
obtener información de grupo multicast
-m
obtener información de miembro multicast. Si se especifica un grupo, limitar la salida al grupo especificado e imprimir una línea que contenga solo el GUID y la descripción del nodo para cada entrada. Ejemplo: saquery -m 0xc000
-x
obtener información de LinkRecord
--src-to-dst <src:dst>
obtener un PathRecord para <src:dst> donde src y dst son nombres de nodo o LIDs
--sgid-to-dgid <sgid:dgid>
obtener un PathRecord de sgid a dgid donde ambos GIDs están en un formato IPv6 aceptable para inet_pton (3)
--smkey <val>
usar el valor de SM_Key para la consulta. Solo se usará con consultas "confiables". Si se especifica un valor no numérico (como 'x'), saquery solicitará un valor. El valor predeterminado (cuando no se especifica aquí ni en /etc/infiniband-diags/ibdiag.conf) es usar SM_Key == 0 (o "no confiable")
-K, --show_keys
mostrar las claves de seguridad (mkey, smkey, etc.) asociadas con la solicitud.

--slid <lid> LID de origen (PathRecord)

--dlid <lid> LID de destino (PathRecord)

--mlid <lid> LID multicast (MCMemberRecord)

--sgid <gid> GID de origen (formato IPv6) (PathRecord)

--dgid <gid> GID de destino (formato IPv6) (PathRecord)

--gid <gid> GID de puerto (MCMemberRecord)

--mgid <gid> GID multicast (MCMemberRecord)

--reversible Camino reversible (PathRecord)

--numb_path Número de caminos (PathRecord)

--pkey P_Key (PathRecord, MCMemberRecord). Si se especifica un valor no numérico (como 'x')
entonces saquery solicitará un valor

--qos_class Clase QoS (PathRecord)

--sl Nivel de servicio (PathRecord, MCMemberRecord)

--mtu MTU y selector (PathRecord, MCMemberRecord)

--rate Tasa y selector (PathRecord, MCMemberRecord)

--pkt_lifetime Vida útil del paquete y selector (PathRecord, MCMemberRecord)

--qkey Q_Key (MCMemberRecord). Si se especifica un valor no numérico (como 'x')
entonces saquery solicitará un valor

--tclass Clase de tráfico (PathRecord, MCMemberRecord)

--flow_label Etiqueta de flujo (PathRecord, MCMemberRecord)

--hop_limit Límite de saltos (PathRecord, MCMemberRecord)

--scope Alcance (MCMemberRecord)

--join_state Estado de unión (MCMemberRecord)

--proxy_join Unión proxy (MCMemberRecord)

--service_id ServiceID (PathRecord)

ClassPortInfo (CPI)

PortInfoRecord (PIR) [[lid]/[puerto]/[opciones]]
SL2VLTableRecord (SL2VL) [[lid]/[puerto_entrada]/[puerto_salida]]
PKeyTableRecord (PKTR) [[lid]/[puerto]/[bloque]]
VLArbitrationTableRecord (VLAR) [[lid]/[puerto]/[bloque]]
InformInfoRecord (IIR)
LinkRecord (LR) [[lid_origen]/[puerto_origen]] [[lid_destino]/[puerto_destino]]
ServiceRecord (SR)
PathRecord (PR)
MCMemberRecord (MCMR)
LFTRecord (LFTR) [[lid]/[bloque]]
MFTRecord (MFTR) [[mlid]/[posicion]/[bloque]]
GUIDInfoRecord (GIR) [[lid]/[bloque]]
SwitchInfoRecord (SWIR) [lid]
SMInfoRecord (SMIR) [lid]

Banderas de selección de puerto

-C, --Ca <nombre_ca> usar el nombre_ca especificado.

-P, --Port <puerto_ca> usar el puerto_ca especificado.

Selección de puerto local

Soporte de múltiples puertos/múltiples CA: cuando no se especifica ningún dispositivo o puerto IB (ver los "parámetros umad locales" a continuación), la biblioteca libibumad selecciona el puerto a usar según los siguientes criterios:

1.
el primer puerto que esté ACTIVO.
2.
si no se encuentra, el primer puerto que esté ARRIBA (enlace físico arriba).

Si se especifica un puerto y/o un nombre de CA, la biblioteca libibumad intenta cumplir la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                 # usa el primer puerto (criterio #1 anterior)
ibaddr -C mthca1       # selecciona el mejor puerto solo de "mthca1".
ibaddr -P 2            # usa el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usa solo el puerto especificado.

Banderas de depuración

-d
aumenta el nivel de depuración de IB. Puede usarse varias veces (-ddd o -d -d -d).
-e
muestra errores de envío y recepción (tiempos de espera y otros)

-h, --help muestra el mensaje de uso

-v, --verbose
aumenta el nivel de verbosidad de la aplicación. Puede usarse varias veces (-vv o -v -v -v)

-V, --version muestra la información de la versión.

Banderas de configuración

-t, --timeout <timeout_ms> anula el tiempo de espera predeterminado para los mads solicitados.

--outstanding_smps, -o <val>
Especifica el número de SMPs pendientes que deben emitirse durante el escaneo.

Predeterminado: 2

--node-name-map <mapa-nombres-nodo> Especifica un mapa de nombres de nodo.

Este archivo mapea GUIDs a nombres más amigables para el usuario. Ver la sección ARCHIVOS.

--config, -z <archivo_config> Especifica un archivo de configuración alternativo.

ARCHIVOS COMUNES

ARCHIVO DE CONFIGURACION

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener más detalles.

FORMATO DEL ARCHIVO DE MAPA DE NOMBRES DE NODOS

El mapa de nombres de nodos se utiliza para especificar nombres amigables para los nodos en la salida. Las GUID se utilizan para realizar la búsqueda.

Esta funcionalidad es proporcionada por el paquete opensm-libs. Consulte opensm(8) para conocer la ubicación del archivo en su instalación.

Genéricamente:

# comentario
<guid> "<nombre>"

Ejemplo:

# IB1
# Tarjetas de línea
0x0008f104003f125c "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f125d "IB1 (Rack 11 slot 1   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10d2 "IB1 (Rack 11 slot 2   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10d3 "IB1 (Rack 11 slot 2   ) ISR9288/ISR9096 Voltaire sLB-24D"
0x0008f104003f10bf "IB1 (Rack 11 slot 12  ) ISR9288/ISR9096 Voltaire sLB-24D"
# Spines
0x0008f10400400e2d "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2e "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e2f "IB1 (Rack 11 spine 1   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e31 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
0x0008f10400400e32 "IB1 (Rack 11 spine 2   ) ISR9288 Voltaire sFB-12D"
# GUID   Node Name
0x0008f10400411a08 "SW1  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f10400411a28 "SW2  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f10400411a34 "SW3  (Rack  3) ISR9024 Voltaire 9024D"
0x0008f104004119d0 "SW4  (Rack  3) ISR9024 Voltaire 9024D"

DEPENDENCIAS

OpenSM (u otra SM/SA en ejecución), libosmcomp, libibumad, libibmad
