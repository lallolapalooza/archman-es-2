NOMBRE

sane-hp - Backend SANE para escáneres HP ScanJet

DESCRIPCIÓN

La biblioteca sane-hp implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a escáneres HP ScanJet que soportan SCL (Scanner Control Language de HP). Los siguientes escáneres se sabe que funcionan positivamente con este backend:

Modelo:         ID de producto:     Interfaz:
----------     -----------     ----------
ScanJet Plus   C9195A          Tarjeta de interfaz paralela HP
ScanJet IIc    C1750A 3226     SCSI
ScanJet IIcx   C2500A 3332     SCSI
ScanJet IIp    C1790A          SCSI
ScanJet 3C     C2520A 3503     SCSI
ScanJet 3P     C2570A 3406     SCSI
ScanJet 4C     C2520A          SCSI
ScanJet 4P     C1130A 3540     SCSI
ScanJet 4100C  C6290A          USB
ScanJet 5P     C5110A          SCSI
ScanJet 5100C  C5190A          puerto paralelo
ScanJet 5200C  C7190A 3846     puerto paralelo/USB
ScanJet 6100C  C2520A 3644     SCSI
ScanJet 6200C  C6270A 3828     SCSI/USB
ScanJet 6250C  C6270A 3828     SCSI/USB
ScanJet 6300C  C7670A          SCSI/USB
ScanJet 6350C  C7670A          SCSI/USB
ScanJet 6390C  C7670A          SCSI/USB
PhotoSmart     C5100A R029,R030,R032    SCSI

El soporte para los modelos 5100C/5200C conectados al puerto paralelo requiere el controlador ppSCSI disponible en http://cyberelk.net/tim/parport/ppscsi.html y http://penguin-breeder.org/kernel/download/.

El soporte para los modelos 5200C/62X0C/63X0C conectados a USB requiere libusb. Ver sane-usb(5) para más detalles.

El backend sane-hp ya no soporta periféricos multifunción OfficeJet. Para estos dispositivos, use los paquetes externos "hplip" disponibles en: https://developers.hp.com/hp-linux-imaging-and-printing/. Para información sobre el controlador hpoj anterior, ver: http://hpoj.sourceforge.net/.

Debido a que Hewlett-Packard ya no produce escáneres que soporten SCL (aparte de los OfficeJets), la lista anterior de escáneres soportados es completa. Otros escáneres HP no son soportados por el backend sane-hp, pero podrían ser soportados por otro. Ver http://www.sane-project.org/. También puede seguir la lista de correo sane-devel en http://www.sane-project.org/mailing-lists.html.

Se pueden encontrar más detalles sobre el backend hp en su página principal http://web.archive.org/web/20070206115546/http://www.kirchgessner.net/sane.html.

NOMBRES DE DISPOSITIVO

Este backend espera nombres de dispositivo del tipo:

especial

Donde especial es el nombre de la ruta UNIX para el dispositivo especial que corresponde al escáner. Para escáneres SCSI, el nombre del dispositivo especial debe ser un dispositivo SCSI genérico o un enlace simbólico a dicho dispositivo. En Linux, un nombre de dispositivo así podría ser /dev/sga o /dev/sg2, por ejemplo. Si el nombre del dispositivo especial contiene "usb", "uscanner" o "ugen", se asume que el escáner está conectado por USB. Para el HP ScanJet Plus, el nombre del dispositivo especial debe ser el dispositivo que corresponde a la tarjeta de interfaz paralela que se envió con el escáner. Ese es /dev/hpscan. Se requiere un controlador especial para esta tarjeta. Ver ftp://rvs.ctrl-c.liu.se/pub/wingel/hpscan para detalles. Si el enlace no funciona, intente ftp://sunsite.unc.edu/pub/Linux/kernel/patches/scanners.

CONFIGURACIÓN

El contenido del archivo hp.conf es una lista de opciones y nombres de dispositivo que corresponden a los escáneres HP ScanJet. Las líneas vacías y las líneas que comienzan con un signo de almohadilla (#) se ignoran. Ver sane-scsi(5) y sane-usb(5) para detalles sobre qué constituye un nombre de dispositivo válido.

Las opciones especificadas antes de la primera línea que contiene un nombre de dispositivo son los valores predeterminados para todos los dispositivos. Las opciones especificadas debajo de una línea que contiene un nombre de dispositivo se aplican solo al dispositivo mencionado más recientemente.

Las opciones soportadas son connect-scsi, connect-device, enable-image-buffering y dumb-read.

La opción connect-scsi especifica que el escáner está conectado al sistema por SCSI. La entrada/salida se realiza utilizando comandos SCSI. Este es el valor predeterminado. Pero si el nombre de su dispositivo SCSI contiene "usb", "uscanner" o "ugen", se debe especificar la opción connect-scsi. De lo contrario, se asume que el escáner está conectado por USB.

La opción connect-device especifica que el escáner está conectado al sistema por un dispositivo especial. La entrada/salida se realiza mediante operaciones read()/write() en el dispositivo. Esta opción debe usarse para HP ScanJet Plus o escáneres conectados a USB que se acceden a través de un dispositivo con nombre (por ejemplo, /dev/usb/scanner0). Para nombres de dispositivo que contienen "usb", "uscanner" o "ugen", no es necesario especificar la opción connect-device.

La opción enable-image-buffering almacena la imagen escaneada en memoria antes de pasarla al frontend. Podría usarse en caso de lámpara del escáner que se mueve hacia adelante/atrás.

La opción dumb-read puede usarse para solucionar problemas con "Error durante E/S del dispositivo". Estos problemas pueden ocurrir con ciertos convertidores SCSI a USB o tarjetas SCSI Buslogic. La opción no debe usarse para dispositivos SCSI que funcionan correctamente. De lo contrario, el inicio de los frontends y el cambio de parámetros podrían ser más lentos.

A continuación se muestra un archivo de configuración de ejemplo:

/dev/scanner
# esto es un comentario
/dev/hpscan
option connect-device

/dev/scanner es típicamente un enlace simbólico al dispositivo escáner SCSI real.

ARCHIVOS

/etc/sane.d/hp.conf
El archivo de configuración del backend (ver también la descripción de SANE_CONFIG_DIR más abajo).
/usr/lib/sane/libsane-hp.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-hp.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).
$HOME/.sane/calib-hp:<device>.dat
Datos de calibración para HP PhotoSmart PhotoScanner que se recuperan del escáner después de la calibración. Los datos se cargan en el escáner al inicio del backend si está en modo de medios 'imprimir medios' o si el modo de medios se cambia a 'imprimir medios'.

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:') , en OS/2, están separados por un punto y coma (`;'). Si esta variable no está configurada, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (.) y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorio, entonces los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, configurar SANE_CONFIG_DIR a "/tmp/config:" resultaría en la búsqueda de los directorios tmp/config, ., y /etc/sane.d (en este orden).
SANE_DEBUG_HP
Si la biblioteca fue compilada con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.
SANE_HOME_HP
Solo se usa para OS/2 y junto con el uso de HP PhotoSmart PhotoScanner. Debe configurarse al directorio donde se encuentra el directorio .sane. Se utiliza para guardar y leer el archivo de calibración.

sane-hp(5) — Arch Linux man pages

NAME

sane-hp — SANE backend for HP ScanJet scanners

DESCRIPTION

The sane-hp library is a backend for SANE (Scanner Access Now Easy) that supports a variety of HP ScanJet and PhotoSmart scanners.

DEVICE NAMES

This backend supports the following device names:

hp:usb[:<Bus>/<Device>]
If there are multiple USB scanners attached, you can specify the scanner by its Bus and Device number. If omitted, the first available USB scanner is used.
hp:scanner[:<DeviceFile>]
For SCSI scanners. <DeviceFile> is optional. If omitted, sane-scsi(5) is used to find the scanner.
hp:parallel[:<DeviceFile>]
For parallel port scanners. The default <DeviceFile> is /dev/parport0.

CONFIGURATION

The configuration file for this backend is named sane.d(5).

The file sane-hp.conf(5)

contains configuration information specific to the sane-hp backend. This file is located in the @sconfdir@ directory.

The configuration options are listed below. If an option is listed under a certain device type (e.g. USB, SCSI, Parallel), it will only be applied to that device type. If an option is listed as global, it will be applied to all device types. Note that options can be specified multiple times.

Option: USB_SCSI
Description: Use USB/SCSI emulation for scanners connected via USB. This option is only useful for scanners that appear to be SCSI scanners over USB. The ScanJet 4c, 5p/5s, 6p/6s, and 7p support this feature. If this option is omitted, the default behaviour is to use the USB driver.

Option: USER_NAME
Description: Use this option to specify the user name of the scanner owner.

Option: PASS_WORD
Description: Use this option to specify the password of the scanner owner.

Option: LOW_MEM_MODE
Description: If this option is enabled, the backend tries to reduce the amount of RAM used during a scan. This may slow down the scanning process.

Option: USE_MEDIABOARD
Description: For models like the PhotoSmart 612, PhotoSmart 1000, PhotoSmart 1100, and PhotoSmart 1200, this option enables the use of the mediaboard. This allows for a higher scan resolution.

Option: ADF_ONLY
Description: For models that support both a flatbed and an ADF, this option forces the use of the ADF.

Option: FORCE_POWER_CONTROL
Description: For PhotoSmart scanners, this option enables power control to be explicitly turned on or off. Note that this may not be supported by all PhotoSmart models.

Option: RECALIBRATE
Description: For PhotoSmart scanners, this option forces a calibration to be performed before each scan. This may slow down the scanning process.

Option: FORCE_LEGACY_MODE
Description: For PhotoSmart scanners, this option forces the use of legacy mode. This is usually only needed for older firmware versions.

Option: MAX_ADF_PAGES
Description: For models with an Automatic Document Feeder (ADF), this option sets the maximum number of pages that can be scanned from the ADF in one operation. If this option is omitted, the default is 50 pages.

Option: AUTO_CLOSE_LOOPS
Description: For PhotoSmart scanners, this option enables the automatic closing of loops, which can help prevent errors with certain scanner models.

Option: BACKEND_DEBUG [0-15]
Description: This option enables debugging output for the backend. The value is a bitmask. Higher values enable more verbose output.

Example configuration for a ScanJet 5p connected via USB:

usb 0/003/03

Example configuration for a ScanJet 5p connected via SCSI:

scsi /dev/sg0

Example configuration for a PhotoSmart 1000:

hp:usb
# or
hp:scanner
USE_MEDIABOARD

FILES

@sconfdir@/sane-hp.conf
Backend configuration file.

ENVIRONMENT

SANE_HP_KEEPOPEN_USB
SANE_HP_KEEPOPEN_DEVICE
For each type of connection (connect-scsi, connect-usb, connect-device) it can be specified if the connection to the device should be kept open ("1") or not ("0"). Usually the connections are closed after an operation is performed. Keeping connection open to SCSI-devices can result in errors during device IO when the scanner has not been used for some time. By default, USB-connections are kept open. Other connections are closed.
SANE_HP_RDREDO
Specifies number of retries for read operation before returning an EOF error. Only supported for non-SCSI devices. Default: 1 retry. Time between retries is 0.1 seconds.

BUGS

HP PhotoSmart PhotoScanner
In media mode 'slide' and 'negative', scan resolutions are rounded to multiple of 300 dpi. The scanner does not scale the data correctly on other resolutions. Some newer models (firmware code R030 and later) do not support adjustment of contrast/intensity level and tone map. The backend will simulate this by software, but only for gray and 24 bit color.
Automatic Document Feeder (ADF)
For use of the ADF with xscanimage(1), first place paper in the ADF and then change option scan source to 'ADF'. Press 'change document' to load a sheet. Then press 'scan' to start a scan. Maybe it is sufficient to press 'scan' without 'change document' for repeated scans. The use of the preview window is not recommended when working with the ADF. Setting a window to scan from ADF is not supported with xscanimage(1). Try xsane(1).
Immediate actions
Some actions in xscanimage(1) (i.e. unload, select media, calibrate) have an immediate effect on the scanner without starting a scan. These options can not be used with scanimage(1).

TODO

HP PhotoSmart PhotoScanner
PhotoScanners with firmware release R030 and up have no firmware support for contrast/brightness/gamma table. In the current backend this is simulated by software on 24 bits data. Simulation on 30 bits should give better results.
Data widths greater than 8 bits
Custom gamma table does not work.
Parallel scanner support
Beside the ScanJet Plus which came with its own parallel interface card, currently only the HP ScanJet 5100C/5200C are supported. These scanners are using an internal parallel-to-SCSI converter which is supported by the ppSCSI-driver (see above).
