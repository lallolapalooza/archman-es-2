NOMBRE

sane-xerox_mfp - Backend de SANE para dispositivos Xerox Phaser 3200MFP et al.

DESCRIPCIÓN

La biblioteca sane-xerox_mfp implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a varios escáneres Samsung, Xerox y Dell basados en Samsung. Por favor, consulta la lista completa de dispositivos compatibles en http://www.sane-project.org/sane-supported-devices.html.

CONFIGURACIÓN

/etc/sane.d/xerox_mfp.conf
Los escáneres USB no necesitan ninguna configuración.

Para SCX-4500W en modo de red, necesitas especificar

tcp dirección_host [puerto]

La dirección_host se pasa a través del resolvedor, por lo que puede ser una IP con puntos o un nombre de /etc/hosts o que se pueda resolver a través de DNS.

ARCHIVOS

/etc/sane.d/xerox_mfp.conf
El archivo de configuración del backend. Por defecto, todos los tipos/modelos de escáner están habilitados, es posible que quieras comentar las entradas no deseadas.
/usr/lib/sane/libsane-xerox_mfp.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-xerox_mfp.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_DEBUG_XEROX_MFP
Si la biblioteca fue compilada con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Los niveles de depuración más altos aumentan la verbosidad de la salida.

Ejemplo: export SANE_DEBUG_XEROX_MFP=4

LIMITACIONES

La autoconfiguración multicast para escáneres de red aún no está implementada. La direccionamiento IPv6 nunca se ha probado.

ERRORES Y SOPORTE

Si has encontrado un error o necesitas soporte, por favor, sigue la forma de código abierto de obtener soporte a través de listas de correo http://www.sane-project.org/mailing-lists.html o el rastreador de errores de SANE http://www.sane-project.org/bugs.html.
