SADF(1) Manual de Usuario de Linux SADF(1)

NOMBRE

sadf - Muestra datos recopilados por sar en múltiples formatos.

SINOPSIS

sadf [ -C ] [ -c | -d | -g | -j | -l | -p | -r | -x ] [ -H ] [ -h ] [ -T | -t | -U ] [ -V ] [ -O opts [,...] ] [ -P { lista_cpu | ALL } ] [ -s [ hora_inicio ] ] ] [ -e [ hora_fin ] ] ] [ --dev=lista_dev ] [ --fs=lista_fs ] [ --iface=lista_iface] [ --int=lista_int ] [ -- opciones_sar ] [ intervalo [ conteo ] ] [ archivo_datos | -[0-9]+ ]

DESCRIPCIÓN

El comando sadf se utiliza para mostrar el contenido de los archivos de datos creados por el comando sar(1). Pero a diferencia de sar, sadf puede escribir sus datos en muchos formatos diferentes (CSV, XML, etc.) El formato predeterminado es uno que puede ser fácilmente manejado por comandos de procesamiento de patrones como awk (ver opción -p). El comando sadf también puede usarse para dibujar gráficos de las diversas actividades recopiladas por sar y mostrarlas como gráficos SVG (Scalable Vector Graphics) en su navegador web (ver opción -g).

El comando sadf extrae y escribe en la salida estándar los registros guardados en el archivo archivo_datos. Este archivo debe haber sido creado por una versión de sar compatible con la de sadf. Si se omite archivo_datos, sadf usa el archivo de datos diario de actividad del sistema estándar. También es posible ingresar -1, -2, etc., como argumento a sadf para mostrar los datos de hace tantos días. Por ejemplo, -1 apuntará al archivo de datos diario de actividad del sistema estándar de ayer.

El archivo de datos diario de actividad del sistema estándar se llama saDD o saYYYYMMDD, donde YYYY representa el año actual, MM el mes actual y DD el día actual. sadf buscará el más reciente entre saDD y saYYYYMMDD, y lo usará. Por defecto, se encuentra en el directorio /var/log/sa. Sin embargo, es posible especificar una ubicación alternativa: si archivo_datos es un directorio (en lugar de un archivo plano), se considerará el directorio donde se encuentra el archivo de datos diario de actividad del sistema estándar.

Los parámetros intervalo y conteo se utilizan para indicarle a sadf que seleccione conteo registros con una diferencia de intervalo segundos. Si no se establece el parámetro conteo, se mostrarán todos los registros guardados en el archivo de datos.

Todas las banderas de actividad de sar pueden ingresarse en la línea de comandos para indicar qué actividades se deben reportar. Antes de especificarlas, coloque un par de guiones (--) en la línea de comandos para no confundir las banderas con las de sadf. No especificar ninguna bandera selecciona solo la actividad de la CPU.

OPCIONES

-C
Indica a sadf que muestre los comentarios presentes en el archivo.
-c
Convierte un archivo de datos binario de actividad del sistema antiguo (versión 9.1.6 y posteriores) al formato actual. Utilice la siguiente sintaxis:

sadf -c archivo_datos_antiguo > archivo_datos_nuevo

La conversión se puede controlar usando la opción -O (ver más abajo).

-d
Imprime el contenido del archivo de datos en un formato que pueda ser fácilmente ingerido por un sistema de gestión de bases de datos relacionales. La salida consiste en campos separados por un punto y coma. Cada registro contiene el nombre del host donde se creó el archivo, el valor del intervalo (o -1 si no es aplicable), la marca de tiempo en un formato fácilmente aceptable por la mayoría de las bases de datos, y campos de datos adicionales separados por punto y coma según lo especificado por las opciones de línea de comandos opciones_sar. Tenga en cuenta que la salida de la marca de tiempo puede controlarse mediante las opciones -T, -t y -U.
--dev=lista_dev
Especifica los dispositivos de bloque para los que sadf mostrará estadísticas. lista_dev es una lista de nombres de dispositivos separados por comas. Útil con la opción -d de sar.

-e [ hh:mm[:ss] ]
-e [ segundos_desde_la_epoch ]

Establece la hora de finalización del informe. La hora de finalización predeterminada es 18:00:00. Las horas deben proporcionarse en formato de 24 horas, o como el número de segundos desde la epoch (proporcionado como un número de 10 dígitos).
--fs=lista_fs
Especifica los sistemas de archivos para los que sadf mostrará estadísticas. lista_fs es una lista de nombres de sistemas de archivos o puntos de montaje separados por comas. Útil con la opción -F de sar.
-g
Imprime el contenido del archivo de datos en formato SVG (Scalable Vector Graphics). Esta opción le permite mostrar gráficos atractivos en su navegador web. Utilice la siguiente sintaxis:

sadf -g archivo_datos_aqui [ -- opciones_sar ] > salida.svg

y abra el archivo SVG resultante en su navegador web favorito. La salida se puede controlar usando la opción -O (ver más abajo).

-H
Muestra solo la cabecera del informe (cuando sea aplicable). Si no se ha especificado ningún formato, se mostrarán los datos de cabecera (metadatos) del archivo de datos.
-h
Cuando se usa junto con la opción -d, todas las actividades se mostrarán horizontalmente en una sola línea.
--iface=lista_iface
Especifica las interfaces de red para las que sadf mostrará estadísticas. lista_iface es una lista de nombres de interfaces separados por comas. Útil con las opciones -n DEV y -n EDEV de sar.
--int=lista_int
Especifica los nombres de interrupciones para los que sadf mostrará estadísticas. lista_int es una lista de valores o rangos de valores separados por comas (por ejemplo, 0-16,35,40-). Útil con la opción -I de sar.
-j
Imprime el contenido del archivo de datos en formato JSON (JavaScript Object Notation). Las marcas de tiempo se pueden controlar mediante las opciones -T y -t.
-l
Exporta el contenido del archivo de datos a un archivo de archivo PCP (Performance Co-Pilot). El nombre del archivo de archivo se puede especificar usando la palabra clave pcparchive= con la opción -O.
-O opts[,...]
Utiliza las opciones especificadas para controlar la salida de sadf. Las siguientes opciones se utilizan para controlar la salida SVG mostrada por sadf -g:
autoscale
Dibuja todos los gráficos de una vista dada tan grandes como sea posible basándose en la escala de la vista actual. Para hacer esto, se utiliza un factor (10, 100, 1000...) para ampliar el dibujo del gráfico. Esta opción puede ser interesante cuando se dibujan varios gráficos en la misma vista, algunos con valores muy pequeños y otros con valores altos, siendo estos últimos difíciles de ver para los primeros.
bwcol
Utiliza una paleta de blanco y negro para dibujar los gráficos.
customcol
Utiliza una paleta de colores personalizable en lugar de la predeterminada para dibujar los gráficos. Consulte la variable de entorno S_COLORS_PALETTE a continuación para saber cómo personalizar esa paleta.
debug
Agrega comentarios útiles en el archivo de salida SVG.
height=valor
Establece la altura del lienzo SVG a valor.
oneday
Muestra los datos de los gráficos durante un período de 24 horas. Tenga en cuenta que las horas todavía se imprimen en UTC por defecto: debería usar la opción -T para imprimirlas en hora local y obtener una ventana de tiempo que comience desde la medianoche.
packed
Agrupa todas las vistas de la misma actividad (y para el mismo dispositivo) en la misma fila.
showidle
También muestra el estado de %idle en los gráficos para
Estadísticas de la CPU.
showinfo
Muestra información adicional (como la fecha y el nombre del host) en cada vista.
showtoc
Añade una tabla de contenidos al principio de la salida SVG, que consiste en enlaces que apuntan al primer gráfico de cada actividad.
skipempty
No muestra vistas donde todos los gráficos tienen solo valores cero.
La siguiente opción puede ser utilizada al convertir un antiguo archivo de datos binarios de actividad del sistema a su formato actual y actualizado:
hz=valor
Especifica el número de tics por segundo para la máquina donde se creó el archivo de datos antiguo.
La siguiente opción puede ser utilizada cuando los datos se exportan a un archivo PCP:
pcparchive=nombre
Especifica el nombre del archivo PCP a crear.
La siguiente opción se utiliza para controlar la salida cruda mostrada por sadf -r:
debug
Muestra información adicional, principalmente útil para depuración.
-P { lista_cpu | ALL
Indica a sadf que las estadísticas dependientes del procesador se informarán solo para el procesador o procesadores especificados. lista_cpu es una lista de valores separados por comas o rangos de valores (por ejemplo, 0,2,4-7,12-). Tenga en cuenta que el procesador 0 es el primer procesador, y el procesador all es el promedio global entre todos los procesadores. Especificar la palabra clave ALL informa estadísticas para cada procesador individual y globalmente para todos los procesadores.
-p
Imprime el contenido del archivo de datos en un formato que pueda ser fácilmente manejado por comandos de procesamiento de patrones como awk. La salida consiste en campos separados por tabulaciones. Cada registro contiene el nombre del host desde donde se creó el archivo, el valor del intervalo (o -1 si no aplica), la marca de tiempo, el nombre del dispositivo (o - si no aplica) y su valor. Tenga en cuenta que la salida de la marca de tiempo puede ser controlada por las opciones -T, -t y -U.
-r
Imprime el contenido crudo del archivo de datos. Con este formato, los valores de todos los contadores se muestran tal como se leen del kernel, lo que significa, por ejemplo, que no se calculan valores promedio sobre el intervalo de tiempo transcurrido. La salida puede ser controlada usando la opción -O (ver arriba).

-s [ hh:mm[:ss] ]
-s [ segundos_desde_la_epoca ]

Establece la hora de inicio de los datos, lo que hace que el comando sadf extraiga registros marcados con la hora especificada o posteriores a ella. La hora de inicio predeterminada es las 08:00:00. Las horas deben proporcionarse en formato de 24 horas, o como el número de segundos desde la época (proporcionado como un número de 10 dígitos).
-T
Muestra la marca de tiempo en hora local en lugar de UTC (Tiempo Universal Coordinado).
-t
Muestra la marca de tiempo en la hora local original del creador del archivo de datos en lugar de UTC (Tiempo Universal Coordinado).
-U
Muestra la marca de tiempo (UTC - Tiempo Universal Coordinado) en segundos desde la época.
-V
Imprime el número de versión y sale.
-x
Imprime el contenido del archivo de datos en formato XML. Las marcas de tiempo pueden ser controladas por las opciones -T y -t. La DTD (Definición de Tipo de Documento) y el Esquema XML correspondientes se incluyen en el paquete fuente de sysstat. También están disponibles en https://sysstat.github.io/.

ENTORNO

El comando sadf tiene en cuenta las siguientes variables de entorno:

S_COLORS_PALETTE
Especifica los colores utilizados por sadf -g para renderizar la salida SVG. Esta variable de entorno solo se tiene en cuenta cuando la paleta de colores personalizada ha sido seleccionada con la opción customcol (ver opción -O). Su valor es una lista separada por dos puntos de capacidades asociadas con números hexadecimales de seis dígitos y tres bytes (tríos hexadecimales) que representan colores y que por defecto son

0=000000:1=1a1aff:2=1affb2:3=b21aff:
4=1ab2ff:5=ff1a1a:6=ffb31a:7=b2ff1a:
8=efefef:9=000000:A=1a1aff:B=1affb2:
C=b21aff:D=1ab2ff:E=ff1a1a:F=ffb31a:
G=bebebe:H=000000:I=000000:K=ffffff:
L=000000:T=000000:W=000000:X=000000

Las capacidades que consisten en un dígito hexadecimal (de 0 a F) se utilizan para especificar los primeros dieciséis colores de la paleta (estos colores se utilizan para dibujar los gráficos), por ejemplo, 3=ffffff indicaría que el tercer color de la paleta es blanco (0xffffff).
Otras capacidades son:

G=
Especifica el color utilizado para dibujar las líneas de la cuadrícula.
H=
Especifica el color utilizado para mostrar la cabecera del informe.
I=
Especifica el color utilizado para mostrar información adicional (por ejemplo, fecha, nombre del host...).
K=
Especifica el color utilizado para el fondo de los gráficos.
L=
Especifica el color predeterminado (que se utiliza, por ejemplo, para mostrar la tabla de contenidos).
T=
Especifica el color utilizado para mostrar el título de los gráficos.
W=
Especifica el color utilizado para mostrar mensajes de advertencia y error.
X=
Especifica el color utilizado para dibujar los ejes y mostrar las graduaciones.
S_TIME_DEF_TIME
Si esta variable existe y su valor es UTC, entonces sadf utilizará la hora UTC en lugar de la hora local para determinar el archivo de datos diario actual ubicado en el directorio /var/log/sa.

EJEMPLOS

sadf -d /var/log/sa/sa21 -- -r -n DEV
Extrae estadísticas de memoria y red del archivo de actividad del sistema sa21 y las muestra en un formato que puede ser ingerido por una base de datos.
sadf -p -P 1
Extrae estadísticas de CPU para el procesador 1 (el segundo procesador) del archivo de datos diario actual y las muestra en un formato que puede ser fácilmente manejado por un comando de procesamiento de patrones.

ERRORES

La salida SVG (tal como la crea la opción -g) cumple totalmente con el estándar SVG 1.1. Los gráficos se han mostrado con éxito en varios navegadores web, incluyendo Firefox, Chrome y Opera. Sin embargo, la renderización SVG está rota en los navegadores de Microsoft (probado en Internet Explorer 11 y Edge 13.1): por lo tanto, no los utilice.

ARCHIVOS

/var/log/sa/saDD
/var/log/sa/saYYYYMMDD

Los archivos de datos diarios estándar de actividad del sistema y su ubicación predeterminada. YYYY representa el año actual, MM el mes actual y DD el día actual.
