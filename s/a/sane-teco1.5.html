NOMBRE

sane-teco1 - backend de SANE para escáneres TECO / RELISYS

DESCRIPCIÓN

La biblioteca sane-teco1 implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a algunos escáneres planos SCSI de TECO. ¡Este backend debe considerarse software de calidad beta! Los escáneres TECO se venden bajo diversas marcas como RELISYS, PIOTECH, TRUST. Este backend puede que los admita o no.

Los escáneres que deberían funcionar con este backend son:

  Relisys AVEC 2412        VM3520+       probado
  Relisys AVEC 4800        VM4530        sin probar
  Relisys AVEC 4816        VM4530+       sin probar
  Relisys RELI 2400        VM3530        sin probar
  Relisys RELI 2412        VM3530+       probado
  Relisys RELI 2412        VM3530+       sin probar
  Relisys RELI 4816        VM4540        probado
  Relisys RELI 4830        VM4542        probado
  Relisys RELI 9600        VM6530        sin probar
  Relisys RELI 9612        VM6530*       sin probar
  Relisys RELI 9624        VM6530+       sin probar
  Relisys RELI 9630        VM6540        sin probar
  Relisys RELI DS15        VM3440        sin probar
  Relisys RELI DS6         VM3420        sin probar
  Dextra  DF-600P          VM3510        probado
  Dextra  DF-4830T         VM4542        sin probar
  Dextra  DF-1200T+        VM3530+       sin probar
  Dextra  DF-9624          VM6530+       sin probar

Tenga en cuenta que los escáneres sin probar no serán compatibles directamente. Debería contactar con el autor para eso.

El número VM de TECO generalmente se puede encontrar en la parte posterior del escáner. También es parte del ID de la FCC. sane-find-scanner -v también mostrará la consulta SCSI, y si es un escáner TECO, el nombre también estará allí.

Las opciones que admite el backend se pueden seleccionar a través de opciones de línea de comandos de programas como scanimage(1) o a través de elementos GUI en xscanimage(1) o xsane(1).

Si tiene algún éxito con un escáner no listado aquí, o si nota algún comportamiento extraño, por favor repórtelo al mantenedor del backend o a la lista de correo de SANE.

Las opciones de línea de comandos válidas y su sintaxis se pueden listar usando:

scanimage --help -d teco1
Modo de escaneo
--modo Blanco y Negro|Escala de grises|Color
Selecciona el modo básico de operación del escáner. Las opciones válidas son Blanco y Negro, Escala de grises y Color.

El modo Blanco y Negro es solo para blanco y negro (1 bit). Escala de grises producirá 256 niveles de gris (8 bits). Color producirá una imagen en color de 24 bits.

--resolución 1..600
Selecciona la resolución para un escaneo. El escáner puede realizar todas las resoluciones entre 1 y 600, en incrementos de 1.
Opciones de geometría
-l -t -x -y
Controla el área de escaneo: -l establece la coordenada x superior izquierda, -t la coordenada y superior izquierda, -x selecciona el ancho y -y la altura del área de escaneo. Todos los parámetros se especifican en milímetros por defecto.
Opciones de mejora
--gamma-personalizada
(solo modo color) permite al usuario especificar una tabla gamma (ver los siguientes 3 parámetros).
--tabla-gamma-roja
Se puede utilizar para descargar una tabla gamma definida por el usuario para el canal rojo. La tabla debe tener 256 bytes. Solo modo color.
--tabla-gamma-verde
Se puede utilizar para descargar una tabla gamma definida por el usuario para el canal verde. La tabla debe tener 256 bytes. Solo modo color.
--tabla-gamma-azul
Se puede utilizar para descargar una tabla gamma definida por el usuario para el canal azul. La tabla debe tener 256 bytes. Solo modo color.
--tramado Line art|2x2|3x3|4x4 bayer|4x4 smooth|8x8 bayer|8x8 smooth|8x8 horizontal|8x8 vertical
Selecciona la máscara de tramado a utilizar. Solo Blanco y Negro.
--vista-previa
Solicita un escaneo de vista previa. La resolución utilizada es de 22 ppp y el área de escaneo es la máxima permitida. El modo de escaneo es el seleccionado por el usuario. El valor predeterminado es "no".

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/teco1.conf admite un solo elemento: el nombre del dispositivo a utilizar (ej. /dev/scanner).

ARCHIVOS

/usr/lib/sane/libsane-teco1.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-teco1.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_DEBUG_TECO1
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.

LIMITACIONES

El controlador TWAIN de Windows tiene muchas más opciones que este backend de SANE. Sin embargo, son solo ajustes de software. Este backend solo implementa lo que el escáner puede admitir.

ERRORES

Ninguno conocido.
