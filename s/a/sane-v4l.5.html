NOMBRE

sane-v4l - Interfaz SANE para la API de Video para Linux

DESCRIPCIÓN

La biblioteca sane-v4l implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso genérico a cámaras de video y equipos similares utilizando la API V4L (Video for Linux).

¡Esto es software ALFA! De verdad. Faltan funciones importantes y hay muchos errores. El código actualmente solo se ha probado en un sistema Linux 2.4 con una tarjeta de video Hauppauge WinTV.

NOMBRES DE DISPOSITIVO

Este backend espera nombres de dispositivo del tipo:

especial

Donde especial es la ruta de acceso UNIX para el dispositivo especial que corresponde al dispositivo v4l. El nombre del dispositivo especial debe ser un dispositivo v4l o un enlace simbólico a dicho dispositivo. Por ejemplo, un nombre de dispositivo de este tipo podría ser /dev/video0 o /dev/bttv0.

CONFIGURACIÓN

El contenido del archivo v4l.conf es una lista de nombres de dispositivos que corresponden a dispositivos v4l. Las líneas vacías y las líneas que comienzan con un signo de almohadilla (#) se ignoran. A continuación se muestra un archivo de configuración de ejemplo:

/dev/bttv0
# este es un comentario
/dev/video3

ARCHIVOS

/etc/sane.d/v4l.conf
El archivo de configuración del backend (ver también la descripción de SANE_CONFIG_DIR más abajo).
/usr/lib/sane/libsane-v4l.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-v4l.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por un punto y coma (`;'). Si esta variable no está establecida, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorios, entonces los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, establecer SANE_CONFIG_DIR a "/tmp/config:" resultaría en la búsqueda de los directorios tmp/config, . y /etc/sane.d (en este orden).
SANE_DEBUG_V4L
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.

AUTOR

ERRORES:

Si hay más de una tarjeta de video presente, puede ocurrir un bloqueo. Falta la selección de frecuencia y geometría.
Envíe informes de errores a la lista de correo de SANE: sane-devel@alioth-lists.debian.net. Debe estar suscrito a la lista para enviar correos. Consulte http://www.sane-project.org/mailing-lists.html para obtener detalles.
