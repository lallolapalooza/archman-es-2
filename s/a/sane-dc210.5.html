NOMBRE

sane-dc210 - Backend de SANE para la cámara digital Kodak DC210

DESCRIPCIÓN

La biblioteca sane-dc210 implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a la cámara Kodak DC210. ¡ESTE ES CÓDIGO EXTREMADAMENTE ALFA! ¡ÚSALO BAJO TU PROPIO RIESGO!

NOMBRES DE DISPOSITIVO

La versión actual del backend solo permite conectar una cámara. El nombre del dispositivo es siempre "0".

CONFIGURACIÓN

El contenido de dc210.conf especifica el puerto serie y la velocidad en baudios a utilizar. El parámetro baud especifica la velocidad máxima a utilizar mientras se descargan las imágenes. (La cámara siempre se inicializa usando 9600 baudios, luego cambia a la velocidad superior). En mi Pentium de 90 MHz, generalmente no tengo problemas para descargar a 115200 baudios siempre que el sistema no esté excesivamente ocupado y la "bandera de desenmascaramiento de interrupciones" esté establecida en el controlador IDE (hdparm -u1). Las velocidades en baudios admitidas son: 9600, 19200, 38400, 57600 y 115200.

La línea dumpinquiry provoca que se imprima información sobre la cámara.

cmdrespause especifica cuántos microsegundos (1.000.000 de segundos) esperar entre la escritura del comando y la lectura del resultado. 125000 parece ser lo mínimo que pude usar de forma fiable.

breakpause especifica cuántos microsegundos (1.000.000 de segundos) entre el envío de la interrupción "de vuelta a predeterminado" y el envío de comandos.

Las líneas vacías y las líneas que comienzan con una almohadilla (#) se ignoran. A continuación se muestra un archivo de configuración de ejemplo:

puerto=/dev/ttyS0
# esto es un comentario
baud=115200
dumpinquiry
cmdrespause=125000
breakpause=1000000

ARCHIVOS

/etc/sane.d/dc210.conf
El archivo de configuración del backend (ver también la descripción de SANE_CONFIG_DIR abajo).
/usr/lib/sane/libsane-dc210.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-dc210.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por un punto y coma (`;'). Si esta variable no está configurada, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorios, entonces los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, configurar SANE_CONFIG_DIR a "/tmp/config:" resultaría en la búsqueda de los directorios tmp/config, ., y /etc/sane.d (en este orden).
SANE_DEBUG_DC210
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Un valor de 128 solicita una salida de depuración máximamente detallada; niveles más pequeños reducen la verbosidad.
