sane-s9036(5) SANE Scanner Access Now Easy sane-s9036(5)

NOMBRE

sane-s9036 - Backend de SANE para escáneres planos Siemens 9036

DESCRIPCIÓN

La biblioteca sane-s9036 implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a los escáneres planos Siemens 9036.

NOMBRES DE DISPOSITIVO

Este backend espera nombres de dispositivo del tipo:

especial

Donde especial es la ruta del dispositivo especial que corresponde a un escáner SCSI. El nombre del dispositivo especial debe ser un dispositivo SCSI genérico o un enlace simbólico a dicho dispositivo. El programa sane-find-scanner(1) ayuda a averiguar el nombre de dispositivo correcto. En Linux, un nombre de dispositivo de este tipo podría ser /dev/sga o /dev/sge, por ejemplo. Consulte sane-scsi(5) para más detalles.

FICHEROS

/etc/sane.d/s9036.conf
El fichero de configuración del backend (véase también la descripción de SANE_CONFIG_DIR más abajo).
/usr/lib/sane/libsane-s9036.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-s9036.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el fichero de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por un punto y coma (`;'). Si esta variable no está definida, el fichero de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorios, entonces los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, definir SANE_CONFIG_DIR a "/tmp/config:" resultaría en la búsqueda de los directorios tmp/config, ., y /etc/sane.d (en este orden).
SANE_DEBUG_S9036
Si la biblioteca fue compilada con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Niveles de depuración más altos aumentan la verbosidad de la salida.

Ejemplo: export SANE_DEBUG_S9036=4

sane(7), sane-scsi(5)
