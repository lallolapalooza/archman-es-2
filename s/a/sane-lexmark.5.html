NOMBRE

sane-lexmark - Backend SANE para escáneres Lexmark de la serie X1100/X1200

DESCRIPCIÓN

La biblioteca sane-lexmark implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a la parte del escáner de los AIOs Lexmark X1100/X1200. ¡Este backend debe considerarse software de calidad beta!

Los escáneres que deberían funcionar con este backend son:

   Vendedor   Modelo        Estado
----------------------  -----------
  Lexmark   X74           bueno
  Lexmark   X1110         no probado
  Lexmark   X1140         no probado
  Lexmark   X1150         bueno
  Lexmark   X1170         bueno
  Lexmark   X1180         bueno
  Lexmark   X1185         completo
  Lexmark   X12xx         bueno en USB1.1,
                          no completamente probado en USB2.0
  Dell      A920          bueno

Las opciones que soporta el backend se pueden seleccionar a través de opciones de línea de comandos en programas como scanimage(1) o a través de elementos de la interfaz gráfica en xscanimage(1) o xsane(1).

Si nota algún comportamiento extraño, por favor repórtelo al mantenedor del backend o a la lista de correo de SANE.

Las opciones de línea de comandos válidas y su sintaxis se pueden listar usando

scanimage --help -d lexmark:usb:<puerto usb>

Opciones de Modo de Escaneo
--modo
selecciona el modo básico de operación del escáner. Las opciones válidas son Color, Gris y Lineart. El modo predeterminado es Color. El modo Lineart es solo blanco y negro (1 bit). El modo Gris producirá 256 niveles de gris (8 bits). El modo Color permite más de 16 millones de colores diferentes producidos a partir de 24 bits de información de color.
--resolucion
selecciona la resolución para un escaneo. Las resoluciones horizontal y vertical se establecen mediante el valor de esta opción. El escáner es capaz de las siguientes resoluciones para el valor de opción especificado:
  Valor   Resolución Hor.  Resolución Vert.
  -----   ---------------  -------------------
  75      75dpi            75dpi
  150     150dpi           150dpi
  300     300dpi           300dpi
  600     600dpi           600dpi
  1200    600dpi           1200dpi  (solo para modelos X11xx con sensor 'B2')
--vista_previa
solicita un escaneo de vista previa. La resolución utilizada para ese escaneo es de 75 dpi y el área de escaneo y el modo de escaneo son como se especifican a través de sus opciones, o el valor predeterminado si no se especifica. El valor predeterminado para el modo de vista previa es "no".
--umbral
selecciona el brillo mínimo para obtener un punto blanco. El umbral solo se utiliza con escaneos en modo Lineart. Se especifica como un porcentaje en el rango 0..100% (en pasos de 1). El valor predeterminado de la opción umbral es 50.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/lexmark.conf contiene solo el ID del dispositivo USB (por ejemplo, usb 0x043d 0x007c).

ARCHIVOS

/usr/lib/sane/libsane-lexmark.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-lexmark.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_DEBUG_LEXMARK
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 255 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.
SANE_DEBUG_LEXMARK_LOW
Proporciona salida de depuración para funciones Lexmark de bajo nivel.

LIMITACIONES

El controlador TWAIN de Windows tiene muchas más opciones que este backend SANE. Sin embargo, solo son ajustes de software. Este backend solo implementa lo que el escáner puede soportar. Por ejemplo, la corrección de sombreado (rayas verticales debido a la variación del sensor en su ancho) se realiza por software. La posición de estacionamiento del cabezal también se detecta por software. La compresión de datos no es compatible para la serie X1200 en USB 1.1, lo que provoca escaneos lentos.

ERRORES

Actualmente no se conocen errores.
