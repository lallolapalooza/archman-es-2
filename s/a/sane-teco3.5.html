NOMBRE

sane-teco3 - Backend de SANE para escáneres TECO / RELISYS

DESCRIPCIÓN

La biblioteca sane-teco3 implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a algunos escáneres planos SCSI de TECO. Este backend debe considerarse software de calidad alfa. Los escáneres TECO se venden bajo diversas marcas como RELYSIS, PIOTECH, TRUST. Este backend puede o no ser compatible con el suyo.

Los escáneres que deberían funcionar con este backend son:

  Modelo del Vendedor           Modelo TECO   estado
  ---------------------------  ----------  ----------
  Relisys Scorpio                VM3552     probado
  Plustek OpticPro 2400SP        VM3552     no probado
  PIOTECH Splendeur 3024         VM3552     probado
  Trust Imagery 2400 SP          VM3552     probado
  Trust Imagery 4800 SP+         VM3552     probado
  Trust Imagery 9600 SP          VM3552     no probado

El número de modelo TECO VM se suele encontrar en la parte posterior del escáner. También forma parte del ID de la FCC.

Las opciones que admite el backend se pueden seleccionar a través de opciones de línea de comandos para programas como scanimage(1) o a través de elementos de GUI en xscanimage(1) o xsane(1).

Si tiene algún éxito con un escáner no listado aquí, o si nota algún comportamiento extraño, por favor informe al mantenedor del backend o a la lista de correo de SANE.

OPCIONES

Las opciones válidas de línea de comandos y su sintaxis se pueden listar usando:

scanimage --help -d teco3
Modo de Escaneo
--mode Blanco y Negro|Escala de Grises|Color
Selecciona el modo básico de operación del escáner. El modo Blanco y Negro es solo blanco y negro (1 bit). Escala de Grises producirá 256 niveles de gris (8 bits). Color producirá una imagen a color de 24 bits.
--resolution 1..1200
Selecciona la resolución para un escaneo. El escáner puede manejar todas las resoluciones entre 1 y 1200, en incrementos de 1.
--vista
Solicita un escaneo de vista previa. La resolución utilizada para ese escaneo es de 22 dpi y el área de escaneo es la máxima permitida. El modo de escaneo es seleccionado por el usuario. El valor predeterminado es "no".
Opciones de Geometría
-l -t -x -y
Controlan el área de escaneo: -l establece la coordenada x superior izquierda, -t la coordenada y superior izquierda, -x selecciona el ancho y -y la altura del área de escaneo. Todos los parámetros se especifican en milímetros por defecto.

OPCIONES SOLO EN MODO COLOR

--gamma-personalizada
Permite al usuario especificar una tabla gamma (ver los siguientes 3 parámetros).
--tabla-gamma-roja
Se puede usar para descargar una tabla gamma definida por el usuario para el canal rojo. La tabla debe tener 1024 bytes de longitud.
--tabla-gamma-verde
Se puede usar para descargar una tabla gamma definida por el usuario para el canal verde. La tabla debe tener 1024 bytes de longitud.
--tabla-gamma-azul
Se puede usar para descargar una tabla gamma definida por el usuario para el canal azul. La tabla debe tener 1024 bytes de longitud.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/teco3.conf solo admite un elemento: el nombre del dispositivo a utilizar (p. ej., /dev/scanner).

ARCHIVOS

/usr/lib/sane/libsane-teco3.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-teco3.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_DEBUG_TECO3
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.

LIMITACIONES

El controlador TWAIN de Windows tiene muchas más opciones que este backend SANE. Sin embargo, son solo ajustes de software. Este backend solo implementa lo que el escáner puede soportar.

ERRORES

No muchos.
