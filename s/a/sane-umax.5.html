NOMBRE

sane-umax - Backend de SANE para escáneres UMAX

SOBRE ESTE ARCHIVO

¡Este archivo es solo una breve descripción del backend sane-umax para SANE! Para obtener información detallada, eche un vistazo a sane-umax-doc.html (¡está incluido en el directorio fuente de sane y en la ayuda en línea de xsane(1)!).

DESCRIPCIÓN

La biblioteca sane-umax implementa un backend de SANE que proporciona acceso a varios escáneres UMAX-SCSI y algunos escáneres SCSI Linotype Hell. Los escáneres paralelos y USB no son (¡y probablemente nunca lo serán!) compatibles.

¡Sugiero que mantenga una mano en el botón de encendido del escáner mientras intenta los primeros escaneos!

CONFIGURACIÓN

El archivo de configuración para este backend reside en /etc/sane.d/umax.conf.

Su contenido es una lista de nombres de dispositivos que corresponden a escáneres UMAX y compatibles con UMAX. Las líneas vacías y las líneas que comienzan con un signo de almohadilla (#) se ignoran. A continuación se muestra un archivo de configuración de ejemplo:

 # este es un comentario
 #
 option scsi-maxqueue 4
 option scsi-buffer-size-min 65536
 option scsi-buffer-size-max 131072
 option scan-lines 40
 option preview-lines 10
 option scsi-maxqueue 2
 option execute-request-sense 0
 option force-preview-bit-rgb 0
 option slow-speed -1
 option care-about-smearing -1
 option calibration-full-ccd -1
 option calibration-width-offset -1
 option calibration-bytes-pixel -1
 option exposure-time-rgb-bind -1
 option invert-shading-data -1
 option lamp-control-available 0
 option gamma-lsb-padded 0
 /dev/sge
 #scsi Vendor Model Type Bus Channel ID LUN
 # El siguiente escáner soporta control de lámpara
 option lamp-control-available 1
 scsi UMAX * Scanner * * * * *
 # el escáner en /dev/scanner no soporta control de lámpara
 option lamp-control-available 0
 /dev/scanner
execute-request-sense:
valores: 0 = deshabilitado, 1 = habilitado
predeterminado = 0
Si se establece en 1, se llama a umax_do_request_sense() en umax_do_calibration(). Esto puede colgar el sistema, pero ha estado habilitado hasta esta versión.
scsi-buffer-size-min, scsi-buffer-size-max:
valores: 4096-1048576
predeterminado min = 32768, max = 131072
Especialmente el valor mínimo es muy importante. Si este valor se establece demasiado bajo, el backend no puede enviar tablas gamma al escáner ni realizar una calibración de color correcta. Esto puede resultar en extraños efectos de color. Si el valor mínimo se establece demasiado alto, el backend no puede asignar el tamaño de búfer SCSI solicitado y se aborta con un error de falta de memoria. El valor predeterminado es 32KB, para algunos escáneres debería aumentarse a 64KB.
scan-lines, preview-lines:
valores: 1-65535
predeterminado: scan-lines = 40, preview-lines = 10
definen el número máximo de líneas que se escanean en un búfer
force-preview-bit-rgb:
valores: 0 = deshabilitado, 1 = habilitado
predeterminado = 0
establece el bit de previsualización en el escaneo real rgb
slow-speed, care-about-smearing:
valores: -1 = automático, 0 = deshabilitado, 1 = habilitado
predeterminado = -1
Opciones peligrosas, necesarias para algunos escáneres.
No cambie estas opciones a menos que sepa realmente lo que está haciendo, de lo contrario, podría dañar su escáner con valores inválidos.
calibration-full-ccd:
valores: -1 = automático, 0 = deshabilitado, 1 = habilitado
predeterminado = -1
realiza la calibración para cada píxel del ccd en lugar de la imagen seleccionada
calibration-width-offset:
valores: -99999 = automático, > -99999 valor establecido
añade un desplazamiento al ancho calculado para la imagen/ccd
calibration-bytes-pixel:
valores: -1 = deshabilitado, 0 = no establecido, 1 = 1 byte/píxel, 2 = 2 bytes/píxel
usa # bytes por píxel para la calibración
exposure-time-rgb-bind:
valores: -1 = establecido automáticamente por el controlador - si se conoce, 0 = deshabilitado (selección propia para rojo, verde y azul), 1 = habilitado (mismos valores para rojo, verde y azul)
invert-shading-data:
valores: -1 = establecido automáticamente por el controlador - si se conoce, 0 = deshabilitado, 1 = habilitado
predeterminado = -1
invierte los datos de sombreado antes de enviarlos de vuelta al escáner
lamp-control-available:
valores: 0 = establecido automáticamente por el controlador - si se conoce, 1 = disponible
predeterminado = 0
gamma-lsb-padded:
valores: -1 = establecido automáticamente por el controlador - si se conoce, 0 = los datos gamma tienen relleno msb, 1 = los datos gamma tienen relleno lsb
predeterminado = -1
handle-bad-sense-error:
valores: 0 = manejar como dispositivo ocupado, 1 = manejar como ok, 2 = manejar como error de i/o, 3 = ignorar código de error malo - continuar con el manejador de sense
predeterminado = 0
scsi-maxqueue:
valores: 1..# (máximo definido en tiempo de compilación)
predeterminado = 2
la mayoría de los controladores SCSI permiten la cola interna de comandos con una profundidad de 2 comandos. En la mayoría de los casos, no mejora nada si aumenta este valor. Si su controlador SCSI no admite ninguna cola de comandos, puede intentar establecer este valor en 1.

El nombre de dispositivo especial debe ser un dispositivo SCSI genérico o un enlace simbólico a dicho dispositivo. Para averiguar a qué dispositivo está asignado su escáner y cómo debe configurar los permisos de ese dispositivo, eche un vistazo a sane-scsi(5).

CONSEJOS ADAPTADOR SCSI

Los adaptadores SCSI ISA que se envían con algunos escáneres UMAX no están muy bien soportados por Linux (¡sugiero no usarlos!), los adaptadores SCSI PCI que vienen con algunos escáneres UMAX no son compatibles en absoluto (que yo sepa). En otras plataformas, estos adaptadores SCSI no son compatibles. Por lo tanto, normalmente necesitará comprar otro adaptador SCSI que sea compatible con su plataforma. Consulte los FAQs de hardware y HOWTOs relevantes para su plataforma para obtener más información.

Los escáneres UMAX bloquean el bus SCSI durante unos segundos al escanear. No es necesario conectar el escáner a su propio adaptador SCSI. Pero si necesita un tiempo de respuesta corto para su disco duro SCSI (por ejemplo, si su ordenador es un servidor de archivos) u otros dispositivos SCSI, sugiero que utilice un adaptador SCSI propio para su escáner UMAX.

Si tiene algún problema con su escáner UMAX, revise su cadena SCSI (longitud del cable, terminación, ...).

Ver también: sane-scsi(5)

ENTORNO

SANE_DEBUG_UMAX
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad. Valores de SANE_DEBUG_UMAX: 
Número  Observación
 0       imprimir errores importantes (impresos cada vez)
 1       imprimir errores
 2       imprimir sense
 3       imprimir advertencias
 4       imprimir consulta del escáner
 5       imprimir información
 6       imprimir información menos importante
 7       imprimir procedimientos llamados
 8       imprimir mensajes de reader_process
 10      imprimir sane-init-routines llamados
 11      imprimir sane-procedu

CONFIGURACIÓN

El controlador sane-umax puede ser configurado modificando el archivo de configuración del controlador.

FILES

/etc/sane.d/umax.conf

Este archivo contiene la configuración específica del controlador sane-umax. Las líneas que comienzan con un carácter de almohadilla (#) o punto y coma (;) se ignoran. El archivo contiene las siguientes directivas:

  • dispositivo o device

Esta directiva se utiliza para especificar el nombre del dispositivo SANE para el escáner UMAX.

  • modelo o model

Esta directiva se utiliza para especificar el modelo del escáner UMAX. Si no se especifica, el controlador intentará detectar el modelo automáticamente.

  • escaneado- SCSI o scsi-scan

Esta directiva indica al controlador que utilice el escaneo SCSI para el escáner. Esto puede ser útil si el escáner no se detecta correctamente utilizando el método estándar.

  • opciones-configuración o config-options

Esta directiva permite especificar opciones de configuración específicas para el escáner. Las opciones disponibles dependen del modelo del escáner.

SCSI ADAPTER TIPS

Si estás teniendo problemas para que tu escáner SANE sea detectado, es posible que necesites ajustar las opciones de tu adaptador SCSI. Aquí tienes algunos consejos:

  • Asegúrate de que tu adaptador SCSI esté configurado correctamente y que los IRQ y DMA sean correctos.
  • Asegúrate de que el escáner esté configurado en la ID SCSI correcta. La mayoría de los escáneres UMAX utilizan la ID 2.
  • Si sigues teniendo problemas, intenta desactivar la sincronización rápida en tu adaptador SCSI.
  • También puedes intentar deshabilitar el modo de transferencia síncrona en tu adaptador SCSI.

FILES

/etc/sane.d/umax.conf

ENVIRONMENT

El controlador sane-umax utiliza las siguientes variables de entorno:

SANE_CONFIG_DIR
Este directorio se utiliza para buscar archivos de configuración. Si no se establece, se utilizan los directorios de configuración predeterminados del sistema.
SANE_DEBUG_UMAX
Este archivo controla el nivel de depuración para el controlador sane-umax. Los valores más altos dan más información de depuración. 
 12      print sane infos
 13      print sane option-control messages

Example:

export SANE_DEBUG_UMAX=8
