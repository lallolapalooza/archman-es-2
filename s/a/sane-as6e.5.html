sane-as6e(5) Acceso Fácil a Escáner SANE sane-as6e(5)

NOMBRE

sane-as6e - backend SANE para usar el escáner con interfaz de puerto paralelo Artec AS6E.

DESCRIPCIÓN

La biblioteca sane-as6e implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso al escáner plano Artec AS6E. Requiere el programa as6edriver para funcionar. El programa as6edriver no se incluye con el paquete SANE. Se puede encontrar en http://as6edriver.sourceforge.net. Consulte la documentación de as6edriver para obtener información técnica.

El programa as6edriver debe estar en la ruta para los ejecutables ($PATH). Especialmente si ejecuta saned(8) (el demonio de escaneo de red SANE), asegúrese de configurar correctamente la ruta para inetd(8) o xinetd(8) o coloque el programa en un directorio que esté en la ruta.

ARCHIVOS

as6edriver - programa controlador que controla el escáner.

VER TAMBIÉN

sane(7), as6edriver(5), saned(8), inetd(8), xinetd(8)
http://as6edriver.sourceforge.net
