sane-epjitsu(5) Acceso Fácil a Escáneres SANE sane-epjitsu(5)

NOMBRE

sane-epjitsu - Backend SANE para escáneres Fujitsu USB basados en Epson

DESCRIPCIÓN

La biblioteca sane-epjitsu implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso básico a los escáneres Fujitsu fi-60F/fi-65F y ScanSnap S300/S1300(i)/S1100(i).

SOPORTE DE HARDWARE

Estos escáneres son bastante limitados, solo admiten un par de modos y resoluciones, y siempre escanean a ancho completo. El backend admite modos faltantes (binario, escala de grises) y resoluciones intermedias en software, pero solo proporciona controles mínimos del área de escaneo. Ver PROBLEMAS CONOCIDOS.

Este backend puede admitir otros escáneres. Si la inspección física revela un chipset Epson, póngase en contacto con el autor para obtener instrucciones sobre cómo recopilar un rastreo USB en Windows para verificarlo.

OPCIONES

Se ha realizado un esfuerzo limitado para exponer las opciones estándar a la API. Esto permite a un frontend configurar la resolución, el modo de color y elegir la configuración del ADF. El backend sane-epjitsu admite las siguientes opciones básicas para la mayoría de los escáneres:

fuente s

Selecciona la fuente para el escaneo. Las opciones pueden incluir "Flatbed", "ADF Front", "ADF Back", "ADF Duplex".

modo m

Selecciona el modo para el escaneo. Las opciones pueden incluir "Lineart", "Gray", "Color".

resolución, y-resolución

Controla la resolución de escaneo. Establecer --resolution también establece --y-resolution, aunque este comportamiento es anulado por algunos frontends.

Habrá otras opciones disponibles según las capacidades del escáner. Use 'scanimage --help' para obtener una lista. Tenga en cuenta que algunas opciones pueden aparecer solo cuando se ha establecido otra opción, y que las opciones avanzadas pueden estar ocultas por el frontend.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/epjitsu.conf se utiliza para indicar al backend cómo buscar escáneres y proporcionar opciones que controlan el funcionamiento del backend. Este archivo se lee cada vez que el frontend solicita al backend una lista de escáneres, generalmente solo cuando el frontend se inicia. Si el archivo de configuración falta, el backend no funcionará.

Los escáneres se pueden especificar en el archivo de configuración de dos maneras:

"usb 0x04c5 0x10c7" (u otros ids de proveedor/producto)

Solicita al backend que busque en todos los buses USB del sistema un dispositivo que utilice ese id de proveedor y producto. Luego se consultará al dispositivo para determinar si es un escáner compatible.

"usb /dev/usb/scanner0" (u otro archivo de dispositivo)

Algunos sistemas utilizan un controlador de kernel para acceder a los escáneres USB. Este método no ha sido probado.

La única opción de configuración admitida es "firmware /RUTA/AL/ARCHIVO", que le permite establecer la ubicación del archivo de firmware que ha extraído del controlador de Windows.

Nota: Este firmware es una obra con derechos de autor de Fujitsu, por lo que no puede ser proporcionado por el backend ni por el autor. Por favor, no pregunte.

Nota: Estos escáneres REQUIEREN un archivo de firmware para funcionar. Consulte el archivo de configuración proporcionado para obtener más detalles.

Nota: Esta opción puede aparecer varias veces en el archivo de configuración. Solo se aplica a los escáneres descubiertos por las líneas 'usb' que siguen a esta opción.

ENTORNO

El backend utiliza una única variable de entorno, SANE_DEBUG_EPJITSU, que habilita la salida de depuración en stderr. Los valores válidos son:

5 Errores
10 Traza de funciones
15 Detalle de funciones
20 Comandos de opciones
25 Traza USB
30 Detalle USB
35 Ruido inútil

PROBLEMAS CONOCIDOS

Solo se exponen opciones limitadas del área de escaneo.
El modo de escala de grises de hardware de los escáneres fi-60F y fi-65F no se utiliza, porque el código de calibración no está terminado.
