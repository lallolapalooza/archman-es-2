NOMBRE

sockaddr, sockaddr_storage, sockaddr_in, sockaddr_in6, sockaddr_un, socklen_t, in_addr, in6_addr, in_addr_t, in_port_t, - dirección de socket

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <sys/socket.h>
struct sockaddr {
    sa_family_t     sa_family;      /* Familia de direcciones */
    char            sa_data[];      /* Dirección del socket */
};
struct sockaddr_storage {
    sa_family_t     ss_family;      /* Familia de direcciones */
};
typedef /* ... */ socklen_t;
typedef /* ... */ sa_family_t;

Sockets de dominio de Internet

#include <netinet/in.h>
struct sockaddr_in {
    sa_family_t     sin_family;     /* AF_INET */
    in_port_t       sin_port;       /* Número de puerto */
    struct in_addr  sin_addr;       /* Dirección IPv4 */
};
struct sockaddr_in6 {
    sa_family_t     sin6_family;    /* AF_INET6 */
    in_port_t       sin6_port;      /* Número de puerto */
    uint32_t        sin6_flowinfo;  /* Información de flujo IPv6 */
    struct in6_addr sin6_addr;      /* Dirección IPv6 */
    uint32_t        sin6_scope_id;  /* Conjunto de interfaces para un ámbito */
};
struct in_addr {
    in_addr_t s_addr;
};
struct in6_addr {
    uint8_t   s6_addr[16];
};
typedef uint32_t in_addr_t;
typedef uint16_t in_port_t;

Sockets de dominio UNIX

#include <sys/un.h>
struct sockaddr_un {
    sa_family_t     sun_family;     /* Familia de direcciones */
    char            sun_path[];     /* Ruta del socket */
};

DESCRIPCIÓN

sockaddr
Describe una dirección de socket.
sockaddr_storage
Una estructura al menos tan grande como cualquier otra estructura de dirección sockaddr_*. Está alineada de manera que un puntero a ella pueda ser convertido a un puntero a otras estructuras sockaddr_* y utilizada para acceder a sus campos.
socklen_t
Describe la longitud de una dirección de socket. Este es un tipo entero de al menos 32 bits.
sa_family_t
Describe la familia de protocolos de un socket. Este es un tipo entero sin signo.

Sockets de dominio de Internet

sockaddr_in
Describe una dirección de socket de dominio de Internet IPv4. Los miembros sin_port y sin_addr se almacenan en orden de bytes de red.
sockaddr_in6
Describe una dirección de socket de dominio de Internet IPv6. El array sin6_addr.s6_addr se utiliza para contener una dirección IPv6 de 128 bits, almacenada en orden de bytes de red.

Sockets de dominio UNIX

sockaddr_un
Describe una dirección de socket de dominio UNIX.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.

socklen_t fue inventado por POSIX. Ver también accept(2).

Estas estructuras se inventaron antes de las reglas modernas de estricto aliasing de ISO C. Si se aplicaran las reglas de aliasing estrictamente, estas estructuras serían extremadamente difíciles de usar sin invocar comportamiento indefinido. POSIX.1-2024 lo solucionó exigiendo que las implementaciones se aseguren de que estas estructuras puedan usarse de forma segura tal como fueron diseñadas.

NOTAS

socklen_t también se define en <netdb.h>.

sa_family_t también se define en <netinet/in.h> y <sys/un.h>.
