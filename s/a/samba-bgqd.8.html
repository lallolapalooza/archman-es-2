SAMBA-BGQD(8) Herramientas de administración del sistema SAMBA-BGQD(8)

NOMBRE

samba-bgqd - Este es un programa auxiliar interno que realiza tareas relacionadas con la impresión asíncrona.

SINOPSIS

samba-bgqd

DESCRIPCIÓN

Esta herramienta forma parte del conjunto samba(7).

samba-bgqd es un programa auxiliar que será iniciado por smbd o spoolssd para realizar tareas como la actualización de la lista de impresoras u otras tareas de gestión de forma asíncrona bajo demanda. No está pensado para ser llamado por usuarios o administradores.

AUTOR

El software Samba original y las utilidades relacionadas fueron creados por Andrew Tridgell. Samba es ahora desarrollado por el Equipo de Samba como un proyecto de Código Abierto, de manera similar a como se desarrolla el kernel de Linux.
