NOMBRE

sane-mustek_usb2 - Backend SANE para escáneres planos USB basados en SQ113

DESCRIPCIÓN

La biblioteca sane-mustek_usb2 implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a escáneres planos USB basados en el chipset Service & Quality SQ113. En este momento, solo se admite el Mustek BearPaw 2448 TA Pro. Está previsto añadir soporte para otros escáneres basados en los chips SQ113 y quizás SQ11. Para más detalles, consulta la página principal del backend sane-mustek_usb2: http://www.meier-geinitz.de/sane/mustek_usb2-backend/.

Este es software BETA. Especialmente si pruebas escáneres nuevos o no probados, ten la mano cerca del enchufe del escáner y desenchúfalo si el cabezal choca al final del área de escaneo.

Si posees un escáner diferente a los listados en la página principal de mustek_usb2 que funcione con este backend, por favor, házmelo saber enviando el nombre exacto del modelo del escáner y los IDs de proveedor y dispositivo USB (por ejemplo, de sane-find-scanner(1) o syslog) a mí. Incluso si el nombre del escáner es ligeramente diferente a los modelos ya listados como compatibles, por favor, házmelo saber.

PROBLEMAS DE LIBUSB

Por favor, usa libusb-0.1.8 o posterior. Sin libusb o con versiones anteriores de libusb, se pueden esperar todo tipo de problemas. El escáner debería ser encontrado por sane-find-scanner(1) sin acciones adicionales. Para configurar permisos e información general de USB, consulta sane-usb(5).

ARCHIVOS

/usr/lib/sane/libsane-mustek_usb2.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-mustek_usb2.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_DEBUG_MUSTEK_USB2
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Niveles de depuración más altos aumentan la verbosidad de la salida.

Ejemplo: export SANE_DEBUG_MUSTEK_USB2=4
