NOMBRE

sane-sm3600 - Backend SANE para escáneres Microtek con chip USB M011

DESCRIPCIÓN

La biblioteca sane-sm3600 implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a algunos escáneres Microtek con el chip USB personalizado Toshiba M011. Este backend debe considerarse alfa.

También existen backends para escáneres Microtek con conjunto de comandos SCSI. Consulte sane-microtek(5) y sane-microtek2(5) para obtener más detalles.

Por el momento, los siguientes escáneres se sabe que funcionan positivamente con este backend:

Proveedor     Identificador de producto:     Observación:
--------   --------------  -----------
Microtek   ScanMaker 3600  todos los modos ok
Microtek   ScanMaker 3700  se informa que funciona
Microtek   ScanMaker 3750  se informa que funciona

Si posee un escáner Microtek con el chip M011 distinto de los listados anteriormente, ¡puede que funcione o no con SANE!

OPCIONES DEL FRONTEND

Este backend habilita dinámicamente las opciones para el frontend, que son compatibles con el escáner en función del modo de escaneo y otras opciones. Las opciones no compatibles se deshabilitan.

Las siguientes opciones son compatibles con el backend sane-sm3600: escaneos en color, escala de grises, semitonos y arte lineal. También contraste, brillo y corrección gamma.

NOMBRES DE DISPOSITIVO

Este backend no admite nombres de dispositivo en un formato estandarizado.

CONFIGURACIÓN

Este backend no admite un archivo de configuración en este momento.

ARCHIVOS

/usr/lib/sane/libsane-sm3600.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-sm3600.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_DEBUG_SM3600
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad. Para ver mensajes de error en stderr, establezca SANE_DEBUG_SM3600 en 1.

Por ejemplo, simplemente diga:
export SANE_DEBUG_SM3600=5
