NOMBRE

sane-canon - Backend de SANE para escáneres SCSI de Canon

DESCRIPCIÓN

La biblioteca sane-canon implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a los siguientes escáneres planos y de película de Canon:

CanoScan 300
CanoScan 600
CanoScan FB620S
CanoScan FB1200S
CanoScan FS2700F
CanoScan FS2710S

Los escáneres con puerto paralelo y USB no son compatibles con este backend; consulte las páginas del manual de sane-canon_pp(5) y sane-canon630u(5) para obtener más información.

IMPORTANTE: Este es código beta. Probamos el código en los escáneres mencionados anteriormente, utilizando los ordenadores y sistemas operativos disponibles para nosotros, pero no podemos garantizar que el backend funcione correctamente con futuros sistemas operativos, adaptadores SCSI, programas frontales de SANE o escáneres Canon no incluidos en la lista anterior. En algunos casos, su ordenador podría incluso colgarse. No se puede excluir (aunque lo consideramos extremadamente improbable) que su escáner resulte dañado.

Dicho esto, LOS PROBADORES SON BIENVENIDOS. Envíe sus informes de errores y comentarios a Manuel Panea <mpd@rzg.mpg.de>; para preguntas sobre los FB620 y FB1200S, póngase en contacto con Mitsuru Okaniwa <m-okaniwa@bea.hi-ho.ne.jp>, para los FS2710S Ulrich Deiters <ukd@xenon.pc.uni-koeln.de>.

CONSEJOS (FS2700F)

Se ha descubierto que escanear diapositivas o negativos requiere correcciones gamma bastante grandes de aproximadamente 2.2 a 2.4 (el mismo valor para rojo, verde y azul). Se recomienda utilizar los controles de exposición automática del frontend xsane(1) para obtener los mejores resultados.

La función "Auto Focus" (Enfoque Automático) activa un pase especial para determinar el valor de enfoque. Después de eso, tiene lugar el pase de escaneo real.

Incluso con "Auto Focus" activado, la imagen escaneada a menudo resulta un poco borrosa. Usar el gimp(1) para hacer un "Filtro->Mejorar->Enfocar" en aproximadamente 40 a 60 mejora la imagen considerablemente.

CONSEJOS (FS2710S)

Las correcciones gamma las realiza no el escáner, sino el backend. El escáner siempre se ejecuta en modo de 12 bits. En modo "color", los datos de la imagen se corrigen para gamma, punto de sombra, etc., y luego se truncan a intensidades de 8 bits; el valor gamma predeterminado es 2.0. En modo "raw", los datos de la imagen se exportan sin correcciones como intensidades de 16 bits; este modo se puede recomendar si se deben realizar ajustes extensos en una imagen (y si el frontend puede manejar intensidades de 16 bits).

Los negativos se manejan mediante una simple inversión de color y requerirán la eliminación manual de la decoloración azul.

ARCHIVOS

/usr/lib/sane/libsane-canon.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-canon.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_DEBUG_CANON
Si la biblioteca fue compilada con soporte de depuración activado, esta variable de entorno controla el nivel de depuración para este backend. Los niveles de depuración más altos aumentan la verbosidad de la salida.

Ejemplo: export SANE_DEBUG_CANON=4
