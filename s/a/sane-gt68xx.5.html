NOMBRE

sane-gt68xx - Backend SANE para escáneres planos USB basados en GT-68XX

DESCRIPCIÓN

La biblioteca sane-gt68xx implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a escáneres planos USB basados en los chips Grandtech GT-6801 y GT-6816. Una lista de escáneres compatibles se puede encontrar en la página principal del backend gt68xx: http://www.meier-geinitz.de/sane/gt68xx-backend/.

Este es software BETA. Especialmente si está probando escáneres nuevos o no probados, tenga la mano en el enchufe del escáner y desenchúfelo si el cabezal choca al final del área de escaneo.

Si posee un escáner diferente a los listados en la página principal de gt68xx que funcione con este backend, por favor, házmelo saber enviando el nombre exacto del modelo del escáner y los IDs de vendedor y producto USB (por ejemplo, de sane-find-scanner(1) o syslog) a mí. Incluso si el nombre del escáner es solo ligeramente diferente a los modelos ya listados como compatibles, por favor, házmelo saber.

Si posee un escáner que no es detectado por el backend gt68xx pero tiene un chipset GT-6801 o GT-6816, puede intentar añadirlo al backend. Eche un vistazo a la siguiente página web: http://www.meier-geinitz.de/sane/gt68xx-backend/adding.html

PROBLEMAS DE LIBUSB

Por favor, utilice libusb-0.1.8 o posterior. Sin libusb o con versiones anteriores de libusb, se pueden esperar todo tipo de problemas. El escáner debería ser encontrado por sane-find-scanner(1) sin más acciones. Para la configuración de permisos e información general de USB, consulte sane-usb(5).

ARCHIVO DE FIRMA

Necesita un archivo de firma (firmware) para su escáner. Es un pequeño archivo que contiene software que se cargará en la memoria del escáner. Suele llamarse *.usb, por ejemplo, PS1fw.usb. Viene en el CD de instalación proporcionado por el fabricante, pero puede estar empaquetado junto con el programa de instalación en un archivo .exe. Para los escáneres Mustek, el archivo se puede descargar de la página principal del backend gt68xx. Para otros escáneres, revise el CD en busca de archivos *.usb. Si solo encuentra archivos *.cab, intente cabextract(1) para desempaquetar. Si todo lo demás falla, debe instalar el controlador de Windows y obtener la firma de ahí (normalmente en los directorios windows/system o system32). Coloque ese archivo de firma en /usr/share/sane/gt68xx/. Asegúrese de que sea legible por todos.

CONFIGURACIÓN

El contenido del archivo gt68xx.conf es una lista de líneas usb que contienen IDs de vendedor y producto que corresponden a escáneres USB. El archivo también puede contener líneas de opción. Las líneas vacías y las líneas que comienzan con un signo de almohadilla (#) se ignoran. Los escáneres se detectan automáticamente mediante las declaraciones usb vendor_id product_id que ya están incluidas en gt68xx.conf. "vendor_id" y "product_id" son números hexadecimales que identifican el escáner.

Las opciones override, firmware, vendor, model y afe deben colocarse después de la línea usb a la que se refieren.

La opción override se utiliza para anular los parámetros predeterminados del modelo. Esto es necesario para algunos escáneres que usan los mismos IDs de vendedor/producto pero son diferentes. Para estos escáneres, ya hay líneas de anulación comentadas en el archivo de configuración. override mustek-scanexpress-1200-ub-plus es necesario para el Mustek Scanexpress 1200 UB Plus, el Medion/Lifetec/Tevion LT 9452 y el Trust Compact Scan USB 19200. override artec-ultima-2000 se utiliza para el Artec Ultima 2000, el Boeder SmartScan Slim Edition, el Medion/ Lifetec/ Tevion/ Cytron MD/LT 9385, el Medion/ Lifetec/ Tevion MD 9458 y el Trust Flat Scan USB 19200. override mustek-bearpaw-2400-cu es necesario para el Mustek BearPaw 2400 CU y el Fujitsu 1200CUS. La opción override debe ser la primera después de la línea usb.

La opción firmware selecciona el nombre y la ruta del archivo de firma. Solo es necesaria si la configuración predeterminada (o la anulada) no funciona. El directorio de firma predeterminado es /usr/share/sane/gt68xx/. Es posible que necesite crear este directorio. Si desea colocar los archivos de firma en una ruta diferente, utilice una línea firmware.

Las opciones vendor y model no son absolutamente necesarias pero son convenientes. Bastantes escáneres de diferentes fabricantes comparten los mismos IDs de vendedor/producto, por lo que puede establecer el nombre "correcto" aquí.

La opción afe permite establecer valores personalizados de offset y ganancia para el FrontEnd Analógico del escáner. Esta opción se puede usar para seleccionar los valores AFE si la calibración automática gruesa está deshabilitada, o para hacer que la calibración automática gruesa sea más rápida. Para este último uso, habilite el nivel de depuración 3 (ver abajo), escanee una imagen y busque la línea de depuración con "afe". Copie esta línea a gt68xx.conf. La opción tiene seis parámetros: offset rojo, ganancia roja, offset verde, ganancia verde, offset azul y ganancia azul.

A continuación se muestra un ejemplo de archivo de configuración:

usb 0x05d8 0x4002
override "mustek-scanexpress-1200-ub-plus"
firmware "/opt/gt68xx/SBfw.usb"
vendor "Trust"
model "Compact Scan USB 19200"
afe 0x20 0x02 0x22 0x03 0x1f 0x04

ARCHIVOS

/etc/sane.d/gt68xx.conf
El archivo de configuración del backend (ver también la descripción de SANE_CONFIG_DIR más abajo).
/usr/lib/sane/libsane-gt68xx.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-gt68xx.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por un punto y coma (`;'). Si esta variable no está configurada, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorio, entonces se buscan los directorios predeterminados después de los directorios especificados explícitamente. Por ejemplo, configurar SANE_CONFIG_DIR a "/tmp/config:" resultaría en la búsqueda de los directorios tmp/config, . y /etc/sane.d (en este orden).
SANE_DEBUG_GT68XX
Si la biblioteca fue compilada con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Niveles de depuración más altos aumentan la verbosidad de la salida. Si el nivel de depuración se establece en 1 o superior, estarán disponibles algunas opciones de depuración que normalmente están ocultas. Manéjelas con cuidado.

Ejemplo: export SANE_DEBUG_GT68XX=4
