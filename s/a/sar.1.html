NOMBRE

sar - Recopilar, informar o guardar información de actividad del sistema.

SINOPSIS

sar [ -A ] [ -B ] [ -b ] [ -C ] [ -D ] [ -d ] [ -F [ MOUNT ] ] [ -H ] [ -h ] [ -p ] [ -r [ ALL ] ] [ -S ] [ -t ] [ -u [ ALL ] ] [ -V ] [ -v ] [ -W ] [ -w ] [ -x ] [ -y ] [ -z ] [ --dec={ 0 | 1 | 2 } ] [ --dev=lista_disp ] [ --fs=lista_fs ] [ --help ] [ --human ] [ --iface=lista_interf ] [ --int=lista_int ] [ --pretty ] [ --sadc ] [ -I [ SUMA | TODO ] ] [ -P { lista_cpu | TODO } ] [ -m { palabra_clave[,...] | TODO } ] [ -n { palabra_clave[,...] | TODO } ] [ -q [ palabra_clave[,...] | TODO ] ] [ -j { SID | ID | LABEL | PATH | UUID | ... } ] [ -f [ nombre_archivo ] | -o [ nombre_archivo ] | -[0-9]+ ] [ -i intervalo ] [ -s [ hora_inicio ] ] [ -e [ hora_fin ] ] ] [ intervalo [ conteo ] ]

DESCRIPCIÓN

El comando sar escribe en la salida estándar el contenido de contadores de actividad acumulados seleccionados en el sistema operativo. El sistema de contabilidad, basado en los valores de los parámetros conteo y intervalo, escribe información el número especificado de veces con un espaciado en segundos de los intervalos especificados. Si el parámetro intervalo se establece en cero, el comando sar muestra las estadísticas promedio desde que el sistema se inició. Si el parámetro intervalo se especifica sin el parámetro conteo, se generan informes de forma continua. Los datos recopilados también se pueden guardar en el archivo especificado por el indicador -o nombre_archivo, además de mostrarse en la pantalla. Si se omite nombre_archivo, sar utiliza el archivo de datos diario de actividad del sistema estándar (ver más abajo).

El comando sar extrae y escribe en la salida estándar registros previamente guardados en un archivo. Este archivo puede ser el especificado por el indicador -f o, por defecto, el archivo de datos diario de actividad del sistema estándar. También es posible ingresar -1, -2, etc., como argumento a sar para mostrar datos de esos días atrás. Por ejemplo, -1 apuntará al archivo de actividad del sistema estándar de ayer.

Los archivos de datos diarios de actividad del sistema estándar se nombran saDD o saYYYYMMDD, donde YYYY representa el año actual, MM representa el mes actual y DD representa el día actual. Son los archivos predeterminados que sar utiliza solo cuando no se ha especificado explícitamente ningún nombre de archivo. Al utilizarse para escribir datos en archivos (con su opción -o), sar usará saYYYYMMDD si también se ha especificado la opción -D, de lo contrario usará saDD. Al utilizarse para mostrar los registros guardados previamente en un archivo, sar buscará el más reciente de saDD y saYYYYMMDD, y lo usará.

Los archivos de datos diarios de actividad del sistema estándar se encuentran en el directorio /var/log/sa por defecto. Sin embargo, es posible especificar una ubicación alternativa para ellos: si se utiliza un directorio (en lugar de un archivo plano) con las opciones -f o -o, se considerará el directorio que contiene los archivos de datos.

Sin el indicador -P, el comando sar informa estadísticas globales del sistema (globales entre todos los procesadores), que se calculan como promedios para los valores expresados como porcentajes y como sumas en otros casos. Si se proporciona el indicador -P, el comando sar informa la actividad relacionada con uno o varios procesadores especificados. Si se usa -P ALL, el comando sar informa estadísticas para cada procesador individual y estadísticas globales entre todos los procesadores. Los procesadores sin conexión no se muestran.

Puede seleccionar información sobre actividades específicas del sistema utilizando indicadores. No especificar ningún indicador selecciona solo la actividad de la CPU. Especificar el indicador -A selecciona todas las actividades posibles.

La versión predeterminada del comando sar (informe de utilización de la CPU) puede ser una de las primeras utilidades que el usuario ejecute para comenzar la investigación de la actividad del sistema, ya que monitorea los principales recursos del sistema. Si la utilización de la CPU está cerca del 100 por ciento (usuario + nice + sistema), la carga de trabajo muestreada está limitada por la CPU.

Si se desean múltiples muestras y múltiples informes, es conveniente especificar un archivo de salida para el comando sar. Ejecute el comando sar como un proceso en segundo plano. La sintaxis para esto es:

sar -o archivo_datos intervalo conteo >/dev/null 2>&1 &

Todos los datos se capturan en formato binario y se guardan en un archivo (archivo_datos). Los datos pueden luego mostrarse selectivamente con el comando sar utilizando la opción -f. Establezca los parámetros intervalo y conteo para seleccionar conteo registros en intervalos de intervalo segundos. Si el parámetro conteo no se establece, se seleccionarán todos los registros guardados en el archivo. La recopilación de datos de esta manera es útil para caracterizar el uso del sistema durante un período de tiempo y determinar las horas de uso pico.

Nota: El comando sar solo informa sobre actividades locales.

OPCIONES

-A
Esto es equivalente a especificar -bBdFHISvwWy -m ALL -n ALL -q ALL -r ALL -u ALL. Esta opción también implica especificar -I ALL -P ALL a menos que estas opciones se establezcan explícitamente en la línea de comandos.
-B
Informar estadísticas de paginación. Se muestran los siguientes valores:
pgpgin/s
Número total de kibibytes que el sistema trajo del disco por segundo.
pgpgout/s
Número total de kibibytes que el sistema paginó al disco por segundo.
fault/s
Número de fallos de página (menores + mayores) cometidos por el sistema por segundo. Esto no es un recuento de fallos de página que generan I/O, ya que algunos fallos de página se pueden resolver sin I/O.
majflt/s
Número de fallos mayores que el sistema ha cometido por segundo, aquellos que han requerido cargar una página de memoria desde el disco.
pgfree/s
Número de páginas que el sistema ha puesto en la lista de libres por segundo.
pgscank/s
Número de páginas escaneadas por el demonio kswapd por segundo.
pgscand/s
Número de páginas escaneadas directamente por segundo.
pgsteal/s
Número de páginas que el sistema ha recuperado de la caché (pagecache y swapcache) por segundo para satisfacer sus demandas de memoria.
pgprom/s
Número de páginas promovidas (es decir, migradas de tipos de memoria lentos a rápidos) por el sistema por segundo.
pgdem/s
Número de páginas degradadas (es decir, migradas de tipos de memoria rápidos a lentos) por el sistema por segundo.
-b
Informar estadísticas de E/S y tasa de transferencia. Se muestran los siguientes valores:
tps
Número total de transferencias por segundo que se emitieron a dispositivos físicos. Una transferencia es una solicitud de E/S a un dispositivo físico. Múltiples solicitudes lógicas pueden combinarse en una sola solicitud de E/S al dispositivo. Una transferencia tiene un tamaño indeterminado.
rtps
Número total de solicitudes de lectura por segundo emitidas a dispositivos físicos.
wtps
Número total de solicitudes de escritura por segundo emitidas a dispositivos físicos.
dtps
Número total de solicitudes de descarte por segundo emitidas a dispositivos físicos.
bread/s
Cantidad total de datos leídos de los dispositivos en bloques por segundo. Los bloques equivalen a sectores y, por lo tanto, tienen un tamaño de 512 bytes.
bwrtn/s
Cantidad total de datos escritos en dispositivos en bloques por segundo.
bdscd/s
Cantidad total de datos descartados para dispositivos en bloques por segundo.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

-C
Al leer datos de un archivo, indica a sar que muestre los comentarios que han sido insertados por sadc.
-D
Utiliza saYYYYMMDD en lugar de saDD como nombre de archivo estándar para los datos de actividad diaria del sistema. Esta opción solo funciona cuando se utiliza junto con la opción -o para guardar los datos en un archivo.
-d
Informa sobre la actividad de cada dispositivo de bloque. Cuando se muestran los datos, el nombre del dispositivo se muestra como aparece (o debería aparecer) en /dev. sar utiliza los datos en /sys para determinar el nombre del dispositivo basándose en sus números mayor y menor. Si esta resolución de nombres falla, sar utilizará el mapeo de nombres controlado por el archivo /etc/conf.d/sysstat.ioconf. Los nombres de dispositivo persistentes también se pueden imprimir si se utiliza la opción -j (ver más abajo). Las estadísticas para todos los dispositivos se muestran a menos que se especifique una lista restringida usando la opción --dev= (ver la entrada de opción correspondiente). Tenga en cuenta que la actividad del disco depende de las opciones -S DISK y -S XDISK de sadc para ser recopilada. Se muestran los siguientes valores:
tps
Número total de transferencias por segundo que se emitieron a dispositivos físicos. Una transferencia es una solicitud de E/S a un dispositivo físico. Múltiples solicitudes lógicas pueden combinarse en una única solicitud de E/S al dispositivo. Una transferencia tiene un tamaño indeterminado.
rkB/s
Número de kibibytes leídos del dispositivo por segundo.
wkB/s
Número de kibibytes escritos en el dispositivo por segundo.
dkB/s
Número de kibibytes descartados para el dispositivo por segundo.
areq-sz
El tamaño promedio (en kibibytes) de las solicitudes de E/S que se emitieron al dispositivo.
Nota: En versiones anteriores, este campo se conocía como avgrq-sz y se expresaba en sectores.
aqu-sz
La longitud promedio de la cola de las solicitudes que se emitieron al dispositivo.
Nota: En versiones anteriores, este campo se conocía como avgqu-sz.
await
El tiempo promedio (en milisegundos) para que las solicitudes de E/S emitidas al dispositivo sean atendidas. Esto incluye el tiempo que las solicitudes pasan en cola y el tiempo que se dedican a servirlas.
%util
Porcentaje del tiempo transcurrido durante el cual se emitieron solicitudes de E/S al dispositivo (utilización de ancho de banda para el dispositivo). La saturación del dispositivo ocurre cuando este valor está cerca del 100% para dispositivos que sirven solicitudes en serie. Pero para dispositivos que sirven solicitudes en paralelo, como arreglos RAID y SSD modernos, este número no refleja sus límites de rendimiento.
--dec={ 0 | 1 | 2 }
Especifica el número de lugares decimales a usar (de 0 a 2, el valor predeterminado es 2).
--dev=lista_disp
Especifica los dispositivos de bloque para los cuales sar mostrará estadísticas. lista_disp es una lista de nombres de dispositivos separados por comas.

-e [ hh:mm[:ss] ]
-e [ segundos_desde_la_epoca ]

Establece la hora de finalización del informe. La hora de finalización predeterminada es 18:00:00. Las horas deben proporcionarse en formato de 24 horas, o como el número de segundos desde la época (proporcionado como un número de 10 dígitos). Esta opción se puede usar cuando los datos se leen o escriben en un archivo (opciones -f o -o).
-F [ MOUNT ]
Muestra estadísticas para los sistemas de archivos montados actualmente. Se ignoran los pseudo-sistemas de archivos. Al final del informe, sar mostrará un resumen de todos esos sistemas de archivos. El uso de la palabra clave de parámetro MOUNT indica que se informará el punto de montaje en lugar del dispositivo del sistema de archivos. Las estadísticas para todos los sistemas de archivos se muestran a menos que se especifique una lista restringida usando la opción --fs= (ver la entrada de opción correspondiente). Tenga en cuenta que las estadísticas de los sistemas de archivos dependen de la opción -S XDISK de sadc para ser recopiladas.

Se muestran los siguientes valores:

MBfsfree
Cantidad total de espacio libre en mebibytes (incluido el espacio disponible solo para usuarios privilegiados).
MBfsused
Cantidad total de espacio utilizado en mebibytes.
%fsused
Porcentaje de espacio del sistema de archivos utilizado, visto por un usuario privilegiado.
%ufsused
Porcentaje de espacio del sistema de archivos utilizado, visto por un usuario no privilegiado.
Ifree
Número total de nodos de archivo libres en el sistema de archivos.
Iused
Número total de nodos de archivo utilizados en el sistema de archivos.
%Iused
Porcentaje de nodos de archivo utilizados en el sistema de archivos.
-f [ nombre_archivo ]
Extrae registros del nombre_archivo (creado por la bandera -o nombre_archivo). El valor predeterminado del parámetro nombre_archivo es el archivo de datos diario de actividad del sistema estándar actual. Si nombre_archivo es un directorio en lugar de un archivo plano, se considera el directorio donde se encuentran los archivos de datos diarios de actividad del sistema estándar. La opción -f es exclusiva de la opción -o.
--fs=lista_fs
Especifica los sistemas de archivos para los cuales sar mostrará estadísticas. lista_fs es una lista de nombres de sistemas de archivos o puntos de montaje separados por comas.
-H
Informa estadísticas de utilización de hugepages. Se muestran los siguientes valores:
kbhugfree
Cantidad de memoria de hugepages en kibibytes que aún no ha sido asignada.
kbhugused
Cantidad de memoria de hugepages en kibibytes que ha sido asignada.
%hugused
Porcentaje de la memoria total de hugepages que ha sido asignada.
kbhugrsvd
Cantidad de memoria de hugepages reservada en kibibytes.
kbhugsurp
Cantidad de memoria de hugepages de excedente en kibibytes.
-h
Esta opción es equivalente a especificar --pretty --human.
--help
Muestra un breve mensaje de ayuda y luego sale.
--human
Imprime los tamaños en formato legible por humanos (por ejemplo, 1.0k, 1.2M, etc.). Las unidades mostradas con esta opción reemplazan cualquier otra unidad predeterminada (por ejemplo, kibibytes, sectores...) asociada con las métricas.
-I [ SUM | ALL ]
Informa estadísticas de interrupciones. Los valores mostrados son el número de interrupciones por segundo para el procesador dado o entre todos los procesadores. Se puede especificar una lista de interrupciones usando --int= (ver esta opción). La palabra clave SUM indica que se debe mostrar el número total de interrupciones recibidas por segundo. La palabra clave ALL indica que se deben informar las estadísticas de todas las interrupciones (este es el valor predeterminado). Tenga en cuenta que las estadísticas de interrupciones dependen de la opción -S INT de sadc para ser recopiladas.
-i intervalo
Selecciona registros de datos en segundos lo más cerca posible del número especificado por el parámetro intervalo.
--iface=lista_interfaz
Especifica las interfaces de red para las cuales sar mostrará estadísticas. lista_interfaz es una lista de nombres de interfaz separados por comas.
--int=lista_int
Especifica los nombres de interrupción para los cuales sar mostrará estadísticas. lista_int es una lista de valores separados por comas o rangos de valores (por ejemplo, 0-16,35,40-).
-j { SID | ID | LABEL | PATH | UUID | ... }
Muestra nombres de dispositivo persistentes. Utilice esta opción junto con la opción -d. Las palabras clave ID, LABEL, etc. especifican el tipo de nombre persistente. Estas palabras clave no son limitadas, solo es un requisito previo que el directorio con los nombres persistentes requeridos esté presente en /dev/disk. La palabra clave SID intenta obtener un identificador estable para usarlo como nombre de dispositivo. Un identificador estable no cambiará entre reinicios para el mismo dispositivo físico. Si existe, este identificador suele ser el WWN (World Wide Name) del dispositivo, leído del directorio /dev/disk/by-id.
-m { palabra_clave[,...] | ALL }
Informa estadísticas de gestión de energía. Tenga en cuenta que estas estadísticas dependen de la opción -S POWER de sadc para ser recopiladas.

Las palabras clave posibles son BAT, CPU, FAN, FREQ, IN, TEMP y USB.

Con la palabra clave BAT, se informan estadísticas sobre la capacidad de las baterías. Se muestran los siguientes valores:

%cap
Capacidad de la batería.
cap/min
Capacidad perdida o ganada por minuto por la batería.
status
Estado de carga de la batería: ↑ (llena), ↗ (cargando), → (no cargando), ↘ (descargando), ? (desconocido).
Con la palabra clave CPU, se informan estadísticas sobre la CPU. Se muestra el siguiente valor:
MHz
Frecuencia instantánea del reloj de la CPU en MHz.
Con la palabra clave FAN, se informan estadísticas sobre la velocidad de los ventiladores. Se muestran los siguientes valores:
rpm
Velocidad del ventilador expresada en revoluciones por minuto.
drpm
drpm
Este campo se calcula como la diferencia entre la velocidad actual del ventilador (rpm) y su límite inferior (fan_min).
DEVICE
Nombre del dispositivo del sensor.
Con la palabra clave FREQ, se informan estadísticas sobre la frecuencia de reloj de la CPU. Los siguientes valores se muestran:
wghMHz
Frecuencia de reloj de CPU promedio ponderada en MHz. Tenga en cuenta que el controlador cpufreq-stats debe compilarse en el kernel para que esta opción funcione.
Con la palabra clave IN, se informan estadísticas sobre las entradas de voltaje. Los siguientes valores se muestran:
inV
Entrada de voltaje expresada en Voltios.
%in
Valor de entrada relativo. Un valor del 100% significa que la entrada de voltaje ha alcanzado su límite superior (in_max), mientras que un valor del 0% significa que ha alcanzado su límite inferior (in_min).
DEVICE
Nombre del dispositivo del sensor.
Con la palabra clave TEMP, se informan estadísticas sobre la temperatura de los dispositivos. Los siguientes valores se muestran:
degC
Temperatura del dispositivo expresada en grados Celsius.
%temp
Temperatura relativa del dispositivo. Un valor del 100% significa que la temperatura ha alcanzado su límite superior (temp_max).
DEVICE
Nombre del dispositivo del sensor.
Con la palabra clave USB, el comando sar toma una instantánea de todos los dispositivos USB actualmente conectados al sistema. Al final del informe, sar mostrará un resumen de todos esos dispositivos USB. Los siguientes valores se muestran:
BUS
Número de concentrador raíz del dispositivo USB.
idvendor
Número de ID de proveedor (asignado por la organización USB).
idprod
Número de ID de producto (asignado por el fabricante).
maxpower
Consumo máximo de energía del dispositivo (expresado en mA).
manufact
Nombre del fabricante.
product
Nombre del producto.
La palabra clave ALL es equivalente a especificar todas las palabras clave anteriores y, por lo tanto, se informan todas las estadísticas de administración de energía.
-n { keyword[,...] | ALL }
Informar estadísticas de red.

Las palabras clave posibles son DEV, EDEV, FC, ICMP, EICMP, ICMP6, EICMP6, IP, EIP, IP6, EIP6, NFS, NFSD, SOCK, SOCK6, SOFT, TCP, ETCP, UDP y UDP6.

Con la palabra clave DEV, se informan estadísticas de los dispositivos de red. Se muestran estadísticas para todas las interfaces de red, a menos que se especifique una lista restringida usando la opción --iface= (consulte la entrada de opción correspondiente). Los siguientes valores se muestran:

IFACE
Nombre de la interfaz de red para la que se informan las estadísticas.
rxpck/s
Número total de paquetes recibidos por segundo.
txpck/s
Número total de paquetes transmitidos por segundo.
rxkB/s
Número total de kibibytes recibidos por segundo.
txkB/s
Número total de kibibytes transmitidos por segundo.
rxcmp/s
Número de paquetes comprimidos recibidos por segundo (para cslip, etc.).
txcmp/s
Número de paquetes comprimidos transmitidos por segundo.
rxmcst/s
Número de paquetes multicast recibidos por segundo.
%ifutil
Porcentaje de utilización de la interfaz de red. Para interfaces half-duplex, la utilización se calcula utilizando la suma de rxkB/s y txkB/s como porcentaje de la velocidad de la interfaz. Para full-duplex, este es el mayor de rxkB/S o txkB/s.
Con la palabra clave EDEV, se informan estadísticas sobre fallos (errores) de los dispositivos de red. Se muestran estadísticas para todas las interfaces de red, a menos que se especifique una lista restringida usando la opción --iface= (consulte la entrada de opción correspondiente). Los siguientes valores se muestran:
IFACE
Nombre de la interfaz de red para la que se informan las estadísticas.
rxerr/s
Número total de paquetes erróneos recibidos por segundo.
txerr/s
Número total de errores que ocurrieron por segundo al transmitir paquetes.
coll/s
Número de colisiones que ocurrieron por segundo al transmitir paquetes.
rxdrop/s
Número de paquetes recibidos descartados por segundo debido a la falta de espacio en los búferes de Linux.
txdrop/s
Número de paquetes transmitidos descartados por segundo debido a la falta de espacio en los búferes de Linux.
txcarr/s
Número de errores de portadora que ocurrieron por segundo al transmitir paquetes.
rxfram/s
Número de errores de alineación de trama que ocurrieron por segundo en los paquetes recibidos.
rxfifo/s
Número de errores de desbordamiento de FIFO que ocurrieron por segundo en los paquetes recibidos.
txfifo/s
Número de errores de desbordamiento de FIFO que ocurrieron por segundo en los paquetes transmitidos.
Con la palabra clave FC, se informan estadísticas sobre el tráfico de canal de fibra. Tenga en cuenta que las estadísticas de canal de fibra dependen de la opción -S DISK de sadc para ser recopiladas. Los siguientes valores se muestran:
FCHOST
Nombre de la interfaz del adaptador de bus host de canal de fibra (HBA) para la que se informan las estadísticas.
fch_rxf/s
El número total de tramas recibidas por segundo.
fch_txf/s
El número total de tramas transmitidas por segundo.
fch_rxw/s
El número total de palabras de transmisión recibidas por segundo.
fch_txw/s
El número total de palabras de transmisión transmitidas por segundo.
Con la palabra clave ICMP, se informan estadísticas sobre el tráfico de red ICMPv4. Tenga en cuenta que las estadísticas de ICMPv4 dependen de la opción -S SNMP de sadc para ser recopiladas. Los siguientes valores se muestran (nombres SNMP formales entre corchetes):
imsg/s
El número total de mensajes ICMP que la entidad recibió por segundo [icmpInMsgs]. Tenga en cuenta que este contador incluye todos los contados por ierr/s.
omsg/s
El número total de mensajes ICMP que esta entidad intentó enviar por segundo [icmpOutMsgs]. Tenga en cuenta que este contador incluye todos los contados por oerr/s.
iech/s
El número de mensajes ICMP Echo (solicitud) recibidos por segundo [icmpInEchos].
iechr/s
El número de mensajes ICMP Echo Reply recibidos por segundo [icmpInEchoReps].
oech/s
El número de mensajes ICMP Echo (solicitud) enviados por segundo [icmpOutEchos].
oechr/s
El número de mensajes ICMP Echo Reply enviados por segundo [icmpOutEchoReps].
itm/s
El número de mensajes ICMP Timestamp (solicitud) recibidos por segundo [icmpInTimestamps].
itmr/s
El número de mensajes ICMP Timestamp Reply recibidos por segundo [icmpInTimestampReps].
otm/s
El número de mensajes ICMP Timestamp (solicitud) enviados por segundo [icmpOutTimestamps].
otmr/s
El número de mensajes ICMP Timestamp Reply enviados por segundo [icmpOutTimestampReps].
iadrmk/s
El número de mensajes ICMP Address Mask Request recibidos por segundo [icmpInAddrMasks].
iadrmkr/s
El número de mensajes ICMP Address Mask Reply recibidos por segundo [icmpInAddrMaskReps].
oadrmk/s
El número de mensajes ICMP Address Mask Request enviados por segundo [icmpOutAddrMasks].
oadrmkr/s
El número de mensajes ICMP Address Mask Reply enviados por segundo [icmpOutAddrMaskReps].
Con la palabra clave EICMP, se informan estadísticas sobre mensajes de error ICMPv4. Tenga en cuenta que las estadísticas de ICMPv4 dependen de la opción -S SNMP de sadc para ser recopiladas. Los siguientes valores se muestran (nombres SNMP formales entre corchetes):

La palabra clave ALL es equivalente a especificar todas las palabras clave anteriores y, por lo tanto, se informan todas las actividades de red.
-o [ nombre_archivo ]
Guarda las lecturas en el archivo en formato binario. Cada lectura está en un registro separado. El valor predeterminado del parámetro nombre_archivo es el archivo de datos diario de actividad del sistema estándar actual. Si nombre_archivo es un directorio en lugar de un archivo plano, se considera el directorio donde se encuentran los archivos de datos diarios de actividad del sistema estándar. La opción -o es exclusiva de la opción -f. Se guardan en el archivo todos los datos disponibles del kernel (de hecho, sar llama a su recopilador de datos sadc con la opción -S ALL. Véase la página del manual de sadc(8)).
-P { lista_cpu | ALL }
Informa estadísticas por procesador para el procesador o procesadores especificados. lista_cpu es una lista de valores separados por comas o rangos de valores (por ejemplo, 0,2,4-7,12-). Tenga en cuenta que el procesador 0 es el primer procesador y el procesador all es el promedio global entre todos los procesadores. Especificar la palabra clave ALL informa estadísticas para cada procesador individual y globalmente para todos los procesadores. Los procesadores fuera de línea no se muestran.
-p, --pretty
Hace que los informes sean más fáciles de leer para un humano. Esta opción puede ser especialmente útil al mostrar estadísticas de, por ejemplo, interfaces de red o dispositivos de bloque.
-q [ palabra_clave[,...] | ALL ]
Informa estadísticas de carga del sistema y de bloqueo de presión (pressure-stall).

Las palabras clave posibles son CPU, IO, LOAD, MEM y PSI.

Con la palabra clave CPU, se informan estadísticas de presión de CPU. Se muestran los siguientes valores:

%scpu-10
Porcentaje del tiempo que al menos algunas tareas ejecutables se retrasaron porque la CPU no estaba disponible para ellas, durante la ventana de los últimos 10 segundos.
%scpu-60
Porcentaje del tiempo que al menos algunas tareas ejecutables se retrasaron porque la CPU no estaba disponible para ellas, durante la ventana de los últimos 60 segundos.
%scpu-300
Porcentaje del tiempo que al menos algunas tareas ejecutables se retrasaron porque la CPU no estaba disponible para ellas, durante la ventana de los últimos 300 segundos.
%scpu
Porcentaje del tiempo que al menos algunas tareas ejecutables se retrasaron porque la CPU no estaba disponible para ellas, durante el último intervalo de tiempo.
Con la palabra clave IO, se informan estadísticas de presión de E/S.
d. Los siguientes valores se muestran:
%sio-10
Porcentaje del tiempo en que al menos algunas tareas perdieron esperando E/S, durante la última ventana de 10 segundos.
%sio-60
Porcentaje del tiempo en que al menos algunas tareas perdieron esperando E/S, durante la última ventana de 60 segundos.
%sio-300
Porcentaje del tiempo en que al menos algunas tareas perdieron esperando E/S, durante la última ventana de 300 segundos.
%sio
Porcentaje del tiempo en que al menos algunas tareas perdieron esperando E/S, durante el último intervalo de tiempo.
%fio-10
Porcentaje del tiempo durante el cual todas las tareas no inactivas se detuvieron esperando E/S, durante la última ventana de 10 segundos.
%fio-60
Porcentaje del tiempo durante el cual todas las tareas no inactivas se detuvieron esperando E/S, durante la última ventana de 60 segundos.
%fio-300
Porcentaje del tiempo durante el cual todas las tareas no inactivas se detuvieron esperando E/S, durante la última ventana de 300 segundos.
%fio
Porcentaje del tiempo durante el cual todas las tareas no inactivas se detuvieron esperando E/S, durante el último intervalo de tiempo.
Con la palabra clave LOAD, se informan estadísticas de la longitud de la cola y del promedio de carga. Los siguientes valores se muestran:
runq-sz
Longitud de la cola de ejecución (número de tareas ejecutándose o esperando tiempo de ejecución).
plist-sz
Número de tareas en la lista de tareas.
ldavg-1
Promedio de carga del sistema durante el último minuto. El promedio de carga se calcula como el número promedio de tareas ejecutables o en ejecución (estado R) y el número de tareas en espera ininterrumpible (estado D) durante el intervalo especificado.
ldavg-5
Promedio de carga del sistema durante los últimos 5 minutos.
ldavg-15
Promedio de carga del sistema durante los últimos 15 minutos.
blocked
Número de tareas actualmente bloqueadas, esperando a que se complete la E/S.
Con la palabra clave MEM, se informan estadísticas de presión de memoria. Los siguientes valores se muestran:
%smem-10
Porcentaje del tiempo durante el cual al menos algunas tareas estuvieron esperando recursos de memoria, durante la última ventana de 10 segundos.
%smem-60
Porcentaje del tiempo durante el cual al menos algunas tareas estuvieron esperando recursos de memoria, durante la última ventana de 60 segundos.
%smem-300
Porcentaje del tiempo durante el cual al menos algunas tareas estuvieron esperando recursos de memoria, durante la última ventana de 300 segundos.
%smem
Porcentaje del tiempo durante el cual al menos algunas tareas estuvieron esperando recursos de memoria, durante el último intervalo de tiempo.
%fmem-10
Porcentaje del tiempo durante el cual todas las tareas no inactivas se detuvieron esperando recursos de memoria, durante la última ventana de 10 segundos.
%fmem-60
Porcentaje del tiempo durante el cual todas las tareas no inactivas se detuvieron esperando recursos de memoria, durante la última ventana de 60 segundos.
%fmem-300
Porcentaje del tiempo durante el cual todas las tareas no inactivas se detuvieron esperando recursos de memoria, durante la última ventana de 300 segundos.
%fmem
Porcentaje del tiempo durante el cual todas las tareas no inactivas se detuvieron esperando recursos de memoria, durante el último intervalo de tiempo.
La palabra clave PSI es equivalente a especificar las palabras clave CPU, IO y MEM juntas y, por lo tanto, se informan todas las estadísticas de presión-espera.

La palabra clave ALL es equivalente a especificar todas las palabras clave anteriores y, por lo tanto, se informan todas las estadísticas.

-r [ ALL ]
Informa estadísticas de utilización de memoria. La palabra clave ALL indica que todos los campos de memoria deben mostrarse. Los siguientes valores pueden mostrarse:
kbmemfree
Cantidad de memoria libre disponible en kibibytes.
kbavail
Estimación de cuánta memoria en kibibytes está disponible para iniciar nuevas aplicaciones, sin paginación. La estimación tiene en cuenta que el sistema necesita algo de caché de páginas para funcionar bien, y que no toda la slab recuperable será recuperable, debido a elementos en uso. El impacto de estos factores variará de un sistema a otro. Si no lo proporciona el kernel, este campo es el mismo que kbmemfree.
kbmemused
Cantidad de memoria utilizada en kibibytes (calculada como memoria total instalada - kbavail).
%memused
Porcentaje de memoria utilizada.
kbbuffers
Cantidad de memoria utilizada como búferes por el kernel en kibibytes.
kbcached
Cantidad de memoria utilizada para caché de datos por el kernel en kibibytes.
kbcommit
Cantidad de memoria en kibibytes necesaria para la carga de trabajo actual. Esta es una estimación de cuánta RAM/swap se necesita para garantizar que nunca haya falta de memoria.
%commit
Porcentaje de memoria necesaria para la carga de trabajo actual en relación con la cantidad total de memoria (RAM+swap). Este número puede ser superior al 100% porque el kernel generalmente sobreasigna memoria.
kbactive
Cantidad de memoria activa en kibibytes (memoria que se ha utilizado más recientemente y que normalmente no se recupera a menos que sea absolutamente necesario).
kbinact
Cantidad de memoria inactiva en kibibytes (memoria que se ha utilizado menos recientemente. Es más elegible para ser recuperada para otros propósitos).
kbdirty
Cantidad de memoria en kibibytes esperando ser escrita en el disco.
kbshmem
Cantidad de memoria compartida en kibibytes (memoria utilizada principalmente por tmpfs).
kbanonpg
Cantidad de páginas no respaldadas por archivos en kibibytes mapeadas en las tablas de páginas del espacio de usuario.
kbslab
Cantidad de memoria en kibibytes utilizada por el kernel para almacenar en caché estructuras de datos para su propio uso.
kbkstack
Cantidad de memoria en kibibytes utilizada para el espacio de pila del kernel.
kbpgtbl
Cantidad de memoria en kibibytes dedicada al nivel más bajo de tablas de páginas.
kbvmused
Cantidad de memoria en kibibytes de espacio de direcciones virtuales utilizado.
-S
Informa estadísticas de utilización del espacio de intercambio. Los siguientes valores se muestran:
kbswpfree
Cantidad de espacio de intercambio libre en kibibytes.
kbswpused
Cantidad de espacio de intercambio utilizado en kibibytes.
%swpused
Porcentaje de espacio de intercambio utilizado.
kbswpcad
Cantidad de memoria de intercambio en caché en kibibytes. Esta es memoria que una vez fue intercambiada, se vuelve a intercambiar pero todavía está en el área de intercambio (si se necesita memoria, no necesita ser intercambiada nuevamente porque ya está en el área de intercambio. Esto ahorra E/S).
%swpcad
Porcentaje de memoria de intercambio en caché en relación con la cantidad de espacio de intercambio utilizado.

-s [ hh:mm[:ss] ]
-s [ segundos desde la época ]

Establece la hora de inicio de los datos, haciendo que el comando sar extraiga los registros a la hora especificada o después. La hora de inicio predeterminada es 08:00:00. Las horas deben proporcionarse en formato de 24 horas, o como el número de segundos desde la época (proporcionado como un número de 10 dígitos). Esta opción solo se puede utilizar cuando los datos se leen de un archivo (opción -f).
--sadc
Indica qué colector de datos llama sar. Si el colector de datos se busca en PATH, ingrese "which sadc" para saber dónde se encuentra.
-t
Al leer datos de un archivo de datos diario, indica que sar debe mostrar las marcas de tiempo en la hora local original del creador del archivo de datos. Sin esta opción, el comando sar muestra las marcas de tiempo en la hora local del usuario.
-u [ ALL ]
Informa sobre la utilización de la CPU. La palabra clave ALL indica que todos los campos de CPU deben mostrarse. El informe puede mostrar los siguientes campos:
%user
Porcentaje de utilización de la CPU que ocurrió mientras se ejecutaba a nivel de usuario (aplicación). Tenga en cuenta que este campo incluye el tiempo dedicado a ejecutar procesadores virtuales.
%usr
Porcentaje de utilización de la CPU que ocurrió mientras se ejecutaba a nivel de usuario (aplicación). Tenga en cuenta que este campo NO incluye el tiempo dedicado a ejecutar procesadores virtuales.
%nice
Porcentaje de utilización de la CPU que ocurrió mientras se ejecutaba a nivel de usuario con prioridad nice.
%system
Porcentaje de utilización de la CPU que ocurrió mientras se ejecutaba a nivel de sistema (kernel). Tenga en cuenta que este campo incluye el tiempo dedicado a atender interrupciones de hardware y software.
%sys
Porcentaje de utilización de la CPU que ocurrió mientras se ejecutaba a nivel de sistema (kernel). Tenga en cuenta que este campo NO incluye el tiempo dedicado a atender interrupciones de hardware o software.
%iowait
Porcentaje de tiempo en que la CPU o CPUs estuvieron inactivas durante el cual el sistema tuvo una solicitud de E/S de disco pendiente.
%steal
Porcentaje de tiempo empleado en espera involuntaria por la CPU o CPUs virtuales mientras el hipervisor estaba atendiendo a otro procesador virtual.
%irq
Porcentaje de tiempo empleado por la CPU o CPUs para atender interrupciones de hardware.
%soft
Porcentaje de tiempo empleado por la CPU o CPUs para atender interrupciones de software.
%guest
Porcentaje de tiempo empleado por la CPU o CPU para ejecutar un procesador virtual.
%gnice
Porcentaje de tiempo que la CPU o CPUs dedican a ejecutar un invitado con prioridad niced.
%idle
Porcentaje de tiempo que la CPU o CPUs estuvieron inactivas y el sistema no tuvo una solicitud pendiente de E/S de disco.
-V
Mostrar el número de versión y salir.
-v
Informar sobre el estado de las tablas de inodos, archivos y otras tablas del núcleo. Se muestran los siguientes valores:
dentunusd
Número de entradas de caché no utilizadas en la caché de directorios.
file-nr
Número de manejadores de archivos utilizados por el sistema.
inode-nr
Número de manejadores de inodos utilizados por el sistema.
pty-nr
Número de pseudo-terminales utilizados por el sistema.
-W
Informar estadísticas de intercambio (swapping). Se muestran los siguientes valores:

Número total de páginas de intercambio que el sistema trajo por segundo.
pswpout/s
Número total de páginas de intercambio que el sistema sacó por segundo.

-x
Informes extendidos: Muestra los valores mínimo y máximo además de los promedios al final del informe.

Informar sobre la actividad de los dispositivos TTY. Se muestran los siguientes valores:

ENTORNO

El comando sar tiene en cuenta las siguientes variables de entorno:

S_COLORS
Por defecto, las estadísticas se muestran en color cuando la salida está conectada a un terminal. Utilice esta variable para cambiar la configuración. Los valores posibles para esta variable son never (nunca), always (siempre) o auto (esta última es equivalente a la configuración predeterminada).
Tenga en cuenta que el color (ya sea rojo, amarillo o algún otro color) utilizado para mostrar un valor no indica ningún tipo de problema simplemente por el color. Solo indica diferentes rangos de valores.
S_COLORS_SGR
Especifique los colores y otros atributos utilizados para mostrar las estadísticas en el terminal. Su valor es una lista de capacidades separada por dos puntos que por defecto es C=33;22:I=32;22:N=34;1:R=31;22:W=35;1:X=31;1:Z=34;22. Las capacidades admitidas son:
C=
Subcadena SGR (Select Graphic Rendition) para comentarios insertados en los archivos binarios de datos diarios.
I=
Subcadena SGR para nombres o valores de elementos (por ejemplo, interfaces de red, número de CPU...)
N=
Subcadena SGR para valores de estadísticas distintos de cero.
R=
Subcadena SGR para mensajes de reinicio.
W= (o M=)
Subcadena SGR para valores porcentuales en el rango del 75% al 90% (o en el rango del 10% al 25% dependiendo del significado de la métrica). También se utiliza para valores negativos en el rango de -10 a -5.
X= (o H=)
Subcadena SGR para valores porcentuales mayores o iguales al 90% (o menores o iguales al 10% dependiendo del significado de la métrica). También se utiliza para valores negativos menores o iguales a -10.
Z=
Subcadena SGR para valores cero.
S_REPEAT_HEADER
Esta variable contiene el número máximo de líneas después del cual se debe mostrar una cabecera por sar cuando la salida no es un terminal.
S_TIME_DEF_TIME
Si esta variable existe y su valor es UTC entonces sar guardará sus datos en hora UTC (los datos se seguirán mostrando en hora local). sar también utilizará la hora UTC en lugar de la hora local para determinar el archivo de datos diario actual ubicado en el directorio /var/log/sa. Esta variable puede ser útil para servidores con usuarios ubicados en varias zonas horarias.
S_TIME_FORMAT
Si esta variable existe y su valor es ISO entonces la configuración regional actual se ignorará al imprimir la fecha en la cabecera del informe. El comando sar utilizará el formato ISO 8601 (AAAA-MM-DD) en su lugar. La marca de tiempo también cumplirá con el formato ISO 8601.

EJEMPLOS

sar -u 2 5
Informe sobre la utilización de la CPU cada 2 segundos. Se muestran 5 líneas.
sar -I --int=14 -o int14.file 2 10
Informe sobre estadísticas de IRQ 14 cada 2 segundos. Se muestran 10 líneas. Los datos se almacenan en un archivo llamado int14.file.
sar -r -n DEV -f /var/log/sa/sa16
Muestra estadísticas de memoria y red guardadas en el archivo de datos diario sa16.
sar -A
Muestra todas las estadísticas guardadas en el archivo de datos diario actual.

ERRORES

El sistema de archivos /proc debe estar montado para que el comando sar funcione.

No todas las estadísticas están necesariamente disponibles, dependiendo de la versión del kernel utilizada. sar asume que está utilizando al menos un kernel 2.6.

Aunque sar muestra unidades correspondientes a kilobytes (kB), megabytes (MB)..., en realidad utiliza kibibytes (kiB), mebibytes (MiB)... Un kibibyte es igual a 1024 bytes, y un mebibyte es igual a 1024 kibibytes.

ARCHIVOS

/var/log/sa/saDD
/var/log/sa/saYYYYMMDD

Los archivos de datos diarios de actividad del sistema estándar y su ubicación predeterminada. YYYY representa el año actual, MM representa el mes actual y DD representa el día actual.

/proc y /sys contienen varios archivos con estadísticas del sistema.
