NOMBRE

sane-config - obtener información sobre la versión instalada de libsane

SINOPSIS

sane-config [--prefix] [--exec-prefix] [--libs] [--cflags] [--ldflags] [--version] [--help [OPCIÓN]]

DESCRIPCIÓN

sane-config es una herramienta que se utiliza para determinar las opciones del compilador y del enlazador que deben usarse para compilar y enlazar frontends de SANE a una biblioteca backend de SANE (libsane).

OPCIONES

sane-config acepta las siguientes opciones (no se puede utilizar más de una opción a la vez):

--version
Imprime la versión actualmente instalada de libsane en la salida estándar.
--help OPCIÓN
Imprime un breve mensaje de uso. Si se especifica OPCIÓN, se imprime la ayuda para esa opción (por ejemplo, --libs) (si está disponible).
--libs
Imprime las bibliotecas adicionales que son necesarias para enlazar un frontend de SANE a libsane.
--ldflags
Imprime las opciones del enlazador que son necesarias para enlazar un frontend de SANE a libsane.
--cflags
Imprime las opciones del compilador que son necesarias para compilar un frontend de SANE.
--prefix
Imprime el prefijo utilizado durante la compilación de libsane.
--exec-prefix
Imprime el prefijo de ejecución utilizado durante la compilación de libsane.
