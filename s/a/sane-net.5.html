sane-net(5) SANE Scanner Access Now Easy sane-net(5)

NOMBRE

sane-net - backend de red SANE

DESCRIPCIÓN

La biblioteca sane-net implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a dispositivos de adquisición de imágenes a través de una conexión de red. Esto hace posible controlar dispositivos conectados a un host remoto y también proporciona un medio para otorgar a los usuarios acceso a recursos protegidos.

NOMBRES DE DISPOSITIVO

Este backend espera nombres de dispositivo con el siguiente formato:

host:dispositivo

Donde host es el nombre (o dirección IP) del host (remoto) y dispositivo es el nombre del dispositivo en este host al que se debe dirigir. Si el nombre del dispositivo no contiene dos puntos (:), entonces toda la cadena se trata como la cadena dispositivo para el host predeterminado. El host predeterminado es el host listado al final en el archivo de configuración (ver más abajo).

Se puede especificar una dirección IPv6 encerrada entre corchetes:

[::1]:dispositivo

CONFIGURACIÓN

El archivo net.conf contiene tanto las opciones del backend como una lista de nombres de host (o direcciones IP) a los que se debe contactar para las solicitudes de escaneo. Cualquier cosa que no sea una de las opciones listadas a continuación se tratará como un nombre de host.

connect_timeout = nsecs
Tiempo de espera (en segundos) para la conexión inicial al servidor saned(8). Esto evitará que el backend se bloquee durante varios minutos intentando conectarse a un host saned(8) que no responde (interrupción de red, host caído, ...). La variable de entorno SANE_NET_TIMEOUT también se puede usar para especificar el tiempo de espera en tiempo de ejecución.

Las líneas vacías y las líneas que comienzan con un signo de almohadilla (#) se ignoran. Tenga en cuenta que las direcciones IPv6 en este archivo no necesitan estar encerradas entre corchetes. A continuación se muestra un archivo de configuración de ejemplo:

scan-server.somedomain.firm
192.168.0.1
# esto es un comentario
localhost
::1

La lista de hosts anterior se puede ampliar en tiempo de ejecución utilizando la variable de entorno SANE_NET_HOSTS. Esta variable de entorno es una lista separada por dos puntos de nombres de host o direcciones IP que deben ser contactados además de los hosts mencionados en el archivo de configuración. Por ejemplo, un usuario podría establecer la variable de entorno en la cadena:

new.scanner.com:[::1]:192.168.0.2:scanner.univ.edu

Para solicitar que se contacte a los hosts new.scanner.com , [::1] , 192.168.0.2 y scanner.univ.edu además de los hosts listados anteriormente.

Para que este backend funcione correctamente, también es necesario definir el servicio sane-port en /etc/services con una línea de la siguiente forma:

sane-port 6566/tcp # SANE network scanner daemon

ARCHIVOS

/etc/sane.d/net.conf
El archivo de configuración del backend (ver también la descripción de SANE_CONFIG_DIR a continuación).
/usr/lib/sane/libsane-net.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-net.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por un punto y coma (`;'). Si esta variable no está configurada, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorios, entonces se buscan los directorios predeterminados después de los directorios especificados explícitamente. Por ejemplo, configurar SANE_CONFIG_DIR a "/tmp/config:" daría como resultado la búsqueda de los directorios tmp/config, ., y /etc/sane.d (en ese orden).
SANE_NET_HOSTS
Una lista separada por dos puntos de nombres de host o direcciones IP a contactar por este backend.
SANE_NET_TIMEOUT
Número de segundos a esperar una respuesta del servidor saned(8) para la solicitud de conexión inicial.
SANE_DEBUG_NET
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.

ERRORES

Si saned(8) ha caducado, el backend net puede entrar en un bucle con solicitudes de autorización.
