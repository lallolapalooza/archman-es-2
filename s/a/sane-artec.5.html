NOMBRE

sane-artec - Backend SANE para escáneres planos Artec

DESCRIPCIÓN

La biblioteca sane-artec implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a escáneres planos SCSI de Artec/Ultima. En la actualidad, los siguientes escáneres se sabe que funcionan al menos parcialmente con este backend:

* Artec A6000C
* Artec A6000C PLUS
* Artec ViewStation AT3
* BlackWidow BW4800SP (rebadged Artec AT3)
* Artec ViewStation AT6
* Artec ViewStation AT12
* Artec AM12S
* Plustek 19200S (rebadged Artec AM12S)

Aunque esta página del manual se actualiza generalmente con cada lanzamiento, la información actualizada sobre nuevos lanzamientos y consejos útiles adicionales están disponibles en la página principal del backend: http://www4.infi.net/~cpinkham/sane.

CONFIGURACIÓN

El contenido del archivo artec.conf es una lista de nombres de dispositivos que corresponden a escáneres Artec. Las líneas vacías y las líneas que comienzan con un signo de almohadilla (#) se ignoran. Consulte sane-scsi(5) para obtener detalles sobre lo que constituye un nombre de dispositivo válido.

Archivo de ejemplo: 

# artec.conf
#
# esto es un comentario.
#
# esta línea dice que busque cualquier dispositivo SCSI que sea un escáner y tenga
#     una cadena de proveedor de 'ULTIMA'
scsi ULTIMA
#
# la siguiente línea fuerza al backend a asumir que el siguiente escáner encontrado tiene
#     la cadena de proveedor especificada (útil para probar modelos rebadged).
vendor ULTIMA
#
# la siguiente línea fuerza al backend a asumir que el siguiente escáner encontrado tiene
#     la cadena de modelo especificada (útil para probar modelos rebadged).
model AT3
#
# ahora una línea que realmente especifica un dispositivo. El backend va a
#     asumir que es un Artec/Ultima AT3 porque forzamos el proveedor y el modelo
#     anteriormente.
/dev/scanner
#
# una vez que llegamos a una línea de dispositivo escáner, el proveedor y modelo forzados
#     se 'olvidan', por lo que el proveedor y modelo para este siguiente dispositivo se
#     determinarán a partir del resultado de una consulta SCSI.
/dev/sge
#

CONSEJOS PARA EL ADAPTADOR SCSI

Algunos escáneres Artec vienen con un adaptador SCSI incluido. Si su escáner vino con tarjetas SCSI DTC ISA, probablemente pueda usarlas con kernels recientes (>= 2.2.0) usando el soporte genérico NCR5380. Debe pasar el siguiente argumento de arranque al kernel: "dtc3181e=0x2c0,0"
No tengo información sobre el adaptador SCSI PCI incluido con algunos escáneres Artec más nuevos.

ARCHIVOS

/etc/sane.d/artec.conf
El archivo de configuración del backend (ver también la descripción de SANE_CONFIG_DIR abajo).
/usr/lib/sane/libsane-artec.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-artec.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por punto y coma (`;'). Si esta variable no está configurada, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorios, entonces se buscan los directorios predeterminados después de los directorios especificados explícitamente. Por ejemplo, configurar SANE_CONFIG_DIR a "/tmp/config:" resultaría en que los directorios tmp/config, . y /etc/sane.d se buscaran (en este orden).
SANE_DEBUG_ARTEC
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad: SANE_DEBUG_ARTEC valores: 
Número  Observación
 0       imprime errores importantes
 1       imprime errores
 2       imprime sense
 3       imprime advertencias
 4       imprime consulta del escáner
 5       imprime información
 6       imprime información menos importante
 7       imprime procedimientos llamados importantes
 8       imprime todos los procedimientos llamados
 9       imprime mensajes de información/datos de procedimiento
 10      imprime rutinas de inicialización de sane llamadas
 11      imprime procedimientos de sane llamados
 12      imprime información de sane
 13      imprime mensajes de control de opciones de sane
 50      imprime mensajes detallados de datos/depuración
 == 100  imprime datos de calibración gamma RGB de software
 == 101  imprime datos crudos del escáner al archivo artec.data.raw
 == 128  imprime todos los mensajes

Ejemplo: exportar SANE_DEBUG_ARTEC=13

ERRORES

Errores conocidos en esta versión: los usuarios de A6000C+ con firmware v1.92 o anterior tienen problemas con el backend, la causa no se ha determinado. A veces el backend no es particularmente robusto, es posible que bloquee el bus SCSI (y/o la máquina) al no tener suficiente paciencia al escanear. La corrección gamma de 3 canales no está implementada y la corrección gamma de canal único no funciona del todo bien en modelos distintos del AT3.
