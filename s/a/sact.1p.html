SACT(1P) Manual del programador POSIX SACT(1P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sact — imprime la actividad de edición de archivos SCCS actual (DESARROLLO)

SINOPSIS

sact archivo...

DESCRIPCIÓN

La utilidad sact informará al usuario de cualquier delta pendiente en un archivo SCCS con nombre, escribiendo una lista en la salida estándar. Esta situación ocurre cuando get -e se ha ejecutado previamente sin una ejecución posterior de delta, unget o sccs unedit.

OPCIONES

Ninguna.

OPERANDOS

Se admitirá el siguiente operando:

archivo
Una ruta de un archivo SCCS existente o un directorio. Si archivo es un directorio, la utilidad sact se comportará como si cada archivo del directorio se especificara como un archivo con nombre, excepto que los archivos que no son SCCS (el componente final de la ruta no comienza con s.) y los archivos no legibles se ignorarán silenciosamente.

Si aparece exactamente un operando archivo y es '-', se leerá la entrada estándar; cada línea de la entrada estándar se tomará como el nombre de un archivo SCCS a procesar. Los archivos que no son SCCS y los archivos no legibles se ignorarán silenciosamente.

ENTRADA ESTÁNDAR

La entrada estándar será un archivo de texto utilizado solo cuando el operando archivo se especifica como '-'. Cada línea del archivo de texto se interpretará como una ruta SCCS.

ARCHIVOS DE ENTRADA

Cualquier archivo SCCS interrogado son archivos de formato no especificado.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de sact:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en una cadena de valor no vacía, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a multibyte en argumentos y archivos de entrada).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en la salida de error estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASINCRONOS

Predeterminado.

SALIDA ESTÁNDAR

La salida para cada archivo con nombre consistirá en una línea con el siguiente formato:

"%s %s %s %s %s\n", <SID>, <nuevo SID>, <inicio_sesion>, <fecha>, <hora>
<SID>
Especifica el SID de un delta que existe actualmente en el archivo SCCS al que se realizan cambios para crear el nuevo delta.
<nuevo SID>
Especifica el SID para el nuevo delta a crear.
<inicio_sesion>
Contiene el nombre de inicio de sesión del usuario que crea el delta (es decir, que ejecutó un get para editar).
<fecha>
Contiene la fecha en que se ejecutó get -e, en el formato utilizado por la palabra clave de datos prs :D:.
<hora>
Contiene la hora en que se ejecutó get -e, en el formato utilizado por la palabra clave de datos prs :T:.

Si hay más de un archivo con nombre o si se nombra un directorio o la entrada estándar, cada ruta se escribirá antes que cada una de las líneas anteriores:

"\n%s:\n", <ruta>

ERROR ESTÁNDAR

El error estándar se utilizará solo para mensajes informativos opcionales relacionados con archivos SCCS sin deltas pendientes, y para mensajes diagnósticos.
