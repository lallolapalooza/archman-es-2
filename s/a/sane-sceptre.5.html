NOMBRE

sane-sceptre - Backend de SANE para escáneres SCEPTRE

DESCRIPCIÓN

La biblioteca sane-sceptre implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a escáneres planos Sceptre. ¡Este backend debe considerarse software de calidad beta! Por favor, informe de cualquier comportamiento extraño al mantenedor del backend o a la lista de correo de SANE.

En la actualidad, solo se sabe que un escáner funciona con este backend:

Modelo                      Tipo de conexión
---------------------------  -------------------
Sceptre VividScan S1200      SCSI

La marca de este escáner es KINPO, por lo que otros escáneres de ese fabricante también podrían funcionar (por ejemplo, el S600).

OPCIONES

Las opciones que admite el backend se pueden seleccionar a través de opciones de línea de comandos para programas como scanimage(1) o a través de elementos de la interfaz gráfica en xscanimage(1) o xsane(1).

Las opciones de línea de comandos válidas y su sintaxis se pueden listar usando

scanimage --help -d sceptre
Modo de escaneo
--mode Lineart|Halftone|Gray|Color
Selecciona el modo básico de funcionamiento del escáner. El modo Lineart y Halftone son solo blanco y negro (1 bit). Gray producirá 256 niveles de gris (8 bits). Color producirá una imagen en color de 24 bits. El escáner admite 30 bits internamente, pero solo exporta 24.
--resolution 50..1200
Selecciona la resolución para un escaneo. El escáner puede realizar varias resoluciones entre 50 y 1200.
--halftone-pattern 1|2|3|4
Selecciona el patrón que se utiliza en el modo Halftone.
--gamma-correction Default|User Defined|High Density Printing|Low density printing|High contrast printing
controla la corrección gamma interna del escáner.
--custom-gamma
Permite al usuario especificar una tabla gamma (ver los siguientes 3 parámetros). Solo modo Color.
--red-gamma-table
Se puede usar para descargar una tabla gamma definida por el usuario para el canal rojo. La tabla debe tener 256 bytes de longitud. Solo modo Color.
--green-gamma-table
Se puede usar para descargar una tabla gamma definida por el usuario para el canal verde. La tabla debe tener 256 bytes de longitud. Solo modo Color.
--blue-gamma-table
Se puede usar para descargar una tabla gamma definida por el usuario para el canal azul. La tabla debe tener 256 bytes de longitud. Solo modo Color.
--threshold 0..255
Establece el umbral para los píxeles en blanco y negro en el modo Lineart. Los valores posibles van de 0 (más oscuro) a 255 (más claro).
--preview
Solicita un escaneo de vista previa. La resolución utilizada para ese escaneo es de 30 dpi y el área de escaneo es la máxima permitida. El modo de escaneo lo selecciona el usuario. El valor predeterminado es "no".
Las opciones de geometría
-l -t -x -y
controlan el área de escaneo: -l establece la coordenada x de la esquina superior izquierda, -t la coordenada y de la esquina superior izquierda, -x selecciona el ancho y -y la altura del área de escaneo. Todos los parámetros se especifican en milímetros por defecto.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/sceptre.conf solo admite un elemento: el nombre del dispositivo a utilizar (por ejemplo, /dev/scanner).

ARCHIVOS

/usr/lib/sane/libsane-sceptre.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-sceptre.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_DEBUG_SCEPTRE
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Los niveles más bajos reducen la verbosidad.

LIMITACIONES

Resoluciones
El controlador TWAIN de Windows se puede configurar a cualquier resolución entre 50 y 1200 (excluida la interpolación de software). Este backend no puede. Solo hay disponibles un puñado de resoluciones, aunque deberían ser suficientes.

ERRORES

Ninguno conocido.
