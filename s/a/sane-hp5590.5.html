sane-hp5590(5) SANE Scanner Access Now Easy sane-hp5590(5)

NOMBRE

sane-hp5590 - Backend SANE para escáneres Hewlett-Packard 4500C/4570C/5500C/5550C/5590/7650 Workgroup/Document

DESCRIPCIÓN

La biblioteca sane-hp5590 implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a los siguientes escáneres Workgroup/Document de Hewlett-Packard:

•
ScanJet 4500C
•
ScanJet 4570C
•
ScanJet 5500C
•
ScanJet 5550C
•
ScanJet 5590
•
ScanJet 7650

Si usted posee un escáner distinto de los enumerados arriba que funciona con este backend, por favor háganoslo saber enviando el nombre exacto del modelo del escáner y los IDs de vendedor y dispositivo USB (por ej. de /sys/bus/usb/devices, sane-find-scanner(1) o syslog) a nosotros. Incluso si el nombre del escáner es solo ligeramente diferente de los modelos mencionados anteriormente, por favor háganoslo saber.

OPCIONES

Las opciones que soporta el backend pueden seleccionarse a través de opciones de línea de comandos para programas como scanimage(1) o a través de elementos de interfaz gráfica en xscanimage(1) o xsane(1). Las opciones válidas de línea de comandos y su sintaxis se pueden listar usando:

scanimage --help -d hp5590:interfaz:dispositivo

donde interfaz y dispositivo especifican el dispositivo en cuestión, como en el archivo de configuración. Añada --all-options para listar también las opciones de lectura de hardware. El parámetro -d y su argumento pueden omitirse para obtener información sobre el primer escáner identificado.

Use el comando:

scanimage -L

para listar todos los dispositivos reconocidos por su instalación SANE.

OPCIONES ESPECÍFICAS DEL DISPOSITIVO

-l n
Posición X superior izquierda del área de escaneo en mm. Rango permitido: 0 .. 215.889.
-t n
Posición Y superior izquierda del área de escaneo en mm. Rango permitido: 0 .. 297.699.
-x n
Ancho X del área de escaneo en mm. Rango permitido: 0 .. 215.889.
-y n
Alto Y del área de escaneo en mm. Rango permitido: 0 .. 297.699.

Por defecto, se escaneará el tamaño máximo.

--mode modo
Selecciona el modo de color. modo debe ser uno de: “Color”, “Color (48 bits)”, “Gris”, “Lineart”.
•
“Color” - El escaneo se realiza con 3 * 8 bits de valores de color RGB por píxel.
•
“Color (48 bits)” - El escaneo se realiza con 3 * 16 bits de valores de color RGB por píxel.
•
“Gris” - El escaneo se realiza con 1 valor de gris de 8 bits por píxel.
•
“Lineart” - El escaneo se realiza con 1 bit de valor blanco y negro por píxel.
--source fuente
Selecciona la fuente para el escaneo. fuente debe ser uno de: “Plano”, “ADF”, “ADF Duplex”, “TMA Diapositivas”, “TMA Negativos”.
•
“Plano” - Escanea el documento en el cristal plano.
•
“ADF” - Escanea las caras frontales de los documentos con el alimentador automático de documentos.
•
“ADF Duplex” - Escanea las caras frontales y traseras de los documentos con el alimentador automático de documentos. Nota: las imágenes de la cara trasera deben ser rotadas en un paso de postprocesamiento separado.
•
“TMA Diapositivas” - Escaneo de diapositivas con adaptador de medios transparentes. (No totalmente soportado por el backend hp5590).
•
“TMA Negativos” - Escaneo de película negativa con adaptador de medios transparentes. (No totalmente soportado por el backend hp5590).
--resolución res
Establece la resolución de la imagen escaneada en dpi. res debe ser uno de: 100, 200, 300, 600, 1200, 2400.

Configuraciones por defecto: Lineart, Plano, 100 dpi.

--extender-tiempo-de-espera-lámpara[=sí|no]
Extiende el período de tiempo de espera de la lámpara. no = 15 minutos, sí = 1 hora. (Por defecto: no)
--esperar-botón[=sí|no]
Espera la pulsación de un botón antes de que comience el escaneo. (Por defecto: no)
--vista-previa[=sí|no]
Solicita un escaneo de calidad de vista previa. (Por defecto: no)
--ocultar-píxel-fin-de-página[=sí|no]
Oculta los píxeles indicadores de fin de página y los sobrescribe con el color de los píxeles vecinos. (Por defecto: sí)
El escáner utiliza el último píxel en cada línea de escaneo para almacenar el estado de fin de página. Esto es necesario para detectar el final de la hoja del documento cuando se utiliza el alimentador automático de documentos (ADF). Desafortunadamente, los píxeles de fin de página también se generan en escaneos planos. Se recomienda ocultar estos píxeles.
--modo-líneas-finales modo
Modo de relleno de las líneas finales después del fin de página cuando se utiliza el alimentador automático de documentos (ADF). modo debe ser uno de: “último”, “crudo”, “raster”, “blanco”, “negro”, “color”. (Por defecto: “último”)
•
“último” = repite la última línea de escaneo (recomendado),
•
“crudo” = lee datos de escaneo crudos (no recomendado),
•
“raster” = genera un patrón de píxeles en blanco y negro,
•
“blanco” = píxeles blancos,
•
“negro” = píxeles negros,
•
“color” = píxeles de color RGB o gris (ver siguiente opción).
--color-líneas-finales n
Establece el valor de color para el relleno de las líneas de escaneo finales en el modo de líneas finales “color” (ver opción anterior). (Color por defecto: violeta)
El valor de color RGB debe especificarse y calcularse como 65536 * r + 256 * g + b, donde r, g, b son valores en el rango de 0 .. 255.

OPCIONES DE LECTURA

Las siguientes opciones permiten leer el estado del botón, el valor del contador, la configuración de color y el estado del documento en el ADF. Esto puede usarse para controlar programáticamente opciones del escáner correspondientes, como cambiar entre el modo plano y ADF, o activar tareas de postprocesamiento después del escaneo.

--botón-presionado
Obtiene el ID del último botón presionado. El ID es uno de “ninguno”, “encendido”, “escanear”, “coleccionar”, “archivo”, “email”, “copiar”, “arriba”, “abajo”, “modo”, “cancelar”.
El escáner almacena el ID del último botón presionado hasta que se lee. Después de leerlo, el estado se reinicia y las lecturas posteriores devolverán “ninguno”.
--led-color
Obtiene el estado de los indicadores LED de color. El estado es “color” o “blanco_negro”.
sane-hp5590.5.en

NAME

sane-hp5590 - The SANE backend for HP 5590 scanner family

DESCRIPTION

The sane-hp5590 is a backend for SANE (Scanner Access Now Easy) that supports the HP 5590 scanner family.

The supported models are:

  • HP ScanJet 5590

This backend was tested with the HP ScanJet 5590. It is not guaranteed that it will work with other scanners in the family.

DEVICE SPECIFIC OPTIONS

This backend does not offer any device specific options.

READ OUT OPTIONS

The following options can be used to read out information from the scanner.

--counter-value
Obtiene el valor del contador tal como se muestra en la pantalla LCD. El valor está en el rango de 1..99.
--doc-in-adf
Obtiene el estado del indicador de documento disponible del alimentador automático de documentos (ADF). El estado es "yes" o "no".

HINTS FOR USERS OF SCANBD

scanbd(8) es un demonio de botones del escáner, que puede leer los botones del escáner y activar acciones de escaneo.

No utilice la antigua interfaz scanbuttond(8) con hp5590. Está obsoleta y ya no debe utilizarse. La interfaz regular de scanbd(8) está totalmente soportada por la versión actual del backend de hp5590.

Este ejemplo muestra un archivo de configuración mínimo y el archivo de script correspondiente para scanbd(8) para ser incluido en scanbd.conf.

•
hp5590.conf
device hp5590 {
    # Device matching
    filter = "^hp5590.*"
    desc = "HP5590 Scanner Family"
    # Read out counter value and store in environment variable.
    function function_lcd_counter {
        filter = "^counter-value.*"
        desc   = "hp5590: LCD counter"
        env    = "SCANBD_FUNCTION_LCD_COUNTER"
    }
    # Run scan script when button is pressed.
    action do-scan {
        filter = "^button-pressed.*"
        desc   = "hp5590: Scan button pressed"
        script = "scan_action.script"
        string-trigger {
            from-value  = "none"
            to-value    = "scan"
        }
    }
}
•
scan_action.script
#!/bin/bash
echo device = $SCANBD_DEVICE
echo action = $SCANBD_ACTION
echo counter = $SCANBD_FUNCTION_LCD_COUNTER
scanfile="$HOME/tmp/scans/scan-$(date +%s).pnm"
case $SCANBD_ACTION in
do-scan)
    scanimage -d "$SCANBD_DEVICE" > "$scanfile"
    ;;
*)
    echo Warning: Unknown scanbd action: "$SCANBD_ACTION"
    ;;
esac

ENVIRONMENT

Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend.

SANE_DEBUG_HP5590

Niveles de depuración más altos aumentan la verbosidad de la salida:

10 - generic processing
20 - verbose backend messages
40 - HP5590 high-level commands
50 - HP5590 low-level (USB-in-USB) commands
Ejemplo:
export SANE_DEBUG_HP5590=50
