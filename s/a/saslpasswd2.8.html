SASLPASSWD2(8) Manual del Administrador del Sistema SASLPASSWD2(8)

NOMBRE

saslpasswd2 - establece la contraseña de un usuario de sasl

SINOPSIS

saslpasswd2 [-p] [-d] [-c] [-n] [-f archivo] [-u dominio] [-a nombreapp] [-v] idusuario

DESCRIPCIÓN

saslpasswd2 es utilizado por un administrador del servidor para establecer la contraseña de sasl de un usuario para programas de servidor y mecanismos SASL que utilizan la base de datos estándar de secretos de usuario de libsasl.

OPCIONES

-p
Modo de tubería - saslpasswd2 no solicitará la contraseña ni verificará que se introdujo correctamente. Este es el valor predeterminado cuando la entrada estándar no es una terminal.
-c
Crea una entrada para el usuario si el usuario aún no existe. Esto es mutuamente excluyente con la bandera -d (eliminar usuario).
-d
Elimina la entrada del usuario. Esto es mutuamente excluyente con la bandera -c (crear usuario).
-n
No establezca la propiedad userPassword en texto plano para el usuario. Solo se establecerán secretos específicos del mecanismo (por ejemplo, OTP, SCRAM, SRP)
-u dominio
use dominio como dominio de usuario (realm).
-f archivo
use archivo para sasldb
-a nombreapp
use nombreapp como nombre de aplicación.
-v
Imprime el número de versión de libsasl2 y sale.
