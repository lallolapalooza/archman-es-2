NOMBRE

sane-escl - Backend de SANE para escáneres eSCL

DESCRIPCIÓN

La biblioteca sane-escl implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a escáneres con protocolo eSCL.

Actualmente, los siguientes modelos funcionan con este backend (esta lista no es exhaustiva):

BROTHER DCP-J772DW, DCP-L2530DW
BROTHER HL-L2590DW
BROTHER MFC-J4540DW, MFC-J985DW, MFC-J1300DW
CANON IR C3520
CANON PIXMA MG5765
CANON PIXMA G4511, G7050
CANON PIXMA TR4520, TR4540, TR4550, TR4551, TR7500, TR8500
CANON PIXMA TR8520
CANON PIXMA TS3100, TS3150, TS3151, TS3152, TS3300, TS3350
CANON PIXMA TS3351, TS3352, TS3450, TS3451, TS3452, TS5350
CANON PIXMA TS5351, TS5150, TS6150, TS8050, TS8350, TS9100
EPSON ET-2750, ET-3750, ET-4750
EPSON EcoTank L3160
EPSON XP-4200, XP-6100
HP DESKJET 2710, DESKJET 2723, DESKJET 3760
HP LASERJET ENTREPRISE FLOW MFP M578,
HP LASERJET MFP M28W, LASERJET MFP M630
HP OFFICEJET 4630, OFFICEJET PRO 8610
RICOH SP3710S
XEROX VERSALINK C7220

El backend sane-escl para SANE soporta dispositivos AirScan/eSCL que se anuncian a sí mismos en mDNS como _uscan._utcp o _uscans._utcp. Si el dispositivo está disponible, el backend sane-escl recupera estas capacidades. El usuario configura e inicia el escaneo. Una lista de dispositivos que usan el protocolo eSCL se puede encontrar en https://support.apple.com/en-us/HT201311. Aunque se espera que estos dispositivos funcionen, su experiencia puede variar.

ARCHIVOS

/etc/sane.d/escl.conf
El archivo de configuración del backend.
/usr/lib/sane/libsane-escl.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-escl.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_DEBUG_ESCL
Si la biblioteca fue compilada con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.
