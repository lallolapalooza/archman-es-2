SAMBA-LOG-PARSER(1) Comandos de usuario SAMBA-LOG-PARSER(1)

NOMBRE

samba-log-parser - Analizador de rastreo de Samba (winbind).

Opciones:
-h, --help mostrar esta ayuda y salir
--traceid ID especificar el traceid de los registros de rastreo
--pid PID especificar el pid del cliente winbind
--breakdown desglosar los rastreos en archivos por traceid
--merge-by-timestamp fusionar registros por marca de tiempo
--flow mostrar los rastreos de flujo de solicitud/subsolicitud
--flow-compact mostrar los rastreos de flujo de solicitud/subsolicitud sin detalles de dcerpc

SINOPSIS

samba-log-parser {ruta} [--pid=PID] [--traceid=ID] [--breakdown] [--merge-by-timestamp] [--flow] [--flow-compact] [-h|--help]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto samba(7).

El programa samba-log-parser analiza los registros de samba winbind.

OPCIONES

Las siguientes opciones están disponibles para el programa samba-log-parser.

--pid=PID

Muestra los rastreos para el cliente winbind con el PID correspondiente.

--traceid=ID

Muestra los rastreos con el campo de encabezado de depuración traceid coincidente.

--breakdown

Desglosa todos los rastreos en archivos separados en el directorio de trabajo actual. Para cada traceid, se crean tres archivos: traceid.full traceid.flow traceid.flowcompact

--merge-by-timestamp

Ordena las líneas de rastreo según la marca de tiempo. Funciona también con archivos de registro sin el campo de encabezado traceid.

--flow

Muestra el flujo de solicitud/subsolicitud.

--flow-compact

Muestra el flujo de solicitud/subsolicitud sin los detalles de la llamada dcerpc.

EJEMPLOS

Muestra los rastreos de flujo para el ID de rastreo 1234 del archivo de registro log.winbind:

# samba-log-parser --traceid 1234 --flow /var/log/samba/log.winbind

Muestra los rastreos completos para el cliente winbind con PID 999999 ordenados por marca de tiempo para los archivos de registro en el directorio de registro de samba:

# samba-log-parser --pid 999999 --merge-by-timestamp /var/log/samba

Desglosa los rastreos en archivos separados según el traceid ordenados por marca de tiempo para los archivos de registro en el directorio de registro de samba:

# samba-log-parser --breakdown --merge-by-timestamp /var/log/samba

Ordena los rastreos por marca de tiempo para los archivos de registro en el directorio de registro de samba. Los rastreos no necesitan contener el campo de encabezado traceid.

# samba-log-parser --merge-by-timestamp /var/log/samba
