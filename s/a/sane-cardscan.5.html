NOMBRE

sane-cardscan - Backend SANE para escáneres USB Corex CardScan

DESCRIPCIÓN

La biblioteca sane-cardscan implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a los escáneres de formato pequeño Corex CardScan 800c y 600c.

El backend solo admite modos de escala de grises y color y medios de longitud (teóricamente) infinita.

Este backend puede admitir otros escáneres. La mejor manera de determinar el nivel de soporte es obtener un rastreo del controlador de Windows en acción y enviárselo al autor.

OPCIONES

El backend cardscan admite las siguientes opciones:

--mode Gray|Color
Selecciona el modo para el escaneo.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración cardscan.conf se utiliza para indicar al backend cómo buscar escáneres y proporcionar opciones que controlen el funcionamiento del backend. Este archivo se lee cada vez que el frontend solicita al backend una lista de escáneres, generalmente solo cuando se inicia el frontend. Si el archivo de configuración no existe, el backend utilizará un conjunto de valores predeterminados compilados, que son idénticos al archivo de configuración predeterminado que se envía con SANE.

Los escáneres se pueden especificar en el archivo de configuración de 2 maneras:

"usb 0x04c5 0x1042" (u otros ids de vendedor/producto)

Solicita al backend que busque en todos los buses usb del sistema un dispositivo que utilice ese id de vendedor y producto. Luego se consultará al dispositivo para determinar si es un escáner cardscan.

"usb /dev/usb/scanner0" (u otro archivo de dispositivo)

Algunos sistemas utilizan un controlador de kernel para acceder a los escáneres usb. Este método no ha sido probado.

Además, hay dos opciones de configuración que controlan el protocolo utilizado por el backend:

"lines_per_block 16" (u otro número de 1 a 32)

Controla el número de líneas de datos de imagen que se adquirirán en cada pasada. Los escáneres más antiguos requerirán que este número sea menor, a menudo 1.

"has_cal_buffer 1" (1 o 0)

Hace que el backend obtenga datos de calibración del escáner durante la inicialización. Los escáneres más antiguos no admiten esta solicitud y deben configurarse en 0.

ENTORNO

El backend utiliza una única variable de entorno, SANE_DEBUG_CARDSCAN, que habilita la salida de depuración en stderr. Los valores válidos son:

5 Errores
10 Rastreo de funciones
15 Detalle de funciones
20 Comandos de opciones
25 Rastreo SCSI/USB
30 Detalle SCSI/USB
35 Ruido inútil

PROBLEMAS CONOCIDOS

El escáner no parece tener mucho control posible, por lo que el backend no puede establecer valores de coordenadas x/y, resoluciones, etc. Estas cosas podrían simularse en el backend, pero hay muchas herramientas de línea de comandos.
El backend tampoco envía todos los comandos que el controlador de Windows hace, por lo que puede que no funcione igual.
El backend no tiene las opciones de calibración o expulsión del controlador de Windows.
