NOMBRE

sane-canon630u - Backend SANE para el escáner plano USB Canon 630u

DESCRIPCIÓN

La librería sane-canon630u implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a los siguientes escáneres planos Canon:

CanoScan 630u
CanoScan 636u

El escaneo en color es compatible a 75, 150, 300 y 600 dpi, y la ganancia analógica y gamma son ajustables.

SE BIENVENIDOS LOS PROBADORES. Envía tus informes de errores y comentarios a Nathan Rutman <nthn1@yahoo.com>.

CONFIGURACIÓN

El contenido del archivo canon630u.conf es una lista de nombres de dispositivos que corresponden a escáneres Canon USB. Las líneas vacías y las líneas que comienzan con un signo de almohadilla (#) se ignoran. Solo se puede listar un nombre de dispositivo en canon630u.conf. El programa sane-find-scanner(1) ayuda a descubrir el nombre de dispositivo correcto. En Linux, tal nombre de dispositivo podría ser /dev/usb/scanner0 por ejemplo. Ver sane-usb(5) para detalles.

Este controlador de escáner específico del producto utiliza el controlador USB del kernel de bajo nivel "scanner". Busca "Driver=usbscanner" en /proc/bus/usb/devices. Si "Driver=(none)", intenta forzarlo con insmod scanner vendor=0x04a9 product=0x2204

NOTAS

Debido a la falta de voluntad de Canon para proporcionar documentación del escáner, este software fue desarrollado analizando el tráfico USB del controlador de Windows 2000. Así que cosas como el procedimiento de calibración, lo inventé yo; parece funcionar para mi escáner. Si tienes quejas, házmelo saber.

Este controlador requiere la capacidad de enviar Mensajes de Control USB, disponibles en el kernel 2.4.12 o posterior.

Algunos usuarios han informado que este controlador no funciona en absoluto. Este parece ser un problema específico del hardware, aunque no sé cuál es exactamente el problema. Si tienes problemas, por favor envíame la información en /proc/bus/usb/devices, /proc/pci, la versión del controlador scanner.c del kernel de /var/log/messages, y la salida de SANE_DEBUG_CANON630U=12 scanimage > /dev/null

ARCHIVOS

/etc/sane.d/canon630u.conf
El archivo de configuración del backend (ver también la descripción de SANE_CONFIG_DIR a continuación).
/usr/lib/sane/libsane-canon630u.a
La librería estática que implementa este backend.
/usr/lib/sane/libsane-canon630u.so
La librería compartida que implementa este backend (presente en sistemas que soportan carga dinámica).
/tmp/canon.cal
El archivo de calibración utilizado para normalizar el brillo de los píxeles. Se calcula cada vez que el escáner se usa por primera vez después de haber perdido energía. Eliminar este archivo forzará la recalibración.

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), bajo OS/2, están separados por un punto y coma (`;'). Si esta variable no está establecida, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorio, entonces los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, establecer SANE_CONFIG_DIR a "/tmp/config:" resultaría en la búsqueda de los directorios tmp/config, ., y /etc/sane.d (en este orden).
SANE_DEBUG_CANON630U
Si la librería fue compilada con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Niveles de depuración más altos aumentan la verbosidad de la salida.

Ejemplo:
SANE_DEBUG_CANON630U=12 scanimage > /dev/null
