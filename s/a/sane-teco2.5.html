sane-teco2(5) SANE Scanner Access Now Easy sane-teco2(5)

NOMBRE

sane-teco2 - backend SANE para escáneres TECO / RELISYS

DESCRIPCIÓN

La biblioteca sane-teco2 implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a algunos escáneres planos SCSI TECO. Este backend debe considerarse software de calidad beta. Los escáneres TECO se venden bajo diversas marcas como Mustek, Relisys, Piotech, Primax, TRUST. Es posible que este backend no admita el tuyo.

Los escáneres que deberían funcionar con este backend son:

   Fabricante Modelo          Modelo TECO     estado
--------------------------- --------------  -----------
  Mustek ScanMagic 4830S      VM3575         no probado
  Primax Jewel 4800           VM356A         bueno
  Primax Profi 9600           VM6575         básico
  Primax Profi 19200          VM6586         bueno
  Relisys APOLLO Express 3    VM356A         básico
  Relisys APOLLO Express 6    VM6565         bueno
  Relisys APOLLO Express 12   ?              no probado
  Relisys AVEC II S3          VM3564         bueno
  Relisys AVEC Super 3        VM3575         básico
  Relisys SCORPIO Pro         VM6575         bueno
  Relisys SCORPIO Pro-S       VM6586         no probado
  Relisys SCORPIO Super 3     VM3575         bueno

Para todos estos escáneres, los modos lineart y gris funcionan bien. Sin embargo, la mayoría de ellos no admiten más que un puñado de resoluciones en modo color. Consulte la página principal del backend (en AUTOR) para conocer el estado exacto de cada escáner.

Tenga en cuenta que los escáneres no probados no serán compatibles directamente. Debería contactar al autor para eso.

El número VM de TECO generalmente se puede encontrar en la parte posterior del escáner. También es parte del ID de la FCC.

Las opciones que admite el backend se pueden seleccionar a través de opciones de línea de comandos en programas como scanimage(1) o a través de elementos de interfaz gráfica en xscanimage(1), xsane(1), quiteinsane(1) o kooka(1).

Si tiene algún éxito con un escáner no listado aquí, o si nota algún comportamiento extraño, por favor informe al mantenedor del backend o a la lista de correo de SANE.

OPCIONES

Las opciones válidas de línea de comandos y su sintaxis se pueden listar usando:

scanimage --help -d teco2
Modo de Escaneo
--mode Lineart|Gray|Color
selecciona el modo básico de operación del escáner. El modo Lineart es solo blanco y negro (1 bit). El modo Gray producirá 256 niveles de gris (8 bits). Color producirá una imagen a color de 24 bits.
--resolution 1..600
Selecciona la resolución para un escaneo. El escáner puede realizar todas las resoluciones entre 1 y 600, en incrementos de 1, para Lineart y Gray. Para Color, hay un conjunto limitado de resoluciones disponibles.

Nota: Todos los valores con resolución vertical en dpi > 300 (300 x 600) o 600 (600 x 1200) resultan en una proporción incorrecta para el escaneo. La proporción se puede ajustar con el siguiente comando convert(1) de imagemagick:
convert -geometry (dpi/max_xdpi * 100%)x100%
max_xdpi es para la constante vm3575 con 300 dpi, por ejemplo, 600 dpi se ajusta con: convert -geometry 200%x100%

--preview
solicita un escaneo de previsualización. La resolución utilizada para ese escaneo es de 50 dpi (para VM356A y VM6575, 75 dpi) y el área de escaneo es el máximo permitido. El modo de escaneo es seleccionado por el usuario. El valor predeterminado es "no".
Opciones de geometría
-l, -t, -x, -y
Controlan el área de escaneo: -l establece la coordenada x de la esquina superior izquierda, -t la coordenada y de la esquina superior izquierda, -x selecciona el ancho y -y la altura del área de escaneo. Todos los parámetros se especifican en milímetros por defecto.
Opciones de mejora
--custom-gamma (sin opción de gamma personalizada para VM3564 y VM356A)
(solo en modo color) permite al usuario especificar una tabla gamma (ver los siguientes 3 parámetros).

OPCIONES PARA MODO COLOR

Estas opciones son válidas solo para el modo de escaneo Color.

--red-gamma-table
Se puede usar para descargar una tabla gamma definida por el usuario para el canal rojo. La tabla debe tener 256 bytes de longitud.
--green-gamma-table
Se puede usar para descargar una tabla gamma definida por el usuario para el canal verde. La tabla debe tener 256 bytes de longitud.
--blue-gamma-table
Se puede usar para descargar una tabla gamma definida por el usuario para el canal azul. La tabla debe tener 256 bytes de longitud.

OPCIONES SOLO PARA VM3564, VM356A, VM3575 y VM6575

Estas opciones solo están disponibles para los modelos VM3564, VM356A, VM3575 y VM6575.

--white-level-r 0..64
Selecciona qué nivel de radiancia roja se considerará "blanco", al escanear algunas hojas cambiando el valor de calibración cargado en el escáner. Escala 0..64 en pasos de 1.
--white-level-g 0..64
Selecciona qué nivel de radiancia verde se considerará "blanco", al escanear algunas hojas cambiando el valor de calibración cargado en el escáner. Escala 0..64 en pasos de 1.
--white-level-b 0..64
Selecciona qué nivel de radiancia azul se considerará "blanco", al escanear algunas hojas cambiando el valor de calibración cargado en el escáner. Escala 0..64 en pasos de 1.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/teco2.conf admite solo un elemento: el nombre del dispositivo a usar (ej. /dev/scanner).

ARCHIVOS

/usr/lib/sane/libsane-teco2.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-teco2.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica.

ENTORNO

SANE_DEBUG_TECO2
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.
SANE_TECO2_CAL_ALGO
Ya sea 0 o 1. Selecciona el algoritmo de calibración. Un valor de 1 parece dar mejores escaneos en los modelos VM356A, VM3575. Se agradecen comentarios al respecto. Para VM3564, VM356A, VM3575, VM6575 el valor predeterminado es 1. Para otros tipos compatibles, el valor predeterminado es 0.

LIMITACIONES

El controlador TWAIN de Windows tiene muchas más opciones que este backend SANE. Sin embargo, son solo ajustes de software. Este backend solo implementa lo que el escáner puede admitir.

ERRORES

Muchos. Partes de este backend aún están en desarrollo.
