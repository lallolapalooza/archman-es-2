NOMBRE

sane-rts8891 - Backend de SANE para escáneres basados en rts8891

DESCRIPCIÓN

La biblioteca sane-rts8891 implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a escáneres basados en el ASIC rts8891.

Los escáneres que funcionan con este backend son:

   Fabricante Modelo           estado
----------------------  -----------
  Umax Astra 4400       sin probar
  Umax Astra 4450       sin probar
  HP scanjet 4000c      bueno
  HP scanjet 4470c      bueno

Las opciones que el backend soporta se pueden seleccionar a través de opciones de línea de comandos de programas como scanimage(1) o a través de elementos de interfaz gráfica en xscanimage(1) o xsane(1).

Si nota algún comportamiento extraño, por favor, informe al mantenedor del backend o a la lista de correo de SANE.

Las opciones válidas de línea de comandos y su sintaxis se pueden listar usando

scanimage --help -d rts8891
Opciones de Modo de Escaneo
--modo
selecciona el modo básico de operación del escáner. Las opciones válidas son Color, Gris y Línea. El modo predeterminado es Color. El modo Línea es solo para blanco y negro (1 bit). Gris producirá 256 niveles de gris (8 bits). El modo Color permite más de 16 millones de colores diferentes producidos a partir de 24 bits de información de color.
--resolución
selecciona la resolución para un escaneo. Las resoluciones horizontal y vertical se establecen con el valor de esta opción. El escáner es capaz de las siguientes resoluciones para el valor de opción especificado:
  Valor   Resolución Hor.  Resolución Vert.
  -----   ---------------  -------------------
  75      75dpi            75dpi
  150     150dpi           150dpi
  300     300dpi           300dpi
  600     600dpi           600dpi
  1200    1200dpi          1200dpi
--vista-previa
solicita un escaneo de vista previa. La resolución utilizada para ese escaneo es de 75 dpi y el área de escaneo y el modo de escaneo son como se especifican a través de sus opciones, o el predeterminado si no se especifica. El valor predeterminado para el modo de vista previa es "no".
--umbral
selecciona el brillo mínimo para obtener un punto blanco. El umbral solo se utiliza con escaneos en modo Línea. Se especifica como un porcentaje en el rango 0..100% (en pasos de 1). El valor predeterminado de la opción de umbral es 50.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/rts8891.conf contiene los IDs de dispositivos USB de los escáneres compatibles (por ejemplo, usb 0x043d 0x007c) y las opciones de configuración del escáner. Las líneas vacías y las líneas que comienzan con un signo de almohadilla (#) se ignoran.

Las opciones soportadas son allowsharing, modelnumber

Opción

allowsharing
habilita o no el compartir el escáner entre múltiples frontends al mismo tiempo.
modelnumber
se utiliza para forzar el modelo reportado por el backend y solo es útil en el caso de un escáner cuya NVRAM ha sido borrada. 
0 para reportar un HP4470c.
1 para reportar un HP4400c.
2 para reportar un Astra 4400.

ARCHIVOS

/usr/lib/sane/libsane-rts8891.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-rts8891.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_DEBUG_RTS8891 SANE_DEBUG_RTS8891_LOW SANE_DEBUG_RTS88XX_LIB
Si la biblioteca fue compilada con soporte de depuración habilitado, estas variables de entorno controlan el nivel de depuración para este backend. Por ejemplo, un valor de 255 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.

LIMITACIONES

Existen escáneres del mismo modelo con diferentes sensores, debido a la falta de datos (es decir, registros USB) algunos sensores tienen mejor soporte que otros. Al menos el modo de 75 dpi funciona para cualquier modelo. Compartir el escáner entre varios frontends al mismo tiempo (opción allowsharing) puede no funcionar en algunos controladores USB.

XPA no está (todavía) soportado.

ERRORES

Actualmente no se conocen errores.
