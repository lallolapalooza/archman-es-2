NOMBRE

sane-umax1220u - Backend de SANE para el UMAX Astra 1220U y escáneres similares

DESCRIPCIÓN

La biblioteca sane-umax1220 implementa un backend de SANE (Scanner Access Now Easy) para el UMAX Astra 1220U y escáneres similares.

Para más información sobre este backend, visite http://umax1220u-sane.sourceforge.net/.

SOPORTE PARA UMAX ASTRA 1600U/2000U/2100U

Este backend también es capaz de controlar el UMAX Astra 1600U/2000U/2100U. El 2100U está confirmado que funciona. Para los otros escáneres aún no se han recibido informes. Por favor, contáctenos y díganos si su escáner funciona (sane-devel@alioth-lists.debian.net).

CONFIGURACIÓN

Normalmente, no se necesita configuración manual. El archivo de configuración para este backend reside en /etc/sane.d/umax1220u.conf.

Su contenido es una lista de nombres de dispositivos que corresponden a los escáneres UMAX Astra. Las líneas vacías y las líneas que comienzan con un signo de almohadilla (#) se ignoran. A continuación se muestra un archivo de configuración de ejemplo:

 #usb vendor product
 usb 0x1606 0x0010
 # Device list for non-linux systems
 /dev/scanner
 /dev/usb/scanner0

Consulte sane-usb(5) para obtener información sobre cómo establecer los permisos de acceso en los archivos de dispositivo usb.

ARCHIVOS

El archivo de configuración del backend:
/etc/sane.d/umax1220u.conf
La biblioteca estática que implementa este backend:
/usr/lib/sane/libsane-umax1220u.a
La biblioteca compartida que implementa este backend:
/usr/lib/sane/libsane-umax1220u.so (presente en sistemas que admiten carga dinámica)

ENTORNO

SANE_DEBUG_UMAX1220U
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad:

Valores de SANE_DEBUG_UMAX1220U:

Número  Observación
 1       imprimir fallos
 2       imprimir información
 3       imprimir llamadas a funciones de alto nivel
 4       imprimir puntos de control de funciones de alto nivel
 9       imprimir llamadas a funciones de nivel medio
 10      imprimir puntos de control de funciones de nivel medio
 80      entrada de función a nivel de protocolo
 90      salida de función a nivel de protocolo
Ejemplo:
export SANE_DEBUG_UMAX1220U=10

ERRORES CONOCIDOS

El escaneo a 600 dpi puede fallar para tamaños de imagen grandes.

Si sigues recibiendo errores de E/S, intenta apagar y encender la alimentación de tu escáner para reiniciarlo.

No hay forma de cancelar un escaneo, ya que el controlador ignora sane_cancel().

Si intentas escanear una imagen demasiado pequeña, obtendrás errores de E/S. Asegúrate de ajustar el área de escaneo antes de realizar un escaneo, ya que, por defecto, el área de escaneo es cero.

REPORTE DE ERRORES

Este backend no se mantiene activamente. Sin embargo, los informes de errores y comentarios deben enviarse a la lista de correo de sane-devel. Al informar sobre errores, ejecute el backend con SANE_DEBUG_UMAX1220U establecido en 10 y adjunte una copia de los mensajes de registro.
