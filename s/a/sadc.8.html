SADC(8) Manual del Usuario de Linux SADC(8)

NOMBRE

sadc - Recolector de datos de actividad del sistema.

SINOPSIS

/usr/lib/sa/sadc [ -C comentario ] [ -D ] [ -F ] [ -f ] [ -L ] [ -V ] [ -S { palabra_clave[,...] | ALL | XALL } ] [ intervalo [ conteo ] ] [ archivo_salida ]

DESCRIPCIÓN

El comando sadc toma muestras de datos del sistema un número especificado de veces (conteo) a un intervalo especificado medido en segundos (intervalo). Escribe en formato binario en el archivo_salida especificado o en la salida estándar. Si archivo_salida se establece en -, entonces sadc utiliza el archivo de datos diario de actividad del sistema (ver abajo). En este caso, si el archivo ya existe, sadc lo sobrescribirá si es de un mes anterior. Por defecto sadc recolecta la mayoría de los datos disponibles del kernel. Pero también hay métricas opcionales, para las cuales las opciones relevantes deben pasarse explícitamente a sadc para ser recolectadas (ver opción -S abajo).

El archivo de datos diario de actividad del sistema se llama saDD a menos que se use la opción -D, en cuyo caso su nombre es saYYYYMMDD, donde YYYY representa el año actual, MM representa el mes actual y DD representa el día actual. Por defecto se encuentra en el directorio /var/log/sa. Sin embargo, es posible especificar una ubicación alternativa para él: Si archivo_salida es un directorio (en lugar de un archivo plano) entonces se considerará como el directorio donde se guardará el archivo de datos diario de actividad del sistema.

Cuando el parámetro conteo no se especifica, sadc escribe sus datos sin fin. Cuando tanto intervalo como conteo no se especifican, y la opción -C no se usa, se escribirá un registro ficticio, que se usa al inicio del sistema para marcar el momento en que el contador se reinicia desde 0. Por ejemplo, uno de los scripts de inicio del sistema puede escribir la marca de reinicio en el archivo de datos diario con la entrada de comando:

/usr/lib/sa/sadc -

El comando sadc está destinado a ser utilizado como un backend para el comando sar.

Nota: El comando sadc solo informa sobre actividades locales.

OPCIONES

-C comentario
Cuando no se especifican los parámetros intervalo ni conteo, esta opción le indica a sadc que escriba un registro ficticio que contenga la cadena de comentario especificada. Este comentario puede ser mostrado luego con la opción -C de sar.
-D
Usa saYYYYMMDD en lugar de saDD como nombre del archivo de datos diario de actividad del sistema.
-F
Se forzará la creación de archivo_salida. Si el archivo ya existe y tiene un formato desconocido para sadc, se truncará. Esto puede ser útil para archivos de datos creados por una versión anterior de sadc y cuyo formato ya no sea compatible con el actual.
-f
Se utilizará fdatasync() para asegurar que los datos se escriban en disco. Esto difiere de la operación normal en que un reinicio repentino del sistema es menos probable que resulte en la corrupción de los archivos de datos saDD. Sin embargo, esto tiene un costo de rendimiento dentro del proceso sadc ya que el progreso hacia adelante se bloqueará mientras los datos se escriben en el disco subyacente en lugar de solo en la caché.
-L
sadc intentará obtener un bloqueo exclusivo en el archivo_salida antes de escribir en él o truncarlo. La falla al obtener el bloqueo es fatal, excepto en el caso de intentar escribir un registro normal (es decir, no ficticio y no encabezado) en un archivo existente, en cuyo caso sadc intentará nuevamente en el siguiente intervalo. Normalmente, la única razón por la que un bloqueo podría fallar sería si otro proceso sadc también estuviera escribiendo en el archivo. Esto puede ocurrir cuando se usa cron para lanzar sadc. Si el sistema está bajo carga pesada, un sadc antiguo podría todavía estar ejecutándose cuando cron inicie uno nuevo. Sin bloqueo, esta situación puede resultar en un archivo de actividad del sistema corrupto.
-S { palabra_clave[,...] | ALL | XALL }
Las palabras clave posibles son DISK, INT, IPV6, POWER, SNMP, XDISK, ALL y XALL.
Especifica qué actividades opcionales deben ser recolectadas por sadc. Algunas actividades son opcionales para evitar que los archivos de datos crezcan demasiado. La palabra clave DISK indica que sadc debe recolectar datos para dispositivos de bloque. La palabra clave INT indica que sadc debe recolectar datos para interrupciones del sistema. La palabra clave IPV6 indica que las estadísticas IPv6 deben ser recolectadas por sadc. La palabra clave POWER indica que las estadísticas de gestión de energía deben ser recolectadas por sadc. La palabra clave SNMP indica que las estadísticas SNMP deben ser recolectadas por sadc. La palabra clave ALL es equivalente a especificar todas las palabras clave anteriores y, por lo tanto, se recolectan todas las actividades anteriores.
La palabra clave XDISK es una extensión de la de DISK e indica que las estadísticas de particiones y sistemas de archivos deben ser recolectadas por sadc además de las estadísticas de disco. Esta opción solo funciona con kernels 2.6.25 y posteriores. La palabra clave XALL es equivalente a especificar todas las palabras clave anteriores (incluidas las extensiones de palabras clave) y, por lo tanto, se recolectan todas las actividades posibles.
Nota importante: Las actividades (incluidas las opcionales) guardadas en un archivo de datos existente prevalecen sobre las seleccionadas con la opción -S. En consecuencia, añadir datos a un archivo de datos existente resultará en que la opción -S sea ignorada.
-V
Imprime el número de versión y sale.

AMBIENTE

El comando sadc tiene en cuenta la siguiente variable de entorno:

S_TIME_DEF_TIME
Si esta variable existe y su valor es UTC entonces sadc guardará sus datos en tiempo UTC. sadc también usará el tiempo UTC en lugar del tiempo local para determinar el archivo de datos diario actual ubicado en el directorio /var/log/sa.

EJEMPLOS

/usr/lib/sa/sadc 1 10 /tmp/datafile
Escribe 10 registros de intervalos de un segundo en el archivo binario /tmp/datafile.
/usr/lib/sa/sadc -C "Inicio de copia de seguridad" /tmp/datafile
Inserta el comentario "Inicio de copia de seguridad" en el archivo /tmp/datafile.

ERRORES

El sistema de archivos /proc debe estar montado para que el comando sadc funcione.

No todas las estadísticas están necesariamente disponibles, dependiendo de la versión del kernel utilizada. sadc asume que estás utilizando al menos un kernel 2.6.

ARCHIVOS

/var/log/sa/saDD
/var/log/sa/saYYYYMMDD

Los archivos de datos diarios de actividad del sistema y su ubicación por defecto. YYYY representa el año actual, MM representa el mes actual y DD representa el día actual.
/proc y /sys contienen varios archivos con estadísticas del sistema.
