NOMBRE

sane-artec_eplus48u - Backend SANE para el escáner Artec E+ 48U y modelos re-etiquetados

DESCRIPCIÓN

La biblioteca sane-artec_eplus48u implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a varios escáneres planos USB que utilizan el chipset GT6816, como el Artec E+ 48U. Estos escáneres tienen un sensor de imagen de contacto (CIS).

Puede encontrar una lista completa de dispositivos compatibles en http://www.sane-project.org/sane-supported-devices.html.

Este es software ALFA. Especialmente si prueba escáneres nuevos o no probados, mantenga la mano en el enchufe del escáner y desenchúfelo si el cabezal choca al final del área de escaneo.

Si posee un escáner diferente a los mencionados en la lista que funcione con este backend, por favor, háganoslo saber enviando el nombre exacto del modelo del escáner y los ids de vendedor y producto USB (por ejemplo, de /proc/bus/usb/devices, sane-find-scanner(1) o syslog) a mí. Incluso si el nombre del escáner es solo ligeramente diferente a los modelos mencionados anteriormente, por favor, háganoslo saber.

PROBLEMAS DEL NÚCLEO

Si libusb-0.1.6 o posterior está instalado, esta sección puede omitirse. El escáner debería ser encontrado por sane-find-scanner(1) sin más acciones. Para configurar permisos e información general de USB, consulte sane-usb(5).

Cuando utilice el módulo de escáner, se requiere un kernel de Linux 2.4.12 o más reciente.

ARCHIVO DE FIRMA

Necesita un archivo de firma (firmware) para su escáner. Es un archivo pequeño que contiene software que se cargará en la memoria del escáner. Para los escáneres mencionados anteriormente, suele llamarse Artec48.usb o 1200.usb. Puede encontrarlo en el CD de instalación proporcionado por el fabricante, normalmente en el directorio Win98, WinMe o similar. Si el controlador de Windows está instalado en su ordenador, también puede encontrar el archivo de firma en c:288vers.

CONFIGURACIÓN

El contenido del archivo artec_eplus48u.conf es una lista de líneas usb que contienen los ids de vendedor y producto que corresponden a los escáneres USB. El archivo también puede contener líneas de opciones. Las líneas vacías y las líneas que comienzan con una almohadilla (#) se ignoran. Los escáneres se autodetectan mediante las declaraciones usb vendor_id product_id que ya están incluidas en artec_eplus48u.conf. "vendor_id" y "product_id" son números hexadecimales que identifican el escáner.

Cada sección usb puede tener opciones adicionales.

artecFirmwareFile /usr/share/sane/artec_eplus48u/Artec48.usb
La ruta al archivo de firma. Esta opción es obligatoria.
redGamma 1.0
greenGamma 1.0
blueGamma 1.0
masterGamma 1.9
Estos son los valores gamma por defecto. Si establece la opción "Defaults" con un frontend, las opciones gamma se restablecerán a los valores especificados aquí.
redOffset 0x28
greenOffset 0x2f
blueOffset 0x2f
redExposure 0xa7
greenExposure 0x116
blueExposure 0xdc
Estos son los valores por defecto para el tiempo de offset y exposición. Puede cambiarlos (por ejemplo, para acelerar la calibración) si no desea guardar los datos de calibración de forma permanente.
vendorString Artec
modelString E+ 48U
Por defecto, el escáner se informa como "Artec E+ 48U". Si no le gusta esto, por ejemplo, porque tiene un Tevion MD 9693, cambie las opciones en consecuencia.

ARCHIVOS

/usr/local/etc/sane.d/artec_eplus48u.conf
El archivo de configuración del backend (consulte también la descripción de SANE_CONFIG_DIR más abajo).
/usr/local/lib/sane/libsane-artec_eplus48u.a
La biblioteca estática que implementa este backend.
/usr/local/lib/sane/libsane-artec_eplus48u.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por un punto y coma (`;'). Si esta variable no está establecida, el archivo de configuración se busca en dos directorios por defecto: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorios, entonces los directorios por defecto se buscan después de los directorios especificados explícitamente. Por ejemplo, establecer SANE_CONFIG_DIR a "/tmp/config:" resultaría en que los directorios tmp/config, . y /etc/sane.d se buscaran (en este orden).
SANE_DEBUG_ARTEC_EPLUS48U
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Los niveles de depuración más altos aumentan la verbosidad de la salida.

Ejemplo: export SANE_DEBUG_ARTEC_EPLUS48U=3

ERRORES

Este backend solo ha sido probado en Linux. Si lo está utilizando en una plataforma diferente, por favor, póngase en contacto con nosotros.

La interpolación con 1200 dpi es débil.

Falta el soporte para botones debido a la falta de soporte en SANE.

Por favor, póngase en contacto con nosotros si encuentra un error: http://www.sane-project.org/bugs.html.
