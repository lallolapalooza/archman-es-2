NOMBRE

sane-dc240 - Backend de SANE para la cámara digital Kodak DC240

DESCRIPCIÓN

La biblioteca sane-dc240 implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a la cámara Kodak DC240. ¡¡ESTE ES CÓDIGO EXTREMADAMENTE ALFA!! ¡ÚSALO BAJO TU PROPIO RIESGO!!

NOMBRES DE DISPOSITIVO

La versión actual del backend solo permite conectar una cámara. El nombre del dispositivo es siempre "0".

CONFIGURACIÓN

El contenido de dc240.conf especifica el puerto serie y la velocidad en baudios a usar. La velocidad en baud especifica la velocidad máxima a usar mientras se descargan las imágenes. (La cámara siempre se inicializa usando 9600 baudios, luego cambia a una velocidad mayor). En un Pentium de 450MHz, normalmente no tengo problemas para descargar a 115200 baudios, aunque la cámara a veces tiene que reenviar paquetes debido a caracteres perdidos. Los resultados son mejores cuando se establece el "indicador de enmascaramiento de interrupción" en el controlador IDE (hdparm -u1). Las velocidades en baudios admitidas son: 9600, 19200, 38400, 57600 y 115200.

La línea dumpinquiry hace que se imprima información sobre la cámara.

cmdrespause especifica cuántos microsegundos (millonésimas de segundo) esperar entre escribir el comando y leer el resultado. 125000 parece ser lo más bajo que pude ir de manera fiable.

breakpause especifica cuántos microsegundos (millonésimas de segundo) entre el envío de la interrupción "volver a la configuración predeterminada" y el envío de comandos.

Las líneas vacías y las líneas que comienzan con un signo de almohadilla (#) se ignoran. A continuación se muestra un ejemplo de archivo de configuración:

port=/dev/ttyS0
# esto es un comentario
baud=115200
dumpinquiry
cmdrespause=125000
breakpause=1000000

ARCHIVOS

/etc/sane.d/dc240.conf
El archivo de configuración del backend (ver también la descripción de SANE_CONFIG_DIR abajo).
/usr/lib/sane/libsane-dc240.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-dc240.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por un punto y coma (`;'). Si esta variable no está establecida, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorio, entonces los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, establecer SANE_CONFIG_DIR a "/tmp/config:" resultaría en la búsqueda de los directorios tmp/config, . y /etc/sane.d (en este orden).
SANE_DEBUG_DC240
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Un valor de 128 solicita una salida de depuración extremadamente detallada; niveles más bajos reducen la verbosidad.

ERRORES

La principal limitación que conozco es que el backend asume que el directorio en la cámara es 100dc240. Una vez que la cámara ha tomado más de 9999 imágenes, el directorio se incrementará a 101dc240. No solo deberíamos comprobar el directorio adicional, sino que es posible que las imágenes se encuentren en varios directorios.
