NOMBRE

sane-hpsj5s - backend de SANE para el escáner de alimentación continua HP ScanJet 5S

DESCRIPCIÓN

La biblioteca sane-hpsj5s implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso al escáner de alimentación continua Hewlett-Packard ScanJet 5S del puerto paralelo.

IMPORTANTE: este es un código alfa. No esperes que funcione correctamente. Muchas funciones faltan, otras contienen errores. En algunos casos, tu ordenador incluso podría colgarse. No se puede excluir (aunque lo considero extremadamente improbable) que tu escáner resulte dañado.

LIMITACIONES: Por ahora, este backend solo funciona en Linux. Esta limitación se debe a la dependencia de la biblioteca libieee1284(3). Si tu sistema soporta libieee1284(3), este backend debería funcionar. Si has portado libieee1284(3) para tu plataforma, por favor házmelo saber. Tu sistema debería soportar el modo EPP (o EPP+ECP) para operar este escáner. Las versiones futuras también soportarán los modos ECP y SPP (Nibble y Byte). Está planeado soportar escáneres no solo en la posición 0 de la cadena margarita, sino en cualquier lugar. También se podría implementar soporte para múltiples escáneres.

La versión actual solo implementa escaneo en escala de grises. Los modos Color Verdadero y Blanco y Negro no están soportados por ahora.

Dicho esto, se dan la bienvenida a los probadores. Envía tus informes de errores y comentarios a Max Vorobiev <pcwizard@yandex.ru>.

NOMBRES DE DISPOSITIVO

Este backend espera nombres de dispositivo de la forma:

especial

Donde especial es el nombre del puerto paralelo en la forma que libieee1284(3) espera. Parece depender del sistema. Bajo Linux, es parport0, parport1, etc.

CONFIGURACIÓN

El contenido del archivo hpsj5s.conf es una lista de nombres de puerto paralelo que corresponden a escáneres HP ScanJet 5S. Las líneas vacías y las líneas que empiezan por una almohadilla (#) se ignoran. Solo se puede listar un nombre de dispositivo en hpsj5s.conf por el momento. Las versiones futuras soportarán la selección de cadena margarita.

CONSEJOS

Parece que el escáner HP ScanJet 5S utiliza corrección de ruido por software. Esta característica, junto con la corrección gamma y la calibración, no están implementadas por ahora. Se manejarán en versiones futuras. La resolución nativa para este escáner es de 300 DPI. Otros modos pueden presentar artefactos de aliasing.

ARCHIVOS

/etc/sane.d/hpsj5s.conf
El archivo de configuración del backend (ver también la descripción de SANE_CONFIG_DIR a continuación).
/usr/lib/sane/libsane-hpsj5s.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-hpsj5s.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), bajo OS/2, están separados por un punto y coma (`;'). Si esta variable no está establecida, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorio, entonces los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, establecer SANE_CONFIG_DIR a "/tmp/config:" resultaría en la búsqueda de los directorios tmp/config, . y /etc/sane.d (en este orden).
SANE_DEBUG_HPSJ5S
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Niveles de depuración más altos aumentan la verbosidad de la salida.
