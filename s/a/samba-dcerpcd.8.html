SAMBA-DCERPCD(8) Herramientas de Administración del Sistema SAMBA-DCERPCD(8)

NOMBRE

samba-dcerpcd - Este es uno de los procesos del servidor DCERPC de Samba que puede escuchar en sockets donde se ofrecen servicios RPC y es el proceso padre de los servicios DCERPC que invoca. A menos que se invoque por separado, es iniciado bajo demanda por smbd o winbind y sirve DCERPC solo a través de tuberías con nombre (np) como un proceso auxiliar. Esta será la configuración estándar para la mayoría de las instalaciones (servidor independiente/miembro/servidor AD) a menos que modifiquen sus scripts de inicio. Tenga en cuenta que cuando Samba se configura como controlador de dominio de Active Directory, el proceso samba que invoca a smbd seguirá proporcionando sus servicios DCERPC normales, no samba-dcerpcd. Cuando se invoca por separado mediante scripts de inicio del sistema o un demonio, la opción global de smb.conf rpc start on demand helpers = false DEBE establecerse para permitir que samba-dcerpcd se inicie de forma independiente.

SINOPSIS

samba-dcerpcd [-D|--daemon] [-i|--interactive] [-F|--foreground] [--no-process-group] [-d <nivel>] [--debug-stdout] [--configfile=<archivo>] [--option=<nombre>=<valor>] [--leak-report] [--leak-report-full] [-V|--version] [--libexec-rpcds] [--np-helper] [--ready-signal-fd=<fd>] [<SERVICIO_1>] [<SERVICIO_2>] [<...>]

DESCRIPCIÓN

Esta herramienta forma parte de la suite samba(7).

samba-dcerpcd se puede utilizar de dos maneras. En el caso normal sin modificación de los scripts de inicio y con la opción global de smb.conf rpc start on demand helpers = true establecida (la configuración predeterminada), se invoca bajo demanda desde smbd o winbind con una línea de comandos que contiene --np-helper para servir DCERPC a través de tuberías con nombre (np). También se puede utilizar en modo independiente, donde se inicia por separado de smbd o winbind a través de scripts de inicio del sistema. Si se invoca como un demonio independiente o se inicia desde scripts de inicio del sistema, la opción global de smb.conf rpc start on demand helpers = false DEBE establecerse en false. Si la opción global de smb.conf rpc start on demand helpers = true se establece en true o se deja como predeterminada, samba-dcerpcd fallará al iniciarse y registrará un mensaje de error.

Tenga en cuenta que cuando Samba se ejecuta en modo de controlador de dominio de Active Directory, el código AD de Samba seguirá proporcionando sus servicios DCERPC normales, al mismo tiempo que permite que samba-dcerpcd proporcione servicios como SRVSVC de la misma manera que lo hacía smbd en esta configuración.

El modo independiente también puede ser útil para usarlo fuera del marco de Samba, por ejemplo, para usarlo con el servidor SMB2 del kernel de Linux ksmbd o posiblemente otras implementaciones de servidor SMB2. En este modo, se comporta como inetd y escucha en sockets en nombre de las implementaciones del servidor RPC.

Cuando un cliente se conecta, samba-dcerpcd iniciará el binario del servicio RPC relevante bajo demanda y le cederá la conexión. Cuando un servicio RPC ha estado inactivo durante un tiempo, samba-dcerpcd le pedirá que se cierre de nuevo.

OPCIONES

-D|--daemon

Si se especifica, este parámetro hace que el servidor opere como un demonio. Es decir, se desvincula y se ejecuta en segundo plano, atendiendo las solicitudes en el puerto apropiado. Operar el servidor como un demonio es útil para ejecutar samba-dcerpcd fuera del marco de Samba. Sin embargo, también se puede usar de esta manera dentro de Samba para servidores miembros si se configura para iniciarse a través de scripts de inicio del sistema. Este interruptor se asume si samba-dcerpcd se ejecuta en la línea de comandos de una shell.

-i|--interactive

Si se especifica este parámetro, hace que el servidor se ejecute "interactivamente", no como un demonio, incluso si el servidor se ejecuta en la línea de comandos de una shell. Establecer este parámetro niega el modo de demonio implícito cuando se ejecuta desde la línea de comandos. samba-dcerpcd solo aceptará una conexión y terminará. También registrará en la salida estándar, como si se hubiera dado el parámetro -S.

-F|--foreground

Si se especifica, este parámetro hace que el proceso principal de samba-dcerpcd no se convierta en demonio, es decir, no haga doble fork ni se disocie de la terminal. Los procesos hijos todavía se crean de forma normal para atender cada solicitud de conexión, pero el proceso principal no se cierra. Este modo de operación es adecuado para ejecutar samba-dcerpcd bajo supervisores de procesos como supervise y svscan del paquete daemontools de Daniel J. Bernstein, o el monitor de procesos de AIX.

--no-process-group

No crear un nuevo grupo de procesos para samba-dcerpcd.

--libexec-rpcds

Ofrecer servicios RPC para todos los demonios en LIBEXECDIR de Samba, todos los programas que comiencen con "rpcd_" se asumen para ofrecer servicios RPC. Si no usa la opción --libexec-rpcds, puede enumerar explícitamente todos los ayudantes de servicios RPC en la línea de comandos.

--np-helper

Ejecuta samba-dcerpcd bajo demanda abriendo sockets de tubería con nombre como ayudantes para smbd o winbind. Para ejecutar en este modo, la opción global de smb.conf rpc start on demand helpers = true debe establecerse en true (esta es la configuración predeterminada).

--ready-signal-fd=<fd>

Reportar la preparación del servicio a través de este fd a smbd o winbind. Solo para uso interno.
