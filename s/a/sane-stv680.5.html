NOMBRE

sane-stv680 - Backend de SANE para cámaras STV680

DESCRIPCIÓN

La biblioteca sane-stv680 implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a algunas cámaras STV680. ¡Este backend debe considerarse software de calidad beta! Las cámaras STV680 se venden bajo diversas marcas como Aiptek. Este backend puede o no ser compatible con la tuya.

Las cámaras que deberían funcionar con este backend son:

Vendedor Modelo              ID de vendedor USB  ID de producto USB  estado
------------------------  -------------  --------------  --------
AIPTEK stv680                0x0553         0x0202       básico
Konica e-mini                0x04c8         0x0722       sin probar
DigitalDream l'espion XS     0x1183         0x0001       sin probar
Creative WebCam Go mini      0x041e         0x4007       sin probar

Para todas estas cámaras, consulta la página principal del backend (en AUTOR) para conocer el estado exacto de cada cámara.

Para el inicio de este backend, asegúrate de que si está presente el módulo del kernel stv680, se elimine o deshabilite.
También, antes de usarlo, habilita el backend editando el archivo /etc/sane.d/dll.conf, cambia #stv680 por stv680.

Para problemas con las cámaras no probadas, deberías contactar al autor.

Las opciones que soporta el backend se pueden seleccionar a través de opciones de línea de comandos para programas como scanimage(1) o a través de elementos gráficos en xcam(1). Para ambos programas, utiliza la opción -B necesaria para el buffer de tamaño.

Algunos ejemplos de frontends:

xcam(1)

xcam -B

scanimage(1): para escribir en modo batch a un archivo o a un archivo nuevo cada vez:

scanimage -B -d stv680:libusb:001:002 --batch=out.ppm --batch-count 5 --mode "Color RGB"
scanimage -B -d stv680:libusb:001:002 --batch=out%d.ppm --batch-count 5 --mode "Color RGB"

Si tienes algún éxito con una cámara no listada aquí, o si observas algún comportamiento extraño, por favor informa al mantenedor del backend o a la lista de correo de SANE.

Las opciones de línea de comandos válidas y su sintaxis se pueden listar usando:

scanimage --help -d stv680
Modo de Escaneo
--mode
selecciona el modo básico de operación de la webcam; las opciones válidas son:

La resolución de lectura es de 8 bits, la resolución de salida es de 24 bits. Selecciona la resolución para un escaneo. La cámara solo puede realizar las resoluciones listadas.

--Raw
en este modo se muestran datos crudos
--Color
en este modo se realiza el desentrelazado bayer pero sin corrección de color
--Color_RGB
desentrelazado bayer, corrección de color
--Color_RGB_TXT
desentrelazado bayer, corrección de color, se añade una línea de texto con fecha y hora
Opciones de mejora
--white-level-r -32..+32
selecciona qué nivel de radiancia roja debe considerarse "blanco", al escanear algunas hojas cambiando el valor de calibración cargado en el escáner. Escala -32 .. 0 .. +32 en pasos de 1.
--white-level-g -32..+32
selecciona qué nivel de radiancia verde debe considerarse "blanco", al escanear algunas hojas cambiando el valor de calibración cargado en el escáner. Escala -32 .. 0 .. +32 en pasos de 1.
--white-level-b -32..+32
selecciona qué nivel de radiancia azul debe considerarse "blanco", al escanear algunas hojas cambiando el valor de calibración cargado en el escáner. Escala -32 .. 0 .. +32 en pasos de 1.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/stv680.conf solo soporta un elemento: el nombre del dispositivo a usar (ej. usb 0x.... 0x....).

ARCHIVOS

/usr/lib/sane/libsane-stv680.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-stv680.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_DEBUG_STV680
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.

LIMITACIONES

El controlador TWAIN de Windows tiene muchas más opciones que este backend SANE. Sin embargo, solo son ajustes de software. Este backend solo implementa lo que la cámara web puede soportar.

ERRORES

Muchos. Partes de este backend aún están en desarrollo.
1. Algunas cámaras sin probar.
2. Transmisión de video lenta y se detiene a veces (scanimage).
3. A veces 1/3 de la imagen está mal (xcam).
