NOMBRE

sane-canon_dr - Backend SANE para escáneres Canon de la serie DR

DESCRIPCIÓN

La biblioteca sane-canon_dr implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a algunos escáneres Canon de la serie DR.

Este documento describe la versión 60 del backend, que se distribuyó con SANE 1.0.32.

HARDWARE SOPORTADO

Esta versión solo ha sido probada con algunos modelos de escáner. Por favor, consulte http://www.sane-project.org/sane-supported-devices.html para la lista más reciente.

Este backend puede soportar otros escáneres Canon. La mejor manera de determinar el nivel de soporte es probar el escáner directamente o recopilar un rastreo del controlador de Windows en acción. Por favor, póngase en contacto con el autor para obtener ayuda o compartir resultados de pruebas.

En general, las máquinas más grandes (DR-4000 y superiores) que han sido probadas utilizan un protocolo bastante completo, con soporte de hardware para muchos modos, resoluciones y características. Las máquinas más pequeñas tienen muchas limitaciones, como resoluciones horizontales faltantes, modo binario faltante, escaneo siempre a ancho completo, etc. Hay código en el backend para abordar estos problemas, pero no parece haber forma de detectar si son necesarios, por lo que deben estar codificados de forma fija.

OPCIONES

Se ha hecho un esfuerzo por exponer la mayoría de las opciones de hardware, incluyendo:

--source Plano|ADF Frontal|ADF Posterior|ADF Dúplex
Selecciona la fuente para el escaneo.
--mode Lineart|Halftone|Gris|Color
Selecciona el modo para el escaneo.
--resolution
Controla la resolución del escaneo.
--tl-x, --tl-y, --br-x, --br-y
Establece las coordenadas de la esquina superior izquierda y la esquina inferior derecha del área de escaneo. Estas son renombradas como -t, -l, -x, -y por algunos frontends.
--page-width, --page-height
Establece el tamaño del papel. Utilizado por el escáner para determinar el centrado de las coordenadas de escaneo al usar el ADF (Alimentador Automático de Documentos) y para detectar errores de doble alimentación.

Habrá otras opciones disponibles según las capacidades del escáner: mejora, compresión, botones y sensores, etc.

Además, el backend expone varias opciones de 'software'. Estas son reimplementaciones de características proporcionadas nativamente por escáneres más grandes, pero que se ejecutan en la computadora host. Esto permite que las máquinas más pequeñas tengan capacidades similares. Tenga en cuenta que estas características son algo simplistas y pueden no funcionar tan bien como las implementaciones nativas. Tenga en cuenta también que todas estas características requieren que el controlador almacene en caché la imagen completa en memoria. Esto casi con certeza resultará en una reducción de la velocidad de escaneo.

--swcrop
Solicita al controlador que detecte las extremidades del papel dentro de la imagen más grande y recorte los bordes vacíos.
--swdeskew
Solicita al controlador que detecte la rotación del papel dentro de la imagen más grande y compense la rotación.
--swdespeck X
Solicita al controlador que encuentre y elimine puntos de diámetro X o menor de la imagen, y rellene el espacio con el color circundante promedio.

Use 'scanimage --help' para obtener una lista, pero tenga en cuenta que algunas opciones solo se pueden configurar cuando se ha configurado otra opción, y que las opciones avanzadas pueden estar ocultas por algunos programas front-end.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración canon_dr.conf se utiliza para indicarle al backend cómo buscar escáneres y proporcionar opciones que controlan el funcionamiento del backend. Este archivo se lee cada vez que el frontend solicita al backend una lista de escáneres, generalmente solo cuando se inicia el frontend. Si falta el archivo de configuración, el backend fallará al ejecutarse.

Los escáneres se pueden especificar en el archivo de configuración de 4 maneras:

"scsi CANON DR"

Solicita al backend que busque en todos los buses scsi del sistema un dispositivo que se informe a sí mismo como un escáner fabricado por 'CANON', con un nombre de modelo que comience con 'DR'.

"scsi /dev/sg0" (u otro archivo de dispositivo scsi)

Solicita al backend que abra el dispositivo scsi nombrado. Solo es útil si tiene varios escáneres compatibles conectados a su sistema y necesita especificar uno. Probablemente no debería usarse con la otra línea "scsi" anterior.

"usb 0x04a9 0x1603" (u otros ids de vendedor/producto)

Solicita al backend que busque en todos los buses usb del sistema un dispositivo que utilice ese id de vendedor y producto. Luego se consultará al dispositivo para determinar si es un escáner Canon.

"usb /dev/usb/scanner0" (u otro archivo de dispositivo)

Algunos sistemas utilizan un controlador de kernel para acceder a los escáneres usb. Este método no ha sido probado.

Además de las líneas 'scsi' y 'usb', el archivo de configuración soporta las siguientes líneas 'option':

"option buffer-size [número de bytes]"

Establece el número de bytes en el búfer de datos a algo diferente del valor predeterminado compilado de 4 MB. Valores grandes pueden causar tiempos de espera o bloqueos, valores pequeños pueden causar escaneos lentos.

Nota: El backend no impone un límite superior a este valor, ya que algunos usuarios lo requerían bastante grande. No se recomiendan valores superiores al predeterminado, y pueden bloquear su sistema operativo o el controlador de su tarjeta scsi. Se le ha advertido.

"option vendor-name [cadena de texto]"
"option model-name [cadena de texto]"
"option version-name [cadena de texto]"

Estas opciones se pueden utilizar colectivamente para anular los valores proporcionados por el escáner, o para proporcionar los valores cuando el escáner no puede hacerlo.

"option padded-read [0|1]"

Algunos escáneres anteponen 12 bytes a todos los datos transmitidos al host. Habilite esta opción si el escáner no responde a los comandos.

"option duplex-offset [entero]"

Algunos escáneres rellenan el borde superior de un lado de un escaneo dúplex. Hay cierta variación en la cantidad de relleno. Modifique esta opción si su unidad muestra una banda de datos de imagen no deseada en un solo lado.

NOTA: Las líneas "option" pueden aparecer múltiples veces en el archivo de configuración. Solo se aplican a los escáneres descubiertos por la siguiente línea 'scsi/usb'.

ENTORNO

El backend utiliza una única variable de entorno, SANE_DEBUG_CANON_DR, que habilita la salida de depuración a stderr. Los valores válidos son:

5 Errores
10 Rastreo de funciones
15 Detalle de funciones
20 Comandos de opciones
25 Rastreo SCSI/USB
30 Detalle SCSI/USB
35 Ruido inútil

PROBLEMAS CONOCIDOS

Este backend fue completamente ingeniería inversa a partir de rastreos usb del controlador propietario. Varias características avanzadas de las máquinas pueden no estar habilitadas. Muchas máquinas no han sido probadas. Su protocolo es desconocido.
