NOMBRE

sane-sm3840 - Backend de SANE para escáneres Microtek con chip USB SCAN08

DESCRIPCIÓN

La biblioteca sane-sm3840 implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a algunos escáneres Microtek con el chip USB SCAN08.

Existen backends para escáneres Microtek con conjunto de comandos SCSI. Consulte sane-microtek(5) y sane-microtek2(5) para más detalles.

También existe un controlador para la serie Microtek 3600, ver sane-sm3600(5) para más detalles.

En la actualidad, los siguientes escáneres se sabe que funcionan correctamente con este backend:

Vendedor     ID de producto:     Observación:
--------   --------------  -----------
Microtek   ScanMaker 3840  Todos los modos OK
Microtek   ScanMaker 4800  Todos los modos OK

Si posee un escáner Microtek con el chip SCAN08 distinto de los mencionados anteriormente, puede que funcione o no con SANE. No dude en contactar al autor del backend (earle@ziplabel.com) para informar de los resultados con escáneres que no estén en la lista.

OPCIONES DEL FRONTEND

Las siguientes opciones son compatibles con el controlador sane-sm3840:

--mode color|gray|lineart|halftone
Modo de color o escala de grises.
--resolution 150|300|600|1200
Píxeles por pulgada para escaneos.
--depth 8|16
Tenga en cuenta que los bits menos significativos del modo de 16bpp pueden ser ruido.
--brightness 1..4096
Números más altos aumentan el brillo de la imagen devuelta.
--contrast 0.1..9.9
Números más grandes disminuyen el contraste de la imagen devuelta.
--lamp-timeout 1..15
Tiempo en minutos hasta que la lámpara se apaga después de un escaneo.

CONFIGURACIÓN

Este backend no admite un archivo de configuración en este momento.

ARCHIVOS

/usr/lib/sane/libsane-sm3840.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-sm3840.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_DEBUG_SM3840
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad. Para ver los mensajes de error en stderr, establezca SANE_DEBUG_SM3840 a 1.
