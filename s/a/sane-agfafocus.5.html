sane-agfafocus(5) Acceso Sencillo a Escáneres SANE sane-agfafocus(5)

NOMBRE

sane-agfafocus - Backend de SANE para escáneres planos AGFA Focus

DESCRIPCIÓN

La biblioteca sane-agfafocus implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a escáneres planos AGFA Focus. En la actualidad, los siguientes escáneres son compatibles con este backend:

AGFA Focus GS Scanner (6 bits escala de grises) (no probado)
AGFA Focus Lineart Scanner (lineart) (no probado)
AGFA Focus II (8 bits escala de grises) (no probado)
AGFA Focus Color (color de 24 bits 3 pasadas)
AGFA Focus Color Plus (color de 24 bits 3 pasadas)

Siemens S9036 (8 bits escala de grises) (no probado)

El controlador soporta escaneos de line art, grises de 6bpp y 8bpp, y color de 18bpp y 24bpp.

Si posees un escáner diferente a los mencionados anteriormente que funcione con este backend, por favor, háznoslo saber enviando el nombre del modelo del escáner, la ID SCSI y la revisión del firmware a sane-devel@alioth-lists.debian.net. Echa un vistazo a http://www.sane-project.org/mailing-lists.html para suscribirte a sane-devel.

Todos estos escáneres son anteriores a SCSI-2, y ni siquiera se informan correctamente a SCSI Inquiry. Esto es típicamente evidente en los escaneos del bus SCSI, donde el escáner aparecerá solo con cadenas de basura como proveedor y modelo.

NOMBRES DE DISPOSITIVO

Este backend espera nombres de dispositivo del tipo:

especial

donde especial es el nombre de la ruta para el dispositivo especial que corresponde a un escáner SCSI. Para escáneres SCSI, el nombre del dispositivo especial debe ser un dispositivo SCSI genérico o un enlace simbólico a dicho dispositivo. En Linux, un nombre de dispositivo así podría ser /dev/sga o /dev/sge, por ejemplo. Consulta sane-scsi(5) para obtener detalles.

CONFIGURACIÓN

El contenido del archivo agfafocus.conf es una lista de nombres de dispositivos que corresponden a escáneres AGFA Focus. Las líneas vacías y las líneas que comienzan con una almohadilla (#) se ignoran. A continuación se muestra un ejemplo de archivo de configuración:

/dev/scanner
# esto es un comentario
/dev/sge

ARCHIVOS

/etc/sane.d/agfafocus.conf
El archivo de configuración del backend (véase también la descripción de SANE_CONFIG_DIR a continuación).
/usr/lib/libsane-agfafocus.a
La biblioteca estática que implementa este backend.
/usr/lib/libsane-agfafocus.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por punto y coma (`;'). Si esta variable no está configurada, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorio, entonces se buscan los directorios predeterminados después de los directorios especificados explícitamente. Por ejemplo, establecer SANE_CONFIG_DIR a "/tmp/config:" daría como resultado la búsqueda en los directorios tmp/config, ., y /etc/sane.d (en este orden).
SANE_DEBUG_AGFAFOCUS
Si la biblioteca fue compilada con soporte de depuración activado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad. Valores de SANE_DEBUG_AGFAFOCUS: 
Número  Observación
 0       imprimir errores importantes (impresos cada vez)
 1       imprimir errores
 2       imprimir sense
 3       imprimir advertencias
 4       imprimir consulta del escáner
 5       imprimir información
 6       imprimir información menos importante
 7       imprimir procedimientos llamados
 8       imprimir mensajes de reader_process
 10      imprimir sane-init-routines llamados
 11      imprimir procedimientos sane llamados
 12      imprimir información sane
 13      imprimir mensajes de sane option-control

FUNCIONALIDAD FALTANTE

La carga de matrices de tramas y curvas de tono ha sido implementada, pero hasta ahora no ha demostrado ser útil para nada. Por esta razón, estas opciones han sido deshabilitadas.

ERRORES

Los escáneres que no soportan desconexión tienen problemas con los tiempos de espera SCSI si el bus SCSI se carga, por ejemplo, si haces una compilación del kernel al mismo tiempo que escaneas. Para ver si tu escáner soporta desconexión, ejecuta SANE_DEBUG_AGFAFOCUS=128 scanimage -L en una terminal y busca la línea "disconnect:".

DEPURACIÓN

Si tienes problemas para que SANE detecte tu escáner, asegúrate de que el backend de Artec esté deshabilitado. De alguna manera, este backend causa que al menos mi escáner no responda correctamente a los comandos de consulta SCSI.

Si encuentras un error, por favor, configura la variable de entorno SANE_DEBUG_AGFAFOCUS a 128 e intenta reproducir el problema. Luego envíame un informe con el registro adjunto.

Si encuentras un error en el bus SCSI o imágenes recortadas y/o desplazadas, también configura la variable de entorno SANE_DEBUG_SANEI_SCSI a 128 antes de enviarme el informe.

PENDIENTE

¿Más escáneres?

Los escáneres AGFA ACS y ARCUS son similares a los escáneres FOCUS. El controlador probablemente podría extenderse para soportar estos escáneres sin demasiados cambios. No tengo acceso a tales escáneres y no puedo agregar soporte para ellos. Sin embargo, si posees uno de estos escáneres, podría ser útil para agregar soporte para ellos.

Los escáneres AGFA HORIZON son escáneres SCSI-2, y probablemente sería más fácil soportarlos en un backend compatible con SCSI-2.

sane-agfafocus.5 - Documentación de sane-agfafocus

NOMBRE

agfafocus - Interfaz de escaneo SANE para escáneres Agfa Focus

SINOPSIS

#include <sane.h>

SANE_Const char *sane_agfafocus_options (SANE_Const char *key);

DESCRIPCIÓN

La interfaz agfafocus es una interfaz para varios escáneres Agfa Focus. Actualmente, solo se ha probado con el Agfa Focus S. El escáner se conecta al puerto paralelo.

OPCIONES

Esta interfaz implementa las siguientes opciones:

opciones de escaneo

Esta es la opción principal para configurar el escáner. El comportamiento exacto depende de la configuración del escáner y del modelo. El siguiente es un ejemplo de una configuración típica:

opciones de escaneo = modo de color, resolución, geometría
modo de color

Establece el modo de color del escaneo. Los modos disponibles pueden incluir:

  • gris: Escaneo en escala de grises.
  • color: Escaneo en color.
resolución

Establece la resolución del escaneo en puntos por pulgada (dpi). La resolución admitida varía según el modelo del escáner. Por ejemplo, el Agfa Focus S admite resoluciones de 300 dpi y 600 dpi.

geometría

Establece el área de escaneo. Esto se expresa como una tupla de cuatro números:x, y, ancho, alto. Las unidades son pulgadas. Por ejemplo,0,0,8.5,11escanea una página de tamaño carta completa.

AJUSTE FINO (TUNING)

Si el escáner no funciona correctamente, puede intentar ajustar varios parámetros. La interfaz agfafocus expone algunas opciones para esto:

tiempo de espera

Establece el tiempo de espera en segundos para las operaciones de E/S del puerto paralelo. El valor predeterminado suele ser 10 segundos. Puede aumentar este valor si experimenta tiempos de espera de E/S.

retardo_inicio

Establece un retardo en microsegundos después de encender el escáner y antes de enviar comandos. Esto puede ser útil para escáneres más antiguos que necesitan tiempo para inicializarse.

retardo_exposicion

Establece un retardo en microsegundos después de la exposición de la imagen y antes de leer los datos. Esto puede ser necesario para que el cabezal del escáner se estabilice.

PUERTO PARALELO

Esta interfaz utiliza el puerto paralelo estándar para la comunicación. Asegúrese de que el puerto paralelo esté configurado correctamente en la BIOS de su sistema. A menudo, los puertos paralelos se configuran en modo EPP o ECP para un mejor rendimiento. Sin embargo, algunos escáneres más antiguos pueden requerir modo SPP.

BUGS

No se conocen errores importantes en este momento.

DEBUG

Para habilitar la depuración, ejecute la aplicación SANE con la variable de entorno SANE_DEBUG_AGFAFOCUS establecida en un nivel de depuración adecuado (por ejemplo, 127).

export SANE_DEBUG_AGFAFOCUS=127
