save_d(3) Manual de funciones de biblioteca save_d(3)

NOMBRE

save_d - Controlador de AA-lib utilizado para guardar imágenes de arte ASCII en un archivo en el formato especificado.

SINOPSIS

#include <aalib.h>

extern const struct aa_driver save_d;

DESCRIPCIÓN

Inicialice este controlador usando la función aa_init y especifique los parámetros dependientes del controlador en la estructura aa_savedata para guardar la imagen en un archivo. Consulte la documentación de texinfo para obtener detalles.
