NOMBRE

sane-epson - Backend SANE para escáneres EPSON

DESCRIPCIÓN

La biblioteca sane-epson implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a escáneres planos EPSON. ¡Algunas funciones de este backend deben considerarse software de calidad beta! La mayoría de las funciones han sido estables durante mucho tiempo, pero, por supuesto, el desarrollo nuevo no puede y a menudo no funcionará correctamente desde el primer día. Por favor, informe cualquier comportamiento extraño al mantenedor del backend.

Actualmente, se sabe que los siguientes escáneres funcionan con este backend:

Modelo:                       Tipo de Conexión
---------------------------  -------------------
GT-5000                      SCSI, paralelo
GT-6000                      paralelo
GT-6500                      SCSI (use solo la línea "scsi" en epson.conf)
ActionScanner II             SCSI, paralelo
GT-7000                      SCSI
Perfection 636               SCSI
Perfection 636U              USB
Perfection 610               USB
Perfection 640               USB
Perfection 1200S             SCSI
Perfection 1200U             USB
Perfection 1240              USB, SCSI
Perfection 1640              USB, SCSI
Perfection 1650              USB
Perfection 1660              USB
Perfection 2400              USB
Perfection 2450              USB, IEEE-1394
Expression 636 / GT-9500     SCSI
Expression 1600              USB, SCSI, IEEE-1394
Expression 1680              USB, SCSI, IEEE-1394
CX-3200                      USB
CX-5200                      USB
y muchos más. La lista oficial está en el sitio web de Sane.

Para otros escáneres, el software puede funcionar o no. Por favor, envíe un correo electrónico al autor del backend (khk@khk.net) para informar sobre el éxito con escáneres que no están en la lista o problemas con escáneres que sí están listados.

OPCIONES

Las opciones que el backend soporta se pueden seleccionar a través de opciones de línea de comandos para programas como scanimage(1) o a través de elementos de GUI en programas como xscanimage(1) o xsane(1).

Las opciones válidas de línea de comandos y su sintaxis se pueden listar usando:

scanimage --help -d epson

No todos los dispositivos soportan todas las opciones.

Modo de Escaneo
El interruptor --mode selecciona el modo básico de operación del escáner. Las opciones válidas son Binario, Gris y Color. El modo Binario es solo blanco y negro, Gris producirá 256 niveles de gris o más, dependiendo del escáner, y Color significa modo de color de 24 bits o más, dependiendo del escáner. Algunos escáneres usarán internamente 36 bits de color, pero su interfaz externa puede soportar solo 24 bits.

La opción --depth selecciona la profundidad de bits que utiliza el escáner. Esta opción solo está disponible para escáneres que soportan más de una profundidad de bits. Los escáneres más antiguos siempre transferirán la imagen en modo de 8 bits. Los escáneres más nuevos permiten seleccionar 8 bits, 12 o 14 bits por canal de color. Para un escaneo en color, esto significa una profundidad de color efectiva de 36 o 42 bits en todos los tres canales. Las opciones válidas dependen del modelo del escáner.

El interruptor --halftoning selecciona el modo que se usa en modo Binario. Las opciones válidas son "None", "Halftone A (Hard Tone)", "Halftone B (Soft Tone)", "Halftone C (Net Screen)", "Dither A (4x4 Bayer)", "Dither B (4x4 Spiral)", "Dither C (4x4 Net Screen)", "Dither D (8x4 Net Screen)", "Text Enhanced Technology", "Download pattern A", y "Download pattern B".

El interruptor --dropout selecciona el llamado color de descarte. Las opciones válidas son Ninguno, Rojo, Verde y Azul. El valor predeterminado es Ninguno. El color de descarte se utiliza para el escaneo monocromático y selecciona el color que no se escanea. Esto se puede usar para, por ejemplo, escanear un original con un fondo de color.

El interruptor --brightness controla el brillo del escaneo. Las opciones válidas son valores enteros de -3 a 3. El valor predeterminado es 0. Cuanto mayor sea el valor de brillo, más brillante será la imagen. Si se selecciona una tabla definida por el usuario para la corrección gamma, el parámetro de brillo no está disponible.

El interruptor --sharpness establece la nitidez de los datos de la imagen. Las opciones válidas son valores enteros de -2 a 2, con -2 significando "Defocus", -1 "Defocus ligeramente", 0 "Normal", 1 "Nitidez ligeramente" y 2 "Nitidez".

El interruptor --gamma-correction controla la corrección gamma interna del escáner. Las opciones válidas son "Default", "User defined", "High density printing", "Low density printing" y "High contrast printing".

El interruptor --color-correction controla la función de corrección de color interna del escáner. Las opciones válidas son "No Correction", "Impact-dot printers", "Thermal printers", "Ink-jet printers" y "CRT monitors". El valor predeterminado es "CRT monitors".

El interruptor --resolution selecciona la resolución para un escaneo. Algunos escáneres EPSON escanearán en cualquier resolución entre el valor más bajo y el más alto posible. La lista reportada por el escáner se puede mostrar usando los parámetros "--help -d epson" de scanimage(1).

La opción --mirror controla la forma en que se escanea la imagen. Al leer los datos de la imagen de derecha a izquierda, la imagen se invierte. Las opciones válidas son "yes" y "no". El valor predeterminado es "no".

La opción --speed puede mejorar la velocidad de escaneo en modo monocromo. Las opciones válidas son "yes" o "no", la opción "yes" acelerará el escaneo si esta opción es compatible.

El interruptor --auto-area-segmentation activa la segmentación automática de área para escaneos monocromos. El escáner intentará determinar qué áreas son texto y cuáles contienen imágenes. Las áreas de imagen se tramarán y el texto se mejorará. Las opciones válidas son "yes" y "no". El valor predeterminado es "yes".

El parámetro --gamma-table se puede utilizar para descargar una tabla gamma definida por el usuario. La opción toma 256 valores del rango 0-255. En modo color, esta opción afecta por igual a los canales rojo, verde y azul.

El parámetro --red-gamma-table se puede utilizar para descargar una tabla gamma definida por el usuario para el canal rojo. Las opciones válidas son las mismas que para --gamma-table.

El parámetro --green-gamma-table se puede utilizar para descargar una tabla gamma definida por el usuario para el canal verde. Las opciones válidas son las mismas que para --gamma-table.

El parámetro --blue-gamma-table se puede utilizar para descargar una tabla gamma definida por el usuario para el canal azul. Las opciones válidas son las mismas que para --gamma-table.

Los coeficientes de corrección de color --cct-1 --cct-2 --cct-3 ... --cct-9 instalarán coeficientes de corrección de color para la corrección de color definida por el usuario. Los valores se especifican como enteros en el rango -127..127.

La opción --preview solicita un escaneo de vista previa. El software frontend selecciona automáticamente una resolución baja. Las opciones válidas son "yes" y "no". El valor predeterminado es "no".

Las opciones --preview-speed aumentarán la velocidad de escaneo si esto es compatible con el escáner. Las opciones válidas son "yes" y "no", el valor predeterminado es "no".

Las opciones de geometría -l -t -x -y controlan el área de escaneo: -l establece la coordenada x superior izquierda, -t la coordenada y superior izquierda, -x selecciona el ancho y -y la altura del área de escaneo. Todos los parámetros se especifican en milímetros.

La opción --quick-format permite al usuario seleccionar un área de escaneo con tamaños predefinidos. Los parámetros válidos son "CD", "A5 portrait", "A5 landscape", "Letter", "A4" y "max". El valor predeterminado es "max", que selecciona el área más grande posible.

La opción --source selecciona la fuente de escaneo. Las opciones válidas dependen de las opciones instaladas. El valor predeterminado es "Flatbed".

NOMBRE

sane-epson - un backend de SANE para escáneres Epson

DESCRIPCIÓN

El backend sane-epson implementa una interfaz SANE (Scanner Access Now Easy) de nivel API-V2 para varios escáneres Epson. Utiliza la biblioteca sane-sg para la comunicación con el escáner. La lista de escáneres soportados se puede encontrar en la página de inicio de SANE.

Este backend fue desarrollado y probado en un Epson GT-7000 y funciona en la mayoría de los escáneres Epson que son compatibles con el protocolo de escáner Epson o que tienen el mismo comportamiento de dispositivo USB que el GT-7000.

Este backend tiene soporte para la mayoría de las opciones del dispositivo de SANE:

Modos
Modo de color (color, escala de grises, blanco y negro), resolución (píxeles por pulgada).
Geometría
Área de escaneo (x, y, ancho, alto).
Profundidad de bits
Las resoluciones soportadas son 1, 8 y 24 bits por píxel.
Opciones
Las opciones del escáner específicas de Epson se implementan como opciones de SANE.

OPCIONES

Este backend soporta las siguientes opciones específicas de Epson:

--auto-detect-auto-adjust
Esta opción fuerza al escáner a detectar el tipo de documento y a ajustar la configuración de escaneo automáticamente. El escáner ignora todas las opciones de resolución y de bits por píxel si esta opción está activada. El escáner se inicia con la resolución de escaneo por defecto de 300 dpi.
--auto-eject
La opción --auto-eject eyectará una página después de escanear desde el alimentador de documentos.
--film-type
La opción --film-type seleccionará el tipo de película para escaneos con la unidad de transparencia. Esta opción solo se activa si la TPU se selecciona como fuente de escaneo. Las opciones válidas son "Negative Film" y "Positive Film".
--focus-position
La opción --focus-position selecciona la posición de enfoque para todos los escaneos. Las opciones válidas son "Focus 2.5mm above glass" y "Focus on glass". El enfoque en el punto de 2.5 mm por encima del cristal es necesario para escaneos con la unidad de transparencia, para que el escáner pueda enfocar la película si se utiliza uno de los soportes de película. Esta opción solo es funcional para escáneres seleccionados, todos los demás escáneres ignorarán esta opción.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/epson.conf especifica los dispositivos que utilizará el backend. Los tipos de conexión posibles son:

SCSI
Este es el valor predeterminado, y si no se especifica nada más, el software de backend abrirá una ruta dada como dispositivo SCSI. Se puede encontrar más información sobre la sintaxis válida para dispositivos SCSI en sane-scsi(5).
Normalmente, los escáneres SCSI se configuran con una línea "scsi EPSON" en este archivo. En algunos casos, puede ser necesario usar solo la cadena "scsi" (por ejemplo, para el GT-6500).
PIO - Interfaz Paralela
La interfaz paralela se puede configurar de dos maneras: Un valor entero que comience al principio de una línea se interpretará como la dirección de E/S del puerto paralelo. Para que sea más claro que una dirección de E/S configurada es un puerto paralelo, la dirección del puerto puede ir precedida de la cadena "PIO". La conexión PIO no utiliza un archivo de dispositivo especial en el directorio /dev. La dirección de E/S se puede especificar en modo hexadecimal (precedida de "0x").
USB
Un archivo de dispositivo que va precedido de la cadena "USB" se trata como un escáner conectado a través del Bus Serie Universal. El archivo de dispositivo especial correcto debe crearse antes de usarlo con Sane. Consulte la documentación de USB para obtener más información sobre cómo configurar el subsistema USB y los archivos de dispositivo requeridos.

ARCHIVOS

/usr/lib/sane/libsane-epson.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-epson.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_DEBUG_EPSON
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más pequeños reducen la verbosidad.
SANE_DEBUG_EPSON_SCSI
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración relacionado con SCSI para este backend. Solo se admite un valor de 2.
SANE_EPSON_CMD_LVL
Esto permite anular la función o el nivel de comando que utiliza el backend para comunicarse con el escáner. El nivel de función que admite un escáner se determina durante la inicialización del dispositivo. Si el backend no reconoce el nivel de función informado por el escáner, usará por defecto el nivel de función B3. Los niveles de función válidos son A1, A2, B1, B2, B3, B4, B5, B6, B7, B8, D1 y F5. ¡Use esta función solo si sabe lo que está haciendo!

ERRORES

Ninguno :-) Al menos ninguno conocido actualmente.

DISPOSITIVOS NO SOPORTADOS

El backend puede usarse con escáneres Epson que aún no figuran en la lista de dispositivos compatibles. Un escáner no reconocido puede usar por defecto el nivel de función B3, lo que significa que no todas las funciones de las que puede ser capaz el escáner son accesibles.

Si el escáner ni siquiera se reconoce como un escáner Epson, probablemente se deba a que el nombre del dispositivo informado por el escáner no tiene el formato correcto. Por favor, envíe esta información al mantenedor del backend (la dirección de correo electrónico está en la sección AUTOR de esta página man o en el archivo AUTHORS de la distribución SANE).

Los modelos Perfection 600, Perfection 650, Perfection 660, Perfection 1250 y Perfection 1260 no están soportados por este backend.
