NOMBRE

samba - Servidor de archivos SMB/CIFS y AD de Windows para UNIX

SINOPSIS

samba

DESCRIPCIÓN

El conjunto de software Samba es una colección de programas que implementa el protocolo Server Message Block (comúnmente abreviado como SMB) para sistemas UNIX y proporciona servicios de Active Directory. La primera versión del protocolo SMB a veces también se denomina Common Internet File System (CIFS). Para una descripción más completa, consulte http://www.ubiqx.org/cifs/. Samba también implementa el protocolo NetBIOS en nmbd.

samba(8)

El demonio samba proporciona los servicios de Active Directory y servicios de archivos e impresión a los clientes SMB. El archivo de configuración para este demonio se describe en smb.conf(5).

smbd(8)

El demonio smbd proporciona los servicios de archivos e impresión a los clientes SMB. El archivo de configuración para este demonio se describe en smb.conf(5).

nmbd(8)

El demonio nmbd proporciona el servicio de nombres NetBIOS y el soporte de navegación. El archivo de configuración para este demonio se describe en smb.conf(5).

winbindd(8)

winbindd es un demonio que se utiliza para integrar la autenticación y la base de datos de usuarios en UNIX.

smbclient(1)

El programa smbclient implementa un cliente simple similar a ftp. Es útil para acceder a recursos compartidos SMB en otros servidores SMB compatibles y también puede usarse para permitir que una máquina UNIX imprima en una impresora conectada a cualquier servidor SMB.

samba-tool(8)

samba-tool es la herramienta principal de administración de Samba en lo que respecta a los servicios de Active Directory.

testparm(1)

La utilidad testparm es un verificador de sintaxis simple para el archivo de configuración smb.conf(5) de Samba. Sin embargo, en el modo de servidor AD, se debe usar samba-tool testparm.

smbstatus(1)

La herramienta smbstatus proporciona acceso a información sobre las conexiones actuales a smbd.

nmblookup(1)

La herramienta nmblookup permite realizar consultas de nombres NetBIOS.

smbpasswd(8)

El comando smbpasswd es una herramienta para establecer contraseñas en Samba local y también en servidores SMB remotos.

smbcacls(1)

El comando smbcacls es una herramienta para establecer ACLs en servidores SMB remotos.

smbtree(1)

El comando smbtree es una herramienta de vecindario de red basada en texto.

smbtar(1)

smbtar puede hacer copias de seguridad de datos directamente desde servidores SMB.

smbspool(8)

smbspool es una utilidad auxiliar para imprimir en impresoras conectadas a servidores SMB.

smbcontrol(1)

smbcontrol es una utilidad que puede cambiar el comportamiento de los demonios samba, smbd, nmbd y winbindd en ejecución.

rpcclient(1)

rpcclient es una utilidad que se puede utilizar para ejecutar comandos RPC en servidores SMB remotos.

pdbedit(8)

El comando pdbedit se puede utilizar para mantener la base de datos de usuarios local en un servidor Samba.

net(8)

El comando net es la herramienta de administración principal para servidores miembro y autónomos de Samba.

wbinfo(1)

wbinfo es una utilidad que recupera y almacena información relacionada con winbind.

profiles(1)

profiles es una utilidad de línea de comandos que se puede utilizar para reemplazar todas las ocurrencias de un SID determinado por otro SID.

log2pcap(1)

log2pcap es una utilidad para generar archivos de rastreo pcap a partir de archivos de registro de Samba.

vfstest(1)

vfstest es una utilidad que se puede utilizar para probar módulos vfs.

ntlm_auth(1)

ntlm_auth es una utilidad auxiliar para programas externos que desean realizar autenticación NTLM.

smbcquotas(1)

smbcquotas es una herramienta para administrar cuotas en servidores SMB remotos.

COMPONENTES

El conjunto de software Samba se compone de varios componentes. Cada componente se describe en una página de manual separada. Se recomienda encarecidamente que lea la documentación que viene con Samba y las páginas del manual de los componentes que utilice. Si las páginas del manual y los documentos no son lo suficientemente claros, visite https://devel.samba.org para obtener información sobre cómo informar de un error o enviar un parche.

Si necesita ayuda, visite la página web de Samba en https://www.samba.org/ y explore las muchas opciones disponibles para usted.

DISPONIBILIDAD

El conjunto de software Samba tiene la licencia GNU Public License (GPL). Una copia de esa licencia debería haber venido con el paquete en el archivo COPYING. Se le anima a distribuir copias del conjunto de software Samba, pero respete los términos de esta licencia.

La última versión del conjunto de software Samba se puede obtener en https://download.samba.org/pub/samba/.

El Wiki de Samba en https://wiki.samba.org también tiene mucha información útil. En la lista de correo de Samba en https://lists.samba.org puede encontrar mucha información en los archivos y puede suscribirse a la lista de samba y pedir ayuda o discutir cosas.

CONTRIBUCIONES

CONTRIBUIDORES

Los contribuidores al proyecto son ahora demasiado numerosos para mencionarlos aquí, pero todos merecen el agradecimiento de todos los usuarios de Samba. Para ver una lista completa, consulte el registro de cambios en el paquete fuente para los cambios anteriores a CVS y en https://git.samba.org/ para los contribuidores a Samba después de GIT. GIT es el sistema de control de código fuente de código abierto utilizado por el Equipo de Samba para desarrollar Samba. El proyecto habría sido inmanejable sin él.

AUTOR
