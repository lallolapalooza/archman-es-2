NOMBRE

samba_downgrade_db - Herramienta de Samba para degradar bases de datos AD

SINOPSIS

samba_downgrade_db [-H] [-s]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de utilidades de samba(8).

El formato de la base de datos de Active Directory (AD) de Samba cambió en las versiones 4.8 y 4.11. Al degradar un Controlador de Dominio (DC) de AD de Samba a una versión anterior a cualquiera de estas (por ejemplo, de 4.11 a 4.10), la base de datos de AD debe degradarse manualmente *antes* de que los paquetes de Samba puedan ser degradados de forma segura.

Esta herramienta degrada una base de datos sam.ldb de Samba desde el formato utilizado en la versión 4.23.3 al de la versión 4.7. El formato de base de datos v4.7 puede ser leído de forma segura por cualquier versión de Samba. Si es necesario, versiones posteriores de Samba reempaquetarán y reconfigurarán una base de datos en formato v4.7 cuando se inicie el ejecutable de Samba por primera vez.

Tenga en cuenta que todos los servicios de Samba deben estar detenidos en el DC antes de ejecutar esta herramienta. Una vez que la herramienta haya finalizado, no reinicie samba ni modifique la base de datos antes de haber degradado el paquete de software de Samba.

OPCIONES

-H [archivo sam.ldb]

Enlace directo a un archivo sam.ldb en lugar de usar la ruta en el smb.conf del sistema

-s [archivo smb.conf]

Enlace directo al archivo smb.conf en lugar del predeterminado del sistema (generalmente en /usr/local/samba/etc/smb.conf)
