NOMBRE

sane-nec - backend de SANE para escáneres NEC

DESCRIPCIÓN

La biblioteca sane-nec implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a escáneres SCSI de NEC. ¡Este backend debe considerarse software de calidad alfa! En el estado actual, se sabe que funciona con escáneres PC-IN500/4C. Otras series de escáneres MultiReader no son compatibles. Los escáneres PC-IN 500/4C y MultiReader solo se venden en Japón (excepto Multi Reader PetiScan).

Para otros escáneres, puede funcionar o no.

El backend tiene los siguientes problemas conocidos:

- El modo ColorLineart no es compatible.
- El nombre del dispositivo está fijado a /dev/scanner

Por el momento, se sabe que los siguientes escáneres funcionan con este backend.

Vendedor Producto id
------ -----------
NEC    PC-IN500/4C

ARCHIVOS

/etc/sane.d/nec.conf
El archivo de configuración del backend.
/usr/lib/sane/libsane-nec.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-nec.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_DEBUG_NEC
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.

VER TAMBIÉN

sane(7), sane-scsi(5)
