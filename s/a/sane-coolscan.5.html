NOMBRE

sane-coolscan - Backend de SANE para escáneres de película Nikon

SOBRE ESTE ARCHIVO

Este archivo es una breve descripción del backend coolscan para SANE.

DESCRIPCIÓN

La biblioteca sane-coolscan implementa un backend de SANE que proporciona la interfaz a los siguientes escáneres de película Nikon Coolscan: Nikon LS20, LS30, LS1000, LS2000.

Aunque el backend ha funcionado para varias personas, todavía existen algunos problemas, especialmente en combinación con algunas tarjetas/controladores SCSI (AHA-1505/aha152x.o) y el comando de enfoque automático. Deberías considerar este backend como 'alfa' y tener cuidado la primera vez que lo uses.

CONFIGURACIÓN

El archivo de configuración para este backend se encuentra en /etc/sane.d/coolscan.conf.

Su contenido es una lista de nombres de dispositivos que corresponden a los escáneres Nikon Coolscan. Las líneas vacías y las líneas que comienzan con una almohadilla (#) se ignoran. A continuación se muestra un archivo de configuración de ejemplo:

 #scsi Vendor Model Type
 scsi Nikon * Scanner
 /dev/scanner

El nombre de dispositivo especial debe ser un dispositivo SCSI genérico o un enlace simbólico a dicho dispositivo. Para averiguar a qué dispositivo está asignado tu escáner y cómo puedes configurar los permisos de ese dispositivo, consulta sane-scsi(5).

CONSEJOS PARA ADAPTADORES SCSI

Algunos adaptadores SCSI y controladores SCSI de bajo nivel no funcionan correctamente con este backend y los escáneres Coolscan. Estos sistemas se cuelgan cuando se envía el comando de enfoque automático al escáner. Para ver una lista de las combinaciones de tarjeta/controlador que funcionan o no, consulta: http://andreas.rick.free.fr/sane/autofocus.html.

ARCHIVOS

El archivo de configuración del backend:
/etc/sane.d/coolscan.conf
La biblioteca estática que implementa este backend:
/usr/lib/sane/libsane-coolscan.a
La biblioteca compartida que implementa este backend:
/usr/lib/sane/libsane-coolscan.so (presente en sistemas que admiten carga dinámica)

ENTORNO

SANE_DEBUG_COOLSCAN
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.

Ejemplos:

En bash:
export SANE_DEBUG_COOLSCAN=8

En csh:
setenv SANE_DEBUG_COOLSCAN 8

ERRORES

El comando de enfoque automático no funciona con algunas combinaciones de tarjeta/controlador SCSI.

La tabla gamma aún no está implementada para el LS1000.

La eliminación de polvo aún no funciona.
