SAMBA_GPOUPDATE(8) Herramientas de Administración del Sistema SAMBA_GPOUPDATE(8)

NOMBRE

samba-gpupdate - aplicar directivas de grupo

SINOPSIS

samba-gpupdate

samba-gpupdate [opciones]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de utilidades de samba(1).

samba-gpupdate es un script para aplicar y desaplicar Directivas de Grupo. Aplica directivas de contraseñas (antigüedad mínima/máxima de contraseña, longitud mínima de contraseña y complejidad de contraseña), directivas de kerberos (tiempo de vida de tickets de usuario/servicio y tiempo de vida de renovación), directivas de smb.conf, scripts de cron horarios/diarios/semanales/mensuales, privilegios Sudo, mensajes del Día del Inicio de Sesión y mensajes de inicio de sesión, etc.

OPCIONES

-h, --help mostrar este mensaje de ayuda y salir

-H URL, --url=URL URL para el samdb

-X, --unapply Desaplicar Directiva de Grupo

--target {Computer | User}

--force Reaplica todas las configuraciones de directiva

--rsop Imprimir el Conjunto Resultante de Directivas

Opciones Comunes de Samba:

-s FILE, --configfile=ARCHIVO Archivo de configuración

-d DEBUGLEVEL, --debuglevel=NIVEL_DE_DEPURACIÓN nivel de depuración

--option=OPCIÓN establecer opción de smb.conf desde la línea de comandos

--realm=REALM establecer el nombre del realm

Opciones de Versión:

-V, --version Mostrar número de versión

Opciones de Credenciales:

--simple-bind-dn=DN DN para usar para un enlace simple

--password=CONTRASEÑA Contraseña

-U USUARIO, --username=USUARIO Nombre de usuario

-W GRUPO_DE_TRABAJO, --workgroup=GRUPO_DE_TRABAJO Grupo de Trabajo

-N, --no-pass No pedir contraseña

-k KERBEROS, --kerberos=KERBEROS Usar Kerberos

--ipaddress=DIRECCIÓN_IP Dirección IP del servidor

-P, --machine-pass Usar contraseña de cuenta de máquina almacenada
