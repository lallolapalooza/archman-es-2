NOMBRE

sane-kodakaio - backend SANE para impresoras/escáneres multifunción Kodak

DESCRIPCIÓN

La biblioteca sane-kodakaio implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a las impresoras/escáneres multifunción Kodak, como las series ESP y Hero.

Este documento describe la versión 2.4 del backend, que es la primera candidata para su incorporación a sane-backends.

HARDWARE SOPORTADO

Esta versión debería soportar modelos de las series Kodak ESP y Hero, y posiblemente algunos escáneres multifunción Advent. Los modelos ESP 5250 y Hero 9.1 se utilizaron para desarrollar el backend, pero otros modelos podrían funcionar. Consulte la lista de dispositivos soportados en http://www.sane-project.org/sane-backends.html#S-KODAKAIO.

Si tiene un modelo que no está en esa lista, o está marcado como 'sin probar': la mejor manera de determinar el nivel de soporte es probar el escáner directamente.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración kodakaio.conf se utiliza para indicar al backend cómo buscar escáneres y proporcionar opciones que controlan el funcionamiento del backend. Este archivo se lee cada vez que el frontend solicita al backend una lista de escáneres, generalmente solo cuando el frontend se inicia.

ENTORNO

SANE_DEBUG_KODAKAIO
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Los niveles de depuración más altos aumentan la verbosidad de la salida.

PROBLEMAS CONOCIDOS

La mayoría de las opciones de hardware no son compatibles o no se exponen para el control por parte del usuario, incluyendo: detección de alimentador múltiple, compresión de imágenes, etc.
