NOMBRE

sane-epsonds - Backend de SANE para escáneres EPSON ESC/I-2

DESCRIPCIÓN

La biblioteca sane-epsonds implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a escáneres Epson ESC/I-2.

Las opciones de línea de comandos válidas y su sintaxis se pueden listar usando

scanimage --help -d epsonds

No todos los dispositivos soportan todas las opciones.

Modo de Escaneo
El interruptor --mode selecciona el modo básico de operación del escáner. Las opciones válidas son Lineart, Gray y Color. El modo Lineart es solo blanco y negro, Gray producirá 256 niveles de gris o más dependiendo del escáner y Color significa modo de color de 24 bits o más dependiendo del escáner. Algunos escáneres usarán internamente 36 bits de color, sin embargo, su interfaz externa puede soportar solo 24 bits.

La opción --depth selecciona la profundidad de bits que está utilizando el escáner. Esta opción solo está disponible para escáneres que soportan más de una profundidad de bits. Los escáneres más antiguos siempre transferirán la imagen en modo de 8 bits. Los escáneres más nuevos permiten seleccionar 8 bits, 12 o 14 bits por canal de color. Para un escaneo en color, esto significa una profundidad de color efectiva de 36 o 42 bits en todos los tres canales. Las opciones válidas dependen del modelo del escáner.

El interruptor --resolution selecciona la resolución para un escaneo. Algunos escáneres EPSON escanearán a cualquier resolución entre el valor más bajo y el más alto posible. La lista reportada por el escáner se puede mostrar usando los parámetros "--help -d epson" para scanimage(1).

Las opciones de geometría -l -t -x -y controlan el área de escaneo: -l establece la coordenada x de la esquina superior izquierda, -t la coordenada y de la esquina superior izquierda, -x selecciona el ancho y -y la altura del área de escaneo. Todos los parámetros se especifican en milímetros.

La opción --source selecciona la fuente de escaneo. Las opciones válidas dependen de las opciones instaladas. El valor por defecto es "Flatbed".

La opción --eject expulsa la hoja en el ADF.

La opción --adf-mode selecciona el modo ADF (simplex/dúplex).

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/epsonds.conf especifica los dispositivos que utilizará el backend. Los posibles tipos de conexión son:

USB
Para escáneres USB no detectados automáticamente, sus ID de VENDOR y PRODUCT se pueden especificar manualmente en el archivo de configuración. Se puede encontrar más información sobre la sintaxis válida para dispositivos USB en sane-usb(5).
Red (aún no soportada)
Los escáneres de red se pueden auto-descubrir si se especifica autodiscovery después de la palabra clave net. También se puede usar una dirección IP para conectarse.

ARCHIVOS

/usr/lib/sane/libsane-epsonds.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-epsonds.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_DEBUG_EPSONDS
Si la biblioteca fue compilada con soporte de depuración activado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad. Los valores alrededor de 11-16 suelen ser suficientes para un informe de errores.

VER TAMBIÉN
