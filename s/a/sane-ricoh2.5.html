NOMBRE

sane-ricoh2 - Backend de SANE para escáneres planos Ricoh

DESCRIPCIÓN

La biblioteca sane-ricoh2 implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a los siguientes escáneres planos Ricoh:

SG-3110SFNw
SG-3100SNw
SP-100SU
SP-111SU (SP-112SU)

ARCHIVOS

/usr/lib/sane/libsane-ricoh2.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-ricoh2.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

OPCIONES

Las opciones que admite el backend se pueden seleccionar a través de opciones de línea de comandos para programas como scanimage(1) o a través de elementos de interfaz gráfica en programas como xscanimage(1) o xsane(1).

Las siguientes opciones son compatibles con ricoh2:

--mode color|gray

Modo de color o escala de grises.

--resolution 300|600

Resolución en DPI.

ENTORNO

SANE_DEBUG_RICOH2
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Los niveles de depuración más altos aumentan la verbosidad de la salida.

VEASE TAMBIÉN

sane(7), sane-usb(5), scanimage(1), xscanimage(1), xsane(1)
