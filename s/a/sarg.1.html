NOMBRE

sarg - Generador de Informes de Análisis de Squid

SINOPSIS

sarg [opciones] [archivo_log...]

DESCRIPCIÓN

sarg es un analizador y procesador de archivos de log para el Proxy Web de Caché de Squid[1]. Permite ver "dónde" van sus usuarios en Internet.

sarg genera informes en HTML con campos como: usuarios, direcciones IP, bytes, sitios y horas. Estos archivos HTML pueden aparecer en el directorio de su servidor web para ser navegados por usuarios o administradores. También puede hacer que sarg envíe los informes por correo electrónico al administrador de la Caché de Squid.

sarg puede leer logs de acceso de Squid o Microsoft ISA. Opcionalmente, puede complementar los informes con el log de un filtro/redireccionador de Squid como squidGuard[2].

OPCIONES

A continuación se incluye un resumen de las opciones.

-h --help

Muestra un resumen de las opciones.

-a hostname|ip dirección

Limita el informe a los registros que contienen el nombre de host/dirección IP especificados

-b nombre_archivo

Habilita el log de UserAgent y lo escribe en nombre_archivo.

-c nombre_archivo

Lee nombre_archivo para obtener una lista de los hosts web que se deben excluir del informe. Consulte la sección "ARCHIVO DE EXCLUSIÓN DE HOSTS".

--convert

Convierte el campo de fecha/hora del archivo de log de Squid a un formato legible por humanos. Se leen todos los archivos de log y se emiten como un solo texto en la salida estándar.

--css

Genera la hoja de estilos CSS interna que sarg inserta en los informes, y la envía a la salida estándar. Puede redirigir la salida a un archivo de su elección y editarlo. Luego, puede sobrescribir el CSS interno con external_css_file en sarg.conf.

El uso de un CSS externo puede reducir el tamaño del archivo de informe. Si tiene poco espacio en disco, considere exportar el CSS como se explicó anteriormente.

-d fecha

Utiliza fecha para restringir el informe a un rango de fechas específico durante el procesamiento del archivo de log. El formato para fecha es dd/mm/aaaa-dd/mm/aaaa o una fecha única dd/mm/aaaa. Los rangos de fechas también se pueden especificar como dia-n, semana-n, o mes-n donde n es el número de días, semanas o meses anteriores. Tenga en cuenta que no hay espacios alrededor del guion.

-e correo_electronico

Envía el informe a correo_electronico (salida estándar para consola).

-f nombre_archivo

Lee la configuración desde nombre_archivo.

-g e|u

Establece el formato de fecha en los informes generados.
e = Europa -> dd/mm/aa
u = USA -> mm/dd/aa

-i

Genera informes por usuario y dirección IP.

Nota
Esto requiere que la opción report_type en el archivo de configuración contenga "users_sites".

--keeplogs

No elimina ningún informe antiguo. Es equivalente a establecer --lastlog 0, pero se proporciona para mayor comodidad.

-l nombre_archivo

Utiliza nombre_archivo como log de entrada. Esta opción se puede repetir hasta 255 veces para leer varios archivos. Si los archivos terminan con la extensión .gz, .bz2 o .Z, se descomprimen. Si el nombre del archivo es solo -, el archivo de log se lee desde la entrada estándar. En ese caso, no puede estar comprimido.

Esta opción se mantiene por compatibilidad con versiones anteriores de sarg, pero a partir de sarg 2.3, los archivos de log se pueden nombrar en la línea de comandos sin la opción -l. Permite el uso de comodines en la línea de comandos. Asegúrese de no superar el límite de 255 archivos.

--lastlog n

Limita el número de logs conservados en el directorio de salida a n. Cualquier informe supernumerario se elimina comenzando por el informe más antiguo. El valor de n debe ser positivo o cero. Un valor de cero significa que no se debe eliminar ningún informe.

-L nombre_archivo

Lee un archivo de log de redireccionamiento de proxy, como los creados por squidGuard o Rejik. Si utiliza esta opción, es posible que desee configurar redirector_log_format en sarg.conf para que coincida con el formato de salida de su programa de filtrado de contenido web. Esta opción se puede repetir hasta 64 veces para leer varios archivos.

-n

Habilita la resolución de direcciones IP.

-o directorio

Escribe el informe en directorio.

-p

Genera informes utilizando la dirección IP en lugar del ID de usuario.

-P prefijo --splitprefix prefijo

Esta opción debe usarse con --split. Si se proporciona, el log de entrada se divide en varios archivos, cada uno conteniendo un día. El nombre de los archivos de salida se compone del prefijo y la fecha formateada como -AAAA-MM-DD.

Los archivos de salida se escriben en el directorio de salida especificado con -o o en el directorio actual.

-r

Genera el informe en tiempo real en la salida estándar y sale.

-s cadena

Limita el informe al sitio especificado por cadena [ej. www.debian.org]

--split

Divide el archivo de log de Squid y lo emite como texto en la salida estándar, omitiendo las fechas fuera del rango especificado por el parámetro -d. Si se combina con --convert, las fechas también se convierten a un formato legible por humanos.

Combinado con -P, el log se escribe en varios archivos, cada uno conteniendo un día del log original.

--statistics

Escribe algunas estadísticas sobre el tiempo de ejecución. Las estadísticas incluyen el tiempo total de ejecución; el número de registros leídos en los archivos de log de entrada y el tiempo que se tardó en leerlos; el número de registros y usuarios procesados y el tiempo que se tardó en procesarlos.

-t cadena

Limita los registros incluidos en el informe según la hora del día. El formato para cadena es HH:MM o HH:MM-HH:MM. El primero informa solo la hora solicitada. El segundo informa cualquier entrada que caiga dentro del rango solicitado. Este límite complementa el límite impuesto por la opción -d.

-u usuario

Limita los informes a las actividades del usuario.

-v

Muestra la versión de sarg y sale.

-w directorio

Almacena archivos temporales en directorio. De hecho, sarg almacena sus archivos temporales en el subdirectorio sarg de directorio. Asegúrese de establecer el directorio de salida HTML en un lugar fuera del directorio temporal o sarg podría fallar o eliminar el informe al completar su tarea.

-x

Escribe mensajes de depuración en stdout

-z

Escribe mensajes de proceso en stdout.

ARCHIVO DE EXCLUSIÓN DE HOSTS

Se le puede indicar a Sarg que excluya hosts visitados proporcionándole un archivo que contenga un host a excluir por línea. El "host" puede ser uno de los siguientes:

•un nombre de host completo,
•un nombre de host que comience con un comodín (*) para coincidir con cualquier prefijo,
•una única dirección IP,
•una subred notada a.b.c.d/e.

Ejemplo 1. Ejemplo de archivo de exclusión de hosts

*.google.com
10.0.0.0/8

Sarg no puede excluir direcciones IPv6 en este momento.
