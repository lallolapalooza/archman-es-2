sane-matsushita(5) Acceso Fácil a Escáneres SANE sane-matsushita(5)

NOMBRE

sane-matsushita - backend SANE para escáneres de alta velocidad Panasonic KV-SS

DESCRIPCIÓN

La biblioteca sane-matsushita implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a algunos escáneres de alta velocidad Panasonic KV-SS. Este backend es estable.

Actualmente, se sabe que los siguientes escáneres funcionan con este backend:

  ID de producto
--------------
   KV-SS25
   KV-SS25D
   KV-SS55EX (*)
   KV-S2025C (*)
   KV-S2045C (*)
   KV-S2065L (*)

(*) ADVERTENCIA: Ninguna de las opciones avanzadas de estos escáneres está disponible (es decir, no hay color, no hay alta resolución, no hay recorte automático). Básicamente, el controlador no hace más de lo que hace para el KV-SS25. No tengo acceso a tales escáneres y, por lo tanto, no puedo agregar estas opciones.

Es posible que otros escáneres de alta velocidad Panasonic funcionen o no con este backend.

Las opciones válidas de línea de comandos y su sintaxis se pueden listar usando:

scanimage --help -d matsushita

Modo de escaneo
--modo
selecciona el modo básico de operación del escáner.
--resolucion
selecciona la resolución para un escaneo. Cada modelo admite todas o un subconjunto de estas resoluciones: 100, 150, 200, 240, 300, 360, 400.
--dúplex
indica si se deben escanear ambos lados de la hoja.
--modo-alimentador
selecciona el número de páginas a escanear (una o hasta que la bandeja esté vacía).
Geometría
--tamaño-papel A4|...|Oficio|Carta [A4]
selecciona el área a escanear. Ajusta las opciones -l -t -x -y en consecuencia. No necesita ser el tamaño real del papel.
-l -t -x -y
controla el área de escaneo: -l establece la coordenada x de la esquina superior izquierda, -t la coordenada y de la esquina superior izquierda, -x selecciona el ancho y -y la altura del área de escaneo. Todos los parámetros se especifican en milímetros. Es posible usar la opción --tamaño-papel en su lugar.
Mejora
--brillo
controla el brillo de la imagen adquirida. El valor varía de 1 a 255, o menos, dependiendo del modelo del escáner.
--contraste
controla el contraste de la imagen adquirida. Algunos modelos no admiten esta opción.
--umbral-automático
establece automáticamente el brillo, el contraste, el nivel de blanco, la gamma, la reducción de ruido y el énfasis de la imagen. Estas opciones no están disponibles cuando se usa el umbral automático.
--patron-tramado
establece la gradación tonal para el modo de tramado. La descarga de patrones no está implementada por el backend.
--autoseparacion
proporciona separación automática de texto e imágenes.
--nivel-blanco
indica la fuente de la base blanca.
--reduccion-ruido
reduce el ruido de puntos aislados. Esta opción no es compatible con todos los escáneres.
--enfasis-imagen
establece el énfasis de la imagen. Algunas selecciones no están disponibles en todos los escáneres.
--gamma
establece la curva gamma. Solo es válida para modos Gris y no está disponible en todos los escáneres. La descarga de gamma no está implementada por el backend.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración /etc/sane.d/matsushita.conf admite el nombre del dispositivo a usar (por ejemplo, /dev/scanner) y la opción SCSI para detectar automáticamente los escáneres compatibles.

ARCHIVOS

/usr/lib/sane/libsane-matsushita.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-matsushita.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_DEBUG_MATSUSHITA
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 128 solicita que se imprima toda la salida de depuración. Niveles más bajos reducen la verbosidad.

LIMITACIONES

Memoria en el KV-SS 25
El KV-SS 25 no tiene suficiente memoria interna para escanear una página A4 completa en modo dúplex a alta resolución. El frontend devolverá un error de memoria en ese caso. Aparentemente, el KV-SS 25D no tiene ese problema.
Descarga de patrones y gamma
El escáner, con el firmware adecuado, puede descargar un patrón de tramado y una tabla gamma. Esto no está implementado.
Sub-áreas
El escáner puede admitir hasta 3 sub-áreas en cada lado para definir opciones de mejora más precisas. Esto no está implementado.
Modo dúplex
El backend no admite la configuración de opciones diferentes para cada lado. El escaneo se realizará con las mismas opciones (patrón de tramado, brillo, énfasis de imagen) para ambos lados.

EJEMPLO DE ESCANEO

Hasta la fecha, el único frontend capaz de utilizar este escáner a toda velocidad es scanadf(1).

Una línea de comandos de scanadf(1) sería:

scanadf -d matsushita --output-file scan%04d.pbm --start-count 0 --dúplex --resolucion 300 --modo-alimentador="Todas las páginas" --tamaño-papel="A4"

ERRORES

Ninguno conocido.

sane-matsushita(5)

Controlador SANE para escáneres Matsushita/Panasonic

NOMBRE

sane-matsushita - controlador SANE para escáneres Matsushita/Panasonic

DESCRIPCIÓN

El archivo sane-matsushita.conf puede contener líneas que especifiquen opciones de configuración. Sin embargo, este controlador no tiene opciones de configuración disponibles.

Este controlador soporta los siguientes escáneres Matsushita/Panasonic:

  • Cruse CS-400
  • Panasonic KV-S1020C
  • Panasonic KV-S1025C
  • Panasonic KV-S1040C
  • Panasonic KV-S1045C
  • Panasonic KV-S2045C
  • Panasonic KV-S2065C
  • Panasonic KV-SS25
  • Panasonic KV-SS20
  • Panasonic UF-8000C
  • Panasonic UF-9000C
  • Panasonic KX-LC100

ARCHIVO_DE_CONFIGURACIÓN

El archivo de configuración (normalmente /etc/sane.d/matsushita.conf) puede contener líneas que especifiquen opciones de configuración. Este controlador no tiene opciones de configuración disponibles.

ARCHIVOS

  • /etc/sane.d/matsushita.conf
  • /usr/lib/sane/libsane-matsushita.so (o similar)

ENTORNO

SANE_CONFIG_DIR puede ser utilizado para especificar un nombre de archivo de configuración alternativo.

LIMITACIONES

Ninguna conocida.

EJEMPLO_DE_ESCANEO

No aplica.

ERRORES

Ninguno conocido.

VER_TAMBIÉN

sane-scsi(5), sane-usb(5), sane-find-scanner(1), scanimage(1)
