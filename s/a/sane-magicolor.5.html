NOMBRE

sane-magicolor - backend de SANE para escáneres KONICA MINOLTA magicolor y Toshiba TEC e-STUDIO

DESCRIPCIÓN

El backend sane-magicolor soporta escáneres KONICA MINOLTA magicolor y Toshiba TEC e-STUDIO conectados vía USB o LAN.

DISPOSITIVOS SOPORTADOS

El siguiente escáner debería funcionar con este backend:

Detalles del dispositivo
-----------------------------
Vendedor: KONICA MINOLTA
Modelo: magicolor 1690MF
Vendedor: Toshiba TEC
Modelo: e-STUDIO2323AM

CONFIGURACIÓN

Esta sección describe las entradas del archivo de configuración del backend. El archivo está ubicado en:

/etc/sane.d/magicolor.conf

Para una configuración adecuada, se necesita al menos una de las siguientes entradas:

net autodiscovery
net [DIRECCIÓN IP] [ID DEL DISPOSITIVO]
usb
usb [ID DEL VENDEDOR] [ID DEL DISPOSITIVO]

ARCHIVOS

/etc/sane.d/magicolor.conf
El archivo de configuración del backend
/usr/lib/sane/libsane-magicolor.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-magicolor.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por un punto y coma (`;'). Si esta variable no está configurada, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorio, entonces los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, configurar SANE_CONFIG_DIR a "/tmp/config:" resultaría en la búsqueda de los directorios /tmp/config, ., y /etc/sane.d (en este orden).
SANE_DEBUG_MAGICOLOR
Si la biblioteca fue compilada con soporte de depuración activado, esta variable de entorno controla el nivel de depuración para este backend. Niveles de depuración más altos aumentan la verbosidad de la salida.

Ejemplo: export SANE_DEBUG_MAGICOLOR=127

Para obtener mensajes de depuración del backend, configure esta variable de entorno antes de llamar a su frontend favorito (por ejemplo, xscanimage(1)).

Ejemplo: SANE_DEBUG_MAGICOLOR=65 xscanimage

ERRORES CONOCIDOS Y RESTRICCIONES

Los escaneos de color grandes a veces pueden caducar por razones desconocidas (el escáner simplemente deja de devolver datos).

Cancelar escaneos grandes puede bloquear el escáner.
