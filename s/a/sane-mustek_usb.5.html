sane-mustek_usb(5) SANE Scanner Access Now Easy sane-mustek_usb(5)

NOMBRE

sane-mustek_usb - Backend de SANE para escáneres planos USB Mustek

DESCRIPCIÓN

La biblioteca sane-mustek_usb implementa un backend de SANE (Scanner Access Now Easy) que proporciona acceso a escáneres planos USB Mustek (incluyendo un clon de Trust). Actualmente, se sabe que los siguientes escáneres funcionan más o menos con este backend:

Mustek 600 CU
Mustek 1200 UB
Mustek 1200 CU
Mustek 1200 CU Plus
Trust Compact Scan USB 19200

Se pueden encontrar más detalles en la página principal del backend Mustek USB http://www.meier-geinitz.de/sane/mustek_usb-backend/.

Los escáneres Mustek BearPaw 1200 y 2400 son compatibles con el backend plustek. Consulte sane-plustek(5) para obtener detalles. El Mustek BearPaw 1200F es compatible con el backend MA-1509. Consulte sane-ma1509(5) para obtener detalles. Otros escáneres USB Mustek son compatibles con el backend gt68xx, consulte sane-gt68xx(5).

Este backend solo puede funcionar con escáneres que ya sean detectados por el sistema operativo. Consulte sane-usb(5) para obtener detalles.

Si posee un escáner Mustek (o Trust) que no sea de los mencionados anteriormente y que funcione con este backend, por favor, hágamelo saber enviando el nombre exacto del modelo del escáner y los IDs del proveedor y producto USB (por ejemplo, de /proc/bus/usb/devices o syslog) a mí.

NOMBRES DE DISPOSITIVO

Este backend espera nombres de dispositivo del tipo:

especial

Donde especial es una ruta al dispositivo especial que corresponde a un escáner USB. Con Linux, un nombre de dispositivo podría ser /dev/usb/scanner0 o /dev/usbscanner1, por ejemplo.

Para FreeBSD use /dev/uscanner0.

CONFIGURACIÓN

El contenido del archivo mustek_usb.conf es una lista de opciones y nombres de dispositivo que corresponden a escáneres USB Mustek. Las líneas vacías y las líneas que comienzan con un signo de almohadilla (#) se ignoran. Si se coloca un nombre de dispositivo en mustek_usb.conf, debe ir seguido de una línea que contenga la palabra clave option y una opción que especifique el tipo de escáner. Las siguientes opciones se pueden utilizar: 600cu, 1200cu, 1200cu_plus, 1200ub. Para el Trust Compact Scan USB 19200 use `option 1200ub'.

En lugar de usar el nombre del dispositivo, el escáner puede ser autodetectado mediante declaraciones usb vendor_id product_id que ya están incluidas en mustek_usb.conf. Esto solo se admite en Linux 2.4.8 y superior y en todos los sistemas que admiten libusb. "vendor_id" y "product_id" son números hexadecimales que identifican el escáner. Si esto no funciona, se debe colocar un nombre de dispositivo y la opción que especifica el tipo de escáner en mustek_usb.conf como se describió anteriormente.

La opción global option max_block_size se puede usar para limitar la cantidad de datos adquiridos en un turno del sistema USB. Puede valer la pena intentarlo si ocurren errores de USB.

A continuación se muestra un ejemplo de archivo de configuración:

# Comentario
option max_block_size 1024
usb 0x055f 0x0001
/dev/usb/scanner0
option 600cu

La primera línea se ignora. La segunda línea establece el tamaño del búfer a un máximo de 1024 bytes. La tercera línea intenta autodetectar un escáner con el ID del proveedor 0x055f y el ID del producto 0x0001 (Mustek 1200 CU). La cuarta línea indica al backend que se conecte a /dev/usb/scanner0 y la quinta línea especifica que /dev/usb/scanner0 es un Mustek 600 CU.

ARCHIVOS

/etc/sane.d/mustek_usb.conf
El archivo de configuración del backend (consulte también la descripción de SANE_CONFIG_DIR más abajo).
/usr/lib/sane/libsane-mustek_usb.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-mustek_usb.so
La biblioteca compartida que implementa este backend (presente en sistemas que admiten carga dinámica).

ENTORNO

SANE_CONFIG_DIR
Esta variable de entorno especifica la lista de directorios que pueden contener el archivo de configuración. En sistemas *NIX, los directorios están separados por dos puntos (`:'), en OS/2, están separados por un punto y coma (`;'). Si esta variable no está configurada, el archivo de configuración se busca en dos directorios predeterminados: primero, el directorio de trabajo actual (".") y luego en /etc/sane.d. Si el valor de la variable de entorno termina con el carácter separador de directorio, los directorios predeterminados se buscan después de los directorios especificados explícitamente. Por ejemplo, configurar SANE_CONFIG_DIR a "/tmp/config:" daría como resultado la búsqueda de los directorios tmp/config, . y /etc/sane.d (en este orden).
SANE_DEBUG_MUSTEK_USB
Si la biblioteca se compiló con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Niveles de depuración más altos aumentan la verbosidad de la salida. 
Valor  Descripción
0      sin salida
1      imprimir errores fatales
2      imprimir mensajes importantes
3      imprimir errores no fatales y mensajes menos importantes
4      imprimir todos los mensajes excepto los de depuración
5      imprimir mensajes de depuración de alto nivel
6      imprimir mensajes de depuración de nivel medio
7      imprimir mensajes de depuración de bajo nivel

Ejemplo: export SANE_DEBUG_MUSTEK_USB=4

AUTOR

Henning Meier-Geinitz <henning@meier-geinitz.de>
Este backend se basa en el backend Mustek 1200ub de Mustek, mantenido por Tom Wang.

ERRORES

Estos dispositivos tienen un error de hardware: una vez que se les escribe datos, no se pueden restablecer (toggle = DATA0). Eso significa que cualquier operación que intente restablecer el dispositivo resultará en timeouts.

En versiones anteriores, este backend fallaba cuando se cargaba por segunda vez en algunas configuraciones. La única opción era volver a enchufar el escáner en ese caso. El backend ahora utiliza una solución alternativa para ese error, pero solo se ha probado en Linux. Se agradecen informes sobre otros sistemas operativos.

Hay información más detallada sobre errores disponible en la página principal del backend Mustek http://www.meier-geinitz.de/sane/mustek_usb-backend/.
