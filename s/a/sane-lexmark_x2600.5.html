NOMBRE

sane-lexmark_x2600 - backend SANE para escáneres Lexmark X2600 Series

DESCRIPCIÓN

La biblioteca sane-lexmark implementa un backend SANE (Scanner Access Now Easy) que proporciona acceso a la parte del escáner de los AIOs Lexmark X2600.

Los escáneres que deberían funcionar con este backend son:

   Fabricante Modelo           estado
----------------------  -----------
  Lexmark X2670           bueno

Las opciones que soporta el backend se pueden seleccionar a través de opciones de línea de comandos para programas como scanimage(1) o a través de elementos de GUI en xscanimage(1) , xsane(1). o simple-scan(1).
Si nota algún comportamiento extraño, por favor repórtelo al mantenedor del backend o a la lista de correo de SANE.

ARCHIVOS

/usr/lib/sane/libsane-lexmark_x2600.a
La biblioteca estática que implementa este backend.
/usr/lib/sane/libsane-lexmark_x2600.so
La biblioteca compartida que implementa este backend (presente en sistemas que soportan carga dinámica).

ENTORNO

SANE_DEBUG_LEXMARK_X2600
Si la biblioteca fue compilada con soporte de depuración habilitado, esta variable de entorno controla el nivel de depuración para este backend. Por ejemplo, un valor de 255 solicita que se imprima toda la salida de depuración. Niveles más pequeños reducen la verbosidad.
