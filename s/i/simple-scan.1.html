NOMBRE

simple-scan - Utilidad de escaneo

SINOPSIS

simple-scan [DISPOSITIVO]

DESCRIPCIÓN

Esta página de manual documenta brevemente el comando simple-scan.

Document Scanner es una aplicación fácil de usar, diseñada para permitir a los usuarios conectar su escáner y obtener rápidamente la imagen/documento en un formato apropiado.

Document Scanner ha sido escrito con las bibliotecas GTK+, y después de instalar la aplicación, puedes ejecutarla desde el menú Aplicaciones.

OPCIONES

Estos programas siguen la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones. Para una descripción completa, consulte los archivos Info.

-d, --debug
Imprime mensajes de depuración.
-v, --version
Muestra la versión de lanzamiento.
-?, --help
Muestra las opciones de ayuda.
--help-all
Muestra todas las opciones de ayuda.
-d, --help-gtk
Muestra las opciones de GTK+.
