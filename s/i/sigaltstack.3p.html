SIGALTSTACK(3P) Manual de programador POSIX SIGALTSTACK(3P)

PRÓLOGO

Esta página del manual forma parte del Manual de programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sigaltstack — configurar y obtener contexto de pila de señal alternativa

SINOPSIS

#include <signal.h>
int sigaltstack(const stack_t *restrict ss, stack_t *restrict oss);

DESCRIPCIÓN

La función sigaltstack() permite a un proceso definir y examinar el estado de una pila alternativa para manejadores de señales para el hilo actual. Las señales que se han declarado explícitamente para ejecutarse en la pila alternativa se entregarán en la pila alternativa.

Si ss no es un puntero nulo, apunta a una estructura stack_t que especifica la pila de señales alternativa que entrará en vigor al regresar de sigaltstack(). El miembro ss_flags especifica el nuevo estado de la pila. Si se establece en SS_DISABLE, la pila se deshabilita y ss_sp y ss_size se ignoran. De lo contrario, la pila se habilitará y los miembros ss_sp y ss_size especifican la nueva dirección y tamaño de la pila.

El rango de direcciones que comienza en ss_sp hasta, pero sin incluir, ss_sp+ss_size está disponible para la implementación para su uso como pila. Esta función no hace suposiciones respecto a qué extremo es la base de la pila y en qué dirección crece la pila a medida que se empujan elementos.

Si oss no es un puntero nulo, tras una finalización satisfactoria, apuntará a una estructura stack_t que especifica la pila de señales alternativa que estaba en vigor antes de la llamada a sigaltstack(). Los miembros ss_sp y ss_size especifican la dirección y el tamaño de esa pila. El miembro ss_flags especifica el estado de la pila y puede contener uno de los siguientes valores:

SS_ONSTACK
El proceso se está ejecutando actualmente en la pila de señales alternativa. Los intentos de modificar la pila de señales alternativa mientras el proceso se está ejecutando en ella fallan. Los procesos no modificarán esta bandera.
SS_DISABLE
La pila de señales alternativa está actualmente deshabilitada.

El valor SIGSTKSZ es un valor predeterminado del sistema que especifica el número de bytes que se utilizarían para cubrir el caso habitual al asignar manualmente un área de pila alternativa. El valor MINSIGSTKSZ se define como el tamaño mínimo de pila para un manejador de señales. Al calcular un tamaño de pila alternativa, un programa debe agregar esa cantidad a sus requisitos de pila para permitir la sobrecarga de la implementación del sistema. Las constantes SS_ONSTACK, SS_DISABLE, SIGSTKSZ y MINSIGSTKSZ están definidas en <signal.h>.

Después de una llamada satisfactoria a una de las funciones exec, no hay pilas de señales alternativas en la nueva imagen del proceso.

En algunas implementaciones, una señal (ya sea que se indique o no que se ejecute en la pila alternativa) siempre se ejecutará en la pila alternativa si se entrega mientras se está capturando otra señal utilizando la pila alternativa.

El uso de esta función por hilos de biblioteca que no están ligados a entidades programadas por el kernel da como resultado un comportamiento indefinido.

VALOR DE RETORNO

Al finalizar satisfactoriamente, sigaltstack() devolverá 0; de lo contrario, devolverá -1 y establecerá errno para indicar el error.

ERRORES

La función sigaltstack() fallará si:

EINVAL
El argumento ss no es un puntero nulo, y el miembro ss_flags apuntado por ss contiene indicadores distintos de SS_DISABLE.
ENOMEM
El tamaño del área de pila alternativa es menor que MINSIGSTKSZ.
EPERM
Se intentó modificar una pila activa.

EJEMPLOS

Asignación de Memoria para una Pila Alternativa

El siguiente ejemplo ilustra un método para asignar memoria para una pila alternativa.

#include <signal.h>
...
if ((sigstk.ss_sp = malloc(SIGSTKSZ)) == NULL)
    /* Retorno de error. */
sigstk.ss_size = SIGSTKSZ;
sigstk.ss_flags = 0;
if (sigaltstack(&sigstk,(stack_t *)0) < 0)
    perror("sigaltstack");

USO POR LA APLICACIÓN

En algunas implementaciones, el espacio de pila se expande automáticamente según sea necesario. En esas implementaciones, la expansión automática normalmente no está disponible para una pila alternativa. Si la pila se desborda, el comportamiento es indefinido.
