NOMBRE

sierpinski - dibuja fractales de triángulo de Sierpinski

SINOPSIS

sierpinski [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--mono] [--install] [--visual visual] [--ncolors entero] [--delay microsegundos] [--cycles entero] [--count entero]

[--fps]

DESCRIPCIÓN

El programa sierpinski dibuja fractales de triángulo de Sierpinski.

OPCIONES

sierpinski acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Si está en una pantalla en color, finge que está en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--ncolors entero
Cuántos colores se deben usar (si es posible). Por defecto 64. Los colores se eligen al azar.
--cycles entero
--count entero
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

MEDIO AMBIENTE

DISPLAY
para obtener el host y el número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1), xlock(1)
