NOMBRE

sisusb - Controlador de vídeo USB SiS

SINOPSIS

Section "Device"
  Identifier "nombre_disp"
  Driver "sisusb"
  ...
EndSection

DESCRIPCIÓN

sisusb es un controlador de Xorg para chips de vídeo SiS (Silicon Integrated Systems) que están conectados a través de un dongle USB basado en Net2280. El controlador no está acelerado, pero proporciona soporte para profundidades de color de 8, 16 y 24 bpp, así como para Render y otras extensiones.

HARDWARE SOPORTADO

El controlador sisusb soporta tarjetas de vídeo USB basadas en los siguientes chipsets:

SiS315E/PRO

El SiS315E/PRO cuenta con dos controladores CRT. Sin embargo, en su versión USB, solo se utiliza la primera salida, denominada "CRT1".

DETALLES DE CONFIGURACIÓN

Consulte xorg.conf(5) para obtener detalles generales de configuración y sis(4) para más información. Esta página del manual solo cubre un subconjunto de las opciones admitidas.

Se puede obtener información detallada sobre todas las opciones admitidas en http://www.winischhofer.at/linuxsisusbvga.shtml

Tenga en cuenta que este controlador también requiere un controlador de kernel de Linux, que se incluye en Linux 2.6.12 y posteriores, y también está disponible en el sitio web mencionado.

Se admiten las siguientes Opciones del controlador:

Option "HWCursor" "booleano"
Habilita o deshabilita el cursor de hardware. No se recomienda deshabilitar el cursor de hardware, ya que esto aumentará la cantidad de datos transferidos a través de USB. Predeterminado: HWCursor está activado.
Option "SWCursor" "booleano"
Lo opuesto a HWCursor. Esto habilita o deshabilita el cursor de software. Este tipo de cursor es más lento porque el puntero debe ser pintado en la pantalla gráfica. Esto aumenta significativamente la cantidad de datos transferidos a través de USB. Predeterminado: SWCursor está desactivado.
Option "CRT1Gamma" "booleano"
Habilita o deshabilita la corrección gamma. Predeterminado: La corrección gamma está activada.
Option "DisconnectTimeout" "entero"
Esta opción determina cómo reaccionará el controlador ante la desconexión del dispositivo USB. Si el entero proporcionado es -1, el controlador abortará el servidor X inmediatamente tras la desconexión. Si el valor dado es 0, el controlador sondeará para una reconexión cada 2 segundos y, en caso de detectar el dispositivo, restablecerá la pantalla. Si el valor es mayor que 0, el controlador realizará esta reprobación dentro del número dado de segundos y abortará el servidor si no detecta el dispositivo dentro de este tiempo de espera. Predeterminado: 0 (sondear indefinidamente para la reconexión del dispositivo).
