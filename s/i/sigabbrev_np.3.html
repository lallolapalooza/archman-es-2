strsignal(3) Manual de funciones de biblioteca strsignal(3)

NOMBRE

strsignal, sigabbrev_np, sigdescr_np, sys_siglist - devolver una cadena que describe la señal

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <string.h>
char *strsignal(int sig);
const char *sigdescr_np(int sig);
const char *sigabbrev_np(int sig);
[[deprecated]] extern const char *const sys_siglist[];
Requisitos de Feature Test Macro para glibc (ver feature_test_macros(7)):

sigabbrev_np(), sigdescr_np():

    _GNU_SOURCE

strsignal():

    Desde glibc 2.10 hasta glibc 2.31:
        _POSIX_C_SOURCE >= 200809L
    Antes de glibc 2.10:
        _GNU_SOURCE

sys_siglist:

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE

DESCRIPCIÓN

La función strsignal() devuelve una cadena que describe el número de señal pasado en el argumento sig. La cadena solo puede usarse hasta la próxima llamada a strsignal(). La cadena devuelta por strsignal() está localizada según la categoría LC_MESSAGES del entorno local actual.

La función sigdescr_np() devuelve una cadena que describe el número de señal pasado en el argumento sig. A diferencia de strsignal(), esta cadena no se ve influenciada por el entorno local actual.

La función sigabbrev_np() devuelve el nombre abreviado de la señal, sig. Por ejemplo, dado el valor SIGINT, devuelve la cadena "INT".

El array (obsoleto) sys_siglist contiene las cadenas de descripción de señales indexadas por número de señal. Se debe usar la función strsignal() o sigdescr_np() en lugar de este array; ver también VERSIONS.

VALOR DE RETORNO

La función strsignal() devuelve la cadena de descripción apropiada, o un mensaje de señal desconocida si el número de señal es inválido. En algunos sistemas (pero no en Linux), NULL puede devolverse en su lugar para un número de señal inválido.

Las funciones sigdescr_np() y sigabbrev_np() devuelven la cadena de descripción apropiada. La cadena devuelta está asignada estáticamente y es válida durante la vida del programa. Estas funciones devuelven NULL para un número de señal inválido.
