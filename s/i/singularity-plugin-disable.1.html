NOMBRE

apptainer-plugin-disable - deshabilitar un plugin de Apptainer instalado

SINOPSIS

apptainer plugin disable

DESCRIPCIÓN

El comando 'plugin disable' permite a un usuario deshabilitar un plugin que ya está
instalado en el sistema y que ha sido previamente habilitado.

OPCIONES

-h, --help[=false] ayuda para disable

EJEMPLO

  $ apptainer plugin disable example.org/plugin
