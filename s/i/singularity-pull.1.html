NOMBRE

apptainer-pull - Descargar una imagen desde una URI

SINOPSIS

apptainer pull [opciones de descarga...] [archivo de salida]

DESCRIPCIÓN

El comando 'pull' te permite descargar o construir un contenedor desde una
URI dada. Las URIs soportadas incluyen:

library: Descarga una imagen de la biblioteca configurada actualmente
library://usuario/colección/contenedor[:etiqueta]

docker: Descarga una imagen Docker/OCI desde Docker Hub, u otro registro OCI.
docker://usuario/imagen:etiqueta

shub: Descarga una imagen desde Singularity Hub
shub://usuario/imagen:etiqueta

oras: Descarga una imagen SIF desde un registro OCI que soporta ORAS.
oras://registro/espacio-de-nombres/imagen:etiqueta

http, https: Descarga una imagen usando el protocolo http(s?)
https://ejemplo.com/alpine.sif

OPCIONES

--arch="amd64" arquitectura desde la cual descargar de la biblioteca

--arch-variant="" variante de arquitectura a descargar de la biblioteca

--authfile="" archivo de autenticación estilo Docker a usar para escribir/leer credenciales del registro OCI

--dir="" descargar imágenes al directorio específico

--disable-cache[=false] no usar o crear imágenes/blobs en caché

--docker-host="" especificar un host de daemon Docker personalizado

--docker-login[=false] iniciar sesión en un Repositorio Docker interactivamente

-F, --force[=false] sobrescribir un archivo de imagen si existe

-h, --help[=false] ayuda para pull

--library="" descargar imágenes de la biblioteca proporcionada

--no-cleanup[=false] NO limpiar el paquete después de un fallo en la construcción, puede ser útil para depuración

--no-https[=false] usar http en lugar de https para URIs docker://, oras:// y library:///...

--sandbox[=false] descargar imagen en formato sandbox (estructura de directorios chroot)

EJEMPLO

  Desde una biblioteca
  $ apptainer pull alpine.sif library://alpine:latest
  Desde Docker
  $ apptainer pull tensorflow.sif docker://tensorflow/tensorflow:latest
  $ apptainer pull --arch arm --arch-variant 6 alpine.sif docker://alpine:latest
  Desde Shub
  $ apptainer pull apptainer-images.sif shub://vsoch/apptainer-images
  Desde un registro OCI compatible (ej. Azure Container Registry)
  $ apptainer pull image.sif oras://<usuario>.azurecr.io/espacio-de-nombres/imagen:etiqueta
