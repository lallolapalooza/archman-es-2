NOMBRE

signoff - Firmar o revocar paquetes de pruebas de Arch Linux

SINOPSIS

signoff [opciones] [paquete]

DESCRIPCIÓN

Los paquetes en los repositorios de pruebas de Arch Linux pueden ser firmados como completamente funcionales por el Equipo de Pruebas de Arch Linux y, después de una cierta cantidad de firmas, promocionados a los repositorios normales. La herramienta signoff está creada para que el Equipo de Pruebas de Arch Linux pueda firmar paquetes de forma interactiva más fácilmente.

OPCIONES

-s, --signoff paquete

Firma el paquete especificado.

-r, --revoke paquete

Revoca el paquete especificado.

-l, --list

Lista de paquetes que se pueden firmar.

-i, --interactive

Firma paquetes interactivamente.

-u, --uninstalled

Incluye paquetes no instalados al listar.

-a, --signed-off

Incluye paquetes firmados al listar.

-q, --quiet

Menos verboso al listar paquetes.

-b, --db-path <ruta_db>

Ruta de la base de datos de pacman

--username nombre_usuario

Nombre de usuario de ArchWeb.

--password contraseña

Contraseña de ArchWeb.

--noconfirm

No pedir confirmación.

--nocolor

No usar color en la salida.

-h, --help

Muestra este mensaje y sale.

ENTORNO

ARCHWEB_USERNAME

El nombre de usuario de archweb a usar para iniciar sesión en archweb.

ARCHWEB_PASSWORD

La contraseña de archweb a usar para iniciar sesión en archweb.
