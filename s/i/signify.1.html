SIGNIFY(1) Manual de comandos generales SIGNIFY(1)

NOMBRE

signify — firma y verifica archivos criptográficamente

SINOPSIS

signify -C [-q] [-p clave_pub] [-t tipoclave] -x archivo_firma [archivo ...]

signify -G [-n] [-c comentario] -p clave_pub -s clave_sec

signify -S [-enz] [-x archivo_firma] -s clave_sec -m mensaje

signify -V [-eqz] [-p clave_pub] [-t tipoclave] [-x archivo_firma] -m mensaje

DESCRIPCIÓN

La utilidad signify crea y verifica firmas criptográficas. Una firma verifica la integridad de un mensaje. El modo de operación se selecciona con las siguientes opciones:

-C
Verifica una lista de suma de verificación firmada y luego verifica la suma de verificación de cada archivo. Si no se especifican archivos, se verifican todos. archivo_firma debe ser la salida firmada de sha256(1).
-G
Genera un nuevo par de claves. Los nombres de clave deben seguir la convención de nombreclave.pub y nombreclave.sec para las claves pública y secreta, respectivamente.
-S
Firma el archivo de mensaje especificado y crea una firma.
-V
Verifica que el mensaje y la firma coincidan.

Las otras opciones son las siguientes:

-c comentario
Especifica el comentario que se añadirá durante la generación de la clave.
-e
Al firmar, incrusta el mensaje después de la firma. Al verificar, extrae el mensaje de la firma. (Esto requiere que la firma se haya creado usando -e y crea un nuevo archivo de mensaje como salida.)
-m mensaje
Al firmar, el archivo que contiene el mensaje a firmar. Al verificar, el archivo que contiene el mensaje a verificar. Al verificar con -e, el archivo a crear.
-n
Al generar un par de claves, no pide una contraseña. De lo contrario, signify solicitará al usuario una contraseña para proteger la clave secreta. Al firmar con -z, almacena una marca de tiempo cero en la cabecera de gzip(1).
-p clave_pub
Clave pública producida por -G, y utilizada por -V para comprobar una firma.
-q
Modo silencioso. Suprime la salida informativa.
-s clave_sec
Clave secreta (privada) producida por -G, y utilizada por -S para firmar un mensaje.
-t tipoclave
Al deducir la clave correcta para verificar una firma, asegúrate de que la clave real coincida con /etc/signify/*-tipoclave.pub.
-x archivo_firma
El archivo de firma a crear o verificar. El valor predeterminado es mensaje.sig.
-z
Firma y verifica archivos gzip(1), donde los datos de la firma están incrustados en la cabecera de gzip(1).

Los archivos de clave y firma creados por signify tienen el mismo formato. La primera línea del archivo es un comentario de texto libre que puede ser editado, siempre que no supere una sola línea. Los comentarios de firma se generarán basándose en el nombre de la clave secreta utilizada para firmar. Este comentario puede ser luego utilizado como una pista para el nombre de la clave pública al verificar. La segunda línea del archivo es la clave o firma real codificada en base64.

ESTADO DE SALIDA

La utilidad signify sale con 0 en caso de éxito, y >0 si ocurre un error. Puede fallar por una de las siguientes razones:

  • Algunos archivos necesarios no existen.
  • La contraseña introducida es incorrecta.
  • El archivo de mensaje estaba corrupto y su firma no coincide.
  • El archivo de mensaje es demasiado grande.

EJEMPLOS

Crear un nuevo par de claves:

$ signify -G -p newkey.pub -s newkey.sec

Firmar un archivo, especificando un nombre para la firma:

$ signify -S -s key.sec -m message.txt -x msg.sig

Verificar una firma, utilizando el nombre predeterminado de la firma:

$ signify -V -p key.pub -m generalsorders.txt

Verificar un directorio de lanzamiento que contiene SHA256.sig y un conjunto completo de archivos de lanzamiento:

$ signify -C -p /etc/signify/openbsd-76-base.pub -x SHA256.sig

Verificar un bsd.rd antes de una actualización:

$ signify -C -p /etc/signify/openbsd-76-base.pub -x SHA256.sig bsd.rd

Firmar un archivo gzip:

$ signify -Sz -s key-arc.sec -m in.tgz -x out.tgz

Verificar una canalización gzip:

$ ftp url | signify -Vz -t arc | tar ztf -

VER TAMBIÉN
