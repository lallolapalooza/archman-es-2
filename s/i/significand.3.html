significand(3) Manual de funciones de biblioteca significand(3)

NOMBRE

significand, significandf, significandl - obtener la mantisa de un número de punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double significand(double x);
float significandf(float x);
long double significandl(long double x);
Requisitos de Feature Test Macro para glibc (ver feature_test_macros(7)):

significand(), significandf(), significandl():

    /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones devuelven la mantisa de x escalada al rango [1, FLT_RADIX). Son equivalentes a


scalb(x, (double) -ilogb(x))

Esta función existe principalmente para su uso en ciertas pruebas estandarizadas de conformidad con IEEE 754.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
significand (), significandf (), significandl () Seguridad en hilos MT-Safe

ESTÁNDARES
