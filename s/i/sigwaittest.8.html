NOMBRE

sigwaittest - Inicia dos hilos o bifurca dos procesos y mide la latencia entre el envío y la recepción de una señal

SINTAXIS

sigwaittest [-a|--affinity PROC] [-b|--breaktrace USEC] [-d|--distance DIST] [-D|--duration TIME] [-f|--fork [OPT]] [-i|--interval INTV] [--json FILENAME] [-l|--loops LOOPS] [-p|--prio PRIO] [-t|--threads [NUM]]

DESCRIPCIÓN

El programa sigwaittest inicia dos hilos o, opcionalmente, bifurca dos procesos que se sincronizan mediante señales y mide la latencia entre el envío de una señal y el retorno de sigwait().

OPCIONES

-a, --affinity[=PROC]
Ejecutar en el procesador número PROC. Si no se especifica PROC, ejecutar en el procesador actual.
-b, --breaktrace=USEC
Enviar comando de interrupción de rastreo cuando la latencia sea > USEC. Esta es una opción de depuración para controlar el rastreador de latencia en el parche de preemption en tiempo real. Es útil para rastrear latencias inesperadamente grandes de un sistema.
-d, --distance=DIST
Establecer la distancia de los intervalos de los hilos en microsegundos (por defecto es 500 us). Cuando se llama a cyclictest con la opción -t y se crean más de un hilo, este valor de distancia se suma al intervalo de los hilos: Intervalo(hilo N) = Intervalo(hilo N-1) + DIST
-D, --duration=TIME
Especificar una duración para la ejecución de la prueba.
Añadir 'm', 'h', o 'd' para especificar minutos, horas o días.
-f, --fork[=OPT]
En lugar de crear hilos (que es el valor predeterminado), bifurcar nuevos procesos.
-i, --interval=INTV
Establecer el intervalo base del(los) hilo(s) en microsegundos (por defecto es 1000 us). Esto establece el intervalo del primer hilo. Ver también -d.
--json=FILENAME
Escribir los resultados finales en FILENAME, en formato JSON.
-l, --loops=LOOPS
Establecer el número de bucles. El valor predeterminado es 0 (infinito). Esta opción es útil para pruebas automatizadas con un número dado de ciclos de prueba. sigwaittest se detiene una vez que se alcanza el número de intervalos del temporizador.
-p, --prio=PRIO
Establecer la prioridad del proceso.
-t, --threads[=NUM]
Establecer el número de hilos de prueba (por defecto es 1, si no se proporciona esta opción). Si se especifica NUM, crear NUM hilos de prueba. Si no se especifica NUM, NUM se establece en el número de CPUs disponibles.

EJEMPLOS

El siguiente ejemplo se ejecutó en una CPU de 4 vías:

# sigwaittest -a -t -p99 -i100 -d25 -l1000000
#0: ID11510, P99, CPU0, I100; #1: ID11511, P99, CPU0, Cycles 1000000
#2: ID11512, P98, CPU1, I125; #3: ID11513, P98, CPU1, Cycles 817484
#4: ID11514, P97, CPU2, I150; #5: ID11515, P97, CPU2, Cycles 668213
#6: ID11516, P96, CPU3, I175; #7: ID11517, P96, CPU3, Cycles 597344
#1 -> #0, Min    1, Cur    2, Avg    3, Max   30
#3 -> #2, Min    1, Cur   26, Avg    3, Max   42
#5 -> #4, Min    1, Cur   46, Avg    4, Max   67
