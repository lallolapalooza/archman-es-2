sigset(3) Manual de Funciones de Biblioteca sigset(3)

NOMBRE

sigset, sighold, sigrelse, sigignore - API de señales de System V

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <signal.h>
typedef typeof(void (int))  *sighandler_t;
[[deprecated]] sighandler_t sigset(int sig, sighandler_t disp);
[[deprecated]] int sighold(int sig);
[[deprecated]] int sigrelse(int sig);
[[deprecated]] int sigignore(int sig);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

sigset(), sighold(), sigrelse(), sigignore():

    _XOPEN_SOURCE >= 500

DESCRIPCIÓN

Estas funciones se proporcionan en glibc como una interfaz de compatibilidad para programas que utilizan la API de señales histórica de System V. Esta API está obsoleta: las nuevas aplicaciones deben usar la API de señales POSIX (sigaction(2), sigprocmask(2), etc.)

La función sigset() modifica la disposición de la señal sig. El argumento disp puede ser la dirección de una función manejadora de señales o una de las siguientes constantes:

SIG_DFL
Restablece la disposición de sig a la predeterminada.
SIG_IGN
Ignora sig.
SIG_HOLD
Añade sig a la máscara de señales del proceso, pero deja la disposición de sig sin cambios.

Si disp especifica la dirección de un manejador de señales, entonces sig se añade a la máscara de señales del proceso durante la ejecución del manejador.

Si disp se especificó como un valor distinto de SIG_HOLD, entonces sig se elimina de la máscara de señales del proceso.

Las disposiciones para SIGKILL y SIGSTOP no se pueden cambiar.

La función sighold() añade sig a la máscara de señales del proceso que llama.

La función sigrelse() elimina sig de la máscara de señales del proceso que llama.

La función sigignore() establece la disposición de sig en SIG_IGN.

VALOR DE RETORNO

En caso de éxito, sigset() devuelve SIG_HOLD si sig estaba bloqueada antes de la llamada, o la disposición anterior de la señal si no estaba bloqueada antes de la llamada. En caso de error, sigset() devuelve -1, con errno establecido para indicar el error. (Pero ver ERRORES más abajo).

Las funciones sighold(), sigrelse() y sigignore() devuelven 0 en caso de éxito; en caso de error, estas funciones devuelven -1 y establecen errno para indicar el error.

ERRORES

Para sigset() ver los ERRORES bajo sigaction(2) y sigprocmask(2).

Para sighold() y sigrelse() ver los ERRORES bajo sigprocmask(2).

Para sigignore(), ver los errores bajo sigaction(2).

ESTÁNDARES

POSIX.1-2008.

sighandler_t
GNU. POSIX.1 usa el mismo tipo pero sin un typedef.

HISTORIA

glibc 2.1. SVr4, POSIX.1-2001. POSIX.1-2008 marca estas funciones como obsoletas, recomendando el uso de sigaction(2), sigprocmask(2), pthread_sigmask(3) y sigsuspend(2) en su lugar.

NOTAS

La función sigset() proporciona semántica de manejo de señales confiable (como al llamar a sigaction(2) con sa_mask igual a 0).

En System V, la función signal() proporciona semántica no confiable (como al llamar a sigaction(2) con sa_mask igual a SA_RESETHAND | SA_NODEFER). En BSD, signal() proporciona semántica confiable. POSIX.1-2001 deja estos aspectos de signal() sin especificar. Ver signal(2) para más detalles.

Para esperar una señal, BSD y System V proporcionaron una función llamada sigpause(3), pero esta función tiene un argumento diferente en los dos sistemas. Ver sigpause(3) para detalles.

ERRORES CONOCIDOS

Antes de glibc 2.2, sigset() no desbloqueaba sig si disp se especificaba como un valor distinto de SIG_HOLD.

Antes de glibc 2.5, sigset() no devuelve correctamente la disposición anterior de la señal en dos casos. Primero, si disp se especifica como SIG_HOLD, entonces un sigset() exitoso siempre devuelve SIG_HOLD. En su lugar, debería devolver la disposición anterior de la señal (a menos que la señal estuviera bloqueada, en cuyo caso debería devolverse SIG_HOLD). Segundo, si la señal está actualmente bloqueada, entonces el valor de retorno de un sigset() exitoso debe ser SIG_HOLD. En su lugar, se devuelve la disposición anterior de la señal. Estos problemas se han corregido desde glibc 2.5.
