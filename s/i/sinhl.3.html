sinhl(3) Manual de funciones de la biblioteca sinhl(3)

NOMBRE

sinh, sinhf, sinhl - función seno hiperbólico

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double sinh(double x);
float sinhf(float x);
long double sinhl(long double x);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

sinhf(), sinhl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones devuelven el seno hiperbólico de x, que se define matemáticamente como:

    sinh(x) = (exp(x) - exp(-x)) / 2

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el seno hiperbólico de x.

Si x es un NaN, se devuelve un NaN.

Si x es +0 (-0), se devuelve +0 (-0).

Si x es infinito positivo (infinito negativo), se devuelve infinito positivo (infinito negativo).

Si el resultado desborda, ocurre un error de rango y las funciones devuelven HUGE_VAL, HUGE_VALF o HUGE_VALL, respectivamente, con el mismo signo que x.

ERRORES

Consulte math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de rango: desbordamiento del resultado
errno se establece en ERANGE. Se genera una excepción de punto flotante de desbordamiento (FE_OVERFLOW).

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
sinh (), sinhf (), sinhl () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIAL

C99, POSIX.1-2001.

La variante que devuelve double también se ajusta a SVr4, 4.3BSD, C89.

VéASE TAMBIÉN

acosh(3), asinh(3), atanh(3), cosh(3), csinh(3), tanh(3)
