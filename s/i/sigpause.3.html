sigpause(3) Manual de funciones de biblioteca sigpause(3)

NOMBRE

sigpause - libera señales bloqueadas atómicamente y espera una interrupción

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINAPSIS

#include <signal.h>
[[deprecated]] int sigpause(int sigmask);  /* BSD (pero ver VERSIONS) */
[[deprecated]] int sigpause(int sig);      /* POSIX.1 / SysV / UNIX 95 */

DESCRIPCIÓN

No utilice esta función. Utilice sigsuspend(2) en su lugar.

La función sigpause() está diseñada para esperar alguna señal. Cambia la máscara de señales del proceso (conjunto de señales bloqueadas) y luego espera a que llegue una señal. Al llegar una señal, se restaura la máscara de señales original.

VALOR DE RETORNO

Si sigpause() retorna, fue interrumpida por una señal y el valor de retorno es -1 con errno establecido en EINTR.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
sigpause () Seguridad de hilos MT-Safe

VERSIOnES

En Linux, esta rutina es una llamada al sistema solo en la arquitectura Sparc (sparc64).

glibc utiliza la versión BSD si se define la macro de prueba de características _BSD_SOURCE y ninguna de _POSIX_SOURCE, _POSIX_C_SOURCE, _XOPEN_SOURCE, _GNU_SOURCE, o _SVID_SOURCE está definida. De lo contrario, se utiliza la versión System V, y las macros de prueba de características deben definirse de la siguiente manera para obtener la declaración:

•
Desde glibc 2.26: _XOPEN_SOURCE >= 500
•
glibc 2.25 y anteriores: _XOPEN_SOURCE

Desde glibc 2.19, solo la versión System V es expuesta por <signal.h>; las aplicaciones que anteriormente utilizaban la sigpause() de BSD deben modificarse para usar sigsuspend(2).

ESTáNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001. Obsoleto en POSIX.1-2008.

La versión clásica de BSD de esta función apareció en 4.2BSD. Establece la máscara de señales del proceso a sigmask. UNIX 95 estandarizó la versión incompatible de System V de esta función, que elimina solo la señal especificada sig de la máscara de señales del proceso. La desafortunada situación con dos funciones incompatibles con el mismo nombre se resolvió con la función sigsuspend(2), que toma un argumento sigset_t * (en lugar de un int).

VéASE TAMBIÉN

kill(2), sigaction(2), sigprocmask(2), sigsuspend(2), sigblock(3), sigvec(3), feature_test_macros(7)
