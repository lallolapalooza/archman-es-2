STAILQ(3) Manual de Funciones de Biblioteca STAILQ(3)

NOMBRE

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, STAILQ_CONCAT, STAILQ_EMPTY, STAILQ_ENTRY, STAILQ_FIRST, STAILQ_FOREACH, STAILQ_HEAD, STAILQ_HEAD_INITIALIZER, STAILQ_INIT, STAILQ_INSERT_AFTER, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_NEXT, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, - implementación de una cola enlazada simple al final

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TIPO);
STAILQ_HEAD(NOMBRE_CABECERA, TIPO);
STAILQ_HEAD NOMBRE_CABECERA_INICIALIZADOR(STAILQ_HEAD cabecera);
void STAILQ_INIT(STAILQ_HEAD *cabecera);
int STAILQ_EMPTY(STAILQ_HEAD *cabecera);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *cabecera,
                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *cabecera,
                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *cabecera, struct TIPO *elem_lista,
                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);
struct TIPO *STAILQ_FIRST(STAILQ_HEAD *cabecera);
struct TIPO *STAILQ_NEXT(struct TIPO *elem, STAILQ_ENTRY NOMBRE);
STAILQ_FOREACH(struct TIPO *var, STAILQ_HEAD *cabecera, STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE(STAILQ_HEAD *cabecera, struct TIPO *elem, TIPO,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *cabecera,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_CONCAT(STAILQ_HEAD *cabecera1, STAILQ_HEAD *cabecera2);

Nota: Existen macros idénticas prefijadas con SIMPLEQ en lugar de STAILQ; ver VERSIONES.

DESCRIPCIÓN

Estas macros definen y operan sobre colas enlazadas simples al final.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro STAILQ_HEAD().

Creación

Una cola enlazada simple al final está encabezada por una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola al final y otro al último elemento de la cola al final. Los elementos están enlazados simplemente para una mínima sobrecarga de espacio y manipulación de punteros, a costa de una eliminación O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la cola al final después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:


STAILQ_HEAD(NOMBRE_CABECERA, TIPO) cabecera;

donde struct NOMBRE_CABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos que se enlazarán en la cola al final. Posteriormente, se puede declarar un puntero al inicio de la cola al final como:


struct NOMBRE_CABECERA *cabecerp;

(Los nombres cabecera y cabecerp son seleccionables por el usuario).

STAILQ_ENTRY() declara una estructura que conecta los elementos en la cola al final.

STAILQ_HEAD_INITIALIZER() evalúa a un inicializador para la cola cabecera.

STAILQ_INIT() inicializa la cola al final referenciada por cabecera.

STAILQ_EMPTY() evalúa a verdadero si no hay elementos en la cola al final.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elem al principio de la cola al final.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elem al final de la cola al final.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elem_lista.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola al final o NULL si la cola al final está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola al final, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola al final referenciada por cabecera en la dirección hacia adelante, asignando cada elemento en su turno a var.

Eliminación

STAILQ_REMOVE() elimina el elemento elem de la cola al final.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola al final. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola al final deben usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola al final encabezada por cabecera2 al final de la encabezada por cabecera1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía y cero si la cola contiene al menos una entrada.

STAILQ_FIRST() y STAILQ_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la cola cabecera.

VERSIONES

Algunos BSD proporcionan SIMPLEQ en lugar de STAILQ. Son idénticos, pero por razones históricas se llamaron de manera diferente en diferentes BSD. STAILQ se originó en FreeBSD y SIMPLEQ en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticos excepto por una ausencia de equivalente SIMPLEQ para STAILQ_CONCAT().

ERRORES

STAILQ_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

ESTANDARES

BSD.

HISTORIA

4.4BSD.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    STAILQ_ENTRY(entrada) entradas;        /* Cola enlazada simple al final */
};
STAILQ_HEAD(cabeza_simple, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabeza_simple cabeza;                  /* Cola enlazada simple al
                                                     final */
    STAILQ_INIT(&cabeza);                     /* Inicializar la cola */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    STAILQ_INSERT_HEAD(&cabeza, n1, entradas);
    n1 = malloc(sizeof(struct entrada));      /* Insertar al final */
    STAILQ_INSERT_TAIL(&cabeza, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    STAILQ_INSERT_AFTER(&cabeza, n1, n2, entradas);
    STAILQ_REMOVE(&cabeza, n2, entrada, entradas); /* Eliminación */
    free(n2);
    n3 = STAILQ_FIRST(&cabeza);
    STAILQ_REMOVE_HEAD(&cabeza, entradas);     /* Eliminación del principio */
    free(n3);
    n1 = STAILQ_FIRST(&cabeza);
    n1->datos = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entrada));
        STAILQ_INSERT_HEAD(&cabeza, n1, entradas);
        n1->datos = i;
    }

NAME

simpleq - singly linked tail queue

#include <sys/queue.h>

STAILQ_HEAD(name, type);
STAILQ_HEAD_INITIALIZER(head);
STAILQ_INIT(head);
STAILQ_CONCAT(head1, head2);
STAILQ_EMPTY(head);
STAILQ_FIRST(head);
STAILQ_LAST(head, type);
STAILQ_NEXT(elm, field);
STAILQ_PREV(elm, type, field);
STAILQ_REMOVE_HEAD(head, field);
STAILQ_REMOVE_TAIL(head, field);
STAILQ_REMOVE(head, elm, type, field);
STAILQ_INSERT_HEAD(head, elm, field);
STAILQ_INSERT_TAIL(head, elm, field);
STAILQ_INSERT_BEFORE(listelm, elm, field);
STAILQ_INSERT_AFTER(listelm, elm, field);
STAILQ_FOREACH(var, head, field);
STAILQ_FOREACH_SAFE(var, head, field, nextvar);
STAILQ_FOREACH_REVERSE(var, head, type, field);
STAILQ_FOREACH_REVERSE_SAFE(var, head, type, field, nextvar);
STAILQ_SWAP(head1, head2, type);

A singly linked tail queue is a singly linked list which provides efficient O(1) insertion and deletion at both the head and the tail of the list.

A singly linked tail queue is defined by the following macros:

STAILQ_HEAD(name, type)
Declares a structure named name that contains a single pointer to a type structure. This structure will serve as the head of the tail queue. For example, a queue of nodes named my_node_t would be declared as STAILQ_HEAD(my_list_t, my_node_t) my_list;.
STAILQ_HEAD_INITIALIZER(head)
Returns an initializer for an empty tail queue head named head.
STAILQ_INIT(head)
Initializes an empty tail queue head named head.
STAILQ_CONCAT(head1, head2)
Concatenates the tail queue head2 onto the end of the tail queue head1. After the operation, head2 is empty.
STAILQ_EMPTY(head)
Returns true if the tail queue head is empty, false otherwise.
STAILQ_FIRST(head)
Returns a pointer to the first element in the tail queue head, or NULL if the queue is empty.
STAILQ_LAST(head, type)
Returns a pointer to the last element in the tail queue head, or NULL if the queue is empty. The type argument is the structure type used in the tail queue.
STAILQ_NEXT(elm, field)
Returns a pointer to the next element in the tail queue after the element elm. The field argument is the name of the pointer field used in the tail queue.
STAILQ_PREV(elm, type, field)
Returns a pointer to the previous element in the tail queue before the element elm. The type argument is the structure type used in the tail queue, and the field argument is the name of the pointer field used in the tail queue.
STAILQ_REMOVE_HEAD(head, field)
Removes the first element from the tail queue head. The field argument is the name of the pointer field used in the tail queue.
STAILQ_REMOVE_TAIL(head, field)
Removes the last element from the tail queue head. The field argument is the name of the pointer field used in the tail queue.
STAILQ_REMOVE(head, elm, type, field)
Removes the element elm from the tail queue head. The type argument is the structure type used in the tail queue, and the field argument is the name of the pointer field used in the tail queue.
STAILQ_INSERT_HEAD(head, elm, field)
Inserts the element elm at the head of the tail queue head. The field argument is the name of the pointer field used in the tail queue.
STAILQ_INSERT_TAIL(head, elm, field)
Inserts the element elm at the tail of the tail queue head. The field argument is the name of the pointer field used in the tail queue.
STAILQ_INSERT_BEFORE(listelm, elm, field)
Inserts the element elm before the element listelm in the tail queue. The field argument is the name of the pointer field used in the tail queue.
STAILQ_INSERT_AFTER(listelm, elm, field)
Inserts the element elm after the element listelm in the tail queue. The field argument is the name of the pointer field used in the tail queue.
STAILQ_FOREACH(var, head, field)
Iterates over the elements in the tail queue head. The var argument is a pointer to the element, and the field argument is the name of the pointer field used in the tail queue.
STAILQ_FOREACH_SAFE(var, head, field, nextvar)
A safe version of STAILQ_FOREACH that allows elements to be removed during iteration. The nextvar argument is a pointer to hold the next element.
STAILQ_FOREACH_REVERSE(var, head, type, field)
Iterates over the elements in the tail queue head in reverse order. The var argument is a pointer to the element, the type argument is the structure type used in the tail queue, and the field argument is the name of the pointer field used in the tail queue.
STAILQ_FOREACH_REVERSE_SAFE(var, head, type, field, nextvar)
A safe version of STAILQ_FOREACH_REVERSE that allows elements to be removed during iteration. The nextvar argument is a pointer to hold the next element.
STAILQ_SWAP(head1, head2, type)
Swaps the contents of the two tail queues head1 and head2. The type argument is the structure type used in the tail queue.

All elements in a tail queue must be of the same type. Each element must have a field that contains a pointer to the next element in the queue. This field is specified by the field argument in the macros above.

The STAILQ_FIRST, STAILQ_LAST, STAILQ_NEXT, and STAILQ_PREV macros return pointers to elements in the queue, or NULL if the queue is empty or the specified element is not found.

The STAILQ_EMPTY macro returns a non-zero value if the queue is empty, and 0 otherwise.

These macros were first introduced in FreeBSD 3.0.

The STAILQ_PREV macro is O(n) and should be used with caution.

The STAILQ_* macros are inspired by the queue(3) macros found in BSD-derived systems. They are not part of any POSIX or other standard.

The singly linked tail queue implementation first appeared in FreeBSD.

The following example demonstrates how to use a singly linked tail queue:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
    int data;
    STAILQ_ENTRY(node) entries;
};

int
main(void) {
    struct node *np, *n1, *n2;
    STAILQ_HEAD(my_list_t, node) head = STAILQ_HEAD_INITIALIZER(head);

                               /* Insert elements */
    np = malloc(sizeof(struct node));
    np->data = 1;
    STAILQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(struct node));
    np->data = 2;
    STAILQ_INSERT_TAIL(&head, np, entries);

                               /* Forward traversal */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                            /* TailQ deletion */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
