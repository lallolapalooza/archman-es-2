NOMBRE

apptainer-instance-stop - Detiene una instancia con nombre de una imagen de contenedor dada

SINOPSIS

apptainer instance stop [opciones de stop...] [instancia]

DESCRIPCIÓN

El comando apptainer instance stop te permite detener y limpiar una instancia con nombre,
en ejecución, de una imagen de contenedor dada.

OPCIONES

-a, --all[=false] detener todas las instancias del usuario

-F, --force[=false] forzar el cierre de la instancia

-h, --help[=false] ayuda para stop

-s, --signal="" señal enviada a la instancia

-t, --timeout=10 forzar el cierre de las instancias que no se detienen después de X segundos

-u, --user="" si se ejecuta como root, detener las instancias que pertenecen al usuario

EJEMPLO

  $ apptainer instance start my-sql.sif mysql1
  $ apptainer instance start my-sql.sif mysql2
  $ apptainer instance stop mysql*
  Deteniendo la instancia mysql1 de my-sql.sif (PID=23845)
  Deteniendo la instancia mysql2 de my-sql.sif (PID=23858)
  $ apptainer instance start my-sql.sif mysql1
  Forzar el apagado de la instancia
  $ apptainer instance stop -f mysql1 (puede corromper datos)
  Enviar SIGTERM a la instancia
  $ apptainer instance stop -s SIGTERM mysql1
  $ apptainer instance stop -s TERM mysql1
  $ apptainer instance stop -s 15 mysql1
