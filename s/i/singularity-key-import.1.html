NOMBRE

apptainer-key-import - Importar una clave local al keyring local o global

SINOPSIS

apptainer key import [opciones de importación...]

DESCRIPCIÓN

El comando 'key import' te permite añadir una clave a tu keyring local o global
desde un archivo específico.

OPCIONES

-g, --global[=false] gestiona las claves públicas globales (importar/obtener/eliminar están restringidos al usuario root o solo a la instalación sin privilegios)

-h, --help[=false] ayuda para importar

-d, --keysdir="/build/.apptainer/keys" establece la ruta del directorio del keyring local, una forma alternativa es establecer la variable de entorno 'APPTAINER_KEYSDIR'

--new-password[=false] establece una nueva contraseña para la clave privada

EJEMPLO

  $ apptainer key import ./mi-clave.asc
  # Importar al keyring global (solo usuario root)
  $ apptainer key import --global ./mi-clave.asc
