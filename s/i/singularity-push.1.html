NOMBRE

apptainer-push - Sube una imagen al URI proporcionado

SINOPSIS

apptainer push [opciones_push...]

DESCRIPCIÓN

El comando 'push' te permite subir un contenedor SIF a un URI
dado. Los URIs compatibles incluyen:

library:
library://usuario/colección/contenedor[:etiqueta]

oras:
oras://registro/espacio_nombres/imagen:etiqueta

NOTA: Siempre es una buena práctica firmar tus contenedores antes
de subirlos a la biblioteca. Se requiere un token de autenticación para subir a la biblioteca,
así que puede que necesites configurarlo primero con 'apptainer remote'.

OPCIONES

-U, --allow-unsigned[=false] no requerir una imagen de contenedor firmada

--authfile="" archivo de autenticación estilo Docker para usar al escribir/leer credenciales del registro OCI

-D, --description="" descripción para la imagen del contenedor (solo library://)

--docker-host="" especificar un host de demonio Docker personalizado

-h, --help[=false] ayuda para push

--library="" la biblioteca a la que subir

--no-https[=false] usar http en lugar de https para URIs docker://, oras:// y library:///...

EJEMPLO

  A la Biblioteca
  $ apptainer push /home/user/my.sif library://user/collection/my.sif:latest
  A registro OCI compatible
  $ apptainer push /home/user/my.sif oras://registry/namespace/image:tag
