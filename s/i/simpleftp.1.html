NOMBRE

simpleftp - Cliente rudimentario de FTP y HTTP(S)

SINOPSIS

simpleftp url [...]

DESCRIPCIÓN

simpleftp es un script de Perl que proporciona soporte básico para obtener archivos de forma orientada a lotes. Toma una o más URLs FTP o HTTP(S) en la línea de comandos. Los archivos se recuperarán de los servidores FTP o web remotos y se colocarán en el directorio actual con el mismo nombre base que en el remoto; por ejemplo, https://downloads.isc.org/pub/usenet/CONFIG/active.gz se almacena como active.gz en el directorio actual.

El script comprende correctamente nombres de usuario, contraseñas y puertos especificados de la siguiente manera:

ftp://usuario:contraseña@servidor:puerto/ruta/archivo

simpleftp tiene un tiempo de espera codificado de 30 segundos. Utiliza el modo binario y el modo pasivo para las transferencias de datos FTP.

Sale con el estado 0 en caso de éxito. De lo contrario, el estado de salida es el número de transferencias fallidas.

INN solo usa simpleftp cuando ejecuta actsyncd. Si wget (o también ncftpget o ncftp para el único ámbito de FTP) se encuentra en el momento de la configuración, se utilizará en lugar de este script.

ERRORES

simpleftp es un sustituto extremadamente pobre para programas más completos como la utilidad wget disponible gratuitamente, que se recomienda utilizar en su lugar. Fue escrito solo para proporcionar soporte elemental en INN para la obtención no interactiva de archivos en https://downloads.isc.org/pub/pgpcontrol/ o https://downloads.isc.org/pub/usenet/CONFIG/ sin requerir que los administradores instalen otro paquete más. Sus deficiencias como programa de propósito general son demasiadas para mencionarlas, pero una que destaca es que los archivos descargados por simpleftp anulan los archivos existentes con el mismo nombre en el directorio local.

El soporte HTTP requiere el módulo Perl "HTTP::Tiny", instalado solo en Perl 5.14.0 y posteriores como módulo principal de Perl. Además, los módulos Perl "IO::Socket::SSL" y "Net::SSLeay" son necesarios para el soporte HTTPS. En caso de que no estén instalados, simpleftp no puede manejar estos protocolos.

HISTORIA

Creado por David C Lawrence <tale@isc.org> para InterNetNews. Reescribido para usar "HTTP::Tiny" y "Net::FTP" por Julien Elie.
