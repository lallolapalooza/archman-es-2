NOMBRE

apptainer-key-search - Buscar claves en un servidor de claves

SINOPSIS

apptainer key search [opciones de búsqueda...]

DESCRIPCIÓN

El comando 'key search' te permite conectarte a un servidor de claves y buscar
claves públicas que coincidan con el argumento pasado a la línea de comandos. Puedes
buscar por nombre, correo electrónico o huella digital / ID de clave. (Máximo 100 entidades de búsqueda)

OPCIONES

-h, --help[=false] Ayuda para la búsqueda

-l, --long-list[=false] Mostrar lista larga al buscar claves

-u, --url="" Especificar la URL del servidor de claves

EJEMPLO

  $ apptainer key search apptainer.org
  # buscar por huella digital:
  $ apptainer key search 8883491F4268F173C6E5DC49EDECE4F3F38D871E
  # buscar por ID de clave:
  $ apptainer key search F38D871E
