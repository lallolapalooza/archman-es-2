SIXEL2PNG(1) Manual de Comandos Generales SIXEL2PNG(1)

NOMBRE

sixel2png - convierte imágenes DEC SIXEL a formato PNG

SINOPSIS

sixel2png -i <archivo seisel de entrada> -o <archivo png de salida>
img2sixel < <archivo seisel de entrada> > <archivo png de salida>

DESCRIPCIÓN

img2sixel convierte imágenes DEC SIXEL a formato PNG.

OPCIONES DE LÍNEA DE COMANDOS

img2sixel tiene las siguientes opciones de línea de comandos:

-i
Especifica el archivo de entrada. Si se omite o es "-", este comando acepta datos SIXEL desde STDIN.
-o
Especifica el archivo de salida. Si se omite o es "-", este comando emite datos SIXEL a STDOUT.

VER TAMBIÉN

sixel(5) img2sixel(1)

AUTORES

sixel2png es mantenido por Hayaki Saito. Hemos importado todo el código de stbiw-1.01, escrito por Sean Barrett y sus colaboradores, para escribir imágenes PNG.
