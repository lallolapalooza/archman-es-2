sigprocmask(2) Manual de llamadas al sistema sigprocmask(2)

NOMBRE

sigprocmask, rt_sigprocmask - examinar y cambiar señales bloqueadas

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <signal.h>

/* Prototipo de la función wrapper de glibc */
int sigprocmask(int how, const sigset_t *_Nullable restrict set,
                           sigset_t *_Nullable restrict oldset);
#include <signal.h>           /* Definición de constantes SIG_* */
#include <sys/syscall.h>      /* Definición de constantes SYS_* */
#include <unistd.h>
/* Prototipo de la llamada al sistema subyacente */
int syscall(SYS_rt_sigprocmask, int how,
                           const kernel_sigset_t *_Nullable set,
                           kernel_sigset_t *_Nullable oldset,
                           size_t sigsetsize);
/* Prototipo de la llamada al sistema heredada */
[[deprecated]] int syscall(SYS_sigprocmask, int how,
                           const old_kernel_sigset_t *_Nullable set,
                           old_kernel_sigset_t *_Nullable oldset);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

sigprocmask():

    _POSIX_C_SOURCE

DESCRIPCIÓN

sigprocmask() se utiliza para obtener y/o cambiar la máscara de señales del hilo llamante. La máscara de señales es el conjunto de señales cuya entrega está actualmente bloqueada para el llamante (ver también signal(7) para más detalles).

El comportamiento de la llamada depende del valor de how, como sigue.

SIG_BLOCK
El conjunto de señales bloqueadas es la unión del conjunto actual y el argumento set.
SIG_UNBLOCK
Las señales en set se eliminan del conjunto actual de señales bloqueadas. Es permisible intentar desbloquear una señal que no está bloqueada.
SIG_SETMASK
El conjunto de señales bloqueadas se establece en el argumento set.

Si oldset no es NULL, el valor anterior de la máscara de señales se almacena en oldset.

Si set es NULL, entonces la máscara de señales no cambia (es decir, se ignora how), pero el valor actual de la máscara de señales se devuelve de todos modos en oldset (si no es NULL).

Un conjunto de funciones para modificar e inspeccionar variables del tipo sigset_t ("conjuntos de señales") se describe en sigsetops(3).

El uso de sigprocmask() no está especificado en un proceso multihilo; ver pthread_sigmask(3).

VALOR DE RETORNO

sigprocmask() devuelve 0 en caso de éxito. En caso de fallo, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
El argumento set o oldset apunta fuera del espacio de direcciones asignado del proceso.
EINVAL
O bien el valor especificado en how era inválido o el kernel no soporta el tamaño pasado en sigsetsize.

VERSIÓNES

Diferencias entre la biblioteca C y el kernel

La definición del kernel de sigset_t difiere en tamaño de la utilizada por la biblioteca C. En esta página del manual, la primera se denomina kernel_sigset_t (sin embargo, se llama sigset_t en los fuentes del kernel).

La función wrapper de glibc para sigprocmask() ignora silenciosamente los intentos de bloquear las dos señales de tiempo real que se utilizan internamente por la implementación de hilos NPTL. Ver nptl(7) para más detalles.

La llamada al sistema original de Linux se llamaba sigprocmask(). Sin embargo, con la adición de señales de tiempo real en Linux 2.2, el tipo sigset_t de tamaño fijo y 32 bits (denominado old_kernel_sigset_t en esta página del manual) soportado por esa llamada al sistema ya no era adecuado. En consecuencia, se añadió una nueva llamada al sistema, rt_sigprocmask(), para soportar un tipo sigset_t ampliado (denominado kernel_sigset_t en esta página del manual). La nueva llamada al sistema toma un cuarto argumento, size_t sigsetsize, que especifica el tamaño en bytes de los conjuntos de señales en set y oldset. Actualmente, se requiere que este argumento tenga un valor fijo específico de la arquitectura (igual a sizeof(kernel_sigset_t)).

La función wrapper sigprocmask() de glibc oculta estos detalles, llamando de forma transparente a rt_sigprocmask() cuando el kernel la proporciona.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.

NOTAS

No es posible bloquear SIGKILL o SIGSTOP. Los intentos de hacerlo se ignoran silenciosamente.

Cada uno de los hilos de un proceso tiene su propia máscara de señales.

Un hijo creado a través de fork(2) hereda una copia de la máscara de señales de su padre; la máscara de señales se conserva en las llamadas a execve(2).

Si SIGBUS, SIGFPE, SIGILL, o SIGSEGV se generan mientras están bloqueadas, el resultado es indefinido, a menos que la señal haya sido generada por kill(2), sigqueue(3), o raise(3).

Ver sigsetops(3) para detalles sobre la manipulación de conjuntos de señales.

Tenga en cuenta que es permisible (aunque no muy útil) especificar tanto set como oldset como NULL.

VER TAMBIÉN

kill(2), pause(2), sigaction(2), signal(2), sigpending(2), sigsuspend(2), pthread_sigmask(3), sigqueue(3), sigsetops(3), signal(7)

NOMBRE

sigprocmask - manipular la máscara de bloqueo de señales

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <signal.h>

int sigprocmask(int how, const sigset_t *set, sigset_t *oldset);

DESCRIPCIÓN

sigprocmask se utiliza para examinar y/o cambiar la máscara de bloqueo de señales del proceso que realiza la llamada.

La máscara de bloqueo de señales de un proceso especifica el conjunto de señales que están actualmente bloqueadas para ser entregadas a ese proceso.

Los argumentos son:

how
Indica cómo se debe modificar la máscara de bloqueo de señales. Los valores posibles son:
SIG_BLOCK
El conjunto de señales especificado por set se añade al conjunto de señales bloqueadas actualmente.
SIG_UNBLOCK
El conjunto de señales especificado por set se elimina del conjunto de señales bloqueadas actualmente.
SIG_SETMASK
La máscara de bloqueo de señales se establece en el valor especificado por set.

Si oldset no es NULL, la máscara de bloqueo de señales anterior se almacena en la ubicación a la que apunta oldset.

Si set es NULL, la llamada a sigprocmask no modifica la máscara de bloqueo de señales. Esto se puede utilizar para consultar la máscara actual leyendo el valor en oldset.

VALOR DE RETORNO

En caso de éxito, sigprocmask devuelve 0. En caso de error, devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
El valor de how no es válido.

VERSIONES

sigprocmask está disponible en la versión 2.1 de POSIX.1.

ESTANDARES

POSIX.1-2001, POSIX.1-2008, POSIX.1-2017.

HISTORIA

sigprocmask apareció en la versión 2.1 de POSIX.

NOTAS

El conjunto de señales para set se manipula utilizando las funciones sigemptyset, sigfillset, sigaddset, sigdelset y sigismember, que se definen en la página del manual sigsetops(3).

Tenga en cuenta que las señales bloqueadas aún pueden entregarse al proceso cuando se desbloquean. Las señales pendientes que se han desbloqueado se entregarán antes de que una llamada al sistema que fue interrumpida por la señal se reanude.

VER TAMBIEN

kill(2), pause(2), sigaction(2), sigpending(2), sigsuspend(2), sigsetops(3), signal(7).
