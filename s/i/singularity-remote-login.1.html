NOMBRE

apptainer-remote-login - Iniciar sesión en un punto final remoto de apptainer

SINOPSIS

apptainer remote login [opciones de inicio de sesión...]

DESCRIPCIÓN

El comando 'remote login' te permite establecer credenciales para un punto final
específico.

Si no se especifica ningún punto final o registro, el comando iniciará sesión en el punto final
remoto activo actualmente.

OPCIONES

-h, --help[=false] ayuda para iniciar sesión

-i, --insecure[=false] permitir inicio de sesión inseguro

-p, --password="" contraseña / token para autenticarse

--password-stdin[=false] tomar la contraseña de la entrada estándar

--tokenfile="" ruta al archivo que contiene el token de autenticación para iniciar sesión (solo puntos finales remotos)

-u, --username="" nombre de usuario para autenticarse

EJEMPLO

  Para iniciar sesión en un punto final:
  $ apptainer remote login SylabsCloud
