sile(1) Manual de Comandos Generales sile(1)

NOMBRE

sile - El motor de diseño mejorado de Simon

SINOPSIS

sile [opciones] [ENTRADA]

DESCRIPCIÓN

El formateador SILE lee archivos de entrada y formatea el contenido en un formato de documento renderizado, típicamente PDF.

Por defecto, los archivos de entrada pueden estar en marcado SIL declarativo, XML estructurado o Lua programático. El formato de entrada se detecta automáticamente por los módulos activos. Por defecto, la salida será un archivo con el mismo nombre que el primer archivo de entrada con la extensión cambiada a .pdf. El nombre del archivo de salida se puede anular con el argumento --output. Usando --backend se puede cambiar a un formato de salida diferente (o un controlador diferente para el mismo formato). Se pueden manejar entradas o salidas adicionales cargando un módulo de terceros que los soporte agregando el argumento --use en la línea de comandos (que se cargará antes de intentar leer los documentos de entrada).

OPCIONES

-b, --backend=valor
Especifica el backend de salida.
El valor predeterminado es libtexpdf y es adecuado para la mayoría de las salidas PDF. Las alternativas soportadas directamente incluyen text, debug, dummy, cairo y podofo. Otros formateadores pueden habilitarse a través de --use.
-c, --class=valor
Anula la clase de documento predeterminada o especificada.
La clase predeterminada para documentos que no especifican una en la etiqueta raíz es plain. Esto se puede usar para cambiar la clase predeterminada o para anular la clase realmente especificada en un documento. Otras clases incluidas son base, bible, book, diglot, docbook, docbook, jbook, jplain, letter, pecha, tbook, tplain y triglot. Otras se cargarán dinámicamente desde la ruta del módulo.
-d, --debug=valor[,valor]
Muestra información de depuración para aspectos etiquetados de la operación de SILE.
Se pueden proporcionar varias banderas de depuración como una lista separada por comas. Si bien los paquetes pueden definir sus propias banderas de depuración, las más utilizadas son typesetter, pagebuilder, vboxes, break, frames, profile y versions. Se puede especificar varias veces.
-e, --evaluate=valor
Evalúa la expresión Lua antes de procesar la entrada.
Se puede especificar varias veces.
-E, --evaluate-after=valor
Evalúa la expresión Lua después de procesar la entrada.
Se puede especificar varias veces.
-f, --fontmanager=valor
Especifica qué gestor de fuentes usar.
El gestor de fuentes es responsable de descubrir las ubicaciones de los archivos de fuentes en el sistema dada una fuente de nombre. El gestor de fuentes predeterminado es fontconfig en sistemas que no son macOS y macfonts en macOS.
-m, --makedepsarchivo
Genera una lista de dependencias en formato Makefile.
Esto rastrea todos los archivos (archivos de entrada, bibliotecas Lua, fuentes, imágenes, etc.) utilizados durante el proceso de maquetación. Después de la finalización, la lista se escribe en ARCHIVO en formato de lista de dependencias para un objetivo en un Makefile. Esto se puede usar más tarde para determinar si un PDF necesita ser renderizado nuevamente en función de si alguna entrada ha cambiado.
-o, --output=archivo
Establece explícitamente el nombre del archivo de salida.
Por defecto, el nombre base del primer archivo de entrada se usará como el nombre del archivo de salida. Se elegirá una extensión basada en el backend de salida, típicamente .pdf. Con esta opción se puede dar cualquier nombre y ruta arbitraria. Adicionalmente - se puede usar para escribir la salida a STDOUT.
-O, --options=parametro=valor[,parametro=valor]
Establece o anula las opciones de la clase de documento.
Se puede usar para cambiar las opciones predeterminadas o anular las especificadas en un documento. Por ejemplo, establecer --options papersize=letter anularía tanto el papersize predeterminado A4 como cualquiera establecido específicamente en las opciones del documento. Se puede especificar varias veces.
-I, --include=nombrearchivo
Obsoleto, use --use, --preamble, --postamble o múltiples archivos de entrada.
-p, --preamble=nombrearchivo
Incluye el contenido de un archivo SIL, XML u otro recurso antes del contenido del documento de entrada.
El valor debe ser un nombre de archivo completo con una ruta relativa al PWD o una ruta absoluta. Se puede especificar varias veces.
-P, --postamble=nombrearchivo
Incluye el contenido de un archivo SIL, XML u otro recurso después del contenido del documento de entrada.
El valor debe ser un nombre de archivo completo con una ruta relativa al PWD o una ruta absoluta. Se puede especificar varias veces.
-u, --use=modulo[[parametro=valor[,parametro=valor]]]
Carga e inicializa una clase, un lector de entrada, un conformador o otro módulo antes de procesar la entrada principal.
El valor debe ser un nombre de módulo cargable (sin extensión, usando '.' como separador de ruta) y se cargará usando la ruta de búsqueda de módulos de SILE. Se pueden pasar opciones al módulo encerrando pares clave=valor entre corchetes después del nombre del módulo. Esto es particularmente útil cuando el documento de entrada no es SIL o un esquema XML reconocido de forma nativa y SILE necesita ser enseñado trucos nuevos antes incluso de intentar leer el archivo de entrada. Si el módulo es una clase de documento, reemplazará plain como la clase predeterminada para procesar documentos que no especifican explícitamente una para usar. Debido a que esto se ejecuta antes de cargar el documento, puede incluso agregar un analizador de entrada o modificar uno existente para admitir nuevos formatos de archivo. Los módulos de paquete se agregarán al preámbulo para cargarse después de que la clase se inicialice. Se puede especificar varias veces.
-q, --quiet
Suprime advertencias y mensajes informativos durante el procesamiento.
-t, --traceback
Muestra un rastro de ubicación detallado en errores y advertencias.
[ENTRADA]
Nombre(s) de archivo del documento de entrada, por defecto en formatos SIL, XML o Lua.
Uno o más archivos de entrada de los cuales procesar el contenido. El primer archivo listado se considera el documento maestro, los otros se procesan en secuencia. Se pueden habilitar otros formatos de entrada a través de --use. Use - para leer un flujo de contenido desde STDIN.
-h, --help
Imprime el mensaje de ayuda y sale.
-v, --version
Imprime la versión.
