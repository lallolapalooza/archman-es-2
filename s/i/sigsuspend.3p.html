SIGSUSPEND(3P) Manual de Programador de POSIX SIGSUSPEND(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sigsuspend — esperar una señal

SINOPSIS

#include <signal.h>
int sigsuspend(const sigset_t *sigmask);

DESCRIPCIÓN

La función sigsuspend() reemplazará la máscara de señales actual del hilo que llama con el conjunto de señales apuntado por sigmask y luego suspenderá el hilo hasta la entrega de una señal cuya acción sea ejecutar una función de captura de señales o terminar el proceso. Esto no provocará que otras señales que puedan haber estado pendientes en el proceso se conviertan en pendientes para el hilo.

Si la acción es terminar el proceso, sigsuspend() nunca regresará. Si la acción es ejecutar una función de captura de señales, sigsuspend() regresará después de que la función de captura de señales regrese, con la máscara de señales restaurada al conjunto que existía antes de la llamada sigsuspend().

No es posible bloquear señales que no puedan ser ignoradas. Esto es impuesto por el sistema sin indicar un error.

VALOR DE RETORNO

Dado que sigsuspend() suspende la ejecución del hilo indefinidamente, no hay un valor de retorno de finalización exitosa. Si se produce un retorno, se devolverá -1 y errno se establecerá para indicar el error.

ERRORES

La función sigsuspend() fallará si:

EINTR
Una señal es capturada por el proceso que llama y el control regresa desde la función de captura de señales.

USO DE LA APLICACIÓN

Normalmente, al principio de una sección de código crítica, un conjunto especificado de señales se bloquea utilizando la función sigprocmask(). Cuando el hilo ha completado la sección crítica y necesita esperar la(s) señal(es) previamente bloqueada(s), se detiene llamando a sigsuspend() con la máscara que fue devuelta por la llamada sigprocmask().

FUNDAMENTO

El código que desea evitar la ambigüedad de la máscara de señales para los manejadores de cancelación de hilos puede instalar un manejador de cancelación adicional que restablezca la máscara de señales al valor esperado.

void cleanup(void *arg)
{
    sigset_t *ss = (sigset_t *) arg;
    pthread_sigmask(SIG_SETMASK, ss, NULL);
}
int call_sigsuspend(const sigset_t *mask)
{
    sigset_t oldmask;
    int result;
    pthread_sigmask(SIG_SETMASK, NULL, &oldmask);
    pthread_cleanup_push(cleanup, &oldmask);
    result = sigsuspend(sigmask);
    pthread_cleanup_pop(0);
    return result;
}
