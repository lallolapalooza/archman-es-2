SIGHOLD(3P) Manual del Programador POSIX SIGHOLD(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sighold, sigignore, sigpause, sigrelse, sigset — gestión de señales

SINOPSIS

#include <signal.h>
int sighold(int sig);
int sigignore(int sig);
int sigpause(int sig);
int sigrelse(int sig);
void (*sigset(int sig, void (*disp)(int)))(int);

DESCRIPCIÓN

El uso de cualquiera de estas funciones no está especificado en un proceso multihilo.

Las funciones sighold(), sigignore(), sigpause(), sigrelse() y sigset() proporcionan una gestión simplificada de señales.

La función sigset() modificará las disposiciones de las señales. El argumento sig especifica la señal, que puede ser cualquier señal excepto SIGKILL y SIGSTOP. El argumento disp especifica la disposición de la señal, que puede ser SIG_DFL, SIG_IGN, o la dirección de un manejador de señales. Si se utiliza sigset(), y disp es la dirección de un manejador de señales, el sistema añadirá sig a la máscara de señales del proceso llamante antes de ejecutar el manejador de señales; cuando el manejador de señales retorne, el sistema restaurará la máscara de señales del proceso llamante a su estado anterior a la entrega de la señal. Además, si se utiliza sigset(), y disp es igual a SIG_HOLD, sig se añadirá a la máscara de señales del proceso llamante y la disposición de sig permanecerá sin cambios. Si se utiliza sigset(), y disp no es igual a SIG_HOLD, sig se eliminará de la máscara de señales del proceso llamante.

La función sighold() añadirá sig a la máscara de señales del proceso llamante.

La función sigrelse() eliminará sig de la máscara de señales del proceso llamante.

La función sigignore() establecerá la disposición de sig a SIG_IGN.

La función sigpause() eliminará sig de la máscara de señales del proceso llamante y suspenderá el proceso llamante hasta que se reciba una señal. La función sigpause() restaurará la máscara de señales del proceso a su estado original antes de retornar.

Si la acción para la señal SIGCHLD se establece en SIG_IGN, los procesos hijos de los procesos llamantes no se transformarán en procesos zombie cuando terminen. Si el proceso llamante espera posteriormente a sus hijos, y el proceso no tiene hijos no esperados que se hayan transformado en procesos zombie, se bloqueará hasta que todos sus hijos terminen, y wait(), waitid() y waitpid() fallarán y establecerán errno a [ECHILD].

VALOR DE RETORNO

Al completarse con éxito, sigset() retornará SIG_HOLD si la señal había sido bloqueada y la disposición anterior de la señal si no había sido bloqueada. De lo contrario, retornará SIG_ERR y errno se establecerá para indicar el error.

La función sigpause() suspenderá la ejecución del hilo hasta que se reciba una señal, momento en el cual retornará -1 y establecerá errno a [EINTR].

Para todas las demás funciones, al completarse con éxito, se retornará 0. De lo contrario, se retornará -1 y errno se establecerá para indicar el error.

ERRORES

Estas funciones fallarán si:

EINVAL
El argumento sig es un número de señal ilegal.

Las funciones sigset() y sigignore() fallarán si:

EINVAL
Se intenta capturar una señal que no se puede capturar, o ignorar una señal que no se puede ignorar.

USO EN APLICACIONES

La función sigaction() proporciona un mecanismo más completo y fiable para controlar las señales; las nuevas aplicaciones deben utilizar la función sigaction() en lugar de la función obsoleta sigset().

La función sighold(), junto con sigrelse() o sigpause(), puede utilizarse para establecer regiones críticas de código que requieran que la entrega de una señal se posponga temporalmente. Para una mayor portabilidad, se deben utilizar las funciones pthread_sigmask() o sigprocmask() en lugar de las funciones obsoletas sighold() y sigrelse().

Para una mayor portabilidad, se debe utilizar la función sigsuspend() en lugar de la función obsoleta sigpause().

FUNDAMENTO

Cada una de estas funciones históricas tiene un análogo directo en las otras funciones que deben ser por hilo y seguras para hilos (aparte de sigprocmask(), que es reemplazada por pthread_sigmask()). La función sigset() se puede implementar como un simple envoltorio para sigaction(). La función sighold() es equivalente a sigprocmask() o pthread_sigmask() con SIG_BLOCK establecido. La función sigignore() es equivalente a sigaction() con SIG_IGN establecido. La función sigpause() es equivalente a sigsuspend(). La función sigrelse() es equivalente a sigprocmask() o pthread_sigmask() con SIG_UNBLOCK establecido.

DIRECCIONES FUTURAS

Estas funciones pueden ser eliminadas en una versión futura.
