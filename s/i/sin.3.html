sin(3) Manual de Funciones de Biblioteca sin(3)

NOMBRE

sin, sinf, sinl - función seno

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double sin(double x);
float sinf(float x);
long double sinl(long double x);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

sinf(), sinl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones devuelven el seno de x, donde x se da en radianes.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el seno de x.

Si x es un NaN, se devuelve un NaN.

Si x es infinito positivo o infinito negativo, ocurre un error de dominio y se devuelve un NaN.

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es un infinito
errno se establece en EDOM (pero ver BUGS). Se genera una excepción de punto flotante inválida (FE_INVALID).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
sin (), sinf (), sinl () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C99, POSIX.1-2001.

La variante que devuelve double también cumple con SVR4, 4.3BSD, C89.

ERRORES DE PROGRAMACIÓN

Antes de glibc 2.10, la implementación de glibc no establecía errno en EDOM cuando ocurría un error de dominio.

VER TAMBIÉN

acos(3), asin(3), atan(3), atan2(3), cos(3), csin(3), sincos(3), tan(3)
