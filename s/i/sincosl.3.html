sincos(3) Manual de funciones de la biblioteca sincos(3)

NOMBRE

sincos, sincosf, sincosl - calcular seno y coseno simultáneamente

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <math.h>
void sincos(double x, double *sin, double *cos);
void sincosf(float x, float *sin, float *cos);
void sincosl(long double x, long double *sin, long double *cos);

DESCRIPCIÓN

Varias aplicaciones necesitan el seno y el coseno del mismo ángulo x. Estas funciones calculan ambos al mismo tiempo y almacenan los resultados en *sin y *cos. El uso de esta función puede ser más eficiente que dos llamadas separadas a sin(3) y cos(3).

Si x es un NaN, se devuelve un NaN en *sin y *cos.

Si x es infinito positivo o infinito negativo, ocurre un error de dominio y se devuelve un NaN en *sin y *cos.

VALOR DE RETORNO

Estas funciones devuelven void.

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es un infinito
errno se establece en EDOM (pero ver BUGS). Se genera una excepción de punto flotante no válida (FE_INVALID).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
sincos (), sincosf (), sincosl () Seguridad de hilos MT-Safe

ESTANDARES

GNU.

HISTORIA

glibc 2.1.

NOTAS

Para ver la ventaja de rendimiento de sincos(), puede ser necesario deshabilitar las optimizaciones integradas de gcc(1), usando flags como:


cc -O -lm -fno-builtin prog.c

BUGS

Antes de glibc 2.22, la implementación de glibc no establecía errno a EDOM cuando ocurría un error de dominio.

VER TAMBIÉN

cos(3), sin(3), tan(3)
