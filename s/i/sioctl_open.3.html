DESCRIPCIÓN

Los dispositivos de audio pueden exponer un número de controles, como el control de volumen de reproducción. Cada control tiene una dirección entera y un valor entero. Algunos valores son booleanos y solo se pueden cambiar a 0 (apagado) o 1 (encendido). Cualquier control puede ser modificado enviando un nuevo valor a su dirección. Cuando los valores cambian, se envían notificaciones asíncronas.

Las descripciones de los controles están disponibles, lo que permite agruparlos y representarlos de forma legible.

Abrir y cerrar el dispositivo de control

Primero, la aplicación debe llamar a la función sioctl_open() para obtener un manejador que se pasará como argumento hdl a otras funciones.

El parámetro name proporciona la cadena del dispositivo discutida en sndio(7). En la mayoría de los casos, debe establecerse en SIO_DEVANY para permitir que el usuario lo seleccione usando la variable de entorno AUDIODEVICE. El parámetro mode es un mapa de bits de las constantes SIOCTL_READ y SIOCTL_WRITE que indican si los valores de control se pueden leer y modificar respectivamente.

Si el argumento nbio_flag es 1, entonces la función sioctl_setval() (ver más abajo) puede fallar en lugar de bloquearse, y la función sioctl_ondesc() no se bloquea.

La función sioctl_close() cierra el dispositivo de control y libera cualquier recurso asignado asociado con el manejador.

Descripciones de controles

La función sioctl_ondesc() se puede utilizar para obtener la descripción de todos los controles disponibles y sus valores iniciales. Registra una función de devolución de llamada que se invoca inmediatamente para todos los controles. Se llama una vez con un argumento NULL para indicar que se envió la descripción completa y que el llamante tiene una representación coherente del conjunto de controles.

Luego, cada vez que cambie una descripción de control, se invocará la función de devolución de llamada con la información actualizada seguida de una llamada con un argumento NULL.

Los controles se describen mediante la estructura sioctl_desc de la siguiente manera:

struct sioctl_node {
	char name[SIOCTL_NAMEMAX];	/* ej. "spkr" */
	int unit;			/* número opcional o -1 */
};

struct sioctl_desc {
	unsigned int addr;		/* dirección del control */
#define SIOCTL_NONE		0	/* eliminado */
#define SIOCTL_NUM		2	/* entero en el rango maxval */
#define SIOCTL_SW		3	/* interruptor encendido/apagado (1 o 0) */
#define SIOCTL_VEC		4	/* número, elemento de vector */
#define SIOCTL_LIST		5	/* interruptor, elemento de una lista */
#define SIOCTL_SEL		6	/* elemento de un selector */
	unsigned int type;		/* uno de los anteriores */
	char func[SIOCTL_NAMEMAX];	/* nombre de función, ej. "level" */
	char group[SIOCTL_NAMEMAX];	/* grupo al que pertenece este control */
	struct sioctl_node node0;	/* nodo afectado */
	struct sioctl_node node1;	/* dito para SIOCTL_{VEC,LIST,SEL} */
	unsigned int maxval;		/* valor máximo */
	char display[SIOCTL_DISPLAYMAX];	/* pista de formato libre */
};

El atributo addr es la dirección del control, utilizable con sioctl_setval() para establecer su valor.

El atributo type indica qué describe la estructura. Los tipos posibles son:

SIOCTL_NONE
Se eliminó un control previamente válido.
SIOCTL_NUM
Un control entero en el rango de 0 a maxval, inclusive. Por ejemplo, el volumen del altavoz.
SIOCTL_SW
Un control booleano. Por ejemplo, el interruptor para silenciar el altavoz.
SIOCTL_VEC
Elemento de una matriz de controles enteros. Por ejemplo, la perilla para controlar la cantidad de señal que fluye desde la entrada de línea al altavoz.
SIOCTL_LIST
Un elemento de una matriz de interruptores booleanos. Por ejemplo, la posición de entrada de línea del selector de fuente del altavoz.
SIOCTL_SEL
Igual que SIOCTL_LIST pero se selecciona exactamente un elemento a la vez.

El atributo func es el nombre del parámetro que se está controlando. Puede que no haya parámetros de diferentes tipos con el mismo nombre.

Los atributos node0 y node1 indican los nombres de los nodos controlados, típicamente canales de flujos de audio. node1 solo es significativo para SIOCTL_VEC, SIOCTL_LIST y SIOCTL_SEL.

Los nombres en los atributos node0 y node1 y func son cadenas utilizables como identificadores únicos dentro del group dado.

El atributo maxval indica el valor máximo de este control. Para los tipos de control booleanos, se establece en 1.

El atributo display contiene una cadena opcional de formato libre que proporciona pistas adicionales sobre el control, como el modelo de hardware o las unidades.

Interfaz para poll(2)

La función sioctl_pollfd() rellena el array pfd de estructuras pollfd, usadas por poll(2), con events; este último es una máscara de bits de constantes POLLIN y POLLOUT. sioctl_pollfd() devuelve el número de estructuras pollfd rellenadas. La función sioctl_revents() devuelve la máscara de bits establecida por poll(2) en el array pfd de estructuras pollfd. Si se establece POLLOUT, se puede llamar a sioctl_setval() sin bloqueo. Se puede establecer POLLHUP si ocurre un error, incluso si no se selecciona con sioctl_pollfd(). POLLIN aún no se usa.

La función sioctl_nfds() devuelve el número de estructuras pollfd que el llamador debe preasignar para estar seguro de que sioctl_pollfd() nunca desbordará.
