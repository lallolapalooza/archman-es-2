SIG-LIST-TO-CERTS(1) Comandos de usuario SIG-LIST-TO-CERTS(1)

NOMBRE

sig-list-to-certs - herramienta para convertir listas de firmas EFI a certificados openssl

SINOPSIS

sig-list-to-certs <archivo de lista de firmas efi> <nombre base de archivo de certificado>

DESCRIPCIÓN

Toma <archivo de lista de firmas efi> y lo convierte a un conjunto de certificados openssl en formato DER en <nombre base de archivo de certificado>.n (donde n va de 0 al número de certificados en el archivo)

EJEMPLOS

Para ver qué certificados tiene actualmente su sistema UEFI, puede ejecutar el comando dmpstore para imprimirlos en un archivo

dmpstore PK > PK.uc16

Este archivo no es fácilmente legible en un sistema Unix estándar porque está en formato UC-16, así que conviértalo a texto normal

iconv -f utf-16 PK.uc16 > PK.txt

Ahora elimine la cabecera que dice algo como


Dump Variable pk
Variable NV+RT+BS 'Efi:PK' DataSize = 2DA

Dejando solo el volcado hexadecimal. Esto puede ser convertido a una lista de firmas EFI por xxd

xxd -r PK.txt > PK.esl

y ahora puede extraer certificados legibles por openssl de esto

sig-list-to-certs PK.esl PK

Lo que imprimirá alguna información como


X509 Header sls=730, header=0, sig=686
file PK.0: Guid 77fa9abd-0359-4d32-4d60-28f4e78f784b
Written 686 bytes

Y finalmente, puede ver el certificado en formato de texto

openssl x509 -text -inform DER -in PK.0

Suponiendo que es un certificado X509
