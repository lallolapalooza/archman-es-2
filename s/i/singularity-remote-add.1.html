NOMBRE

apptainer-remote-add - Añadir un nuevo punto final remoto de apptainer

SINOPSIS

apptainer remote add [opciones de añadir...]

DESCRIPCIÓN

El comando 'remote add' te permite añadir un nuevo punto final remoto para ser
usado para los servicios remotos de apptainer. La autenticación con un punto final
recién creado se realizará automáticamente.

OPCIONES

-g, --global[=false] editar la lista de puntos finales remotos configurados globalmente

-h, --help[=false] ayuda para añadir

-i, --insecure[=false] permitir la conexión a un punto final http inseguro.

-n, --no-default[=false] no designar el punto final remoto recién añadido como el predeterminado

--no-login[=false] omitir el paso de inicio de sesión automático

--tokenfile="" ruta al archivo que contiene el token de autenticación para el inicio de sesión (solo puntos finales remotos)

EJEMPLO

  $ apptainer remote add EjemploNube cloud.example.com
