NOMBRE

apptainer-plugin-install - Instalar un plugin compilado de Apptainer

SINOPSIS

apptainer plugin install

DESCRIPCIÓN

El comando 'plugin install' instala el plugin compilado encontrado en ruta_del_plugin
en el directorio apropiado del host.

OPCIONES

-h, --help[=false] Ayuda para instalar

EJEMPLO

  $ apptainer plugin install $HOME/apptainer/test-plugin/test-plugin.sif
