NOMBRE

apptainer-capability-add - Añadir capacidades a un usuario o grupo (requiere root)

SINOPSIS

apptainer capability add [opciones de añadir...]

DESCRIPCIÓN

Añade capacidades de Linux a un usuario o grupo. NOTA: Este comando requiere
root para ejecutarse.

El argumento de capacidades debe estar separado por comas y no es sensible a
mayúsculas y minúsculas.

Para ver las capacidades disponibles, escribe "apptainer capability avail" o consulta el
manual de capacidades "man 7 capabilities".

OPCIONES

-g, --group="" gestionar capacidades para un grupo

-h, --help[=false] ayuda para añadir

-u, --user="" gestionar capacidades para un usuario

EJEMPLO

  $ sudo apptainer capability add --user nobody AUDIT_READ,chown
  $ sudo apptainer capability add --group nobody cap_audit_write
  Para añadir todas las capacidades a un usuario:
  $ sudo apptainer capability add --user nobody all
