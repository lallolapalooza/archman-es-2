NOMBRE

sievec - Compilador de scripts Sieve de Pigeonhole

SINOPSIS

sievec [opciones] archivo-script [archivo-salida]

DESCRIPCIÓN


es parte de Pigeonhole (pigeonhole(7)), que añade soporte para Sieve (RFC 5228) y ManageSieve (RFC 5804) a Dovecot (dovecot(1)).


permite compilar scripts Sieve en una representación binaria. El binario resultante puede ser utilizado directamente para procesar mensajes de correo electrónico durante el proceso de entrega. La entrega de mensajes de correo electrónico y, mediante el plugin Sieve de LDA, también la ejecución de scripts Sieve, es realizada por el agente de entrega local (LDA) de Dovecot, llamado dovecot-lda(1).

ya que dovecot-lda(1) lo hará automáticamente si el binario falta. Sin embargo, en algunos casos dovecot-lda(1) no tiene permiso para escribir el binario compilado en disco, obligándolo a recompilar el script cada vez que se ejecuta. Usando la

La implementación Sieve de Pigeonhole reconoce los archivos con extensión .sieve como scripts Sieve y los archivos correspondientes con extensión .svbin como el binario compilado asociado. Esto significa, por ejemplo, que el LDA de Dovecot primero buscará un archivo binario "dovecot.svbin" cuando necesite ejecutar "dovecot.sieve". Compilará un nuevo binario cuando falte o esté desactualizado.


permite generar un volcado textual (y por lo tanto legible por humanos) del código Sieve generado en el archivo especificado. La salida es entonces idéntica a lo que produce el comando sieve-dump(1) para un archivo binario almacenado. Esta salida es principalmente útil para encontrar errores en el compilador que produzcan binarios corruptos.

OPCIONES

-c archivo-config

Ruta alternativa al archivo de configuración de Dovecot.

-d


puede omitirse, lo cual tiene el mismo efecto que '-'. La salida es idéntica a lo que produce el comando sieve-dump(1) para un archivo binario Sieve compilado. Tenga en cuenta que esta opción no está permitida cuando

-D

Habilita la depuración de Sieve.

-o configuración=valor

Sobrescribe la configuración del archivo /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para sobrescribir múltiples configuraciones, la opción -o puede especificarse varias veces.

-u usuario/máscara

Ejecuta el comando solo para el usuario dado. También es posible usar los comodines '*' y '?' (ej. -u *@example.org).

-x auth_info

auth_info especifica condiciones adicionales para el comando user. La cadena de opción auth_info debe darse como un par nombre = valor. Para múltiples condiciones, la opción -x puede proporcionarse varias veces.

Nombres posibles para auth_info son:

service

El servicio para el cual se debe probar la consulta de la base de datos de usuarios. El valor puede ser el nombre de un servicio, comúnmente utilizado con Dovecot. Por ejemplo: imap, pop3 o smtp.

session

Identificador de sesión.

lip

La dirección IP local (servidor) para la prueba.

rip

La dirección IP remota (cliente) para la prueba.

lport

El puerto local, ej. 143

rport

El puerto remoto, ej. 24567

real_lip

La IP local a la que el cliente se conectó en este host.

real_rip

La IP remota desde donde el cliente se conectó a este host.

real_lport

El puerto local al que se conectó el cliente en este host.

real_rport

El puerto remoto desde donde el cliente se conectó a este host.

forward_<campo>

Campo a reenviar como %{forward:campo} al proceso de autenticación.

ARGUMENTOS

archivo-script

Especifica el script a compilar. Si el argumento archivo-script es un directorio, todos los archivos en ese directorio con extensión .sieve se compilarán en un archivo binario .svbin correspondiente. La compilación no se detiene ante errores; intenta compilar tantos scripts en el directorio como sea posible. Tenga en cuenta que la opción -d y el argumento archivo-salida no están permitidos cuando el argumento archivo-script es un directorio.

archivo-salida

Especifica dónde se escribirá la salida (binaria). Este argumento es opcional. Si se omite, un binario compilado desde <nombre-script>.sieve se guarda como <nombre-script>.svbin. Si se omite este argumento y se especifica -b, el volcado binario se enviará a stdout.

ESTADO DE SALIDA

sievec saldrá con uno de los siguientes valores:

0

La compilación fue exitosa. (EX_OK, EXIT_SUCCESS)

1

La operación falló. Se devuelve para casi todos los fallos. (EXIT_FAILURE)

64

Se proporcionó un parámetro inválido. (EX_USAGE)

67

El usuario no existe.

68

No existe el archivo de entrada, la dirección u otro recurso.

73

No se puede crear el archivo de salida.

77

Error de permisos.

78

Error de configuración.

127

Error desconocido.

ARCHIVOS

/etc/dovecot/dovecot.conf

Archivo de configuración principal de Dovecot.

/etc/dovecot/conf.d/90-sieve.conf

Configuración del intérprete Sieve (incluido desde el archivo de configuración principal de Dovecot).

REPORTE DE ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
