NOMBRE

apptainer-keyserver - Gestionar servidores de claves de apptainer

SINOPSIS

apptainer keyserver [opciones de subcomando...]

DESCRIPCIÓN

El comando 'keyserver' te permite gestionar servidores de claves independientes que se usarán para recuperar claves criptográficas.

OPCIONES

-c, --config="/build/.apptainer/remote.yaml" ruta al archivo que contiene las configuraciones del servidor de claves

-h, --help[=false] ayuda para keyserver

EJEMPLO

  Todos los comandos de grupo tienen su propia salida de ayuda:
    $ apptainer help keyserver add
    $ apptainer keyserver add

VEASE TAMBIÉN

apptainer(1), apptainer-keyserver-add(1), apptainer-keyserver-list(1), apptainer-keyserver-login(1), apptainer-keyserver-logout(1), apptainer-keyserver-remove(1)
