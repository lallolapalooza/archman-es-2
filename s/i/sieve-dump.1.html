NOMBRE

sieve-dump - Herramienta de volcado binario de scripts Sieve de Pigeonhole

SINOPSIS

sieve-dump [opciones] archivo-binario-sieve [archivo-salida]

DESCRIPCIÓN


es parte de Pigeonhole (pigeonhole(7)), que añade soporte para Sieve (RFC 5228) y ManageSieve (RFC 5804) a Dovecot (dovecot(1)).


El comando, los binarios de Sieve, que son producidos por ejemplo por sievec(1), pueden ser transformados en una representación textual legible por humanos. Esto puede proporcionar información valiosa sobre cómo se ejecuta el script Sieve. También es particularmente útil para ver binarios corruptos que pueden resultar de errores en la implementación de Sieve. Esta herramienta está destinada principalmente a fines de desarrollo, por lo que normalmente los administradores del sistema y los usuarios no necesitarán usar esta herramienta.

El formato de la salida no se explica aquí en detalle, pero debería ser relativamente fácil de entender. Los binarios de Sieve comprenden un conjunto de bloques de datos, cada uno de los cuales puede contener datos arbitrarios. Para la implementación del lenguaje base se utilizan dos bloques: el primero contiene una especificación de todas las extensiones de lenguaje requeridas y el segundo contiene el programa Sieve principal. Los programas Sieve compilados se representan como código de bytes plano y, por lo tanto, el volcado del programa principal es una lista de desensamblado de las operaciones del intérprete. Las extensiones pueden definir nuevas operaciones y usar bloques adicionales. Por lo tanto, la salida de sieve-dump depende en gran medida de las extensiones de lenguaje utilizadas al compilar el binario.

OPCIONES

-c archivo-config

Ruta alternativa al archivo de configuración de Dovecot.

-D

Habilita la depuración de Sieve.

-h

Produce una salida hexdump por bloque de todo el binario en lugar de la salida normal legible por humanos.

-o configuración=valor

Anula la configuración del archivo /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular múltiples configuraciones, la opción -o puede especificarse varias veces.

-u usuario/máscara

Ejecuta el comando solo para el usuario dado. También es posible usar los comodines '*' y '?' (por ejemplo, -u *@example.org).

-x auth_info

auth_info especifica condiciones adicionales para el comando user. La cadena de opción auth_info debe proporcionarse como un par nombre = valor. Para múltiples condiciones, la opción -x podría proporcionarse varias veces.

Los nombres posibles para auth_info son:

service

El servicio para el cual se debe probar la consulta de la base de datos de usuarios. El valor puede ser el nombre de un servicio, comúnmente utilizado con Dovecot. Por ejemplo: imap, pop3 o smtp.

session

Identificador de sesión.

lip

La dirección IP local (servidor) para la prueba.

rip

La dirección IP remota (cliente) para la prueba.

lport

El puerto local, por ejemplo, 143.

rport

El puerto remoto, por ejemplo, 24567.

real_lip

La IP local a la que el cliente se conectó en este host.

real_rip

La IP remota desde la que se conectó el cliente a este host.

real_lport

El puerto local al que el cliente se conectó en este host.

real_rport

El puerto remoto desde el que se conectó el cliente a este host.

forward_<field>

Campo para reenviar como %{forward:campo} al proceso de autenticación.

ARGUMENTOS

archivo-binario-sieve

Especifica el archivo binario Sieve que necesita ser volcado.

archivo-salida

Especifica dónde debe escribirse la salida. Este argumento es opcional. Si se omite, la salida se escribe en stdout.

ESTADO DE SALIDA

sieve-dump saldrá con uno de los siguientes valores:

0

El volcado fue exitoso. (EX_OK, EXIT_SUCCESS)

1

La operación falló. Esto se devuelve para casi todos los fallos. (EXIT_FAILURE)

64

Se proporcionó un parámetro inválido. (EX_USAGE)

ARCHIVOS

/etc/dovecot/dovecot.conf

Archivo de configuración principal de Dovecot.

/etc/dovecot/conf.d/90-sieve.conf

Configuración del intérprete Sieve (incluido desde el archivo de configuración principal de Dovecot).

REPORTAR ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la Lista de Correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
