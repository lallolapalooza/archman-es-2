NOMBRE

sieve-dump - Herramienta de volcado binario de scripts Sieve de Pigeonhole

SINOPSIS

sieve-dump [opciones] sieve-binary [archivo-salida]

DESCRIPCIÓN


El comando sieve-dump es parte de Pigeonhole (pigeonhole(7)), que añade soporte Sieve (RFC 5228) y ManageSieve (RFC 5804) a Dovecot (dovecot(1)).

Con el comando sieve-dump, los binarios Sieve, que se producen por ejemplo con sievec(1), pueden transformarse en una representación textual legible por humanos. Esto puede proporcionar una visión valiosa de cómo se ejecuta el script Sieve. También es particularmente útil para ver binarios corruptos que pueden resultar de errores en la implementación de Sieve. Esta herramienta está pensada principalmente para fines de desarrollo, por lo que normalmente los administradores de sistemas y los usuarios no necesitarán usarla.

El formato de la salida no se explica aquí en detalle, pero debería ser relativamente fácil de entender. Los binarios Sieve comprenden un conjunto de bloques de datos, cada uno de los cuales puede contener datos arbitrarios. Para la implementación del lenguaje base se utilizan dos bloques: el primero contiene una especificación de todas las extensiones de lenguaje requeridas y el segundo contiene el programa Sieve principal. Los programas Sieve compilados se representan como código de bytes plano y, por lo tanto, el volcado del programa principal es una lista de desensamblado de las operaciones del intérprete. Las extensiones pueden definir nuevas operaciones y utilizar bloques adicionales. Por lo tanto, la salida de sieve-dump depende en gran medida de las extensiones de lenguaje utilizadas al compilar el binario.

OPCIONES

-c archivo-config

Ruta alternativa del archivo de configuración de Dovecot.

-D

Habilita la depuración de Sieve.

-h

Produce una salida hexdump por bloque de todo el binario en lugar de la salida normal legible por humanos.

-o configuracion=valor

Sobrescribe la configuracion del archivo /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para sobrescribir múltiples configuraciones, la opción -o puede especificarse varias veces.

-u usuario/mascara

Ejecuta el comando solo para el usuario dado. También es posible usar los comodines '*' y '?' (por ejemplo, -u *@example.org).

-x info-autenticacion

info-autenticacion especifica condiciones adicionales para el comando user. La cadena de opción info-autenticacion debe proporcionarse como un par nombre = valor. Para múltiples condiciones, la opción -x puede proporcionarse varias veces.

Los nombres posibles para info-autenticacion son:

service

El servicio para el que se debe probar la búsqueda en la base de datos de usuarios. El valor puede ser el nombre de un servicio, comúnmente utilizado con Dovecot. Por ejemplo: imap, pop3 o smtp.

session

Identificador de sesión.

lip

La dirección IP local (servidor) para la prueba.

rip

La dirección IP remota (cliente) para la prueba.

lport

El puerto local, por ejemplo, 143

rport

El puerto remoto, por ejemplo, 24567

real_lip

La IP local a la que el cliente se conectó en este host.

real_rip

La IP remota desde la que el cliente se conectó a este host.

real_lport

El puerto local al que el cliente se conectó en este host.

real_rport

El puerto remoto desde el que el cliente se conectó a este host.

forward_<campo>

Campo a reenviar como %{forward:campo} al proceso de autenticación.

ARGUMENTOS

sieve-binary

Especifica el archivo binario Sieve que necesita ser volcado.

archivo-salida

Especifica dónde se debe escribir la salida. Este argumento es opcional. Si se omite, la salida se escribe en stdout.

ESTADO DE SALIDA

sieve-dump saldrá con uno de los siguientes valores:

0

El volcado fue exitoso. (EX_OK, EXIT_SUCCESS)

1

La operación falló. Se devuelve para casi todos los fallos. (EXIT_FAILURE)

64

Se proporcionó un parámetro inválido. (EX_USAGE)

ARCHIVOS

/etc/dovecot/dovecot.conf

Archivo de configuración principal de Dovecot.

/etc/dovecot/conf.d/90-sieve.conf

Configuración del intérprete Sieve (incluido desde el archivo de configuración principal de Dovecot).

REPORTE DE ERRORES

Informe de errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo informar errores está disponible en: https://dovecot.org/bugreport.html
