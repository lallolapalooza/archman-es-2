NOMBRE

apptainer-instance-list - Listar todas las instancias de Apptainer en ejecución y con nombre

SINOPSIS

apptainer instance list [opciones de lista...] []

DESCRIPCIÓN

El comando instance list te permite ver las instancias de contenedor de Apptainer
que se están ejecutando actualmente en segundo plano.

OPCIONES

-a, --all[=false] mostrar todas las instancias (incluir instancias --sharens)

-h, --help[=false] ayuda para list

-j, --json[=false] imprimir json estructurado en lugar de lista

-l, --logs[=false] mostrar la ubicación de los archivos de registro de stdout y sterr para las instancias

-u, --user="" si se ejecuta como root, listar instancias de ""

EJEMPLO

  $ apptainer instance list
  NOMBRE DE INSTANCIA      PID       IMAGEN
  test               11963     /home/mibauer/apptainer/sinstance/test.sif
  test2              11964     /home/mibauer/apptainer/sinstance/test.sif
  lolcow             11965     /home/mibauer/apptainer/sinstance/lolcow.sif
  $ apptainer instance list 'test*'
  NOMBRE DE INSTANCIA      PID       IMAGEN
  test               11963     /home/mibauer/apptainer/sinstance/test.sif
  test2              11964     /home/mibauer/apptainer/sinstance/test.sif
  $ sudo apptainer instance list -u mibauer
  NOMBRE DE INSTANCIA      PID       IMAGEN
  test               11963     /home/mibauer/apptainer/sinstance/test.sif
  test2              16219     /home/mibauer/apptainer/sinstance/test.sif
