NOMBRE

apptainer-sif-add - Añadir objeto de datos

SINOPSIS

apptainer sif add [flags]

DESCRIPCIÓN

Añade un objeto de datos a una imagen SIF.

OPCIONES

--alignment=0 establece la alineación [por defecto: 4096 con --datatype 4-Partition, 0 en caso contrario]

--datatype=0 el tipo de datos a añadir [NECESARIO, sin valor por defecto]:
1-Deffile, 2-EnvVar, 3-Labels,
4-Partition, 5-Signature, 6-GenericJSON,
7-Generic, 8-CryptoMessage, 9-SBOM,
10-OCI.RootIndex, 11-OCI.Blob

--filename="" establece el nombre de archivo lógico/manejador [por defecto: nombre de archivo de entrada]

--groupid=0 establece el groupid [por defecto: 0]

-h, --help[=false] ayuda para add

--link=0 establece el puntero de enlace [por defecto: 0]

--partarch=0 la arquitectura principal utilizada (con --datatype 4-Partition) [NECESARIO, sin valor por defecto]:
1-386, 2-amd64, 3-arm,
4-arm64, 5-ppc64, 6-ppc64le,
7-mips, 8-mipsle, 9-mips64,
10-mips64le, 11-s390x, 12-riscv64

--partfs=0 el sistema de archivos utilizado (con --datatype 4-Partition) [NECESARIO, sin valor por defecto]:
1-Squash, 2-Ext3, 3-ImmuObj,
4-Raw

--parttype=0 el tipo de partición (con --datatype 4-Partition) [NECESARIO, sin valor por defecto]:
1-System, 2-PrimSys, 3-Data,
4-Overlay

--sbomformat="" el formato SBOM (con --datatype 9-sbom):
cyclonedx-json, cyclonedx-xml, github-json,
spdx-json, spdx-rdf, spdx-tag-value,
spdx-yaml, syft-json

--signentity="" la entidad que firma (con --datatype 5-Signature) [NECESARIO, sin valor por defecto]:
ejemplo: 433FE984155206BD962725E20E8713472A879943

--signhash=0 el hash de firma utilizado (con --datatype 5-Signature) [NECESARIO, sin valor por defecto]:
1-SHA256, 2-SHA384, 3-SHA512,
4-BLAKE2s_256, 5-BLAKE2b_256

EJEMPLO

sif add image.sif recipe.def --datatype 1
sif add image.sif rootfs.squashfs --datatype 4 --parttype 1 --partfs 1 --partarch 2
sif add image.sif signature.bin --datatype 5 --signentity 433FE984155206BD962725E20E8713472A879943 --signhash 1
