NOMBRE

signstar-configure-build - Interfaz de línea de comandos para la configuración de compilación de imágenes de Signstar

SINOPSIS

signstar-configure-build [-c|--config] [-v|--version] [-h|--help]

DESCRIPCIÓN

Interfaz de línea de comandos para la configuración de compilación de imágenes de Signstar

¡NOTA: Este comando debe ejecutarse como root!

Este ejecutable está diseñado para usarse en la configuración de usuarios del sistema relevantes de un sistema Signstar durante la compilación.

Crea usuarios del sistema y su integración basándose en un archivo de configuración central.

Por defecto, se utiliza uno de los siguientes archivos de configuración si existe, en el siguiente orden:

- "/usr/local/share/signstar/config.toml"

- "/run/signstar/config.toml"

- "/etc/signstar/config.toml"

Si ninguno de los anteriores se encuentra, se utiliza la ubicación predeterminada "/usr/share/signstar/config.toml". Alternativamente, se puede especificar una ubicación de archivo de configuración personalizada utilizando la opción "--config"/ "-c".

Los usuarios del sistema, si no existen ya, se crean con la ayuda de `useradd`. Los usuarios se crean sin contraseña y se configuran con un directorio personal debajo de "/var/lib/signstar/home/". Sin embargo, su directorio personal no se crea automáticamente. Las cuentas de usuario del sistema se desbloquean posteriormente con la ayuda de `usermod`. Para cada usuario del sistema, se proporciona una integración de tmpfiles.d debajo de "/usr/lib/tmpfiles.d", para permitir la creación automática de su directorio personal.

Si el archivo de configuración utilizado asocia al usuario del sistema con claves públicas SSH, se crea un archivo dedicado "authorized_keys" que contiene las claves públicas SSH para el usuario debajo de "/etc/ssh/". Además, se crea una configuración de inclusión (drop-in) de "sshd_config" debajo de "/etc/ssh/sshd_config.d/". Esta configuración de inclusión de "sshd_config" fuerza el uso de "authorized_keys" del usuario y el uso de un comando específico (es decir, uno de ["signstar-download-backup", "signstar-download-key-certificate", "signstar-download-metrics", "signstar-download-secret-share", "signstar-download-wireguard", "signstar-sign", "signstar-upload-backup", "signstar-upload-secret-share", "signstar-upload-update"]) dependiendo del rol del usuario.

OPCIONES

-c, --config <CONFIG>
La ruta a un archivo de configuración personalizado.

Si se especifica, se utiliza el archivo de configuración personalizado en lugar de la ubicación predeterminada del archivo de configuración.

Si no se especifica, se utiliza uno de los siguientes archivos de configuración si existe, en el siguiente orden:

- "/usr/local/share/signstar/config.toml"

- "/run/signstar/config.toml"

- "/etc/signstar/config.toml"

Si ninguno de los anteriores se encuentra, se utiliza la ubicación predeterminada "/usr/share/signstar/config.toml".

También se puede especificar con la variable de entorno SIGNSTAR_CONFIG.
-v, --version
Devuelve el nombre y la versión de la aplicación.
-h, --help
Imprime la ayuda (ve un resumen con '-h').
