NOMBRE

signstar-request-signature send - Enviar solicitud de firma sobre SSH

SINOPSIS

signstar-request-signature send <--host> [--port] <--user> <--agent-socket> <--user-public-key> <--known-hosts> [-v|--verbose]... [-q|--quiet]... [-h|--help] <ENTRADA>

DESCRIPCIÓN

Enviar solicitud de firma sobre SSH

OPCIONES

--host <HOST>
Host de Signstar
--port <PORT> [por defecto: 22]
Puerto de Signstar
--user <USUARIO>
Usuario de Signstar
--agent-socket <AGENT_SOCKET>
Ruta al socket del agente utilizado para la autenticación del usuario
--user-public-key <USER_PUBLIC_KEY>
Clave pública de un usuario
--known-hosts <KNOWN_HOSTS>
Ruta a un archivo de hosts conocidos que contiene las claves públicas del servidor
-v, --verbose
Aumentar la verbosidad del registro
-q, --quiet
Disminuir la verbosidad del registro
-h, --help
Imprimir ayuda
<ENTRADA>
La ruta a un archivo que se está firmando
También se puede especificar con la variable de entorno SIGNSTAR_REQUEST_FILE.
