NOMBRE

signset-editor - Editor GUI de Conjuntos de Firma de DNSSEC-Tools

SINOPSIS

signset-editor <archivo-keyrec>

DESCRIPCIÓN

signset-editor proporciona la capacidad de gestionar conjuntos de firma de forma sencilla en una GUI. Un conjunto de firma contiene cero o más nombres de keyrec de claves. Estos conjuntos son utilizados por otras utilidades de DNSSEC-Tools para firmar zonas. Los conjuntos de firma encontrados en el archivo keyrec dado se muestran en una nueva ventana. Se pueden crear nuevos conjuntos de firma y modificar o eliminar conjuntos de firma existentes desde signset-editor.

signset-editor tiene dos modos de visualización. La Vista de Conjuntos de Firma muestra los nombres de todos los keyrec de clave en cada conjunto de firma del archivo keyrec dado. La Vista de Keyrec muestra los nombres de todos los keyrec de clave en el archivo keyrec dado. signset-editor se inicia en modo de Vista de Conjuntos de Firma, pero el modo se puede alternar según sea necesario.

Un alternador adicional controla la visualización de datos adicionales. Si el alternador de Datos Extendidos se activa, la Vista de Conjuntos de Firma muestra los nombres de los keyrec de clave en cada conjunto de firma y la Vista de Keyrec muestra los nombres de cada conjunto de firma en el que se encuentra cada keyrec de clave. Si el alternador de Datos Extendidos se desactiva, la Vista de Conjuntos de Firma solo muestra los nombres de los keyrec de clave en cada conjunto y la Vista de Keyrec solo muestra los nombres de los keyrec de clave.

signset-editor tiene un número reducido de comandos. Todos estos comandos están disponibles a través de los menús, y la mayoría tienen un acelerador de teclado. Los comandos se describen en la siguiente sección.

La gestión de conjuntos de firma puede realizarse utilizando un editor de texto normal. Sin embargo, signset-editor proporciona una bonita GUI que solo manipula conjuntos de firma sin el potencial desorden visual del resto de las entradas keyrec.

DESHACER MODIFICACIONES

signset-editor tiene la capacidad de revertir las modificaciones que ha realizado en un archivo keyrec. Esta restauración histórica solo funcionará para las modificaciones realizadas durante una ejecución particular de signset-editor; las modificaciones realizadas durante una ejecución anterior pueden no ser deshechas.

Al deshacer modificaciones, signset-editor no necesariamente restaura el orden de los nombres dentro del campo signing_set de un keyrec. Sin embargo, los datos del conjunto de firma se mantienen. Esto significa que un archivo keyrec "deshecho" puede no ser exactamente el mismo, byte por byte, que el archivo original, pero se mantiene el significado correcto de los datos.

Después de una operación de "Guardar", los datos necesarios para revertir las modificaciones se eliminan. Este no es el caso de la operación "Guardar como".

OPCIONES

signset-editor acepta las siguientes opciones:

-Version
Muestra la información de la versión de signset-editor y del paquete DNSSEC-Tools.
-help
Muestra un mensaje de uso.

COMANDOS

signset-editor proporciona los siguientes comandos, organizados por menús:

Abrir (menú Archivo)
Abrir un nuevo archivo keyrec. Si el archivo especificado no existe, se le pedirá al usuario que elija una acción. Si el usuario elige la acción "Continuar", entonces signset-editor continuará editando el archivo keyrec actual. Si se selecciona la acción "Salir", entonces signset-editor saldrá.
Guardar (menú Archivo)
Guarda el archivo keyrec actual. Los datos para el comando "Deshacer Cambios" se purgan, por lo que este archivo aparecerá sin modificar.

No ocurrirá nada si no se han realizado cambios.

Guardar como (menú Archivo)
Guarda el archivo keyrec actual con un nombre seleccionado por el usuario.
Salir (menú Archivo)
Sale de signset-editor.
Deshacer Cambios (menú Edición)
Revierte las modificaciones realizadas en los conjuntos de firma y los keyrecs. Esto es solo para la versión en memoria del archivo keyrec.
Nuevo Conjunto de Firma (menú Comandos)
Crea un nuevo conjunto de firma. Se le da al usuario la opción de agregar keyrecs de clave al nuevo conjunto.

Este comando está disponible en ambos modos de visualización.

Eliminar Conjunto de Firma/Clave (menú Comandos)
Elimina el conjunto de firma o la clave seleccionada.

Este comando está disponible en ambos modos de visualización. Si se utiliza desde el modo Vista de Conjuntos de Firma, todas las claves del conjunto de firma seleccionado se eliminarán de ese conjunto. Si se utiliza desde el modo Vista de Keyrec, la clave seleccionada ya no formará parte de ningún conjunto de firma.

Modificar Conjunto de Firma/Clave (menú Comandos)
Modifica el conjunto de firma o la clave seleccionada.

Este comando está disponible en ambos modos de visualización. Si se utiliza desde el modo Vista de Conjuntos de Firma, el conjunto de firma seleccionado puede modificarse agregando claves a ese conjunto o eliminándolas de él. Si se utiliza desde el modo Vista de Keyrec, la clave seleccionada puede agregarse o eliminarse de cualquiera de los conjuntos de firma definidos.

Ver Conjuntos de Firma (menú Visualización)
La ventana principal mostrará los conjuntos de firma del archivo keyrec. Si se van a mostrar Datos Extendidos, entonces también se mostrará cada keyrec de clave en el conjunto de firma. Si no se van a mostrar datos extendidos, solo se mostrarán los nombres de los conjuntos de firma.

Este comando es un alternador que cambia entre el modo Ver Conjuntos de Firma y el modo Ver Keyrecs.

Ver Keyrecs (menú Visualización)
La ventana principal mostrará los nombres de los keyrec de clave del archivo keyrec. Si se van a mostrar Datos Extendidos, entonces también se mostrará el nombre de cada conjunto de firma del keyrec. Si no se van a mostrar datos extendidos, solo se mostrarán los nombres de los keyrec.

Este comando es un alternador que cambia entre el modo Ver Keyrecs y el modo Ver Conjuntos de Firma.

Mostrar Datos Extendidos (menú Visualización)
Se mostrarán datos adicionales en la ventana principal. Para el modo Vista de Conjuntos de Firma, se mostrarán los nombres del conjunto de firma y sus keyrecs de clave constituyentes. Para el modo Vista de Keyrec, se mostrarán los nombres de los keyrecs de clave y los Conjuntos de Firma en los que se encuentra.

Este comando es un alternador que cambia entre la visualización de Datos Extendidos y la no visualización de Datos Extendidos.

No Mostrar Datos Extendidos (menú Visualización)
No se mostrarán datos adicionales en la ventana principal. Para el modo Vista de Conjuntos de Firma, solo se mostrarán los nombres de los Conjuntos de Firma. Para el modo Vista de Keyrec, solo se mostrarán los nombres de los keyrecs.

Este comando es un alternador que cambia entre la no visualización de Datos Extendidos y la visualización de Datos Extendidos.

Ayuda (menú Ayuda)
Muestra una ventana de ayuda.

ACELERADORES DE TECLADO

A continuación se muestran los aceleradores de teclado para los comandos de signset-editor:

Ctrl-D  Eliminar Conjunto de Firma
Ctrl-E  Mostrar Datos Extendidos / No Mostrar Datos Extendidos
Ctrl-H  Ayuda
Ctrl-M  Modificar Conjunto de Firma
Ctrl-N  Nuevo Conjunto de Firma
Ctrl-O  Abrir
Ctrl-Q  Salir
Ctrl-S  Guardar
Ctrl-U  Deshacer Cambios
Ctrl-V  Ver Conjuntos de Firma / Ver Keyrecs
Ctrl-W  Cerrar Ventana (Nuevo Conjunto de Firma, Modificar Conjunto de Firma, Ayuda)

Todos estos aceleradores son letras minúsculas.

signset-editor(1p) — Manual page for signset-editor(1p)

NAME

signset-editor — Edit a set of zone signing configuration and keys

SYNOPSIS

signset-editor [options]

DESCRIPTION

This program is a graphical front-end to the DNSSEC-Tools key-recovery and zone-signing utilities. It allows the user to create and edit zone signing configurations and key-signing keys (KSKs) and zone-signing keys (ZSKs).

The program is written in Perl/Tk.

OPTIONS

No specific command-line options are documented for this version of the program.

COMMANDS

This program is an interactive application. The available commands are accessible through the graphical user interface.

KEYBOARD ACCELERATORS

The following keyboard accelerators are available:

Ctrl-f: Find or filter.

Ctrl-n: Next item.

Ctrl-p: Previous item.

Ctrl-s: Save changes.

Ctrl-o: Open a configuration file.

Ctrl-q: Quit the application.

Ctrl-h: Show help.

REQUIREMENTS

This program requires Perl and the Perl/Tk extension to be installed on your system.
