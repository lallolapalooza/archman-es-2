NOMBRE

apptainer-registry-logout - Cerrar sesión en un registro OCI/Docker

SINOPSIS

apptainer registry logout

DESCRIPCIÓN

El comando 'registry logout' te permite cerrar sesión en un registro OCI/Docker.

OPCIONES

--authfile="" Archivo de autenticación estilo Docker para usar al escribir/leer credenciales de registro OCI

-h, --help[=false] Ayuda para cerrar sesión

EJEMPLO

  Para cerrar sesión en un registro OCI/Docker
  $ apptainer registry logout docker://docker.io
