NOMBRE

apptainer-oci-kill - Detiene un contenedor (solo usuario root)

SINOPSIS

apptainer oci kill [opciones-kill...]

DESCRIPCIÓN

Invoca la operación de eliminación (kill) para detener procesos en ejecución dentro del contenedor identificado por el ID del contenedor.

OPCIONES

-f, --force[=false] detiene el proceso del contenedor con SIGKILL

-h, --help[=false] ayuda para kill

-s, --signal="SIGTERM" señal enviada al contenedor

-t, --timeout=0 tiempo de espera en segundos antes de detener el contenedor

EJEMPLO

  $ apptainer oci kill mi-contenedor INT
  $ apptainer oci kill mi-contenedor -s INT
