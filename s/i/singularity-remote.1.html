NOMBRE

apptainer-remote - Gestionar puntos finales remotos de apptainer

SINOPSIS

apptainer remote [opciones remotas...]

DESCRIPCIÓN

El comando 'remote' te permite gestionar los puntos finales remotos de Apptainer a través de
sus subcomandos.

Un 'punto final remoto' es un grupo de servicios compatible con la
API de la biblioteca de contenedores. El punto final remoto es una única dirección,
por ejemplo, 'cloud.example.com', a través de la cual se descubrirán automáticamente
los servicios de biblioteca y/o almacén de claves.

Para configurar un punto final remoto debes usar 'remote add'. Puedes iniciar sesión con 'remote login' si
realizarás acciones que requieran autenticación. Cambia entre los puntos finales
remotos configurados con el comando 'remote use'. El punto final remoto activo se
utilizará para operaciones clave, y para extraer (pull) y enviar (push) desde
'library://'. También puedes cerrar sesión con 'remote logout' y eliminar con 'remote remove' un punto final que
ya no se requiera.

La configuración remota se almacena en $HOME/.apptainer/remotes.yaml por defecto.

OPCIONES

-c, --config="/build/.apptainer/remote.yaml" ruta al archivo que contiene las configuraciones de los puntos finales remotos

-h, --help[=false] ayuda para remote

EJEMPLO

  Todos los comandos de grupo tienen su propia salida de ayuda:
    $ apptainer help remote list
    $ apptainer remote list
