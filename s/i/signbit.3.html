signbit(3) Manual de funciones de biblioteca signbit(3)

NOMBRE

signbit - comprueba el signo de un número real de punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINAPSIS

#include <math.h>
int signbit(x);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

signbit():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

signbit() es una macro genérica que puede funcionar con todos los tipos de punto flotante reales. Devuelve un valor distinto de cero si el valor de x tiene su bit de signo establecido.

Esto no es lo mismo que x < 0.0, porque el punto flotante IEEE 754 permite que el cero sea con signo. La comparación -0.0 < 0.0 es falsa, pero signbit(-0.0) devolverá un valor distinto de cero.

NaNs e infinitos tienen un bit de signo.

VALOR DE RETORNO

La macro signbit() devuelve un valor distinto de cero si el signo de x es negativo; de lo contrario, devuelve cero.

ERRORES

No ocurren errores.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
signbit () Seguridad de hilos Seguro para hilos (MT-Safe)

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C99.

Esta función está definida en IEC 559 (y en el apéndice con funciones recomendadas en IEEE 754/IEEE 854).
