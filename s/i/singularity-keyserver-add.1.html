NOMBRE

apptainer-keyserver-add - Añadir un servidor de claves (solo usuario root)

SINOPSIS

apptainer keyserver add [opciones] [nombreRemoto]

DESCRIPCIÓN

El comando 'keyserver add' permite al usuario especificar un servidor de claves adicional.
La opción --order especifica el orden del nuevo servidor de claves con respecto a los
servidores de claves que ya se han especificado. Por lo tanto, al especificar
'--order 1', el nuevo servidor de claves se convertirá en el principal. Si no se especifica ningún punto final, el nuevo servidor de claves se asociará con el punto final remoto predeterminado.

OPCIONES

-h, --help[=false] Ayuda para add

-i, --insecure[=false] Permitir conexión insegura al servidor de claves

-o, --order=0 Definir el orden del servidor de claves

EJEMPLO

  $ apptainer keyserver add https://keys.example.com
  Para añadir un servidor de claves que se utilizará como servidor de claves principal para el punto final actual:
  $ apptainer keyserver add --order 1 https://keys.example.com
