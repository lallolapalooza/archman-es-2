NOMBRE

apptainer - plataforma de contenedores de Linux optimizada para Computación de Alto Rendimiento (HPC) y Computación de Rendimiento Empresarial (EPC)

SINOPSIS

apptainer [opciones globales...]

DESCRIPCIÓN

Los contenedores Apptainer proporcionan una capa de virtualización de aplicaciones que permite la movilidad de la computación a través de la portabilidad de aplicaciones y entornos. Con Apptainer, es posible crear un sistema de archivos raíz que se ejecute en cualquier otro sistema Linux donde Apptainer esté instalado.

OPCIONES

--build-config[=false] usa la configuración necesaria para construir contenedores

-c, --config="/etc/apptainer/apptainer.conf" especifica un archivo de configuración (solo para instalación como root o sin privilegios)

-d, --debug[=false] imprime información de depuración (máxima verbosidad)

-h, --help[=false] ayuda para apptainer

--nocolor[=false] imprime sin salida en color (predeterminado Falso)

-q, --quiet[=false] suprime la salida normal

-s, --silent[=false] solo imprime errores

-v, --verbose[=false] imprime información adicional

EJEMPLO

  $ apptainer help <comando> [<subcomando>]
  $ apptainer help build
  $ apptainer help instance start
