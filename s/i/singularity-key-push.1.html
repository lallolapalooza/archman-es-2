NOMBRE

apptainer-key-push - Sube una clave pública a un servidor de claves

SINOPSIS

apptainer key push [opciones de push...]

DESCRIPCIÓN

El comando 'key push' te permite conectarte a un servidor de claves y subir claves
públicas del llavero local o global.

OPCIONES

-g, --global[=false] administrar claves públicas globales (importar/descargar/eliminar están restringidos solo al usuario root o a la instalación no privilegiada)

-h, --help[=false] ayuda para push

-d, --keysdir="/build/.apptainer/keys" establecer la ruta del directorio del llavero local, una forma alternativa es establecer la variable de entorno 'APPTAINER_KEYSDIR'

-u, --url="" especificar la URL del servidor de claves

EJEMPLO

  $ apptainer key push 8883491F4268F173C6E5DC49EDECE4F3F38D871E
