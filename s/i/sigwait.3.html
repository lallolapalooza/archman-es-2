sigwait(3) Manual de funciones de biblioteca sigwait(3)

NOMBRE

sigwait - esperar una señal

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <signal.h>
int sigwait(const sigset_t *restrict set, int *restrict sig);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

sigwait():

    Desde glibc 2.26:
        _POSIX_C_SOURCE >= 199506L
    glibc 2.25 y anteriores:
        _POSIX_C_SOURCE

DESCRIPCIÓN

La función sigwait() suspende la ejecución del hilo llamante hasta que se convierta en pendiente una de las señales especificadas en el conjunto de señales set. Para que una señal se convierta en pendiente, primero debe ser bloqueada con sigprocmask(2). La función acepta la señal (la elimina de la lista de señales pendientes) y devuelve el número de señal en sig.

El funcionamiento de sigwait() es el mismo que el de sigwaitinfo(2), excepto que:

•
sigwait() devuelve solo el número de señal, en lugar de una estructura siginfo_t que describe la señal.
•
Los valores de retorno de las dos funciones son diferentes.

VALOR DE RETORNO

En caso de éxito, sigwait() devuelve 0. En caso de error, devuelve un número de error positivo (listado en ERRORES).

ERRORES

EINVAL
set contiene un número de señal no válido.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
sigwait () Seguridad de hilos MT-Safe

VERSIONES

sigwait() se implementa utilizando sigtimedwait(2); consulte sus NOTAS.

La implementación de glibc de sigwait() ignora silenciosamente los intentos de esperar las dos señales de tiempo real que se utilizan internamente por la implementación de hilos NPTL. Ver nptl(7) para más detalles.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

EJEMPLOS

Ver pthread_sigmask(3).

VER TAMBIÉN
