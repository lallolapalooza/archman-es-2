SIEGE.CONFIG(1) utilidad siege.config SIEGE.CONFIG(1)

NOMBRE

siege.config - construye una plantilla siege.conf en el directorio de inicio del usuario.

INTRODUCCIÓN

siege utiliza los ajustes predeterminados almacenados en $HOME/.siege/siege.conf. Esta utilidad creará un nuevo siege.conf si aún no existe. En general, no deberías tener que ejecutar este comando con versiones de siege iguales o posteriores a la 4.0.0.

Al inicio, siege busca un archivo $HOME/.siege/siege.conf. Si no existe, siege ejecutará este comando para crear uno nuevo y luego leerá ese archivo para configurarse.

INVOCACIÓN

El formato para invocar siege.config es el siguiente:

siege.config [sin argumentos]
