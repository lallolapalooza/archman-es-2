NOMBRE

signaltest - software de prueba de ronda de señales

SINOPSIS

signaltest [ -a|--affinity NUM] [ -b|--backtrace USEC ] [-D|--duration TIME] [-h|--help] [--json FILENAME] [-l|--loops LOOPS ] [-p|--prio PRIO] [-q|--quiet] [-S|--smp] [-t|--threads NUM] [-m|--mlockall ] [-v|--verbose ]

OPCIONES

Estos programas siguen la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones ('--').

-a, --affinity[=PROC-SET]
Ejecutar hilos en el conjunto de procesadores dado por PROC-SET. Si no se especifica PROC-SET, se usarán todos los procesadores. Los hilos se asignarán a los procesadores del conjunto en orden numérico, de forma cíclica.
El conjunto de procesadores puede especificarse como A,B,C, o A-C, o A-B,D-F, y así sucesivamente*. El carácter ! se puede usar para negar un conjunto. Por ejemplo, !B-D significa usar todas las CPUs disponibles excepto B a D. Los números de CPU son los mismos que se muestran en el campo processor de /proc/cpuinfo. Consulte numa(3) para obtener más información sobre cómo especificar conjuntos de CPU. * El soporte para conjuntos de CPU requiere la versión de libnuma >= 2. Para libnuma v1, PROC-SET, si se especifica, debe ser un único número de CPU.
-b, --breaktrace=USEC
Enviar comando de interrupción de rastreo cuando la latencia sea > USEC
-D, --duration=TIME
Especificar una duración para la ejecución de la prueba.
Añada 'm', 'h', o 'd' para especificar minutos, horas o días.
--help

mostrar información de uso
--json=FILENAME
Escribir los resultados finales en FILENAME, en formato JSON.
-l, --loops=LOOPS
Número de bucles: por defecto=0 (infinito)
-p, --priority=PRIO
Prioridad del hilo de mayor prioridad
-q, --quiet
imprimir solo un resumen al salir
-S, --smp
Establecer opciones para pruebas estándar en sistemas SMP. Equivalente a usar las opciones: "-t -a", manteniendo también cualquier prioridad especificada igual en todos los hilos
-t, --threads=NUM
número de hilos: por defecto=2
-m, --mlockall
bloquear la memoria actual y futura
-v, --verbose
mostrar valores en stdout para estadísticas
formato: n:c:v n=número de tarea c=conteo v=valor en us
