sigtrap(3perl) Guía del programador de Perl sigtrap(3perl)

NOMBRE

sigtrap - Pragma de Perl para habilitar el manejo simple de señales

SINOPSIS

use sigtrap;
use sigtrap qw(stack-trace old-interface-signals);  # equivalente
use sigtrap qw(BUS SEGV PIPE ABRT);
use sigtrap qw(die INT QUIT);
use sigtrap qw(die normal-signals);
use sigtrap qw(die untrapped normal-signals);
use sigtrap qw(die untrapped normal-signals
                stack-trace any error-signals);
use sigtrap 'handler' => \&mi_manejador, 'normal-signals';
use sigtrap qw(handler mi_manejador normal-signals
                stack-trace error-signals);

DESCRIPCIÓN

El pragma sigtrap es una interfaz simple para instalar manejadores de señales. Puede hacer que instale uno de los dos manejadores proporcionados por el propio sigtrap (uno que proporciona un rastreo de pila de Perl y otro que simplemente hace die()), o alternativamente puede proporcionar su propio manejador para que lo instale. Se le puede indicar que solo instale un manejador para señales que no estén atrapadas o que estén ignoradas. Tiene tres listas de señales para atrapar, además de que puede proporcionar su propia lista de señales.

Los argumentos pasados a la declaración "use" que invoca a sigtrap se procesan en orden. Cuando se encuentra un nombre de señal o el nombre de una de las listas de señales de sigtrap, se instala un manejador inmediatamente; cuando se encuentra una opción, afecta a los manejadores instalados posteriormente.

OPCIONES

MANEJADORES DE SEÑALES

Estas opciones afectan qué manejador se utilizará para las señales instaladas posteriormente.

stack-trace
El manejador utilizado para las señales instaladas posteriormente emite un rastreo de pila de Perl a STDERR e intenta volcar el núcleo. Este es el manejador de señales predeterminado.
die
El manejador utilizado para las señales instaladas posteriormente llama a "die" (en realidad, a "croak") con un mensaje que indica qué señal fue capturada.
handler tu-manejador
tu-manejador se utilizará como manejador para las señales instaladas posteriormente. tu-manejador puede ser cualquier valor válido para una asignación a un elemento de %SIG. Consulte perlvar para ver ejemplos de funciones manejadoras.

LISTAS DE SEÑALES

sigtrap tiene algunas listas integradas de señales para atrapar. Son:

normal-signals
Estas son las señales que un programa podría esperar encontrar normalmente y que por defecto hacen que termine. Son HUP, INT, PIPE y TERM.
error-signals
Estas señales generalmente indican un problema grave con el intérprete de Perl o con su script. Son ABRT, BUS, EMT, FPE, ILL, QUIT, SEGV, SYS y TRAP.
old-interface-signals
Estas son las señales que eran atrapadas por defecto por la antigua interfaz de sigtrap; son ABRT, BUS, EMT, FPE, ILL, PIPE, QUIT, SEGV, SYS, TERM y TRAP. Si no se pasan señales o listas de señales a sigtrap, se utiliza esta lista.

Para cada una de estas tres listas, la colección de señales configuradas para ser atrapadas se verifica antes de atraparlas; si su arquitectura no implementa una señal particular, no será atrapada sino silenciosamente ignorada.

OTRAS

untrapped
Este token le indica a sigtrap que instale manejadores solo para las señales listadas posteriormente que no estén ya atrapadas o ignoradas.
any
Este token le indica a sigtrap que instale manejadores para todas las señales listadas posteriormente. Este es el comportamiento predeterminado.
señal
Cualquier argumento que parezca un nombre de señal (es decir, "/^[A-Z][A-Z0-9]*$/") indica que sigtrap debe instalar un manejador para ese nombre.
número
Requiere que se esté utilizando al menos la versión número de sigtrap.

EJEMPLOS

Proporcionar un rastreo de pila para las `old-interface-signals`:

use sigtrap;

Lo mismo:

use sigtrap qw(stack-trace old-interface-signals);

Proporcionar un rastreo de pila solo en las 4 señales listadas:

use sigtrap qw(BUS SEGV PIPE ABRT);

Morir en INT o QUIT:

use sigtrap qw(die INT QUIT);

Morir en HUP, INT, PIPE o TERM:

use sigtrap qw(die normal-signals);

Morir en HUP, INT, PIPE o TERM, sin cambiar el comportamiento de las señales que ya están atrapadas o ignoradas:

use sigtrap qw(die untrapped normal-signals);

Morir al recibir cualquiera de las `normal-signals` que actualmente no esté atrapada (`untrapped`), proporcionar un rastreo de pila al recibir cualquiera de las `error-signals`:

use sigtrap qw(die untrapped normal-signals
                stack-trace any error-signals);

Instalar `mi_manejador()` como el manejador para las `normal-signals`:

use sigtrap 'handler', \&mi_manejador, 'normal-signals';

Instalar `mi_manejador()` como el manejador para las `normal-signals`, proporcionar un rastreo de pila de Perl al recibir una de las `error-signals`:

use sigtrap qw(handler mi_manejador normal-signals
                stack-trace error-signals);
