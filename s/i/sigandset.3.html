SIGSETOPS(3) Manual de Funciones de Biblioteca SIGSETOPS(3)

NOMBRE

sigemptyset, sigfillset, sigaddset, sigdelset, sigismember - operaciones de conjuntos de señales POSIX

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <signal.h>
int sigemptyset(sigset_t *set);
int sigfillset(sigset_t *set);
int sigaddset(sigset_t *set, int signum);
int sigdelset(sigset_t *set, int signum);
int sigismember(const sigset_t *set, int signum);
Requisitos de Macros de Prueba de Funciones para glibc (ver feature_test_macros(7)):

sigemptyset(), sigfillset(), sigaddset(), sigdelset(), sigismember():

    _POSIX_C_SOURCE

DESCRIPCIÓN

Estas funciones permiten la manipulación de conjuntos de señales POSIX.

sigemptyset() inicializa el conjunto de señales dado por set a vacío, excluyendo todas las señales del conjunto.

sigfillset() inicializa set a completo, incluyendo todas las señales.

sigaddset() y sigdelset() añaden y eliminan, respectivamente, la señal signum de set.

sigismember() comprueba si signum es miembro de set.

Los objetos de tipo sigset_t deben inicializarse mediante una llamada a sigemptyset() o sigfillset() antes de ser pasados a las funciones sigaddset(), sigdelset() y sigismember() o a las funciones adicionales de glibc descritas a continuación (sigisemptyset(), sigandset() y sigorset()). Los resultados no están definidos si esto no se hace.

VALOR DE RETORNO

sigemptyset(), sigfillset(), sigaddset(), y sigdelset() devuelven 0 en caso de éxito y -1 en caso de error.

sigismember() devuelve 1 si signum es miembro de set, 0 si signum no es miembro, y -1 en caso de error.

En caso de error, estas funciones establecen errno para indicar el error.

ERRORES

EINVAL
signum no es una señal válida.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
sigemptyset (), sigfillset (), sigaddset (), sigdelset (), sigismember (), sigisemptyset (), sigorset (), sigandset () Seguridad en hilos MT-Safe

VERSIONES

GNU

Si se define la macro de prueba de función _GNU_SOURCE, entonces <signal.h> expone tres funciones más para manipular conjuntos de señales:

int sigisemptyset(const sigset_t *set);
int sigorset(sigset_t *dest, const sigset_t *left,
              const sigset_t *right);
int sigandset(sigset_t *dest, const sigset_t *left,
              const sigset_t *right);

sigisemptyset() devuelve 1 si set no contiene ninguna señal, y 0 en caso contrario.

sigorset() coloca la unión de los conjuntos left y right en dest. sigandset() coloca la intersección de los conjuntos left y right en dest. Ambas funciones devuelven 0 en caso de éxito y -1 en caso de fallo.

Estas funciones no son estándar (algunos otros sistemas proporcionan funciones similares) y su uso debe evitarse en aplicaciones portátiles.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

NOTAS

Al crear un conjunto de señales completo, la función sigfillset() de glibc no incluye las dos señales de tiempo real utilizadas internamente por la implementación de hilos NPTL. Ver nptl(7) para más detalles.

VER TAMBIÉN

sigaction(2), sigpending(2), sigprocmask(2), sigsuspend(2)
