sigqueue(3) Manual de funciones de biblioteca sigqueue(3)

NOMBRE

sigqueue - pone en cola una señal y datos a un proceso

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <signal.h>
int sigqueue(pid_t pid, int sig, const union sigval value);
Requisitos de macro de prueba de características para glibc (consulte feature_test_macros(7)):

sigqueue():

    _POSIX_C_SOURCE >= 199309L

DESCRIPCIÓN

sigqueue() envía la señal especificada en sig al proceso cuyo PID se indica en pid. Los permisos requeridos para enviar una señal son los mismos que para kill(2). Al igual que con kill(2), la señal nula (0) se puede usar para verificar si existe un proceso con un PID dado.

El argumento value se utiliza para especificar un elemento de datos adjunto (ya sea un entero o un valor de puntero) que se enviará con la señal, y tiene el siguiente tipo:


union sigval {
    int   sival_int;
    void *sival_ptr;
};

Si el proceso receptor ha instalado un manejador para esta señal utilizando la bandera SA_SIGINFO en sigaction(2), entonces puede obtener estos datos a través del campo si_value de la estructura siginfo_t que se pasa como segundo argumento al manejador. Además, el campo si_code de esa estructura se establecerá en SI_QUEUE.

VALOR DE RETORNO

En caso de éxito, sigqueue() devuelve 0, lo que indica que la señal se puso en cola correctamente para el proceso receptor. De lo contrario, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EAGAIN
Se ha alcanzado el límite de señales que se pueden poner en cola. (Consulte signal(7) para obtener más información).
EINVAL
sig no era válido.
EPERM
El proceso no tiene permiso para enviar la señal al proceso receptor. Para los permisos requeridos, consulte kill(2).
ESRCH
Ningún proceso tiene un PID que coincida con pid.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
sigqueue () Seguridad de hilos MT-Safe

VERSIOnES

Diferencias entre la biblioteca C y el núcleo

En Linux, sigqueue() se implementa utilizando la llamada al sistema rt_sigqueueinfo(2). La llamada al sistema difiere en su tercer argumento, que es la estructura siginfo_t que se proporcionará al manejador de señales del proceso receptor o que devolverá la llamada sigtimedwait(2) del proceso receptor. Dentro de la envoltura sigqueue() de glibc, este argumento, uinfo, se inicializa de la siguiente manera:


uinfo.si_signo = sig;      /* Argumento proporcionado a sigqueue() */
uinfo.si_code = SI_QUEUE;
uinfo.si_pid = getpid();   /* ID del proceso remitente */
uinfo.si_uid = getuid();   /* UID real del remitente */
uinfo.si_value = val;      /* Argumento proporcionado a sigqueue() */

ESTáNDARES

POSIX.1-2008.

HISTORIA

Linux 2.2. POSIX.1-2001.

NOTAS

Si esta función resulta en el envío de una señal al proceso que la invocó, y esa señal no fue bloqueada por el hilo que la invocó, y ningún otro hilo estaba dispuesto a manejar esta señal (ya sea desbloqueándola o esperando por ella usando sigwait(3)), entonces se debe entregar al menos una señal a este hilo antes de que esta función devuelva.

VéASE TAMBIÉN

kill(2), rt_sigqueueinfo(2), sigaction(2), signal(2), pthread_sigqueue(3), sigwait(3), signal(7)
