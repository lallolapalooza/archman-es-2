PROLOG

Esta página del manual es parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sigdelset — eliminar una señal de un conjunto de señales

SINOPSIS

#include <signal.h>
int sigdelset(sigset_t *set, int signo);

DESCRIPCIÓN

La función sigdelset() elimina la señal individual especificada por signo del conjunto de señales apuntado por set.

Las aplicaciones deben llamar a sigemptyset() o sigfillset() al menos una vez para cada objeto de tipo sigset_t antes de cualquier otro uso de dicho objeto. Si dicho objeto no se inicializa de esta manera, pero aun así se proporciona como argumento a cualquiera de pthread_sigmask(), sigaction(), sigaddset(), sigdelset(), sigismember(), sigpending(), sigprocmask(), sigsuspend(), sigtimedwait(), sigwait(), o sigwaitinfo(), los resultados no están definidos.

VALOR DE RETORNO

Al completarse con éxito, sigdelset() devolverá 0; de lo contrario, devolverá -1 y establecerá errno para indicar el error.

ERRORES

La función sigdelset() puede fallar si:

EINVAL
El argumento signo no es un número de señal válido, o es un número de señal no soportado.
