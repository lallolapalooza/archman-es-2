NOMBRE

apptainer-inspect - Muestra metadatos de una imagen

SINOPSIS

apptainer inspect [opciones de inspect...]

DESCRIPCIÓN

Inspect le mostrará las etiquetas, variables de entorno, aplicaciones y scripts asociados
con la imagen determinada por las banderas que pase. Por defecto, se mostrarán en
texto plano. Si desea listarlos en formato json, debe usar la bandera --json.

OPCIONES

--all[=false] muestra todos los datos disponibles (implica la opción --json)

--app="" inspecciona una aplicación específica

-d, --deffile[=false] muestra el archivo de definición de Apptainer que se utilizó para generar la imagen

-e, --environment[=false] muestra la configuración del entorno para la imagen

-h, --help[=false] ayuda para inspect

-H, --helpfile[=false] inspecciona el archivo de ayuda del script de ejecución, si existe

-j, --json[=false] imprime json estructurado en lugar de secciones

-l, --labels[=false] muestra las etiquetas de la imagen (por defecto)

--list-apps[=false] lista todas las aplicaciones en un contenedor

-r, --runscript[=false] muestra el script de ejecución de la imagen

-s, --startscript[=false] muestra el script de inicio de la imagen

-t, --test[=false] muestra el script de prueba de la imagen

EJEMPLO

  $ apptainer inspect ubuntu.sif
  Si desea listar las aplicaciones (apps) instaladas en un contenedor (ubicado en
  /scif/apps), debe ejecutar el comando inspect con la bandera --list-apps <imagen-contenedor>.
  (Ver https://sci-f.github.io para más información sobre aplicaciones SCIF)
  Las siguientes variables de entorno están disponibles cuando se llaman
  desde el shell dentro del contenedor. Las variables superiores son relevantes
  para la aplicación activa (--app <app>) y las inferiores están disponibles para todas
  las aplicaciones independientemente de la aplicación activa. Ambos conjuntos de variables también están disponibles durante el desarrollo (en tiempo de construcción).
  ENTORNO DE LA APLICACIÓN ACTIVA:
      SCIF_APPNAME       el nombre de la aplicación activa
      SCIF_APPROOT       la carpeta de instalación de la aplicación creada en /scif/apps/<app>
      SCIF_APPMETA       la carpeta de metadatos de la aplicación
      SCIF_APPDATA       la carpeta de datos creada para la aplicación en /scif/data/<app>
        SCIF_APPINPUT    carpeta de entrada esperada dentro de la carpeta base de datos
        SCIF_APPOUTPUT   la carpeta de datos de salida dentro de la carpeta base de datos
      SCIF_APPENV        apunta al archivo environment.sh personalizado de la aplicación en su carpeta de metadatos
      SCIF_APPLABELS     es el archivo labels.json de la aplicación en la carpeta de metadatos
      SCIF_APPBIN        es la carpeta bin para la aplicación, que se añade automáticamente a la variable $PATH cuando la aplicación está activa
      SCIF_APPLIB        es la carpeta de bibliotecas de la aplicación que se añade a la variable LD_LIBRARY_PATH
      SCIF_APPRUN        es el script de ejecución
      SCIF_APPSTART      es el script de inicio
      SCIF_APPHELP       es el archivo de ayuda para el script de ejecución
      SCIF_APPTEST       es el script de prueba (test.sh) asociado a la aplicación
      SCIF_APPNAME       el nombre de la aplicación activa
      SCIF_APPFILES      la sección de archivos asociada a la aplicación que se añade a
  ENTORNO GLOBAL DE APLICACIONES:
      SCIF_DATA             base de datos definida por scif para todas las aplicaciones (/scif/data)
      SCIF_APPS             bases de instalación definidas por scif para todas las aplicaciones (/scif/apps)
      SCIF_APPROOT_<app>    raíz para la aplicación <app>
      SCIF_APPDATA_<app>    raíz de datos para la aplicación <app>
  Para listar todas sus aplicaciones:
  $ apptainer inspect --list-apps ubuntu.sif
  Para listar solo las etiquetas en formato json de una imagen:
  $ apptainer inspect --json --labels ubuntu.sif
  Para verificar que posee una única aplicación en la imagen de su contenedor, utilice la bandera --app <nombre-aplicacion>:
  $ apptainer inspect --app <nombre-aplicacion> ubuntu.sif
