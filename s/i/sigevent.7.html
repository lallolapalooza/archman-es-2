sigevent(3type) sigevent(3type)

NOMBRE

sigevent, sigval - estructura para notificación de rutinas asíncronas

SINOPSIS

#include <signal.h>
struct sigevent {
    int             sigev_notify;  /* Tipo de notificación */
    int             sigev_signo;   /* Número de señal */
    union sigval    sigev_value;   /* Datos pasados con la notificación */
    typeof(void (union sigval))  *sigev_notify_function;
                                   /* Función de notificación
                                      (SIGEV_THREAD) */
    pthread_attr_t *sigev_notify_attributes;
                                   /* Atributos de notificación */
    /* Solo Linux: */
    pid_t           sigev_notify_thread_id;
                                   /* ID del hilo a señalar
                                      (SIGEV_THREAD_ID) */
};
union sigval {                     /* Datos pasados con la notificación */
    int             sival_int;     /* Valor entero */
    void           *sival_ptr;     /* Valor puntero */
};

DESCRIPCIÓN

sigevent

La estructura sigevent es utilizada por varias APIs para describir la forma en que un proceso debe ser notificado sobre un evento (por ejemplo, la finalización de una solicitud asíncrona, la expiración de un temporizador o la llegada de un mensaje).

La definición mostrada en la SINOPSIS es aproximada: algunos de los campos en la estructura sigevent pueden definirse como parte de una unión. Los programas deben emplear solo aquellos campos relevantes para el valor especificado en sigev_notify.

El campo sigev_notify especifica cómo se realiza la notificación. Este campo puede tener uno de los siguientes valores:

SIGEV_NONE
Una notificación "nula": no hacer nada cuando ocurra el evento.
SIGEV_SIGNAL
Notificar al proceso enviando la señal especificada en sigev_signo.
Si la señal es capturada con un manejador de señales registrado utilizando el flag SA_SIGINFO de sigaction(2), entonces los siguientes campos se establecen en la estructura siginfo_t que se pasa como segundo argumento del manejador:
si_code
Este campo se establece a un valor que depende de la API que entrega la notificación.
si_signo
Este campo se establece al número de señal (es decir, el mismo valor que en sigev_signo).
si_value
Este campo se establece al valor especificado en sigev_value.
Dependiendo de la API, otros campos también pueden establecerse en la estructura siginfo_t.
La misma información también está disponible si la señal se acepta usando sigwaitinfo(2).
SIGEV_THREAD
Notificar al proceso invocando sigev_notify_function "como si" fuera la función de inicio de un nuevo hilo. (Entre las posibilidades de implementación se encuentra que cada notificación de temporizador podría resultar en la creación de un nuevo hilo, o que se crea un único hilo para recibir todas las notificaciones.) La función se invoca con sigev_value como su único argumento. Si sigev_notify_attributes no es NULL, debe apuntar a una estructura pthread_attr_t que defina atributos para el nuevo hilo (ver pthread_attr_init(3)).
SIGEV_THREAD_ID (Específico de Linux)
Actualmente solo utilizado por temporizadores POSIX; ver timer_create(2).

sigval

Datos pasados con una señal.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.

<aio.h> y <time.h> definen sigevent desde POSIX.1-2008.

NOTAS

Las siguientes cabeceras también proporcionan sigevent: <aio.h>, <mqueue.h>, y <time.h>.
