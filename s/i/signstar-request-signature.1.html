NOMBRE

signstar-request-signature - Argumentos de línea de comandos para firmar

SINOPSIS

signstar-request-signature [-v|--verbose]... [-q|--quiet]... [-h|--help] <subcomandos>

DESCRIPCIÓN

Argumentos de línea de comandos para firmar

OPCIONES

-v, --verbose
Incrementar la verbosidad del registro
-q, --quiet
Disminuir la verbosidad del registro
-h, --help
Imprimir ayuda

SUBCOMANDOS

signstar-request-signature-prepare(1)
Preparar solicitud de firma para un archivo
signstar-request-signature-send(1)
Enviar solicitud de firma a través de SSH
signstar-request-signature-help(1)
Imprimir este mensaje o la ayuda de los subcomandos dados
