NOMBRE

apptainer-oci - Gestionar contenedores OCI

SINOPSIS

apptainer oci

DESCRIPCIÓN

Permite gestionar contenedores de directorios de bundles OCI.

NOTA: todos los comandos oci requieren ejecutarse como root

OPCIONES

-h, --help[=false] Ayuda para oci

EJEMPLO

  Todos los comandos de grupo tienen su propia salida de ayuda:
  $ apptainer oci create -b ~/bundle micontenedor
  $ apptainer oci start micontenedor
