sigvec(3) Manual de Funciones de Biblioteca sigvec(3)

NOMBRE

sigvec, sigblock, sigsetmask, siggetmask, sigmask - API de señales de BSD

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <signal.h>
[[deprecated]] int sigvec(int sig, const struct sigvec *vec,
                          struct sigvec *ovec);
[[deprecated]] int sigmask(int signum);
[[deprecated]] int sigblock(int mask);
[[deprecated]] int sigsetmask(int mask);
[[deprecated]] int siggetmask(void);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

Todas las funciones mostradas arriba:

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE

DESCRIPCIÓN

Estas funciones se proporcionan en glibc como una interfaz de compatibilidad para programas que utilizan la API histórica de señales de BSD. Esta API está obsoleta: las nuevas aplicaciones deben usar la API de señales POSIX (sigaction(2), sigprocmask(2), etc.).

La función sigvec() establece y/o obtiene la disposición de la señal sig (similar a la sigaction(2) de POSIX). Si vec no es NULL, apunta a una estructura sigvec que define la nueva disposición para sig. Si ovec no es NULL, apunta a una estructura sigvec que se utiliza para devolver la disposición anterior de sig. Para obtener la disposición actual de sig sin cambiarla, especifique NULL para vec y un puntero no nulo para ovec.

Las disposiciones para SIGKILL y SIGSTOP no se pueden cambiar.

La estructura sigvec tiene la siguiente forma:


struct sigvec {
    void (*sv_handler)(int); /* Disposición de la señal */
    int    sv_mask;          /* Señales a bloquear en el manejador */
    int    sv_flags;         /* Indicadores */
};

El campo sv_handler especifica la disposición de la señal, y es:

la dirección de una función manejadora de señales;
SIG_DFL, que significa que se aplica la disposición por defecto para la señal;
SIG_IGN, que significa que la señal se ignora.

Si sv_handler especifica la dirección de una función manejadora de señales, entonces sv_mask especifica una máscara de señales que deben bloquearse mientras se ejecuta el manejador. Además, la señal para la que se invoca el manejador también se bloquea. Los intentos de bloquear SIGKILL o SIGSTOP se ignoran silenciosamente.

Si sv_handler especifica la dirección de una función manejadora de señales, entonces el campo sv_flags especifica indicadores que controlan lo que sucede cuando se llama al manejador. Este campo puede contener cero o más de los siguientes indicadores:

SV_INTERRUPT
Si el manejador de señales interrumpe una llamada al sistema bloqueante, entonces al regresar del manejador la llamada al sistema no se reinicia: en su lugar, falla con el error EINTR. Si este indicador no se especifica, las llamadas al sistema se reinician por defecto.
SV_RESETHAND
Restablece la disposición de la señal a la predeterminada antes de llamar al manejador de señales. Si este indicador no se especifica, el manejador permanece establecido hasta que se elimina explícitamente mediante una llamada posterior a sigvec() o hasta que el proceso realiza una execve(2).
SV_ONSTACK
Manejar la señal en la pila de señales alternativa (establecida históricamente bajo BSD usando la función obsoleta sigstack(); el reemplazo POSIX es sigaltstack(2)).

El macro sigmask() construye y devuelve una "máscara de señales" para signum. Por ejemplo, podemos inicializar el campo vec.sv_mask dado a sigvec() con código como el siguiente:


vec.sv_mask = sigmask(SIGQUIT) | sigmask(SIGABRT);
            /* Bloquear SIGQUIT y SIGABRT durante
               la ejecución del manejador */

La función sigblock() añade las señales en mask a la máscara de señales del proceso (similar a sigprocmask(SIG_BLOCK) de POSIX) y devuelve la máscara de señales anterior del proceso. Los intentos de bloquear SIGKILL o SIGSTOP se ignoran silenciosamente.

La función sigsetmask() establece la máscara de señales del proceso al valor dado en mask (similar a sigprocmask(SIG_SETMASK) de POSIX) y devuelve la máscara de señales anterior del proceso.

La función siggetmask() devuelve la máscara de señales actual del proceso. Esta llamada es equivalente a sigblock(0).

VALOR DE RETORNO

La función sigvec() devuelve 0 en caso de éxito; en caso de error, devuelve -1 y establece errno para indicar el error.

Las funciones sigblock() y sigsetmask() devuelven la máscara de señales anterior.

El macro sigmask() devuelve la máscara de señales para signum.

ERRORES

Ver los ERRORES en sigaction(2) y sigprocmask(2).

NOTAS

En 4.3BSD, la función signal() proporcionaba semántica fiable (como al llamar a sigvec() con vec.sv_mask igual a 0). En System V, signal() proporcionaba semántica no fiable. POSIX.1 deja estos aspectos de signal() sin especificar. Ver signal(2) para más detalles.

Para esperar una señal, BSD y System V proporcionaban una función llamada sigpause(3), pero esta función tiene un argumento diferente en los dos sistemas. Ver sigpause(3) para detalles.
