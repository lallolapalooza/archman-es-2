SIG2DOT(1) Manual de comandos generales SIG2DOT(1)

NOMBRE

sig2dot - crea un archivo .dot a partir de un listado de firmas GPG

SINOPSIS

sig2dot [OPCIONES] < archivo-entrada > archivo-salida

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando sig2dot. Sig2dot analiza la salida de "gpg --list-sigs" y produce un archivo .dot que puede ser utilizado como entrada para un programa de gráficos.

OPCIONES

sig2dot acepta las siguientes opciones:

-b
Blanco y negro / no colorear.
-d <fecha>
Renderiza el gráfico como apareció en <fecha> (ignora las firmas más recientes). La fecha debe estar en el formato "YYYY-MM-DD". También ignorará las claves que hayan sido revocadas desde entonces.
-s <nombre-archivo-html>
Produce un archivo de estadísticas HTML detallado con el número de firmas por nodo.
-a
Graficar todas las claves, incluso si no tienen firma
-r <cadena-clave-revocada>
Establece el texto para la cadena de clave revocada utilizada por GnuPG. El valor predeterminado es el que se usa en la versión en inglés. Este parámetro puede configurarse para versiones de GnuPG localizadas a otros idiomas. Predeterminado: "[revoked".
-t <título>
Establece el título del gráfico generado. Predeterminado: "Keyring Statistics".
-u <cadena-usuario-no-encontrado>
Establece el texto para la cadena de usuario no encontrado utilizada por GnuPG. El valor predeterminado es el que se usa en la versión en inglés. Este parámetro puede configurarse para versiones de GnuPG localizadas a otros idiomas. Predeterminado: "[user id not found]".
-q
Silencioso.
-h
Imprimir ayuda y salir.
-v
Imprimir versión y salir.

EJEMPLO

gpg --list-sigs | sig2dot > sigs.dot

springgraph < sigs.dot > sigs.png

VER TAMBIÉN

springgraph(1) gnupg(1)
