DESCRIPCIÓN

Cada instalación de "findlib" tiene una ubicación predeterminada para los directorios de paquetes, que normalmente es un directorio llamado "site-lib". La ubicación se puede establecer mediante las variables de configuración path (usada para buscar paquetes) y destdir (usada para instalar nuevos paquetes); véase findlib.conf.

El nombre de un paquete es el nombre del directorio del paquete. Por ejemplo, si destdir=/usr/local/lib/ocaml/site-lib, el paquete p se instalará en el subdirectorio /usr/local/lib/ocaml/site-lib/p. Este subdirectorio debe contener el archivo META y todos los demás archivos que pertenecen al paquete. Los nombres de los paquetes no deben contener el carácter '.'.

La variable destdir especifica el directorio para nuevos paquetes. Solo puede haber un directorio de este tipo a la vez; pero, por supuesto, puede cambiar este directorio en findlib.conf. El comando ocamlfind install coloca nuevos paquetes en este directorio; se recomienda usar este comando para la instalación, ya que asegura que el diseño del directorio sea correcto.

Para buscar paquetes, findlib utiliza (únicamente) la variable path, que puede nombrar varias ubicaciones a examinar.

Para sistemas con soporte de DLL, puede existir otro directorio: stublibs. Si está presente, findlib instalará las DLL en este directorio, que es compartido por todos los paquetes en la misma ubicación de site-lib. Findlib recuerda qué DLL pertenece a qué paquete mediante archivos especiales con el sufijo ".owner"; por ejemplo, para la DLL "dllpcre.so", hay otro archivo "dllpcre.so.owner" que contiene la cadena "pcre", de modo que findlib sabe que el paquete "pcre" es el propietario de esta DLL. No es posible que una DLL sea propiedad de varios paquetes.

Si el directorio stublibs no existe, las DLL se instalan normalmente en los directorios de paquetes como cualquier otro archivo.

Para necesidades especiales, se puede instalar un script postinstall y/o postremove en el directorio site-lib. Estos scripts se invocan después de la instalación o eliminación de un paquete, respectivamente.

     |  |
     |  +-

     |  +-

     |
     +-

     +

     :
     \
  :

  |
  \
    metaregistry
    |
    +- META.paquete1
    +- META.paquete2
    +
    :
    \
       META.paqueteN

Este es un diseño de directorio alternativo que recopila todos los archivos META en un solo directorio. Puede configurar este diseño estableciendo path a la ubicación absoluta de metaregistry. Findlib reconoce que hay archivos META en este directorio y los utiliza; no es necesario incluir site-lib en el path.

Para que funcione, los archivos META deben contener una directiva de directorio que apunte al directorio del paquete correspondiente que reside debajo de site-lib.

El comando ocamlfind install también maneja este diseño. La variable destdir debe contener la ubicación absoluta de site-lib, y la variable metadir debe contener la ubicación absoluta de metaregistry. Tenga en cuenta que ocamlfind install añade automáticamente una directiva de directorio al archivo META, por lo que no necesita hacerlo manualmente.
