siginterrupt(3) Manual de Funciones de Librería siginterrupt(3)

NOMBRE

siginterrupt - permitir que las señales interrumpan llamadas al sistema

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <signal.h>
[[deprecated]] int siginterrupt(int sig, int flag);
Requisitos de Macro de Prueba de Funcionalidades para glibc (ver feature_test_macros(7)):

siginterrupt():

    _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.12: */ _POSIX_C_SOURCE >= 200809L
        || /* glibc <= 2.19: */ _BSD_SOURCE

DESCRIPCIÓN

La función siginterrupt() cambia el comportamiento de reinicio cuando una llamada al sistema es interrumpida por la señal sig. Si el argumento flag es falso (0), entonces las llamadas al sistema se reiniciarán si son interrumpidas por la señal especificada sig. Este es el comportamiento predeterminado en Linux.

Si el argumento flag es verdadero (1) y no se ha transferido ningún dato, entonces una llamada al sistema interrumpida por la señal sig devolverá -1 y errno se establecerá a EINTR.

Si el argumento flag es verdadero (1) y la transferencia de datos ha comenzado, entonces la llamada al sistema se interrumpirá y devolverá la cantidad real de datos transferidos.

VALOR DE RETORNO

La función siginterrupt() devuelve 0 si tiene éxito. Devuelve -1 si el número de señal sig es inválido, con errno establecido para indicar el error.

ERRORES

EINVAL
El número de señal especificado es inválido.

HISTORIAL

4.3BSD, POSIX.1-2001. Obsoleto en POSIX.1-2008, recomendando el uso de sigaction(2) con la bandera SA_RESTART en su lugar.
