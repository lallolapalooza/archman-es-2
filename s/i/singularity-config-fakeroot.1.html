NOMBRE

apptainer-config-fakeroot - Gestiona entradas de mapeo de usuarios fakeroot (solo usuario root)

SINOPSIS

apptainer config fakeroot

DESCRIPCIÓN

El comando config fakeroot permite a un usuario root añadir/eliminar/activar/desactivar mapeos de usuarios de fakeroot.

OPCIONES

-a, --add[=false] añade una entrada de mapeo de fakeroot para un usuario, permitiéndole usar la funcionalidad fakeroot

-d, --disable[=false] desactiva una entrada de mapeo de fakeroot de un usuario, impidiéndole usar la funcionalidad fakeroot (la entrada de mapeo de usuario debe estar presente)

-e, --enable[=false] activa una entrada de mapeo de fakeroot de un usuario, permitiéndole usar la funcionalidad fakeroot (la entrada de mapeo de usuario debe estar presente)

-h, --help[=false] ayuda para fakeroot

-r, --remove[=false] elimina la entrada de mapeo de fakeroot de un usuario, impidiéndole usar la funcionalidad fakeroot

EJEMPLO

  Para añadir un mapeo de usuario fakeroot para el usuario vagrant:
  $ apptainer config fakeroot --add vagrant
  Para eliminar un mapeo de usuario fakeroot para el usuario vagrant:
  $ apptainer config fakeroot --remove vagrant
  Para desactivar un mapeo de usuario fakeroot para el usuario vagrant:
  $ apptainer config fakeroot --disable vagrant
  Para activar un mapeo de usuario fakeroot para el usuario vagrant:
  $ apptainer config fakeroot --enable vagrant
