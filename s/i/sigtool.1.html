NOMBRE

sigtool - herramienta de gestión de firmas y bases de datos

SINOPSIS

sigtool [opciones]

DESCRIPCIÓN

sigtool se puede usar para generar sumas de comprobación MD5, convertir datos a formato hexadecimal, listar firmas de virus y construir/desempaquetar/probar/verificar bases de datos CVD y scripts de actualización.

OPCIONES COMUNES

-h, --help
Muestra información de ayuda y sale.
-V, --version
Imprime el número de versión y sale.
--quiet
Silencioso, muestra solo mensajes de error.
--debug
Habilita mensajes de depuración
--stdout
Escribe todos los mensajes en stdout.
--tempdir=DIRECTORIO
Crea archivos temporales en DIRECTORIO. El directorio debe ser escribible por el usuario que ejecuta sigtool.
--leave-temps
No elimina los archivos temporales.
--datadir=DIR
Usa DIR como el directorio de bases de datos predeterminado para todas las operaciones.

COMANDOS PARA TRABAJAR CON FIRMAS

-l[ARCHIVO], --list-sigs[=ARCHIVO]
Lista todos los nombres de firmas del directorio de bases de datos local (predeterminado) o de ARCHIVO.
-fEXPRESIÓN_REGULAR, --find-sigs=EXPRESIÓN_REGULAR
Busca y muestra firmas del directorio de bases de datos local que coincidan con la EXPRESIÓN_REGULAR dada. Se comprueba todo el cuerpo de la firma (nombre, cadena hexadecimal, etc.).
--decode-sigs=EXPRESIÓN_REGULAR
Decodifica firmas leídas de la entrada estándar (por ejemplo, canalizadas desde --find-sigs)
--test-sigs=BASE_DE_DATOS ARCHIVO_OBJETIVO
Prueba todas las firmas de BASE_DE_DATOS contra ARCHIVO_OBJETIVO. Esta opción solo dará resultados válidos si el archivo objetivo es el final (después de desempaquetar, normalizar, etc.) para el cual se crearon las firmas.

COMANDOS PARA GENERAR FIRMAS

--md5 [ARCHIVOS]
Genera la suma de comprobación MD5 desde stdin o firmas MD5 para ARCHIVOS.
--sha1 [ARCHIVOS]
Genera la suma de comprobación SHA1 desde stdin o firmas SHA1 para ARCHIVOS.
--sha2-256 [ARCHIVOS]
Genera la suma de comprobación SHA2-256 desde stdin o firmas SHA2-256 para ARCHIVOS. La opción anterior --sha256 está obsoleta y puede eliminarse en una futura versión.
--mdb [ARCHIVOS]
Genera firmas .mdb (hash de sección PE) para ARCHIVOS.
--imp [ARCHIVOS]
Genera firmas .imp (hash de tabla de direcciones de importación PE) para ARCHIVOS.
--fuzzy-img [ARCHIVOS]
Genera hash difuso de imagen para cada archivo.

COMANDOS PARA NORMALIZAR ARCHIVOS

--html-normalise=ARCHIVO
Crea archivos HTML normalizados comment.html, nocomment.html y script.html en el directorio de trabajo actual.
--ascii-normalise=ARCHIVO
Crea un archivo de texto normalizado a partir de una fuente ASCII.
--utf16-decode=ARCHIVO
Decodifica datos codificados en UTF16.

COMANDOS PARA ANÁLISIS DE ARCHIVOS

--vba=ARCHIVO
Extrae macros VBA/Word6 del documento MS Office dado.
--vba-hex=ARCHIVO
Extrae macros Word6 del documento MS Office dado y muestra los valores hexadecimales correspondientes.
--print-certs=ARCHIVO
Muestra detalles de Authenticode de un archivo PE.
--hex-dump
Lee datos de stdin y escribe la cadena hexadecimal en stdout.

COMANDOS PARA TRABAJAR CON CVD

-i, --info
Muestra información de un CVD y verifica su firma MD5 y digital.
--build=ARCHIVO, -b ARCHIVO
Construye un archivo CVD. Se requiere -s, --server para bases de datos de virus firmadas (.cvd), o --unsigned para no firmadas (.cud).
--max-bad-sigs=NÚMERO
Número máximo de firmas incorrectas al construir un CVD. Predeterminado: 3000
--flevel
Especifica un flevel personalizado. Predeterminado: 77
--cvd-version
Especifica el número de versión a usar para la compilación. El predeterminado es usar el valor+1 del CVD actual en --datadir. Si no se encuentra ningún archivo de datos, el comportamiento predeterminado es solicitar un número de versión, este modificador evitará la solicitud. NOTA: Si se encuentra un CVD en el --datadir, se usará su versión+1 y este valor se ignorará.
--no-cdiff
No crea un archivo .cdiff al construir un nuevo archivo de base de datos.
--hybrid
Crea un archivo de base de datos híbrido (estándar y bytecode).
--unsigned
Crea un archivo de base de datos sin firmas digitales (.cud).
--server=DIRECCIÓN
Dirección del Servicio de Firma de ClamAV (solo para mantenedores de bases de datos de virus).
--unpack=ARCHIVO, -u ARCHIVO
Desempaqueta ARCHIVO (CVD) en el directorio actual.
--unpack-current
Desempaqueta un archivo CVD local (main o daily) en el directorio actual.
--fips-limits
Aplica límites similares a FIPS al uso de algoritmos hash para fines criptográficos. Deshabilitará las firmas FP MD5 y SHA1 y requerirá archivos '.sign' para verificar la autenticidad de los CVD.

COMANDOS PARA TRABAJAR CON ARCHIVOS DE PARCHE CDIFF

--diff=VIEJO NUEVO, -d VIEJO NUEVO
Crea un archivo de diferencia para CVDs/INCDIRs VIEJOS y NUEVOS.
--compare=VIEJO NUEVO, -c VIEJO NUEVO
Este comando comparará dos archivos de texto y mostrará las diferencias en formato cdiff.
--run-cdiff=ARCHIVO, -r ARCHIVO
Ejecuta el script de actualización ARCHIVO en el directorio actual.
--verify-cdiff=ARCHIVO, -r ARCHIVO
Verifica DIFF contra CVD/INCDIR.

COMANDOS PARA CREAR Y VERIFICAR FIRMAS DIGITALES DESMONTADAS

--sign
Firma un archivo. El nombre del archivo .sign resultante será en el formato: dbname-version.cvd.sign o ARCHIVO.sign para objetivos que no sean CVD. I

COMANDOS PARA TRABAJAR CON FIRMAS

--sign=ARCH
Genera una firma para la base de datos de firmas de un ARCH determinado. El nombre del archivo de firma será: dbname-version.ARCH.sign. El archivo de firma se creará junto al archivo de destino. Si ya existe un archivo .sign, la nueva firma se añadirá al archivo.
--key=FILE
Especifica una clave de firma.
--cert=FILE
Especifica un certificado de firma. Se puede usar más de una vez para añadir certificados intermedios y raíz.
--append
Se usa para añadir una línea de firma a un archivo .sign existente. De lo contrario, un archivo .sign existente será sobrescrito.
--verify
Encuentra y verifica una firma digital separada para el archivo dado. El nombre del archivo de firma digital debe tener el formato: dbname-version.cvd.sign o FILE.sign para objetivos que no son CVD. Debe encontrarse junto al archivo de destino.
--cvdcertsdir=DIR
Especifica un directorio que contiene el certificado CA raíz necesario para verificar la firma. Si no se proporciona, entonces sigtool buscará en el directorio de certificados predeterminado.

VARIABLES DE ENTORNO

Sigtool utiliza las siguientes variables de entorno:

SIGNDUSER
El nombre de usuario para autenticarse con el servidor de firma al construir una base de datos CVD firmada.
SIGNDPASS
La contraseña para autenticarse con el servidor de firma al construir una base de datos CVD firmada.
CVD_CERTS_DIR
Especifica un directorio que contiene el certificado CA raíz necesario para verificar firmas digitales CVD separadas. Si no se proporciona, entonces sigtool buscará en el directorio predeterminado.

EJEMPLOS

Generar una cadena hexadecimal a partir de testfile y guardarla en testfile.hex:

cat testfile | sigtool --hex-dump > testfile.hex
