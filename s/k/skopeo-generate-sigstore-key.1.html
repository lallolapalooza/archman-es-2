NOMBRE

skopeo-generate-sigstore-key - Genera un par de claves pública/privada de sigstore.

SINOPSIS

skopeo generate-sigstore-key [opciones] --output-prefix prefijo

DESCRIPCIÓN

Genera un par de claves pública/privada adecuado para crear firmas de imágenes de sigstore. La clave privada se cifra con una contraseña; si no se proporciona una mediante una opción, este comando la solicitará interactivamente.

La clave privada se escribe en prefijo.private. La clave pública se escribe en prefijo.pub.

OPCIONES

Consulte también skopeo(1) para ver las opciones que se colocan antes del nombre del subcomando.

--help, -h

Imprime el aviso de uso.

--output-prefix prefijo

Obligatorio. Prefijo de ruta para las claves de salida (prefijo.private y prefijo.pub).

--passphrase-file ruta

La contraseña a utilizar para cifrar la clave privada. Solo se leerá la primera línea. Una contraseña almacenada en un archivo tiene una seguridad cuestionable si otros usuarios pueden leer este archivo. No utilice esta opción si se puede evitar.

EJEMPLOS

$ skopeo generate-sigstore-key --output-prefix mi-clave
