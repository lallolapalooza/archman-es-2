NOMBRE

skopeo-logout - Cerrar sesión en un registro de contenedores.

SINOPSIS

skopeo logout [opciones] registro

DESCRIPCIÓN

skopeo logout cierra sesión en un servidor de registro especificado eliminando las credenciales cacheadas almacenadas en el archivo auth.json. La ruta del archivo de credenciales puede ser anulada por el usuario estableciendo el indicador authfile. Se pueden eliminar todas las credenciales cacheadas estableciendo el indicador all.

OPCIONES

Ver también skopeo(1) para las opciones que se colocan antes del nombre del subcomando.

--authfile=ruta

Ruta del archivo de credenciales del registro gestionado. En Linux, la predeterminada es ${XDG_RUNTIME_DIR}/containers/auth.json. Consulte containers-auth.json(5) para más detalles sobre la predeterminada en otras plataformas.

El valor predeterminado de esta opción se lee de la variable de entorno REGISTRY\_AUTH\_FILE.

--compat-auth-file=ruta

En lugar de actualizar el archivo de credenciales predeterminado, actualiza el que se encuentra en ruta y utiliza un formato compatible con Docker.

--all, -a

Eliminar las credenciales cacheadas para todos los registros en el archivo auth

--help, -h

Imprimir la declaración de uso

--tls-verify=bool

Requerir HTTPS y verificar certificados al comunicarse con el registro de contenedores o el demonio. El valor predeterminado es la configuración de registry.conf.

EJEMPLOS

$ skopeo logout docker.io
Elimina las credenciales de inicio de sesión para docker.io
$ skopeo logout --authfile authdir/myauths.json docker.io
Elimina las credenciales de inicio de sesión para docker.io
$ skopeo logout --all
Elimina las credenciales de inicio de sesión para todos los registros

VER TAMBIÉN

skopeo(1), skopeo-login(1), containers-auth.json(5)
