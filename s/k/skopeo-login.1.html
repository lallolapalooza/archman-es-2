NOMBRE

skopeo-login - Iniciar sesión en un registro de contenedores.

SINOPSIS

skopeo login [opciones] registro

DESCRIPCIÓN

skopeo login inicia sesión en un servidor de registro especificado con el nombre de usuario y la contraseña correctos. skopeo login lee el nombre de usuario y la contraseña de STDIN. El nombre de usuario y la contraseña también se pueden establecer utilizando las opciones username y password. La ruta del archivo de credenciales puede ser especificada por el usuario estableciendo la opción authfile.

OPCIONES

Consulte también skopeo(1) para ver las opciones que se colocan antes del nombre del subcomando.

--password, -p=contraseña

Contraseña para el registro

--password-stdin

Toma la contraseña de stdin

--username, -u=nombredeusuario

Nombre de usuario para el registro

--authfile=ruta

Ruta del archivo de credenciales de registro gestionado. En Linux, el valor predeterminado es ${XDG_RUNTIME_DIR}/containers/auth.json. Consulte containers-auth.json(5) para más detalles sobre el valor predeterminado en otras plataformas.

El valor predeterminado de esta opción se lee de la variable de entorno REGISTRY\_AUTH\_FILE.

--compat-auth-file=ruta

En lugar de actualizar el archivo de credenciales predeterminado, actualiza el que se encuentra en ruta y utiliza un formato compatible con Docker.

--get-login

Devuelve el usuario conectado para el registro. Devuelve un error si no se encuentra ningún inicio de sesión.

--cert-dir=ruta

Utiliza certificados en ruta (*.crt, *.cert, *.key) para conectarse al registro. El directorio de certificados predeterminado es /etc/containers/certs.d.

--help, -h

Imprime la declaración de uso

--tls-verify=booleano

Requiere HTTPS y verifica los certificados al hablar con el registro de contenedores o el demonio. El valor predeterminado es la configuración de registry.conf.

--verbose, -v

Escribe información más detallada en stdout

EJEMPLOS

$ skopeo login docker.io
Username: testuser
Password:
Login Succeeded!
$ skopeo login -u testuser -p testpassword localhost:5000
Login Succeeded!
$ skopeo login --authfile authdir/myauths.json docker.io
Username: testuser
Password:
Login Succeeded!
$ skopeo login --tls-verify=false -u test -p test localhost:5000
Login Succeeded!
$ skopeo login --cert-dir /etc/containers/certs.d/ -u foo -p bar localhost:5000
Login Succeeded!
$ skopeo login -u testuser  --password-stdin < testpassword.txt docker.io
Login Succeeded!
$ echo $testpassword | skopeo login -u testuser --password-stdin docker.io
Login Succeeded!

VEA TAMBIÉN

skopeo(1), skopeo-logout(1), containers-auth.json(5), containers-registries.conf(5), containers-certs.d.5.md
