skopeo-standalone-sign(1)

Paquete: skopeo

Licencias: Apache-2.0

skopeo-standalone-sign(1)() skopeo-standalone-sign(1)()

NOMBRE

skopeo standalone-sign - Herramienta de depuración - Firma una imagen localmente sin subirla.

SINOPSIS

skopeo standalone-sign [opciones] manifiesto referencia-docker huella-digital-clave --output|-o firma

DESCRIPCIÓN

Esta es principalmente una herramienta de depuración, útil para casos especiales, y que normalmente no debería formar parte de tu flujo de trabajo operacional normal; usa skopeo copy --sign-by en su lugar para publicar y firmar una imagen en un solo paso.

manifiesto Ruta a un archivo que contiene el manifiesto de la imagen

referencia-docker Una referencia de docker para identificar la imagen

huella-digital-clave Identidad de clave a usar para firmar

OPCIONES

Ver también skopeo(1) para opciones que se colocan antes del nombre del subcomando.

--help, -h

Imprime el enunciado de uso

--output, -o archivo de salida

Escribe la firma en el archivo de salida.

--passphrase-file=ruta

La contraseña a usar al firmar con el ID de clave de --sign-by. Solo se leerá la primera línea. Una contraseña almacenada en un archivo es de seguridad cuestionable si otros usuarios pueden leer este archivo. No uses esta opción si puedes evitarlo.

EJEMPLOS

$ skopeo standalone-sign busybox-manifest.json registry.example.com/example/busybox 1D8230F6CDB6A06716E414C1DB72F2188BB46CC8 --output busybox.signature
$

NOTAS

Este comando está destinado a usarse con firmas locales, por ejemplo, OpenPGP (es posible que se agreguen otros formatos de firma en el futuro), según containers-signature(5). Además, este comando no interactúa con los artefactos generados por Docker Content Trust (DCT). Para obtener más información, consulta containers-signature(5) ⟨https://github.com/containers/image/blob/main/docs/containers-signature.5.md⟩.
