SKATE(1) Skate, un almacén personal de clave-valor. SKATE(1)

NOMBRE

skate - Skate, un almacén personal de clave-valor.

SINOPSIS

skate [opciones...] [argumento...]

DESCRIPCIÓN

COMANDOS

eliminar CLAVE[@DB]
Elimina una clave con una base de datos opcional @.
eliminar-db [@DB]
Elimina una base de datos.
obtener CLAVE[@DB]
Obtiene un valor para una clave con una base de datos opcional @.
OPCIONES
--b --mostrar-binarios imprime valores binarios
ayuda [comando]
Ayuda sobre cualquier comando.
listar [@DB]
Lista pares clave-valor con una base de datos opcional @.
OPCIONES
--d --delimitador delimitador para separar claves y valores
--k --solo-claves
solo imprime claves y no obtiene valores de la base de datos
--r --inverso
listar en orden lexicográfico inverso
--b --mostrar-binarios
imprime valores binarios
--v --solo-valores
solo imprime valores
listar-dbs
Lista bases de datos.
establecer CLAVE[@DB] [VALOR]
Establece un valor para una clave con una base de datos opcional @. Si se omite VALOR, lee el valor de la entrada estándar.
