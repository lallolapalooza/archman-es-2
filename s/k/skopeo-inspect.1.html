NOMBRE

skopeo-inspect - Devuelve información de bajo nivel de nombre-imagen en un registro.

SINOPSIS

skopeo inspect [opciones] nombre-imagen

DESCRIPCIÓN

Devuelve información de bajo nivel de nombre-imagen en un registro. Véase skopeo(1) para el formato de nombre-imagen.

La salida predeterminada incluye datos de varias fuentes: entrada del usuario (Name), el repositorio remoto, si existe (RepoTags), el manifiesto de nivel superior (Digest), y una imagen por arquitectura/sistema operativo que coincide con el entorno de ejecución actual (la mayoría de los otros valores). Para ver los valores de una arquitectura/sistema operativo diferente, use las opciones --override-os / --override-arch documentadas en skopeo(1).

OPCIONES

Ver también skopeo(1) para las opciones que se colocan antes del nombre del subcomando.

--authfile ruta

Ruta del archivo principal de credenciales del registro. En Linux, el valor predeterminado es ${XDG_RUNTIME_DIR}/containers/auth.json. Véase containers-auth.json(5) para más detalles sobre el mecanismo de búsqueda de credenciales y los valores predeterminados en otras plataformas.

Use skopeo login para gestionar las credenciales.

El valor predeterminado de esta opción se lee de la variable de entorno REGISTRY\_AUTH\_FILE.

--cert-dir ruta

Use certificados en ruta (*.crt, *.cert, *.key) para conectarse al registro.

--config

Muestra la configuración en formato OCI, el valor predeterminado es formatear en formato JSON.

--creds usuario[:contraseña]

Nombre de usuario y contraseña para acceder al registro.

--daemon-host host

Use el host del demonio de Docker en host (solo transporte docker-daemon:)

--format, -f=formato

Formatea la salida usando la plantilla Go proporcionada. Las claves del JSON devuelto se pueden usar como valores para la bandera --format (ver ejemplos más abajo). Admite las funciones de plantillas Go disponibles en https://pkg.go.dev/github.com/containers/common/pkg/report#hdr-Template_Functions

--help, -h

Imprime el enunciado de uso

--no-creds

Accede al registro de forma anónima.

--raw

Muestra el manifiesto o datos de configuración sin procesar según la opción --config. La opción --format no es compatible con la opción --raw.

--registry-token Token Bearer

Token del registro para acceder al registro.

--retry-times

El número de veces que se reintentará.

--retry-delay

Retardo fijo entre reintentos. Si no se establece (o se establece en 0s), el tiempo de espera de reintento aumentará exponencialmente según el número de intentos fallidos.

--shared-blob-dir directorio

Directorio a utilizar para compartir blobs entre repositorios OCI.

--tls-verify=bool

Requiere HTTPS y verifica certificados al hablar con el registro o demonio de contenedores. Predeterminado según la configuración de registry.conf.

--username

El nombre de usuario para acceder al registro.

--password

La contraseña para acceder al registro.

--no-tags, -n

No listar las etiquetas disponibles del repositorio en la salida. Cuando es true, el array RepoTags estará vacío. Predeterminado a false, que incluye todas las etiquetas disponibles.

    skopeo-inspect

    skopeo-inspect(1) man pages skopeo-inspect(1)

    DESCRIPTION

    skopeo-inspect can inspect an image on a container registry or a storage. It displays the manifest, configuration, and other metadata of the image.

    OPTIONS

    --raw
    Display the raw manifest data instead of parsing it.
    --tls-verify=boolean
    Require HTTPS client certificates that are verified by a remote server's CA. This is the default, so this option can be used to disable it.

    EXAMPLES

    Inspect an image from Docker Hub: 

    skopeo inspect docker://docker.io/library/ubuntu:latest
    Inspect an image from a private registry: 
    skopeo inspect docker://myregistry.com/myimage:latest
    Inspect an image and display the raw manifest data: 
    skopeo inspect --raw docker://docker.io/library/ubuntu:latest
