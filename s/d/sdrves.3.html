subroutine sdrves (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, real, dimension( lda, * ) a, integer lda, real, dimension( lda, * ) h, real, dimension( lda, * ) ht, real, dimension( * ) wr, real, dimension( * ) wi, real, dimension( * ) wrt, real, dimension( * ) wit, real, dimension( ldvs, * ) vs, integer ldvs, real, dimension( 13 ) result, real, dimension( * ) work, integer nwork, integer, dimension( * ) iwork, logical, dimension( * ) bwork, integer info)

SDRVES

Propósito:

!>
!>    SDRVES comprueba el driver SGEES para el problema de valores propios no simétricos (forma de Schur).
!>
!>    Cuando se llama a SDRVES, se especifica un número de tamaños de matriz y un número de tipos de matriz.
!>    Para cada tamaño y cada tipo de matriz, se generará una matriz y se utilizará para probar las rutinas de valores propios no simétricos.
!>    Para cada matriz, se realizarán 13 pruebas:
!>
!>    (1)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>           (sin ordenación de valores propios)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de los vectores propios de Schur, y T está en forma de Schur
!>      (sin ordenación de valores propios).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (sin ordenación de valores propios).
!>
!>    (4)     0     si WR+sqrt(-1)*WI son valores propios de T
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (5)     0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (6)     0     si valores propios(con VS) = valores propios(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (7)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de los vectores propios de Schur, y T está en forma de Schur
!>      (con ordenación de valores propios).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (con ordenación de valores propios).
!>
!>    (10)    0     si WR+sqrt(-1)*WI son valores propios de T
!>            1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (11)    0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (12)    0     si valores propios(con VS) = valores propios(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (13)    si la ordenación funcionó y SDIM es el número de
!>            valores propios que fueron SELECCIONADOS.
!>
!>    Los tamaños de matriz se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los tipos de matriz se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará una matriz de tipo j.
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1's en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP y signos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1)
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP y signos aleatorios.
!>    (6)  Una matriz diagonal con entradas espaciadas de forma lineal 1, ULP, ..., ULP
!>         y signos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de desbordamiento.
!>    (8)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de subdesbordamiento.
!>
!>    (9)  Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>         en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (10) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>         en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (11) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas linealmente 1, ULP,..., ULP con signos aleatorios
!>         en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (12) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene valores propios reales o emparejados complejos conjugados elegidos aleatoriamente de ( ULP, 1 ) y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (13) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con signos aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (14) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con signos aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (15) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas linealmente 1, ULP,..., ULP
!>         con signos aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (16) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene valores propios reales o emparejados complejos conjugados
!>         elegidos aleatoriamente de ( ULP, 1 ) y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (17) Igual que (16), pero multiplicado por una constante cercana
!>         al umbral de desbordamiento.
!>    (18) Igual que (16), pero multiplicado por una constante cercana
!>         al umbral de subdesbordamiento.
!>
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de (-1,1).
!>         Si N es al menos 4, todas las entradas en las dos primeras filas y la última
!>         fila, y la primera columna y las dos últimas columnas son cero.
!>    (20) Igual que (19), pero multiplicado por una constante cercana
!>         al umbral de desbordamiento.
!>    (21) Igual que (19), pero multiplicado por una constante cercana
!>         al umbral de subdesbordamiento.
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          SDRVES no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es un array INTEGER, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SDRVES
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1

NAME

sdrves - This subroutine tests the nonsymmetric eigenvalue routines.

SYNOPSIS

   SUBROUTINE SDRVES( NSIZES, NN, NTYPES, THRESH, NOUNIT,
  &                  A, LDA, H, HT, WR, WI, WRT, WIT, VS, LDVS,
  &                  RESULT, WORK, NWORK, IWORK, BWORK, INFO )

Function/Subroutine Documentation

This subroutine tests the nonsymmetric eigenvalue routines.

NSIZES 
NSIZES is INTEGER
The number of values of N to test.
NN 
NN is INTEGER array, dimension (NSIZES)
The dimensions of the matrices to be tested.
NTYPES 
NTYPES is INTEGER
The number of matrix types to be tested.
THRESH 
THRESH is REAL
A test will count as failed if the relative error in the computed
eigenvalue or eigenvector exceeds THRESH. A test also fails if the
calculated residual is greater than THRESH.
NOUNIT 
NOUNIT is INTEGER
The FORTRAN unit number for printing error messages.
A 
A is REAL array, dimension (LDA, max(NN))
Used to hold the matrix whose eigenvalues are to be computed. On exit,
A contains the last matrix actually used.
LDA 
LDA is INTEGER
The leading dimension of A, and H. LDA must be at least 1 and at least
max(NN).
H 
H is REAL array, dimension (LDA, max(NN))
Another copy of the test matrix A, modified by SGEES.
HT 
HT is REAL array, dimension (LDA, max(NN))
Yet another copy of the test matrix A, modified by SGEES.
WR 
WR is REAL array, dimension (max(NN))
WI 
WI is REAL array, dimension (max(NN))
The real and imaginary parts of the eigenvalues of A. On exit, WR + WI*i
are the eigenvalues of the matrix in A.
WRT 
WRT is REAL array, dimension (max(NN))
WIT 
WIT is REAL array, dimension (max(NN))
Like WR, WI, these arrays contain the eigenvalues of A, but those
computed when SGEES only computes a partial eigendecomposition, i.e.
not Schur vectors.
VS 
VS is REAL array, dimension (LDVS, max(NN))
VS holds the computed Schur vectors.
LDVS 
LDVS is INTEGER
Leading dimension of VS. Must be at least max(1,max(NN)).
RESULT 
RESULT is REAL array, dimension (13)
The values computed by the 13 tests described above. The values are
currently limited to 1/ulp, to avoid overflow.
WORK 
WORK is REAL array, dimension (NWORK)
NWORK 
NWORK is INTEGER
The number of entries in WORK. This must be at least
5*NN(j)+2*NN(j)**2 for all j.
IWORK 
IWORK is INTEGER array, dimension (max(NN))
BWORK 
BWORK is LOGICAL array, dimension (max(NN))
INFO 
INFO is INTEGER
If 0, then everything ran OK.
-1: NSIZES < 0
-2: Some NN(j) < 0
-3: NTYPES < 0
-6: THRESH < 0
-9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ).
-17: LDVS < 1 or LDVS < NMAX, where NMAX is max( NN(j) ).
-20: NWORK too small.
If SLATMR, SLATMS, SLATME or SGEES returns an error code,
the absolute value of it is returned.
-----------------------------------------------------------------------

     Some Local Variables and Parameters:
     ---- ----- --------- --- ----------

     ZERO, ONE       Real 0 and 1.
     MAXTYP          The number of types defined.
     NMAX            Largest value in NN.
     NERRS           The number of tests which have exceeded THRESH
     COND, CONDS,
     IMODE           Values to be passed to the matrix generators.
     ANORM           Norm of A; passed to matrix generators.

     OVFL, UNFL      Overflow and underflow thresholds.
     ULP, ULPINV     Finest relative precision and its inverse.
     RTULP, RTULPI   Square roots of the previous 4 values.

            The following four arrays decode JTYPE:
     KTYPE(j)        The general type (1-10) for type .
     KMODE(j)        The MODE value to be passed to the matrix
                     generator for type .
     KMAGN(j)        The order of magnitude ( O(1),
                     O(overflow^(1/2) ), O(underflow^(1/2) )
     KCONDS(j)       Selectw whether CONDS is to be 1 or
                     1/sqrt(ulp).  (0 means irrelevant.)
