Documentación de la función/subrutina

subrutina sdrges (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, real, dimension( lda, * ) a, integer lda, real, dimension( lda, * ) b, real, dimension( lda, * ) s, real, dimension( lda, * ) t, real, dimension( ldq, * ) q, integer ldq, real, dimension( ldq, * ) z, real, dimension( * ) alphar, real, dimension( * ) alphai, real, dimension( * ) beta, real, dimension( * ) work, integer lwork, real, dimension( 13 ) result, logical, dimension( * ) bwork, integer info)

SDRGES

Propósito:

!>
!> SDRGES comprueba el controlador del problema del valor propio generalizado no simétrico (forma de Schur)
!> SGGES.
!>
!> SGGES factoriza A y B como Q S Z'  y Q T Z' , donde ' significa
!> transpuesta, T es triangular superior, S está en forma de Schur generalizada
!> (bloque triangular superior, con bloques de 1x1 y 2x2 en la diagonal,
!> los bloques de 2x2 correspondientes a pares conjugados complejos de
!> valores propios generalizados), y Q y Z son ortogonales. También
!> calcula los valores propios generalizados (alpha(j),beta(j)), j=1,...,n,
!> Por lo tanto, w(j) = alpha(j)/beta(j) es una raíz de la característica
!> ecuación
!>                 det( A - w(j) B ) = 0
!> Opcionalmente, también reordena los valores propios para que un clúster
!> seleccionado de valores propios aparezca en el bloque diagonal principal de
!> las formas de Schur.
!>
!> Cuando se llama a SDRGES, se especifica un número de tamaños de matriz ()
!> y un número de tipos de matriz. Para cada tamaño ()
!> y cada TIPO de matriz, se generará un par de matrices (A, B)
!> y se utilizará para las pruebas. Para cada par de matrices, se realizarán las siguientes 13 pruebas
!> y se compararán con el umbral THRESH, excepto
!> las pruebas (5), (11) y (13).
!>
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp ) (sin ordenación de valores propios)
!>
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp ) (sin ordenación de valores propios)
!>
!>
!> (3)   | I - QQ' | / ( n ulp ) (sin ordenación de valores propios)
!>
!>
!> (4)   | I - ZZ' | / ( n ulp ) (sin ordenación de valores propios)
!>
!> (5)   si A está en forma de Schur (es decir, forma cuasi-triangular)
!>       (sin ordenación de valores propios)
!>
!> (6)   si los valores propios = bloques diagonales de la forma de Schur (S, T),
!>       es decir, prueba el máximo sobre j de D(j)  donde:
!>
!>       si alpha(j) es real:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) es complejo:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>       y S y T son aquí los bloques diagonales de 2x2 de S y T
!>       correspondientes a los valores propios j-ésimo y (j+1)-ésimo.
!>       (sin ordenación de valores propios)
!>
!> (7)   | (A,B) - Q (S,T) Z' | / ( | (A,B) | n ulp )
!>            (con ordenación de valores propios).
!>
!> (8)   | I - QQ' | / ( n ulp ) (con ordenación de valores propios).
!>
!> (9)   | I - ZZ' | / ( n ulp ) (con ordenación de valores propios).
!>
!> (10)  si A está en forma de Schur (es decir, forma cuasi-triangular)
!>       (con ordenación de valores propios).
!>
!> (11)  si los valores propios = bloques diagonales de la forma de Schur (S, T),
!>       es decir, prueba el máximo sobre j de D(j)  donde:
!>
!>       si alpha(j) es real:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) es complejo:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>       y S y T son aquí los bloques diagonales de 2x2 de S y T
!>       correspondientes a los valores propios j-ésimo y (j+1)-ésimo.
!>       (con ordenación de valores propios).
!>
!> (12)  si la ordenación funcionó y SDIM es el número de valores propios
!>       que fueron SELECCIONADOS.
!>
!> Matrices de prueba
!> =============
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los tipos de matriz se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., se generará el tipo de matriz j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una identidad y una matriz cero)
!>
!> (3)  ( 0, I )         (una identidad y una matriz cero)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad kxk y J un bloque de Jordan (k+1)x(k+1)
!>                       k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es diag( 0, 1,..., N-1 ) (una matriz diagonal
!>                       con esas entradas diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde big es cercano al desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z    donde T1 y T2 son matrices triangulares superiores
!>                        con entradas aleatorias O(1) por encima de la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de máquina.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorias.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>

Function/Subroutine Documentation

This routine is the driver program for the generalized Schur decomposition.

It is a matrix generator and tester for the subroutine SGGES.

SDRGES sets up parameters and calls the appropriate test routines.

  SDRGES generates random matrices A and B and checks the routine SGGES.
  Type 1 and 2 tests generate non-singular matrices.
  Type 1 tests check the generation of non-singular matrices.
  Type 2 tests check the computation of the generalized Schur
  decomposition of non-singular matrices.

  Types 3, 4 and 5 test the computation of the generalized Schur
  decomposition.
  Type 3 tests check the computation of the generalized Schur
  decomposition of matrices that are already in generalized Schur
  form.
  Type 4 tests check the computation of the generalized Schur
  decomposition of singular matrices.
  Type 5 tests check the computation of the generalized Schur
  decomposition of matrices that are almost singular.

  Type 6 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 7 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 8 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 9 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 10 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 11 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 12 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 13 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 14 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 15 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 16 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 17 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 18 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 19 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 20 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 21 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 22 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 23 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 24 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 25 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.
  Type 26 tests check the computation of the generalized Schur
  decomposition of matrices with various structures.

  The following special matrix types are supported:
  0. Random triangular matrices
  1. Random matrices
  2. Random matrices with R = U*S*V**T, where S is diagonal with
     eigenvalues on the diagonal.
  3. Random matrices with R = U*S*V**T, where S is diagonal with
     eigenvalues on the diagonal and U and V are random orthogonal
     matrices.
  4. Random matrices with R = U*S*V**T, where S is diagonal with
     eigenvalues on the diagonal and U and V are random unitary
     matrices.
  5. Random matrices in generalized Schur form
     diag(T1) = ( 0, 1, ..., 1, 0, 0 )
  6. Random matrices in generalized Schur form
     diag(T2) = ( 0, 1, ..., 1, 0, 0 )

(26) Q ( T1, T2 ) Z     where T1 and T2 are random upper-triangular
                         matrices.

Parameters

NSIZES 
!>          NSIZES is INTEGER
!>          The number of sizes of matrices to use.  If it is zero,
!>          SDRGES does nothing.  NSIZES >= 0.
!>

NN

!>          NN is INTEGER array, dimension (NSIZES)
!>          An array containing the sizes to be used for the matrices.
!>          Zero values will be skipped.  NN >= 0.
!>

NTYPES

!>          NTYPES is INTEGER
!>          The number of elements in DOTYPE.   If it is zero, SDRGES
!>          does nothing.  It must be at least zero.  If it is MAXTYP+1
!>          and NSIZES is 1, then an additional type, MAXTYP+1 is
!>          defined, which is to use whatever matrix is in A on input.
!>          This is only useful if DOTYPE(1:MAXTYP) is .FALSE. and
!>          DOTYPE(MAXTYP+1) is .TRUE. .
!>

DOTYPE

!>          DOTYPE is LOGICAL array, dimension (NTYPES)
!>          If DOTYPE(j) is .TRUE., then for each size in NN a
!>          matrix of that size and of type j will be generated.
!>          If NTYPES is smaller than the maximum number of types
!>          defined (PARAMETER MAXTYP), then types NTYPES+1 through
!>          MAXTYP will not be generated. If NTYPES is larger
!>          than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!>          will be ignored.
!>

ISEED

!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096. Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to SDRGES to continue the same random number
!>          sequence.
!>

THRESH

!>          THRESH is REAL
!>          A test will count as  if the , computed as
!>          described above, exceeds THRESH.  Note that the error is
!>          scaled to be O(1), so THRESH should be a reasonably small
!>          multiple of 1, e.g., 10 or 100.  In particular, it should
!>          not depend on the precision (single vs. double) or the size
!>          of the matrix.  THRESH >= 0.
!>

NOUNIT

!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IINFO not equal to 0.)
!>

A

!>          A is REAL array,
!>                                       dimension(LDA, max(NN))
!>          Used to hold the original A matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of A, B, S, and T.
!>          It must be at least 1 and at least max( NN ).
!>

B

!>          B is REAL array,
!>                                       dimension(LDA, max(NN))
!>          Used to hold the original B matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!>          S is REAL array, dimension (LDA, max(NN))
!>          The Schur form matrix computed from A by SGGES.  On exit, S
!>          contains the Schur form matrix corresponding to the matrix
!>          in A.
!>

T

!>          T is REAL array, dimension (LDA, max(NN))
!>          The upper triangular matrix computed from B by SGGES.
!>

Q

!>          Q is REAL array, dimension (LDQ, max(NN))
!>          The (left) orthogonal matrix computed by SGGES.
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of Q and Z. It must
!>          be at least 1 and at least max( NN ).
!>

Z

!>          Z is REAL array, dimension( LDQ, max(NN) )
!>          The (right) orthogonal matrix computed by SGGES.
!>

ALPHAR

!>          ALPHAR is REAL array, dimension (max(NN))
!>

ALPHAI

!>          ALPHAI is REAL array, dimension (max(NN))
!>

BETA

!>          BETA is REAL array, dimension (max(NN))
!>
!>          The generalized eigenvalues of (A,B) computed by SGGES.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) is the k-th

WORK

!>          WORK is REAL array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.

!>          RESULT is REAL array, dimension (15)
!>          The values computed by the tests described above.
!>          The values are currently limited to 1/ulp, to avoid overflow.

!>          BWORK is LOGICAL array, dimension (N)
!>

!>          INFO is INTEGER
!>          = 0:  successful exit
