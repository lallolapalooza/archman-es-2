sd_event_source_set_destroy_callback(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_EVENT_SOURCE_SET_DESTROY_CALLBACK(3) sd_event_source_set_destroy_callback SD_EVENT_SOURCE_SET_DESTROY_CALLBACK(3)

NOMBRE

sd_event_source_set_destroy_callback, sd_event_source_get_destroy_callback, sd_event_destroy_t - Definir la función de devolución de llamada para la limpieza de recursos

SINOPSIS

#include <systemd/sd-event.h>

typedef int (*sd_event_destroy_t)(void *userdata);

int sd_event_source_set_destroy_callback(sd_event_source *source, sd_event_destroy_t callback);

int sd_event_source_get_destroy_callback(sd_event_source *source, sd_event_destroy_t *callback);

DESCRIPCIÓN

sd_event_source_set_destroy_callback() establece callback como la función de devolución de llamada que se llamará justo antes de que el objeto de origen de eventos source sea desasignado. El puntero userdata del objeto de origen de eventos se pasará como parámetro userdata. Este puntero puede establecerse mediante un argumento a las funciones constructoras, véase sd_event_add_io(3), o directamente, véase sd_event_source_set_userdata(3). Esta función de devolución de llamada se llama incluso si userdata es NULL. Tenga en cuenta que esta devolución de llamada se invoca en un momento en que el propio objeto de origen de eventos ya está invalidado, y no está permitido ejecutar operaciones o tomar nuevas referencias al objeto de origen de eventos.

sd_event_source_get_destroy_callback() devuelve la devolución de llamada actual para source en el parámetro callback.

VALOR DE RETORNO

En caso de éxito, sd_event_source_set_destroy_callback() devuelve 0 o un entero positivo. En caso de fallo, devuelve un código de error negativo al estilo errno.

sd_event_source_get_destroy_callback() devuelve positivo si la función de devolución de llamada de destrucción está establecida, 0 si no. En caso de fallo, devuelve un código de error negativo al estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El parámetro source es NULL.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_event_destroy_t(), sd_event_source_set_destroy_callback() y sd_event_source_get_destroy_callback() se añadieron en la versión 239.
