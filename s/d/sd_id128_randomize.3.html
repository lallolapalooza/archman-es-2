SD_ID128_RANDOMIZE(3) sd_id128_randomize SD_ID128_RANDOMIZE(3)

NOMBRE

sd_id128_randomize - Generar IDs de 128 bits

SINOPSIS

#include <systemd/sd-id128.h>

int sd_id128_randomize(sd_id128_t *ret);

DESCRIPCIÓN

sd_id128_randomize() genera un nuevo ID aleatorio de 128 bits y lo devuelve en ret. Cada invocación devuelve un nuevo ID generado aleatoriamente. Utiliza el generador de números aleatorios del kernel getrandom(2).

Tenga en cuenta que sd_id128_randomize() siempre devuelve un ID compatible con UUID Variante 1 Versión 4. Por lo tanto, está garantizado que esta función nunca devolverá el ID que consiste en todos los bits cero o todos los bits uno (SD_ID128_NULL, SD_ID128_ALLF).

Para más información sobre el tipo "sd_id128_t", consulte sd-id128(3).

El comando new de systemd-id128(1) puede ser utilizado como una interfaz de línea de comandos para sd_id128_randomize().

VALOR DE RETORNO

La llamada devuelve 0 en caso de éxito (en cuyo caso ret se rellena) o un código de error negativo estilo errno.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para múltiples hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se han iniciado otros hilos.

HISTORIA

sd_id128_randomize() se añadió en la versión 187.
