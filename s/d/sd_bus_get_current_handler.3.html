sd_bus_get_current_handler(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_GET_CURRENT_HANDLER(3) sd_bus_get_current_handler SD_BUS_GET_CURRENT_HANDLER(3)

NOMBRE

sd_bus_get_current_handler, sd_bus_get_current_message, sd_bus_get_current_slot, sd_bus_get_current_userdata - Consultar información del callback con el que se está ejecutando actualmente un objeto de bus

SINOPSIS

#include <systemd/sd-bus.h>

typedef int (*sd_bus_message_handler_t)(sd_bus_message *m, void *userdata, sd_bus_error *ret_error);

sd_bus_message_handler_t sd_bus_get_current_handler(sd_bus *bus);

sd_bus_message* sd_bus_get_current_message(sd_bus *bus);

sd_bus_slot* sd_bus_get_current_slot(sd_bus *bus);

void* sd_bus_get_current_userdata(sd_bus *bus);

DESCRIPCIÓN

Cada vez que sd-bus está a punto de invocar una función de callback suministrada por el usuario, almacena el callback actual, el mensaje D-Bus, la ranura (slot) y el puntero de datos de usuario y permite consultarlos a través de sd_bus_get_current_handler(), sd_bus_get_current_message(), sd_bus_get_current_slot() y sd_bus_get_current_userdata(), respectivamente. Si bus no se puede resolver o si la ejecución no reside en un callback suministrado por el usuario de bus, estas funciones devuelven NULL.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el objeto solicitado. En caso de error, devuelven NULL.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_get_current_handler(), sd_bus_get_current_message(), sd_bus_get_current_slot() y sd_bus_get_current_userdata() se añadieron en la versión 221.
