subrutina sdrvbd (integer nsizes, integer, dimension( * ) mm, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, real, dimension( lda, * ) a, integer lda, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldvt, * ) vt, integer ldvt, real, dimension( lda, * ) asav, real, dimension( ldu, * ) usav, real, dimension( ldvt, * ) vtsav, real, dimension( * ) s, real, dimension( * ) ssav, real, dimension( * ) e, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer nout, integer info)

SDRVBD

Propósito:

!>
!> SDRVBD comprueba los drivers de la descomposición en valores singulares (SVD)
!> SGESVD, SGESDD, SGESVDQ, SGESVJ, SGEJSV y DGESVDX.
!>
!> Tanto SGESVD como SGESDD factorizan A = U diag(S) VT, donde U y VT son
!> ortogonales y diag(S) es diagonal con las entradas del array S
!> en su diagonal. Las entradas de S son los valores singulares,
!> no negativos y almacenados en orden decreciente. U y VT pueden
!> opcionalmente no calcularse, sobrescribirse en A, o calcularse parcialmente.
!>
!> A es M por N. Sea MNMIN = min( M, N ). S tiene dimensión MNMIN.
!> U puede ser M por M o M por MNMIN. VT puede ser N por N o MNMIN por N.
!>
!> Cuando se llama a SDRVBD, se especifican una serie de tamaños de matrices (M's y N's)
!> y una serie de tipos de matrices. Para cada tamaño (M,N)
!> y cada tipo de matriz, y para el espacio de trabajo mínimo así como
!> el espacio de trabajo adecuado para permitir el bloqueo, se generará
!> una matriz M x N y se utilizará para probar las rutinas SVD. Para cada matriz, A será
!> factorizada como A = U diag(S) VT y se computarán las siguientes 12 pruebas:
!>
!> Prueba para SGESVD:
!>
!> (1)    | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (2)    | I - U'U | / ( M ulp )
!>
!> (3)    | I - VT VT' | / ( N ulp )
!>
!> (4)    S contiene MNMIN valores no negativos en orden decreciente.
!>        (Retorna 0 si es verdadero, 1/ULP si es falso.)
!>
!> (5)    | U - Upartial | / ( M ulp ) donde Upartial es una U calculada parcialmente.
!>
!> (6)    | VT - VTpartial | / ( N ulp ) donde VTpartial es una VT calculada parcialmente.
!>
!> (7)    | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>        vector de valores singulares de la SVD parcial
!>
!> Prueba para SGESDD:
!>
!> (8)    | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (9)    | I - U'U | / ( M ulp )
!>
!> (10)   | I - VT VT' | / ( N ulp )
!>
!> (11)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Retorna 0 si es verdadero, 1/ULP si es falso.)
!>
!> (12)   | U - Upartial | / ( M ulp ) donde Upartial es una U calculada parcialmente.
!>
!> (13)   | VT - VTpartial | / ( N ulp ) donde VTpartial es una VT calculada parcialmente.
!>
!> (14)   | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>        vector de valores singulares de la SVD parcial
!>
!> Prueba para SGESVDQ:
!>
!> (36)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (37)   | I - U'U | / ( M ulp )
!>
!> (38)   | I - VT VT' | / ( N ulp )
!>
!> (39)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Retorna 0 si es verdadero, 1/ULP si es falso.)
!>
!> Prueba para SGESVJ:
!>
!> (15)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (16)   | I - U'U | / ( M ulp )
!>
!> (17)   | I - VT VT' | / ( N ulp )
!>
!> (18)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Retorna 0 si es verdadero, 1/ULP si es falso.)
!>
!> Prueba para SGEJSV:
!>
!> (19)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (20)   | I - U'U | / ( M ulp )
!>
!> (21)   | I - VT VT' | / ( N ulp )
!>
!> (22)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Retorna 0 si es verdadero, 1/ULP si es falso.)
!>
!> Prueba para SGESVDX( 'V', 'V', 'A' )/SGESVDX( 'N', 'N', 'A' )
!>
!> (23)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (24)   | I - U'U | / ( M ulp )
!>
!> (25)   | I - VT VT' | / ( N ulp )
!>
!> (26)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Retorna 0 si es verdadero, 1/ULP si es falso.)
!>
!> (27)   | U - Upartial | / ( M ulp ) donde Upartial es una U calculada parcialmente.
!>
!> (28)   | VT - VTpartial | / ( N ulp ) donde VTpartial es una VT calculada parcialmente.
!>
!> (29)   | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>        vector de valores singulares de la SVD parcial
!>
!> Prueba para SGESVDX( 'V', 'V', 'I' )
!>
!> (30)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (31)   | I - U'U | / ( M ulp )
!>
!> (32)   | I - VT VT' | / ( N ulp )
!>
!> Prueba para SGESVDX( 'V', 'V', 'V' )
!>
!> (33)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (34)   | I - U'U | / ( M ulp )
!>
!> (35)   | I - VT VT' | / ( N ulp )
!>
!> Los tamaños de matriz (M,N) se especifican mediante los arrays MM(1:NSIZES) y
!> NN(1:NSIZES); el valor de cada par de elementos (MM(j),NN(j))
!> especifica un tamaño. Los tipos de matriz se especifican mediante un array lógico
!> DOTYPE( 1:NTYPES ); si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!> (3)  Una matriz de la forma U D V, donde U y V son ortogonales y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!> (4)  Igual que (3), pero multiplicada por el umbral de subdesbordamiento / ULP.
!> (5)  Igual que (3), pero multiplicada por el umbral de rebordeamiento * ULP.
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matriz (M,N) contenidos en los vectores
!>          MM y NN.
!>

MM

!>          MM es un array INTEGER, de dimensión (NSIZES)
!>          Los valores de la dimensión de fila de la matriz M.
!>

NN

!>          NN es un array INTEGER, de dimensión (NSIZES)
!>          Los valores de la dimensión de columna de la matriz N.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SDRVBD
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar las matrices que estén en A y B.
!>          Esto solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño (m,n), se generará una matriz
!>          de tipo j. Si NTYPES es menor que el
!>          número máximo de tipos definidos (PARAMETER MAXTYP), entonces
!>          los tipos NTYPES+1 a MAXTYP no se generarán. Si
!>          NTYPES es mayor que MAXTYP, DOTYPE(MAXTYP+1) a
!>          DOTYPE(NTYPES) serán ignorados.
!>

ISEED

!>          ISEED es un array INTEGER, de dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios. Los elementos
!>          del array deben estar entre 0 y 4095; si no, se reducirán módulo 4096.
!>          Además, ISEED(4) debe ser impar.
!>          En la salida, ISEED se modifica y puede usarse en la siguiente llamada a
!> sdrvbd
!>          para generar el mismo conjunto de pruebas.
!>

THRESH

!>          THRESH es REAL
!>          Un umbral de tolerancia para las pruebas relativas. Para pruebas relativas,
!>          se espera que el error sea menor o igual a THRESH * ULPs.
!>

A

!>          A es un array REAL, de dimensión (LDA, *)
!>          En la entrada, A contiene la matriz a factorizar. Si DOTYPE(MAXTYP+1) es
!>          .TRUE., entonces A contendrá la matriz a utilizar.
!>          En la salida, A se sobrescribe con U y VT, dependiendo de los argumentos
!>          de las rutinas SVD.
!>

LDA

!>          LDA es INTEGER
!>          El dimensionamiento de la primera dimensión de A. LDA debe ser al menos
!>          max(1, M).
!>

U

!>          U es un array REAL, de dimensión (LDU, *)
!>          En la salida, U contiene la matriz ortogonal de la izquierda.
!>

LDU

!>          LDU es INTEGER
!>          El dimensionamiento de la primera dimensión de U. LDU debe ser al menos
!>          max(1, M).
!>

VT

!>          VT es un array REAL, de dimensión (LDVT, *)
!>          En la salida, VT contiene la matriz ortogonal de la derecha (transpuesta).
!>

LDVT

!>          LDVT es INTEGER
!>          El dimensionamiento de la primera dimensión de VT. LDVT debe ser al menos
!>          max(1, min(M,N)).
!>

ASAV

!>          ASAV es un array REAL, de dimensión (LDA, *)
!>          Una copia de la matriz A en la entrada.
!>

USAV

!>          USAV es un array REAL, de dimensión (LDU, *)
!>          Una copia de la matriz U.
!>

VTSAV

!>          VTSAV es un array REAL, de dimensión (LDVT, *)
!>          Una copia de la matriz VT.
!>

S

!>          S es un array REAL, de dimensión (*)
!>          En la salida, S contiene los valores singulares de A, en orden decreciente.
!>

SSAV

!>          SSAV es un array REAL, de dimensión (*)
!>          Una copia del array S.
!>

E

!>          E es un array REAL, de dimensión (*)
!>          Este argumento es necesario para la compatibilidad de la interfaz, pero no se utiliza.
!>

WORK

!>          WORK es un array REAL, de dimensión (*)
!>          Un array de trabajo. El tamaño de WORK depende de los parámetros de las
!>          rutinas SVD que se estén probando. SDRVBD determinará el tamaño
!>          requerido y lo almacenará en LWORK.
!>

LWORK

!>          LWORK es INTEGER
!>          El tamaño del array WORK. Si LWORK es demasiado pequeño, SDRVBD devolverá
!>          un código de error. Se utiliza un valor negativo para indicar el tamaño
!>          requerido para la ejecución.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (*)
!>          Un array de trabajo para enteros. El tamaño de IWORK depende de los
!>          parámetros de las rutinas SVD que se estén probando. SDRVBD determinará
!>          el tamaño requerido.
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad de salida para los informes de prueba.
!>

INFO

!>          INFO es INTEGER
!>          INFO = 0:  Prueba correcta.
!>          INFO < 0:  Número de error del argumento. Si INFO = -k, el k-ésimo
!>                     argumento tuvo un valor prohibido. Si INFO = -32,
!>                     significa que LWORK es demasiado pequeño.
!>          INFO > 0:  Un error de la rutina SVD. El valor de INFO depende de la
!>                     rutina SVD que falló.
!>

EJEMPLO

Este es un fragmento de un programa de prueba que invoca a SDRVBD:

PROGRAM TESTDRVBD
  IMPLICIT NONE
  INTEGER NSIZES, NTYPES, NOUT, INFO, LWORK, LDA, LDU, LDVT
  PARAMETER (NSIZES=2, NTYPES=5, NOUT=6)
  INTEGER MM(NSIZES), NN(NSIZES), IWORK(*)
  LOGICAL DOTYPE(NTYPES)
  REAL THRESH, A(20,20), U(20,20), VT(20,20), ASAV(20,20)
  REAL USAV(20,20), VTSAV(20,20), S(20), SSAV(20), E(20)
  REAL WORK(*)
  INTEGER ISEED(4)
  INTEGER J, K, M, N, MNMIN

  SAVE ISEED / 1984, 2, 0, 1 /

  DO K = 1, NTYPES
     DOTYPE(K) = .TRUE.
  END DO
  !DOTYPE(5) = .FALSE.

  MM(1) = 6; NN(1) = 4
  MM(2) = 8; NN(2) = 3

  ! Calcular el tamaño del espacio de trabajo requerido
  ! Para este ejemplo, estimamos un tamaño LWORK = 4000
  LWORK = 4000
  ALLOCATE (WORK(LWORK))
  ALLOCATE (IWORK(100)) ! Estimamos un tamaño para IWORK

  CALL SDRVBD(NSIZES, MM, NN, NTYPES, DOTYPE, ISEED, THRESH,
 &             A, LDA, U, LDU, VT, LDVT, ASAV, USAV, VTSAV,
 &             S, SSAV, E, WORK, LWORK, IWORK, NOUT, INFO)

  IF (INFO .NE. 0) THEN
     PRINT *, '*** SDRVBD falló con INFO = ', INFO
  ELSE
     PRINT *, 'SDRVBD completado con éxito.'
  END IF

  DEALLOCATE (WORK)
  DEALLOCATE (IWORK)
END PROGRAM TESTDRVBD

Para ejecutar este ejemplo:

  1. Compile el código usando un compilador Fortran (por ejemplo, gfortran).
  2. Ejecute el programa compilado.

La salida mostrará si las pruebas de SDRVBD se completaron con éxito o si hubo algún error.

sdrvbd(3) — LAPACK

NAME

sdrvbd - distributed driver routine for the divide and conquer SVD

SYNOPSIS

 CALL SDRVBD( NMAX, MMAX, NN, MM, NTIPES, TYPES, THRESH, A, LDA, &
                 U, LDU, VT, LDVT, ASAV, USAV, VTSAV, S, SSAV, E, WORK, LWORK, &
                 IWORK, NOUT, INFO )

Function/Subroutine Documentation

NMAX

NMAX is INTEGER

The maximum value of dimension N in NN.

MMAX

MMAX is INTEGER

The maximum value of dimension M in MM.

NN

NN is INTEGER array, dimension (NSIZES)

An array of dimensions of the matrices to be used.

MM

MM is INTEGER array, dimension (NSIZES)

An array of dimensions of the matrices to be used.

NTIPES

NTIPES is INTEGER

The number of types of matrices to be tested.

TYPES

TYPES is INTEGER array, dimension (NTIPES)

The particular types of matrices to be tested. Each type is an integer whose value is between 0 and 16, inclusive. The value of each type is determined by the SLATMS routine.

THRESH

THRESH is REAL

The threshold value for the test ratios. A result is included in the output file if RESULT >= THRESH. The test ratios are scaled to be O(1), so THRESH should be a small multiple of 1, e.g., 10 or 100. To have every test ratio printed, use THRESH = 0.

A

A is REAL array, dimension (LDA,NMAX)

where NMAX is the maximum value of N in NN.

LDA

LDA is INTEGER

The leading dimension of the array A. LDA >= max(1,MMAX), where MMAX is the maximum value of M in MM.

U

U is REAL array, dimension (LDU,MMAX)

LDU

LDU is INTEGER

The leading dimension of the array U. LDU >= max(1,MMAX).

VT

VT is REAL array, dimension (LDVT,NMAX)

LDVT

LDVT is INTEGER

The leading dimension of the array VT. LDVT >= max(1,NMAX).

ASAV

ASAV is REAL array, dimension (LDA,NMAX)

USAV

USAV is REAL array, dimension (LDU,MMAX)

VTSAV

VTSAV is REAL array, dimension (LDVT,NMAX)

S

S is REAL array, dimension (max(min(MM,NN)))

SSAV

SSAV is REAL array, dimension (max(min(MM,NN)))

E

E is REAL array, dimension (max(min(MM,NN)))

WORK

WORK is REAL array, dimension (LWORK)

LWORK

LWORK is INTEGER

The number of entries in WORK. This must be at least max(3*MN+MX,5*MN-4)+2*MN**2 for all pairs pairs (MN,MX)=( min(MM(j),NN(j), max(MM(j),NN(j)) )

IWORK

IWORK is INTEGER array, dimension at least 8*min(M,N)

NOUT

NOUT is INTEGER

The FORTRAN unit number for printing out error messages (e.g., if a routine returns IINFO not equal to 0.)

INFO

INFO is INTEGER

If 0, then everything ran OK.

-1: NSIZES < 0

-2: Some MM(j) < 0

-3: Some NN(j) < 0

-4: NTYPES < 0

-7: THRESH < 0

-10: LDA < 1 or LDA < MMAX, where MMAX is max( MM(j) ).

-12: LDU < 1 or LDU < MMAX.

-14: LDVT < 1 or LDVT < NMAX, where NMAX is max( NN(j) ).

-21: LWORK too small.

If SLATMS, or SGESVD returns an error code, the absolute value of it is returned.
