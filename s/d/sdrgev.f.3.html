Documentación de Función/Subrutina

subroutine sdrgev (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, real, dimension( lda, * ) a, integer lda, real, dimension( lda, * ) b, real, dimension( lda, * ) s, real, dimension( lda, * ) t, real, dimension( ldq, * ) q, integer ldq, real, dimension( ldq, * ) z, real, dimension( ldqe, * ) qe, integer ldqe, real, dimension( * ) alphar, real, dimension( * ) alphai, real, dimension( * ) beta, real, dimension( * ) alphr1, real, dimension( * ) alphi1, real, dimension( * ) beta1, real, dimension( * ) work, integer lwork, real, dimension( * ) result, integer info)

SDRGEV

Propósito:

!>
!> SDRGEV comprueba la subrutina del controlador del problema de valores
!> propios generalizados no simétricos SGGEV.
!>
!> SGGEV calcula para un par de matrices no simétricas n-por-n (A,B) los
!> valores propios generalizados y, opcionalmente, los vectores propios
!> izquierdos y derechos.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una relación alpha/beta = w, tal que A - w*B es singular. Se representa
!> usualmente como el par (alpha,beta), ya que hay una interpretación razonable
!> para beta=0, e incluso para ambos siendo cero.
!>
!> Un vector propio generalizado derecho correspondiente a un valor propio
!> generalizado w para un par de matrices (A,B) es un vector r tal que
!> (A - wB) * r = 0. Un vector propio generalizado izquierdo es un vector l
!> tal que l**H * (A - wB) = 0, donde l**H es la transpuesta conjugada de l.
!>
!> Cuando se llama a SDRGEV, se especifica un número de tamaños de matrices
!> (NN) y un número de tipos de matrices (DOTYPE). Para cada tamaño (NN(j))
!> y cada tipo de matriz, se generará un par de matrices (A, B) y se
!> utilizará para la prueba. Para cada par de matrices, se realizarán las
!> siguientes pruebas y se compararán con el umbral THRESH.
!>
!> Resultados de SGGEV:
!>
!> (1)  máx sobre todos los pares de valores/vectores propios izquierdos
!>      (alpha/beta,l) de
!>
!>      | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>      donde VL**H es la transpuesta conjugada de VL.
!>
!> (2)  | |VL(i)| - 1 | / ulp y si el componente más grande es real
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!> (3)  máx sobre todos los pares de valores/vectores propios izquierdos
!>      (alpha/beta,r) de
!>
!>      | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4)  | |VR(i)| - 1 | / ulp y si el componente más grande es real
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!> (5)  W(completo) = W(parcial)
!>      W(completo) denota los valores propios calculados cuando tanto l
!>      como r también se calculan, y W(parcial) denota los valores propios
!>      calculados cuando solo se calculan W, solo W y r, o solo W y l.
!>
!> (6)  VL(completo) = VL(parcial)
!>      VL(completo) denota los vectores propios izquierdos calculados cuando
!>      tanto l como r se calculan, y VL(parcial) denota el resultado
!>      cuando solo se calcula l.
!>
!> (7)  VR(completo) = VR(parcial)
!>      VR(completo) denota los vectores propios derechos calculados cuando
!>      tanto l como r también se calculan, y VR(parcial) denota el resultado
!>      cuando solo se calcula l.
!>
!>
!> Matrices de Prueba
!> ---- --------
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los tipos de matrices se especifican mediante un array lógico DOTYPE(1:NTYPES);
!> si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una identidad y una matriz cero)
!>
!> (3)  ( 0, I )         (una identidad y una matriz cero)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         donde  X = ( J   0  )  e Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       e I es una identidad k x k y J un bloque de
!>                       Jordan (k+1)x(k+1); k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es diag( 0, 1,..., N-1 ) (una matriz diagonal
!>                       con esas entradas diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde  es cercano al desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z    donde T1 y T2 son matrices triangulares superiores
!>                        con entradas O(1) aleatorias por encima de la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de máquina.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorias.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     donde T1 y T2 son matrices triangulares
!>                         superiores aleatorias.
!>
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar. Si es cero,
!>          SDRGES no hace nada.  NSIZES >= 0.
!>

NN

!>          NN es INTEGER array, dimension (NSIZES)
!>          Un array que contiene los tamaños a usar para las matrices.
!>          Los valores cero serán omitidos.  NN >= 0.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SDRGES
!>          no hace nada. NTYPES >= 0.
!>

DOTYPE

!>          DOTYPE es LOGICAL array, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces el tipo j de matriz
!>          será probado.
!>

ISEED

!>          ISEED es INTEGER array, dimension (4)
!>          La semilla para la generación de números aleatorios. ISEED
!>          se actualiza durante la ejecución de la rutina.
!>

THRESH

!>          THRESH es REAL
!>          Un umbral para las pruebas de error.  Los resultados
!>          mayores que THRESH son considerados fallidos.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          NOUNIT = 0: Se esperan vectores propios unitarios.
!>          NOUNIT = 1: Los vectores propios no necesariamente
!>                    necesitan ser unitarios.
!>

A

!>          A es REAL array, dimension (LDA, *)
!>          En la entrada, A es una matriz N x N. Si DOTYPE(16) o
!>          DOTYPE(26) es .TRUE., A es una matriz de entrada.
!>          Si DOTYPE(17-25) es .TRUE., A es una matriz de entrada.
!>          La matriz N x N puede contener el bloque de Jordan transpuesto
!>          o matrices triangulares superiores. Si DOTYPE(1-15) es .TRUE.,
!>          A es una matriz de salida.
!>

LDA

!>          LDA es INTEGER
!>          La longitud de la primera dimensión de A, B, S, T, Q, Z.
!>          LDA >= max(1, N).
!>

B

!>          B es REAL array, dimension (LDA, *)
!>          En la entrada, B es una matriz N x N. Si DOTYPE(3) o DOTYPE(16)
!>          o DOTYPE(26) es .TRUE., B es una matriz de entrada.
!>          Si DOTYPE(17-25) es .TRUE., B es una matriz de entrada.
!>          Si DOTYPE(1-15) es .TRUE., B es una matriz de salida.
!>

S

!>          S es REAL array, dimension (LDA, *)
!>          S es una matriz de salida N x N.  S contiene la parte
!>          triangular superior de la matriz A en la forma reducida
!>          de Schur.
!>

T

!>          T es REAL array, dimension (LDA, *)
!>          T es una matriz de salida N x N. T contiene la parte
!>          triangular superior de la matriz B en la forma reducida
!>          de Schur.
!>

Q

!>          Q es REAL array, dimension (LDQ, *)
!>          Q es una matriz de salida LDQ x N.  Q contiene los
!>          vectores propios izquierdos de la matriz A en la forma
!>          reducida de Schur.
!>

LDQ

!>          LDQ es INTEGER
!>          La longitud de la primera dimensión de Q y QE. LDQ >= max(1, N).
!>

Z

!>          Z es REAL array, dimension (LDQ, *)
!>          Z es una matriz de salida LDQ x N. Z contiene los
!>          vectores propios derechos de la matriz A en la forma
!>          reducida de Schur.
!>

QE

!>          QE es REAL array, dimension (LDQE, *)
!>          QE es una matriz de salida LDQE x N. QE contiene los
!>          vectores propios izquierdos de la matriz B en la forma
!>          reducida de Schur.
!>

LDQE

!>          LDQE es INTEGER
!>          La longitud de la primera dimensión de QE. LDQE >= max(1, N).
!>

ALPHAR

!>          ALPHAR es REAL array, dimension (*)
!>          ALPHAR es un array de salida de longitud N. ALPHAR y ALPHAI
!>          contienen los numeradores de los valores propios generalizados.
!>

ALPHAI

!>          ALPHAI es REAL array, dimension (*)
!>          ALPHAI es un array de salida de longitud N.
!>

BETA

!>          BETA es REAL array, dimension (*)
!>          BETA es un array de salida de longitud N. BETA contiene los
!>          denominadores de los valores propios generalizados.
!>

ALPHR1

!>          ALPHR1 es REAL array, dimension (*)
!>          ALPHR1 es un array de salida de longitud N. ALPHR1 y ALPHI1
!>          contienen los numeradores de los valores propios generalizados
!>          cuando solo se calculan los valores propios izquierdos.
!>

ALPHI1

!>          ALPHI1 es REAL array, dimension (*)
!>          ALPHI1 es un array de salida de longitud N.
!>

BETA1

!>          BETA1 es REAL array, dimension (*)
!>          BETA1 es un array de salida de longitud N. BETA1 contiene los
!>          denominadores de los valores propios generalizados cuando solo
!>          se calculan los valores propios izquierdos.
!>

WORK

!>          WORK es REAL array, dimension (LWORK)
!>          Un array de trabajo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= max(1, 2*N*N).
!>

RESULT

!>          RESULT es REAL array, dimension (12)
!>          El resultado de las pruebas.  Si RESULT(i) es aproximadamente
!>          cero, entonces la prueba i pasó.  Si RESULT(i) > THRESH,
!>          entonces la prueba i falló.
!>

INFO

!>          INFO es INTEGER
!>          INFO = 0: Se ejecutó correctamente.
!>          INFO < 0: Si INFO = -i, entonces el i-ésimo argumento
!>                    pasó a la rutina SGGEV tenía un valor ilegal.
!>                    Se sabe que INFO = -11, -12, -13, -14, -15, -16, -17
!>                    ó -18.
!>          INFO > 0: Si INFO = i, entonces la rutina SGGEV falló al converger;
!>                    i es el número de iteraciones que se ejecutaron.
!>

DOTYPE

!> DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!> Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!> una matriz de ese tamaño y de tipo j.
!> Si NTYPES es menor que el número máximo de tipos definidos
!> (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!> MAXTYP no se generarán. Si NTYPES es mayor que MAXTYP,
!> DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES) se ignorarán.
!>

ISEED

!> ISEED es un array INTEGER, de dimensión (4)
!> A la entrada, ISEED especifica la semilla del generador de números
!> aleatorios. Los elementos del array deben estar entre 0 y 4095;
!> si no, se reducirán módulo 4096. Además, ISEED(4) debe ser impar.
!> El generador de números aleatorios utiliza una secuencia lineal
!> congruencial limitada a enteros pequeños, por lo que debería
!> producir números aleatorios independientes de la máquina. Los
!> valores de ISEED se modifican a la salida y pueden usarse en la
!> siguiente llamada a SDRGES para continuar la misma secuencia de
!> números aleatorios.
!>

THRESH

!> THRESH es REAL
!> Una prueba se considerará exitosa si la , calculada como
!> se describe arriba, excede THRESH. Tenga en cuenta que el error se
!> escala para ser O(1), por lo que THRESH debería ser un múltiplo
!> razonablemente pequeño de 1, por ejemplo, 10 o 100. En
!> particular, no debería depender de la precisión (simple o doble)
!> ni del tamaño de la matriz. Debe ser como mínimo cero.
!>

NOUNIT

!> NOUNIT es INTEGER
!> El número de unidad FORTRAN para imprimir mensajes de error
!> (por ejemplo, si una rutina devuelve IERR distinto de 0).
!>

A

!> A es un array REAL,
!> de dimensión (LDA, max(NN))
!> Se utiliza para almacenar la matriz A original. Se usa como entrada solo
!> si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!> DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!> LDA es INTEGER
!> La dimensión principal de A, B, S y T.
!> Debe ser al menos 1 y al menos max(NN).
!>

B

!> B es un array REAL,
!> de dimensión (LDA, max(NN))
!> Se utiliza para almacenar la matriz B original. Se usa como entrada solo
!> si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!> DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!> S es un array REAL,
!> de dimensión (LDA, max(NN))
!> La matriz en forma de Schur calculada a partir de A por SGGES. A la
!> salida, S contiene la matriz en forma de Schur correspondiente a la
!> matriz en A.
!>

T

!> T es un array REAL,
!> de dimensión (LDA, max(NN))
!> La matriz triangular superior calculada a partir de B por SGGES.
!>

Q

!> Q es un array REAL,
!> de dimensión (LDQ, max(NN))
!> La matriz (izquierda) de vectores propios calculada por SGGEV.
!>

LDQ

!> LDQ es INTEGER
!> La dimensión principal de Q y Z. Debe
!> ser al menos 1 y al menos max(NN).
!>

Z

!> Z es un array REAL, de dimensión (LDQ, max(NN))
!> La matriz ortogonal (derecha) calculada por SGGES.
!>

QE

!> QE es un array REAL, de dimensión (LDQ, max(NN))
!> QE contiene los vectores propios derechos o izquierdos calculados.
!>

LDQE

!> LDQE es INTEGER
!> La dimensión principal de QE. LDQE >= max(1, max(NN)).
!>

ALPHAR

!> ALPHAR es un array REAL, de dimensión (max(NN))
!>

ALPHAI

!> ALPHAI es un array REAL, de dimensión (max(NN))
!>

BETA

!> BETA es un array REAL, de dimensión (max(NN))
!> \verbatim
!> Los valores propios generalizados de (A,B) calculados por SGGEV.
!> (ALPHAR(k)+ALPHAI(k)*i) / BETA(k) es el k-ésimo
!> valor propio generalizado de A y B.
!>

ALPHR1

!> ALPHR1 es un array REAL, de dimensión (max(NN))
!>

ALPHI1

!> ALPHI1 es un array REAL, de dimensión (max(NN))
!>

BETA1

!> BETA1 es un array REAL, de dimensión (max(NN))
!>
!> Al igual que ALPHAR, ALPHAI, BETA, estos arrays contienen los
!> valores propios de A y B, pero aquellos calculados cuando SGGEV solo
!> calcula una descomposición de valores propios parcial, es decir, no
!> los valores propios ni los vectores propios izquierdos y derechos.
!>

WORK

!> WORK es un array REAL, de dimensión (LWORK)
!>

LWORK

!> LWORK es INTEGER
!> El número de entradas en WORK. LWORK >= MAX( 8*N, N*(N+1) ).
!>

RESULT

!> RESULT es un array REAL, de dimensión (2)
!> Los valores calculados por las pruebas descritas anteriormente.
!> Los valores están actualmente limitados a 1/ulp, para evitar
!> desbordamientos.
!>

INFO

!> INFO es INTEGER
!> = 0: salida exitosa
!> < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!> > 0: una rutina devolvió un código de error. INFO es el
!> valor absoluto del valor INFO devuelto.
!>
