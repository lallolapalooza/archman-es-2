DESCRIPCIÓN

La función sd_device_enumerator_add_match_parent() añade un filtro al enumerator para que solo se enumeren los dispositivos bajo el árbol del dispositivo parent especificado. Si se llama varias veces, el dispositivo parent previamente configurado se borra y solo la última llamada tiene efecto.

La función sd_device_enumerator_add_match_property() añade un filtro al enumerator para que solo se enumeren los dispositivos con la property especificada igual al value. Tanto property como value pueden ser un patrón glob. Cuando se llama varias veces, se enumeran los dispositivos que tienen al menos una de las propiedades especificadas con valores coincidentes. Es decir, los filtros se combinan con OR.

La función sd_device_enumerator_add_match_property_required() añade un filtro al enumerator para que solo se enumeren los dispositivos con la property especificada igual al value. Esta función es similar a sd_device_enumerator_add_match_property(), pero cuando se llama varias veces, se enumeran los dispositivos que tienen *todas* las propiedades especificadas con valores coincidentes. Es decir, los filtros se combinan con AND.

La función sd_device_enumerator_add_match_subsystem() añade un filtro al enumerator para que se enumeren todos los dispositivos del subsystem especificado, cuando match es true. Cuando match es false, se enumeran todos los dispositivos excepto los del subsystem especificado. Cuando se llama varias veces, los filtros positivos se combinan con OR, y los negativos con AND.

La función sd_device_enumerator_add_match_sysattr() añade un filtro al atributo sysfs sysattr que coincida con value. value puede ser un patrón glob. Si value es NULL, se incluyen los dispositivos que tienen (si match es true) o no tienen (si match es false) el sysattr especificado, independientemente de su valor. Es decir, NULL es mayormente equivalente a "*" . Cuando esta función se llama varias veces, solo se enumeran los dispositivos que coinciden con todos los filtros sysattr especificados. Es decir, estos filtros se combinan con AND.

La función sd_device_enumerator_add_match_sysname() añade un filtro para que solo se enumeren los dispositivos cuyo nombre de sistema coincida con sysname. sysname puede ser un patrón glob. Cuando se llama varias veces, los filtros se combinan con OR.

La función sd_device_enumerator_add_nomatch_sysname() añade un filtro para que se excluyan de la enumeración los dispositivos cuyo nombre de sistema coincida con sysname. Esto es útil para excluir dispositivos específicos del proceso de enumeración. Cuando se llama varias veces, las características se combinan con AND.

La función sd_device_enumerator_add_match_tag() añade un filtro para que solo se enumeren los dispositivos etiquetados con tag. Cuando se llama varias veces, los filtros se combinan con OR.

La función sd_device_enumerator_allow_uninitialized() permite que se incluyan en la enumeración los dispositivos que aún no han sido inicializados por udev.

La función sd_device_enumerator_add_all_parents() enumera todos los dispositivos padre de los dispositivos coincidentes. Esto es útil para casos en los que se desean incluir todos los dispositivos padre en la enumeración, como cuando se está interesado en todo el árbol de dispositivos que conduce a un dispositivo específico.

VALOR DE RETORNO

Todas las funciones devuelven 0 o un entero positivo en caso de éxito, o un código de error negativo de estilo errno en caso de fallo.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ENOMEM

Fallo en la asignación de memoria.

-EINVAL

Uno de los argumentos es inválido.

EJEMPLOS

Ejemplo 1. Detectar Dispositivos USB Extraíbles (Usando Coincidencia y Exclusión)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* Crear un nuevo enumerador de dispositivos */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "Fallo al crear el enumerador de dispositivos: %s\n", strerror(-r));
        return 1;
    }
    /* Incluir solo dispositivos del subsistema "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "Fallo al añadir la coincidencia de subsistema: %s\n", strerror(-r));
        return 1;
    }
    /*
     * Excluir dispositivos donde el attr "removable" sea "0"
     * Estos suelen ser dispositivos no extraíbles como interfaces USB integradas
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "Fallo al añadir la coincidencia de sysattr: %s\n", strerror(-r));
        return 1;
    }
    /* Empezar a enumerar los dispositivos coincidentes */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* Obtener el syspath para el dispositivo */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("Dispositivo USB extraíble encontrado: %s\n", syspath);
    }
    return 0;
}

sd_device_enumerator_add_all_parents(3) — systemd libs documentation

NAME

sd_device_enumerator_add_all_parents - Add all parent devices of a device to an enumerator

SYNOPSIS

#include <systemd/sd-device.h>
int sd_device_enumerator_add_all_parents(sd_device_enumerator *enumerator, sd_device *device);

DESCRIPTION

The sd_device_enumerator_add_all_parents() function is used to add all parent devices of the specified device to the enumerator. This is useful if you want to enumerate devices and their ancestors.

The function will recursively find all parent devices until it reaches the root device. Each parent device found will be added to the enumerator.

RETURN VALUE

On success, sd_device_enumerator_add_all_parents() returns a non-negative integer. On failure, it returns a negative errno value.

EXAMPLES

None.

HISTORY

sd_device_enumerator_add_all_parents() was added in version 258.
