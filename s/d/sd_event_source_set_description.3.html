sd_event_source_set_description(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_EVENT_SOURCE_SET_DESCRIPTION(3) sd_event_source_set_description SD_EVENT_SOURCE_SET_DESCRIPTION(3)

NOMBRE

sd_event_source_set_description, sd_event_source_get_description - Establecer u obtener nombres descriptivos de fuentes de eventos

SINOPSIS

#include <systemd/sd-event.h>

int sd_event_source_set_description(sd_event_source *source, const char *description);

int sd_event_source_get_description(sd_event_source *source, const char **ret);

DESCRIPCIÓN

sd_event_source_set_description() puede usarse para establecer un nombre descriptivo arbitrario para el objeto fuente de eventos especificado como source. Este nombre se usará en mensajes de depuración generados por sd-event(3) para esta fuente de eventos, y puede ser consultado usando sd_event_source_get_description() para fines de depuración. El parámetro description debe apuntar a una cadena terminada en NUL o ser NULL. En este último caso, el nombre descriptivo se eliminará. La cadena se copia internamente, por lo tanto, el argumento description no se referencia después de que la función retorna.

sd_event_source_get_description() puede usarse para consultar el nombre descriptivo actual asignado al objeto fuente de eventos source. Devuelve un puntero al nombre actual en ret, almacenado en memoria interna de la fuente de eventos. La memoria se invalida cuando la fuente de eventos se destruye o el nombre descriptivo se cambia.

Las fuentes de eventos generalmente no tienen una descripción establecida cuando se crean, excepto las fuentes de eventos de señales UNIX creadas con sd_event_add_signal(3), cuyo nombre descriptivo se inicializa al nombre constante de la señal en C (por ejemplo, "SIGINT" o "SIGTERM").

VALOR DE RETORNO

En caso de éxito, sd_event_source_set_description() y sd_event_source_get_description() devuelven un entero no negativo. En caso de fallo, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

source no es un puntero válido a un objeto sd_event_source o el argumento description para sd_event_source_get_description() es NULL.

-ENOMEM

No hay suficiente memoria para copiar el nombre.

-ECHILD

El bucle de eventos se creó en un proceso, biblioteca o instancia de módulo diferente.

-ENXIO

No se estableció ningún nombre para la fuente de eventos.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que está declarado como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_event_source_set_description() y sd_event_source_get_description() se añadieron en la versión 229.
