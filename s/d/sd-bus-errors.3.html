DESCRIPCIÓN

Además de los nombres de error que definen los programas de usuario, D-Bus conoce una serie de nombres de error genéricos y estandarizados que se enumeran a continuación.

Además de esta lista, en sd-bus, el espacio de nombres de error especial "System.Error." se utiliza para mapear errores genéricos del sistema Linux (tal como se definen en errno(3)) a errores de D-Bus y viceversa. Por ejemplo, el error EUCLEAN se mapea a "System.Error.EUCLEAN" y viceversa.

SD_BUS_ERROR_FAILED

Una indicación de error genérica. Consulte el mensaje de error para obtener más detalles. Se debe evitar este nombre de error, en favor de un nombre de error más expresivo.

Añadido en la versión 223.

SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
