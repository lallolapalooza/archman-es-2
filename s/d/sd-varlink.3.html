NOMBRE

sd-varlink - APIs para Varlink IPC

SINOPSIS

#include <systemd/sd-varlink.h>

pkg-config --cflags --libs libsystemd

DESCRIPCIÓN

sd-varlink.h es parte de libsystemd(3) y proporciona APIs para implementar clientes y servicios Varlink IPC. Consulte https://varlink.org/ para obtener más información sobre Varlink IPC.

Varlink IPC utiliza JSON[1] como formato de serialización. La API sd-varlink se basa en la API de sd-json(3) para la serialización, deserialización y manipulación de JSON.

La herramienta varlinkctl(1) pone la funcionalidad implementada por sd-varlink a disposición desde la línea de comandos.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

VER TAMBIÉN
