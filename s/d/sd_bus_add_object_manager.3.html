SD_BUS_ADD_OBJECT_MANAGER(3) sd_bus_add_object_manager SD_BUS_ADD_OBJECT_MANAGER(3)

NOMBRE

sd_bus_add_object_manager - Añadir un gestor de objetos D-Bus para un subárbol de objetos D-Bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_add_object_manager(sd_bus *bus, sd_bus_slot **slot, const char *path);

DESCRIPCIÓN

sd_bus_add_object_manager() instala un manejador para la ruta dada que implementa el método GetManagedObjects() de la interfaz org.freedesktop.DBus.ObjectManager. Véase org.freedesktop.DBus.ObjectManager[1] para más información.

Para implementar las señales InterfacesAdded y InterfacesRemoved de la interfaz org.freedesktop.DBus.ObjectManager, llame a sd_bus_emit_interfaces_added(3) y sd_bus_emit_interfaces_removed(3) cada vez que se añadan o eliminen interfaces del subárbol, respectivamente.

Cuando sd_bus_add_object_manager() tiene éxito, se crea internamente un slot. Si el parámetro de salida slot es NULL, se crea un objeto slot "flotante", véase sd_bus_slot_set_floating(3). De lo contrario, se devuelve un puntero al objeto slot. En ese caso, la referencia al objeto slot debe ser eliminada cuando el gestor de objetos ya no sea necesario, véase sd_bus_slot_unref(3).

VALOR DE RETORNO

En caso de éxito, sd_bus_add_object_manager() devuelve un entero no negativo. En caso de error, devuelve un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Uno de los parámetros requeridos es NULL o path no es una ruta de objeto válida.

-ENOPKG

El bus no se puede resolver.

-ECHILD

El bus se creó en un proceso, biblioteca o instancia de módulo diferente.

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config de libsystemd, véase pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_add_object_manager() se añadió en la versión 221.
