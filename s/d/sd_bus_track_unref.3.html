NOMBRE

int sd_bus_track_new(sd_bus* bus, sd_bus_track** ret, sd_bus_track_handler_t handler, void* userdata);

sd_bus_track *sd_bus_track_unref(sd_bus_track *t);

void sd_bus_track_unrefp(sd_bus_track **t);

int sd_bus_track_get_recursive(sd_bus_track *t);

int sd_bus_track_set_recursive(sd_bus_track *t, int b);

sd_bus* sd_bus_track_get_bus(sd_bus_track *t);

void* sd_bus_track_get_userdata(sd_bus_track *t);

void* sd_bus_track_set_userdata(sd_bus_track *t, void *userdata);

DESCRIPCIÓN

sd_bus_track_new() crea un nuevo objeto de rastreo de pares del bus. El objeto se asigna para el bus especificado y se devuelve en el parámetro *ret. Después de su uso, el objeto debe liberarse volviendo a soltar la referencia adquirida con sd_bus_track_unref() (ver más abajo). Un objeto de rastreo de pares del bus puede utilizarse para mantener un registro de los pares en un bus IPC específico, para casos en los que los pares hacen uso de uno o más objetos locales, con el fin de controlar el ciclo de vida de los objetos locales y garantizar que permanezcan activos mientras los pares que los necesitan estén presentes, y se eliminen (y posiblemente se destruyan) tan pronto como todos los pares relevantes hayan desaparecido. Cada objeto de rastreo de pares del bus puede usarse para rastrear cero, uno o más pares a la vez. Las referencias a pares del bus específicos se añaden a través de sd_bus_track_add_name(3) o sd_bus_track_add_sender(). Pueden eliminarse de nuevo a través de sd_bus_track_remove_name() y sd_bus_track_remove_sender(). Alternativamente, las referencias a los pares se eliminan automáticamente cuando se desconectan del bus. Si no es NULL, el handler puede especificar una función que se invoca cada vez que se suelta la última referencia, independientemente de si la referencia se suelta explícitamente a través de sd_bus_track_remove_name() o implícitamente porque el par se desconectó del bus. El argumento final userdata puede usarse para adjuntar un puntero de datos de usuario genérico al objeto. Este puntero se pasa a la función de devolución de llamada del manejador cuando se invoca.

sd_bus_track_ref() crea una nueva referencia a un objeto de rastreo de pares del bus. Este objeto no se destruirá hasta que se haya llamado a sd_bus_track_unref() tantas veces más una. Una vez que el contador de referencias ha caído a cero, el objeto especificado ya no puede utilizarse; las llamadas posteriores a sd_bus_track_ref() o sd_bus_track_unref() sobre el mismo objeto son ilegales.

sd_bus_track_unref() destruye una referencia a un objeto de rastreo de pares del bus.

sd_bus_track_unrefp() es similar a sd_bus_track_unref() pero toma un puntero a un puntero a un objeto sd_bus_track. Esta llamada es útil en conjunción con el Atributo de Variable de Limpieza de GCC y LLVM[1]. Tenga en cuenta que esta función está definida como una función en línea.

sd_bus_track_ref(), sd_bus_track_unref() y sd_bus_track_unrefp() no ejecutan ninguna operación si el objeto de rastreo de pares del bus pasado es NULL.

Los objetos de rastreo de pares del bus pueden existir en dos modos: por defecto operan en modo no recursivo, pero opcionalmente pueden cambiarse al modo recursivo. Si operan en el modo no recursivo por defecto, un par se rastrea o no se rastrea. En este modo, invocar sd_bus_track_add_name() varias veces seguidas para el mismo par es completamente equivalente a llamarlo solo una vez, ya que la llamada añade el par al conjunto de pares rastreados si es necesario, y no ejecuta ninguna operación si el par ya está siendo rastreado. Una única invocación de sd_bus_track_remove_name() elimina la referencia al par de nuevo, independientemente de cuántas veces se llamó a sd_bus_track_add_name() antes. Si operan en modo recursivo, se cuenta el número de veces que se invoca sd_bus_track_add_name() para el mismo nombre de par y se debe llamar a sd_bus_track_remove_name() el mismo número de veces antes de que el par ya no sea rastreado, con la excepción de cuando el par rastreado desaparece del bus, en cuyo caso el recuento es irrelevante y el rastreo del par específico se elimina inmediatamente. sd_bus_track_get_recursive() puede usarse para determinar si el objeto de rastreo de pares del bus está operando en modo recursivo. sd_bus_track_set_recursive() puede usarse para habilitar o deshabilitar el modo recursivo. Por defecto, un objeto de rastreo de pares del bus opera en modo no recursivo, y sd_bus_track_get_recursive() para un objeto recién asignado, por lo tanto, devuelve un valor igual a cero. Use sd_bus_track_set_recursive() para habilitar el modo recursivo, justo después de la asignación. Toma un argumento booleano para habilitar o deshabilitar el modo recursivo. Tenga en cuenta que los objetos de rastreo para los que ya se ha invocado sd_bus_track_add_name() al menos una vez (y que, por lo tanto, rastrean uno o más pares) ya no pueden cambiar de modo recursivo a no recursivo.

sd_bus_track_get_bus() devuelve el objeto bus al que pertenece el objeto de rastreo de pares del bus. Devuelve el objeto bus pasado inicialmente a sd_bus_track_new() cuando el objeto fue asignado.

sd_bus_track_get_userdata() devuelve el puntero de datos de usuario genérico establecido en el objeto de rastreo de pares del bus en el momento de la creación usando sd_bus_track_new() o en un momento posterior, usando sd_bus_track_set_userdata().

VALOR DE RETORNO

En caso de éxito, sd_bus_track_new() y sd_bus_track_set_recursive() devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo tipo errno.

sd_bus_track_ref() siempre devuelve el argumento.

sd_bus_track_unref() siempre devuelve NULL.

sd_bus_track_get_recursive() devuelve 0 si se selecciona el modo no recursivo (por defecto), y mayor que 0 si se selecciona el modo recursivo. En caso de error, se devuelve un código de error negativo tipo errno.

sd_bus_track_get_bus() devuelve el objeto bus asociado al objeto de rastreo de pares del bus.

sd_bus_track_get_userdata() devuelve el puntero de datos de usuario genérico asociado al objeto de rastreo de pares del bus. sd_bus_track_set_userdata() devuelve el puntero de datos de usuario anteriormente establecido.

PROPIEDAD DE LA REFERENCIA

La función sd_bus_track_new() crea un nuevo objeto y el llamador posee la única referencia. Cuando ya no sea necesaria, esta referencia debe destruirse con sd_bus_track_unref().

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EBUSY

Ya se han añadido pares del bus al objeto de rastreo de pares del bus y se llamó a sd_bus_track_set_recursive() para cambiar el modo de rastreo.

-EINVAL

El parámetro especificado es inválido (NULL en caso de parámetros de salida).

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

NAME

sd_bus_track_unref, sd_bus_track_unrefp - Decrement a bus tracking object's reference count

SYNOPSIS

#include <systemd/sd-bus.h>

sd_bus_track_t *sd_bus_track_ref(sd_bus_track_t *track);

void sd_bus_track_unref(sd_bus_track_t *track);

sd_bus_track_t *sd_bus_track_unrefp(sd_bus_track_t **trackp);

DESCRIPTION

The sd_bus_track_ref() function increments the reference count of the bus tracking object track. It returns the same object that was passed in as track.

The sd_bus_track_unref() function decrements the reference count of the bus tracking object track. If the reference count drops to zero, the object is deallocated.

The sd_bus_track_unrefp() function is a convenience wrapper that first calls sd_bus_track_unref() for the object pointed to by trackp, and then sets the pointer trackp to NULL. This is useful for preventing use-after-free bugs.

Bus tracking objects are used to monitor object paths or service names. See sd_bus_track_new(3) for details.

RETURN VALUE

The sd_bus_track_ref() function returns the same track that was passed in.

The sd_bus_track_unrefp() function returns NULL.

REFERENCE OWNERSHIP

The caller gains a new reference to the bus tracking object via sd_bus_track_ref(). Each reference must be dropped via sd_bus_track_unref().

The sd_bus_track_unrefp() function transfers ownership of all references to the object to the function. When the reference count drops to zero, the object is deallocated.

NOTES

These functions are thread-safe. They may be called from any thread.

A bus tracking object may be passed to multiple threads for incrementing and decrementing the reference count.
