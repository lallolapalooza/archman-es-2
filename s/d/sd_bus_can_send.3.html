sd_bus_can_send(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_CAN_SEND(3) sd_bus_can_send SD_BUS_CAN_SEND(3)

NOMBRE

sd_bus_can_send - Comprueba qué tipos se pueden enviar a través de un objeto de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_can_send(sd_bus *bus, char type);

DESCRIPCIÓN

sd_bus_can_send() se utiliza principalmente para comprobar si el paso de descriptores de archivo está disponible en el bus dado. type puede ser cualquiera de las constantes SD_BUS_TYPE.

VALOR DE RETORNO

En caso de error, sd_bus_can_send() devuelve un código de error negativo al estilo de errno. Si los valores del tipo dado se pueden enviar a través del bus dado, devuelve un entero positivo. De lo contrario, devuelve cero.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ENOPKG

No se pudo resolver el objeto de bus bus.

-ENOTCONN

El parámetro de entrada bus es NULL o el bus no está conectado.

-ECHILD

El objeto de bus bus se creó en un proceso diferente.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se han iniciado otros hilos.

HISTORIA

sd_bus_can_send() se añadió en la versión 221.
