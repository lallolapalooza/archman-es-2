SD_BUS_ENQUEUE_FOR_READ(3) sd_bus_enqueue_for_read SD_BUS_ENQUEUE_FOR_READ(3)

NOMBRE

sd_bus_enqueue_for_read - Reencolar un mensaje del bus en una conexión de bus, para lectura

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_enqueue_for_read(sd_bus *bus, sd_bus_message *message);

DESCRIPCIÓN

sd_bus_enqueue_for_read() puede ser utilizado para reencolar un mensaje de bus entrante en la cola de lectura local, de modo que sea procesado y despachado localmente de nuevo, de forma similar a como se procesa un mensaje entrante del par. Toma un objeto de conexión de bus y el mensaje a reencolar. Se toma una referencia del mensaje y la referencia del llamante permanece en posesión del llamante. El mensaje se encola al final de la cola, por lo que se despachará después de que todos los demás mensajes ya encolados sean despachados.

Esta llamada es principalmente útil para tratar con llamadas a métodos entrantes que solo pueden procesarse después de que se complete una operación asíncrona adicional. Un ejemplo son las solicitudes de autorización de PolicyKit que se determina que son necesarias para autorizar una llamada a método recién recibida: cuando se recibe la respuesta de PolicyKit, la llamada a método original puede ser reencolada para procesarla de nuevo, esta vez con el resultado de autorización conocido.

VALOR DE RETORNO

En caso de éxito, esta función devuelve 0 o un entero positivo. En caso de fallo, devuelve un código de error negativo al estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ECHILD

La conexión del bus se ha creado en un proceso, biblioteca o instancia de módulo diferente.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara no ser seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_enqueue_for_read() se añadió en la versión 245.
