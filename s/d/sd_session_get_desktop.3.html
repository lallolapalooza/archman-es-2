SD_SESSION_IS_ACTIVE(3) sd_session_is_active SD_SESSION_IS_ACTIVE(3)

NOMBRE

sd_session_is_active, sd_session_is_remote, sd_session_get_state, sd_session_get_uid, sd_session_get_username, sd_session_get_seat, sd_session_get_start_time, sd_session_get_service, sd_session_get_type, sd_session_get_class, sd_session_get_desktop, sd_session_get_display, sd_session_get_tty, sd_session_get_vt, sd_session_get_remote_host, sd_session_get_remote_user, sd_session_get_leader - Determinar el estado de una sesión específica

SINOPSIS

#include <systemd/sd-login.h>

int sd_session_is_active(const char *session);

int sd_session_is_remote(const char *session);

int sd_session_get_state(const char *session, char **state);

int sd_session_get_uid(const char *session, uid_t *uid);

int sd_session_get_username(const char *session, char **username);

int sd_session_get_seat(const char *session, char **seat);

int sd_session_get_start_time(const char *session, uint64_t *usec);

int sd_session_get_service(const char *session, char **service);

int sd_session_get_type(const char *session, char **type);

int sd_session_get_class(const char *session, char **class);

int sd_session_get_desktop(const char *session, char **desktop);

int sd_session_get_display(const char *session, char **display);

int sd_session_get_leader(const char *session, pid_t *leader);

int sd_session_get_remote_host(const char *session, char **remote_host);

int sd_session_get_remote_user(const char *session, char **remote_user);

int sd_session_get_tty(const char *session, char **tty);

int sd_session_get_vt(const char *session, unsigned int *vt);

DESCRIPCIÓN

sd_session_is_active() se puede usar para determinar si la sesión identificada por el identificador de sesión especificado está actualmente activa (es decir, actualmente en primer plano y disponible para entrada de usuario) o no.

sd_session_is_remote() se puede usar para determinar si la sesión identificada por el identificador de sesión especificado es una sesión remota (es decir, su host remoto es conocido) o no.

sd_session_get_state() se puede usar para determinar el estado de la sesión identificada por el identificador de sesión especificado. Los siguientes estados se conocen actualmente: "online" (sesión iniciada, pero sesión no activa, es decir, no en primer plano), "active" (sesión iniciada y activa, es decir, en primer plano), "closing" (sesión nominalmente cerrada, pero algunos procesos que le pertenecen todavía están presentes). En el futuro, se podrían definir estados adicionales; el código cliente debe escribirse para ser robusto ante el retorno de cadenas de estado adicionales. Esta función es una versión más genérica de sd_session_is_active(). La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_uid() se puede usar para determinar el identificador de usuario del usuario de Unix al que pertenece la sesión identificada por el identificador de sesión especificado.

sd_session_get_username() se puede usar para determinar el nombre del usuario de Unix al que pertenece la sesión identificada por el identificador de sesión especificado. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_seat() se puede usar para determinar el identificador del asiento al que pertenece la sesión identificada por el identificador de sesión especificado. Tenga en cuenta que no todas las sesiones están conectadas a un asiento; esta llamada fallará (devolviendo -ENODATA) para ellas. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_start_time() se puede usar para determinar la hora de inicio de la sesión identificada por el identificador de sesión especificado. El usec está en microsegundos desde la época (CLOCK_REALTIME).

sd_session_get_service() se puede usar para determinar el nombre del servicio (tal como se pasó durante la configuración de la sesión PAM) que registró la sesión identificada por el identificador de sesión especificado. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_type() se puede usar para determinar el tipo de sesión identificada por el identificador de sesión especificado. La cadena devuelta es uno de "x11", "wayland", "tty", "mir" o "unspecified" y debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_class() se puede usar para determinar la clase de la sesión identificada por el identificador de sesión especificado. La cadena devuelta es una de "user", "user-early", "user-light", "user-early-light", "user-incomplete", "greeter", "lock-screen", "background", "background-light", "manager" o "manager-early" y debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_desktop() se puede usar para determinar la marca del escritorio que se ejecuta en la sesión identificada por el identificador de sesión especificado. Este campo puede ser establecido libremente por los entornos de escritorio y no sigue ningún formato especial. Sin embargo, se recomienda encarecidamente a los escritorios que utilicen los mismos identificadores y capitalización que para $XDG_CURRENT_DESKTOP, tal como se define en la Especificación de Entradas de Escritorio[1]. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_display() se puede usar para determinar la pantalla X11 de la sesión identificada por el identificador de sesión especificado. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_leader() se puede usar para determinar el PID del líder de la sesión identificada por el identificador de sesión especificado.

sd_session_get_remote_host() se puede usar para determinar el nombre de host remoto de la sesión identificada por el identificador de sesión especificado. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_remote_user() se puede usar para determinar el nombre de usuario remoto de la sesión identificada por el identificador de sesión especificado. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso. Tenga en cuenta que este valor rara vez es conocido por el sistema, e incluso entonces no debe confiarse en él.

sd_session_get_tty() se puede usar para determinar el dispositivo TTY de la sesión identificada por el identificador de sesión especificado. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_vt() se puede usar para determinar el número de VT de la sesión identificada por el identificador de sesión especificado. Esta función devolverá un error si el asiento no admite VTs.

Si el parámetro session de alguna de estas funciones se pasa como NULL, la operación se ejecuta para la sesión de la que el proceso que llama es miembro, si existe alguna.

sd_session_get_desktop(3)

NAME

sd_session_get_desktop, sd_session_get_state, sd_session_get_tty, sd_session_get_vt, sd_session_is_remote, sd_session_get_remote_user, sd_session_get_remote_host, sd_session_get_username, sd_session_get_start_time, sd_session_get_leader — Obtener información sobre una sesión de usuario

SYNOPSIS

#include <systemd/sd-login.h>

int sd_session_get_desktop(const char *session_id, const char **desktop);
int sd_session_get_state(const char *session_id, const char **state);
int sd_session_get_tty(const char *session_id, const char **tty);
int sd_session_get_vt(const char *session_id, unsigned *vt);
int sd_session_is_remote(const char *session_id, int *remote);
int sd_session_get_remote_user(const char *session_id, const char **user);
int sd_session_get_remote_host(const char *session_id, const char **host);
int sd_session_get_username(const char *session_id, const char **user);
int sd_session_get_start_time(const char *session_id, struct timespec *ts);
int sd_session_get_leader(const char *session_id, pid_t *leader);

DESCRIPTION

El sistema systemd(1) rastrea las sesiones de usuario. Las funciones descritas aquí permiten consultar información sobre una sesión específica, identificada por su session_id.

Las funciones devuelven un puntero al valor solicitado a través de los parámetros de salida (por ejemplo, desktop, state, tty, vt, remote, user, host, username, leader) y llenan la estructura de tiempo ts si se solicita la hora de inicio.

Si la sesión es local, sd_session_is_remote devolverá 0 en el parámetro remote. Si es remota, devolverá 1. Si no se conoce o no se puede determinar el estado remoto, se devolverá -ENODATA.

La cadena devuelta en los parámetros de salida desktop, state, tty, user y host es un puntero a memoria interna y no debe modificarse ni liberarse. Seguirá siendo válido hasta la siguiente llamada a la misma función o hasta que la biblioteca libsystemd sea descargada.

El valor de retorno vt es el número de la consola virtual (VT) en la que se ejecuta la sesión, si la hay.

El parámetro leader es el ID del proceso (PID) del líder de la sesión.

sd_session_get_desktop, sd_session_get_state, sd_session_get_tty, sd_session_get_vt, sd_session_is_remote, sd_session_get_remote_user, sd_session_get_remote_host, sd_session_get_username, sd_session_get_start_time, sd_session_get_leader devuelven 0 o un entero positivo. En caso de error, estas llamadas devuelven un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ENXIO

La sesión especificada no existe.

-ENODATA

El campo dado no está especificado para la sesión descrita.

-EINVAL

Un parámetro de entrada era inválido (fuera de rango, o NULL, donde no se acepta).

-ENOMEM

Falló la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, contra la cual se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_session_get_tty() se añadió en la versión 198.

sd_session_get_vt() se añadió en la versión 207.
