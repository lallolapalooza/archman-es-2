Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_TRACK_ADD_NAME(3) sd_bus_track_add_name SD_BUS_TRACK_ADD_NAME(3)

NOMBRE

sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_remove_sender, sd_bus_track_count, sd_bus_track_count_sender, sd_bus_track_count_name, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next - Añadir, eliminar y recuperar pares de bus rastreados en un objeto de rastreo de pares de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(sd_bus_track* t, const char* name);

int sd_bus_track_add_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_remove_name(sd_bus_track* t, const char* name);

int sd_bus_track_remove_sender(sd_bus_track* t, sd_bus_message* message);

unsigned sd_bus_track_count(sd_bus_track* t);

int sd_bus_track_count_name(sd_bus_track* t, const char* name);

int sd_bus_track_count_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_contains(sd_bus_track* t, const char* name);

const char* sd_bus_track_first(sd_bus_track* t);

const char* sd_bus_track_next(sd_bus_track* t);

DESCRIPCIÓN

sd_bus_track_add_name() añade un par a rastrear a un objeto de rastreo de pares de bus. El primer argumento debe referirse a un objeto de rastreo de pares de bus creado con sd_bus_track_new(3), el segundo nombre debe referirse a un nombre de par D-Bus a rastrear, ya sea en formato de servicio único o conocido. Si el nombre aún no está siendo rastreado, se añadirá a la lista de nombres a rastrear. Si ya está siendo rastreado y el modo no recursivo está habilitado, esta llamada no ejecutará ninguna operación. Si el modo recursivo está habilitado, un contador por nombre se incrementará en uno cada vez que se invoque esta llamada, y sd_bus_track_remove_name() debe ser llamada tantas veces como se invocó sd_bus_track_add_name() para dejar de rastrear el nombre. Utilice sd_bus_track_set_recursive(3) para cambiar del modo no recursivo predeterminado al modo recursivo, o viceversa. Tenga en cuenta que el nombre especificado se rastrea tal cual, los nombres conocidos no se resuelven a nombres únicos con esta llamada. Tenga en cuenta que múltiples objetos de rastreo de pares de bus pueden rastrear el mismo nombre.

sd_bus_track_remove_name() deshace el efecto de sd_bus_track_add_name() y elimina un nombre de par de bus de la lista de pares a vigilar. Dependiendo de si el modo no recursivo o recursivo está habilitado para el objeto de rastreo de pares de bus, esta llamada eliminará el nombre completamente del objeto de rastreo, o simplemente decrementará el contador por nombre en uno, eliminando el nombre solo cuando el contador alcance cero (ver arriba). Tenga en cuenta que un par de bus que se desconecta del bus eliminará implícitamente sus nombres completamente del objeto de rastreo de pares de bus, independientemente del contador por nombre actual.

sd_bus_track_add_sender() y sd_bus_track_remove_sender() son similares a sd_bus_track_add_name() y sd_bus_track_remove_name() pero toman un mensaje de bus como argumento. Se determina el remitente de este mensaje de bus y se añade/elimina del objeto de rastreo de pares de bus. Como los mensajes siempre se originan de nombres únicos, y nunca de nombres conocidos, esto significa que esta llamada efectivamente solo añadirá nombres únicos al objeto de rastreo de pares de bus.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente en el objeto de rastreo de pares de bus especificado. Tenga en cuenta que esta función siempre devuelve el número real de nombres rastreados y, por lo tanto, si se ha invocado sd_bus_track_add_name() varias veces para el mismo nombre, solo se cuenta como uno, independientemente de si el modo recursivo está habilitado o no.

sd_bus_track_count_name() devuelve el contador por nombre actual para el nombre especificado. Si se utiliza el modo no recursivo, devuelve 1 o 0, dependiendo de si el nombre especificado se ha añadido antes al objeto de rastreo o no. Si se ha habilitado el modo recursivo, también se pueden devolver valores mayores que 1, en caso de que se haya llamado sd_bus_track_add_name() varias veces para el mismo nombre.

sd_bus_track_count_sender() es similar a sd_bus_track_count_name(), pero toma un objeto de mensaje de bus y devuelve el contador por nombre que coincide con el remitente del mensaje.

sd_bus_track_contains() se puede utilizar para determinar si el nombre especificado se ha añadido al menos una vez al objeto de rastreo de pares de bus especificado.

sd_bus_track_first() y sd_bus_track_next() se pueden utilizar para enumerar todos los nombres que se están rastreando actualmente en el objeto de rastreo de pares de bus pasado. sd_bus_track_first() devuelve la primera entrada en el objeto y reinicia un índice de lectura mantenido internamente. Cada invocación subsiguiente de sd_bus_track_next() devuelve el siguiente nombre contenido en el objeto de bus. Si se llega al final, se devuelve NULL. Si no se han añadido nombres al objeto todavía, sd_bus_track_first() devolverá NULL inmediatamente. El orden en que se devuelven los nombres no está definido; en particular, no está definido qué nombre se considera el primero devuelto. Si el modo recursivo está habilitado y el mismo nombre se ha añadido varias veces al objeto de rastreo de pares de bus, solo se devuelve una vez en esta enumeración. Si se añaden nuevos nombres o se eliminan nombres existentes del objeto de rastreo de pares de bus mientras se está enumerando, la enumeración finaliza en la próxima invocación de sd_bus_track_next(), ya que se devuelve NULL.

VALOR DE RETORNO

En caso de éxito, sd_bus_track_add_name() y sd_bus_track_add_sender() devuelven 0 si el nombre especificado ya se había añadido antes al objeto de rastreo de pares de bus y un valor positivo si no es así. En caso de fallo, devuelven un código de error negativo con estilo errno.

sd_bus_track_remove_name() y sd_bus_track_remove_sender() devuelven un valor positivo si el nombre especificado estaba previamente rastreado por el objeto de rastreo de pares de bus y ahora ha sido eliminado. En modo no recursivo, se devuelve 0 si el nombre especificado aún no estaba siendo rastreado. En modo recursivo, se devuelve -EUNATCH en este caso. En caso de fallo, devuelven un código de error negativo con estilo errno.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente, o 0 en caso de fallo.

sd_bus_track_count_name() y sd_bus_track_count_sender() devuelven el contador por nombre actual para el nombre especificado o el remitente del mensaje especificado. Se devuelve cero para los nombres que aún no se están rastreando, un valor positivo para los nombres añadidos al menos una vez. Los valores mayores que 1 solo se devuelven en modo recursivo. En caso de fallo, se devuelve un código de error negativo con estilo errno.

sd_bus_track_contains() devuelve el nombre pasado si existe en el objeto de rastreo de pares de bus. En caso de fallo, y si el nombre no se ha añadido todavía, se devuelve NULL.

sd_bus_track_first() y sd_bus_track_next() devuelven el primer/siguiente nombre contenido en el objeto de rastreo de pares de bus, y NULL si se alcanza el final de la enumeración y en caso de error.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EUNATCH

sd_bus_track_remove_name() o sd_bus_track_remove_sender() se han invocado para un nombre no añadido previamente al objeto de par de bus.

-EINVAL

El parámetro especificado es inválido.

-ENOMEM

Fallo en la asignación de memoria.

sd_bus_track_remove_sender.3.en

NAME

sd_bus_track_remove_sender, sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_count, sd_bus_track_count_name, sd_bus_track_count_sender, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next — Manage the set of sender names or sender addresses to track messages from

SYNOPSIS

#include <systemd/sd-bus.h>


int sd_bus_track_remove_sender(sd_bus_track *track, const char *sender);


int sd_bus_track_add_name(sd_bus_track *track, const char *name);


int sd_bus_track_add_sender(sd_bus_track *track, const char *sender);


int sd_bus_track_remove_name(sd_bus_track *track, const char *name);


size_t sd_bus_track_count(const sd_bus_track *track);


size_t sd_bus_track_count_name(const sd_bus_track *track, const char *name);


size_t sd_bus_track_count_sender(const sd_bus_track *track, const char *sender);


int sd_bus_track_contains(const sd_bus_track *track, const char *sender);


sd_bus_message *sd_bus_track_first(sd_bus_track *track);


sd_bus_message *sd_bus_track_next(sd_bus_track *track);

DESCRIPTION

sd_bus_track_add_name() and sd_bus_track_add_sender() add the specified name or sender to the set of senders to track messages from in the given track. If a sender is added, messages from this sender will be tracked. If a name is added, messages sent to this bus name will be tracked. Note that a bus name may be owned by multiple processes, and this function will track messages sent to any of these owning processes.

sd_bus_track_remove_name() and sd_bus_track_remove_sender() remove the specified name or sender from the set of senders to track.

sd_bus_track_count() returns the total number of senders and names currently tracked.

sd_bus_track_count_name() returns the number of times the specified name is tracked. This is usually 0 or 1.

sd_bus_track_count_sender() returns the number of times the specified sender is tracked. This is usually 0 or 1.

sd_bus_track_contains() checks if the specified sender is currently tracked. It returns 1 if the sender is tracked, and 0 otherwise.

sd_bus_track_first() and sd_bus_track_next() are used to iterate over all the messages that have been tracked since the last call to sd_bus_track_first() or sd_bus_track_next().

When a message is received that matches any of the tracked senders or names, it is added to the tracking list. sd_bus_track_first() initializes the iteration and returns the first tracked message, or NULL if no messages have been tracked. Subsequent calls to sd_bus_track_next() return the next tracked message, or NULL when the end of the list is reached. The messages returned by these functions are owned by the track object and should not be freed or modified by the caller. They are valid only until the next call to sd_bus_track_add_name(), sd_bus_track_add_sender(), sd_bus_track_remove_name(), sd_bus_track_remove_sender(), or sd_bus_track_first().

The tracking functionality is intended for debugging and introspection purposes. It can introduce significant overhead, especially when tracking many senders or names, or when many messages are being sent.

The tracking list is cleared when the track object is destroyed, or when sd_bus_track_new() is called again on the same object.

RETURN VALUE

sd_bus_track_add_name(), sd_bus_track_add_sender(), sd_bus_track_remove_name(), and sd_bus_track_remove_sender() return 0 on success, or a negative errno value on failure. The tracked sender/name is only removed if it was previously added.

sd_bus_track_count(), sd_bus_track_count_name(), and sd_bus_track_count_sender() return the count.

sd_bus_track_contains() returns 1 if the sender is tracked, 0 otherwise.

sd_bus_track_first() and sd_bus_track_next() return a pointer to the tracked message on success, or NULL if no more messages are available or if an error occurred.

NOTES

This functionality is primarily intended for use with event loops like sd_event_loop(). Messages are only captured if the bus object is attached to an event loop. If the bus object is not attached to an event loop, messages will not be tracked.

When using sd_bus_track_add_name() and sd_bus_track_remove_name() you need to be careful about which bus you are tracking. Messages sent to system bus names will only be tracked if the track object is associated with the system bus. Similarly, messages sent to session bus names will only be tracked if the track object is associated with the session bus.

If sd_bus_track_add_name() is called before any threads have been started, it may block indefinitely until the name is registered.
