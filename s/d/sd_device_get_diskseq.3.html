NOMBRE

DESCRIPCIÓN

sd_device_get_syspath() devuelve la ruta sysfs del registro del dispositivo especificado, incluyendo el prefijo /sys. Ejemplo: /sys/devices/virtual/tty/tty7

sd_device_get_devpath() devuelve la ruta sysfs del registro del dispositivo especificado, excluyendo el prefijo /sys. Ejemplo: /devices/virtual/tty/tty7

sd_device_get_sysname() devuelve el nombre sysfs del registro del dispositivo especificado, es decir, el último componente de la ruta sysfs. Ejemplo: "tty7" para el dispositivo /sys/devices/virtual/tty/tty7

sd_device_get_sysnum() devuelve el número de dispositivo sysfs del registro del dispositivo especificado, es decir, el sufijo numérico del último componente de la ruta sysfs. Ejemplo: "7" para el dispositivo /sys/devices/virtual/tty/tty7

sd_device_get_subsystem() devuelve el subsistema del kernel del registro del dispositivo especificado. Esta es una cadena corta que cabe en un nombre de archivo, por lo tanto, no contiene una barra y no puede estar vacía. Ejemplo: "tty", "block" o "net".

sd_device_get_driver_subsystem() devuelve el tipo de bus conectado de los dispositivos cargados por el registro del dispositivo controlador especificado. Por ejemplo, cuando se especifica el registro del dispositivo controlador "iwlwifi", que es utilizado por las interfaces de red inalámbricas conectadas al bus PCI, esta función devuelve "pci". Esta función solo tiene éxito cuando sd_device_get_subsystem() devuelve "drivers". Ejemplo: "pci", "i2c", o "hid".

sd_device_get_devtype() devuelve el tipo de dispositivo del registro del dispositivo especificado, si el subsistema gestiona múltiples tipos de dispositivos. Ejemplo: para dispositivos del subsistema "block" este puede ser "disk" o "partition"

sd_device_get_devname() devuelve la ruta del nodo del dispositivo del registro del dispositivo especificado si el dispositivo tiene un nodo de dispositivo. Ejemplo: para /sys/devices/virtual/tty/tty7 típicamente se devuelve la cadena /dev/tty7.

sd_device_get_devnum() devuelve el mayor/menor del nodo del dispositivo (es decir, dev_t) del registro del dispositivo especificado si el dispositivo tiene un nodo de dispositivo (es decir, el que devuelve sd_device_get_devname()). Para dispositivos que pertenecen al subsistema "block", esto se refiere a un nodo de dispositivo de bloque, en todos los demás casos a un nodo de dispositivo de carácter. Ejemplo: para el dispositivo /sys/devices/virtual/tty/tty7, esto típicamente devuelve el número de dispositivo con mayor/menor "4:7".

sd_device_get_ifindex() devuelve el índice de la interfaz de red del registro del dispositivo especificado, si el dispositivo encapsula un dispositivo de interfaz de red, es decir, pertenece al subsistema "net". Ejemplo: la interfaz "lo" típicamente tiene el índice de interfaz 1.

sd_device_get_driver() devuelve el nombre del controlador del kernel adjunto al dispositivo. Tenga en cuenta que el campo del controlador se establece en los dispositivos consumidos por el controlador, no en el dispositivo creado por él. Ejemplo: un dispositivo PCI /sys/bus/pci/devices/0000:00:1f.6 podría estar adjunto a un controlador "e1000e".

sd_device_get_diskseq() devuelve el número de secuencia de disco del kernel del dispositivo de bloque. Este número aumenta monotónicamente cada vez que cambia un medio de respaldo de un dispositivo de bloque sin que cambie el nombre del dispositivo, y es relevante para los dispositivos de bloque que encapsulan dispositivos con medios cambiantes (por ejemplo, disquete o CD-ROM), o dispositivos de bloque de loopback. Solo se define para dispositivos de bloque, es decir, aquellos del subsistema "block".

sd_device_get_device_id() devuelve la cadena corta que identifica el registro del dispositivo. Cuando el ID del dispositivo obtenido por la función para un registro de dispositivo especificado se pasa a sd_device_new_from_device_id(), se obtendrá una nueva instancia del mismo registro de dispositivo. Cuando se especifica un dispositivo de bloque o de carácter, que tiene un nodo de dispositivo correspondiente, esto devuelve "b" o "c", respectivamente, seguido de los números mayor y menor del nodo del dispositivo separados por dos puntos. Ejemplo: "b259:1" o "c10:121". Cuando se especifica un dispositivo de interfaz de red, esto devuelve "n" seguido del índice de interfaz, que se puede obtener mediante sd_device_get_ifindex(). Ejemplo: "n1". Cuando se especifica un dispositivo en el subsistema "driver", esto devuelve "+drivers:" seguido de su subsistema controlador y nombre sysfs separados por dos puntos. Ejemplo: "+drivers:pci:iwlwifi" para un registro de dispositivo controlador cuyo subsistema controlador es "pci" y cuyo nombre sysfs es "iwlwifi". Cuando se especifica otro tipo de dispositivo, esta función devuelve "+" seguido de su subsistema y nombre sysfs separados por dos puntos. Ejemplo: "+acpi:ACPI0003:00", "+input:input16", o "+pci:0000:00:1f.6".

VALOR DE RETORNO

En caso de éxito, estas llamadas devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo del estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Un parámetro especificado es inválido.

Añadido en la versión 251.

-ENOENT

El campo solicitado no está presente en el registro del dispositivo.

Añadido en la versión 251.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y vincular con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara que no es seguro para multihilo. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

sd_device_get_driver_subsystem(3) - Arch manual pages

NAME

sd_device_get_driver_subsystem, sd_device_get_device_id - Obtener información del subsistema del controlador y del ID del dispositivo

SYNOPSIS

   #include <systemd/sd-device.h>

   const char *sd_device_get_driver_subsystem(sd_device *device);
   int sd_device_get_device_id(sd_device *device, uint64_t *id);

DESCRIPTION

El método sd_device_get_driver_subsystem() devuelve el nombre del subsistema del controlador asociado con el device. Por ejemplo, puede devolver "usb", "pci", "scsi", "block", etc. El valor devuelto es una referencia a una cadena de caracteres interna y no debe modificarse ni liberarse. Si el dispositivo no tiene un controlador asociado o si se produce un error, se devuelve NULL.

El método sd_device_get_device_id() recupera un identificador único de 64 bits para el device. Este identificador se pasa en la variable id. El identificador es estable en reinicios del sistema, pero puede cambiar si el dispositivo de hardware se modifica (por ejemplo, si se reemplaza la placa base). Si el dispositivo no tiene un ID de dispositivo (por ejemplo, porque no está siendo administrado por udev), la función devolverá 0 y id contendrá el valor 0. Si se produce un error, la función devolverá un valor negativo.

RETURN VALUE

sd_device_get_driver_subsystem() devuelve una cadena de caracteres que apunta al subsistema del controlador o NULL en caso de error o si no hay ninguno.

sd_device_get_device_id() devuelve 0 en caso de éxito y un valor negativo en caso de error.

NOTES

Estas funciones solo están disponibles si la biblioteca libsystemd se compiló con soporte para udev.

HISTORY

Los métodos sd_device_get_driver_subsystem() y sd_device_get_device_id() se añadieron en la versión 257.
