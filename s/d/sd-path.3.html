NOMBRE

sd-path - APIs para consultar rutas del sistema de archivos

SINOPSIS

#include <systemd/sd-path.h>

pkg-config --cflags --libs libsystemd

DESCRIPCIÓN

sd-path.h es parte de libsystemd(3) y proporciona APIs para consultar rutas del sistema de archivos. Esta funcionalidad es similar a la funcionalidad de línea de comandos proporcionada por systemd-path(1).

Consulte sd_path_lookup(3) para obtener información sobre las funciones disponibles.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara no ser seguro para hilos (multi-thread-safe). Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

VER TAMBIÉN

systemd(1), systemd-path(1), pkg-config(1)
