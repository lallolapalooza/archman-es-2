NOMBRE

sd_bus_slot_set_floating, sd_bus_slot_get_floating - Controlar si un objeto de ranura de bus está "flotante"

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_slot_set_floating(sd_bus_slot *slot, int b);

int sd_bus_slot_get_floating(sd_bus_slot *slot);

DESCRIPCIÓN

sd_bus_slot_set_floating() controla si el objeto de ranura de bus especificado slot será "flotante" o no. La vida útil de un objeto de ranura de bus flotante está ligada a la vida útil del objeto de bus con el que está asociado, lo que significa que permanece asignado mientras el objeto de bus en sí mismo y se libera automáticamente cuando se libera el objeto de bus. Los objetos de ranura de bus regulares (es decir, no flotantes) mantienen una referencia al bus, por lo tanto, el objeto de bus permanece asignado al menos mientras exista al menos un objeto de ranura de bus con referencia. Por lo tanto, el estado flotante controla la dirección de las referencias entre el objeto de bus y los objetos de ranura de bus: si es flotante, el bus fija la ranura de bus, y de lo contrario, la ranura de bus fija los objetos de bus. Use sd_bus_slot_set_floating() para cambiar entre ambos modos: si el parámetro b es cero, la ranura de objeto se convierte en una ranura de objeto regular (no flotante), de lo contrario, se convierte en un objeto flotante.

Los objetos de ranura de bus pueden ser asignados con llamadas como sd_bus_add_match(3). Si la slot de estas funciones es distinta de NULL, el objeto de ranura será del tipo regular (es decir, no flotante), de lo contrario, se creará flotante. Con sd_bus_slot_set_floating(), un objeto de ranura de bus asignado como regular puede convertirse en un objeto flotante y viceversa. Esto es particularmente útil para crear un objeto de ranura de bus, luego cambiar sus parámetros y luego convertirlo en un objeto flotante, cuya vida útil es gestionada por el objeto de bus.

sd_bus_slot_get_floating() devuelve el estado flotante actual del objeto de ranura de bus especificado. Devuelve un valor negativo en caso de error, cero si el objeto de ranura de bus es un objeto regular (no flotante) y positivo en caso contrario.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El parámetro slot es NULL.

-ECHILD

La conexión del bus se creó en un proceso, biblioteca o instancia de módulo diferente.

-ESTALE

El objeto de bus al que está asociado el objeto de ranura de bus especificado ya se ha liberado, por lo tanto, ya no se puede realizar ningún cambio en el estado flotante.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando aún no se han iniciado otros hilos.

HISTORIA

sd_bus_slot_set_floating() y sd_bus_slot_get_floating() se agregaron en la versión 239.
