DESCRIPCIÓN

La estructura sd_bus_error contiene información sobre una condición de error de D-Bus, o la ausencia de la misma. Las funciones descritas a continuación se pueden usar para establecer y consultar campos en esta estructura.

•El campo nombre contiene un identificador corto de un error. Debe seguir las reglas para nombres de error descritas en la especificación de D-Bus, subsección Nombres Válidos de D-Bus[1]. Una serie de nombres de error comunes y estandarizados se describen en sd-bus-errors(3), pero las aplicaciones pueden definir errores adicionales específicos del dominio.
•El campo mensaje generalmente contiene una cadena legible por humanos que describe los detalles, pero puede ser NULL.

Una estructura sd_bus_error no establecida debe tener ambos campos inicializados a NULL y significa ausencia de error, es decir, éxito. Asigne SD_BUS_ERROR_NULL a la estructura para inicializar ambos campos a NULL. Cuando ya no sean necesarios, los recursos que mantiene la estructura sd_bus_error deben destruirse con sd_bus_error_free().

sd_bus_error_set() establece una estructura de error con los nombres y mensajes especificados. Las cadenas se copiarán en memoria interna recién asignada. Es esencial liberar el contenido nuevamente cuando ya no se requiera (ver arriba). No utilice esta llamada en estructuras de error que ya se hayan establecido. Si tiene la intención de reutilizar una estructura de error, libere primero los datos antiguos que contiene con sd_bus_error_free().

sd_bus_error_set() devolverá un valor similar a errno (ver errno(3)) determinado a partir del nombre de error nombre especificado. Si nombre es NULL, se asume que no ocurrió ningún error y se devuelve 0. Si nombre no es nulo, siempre se devuelve un valor negativo. Si e es NULL, no se inicializa ninguna estructura de error, pero nombre todavía se convierte en un valor de estilo errno.

Varios errores de D-Bus bien conocidos se convierten en sus contrapartes errno bien conocidas, y los demás a -EIO. Ver sd-bus-errors(3) para una lista de nombres de error bien conocidos. Se pueden definir mapeos de error adicionales con sd_bus_error_add_map(3).

sd_bus_error_set() está diseñado para ser utilizado de manera conveniente en una sentencia return. Si mensaje es NULL, no se establece ningún mensaje. Esta llamada puede fallar si no se puede asignar memoria para las cadenas de nombre y mensaje, en cuyo caso se establecerá un error SD_BUS_ERROR_NO_MEMORY y se devolverá -ENOMEM.

sd_bus_error_setf() y sd_bus_error_setfv() son similares a sd_bus_error_set(), pero toman una cadena de formato printf(3) y argumentos correspondientes para generar el campo mensaje. sd_bus_error_setf() utiliza argumentos variádicos y sd_bus_error_setfv() acepta los argumentos como una lista de parámetros va_arg(3).

sd_bus_error_set_const() es similar a sd_bus_error_set(), pero los parámetros de cadena no se copian internamente y, por lo tanto, deben permanecer constantes y válidos durante la vida útil de e. Utilice esta llamada para evitar asignaciones de memoria al establecer estructuras de error. Dado que esta llamada no asigna memoria, no fallará con una condición de falta de memoria como puede hacerlo sd_bus_error_set(), como se describe anteriormente. Alternativamente, la macro SD_BUS_ERROR_MAKE_CONST() puede usarse para generar una estructura de error literal y constante sobre la marcha.

sd_bus_error_set_errno() devolverá inmediatamente 0 si el parámetro de error especificado error es 0. De lo contrario, establecerá nombre a partir de un valor similar a errno que se convierte en un error de D-Bus. strerror_r(3) se usará para establecer mensaje. Se utilizarán nombres de error de D-Bus bien conocidos para nombre si son aplicables, de lo contrario, se generará un nombre en el espacio de nombres "System.Error.". Se ignora el signo del número de error especificado y se usa implícitamente su valor absoluto. Si el error especificado error no es cero, la llamada siempre devuelve un valor negativo, para un uso conveniente en sentencias return. Esta llamada puede fallar debido a falta de memoria, en cuyo caso se establece un error SD_BUS_ERROR_NO_MEMORY en su lugar y se devuelve -ENOMEM.

sd_bus_error_set_errnof() y sd_bus_error_set_errnof() son similares a sd_bus_error_set_errno(), pero además de error, toman una cadena de formato printf(3) y argumentos correspondientes. El campo mensaje se generará a partir de formato y los argumentos. sd_bus_error_set_errnof() utiliza argumentos variádicos y sd_bus_error_set_errnofv() acepta los argumentos como una lista de parámetros va_arg(3).

sd_bus_error_get_errno() convierte el campo nombre de una estructura de error en un valor similar a errno (positivo) utilizando las mismas reglas que sd_bus_error_set(). Si e es NULL, se devolverá 0.

sd_bus_error_copy() inicializará dst utilizando los valores de e, si e ha sido previamente establecido con un valor de error. De lo contrario, devolverá inmediatamente. Si las cadenas en e se establecieron usando sd_bus_error_set_const(), se compartirán. De lo contrario, se copiarán. Antes de esta llamada, dst debe estar sin establecer, es decir, recién inicializado con NULL o restablecido usando sd_bus_error_free().

sd_bus_error_copy() generalmente devuelve 0 o un valor negativo similar a errno basado en el parámetro de entrada e: 0 si no estaba establecido y un entero negativo si estaba establecido con algún error, de forma similar a sd_bus_error_set(). DESCRIPTION

Las estructuras sd_bus_error se utilizan para transportar información de error a través de las APIs de sd-bus. Normalmente, un error del bus se compone de un nombre de error (una cadena alfanumérica con puntos, que se asemeja a un nombre de interfaz D-Bus) y un mensaje de error descriptivo (una cadena arbitraria).

sd_bus_error_set() establece el error en la estructura apuntada por error con el nombre de error dado en name y el mensaje dado en message. Se asignará memoria para almacenar copias de estas cadenas. Si el campo name o message son NULL, se tratarán como cadenas vacías.

sd_bus_error_setf(), sd_bus_error_setfv() y sd_bus_error_setfv() son similares a sd_bus_error_set(), pero construyen el mensaje de error utilizando un formato de cadena y argumentos variables, de manera similar a printf(3).

sd_bus_error_set_const() es similar a sd_bus_error_set(), pero no asigna memoria para las cadenas de nombre y mensaje. En su lugar, toma prestadas las cadenas pasadas. Estas deben ser válidas hasta que el error sea liberado o sobrescrito. Esto es útil para errores predefinidos que tienen una vida útil más larga.

sd_bus_error_set_errno(), sd_bus_error_set_errnof() y sd_bus_error_set_errnofv() son similares a sd_bus_error_set(), sd_bus_error_setf() y sd_bus_error_setfv(), respectivamente, pero también toman un número de error errno. Este número de error se utilizará para construir el nombre del error D-Bus (véase la sección RETURN VALUE más abajo) y para inicializar el campo message si no se proporciona explícitamente. El nombre del error se forma anteponiendo el valor de errno a la cadena de formato proporcionada en name_format.

sd_bus_error_free() libera cualquier memoria asignada por las funciones de establecimiento de errores y reinicia la estructura de error a un estado no establecido (todos los campos son NULL). La estructura en sí misma no se libera, solo su contenido. Esta función puede llamarse de forma segura en estructuras de error no establecidas o en punteros NULL.

sd_bus_error_copy() copia la información de error de src a dst. Se asignará nueva memoria para las cadenas de nombre y mensaje en dst, que contendrán copias de las cadenas de src. Si src no tiene ningún error establecido, dst se reiniciará a un estado no establecido. Si dst ya tiene un error establecido, se liberará antes de la copia. Esto puede fallar si la asignación de memoria falla, devolviendo -ENOMEM.

sd_bus_error_move() es similar a sd_bus_error_copy(), pero moverá cualquier información de error de e a dst, reiniciando la primera. Esta función no puede fallar, ya que no se asigna memoria nueva. Tenga en cuenta que si e no está establecido, dst se inicializará a SD_BUS_ERROR_NULL. Además, si dst es NULL no se realizará ninguna operación sobre él y se liberarán y reiniciarán los recursos mantenidos por e. Devuelve un valor de error de tipo errno convertido, no positivo.

sd_bus_error_is_set() devolverá un valor distinto de cero si e no es NULL y se ha establecido un error, false en caso contrario.

sd_bus_error_has_name() devolverá un valor distinto de cero si e no es NULL y se ha establecido un error con el mismo name, false en caso contrario.

sd_bus_error_has_names_sentinel() es similar a sd_bus_error_has_name(), pero toma múltiples nombres para comparar. La lista debe terminar con NULL. sd_bus_error_has_names() es un macro que envuelve a sd_bus_error_has_names_sentinel() que añade el terminador NULL automáticamente.

sd_bus_error_free() destruirá los recursos mantenidos por e. El parámetro en sí mismo no se desasignará, y debe ser liberado por el llamador si es necesario. La función también puede ser llamada de forma segura en errores no establecidos (estructuras de error con ambos campos establecidos a NULL), en cuyo caso no realiza ninguna operación. Esta llamada reiniciará la estructura de error después de liberar los datos, de modo que todos los campos se establezcan a NULL. La estructura puede ser reutilizada después.

REFERENCE OWNERSHIP

sd_bus_error no tiene conteo de referencias. Los usuarios deben destruir los recursos que mantiene llamando a sd_bus_error_free(). Normalmente, las estructuras de error se asignan en la pila o se pasan como parámetros de función, pero también pueden ser asignadas dinámicamente, en cuyo caso es deber del llamador liberar la memoria que mantiene la estructura en sí misma después de liberar su contenido con sd_bus_error_free().

RETURN VALUE

Las funciones sd_bus_error_set(), sd_bus_error_setf() y sd_bus_error_set_const() siempre devuelven 0 cuando el valor de error especificado es NULL, y un valor negativo similar a errno correspondiente al parámetro name en caso contrario. Las funciones sd_bus_error_set_errno(), sd_bus_error_set_errnof() y sd_bus_error_set_errnofv(), devuelven 0 cuando el valor de error especificado es 0, y un valor negativo similar a errno correspondiente al parámetro error en caso contrario. Si ocurre un error internamente, se devolverá uno de los valores de error negativos listados a continuación. Esto permite que esas funciones se utilicen convenientemente en una sentencia de return, véase el ejemplo a continuación.

sd_bus_error_get_errno() devuelve false cuando e es NULL, y un valor de errno positivo mapeado desde e->name en caso contrario.

sd_bus_error_copy() y sd_bus_error_move() devuelven un valor de error negativo convertido desde el error de origen, y cero si el error no se ha establecido. Esto permite que esas funciones se utilicen convenientemente en una sentencia de return, véase el ejemplo a continuación.

sd_bus_error_is_set() devuelve un valor distinto de cero cuando e y el campo name no son NULL, cero en caso contrario.

sd_bus_error_has_name(), sd_bus_error_has_names(), y sd_bus_error_has_names_sentinel() devuelven un valor distinto de cero cuando e no es NULL y el campo name es igual a uno de los nombres dados, cero en caso contrario.

Errores

El valor de retorno puede indicar los siguientes problemas en la invocación de la función en sí misma:

-EINVAL

El error ya estaba establecido en la estructura sd_bus_error cuando se llamó a una de las funciones de establecimiento de errores.

-ENOMEM

Fallo en la asignación de memoria.

En caso de éxito, sd_bus_error_set(), sd_bus_error_setf(), sd_bus_error_set_const(), sd_bus_error_set_errno(), sd_bus_error_set_errnof(), sd_bus_error_set_errnofv(), sd_bus_error_copy(), y sd_bus_error_move() devolverán un valor negativo similar a errno convertido, o 0 si el parámetro de error es NULL o no está establecido. Los errores D-Bus se convierten al valor integral similar a errno, y el mecanismo de mapeo es extensible, véase la discusión anterior. Esto significa efectivamente que casi cualquier valor negativo similar a errno puede ser devuelto.

EJEMPLOS

Ejemplo 1. Usando el valor de retorno negativo para propagar un error

/* SPDX-License-Identifier: MIT-0 */
#include <errno.h>
#include <string.h>
#include <unistd.h>
#include <systemd/sd-bus.h>
int writer_with_negative_errno_return(int fd, sd_bus_error *error) {
  const char *message = "Hello, World!\n";
  ssize_t n = write(fd, message, strlen(message));
  if (n >= 0)
    return n; /* En caso de éxito, devuelve el número de bytes escritos, posiblemente 0. */
  /* En caso de error, inicializa la estructura de error y también propaga el valor de errno
   * que write(2) estableció para nosotros. */
  return sd_bus_error_set_errnof(error, errno, "Failed to write to fd %i: %s", fd, strerror(errno));
}
