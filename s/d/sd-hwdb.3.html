NOMBRE

sd-hwdb - Acceso de solo lectura a la base de datos de descripción de hardware

SINOPSIS

#include <systemd/sd-hwdb.h>

pkg-config --cflags --libs libsystemd

DESCRIPCIÓN

sd-hwdb.h es parte de libsystemd(3) y permite el acceso de solo lectura a la base de datos de propiedades de hardware de systemd. Consulte hwdb(7) y systemd-hwdb(8) para obtener más información sobre la base de datos.

Consulte sd_hwdb_new(3) y sd_hwdb_get(3) para obtener información sobre las funciones disponibles.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un subproceso paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros subprocesos.

VER TAMBIÉN
