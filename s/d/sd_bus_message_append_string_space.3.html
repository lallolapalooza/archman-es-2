sd_bus_message_append_string_space(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_MESSAGE_APPEND_STRING_MEMFD(3) sd_bus_message_append_string_memfd SD_BUS_MESSAGE_APPEND_STRING_MEMFD(3)

NOMBRE

sd_bus_message_append_string_memfd, sd_bus_message_append_string_iovec, sd_bus_message_append_string_space - Adjuntar una cadena a un mensaje

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_message_append_string_memfd(sd_bus_message *m, int memfd);

int sd_bus_message_append_string_iovec(sd_bus_message *m, const struct iovec *iov, unsigned n);

int sd_bus_message_append_string_space(sd_bus_message *m, size_t size, char **s);

DESCRIPCIÓN

Las funciones sd_bus_message_append_string_memfd() y sd_bus_message_append_string_iovec() se pueden usar para adjuntar una única cadena (elemento de tipo "s") al mensaje m.

En el caso de sd_bus_message_append_string_memfd(), el contenido de memfd constituye la cadena. Debe cumplir las mismas restricciones descritas para el tipo "s" en sd_bus_message_append_basic(3).

En el caso de sd_bus_message_append_string_iovec(), la carga útil de iov constituye la cadena. Debe cumplir las mismas restricciones descritas para el tipo "s" en sd_bus_message_append_basic(3).

El argumento iov debe apuntar a n estructuras struct iovec. Cada estructura puede tener el campo iov_base establecido, en cuyo caso la memoria apuntada se copiará en el mensaje, o no establecido, en cuyo caso se insertará un bloque de espacios (ASCII 32) de longitud iov_len. La memoria apuntada por iov puede modificarse después de esta llamada.

La función sd_bus_message_append_string_space() reserva espacio para una cadena en el mensaje m. Se comporta de forma similar a sd_bus_message_append_basic() con el tipo "s", pero en lugar de copiar una cadena en el mensaje, devuelve un puntero al área de destino al llamador en el puntero p. Se asigna espacio para la cadena de longitud size más el terminador NUL.

VALOR DE RETORNO

En caso de éxito, estas llamadas devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Parámetro especificado inválido.

-EPERM

El mensaje ha sido sellado.

-ESTALE

El mensaje está en estado inválido.

-ENXIO

El mensaje no se puede adjuntar.

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un subproceso paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros subprocesos.
