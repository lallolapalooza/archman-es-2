sd_bus_object_path_is_valid(3)

SD_BUS_INTERFACE_NAME_IS_VALID(3) sd_bus_interface_name_is_valid SD_BUS_INTERFACE_NAME_IS_VALID(3)

NOMBRE

sd_bus_interface_name_is_valid, sd_bus_service_name_is_valid, sd_bus_member_name_is_valid, sd_bus_object_path_is_valid - Comprobar si una cadena es un nombre de bus o una ruta de objeto válida

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_interface_name_is_valid(const char* p);

int sd_bus_service_name_is_valid(const char* p);

int sd_bus_member_name_is_valid(const char* p);

int sd_bus_object_path_is_valid(const char* p);

DESCRIPCIÓN

sd_bus_interface_name_is_valid() comprueba si una cadena dada p es un nombre de interfaz de bus sintácticamente válido. De manera similar, sd_bus_service_name_is_valid() comprueba si el argumento es un nombre de servicio de bus válido, sd_bus_member_name_is_valid() comprueba si el argumento es un nombre de miembro de interfaz de bus válido, y sd_bus_object_path_is_valid() comprueba si el argumento es una ruta de objeto de bus válida. Estas funciones generalmente comprueban que solo se utilizan caracteres permitidos y que la longitud de la cadena está dentro de los límites.

VALOR DE RETORNO

Estas funciones devuelven 1 si el argumento es un nombre de interfaz / servicio / miembro o ruta de objeto válida, y 0 si no lo es. Si el argumento es NULL, se devuelve un error.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El parámetro p es NULL.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que está declarado como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar las llamadas a setenv() solo desde una fase temprana del programa cuando aún no se han iniciado otros hilos.

HISTORIAL

sd_bus_interface_name_is_valid(), sd_bus_service_name_is_valid(), sd_bus_member_name_is_valid(), y sd_bus_object_path_is_valid() se añadieron en la versión 246.
