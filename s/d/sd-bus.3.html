SINOPSIS

#include <systemd/sd-bus.h>

DESCRIPCIÓN

sd-bus.h es parte de libsystemd(3) y proporciona una implementación de un cliente D-Bus IPC. Consulte https://www.freedesktop.org/software/dbus/ para obtener más información sobre D-Bus IPC.

sd-bus(3) — systemd 258.2

NAME

sd-bus - Extended Inter-Process Communication implementation

SYNOPSIS

#include <systemd/sd-bus.h>

DESCRIPTION

The sd-bus library provides an implementation of the D-Bus specification, which is a message bus system, a low-level inter-process communication (IPC) mechanism that is used for various purposes in modern Linux operating systems.

The library is designed for efficiency, ease of use, and multi-threading. It aims to be a simpler and more modern alternative to the older libdbus-1(3) library.

The primary types provided by the library are:

sd_bus*
Represents a connection to a D-Bus bus (either the system bus, the session bus, or a private bus).
sd_bus_message*
Represents a D-Bus message, which can be a method call, a method return, an error, or a signal.
sd_bus_error*
Represents a D-Bus error.
sd_bus_slot*
Represents a listener for D-Bus signals or method calls.

The library offers functions for managing bus connections, sending and receiving messages, registering signal handlers and method call handlers, and more. It integrates seamlessly with the sd-event(3) event loop for asynchronous operation.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa, cuando aún no se han iniciado otros hilos.
