sd_bus_reply_method_errorf(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_REPLY_METHOD_ERROR(3) sd_bus_reply_method_error SD_BUS_REPLY_METHOD_ERROR(3)

NOMBRE

sd_bus_reply_method_error, sd_bus_reply_method_errorf, sd_bus_reply_method_errorfv, sd_bus_reply_method_errno, sd_bus_reply_method_errnof, sd_bus_reply_method_errnofv - Responder con un error a una llamada de método D-Bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_reply_method_error(sd_bus_message *call, const sd_bus_error *e);

int sd_bus_reply_method_errorf(sd_bus_message *call, const char *name, const char *format, ...);

int sd_bus_reply_method_errorfv(sd_bus_message *call, const char *name, const char *format, va_list ap);

int sd_bus_reply_method_errno(sd_bus_message *call, int error, const sd_bus_error *p);

int sd_bus_reply_method_errnof(sd_bus_message *call, int error, const char *format, ...);

int sd_bus_reply_method_errnofv(sd_bus_message *call, int error, const char *format, va_list ap);

DESCRIPCIÓN

La función sd_bus_reply_method_error() envía una respuesta de error al mensaje call. La estructura de error e especifica el error a enviar y se utiliza como se describe en sd_bus_message_new_method_error(3). Si no se espera una respuesta a call, esta función se completa sin enviar una respuesta.

sd_bus_reply_method_errorf() es a sd_bus_reply_method_error() lo que sd_bus_message_new_method_errorf() es a sd_bus_message_new_method_error().

sd_bus_reply_method_errno() es a sd_bus_reply_method_error() lo que sd_bus_message_new_method_errno() es a sd_bus_message_new_method_error().

sd_bus_reply_method_errnof() es a sd_bus_reply_method_error() lo que sd_bus_message_new_method_errnof() es a sd_bus_message_new_method_error().

VALOR DE RETORNO

Esta función devuelve un entero no negativo si la respuesta de error se envió correctamente o si call no espera una respuesta. En caso de error, devuelve un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El parámetro de entrada call es NULL.

call no es un mensaje de llamada a método.

call no está adjunto a un bus.

El parámetro de error e para sd_bus_reply_method_error() no está establecido, ver sd_bus_error_is_set(3).

-EPERM

El mensaje call ha sido sellado.

-ENOTCONN

El bus al que está adjunto el mensaje call no está conectado.

-ENOMEM

Fallo en la asignación de memoria.

Además, se puede devolver cualquier error devuelto por sd_bus_send(3).

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer las llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
