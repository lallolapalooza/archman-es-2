NOMBRE

sd_device_get_syspath, sd_device_get_devpath, sd_device_get_sysname, sd_device_get_sysnum, sd_device_get_subsystem, sd_device_get_driver_subsystem, sd_device_get_devtype, sd_device_get_devname, sd_device_get_devnum, sd_device_get_ifindex, sd_device_get_driver, sd_device_get_diskseq, sd_device_get_device_id - Devuelve varios campos de los objetos de dispositivo

SINOPSIS

#include <systemd/sd-device.h>

int sd_device_get_syspath(sd_device *device, const char **ret);

int sd_device_get_devpath(sd_device *device, const char **ret);

int sd_device_get_sysname(sd_device *device, const char **ret);

int sd_device_get_sysnum(sd_device *device, const char **ret);

int sd_device_get_subsystem(sd_device *device, const char **ret);

int sd_device_get_driver_subsystem(sd_device *device, const char **ret);

int sd_device_get_devtype(sd_device *device, const char **ret);

int sd_device_get_devname(sd_device *device, const char **ret);

int sd_device_get_devnum(sd_device *device, dev_t *ret);

int sd_device_get_ifindex(sd_device *device, int *ret);

int sd_device_get_driver(sd_device *device, const char **ret);

int sd_device_get_diskseq(sd_device *device, uint64_t *ret);

int sd_device_get_device_id(sd_device *device, const char **ret);

DESCRIPCIÓN

sd_device_get_syspath() devuelve la ruta sysfs del registro de dispositivo especificado, incluyendo el prefijo /sys. Ejemplo: /sys/devices/virtual/tty/tty7

sd_device_get_devpath() devuelve la ruta sysfs del registro de dispositivo especificado, excluyendo el prefijo /sys. Ejemplo: /devices/virtual/tty/tty7

sd_device_get_sysname() devuelve el nombre sysfs del registro de dispositivo especificado, es decir, el último componente de la ruta sysfs. Ejemplo: "tty7" para el dispositivo /sys/devices/virtual/tty/tty7

sd_device_get_sysnum() devuelve el número de dispositivo sysfs del registro de dispositivo especificado, es decir, el sufijo numérico del último componente de la ruta sysfs. Ejemplo: "7" para el dispositivo /sys/devices/virtual/tty/tty7

sd_device_get_subsystem() devuelve el subsistema del kernel del registro de dispositivo especificado. Esta es una cadena corta que cabe en un nombre de archivo, y por lo tanto no contiene una barra y no puede estar vacía. Ejemplo: "tty", "block" o "net".

sd_device_get_driver_subsystem() devuelve el tipo de bus conectado de los dispositivos cargados por el registro de dispositivo controlador especificado. Por ejemplo, cuando se especifica el dispositivo controlador "iwlwifi", que es utilizado por las interfaces de red inalámbricas conectadas al bus PCI, esta función devuelve "pci". Esta función solo tiene éxito cuando sd_device_get_subsystem() devuelve "drivers". Ejemplo: "pci", "i2c", o "hid".

sd_device_get_devtype() devuelve el tipo de dispositivo del registro de dispositivo especificado, si el subsistema gestiona múltiples tipos de dispositivos. Ejemplo: para dispositivos del subsistema "block" este puede ser "disk" o "partition"

sd_device_get_devname() devuelve la ruta del nodo del dispositivo del registro de dispositivo especificado si el dispositivo tiene un nodo de dispositivo. Ejemplo: para /sys/devices/virtual/tty/tty7 la cadena /dev/tty7 típicamente se devuelve.

sd_device_get_devnum() devuelve el mayor/menor del nodo del dispositivo (es decir, dev_t) del registro de dispositivo especificado si el dispositivo tiene un nodo de dispositivo (es decir, el devuelto por sd_device_get_devname()). Para dispositivos que pertenecen al subsistema "block" esto se refiere a un nodo de dispositivo de bloque, en todos los demás casos a un nodo de dispositivo de carácter. Ejemplo: para el dispositivo /sys/devices/virtual/tty/tty7 esto típicamente devuelve el número de dispositivo con mayor/menor "4:7".

sd_device_get_ifindex() devuelve el índice de la interfaz de red del registro de dispositivo especificado, si el dispositivo encapsula un dispositivo de interfaz de red, es decir, pertenece al subsistema "net". Ejemplo: la interfaz "lo" típicamente tiene el índice de interfaz 1.

sd_device_get_driver() devuelve el nombre del controlador del kernel adjunto al dispositivo. Tenga en cuenta que el campo del controlador se establece en los dispositivos consumidos por el controlador, no en el dispositivo creado por él. Ejemplo: un dispositivo PCI /sys/bus/pci/devices/0000:00:1f.6 podría estar adjunto a un controlador "e1000e".

sd_device_get_diskseq() devuelve el número de secuencia de disco del kernel del dispositivo de bloque. Este número aumenta monotónicamente cada vez que cambia el medio de respaldo de un dispositivo de bloque sin que cambie el nombre del dispositivo, y es relevante para los dispositivos de bloque que encapsulan dispositivos con medios cambiantes (por ejemplo, disquete o CD-ROM), o dispositivos de bloque de loopback. Solo definido para dispositivos de bloque, es decir, aquellos del subsistema "block".

sd_device_get_device_id() devuelve la cadena corta que identifica el registro del dispositivo. Cuando el ID del dispositivo obtenido por la función para un registro de dispositivo especificado se pasa a sd_device_new_from_device_id(), se obtendrá una nueva instancia del mismo registro de dispositivo. Cuando se especifica un dispositivo de bloque o de carácter, que tiene un nodo de dispositivo correspondiente, esto devuelve "b" o "c", respectivamente, seguido de los números mayor y menor del nodo del dispositivo separados por dos puntos. Ejemplo: "b259:1" o "c10:121". Cuando se especifica un dispositivo de interfaz de red, esto devuelve "n" seguido del índice de la interfaz, que se puede obtener mediante sd_device_get_ifindex(). Ejemplo: "n1". Cuando se especifica un dispositivo en el subsistema "driver", esto devuelve "+drivers:" seguido de su subsistema de controlador y nombre sysfs separados por dos puntos. Ejemplo: "+drivers:pci:iwlwifi" para un registro de dispositivo controlador cuyo subsistema de controlador es "pci" y el nombre sysfs es "iwlwifi", Cuando se especifica otro tipo de dispositivo, esta función devuelve "+" seguido de su subsistema y nombre sysfs separados por dos puntos. Ejemplo: "+acpi:ACPI0003:00", "+input:input16", o "+pci:0000:00:1f.6".

VALOR DEVUELTO

En caso de éxito, estas llamadas devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Un parámetro especificado es inválido.

Añadido en la versión 251.

-ENOENT

El campo solicitado no está presente en el registro del dispositivo.

Añadido en la versión 251.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada contra y enlazada con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara que no es seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

sd_device_get_sysname.3.en.html

NAME

sd_device_get_sysname, sd_device_get_driver, sd_device_get_subsystem, sd_device_get_device_id — obtener información de un dispositivo

SYNOPSIS

#include <systemd/sd-device.h>
                    
int sd_device_get_sysname(sd_device *device, const char **name);
int sd_device_get_driver(sd_device *device, const char **driver);
int sd_device_get_subsystem(sd_device *device, const char **subsystem);
int sd_device_get_device_id(sd_device *device, const char **id);

DESCRIPTION

Las funciones sd_device_get_sysname(), sd_device_get_driver(), sd_device_get_subsystem() y sd_device_get_device_id() exponen varias propiedades del dispositivo pasado en el argumento device.

La función sd_device_get_sysname() devuelve el nombre del dispositivo en el subsistema sysfs. Este es el nombre que se encuentra en directorios como /sys/block/sda o /sys/class/net/eth0.

La función sd_device_get_driver() devuelve el nombre del controlador que está gestionando este dispositivo. Por ejemplo, podría ser e1000e para una interfaz de red.

La función sd_device_get_subsystem() devuelve el nombre del subsistema de sysfs al que pertenece este dispositivo. Por ejemplo, podría ser block, net o input.

La función sd_device_get_device_id() devuelve un identificador único para el dispositivo en su subsistema. Este identificador es a menudo el mismo que el valor devuelto por sd_device_get_sysname(), pero puede ser diferente para ciertos subsistemas (por ejemplo, los dispositivos USB tendrán IDs más complejos).

Los punteros devueltos en name, driver, subsystem e id apuntan a cadenas de caracteres internas de la biblioteca systemd y no deben modificarse ni liberarse. Son válidos hasta que el objeto sd_device se libere o se modifique de manera que cause la actualización de estas propiedades.

RETURN VALUE

En caso de éxito, estas funciones devuelven 0 o un valor positivo. En caso de error, devuelven un código de error negativo. Si el dispositivo no tiene un valor para la propiedad solicitada (por ejemplo, no hay un controlador asociado), devuelven 0 y el puntero de salida se establece en NULL.

NOTES

Estas funciones requieren un objeto sd_device válido. Los objetos sd_device se pueden obtener usando funciones como sd_device_get_devname() o a través del escaneo de dispositivos con sd_device_enumerate() y sd_device_get_parent().

HISTORY

sd_device_get_driver_subsystem() y sd_device_get_device_id() se agregaron en la versión 257.
