NOMBRE

sd-device - API para enumerar e inspeccionar dispositivos locales

SINOPSIS

#include <systemd/sd-device.h>

pkg-config --cflags --libs libsystemd

DESCRIPCIÓN

sd-device.h es parte de libsystemd(3) y proporciona una API para inspeccionar y enumerar dispositivos en el sistema local. Proporciona una interfaz programática a la base de datos de dispositivos y sus propiedades gestionada por systemd-udevd.service(8). Esta API es un reemplazo para libudev(3) y libudev.h.

Vea

sd_device_get_syspath(3),
sd_device_ref(3)
para más información sobre las funciones disponibles.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, la cual puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos múltiples (multi-thread-safe). Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

VER TAMBIÉN

systemd(1), sd-event(3), udevadm(8)
