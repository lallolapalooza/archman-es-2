Propósito:

!>
!> SDRGES3 comprueba el controlador del problema de valores propios generalizados no simétricos
!> (forma de Schur) SGGES3.
!>
!> SGGES3 factoriza A y B como Q S Z'  y Q T Z' , donde ' significa
!> transpuesta, T es triangular superior, S está en forma de Schur generalizada
!> (triangular superior en bloque, con bloques de 1x1 y 2x2 en la diagonal,
!> los bloques de 2x2 corresponden a pares de valores propios generalizados conjugados complejos),
!> y Q y Z son ortogonales. También calcula los valores propios generalizados (alpha(j),beta(j)), j=1,...,n,
!> Por lo tanto, w(j) = alpha(j)/beta(j) es una raíz de la ecuación característica
!>                 det( A - w(j) B ) = 0
!> Opcionalmente, también reordena los valores propios para que un grupo seleccionado
!> de valores propios aparezca en el bloque diagonal principal de las
!> formas de Schur.
!>
!> Cuando se llama a SDRGES3, se especifica un número de tamaños de matriz ()
!> y un número de tipos de matriz.  Para cada tamaño ()
!> y cada TIPO de matriz, se generará y utilizará un par de matrices (A, B)
!> para la prueba. Para cada par de matrices, se realizarán las siguientes 13 pruebas
!> y se compararán con el umbral THRESH, excepto las pruebas (5), (11) y (13).
!>
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp ) (sin ordenar los valores propios)
!>
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp ) (sin ordenar los valores propios)
!>
!>
!> (3)   | I - QQ' | / ( n ulp ) (sin ordenar los valores propios)
!>
!>
!> (4)   | I - ZZ' | / ( n ulp ) (sin ordenar los valores propios)
!> (5)   si A está en forma de Schur (es decir, forma cuasi-triangular)
!>       (sin ordenar los valores propios)
!>
!> (6)   si los valores propios = bloques diagonales de la forma de Schur (S, T),
!>       es decir, se prueba el máximo sobre j de D(j)  donde:
!>
!>       si alpha(j) es real:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) es complejo:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>       y S y T son aquí los bloques diagonales de 2x2 de S y T
!>       correspondientes a los valores propios j-ésimo y (j+1)-ésimo.
!>       (sin ordenar los valores propios)
!>
!> (7)   | (A,B) - Q (S,T) Z' | / ( | (A,B) | n ulp )
!>            (con ordenación de valores propios).
!>
!> (8)   | I - QQ' | / ( n ulp ) (con ordenación de valores propios).
!>
!> (9)   | I - ZZ' | / ( n ulp ) (con ordenación de valores propios).
!>
!> (10)  si A está en forma de Schur (es decir, forma cuasi-triangular)
!>       (con ordenación de valores propios).
!>
!> (11)  si los valores propios = bloques diagonales de la forma de Schur (S, T),
!>       es decir, se prueba el máximo sobre j de D(j)  donde:
!>
!>       si alpha(j) es real:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) es complejo:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>       y S y T son aquí los bloques diagonales de 2x2 de S y T
!>       correspondientes a los valores propios j-ésimo y (j+1)-ésimo.
!>       (con ordenación de valores propios).
!>
!> (12)  si la ordenación funcionó y SDIM es el número de valores propios
!>       que fueron SELECCIONADOS.

SDRGES3 — Real generalized Schur decomposition test routines.

SYNOPSIS

    SUBROUTINE SDRGES3( NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH,
                        NOUNIT, A, LDA, B, S, T, Q, LDQ, Z, ALPHAR,
                        ALPHAI, BETA, WORK, LWORK, RESULT, BWORK, INFO )
        INTEGER NSIZES, NN(*), NTYPES, ISEED(4), NOUNIT, LDA, LDQ,
                LWORK, INFO
        REAL THRESH, A(LDA,*), B(LDA,*), S(LDA,*), T(LDA,*),
             Q(LDQ,*), Z(LDQ,*), ALPHAR(*), ALPHAI(*), BETA(*),
             WORK(*), RESULT(15)
        LOGICAL DOTYPE(*), BWORK(*)

Function/Subroutine Documentation

SDRGES3 is a subroutine that tests the S/DGE{G,Q,R}S routines.

The generalized Schur decomposition is computed for a matrix pair (A, B) as follows: 

    Q' * A * Z = S
    Q' * B * Z = T

where S is upper triangular and T is upper triangular (or sometimes upper Hessenberg). Q and Z are orthogonal matrices. The generalized eigenvalues are then computed from the diagonal elements of S and T.

The routine SDRGES3 checks the accuracy of the generalized Schur decomposition by verifying the following properties:

  1. Orthogonality of Q and Z: Q'*Q = I, Z'*Z = I.
  2. Decomposition accuracy: A = Q*S*Z', B = Q*T*Z'.
  3. Schur form accuracy: The computed T is upper triangular.
  4. Eigenvalue accuracy: The computed generalized eigenvalues (ALPHAR(k) + i*ALPHAI(k)) / BETA(k) are correct.

Parameters

NSIZES

INTEGER. The number of sizes of matrices to use. If it is zero, SDRGES3 does nothing. NSIZES >= 0.

NN

INTEGER array, dimension (NSIZES). An array containing the sizes to be used for the matrices. Zero values will be skipped. NN >= 0.

NTYPES

INTEGER. The number of elements in DOTYPE. If it is zero, SDRGES3 does nothing. It must be at least zero. If it is MAXTYP+1 and NSIZES is 1, then an additional type, MAXTYP+1 is defined, which is to use whatever matrix is in A on input. This is only useful if DOTYPE(1:MAXTYP) is .FALSE. and DOTYPE(MAXTYP+1) is .TRUE. .

DOTYPE

LOGICAL array, dimension (NTYPES). If DOTYPE(j) is .TRUE., then for each size in NN a matrix of that size and of type j will be generated. If NTYPES is smaller than the maximum number of types defined (PARAMETER MAXTYP), then types NTYPES+1 through MAXTYP will not be generated. If NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES) will be ignored.

ISEED

INTEGER array, dimension (4). On entry ISEED specifies the seed of the random number generator. The array elements should be between 0 and 4095; if not they will be reduced mod 4096. Also, ISEED(4) must be odd. The random number generator uses a linear congruential sequence limited to small integers, and so should produce machine independent random numbers. The values of ISEED are changed on exit, and can be used in the next call to SDRGES3 to continue the same random number sequence.

THRESH

REAL. A test will count as passed if the computed error, as described above, does not exceed THRESH. Note that the error is scaled to be O(1), so THRESH should be a reasonably small multiple of 1, e.g., 10 or 100. In particular, it should not depend on the precision (single vs. double) or the size of the matrix. THRESH >= 0.

NOUNIT

INTEGER. The FORTRAN unit number for printing out error messages (e.g., if a routine returns IINFO not equal to 0.)

A

REAL array, dimension(LDA, max(NN)). Used to hold the original A matrix. Used as input only if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and DOTYPE(MAXTYP+1)=.TRUE. .

LDA

INTEGER. The leading dimension of A, B, S, and T. It must be at least 1 and at least max( NN ).

B

REAL array, dimension(LDA, max(NN)). Used to hold the original B matrix. Used as input only if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and DOTYPE(MAXTYP+1)=.TRUE. .

S

REAL array, dimension (LDA, max(NN)). The Schur form matrix computed from A by SGGES3. On exit, S contains the Schur form matrix corresponding to the matrix in A.

T

REAL array, dimension (LDA, max(NN)). The upper triangular matrix computed from B by SGGES3.

Q

REAL array, dimension (LDQ, max(NN)). The (left) orthogonal matrix computed by SGGES3.

LDQ

INTEGER. The leading dimension of Q and Z. It must be at least 1 and at least max( NN ).

Z

REAL array, dimension( LDQ, max(NN) ). The (right) orthogonal matrix computed by SGGES3.

ALPHAR

REAL array, dimension (max(NN)).

ALPHAI

REAL array, dimension (max(NN)).

BETA

REAL array, dimension (max(NN)). The generalized eigenvalues of (A,B) computed by SGGES3. ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) is the k-th generalized eigenvalue of A and B.

WORK

REAL array, dimension (LWORK).

LWORK

INTEGER. The dimension of the array WORK. LWORK >= MAX( 10*(N+1), 3*N*N ), where N is the largest matrix dimension.

RESULT

REAL array, dimension (15). The values computed by the tests described above. The values are currently limited to 1/ulp, to avoid overflow.

BWORK

LOGICAL array, dimension (N).

INFO

INTEGER.

  • = 0: successful exit
  • < 0: if INFO = -i, the i-th argument had an illegal value.
  • > 0: A routine returned an error code. INFO is the absolute value of the INFO value returned.
