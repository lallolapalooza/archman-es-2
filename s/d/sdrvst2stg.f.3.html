SDRVST2STG

Propósito:

!>
!>      SDRVST2STG  comprueba los drivers del problema de valores propios simétricos.
!>
!>              SSTEV calcula todos los valores propios y, opcionalmente, los
!>              vectores propios de una matriz tridiagonal simétrica real.
!>
!>              SSTEVX calcula valores propios seleccionados y, opcionalmente, los
!>              vectores propios de una matriz tridiagonal simétrica real.
!>
!>              SSTEVR calcula valores propios seleccionados y, opcionalmente, los
!>              vectores propios de una matriz tridiagonal simétrica real
!>              utilizando la Representación Relativamente Robusta donde sea posible.
!>
!>              SSYEV calcula todos los valores propios y, opcionalmente, los
!>              vectores propios de una matriz simétrica real.
!>
!>              SSYEVX calcula valores propios seleccionados y, opcionalmente, los
!>              vectores propios de una matriz simétrica real.
!>
!>              SSYEVR calcula valores propios seleccionados y, opcionalmente, los
!>              vectores propios de una matriz simétrica real
!>              utilizando la Representación Relativamente Robusta donde sea posible.
!>
!>              SSPEV calcula todos los valores propios y, opcionalmente, los
!>              vectores propios de una matriz simétrica en almacenamiento
!>              compacto.
!>
!>              SSPEVX calcula valores propios seleccionados y, opcionalmente, los
!>              vectores propios de una matriz simétrica en almacenamiento
!>              compacto.
!>
!>              SSBEV calcula todos los valores propios y, opcionalmente, los
!>              vectores propios de una matriz de banda simétrica real.
!>
!>              SSBEVX calcula valores propios seleccionados y, opcionalmente, los
!>              vectores propios de una matriz de banda simétrica real.
!>
!>              SSYEVD calcula todos los valores propios y, opcionalmente, los
!>              vectores propios de una matriz simétrica real utilizando
!>              un algoritmo de divide y vencerás.
!>
!>              SSPEVD calcula todos los valores propios y, opcionalmente, los
!>              vectores propios de una matriz simétrica en almacenamiento
!>              compacto, utilizando un algoritmo de divide y vencerás.
!>
!>              SSBEVD calcula todos los valores propios y, opcionalmente, los
!>              vectores propios de una matriz de banda simétrica real,
!>              utilizando un algoritmo de divide y vencerás.
!>
!>      Cuando se llama a SDRVST2STG, se especifica un número de tamaños de
!>      matriz () y un número de tipos de matriz. Para cada tamaño ()
!>      y cada tipo de matriz, se generará y utilizará una matriz para
!>      probar los drivers apropiados. Para cada matriz y cada rutina de
!>      driver llamada, se realizarán las siguientes pruebas:
!>
!>      (1)     | A - Z D Z' | / ( |A| n ulp )
!>
!>      (2)     | I - Z Z' | / ( n ulp )
!>
!>      (3)     | D1 - D2 | / ( |D1| ulp )
!>
!>      donde Z es la matriz de vectores propios devuelta cuando se da la
!>      opción de vector propio y D1 y D2 son los valores propios
!>      devueltos con y sin la opción de vector propio.
!>
!>      Los  se especifican mediante un array NN(1:NSIZES); el valor de
!>      cada elemento NN(j) especifica un tamaño.
!>      Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., se generará la matriz de tipo j.
!>      Actualmente, la lista de tipos posibles es:
!>
!>      (1)  La matriz cero.
!>      (2)  La matriz identidad.
!>
!>      (3)  Una matriz diagonal con valores propios espaciados uniformemente
!>           1, ..., ULP  y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1)
!>      (4)  Una matriz diagonal con valores propios espaciados geométricamente
!>           1, ..., ULP  y signos aleatorios.
!>      (5)  Una matriz diagonal con  valores propios
!>           1, ULP, ..., ULP y signos aleatorios.
!>
!>      (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8)  Una matriz de la forma  U' D U, donde U es ortogonal y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (9)  Una matriz de la forma  U' D U, donde U es ortogonal y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (10) Una matriz de la forma  U' D U, donde U es ortogonal y
!>           D tiene  entradas 1, ULP, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>      (16) Una matriz de banda con semi-ancho de banda elegido aleatoriamente entre
!>           0 y N-1, con valores propios espaciados uniformemente 1, ..., ULP
!>           con signos aleatorios.
!>      (17) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (18) Igual que (16), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>  NSIZES  INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          SDRVST2STG no hace nada. Debe ser al menos cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SDRVST2STG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es utilizar cualquier matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>          No modificado.
!>
!>  DOTYPE  LOGICAL array, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>          No modificado.
!>
!>  ISEED   INTEGER array, dimension (4)
!>          En la entrada I

NAME

sdrvst2stg

driver routine for testing SSYEVR, SSPEVR, SSBEVR, SSYEVR_2STAGE

SYNOPSIS

SUBROUTINE SDRVST2STG(
     NMAX, NBMAX, THRESH,
     DRVVER, PREF, INFO )

Parameters:

INTEGER
NMAX
INTEGER
NBMAX
REAL
THRESH
CHARACTER*3
DRVVER
CHARACTER*1
PREF
INTEGER
INFO

Function/Subroutine Documentation

This routine is a driver for testing the following routines:

    SSYEVR_2STAGE
    SSYEVR
    SSPEVR
    SSBEVR

The tests are performed for the following problem types:

    General symmetric eigenvalue problem: A * x = lambda * x
    where A is real symmetric.

The tests are performed for the following subroutine interfaces:

    SSYEVR_2STAGE( UPLO, JOBZ, RANGE, M, A, LDA, VL, VU, IL, IU, ABSTOL,
                   WORK, LWORK, TEMP, LWORK_TEMP, IWORK, LIWORK, D, SDISCR,
                   INFO )

    SSYEVR( UPLO, JOBZ, RANGE, M, A, LDA, VL, VU, IL, IU, ABSTOL,
            WORK, LWORK, IWORK, LIWORK, D, SDISCR, INFO )

    SSPEVR( UPLO, JOBZ, RANGE, M, AP, VL, VU, IL, IU, ABSTOL,
            WORK, LWORK, IWORK, LIWORK, D, SDISCR, INFO )

    SSBEVR( UPLO, JOBZ, RANGE, M, AB, LDAB, VL, VU, IL, IU, ABSTOL,
            WORK, LWORK, IWORK, LIWORK, D, SDISCR, INFO )

The following tables summarize the tests performed.

    Tests 1-24 are for SSYEVR_2STAGE and SSYEVR with UPLO='L'.
    Tests 1-12 are for SSYEVR_2STAGE.
    Tests 13-24 are for SSYEVR.

    Test 1: | A - U S U' | / ( |A| n ulp )        SSYEVR_2STAGE('L','N','A', ... )
    Test 2: | I - U U' | / ( n ulp )              SSYEVR_2STAGE('L','N','A', ... )
    Test 3: |D(with Z) - D(w/o Z)| / (|D| ulp)    SSYEVR_2STAGE('L','N','A', ... )
