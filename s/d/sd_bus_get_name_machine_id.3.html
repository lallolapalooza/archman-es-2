NOMBRE

sd_bus_get_name_machine_id - Recupera la identidad de la máquina de un cliente de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_get_name_machine_id(sd_bus *bus, const char *name, sd_id128_t *machine);

DESCRIPCIÓN

sd_bus_get_name_machine_id() recupera la identidad de máquina D-Bus de la máquina en la que se está ejecutando el cliente de bus identificado por name. Internamente, llama al método GetMachineId de la interfaz org.freedesktop.DBus.Peer. La identidad de máquina D-Bus es un UUID de 128 bits. En sistemas Linux que ejecutan systemd, esto corresponde al contenido de /etc/machine-id. En caso de éxito, la identidad de la máquina se almacena en machine.

VALOR DE RETORNO

En caso de éxito, esta función devuelve un entero no negativo. En caso de error, devuelve un código de error negativo al estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Un argumento es inválido.

-ENOPKG

El bus no se puede resolver.

-ECHILD

El bus se creó en un proceso, biblioteca o instancia de módulo diferente.

-ENOMEM

Fallo al asignar memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_get_name_machine_id() se añadió en la versión 221.
