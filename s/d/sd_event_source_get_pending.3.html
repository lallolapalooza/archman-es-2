NOMBRE

sd_event_source_get_pending - Determinar el estado pendiente de las fuentes de eventos

SINOPSIS

#include <systemd/sd-event.h>

int sd_event_source_get_pending(sd_event_source *source);

DESCRIPCIÓN

sd_event_source_get_pending() puede usarse para determinar si la fuente de eventos especificada como source ha visto eventos pero aún no ha sido despachada (y por lo tanto está marcada como "pendiente").

Inicialmente, los objetos de fuente de eventos no están marcados como pendientes cuando se crean con llamadas como sd_event_add_io(3), sd_event_add_time(3), con la excepción de aquellos creados con sd_event_add_defer(3) que se marcan inmediatamente como pendientes, y sd_event_add_exit(3) para los cuales el concepto de "pendiente" no está definido. Para más detalles, consulte las páginas del manual correspondientes.

En cada iteración del bucle de eventos, se despacha una fuente de eventos de aquellas marcadas como pendientes, en el orden definido por la prioridad de la fuente de eventos, establecida con sd_event_source_set_priority(3).

Para fuentes de eventos de E/S, creadas con sd_event_add_io(3), la llamada sd_event_source_get_io_revents(3) puede usarse para consultar el tipo de evento pendiente con más detalle.

VALOR DE RETORNO

En caso de éxito, sd_event_source_get_pending() devuelve un entero mayor que cero cuando la fuente de eventos está marcada como pendiente, y cero cuando no lo está. En caso de error, devuelve un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

source no es un puntero válido a un objeto sd_event_source.

-EDOM

source se refiere a un objeto de fuente de eventos creado con sd_event_add_exit(3).

-ENOMEM

No hay suficiente memoria.

-ESTALE

El bucle de eventos ya está terminado.

-ECHILD

El bucle de eventos se creó en un proceso, biblioteca o instancia de módulo diferente.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_event_source_get_pending() se agregó en la versión 229.
