SDRGEV

Propósito:

!>
!> SDRGEV comprueba la rutina de control de problemas de valores propios generalizados no simétricos SGGEV.
!>
!> SGGEV calcula para un par de matrices no simétricas n x n (A, B) los
!> valores propios generalizados y, opcionalmente, los vectores propios izquierdos y derechos.
!>
!> Un valor propio generalizado para un par de matrices (A, B) es un escalar w
!> o una relación alpha/beta = w, tal que A - w*B es singular. Normalmente
!> se representa como el par (alpha, beta), ya que hay una interpretación razonable
!> para beta=0, e incluso para ambos a cero.
!>
!> Un vector propio generalizado derecho correspondiente a un valor propio
!> generalizado w para un par de matrices (A, B) es un vector r tal que
!> (A - wB) * r = 0. Un vector propio generalizado izquierdo es un vector l
!> tal que l**H * (A - wB) = 0, donde l**H es la transpuesta conjugada de l.
!>
!> Cuando se llama a SDRGEV, se especifica un número de tamaño de matriz () y un
!> número de tipo de matriz. Para cada tamaño () y cada tipo de matriz, se generará
!> un par de matrices (A, B) y se utilizará para las pruebas. Para cada par de matrices,
!> se realizarán las siguientes pruebas y se compararán con el umbral THRESH.
!>
!> Resultados de SGGEV:
!>
!> (1) max sobre todos los pares de valores propios/vectores propios izquierdos (alpha/beta, l) de
!>
!>     | VL**H * (beta A - alpha B) | / ( ulp max(|beta A|, |alpha B|) )
!>
!>     donde VL**H es la transpuesta conjugada de VL.
!>
!> (2) | |VL(i)| - 1 | / ulp y si el componente más grande es real
!>
!>     VL(i) denota la i-ésima columna de VL.
!>
!> (3) max sobre todos los pares de valores propios/vectores propios izquierdos (alpha/beta, r) de
!>
!>     | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4) | |VR(i)| - 1 | / ulp y si el componente más grande es real
!>
!>     VR(i) denota la i-ésima columna de VR.
!>
!> (5) W(completo) = W(parcial)
!>     W(completo) denota los valores propios calculados cuando l y r
!>     también se calculan, y W(parcial) denota los valores propios
!>     calculados cuando solo se calculan W, solo W y r, o solo W y l.
!>
!> (6) VL(completo) = VL(parcial)
!>     VL(completo) denota los vectores propios izquierdos calculados cuando l
!>     y r se calculan, y VL(parcial) denota el resultado
!>     cuando solo se calcula l.
!>
!> (7) VR(completo) = VR(parcial)
!>     VR(completo) denota los vectores propios derechos calculados cuando l
!>     y r también se calculan, y VR(parcial) denota el resultado
!>     cuando solo se calcula l.
!>
!>
!> Matrices de Prueba
!> ---- --------
!>
!> Los tamaños de las matrices de prueba se especifican mediante una matriz
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los tipos se especifican mediante una matriz lógica DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., se generará el tipo de matriz j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1) ( 0, 0 ) (un par de matrices cero)
!>
!> (2) ( I, 0 ) (una identidad y una matriz cero)
!>
!> (3) ( 0, I ) (una identidad y una matriz cero)
!>
!> (4) ( I, I ) (un par de matrices identidad)
!>
!>         t   t
!> (5) ( J , J  ) (un par de bloques de Jordan transpuesta)
!>
!>                                     t                ( I   0  )
!> (6) ( X, Y ) donde  X = ( J   0  )  e Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad k x k y J un bloque de Jordan (k+1)x(k+1)
!>                       k=(N-1)/2
!>
!> (7) ( D, I ) donde D es diag( 0, 1,..., N-1 ) (una matriz diagonal
!>                       con esas entradas diagonales.)
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) donde big está cerca del desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 ) donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z donde T1 y T2 son matrices triangulares superiores
!>                        con entradas O(1) aleatorias sobre la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de la máquina.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1) = ( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorias.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     donde T1 y T2 son matrices triangulares superiores aleatorias.
!>
!>

Parámetros

NSIZES 
!>          NSIZES es ENTERO
!>          El número de tamaños de matrices a usar. Si es cero,
!>          SDRGES no hace nada. NSIZES >= 0.
!>

NN

!>          NN es una matriz ENTERA, dimensión (NSIZES)
!>          Una matriz que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. NN >= 0.
!>

NTYPES

!>          NTYPES es ENTERO
!>          El número de elementos en DOTYPE. Si es cero, SDRGES
!>          no hace nada.

DOTYPE

!> DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!> Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!> una matriz de ese tamaño y de tipo j.
!> Si NTYPES es menor que el número máximo de tipos definidos
!> (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!> MAXTYP no se generarán. Si NTYPES es mayor que MAXTYP,
!> DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES) se ignorarán.
!>

ISEED

!> ISEED es un array INTEGER, de dimensión (4)
!> En la entrada, ISEED especifica la semilla del generador de números
!> aleatorios. Los elementos del array deben estar entre 0 y 4095;
!> si no, se reducirán módulo 4096. Además, ISEED(4) debe ser impar.
!> El generador de números aleatorios utiliza una secuencia congruencial
!> lineal limitada a enteros pequeños y, por lo tanto, debería producir
!> números aleatorios independientes de la máquina. Los valores de ISEED
!> cambian a la salida y pueden usarse en la siguiente llamada a SDRGES
!> para continuar la misma secuencia de números aleatorios.
!>

THRESH

!> THRESH es REAL
!> Una prueba se contará como si la , calculada como se describe
!> anteriormente, excede THRESH. Tenga en cuenta que el error se
!> escala para ser O(1), por lo que THRESH debería ser un múltiplo
!> razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular,
!> no debe depender de la precisión (simple o doble) ni del tamaño
!> de la matriz. Debe ser al menos cero.
!>

NOUNIT

!> NOUNIT es INTEGER
!> El número de unidad FORTRAN para imprimir mensajes de error
!> (por ejemplo, si una rutina devuelve IERR distinto de 0).
!>

A

!> A es un array REAL,
!> de dimensión (LDA, max(NN))
!> Se usa para almacenar la matriz A original. Se usa solo como entrada
!> si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!> DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!> LDA es INTEGER
!> La dimensión principal de A, B, S y T.
!> Debe ser al menos 1 y al menos max( NN ).
!>

B

!> B es un array REAL,
!> de dimensión (LDA, max(NN))
!> Se usa para almacenar la matriz B original. Se usa solo como entrada
!> si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!> DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!> S es un array REAL,
!> de dimensión (LDA, max(NN))
!> La matriz de forma de Schur calculada a partir de A por SGGES. A la
!> salida, S contiene la matriz de forma de Schur correspondiente a la
!> matriz en A.
!>

T

!> T es un array REAL,
!> de dimensión (LDA, max(NN))
!> La matriz triangular superior calculada a partir de B por SGGES.
!>

Q

!> Q es un array REAL,
!> de dimensión (LDQ, max(NN))
!> La matriz de (vectores propios izquierdos) calculada por SGGEV.
!>

LDQ

!> LDQ es INTEGER
!> La dimensión principal de Q y Z. Debe ser
!> al menos 1 y al menos max( NN ).
!>

Z

!> Z es un array REAL, de dimensión( LDQ, max(NN) )
!> La matriz ortogonal de (vectores propios derechos) calculada por SGGES.
!>

QE

!> QE es un array REAL, de dimensión( LDQ, max(NN) )
!> QE contiene los vectores propios derechos o izquierdos calculados.
!>

LDQE

!> LDQE es INTEGER
!> La dimensión principal de QE. LDQE >= max(1,max(NN)).
!>

ALPHAR

!> ALPHAR es un array REAL, de dimensión (max(NN))
!>

ALPHAI

!> ALPHAI es un array REAL, de dimensión (max(NN))
!>

BETA

!> BETA es un array REAL, de dimensión (max(NN))
!> \verbatim
!> Los valores propios generalizados de (A,B) calculados por SGGEV.
!> ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) es el k-ésimo
!> valor propio generalizado de A y B.
!>

ALPHR1

!> ALPHR1 es un array REAL, de dimensión (max(NN))
!>

ALPHI1

!> ALPHI1 es un array REAL, de dimensión (max(NN))
!>

BETA1

!> BETA1 es un array REAL, de dimensión (max(NN))
!>
!> Al igual que ALPHAR, ALPHAI, BETA, estos arrays contienen los
!> valores propios de A y B, pero los calculados cuando SGGEV solo
!> calcula una descomposicion de valores propios parcial, es decir, no
!> los valores propios ni los vectores propios izquierdos y derechos.
!>

WORK

!> WORK es un array REAL, de dimensión (LWORK)
!>

LWORK

!> LWORK es INTEGER
!> El número de entradas en WORK. LWORK >= MAX( 8*N, N*(N+1) ).
!>

RESULT

!> RESULT es un array REAL, de dimensión (2)
!> Los valores calculados por las pruebas descritas anteriormente.
!> Actualmente, los valores se limitan a 1/ulp, para evitar desbordamientos.
!>

INFO

!> INFO es INTEGER
!> = 0: Salida exitosa
!> < 0: Si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!> > 0: Una rutina devolvió un código de error. INFO es el
!> valor absoluto del valor INFO devuelto.
!>
