NOMBRE

#include <systemd/sd-bus-vtable.h>

int sd_bus_emit_signal(sd_bus *bus, const char *path, const char *interface, const char *member, const char *types, ...);

DESCRIPCIÓN

sd_bus_emit_signal() es una función de conveniencia para inicializar un objeto de mensaje de bus y emitir la señal D-Bus correspondiente. Combina las funciones sd_bus_message_new_signal(3), sd_bus_message_append(3) y sd_bus_send(3) en una única llamada a función. sd_bus_emit_signalv() es equivalente a sd_bus_message_append(), excepto que se llama con una lista "va_list" en lugar de un número variable de argumentos.

sd_bus_emit_signal_to() y sd_bus_emit_signal_tov() son idénticas a sd_bus_emit_signal() y sd_bus_emit_signalv(), excepto que pueden emitir la señal a un único destino. Pase destination como NULL para difundir la señal.

sd_bus_emit_interfaces_added() y sd_bus_emit_interfaces_removed() se utilizan para implementar las señales InterfacesAdded y InterfacesRemoved de la interfaz org.freedesktop.DBus.ObjectManager. Toman una ruta cuyo interfaces han sido modificadas como argumento y una lista variable de interfaces que han sido añadidas o eliminadas, respectivamente. El último argumento pasado a sd_bus_emit_interfaces_added() y sd_bus_emit_interfaces_removed() *debe* ser NULL. Esto permite que ambas funciones determinen de forma segura el número de argumentos de interfaz pasados. sd_bus_emit_interfaces_added_strv() y sd_bus_emit_interfaces_removed_strv() son idénticas a sus respectivas contrapartes pero ambas toman la lista de interfaces como un único argumento en lugar de un número variable de argumentos.

sd_bus_emit_properties_changed() se utiliza para implementar la señal PropertiesChanged de la interfaz org.freedesktop.DBus.Properties. Toma una ruta de objeto, una interfaz y una lista variable de nombres de propiedad como argumentos. El último argumento pasado a sd_bus_emit_properties_changed() *debe* ser NULL. Esto le permite determinar de forma segura el número de nombres de propiedad pasados. sd_bus_emit_properties_changed_strv() es idéntica a sd_bus_emit_properties_changed() pero toma la lista de nombres de propiedad como un único argumento en lugar de un número variable de argumentos.

sd_bus_emit_object_added() y sd_bus_emit_object_removed() son funciones de conveniencia para emitir las señales InterfacesAdded o InterfacesRemoved para todas las interfaces registradas en una ruta de objeto específica, respectivamente. Esto incluye cualquier tabla de búsqueda principal si no se anulan por una tabla de búsqueda hija más aplicable. También incluye todas las interfaces D-Bus estándar implementadas por el propio sd-bus en cualquier objeto registrado.

Tenga en cuenta que sd_bus_emit_interfaces_added(), sd_bus_emit_interfaces_removed(), sd_bus_emit_object_added() y sd_bus_emit_object_removed() requieren que se haya registrado un gestor de objetos en la ruta de objeto dada o en una de sus rutas de objeto padre utilizando sd_bus_add_object_manager(3).

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven un entero no negativo. En caso de error, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Uno de los parámetros requeridos es NULL o inválido. Se pasó una interfaz D-Bus reservada como parámetro interface.

-ENOPKG

No se puede resolver el bus.

-ECHILD

El bus se creó en un proceso, biblioteca o instancia de módulo diferente.

-ENOMEM

Fallo en la asignación de memoria.

-ESRCH

Una de las funciones sd_bus_emit_interfaces_added(), sd_bus_emit_interfaces_removed(), sd_bus_emit_object_added() o sd_bus_emit_object_removed() se llamó en un objeto sin un gestor de objetos registrado en su propia ruta de objeto o en una de sus rutas de objeto padre.

Consulte las páginas del manual de sd_bus_message_new_signal(3), sd_bus_message_append(3) y sd_bus_send(3) para ver más errores posibles.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

NAME

sd_bus_emit_signalv, sd_bus_emit_signal_to, sd_bus_emit_signal_tov — Enviar una señal D-Bus

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_emit_signalv(sd_bus *u, const char *path, const char *interface, const char *member, const char *signature, va_list ap);

int sd_bus_emit_signal_to(sd_bus *u, const char *destination, const char *path, const char *interface, const char *member, const char *signature, ...);

int sd_bus_emit_signal_tov(sd_bus *u, const char *destination, const char *path, const char *interface, const char *member, const char *signature, va_list ap);

DESCRIPTION

These functions may be used to send a D-Bus signal. They construct a new D-Bus message, fill it with the provided arguments, and dispatch it onto the bus.

The signal is identified by its path, interface, member name, and the type signature of its arguments.

sd_bus_emit_signalv, sd_bus_emit_signal_to and sd_bus_emit_signal_tov are similar to sd_bus_emit_signal(3), but allow specifying the arguments using a va_list.

sd_bus_emit_signal_to and sd_bus_emit_signal_tov additionally take a destination parameter. If this is NULL, the signal is sent to all recipients. Otherwise, it is sent only to the specified destination service.

RETURN VALUE

On success, these functions return a non-negative integer. On failure, they return a negative error number.

NOTES

A va_list argument passed to sd_bus_emit_signalv or sd_bus_emit_signal_tov may be modified by the function. If the same va_list is to be used multiple times, it should be reset using va_copy(3).

The following functions were added in version 221:

sd_bus_emit_interfaces_removed_strv(), sd_bus_emit_properties_changed(), sd_bus_emit_properties_changed_strv().

sd_bus_emit_object_added(), and sd_bus_emit_object_removed() were added in version 222.

sd_bus_emit_signalv was added in version 246.

sd_bus_emit_signal_to and sd_bus_emit_signal_tov were added in version 253.
