SD_JOURNAL_GET_REALTIME_USEC(3) sd_journal_get_realtime_usec SD_JOURNAL_GET_REALTIME_USEC(3)

NOMBRE

sd_journal_get_realtime_usec, sd_journal_get_monotonic_usec - Leer marcas de tiempo de la entrada actual del journal

SINOPSIS

#include <systemd/sd-journal.h>

int sd_journal_get_realtime_usec(sd_journal *j, uint64_t *usec);

int sd_journal_get_monotonic_usec(sd_journal *j, uint64_t *usec, sd_id128_t *boot_id);

DESCRIPCIÓN

sd_journal_get_realtime_usec() obtiene la marca de tiempo en tiempo real (reloj de pared) de la entrada actual del journal. Toma dos argumentos: el objeto de contexto del journal y un puntero a un entero sin signo de 64 bits para almacenar la marca de tiempo. La marca de tiempo está en microsegundos desde la época, es decir, CLOCK_REALTIME.

sd_journal_get_monotonic_usec() obtiene la marca de tiempo monotónica de la entrada actual del journal. Toma tres argumentos: el objeto de contexto del journal, un puntero a un entero sin signo de 64 bits para almacenar la marca de tiempo, y un búfer de ID de 128 bits para almacenar el ID de arranque de la marca de tiempo monotónica. La marca de tiempo está en microsegundos desde el arranque de un arranque específico, es decir, CLOCK_MONOTONIC. Dado que el reloj monotónico comienza de nuevo con cada reinicio, solo define un punto en el tiempo bien definido cuando se usa junto con un identificador que identifica el arranque. Consulte sd_id128_get_boot(3) para obtener más información. Si se pasa el parámetro boot_id como NULL, la función fallará si la marca de tiempo monotónica de la entrada actual no corresponde al arranque del sistema actual.

Tenga en cuenta que estas funciones no funcionarán antes de que sd_journal_next(3) (o una llamada relacionada) se haya realizado al menos una vez, para posicionar el puntero de lectura en una entrada válida.

VALOR DE RETORNO

sd_journal_get_realtime_usec() y sd_journal_get_monotonic_usec() devuelven 0 en caso de éxito o un código de error negativo de estilo errno. Si se pasó el parámetro boot_id como NULL y la marca de tiempo monotónica de la entrada actual no corresponde al arranque del sistema actual, sd_journal_get_monotonic_usec() devuelve -ESTALE.

NOTAS

Todas las funciones enumeradas aquí son agnósticas al hilo y solo un hilo puede operar en un objeto determinado en un momento dado. Diferentes hilos pueden acceder al mismo objeto en diferentes momentos. Se pueden utilizar varios objetos independientes desde diferentes hilos en paralelo.

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd.

HISTORIAL

sd_journal_get_realtime_usec() y sd_journal_get_monotonic_usec() se agregaron en la versión 187.
