SDRVSG2STG

Propósito:

!>
!>      SDRVSG2STG comprueba los drivers del subproblema del autovalor generalizado real simétrico.
!>
!>              SSYGV calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un subproblema generalizado real simétrico-definido.
!>
!>              SSYGVD calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un subproblema generalizado real simétrico-definido
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              SSYGVX calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de un subproblema generalizado real simétrico-definido.
!>
!>              SSPGV calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un subproblema generalizado real simétrico-definido
!>              en almacenamiento empaquetado.
!>
!>              SSPGVD calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un subproblema generalizado real simétrico-definido
!>              en almacenamiento empaquetado utilizando un algoritmo de divide y vencerás.
!>
!>              SSPGVX calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de un subproblema generalizado real simétrico-definido
!>              en almacenamiento empaquetado.
!>
!>              SSBGV calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un subproblema generalizado real simétrico-banda
!>              definido.
!>
!>              SSBGVD calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un subproblema generalizado real simétrico-banda
!>              definido utilizando un algoritmo de divide y vencerás.
!>
!>              SSBGVX calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de un subproblema generalizado real simétrico-banda
!>              definido.
!>
!>      Cuando se llama a SDRVSG2STG, se especifica un número de tamaños de matriz () y un
!>      número de tipos de matriz. Para cada tamaño () y cada tipo de matriz, se generará
!>      una matriz A del tipo dado; también se generará una matriz B aleatoria bien condicionada
!>      y el par (A,B) se utilizará para probar los drivers.
!>
!>      Para cada par (A,B), se realizan las siguientes pruebas:
!>
!>      (1) SSYGV con ITYPE = 1 y UPLO ='U':
!>
!>              | A Z - B Z D | / ( |A| |Z| n ulp )
!>              | D - D2 | / ( |D| ulp )   donde D es calculado por
!>                                         SSYGV y D2 es calculado por
!>                                         SSYGV_2STAGE. Esta prueba
!>                                         solo se realiza para SSYGV
!>
!>      (2) igual que (1) pero llamando a SSPGV
!>      (3) igual que (1) pero llamando a SSBGV
!>      (4) igual que (1) pero con UPLO = 'L'
!>      (5) igual que (4) pero llamando a SSPGV
!>      (6) igual que (4) pero llamando a SSBGV
!>
!>      (7) SSYGV con ITYPE = 2 y UPLO ='U':
!>
!>              | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (8) igual que (7) pero llamando a SSPGV
!>      (9) igual que (7) pero con UPLO = 'L'
!>      (10) igual que (9) pero llamando a SSPGV
!>
!>      (11) SSYGV con ITYPE = 3 y UPLO ='U':
!>
!>              | B A Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (12) igual que (11) pero llamando a SSPGV
!>      (13) igual que (11) pero con UPLO = 'L'
!>      (14) igual que (13) pero llamando a SSPGV
!>
!>      SSYGVD, SSPGVD y SSBGVD realizaron las mismas 14 pruebas.
!>
!>      SSYGVX, SSPGVX y SSBGVX realizaron las pruebas anteriores 14 con
!>      el parámetro RANGE = 'A', 'N' e 'I', respectivamente.
!>
!>      Los se especifican mediante un array NN(1:NSIZES); el valor
!>      de cada elemento NN(j) especifica un tamaño.
!>      Los se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .VERDADERO., entonces se generará el tipo de matriz j.
!>      Este tipo se utiliza para la matriz A que tiene un semi-ancho de banda KA.
!>      B se genera como una matriz positiva definida bien condicionada
!>      con semi-ancho de banda KB (<= KA).
!>      Actualmente, la lista de tipos posibles para A es:
!>
!>      (1) La matriz cero.
!>      (2) La matriz identidad.
!>
!>      (3) Una matriz diagonal con entradas espaciadas uniformemente
!>           1, ..., ULP y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1)
!>      (4) Una matriz diagonal con entradas espaciadas geométricamente
!>           1, ..., ULP y signos aleatorios.
!>      (5) Una matriz diagonal con entradas
!>           1, ULP, ..., ULP y signos aleatorios.
!>
!>      (6) Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7) Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8) Una matriz de la forma U* D U, donde U es ortogonal y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (9) Una matriz de la forma U* D U, donde U es ortogonal y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>      (10) Una matriz de la forma U* D U, donde U es ortogonal y
!>           D tiene entradas 1, ULP, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (16) Igual que (8), pero con KA = 1 y KB = 1
!>      (17) Igual que (8), pero con KA = 2 y KB = 1
!>      (18) Igual que (8), pero con KA = 2 y KB = 2
!>      (19) Igual que (8), pero con KA = 3 y KB = 1
!>      (20) Igual que (8), pero con KA = 3 y KB = 2
!>      (21) Igual que (8), pero con KA = 3 y KB = 3
!> 
!>  NSIZES  ENTERO
!>          El número de tamaños de matrices a usar. Si es cero,
!>          SDRVSG2STG no hace nada. Debe ser al menos cero.
!>          No modificado.
!>
!>  NN      ARRAY ENTERO, dimensión (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>          No modificado.
!>
!>  NTYPES  ENTERO
!>          El número de elementos en DOTYPE. Si es cero, SDRVSG2STG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar cualquier matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSO. y
!>          DOTYPE(MAXTYP+1) es .VERDADERO. .
!>          No modificado.
!>

NAME

sdrvsg2stg - checks the nonsymmetric eigenvalue routines

SYNOPSIS

  SUBROUTINE SDRVSG2STG( DOTYPE, NTYPES, NN, NSIZES, ISEED, THRESH,
                           NOUNIT, A, LDA, B, LDB, D, Z, LDZ, AB, BB,
                           AP, BP, WORK, NWORK, IWORK, LIWORK, RESULT, INFO )
  LOGICAL             DOTYPE( NTYPES )
  INTEGER             NN( NSIZES ), NSIZES, ISEED( 4 ), NOUNIT, LDA,
                      LDB, LDZ, NWORK, LIWORK, INFO
  REAL                THRESH, A( LDA, * ), B( LDB, * ), D( * ),
                      Z( LDZ, * ), AB( LDA, * ), BB( LDB, * ),
                      AP( * ), BP( * ), WORK( * ), RESULT( 70 )
  INTEGER             NTYPES

Function/Subroutine Documentation

  This routine is a driver for the nonsymmetric eigenvalue routines.
  It is used by SLATMR to generate test matrices.

  Arguments
  =========

  DOTYPE  LOGICAL array, dimension (NTYPES)
          If DOTYPE(j) is .TRUE., then for each size in NN a
          matrix of that size and of type j will be generated.
          If NTYPES is smaller than the maximum number of types
          defined (PARAMETER MAXTYP), then types NTYPES+1 through
          MAXTYP will not be generated.  If NTYPES is larger
          than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
          will be ignored.
          Not modified.

  ISEED   INTEGER array, dimension (4)
          On entry ISEED specifies the seed of the random number
          generator. The array elements should be between 0 and 4095;
          if not they will be reduced mod 4096.  Also, ISEED(4) must
          be odd.  The random number generator uses a linear
          congruential sequence limited to small integers, and so
          should produce machine independent random numbers. The
          values of ISEED are changed on exit, and can be used in the
          next call to SDRVSG2STG to continue the same random number
          sequence.
          Modified.

  THRESH  REAL
          A test will count as  if the , computed as
          described above, exceeds THRESH.  Note that the error
          is scaled to be O(1), so THRESH should be a reasonably
          small multiple of 1, e.g., 10 or 100.  In particular,
          it should not depend on the precision (single vs. real)
          or the size of the matrix.  It must be at least zero.
          Not modified.

  NOUNIT  INTEGER
          The FORTRAN unit number for printing out error messages
          (e.g., if a routine returns IINFO not equal to 0.)
          Not modified.

  A       REAL             array, dimension (LDA , max(NN))
          Used to hold the matrix whose eigenvalues are to be
          computed.  On exit, A contains the last matrix actually
          used.
          Modified.

  LDA     INTEGER
          The leading dimension of A and AB.  It must be at
          least 1 and at least max( NN ).
          Not modified.

  B       REAL             array, dimension (LDB , max(NN))
          Used to hold the symmetric positive definite matrix for
          the generalized problem.
          On exit, B contains the last matrix actually
          used.
          Modified.

  LDB     INTEGER
          The leading dimension of B and BB.  It must be at
          least 1 and at least max( NN ).
          Not modified.

  D       REAL             array, dimension (max(NN))
          The eigenvalues of A. On exit, the eigenvalues in D
          correspond with the matrix in A.
          Modified.

  Z       REAL             array, dimension (LDZ, max(NN))
          The matrix of eigenvectors.
          Modified.

  LDZ     INTEGER
          The leading dimension of Z.  It must be at least 1 and
          at least max( NN ).
          Not modified.

  AB      REAL             array, dimension (LDA, max(NN))
          Workspace.
          Modified.

  BB      REAL             array, dimension (LDB, max(NN))
          Workspace.
          Modified.

  AP      REAL             array, dimension (max(NN)**2)
          Workspace.
          Modified.

  BP      REAL             array, dimension (max(NN)**2)
          Workspace.
          Modified.

  WORK    REAL array, dimension (NWORK)
          Workspace.
          Modified.

  NWORK   INTEGER
          The number of entries in WORK.  This must be at least
          1+5*N+2*N*lg(N)+3*N**2 where N = max( NN(j) ) and
          lg( N ) = smallest integer k such that 2**k >= N.
          Not modified.

  IWORK   INTEGER array, dimension (LIWORK)
          Workspace.
          Modified.

  LIWORK  INTEGER
          The number of entries in WORK.  This must be at least 6*N.
          Not modified.

  RESULT  REAL array, dimension (70)
          The values computed by the 70 tests described above.
          Modified.

  INFO    INTEGER
          If 0, then everything ran OK.
           -1: NSIZES < 0
           -2: Some NN(j) < 0
           -3: NTYPES < 0
           -5: THRESH < 0
           -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ).
          -16: LDZ < 1 or LDZ < NMAX.
          -21: NWORK too small.
          -23: LIWORK too small.
          If  SLATMR, SLATMS, SSYGV, SSPGV, SSBGV, SSYGVD, SSPGVD,
              SSBGVD, SSYGVX, SSPGVX or SSBGVX returns an error code,
              the absolute value of it is returned.
          Modified.

  ----------------------------------------------------------------------

       Some Local Variables and Parameters:
       ---- ----- --------- --- ----------
       ZERO, ONE       Real 0 and 1.
       MAXTYP          The number of types defined.
       NTEST           The number of tests that have been run
                       on this matrix.
       NTESTT          The total number of tests for this call.
       NMAX            Largest value in NN.
       NMATS           The number of matrices generated so far.
       NERRS           The number of tests which have exceeded THRESH
                       so far (computed by SLAFTS).
       COND, IMODE     Values to be passed to the matrix generators.
       ANORM           Norm of A; passed to matrix generators.

       OVFL, UNFL      Overflow and underflow thresholds.
       ULP, ULPINV     Finest relative precision and its inverse.
       RTOVFL, RTUNFL  Square roots of the previous 2 values.
               The following four arrays decode JTYPE:
       KTYPE(j)        The general type (1-10) for type .
       KMODE(j)        The MODE value to be passed to the matrix
                       generator for type .
       KMAGN(j)        The order of magnitude ( O(1),
                       O(overflow^(1/2) ), O(underflow^(1/2) )
