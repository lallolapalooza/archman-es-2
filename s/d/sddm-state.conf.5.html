NOMBRE

state.conf - configuración del gestor de pantalla sddm

SINOPSIS

~sddm/state.conf

DESCRIPCIÓN

Este archivo contiene la configuración del estado para el gestor de pantalla sddm sddm(1).

OPCIONES

Todas las opciones se configuran en la sección [Last]:

Sesión=
Nombre del archivo de sesión de la última sesión seleccionada. Esta sesión se preseleccionará cuando aparezca la pantalla de inicio de sesión. El valor predeterminado está vacío.
Usuario=
Nombre del último usuario que inició sesión. Este nombre de usuario se preseleccionará/mostrará cuando aparezca la pantalla de inicio de sesión. El valor predeterminado está vacío.

VER TAMBIÉN

sddm(1)

La documentación completa para sddm está disponible en https://github.com/sddm/sddm
