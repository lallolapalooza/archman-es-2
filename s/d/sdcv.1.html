NOMBRE

sdcv - versión de consola del programa StarDict

SINOPSIS

sdcv [ opciones ] [lista de palabras]

DESCRIPCIÓN

sdcv es una utilidad simple y multiplataforma basada en texto para trabajar con diccionarios en formato StarDict. Cada palabra de la "lista de palabras" puede ser una cadena con un '/' inicial para usar un algoritmo de búsqueda difusa, con un '|' inicial para usar búsqueda de texto completo, y la cadena puede contener '?' y '*' para búsqueda de expresiones regulares. Funciona en modo interactivo y no interactivo. Para salir del modo interactivo, presiona Ctrl+D. En modo interactivo, si sdcv fue compilado con soporte para la biblioteca readline, puedes usar las teclas ARRIBA y ABAJO para desplazarte por el historial.

OPCIONES

-h --help
Muestra el mensaje de ayuda y sale
-v --version
Muestra la versión y sale
-l --list-dicts
Muestra la lista de diccionarios disponibles y sale
-u --use-dict nombre_archivo
Para buscar, usa solo el diccionario con este nombre de libro
-n --non-interactive
Para usar en scripts
-x --only-data-dir
Para usar en scripts: usa solo los diccionarios en el directorio de datos, no busques en directorios de usuario y del sistema
-e --exact-search
No busques palabras similares de forma difusa, solo devuelve coincidencias exactas
-j --json
Imprime los resultados de list-dicts y búsquedas como json, no como texto plano. Para usar en el procesamiento automático de los resultados de una búsqueda de diccionario.
--utf8-output
Fuerza a sdcv a no convertir a la codificación de caracteres local, produce salida en utf8
--utf8-input
Fuerza a sdcv a no convertir desde la codificación de caracteres local, asume que la entrada está en utf8
--data-dir ruta/al/directorio
Usa este directorio como ruta al directorio de datos de stardict. Esto significa que sdcv busca diccionarios en data-dir/dic.
--color
Usa códigos de escape ANSI para colorear la salida de sdcv (no funciona con salida json).

ARCHIVOS

/usr/share/stardict/dic
$(XDG_DATA_HOME)/stardict/dic

Lugar donde sdcv espera encontrar diccionarios. En lugar de /usr/share/stardict/dic puedes usar cualquier directorio que desees, simplemente establece la variable de entorno STARDICT_DATA_DIR. Por ejemplo, si tienes diccionarios en /mnt/data/stardict-dicts/dic, establece STARDICT_DATA_DIR a /mnt/data/stardict-dicts.

$(XDG_DATA_HOME)/sdcv_history

Este archivo incluye las últimas $(SDCV_HISTSIZE) palabras que buscaste con sdcv. SDCV usa este archivo solo si fue compilado con soporte para la biblioteca readline.

$(XDG_CONFIG_HOME)/sdcv_ordering

Este es un archivo de texto que contiene un nombre de libro de diccionario por línea. Especifica en qué orden se deben mostrar los resultados de una búsqueda.

ENTORNO

Variables de Entorno Utilizadas Por sdcv:

STARDICT_DATA_DIR
Si está configurada, sdcv usa esta variable como el directorio de datos, esto significa que sdcv busca diccionarios en $STARDICT_DATA_DIR/dic
SDCV_HISTSIZE
Si está configurada, sdcv escribe en $(XDG_DATA_HOME)/sdcv_history (o $(SDCV_HISTFILE)) las últimas $(SDCV_HISTSIZE) palabras que buscas con sdcv. Si no está configurada, se guardan las últimas 2000 palabras en $(XDG_DATA_HOME)/sdcv_history.
SDCV_HISTFILE
Si está configurada, sdcv escribe su historial en $(SDCV_HISTFILE). Si no está configurada, se usará la ruta predeterminada $(XDG_DATA_HOME)/sdcv_history.
SDCV_PAGER
Si SDCV_PAGER está configurada, su valor se usa como el nombre del programa para mostrar el artículo del diccionario.

ERRORES

Envía informes de errores por correo electrónico a dushistov en mail punto ru. Asegúrate de incluir la palabra "sdcv" en algún lugar del campo "Subject:".
