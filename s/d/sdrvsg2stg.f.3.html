subrutina sdrvsg2stg (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) d, real, dimension( * ) d2, real, dimension( ldz, * ) z, integer ldz, real, dimension( lda, * ) ab, real, dimension( ldb, * ) bb, real, dimension( * ) ap, real, dimension( * ) bp, real, dimension( * ) work, integer nwork, integer, dimension( * ) iwork, integer liwork, real, dimension( * ) result, integer info)

SDRVSG2STG

Propósito:

!>
!>      SDRVSG2STG comprueba los drivers del problema general de autovalores
!>      simétricos reales.
!>
!>              SSYGV calcula todos los autovalores y, opcionalmente, los
!>              autovectores de un problema general de autovalores
!>              simétrico-definido real.
!>
!>              SSYGVD calcula todos los autovalores y, opcionalmente, los
!>              autovectores de un problema general de autovalores
!>              simétrico-definido real usando un algoritmo de divide y
!>              vencerás.
!>
!>              SSYGVX calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de un problema general de autovalores
!>              simétrico-definido real.
!>
!>              SSPGV calcula todos los autovalores y, opcionalmente, los
!>              autovectores de un problema general de autovalores
!>              simétrico-definido real en almacenamiento empaquetado.
!>
!>              SSPGVD calcula todos los autovalores y, opcionalmente, los
!>              autovectores de un problema general de autovalores
!>              simétrico-definido real en almacenamiento empaquetado
!>              usando un algoritmo de divide y vencerás.
!>
!>              SSPGVX calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de un problema general de autovalores
!>              simétrico-definido real en almacenamiento empaquetado.
!>
!>              SSBGV calcula todos los autovalores y, opcionalmente, los
!>              autovectores de un problema general de autovalores
!>              simétrico-definido real de banda.
!>
!>              SSBGVD calcula todos los autovalores y, opcionalmente, los
!>              autovectores de un problema general de autovalores
!>              simétrico-definido real de banda usando un algoritmo de
!>              divide y vencerás.
!>
!>              SSBGVX calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de un problema general de autovalores
!>              simétrico-definido real de banda.
!>
!>      Cuando se llama a SDRVSG2STG, se especifica un número de tamaños de
!>      matriz () y un número de tipos de matriz. Para cada tamaño () y cada
!>      tipo de matriz, se generará una matriz A del tipo dado; también se
!>      genera una matriz B aleatoria bien condicionada y el par (A,B) se
!>      utiliza para probar los drivers.
!>
!>      Para cada par (A,B), se realizan las siguientes pruebas:
!>
!>      (1) SSYGV con ITYPE = 1 y UPLO ='U':
!>
!>              | A Z - B Z D | / ( |A| |Z| n ulp )
!>              | D - D2 | / ( |D| ulp )   donde D es calculado por
!>                                         SSYGV y D2 es calculado por
!>                                         SSYGV_2STAGE. Esta prueba solo
!>                                         se realiza para SSYGV
!>
!>      (2) igual que (1) pero llamando a SSPGV
!>      (3) igual que (1) pero llamando a SSBGV
!>      (4) igual que (1) pero con UPLO = 'L'
!>      (5) igual que (4) pero llamando a SSPGV
!>      (6) igual que (4) pero llamando a SSBGV
!>
!>      (7) SSYGV con ITYPE = 2 y UPLO ='U':
!>
!>              | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (8) igual que (7) pero llamando a SSPGV
!>      (9) igual que (7) pero con UPLO = 'L'
!>      (10) igual que (9) pero llamando a SSPGV
!>
!>      (11) SSYGV con ITYPE = 3 y UPLO ='U':
!>
!>              | B A Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (12) igual que (11) pero llamando a SSPGV
!>      (13) igual que (11) pero con UPLO = 'L'
!>      (14) igual que (13) pero llamando a SSPGV
!>
!>      SSYGVD, SSPGVD y SSBGVD realizaron las mismas 14 pruebas.
!>
!>      SSYGVX, SSPGVX y SSBGVX realizaron las pruebas anteriores de 14
!>      con los parámetros RANGE = 'A', 'N' e 'I', respectivamente.
!>
!>      Los tamaños de matriz se especifican mediante un array NN(1:NSIZES);
!>      el valor de cada elemento NN(j) especifica un tamaño.
!>      Los tipos de matriz se especifican mediante un array lógico DOTYPE(
!>      1:NTYPES ); si DOTYPE(j) es .TRUE., entonces se generará el tipo de
!>      matriz j. Este tipo se utiliza para la matriz A que tiene un
!>      semibanda KA. B se genera como una matriz positiva definida bien
!>      condicionada con semibanda KB (<= KA).
!>      Actualmente, la lista de tipos posibles para A es:
!>
!>      (1) La matriz cero.
!>      (2) La matriz identidad.
!>
!>      (3) Una matriz diagonal con entradas espaciadas uniformemente
!>          1, ..., ULP y signos aleatorios.
!>          (ULP = (primer número mayor que 1) - 1)
!>      (4) Una matriz diagonal con entradas espaciadas geométricamente
!>          1, ..., ULP y signos aleatorios.
!>      (5) Una matriz diagonal con entradas
!>          1, ULP, ..., ULP y signos aleatorios.
!>
!>      (6) Igual que (4), pero multiplicada por SQRT( umbral de
!>          desbordamiento)
!>      (7) Igual que (4), pero multiplicada por SQRT( umbral de
!>          subdesbordamiento)
!>
!>      (8) Una matriz de la forma U* D U, donde U es ortogonal y
!>          D tiene entradas espaciadas uniformemente 1, ..., ULP con
!>          signos aleatorios en la diagonal.
!>
!>      (9) Una matriz de la forma U* D U, donde U es ortogonal y
!>          D tiene entradas espaciadas geométricamente 1, ..., ULP con
!>          signos aleatorios en la diagonal.
!>
!>      (10) Una matriz de la forma U* D U, donde U es ortogonal y
!>           D tiene entradas 1, ULP, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicada por SQRT( umbral de
!>           desbordamiento)
!>      (12) Igual que (8), pero multiplicada por SQRT( umbral de
!>           subdesbordamiento)
!>
!>      (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicada por SQRT( umbral de
!>           desbordamiento)
!>      (15) Igual que (13), pero multiplicada por SQRT( umbral de
!>           subdesbordamiento)
!>
!>      (16) Igual que (8), pero con KA = 1 y KB = 1
!>      (17) Igual que (8), pero con KA = 2 y KB = 1
!>      (18) Igual que (8), pero con KA = 2 y KB = 2
!>      (19) Igual que (8), pero con KA = 3 y KB = 1
!>      (20) Igual que (8), pero con KA = 3 y KB = 2
!>      (21) Igual que (8), pero con KA = 3 y KB = 3
!> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matriz a utilizar. Si es cero,
!>          SDRVSG2STG no hace nada. Debe ser mayor o igual que cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero serán omitidos. Los valores deben ser mayores o
!>          iguales que cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SDRVSG2STG
!>          no hace nada. Debe ser mayor o igual que cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar cualquier matriz que esté en A. Esto solo es útil si
!!>          DOTYPE(1:MAXTYP) es .FALSE. y DOTYPE(MAXTYP+1) es .TRUE.
!>          No modificado.
!>
!>  DOTYPE  LOGICAL array, dimension (NTYPES)
!>          Un array que especifica los tipos de matriz a utilizar. Si
!>          DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!>          No modificado.
!>
!>  ISEED   INTEGER array, dimension (4)
!>          Una semilla para los generadores de números aleatorios.
!>          Modificado.
!>
!>  THRESH  REAL
!>          Umbral para la norma de la matriz.
!>          No modificado.
!>
!>  NOUNIT  INTEGER
!>          Número de vectores unitarios a generar. Si es distinto de cero,
!>          los vectores unitarios L (autovectores) son generados; de lo
!>          contrario, solo se calculan los autovalores.
!>          No modificado.
!>
!>  A       REAL array, dimension (LDA, *)
!>          Matriz de entrada.
!>
!>  LDA     INTEGER
!>          Dimension principal del array A.
!>
!>  B       REAL array, dimension (LDB, *)
!>          Matriz de entrada.
!>
!>  LDB     INTEGER
!>          Dimension principal del array B.
!>
!>  D       REAL array, dimension (*)
!>          Array para almacenar los autovalores calculados.
!>
!>  D2      REAL array, dimension (*)
!>          Array para almacenar los autovalores calculados por SSYGV_2STAGE.
!>
!>  Z       REAL array, dimension (LDZ, *)
!>          Array para almacenar los autovectores calculados.
!>
!>  LDZ     INTEGER
!>          Dimension principal del array Z.
!>
!>  AB      REAL array, dimension (LDA, *)
!>          Matriz de entrada para las pruebas con SSBGV.
!>
!>  BB      REAL array, dimension (LDB, *)
!>          Matriz de entrada para las pruebas con SSBGV.
!>
!>  AP      REAL array, dimension (*)
!>          Matriz de entrada para las pruebas con SSPGV.
!>
!>  BP      REAL array, dimension (*)
!>          Matriz de entrada para las pruebas con SSPGV.
!>
!>  WORK    REAL array, dimension (*)
!>          Array de trabajo.
!>
!>  NWORK   INTEGER
!>          Longitud del array WORK.
!>
!>  IWORK   INTEGER array, dimension (*)
!>          Array de trabajo para enteros.
!>
!>  LIWORK  INTEGER
!>          Longitud del array IWORK.
!>
!>  RESULT  REAL array, dimension (*)
!>          Array para almacenar los resultados de las pruebas.
!>
!>  INFO    INTEGER
!>          Variable de salida. Si es 0, las pruebas fueron exitosas. Si es
!>          negativa, indica un error en los parámetros de entrada. Si es
!>          positiva, indica el número de pruebas fallidas.
!>
!>------------------------------------------------------------------------------
!>

Si NTYPES es mayor que MAXTYP, !> DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES) serán ignorados. !> No modificado. !> !> ISEED INTEGER array, dimension (4) !> A la entrada, ISEED especifica la semilla del generador de números !> aleatorios. Los elementos del array deben estar entre 0 y 4095; !> si no lo están, se reducirán módulo 4096. Además, ISEED(4) debe !> ser impar. El generador de números aleatorios utiliza una secuencia !> congruencial lineal limitada a enteros pequeños, y por lo tanto !> debería producir números aleatorios independientes de la máquina. !> Los valores de ISEED se modifican a la salida y pueden usarse en la !> siguiente llamada a SDRVSG2STG para continuar la misma secuencia de !> números aleatorios. !> Modificado. !> !> THRESH REAL !> Una prueba se considerará como si el error, calculado como !> se describe anteriormente, excede THRESH. Tenga en cuenta que el error !> se escala para ser O(1), por lo que THRESH debería ser un múltiplo !> razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular, !> no debe depender de la precisión (simple vs. real) ni del tamaño !> de la matriz. Debe ser al menos cero. !> No modificado. !> !> NOUNIT INTEGER !> El número de unidad FORTRAN para imprimir mensajes de error !> (por ejemplo, si una rutina devuelve IINFO distinto de 0). !> No modificado. !> !> A REAL array, dimension (LDA , max(NN)) !> Se utiliza para almacenar la matriz cuyos valores propios se van a !> calcular. A la salida, A contiene la última matriz utilizada !> realmente. !> Modificado. !> !> LDA INTEGER !> La dimensión principal de A y AB. Debe ser al menos 1 y al menos !> max( NN ). !> No modificado. !> !> B REAL array, dimension (LDB , max(NN)) !> Se utiliza para almacenar la matriz simétrica definida positiva !> para el problema generalizado. !> A la salida, B contiene la última matriz utilizada !> realmente. !> Modificado. !> !> LDB INTEGER !> La dimensión principal de B y BB. Debe ser al menos 1 y al menos !> max( NN ). !> No modificado. !> !> D REAL array, dimension (max(NN)) !> Los valores propios de A. A la salida, los valores propios en D !> corresponden con la matriz en A. !> Modificado. !> !> Z REAL array, dimension (LDZ, max(NN)) !> La matriz de vectores propios. !> Modificado. !> !> LDZ INTEGER !> La dimensión principal de Z. Debe ser al menos 1 y al menos !> max( NN ). !> No modificado. !> !> AB REAL array, dimension (LDA, max(NN)) !> Espacio de trabajo. !> Modificado. !> !> BB REAL array, dimension (LDB, max(NN)) !> Espacio de trabajo. !> Modificado. !> !> AP REAL array, dimension (max(NN)**2) !> Espacio de trabajo. !> Modificado. !> !> BP REAL array, dimension (max(NN)**2) !> Espacio de trabajo. !> Modificado. !> !> WORK REAL array, dimension (NWORK) !> Espacio de trabajo. !> Modificado. !> !> NWORK INTEGER !> El número de entradas en WORK. Debe ser al menos !> 1+5*N+2*N*lg(N)+3*N**2 donde N = max( NN(j) ) y !> lg( N ) = el entero más pequeño k tal que 2**k >= N. !> No modificado. !> !> IWORK INTEGER array, dimension (LIWORK) !> Espacio de trabajo. !> Modificado. !> !> LIWORK INTEGER !> El número de entradas en WORK. Debe ser al menos 6*N. !> No modificado. !> !> RESULT REAL array, dimension (70) !> Los valores calculados por las 70 pruebas descritas anteriormente. !> Modificado. !> !> INFO INTEGER !> Si 0, entonces todo funcionó correctamente. !> -1: NSIZES < 0 !> -2: Algún NN(j) < 0 !> -3: NTYPES < 0 !> -5: THRESH < 0 !> -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ). !> -16: LDZ < 1 o LDZ < NMAX. !> -21: NWORK es demasiado pequeño. !> -23: LIWORK es demasiado pequeño. !> Si SLATMR, SLATMS, SSYGV, SSPGV, SSBGV, SSYGVD, SSPGVD, !> SSBGVD, SSYGVX, SSPGVX o SSBGVX devuelve un código de error, !> se devuelve el valor absoluto del mismo. !> Modificado. !> !> ---------------------------------------------------------------------- !> !> Algunas variables y parámetros locales: !> ---- ----- --------- --- ---------- !> ZERO, ONE Reales 0 y 1. !> MAXTYP El número de tipos definidos. !> NTEST El número de pruebas que se han realizado !> en esta matriz. !> NTESTT El número total de pruebas para esta llamada. !> NMAX El valor más grande en NN. !> NMATS El número de matrices generadas hasta ahora. !> NERRS El número de pruebas que han excedido THRESH !> hasta ahora (calculado por SLAFTS). !> COND, IMODE Valores que se pasarán a los generadores de matrices. !> ANORM Norma de A; se pasa a los generadores de matrices. !> !> OVFL, UNFL Umbrales de desbordamiento y subdesbordamiento. !> ULP, ULPINV Precisión relativa más fina y su inversa. !> RTOVFL, RTUNFL Raíces cuadradas de los dos valores anteriores. !> Los siguientes cuatro arrays decodifican JTYPE: !> KTYPE(j) El tipo general (1-10) para el tipo . !> KMODE(j) El valor MODE que se pasará al generador de matrices !> para el tipo . !> KMAGN(j) El orden de magnitud ( O(1), !> O(overflow^(1/2) ), O(underflow^(1/2) ) !>
