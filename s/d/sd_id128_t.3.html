DESCRIPCIÓN

sd-id128.h es parte de libsystemd(3) y proporciona API para generar, convertir y comparar valores de ID de 128 bits. Los valores de ID de 128 bits procesados y generados por estas API son una generalización de los UUID de OSF tal como se definen en RFC 4122[1], pero utilizan un formato de cadena más simple. Estas funciones no imponen ninguna estructura en los IDs utilizados, a diferencia de los UUID de OSF o los GUID de Microsoft, pero son mayormente compatibles con esos tipos de IDs.

Un ID de 128 bits se implementa como la siguiente unión de tipos:

typedef union sd_id128 {
  uint8_t bytes[16];
  uint64_t qwords[2];
} sd_id128_t;

Esta unión permite acceder al ID de 128 bits como 16 bytes separados o dos palabras de 64 bits. Generalmente es más seguro acceder a los componentes del ID por su array de 8 bits para evitar problemas de endianness. Esta unión está destinada a ser pasada por valor (en lugar de por referencia) y puede ser manipulada directamente por los clientes.

Se definen un par de macros para denotar y decodificar IDs de 128 bits:

SD_ID128_MAKE() se usa para escribir un ID constante en el código fuente. Un modismo comúnmente utilizado es asignar un nombre a un ID usando esta macro:

#define SD_MESSAGE_COREDUMP SD_ID128_MAKE(fc,2e,22,bc,6e,e6,47,b6,b9,07,29,ab,34,a2,50,b1)

SD_ID128_NULL define un ID que consiste únicamente en bytes NUL (es decir, todos los bits apagados).

SD_ID128_ALLF define un ID que consiste únicamente en bytes 0xFF (es decir, todos los bits encendidos).

SD_ID128_MAKE_STR() es similar a SD_ID128_MAKE(), pero crea una expresión const char* que se puede usar convenientemente en formatos de mensajes y similares:

#include <stdio.h>
#define SD_MESSAGE_COREDUMP_STR SD_ID128_MAKE_STR(fc,2e,22,bc,6e,e6,47,b6,b9,07,29,ab,34,a2,50,b1)
int main(int argc, char **argv) {
  puts("Match for coredumps: MESSAGE_ID=" SD_MESSAGE_COREDUMP_STR);
}

SD_ID128_CONST_STR() convierte IDs constantes en cadenas constantes para su salida. El siguiente código de ejemplo generará la cadena "fc2e22bc6ee647b6b90729ab34a250b1":

int main(int argc, char *argv[]) {
  puts("Match for coredumps: %s", SD_ID128_CONST_STR(SD_MESSAGE_COREDUMP));
}

SD_ID128_FORMAT_STR y SD_ID128_FORMAT_VAL() se usan para formatear un ID en una cadena de formato printf(3), como se muestra en el siguiente ejemplo:

int main(int argc, char *argv[]) {
  sd_id128_t id;
  id = SD_ID128_MAKE(ee,89,be,71,bd,6e,43,d6,91,e6,c5,5d,eb,03,02,07);
  printf("The ID encoded in this C file is " SD_ID128_FORMAT_STR ".\n", SD_ID128_FORMAT_VAL(id));
  return 0;
}

SD_ID128_UUID_FORMAT_STR y SD_ID128_MAKE_UUID_STR() son similares a SD_ID128_FORMAT_STR y SD_ID128_MAKE_STR(), pero incluyen guiones separadores para ajustarse a la "representación canónica de UUID[2]". Formatean la cadena basándose en las reglas de la Variante 1 de RFC4122[1], es decir, convirtiendo desde el orden de bytes Big Endian. Esto coincide con el comportamiento de la mayoría de la otra infraestructura del espacio de usuario de Linux. Probablemente sea mejor evitar los UUID de otras variantes para evitar ambigüedades innecesarias. Todos los IDs de 128 bits generados por las API de sd-id128 se ajustan estrictamente a los UUID de Variante 1 Versión 4, según RFC 4122.

sd_id128_equal() compara dos IDs de 128 bits:

int main(int argc, char *argv[]) {
  sd_id128_t a, b, c;
  a = SD_ID128_MAKE(ee,89,be,71,bd,6e,43,d6,91,e6,c5,5d,eb,03,02,07);
  b = SD_ID128_MAKE(f2,28,88,9c,5f,09,44,15,9d,d7,04,77,58,cb,e7,3e);
  c = a;
  assert(sd_id128_equal(a, c));
  assert(!sd_id128_equal(a, b));
  return 0;
}

sd_id128_string_equal() es similar a sd_id128_equal(), pero el primer ID se formatea como const char*. Se aplican las mismas restricciones que al primer argumento de sd_id128_from_string().

sd_id128_is_null() comprueba si un ID consiste únicamente en bytes NUL:

assert(sd_id128_is_null(SD_ID128_NULL));

De manera similar, sd_id128_is_allf() comprueba si un ID consiste únicamente en bytes 0xFF (todos los bits encendidos):

assert(sd_id128_is_allf(SD_ID128_ALLF));

sd_id128_in_set_sentinel() toma una lista de IDs y devuelve verdadero si el primer argumento es igual a cualquiera de los argumentos subsiguientes. La lista de argumentos se termina con un centinela SD_ID128_NULL, que debe estar presente.

sd_id128_in_set() es una función de conveniencia que toma una lista de IDs y devuelve verdadero si el primer argumento es igual a cualquiera de los argumentos subsiguientes:

int main(int argc, char *argv[]) {
  sd_id12_t a = SD_ID128_MAKE(ee,89,be,71,bd,6e,43,d6,91,e6,c5,5d,eb,03,02,07);
  assert(sd_id128_in_set(a, a));
  assert(sd_id128_in_set(a, a, a));
  assert(!sd_id128_in_set(a));
  assert(!sd_id128_in_set(a,
                          SD_ID128_MAKE(f2,28,88,9c,5f,09,44,15,9d,d7,04,77,58,cb,e7,3e)
                          SD_ID128_MAKE(2f,88,28,5f,9c,44,09,9d,d7,15,77,04,bc,85,7e,e3)
                          SD_ID128_ALLF));
  return 0;
}

sd_id128_in_set() se define como una macro sobre sd_id128_in_set_sentinel(), agregando automáticamente el centinela SD_ID128_NULL. Dado que sd_id128_in_set_sentinel() usa SD_ID128_NULL como centinela, SD_ID128_NULL no puede ser colocado de otra manera en la lista de argumentos.

sd_id128_in_setv() es similar a sd_id128_in_set_sentinel(), pero toma un argumento de struct varargs.

Se pueden generar nuevos IDs aleatorios con el comando new de systemd-id128(1).

Ver sd_id128_to_string(3), sd_id128_randomize(3) y sd_id128_get_machine(3) para obtener información sobre otras implementa

sd_id128_t(3)

NAME

sd_id128_t, sd_id128_equal, sd_id128_string_equal, sd_id128_is_null, sd_id128_is_allf, sd_id128_in_setv, sd_id128_in_set_sentinel, sd_id128_in_set - Primitive type for 128-bit identifiers and related functions

SYNOPSIS

#include <systemd/id128.h>

typedef union sd_id128 {
    uint8_t bytes[16];
    uint64_t u64[2];
    uint32_t u32[4];
    uint16_t u16[8];
} sd_id128_t;

int sd_id128_equal(const sd_id128_t *a, const sd_id128_t *b);
int sd_id128_string_equal(const sd_id128_t *a, const char *s);
int sd_id128_is_null(const sd_id128_t *id);
int sd_id128_is_allf(const sd_id128_t *id);
int sd_id128_in_setv(const sd_id128_t *id, const sd_id128_t *set[]);
int sd_id128_in_set_sentinel(const sd_id128_t *id, const sd_id128_t *set[], const sd_id128_t *sentinel);
int sd_id128_in_set(const sd_id128_t *id, const sd_id128_t *set[]);

DESCRIPTION

sd_id128_t is a primitive type for storing 128-bit identifiers, such as UUIDs. It is a union that may be accessed using different integer types, or as an array of 16 bytes.

The following functions are available to work with this type:

sd_id128_equal() compares two 128-bit identifiers a and b. It returns a positive value if they are equal, and 0 otherwise.

sd_id128_string_equal() compares a 128-bit identifier a with its canonical string representation s (see sd_id128_to_string(3)). It returns a positive value if they are equal, and 0 otherwise.

sd_id128_is_null() checks if the identifier id is the null identifier (all bits zero). Returns a positive value if it is, and 0 otherwise.

sd_id128_is_allf() checks if the identifier id is the "all ones" identifier (all bits one). Returns a positive value if it is, and 0 otherwise.

sd_id128_in_setv() checks if the identifier id is present in the null-terminated array of 128-bit identifiers set. Returns a positive value if it is present, and 0 otherwise.

sd_id128_in_set_sentinel() is similar to sd_id128_in_setv(), but the array set is terminated by the specific sentinel identifier. This is useful when the sentinel value is not suitable for use in a C `NULL` context.

sd_id128_in_set() is a convenience function for sd_id128_in_set_sentinel(), using the null identifier as the sentinel. This is the most common case.

Note that the printf(3) family of functions, as well as journalctl(1) and sd-journal(3), accept `SD_ID128_FORMAT` as a format specifier for printing these identifiers.

These functions are part of the low-level systemd API. See systemd(1) for a list of systemd libraries.

The following helper macros are available for convenience:

SD_ID128_NULL: evaluates to the null identifier.

SD_ID128_ALLF: evaluates to the "all ones" identifier.

SD_ID128_HOST_ID: evaluates to the value of the host ID, read from `/etc/machine-id` or `/var/lib/dbus/machine-id`. See sd_id128_get_machine(3).

SD_ID128_RANDOM_V4: evaluates to a randomly generated UUID version 4.

SD_ID128_STRUMENTED

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
