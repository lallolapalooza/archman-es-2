sd_bus_get_address(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_SET_ADDRESS(3) sd_bus_set_address SD_BUS_SET_ADDRESS(3)

NOMBRE

sd_bus_set_address, sd_bus_get_address, sd_bus_set_exec - Establecer o consultar la dirección de la conexión del bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_set_address(sd_bus *bus, const char *address);

int sd_bus_get_address(sd_bus *bus, const char **address);

int sd_bus_set_exec(sd_bus *bus, const char *path, char *const *argv);

DESCRIPCIÓN

sd_bus_set_address() configura una lista de direcciones de intermediarios de bus a las que intentar conectarse en una llamada posterior a sd_bus_start(3). El argumento es una lista de direcciones separadas por ";" a la que intentar conectarse. Cada elemento debe ser uno de los siguientes:

•Una dirección de socket Unix especificada como "unix:guid=guid,path=path" o "unix:guid=guid,abstract=path". Exactamente una de las claves path= y abstract= debe estar presente, mientras que guid= es opcional.
•Una dirección de socket TCP especificada como "tcp:[guid=guid,][host=host][,port=port][,family=family]". Una o ambas claves host= y port= deben estar presentes, mientras que el resto es opcional. family puede ser ipv4 o ipv6.
•Un ejecutable a lanzar especificado como "unixexec:guid=guid,path=path,argv1=argument,argv2=argument,...". La clave path= debe estar presente, mientras que guid= es opcional.
•Una máquina (contenedor) a la que conectarse especificada como "x-machine-unix:guid=guid,machine=machine,pid=pid". Exactamente una de las claves machine= y pid= debe estar presente, mientras que guid= es opcional. machine es el nombre de un contenedor local. Consulte machinectl(1) para más información sobre el concepto de "máquina". "machine=.host" puede usarse para especificar la máquina anfitriona. Se creará una conexión al socket del bus del sistema estándar dentro de la máquina especificada.

En todos los casos, el parámetro guid es un identificador del par remoto, en la sintaxis aceptada por sd_id128_from_string(3). Si se especifica, el identificador devuelto por el par después de que se establezca la conexión se verificará y la conexión se rechazará en caso de una discrepancia.

Tenga en cuenta que las direcciones pasadas a sd_bus_set_address() podrían no ser verificadas inmediatamente. Si son inválidas, un error puede ser devuelto, por ejemplo, de una llamada posterior a sd_bus_start(3).

sd_bus_get_address() devuelve las direcciones previamente establecidas. Además de ser establecidas explícitamente por sd_bus_set_address(), la dirección también será establecida automáticamente por sd_bus_open(3) y llamadas similares, basándose en variables de entorno o valores predeterminados integrados.

sd_bus_set_exec() es una función abreviada para establecer una dirección "unixexec" que lanza el ejecutable dado con los argumentos dados. Si argv es NULL, el ejecutable dado se lanza sin argumentos adicionales.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven un entero no negativo. En caso de fallo, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Los parámetros de entrada bus o address son NULL.

Añadido en la versión 246.

-ENOPKG

El objeto de bus bus no pudo ser resuelto.

Añadido en la versión 246.

-EPERM

El parámetro de entrada bus está en un estado incorrecto (sd_bus_set_address() solo puede ser llamado una vez en un objeto de bus recién creado).

Añadido en la versión 246.

-ECHILD

El objeto de bus bus fue creado en un proceso diferente.

Añadido en la versión 246.

-ENODATA

El objeto de bus bus no tiene una dirección configurada.

Añadido en la versión 246.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_set_address(), sd_bus_get_address(), y sd_bus_set_exec() fueron añadidas en la versión 246.
