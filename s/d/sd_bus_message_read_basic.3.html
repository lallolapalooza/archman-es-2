NOMBRE

sd_bus_message_read_basic - Leer un tipo básico de un mensaje

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_message_read_basic(sd_bus_message *m, char tipo, void *p);

DESCRIPCIÓN

sd_bus_message_read_basic() lee un tipo básico de un mensaje y avanza la posición de lectura en el mensaje. El conjunto de tipos básicos y sus códigos ASCII pasados en tipo se describen en la Especificación D-Bus[1].

Si p no es NULL, debe contener un puntero a un objeto apropiado. Por ejemplo, si tipo es 'y', el objeto pasado en p debe ser de tipo uint8_t *. Si tipo es 's', el objeto pasado en p debe ser de tipo const char **. Tenga en cuenta que, si el tipo básico es un puntero (por ejemplo, const char * en el caso de una cadena), el puntero solo se presta y el contenido debe copiarse si se va a utilizar después del final de la vida útil del mensaje. Del mismo modo, durante la vida útil de dicho puntero, el mensaje no debe modificarse. Si tipo es 'h' (descriptor de archivo UNIX), la llamada no duplica el descriptor y el descriptor devuelto permanece en posesión del objeto del mensaje, y debe ser duplicado por el llamador para mantener una referencia abierta a él después de que el objeto del mensaje sea liberado (por ejemplo, llamando a "fcntl(fd, FD_DUPFD_CLOEXEC, 3)"). Consulte la tabla siguiente para obtener una lista completa de tipos permitidos.

Tabla 1. Especificadores de tipo de elemento

Especificador Constante Descripción Tipo C Esperado
"y" SD_BUS_TYPE_BYTE Entero sin signo de 8 bits uint8_t *
"b" SD_BUS_TYPE_BOOLEAN booleano int * (NOTA: no bool *)
"n" SD_BUS_TYPE_INT16 Entero con signo de 16 bits int16_t *
"q" SD_BUS_TYPE_UINT16 Entero sin signo de 16 bits uint16_t *
"i" SD_BUS_TYPE_INT32 Entero con signo de 32 bits int32_t *
"u" SD_BUS_TYPE_UINT32 Entero sin signo de 32 bits uint32_t *
"x" SD_BUS_TYPE_INT64 Entero con signo de 64 bits int64_t *
"t" SD_BUS_TYPE_UINT64 Entero sin signo de 64 bits uint64_t *
"d" SD_BUS_TYPE_DOUBLE Punto flotante de doble precisión IEEE 754 double *
"s" SD_BUS_TYPE_STRING Cadena UTF-8 const char **
"o" SD_BUS_TYPE_OBJECT_PATH Cadena de ruta de objeto D-Bus const char **
"g" SD_BUS_TYPE_SIGNATURE Cadena de firma D-Bus const char **
"h" SD_BUS_TYPE_UNIX_FD Descriptor de archivo UNIX int *

Si no hay un objeto del tipo especificado en la posición actual del mensaje, se devuelve un error.

VALOR DE RETORNO

En caso de éxito, sd_bus_message_read_basic() devuelve un entero positivo. Si se ha alcanzado el final del array abierto actualmente, devuelve 0. En caso de error, devuelve un código de error negativo al estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

La cadena de tipo especificada es inválida o el parámetro del mensaje es NULL.

-ENXIO

El mensaje no contiene el tipo especificado en la posición actual.

-EBADMSG

El mensaje no se puede analizar.

HISTORIA

sd_bus_message_read_basic() se añadió en la versión 221.
