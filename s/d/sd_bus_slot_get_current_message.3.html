sd_bus_slot_get_current_message(3)

SD_BUS_SLOT_GET_BUS(3) sd_bus_slot_get_bus SD_BUS_SLOT_GET_BUS(3)

NOMBRE

sd_bus_slot_get_bus, sd_bus_slot_get_current_handler, sd_bus_slot_get_current_message, sd_bus_slot_get_current_userdata - Consultar información adjunta a un objeto de ranura de bus

SINOPSIS

#include <systemd/sd-bus.h>

typedef int (*sd_bus_message_handler_t)(sd_bus_message *m, void *userdata, sd_bus_error *ret_error);

sd_bus *sd_bus_slot_get_bus(sd_bus_slot *slot);

sd_bus_message_handler_t sd_bus_slot_get_current_handler(sd_bus_slot *slot);

sd_bus_message *sd_bus_slot_get_current_message(sd_bus_slot *slot);

void *sd_bus_slot_get_current_userdata(sd_bus_slot *slot);

DESCRIPCIÓN

sd_bus_slot_get_bus() devuelve el objeto de bus al que está adjunta la ranura de mensaje slot.

sd_bus_slot_get_current_handler(), sd_bus_slot_get_current_message() y sd_bus_slot_get_current_userdata() devuelven el manejador actual, el mensaje y los datos de usuario, respectivamente, de la ranura de bus a la que está adjunta si estamos ejecutando actualmente la devolución de llamada asociada con slot.

VALOR DE RETORNO

sd_bus_slot_get_bus() siempre devuelve el objeto de bus.

En caso de éxito, sd_bus_slot_get_current_handler(), sd_bus_slot_get_current_message() y sd_bus_slot_get_current_userdata() devuelven el objeto solicitado. En caso de error, devuelven NULL.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para multihilo. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIAL

sd_bus_slot_get_bus(), sd_bus_slot_get_current_handler(), sd_bus_slot_get_current_message() y sd_bus_slot_get_current_userdata() se añadieron en la versión 246.
