sd_bus_message_get_member(3)

Paquete: systemd-libs

SD_BUS_MESSAGE_SET_DESTINATION(3) sd_bus_message_set_destination SD_BUS_MESSAGE_SET_DESTINATION(3)

NOMBRE

sd_bus_message_set_destination, sd_bus_message_get_destination, sd_bus_message_get_path, sd_bus_message_get_interface, sd_bus_message_get_member, sd_bus_message_set_sender, sd_bus_message_get_sender - Establecer y consultar información de direccionamiento de mensajes del bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_message_set_destination(sd_bus_message *message, const char *destination);

const char* sd_bus_message_get_destination(sd_bus_message *message);

const char* sd_bus_message_get_path(sd_bus_message *message);

const char* sd_bus_message_get_interface(sd_bus_message *message);

const char* sd_bus_message_get_member(sd_bus_message *message);

int sd_bus_message_set_sender(sd_bus_message *message, const char *sender);

const char* sd_bus_message_get_sender(sd_bus_message *message);

DESCRIPCIÓN

sd_bus_message_set_destination() establece el nombre del servicio de destino para el objeto de mensaje de bus especificado. El nombre especificado debe ser un nombre de servicio único o conocido válido.

sd_bus_message_get_destination(), sd_bus_message_get_path(), sd_bus_message_get_interface() y sd_bus_message_get_member() devuelven los campos de destino, ruta, interfaz y miembro de la cabecera de message. El valor de retorno será NULL si message es NULL o si el mensaje es de un tipo que no utiliza esos campos o si el mensaje no los tiene establecidos. Consulte sd_bus_message_new_method_call(3) y sd_bus_message_set_destination(3) para una mayor discusión sobre esos valores.

sd_bus_message_set_sender() establece el nombre del servicio remitente para el objeto de mensaje de bus especificado. El nombre especificado debe ser un nombre de servicio único o conocido válido. Esta función solo es útil para mensajes que se envían a través de conexiones directas, ya que para las conexiones a intermediarios de bus, el intermediario rellenará el campo de destino de todos modos, y el campo remitente establecido por el remitente original se ignora.

sd_bus_message_get_sender() devuelve el campo remitente de message.

Cuando se devuelve una cadena, es un puntero al almacenamiento interno y no se puede modificar ni liberar. Solo es válido mientras message siga siendo referenciado y este campo no haya sido modificado por una llamada diferente.

VALOR DE RETORNO

En caso de éxito, estas llamadas devuelven 0 o un entero positivo. En caso de error, estas llamadas devuelven un código de error negativo al estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El parámetro message o el parámetro de salida son NULL.

-EPERM

Para sd_bus_message_set_destination() y sd_bus_message_set_sender(), el mensaje ya está sellado.

-EEXIST

El mensaje ya tiene un campo de destino o remitente establecido.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para multihilo. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando aún no se hayan iniciado otros hilos.

HISTORIAL

sd_bus_message_set_destination() y sd_bus_message_set_sender() se añadieron en la versión 237.

sd_bus_message_get_destination(), sd_bus_message_get_path(), sd_bus_message_get_interface(), sd_bus_message_get_member() y sd_bus_message_get_sender() se añadieron en la versión 240.
