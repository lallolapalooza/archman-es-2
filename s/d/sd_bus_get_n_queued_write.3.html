NOMBRE

sd_bus_get_n_queued_read, sd_bus_get_n_queued_write - Obtener el número de mensajes de bus pendientes en las colas de lectura y escritura de un objeto de conexión de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_get_n_queued_read(sd_bus *bus, uint64_t *ret);

int sd_bus_get_n_queued_write(sd_bus *bus, uint64_t *ret);

DESCRIPCIÓN

sd_bus_get_n_queued_read() puede usarse para consultar el número de mensajes de bus en la cola de lectura de un objeto de conexión de bus. La cola de lectura contiene todos los mensajes leídos del medio de transporte (por ejemplo, el socket de red) pero que aún no han sido procesados localmente. La función espera dos argumentos: el objeto de bus a consultar y un puntero a una variable contadora de 64 bits para escribir el tamaño actual de la cola. Utilice sd_bus_process() para procesar los mensajes en cola, es decir, para reducir el tamaño de la cola de lectura (así como, de hecho, la cola de escritura, véase más abajo).

De manera similar, sd_bus_get_n_queued_write() puede usarse para consultar el número de mensajes de bus pendientes actualmente en la cola de escritura de un objeto de conexión de bus. La cola de escritura contiene todos los mensajes encolados en la conexión con una llamada como sd_bus_send() pero que aún no se han escrito en el medio de transporte. Los argumentos esperados son similares a sd_bus_get_n_queued_read(). Aquí también, use sd_bus_process() para reducir el tamaño de la cola de escritura. Alternativamente, use sd_bus_flush() para escribir de forma síncrona cualquier mensaje de bus pendiente hasta que la cola de escritura esté vacía.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ECHILD

La conexión de bus se creó en un proceso, biblioteca o instancia de módulo diferente.

HISTORIA

sd_bus_get_n_queued_read() y sd_bus_get_n_queued_write() se añadieron en la versión 238.
