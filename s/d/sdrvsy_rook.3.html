SDRVSY_ROOK

Propósito:

!>
!> SDRVSY_ROOK prueba las rutinas de controlador SSYSV_ROOK.
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LÓGICO, de dimensión (NTYPES)
!>          Los tipos de matrices a utilizar para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se utilizan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se utiliza.
!>

NN

!>          NN es un ENTERO
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array de ENTEROS, de dimensión (NN)
!>          Los valores de la dimensión N de la matriz.
!>

NRHS

!>          NRHS es un ENTERO
!>          El número de vectores del lado derecho a generar para
!>          cada sistema lineal.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          cada relación de prueba se imprima, use THRESH = 0.
!>

TSTERR

!>          TSTERR es LÓGICO
!>          Indicador que señala si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es un ENTERO
!>          El valor máximo permitido para N, utilizado en la dimensión de los
!>          arrays de trabajo.
!>

A

!>          A es un array de REAL, dimensión (NMAX*NMAX)
!>

AFAC

!>          AFAC es un array de REAL, dimensión (NMAX*NMAX)
!>

AINV

!>          AINV es un array de REAL, dimensión (NMAX*NMAX)
!>

B

!>          B es un array de REAL, dimensión (NMAX*NRHS)
!>

X

!>          X es un array de REAL, dimensión (NMAX*NRHS)
!>

XACT

!>          XACT es un array de REAL, dimensión (NMAX*NRHS)
!>

WORK

!>          WORK es un array de REAL, dimensión
!>                      (NMAX*max(2,NRHS))
!>

RWORK

!>          RWORK es un array de REAL, dimensión (NMAX+2*NRHS)
!>

IWORK

!>          IWORK es un array de ENTEROS, dimensión (2*NMAX)
!>

NOUT

!>          NOUT es un ENTERO
!>          El número de unidad para la salida.
!>
