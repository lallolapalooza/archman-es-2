SD_BUS_LIST_NAMES(3) sd_bus_list_names SD_BUS_LIST_NAMES(3)

NOMBRE

sd_bus_list_names - Recuperar información sobre nombres registrados en un bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_list_names(sd_bus *bus, char ***acquired, char ***activatable);

DESCRIPCIÓN

sd_bus_list_names() recupera información sobre los nombres registrados en un bus. Si acquired no es NULL, esta función llama a org.freedesktop.DBus.ListNames[1] para recuperar la lista de nombres actualmente propiedad del bus. Si acquired no es NULL, la función llama a org.freedesktop.DBus.ListActivableNames[2] para recuperar la lista de todos los nombres en el bus que pueden ser activados. Tenga en cuenta que la propiedad de los arrays devueltos por sd_bus_list_names() en acquired y activatable se transfiere al llamador y, por lo tanto, el llamador es responsable de liberar estos arrays y sus contenidos.

VALOR DE RETORNO

En caso de éxito, sd_bus_list_names() devuelve un entero no negativo. En caso de fallo, devuelve un código de error negativo al estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

bus o ambos acquired y activatable eran NULL.

-ENOPKG

El bus no se puede resolver.

-ECHILD

El bus se creó en un proceso, biblioteca o instancia de módulo diferente.

-ENOMEM

Fallo en la asignación de memoria.

-ENOTCONN

El bus no está conectado.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_list_names() se añadió en la versión 221.
