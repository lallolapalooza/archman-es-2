sd_event_source_unrefp(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_EVENT_SOURCE_UNREF(3) sd_event_source_unref SD_EVENT_SOURCE_UNREF(3)

NOMBRE

sd_event_source_unref, sd_event_source_unrefp, sd_event_source_ref, sd_event_source_disable_unref, sd_event_source_disable_unrefp - Aumentar o disminuir los contadores de referencia de la fuente de eventos

SINOPSIS

#include <systemd/sd-event.h>

sd_event_source* sd_event_source_unref(sd_event_source *source);

void sd_event_source_unrefp(sd_event_source **source);

sd_event_source* sd_event_source_ref(sd_event_source *source);

sd_event_source* sd_event_source_disable_unref(sd_event_source *source);

void sd_event_source_disable_unrefp(sd_event_source **source);

DESCRIPCIÓN

sd_event_source_unref() se puede utilizar para decrementar en uno el contador de referencias interno del objeto de fuente de eventos especificado por source. El contador de referencias se inicializa en uno, cuando la fuente de eventos se crea con llamadas como sd_event_add_io(3) o sd_event_add_time(3). Cuando el contador de referencias llega a cero, el objeto se desvincula del objeto del bucle de eventos y se destruye.

sd_event_source_unrefp() es similar a sd_event_source_unref() pero toma un puntero a un puntero a un objeto sd_event_source. Esta llamada es útil en conjunción con el Atributo de Variable de Limpieza de GCC y LLVM[1]. Tenga en cuenta que esta función se define como una función en línea.

sd_event_source_ref() se puede utilizar para incrementar en uno el contador de referencias interno del objeto de fuente de eventos especificado por source.

sd_event_source_unref(), sd_bus_creds_unrefp() y sd_bus_creds_ref() no ejecutan ninguna operación si el objeto de fuente de eventos pasado es NULL.

Tenga en cuenta que los objetos de fuente de eventos permanecen activos y pueden ser despachados mientras su contador de referencias sea mayor que cero. Para soltar una referencia de una fuente de eventos y asegurar que la función de manejador de eventos asociada no se llame más, se recomienda combinar una llamada a sd_event_source_unref() con una llamada previa a sd_event_source_set_enabled() con SD_EVENT_OFF o llamar a sd_event_source_disable_unref(), véase más abajo.

sd_event_source_disable_unref() combina una llamada a sd_event_source_set_enabled() con SD_EVENT_OFF con sd_event_source_unref(). Esto asegura que la fuente se deshabilita antes de que la referencia local a ella se pierda. Se permite que el parámetro source sea NULL.

sd_event_source_disable_unrefp() es similar a sd_event_source_unrefp(), pero además deshabilita la fuente primero. Esta llamada es útil en conjunción con el Atributo de Variable de Limpieza de GCC y LLVM[1]. Tenga en cuenta que esta función se define como una función en línea.

VALOR DE RETORNO

sd_event_source_unref() y sd_event_source_disable_unref() siempre devuelven NULL. sd_event_source_ref() siempre devuelve el objeto de fuente de eventos pasado.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que está declarado como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar las llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_event_source_unref(), sd_event_source_unrefp() y sd_event_source_ref() se añadieron en la versión 229.

sd_event_source_disable_unref() y sd_event_source_disable_unrefp() se añadieron en la versión 243.
