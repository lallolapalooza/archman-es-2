NOMBRE

sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_remove_sender, sd_bus_track_count, sd_bus_track_count_sender, sd_bus_track_count_name, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next - Añadir, eliminar y recuperar pares de bus rastreados en un objeto de rastreo de pares de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(sd_bus_track* t, const char* name);

int sd_bus_track_add_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_remove_name(sd_bus_track* t, const char* name);

int sd_bus_track_remove_sender(sd_bus_track* t, sd_bus_message* message);

unsigned sd_bus_track_count(sd_bus_track* t);

int sd_bus_track_count_name(sd_bus_track* t, const char* name);

int sd_bus_track_count_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_contains(sd_bus_track* t, const char* name);

const char* sd_bus_track_first(sd_bus_track* t);

const char* sd_bus_track_next(sd_bus_track* t);

DESCRIPCIÓN

sd_bus_track_add_name() añade un par a rastrear a un objeto de rastreo de pares de bus. El primer argumento debe referirse a un objeto de rastreo de pares de bus creado con sd_bus_track_new(3), el segundo nombre debe referirse a un nombre de par de D-Bus a rastrear, ya sea en formato de servicio único o bien conocido. Si el nombre no se está rastreando aún, se añadirá a la lista de nombres a rastrear. Si ya se está rastreando y el modo no recursivo está habilitado, esta llamada no ejecutará ninguna operación. Si el modo recursivo está habilitado, un contador por nombre se incrementará en uno cada vez que se invoque esta llamada, y sd_bus_track_remove_name() deberá llamarse tantas veces como se haya invocado sd_bus_track_add_name() antes para detener el rastreo del nombre. Utilice sd_bus_track_set_recursive(3) para cambiar del modo no recursivo por defecto al modo recursivo, o viceversa. Tenga en cuenta que el nombre especificado se rastrea tal como está, los nombres bien conocidos no se resuelven a nombres únicos por esta llamada. Tenga en cuenta que múltiples objetos de rastreo de pares de bus pueden rastrear el mismo nombre.

sd_bus_track_remove_name() deshace el efecto de sd_bus_track_add_name() y elimina un nombre de par de bus de la lista de pares a observar. Dependiendo de si el modo no recursivo o recursivo está habilitado para el objeto de rastreo de pares de bus, esta llamada eliminará completamente el nombre del objeto de rastreo, o simplemente decrementará el contador por nombre en uno, eliminando el nombre solo cuando el contador llegue a cero (ver arriba). Tenga en cuenta que la desconexión de un par de bus del bus eliminará implícitamente sus nombres por completo del objeto de rastreo de pares de bus, independientemente del contador actual por nombre.

sd_bus_track_add_sender() y sd_bus_track_remove_sender() son similares a sd_bus_track_add_name() y sd_bus_track_remove_name(), pero toman un mensaje de bus como argumento. Se determina el remitente de este mensaje de bus y se añade/elimina del objeto de rastreo de pares de bus. Como los mensajes siempre se originan de nombres únicos y nunca de nombres bien conocidos, esto significa que esta llamada efectivamente solo añadirá nombres únicos al objeto de rastreo de pares de bus.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente por el objeto de rastreo de pares de bus especificado. Tenga en cuenta que esta función siempre devuelve el número real de nombres rastreados y, por lo tanto, si se ha invocado sd_bus_track_add_name() varias veces para el mismo nombre, solo se cuenta como uno, independientemente de si el modo recursivo está habilitado o no.

sd_bus_track_count_name() devuelve el contador actual por nombre para el nombre especificado. Si se utiliza el modo no recursivo, esto devuelve 1 o 0, dependiendo de si el nombre especificado se ha añadido previamente al objeto de rastreo o no. Si se ha habilitado el modo recursivo, también pueden devolverse valores mayores que 1, en caso de que se haya llamado a sd_bus_track_add_name() varias veces para el mismo nombre.

sd_bus_track_count_sender() es similar a sd_bus_track_count_name(), pero toma un objeto de mensaje de bus y devuelve el contador por nombre que coincide con el remitente del mensaje.

sd_bus_track_contains() se puede utilizar para determinar si el nombre especificado se ha añadido al menos una vez al objeto de rastreo de pares de bus especificado.

sd_bus_track_first() y sd_bus_track_next() se pueden utilizar para enumerar todos los nombres que se están rastreando actualmente por el objeto de rastreo de pares de bus pasado. sd_bus_track_first() devuelve la primera entrada del objeto y restablece un índice de lectura mantenido internamente. Cada invocación subsiguiente de sd_bus_track_next() devuelve el siguiente nombre contenido en el objeto de bus. Si se alcanza el final, se devuelve NULL. Si no se ha añadido ningún nombre al objeto aún, sd_bus_track_first() devolverá NULL inmediatamente. El orden en que se devuelven los nombres no está definido; en particular, no se define qué nombre se considera el primero devuelto. Si el modo recursivo está habilitado y el mismo nombre se ha añadido varias veces al objeto de rastreo de pares de bus, solo se devuelve una vez en esta enumeración. Si se añaden nuevos nombres o se eliminan nombres existentes del objeto de rastreo de pares de bus mientras se está enumerando, la enumeración finaliza en la siguiente invocación de sd_bus_track_next() ya que se devuelve NULL.

VALOR DE RETORNO

En caso de éxito, sd_bus_track_add_name() y sd_bus_track_add_sender() devuelven 0 si el nombre especificado ya se había añadido previamente al objeto de rastreo de pares de bus y un valor positivo si no. En caso de error, devuelven un código de error negativo al estilo errno.

sd_bus_track_remove_name() y sd_bus_track_remove_sender() devuelven un valor positivo si el nombre especificado estaba rastreado previamente por el objeto de rastreo de pares de bus y ahora ha sido eliminado. En modo no recursivo, se devuelve 0 si el nombre especificado aún no estaba siendo rastreado. En modo recursivo, se devuelve -EUNATCH en este caso. En caso de error, devuelven un código de error negativo al estilo errno.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente, o 0 en caso de error.

sd_bus_track_count_name() y sd_bus_track_count_sender() devuelven el contador actual por nombre para el nombre especificado o el remitente del mensaje especificado. Se devuelve cero para nombres que aún no se están rastreando, un valor positivo para nombres añadidos al menos una vez. Valores mayores que 1 solo se devuelven en modo recursivo. En caso de error, se devuelve un código de error negativo al estilo errno.

sd_bus_track_contains() devuelve el nombre pasado si existe en el objeto de rastreo de pares de bus. En caso de error, y si el nombre aún no se ha añadido, se devuelve NULL.

sd_bus_track_first() y sd_bus_track_next() devuelven el primer/siguiente nombre contenido en el objeto de rastreo de pares de bus, y NULL si se alcanza el final de la enumeración y en caso de error.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EUNATCH

Se ha invocado sd_bus_track_remove_name() o sd_bus_track_remove_sender() para un nombre no añadido previamente al objeto de par de bus.

-EINVAL

El parámetro especificado es inválido.

-ENOMEM

Fallo en la asignación de memoria.

NAME

sd_bus_track_count, sd_bus_track_count_name, sd_bus_track_count_sender - Count bus names or senders in a bus track

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_count(sd_bus_track *track);
int sd_bus_track_count_name(sd_bus_track *track, const char *name);
int sd_bus_track_count_sender(sd_bus_track *track, const char *sender);

DESCRIPTION

sd_bus_track_count() returns the total number of unique bus names and sender addresses that are currently tracked in track.

sd_bus_track_count_name() returns the number of times the specific bus name name is tracked in track. This count can be greater than one if the name was added multiple times.

sd_bus_track_count_sender() returns the number of times the specific sender address sender is tracked in track. This count can be greater than one if the sender address was added multiple times.

Bus names and sender addresses are added to a bus track using sd_bus_track_add_name() and sd_bus_track_add_sender(), respectively.

RETURN VALUE

sd_bus_track_count(), sd_bus_track_count_name(), and sd_bus_track_count_sender() return the count on success, or a negative errno value on error. Note that the count may be zero if no entries are tracked.

NOTES

These functions operate on an existing bus track object. The bus track object is used to keep track of bus names or sender addresses. A bus track is created with sd_bus_track_new(). The track object is immutable and is associated with the bus object it was created from. The track might become stale if the associated bus object is destroyed. A bus track should be destroyed using sd_bus_track_unref().

The counts returned are valid only for the specific point in time when the function is called. Because bus tracks are typically used in the context of message queues or event loops, the state of a bus track can change asynchronously at any time, even between consecutive calls to these functions. This means that the returned count might not accurately reflect the state of the bus track a moment later.

These functions are intended for use in an early phase of the program when no other threads have been started.
