Propósito:

!>
!>      SDRVST  comprueba los drivers del problema de valores propios simétricos.
!>
!>              SSTEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica tridiagonal real.
!>
!>              SSTEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz simétrica tridiagonal real.
!>
!>              SSTEVR calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz simétrica tridiagonal real
!>              utilizando la Representación Relativamente Robusta cuando es posible.
!>
!>              SSYEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real.
!>
!>              SSYEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz simétrica real.
!>
!>              SSYEVR calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz simétrica real
!>              utilizando la Representación Relativamente Robusta cuando es posible.
!>
!>              SSPEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real en almacenamiento
!>              empaquetado.
!>
!>              SSPEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz simétrica real en almacenamiento
!>              empaquetado.
!>
!>              SSBEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz de banda simétrica real.
!>
!>              SSBEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz de banda simétrica real.
!>
!>              SSYEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              SSPEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real en almacenamiento
!>              empaquetado, utilizando un algoritmo de divide y vencerás.
!>
!>              SSBEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz de banda simétrica real,
!>              utilizando un algoritmo de divide y vencerás.
!>
!>      Cuando se llama a SDRVST, se especifican varios tamaños de matrices () y
!>      varios tipos de matrices. Para cada tamaño () y cada tipo de matriz,
!>      se generará una matriz y se utilizará para probar las rutinas drivers apropiadas.
!>      Para cada matriz y cada rutina driver llamada, se realizarán las siguientes pruebas:
!>
!>      (1)     | A - Z D Z' | / ( |A| n ulp )
!>
!>      (2)     | I - Z Z' | / ( n ulp )
!>
!>      (3)     | D1 - D2 | / ( |D1| ulp )
!>
!>      donde Z es la matriz de vectores propios devuelta cuando se da la opción de
!>      vectores propios, y D1 y D2 son los valores propios devueltos con y sin
!>      la opción de vectores propios.
!>
!>      Los tamaños se especifican mediante un array NN(1:NSIZES); el valor de
!>      cada elemento NN(j) especifica un tamaño.
!>      Los tipos se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!>      Actualmente, la lista de tipos posibles es:
!>
!>      (1)  La matriz cero.
!>      (2)  La matriz identidad.
!>
!>      (3)  Una matriz diagonal con valores propios espaciados uniformemente
!>           1, ..., ULP y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1 )
!>      (4)  Una matriz diagonal con valores propios espaciados geométricamente
!>           1, ..., ULP y signos aleatorios.
!>      (5)  Una matriz diagonal con valores propios
!>           1, ULP, ..., ULP y signos aleatorios.
!>
!>      (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8)  Una matriz de la forma U' D U, donde U es ortogonal y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (9)  Una matriz de la forma U' D U, donde U es ortogonal y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (10) Una matriz de la forma U' D U, donde U es ortogonal y
!>           D tiene entradas 1, ULP,..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>      (16) Una matriz de banda con ancho de banda semi-aleatorio elegido entre
!>           0 y N-1, con valores propios espaciados uniformemente 1, ..., ULP
!>           con signos aleatorios.
!>      (17) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (18) Igual que (16), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>

NAME

sdrvst - subroutine to test the standard driver routines SSYEV, SSYEVX, SSPEV, SSPEVX, SSBEV, SSBEVX

SYNOPSIS

    SUBROUTINE SDRVST( NI, NL, NR, NMAX,THRESH, AIOUT, INFO )

Parameters:

NI
INTEGER. Number of values of N to try.
NL
INTEGER. Number of values of NB to try.
NR
INTEGER. Number of values of NR to try.
NMAX
INTEGER. Maximum value of N allowed.
THRESH
REAL. Threshold for checking error codes.
AIOUT
INTEGER. Array for outputting information.
INFO
INTEGER. Error flag.

Function/Subroutine Documentation

!>     This subroutine tests the standard driver routines SSYEV, SSYEVX,
!>     SSPEV, SSPEVX, SSBEV, SSBEVX.
!>
!>     The following values of UPLO are used: 'L', 'U'.
!>     The following values of JOBZ are used: 'N', 'V'.
!>     The following values of RANGE are used: 'A', 'I', 'V'.
!>
!>     The tests are performed on matrices A of size N x N, where
!>     N is chosen from the list of values for NI.
!>     The blocking sizes NB are chosen from the list of values for NL.
!>     The number of right hand sides NR is chosen from the list of values for NR.
!>
!>     The accuracy of the eigenvalue decomposition is measured by the
!>     following quantities:
!>
!>     1. | A - U S U' | / ( |A| n ulp )
!>        where U is the matrix of eigenvectors and S is the diagonal
!>        matrix of eigenvalues. This tests the accuracy of the
!>        eigenvectors and eigenvalues.
!>
!>     2. | I - U U' | / ( n ulp )
!>        where I is the identity matrix. This tests the orthogonality
!>        of the eigenvectors.
!>
!>     3. |D(with Z) - D(w/o Z)| / (|D| ulp)
!>        where D is the diagonal matrix of eigenvalues. This tests the
!>        accuracy of the eigenvalues when computed with and without
!>        pivoting.
!>
!>     The tests are performed for the following routines:
!>
!>     SSYEV: General driver for non-symmetric eigenvalue problem.
!>     SSYEVX: General driver for non-symmetric eigenvalue problem with constraints.
!>     SSPEV: Packed general driver for non-symmetric eigenvalue problem.
!>     SSPEVX: Packed general driver for non-symmetric eigenvalue problem with constraints.
!>     SSBEV: Band general driver for non-symmetric eigenvalue problem.
!>     SSBEVX: Band general driver for non-symmetric eigenvalue problem with constraints.
!>
!>     The following is a list of the tests performed:
!>
!>    Tests 25 through 78 use UPLO='L'
