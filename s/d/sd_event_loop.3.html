SD_EVENT_RUN(3) sd_event_run SD_EVENT_RUN(3)

NOMBRE

sd_event_run, sd_event_loop - Ejecutar un bucle de eventos

SINOPSIS

#include <systemd/sd-event.h>

int sd_event_run(sd_event *event, uint64_t usec);

int sd_event_loop(sd_event *event);

DESCRIPCIÓN

sd_event_run() se puede utilizar para ejecutar una única iteración del bucle de eventos especificado en el parámetro event. La función espera hasta que haya un evento para procesar disponible y despacha el manejador registrado para él. El parámetro usec especifica el tiempo máximo (en microsegundos) a esperar por un evento. Use (uint64_t) -1 para especificar un tiempo de espera infinito.

sd_event_loop() invoca sd_event_run() en un bucle, implementando así el bucle de eventos real. La llamada retorna tan pronto como se solicitó la salida utilizando sd_event_exit(3).

El objeto del bucle de eventos event se crea con sd_event_new(3). Las fuentes de eventos a esperar y sus manejadores se pueden registrar con sd_event_add_io(3), sd_event_add_time(3), sd_event_add_signal(3), sd_event_add_child(3), sd_event_add_defer(3), sd_event_add_post(3) y sd_event_add_exit(3).

Para un control de bajo nivel de la ejecución del bucle de eventos, use sd_event_prepare(3), sd_event_wait(3) y sd_event_dispatch(3) que están envueltos por sd_event_run(). Junto con sd_event_get_fd(3), estas funciones permiten la integración de un bucle de eventos sd-event(3) en implementaciones de bucles de eventos externos.

VALOR DE RETORNO

En caso de fallo, estas funciones devuelven un código de error negativo estilo errno. sd_event_run() devuelve un entero positivo y distinto de cero si se despachó una fuente de eventos, y cero cuando el tiempo de espera especificado se agotó antes de que una fuente de eventos viera algún evento, y por lo tanto, no se despachó ninguna fuente de eventos. sd_event_loop() devuelve el código de salida especificado al invocar sd_event_exit().

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El parámetro event es inválido o es NULL.

-EBUSY

El objeto del bucle de eventos no está en el estado correcto (ver sd_event_prepare(3) para una explicación de los estados posibles).

-ESTALE

El bucle de eventos ya está terminado.

-ECHILD

El bucle de eventos se creó en un proceso, biblioteca o instancia de módulo diferente.

También pueden ocurrir otros errores.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se han iniciado otros hilos.

HISTORIA

sd_event_run() y sd_event_loop() se añadieron en la versión 220.
