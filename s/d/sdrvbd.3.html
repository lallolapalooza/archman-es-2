SDRVBD

Propósito:

!>
!> SDRVBD verifica los drivers de descomposición de valores singulares (SVD)
!> SGESVD, SGESDD, SGESVDQ, SGESVJ, SGEJSV y DGESVDX.
!>
!> Tanto SGESVD como SGESDD factorizan A = U diag(S) VT, donde U y VT son
!> ortogonales y diag(S) es diagonal con las entradas del array S
!> en su diagonal. Las entradas de S son los valores singulares,
!> no negativos y almacenados en orden decreciente. U y VT pueden
!> opcionalmente no ser calculados, sobrescritos en A, o calculados parcialmente.
!>
!> A es M por N. Sea MNMIN = min( M, N ). S tiene dimensión MNMIN.
!> U puede ser M por M o M por MNMIN. VT puede ser N por N o MNMIN por N.
!>
!> Cuando se llama a SDRVBD, se especifican un número de dimensiones de matriz (M's y N's)
!> y un número de tipos de matriz. Para cada tamaño (M,N)
!> y cada tipo de matriz, y para el espacio de trabajo mínimo así como
!> para el espacio de trabajo adecuado para permitir el bloqueo, se generará una matriz
!> M x N y se usará para probar las rutinas SVD. Para cada matriz, A se
!> factorizará como A = U diag(S) VT y se calcularán las siguientes 12 pruebas:
!>
!> Prueba para SGESVD:
!>
!> (1)    | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (2)    | I - U'U | / ( M ulp )
!>
!> (3)    | I - VT VT' | / ( N ulp )
!>
!> (4)    S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso).
!>
!> (5)    | U - Upartial | / ( M ulp ) donde Upartial es un U calculado parcialmente.
!>
!> (6)    | VT - VTpartial | / ( N ulp ) donde VTpartial es un VT calculado parcialmente.
!>
!> (7)    | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>        vector de valores singulares de la SVD parcial
!>
!> Prueba para SGESDD:
!>
!> (8)    | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (9)    | I - U'U | / ( M ulp )
!>
!> (10)   | I - VT VT' | / ( N ulp )
!>
!> (11)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso).
!>
!> (12)   | U - Upartial | / ( M ulp ) donde Upartial es un U calculado parcialmente.
!>
!> (13)   | VT - VTpartial | / ( N ulp ) donde VTpartial es un VT calculado parcialmente.
!>
!> (14)   | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>        vector de valores singulares de la SVD parcial
!>
!> Prueba para SGESVDQ:
!>
!> (36)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (37)   | I - U'U | / ( M ulp )
!>
!> (38)   | I - VT VT' | / ( N ulp )
!>
!> (39)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso).
!>
!> Prueba para SGESVJ:
!>
!> (15)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (16)   | I - U'U | / ( M ulp )
!>
!> (17)   | I - VT VT' | / ( N ulp )
!>
!> (18)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso).
!>
!> Prueba para SGEJSV:
!>
!> (19)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (20)   | I - U'U | / ( M ulp )
!>
!> (21)   | I - VT VT' | / ( N ulp )
!>
!> (22)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso).
!>
!> Prueba para SGESVDX( 'V', 'V', 'A' )/SGESVDX( 'N', 'N', 'A' )
!>
!> (23)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (24)   | I - U'U | / ( M ulp )
!>
!> (25)   | I - VT VT' | / ( N ulp )
!>
!> (26)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso).
!>
!> (27)   | U - Upartial | / ( M ulp ) donde Upartial es un U calculado parcialmente.
!>
!> (28)   | VT - VTpartial | / ( N ulp ) donde VTpartial es un VT calculado parcialmente.
!>
!> (29)   | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>        vector de valores singulares de la SVD parcial
!>
!> Prueba para SGESVDX( 'V', 'V', 'I' )
!>
!> (30)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (31)   | I - U'U | / ( M ulp )
!>
!> (32)   | I - VT VT' | / ( N ulp )
!>
!> Prueba para SGESVDX( 'V', 'V', 'V' )
!>
!> (33)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (34)   | I - U'U | / ( M ulp )
!>
!> (35)   | I - VT VT' | / ( N ulp )
!>
!> Los tamaños (M's y N's) se especifican por los arrays MM(1:NSIZES) y
!> NN(1:NSIZES); el valor de cada par de elementos (MM(j),NN(j))
!> especifica un tamaño. Los tipos de matriz se especifican por un array lógico
!> DOTYPE( 1:NTYPES ); si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!> (3)  Una matriz de la forma U D V, donde U y V son ortogonales y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!> (4)  Igual que (3), pero multiplicado por el umbral de subdesbordamiento / ULP.
!> (5)  Igual que (3), pero multiplicado por el umbral de desbordamiento * ULP.
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matriz (M,N) contenidos en los vectores
!>          MM y NN.
!>

MM

!>          MM es un array INTEGER, de dimensión (NSIZES)
!>          Los valores de la dimensión de fila de la matriz M.
!>

NN

!>          NN es un array INTEGER, de dimensión (NSIZES)
!>          Los valores de la dimensión de columna de la matriz N.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SDRVBD
!>          no hace nada. Debe ser como mínimo cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar las matrices que estén en A y B.
!>          Esto solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño (m,n), se generará una matriz
!>          de tipo j. Si NTYPES es menor que el
!>          número máximo de tipos definidos (PARAMETER MAXTYP), entonces
!>          los tipos NTYPES+1 hasta MAXTYP no se generarán. Si
!>          NTYPES es mayor que MAXTYP, DOTYPE(MAXTYP+1) hasta
!>          DOTYPE(NTYPES) se ignorarán.
!>

ISEED

!>          ISEED es un array INTEGER, de dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios. Los elementos
!>          del array deben estar entre 0 y 4095; si no, se reducirán
!>          módulo 4096. Además, ISEED(4) debe ser impar.
!>          En la salida, ISEED se modifica y se puede usar en la siguiente llamada a
!>

sdrvbd(3) - LAPACK

NAME

sdrvbd - driver for the nonsymmetric eigenvalue problem

SYNOPSIS

 SUBROUTINE SDRVBD( NSIZES, NN, MM, NTYPES, THRESH, A, LDA, U, LDU, VT, LDVT,
 &                   ASAV, USAV, VTSAV, S, SSAV, E, WORK, LWORK, IWORK, NOUT,
 &                   INFO )

The subroutine is declared with the following parameters:

CHARACTER*(*) NTYPES

NTYPES is a CHARACTER string, containing a list of character indicators for the types of matrices to be generated. If NTYPES is empty, all the matrices will be generated.

The generated matrix has properties indicated by the following characters:

'U'
Orthogonal matrix
'S'
Singular matrix, condition number is 10**(-SINGULAR)
'G'
Geometrical distribution of eigenvalues, condition number is 10**(-SINGULAR)
'I'
Integer matrix, condition number is 10**(-SINGULAR)
'L'
Lower triangular matrix
'U'
Upper triangular matrix
'B'
Bidiagonal matrix
'T'
Tridiagonal matrix
'C'
Completely general sparse matrix
'X'
Cut-off sparse matrix
'Z'
Zero matrix
INTEGER NSIZES

NSIZES is the number of pairs of dimensions to be tested.

INTEGER array NN

NN is an array of dimension (NSIZES). It contains the values of N to be tested.

INTEGER array MM

MM is an array of dimension (NSIZES). It contains the values of M for the corresponding N in NN.

CHARACTER*(*) NTYPES

NTYPES is a CHARACTER string, containing a list of character indicators for the types of matrices to be generated. If NTYPES is empty, all the matrices will be generated.

The generated matrix has properties indicated by the following characters:

'U'
Orthogonal matrix
'S'
Singular matrix, condition number is 10**(-SINGULAR)
'G'
Geometrical distribution of eigenvalues, condition number is 10**(-SINGULAR)
'I'
Integer matrix, condition number is 10**(-SINGULAR)
'L'
Lower triangular matrix
'U'
Upper triangular matrix
'B'
Bidiagonal matrix
'T'
Tridiagonal matrix
'C'
Completely general sparse matrix
'X'
Cut-off sparse matrix
'Z'
Zero matrix
REAL THRESH

THRESH is the threshold value for the test ratios. A result is included in the output file if RESULT >= THRESH. The test ratios are scaled to be O(1), so THRESH should be a small multiple of 1, e.g., 10 or 100. To have every test ratio printed, use THRESH = 0.

REAL array A

A is the array A, dimension (LDA,NMAX), where NMAX is the maximum value of N in NN.

INTEGER LDA

LDA is the leading dimension of the array A. LDA >= max(1,MMAX), where MMAX is the maximum value of M in MM.

REAL array U

U is the array U, dimension (LDU,MMAX).

INTEGER LDU

LDU is the leading dimension of the array U. LDU >= max(1,MMAX).

REAL array VT

VT is the array VT, dimension (LDVT,NMAX).

INTEGER LDVT

LDVT is the leading dimension of the array VT. LDVT >= max(1,NMAX).

REAL array ASAV

ASAV is the array ASAV, dimension (LDA,NMAX).

REAL array USAV

USAV is the array USAV, dimension (LDU,MMAX).

REAL array VTSAV

VTSAV is the array VTSAV, dimension (LDVT,NMAX).

REAL array S

S is the array S, dimension (max(min(MM,NN))).

REAL array SSAV

SSAV is the array SSAV, dimension (max(min(MM,NN))).

REAL array E

E is the array E, dimension (max(min(MM,NN))).

REAL array WORK

WORK is a real array, dimension (LWORK).

INTEGER LWORK

LWORK is the dimension of the array WORK. This must be at least max(3*MN+MX,5*MN-4)+2*MN**2 for all pairs (MN,MX)=( min(MM(j),NN(j)), max(MM(j),NN(j)) ).

INTEGER array IWORK

IWORK is an integer array of dimension at least 8*min(M,N).

INTEGER NOUT

NOUT is the FORTRAN unit number for printing out error messages (e.g., if a routine returns INFO not equal to 0).

INTEGER INFO

INFO is an INTEGER.

If 0, then everything ran OK.
-1: NSIZES < 0
-2: Some MM(j) < 0
-3: Some NN(j) < 0
-4: NTYPES < 0
-7: THRESH < 0
-10: LDA < 1 or LDA < MMAX, where MMAX is max( MM(j) ).
-12: LDU < 1 or LDU < MMAX.
-14: LDVT < 1 or LDVT < NMAX, where NMAX is max( NN(j) ).
-21: LWORK too small.
If SLATMS, or SGESVD returns an error code, the absolute value of it is returned.
