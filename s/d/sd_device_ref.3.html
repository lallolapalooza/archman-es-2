sd_device_ref(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_DEVICE_REF(3) sd_device_ref SD_DEVICE_REF(3)

NOMBRE

sd_device_ref, sd_device_unref, sd_device_unrefp - Crear o destruir referencias a un objeto de dispositivo

SINOPSIS

#include <systemd/sd-device.h>

sd_device* sd_device_ref(sd_device *dispositivo);

sd_device* sd_device_unref(sd_device *dispositivo);

void sd_device_unrefp(sd_device **dispositivo);

sd_device_ref() incrementa el contador de referencias interno de dispositivo en uno.

sd_device_unref() decrementa el contador de referencias interno de dispositivo en uno. Una vez que el contador de referencias ha caído a cero, dispositivo se destruye y no se puede usar más, por lo que las llamadas posteriores a sd_device_ref() o sd_device_unref() son ilegales.

sd_device_unrefp() es similar a sd_device_unref() pero toma un puntero a un puntero a un objeto sd_device. Esta llamada es útil en conjunción con el Atributo de Variable de Limpieza de GCC y LLVM[1]. Tenga en cuenta que esta función se define como una función en línea. Utilice una declaración como la siguiente, para asignar un objeto de dispositivo que se liberará automáticamente al salir del bloque de código:

{
  __attribute__((cleanup(sd_device_unrefp))) sd_device *dispositivo = NULL;
  int r;
  ...
  r = sd_device_new_from_syspath(&dispositivo, "...");
  if (r < 0) {
    errno = -r;
    fprintf(stderr, "Error al asignar dispositivo: %m\n");
  }
  ...
}

sd_device_ref() y sd_device_unref() no ejecutan ninguna operación si el argumento es NULL. sd_device_unrefp() primero desreferenciará su argumento, que no debe ser NULL, y no ejecutará ninguna operación si *ese* es NULL.

VALOR DE RETORNO

sd_device_ref() siempre devuelve el argumento, y sd_device_unref() siempre devuelve NULL.

HISTORIAL

sd_device_ref(), sd_device_unref() y sd_device_unrefp() se añadieron en la versión 251.
