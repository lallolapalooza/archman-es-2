SD_BUS_MESSAGE_READ_ARRAY(3) sd_bus_message_read_array SD_BUS_MESSAGE_READ_ARRAY(3)

NOMBRE

sd_bus_message_read_array - Acceder a un array de elementos en un mensaje

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_message_read_array(sd_bus_message *m, char tipo, const void **ptr, size_t *tamano);

DESCRIPCIÓN

sd_bus_message_read_array() proporciona acceso a los elementos de un array en el mensaje del bus m. El "puntero de lectura" en el mensaje debe estar justo antes de un array del tipo tipo. Como caso especial, tipo puede ser NUL, en cuyo caso cualquier tipo trivial es aceptable. Se devuelve un puntero a los datos del array en el parámetro ptr y el tamaño de los datos del array (en bytes) se devuelve en el parámetro tamano. Si el parámetro tamano devuelto es 0, se devolverá un puntero válido no nulo como ptr, pero no podrá ser desreferenciado. Los datos están alineados según corresponda para el tipo de dato. Los datos son parte del mensaje — no pueden modificarse y solo son válidos mientras el mensaje sea referenciado. Después de que esta función regrese, el "puntero de lectura" apuntará al siguiente elemento después del array.

Tenga en cuenta que esta función solo admite arrays de tipos triviales, es decir, arrays de booleanos, los diversos tipos de enteros, así como números de punto flotante. En particular, no puede usarse para arrays de cadenas, estructuras o similares.

VALOR DE RETORNO

En caso de éxito y cuando se ha leído un array, sd_bus_message_read_array() devuelve un entero mayor que cero. Si se invoca dentro de un elemento contenedor (como un array, por ejemplo, al operar en un array de arrays) y el último elemento del contenedor externo ya ha sido leído y el puntero de lectura está por lo tanto detrás del último elemento del contenedor externo, esta llamada devuelve 0 (y el puntero devuelto será NULL y el tamaño será 0). En caso de error, devuelve un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El tipo especificado es inválido o no es un tipo trivial (ver arriba), o el parámetro del mensaje o uno de los parámetros de salida son NULL.

-EOPNOTSUPP

El orden de bytes en el mensaje es diferente del orden de bytes nativo.

-EPERM

El mensaje no está sellado.

-EBADMSG

El mensaje no se puede analizar.

HISTORIA

sd_bus_message_read_array() se añadió en la versión 240.
