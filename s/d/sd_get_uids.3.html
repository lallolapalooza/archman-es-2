sd_get_uids(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_GET_SEATS(3) sd_get_seats SD_GET_SEATS(3)

NOMBRE

sd_get_seats, sd_get_sessions, sd_get_uids, sd_get_machine_names - Determinar asientos, sesiones, usuarios conectados y máquinas/contenedores virtuales disponibles

SINOPSIS

#include <systemd/sd-login.h>

int sd_get_seats(char ***asientos);

int sd_get_sessions(char ***sesiones);

int sd_get_uids(uid_t **usuarios);

int sd_get_machine_names(char ***maquinas);

DESCRIPCION

sd_get_seats() se puede utilizar para determinar todos los asientos locales disponibles actualmente. Devuelve el número de identificadores de asiento y, si el puntero de entrada no es NULL, se almacena una matriz terminada en NULL de identificadores de asiento en la dirección. La matriz devuelta y todas las cadenas a las que hace referencia deben liberarse con la llamada free(3) de la libc después de su uso. Tenga en cuenta que en lugar de una matriz vacía, se puede devolver NULL y esto debe considerarse equivalente a una matriz vacía.

De manera similar, sd_get_sessions() se puede utilizar para determinar todas las sesiones de inicio de sesión actuales.

De manera similar, sd_get_uids() se puede utilizar para determinar todos los usuarios de Unix que tienen sesiones de inicio de sesión actualmente.

De manera similar, sd_get_machine_names() se puede utilizar para determinar todas las máquinas virtuales y contenedores actuales en el sistema.

Tenga en cuenta que las listas devueltas no están ordenadas y se encuentran en un orden indefinido.

VALOR DE RETORNO

En caso de éxito, sd_get_seats(), sd_get_sessions(), sd_get_uids() y sd_get_machine_names() devuelven el número de entradas en las matrices. En caso de error, estas llamadas devuelven un código de error negativo al estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIAL

sd_get_machine_names() se añadió en la versión 203.
