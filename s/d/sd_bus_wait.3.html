NOMBRE

sd_bus_wait - Espera E/S en una conexión de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_wait(sd_bus *bus, uint64_t timeout_usec);

DESCRIPCIÓN

sd_bus_wait() espera sincrónicamente E/S en el objeto de conexión de bus especificado. Se supone que esta función debe ser llamada cada vez que sd_bus_process(3) devuelve cero, indicando que no hay trabajo pendiente en la conexión. Internamente, esta llamada invoca ppoll(2), para esperar E/S en la conexión del bus. Si se especifica el parámetro timeout_usec, la llamada se bloqueará como máximo durante el tiempo especificado en μs. Pase UINT64_MAX para permitir que duerma indefinidamente.

Después de cada invocación de sd_bus_wait(), se debe invocar la llamada sd_bus_process() para procesar cualquier trabajo de E/S pendiente.

Tenga en cuenta que sd_bus_wait() solo es adecuado para programas simples, ya que no permite esperar otros eventos de E/S. Para programas más complejos, conecte el objeto de conexión del bus a un bucle de eventos externo usando sd_bus_get_fd(3) o a un bucle de eventos de sd-event(3) usando sd_bus_attach_event(3).

VALOR DE RETORNO

Si se vio alguna E/S, se devuelve un valor positivo, de lo contrario cero. Si ocurre un error, se devuelve un código de error negativo al estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Se pasó un objeto de bus inválido.

-ECHILD

La conexión del bus se asignó en un proceso padre y se está reutilizando en un proceso hijo después de fork().

-ENOTCONN

La conexión del bus ya ha terminado.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar contra y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que está declarado como no seguro para subprocesos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_wait() se agregó en la versión 240.
