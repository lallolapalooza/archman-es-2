DESCRIPCIÓN

sd_path_lookup() y sd_bus_path_lookup_strv() devuelven una ruta única o un conjunto de rutas de sistemas de archivos especificadas por el argumento type. En el caso de sd_path_lookup() se devuelve una única cadena terminada en NUL. Cuando type especifica un conjunto de rutas, estas se concatenan usando ":" como separador (como se hace tradicionalmente para, por ejemplo, $PATH o $LD_LIBRARY_PATH). En el caso de sd_path_lookup_strv() se devuelve un array de cadenas terminado en NULL (strv). Si se proporciona el sufijo suffix, este se concatena a cada una de las rutas después de una barra ("/"). Todas las rutas devueltas son absolutas.

Para las rutas que se refieren a directorios de usuario, se sigue la especificación XDG relevante, con soporte para variables de entorno como $XDG_DOCUMENTS_DIR, $XDG_DESKTOP_DIR, ..., y configuración explícita en /etc/xdg/user-dirs.conf o ${XDG_CONFIG_HOME}/user-dirs.dirs. Consulte la Especificación de Directorios Base de XDG[1] para más detalles.

systemd-path(1) es un envoltorio para sd_path_lookup() y permite consultar el mismo conjunto de rutas.

VALOR DE RETORNO

En caso de éxito, sd_path_lookup() y sd_path_lookup_strv() devuelven un entero no negativo. En caso de error, cualquiera de las funciones devuelve un número de error negativo estilo errno.

La cadena o el array de cadenas (strv) devuelto deben ser liberados (free(3)) por el llamante.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EOPNOTSUPP

Identificador type desconocido.

Añadido en la versión 246.

-EINVAL

El argumento de salida es NULL.

Añadido en la versión 246.

-ENXIO

La consulta falló debido a una variable de entorno no definida (por ejemplo, para SD_PATH_USER_RUNTIME cuando $XDG_RUNTIME_DIR no está definida).

Añadido en la versión 246.

-ENOMEM

Error de asignación de memoria.

Añadido en la versión 246.

EJEMPLOS

Buscar la ubicación de ~/Documentos

/* SPDX-License-Identifier: MIT-0 */
#include <stdio.h>
#include <stdlib.h>
#include <systemd/sd-path.h>
int main(void) {
  int r;
  char *t;
  r = sd_path_lookup(SD_PATH_USER_DOCUMENTS, NULL, &t);
  if (r < 0)
    return EXIT_FAILURE;
  printf("~/Documentos: %s\n", t);
  free(t);
  return EXIT_SUCCESS;
}

Tenga en cuenta que la respuesta predeterminada de $HOME/Documents puede ser anulada por user-dirs.conf o $XDG_DOCUMENTS_DIR.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, contra la cual se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara no ser seguro para hilos múltiples. Esto significa que el código que llama a las funciones aquí descritas no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar las llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_path_lookup() y sd_path_lookup_strv() se añadieron en la versión 246.

NAME

sd_path_lookup — obtener la ruta de un directorio de datos específico para el usuario

SYNOPSIS

#include <systemd/sd-path.h>

int sd_path_lookup(const char *path, const char *filename, char **ret_path);

DESCRIPTION

La función sd_path_lookup() busca el archivo filename en el directorio especificado por path. Si se encuentra el archivo, la ruta completa se devuelve en ret_path. El valor devuelto en ret_path se asigna dinámicamente y debe liberarse con free(3) por el llamante. Si no se encuentra el archivo, ret_path se establece en NULL y se devuelve 0.

La ruta path puede ser absoluta o relativa. Si es relativa, se resolverá en relación con el directorio de inicio del usuario actual.

filename debe ser el nombre de un archivo sin ninguna barra diagonal.

RETURN VALUE

En caso de éxito, devuelve el número de directorios buscados (que siempre es 1). En caso de error, devuelve un código de error negativo.

EXAMPLES

#include <stdio.h>
#include <stdlib.h>
#include <systemd/sd-path.h>

int main(void) {
    char *config_file = NULL;
    int r;

    r = sd_path_lookup("/etc/myapp", "config.conf", &config_file);
    if (r < 0) {
        fprintf(stderr, "Error looking up config file: %s\n", strerror(-r));
        return 1;
    }

    if (config_file) {
        printf("Config file found at: %s\n", config_file);
        free(config_file);
    } else {
        printf("Config file not found.\n");
    }

    return 0;
}

NOTES

Esta función es útil para buscar archivos de configuración u otros datos específicos del usuario en una ubicación conocida.

HISTORY

La función sd_path_lookup() se introdujo en systemd versión 247.
