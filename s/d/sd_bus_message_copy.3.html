SD_BUS_MESSAGE_COPY(3) sd_bus_message_copy SD_BUS_MESSAGE_COPY(3)

NOMBRE

sd_bus_message_copy - Copia el contenido de un mensaje a otro

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_message_copy(sd_bus_message *m, sd_bus_message *source, int all);

DESCRIPCIÓN

sd_bus_message_copy() copia el contenido del mensaje source a m. Si all es falso, se copia un único tipo completo (básico o contenedor). Si all es verdadero, el contenido se copia hasta el final del contenedor abierto actualmente o hasta el final de source.

VALOR DE RETORNO

En caso de éxito, esta llamada devuelve verdadero si se copió algo, y falso si no había nada que copiar. En caso de error, devuelve un código de error negativo al estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

source o m son NULL.

-EPERM

El mensaje m ha sido sellado o source no ha sido sellado.

-ESTALE

El mensaje de destino está en un estado inválido.

-ENXIO

El mensaje de destino no se puede añadir.

-ENOMEM

Fallo al asignar memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse contra y enlazarse con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que está declarado como no seguro para subprocesos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
