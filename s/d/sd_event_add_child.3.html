VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ENOMEM

No hay suficiente memoria para asignar un objeto.

-EINVAL

Se ha pasado un argumento inválido. Esto incluye especificar una máscara vacía en options o una máscara que contenga valores distintos a una combinación de WEXITED, WSTOPPED y WCONTINUED.

-EBUSY

Ya hay un manejador instalado para este proceso hijo, o SIGCHLD no está bloqueado.

-ESTALE

El bucle de eventos ya ha terminado.

-ECHILD

El bucle de eventos se ha creado en un proceso, biblioteca o instancia de módulo diferente.

-EDOM

La fuente de eventos pasada no es una fuente de eventos de proceso hijo.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un subproceso paralelo. Se recomienda realizar llamadas a setenv() solo en una fase temprana del programa, cuando aún no se han iniciado otros subprocesos.

EJEMPLO

Ejemplo 1. Bucle de salida cuando el hijo termina

/* SPDX-License-Identifier: MIT-0 */
#define _GNU_SOURCE 1
#include <assert.h>
#include <stdio.h>
#include <unistd.h>
#include <systemd/sd-event.h>
int main(int argc, char **argv) {
  pid_t pid = fork();
  assert(pid >= 0);
  /* La señal SIGCHLD debe estar bloqueada para que sd_event_add_child funcione */
  sigset_t ss;
  sigemptyset(&ss);
  sigaddset(&ss, SIGCHLD);
  sigprocmask(SIG_BLOCK, &ss, NULL);
  if (pid == 0)  /* hijo */
    sleep(1);
  else {         /* padre */
    sd_event *e = NULL;
    int r;
    /* Crear el bucle de eventos predeterminado */
    sd_event_default(&e);
    assert(e);
    /* Creamos una fuente de eventos hijo flotante (adjunta a 'e').
     * El manejador predeterminado se llamará con 666 como userdata, que
     * se convertirá en el valor de salida del bucle. */
    r = sd_event_add_child(e, NULL, pid, WEXITED, NULL, (void*) 666);
    assert(r >= 0);
    r = sd_event_loop(e);
    assert(r == 666);
    sd_event_unref(e);
  }
  return 0;
}
