void sd_bus_track_unrefp(sd_bus_track **t);

void* sd_bus_track_set_userdata(sd_bus_track *t, void *userdata);

DESCRIPCIÓN

sd_bus_track_new() crea un nuevo objeto de rastreo de pares del bus. El objeto se asigna para el bus especificado y se devuelve en el parámetro *ret. Después de su uso, el objeto debe liberarse de nuevo soltando la referencia adquirida con sd_bus_track_unref() (ver abajo). Un objeto de rastreo de pares del bus puede usarse para mantener un seguimiento de los pares en un bus IPC específico, para casos en los que los pares hacen uso de uno o más objetos locales, para controlar el ciclo de vida de los objetos locales y asegurar que permanezcan disponibles mientras los pares que los necesitan estén presentes, y se desreferencien (y posiblemente se destruyan) tan pronto como todos los pares relevantes hayan desaparecido. Cada objeto de rastreo de pares del bus puede usarse para rastrear cero, uno o más pares a la vez. Las referencias a pares de bus específicos se añaden a través de sd_bus_track_add_name(3) o sd_bus_track_add_sender(). Pueden eliminarse de nuevo a través de sd_bus_track_remove_name() y sd_bus_track_remove_sender(). Alternativamente, las referencias a los pares se eliminan automáticamente cuando se desconectan del bus. Si no es NULL, el parámetro handler puede especificar una función que se invoca cada vez que se suelta la última referencia, independientemente de si la referencia se suelta explícitamente a través de sd_bus_track_remove_name() o implícitamente porque el par se desconectó del bus. El argumento final userdata puede usarse para adjuntar un puntero genérico de datos de usuario al objeto. Este puntero se pasa a la función de devolución de llamada (handler) cuando se invoca.

sd_bus_track_ref() crea una nueva referencia a un objeto de rastreo de pares del bus. Este objeto no se destruirá hasta que se haya llamado a sd_bus_track_unref() tantas veces más una vez. Una vez que el contador de referencias ha caído a cero, el objeto especificado ya no puede usarse; las llamadas posteriores a sd_bus_track_ref() o sd_bus_track_unref() sobre el mismo objeto son ilegales.

sd_bus_track_unref() destruye una referencia a un objeto de rastreo de pares del bus.

sd_bus_track_unrefp() es similar a sd_bus_track_unref() pero toma un puntero a un puntero a un objeto sd_bus_track. Esta llamada es útil en conjunción con el **Atributo de Variable de Limpieza** de GCC y LLVM [1]. Tenga en cuenta que esta función está definida como una función en línea.

sd_bus_track_ref(), sd_bus_track_unref() y sd_bus_track_unrefp() no realizan ninguna operación si el objeto de rastreo de pares del bus pasado es NULL.

Los objetos de rastreo de pares del bus pueden existir en dos modos: por defecto operan en modo no recursivo, pero opcionalmente pueden cambiarse al modo recursivo. Si operan en el modo no recursivo por defecto, un par se rastrea o no se rastrea. En este modo, invocar sd_bus_track_add_name() varias veces seguidas para el mismo par es completamente equivalente a llamarlo solo una vez, ya que la llamada agrega el par al conjunto de pares rastreados si es necesario, y no realiza ninguna operación si el par ya está siendo rastreado. Una única invocación de sd_bus_track_remove_name() elimina la referencia al par nuevamente, independientemente de cuántas veces se llamó a sd_bus_track_add_name() antes. Si operan en modo recursivo, se cuenta el número de veces que se invoca sd_bus_track_add_name() para el mismo nombre de par y se debe llamar a sd_bus_track_remove_name() el mismo número de veces antes de que el par deje de ser rastreado, con la excepción de cuando el par rastreado desaparece del bus, en cuyo caso el recuento es irrelevante y el rastreo del par específico se elimina inmediatamente. sd_bus_track_get_recursive() puede usarse para determinar si el objeto de rastreo de pares del bus está operando en modo recursivo. sd_bus_track_set_recursive() puede usarse para habilitar o deshabilitar el modo recursivo. Por defecto, un objeto de rastreo de pares del bus opera en modo no recursivo, y sd_bus_track_get_recursive() para un objeto recién asignado, por lo tanto, devuelve un valor igual a cero. Use sd_bus_track_set_recursive() para habilitar el modo recursivo, justo después de la asignación. Toma un argumento booleano para habilitar o deshabilitar el modo recursivo. Tenga en cuenta que los objetos de rastreo para los cuales ya se ha invocado sd_bus_track_add_name() al menos una vez (y que, por lo tanto, ya rastrean uno o más pares) no pueden cambiarse de modo recursivo a no recursivo.

sd_bus_track_get_bus() devuelve el objeto del bus al que pertenece el objeto de rastreo de pares del bus. Devuelve el objeto del bus pasado inicialmente a sd_bus_track_new() cuando se asignó el objeto.

sd_bus_track_get_userdata() devuelve el puntero genérico de datos de usuario establecido en el objeto de rastreo de pares del bus en el momento de la creación utilizando sd_bus_track_new() o en un momento posterior, utilizando sd_bus_track_set_userdata().

VALOR DE RETORNO

En caso de éxito, sd_bus_track_new() y sd_bus_track_set_recursive() devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo de estilo errno.

sd_bus_track_ref() siempre devuelve el argumento.

sd_bus_track_unref() siempre devuelve NULL.

sd_bus_track_get_recursive() devuelve 0 si se selecciona el modo no recursivo (por defecto), y mayor que 0 si se selecciona el modo recursivo. En caso de error, se devuelve un código de error negativo de estilo errno.

sd_bus_track_get_bus() devuelve el objeto del bus asociado al objeto de rastreo de pares del bus.

sd_bus_track_get_userdata() devuelve el puntero genérico de datos de usuario asociado al objeto de rastreo de pares del bus. sd_bus_track_set_userdata() devuelve el puntero de datos de usuario anterior establecido.

PROPIEDAD DE LA REFERENCIA

La función sd_bus_track_new() crea un nuevo objeto y el llamante posee la única referencia. Cuando ya no se necesite, esta referencia debe destruirse con sd_bus_track_unref().

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EBUSY

Ya se han añadido pares del bus al objeto de rastreo de pares del bus y se llamó a sd_bus_track_set_recursive() para cambiar el modo de rastreo.

-EINVAL

El parámetro especificado es inválido (NULL en caso de parámetros de salida).

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos (no multi-thread-safe). Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

NAME

sd_bus_track_set_userdata, sd_bus_track_get_userdata — Associate arbitrary data with a bus tracker

SYNOPSIS

#include <systemd/sd-bus.h>
void *sd_bus_track_get_userdata(sd_bus_track *track);
int sd_bus_track_set_userdata(sd_bus_track *track, void *userdata);

DESCRIPTION

The sd_bus_track_set_userdata() function associates arbitrary data, pointed to by userdata, with the bus tracker object track. This data is not owned by the bus tracker and should be managed externally.

The sd_bus_track_get_userdata() function returns the arbitrary data previously set using sd_bus_track_set_userdata() on the bus tracker object track.

RETURN VALUE

sd_bus_track_get_userdata() returns a pointer to the user-defined data, or NULL if no data was set.

sd_bus_track_set_userdata() returns 0 on success, or a negative errno error code on failure.

REFERENCE OWNERSHIP

The userdata is not owned by the track object. The caller is responsible for managing the lifetime of the userdata. The track object does not hold any reference to the userdata, and it will not be freed or unreferenced when the track object is destroyed.

NOTES

The sd_bus_track_set_userdata() function does not take ownership of the passed pointer. The caller is responsible for managing the lifetime of the data pointed to by userdata.

The sd_bus_track_get_userdata() function returns the pointer set by sd_bus_track_set_userdata(). If no pointer was set, it returns NULL.
