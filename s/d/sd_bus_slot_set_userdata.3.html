sd_bus_slot_set_userdata(3)

SD_BUS_SLOT_SET_USERDATA(3) sd_bus_slot_set_userdata SD_BUS_SLOT_SET_USERDATA(3)

NOMBRE

sd_bus_slot_set_userdata, sd_bus_slot_get_userdata - Establece y consulta el valor del campo "userdata"

SINOPSIS

#include <systemd/sd-bus.h>

void* sd_bus_slot_set_userdata(sd_bus_slot* slot, void* userdata);

void* sd_bus_slot_get_userdata(sd_bus_slot* slot);

DESCRIPCIÓN

El puntero userdata permite pasar datos entre el punto donde se registra una función de llamada (callback), por ejemplo, al añadir un filtro usando sd_bus_add_filter(3) o al realizar una llamada a función asíncrona usando sd_bus_call_async(3), y el punto donde se llama a la función de llamada, sin necesidad de tener ningún estado global. El puntero tiene el tipo void* y no es utilizado por las funciones de sd-bus de ninguna manera, excepto para pasarlo a la función de llamada.

Generalmente, el campo userdata se establece cuando el objeto slot se registra inicialmente. sd_bus_slot_set_userdata() puede ser utilizado para cambiarlo posteriormente para el objeto slot de bus slot. El valor anterior del campo es devuelto. El argumento y el valor devuelto pueden ser NULL. Se pasará como argumento userdata a la función de llamada adjunta al slot.

sd_bus_slot_get_userdata() obtiene el valor del campo userdata en el objeto slot de bus slot.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el valor del campo userdata antes de la llamada a la función. Si el objeto slot es NULL, se devolverá NULL para indicar un error, pero esto no es distinguible del valor NULL del campo userdata.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer las llamadas a setenv() solo en una fase temprana del programa, cuando aún no se han iniciado otros hilos.

HISTORIA

sd_bus_slot_set_userdata() y sd_bus_slot_get_userdata() se añadieron en la versión 240.
