SD_BUS_ATTACH_EVENT(3) sd_bus_attach_event SD_BUS_ATTACH_EVENT(3)

NOMBRE

sd_bus_attach_event, sd_bus_detach_event, sd_bus_get_event - Adjuntar un objeto de conexión de bus a un bucle de eventos

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_attach_event(sd_bus *bus, sd_event *e, int priority);

int sd_bus_detach_event(sd_bus *bus);

sd_event *sd_bus_get_event(sd_bus *bus);

DESCRIPCIÓN

sd_bus_attach_event() adjunta el objeto de conexión de bus especificado a un objeto de bucle de eventos de sd-event(3) con la prioridad especificada (consulte sd_event_source_set_priority(3) para obtener detalles sobre las prioridades del bucle de eventos). Cuando un objeto de conexión de bus se adjunta a un bucle de eventos, los mensajes entrantes se leerán y procesarán automáticamente, y los mensajes salientes se escribirán, cada vez que se ejecute el bucle de eventos. Cuando el bucle de eventos está a punto de terminar, la conexión de bus se vaciará y cerrará automáticamente (consulte sd_bus_set_close_on_exit(3) para obtener detalles sobre esto). Por defecto, los objetos de conexión de bus no están adjuntos a ningún bucle de eventos. Cuando un objeto de conexión de bus se adjunta a uno, no es necesario invocar sd_bus_wait(3) o sd_bus_process(3), ya que esta funcionalidad es manejada automáticamente por el bucle de eventos.

sd_bus_detach_event() desadjunta un objeto de bus de su bucle de eventos.

sd_bus_get_event() devuelve el objeto del bucle de eventos al que está actualmente adjunto el objeto de bus especificado, o NULL si actualmente no está adjunto a ninguno.

Tenga en cuenta que sd_bus_attach_event() es solo una de las tres formas admitidas para implementar el manejo de eventos de E/S para conexiones de bus. Alternativamente, use sd_bus_get_fd(3) para conectar un objeto de conexión de bus con bucles de eventos externos o manuales. O use sd_bus_wait(3) como una simple llamada síncrona y bloqueante para esperar E/S.

VALOR DE RETORNO

En caso de éxito, sd_bus_attach_event() y sd_bus_detach_event() devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo al estilo errno.

sd_bus_get_event() devuelve un objeto de bucle de eventos o NULL.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ECHILD

La conexión de bus se ha creado en un proceso, biblioteca o instancia de módulo diferente.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd .

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_attach_event(), sd_bus_detach_event() y sd_bus_get_event() se añadieron en la versión 221.
