sd_device_enumerator_unref(3)

SD_DEVICE_ENUMERATOR_NEW(3) sd_device_enumerator_new SD_DEVICE_ENUMERATOR_NEW(3)

NOMBRE

sd_device_enumerator_new, sd_device_enumerator_ref, sd_device_enumerator_unref, sd_device_enumerator_unrefp - Crear, referenciar y liberar un objeto enumerador de dispositivos

SINOPSIS

#include <systemd/sd-device.h>

int sd_device_enumerator_new(sd_device_enumerator **ret);

sd_device_enumerator* sd_device_enumerator_ref(sd_device_enumerator *enumerator);

sd_device_enumerator* sd_device_enumerator_unref(sd_device_enumerator *enumerator);

void sd_device_enumerator_unrefp(sd_device_enumerator **enumerator);

DESCRIPCIÓN

La familia de funciones sd_device_enumerator proporciona una forma de iterar sobre los dispositivos reconocidos por systemd-udevd(8). El enumerador permite filtrar y hacer coincidir dispositivos por subsistema, propiedades y otros atributos.

sd_device_enumerator_new() crea un nuevo objeto enumerador de dispositivos y almacena el resultado en el puntero referenciado por ret. Devuelve 0 en caso de éxito o un código de error negativo de estilo errno en caso de fallo.

sd_device_enumerator_ref() incrementa el contador de referencias del enumerator especificado en uno.

sd_device_enumerator_unref() decrementa el contador de referencias del enumerator en uno. Cuando el contador de referencias alcanza cero, el objeto enumerador se destruye y no puede ser utilizado más, por lo que las llamadas posteriores a sd_device_enumerator_unref() o sd_device_enumerator_unrefp() son ilegales.

sd_device_enumerator_unrefp() es similar a sd_device_enumerator_unref() pero toma un puntero a un puntero a un objeto sd_device_enumerator. Esta llamada es útil en conjunción con el **Attribute de Limpieza de Variables**[1] de GCC y LLVM. Tenga en cuenta que esta función se define como una función en línea. Utilice una declaración como la siguiente para asignar un objeto sd_device_enumerator que se libera automáticamente al salir del bloque de código:

{
  __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
  int r;
  ...
  r = sd_device_enumerator_new(&enumerator);
  if (r < 0)
    fprintf(stderr, "Error al asignar sd_device_enumerator: %s\n", strerror(-r));
  ...
}

sd_device_enumerator_ref() y sd_device_enumerator_unref() no realizan ninguna operación si el enumerator es NULL. sd_device_enumerator_unrefp() primero desreferenciará su argumento, que no debe ser NULL, y no realizará ninguna operación si *ese* es NULL.

VALOR DE RETORNO

sd_device_enumerator_new() devuelve 0 en caso de éxito o un código de error negativo de estilo errno en caso de fallo.

sd_device_enumerator_ref() siempre devuelve el puntero al enumerador.

sd_device_enumerator_unref() siempre devuelve NULL.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ENOMEM

Fallo en la asignación de memoria.

-EINVAL

El argumento es inválido.

EJEMPLO

Ejemplo 1. Uso de sd_device_enumerator_new()

/* SPDX-License-Identifier: MIT-0 */
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    sd_device_enumerator *enumerator;
    int r;
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "Error al crear el enumerador: %s\n", strerror(-r));
        return 1;
    }
    sd_device_enumerator_ref(enumerator);
    sd_device_enumerator_unref(enumerator);
    sd_device_enumerator_unref(enumerator);
    return 0;
}
