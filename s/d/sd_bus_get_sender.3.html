SD_BUS_SET_SENDER(3) sd_bus_set_sender SD_BUS_SET_SENDER(3)

NOMBRE

sd_bus_set_sender, sd_bus_get_sender - Configura el remitente por defecto para mensajes salientes

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_set_sender(sd_bus *bus, const char* name);

int sd_bus_get_sender(sd_bus *bus, const char** name);

DESCRIPCIÓN

sd_bus_set_sender() configura el nombre de servicio remitente por defecto a usar para mensajes salientes. El nombre de servicio especificado en el parámetro name se establece en todos los mensajes salientes que se envían en la conexión y que aún no tienen un remitente establecido, por ejemplo a través de sd_bus_message_set_sender(3). Tenga en cuenta que esta función solo se admite en conexiones directas, es decir, no en conexiones a un intermediario de bus, ya que el intermediario rellenará el nombre del servicio remitente automáticamente de todos modos. Por defecto, no se configura ningún nombre de remitente, y por lo tanto, los mensajes se envían sin el campo remitente establecido. Si el parámetro name se especifica como NULL, el nombre de servicio remitente por defecto se borra, volviendo al estado por defecto si se había configurado un nombre de servicio remitente por defecto previamente. Si se pasa como no NULL, el nombre especificado debe ser un nombre de servicio único o bien conocido válido.

sd_bus_get_sender() se puede utilizar para consultar el nombre de servicio por defecto actual para mensajes salientes.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo al estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ECHILD

La conexión del bus se ha creado en un proceso, biblioteca o instancia de módulo diferente.

-EPERM

El objeto de conexión de bus especificado no es una conexión directa sino una conexión intermediada.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_set_sender() y sd_bus_get_sender() se añadieron en la versión 237.
