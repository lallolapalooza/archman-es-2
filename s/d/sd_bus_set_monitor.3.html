SD_BUS_SET_SERVER(3) sd_bus_set_server SD_BUS_SET_SERVER(3)

NOMBRE

sd_bus_set_server, sd_bus_is_server, sd_bus_get_bus_id, sd_bus_set_bus_client, sd_bus_is_bus_client, sd_bus_set_monitor, sd_bus_is_monitor - Configurar el modo de conexión para un objeto de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_set_server(sd_bus *bus, int b, sd_id128_t id);

int sd_bus_is_server(sd_bus *bus);

int sd_bus_get_bus_id(sd_bus *bus, sd_id128_t *id);

int sd_bus_set_bus_client(sd_bus *bus, int b);

int sd_bus_is_bus_client(sd_bus *bus);

int sd_bus_set_monitor(sd_bus *bus, int b);

int sd_bus_is_monitor(sd_bus *bus);

DESCRIPCIÓN

sd_bus_set_server() configura el objeto de bus como un servidor para conexiones D-Bus directas. b habilita/deshabilita el modo servidor. Si es cero, el modo servidor está deshabilitado. De lo contrario, el modo servidor está habilitado. Configurar un objeto de bus como servidor es necesario para permitir el establecimiento de conexiones directas entre dos pares sin pasar por el demonio D-Bus. id debe contener un identificador entero de 128 bits para el servidor. Si los clientes añaden un campo guid a su cadena de dirección D-Bus, el id del servidor debe coincidir con este guid o la autenticación D-Bus fallará. Si no se define ningún id específico para el servidor, sd_id128_randomize(3) puede ser utilizado para generar un id aleatorio en su lugar.

sd_bus_is_server() devuelve si el modo servidor está habilitado para el objeto de bus dado.

sd_bus_get_bus_id() almacena el id del servidor D-Bus configurado usando sd_bus_set_server() (para objetos de bus de servidor) o recibido durante la autenticación D-Bus (para objetos de bus de cliente) en id.

sd_bus_set_bus_client() configura el objeto de bus como un cliente del demonio D-Bus. b habilita/deshabilita el modo cliente. Si es cero, el modo cliente está deshabilitado y el objeto de bus debe conectarse directamente a un servidor D-Bus. De lo contrario, el modo cliente está habilitado y el objeto de bus debe conectarse a un demonio D-Bus. Al conectarse a un bus existente usando cualquiera de las funciones de la familia sd_bus_open(3) o cualquiera de las funciones de la familia sd_bus_default(3), el objeto de bus se configura automáticamente como cliente de bus. Sin embargo, al conectarse a un demonio D-Bus llamando a sd_bus_set_address(3) seguido de sd_bus_start(3), el objeto de bus debe ser configurado manualmente como cliente de bus usando sd_bus_set_bus_client(). Por defecto, un objeto de bus no está configurado como cliente del demonio D-Bus.

sd_bus_is_bus_client() devuelve si el modo cliente está habilitado/deshabilitado para el objeto de bus dado.

sd_bus_set_monitor() configura el objeto de bus como un objeto monitor D-Bus. b habilita/deshabilita el modo monitor. Si es cero, el modo monitor está deshabilitado. Si es distinto de cero, el modo monitor está habilitado. Cuando el modo monitor está habilitado, no se pueden enviar mensajes a través del objeto de bus y no puede exponer ningún objeto en el bus. Para empezar a monitorizar mensajes, llame al método org.freedesktop.DBus.Monitoring.BecomeMonitor del demonio D-Bus y pase una lista de coincidencias que indiquen qué mensajes interceptar. Consulte La especificación D-Bus[1] para más información.

sd_bus_is_monitor() devuelve si el modo monitor está habilitado/deshabilitado para el objeto de bus dado.

VALOR DE RETORNO

En caso de éxito, sd_bus_set_server(), sd_bus_get_bus_id(), sd_bus_set_bus_client() y sd_bus_set_monitor() devuelven un entero no negativo. En caso de error, devuelven un código de error negativo estilo errno.

sd_bus_is_server(), sd_bus_is_bus_client() y sd_bus_is_monitor() devuelven un entero positivo cuando el modo servidor o cliente está habilitado, respectivamente. De lo contrario, devuelven cero.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ECHILD

La conexión del bus se ha creado en un proceso, biblioteca o instancia de módulo diferente.

Añadido en la versión 246.

-EPERM

La conexión del bus ya se ha iniciado.

Añadido en la versión 246.

-ENOPKG

El bus no se puede resolver.

Añadido en la versión 246.

-EINVAL

Un parámetro requerido era NULL o b era cero y id no era igual a SD_ID128_NULL.

Añadido en la versión 246.

-ENOTCONN

El bus no está conectado.

Añadido en la versión 246.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí usa getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_set_server(), sd_bus_is_server(), sd_bus_get_bus_id(), sd_bus_set_bus_client(), sd_bus_is_bus_client(), sd_bus_set_monitor(), y sd_bus_is_monitor() se añadieron en la versión 246.
