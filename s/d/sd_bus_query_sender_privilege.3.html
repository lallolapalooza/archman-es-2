SD_BUS_QUERY_SENDER_CREDS(3) sd_bus_query_sender_creds SD_BUS_QUERY_SENDER_CREDS(3)

NOMBRE

sd_bus_query_sender_creds, sd_bus_query_sender_privilege - Consultar credenciales/privilegios del remitente del mensaje del bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_query_sender_creds(sd_bus_message *m, uint64_t mask, sd_bus_creds **creds);

sd_bus_error* sd_bus_query_sender_privilege(sd_bus_message *m, int capability);

DESCRIPCIÓN

sd_bus_query_sender_creds() devuelve las credenciales del mensaje m. El parámetro mask es una combinación de flags SD_BUS_CREDS_* que indican qué información de credenciales interesa al llamante. Véase sd_bus_creds_new_from_pid(3) para una lista de flags posibles. Primero, este mensaje verifica si las credenciales solicitadas están adjuntas al propio mensaje. Si no lo están, pero el mensaje contiene el PID del remitente y el llamante especificó el flag SD_BUS_CREDS_AUGMENT, esta función intenta averiguar las credenciales faltantes por otros medios (empezando por el PID). Si el PID no está disponible pero el mensaje tiene un remitente, esta función llama a sd_bus_get_name_creds(3) para obtener las credenciales solicitadas. Si el mensaje no tiene remitente (cuando se usa una conexión directa), esta función llama a sd_bus_get_owner_creds(3) para obtener las credenciales solicitadas. En caso de éxito, las credenciales solicitadas se almacenan en creds. La propiedad del objeto de credenciales en creds se transfiere al llamante y debe liberarse llamando a sd_bus_creds_unref(3).

sd_bus_query_sender_privilege() verifica si el mensaje m tiene los privilegios solicitados. Si capability es un entero no negativo, esta función verifica si el mensaje tiene la capacidad con el mismo valor. Véase capabilities(7) para una lista de capacidades. Si capability es un entero negativo, esta función devuelve si el remitente del mensaje se ejecuta como el mismo usuario que el receptor del mensaje, o si el remitente del mensaje se ejecuta como root y el receptor del mensaje no se ejecuta como root. En caso de éxito y si el mensaje tiene los privilegios solicitados, esta función devuelve un entero positivo. Si el mensaje no tiene los privilegios solicitados, esta función devuelve cero.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven un entero no negativo. En caso de error, devuelven un código de error negativo tipo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El mensaje m o un parámetro de salida es NULL.

Añadido en la versión 246.

-ENOTCONN

El bus de m no está conectado.

Añadido en la versión 246.

-ECHILD

El bus de m se creó en un proceso, biblioteca o instancia de módulo diferente.

Añadido en la versión 246.

-EPERM

El mensaje m no está sellado.

Añadido en la versión 246.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_query_sender_creds() y sd_bus_query_sender_privilege() se añadieron en la versión 246.
