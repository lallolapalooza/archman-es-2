SD_BUS_MESSAGE_GET_COOKIE(3) sd_bus_message_get_cookie SD_BUS_MESSAGE_GET_COOKIE(3)

NOMBRE

sd_bus_message_get_cookie, sd_bus_message_get_reply_cookie - Devuelve la cookie de transacción de un mensaje

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_message_get_cookie(sd_bus_message *message, uint64_t *cookie);

int sd_bus_message_get_reply_cookie(sd_bus_message *message, uint64_t *cookie);

DESCRIPCIÓN

sd_bus_message_get_cookie() devuelve la cookie de transacción de un mensaje. La cookie identifica de forma única un mensaje dentro de cada par de buses, pero no es globalmente única. Se asigna cuando se envía un mensaje.

sd_bus_message_get_reply_cookie() devuelve la cookie de transacción del mensaje al que responde el mensaje especificado. Cuando se genera un mensaje de respuesta para un mensaje de llamada a método, su cookie se copia en este campo. Tenga en cuenta que, si bien cada mensaje que se transfiere se identifica mediante una cookie, solo los mensajes de respuesta llevan un campo de cookie de respuesta.

Ambas funciones toman un objeto de mensaje como primer parámetro y un lugar para almacenar la cookie de 64 bits.

VALOR DE RETORNO

En caso de éxito, estas llamadas devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo estilo errno.

En caso de éxito, la cookie/cookie de respuesta se devuelve en la variable entera sin signo de 64 bits especificada.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Un parámetro especificado es inválido.

-ENODATA

No se ha asignado ninguna cookie a este mensaje. Esto indica que el mensaje aún no se ha enviado y, por lo tanto, no tiene una cookie asignada, o que el mensaje no es un mensaje de respuesta de método y, por lo tanto, lleva un campo de cookie de respuesta.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un subproceso paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros subprocesos.

HISTORIA

sd_bus_message_get_cookie() y sd_bus_message_get_reply_cookie() se añadieron en la versión 209.
