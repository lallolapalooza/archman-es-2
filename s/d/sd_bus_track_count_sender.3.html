SD_BUS_TRACK_ADD_NAME(3) sd_bus_track_add_name SD_BUS_TRACK_ADD_NAME(3)

NOMBRE

sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_remove_sender, sd_bus_track_count, sd_bus_track_count_sender, sd_bus_track_count_name, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next - Añadir, eliminar y recuperar pares del bus rastreados en un objeto de rastreo de pares del bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(sd_bus_track* t, const char* name);

int sd_bus_track_add_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_remove_name(sd_bus_track* t, const char* name);

int sd_bus_track_remove_sender(sd_bus_track* t, sd_bus_message* message);

unsigned sd_bus_track_count(sd_bus_track* t);

int sd_bus_track_count_name(sd_bus_track* t, const char* name);

int sd_bus_track_count_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_contains(sd_bus_track* t, const char* name);

const char* sd_bus_track_first(sd_bus_track* t);

const char* sd_bus_track_next(sd_bus_track* t);

DESCRIPCIÓN

sd_bus_track_add_name() añade un par a rastrear a un objeto de rastreo de pares del bus. El primer argumento debe hacer referencia a un objeto de rastreo de pares del bus creado con sd_bus_track_new(3), el segundo nombre debe hacer referencia a un nombre de par D-Bus a rastrear, ya sea en formato de servicio conocido o único. Si el nombre aún no se está rastreando, se añadirá a la lista de nombres a rastrear. Si ya se está rastreando y el modo no recursivo está habilitado, no se ejecuta ninguna operación en esta llamada. Si el modo recursivo está habilitado, un contador por nombre se incrementa en uno cada vez que se invoca esta llamada, y sd_bus_track_remove_name() debe llamarse tantas veces como se haya invocado sd_bus_track_add_name() para dejar de rastrear el nombre. Use sd_bus_track_set_recursive(3) para cambiar del modo no recursivo predeterminado al modo recursivo, o viceversa. Tenga en cuenta que el nombre especificado se rastrea tal como está, los nombres conocidos no se resuelven a nombres únicos mediante esta llamada. Tenga en cuenta que varios objetos de rastreo de pares del bus pueden rastrear el mismo nombre.

sd_bus_track_remove_name() deshace el efecto de sd_bus_track_add_name() y elimina un nombre de par del bus de la lista de pares a observar. Dependiendo de si el modo no recursivo o recursivo está habilitado para el objeto de rastreo de pares del bus, esta llamada eliminará completamente el nombre del objeto de rastreo, o simplemente disminuirá el contador por nombre en uno, eliminando el nombre solo cuando el contador llega a cero (ver arriba). Tenga en cuenta que un par del bus que se desconecta del bus eliminará implícitamente sus nombres completamente del objeto de rastreo de pares del bus, independientemente del contador por nombre actual.

sd_bus_track_add_sender() y sd_bus_track_remove_sender() son similares a sd_bus_track_add_name() y sd_bus_track_remove_name() pero toman un mensaje de bus como argumento. Se determina el remitente de este mensaje de bus y se añade/elimina del objeto de rastreo de pares del bus. Como los mensajes siempre se originan de nombres únicos, y nunca de nombres conocidos, esto significa que esta llamada efectivamente solo añadirá nombres únicos al objeto de rastreo de pares del bus.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente en el objeto de rastreo de pares del bus especificado. Tenga en cuenta que esta función siempre devuelve el número real de nombres rastreados, y por lo tanto, si sd_bus_track_add_name() se ha invocado múltiples veces para el mismo nombre, solo se cuenta como uno, independientemente de si el modo recursivo está en uso o no.

sd_bus_track_count_name() devuelve el contador por nombre actual para el nombre especificado. Si se usa el modo no recursivo, devuelve 1 o 0, dependiendo de si el nombre especificado se ha añadido previamente al objeto de rastreo o no. Si se ha habilitado el modo recursivo, también pueden devolver valores mayores que 1, en caso de que sd_bus_track_add_name() se haya llamado varias veces para el mismo nombre.

sd_bus_track_count_sender() es similar a sd_bus_track_count_name(), pero toma un objeto de mensaje de bus y devuelve el contador por nombre que coincide con el remitente del mensaje.

sd_bus_track_contains() se puede utilizar para determinar si el nombre especificado se ha añadido al menos una vez al objeto de rastreo de pares del bus especificado.

sd_bus_track_first() y sd_bus_track_next() pueden utilizarse para enumerar todos los nombres que se están rastreando actualmente en el objeto de rastreo de pares del bus pasado. sd_bus_track_first() devuelve la primera entrada en el objeto y restablece un índice de lectura mantenido internamente. Cada invocación posterior de sd_bus_track_next() devuelve el siguiente nombre contenido en el objeto del bus. Si se alcanza el final, se devuelve NULL. Si no se ha añadido ningún nombre al objeto todavía, sd_bus_track_first() devolverá NULL inmediatamente. El orden en que se devuelven los nombres no está definido; en particular, qué nombre se considera el primero devuelto no está definido. Si el modo recursivo está habilitado y el mismo nombre se ha añadido múltiples veces al objeto de rastreo de pares del bus, solo se devuelve una vez en esta enumeración. Si se añaden nuevos nombres o se eliminan nombres existentes del objeto de rastreo de pares del bus mientras se está enumerando, la enumeración finaliza en la siguiente invocación de sd_bus_track_next(), ya que se devuelve NULL.

VALOR DE RETORNO

En caso de éxito, sd_bus_track_add_name() y sd_bus_track_add_sender() devuelven 0 si el nombre especificado ya se había añadido previamente al objeto de rastreo de pares del bus y un valor positivo si no. En caso de error, devuelven un código de error negativo de estilo errno.

sd_bus_track_remove_name() y sd_bus_track_remove_sender() devuelven un valor positivo si el nombre especificado fue rastreado previamente por el objeto de rastreo de pares del bus y ahora ha sido eliminado. En modo no recursivo, se devuelve 0 si el nombre especificado aún no estaba siendo rastreado. En modo recursivo, se devuelve -EUNATCH en este caso. En caso de error, devuelven un código de error negativo de estilo errno.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente, o 0 en caso de error.

sd_bus_track_count_name() y sd_bus_track_count_sender() devuelven el contador por nombre actual para el nombre especificado o el remitente del mensaje especificado. Se devuelve cero para los nombres que aún no se están rastreando, un valor positivo para los nombres añadidos al menos una vez. Valores mayores que 1 solo se devuelven en modo recursivo. En caso de error, se devuelve un código de error negativo de estilo errno.

sd_bus_track_contains() devuelve el nombre pasado si existe en el objeto de rastreo de pares del bus. En caso de error, y si el nombre aún no se ha añadido, se devuelve NULL.

sd_bus_track_first() y sd_bus_track_next() devuelven el primer/siguiente nombre contenido en el objeto de rastreo de pares del bus, y NULL si se alcanza el final de la enumeración y en caso de error.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EUNATCH

sd_bus_track_remove_name() o sd_bus_track_remove_sender() se han invocado para un nombre no añadido previamente al objeto de pares del bus.

-EINVAL

El parámetro especificado es inválido.

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

sd_bus_track_count_sender(3) — systemd libs

NAME

sd_bus_track_count_sender, sd_bus_track_add_sender, sd_bus_track_remove_sender, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next, sd_bus_track_add_name, sd_bus_track_count_name, sd_bus_track_count — Rastrear objetos de bus y obtener información sobre ellos

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_count_sender(sd_bus_track *track, const char *sender);
int sd_bus_track_add_sender(sd_bus_track *track, const char *sender);
int sd_bus_track_remove_sender(sd_bus_track *track, const char *sender);
int sd_bus_track_contains(sd_bus_track *track, const char *sender);
int sd_bus_track_first(sd_bus_track *track, const char **sender);
int sd_bus_track_next(sd_bus_track *track, const char **sender);
int sd_bus_track_add_name(sd_bus_track *track, const char *name);
int sd_bus_track_count_name(sd_bus_track *track, const char *name);
int sd_bus_track_count(sd_bus_track *track);

DESCRIPTION

El objeto sd_bus_track permite mantener un registro de un conjunto de nombres de servicios en el bus, o de remitentes de mensajes (a través de sus nombres de servicio). Esto es útil para monitorear un subconjunto de servicios en el bus y ser notificado cuando cambian de disponibilidad.

sd_bus_track_new(3) crea un nuevo objeto sd_bus_track. Después de la creación, puede agregar nombres de servicio o remitentes al seguimiento usando sd_bus_track_add_name(3) y sd_bus_track_add_sender(3), respectivamente. Tenga en cuenta que la adición de un remitente implica que solo se rastrearán los mensajes que provienen de ese remitente específico. La adición de un nombre de servicio implica que todos los mensajes que provienen de ese nombre de servicio serán rastreados.

sd_bus_track_remove_name(3) y sd_bus_track_remove_sender(3) eliminan un nombre de servicio o un remitente del seguimiento.

sd_bus_track_count(3) devuelve el número total de remitentes y nombres de servicio que se están rastreando actualmente. sd_bus_track_count_name(3) devuelve el número de nombres de servicio que se están rastreando actualmente. sd_bus_track_count_sender(3) devuelve el número de remitentes que se están rastreando actualmente.

sd_bus_track_contains(3) comprueba si el track dado está rastreando actualmente el sender especificado. Devuelve 1 si es así, 0 si no.

sd_bus_track_first(3) e sd_bus_track_next(3) se utilizan para iterar sobre los remitentes o nombres de servicio que se están rastreando actualmente. sd_bus_track_first(3) debe llamarse una vez para obtener el primer elemento. Luego, sd_bus_track_next(3) se llama repetidamente para obtener los elementos restantes. El puntero sender se establecerá en el remitente o nombre de servicio actual en cada iteración. La iteración termina cuando se devuelve un valor de retorno negativo.

RETURN VALUE

Las funciones que agregan o eliminan elementos devuelven 0 si la operación se realizó correctamente, o un código de error negativo si falló. Las funciones de conteo devuelven el recuento solicitado, o 0 si no hay elementos. sd_bus_track_contains(3) devuelve 1 si el remitente está contenido, 0 en caso contrario. sd_bus_track_first(3) e sd_bus_track_next(3) devuelven 0 si se encontró un elemento, o un valor negativo si no hay más elementos o si ocurrió un error.

NOTES

Cuando se usa sd_bus_track_add_sender(3) y sd_bus_track_remove_sender(3), los nombres de remitente son cadenas de texto que representan los nombres de servicio de los procesos que envían mensajes. Estos nombres suelen ser iguales a los nombres de servicio que los procesos solicitan al conectarse al bus.

Cuando se usa sd_bus_track_add_name(3) y sd_bus_track_remove_name(3), los nombres de servicio son cadenas de texto que representan los nombres de servicio que se desean rastrear. Esto es útil para rastrear todos los mensajes enviados por cualquier proceso que se identifique con ese nombre de servicio.

El seguimiento de remitentes o nombres de servicio puede ser una operación costosa, especialmente si se realiza desde una fase temprana del programa cuando aún no se han iniciado otros hilos.
