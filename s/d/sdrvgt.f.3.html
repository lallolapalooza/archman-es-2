DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina sdrvgt (logical, dimension( * ) dotype, integer nn, integer, dimension( * ) nval, integer nrhs, real thresh, logical tsterr, real, dimension( * ) a, real, dimension( * ) af, real, dimension( * ) b, real, dimension( * ) x, real, dimension( * ) xact, real, dimension( * ) work, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer nout)

SDRVGT

Propósito

!>
!> SDRVGT prueba SGTSV y -SVX.
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Los tipos de matrices a usar para la prueba. Las matrices del tipo j
!>          (para 1 <= j <= NTYPES) se usan para la prueba si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se usa.
!>

NN

!>          NN es INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, de dimensión (NN)
!>          Los valores de la dimensión de la matriz N.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, NRHS >= 0.
!>

THRESH

!>          THRESH es REAL
!>          El valor umbral para las razones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          cada razón de prueba se imprima, usar THRESH = 0.
!>

TSTERR

!>          TSTERR es LOGICAL
!>          Bandera que indica si se deben probar las salidas de error.
!>

A

!>          A es un array REAL, de dimensión (NMAX*4)
!>

AF

!>          AF es un array REAL, de dimensión (NMAX*4)
!>

B

!>          B es un array REAL, de dimensión (NMAX*NRHS)
!>

X

!>          X es un array REAL, de dimensión (NMAX*NRHS)
!>

XACT

!>          XACT es un array REAL, de dimensión (NMAX*NRHS)
!>

WORK

!>          WORK es un array REAL, de dimensión
!>                      (NMAX*max(3,NRHS))
!>

RWORK

!>          RWORK es un array REAL, de dimensión
!>                      (max(NMAX,2*NRHS))
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (2*NMAX)
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>
