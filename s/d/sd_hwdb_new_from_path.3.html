sd_hwdb_new_from_path(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_HWDB_NEW(3) sd_hwdb_new SD_HWDB_NEW(3)

NOMBRE

sd_hwdb_new, sd_hwdb_new_from_path, sd_hwdb_ref, sd_hwdb_unref - Crear un nuevo objeto hwdb y crear o destruir referencias a él

SINOPSIS

#include <systemd/sd-hwdb.h>

int sd_hwdb_new(sd_hwdb **hwdb);

int sd_hwdb_new_from_path(const char *path, sd_hwdb **hwdb);

sd_hwdb* sd_hwdb_ref(sd_hwdb *hwdb);

sd_hwdb* sd_hwdb_unref(sd_hwdb *hwdb);

DESCRIPCIÓN

sd_hwdb_new() crea un nuevo objeto hwdb para acceder a la base de datos binaria hwdb. Tras la inicialización, se localiza y abre el archivo que contiene la representación binaria de la base de datos de hardware. El nuevo objeto se devuelve en hwdb.

sd_hwdb_new_from_path() puede utilizarse para especificar la ruta desde la cual se debe abrir la base de datos binaria de hardware.

El objeto hwdb tiene un contador de referencias. sd_hwdb_ref() y sd_hwdb_unref() pueden utilizarse para obtener una nueva referencia o destruir una referencia existente a un objeto. El llamante debe desechar la referencia adquirida con sd_hwdb_new() llamando a sd_hwdb_unref() cuando haya terminado con el objeto.

Utilice sd_hwdb_seek(3), sd_hwdb_get(3), y sd_hwdb_enumerate(3) para acceder a las entradas.

VALOR DE RETORNO

En caso de éxito, sd_hwdb_new() y sd_hwdb_new_from_path() devuelven un entero no negativo. En caso de error, se devuelve un código de error negativo de estilo errno.

sd_hwdb_ref() siempre devuelve el argumento.

sd_hwdb_unref() siempre devuelve NULL.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ENOENT

No se pudo localizar el archivo de la base de datos binaria de hardware. Consulte systemd-hwdb(8) para más información.

Añadido en la versión 246.

-EINVAL

El archivo de la base de datos binaria de hardware localizado está en un formato incompatible.

Añadido en la versión 246.

-ENOMEM

Fallo en la asignación de memoria.

Añadido en la versión 246.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos (multi-thread-safe). Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar las llamadas a setenv() solo desde una fase temprana del programa, cuando aún no se hayan iniciado otros hilos.

HISTORIA

sd_hwdb_new(), sd_hwdb_ref() y sd_hwdb_unref() se añadieron en la versión 246.

sd_hwdb_new_from_path() se añadió en la versión 252.
