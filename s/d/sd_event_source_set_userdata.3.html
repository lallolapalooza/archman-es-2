SD_EVENT_SOURCE_SET_USERDATA(3) sd_event_source_set_userdata SD_EVENT_SOURCE_SET_USERDATA(3)

NOMBRE

sd_event_source_set_userdata, sd_event_source_get_userdata - Establecer o recuperar el puntero de datos de usuario de las fuentes de eventos

SINOPSIS

#include <systemd/sd-event.h>

void* sd_event_source_set_userdata(sd_event_source *fuente, void *datos_usuario);

void* sd_event_source_get_userdata(sd_event_source *fuente);

DESCRIPCIÓN

sd_event_source_set_userdata() puede ser utilizada para establecer un puntero de datos de usuario arbitrario para el objeto de fuente de eventos especificado como fuente. El puntero de datos de usuario generalmente se especifica al crear un objeto de fuente de eventos con llamadas como sd_event_add_io(3) o sd_event_add_time(3), y puede ser actualizado con esta llamada. Los datos de usuario también se pasan a todas las funciones de callback manejadoras asociadas con la fuente de eventos. El parámetro datos_usuario especifica el nuevo puntero de datos de usuario a establecer; la función devuelve el puntero de datos de usuario anterior. Tenga en cuenta que NULL es un puntero de datos de usuario válido.

sd_event_source_get_userdata() puede ser utilizada para consultar el puntero de datos de usuario actual asignado al objeto de fuente de eventos fuente.

VALOR DE RETORNO

En caso de éxito, sd_event_source_set_userdata() y sd_event_source_get_userdata() devuelven el puntero de datos de usuario previamente establecido. En caso de error, devuelven NULL.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara no ser seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando aún no se han iniciado otros hilos.

HISTORIAL

sd_event_source_set_userdata() y sd_event_source_get_userdata() se agregaron en la versión 229.
