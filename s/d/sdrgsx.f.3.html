SDRGSX

Propósito:

!>
!> SDRGSX comprueba el controlador experto del problema de valores propios generalizados no simétricos (forma de Schur) SGGESX.
!>
!> SGGESX factoriza A y B como Q S Z' y Q T Z', donde ' significa transpuesta, T es triangular superior, S está en forma de Schur generalizada (bloque triangular superior, con bloques de 1x1 y 2x2 en la diagonal, los bloques de 2x2 corresponden a pares conjugados complejos de valores propios generalizados), y Q y Z son ortogonales. También calcula los valores propios generalizados (alpha(1),beta(1)), ..., (alpha(n),beta(n)). Por lo tanto, w(j) = alpha(j)/beta(j) es una raíz de la ecuación característica
!>
!>     det( A - w(j) B ) = 0
!>
!> Opcionalmente, también reordena los valores propios para que un clúster seleccionado de valores propios aparezca en el bloque de diagonal principal de las formas de Schur; calcula un número recíproco de condición para el promedio de los valores propios seleccionados; y calcula un número recíproco de condición para los subespacios deflactantes derecho e izquierdo correspondientes a los valores propios seleccionados.
!>
!> Cuando se llama a SDRGSX con NSIZE > 0, se utilizan cinco (5) tipos de pares de matrices integradas para probar la rutina SGGESX.
!>
!> Cuando se llama a SDRGSX con NSIZE = 0, lee datos de matrices de prueba para probar SGGESX.
!>
!> Para cada par de matrices, se realizarán las siguientes pruebas y se compararán con el umbral THRESH, excepto para las pruebas (7) y (9):
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp )
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp )
!>
!> (3)   | I - QQ' | / ( n ulp )
!>
!> (4)   | I - ZZ' | / ( n ulp )
!>
!> (5)   si A está en forma de Schur (es decir, forma cuasi-triangular)
!>
!> (6)   máximo sobre j de D(j) donde:
!>
!>       si alpha(j) es real:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) es complejo:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>           y S y T son aquí los bloques diagonales de 2x2 de S y T
!>           correspondientes a los valores propios j y j+1.
!>
!> (7)   si la ordenación funcionó y SDIM es el número de valores propios
!>       que fueron seleccionados.
!>
!> (8)   el valor estimado DIF no difiere de los valores verdaderos de
!>       Difu y Difl en más de un factor 10*THRESH. Si la estimación DIF
!>       es cero, los valores verdaderos correspondientes de Difu y Difl
!>       deben ser menores que EPS*norm(A, B). Si el valor verdadero de Difu
!>       y Difl son cero, la estimación DIF debe ser menor que
!>       EPS*norm(A, B).
!>
!> (9)   Si SGGESX devuelve INFO = N+3, la reordenación
!>       y comprobamos que DIF = PL = PR = 0 y que el valor verdadero de
!>       Difu y Difl es < EPS*norm(A, B). Contamos los eventos cuando
!>       INFO=N+3.
!>
!> Para matrices de prueba leídas, se ejecutan las pruebas anteriores, excepto que el
!> valor exacto de DIF (y PL) son datos de entrada. Además, hay
!> una prueba más para matrices de prueba leídas:
!>
!> (10)  el valor estimado PL no difiere del valor verdadero de
!>       PLTRU en más de un factor THRESH. Si la estimación PL es
!>       cero, el valor verdadero correspondiente de PLTRU debe ser menor que
!>       EPS*norm(A, B). Si el valor verdadero de PLTRU es cero, la
!>       estimación PL debe ser menor que EPS*norm(A, B).
!>
!> Tenga en cuenta que para las pruebas integradas, se generan y prueban un total de 10*NSIZE*(NSIZE-1)
!> pares de matrices. NSIZE debe mantenerse pequeño.
!>
!> Se utiliza SVD (rutina SGESVD) para calcular el valor verdadero de DIF_u
!> y DIF_l al probar los problemas de prueba integrados.
!>
!> Matrices de Prueba Integradas
!> ======================
!>
!> Todas las matrices de prueba integradas son el bloque 2x2 de
!> matrices triangulares
!>
!>          A = [ A11 A12 ]    y      B = [ B11 B12 ]
!>              [     A22 ]                 [     B22 ]
!>
!> donde para diferentes tipos A11 y A22 se dan de la siguiente manera.
!> A12 y B12 se eligen para que la ecuación de Sylvester generalizada
!>
!>          A11*R - L*A22 = -A12
!>          B11*R - L*B22 = -B12
!>
!> tengan soluciones prescritas R y L.
!>
!> Tipo 1:  A11 = J_m(1,-1) y A_22 = J_k(1-a,1).
!>          B11 = I_m, B22 = I_k
!>          donde J_k(a,b) es el bloque de Jordan kxk con ``a'' en la
!>          diagonal y ``b'' en la superdiagonal.
!>
!> Tipo 2:  A11 = (a_ij) = ( 2(.5-sin(i)) ) y
!>          B11 = (b_ij) = ( 2(.5-sin(ij)) ) para i=1,...,m, j=i,...,m
!>          A22 = (a_ij) = ( 2(.5-sin(i+j)) ) y
!>          B22 = (b_ij) = ( 2(.5-sin(ij)) ) para i=m+1,...,k, j=i,...,k
!>
!> Tipo 3:  A11, A22 y B11, B22 se eligen como para el Tipo 2, pero cada
!>          segundo bloque diagonal en A_11 y cada tercer bloque diagonal
!>          en A_22 se convierten en bloques de 2x2.
!>
!> Tipo 4:  A11 = ( 20(.5 - sin(ij)) ) y B22 = ( 2(.5 - sin(i+j)) )
!>             para i=1,...,m,  j=1,...,m y
!>          A22 = ( 20(.5 - sin(i+j)) ) y B22 = ( 2(.5 - sin(ij)) )
!>             para i=m+1,...,k,  j=m+1,...,k
!>
!> Tipo 5:  (A,B) y tienen valores propios potencialmente cercanos o comunes y
!>          una desviación muy grande de la diagonalidad de bloques A_11
!>          se elige como la submatriz principal m x m de A_1:
!>                  |  1  b                            |
!>                  | -b  1                            |
!>                  |        1+d  b                    |
!>                  |         -b 1+d                   |
!>           A_1 =  |                  d  1            |
!>                  |                 -1  d            |
!>                  |                        -d  1     |
!>                  |                        -1 -d     |
!>                  |                               1  |
!>          y A_22 se elige como la submatriz principal k x k de A_2:
!>                  | -1  b                            |
!>                  | -b -1                            |
!>                  |       1-d  b                     |
!>                  |       -b  1-d                    |
!>           A_2 =  |                 d 1+b            |
!>                  |               -1-b d             |
!>                  |                       -d  1+b    |
!>                  |                      -1+b  -d    |
!>                  |                              1-d |
!>          y la matriz B se eligen como matrices de identidad (ver SLATM5).
!>
!>

NCMAX

!>          NCMAX es INTEGER
!>          NMAX máximo permitido para generar la matriz de Kronecker
!>          en la llamada a SLAKF2
!>

THRESH

!>          THRESH es REAL
!>          Una prueba contará como si el, calculado como
!>          se describe anteriormente, excede THRESH. Tenga en cuenta que el error
!>          está escalado para ser O(1), por lo que THRESH debería ser un múltiplo
!>          razonable de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          o el tamaño de la matriz. THRESH >= 0.
!>

NIN

!>          NIN es INTEGER
!>          El número de unidad de FORTRAN para leer el archivo de datos de
!>          problemas a resolver.
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad de FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0).
!>

A

!>          A es un array REAL, de dimensión (LDA, NSIZE)
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular. A la salida, A contiene la última matriz utilizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A, B, AI, BI, Z y Q,
!>          LDA >= max( 1, NSIZE ). Para la prueba de lectura,
!>          LDA >= max( 1, N ), N es el tamaño de las matrices de prueba.
!>

B

!>          B es un array REAL, de dimensión (LDA, NSIZE)
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular. A la salida, B contiene la última matriz utilizada.
!>

AI

!>          AI es un array REAL, de dimensión (LDA, NSIZE)
!>          Copia de A, modificada por SGGESX.
!>

BI

!>          BI es un array REAL, de dimensión (LDA, NSIZE)
!>          Copia de B, modificada por SGGESX.
!>

Z

!>          Z es un array REAL, de dimensión (LDA, NSIZE)
!>          Z contiene los vectores de Schur izquierdos calculados por SGGESX.

Q

!>          Q es un array REAL, de dimensión (LDA, NSIZE)
!>          Q contiene los vectores de Schur derechos calculados por SGGESX.

ALPHAR

!>          ALPHAR es un array REAL, de dimensión (NSIZE)
!>

ALPHAI

!>          ALPHAI es un array REAL, de dimensión (NSIZE)

BETA
