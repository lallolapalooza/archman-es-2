SDFFILTER(1) Comandos de usuario SDFFILTER(1)

NOMBRE

sdffilter - página del manual para sdffilter 25.11

SINOPSIS

sdffilter [OPCIONES] archivosDeEntrada...

DESCRIPCIÓN

Proporciona información en una variedad de formatos (incluido uno similar a usda) sobre Capas Sdf o partes especificadas (filtradas) de una capa.

Posicionales:

archivosDeEntrada ...
Los archivos de entrada a procesar

OPCIONES

-h,--ayuda
Imprimir este mensaje de ayuda y salir
-p,--ruta expresion_regular
Informar solo de las rutas que coincidan con esta expresión regular.
-f,--campo expresion_regular
Informar solo de los campos que coincidan con esta expresión regular.
-t,--tiempo n o ff..lf
Informar solo de estos tiempos (n) o rangos de tiempo (ff..lf) para campos de 'timeSamples'
--toleranciaTiempo tol
Informar de tiempos cercanos a los solicitados dentro de esta tolerancia relativa. Predeterminado: 0.000125
--limiteTamanoArray INT
Truncar arrays con más de este número de elementos. Si es -1, no truncar arrays. Predeterminado: 0 para salida 'outline', 8 para salida 'pseudoLayer', y -1 para salida 'layer'.
--limiteTamanoMuestrasTiempo INT
Truncar timeSamples con más de este número de valores. Si es -1, no truncar timeSamples. Predeterminado: 0 para salida 'outline', 8 para salida 'pseudoLayer', y -1 para salida 'layer'. El truncamiento se realiza después de filtrar inicialmente por los argumentos de --tiempo.
-o,--salida TEXTO
Dirigir la salida a este archivo. Utilice 'outputFormat' para un control más fino sobre el formato subyacente para formatos de salida que no se determinan de forma única por la extensión del archivo.
--tipoSalida validez|resumen|esquema|pseudoCapa|capa
Especificar el formato de salida; 'resumen' informa de estadísticas generales, 'esquema' es un informe de texto plano de rutas y campos, 'pseudoCapa' es similar al formato de archivo usda pero con valores de array y timeSamples truncados para facilitar la lectura humana, y 'capa' es la salida de capa real, con el formato controlado por los argumentos 'salida' y 'formatoSalida'. Predeterminado: esquema
--formatoSalida TEXTO
Suministrar esto como la entrada 'format' de SdfFileFormatArguments para la salida 'capa' a un archivo. Requiere salida de 'capa' y un archivo de salida especificado.
--ordenarPor ruta|campo
Agrupar la salida 'esquema' por ruta o por campo. Ignorado para otros tipos de salida. Predeterminado: ruta
--sinValores
No informar de los valores de los campos.
