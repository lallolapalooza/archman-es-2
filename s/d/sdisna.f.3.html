subroutine sdisna (character job, integer m, integer n, real, dimension( * ) d, real, dimension( * ) sep, integer info)

SDISNA

Propósito:

!>
!> SDISNA calcula los números de condición recíprocos para los
!>   vectores propios de una matriz simétrica real o Hermitiana compleja
!>   o para los vectores singulares izquierdos o derechos de una matriz
!>   general m-por-n. El número de condición recíproco es la 'brecha'
!>   entre el valor propio o singular correspondiente y el más cercano.
!>
!> El límite del error, medido por ángulo en radianes, en el vector I-ésimo
!> calculado viene dado por
!>
!>        SLAMCH( 'E' ) * ( ANORM / SEP( I ) )
!>
!> donde ANORM = norma 2(A) = max( abs( D(j) ) ). SEP(I) no se permite
!>   que sea menor que SLAMCH( 'E' )*ANORM para limitar el tamaño del
!>   límite de error.
!>
!> SDISNA también puede usarse para calcular límites de error para
!>   vectores propios del problema Hermitiano definido generalizado.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica para qué problema se deben calcular los números de
!>          condición recíprocos:
!>          = 'E':  los vectores propios de una matriz simétrica/Hermitiana;
!>          = 'L':  los vectores singulares izquierdos de una matriz general;
!>          = 'R':  los vectores singulares derechos de una matriz general.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz. M >= 0.
!>

N

!>          N es INTEGER
!>          Si JOB = 'L' o 'R', el número de columnas de la matriz,
!>          en cuyo caso N >= 0. Ignorado si JOB = 'E'.
!>

D

!>          D es array REAL, dimension (M) si JOB = 'E'
!>                              dimension (min(M,N)) si JOB = 'L' o 'R'
!>          Los valores propios (si JOB = 'E') o los valores singulares (si
!>          JOB = 'L' o 'R') de la matriz, en orden creciente o decreciente.
!>          Si son valores singulares, deben ser no negativos.
!>

SEP

!>          SEP es array REAL, dimension (M) si JOB = 'E'
!>                               dimension (min(M,N)) si JOB = 'L' o 'R'
!>          Los números de condición recíprocos de los vectores.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal.
!>
