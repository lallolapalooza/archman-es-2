sd_bus_negotiate_fds(3)

SD_BUS_NEGOTIATE_FDS(3) sd_bus_negotiate_fds SD_BUS_NEGOTIATE_FDS(3)

NOMBRE

sd_bus_negotiate_fds, sd_bus_negotiate_timestamp, sd_bus_negotiate_creds, sd_bus_get_creds_mask - Controlar la negociación de características en conexiones de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_negotiate_fds(sd_bus *bus, int b);

int sd_bus_negotiate_timestamp(sd_bus *bus, int b);

int sd_bus_negotiate_creds(sd_bus *bus, int b, uint64_t mask);

int sd_bus_get_creds_mask(sd_bus *bus, uint64_t *mask);

DESCRIPCIÓN

sd_bus_negotiate_fds() controla si se deben negociar el paso de descriptores de archivo para la conexión de bus especificada. Toma un objeto de bus y un booleano que, cuando es verdadero, habilita el paso de descriptores de archivo, y cuando es falso, lo deshabilita. Tenga en cuenta que no todos los transportes y servidores admiten el paso de descriptores de archivo. En particular, los transportes en red generalmente no admiten el paso de descriptores de archivo. Para averiguar si el paso de descriptores de archivo está disponible después de la negociación, use sd_bus_can_send(3) y pase SD_BUS_TYPE_UNIX_FD. Tenga en cuenta que el paso de descriptores de archivo siempre está habilitado tanto para enviar como para recibir, o para ninguno, pero nunca solo en una dirección. Por defecto, la negociación del paso de descriptores de archivo está habilitada para todas las conexiones.

sd_bus_negotiate_timestamp() controla si se adjuntarán automáticamente marcas de tiempo implícitas del remitente a todos los mensajes entrantes. Toma un objeto de bus y un booleano que, cuando es verdadero, habilita la marca de tiempo, y cuando es falso, la deshabilita. Use sd_bus_message_get_monotonic_usec(3), sd_bus_message_get_realtime_usec(3), sd_bus_message_get_seqnum(3) para consultar las marcas de tiempo de los mensajes entrantes. Si la negociación está deshabilitada o no es compatible, estas llamadas fallarán con -ENODATA. Tenga en cuenta que actualmente ningún transporte admite la marca de tiempo de los mensajes. Por defecto, la marca de tiempo de los mensajes no se negocia para las conexiones.

sd_bus_negotiate_creds() controla si y qué credenciales implícitas del remitente se adjuntarán automáticamente a todos los mensajes entrantes. Toma un objeto de bus y un booleano que indica si habilitar o deshabilitar las partes de credenciales codificadas en el valor de máscara de bits proporcionado. Tenga en cuenta que no todos los transportes admiten la adjunción de credenciales del remitente a los mensajes, o no admiten todos los tipos de parámetros de credenciales del remitente, o pueden suprimirlas bajo ciertas circunstancias para mensajes individuales. Específicamente, dbus1 solo admite SD_BUS_CREDS_UNIQUE_NAME. Las credenciales del remitente son adecuadas para decisiones de autorización. Por defecto, solo se habilitan SD_BUS_CREDS_WELL_KNOWN_NAMES y SD_BUS_CREDS_UNIQUE_NAME. De hecho, estos dos campos de credenciales siempre se envían y no se pueden desactivar.

sd_bus_get_creds_mask() devuelve el conjunto de credenciales del remitente que se negoció para adjuntar a todos los mensajes entrantes en mask. Este valor es solo un límite superior. Por lo tanto, asegúrese siempre de verificar explícitamente qué credenciales están adjuntas a un mensaje específico antes de usarlo.

La función sd_bus_negotiate_fds() solo se puede llamar antes de que la conexión se haya iniciado con sd_bus_start(3). Tanto sd_bus_negotiate_timestamp() como sd_bus_negotiate_creds() también se pueden llamar después de que se haya configurado una conexión. Tenga en cuenta que, al operar en una conexión compartida entre varios componentes del mismo programa (por ejemplo, a través de sd_bus_default(3)), se recomienda encarecidamente habilitar solo campos de metadatos adicionales por mensaje, pero nunca deshabilitarlos de nuevo, para no deshabilitar la funcionalidad necesaria para otros componentes.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven un entero no negativo. En caso de error, devuelven un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EPERM

La conexión de bus ya ha sido iniciada.

-EINVAL

Un argumento es inválido.

Añadido en la versión 246.

-ENOPKG

El bus no se puede resolver.

Añadido en la versión 246.

-ECHILD

El bus fue creado en un proceso, biblioteca o instancia de módulo diferente.

Añadido en la versión 246.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que está declarado como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un subproceso paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros subprocesos.

HISTORIA

sd_bus_negotiate_fds(), sd_bus_negotiate_timestamp() y sd_bus_negotiate_creds() se añadieron en la versión 212.

sd_bus_get_creds_mask() se añadió en la versión 246.
