sd_varlink_get_description(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_VARLINK_SET_DESCRIPTION(3) sd_varlink_set_description SD_VARLINK_SET_DESCRIPTION(3)

NOMBRE

sd_varlink_set_description, sd_varlink_get_description - Establecer o consultar la descripción de un objeto de conexión Varlink

SINOPSIS

#include <systemd/sd-varlink.h>

int sd_varlink_set_description(sd_varlink *link, const char *description);

const char* sd_varlink_get_description(sd_varlink *link);

DESCRIPCIÓN

sd_varlink_set_description() establece la cadena de descripción que se utiliza en el registro a la cadena especificada. La cadena se copia internamente y se libera cuando el objeto de conexión Varlink se desasigna. El argumento description puede ser NULL, en cuyo caso la descripción se elimina.

sd_varlink_get_description() devuelve una cadena de descripción para la conexión Varlink especificada. Esta cadena puede haber sido establecida previamente con sd_varlink_set_description(). Si no se establece de esta manera, puede devolverse una cadena predeterminada o NULL, dependiendo de cómo se asignó y configuró la conexión.

VALOR DE RETORNO

En caso de éxito, sd_varlink_set_description() devuelve un entero no negativo. En caso de error, devuelve un código de error negativo estilo errno. sd_varlink_get_description() devuelve NULL o un puntero a la cadena de descripción.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Un argumento es inválido.

-ENOMEM

Error de asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para múltiples hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIAL

sd_varlink_set_description() se añadió en la versión 257.

sd_varlink_get_description() se añadió en la versión 258.
