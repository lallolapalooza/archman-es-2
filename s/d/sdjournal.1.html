NOMBRE

sdjournal - Proporciona una interfaz para capturar entradas del journal de systemd.

SINOPSIS

sdjournal [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interfaz> ] [ --extcap-config ] [ --capture ] [ --fifo=<ruta a archivo o tubería> ] [ --start-from=<conteo de entradas> ]

DESCRIPCIÓN

sdjournal es una herramienta extcap que permite capturar entradas del journal de systemd. Se puede utilizar para correlacionar eventos del sistema con el tráfico de red.

Interfaces soportadas:

1.sdjournal

OPCIONES

--help

Imprime los argumentos del programa.

--version

Imprime la versión del programa.

--extcap-interfaces

Lista las interfaces disponibles.

--extcap-interface=<interfaz>

Usa las interfaces especificadas.

--extcap-dlts

Lista los DLTs de la interfaz especificada.

--extcap-config

Lista las opciones de configuración de la interfaz especificada.

--capture

Comienza a capturar desde la interfaz especificada y escribe los datos crudos de los paquetes en la ubicación especificada por --fifo.

--fifo=<ruta a archivo o tubería>

Guarda el paquete capturado en un archivo o lo envía a través de una tubería.

--start-from=<conteo de entradas>

Comienza desde las últimas <conteo de entradas> entradas, similar al argumento "-n" o "--lines" para el comando tail(1). Los valores prefijados con un signo + comienzan desde el principio del journal, de lo contrario, el conteo comienza desde el final. El valor predeterminado es 10. Para incluir todas las entradas, usa +0.

EJEMPLOS

Para ver los argumentos del programa:

sdjournal --help

Para ver la versión del programa:

sdjournal --version

Para ver las interfaces:

sdjournal --extcap-interfaces

Solo se soporta una interfaz (sdjournal).

Salida de ejemplo

interface {value=sdjournal}{display=Captura del journal de systemd}

Para ver los DLTs de la interfaz:

sdjournal --extcap-interface=sdjournal --extcap-dlts

Salida de ejemplo

dlt {number=147}{name=sdjournal}{display=USER0}

Para ver las opciones de configuración de la interfaz:

sdjournal --extcap-interface=sdjournal --extcap-config

Salida de ejemplo

arg {number=0}{call=--start-from}{display=Posición inicial}{type=string}
    {tooltip=La posición inicial del journal. Los valores con un "+" al principio comienzan desde el principio, similar al comando "tail"}

Para capturar:

sdjournal --extcap-interface=sdjournal --fifo=/tmp/sdjournal.pcap --capture

Para capturar todas las entradas desde que el sistema arrancó:

sdjournal --extcap-interface=sdjournal --fifo=/tmp/sdjournal.pcap --capture --start-from +0

Nota

Para detener la captura, presiona CTRL+C / mata / termina la aplicación.
