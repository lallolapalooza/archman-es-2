SD_BUS_IS_OPEN(3) sd_bus_is_open SD_BUS_IS_OPEN(3)

NOMBRE

sd_bus_is_open, sd_bus_is_ready - Comprobar si la conexión del bus está abierta o lista

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_is_open(sd_bus *bus);

int sd_bus_is_ready(sd_bus *bus);

DESCRIPCIÓN

sd_bus_is_open() comprueba si la conexión del bus especificada está abierta, es decir, en proceso de ser establecida, ya establecida o en proceso de ser cerrada. Devuelve cero cuando la conexión aún no ha comenzado (es decir, sd_bus_start(3) o una llamada equivalente aún no se ha invocado), o está completamente terminada de nuevo (por ejemplo, después de sd_bus_close(3)), devuelve un valor positivo en caso contrario.

sd_bus_is_ready() comprueba si la conexión especificada está completamente establecida, es decir, ha completado las fases de conexión y autenticación del protocolo y ha recibido la respuesta a la llamada del método Hello(), y no está en proceso de ser cerrada de nuevo. Devuelve cero fuera de este estado y un valor positivo en caso contrario. Efectivamente, esta función devuelve un valor positivo mientras se pueden enviar o recibir mensajes regulares en la conexión.

El argumento bus puede ser NULL, en cuyo caso también se devuelve cero.

Para ser notificado cuando la conexión esté completamente establecida, use sd_bus_set_connected_signal(3) e instale una coincidencia para la señal Connected() en la interfaz "org.freedesktop.DBus.Local". Para ser notificado cuando la conexión se cierre de nuevo, instale una coincidencia para la señal Disconnected() en la interfaz "org.freedesktop.DBus.Local".

VALOR DE RETORNO

Estas funciones devuelven 0 si el bus no está en el estado dado y un entero positivo cuando lo está. En caso de error, se devuelve un código de error negativo al estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ECHILD

La conexión del bus se ha creado en un proceso, biblioteca o instancia de módulo diferente.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_is_open() se añadió en la versión 221.

sd_bus_is_ready() se añadió en la versión 237.
