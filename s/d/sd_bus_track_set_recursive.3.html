#include <systemd/sd-bus.h>

void sd_bus_track_unrefp(sd_bus_track **t);

int sd_bus_track_set_recursive(sd_bus_track *t, int b);

void* sd_bus_track_get_userdata(sd_bus_track *t);

void* sd_bus_track_set_userdata(sd_bus_track *t, void *userdata);

DESCRIPCIÓN

sd_bus_track_new() crea un nuevo objeto de seguimiento de compañeros del bus. El objeto se asigna para el bus especificado y se devuelve en el parámetro *ret. Después de su uso, el objeto debe liberarse nuevamente soltando la referencia adquirida con sd_bus_track_unref() (ver abajo). Un objeto de seguimiento de compañeros del bus puede usarse para realizar un seguimiento de los compañeros en un bus IPC específico, para casos en los que los compañeros hacen uso de uno o más objetos locales, con el fin de controlar el ciclo de vida de los objetos locales y asegurar que permanezcan mientras los compañeros que los necesitan estén presentes, y se desreferencien (y posiblemente se destruyan) tan pronto como todos los compañeros relevantes hayan desaparecido. Cada objeto de seguimiento de compañeros del bus puede usarse para rastrear cero, uno o más compañeros a la vez. Las referencias a compañeros específicos del bus se agregan a través de sd_bus_track_add_name(3) o sd_bus_track_add_sender(). Pueden eliminarse nuevamente a través de sd_bus_track_remove_name() y sd_bus_track_remove_sender(). Alternativamente, las referencias a los compañeros se eliminan automáticamente cuando se desconectan del bus. Si no es NULL, el handler puede especificar una función que se invoca cada vez que se suelta la última referencia, independientemente de si la referencia se suelta explícitamente a través de sd_bus_track_remove_name() o implícitamente porque el compañero se desconectó del bus. El argumento final userdata puede usarse para adjuntar un puntero de datos de usuario genérico al objeto. Este puntero se pasa a la función de devolución de llamada del manejador cuando se invoca.

sd_bus_track_ref() crea una nueva referencia a un objeto de seguimiento de compañeros del bus. Este objeto no se destruirá hasta que se haya llamado a sd_bus_track_unref() tantas veces más una. Una vez que el contador de referencias ha caído a cero, el objeto especificado ya no puede usarse, y las llamadas posteriores a sd_bus_track_ref() o sd_bus_track_unref() sobre el mismo objeto son ilegales.

sd_bus_track_unref() destruye una referencia a un objeto de seguimiento de compañeros del bus.

sd_bus_track_unrefp() es similar a sd_bus_track_unref() pero toma un puntero a un puntero a un objeto sd_bus_track. Esta llamada es útil en conjunción con el Atributo de Variable de Limpieza de GCC y LLVM[1]. Tenga en cuenta que esta función está definida como una función en línea.

sd_bus_track_ref(), sd_bus_track_unref() y sd_bus_track_unrefp() no ejecutan ninguna operación si el objeto de seguimiento de compañeros del bus pasado es NULL.

Los objetos de seguimiento de compañeros del bus pueden existir en dos modos: por defecto operan en modo no recursivo, pero opcionalmente pueden cambiarse a modo recursivo. Si operan en el modo no recursivo por defecto, un compañero es rastreado o no rastreado. En este modo, invocar sd_bus_track_add_name() varias veces seguidas para el mismo compañero es completamente equivalente a llamarlo solo una vez, ya que la llamada agrega el compañero al conjunto de compañeros rastreados si es necesario, y no ejecuta ninguna operación si el compañero ya está siendo rastreado. Una única invocación de sd_bus_track_remove_name() elimina la referencia al compañero nuevamente, independientemente de cuántas veces se haya llamado a sd_bus_track_add_name() antes. Si operan en modo recursivo, se cuenta el número de veces que se invoca sd_bus_track_add_name() para el mismo nombre de compañero y se debe llamar a sd_bus_track_remove_name() el mismo número de veces antes de que el compañero no sea rastreado, con la excepción de cuando el compañero rastreado desaparece del bus, en cuyo caso el recuento es irrelevante y el rastreo del compañero específico se elimina inmediatamente. sd_bus_track_get_recursive() se puede usar para determinar si el objeto de seguimiento de compañeros del bus está operando en modo recursivo. sd_bus_track_set_recursive() se puede usar para habilitar o deshabilitar el modo recursivo. Por defecto, un objeto de seguimiento de compañeros del bus opera en modo no recursivo, y sd_bus_track_get_recursive() para un objeto recién asignado, por lo tanto, devuelve un valor igual a cero. Use sd_bus_track_set_recursive() para habilitar el modo recursivo, justo después de la asignación. Toma un argumento booleano para habilitar o deshabilitar el modo recursivo. Tenga en cuenta que los objetos de seguimiento para los cuales sd_bus_track_add_name() ya se invocó al menos una vez (y que por lo tanto rastrean uno o más compañeros) ya no pueden cambiarse de modo recursivo a no recursivo.

sd_bus_track_get_bus() devuelve el objeto de bus al que pertenece el objeto de seguimiento de compañeros del bus. Devuelve el objeto de bus pasado inicialmente a sd_bus_track_new() cuando se asignó el objeto.

sd_bus_track_get_userdata() devuelve el puntero de datos de usuario genérico establecido en el objeto de seguimiento de compañeros del bus en el momento de la creación usando sd_bus_track_new() o en un momento posterior, usando sd_bus_track_set_userdata().

VALOR DE RETORNO

En caso de éxito, sd_bus_track_new() y sd_bus_track_set_recursive() devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo estilo errno.

sd_bus_track_ref() siempre devuelve el argumento.

sd_bus_track_unref() siempre devuelve NULL.

sd_bus_track_get_recursive() devuelve 0 si se selecciona el modo no recursivo (por defecto), y mayor que 0 si se selecciona el modo recursivo. En caso de error, se devuelve un código de error negativo estilo errno.

sd_bus_track_get_bus() devuelve el objeto de bus asociado al objeto de seguimiento de compañeros del bus.

sd_bus_track_get_userdata() devuelve el puntero de datos de usuario genérico asociado con el objeto de seguimiento de compañeros del bus. sd_bus_track_set_userdata() devuelve el puntero de datos de usuario previo establecido.

PROPIEDAD DE LA REFERENCIA

La función sd_bus_track_new() crea un nuevo objeto y el llamador es el propietario de la única referencia. Cuando ya no sea necesaria, esta referencia debe destruirse con sd_bus_track_unref().

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EBUSY

Ya se han agregado compañeros del bus al objeto de seguimiento de compañeros del bus y se llamó a sd_bus_track_set_recursive() para cambiar el modo de rastreo.

-EINVAL

El parámetro especificado es inválido (NULL en caso de parámetros de salida).

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí usa getenv(3), que se declara como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
