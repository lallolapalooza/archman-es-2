sd_seat_get_sessions(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_SEAT_GET_ACTIVE(3) sd_seat_get_active SD_SEAT_GET_ACTIVE(3)

NOMBRE

sd_seat_get_active, sd_seat_get_sessions, sd_seat_can_tty, sd_seat_can_graphical - Determinar el estado de un asiento específico

SINOPSIS

#include <systemd/sd-login.h>

int sd_seat_get_active(const char *seat, char **session, uid_t *uid);

int sd_seat_get_sessions(const char *seat, char ***ret_sessions, uid_t **ret_uids, unsigned int *ret_n_uids);

int sd_seat_can_tty(const char *seat);

int sd_seat_can_graphical(const char *seat);

DESCRIPCIÓN

sd_seat_get_active() puede usarse para determinar qué sesión está actualmente activa en un asiento, si es que hay alguna. Devuelve el identificador de sesión y el identificador de usuario del usuario de Unix al que pertenece la sesión. Se puede pasar NULL al parámetro del identificador de sesión o al identificador de usuario, en cuyo caso solo se consultará uno de los parámetros. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_seat_get_sessions() puede usarse para determinar todas las sesiones en el asiento especificado. Devuelve dos arrays, uno (terminado en NULL) con los identificadores de sesión y otro con los identificadores de usuario de los usuarios de Unix a los que pertenecen las sesiones. Se puede usar un parámetro adicional para devolver el número de entradas en este último array. Este valor es el mismo que el valor de retorno si este es no negativo. Los parámetros de salida pueden pasarse como NULL en caso de que estos valores de salida no sean necesarios. Los arrays y las cadenas a los que hacen referencia deben liberarse con la llamada free(3) de libc después de su uso. Tenga en cuenta que en lugar de un array vacío, puede devolverse NULL y esto debe considerarse equivalente a un array vacío.

sd_seat_can_tty() puede usarse para determinar si un asiento específico proporciona funcionalidad TTY, es decir, si es útil como consola de texto.

sd_seat_can_graphical() puede usarse para determinar si un asiento específico proporciona funcionalidad gráfica, es decir, si es útil como pantalla gráfica.

Si el parámetro seat de cualquiera de estas funciones se pasa como NULL, la operación se ejecuta para el asiento de la sesión del proceso de llamada, si es que existe.

VALOR DE RETORNO

En caso de éxito, sd_seat_get_active() devuelve 0 o un entero positivo. En caso de éxito, sd_seat_get_sessions() devuelve el número de entradas en el array de identificadores de sesión. Si la prueba tiene éxito, sd_seat_can_tty() y sd_seat_can_graphical() devuelven un entero positivo; si falla, devuelven 0. En caso de error, estas llamadas devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ENODATA

El campo dado no está especificado para el asiento descrito.

-ENXIO

El asiento especificado es desconocido.

-EINVAL

Un parámetro de entrada era inválido (fuera de rango o NULL, donde eso no se acepta).

-ENOMEM

Falló la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_seat_can_tty() y sd_seat_can_graphical() se añadieron en la versión 186.
