SD_JOURNAL_GET_CURSOR(3) sd_journal_get_cursor SD_JOURNAL_GET_CURSOR(3)

NOMBRE

sd_journal_get_cursor, sd_journal_test_cursor - Obtener una cadena de cursor para o probar una cadena de cursor contra la entrada actual del journal

SINOPSIS

#include <systemd/sd-journal.h>

int sd_journal_get_cursor(sd_journal *j, char **ret_cursor);

int sd_journal_test_cursor(sd_journal *j, const char *cursor);

DESCRIPCIÓN

sd_journal_get_cursor() devuelve una cadena de cursor para la entrada actual del journal. Un cursor es una serialización de la posición actual del journal formateada como texto. La cadena solo contiene caracteres imprimibles y puede ser pasada en forma de texto. El cursor identifica una entrada del journal de forma global y estable, y puede ser usado para buscarla más tarde a través de sd_journal_seek_cursor(3). La cadena del cursor debe ser considerada opaca y no debe ser analizada por los clientes. Buscar una posición de cursor sin que la entrada específica esté disponible localmente buscará la entrada disponible más cercana (en términos de tiempo). La llamada toma dos argumentos: un objeto de contexto de journal y un puntero a un puntero de cadena donde se colocará la cadena del cursor. La cadena se asigna usando malloc(3) de libc y debe ser liberada después de su uso con free(3). El parámetro ret_cursor puede ser pasado como NULL en cuyo caso la cadena del cursor no se genera, sin embargo, el valor de retorno indicará si el contexto del journal está posicionado actualmente en una entrada y, por lo tanto, tiene un cursor asociado.

sd_journal_test_cursor() puede ser usado para comprobar si la posición actual en el journal coincide con el cursor especificado. Esto es útil ya que las cadenas de cursor no identifican una entrada de forma única: la misma entrada podría ser referenciada por múltiples cadenas de cursor diferentes, y por lo tanto, comparar cadenas de cursores no es posible. Use esta llamada para verificar después de una invocación de sd_journal_seek_cursor(3) si la entrada buscada fue realmente encontrada en el journal o si se usó la siguiente entrada más cercana en su lugar.

Tenga en cuenta que sd_journal_get_cursor() y sd_journal_test_cursor() no funcionarán antes de que se haya llamado al menos una vez a sd_journal_next(3) (o a una de las otras funciones que se mueven a una entrada) para posicionar el puntero de lectura en una entrada válida.

VALOR DE RETORNO

sd_journal_get_cursor() devuelve 0 en caso de éxito o un código de error negativo al estilo de errno. sd_journal_test_cursor() devuelve un valor positivo si la entrada actual coincide con el cursor especificado, 0 si no coincide con el cursor especificado, o un código de error negativo al estilo de errno en caso de fallo.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EADDRNOTAVAIL

El contexto del journal no está posicionado actualmente en ninguna entrada, y por lo tanto no se puede generar ninguna cadena de cursor.

-EINVAL

El parámetro del contexto del journal es NULL.

-ECHILD

El objeto de contexto del journal fue asignado en un proceso diferente al que se está utilizando ahora.

NOTAS

Todas las funciones enumeradas aquí son agnósticas a hilos y solo un único hilo puede operar sobre un objeto dado en un momento dado. Diferentes hilos pueden acceder al mismo objeto en diferentes momentos. Múltiples objetos independientes pueden ser utilizados desde diferentes hilos en paralelo.

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

HISTORIA

sd_journal_test_cursor() se añadió en la versión 195.
