sd_bus_set_method_call_timeout(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_SET_METHOD_CALL_TIMEOUT(3) sd_bus_set_method_call_timeout SD_BUS_SET_METHOD_CALL_TIMEOUT(3)

NOMBRE

sd_bus_set_method_call_timeout, sd_bus_get_method_call_timeout - Establecer o consultar el tiempo de espera de llamada de método D-Bus predeterminado de un objeto de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_set_method_call_timeout(sd_bus *bus, uint64_t usec);

int sd_bus_get_method_call_timeout(sd_bus *bus, uint64_t *ret);

DESCRIPCIÓN

sd_bus_set_method_call_timeout() establece el tiempo de espera de llamada de método D-Bus predeterminado de bus a usec microsegundos.

sd_bus_get_method_call_timeout() consulta el tiempo de espera de llamada de método D-Bus predeterminado de bus. Si no se estableció ningún tiempo de espera de llamada de método usando sd_bus_set_method_call_timeout(), el tiempo de espera se lee de la variable de entorno $SYSTEMD_BUS_TIMEOUT. Si esta variable de entorno no está establecida o no contiene un tiempo de espera válido, la implementación recurre a un tiempo de espera de llamada de método predefinido de 25 segundos. Tenga en cuenta que $SYSTEMD_BUS_TIMEOUT se lee una vez y se almacena en caché, por lo que los llamadores no deben confiar en poder cambiar el tiempo de espera de llamada de método predeterminado en tiempo de ejecución cambiando el valor de $SYSTEMD_BUS_TIMEOUT. En su lugar, llame a sd_bus_set_method_call_timeout() para cambiar el tiempo de espera de llamada de método predeterminado.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven un entero no negativo. En caso de error, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Los parámetros bus o ret son NULL.

Añadido en la versión 246.

-ENOPKG

No se pudo resolver el objeto de bus bus.

Añadido en la versión 246.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_set_method_call_timeout() y sd_bus_get_method_call_timeout() se añadieron en la versión 246.
