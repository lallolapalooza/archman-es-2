SDRGEV3

Propósito:

!>
!> SDRGEV3 comprueba la subrutina principal de prueba para el problema de valores
!> propios generalizado no simétrico SGGEV3.
!>
!> SGGEV3 calcula para un par de matrices no simétricas (A,B) de n por n,
!> los valores propios generalizados y, opcionalmente, los vectores propios
!> izquierdos y derechos.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una relación alpha/beta = w, tal que A - w*B es singular. Generalmente
!> se representa como el par (alpha,beta), ya que hay una interpretación
!> razonable para beta=0, e incluso para que ambos sean cero.
!>
!> Un vector propio generalizado derecho correspondiente a un valor propio
!> generalizado w para un par de matrices (A,B) es un vector r tal que
!> (A - wB) * r = 0. Un vector propio generalizado izquierdo es un vector l tal
!> que l**H * (A - wB) = 0, donde l**H es la traspuesta conjugada de l.
!>
!> Cuando se llama a SDRGEV3, se especifican varios tamaños de matriz y
!> varios tipos de matriz. Para cada tamaño y cada tipo de matriz, se generará
!> un par de matrices (A, B) y se utilizará para las pruebas. Para cada par de
!> matrices, se realizarán las siguientes pruebas y se compararán con el
!> umbral THRESH.
!>
!> Resultados de SGGEV3:
!>
!> (1) max sobre todos los pares de valores/vectores propios izquierdos (alpha/beta,l) de
!>
!>     | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>     donde VL**H es la traspuesta conjugada de VL.
!>
!> (2) | |VL(i)| - 1 | / ulp y si el componente más grande es real
!>
!>     VL(i) denota la i-ésima columna de VL.
!>
!> (3) max sobre todos los pares de valores/vectores propios derechos (alpha/beta,r) de
!>
!>     | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4) | |VR(i)| - 1 | / ulp y si el componente más grande es real
!>
!>     VR(i) denota la i-ésima columna de VR.
!>
!> (5) W(completo) = W(parcial)
!>     W(completo) denota los valores propios calculados cuando se calculan
!>     tanto l como r, y W(parcial) denota los valores propios calculados
!>     cuando solo se calculan W, solo W y r, o solo W y l.
!>
!> (6) VL(completo) = VL(parcial)
!>     VL(completo) denota los vectores propios izquierdos calculados cuando se
!>     calculan tanto l como r, y VL(parcial) denota el resultado cuando solo
!>     se calcula l.
!>
!> (7) VR(completo) = VR(parcial)
!>     VR(completo) denota los vectores propios derechos calculados cuando se
!>     calculan tanto l como r, y VR(parcial) denota el resultado cuando solo
!>     se calcula l.
!>
!>
!> Matrices de Prueba
!> ---- --------------
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los tipos de matriz se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1) ( 0, 0 )         (un par de matrices cero)
!>
!> (2) ( I, 0 )         (una identidad y una matriz cero)
!>
!> (3) ( 0, I )         (una identidad y una matriz cero)
!>
!> (4) ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5) ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6) ( X, Y )         donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad k x k y J un bloque de Jordan
!>                       (k+1)x(k+1); k=(N-1)/2
!>
!> (7) ( D, I )         donde D es diag( 0, 1,..., N-1 ) (una matriz diagonal
!>                       con esas entradas diagonales.)
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) donde big es cercano al desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z    donde T1 y T2 son matrices triangulares superiores
!>                        con entradas O(1) aleatorias por encima de la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de máquina.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorias.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     donde T1 y T2 son matrices triangulares superiores
!>                         aleatorias.
!>
!>

the generalized eigenvalue problem for the full reproducibility

Function/Subroutine Documentation

NTYPES

!> NTYPES is an INTEGER, the number of types of matrices to be generated.
!> If NTYPES is smaller than the maximum number of types defined
!> (PARAMETER MAXTYP), then types NTYPES+1 through MAXTYP will not be
!> generated. If NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through
!> DOTYPE(NTYPES) will be ignored.
!>

NSIZES

!> NSIZES is an INTEGER, the number of matrix sizes to be generated.
!>

NN

!> NN is an INTEGER array, dimension (NSIZES).
!> NN(i) specifies the size of the i-th problem to be generated.
!>

DOTYPE

!> DOTYPE is LOGICAL array, dimension (NTYPES)
!> If DOTYPE(j) is .TRUE., then for each size in NN a
!> matrix of that size and of type j will be generated.
!> If NTYPES is smaller than the maximum number of types
!> defined (PARAMETER MAXTYP), then types NTYPES+1 through
!> MAXTYP will not be generated. If NTYPES is larger
!> than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!> will be ignored.
!>

ISEED

!> ISEED is INTEGER array, dimension (4)
!> On entry ISEED specifies the seed of the random number
!> generator. The array elements should be between 0 and 4095;
!> if not they will be reduced mod 4096. Also, ISEED(4) must
!> be odd.  The random number generator uses a linear
!> congruential sequence limited to small integers, and so
!> should produce machine independent random numbers. The
!> values of ISEED are changed on exit, and can be used in the
!> next call to SDRGEV3 to continue the same random number
!> sequence.
!>

THRESH

!> THRESH is REAL
!> A test will count as  if the , computed as
!> described above, exceeds THRESH.  Note that the error is
!> scaled to be O(1), so THRESH should be a reasonably small
!> multiple of 1, e.g., 10 or 100.  In particular, it should
!> not depend on the precision (single vs. double) or the size
!> of the matrix.  It must be at least zero.
!>

NOUNIT

!> NOUNIT is INTEGER
!> The FORTRAN unit number for printing out error messages
!> (e.g., if a routine returns IERR not equal to 0.)
!>

A

!> A is REAL array,
!>                                      dimension(LDA, max(NN))
!> Used to hold the original A matrix.  Used as input only
!> if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!> DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!> LDA is INTEGER
!> The leading dimension of A, B, S, and T.
!> It must be at least 1 and at least max( NN ).
!>

B

!> B is REAL array,
!>                                      dimension(LDA, max(NN))
!> Used to hold the original B matrix.  Used as input only
!> if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!> DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!> S is REAL array,
!>                                dimension (LDA, max(NN))
!> The Schur form matrix computed from A by SGGEV3.  On exit, S
!> contains the Schur form matrix corresponding to the matrix
!> in A.
!>

T

!> T is REAL array,
!>                                dimension (LDA, max(NN))
!> The upper triangular matrix computed from B by SGGEV3.
!>

Q

!> Q is REAL array,
!>                                dimension (LDQ, max(NN))
!> The (left) eigenvectors matrix computed by SGGEV3.
!>

LDQ

!> LDQ is INTEGER
!> The leading dimension of Q and Z. It must
!> be at least 1 and at least max( NN ).
!>

Z

!> Z is REAL array, dimension( LDQ, max(NN) )
!> The (right) orthogonal matrix computed by SGGEV3.
!>

QE

!> QE is REAL array, dimension( LDQ, max(NN) )
!> QE holds the computed right or left eigenvectors.
!>

LDQE

!> LDQE is INTEGER
!> The leading dimension of QE. LDQE >= max(1,max(NN)).
!>

ALPHAR

!> ALPHAR is REAL array, dimension (max(NN))
!>

ALPHAI

!> ALPHAI is REAL array, dimension (max(NN))
!>

BETA

!> BETA is REAL array, dimension (max(NN))
!>
!> The generalized eigenvalues of (A,B) computed by SGGEV3.
!> ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) is the k-th
!> generalized eigenvalue of A and B.
!>

ALPHR1

!> ALPHR1 is REAL array, dimension (max(NN))
!>

ALPHI1

!> ALPHI1 is REAL array, dimension (max(NN))
!>

BETA1

!> BETA1 is REAL array, dimension (max(NN))
!>
!> Like ALPHAR, ALPHAI, BETA, these arrays contain the
!> eigenvalues of A and B, but those computed when SGGEV3 only
!> computes a partial eigendecomposition, i.e. not the
!> eigenvalues and left and right eigenvectors.
!>

WORK

!> WORK is REAL array, dimension (LWORK)
!>

LWORK

!> LWORK is INTEGER
!> The number of entries in WORK.  LWORK >= MAX( 8*N, N*(N+1) ).
!>

RESULT

!> RESULT is REAL array, dimension (2)
!> The values computed by the tests described above.
!> The values are currently limited to 1/ulp, to avoid overflow.
!>

INFO

!> INFO is INTEGER
!> = 0:  successful exit
!> < 0:  if INFO = -i, the i-th argument had an illegal value.
!> > 0:  A routine returned an error code.  INFO is the
!>       absolute value of the INFO value returned.
!>
