DESCRIPCIÓN

La función sd_device_enumerator_add_match_parent() añade un filtro al enumerator para que solo se enumeren los dispositivos bajo el árbol del dispositivo parent especificado. Si se llama varias veces, el dispositivo parent establecido previamente se borra y solo la última llamada tiene efecto.

La función sd_device_enumerator_add_match_property() añade un filtro al enumerator para que solo se enumeren los dispositivos cuya property especificada sea igual al value. Tanto property como value pueden ser patrones glob. Cuando se llama varias veces, se enumeran los dispositivos que tienen al menos una de las propiedades especificadas con valores coincidentes. Es decir, los filtros se combinan con OR.

La función sd_device_enumerator_add_match_property_required() añade un filtro al enumerator para que solo se enumeren los dispositivos cuya property especificada sea igual al value. Esta función es similar a sd_device_enumerator_add_match_property(), pero cuando se llama varias veces, se enumeran los dispositivos que tienen todas las propiedades especificadas con valores coincidentes. Es decir, los filtros se combinan con AND.

La función sd_device_enumerator_add_match_subsystem() añade un filtro al enumerator para que se listen todos los dispositivos del subsystem especificado, cuando match es true. Cuando match es false, se enumeran todos los dispositivos excepto los del subsystem especificado. Cuando se llama varias veces, los filtros positivos se combinan con OR y los negativos con AND.

La función sd_device_enumerator_add_match_sysattr() añade un filtro al atributo sysfs sysattr que coincida con value. value puede ser un patrón glob. Si value es NULL, se incluyen los dispositivos que tienen (si match es true) o no tienen (si match es false) el sysattr especificado, independientemente de su valor. Es decir, NULL es en gran medida equivalente a "*". Cuando esta función se llama varias veces, solo se enumeran los dispositivos que coinciden con todos los filtros de sysattr especificados. Es decir, estos filtros se combinan con AND.

La función sd_device_enumerator_add_match_sysname() añade un filtro para que solo se enumeren los dispositivos cuyo nombre de sistema (sysname) sea igual a sysname. sysname puede ser un patrón glob. Cuando se llama varias veces, los filtros se combinan con OR.

La función sd_device_enumerator_add_nomatch_sysname() añade un filtro para excluir de la enumeración los dispositivos cuyo nombre de sistema (sysname) sea igual a sysname. Esto es útil para excluir dispositivos específicos del proceso de enumeración. Cuando se llama varias veces, las características se combinan con AND.

La función sd_device_enumerator_add_match_tag() añade un filtro para que solo se enumeren los dispositivos etiquetados con tag. Cuando se llama varias veces, los filtros se combinan con OR.

La función sd_device_enumerator_allow_uninitialized() permite incluir en la enumeración los dispositivos que aún no han sido inicializados por udev.

La función sd_device_enumerator_add_all_parents() enumera todos los dispositivos padre de los dispositivos coincidentes. Esto es útil para casos en los que se desean incluir todos los dispositivos padre en la enumeración, como cuando se está interesado en el árbol de dispositivos completo que conduce a un dispositivo específico.

VALOR DE RETORNO

Todas las funciones devuelven 0 o un entero positivo en caso de éxito, o un código de error negativo estilo errno en caso de fallo.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ENOMEM

Fallo en la asignación de memoria.

-EINVAL

Uno de los argumentos es inválido.

EJEMPLOS

Ejemplo 1. Detectar Dispositivos USB Extraíbles (Usando Coincidencia y Exclusión)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* Crear un nuevo enumerador de dispositivos */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "Fallo al crear el enumerador de dispositivos: %s\n", strerror(-r));
        return 1;
    }
    /* Incluir solo dispositivos del subsistema "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "Fallo al añadir coincidencia de subsistema: %s\n", strerror(-r));
        return 1;
    }
    /*
     * Excluir dispositivos donde el atributo sysfs "removable" es "0"
     * Estos son típicamente dispositivos no extraíbles como interfaces USB integradas
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "Fallo al añadir coincidencia de sysattr: %s\n", strerror(-r));
        return 1;
    }
    /* Comenzar a enumerar los dispositivos coincidentes */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* Obtener la ruta sysfs (syspath) del dispositivo */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("Dispositivo USB extraíble encontrado: %s\n", syspath);
    }
    return 0;
}

DESCRIPTION

The sd_device_enumerator API provides an interface for iterating through and querying devices managed by udev(8). This API is part of systemd-libs(3).

A sd_device_enumerator object is used to define search criteria and then to retrieve matching devices.

First, an enumerator object should be created with sd_device_enumerator_new(). Then, zero or more matching criteria can be added using the sd_device_enumerator_add_match_*() functions. After setting up the criteria, devices can be retrieved using sd_device_enumerator_get_device_first() and sd_device_enumerator_get_device_next() in a loop, or using the convenience functions like sd_device_enumerator_get_devices_by_sysname().

After iterating through all devices, the enumerator object should be released with sd_device_enumerator_done().

The functions sd_device_enumerator_ref() and sd_device_enumerator_unref() may be used to manage the lifetime of the enumerator object.

The functions sd_device_enumerator_get_parent_device() and sd_device_enumerator_get_child_device() may be used to navigate the device tree.

sd_device_enumerator_add_all_parents() adds all parent devices of the current device to the enumerator's results. This is a recursive operation.

sd_device_enumerator_add_all_children() adds all child devices of the current device to the enumerator's results. This is a recursive operation.

The various sd_device_enumerator_add_match_*() functions add filters to the enumerator. When devices are retrieved, only those matching *all* the specified filters will be returned. If no filters are added, all devices will be returned.

Supported matching functions are:

sd_device_enumerator_add_match_sysname(enumerator, sysname)
Matches devices by their sysname (e.g. "sda", "input0").
sd_device_enumerator_add_match_subsystem(enumerator, subsystem)
Matches devices by their subsystem (e.g. "block", "input").
sd_device_enumerator_add_match_tag(enumerator, tag)
Matches devices by their tag (e.g. "systemd", "uaccess").
sd_device_enumerator_add_match_type(enumerator, type)
Matches devices by their type (e.g. "disk", "partition").
sd_device_enumerator_add_match_property(enumerator, name, value)
Matches devices by having a specific device property name set to value.
sd_device_enumerator_add_match_path(enumerator, path)
Matches devices by their path (e.g. "/dev/sda"). Note that this is the device node path, not the sysfs path.
sd_device_enumerator_add_match_exclusive_path(enumerator, path)
Similar to sd_device_enumerator_add_match_path(), but guarantees that only one device node path will match. This is useful for devices that might expose multiple device nodes, like serial ports.
sd_device_enumerator_add_sysnum_path(enumerator, path)
Matches devices based on the "sysnum" device property, often used for devices like network interfaces or sound cards. This is often used in conjunction with sd_device_enumerator_add_match_subsystem().

The functions sd_device_enumerator_get_device_first() and sd_device_enumerator_get_device_next() allow iterating over all devices matching the specified criteria. device is a pointer to a sd_device object, which is reference counted. The caller must call sd_device_unref() on the returned device when done with it.

The functions sd_device_enumerator_get_devices_by_*() are convenience functions that return all matching devices in an array. The caller is responsible for freeing the returned array using free(). The individual sd_device objects within the array are still reference counted and must be unreferenced using sd_device_unref().

sd_device_enumerator_get_device_by_path() and sd_device_enumerator_get_device_by_sysname() retrieve a single device. If multiple devices match, one is returned arbitrarily.

sd_device_enumerator_done() should be called to release resources associated with the enumerator.

The sd_device object represents a device. It is reference counted. Use sd_device_ref() to increment the reference count and sd_device_unref() to decrement it. When the reference count drops to zero, the device object is freed.

Refer to sd_device(3) for details on the sd_device object and its associated functions.

RETURN VALUE

The sd_device_enumerator_add_*(), sd_device_enumerator_get_device_*(), sd_device_enumerator_get_parent_device(), sd_device_enumerator_get_child_device(), and sd_device_enumerator_done() functions return 0 on success, or a negative errno value on failure. Specifically:

-ENOMEM
Memory allocation failed.
-EINVAL
Invalid argument supplied.
-ENOENT
No matching device found.

The sd_device_enumerator_new() function returns 1 on success or a negative errno value on failure. Note that it returns 1 instead of 0 on success.

The sd_device_enumerator_ref() and sd_device_enumerator_unref() functions return the enumerator object passed to them.

EXAMPLES

Example 1: Find all USB storage devices

sd_device_enumerator *enumerator = NULL;
sd_device *device = NULL;
int r;

r = sd_device_enumerator_new(&enumerator);
if (r < 0)
    goto error;

r = sd_device_enumerator_add_match_subsystem(enumerator, "usb");
if (r < 0)
    goto error;

r = sd_device_enumerator_add_match_sysname(enumerator, "storage");
if (r < 0)
    goto error;

// You might want to iterate through devices here
// r = sd_device_enumerator_get_device_first(enumerator, &device);
// while (r > 0) {
//     // Process device
//     sd_device_unref(device);
//     r = sd_device_enumerator_get_device_next(enumerator, &device);
// }

// Or use a convenience function
sd_device **devices = NULL;
size_t count = 0;
r = sd_device_enumerator_get_devices_by_subsystem(enumerator, "usb", &devices, &count);
if (r > 0) {
    for (size_t i = 0; i < count; i++) {
        // Process devices[i]
        printf("Found USB device: %s\n", sd_device_get_sysname(devices[i]));
    }
    free(devices); // Free the array of device pointers
} else if (r < 0 && r != -ENOENT) {
    goto error;
}

sd_device_enumerator_done(enumerator);
return 0;

error:
    fprintf(stderr, "Error: %s\n", strerror(-r));
    sd_device_unref(device); // If device was assigned
    sd_device_enumerator_done(enumerator);
    return r;
