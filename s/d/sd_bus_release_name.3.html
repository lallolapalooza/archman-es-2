sd_bus_release_name(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_REQUEST_NAME(3) sd_bus_request_name SD_BUS_REQUEST_NAME(3)

NOMBRE

sd_bus_request_name, sd_bus_request_name_async, sd_bus_release_name, sd_bus_release_name_async - Solicitar o liberar un nombre de servicio conocido en un bus

SINOPSIS

#include <systemd/sd-bus.h>

typedef int (*sd_bus_message_handler_t)(sd_bus_message *m, void *userdata, sd_bus_error *ret_error);

int sd_bus_request_name(sd_bus *bus, const char *name, uint64_t flags);

int sd_bus_request_name_async(sd_bus *bus, sd_bus_slot **slot, const char *name, uint64_t flags, sd_bus_message_handler_t callback, void *userdata);

int sd_bus_release_name(sd_bus *bus, const char *name);

int sd_bus_release_name_async(sd_bus *bus, sd_bus_slot **slot, const char *name, sd_bus_message_handler_t callback, void *userdata);

DESCRIPCIÓN

sd_bus_request_name() solicita un nombre de servicio conocido en un bus. Toma una conexión de bus, un nombre de bus válido y un parámetro de banderas. El parámetro de banderas es una combinación de cero o más de las siguientes banderas:

SD_BUS_NAME_ALLOW_REPLACEMENT

Después de adquirir el nombre con éxito, permitir a otros pares hacerse cargo del nombre cuando intenten adquirirlo con la bandera SD_BUS_NAME_REPLACE_EXISTING establecida. Si SD_BUS_NAME_ALLOW_REPLACEMENT no está establecida en la solicitud original, dicha solicitud por otros pares será denegada.

Añadido en la versión 209.

SD_BUS_NAME_REPLACE_EXISTING

Hacerse cargo del nombre si ya ha sido adquirido por otro par, y ese otro par ha permitido la sustitución estableciendo SD_BUS_NAME_ALLOW_REPLACEMENT mientras lo adquiría.

Añadido en la versión 209.

SD_BUS_NAME_QUEUE

Poner en cola la adquisición del nombre cuando el nombre ya está ocupado.

Añadido en la versión 209.

sd_bus_request_name() opera de forma síncrona: se envía un mensaje solicitando el nombre al intermediario del bus, y la llamada espera hasta que el intermediario responde.

sd_bus_request_name_async() es una versión asíncrona de sd_bus_request_name(). En lugar de esperar a que la solicitud se complete, el mensaje de solicitud se pone en cola. La función de callback especificada se llamará cuando se reciba la respuesta del intermediario. Si el parámetro se especifica como **NULL**, se utiliza una implementación predeterminada que terminará la conexión cuando el nombre no pueda ser adquirido. La función devuelve un objeto de ranura en su parámetro slot — si se pasa como no **NULL** — que puede usarse como referencia a la operación de solicitud de nombre. Use sd_bus_slot_unref(3) para destruir esta referencia. Tenga en cuenta que destruir la referencia no anulará el registro del nombre, sino que simplemente garantizará que la función de devolución de llamada especificada ya no se llame.

sd_bus_release_name() libera un nombre conocido adquirido. Toma una conexión de bus y un nombre de bus válido como parámetros. Esta función opera de forma síncrona, enviando un mensaje de solicitud de liberación al intermediario del bus y esperando a que responda.

sd_bus_release_name_async() es una versión asíncrona de sd_bus_release_name(). La función de callback especificada se llama cuando el nombre ha sido liberado con éxito. Si se especifica como **NULL**, se utiliza una implementación genérica que ignora el resultado de la operación. Como se mencionó anteriormente, el slot (si no es **NULL**) se establece en un objeto que puede usarse para referenciar la operación.

Estas funciones solo están disponibles en conexiones de bus, es decir, conexiones a un intermediario de bus y no en conexiones directas.

VALOR DE RETORNO

En caso de éxito, estas llamadas devuelven 0 o un entero positivo. En caso de error, estas llamadas devuelven un código de error negativo de estilo errno.

Si se especifica SD_BUS_NAME_QUEUE, sd_bus_request_name() devolverá 0 cuando el nombre ya esté ocupado por otro par y el cliente se haya añadido a la cola para el nombre. En ese caso, el llamador puede suscribirse a señales "NameOwnerChanged" para ser notificado cuando el nombre se adquiera con éxito. sd_bus_request_name() devuelve > 0 cuando el nombre se ha adquirido inmediatamente con éxito.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EALREADY

El llamador ya es el propietario del nombre especificado.

-EEXIST

El nombre ya ha sido adquirido por un par diferente, y SD_BUS_NAME_REPLACE_EXISTING no se especificó o el otro par no especificó SD_BUS_NAME_ALLOW_REPLACEMENT al adquirir el nombre.

-ESRCH

Se intentó liberar un nombre que actualmente no está registrado en el bus.

-EADDRINUSE

Se intentó liberar un nombre que es propiedad de un par diferente en el bus.

-EINVAL

Un parámetro especificado es inválido. Esto también se genera cuando el nombre solicitado es un nombre de servicio especial reservado por la especificación D-Bus, o cuando la operación se solicita en una conexión que no se refiere a un bus.

-ENOTCONN

La conexión del bus se ha desconectado.

-ECHILD

La conexión del bus se creó en un proceso diferente al actual.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_request_name() y sd_bus_release_name() se añadieron en la versión 209.

sd_bus_request_name_async() y sd_bus_release_name_async() se añadieron en la versión 237.
