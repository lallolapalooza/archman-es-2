sd_bus_message_read_strv(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_MESSAGE_READ_STRV(3) sd_bus_message_read_strv SD_BUS_MESSAGE_READ_STRV(3)

NOMBRE

sd_bus_message_read_strv, sd_bus_message_read_strv_extend - Acceder a un array de cadenas en un mensaje

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_message_read_strv(sd_bus_message *m, char ***l);

int sd_bus_message_read_strv_extend(sd_bus_message *m, char ***l);

DESCRIPCIÓN

sd_bus_message_read_strv() lee un array de elementos tipo cadena del mensaje m. El "puntero de lectura" en el mensaje debe estar justo antes de un array de cadenas (tipo D-Bus "as"), rutas de objeto (tipo D-Bus "ao") o firmas (tipo D-Bus "ag"). En caso de éxito, se devuelve un puntero a un array de cadenas terminado en NULL (strv) en el parámetro de salida l. Tenga en cuenta que la propiedad de este array se transfiere al llamador. Por lo tanto, el llamador es responsable de liberar este array y su contenido. Tenga en cuenta también que, por motivos de optimización, si se encuentra un array vacío, podría devolverse un puntero NULL aquí, y debe considerarse equivalente a un array con cero entradas.

sd_bus_message_read_strv_extend() es similar, pero el segundo parámetro es un parámetro de entrada-salida. Si *l es NULL, se comporta de forma idéntica a sd_bus_message_read_strv(). De lo contrario, *l debe apuntar a un strv, que se reasignará y extenderá con cadenas adicionales. Esta función es particularmente útil al combinar múltiples listas de cadenas en un mensaje o varios mensajes en un único array de cadenas.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven un entero no negativo. En caso de error, devuelven un código de error negativo al estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

m o l son NULL.

Añadido en la versión 246.

-EPERM

El mensaje no está sellado.

Añadido en la versión 246.

-EBADMSG

El mensaje no se puede analizar.

Añadido en la versión 246.

-ENXIO

El "puntero de lectura" del mensaje no está justo antes de un array del tipo apropiado.

Añadido en la versión 248.

HISTORIA

sd_bus_message_read_strv() se añadió en la versión 246.

sd_bus_message_read_strv_extend() se añadió en la versión 252.
