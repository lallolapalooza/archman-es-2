SD_JOURNAL_ENUMERATE_FIELDS(3) sd_journal_enumerate_fields SD_JOURNAL_ENUMERATE_FIELDS(3)

NOMBRE

sd_journal_enumerate_fields, sd_journal_restart_fields, SD_JOURNAL_FOREACH_FIELD - Leer nombres de campos usados del journal

SINOPSIS

#include <systemd/sd-journal.h>

int sd_journal_enumerate_fields(sd_journal *j, const char **field);

void sd_journal_restart_fields(sd_journal *j);

SD_JOURNAL_FOREACH_FIELD(sd_journal *j, const char *field);

DESCRIPCIÓN

sd_journal_enumerate_fields() puede usarse para iterar a través de todos los nombres de campos usados en los archivos del journal abiertos. En cada invocación se devuelve el siguiente nombre de campo. El orden de los nombres de campo devueltos no está definido. Toma dos argumentos: el objeto de contexto del journal, más un puntero a un puntero de cadena constante donde se almacena el nombre del campo. Los datos devueltos están en un mapa de memoria de solo lectura y solo son válidos hasta la próxima invocación de sd_journal_enumerate_fields(). Tenga en cuenta que esta llamada está sujeta al umbral del tamaño del campo de datos controlado por sd_journal_set_data_threshold().

sd_journal_restart_fields() reinicia el índice de enumeración de nombres de campo al principio de la lista. La próxima invocación de sd_journal_enumerate_fields() devolverá el primer nombre de campo de nuevo.

La macro SD_JOURNAL_FOREACH_FIELD() puede usarse como un práctico envoltorio alrededor de sd_journal_restart_fields() y sd_journal_enumerate_fields().

Estas funciones actualmente no están influenciadas por las coincidencias establecidas con sd_journal_add_match(), pero esto podría cambiar en una versión posterior de este software.

Para recuperar los posibles valores que un campo específico puede tomar, use sd_journal_query_unique(3).

VALOR DE RETORNO

sd_journal_enumerate_fields() devuelve un entero positivo si se ha leído el siguiente nombre de campo, 0 cuando ya no quedan nombres de campo conocidos, o un código de error negativo de estilo errno. sd_journal_restart_fields() no devuelve nada.

NOTAS

Todas las funciones descritas aquí son agnósticas a los hilos y solo un hilo puede operar sobre un objeto dado en un momento dado. Diferentes hilos pueden acceder al mismo objeto en diferentes momentos. Se pueden usar múltiples objetos independientes desde diferentes hilos en paralelo.

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

EJEMPLOS

Use la macro SD_JOURNAL_FOREACH_FIELD() para iterar a través de todos los nombres de campo en uso en el journal actual.

/* SPDX-License-Identifier: MIT-0 */
#include <errno.h>
#include <stdio.h>
#include <systemd/sd-journal.h>
int main(int argc, char *argv[]) {
  sd_journal *j;
  const char *field;
  int r;
  r = sd_journal_open(&j, SD_JOURNAL_LOCAL_ONLY);
  if (r < 0) {
    fprintf(stderr, "Failed to open journal: %s\n", strerror(-r));
    return 1;
  }
  SD_JOURNAL_FOREACH_FIELD(j, field)
    printf("%s\n", field);
  sd_journal_close(j);
  return 0;
}

HISTORIA

sd_journal_enumerate_fields(), sd_journal_restart_fields(), y SD_JOURNAL_FOREACH_FIELD() se añadieron en la versión 229.
