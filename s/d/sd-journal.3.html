NOMBRE

sd-journal - APIs para enviar y consultar entradas de registro hacia y desde el journal

SINOPSIS

#include <systemd/sd-journal.h>

pkg-config --cflags --libs libsystemd

DESCRIPCIÓN

sd-journal.h es parte de libsystemd(3) y proporciona APIs para enviar y consultar entradas de registro. Las APIs expuestas actúan tanto como cliente del servicio de journal systemd-journald.service(8) como analizador de los archivos del journal en disco.

Ver sd_journal_print(3), sd_journal_stream_fd(3), sd_journal_open(3), sd_journal_next(3), sd_journal_get_realtime_usec(3), sd_journal_add_match(3), sd_journal_seek_head(3), sd_journal_enumerate_fields(3), sd_journal_get_cursor(3), sd_journal_get_cutoff_realtime_usec(3), sd_journal_get_cutoff_monotonic_usec(3), sd_journal_get_usage(3), sd_journal_get_catalog(3), sd_journal_get_fd(3), sd_journal_has_runtime_files(3) y sd_journal_has_persistent_files(3) para más información sobre las funciones implementadas.

El acceso desde línea de comandos para enviar entradas al journal está disponible con la herramienta systemd-cat(1). El acceso desde línea de comandos para consultar entradas del journal está disponible con la herramienta journalctl(1).

SEGURIDAD DE HILOS

Las funciones que operan sobre objetos sd_journal son agnósticas a los hilos — un puntero sd_journal dado solo puede usarse desde un hilo a la vez, pero múltiples hilos independientes pueden usar múltiples objetos concurrentemente. Algunas funciones — aquellas que se utilizan para enviar entradas al journal, como sd_journal_print(3) y similares, o aquellas que se utilizan para recuperar información global como sd_journal_stream_fd(3) y sd_journal_get_catalog_for_message_id(3) — son completamente seguras para hilos y pueden ser llamadas desde múltiples hilos en paralelo.

DEPENDENCIAS OPCIONALES

Dependiendo de las opciones de compilación habilitadas, las funciones que operan sobre objetos sd_journal pueden causar que se carguen dinámicamente bibliotecas compartidas opcionales a través de dlopen(3), como bibliotecas de descompresión (xz, lz4, zstd) o bibliotecas criptográficas (gcrypt).

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, la cual puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para uso multitarea. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer las llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
