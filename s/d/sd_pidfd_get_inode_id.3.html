SD_PIDFD_GET_INODE_ID(3) sd_pidfd_get_inode_id SD_PIDFD_GET_INODE_ID(3)

NOMBRE

sd_pidfd_get_inode_id - Adquirir el ID de inodo de 64 bits de un descriptor de archivo PID (PIDFD)

SINOPSIS

#include <systemd/sd-daemon.h>

int sd_pidfd_get_inode_id(int pidfd, uint64_t *ret);

DESCRIPCIÓN

sd_pidfd_get_inode_id() puede ser invocado para adquirir el ID de inodo de 64 bits de un descriptor de archivo PID (PIDFD), el cual puede ser usado para identificar de forma fiable un proceso durante el arranque actual.

Como ejemplo típico, el gestor de servicios establece las variables de entorno $MAINPIDFDID y $MANAGERPIDFDID a los IDs de inodo del proceso principal del servicio y del propio gestor de servicios, respectivamente, si dicha funcionalidad es soportada por el kernel.

En arquitecturas de 64 bits, el ID de inodo puede ser obtenido directamente mediante una llamada a fstat(2) en un pidfd dado. Sin embargo, en arquitecturas de 32 bits, el campo .st_ino de struct stat también es de 32 bits, lo cual, similar a los PIDs, está sujeto a reutilización. Por lo tanto, se ha añadido un segundo mecanismo que aprovecha name_to_handle_at(2) al kernel en la versión 6.14. Esta utilidad se añade para simplificar el manejo posterior de los internos de pidfd/pidfs.

VALOR DE RETORNO

En caso de éxito, la función retorna 0 o un entero positivo. En caso de error, se retorna un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EOPNOTSUPP

El ID de inodo PIDFD estable no es soportado por el kernel en ejecución, o el sistema es de 32 bits y name_to_handle_at() no está disponible.

-EBADF

El descriptor de archivo especificado es inválido, o no es un PIDFD.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, la cual puede ser compilada y enlazada con el archivo pkg-config(1) de libsystemd.

HISTORIA

sd_pidfd_get_inode_id() fue añadida en la versión 258.
