SD_BUS_TRACK_ADD_NAME(3) sd_bus_track_add_name SD_BUS_TRACK_ADD_NAME(3)

NOMBRE

sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_remove_sender, sd_bus_track_count, sd_bus_track_count_sender, sd_bus_track_count_name, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next - Añadir, eliminar y recuperar pares de bus rastreados en un objeto de rastreo de pares de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(sd_bus_track* t, const char* name);

int sd_bus_track_add_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_remove_name(sd_bus_track* t, const char* name);

int sd_bus_track_remove_sender(sd_bus_track* t, sd_bus_message* message);

unsigned sd_bus_track_count(sd_bus_track* t);

int sd_bus_track_count_name(sd_bus_track* t, const char* name);

int sd_bus_track_count_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_contains(sd_bus_track* t, const char* name);

const char* sd_bus_track_first(sd_bus_track* t);

const char* sd_bus_track_next(sd_bus_track* t);

DESCRIPCIÓN

sd_bus_track_add_name() añade un par para rastrear a un objeto de rastreo de pares de bus. El primer argumento debe referirse a un objeto de rastreo de pares de bus creado con sd_bus_track_new(3), el segundo nombre debe referirse a un nombre de par de D-Bus para rastrear, ya sea en formato de servicio único o conocido. Si el nombre aún no se está rastreando, se agregará a la lista de nombres a rastrear. Si ya se está rastreando y el modo no recursivo está activado, no se ejecuta ninguna operación en esta llamada. Si el modo recursivo está activado, un contador por nombre se incrementa en uno cada vez que se invoca esta llamada, y sd_bus_track_remove_name() debe llamarse tantas veces como se invocó sd_bus_track_add_name() para dejar de rastrear el nombre. Utilice sd_bus_track_set_recursive(3) para cambiar del modo no recursivo predeterminado al modo recursivo, o viceversa. Tenga en cuenta que el nombre especificado se rastrea tal como está, los nombres conocidos no se resuelven a nombres únicos mediante esta llamada. Tenga en cuenta que varios objetos de rastreo de pares de bus pueden rastrear el mismo nombre.

sd_bus_track_remove_name() deshace el efecto de sd_bus_track_add_name() y elimina un nombre de par de bus de la lista de pares a observar. Dependiendo de si el modo no recursivo o recursivo está activado para el objeto de rastreo de pares de bus, esta llamada eliminará completamente el nombre del objeto de rastreo o simplemente disminuirá el contador por nombre en uno, eliminando el nombre solo cuando el contador llegue a cero (ver arriba). Tenga en cuenta que un par de bus que se desconecta del bus eliminará implícitamente sus nombres completamente del objeto de rastreo de pares de bus, independientemente del contador por nombre actual.

sd_bus_track_add_sender() y sd_bus_track_remove_sender() son similares a sd_bus_track_add_name() y sd_bus_track_remove_name() pero toman un mensaje de bus como argumento. Se determina el remitente de este mensaje de bus y se agrega/elimina del objeto de rastreo de pares de bus. Como los mensajes siempre se originan de nombres únicos y nunca de nombres conocidos, esto significa que esta llamada efectivamente solo agregará nombres únicos al objeto de rastreo de pares de bus.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente en el objeto de rastreo de pares de bus especificado. Tenga en cuenta que esta función siempre devuelve el número real de nombres rastreados y, por lo tanto, si se ha invocado sd_bus_track_add_name() varias veces para el mismo nombre, solo se cuenta como uno, independientemente de si se utiliza el modo recursivo o no.

sd_bus_track_count_name() devuelve el contador por nombre actual para el nombre especificado. Si se utiliza el modo no recursivo, devuelve 1 o 0, dependiendo de si el nombre especificado se ha agregado previamente al objeto de rastreo o no. Si se ha habilitado el modo recursivo, también pueden devolver valores mayores que 1, en caso de que sd_bus_track_add_name() se haya llamado varias veces para el mismo nombre.

sd_bus_track_count_sender() es similar a sd_bus_track_count_name(), pero toma un objeto de mensaje de bus y devuelve el contador por nombre que coincide con el remitente del mensaje.

sd_bus_track_contains() se puede usar para determinar si el nombre especificado se ha agregado al menos una vez al objeto de rastreo de pares de bus especificado.

sd_bus_track_first() y sd_bus_track_next() se pueden usar para enumerar todos los nombres que se están rastreando actualmente en el objeto de rastreo de pares de bus pasado. sd_bus_track_first() devuelve la primera entrada en el objeto y restablece un índice de lectura mantenido internamente. Cada invocación posterior de sd_bus_track_next() devuelve el siguiente nombre contenido en el objeto de bus. Si se llega al final, se devuelve NULL. Si aún no se han agregado nombres al objeto, sd_bus_track_first() devolverá NULL inmediatamente. El orden en que se devuelven los nombres no está definido; en particular, qué nombre se considera el primero devuelto no está definido. Si el modo recursivo está activado y el mismo nombre se ha agregado varias veces al objeto de rastreo de pares de bus, solo se devuelve una vez en esta enumeración. Si se agregan nuevos nombres o se eliminan nombres existentes del objeto de rastreo de pares de bus mientras se está enumerando, la enumeración termina en la próxima invocación de sd_bus_track_next() ya que se devuelve NULL.

VALOR DE RETORNO

En caso de éxito, sd_bus_track_add_name() y sd_bus_track_add_sender() devuelven 0 si el nombre especificado ya se había agregado previamente al objeto de rastreo de pares de bus y un valor positivo si no lo ha hecho. En caso de fallo, devuelven un código de error negativo estilo errno.

sd_bus_track_remove_name() y sd_bus_track_remove_sender() devuelven un valor positivo si el nombre especificado fue rastreado previamente por el objeto de rastreo de pares de bus y ahora ha sido eliminado. En modo no recursivo, se devuelve 0 si el nombre especificado aún no se estaba rastreando. En modo recursivo, se devuelve -EUNATCH en este caso. En caso de fallo, devuelven un código de error negativo estilo errno.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente, o 0 en caso de fallo.

sd_bus_track_count_name() y sd_bus_track_count_sender() devuelven el contador por nombre actual para el nombre especificado o el remitente del mensaje especificado. Se devuelve cero para los nombres que aún no se están rastreando, un valor positivo para los nombres agregados al menos una vez. Los valores mayores que 1 solo se devuelven en modo recursivo. En caso de fallo, se devuelve un código de error negativo estilo errno.

sd_bus_track_contains() devuelve el nombre pasado si existe en el objeto de rastreo de pares de bus. En caso de fallo, y si el nombre aún no se ha agregado, se devuelve NULL.

sd_bus_track_first() y sd_bus_track_next() devuelven el primer/siguiente nombre contenido en el objeto de rastreo de pares de bus, y NULL si se alcanza el final de la enumeración y en caso de error.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EUNATCH

sd_bus_track_remove_name() o sd_bus_track_remove_sender() se han invocado para un nombre no agregado previamente al objeto de par de bus.

-EINVAL

El parámetro especificado es inválido.

-ENOMEM

Fallo en la asignación de memoria.

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(struct sd_bus_track *track, const char *name);

int sd_bus_track_add_sender(struct sd_bus_track *track, uint64_t sender_id);

int sd_bus_track_remove_name(struct sd_bus_track *track, const char *name);

int sd_bus_track_remove_sender(struct sd_bus_track *track, uint64_t sender_id);

size_t sd_bus_track_count(struct sd_bus_track *track);

size_t sd_bus_track_count_name(struct sd_bus_track *track, const char *name);

size_t sd_bus_track_count_sender(struct sd_bus_track *track, uint64_t sender_id);

int sd_bus_track_contains(struct sd_bus_track *track, sd_bus_message *message);

sd_bus_message * sd_bus_track_first(struct sd_bus_track *track);

sd_bus_message * sd_bus_track_next(struct sd_bus_track *track);

DESCRIPCIÓN

Un objeto sd_bus_track es una colección de mensajes del bus, ya sea por nombre de servicio o por ID de remitente. Este mecanismo se utiliza para realizar un seguimiento de los mensajes que se envían o reciben en una conexión de bus. Puede ser útil para depurar la comunicación del bus o para implementar mecanismos de gestión de concurrencia en el bus.

Las funciones sd_bus_track_add_name() y sd_bus_track_add_sender() añaden un nombre de servicio o un ID de remitente al objeto track, respectivamente. Cuando se añaden, todos los mensajes futuros que provengan de ese remitente o que se envíen a ese servicio serán registrados por el objeto track.

Las funciones sd_bus_track_remove_name() y sd_bus_track_remove_sender() eliminan un nombre de servicio o un ID de remitente del objeto track. A partir de entonces, los mensajes relacionados con ese nombre/ID ya no serán registrados.

La función sd_bus_track_count() devuelve el número total de mensajes registrados actualmente por el objeto track. Las funciones sd_bus_track_count_name() y sd_bus_track_count_sender() devuelven el número de mensajes registrados de un servicio específico o de un remitente específico, respectivamente.

La función sd_bus_track_contains() comprueba si un mensaje específico está registrado actualmente por el objeto track. Devuelve verdadero si el mensaje está registrado, falso en caso contrario.

Las funciones sd_bus_track_first() y sd_bus_track_next() se utilizan para iterar sobre los mensajes registrados en el objeto track. sd_bus_track_first() devuelve el primer mensaje registrado, y sd_bus_track_next() devuelve el siguiente mensaje. Estas funciones devuelven NULL cuando no hay más mensajes para iterar.

El objeto sd_bus_track debe ser creado con sd_bus_track_new() y liberado con sd_bus_track_destroy().

VALOR DE RETORNO

sd_bus_track_add_name(), sd_bus_track_add_sender(), sd_bus_track_remove_name(), sd_bus_track_remove_sender(), sd_bus_track_contains() devuelven 0 con éxito o un número negativo en caso de error. sd_bus_track_contains() devuelve 1 si el mensaje está contenido.

sd_bus_track_count(), sd_bus_track_count_name(), sd_bus_track_count_sender() devuelven el número de mensajes registrados.

sd_bus_track_first() y sd_bus_track_next() devuelven un puntero a un mensaje o NULL si no hay más mensajes.

NOTAS

El objeto sd_bus_track mantiene punteros a los mensajes registrados. No toma la propiedad de ellos, y los mensajes seguidos deben ser liberados por el código de la aplicación cuando ya no sean necesarios. Si el bus se cierra, todos los mensajes pendientes en el track se pierden.

Los mensajes que se envían a través de un bus de comunicación bidireccional pueden ser registrados por más de un seguimiento si se añaden tanto el nombre del servicio de destino como el ID del remitente del bus en el seguimiento.

Es importante tener en cuenta que el seguimiento de mensajes puede tener implicaciones en el rendimiento, especialmente en buses con mucho tráfico. Utilice esta característica con prudencia.

Esta funcionalidad sólo está disponible en el bus del sistema principal o en buses de sesión que se hayan creado con la opción SD_BUS_KEEP_UNREFERENCED. Por ejemplo, si se utiliza para depurar el bus del sistema, sólo funcionará si el objeto sd_bus_track se crea antes de que el bus del sistema se inicialice completamente.
