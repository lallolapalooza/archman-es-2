SD_BUS_TRACK_ADD_NAME(3) sd_bus_track_add_name SD_BUS_TRACK_ADD_NAME(3)

NOMBRE

sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_remove_sender, sd_bus_track_count, sd_bus_track_count_sender, sd_bus_track_count_name, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next - Añadir, eliminar y recuperar pares de bus rastreados en un objeto de rastreo de pares de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(sd_bus_track* t, const char* name);

int sd_bus_track_add_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_remove_name(sd_bus_track* t, const char* name);

int sd_bus_track_remove_sender(sd_bus_track* t, sd_bus_message* message);

unsigned sd_bus_track_count(sd_bus_track* t);

int sd_bus_track_count_name(sd_bus_track* t, const char* name);

int sd_bus_track_count_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_contains(sd_bus_track* t, const char* name);

const char* sd_bus_track_first(sd_bus_track* t);

const char* sd_bus_track_next(sd_bus_track* t);

DESCRIPCIÓN

sd_bus_track_add_name() añade un par a rastrear a un objeto de rastreo de pares de bus. El primer argumento debe referirse a un objeto de rastreo de pares de bus creado con sd_bus_track_new(3), el segundo nombre debe referirse a un nombre de par D-Bus a rastrear, ya sea en formato de servicio único o conocido. Si el nombre aún no está siendo rastreado, se añadirá a la lista de nombres a rastrear. Si ya está siendo rastreado y el modo no recursivo está habilitado, esta llamada no ejecutará ninguna operación. Si el modo recursivo está habilitado, un contador por nombre se incrementará en uno cada vez que se invoque esta llamada, y sd_bus_track_remove_name() debe ser llamada tantas veces como se invocó sd_bus_track_add_name() para detener el rastreo del nombre. Utilice sd_bus_track_set_recursive(3) para cambiar del modo no recursivo por defecto al modo recursivo, o viceversa. Tenga en cuenta que el nombre especificado se rastrea tal cual, los nombres conocidos no se resuelven a nombres únicos mediante esta llamada. Tenga en cuenta que varios objetos de rastreo de pares de bus pueden rastrear el mismo nombre.

sd_bus_track_remove_name() deshace el efecto de sd_bus_track_add_name() y elimina un nombre de par de bus de la lista de pares a observar. Dependiendo de si el modo no recursivo o recursivo está habilitado para el objeto de rastreo de pares de bus, esta llamada eliminará completamente el nombre del objeto de rastreo, o simplemente decrementará el contador por nombre en uno, eliminando el nombre solo cuando el contador alcance cero (ver arriba). Tenga en cuenta que un par de bus que se desconecta del bus eliminará implícitamente sus nombres completamente del objeto de rastreo de pares de bus, independientemente del contador por nombre actual.

sd_bus_track_add_sender() y sd_bus_track_remove_sender() son similares a sd_bus_track_add_name() y sd_bus_track_remove_name() pero toman un mensaje de bus como argumento. Se determina el remitente de este mensaje de bus y se añade/elimina del objeto de rastreo de pares de bus. Como los mensajes siempre se originan de nombres únicos y nunca de nombres conocidos, esto significa que esta llamada efectivamente solo añadirá nombres únicos al objeto de rastreo de pares de bus.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente en el objeto de rastreo de pares de bus especificado. Tenga en cuenta que esta función siempre devuelve el número real de nombres rastreados y, por lo tanto, si se ha invocado sd_bus_track_add_name() varias veces para el mismo nombre, solo se contará como uno, independientemente de si se utiliza el modo recursivo o no.

sd_bus_track_count_name() devuelve el contador por nombre actual para el nombre especificado. Si se utiliza el modo no recursivo, devuelve 1 o 0, dependiendo de si el nombre especificado se ha añadido previamente al objeto de rastreo o no. Si se ha habilitado el modo recursivo, también pueden devolverse valores mayores que 1, en caso de que sd_bus_track_add_name() se haya llamado varias veces para el mismo nombre.

sd_bus_track_count_sender() es similar a sd_bus_track_count_name(), pero toma un objeto de mensaje de bus y devuelve el contador por nombre que coincide con el remitente del mensaje.

sd_bus_track_contains() se puede utilizar para determinar si el nombre especificado se ha añadido al menos una vez al objeto de rastreo de pares de bus especificado.

sd_bus_track_first() y sd_bus_track_next() se pueden utilizar para enumerar todos los nombres que se están rastreando actualmente en el objeto de rastreo de pares de bus pasado. sd_bus_track_first() devuelve la primera entrada en el objeto y restablece un índice de lectura mantenido internamente. Cada invocación subsiguiente de sd_bus_track_next() devuelve el siguiente nombre contenido en el objeto de bus. Si se alcanza el final, se devuelve NULL. Si aún no se han añadido nombres al objeto, sd_bus_track_first() devolverá NULL inmediatamente. El orden en que se devuelven los nombres no está definido; en particular, no está definido qué nombre se considera el primero devuelto. Si el modo recursivo está habilitado y el mismo nombre se ha añadido varias veces al objeto de rastreo de pares de bus, solo se devuelve una vez en esta enumeración. Si se añaden nuevos nombres o se eliminan nombres existentes del objeto de rastreo de pares de bus mientras se enumera, la enumeración termina en la siguiente invocación de sd_bus_track_next(), ya que se devuelve NULL.

VALOR DE RETORNO

En caso de éxito, sd_bus_track_add_name() y sd_bus_track_add_sender() devuelven 0 si el nombre especificado ya se había añadido previamente al objeto de rastreo de pares de bus y un valor positivo si no. En caso de error, devuelven un código de error negativo de estilo errno.

sd_bus_track_remove_name() y sd_bus_track_remove_sender() devuelven un valor positivo si el nombre especificado estaba previamente rastreado por el objeto de rastreo de pares de bus y ahora ha sido eliminado. En modo no recursivo, se devuelve 0 si el nombre especificado aún no estaba siendo rastreado. En modo recursivo, se devuelve -EUNATCH en este caso. En caso de error, devuelven un código de error negativo de estilo errno.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente, o 0 en caso de error.

sd_bus_track_count_name() y sd_bus_track_count_sender() devuelven el contador por nombre actual para el nombre especificado o el remitente del mensaje especificado. Se devuelve cero para los nombres que aún no se están rastreando, un valor positivo para los nombres añadidos al menos una vez. Los valores mayores que 1 solo se devuelven en modo recursivo. En caso de error, se devuelve un código de error negativo de estilo errno.

sd_bus_track_contains() devuelve el nombre pasado si existe en el objeto de rastreo de pares de bus. En caso de error, y si el nombre no se ha añadido aún, se devuelve NULL.

sd_bus_track_first() y sd_bus_track_next() devuelven el primer/siguiente nombre contenido en el objeto de rastreo de pares de bus, y NULL si se alcanza el final de la enumeración y en caso de error.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EUNATCH

sd_bus_track_remove_name() o sd_bus_track_remove_sender() se han invocado para un nombre no añadido previamente al objeto de par de bus.

-EINVAL

El parámetro especificado es inválido.

-ENOMEM

Error en la asignación de memoria.

sd_bus_track_contains(3)

NAME

sd_bus_track_contains – check if a bus track contains a specific name or sender

SYNOPSIS

#include <systemd/sd-bus.h>
int sd_bus_track_contains(sd_bus_track *track, const char *name);
int sd_bus_track_contains_name(sd_bus_track *track, const char *name);
int sd_bus_track_contains_sender(sd_bus_track *track, const char *sender);

DESCRIPTION

The sd_bus_track_contains(), sd_bus_track_contains_name(), and sd_bus_track_contains_sender() functions check if the given track object contains a specific bus name or sender. The name parameter should be a well-formed bus name. The sender parameter should be a well-formed sender name (e.g. a service name).

If track is NULL, these functions will return 0.

These functions are equivalent to sd_bus_track_contains_name().

RETURN VALUE

On success, these functions return a non-zero value if the name or sender is found in the track, and 0 otherwise.

On failure, they return a negative error number.

NOTES

These functions may be called at any time, but the track object is only meaningful after sd_bus_track_new(3) has been called and before sd_bus_track_unref(3) is called. Specifically, they are useful to check if a message sender is in the track, possibly for security reasons, or to check if a specific service name is currently tracked. This is most useful when the track object is created early in the program's phase when no other threads have been started.
