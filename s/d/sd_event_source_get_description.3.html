sd_event_source_get_description(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_EVENT_SOURCE_SET_DESCRIPTION(3) sd_event_source_set_description SD_EVENT_SOURCE_SET_DESCRIPTION(3)

NOMBRE

sd_event_source_set_description, sd_event_source_get_description - Establecer o recuperar nombres descriptivos de las fuentes de eventos

SINOPSIS

#include <systemd/sd-event.h>

int sd_event_source_set_description(sd_event_source *source, const char *description);

int sd_event_source_get_description(sd_event_source *source, const char **ret);

DESCRIPCIÓN

sd_event_source_set_description() se puede utilizar para establecer un nombre descriptivo arbitrario para el objeto de fuente de evento especificado como source. Este nombre se utilizará en mensajes de depuración generados por sd-event(3) para esta fuente de evento, y puede ser consultado usando sd_event_source_get_description() con fines de depuración. El parámetro description debe apuntar a una cadena terminada en NUL o ser NULL. En este último caso, se eliminará el nombre descriptivo. La cadena se copia internamente, por lo tanto, el argumento description no se referencia después de que la función retorna.

sd_event_source_get_description() se puede utilizar para consultar el nombre descriptivo actual asignado al objeto de fuente de evento source. Devuelve un puntero al nombre actual en ret, almacenado en memoria interna de la fuente de evento. La memoria se invalida cuando la fuente de evento se destruye o se cambia el nombre descriptivo.

Los objetos de fuente de evento generalmente no tienen una descripción establecida cuando se crean, excepto las fuentes de eventos de señales UNIX creadas con sd_event_add_signal(3), cuyo nombre descriptivo se inicializa con el nombre de la constante C de la señal (por ejemplo, "SIGINT" o "SIGTERM").

VALOR DE RETORNO

En caso de éxito, sd_event_source_set_description() y sd_event_source_get_description() devuelven un entero no negativo. En caso de error, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

source no es un puntero válido a un objeto sd_event_source o el argumento description para sd_event_source_get_description() es NULL.

-ENOMEM

No hay suficiente memoria para copiar el nombre.

-ECHILD

El bucle de eventos se ha creado en un proceso, biblioteca o instancia de módulo diferente.

-ENXIO

No se estableció ningún nombre para la fuente de evento.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y vincular con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_event_source_set_description() y sd_event_source_get_description() se agregaron en la versión 229.
