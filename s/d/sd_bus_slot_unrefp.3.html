sd_bus_slot_unrefp(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_SLOT_REF(3) sd_bus_slot_ref SD_BUS_SLOT_REF(3)

NOMBRE

sd_bus_slot_ref, sd_bus_slot_unref, sd_bus_slot_unrefp - Crear y destruir referencias a un objeto de ranura de bus

SINOPSIS

#include <systemd/sd-bus.h>

sd_bus_slot *sd_bus_slot_ref(sd_bus_slot *slot);

sd_bus_slot *sd_bus_slot_unref(sd_bus_slot *slot);

void sd_bus_slot_unrefp(sd_bus_slot **slotp);

DESCRIPCIÓN

sd_bus_slot_ref() incrementa el contador de referencias interno de slot en uno.

sd_bus_slot_unref() decrementa el contador de referencias interno de slot en uno. Una vez que el contador de referencias ha caído a cero, el objeto de ranura se destruye y no puede usarse más, por lo que las llamadas posteriores a sd_bus_slot_ref() o sd_bus_slot_unref() son ilegales.

sd_bus_slot_unrefp() es similar a sd_bus_slot_unref() pero toma un puntero a un puntero a un objeto sd_bus_slot. Esta llamada es útil en conjunción con el **Atributo de Variable de Limpieza**[1] de GCC y LLVM. Consulte sd_bus_new(3) para un ejemplo de cómo usar el atributo de limpieza.

sd_bus_slot_ref() y sd_bus_slot_unref() no realizan ninguna operación si la dirección del objeto de bus pasada es NULL. sd_bus_slot_unrefp() primero desreferenciará su argumento, que no debe ser NULL, y no realizará ninguna operación si *eso* es NULL.

VALOR DE RETORNO

sd_bus_slot_ref() siempre devuelve el argumento.

sd_bus_slot_unref() siempre devuelve NULL.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_slot_ref(), sd_bus_slot_unref() y sd_bus_slot_unrefp() se añadieron en la versión 240.
