sd_journal_step_one(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_JOURNAL_NEXT(3) sd_journal_next SD_JOURNAL_NEXT(3)

NOMBRE

sd_journal_next, sd_journal_previous, sd_journal_step_one, sd_journal_next_skip, sd_journal_previous_skip, SD_JOURNAL_FOREACH, SD_JOURNAL_FOREACH_BACKWARDS - Avanzar o retroceder el puntero de lectura en el journal

SINOPSIS

#include <systemd/sd-journal.h>

int sd_journal_next(sd_journal *j);

int sd_journal_previous(sd_journal *j);

int sd_journal_step_one(sd_journal *j, int avanzado);

int sd_journal_next_skip(sd_journal *j, uint64_t saltar);

int sd_journal_previous_skip(sd_journal *j, uint64_t saltar);

SD_JOURNAL_FOREACH(sd_journal *j);

SD_JOURNAL_FOREACH_BACKWARDS(sd_journal *j);

DESCRIPCIÓN

sd_journal_next() avanza el puntero de lectura en el journal una entrada. El único argumento que toma es un objeto de contexto del journal asignado con sd_journal_open(3). Después de una invocación exitosa, la entrada puede leerse con funciones como sd_journal_get_data(3).

De manera similar, sd_journal_previous() retrocede el puntero de lectura una entrada.

sd_journal_step_one() también mueve el puntero de lectura. Si la ubicación actual es la cabeza del journal, p. ej., cuando se llama después de sd_journal_seek_head(), es equivalente a sd_journal_next() y el argumento avanzado se ignorará. De manera similar, si la ubicación actual es la cola del journal, p. ej., cuando se llama después de sd_journal_seek_tail(), es equivalente a sd_journal_previous() y avanzado se ignorará. De lo contrario, es equivalente a sd_journal_next() cuando avanzado es distinto de cero, y sd_journal_previous() cuando avanzado es cero.

sd_journal_next_skip() y sd_journal_previous_skip() avanzan/retroceden el puntero de lectura múltiples entradas a la vez, según lo especificado en el parámetro saltar. El parámetro saltar debe ser menor o igual a 2147483647 (2³¹-1).

El journal está estrictamente ordenado por tiempo de recepción y, por lo tanto, avanzar a la siguiente entrada garantiza que la entrada a la que apunta es posterior en el tiempo a la anterior, o tiene la misma marca de tiempo.

Tenga en cuenta que sd_journal_get_data(3) y llamadas relacionadas fallarán a menos que se haya invocado sd_journal_next() al menos una vez para posicionar el puntero de lectura en una entrada del journal.

Tenga en cuenta que la macro SD_JOURNAL_FOREACH() se puede usar como envoltorio alrededor de sd_journal_seek_head(3) y sd_journal_next() para facilitar la iteración a través del journal. Consulte a continuación un ejemplo. De manera similar, SD_JOURNAL_FOREACH_BACKWARDS() se puede usar para iterar el journal en orden inverso.

VALOR DE RETORNO

Las cuatro llamadas devuelven el número de entradas avanzadas/retrocedidas con éxito o un código de error negativo de estilo errno. Cuando se alcanza el final o el principio del journal, se devuelve un número menor que el solicitado. Más específicamente, si sd_journal_next() o sd_journal_previous() alcanzan el final/principio del journal, devolverán 0, en lugar de 1 cuando tengan éxito. Esto debe considerarse como un marcador de fin de archivo (EOF).

NOTAS

Todas las funciones aquí descritas son agnósticas a hilos y solo un hilo puede operar en un objeto dado en un momento dado. Diferentes hilos pueden acceder al mismo objeto en diferentes momentos. Se pueden utilizar múltiples objetos independientes desde diferentes hilos en paralelo.

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

EJEMPLOS

Iterando a través del journal:

/* SPDX-License-Identifier: MIT-0 */
#include <errno.h>
#include <stdio.h>
#include <systemd/sd-journal.h>
int main(int argc, char *argv[]) {
  int r;
  sd_journal *j;
  r = sd_journal_open(&j, SD_JOURNAL_LOCAL_ONLY);
  if (r < 0) {
    fprintf(stderr, "Falló al abrir el journal: %s\n", strerror(-r));
    return 1;
  }
  SD_JOURNAL_FOREACH(j) {
    const char *d;
    size_t l;
    r = sd_journal_get_data(j, "MESSAGE", (const void **)&d, &l);
    if (r < 0) {
      fprintf(stderr, "Falló al leer el campo MESSAGE: %s\n", strerror(-r));
      continue;
    }
    printf("%.*s\n", (int) l, d);
  }
  sd_journal_close(j);
  return 0;
}

HISTORIA

sd_journal_next(), sd_journal_previous(), sd_journal_next_skip(), sd_journal_previous_skip(), SD_JOURNAL_FOREACH() y SD_JOURNAL_FOREACH_BACKWARDS() se añadieron en la versión 187.

sd_journal_step_one() se añadió en la versión 254.
