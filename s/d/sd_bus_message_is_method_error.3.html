sd_bus_message_is_method_error(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_MESSAGE_GET_TYPE(3) sd_bus_message_get_type SD_BUS_MESSAGE_GET_TYPE(3)

NOMBRE

sd_bus_message_get_type, sd_bus_message_get_error, sd_bus_message_get_errno, sd_bus_message_get_creds, sd_bus_message_is_signal, sd_bus_message_is_method_call, sd_bus_message_is_method_error - Consultar metadatos de direccionamiento/credenciales del mensaje del bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_message_get_type(sd_bus_message *m, uint8_t *type);

sd_bus_error* sd_bus_message_get_error(sd_bus_message *m);

int sd_bus_message_get_errno(sd_bus_message *m);

sd_bus_creds* sd_bus_message_get_creds(sd_bus_message *m);

int sd_bus_message_is_signal(sd_bus_message *m, const char *interface, const char *member);

int sd_bus_message_is_method_call(sd_bus_message *m, const char *interface, const char *member);

int sd_bus_message_is_method_error(sd_bus_message *m, const char *name);

DESCRIPCIÓN

sd_bus_message_get_type() devuelve el tipo de un mensaje en el parámetro de salida type, uno de SD_BUS_MESSAGE_METHOD_CALL, SD_BUS_MESSAGE_METHOD_RETURN, SD_BUS_MESSAGE_METHOD_ERROR, SD_BUS_MESSAGE_SIGNAL. Este tipo se especifica como parámetro al crear el mensaje usando sd_bus_message_new(3), o se establece automáticamente al crear el mensaje usando sd_bus_message_new_signal(3), sd_bus_message_new_method_call(3), sd_bus_message_new_method_error(3) y funciones similares.

sd_bus_message_get_error() devuelve el error almacenado en el mensaje m, si hay alguno. De lo contrario, devuelve NULL. sd_bus_message_get_errno() devuelve el error almacenado en el mensaje m como un valor positivo de estilo errno, si hay alguno. De lo contrario, devuelve cero. Los errores se mapean a valores errno según los mapeos de error predeterminados y cualquier mapeo adicional registrado. Ver sd-bus-errors(3) y sd_bus_error_add_map(3).

sd_bus_message_get_creds() devuelve las credenciales del mensaje adjuntas al mensaje m. Si no hay credenciales adjuntas al mensaje, devuelve NULL. La propiedad de la instancia de credenciales no se transfiere al llamador y, por lo tanto, no debe liberarse.

sd_bus_message_is_signal() comprueba si el mensaje m es un mensaje de señal. Si interface no es nulo, también comprueba si el mensaje tiene la misma interfaz establecida. Si member no es nulo, también comprueba si el mensaje tiene el mismo miembro establecido. Ver también sd_bus_message_new_signal(3). Devuelve verdadero cuando todas las comprobaciones pasan.

sd_bus_message_is_method_call() comprueba si el mensaje m es un mensaje de llamada a método. Si interface no es nulo, también comprueba si el mensaje tiene la misma interfaz establecida. Si member no es nulo, también comprueba si el mensaje tiene el mismo miembro establecido. Ver también sd_bus_message_new_method_call(3). Devuelve verdadero cuando todas las comprobaciones pasan.

sd_bus_message_is_method_error() comprueba si el mensaje m es un mensaje de respuesta de error. Si name no es nulo, también comprueba si el mensaje tiene el mismo identificador de error establecido. Ver también sd_bus_message_new_method_error(3). Devuelve verdadero cuando todas las comprobaciones pasan.

VALOR DE RETORNO

En caso de éxito, estas funciones (excepto sd_bus_message_get_error() y sd_bus_message_get_creds()) devuelven un entero no negativo. En caso de fallo, devuelven un código de error negativo de estilo errno. sd_bus_message_get_errno() siempre devuelve un entero no negativo, incluso en caso de fallo.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El parámetro de mensaje m o un parámetro de salida es NULL.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_message_get_type(), sd_bus_message_is_signal(), sd_bus_message_is_method_call(), y sd_bus_message_is_method_error() se añadieron en la versión 240.

sd_bus_message_get_error(), sd_bus_message_get_errno(), y sd_bus_message_get_creds() se añadieron en la versión 246.
