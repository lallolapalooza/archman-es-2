SDRVSG

Propósito:

!>
!>      SDRVSG comprueba los controladores del problema de eigenvalor generalizado
!>      simétrico real.
!>
!>              SSYGV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de un problema de eigenvalor generalizado
!>              simétrico-definido real.
!>
!>              SSYGVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de un problema de eigenvalor generalizado
!>              simétrico-definido real utilizando un algoritmo de divide y vencerás.
!>
!>              SSYGVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de un problema de eigenvalor generalizado
!>              simétrico-definido real.
!>
!>              SSPGV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de un problema de eigenvalor generalizado
!>              simétrico-definido real en almacenamiento empaquetado.
!>
!>              SSPGVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de un problema de eigenvalor generalizado
!>              simétrico-definido real en almacenamiento empaquetado
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              SSPGVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de un problema de eigenvalor generalizado
!>              simétrico-definido real en almacenamiento empaquetado.
!>
!>              SSBGV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de un problema de eigenvalor generalizado
!>              simétrico-definido de banda real.
!>
!>              SSBGVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de un problema de eigenvalor generalizado
!>              simétrico-definido de banda real utilizando un algoritmo de divide y
!>              vencerás.
!>
!>              SSBGVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de un problema de eigenvalor generalizado
!>              simétrico-definido de banda real.
!>
!>      Cuando se llama a SDRVSG, se especifica un número de tamaños de matriz () y
!>      un número de tipos de matriz. Para cada tamaño () y cada tipo de matriz, se
!>      generará una matriz A del tipo dado; también se genera una matriz B aleatoria
!>      bien condicionada y el par (A,B) se utiliza para probar los controladores.
!>
!>      Para cada par (A,B), se realizan las siguientes pruebas:
!>
!>      (1) SSYGV con ITYPE = 1 y UPLO ='U':
!>
!>              | A Z - B Z D | / ( |A| |Z| n ulp )
!>
!>      (2) igual que (1) pero llamando a SSPGV
!>      (3) igual que (1) pero llamando a SSBGV
!>      (4) igual que (1) pero con UPLO = 'L'
!>      (5) igual que (4) pero llamando a SSPGV
!>      (6) igual que (4) pero llamando a SSBGV
!>
!>      (7) SSYGV con ITYPE = 2 y UPLO ='U':
!>
!>              | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (8) igual que (7) pero llamando a SSPGV
!>      (9) igual que (7) pero con UPLO = 'L'
!>      (10) igual que (9) pero llamando a SSPGV
!>
!>      (11) SSYGV con ITYPE = 3 y UPLO ='U':
!>
!>              | B A Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (12) igual que (11) pero llamando a SSPGV
!>      (13) igual que (11) pero con UPLO = 'L'
!>      (14) igual que (13) pero llamando a SSPGV
!>
!>      SSYGVD, SSPGVD y SSBGVD realizaron las mismas 14 pruebas.
!>
!>      SSYGVX, SSPGVX y SSBGVX realizaron las 14 pruebas anteriores con
!>      el parámetro RANGE = 'A', 'N' e 'I', respectivamente.
!>
!>      Los tamaños () se especifican mediante un array NN(1:NSIZES); el valor
!>      de cada elemento NN(j) especifica un tamaño.
!>      Los tipos de matriz se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!>      Este tipo se utiliza para la matriz A que tiene un semi-ancho de banda KA.
!>      B se genera como una matriz definida positiva bien condicionada
!>      con semi-ancho de banda KB (<= KA).
!>      Actualmente, la lista de tipos posibles para A es:
!>
!>      (1) La matriz cero.
!>      (2) La matriz identidad.
!>
!>      (3) Una matriz diagonal con entradas espaciadas uniformemente
!>          1, ..., ULP y signos aleatorios.
!>          (ULP = (primer número mayor que 1) - 1 )
!>      (4) Una matriz diagonal con entradas espaciadas geométricamente
!>          1, ..., ULP y signos aleatorios.
!>      (5) Una matriz diagonal con entradas
!>          1, ULP, ..., ULP y signos aleatorios.
!>
!>      (6) Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7) Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8) Una matriz de la forma U* D U, donde U es ortogonal y
!>          D tiene entradas espaciadas uniformemente 1, ..., ULP con signos
!>          aleatorios en la diagonal.
!>
!>      (9) Una matriz de la forma U* D U, donde U es ortogonal y
!>          D tiene entradas espaciadas geométricamente 1, ..., ULP con signos
!>          aleatorios en la diagonal.
!>
!>      (10) Una matriz de la forma U* D U, donde U es ortogonal y
!>          D tiene entradas
!>          1, ULP,..., ULP con signos aleatorios
!>          en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (16) Igual que (8), pero con KA = 1 y KB = 1
!>      (17) Igual que (8), pero con KA = 2 y KB = 1
!>      (18) Igual que (8), pero con KA = 2 y KB = 2
!>      (19) Igual que (8), pero con KA = 3 y KB = 1
!>      (20) Igual que (8), pero con KA = 3 y KB = 2
!>      (21) Igual que (8), pero con KA = 3 y KB = 3
!> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          SDRVSG no hace nada. Debe ser al menos cero.
!>          No modificado.
!>
!>  NN      Array INTEGER, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Se omitirán los valores cero. Los valores deben ser al menos
!>          cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SDRVSG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar cualquier matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>          No modificado.
!>
!>  DOTYPE  Array LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN una
!>          matriz de ese tamaño y de tipo j se generará.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1:NTYPES) se ignora.
!>          No modificado.
!>
!>  ISEED   INTEGER array, dimension (4)
!>          Utilizado para inicializar el generador de números aleatorios.
!>          Modificado por RANDU.
!>
!>  THRESH  REAL
!>          Umbral para la prueba de residuos.  Un valor típico es
!>          diez veces el valor de epsilon para la máquina que se está
!>          utilizando.  Por ejemplo, si epsilon es 2**(-20), se podría
!>          utilizar THRESH = 2**(-16).
!>          No modificado.
!>
!>  NOUNIT  INTEGER
!>          Si NOUNIT = .TRUE., entonces las matrices unitarias U, V y Z
!>          no son generadas.
!>          No modificado.
!>
!>  A       (REAL*4) dimension (LDA,*)
!>          Matriz de entrada, de dimensión (N, N).
!>
!>  LDA     INTEGER
!>          Longitud de la línea de A. LDA >= max(1, N).
!>
!>  B       (REAL*4) dimension (LDB,*)
!>          Matriz de entrada, de dimensión (N, N).
!>
!>  LDB     INTEGER
!>          Longitud de la línea de B. LDB >= max(1, N).
!>
!>  D       (REAL*4) dimension (*)
!>          Vector de valores propios.
!>
!>  Z       (REAL*4) dimension (LDZ,*)
!>          Matriz de vectores propios.
!>
!>  LDZ     INTEGER
!>          Longitud de la línea de Z. LDZ >= max(1, N).
!>
!>  AB      (REAL*4) dimension (LDA,*)
!>          Matriz de entrada, de dimensión (N, N).
!>
!>  BB      (REAL*4) dimension (LDB,*)
!>          Matriz de entrada, de dimensión (N, N).
!>
!>  AP      (REAL*4) dimension (*)
!>          Matriz de entrada empaquetada.
!>
!>  BP      (REAL*4) dimension (*)
!>          Matriz de entrada empaquetada.
!>
!>  WORK    (REAL*4) dimension (NWORK)
!>          Array de trabajo.
!>
!>  NWORK   INTEGER
!>          Número de elementos en WORK.
!>
!>  IWORK   (INTEGER) dimension (LIWORK)
!>          Array de trabajo para enteros.
!>
!>  LIWORK  INTEGER
!>          Número de elementos en IWORK.
!>
!>  RESULT  (REAL*4) dimension (*)
!>          Array de resultados.
!>
!>  INFO    INTEGER
!>          = 0:  correcta ejecución
!>          < 0:  el i-ésimo argumento hacia atrás tenía un valor ilegal.
!>                Como consecuencia, la ejecución del programa
!>                ha sido abortada.
!>          > 0:  Fallo en la convergencia de algún valor propio,
!>                en la posición INFO se encuentra el número de valor propio
!>                que no ha convergido.
!>
!>
