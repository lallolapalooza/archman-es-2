sd_bus_message_get_interface(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_MESSAGE_SET_DESTINATION(3) sd_bus_message_set_destination SD_BUS_MESSAGE_SET_DESTINATION(3)

NOMBRE

sd_bus_message_set_destination, sd_bus_message_get_destination, sd_bus_message_get_path, sd_bus_message_get_interface, sd_bus_message_get_member, sd_bus_message_set_sender, sd_bus_message_get_sender - Establecer y consultar la información de direccionamiento de mensajes del bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_message_set_destination(sd_bus_message *message, const char *destination);

const char* sd_bus_message_get_destination(sd_bus_message *message);

const char* sd_bus_message_get_path(sd_bus_message *message);

const char* sd_bus_message_get_interface(sd_bus_message *message);

const char* sd_bus_message_get_member(sd_bus_message *message);

int sd_bus_message_set_sender(sd_bus_message *message, const char *sender);

const char* sd_bus_message_get_sender(sd_bus_message *message);

DESCRIPCIÓN

sd_bus_message_set_destination() establece el nombre del servicio de destino para el objeto de mensaje de bus especificado. El nombre especificado debe ser un nombre de servicio único o bien conocido válido.

sd_bus_message_get_destination(), sd_bus_message_get_path(), sd_bus_message_get_interface(), y sd_bus_message_get_member() devuelven los campos de destino, ruta, interfaz y miembro de la cabecera de message. El valor de retorno será NULL si message es NULL o si el mensaje es de un tipo que no utiliza esos campos o si el mensaje no los tiene establecidos. Consulte sd_bus_message_new_method_call(3) y sd_bus_message_set_destination(3) para obtener más información sobre esos valores.

sd_bus_message_set_sender() establece el nombre del servicio emisor para el objeto de mensaje de bus especificado. El nombre especificado debe ser un nombre de servicio único o bien conocido válido. Esta función solo es útil para mensajes que se envían en conexiones directas, ya que para las conexiones a intermediarios de bus, el intermediario rellenará el campo de destino de todos modos, y el campo emisor establecido por el emisor original se ignora.

sd_bus_message_get_sender() devuelve el campo emisor de message.

Cuando se devuelve una cadena, es un puntero a almacenamiento interno y no puede modificarse ni liberarse. Solo es válido mientras el message permanezca referenciado y este campo no haya sido modificado por una llamada diferente.

VALOR DE RETORNO

En caso de éxito, estas llamadas devuelven 0 o un entero positivo. En caso de error, estas llamadas devuelven un código de error negativo de tipo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El parámetro message o el parámetro de salida son NULL.

-EPERM

Para sd_bus_message_set_destination() y sd_bus_message_set_sender(), el mensaje ya está sellado.

-EEXIST

El mensaje ya tiene un campo de destino o emisor establecido.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para multihilo. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_message_set_destination() y sd_bus_message_set_sender() se añadieron en la versión 237.

sd_bus_message_get_destination(), sd_bus_message_get_path(), sd_bus_message_get_interface(), sd_bus_message_get_member(), y sd_bus_message_get_sender() se añadieron en la versión 240.
