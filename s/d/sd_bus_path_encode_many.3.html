SD_BUS_PATH_ENCODE(3) sd_bus_path_encode SD_BUS_PATH_ENCODE(3)

NOMBRE

sd_bus_path_encode, sd_bus_path_encode_many, sd_bus_path_decode, sd_bus_path_decode_many - Convertir un identificador externo en una ruta de objeto y viceversa

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_path_encode(const char *prefix, const char *external_id, char **ret_path);

int sd_bus_path_encode_many(char **out, const char *path_template, ...);

int sd_bus_path_decode(const char *path, const char *prefix, char **ret_external_id);

int sd_bus_path_decode_many(const char *path, const char *path_template, ...);

DESCRIPCIÓN

sd_bus_path_encode() y sd_bus_path_decode() convierten cadenas de identificadores externos en rutas de objeto y viceversa. Estas funciones son útiles para mapear identificadores de cadena específicos de la aplicación de cualquier tipo a rutas de objeto del bus de una manera simple, reversible y segura.

sd_bus_path_encode() toma un prefijo de ruta del bus y un identificador externo como argumentos, además de un lugar para almacenar la cadena de ruta del bus devuelta. El prefijo de la ruta del bus debe ser una ruta de bus válida, que comience con una barra "/" y no termine con una. El identificador externo puede tener cualquier formato, puede ser una cadena vacía y no tiene restricciones en el conjunto de caracteres, sin embargo, siempre debe estar terminado en NUL. La cadena devuelta será la concatenación del prefijo de la ruta del bus más una versión codificada del identificador externo. Esta operación se puede revertir con sd_bus_path_decode(). Se recomienda utilizar solo identificadores externos que generalmente requieran poca codificación para convertirse en identificadores de ruta de bus válidos (por ejemplo, utilizando un conjunto de caracteres ASCII de 7 bits), para garantizar que la ruta de bus resultante siga siendo corta y fácil de procesar.

sd_bus_path_decode() revierte la operación de sd_bus_path_encode() y, por lo tanto, regenera una cadena de identificador externo a partir de una ruta de bus. Toma una ruta de bus y una cadena de prefijo, además de un lugar para almacenar la cadena de identificador externo devuelta. Si la ruta del bus no comienza con el prefijo especificado, se devuelve 0 y la cadena devuelta se establece en NULL. De lo contrario, la cadena que sigue al prefijo se decodifica y se devuelve en la cadena del identificador externo.

La codificación utilizada reemplazará todos los caracteres que son inválidos en una ruta de objeto de bus por "_", seguido de un valor hexadecimal. Como caso especial, la cadena vacía se reemplazará por un único "_".

sd_bus_path_encode_many() funciona como su contraparte sd_bus_path_encode(), pero toma una plantilla de ruta como argumento y codifica múltiples etiquetas según sus directivas incrustadas. Por cada carácter "%" encontrado en la plantilla, el llamador debe proporcionar una cadena a través de varargs, que se codificará y se incrustará en la posición del carácter "%". Cualquier otro carácter en la plantilla se copia literalmente en la ruta codificada.

sd_bus_path_decode_many() hace lo inverso de sd_bus_path_encode_many(). Decodifica la ruta de objeto pasada según la plantilla de ruta dada. Por cada carácter "%" en la plantilla, el llamador debe proporcionar un almacenamiento de salida ("char **") a través de varargs. La etiqueta decodificada se almacenará allí. Cada carácter "%" solo coincidirá con la etiqueta actual. Nunca coincidirá entre etiquetas. Además, solo se permite una directiva por etiqueta. Si se pasa NULL como almacenamiento de salida, la etiqueta se verifica pero no se devuelve al llamador.

VALOR DE RETORNO

En caso de éxito, sd_bus_path_encode() devuelve un valor positivo o 0, y una ruta de bus válida en el argumento de retorno. En caso de éxito, sd_bus_path_decode() devuelve un valor positivo si el prefijo coincidió, o 0 si no lo hizo. Si el prefijo coincidió, el identificador externo se devuelve en el parámetro de retorno. Si no coincidió, se devuelve NULL en el parámetro de retorno. En caso de fallo, cualquiera de las funciones devuelve un número de error negativo estilo errno. Las cadenas devueltas deben ser liberadas por el llamador usando free(3).

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y vincular con el archivo libsystemd de pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para multihilo. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_path_encode() y sd_bus_path_decode() se agregaron en la versión 211.

sd_bus_path_encode_many() y sd_bus_path_decode_many() se agregaron en la versión 227.
