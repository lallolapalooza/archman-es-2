SDRVST2STG

Propósito:

!>
!>      SDRVST2STG  verifica los drivers del problema de valores propios simétricos.
!>
!>              SSTEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz tridiagonal simétrica real.
!>
!>              SSTEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz tridiagonal simétrica real.
!>
!>              SSTEVR calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz tridiagonal simétrica real
!>              utilizando la Representación Relativamente Robusta cuando es posible.
!>
!>              SSYEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real.
!>
!>              SSYEVX calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz simétrica real.
!>
!>              SSYEVR calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz simétrica real
!>              utilizando la Representación Relativamente Robusta cuando es posible.
!>
!>              SSPEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real en
!>              almacenamiento empaquetado.
!>
!>              SSPEVX calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz simétrica real en
!>              almacenamiento empaquetado.
!>
!>              SSBEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz de banda simétrica real.
!>
!>              SSBEVX calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz de banda simétrica real.
!>
!>              SSYEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real utilizando
!>              un algoritmo de división y conquista.
!>
!>              SSPEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real en
!>              almacenamiento empaquetado, utilizando un algoritmo de división y conquista.
!>
!>              SSBEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz de banda simétrica real,
!>              utilizando un algoritmo de división y conquista.
!>
!>      Cuando se llama a SDRVST2STG, se especifica un número de tamaños de
!>      matriz () y un número de tipos de matriz. Por cada tamaño ()
!>      y cada tipo de matriz, se generará una matriz y se utilizará
!>      para probar los drivers apropiados. Para cada matriz y cada
!>      driver llamado, se realizarán las siguientes pruebas:
!>
!>      (1)     | A - Z D Z' | / ( |A| n ulp )
!>
!>      (2)     | I - Z Z' | / ( n ulp )
!>
!>      (3)     | D1 - D2 | / ( |D1| ulp )
!>
!>      donde Z es la matriz de vectores propios devuelta cuando se da la
!>      opción de vectores propios y D1 y D2 son los valores propios
!>      devueltos con y sin la opción de vectores propios.
!>
!>      Los tamaños () se especifican mediante un array NN(1:NSIZES); el valor de
!>      cada elemento NN(j) especifica un tamaño.
!>      Los tipos de matriz () se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!>      Actualmente, la lista de tipos posibles es:
!>
!>      (1)  La matriz cero.
!>      (2)  La matriz identidad.
!>
!>      (3)  Una matriz diagonal con valores propios espaciados uniformemente
!>           1, ..., ULP  y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1 )
!>      (4)  Una matriz diagonal con valores propios espaciados geométricamente
!>           1, ..., ULP  y signos aleatorios.
!>      (5)  Una matriz diagonal con  valores propios
!>           1, ULP, ..., ULP y signos aleatorios.
!>
!>      (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8)  Una matriz de la forma  U' D U, donde U es ortogonal y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (9)  Una matriz de la forma  U' D U, donde U es ortogonal y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (10) Una matriz de la forma  U' D U, donde U es ortogonal y
!>           D tiene entradas  1, ULP,..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz simétrica con entradas aleatorias elegidas entre (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>      (16) Una matriz de banda con ancho de banda medio elegido aleatoriamente entre
!>           0 y N-1, con valores propios espaciados uniformemente 1, ..., ULP
!>           con signos aleatorios.
!>      (17) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (18) Igual que (16), pero multiplicado por SQRT( umbral de subdesbordamiento )
!> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matriz a utilizar. Si es cero,
!>          SDRVST2STG no hace nada. Debe ser como mínimo cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Se omitirán los valores cero. Los valores deben ser como mínimo
!>          cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SDRVST2STG
!>          no hace nada. Debe ser como mínimo cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar cualquier matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>          No modificado.
!>
!>  DOTYPE  LOGICAL array, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>          No modificado.
!>
!>  ISEED   INTEGER array, dimension (4)
!>          En la entrada ISE
ED especifica la semilla del generador de números aleatorios. Los elementos del array deben estar entre 0 y 4095; si no, se reducirán módulo 4096. Además, ISEED(4) debe ser impar. El generador de números aleatorios utiliza una secuencia congruencial lineal limitada a enteros pequeños, por lo que debería producir números aleatorios independientes de la máquina. Los valores de ISEED se modifican a la salida y se pueden utilizar en la siguiente llamada a SDRVST2STG para continuar la misma secuencia de números aleatorios. Modificado. THRESH REAL Un test contará como válido si el valor calculado como se describe anteriormente supera THRESH. Tenga en cuenta que el error se escala para ser O(1), por lo que THRESH debería ser un múltiplo razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular, no debe depender de la precisión (simple o doble) ni del tamaño de la matriz. Debe ser al menos cero. No modificado. NOUNIT INTEGER El número de unidad FORTRAN para imprimir mensajes de error (por ejemplo, si una rutina devuelve IINFO distinto de 0). No modificado. A REAL array, dimension (LDA , max(NN)) Se utiliza para contener la matriz cuyos valores propios se van a calcular. A la salida, A contiene la última matriz utilizada. Modificado. LDA INTEGER La dimensión principal de A. Debe ser al menos 1 y al menos max( NN ). No modificado. D1 REAL array, dimension (max(NN)) Los valores propios de A, calculados por SSTEQR simultáneamente con Z. A la salida, los valores propios en D1 corresponden a la matriz en A. Modificado. D2 REAL array, dimension (max(NN)) Los valores propios de A, calculados por SSTEQR si no se calcula Z. A la salida, los valores propios en D2 corresponden a la matriz en A. Modificado. D3 REAL array, dimension (max(NN)) Los valores propios de A, calculados por SSTERF. A la salida, los valores propios en D3 corresponden a la matriz en A. Modificado. D4 REAL array, dimension EVEIGS REAL array, dimension (max(NN)) Los valores propios calculados por SSTEV('N', ... ) (Me reservo el derecho de cambiar esto a la salida del algoritmo que calcule los valores propios más precisos). WA1 REAL array, dimension WA2 REAL array, dimension WA3 REAL array, dimension U REAL array, dimension (LDU, max(NN)) La matriz ortogonal calculada por SSYTRD + SORGTR. Modificado. LDU INTEGER La dimensión principal de U, Z y V. Debe ser al menos 1 y al menos max( NN ). No modificado. V REAL array, dimension (LDU, max(NN)) Los vectores de Householder calculados por SSYTRD al reducir A a forma tridiagonal. Modificado. TAU REAL array, dimension (max(NN)) Los factores de Householder calculados por SSYTRD al reducir A a forma tridiagonal. Modificado. Z REAL array, dimension (LDU, max(NN)) La matriz ortogonal de vectores propios calculada por SSTEQR, SPTEQR y SSTEIN. Modificado. WORK REAL array, dimension (LWORK) Espacio de trabajo. Modificado. LWORK INTEGER El número de entradas en WORK. Debe ser al menos 1 + 4 * Nmax + 2 * Nmax * lg Nmax + 4 * Nmax**2 donde Nmax = max( NN(j), 2 ) y lg = logaritmo base 2. No modificado. IWORK INTEGER array, dimension (6 + 6*Nmax + 5 * Nmax * lg Nmax ) donde Nmax = max( NN(j), 2 ) y lg = logaritmo base 2. Espacio de trabajo. Modificado. RESULT REAL array, dimension (105) Los valores calculados por los tests descritos anteriormente. Los valores están actualmente limitados a 1/ulp, para evitar desbordamiento. Modificado. INFO INTEGER Si es 0, entonces todo funcionó correctamente. -1: NSIZES < 0 -2: Algún NN(j) < 0 -3: NTYPES < 0 -5: THRESH < 0 -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ). -16: LDU < 1 o LDU < NMAX. -21: LWORK demasiado pequeño. Si SLATMR, SLATMS, SSYTRD, SORGTR, SSTEQR, SSTERF o SORMTR devuelven un código de error, se devuelve su valor absoluto.
