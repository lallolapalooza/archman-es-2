SD_BUS_SET_CONNECTED_SIGNAL(3) sd_bus_set_connected_signal SD_BUS_SET_CONNECTED_SIGNAL(3)

NOMBRE

sd_bus_set_connected_signal, sd_bus_get_connected_signal - Controlar la emisión de la señal local de establecimiento de conexión en conexiones de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_set_connected_signal(sd_bus *bus, int b);

int sd_bus_get_connected_signal(sd_bus *bus);

DESCRIPCIÓN

sd_bus_set_connected_signal() se puede usar para controlar si se generará un mensaje de señal local y sintético Connected() y se encolará para su despacho cuando la conexión se establezca completamente. Si el parámetro b es cero, el mensaje no se genera (el valor predeterminado), de lo contrario, se genera.

sd_bus_get_connected_signal() se puede usar para consultar si esta característica está habilitada. Devuelve cero si no lo está, y un valor positivo en caso contrario.

El mensaje de señal Connected() se genera desde el servicio "org.freedesktop.DBus.Local" e interfaz, y la ruta de objeto "/org/freedesktop/DBus/Local". Utilice sd_bus_match_signal_async(3) para coincidir con esta señal.

Este mensaje es particularmente útil en transportes lentos donde las conexiones tardan mucho en establecerse. Este es el caso especialmente cuando se usa sd_bus_set_watch_bind(3). La señal se genera cuando sd_bus_is_ready(3) devuelve positivo por primera vez.

La señal Connected() corresponde con la señal Disconnected() que se sintetiza localmente cuando la conexión se termina. Esta última se genera incondicionalmente sin embargo, a diferencia de la primera que necesita ser habilitada explícitamente antes de que se genere, con sd_bus_set_connected_signal().

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ECHILD

La conexión de bus se ha creado en un proceso, biblioteca o instancia de módulo diferente.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se han iniciado otros hilos.

HISTORIA

sd_bus_set_connected_signal() y sd_bus_get_connected_signal() se añadieron en la versión 237.
