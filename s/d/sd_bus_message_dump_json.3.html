sd_bus_message_dump_json(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_MESSAGE_DUMP(3) sd_bus_message_dump SD_BUS_MESSAGE_DUMP(3)

NOMBRE

sd_bus_message_dump, sd_bus_message_dump_json - Producir una representación en cadena de un mensaje para fines de depuración

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_message_dump(sd_bus_message *m, FILE *f, uint64_t flags);

int sd_bus_message_dump_json(sd_bus_message *m, uint64_t flags, sd_json_variant **ret);

DESCRIPCIÓN

La función sd_bus_message_dump() escribe una representación textual del mensaje m en el flujo f. Si f es NULL, se usará la salida estándar (stdio). Esta función está pensada para ser utilizada con fines de depuración, y la salida no es estable ni está diseñada para ser legible por máquinas.

La función sd_bus_message_dump_json() convierte el mensaje DBus m a una variante JSON y la almacena en ret. El llamador debe llamar a sd_json_variant_unref() para la variante JSON adquirida después de su uso. A diferencia de sd_bus_message_dump(), la función en sí no imprime nada. Para imprimir el mensaje DBus en formato JSON, por favor, pase la variante JSON devuelta a sd_json_variant_dump().

El parámetro flags se puede usar para modificar la salida, y es una combinación de cero o más de las siguientes banderas:

SD_BUS_MESSAGE_DUMP_WITH_HEADER

Se imprimirá o incluirá en el objeto JSON resultante la cabecera del mensaje que especifica el tipo de mensaje, las banderas y metadatos adicionales.

SD_BUS_MESSAGE_DUMP_SUBTREE_ONLY

Solo se imprimirá o convertirá el contenedor actual. Cuando la bandera *no* se especifica, se imprimirá o convertirá el contenido del mensaje completo.

Tenga en cuenta que estas funciones mueven el puntero de lectura del mensaje. Puede ser necesario restablecer la posición posteriormente, por ejemplo con sd_bus_message_rewind(3).

EJEMPLOS

Salida para un mensaje de señal (con SD_BUS_MESSAGE_DUMP_WITH_HEADER):

> Type=signal  Endian=l  Flags=1  Version=1  Cookie=22
  Path=/value/a  Interface=org.freedesktop.DBus.Properties  Member=PropertiesChanged
  MESSAGE "sa{sv}as" {
          STRING "org.freedesktop.systemd.ValueTest";
          ARRAY " {sv}" {
                  DICT_ENTRY "sv" {
                          STRING "Value";
                          VARIANT "s" {
                                  STRING "object 0x1e, path /value/a";
                          };
                  };
          };
          ARRAY "s" {
                  STRING "Value2";
                  STRING "AnExplicitProperty";
          };
  };

VALOR DE RETORNO

En caso de éxito, esta función devuelve 0 o un entero positivo. En caso de error, devuelve un código de error negativo de estilo errno. Actualmente no se definen códigos de error.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
