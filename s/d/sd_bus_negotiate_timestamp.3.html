SD_BUS_NEGOTIATE_FDS(3) sd_bus_negotiate_fds SD_BUS_NEGOTIATE_FDS(3)

NOMBRE

sd_bus_negotiate_fds, sd_bus_negotiate_timestamp, sd_bus_negotiate_creds, sd_bus_get_creds_mask - Controlar la negociación de características en conexiones de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_negotiate_fds(sd_bus *bus, int b);

int sd_bus_negotiate_timestamp(sd_bus *bus, int b);

int sd_bus_negotiate_creds(sd_bus *bus, int b, uint64_t mask);

int sd_bus_get_creds_mask(sd_bus *bus, uint64_t *mask);

DESCRIPCIÓN

sd_bus_negotiate_fds() controla si se deben negociar la transmisión de descriptores de archivo para la conexión de bus especificada. Toma un objeto de bus y un booleano que, cuando es verdadero, habilita la transmisión de descriptores de archivo, y cuando es falso, la deshabilita. Tenga en cuenta que no todos los transportes y servidores admiten la transmisión de descriptores de archivo. En particular, los transportes en red generalmente no admiten la transmisión de descriptores de archivo. Para averiguar si la transmisión de descriptores de archivo está disponible después de la negociación, utilice sd_bus_can_send(3) y pase SD_BUS_TYPE_UNIX_FD. Tenga en cuenta que la transmisión de descriptores de archivo siempre está habilitada para envío y recepción o para ninguno, pero nunca solo en una dirección. Por defecto, se negocia la transmisión de descriptores de archivo para todas las conexiones.

sd_bus_negotiate_timestamp() controla si las marcas de tiempo implícitas del remitente se adjuntarán automáticamente a todos los mensajes entrantes. Toma un objeto de bus y un booleano que, cuando es verdadero, habilita el marcado de tiempo, y cuando es falso, lo deshabilita. Utilice sd_bus_message_get_monotonic_usec(3), sd_bus_message_get_realtime_usec(3), sd_bus_message_get_seqnum(3) para consultar las marcas de tiempo de los mensajes entrantes. Si la negociación está deshabilitada o no es compatible, estas llamadas fallarán con -ENODATA. Tenga en cuenta que actualmente ningún transporte admite el marcado de tiempo de los mensajes. Por defecto, no se negocia el marcado de tiempo de mensajes para las conexiones.

sd_bus_negotiate_creds() controla si y qué credenciales implícitas del remitente se adjuntarán automáticamente a todos los mensajes entrantes. Toma un objeto de bus y un booleano que indica si habilitar o deshabilitar las partes de credenciales codificadas en el valor de la máscara de bits proporcionada. Tenga en cuenta que no todos los transportes admiten la adjunción de credenciales del remitente a los mensajes, o no admiten todos los tipos de parámetros de credenciales del remitente, o pueden suprimirlos bajo ciertas circunstancias para mensajes individuales. Específicamente, dbus1 solo admite SD_BUS_CREDS_UNIQUE_NAME. Las credenciales del remitente son adecuadas para decisiones de autorización. Por defecto, solo están habilitadas SD_BUS_CREDS_WELL_KNOWN_NAMES y SD_BUS_CREDS_UNIQUE_NAME. De hecho, estos dos campos de credenciales siempre se envían y no se pueden desactivar.

sd_bus_get_creds_mask() devuelve el conjunto de credenciales del remitente que se negoció para adjuntar a todos los mensajes entrantes en mask. Este valor es solo un límite superior. Por lo tanto, siempre asegúrese de verificar explícitamente qué credenciales se adjuntan a un mensaje específico antes de usarlo.

La función sd_bus_negotiate_fds() solo puede llamarse antes de que la conexión se haya iniciado con sd_bus_start(3). Tanto sd_bus_negotiate_timestamp() como sd_bus_negotiate_creds() también pueden llamarse después de que se haya configurado una conexión. Tenga en cuenta que, al operar en una conexión que es compartida entre múltiples componentes del mismo programa (por ejemplo, a través de sd_bus_default(3)), se recomienda encarecidamente habilitar solo campos de metadatos adicionales por mensaje, pero nunca deshabilitarlos nuevamente, para no deshabilitar la funcionalidad necesaria para otros componentes.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven un entero no negativo. En caso de error, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EPERM

La conexión de bus ya se ha iniciado.

-EINVAL

Un argumento es inválido.

Añadido en la versión 246.

-ENOPKG

El bus no se puede resolver.

Añadido en la versión 246.

-ECHILD

El bus se creó en un proceso, biblioteca o instancia de módulo diferente.

Añadido en la versión 246.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y vincular con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que está declarado como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer las llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_negotiate_fds(), sd_bus_negotiate_timestamp() y sd_bus_negotiate_creds() se añadieron en la versión 212.

sd_bus_get_creds_mask() se añadió en la versión 246.
