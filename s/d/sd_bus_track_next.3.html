sd_bus_track_next(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_TRACK_ADD_NAME(3) sd_bus_track_add_name SD_BUS_TRACK_ADD_NAME(3)

NOMBRE

sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_remove_sender, sd_bus_track_count, sd_bus_track_count_sender, sd_bus_track_count_name, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next - Añadir, eliminar y recuperar nodos de bus rastreados en un objeto de rastreo de nodos de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(sd_bus_track* t, const char* name);

int sd_bus_track_add_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_remove_name(sd_bus_track* t, const char* name);

int sd_bus_track_remove_sender(sd_bus_track* t, sd_bus_message* message);

unsigned sd_bus_track_count(sd_bus_track* t);

int sd_bus_track_count_name(sd_bus_track* t, const char* name);

int sd_bus_track_count_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_contains(sd_bus_track* t, const char* name);

const char* sd_bus_track_first(sd_bus_track* t);

const char* sd_bus_track_next(sd_bus_track* t);

DESCRIPCIÓN

sd_bus_track_add_name() añade un nodo a rastrear a un objeto de rastreo de nodos de bus. El primer argumento debe hacer referencia a un objeto de rastreo de nodos de bus creado con sd_bus_track_new(3), el segundo nombre debe hacer referencia a un nombre de nodo de D-Bus a rastrear, en formato de servicio conocido o único. Si el nombre aún no se está rastreando, se añadirá a la lista de nombres a rastrear. Si ya se está rastreando y el modo no recursivo está habilitado, esta llamada no ejecutará ninguna operación. Si el modo recursivo está habilitado, un contador por nombre se incrementará en uno cada vez que se invoque esta llamada, y sd_bus_track_remove_name() deberá llamarse tantas veces como se invocó sd_bus_track_add_name() para dejar de rastrear el nombre. Utilice sd_bus_track_set_recursive(3) para cambiar del modo no recursivo predeterminado al modo recursivo, o viceversa. Tenga en cuenta que el nombre especificado se rastrea tal cual, los nombres conocidos no se resuelven a nombres únicos mediante esta llamada. Tenga en cuenta que varios objetos de rastreo de nodos de bus pueden rastrear el mismo nombre.

sd_bus_track_remove_name() deshace el efecto de sd_bus_track_add_name() y elimina un nombre de nodo de bus de la lista de nodos a vigilar. Dependiendo de si el modo no recursivo o recursivo está habilitado para el objeto de rastreo de nodos de bus, esta llamada eliminará el nombre por completo del objeto de rastreo o simplemente disminuirá el contador por nombre en uno, eliminando el nombre solo cuando el contador llegue a cero (ver arriba). Tenga en cuenta que un nodo de bus que se desconecta del bus eliminará implícitamente sus nombres por completo del objeto de rastreo de nodos de bus, independientemente del contador por nombre actual.

sd_bus_track_add_sender() y sd_bus_track_remove_sender() son similares a sd_bus_track_add_name() y sd_bus_track_remove_name() pero toman un mensaje de bus como argumento. Se determina el remitente de este mensaje de bus y se añade/elimina del objeto de rastreo de nodos de bus. Dado que los mensajes siempre se originan de nombres únicos, y nunca de nombres conocidos, esto significa que esta llamada efectivamente solo añadirá nombres únicos al objeto de rastreo de nodos de bus.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente por el objeto de rastreo de nodos de bus especificado. Tenga en cuenta que esta función siempre devuelve el número real de nombres rastreados y, por lo tanto, si se ha invocado sd_bus_track_add_name() varias veces para el mismo nombre, solo se cuenta como uno, independientemente de si se utiliza el modo recursivo o no.

sd_bus_track_count_name() devuelve el contador por nombre actual para el nombre especificado. Si se utiliza el modo no recursivo, esto devuelve 1 o 0, dependiendo de si el nombre especificado se ha añadido antes al objeto de rastreo o no. Si se ha habilitado el modo recursivo, también se pueden devolver valores mayores que 1, en caso de que se haya invocado sd_bus_track_add_name() varias veces para el mismo nombre.

sd_bus_track_count_sender() es similar a sd_bus_track_count_name(), pero toma un objeto de mensaje de bus y devuelve el contador por nombre que coincide con el remitente del mensaje.

sd_bus_track_contains() se puede utilizar para determinar si el nombre especificado se ha añadido al menos una vez al objeto de rastreo de nodos de bus especificado.

sd_bus_track_first() y sd_bus_track_next() se pueden utilizar para enumerar todos los nombres que se están rastreando actualmente por el objeto de rastreo de nodos de bus pasado. sd_bus_track_first() devuelve la primera entrada del objeto y restablece un índice de lectura mantenido internamente. Cada invocación subsiguiente de sd_bus_track_next() devuelve el siguiente nombre contenido en el objeto de bus. Si se llega al final, se devuelve NULL. Si aún no se han añadido nombres al objeto, sd_bus_track_first() devolverá NULL inmediatamente. El orden en que se devuelven los nombres no está definido; en particular, no está definido qué nombre se considera el primero devuelto. Si el modo recursivo está habilitado y el mismo nombre se ha añadido varias veces al objeto de rastreo de nodos de bus, solo se devuelve una vez en esta enumeración. Si se añaden nombres nuevos o se eliminan nombres existentes del objeto de rastreo de nodos de bus mientras se está enumerando, la enumeración finaliza en la próxima invocación de sd_bus_track_next(), ya que se devuelve NULL.

VALOR_DE_RETORNO

En caso de éxito, sd_bus_track_add_name() y sd_bus_track_add_sender() devuelven 0 si el nombre especificado ya se había añadido antes al objeto de rastreo de nodos de bus y un valor positivo si no. En caso de error, devuelven un código de error negativo de estilo errno.

sd_bus_track_remove_name() y sd_bus_track_remove_sender() devuelven un valor positivo si el nombre especificado estaba previamente rastreado por el objeto de rastreo de nodos de bus y ahora ha sido eliminado. En modo no recursivo, se devuelve 0 si el nombre especificado aún no estaba siendo rastreado. En modo recursivo, se devuelve -EUNATCH en este caso. En caso de error, devuelven un código de error negativo de estilo errno.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente, o 0 en caso de error.

sd_bus_track_count_name() y sd_bus_track_count_sender() devuelven el contador por nombre actual para el nombre especificado o el remitente del mensaje especificado. Se devuelve cero para los nombres que aún no se están rastreando, un valor positivo para los nombres añadidos al menos una vez. Los valores mayores que 1 solo se devuelven en modo recursivo. En caso de error, se devuelve un código de error negativo de estilo errno.

sd_bus_track_contains() devuelve el nombre pasado si existe en el objeto de rastreo de nodos de bus. En caso de error, y si el nombre aún no se ha añadido, se devuelve NULL.

sd_bus_track_first() y sd_bus_track_next() devuelven el primer/siguiente nombre contenido en el objeto de rastreo de nodos de bus, y NULL si se llega al final de la enumeración y en caso de error.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EUNATCH

Se ha invocado sd_bus_track_remove_name() o sd_bus_track_remove_sender() para un nombre no añadido previamente al objeto de bus.

-EINVAL

Parámetro especificado inválido.

-ENOMEM

Fallo al asignar memoria.
