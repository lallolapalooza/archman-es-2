SD_EVENT_GET_FD(3) sd_event_get_fd SD_EVENT_GET_FD(3)

NOMBRE

sd_event_get_fd - Obtener un descriptor de archivo para sondear eventos del bucle de eventos

SINOPSIS

#include <systemd/sd-event.h>

int sd_event_get_fd(sd_event *event);

DESCRIPCIÓN

sd_event_get_fd() devuelve el descriptor de archivo que un objeto de bucle de eventos devuelto por la función sd_event_new(3) utiliza para esperar eventos. Este descriptor de archivo puede ser sondeado para eventos POLLIN/EPOLLIN. Esto hace posible incrustar un bucle de eventos sd-event(3) en otro bucle de eventos, posiblemente extranjero.

El descriptor de archivo devuelto se refiere a un objeto epoll(7). Se recomienda no alterarlo invocando epoll_ctl(2) sobre él, para evitar interferencias con la lógica interna y las suposiciones del bucle de eventos.

VALOR DEVUELTO

En caso de éxito, sd_event_get_fd() devuelve un descriptor de archivo no negativo. En caso de error, devuelve un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

event no es un puntero válido a una estructura sd_event.

-ECHILD

El bucle de eventos se ha creado en un proceso, biblioteca o instancia de módulo diferente.

EJEMPLOS

Ejemplo 1. Integración en el bucle de eventos GLib

/* SPDX-License-Identifier: MIT-0 */
#include <stdlib.h>
#include <glib.h>
#include <systemd/sd-event.h>
typedef struct SDEventSource {
  GSource source;
  GPollFD pollfd;
  sd_event *event;
} SDEventSource;
static gboolean event_prepare(GSource *source, gint *timeout_) {
  return sd_event_prepare(((SDEventSource *)source)->event) > 0;
}
static gboolean event_check(GSource *source) {
  return sd_event_wait(((SDEventSource *)source)->event, 0) > 0;
}
static gboolean event_dispatch(GSource *source, GSourceFunc callback, gpointer user_data) {
  return sd_event_dispatch(((SDEventSource *)source)->event) > 0;
}
static void event_finalize(GSource *source) {
  sd_event_unref(((SDEventSource *)source)->event);
}
static GSourceFuncs event_funcs = {
  .prepare = event_prepare,
  .check = event_check,
  .dispatch = event_dispatch,
  .finalize = event_finalize,
};
GSource *g_sd_event_create_source(sd_event *event) {
  SDEventSource *source;
  source = (SDEventSource *)g_source_new(&event_funcs, sizeof(SDEventSource));
  source->event = sd_event_ref(event);
  source->pollfd.fd = sd_event_get_fd(event);
  source->pollfd.events = G_IO_IN | G_IO_HUP | G_IO_ERR;
  g_source_add_poll((GSource *)source, &source->pollfd);
  return (GSource *)source;
}

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA
