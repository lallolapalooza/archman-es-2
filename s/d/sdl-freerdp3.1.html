NOMBRE

sdl-freerdp3 - Cliente FreeRDP SDL

SINOPSIS

sdl-freerdp3 [archivo] [opciones] [/v:servidor[:puerto]]

DESCRIPCIÓN

sdl-freerdp3 es un cliente de Protocolo de Escritorio Remoto (RDP) de SDL que forma parte del proyecto FreeRDP. Un servidor RDP está integrado en muchas ediciones de Windows. Servidores alternativos incluyen ogon, gnome-remote-desktop, xrdp y VRDP (VirtualBox).

Opciones de aceptación de certificado. ¡Úsese con cuidado!
* deny ... Aborta automáticamente la conexión si el certificado no coincide, sin interacción del usuario.
* ignore ... Ignora las comprobaciones del certificado por completo (anula todas las demás opciones)
* name ... Usa el <nombre> alternativo en lugar del sujeto del certificado para coincidir con los certificados almacenados localmente
* tofu ... Acepta el certificado incondicionalmente en la primera conexión y lo rechaza en conexiones subsiguientes si el certificado no coincide
* fingerprints ... Una lista de hashes de certificados que se aceptan incondicionalmente para una conexión

ARCHIVO DE CONFIGURACIÓN

Formato y ubicación:

El archivo de configuración se almacena por usuario.

La variable de entorno XDG_CONFIG_HOME se puede utilizar para anular el directorio base.

Esto tiene como valor predeterminado ~/.config La ubicación relativa a XDG_CONFIG_HOME es $XDG_CONFIG_HOME/freerdp/sdl-freerdp.json

La configuración se almacena en formato JSON.

Opciones admitidas:

SDL_KeyModMask

Define la combinación de teclas requerida para los atajos del cliente SDL.

Predeterminado: KMOD_RSHIFT

Una matriz de cadenas SDL_Keymod como se define en https://wiki.libsdl.org/SDL3/SDL_Keymod
usa KEYMOD_NONE para deshabilitar los atajos.

SDL_Fullscreen

Activa/desactiva el estado de pantalla completa del cliente.

Predeterminado: SDL_SCANCODE_RETURN.

Una cadena como se define en https://wiki.libsdl.org/SDL3/SDL_Scancode

SDL_Minimize

Minimiza la ventana del cliente.

Predeterminado: SDL_SCANCODE_M.

Una cadena como se define en https://wiki.libsdl.org/SDL3/SDL_Scancode

SDL_Resizeable

Activa/desactiva el estado de redimensionamiento de la ventana local.

Predeterminado: SDL_SCANCODE_R.

Una cadena como se define en https://wiki.libsdl.org/SDL3/SDL_Scancode

SDL_Grab

Activa/desactiva el estado de captura del teclado y el ratón.
Si el teclado está capturado, los atajos del sistema local ya no funcionan y se envían al sistema remoto.
Si el ratón está capturado (opcional), la detección de gestos local no funciona y el ratón podría no poder salir de la ventana RDP. Los eventos del ratón no se alteran.

Predeterminado: SDL_SCANCODE_G.

Una cadena como se define en https://wiki.libsdl.org/SDL3/SDL_Scancode

SDL_Disconnect

Desconecta de la sesión RDP.

Predeterminado: SDL_SCANCODE_D.

Una cadena como se define en https://wiki.libsdl.org/SDL3/SDL_Scancode

CONFIGURACIÓN GLOBAL (cliente común)

Formato y ubicación:

Los archivos de configuración se almacenan en la configuración del sistema global.

La ubicación común de configuración de certificados es /etc/FreeRDP/certificates.json

El formato del archivo es JSON.

Opciones admitidas:

deny

Booleano JSON

Deniega el certificado si la verificación con el almacén SSL del sistema no tuvo éxito.

ignore

Booleano JSON

Ignora los fallos del certificado, simplemente ignora el certificado.

deny-userconfig

Booleano JSON

Si las verificaciones en la configuración global no aceptan el certificado, no se le preguntará al usuario.

certificate-db

Matriz JSON

Una matriz de objetos JSON con:

type

Cadena JSON

una cadena que identifica el algoritmo hash utilizado, por ejemplo, sha256.

hash

Cadena JSON

una cadena de valores enteros hexadecimales que representan el hash del certificado, por ejemplo, 0123456789abcdef.

CONFIGURACIÓN GLOBAL (cliente SDL3)

La ubicación de la configuración del cliente SDL3 es /etc/FreeRDP/sdl-freerdp.json

Formato del archivo: JSON

Opciones admitidas:

isUserConfigEnabled

Booleano JSON

Permite o bloquea el soporte del archivo de configuración por usuario.

Todas las opciones de nivel de usuario de **ARCHIVO DE CONFIGURACIÓN** se pueden establecer aquí también.

EJEMPLOS

sdl-freerdp3 connection.rdp /p:Pwd123! /f

Conéctate en modo de pantalla completa utilizando una configuración almacenada connection.rdp y la contraseña Pwd123!.

sdl-freerdp3 /u:USER /size:50%h /v:rdp.contoso.com

Conéctate al host rdp.contoso.com con el usuario USER y un tamaño del 50 por ciento de la altura. Si se establece el ancho (w) en lugar de la altura (h), como en /size:50%w, se utiliza el 50 por ciento del ancho.

sdl-freerdp3 /u:CONTOSO\\JohnDoe /p:Pwd123! /v:rdp.contoso.com

Conéctate al host rdp.contoso.com con el usuario CONTOSO\\JohnDoe y la contraseña Pwd123!.

sdl-freerdp3 /u:JohnDoe /p:Pwd123! /w:1366 /h:768 /v:192.168.1.100:4489

Conéctate al host 192.168.1.100 en el puerto 4489 con el usuario JohnDoe, contraseña Pwd123!. El ancho de pantalla se establece en 1366 y la altura en 768.

sdl-freerdp3 /u:JohnDoe /p:Pwd123! /vmconnect:C824F53E-95D2-46C6-9A18-23A5BB403532 /v:192.168.1.100

Establece una conexión al host 192.168.1.100 con el usuario JohnDoe, contraseña Pwd123! y conéctate a la consola Hyper-V (usa el puerto 2179, deshabilita la negociación) con el VMID C824F53E-95D2-46C6-9A18-23A5BB403532.
