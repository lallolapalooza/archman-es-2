sd_varlink_send(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_VARLINK_SEND(3) sd_varlink_send SD_VARLINK_SEND(3)

NOMBRE

sd_varlink_send, sd_varlink_sendb, sd_varlink_sendbo - Pone en cola una llamada a método Varlink, sin esperar una respuesta

SINOPSIS

#include <systemd/sd-varlink.h>

int sd_varlink_send(sd_varlink *link, const char *method, sd_json_variant *parameters);

int sd_varlink_sendb(sd_varlink *link, const char *method, ...);

int sd_varlink_sendbo(sd_varlink *link, const char *method, ...);

DESCRIPCIÓN

sd_varlink_send() envía una llamada a método a través de una conexión Varlink. Toma el objeto de conexión Varlink, un nombre de método como parámetro de cadena, y un objeto JSON que contiene los parámetros a pasar como parámetros de función. Esta llamada es asíncrona: el mensaje no se entregará inmediatamente, sino solo una vez que se invoque sd_varlink_process(3) (lo que ocurrirá automáticamente en una de las siguientes iteraciones del bucle de eventos si la conexión Varlink está adjunta a un bucle de eventos).

sd_varlink_sendb() es similar a sd_varlink_send(), pero en lugar de esperar un objeto sd_json_variant completamente construido que contenga los parámetros, este objeto se construye sobre la marcha directamente a partir de la lista de parámetros, en un estilo idéntico a sd_json_build(3).

sd_varlink_sendbo() es idéntico a sd_varlink_sendb(), pero se agrega implícitamente un objeto envolvente, de modo que se espera que la lista de parámetros consista únicamente en pares de campos. Para obtener detalles sobre la lista de argumentos esperada, consulte sd_json_buildo(3).

Utilice sd_varlink_send(), sd_varlink_sendb() y sd_varlink_sendbo() solo si no se requieren resultados de llamada de método, ya que no proporcionan parámetros de retorno ni información de éxito/fracaso. Utilice sd_varlink_call(3) (y llamadas relacionadas) para enviar una llamada de método de forma síncrona, devolviendo la respuesta del servidor.

VALOR DE RETORNO

En caso de éxito, sd_varlink_send(), sd_varlink_sendb() y sd_varlink_sendbo() devuelven un entero no negativo. En caso de fallo, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Un argumento es inválido.

-ENOMEM

Error de asignación de memoria.

-ENOTCONN

El objeto de conexión Varlink no está conectado.

-EBUSY

El objeto de conexión Varlink ya está en uso para otros propósitos, es decir, ejecución de una llamada a método o similar.

-ENOBUFS

Se ha alcanzado el límite interno de mensajes en cola para la conexión Varlink. Este límite es muy alto y alcanzarlo típicamente indica que el objeto de conexión Varlink está bloqueado; posiblemente porque sd_varlink_process(3) no se ha llamado con suficiente regularidad, o porque el par no está procesando ningún mensaje en cola. Este límite es una precaución para garantizar que un par bloqueado no resulte en asignaciones de memoria ilimitadas en el lado del cliente.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y vincular con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_varlink_send(), sd_varlink_sendb(), sd_varlink_sendbo() se agregaron en la versión 257.
