NOMBRE

sd_bus_message_verify_type - Comprobar si el mensaje tiene el tipo especificado en la ubicación actual

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_message_verify_type(sd_bus_message *m, char type, const char* contents);

DESCRIPCIÓN

sd_bus_message_verify_type() comprueba si el tipo completo en la ubicación actual del mensaje m coincide con el type y contents especificados. Si es distinto de cero, el parámetro type debe ser uno de los tipos especificados en sd_bus_message_append(3). Si es distinto de nulo, el parámetro contents debe ser una secuencia válida de tipos completos. Si se especifican tanto type como contents, type debe ser un tipo contenedor.

Si se especifica type, el tipo en el mensaje debe coincidir. Si se especifica contents, el tipo en el mensaje debe ser un tipo contenedor con esta firma.

VALOR DE RETORNO

En caso de éxito, esta llamada devuelve verdadero si el tipo coincide y cero si no coincide (el mensaje m contiene datos diferentes o se ha alcanzado el final del mensaje). En caso de error, devuelve un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

m o ambos type y contents son NULL.

Los argumentos no cumplen otras restricciones mencionadas anteriormente.

-EPERM

El mensaje m no está sellado.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
