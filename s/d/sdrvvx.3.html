Documentación de Función/Subrutina

subroutine sdrvvx (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer niunit, integer nounit, real, dimension( lda, * ) a, integer lda, real, dimension( lda, * ) h, real, dimension( * ) wr, real, dimension( * ) wi, real, dimension( * ) wr1, real, dimension( * ) wi1, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, real, dimension( ldlre, * ) lre, integer ldlre, real, dimension( * ) rcondv, real, dimension( * ) rcndv1, real, dimension( * ) rcdvin, real, dimension( * ) rconde, real, dimension( * ) rcnde1, real, dimension( * ) rcdein, real, dimension( * ) scale, real, dimension( * ) scale1, real, dimension( 11 ) result, real, dimension( * ) work, integer nwork, integer, dimension( * ) iwork, integer info)

SDRVVX

Propósito:

!>
!>    SDRVVX  comprueba el controlador experto del problema de valores
!>    propios no simétricos SGEEVX.
!>
!>    SDRVVX utiliza matrices de prueba generadas aleatoriamente según los
!>    datos proporcionados en la secuencia de llamada, así como datos leídos
!>    de un archivo de entrada e incluyendo números de condición precalculados
!>    con los que compara los que calcula.
!>
!>    Cuando se llama a SDRVVX, se especifica un número de tamaños de matriz ()
!>    y un número de tipos de matriz en la secuencia de llamada.
!>    Para cada tamaño () y cada tipo de matriz, se generará y utilizará
!>    una matriz para probar las rutinas de valores propios no simétricos.
!>    Para cada matriz, se realizarán 9 pruebas:
!>
!>    (1)     | A * VR - VR * W | / ( n |A| ulp )
!>
!>      Aquí VR es la matriz de vectores propios derechos unitarios.
!>      W es una matriz diagonal por bloques, con un bloque 1x1 para cada
!>      valor propio real y un bloque 2x2 para cada par conjugado complejo.
!>      Si los valores propios j y j+1 son un par conjugado complejo,
!>      de modo que WR(j) = WR(j+1) = wr y WI(j) = - WI(j+1) = wi, entonces
!>      el bloque 2x2 correspondiente al par será:
!>
!>              (  wr  wi  )
!>              ( -wi  wr  )
!>
!>      Un bloque de este tipo que multiplica a una matriz n x 2  ( ur ui )
!>      por la derecha será lo mismo que multiplicar  ur + i*ui  por  wr + i*wi.
!>
!>    (2)     | A**H * VL - VL * W**H | / ( n |A| ulp )
!>
!>      Aquí VL es la matriz de vectores propios izquierdos unitarios, A**H es
!>      la transpuesta conjugada de A, y W es como se describió anteriormente.
!>
!>    (3)     | |VR(i)| - 1 | / ulp y componente real más grande
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp y componente real más grande
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!>    (5)     W(completo) = W(parcial)
!>
!>      W(completo) denota los valores propios calculados cuando también se
!>      calculan VR, VL, RCONDV y RCONDE, y W(parcial) denota el resultado
!>      cuando solo se calculan algunos de VR, VL, RCONDV y RCONDE.
!>
!>    (6)     VR(completo) = VR(parcial)
!>
!>      VR(completo) denota los vectores propios derechos calculados cuando se
!>      calculan VL, RCONDV y RCONDE, y VR(parcial) denota el resultado cuando
!>      solo se calculan algunos de VL y RCONDV.
!>
!>    (7)     VL(completo) = VL(parcial)
!>
!>      VL(completo) denota los vectores propios izquierdos calculados cuando se
!>      calculan VR, RCONDV y RCONDE, y VL(parcial) denota el resultado cuando
!>      solo se calculan algunos de VR y RCONDV.
!>
!>    (8)     0 si SCALE, ILO, IHI, ABNRM (completo) =
!>                 SCALE, ILO, IHI, ABNRM (parcial)
!>            1/ulp de lo contrario
!>
!>      SCALE, ILO, IHI y ABNRM describen cómo se equilibra la matriz.
!>      (completo) es cuando también se calculan VR, VL, RCONDE y RCONDV, y
!>      (parcial) es cuando algunos no se calculan.
!>
!>    (9)     RCONDV(completo) = RCONDV(parcial)
!>
!>      RCONDV(completo) denota los números recíprocos de condición de los
!>      vectores propios derechos calculados cuando también se calculan VR, VL y
!>      RCONDE. RCONDV(parcial) denota los números recíprocos de condición
!>      cuando solo se calculan algunos de VR, VL y RCONDE.
!>
!>    Los  se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1 en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP y signos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1)
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP y signos aleatorios.
!>    (6)  Una matriz diagonal con  entradas 1, ULP, ..., ULP
!>         y signos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de desbordamiento.
!>    (8)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de subdesbordamiento.
!>
!>    (9)  Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con
!>         signos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (10) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con
!>         signos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (11) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene  entradas 1, ULP,..., ULP con
!>         signos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (12) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene valores propios reales o conjugados complejos elegidos
!>         aleatoriamente de ( ULP, 1 ) y entradas aleatorias O(1) en el
!>         triángulo superior.
!>
!>    (13) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con signos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (14) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con signos aleatorios en la diagonal y entradas
!>         aleatorias O(1) en el triángulo superior.
!>
!>    (15) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene  entradas 1, ULP,..., ULP
!>         con signos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (16) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene valores propios reales o conjugados complejos
!>         pareados elegidos aleatoriamente de ( ULP, 1 ) y entradas
!>         aleatorias O(1) en el triángulo superior.
!>
!>    Los números de condición recíprocos se calculan para los vectores
!>    propios derechos y izquierdos. Se utilizan las siguientes sentencias
!!>    para cada uno de los problemas de valores propios y de
!>    vectores propios:
!>
!>    Problema de valores propios:
!>       (1) VR, VL, RCONDE y RCONDV se calculan.
!>       (2) VL, RCONDE y RCONDV se calculan.
!>       (3) VR, RCONDE y RCONDV se calculan.
!>       (4) VR, VL, RCONDE se calculan.
!>       (5) RCONDE y RCONDV se calculan.
!>       (6) RCONDE se calcula.
!>
!>    Problema de vector propio derecho:
!>       (1) VR, VL, RCONDV y RCONDE se calculan.
!>       (2) VL, RCONDV y RCONDE se calculan.
!>       (3) VR, RCONDV y RCONDE se calculan.
!>       (4) VR, VL, RCONDV se calculan.
!>       (5) RCONDV y RCONDE se calculan.
!>       (6) RCONDV se calcula.
!>
!>    Problema de vector propio izquierdo:
!>       (1) VR, VL, RCONDV y RCONDE se calculan.
!>       (2) VL, RCONDV y RCONDE se calculan.
!>       (3) VR, RCONDV y RCONDE se calculan.
!>       (4) VR, VL, RCONDV se calculan.
!>       (5) RCONDV y RCONDE se calculan.
!>       (6) RCONDV se calcula.
!>
!>    Se calcula el número de condición recíproco de los valores propios
!>    (RCONDE y RCNDE1) y de los vectores propios derechos (RCONDV y
!>    RCNDV1).
!>
!>    Los resultados de la prueba se almacenan en el array RESULT(1:11).
!>    Se calcula la escala de los valores propios y vectores propios derechos
!>    y izquierdos.
!>
!>    Los resultados se imprimen como un mensaje de cabecera, seguido de
!>    una línea de resultados para cada tipo de matriz y cada tamaño de matriz
!>    especificado.  Un asterisco en la línea indica un resultado
!>    problemático.
!>
!>    Argumentos:
!>
!>    NSZES   (input) INTEGER
!>            el número de tamaños de matriz a probar.
!>
!>    NN      (input) INTEGER, dimension( NSZES )
!>            un array que contiene los tamaños de matriz a probar.  Cada
!>            tamaño es una matriz cuadrada de orden NN(j).
!>
!>    NTYPES  (input) INTEGER
!>            el número de tipos de matriz a probar.
!>
!>    DOTYPE  (input) LOGICAL, dimension( NTYPES )
!>            un array que especifica qué tipos de matriz probar.  Si
!>            DOTYPE(j) es .TRUE., entonces se prueba el tipo j.
!>
!>    ISEED   (input/output) INTEGER, dimension( 4 )
!>            el generador de números aleatorios.  Se modifica para obtener
!>            nuevos números aleatorios.
!>
!>    THRESH  (input) REAL
!>            un umbral para las pruebas.  Se calcula un error de prueba
!>            relativo a la máquina y aTHRESH.  Por ejemplo, si la precisión
!>            de la máquina es EPS, se espera que el error relativo sea menor
!>            que THRESH * EPS.
!>
!>    NIUNIT  (input) INTEGER
!>            el número de unidades de entrada de datos para la prueba de
!>            lectura de datos.
!>
!>    NOUNTT  (input) INTEGER
!>            el número de unidades de salida de datos para la prueba de
!>            escritura de datos.
!>
!>    A       (workspace) REAL, dimension( LDA, max(NN) )
!>            matriz de entrada.
!>
!>    LDA     (input) INTEGER
!>            la longitud de la primera dimensión de A.
!>
!>    H       (workspace) REAL, dimension( LDA, max(NN) )
!>            matriz de entrada.
!>
!>    WR      (output) REAL, dimension( max(NN) )
!>            valores propios reales.
!>
!>    WI      (output) REAL, dimension( max(NN) )
!>            parte imaginaria de los valores propios.
!>
!>    WR1     (output) REAL, dimension( max(NN) )
!>            valores propios reales.
!>
!>    WI1     (output) REAL, dimension( max(NN) )
!>            parte imaginaria de los valores propios.
!>
!>    VL      (output) REAL, dimension( LDVL, max(NN) )
!>            vectores propios izquierdos.
!>
!>    LDVL    (input) INTEGER
!>            la longitud de la primera dimensión de VL.
!>
!>    VR      (output) REAL, dimension( LDVR, max(NN) )
!>            vectores propios derechos.
!>
!>    LDVR    (input) INTEGER
!>            la longitud de la primera dimensión de VR.
!>
!>    LRE     (workspace) REAL, dimension( max(NN) )
!>            matriz de entrada.
!>
!>    LDLRE   (input) INTEGER
!>            la longitud de la primera dimensión de LRE.
!>
!>    RCONDV  (output) REAL, dimension( max(NN) )
!>            números recíprocos de condición de los vectores propios
!>            derechos.
!>
!>    RCNDV1  (output) REAL, dimension( max(NN) )
!>            números recíprocos de condición de los vectores propios
!>            derechos.
!>
!>    RCDVIN  (output) REAL, dimension( max(NN) )
!>            números recíprocos de condición de los vectores propios
!>            derechos.
!>
!>    RCONDE  (output) REAL, dimension( max(NN) )
!>            números recíprocos de condición de los valores propios.
!>
!>    RCNDE1  (output) REAL, dimension( max(NN) )
!>            números recíprocos de condición de los valores propios.
!>
!>    RCDEIN  (output) REAL, dimension( max(NN) )
!>            números recíprocos de condición de los valores propios.
!>
!>    SCALE   (output) REAL, dimension( max(NN) )
!>            factores de escala usados en el equilibrado.
!>
!>    SCALE1  (output) REAL, dimension( max(NN) )
!>            factores de escala usados en el equilibrado.
!>
!>    RESULT  (output) REAL, dimension( 11 )
!>            resultados de la prueba.  RESULT(i) es el resultado de la
!>            i-ésima prueba.
!>
!>    WORK    (workspace) REAL, dimension( * )
!>            un array de trabajo.
!>
!>    NWORK   (input) INTEGER
!>            la longitud del array WORK.
!>
!>    IWORK   (workspace) INTEGER, dimension( * )
!>            un array de trabajo para enteros.
!>
!>    INFO    (output) INTEGER
!>            = 0:  todas las pruebas correctas.
!>            > 0:  un valor de error de prueba.
!>            < 0:  un error de entrada, si el valor absoluto |INFO| es
!>                  igual a uno de los parámetros de entrada, entonces el
!>                  parámetro número |INFO| tiene un valor ilegal.  Asegúrese
!>                  que los arrays de entrada no estén vacíos.
!>
!>    ----------------------------------------------------------------------
!>
!>    Parámetros de tipo de matriz:
!>
!>    Tipo 1: Matriz cero.
!>    Tipo 2: Matriz identidad.
!>    Tipo 3: Bloque de Jordan de unos.
!>    Tipo 4: Matriz diagonal con entradas espaciadas uniformemente
!>            1,...,ULP y signos aleatorios.
!>    Tipo 5: Matriz diagonal con entradas espaciadas geométricamente
!>            1,...,ULP y signos aleatorios.
!>    Tipo 6: Matriz diagonal con entradas 1, ULP, ..., ULP y signos
!>            aleatorios.
!>    Tipo 7: Igual que Tipo 4 pero escalada cerca del desbordamiento.
!>    Tipo 8: Igual que Tipo 4 pero escalada cerca del subdesbordamiento.
!>    Tipo 9: Matriz de la forma U' T U, donde T tiene entradas espaciadas
!>            uniformemente en la diagonal y U es ortogonal.
!>    Tipo 10: Matriz de la forma U' T U, donde T tiene entradas espaciadas
!>            geométricamente en la diagonal y U es ortogonal.
!>    Tipo 11: Matriz de la forma U' T U, donde T tiene entradas 1, ULP, ...
!>            en la diagonal y U es ortogonal.
!>    Tipo 12: Matriz de la forma U' T U, donde T tiene valores propios
!>            aleatorios en la diagonal y U es ortogonal.
!>    Tipo 13: Matriz de la forma X' T X, donde T tiene entradas espaciadas
!>            uniformemente en la diagonal y X tiene condición sqrt(ULP).
!>    Tipo 14: Matriz de la forma X' T X, donde T tiene entradas espaciadas
!>            geométricamente en la diagonal y X tiene condición sqrt(ULP).
!>    Tipo 15: Matriz de la forma X' T X, donde T tiene entradas 1, ULP, ...
!>            en la diagonal y X tiene condición sqrt(ULP).
!>    Tipo 16: Matriz de la forma X' T X, donde T tiene valores propios
!>            aleatorios en la diagonal y X tiene condición sqrt(ULP).
!>
!>    ----------------------------------------------------------------------
!>
!>    Pruebas de Precisión:
!>       (1)  Verificar A * VR = VR * W
!>       (2)  Verificar A**H * VL = VL * W**H
!>       (3)  Verificar ||VR(i)|| = 1
!>       (4)  Verificar ||VL(i)|| = 1
!>       (5)  Verificar valores propios calculados con y sin vectores propios
!>       (6)  Verificar vectores propios derechos calculados con y sin
!>            vectores propios izquierdos y números de condición
!>       (7)  Verificar vectores propios izquierdos calculados con y sin
!>            vectores propios derechos y números de condición
!>       (8)  Verificar el equilibrio de la matriz
!>       (9)  Verificar los números recíprocos de condición de los vectores
!>            propios derechos
!>
!>    ----------------------------------------------------------------------
!>
!>    Pruebas de Números de Condición Recíprocos:
!>       RCONDE y RCONDV se calculan usando el algoritmo de Little
!>       and Web, con y sin el cálculo de los vectores propios.
!>
!>    ----------------------------------------------------------------------
!>
!>    Notas sobre las pruebas:
!>       Los tamaños de matriz y los tipos de matriz se especifican en
!>       los argumentos de entrada NN y DOTYPE.
!>       Se genera un número de semilla aleatoria de ISEED para cada prueba.
!>       El umbral THRESH se utiliza para determinar si las pruebas de
!>       precisión son exitosas.
!>       NIUNIT y NOUNIT son las unidades lógicas de entrada y salida para
!>       las pruebas de E/S de archivos.
!>       A, H, VL, VR, LRE, WORK, y IWORK son arrays de espacio de trabajo.
!>       Los resultados de la prueba se almacenan en RESULT.
!>       INFO indica el estado de la ejecución.
!>
!>    ----------------------------------------------------------------------
!>
!>    Ejemplo de uso:
!>
!>    Para probar todas las rutinas de valores propios no simétricos con
!>    tamaños de matriz 10 y 20, y todos los tipos de matriz del 1 al 4:
!>
!>    INTEGER NSZES, NTYPES, NN(2), INFO, NWORK
!>    LOGICAL DOTYPE(4)
!>    REAL THRESH, A(20,20), H(20,20), WR(20), WI(20), WR1(20), WI1(20)
!>    REAL VL(20,20), VR(20,20), LRE(20,20), RCONDV(20), RCNDV1(20)
!>    REAL RCDVIN(20), RCONDE(20), RCNDE1(20), RCDEIN(20)
!>    REAL SCALE(20), SCALE1(20), RESULT(11), WORK(400)
!>    INTEGER ISEED(4), IWORK(100)
!>
!>    NSZES = 2
!>    NN = (/10, 20/)
!>    NTYPES = 4
!>    DOTYPE = .TRUE., .TRUE., .TRUE., .TRUE.
!>    THRESH = 1.0E-6
!>    NIUNIT = 5
!>    NOUNTT = 6
!>    NWORK = 400
!>    ISEED = (/12345, 67890, 13579, 24680/)
!>
!>    CALL SDRVVX(NSZES, NN, NTYPES, DOTYPE, ISEED, THRESH, NIUNIT, NOUNTT,
!>                A, 20, H, 20, WR, WI, WR1, WI1, VL, 20, VR, 20,
!>                LRE, 20, RCONDV, RCNDV1, RCDVIN, RCONDE, RCNDE1,
!>                RCDEIN, SCALE, SCALE1, RESULT, WORK, NWORK, IWORK, INFO)
!>
!>    ----------------------------------------------------------------------
!>
!>    Condiciones de parámetros de entrada:
!>       - NSZES >= 0
!>       - Si NSZES > 0, entonces NN debe ser un array de tamaño NSZES.
!>       - NTYPES >= 0
!>       - Si NTYPES > 0, entonces DOTYPE debe ser un array de tamaño NTYPES.
!>       - THRESH debe ser positivo.
!>       - NIUNIT y NOUNIT deben ser unidades lógicas válidas.
!>       - LDA, LDVL, LDVR, LDLRE deben ser positivos y >= max(NN).
!>       - NWORK debe ser >= el tamaño mínimo requerido para WORK.
!>       - ISEED debe ser un array de tamaño 4.
!>       - IWORK debe ser un array de tamaño apropiado.
!>
!>    ----------------------------------------------------------------------
!>
!>    Comentarios:
!>       La subrutina SDRVVX está destinada a probar la rutina SGEEVX.
!>       Se genera una variedad de matrices de prueba, y se comparan los
!>       resultados de SGEEVX con los resultados conocidos o esperados.
!>       La subrutina imprime un resumen de los resultados de la prueba.
!>

(16) Matriz simétrica con valores propios elegidos aleatoriamente de ( ULP, 1 ) y entradas O(1) en el triángulo superior.

(17) Igual que (16), pero multiplicado por una constante cercana al umbral de desbordamiento.

(18) Igual que (16), pero multiplicado por una constante cercana al umbral de subdesbordamiento.

(19) Matriz no simétrica con entradas aleatorias elegidas de (-1,1). Si N es al menos 4, todas las entradas en las dos primeras filas y la última fila, y la primera columna y las dos últimas columnas son cero.

(20) Igual que (19), pero multiplicado por una constante cercana al umbral de desbordamiento.

(21) Igual que (19), pero multiplicado por una constante cercana al umbral de subdesbordamiento.

Además, se leerá un archivo de entrada de la unidad lógica NIUNIT. El archivo contiene matrices junto con valores propios precalculados y números de condición recíprocos para los valores propios y vectores propios derechos. Para estas matrices, además de las pruebas (1) a (9), calcularemos las siguientes dos pruebas:

(10) |RCONDV - RCDVIN| / cond(RCONDV)

RCONDV es el número de condición recíproco de los vectores propios derechos calculado por SGEEVX y RCDVIN (el valor verdadero precalculado) se suministra como entrada. cond(RCONDV) es el número de condición de RCONDV, y tiene en cuenta los errores en el cálculo de RCONDV, de modo que la cantidad resultante debería ser O(ULP). cond(RCONDV) está esencialmente dado por norm(A)/RCONDE.

(11) |RCONDE - RCDEIN| / cond(RCONDE)

RCONDE es el número de condición recíproco de los valores propios calculado por SGEEVX y RCDEIN (el valor verdadero precalculado) se suministra como entrada. cond(RCONDE) es el número de condición de RCONDE, y tiene en cuenta los errores en el cálculo de RCONDE, de modo que la cantidad resultante debería ser O(ULP). cond(RCONDE) está esencialmente dado por norm(A)/RCONDV.
