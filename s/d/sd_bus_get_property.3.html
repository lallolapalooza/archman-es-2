sd_bus_get_property(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_SET_PROPERTY(3) sd_bus_set_property SD_BUS_SET_PROPERTY(3)

NOMBRE

sd_bus_set_property, sd_bus_set_propertyv, sd_bus_get_property, sd_bus_get_property_trivial, sd_bus_get_property_string, sd_bus_get_property_strv - Establecer o consultar propiedades de servicios D-Bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_set_property(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, const char *type, ...);

int sd_bus_set_propertyv(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, const char *type, va_list ap);

int sd_bus_get_property(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, sd_bus_message **reply, const char *type);

int sd_bus_get_property_trivial(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, char type, void *ret_ptr);

int sd_bus_get_property_string(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, char **ret);

int sd_bus_get_property_strv(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, char ***ret);

DESCRIPCIÓN

Estas funciones establecen o consultan propiedades de D-Bus. Las propiedades de D-Bus son campos de servicio expuestos a través de la interfaz org.freedesktop.DBus.Properties. Bajo el capó, estas funciones llaman a métodos de la interfaz org.freedesktop.DBus.Properties y, como resultado, sus semánticas son similares a las de sd_bus_call_method(3).

sd_bus_set_property() establece una propiedad de D-Bus. Si el establecimiento de la propiedad falla o ocurre un error interno, se devuelve un error y se almacena opcionalmente una descripción extendida del error en ret_error si no es NULL. type y los argumentos que le siguen describen el nuevo valor de la propiedad y deben seguir el formato descrito en sd_bus_message_append(3).

sd_bus_set_propertyv() es equivalente a sd_bus_set_property(), excepto que se llama con una "va_list" en lugar de un número variable de argumentos.

sd_bus_get_property() consulta una propiedad de D-Bus. Si la recuperación de la propiedad falla o ocurre un error interno, se devuelve un error y se almacena opcionalmente una descripción extendida del error en ret_error si no es NULL. En caso de éxito, la propiedad se almacena en reply. type describe el tipo de propiedad y debe seguir el formato descrito en sd_bus_message_append(3).

sd_bus_get_property_trivial(), sd_bus_get_property_string() y sd_bus_get_property_strv() son atajos para sd_bus_get_property() que se utilizan para consultar propiedades básicas, de cadena y de vectores de cadenas, respectivamente. El llamador es responsable de liberar los resultados de cadena y vector de cadenas almacenados en ret por sd_bus_get_property_string() y sd_bus_get_property_strv().

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven un entero no negativo. En caso de error, devuelven un código de error negativo estilo errno.

Errores

Consulte la página del manual de sd_bus_call_method(3) para una lista de posibles errores.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_set_property(), sd_bus_set_propertyv(), sd_bus_get_property(), sd_bus_get_property_trivial(), sd_bus_get_property_string() y sd_bus_get_property_strv() se añadieron en la versión 246.
