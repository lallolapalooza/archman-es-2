NOMBRE

sd-json - APIs para tratar objetos JSON

SINOPSIS

#include <systemd/sd-json.h>

pkg-config --cflags --libs libsystemd

DESCRIPCIÓN

sd-json.h forma parte de libsystemd(3) y proporciona APIs para analizar, generar, formatear y operar de otra manera con objetos JSON.

La estructura de datos central de la API es JsonVariant, que encapsula un objeto JSON, un array, una cadena, un booleano, un número o un valor nulo. Estas estructuras de datos se consideran mayormente inmutables después de su construcción (es decir, su contenido no cambiará, pero algunos metadatos sí podrían hacerlo, como los contadores de referencia).

Las APIs se dividen ampliamente en cinco categorías:

•APIs para operar directamente con objetos JsonVariant, en el espacio de nombres sd_json_variant*.
•APIs para construir objetos JSON complejos, en el espacio de nombres sd_json_build*.
•APIs para mapear objetos JsonVariant y sus campos a campos coincidentes en estructuras C, en el espacio de nombres sd_json_dispatch*.
•APIs para convertir una representación de cadena de un objeto JSON en un objeto JsonVariant, en el espacio de nombres sd_json_parse*.
•APIs para convertir un objeto JsonVariant en su representación de cadena, en el espacio de nombres sd_json_format*.

Esta biblioteca JSON codificará internamente los números enteros JSON en el rango INT64_MIN...UINT64_MAX en enteros nativos de 64 bits con signo o sin signo, y los reproducirá sin pérdida de precisión. Los números no enteros se almacenan en números de punto flotante IEEE de 64 bits.

Si las funciones devuelven arrays de cadenas, estos son generalmente terminados en NULL y deben ser liberados por el llamador con la llamada free(3) de libc después de su uso, incluyendo las cadenas referenciadas en ellos. Del mismo modo, las cadenas individuales devueltas también deben ser liberadas.

Como excepción especial, en lugar de un array de cadenas vacío, se puede devolver NULL, que debe tratarse de forma equivalente a un array de cadenas vacío.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para multihilo. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
