SD_EVENT_SET_SIGNAL_EXIT(3) sd_event_set_signal_exit SD_EVENT_SET_SIGNAL_EXIT(3)

NOMBRE

sd_event_set_signal_exit - Salir automáticamente del bucle de eventos con SIGINT y SIGTERM

SINOPSIS

#include <systemd/sd-event.h>

int sd_event_set_signal_exit(sd_event *event, int b);

DESCRIPCIÓN

sd_event_set_signal_exit() se puede usar para asegurar que el bucle de eventos termine una vez que se reciba una señal SIGINT o SIGTERM. Es un envoltorio de conveniencia para las invocaciones de sd_event_add_signal(3) para ambas señales. Las dos señales se añaden automáticamente a la máscara de señales del hilo de llamadas (si un programa es multihilo, se debe tener cuidado de invocar esta función antes de que se inicie el primer hilo o de bloquear manualmente las dos señales en todo el proceso primero).

Si el parámetro b se especifica como verdadero, el bucle de eventos terminará con SIGINT y SIGTERM. Si se especifica como falso, ya no lo hará. Cuando esta funcionalidad se desactiva, la máscara de señales del hilo de llamadas se restaura para que coincida con el estado anterior a su activación, para las dos señales. Por defecto, las dos señales no son manejadas por el bucle de eventos, y está en vigor el manejo de señales predeterminado de Linux para ellas.

Es habitual que los programas UNIX salgan al recibir cualquiera de estas dos señales, por lo que normalmente es una buena idea habilitar esta funcionalidad para el bucle de eventos principal de un programa.

VALOR DE RETORNO

sd_event_set_signal_exit() devuelve un valor entero positivo no nulo cuando la configuración se cambió con éxito. Devuelve un cero cuando la configuración especificada ya estaba en vigor. En caso de error, devuelve un código de error negativo estilo errno(3).

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ECHILD

El bucle de eventos se ha creado en un proceso, biblioteca o instancia de módulo diferente.

Añadido en la versión 252.

-EINVAL

El objeto del bucle de eventos pasado no era válido.

Añadido en la versión 252.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_event_set_signal_exit() se añadió en la versión 252.
