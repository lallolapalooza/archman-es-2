Documentación de Función/Subrutina

subroutine sdrvsy (logical, dimension( * ) dotype, integer nn, integer, dimension( * ) nval, integer nrhs, real thresh, logical tsterr, integer nmax, real, dimension( * ) a, real, dimension( * ) afac, real, dimension( * ) ainv, real, dimension( * ) b, real, dimension( * ) x, real, dimension( * ) xact, real, dimension( * ) work, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer nout)

SDRVSY

Propósito:

!>
!> SDRVSY prueba las rutinas de controlador SSYSV y -SVX.
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LOGICAL, dimension (NTYPES)
!>          Los tipos de matrices a usar para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se usan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se usa.
!>

NN

!>          NN es un INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, dimension (NN)
!>          Los valores de la dimensión de la matriz N.
!>

NRHS

!>          NRHS es un INTEGER
!>          El número de vectores del lado derecho a generar para
!>          cada sistema lineal.
!>

THRESH

!>          THRESH es un REAL
!>          El valor umbral para las ratios de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para tener
!>          cada ratio de prueba impreso, usar THRESH = 0.
!>

TSTERR

!>          TSTERR es un LOGICAL
!>          Bandera que indica si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es un INTEGER
!>          El valor máximo permitido para N, usado en la dimensionamiento de los
!>          arrays de trabajo.
!>

A

!>          A es un array REAL, dimension (NMAX*NMAX)
!>

AFAC

!>          AFAC es un array REAL, dimension (NMAX*NMAX)
!>

AINV

!>          AINV es un array REAL, dimension (NMAX*NMAX)
!>

B

!>          B es un array REAL, dimension (NMAX*NRHS)
!>

X

!>          X es un array REAL, dimension (NMAX*NRHS)
!>

XACT

!>          XACT es un array REAL, dimension (NMAX*NRHS)
!>

WORK

!>          WORK es un array REAL, dimension (NMAX*max(2,NRHS))
!>

RWORK

!>          RWORK es un array REAL, dimension (NMAX+2*NRHS)
!>

IWORK

!>          IWORK es un array INTEGER, dimension (2*NMAX)
!>

NOUT

!>          NOUT es un INTEGER
!>          El número de unidad para la salida.
!>
