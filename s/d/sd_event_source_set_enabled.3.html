sd_event_source_set_enabled(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_EVENT_SOURCE_SET_ENABLED(3) sd_event_source_set_enabled SD_EVENT_SOURCE_SET_ENABLED(3)

NOMBRE

sd_event_source_set_enabled, sd_event_source_get_enabled, SD_EVENT_ON, SD_EVENT_OFF, SD_EVENT_ONESHOT - Habilitar o deshabilitar fuentes de eventos

SINOPSIS

#include <systemd/sd-event.h>
enum {
        SD_EVENT_OFF = 0,
        SD_EVENT_ON = 1,
        SD_EVENT_ONESHOT = -1,
};

int sd_event_source_set_enabled(sd_event_source *source, int enabled);

int sd_event_source_get_enabled(sd_event_source *source, int *ret);

DESCRIPCIÓN

sd_event_source_set_enabled() puede ser usado para habilitar o deshabilitar el objeto fuente de evento especificado como source. El parámetro enabled toma uno de SD_EVENT_ON (para habilitar), SD_EVENT_OFF (para deshabilitar) o SD_EVENT_ONESHOT. Si se invoca con SD_EVENT_ONESHOT la fuente de evento se habilitará pero se restablecerá automáticamente a SD_EVENT_OFF después de un despacho. Para SD_EVENT_OFF, la fuente de evento source puede ser NULL, en cuyo caso la función no hace nada. De lo contrario, source debe ser un puntero válido a un objeto sd_event_source.

Las fuentes de evento que están deshabilitadas no causarán despertares del bucle de eventos y no serán despachadas, hasta que se habiliten nuevamente.

sd_event_source_get_enabled() puede ser usado para consultar si el objeto fuente de evento source está actualmente habilitado o no. Si tanto source como el parámetro de salida ret son NULL, esta función devuelve falso. De lo contrario, source debe ser un puntero válido a un objeto sd_event_source. Si el parámetro de salida ret no es NULL, se establece en el estado de habilitación (uno de SD_EVENT_ON, SD_EVENT_OFF, SD_EVENT_ONESHOT). La función también devuelve verdadero si la fuente de evento no está deshabilitada.

Los objetos fuente de evento se habilitan cuando se crean por primera vez con llamadas como sd_event_add_io(3), sd_event_add_time(3). Sin embargo, dependiendo del tipo de fuente de evento, se habilitan continuamente (SD_EVENT_ON) o solo para una única invocación del manejador de la fuente de evento (SD_EVENT_ONESHOT). Para más detalles, consulte las páginas del manual respectivas.

Dado que los objetos fuente de evento permanecen activos y pueden ser despachados siempre que haya al menos una referencia a ellos, en muchos casos es una buena idea combinar una llamada a sd_event_source_unref(3) con una llamada previa a sd_event_source_set_enabled() con SD_EVENT_OFF, para asegurar que la fuente de evento no se despache nuevamente hasta que se descarten todas las demás referencias restantes.

VALOR DE RETORNO

En caso de éxito, sd_event_source_set_enabled() devuelve un entero no negativo. sd_event_source_get_enabled() devuelve cero si la fuente está deshabilitada (SD_EVENT_OFF) y un entero positivo en caso contrario. En caso de error, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

source no es un puntero válido a un objeto sd_event_source.

-ENOMEM

Memoria insuficiente.

-ECHILD

El bucle de eventos se ha creado en un proceso, biblioteca o instancia de módulo diferente.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_event_source_set_enabled() y sd_event_source_get_enabled() se añadieron en la versión 229.
