sd_bus_reply_method_return(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_REPLY_METHOD_RETURN(3) sd_bus_reply_method_return SD_BUS_REPLY_METHOD_RETURN(3)

NOMBRE

sd_bus_reply_method_return, sd_bus_reply_method_returnv - Responder a una llamada de método D-Bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_reply_method_return(sd_bus_message *call, const char *types, ...);

int sd_bus_reply_method_returnv(sd_bus_message *call, const char *types, va_list ap);

DESCRIPCIÓN

sd_bus_reply_method_return() envía una respuesta al mensaje call. La cadena de tipos types y los argumentos que la siguen deben cumplir el formato descrito en sd_bus_message_append(3). Si no se espera respuesta para call, esta función se completa sin enviar una respuesta.

VALOR DE RETORNO

En caso de éxito, esta función devuelve un entero no negativo. En caso de error, devuelve un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El parámetro de entrada call es **NULL**.

El mensaje call no es un mensaje de llamada a método.

El mensaje call no está adjunto a un bus.

El mensaje m no es un mensaje de respuesta de método.

Añadido en la versión 246.

-EPERM

El mensaje call ha sido sellado.

Añadido en la versión 246.

-ENOTCONN

El bus al que está adjunto el mensaje call no está conectado.

Añadido en la versión 246.

-ENOMEM

Error en la asignación de memoria.

Añadido en la versión 246.

Además, se pueden devolver cualesquiera errores devueltos por sd_bus_send(3).

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara no ser seguro para múltiples hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar las llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
