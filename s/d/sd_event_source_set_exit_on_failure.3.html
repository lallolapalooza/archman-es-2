sd_event_source_set_exit_on_failure(3)

SD_EVENT_SOURCE_SET_EXIT_ON_FAILURE(3) sd_event_source_set_exit_on_failure SD_EVENT_SOURCE_SET_EXIT_ON_FAILURE(3)

NOMBRE

sd_event_source_set_exit_on_failure, sd_event_source_get_exit_on_failure - Establecer o recuperar la función de salida en caso de fallo de las fuentes de eventos

SINOPSIS

#include <systemd/sd-event.h>

int sd_event_source_set_exit_on_failure(sd_event_source *source, int b);

int sd_event_source_get_exit_on_failure(sd_event_source *source);

DESCRIPCIÓN

sd_event_source_set_exit_on_failure() puede utilizarse para establecer/desactivar el indicador de salida en caso de fallo del objeto de fuente de eventos especificado como source. El indicador está desactivado por defecto. Si está activado y la función de devolución de llamada configurada para la fuente de eventos devuelve un código de fallo (es decir, un valor negativo), el bucle de eventos también se sale, utilizando el código de retorno de la devolución de llamada como código de salida para sd_event_exit(3). Si está desactivado, la fuente de eventos se deshabilita pero el bucle de eventos continúa ejecutándose. Establecer este indicador es útil para fuentes de eventos "dominantes" que definen el propósito y la razón del bucle de eventos, y cuyo fallo, por lo tanto, debería propagarse al propio bucle de eventos, a diferencia de las fuentes de eventos "auxiliares" cuyos fallos deben permanecer locales y afectar a la fuente de eventos, pero no propagarse más.

sd_event_source_get_exit_on_failure() puede utilizarse para consultar el indicador actualmente configurado para el objeto de fuente de eventos source.

VALOR DEVUELTO

En caso de éxito, sd_event_source_set_exit_on_failure() devuelve un entero no negativo. sd_event_source_get_exit_on_failure() devuelve 0 si el indicador está desactivado, > 0 si el indicador está activado. En caso de error, ambas devuelven un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

source no es un puntero válido a un objeto sd_event_source.

Añadido en la versión 247.

-EDOM

La fuente de eventos se refiere a una fuente de eventos de salida (como se crea con sd_event_add_exit(3)), para la cual esta funcionalidad no es compatible.

Añadido en la versión 247.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que está declarado como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_event_source_set_exit_on_failure() y sd_event_source_get_exit_on_failure() se añadieron en la versión 247.
