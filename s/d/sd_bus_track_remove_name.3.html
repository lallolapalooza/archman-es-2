sd_bus_track_remove_name(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_TRACK_ADD_NAME(3) sd_bus_track_add_name SD_BUS_TRACK_ADD_NAME(3)

NOMBRE

sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_remove_sender, sd_bus_track_count, sd_bus_track_count_sender, sd_bus_track_count_name, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next - Añadir, eliminar y recuperar pares de bus rastreados en un objeto de rastreo de pares de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(sd_bus_track* t, const char* name);

int sd_bus_track_add_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_remove_name(sd_bus_track* t, const char* name);

int sd_bus_track_remove_sender(sd_bus_track* t, sd_bus_message* message);

unsigned sd_bus_track_count(sd_bus_track* t);

int sd_bus_track_count_name(sd_bus_track* t, const char* name);

int sd_bus_track_count_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_contains(sd_bus_track* t, const char* name);

const char* sd_bus_track_first(sd_bus_track* t);

const char* sd_bus_track_next(sd_bus_track* t);

DESCRIPCIÓN

sd_bus_track_add_name() añade un par a rastrear a un objeto de rastreo de pares de bus. El primer argumento debe referirse a un objeto de rastreo de pares de bus creado con sd_bus_track_new(3), el segundo nombre debe referirse a un nombre de par de D-Bus a rastrear, ya sea en formato de servicio conocido o único. Si el nombre no se está rastreando todavía, se añadirá a la lista de nombres a rastrear. Si ya se está rastreando y el modo no recursivo está activado, no se ejecuta ninguna operación en esta llamada. Si el modo recursivo está activado, un contador por nombre se incrementa en uno cada vez que se invoca esta llamada, y sd_bus_track_remove_name() debe ser llamada tantas veces como se invocó sd_bus_track_add_name() antes para detener el rastreo del nombre. Utilice sd_bus_track_set_recursive(3) para cambiar del modo no recursivo por defecto al modo recursivo, o viceversa. Tenga en cuenta que el nombre especificado se rastrea tal cual, los nombres conocidos no se resuelven a nombres únicos mediante esta llamada. Tenga en cuenta que múltiples objetos de rastreo de pares de bus pueden rastrear el mismo nombre.

sd_bus_track_remove_name() deshace el efecto de sd_bus_track_add_name() y elimina un nombre de par de bus de la lista de pares a vigilar. Dependiendo de si el modo no recursivo o recursivo está activado para el objeto de rastreo de pares de bus, esta llamada eliminará el nombre completamente del objeto de rastreo, o simplemente decrementará el contador por nombre en uno, eliminando el nombre solo cuando el contador llegue a cero (ver arriba). Tenga en cuenta que un par de bus que se desconecta del bus eliminará implícitamente sus nombres completamente del objeto de rastreo de pares de bus, independientemente del contador actual por nombre.

sd_bus_track_add_sender() y sd_bus_track_remove_sender() son similares a sd_bus_track_add_name() y sd_bus_track_remove_name() pero toman un mensaje de bus como argumento. Se determina el remitente de este mensaje de bus y se añade/elimina del objeto de rastreo de pares de bus. Como los mensajes se originan siempre de nombres únicos, y nunca de nombres conocidos, esto significa que esta llamada efectivamente solo añadirá nombres únicos al objeto de rastreo de pares de bus.

sd_bus_track_count() devuelve el número de nombres que están siendo rastreados actualmente por el objeto de rastreo de pares de bus especificado. Tenga en cuenta que esta función siempre devuelve el número real de nombres rastreados y, por lo tanto, si sd_bus_track_add_name() se ha invocado varias veces para el mismo nombre, solo se cuenta como uno, independientemente de si se utiliza el modo recursivo o no.

sd_bus_track_count_name() devuelve el contador actual por nombre para el nombre especificado. Si se utiliza el modo no recursivo, devuelve 1 o 0, dependiendo de si el nombre especificado se ha añadido o no previamente al objeto de rastreo. Si se ha activado el modo recursivo, también pueden devolverse valores mayores que 1, en caso de que sd_bus_track_add_name() se haya llamado varias veces para el mismo nombre.

sd_bus_track_count_sender() es similar a sd_bus_track_count_name(), pero toma un objeto de mensaje de bus y devuelve el contador por nombre que coincide con el remitente del mensaje.

sd_bus_track_contains() puede utilizarse para determinar si el nombre especificado se ha añadido al menos una vez al objeto de rastreo de pares de bus especificado.

sd_bus_track_first() y sd_bus_track_next() pueden utilizarse para enumerar todos los nombres que están siendo rastreados actualmente por el objeto de rastreo de pares de bus pasado. sd_bus_track_first() devuelve la primera entrada del objeto y reinicia un índice de lectura mantenido internamente. Cada invocación subsiguiente de sd_bus_track_next() devuelve el siguiente nombre contenido en el objeto de bus. Si se alcanza el final, se devuelve NULL. Si no se ha añadido ningún nombre al objeto todavía, sd_bus_track_first() devolverá NULL inmediatamente. El orden en que se devuelven los nombres no está definido; en particular, no está definido qué nombre se considera el primero devuelto. Si el modo recursivo está activado y el mismo nombre se ha añadido varias veces al objeto de rastreo de pares de bus, solo se devuelve una vez en esta enumeración. Si se añaden nuevos nombres o se eliminan nombres existentes del objeto de rastreo de pares de bus mientras se está enumerando, la enumeración finaliza en la siguiente invocación de sd_bus_track_next() ya que se devuelve NULL.

VALOR DE RETORNO

En caso de éxito, sd_bus_track_add_name() y sd_bus_track_add_sender() devuelven 0 si el nombre especificado ya se ha añadido previamente al objeto de rastreo de pares de bus y un valor positivo si no lo ha hecho. En caso de error, devuelven un código de error negativo al estilo errno.

sd_bus_track_remove_name() y sd_bus_track_remove_sender() devuelven un valor positivo si el nombre especificado fue rastreado previamente por el objeto de rastreo de pares de bus y ahora ha sido eliminado. En modo no recursivo, se devuelve 0 si el nombre especificado no estaba siendo rastreado todavía. En modo recursivo, se devuelve -EUNATCH en este caso. En caso de error, devuelven un código de error negativo al estilo errno.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente, o 0 en caso de error.

sd_bus_track_count_name() y sd_bus_track_count_sender() devuelven el contador actual por nombre para el nombre especificado o el remitente del mensaje especificado. Se devuelve cero para los nombres que aún no se están rastreando, un valor positivo para los nombres añadidos al menos una vez. Valores mayores que 1 solo se devuelven en modo recursivo. En caso de error, se devuelve un código de error negativo al estilo errno.

sd_bus_track_contains() devuelve el nombre pasado si existe en el objeto de rastreo de pares de bus. En caso de error, y si el nombre no se ha añadido todavía, se devuelve NULL.

sd_bus_track_first() y sd_bus_track_next() devuelven el primer/siguiente nombre contenido en el objeto de rastreo de pares de bus, y NULL si se alcanza el final de la enumeración y en caso de error.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EUNATCH

sd_bus_track_remove_name() o sd_bus_track_remove_sender() han sido invocadas para un nombre no añadido previamente al objeto de par de bus.

-EINVAL

El parámetro especificado es inválido.

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

DESCRIPTION

These functions operate on a sd_bus_track object, which is a collection of bus names and/or sender names. A bus name is a service name like org.freedesktop.Notifications. A sender name is the unique bus name of a client, like :1.10. Bus names are managed by the bus daemon, while sender names are assigned dynamically when a client connects.

sd_bus_track_new(3) creates a new, empty track object. sd_bus_track_add_name() adds the bus name name to the track object track. sd_bus_track_add_sender() adds the sender name sender to the track object track. It is possible to add both bus names and sender names to the same track object.

sd_bus_track_remove_name() removes the bus name name from the track object track. sd_bus_track_remove_sender() removes the sender name sender from the track object track. If the name/sender is not present in the track, these functions have no effect.

sd_bus_track_count() returns the total number of bus names and sender names currently in the track. sd_bus_track_count_name() returns the number of bus names in the track. sd_bus_track_count_sender() returns the number of sender names in the track.

sd_bus_track_contains() checks if the track object track contains the bus name name. It returns one if the name is present, and zero otherwise. It only checks for bus names, not sender names.

The functions sd_bus_track_first() and sd_bus_track_next() may be used to iterate over all the entries (both bus names and sender names) in a track. sd_bus_track_first() returns a pointer to the first entry, or NULL if the track is empty. sd_bus_track_next() takes a pointer to an entry and returns a pointer to the next entry, or NULL if it was the last entry. The returned pointers are of type sd_bus_track_entry_t *. The actual name/sender string may be accessed via the name field of the sd_bus_track_entry_t structure.

A track object is useful for keeping track of a set of services or clients, for example, to monitor them for availability. For instance, sd_bus_add_match(3) can take a track object to register a set of match rules for all services that match the names in the track.

The track object is passed to sd_bus_add_match(3) and sd_bus_add_filter(3). The track object will be updated by the bus daemon if the services tracked appear or disappear. Callbacks registered via sd_bus_add_watch_for_change(3) will be invoked when the track object's contents change.

It is possible to add a bus name to a track object multiple times, or add the same sender name multiple times. The sd_bus_track_count* functions will count each occurrence. However, iteration with sd_bus_track_first() / sd_bus_track_next() will only yield each unique name once.

Track objects should be destroyed with sd_bus_track_unref(3).

RETURN VALUE

sd_bus_track_add_name(), sd_bus_track_add_sender(), sd_bus_track_remove_name(), and sd_bus_track_remove_sender() return 0 on success, or a negative errno value on failure.

sd_bus_track_count(), sd_bus_track_count_name(), and sd_bus_track_count_sender() return the number of items in the track.

sd_bus_track_contains() returns 1 if the name is found, 0 otherwise.

sd_bus_track_first() returns a pointer to the first entry or NULL.

sd_bus_track_next() returns a pointer to the next entry or NULL.

NOTES

All these functions may be called from an early phase of the program when no other threads have been started.
