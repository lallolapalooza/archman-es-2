NOMBRE

sd_bus_pending_method_calls - Devuelve el número de llamadas a método salientes pendientes actualmente

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_pending_method_calls(sd_bus *bus);

DESCRIPCIÓN

sd_bus_pending_method_calls() devuelve el número de llamadas a método salientes pendientes actualmente, es decir, llamadas a método encoladas con sd_bus_call_async(3) para las que aún no se ha recibido respuesta y que aún no han alcanzado un tiempo de espera.

El argumento bus puede ser NULL, en cuyo caso se devuelve cero.

VALOR DE RETORNO

Esta función devuelve 0 si no hay llamadas a método pendientes o si se especificó un objeto bus NULL. En caso de error, se devuelve un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ECHILD

La conexión del bus se ha creado en un proceso, biblioteca o instancia de módulo diferente.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos (thread-safe). Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_pending_method_calls() se añadió en la versión 257.
