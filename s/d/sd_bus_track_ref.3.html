SD_BUS_TRACK_NEW(3) sd_bus_track_new SD_BUS_TRACK_NEW(3)

NOMBRE

sd_bus_track_new, sd_bus_track_ref, sd_bus_track_unref, sd_bus_track_unrefp, sd_bus_track_set_recursive, sd_bus_track_get_recursive, sd_bus_track_get_bus, sd_bus_track_get_userdata, sd_bus_track_set_userdata - Rastrear pares del bus

SINOPSIS

#include <systemd/sd-bus.h>

typedef int (*sd_bus_track_handler_t)(sd_bus_track *track, void *userdata);

int sd_bus_track_new(sd_bus* bus, sd_bus_track** ret, sd_bus_track_handler_t handler, void* userdata);

sd_bus_track *sd_bus_track_ref(sd_bus_track *t);

sd_bus_track *sd_bus_track_unref(sd_bus_track *t);

void sd_bus_track_unrefp(sd_bus_track **t);

int sd_bus_track_get_recursive(sd_bus_track *t);

int sd_bus_track_set_recursive(sd_bus_track *t, int b);

sd_bus* sd_bus_track_get_bus(sd_bus_track *t);

void* sd_bus_track_get_userdata(sd_bus_track *t);

void* sd_bus_track_set_userdata(sd_bus_track *t, void *userdata);

DESCRIPCIÓN

sd_bus_track_new() crea un nuevo objeto de rastreo de pares del bus. El objeto se asigna para el bus especificado y se devuelve en el parámetro *ret. Después de su uso, el objeto debe liberarse nuevamente soltando la referencia adquirida con sd_bus_track_unref() (ver abajo). Un objeto de rastreo de pares del bus puede usarse para hacer un seguimiento de los pares en un bus IPC específico, para casos en los que los pares hacen uso de uno o más objetos locales, a fin de controlar el ciclo de vida de los objetos locales y asegurar que permanezcan activos mientras los pares que los necesitan estén presentes, y se desreferencien (y posiblemente se destruyan) tan pronto como todos los pares relevantes hayan desaparecido. Cada objeto de rastreo de pares del bus puede usarse para rastrear cero, uno o más pares a la vez. Las referencias a pares específicos del bus se agregan a través de sd_bus_track_add_name(3) o sd_bus_track_add_sender(). Pueden eliminarse nuevamente a través de sd_bus_track_remove_name() y sd_bus_track_remove_sender(). Alternativamente, las referencias a los pares se eliminan automáticamente cuando se desconectan del bus. Si no es NULL, el handler puede especificar una función que se invoca cada vez que se suelta la última referencia, independientemente de si la referencia se suelta explícitamente a través de sd_bus_track_remove_name() o implícitamente porque el par se desconectó del bus. El argumento final userdata puede usarse para adjuntar un puntero de datos de usuario genérico al objeto. Este puntero se pasa a la función de devolución de llamada del manejador cuando se invoca.

sd_bus_track_ref() crea una nueva referencia a un objeto de rastreo de pares del bus. Este objeto no se destruirá hasta que se haya llamado a sd_bus_track_unref() tantas veces más una. Una vez que el recuento de referencias ha caído a cero, el objeto especificado ya no puede usarse; las llamadas posteriores a sd_bus_track_ref() o sd_bus_track_unref() sobre el mismo objeto son ilegales.

sd_bus_track_unref() destruye una referencia a un objeto de rastreo de pares del bus.

sd_bus_track_unrefp() es similar a sd_bus_track_unref() pero toma un puntero a un puntero a un objeto sd_bus_track. Esta llamada es útil en conjunción con el **Atributo de Variable de Limpieza**[1] de GCC y LLVM. Tenga en cuenta que esta función se define como una función en línea.

sd_bus_track_ref(), sd_bus_track_unref() y sd_bus_track_unrefp() no realizan ninguna operación si el objeto de rastreo de pares del bus pasado es NULL.

Los objetos de rastreo de pares del bus pueden existir en dos modos: por defecto operan en modo no recursivo, pero opcionalmente pueden cambiarse al modo recursivo. Si se opera en el modo no recursivo por defecto, un par se rastrea o no se rastrea. En este modo, invocar sd_bus_track_add_name() varias veces seguidas para el mismo par es completamente equivalente a llamarlo solo una vez, ya que la llamada agrega el par al conjunto de pares rastreados si es necesario y no realiza ninguna operación si el par ya está siendo rastreado. Una única invocación de sd_bus_track_remove_name() elimina la referencia al par nuevamente, independientemente de cuántas veces se llamó a sd_bus_track_add_name() antes. Si se opera en modo recursivo, el número de veces que se invoca sd_bus_track_add_name() para el mismo nombre de par se cuenta y debe llamarse a sd_bus_track_remove_name() el mismo número de veces antes de que el par no sea rastreado, con la excepción de cuando el par rastreado desaparece del bus, en cuyo caso el recuento es irrelevante y el rastreo del par específico se elimina inmediatamente. sd_bus_track_get_recursive() puede usarse para determinar si el objeto de rastreo de pares del bus está operando en modo recursivo. sd_bus_track_set_recursive() puede usarse para habilitar o deshabilitar el modo recursivo. Por defecto, un objeto de rastreo de pares del bus opera en modo no recursivo, y sd_bus_track_get_recursive() para un objeto recién asignado, por lo tanto, devuelve un valor igual a cero. Use sd_bus_track_set_recursive() para habilitar el modo recursivo, justo después de la asignación. Toma un argumento booleano para habilitar o deshabilitar el modo recursivo. Tenga en cuenta que los objetos de rastreo para los cuales ya se ha invocado sd_bus_track_add_name() al menos una vez (y que por lo tanto rastrean ya uno o más pares) ya no pueden cambiarse de modo recursivo a no recursivo.

sd_bus_track_get_bus() devuelve el objeto del bus al que pertenece el objeto de rastreo de pares del bus. Devuelve el objeto del bus pasado inicialmente a sd_bus_track_new() cuando se asignó el objeto.

sd_bus_track_get_userdata() devuelve el puntero de datos de usuario genérico establecido en el objeto de rastreo de pares del bus en el momento de la creación utilizando sd_bus_track_new() o en un momento posterior, utilizando sd_bus_track_set_userdata().

VALOR DE RETORNO

En caso de éxito, sd_bus_track_new() y sd_bus_track_set_recursive() devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo de estilo errno.

sd_bus_track_ref() siempre devuelve el argumento.

sd_bus_track_unref() siempre devuelve NULL.

sd_bus_track_get_recursive() devuelve 0 si se selecciona el modo no recursivo (por defecto), y mayor que 0 si se selecciona el modo recursivo. En caso de error, se devuelve un código de error negativo de estilo errno.

sd_bus_track_get_bus() devuelve el objeto del bus asociado al objeto de rastreo de pares del bus.

sd_bus_track_get_userdata() devuelve el puntero de datos de usuario genérico asociado con el objeto de rastreo de pares del bus. sd_bus_track_set_userdata() devuelve el puntero de datos de usuario anteriormente establecido.

PROPIEDAD DE REFERENCIA

La función sd_bus_track_new() crea un nuevo objeto y el llamador posee la única referencia. Cuando ya no se necesite, esta referencia debe destruirse con sd_bus_track_unref().

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EBUSY

Ya se han agregado pares del bus al objeto de rastreo de pares del bus y se llamó a sd_bus_track_set_recursive() para cambiar el modo de rastreo.

-EINVAL

El parámetro especificado es inválido (NULL en caso de parámetros de salida).

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

La funcionalidad de rastreo de pares del bus se introdujo en systemd versión 237.

NAME

sd_bus_track_ref, sd_bus_track_unref, sd_bus_track_unrefp, sd_bus_track_get_recursive, sd_bus_track_set_recursive, sd_bus_track_get_bus, sd_bus_track_get_userdata, sd_bus_track_set_userdata - Gestionar la referencia del bus de rastreo

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_ref(sd_bus_track *track);
int sd_bus_track_unref(sd_bus_track *track);
int sd_bus_track_unrefp(sd_bus_track **trackp);
int sd_bus_track_get_recursive(sd_bus_track *track);
int sd_bus_track_set_recursive(sd_bus_track *track, int recursive);
sd_bus *sd_bus_track_get_bus(sd_bus_track *track);
void *sd_bus_track_get_userdata(sd_bus_track *track);
int sd_bus_track_set_userdata(sd_bus_track *track, void *userdata);

DESCRIPTION

sd_bus_track_ref() incrementa el contador de referencias del objeto de rastreo de bus especificado por track. sd_bus_track_unref() decrementa el contador de referencias del objeto de rastreo de bus especificado por track. sd_bus_track_unrefp() es similar a sd_bus_track_unref(), pero también establece el puntero trackp a NULL si la desreferencia resulta en la liberación del objeto.

El objeto de rastreo se libera tan pronto como su contador de referencias llega a cero. Las llamadas a sd_bus_track_unref() y sd_bus_track_unrefp() pueden liberar el objeto de rastreo y, por lo tanto, todos los punteros a él se vuelven inválidos.

sd_bus_track_get_recursive() devuelve si el objeto de rastreo está configurado para rastrear recursivamente las llamadas de métodos y las señales provenientes de otros objetos de rastreo en el mismo bus. Véase sd_bus_track_new(3) para más detalles.

sd_bus_track_set_recursive() configura la bandera recursiva del objeto de rastreo. Si recursive es distinto de cero, el rastreo se vuelve recursivo.

sd_bus_track_get_bus() devuelve el bus de bajo nivel sd_bus al que está asociado este objeto de rastreo.

sd_bus_track_get_userdata() devuelve el dato de usuario arbitrario que se asoció previamente con este objeto de rastreo usando sd_bus_track_set_userdata().

sd_bus_track_set_userdata() establece el dato de usuario arbitrario userdata para el objeto de rastreo. Esto no tiene ningún efecto en el ciclo de vida del objeto de rastreo.

RETURN VALUE

sd_bus_track_ref() devuelve 0 si tiene éxito, o un número negativo en caso de error.

sd_bus_track_unref() y sd_bus_track_unrefp() devuelven el valor del contador de referencias después de la desreferencia.

sd_bus_track_get_recursive() devuelve el valor de la bandera recursiva (1 o 0).

sd_bus_track_set_recursive() devuelve 0 si tiene éxito, o un número negativo en caso de error.

sd_bus_track_get_bus() devuelve el bus asociado, o NULL.

sd_bus_track_get_userdata() devuelve los datos de usuario establecidos previamente, o NULL.

sd_bus_track_set_userdata() devuelve 0 si tiene éxito, o un número negativo en caso de error.

REFERENCE OWNERSHIP

Las funciones sd_bus_track_*() utilizan el modelo de recuento de referencias. Las funciones que devuelven un nuevo objeto (como sd_bus_track_new(3)) le otorgan la propiedad de una referencia. Las funciones que toman un objeto como argumento esperan que la propiedad de referencia se mantenga o se otorge (como sd_bus_track_ref()). Finalmente, las funciones que desreferencian un objeto (como sd_bus_track_unref()) asumen que la propiedad se está renunciando, y liberarán el objeto cuando el recuento de referencias llegue a cero. Véase sd_bus_ref(3) para más detalles sobre la propiedad de referencia.

NOTES

El campo userdata se inicializa a NULL. No se llama a ninguna función de liberación para este campo cuando se libera el objeto de rastreo.

El campo recursive se inicializa a 0 (no recursivo).

Los objetos de rastreo son seguros para hilos. Es seguro llamar a sd_bus_track_ref() y sd_bus_track_unref() desde múltiples hilos concurrentemente.
