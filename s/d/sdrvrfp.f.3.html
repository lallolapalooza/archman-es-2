SDRVRFP

Propósito:

!>
!> SDRVRFP prueba las rutinas RFP de LAPACK:
!>     SPFTRF, SPFTRS, y SPFTRI.
!>
!> Esta rutina de prueba sigue las mismas pruebas que DDRVPO (prueba para el
!> solver de formato completo Simétrico Definido Positivo).
!>
!> Las pruebas se realizan en Formato Completo, la conversión de ida y vuelta
!> desde formato completo a formato RFP se realiza utilizando las rutinas STRTTF y
!> STFTTR.
!>
!> Primero, se crea una matriz A específica de tamaño N. Hay nueve tipos de
!> matrices diferentes posibles.
!>  1. Diagonal                        6. Aleatoria, CNDNUM = sqrt(0.1/EPS)
!>  2. Aleatoria, CNDNUM = 2              7. Aleatoria, CNDNUM = 0.1/EPS
!> *3. Primera fila y columna cero       8. Escalada cerca del subdesbordamiento
!> *4. Última fila y columna cero        9. Escalada cerca del desbordamiento
!> *5. Fila y columna central cero
!> (* - prueba las salidas de error de SPFTRF, no se calculan ratios de prueba)
!> Se crea una solución XACT de tamaño N-por-NRHS y el lado derecho asociado B.
!> Luego se llama a SPFTRF para calcular L (o U), el factor de Cholesky de A.
!> Luego L (o U) se utiliza para resolver el sistema lineal de ecuaciones
!> AX = B. Esto da X. Luego L (o U) se utiliza para calcular la inversa de A,
!> AINV. Luego se realizan las siguientes cuatro pruebas:
!> (1) norm( L*L' - A ) / ( N * norm(A) * EPS ) o
!>     norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> (2) norm(B - A*X) / ( norm(A) * norm(X) * EPS ),
!> (3) norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> (4) ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS ),
!> donde EPS es la precisión de la máquina, RCOND es el número de condición de A, y
!> norm( . ) es la norma 1 para (1,2,3) y la norma infinito para (4).
!> Ocurren errores cuando el parámetro INFO no es el esperado. Fallan cuando
!> un ratio de prueba es mayor que THRES.
!>

!>                El número de valores de NRHS contenidos en el vector NSVAL.
