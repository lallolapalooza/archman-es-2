sd_bus_track_add_name(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_TRACK_ADD_NAME(3) sd_bus_track_add_name SD_BUS_TRACK_ADD_NAME(3)

NOMBRE

sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_remove_sender, sd_bus_track_count, sd_bus_track_count_sender, sd_bus_track_count_name, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next - Añadir, eliminar y recuperar pares de buses rastreados en un objeto de rastreo de pares de buses

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(sd_bus_track* t, const char* name);

int sd_bus_track_add_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_remove_name(sd_bus_track* t, const char* name);

int sd_bus_track_remove_sender(sd_bus_track* t, sd_bus_message* message);

unsigned sd_bus_track_count(sd_bus_track* t);

int sd_bus_track_count_name(sd_bus_track* t, const char* name);

int sd_bus_track_count_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_contains(sd_bus_track* t, const char* name);

const char* sd_bus_track_first(sd_bus_track* t);

const char* sd_bus_track_next(sd_bus_track* t);

DESCRIPCIÓN

sd_bus_track_add_name() añade un par para rastrear a un objeto de rastreo de pares de buses. El primer argumento debe referirse a un objeto de rastreo de pares de buses creado con sd_bus_track_new(3), el segundo nombre debe referirse a un nombre de par de D-Bus para rastrear, en formato de servicio conocido o único. Si el nombre aún no está siendo rastreado, se añadirá a la lista de nombres a rastrear. Si ya está siendo rastreado y el modo no recursivo está habilitado, esta llamada no ejecutará ninguna operación. Si el modo recursivo está habilitado, un contador por nombre se incrementará en uno cada vez que se invoque esta llamada, y sd_bus_track_remove_name() tendrá que ser llamada tantas veces como sd_bus_track_add_name() haya sido invocada antes para detener el rastreo del nombre. Utilice sd_bus_track_set_recursive(3) para cambiar del modo no recursivo por defecto al modo recursivo, o viceversa. Tenga en cuenta que el nombre especificado se rastrea tal como está, los nombres conocidos no se resuelven a nombres únicos por esta llamada. Tenga en cuenta que múltiples objetos de rastreo de pares de buses pueden rastrear el mismo nombre.

sd_bus_track_remove_name() deshace el efecto de sd_bus_track_add_name() y elimina un nombre de par de bus de la lista de pares a vigilar. Dependiendo de si el modo no recursivo o recursivo está habilitado para el objeto de rastreo de pares de buses, esta llamada eliminará el nombre completamente del objeto de rastreo, o simplemente decrementará el contador por nombre en uno, eliminando el nombre solo cuando el contador llegue a cero (ver arriba). Tenga en cuenta que un par de bus que se desconecta del bus eliminará implícitamente sus nombres completamente del objeto de rastreo de pares de buses, independientemente del contador actual por nombre.

sd_bus_track_add_sender() y sd_bus_track_remove_sender() son similares a sd_bus_track_add_name() y sd_bus_track_remove_name() pero toman un mensaje de bus como argumento. Se determina el remitente de este mensaje de bus y se añade/elimina del objeto de rastreo de pares de buses. Como los mensajes siempre se originan de nombres únicos, y nunca de nombres conocidos, esto significa que esta llamada efectivamente solo añadirá nombres únicos al objeto de rastreo de pares de buses.

sd_bus_track_count() devuelve el número de nombres que están siendo rastreados actualmente por el objeto de rastreo de pares de buses especificado. Tenga en cuenta que esta función siempre devuelve el número real de nombres rastreados, y por lo tanto, si sd_bus_track_add_name() ha sido invocada múltiples veces para el mismo nombre, solo se cuenta como uno, independientemente de si se usa el modo recursivo o no.

sd_bus_track_count_name() devuelve el contador actual por nombre para el nombre especificado. Si se usa el modo no recursivo, devuelve 1 o 0, dependiendo de si el nombre especificado ha sido añadido previamente al objeto de rastreo, o no. Si se ha habilitado el modo recursivo, también se pueden devolver valores mayores que 1, en caso de que sd_bus_track_add_name() se haya llamado múltiples veces para el mismo nombre.

sd_bus_track_count_sender() es similar a sd_bus_track_count_name(), pero toma un objeto de mensaje de bus y devuelve el contador por nombre que coincide con el remitente del mensaje.

sd_bus_track_contains() se puede utilizar para determinar si el nombre especificado se ha añadido al menos una vez al objeto de rastreo de pares de buses especificado.

sd_bus_track_first() y sd_bus_track_next() pueden utilizarse para enumerar todos los nombres que están siendo rastreados actualmente por el objeto de rastreo de pares de buses pasado. sd_bus_track_first() devuelve la primera entrada en el objeto y restablece un índice de lectura mantenido internamente. Cada invocación subsiguiente de sd_bus_track_next() devuelve el siguiente nombre contenido en el objeto de bus. Si se alcanza el final, se devuelve NULL. Si aún no se han añadido nombres al objeto, sd_bus_track_first() devolverá NULL inmediatamente. El orden en que se devuelven los nombres no está definido; en particular, qué nombre se considera el primero devuelto no está definido. Si el modo recursivo está habilitado y el mismo nombre se ha añadido múltiples veces al objeto de rastreo de pares de buses, solo se devuelve una vez en esta enumeración. Si se añaden nuevos nombres o se eliminan nombres existentes del objeto de rastreo de pares de buses mientras se está enumerando, la enumeración termina en la próxima invocación de sd_bus_track_next() ya que se devuelve NULL.

VALOR DE RETORNO

En caso de éxito, sd_bus_track_add_name() y sd_bus_track_add_sender() devuelven 0 si el nombre especificado ya se había añadido previamente al objeto de rastreo de pares de buses y positivo si no ha sido así. En caso de error, devuelven un código de error negativo estilo errno.

sd_bus_track_remove_name() y sd_bus_track_remove_sender() devuelven positivo si el nombre especificado estaba previamente rastreado por el objeto de rastreo de pares de buses y ahora ha sido eliminado. En modo no recursivo, se devuelve 0 si el nombre especificado aún no estaba siendo rastreado. En modo recursivo, se devuelve -EUNATCH en este caso. En caso de error, devuelven un código de error negativo estilo errno.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente, o 0 en caso de error.

sd_bus_track_count_name() y sd_bus_track_count_sender() devuelven el contador actual por nombre para el nombre especificado o el remitente del mensaje especificado. Se devuelve cero para nombres que aún no se están rastreando, un valor positivo para nombres añadidos al menos una vez. Valores mayores que 1 solo se devuelven en modo recursivo. En caso de error, se devuelve un código de error negativo estilo errno.

sd_bus_track_contains() devuelve el nombre pasado si existe en el objeto de rastreo de pares de buses. En caso de error, y si el nombre aún no se ha añadido, se devuelve NULL.

sd_bus_track_first() y sd_bus_track_next() devuelven el primer/siguiente nombre contenido en el objeto de rastreo de pares de buses, y NULL si se alcanza el final de la enumeración y en caso de error.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EUNATCH

Se ha invocado sd_bus_track_remove_name() o sd_bus_track_remove_sender() para un nombre no añadido previamente al objeto de par de bus.

-EINVAL

El parámetro especificado es inválido.

-ENOMEM

Fallo en la asignación de memoria.
