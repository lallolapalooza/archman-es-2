#include <systemd/sd-bus.h>

int sd_bus_set_description(sd_bus *bus, const char *description);

int sd_bus_get_description(sd_bus *bus, const char **description);

int sd_bus_set_anonymous(sd_bus *bus, int b);

int sd_bus_set_trusted(sd_bus *bus, int b);

int sd_bus_is_trusted(sd_bus *bus);

int sd_bus_set_allow_interactive_authorization(sd_bus *bus, int b);

int sd_bus_get_tid(sd_bus *bus, pid_t *tid);

int sd_bus_get_unique_name(sd_bus *bus, const char **unique);

DESCRIPCIÓN

sd_bus_set_description() establece la cadena de descripción que se utiliza en el registro en la cadena especificada. La cadena se copia internamente y se libera cuando se desasigna el objeto bus. El argumento description puede ser NULL, en cuyo caso la descripción se desactiva. Esta función debe llamarse antes de que el bus se inicie.

sd_bus_get_description() devuelve una cadena de descripción en description. Esta cadena puede haber sido establecida previamente con sd_bus_set_description() o sd_bus_open_with_description(3) o similar. Si no se establece de esta manera, se devolverá una cadena predeterminada como "system" o "user" para los buses del sistema o del usuario, y -ENXIO en caso contrario.

sd_bus_set_anonymous() habilita o deshabilita la "autenticación anónima", es decir, la falta de autenticación, del par del bus. Esta función debe llamarse antes de que el bus se inicie. Consulte la sección Mecanismos de Autenticación de D-Bus[1] de la especificación D-Bus para obtener más detalles.

sd_bus_is_anonymous() devuelve verdadero si la conexión del bus permite la autenticación anónima (en el sentido descrito en el párrafo anterior).

sd_bus_set_trusted() establece el estado "confiable" en el objeto bus. Si es verdadero, todas las conexiones en el bus son confiables y se concede acceso a todos los métodos privilegiados y no privilegiados. Esta función debe llamarse antes de que el bus se inicie.

sd_bus_is_trusted() devuelve verdadero si la conexión del bus es confiable (en el sentido descrito en el párrafo anterior).

sd_bus_set_allow_interactive_authorization() habilita o deshabilita la autorización interactiva para las llamadas a métodos. Si es verdadero, los mensajes se marcan con la bandera ALLOW_INTERACTIVE_AUTHORIZATION especificada por la especificación D-Bus[2], informando al lado receptor que el llamador está preparado para esperar la autorización interactiva, que puede tardar un tiempo considerable en completarse. Si esta bandera está establecida, al usuario se le pueden solicitar contraseñas o confirmación a través de polkit[3] o un marco similar.

sd_bus_get_allow_interactive_authorization() devuelve verdadero si se permite la autorización interactiva y falso si no.

sd_bus_get_scope() almacena el ámbito del objeto bus dado en scope. El ámbito del bus del sistema es "system". El ámbito de un bus de sesión de usuario es "user". Si el objeto bus dado no es el bus del sistema o un bus de sesión de usuario, sd_bus_get_scope() devuelve un error.

sd_bus_get_tid() almacena el id. de hilo del kernel del hilo asociado con el objeto bus dado en tid. Si bus es un objeto bus predeterminado obtenido llamando a una de las funciones de la familia sd_bus_default(3), almacena el id. de hilo del hilo en el que se creó el objeto bus. De lo contrario, si el objeto bus está adjunto a un bucle de eventos, almacena el id. de hilo del hilo en el que se creó el objeto del bucle de eventos. Si bus no es un objeto bus predeterminado y no está adjunto a un bucle de eventos, sd_bus_get_tid() devuelve un error.

sd_bus_get_unique_name() almacena el nombre único del objeto bus en el bus en unique. Consulte La especificación D-Bus[4] para obtener más información sobre los nombres de bus. Tenga en cuenta que el llamador no es propietario de la cadena almacenada en unique y no debe liberarla.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven un entero no negativo. En caso de error, devuelven un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Un argumento es inválido.

-ENOPKG

El bus no se puede resolver.

-EPERM

El bus ya se ha iniciado.

-ECHILD

El bus se creó en un proceso, biblioteca o instancia de módulo diferente.

-ENOMEM

Fallo en la asignación de memoria.

-ENODATA

El objeto bus pasado a sd_bus_get_scope() no era un bus del sistema ni un bus de sesión de usuario.

Añadido en la versión 246.

-ENXIO

El objeto bus pasado a sd_bus_get_tid() no era un objeto bus predeterminado y no está adjunto a un bucle de eventos.

El objeto bus pasado a sd_bus_get_description() no tenía una description.

Añadido en la versión 246.

NAME

sd_bus_get_tid - Obtener el identificador de hilo del bus D-Bus

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_get_tid(sd_bus *bus, uint64_t *tid);

DESCRIPTION

La función sd_bus_get_tid() recupera el identificador de hilo de la conexión de bus D-Bus especificada por bus. El identificador de hilo se almacena en la variable apuntada por tid. Si el bus no tiene un identificador de hilo asociado (por ejemplo, si el bus fue creado sin uno), se devolverá el valor 0. El identificador de hilo se utiliza para la multiplexación de mensajes y es asignado por el servicio de bus. Consulte la especificación de D-Bus para más detalles.

RETURN VALUE

En caso de éxito, las funciones sd_bus_get_tid() devuelven 0. En caso de error, devuelven un código de error negativo. Si bus es NULL, se devuelve -EINVAL.

NOTES

El identificador de hilo sólo es relevante para conexiones a nivel de sistema (con sd_bus_open_system()) y sólo si el servicio de bus subyacente lo soporta y lo proporciona. Para conexiones a nivel de sesión, normalmente no hay un identificador de hilo válido.

HISTORY

La función sd_bus_get_tid() estuvo disponible primero en systemd 248.
