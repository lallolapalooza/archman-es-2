sd_bus_reply_method_returnv(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_REPLY_METHOD_RETURNV(3) sd_bus_reply_method_returnv SD_BUS_REPLY_METHOD_RETURNV(3)

NOMBRE

sd_bus_reply_method_return, sd_bus_reply_method_returnv - Responder a una llamada a método D-Bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_reply_method_return(sd_bus_message *call, const char *types, ...);

int sd_bus_reply_method_returnv(sd_bus_message *call, const char *types, va_list ap);

DESCRIPCIÓN

sd_bus_reply_method_return() envía una respuesta al mensaje call. La cadena de tipos types y los argumentos que le siguen deben cumplir el formato descrito en sd_bus_message_append(3). Si no se espera respuesta para call, esta función se completa sin enviar una respuesta.

VALOR DE RETORNO

En caso de éxito, esta función devuelve un entero no negativo. En caso de error, devuelve un código de error negativo del tipo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El parámetro de entrada call es NULL.

El mensaje call no es un mensaje de llamada a método.

El mensaje call no está adjunto a un bus.

El mensaje m no es un mensaje de respuesta de método.

Añadido en la versión 246.

-EPERM

El mensaje call ha sido sellado.

Añadido en la versión 246.

-ENOTCONN

El bus al que está adjunto el mensaje call no está conectado.

Añadido en la versión 246.

-ENOMEM

Falló la asignación de memoria.

Añadido en la versión 246.

Además, se puede devolver cualquier error devuelto por sd_bus_send(3).

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
