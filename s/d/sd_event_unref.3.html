sd_event_unref(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_EVENT_NEW(3) sd_event_new SD_EVENT_NEW(3)

NOMBRE

sd_event_new, sd_event_default, sd_event_ref, sd_event_unref, sd_event_unrefp, sd_event_get_tid, sd_event - Adquirir y liberar un objeto de bucle de eventos

SINOPSIS

#include <systemd/sd-event.h>
typedef struct sd_event sd_event;

int sd_event_new(sd_event **event);

int sd_event_default(sd_event **event);

sd_event *sd_event_ref(sd_event *event);

sd_event *sd_event_unref(sd_event *event);

void sd_event_unrefp(sd_event **event);

int sd_event_get_tid(sd_event *event, pid_t *ret);

DESCRIPCIÓN

sd_event_new() asigna un nuevo objeto de bucle de eventos. El objeto de bucle de eventos se devuelve en el parámetro event. Después de su uso, suelte la referencia devuelta con sd_event_unref(). Cuando se suelta la última referencia, el objeto se libera.

sd_event_default() adquiere una referencia al objeto de bucle de eventos predeterminado del hilo que llama, posiblemente asignando un nuevo objeto si aún no se ha asignado ningún objeto de bucle de eventos predeterminado para el hilo. Después de su uso, suelte la referencia devuelta con sd_event_unref(). Cuando se suelta la última referencia, el bucle de eventos se libera. Si se llama a esta función mientras el objeto devuelto por una llamada anterior desde el mismo hilo todavía está referenciado, se devuelve el mismo objeto, pero la referencia se incrementa en uno. Se recomienda usar esta llamada en lugar de sd_event_new() para compartir objetos de bucle de eventos entre varios componentes que se despachan en el mismo hilo. Todos los hilos tienen exactamente cero o un objeto de bucle de eventos predeterminado asociado, pero nunca más.

Después de asignar un objeto de bucle de eventos, agregue fuentes de eventos con sd_event_add_io(3), sd_event_add_time(3), sd_event_add_signal(3), sd_event_add_child(3), sd_event_add_inotify(3), sd_event_add_defer(3), sd_event_add_post(3) o sd_event_add_exit(3), y luego ejecute el bucle de eventos usando sd_event_loop(3).

sd_event_ref() incrementa el contador de referencias del objeto de bucle de eventos especificado en uno.

sd_event_unref() decrementa el contador de referencias del objeto de bucle de eventos especificado en uno. Si el contador llega a cero, el objeto se libera. Tenga en cuenta que se libera independientemente de si es el objeto de bucle de eventos predeterminado para un hilo o no. Esto significa que asignar un bucle de eventos con sd_event_default(), luego liberarlo, y luego adquirir uno nuevo con sd_event_default() resultará en dos objetos distintos. Tenga en cuenta que, para liberar un objeto de bucle de eventos, todas las fuentes de eventos restantes del bucle de eventos también deben liberarse, ya que cada una mantiene una referencia a él.

sd_event_unrefp() es similar a sd_event_unref(), pero toma un puntero a un puntero a un objeto sd_event. Esta llamada es útil en conjunción con el Atributo de Variable de Limpieza de GCC y LLVM [1]. Tenga en cuenta que esta función se define como una función en línea. Use una declaración como la siguiente, para asignar un objeto de bucle de eventos que se libera automáticamente al salir del bloque de código:

{
        __attribute__((cleanup(sd_event_unrefp))) sd_event *event = NULL;
        int r;
        ...
        r = sd_event_default(&event);
        if (r < 0) {
          errno = -r;
          fprintf(stderr, "Error al asignar el bucle de eventos: %m\n");
        }
        ...
}

sd_event_ref(), sd_event_unref() y sd_event_unrefp() no realizan ninguna operación si el objeto de bucle de eventos pasado es NULL.

sd_event_get_tid() recupera el identificador del hilo ("TID") del hilo con el que está asociado el objeto de bucle de eventos especificado. Esta llamada solo es compatible con bucles de eventos asignados con sd_event_default() y devuelve el identificador del hilo del que el bucle de eventos es el bucle de eventos predeterminado. Consulte gettid(2) para obtener más información sobre los identificadores de hilo.

VALOR DE RETORNO

En caso de éxito, sd_event_new(), sd_event_default() y sd_event_get_tid() devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo de estilo errno. sd_event_ref() siempre devuelve un puntero al objeto de bucle de eventos pasado. sd_event_unref() siempre devuelve NULL.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ENOMEM

No hay suficiente memoria para asignar el objeto.

-EMFILE

Se ha asignado el número máximo de bucles de eventos.

-ENXIO

Se invocó sd_event_get_tid() en un objeto de bucle de eventos que no fue asignado con sd_event_default().

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd de pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv() desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_event_new(), sd_event_default(), sd_event_ref() y sd_event_unref() se agregaron en la versión 213.

sd_event_unrefp() y sd_event_get_tid() se agregaron en la versión 229.
