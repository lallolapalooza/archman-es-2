sd_hwdb_get(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_HWDB_GET(3) sd_hwdb_get SD_HWDB_GET(3)

NOMBRE

sd_hwdb_get, sd_hwdb_seek, sd_hwdb_enumerate, SD_HWDB_FOREACH_PROPERTY - Buscar en hwdb o acceder a entradas

SINOPSIS

#include <systemd/sd-hwdb.h>

int sd_hwdb_get(sd_hwdb *hwdb, const char *modalias, const char *key, const char **value);

int sd_hwdb_seek(sd_hwdb *hwdb, const char *modalias);

int sd_hwdb_enumerate(sd_hwdb *hwdb, const char **key, const char **value);

SD_HWDB_FOREACH_PROPERTY(hwdb, modalias, key, value);

DESCRIPCIÓN

sd_hwdb_get() consulta el objeto hwdb creado anteriormente con sd_hwdb_new(3) para entradas que coincidan con la cadena modalias especificada, y devuelve el valor correspondiente a la clave key. El valor se devuelve como una cadena terminada en NUL en value. No debe ser modificada por el llamador y es válida mientras se mantenga una referencia a hwdb. Cuando múltiples patrones en la base de datos coinciden con modalias, se utiliza el que tiene la mayor prioridad. Véase hwdb(7) para más detalles.

sd_hwdb_seek() selecciona entradas que coincidan con la cadena modalias especificada. Las consultas posteriores con sd_hwdb_enumerate() accederán a los pares clave-valor para esa cadena.

sd_hwdb_enumerate() devuelve (por turnos) todos los pares clave-valor definidos para la cadena utilizada con sd_hwdb_seek(). Cada par se devuelve como cadenas terminadas en NUL en key y value. Las cadenas no deben ser modificadas por el llamador y son válidas mientras se mantenga una referencia a hwdb. Cuando múltiples patrones en la base de datos coinciden con modalias, se utiliza la combinación de todos los pares clave-valor coincidentes. Véase hwdb(7) para más detalles.

La macro SD_HWDB_FOREACH_PROPERTY() combina sd_hwdb_seek() y sd_hwdb_enumerate(). No se realiza manejo de errores y la iteración simplemente se detiene ante un error. Véase el ejemplo a continuación.

VALOR DE RETORNO

En caso de éxito, sd_hwdb_get() y sd_hwdb_seek() devuelven un entero no negativo. En caso de error, devuelven un código de error negativo de estilo errno.

sd_hwdb_enumerate() devuelve un entero positivo si se encontró otro par clave-valor o cero si todas las entradas ya han sido enumeradas. En caso de error, devuelve un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Un parámetro es NULL.

Añadido en la versión 246.

-ENOENT

No se encontró una entrada para el modalias especificado.

Añadido en la versión 246.

-EAGAIN

sd_hwdb_seek() no fue llamado antes que sd_hwdb_enumerate().

Añadido en la versión 246.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

EJEMPLOS

Ejemplo 1. Buscar entradas hwdb para un dispositivo USB

/* SPDX-License-Identifier: MIT-0 */
#define _GNU_SOURCE 1
#include <stdio.h>
#include <stdint.h>
#include <systemd/sd-hwdb.h>
int print_usb_properties(uint16_t vid, uint16_t pid) {
  char match[128];
  sd_hwdb *hwdb;
  const char *key, *value;
  int r;
  /* Coincidir con esta combinación de ID de proveedor y producto USB */
  snprintf(match, sizeof match, "usb:v%04Xp%04X", vid, pid);
  r = sd_hwdb_new(&hwdb);
  if (r < 0)
    return r;
  SD_HWDB_FOREACH_PROPERTY(hwdb, match, key, value)
    printf("%s: \"%s\" → \"%s\"\n", match, key, value);
  sd_hwdb_unref(hwdb);
  return 0;
}
int main(int argc, char **argv) {
  print_usb_properties(0x046D, 0xC534);
  return 0;
}

El efecto es similar a llamar a systemd-hwdb query usb:v046DpC534.
