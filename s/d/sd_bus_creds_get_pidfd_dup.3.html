DESCRIPCIÓN

Estas funciones devuelven información de credenciales de un objeto sd_bus_creds. Los objetos de credenciales pueden crearse con sd_bus_creds_new_from_pid(3), en cuyo caso describen las credenciales del proceso identificado por el PID especificado, con sd_bus_get_name_creds(3), en cuyo caso describen las credenciales de un par del bus identificado por el nombre de bus especificado, con sd_bus_get_owner_creds(3), en cuyo caso describen las credenciales del creador de un bus, o con sd_bus_message_get_creds(3), en cuyo caso describen las credenciales del remitente del mensaje.

No todos los campos de credenciales forman parte de cada objeto "sd_bus_creds". Utilice sd_bus_creds_get_mask(3) para determinar la máscara de campos disponibles.

sd_bus_creds_get_pid() recuperará el PID (identificador de proceso). De manera similar, sd_bus_creds_get_ppid() recuperará el PID padre. Tenga en cuenta que el PID 1 no tiene proceso padre, en cuyo caso se devuelve -ENXIO.

sd_bus_creds_get_pidfd_dup() recuperará el descriptor de archivo PID (pidfd), consulte pidfd_open(2) para más detalles. El descriptor de archivo se duplica y, por lo tanto, debe ser cerrado por el llamador.

sd_bus_creds_get_tid() recuperará el TID (identificador de hilo).

sd_bus_creds_get_uid() recuperará el UID numérico (identificador de usuario). De manera similar, sd_bus_creds_get_euid() devuelve el UID efectivo, sd_bus_creds_get_suid() el UID guardado y sd_bus_creds_get_fsuid() el UID del sistema de archivos.

sd_bus_creds_get_gid() recuperará el GID numérico (identificador de grupo). De manera similar, sd_bus_creds_get_egid() devuelve el GID efectivo, sd_bus_creds_get_sgid() el GID guardado y sd_bus_creds_get_fsgid() el GID del sistema de archivos.

sd_bus_creds_get_supplementary_gids() recuperará la lista de GIDs suplementarios.

sd_bus_creds_get_comm() recuperará el campo comm (nombre truncado del ejecutable, tal como se almacena en /proc/pid/comm).

sd_bus_creds_get_tid_comm() recuperará el campo comm del hilo (tal como se almacena en /proc/pid/task/tid/comm).

sd_bus_creds_get_exe() recuperará la ruta al ejecutable del programa (tal como se almacena en el enlace /proc/pid/exe, pero con el sufijo " (eliminado)" eliminado). Tenga en cuenta que los hilos del kernel no tienen una ruta ejecutable, en cuyo caso se devuelve -ENXIO. Tenga en cuenta que esta propiedad no debe utilizarse para obtener información explicativa, en particular no debe utilizarse para decisiones relevantes para la seguridad. Esto se debe a que el ejecutable podría haber sido reemplazado o eliminado en el momento en que se pueda procesar el valor. DESCRIPCIÓN

Las funciones sd_bus_creds_get_*() buscan recuperar información específica de las credenciales del par de bus D-Bus representado por el objeto c. El objeto c debe haber sido creado previamente con sd_bus_creds_new_from_pid(3) o similar.

Las siguientes funciones están disponibles:

sd_bus_creds_get_pid()
Recupera el ID del proceso (PID).
sd_bus_creds_get_tid()
Recupera el ID del hilo ( TID). Este puede diferir del PID para procesos multihilo.
sd_bus_creds_get_uid()
Recupera el ID de usuario real efectivo (EUID).
sd_bus_creds_get_gid()
Recupera el ID de grupo real efectivo (EGID).
sd_bus_creds_get_euid()
Equivalente a sd_bus_creds_get_uid().
sd_bus_creds_get_egid()
Equivalente a sd_bus_creds_get_gid().
sd_bus_creds_get_suid()
Recupera el ID de usuario guardado (SUID).
sd_bus_creds_get_sgid()
Recupera el ID de grupo guardado (SGID).
sd_bus_creds_get_fsuid()
Recupera el ID de usuario de la comprobación del sistema de archivos (fsuid).
sd_bus_creds_get_fsgid()
Recupera el ID de grupo de la comprobación del sistema de archivos (fsgid).
sd_bus_creds_get_supplementary_gids()
Recupera el array de IDs de grupo suplementarios. El array está terminado en NULL y cada elemento está terminado en NULL.
sd_bus_creds_get_comm()
Recupera el nombre de la tarea del proceso tal como se almacena en /proc/pid/comm. Tenga en cuenta que este nombre puede estar truncado a 16 caracteres y puede haber sido modificado por el proceso. Para hilos kernel, se devuelve el nombre del hilo kernel, con el sufijo de nombre de objeto '\0' (eliminado).
sd_bus_creds_get_tid_comm()
Similar a sd_bus_creds_get_comm(), pero recupera el nombre de la tarea del hilo específico dado por TID.
sd_bus_creds_get_exe()
Recupera el nombre del archivo ejecutable del proceso tal como se almacena en /proc/pid/exe (es decir, un enlace simbólico al ejecutable).
sd_bus_creds_get_cmdline()
Recupera un array de argumentos de línea de comandos (tal como se almacena en /proc/pid/cmdline). Tenga en cuenta que los hilos kernel no tienen una línea de comandos, en cuyo caso se devuelve -ENXIO.
sd_bus_creds_get_cgroup()
Recupera la ruta del cgroup. Ver Control Groups v2[1].
sd_bus_creds_get_unit()
Recupera el nombre de la unidad systemd (en la instancia del sistema de systemd) de la que forma parte el proceso. Ver systemd.unit(5). Para procesos que no forman parte de una unidad, devuelve -ENXIO.
sd_bus_creds_get_user_unit()
Recupera el nombre de la unidad systemd (en la instancia de usuario de systemd) de la que forma parte el proceso. Ver systemd.unit(5). Para procesos que no forman parte de una unidad de usuario, devuelve -ENXIO.
sd_bus_creds_get_slice()
Recupera el slice systemd (una unidad en la instancia del sistema de systemd) del que forma parte el proceso. Ver systemd.slice(5). De manera similar, sd_bus_creds_get_user_slice() recupera el slice systemd del proceso, en la instancia de usuario de systemd.
sd_bus_creds_get_session()
Recupera el identificador de la sesión de inicio de sesión de la que forma parte el proceso. Tenga en cuenta que la sesión de inicio de sesión puede estar limitada a uno o dos procesos stub. Los procesos de usuario pueden, en su lugar, iniciarse desde su gestor de usuario systemd, por ejemplo, aplicaciones GUI iniciadas usando activación DBus, así como procesos de servicio que se comparten entre múltiples inicios de sesión del mismo usuario. Para procesos que no forman parte de una sesión, devuelve -ENXIO.
sd_bus_creds_get_owner_uid()
Recupera el UID numérico (identificador de usuario) del usuario que posee la unidad de usuario o la sesión de inicio de sesión de la que forma parte el proceso. Ver systemd-logind.service(8). Para procesos que no forman parte de una unidad de usuario o sesión, devuelve -ENXIO.
sd_bus_creds_get_pidfd_dup()
Duplica el descriptor de archivo pidfd para el proceso. Este descriptor de archivo puede usarse para obtener el PID de forma más fiable que leyendo /proc/pid/pid, especialmente en escenarios de carrera.
sd_bus_creds_has_effective_cap()
Comprueba si la capacidad especificada por capability estaba establecida en la máscara de capacidades efectivas. Un valor de retorno positivo significa que estaba establecida, cero significa que no estaba establecida, y un valor de retorno negativo indica un error. Ver capabilities(7) y los ajustes AmbientCapabilities= y CapabilityBoundingSet= en systemd.exec(5).
sd_bus_creds_has_permitted_cap()
Es similar a sd_bus_creds_has_effective_cap(), pero comprobará la máscara de capacidades permitidas.
sd_bus_creds_has_inheritable_cap()
Es similar a sd_bus_creds_has_effective_cap(), pero comprobará la máscara de capacidades heredables.
sd_bus_creds_has_bounding_cap()
Es similar a sd_bus_creds_has_effective_cap(), pero comprobará la máscara de capacidades limitantes.
sd_bus_creds_get_selinux_context()
Recupera el contexto de seguridad SELinux (etiqueta) del proceso.
sd_bus_creds_get_audit_session_id()
Recupera el identificador de sesión de auditoría del proceso. Devuelve -ENXIO para procesos que no forman parte de una sesión de auditoría.
sd_bus_creds_get_audit_login_uid()
Recupera el identificador de inicio de sesión de auditoría del usuario (el identificador del usuario que es "responsable" de la sesión). Devuelve -ENXIO para procesos que no forman parte de una sesión de auditoría.
sd_bus_creds_get_tty()
Recupera el TTY de control, sin el prefijo "/dev/". Devuelve -ENXIO para procesos que no tienen un TTY de control.
sd_bus_creds_get_unique_name()
Recupera el nombre único de D-Bus. Ver La especificación de D-Bus[2].
sd_bus_creds_get_well_known_names()
Recupera el conjunto de nombres conocidos de D-Bus. Ver La especificación de D-Bus[2].
sd_bus_creds_get_description()
Recupera un nombre descriptivo de la conexión de bus del par. Este nombre es útil para discernir múltiples conexiones de bus del mismo par, y puede ser alterado por el par con la llamada sd_bus_set_description(3).

Todas las funciones que toman un parámetro const char** almacenarán la respuesta allí como una dirección de una cadena terminada en NUL. Será válida mientras c siga siendo válida y no debe ser liberada ni modificada por el llamador.

Todas las funciones que toman un parámetro char*** almacenarán la respuesta allí como una dirección de un array de cadenas. Cada cadena individual está terminada en NUL, y el array está terminado en NULL en su conjunto. Será válida mientras c siga siendo válida y no debe ser liberada ni modificada por el llamador.

VALOR DE RETORNO

En caso de éxito, estas llamadas devuelven 0 o un entero positivo. En caso de error, estas llamadas devuelven un código de error negativo de tipo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ENODATA

El campo especificado no está disponible en el objeto de credenciales c.

-ENXIO

El campo especificado no está definido para el proceso o par descrito. Esto será devuelto por sd_bus_creds_get_unit(), sd_bus_creds_get_slice(), sd_bus_creds_get_user_unit(), sd_bus_creds_get_user_slice(), y sd_bus_creds_get_session() si el proceso no forma parte de una unidad de sistema systemd, unidad de usuario systemd, slice systemd, o sesión logind. Será devuelto por sd_bus_creds_get_owner_uid() si el proceso no forma parte de una unidad de usuario systemd o sesión logind. También será devuelto por sd_bus_creds_get_exe() y sd_bus_creds_get_cmdline() para hilos kernel (ya que estos no se inician desde un binario ejecutable, ni tienen una línea de comandos), y por sd_bus_creds_get_audit_session_id() y sd_bus_creds_get_audit_login_uid() cuando el proceso no forma parte de una sesión de auditoría, y sd_bus_creds_get_tty() si el proceso no tiene un TTY de control.

-EINVAL

El parámetro puntero especificado es NULL.

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede ser compilada y enlazada con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para multihilo. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
