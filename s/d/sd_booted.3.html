NOMBRE

sd_booted - Comprueba si el sistema está ejecutando el sistema de inicio systemd

SINOPSIS

#include <systemd/sd-daemon.h>

int sd_booted(void);

DESCRIPCIÓN

sd_booted() comprueba si el sistema se inició utilizando el sistema de inicio systemd.

VALOR DE RETORNO

En caso de fallo, esta llamada devuelve un código de error negativo al estilo errno. Si el sistema se inició con systemd como sistema de inicio, esta llamada devuelve un valor de retorno positivo, de lo contrario cero.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

Internamente, esta función comprueba si existe el directorio /run/systemd/system/. Una simple comprobación como esta también se puede implementar fácilmente en shell o en cualquier otro lenguaje.
