SD_BUS_ADD_NODE_ENUMERATOR(3) sd_bus_add_node_enumerator SD_BUS_ADD_NODE_ENUMERATOR(3)

NOMBRE

sd_bus_add_node_enumerator - Añade un enumerador de nodos para un prefijo de ruta de objeto D-Bus

SINOPSIS

#include <systemd/sd-bus.h>

typedef int (*sd_bus_node_enumerator_t)(sd_bus *bus, const char *prefix, void *userdata, char ***ret_nodes, sd_bus_error *ret_error);

int sd_bus_add_node_enumerator(sd_bus *bus, sd_bus_slot **slot, const char *path, sd_bus_node_enumerator_t callback, void *userdata);

DESCRIPCIÓN

sd_bus_add_node_enumerator() añade un enumerador de nodos D-Bus para el prefijo de ruta dado. La función de devolución de llamada dada se llama para enumerar todos los objetos disponibles con el prefijo de ruta dado cuando sea necesario (por ejemplo, cuando se llaman org.freedesktop.DBus.Introspectable.Introspect o org.freedesktop.DBus.ObjectManager.GetManagedObjects en un servicio D-Bus gestionado por sd-bus).

Se llama a callback con la ruta y el puntero de datos de usuario registrados con sd_bus_add_node_enumerator(). Cuando se llama, debe almacenar todas las rutas de objetos hijos de la ruta dada en ret_nodes con un elemento terminador NULL. La función de devolución de llamada debe devolver un valor no negativo en caso de éxito. Si ocurre un error, puede devolver un entero negativo, establecer ret_error en un error no vacío o hacer ambas cosas. Cualquier error devuelto por la función de devolución de llamada se codifica como errores D-Bus y se envía al llamante. Los errores en ret_error tienen prioridad sobre los valores de retorno negativos.

Tenga en cuenta que una función de devolución de llamada de enumerador de nodos solo se llamará para un único prefijo de ruta y, por lo tanto, para un funcionamiento normal, se puede ignorar prefix. Además, un enumerador de nodos solo se utiliza para enumerar los objetos hijos disponibles bajo un prefijo dado. Para instalar un manejador para un conjunto de objetos hijos dinámicos, utilice sd_bus_add_fallback_vtable(3).

Cuando sd_bus_add_node_enumerator() tiene éxito, se crea una ranura internamente. Si el parámetro de salida slot es NULL, se crea un objeto de ranura "flotante", véase sd_bus_slot_set_floating(3). De lo contrario, se devuelve un puntero al objeto de ranura. En ese caso, la referencia al objeto de ranura debe eliminarse cuando el enumerador de nodos ya no sea necesario, véase sd_bus_slot_unref(3).

VALOR DE RETORNO

En caso de éxito, sd_bus_add_node_enumerator() devuelve un entero no negativo. En caso de fallo, devuelve un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Uno de los parámetros requeridos es NULL o path no es una ruta de objeto válida.

-ENOPKG

El bus no se puede resolver.

-ECHILD

El bus se creó en un proceso, biblioteca o instancia de módulo diferente.

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_node_enumerator_t() y sd_bus_add_node_enumerator() se añadieron en la versión 221.
