sd_machine_get_class(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_MACHINE_GET_CLASS(3) sd_machine_get_class SD_MACHINE_GET_CLASS(3)

NOMBRE

sd_machine_get_class, sd_machine_get_ifindices - Determinar la clase y los índices de las interfaces de red de una máquina virtual o contenedor ejecutándose localmente

SINOPSIS

#include <systemd/sd-login.h>

int sd_machine_get_class(const char* machine, char **class);

int sd_machine_get_ifindices(const char* machine, int **ret_ifindices);

DESCRIPCIÓN

sd_machine_get_class() se puede usar para determinar la clase de una máquina virtual o contenedor ejecutándose localmente que está registrado con systemd-machined.service(8). La cadena devuelta es "vm" o "container". La cadena devuelta debe liberarse con la llamada a free(3) de libc después de su uso.

sd_machine_get_ifindices() se puede usar para determinar los índices numéricos de las interfaces de red en el host que apuntan hacia la máquina virtual o contenedor especificado ejecutándose localmente. La máquina virtual o contenedor debe estar registrado con systemd-machined.service(8). El parámetro de salida ret_ifindices puede pasarse como NULL cuando el valor de salida no es necesario. El array devuelto debe liberarse con la llamada a free(3) de libc después de su uso.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven un entero no negativo. sd_machine_get_ifindices() devuelve el número de interfaces de red relevantes. En caso de fallo, estas llamadas devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ENXIO

La máquina especificada no existe o no se está ejecutando actualmente.

-EINVAL

Un parámetro de entrada era inválido (fuera de rango o NULL, donde no se acepta).

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un subproceso paralelo. Se recomienda realizar solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros subprocesos.

HISTORIA

sd_machine_get_class() y sd_machine_get_ifindices() se añadieron en la versión 217.

VER TAMBIÉN
