Propósito:

!>
!>    SDRVES comprueba el problema del autovalor no simétrico (forma de Schur)
!>    controlador SGEES.
!>
!>    Cuando se llama a SDRVES, se especifica un número de tamaños de matriz () y un
!>    número de tipos de matriz. Para cada tamaño () y cada tipo de matriz, se generará y utilizará una matriz
!>    para probar las rutinas de autovalores no simétricos. Para cada matriz, se realizarán 13 pruebas:
!>
!>    (1)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>           (sin ordenar autovalores)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de autovectores de Schur, y T está en forma de Schur
!>      (sin ordenar autovalores).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (sin ordenar autovalores).
!>
!>    (4)     0     si WR+sqrt(-1)*WI son autovalores de T
!>            1/ulp en caso contrario
!>            (sin ordenar autovalores)
!>
!>    (5)     0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenar autovalores)
!>
!>    (6)     0     si autovalores(con VS) = autovalores(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenar autovalores)
!>
!>    (7)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de autovectores de Schur, y T está en forma de Schur
!>      (con ordenación de autovalores).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (con ordenación de autovalores).
!>
!>    (10)    0     si WR+sqrt(-1)*WI son autovalores de T
!>            1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (11)    0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (12)    0     si autovalores(con VS) = autovalores(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (13)    si la ordenación funcionó y SDIM es el número de
!>            autovalores que fueron SELECCIONADOS
!>
!>    Los tamaños de matriz se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los tipos de matriz se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1 en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP y signos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1)
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP y signos aleatorios.
!>    (6)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>         y signos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicada por una constante cercana
!>         al umbral de desbordamiento.
!>    (8)  Igual que (4), pero multiplicada por una constante cercana
!>         al umbral de subdesbordamiento.
!>
!>    (9)  Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (10) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (11) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene entradas 1, ULP,..., ULP en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (12) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene autovalores reales o pares conjugados complejos elegidos aleatoriamente de ( ULP, 1 )
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (13) Una matriz de la forma X' T X, donde X tiene una condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (14) Una matriz de la forma X' T X, donde X tiene una condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (15) Una matriz de la forma X' T X, donde X tiene una condición
!>         SQRT( ULP ) y T tiene entradas 1, ULP,..., ULP en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (16) Una matriz de la forma X' T X, donde X tiene una condición
!>         SQRT( ULP ) y T tiene autovalores reales o pares conjugados complejos
!>         elegidos aleatoriamente de ( ULP, 1 ) y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (17) Igual que (16), pero multiplicada por una constante cercana
!>         al umbral de desbordamiento.
!>    (18) Igual que (16), pero multiplicada por una constante cercana
!>         al umbral de subdesbordamiento.
!>
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de (-1,1).
!>         Si N es al menos 4, todas las entradas en las dos primeras filas y la última
!>         fila, y la primera columna y las dos últimas columnas son cero.
!>    (20) Igual que (19), pero multiplicada por una constante cercana
!>         al umbral de desbordamiento.
!>    (21) Igual que (19), pero multiplicada por una constante cercana
!>         al umbral de subdesbordamiento.

Function/Subroutine Documentation

SDRVES is a driver routine for testing the nonsymmetric eigenvalue routines.

Description:

 SDRVES generates and tests the nonsymmetric eigenvalue routines SLATME,
 SLATMS, SLATME, SGEES, and SVDES. The nonsymmetric eigenvalue routines
 are specified by the input parameter JTYPE. The matrix is generated by
 SLATME or SLATMS, and the nonsymmetric eigenvalue problem is solved by
 SGEES.

The eigenvalues are computed by SGEES. The Schur vectors are computed by SGEES. A test for the computed eigenvalues and Schur vectors is performed.

The tests are performed on matrices A, H, and HT. H is the upper Hessenberg form of A computed by SGEES. HT is another matrix, related to H, and used in the computation of the Schur vectors. The computed eigenvalues are WR + WI*i. The computed Schur vectors are VS.

The results are compared to the expected results from the test routines. The following tests are performed:

  1. Check that the computed eigenvalues are correct.
  2. Check that the computed Schur vectors are correct.
  3. Check that the computed Schur vectors are orthogonal.
  4. Check that the computed Schur vectors form a Schur basis.
  5. Check that the computed Schur vectors are correct with respect to the eigenvalues.

Parameters:

LAION

 LAION is INTEGER
 Specifies the form of the matrix A to be generated.
 LAION = 0, A is generated from scratch.
 LAION = 1, A is generated from scratch with a condition number CONDS.
 LAION = 2, A is generated from scratch with a condition number CONDS
 and a norm ANORM.
 LAION = 3, A is generated from scratch with a condition number CONDS,
 a norm ANORM, and a value SLOPE.

NSIZES

 NSIZES is INTEGER
 The number of sizes of matrices to be tested.

NN

 NN is INTEGER array, dimension (NSIZES)
 The sizes of the matrices to be tested. NN(j) = N.

NTYPES

 NTYPES is INTEGER
 The number of matrix types to be tested. NTYPES must be between 0
 and MAXTYP. If NTYPES = 0, then only the types specified by LAION=0
 are generated. If NTYPES > 0, then the first NTYPES types are
 generated, plus the types specified by LAION.

ISEED

 ISEED is INTEGER array, dimension (4)
 On entry ISEED specifies the seed of the random number generator. The
 array elements should be between 0 and 4095; if not they will be
 reduced mod 4096. Also, ISEED(4) must be odd. The random number
 generator uses a linear congruential sequence limited to small
 integers, and so should produce machine independent random numbers. The
 values of ISEED are changed on exit, and can be used in the next call
 to SDRVES to continue the same random number sequence.

THRESH

 THRESH is REAL
 A test will count as a failure if the error, computed as described
 above, exceeds THRESH. Note that the error is scaled to be O(1), so
 THRESH should be a reasonably small multiple of 1, e.g., 10 or 100.
 In particular, it should not depend on the precision (single vs.
 double) or the size of the matrix. It must be at least zero.

NOUNIT

 NOUNIT is INTEGER
 The FORTRAN unit number for printing out error messages (e.g., if a
 routine returns INFO not equal to 0.)

A

 A is REAL array, dimension (LDA, max(NN))
 Used to hold the matrix whose eigenvalues are to be computed. On exit,
 A contains the last matrix actually used.

LDA

 LDA is INTEGER
 The leading dimension of A, and H. LDA must be at least 1 and at least
 max(NN).

H

 H is REAL array, dimension (LDA, max(NN))
 Another copy of the test matrix A, modified by SGEES.

HT

 HT is REAL array, dimension (LDA, max(NN))
 Yet another copy of the test matrix A, modified by SGEES.

WR

 WR is REAL array, dimension (max(NN))

WI

 WI is REAL array, dimension (max(NN))
 The real and imaginary parts of the eigenvalues of A. On exit, WR +
 WI*i are the eigenvalues of the matrix in A.

WRT

 WRT is REAL array, dimension (max(NN))

WIT

 WIT is REAL array, dimension (max(NN))
 Like WR, WI, these arrays contain the eigenvalues of A, but those
 computed when SGEES only computes a partial eigendecomposition, i.e.
 not Schur vectors
 


VS


 VS is REAL array, dimension (LDVS, max(NN))
 VS holds the computed Schur vectors.
 


LDVS


 LDVS is INTEGER
 Leading dimension of VS. Must be at least max(1,max(NN)).
 


RESULT


 RESULT is REAL array, dimension (13)
 The values computed by the 13 tests described above. The values are
 currently limited to 1/ulp, to avoid overflow.
 


WORK


 WORK is REAL array, dimension (NWORK)
 


NWORK


 NWORK is INTEGER
 The number of entries in WORK. This must be at least 5*NN(j)+2*NN(j)**2
 for all j.
 


IWORK


 IWORK is INTEGER array, dimension (max(NN))
 


BWORK


 BWORK is LOGICAL array, dimension (max(NN))
 


INFO


 INFO is INTEGER
 If 0, then everything ran OK.
  -1: NSIZES < 0
  -2: Some NN(j) < 0
  -3: NTYPES < 0
  -6: THRESH < 0
  -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ).
  -17: LDVS < 1 or LDVS < NMAX, where NMAX is max( NN(j) ).
  -20: NWORK too small.
 If SLATMR, SLATMS, SLATME or SGEES returns an error code, the
 absolute value of it is returned.

Some Local Variables and Parameters:


     ZERO, ONE       Real 0 and 1.
     MAXTYP          The number of types defined.
     NMAX            Largest value in NN.
     NERRS           The number of tests which have exceeded THRESH
     COND, CONDS,

     ANORM           Norm of A; passed to matrix generators.

     OVFL, UNFL      Overflow and underflow thresholds.
     ULP, ULPINV     Finest relative precision and its inverse.
     RTULP, RTULPI   Square roots of the previous 4 values.

             The following four arrays decode JTYPE:
     KTYPE(j)        The general type (1-10) for type j.
     KMODE(j)        The MODE value to be passed to the matrix
                     generator for type j.
     KMAGN(j)        The order of magnitude ( O(1),
                     O(overflow^(1/2) ), O(underflow^(1/2) )
     KCONDS(j)       Selects whether CONDS is to be 1 or
                     1/sqrt(ulp).  (0 means irrelevant.)
