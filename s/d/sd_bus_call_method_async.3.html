sd_bus_call_method_async(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_CALL_METHOD(3) sd_bus_call_method SD_BUS_CALL_METHOD(3)

NOMBRE

sd_bus_call_method, sd_bus_call_methodv, sd_bus_call_method_async, sd_bus_call_method_asyncv - Inicializa un objeto de mensaje de bus e invoca la llamada al método D-Bus correspondiente

SINOPSIS

#include <systemd/sd-bus.h>

typedef int (*sd_bus_message_handler_t)(sd_bus_message *m, void *userdata, sd_bus_error *ret_error);

int sd_bus_call_method(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, sd_bus_message **reply, const char *types, ...);

int sd_bus_call_methodv(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, sd_bus_message **reply, const char *types, va_list ap);

int sd_bus_call_method_async(sd_bus *bus, sd_bus_slot **slot, const char *destination, const char *path, const char *interface, const char *member, sd_bus_message_handler_t callback, void *userdata, const char *types, ...);

int sd_bus_call_method_asyncv(sd_bus *bus, sd_bus_slot **slot, const char *destination, const char *path, const char *interface, const char *member, sd_bus_message_handler_t callback, void *userdata, const char *types, va_list ap);

DESCRIPCIÓN

sd_bus_call_method() es una función de conveniencia para inicializar un objeto de mensaje de bus y llamar al método D-Bus correspondiente. Combina las funciones sd_bus_message_new_method_call(3), sd_bus_message_append(3) y sd_bus_call(3) en una única llamada a función.

sd_bus_call_method_async() es una función de conveniencia para inicializar un objeto de mensaje de bus y llamar al método D-Bus correspondiente de forma asíncrona. Combina las funciones sd_bus_message_new_method_call(3), sd_bus_message_append(3) y sd_bus_call_async(3) en una única llamada a función.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven un entero no negativo. En caso de error, devuelven un código de error negativo al estilo errno.

Errores

Consulte las páginas del manual de sd_bus_message_new_method_call(3), sd_bus_message_append(3), sd_bus_call(3) y sd_bus_call_async(3) para obtener una lista de posibles errores.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd de pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se han iniciado otros hilos.

EJEMPLOS

Ejemplo 1. Realizar una llamada a un método D-Bus que acepte un único parámetro

/* SPDX-License-Identifier: MIT-0 */
/* Esto es equivalente a:
 * busctl call org.freedesktop.systemd1 /org/freedesktop/systemd1 \
 *       org.freedesktop.systemd1.Manager GetUnitByPID $$
 *
 * Compilar con 'cc print-unit-path-call-method.c -lsystemd'
 */
#include <errno.h>
#include <stdio.h>
#include <sys/types.h>
#include <unistd.h>
#include <systemd/sd-bus.h>
#define _cleanup_(f) __attribute__((cleanup(f)))
#define DESTINATION "org.freedesktop.systemd1"
#define PATH        "/org/freedesktop/systemd1"
#define INTERFACE   "org.freedesktop.systemd1.Manager"
#define MEMBER      "GetUnitByPID"
static int log_error(int error, const char *message) {
  fprintf(stderr, "%s: %s\n", message, strerror(-error));
  return error;
}
int main(int argc, char **argv) {
  _cleanup_(sd_bus_flush_close_unrefp) sd_bus *bus = NULL;
  _cleanup_(sd_bus_error_free) sd_bus_error error = SD_BUS_ERROR_NULL;
  _cleanup_(sd_bus_message_unrefp) sd_bus_message *reply = NULL;
  int r;
  r = sd_bus_open_system(&bus);
  if (r < 0)
    return log_error(r, "Error al adquirir el bus");
  r = sd_bus_call_method(bus, DESTINATION, PATH, INTERFACE, MEMBER, &error, &reply, "u", (unsigned) getpid());
  if (r < 0)
    return log_error(r, "La llamada a MEMBER falló");
  const char *ans;
  r = sd_bus_message_read(reply, "o", &ans);
  if (r < 0)
    return log_error(r, "Error al leer la respuesta");
  printf("La ruta de la unidad es \"%s\".\n", ans);
  return 0;
}

Esto define un programa mínimamente útil que abrirá una conexión al bus, llamará a un método, esperará la respuesta y finalmente extraerá e imprimirá la respuesta. Maneja errores y la gestión adecuada de la memoria.

HISTORIA

sd_bus_call_method() y sd_bus_call_method_async() se añadieron en la versión 221.

sd_bus_call_methodv() y sd_bus_call_method_asyncv() se añadieron en la versión 246.
