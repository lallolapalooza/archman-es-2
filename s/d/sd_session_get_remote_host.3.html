NOMBRE

sd_session_is_active, sd_session_is_remote, sd_session_get_state, sd_session_get_uid, sd_session_get_username, sd_session_get_seat, sd_session_get_start_time, sd_session_get_service, sd_session_get_type, sd_session_get_class, sd_session_get_desktop, sd_session_get_display, sd_session_get_tty, sd_session_get_vt, sd_session_get_remote_host, sd_session_get_remote_user, sd_session_get_leader - Determinar el estado de una sesión específica

DESCRIPCIÓN

sd_session_is_active() puede usarse para determinar si la sesión identificada por el identificador de sesión especificado está actualmente activa (es decir, actualmente en primer plano y disponible para entrada del usuario) o no.

sd_session_is_remote() puede usarse para determinar si la sesión identificada por el identificador de sesión especificado es una sesión remota (es decir, su host remoto es conocido) o no.

sd_session_get_state() puede usarse para determinar el estado de la sesión identificada por el identificador de sesión especificado. Los siguientes estados se conocen actualmente: "online" (sesión iniciada sesión, pero la sesión no está activa, es decir, no está en primer plano), "active" (sesión iniciada sesión y activa, es decir, en primer plano), "closing" (sesión nominalmente cerrada sesión, pero algunos procesos que le pertenecen todavía están presentes). En el futuro, se podrían definir estados adicionales; el código cliente debe estar escrito para ser robusto ante el retorno de cadenas de estado adicionales. Esta función es una versión más genérica de sd_session_is_active(). La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_uid() puede usarse para determinar el identificador de usuario del usuario de Unix al que pertenece la sesión identificada por el identificador de sesión especificado.

sd_session_get_username() puede usarse para determinar el nombre del usuario de Unix al que pertenece la sesión identificada por el identificador de sesión especificado. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_seat() puede usarse para determinar el identificador del asiento al que pertenece la sesión identificada por el identificador de sesión especificado. Tenga en cuenta que no todas las sesiones están conectadas a un asiento; esta llamada fallará (devolviendo -ENODATA) para ellas. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_start_time() puede usarse para determinar la hora de inicio de la sesión identificada por el identificador de sesión especificado. El usec está en microsegundos desde la época (CLOCK_REALTIME).

sd_session_get_service() puede usarse para determinar el nombre del servicio (pasado durante la configuración de la sesión PAM) que registró la sesión identificada por el identificador de sesión especificado. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_type() puede usarse para determinar el tipo de la sesión identificada por el identificador de sesión especificado. La cadena devuelta es una de "x11", "wayland", "tty", "mir" o "unspecified" y debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_class() puede usarse para determinar la clase de la sesión identificada por el identificador de sesión especificado. La cadena devuelta es una de "user", "user-early", "user-light", "user-early-light", "user-incomplete", "greeter", "lock-screen", "background", "background-light", "manager" o "manager-early" y debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_desktop() puede usarse para determinar la marca del escritorio que se ejecuta en la sesión identificada por el identificador de sesión especificado. Este campo puede ser establecido libremente por los entornos de escritorio y no sigue ningún formato especial. Sin embargo, se recomienda encarecidamente a los escritorios que utilicen los mismos identificadores y capitalización que para $XDG_CURRENT_DESKTOP, según lo definido por la Especificación de Entrada de Escritorio[1]. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_display() puede usarse para determinar la pantalla X11 de la sesión identificada por el identificador de sesión especificado. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_leader() puede usarse para determinar el PID del líder de la sesión identificada por el identificador de sesión especificado.

sd_session_get_remote_host() puede usarse para determinar el nombre de host remoto de la sesión identificada por el identificador de sesión especificado. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_remote_user() puede usarse para determinar el nombre de usuario remoto de la sesión identificada por el identificador de sesión especificado. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso. Tenga en cuenta que este valor rara vez es conocido por el sistema, e incluso entonces no debe confiarse en él.

sd_session_get_tty() puede usarse para determinar el dispositivo TTY de la sesión identificada por el identificador de sesión especificado. La cadena devuelta debe liberarse con la llamada free(3) de libc después de su uso.

sd_session_get_vt() puede usarse para determinar el número de VT de la sesión identificada por el identificador de sesión especificado. Esta función devolverá un error si el asiento no admite VTs.

Si el parámetro session de cualquiera de estas funciones se pasa como NULL, la operación se ejecuta para la sesión de la que el proceso que llama es miembro, si hay alguna.

NAME

sd_session_get_display, sd_session_get_leader, sd_session_get_remote_host, sd_session_get_remote_user, sd_session_get_tty, sd_session_get_vt, sd_session_is_remote, sd_session_get_desktop, sd_session_get_username, sd_session_get_state, sd_session_get_start_time - Get information about a session

SYNOPSIS

All functions listed in this page share the following properties:

#include <systemd/sd-login.h>

int sd_session_get_display(const char *session, const char **display);
int sd_session_get_leader(const char *session, pid_t *leader);
int sd_session_get_remote_user(const char *session, const char **remote_user);
int sd_session_get_remote_host(const char *session, const char **remote_host);
int sd_session_get_tty(const char *session, const char **tty);
int sd_session_get_vt(const char *session, int *vt);
int sd_session_is_remote(const char *session);
int sd_session_get_desktop(const char *session, const char **desktop);
int sd_session_get_username(const char *session, const char **username);
int sd_session_get_state(const char *session, const char **state);
int sd_session_get_start_time(const char *session, time_t *st);

DESCRIPTION

These functions may be used to retrieve various metadata associated with a session. The session is identified by its session ID string, which is the first argument. If the session ID is NULL, the current session is used.

sd_session_get_display() retrieves the display name (e.g. ":0") of the session.

sd_session_get_leader() retrieves the process ID of the session's leader process.

sd_session_get_remote_user() retrieves the login name of the remote user, if the session is remote.

sd_session_get_remote_host() retrieves the hostname of the remote host, if the session is remote.

sd_session_get_tty() retrieves the name of the TTY device (e.g. "tty1") associated with the session, if any.

sd_session_get_vt() retrieves the number of the virtual terminal (e.g. 1) associated with the session, if any.

sd_session_is_remote() checks if the session is remote. Returns 1 if the session is remote, 0 otherwise.

sd_session_get_desktop() retrieves the desktop environment name (e.g. "gnome-shell") of the session, if set.

sd_session_get_username() retrieves the login name of the user running the session.

sd_session_get_state() retrieves the session state string (e.g. "running", "closing"). See sd-login(3) for possible states.

sd_session_get_start_time() retrieves the session start time as seconds since the Epoch.

RETURN VALUE

On success, these calls return 0 or a positive integer. On failure, these calls return a negative errno-style error code.

Errors

Returned errors may indicate the following problems:

-ENXIO

The specified session does not exist.

-ENODATA

The given field is not specified for the described session.

-EINVAL

An input parameter was invalid (out of range, or NULL, where that is not accepted).

-ENOMEM

Memory allocation failed.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.

HISTORY

sd_session_get_tty() was added in version 198.

sd_session_get_vt() was added in version 207.

sd_session_is_remote(), sd_session_get_remote_host(), and sd_session_get_remote_user() were added in version 209.

sd_session_get_desktop() was added in version 217.

sd_session_get_username(), sd_session_get_start_time(), and sd_session_get_leader() were added in version 254.
