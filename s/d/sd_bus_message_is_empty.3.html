sd_bus_message_is_empty(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_MESSAGE_GET_SIGNATURE(3) sd_bus_message_get_signature SD_BUS_MESSAGE_GET_SIGNATURE(3)

NOMBRE

sd_bus_message_get_signature, sd_bus_message_is_empty, sd_bus_message_has_signature - Consultar la firma del mensaje del bus

SINOPSIS

#include <systemd/sd-bus.h>

const char* sd_bus_message_get_signature(sd_bus_message *mensaje, int completo);

int sd_bus_message_is_empty(sd_bus_message *mensaje);

int sd_bus_message_has_signature(sd_bus_message *mensaje, const char *firma);

DESCRIPCIÓN

sd_bus_message_get_signature() devuelve la firma del mensaje mensaje. Si completo es verdadero, se devuelve la firma del mensaje completo, y solo la firma del contenedor actualmente abierto en caso contrario.

sd_bus_message_is_empty() devuelve verdadero si el mensaje está vacío, es decir, cuando su firma está vacía.

sd_bus_message_has_signature() devuelve verdadero si la firma del mensaje mensaje coincide con la firma dada. El parámetro firma puede ser NULL, lo que se trata igual que una cadena vacía, que es equivalente a llamar a sd_bus_message_is_empty().

VALOR DE RETORNO

En caso de éxito, sd_bus_message_get_signature() devuelve la firma, y NULL en caso de error.

Las otras funciones devuelven 0 o un entero positivo en caso de éxito. En caso de fallo, devuelven un código de error negativo de tipo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

El parámetro mensaje es NULL.

NULL

El parámetro mensaje es NULL.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_message_get_signature(), sd_bus_message_is_empty(), y sd_bus_message_has_signature() se añadieron en la versión 240.
