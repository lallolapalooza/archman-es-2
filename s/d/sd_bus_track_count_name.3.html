SD_BUS_TRACK_ADD_NAME(3) sd_bus_track_add_name SD_BUS_TRACK_ADD_NAME(3)

NOMBRE

sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, sd_bus_track_remove_sender, sd_bus_track_count, sd_bus_track_count_sender, sd_bus_track_count_name, sd_bus_track_contains, sd_bus_track_first, sd_bus_track_next - Añadir, eliminar y recuperar compañeros de bus rastreados en un objeto de rastreo de compañeros de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_track_add_name(sd_bus_track* t, const char* name);

int sd_bus_track_add_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_remove_name(sd_bus_track* t, const char* name);

int sd_bus_track_remove_sender(sd_bus_track* t, sd_bus_message* message);

unsigned sd_bus_track_count(sd_bus_track* t);

int sd_bus_track_count_name(sd_bus_track* t, const char* name);

int sd_bus_track_count_sender(sd_bus_track* t, sd_bus_message* message);

int sd_bus_track_contains(sd_bus_track* t, const char* name);

const char* sd_bus_track_first(sd_bus_track* t);

const char* sd_bus_track_next(sd_bus_track* t);

DESCRIPCIÓN

sd_bus_track_add_name() añade un compañero para rastrear a un objeto de rastreo de compañeros de bus. El primer argumento debe referirse a un objeto de rastreo de compañeros de bus creado con sd_bus_track_new(3), el segundo nombre debe referirse a un nombre de compañero D-Bus a rastrear, ya sea en formato de servicio único o conocido. Si el nombre aún no se está rastreando, se añadirá a la lista de nombres a rastrear. Si ya se está rastreando y el modo no recursivo está activado, no se ejecutará ninguna operación con esta llamada. Si el modo recursivo está activado, un contador por nombre se incrementará en uno cada vez que se invoque esta llamada, y sd_bus_track_remove_name() deberá llamarse tantas veces como sd_bus_track_add_name() se haya invocado antes para detener el rastreo del nombre. Utilice sd_bus_track_set_recursive(3) para cambiar del modo no recursivo predeterminado al modo recursivo, o viceversa. Tenga en cuenta que el nombre especificado se rastrea tal cual, los nombres conocidos no se resuelven a nombres únicos con esta llamada. Tenga en cuenta que múltiples objetos de rastreo de compañeros de bus pueden rastrear el mismo nombre.

sd_bus_track_remove_name() deshace el efecto de sd_bus_track_add_name() y elimina un nombre de compañero de bus de la lista de compañeros a vigilar. Dependiendo de si el modo no recursivo o recursivo está activado para el objeto de rastreo de compañeros de bus, esta llamada eliminará completamente el nombre del objeto de rastreo o simplemente decrementará el contador por nombre en uno, eliminando el nombre solo cuando el contador llegue a cero (ver arriba). Tenga en cuenta que un compañero de bus que se desconecta del bus eliminará implícitamente sus nombres completamente del objeto de rastreo de compañeros de bus, independientemente del contador por nombre actual.

sd_bus_track_add_sender() y sd_bus_track_remove_sender() son similares a sd_bus_track_add_name() y sd_bus_track_remove_name(), pero toman un mensaje de bus como argumento. Se determina el remitente de este mensaje de bus y se añade/elimina del objeto de rastreo de compañeros de bus. Como los mensajes siempre se originan de nombres únicos y nunca de nombres conocidos, esto significa que esta llamada efectivamente solo añadirá nombres únicos al objeto de rastreo de compañeros de bus.

sd_bus_track_count() devuelve el número de nombres que están siendo rastreados actualmente por el objeto de rastreo de compañeros de bus especificado. Tenga en cuenta que esta función siempre devuelve el número real de nombres rastreados y, por lo tanto, si se ha invocado sd_bus_track_add_name() varias veces para el mismo nombre, solo se cuenta como uno, independientemente de si se utiliza el modo recursivo o no.

sd_bus_track_count_name() devuelve el contador actual por nombre para el nombre especificado. Si se utiliza el modo no recursivo, devuelve 1 o 0, dependiendo de si el nombre especificado se ha añadido previamente al objeto de rastreo o no. Si se ha habilitado el modo recursivo, también pueden devolverse valores mayores que 1, en caso de que sd_bus_track_add_name() se haya llamado varias veces para el mismo nombre.

sd_bus_track_count_sender() es similar a sd_bus_track_count_name(), pero toma un objeto de mensaje de bus y devuelve el contador por nombre que coincide con el remitente del mensaje.

sd_bus_track_contains() se puede utilizar para determinar si el nombre especificado se ha añadido al menos una vez al objeto de rastreo de compañeros de bus especificado.

sd_bus_track_first() y sd_bus_track_next() se pueden utilizar para enumerar todos los nombres que están siendo rastreados actualmente por el objeto de rastreo de compañeros de bus pasado. sd_bus_track_first() devuelve la primera entrada del objeto y restablece un índice de lectura mantenido internamente. Cada invocación subsiguiente de sd_bus_track_next() devuelve el siguiente nombre contenido en el objeto de bus. Si se llega al final, se devuelve NULL. Si aún no se han añadido nombres al objeto, sd_bus_track_first() devolverá NULL inmediatamente. El orden en que se devuelven los nombres no está definido; en particular, no está definido qué nombre se considera el primero devuelto. Si el modo recursivo está activado y el mismo nombre se ha añadido varias veces al objeto de rastreo de compañeros de bus, solo se devuelve una vez en esta enumeración. Si se añaden nuevos nombres o se eliminan nombres existentes del objeto de rastreo de compañeros de bus mientras se está enumerando, la enumeración finaliza en la próxima invocación de sd_bus_track_next() ya que se devuelve NULL.

VALOR DE RETORNO

En caso de éxito, sd_bus_track_add_name() y sd_bus_track_add_sender() devuelven 0 si el nombre especificado ya se había añadido previamente al objeto de rastreo de compañeros de bus y un valor positivo si no. En caso de error, devuelven un código de error negativo al estilo errno.

sd_bus_track_remove_name() y sd_bus_track_remove_sender() devuelven un valor positivo si el nombre especificado estaba previamente rastreado por el objeto de rastreo de compañeros de bus y ahora ha sido eliminado. En modo no recursivo, se devuelve 0 si el nombre especificado aún no estaba siendo rastreado. En modo recursivo, se devuelve -EUNATCH en este caso. En caso de error, devuelven un código de error negativo al estilo errno.

sd_bus_track_count() devuelve el número de nombres que se están rastreando actualmente, o 0 en caso de error.

sd_bus_track_count_name() y sd_bus_track_count_sender() devuelven el contador actual por nombre para el nombre especificado o el remitente del mensaje especificado. Se devuelve cero para los nombres que aún no se están rastreando, un valor positivo para los nombres añadidos al menos una vez. Los valores mayores que 1 solo se devuelven en modo recursivo. En caso de error, se devuelve un código de error negativo al estilo errno.

sd_bus_track_contains() devuelve el nombre pasado si existe en el objeto de rastreo de compañeros de bus. En caso de error, y si el nombre aún no se ha añadido, se devuelve NULL.

sd_bus_track_first() y sd_bus_track_next() devuelven el primer/siguiente nombre contenido en el objeto de rastreo de compañeros de bus, y NULL si se llega al final de la enumeración y en caso de error.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EUNATCH

Se ha invocado sd_bus_track_remove_name() o sd_bus_track_remove_sender() para un nombre no añadido previamente al objeto de bus.

-EINVAL

El parámetro especificado es inválido.

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar solo llamadas a setenv()

sd_bus_track_count_name(3) - Arch Linux

NAME

sd_bus_track_count_name, sd_bus_track_count_sender - Get the number of bus names or senders in a bus track object

SYNOPSIS

#include <systemd/sd-bus.h>

size_t sd_bus_track_count_name(sd_bus_track *track);
size_t sd_bus_track_count_sender(sd_bus_track *track);

DESCRIPTION

sd_bus_track_count_name() returns the number of bus names that are currently registered in the bus track object track. This count includes names added via sd_bus_track_add_name(3). An empty track object contains 0 names.

sd_bus_track_count_sender() returns the number of senders that are currently registered in the bus track object track. This count includes senders added via sd_bus_track_add_sender(3). An empty track object contains 0 senders.

RETURN VALUE

On success, both functions return the number of bus names or senders registered in the track object, respectively. If track is NULL, they return 0.

NOTES

These functions are useful for determining if a bus track object is empty or contains any entries. They are generally inexpensive to call.

The track object is designed to track bus names or senders that are created or destroyed. The counts returned by these functions reflect the state of the track object at the time of the call. They do not necessarily reflect the number of active connections on the bus.

It is recommended to use these functions after the bus track object has been initialized and populated with entries, or to check for emptiness before proceeding with operations that depend on the presence of specific names or senders.

The track object should be created before adding any names or senders. Use sd_bus_track_new(3) to create a new track object. Ensure that the track object is properly managed and freed when no longer needed using sd_bus_track_unref(3).

These functions can be safely called from any thread, including from within an event loop handler. It is safe to call them even from an early phase of the program when no other threads have been started.
