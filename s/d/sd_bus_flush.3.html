SD_BUS_CLOSE(3) sd_bus_close SD_BUS_CLOSE(3)

NOMBRE

sd_bus_close, sd_bus_flush, sd_bus_default_flush_close - Cerrar y vaciar una conexión de bus

SINOPSIS

#include <systemd/sd-bus.h>

void sd_bus_close(sd_bus *bus);

int sd_bus_flush(sd_bus *bus);

void sd_bus_default_flush_close(void);

DESCRIPCIÓN

sd_bus_close() desconecta la conexión de bus especificada. Cuando se invoca esta llamada y el objeto de bus especificado se refiere a una conexión activa, esta se termina inmediatamente. No se pueden enviar ni recibir más mensajes a través de ella. Se liberan todos los mensajes en cola en el objeto de bus (tanto entrantes como salientes). Si se invoca en un objeto de bus NULL o cuando la conexión de bus ya está cerrada, esta función no realiza ninguna operación. Esta llamada no libera ni desreferencia el objeto de bus en sí. Utilice sd_bus_unref(3) para eso.

sd_bus_flush() escribe de forma síncrona todos los mensajes salientes en cola en una conexión de bus si los hay. Esta llamada a función puede bloquearse si el par no está procesando los mensajes del bus rápidamente.

Antes de que un programa termine, suele ser una buena idea vaciar todos los mensajes pendientes con sd_bus_flush() y luego cerrar las conexiones con sd_bus_close() para asegurar que no se pierdan mensajes sin escribir, que no se puedan poner más mensajes en cola y que se liberen todos los mensajes entrantes pero no procesados. Después de realizar ambas operaciones, es aconsejable también soltar las referencias restantes al objeto de bus para que pueda ser liberado. Dado que estas tres operaciones se realizan con frecuencia juntas, se proporciona una llamada auxiliar sd_bus_flush_close_unref(3) que las combina en una.

sd_bus_default_flush_close() es similar a sd_bus_flush_close_unref(), pero no toma un argumento de puntero de bus y en su lugar itera sobre cualquiera de los buses "predeterminados" abiertos por sd_bus_default(3), sd_bus_default_user(3), sd_bus_default_system(3) y llamadas similares. sd_bus_default_flush_close() es particularmente útil para limpiar cualquier bus abierto utilizando esas llamadas antes de que el programa finalice.

VALOR DE RETORNO

En caso de éxito, sd_bus_flush() devuelve un entero no negativo. En caso de error, devuelve un código de error negativo de tipo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ECHILD

La conexión de bus se ha creado en un proceso, biblioteca o instancia de módulo diferente.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_close() y sd_bus_flush() se añadieron en la versión 221.

sd_bus_default_flush_close() se añadió en la versión 227.
