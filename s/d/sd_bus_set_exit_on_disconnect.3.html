sd_bus_set_exit_on_disconnect(3)

SD_BUS_SET_EXIT_ON_DISCONNECT(3) sd_bus_set_exit_on_disconnect SD_BUS_SET_EXIT_ON_DISCONNECT(3)

NOMBRE

sd_bus_set_exit_on_disconnect, sd_bus_get_exit_on_disconnect - Controlar el comportamiento de salida al desconectarse el objeto del bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_set_exit_on_disconnect(sd_bus *bus, int b);

int sd_bus_get_exit_on_disconnect(sd_bus *bus);

DESCRIPCIÓN

sd_bus_set_exit_on_disconnect() se puede utilizar para configurar el comportamiento de salida cuando el objeto del bus dado se desconecta. Si b es cero, no se ejecuta ninguna lógica especial cuando el objeto del bus se desconecta. Si b no es cero, el comportamiento al desconectarse depende de si el objeto del bus está adjunto a un bucle de eventos o no. Si el objeto del bus está adjunto a un bucle de eventos (ver sd_bus_attach_event(3)), el bucle de eventos se cierra cuando el objeto del bus se desconecta (como si se llamara a sd_event_exit(3)). De lo contrario, se llama a exit(3). El código de salida pasado a sd_event_exit() y exit() es EXIT_FAILURE. Si el objeto del bus ya se ha desconectado al habilitar el comportamiento de salida, el comportamiento de salida se ejecuta inmediatamente. Por defecto, el comportamiento de salida está deshabilitado.

sd_bus_get_exit_on_disconnect() devuelve si el comportamiento de salida al desconectarse está habilitado para el objeto del bus dado.

VALOR DE RETORNO

En caso de éxito, sd_bus_set_exit_on_disconnect() devuelve un entero no negativo. En caso de error, devuelve un código de error negativo al estilo errno.

sd_bus_get_exit_on_disconnect() devuelve un entero positivo si el comportamiento de salida al desconectarse está habilitado. De lo contrario, devuelve cero.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Un parámetro requerido era NULL.

Añadido en la versión 246.

-ENOPKG

No se pudo resolver el objeto del bus.

Añadido en la versión 246.

-ECHILD

La conexión del bus se creó en un proceso, biblioteca o instancia de módulo diferente.

Añadido en la versión 246.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_set_exit_on_disconnect() y sd_bus_get_exit_on_disconnect() se añadieron en la versión 246.
