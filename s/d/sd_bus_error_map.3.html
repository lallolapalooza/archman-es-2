sd_bus_error_map(3)

SD_BUS_ERROR_ADD_MAP(3) sd_bus_error_add_map SD_BUS_ERROR_ADD_MAP(3)

NOMBRE

sd_bus_error_add_map, sd_bus_error_map, SD_BUS_ERROR_MAP, SD_BUS_ERROR_END - Mapeos adicionales de errores sd-dbus

SINOPSIS

#include <systemd/sd-bus.h>
typedef struct {
        const char *name;
        int code;
        ...
} sd_bus_error_map;
SD_BUS_ERROR_MAP(nombre, código)
SD_BUS_ERROR_MAP_END

int sd_bus_error_add_map(const sd_bus_error_map *map);

DESCRIPCIÓN

La llamada sd_bus_error_add_map() puede ser utilizada para registrar mapeos adicionales para convertir errores de D-Bus a errores de estilo errno de Linux. Los mapeos definidos con esta llamada son consultados por llamadas como sd_bus_error_set(3) o sd_bus_error_get_errno(3). Por defecto, se conocen una serie de mapeos genéricos y estandarizados, tal como se documenta en sd-bus-errors(3). Utilice esta llamada para añadir mapeos adicionales, específicos de la aplicación.

La función toma un puntero a una matriz de estructuras sd_bus_error_map. Se añade una referencia a la matriz especificada a las tablas de búsqueda de mapeos de errores. Tenga en cuenta que la estructura no se copia y, por lo tanto, es esencial que la matriz permanezca disponible y constante durante toda la vida restante del proceso.

La matriz de mapeo debe construirse con una serie de invocaciones de la macro SD_BUS_ERROR_MAP() que toman una cadena de nombre literal y un número de error (positivo) de estilo errno. La última entrada de la matriz debe ser una invocación de la macro SD_BUS_ERROR_MAP_END. La matriz no debe construirse sin el uso de estas dos macros.

Tenga en cuenta que la llamada es idempotente: es seguro invocarla varias veces con el mismo parámetro, lo que solo añadirá la matriz de mapeo pasada una vez.

Tenga en cuenta que la memoria asignada por esta llamada no está destinada a ser liberada durante la vida del proceso. No debe liberarse explícitamente.

VALOR DE RETORNO

sd_bus_error_add_map() devuelve un valor positivo cuando la nueva matriz se añadió a las tablas de búsqueda. Devuelve cero cuando la misma matriz ya se añadió anteriormente. En caso de error, se devuelve un código de error negativo de estilo errno. Consulte a continuación los códigos de error conocidos.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

La matriz de mapeo especificada es inválida.

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo pkg-config(1) de libsystemd .

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_error_add_map() se añadió en la versión 221.
