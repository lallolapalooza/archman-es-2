sdptool(1) Administración del sistema Linux sdptool(1)

Nombre

sdptool - controlar e interrogar servidores SDP

SINOPSIS

sdptool [OPCIONES] [COMANDO [PARAMETROS]]

DESCRIPCIÓN

sdptool(1) proporciona la interfaz para realizar consultas SDP en dispositivos Bluetooth y administrar una base de datos SDP local.

COMANDOS

Los siguientes comandos están disponibles. En todos los casos, bdaddr especifica el dispositivo a buscar o explorar. Si se usa local para bdaddr, se buscará en la base de datos SDP local.

Los servicios se identifican y manipulan con un handle_registro de 4 bytes (NO el nombre del servicio). Para encontrar el handle_registro de un servicio, busque la línea "Service RecHandle" en los resultados de search o browse.

search [--bdaddr bdaddr] [--tree] [--raw] [--xml] nombre_servicio
Buscar servicios.

Los nombres de servicio conocidos son DID, SP, DUN, LAN, FAX, OPUSH, FTP, HS, HF, HFAG, SAP, NAP, GN, PANU, HCRP, HID, CIP, A2SRC, A2SNK, AVRCT, AVRTG, UDIUE, UDITE y SYNCML.

browse [--tree] [--raw] [--xml] [bdaddr]
Explorar todos los servicios disponibles en el dispositivo especificado por una dirección Bluetooth como parámetro.
records [--tree] [--raw] [--xml] bdaddr
Recuperar todos los registros de servicio posibles.
add [ --handle=N --channel=N ]
Agregar un servicio a la base de datos SDP local.

Puede especificar un handle para este registro usando la opción --handle.

Puede especificar un canal para agregar el servicio usando la opción --channel.

NOTA: La configuración de los adaptadores locales no se actualizará y este comando solo debe usarse para pruebas SDP.

del handle_registro
Eliminar un servicio de la base de datos SDP local.

NOTA: La configuración de los adaptadores locales no se actualizará y este comando solo debe usarse para pruebas SDP.

get [--tree] [--raw] [--xml] [--bdaddr bdaddr] handle_registro
Recuperar un servicio de la base de datos SDP local.
setattr handle_registro id_atributo valor_atributo
Establecer o agregar un atributo a un registro SDP.
setseq handle_registro id_atributo valores_atributo
Establecer o agregar una secuencia de atributos a un registro SDP.

OPCIONES

--help
Muestra ayuda sobre el uso de sdptool.

EJEMPLOS

$ sdptool browse 00:80:98:24:15:6D
$ sdptool browse local
$ sdptool add DUN
$ sdptool del 0x10000
