sd_bus_slot_get_description(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_SLOT_SET_DESCRIPTION(3) sd_bus_slot_set_description SD_BUS_SLOT_SET_DESCRIPTION(3)

NOMBRE

sd_bus_slot_set_description, sd_bus_slot_get_description - Establecer o consultar la descripción de los objetos de ranura de bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_slot_set_description(sd_bus_slot* slot, const char *description);

int sd_bus_slot_get_description(sd_bus_slot* bus, const char **description);

DESCRIPCIÓN

sd_bus_slot_set_description() establece la cadena de descripción que se utiliza en los registros a la cadena especificada. La cadena se copia internamente y se libera cuando el objeto de ranura de bus se desasigna. El argumento description puede ser NULL, en cuyo caso la descripción se elimina.

sd_bus_slot_get_description() devuelve una cadena de descripción en description. Si la cadena no está establecida, por ejemplo, con sd_bus_slot_set_description(), y la ranura es una ranura de devolución de llamada de coincidencia de bus, se devolverá la cadena de coincidencia. De lo contrario, se devolverá -ENXIO.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0 o un entero positivo. En caso de error, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Un argumento requerido es NULL.

-ENXIO

El objeto de ranura de bus no tiene descripción.

-ENOMEM

Fallo en la asignación de memoria.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y vincular con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIAL

sd_bus_slot_set_description() y sd_bus_slot_get_description() se añadieron en la versión 240.
