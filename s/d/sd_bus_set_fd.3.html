SD_BUS_SET_FD(3) sd_bus_set_fd SD_BUS_SET_FD(3)

NOMBRE

sd_bus_set_fd - Establecer los descriptores de archivo para la comunicación del bus

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_set_fd(sd_bus *bus, int input_fd, int output_fd);

DESCRIPCIÓN

sd_bus_set_fd() establece los descriptores de archivo utilizados para comunicarse por un objeto de conexión del bus. Tanto input_fd como output_fd deben ser descriptores de archivo válidos, que se refieren a objetos de archivo basados en flujos (por ejemplo, un socket de flujo, un par de tuberías o FIFOs, o incluso un dispositivo TTY). input_fd debe ser legible y output_fd debe ser escribible. El mismo descriptor de archivo puede ser utilizado (y típicamente lo es) tanto como descriptor de archivo de entrada como de salida. Esta función debe llamarse antes de que la conexión del bus se inicie a través de sd_bus_start(3).

El objeto de conexión del bus tomará posesión de los descriptores de archivo pasados y los cerrará automáticamente cuando sea liberado. Utilice sd_bus_set_close_on_exit(3) para desactivar este comportamiento.

VALOR DE RETORNO

En caso de éxito, sd_bus_set_fd() devuelve un entero no negativo. En caso de error, devuelve un código de error negativo de estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

Se pasó un objeto de bus inválido.

Añadido en la versión 248.

-ECHILD

La conexión del bus se asignó en un proceso padre y se está reutilizando en un proceso hijo después de fork().

Añadido en la versión 248.

-EBADF

Se pasó un descriptor de archivo inválido a sd_bus_set_fd().

Añadido en la versión 248.

-ENOPKG

El bus no se puede resolver.

Añadido en la versión 248.

-EPERM

La conexión del bus ya ha sido iniciada.

Añadido en la versión 248.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que puede compilarse y enlazarse con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer las llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_bus_set_fd() se añadió en la versión 248.
