SD_BUS_SET_CLOSE_ON_EXIT(3) sd_bus_set_close_on_exit SD_BUS_SET_CLOSE_ON_EXIT(3)

NOMBRE

sd_bus_set_close_on_exit, sd_bus_get_close_on_exit - Controlar si se cierra la conexión del bus durante la fase de salida del bucle de eventos

SINOPSIS

#include <systemd/sd-bus.h>

int sd_bus_set_close_on_exit(sd_bus *bus, int b);

int sd_bus_get_close_on_exit(sd_bus *bus);

DESCRIPCIÓN

sd_bus_set_close_on_exit() se puede utilizar para habilitar o deshabilitar si la conexión del bus se vacía (como en sd_bus_flush(3)) y se cierra (como en sd_bus_close(3)) durante la fase de salida del bucle de eventos. Esta lógica solo se aplica a las conexiones del bus que están adjuntas a un bucle de eventos sd-event(3), ver sd_bus_attach_event(3). Por defecto, este mecanismo está habilitado y asegura que cualquier mensaje pendiente que no se haya escrito en la conexión del bus se escriba cuando el bucle de eventos se esté cerrando. En algunos casos, este comportamiento no es deseable, por ejemplo, cuando la conexión del bus debe permanecer utilizable hasta después de que el bucle de eventos haya salido. Si b es verdadero, la función está habilitada (que es el valor predeterminado), de lo contrario, está deshabilitada.

sd_bus_get_close_on_exit() se puede utilizar para consultar la configuración actual de esta función. Devuelve cero cuando la función está deshabilitada y un valor positivo si está habilitada.

VALOR DE RETORNO

En caso de éxito, sd_bus_set_close_on_exit() devuelve un entero no negativo. En caso de error, devuelve un código de error negativo estilo errno.

sd_bus_get_close_on_exit() devuelve 0 si la función está actualmente deshabilitada o un entero positivo si está habilitada. En caso de error, devuelve un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-ECHILD

La conexión del bus se creó en un proceso, biblioteca o instancia de módulo diferente.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que está declarado como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un subproceso paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros subprocesos.

HISTORIAL

sd_bus_set_close_on_exit() y sd_bus_get_close_on_exit() se agregaron en la versión 240.
