SD_EVENT_SOURCE_SET_FLOATING(3) sd_event_source_set_floating SD_EVENT_SOURCE_SET_FLOATING(3)

NOMBRE

sd_event_source_set_floating, sd_event_source_get_floating - Establecer o recuperar el estado 'flotante' de las fuentes de eventos

SINOPSIS

#include <systemd/sd-event.h>

int sd_event_source_set_floating(sd_event_source *fuente, int flotante);

int sd_event_source_get_floating(sd_event_source *fuente);

DESCRIPCIÓN

sd_event_source_set_floating() toma un valor booleano y establece el estado 'flotante' del objeto de fuente de eventos especificado. Esto se utiliza para cambiar la dirección de los recuentos de referencias para el objeto y el bucle de eventos con el que está asociado. En modo no flotante, el objeto de fuente de eventos mantiene una referencia al objeto del bucle de eventos, pero no viceversa. El creador del objeto de fuente de eventos debe mantener una referencia a él mientras la fuente deba existir. En modo flotante, el bucle de eventos mantiene una referencia al objeto de fuente y disminuirá el recuento de referencias al liberarse. Esto significa que se debe mantener una referencia al bucle de eventos para evitar que ambos se destruyan.

Varias llamadas que asignan objetos de fuente de eventos (es decir, sd_event_add_io(3), sd_event_add_time(3) y similares) establecerán automáticamente un objeto de fuente de eventos en modo 'flotante' si el llamador pasó NULL en el parámetro utilizado para devolver una referencia al objeto de fuente de eventos. Sin embargo, puede ser necesario obtener acceso temporal al objeto de fuente, por ejemplo, para ajustar las propiedades de la fuente de eventos después de la asignación (por ejemplo, su prioridad o cadena de descripción). En esos casos, el objeto puede crearse en modo no flotante, y la referencia devuelta se utiliza para ajustar las propiedades, y el objeto se marca como flotante después, y la referencia en el llamador se descarta.

sd_event_source_get_floating() se puede utilizar para consultar el estado 'flotante' actual del objeto de fuente de eventos fuente. Devuelve cero si el modo 'flotante' está desactivado, positivo si está activado.

VALOR DE RETORNO

En caso de éxito, sd_event_source_set_floating() y sd_event_source_get_floating() devuelven un entero no negativo. En caso de error, devuelven un código de error negativo estilo errno.

Errores

Los errores devueltos pueden indicar los siguientes problemas:

-EINVAL

fuente no es un puntero válido a un objeto sd_event_source.

Añadido en la versión 244.

-ECHILD

El bucle de eventos se creó en un proceso, biblioteca o instancia de módulo diferente.

Añadido en la versión 244.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.

HISTORIA

sd_event_source_set_floating() y sd_event_source_get_floating() se añadieron en la versión 244.
