Propósito:

!>
!>      SDRVSG comprueba los drivers del problema de eigenpartes generalizado real simétrico.
!>
!>              SSYGV calcula todos los valores propios y, opcionalmente, los vectores propios de un problema generalizado de eigenpartes definido real simétrico.
!>
!>              SSYGVD calcula todos los valores propios y, opcionalmente, los vectores propios de un problema generalizado de eigenpartes definido real simétrico utilizando un algoritmo de división y conquista.
!>
!>              SSYGVX calcula valores propios seleccionados y, opcionalmente, vectores propios de un problema generalizado de eigenpartes definido real simétrico.
!>
!>              SSPGV calcula todos los valores propios y, opcionalmente, los vectores propios de un problema generalizado de eigenpartes definido real simétrico en almacenamiento empaquetado.
!>
!>              SSPGVD calcula todos los valores propios y, opcionalmente, los vectores propios de un problema generalizado de eigenpartes definido real simétrico en almacenamiento empaquetado utilizando un algoritmo de división y conquista.
!>
!>              SSPGVX calcula valores propios seleccionados y, opcionalmente, vectores propios de un problema generalizado de eigenpartes definido real simétrico en almacenamiento empaquetado.
!>
!>              SSBGV calcula todos los valores propios y, opcionalmente, los vectores propios de un problema generalizado de eigenpartes definido real simétrico en banda.
!>
!>              SSBGVD calcula todos los valores propios y, opcionalmente, los vectores propios de un problema generalizado de eigenpartes definido real simétrico en banda utilizando un algoritmo de división y conquista.
!>
!>              SSBGVX calcula valores propios seleccionados y, opcionalmente, vectores propios de un problema generalizado de eigenpartes definido real simétrico en banda.
!>
!>      Cuando se llama a SDRVSG, se especifica un número de tamaños de matrices y un número de tipos de matrices. Para cada tamaño y cada tipo de matriz, se generará una matriz A del tipo dado; también se genera una matriz B aleatoria bien condicionada y el par (A,B) se utiliza para probar los drivers.
!>
!>      Para cada par (A,B), se realizan las siguientes pruebas:
!>
!>      (1) SSYGV con ITYPE = 1 y UPLO ='U':
!>
!>              | A Z - B Z D | / ( |A| |Z| n ulp )
!>
!>      (2) lo mismo que (1) pero llamando a SSPGV
!>      (3) lo mismo que (1) pero llamando a SSBGV
!>      (4) lo mismo que (1) pero con UPLO = 'L'
!>      (5) lo mismo que (4) pero llamando a SSPGV
!>      (6) lo mismo que (4) pero llamando a SSBGV
!>
!>      (7) SSYGV con ITYPE = 2 y UPLO ='U':
!>
!>              | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (8) lo mismo que (7) pero llamando a SSPGV
!>      (9) lo mismo que (7) pero con UPLO = 'L'
!>      (10) lo mismo que (9) pero llamando a SSPGV
!>
!>      (11) SSYGV con ITYPE = 3 y UPLO ='U':
!>
!>              | B A Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (12) lo mismo que (11) pero llamando a SSPGV
!>      (13) lo mismo que (11) pero con UPLO = 'L'
!>      (14) lo mismo que (13) pero llamando a SSPGV
!>
!>      SSYGVD, SSPGVD y SSBGVD realizaron las mismas 14 pruebas.
!>
!>      SSYGVX, SSPGVX y SSBGVX realizaron las pruebas anteriores de 14 con los parámetros RANGE = 'A', 'N' e 'I', respectivamente.
!>
!>      Los tamaños de matrices se especifican mediante un array NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!>      Los tipos de matrices se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!>      Este tipo se utiliza para la matriz A que tiene un ancho de banda semisuperior KA.
!>      B se genera como una matriz definida positiva bien condicionada con un ancho de banda semisuperior KB (<= KA).
!>      Actualmente, la lista de tipos posibles para A es:
!>
!>      (1) La matriz cero.
!>      (2) La matriz identidad.
!>
!>      (3) Una matriz diagonal con entradas espaciadas uniformemente
!>           1, ..., ULP y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1 )
!>      (4) Una matriz diagonal con entradas espaciadas geométricamente
!>           1, ..., ULP y signos aleatorios.
!>      (5) Una matriz diagonal con entradas
!>           1, ULP, ..., ULP y signos aleatorios.
!>
!>      (6) Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7) Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8) Una matriz de la forma U* D U, donde U es ortogonal y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (9) Una matriz de la forma U* D U, donde U es ortogonal y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (10) Una matriz de la forma U* D U, donde U es ortogonal y
!>           D tiene entradas 1, ULP,..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) matriz simétrica con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (16) Igual que (8), pero con KA = 1 y KB = 1
!>      (17) Igual que (8), pero con KA = 2 y KB = 1
!>      (18) Igual que (8), pero con KA = 2 y KB = 2
!>      (19) Igual que (8), pero con KA = 3 y KB = 1
!>      (20) Igual que (8), pero con KA = 3 y KB = 2
!>      (21) Igual que (8), pero con KA = 3 y KB = 3
!> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          SDRVSG no hace nada. Debe ser al menos cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Se omitirán los valores cero. Los valores deben ser al menos
!>          cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE. Si es cero, SDRVSG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es utilizar la matriz que esté en A. Esto
!>          sólo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>          No modificado.
!>
!>  DOTYPE  LOGICAL array, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 a
!>          MAXTYP no se generarán. Si NTYPES es mayor

sdrvsg.f(3)

NAME

sdrvsg - subroutine to test SSYGV, SSPGV, SSBGV, SSYGVD, SSPGVD, SSBGVD, SSYGVX, SSPGVX, and SSBGVX

SYNOPSIS

CALL SDRVSG( NSIZES, NN, NTYPES, ISEED, THRESH, NOUNIT, A, LDA, B, LDB, D,
             Z, LDZ, AB, BB, AP, BP, WORK, NWORK, IWORK, LIWORK, RESULT,
             INFO )

Function/Subroutine Documentation

This routine tests the following routines:

  * General matrix eigenvector routines:
    * SSYGV      -- compute the eigenvalues and eigenvectors of a real
    *              symmetric matrix A and a real symmetric positive definite
    *              (or indefinite) matrix B.
    * SSPGV      -- compute the eigenvalues and eigenvectors of a real
    *              symmetric matrix A and a real symmetric positive definite
    *              (or indefinite) matrix B, in packed storage.
    * SSBGV      -- compute the eigenvalues and eigenvectors of a real
    *              symmetric matrix A and a real symmetric positive definite
    *              (or indefinite) matrix B, in band storage.

  * Generalized eigenvalue routines for diagonal matrices:
    * SSYGVD     -- compute the eigenvalues and eigenvectors of a real
    *              symmetric matrix A and a real symmetric positive definite
    *              (or indefinite) matrix B.
    * SSPGVD     -- compute the eigenvalues and eigenvectors of a real
    *              symmetric matrix A and a real symmetric positive definite
    *              (or indefinite) matrix B, in packed storage.
    * SSBGVD     -- compute the eigenvalues and eigenvectors of a real
    *              symmetric matrix A and a real symmetric positive definite
    *              (or indefinite) matrix B, in band storage.

  * Routines that allow selecting the eigenvalue computation method:
    * SSYGVX     -- compute the eigenvalues and eigenvectors of a real
    *              symmetric matrix A and a real symmetric positive definite
    *              (or indefinite) matrix B.
    * SSPGVX     -- compute the eigenvalues and eigenvectors of a real
    *              symmetric matrix A and a real symmetric positive definite
    *              (or indefinite) matrix B, in packed storage.
    * SSBGVX     -- compute the eigenvalues and eigenvectors of a real
    *              symmetric matrix A and a real symmetric positive definite
    *              (or indefinite) matrix B, in band storage.

The routine tests the above routines in the following order:

  * SLATMR : Generates random matrices with specified properties.
  * SLATMS : Generates random symmetric matrices with specified properties.
  * SSYGV  : Computes the eigenvalues and eigenvectors of a symmetric
             matrix A and a symmetric positive definite matrix B.
  * SSPGV  : Computes the eigenvalues and eigenvectors of a symmetric
             matrix A and a symmetric positive definite matrix B,
             in packed storage.
  * SSBGV  : Computes the eigenvalues and eigenvectors of a symmetric
             matrix A and a symmetric positive definite matrix B,
             in band storage.
  * SSYGVD : Computes the eigenvalues and eigenvectors of a symmetric
             matrix A and a symmetric positive definite matrix B.
  * SSPGVD : Computes the eigenvalues and eigenvectors of a symmetric
             matrix A and a symmetric positive definite matrix B,
             in packed storage.
  * SSBGVD : Computes the eigenvalues and eigenvectors of a symmetric
             matrix A and a symmetric positive definite matrix B,
             in band storage.
  * SSYGVX : Computes the eigenvalues and eigenvectors of a symmetric
             matrix A and a symmetric positive definite matrix B.
  * SSPGVX : Computes the eigenvalues and eigenvectors of a symmetric
             matrix A and a symmetric positive definite matrix B,
             in packed storage.
  * SSBGVX : Computes the eigenvalues and eigenvectors of a symmetric
             matrix A and a symmetric positive definite matrix B,
             in band storage.
  * SLAFTS : Collects and reports results of the tests.

The following is a description of the input parameters to SDRVSG.

NSIZES
INTEGER. The number of values of N in NN. Not modified.
NN
INTEGER array, dimension (NSIZES).

Specifies the sizes of the matrices to be generated. NN(j) is the order of the matrices for the j-th problem. Not modified.

NTYPES
INTEGER. The number of types of matrices to be generated. For each type of matrix, a set of problems with different sizes and conditions numbers is generated. Not modified.
DOTYPE
LOGICAL array, dimension (NTYPES).

For each problem type J, DOTYPE(J) must be TRUE. if the J-th problem type is to be tested, and FALSE. otherwise. DOTYPE(J) is set to TRUE. for J=1 to MIN(NTYPES, 70). Note that the number of test types is limited to 70. Modified.

ISEED
INTEGER array, dimension (4).

On entry ISEED specifies the seed of the random number generator. The array elements should be between 0 and 4095; if not they will be reduced mod 4096. Also, ISEED(4) must be odd. The random number generator uses a linear congruential sequence limited to small integers, and so should produce machine independent random numbers. The values of ISEED are changed on exit, and can be used in the next call to SDRVSG to continue the same random number sequence. Modified.

THRESH
REAL.

A test will count as an error if the relative error, computed as described above, exceeds THRESH. Note that the error is scaled to be O(1), so THRESH should be a reasonably small multiple of 1, e.g., 10 or 100. In particular, it should not depend on the precision (single vs. double) or the size of the matrix. It must be at least zero. Not modified.

NOUNIT
INTEGER.

The FORTRAN unit number for printing out error messages (e.g., if a routine returns IINFO not equal to 0.) Not modified.

A
REAL array, dimension (LDA , max(NN)).

Used to hold the matrix whose eigenvalues are to be computed. On exit, A contains the last matrix actually used. Modified.

LDA
INTEGER.

The leading dimension of A and AB. It must be at least 1 and at least max( NN ). Not modified.

B
REAL array, dimension (LDB , max(NN)).

Used to hold the symmetric positive definite matrix for the generalized problem. On exit, B contains the last matrix actually used. Modified.

LDB
INTEGER.

The leading dimension of B and BB. It must be at least 1 and at least max( NN ). Not modified.

D
REAL array, dimension (max(NN)).

The eigenvalues of A. On exit, the eigenvalues in D correspond with the matrix in A. Modified.

Z
REAL array, dimension (LDZ, max(NN)).

The matrix of eigenvectors. Modified.

LDZ
INTEGER.

The leading dimension of Z. It must be at least 1 and at least max( NN ). Not modified.

AB
REAL array, dimension (LDA, max(NN)).

Workspace. Modified.

BB
REAL array, dimension (LDB, max(NN)).

Workspace. Modified.

AP
REAL array, dimension (max(NN)**2).

Workspace. Modified.

BP
REAL array, dimension (max(NN)**2).

Workspace. Modified.

WORK
REAL array, dimension (NWORK).

Workspace. Modified.

NWORK
INTEGER.

The number of entries in WORK. This must be at least 1+5*N+2*N*lg(N)+3*N**2 where N = max( NN(j) ) and lg( N ) = smallest integer k such that 2**k >= N. Not modified.

IWORK
INTEGER array, dimension (LIWORK).

Workspace. Modified.

LIWORK
INTEGER.

The number of entries in WORK. This must be at least 6*N. Not modified.

RESULT
REAL array, dimension (70).

The values computed by the 70 tests described above. Modified.

INFO
INTEGER.

If 0, then everything ran OK. -1: NSIZES < 0 -2: Some NN(j) < 0 -3: NTYPES < 0 -5: THRESH < 0 -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ). -16: LDZ < 1 or LDZ < NMAX. -21: NWORK too small. -23: LIWORK too small. If SLATMR, SLATMS, SSYGV, SSPGV, SSBGV, SSYGVD, SSPGVD, SSBGVD, SSYGVX, SSPGVX or SSBGVX returns an error code, the absolute value of it is returned. Modified.

----------------------------------------------------------------------

Some Local Variables and Parameters:

---- ----- --------- --- ----------

ZERO, ONE Real 0 and 1.

MAXTYP The number of types defined.

NTEST The number of tests that have been run on this matrix.

NTESTT The total number of tests for this call.

NMAX Largest value in NN.

NMATS The number of matrices generated so far.

NERRS The number of tests which have exceeded THRESH so far (computed by SLAFTS).

COND, IMODE Values to be passed to the matrix generators.

ANORM Norm of A; passed to matrix generators.

OVFL, UNFL Overflow and underflow thresholds.

ULP, ULPINV Finest relative precision and its inverse.

RTOVFL, RTUNFL Square roots of the previous 2 values. The following four arrays decode JTYPE:

KTYPE(j) The general type (1-10) for type J.

KMODE(j) The MODE value to be passed to the matrix generator for type J.

KMAGN(j) The order of magnitude ( O(1), O(overflow^(1/2) ), O(underflow^(1/2) )

----------------------------------------------------------------------

The loop which processes the types of matrices is

DO 110 JTYPE = 1, NTYPES
  IF (.NOT. DOTYPE(JTYPE)) GO TO 110
  NTEST = NTEST + 1
  ISTART = 1
  IF (JTYPE .GE. 10) ISTART = 2
  IF (JTYPE .GE. 70) ISTART = 4
  IF (JTYPE .GE. 80) ISTART = 5
  IF (JTYPE .GE. 90) ISTART = 7
