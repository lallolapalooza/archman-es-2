Propósito:

!>
!> SDRGES3 comprueba el controlador del problema de valores propios generalizados (forma de Schur) no simétrico SGGES3.
!>
!> SGGES3 factoriza A y B como Q S Z' y Q T Z', donde ' significa transpuesta, T es triangular superior, S está en forma de Schur generalizada (triangular superior por bloques, con bloques de 1x1 y 2x2 en la diagonal, los bloques 2x2 corresponden a pares de valores propios generalizados conjugados complejos), y Q y Z son ortogonales. También calcula los valores propios generalizados (alpha(j),beta(j)), j=1,...,n. Así, w(j) = alpha(j)/beta(j) es una raíz de la ecuación característica
!>                 det( A - w(j) B ) = 0
!> Opcionalmente, también reordena los valores propios para que un clúster seleccionado de valores propios aparezca en el bloque diagonal principal de las formas de Schur.
!>
!> Cuando se llama a SDRGES3, se especifica un número de tamaños de matriz () y un número de tipos de matriz. Para cada tamaño () y cada TIPO de matriz, se generará y utilizará un par de matrices (A, B) para las pruebas. Para cada par de matrices, se realizarán las siguientes 13 pruebas y se compararán con el umbral THRESH, excepto las pruebas (5), (11) y (13).
!>
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp ) (sin ordenación de valores propios)
!>
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp ) (sin ordenación de valores propios)
!>
!>
!> (3)   | I - QQ' | / ( n ulp ) (sin ordenación de valores propios)
!>
!>
!> (4)   | I - ZZ' | / ( n ulp ) (sin ordenación de valores propios)
!>
!> (5)   si A está en forma de Schur (es decir, forma cuasi-triangular)
!>       (sin ordenación de valores propios)
!>
!> (6)   si los valores propios = bloques diagonales de la forma de Schur (S, T),
!>       es decir, prueba el máximo sobre j de D(j) donde:
!>
!>       si alpha(j) es real:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) es complejo:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>       y S y T son aquí los bloques diagonales 2x2 de S y T
!>       correspondientes a los valores propios j y j+1.
!>       (sin ordenación de valores propios)
!>
!> (7)   | (A,B) - Q (S,T) Z' | / ( | (A,B) | n ulp )
!>            (con ordenación de valores propios).
!>
!> (8)   | I - QQ' | / ( n ulp ) (con ordenación de valores propios).
!>
!> (9)   | I - ZZ' | / ( n ulp ) (con ordenación de valores propios).
!>
!> (10)  si A está en forma de Schur (es decir, forma cuasi-triangular)
!>       (con ordenación de valores propios).
!>
!> (11)  si los valores propios = bloques diagonales de la forma de Schur (S, T),
!>       es decir, prueba el máximo sobre j de D(j) donde:
!>
!>       si alpha(j) es real:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) es complejo:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>       y S y T son aquí los bloques diagonales 2x2 de S y T
!>       correspondientes a los valores propios j y j+1.
!>       (con ordenación de valores propios).
!>
!> (12)  si la ordenación funcionó y SDIM es el número de valores propios
!>       que fueron SELECCIONADOS.
!>
!> Matrices de Prueba
!> =============
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array

!> Los tipos se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una identidad y una matriz cero)

!> (4)  ( I, I )         (un par de matrices identidad)

!>         t   t

!>                                     t                ( I   0  )

!>                                  ( 0   I  )          ( 0   J  )

!>                       k=(N-1)/2

!> (7)  ( D, I )         donde D es diag( 0, 1,..., N-1 ) (una matriz diagonal
!>                       con esas entradas diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde  es cercano al desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>

!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z    donde T1 y T2 son matrices triangulares superiores
!>                        con entradas O(1) aleatorias por encima de la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, 1, ..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de máquina.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorios.

NAME

sdrges3 -
This subroutine tests the driver routine SGGES3.

SYNOPSIS

SUBROUTINE SDRGES3(
     . )

Function/Subroutine Documentation

sdrges3 is a subroutine that tests the driver routine sgges3, which computes the generalized eigenvalues for a pair of general matrices (A, B).

The subroutine generates test matrices of various types and sizes, computes their generalized Schur factorization using sgges3, and then checks the accuracy of the results.

The following types of matrices are generated:

0
Matrices A and B are zero matrices.
1
Matrices A and B are random upper-triangular matrices.
2
Matrices A and B are random matrices.
3
Matrix A is a random upper-triangular matrix and matrix B is a random non-upper-triangular matrix.
4
Matrix A is a random non-upper-triangular matrix and matrix B is a random upper-triangular matrix.
5
Matrices A and B are random orthogonal matrices.
6
Matrix A is a random upper-triangular matrix and matrix B is a random orthogonal matrix.
7
Matrix A is a random orthogonal matrix and matrix B is a random upper-triangular matrix.
8
Matrices A and B are diagonal matrices.
9
Matrix A is a diagonal matrix and matrix B is a random matrix.
10
Matrix A is a random matrix and matrix B is a diagonal matrix.
11
Matrices A and B are upper-triangular matrices.
12
Matrix A is a upper-triangular matrix and matrix B is a random matrix.
13
Matrix A is a random matrix and matrix B is a upper-triangular matrix.
14
Matrices A and B are lower-triangular matrices.
15
Matrix A is a lower-triangular matrix and matrix B is a random matrix.
16
Matrix A is a random matrix and matrix B is a lower-triangular matrix.
17
Matrices A and B are matrices with random eigenvalues.
18
Matrices A and B are Hilbert matrices.
19
Matrices A and B are geometrically progressive matrices.
20
Matrices A and B are matrices with random integer entries.
21
Matrix A is a zero matrix and matrix B is a random matrix.
22
Matrix A is a random matrix and matrix B is a zero matrix.
23
Matrices A and B are random upper-triangular matrices with random eigenvalues.
24
Matrices A and B are random matrices with random eigenvalues.
25
Matrices A and B are upper-triangular matrices with specified diagonal elements.
26
Matrices A and B are random upper-triangular matrices.

The subroutine checks the following conditions:

1
Reconstruction of A and B from the computed Schur forms S and T, and the orthogonal matrices Q and Z.
2
Orthogonality of the computed matrices Q and Z.
3
Equality of the computed eigenvalues and the eigenvalues computed from the Schur forms.

The results of the tests are stored in the RESULT array.

Parameters

NSIZES 
!>          NSIZES is INTEGER
!>          The number of sizes of matrices to use.  If it is zero,
!>          SDRGES3 does nothing.  NSIZES >= 0.
!>

NN

!>          NN is INTEGER array, dimension (NSIZES)
!>          An array containing the sizes to be used for the matrices.
!>          Zero values will be skipped.  NN >= 0.
!>

NTYPES

!>          NTYPES is INTEGER
!>          The number of elements in DOTYPE.   If it is zero, SDRGES3
!>          does nothing.  It must be at least zero.  If it is MAXTYP+1
!>          and NSIZES is 1, then an additional type, MAXTYP+1 is
!>          defined, which is to use whatever matrix is in A on input.
!>          This is only useful if DOTYPE(1:MAXTYP) is .FALSE. and
!>          DOTYPE(MAXTYP+1) is .TRUE. .
!>

DOTYPE

!>          DOTYPE is LOGICAL array, dimension (NTYPES)
!>          If DOTYPE(j) is .TRUE., then for each size in NN a
!>          matrix of that size and of type j will be generated.
!>          If NTYPES is smaller than the maximum number of types
!>          defined (PARAMETER MAXTYP), then types NTYPES+1 through
!>          MAXTYP will not be generated. If NTYPES is larger
!>          than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!>          will be ignored.
!>

ISEED

!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096. Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to SDRGES3 to continue the same random number
!>          sequence.
!>

THRESH

!>          THRESH is REAL
!>          A test will count as  if the , computed as
!>          described above, exceeds THRESH.  Note that the error is
!>          scaled to be O(1), so THRESH should be a reasonably small
!>          multiple of 1, e.g., 10 or 100.  In particular, it should
!>          not depend on the precision (single vs. double) or the size
!>          of the matrix.  THRESH >= 0.
!>

NOUNIT

!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IINFO not equal to 0.)
!>

A

!>          A is REAL array,
!>                                       dimension(LDA, max(NN))
!>          Used to hold the original A matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of A, B, S, and T.
!>          It must be at least 1 and at least max( NN ).
!>

B

!>          B is REAL array,
!>                                       dimension(LDA, max(NN))
!>          Used to hold the original B matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!>          S is REAL array, dimension (LDA, max(NN))
!>          The Schur form matrix computed from A by SGGES3.  On exit, S
!>          contains the Schur form matrix corresponding to the matrix
!>          in A.
!>

T

!>          T is REAL array, dimension (LDA, max(NN))
!>          The upper triangular matrix computed from B by SGGES3.
!>

Q

!>          Q is REAL array, dimension (LDQ, max(NN))
!>          The (left) orthogonal matrix computed by SGGES3.
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of Q and Z. It must
!>          be at least 1 and at least max( NN ).
!>

Z

!>          Z is REAL array, dimension( LDQ, max(NN) )
!>          The (right) orthogonal matrix computed by SGGES3.
!>

ALPHAR

!>          ALPHAR is REAL array, dimension (max(NN))
!>

ALPHAI

!>          ALPHAI is REAL array, dimension (max(NN))
!>

BETA

!>          BETA is REAL array, dimension (max(NN))
!>
!>          The generalized eigenvalues of (A,B) computed by SGGES3.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) is the k-th
!>          generalized eigenvalue of A and B.
!>

WORK

!>          WORK is REAL array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          LWORK >= MAX( 10*(N+1), 3*N*N ), where N is the largest
!>          matrix dimension.
!>

RESULT

!>          RESULT is REAL array, dimension (15)
!>          The values computed by the tests described above.
!>          The values are currently limited to 1/ulp, to avoid overflow.
!>

BWORK

!>          BWORK is LOGICAL array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  A routine returned an error code.  INFO is the
!>                absolute value of the INFO value returned.
!>
