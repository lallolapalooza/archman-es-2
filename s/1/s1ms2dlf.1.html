NOMBRE

s1ms2dlf - convierte los archivos de registro SMTP de SunONE Messaging Server al DLF de correo electrónico

SINOPSIS

nms2dlf

DESCRIPCIÓN

Este programa convierte un archivo de registro de SunONE Messaging Server generado por el servicio SMTP al DLF de correo electrónico de Lire. El archivo de registro se espera en la entrada estándar, el archivo DLF se imprime en la salida estándar.

Para procesar correctamente el archivo de registro, debe activar el registro de los siguientes canales:

LIMITACIONES

Este convertidor DLF fue desarrollado para SunONE Messaging Server versión 5.2. Otras versiones pueden funcionar o no. Póngase en contacto con los desarrolladores de LogReport si tiene problemas con este convertidor.

Puede encontrar información sobre el formato de registro utilizado por SunONE Messaging Server en la siguiente URL:

http://docs.sun.com/source/816-6009-10/logging.htm

CONFIGURACIÓN DEL REGISTRO DEL MÓDULO MAILBOX-DELIVER

Descubrimos que, de forma predeterminada, no hay registros del módulo de entrega de buzones. Para solucionar este problema, asegúrese de hacer lo siguiente:

1.
Acceda al MTA o Message Store de SunONE Messaging Server
2.
Conviértase en el usuario del servidor de correo (generalmente no debería ser root, sino típicamente un usuario como mailsrv o el que se definió en el momento de la instalación; consulte la propiedad de los archivos en su instancia de servidor de mensajes, por ejemplo)
3.
Vaya a la ubicación correcta, algo como: raíz-servidor/instancia-msg

Por ejemplo, podría ser: /opt/sunone/s1ms5/msg-mymailserver

4.
Haga: 
POR ESCRIBIR

EJEMPLOS

Para procesar un registro como el producido por Netscape Messaging Server

$ s1ms2dlf < mail.log

s1ms2dlf rara vez se usará por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report nms < /var/log/mail.log
