FBB::SharedMutex(3bobcat) Mutex para memoria compartida FBB::SharedMutex(3bobcat)

NOMBRE

FBB::SharedMutex - Mutex para memoria compartida

SINOPSIS

#include <bobcat/sharedmutex>
Opción de enlace: -lpthread, -lbobcat

DESCRIPCIÓN

La memoria compartida puede ser utilizada por múltiples procesos. Para sincronizar el acceso a la memoria compartida, se puede definir un FBB::SharedMutex dentro de un segmento de memoria compartida. Los objetos SharedMutex permiten a los clientes bloquear un segmento de memoria compartida antes de leer o escribir su contenido. Por ejemplo, la clase Bobcat FBB::SharedSegment define un SharedMutex en su segmento de memoria compartida.

La clase SharedMutex utiliza las facilidades ofrecidas por la biblioteca PThread para implementar el bloqueo de memoria compartida (no recursivo). Para forzar el desbloqueo de un segmento de memoria compartida (posiblemente) bloqueado, se puede llamar a su destructor.

Los mutexes SharedMutex no son recursivos, lo que provoca interbloqueos si su miembro lock se llama dos veces desde el mismo hilo de ejecución sin una llamada intermedia a unlock del mutex. Si esto causa preocupación, se puede definir una variable que indique si el bloqueo ya se ha obtenido.

CONSTRUCTORES, DESTRUCTOR

o
SharedMutex():
El constructor por defecto inicializa un objeto FBB::SharedMutex a un mutex de memoria compartida (usando el atributo PTHREAD_PROCESS_SHARED). Como un objeto FBB::SharedMutex normalmente se define dentro de un segmento de memoria compartida, la memoria del objeto ya está disponible. En este caso, se debe usar la colocación new para llamar al constructor. Por ejemplo, si un segmento de memoria compartida está adjunto al proceso actual en d_shared, y se debe definir un FBB::SharedMutex en la dirección de d_shared, entonces el objeto FBB::SharedMutex se puede inicializar así: 
    new (d_shared) FBB::SharedMutex;
Advertencia: al usar la colocación new para inicializar un SharedMutex, asegúrese de que el SharedMutex encaje dentro de un bloque (es decir, shared.blockOffset() + sizeof(SharedMemory) < shared.dataSegmentSize()). Si no es así, use seek para cambiar a un desplazamiento donde se cumpla esta igualdad, o simplemente use SharedMemory::create así: 
    FBB::SharedMemory::create<FBB::SharedMutex>();
o
~SharedMutex():
El destructor de la clase libera todos los bloqueos del segmento de memoria compartida anidados del proceso actual. Para destruir un objeto FBB::SharedMutex que ha sido construido usando el operador new de colocación, use 
d_sharedMutex->~SharedMutex();
(suponiendo que SharedMutex *d_sharedMutex apunta a la ubicación donde la colocación new ha inicializado previamente el objeto FBB::SharedMutex.)
Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO

o
void lock() const:
Al regresar de esta función miembro, el proceso actual ha bloqueado el segmento de memoria compartida. Tenga en cuenta que los objetos SharedMutex no son recursivos.
o
void unlock() const:
Se libera el bloqueo del segmento de memoria compartida del objeto. Esta función miembro también se puede llamar si el bloqueo del SharedMutex no se ha obtenido.

FUNCIÓN MIEMBRO PROTEGIDA

o
pthread_mutex_t *mutexPtr():
Se devuelve un puntero al objeto pthread_mutex_t utilizado por el objeto SharedMutex;

EJEMPLO

#include <sys/types.h>
#include <signal.h>
#include <iostream>
#include <string>
#include <chrono>
#include <bobcat/fork>
#include <bobcat/semaphore>
#include <bobcat/sharedsegment>
#include <bobcat/sharedmutex>
using namespace std;
using namespace FBB;
class Wait: public Fork
{
    SharedSegment *d_shared;
    int d_id;
    SharedMutex *d_mutex;
    public:
        Wait();
        ~Wait();
        void childProcess() override;
        void parentProcess() override;
};
Wait::Wait()
:
    d_shared(SharedSegment::create(&d_id, 1, 100, 0700)),
    d_mutex(new (d_shared) SharedMutex)
{
    cout << "shared memory ID = " << d_id << ’\n’;
}
Wait::~Wait()
{
    d_mutex->~SharedMutex();
    SharedSegment::deleteSegment(d_id);
    cout << "deleted the shared memory\n";
}
void Wait::childProcess()
{
    Semaphore waiter{0};
    while (true)
    {
        waiter.wait_for(chrono::seconds(2));
        d_mutex->lock();
        cout << "child hello\n";
        d_mutex->unlock();
    }
}
void Wait::parentProcess()
{
    string line;
    do
    {
        cout << "press enter to allow the parent to locck\n";
        cin.ignore(100, ’\n’);
        d_mutex->lock();
        cout << "parent has the lock, press enter to continue "
                "(to end: some input)\n";
        getline(cin, line);
        d_mutex->unlock();
    }
    while (line.empty());
    kill(pid(), SIGTERM);
}
int main()
{
    Wait waiter;
    waiter.fork();
}
