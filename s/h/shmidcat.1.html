SHMIDCAT(1) Trampolín de memoria compartida SHMIDCAT(1)

NOMBRE

shmidcat - Copia stdin/archivo a un bloque de memoria compartida para gtkwave(1)

SINTAXIS

shmidcat [ARCHIVO_VCD]

DESCRIPCIÓN

Copia el archivo especificado en la línea de comandos o stdin (si no se especifica archivo) línea por línea a un bloque de memoria compartida. stdout contendrá un ID de memoria compartida que debe pasarse a gtkwave(1).

EJEMPLOS

Para ejecutar este programa de la manera estándar, escriba:

cat whatever.vcd | shmidcat
El ID de memoria compartida se emite a stdout.
shmidcat whatever.vcd | gtkwave -v -I whatever.sav
GTKWave toma directamente el ID de stdin.

LIMITACIONES

Este programa es principalmente solo para fines ilustrativos y de prueba. Su uso principal es para personas que deseen escribir volcadores de VCD interactivos para gtkwave(1), ya que su código fuente puede ser examinado, particularmente la función emit_string(). También se puede usar para probar si un archivo VCD existente se cargará correctamente en modo interactivo. Tenga en cuenta que también se puede usar para redirigir archivos VCD que se escriben en una tubería a gtkwave(1) de forma no bloqueante.
