SHA224SUM(1) Comandos de usuario SHA224SUM(1)

NOMBRE

sha224sum - calcula y verifica el resumen de mensajes SHA224

SINOPSIS

sha224sum [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Imprime o verifica sumas de control SHA224 (224 bits).

Sin ARCHIVO, o cuando ARCHIVO es -, lee de la entrada estándar.

-b, --binary
lee en modo binario
-c, --check
lee sumas de control de los ARCHIVOS y las verifica
--tag
crea una suma de control estilo BSD
-t, --text
lee en modo texto (por defecto)
-z, --zero
termina cada línea de salida con NULO, no con nueva línea, y deshabilita el escapado de nombres de archivo

Las siguientes cinco opciones son útiles solo al verificar sumas de control:

--ignore-missing
no falla ni informa estado de archivos faltantes
--quiet
no imprime OK para cada archivo verificado correctamente
--status
no muestra nada, el código de estado muestra el éxito
--strict
sale con un valor no cero para líneas de suma de control mal formateadas
-w, --warn
advierte sobre líneas de suma de control mal formateadas
--help
muestra esta ayuda y sale
--version
muestra información de versión y sale

Las sumas se calculan como se describe en la RFC 3874. Al verificar, la entrada debe ser una salida anterior de este programa. El modo por defecto es imprimir una línea con: suma de control, un espacio, un carácter que indica el modo de entrada ('*' para binario, ' ' para texto o donde el binario es insignificante), y el nombre para cada ARCHIVO.

No hay diferencia entre el modo binario y el modo texto en sistemas GNU.
