DESCRIPCIÓN

Las rutinas de "get" con paso especificado recuperan datos de matriz disponibles en la dirección source en el PE remoto (pe). Los elementos de la matriz source están separados por un paso (sst). Una vez que los datos son recibidos, se almacenan en la dirección de memoria local target, separados por el paso (tst). Las rutinas devuelven cuando los datos han sido copiados en la matriz local target.

Los argumentos son los siguientes:

target
Matriz a actualizar en el PE local.
source
Matriz que contiene los datos a copiar en el PE remoto.
tst
El paso entre elementos consecutivos de la matriz destino. El paso se escala por el tamaño del elemento de la matriz destino. Un valor de 1 indica datos contiguos. tst debe ser de tipo entero. Si llamas desde Fortran, debe ser un valor entero predeterminado.
sst
El paso entre elementos consecutivos de la matriz fuente. El paso se escala por el tamaño del elemento de la matriz fuente. Un valor de 1 indica datos contiguos. sst debe ser de tipo entero. Si llamas desde Fortran, debe ser un valor entero predeterminado.
len
Número de elementos en las matrices destino y fuente. len debe ser de tipo entero. Si usas Fortran, debe ser una constante, variable o elemento de matriz de tipo entero predeterminado.
pe
Número de PE del PE remoto. pe debe ser de tipo entero. Si usas Fortran, debe ser una constante, variable o elemento de matriz de tipo entero predeterminado.

Los objetos de datos destino y fuente deben cumplir con las restricciones de tipo, que son las siguientes:

shmem_iget32, shmem_iget4: Cualquier tipo no caracter que tenga un tamaño de almacenamiento
igual a 32 bits.
shmem_iget64, shmem_iget8: Cualquier tipo no caracter que tenga un tamaño de almacenamiento
igual a 64 bits.
shmem_iget128: Cualquier tipo no caracter que tenga un tamaño de almacenamiento igual a
128 bits.

shmem_short_iget: Elementos de tipo short.

shmem_int_iget: Elementos de tipo int.

shmem_long_iget: Elementos de tipo long.

shmem_longlong_iget: Elementos de tipo long long.

shmem_float_iget: Elementos de tipo float.

shmem_double_iget: Elementos de tipo double.

shmem_longdouble_iget: Elementos de tipo long double.

SHMEM_COMPLEX_IGET: Elementos de tipo complex de tamaño predeterminado.

SHMEM_DOUBLE_IGET: (Fortran) Elementos de tipo double precision.

SHMEM_INTEGER_IGET: Elementos de tipo integer.

SHMEM_LOGICAL_IGET: Elementos de tipo logical.

SHMEM_REAL_IGET: Elementos de tipo real.

shmem_longdouble_iget: Elementos de tipo long double.

SHMEM_COMPLEX_IGET: Elementos de tipo complex de tamaño predeterminado.

SHMEM_DOUBLE_IGET: (Fortran) Elementos de tipo double precision.

SHMEM_INTEGER_IGET: Elementos de tipo integer.

SHMEM_LOGICAL_IGET: Elementos de tipo logical.

SHMEM_REAL_IGET: Elementos de tipo real.

Si usas Fortran, los tipos de datos deben ser de tamaño predeterminado. Por ejemplo, una variable real debe declararse como REAL, REAL*4, o REAL(KIND=4).

NOTAS

Consulta intro_shmem(3) para una definición del término remotamente accesible.

EJEMPLOS

El siguiente ejemplo simple utiliza shmem_logical_iget en un programa Fortran. Compila este ejemplo con la opción del compilador -lsma.

PROGRAM STRIDELOGICAL
  LOGICAL SOURCE(10), TARGET(5)
  SAVE SOURCE ! SAVE HACE QUE SEA ACCESIBLE REMOTAMENTE
  DATA SOURCE /.T.,.F.,.T.,.F.,.T.,.F.,.T.,.F.,.T.,.F./
  DATA TARGET / 5*.F. /
  CALL START_PES(2)
  IF (MY_PE() .EQ. 0) THEN
    CALL SHMEM_LOGICAL_IGET(TARGET, SOURCE, 1, 2, 5, 1)
    PRINT*,'TARGET DESPUÉS DE SHMEM_LOGICAL_IGET:',TARGET
  ENDIF
  CALL SHMEM_BARRIER_ALL
END
