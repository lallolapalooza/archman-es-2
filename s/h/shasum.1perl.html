SHASUM(1perl) Guía de referencia del programador de Perl SHASUM(1perl)

NOMBRE

shasum - Imprimir o verificar sumas de verificación SHA

SINOPSIS

Uso: shasum [OPCIÓN]... [ARCHIVO]...
Imprime o verifica sumas de verificación SHA.
Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar.
  -a, --algorithm   1 (por defecto), 224, 256, 384, 512, 512224, 512256
  -b, --binary      leer en modo binario
  -c, --check       leer sumas SHA de los ARCHIVOS y verificarlas
      --tag         crear una suma de verificación estilo BSD
  -t, --text        leer en modo texto (por defecto)
  -U, --UNIVERSAL   leer en modo de nuevas líneas universales
                        produce el mismo digest en Windows/Unix/Mac
  -0, --01          leer en modo BITS
                        '0' ASCII interpretado como 0-bit,
                        '1' ASCII interpretado como 1-bit,
                        todos los demás caracteres ignorados
Las siguientes cinco opciones solo son útiles al verificar sumas de verificación:
      --ignore-missing  no fallar ni reportar el estado de archivos faltantes
  -q, --quiet           no imprimir OK para cada archivo verificado con éxito
  -s, --status          no generar ninguna salida, el código de estado muestra el éxito
      --strict          salir con un valor distinto de cero para líneas de suma de verificación mal formateadas
  -w, --warn            advertir sobre líneas de suma de verificación mal formateadas
  -h, --help        mostrar esta ayuda y salir
  -v, --version     mostrar información de versión y salir
Al verificar sumas SHA-512/224 o SHA-512/256, indica el
algoritmo explícitamente usando la opción -a, por ejemplo
  shasum -a 512224 -c archivo_sumas
Las sumas se calculan como se describe en FIPS PUB 180-4.  Al verificar,
la entrada debe ser una salida anterior de este programa.  El modo
por defecto es imprimir una línea con la suma de verificación, un carácter que indica el tipo
(`*' para binario, ` ' para texto, `U' para UNIVERSAL, `^' para BITS),
y el nombre para cada ARCHIVO.  La línea comienza con un carácter `\' si el
nombre del ARCHIVO contiene saltos de línea o barras invertidas, que luego se
reemplazan por las secuencias de dos caracteres `\n' y `\\' respectivamente.
Reportar errores de shasum a mshelor@cpan.org

DESCRIPCIÓN

Ejecutar shasum suele ser la forma más rápida de calcular los digests de mensajes SHA. El usuario simplemente alimenta datos al script a través de archivos o la entrada estándar, y luego recoge los resultados de la salida estándar.

El siguiente comando muestra cómo calcular digests para entradas típicas como el vector de prueba de NIST "abc":

perl -e "print qq(abc)" | shasum

O, si quieres usar SHA-256 en lugar del SHA-1 por defecto, simplemente di:

perl -e "print qq(abc)" | shasum -a 256

Como shasum imita el comportamiento de los programas combinados de GNU sha1sum, sha224sum, sha256sum, sha384sum y sha512sum, puedes instalar este script como un reemplazo conveniente.

A diferencia de los programas de GNU, shasum abarca el estándar SHA completo al permitir entradas de bytes parciales. Esto se logra a través de la opción BITS (-0). El siguiente ejemplo calcula el digest SHA-224 del mensaje de 7 bits 0001100:

perl -e "print qq(0001100)" | shasum -0 -a 224
