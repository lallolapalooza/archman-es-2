FBB::SharedStream(3bobcat) I/O en memoria compartida FBB::SharedStream(3bobcat)

NOMBRE

FBB::SharedStream - Operaciones de E/S en memoria compartida

SINOPSIS

#include <bobcat/sharedstream>
Opción de enlace: -lpthread -lbobcat

DESCRIPCIÓN

Esta clase combina las características de las clases std::istream y std::ostream, operando en memoria compartida. Al igual que con los objetos std::fstream, se requiere una llamada al miembro seekp o seekg para cambiar de escritura a lectura o viceversa.

Al igual que con los objetos std::fstream, los objetos FBB::SharedStream no mantienen desplazamientos separados para lectura y escritura: los miembros seek siempre se refieren al (único) desplazamiento mantenido por el objeto FBB::SharedMemory al que se interfaz el objeto SharedStream.

Por lo tanto, aunque tellg y tellp devuelven valores idénticos, tellg no debe llamarse después de escribir en un objeto SharedStream, y tellp no debe llamarse después de leer de un objeto SharedStream, ya que llamar a miembros relacionados con la lectura (tellg) después de escribir y viceversa pone el flujo en su estado de fallo.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

FBB::SharedBuf (herencia privada),
std::istream,
std::ostream,
FBB::SharedEnum__ (cf. sharedmemory(3bobcat) para una descripción de esta clase base).

ENUMERACIÓN SIZEUNIT

El enum SizeUnit define las siguientes constantes simbólicas:

o
kB, representando 1024 (2**10) bytes de memoria;
o
MB, representando 1048576 (2**20) bytes de memoria;
o
GB, representando 1073741824 (2**30) bytes de memoria)

CONSTRUCTORES

o
SharedStream():
El constructor por defecto define un objeto stub de SharedStream que no puede usarse inmediatamente para acceder a la memoria compartida. Para usarlo, primero debe llamarse a su miembro open.
o
SharedStream(size_t maxSize, SizeUnit sizeUnit, std::ios::openmode openMode = std::ios::in | std::ios::out, size_t access = 0600):
Este constructor crea un flujo que hereda las facilidades de un std::istream y std::ostream que se interconecta con un segmento de memoria compartida que tiene una capacidad de al menos maxSize * sizeUnit bytes.
Por defecto, el segmento de memoria compartida se abre para lectura y escritura. A diferencia de los modos de apertura utilizados para flujos de archivo, crear un flujo de memoria compartida con los modos de apertura ios::in | ios::out está bien. En este caso, el segmento de memoria compartida se crea y una vez que la información se ha escrito en la memoria compartida, también se puede volver a leer.
Los derechos de acceso de la memoria compartida se definen mediante el parámetro access, interpretado como un valor octal, utilizando la forma bien conocida (chmod(1)) para definir los derechos de acceso para el propietario, el grupo y los demás.
Si la construcción falla, se lanza una FBB::Exception.
o
SharedStream(int id, std::ios::openmode openMode = std::ios::in | std::ios::out):
Este constructor crea un flujo que hereda las facilidades de un std::istream y std::ostream que se conecta a un segmento de memoria compartida con ID id.
Especificar el indicador ios::trunc borra inmediatamente el contenido de la memoria compartida.
Se lanza una FBB::Exception si la construcción falla (por ejemplo, no existe un segmento de memoria compartida con ID id),
Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::istream y std::ostream y los valores enum kB, MB y GB, definidos por FBB::SharedEnum__ están disponibles.
o
FBB::SharedCondition attachSharedCondition(std::ios::off_type offset, std::ios::seekdir origin):
Devuelve un objeto FBB::SharedCondition(3), que se interconecta con una variable de condición compartida ubicada en el desplazamiento offset (relativo a origin) en el objeto SharedMemory al que se interconecta el objeto SharedStream. Este miembro no altera el valor devuelto por los miembros tellg y tellp del flujo.
Se lanza una FBB::Exception si el objeto FBB::SharedCondition no pudo construirse.
o
FBB::SharedCondition createSharedCondition():
Devuelve un objeto FBB::SharedCondition(3), que se interconecta con una variable de condición compartida recién creada que se crea en el desplazamiento actual del objeto SharedMemory al que se interconecta el objeto SharedStream (o en el primer desplazamiento del siguiente bloque de datos de memoria compartida, cf. sharedcondition(3bobcat)). Crear un objeto SharedCondition no altera el valor devuelto por los miembros tellg y tellp del flujo.
Se lanza una FBB::Exception si el objeto FBB::SharedCondition no pudo construirse.
o
int id() const:
Se devuelve el ID del segmento de memoria compartida.
o
void kill():
Sin bloquear primero la memoria compartida, toda la memoria compartida se devuelve al sistema operativo. El objeto FBB::SharedStream queda inutilizable después de regresar de kill. Otros procesos que estaban usando la memoria compartida pueden seguir haciéndolo.
o
void memInfo(std::ostream &out, char const *end = "\n"):
La información sobre el objeto SharedMemory se inserta en el objeto ostream proporcionado. Se muestran los ID de los segmentos compartidos, sus tamaños, el número máximo de segmentos de memoria compartida, el número de bytes que se pueden leer de la memoria compartida y su capacidad de almacenamiento real, etc. Después de la información sobre la memoria compartida, se inserta end en out.
o
void open(size_t maxSize, SizeUnit sizeUnit, std::ios::openmode openMode = std::ios::in | std::ios::out, size_t access = 0600):
Este miembro crea un segmento de memoria compartida con una capacidad de al menos maxSize * sizeUnit bytes, y conecta el segmento de memoria compartida a FBB::SharedStream. No existe un miembro close correspondiente y no es necesario.
Por defecto, el segmento de memoria compartida se abre para lectura y escritura. A diferencia de los modos de apertura utilizados para flujos de archivo, crear un flujo de memoria compartida con los modos de apertura ios::in | ios::out está bien. En este caso, el segmento de memoria compartida se crea y una vez que la información se ha escrito en la memoria compartida, también se puede volver a leer.
Los derechos de acceso de la memoria compartida se definen mediante el parámetro access, interpretado como un valor octal, utilizando la forma bien conocida (chmod(1)) para definir los derechos de acceso para el propietario, el grupo y los demás.
Si la apertura falla, se lanza una FBB::Exception.
o
void open(int id, std::ios::openmode openMode = std::ios::in | std::ios::out):
Este miembro conecta el objeto FBB::SharedStream a un segmento de memoria compartida con ID id
i>. Un miembro close coincidente no existe y no es requerido. Si la apertura tiene éxito, la memoria compartida está lista para su uso.
Especificar el flag ios::trunc borra inmediatamente el contenido de la memoria compartida.
Se lanza una FBB::Exception si la apertura falla (por ejemplo, no existe un segmento de memoria compartida con el ID id).
o
void remove():
Primero se bloquea la memoria compartida. Luego, toda la memoria compartida se devuelve al sistema operativo. El objeto FBB::SharedStream no se puede utilizar después de regresar de remove. Otros procesos que estaban utilizando la memoria compartida pueden continuar haciéndolo.
o
bool truncate(std::streamsize offset):
Si offset no excede el valor devuelto por seekg(0, std::ios::end), entonces este último valor se cambia a offset y se devuelve true. De lo contrario, se devuelve false y el valor devuelto por seekg no se altera. Si el valor devuelto por tellg excedía offset, el valor de retorno de tellg también se reduce a offset. Las operaciones de lectura posteriores en la memoria compartida solo pueden tener éxito mientras el valor de retorno de tellg no haya alcanzado el valor offset.

EJEMPLO

#include <iostream>
#include <string>
#include <ostream>
#include <istream>
#include <bobcat/exception>
#include <bobcat/sharedstream>
#include <bobcat/sharedcondition>
using namespace std;
using namespace FBB;
int main()
{
    SharedStream sharedStream;
    int id = -1;
    while (true)
    {
        cout <<
                "\n"
                " K             matar (sin bloqueo) segmento compartido existente\n"
                " S             mostrar estadísticas del segmento compartido actual\n"
                " L <id>        Cargar segmento <id>\n"
                " C             Instalar una SharedCondition en el desplazamiento 0\n"
                " c            crear nueva memoria compartida (establece id)\n"
//                " l            bloquear segmento id hasta que se presione una tecla\n"
//                " p <x> c      poner el carácter c en el desplazamiento x\n"
                " q            salir\n"
//                " r <x> <n>    leer n caracteres desde el desplazamiento x\n"
//                " w <x> args   escribir todos los argumentos en el desplazamiento x\n"
                  " i            insertar líneas (hasta vaciar) en el desplazamiento actual\n"
                  " x            extraer líneas (hasta EOF) desde el desplazamiento actual\n"
                  " X            extraer la siguiente línea desde el desplazamiento actual\n"
                  "              cuando se modifica a través de 'N'\n"
                  " N            notificar a una X en espera\n"
                  " s <x>        buscar (abs) desplazamiento x\n"
                "? ";
        char ch;
        cin >> ch;
        ios::off_type offset;
        cout << "Solicitado: " << ch << ’\n’;
        sharedStream.clear();
        switch (ch)
        {
            case ’c’:
            {
                sharedStream.open(1, SharedStream::kB);
                id = sharedStream.id();
                cout << "id = " << id << ’\n’;
                sharedStream.memInfo(cout);
                cout << ’\n’;
            }
            break;
            case ’C’:
            {
                sharedStream.seekp(0);
                SharedCondition cond(sharedStream.createSharedCondition());
                sharedStream.seekg(cond.width());
                break;
            }
            case ’K’:         // eliminar segmento
            {
                if (id == -1)
                {
                    cout << "Ningún segmento cargado\n";
                    continue;
                }
                cout << "Eliminando segmento id = " << id << ’\n’;
                if (ch == ’R’)
                    sharedStream.remove();
                else
                    sharedStream.kill();
                id = -1;
            }
            break;
            case ’L’:
                cin >> id;
                cout << "Cargando segmento " << id << ’\n’;
                sharedStream.open(id);
                sharedStream.memInfo(cout);
                cout << ’\n’;
            break;
            case ’S’:
                if (id == -1)
                {
                    cout << "Ningún segmento cargado\n";
                    continue;
                }
                sharedStream.memInfo(cout);
                cout << ’\n’;

            case ’s’:

                size_t offset;
                if (id == -1)

                    continue;
                }
                cin >> offset;
                sharedStream.seekg(offset);
                sharedStream.seekp(offset);
                cout << "tellg: " << sharedStream.tellg() << ", "
                        "tellp: " << sharedStream.tellp() << ’\n’;
            }
            break;
            case ’i’:
            {
                string line;
                getline(cin, line);
                sharedStream.seekp(0, ios::cur);
                while (true)
                {
                    cout << "? ";
                    if (not getline(cin, line) || line.empty())
                        break;
                    sharedStream << line << endl;
                    cout <<
                            "   tellp: " << sharedStream.tellp() << ’\n’;
                }
                    cout << // "   tellg: " << sharedStream.tellg() << ", "
                            "   tellp: " << sharedStream.tellp() << ’\n’;
            }
            break;
            case ’x’:
            {
                string line;
                sharedStream.seekg(0, ios::cur);
                while (true)
                {
                    cout << ": ";
                    if (not getline(sharedStream, line))
                        break;
                    cout << line << "\n"
                            "   tellg: " << sharedStream.tellg() << ", "
                            "   tellp: " << sharedStream.tellp() << ’\n’;
                }
            }
            break;
            case ’X’:
            {
                SharedCondition cond(sharedStream.attachSharedCondition(0));
                string line;
                sharedStream.seekg(cond.width());
                cond.lock();
                while (true)
                {
                    cond.wait();
                    cout << ": ";
                    if (not getline(sharedStream, line))
                        break;
                    cout << line << "\n"
                            "   tellg: " << sharedStream.tellg() << ", "
                            "   tellp: " << sharedStream.tellp() << ’\n’;
                }
                cout << "Todo listo\n";
                cond.unlock();
            }
            break;
            case ’N’:
            {
                string line;
                getline(cin, line);
                SharedCondition cond(sharedStream.attachSharedCondition(0));

                {
                    cout << "’enter’ o ’q’? ";
                    getline(cin, line);
                    if (line == "q")
                        break;
                    cond.lock();
                    cond.notify();

                }
            }
            break;
