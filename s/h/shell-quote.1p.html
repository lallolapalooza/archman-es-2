SHELL-QUOTE(1p) Documentación de Perl contribuida por el usuario SHELL-QUOTE(1p)

NOMBRE

shell-quote - cita argumentos para su uso seguro, sin modificar en un comando de shell

SINOPSIS

shell-quote [conmutador]... arg...

DESCRIPCIÓN

shell-quote le permite pasar cadenas arbitrarias a través del shell de modo que no sean modificadas por el shell. Esto le permite procesar comandos o archivos con espacios en blanco incrustados o caracteres de globbing del shell de forma segura. Aquí hay algunos ejemplos.

EJEMPLOS

ssh preservando argumentos
Al ejecutar un comando remoto con ssh, ssh no preserva los argumentos separados que recibe. Simplemente los une con espacios y los pasa a "$SHELL -c". Esto no funciona como se esperaba: 
ssh host touch 'hola mundo'           # falla

Crea 2 archivos, hola y mundo. En su lugar, haga esto:

cmd=`shell-quote touch 'hola mundo'`
ssh host "$cmd"

Esto le da solo 1 archivo, hola mundo.

procesar salida de find
Normalmente no es posible procesar una lista arbitraria de archivos de salida por find con un script de shell. Cualquier cosa que ponga en $IFS para dividir la salida podría estar legítimamente en el nombre de un archivo. Aquí le mostramos cómo puede hacerlo usando shell-quote: 
eval set -- `find -type f -print0 | xargs -0 shell-quote --`
depurar scripts de shell
shell-quote es mejor que echo para depurar scripts de shell. 
debug() {
    [ -z "$debug" ] || shell-quote "debug:" "$@"
}

Con echo no puede distinguir entre "debug 'hola mundo'" y "debug hola mundo", pero con shell-quote sí puede.

guardar un comando para después
shell-quote se puede usar para construir un comando de shell para ejecutar más tarde. Supongamos que desea que el usuario pueda proporcionarle conmutadores para un comando que va a ejecutar. Si no desea que los conmutadores se reevalúen por el shell (lo que generalmente es una buena idea, de lo contrario, hay cosas que el usuario no puede pasar), puede hacer algo como esto: 
user_switches=
while [ $# != 0 ]
do
    case x$1 in
        x--pass-through)
            [ $# -gt 1 ] || die "se necesita un argumento para $1"
            user_switches="$user_switches "`shell-quote -- "$2"`
            shift;;
        # procesar otros conmutadores
    esac
    shift
done
# más tarde
eval "shell-quote some-command $user_switches mis argumentos"
