DESCRIPCIÓN

Las rutinas de "get" con saltos recuperan datos de arreglos disponibles en la dirección source en el PE remoto (pe). Los elementos del arreglo source están separados por un salto sst. Una vez que se reciben los datos, se almacenan en la dirección de memoria local target, separados por el salto tst. Las rutinas regresan cuando los datos han sido copiados al arreglo local target.

Los argumentos son los siguientes:

target
Arreglo que se actualizará en el PE local.
source
Arreglo que contiene los datos a copiar en el PE remoto.
tst
El salto entre elementos consecutivos del arreglo de destino. El salto se escala por el tamaño del elemento del arreglo de destino. Un valor de 1 indica datos contiguos. tst debe ser de tipo entero. Si estás llamando desde Fortran, debe ser un valor entero predeterminado.
sst
El salto entre elementos consecutivos del arreglo de origen. El salto se escala por el tamaño del elemento del arreglo de origen. Un valor de 1 indica datos contiguos. sst debe ser de tipo entero. Si estás llamando desde Fortran, debe ser un valor entero predeterminado.
len
Número de elementos en los arreglos de destino y origen. len debe ser de tipo entero. Si estás usando Fortran, debe ser una constante, variable o elemento de arreglo de tipo entero predeterminado.
pe
Número de PE del PE remoto. pe debe ser de tipo entero. Si estás usando Fortran, debe ser una constante, variable o elemento de arreglo de tipo entero predeterminado.

Los objetos de datos de destino y origen deben cumplir con las restricciones de tipo, que son las siguientes:

shmem_iget32, shmem_iget4: Cualquier tipo no carácter que tenga un tamaño de almacenamiento
igual a 32 bits.
shmem_iget64, shmem_iget8: Cualquier tipo no carácter que tenga un tamaño de almacenamiento
igual a 64 bits.
shmem_iget128: Cualquier tipo no carácter que tenga un tamaño de almacenamiento igual a
128 bits.

shmem_short_iget: Elementos de tipo short.

shmem_int_iget: Elementos de tipo int.

shmem_long_iget: Elementos de tipo long.

shmem_longlong_iget: Elementos de tipo long long.

shmem_float_iget: Elementos de tipo float.

shmem_double_iget: Elementos de tipo double.

shmem_longdouble_iget: Elementos de tipo long double.

SHMEM_COMPLEX_IGET: Elementos de tipo complejo de tamaño predeterminado.

SHMEM_DOUBLE_IGET: (Fortran) Elementos de tipo double precision.

SHMEM_INTEGER_IGET: Elementos de tipo integer.

SHMEM_LOGICAL_IGET: Elementos de tipo logical.

SHMEM_REAL_IGET: Elementos de tipo real.

shmem_longdouble_iget: Elementos de tipo long double.

EJEMPLOS

El siguiente ejemplo simple utiliza shmem_logical_iget en un programa Fortran. Compila este ejemplo con la opción del compilador -lsma.

PROGRAM STRIDELOGICAL
  LOGICAL SOURCE(10), TARGET(5)
  SAVE SOURCE ! SAVE HACE QUE SEA ACCESIBLE REMOTAMENTE
  DATA SOURCE /.T.,.F.,.T.,.F.,.T.,.F.,.T.,.F.,.T.,.F./
  DATA TARGET / 5*.F. /
  CALL START_PES(2)
  IF (MY_PE() .EQ. 0) THEN
    CALL SHMEM_LOGICAL_IGET(TARGET, SOURCE, 1, 2, 5, 1)
    PRINT*,'TARGET DESPUÉS DE SHMEM_LOGICAL_IGET:',TARGET
  ENDIF
  CALL SHMEM_BARRIER_ALL
END

shmem_float_iget(3)

SHMEM NAME

SYNOPSIS

shmem_float_iget(void *addr, int pe)

DESCRIPTION

The shmem_float_iget routine is used to retrieve a single float element from remote memory. The argument addr is a pointer to the target memory on the remote processing element (PE) specified by pe. The target memory must be an array of floats.

NOTES

No additional notes are available.

EXAMPLES


// Example usage of shmem_float_iget
#include <stdio.h>
#include <shmem.h>

int main(void) {
    float target_value;
    float remote_array[10];
    int pe;

    // Initialize SHMEM
    shmem_init();

    // Get my PE
    pe = shmem_my_pe();

    // Initialize remote_array on PE 0
    if (pe == 0) {
        for (int i = 0; i < 10; i++) {
            remote_array[i] = (float)(pe * 10 + i);
        }
    }

    // Synchronize PEs
    shmem_barrier_all();

    // Get the second element (index 1) from PE 0's remote_array
    target_value = shmem_float_iget(&remote_array[1], 0);

    // Print the retrieved value
    printf("PE %d: Retrieved value = %f\n", pe, target_value);

    // Finalize SHMEM
    shmem_finalize();

    return 0;
}
