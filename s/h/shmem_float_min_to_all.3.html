DESCRIPCIÓN

Las rutinas de reducción de memoria compartida (SHMEM) calculan una o más reducciones en arrays simétricos en múltiples PEs virtuales. Una reducción realiza una operación binaria asociativa en un conjunto de valores. Para una lista de otras rutinas de reducción SHMEM, ver intro_shmem(3).

Como con todas las rutinas colectivas SHMEM, cada una de estas rutinas asume que solo los PEs del conjunto activo llaman a la rutina. Si un PE que no está en el conjunto activo llama a una rutina colectiva SHMEM, el comportamiento no está definido.

El argumento nreduce determina el número de reducciones separadas a realizar. El array fuente en todos los PEs del conjunto activo proporciona un elemento para cada reducción. Los resultados de las reducciones se colocan en el array destino en todos los PEs del conjunto activo. El conjunto activo se define por el trío PE_start, logPE_stride, PE_size.

Los arrays fuente y destino pueden ser el mismo array, pero no pueden ser arrays superpuestos.

Los argumentos son los siguientes:

target
Un array simétrico de longitud nreduce elementos para recibir los resultados de las operaciones de reducción. El tipo de datos de target varía con la versión de la rutina de reducción que se llama. Al llamar desde C/C++, consulte la sección SINOPSIS para obtener información sobre el tipo de datos. Al llamar desde Fortran, los tipos de datos de destino son los siguientes:

shmem_int4_min_to_all: Entero, con un tamaño de elemento de 4 bytes

shmem_int8_min_to_all: Entero, con un tamaño de elemento de 8 bytes

shmem_real4_min_to_all: Real, con un tamaño de elemento de 4 bytes

shmem_real8_min_to_all: Real, con un tamaño de elemento de 8 bytes

shmem_real16_min_to_all: Real, con un tamaño de elemento de 16 bytes

source Un array simétrico: de longitud nreduce elementos, que contiene un
elemento para cada operación de reducción separada. El argumento source debe tener el mismo tipo de datos que target.
nreduce
El número de elementos en los arrays target y source. nreduce debe ser de tipo entero. Si está utilizando Fortran, debe ser un valor entero por defecto.
PE_start
El número PE virtual más bajo del conjunto activo de PEs. PE_start debe ser de tipo entero. Si está utilizando Fortran, debe ser un valor entero por defecto.
logPE_stride
El logaritmo (base 2) del paso entre números PE virtuales consecutivos en el conjunto activo. logPE_stride debe ser de tipo entero. Si está utilizando Fortran, debe ser un valor entero por defecto.
PE_size
El número de PEs en el conjunto activo. PE_size debe ser de tipo entero. Si está utilizando Fortran, debe ser un valor entero por defecto.
pWrk
Un array de trabajo simétrico. El argumento pWrk debe tener el mismo tipo de datos que target. En C/C++, contiene max(nreduce/2 + 1, _SHMEM_REDUCE_MIN_WRKDATA_SIZE) elementos. En Fortran, contiene max(nreduce/2 + 1, SHMEM_REDUCE_MIN_WRKDATA_SIZE) elementos.
pSync
Un array de trabajo simétrico. En C/C++, pSync es de tipo long y tamaño _SHMEM_REDUCE_SYNC_SIZE. En Fortran, pSync es de tipo entero y tamaño SHMEM_REDUCE_SYNC_SIZE. Si está utilizando Fortran, debe ser un valor entero por defecto. Cada elemento de este array debe inicializarse con el valor _SHMEM_SYNC_VALUE (en C/C++) o SHMEM_SYNC_VALUE (en Fortran) antes de que cualquiera de los PEs del conjunto activo entre en la rutina de reducción.

Los valores de los argumentos nreduce, PE_start, logPE_stride y PE_size deben ser iguales en todos los PEs del conjunto activo. Los mismos arrays target y source, y los mismos arrays de trabajo pWrk y pSync, deben pasarse a todos los PEs del conjunto activo.

Antes de que cualquier PE llame a una rutina de reducción, debe asegurarse de que se cumplen las siguientes condiciones (a menudo se necesita sincronización mediante una barrera u otro método para garantizar esto): Los arrays pWrk y pSync en todos los PEs del conjunto activo ya no están en uso debido a una llamada anterior a una rutina colectiva SHMEM. El array target en todos los PEs del conjunto activo está listo para aceptar los resultados de la reducción.

Al regresar de una rutina de reducción, lo siguiente es cierto para el PE local: El array target se actualiza. Los valores en el array pSync se restauran a sus valores originales.

NOTAS

Los términos colectivo, simétrico y alineado en caché se definen en intro_shmem(3). Todas las rutinas de reducción SHMEM restauran los valores en pSync antes de devolverlos, por lo que un buffer pSync particular solo necesita inicializarse la primera vez que se usa.

Debe asegurarse de que el array pSync no está siendo actualizado en ningún PE del conjunto activo mientras alguno de los PEs participa en el procesamiento de una rutina de reducción SHMEM. Tenga cuidado con las siguientes situaciones: Si el array pSync se inicializa en tiempo de ejecución, se necesita algún tipo de sincronización para garantizar que todos los PEs del conjunto de trabajo han inicializado pSync antes de que alguno de ellos entre en una rutina SHMEM llamada con el array de sincronización pSync. Un array pSync o pWrk puede reutilizarse en una llamada posterior a la rutina de reducción solo si ninguno de los PEs del conjunto activo todavía está procesando una llamada anterior a la rutina de reducción que utilizó los mismos arrays pSync o pWrk. En general, esto solo se puede garantizar realizando algún tipo de sincronización. Sin embargo, en el caso especial de las rutinas de reducción que se llaman con el mismo conjunto activo, puede asignar dos arrays pSync y pWrk y alternar entre ellos en llamadas sucesivas.

shmem_float_min_to_all(3) — Open MPI 5.0.9-2 documentation

NAME

shmem_float_min_to_all, shmem_double_min_to_all, shmem_longdouble_min_to_all, shmem_real32_min_to_all, shmem_real64_min_to_all, shmem_real128_min_to_all — collect minimum values across all PEs

SYNOPSIS

C/F77
int shmem_real32_min_to_all(float *target, float *source, int nreduce);
int shmem_real64_min_to_all(double *target, double *source, int nreduce);
int shmem_real128_min_to_all(long double *target, long double *source, int nreduce);
Fortran
CALL SHMEM_REAL4_MIN_TO_ALL(target, source, nreduce)
CALL SHMEM_REAL8_MIN_TO_ALL(target, source, nreduce)
CALL SHMEM_REAL16_MIN_TO_ALL(target, source, nreduce)

DESCRIPTION

The shmem_*_min_to_all routines are collective operations that perform a reduction on the array elements of type float, double, or long double. The operation applied is the minimum. Each process provides an array source and an array target. The number of elements to be reduced is specified by nreduce.

The reduction is performed across all the processing elements (PEs) in the Cartesian group. The result of the reduction is placed in the target array on each PE. For each element i, the operation finds the minimum value of source[i] across all PEs and stores the result in target[i].

The specific routines available are:

shmem_real32_min_to_all
Reduces float (real*4) values.
shmem_real64_min_to_all
Reduces double (real*8) values.
shmem_real128_min_to_all
Reduces long double (real*16) values.
SHMEM_REAL4_MIN_TO_ALL
Fortran interface for float.
SHMEM_REAL8_MIN_TO_ALL
Fortran interface for double.
SHMEM_REAL16_MIN_TO_ALL
Fortran interface for long double.

The target and source arrays must be symmetric on all PEs participating in the reduction. That is, target[i] and source[i] must refer to the same data element on every PE.

The optional arguments pWrk and pSync are used for optimizations and synchronization. If these are not provided, internal scratch space and synchronization are used.

The routine returns an integer status code, 0 on success.

NOTES

The shmem_*_min_to_all routines require that the number of PEs in the Cartesian group is even. The behavior is undefined if the number of PEs is odd.

The arguments target, source, pWrk, and pSync are pointers to memory. The size of the pWrk array depends on the specific reduction operation and the number of elements being reduced. The pSync array is used for synchronization between PEs.

EXAMPLES

Example 1: Fortran code to find the minimum value of FOO across all even PEs.

INCLUDE "mpp/shmem.fh"
INTEGER PSYNC(SHMEM_REDUCE_SYNC_SIZE)
DATA PSYNC /SHMEM_REDUCE_SYNC_SIZE*SHMEM_SYNC_VALUE/
PARAMETER (NR=1)
REAL FOO, FOOMIN, PWRK(MAX(NR/2+1,SHMEM_REDUCE_MIN_WRKDATA_SIZE))
COMMON /COM/ FOO, FOOMIN, PWRK
INTRINSIC MY_PE
IF ( MOD(MY_PE(),2) .EQ. 0) THEN
  CALL SHMEM_REAL8_MIN_TO_ALL(FOOMIN, FOO, NR, 0, 1, N$PES/2,
  & PWRK, PSYNC)
  PRINT *, 'Result on PE ', MY_PE(), ' is ', FOOMIN
ENDIF

Example 2: C/C++ call.

shmem_int_min_to_all( target, source, 3, 0, 0, 8, pwrk, psync );

The preceding call is more efficient, but semantically equivalent to, the combination of the following calls:

shmem_int_min_to_all(&(target[0]), &(source[0]), 1, 0, 0, 8,
  pwrk1, psync1);
shmem_int_min_to_all(&(target[1]), &(source[1]), 1, 0, 0, 8,
  pwrk2, psync2);
shmem_int_min_to_all(&(target[2]), &(source[2]), 1, 0, 0, 8,
  pwrk1, psync1);

Note that two sets of pWrk and pSync arrays are used alternately because no synchronization is done between calls.
