NOMBRE

Shutter - Herramienta de captura de pantalla rica en funciones

SINOPSIS

shutter [opciones]

DERECHOS DE AUTOR

Shutter es Copyright (C) por Mario Kemper y Shutter Team

DESCRIPCIÓN

Shutter es un programa de captura de pantalla rico en funciones. Puedes tomar una captura de pantalla de un área específica, ventana, tu pantalla completa, o incluso de una página web - aplicarle diferentes efectos, dibujar sobre ella para resaltar puntos, y luego subirla a un sitio de alojamiento de imágenes, todo dentro de una sola ventana.

OPCIONES

Ejemplo 1
shutter -a -p=miperfil --min_al_arrancar
Ejemplo 2
shutter -s=100,100,300,300 -e
Ejemplo 3
shutter --ventana=.*firefox.*
Ejemplo 4
shutter --web=http://shutter-project.org/ -e

OPCIONES DE MODO DE CAPTURA

-s, --select=[X,Y,ANCHO,ALTO]
Captura un área de la pantalla. Proporcionar X,Y,ANCHO,ALTO es opcional.
-f, --full
Captura la pantalla completa.
-w, --window=[PATRON_NOMBRE]
Selecciona una ventana para capturar. Proporcionar un PATRON_NOMBRE (regex estilo Perl) es opcional.
-a, --active
Captura la ventana activa actual.
-m, --menu
Captura un menú.
-t, --tooltip
Captura una tooltip.
--web=[URL]
Captura una página web. Proporcionar una URL es opcional.
-r, --redo
Repite la última captura de pantalla.

OPCIONES DE CONFIGURACIÓN

-p, --profile=NOMBRE
Carga un perfil específico al arrancar.
-o, --output=NOMBRE_ARCHIVO
Especifica un nombre de archivo para guardar la captura de pantalla (sobrescribe cualquier configuración relacionada con el perfil).

Formatos de imagen soportados: Puedes guardar en cualquier formato de imagen popular (ej. jpeg, png, gif, bmp). Adicionalmente, es posible guardar en pdf, ps o svg.

Por favor, ten en cuenta: Hay varios comodines disponibles, como

%Y = año
%m = mes
%d = día
%T = hora
$w = ancho
$h = alto
$name = propósito múltiple (ej. título de ventana)
$nb_name = como $name pero sin espacios en las cadenas resultantes
$profile = nombre del perfil actual
$R = carácter aleatorio (ej. $RRRR = ag4r)
%NN = contador

La cadena es interpretada por strftime. Consulta "man strftime" para más ejemplos.

Como ejemplo: shutter -f -e -o './%y-%m-%d_$w_$h.png' crearía un archivo llamado '11-10-28_1280_800.png' en el directorio actual.

-d, --delay=SEGUNDOS
Espera n segundos antes de tomar una captura de pantalla.
-c, --include_cursor
Incluye el cursor al tomar una captura de pantalla.
-C, --remove_cursor
Elimina el cursor al tomar una captura de pantalla.

OPCIONES DE APLICACIÓN

-h, --help
Imprime un breve mensaje de ayuda y sale.
-v, --version
Imprime información de la versión.
--debug
Imprime mucha información de depuración en STDOUT.
--clear_cache
Limpia la caché, por ejemplo, plugins instalados, al arrancar.
--min_at_startup
Inicia Shutter minimizado a la bandeja.
--disable_systray
Deshabilita el icono de la bandeja del sistema.
-e, --exit_after_capture
Sale después de que se haya realizado la primera captura. Esto es útil cuando se usa Shutter en scripts.
-n, --no_session
No añade la captura de pantalla a la sesión. Esto es útil cuando se usa Shutter en scripts.

INFORMES DE ERRORES

Si encuentras un error en Shutter, deberías informarlo. Pero antes, deberías asegurarte de que realmente es un error, y que aparece en la última versión de Shutter.

La última versión siempre está disponible en: https://github.com/shutter-project/shutter/releases

Una vez que hayas determinado que un error existe, por favor, repórtalo en github: https://github.com/shutter-project/shutter/issues/new
