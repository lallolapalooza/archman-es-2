SHREALLOC(3) Open MPI SHREALLOC(3)

shmem_malloc(3), shmem_free(3), shmem_align(3), shmem_realloc(3) shmalloc(3), shfree(3), shmemalign(3), shrealloc(3) - Funciones de gestión de memoria simétrica del montón.

SINÓPSIS

C o C++:

#include <mpp/shmem.h>
void *shmem_malloc(size_t size)
void *shmalloc(size_t size)
void shmem_free(void *ptr)
void shfree(void *ptr)
void *shmem_realloc(void *ptr, size_t size)
void *shrealloc(void *ptr, size_t size)
void *shmem_align(size_t alignment, size_t size)
void *shmemalign(size_t alignment, size_t size)
extern long malloc_error

DESCRIPCIÓN

La función shmem_malloc devuelve un puntero a un bloque de al menos size bytes, adecuadamente alineado para cualquier uso. Este espacio se aloca desde el montón simétrico (en contraste con malloc(3), que aloca desde el montón privado).

La función shmem_align aloca un bloque en el montón simétrico que tiene una alineación de bytes especificada por el argumento alignment.

La función shmem_free provoca que el bloque al que apunta ptr sea desalocado, es decir, que quede disponible para futuras asignaciones. Si ptr es un puntero nulo, no se realiza ninguna acción; de lo contrario, si el argumento no coincide con un puntero devuelto previamente por una función del montón simétrico, o si el espacio ya ha sido desalocado, se establece malloc_error para indicar el error, y shfree retorna.

La función shmem_realloc cambia el tamaño del bloque al que apunta ptr al tamaño (en bytes) especificado por size.

El contenido del bloque no se modifica hasta el menor de los tamaños nuevo y antiguo. Si el nuevo tamaño es mayor, el valor de la porción recién asignada del bloque es indeterminado. Si ptr es un puntero nulo, la función shrealloc se comporta como la función shmalloc para el tamaño especificado. Si size es 0 y ptr no es un puntero nulo, se libera el bloque al que apunta. De lo contrario, si ptr no coincide con un puntero devuelto previamente por una función del montón simétrico, o si el espacio ya ha sido desalocado, la variable malloc_error se establece para indicar el error, y shrealloc devuelve un puntero nulo. Si el espacio no se puede alocar, el bloque al que apunta ptr no se modifica.

Las funciones shmem_malloc, shmem_free y shmem_realloc se proporcionan para que múltiples PEs en una aplicación puedan alocar bloques de memoria simétricos y remotamente accesibles. Estos bloques de memoria se pueden usar luego con rutinas de comunicación (shmem). Cada una de estas funciones llama a la función shmem_barrier_all(3) antes de retornar; esto asegura que todos los PEs participen en la asignación de memoria y que la memoria en otros PEs pueda ser utilizada tan pronto como el PE local retorne.

El usuario es responsable de llamar a estas funciones con argumentos idénticos en todos los PEs; si se utilizan argumentos de tamaño diferentes, las llamadas posteriores pueden no devolver la misma dirección de montón simétrico en todos los PEs.

NOTAS

El tamaño total del montón simétrico se determina al inicio del trabajo. Se puede ajustar el tamaño del montón usando la variable de entorno SHMEM_SYMMETRIC_HEAP_SIZE. Consulte la página del manual de intro_shmem(3) para más detalles. Las funciones shmem_malloc, shmem_free y shmem_realloc difieren de las funciones de asignación de montón privado en que todos los PEs de una aplicación deben llamarlas (se usa una barrera para asegurar esto).

VALORES DE RETORNO

La función shmem_malloc devuelve un puntero al espacio asignado (que debe ser idéntico en todos los PEs); de lo contrario, devuelve un puntero nulo (con malloc_error establecido). La función shmem_free no devuelve ningún valor. La función shmem_realloc devuelve un puntero al espacio asignado (que puede haberse movido); de lo contrario, devuelve un puntero nulo (con malloc_error establecido).
