SHARESEC(1) Comandos de usuario SHARESEC(1)

NOMBRE

sharesec - Establecer u obtener ACLs de compartición

SINOPSIS

sharesec {nombre_comparticion} [-r, --eliminar=ACL] [-m, --modificar=ACL] [-a, --agregar=ACL] [-R, --reemplazar=ACLs] [-D, --borrar] [-v, --ver] [--ver-todo] [-M, --sid-maquina] [-F, --forzar] [-d, --nivel-debug=NIVEL_DEBUG] [-s, --archivo-config=ARCHIVO_CONFIG] [-l, --base-log=ARCHIVO_LOG] [-S, --establecer-sddl=CADENA] [--ver-sddl] [-?|--ayuda] [--uso] [-d|--nivel-debug=NIVEL_DEBUG] [--debug-stdout] [--archivo-config=ARCHIVO_CONFIG] [--opcion=nombre=valor] [-l|--base-log=ARCHIVO_LOG] [--informe-fugas] [--informe-fugas-completo]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de herramientas de samba(7).

El programa sharesec manipula los permisos de compartición en comparticiones de archivos SMB.

OPCIONES

Las siguientes opciones están disponibles para el programa sharesec. El formato de las ACLs se describe en la sección FORMATO DE ACL.

-a|--agregar=ACL

Agrega las ACEs especificadas a la lista de ACLs.

-D|--borrar

Borra el descriptor de seguridad completo.

-F|--forzar

Fuerza el almacenamiento de la ACL.

-m|--modificar=ACL

Modifica las ACEs existentes.

-M|--sid-maquina

Inicializa el SID de la máquina.

-r|--eliminar=ACL

Elimina ACEs.

-R|--reemplazar=ACLs

Sobrescribe una ACL de permisos de compartición existente.

-v|--ver

Lista una ACL de compartición

--ver-todo

Lista todas las ACLs de compartición

-S|--establecer-sddl=CADENA

Establece el descriptor de seguridad proporcionando la ACL en formato SDDL.

--ver-sddl

Lista una ACL de compartición en formato SDDL.

-?|--ayuda

Imprime un resumen de las opciones de la línea de comandos.

--uso

Muestra un mensaje de uso breve.

-d|--nivel-debug=nivel

nivel es un entero de 0 a 10. El valor predeterminado si este parámetro no se especifica es 1 para aplicaciones cliente.

Cuanto más alto sea este valor, más detalle se registrará en los archivos de registro sobre las actividades del servidor. En el nivel 0, solo se registrarán errores críticos y advertencias graves. El nivel 1 es un nivel razonable para el funcionamiento diario: genera una pequeña cantidad de información sobre las operaciones realizadas.

Los niveles superiores a 1 generarán una cantidad considerable de datos de registro y solo deben usarse al investigar un problema. Los niveles superiores a 3 están diseñados solo para desarrolladores y generan ENORMES cantidades de datos de registro, la mayoría de los cuales son extremadamente crípticos.

Tenga en cuenta que especificar este parámetro aquí anulará el parámetro de nivel de registro en el archivo /etc/samba/smb.conf.

--debug-stdout

Redirigirá la salida de depuración a STDOUT. Por defecto, todos los clientes registran en STDERR.

--archivo-config=<archivo de configuración>

El archivo especificado contiene los detalles de configuración requeridos por el cliente. La información de este archivo puede ser general para cliente y servidor o proporcionar solo opciones específicas del cliente como, por ejemplo, client smb encrypt. Consulte /etc/samba/smb.conf para obtener más información. El nombre del archivo de configuración predeterminado se determina en tiempo de compilación.

--opcion=<nombre>=<valor>

Establece la opción de smb.conf(5) "<nombre>" al valor "<valor>" desde la línea de comandos. Esto anula los valores predeterminados compilados y las opciones leídas del archivo de configuración. Si un nombre o un valor incluyen un espacio, envuelva todo --opcion=nombre=valor entre comillas.

-l|--base-log=<directorio de registro>

Nombre del directorio base para los archivos de registro/depuración. Se añadirá la extensión ".progname" (por ejemplo, log.smbclient, log.smbd, etc...). El cliente nunca elimina el archivo de registro.

--informe-fugas

Habilita el informe de fugas de talloc al salir.

--informe-fugas-completo

Habilita el informe completo de fugas de talloc al salir.

-V|--version

Imprime el número de versión del programa.

FORMATO DE ACL

El formato de una ACL es una o más entradas de ACL separadas por comas o saltos de línea. Una entrada de ACL es una de las siguientes:

REVISION:<número de revisión>
PROPIETARIO:<sid o nombre>
GRUPO:<sid o nombre>
ACL:<sid o nombre>:<tipo>/<flags>/<máscara>

La revisión de la ACL especifica la revisión interna de la ACL de Windows NT para el descriptor de seguridad. Si no se especifica, el valor predeterminado es 1. Usar valores distintos de 1 puede causar un comportamiento extraño.

El propietario y el grupo especifican los SIDs del propietario y del grupo para el objeto. Las ACLs de compartición no especifican un propietario ni un grupo, por lo que estos campos están vacíos.

Las ACLs especifican los permisos otorgados al SID. Este SID puede especificarse en formato S-1-x-y-z o como un nombre, en cuyo caso se resuelve contra el servidor en el que residen el archivo o directorio. El tipo, las banderas y la máscara determinan el tipo de acceso otorgado al SID.

El tipo puede ser ALLOWED (permitido) o DENIED (denegado) para permitir/denegar el acceso al SID. Los valores de las banderas son generalmente cero para las ACLs de compartición.

La máscara es un valor que expresa el derecho de acceso otorgado al SID. Puede proporcionarse como un valor decimal o hexadecimal, o usando una de las siguientes cadenas de texto que se mapean a los permisos de archivo de NT del mismo nombre.

•R - Permitir acceso de lectura
•W - Permitir acceso de escritura
•X - Permiso de ejecución sobre el objeto
•D - Eliminar el objeto
•P - Cambiar permisos
•O - Tomar posesión

Los siguientes permisos combinados pueden especificarse:

•READ - Equivalente a permisos 'RX'
•CHANGE - Equivalente a permisos 'RXWD'
•FULL - Equivalente a permisos 'RWXDPO'

ESTADO DE SALIDA

El programa sharesec establece el estado de salida en función del éxito o fracaso de las operaciones realizadas. El estado de salida puede ser uno de los siguientes valores.

Si la operación tuvo éxito, sharesec devuelve un estado de salida de 0. Si sharesec no pudo conectarse al servidor especificado, o hubo un error al obtener o establecer las ACLs, se devuelve un estado de salida de 1. Si hubo un error al analizar algún argumento de la línea de comandos, se devuelve un estado de salida de 2.

EJEMPLOS

Agrega acceso completo para el SID S-1-5-21-1866488690-1365729215-3963860297-17724 en comparticion:

host:~ # sharesec comparticion -a S-1-5-21-1866488690-1365729215-3963860297-17724:PERMITIDO/0/FULL

Lista todas las ACEs para comparticion:

host:~ # sharesec comparticion -v
REVISION:1
CONTROL:SR|DP
PROPIETARIO:
GRUPO:
ACL:S-1-1-0:PERMITIDO/0x0/FULL
ACL:S-1-5-21-1866488690-1365729215-3963860297-17724:PERMITIDO/0x0/FULL
