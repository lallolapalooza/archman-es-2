shmem_short_g(3)

Paquete: openmpi

SHMEM_SHORT_G(3) Open MPI SHMEM_SHORT_G(3)

shmem_char_g(3), shmem_float_g(3), shmem_int_g(3), shmem_long_g(3), shmem_short_g(3), shmem_longlong_g(3), shmem_longdouble_g(3) - Estas rutinas proporcionan un mecanismo de baja latencia para leer tipos básicos (char, short, int, float, double, long, long long, long double) de objetos de datos simétricos en PEs remotos.

SYNOPSIS

C o C++:

#include <mpp/shmem.h>
char shmem_char_g(const char *addr, int pe)
short shmem_short_g(const short *addr, int pe)
int shmem_int_g(const int *addr, int pe)
long shmem_long_g(const long *addr, int pe)
long shmem_longlong_g(const long long *addr, int pe)
float shmem_float_g(const float *addr, int pe)
double shmem_double_g(const double *addr, int pe)
long shmem_longdouble_g(const long double *addr, int pe)

DESCRIPCIÓN

Estas rutinas proporcionan una capacidad de "get" de latencia muy baja para elementos individuales de la mayoría de los tipos básicos.

Los argumentos son los siguientes:

addr
El elemento del array o el objeto de datos escalar accesible remotamente que recibirá los datos en el PE remoto.
pe
El número del PE remoto.
