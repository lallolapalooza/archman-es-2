NOMBRE

shlock - Crear archivos de bloqueo para usar en scripts de shell

SINOPSIS

shlock [-b|-c|-u] -f nombre -p pid

DESCRIPCIÓN

shlock intenta crear un archivo de bloqueo llamado nombre y escribir el ID del proceso pid en él. Si el archivo ya existe, shlock leerá el ID del proceso del archivo y probará a ver si el proceso se está ejecutando actualmente. Si el proceso existe, entonces el archivo no se creará. shlock saldrá con un estado cero si pudo crear el archivo de bloqueo, o no cero si el archivo se refiere a un proceso actualmente activo.

Se puede usar un wrapper de Perl para shlock a través del módulo "INN::Utils::Shlock".

OPCIONES

-b
Los IDs de proceso normalmente se leen y escriben en ASCII. Si se usa la bandera -b, se escribirán como un entero binario.
-c
Si se usa la bandera -c, entonces shlock no creará un archivo de bloqueo, sino que usará el archivo para ver si el bloqueo está en posesión de otro programa. Si el bloqueo es válido, el programa saldrá con un estado no cero; si el bloqueo no es válido (es decir, invocar shlock sin la bandera habría tenido éxito), entonces el programa saldrá con un estado cero.
-f nombre
nombre es el nombre del archivo de bloqueo que shlock intenta crear. Si el archivo ya existe, leerá el ID del proceso del archivo y saldrá con un estado no cero si este proceso está actualmente activo.
-p pid
pid es el ID del proceso que se escribirá en el archivo nombre.
-u
Para compatibilidad con otros sistemas, se acepta la bandera -u como sinónimo de -b ya que muchos paquetes de UUCP usan bloqueos binarios.

EJEMPLOS

El siguiente ejemplo muestra cómo se usaría shlock dentro de un script de shell:

LOCK=<ruta del ejecutable en inn.conf>/LOCK.send
trap 'rm -f ${LOCK} ; exit 1' 1 2 3 15
if shlock -p $$ -f ${LOCK} ; then
    # Hacer el trabajo apropiado.
else
    echo "Bloqueado por `cat ${LOCK}`"
fi
