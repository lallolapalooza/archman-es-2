SINÓPSIS

C o C++:

#include <mpp/shmem.h>
void shmem_int_wait(volatile int *var, int value)
void shmem_int_wait_until(volatile int *var, int cond, int value)
void shmem_long_wait(volatile long *var, long value)
void shmem_long_wait_until(volatile long *var, int cond, long value)
void shmem_longlong_wait(volatile long long *var, long long value)
void shmem_longlong_wait_until(volatile long long *var, int cond,
  long long value)
void shmem_short_wait(volatile short *var, short value)
void shmem_short_wait_until(volatile short *var, int cond,
  short value)
void shmem_wait(volatile long *ivar, long cmp_value)
void shmem_wait_until(volatile long *ivar, int cmp, long value)

Fortran:

INCLUDE "mpp/shmem.fh"
CALL SHMEM_INT4_WAIT(ivar, cmp_value)
CALL SHMEM_INT4_WAIT_UNTIL(ivar, cmp, cmp_value)
CALL SHMEM_INT8_WAIT(ivar, cmp_value)
CALL SHMEM_INT8_WAIT_UNTIL(ivar, cmp, cmp_value)
CALL SHMEM_WAIT(ivar, cmp_value)
CALL SHMEM_WAIT_UNTIL(ivar, cmp, cmp_value)

DESCRIPCIÓN

shmem_wait y shmem_wait_until esperan a que ivar sea modificado por una escritura remota o un intercambio atómico emitido por un procesador diferente. Estas rutinas se pueden usar para la sincronización dirigida punto a punto. Una llamada a shmem_wait no retorna hasta que otro procesador escribe un valor, distinto de cmp_value, en ivar en el procesador que espera. Una llamada a shmem_wait_until no retorna hasta que otro procesador modifica ivar para satisfacer la condición implícita por cmp y cmp_value. Este mecanismo es útil cuando un procesador necesita notificar a otro procesador que ha completado alguna acción.

Los argumentos son los siguientes:

target
El objeto de datos entero accesible remotamente que se va a actualizar en el PE remoto. Si está usando C/C++, el tipo de target debe coincidir con el implicado en la sección SINÓPSIS. Si está usando el compilador Fortran, debe ser de tipo entero con un tamaño de elemento de 4 bytes para SHMEM_INT4_ADD y 8 bytes para SHMEM_INT8_ADD.
value
El valor que se va a sumar atómicamente a target. Si está usando C/C++, el tipo de value debe coincidir con el implicado en la sección SINÓPSIS. Si está usando Fortran, debe ser de tipo entero con un tamaño de elemento del mismo tamaño que target.
pe
Un entero que indica el número de PE en el que se va a actualizar target. Si está usando Fortran, debe ser un valor entero predeterminado.
ivar
Una variable entera accesible remotamente que está siendo actualizada por otro PE. Si está usando C/C++, el tipo de ivar debe coincidir con el implicado en la sección SINÓPSIS. Si está usando Fortran, ivar debe ser un tipo entero de tamaño específico según la función que se esté llamando, como sigue:

shmem_wait, shmem_wait_until:** ENTERO predeterminado

shmem_int4_wait, shmem_int4_wait_until:** INTEGER*4

shmem_int8_wait, shmem_int8_wait_until:** INTEGER*8

cmp
El operador de comparación que compara ivar con cmp_value. cmp debe ser de tipo entero. Si está usando Fortran, debe ser de tipo predeterminado. Si está usando C/C++, el tipo de cmp debe coincidir con el implicado en la sección SINÓPSIS. Los siguientes valores de cmp son compatibles:
SHMEM_CMP_EQ
Igual
SHMEM_CMP_NE
No igual
SHMEM_CMP_GT
Mayor que
SHMEM_CMP_LE
Menor o igual que
SHMEM_CMP_LT
Menor que
SHMEM_CMP_GE
Mayor o igual que
cmp_value
cmp_value debe ser de tipo entero. Si está usando C/C++, el tipo de cmp_value debe coincidir con el implicado en la sección SINÓPSIS. Si está usando Fortran, cmp_value debe ser un entero del mismo tamaño y tipo que ivar. Las rutinas shmem_wait retornan cuando ivar ya no es igual a cmp_value. Las rutinas shmem_wait_until retornan cuando la condición de comparación se cumple. La condición de comparación se define mediante el argumento ivar comparado con cmp_value usando el operador de comparación, cmp.

EJEMPLOS

Ejemplo 1: La siguiente llamada retorna cuando la variable ivar no es igual a 100:

INTEGER*8 IVAR
CALL SHMEM_INT8_WAIT(IVAR, INT8(100))

Ejemplo 2: La siguiente llamada a SHMEM_INT8_WAIT_UNTIL es equivalente a la llamada a SHMEM_INT8_WAIT en el ejemplo 1:

INTEGER*8 IVAR
CALL SHMEM_INT8_WAIT_UNTIL(IVAR, SHMEM_CMP_NE, INT8(100))

Ejemplo 3: La siguiente llamada C/C++ espera hasta que el bit de signo en ivar sea establecido por una transferencia desde un PE remoto:

int ivar;
shmem_int_wait_until(&ivar, SHMEM_CMP_LT, 0);

Ejemplo 4: El siguiente ejemplo de Fortran se encuentra en el contexto de una subrutina:

SUBROUTINE EXAMPLE()
  INTEGER FLAG_VAR
  COMMON/FLAG/FLAG_VAR
  . . .
  FLAG_VAR = FLAG_VALUE ! inicializa la variable de evento
  . . .
  IF (FLAG_VAR .EQ. FLAG_VALUE) THEN
    CALL SHMEM_WAIT(FLAG_VAR, FLAG_VALUE)
  ENDIF
  FLAG_VAR = FLAG_VALUE ! reinicia la variable de evento para la próxima vez
  . . .
END
