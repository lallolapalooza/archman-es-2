NOMBRE

shikanectl - controla el demonio de shikane

SINOPSIS

shikanectl [opciones] <comando>

OPCIONES

-h, --help
Imprime información de ayuda
-s, --socket socket
Conéctate al socket especificado
-V, --version
Imprime información de la versión

COMANDOS

recargar [archivo]
Recarga el archivo de configuración del demonio, opcionalmente proporcionando un archivo diferente.
cambiar nombre
Usa el perfil dado temporalmente.
exportar [opciones] nombre
Exporta la configuración de pantalla actual como configuración de shikane. Incluye el proveedor, modelo y número de serie en las búsquedas por defecto. Se recomienda usar un nombre significativo y único para el nuevo perfil.

OPCIONES DE EXPORTACIÓN

-d, --description
Incluye la descripción en las búsquedas
-n, --name
Incluye el nombre en las búsquedas
-m, --model
Incluye el modelo en las búsquedas
-s, --serial
Incluye el número de serie en las búsquedas
-v, --vendor
Incluye el proveedor en las búsquedas

EJEMPLOS

Usando shikanectl export para añadir la configuración de salida actual como un nuevo perfil a tu configuración existente. Simplemente reemplaza el nombre del perfil con algo significativo y único.

shikanectl export "NUEVO_NOMBRE_PERFIL" >> $XDG_CONFIG_HOME/shikane/config.toml

ERRORES

Esperemos que menos de 4.
