shmem_long_fadd(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_LONG_FADD(3) Open MPI SHMEM_LONG_FADD(3)

shmem_int4_fadd(3), shmem_int8_fadd(3), shmem_int_fadd(3), shmem_long_fadd(3), shmem_longlong_fadd(3) - Realiza una operación atómica de obtener y sumar en un objeto de datos remoto

SINOPSIS

C o C++:

#include <mpp/shmem.h>
int shmem_int_fadd(int *target, int value, int pe)
long shmem_long_fadd(long *target, long value, int pe)
long long shmem_longlong_fadd(long long *target, longlong value,
  int pe)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER pe
INTEGER(KIND=4) SHMEM_INT4_FADD, ires, target, value
ires = SHMEM_INT4_FADD(target, value, pe)
INTEGER(KIND=8) SHMEM_INT8_FADD, ires, target, value
ires = SHMEM_INT8_FADD(target, value, pe)

DESCRIPCIÓN

Las funciones shmem_fadd realizan una operación atómica de obtener y sumar. Una operación atómica de obtener y sumar obtiene el valor anterior del objetivo y le suma el valor al objetivo sin la posibilidad de que otro proceso actualice el objetivo entre el momento de la obtención y la actualización. Estas rutinas suman el valor al objetivo en el Elemento de Procesamiento (PE) pe y devuelven el contenido anterior del objetivo como una operación atómica.

Los argumentos son los siguientes:

objetivo
El objeto de datos entero accesible remotamente que se va a actualizar en el PE remoto. El tipo de objetivo debe coincidir con el implícito en la sección SINOPSIS.
valor
El valor que se añadirá atómicamente al objetivo. El tipo de valor debe coincidir con el implícito en la sección SINOPSIS.
pe
Un entero que indica el número de PE en el que se actualizará el objetivo. Si utiliza Fortran, debe ser un valor entero predeterminado.

NOTAS

El término accesible remotamente se define en intro_shmem(3).

VALORES DE RETORNO

Los contenidos que estaban en la dirección del objetivo en el PE remoto antes de la operación de suma atómica.
