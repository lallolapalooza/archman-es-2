shmem_longlong_swap(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_LONGLONG_SWAP(3) Open MPI SHMEM_LONGLONG_SWAP(3)

shmem_double_swap(3), shmem_float_swap(3), shmem_int_swap(3), shmem_long_swap(3), shmem_swap(3), shmem_int4_swap(3), shmem_int8_swap(3), shmem_real4_swap(3), shmem_real8_swap(3), shmem_longlong_swap(3) - Realiza un intercambio atómico a un objeto de datos remoto

SINOPSIS

C o C++:

#include <mpp/shmem.h>
double shmem_double_swap(double *target, double value,
  int pe)
float shmem_float_swap(float *target, float value, int pe)
int shmem_int_swap(int *target, int value, int pe)
long shmem_long_swap(long *target, long value, int pe)
long long shmem_longlong_swap(long long *target,
  long long value, int pe)
long shmem_swap(long *target, long value, int pe)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER pe
INTEGER SHMEM_SWAP
ires = SHMEM_SWAP(target, value, pe)
INTEGER(KIND=4) SHMEM_INT4_SWAP
ires = SHMEM_INT4_SWAP(target, value, pe)
INTEGER(KIND=8) SHMEM_INT8_SWAP
ires = SHMEM_INT8_SWAP(target, value, pe)
REAL(KIND=4) SHMEM_REAL4_SWAP
res = SHMEM_REAL4_SWAP(target, value, pe)
REAL(KIND=8) SHMEM_REAL8_SWAP
res = SHMEM_REAL8_SWAP(target, value, pe)

DESCRIPCIÓN

Las rutinas de intercambio atómico escriben value en la dirección target en el PE pe, y devuelven el contenido previo de target en una operación atómica.

Los argumentos son los siguientes:

target
El objeto de datos entero accesible remotamente que se va a actualizar en el PE remoto. Si estás utilizando C/C++, el tipo de target debe coincidir con el implícito en la sección SINOPSIS. Si estás utilizando Fortran, debe ser del siguiente tipo:

SHMEM_SWAP: Entero de tipo predeterminado

SHMEM_INT4_SWAP: Entero de 4 bytes

SHMEM_INT8_SWAP: Entero de 8 bytes

SHMEM_REAL4_SWAP: Real de 4 bytes

SHMEM_REAL8_SWAP: Real de 8 bytes

value
Valor que se va a escribir atómicamente en el PE remoto. value es del mismo tipo que target.
pe
Un entero que indica el número de PE en el que se va a actualizar target. Si estás utilizando Fortran, debe ser un valor entero predeterminado.

NOTAS

El término accesible remotamente se define en intro_shmem(3).

VALORES DE RETORNO

Se devuelven los contenidos que estaban en la dirección target en el PE remoto antes del intercambio.
