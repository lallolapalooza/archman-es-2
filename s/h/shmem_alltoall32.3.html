SHMEM_ALLTOALL32(3) Open MPI SHMEM_ALLTOALL32(3)

shmem_alltoall32(3), shmem_alltoall64(3), shmem_alltoalls32(3), shmem_alltoalls64(3) - rutina colectiva donde cada PE intercambia una cantidad fija de datos con todos los demás PEs del conjunto Activo

SINOPSIS

C o C++:

#include <mpp/shmem.h>
void shmem_alltoall32(void *target, const void *source,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoall64(void *target, const void *source,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoalls32(void *target, const void *source,
  ptrdiff_t dst, ptrdiff_t sst,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoalls64(void *target, const void *source,
  ptrdiff_t dst, ptrdiff_t sst,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER dst, sst, nelems, PE_root, PE_start, logPE_stride, PE_size
INTEGER pSync(SHMEM_ALLTOALL_SYNC_SIZE)
CALL SHMEM_ALLTOALL32(target, source, nelems,
& PE_start, logPE_stride, PE_size, fIpSync)
CALL SHMEM_ALLTOALL64(target, source, nelems,
& PE_start, logPE_stride, PE_size, pSync)
CALL SHMEM_ALLTOALLS32(target, source, dst, sst, nelems,
& PE_start, logPE_stride, PE_size, pSync)
CALL SHMEM_ALLTOALLS64(target, source, dst, sst, nelems,
& PE_start, logPE_stride, PE_size, pSync)

DESCRIPCIÓN

Las rutinas shmem_alltoalls son rutinas colectivas. Cada PE del conjunto Activo intercambia nelems elementos de datos con strides de 32 bits (para shmem_alltoalls32) o 64 bits (para shmem_alltoalls64) con todos los demás PEs del conjunto. Tanto los strides, dst y sst, deben ser mayores o iguales a 1. El bloque j-ésimo * sst enviado desde el PE i al PE j se coloca en el bloque i-ésimo * dst del objeto de datos de destino en el PE j. Como con todas las rutinas colectivas de OpenSHMEM, estas rutinas asumen que solo los PEs del conjunto Activo llaman a la rutina. Si un PE que no está en el conjunto Activo llama a una rutina colectiva de OpenSHMEM, se producirá un comportamiento indefinido. Los valores de los argumentos dst, sst, nelems, PE_start, logPE_stride y PE_size deben ser iguales en todos los PEs del conjunto Activo. Los mismos objetos de datos de destino y origen, y el mismo array de trabajo pSync deben pasarse a todos los PEs del conjunto Activo. Antes de cualquier llamada a una rutina shmem_alltoalls, deben existir las siguientes condiciones (a menudo se necesita sincronización mediante una barrera o algún otro método para asegurar esto): El array pSync en todos los PEs del conjunto Activo no está todavía en uso por una llamada anterior a una rutina shmem_alltoalls. El objeto de datos de destino en todos los PEs del conjunto Activo está listo para recibir los datos de shmem_alltoalls. Al regresar de una rutina shmem_alltoalls, lo siguiente es cierto para el PE local: Su objeto de datos simétrico de destino está completamente actualizado y los datos se han copiado fuera del objeto de datos de origen. Los valores en el array pSync se restauran a los valores originales.

Los argumentos son los siguientes:

Un objeto de datos simétrico con uno de los siguientes tipos de datos:

shmem_alltoall32: Cualquier tipo no carácter que
tenga un tamaño de elemento de 32 bits. No se permiten tipos derivados de Fortran ni estructuras de C/C++.
shmem_alltoall64: Cualquier tipo no carácter que tenga un tamaño de elemento
de 64 bits. No se permiten tipos derivados de Fortran ni estructuras de C/C++.

target Un objeto de datos simétrico lo suficientemente grande como para recibir el total combinado de nelems elementos de cada PE en el conjunto Activo.

source
Un objeto de datos simétrico que contiene nelems elementos de datos para cada PE en el conjunto Activo, ordenados según el PE de destino.
dst
El stride entre elementos consecutivos del objeto de datos de destino. El stride se escala por el tamaño del elemento. Un valor de 1 indica datos contiguos. dst debe ser de tipo ptrdiff_t. Si está usando Fortran, debe ser un valor entero predeterminado.
sst
El stride entre elementos consecutivos del objeto de datos de origen. El stride se escala por el tamaño del elemento. Un valor de 1 indica datos contiguos. sst debe ser de tipo ptrdiff_t. Si está usando Fortran, debe ser un valor entero predeterminado.
nelems
El número de elementos a intercambiar para cada PE. nelems debe ser de tipo size_t para C/C++. Si está usando Fortran, debe ser un valor entero predeterminado.
PE_start
El número de PE virtual más bajo del conjunto activo de PEs. PE_start debe ser de tipo entero. Si está usando Fortran, debe ser un valor entero predeterminado.
logPE_stride
El logaritmo (base 2) del stride entre números de PE virtuales consecutivos en el conjunto activo. log_PE_stride debe ser de tipo entero. Si está usando Fortran, debe ser un valor entero predeterminado.
PE_size
El número de PEs en el conjunto activo. PE_size debe ser de tipo entero. Si está usando Fortran, debe ser un valor entero predeterminado.
pSync
Un array de trabajo simétrico. En C/C++, pSync debe ser de tipo long y tamaño _SHMEM_ALLTOALL_SYNC_SIZE. En Fortran, pSync debe ser de tipo entero y tamaño SHMEM_ALLTOALL_SYNC_SIZE. Cada elemento de este array debe inicializarse con el valor _SHMEM_SYNC_VALUE (en C/C++) o SHMEM_SYNC_VALUE (en Fortran) antes de que cualquiera de los PEs del conjunto activo entre en shmem_barrier().

Al regresar de una rutina shmem_alltoalls, lo siguiente es cierto para el PE local: Su objeto de datos simétrico de destino está completamente actualizado y los datos se han copiado fuera del objeto de datos de origen. Los valores en el array pSync se restauran a los valores originales.

Los valores de los argumentos PE_root, PE_start, logPE_stride y PE_size deben ser iguales en todos los PEs del conjunto activo. Los mismos objetos de datos de destino y origen y el mismo array de trabajo pSync deben pasarse a todos los PEs del conjunto activo.

Antes de que cualquier PE llame a una rutina alltoall, debe asegurarse de que las siguientes condiciones existen (a menudo se necesita sincronización mediante una barrera o algún otro método para asegurar esto): El array pSync en todos los PEs del conjunto activo no está todavía en uso por una llamada anterior a una rutina alltoall. El array de destino en todos los PEs del conjunto activo está listo para aceptar los datos de alltoall.

NOTAS

Los términos colectivo y simétrico se definen en intro_shmem(3).

Todas las rutinas SHMEM alltoall restauran pSync a su contenido original. Múltiples llamadas a rutinas SHMEM que usan el mismo array pSync no requieren que pSync se reinicialice después de la primera llamada.

Debe asegurarse de que el array pSync no está siendo actualizado por ningún PE del conjunto activo mientras cualquiera de los PEs participa en el procesamiento de una rutina de difusión SHMEM. Tenga cuidado para evitar estas situaciones: Si el array pSync se inicializa en tiempo de ejecución, se necesita algún tipo de sincronización para asegurar que todos los PEs del conjunto de trabajo hayan inicializado pSync antes de que cualquiera de ellos entre en una rutina SHMEM llamada con el array de sincronización pSync. Un array pSync puede reutilizarse en una rutina SHMEM posterior solo si ninguno de los PEs del conjunto activo todavía está procesando una llamada previa a la rutina SHMEM alltoall que utilizó el mismo array pSync. En general, esto solo se puede asegurar realizando algún tipo de sincronización. Sin embargo, en el caso especial de las rutinas SHMEM que se llaman con el mismo conjunto activo, puede asignar dos arrays pSync y alternar entre ellos en llamadas sucesivas.

shmem_alltoall32(3) — Open MPI Community

SYNOPSIS

#include <mpi.h>
#include <shmem.h>

void shmem_alltoall32(void *dest, const void *source, int nlong,
                     int pe_start, int pe_stride, int pe_count,
                     long *pSync);
void shmem_alltoall64(void *dest, const void *source, int nlong,
                     int pe_start, int pe_stride, int pe_count,
                     long *pSync);

DESCRIPTION

The symmetric all-to-all operations perform a global data-interchange operation. Each processing element (PE) sends the same contiguous data object to every other PE, and receives a data object from every other PE.

The elements in the source array are sent to all PEs specified by the pe_start, pe_stride, and pe_count arguments. The data received is placed into the dest array.

The size of the data object is specified by nlong. The shmem_alltoall32 routine operates on 32-bit words, and the shmem_alltoall64 routine operates on 64-bit words.

The arguments pe_start, pe_stride, and pe_count define the set of PEs that participate in the communication. The participating PEs are numbered pe_start, pe_start + pe_stride, ..., pe_start + (pe_count - 1) * pe_stride. If pe_stride is zero, then pe_count must be one and pe_start must be 0.

All PEs must participate in the operation, and the arguments pe_start, pe_stride, and pe_count must be the same for all PEs.

The pSync argument is a pointer to an array of SHMEM_ALLTOALLS_SYNC_SIZE integers. This array must be initialized to SHMEM_SYNC_VALUE on all participating PEs prior to calling the collective routine. This synchronization is required to ensure that all PEs have completed the operation.

NOTES

The shmem_alltoall32 and shmem_alltoall64 routines are collective routines. All PEs must execute these routines.

The dest and source arguments must be symmetric across all participating PEs. Specifically, the address and size of the data object must be the same for all PEs.

The pSync array must be allocated symmetrically across all participating PEs. All elements of the pSync array must be initialized to SHMEM_SYNC_VALUE before calling the routine.

EXAMPLES

#include <shmem.h>
#include <stdio.h>
#include <stdlib.h>

#define COUNT 100

int main(int argc, char **argv) {
    long *source;
    long *dest;
    long *pSync;
    int i, pe, count;

    /* Initialize shared memory environment */
    start_pes(0);

    /* Allocate memory for source, destination, and synchronization arrays */
    source = (long *) shmem_malloc(sizeof(long) * COUNT);
    dest = (long *) shmem_malloc(sizeof(long) * COUNT * shmem_n_pes());
    pSync = (long *) shmem_malloc(sizeof(long) * SHMEM_ALLTOALLS_SYNC_SIZE);

    /* Initialize source array */
    for (i = 0; i < COUNT; i++) {
        source[i] = shmem_my_pe() * COUNT + i;
    }

    /* Initialize synchronization array */
    for (i = 0; i < SHMEM_ALLTOALLS_SYNC_SIZE; i++) {
        pSync[i] = SHMEM_SYNC_VALUE;
    }

    /* Wait for all PEs to initialize pSync */
    shmem_barrier_all();

    /* Perform the alltoall operation */
    shmem_alltoall64(dest, source, COUNT, 0, 1, shmem_n_pes(), pSync);

    /* Verify the results */
    for (pe = 0; pe < shmem_n_pes(); pe++) {
        for (i = 0; i < COUNT; i++) {
            if (dest[pe * COUNT + i] != pe * COUNT + i) {
                printf("[%d] ERROR: dest[%d] = %ld, expected %ld\n",
                       shmem_my_pe(), pe * COUNT + i, dest[pe * COUNT + i],
                       pe * COUNT + i);
            }
        }
    }

    /* Free allocated memory */
    shmem_free(source);
    shmem_free(dest);
    shmem_free(pSync);

    /* Finalize shared memory environment */
    shmem_finalize();

    return 0;
}

#include <shmem.h>
#include <stdio.h>
#include <stdlib.h>

#define COUNT 100

int main(int argc, char **argv) {
    int *source;
    int *dest;
    long *pSync;
    int i, pe;
    int count; /* Number of elements to send/receive */

    /* Initialize the OpenSHMEM environment */
    start_pes(0);

    /* Determine the number of PEs and the current PE */
    int num_pes = shmem_n_pes();
    int my_pe = shmem_my_pe();

    /* Allocate memory for the source, destination, and synchronization arrays */
    /* Source array will hold data to be sent */
    source = (int *) shmem_malloc(sizeof(int) * COUNT);
    /* Destination array will hold data received from all PEs */
    dest = (int *) shmem_malloc(sizeof(int) * COUNT * num_pes);
    /* Synchronization array for the alltoall collective */
    pSync = (long *) shmem_malloc(sizeof(long) * SHMEM_ALLTOALLS_SYNC_SIZE);

    /* Initialize the source array with values unique to each PE */
    /* Each PE 'my_pe' fills its source array with 'my_pe * COUNT + i' */
    for (i = 0; i < COUNT; i++) {
        source[i] = my_pe * COUNT + i;
    }

    /* Initialize the synchronization array with the required sync value */
    /* This is crucial for the correct functioning of collective operations */
    for (i = 0; i < SHMEM_ALLTOALLS_SYNC_SIZE; i++) {
        pSync[i] = SHMEM_SYNC_VALUE;
    }

    /* Synchronize all PEs to ensure they are ready for the collective operation */
    /* All PEs must reach this barrier before proceeding */
    shmem_barrier_all();

    /* Perform the all-to-all communication */
    /* 'dest': buffer to receive data */
    /* 'source': buffer containing data to send */
    /* 'COUNT': number of 32-bit integers to exchange per PE */
    /* '0': starting PE index (all PEs participate) */
    /* '1': stride between PE indices */
    /* 'num_pes': number of PEs to participate */
    /* 'pSync': synchronization array */
    shmem_alltoalls32(dest, source, COUNT, 0, 1, num_pes, pSync);

    /* Verify the results */
    /* Each PE checks if the data received is correct */
    /* For a given PE 'pe', it should have received the data that PE 'pe' sent */
    for (pe = 0; pe < num_pes; pe++) {
        for (i = 0; i < COUNT; i++) {
            /* The data at dest[pe*COUNT + i] should be the value sent by PE 'pe' */
            /* which is 'pe * COUNT + i' */
            if (dest[(pe * COUNT) + i] != pe * COUNT + i) {
                printf("[%d] ERROR: dest[%d]=%d, should be %d\n",
                       my_pe, (pe * COUNT) + i, dest[(pe * COUNT) + i],
                       pe * COUNT + i);
            }
        }
    }

    /* Wait for all PEs to finish verification */
    shmem_barrier_all();

    /* Free the dynamically allocated memory */
    shmem_free(source);
    shmem_free(dest);
    shmem_free(pSync);

    /* Finalize the OpenSHMEM environment */
    shmem_finalize();

    return 0;
}
