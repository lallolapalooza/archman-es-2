shmem_int_cswap(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_INT_CSWAP(3) Open MPI SHMEM_INT_CSWAP(3)

shmem_int_cswap(3), shmem_int4_cswap(3), shmem_int8_cswap(3), shmem_long_cswap(3), shmem_longlong_cswap(3) - Realiza un intercambio condicional atómico en un objeto de datos remoto

SINOPSIS

C o C++:

#include <mpp/shmem.h>
int shmem_int_cswap(int *target, int cond, int value, int pe)
long shmem_long_cswap(long *target, long cond, long value,
  int pe)
long long shmem_longlong_cswap(longlong *target,
  longlong cond, longlong value, int pe)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER pe
INTEGER(KIND=4) SHMEM_INT4_CSWAP
ires = SHMEM_INT4_CSWAP(target, cond, value, pe)
INTEGER(KIND=8) SHMEM_INT8_CSWAP
ires = SHMEM_INT8_CSWAP(target, cond, value, pe)

DESCRIPCIÓN

Las rutinas de intercambio condicional actualizan condicionalmente un objeto de datos destino en un elemento de procesamiento (PE) arbitrario y devuelven el contenido previo del objeto de datos en una única operación atómica.

Los argumentos son los siguientes:

objetivo
El objeto de datos entero accesible remotamente que se va a actualizar en el PE remoto. Si estás usando C/C++, el tipo de objetivo debe coincidir con el implícito en la sección SINOPSIS. Si estás usando el compilador Fortran, debe ser de tipo entero con un tamaño de elemento de 4 bytes para SHMEM_INT4_ADD y 8 bytes para SHMEM_INT8_ADD.
valor
El valor que se va a añadir atómicamente a objetivo. Si estás usando C/C++, el tipo de valor debe coincidir con el implícito en la sección SINOPSIS. Si estás usando Fortran, debe ser de tipo entero con un tamaño de elemento igual al de objetivo.
pe
Un entero que indica el número de PE en el que se va a actualizar objetivo. Si estás usando Fortran, debe ser un valor entero predeterminado.
objetivo
El objeto de datos entero accesible remotamente que se va a actualizar en el PE remoto. Si estás usando C/C++, el tipo de datos de objetivo debe coincidir con el implícito en la sección SINOPSIS. Si estás usando Fortran, debe ser del siguiente tipo:

SHMEM_INT4_CSWAP: entero de 4 bytes

SHMEM_INT8_CSWAP: entero de 8 bytes

cond
cond se compara con el valor objetivo remoto. Si cond y el objetivo remoto son iguales, entonces valor se intercambia en el objetivo remoto. De lo contrario, el objetivo remoto no cambia. En cualquier caso, el valor antiguo del objetivo remoto se devuelve como valor de retorno de la función. cond debe ser del mismo tipo de datos que objetivo.
valor
El valor que se va a escribir atómicamente en el PE remoto. valor debe ser del mismo tipo de datos que objetivo.
pe
Un entero que indica el número de PE en el que se va a actualizar objetivo. Si estás usando Fortran, debe ser un valor entero predeterminado.

NOTAS

El término accesible remotamente se define en intro_shmem(3).

VALORES DE RETORNO

Los contenidos que estaban en el objeto de datos objetivo en el PE remoto antes del intercambio condicional.

EJEMPLOS

La siguiente llamada asegura que el primer PE en ejecutar el intercambio condicional escribirá correctamente su número de PE en race_winner en el PE 0.

main()
{
  static int race_winner = -1;
  int oldval;
  shmem_init();
  oldval = shmem_int_cswap(&race_winner, -1, shmem_my_pe(), 0);
  if (oldval == -1)
    printf("pe %d fue el primero\n",shmem_my_pe());
}
