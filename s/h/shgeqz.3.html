SHGEQZ

Propósito:

!>
!> SHGEQZ calcula los valores propios de un par de matrices reales (H,T),
!> donde H es una matriz superior de Hessenberg y T es triangular superior,
!> utilizando el método QZ de doble desplazamiento.
!> Los pares de matrices de este tipo se producen por la reducción a
!> forma de Hessenberg generalizada de un par de matrices real (A,B):
!>
!>    A = Q1*H*Z1**T,  B = Q1*T*Z1**T,
!>
!> como se calcula por SGGHRD.
!>
!> Si JOB='S', entonces el par Hessenberg-triangular (H,T) se
!> reduce también a forma de Schur generalizada,
!>
!>    H = Q*S*Z**T,  T = Q*P*Z**T,
!>
!> donde Q y Z son matrices ortogonales, P es una matriz triangular
!> superior, y S es una matriz cuasi-triangular con bloques diagonales de 1x1 y 2x2.
!>
!> Los bloques de 1x1 corresponden a valores propios reales del par de matrices
!> (H,T) y los bloques de 2x2 corresponden a pares conjugados complejos de
!> valores propios.
!>
!> Adicionalmente, los bloques diagonales triangulares superiores de 2x2 de P
!> correspondientes a los bloques de 2x2 de S se reducen a forma diagonal positiva,
!> es decir, si S(j+1,j) no es cero, entonces P(j+1,j) = P(j,j+1) = 0,
!> P(j,j) > 0, y P(j+1,j+1) > 0.
!>
!> Opcionalmente, la matriz ortogonal Q de la factorización de Schur
!> generalizada puede ser postmultiplicada en una matriz de entrada Q1, y la
!> matriz ortogonal Z puede ser postmultiplicada en una matriz de entrada Z1.
!> Si Q1 y Z1 son las matrices ortogonales de SGGHRD que redujeron
!> el par de matrices (A,B) a forma de Hessenberg generalizada, entonces las
!> matrices de salida Q1*Q y Z1*Z son los factores ortogonales de la
!> factorización de Schur generalizada de (A,B):
!>
!>    A = (Q1*Q)*S*(Z1*Z)**T,  B = (Q1*Q)*P*(Z1*Z)**T.
!>
!> Para evitar desbordamiento, los valores propios del par de matrices (H,T) (equivalente,
!> de (A,B)) se calculan como un par de valores (alfa,beta), donde alfa es
!> complejo y beta real.
!> Si beta es distinto de cero, lambda = alpha / beta es un valor propio del
!> problema de valores propios generalizado no simétrico (GNEP)
!>    A*x = lambda*B*x
!> y si alpha es distinto de cero, mu = beta / alpha es un valor propio de la
!> forma alternativa del GNEP
!>    mu*A*y = B*y.
!> Los valores propios reales se pueden leer directamente de la forma de Schur
!> generalizada:
!>   alpha = S(i,i), beta = P(i,i).
!>
!> Ref: C.B. Moler & G.W. Stewart, , SIAM J. Numer. Anal., 10(1973),
!>      pp. 241--256.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          = 'E': Calcula solo los valores propios;
!>          = 'S': Calcula los valores propios y la forma de Schur.
!>

COMPQ

!>          COMPQ es CHARACTER*1
!>          = 'N': Los vectores de Schur izquierdos (Q) no se calculan;
!>          = 'I': Q se inicializa a la matriz identidad y se devuelve la matriz Q
!>                 de vectores de Schur izquierdos de (H,T);
!>          = 'V': Q debe contener una matriz ortogonal Q1 en la entrada y
!>                 se devuelve el producto Q1*Q.
!>

COMPZ

!>          COMPZ es CHARACTER*1
!>          = 'N': Los vectores de Schur derechos (Z) no se calculan;
!>          = 'I': Z se inicializa a la matriz identidad y se devuelve la matriz Z
!>                 de vectores de Schur derechos de (H,T);
!>          = 'V': Z debe contener una matriz ortogonal Z1 en la entrada y
!>                 se devuelve el producto Z1*Z.
!>

N

!>          N es INTEGER
!>          El orden de las matrices H, T, Q y Z.  N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI marcan las filas y columnas de H que están en
!>          forma de Hessenberg. Se asume que A ya es triangular superior
!>          en las filas y columnas 1:ILO-1 e IHI+1:N.
!>          Si N > 0, 1 <= ILO <= IHI <= N; si N = 0, ILO=1 e IHI=0.
!>

H

!>          H es array REAL, dimensión (LDH, N)
!>          En la entrada, la matriz superior de Hessenberg H de NxN.
!>          En la salida, si JOB = 'S', H contiene la matriz cuasi-triangular superior
!>          S de la factorización de Schur generalizada.
!>          Si JOB = 'E', los bloques diagonales de H coinciden con los de S, pero
!>          el resto de H no está especificado.
!>

LDH

!>          LDH es INTEGER
!>          La dimensión principal del array H.  LDH >= max( 1, N ).
!>

T

!>          T es array REAL, dimensión (LDT, N)
!>          En la entrada, la matriz triangular superior T de NxN.
!>          En la salida, si JOB = 'S', T contiene la matriz triangular
!>          superior P de la factorización de Schur generalizada;
!>          los bloques diagonales de 2x2 de P correspondientes a los bloques de 2x2 de S
!>          se reducen a forma diagonal positiva, es decir, si H(j+1,j) es
!>          distinto de cero, entonces T(j+1,j) = T(j,j+1) = 0, T(j,j) > 0, y
!>          T(j+1,j+1) > 0.
!>          Si JOB = 'E', los bloques diagonales de T coinciden con los de P, pero
!>          el resto de T no está especificado.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.  LDT >= max( 1, N ).
!>

ALPHAR

!>          ALPHAR es array REAL, dimensión (N)
!>          Las partes reales de cada escalar alfa que define un valor propio
!>          de GNEP.
!>

ALPHAI

!>          ALPHAI es array REAL, dimensión (N)
!>          Las partes imaginarias de cada escalar alfa que define un
!>          valor propio de GNEP.
!>          Si ALPHAI(j) es cero, entonces el j-ésimo valor propio es real; si
!>          es positivo, entonces los valores propios j-ésimo y (j+1)-ésimo son un
!>          par conjugado complejo, con ALPHAI(j+1) = -ALPHAI(j).
!>

BETA

!>          BETA es array REAL, dimensión (N)
!>          Los escalares beta que definen los valores propios de GNEP.
!>          Juntos, las cantidades alpha = (ALPHAR(j),ALPHAI(j)) y
!>          beta = BETA(j) representan el j-ésimo valor propio del
!>          par de matrices (A,B), en una de las formas lambda = alpha/beta o
!>          mu = beta/alpha. Dado que lambda o mu pueden desbordarse,
!>          no deben calcularse, en general.
!>

Q

!>          Q es array REAL, dimensión (LDQ, N)
!>          En la entrada, si COMPQ = 'V', la matriz ortogonal Q1 utilizada en
!>          la reducción de (A,B) a forma de Hessenberg generalizada.
!>          En la salida, si COMPQ = 'I', la matriz ortogonal de vectores de Schur
!>          izquierdos de (H,T), y si COMPQ = 'V', la matriz ortogonal de
!>          vectores de Schur izquierdos de (A,B).
!>          No referenciado si COMPQ = 'N'.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.  LDQ >= 1.
!>          Si COMPQ='V' o 'I', entonces LDQ >= N.
!>

Z

!>          Z es array REAL, dimensión (LDZ, N)
!>          En la entrada, si COMPZ = 'V', la matriz ortogonal Z1 utilizada en
!>          la reducción de (A,B) a forma de Hessenberg generalizada.
!>          En la salida, si COMPZ = 'I', la matriz ortogonal de

Function/Subroutine Documentation

SHGEQZ computes the generalized Schur factorization of a real matrix pair (A, B) in the reduced form.

This subroutine is obsolete and is superseded by SGGEQRF and STGSJA.

Arguments:

CHSB

CHSB is CHARACTER*1
 CHSB = 'S' or 'N'.
 If CHSB = 'S', then the input matrices A and B are assumed to be already
 reduced by ZLAHQR to upper triangular form.
 If CHSB = 'N', then the matrices A and B are arbitrary.

NCHSB

NCHSB is INTEGER
 NCHSB = 1 if CHSB = 'S'
 NCHSB = 2 if CHSB = 'N'

JOB

JOB is CHARACTER*1
 JOB = 'E': compute the eigenvalues only.
 JOB = 'V': compute the eigenvalues and the Schur vectors.
 JOB = 'L': compute the eigenvalues and the left Schur vectors.
 JOB = 'R': compute the eigenvalues and the right Schur vectors.

COMPZ

COMPZ is CHARACTER*1
 COMPZ = 'N': do not compute the Schur vectors.
 COMPZ = 'V': compute the Schur vectors Z.
 COMPZ = 'I': compute the Schur vectors Z.
 COMPZ = 'L': compute the left Schur vectors.
 COMPZ = 'R': compute the right Schur vectors.

MATZ

MATZ is CHARACTER*1
 MATZ = 'N': do not compute the Schur vectors.
 MATZ = 'V': compute the Schur vectors Z.
 MATZ = 'I': compute the Schur vectors Z.
 MATZ = 'L': compute the left Schur vectors.
 MATZ = 'R': compute the right Schur vectors.

N

N is INTEGER
 The order of the matrices A and B.  N >= 0.

A

A is REAL array, dimension (LDA,*)
 On entry, A contains the matrix A.
 On exit, A is overwritten by its upper quasi-triangular matrix H,
 which is stored in the upper triangle of A.

LDA

LDA is INTEGER
 The leading dimension of A. LDA >= max(1,N).

B

B is REAL array, dimension (LDB,*)
 On entry, B contains the matrix B.
 On exit, B is overwritten by its upper triangular matrix T, which is
 stored in the upper triangle of B.

LDB

LDB is INTEGER
 The leading dimension of B. LDB >= max(1,N).

ALPHA

ALPHA is COMPLEX array, dimension (N)
 On exit, ALPHA(i) and BETA(i) specify the I-th generalized eigenvalue
                lambda_i = ALPHA(i) / BETA(i).
 ALPHA(i) is always real.

BETA

BETA is COMPLEX array, dimension (N)
 On exit, ALPHA(i) and BETA(i) specify the I-th generalized eigenvalue
                lambda_i = ALPHA(i) / BETA(i).
 BETA(i) is always real.

MATZ

MATZ is CHARACTER*1
 MATZ = 'N': do not compute the Schur vectors.
 MATZ = 'V': compute the Schur vectors Z.
 MATZ = 'I': compute the Schur vectors Z.
 MATZ = 'L': compute the left Schur vectors.
 MATZ = 'R': compute the right Schur vectors.

LDZ

LDZ is INTEGER
 The leading dimension of the array Z. LDZ >= 1.
 If MATZ = 'V', 'I', 'L', or 'R', then LDZ >= N.

Z

Z is REAL array, dimension (LDZ, N)
 On exit, if MATZ = 'V', Z contains the orthogonal matrix Z of right
                Schur vectors.
 If MATZ = 'I', Z contains the orthogonal matrix Z of left Schur
                vectors.
 If MATZ = 'L', Z contains the orthogonal matrix of left Schur vectors.
 If MATZ = 'R', Z contains the orthogonal matrix of right Schur vectors.

WORK

WORK is REAL array, dimension (MAX(1,LWORK))
 On exit, if INFO >= 0, WORK(1) returns the optimal LWORK.

LWORK

LWORK is INTEGER
 The dimension of the array WORK. LWORK >= max(1,N).
 If LWORK = -1, then a workspace query is assumed; the routine
 only calculates the optimal size of the WORK array, returns
 this value as the first entry of the WORK array, and no error
 message related to LWORK is issued by XERBLA.

INFO

INFO is INTEGER
 = 0: successful exit
 < 0: if INFO = -i, the i-th argument had an illegal value
 = 1,...,N: the QZ iteration did not converge. (H,T) is not
            in Schur form, but ALPHAR(i), ALPHAI(i), and
            BETA(i), i=INFO+1,...,N should be correct.
 = N+1,...,2*N: the shift calculation failed. (H,T) is not
            in Schur form, but ALPHAR(i), ALPHAI(i), and
            BETA(i), i=INFO-N+1,...,N should be correct.
