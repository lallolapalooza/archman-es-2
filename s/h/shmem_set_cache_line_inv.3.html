shmem_set_cache_line_inv(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_SET_CACHE_LINE_INV(3) Open MPI SHMEM_SET_CACHE_LINE_INV(3)

shmem_clear_cache_inv(3), shmem_set_cache_inv(3), shmem_set_cache_line_inv(3), shmem_udcflush(3), shmem_udcflush_line(3) - Controla las utilidades de la caché de datos

SINOPSIS

C o C++:

#include <mpp/shmem.h>
void shmem_clear_cache_inv(void)
void shmem_clear_cache_line_inv(void *target)
void shmem_set_cache_inv(void)
void shmem_set_cache_line_inv(void *target)
void shmem_udcflush(void)
void shmem_udcflush_line(void *target)

Fortran:

INCLUDE "mpp/shmem.fh"
CALL SHMEM_CLEAR_CACHE_INV
CALL SHMEM_CLEAR_CACHE_LINE_INV(target)
CALL SHMEM_SET_CACHE_INV
CALL SHMEM_SET_CACHE_LINE_INV(target)
CALL SHMEM_UDCFLUSH
CALL SHMEM_UDCFLUSH_LINE(target)

DESCRIPCIÓN

El siguiente argumento se pasa a las rutinas de control de línea de caché:

objetivo
Un objeto de datos que es local al elemento de procesamiento (PE). objetivo puede ser de cualquier tipo no caracter. Si estás usando Fortran, puede ser de cualquier tipo.

shmem_clear_cache_inv deshabilita el modo automático de coherencia de caché previamente habilitado por shmem_set_cache_inv o shmem_set_cache_line_inv.

shmem_clear_cache_line_inv deshabilita el modo automático de coherencia de caché solo para la línea de caché asociada con la dirección de objetivo.

shmem_set_cache_inv habilita la API OpenSHMEM para decidir automáticamente la mejor estrategia para la coherencia de caché.

shmem_set_cache_line_inv habilita el modo automático de coherencia de caché solo para la línea de caché asociada con la dirección de objetivo.

shmem_clear_cache_inv deshabilita el modo automático de coherencia de caché previamente habilitado por shmem_set_cache_inv o shmem_set_cache_line_inv.

shmem_udcflush hace que toda la caché de datos del usuario sea coherente.

shmem_udcflush_line hace coherente la línea de caché que corresponde a la dirección especificada por objetivo.

NOTAS

Estas rutinas se han conservado para mejorar la compatibilidad con versiones anteriores de arquitecturas heredadas.
