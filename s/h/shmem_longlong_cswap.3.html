shmem_longlong_cswap(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_LONGLONG_CSWAP(3) Open MPI SHMEM_LONGLONG_CSWAP(3)

shmem_int_cswap(3), shmem_int4_cswap(3), shmem_int8_cswap(3), shmem_long_cswap(3), shmem_longlong_cswap(3) - Realiza un intercambio condicional atómico a un objeto de datos remoto

SYNOPSIS

C o C++:

#include <mpp/shmem.h>
int shmem_int_cswap(int *target, int cond, int value, int pe)
long shmem_long_cswap(long *target, long cond, long value,
  int pe)
long long shmem_longlong_cswap(longlong *target,
  longlong cond, longlong value, int pe)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER pe
INTEGER(KIND=4) SHMEM_INT4_CSWAP
ires = SHMEM_INT4_CSWAP(target, cond, value, pe)
INTEGER(KIND=8) SHMEM_INT8_CSWAP
ires = SHMEM_INT8_CSWAP(target, cond, value, pe)

DESCRIPCIÓN

Las rutinas de intercambio condicional actualizan condicionalmente un objeto de datos objetivo en un elemento de procesamiento (PE) arbitrario y devuelven el contenido anterior del objeto de datos en una operación atómica.

Los argumentos son los siguientes:

target
El objeto de datos entero accesible remotamente que se actualizará en el PE remoto. Si está utilizando C/C++, el tipo de target debe coincidir con el implicado en la sección SYNOPSIS. Si está utilizando el compilador de Fortran, debe ser de tipo entero con un tamaño de elemento de 4 bytes para SHMEM_INT4_ADD y 8 bytes para SHMEM_INT8_ADD.
value
El valor que se añadirá atómicamente a target. Si está utilizando C/C++, el tipo de value debe coincidir con el implicado en la sección SYNOPSIS. Si está utilizando Fortran, debe ser de tipo entero con un tamaño de elemento igual al de target.
pe
Un entero que indica el número de PE en el que se actualizará target. Si está utilizando Fortran, debe ser un valor entero predeterminado.
target
El objeto de datos entero accesible remotamente que se actualizará en el PE remoto. Si está utilizando C/C++, el tipo de datos de target debe coincidir con el implicado en la sección SYNOPSIS. Si está utilizando Fortran, debe ser del siguiente tipo:

SHMEM_INT4_CSWAP: Entero de 4 bytes

SHMEM_INT8_CSWAP: Entero de 8 bytes

cond
cond se compara con el valor objetivo remoto. Si cond y el objetivo son iguales, entonces value se intercambiará por el objetivo remoto. De lo contrario, el objetivo remoto no se modificará. En cualquier caso, el valor anterior del objetivo remoto se devuelve como valor de retorno de la función. cond debe ser del mismo tipo de datos que target.
value
El valor que se escribirá atómicamente en el PE remoto. value debe ser del mismo tipo de datos que target.
pe
Un entero que indica el número de PE en el que se actualizará target. Si está utilizando Fortran, debe ser un valor entero predeterminado.

NOTAS

El término accesible remotamente se define en intro_shmem(3).

VALORES DE RETORNO

Los contenidos que estaban en el objeto de datos objetivo en el PE remoto antes del intercambio condicional.

EJEMPLOS

La siguiente llamada asegura que el primer PE en ejecutar el intercambio condicional escribirá con éxito su número de PE en race_winner en el PE 0.

main()
{
  static int race_winner = -1;
  int oldval;
  shmem_init();
  oldval = shmem_int_cswap(&race_winner, -1, shmem_my_pe(), 0);
  if (oldval == -1)
    printf("pe %d fue el primero\n",shmem_my_pe());
}
