shmem_barrier - Realiza una operación de barrera en un subconjunto de elementos de procesamiento (PEs).

SINOPSIS

C o C++:

#include <mpp/shmem.h>
void shmem_barrier(int PE_start, int logPE_stride, int PE_size,
  long *pSync)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER PE_start, logPE_stride, PE_size
INTEGER pSync(SHMEM_BARRIER_SYNC_SIZE)
CALL SHMEM_BARRIER(PE_start, logPE_stride, PE_size, pSync)

DESCRIPCIÓN

La rutina shmem_barrier no retorna hasta que el subconjunto de PEs especificado por PE_start, logPE_stride y PE_size ha entrado en esta rutina en el mismo punto del camino de ejecución.

Como con todas las rutinas colectivas de SHMEM, cada una de estas rutinas asume que solo los PEs del conjunto activo llaman a la rutina. Si un PE no perteneciente al conjunto activo llama a una rutina colectiva de SHMEM, el resultado es indefinido.

Los argumentos son los siguientes:

PE_start
El número de PE virtual más bajo del conjunto activo de PEs. PE_start debe ser de tipo entero. Si estás usando Fortran, debe ser un valor entero predeterminado.
logPE_stride
El logaritmo (base 2) del paso entre números de PE virtuales consecutivos en el conjunto activo. logPE_stride debe ser de tipo entero. Si estás usando Fortran, debe ser un valor entero predeterminado.
PE_size
El número de PEs en el conjunto activo. PE_size debe ser de tipo entero. Si estás usando Fortran, debe ser un valor entero predeterminado.
pSync
Un array de trabajo simétrico. En C/C++, pSync debe ser de tipo int y tamaño _SHMEM_BARRIER_SYNC_SIZE. En Fortran, pSync debe ser de tipo entero y tamaño SHMEM_BARRIER_SYNC_SIZE. Si estás usando Fortran, debe ser de tipo entero predeterminado. Cada elemento de este array debe ser inicializado a 0 antes de que cualquiera de los PEs del conjunto activo entre en shmem_barrier por primera vez.

Los valores de los argumentos PE_start, logPE_stride y PE_size deben ser iguales en todos los PEs del conjunto activo. El mismo array de trabajo debe ser pasado en pSync a todos los PEs del conjunto activo.

shmem_barrier asegura que todas las escrituras locales emitidas previamente y las actualizaciones de memoria remota emitidas previamente por cualquiera de los PEs del conjunto activo (usando llamadas SHMEM, por ejemplo shmem_put(3)) se completen antes de retornar.

El mismo array pSync puede ser reutilizado en llamadas consecutivas a shmem_barrier si se usa el mismo conjunto activo de PEs.

NOTAS

El término simétrico se define en intro_shmem(3).

Si el array pSync se inicializa en tiempo de ejecución, asegúrate de usar algún tipo de sincronización, por ejemplo, una llamada a shmem_barrier_all(3), antes de llamar a shmem_barrier por primera vez.

Si el conjunto activo no cambia, shmem_barrier puede ser llamado repetidamente con el mismo array pSync. En este caso, no se necesita ninguna sincronización adicional más allá de la implicada por shmem_barrier.

EJEMPLOS

Ejemplo C/C++:

shmem_barrier(PE_start, logPE_stride, size, pSync);

Ejemplo Fortran:

INTEGER PSYNC(SHMEM_BARRIER_SYNC_SIZE)
INTEGER PE_START, LOGPE_STRIDE, PE_SIZE, PSYNC
DATA PSYNC /SHMEM_BARRIER_SYNC_SIZE*0/
CALL SHMEM_BARRIER(PE_START, LOGPE_STRIDE, PE_SIZE, PSYNC)
