NOMBRE

shapeclustering - entrenamiento de agrupamiento de formas para Tesseract

SINOPSIS

shapeclustering -D directorio_salida -U unicharset -O mfunicharset -F propiedades_fuente -X alturas_x ARCHIVO...

DESCRIPCIÓN

shapeclustering(1) toma archivos .tr de características extraídas (generados por tesseract(1) ejecutado en un modo especial desde archivos box) y produce un archivo shapetable y un unicharset mejorado. Este programa todavía es experimental y (aún) no es necesario para entrenar Tesseract.

OPCIONES

-U ARCHIVO

El unicharset generado por unicharset_extractor(1).

-D dir

Directorio donde escribir los archivos de salida.

-F archivo_propiedades_fuente

(Entrada) archivo de propiedades de fuente, donde cada línea tiene el siguiente formato, y cada campo, excepto el nombre de la fuente, es 0 o 1: 
'nombre_fuente' 'cursiva' 'negrita' 'fuente_fija' 'serif' 'fraktur'

-X archivo_alturas_x

(Entrada) archivo de alturas x, cada línea tiene el siguiente formato, donde la altura x se calcula como la altura x en píxeles de un carácter dibujado a 32pt con 300 ppp. [ Es decir, si altura x base + ascendentes + descendentes = 133, ¿cuánto es la altura x? ] 
'nombre_fuente' 'altura_x'

-O ARCHIVO

El unicharset de salida que se entregará a combine_tessdata(1).
