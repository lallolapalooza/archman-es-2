SHOWMOUNT(8) Manual del Administrador del Sistema SHOWMOUNT(8)

NOMBRE

showmount - muestra información de montaje para un servidor NFS

SINOPSIS

showmount [ -adeh ] [ --all ] [ --directories ] [ --exports ] [ --help ] [ --version ] [ host ]

DESCRIPCIÓN

showmount consulta el demonio de montaje en un host remoto para obtener información sobre el estado del servidor NFS en esa máquina. Sin opciones, showmount lista el conjunto de clientes que están montando desde ese host. La salida de showmount está diseñada para aparecer como si hubiera sido procesada a través de ``sort -u''.

OPCIONES

-a o --all
Lista tanto el nombre de host o la dirección IP del cliente como el directorio montado en formato host:dir. Esta información no debe considerarse fiable. Consulte las notas sobre rmtab en rpc.mountd(8).
-d o --directories
Lista solo los directorios montados por algún cliente.
-e o --exports
Muestra la lista de exportaciones del servidor NFS.
-h o --help
Proporciona un breve resumen de ayuda.
-v o --version
Informa del número de versión actual del programa.
--no-headers
Suprime los encabezados descriptivos de la salida.

VER TAMBIÉN

rpc.mountd(8), rpc.nfsd(8)

ERRORES

La completitud y precisión de la información que muestra showmount varía según la implementación del servidor NFS.

Debido a que showmount ordena y elimina duplicados en la salida, es imposible determinar a partir de la salida si un cliente está montando el mismo directorio más de una vez.

showmount funciona contactando directamente el servicio MNT del servidor. Los servidores que solo usan NFSv4 no necesitan anunciar sus manejadores de archivo raíz exportados a través de este método, y es posible que no expongan su servicio MNT a los clientes.
