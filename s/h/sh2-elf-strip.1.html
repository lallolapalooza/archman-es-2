STRIP(1) Herramientas de desarrollo GNU STRIP(1)

NOMBRE

strip - descarta símbolos y otros datos de archivos objeto

SINOPSIS

strip [-F bfdname |--target=bfdname]
[-I bfdname |--input-target=bfdname]
[-O bfdname |--output-target=bfdname]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nombre_simbolo|--keep-symbol=nombre_simbolo]
[-M|--merge-notes][--no-merge-notes]
[-N nombre_simbolo |--strip-symbol=nombre_simbolo]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nombre_seccion |--remove-section=nombre_seccion]
[--keep-section=patron_seccion]
[--remove-relocations=patron_seccion]
[--strip-section-headers]
[-o archivo] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[-v |--verbose] [-V|--version]
[--help] [--info]
archivo_objeto...

DESCRIPCIÓN

GNU strip descarta todos los símbolos de los archivos objeto archivo_objeto. La lista de archivos objeto puede incluir archivos biblioteca. Se debe proporcionar al menos un archivo objeto.

strip modifica los archivos nombrados en sus argumentos, en lugar de escribir copias modificadas con nombres diferentes.

OPCIONES

-F bfdname
--target=bfdname
Trata el archivo_objeto original como un archivo con el formato de código objeto bfdname y lo reescribe en el mismo formato.
--help
Muestra un resumen de las opciones de strip y sale.
--info
Muestra una lista que indica todas las arquitecturas y formatos de objeto disponibles.
-I bfdname
--input-target=bfdname
Trata el archivo_objeto original como un archivo con el formato de código objeto bfdname.
-O bfdname
--output-target=bfdname
Reemplaza archivo_objeto con un archivo en el formato de salida bfdname.
-R nombre_seccion
--remove-section=nombre_seccion
Elimina cualquier sección llamada nombre_seccion del archivo de salida, además de cualquier sección que de otro modo sería eliminada. Esta opción se puede dar varias veces. Tenga en cuenta que usar esta opción inapropiadamente puede hacer que el archivo de salida no sea utilizable. El carácter comodín * se puede dar al final de nombre_seccion. Si es así, se eliminarán todas las secciones que comiencen con nombre_seccion.

Si el primer carácter de patron_seccion es el signo de exclamación (!), entonces las secciones coincidentes no se eliminarán, incluso si un uso anterior de --remove-section en la misma línea de comandos lo haría de otro modo. Por ejemplo:

--remove-section=.text.* --remove-section=!.text.foo

eliminará todas las secciones que coincidan con el patrón '.text.*', pero no eliminará la sección '.text.foo'.

--keep-section=patron_seccion
Al eliminar secciones del archivo de salida, conserva las secciones que coincidan con patron_seccion.
--remove-relocations=patron_seccion
Elimina las reubicaciones del archivo de salida para cualquier sección que coincida con patron_seccion. Esta opción se puede dar varias veces. Tenga en cuenta que usar esta opción inapropiadamente puede hacer que el archivo de salida no sea utilizable. Se aceptan caracteres comodín en patron_seccion. Por ejemplo: 
--remove-relocations=.text.*

eliminará las reubicaciones de todas las secciones que coincidan con el patrón '.text.*'.

Si el primer carácter de patron_seccion es el signo de exclamación (!), entonces las secciones coincidentes no tendrán sus reubicaciones eliminadas, incluso si un uso anterior de --remove-relocations en la misma línea de comandos causaría de otro modo la eliminación de las reubicaciones. Por ejemplo:

--remove-relocations=.text.* --remove-relocations=!.text.foo

eliminará todas las reubicaciones para las secciones que coincidan con el patrón '.text.*', pero no eliminará las reubicaciones de la sección '.text.foo'.

--strip-section-headers
Elimina las cabeceras de sección. Esta opción es específica de los archivos ELF. Implica --strip-all y --merge-notes.
-s
--strip-all
Elimina todos los símbolos.
-g
-S
-d
--strip-debug
Elimina solo los símbolos de depuración.
--strip-dwo
Elimina el contenido de todas las secciones DWARF .dwo, dejando las secciones de depuración restantes y todos los símbolos intactos. Vea la descripción de esta opción en la sección objcopy para más información.
--strip-unneeded
Elimina todos los símbolos que no son necesarios para el procesamiento de reubicación además de los símbolos y secciones de depuración eliminados por --strip-debug.
-K nombre_simbolo
--keep-symbol=nombre_simbolo
Al eliminar símbolos, conserva el símbolo nombre_simbolo incluso si normalmente sería eliminado. Esta opción se puede dar varias veces.
-M
--merge-notes
--no-merge-notes
Para archivos ELF, intenta (o no intenta) reducir el tamaño de cualquier sección de tipo SHT_NOTE eliminando notas duplicadas. Por defecto, se intenta esta reducción a menos que se esté eliminando información de depuración o DWO.
-N nombre_simbolo
--strip-symbol=nombre_simbolo
Elimina el símbolo nombre_simbolo del archivo de origen. Esta opción se puede dar varias veces y se puede combinar con opciones de strip diferentes de -K.
-o archivo
Coloca la salida eliminada en archivo, en lugar de reemplazar el archivo existente. Cuando se usa este argumento, solo se puede especificar un argumento archivo_objeto.
-p
--preserve-dates
Conserva las fechas de acceso y modificación del archivo.
-D
--enable-deterministic-archives
Opera en modo determinista. Al copiar miembros de archivo y escribir el índice de archivo, usa cero para UID, GID, marcas de tiempo y usa modos de archivo consistentes para todos los archivos.

Si binutils fue configurado con --enable-deterministic-archives, entonces este modo está activado por defecto. Se puede deshabilitar con la opción -U, abajo.

-U
--disable-deterministic-archives
No opera en modo determinista. Este es el comportamiento predeterminado a menos que se use la opción -D o si binutils se compiló con --enable-deterministic-archives.
--keep-section-symbols
En archivos ELF, no elimine los símbolos que apuntan a secciones que no se eliminan de otro modo. Por ejemplo, si se utiliza --strip-debug, los símbolos de depuración que apuntan a secciones de depuración no se eliminarán.
--keep-file-symbols
En archivos ELF, no elimine los símbolos de archivo. Por ejemplo, los símbolos como `__init_array_start' o `__init_array_end' no se eliminarán incluso si se utiliza --strip-all.
--only-keep-debug
Conserva solo la información de depuración. Todos los símbolos y secciones que no son de depuración se eliminarán. Esto es lo opuesto a --strip-debug. Tenga en cuenta que si el archivo de entrada ya ha sido procesado por strip con --strip-debug, entonces puede que no sea posible recuperar toda la información de depuración.
-v
--verbose
Muestra el nombre de cada archivo objeto a medida que se procesa.
-V
--version
Muestra la versión de strip y sale.
-x
--discard-all
Elimina todos los símbolos de depuración.
-X
--discard-locals
Elimina todos los símbolos locales de depuración (aquellos cuyos nombres comienzan con un carácter de subrayado y que son de alcance local).

NAME

strip — discard symbols from object files

SYNOPSIS

strip [-F <format>] [-I <format>] [-O <format>] [-R <section>] [-W <wrapper>] [-a] [-b <arg>] [-d <symbol>] [-g] [-h] [-j] [-k] [-N <symbol>] [-S] [-t] [-u] [-x] [-X] [--allow-empty] [--compress-debug-sections[=<compressor>]] [--debug-syms] [--discard-all] [--discard-groups] [--discard-locals] [--enable-deterministic-archives] [--glob-file=file] [--help] [--keep-file-symbols] [--keep-section-symbols] [--no-add-gnu-debuglink] [--no-strip-redirects] [--only-keep-debug] [--preserve-dates] [--remove-section=<section>] [--strip-debug] [--strip-dwo] [--strip-unneeded] [--wildcard] [-V] [--version] [-v] [--verbose] [-w] [-x] [-X] [--help] [--version] [--verbose] [ --help] [ --version] [-v] [ --verbose] [ --help] [ --version] [ -v] [ --verbose] [ -w] [ -x] [ -X] [ -a] [ -b <arg>] [ -d <symbol>] [ -g] [ -h] [ -j] [ -k] [ -N <symbol>] [ -S] [ -t] [ -u] [ -x] [ -X] [ --allow-empty] [ --compress-debug-sections[=<compressor>]] [ --debug-syms] [ --discard-all] [ --discard-groups] [ --discard-locals] [ --enable-deterministic-archives] [ --glob-file=file] [ --help] [ --keep-file-symbols] [ --keep-section-symbols] [ --no-add-gnu-debuglink] [ --no-strip-redirects] [ --only-keep-debug] [ --preserve-dates] [ --remove-section==<section>] [ --strip-debug] [ --strip-dwo] [ --strip-unneeded] [ --wildcard] [ -V] [ --version] [ -v] [ --verbose] [ -w] [ -x] [ -X] [ --help] [ --version] [ -v] [ --verbose] [ --help] [ --version] [ -v] [ --verbose] [ -w] [ -x] [ -X] [ archive(1) [archive...] [file...]

DESCRIPTION

The strip utility is used to reduce the size of object files and executable files by discarding symbols. It can also be used to reduce the size of an executable by removing sections containing debugging information.

The default behavior of strip is to remove all symbols from the files specified.

The options are as follows:

OPTIONS

-a
--keep-intermediate-objects
Do not discard intermediate objects.
-b arg
--strip-section=arg
Strip sections named arg. This option may be repeated to remove multiple sections.
-d
--strip-symbol=
Do not strip symbols named arg. This option may be repeated. When used with the --wildcard option, arg can be a regular expression.
--debug-syms
Retain all debugging symbols. Normally strip removes all symbols, including debugging symbols.
--discard-groups
Discard all symbols in section group.
--strip-debug
Remove debugging symbols and sections. This is equivalent to running strip with the -S option.
--strip-dwo
Remove DWO sections. These sections contain debugging information that has been separated out of the object file.
--strip-unneeded
Remove all symbols, except those that are needed for relocation processing. This is useful for reducing the size of executables.
--enable-deterministic-archives
When copying archive members and writing the archive index, use their actual UID, GID, timestamp, and file mode values. This is the inverse of the -D option, above: when copying archive members and writing the archive index, use their actual UID, GID, timestamp, and file mode values.

This is the default unless binutils was configured with --enable-deterministic-archives.

-w
--wildcard
Permit regular expressions in symbolnames used in other command line options. The question mark (?), asterisk (*), backslash (\) and square brackets ([]) operators can be used anywhere in the symbol name. If the first character of the symbol name is the exclamation point (!) then the sense of the switch is reversed for that symbol. For example: 
-w -K !foo -K fo*

would cause strip to only keep symbols that start with the letters "fo", but to discard the symbol "foo".

-x
--discard-all
Remove non-global symbols.
-X
--discard-locals
Remove compiler-generated local symbols. (These usually start with L or ..)
--keep-section-symbols
When stripping a file, perhaps with --strip-debug or --strip-unneeded, retain any symbols specifying section names, which would otherwise get stripped.
--keep-file-symbols
When stripping a file, perhaps with --strip-debug or --strip-unneeded, retain any symbols specifying source file names, which would otherwise get stripped.
--only-keep-debug
Strip a file, emptying the contents of any sections that would not be stripped by --strip-debug and leaving the debugging sections intact. In ELF files, this preserves all the note sections in the output as well.

Note - the section headers of the stripped sections are preserved, including their sizes, but the contents of the section are discarded. The section headers are preserved so that other tools can match up the debuginfo file with the real executable, even if that executable has been relocated to a different address space.

The intention is that this option will be used in conjunction with --add-gnu-debuglink to create a two part executable. One a stripped binary which will occupy less space in RAM and in a distribution and the second a debugging information file which is only needed if debugging abilities are required. The suggested procedure to create these files is as follows:

1.<Link the executable as normal. Assuming that it is called>
"foo" then...
1.<Run "objcopy --only-keep-debug foo foo.dbg" to>
create a file containing the debugging info.
1.<Run "objcopy --strip-debug foo" to create a>
stripped executable.
1.<Run "objcopy --add-gnu-debuglink=foo.dbg foo">
to add a link to the debugging info into the stripped executable.

Note---the choice of ".dbg" as an extension for the debug info file is arbitrary. Also the "--only-keep-debug" step is optional. You could instead do this:

1.<Link the executable as normal.>
1.<Copy "foo" to "foo.full">
1.<Run "strip --strip-debug foo">
1.<Run "objcopy --add-gnu-debuglink=foo.full foo">

i.e., the file pointed to by the --add-gnu-debuglink can be the full executable. It does not have to be a file created by the --only-keep-debug switch.

Note---this switch is only intended for use on fully linked files. It does not make sense to use it on object files where the debugging information may be incomplete. Besides the gnu_debuglink feature currently only supports the presence of one filename containing debugging information, not multiple filenames on a one-per-object-file basis.

-V
--version
Show the version number for strip.
-v
--verbose
Verbose output: list all object files modified. In the case of archives, strip -v lists all members of the archive.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
