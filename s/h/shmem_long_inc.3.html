shmem_long_inc(3)

SHMEM_LONG_INC(3) Open MPI SHMEM_LONG_INC(3)

shmem_int4_inc(3), shmem_int8_inc(3), shmem_int_inc(3), shmem_long_inc(3), shmem_longlong_inc(3) - Estas rutinas realizan una operación atómica de incremento en un objeto de datos remoto.

SINOPSIS

C o C++:

#include <mpp/shmem.h>
int shmem_int_inc(int *target, int pe)
long shmem_long_inc(long *target, int pe)
long long shmem_longlong_inc(long long *target, int pe)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER pe
INTEGER(KIND=4) SHMEM_INT4_INC, target4
INTEGER(KIND=8) SHMEM_INT8_INC, target8
ires4 = SHMEM_INT4_INC(target4, pe)
ires8 = SHMEM_INT8_INC(target8, pe)

DESCRIPCIÓN

Las rutinas de incremento atómico reemplazan el valor de target por su valor incrementado en uno. La operación debe completarse sin la posibilidad de que otro proceso actualice target entre el momento de la lectura y la actualización.

Los argumentos son los siguientes:

target
El objeto de datos entero accesible remotamente que se va a actualizar en el PE remoto. El tipo de target debe coincidir con el implícito en la sección SINOPSIS.
pe
Un entero que indica el número de PE en el que se debe actualizar target. Si estás usando Fortran, debe ser un valor entero por defecto.

NOTAS

El término accesible remotamente se define en intro_shmem(3).

VALORES DE RETORNO

Ninguno.
