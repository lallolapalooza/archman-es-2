ADDR2LINE(1) Herramientas de desarrollo GNU ADDR2LINE(1)

NOMBRE

addr2line - convierte direcciones o símbolo+desplazamiento en nombres de archivo y números de línea

SINOPSIS

addr2line [-a|--addresses]
[-b nombre_bfd|--target=nombre_bfd]
[-C|--demangle[=estilo]]
[-r|--no-recurse-limit]
[-R|--recurse-limit]
[-e nombre_archivo|--exe=nombre_archivo]
[-f|--functions] [-s|--basename]
[-i|--inlines]
[-p|--pretty-print]
[-j|--section=nombre]
[-H|--help] [-V|--version]
[dir dir ...]

DESCRIPCIÓN

addr2line traduce direcciones o símbolo+desplazamiento a nombres de archivo y números de línea. Dada una dirección o símbolo+desplazamiento en un ejecutable o un desplazamiento en una sección de un objeto relocable, utiliza la información de depuración para determinar qué nombre de archivo y número de línea están asociados con él.

El ejecutable o el objeto relocable a utilizar se especifica con la opción -e. El valor predeterminado es el archivo a.out. La sección en el objeto relocable a utilizar se especifica con la opción -j.

addr2line tiene dos modos de operación.

En el primero, se especifican direcciones hexadecimales o símbolo+desplazamiento en la línea de comandos, y addr2line muestra el nombre del archivo y el número de línea para cada dirección.

En el segundo, addr2line lee direcciones hexadecimales o símbolo+desplazamiento de la entrada estándar, y imprime el nombre del archivo y el número de línea para cada dirección en la salida estándar. En este modo, addr2line puede usarse en una tubería para convertir direcciones seleccionadas dinámicamente.

El formato de la salida es NOMBRE_ARCHIVO:NUMERO_LINEA. Por defecto, cada dirección de entrada genera una línea de salida.

Dos opciones pueden generar líneas adicionales antes de cada línea NOMBRE_ARCHIVO:NUMERO_LINEA (en ese orden).

Si se utiliza la opción -a, se mostrará una línea con la dirección de entrada.

Si se utiliza la opción -f, se mostrará una línea con el NOMBRE_FUNCION. Este es el nombre de la función que contiene la dirección.

Una opción puede generar líneas adicionales después de la línea NOMBRE_ARCHIVO:NUMERO_LINEA.

Si se utiliza la opción -i y el código en la dirección dada está presente debido a la inlining del compilador, se mostrarán líneas adicionales después. Se mostrarán una o dos líneas adicionales (si se usa la opción -f) para cada función inlined.

Alternativamente, si se utiliza la opción -p, cada dirección de entrada genera una única línea de salida larga que contiene la dirección, el nombre de la función, el nombre del archivo y el número de línea. Si también se ha utilizado la opción -i, las funciones inlined se mostrarán de la misma manera, pero en líneas separadas y prefijadas por el texto (inlined by).

Si el nombre del archivo o el nombre de la función no se pueden determinar, addr2line imprimirá dos signos de interrogación en su lugar. Si el número de línea no se puede determinar, addr2line imprimirá 0.

Cuando se usa símbolo+desplazamiento, +desplazamiento es opcional, excepto cuando el símbolo es ambiguo con un número hexadecimal. Los símbolos resueltos pueden ser "mangled" (codificados) o "unmangled" (no codificados), excepto que los símbolos "unmangled" con + no están permitidos.

OPCIONES

Las formas largas y cortas de las opciones, mostradas aquí como alternativas, son equivalentes.

-a
--addresses
Muestra la dirección antes del nombre de la función, el archivo y la información del número de línea. La dirección se imprime con un prefijo 0x para identificarla fácilmente.
-b nombre_bfd
--target=nombre_bfd
Especifica que el formato del código objeto para los archivos objeto es nombre_bfd.
-C
--demangle[=estilo]
Decodifica (demangle) los nombres de símbolos de bajo nivel en nombres de nivel de usuario. Además de eliminar cualquier guion bajo inicial agregado por el sistema, esto hace que los nombres de funciones C++ sean legibles. Diferentes compiladores tienen diferentes estilos de "mangling". El argumento opcional de estilo de "demangling" se puede usar para elegir un estilo de "demangling" apropiado para su compilador.
-e nombre_archivo
--exe=nombre_archivo
Especifica el nombre del ejecutable para el cual se traducirán las direcciones. El archivo predeterminado es a.out.
-f
--functions
Muestra los nombres de las funciones, así como la información del archivo y el número de línea.
-s
--basenames
Muestra solo la parte base de cada nombre de archivo.
-i
--inlines
Si la dirección pertenece a una función que fue inlined, también se imprimirá la información fuente de todos los ámbitos envolventes hasta la primera función no inlined. Por ejemplo, si "main" inlines "callee1" que inlines "callee2", y la dirección es de "callee2", también se imprimirá la información fuente de "callee1" y "main".
-j
--section
Lee los desplazamientos relativos a la sección especificada en lugar de direcciones absolutas.
-p
--pretty-print
Hace que la salida sea más amigable para el humano: cada ubicación se imprime en una línea. Si se especifica la opción -i, las líneas de todos los ámbitos envolventes se prefijan con (inlined by).
-r
-R
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al decodificar cadenas. Dado que los formatos de "mangling" de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote el espacio de pila disponible en la máquina host, provocando un fallo de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidación.

El valor predeterminado es que este límite esté habilitado, pero deshabilitarlo puede ser necesario para decodificar nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible el agotamiento de la pila y cualquier informe de error sobre tal evento será rechazado.

La opción -r es un sinónimo de la opción --no-recurse-limit. La opción -R es un sinónimo de la opción --recurse-limit.

Tenga en cuenta que esta opción solo es efectiva si se ha habilitado la opción -C o --demangle.

@archivo
Lee las opciones de la línea de comandos de archivo. Las opciones leídas se insertan en lugar de la opción @archivo original. Si archivo no existe o no se puede leer, entonces la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando toda la opción con comillas simples o dobles. Se puede incluir cualquier carácter (incluido una barra invertida) prefijando el carácter a incluir con una barra invertida. El archivo puede contener opciones adicionales @archivo; cualquier opción de este tipo se procesará.
