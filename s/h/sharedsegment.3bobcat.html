sharedsegment(3bobcat) Datos de memoria compartida FBB::SharedSegment(3bobcat)

NOMBRE

FBB::SharedSegment - Estructura de datos de memoria compartida

SINOPSIS

#include <bobcat/sharedsegment>
Opción de enlace: -lbobcat

DESCRIPCIÓN

La clase FBB::SharedSegment implementa la estructura de datos de memoria compartida utilizada por las clases de memoria compartida de Bobcat. La clase SharedMemory de Bobcat accede o define un segmento de memoria compartida, controlando todas sus operaciones de lectura y escritura.

La cantidad solicitada de memoria compartida es siempre un límite inferior a la cantidad máxima de memoria compartida que eventualmente puede estar disponible. Al definir un objeto SharedSegment, no toda su memoria compartida potencialmente disponible se asigna inmediatamente. La memoria compartida será asignada por el objeto SharedSegment una vez necesaria (hasta un máximo calculado).

Como ejemplo ficticio: supongamos que se solicitan 100 kB de memoria, entonces el objeto SharedSegment mantiene una tabla de, por ejemplo, 10 entradas, cada una controlando el acceso a un bloque de memoria compartida de 10 kB. Estos bloques de 10 kB no se asignan inmediatamente, sino que estarán disponibles una vez que el programa lea o escriba en direcciones ubicadas en estos segmentos de datos.

Por lo tanto, la clase SharedSegment define una puerta de enlace, controlando el acceso y asignando los segmentos de datos de memoria compartida requeridos. La tabla mencionada consta de nBlocks SharedBlock (sharedblock(3bobcat)) valores, ofreciendo mutex y IDs de segmentos de datos compartidos. Los mutex controlan qué proceso tiene acceso a un bloque particular de memoria de datos compartida, y los IDs son -1, lo que significa que sus segmentos de datos de memoria compartida aún no han sido asignados, o contienen los IDs de los segmentos de datos de memoria compartida definidos.

La única responsabilidad de la clase SharedSegment es ofrecer el marco descrito. Cuando es utilizado por un objeto FBB::SharedMemory, diferentes procesos pueden obtener acceso a diferentes partes de los datos de memoria compartida sin interferir con las acciones de lectura y escritura de otros.

CONSTRUCTORES

No se han definido constructores accesibles públicamente para SharedSegment. Hay disponible una función miembro estática create (ver más abajo) que devuelve un puntero a un segmento de memoria compartida, en el que se ha definido un SharedSegment.

OPERADORES SOBRECARGADOS

o
std::ostream &operator<<(std::ostream &out, SharedSegment const &sharedData):
El operador de inserción sobrecargado inserta estadísticas básicas de los datos de memoria compartida en el objeto ostream. Se muestra información sobre los IDs de los segmentos compartidos, sus tamaños, el número máximo de segmentos de datos compartidos y el número de bytes que se pueden leer de la memoria compartida.
o
FBB::SharedBlock &operator[](size_t idx):
Se devuelve el elemento de tabla idx de la tabla de IDs de bloques FBB::SharedBlock. El comportamiento del programa no está definido si idx es o excede nBlocks().
Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO

o
size_t access() const:
Devuelve los derechos de acceso del segmento de memoria compartida como un número que generalmente se interpreta como un valor octal, utilizando la forma conocida (chmod(1)) para definir los derechos de acceso para el propietario, grupo y otros.
o
void clear():
Todos los bloques de datos de memoria compartida se eliminan incondicionalmente y nReadable devuelve 0 (los bloques de datos de memoria compartida no se bloquean antes de eliminarlos). Después de llamar a clear, todos los segmentos de datos de memoria compartida asignados de SharedSegment han dejado de existir y ya no se pueden utilizar.
o
void lock(size_t idx) const:
Se bloquea el acceso al segmento de datos compartidos idx. Este miembro en sí mismo no admite el bloqueo recursivo.
o
size_t nBlocks() const:
Devuelve el número de bloques de datos de memoria compartida que pueden ser utilizados por el objeto FBB::SharedSegment.
o
int newData(size_t idx):
Devuelve el ID de un segmento de datos de memoria compartida recién creado. El ID también se almacena en la tabla de segmentos de datos de memoria compartida que mantiene el objeto SharedSegment.
Se lanza una FBB::Exception si no se pudo asignar el segmento de datos de memoria compartida.
o
std::streamsize nReadable() const:
Devuelve el número de caracteres (bytes) que se pueden leer desde el principio de la memoria compartida.
o
void nReadableLock() const:
Al regresar de esta función miembro, se ha obtenido un bloqueo del mutex de SharedSegment que controla el acceso al miembro de datos del objeto que almacena el número de caracteres que se pueden leer de la memoria compartida controlada por el objeto SharedSegment.
o
void nReadableUnlock() const:
Esta función miembro libera el bloqueo adquirido previamente por nReadableLock.
o
size_t segmentSize() const:
Devuelve el tamaño (en bytes) de los bloques de datos de memoria compartida. El objeto SharedSegment puede acomodar como máximo segmentSize() * nBlocks() bytes.
o
bool truncate(std::streamsize offset):
Después de llamar a nReadableLock, si offset no excede el valor devuelto por nReadable, nReadable se cambia a offset y se devuelve true. De lo contrario, se devuelve false y el valor devuelto por nReadable no ha cambiado. Antes de devolver, se llama a nReadableUnlock.
o
void unlock(size_t idx) const:
Libera el bloqueo en el segmento de datos de memoria compartida idx. Si el proceso actual no posee el bloqueo del bloque de datos de memoria compartida idx, no sucede nada y la función retorna inmediatamente.
o
void updateNreadable(std::streamsize offset):
El número de bytes que se pueden recuperar de la memoria compartida se actualiza a max(nReadable(), offset).

FUNCIONES MIEMBRO ESTÁTICAS

o
void *attach(int id):
Devuelve la dirección del segmento de memoria compartida id, mapeado al área de memoria del proceso que llama.
Se lanza una FBB::Exception si no se pudo adjuntar el segmento de datos de memoria compartida.
o
SharedSegment *create(int *id, size_t nBlocks, size_t segmentSize, size_t access):
Devuelve un puntero a un objeto SharedSegment recién creado, definido en la memoria compartida del ordenador.
El ID de la memoria compartida creada se almacena en *id. Los argumentos restantes definen el número potencial de bloques de datos de memoria compartida (nBlocks); el tamaño de estos bloques de datos (segmentSize); y los derechos de acceso de la memoria compartida (access, utilizando la representación de valor octal conocida como la usada por chmod(1)).
o
void detach(void *segment):
Desconecta el segmento de memoria compartida segment del área de memoria del proceso que llama.
o
void destroy(int id):
Elimina el segmento de memoria compartida con ID id.
o
int id(void *segment):
Devuelve el ID del segmento de memoria compartida apuntado por segment.

EJEMPLO

El siguiente fragmento de código define una memoria compartida con 10 bloques, cada uno de 100 bytes. También es la fuente de algunos variables de uso común:

  FBB::SharedSegment *segment = FBB::SharedSegment::create(
                                      &sharedId,
                                      10,
                                      100,
                                      0600);
  //...
  // sharedId contains the shared memory ID
  // segment points to the SharedSegment object

DESCRIPCIÓN

This class provides an interface to shared memory segments. Shared memory is a mechanism for inter-process communication (IPC), where the same memory region is mapped into the address space of multiple processes. This allows processes to communicate by reading and writing to that region. The sharedsegment class supports the creation, attachment, detachment, deletion and query of shared memory segments.

Access rights for shared memory segments can be defined using chmod(1) (to define access rights for the owner, the group and others).

To return the shared segment to the operating system deleteSegment should be used.

An FBB::Exception is thrown if the shared memory data segment could not be created.

o
static int createSegment(size_t size, const char *owner):
Creates a shared memory segment of the given size. The segment is created with read and write permissions for the user specified by owner. If owner is nullptr, the segment is created with read and write permissions for all users. The created segment is initialized to zero. Returns the ID of the created shared memory segment.
o
void deleteSegment(int id):
The shared memory segment having ID id is deleted. After calling deleteSegment shared memory segment id doesn’t exist anymore. The id can be the shared memory ID of any segment for which the current user has write permissions.
o
Type *detach(Type *sharedPtr, bool requireOK = true):
This member is defined as a member template. It expects a pointer to a shared memory segment, previously mapped on the calling process’s memory space by attach, and detaches it from the process’s memory space, returning 0.
o
size_t size(int id):
The size (in bytes) of shared memory data block having ID id is returned.

An FBB::Exception is thrown if shared memory data segment id could not be deleted.

By default, detaching the memory must succeed or an FBB::Exception is thrown. Throwing an exception on failure can be prevented by passing false as the member’s second argument.

Note that detaching a memory segment does not destroy it. To return a shared segment to the operating system deleteSegment should be used.

An FBB::Exception is thrown if the size of segment id could not be determined.
