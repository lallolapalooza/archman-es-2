DESCRIPCIÓN

Las rutinas de reducción de memoria compartida (SHMEM) calculan una o más reducciones en arrays simétricos en múltiples PEs virtuales. Una reducción realiza una operación binaria asociativa en un conjunto de valores. Para obtener una lista de otras rutinas de reducción de SHMEM, consulte intro_shmem(3).

Como con todas las rutinas colectivas de SHMEM, cada una de estas rutinas asume que solo los PEs del conjunto activo llaman a la rutina. Si un PE que no está en el conjunto activo llama a una rutina colectiva de SHMEM, el comportamiento no está definido.

El argumento nreduce determina el número de reducciones separadas a realizar. El array source en todos los PEs del conjunto activo proporciona un elemento para cada reducción. Los resultados de las reducciones se colocan en el array target en todos los PEs del conjunto activo. El conjunto activo se define por el triplete PE_start, logPE_stride, PE_size.

Los arrays source y target pueden ser el mismo array, pero no pueden ser arrays superpuestos.

Los argumentos son los siguientes:

objetivo
Un array simétrico de longitud nreduce elementos para recibir los resultados de las operaciones de reducción. El tipo de datos de objetivo varía con la versión de la rutina de reducción que se llama. Al llamar desde C, consulte la sección SINOPSIS para obtener información sobre el tipo de datos.

Al llamar desde Fortran, los tipos de datos de destino son los siguientes:

shmem_comp8_max_to_all: Complejo, con un tamaño de elemento igual a dos
Valores reales de 8 bytes.

shmem_int4_max_to_all: Entero, con un tamaño de elemento de 4 bytes.

shmem_int8_max_to_all: Entero, con un tamaño de elemento de 8 bytes.

shmem_real4_max_to_all: Real, con un tamaño de elemento de 4 bytes.

shmem_real16_max_to_all: Real, con un tamaño de elemento de 16 bytes.

fuente
Un array simétrico de longitud nreduce elementos que contiene un elemento para cada operación de reducción separada. El argumento fuente debe tener el mismo tipo de datos que objetivo.
nreduce
El número de elementos en los arrays objetivo y fuente. nreduce debe ser de tipo entero. Si está utilizando Fortran, debe ser un valor entero predeterminado.
PE_start
El número de PE virtual más bajo del conjunto activo de PEs. PE_start debe ser de tipo entero. Si está utilizando Fortran, debe ser un valor entero predeterminado.
logPE_stride
El logaritmo (base 2) del paso entre números de PE virtuales consecutivos en el conjunto activo. logPE_stride debe ser de tipo entero. Si está utilizando Fortran, debe ser un valor entero predeterminado.
PE_size
El número de PEs en el conjunto activo. PE_size debe ser de tipo entero. Si está utilizando Fortran, debe ser un valor entero predeterminado.
pWrk
Un array de trabajo simétrico. El argumento pWrk debe tener el mismo tipo de datos que objetivo. En C/C++, contiene max(nreduce/2 + 1, _SHMEM_REDUCE_MIN_WRKDATA_SIZE) elementos. En Fortran, contiene max(nreduce/2 + 1, SHMEM_REDUCE_MIN_WRKDATA_SIZE) elementos.
pSync
Un array de trabajo simétrico. En C/C++, pSync es de tipo long y tamaño _SHMEM_REDUCE_SYNC_SIZE. En Fortran, pSync es de tipo entero y tamaño SHMEM_REDUCE_SYNC_SIZE. Si está utilizando Fortran, debe ser un entero predeterminado. Cada elemento de este array debe inicializarse con el valor _SHMEM_SYNC_VALUE (en C/C++) o SHMEM_SYNC_VALUE (en Fortran) antes de que cualquiera de los PEs del conjunto activo ingrese a la rutina de reducción.

Los valores de los argumentos nreduce, PE_start, logPE_stride y PE_size deben ser iguales en todos los PEs del conjunto activo. Los mismos arrays objetivo y fuente, y los mismos arrays de trabajo pWrk y pSync, deben pasarse a todos los PEs del conjunto activo.

Antes de que cualquier PE llame a una rutina de reducción, debe asegurarse de que existen las siguientes condiciones (la sincronización mediante una barrera o algún otro método es a menudo necesaria para garantizar esto): Los arrays pWrk y pSync en todos los PEs del conjunto activo ya no están en uso de una llamada anterior a una rutina colectiva de SHMEM. El array objetivo en todos los PEs del conjunto activo está listo para aceptar los resultados de la reducción.

Al regresar de una rutina de reducción, lo siguiente es cierto para el PE local: El array objetivo se actualiza. Los valores en el array pSync se restauran a los valores originales.

NOTAS

Los términos colectivo, simétrico y alineado en caché se definen en intro_shmem(3). Todas las rutinas de reducción de SHMEM restablecen los valores en pSync antes de devolverlos, por lo que un buffer pSync particular solo necesita ser inicializado la primera vez que se utiliza.

Debe asegurarse de que el array pSync no esté siendo actualizado en ningún PE del conjunto activo mientras alguno de los PEs participa en el procesamiento de una rutina de reducción de SHMEM. Tenga cuidado con las siguientes situaciones: Si el array pSync se inicializa en tiempo de ejecución, se necesita algún tipo de sincronización para garantizar que todos los PEs del conjunto de trabajo hayan inicializado pSync antes de que cualquiera de ellos ingrese a una rutina de SHMEM llamada con el array de sincronización pSync. Un array pSync o pWrk se puede reutilizar en una llamada subsiguiente a la rutina de reducción solo si ninguno de los PEs del conjunto activo todavía está procesando una rutina de reducción anterior que utilizó los mismos arrays pSync o pWrk.

En general, esto solo se puede asegurar mediante algún tipo de sincronización. Sin embargo, en el caso especial de las rutinas de reducción que se llaman con el mismo conjunto activo, puede asignar dos arrays pSync y pWrk y alternar entre ellos en llamadas sucesivas

shmem_longdouble_max_to_all(3) — Open MPI — Arch Linux

NOMBRE

shmem_longdouble_max_to_all, shmem_longdouble_max_reduce, shmem_longdouble_max_all - encuentra el valor máximo de una variable de tipo long double en todos los PEs.

SINOPSIS

C++:
#include <mpi.h>
long double shmem_longdouble_max_to_all( long double value, int pe );
long double shmem_longdouble_max_reduce( long double value, int pe );
long double shmem_longdouble_max_all( long double value );

Fortran:
INCLUDE "mpp/shmem.fh"
REAL*8 shmem_longdouble_max_to_all( value, pe )
REAL*8 value
INTEGER pe
REAL*8 shmem_longdouble_max_reduce( value, pe )
REAL*8 value
INTEGER pe
REAL*8 shmem_longdouble_max_all( value )
REAL*8 value

DESCRIPCIÓN

Las rutinas shmem_longdouble_max_to_all, shmem_longdouble_max_reduce y shmem_longdouble_max_all calculan el valor máximo de la variable value entre todos los PEs (procesos). Cada PE inicia la llamada con su propio valor.

La rutina shmem_longdouble_max_to_all devuelve el valor máximo en el PE especificado por pe. Si pe es -1, el valor máximo se devuelve en todos los PEs.

La rutina shmem_longdouble_max_reduce devuelve el valor máximo en el PE de origen (PE 0).

La rutina shmem_longdouble_max_all devuelve el valor máximo en todos los PEs.

Las variables value y pe son las siguientes:

value
La variable de entrada cuyo valor máximo se va a calcular. El tipo de dato es REAL*8 en Fortran y long double en C/C++.
pe
El PE en el que se devolverá el valor máximo. Si pe es -1, el valor máximo se devolverá en todos los PEs. El tipo de dato es INTEGER en Fortran y int en C/C++.

La rutina shmem_longdouble_max_to_all, shmem_longdouble_max_reduce y shmem_longdouble_max_all son colectivas. Cada PE participa en la operación, y el valor de retorno se define según el tipo de operación (a todos, a uno o a todos los PEs).

Las rutinas shmem_longdouble_max_to_all, shmem_longdouble_max_reduce y shmem_longdouble_max_all utilizan una tabla de comunicación y un búfer de trabajo. Los arrays de sincronización y trabajo son necesarios para estas operaciones. La tabla de sincronización, PSYNC, es un array de enteros de tamaño SHMEM_REDUCE_SYNC_SIZE. El búfer de trabajo, PWRK, es un array de tipo REAL*8 de tamaño MAX(NR/2+1, SHMEM_REDUCE_MIN_WRKDATA_SIZE), donde NR es el número de elementos a procesar. Los arrays PSYNC y PWRK deben ser inicializados antes de llamar a las rutinas.

Para obtener más detalles sobre los arrays de sincronización y trabajo, consulta la documentación de la biblioteca Open SHMEM.

NOTAS

Las rutinas shmem_longdouble_max_to_all, shmem_longdouble_max_reduce y shmem_longdouble_max_all son implícitamente colectivas y deben ser llamadas por todos los PEs del grupo.

El comportamiento de estas rutinas puede variar ligeramente dependiendo de la implementación de Open SHMEM.

Para un uso más eficiente de estas rutinas, considera agrupar múltiples llamadas si es posible y utiliza los arrays PWRK y PSYNC de forma adecuada.

EJEMPLOS

Ejemplo 1: Este ejemplo en Fortran inicializa estáticamente el array pSync y encuentra el valor máximo de la variable FOO de tipo REAL*8 en todos los PEs pares.

INCLUDE "mpp/shmem.fh"
INTEGER PSYNC(SHMEM_REDUCE_SYNC_SIZE)
DATA PSYNC /SHMEM_REDUCE_SYNC_SIZE*SHMEM_SYNC_VALUE/
PARAMETER (NR=1)
REAL*8 FOO, FOOMAX, PWRK(MAX(NR/2+1,SHMEM_REDUCE_MIN_WRKDATA_SIZE))
COMMON /COM/ FOO, FOOMAX, PWRK
INTRINSIC MY_PE
IF ( MOD(MY_PE(),2) .EQ. 0) THEN
  CALL SHMEM_LONGDOUBLE_MAX_TO_ALL(FOOMAX, FOO, NR, 0, 1, N$PES/2,
  & PWRK, PSYNC)
  PRINT *, 'Result on PE ', MY_PE(), ' is ', FOOMAX
ENDIF

Ejemplo 2: Considera la siguiente llamada en C/C++:

shmem_longdouble_max_to_all( target, source, 3, 0, 0, 8, pwrk, psync );

La llamada anterior es más eficiente, pero semánticamente equivalente a, la combinación de las siguientes llamadas:

shmem_longdouble_max_to_all(&(target[0]), &(source[0]), 1, 0, 0, 8,
  pwrk1, psync1);
shmem_longdouble_max_to_all(&(target[1]), &(source[1]), 1, 0, 0, 8,
  pwrk2, psync2);
shmem_longdouble_max_to_all(&(target[2]), &(source[2]), 1, 0, 0, 8,
  pwrk1, psync1);

Ten en cuenta que se utilizan dos conjuntos de arrays pWrk y pSync alternativamente porque no se realiza ninguna sincronización entre llamadas.
