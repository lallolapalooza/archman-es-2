shmem_short_and_to_all(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_SHORT_AND_TO_ALL(3) Open MPI SHMEM_SHORT_AND_TO_ALL(3)

shmem_int_and_to_all(3), shmem_int4_and_to_all(3), shmem_int8_and_to_all(3), shmem_long_and_to_all(3), shmem_longlong_and_to_all(3), shmem_short_and_to_all(3) - Realiza una operación AND a nivel de bits en arrays simétricos sobre el conjunto activo de PEs.

RESUMEN

C o C++:

#include <mpp/shmem.h>
void shmem_int_and_to_all(int *target, const int *source,
  int nreduce, int PE_start, int logPE_stride, int PE_size,
  int *pWrk, long *pSync)
void shmem_long_and_to_all(long *target, const long *source,
  int nreduce, int PE_start, int  logPE_stride, int PE_size,
  long *pWrk, long *pSync)
void shmem_longlong_and_to_all(long long *target,
  const long long *source, int nreduce, int PE_start, int logPE_stride,
  int PE_size, long long *pWrk, long *pSync)
void shmem_short_and_to_all(short *target, const short *source,
  int nreduce, int PE_start, int logPE_stride, int PE_size,
  short *pWrk, long *pSync)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER pSync(SHMEM_REDUCE_SYNC_SIZE)
INTEGER nreduce, PE_start, logPE_stride, PE_size
CALL SHMEM_INT4_AND_TO_ALL(target, source, nreduce,
& PE_start, logPE_stride, PE_size, pWrk, pSync)
CALL SHMEM_INT8_AND_TO_ALL(target, source, nreduce,
& PE_start, logPE_stride, PE_size, pWrk, pSync)

DESCRIPCIÓN

Las rutinas de reducción de memoria compartida (SHMEM) calculan una o más reducciones en arrays simétricos en múltiples PEs virtuales. Una reducción realiza una operación binaria asociativa en un conjunto de valores. Para obtener una lista de otras rutinas de reducción SHMEM, consulte intro_shmem(3).

El argumento nreduce determina el número de reducciones separadas a realizar. El array de origen en todos los PEs del conjunto activo proporciona un elemento para cada reducción. Los resultados de las reducciones se colocan en el array de destino en todos los PEs del conjunto activo. El conjunto activo se define por el triplet PE_start, logPE_stride, PE_size.

Los arrays de origen y destino pueden ser el mismo array, pero no pueden ser arrays superpuestos. Al igual que con todas las rutinas colectivas SHMEM, cada una de estas rutinas asume que solo los PEs del conjunto activo llaman a la rutina. Si un PE que no está en el conjunto activo llama a una rutina colectiva SHMEM, el comportamiento no está definido.

Los argumentos son los siguientes:

target
Un array simétrico, de longitud nreduce elementos, para recibir el resultado de las operaciones de reducción. El tipo de datos de target varía con la versión de la rutina de reducción que se llama. Al llamar desde C/C++, consulte la sección RESUMEN para obtener información sobre el tipo de datos. Al llamar desde Fortran, los tipos de datos de destino son los siguientes:

shmem_int8_and_to_all: Entero, con un tamaño de elemento de 8 bytes

shmem_int4_and_to_all: Entero, con un tamaño de elemento de 4 bytes

source
Un array simétrico, de longitud nreduce elementos, que contiene un elemento por cada operación de reducción separada. El argumento source debe tener el mismo tipo de datos que target.
nreduce
El número de elementos en los arrays target y source. nreduce debe ser de tipo entero. Si utiliza Fortran, debe ser un valor entero predeterminado.
PE_start
El número PE virtual más bajo del conjunto activo de PEs. PE_start debe ser de tipo entero. Si utiliza Fortran, debe ser un valor entero predeterminado.
logPE_stride
El logaritmo (base 2) del paso entre los números PE virtuales consecutivos en el conjunto activo. logPE_stride debe ser de tipo entero. Si utiliza Fortran, debe ser un valor entero predeterminado.
PE_size
El número de PEs en el conjunto activo. PE_size debe ser de tipo entero. Si utiliza Fortran, debe ser un valor entero predeterminado.
pWrk
Un array de trabajo simétrico. El argumento pWrk debe tener el mismo tipo de datos que target. En C/C++, contiene max(nreduce/2 + 1, _SHMEM_REDUCE_MIN_WRKDATA_SIZE) elementos. En Fortran, contiene max(nreduce/2 + 1, SHMEM_REDUCE_MIN_WRKDATA_SIZE) elementos.
pSync
Un array de trabajo simétrico. En C/C++, pSync debe ser de tipo long y tamaño _SHMEM_REDUCE_SYNC_SIZE. En Fortran, pSync debe ser de tipo entero y tamaño SHMEM_REDUCE_SYNC_SIZE. Si utiliza Fortran, debe ser un valor entero predeterminado. Cada elemento de este array debe inicializarse con el valor _SHMEM_SYNC_VALUE (en C/C++) o SHMEM_SYNC_VALUE (en Fortran) antes de que cualquiera de los PEs del conjunto activo entre en la rutina de reducción.

Los valores de los argumentos nreduce, PE_start, logPE_stride y PE_size deben ser iguales en todos los PEs del conjunto activo. Los mismos arrays target y source, y los mismos arrays de trabajo pWrk y pSync, deben pasarse a todos los PEs del conjunto activo.

Antes de que un PE llame a una rutina de reducción, debe asegurarse de que se cumplan las siguientes condiciones (a menudo se necesita sincronización mediante una barrera u otro método para garantizar esto): Los arrays pWrk y pSync en todos los PEs del conjunto activo ya no están en uso desde una llamada anterior a una rutina colectiva SHMEM. El array target en todos los PEs del conjunto activo está listo para aceptar los resultados de la reducción.

Al regresar de una rutina de reducción, se cumplen las siguientes condiciones para el PE local: El array target se actualiza. Los valores en el array pSync se restauran a los valores originales.

NOTAS

Los términos colectivo, simétrico y alineado en caché se definen en intro_shmem(3). Todas las rutinas de reducción SHMEM restablecen los valores en pSync antes de devolverlos, por lo que un buffer pSync particular solo necesita inicializarse la primera vez que se utiliza.

Debe asegurarse de que el array pSync no esté siendo actualizado en ningún PE del conjunto activo mientras alguno de los PEs participa en el procesamiento de una rutina de reducción SHMEM. Tenga cuidado de evitar las siguientes situaciones: Si el array pSync se inicializa en tiempo de ejecución, se necesita algún tipo de sincronización para garantizar que todos los PEs del conjunto de trabajo hayan inicializado pSync antes de que alguno de ellos entre en una rutina SHMEM llamada con el array de sincronización pSync. Un array pSync o pWrk se puede reutilizar en una llamada de rutina de reducción posterior solo si ninguno de los PEs del conjunto activo todavía está procesando una llamada de rutina de reducción anterior que utilizó los mismos arrays pSync o pWrk. En general, esto solo se puede garantizar mediante algún tipo de sincronización. Sin embargo, en el caso especial de las rutinas de reducción que se llaman con el mismo conjunto activo, puede asignar dos arrays pSync y pWrk y alternar entre ellos en llamadas sucesivas.

EJEMPLOS

Ejemplo 1: Este ejemplo de Fortran inicializa estáticamente el array pSync y calcula el AND lógico de la variable entera FOO en todos los PEs pares.

INCLUDE "mpp/shmem.fh"
INTEGER PSYNC(SHMEM_REDUCE_SYNC_SIZE)
DATA PSYNC /SHMEM_REDUCE_SYNC_SIZE*SHMEM_SYNC_VALUE/
PARAMETER (NR=1)
REAL PWRK(MAX(NR/2+1, SHMEM_REDUCE_MIN_WRKDATA_SIZE))
INTEGER FOO, FOOAND
COMMON /COM/ FOO, FOOAND, PWRK
INTRINSIC MY_PE
IF ( MOD(MY_PE(),2) .EQ. 0) THEN
  CALL SHMEM_INT8_AND_TO_ALL(FOOAND, FOO, NR, 0, 1, N$PES/2,
  & PWRK, PSYNC)
  PRINT *, 'Result on PE ', MY_PE(), ' is ', FOOAND
ENDIF

Ejemplo 2: Considere la siguiente llamada a C:

shmem_int_and_to_all( target, source, 3, 0, 0, 8, pwrk, psync );

La llamada anterior es más eficiente, pero semánticamente equivalente, a la combinación de las siguientes llamadas:

shmem_int_and_to_all(&(target[0]), &(source[0]), 1, 0, 0, 8,
  pwrk1, psync1);
shmem_int_and_to_all(&(target[1]), &(source[1]), 1, 0, 0, 8,
  pwrk2, psync2);
shmem_int_and_to_all(&(target[2]), &(source[2]), 1, 0, 0, 8,
  pwrk1, psync1);

Tenga en cuenta que se utilizan dos conjuntos de arrays pWrk y pSync alternativamente porque no se realiza ninguna sincronización entre llamadas.
