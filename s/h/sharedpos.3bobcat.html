FBB::Sharedpos(3bobcat) Desplazamientos de memoria compartida FBB::Sharedpos(3bobcat)

NOMBRE

FBB::Sharedpos - Controlador de desplazamiento de memoria compartida

SINOPSIS

#include <bobcat/sharedpos>
Opción de enlace: -lbobcat

DESCRIPCIÓN

La clase SharedPos es una clase de soporte para las clases de manejo de memoria compartida de Bobcat. Controla el desplazamiento de lectura/escritura de la memoria compartida y asegura que las operaciones de memoria compartida nunca excedan el desplazamiento máximo de la memoria compartida.

La clase SharedPos tiene varios miembros públicos, pero son principalmente útiles para otras clases Shared* ofrecidas por Bobcat. Probablemente haya poco uso para un objeto SharedPos independiente.

En las descripciones de las funciones miembro de la clase, offset se refiere al desplazamiento de lectura/escritura dentro de un objeto FBB::SharedSegment(3bobcat) para el cual SharedPos realiza la administración del desplazamiento.

TIPOS Y ENUMERACIONES

CONSTRUCTORES

Se encuentran disponibles constructores por defecto, de copia y de movimiento, así como los operadores de asignación de copia y de movimiento. El constructor por defecto aún no monitoriza el desplazamiento de un objeto FBB::SharedSegment. El miembro reset se utiliza para comenzar a monitorizar los desplazamientos.

OPERADORES SOBRECARGADOS

o
void operator++():
El desplazamiento se incrementa. Si este miembro se llama cuando el desplazamiento es igual al desplazamiento máximo de la memoria compartida, se lanza una FBB::Exception.
o
void operator+=(size_t len):
El desplazamiento se incrementa en len. Si offset + len excede el desplazamiento máximo de la memoria compartida, entonces el desplazamiento se establece al desplazamiento máximo y se lanza una FBB::Exception.
o
std::ostream &operator<<(std::ostream &out, SharedPos const &pos):
Inserta información sobre el objeto SharedPos en out.

FUNCIONES MIEMBRO

Nota: el comportamiento de las funciones miembro que devuelven valores que se refieren a información de un FBB::SharedSegment no está definido hasta que se haya llamado al miembro reset.

o
bool atMaxOffset() const:
Devuelve true si el desplazamiento es igual al desplazamiento máximo que se puede utilizar para el objeto FBB::SharedSegment configurado.
o
size_t blockIdx() const:
Se devuelve el índice del bloque de datos del segmento compartido del objeto FBB::SharedSegment configurado al que se refiere el desplazamiento.
o
size_t blockOffset() const:
Se devuelve el desplazamiento dentro del bloque de datos del segmento compartido que coincide con el valor de retorno del miembro offset.
o
bool eof() const:
Devuelve true si el desplazamiento excede el desplazamiento máximo de cualquier carácter escrito en la memoria compartida a la que interactúa el objeto SharedPos. Si eof devuelve true, todavía se puede *escribir* información en la memoria compartida: la escritura es posible hasta que se alcance el desplazamiento máximo del segmento de memoria compartida.
o
std::streamsize eos() const:
Se devuelve el desplazamiento justo después del desplazamiento máximo para el bloque de datos del segmento compartido actual. Por ejemplo, si blockIdx devuelve 5 y el tamaño de los bloques de datos del segmento compartido es 2000, entonces eos devuelve 12000 (el primer desplazamiento del segmento 6).
o
std::streamsize maxOffset() const:
Se devuelve el desplazamiento máximo posible que se puede utilizar para el FBB::SharedSegment actualmente monitorizado.
o
std::streamsize offset() const:
Se devuelve el desplazamiento dentro del segmento de memoria compartida actualmente monitorizado.
o
void reset(SharedSegment *sharedData):
El objeto SharedPos se reinicia para monitorizar el desplazamiento del objeto FBB::SharedSegment cuya dirección se pasa como argumento a reset. La dirección debe apuntar a un objeto sharedsegment(3bobcat) que debe existir hasta el final de la vida del objeto SharedPos o hasta su próxima llamada a reset. Inmediatamente después de llamar a reset, el desplazamiento se restablece a 0.
o
std::streamsize showmanyc() const:
Se devuelve el número de caracteres que se pueden leer del bloque de datos del segmento compartido actual. Este miembro interroga el número de caracteres legibles en el segmento de memoria compartida. Este número puede cambiar mientras se ejecuta este miembro. Para recibir un valor de retorno estable, las funciones que llaman deben haber obtenido un bloqueo en los datos de FBB::SharedSegment antes de llamar a este miembro. Véase también la página del manual de sharedsegment(3bobcat).
o
std::ios::pos_type seek(std::ios::off_type offset, std::ios::seekdir origin = std::ios::beg):
El desplazamiento monitorizado se cambia al argumento offset de este miembro, relativo a origin. Buscar más allá de eof está bien. Sin embargo, se devuelve -1 al buscar más allá de maxOffset o al buscar antes del desplazamiento 0 del segmento compartido.
