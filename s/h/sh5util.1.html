sh5util(1) Comandos de Slurm sh5util(1)

NOMBRE

sh5util - Herramienta para fusionar archivos HDF5 del plugin acct_gather_profile que recopila datos detallados para trabajos ejecutados bajo Slurm

SINOPSIS

sh5util

DESCRIPCIÓN

sh5util fusiona los archivos HDF5 producidos en cada nodo para cada paso de un trabajo en un único archivo HDF5 para el trabajo. El archivo resultante puede ser visualizado y manipulado por herramientas comunes de HDF5 como HDF5View, h5dump, h5edit o h5ls.

sh5util también tiene dos modos de extracción. El primero, escribe un conjunto limitado de datos para nodos, pasos y series de datos específicos en formato de "valores separados por comas" a un archivo que puede ser importado en otras herramientas de análisis como hojas de cálculo.

El segundo, (Extracción de Ítem) extrae un ítem de datos de una serie de tiempo para todas las muestras en todos los nodos de un perfil HDF5 de un trabajo.

- Encuentra la muestra con el valor máximo del ítem.

- Escribe un archivo CSV con los totales de mínimos, promedio, máximos e ítems por cada nodo para cada muestra

OPCIONES

-E, --extract

Extrae series de datos de un archivo de trabajo fusionado.

Opciones del modo de extracción
-i, --input=ruta
archivo fusionado del cual extraer (por defecto ./job_$jobid.h5)
-N, --node=nombrenodo
Nombre del nodo a extraer (por defecto es todos)
-l, --level=[Node:Totals | Node:TimeSeries]
Nivel al que se adjunta la serie. (por defecto Node:Totals)
-s, --series=[Energy | Filesystem | Network | Task | Task_#]
Task son todas las tareas, Task_# (# es un id de tarea) (por defecto es todo)
-h, --help
Imprime esta descripción de uso.
-I, --item-extract

Extrae un ítem de datos de todas las muestras de una serie de datos de todos los nodos en un archivo de trabajo fusionado.

Opciones del modo Extracción de Ítem
-s, --series=[Energy | Filesystem | Network | Task]
-d, --data
Nombre del ítem de datos en la serie (Ver nota abajo).
-j, --jobs=<trabajo[.paso]>
El formato es <trabajo[.paso]>. Fusiona este trabajo/paso (o una lista separada por comas de pasos de trabajo). Esta opción es obligatoria. No especificar un paso resultará en el procesamiento de todos los pasos encontrados.
-L, --list

Imprime los ítems de una serie contenidos en un archivo de trabajo.

Opciones del modo Lista
-i, --input=ruta
Archivo fusionado del cual extraer (por defecto ./job_$jobid.h5)
-s, --series=[Energy | Filesystem | Network | Task]
-o, --output=<ruta>
Ruta a un archivo en el cual escribir. Por defecto para la fusión es ./job_$jobid.h5. Por defecto para la extracción es ./extract_$jobid.csv
-p, --profiledir=<dir>
Directorio donde se encuentran los archivos de nodo-paso, por defecto se establece en acct_gather.conf.
-S, --savefiles
En lugar de eliminar los archivos de nodo-paso después de fusionarlos en el archivo del trabajo, mantenerlos.
--usage
Muestra un breve mensaje de uso.
--user=<usuario>
Usuario que perfiló el trabajo. (Útil para el usuario root, por defecto es el usuario que ejecuta este comando.)

RENDIMIENTO

La ejecución de sh5util envía una llamada de procedimiento remoto a slurmctld. Si llegan demasiadas llamadas de sh5util u otros comandos cliente de Slurm que envían llamadas de procedimiento remoto a slurmctld al mismo tiempo, puede resultar en una degradación del rendimiento del demonio slurmctld, posiblemente resultando en una denegación de servicio.

No ejecute sh5util u otros comandos cliente de Slurm que envíen llamadas de procedimiento remoto a slurmctld desde bucles en scripts de shell u otros programas. Asegúrese de que los programas limiten las llamadas a sh5util al mínimo necesario para la información que intenta recopilar.

EJEMPLOS

Fusionar archivos de nodo-paso (como parte de un script sbatch):
$ sbatch -n1 -d$SLURM_JOB_ID --wrap="sh5util --savefiles -j $SLURM_JOB_ID"
Extraer todos los datos de tareas de un nodo:
$ sh5util -j 42 -N snowflake01 --level=Node:TimeSeries --series=Tasks
Extraer todos los datos de energía:
$ sh5util -j 42 --series=Energy --data=power
