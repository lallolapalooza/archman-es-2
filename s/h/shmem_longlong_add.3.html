shmem_longlong_add(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_LONGLONG_ADD(3) Open MPI SHMEM_LONGLONG_ADD(3)

shmem_int_add(3), shmem_int4_add(3), shmem_int8_add(3), shmem_long_add(3), shmem_longlong_add(3) - Realiza una operación de suma atómica.

SINOPSIS

C o C++:

#include <mpp/shmem.h>
void shmem_int_add(int *target, int value, int pe)
void shmem_long_add(long *target, long value, int pe)
void shmem_longlong_add(long long *target, long long value,
  int pe)

Fortran:

include 'mpp/shmem.h'
INTEGER pe
CALL SHMEM_INT4_ADD(target, value, pe)
CALL SHMEM_INT8_ADD(target, value, pe)

DESCRIPCIÓN

Las rutinas de suma atómica suman value a los datos en la dirección target en el PE pe. La operación se completa sin la posibilidad de que otro proceso actualice target entre el momento de la lectura y la actualización.

Los argumentos son los siguientes:

target
El objeto de datos entero accesible remotamente que se actualizará en el PE remoto. Si está utilizando C/C++, el tipo de target debe coincidir con el implícito en la sección SINOPSIS. Si está utilizando el compilador Fortran, debe ser de tipo entero con un tamaño de elemento de 4 bytes para SHMEM_INT4_ADD y de 8 bytes para SHMEM_INT8_ADD.
value
El valor que se sumará atómicamente a target. Si está utilizando C/C++, el tipo de value debe coincidir con el implícito en la sección SINOPSIS. Si está utilizando Fortran, debe ser de tipo entero con un tamaño de elemento igual al de target.
pe
Un entero que indica el número de PE sobre el cual se actualizará target. Si está utilizando Fortran, debe ser un valor entero predeterminado.

NOTAS

El término accesible remotamente se define en intro_shmem(3).
