shmem_malloc(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_MALLOC(3) Open MPI SHMEM_MALLOC(3)

shmem_malloc(3), shmem_free(3), shmem_align(3), shmem_realloc(3) shmalloc(3), shfree(3), shmemalign(3), shrealloc(3) - Funciones de gestión de memoria del montón simétrico.

SINOPSIS

C o C++:

#include <mpp/shmem.h>
void *shmem_malloc(size_t size)
void *shmalloc(size_t size)
void shmem_free(void *ptr)
void shfree(void *ptr)
void *shmem_realloc(void *ptr, size_t size)
void *shrealloc(void *ptr, size_t size)
void *shmem_align(size_t alignment, size_t size)
void *shmemalign(size_t alignment, size_t size)
extern long malloc_error

DESCRIPCIÓN

La función shmem_malloc devuelve un puntero a un bloque de al menos size bytes, convenientemente alineado para cualquier uso. Este espacio se asigna desde el montón simétrico (en contraste con malloc(3), que asigna desde el montón privado).

La función shmem_align asigna un bloque en el montón simétrico que tiene una alineación de bytes especificada por el argumento alignment.

La función shmem_free provoca que el bloque al que apunta ptr sea desasignado, es decir, que quede disponible para futuras asignaciones. Si ptr es un puntero nulo, no se realiza ninguna acción; de lo contrario, si el argumento no coincide con un puntero devuelto anteriormente por una función del montón simétrico, o si el espacio ya ha sido desasignado, se establece malloc_error para indicar el error, y shfree regresa.

La función shmem_realloc cambia el tamaño del bloque al que apunta ptr al tamaño (en bytes) especificado por size.

El contenido del bloque no se modifica hasta el menor de los tamaños nuevo y antiguo. Si el nuevo tamaño es mayor, el valor de la porción recién asignada del bloque es indeterminado. Si ptr es un puntero nulo, la función shrealloc se comporta como la función shmalloc para el tamaño especificado. Si size es 0 y ptr no es un puntero nulo, el bloque al que apunta se libera. De lo contrario, si ptr no coincide con un puntero devuelto anteriormente por una función del montón simétrico, o si el espacio ya ha sido desasignado, la variable malloc_error se establece para indicar el error, y shrealloc devuelve un puntero nulo. Si el espacio no se puede asignar, el bloque al que apunta ptr no se modifica.

Las funciones shmem_malloc, shmem_free y shmem_realloc se proporcionan para que múltiples PEs en una aplicación puedan asignar bloques de memoria simétricos y remotamente accesibles. Estos bloques de memoria se pueden utilizar luego con rutinas de comunicación (shmem). Cada una de estas funciones llama a la función shmem_barrier_all(3) antes de regresar; esto asegura que todos los PEs participen en la asignación de memoria, y que la memoria en otros PEs pueda ser utilizada tan pronto como el PE local regrese.

El usuario es responsable de llamar a estas funciones con argumentos idénticos en todos los PEs; si se utilizan argumentos de tamaño diferentes, las llamadas posteriores pueden no devolver la misma dirección de montón simétrico en todos los PEs.

NOTAS

El tamaño total del montón simétrico se determina al inicio del trabajo. Se puede ajustar el tamaño del montón utilizando la variable de entorno SHMEM_SYMMETRIC_HEAP_SIZE. Consulte la página del manual intro_shmem(3) para obtener más detalles. Las funciones shmem_malloc, shmem_free y shmem_realloc difieren de las funciones de asignación del montón privado en que todos los PEs de una aplicación deben llamarlas (se usa una barrera para asegurar esto).

VALORES DE RETORNO

La función shmem_malloc devuelve un puntero al espacio asignado (que debería ser idéntico en todos los PEs); de lo contrario, devuelve un puntero nulo (con malloc_error establecido). La función shmem_free no devuelve ningún valor. La función shmem_realloc devuelve un puntero al espacio asignado (que puede haberse movido); de lo contrario, devuelve un puntero nulo (con malloc_error establecido).
