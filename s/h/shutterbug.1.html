SHUTTERBUG(1) Manual de Comandos Generales SHUTTERBUG(1)

NOMBRE

shutterbug - aplicación de instantáneas de pantalla

SINOPSIS

shutterbug

DESCRIPCIÓN

Shutterbug es una aplicación simple de instantáneas de pantalla inspirada en SGI Snapshot.

La interfaz de usuario de Shutterbug consiste en un único icono discreto. Todas las funciones de Shutterbug se invocan haciendo clic derecho en este icono, lo que abrirá un menú emergente. Un rectángulo rojo identifica el área de la pantalla que se está capturando.

IDENTIFICACIÓN DEL ÁREA DE PANTALLA

El área de captura de pantalla se identifica mediante un rectángulo rojo. El área de captura se puede mover arrastrando con el ratón derecho, o manteniendo presionada la tecla shift o control durante el arrastre con el ratón izquierdo. El tamaño del rectángulo se puede cambiar arrastrando uno de los cuatro lados o las esquinas.

El área de captura también se puede configurar a un tamaño predefinido y fijo. En ese caso, el rectángulo no se puede redimensionar, solo arrastrar a una posición específica.

INVOCACIÓN DE COMANDOS

Para invocar el menú, haga clic derecho en el icono de la aplicación Shutterbug.

Capturar
Este comando captura una instantánea de pantalla y abre el panel de archivos para guardar la imagen.
Mostrar Lazo
Este comando oculta el lazo rojo que identifica el área de captura.
Tamaño
Abre un submenú con varios tamaños de área de captura predefinidos. Seleccionar Personalizado permitirá la selección arbitraria del área de captura.
Grosor
Este submenú se puede utilizar para cambiar el ancho de línea del rectángulo del lazo del área de captura.
Líneas dentro
Hace que las líneas estén dentro, en lugar de fuera del rectángulo del área de captura. Esto puede ser más preciso para imágenes pequeñas.
Color
Abre el Diálogo de Color para cambiar el color del rectángulo del lazo. El color predeterminado es rojo.
Acerca de
Abre el Diálogo Acerca de, que proporciona el número de versión y otra información sobre Shutterbug.
Salir
Termina el programa.

FORMATOS DE IMAGEN SOPORTADOS

Shutterbug soporta los siguientes formatos de imagen:

GIF CompuServe Graphics Interchange Format, versión 89a.

BMP Microsoft Bitmap Format.

XPM X Pixmap Format.

XBM X Bitmap Format (blanco y negro).

PCX PC PaintBrush format.

TGA Targa Image format.

PPM Portable Pixmap Format.

PNG Portable Network Graphics Format (si está compilado).

JPG Joint Photographics Experts Group JPEG Format (si está compilado).

TIFF Tagged Image File Format (si está compilado).

Formato de Imagen Raster de SUN.

PostScript Adobe PostScript format.
