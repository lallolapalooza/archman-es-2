NOMBRE

shotwell - Gestor de fotos digitales

SINOPSIS

shotwell [OPCIÓN]... [ARCHIVO]

DESCRIPCIÓN

Shotwell es un organizador de fotos digitales diseñado para el entorno de escritorio GNOME. Permite importar fotos desde el disco o cámara, organizarlas de diversas maneras, verlas en modo de pantalla completa o ventana, y exportarlas para compartir con otros.

OPCIONES

-h, --help Muestra las opciones de ayuda

-d, --datadir=CARPETA

Ruta a los datos privados de Shotwell. Usar -d independiente sin --profile --create se considera obsoleto y no debe usarse más.

--no-runtime-monitoring

No monitorizar la carpeta de la biblioteca en tiempo de ejecución para detectar cambios

-f, --fullscreen

Abrir el modo de visualización en pantalla completa. No tiene efecto en modo biblioteca.

--no-startup-progress

No mostrar el medidor de progreso de inicio

-V, --version

Mostrar la versión de la aplicación

--display=DISPLAY

Pantalla X a utilizar

-p, --show-metadata

Volcar todos los metadatos Exif, IPTC y XMP del ARCHIVO

-i, --profile=PERFIL

Iniciar shotwell con un perfil diferente. Un perfil consiste en un conjunto de configuraciones y un nuevo directorio de datos privados. El directorio de datos puede ser sobrescrito especificando también --datadir.

-l, --list-profiles

Mostrar los perfiles disponibles

-b, --profile-browser

Mostrar los perfiles disponibles en un diálogo, con capacidades de gestión y la posibilidad de iniciar Shotwell con un perfil específico haciendo doble clic.

EJEMPLOS

shotwell

Abre Shotwell con la biblioteca del usuario.

shotwell ARCHIVO

Abre un archivo de imagen para edición directa. El archivo no se importa a la biblioteca y los cambios no guardados se pierden al cerrar.

shotwell --profile="Entorno de desarrollo"

Abre shotwell usando el perfil llamado "Entorno de desarrollo".
