oshcc, oshcxx, oshc++, oshfort, shmemcc, shmemcxx, shmemc++, shmemfort — Compiladores de envoltura de OpenSHMEM

SINTAXIS

oshcc [--showme | --showme:compile | --showme:link] ...

oshcxx [--showme | --showme:compile | --showme:link] ...

oshc++ [--showme | --showme:compile | --showme:link] ...

oshfort [--showme | --showme:compile | --showme:link] ...

shmemcc [--showme | --showme:compile | --showme:link] ...

shmemcxx [--showme | --showme:compile | --showme:link] ...

shmemc++ [--showme | --showme:compile | --showme:link] ...

shmemfort [--showme | --showme:compile | --showme:link] ...

OPCIONES

Las siguientes opciones se aplican a todos los compiladores de envoltura:

•
--showme: Esta opción tiene varias variantes (ver abajo). Ninguna de las variantes invoca al compilador subyacente; todas proporcionan información sobre cómo se habría invocado el compilador subyacente si --showme no se hubiera utilizado. La opción básica --showme muestra la línea de comandos que se ejecutaría para compilar el programa.

NOTA:

Si se pasa un argumento que no es un nombre de archivo en la línea de comandos, la opción --showme *no* mostrará ninguna bandera adicional. Por ejemplo, tanto "oshcc --showme como oshcc --showme my_source.c mostrarán todas las banderas suministradas por la envoltura. Pero oshcc --showme -v solo mostrará el nombre del compilador subyacente y -v.
  • --showme:compile: Muestra las banderas del compilador que se habrían proporcionado al compilador subyacente.
  • --showme:link: Muestra las banderas del enlazador que se habrían proporcionado al compilador subyacente.
  • --showme:command: Muestra el comando del compilador subyacente (que puede ser uno o más tokens).
  • --showme:incdirs: Muestra una lista de directorios delimitada por espacios (pero por lo demás sin decorar) que el compilador de envoltura habría proporcionado al compilador subyacente para indicar dónde se encuentran los archivos de encabezado relevantes.
  • --showme:libdirs: Muestra una lista de directorios delimitada por espacios (pero por lo demás sin decorar) que el compilador de envoltura habría proporcionado al enlazador subyacente para indicar dónde se encuentran las bibliotecas relevantes.
  • --showme:libs: Muestra una lista de nombres de bibliotecas delimitada por espacios (pero por lo demás sin decorar) que el compilador de envoltura habría utilizado para enlazar una aplicación. Por ejemplo: mpi open-pal util.
  • --showme:version: Muestra el número de versión de Open MPI.
  • --showme:help: Muestra un breve mensaje de ayuda de uso.

Consulte la página man de su compilador subyacente para ver otras opciones que se pueden pasar a través de oshcc.

DESCRIPCIÓN

Conceptualmente, el papel de estos comandos es bastante simple: añadir de forma transparente las banderas de compilador y enlazador relevantes a la línea de comandos del usuario que son necesarias para compilar / enlazar programas OpenSHMEM, y luego invocar al compilador subyacente para realizar realmente el comando.

Como tales, estos comandos se denominan frecuentemente compiladores “de envoltura” porque en realidad no compilan ni enlazan aplicaciones por sí mismos; solo añaden banderas a la línea de comandos e invocan al compilador de fondo.

ANTECEDENTES

Open MPI proporciona compiladores de envoltura para varios idiomas:

  • oshcc, shmemcc: C
  • oshc++, oshcxx, shmemc++, shmemcxx`:: C++
  • oshfort, shmemfort: Fortran

Los compiladores de envoltura para cada uno de los idiomas son idénticos; se pueden usar indistintamente. Los diferentes nombres se proporcionan únicamente por compatibilidad con versiones anteriores.

NOTAS DE FORTRAN

El compilador de envoltura Fortran para OpenSHMEM (oshfort y shmemfort) puede compilar y enlazar aplicaciones OpenSHMEM que utilicen cualquiera/todas las vinculaciones de Fortran de OpenSHMEM.

Sin embargo, tenga en cuenta que el compilador Fortran puede requerir opciones de línea de comandos adicionales para forzar un dialecto Fortran específico. Por ejemplo, en algunas versiones del compilador IBM XLF, puede ser necesario -qfixed para compilar archivos fuente Fortran de formato fijo si xlf90 es el compilador Fortran subyacente.

Finalmente, tenga en cuenta que oshfort estará inoperativo y devolverá un error al usarse si el soporte de Fortran no se incluyó en la capa de OpenSHMEM.

RESUMEN

oshcc y shmemcc son envolturas de conveniencia para el compilador C subyacente. La traducción de un programa OpenSHMEM requiere el enlace de las bibliotecas específicas de OpenSHMEM que pueden no residir en uno de los directorios de búsqueda estándar de ld(1). También a menudo requiere la inclusión de archivos de encabezado que tampoco se encuentran en una ubicación estándar.

oshcc y shmemcc pasan sus argumentos al compilador C subyacente junto con las opciones -I, -L y -l requeridas por los programas OpenSHMEM.

Lo mismo ocurre con todos los demás compiladores de envoltura de idiomas.

El equipo de OpenSHMEM recomienda *encarecidamente* el uso de los compiladores de envoltura en lugar de intentar enlazar a las bibliotecas de OpenSHMEM manualmente. Esto permite que la implementación específica de OpenSHMEM cambie sin forzar cambios en las directivas del enlazador en los Makefiles de los usuarios. De hecho, el conjunto específico de banderas y bibliotecas utilizadas por los compiladores de envoltura depende de cómo se configuró y construyó OpenSHMEM; los valores pueden cambiar entre diferentes instalaciones de la misma versión de OpenSHMEM.

De hecho, dado que las envolturas son simplemente capas delgadas sobre un compilador subyacente, hay muy, muy pocas razones convincentes para *no* usar oshcc. Cuando no es posible usar las envolturas directamente, se deben usar las opciones --showme:compile y --showme:link para determinar qué banderas usarían las envolturas. Por ejemplo:

shell$ cc -c file1.c `shmemcc --showme:compile`
shell$ cc -c file2.c `shmemcc --showme:compile`
shell$ cc file1.o file2.o `shmemcc --showme:link` -o my_oshmem_program

NOTAS

Es posible hacer que los compiladores de envoltura sean conscientes de múltiples bibliotecas. Es decir, las bibliotecas e inclusiones especificadas pueden diferir según las banderas del compilador especificadas (por ejemplo, con los compiladores GNU en Linux, se puede usar una ruta de biblioteca diferente si se ve -m32 en comparación con -m64). Este no es el comportamiento predeterminado en una compilación estándar, pero puede activarse (por ejemplo, en un paquete binario que proporciona soporte para 32 y 64 bits). *Se puede encontrar más información aquí*.

ARCHIVOS

Las cadenas que los compiladores de envoltura insertan en la línea de comandos antes de invocar al compilador subyacente se almacenan en un archivo de texto creado por OpenSHMEM e instalado en $pkgdata/NOMBRE-wrapper-data.txt, donde:

  • $pkgdata suele ser $prefix/share/openmpi
  • $prefix es el directorio de instalación superior de OpenSHMEM
  • NOMBRE es el nombre del compilador de envoltura (por ejemplo, $pkgdata/shmemcc-wrapper-data.txt)

Raramente es necesario editar estos archivos, pero se pueden examinar para obtener información sobre qué banderas están colocando las envolturas en la línea de comandos.

VARIABLES DE ENTORNO

Por defecto, las envolturas utilizan los compiladores que fueron seleccionados cuando se configuró OpenSHMEM. Estos compiladores fueron encontrados automáticamente por el script “configure” de Open MPI, o fueron seleccionados por el usuario en las variables de entorno CC, CXX y/o FC antes de que se invocara configure. Adicionalmente, otros argumentos específicos del compilador pudieron haber sido seleccionados por configure.

Estos valores se pueden anular selectivamente editando los archivos de texto que contienen esta información de configuración (ver la sección *ARCHIVOS*), o estableciendo variables de entorno seleccionadas

shmemcc(1) — Arch manual pages

NAME

shmemcc - build programs that use the OpenSHMEM C interface

SYNOPSIS

shmemcc [options] [source files] [libraries]

DESCRIPTION

The shmemcc command is a convenience wrapper for building programs that use the OpenSHMEM C interface. It is essentially a front-end to the underlying MPI compiler wrapper, which is typically mpicc(1).

When invoked, shmemcc will prepend the necessary OpenSHMEM compiler and linker flags to the command line before invoking the underlying MPI compiler wrapper.

OPTIONS

All command-line options are passed directly to the underlying MPI compiler wrapper. See mpicc(1) for a detailed list of valid options.

BACKGROUND

OpenSHMEM is a communication library that provides an API for parallel programming. It is based on the Partitioned Global Address Space (PGAS) model.

OpenSHMEM programs are typically built using a compiler wrapper script that sets up the correct include paths and library linking flags. shmemcc serves this purpose for C programs using OpenSHMEM.

FORTRAN NOTES

For Fortran programs, use the shmemfort command instead.

OVERVIEW

The shmemcc utility is a front-end to the underlying MPI compiler wrapper. It is used to compile and link OpenSHMEM C programs.

NOTES

The exact compiler and flags used by shmemcc are determined at OpenSHMEM build time. These are typically configured via environment variables.

FILES

  • /usr/include/shmem.h: The OpenSHMEM C header file.
  • -loshmem: The OpenSHMEM library.

ENVIRONMENT VARIABLES

The behavior of shmemcc can be influenced by several environment variables, all of which are prefixed with oshmem_.

Valid value names are:

  • CPPFLAGS: Flags added when invoking the preprocessor (C or C++)
  • LDFLAGS: Flags added when invoking the linker (C, C++, or Fortran)
  • LIBS: Libraries added when invoking the linker (C, C++, or Fortran)
  • CC: C compiler
  • CFLAGS: C compiler flags
  • CXX: C++ compiler
  • CXXFLAGS: C++ compiler flags
  • FC: Fortran compiler
  • FCFLAGS: Fortran compiler flags
