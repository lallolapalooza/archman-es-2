DESCRIPCIÓN

Las rutinas get proporcionan un método para copiar un objeto de datos simétrico contiguo de un PE diferente a un objeto de datos contiguo en el PE local. Las rutinas devuelven después de publicar la operación. La operación se considera completa después de una llamada posterior a shmem_quiet. Al completar shmem_quiet, los datos se han entregado a la matriz de destino en el PE local.

Los argumentos son los siguientes:

dest
Objeto de datos local que se actualizará.
source
Objeto de datos en el PE identificado por pe que contiene los datos a copiar. Este objeto de datos debe ser accesible remotamente.
nelems
Número de elementos en las matrices de destino y origen. nelems debe ser de tipo entero. Si estás usando Fortran, debe ser una constante, variable o elemento de matriz de tipo entero predeterminado.
pe
Número de PE del PE remoto. pe debe ser de tipo entero. Si estás usando Fortran, debe ser una constante, variable o elemento de matriz de tipo entero predeterminado.

Si estás usando Fortran, los tipos de datos deben ser del tamaño predeterminado. Por ejemplo, una variable real debe declararse como REAL, REAL*4 o REAL(KIND=4).

NOTAS

Consulte intro_shmem(3) para obtener una definición del término accesible remotamente.

EJEMPLOS

Considere este sencillo ejemplo para Fortran.

PROGRAM REDUCTION
  REAL VALUES, SUM
  COMMON /C/ VALUES
  REAL WORK
  CALL START_PES(0) ! PERMITIR CUALQUIER NÚMERO DE PEs
  VALUES = MY_PE() ! INICIALIZARLO A ALGO
  CALL SHMEM_BARRIER_ALL
  SUM = 0.0
  DO I = 0,NUM_PES()-1
    CALL SHMEM_REAL_GET_NBI(WORK, VALUES, 1, I)
    CALL SHMEM_QUIET                ! esperar la entrega
    SUM = SUM + WORK
  ENDDO
  PRINT *, 'PE ', MY_PE(), ' SUMA CALCULADA=', SUM
  CALL SHMEM_BARRIER_ALL
END
