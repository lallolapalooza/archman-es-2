SHY(1) Manual de comandos generales SHY(1)

NOMBRE

shy - lanzador ssh minimalista

SINOPSIS

shy [OPCIONES]

DESCRIPCIÓN

shy es una pequeña interfaz de usuario de consola para conectarse rápidamente a un servidor ssh. Analiza tu archivo `~/.ssh/config` y muestra todos tus patrones "Host", lo que te permite seleccionar rápidamente uno usando un prompt similar a readline.

Normalmente, shy se inicia sin opciones:

shy

Para conectarte más rápidamente a un host, puedes lanzar en modo de búsqueda:

shy -s

Si deseas usar un archivo de configuración diferente a `~/.ssh/config`, puedes pasar una ruta usando las opciones `-c` o `--config`.

OPCIONES

-c, --config ARCHIVO

Usa ARCHIVO en lugar de ~/.ssh/config

-h, --help

Imprime un resumen de ayuda y sale.

-v, --version

Imprime información de la versión y sale.

NOTAS

Si no se encuentra ningún archivo de configuración, shy fallará al iniciarse.

NAVEGACIÓN

shy tiene dos modos: Modo de Navegación y Modo de Búsqueda. Por defecto, el programa está en Modo de Navegación: una vista de lista simple que te permite mover tu host seleccionado hacia arriba o hacia abajo.

Al presionar `i`, `s`, `f` o `/`, el programa entra en Modo de Búsqueda, lo que te permite saltar rápidamente a un host escribiendo el comienzo de su nombre.

ACCESOS DIRECTOS DEL TECLADO EN MODO NAVEGACIÓN

q, Esc, Ctrl-c

Sale de shy.

Flecha Arriba, Ctrl-p, k

Selecciona el host anterior en la lista.
Flecha Abajo, Ctrl-n, j
Selecciona el siguiente host en la lista.
Page Down, Barra espaciadora
Salta hacia abajo cinco entradas.
Page Up, -
Salta hacia arriba cinco entradas.

Enter

Conéctate al host seleccionado.

i, s, /, f

Entra en modo de búsqueda.
r, F5
Actualiza la vista.

ACCESOS DIRECTOS DEL TECLADO EN MODO BÚSQUEDA

Esc, Ctrl-c

Borra la entrada y luego sale del Modo de Búsqueda.

Flecha Arriba, Ctrl-p, k

Selecciona el host coincidente anterior.
Flecha Abajo, Ctrl-n, j
Selecciona el siguiente host coincidente.

Enter

Conéctate al host seleccionado.
