DESCRIPCIÓN

Las rutinas de "get" con pasos especificados recuperan datos de arreglo disponibles en la dirección source en el PE remoto (pe). Los elementos del arreglo source están separados por un paso sst. Una vez que se reciben los datos, se almacenan en la dirección de memoria local target, separados por el paso tst. Las rutinas devuelven el control cuando los datos se han copiado en el arreglo local target.

Los argumentos son los siguientes:

target
Arreglo a actualizar en el PE local.
source
Arreglo que contiene los datos a copiar en el PE remoto.
tst
El paso entre elementos consecutivos del arreglo destino. El paso se escala por el tamaño del elemento del arreglo destino. Un valor de 1 indica datos contiguos. tst debe ser de tipo entero. Si llama desde Fortran, debe ser un valor entero por defecto.
sst
El paso entre elementos consecutivos del arreglo fuente. El paso se escala por el tamaño del elemento del arreglo fuente. Un valor de 1 indica datos contiguos. sst debe ser de tipo entero. Si llama desde Fortran, debe ser un valor entero por defecto.
len
Número de elementos en los arreglos destino y fuente. len debe ser de tipo entero. Si usa Fortran, debe ser una constante, variable o elemento de arreglo de tipo entero por defecto.
pe
Número de PE del PE remoto. pe debe ser de tipo entero. Si usa Fortran, debe ser una constante, variable o elemento de arreglo de tipo entero por defecto.

Los objetos de datos destino y fuente deben cumplir con las restricciones de tipo, que son las siguientes:

shmem_iget32, shmem_iget4: Cualquier tipo no carácter que tenga un tamaño de almacenamiento
igual a 32 bits.
shmem_iget64, shmem_iget8: Cualquier tipo no carácter que tenga un tamaño de almacenamiento
igual a 64 bits.
shmem_iget128: Cualquier tipo no carácter que tenga un tamaño de almacenamiento igual a
128 bits.

shmem_short_iget: Elementos de tipo short.

shmem_int_iget: Elementos de tipo int.

shmem_long_iget: Elementos de tipo long.

shmem_longlong_iget: Elementos de tipo long long.

shmem_float_iget: Elementos de tipo float.

shmem_double_iget: Elementos de tipo double.

shmem_longdouble_iget: Elementos de tipo long double.

SHMEM_COMPLEX_IGET: Elementos de tipo complex de tamaño predeterminado.

SHMEM_DOUBLE_IGET: (Fortran) Elementos de tipo double precision.

SHMEM_INTEGER_IGET: Elementos de tipo integer.

SHMEM_LOGICAL_IGET: Elementos de tipo logical.

SHMEM_REAL_IGET: Elementos de tipo real.

shmem_longdouble_iget: Elementos de tipo long double.

SHMEM_COMPLEX_IGET: Elementos de tipo complex de tamaño predeterminado.

SHMEM_DOUBLE_IGET: (Fortran) Elementos de tipo double precision.

SHMEM_INTEGER_IGET: Elementos de tipo integer.

SHMEM_LOGICAL_IGET: Elementos de tipo logical.

SHMEM_REAL_IGET: Elementos de tipo real.

Si utiliza Fortran, los tipos de datos deben ser de tamaño predeterminado. Por ejemplo, una variable real debe declararse como REAL, REAL*4 o REAL(KIND=4).

NOTAS

Consulte intro_shmem(3) para ver una definición del término accesible remotamente.

EJEMPLOS

El siguiente ejemplo sencillo utiliza shmem_logical_iget en un programa Fortran. Compile este ejemplo con la opción de compilador -lsma.

PROGRAM STRIDELOGICAL
  LOGICAL SOURCE(10), TARGET(5)
  SAVE SOURCE ! SAVE HACE QUE SEA ACCESIBLE REMOTAMENTE
  DATA SOURCE /.T.,.F.,.T.,.F.,.T.,.F.,.T.,.F.,.T.,.F./
  DATA TARGET / 5*.F. /
  CALL START_PES(2)
  IF (MY_PE() .EQ. 0) THEN
    CALL SHMEM_LOGICAL_IGET(TARGET, SOURCE, 1, 2, 5, 1)
    PRINT*,'TARGET DESPUÉS DE SHMEM_LOGICAL_IGET:',TARGET
  ENDIF
  CALL SHMEM_BARRIER_ALL
END
