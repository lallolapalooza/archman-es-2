shmalloc(3), shfree(3), shmemalign(3), shrealloc(3) - Funciones de gestión de memoria del montículo simétrico.

SINOPSIS

C o C++:

#include <mpp/shmem.h>
void *shmalloc(size_t size)
void shfree(void *ptr)
void *shrealloc(void *ptr, size_t size)
void *shmemalign(size_t alignment, size_t size)
extern long malloc_error

DESCRIPCIÓN

La función shmalloc devuelve un puntero a un bloque de al menos `size` bytes, alineado adecuadamente para cualquier uso. Este espacio se asigna desde el montículo simétrico (en contraste con malloc(3), que asigna desde el montículo privado).

La función shmemalign asigna un bloque en el montículo simétrico que tiene una alineación de bytes especificada por el argumento `alignment`.

La función shfree provoca que el bloque al que apunta `ptr` sea liberado, es decir, que quede disponible para futuras asignaciones. Si `ptr` es un puntero nulo, no se realiza ninguna acción; de lo contrario, si el argumento no coincide con un puntero devuelto anteriormente por una función del montículo simétrico, o si el espacio ya ha sido liberado, se establece `malloc_error` para indicar el error, y `shfree` retorna.

La función shrealloc cambia el tamaño del bloque al que apunta `ptr` al tamaño (en bytes) especificado por `size`.

El contenido del bloque se mantiene sin cambios hasta el menor de los tamaños nuevo y antiguo. Si el nuevo tamaño es mayor, el valor de la porción recién asignada del bloque es indeterminado. Si `ptr` es un puntero nulo, la función `shrealloc` se comporta como la función `shmalloc` para el tamaño especificado. Si `size` es 0 y `ptr` no es un puntero nulo, se libera el bloque al que apunta. De lo contrario, si `ptr` no coincide con un puntero devuelto anteriormente por una función del montículo simétrico, o si el espacio ya ha sido liberado, la variable `malloc_error` se establece para indicar el error, y `shrealloc` devuelve un puntero nulo. Si el espacio no puede ser asignado, el bloque al que apunta `ptr` no cambia.

Las funciones `shmalloc`, `shfree` y `shrealloc` se proporcionan para que múltiples PEs (Unidades de Procesamiento) en una aplicación puedan asignar bloques de memoria simétricos y accesibles remotamente. Estos bloques de memoria se pueden utilizar con las rutinas de comunicación (shmem). Cada una de estas funciones llama a la función shmem_barrier_all(3) antes de retornar; esto asegura que todos los PEs participen en la asignación de memoria, y que la memoria en otros PEs pueda ser utilizada tan pronto como el PE local retorne.

El usuario es responsable de llamar a estas funciones con argumentos idénticos en todos los PEs; si se utilizan argumentos de tamaño diferentes, las llamadas subsiguientes pueden no devolver la misma dirección de montículo simétrico en todos los PEs.

NOTAS

El tamaño total del montículo simétrico se determina al inicio del trabajo. Se puede ajustar el tamaño del montículo utilizando la variable de entorno SHMEM_SYMMETRIC_HEAP_SIZE. Consulte la página del manual intro_shmem(3) para más detalles. Las funciones `shmalloc`, `shfree` y `shrealloc` difieren de las funciones de asignación de montículo privado en que todos los PEs de una aplicación deben llamarlas (se utiliza una barrera para asegurar esto).

VALORES DE RETORNO

La función shmalloc devuelve un puntero al espacio asignado (que debe ser idéntico en todos los PEs); de lo contrario, devuelve un puntero nulo (con `malloc_error` establecido). La función shfree no devuelve ningún valor. La función shrealloc devuelve un puntero al espacio asignado (que puede haberse movido); de lo contrario, devuelve un puntero nulo (con `malloc_error` establecido).
