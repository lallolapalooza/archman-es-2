Documentación de función/subrutina

subroutine shst01 (integer n, integer ilo, integer ihi, real, dimension( lda, * ) a, integer lda, real, dimension( ldh, * ) h, integer ldh, real, dimension( ldq, * ) q, integer ldq, real, dimension( lwork ) work, integer lwork, real, dimension( 2 ) result)

SHST01

Propósito:

!>
!> SHST01 comprueba la reducción de una matriz general A a la forma de Hessenberg superior:  A = Q*H*Q'.  Se calculan dos ratios de prueba;
!>
!> RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!> RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
!> Se asume que la matriz Q se proporciona explícitamente tal como estaría
!> después de SGEHRD + SORGHR.
!>
!> En esta versión, ILO e IHI no se utilizan y se asume que son 1 y
!> N, respectivamente.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>
!>          Se asume que A es triangular superior en filas y columnas
!>          1:ILO-1 y IHI+1:N, por lo que Q difiere de la identidad solo en
!>          las filas y columnas ILO+1:IHI.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          La matriz original A de n por n.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

H

!>          H es un array REAL, de dimensión (LDH,N)
!>          La matriz de Hessenberg superior H de la reducción A = Q*H*Q'
!>          calculada por SGEHRD.  Se asume que H es cero debajo de la
!>          primera subdiagonal.
!>

LDH

!>          LDH es INTEGER
!>          La dimensión principal del array H.  LDH >= max(1,N).
!>

Q

!>          Q es un array REAL, de dimensión (LDQ,N)
!>          La matriz ortogonal Q de la reducción A = Q*H*Q' calculada
!>          por SGEHRD + SORGHR.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.  LDQ >= max(1,N).
!>

WORK

!>          WORK es un array REAL, de dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.  LWORK >= 2*N*N.
!>

RESULT

!>          RESULT es un array REAL, de dimensión (2)
!>          RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
