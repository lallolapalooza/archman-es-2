SHIFT(1P) Manual del Programador de POSIX SHIFT(1P)

PROLOG

Esta página del manual forma parte del Manual del Programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

shift — desplazar parámetros posicionales

SINOPSIS

shift [n]

DESCRIPCIÓN

Los parámetros posicionales serán desplazados. Al parámetro posicional 1 se le asignará el valor del parámetro (1+n), al parámetro 2 se le asignará el valor del parámetro (2+n), y así sucesivamente. Los parámetros representados por los números "$#" hasta "$# -n + 1" serán eliminados, y el parámetro '#' se actualizará para reflejar el nuevo número de parámetros posicionales.

El valor n será un entero decimal sin signo menor o igual al valor del parámetro especial '#'. Si n no se proporciona, se asumirá que es 1. Si n es 0, los parámetros posicionales y especiales no se modifican.

ESTADO DE SALIDA

Si el operando n es inválido o es mayor que "$#", esto puede considerarse un error de sintaxis y un shell no interactivo puede salir; si el shell no sale en este caso, se devolverá un estado de salida distinto de cero. De lo contrario, se devolverá cero.
