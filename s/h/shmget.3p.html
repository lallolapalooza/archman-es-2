SHMGET(3P) Manual del programador POSIX SHMGET(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux) o la interfaz puede no estar implementada en Linux.

NOMBRE

shmget — obtener un segmento de memoria compartida XSI

SINOPSIS

#include <sys/shm.h>
int shmget(key_t key, size_t size, int shmflg);

DESCRIPCIÓN

La función shmget() opera sobre memoria compartida XSI (consulte el volumen de Definiciones Base de POSIX.1-2017, Sección 3.346, Objeto de memoria compartida). No está especificado si esta función interactúa con las instalaciones de comunicación entre procesos en tiempo real definidas en la Sección 2.8, Tiempo real.

La función shmget() devolverá el identificador de memoria compartida asociado a key.

Se crearán un identificador de memoria compartida, una estructura de datos asociada y un segmento de memoria compartida de al menos size bytes (consulte <sys/shm.h>) para key si se cumple una de las siguientes condiciones:

*
El argumento key es igual a IPC_PRIVATE.
*
El argumento key no tiene ya un identificador de memoria compartida asociado y (shmflg &IPC_CREAT) es distinto de cero.

Al crearse, la estructura de datos asociada al nuevo identificador de memoria compartida se inicializará de la siguiente manera:

*
Los valores de shm_perm.cuid, shm_perm.uid, shm_perm.cgid y shm_perm.gid se establecen al ID de usuario efectivo y al ID de grupo efectivo, respectivamente, del proceso que llama.
*
Los nueve bits de orden bajo de shm_perm.mode se establecen a los nueve bits de orden bajo de shmflg.
*
El valor de shm_segsz se establece al valor de size.
*
Los valores de shm_lpid, shm_nattch, shm_atime y shm_dtime se establecen a 0.
*
El valor de shm_ctime se establece a la hora actual, según se describe en la Sección 2.7.1, Descripción general de IPC.

Cuando se crea el segmento de memoria compartida, se inicializará con todos los valores a cero.

VALOR DE RETORNO

Al completarse con éxito, shmget() devolverá un entero no negativo, es decir, un identificador de memoria compartida; de lo contrario, devolverá -1 y establecerá errno para indicar el error.

ERRORES

La función shmget() fallará si:

EACCES
Existe un identificador de memoria compartida para key pero el permiso de operación especificado por los nueve bits de orden bajo de shmflg no se concedería; consulte la Sección 2.7, Comunicación entre procesos XSI.
EEXIST
Existe un identificador de memoria compartida para el argumento key pero (shmflg &IPC_CREAT) &&(shmflg &IPC_EXCL) es distinto de cero.
EINVAL
Se va a crear un segmento de memoria compartida y el valor de size es menor que el mínimo impuesto por el sistema o mayor que el máximo impuesto por el sistema.
EINVAL
No se va a crear un segmento de memoria compartida y existe un segmento de memoria compartida para key pero el tamaño del segmento asociado es menor que size.
ENOENT
No existe un identificador de memoria compartida para el argumento key y (shmflg &IPC_CREAT) es 0.
ENOMEM
Se van a crear un identificador de memoria compartida y un segmento de memoria compartida asociado, pero la cantidad de memoria física disponible no es suficiente para satisfacer la solicitud.
ENOSPC
Se va a crear un identificador de memoria compartida, pero se excedería el límite impuesto por el sistema en el número máximo de identificadores de memoria compartida permitidos en todo el sistema.

USO EN APLICACIONES

La Extensión POSIX de Tiempo Real define interfaces alternativas para la comunicación entre procesos. Los desarrolladores de aplicaciones que necesiten utilizar IPC deben diseñar sus aplicaciones de manera que los módulos que utilizan las rutinas de IPC descritas en la Sección 2.7, Comunicación entre procesos XSI, puedan modificarse fácilmente para utilizar las interfaces alternativas.
