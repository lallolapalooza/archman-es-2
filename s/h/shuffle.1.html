shuffle(1) Manual de Comandos Generales shuffle(1)

NOMBRE

shuffle - reordena aleatoriamente las líneas en un archivo

SINOPSIS

shuffle [ archivo_entrada [ archivo_salida ] ]

DESCRIPCIÓN

shuffle lee archivo_entrada en memoria, baraja las líneas y escribe el resultado en archivo_salida.

OPCIONES

Ninguna.

OPERANDOS

Se soportan los siguientes operandos:

archivo_entrada
Un nombre de ruta de un archivo de entrada. Si no se especifica archivo_entrada, o si archivo_entrada es igual a "-", se utiliza la entrada estándar.
archivo_salida
Un nombre de ruta de un archivo de salida. Si no se especifica archivo_salida, o si archivo_salida es igual a "-", se utiliza la salida estándar.

NOTAS

Dado que shuffle lee la entrada en memoria, puede fallar en archivos muy grandes.
