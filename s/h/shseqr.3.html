Documentación de la Función/Subrutina

subroutine shseqr (character job, character compz, integer n, integer ilo, integer ihi, real, dimension( ldh, * ) h, integer ldh, real, dimension( * ) wr, real, dimension( * ) wi, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer info)

SHSEQR

Propósito:

!>
!>    SHSEQR calcula los valores propios de una matriz de Hessenberg H
!>    y, opcionalmente, las matrices T y Z de la descomposición de Schur
!>    H = Z T Z**T, donde T es una matriz cuasi-triangular superior (la
!>    forma de Schur), y Z es la matriz ortogonal de vectores de Schur.
!>
!>    Opcionalmente, Z puede ser postmultiplicada en una matriz ortogonal
!>    de entrada Q para que esta subrutina pueda dar la factorización de
!>    Schur de una matriz A que ha sido reducida a la forma de Hessenberg
!>    H por la matriz ortogonal Q:  A = Q*H*Q**T = (QZ)*T*(QZ)**T.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>           = 'E':  calcula solo los valores propios;
!>           = 'S':  calcula los valores propios y la forma de Schur T.
!>

COMPZ

!>          COMPZ es CHARACTER*1
!>           = 'N':  no se calculan vectores de Schur;
!>           = 'I':  Z se inicializa a la matriz identidad y se devuelve
!>                   la matriz Z de vectores de Schur de H;
!>           = 'V':  Z debe contener una matriz ortogonal Q en la entrada
!>                   y se devuelve el producto Q*Z.
!>

N

!>          N es INTEGER
!>           El orden de la matriz H.  N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>
!>           Se asume que H ya es triangular superior en las filas
!>           y columnas 1:ILO-1 e IHI+1:N. ILO e IHI normalmente se
!>           establecen en una llamada anterior a SGEBAL y luego se
!>           pasan a ZGEHRD cuando la matriz de salida de SGEBAL se
!>           reduce a la forma de Hessenberg. De lo contrario, ILO e IHI
!>           deben establecerse a 1 y N respectivamente.
!>           Si N > 0, entonces 1 <= ILO <= IHI <= N.
!>           Si N = 0, entonces ILO = 1 e IHI = 0.
!>

H

!>          H es un array REAL, de dimensión (LDH,N)
!>           En la entrada, la matriz de Hessenberg superior H.
!>           En la salida, si INFO = 0 y JOB = 'S', entonces H contiene la
!>           matriz cuasi-triangular superior T de la descomposición de
!>           Schur (la forma de Schur); los bloques diagonales de 2x2
!>           (correspondientes a pares de valores propios complejos conjugados)
!>           se devuelven en forma estándar, con H(i,i) = H(i+1,i+1) y
!>           H(i+1,i)*H(i,i+1) < 0. Si INFO = 0 y JOB = 'E', el
!>           contenido de H no está especificado en la salida.
!>           (El valor de salida de H cuando INFO > 0 se da bajo la
!>           descripción de INFO.)
!>
!>           A diferencia de versiones anteriores de SHSEQR, esta subrutina
!>           puede explícitamente H(i,j) = 0 para i > j y j = 1, 2, ... ILO-1
!>           o j = IHI+1, IHI+2, ... N.
!>

LDH

!>          LDH es INTEGER
!>           La dimensión principal del array H. LDH >= max(1,N).
!>

WR

!>          WR es un array REAL, de dimensión (N)
!>

WI

!>          WI es un array REAL, de dimensión (N)
!>
!>           Las partes real e imaginaria, respectivamente, de los valores
!>           propios calculados. Si se calculan dos valores propios como un
!>           par conjugado complejo, se almacenan en elementos consecutivos
!>           de WR y WI, digamos el i-ésimo y el (i+1)-ésimo, con WI(i) > 0 y
!>           WI(i+1) < 0. Si JOB = 'S', los valores propios se almacenan en
!>           el mismo orden que en la diagonal de la forma de Schur devuelta
!>           en H, con WR(i) = H(i,i) y, si H(i:i+1,i:i+1) es un bloque
!>           diagonal de 2x2, WI(i) = sqrt(-H(i+1,i)*H(i,i+1)) y
!>           WI(i+1) = -WI(i).
!>

Z

!>          Z es un array REAL, de dimensión (LDZ,N)
!>           Si COMPZ = 'N', Z no se referencia.
!>           Si COMPZ = 'I', en la entrada Z no necesita estar establecida y
!>           en la salida, si INFO = 0, Z contiene la matriz ortogonal Z de
!>           los vectores de Schur de H. Si COMPZ = 'V', en la entrada Z debe
!>           contener una matriz N-por-N Q, que se asume que es igual a la
!>           matriz identidad excepto por la submatriz Z(ILO:IHI,ILO:IHI).
!>           En la salida, si INFO = 0, Z contiene Q*Z.
!>           Normalmente Q es la matriz ortogonal generada por SORGHR
!>           después de la llamada a SGEHRD que formó la matriz de Hessenberg
!>           H. (El valor de salida de Z cuando INFO > 0 se da bajo la
!>           descripción de INFO.)
!>

LDZ

!>          LDZ es INTEGER
!>           La dimensión principal del array Z. Si COMPZ = 'I' o
!>           COMPZ = 'V', entonces LDZ >= MAX(1,N).
!>           En caso contrario, LDZ >= 1.
!>

WORK

!>          WORK es un array REAL, de dimensión (LWORK)
!>           En la salida, si INFO = 0, WORK(1) devuelve una estimación de
!>           el valor óptimo para LWORK.
!>

LWORK

!>          LWORK es INTEGER
!>           La dimensión del array WORK. LWORK >= max(1,N)
!>           es suficiente y ofrece un rendimiento muy bueno y a veces
!>           óptimo. Sin embargo, LWORK tan grande como 11*N
!>           puede ser necesario para un rendimiento óptimo.
!>           Se recomienda una consulta de espacio de trabajo para
!>           determinar el tamaño óptimo del espacio de trabajo.
!>
!>           Si LWORK = -1, entonces SHSEQR realiza una consulta de espacio
!>           de trabajo. En este caso, SHSEQR comprueba los parámetros de
!>           entrada y estima el tamaño óptimo del espacio de trabajo para
!>           los valores dados de N, ILO e IHI. La estimación se devuelve
!>           en WORK(1). XERBLA no emite ningún mensaje de error relacionado
!>           con LWORK. Ni H ni Z se acceden.
!>

INFO

!>          INFO es INTEGER
!>             = 0:  salida exitosa
!>             < 0:  si INFO = -i, el argumento i tuvo un valor ilegal
!>             > 0:  si INFO = i, SHSEQR no pudo calcular todos los
!>                   valores propios. Los elementos 1:ilo-1 e i+1:n de WR
!>                   y WI contienen aquellos valores propios que se han
!>                   calculado con éxito. (Los fallos son raros.)
!>
!>                   Si INFO > 0 y JOB = 'E', entonces en la salida, los
!>                   valores propios no convergidos restantes son los valores
!>                   propios de la matriz de Hessenberg superior de las filas
!>                   y columnas ILO hasta INFO del valor final de H en la salida.
!>
!>                   Si INFO > 0 y JOB = 'S', entonces en la salida
!>
!>           (*)  (valor inicial de H)*U  = U*(valor final de H)
!>
!>                donde U es una matriz ortogonal. El valor final de H es
!>                de Hessenberg superior y cuasi-triangular en las filas y
!>                columnas INFO+1 hasta IHI.
!>
!>                Si INFO > 0 y COMPZ = 'V', entonces en la salida
!>
!>                  (valor final de Z)  =  (valor inicial de Z)*U
!>
!>                donde U es la matriz ortogonal en (*) (independientemente
!>                del valor de JOB).
!>
!>                Si INFO > 0 y COMPZ = 'I', entonces en la salida
!>                      (valor final de Z)  = U
!>                donde U es la matriz ortogonal en (*) (independientemente
!>                del valor de JOB).
!>
!>                Si INFO > 0 y COMPZ = 'N', entonces Z no se accede.
!>

!>
!>             Valores predeterminados proporcionados por
!>             ILAENV(ISPEC,'SHSEQR',JOB(:1)//COMPZ(:1),N,ILO,IHI,LWORK).
!>             Se sugiere que estos valores predeterminados se ajusten para
!>             lograr el mejor rendimiento en cada entorno computacional
!>             particular.
!>
!>            ISPEC=12: El punto de cruce de SLAHQR vs SLAQR0.
!>                      Predeterminado: 75. (Debe ser al menos 11.)
!>
!>            ISPEC=13: Tamaño de la ventana de deflexión recomendada.
!>                      Esto depende de ILO, IHI y NS. NS es el
!>                      número de desplazamientos simultáneos devueltos
!>                      por ILAENV(ISPEC=15). (Ver ISPEC=15 a continuación).
!>                      El valor predeterminado para (IHI-ILO+1) <= 500 es NS.
!>                      El valor predeterminado para (IHI-ILO+1) >  500 es 3*NS/2.
!>
!>            ISPEC=14: Punto de cruce de Nibble. (Ver IPARMQ para
!>                      detalles.) Predeterminado: 14% del tamaño de la ventana de deflexión.
!>
!>            ISPEC=15: Número de desplazamientos simultáneos en una iteración
!>                      QR multidesplazamiento.
!>
!>                      Si IHI-ILO+1 es...
!>
!>                      mayor que...pero menor... el
!>                      o igual que...      que        predeterminado es
!>
!>                           1               30          NS =   2(+)
!>                          30               60          NS =   4(+)
!>                          60              150          NS =  10(+)
!>                         150              590          NS =  **
!>                         590             3000          NS =  64
!>                        3000             6000          NS = 128
!>                        6000             infinito      NS = 256
!>
!>                  (+)  Por defecto, algunas o todas las matrices de este orden
!>                       se pasan a la rutina de doble desplazamiento implícito
!>                       SLAHQR y este parámetro se ignora. Ver
!>                       ISPEC=12 arriba y los comentarios en IPARMQ para
!>                       detalles.
!>
!>                 (**)  Los asteriscos (**) indican una función ad-hoc
!>                       de N creciente de 10 a 64.
!>
!>            ISPEC=16: Seleccionar multiplicación de matrices estructuradas.
!>                      Si el número de desplazamientos simultáneos (especificado
!>                      por ISPEC=15) es menor que 14, entonces el valor
!>                      predeterminado para ISPEC=16 es 0. De lo contrario,
!>                      el valor predeterminado para ISPEC=16 es 2.
!>
