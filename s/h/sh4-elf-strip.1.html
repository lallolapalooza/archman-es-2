NOMBRE

strip - descarta símbolos y otros datos de los archivos objeto

SINOPSIS

strip [-F nombrebfd |--target=nombrebfd]
[-I nombrebfd |--input-target=nombrebfd]
[-O nombrebfd |--output-target=nombrebfd]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nombresimbolo|--keep-symbol=nombresimbolo]
[-M|--merge-notes][--no-merge-notes]
[-N nombresimbolo |--strip-symbol=nombresimbolo]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nombredeseccion |--remove-section=nombredeseccion]
[--keep-section=patronseccion]
[--remove-relocations=patronseccion]
[--strip-section-headers]
[-o archivo] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[-v |--verbose] [-V|--version]
[--help] [--info]
archivoobjeto...

DESCRIPCIÓN

GNU strip descarta todos los símbolos de los archivos objeto archivoobjeto. La lista de archivos objeto puede incluir archivos. Se debe proporcionar al menos un archivo objeto.

strip modifica los archivos nombrados en sus argumentos, en lugar de escribir copias modificadas con nombres diferentes.

OPCIONES

-F nombrebfd
--target=nombrebfd
Trata el archivoobjeto original como un archivo con el formato de código objeto nombrebfd, y lo reescribe en el mismo formato.
--help
Muestra un resumen de las opciones de strip y sale.
--info
Muestra una lista que indica todas las arquitecturas y formatos de objeto disponibles.
-I nombrebfd
--input-target=nombrebfd
Trata el archivoobjeto original como un archivo con el formato de código objeto nombrebfd.
-O nombrebfd
--output-target=nombrebfd
Reemplaza archivoobjeto con un archivo en el formato de salida nombrebfd.
-R nombredeseccion
--remove-section=nombredeseccion
Elimina cualquier sección llamada nombredeseccion del archivo de salida, además de cualquier sección que de otro modo se eliminaría. Esta opción se puede usar varias veces. Tenga en cuenta que usar esta opción de forma inapropiada puede hacer que el archivo de salida sea inutilizable. El carácter comodín * se puede dar al final de nombredeseccion. Si es así, se eliminarán todas las secciones que comiencen con nombredeseccion.

Si el primer carácter de patronseccion es el signo de exclamación (!), entonces las secciones coincidentes no se eliminarán, incluso si un uso anterior de --remove-section en la misma línea de comandos las eliminaría de otro modo. Por ejemplo:

--remove-section=.text.* --remove-section=!.text.foo

eliminará todas las secciones que coincidan con el patrón '.text.*', pero no eliminará la sección '.text.foo'.

--keep-section=patronseccion
Al eliminar secciones del archivo de salida, mantenga las secciones que coincidan con patronseccion.
--remove-relocations=patronseccion
Elimina las reubicaciones del archivo de salida para cualquier sección que coincida con patronseccion. Esta opción se puede usar varias veces. Tenga en cuenta que usar esta opción de forma inapropiada puede hacer que el archivo de salida sea inutilizable. Se aceptan caracteres comodín en patronseccion. Por ejemplo: 
--remove-relocations=.text.*

eliminará las reubicaciones de todas las secciones que coincidan con el patrón '.text.*'.

Si el primer carácter de patronseccion es el signo de exclamación (!), entonces las secciones coincidentes no tendrán sus reubicaciones eliminadas, incluso si un uso anterior de --remove-relocations en la misma línea de comandos causaría de otro modo la eliminación de las reubicaciones. Por ejemplo:

--remove-relocations=.text.* --remove-relocations=!.text.foo

eliminará todas las reubicaciones de secciones que coincidan con el patrón '.text.*', pero no eliminará las reubicaciones de la sección '.text.foo'.

--strip-section-headers
Elimina las cabeceras de sección. Esta opción es específica de los archivos ELF. Implica --strip-all y --merge-notes.
-s
--strip-all
Elimina todos los símbolos.
-g
-S
-d
--strip-debug
Elimina solo los símbolos de depuración.
--strip-dwo
Elimina el contenido de todas las secciones DWARF .dwo, dejando intactas las secciones de depuración restantes y todos los símbolos. Consulte la descripción de esta opción en la sección objcopy para obtener más información.
--strip-unneeded
Elimina todos los símbolos que no son necesarios para el procesamiento de reubicaciones, además de los símbolos y secciones de depuración eliminados por --strip-debug.
-K nombresimbolo
--keep-symbol=nombresimbolo
Al eliminar símbolos, mantenga el símbolo nombresimbolo incluso si normalmente se eliminaría. Esta opción se puede dar varias veces.
-M
--merge-notes
--no-merge-notes
Para archivos ELF, intenta (o no intenta) reducir el tamaño de cualquier sección de tipo SHT_NOTE eliminando notas duplicadas. Por defecto, se intenta esta reducción a menos que se esté eliminando información de depuración o DWO.
-N nombresimbolo
--strip-symbol=nombresimbolo
Elimina el símbolo nombresimbolo del archivo fuente. Esta opción se puede dar varias veces y se puede combinar con otras opciones de strip distintas de -K.
-o archivo
Coloca la salida procesada en archivo, en lugar de reemplazar el archivo existente. Cuando se utiliza este argumento, solo se puede especificar un argumento archivoobjeto.
-p
--preserve-dates
Conserva las fechas de acceso y modificación del archivo.
-D
--enable-deterministic-archives
Opera en modo determinista. Al copiar miembros de archivo y escribir el índice del archivo, usa cero para UID, GID, marcas de tiempo y usa modos de archivo consistentes para todos los archivos.

Si binutils se configuró con --enable-deterministic-archives, entonces este modo está activado por defecto. Se puede desactivar con la opción -U, a continuación.

OPTIONS

-D
Preserve symbols from archive members, and use their actual UID, GID, timestamp, and file mode values when writing the archive index. This is the inverse of the -U option.
-U
The inverse of the -D option, above: when copying archive members and writing the archive index, use their actual UID, GID, timestamp, and file mode values.
This is the default unless binutils was configured with --enable-deterministic-archives.
-w
--wildcard
Permit regular expressions in symbolnames used in other command line options. The question mark (?), asterisk (*), backslash (\) and square brackets ([]) operators can be used anywhere in the symbol name. If the first character of the symbol name is the exclamation point (!) then the sense of the switch is reversed for that symbol. For example: 
-w -K !foo -K fo*
This would cause strip to only keep symbols that start with the letters "fo", but to discard the symbol "foo".
-x
--discard-all
Remove non-global symbols.
-X
--discard-locals
Remove compiler-generated local symbols. (These usually start with L or ..)
--keep-section-symbols
When stripping a file, perhaps with --strip-debug or --strip-unneeded, retain any symbols specifying section names, which would otherwise get stripped.
--keep-file-symbols
When stripping a file, perhaps with --strip-debug or --strip-unneeded, retain any symbols specifying source file names, which would otherwise get stripped.
--only-keep-debug
Strip a file, emptying the contents of any sections that would not be stripped by --strip-debug and leaving the debugging sections intact. In ELF files, this preserves all the note sections in the output as well.

Note - the section headers of the stripped sections are preserved, including their sizes, but the contents of the section are discarded. The section headers are preserved so that other tools can match up the debuginfo file with the real executable, even if that executable has been relocated to a different address space.

The intention is that this option will be used in conjunction with --add-gnu-debuglink to create a two part executable. One a stripped binary which will occupy less space in RAM and in a distribution and the second a debugging information file which is only needed if debugging abilities are required. The suggested procedure to create these files is as follows:

1.<Link the executable as normal. Assuming that it is called>
"foo" then...
1.<Run "objcopy --only-keep-debug foo foo.dbg" to>
create a file containing the debugging info.
1.<Run "objcopy --strip-debug foo" to create a>
stripped executable.
1.<Run "objcopy --add-gnu-debuglink=foo.dbg foo">
to add a link to the debugging info into the stripped executable.

Note---the choice of ".dbg" as an extension for the debug info file is arbitrary. Also the "--only-keep-debug" step is optional. You could instead do this:

1.<Link the executable as normal.>
1.<Copy "foo" to "foo.full">
1.<Run "strip --strip-debug foo">
1.<Run "objcopy --add-gnu-debuglink=foo.full foo">

i.e., the file pointed to by the --add-gnu-debuglink can be the full executable. It does not have to be a file created by the --only-keep-debug switch.

Note---this switch is only intended for use on fully linked files. It does not make sense to use it on object files where the debugging information may be incomplete. Besides the gnu_debuglink feature currently only supports the presence of one filename containing debugging information, not multiple filenames on a one-per-object-file basis.

-V
--version
Show the version number for strip.
-v
--verbose
Verbose output: list all object files modified. In the case of archives, strip -v lists all members of the archive.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
