shmem_alltoall32(3), shmem_alltoall64(3), shmem_alltoalls32(3), shmem_alltoalls64(3) - rutina colectiva donde cada PE intercambia una cantidad fija de datos con todos los demás PEs en el conjunto Activo

SINÓPSIS

C o C++:

#include <mpp/shmem.h>
void shmem_alltoall32(void *target, const void *source,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoall64(void *target, const void *source,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoalls32(void *target, const void *source,
  ptrdiff_t dst, ptrdiff_t sst,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoalls64(void *target, const void *source,
  ptrdiff_t dst, ptrdiff_t sst,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER dst, sst, nelems, PE_root, PE_start, logPE_stride, PE_size
INTEGER pSync(SHMEM_ALLTOALL_SYNC_SIZE)
CALL SHMEM_ALLTOALL32(target, source, nelems,
& PE_start, logPE_stride, PE_size, fIpSync)
CALL SHMEM_ALLTOALL64(target, source, nelems,
& PE_start, logPE_stride, PE_size, pSync)
CALL SHMEM_ALLTOALLS32(target, source, dst, sst, nelems,
& PE_start, logPE_stride, PE_size, pSync)
CALL SHMEM_ALLTOALLS64(target, source, dst, sst, nelems,
& PE_start, logPE_stride, PE_size, pSync)

DESCRIPCIÓN

Las rutinas shmem_alltoalls son rutinas colectivas. Cada PE del conjunto Activo intercambia `nelems` elementos de datos con pasos (strided) de tamaño 32 bits (para shmem_alltoalls32) o 64 bits (para shmem_alltoalls64) con todos los demás PEs del conjunto. Tanto los pasos, `dst` y `sst`, deben ser mayores o iguales a 1. El bloque `sst*j` enviado desde el PE `i` al PE `j` se coloca en el bloque `dst*i` del objeto de datos de destino en el PE `j`. Al igual que con todas las rutinas colectivas de OpenSHMEM, estas rutinas asumen que solo los PEs del conjunto Activo llaman a la rutina. Si un PE que no está en el conjunto Activo llama a una rutina colectiva de OpenSHMEM, el comportamiento no está definido. Los valores de los argumentos `dst`, `sst`, `nelems`, `PE_start`, `logPE_stride` y `PE_size` deben ser iguales en todos los PEs del conjunto Activo. Los mismos objetos de datos de destino y origen, y el mismo array de trabajo `pSync` deben pasarse a todos los PEs del conjunto Activo. Antes de cualquier llamada a PE a una rutina shmem_alltoalls, deben existir las siguientes condiciones (la sincronización mediante una barrera o algún otro método a menudo es necesaria para garantizar esto): El array `pSync` en todos los PEs del conjunto Activo ya no se está utilizando de una llamada anterior a una rutina shmem_alltoalls. El objeto de datos de destino en todos los PEs del conjunto Activo está listo para recibir los datos de shmem_alltoalls. Al regresar de una rutina shmem_alltoalls, lo siguiente es cierto para el PE local: Su objeto de datos simétrico de destino está completamente actualizado y los datos se han copiado desde el objeto de datos de origen. Los valores en el array `pSync` se restauran a los valores originales.

Los argumentos son los siguientes:

Un objeto de datos simétrico con uno de los siguientes tipos de datos:

shmem_alltoall32: Cualquier tipo no carácter que
tenga un tamaño de elemento de 32 bits. No se permiten tipos derivados de Fortran ni estructuras C/C++.
shmem_alltoall64: Cualquier tipo no carácter que tenga un tamaño de elemento
de 64 bits. No se permiten tipos derivados de Fortran ni estructuras C/C++.

target Un objeto de datos simétrico lo suficientemente grande como para recibir el total combinado de `nelems` elementos de cada PE en el conjunto Activo.

source
Un objeto de datos simétrico que contiene `nelems` elementos de datos para cada PE en el conjunto Activo, ordenados según el PE de destino.
dst
El paso entre elementos consecutivos del objeto de datos de destino. El paso se escala por el tamaño del elemento. Un valor de 1 indica datos contiguos. `dst` debe ser de tipo `ptrdiff_t`. Si está usando Fortran, debe ser un valor entero predeterminado.
sst
El paso entre elementos consecutivos del objeto de datos de origen. El paso se escala por el tamaño del elemento. Un valor de 1 indica datos contiguos. `sst` debe ser de tipo `ptrdiff_t`. Si está usando Fortran, debe ser un valor entero predeterminado.
nelems
El número de elementos a intercambiar para cada PE. `nelems` debe ser de tipo `size_t` para C/C++. Si está usando Fortran, debe ser un valor entero predeterminado.
PE_start
El número de PE virtual más bajo del conjunto activo de PEs. `PE_start` debe ser de tipo entero. Si está usando Fortran, debe ser un valor entero predeterminado.
logPE_stride
El logaritmo (base 2) del paso entre números de PE virtuales consecutivos en el conjunto activo. `log_PE_stride` debe ser de tipo entero. Si está usando Fortran, debe ser un valor entero predeterminado.
PE_size
El número de PEs en el conjunto activo. `PE_size` debe ser de tipo entero. Si está usando Fortran, debe ser un valor entero predeterminado.
pSync
Un array de trabajo simétrico. En C/C++, `pSync` debe ser de tipo `long` y tamaño `_SHMEM_ALLTOALL_SYNC_SIZE`. En Fortran, `pSync` debe ser de tipo entero y tamaño `SHMEM_ALLTOALL_SYNC_SIZE`. Cada elemento de este array debe inicializarse con el valor `_SHMEM_SYNC_VALUE` (en C/C++) o `SHMEM_SYNC_VALUE` (en Fortran) antes de que cualquiera de los PEs del conjunto activo entre en `shmem_barrier()`.

Al regresar de una rutina shmem_alltoalls, lo siguiente es cierto para el PE local: Su objeto de datos simétrico de destino está completamente actualizado y los datos se han copiado desde el objeto de datos de origen. Los valores en el array `pSync` se restauran a los valores originales.

Los valores de los argumentos `PE_root`, `PE_start`, `logPE_stride` y `PE_size` deben ser iguales en todos los PEs del conjunto activo. Los mismos objetos de datos de destino y origen y el mismo array de trabajo `pSync` deben pasarse a todos los PEs del conjunto activo.

Antes de que cualquier PE llame a una rutina alltoall, debe asegurarse de que existan las siguientes condiciones (la sincronización mediante una barrera o algún otro método a menudo es necesaria para garantizar esto): El array `pSync` en todos los PEs del conjunto activo no está siendo utilizado por una llamada anterior a una rutina alltoall. El array de destino en todos los PEs del conjunto activo está listo para recibir los datos de alltoall.

NOTAS

Los términos colectivo y simétrico se definen en intro_shmem(3).

Todas las rutinas SHMEM alltoall restauran `pSync` a su contenido original. Múltiples llamadas a rutinas SHMEM que utilizan el mismo array `pSync` no requieren que `pSync` se reinicialice después de la primera llamada.

Debe asegurarse de que el array `pSync` no está siendo actualizado por ningún PE del conjunto activo mientras alguno de los PEs participa en el procesamiento de una rutina de difusión SHMEM. Tenga cuidado de evitar estas situaciones: Si el array `pSync` se inicializa en tiempo de ejecución, se necesita algún tipo de sincronización para garantizar que todos los PEs del conjunto de trabajo hayan inicializado `pSync` antes de que alguno de ellos entre en una rutina SHMEM llamada con el array de sincronización `pSync`. Un array `pSync` puede reutilizarse en una rutina de difusión SHMEM posterior solo si ninguno de los PEs del conjunto activo todavía está procesando una llamada anterior a la rutina SHMEM alltoall que utilizó el mismo array `pSync`. En general, esto solo se puede garantizar haciendo algún tipo de sincronización. Sin embargo, en el caso especial de las rutinas SHMEM que se llaman con el mismo conjunto activo, puede asignar dos arrays `pSync` y alternar entre ellos en llamadas sucesivas.

shmem_alltoalls64(3)

NAME

shmem_alltoalls64 - collective communication operation, all-to-all communication with 64-bit data elements

SYNTAX

C:
int shmem_alltoalls64(void *dest, const void *source, size_t element_size,
      int nlong, long long val, int logical_group);
Fortran:
CALL SHMEM_ALLTOALLS64(dest, source, element_size, nlong, val, logical_group)

DESCRIPTION

The Symmetric shmem_alltoalls64() routine performs a global all-to-all communication. It is a collective operation that must be executed by all processing elements (PEs) in the calling program. Each PE sends its entire source buffer to every other PE. The data received by each PE is concatenated and placed into the destination buffer.

The shmem_alltoalls64() routine transfers nlong elements of size element_size from each PE’s source buffer to the destination buffer of every PE. The total size of the data transferred between PEs is nlong * element_size bytes.

The dest argument points to the local destination buffer. This buffer receives data from all PEs in the symmetric heap. The total size of the destination buffer must be at least num_pes * nlong * element_size bytes, where num_pes is the total number of PEs in the symmetric multiprocessor.

The source argument points to the local source buffer. The size of the source buffer must be at least nlong * element_size bytes.

The element_size argument specifies the size, in bytes, of each element to be transferred. It must be the same for all PEs.

The nlong argument specifies the number of elements to be transferred from each PE. It must be the same for all PEs.

The val argument is an unused parameter and is present for compatibility with other Open SHMEM routines. It should be set to 0.

The logical_group argument is an unused parameter and is present for compatibility with other Open SHMEM routines.

The data received by each PE from the other PEs is concatenated into the destination buffer. The data from PE `j` is placed after the data from PE `j-1`. The data from PE 0 is placed at the beginning of the destination buffer.

The shmem_alltoalls64() routine is only valid when called within a symmetric heap region.

The destination buffer of PE `i` will contain the data sent from PE `j` contiguously.

The order of data within the destination buffer is as follows:

dest[i] = { data from PE 0, data from PE 1, ..., data from PE (NPES-1) }

Where NPES is the total number of PEs.

Each PE’s contribution to the destination buffer is formed by concatenating the source buffers of all PEs in the order of the PE indices.

The destination buffer of PE `i` will contain the following data:

dest[i] = { source[0] from PE 0, source[0] from PE 1, ..., source[0] from PE (NPES-1) }

where source[0] refers to the source buffer on each PE.

The size of the source buffer on each PE must be nlong * element_size bytes.

The size of the destination buffer on each PE must be NPES * nlong * element_size bytes.

The shmem_alltoalls64() routine is a collective routine. All PEs must call this routine. Furthermore, the arguments element_size, nlong, val, and logical_group must be identical for all PEs.

The dest and source buffers must be symmetric memory.

The contents of the source buffer are unchanged after the call.

The destination buffer is overwritten by the call.

The shmem_alltoalls64() routine is synchronized in the sense that it does not return until all non-blocking communications initiated by earlier calls to shmem_alltoalls64() have completed.

NOTES

The SHMEM_ALLTOALLS_SYNC_SIZE macro defines the size of the synchronization array that must be allocated by the user.

The SHMEM_SYNC_VALUE macro defines the initialization value for the synchronization array.

The shmem_barrier_all() routine must be called before and after the shmem_alltoalls64() routine to ensure that all PEs have initialized their synchronization arrays and to ensure that all communications are complete.

EXAMPLES

/* Compile with:
 *  mpicc -o example example.c
 *
 * Run with:
 *  mpirun -np 4 ./example
 */
#include <stdio.h>
#include <stdlib.h>
#include <assert.h>
#include <string.h>
#include <shmem.h>

#define COUNT 10

int main(int argc, char **argv) {
    long long *dest;
    long long *source;
    long long pSync[SHMEM_ALLTOALLS_SYNC_SIZE];
    int i, pe;

    /* Initialize SHMEM */
    start_pes(0);

    /* Allocate memory for source and destination buffers */
    dest = (long long *) shmem_malloc(shmem_n_pes() * COUNT * sizeof(long long));
    source = (long long *) shmem_malloc(COUNT * sizeof(long long));

    /* Initialize source buffer */
    for (pe = 0; pe < shmem_n_pes(); pe++) {
        for (i = 0; i < COUNT; i++) {
            source[(pe * COUNT) + i] = shmem_my_pe() + pe;
            dest[(pe * COUNT) + i] = 9999;
        }
    }

    /* Initialize synchronization array */
    for (i = 0; i < SHMEM_ALLTOALLS_SYNC_SIZE; i++) {
        pSync[i] = SHMEM_SYNC_VALUE;
    }

    /* Wait for all PEs to initialize pSync */
    shmem_barrier_all();

    /* Perform alltoalls on all PEs */
    shmem_alltoalls64(dest, source, sizeof(long long), COUNT, 0, 0);

    /* Verify results */
    for (pe = 0; pe < shmem_n_pes(); pe++) {
        for (i = 0; i < COUNT; i++) {
            if (dest[(pe * COUNT) + i] != shmem_my_pe() + pe) {
                printf("[%d] ERROR: dest[%d]=%ld, should be %d\n",
                       shmem_my_pe(), (pe * COUNT) + i, dest[(pe * COUNT) + i],
                       shmem_my_pe() + pe);
            }
        }
    }

    shmem_barrier_all();

    /* Free allocated memory */
    shmem_free(dest);
    shmem_free(source);

    /* Finalize SHMEM */
    shmem_finalize();

    return 0;
}
