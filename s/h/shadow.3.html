NOMBRE

shadow, getspnam - rutinas del archivo de contraseñas cifradas

SINTAXIS

#include <shadow.h>

struct spwd *getspent();

struct spwd *getspnam(char *name);

void setspent();

void endspent();

struct spwd *fgetspent(FILE *fp);

struct spwd *sgetspent(char *cp);

int putspent(struct spwd *p, FILE *fp);

int lckpwdf();

int ulckpwdf();

DESCRIPCIÓN

shadow manipula el contenido del archivo de contraseñas shadow, /etc/shadow. La estructura en el archivo #include es:

struct spwd {
      char		*sp_namp; /* nombre de inicio de sesión del usuario */
      char		*sp_pwdp; /* contraseña cifrada */
      long int		sp_lstchg; /* último cambio de contraseña */
      long int		sp_min; /* días hasta que se permite el cambio. */
      long int		sp_max; /* días antes de que se requiera el cambio */
      long int		sp_warn; /* días de advertencia de caducidad */
      long int		sp_inact; /* días antes de que la cuenta esté inactiva */
      long int		sp_expire; /* fecha en que caduca la cuenta */
      unsigned long int	sp_flag; /* reservado para uso futuro */
}

Los significados de cada campo son:

•sp_namp - puntero al nombre de usuario terminado en nulo
•sp_pwdp - puntero a la contraseña terminada en nulo
•sp_lstchg - días desde el 1 de enero de 1970 en que se cambió la contraseña por última vez
•sp_min - días antes de los cuales no se puede cambiar la contraseña
•sp_max - días después de los cuales se debe cambiar la contraseña
•sp_warn - días antes de que caduque la contraseña en que se advierte al usuario de la próxima caducidad
•sp_inact - días después de que caduque la contraseña en que la cuenta se considera inactiva y deshabilitada
•sp_expire - días desde el 1 de enero de 1970 en que se deshabilitará la cuenta
•sp_flag - reservado para uso futuro

DESCRIPCIÓN

getspent, getspname, fgetspent y sgetspent devuelven cada uno un puntero a una estructura spwd. getspent devuelve la siguiente entrada del archivo, y fgetspent devuelve la siguiente entrada del flujo dado, que se supone que es un archivo con el formato correcto. sgetspent devuelve un puntero a una estructura spwd utilizando la cadena proporcionada como entrada. getspnam busca desde la posición actual en el archivo una entrada que coincida con name.

setspent y endspent pueden usarse para comenzar y finalizar, respectivamente, el acceso al archivo de contraseñas shadow.

Las rutinas lckpwdf y ulckpwdf deben usarse para garantizar un acceso exclusivo al archivo /etc/shadow. lckpwdf intenta adquirir un bloqueo utilizando pw_lock durante un máximo de 15 segundos. Continúa intentando adquirir un segundo bloqueo utilizando spw_lock durante el resto de los 15 segundos iniciales. Si alguno de los intentos falla después de un total de 15 segundos, lckpwdf devuelve -1. Cuando se adquieren ambos bloqueos, se devuelve 0.

DIAGNÓSTICOS

Las rutinas devuelven NULL si no hay más entradas disponibles o si se produce un error durante el procesamiento. Las rutinas que tienen int como valor de retorno devuelven 0 para éxito y -1 para fallo.

ADVERTENCIAS

Estas rutinas solo pueden ser utilizadas por el superusuario, ya que el acceso al archivo de contraseñas shadow está restringido.
