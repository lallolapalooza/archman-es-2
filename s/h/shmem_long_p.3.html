shmem_long_p(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_LONG_P(3) Open MPI SHMEM_LONG_P(3)

shmem_char_p(3), shmem_float_p(3), shmem_int_p(3), shmem_long_p(3), shmem_short_p(3), shmem_longlong_p(3), shmem_longdouble_p(3) - Estas rutinas proporcionan un mecanismo de baja latencia para escribir tipos básicos (char, short, int, float, double, long, long long, long double) en objetos de datos simétricos en PEs remotos.

SINOPSIS

C o C++:

#include <mpp/shmem.h>
void shmem_char_p(char *addr, char value, int pe)
void shmem_short_p(short *addr, short value, int pe)
void shmem_int_p(int *addr, int value, int pe)
void shmem_long_p(long *addr, long value, int pe)
void shmem_longlong_p(long long *addr, long long value, int pe)
void shmem_float_p(float *addr, float value, int pe)
void shmem_double_p(double *addr, double value, int pe)
void shmem_longdouble_p(long double *addr, long double value, int pe)

DESCRIPCIÓN

Estas rutinas proporcionan una capacidad de "put" de latencia muy baja para elementos individuales de la mayoría de los tipos básicos.

Los argumentos son los siguientes:

addr
El elemento de array o el objeto de datos escalar accesible remotamente que recibirá los datos en el PE remoto.
value
El valor a transferir a `addr` en el PE remoto.
pe
El número del PE remoto.

Al igual que con shmem_put(3), estas funciones inician la transferencia remota y pueden devolver el control antes de que los datos se entreguen al PE remoto. Utilice shmem_quiet(3) para forzar la finalización de todas las transferencias PUT remotas.

VER TAMBIÉN:

intro_shmem(3) shmem_put(3)
