shmem_pe_accessible - Determina si un elemento de procesamiento (PE) es accesible a través de operaciones de transferencia de datos SHMEM.

SINOPSIS

C:

#include <mpp/shmem.h>
int shmem_pe_accessible(int pe)

Fortran:

INCLUDE "mpp/shmem.fh"
LOGICAL LOG, SHMEM_PE_ACCESSIBLE
INTEGER pe
LOG = SHMEM_PE_ACCESSIBLE(pe)

DESCRIPCIÓN

shmem_pe_accessible devuelve un valor que indica si el PE llamante puede realizar operaciones de comunicación OpenSHMEM con el PE remoto.

VALORES DE RETORNO

C/C++
El valor de retorno es 1 si el PE especificado es un PE remoto válido para las funciones SHMEM; de lo contrario, es 0.
Fortran
El valor de retorno es .TRUE. si el PE especificado es un PE remoto válido para las funciones SHMEM; de lo contrario, es .FALSE..
