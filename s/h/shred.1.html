SHRED(1) Comandos de usuario SHRED(1)

NOMBRE

shred - sobrescribe un archivo para ocultar su contenido, y opcionalmente lo elimina

SINOPSIS

shred [OPCIÓN]... ARCHIVO...

DESCRIPCIÓN

Sobrescribe el(los) ARCHIVO(s) especificado(s) repetidamente, para hacer más difícil la recuperación de los datos, incluso con costosos equipos de análisis de hardware.

Si ARCHIVO es -, se sobrescribe la salida estándar.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-f, --force
cambia los permisos para permitir la escritura si es necesario
-n, --iterations=N
sobrescribe N veces en lugar del valor predeterminado (3)
--random-source=ARCHIVO
obtiene bytes aleatorios de ARCHIVO
-s, --size=N
sobrescribe N bytes (se aceptan sufijos como K, M, G)
-u
desasigna y elimina el archivo después de sobrescribirlo
--remove[=CÓMO]
similar a -u pero permite controlar CÓMO se elimina; véase abajo
-v, --verbose
muestra el progreso
-x, --exact
no redondea los tamaños de archivo al siguiente bloque completo; este es el valor predeterminado para archivos no regulares
-z, --zero
añade una sobrescritura final con ceros para ocultar el proceso de sobrescritura
--help
muestra esta ayuda y sale
--version
muestra la información de la versión y sale

Elimina ARCHIVO(s) si se especifica --remove (-u). El valor predeterminado es no eliminar los archivos porque es común operar en archivos de dispositivo como /dev/hda, y esos archivos normalmente no deberían eliminarse. El parámetro opcional CÓMO indica cómo eliminar una entrada de directorio: 'unlink' => usa una llamada estándar unlink. 'wipe' => también ofusca primero los bytes en el nombre. 'wipesync' => también sincroniza cada byte ofuscado con el dispositivo. El modo predeterminado es 'wipesync', pero ten en cuenta que puede ser costoso.

PRECAUCIÓN: shred asume que el sistema de archivos y el hardware sobrescriben los datos en el lugar. Aunque esto es común, muchas plataformas operan de manera diferente. Además, las copias de seguridad y los espejos pueden contener copias irrecuperables que permitirán recuperar un archivo sobrescrito más tarde. Consulte el manual de GNU coreutils para obtener más detalles.
