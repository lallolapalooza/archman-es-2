NOMBRE

readelf - muestra información sobre archivos ELF

DESCRIPCIÓN

readelf muestra información sobre uno o más archivos objeto en formato ELF. Las opciones controlan qué información particular se debe mostrar.

elffile... son los archivos objeto a examinar. Se admiten archivos ELF de 32 y 64 bits, así como archivos que contienen archivos ELF.

Este programa realiza una función similar a objdump pero entra en más detalle y existe independientemente de la biblioteca BFD, por lo que si hay un error en BFD, readelf no se verá afectado.

OPCIONES

Las formas largas y cortas de las opciones, mostradas aquí como alternativas, son equivalentes. Se debe proporcionar al menos una opción además de -v o -H.

-a
--all
Equivalente a especificar --file-header, --program-headers, --sections, --symbols, --relocs, --dynamic, --notes, --version-info, --arch-specific, --unwind, --section-groups y --histogram.

Nota: esta opción no habilita --use-dynamic en sí misma, por lo que si esa opción no está presente en la línea de comandos, los símbolos dinámicos y las relocalizaciones dinámicas no se mostrarán.

-h
--file-header
Muestra la información contenida en la cabecera ELF al inicio del archivo.
-l
--program-headers
--segments
Muestra la información contenida en las cabeceras de segmento del archivo, si las tiene.
--quiet
Suprime el diagnóstico de "sin símbolos".
-S
--sections
--section-headers
Muestra la información contenida en las cabeceras de sección del archivo, si las tiene.
-g
--section-groups
Muestra la información contenida en los grupos de secciones del archivo, si los tiene.
-t
--section-details
Muestra la información detallada de las secciones. Implica -S.
-s
--symbols
--syms
Muestra las entradas en la tabla de símbolos de la sección del archivo, si la tiene. Si un símbolo tiene información de versión asociada, se muestra también. La cadena de versión se muestra como un sufijo al nombre del símbolo, precedido por un carácter @. Por ejemplo, foo@VER_1. Si la versión es la versión predeterminada a usar al resolver referencias sin versión del símbolo, se muestra como un sufijo precedido por dos caracteres @. Por ejemplo, foo@@VER_2.
--dyn-syms
Muestra las entradas en la sección de tabla de símbolos dinámicos del archivo, si la tiene. El formato de salida es el mismo que el formato utilizado por la opción --syms.
--lto-syms
Muestra el contenido de las tablas de símbolos LTO en el archivo.
--sym-base=[0|8|10|16]
Fuerza que el campo de tamaño de la tabla de símbolos utilice la base dada. Cualquier opción no reconocida se tratará como 0. --sym-base=0 representa el comportamiento predeterminado y heredado. Esto mostrará los tamaños como decimal para números menores de 100000. Para tamaños de 100000 y mayores se usará notación hexadecimal con prefijo 0x. --sym-base=8 dará los tamaños de los símbolos en octal. --sym-base=10 siempre dará los tamaños de los símbolos en decimal. --sym-base=16 siempre dará los tamaños de los símbolos en hexadecimal con prefijo 0x.
-C
--demangle[=estilo]
Decodifica (demangle) nombres de símbolos de bajo nivel a nombres de nivel de usuario. Esto hace que los nombres de funciones de C++ sean legibles. Diferentes compiladores tienen diferentes estilos de mangling. El argumento opcional de estilo de demangling se puede usar para elegir un estilo de demangling apropiado para su compilador.
--no-demangle
No decodificar nombres de símbolos de bajo nivel. Este es el valor predeterminado.
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al decodificar cadenas. Dado que los formatos de mangling de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote la cantidad de espacio de pila disponible en la máquina host, activando una falla de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidamiento.

El valor predeterminado es que este límite esté habilitado, pero deshabilitarlo puede ser necesario para decodificar nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible agotar la pila y cualquier informe de error sobre tal evento será rechazado.

-U method
--unicode=method
Selecciona el método para manejar caracteres no ASCII en los nombres de símbolos. Los métodos disponibles son:
none o ascii
No haga nada con los nombres de símbolos. Este es el valor predeterminado.
lemote
Reemplace los caracteres no ASCII con su representación de secuencias de escape.
utf8
Convierta los nombres de símbolos a UTF-8.
-X
--extra-sym-info
--no-extra-sym-info
Muestra o no información adicional sobre los símbolos. Esto incluye el tipo de enlace, el tipo de visibilidad y el tipo de enlace.
-n
--notes
Muestra las notas del archivo.
-r
--relocs
Muestra las entradas de relocalización del archivo. Si el archivo tiene múltiples secciones de relocalización, se mostrarán todas.
-u
--unwind
Muestra la información de la tabla de desanudado (unwind table) del archivo, si la tiene.
-d
--dynamic
Muestra la información de la sección dinámica del archivo, si la tiene.
-V
--version-info
Muestra la información de versiones del archivo, si la tiene.
-A
--arch-specific
Muestra la información específica de la arquitectura del archivo, si la tiene.
-D
--use-dynamic
Muestra información adicional de la sección dinámica, como los símbolos dinámicos y las relocalizaciones dinámicas. Esto se hace buscando en las tablas de símbolos dinámicos y relocalizaciones dinámicas del archivo, en lugar de en las tablas de símbolos estándar y relocalizaciones estándar.
-L
--lint
--enable-checks
Realiza una serie de comprobaciones de validez en el archivo ELF y muestra un informe de los problemas encontrados.
-x <número o nombre>
--hex-dump=<número o nombre>
Muestra el contenido de la sección especificada, o del segmento especificado, en formato hexadecimal. El número o nombre debe ser el índice de la sección o segmento, o su nombre.
-p <número o nombre>
--string-dump=<número o nombre>
Muestra el contenido de la sección especificada en formato de cadena. El número o nombre debe ser el índice de la sección o su nombre.
-R <número o nombre>
--relocated-dump=<número o nombre>
Muestra el contenido de la sección especificada después de aplicar las relocalizaciones. El número o nombre debe ser el índice de la sección o su nombre.
-z
--decompress
Intenta descomprimir el archivo si está comprimido.
-c
--archive-index
Muestra el índice del archivo si es un archivo de biblioteca.
-w[lLiaprmfFsoORtUuTgAck]
--debug-dump[=tipo]
Muestra información de depuración del archivo. El parámetro tipo es una lista separada por comas de los tipos de información de depuración a mostrar. Los tipos disponibles son:
rawline
decodedline
Información de línea de depuración.
info
Información general de depuración DWARF.
abbrev
Tabla de abreviaturas DWARF.
pubnames
Tabla de nombres públicos DWARF.
aranges
Tabla de rangos DWARF.
macro
Información de macros DWARF.
frames
Información de DWARF `eh_frame`.
frames-interp
Información de DWARF `eh_frame_interp`.
str
Cadena de la tabla de cadenas DWARF.
str-offsets
Desplazamientos de la tabla de cadenas DWARF.
loc
Información de la tabla `loclists` DWARF.
Ranges
Información de la tabla `Rangelists` DWARF.
pubtypes
Tabla de tipos públicos DWARF.
trace_info
Información de seguimiento DWARF.
trace_abbrev
Tabla de abreviaturas de seguimiento DWARF.
trace_aranges
Tabla de rangos de seguimiento DWARF.
gdb_index
Índice GDB.
addr
Tabla de direcciones DWARF.
cu_index
Índice de unidades de compilación DWARF.
links
Vínculos de unidades de compilación DWARF.

Se pueden usar los siguientes modificadores:

follow-links
Seguir los enlaces de las unidades de compilación.
no-follow-links
No seguir los enlaces de las unidades de compilación.
use-debuginfod
Usar el servicio debuginfod para recuperar información de depuración.
do-not-use-debuginfod
No usar el servicio debuginfod.
-P

Procesar enlaces de unidades de compilación DWARF.
--dwarf-depth=n
Establece la profundidad máxima de recursión para el procesamiento de estructuras de datos DWARF.
--dwarf-start=n
Comienza a procesar estructuras de datos DWARF desde el índice de unidad de compilación especificado.
--ctf=section
Muestra información de tipo de compilación (CTF) de la sección especificada.
--ctf-parent=section
Muestra información de tipo de compilación (CTF) del padre de la sección especificada.
--ctf-symbols=section
Muestra los símbolos de tipo de compilación (CTF) de la sección especificada.
--ctf-strings=section
Muestra las cadenas de tipo de compilación (CTF) de la sección especificada.
--sframe=section
Muestra información del marco de pila de la sección especificada.
-I
--histogram
Muestra un histograma de los diferentes tipos de secciones en el archivo.
-v
--version
Muestra la información de versión de readelf y sale.
-W
--wide
Muestra la salida en un formato más ancho, útil para terminales de 80 columnas.
-T
--silent-truncation
No muestre advertencias sobre truncamiento de salida.
-H
--help
Muestra un mensaje de ayuda y sale.

a class="permalink" href="#U">-U [d|i|l|e|x|h]
--unicode=[default|invalid|locale|escape|hex|highlight]
Controla la visualización de caracteres no ASCII en los nombres de identificadores. El valor predeterminado (--unicode=locale o --unicode=default) es tratarlos como caracteres multibyte y mostrarlos en la configuración regional actual. Todas las demás versiones de esta opción tratan los bytes como valores codificados en UTF-8 e intentan interpretarlos. Si no se pueden interpretar o si se utiliza la opción --unicode=invalid, se mostrarán como una secuencia de bytes hexadecimales, encerrados entre llaves.

El uso de la opción --unicode=escape mostrará los caracteres como secuencias de escape unicode (\uxxxx). El uso de --unicode=hex mostrará los caracteres como secuencias de bytes hexadecimales encerradas entre corchetes angulares.

El uso de --unicode=highlight mostrará los caracteres como secuencias de escape unicode, pero también los resaltará en rojo, asumiendo que la salida admite colores. El resaltado está destinado a llamar la atención sobre la presencia de secuencias unicode cuando podrían no ser esperadas.

-X
--extra-sym-info
Al mostrar detalles de los símbolos, incluye información adicional no presentada normalmente. Actualmente, esto solo añade el nombre de la sección referenciada por el campo de índice del símbolo, si lo hay. En el futuro, se puede mostrar más información cuando esta opción esté habilitada.

Habilitar esta opción habilita efectivamente la opción --wide también, al menos al mostrar información de símbolos.

--no-extra-sym-info
Deshabilita el efecto de la opción --extra-sym-info. Este es el valor predeterminado.
-e
--headers
Muestra todas las cabeceras del archivo. Equivalente a -h -l -S.
-n
--notes
Muestra el contenido de los segmentos y/o secciones NOTE, si los hay.
-r
--relocs
Muestra el contenido de la sección de reubicación del archivo, si la tiene.
-u
--unwind
Muestra el contenido de la sección de desenrollado del archivo, si la tiene. Actualmente, solo se admiten las secciones de desenrollado para archivos ELF IA64, así como las tablas de desenrollado ARM (".ARM.exidx" / ".ARM.extab"). Si aún no se ha implementado el soporte para tu arquitectura, puedes intentar volcar el contenido de la sección .eh_frames usando las opciones --debug-dump=frames o --debug-dump=frames-interp.
-d
--dynamic
Muestra el contenido de la sección dinámica del archivo, si la tiene.
-V
--version-info
Muestra el contenido de las secciones de versión en el archivo, si existen.
-A
--arch-specific
Muestra información específica de la arquitectura en el archivo, si la hay.
-D
--use-dynamic
Al mostrar símbolos, esta opción hace que readelf utilice las tablas hash de símbolos en la sección dinámica del archivo, en lugar de las secciones de tabla de símbolos.

Al mostrar reubicaciones, esta opción hace que readelf muestre las reubicaciones dinámicas en lugar de las reubicaciones estáticas.

-L
--lint
--enable-checks
Muestra mensajes de advertencia sobre posibles problemas con los archivos que se están examinando. Si se usa solo, se examinará todo el contenido de los archivos. Si se usa con una de las opciones de volcado, los mensajes de advertencia solo se producirán para los elementos que se están mostrando.
-x <número o nombre>
--hex-dump=<número o nombre>
Muestra el contenido de la sección indicada como bytes hexadecimales. Un número identifica una sección particular por su índice en la tabla de secciones; cualquier otra cadena identifica todas las secciones con ese nombre en el archivo objeto.
-R <número o nombre>
--relocated-dump=<número o nombre>
Muestra el contenido de la sección indicada como bytes hexadecimales. Un número identifica una sección particular por su índice en la tabla de secciones; cualquier otra cadena identifica todas las secciones con ese nombre en el archivo objeto. El contenido de la sección se reubicará antes de mostrarse.
-p <número o nombre>
--string-dump=<número o nombre>
Muestra el contenido de la sección indicada como cadenas imprimibles. Un número identifica una sección particular por su índice en la tabla de secciones; cualquier otra cadena identifica todas las secciones con ese nombre en el archivo objeto.
-z
--decompress
Solicita que las secciones que se están mostrando con las opciones x, R o p se descompriman antes de ser mostradas. Si las secciones no están comprimidas, se mostrarán tal cual.
-c
--archive-index
Muestra la información del índice de símbolos del archivo contenido en la parte de cabecera de los archivos binarios. Realiza la misma función que el comando t de ar, pero sin usar la biblioteca BFD.
-w[lLiaprmfFsOoRtUuTgAckK]
--debug-dump[=rawline,=decodedline,=info,=abbrev,=pubnames,=aranges,=macro,=frames,=frames-interp,=str,=str-offsets,=loc,=Ranges,=pubtypes,=trace_info,=trace_abbrev,=trace_aranges,=gdb_index,=addr,=cu_index,=links,=follow-links]
Muestra el contenido de las secciones de depuración DWARF en el archivo, si las hay. Las secciones de depuración comprimidas se descomprimen automáticamente (temporalmente) antes de ser mostradas. Si una o más de las letras o palabras opcionales siguen al modificador, solo se mostrarán esos tipos de datos. Las letras y palabras se refieren a la siguiente información:
"a"
"=abbrev"
Muestra el contenido de la sección .debug_abbrev.
"A"
"=addr"
Muestra el contenido de la sección .debug_addr.
"c"
"=cu_index"
Muestra el contenido de las secciones .debug_cu_index y/o .debug_tu_index.
"f"
"=frames"
Muestra el contenido sin procesar de una sección .debug_frame.
"F"
"=frames-interp"
Muestra el contenido interpretado de una sección .debug_frame.
"g"
"=gdb_index"
Muestra el contenido de las secciones .gdb_index y/o .debug_names.
"i"
"=info"
Muestra el contenido de la sección .debug_info. Nota: la salida de esta opción también puede ser restringida por el uso de las opciones --dwarf-depth y --dwarf-start.
"k"
"=links"
Muestra el contenido de las secciones .gnu_debuglink, .gnu_debugaltlink y .debug_sup, si alguna de ellas está presente. También muestra cualquier enlace a archivos objeto de depuración separados (dwo), si están especificados por los atributos DW_AT_GNU_dwo_name o DW_AT_dwo_name en la sección .debug_info.
"K"
"=follow-links"
Muestra el contenido de cualquier sección de depuración seleccionada que se encuentre en archivos de información de depuración separados y enlazados. Esto puede resultar en la visualización de múltiples versiones de la misma sección de depuración si existe en más de un archivo.

Además, al mostrar atributos DWARF, si se encuentra un formato que hace referencia al archivo de información de depuración separado, también se mostrará el contenido referenciado.

Nota: en algunas distribuciones, esta opción está habilitada por defecto. Se puede deshabilitar mediante la opción de depuración N. El valor predeterminado se puede elegir al configurar binutils mediante las opciones --enable-follow-debug-links=yes o --enable-follow-debug-links=no. Si no se usan, el valor predeterminado es habilitar el seguimiento de los enlaces de depuración.

Nota: si el soporte para el protocolo debuginfod se habilitó cuando se compilaron binutils, esta opción también incluirá un intento de contactar con los servidores debuginfod mencionados en la variable de entorno DEBUGINFOD_URLS. Esto puede tardar algún tiempo en resolverse. Este comportamiento se puede deshabilitar mediante la opción de depuración =do-not-use-debuginfod.

--dwarf-depth=n
Limit the dump of the ".debug_info" section to n children. This is only useful with --debug-dump=info. The default is to print all DIEs; the special value 0 for n will also have this effect.

With a non-zero value for n, DIEs at or deeper than n levels will not be printed. The range for n is zero-based.

--dwarf-start=n
Print only DIEs beginning with the DIE numbered n. This is only useful with --debug-dump=info.

If specified, this option will suppress printing of any header information and all DIEs before the DIE numbered n. Only siblings and children of the specified DIE will be printed.

This can be used in conjunction with --dwarf-depth.

-P
--process-links
Display the contents of non-debug sections found in separate debuginfo files that are linked to the main file. This option automatically implies the -wK option, and only sections requested by other command line options will be displayed.
--ctf[=section]
Display the contents of the specified CTF section. CTF sections themselves contain many subsections, all of which are displayed in order.

By default, display the name of the section named .ctf, which is the name emitted by ld.

--ctf-parent=member
If the CTF section contains ambiguously-defined types, it will consist of an archive of many CTF dictionaries, all inheriting from one dictionary containing unambiguous types. This member is by default named .ctf, like the section containing it, but it is possible to change this name using the "ctf_link_set_memb_name_changer" function at link time. When looking at CTF archives that have been created by a linker that uses the name changer to rename the parent archive member, --ctf-parent can be used to specify the name used for the parent.
--ctf-symbols=section
--ctf-strings=section
Specify the name of another section from which the CTF file can inherit strings and symbols. By default, the ".symtab" and its linked string table are used.

If either of --ctf-symbols or --ctf-strings is specified, the other must be specified as well.

-I
--histogram
Display a histogram of bucket list lengths when displaying the contents of the symbol tables.
-v
--version
Display the version number of readelf.
-W
--wide
Don't break output lines to fit into 80 columns. By default readelf breaks section header and segment listing lines for 64-bit ELF files, so that they fit into 80 columns. This option causes readelf to print each section header resp. each segment one a single line, which is far more readable on terminals wider than 80 columns.
-T
--silent-truncation
Normally when readelf is displaying a symbol name, and it has to truncate the name to fit into an 80 column display, it will add a suffix of "[...]" to the name. This command line option disables this behaviour, allowing 5 more characters of the name to be displayed and restoring the old behaviour of readelf (prior to release 2.35).
-H
--help
Display the command-line options understood by readelf.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
