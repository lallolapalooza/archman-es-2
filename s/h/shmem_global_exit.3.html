shmem_global_exit - Una rutina que permite a cualquier PE forzar la terminación de un programa completo.

SINOPSIS

C o C++:

#include <mpp/shmem.h>
void shmem_global_exit(int status)

Fortran:

include 'mpp/shmem.fh'
INTEGER STATUS
CALL SHMEM_GLOBAL_EXIT(status)

DESCRIPCIÓN

shmem_global_exit() shmem_global_exit es una rutina no colectiva que permite a cualquier PE forzar la terminación de un programa Open-SHMEM para todos los PEs, pasando un estado de salida al entorno de ejecución. Esta rutina termina el programa completo, no solo la parte de OpenSHMEM. Cuando cualquier PE llama a shmem_global_exit, resulta en la notificación inmediata a todos los PEs para que terminen. shmem_global_exit vacía la E/S y libera recursos de acuerdo con los requisitos de los lenguajes C/C++/Fortran para la terminación normal del programa. Si más de un PE llama a shmem_global_exit, entonces el estado de salida devuelto al entorno será uno de los valores pasados a shmem_global_exit como argumento de estado. No hay retorno al llamador de shmem_global_exit; el control se devuelve desde el programa OpenSHMEM al entorno de ejecución para todos los PEs.
