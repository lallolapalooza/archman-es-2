shmem_barrier_all(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_BARRIER_ALL(3) Open MPI SHMEM_BARRIER_ALL(3)

shmem_barrier_all - Suspende la ejecución del PE (proceso elemental) que llama hasta que todos los demás PEs emitan una llamada a esta declaración shmem_barrier_all() en particular.

SINOPSIS

C o C++:

#include <mpp/shmem.h>
void shmem_barrier_all(void)

Fortran:

include 'mpp/shmem.h'
CALL SHMEM_BARRIER_ALL

DESCRIPCIÓN

La rutina shmem_barrier_all no devuelve nada hasta que todos los demás PEs hayan entrado en esta rutina en el mismo punto de la ruta de ejecución.

Antes de sincronizarse con otros PEs, shmem_barrier_all asegura la finalización de todas las escrituras de memoria local y actualizaciones de memoria remota emitidas previamente a través de funciones SHMEM como shmem_put32(3).

EJEMPLOS

setup_data()
{
  if (shmem_my_pe() == 0) {
    setup();
  }
  /* Todos los PEs esperan a que el PE 0 complete setup(). */
  shmem_barrier_all();
}
