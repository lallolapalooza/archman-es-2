DESCRIPCIÓN

Las rutinas shmem_get transfieren nelems elementos del objeto de datos en la dirección source en el PE remoto pe, al objeto de datos en la dirección target en el PE local. Estas rutinas retornan después de que los datos se hayan copiado a la dirección target en el PE local.

Los argumentos son los siguientes:

target
Objeto de datos local que se actualizará.
source
Objeto de datos en el PE identificado por pe que contiene los datos a copiar. Este objeto de datos debe ser accesible remotamente.
len
Número de elementos en los arrays de destino y origen. len debe ser de tipo entero. Si estás usando Fortran, debe ser una constante, variable o elemento de array de tipo entero predeterminado.
pe
Número de PE del PE remoto. pe debe ser de tipo entero. Si estás usando Fortran, debe ser una constante, variable o elemento de array de tipo entero predeterminado.

Los objetos de datos de destino y origen deben cumplir con las restricciones de tipo, que son las siguientes:

shmem_getmem: Fortran: Cualquier tipo no caracter. C: Cualquier tipo de datos. len es
escalado en bytes.
shmem_get4, shmem_get32: Cualquier tipo no caracter que tenga un tamaño de
almacenamiento igual a 32 bits.
{shmem_get8, shmem_get64}: Cualquier tipo no caracter que tenga un tamaño de almacenamiento igual a
64 bits.
shmem_get128: Cualquier tipo no caracter que tenga un tamaño de almacenamiento igual a 128
bits.

shmem_short_get: Elementos de tipo short.

shmem_int_get: Elementos de tipo int.

shmem_long_get: Elementos de tipo long.

shmem_longlong_get: Elementos de tipo long long.

shmem_float_get: Elementos de tipo float.

shmem_double_get: Elementos de tipo double.

shmem_longdouble_get: Elementos de tipo long double.

SHMEM_CHARACTER_GET: Elementos de tipo carácter. len es el número de
caracteres a transferir. Se ignoran las longitudes de carácter reales de las variables de origen y destino.

SHMEM_COMPLEX_GET: Elementos de tipo complejo de tamaño predeterminado.

SHMEM_DOUBLE_GET: (Fortran) Elementos de tipo de doble precisión.

SHMEM_INTEGER_GET: Elementos de tipo entero.

SHMEM_LOGICAL_GET: Elementos de tipo lógico.

SHMEM_REAL_GET: Elementos de tipo real.

Si estás usando Fortran, los tipos de datos deben ser de tamaño predeterminado. Por ejemplo, una variable real debe declararse como REAL, REAL*4 o REAL(KIND=4).

NOTAS

Consulta intro_shmem(3) para una definición del término accesible remotamente.

EJEMPLOS

Considera este sencillo ejemplo para Fortran.

PROGRAM REDUCTION
  REAL VALUES, SUM
  COMMON /C/ VALUES
  REAL WORK
  CALL START_PES(0) ! PERMITIR CUALQUIER NÚMERO DE PEs
  VALUES = MY_PE() ! INICIALIZARLO A ALGO
  CALL SHMEM_BARRIER_ALL
  SUM = 0.0
  DO I = 0,NUM_PES()-1
    CALL SHMEM_REAL_GET(WORK, VALUES, 1, I)
    SUM = SUM + WORK
  ENDDO
  PRINT *, 'PE ', MY_PE(), ' SUMA CALCULADA=', SUM
  CALL SHMEM_BARRIER_ALL
END
