NOMBRE

shutdown - Detener, apagar o reiniciar la máquina

SINOPSIS

shutdown [OPCIONES...] [HORA] [MENSAJE]

DESCRIPCIÓN

shutdown puede ser utilizado para detener, apagar o reiniciar la máquina.

El primer argumento puede ser una cadena de tiempo (que usualmente es "now"). Opcionalmente, esto puede ser seguido por un mensaje de difusión para ser enviado a todos los usuarios conectados antes de apagar.

La cadena de tiempo puede estar en el formato "hh:mm" para hora/minutos especificando la hora a la que ejecutar el apagado, especificada en formato de reloj de 24 horas. Alternativamente, puede estar en la sintaxis "+m" refiriéndose al número especificado de minutos m a partir de ahora. "now" es un alias para "+0", es decir, para activar un apagado inmediato. Si no se especifica ningún argumento de tiempo, se implica "+1".

Tenga en cuenta que para especificar un mensaje de difusión, debe especificar también un argumento de tiempo.

Si se utiliza el argumento de tiempo, 5 minutos antes de que el sistema se apague, se crea el archivo /run/nologin para asegurar que no se permitan más inicios de sesión.

OPCIONES

Se entienden las siguientes opciones:

--help

Imprime un breve texto de ayuda y sale.

-H, --halt

Detiene la máquina.

-P, --poweroff

Apaga la máquina (por defecto).

-r, --reboot

Reinicia la máquina.

-h

Lo mismo que --poweroff, pero no anula la acción a tomar si es "halt". Por ejemplo, shutdown --reboot -h significa "poweroff", pero shutdown --halt -h significa "halt".

-k

No detiene, apaga ni reinicia, sino que solo escribe el mensaje de difusión.

--no-wall

No envía mensaje de difusión antes de detener, apagar o reiniciar.

-c

Cancela un apagado pendiente. Esto puede ser utilizado para cancelar el efecto de una invocación de shutdown con un argumento de tiempo que no sea "+0" o "now".

--show

Muestra una acción de apagado pendiente y la hora si existe alguna.

Añadido en la versión 250.

ESTADO DE SALIDA

En caso de éxito, se devuelve 0, de lo contrario, un código de error distinto de cero.

COMPATIBILIDAD

El comando shutdown en sistemas init anteriores (incluido sysvinit) provocaba el modo de un solo usuario en lugar de apagar la máquina. Para cambiar al modo de un solo usuario, use systemctl rescue en su lugar.
