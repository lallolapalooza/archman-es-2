SHA512SUM(1) Comandos de usuario SHA512SUM(1)

NOMBRE

sha512sum - calcular y verificar el resumen de mensajes SHA512

SINOPSIS

sha512sum [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Imprime o verifica sumas de control SHA512 (de 512 bits).

Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar.

-b, --binario
leer en modo binario
-c, --comprobar
leer las sumas de control de los ARCHIVO(s) y verificarlos
--etiqueta
crear una suma de control estilo BSD
-t, --texto
leer en modo texto (predeterminado)
-z, --cero
terminar cada línea de salida con NUL, no con nueva línea, y deshabilitar el escape de nombres de archivo

Las cinco siguientes opciones son útiles solo al verificar sumas de control:

--ignorar-faltantes
no fallar ni informar el estado de archivos faltantes
--silencioso
no imprimir OK para cada archivo verificado correctamente
--estado
no generar ninguna salida, el código de estado muestra el éxito
--estricto
salir con un valor no cero para líneas de suma de control mal formateadas
-w, --advertir
advertir sobre líneas de suma de control mal formateadas
--ayuda
mostrar esta ayuda y salir
--version
mostrar información de versión y salir

Las sumas se calculan como se describe en FIPS-180-2. Al comprobar, la entrada debe ser una salida anterior de este programa. El modo predeterminado es imprimir una línea con: suma de control, un espacio, un carácter que indica el modo de entrada ('*' para binario, ' ' para texto o donde el binario es insignificante), y el nombre para cada ARCHIVO.

No hay diferencia entre el modo binario y el modo texto en sistemas GNU.
