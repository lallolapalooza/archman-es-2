shmem_comp4_xor_to_all(3), shmem_int_xor_to_all(3), shmem_int4_xor_to_all(3), shmem_int8_xor_to_all(3), shmem_long_xor_to_all(3), shmem_longlong_xor_to_all(3), shmem_short_xor_to_all(3) - Realiza una operación XOR bit a bit en arrays simétricos en el conjunto activo de PEs.

SINOPSIS

C o C++:

#include <mpp/shmem.h>
void shmem_int_xor_to_all(int *target, const int *source,
  int nreduce, int PE_start, int logPE_stride, int PE_size,
  int *pWrk, long *pSync)
void shmem_long_xor_to_all(long *target, const long *source,
  int nreduce, int PE_start, int logPE_stride, int PE_size,
  long *pWrk, long *pSync)
void shmem_longlong_xor_to_all(long long *target,
  const long long *source, int nreduce, int PE_start, int logPE_stride,
  int PE_size, long long *pWrk, long *pSync)
void shmem_short_xor_to_all(short *target, const short *source,
  int nreduce, int PE_start, int logPE_stride, int PE_size,
  short *pWrk, long *pSync)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER pSync(SHMEM_REDUCE_SYNC_SIZE)
INTEGER nreduce, PE_start, logPE_stride, PE_size
CALL SHMEM_COMP4_XOR_TO_ALL(target, source, nreduce,
& PE_start, logPE_stride, PE_size, pWrk, pSync)
CALL SHMEM_INT4_XOR_TO_ALL(target, source, nreduce,
& PE_start, logPE_stride, PE_size, pWrk, pSync)
CALL SHMEM_INT8_XOR_TO_ALL(target, source, nreduce,
& PE_start, logPE_stride, PE_size, pWrk, pSync)

DESCRIPCIÓN

Las rutinas de reducción de memoria compartida (SHMEM) calculan una o más reducciones en arrays simétricos en múltiples PEs virtuales. Una reducción realiza una operación binaria asociativa en un conjunto de valores. Para una lista de otras rutinas de reducción de SHMEM, consulte intro_shmem(3).

Al igual que con todas las rutinas colectivas de SHMEM, cada una de estas rutinas asume que solo los PEs del conjunto activo llaman a la rutina. Si un PE que no está en el conjunto activo llama a una rutina colectiva de SHMEM, el comportamiento resultante no está definido.

El argumento nreduce determina el número de reducciones separadas a realizar. El array fuente en todos los PEs del conjunto activo proporciona un elemento para cada reducción. Los resultados de las reducciones se colocan en el array destino en todos los PEs del conjunto activo. El conjunto activo se define por el triplete PE_start, logPE_stride, PE_size.

Los arrays fuente y destino pueden ser el mismo array, pero no pueden ser arrays superpuestos.

Los argumentos son los siguientes:

objetivo
Un array simétrico de longitud nreduce elementos para recibir los resultados de las operaciones de reducción. El tipo de datos de objetivo varía con la versión de la rutina de reducción que se llama y el idioma utilizado. Al llamar desde C/C++, consulte la sección SINOPSIS para obtener información sobre el tipo de datos. Al llamar desde Fortran, los tipos de datos de objetivo son los siguientes:
shmem_comp8_xor_to_all:** Complejo, con un tamaño de elemento igual a dos valores reales de 8 bytes
shmem_comp4_xor_to_all:** Complejo, con un tamaño de elemento igual a dos valores reales de 4 bytes

shmem_int8_xor_to_all:** Entero, con un tamaño de elemento de 8 bytes

shmem_int4_xor_to_all:** Entero, con un tamaño de elemento de 4 bytes

shmem_real8_xor_to_all:** Real, con un tamaño de elemento de 8 bytes

shmem_real4_xor_to_all:** Real, con un tamaño de elemento de 4 bytes

fuente
Un array simétrico, de longitud nreduce elementos, que contiene un elemento para cada operación de reducción separada. El argumento fuente debe tener el mismo tipo de datos que objetivo.
nreduce
El número de elementos en los arrays objetivo y fuente. nreduce debe ser de tipo entero. Si está utilizando Fortran, debe ser un valor entero predeterminado.
PE_start
El número PE virtual más bajo del conjunto activo de PEs. PE_start debe ser de tipo entero. Si está utilizando Fortran, debe ser un valor entero predeterminado.
logPE_stride
El logaritmo (base 2) del paso entre los números PE virtuales consecutivos en el conjunto activo. logPE_stride debe ser de tipo entero. Si está utilizando Fortran, debe ser un valor entero predeterminado.
PE_size
El número de PEs en el conjunto activo. PE_size debe ser de tipo entero. Si está utilizando Fortran, debe ser un valor entero predeterminado.
pWrk
Un array de trabajo simétrico. El argumento pWrk debe tener el mismo tipo de datos que objetivo. En C/C++, contiene max(nreduce/2 + 1, _SHMEM_REDUCE_MIN_WRKDATA_SIZE) elementos. En Fortran, contiene max(nreduce/2 + 1, SHMEM_REDUCE_MIN_WRKDATA_SIZE) elementos.
pSync
Un array de trabajo simétrico. En C/C++, pSync es de tipo long y tamaño _SHMEM_REDUCE_SYNC_SIZE. En Fortran, pSync es de tipo entero y tamaño SHMEM_REDUCE_SYNC_SIZE. Si está utilizando Fortran, debe ser un valor entero predeterminado. Cada elemento de este array debe inicializarse con el valor _SHMEM_SYNC_VALUE (en C/C++) o SHMEM_SYNC_VALUE (en Fortran) antes de que cualquiera de los PEs del conjunto activo entre en la rutina de reducción.

Los valores de los argumentos nreduce, PE_start, logPE_stride y PE_size deben ser iguales en todos los PEs del conjunto activo. Los mismos arrays objetivo y fuente, y los mismos arrays de trabajo pWrk y pSync, deben pasarse a todos los PEs del conjunto activo.

Antes de que cualquier PE llame a una rutina de reducción, debe asegurarse de que se cumplan las siguientes condiciones (la sincronización mediante una barrera u otro método suele ser necesaria para garantizar esto): Los arrays pWrk y pSync en todos los PEs del conjunto activo ya no están en uso de una llamada anterior a una rutina colectiva de SHMEM. El array objetivo en todos los PEs del conjunto activo está listo para recibir los resultados de la reducción.

Al regresar de una rutina de reducción, lo siguiente es cierto para el PE local: El array objetivo se actualiza. Los valores en el array pSync se restauran a los valores originales.

NOTAS

Los términos colectivo, simétrico y alineado en caché se definen en intro_shmem(3). Todas las rutinas de reducción de SHMEM restablecen los valores en pSync antes de devolverlos, por lo que un buffer pSync particular solo necesita inicializarse la primera vez que se utiliza.

Debe asegurarse de que el array pSync no esté siendo actualizado en ningún PE del conjunto activo mientras alguno de los PEs participa en el procesamiento de una rutina de reducción de SHMEM. Tenga cuidado con las siguientes situaciones: Si el array pSync se inicializa en tiempo de ejecución, se necesita algún tipo de sincronización para garantizar que todos los PEs del conjunto de trabajo hayan inicializado pSync antes de que cualquiera de ellos entre en una rutina de SHMEM llamada con el array de sincronización pSync. Un array pSync o pWrk puede reutilizarse en una llamada posterior a una rutina de reducción solo si ninguno de los PEs del conjunto activo todavía está procesando una rutina de reducción anterior que utilizó los mismos arrays pSync o pWrk. En general, esto solo se puede garantizar mediante algún tipo de sincronización. Sin embargo, en el caso especial de las rutinas de reducción que se llaman con el mismo conjunto activo, puede asignar dos arrays pSync y pWrk y alternar entre ellos en llamadas sucesivas.

EJEMPLOS

Ejemplo 1: Este ejemplo de Fortran inicializa estáticamente el array pSync y calcula el XOR exclusivo de la variable FOO en todos los PEs pares.

INCLUDE "mpp/shmem.fh"
INTEGER PSYNC(SHMEM_REDUCE_SYNC_SIZE)
DATA PSYNC /SHMEM_REDUCE_SYNC_SIZE*SHMEM_SYNC_VALUE/
PARAMETER (NR=1)
REAL FOO, FOOXOR, PWRK(MAX(NR/2+1,SHMEM_REDUCE_MIN_WRKDATA_SIZE))
COMMON /COM/ FOO, FOOXOR, PWRK
INTRINSIC MY_PE
IF ( MOD(MY_PE(),2) .EQ. 0) THEN
  CALL SHMEM_REAL8_XOR_TO_ALL(FOOXOR, FOO, NR, 0, 1, N$PES/2,
  & PWRK, PSYNC)
  PRINT *, 'Resultado en el PE ', MY_PE(), ' es ', FOOXOR
ENDIF

Ejemplo 2: Considere la siguiente llamada de C/C++:

#include <mpp/shmem.h>
#define NTHREADS 4
int my_pe, n_pes;
long pSync[_SHMEM_REDUCE_SYNC_SIZE];
long pWrk[NTHREADS];
int source[NTHREADS], target[NTHREADS];
int i;
my_pe = shmem_my_pe();
n_pes = shmem_n_pes();
/*
* Initialize pSync array
*/
for(i=0; i < _SHMEM_REDUCE_SYNC_SIZE; i++) {
  pSync[i] = _SHMEM_SYNC_VALUE;
}
/*
* Initialize source array
*/
for(i=0; i < NTHREADS; i++) {
  source[i] = my_pe + i;
}
/*
* Perform the XOR reduction across all PEs
*/
shmem_long_xor_to_all(target, source, NTHREADS, 0, 0, n_pes, pWrk, pSync);
/*
* All target elements will be equal after the reduction
*/
if (my_pe == 0) {
  printf("The reduction result is: %ld\n", target[0]);
}

NAME

shmem_long_xor_to_all - collective parallel XOR reduction

SYNOPSIS

#include <mpi.h>

void shmem_long_xor_to_all(long *target, const long *source, int nreduce, int PE_start, int logPE_stride, int PE_size, long *pWrk, long *pSync);

DESCRIPTION

The shmem_long_xor_to_all routine performs a parallel sum reduction. Specifically, the array of long values pointed to by source is XORed with the array of long values pointed to by target. The result is stored in the array pointed to by target.

The reduction is performed across the PEs specified by PE_start, logPE_stride, and PE_size.

nreduce specifies the number of long elements to be XORed.

PE_start defines the first PE to be included in the reduction. logPE_stride defines the stride between PEs to be included in the reduction. PE_size defines the number of PEs to be included in the reduction.

The reduction operation is performed as follows:

target[i] = target[i] ^ source[i]

for all i from 0 to nreduce-1.

pWrk is a pointer to a symmetric workspace array that is usable by the invoked parallel function. This workspace must be the same size and type as specified in the reference page for the parallel function. The size of the workspace is 2*N words, where N is the number of PEs in the reduction. pSync is a pointer to a symmetric synchronization array.

The synchronization array must be initialized to zero before the call. The synchronization array must be at least N elements in size. Where N is the number of PEs in the reduction.

Note that the pWrk and pSync arrays are pointers to symmetric arrays. This means that the same array can be passed by all PEs in the reduction group. The referenced memory must be accessible by all PEs in the group.

The values in PE_start, logPE_stride, and PE_size are used to determine the set of PEs participating in the reduction. The operation is performed only on the PEs within this set.

The result of the reduction is placed in the target array on each PE participating in the reduction.

NOTES

The shmem_long_xor_to_all routine is a collective operation. All participating PEs must call this routine. The arguments must be identical for all participating PEs.

The pWrk and pSync arrays are specific to the reduction operation being performed and are provided to avoid the need for synchronization between calls.

EXAMPLES

The following code snippet demonstrates the usage of shmem_long_xor_to_all:

#include <stdio.h>
#include <mpp/shmem.h>

int main(void) {
    long source[3];
    long target[3];
    long pWrk[2 * 3]; // Workspace for 3 PEs
    long pSync[3];    // Synchronization array for 3 PEs

    // Initialize source and target arrays
    source[0] = 10;
    source[1] = 20;
    source[2] = 30;
    target[0] = 5;
    target[1] = 15;
    target[2] = 25;

    // Initialize the synchronization array
    for (int i = 0; i < 3; i++) {
        pSync[i] = _SHMEM_SYNC_VALUE;
    }

    // Perform the reduction across all PEs
    // Assuming 3 PEs are participating (0, 1, 2)
    shmem_long_xor_to_all(target, source, 3, 0, 0, 3, pWrk, pSync);

    // Print the result on each PE
    printf("PE %d: target = [%ld, %ld, %ld]\n",
           shmem_my_pe(), target[0], target[1], target[2]);

    return 0;
}

In this example, if PE 0 has target = [5, 15, 25] and source = [10, 20, 30], and PE 1 has target = [6, 16, 26] and source = [11, 21, 31], and PE 2 has target = [7, 17, 27] and source = [12, 22, 32], the final target on each PE will be the XOR reduction of the initial target and source arrays across all PEs. For example, on PE 0, the final target[0] would be 5 ^ 6 ^ 7 = 0.

The preceding call is more efficient, but semantically equivalent to, the combination of the following calls:

shmem_long_xor_to_all(&(target[0]), &(source[0]), 1, 0, 0, 8,
  pwrk, psync);
shmem_long_xor_to_all(&(target[1]), &(source[1]), 1, 0, 0, 8,
  pwrk, psync);
shmem_long_xor_to_all(&(target[2]), &(source[2]), 1, 0, 0, 8,
  pwrk, psync);

Note that two sets of pWrk and pSync arrays are used alternately because no synchronization is done between calls.
