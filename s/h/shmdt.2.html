SHMOP(2) System Calls Manual SHMOP(2)

NOMBRE

shmat, shmdt - operaciones de memoria compartida System V

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/shm.h>
void *shmat(int shmid, const void *_Nullable shmaddr, int shmflg);
int shmdt(const void *shmaddr);

DESCRIPCIÓN

shmat()

shmat() adjunta el segmento de memoria compartida System V identificado por shmid al espacio de direcciones del proceso que llama. La dirección de adjunción se especifica mediante shmaddr con uno de los siguientes criterios:

•
Si shmaddr es NULL, el sistema elige una dirección adecuada (no utilizada) alineada a página para adjuntar el segmento.
•
Si shmaddr no es NULL y se especifica SHM_RND en shmflg, la adjunción se realiza en la dirección igual a shmaddr redondeada hacia abajo al múltiplo más cercano de SHMLBA.
•
De lo contrario, shmaddr debe ser una dirección alineada a página en la que se realiza la adjunción.

Además de SHM_RND, las siguientes banderas se pueden especificar en la máscara de bits del argumento shmflg:

SHM_EXEC (específico de Linux; desde Linux 2.6.9)
Permite la ejecución del contenido del segmento. El llamante debe tener permiso de ejecución sobre el segmento.
SHM_RDONLY
Adjunta el segmento para acceso de solo lectura. El proceso debe tener permiso de lectura para el segmento. Si no se especifica esta bandera, el segmento se adjunta para acceso de lectura y escritura, y el proceso debe tener permiso de lectura y escritura para el segmento. No existe la noción de un segmento de memoria compartida de solo escritura.
SHM_REMAP (específico de Linux)
Esta bandera especifica que el mapeo del segmento debe reemplazar cualquier mapeo existente en el rango que comienza en shmaddr y continúa durante el tamaño del segmento. (Normalmente, se produciría un error EINVAL si ya existe un mapeo en este rango de direcciones). En este caso, shmaddr no debe ser NULL.

El valor de brk(2) del proceso que llama no se altera con la adjunción. El segmento se desadjuntará automáticamente al salir del proceso. El mismo segmento puede adjuntarse como de solo lectura, de lectura/escritura y más de una vez en el espacio de direcciones del proceso.

Una llamada exitosa a shmat() actualiza los miembros de la estructura shmid_ds (ver shmctl(2)) asociada al segmento de memoria compartida de la siguiente manera:

•
shm_atime se establece en la hora actual.
•
shm_lpid se establece en el ID del proceso que llama.
•
shm_nattch se incrementa en uno.

shmdt()

shmdt() desadjunta el segmento de memoria compartida ubicado en la dirección especificada por shmaddr del espacio de direcciones del proceso que llama. El segmento a desadjuntar debe estar actualmente adjuntado con shmaddr igual al valor devuelto por la llamada a shmat() que lo adjuntó.

Tras una llamada exitosa a shmdt(), el sistema actualiza los miembros de la estructura shmid_ds asociada al segmento de memoria compartida de la siguiente manera:

•
shm_dtime se establece en la hora actual.
•
shm_lpid se establece en el ID del proceso que llama.
•
shm_nattch se decrementa en uno. Si se vuelve 0 y el segmento está marcado para eliminación, el segmento se elimina.

VALOR DEVUELTO

En caso de éxito, shmat() devuelve la dirección del segmento de memoria compartida adjuntado; en caso de error, se devuelve (void *) -1 y se establece errno para indicar el error.

En caso de éxito, shmdt() devuelve 0; en caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

shmat() puede fallar con uno de los siguientes errores:

EACCES
El proceso que llama no tiene los permisos requeridos para el tipo de adjunción solicitado y no tiene la capacidad CAP_IPC_OWNER en el espacio de nombres de usuario que rige su espacio de nombres IPC.
EIDRM
shmid apunta a un identificador eliminado.
EINVAL
Valor shmid inválido, dirección shmaddr no alineada (es decir, no alineada a página y SHM_RND no fue especificado) o inválida, o no se puede adjuntar el segmento en shmaddr, o se especificó SHM_REMAP y shmaddr era NULL.
ENOMEM
No se pudo asignar memoria para el descriptor o para las tablas de páginas.

shmdt() puede fallar con uno de los siguientes errores:

EINVAL
No hay ningún segmento de memoria compartida adjuntado en shmaddr; o, shmaddr no está alineado en un límite de página.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001, SVr4.

En SVID 3 (o quizás anterior), el tipo del argumento shmaddr se cambió de char * a const void *, y el tipo devuelto por shmat() de char * a void *.

POSIX.1-2024 cambió el código de error de (void *) -1 a SHM_FAILED.

NOTAS

Después de un fork(2), el hijo hereda los segmentos de memoria compartida adjuntados.

Después de un execve(2), todos los segmentos de memoria compartida adjuntados se desadjuntan del proceso.

Al salir con _exit(2), todos los segmentos de memoria compartida adjuntados se desadjuntan del proceso.

Usar shmat() con shmaddr igual a NULL es la forma preferida y portable de adjuntar un segmento de memoria compartida. Ten en cuenta que el segmento de memoria compartida adjuntado de esta manera puede adjuntarse en direcciones diferentes en procesos diferentes. Por lo tanto, cualquier puntero mantenido dentro de la memoria compartida debe hacerse relativo (típicamente a la dirección de inicio del segmento), en lugar de absoluto.

En Linux, es posible adjuntar un segmento de memoria compartida incluso si ya está marcado para su eliminación. Sin embargo, POSIX.1 no especifica este comportamiento y muchas otras implementaciones no lo soportan.

El siguiente parámetro del sistema afecta a shmat():

SHMLBA
Múltiplo de la dirección límite inferior del segmento. Al especificar explícitamente una dirección de adjunción en una llamada a shmat(), el llamante debe asegurarse de que la dirección sea un múltiplo de este valor. Esto es necesario en algunas arquitecturas, ya sea para garantizar un buen rendimiento de la caché de la CPU o para asegurar que las adjunciónes diferentes del mismo segmento tengan vistas consistentes dentro de la caché de la CPU. SHMLBA es normalmente algún múltiplo del tamaño de página del sistema. (En muchas arquitecturas de Linux, SHMLBA es el mismo que el tamaño de página del sistema.)

La implementación no impone ningún límite intrínseco por proceso en el número de segmentos de memoria compartida (SHMSEG).

Código fuente del programa: svshm_string.h

El siguiente archivo de cabecera es incluido por los programas "reader" y "writer":


/* svshm_string.h
   Licenciado bajo la Licencia Pública General de GNU v2 o posterior.
*/
#ifndef SVSHM_STRING_H
#define SVSHM_STRING_H
#include <err.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/sem.h>
union semun {                   /* Usado en llamadas a semctl() */
    int                 val;
    struct semid_ds     *buf;
    unsigned short      *array;
#if defined(__linux__)
    struct seminfo      *__buf;
#endif
};
#define MEM_SIZE 4096
#endif  // guarda de inclusión

Código fuente del programa: svshm_string_read.c

El programa "reader" crea un segmento de memoria compartida y un conjunto de semáforos que contiene un semáforo. Luego adjunta el objeto de memoria compartida a su espacio de direcciones e inicializa el valor del semáforo a 1. Finalmente, el programa espera a que el valor del semáforo se convierta en 0 y, después, imprime la cadena que el "writer" ha copiado en el segmento de memoria compartida.


/* svshm_string_read.c
   Licenciado bajo la Licencia Pública General de GNU v2 o posterior.
*/
#include <err.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/ipc.h>
#include <sys/sem.h>
#include <sys/shm.h>
#include "svshm_string.h"
int
main(void)
{
    int            semid, shmid;
    char           *addr;
    union semun    arg, dummy;
    struct sembuf  sop;
    /* Crear memoria compartida y conjunto de semáforos que contiene un
       semáforo.  */
    shmid = shmget(IPC_PRIVATE, MEM_SIZE, IPC_CREAT | 0600);
    if (shmid == -1)
        err(EXIT_FAILURE, "shmget");
    semid = semget(IPC_PRIVATE, 1, IPC_CREAT | 0600);
    if (semid == -1)
        err(EXIT_FAILURE, "semget");
    /* Adjuntar memoria compartida a nuestro espacio de direcciones.  */
    addr = shmat(shmid, NULL, SHM_RDONLY);
    if (addr == (void *) -1)
        err(EXIT_FAILURE, "shmat");
    /* Inicializar semáforo 0 en el conjunto con valor 1.  */
    arg.val = 1;
    if (semctl(semid, 0, SETVAL, arg) == -1)
        err(EXIT_FAILURE, "semctl");
    printf("shmid = %d\n", shmid);
    printf("semid = %d\n", semid);
    /* Esperar a que el valor del semáforo se convierta en 0.  */
    sop.sem_num = 0;
    sop.sem_op = 0;
    sop.sem_flg = 0;
    if (semop(semid, &sop, 1) == -1)
        err(EXIT_FAILURE, "semop");
    /* Imprimir la cadena de la memoria compartida.  */
    printf("%s\n", addr);
    /* Eliminar la memoria compartida y el conjunto de semáforos.  */
    if (shmctl(shmid, IPC_RMID, NULL) == -1)
        err(EXIT_FAILURE, "shmctl");
    if (semctl(semid, 0, IPC_RMID, dummy) == -1)
        err(EXIT_FAILURE, "semctl");
    exit(EXIT_SUCCESS);
}

Código fuente del programa: svshm_string_write.c

El programa writer toma tres argumentos de línea de comandos: los IDs del segmento de memoria compartida y del conjunto de semáforos que ya han sido creados por el "reader", y una cadena de texto. Adjunta el segmento de memoria compartida a su espacio de direcciones y luego decrementa el valor del semáforo a 0 para informar al "reader" de que ahora puede examinar el contenido de la memoria compartida.


/* svshm_string_write.c
   Licenciado bajo la Licencia Pública General de GNU v2 o posterior.
*/
#include <err.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/sem.h>
#include <sys/shm.h>
#include "svshm_string.h"
int
main(int argc, char *argv[])
{
    int            semid, shmid;
    char           *addr;
    size_t         size;
    struct sembuf  sop;
    if (argc != 4) {
        fprintf(stderr, "Uso: %s shmid semid string\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    size = strlen(argv[3]) + 1;  /* +1 para incluir el '\0' final */
    if (size > MEM_SIZE) {
        fprintf(stderr, "¡La cadena es demasiado grande!\n");
        exit(EXIT_FAILURE);
    }
    /* Obtener IDs de objetos de la línea de comandos.  */
    shmid = atoi(argv[1]);
    semid = atoi(argv[2]);
    /* Adjuntar memoria compartida a nuestro espacio de direcciones y copiar la cadena
       (incluyendo el byte nulo final) en la memoria.  */
    addr = shmat(shmid, NULL, 0);
    if (addr == (void *) -1)
        err(EXIT_FAILURE, "shmat");
    memcpy(addr, argv[3], size);
    /* Decrementar el semáforo a 0.  */
    sop.sem_num = 0;
    sop.sem_op = -1;
    sop.sem_flg = 0;
    if (semop(semid, &sop, 1) == -1)
        err(EXIT_FAILURE, "semop");
    exit(EXIT_SUCCESS);
}
