NOMBRE

shrinkfile - Encoge archivos en los límites de línea

SINOPSIS

shrinkfile [-nv] [-m tamaño_máx] [-s tamaño] archivo [archivo ...]

DESCRIPCIÓN

El programa shrinkfile encoge archivos a un tamaño máximo dado, preservando los datos al final del archivo. El truncamiento se realiza en los límites de línea, donde una línea es una serie de bytes que terminan con una nueva línea ("\n"). No hay restricción de longitud de línea y los archivos pueden contener cualquier dato binario.

Si la primera línea es más larga que el valor absoluto de tamaño, el archivo se truncará a longitud cero.

El tamaño máximo de archivo que shrinkfile puede manejar es 2,147,483,647 bytes.

Se crean archivos temporales en el directorio pathtmp según se establece en inn.conf. La variable de entorno "TMPDIR" puede usarse para especificar un directorio diferente.

Se añadirá una nueva línea a cualquier archivo no vacío que no termine con una nueva línea, si naturalmente el tamaño resultante del archivo no excede tamaño por esta adición.

Este programa actualmente solo es utilizado por nntpsend(8).

OPCIONES

-m tamaño_máx
Esta opción establece el tamaño máximo permitido antes de que ocurra el truncamiento.

Por defecto, tamaño_máx es el mismo que tamaño (como se establece con la opción -s). Si tamaño_máx es menor que tamaño, tamaño_máx se restablece a tamaño.

Este parámetro puede terminar con una "k", "m" o "g", indicando longitudes en kilobytes (1,024 bytes), megabytes (1,048,576 bytes) o gigabytes (1,073,741,824 bytes). También se permiten letras mayúsculas.

-n
Esta bandera se usa para determinar si algún archivo es demasiado grande. No se alterará ningún archivo en este modo.

Sale con el código de estado 0 si algún archivo es más grande que tamaño_máx (como se establece con la opción -m), y sale con el código de estado 1 en caso contrario.

-s tamaño
Por defecto, se asume que tamaño es cero y los archivos se truncan a cero bytes. Esta bandera puede usarse para cambiar el tamaño de truncamiento. Dado que el programa trunca solo en los límites de línea, el tamaño final puede ser menor que el tamaño de truncamiento especificado.

Este parámetro puede terminar con una "k", "m" o "g", indicando longitudes en kilobytes (1,024 bytes), megabytes (1,048,576 bytes) o gigabytes (1,073,741,824 bytes). También se permiten letras mayúsculas.

-v
Imprime en la salida estándar una línea de estado si un archivo fue encogido.

EJEMPLOS

Ejemplo de uso:

shrinkfile -s 4m curds
shrinkfile -s 1g -v whey
shrinkfile -s 500k -m 4m -v curds whey
if shrinkfile -n -s 100m whey; then echo "whey es demasiado grande"; fi

El primer comando encoge curds a 4 MB si es más grande que ese tamaño. El segundo comando encoge whey a 1 GB e imprime una línea de registro si el archivo es más grande que ese tamaño. El tercer comando encoge tanto curds como whey a 500 kB si son más grandes que 4 MB, e imprime una línea de registro para los archivos que ha encogido. El cuarto comando simplemente imprime una frase si "whey" es más grande que 100 MB, sin encogerlo.
