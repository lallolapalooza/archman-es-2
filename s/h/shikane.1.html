NOMBRE

shikane - configuración dinámica de salida determinista

SINOPSIS

shikane

shikane [-hV] [-o] [-c archivo]

shikane [--oneshot] [--config archivo]

DESCRIPCIÓN

shikane (/ʃiˈkaːnə/) es una herramienta dinámica de configuración de salida que se centra en la precisión y el determinismo.

Detecta y configura automáticamente las pantallas conectadas basándose en un conjunto de perfiles. Cada perfil especifica un conjunto de salidas con parámetros adicionales (por ejemplo, modo, posición, escala). Un perfil se aplicará automáticamente si todas las salidas y modos especificados pueden coincidir perfectamente con las pantallas conectadas actualmente y sus capacidades. (Ver shikane(5) para más detalles.)

Este es un equivalente en Wayland para herramientas como autorandr. Su objetivo es reemplazar completamente a kanshi, superar sus imprecisiones y añadir nuevas características. shikane funciona con compositores Wayland que soportan versiones >=3 del protocolo wlr-output-management (por ejemplo, compositores que usan wlroots v0.16).

OPCIONES

-h, --help
Imprime información de ayuda
-c, --config archivo
Ruta a un archivo de configuración
-o, --oneshot
Habilita el modo de disparo único (oneshot)

Sale después de que se haya aplicado un perfil o si no se encontró ninguna coincidencia de perfil

-s, --socket ruta
Anula la ruta predeterminada del socket IPC
-T, --timeout tiempo de espera
Espera tiempo de espera milisegundos antes de procesar cambios [predeterminado: 0]
-V, --version
Imprime información de la versión

ENTORNO

SHIKANE_LOG
Controla a qué nivel de registro shikane y sus módulos imprimen mensajes a stderr. Los niveles de registro disponibles son error, warn, info, debug y trace; ordenados de mayor a menor prioridad. Un nivel de registro inferior incluye mensajes de los superiores. Establecer SHIKANE_LOG a trace te permitirá ver todo. Establecerlo a off desactiva todo el registro.

Esta variable permite filtrar por módulos y acepta una lista separada por comas: SHIKANE_LOG=shikane=warn,shikane::matching=debug solo mostrará advertencias (warnings) y errores (errors) de shikane, excepto para el módulo de coincidencia, donde se mostrarán mensajes de registro de nivel debug y superiores.

Nota: La salida y el filtrado de registros no es una interfaz estable y puede estar sujeta a cambios en cualquier momento.

SHIKANE_LOG_STYLE
Controla si se usan colores y estilos con caracteres ANSI para la salida de registros. Los valores posibles son auto, always y never. Predeterminado es auto.
SHIKANE_LOG_TIME
Habilita el registro de marcas de tiempo prefijadas si se establece en 1.

ARCHIVOS

shikane lee su configuración de $XDG_CONFIG_HOME/shikane/config.toml por defecto. El programa sale con un error si no se encuentra ningún archivo de configuración. El formato del archivo de configuración se documenta en shikane(5).

ERRORES

Esperanzadamente, menos de 4.
