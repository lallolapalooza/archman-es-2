FBB::SharedBuf(3bobcat) Memoria compartida streambuf FBB::SharedBuf(3bobcat)

NOMBRE

FBB::SharedBuf - streambuf que interactúa con memoria compartida

SINOPSIS

#include <bobcat/sharedbuf>
Opción de enlazado: -lpthread -lbobcat

DESCRIPCIÓN

Esta clase implementa una especialización de la clase std::streambuf, permitiendo a las clases de flujo (std::istream, std::ostream, FBB::ISharedStream, FBB::OSharedStream y FBB::SharedStream) realizar operaciones de E/S en memoria compartida. Los objetos FBB::SharedBuf interactúan con objetos FBB::SharedMemory.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::streambuf, FBB::SharedEnum__ (cf. sharedmemory(3bobcat) para una descripción de esta última clase).

ENUMERACIÓN SIZEUNIT

El enum SizeUnit define las siguientes constantes simbólicas:

o
kB, representando 1024 (2**10) bytes de memoria;
o
MB, representando 1048576 (2**20) bytes de memoria;
o
GB, representando 1073741824 (2**30) bytes de memoria

CONSTRUCTORES

o
SharedBuf():
El constructor por defecto define un objeto SharedBuf de prueba que no puede ser utilizado inmediatamente para acceder a memoria compartida. Antes de que pueda ser utilizado por clases de flujo compartido como FBB::SharedStream, su miembro setMemory debe haber sido llamado primero.
o
SharedBuf(size_t maxSize, SizeUnit sizeUnit, std::ios::openmode openMode = std::ios::in | std::ios::out, size_t access = 0600):
Este constructor crea un segmento de memoria compartida con una capacidad de al menos maxSize * sizeUnit bytes.
Por defecto, el segmento de memoria compartida se abre para lectura y escritura. A diferencia de los modos de apertura utilizados para flujos de archivos, crear un flujo de memoria compartida con los modos de apertura ios::in | ios::out está bien. En este caso, el segmento de memoria compartida se crea y una vez que la información se ha escrito en la memoria compartida, también se puede leer de nuevo.
Los derechos de acceso de la memoria compartida se definen por el parámetro access, interpretado como un valor octal, utilizando la forma bien conocida (chmod(1)) para definir los derechos de acceso para propietario, grupo y otros.
Si la construcción falla, se lanza una excepción FBB::Exception.
o
SharedBuf(int id, std::ios::openmode openMode = std::ios::in | std::ios::out):
Este constructor se conecta a un segmento de memoria compartida con el ID id.
Especificar el flag ios::trunc borra inmediatamente el contenido de la memoria compartida.
Se lanza una excepción FBB::Exception si la construcción falla (por ejemplo, no existe ningún segmento de memoria compartida con el ID id).

Los constructores y operadores de asignación de copia y movimiento no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::streambuf y los valores del enum kB, MB, y GB, definidos por FBB::SharedEnum__, están disponibles.

o
void clear():
La memoria compartida se bloquea primero. Luego, todos los segmentos de datos compartidos se devuelven al sistema operativo, después de lo cual el segmento de memoria compartida se desbloquea de nuevo. Al retornar de clear, el objeto FBB::SharedMemory se reinicializa efectivamente, con offset y nReadable devolviendo 0.
o
int id() const:
Se devuelve el ID del segmento de memoria compartida.
o
void kill():
Sin bloquear la memoria compartida, se elimina la memoria compartida del objeto FBB::SharedBuf. El objeto FBB::SharedBuf queda inutilizable después de retornar de kill.
o
void memInfo(std::ostream &out):
La información sobre el objeto SharedMemory se inserta en el objeto ostream proporcionado. Se muestran los IDs de los segmentos compartidos, sus tamaños, el número máximo de segmentos de memoria compartida, el número de bytes que se pueden leer de la memoria compartida, y su capacidad de almacenamiento real, etc. La información insertada no se termina con un carácter de nueva línea final.
o
void remove():
La memoria compartida se bloquea, y la memoria compartida del objeto FBB::SharedBuf se elimina. El objeto FBB::SharedBuf queda inutilizable después de retornar de remove.
o
void setMemory(SharedMemory &&tmp):
El objeto temporal anónimo SharedMemory que se pasa a setMemory define el nuevo segmento de memoria compartida con el que interactúa el objeto FBB::SharedBuf. También puede ser llamado para reutilizar un objeto FBB::SharedBuf después de llamar a kill o remove.
o
FBB::SharedMemory &sharedMemory():
Se devuelve una referencia al objeto FBB::SharedMemory con el que interactúa el objeto FBB::SharedBuf.

FUNCIONES MIEMBRO PROTEGIDAS

o
FBB::SharedCondition attachSharedCondition(std::ios::off_type offset, std::ios::seekdir origin):
Devuelve un objeto FBB::SharedCondition(3), que interactúa con una variable de condición compartida ubicada en el desplazamiento offset (relativo a origin) en el objeto SharedMemory con el que interactúa el objeto SharedStreamBuf.
Se lanza una excepción FBB::Exception si el objeto FBB::SharedCondition no pudo ser construido.
o
FBB::SharedCondition createSharedCondition():
Devuelve un objeto FBB::SharedCondition(3), que interactúa con una variable de condición compartida recién creada que se crea en el desplazamiento actual del objeto SharedMemory con el que interactúa el objeto SharedStream (o en el primer desplazamiento del siguiente bloque de datos de memoria compartida, cf. sharedcondition(3bobcat)).
Se lanza una excepción FBB::Exception si el objeto FBB::SharedCondition no pudo ser construido.
o
void setOpenMode(std::ios::openmode flag):
El openmode del streambuf se cambia a la configuración definida por flag. Este miembro es utilizado, por ejemplo, por SharedStream::open, para adaptar el openmode de FBB::SharedBuf a los flags que se pasan a open.
o
FBB::SharedMemory &sharedMemory():
Devuelve una referencia al objeto FBB::SharedMemory con el que interactúa el objeto SharedBuf.

ERRORES

Tenga en cuenta que, por defecto, las excepciones lanzadas desde un objeto std::stream son capturadas por el propio objeto de flujo, estableciendo su indicador ios::failbit. Para permitir que las excepciones salgan de un objeto de flujo, se puede llamar a su miembro exceptions, por ejemplo, usando:

    myStream.exceptions(ios::failbit | ios::badbit | ios::eofbit);
