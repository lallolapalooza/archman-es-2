SHOTCUT(1) Comandos de usuario SHOTCUT(1)

NOMBRE

shotcut - editor de video

SINOPSIS

shotcut [opciones] [ARCHIVO]...

OPCIONES

-h, --help
Muestra esta ayuda.
-v, --version
Muestra información de la versión.
--fullscreen
Llena la pantalla con la ventana de Shotcut.
--noupgrade
Oculta el aviso de actualización y el elemento del menú.
--glaxnimate
Ejecuta Glaxnimate en lugar de Shotcut.
--gpu
Usa procesamiento de GPU.
--clear-recent
Borra recientes al salir
--appdata <directorio>
El directorio para la configuración y datos de la aplicación.
--QT_SCALE_FACTOR <número>
El factor de escala para una pantalla de alta DPI
--QT_SCREEN_SCALE_FACTORS <lista>
Una lista separada por punto y coma de factores de escala para cada pantalla
--QT_SCALE_FACTOR_ROUNDING_POLICY <cadena>
Cómo manejar una escala de visualización fraccionaria: Round, Ceil, Floor, RoundPreferFloor, PassThrough
--SDL_AUDIODRIVER <cadena>
Qué API de audio del sistema operativo usar: alsa, arts, dsp, esd, jack, pipewire, pulseaudio

Argumentos:

[ARCHIVO]...
Cero o más archivos o carpetas para abrir

INTERNET

Lo mejor es empezar en https://shotcut.org/tutorials/
