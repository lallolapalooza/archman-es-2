shikane(5) Manual de formatos de archivo shikane(5)

NOMBRE

shikane - archivo de configuración

DESCRIPCIÓN

shikane utiliza el formato de archivo TOML para su archivo de configuración y contiene una matriz de perfiles. Cada perfil es una tabla que contiene una matriz de tablas de salida.

Las palabras "salida", "display" y "monitor" pueden usarse indistintamente. Sin embargo, en el texto a continuación, se hace una distinción entre "display" y "salida". Un "display" se refiere a un monitor conectado actualmente y una "salida" se refiere a una tabla en el archivo de configuración. Lo mismo ocurre con "modo" y "modo" respectivamente. (Tenga en cuenta el peso de la fuente).

shikane selecciona los perfiles posibles automáticamente al inicio y cuando ocurre un cambio en el conjunto de pantallas conectadas actualmente. Un perfil se tiene en cuenta si cada pantalla conectada actualmente puede coincidir con al menos una salida y ninguna salida queda sin coincidir.

Una pantalla coincide con una salida si:

•
el parámetro search coincide con las propiedades de la pantalla (ver también CAMPOS DE SALIDA más abajo)
•
Y la pantalla soporta el modo que se especifica en la tabla de salida.

Después de ensamblar una lista de perfiles posibles, shikane genera todas las variantes de cada perfil. Una vez que todas las variantes han sido verificadas y ordenadas por exactitud, shikane intenta aplicarlas una tras otra hasta que una tenga éxito o no queden variantes para probar.

Las variantes son versiones ligeramente diferentes del mismo perfil.

Por ejemplo, una pantalla dada tiene un conjunto de modos compatibles: 1920x1080@60Hz y 1920x1080@50Hz. Si el modo en config.toml se especifica como "1920x1080", ambos modos se ajustarían a la especificación. En lugar de elegir solo un modo y usarlo, shikane tiene en cuenta ambos generando dos variantes basadas en el mismo perfil. Una variante utiliza el modo 1920x1080@60Hz y la otra variante utiliza el modo 1920x1080@50Hz.

Lo mismo ocurre con el parámetro de búsqueda. Si son posibles múltiples combinaciones (pantalla,salida,modo), shikane genera variantes con todas ellas.

No necesita escribir el archivo de configuración a mano. Puede usar cualquier herramienta para organizar las pantallas como desee y luego usar el comando export de shikanectl(1). Generará la configuración por usted.

FORMATO

timeout = timeout
Opcional. shikane esperará el timeout especificado (en milisegundos) cada vez que se detecte un cambio. Por lo general, no debería establecerlo ya que ralentiza a shikane. Por defecto es 0.
[[profile]]
Opcional. Inicia una nueva tabla de perfil. Se debe especificar un nombre. Ver CAMPOS DE PERFIL para más detalles.

CAMPOS DE PERFIL

name = "name"
Obligatorio. Especifica el nombre del perfil.
[[profile.output]]
Obligatorio. Añade una tabla de salida al perfil. Contiene parámetros utilizados para configurar una pantalla. Ver CAMPOS DE SALIDA para más detalles.

En sway(1), por ejemplo, los nombres y descripciones de las pantallas se pueden obtener a través de swaymsg -t get_outputs.

exec = [ "comando", ... ]
Opcional. Una matriz exec contiene un conjunto de comandos que se ejecutan cuando el perfil se aplicó correctamente. No se garantiza que se conserve el orden de ejecución. El nombre del perfil se puede recuperar de la variable de entorno $SHIKANE_PROFILE_NAME.

CAMPOS DE SALIDA

Una pantalla tiene, entre otros, los atributos nombre, vendor, model, serialnumber y description y puede parecerse a esto: "DP-1", "Empresa Foo", "FooHD-24", "12345678", "Algo Foo Algo Barra"

search = "patrón"

search = "[tipo]patrón"

search = "[[attrs]tipo]patrón"

search = [ "[[attrs]tipo]patrón", ... ]
Obligatorio. Este campo consta de 3 partes. La lista de atributos attrs al principio, el tipo de búsqueda tipo en el medio y el patrón al final.

La lista de atributos attrs define qué atributos se compararán con el patrón y cómo se ponderan. Es una secuencia de letras del conjunto {dnmvs}. Las letras corresponden a las primeras letras de los atributos enumerados anteriormente. Cada atributo no debe usarse más de una vez por campo search. El primer atributo tiene el peso más alto/mejor, el último atributo tiene el peso más bajo/peor. Para que una sola búsqueda se considere aplicable, todos los atributos deben coincidir con el patrón.

El tipo de búsqueda tipo puede ser uno de {=/%}. Los 3 tipos de búsqueda (regex(/), subcadena(%), texto completo(=)) definen cómo se compara el patrón con cada atributo en la lista attrs. Con la comparación de texto completo, los atributos dados se comparan con el patrón para igualdad. Con la comparación de subcadenas, los atributos dados deben contener el patrón como una subcadena. El peso se calcula dividiendo las longitudes de las cadenas de patrón y atributo. Las longitudes iguales se clasificarán igual que la comparación de texto completo. Con la comparación regex, el patrón se interpreta como una expresión regular. La comparación regex siempre se clasificará por debajo de los otros dos tipos de búsqueda.

La lista de atributos y el tipo de búsqueda son opcionales. Si no se especifica, el tipo de búsqueda por defecto es la comparación de texto completo y shikane intenta encontrar al menos un atributo coincidente.

Alternativamente, se pueden especificar varias búsquedas, hasta un máximo de 5, en una matriz.

enable = true | false
Obligatorio. Habilita o deshabilita la pantalla coincidente.
exec = [ "comando", ... ]
Opcional. Una matriz exec contiene un conjunto de comandos que se ejecutan cuando el perfil se aplicó correctamente. No se garantiza que se conserve el orden de ejecución. El nombre de la pantalla se puede recuperar de la variable de entorno $SHIKANE_OUTPUT_NAME.

Las opciones mode, position, scale, transform y adaptive_sync solo cambiarán las propiedades respectivas de la pantalla si se especifican (por ejemplo, la escala de una pantalla no cambiará si el campo scale no está presente).

mode = "best" | "preferred"

mode = "[!]widthxheight[@rate[Hz]]"

mode = { width = width, height = height, refresh = rate[, custom = true | false] }
Opcional. Configura la pantalla coincidente para usar el modo coincidente. Los modos son una combinación de ancho y alto (en píxeles) y una tasa de refresco (en Hz) que su pantalla puede configurar para usar. La tasa de refresco también puede ser un número de punto flotante. Una pantalla no coincidirá con una salida si la pantalla no soporta el modo especificado.

Un modo parametrizado puede declararse opcionalmente como personalizado anteponiendo un signo de exclamación (!). En este caso, shikane no intentará encontrar un modo con los mismos parámetros y simplemente enviará los valores proporcionados al compositor.

Establecer el modo a mejor o preferido le indica a shikane que elija el modo por sí mismo. El modo mejor se determina por shikane como el modo con el mayor número de píxeles, ancho, alto y tasa de refresco. La mayoría de las pantallas anuncian un modo que prefieren. Si el modo se establece en preferido, shikane seleccionará el modo preferido si existe. De lo contrario, se elegirá el mejor modo como recurso de reserva.

posición = "x,y"
Opcional. Coloca la pantalla en la posición especificada en el espacio de coordenadas global.
escala = factor
Opcional. Escala la pantalla por el factor de punto flotante especificado.
transformación = "transformación"
Opcional. Establece la transformación de la pantalla. Puede ser uno de 90, 180, 270 para una rotación; o volteado, volteado-90, volteado-180, volteado-270 para un volteo y una rotación; o normal para ninguna transformación.
adaptive_sync = verdadero | falso
Opcional. Habilita o deshabilita la sincronización adaptativa para la pantalla (también conocida como VRR, Tasa de Refresco Variable).

EJEMPLOS

Las indentaciones no son necesarias y se utilizan aquí solo para ilustrar la jerarquía.

[[perfil]]
nombre = "Empresa Foo con una pantalla vertical"
    [[perfil.salida]]
    buscar = "v=Empresa Foo"
    activar = verdadero
    modo = "1920x1080@50Hz"
    posición = "0,0"
    escala = 1.3
    [[perfil.salida]]
    buscar = "n/HDMI-[ABC]-[1-9]"
    activar = verdadero
    ejecutar = [ "echo Esta es la salida $SHIKANE_OUTPUT_NAME" ]
    posición = "1920,0"
    transformación = "270"
        [perfil.salida.modo]
        ancho = 2560
        alto = 1440
        refresco = 75
[[perfil]]
nombre = "dp personalizado-[1-9] volteado"
ejecutar = [ "echo Esta es una pantalla inusual" ]
    [[perfil.salida]]
    buscar = "/DP-[1-9]"
    activar = verdadero
    transformación = "volteado"
    posición = "0,0"
    modo = "!2000x1500@55.194Hz"

Una computadora portátil tiene una pantalla integrada que siempre está conectada.

[[perfil]]
nombre = "portátil integrada"
    [[perfil.salida]]
    buscar = "eDP-1"
    activar = verdadero
[[perfil]]
nombre = "sin integrada + HDMI"
    [[perfil.salida]]
    buscar = "n=eDP-1"
    activar = falso
    [[perfil.salida]]
    buscar = "n=HDMI-A-1"
    modo = "mejor"
    activar = verdadero

shikane te permite especificar múltiples búsquedas. De esta manera, los perfiles pueden ser lo más específicos posible.

[[perfil]]
nombre = "configuración en casa"
    [[perfil.salida]]
    buscar = "n=eDP-1"
    activar = falso
    [[perfil.salida]]
    buscar = [ "n=HDMI-A-1", "s=1234VBAM", "m=1QX04Z", "v=empresa específica" ]
    activar = verdadero
    [[perfil.salida]]
    buscar = "smv=1234abcd"
    activar = verdadero

En sway(1), por ejemplo, ejecutar puede usarse para mover espacios de trabajo a la pantalla deseada:

[[perfil]]
nombre = "doble monitor"
ejecutar = [
    "swaymsg workspace 1, mover workspace a eDP-1",
    "swaymsg workspace 2, mover workspace a DP-1" ]
salida = [
    {buscar = "eDP-1", activar = verdadero},
    {buscar = "DP-1", activar = verdadero} ]

shikane proporciona la variable $SHIKANE_PROFILE_NAME en el entorno de los procesos ejecutados del array profile.exec y la variable $SHIKANE_OUTPUT_NAME en el entorno de los procesos output.exec. Si estás usando sway(1), la última variable es especialmente útil en conjunto con swayws.

[[perfil]]
nombre = "perfil genérico"
ejecutar = ["notify-send shikane \"Perfil $SHIKANE_PROFILE_NAME aplicado\""]
    [[perfil.salida]]
    buscar = "/DP-[1-9]"
    activar = verdadero
    ejecutar = ["swayws range --numeric 1 5 $SHIKANE_OUTPUT_NAME"]
    [[perfil.salida]]
    buscar = "n%HDMI-"
    activar = verdadero
    modo = "preferido"
    ejecutar = ["swayws range --numeric 6 10 $SHIKANE_OUTPUT_NAME"]
