shutdown(2) Manual de llamadas al sistema shutdown(2)

NOMBRE

shutdown - cerrar una parte de una conexión full-dúplex

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/socket.h>
int shutdown(int sockfd, int how);

DESCRIPCIÓN

La llamada shutdown() provoca que se cierre toda o parte de una conexión full-dúplex en el socket asociado a sockfd. Si how es SHUT_RD, se deshabilitarán las recepciones futuras. Si how es SHUT_WR, se deshabilitarán las transmisiones futuras. Si how es SHUT_RDWR, se deshabilitarán tanto las recepciones como las transmisiones futuras.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EBADF
sockfd no es un descriptor de archivo válido.
EINVAL
Se especificó un valor no válido en how (pero véase BUGS).
ENOTCONN
El socket especificado no está conectado.
ENOTSOCK
El descriptor de archivo sockfd no se refiere a un socket.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, 4.4BSD (apareció por primera vez en 4.2BSD).

NOTAS

Las constantes SHUT_RD, SHUT_WR, SHUT_RDWR tienen los valores 0, 1, 2, respectivamente, y se definen en <sys/socket.h> desde glibc-2.1.91.

BUGS

Las comprobaciones de validez de how se realizan en código específico del dominio, y antes de Linux 3.7 no todos los dominios realizaban estas comprobaciones. Notablemente, los sockets de dominio UNIX simplemente ignoraban los valores no válidos. Este problema se corrigió para los sockets de dominio UNIX en Linux 3.7.

VER TAMBIÉN

close(2), connect(2), socket(2), socket(7)
