SHOWQ(8) Manual del Administrador del Sistema SHOWQ(8)

NOMBRE

showq - listar la cola de correo de Postfix

SINOPSIS

showq [opciones genéricas del demonio de Postfix]

DESCRIPCIÓN


El demonio showq(8) reporta el estado de la cola de correo de Postfix. La salida está pensada para ser formateada por el comando postqueue(1), ya que emula el comando `mailq' de Sendmail.

El demonio showq(8) también puede ejecutarse en modo independiente por el superusuario. Este modo de operación se usa para emular el comando `mailq' mientras el sistema de correo de Postfix está inactivo.

SEGURIDAD

El demonio showq(8) puede ejecutarse en una jaula chroot con privilegios bajos fijos, y no toma entrada del cliente. Su puerto de servicio es accesible para usuarios locales no confiables, por lo que el servicio puede ser susceptible a ataques de denegación de servicio.

ESTÁNDARES

Ninguno. El demonio showq(8) no interactúa con el mundo exterior.

DIAGNÓSTICOS


Los problemas y transacciones se registran en syslogd(8) o postlogd(8).

PARÁMETROS DE CONFIGURACIÓN

Los cambios en main.cf son recogidos automáticamente ya que los procesos showq(8) se ejecutan por un tiempo limitado. Use el comando "postfix reload" para acelerar un cambio.

El texto a continuación proporciona solo un resumen de parámetros. Consulte postconf(5) para más detalles, incluyendo ejemplos.

config_directory (ver salida de 'postconf -d')
La ubicación predeterminada de los archivos de configuración main.cf y master.cf de Postfix.
daemon_timeout (18000s)
Cuánto tiempo puede tardar un proceso demonio de Postfix en manejar una solicitud antes de que sea terminado por un temporizador de vigilancia incorporado.
duplicate_filter_limit (1000)
El número máximo de direcciones recordadas por el filtro de duplicados de direcciones para la expansión de alias de aliases(5) o virtual(5), o para las pantallas de cola de showq(8).
empty_address_recipient (MAILER-DAEMON)
El destinatario del correo dirigido a la dirección nula.
ipc_timeout (3600s)
El límite de tiempo para enviar o recibir información a través de un canal de comunicación interno.
max_idle (100s)
La cantidad máxima de tiempo que un proceso demonio de Postfix inactivo espera una conexión entrante antes de terminar voluntariamente.
max_use (100)
El número máximo de conexiones entrantes que un proceso demonio de Postfix servirá antes de terminar voluntariamente.
process_id (solo lectura)
El ID del proceso de un comando o proceso demonio de Postfix.
process_name (solo lectura)
El nombre del proceso de un comando o proceso demonio de Postfix.
queue_directory (ver salida de 'postconf -d')
La ubicación del directorio de cola principal de Postfix.
syslog_facility (mail)
La instalación de syslog del registro de Postfix.
syslog_name (ver salida de 'postconf -d')
Un prefijo que se antepone al nombre del proceso en los registros de syslog, de modo que, por ejemplo, "smtpd" se convierta en "prefijo/smtpd".

Disponible en Postfix versión 2.9 y posteriores:

enable_long_queue_ids (no)
Habilitar IDs de cola largos y no repetitivos (nombres de archivo de cola).

Disponible en Postfix 3.3 y posteriores:

service_name (solo lectura)
El nombre del servicio master.cf de un proceso demonio de Postfix.
