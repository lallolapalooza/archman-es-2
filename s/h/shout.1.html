SHOUT(1) Manual de comandos generales SHOUT(1)

NOMBRE

shout — cliente fuente de Icecast

SINOPSIS

shout [OPCIONES]

DESCRIPCIÓN

shout lee datos de la entrada estándar y los transmite a Icecast.

OPCIONES

--format formato
Establece el formato del stream. Puede ser "ogg", "mp3" o "webm". El valor predeterminado es "ogg".
-H host
Ver --host
-h
Ver --help
--help
Muestra la ayuda.
--host host
Establece el host de destino. El valor predeterminado es "localhost".
--mount cadena
Establece el punto de montaje. El valor predeterminado es "/example.ogg".
-P puerto
Ver --port
--pass cadena
Establece la contraseña de la fuente. El valor predeterminado es "hackme".
--port puerto
Establece el puerto de destino. Se admiten nombres simbólicos. El valor predeterminado es 8000.
--proto protocolo
Establece el protocolo. El valor predeterminado es "http".
--station-description cadena
Establece la descripción del stream.
--station-genre cadena
Establece el género del stream.
--station-meta clave=valor
Establece la información meta. Tanto la clave como el valor son cadenas arbitrarias.
--station-name cadena
Establece el nombre del stream.
--station-url cadena
Establece la URL del stream.
--tls-mode modo-tls
Establece el modo TLS. Puede ser "disabled", "auto", "auto_no_plain", "rfc2818" o "rfc2817". El valor predeterminado es "auto".

Cuando libshout se compila sin soporte TLS, solo se admiten "disabled" y "auto".

--usage uso{,uso}
Establece los usos del stream. Puede ser:
"audio"
para sub-streams de audio
"visual"
para sub-streams de imagen/vídeo (con más frecuencia combinados con "audio")
"text"
para sub-streams de texto que no sean subtítulos
"subtitle"
para sub-streams de subtítulos
"light"
para sub-streams de control de luz
"ui"
para datos de interfaz de usuario, como menús o botones de DVD
"metadata"
para sub-streams que incluyen metadatos para el stream
"application"
para sub-streams de datos específicos de la aplicación
"control"
para sub-streams que controlan la infraestructura
"complex"
para sub-streams que son en sí mismos una mezcla de otros tipos
"other"
para sub-streams de tipos no listados aquí
"unknown"
para streams que pueden contener sub-streams adicionales de naturaleza desconocida
"3d"
para streams que contienen información para reproducción 3D
"4d"
para streams que contienen información para reproducción 4D/XD
--user cadena
Establece el usuario de la fuente. El valor predeterminado es "source".

NOTAS

Si este binario está enlazado simbólicamente o enlazado físicamente con el nombre "oggfwd", proporciona compatibilidad directa con oggfwd(1).
