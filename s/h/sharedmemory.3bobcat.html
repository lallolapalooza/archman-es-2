FBB::SharedMemory(3bobcat) Memoria Compartida FBB::SharedMemory(3bobcat)

NOMBRE

FBB::SharedMemory - Estructura de memoria compartida

SINOPSIS

#include <bobcat/sharedmemory>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

La clase FBB::SharedMemory implementa una interfaz utilizable para un segmento de memoria compartida puesto a disposición por FBB::SharedSegment y supervisado por FBB::SharedPos. Es el bloque de construcción principal para FBB::SharedBuf, definiendo el 'dispositivo' al que se interconectan FBB::SharedBuf. Todas las E/S relacionadas con memoria compartida deben ser realizadas por objetos FBB::SharedMemory, que son objetos verdaderos, no residiendo ellos mismos en memoria compartida.

Un objeto FBB::SharedMemory define, se conecta y gestiona el acceso a la memoria compartida, encapsulando todas las operaciones de memoria compartida en bruto. Además de la clase FBB::SharedMemory, el archivo de cabecera bobcat/sharedmemory también define una struct SharedEnum__ definiendo enum SizeUnit dentro del espacio de nombres FBB.

La cantidad solicitada de memoria compartida es siempre un límite inferior a la cantidad máxima de memoria compartida que eventualmente puede estar disponible. Al definir un objeto SharedMemory, no toda su memoria compartida potencialmente disponible se asigna inmediatamente. La memoria compartida será asignada por el objeto SharedMemory una vez necesaria (hasta un máximo calculado).

Como ejemplo ficticio: supongamos que se solicitan 100 kB de memoria. El objeto SharedMemory mantiene entonces una tabla de, por ejemplo, 10 entradas, cada entrada controla el acceso a un bloque de memoria compartida de 10 kB. Estos bloques de 10 kB no se asignan inmediatamente, sino que se vuelven disponibles una vez que el programa lee o escribe en direcciones ubicadas en estos bloques de datos. Los bloques de datos recién asignados se inicializan a 0 bytes.

Advertencia: al construir un segmento de memoria compartida, asegúrese de que el ID del segmento se almacene en una ubicación recuperable. Esto permite que otros procesos accedan al segmento compartido. El ID del segmento compartido también es necesario para eliminar un segmento de memoria compartida. Si el ID del segmento compartido se pierde, la memoria ocupada por el segmento de memoria compartida permanece inaccesible (aunque se puede recuperar y eliminar por medios adicionales, como ipcs(1) y ipcrm(1)). El miembro id devuelve el ID de la memoria compartida actualmente supervisada por un objeto FBB::SharedMemory.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

FBB::SharedEnum__

La struct SharedEnum__ es una estructura envoltorio para enum SizeUnit, que está disponible a través de herencia en varias clases FBB::Shared*, y ofrece constantes simbólicas que definen tamaños de memoria estándar. El enum SizeUnit define las siguientes constantes simbólicas:

o
kB, representando 1024 (2**10) bytes de memoria;
o
MB, representando 1048576 (2**20) bytes de memoria;
o
GB, representando 1073741824 (2**30) bytes de memoria

CONSTRUCTORES, DESTRUCTOR

o
SharedMemory():
El constructor predeterminado define un stub vacío, que no se puede usar inmediatamente. Como la clase SharedMemory soporta la asignación por movimiento, los stubs vacíos se pueden reconfigurar fácilmente en cualquier momento después de su construcción.
o
SharedMemory(size_t maxSize, SizeUnit sizeUnit, size_t access = 0600):
Este constructor crea un segmento de memoria compartida que tiene una capacidad de al menos maxSize * sizeUnit bytes. Los derechos de acceso de la memoria compartida se definen por el parámetro access, utilizando los valores octales conocidos (de chmod(1)) para definir los derechos de acceso para el propietario, el grupo y los demás. Si la construcción tiene éxito, la memoria compartida está lista para su uso. Si la construcción falla, se lanza una FBB::Exception.
o
SharedMemory(int id):
Este constructor se conecta a un segmento de memoria compartida con el ID id. Si la construcción tiene éxito, la memoria compartida está lista para su uso. Si la construcción falla (por ejemplo, no existe un segmento de memoria compartida con el ID id), se lanza una FBB::Exception.
o
~SharedMemory():
El destructor desvincula cualquier segmento de memoria compartida adjunta del objeto FBB::SharedMemory. Si el segmento de memoria compartida está actualmente bloqueado por el objeto FBB::SharedMemory, se elimina el bloqueo.

Los constructores (y operadores de asignación) de copia y movimiento no están disponibles.

OPERADORES SOBRECARGADOS

o
std::ostream &operator<<(std::ostream &out, SharedMemory const &sharedMemory):
El operador de inserción sobrecargado inserta información sobre el objeto SharedMemory en el objeto ostream proporcionado. Se muestran los IDs de los segmentos compartidos, sus tamaños, el número máximo de segmentos de memoria compartida, el número de bytes que se pueden leer de la memoria compartida y su capacidad de almacenamiento real, etc.
o
SharedMemory &operator=(SharedMemory &&rhs):
El operador de asignación por movimiento sobrecargado está disponible. Se utiliza para definir (o redefinir) el segmento de memoria compartida con el que está interactuando un objeto FBB::SharedMemory.

FUNCIONES MIEMBRO

o
size_t blockOffset() const:
Se devuelve el desplazamiento dentro del bloque de datos del segmento compartido que coincide con el valor de retorno de offset. Se devuelve 0 si el objeto SharedMemory aún no se ha conectado a un bloque de memoria compartida (o si el desplazamiento ocurre en el desplazamiento 0 del bloque).
o
void clear():
Primero, se bloquea la memoria compartida. Luego, se eliminan todos los segmentos de datos compartidos y los datos de la propia memoria compartida se reinician para indicar que está completamente vacía. Después de esto, el segmento de memoria compartida se desbloquea nuevamente. Al regresar de clear, la memoria compartida El objeto FBB::SharedMemory se reinicializa efectivamente, con offset y nReadable devolviendo 0.
Se lanza una FBB::Exception si el objeto SharedMemory aún no se ha conectado a un bloque de memoria compartida.
o
size_t dataSegmentSize() const:
Devuelve el tamaño (en bytes) del bloque de datos de memoria compartida. Se devuelve 0 si el objeto SharedMemory aún no se ha conectado a un bloque de memoria compartida.
o
int get():
Primero, el objeto FBB::SharedMemory llama a lock para bloquear el segmento de memoria compartida. Luego, se recupera el carácter en offset y se incrementa offset. Luego se llama a unlock y se devuelve el carácter recuperado. Si offset es al menos igual a nReadable, se devuelve EOF inmediatamente.
Se lanza una FBB::Exception si el objeto SharedMemory aún no se ha conectado a un bloque de memoria compartida.
o
int id() const:
Se devuelve el ID del segmento de memoria compartida. Después de kill, id devuelve -1, indicando que el segmento compartido ya no se puede usar (tenga en cuenta que operator= se puede usar para re-inicializar el objeto FBB::SharedMemory).

SYNOPSIS

class SharedMemory {
public:
    SharedMemory(key_t key,
                 std::ios_base::openmode mode = std::ios_base::in | std::ios_base::out);
    ~SharedMemory() noexcept;
    template<typename SharedType, typename... Args>
    SharedType* install(std::streamsize* offset, Args&&... args);
    void kill();
    std::streamsize maxOffset() const;
    std::streamsize nReadable() const;
    std::streamsize offset() const;
    char* ptr();
    int put(int ch);
    template<typename Type>
    int read(Type* value);
    int read(char* data, std::streamsize len);
    template<typename Type>
    int read(std::ios::off_type offset, Type* value,
             std::ios::seekdir origin = std::ios::beg);
    void remove();
    std::ios::pos_type seek(std::ios::off_type offset,
                            std::ios::seekdir origin = std::ios::beg);
    std::streamsize showmanyc() const;
    void swap(SharedMemory& other);
    bool truncate(std::streamsize offset);
    template<typename Type>
    int write(Type const* value);
    int write(char const* data, std::streamsize len);
    template<typename Type>
    int write(std::ios::off_type offset, Type const* value,
              std::ios::seekdir origin = std::ios::beg);
};

DESCRIPTION

SharedMemory(key_t key, std::ios_base::openmode mode = std::ios_base::in | std::ios_base::out): Constructor. Opens or creates a shared memory block identified by key and opened in mode mode. The mode is a bitwise inclusive OR of open modes, which are the same as for shm_open(1). The constructor locks the shared memory block. Otherwise errno is set to the error condition returned by shm_open(1), and an FBB::Exception is thrown.
~SharedMemory() noexcept: Destructor. Unlocks the shared memory block and closes it.
o
template<typename SharedType, typename... Args> SharedType* install(std::streamsize* offset, Args&&... params):
This member was implemented as a member template, using typename SharedType and typename ...Params, allowing perfect forwarding of arguments to SharedType’s constructor.
This member installs a SharedType object at SharedMemory’s at SharedMemory’s first available offset: either at the current offset, or (if SharedType’s size is too big to fit in the current data block at offset) at the first byte of the next SharedSegment shared data block.
The actual offset where the SharedType object is installed is returned in *offset, unless a nullptr is passed as install’s first argument.
A pointer to the installed SharedType is returned, with shmem.offset pointing just beyond SharedType’s last byte.
The SharedType object is installed using placement new. E.g., the following example illustrates how a SharedMutex(3bobcat) object can be installed at the first possible location of SharedMemory shmem: 
    std::streamsize offset;
    FBB::SharedMutex *mutexPtr = shmem.install<FBB::SharedMutex>(&offset);
If the installed object must be destroyed, its destructor must explicitly be called. E.g., to destroy the Mutex pointed at by mutexPtr use mutexPtr->~SharedMutex().
An FBB::Exception is thrown if shmem could not install the object in its shared memory data blocks.
o
void kill():
Without locking the shared memory all shared memory controlled by the SharedMemory object is deleted. The SharedMemory object is unusable after returning from kill, with its id member returns -1. Nothing happens if this member is called when the SharedMemory object has not yet been connected to a shared memory block.
o
std::streamsize maxOffset() const:
The maximum possible offset that can be used with the shared memory segment is returned. The members offset and nReadable never exceed the value returned by maxOffset. 0 is returned if the SharedMemory object has not yet been connected to a shared memory block.
o
std::streamsize nReadable() const:
The number of characters (bytes) that can be read from the beginning of the shared memory is returned. 0 is returned if the SharedMemory object has not yet been connected to a shared memory block.
o
std::streamsize offset() const:
The offset within the shared memory segment (i.e., relative to the segment’s ios::beg position) is returned. 0 is returned if the SharedMemory object has not yet been connected to a shared memory block (or if the offset happens to be at the shared memory’s offset 0).
o
char* ptr():
Returns 0 if offset() == maxOffset(). Otherwise it returns a pointer to the character at index offset within the shared memory segment.
An FBB::Exception is thrown if the SharedMemory object has not yet been connected to a shared memory block.
o
int put(int ch):
After locking the appropriate shared data segment, ch is written at position offset, incrementing offset thereafter. If ch == EOF, EOF is immediately returned.
An FBB::Exception is thrown if the SharedMemory object has not yet been connected to a shared memory block.
o
int read(Type* value):
This member was implemented as a member template. It calls the next member, casting Type * to char *, and using sizeof(Type) as its second argument. The number of bytes actually read is returned. This member returns -1 if initially offset was at least equal to nReadable.
An FBB::Exception is thrown if the SharedMemory object has not yet been connected to a shared memory block.
o
int read(char* data, std::streamsize len):
While locking the appropriate shared data segment(s) at most len bytes are read from the shared memory, starting at offset. The bytes read from shared memory are stored at data. The number of bytes actually read is returned. This member returns -1 if initially offset was at least equal to nReadable.
An FBB::Exception is thrown if the SharedMemory object has not yet been connected to a shared memory block.
o
int read(std::ios::off_type offset, Type* value, std::ios::seekdir origin = std::ios::beg):
This member was implemented as a member template. After changing the SharedMemory’s offset to offset (relative to origin), it calls the first read member, passing it value. The number of bytes actually read is returned. This member returns -1 if initially offset was at least equal to nReadable.
An FBB::Exception is thrown if the SharedMemory object has not yet been connected to a shared memory block.
o
void remove():
The shared memory is locked, after which all shared memory controlled by the FBB::SharedMemory object is deleted. The FBB::SharedMemory object is unusable after returning from remove.
An FBB::Exception is thrown if the SharedMemory object has not yet been connected to a shared memory block.
o
std::ios::pos_type seek(std::ios::off_type offset, std::ios::seekdir origin = std::ios::beg):
Moves the offset position relative to way. The value -1 is returned when seeking before offset 0 or beyond maxOffset, otherwise the offset relative to the begin location of the shared memory (i.e, offset for origin == ios::beg) is returned. 0 is returned if the SharedMemory object has not yet been connected to a shared memory block (or if the offset happens to be at the shared memory’s offset 0).
o
std::streamsize showmanyc() const:
The number of characters that can be read from the current shared segment data block is returned. This member interrogates the number of readable characters in the shared memory segment. This number may change while this member is being executed. In order to receive a stable return value, calling functions should have obtained a lock on the shared memory segment before calling this member. 0 is returned if the SharedMemory object has not yet been connected to a shared memory block (or if the no characters can currently be read).
o
void swap(SharedMemory &other):
The current and other FBB::SharedMemory objects are swapped.
o
bool truncate(std::streamsize offset):
If offset is not exceeding the value returned by nReadable nReadable is changed to offset and true is returned. Otherwise false is returned, and the value returned by nReadable is not changed.
An FBB::Exception is thrown if the SharedMemory object has not yet been connected to a shared memory block.
o
int write(Type const* value):
This member was implemented as a member template. It calls the next member, casting Type const * to char const *, and using sizeof(Type) as its second argument. The number of bytes actually written is returned. This member returns -1 if initially offset was at least equal to maxOffset.
An FBB::Exception is thrown if the SharedMemory object has not yet been connected to a shared memory block.
o
int write(char const* data, std::streamsize len):
The FBB::SharedMemory object calls lock to lock the shared memory, and writes at most len bytes into the shared memory, starting at offset. Next, unlock is called. The number of bytes actually written is returned. The member function returns -1 if initially offset is equal to maxOffset.
An FBB::Exception is thrown if the SharedMemory object has not yet been connected to a shared memory block.
o
int write(std::ios::off_type offset, Type const* value, std::ios::seekdir origin = std::ios::beg):
This member was implemented as a member template. After changing the SharedMemory’s offset to offset (relative to origin), it calls the first write member, passing it value. The number of bytes actually written is returned. This member returns -1 if initially offset was at least equal to maxOffset.
An FBB::Exception is thrown if the SharedMemory object has not yet been connected to a shared memory block.
