shmem_alltoall32(3), shmem_alltoall64(3), shmem_alltoalls32(3), shmem_alltoalls64(3) - rutina colectiva donde cada PE intercambia una cantidad fija de datos con todos los demás PEs del conjunto Activo

SINOPSIS

C o C++:

#include <mpp/shmem.h>
void shmem_alltoall32(void *target, const void *source,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoall64(void *target, const void *source,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoalls32(void *target, const void *source,
  ptrdiff_t dst, ptrdiff_t sst,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoalls64(void *target, const void *source,
  ptrdiff_t dst, ptrdiff_t sst,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER dst, sst, nelems, PE_root, PE_start, logPE_stride, PE_size
INTEGER pSync(SHMEM_ALLTOALL_SYNC_SIZE)
CALL SHMEM_ALLTOALL32(target, source, nelems,
& PE_start, logPE_stride, PE_size, fIpSync)
CALL SHMEM_ALLTOALL64(target, source, nelems,
& PE_start, logPE_stride, PE_size, pSync)
CALL SHMEM_ALLTOALLS32(target, source, dst, sst, nelems,
& PE_start, logPE_stride, PE_size, pSync)
CALL SHMEM_ALLTOALLS64(target, source, dst, sst, nelems,
& PE_start, logPE_stride, PE_size, pSync)

DESCRIPCIÓN

Las rutinas shmem_alltoalls son rutinas colectivas. Cada PE del conjunto Activo intercambia nelems elementos de datos con stride de 32 bits (para shmem_alltoalls32) o 64 bits (para shmem_alltoalls64) con todos los demás PEs del conjunto. Ambos strides, dst y sst, deben ser mayores o iguales a 1. El bloque j-ésimo sst* enviado desde el PE i al PE j se coloca en el bloque i-ésimo dst* del objeto de datos destino en el PE j. Al igual que con todas las rutinas colectivas de OpenSHMEM, estas rutinas asumen que solo los PEs del conjunto Activo llaman a la rutina. Si un PE que no está en el conjunto Activo llama a una rutina colectiva de OpenSHMEM, el resultado es un comportamiento indefinido. Los valores de los argumentos dst, sst, nelems, PE_start, logPE_stride y PE_size deben ser iguales en todos los PEs del conjunto Activo. Los mismos objetos de datos de destino y origen, y el mismo array de trabajo pSync deben pasarse a todos los PEs del conjunto Activo. Antes de que cualquier PE llame a una rutina shmem_alltoalls, deben existir las siguientes condiciones (la sincronización mediante una barrera o algún otro método suele ser necesaria para garantizar esto): El array pSync en todos los PEs del conjunto Activo no está todavía en uso por una llamada anterior a una rutina shmem_alltoalls. El objeto de datos de destino en todos los PEs del conjunto Activo está listo para recibir los datos de shmem_alltoalls. Al regresar de una rutina shmem_alltoalls, lo siguiente es cierto para el PE local: Su objeto de datos simétrico de destino está completamente actualizado y los datos se han copiado desde el objeto de datos de origen. Los valores en el array pSync se restauran a los valores originales.

Los argumentos son los siguientes:

Un objeto de datos simétrico con uno de los siguientes tipos de datos:

shmem_alltoall32: Cualquier tipo no caracter que
tenga un tamaño de elemento de 32 bits. No se permiten tipos derivados de Fortran ni estructuras de C/C++.
shmem_alltoall64: Cualquier tipo no caracter que tenga un tamaño de elemento
de 64 bits. No se permiten tipos derivados de Fortran ni estructuras de C/C++.

target Un objeto de datos simétrico lo suficientemente grande como para recibir el total combinado de nelems elementos de cada PE en el conjunto Activo.

source
Un objeto de datos simétrico que contiene nelems elementos de datos para cada PE en el conjunto Activo, ordenados según el PE de destino.
dst
El stride entre elementos consecutivos del objeto de datos de destino. El stride se escala por el tamaño del elemento. Un valor de 1 indica datos contiguos. dst debe ser de tipo ptrdiff_t. Si estás usando Fortran, debe ser un valor entero predeterminado.
sst
El stride entre elementos consecutivos del objeto de datos de origen. El stride se escala por el tamaño del elemento. Un valor de 1 indica datos contiguos. sst debe ser de tipo ptrdiff_t. Si estás usando Fortran, debe ser un valor entero predeterminado.
nelems
El número de elementos a intercambiar para cada PE. nelems debe ser de tipo size_t para C/C++. Si estás usando Fortran, debe ser un valor entero predeterminado.
PE_start
El número PE virtual más bajo del conjunto activo de PEs. PE_start debe ser de tipo entero. Si estás usando Fortran, debe ser un valor entero predeterminado.
logPE_stride
El logaritmo (base 2) del stride entre números PE virtuales consecutivos en el conjunto activo. log_PE_stride debe ser de tipo entero. Si estás usando Fortran, debe ser un valor entero predeterminado.
PE_size
El número de PEs en el conjunto activo. PE_size debe ser de tipo entero. Si estás usando Fortran, debe ser un valor entero predeterminado.
pSync
Un array de trabajo simétrico. En C/C++, pSync debe ser de tipo long y tamaño _SHMEM_ALLTOALL_SYNC_SIZE. En Fortran, pSync debe ser de tipo entero y tamaño SHMEM_ALLTOALL_SYNC_SIZE. Cada elemento de este array debe inicializarse con el valor _SHMEM_SYNC_VALUE (en C/C++) o SHMEM_SYNC_VALUE (en Fortran) antes de que cualquiera de los PEs del conjunto activo entre en shmem_barrier().

Al regresar de una rutina shmem_alltoalls, lo siguiente es cierto para el PE local: Su objeto de datos simétrico de destino está completamente actualizado y los datos se han copiado desde el objeto de datos de origen. Los valores en el array pSync se restauran a los valores originales.

Los valores de los argumentos PE_root, PE_start, logPE_stride y PE_size deben ser iguales en todos los PEs del conjunto activo. Los mismos objetos de datos de destino y origen, y el mismo array de trabajo pSync deben pasarse a todos los PEs del conjunto activo.

Antes de que cualquier PE llame a una rutina alltoall, debes asegurarte de que las siguientes condiciones existen (la sincronización mediante una barrera o algún otro método suele ser necesaria para garantizar esto): El array pSync en todos los PEs del conjunto activo no está siendo utilizado por una llamada anterior a una rutina alltoall. El array de destino en todos los PEs del conjunto activo está listo para aceptar los datos de alltoall.

NOTAS

Los términos colectiva y simétrica se definen en intro_shmem(3).

Todas las rutinas SHMEM alltoall restauran pSync a su contenido original. Las llamadas múltiples a rutinas SHMEM que utilizan el mismo array pSync no requieren que pSync se reinicialice después de la primera llamada.

Debes asegurarte de que el array pSync no está siendo actualizado por ningún PE del conjunto activo mientras alguno de los PEs participa en el procesamiento de una rutina de difusión SHMEM. Ten cuidado de evitar estas situaciones: Si el array pSync se inicializa en tiempo de ejecución, se necesita algún tipo de sincronización para asegurar que todos los PEs del conjunto de trabajo han inicializado pSync antes de que cualquiera de ellos entre en una rutina SHMEM llamada con el array de sincronización pSync. Un array pSync puede ser reutilizado en una rutina de difusión SHMEM posterior solo si ninguno de los PEs del conjunto activo todavía está procesando una llamada anterior a la rutina SHMEM alltoall que utilizó el mismo array pSync. En general, esto solo se puede garantizar realizando algún tipo de sincronización. Sin embargo, en el caso especial de las rutinas SHMEM que se llaman con el mismo conjunto activo, puedes asignar dos arrays pSync y alternar entre ellos en llamadas sucesivas.

SYNOPSIS

#include <shmem.h>
int shmem_alltoalls64(void *dest, const void *source, ptrdiff_t dst_stride,
       ptrdiff_t src_stride, size_t nelems, int PE_start, int PE_end,
       long long id, void *pSync);

DESCRIPTION

The shmem_alltoalls64 collective routine performs an all-to-all exchange of data between processing elements (PEs).

Each PE sends the same contiguous block of data (specified by source, src_stride, and nelems) to every other PE in the symmetric heap. Each PE receives data from every other PE and concatenates it into the buffer specified by dest (specified by dest, dst_stride, and nelems).

dest points to the destination buffer on each PE. source points to the source buffer on each PE.

dst_stride specifies the stride between elements in the destination buffer. src_stride specifies the stride between elements in the source buffer.

nelems specifies the number of elements to be sent/received by each PE.

PE_start and PE_end define the range of PEs that will participate in the all-to-all exchange. The range includes PEs from PE_start up to and including PE_end.

id specifies the type of data being transferred. shmem_alltoalls64 operates on 64-bit data elements.

pSync is a pointer to a synchronization array. This array must be initialized to SHMEM_SYNC_VALUE on all participating PEs before the call. The size of this array must be at least SHMEM_ALLTOALLS_SYNC_SIZE.

The function uses 64-bit addressing, suitable for large data transfers.

NOTES

The shmem_alltoalls64 routine is a collective operation. All participating PEs must call this routine. The behavior is undefined if PEs outside the specified range PE_start to PE_end call this routine.

The dest and source buffers must be allocated using symmetric memory allocation routines such as shmem_malloc.

The synchronization array pSync prevents overwriting data that is still in use by the communication operation. It is crucial that all PEs participating in the communication synchronize on this array before and after the call to shmem_alltoalls64.

The id parameter distinguishes between different types of communication operations. For shmem_alltoalls64, this parameter should be set to 1 for 64-bit data types.

EXAMPLES

// Example usage of shmem_alltoalls64

#include <shmem.h>
#include <stdio.h>
#include <stdlib.h>

#define COUNT 4
#define SYNC_SIZE 1024 // Minimum size for pSync

int main(void) {
    long long *source, *dest;
    long long pSync[SYNC_SIZE];
    int pe, i;
    int num_pes = shmem_n_pes();
    int my_pe = shmem_my_pe();

    /* Allocate symmetric memory for source and destination buffers */
    source = (long long *)shmem_malloc(num_pes * COUNT * sizeof(long long));
    dest = (long long *)shmem_malloc(num_pes * COUNT * sizeof(long long));

    if (!source || !dest) {
        fprintf(stderr, "[%d] Failed to allocate symmetric memory\n", my_pe);
        shmem_finalize();
        return 1;
    }

    /* Initialize source buffer */
    for (pe = 0; pe < num_pes; pe++) {
        for (i = 0; i < COUNT; i++) {
            source[(pe * COUNT) + i] = my_pe + pe;
            dest[(pe * COUNT) + i] = 9999; // Initialize dest with dummy values
        }
    }

    /* Initialize the synchronization array */
    for (i = 0; i < SYNC_SIZE; i++) {
        pSync[i] = SHMEM_SYNC_VALUE;
    }

    /* Wait for all PEs to initialize pSync */
    shmem_barrier_all();

    /* Perform the all-to-all exchange */
    /* shmem_alltoalls64(dest, source, dst_stride, src_stride, nelems, PE_start, PE_end, id, pSync); */
    /* Here, dst_stride = 1, src_stride = 1, nelems = COUNT, PE_start = 0, PE_end = num_pes - 1, id = 1 (for 64-bit) */
    shmem_alltoalls64(dest, source, 1, 1, COUNT, 0, num_pes - 1, 1, pSync);

    /* Verify results */
    for (pe = 0; pe < num_pes; pe++) {
        for (i = 0; i < COUNT; i++) {
            // Each PE should receive the value (my_pe + pe) from PE 'pe'
            if (dest[(pe * COUNT) + i] != my_pe + pe) {
                printf("[%d] ERROR: dest[%lld]=%lld, should be %d\n",
                       my_pe, (long long)(pe * COUNT) + i, dest[(pe * COUNT) + i],
                       my_pe + pe);
            }
        }
    }

    /* Final synchronization before freeing memory and finalizing */
    shmem_barrier_all();

    shmem_free(dest);
    shmem_free(source);
    shmem_finalize();

    return 0;
}
