shmem_my_pe, my_pe, _my_pe - Devuelve el número de PE virtual del PE que llama.

SINOPSIS

C o C++:

#include <mpp/shmem.h>
int shmem_my_pe (void)
int my_pe (void)

Fortran:

include 'mpp/shmem.fh'
I = SHMEM_MY_PE ()
I = MY_PE ()

DESCRIPCIÓN

my_pe() o shmem_my_pe() devuelven el número del elemento de procesamiento (PE) del PE que llama. No acepta argumentos. El resultado es un entero entre 0 y npes - 1, donde npes es el número total de PEs que ejecutan el programa actual.
