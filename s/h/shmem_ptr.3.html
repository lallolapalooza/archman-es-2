SHMEM_PTR(3) Open MPI SHMEM_PTR(3)

shmem_ptr(3) - Devuelve un puntero a un objeto de datos en un elemento de procesamiento (PE) especificado.

SINÓPSIS

C o C++:

#include <mpp/shmem.h>
void *shmem_ptr(const void *target, int pe)

Fortran:

INCLUDE "mpp/shmem.fh"
POINTER (PTR, POINTEE)
INTEGER pe
PTR = SHMEM_PTR(target, pe)

DESCRIPCIÓN

La rutina shmem_ptr devuelve una dirección que se puede usar para referenciar directamente target en el PE remoto pe. Con esta dirección podemos realizar cargas y almacenamientos ordinarios a la dirección remota.

Cuando una secuencia de cargas (gets) y almacenamientos (puts) a un objeto de datos en un PE remoto no coincide con el patrón de acceso proporcionado en una rutina de transferencia de datos SHMEM como shmem_put32(3) o shmem_real_iget(3), la función shmem_ptr puede proporcionar un medio eficiente para lograr la comunicación.

Los argumentos son los siguientes:

target
El objeto de datos simétrico a referenciar.
pe
Un entero que indica el número de PE en el que se va a acceder a target. Si está usando Fortran, debe ser un valor entero predeterminado.

EJEMPLOS

Este programa Fortran llama a shmem_ptr y luego el PE 0 escribe en el array BIGD en el PE 1:

PROGRAM REMOTEWRITE
  INCLUDE 'mpp/shmem.fh'
  INTEGER BIGD(100)
  SAVE BIGD
  INTEGER POINTEE(*)
  POINTER (PTR,POINTEE)
  CALL START_PES(0)
  IF (MY_PE() .EQ. 0) THEN
                             ! inicializa el array BIGD del PE 1
    PTR = SHMEM_PTR(BIGD, 1) ! obtiene la dirección del BIGD del PE 1
                             ! array
    DO I=1,100
      POINTEE(I) = I
    ENDDO
  ENDIF
  CALL SHMEM_BARRIER_ALL
  IF (MY_PE() .EQ. 1) THEN
    PRINT *, 'BIGD en PE 1 es: '
    PRINT *, BIGD
  ENDIF
END

Este es el programa equivalente escrito en C:

#include <mpp/shmem.h>
main()
{
  static int bigd[100];
  int *ptr;
  int i;
  shmem_init();
  if (shmem_my_pe() == 0) {
  /* inicializa el array bigd del PE 1 */
    ptr = shmem_ptr(bigd, 1);
    for (i=0; i<100; i++)
      *ptr++ = i+1;
  }
  shmem_barrier_all();
  if (shmem_my_pe() == 1) {
    printf("bigd en PE 1 es:\n");
    for (i=0; i<100; i++)
      printf(" %d\n",bigd[i]);
    printf("\n");
  }
}

NOTAS

La función shmem_ptr está disponible solo en sistemas donde las cargas y almacenamientos de memoria ordinarios se utilizan para implementar las operaciones de put y get de SHMEM.

VALORES DE RETORNO

shmem_ptr devuelve un puntero al objeto de datos en el PE remoto especificado. Si target no es accesible remotamente, se devuelve un puntero NULL.
