NOMBRE

showfigfonts - imprime una lista de fuentes figlet disponibles

SINOPSIS

showfigfonts [ -d directorio ] [ palabra ]

DESCRIPCIÓN

Imprime una lista de fuentes figlet disponibles, junto con una muestra de cada fuente. Si se proporciona un directorio, lista las fuentes en ese directorio; de lo contrario, utiliza el directorio de fuentes predeterminado. Si se proporciona una palabra, imprime esa palabra en cada fuente; de lo contrario, imprime el nombre de la fuente.

EJEMPLOS

Para usar showfigfonts con su configuración predeterminada, simplemente escriba

ejemplo% showfigfonts

Para imprimir todas las fuentes en /usr/share/fonts/figlet

ejemplo% showfigfonts -d /usr/share/fonts/figlet

Para imprimir la palabra "foo" usando todas las fuentes disponibles

ejemplo% showfigfonts foo
