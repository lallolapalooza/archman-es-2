SHMCTL(3P) Manual del programador POSIX SHMCTL(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

shmctl — operaciones de control de memoria compartida XSI

SINOPSIS

#include <sys/shm.h>
int shmctl(int shmid, int cmd, struct shmid_ds *buf);

DESCRIPCIÓN

La función shmctl() opera sobre memoria compartida XSI (consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 3.346, Objeto de memoria compartida). No se especifica si esta función interactúa con las facilidades de comunicación entre procesos en tiempo real definidas en la Sección 2.8, Tiempo Real.

La función shmctl() proporciona una variedad de operaciones de control de memoria compartida según lo especificado por cmd. Los siguientes valores para cmd están disponibles:

IPC_STAT
Coloca el valor actual de cada miembro de la estructura de datos shmid_ds asociada con shmid en la estructura apuntada por buf. Los contenidos de la estructura se definen en <sys/shm.h>.
IPC_SET
Establece el valor de los siguientes miembros de la estructura de datos shmid_ds asociada con shmid al valor correspondiente encontrado en la estructura apuntada por buf:
shm_perm.uid
shm_perm.gid
shm_perm.mode    Nueve bits de orden inferior.

Además, la marca de tiempo shm_ctime se establecerá a la hora actual, como se describe en la Sección 2.7.1, Descripción General de IPC.

IPC_SET solo puede ser ejecutado por un proceso que tenga un ID de usuario efectivo igual al de un proceso con privilegios apropiados o al valor de shm_perm.cuid o shm_perm.uid en la estructura de datos shmid_ds asociada con shmid.

IPC_RMID
Elimina el identificador de memoria compartida especificado por shmid del sistema y destruye el segmento de memoria compartida y la estructura de datos shmid_ds asociada a él. IPC_RMID solo puede ser ejecutado por un proceso que tenga un ID de usuario efectivo igual al de un proceso con privilegios apropiados o al valor de shm_perm.cuid o shm_perm.uid en la estructura de datos shmid_ds asociada con shmid.

VALOR DE RETORNO

Al finalizar con éxito, shmctl() devolverá 0; de lo contrario, devolverá -1 y establecerá errno para indicar el error.

ERRORES

La función shmctl() fallará si:

EACCES
El argumento cmd es igual a IPC_STAT y el proceso que llama no tiene permiso de lectura; consulte la Sección 2.7, Comunicación entre procesos XSI.
EINVAL
El valor de shmid no es un identificador de memoria compartida válido, o el valor de cmd no es un comando válido.
EPERM
El argumento cmd es igual a IPC_RMID o IPC_SET y el ID de usuario efectivo del proceso que llama no es igual al de un proceso con privilegios apropiados y no es igual al valor de shm_perm.cuid o shm_perm.uid en la estructura de datos asociada con shmid.

La función shmctl() puede fallar si:

EOVERFLOW
El argumento cmd es IPC_STAT y el valor gid o uid es demasiado grande para almacenarse en la estructura apuntada por el argumento buf.

shmctl(3p)

NOMBRE

shmctl - shmat, shmctl, shmdt, shmget - interfaz de memoria compartida entre procesos (IS)

SINOPSIS

#include <sys/types.h>
#include <sys/ipc.h>
#include <sys/shm.h>

int shmget(key_t key, size_t size, int shmflg);
int shmctl(int shmid, int cmd, struct shmid_ds *buf);
char *shmat(int shmid, const void *shmaddr, int shmflg);
int shmdt(const void *shmaddr);

DESCRIPCIÓN

Estas funciones proporcionan una forma de crear, eliminar, adjuntar y desadjuntar segmentos de memoria compartida entre procesos.

shmget()

La función shmget devuelve un identificador de segmento de memoria compartida asociado con key. Si key es IPC_PRIVATE, se crea un nuevo segmento de memoria compartida y se devuelve su identificador.

El argumento size especifica el tamaño del segmento de memoria compartida en bytes.

El argumento shmflg es un campo de bits que controla la creación y el acceso al segmento. Puede incluir:

  • IPC_CREAT: Crea el segmento si no existe.
  • IPC_EXCL: Si se usa con IPC_CREAT, falla si el segmento ya existe.
  • Permisos de acceso (0666): Especifican los permisos de lectura y escritura para el propietario, grupo y otros.

shmctl()

La función shmctl realiza operaciones de control sobre un segmento de memoria compartida identificado por shmid.

El argumento cmd especifica la operación a realizar:

  • IPC_STAT: Copia la información del segmento en la estructura shmid_ds apuntada por buf.
  • IPC_SET: Establece el propietario y los permisos del segmento utilizando la información de buf. Solo el superusuario o el propietario del segmento pueden usar esta opción.
  • IPC_RMID: Elimina el segmento de memoria compartida. Solo el superusuario o el propietario del segmento pueden usar esta opción.

La estructura shmid_ds contiene información sobre el segmento de memoria compartida, como su tamaño, propietario, permisos, etc.

shmat()

La función shmat adjunta el segmento de memoria compartida identificado por shmid al espacio de direcciones del proceso llamante. Devuelve un puntero al segmento adjunto.

El argumento shmaddr puede ser utilizado para especificar una dirección deseada para adjuntar el segmento. Si es NULL, el sistema elige una dirección disponible.

El argumento shmflg puede ser:

  • SHM_RND: Redondea la dirección de adjunción.
  • SHM_RDONLY: Adjunta el segmento en modo de solo lectura.
  • SHM_REMAP: Remapea un segmento existente.

shmdt()

La función shmdt desadjunta el segmento de memoria compartida asociado con la dirección apuntada por shmaddr del espacio de direcciones del proceso llamante.

VALORES DEVUELTOS

Si se produce un error, todas estas funciones devuelven -1 y establecen errno para indicar el error.

ERRORES

Se pueden producir varios errores, incluyendo:

  • EACCES: Permisos insuficientes para acceder al segmento.
  • EEXIST: El segmento ya existe (con IPC_CREAT y IPC_EXCL).
  • EINVAL: Identificador inválido o key inválida.
  • ENFILE: Se ha alcanzado el límite máximo de archivos abiertos.
  • ENOENT: El segmento no existe.
  • ENOMEM: Memoria insuficiente para adjuntar el segmento.
  • ENOSPC: No hay espacio suficiente en el sistema para el segmento solicitado.
  • EPERM: Permisos insuficientes para la operación solicitada con shmctl.

CONFORME A

POSIX.1-2001, POSIX.1-2008, SVr4, X/OPEN.
