SHMEM_ALLTOALLS32(3) Open MPI SHMEM_ALLTOALLS32(3)

shmem_alltoall32(3), shmem_alltoall64(3), shmem_alltoalls32(3), shmem_alltoalls64(3) - rutina colectiva donde cada PE intercambia una cantidad fija de datos con todos los demás PEs en el conjunto Activo

SINOPSIS

C o C++:

#include <mpp/shmem.h>
void shmem_alltoall32(void *target, const void *source,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoall64(void *target, const void *source,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoalls32(void *target, const void *source,
  ptrdiff_t dst, ptrdiff_t sst,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoalls64(void *target, const void *source,
  ptrdiff_t dst, ptrdiff_t sst,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER dst, sst, nelems, PE_root, PE_start, logPE_stride, PE_size
INTEGER pSync(SHMEM_ALLTOALL_SYNC_SIZE)
CALL SHMEM_ALLTOALL32(target, source, nelems,
& PE_start, logPE_stride, PE_size, fIpSync)
CALL SHMEM_ALLTOALL64(target, source, nelems,
& PE_start, logPE_stride, PE_size, pSync)
CALL SHMEM_ALLTOALLS32(target, source, dst, sst, nelems,
& PE_start, logPE_stride, PE_size, pSync)
CALL SHMEM_ALLTOALLS64(target, source, dst, sst, nelems,
& PE_start, logPE_stride, PE_size, pSync)

DESCRIPCIÓN

Las rutinas shmem_alltoalls son rutinas colectivas. Cada PE en el conjunto Activo intercambia nelems elementos de datos con pasos (strided) de 32 bits (para shmem_alltoalls32) o 64 bits (para shmem_alltoalls64) con todos los demás PEs en el conjunto. Ambos pasos, dst y sst, deben ser mayores o iguales a 1. El bloque j-ésimo de tamaño sst enviado desde el PE i al PE j se coloca en el bloque i-ésimo de tamaño dst del objeto de datos destino en el PE j. Al igual que con todas las rutinas colectivas de OpenSHMEM, estas rutinas asumen que solo los PEs en el conjunto Activo llaman a la rutina. Si un PE no está en el conjunto Activo y llama a una rutina colectiva de OpenSHMEM, el resultado es un comportamiento indefinido. Los valores de los argumentos dst, sst, nelems, PE_start, logPE_stride y PE_size deben ser iguales en todos los PEs del conjunto Activo. Los mismos objetos de datos destino y fuente, y el mismo array de trabajo pSync deben pasarse a todos los PEs del conjunto Activo. Antes de que cualquier PE llame a una rutina shmem_alltoalls, deben existir las siguientes condiciones (la sincronización mediante una barrera u otro método a menudo es necesaria para asegurar esto): El array pSync en todos los PEs del conjunto Activo no está todavía en uso debido a una llamada anterior a una rutina shmem_alltoalls. El objeto de datos destino en todos los PEs del conjunto Activo está listo para recibir los datos de shmem_alltoalls. Al regresar de una rutina shmem_alltoalls, lo siguiente es verdadero para el PE local: Su objeto de datos simétrico destino está completamente actualizado y los datos se han copiado fuera del objeto de datos fuente. Los valores en el array pSync se restauran a los valores originales.

Los argumentos son los siguientes:

Un objeto de datos simétrico con uno de los siguientes tipos de datos:

shmem_alltoall32: Cualquier tipo no carácter que
tenga un tamaño de elemento de 32 bits. No se permiten tipos derivados de Fortran ni estructuras de C/C++.
shmem_alltoall64: Cualquier tipo no carácter que tenga un tamaño
de elemento de 64 bits. No se permiten tipos derivados de Fortran ni estructuras de C/C++.

target Un objeto de datos simétrico lo suficientemente grande como para recibir el total combinado de nelems elementos de cada PE en el conjunto Activo.

source
Un objeto de datos simétrico que contiene nelems elementos de datos para cada PE en el conjunto Activo, ordenados según el PE de destino.
dst
El paso entre elementos consecutivos del objeto de datos destino. El paso se escala por el tamaño del elemento. Un valor de 1 indica datos contiguos. dst debe ser de tipo ptrdiff_t. Si estás usando Fortran, debe ser un valor entero predeterminado.
sst
El paso entre elementos consecutivos del objeto de datos fuente. El paso se escala por el tamaño del elemento. Un valor de 1 indica datos contiguos. sst debe ser de tipo ptrdiff_t. Si estás usando Fortran, debe ser un valor entero predeterminado.
nelems
El número de elementos a intercambiar por cada PE. nelems debe ser de tipo size_t para C/C++. Si estás usando Fortran, debe ser un valor entero predeterminado.
PE_start
El número de PE virtual más bajo del conjunto activo de PEs. PE_start debe ser de tipo entero. Si estás usando Fortran, debe ser un valor entero predeterminado.
logPE_stride
El logaritmo (base 2) del paso entre números de PE virtuales consecutivos en el conjunto activo. log_PE_stride debe ser de tipo entero. Si estás usando Fortran, debe ser un valor entero predeterminado.
PE_size
El número de PEs en el conjunto activo. PE_size debe ser de tipo entero. Si estás usando Fortran, debe ser un valor entero predeterminado.
pSync
Un array de trabajo simétrico. En C/C++, pSync debe ser de tipo long y de tamaño _SHMEM_ALLTOALL_SYNC_SIZE. En Fortran, pSync debe ser de tipo entero y de tamaño SHMEM_ALLTOALL_SYNC_SIZE. Cada elemento de este array debe inicializarse con el valor _SHMEM_SYNC_VALUE (en C/C++) o SHMEM_SYNC_VALUE (en Fortran) antes de que cualquiera de los PEs del conjunto activo entre en shmem_barrier().

Al regresar de una rutina shmem_alltoalls, lo siguiente es verdadero para el PE local: Su objeto de datos simétrico destino está completamente actualizado y los datos se han copiado fuera del objeto de datos fuente. Los valores en el array pSync se restauran a los valores originales.

Los valores de los argumentos PE_root, PE_start, logPE_stride y PE_size deben ser iguales en todos los PEs del conjunto activo. Los mismos objetos de datos destino y fuente, y el mismo array de trabajo pSync deben pasarse a todos los PEs del conjunto activo.

Antes de que cualquier PE llame a una rutina alltoall, debes asegurarte de que existen las siguientes condiciones (la sincronización mediante una barrera u otro método a menudo es necesaria para asegurar esto): El array pSync en todos los PEs del conjunto activo no está todavía en uso debido a una llamada anterior a una rutina alltoall. El array destino en todos los PEs del conjunto activo está listo para recibir los datos de alltoall.

NOTAS

Los términos colectivo y simétrico se definen en intro_shmem(3).

Todas las rutinas SHMEM alltoall restauran pSync a su contenido original. Múltiples llamadas a rutinas SHMEM que usan el mismo array pSync no requieren que pSync se reinicialice después de la primera llamada.

Debes asegurarte de que el array pSync no está siendo actualizado por ningún PE en el conjunto activo mientras alguno de los PEs participa en el procesamiento de una rutina de difusión SHMEM. Ten cuidado de evitar estas situaciones: Si el array pSync se inicializa en tiempo de ejecución, se necesita algún tipo de sincronización para asegurar que todos los PEs del conjunto de trabajo hayan inicializado pSync antes de que cualquiera de ellos entre en una rutina SHMEM llamada con el array de sincronización pSync. Un array pSync puede reutilizarse en una rutina de difusión SHMEM posterior solo si ninguno de los PEs del conjunto activo todavía está procesando una llamada anterior a la rutina SHMEM alltoall que usó el mismo array pSync. En general, esto solo se puede asegurar haciendo algún tipo de sincronización. Sin embargo, en el caso especial de rutinas SHMEM que se llaman con el mismo conjunto activo, puedes asignar dos arrays pSync y alternar entre ellos en llamadas sucesivas.

shmem_alltoalls64(3) — Arch manual pages

SHMEM_ALLTOALLS64

MPI routines

SYNOPSIS

#include <mpi.h>

int shmem_alltoalls64(void *dest, const void *source, int dest_stride,
                      int source_stride, int nlong, int PE_start, int PE_end,
                      long long PE_count, shmem_uintptr_t *pSync);

DESCRIPTION

The symmetric distributed memory routines provide a way to access the memory of other PE’s in a symmetric fashion. The remote PE’s memory is accessed directly, as if it were local.

The shmem_alltoalls64 routine is equivalent to the standard MPI-2 all-to-all operation. Each PE sends the same amount of data to all other PE’s, and receives the same amount of data from all other PE’s.

The arguments are:

dest
The symmetric data object that contains the data to be received.
source
The symmetric data object that contains the data to be sent.
dest_stride
The stride for the destination data object.
source_stride
The stride for the source data object.
nlong
The number of 64-bit words to be sent/received.
PE_start
The starting PE number for the communication group.
PE_end
The ending PE number for the communication group.
PE_count
The number of PE’s in the communication group.
pSync
The array of synchronization doubles.

NOTES

All processes in the default symmetric multiprocessing (SMP) group must participate in the collective communication call. The function should be called by all PEs with the same argument values, except possibly for the symmetric data objects and the synchronization array.

The synchronization array pSync is used to ensure that all processes have entered the all-to-all communication. It is an array of SHMEM_ALLTOALLS_SYNC_SIZE elements, each initialized to SHMEM_SYNC_VALUE.

The arguments PE_start, PE_end, and PE_count are used to specify the range of PEs that participate in the operation. If PE_count is negative, then the default group is used.

EXAMPLES

C
#include <shmem.h>
#include <stdio.h>

int main(void) {
    long long count = 10;
    long long *source;
    long long *dest;
    long long i, pe;
    long long *pSync;

    shmem_init();

    /* Allocate memory for source and destination arrays */
    source = (long long *) shmem_malloc(sizeof(long long) * shmem_n_pes() * count);
    dest = (long long *) shmem_malloc(sizeof(long long) * shmem_n_pes() * count);
    pSync = (long long *) shmem_malloc(sizeof(long long) * SHMEM_ALLTOALLS_SYNC_SIZE);

    /* Initialize source and destination arrays */
    for (pe = 0; pe < shmem_n_pes(); pe++) {
        for (i = 0; i < count; i++) {
            source[(pe * count) + i] = shmem_my_pe() + pe;
            dest[(pe * count) + i] = 9999;
        }
    }

    /* Initialize synchronization array */
    for (i = 0; i < SHMEM_ALLTOALLS_SYNC_SIZE; i++) {
        pSync[i] = SHMEM_SYNC_VALUE;
    }

    /* Wait for all PEs to initialize pSync */
    shmem_barrier_all();

    /* Alltoalls on all PEs */
    shmem_alltoalls64(dest, source, 1, 1, count, 0, 0, shmem_n_pes(), pSync);

    /* Verify results */
    for (pe = 0; pe < shmem_n_pes(); pe++) {
        for (i = 0; i < count; i++) {
            if (dest[(pe * count) + i] != shmem_my_pe() + pe) {
                printf("[%d] ERROR: dest[%lld]=%lld, should be %lld\n",
                       shmem_my_pe(), (pe * count) + i, dest[(pe * count) + i],
                       shmem_my_pe() + pe);
            }
        }
    }

    shmem_barrier_all();
    shmem_free(dest);
    shmem_free(source);
    shmem_finalize();
    return 0;
}
