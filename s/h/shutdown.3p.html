SHUTDOWN(3P) Manual del programador POSIX SHUTDOWN(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

shutdown — cerrar las operaciones de envío y recepción de sockets

SINOPSIS

#include <sys/socket.h>
int shutdown(int socket, int how);

DESCRIPCIÓN

La función shutdown() provocará el cierre de todas o parte de una conexión full-duplex en el socket asociado con el descriptor de archivo socket.

La función shutdown() toma los siguientes argumentos:

socket
Especifica el descriptor de archivo del socket.
how
Especifica el tipo de cierre. Los valores son los siguientes:
SHUT_RD
Deshabilita operaciones de recepción posteriores.
SHUT_WR
Deshabilita operaciones de envío posteriores.
SHUT_RDWR
Deshabilita operaciones de envío y recepción posteriores.

La función shutdown() deshabilita operaciones de envío y/o recepción posteriores en un socket, dependiendo del valor del argumento how.

VALOR DE RETORNO

Al completarse con éxito, shutdown() devolverá 0; de lo contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función shutdown() fallará si:

EBADF
El argumento socket no es un descriptor de archivo válido.
EINVAL
El argumento how es inválido.
ENOTCONN
El socket no está conectado.
ENOTSOCK
El argumento socket no se refiere a un socket.

La función shutdown() puede fallar si:

ENOBUFS
No había suficientes recursos disponibles en el sistema para realizar la operación.
