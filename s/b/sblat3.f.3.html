programa sblat3

SBLAT3

Propósito:

!>
!> Programa de prueba para BLAS de Nivel 3 REAL.
!>
!> El programa debe ser impulsado por un archivo de datos corto. Los primeros 14 registros
!> del archivo se leen usando entrada de lista dirigida, los últimos 7 registros
!> se leen usando el formato ( A7, L2 ). Un ejemplo anotado de un archivo de datos
!> se puede obtener eliminando los primeros 3 caracteres de las siguientes 20 líneas:
!> 'sblat3.out'      NOMBRE DEL ARCHIVO DE RESUMEN DE SALIDA
!> 6                 NÚMERO DE UNIDAD DEL ARCHIVO DE RESUMEN
!> 'SBLAT3.SNAP'     NOMBRE DEL ARCHIVO DE INSTANTÁNEA DE SALIDA
!> -1                NÚMERO DE UNIDAD DEL ARCHIVO DE INSTANTÁNEA (NO USADO SI .LT. 0)
!> F        BANDERA LÓGICA, T PARA REBOBINAR EL ARCHIVO DE INSTANTÁNEA DESPUÉS DE CADA REGISTRO.
!> F        BANDERA LÓGICA, T PARA DETENERSE EN CASO DE FALLOS.
!> T        BANDERA LÓGICA, T PARA PROBAR LAS SALIDAS DE ERROR.
!> 16.0     VALOR UMBRAL DE LA RELACIÓN DE PRUEBA
!> 6                 NÚMERO DE VALORES DE N
!> 0 1 2 3 5 9       VALORES DE N
!> 3                 NÚMERO DE VALORES DE ALPHA
!> 0.0 1.0 0.7       VALORES DE ALPHA
!> 3                 NÚMERO DE VALORES DE BETA
!> 0.0 1.0 1.3       VALORES DE BETA
!> SGEMM  T PARA PRUEBA. MISMAS COLUMNAS.
!> SSYMM  T PARA PRUEBA. MISMAS COLUMNAS.
!> STRMM  T PARA PRUEBA. MISMAS COLUMNAS.
!> STRSM  T PARA PRUEBA. MISMAS COLUMNAS.
!> SSYRK  T PARA PRUEBA. MISMAS COLUMNAS.
!> SSYR2K T PARA PRUEBA. MISMAS COLUMNAS.
!> SGEMMTR T PARA PRUEBA. MISMAS COLUMNAS.
!>
!> Detalles Adicionales
!> ===================
!>
!> Ver:
!>
!>    Dongarra J. J., Du Croz J. J., Duff I. S. y Hammarling S.
!>    Un conjunto de subprogramas básicos de álgebra lineal de Nivel 3.
!>
!>    Memorando Técnico No. 88 (Revisión 1), División de Matemáticas y
!>    Ciencias de la Computación, Laboratorio Nacional de Argonne, 9700
!>    South Cass Avenue, Argonne, Illinois 60439, EE. UU.
!>
!> -- Escrito el 8 de febrero de 1989.
!>    Jack Dongarra, Laboratorio Nacional de Argonne.
!>    Iain Duff, AERE Harwell.
!>    Jeremy Du Croz, Numerical Algorithms Group Ltd.
!>    Sven Hammarling, Numerical Algorithms Group Ltd.
!>

!>              puedan ejecutarse varias veces sin eliminar los archivos de salida generados
!>              (susan)
