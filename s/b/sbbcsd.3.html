SBBCSD

Propósito:

!>
!> SBBCSD calcula la descomposición CS de una matriz ortogonal en
!> forma bidiagonal-bloque,
!>
!>
!>     [ B11 | B12 0  0 ]
!>     [  0  |  0 -I  0 ]
!> X = [----------------]
!>     [ B21 | B22 0  0 ]
!>     [  0  |  0  0  I ]
!>
!>                               [  C | -S  0  0 ]
!>                   [ U1 |    ] [  0 |  0 -I  0 ] [ V1 |    ]**T
!>                 = [---------] [---------------] [---------]   .
!>                   [    | U2 ] [  S |  C  0  0 ] [    | V2 ]
!>                               [  0 |  0  0  I ]
!>
!> X es M-por-M, su bloque superior izquierdo es P-por-Q, y Q no debe ser mayor
!> que P, M-P, o M-Q. (Si Q no es el índice más pequeño, entonces X debe ser
!> transpuesta y/o permutada. Esto se puede hacer en tiempo constante usando
!> las opciones TRANS y SIGNS. Ver SORCSD para más detalles.)
!>
!> Las matrices bidiagonales B11, B12, B21 y B22 están implícitamente representadas
!> por los ángulos THETA(1:Q) y PHI(1:Q-1).
!>
!> Las matrices ortogonales U1, U2, V1T y V2T son de entrada/salida.
!> Las matrices de entrada se premultiplican o postmultiplican por las matrices
!> de vectores singulares apropiadas.
!>

Parámetros

JOBU1 
!>          JOBU1 es CHARACTER
!>          = 'Y':      U1 se actualiza;
!>          de lo contrario:  U1 no se actualiza.
!>

JOBU2

!>          JOBU2 es CHARACTER
!>          = 'Y':      U2 se actualiza;
!>          de lo contrario:  U2 no se actualiza.
!>

JOBV1T

!>          JOBV1T es CHARACTER
!>          = 'Y':      V1T se actualiza;
!>          de lo contrario:  V1T no se actualiza.
!>

JOBV2T

!>          JOBV2T es CHARACTER
!>          = 'Y':      V2T se actualiza;
!>          de lo contrario:  V2T no se actualiza.
!>

TRANS

!>          TRANS es CHARACTER
!>          = 'T':      X, U1, U2, V1T y V2T se almacenan en orden de fila principal;
!>          de lo contrario:  X, U1, U2, V1T y V2T se almacenan en orden de columna principal.
!>

M

!>          M es INTEGER
!>          El número de filas y columnas en X, la matriz ortogonal en
!>          forma bidiagonal-bloque.
!>

P

!>          P es INTEGER
!>          El número de filas en el bloque superior izquierdo de X. 0 <= P <= M.
!>

Q

!>          Q es INTEGER
!>          El número de columnas en el bloque superior izquierdo de X.
!>          0 <= Q <= MIN(P,M-P,M-Q).
!>

THETA

!>          THETA es array REAL, dimensión (Q)
!>          En la entrada, los ángulos THETA(1),...,THETA(Q) que, junto con
!>          PHI(1), ...,PHI(Q-1), definen la matriz en forma bidiagonal-bloque.
!>          En la salida, los ángulos cuyos cosenos y senos definen los
!>          bloques diagonales en la descomposición CS.
!>

PHI

!>          PHI es array REAL, dimensión (Q-1)
!>          Los ángulos PHI(1),...,PHI(Q-1) que, junto con THETA(1),...,
!>          THETA(Q), definen la matriz en forma bidiagonal-bloque.
!>

U1

!>          U1 es array REAL, dimensión (LDU1,P)
!>          En la entrada, una matriz P-por-P. En la salida, U1 se postmultiplica
!>          por la matriz de vectores singulares izquierdos común a [ B11 ; 0 ] y
!>          [ B12 0 0 ; 0 -I 0 0 ].
!>

LDU1

!>          LDU1 es INTEGER
!>          La dimensión principal del array U1, LDU1 >= MAX(1,P).
!>

U2

!>          U2 es array REAL, dimensión (LDU2,M-P)
!>          En la entrada, una matriz (M-P)-por-(M-P). En la salida, U2 se
!>          postmultiplica por la matriz de vectores singulares izquierdos común a
!>          [ B21 ; 0 ] y [ B22 0 0 ; 0 0 I ].
!>

LDU2

!>          LDU2 es INTEGER
!>          La dimensión principal del array U2, LDU2 >= MAX(1,M-P).
!>

V1T

!>          V1T es array REAL, dimensión (LDV1T,Q)
!>          En la entrada, una matriz Q-por-Q. En la salida, V1T se premultiplica
!>          por la transpuesta de la matriz de vectores singulares derechos
!>          común a [ B11 ; 0 ] y [ B21 ; 0 ].
!>

LDV1T

!>          LDV1T es INTEGER
!>          La dimensión principal del array V1T, LDV1T >= MAX(1,Q).
!>

V2T

!>          V2T es array REAL, dimensión (LDV2T,M-Q)
!>          En la entrada, una matriz (M-Q)-por-(M-Q). En la salida, V2T se
!>          premultiplica por la transpuesta de la matriz de vectores singulares
!>          derechos común a [ B12 0 0 ; 0 -I 0 ] y
!>          [ B22 0 0 ; 0 0 I ].
!>

LDV2T

!>          LDV2T es INTEGER
!>          La dimensión principal del array V2T, LDV2T >= MAX(1,M-Q).
!>

B11D

!>          B11D es array REAL, dimensión (Q)
!>          Cuando SBBCSD converge, B11D contiene los cosenos de THETA(1),
!>          ..., THETA(Q). Si SBBCSD no converge, entonces B11D
!>          contiene la diagonal del bloque superior izquierdo parcialmente reducido.
!>

B11E

!>          B11E es array REAL, dimensión (Q-1)
!>          Cuando SBBCSD converge, B11E contiene ceros. Si SBBCSD no
!>          converge, entonces B11E contiene la superdiagonal del
!>          bloque superior izquierdo parcialmente reducido.
!>

B12D

!>          B12D es array REAL, dimensión (Q)
!>          Cuando SBBCSD converge, B12D contiene los senos negativos de
!>          THETA(1), ..., THETA(Q). Si SBBCSD no converge, entonces
!>          B12D contiene la diagonal del bloque superior derecho parcialmente reducido.
!>

B12E

!>          B12E es array REAL, dimensión (Q-1)
!>          Cuando SBBCSD converge, B12E contiene ceros. Si SBBCSD no
!>          converge, entonces B12E contiene la subdiagonal del
!>          bloque superior derecho parcialmente reducido.
!>

B21D

!>          B21D es array REAL, dimensión (Q)
!>          Cuando SBBCSD converge, B21D contiene los senos negativos de
!>          THETA(1), ..., THETA(Q). Si SBBCSD no converge, entonces
!>          B21D contiene la diagonal del bloque inferior izquierdo parcialmente reducido.
!>

B21E

!&g
