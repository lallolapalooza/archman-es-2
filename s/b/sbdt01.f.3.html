DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina sbdt01 (integer m, integer n, integer kd, real, dimension( lda, * ) a, integer lda, real, dimension( ldq, * ) q, integer ldq, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldpt, * ) pt, integer ldpt, real, dimension( * ) work, real resid)

SBDT01

Propósito:

!>
!> SBDT01 reconstruye una matriz general A a partir de su forma
!> bidiagonal
!>    A = Q * B * P**T
!> donde Q (m por min(m,n)) y P**T (min(m,n) por n) son matrices ortogonales
!> y B es bidiagonal.
!>
!> La relación de prueba para probar la reducción es
!>    RESID = norm(A - Q * B * P**T) / ( n * norm(A) * EPS )
!> donde EPS es la precisión de la máquina.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de las matrices A y Q.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices A y P**T.
!>

KD

!>          KD es ENTERO
!>          Si KD = 0, B es diagonal y el array E no se referencia.
!>          Si KD = 1, la reducción fue realizada por xGEBRD; B es
!>          bidiagonal superior si M >= N, y bidiagonal inferior si M < N.
!>          Si KD = -1, la reducción fue realizada por xGBBRD; B es
!>          siempre bidiagonal superior.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          La matriz A de m por n.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

Q

!>          Q es un array REAL, dimensión (LDQ,N)
!>          La matriz ortogonal Q de m por min(m,n) en la reducción
!>          A = Q * B * P**T.
!>

LDQ

!>          LDQ es ENTERO
!>          La dimensión principal del array Q.  LDQ >= max(1,M).
!>

D

!>          D es un array REAL, dimensión (min(M,N))
!>          Los elementos diagonales de la matriz bidiagonal B.
!>

E

!>          E es un array REAL, dimensión (min(M,N)-1)
!>          Los elementos superdiagonales de la matriz bidiagonal B si
!>          m >= n, o los elementos subdiagonales de B si m < n.
!>

PT

!>          PT es un array REAL, dimensión (LDPT,N)
!>          La matriz ortogonal P**T de min(m,n) por n en la reducción
!>          A = Q * B * P**T.
!>

LDPT

!>          LDPT es ENTERO
!>          La dimensión principal del array PT.
!>          LDPT >= max(1,min(M,N)).
!>

WORK

!>          WORK es un array REAL, dimensión (M+N)
!>

RESID

!>          RESID es REAL
!>          La relación de prueba:
!>          norm(A - Q * B * P**T) / ( n * norm(A) * EPS )
!>
