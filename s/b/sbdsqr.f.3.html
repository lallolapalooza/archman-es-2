SBDSQR

Documentación de Función/Subrutina

subrutina sbdsqr (character uplo, integer n, integer ncvt, integer nru, integer ncc, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldvt, * ) vt, integer ldvt, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer info)

SBDSQR

Propósito:

!>
!> SBDSQR calcula los valores singulares y, opcionalmente, los vectores singulares
!> derechas e/o izquierdas a partir de la descomposición en valores singulares (SVD)
!> de una matriz bidiagonal real N-por-N (superior o inferior) B utilizando el
!> algoritmo QR implícito de desplazamiento cero. La SVD de B tiene la forma
!>
!>    B = Q * S * P**T
!>
!> donde S es la matriz diagonal de valores singulares, Q es una matriz ortogonal
!> de vectores singulares izquierdos, y P es una matriz ortogonal de vectores
!> singulares derechos. Si se solicitan vectores singulares izquierdos, esta
!> subrutina en realidad devuelve U*Q en lugar de Q, y, si se solicitan vectores
!> singulares derechos, esta subrutina devuelve P**T*VT en lugar de
!> P**T, para las matrices de entrada dadas U y VT. Cuando U y VT son las
!> matrices ortogonales que reducen una matriz general A a forma bidiagonal:
!> A = U*B*VT, como se calculó por SGEBRD, entonces
!>
!>    A = (U*Q) * S * (P**T*VT)
!>
!> es la SVD de A. Opcionalmente, la subrutina también puede calcular Q**T*C
!> para una matriz de entrada dada C.
!>
!> Ver  por J. Demmel y W. Kahan,
!> LAPACK Working Note #3 (o SIAM J. Sci. Statist. Comput. vol. 11,
!> no. 5, pp. 873-912, Sept 1990) y
!>  por
!> B. Parlett y V. Fernando, Technical Report CPAM-554, Department of
!> Mathematics, University of California at Berkeley, July 1992
!> para una descripción detallada del algoritmo.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  B es superior bidiagonal;
!>          = 'L':  B es inferior bidiagonal.
!>

N

!>          N es INTEGER
!>          El orden de la matriz B.  N >= 0.
!>

NCVT

!>          NCVT es INTEGER
!>          El número de columnas de la matriz VT. NCVT >= 0.
!>

NRU

!>          NRU es INTEGER
!>          El número de filas de la matriz U. NRU >= 0.
!>

NCC

!>          NCC es INTEGER
!>          El número de columnas de la matriz C. NCC >= 0.
!>

D

!>          D es array REAL, dimension (N)
!>          En la entrada, los n elementos diagonales de la matriz bidiagonal B.
!>          En la salida, si INFO=0, los valores singulares de B en orden
!>          decreciente.
!>

E

!>          E es array REAL, dimension (N-1)
!>          En la entrada, los N-1 elementos fuera de la diagonal de la matriz
!>          bidiagonal B.
!>          En la salida, si INFO = 0, E se destruye; si INFO > 0, D y E
!>          contendrán los elementos de la diagonal y superdiagonal de una
!>          matriz bidiagonal ortogonalmente equivalente a la dada en la entrada.
!>

VT

!>          VT es array REAL, dimension (LDVT, NCVT)
!>          En la entrada, una matriz VT de N por NCVT.
!>          En la salida, VT se sobrescribe con P**T * VT.
!>          No se referencia si NCVT = 0.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del array VT.
!>          LDVT >= max(1,N) si NCVT > 0; LDVT >= 1 si NCVT = 0.
!>

U

!>          U es array REAL, dimension (LDU, N)
!>          En la entrada, una matriz U de NRU por N.
!>          En la salida, U se sobrescribe con U * Q.
!>          No se referencia si NRU = 0.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,NRU).
!>

C

!>          C es array REAL, dimension (LDC, NCC)
!>          En la entrada, una matriz C de N por NCC.
!>          En la salida, C se sobrescribe con Q**T * C.
!>          No se referencia si NCC = 0.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C.
!>          LDC >= max(1,N) si NCC > 0; LDC >=1 si NCC = 0.
!>

WORK

!>          WORK es array REAL, dimension (LWORK)
!>          LWORK = 4*N, si NCVT = NRU = NCC = 0, y
!>          LWORK = 4*(N-1), en caso contrario
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  Si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:
!>             si NCVT = NRU = NCC = 0,
!>                = 1, una división fue marcada por un valor positivo en E
!>                = 2, el bloque actual de Z no se diagonalizó después de 30*N
!>                     iteraciones (en el bucle while interno)
!>                = 3, el criterio de terminación del bucle while externo no se cumplió
!>                     (el programa creó más de N bloques no reducidos)
!>             si no NCVT = NRU = NCC = 0,
!>                   el algoritmo no convergió; D y E contienen los
!>                   elementos de una matriz bidiagonal que es ortogonalmente
!>                   similar a la matriz de entrada B; si INFO = i, i
!>                   elementos de E no han convergido a cero.
!>

Parámetros Internos:

!>  TOLMUL  REAL, default = max(10,min(100,EPS**(-1/8)))
!>          TOLMUL controla el criterio de convergencia del bucle QR.
!>          Si es positivo, TOLMUL*EPS es la precisión relativa deseada
!>             en los valores singulares calculados.
!>          Si es negativo, abs(TOLMUL*EPS*sigma_max) es la precisión
!>             absoluta deseada en los valores singulares calculados
!>             (corresponde a una precisión relativa
!>             abs(TOLMUL*EPS) en el valor singular más grande.
!>          abs(TOLMUL) debe estar entre 1 y 1/EPS, y preferiblemente
!>             entre 10 (para convergencia rápida) y .1/EPS
!>             (para que haya alguna precisión en los resultados).
!>          El valor predeterminado es perder una octava o 2 de los
!>          dígitos decimales disponibles en cada valor singular calculado
!>          (el que sea menor).
!>
!>  MAXITR  INTEGER, default = 6
!>          MAXITR controla el número máximo de pasadas del
!>          algoritmo por su bucle interno. El algoritmo se detiene
!>          (y por lo tanto falla en converger) si el número de pasadas
!>          por el bucle interno excede MAXITR*N**2.
!>

Nota:

!>  Informe de error de Cezary Dendek.
!>  El 23 de marzo de 2017, la variable INTEGER MAXIT = MAXITR*N**2 se
!>  eliminó ya que puede desbordarse con bastante facilidad (para N mayor o igual
!>  que 18,919). En su lugar, usamos MAXITDIVN = MAXITR*N.
!>
