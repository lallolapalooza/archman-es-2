subroutine sbbcsd (caracter jobu1, caracter jobu2, caracter jobv1t, caracter jobv2t, caracter trans, entero m, entero p, entero q, real, dimension( * ) theta, real, dimension( * ) phi, real, dimension( ldu1, * ) u1, entero ldu1, real, dimension( ldu2, * ) u2, entero ldu2, real, dimension( ldv1t, * ) v1t, entero ldv1t, real, dimension( ldv2t, * ) v2t, entero ldv2t, real, dimension( * ) b11d, real, dimension( * ) b11e, real, dimension( * ) b12d, real, dimension( * ) b12e, real, dimension( * ) b21d, real, dimension( * ) b21e, real, dimension( * ) b22d, real, dimension( * ) b22e, real, dimension( * ) work, entero lwork, entero info)

SBBCSD

Propósito:

!>
!> SBBCSD calcula la descomposición CS de una matriz ortogonal en
!> forma de bloque bidiagonal,
!>
!>
!>     [ B11 | B12 0  0 ]
!>     [  0  |  0 -I  0 ]
!> X = [----------------]
!>     [ B21 | B22 0  0 ]
!>     [  0  |  0  0  I ]
!>
!>                               [  C | -S  0  0 ]
!>                   [ U1 |    ] [  0 |  0 -I  0 ] [ V1 |    ]**T
!>                 = [---------] [---------------] [---------]   .
!>                   [    | U2 ] [  S |  C  0  0 ] [    | V2 ]
!>                               [  0 |  0  0  I ]
!>
!> X es M por M, su bloque superior izquierdo es P por Q, y Q no debe ser mayor
!> que P, M-P, o M-Q. (Si Q no es el índice más pequeño, entonces X debe ser
!> transpuesta y/o permutada. Esto se puede hacer en tiempo constante usando
!> las opciones TRANS y SIGNS. Ver SORCSD para detalles.)
!>
!> Las matrices bidiagonales B11, B12, B21 y B22 se representan
!> implícitamente por los ángulos THETA(1:Q) y PHI(1:Q-1).
!>
!> Las matrices ortogonales U1, U2, V1T y V2T son de entrada/salida.
!> Las matrices de entrada se multiplican pre o post-multiplicadas por las
!> matrices de vectores singulares apropiadas.
!>

Parámetros

JOBU1 
!>          JOBU1 es CHARACTER
!>          = 'Y':      U1 se actualiza;
!>          de lo contrario:  U1 no se actualiza.
!>

JOBU2

!>          JOBU2 es CHARACTER
!>          = 'Y':      U2 se actualiza;
!>          de lo contrario:  U2 no se actualiza.
!>

JOBV1T

!>          JOBV1T es CHARACTER
!>          = 'Y':      V1T se actualiza;
!>          de lo contrario:  V1T no se actualiza.
!>

JOBV2T

!>          JOBV2T es CHARACTER
!>          = 'Y':      V2T se actualiza;
!>          de lo contrario:  V2T no se actualiza.
!>

TRANS

!>          TRANS es CHARACTER
!>          = 'T':      X, U1, U2, V1T y V2T se almacenan en orden de fila principal;
!>          de lo contrario:  X, U1, U2, V1T y V2T se almacenan en orden de columna principal.
!>

M

!>          M es INTEGER
!>          El número de filas y columnas en X, la matriz ortogonal en
!>          forma de bloque bidiagonal.
!>

P

!>          P es INTEGER
!>          El número de filas en el bloque superior izquierdo de X. 0 <= P <= M.
!>

Q

!>          Q es INTEGER
!>          El número de columnas en el bloque superior izquierdo de X.
!>          0 <= Q <= MIN(P,M-P,M-Q).
!>

THETA

!>          THETA es array REAL, dimension (Q)
!>          En la entrada, los ángulos THETA(1),...,THETA(Q) que, junto con
!>          PHI(1), ...,PHI(Q-1), definen la matriz en forma de bloque bidiagonal.
!>          En la salida, los ángulos cuyos cosenos y senos definen los
!>          bloques diagonales en la descomposición CS.
!>

PHI

!>          PHI es array REAL, dimension (Q-1)
!>          Los ángulos PHI(1),...,PHI(Q-1) que, junto con THETA(1),...,
!>          THETA(Q), definen la matriz en forma de bloque bidiagonal.
!>

U1

!>          U1 es array REAL, dimension (LDU1,P)
!>          En la entrada, una matriz P por P. En la salida, U1 se multiplica
!>          post-multiplicada por la matriz de vectores singulares izquierdos común a [ B11 ; 0 ] y
!>          [ B12 0 0 ; 0 -I 0 0 ].
!>

LDU1

!>          LDU1 es INTEGER
!>          La dimensión principal del array U1, LDU1 >= MAX(1,P).
!>

U2

!>          U2 es array REAL, dimension (LDU2,M-P)
!>          En la entrada, una matriz (M-P) por (M-P). En la salida, U2 se
!>          multiplica post-multiplicada por la matriz de vectores singulares izquierdos común a
!>          [ B21 ; 0 ] y [ B22 0 0 ; 0 0 I ].
!>

LDU2

!>          LDU2 es INTEGER
!>          La dimensión principal del array U2, LDU2 >= MAX(1,M-P).
!>

V1T

!>          V1T es array REAL, dimension (LDV1T,Q)
!>          En la entrada, una matriz Q por Q. En la salida, V1T se multiplica
!>          pre-multiplicada por la transpuesta de la matriz de vectores singulares
!>          derechos común a [ B11 ; 0 ] y [ B21 ; 0 ].
!>

LDV1T

!>          LDV1T es INTEGER
!>          La dimensión principal del array V1T, LDV1T >= MAX(1,Q).
!>

V2T

!>          V2T es array REAL, dimension (LDV2T,M-Q)
!>          En la entrada, una matriz (M-Q) por (M-Q). En la salida, V2T se
!>          multiplica pre-multiplicada por la transpuesta de la matriz de
!>          vectores singulares derechos común a [ B12 0 0 ; 0 -I 0 ] y
!>          [ B22 0 0 ; 0 0 I ].
!>

LDV2T

!>          LDV2T es INTEGER
!>          La dimensión principal del array V2T, LDV2T >= MAX(1,M-Q).
!>

B11D

!>          B11D es array REAL, dimension (Q)
!>          Cuando SBBCSD converge, B11D contiene los cosenos de THETA(1),
!>          ..., THETA(Q). Si SBBCSD falla en converger, entonces B11D
!>          contiene la diagonal del bloque superior izquierdo parcialmente reducido.
!>

B11E

!>          B11E es array REAL, dimension (Q-1)
!>          Cuando SBBCSD converge, B11E contiene ceros. Si SBBCSD falla
!>          en converger, entonces B11E contiene la superdiagonal del
!>          bloque superior izquierdo parcialmente reducido.
!>

B12D

!>          B12D es array REAL, dimension (Q)
!>          Cuando SBBCSD converge, B12D contiene los senos negativos de
!>          THETA(1), ..., THETA(Q). Si SBBCSD falla en converger, entonces
!>          B12D contiene la diagonal del bloque superior derecho parcialmente reducido.
!>

B12E

!>          B12E es array REAL, dimension (Q-1)
!>          Cuando SBBCSD converge, B12E contiene ceros. Si SBBCSD falla
!>          en converger, entonces B12E contiene la subdiagonal del
!>          bloque superior derecho parcialmente reducido.
!>

B21D

!>          B21D es array REAL, dimension (Q)
!>          Cuando SBBCSD converge, B21D contiene los senos negativos de
!>          THETA(1), ..., THETA(Q). Si SBBCSD falla en converger, entonces
!>          B21D contiene la diagonal del bloque inferior izquierdo parcialmente reducido.
!>

B21E

!>          B21E es array REAL, dimension (Q-1)
!>          Cuando SBBCSD converge, B21E contiene ceros. Si SBBCSD falla
!>          en converger, entonces B21E contiene la subdiagonal del
!>          bloque inferior izquierdo parcialmente reducido.
!>

B22D

!>          B22D es array REAL, dimension (Q)
!>          Cuando SBBCSD converge, B22D contiene los cosenos de THETA(1),
!>          ..., THETA(Q). Si SBBCSD falla en converger, entonces B22D
!>          contiene la diagonal del bloque inferior derecho parcialmente reducido.
!>

B22E

!>          B22E es array REAL, dimension (Q-1)
!>          Cuando SBBCSD converge, B22E contiene ceros. Si SBBCSD falla
!>          en converger, entonces B22E contiene la superdiagonal del
!>          bloque inferior derecho parcialmente reducido.
!>

WORK

!>          WORK es array REAL, dimension (LWORK)
!>          Espacio de trabajo de usuario.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,M).
!>

INFO

!>          INFO es INTEGER
!>          = 0: Éxito.
!>          > 0: Error en la entrada, véase Parámetros.
!>          < 0: El algoritmo de actualización de las matrices de SVD no convergía
!>               después de iteraciones. El valor absoluto de INFO es el índice de la
!>               entrada THETA(I) para la que falló la convergencia.
!>

NAME

sbbcsd

computes the Schur decomposition of a real 2-by-2 block matrix and the CS decomposition of its diagonal blocks

    REAL :: V( * )

Function/Subroutine Documentation

This routine computes the Schur decomposition of a real 2-by-2 block matrix and the CS decomposition of its diagonal blocks.

Arguments:

JOBU

CHARACTER*1.

Specifies whether to compute the left Schur vectors.

= 'U': Compute the left Schur vectors.

= 'N': Do not compute the left Schur vectors.

JOBU must be 'U' or 'N'.

JOBV

CHARACTER*1.

Specifies whether to compute the right Schur vectors.

= 'V': Compute the right Schur vectors.

= 'N': Do not compute the right Schur vectors.

JOBV must be 'V' or 'N'.

M

INTEGER.

The number of rows of the matrix X.

P

INTEGER.

The number of columns of the matrix Y.

Q

INTEGER.

The number of columns of the matrix X and the number of rows of the matrix Y.

X

REAL array, dimension (LDX, Q).

On entry, the M-by-Q matrix X.

On exit, the contents of X are not specified.

LDX

INTEGER.

The leading dimension of the array X.

Y

REAL array, dimension (LDY, P).

On entry, the Q-by-P matrix Y.

On exit, the contents of Y are not specified.

LDY

INTEGER.

The leading dimension of the array Y.

R

REAL array, dimension (LDR, L+P).

On entry, the diagonal elements of the upper triangular matrix R. R must contain the diagonal elements of the upper triangular matrix formed by the QR decomposition of [X Y].

On exit, R is not specified.

LDR

INTEGER.

The leading dimension of the array R.

SENTOL

REAL.

The tolerance for determining the condition of the CS decomposition.

If SENTOL is not positive, then the default value is used.

COLW

REAL array, dimension (LDLW, Q).

On exit, COLW contains the CS decomposition of the diagonal blocks.

LDLW

INTEGER.

The leading dimension of the array COLW.

U

REAL array, dimension (LDU, M).

If JOBU = 'U', U contains the left Schur vectors of X. If JOBU = 'N', U is not used.

LDU

INTEGER.

The leading dimension of the array U.

V

REAL array, dimension (LDV, Q).

If JOBV = 'V', V contains the right Schur vectors of X. If JOBV = 'N', V is not used.

LDV

INTEGER.

The leading dimension of the array V.

TRANSL

CHARACTER*1.

Specifies the form of the left transformation.

= 'U': Use unitary matrix U.

= 'N': Use identity matrix.

TRANSR

CHARACTER*1.

Specifies the form of the right transformation.

= 'U': Use unitary matrix V.

= 'N': Use identity matrix.

B11D

REAL array, dimension (Q-1).

When SBBCSD converges, B11D contains zeros. If SBBCSD fails to converge, then B11D contains the subdiagonal of the partially reduced top-left block.

B11E

REAL array, dimension (Q-1).

When SBBCSD converges, B11E contains zeros. If SBBCSD fails to converge, then B11E contains the subdiagonal of the partially reduced top-left block.

B12D

REAL array, dimension (Q).

When SBBCSD converges, B12D contains the negative sines of THETA(1), ..., THETA(Q). If SBBCSD fails to converge, then B12D contains the diagonal of the partially reduced top-right block.

B12E

REAL array, dimension (Q-1).

When SBBCSD converges, B12E contains zeros. If SBBCSD fails to converge, then B12E contains the subdiagonal of the partially reduced top-right block.

B21D

REAL array, dimension (Q-1).

When SBBCSD converges, B21D contains zeros. If SBBCSD fails to converge, then B21D contains the subdiagonal of the partially reduced bottom-left block.

B21E

REAL array, dimension (Q-1).

When SBBCSD converges, B21E contains zeros. If SBBCSD fails to converge, then B21E contains the subdiagonal of the partially reduced bottom-left block.

B22D

REAL array, dimension (Q).

When SBBCSD converges, B22D contains the negative sines of THETA(1), ..., THETA(Q). If SBBCSD fails to converge, then B22D contains the diagonal of the partially reduced bottom-right block.

B22E

REAL array, dimension (Q-1).

When SBBCSD converges, B22E contains zeros. If SBBCSD fails to converge, then B22E contains the subdiagonal of the partially reduced bottom-right block.

WORK

REAL array, dimension (MAX(1,LWORK)).

On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

INTEGER.

The dimension of the array WORK. LWORK >= MAX(1,8*Q).

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the work array, and no error message related to LWORK is issued by XERBLA.

INFO

INTEGER.

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: if SBBCSD did not converge, INFO specifies the number of nonzero entries in PHI, and B11D, B11E, etc., contain the partially reduced matrix.

Internal Parameters:

!>  TOLMUL  REAL, default = MAX(10,MIN(100,EPS**(-1/8)))
!>          TOLMUL controls the convergence criterion of the QR loop.
!>          Angles THETA(i), PHI(i) are rounded to 0 or PI/2 when they
!>          are within TOLMUL*EPS of either bound.
!>
