SBKEYSYNC(1) Comandos de usuario SBKEYSYNC(1)

NOMBRE

sbkeysync - Herramienta de sincronización de claves de arranque seguro UEFI

SINOPSIS

sbkeysync [opciones]

DESCRIPCIÓN

Actualiza las bases de datos de claves EFI desde el sistema de archivos.

OPCIONES

--efivars-path <dir>
Ruta al punto de montaje de efivars (o un directorio normal para pruebas).
--verbose
Imprime información detallada del progreso.
--dry-run
No actualiza las bases de datos de claves del firmware.
--pk
Establece PK.
--keystore <dir>
Lee las claves de <dir>/{db,dbx,KEK}/* (se puede especificar varias veces, el primer directorio tiene prioridad).
--no-default-keystores
No lee las claves de los directorios de almacén de claves predeterminados.
