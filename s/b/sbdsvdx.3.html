subrutina sbdsvdx (character uplo, character jobz, character range, integer n, real, dimension( * ) d, real, dimension( * ) e, real vl, real vu, integer il, integer iu, integer ns, real, dimension( * ) s, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SBDSVDX

Propósito:

!>
!>  SBDSVDX calcula la descomposición en valores singulares (SVD) de una matriz
!>  bidiagonal N por N (superior o inferior) B, B = U * S * VT,
!>  donde S es una matriz diagonal con elementos diagonales no negativos
!>  (los valores singulares de B), y U y VT son matrices ortogonales
!>  de vectores singulares izquierdos y derechos, respectivamente.
!>
!>  Dada una matriz bidiagonal superior B con diagonal D = [ d_1 d_2 ... d_N ]
!>  y superdiagonal E = [ e_1 e_2 ... e_N-1 ], SBDSVDX calcula la
!>  descomposición en valores singulares de B a través de los valores propios
!>  y vectores propios de la matriz tridiagonal N*2 por N*2
!>
!>        |  0  d_1                |
!>        | d_1  0  e_1            |
!>  TGK = |     e_1  0  d_2        |
!>        |         d_2  .   .     |
!>        |              .   .   . |
!>
!>  Si (s,u,v) es un triple singular de B con ||u|| = ||v|| = 1, entonces
!>  (+/-s,q), ||q|| = 1, son pares propios de TGK, con q = P * ( u' +/-v' ) /
!>  sqrt(2) = ( v_1 u_1 v_2 u_2 ... v_n u_n ) / sqrt(2), y
!>  P = [ e_{n+1} e_{1} e_{n+2} e_{2} ... ].
!>
!>  Dada una matriz TGK, se puede a) calcular -s,-v y cambiar signos
!>  para que los valores singulares (y vectores correspondientes) ya estén en
!>  orden descendente (como en SGESVD/SGESDD) o b) calcular s,v y reordenar
!>  los valores (y vectores correspondientes). SBDSVDX implementa a) llamando
!>  a SSTEVX (bisección más iteración inversa, a ser reemplazada
!>  por una versión del algoritmo de Representación Robusta Múltiple
!>  (See P. Willems and B. Lang, A framework for the MR^3
!>  algorithm: theory and implementation, SIAM J. Sci. Comput.,
!>  35:740-766, 2013.)
!>

Parámetros

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  B es bidiagonal superior;
!>          = 'L':  B es bidiagonal inferior.
!>

JOBZ

!>          JOBZ is CHARACTER*1
!>          = 'N':  Solo calcular valores singulares;
!>          = 'V':  Calcular valores singulares y vectores singulares.
!>

RANGE

!>          RANGE is CHARACTER*1
!>          = 'A': se encontrarán todos los valores singulares.
!>          = 'V': se encontrarán todos los valores singulares en el intervalo semiabierto [VL,VU)
!>                 .
!>          = 'I': se encontrarán los valores singulares desde el IL-ésimo hasta el IU-ésimo.
!>

N

!>          N is INTEGER
!>          El orden de la matriz bidiagonal.  N >= 0.
!>

D

!>          D is REAL array, dimension (N)
!>          Los n elementos diagonales de la matriz bidiagonal B.
!>

E

!>          E is REAL array, dimension (max(1,N-1))
!>          Los (n-1) elementos superdiagonales de la matriz bidiagonal
!>          B en los elementos 1 a N-1.
!>

VL

!>         VL is REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores singulares. VU > VL.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>         VU is REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores singulares. VU > VL.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL is INTEGER
!>          Si RANGE='I', el índice del
!>          valor singular más pequeño a devolver.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU is INTEGER
!>          Si RANGE='I', el índice del
!>          valor singular más grande a devolver.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

NS

!>          NS is INTEGER
!>          El número total de valores singulares encontrados.  0 <= NS <= N.
!>          Si RANGE = 'A', NS = N, y si RANGE = 'I', NS = IU-IL+1.
!>

S

!>          S is REAL array, dimension (N)
!>          Los primeros NS elementos contienen los valores singulares seleccionados en
!>          orden ascendente.
!>

Z

!>          Z is REAL array, dimension (2*N,K)
!>          Si JOBZ = 'V', entonces si INFO = 0 las primeras NS columnas de Z
!>          contienen los vectores singulares de la matriz B correspondientes
!>          a los valores singulares seleccionados, con U en las filas 1 a N y V
!>          en las filas N+1 a N*2, es decir,
!>          Z = [ U ]
!>              [ V ]
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: El usuario debe asegurarse de que se suministren al menos K = NS+1 columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de
!>          NS no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ is INTEGER
!>          La dimensión principal del array Z. LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(2,N*2).
!>

WORK

!>          WORK is REAL array, dimension (14*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (12*N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros NS elementos de
!>          IWORK son cero. Si INFO > 0, entonces IWORK contiene los índices
!>          de los vectores propios que no convergieron en DSTEVX.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, entonces i vectores propios fallaron en converger
!>                   en SSTEVX. Los índices de los vectores propios
!>                   (tal como los devuelve SSTEVX) están almacenados en
!>                   el array IWORK.
!>                si INFO = N*2 + 1, ocurrió un error interno.
!>
