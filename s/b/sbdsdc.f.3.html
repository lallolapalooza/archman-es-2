Documentación de la Función/Subrutina

subrutina sbdsdc (character uplo, character compq, integer n, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldvt, * ) vt, integer ldvt, real, dimension( * ) q, integer, dimension( * ) iq, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SBDSDC

Propósito:

!>
!> SBDSDC calcula la descomposición en valores singulares (SVD) de una matriz
!> bidiagonal real N por N (superior o inferior) B:  B = U * S * VT,
!> utilizando un método de divide y vencerás, donde S es una matriz diagonal
!> con elementos diagonales no negativos (los valores singulares de B), y
!> U y VT son matrices ortogonales de vectores singulares izquierdos y derechos,
!> respectivamente. SBDSDC puede usarse para calcular todos los valores singulares,
!> y opcionalmente, vectores singulares o vectores singulares en forma compacta.
!>
!> El código actualmente llama a SLASDQ si solo se desean valores singulares.
!> Sin embargo, puede modificarse ligeramente para calcular valores singulares
!> utilizando el método de divide y vencerás.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  B es superior bidiagonal.
!>          = 'L':  B es inferior bidiagonal.
!>

COMPQ

!>          COMPQ es CHARACTER*1
!>          Especifica si se deben calcular los vectores singulares
!>          de la siguiente manera:
!>          = 'N':  Solo calcular valores singulares;
!>          = 'P':  Calcular valores singulares y calcular vectores
!>                  singulares en forma compacta;
!>          = 'I':  Calcular valores singulares y vectores singulares.
!>

N

!>          N es INTEGER
!>          El orden de la matriz B.  N >= 0.
!>

D

!>          D es arreglo REAL, dimension (N)
!>          En la entrada, los n elementos diagonales de la matriz bidiagonal B.
!>          En la salida, si INFO=0, los valores singulares de B.
!>

E

!>          E es arreglo REAL, dimension (N-1)
!>          En la entrada, los elementos de E contienen los elementos
!>          fuera de la diagonal de la matriz bidiagonal cuya SVD se desea.
!>          En la salida, E ha sido destruido.
!>

U

!>          U es arreglo REAL, dimension (LDU,N)
!>          Si  COMPQ = 'I', entonces:
!>             En la salida, si INFO = 0, U contiene los vectores singulares
!>             izquierdos de la matriz bidiagonal.
!>          Para otros valores de COMPQ, U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del arreglo U.  LDU >= 1.
!>          Si se desean vectores singulares, entonces LDU >= max( 1, N ).
!>

VT

!>          VT es arreglo REAL, dimension (LDVT,N)
!>          Si  COMPQ = 'I', entonces:
!>             En la salida, si INFO = 0, VT**T contiene los vectores singulares
!>             derechos de la matriz bidiagonal.
!>          Para otros valores de COMPQ, VT no se referencia.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del arreglo VT.  LDVT >= 1.
!>          Si se desean vectores singulares, entonces LDVT >= max( 1, N ).
!>

Q

!>          Q es arreglo REAL, dimension (LDQ)
!>          Si  COMPQ = 'P', entonces:
!>             En la salida, si INFO = 0, Q e IQ contienen los vectores singulares
!>             izquierdos y derechos en forma compacta,
!>             requiriendo O(N log N) de espacio en lugar de 2*N**2.
!>             En particular, Q contiene todos los datos REALES en
!>             LDQ >= N*(11 + 2*SMLSIZ + 8*INT(LOG_2(N/(SMLSIZ+1))))
!>             palabras de memoria, donde SMLSIZ es retornado por ILAENV y
!>             es igual al tamaño máximo de los subproblemas en la
!>             parte inferior del árbol de computación (normalmente alrededor de 25).
!>          Para otros valores de COMPQ, Q no se referencia.
!>

IQ

!>          IQ es arreglo INTEGER, dimension (LDIQ)
!>          Si  COMPQ = 'P', entonces:
!>             En la salida, si INFO = 0, Q e IQ contienen los vectores singulares
!>             izquierdos y derechos en forma compacta,
!>             requiriendo O(N log N) de espacio en lugar de 2*N**2.
!>             En particular, IQ contiene todos los datos INTEGER en
!>             LDIQ >= N*(3 + 3*INT(LOG_2(N/(SMLSIZ+1))))
!>             palabras de memoria, donde SMLSIZ es retornado por ILAENV y
!>             es igual al tamaño máximo de los subproblemas en la
!>             parte inferior del árbol de computación (normalmente alrededor de 25).
!>          Para otros valores de COMPQ, IQ no se referencia.
!>

WORK

!>          WORK es arreglo REAL, dimension (MAX(1,LWORK))
!>          Si COMPQ = 'N' entonces LWORK >= (4 * N).
!>          Si COMPQ = 'P' entonces LWORK >= (6 * N).
!>          Si COMPQ = 'I' entonces LWORK >= (3 * N**2 + 4 * N).
!>

IWORK

!>          IWORK es arreglo INTEGER, dimension (8*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo falló en calcular un valor singular.
!>                El proceso de actualización de divide y vencerás falló.
!>
