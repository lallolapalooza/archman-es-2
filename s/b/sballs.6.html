NOMBRE

sballs - dibuja bolas girando como locas en GL

SINOPSIS

sballs [--display host:display.screen] [--window] [--root] [--window-id number] [--visual visual] [--delay microseconds] [--object object_number] [--cycles sphere_speed] [--size viewport_size] [--texture] [--no-texture] [--wireframe] [--no-wireframe] [--trackmouse] [--no-trackmouse] [--fps]

DESCRIPCIÓN

El programa sballs dibuja una animación de bolas girando como locas en GL.

OPCIONES

sballs acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de id (decimal o hexadecimal) de un visual específico.
--fps
Muestra la tasa de fotogramas actual, la carga de la CPU y el recuento de polígonos.
--object número_objeto
Especifica cómo se agrupan las esferas (formando un objeto). Los objetos son:
1
tetraedro
2
cubo. Este es el valor predeterminado.
3
octaedro
4
dodecaedro
5
icosaedro
6
plano
7
pirámide
8
estrella
--size tamaño_viewport
El viewport de la escena GL tiene el tamaño especificado si es mayor que 32 y menor que el tamaño de la pantalla. El valor predeterminado es 0, lo que significa el tamaño completo de la pantalla.
--texture
Muestra un fondo texturizado y esferas. Este es el valor predeterminado.
--no-texture
Deshabilita la texturización de la animación.
--trackmouse
Deja que el ratón sea un joystick para cambiar la vista de la animación. Esto implica --no-wander.
--no-trackmouse
Deshabilita el seguimiento del ratón. Este es el valor predeterminado.
--wire
Dibuja una representación de alambre de las esferas.

MEDIO AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.
