SETEGID(3P) Manual del programador de POSIX SETEGID(3P)

PRÓLOGO

Esta página del manual es parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

setegid — establecer el ID de grupo efectivo

SINOPSIS

#include <unistd.h>
int setegid(gid_t gid);

DESCRIPCIÓN

Si gid es igual al ID de grupo real o al ID de grupo efectivo guardado, o si el proceso tiene privilegios apropiados, setegid() establecerá el ID de grupo efectivo del proceso que llama a gid; el ID de grupo real, el ID de grupo efectivo guardado y cualquier ID de grupo suplementario permanecerán sin cambios.

La función setegid() no afectará a la lista de grupos suplementarios de ninguna manera.

VALOR DE RETORNO

Al completarse con éxito, se devolverá 0; de lo contrario, se devolverá -1 y errno se establecerá para indicar el error.

ERRORES

La función setegid() fallará si:

EINVAL
El valor del argumento gid no es válido y no es compatible con la implementación.
EPERM
El proceso no tiene privilegios apropiados y gid no coincide con el ID de grupo real o el ID de grupo efectivo guardado.
