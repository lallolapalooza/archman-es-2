setpci(8) Las Utilidades PCI setpci(8)

NOMBRE

setpci - configurar dispositivos PCI

SINOPSIS

setpci [opciones] dispositivos operaciones...

DESCRIPCIÓN

setpci es una utilidad para consultar y configurar dispositivos PCI.

Todos los números se introducen en notación hexadecimal.

Se requieren privilegios de root para casi todas las operaciones, excluyendo la lectura del encabezado estándar del espacio de configuración en algunos sistemas operativos. Consulte lspci(8) para obtener detalles sobre los derechos de acceso.

OPCIONES

Opciones generales

-v
Indica a setpci que sea verboso y muestre información detallada sobre los accesos al espacio de configuración.
-f
Indica a setpci que no se queje cuando no haya nada que hacer (cuando no se seleccionan dispositivos). Esta opción está pensada para usarse en scripts de configuración ampliamente distribuidos donde no se tiene certeza de si el dispositivo en cuestión está presente en la máquina o no.
-D
`Modo demostración' - no escribe nada en los registros de configuración. Es útil probar setpci -vD para verificar que su compleja secuencia de operaciones de setpci hace lo que usted cree que debería hacer.
-r
Evita el escaneo del bus si cada operación selecciona un dispositivo específico (usa el selector -s con dominio, bus, slot y función específicos). Esto es más rápido, pero si el dispositivo no existe, falla en lugar de coincidir con un conjunto vacío de dispositivos.
--version
Muestra la versión de setpci. Esta opción debe usarse de forma independiente.
--help
Muestra ayuda detallada sobre las opciones disponibles. Esta opción debe usarse de forma independiente.
--dumpregs
Muestra una lista de todos los registros y capacidades PCI conocidos. Esta opción debe usarse de forma independiente.

Opciones de acceso PCI

Las utilidades PCI utilizan la biblioteca PCI para comunicarse con los dispositivos PCI (consulte pcilib(7) para obtener detalles). Puede usar las siguientes opciones para influir en su comportamiento:

-A <método>
La biblioteca admite una variedad de métodos para acceder al hardware PCI. Por defecto, utiliza el primer método de acceso disponible, pero puede usar esta opción para anular esta decisión. Consulte -A help para obtener una lista de métodos disponibles y sus descripciones.
-O <parametro>=<valor>
El comportamiento de la biblioteca se controla mediante varios parámetros nombrados. Esta opción permite establecer el valor de cualquiera de los parámetros. Use -O help para obtener una lista de parámetros conocidos y sus valores predeterminados.
-H1
Utiliza acceso directo al hardware a través del mecanismo de configuración 1 de Intel. (Esto es un atajo para -A intel-conf1.)
-H2
Utiliza acceso directo al hardware a través del mecanismo de configuración 2 de Intel. (Esto es un atajo para -A intel-conf2.)
-G
Aumenta el nivel de depuración de la biblioteca.

SELECCIÓN DE DISPOSITIVOS

Antes de cada secuencia de operaciones, debe seleccionar qué dispositivos desea que afecte esa operación.

-s [[[[<dominio>]:]<bus>]:][<slot>][.[<func>]]
Considere solo los dispositivos en el dominio especificado (en caso de que su máquina tenga varios puentes host, pueden compartir un espacio de números de bus común o cada uno de ellos puede direccionar un dominio PCI propio; los dominios se numeran de 0 a ffff), bus (0 a ff), slot (0 a 1f) y función (0 a 7). Cada componente de la dirección del dispositivo puede omitirse o establecerse en "*", ambos significando "cualquier valor". Todos los números son hexadecimales. Por ejemplo, "0:" significa todos los dispositivos en el bus 0, "0" significa todas las funciones del dispositivo 0 en cualquier bus, "0.3" selecciona la tercera función del dispositivo 0 en todos los buses y ".4" coincide solo con la cuarta función de cada dispositivo.
-d [<vendedor>]:[<dispositivo>][:<clase>[:<prog-if>]]
Seleccione dispositivos con el vendedor, dispositivo, ID de clase y interfaz de programación especificados. Los ID se proporcionan en hexadecimal y pueden omitirse o darse como "*", ambos significando "cualquier valor". El ID de clase puede contener caracteres "x" que representan "cualquier dígito".

Cuando se combinan -s y -d, solo se seleccionan los dispositivos que coinciden con ambos criterios. Cuando se especifican varias opciones del mismo tipo, la más a la derecha anula las demás.

OPERACIONES

Hay dos tipos de operaciones: lecturas y escrituras. Para leer un registro, simplemente especifique su nombre. Las escrituras tienen el formato nombre=valor,valor... donde cada valor es un número hexadecimal o una expresión del tipo dato:máscara donde tanto dato como máscara son números hexadecimales. En este último caso, solo se cambian los bits correspondientes a unos binarios en la máscara (técnicamente, esto es una operación de lectura-modificación-escritura).

Hay varias formas de identificar un registro:

  • Indique su dirección en hexadecimal.
  • Escriba su nombre. Setpci conoce los nombres de todos los registros en los encabezados de configuración estándar. Use `setpci --dumpregs' para obtener la lista completa. Consulte las especificaciones del bus PCI para conocer el significado preciso de estos registros o consulte header.h o /usr/include/pci/pci.h para obtener un breve esbozo.
  • Si el registro es parte de una capacidad PCI, puede especificar el nombre de la capacidad para obtener la dirección de su primer registro. Consulte los nombres que comienzan con `CAP_' o `ECAP_' en la salida de --dumpregs.
  • Si el nombre de la capacidad no es conocido por setpci, puede referirse a él por su número en el formato CAPid o ECAPid, donde id es el identificador numérico de la capacidad en hexadecimal.
  • Cada uno de los formatos anteriores puede ir seguido de +offset para agregar un desplazamiento (un número hexadecimal) a la dirección. Esta característica puede ser útil para direccionar registros que residen dentro de una capacidad, o para modificar partes de registros estándar.
  • Para elegir cuántos bytes (1, 2 o 4) se transferirán, debe agregar un especificador de ancho .B, .W o .L. El ancho se puede omitir si se refiere a un registro por su nombre y el ancho del registro es bien conocido.
  • Finalmente, si una capacidad existe varias veces, puede elegir a cuál dirigirse usando @número. El indexado comienza en 0.

Todos los nombres de registros y especificadores de ancho no distinguen entre mayúsculas y minúsculas.

EJEMPLOS

COMANDO
solicita el registro de comando de tamaño de palabra (word).
4.w
es una dirección numérica del mismo registro.
COMANDO.l
solicita una palabra de 32 bits que comienza en la ubicación del registro de comando, es decir, los registros de comando y estado juntos.
VENDOR_ID+1.b
especifica el byte superior del registro de ID del vendedor (recuerde, PCI es little-endian).
CAP_PM+2.w
corresponde a la segunda palabra de la capacidad de administración de energía.
ECAP108.l
solicita la primera palabra de 32 bits de la capacidad extendida con ID 0x108.
