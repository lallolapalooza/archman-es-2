sem_unlink(3) Manual de funciones de biblioteca sem_unlink(3)

NOMBRE

sem_unlink - eliminar un semáforo con nombre

BIBLIOTECA

Biblioteca POSIX threads (libpthread, -lpthread)

SINOPSIS

#include <semaphore.h>
int sem_unlink(const char *name);

DESCRIPCIÓN

sem_unlink() elimina el semáforo con nombre al que se refiere name. El nombre del semáforo se elimina inmediatamente. El semáforo se destruye una vez que todos los demás procesos que tienen el semáforo abierto lo cierran.

VALOR DE RETORNO

En caso de éxito, sem_unlink() devuelve 0; en caso de error, devuelve -1, con errno establecido para indicar el error.

ERRORES

EACCES
El llamante no tiene permiso para desvincular este semáforo.
ENAMETOOLONG
name era demasiado largo.
ENOENT
No existe ningún semáforo con el name dado.
