FBB::Selector(3bobcat) Retrasos de tiempo, E/S de múltiples archivos FBB::Selector(3bobcat)

NOMBRE

FBB::Selector - Retrasos de tiempo, alarmas y E/S de múltiples archivos.

SINOPSIS

#include <bobcat/selector>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Los objetos FBB::Selector son envoltorios para las llamadas al sistema select(2) y permiten retrasos de tiempo, funcionalidad de alarma y/o E/S de múltiples archivos. Requiere el uso de descriptores de archivo, los cuales no son una parte oficial de C++. Sin embargo, la mayoría de los sistemas operativos ofrecen descriptores de archivo. Los sockets son descriptores de archivo bien conocidos.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

FUNCIONES MIEMBRO

o
void addExceptFd(int fd):
Añade un descriptor de archivo al conjunto de descriptores de archivo que se supervisan para excepciones (tenga en cuenta que estas no son excepciones de C++. Consulte man 2 select para más detalles).
o
void addReadFd(int fd):
Añade un descriptor de archivo al conjunto de descriptores de archivo que se supervisan para lectura.
o
void addWriteFd(int fd):
Añade un descriptor de archivo al conjunto de descriptores de archivo que se supervisan para escritura.
o
int exceptFd():
Devuelve -1 si no hay más descriptores de archivo disponibles en la categoría de excepción. De lo contrario, devuelve el siguiente descriptor de archivo disponible en la categoría de excepción. Al regresar de wait, esta función puede llamarse repetidamente hasta que se devuelva -1, atendiendo cada descriptor de archivo disponible en su turno.
o
void noAlarm():
Este miembro evita que ocurra cualquier alarma de tiempo de espera.
o
int nReady():
Devuelve el número de descriptores de archivo disponibles. Se devuelve 0 en un tiempo de espera, se devuelve -1 cuando select(2) falló.
o
int readFd():
Devuelve -1 si no hay más descriptores de archivo disponibles para lectura. De lo contrario, devuelve el siguiente descriptor de archivo disponible para lectura. Al regresar de wait, esta función puede llamarse repetidamente hasta que se devuelva -1, atendiendo cada descriptor de archivo disponible en su turno. Tenga en cuenta que el archivo cuyo descriptor de archivo es devuelto por readFd también puede estar en su posición de fin de archivo. El archivo está 'listo para leer', pero no se devolverán caracteres al intentar leer de él debido a su estado de fin de archivo. En ese caso, lo mejor es probablemente eliminar el descriptor de archivo del conjunto de descriptores de archivo activos.
o
void rmExceptFd(int fd):
Elimina un descriptor de archivo del conjunto de descriptores de archivo que se supervisan para excepciones (tenga en cuenta que estas no son excepciones de C++. Consulte man 2 select para más detalles).
o
void rmReadFd(int fd):
Elimina un descriptor de archivo del conjunto de descriptores de archivo que se supervisan para lectura.
o
void rmWriteFd(int fd):
Elimina un descriptor de archivo del conjunto de descriptores de archivo que se supervisan para escritura.
o
void setAlarm(int sec, int usec = 0):
Este miembro establece la alarma en los segundos y microsegundos indicados. Si no ocurrió ninguna acción en uno de los descriptores de archivo supervisados después del tiempo indicado, wait regresará con nReady devolviendo 0. El tiempo de alarma solicitado (sec + usec / 1e+6) no puede ser negativo y no puede exceder std::numeric_limits<int>::max() o se lanzará una excepción FBB::Exception. Una especificación de tiempo de alarma de 0 resulta en que wait regrese inmediatamente. Para desactivar el tiempo de alarma, use noAlarm.
o
int wait():
Este miembro debe llamarse para esperar actividades en los descriptores de archivo instalados o el período de tiempo de espera. Los miembros exceptFd, nReady, readFd y writeFd muestran sus comportamientos definidos solo después de que wait haya regresado.
Lanza una excepción FBB::Exception cuando select(2) falla, lo que muy bien podría indicar el fin de cualquier entrada disponible. También se lanza una excepción si el programa recibió una señal.
Si wait regresa normalmente, su valor de retorno representa el número de descriptores de archivo disponibles. Tenga en cuenta que wait también puede regresar con un descriptor de archivo de entrada devuelto por readFd de un archivo en su posición de fin de archivo. El archivo está 'listo para leer', pero no se devolverán caracteres al intentar leer de él debido a su estado de fin de archivo.
o
int writeFd():
Devuelve -1 si no hay más descriptores de archivo disponibles para escritura. De lo contrario, devuelve el siguiente descriptor de archivo disponible para escritura. Al regresar de wait, esta función puede llamarse repetidamente hasta que se devuelva -1, atendiendo cada descriptor de archivo disponible en su turno.

EJEMPLO

#include <string>
#include <iostream>
#include <bobcat/selector>
#include <bobcat/exception>
using namespace std;
using namespace FBB;
int main(int argc, char **argv, char **envp)
try
{
    Selector selector;
    selector.setAlarm(5);               // cada 5 segundos: la alarma se dispara
    selector.addReadFd(STDIN_FILENO);   // mira también cin
    while (true)
    {
        if (!selector.wait())           // 0: la alarma se dispara
            cout << "¿Sigues ahí?" << endl;
        else
        {
            string s;
            if (!getline(cin, s) || !s.length())
                return 0;
            cout << "Gracias por: " << s << endl;
        }
    }
}
catch (Exception const &e)
{
    cout << e.what() << ’\n’;
    return 1;
}
