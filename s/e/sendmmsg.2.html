sendmmsg(2) Manual de llamadas al sistema sendmmsg(2)

NOMBRE

sendmmsg - enviar múltiples mensajes en un socket

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <sys/socket.h>
int sendmmsg(unsigned int n, struct mmsghdr msgvec[n], unsigned int n,
             int flags);

DESCRIPCIÓN

La llamada al sistema sendmmsg() es una extensión de sendmsg(2) que permite al llamante transmitir múltiples mensajes en un socket utilizando una sola llamada al sistema. (Esto tiene beneficios de rendimiento para algunas aplicaciones.)

El argumento sockfd es el descriptor de archivo del socket en el que se deben transmitir los datos.

El argumento msgvec es un puntero a una matriz de estructuras mmsghdr. El tamaño de esta matriz se especifica en n.

La estructura mmsghdr se define en <sys/socket.h> como:


struct mmsghdr {
    struct msghdr msg_hdr;  /* Cabecera del mensaje */
    unsigned int  msg_len;  /* Número de bytes transmitidos */
};

El campo msg_hdr es una estructura msghdr, como se describe en sendmsg(2). El campo msg_len se utiliza para devolver el número de bytes enviados desde el mensaje en msg_hdr (es decir, el mismo que el valor de retorno de una sola llamada a sendmsg(2)).

El argumento flags contiene banderas OR-ed juntas. Las banderas son las mismas que para sendmsg(2).

Una llamada bloqueante a sendmmsg() se bloquea hasta que se hayan enviado n mensajes. Una llamada no bloqueante envía tantos mensajes como sea posible (hasta el límite especificado por n) y regresa inmediatamente.

Al regresar de sendmmsg(), los campos msg_len de los elementos sucesivos de msgvec se actualizan para contener el número de bytes transmitidos desde el msg_hdr correspondiente. El valor de retorno de la llamada indica el número de elementos de msgvec que se han actualizado.

VALOR DE RETORNO

En caso de éxito, sendmmsg() devuelve el número de mensajes enviados desde msgvec; si este número es menor que n, el llamante puede reintentar con una llamada posterior a sendmmsg() para enviar los mensajes restantes.

En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

Los errores son los mismos que para sendmsg(2). Un error solo se devuelve si no se pudieron enviar datagramas. Ver también ERRORES.

ESTáNDARES

Linux.

HISTORIAL

Linux 3.0, glibc 2.14.

NOTAS

El valor especificado en n está limitado a UIO_MAXIOV (1024).

ERRORES CONOCIDOS

Si ocurre un error después de que se haya enviado al menos un mensaje, la llamada tiene éxito y devuelve el número de mensajes enviados. El código de error se pierde. El llamante puede reintentar la transmisión, comenzando por el primer mensaje fallido, pero no hay garantía de que, si se devuelve un error, sea el mismo que el que se perdió en la llamada anterior.

EJEMPLOS

El siguiente ejemplo utiliza sendmmsg() para enviar onetwo y three en dos datagramas UDP distintos utilizando una sola llamada al sistema. El contenido del primer datagrama proviene de un par de búferes.

#define _GNU_SOURCE
#include <arpa/inet.h>
#include <netinet/in.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/socket.h>
#include <sys/types.h>
int
main(void)
{
    int                 retval;
    int                 sockfd;
    struct iovec        msg1[2], msg2;
    struct mmsghdr      msg[2];
    struct sockaddr_in  addr;
    sockfd = socket(AF_INET, SOCK_DGRAM, 0);
    if (sockfd == -1) {
        perror("socket()");
        exit(EXIT_FAILURE);
    }
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = htonl(INADDR_LOOPBACK);
    addr.sin_port = htons(1234);
    if (connect(sockfd, (struct sockaddr *) &addr, sizeof(addr)) == -1) {
        perror("connect()");
        exit(EXIT_FAILURE);
    }
    memset(msg1, 0, sizeof(msg1));
    msg1[0].iov_base = "one";
    msg1[0].iov_len = 3;
    msg1[1].iov_base = "two";
    msg1[1].iov_len = 3;
    memset(&msg2, 0, sizeof(msg2));
    msg2.iov_base = "three";
    msg2.iov_len = 5;
    memset(msg, 0, sizeof(msg));
    msg[0].msg_hdr.msg_iov = msg1;
    msg[0].msg_hdr.msg_iovlen = 2;
    msg[1].msg_hdr.msg_iov = &msg2;
    msg[1].msg_hdr.msg_iovlen = 1;
    retval = sendmmsg(sockfd, msg, 2, 0);
    if (retval == -1)
        perror("sendmmsg()");
    else
        printf("%d mensajes enviados\n", retval);
    exit(0);
}
