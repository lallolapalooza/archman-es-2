serialver(1) Herramientas de Invocación de Método Remoto (RMI) serialver(1)

NOMBRE

serialver - Devuelve el UID de versión serial para las clases especificadas.

SINOPSIS

serialver [ opciones ] [ nombres_de_clases ]
opciones
Las opciones de la línea de comandos. Ver Opciones.
nombres_de_clases
Las clases para las cuales se debe devolver el serialVersionUID.

DESCRIPCIÓN

El comando serialver devuelve el serialVersionUID para una o más clases en un formato adecuado para copiarlo en una clase en evolución. Cuando se llama sin argumentos, el comando serialver imprime una línea de uso.

OPCIONES

-classpath archivos_ruta

Establece la ruta de búsqueda para las clases y recursos de la aplicación. Separe las clases y los recursos con dos puntos (:).
-show

Muestra una interfaz de usuario simple. Introduzca el nombre completo de la clase y presione la tecla Enter o el botón Show para mostrar el serialVersionUID.
-Jopción

Pasa opción a la Máquina Virtual Java, donde opción es una de las opciones descritas en la página de referencia para el lanzador de aplicaciones Java. Por ejemplo, -J-Xms48m establece la memoria de inicio en 48 MB. Ver java(1).

NOTAS

El comando serialver carga e inicializa las clases especificadas en su máquina virtual y, por defecto, no establece un gestor de seguridad. Si el comando serialver se va a ejecutar con clases no confiables, entonces se puede establecer un gestor de seguridad con la siguiente opción:

-J-Djava.security.manager

Cuando sea necesario, se puede especificar una política de seguridad con la siguiente opción:

-J-Djava.security.policy=<archivo_politica>
