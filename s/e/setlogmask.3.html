setlogmask(3) Manual de funciones de biblioteca setlogmask(3)

NOMBRE

setlogmask - establece la máscara de prioridad de registro

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <syslog.h>
int setlogmask(int mask);

DESCRIPCIÓN

Un proceso tiene una máscara de prioridad de registro que determina qué llamadas a syslog(3) pueden ser registradas. Todas las demás llamadas serán ignoradas. El registro está habilitado para las prioridades que tienen el bit correspondiente establecido en mask. La máscara inicial es tal que el registro está habilitado para todas las prioridades.

La función setlogmask() establece esta máscara de registro para el proceso que la llama y devuelve la máscara anterior. Si el argumento mask es 0, la máscara de registro actual no se modifica.

Las ocho prioridades son LOG_EMERG, LOG_ALERT, LOG_CRIT, LOG_ERR, LOG_WARNING, LOG_NOTICE, LOG_INFO y LOG_DEBUG. El bit correspondiente a una prioridad p es LOG_MASK(p). Algunos sistemas también proporcionan una macro LOG_UPTO(p) para la máscara de todas las prioridades de la lista anterior hasta e incluyendo p.

VALOR DE RETORNO

Esta función devuelve la máscara de prioridad de registro anterior.

ERRORES

Ninguno.

ATRIBUTOS

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

LOG_UPTO() se incluirá en la próxima versión de la especificación POSIX (Issue 8).
