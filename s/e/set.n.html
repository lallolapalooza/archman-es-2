set(n) Comandos integrados de Tcl set(n)

NOMBRE

set - Leer y escribir variables

SINOPSIS

set nombreVar ?valor?

DESCRIPCIÓN

Devuelve el valor de la variable nombreVar. Si se especifica valor, entonces se establece el valor de nombreVar a valor, creando una nueva variable si aún no existe, y devuelve su valor. Si nombreVar contiene un paréntesis de apertura y termina con un paréntesis de cierre, se refiere a un elemento de matriz: los caracteres anteriores al primer paréntesis de apertura son el nombre de la matriz, y los caracteres entre paréntesis son el índice dentro de la matriz. De lo contrario, nombreVar se refiere a una variable escalar.

Si nombreVar incluye calificadores de espacio de nombres (en el nombre de la matriz si se refiere a un elemento de matriz), o si nombreVar no está calificado (no incluye los nombres de ningún espacio de nombres contenedor) pero no hay ningún procedimiento activo, nombreVar se refiere a una variable de espacio de nombres resuelta según las reglas descritas en RESOLUCIÓN DE NOMBRES en la página del manual de namespace.

Si hay un procedimiento activo y nombreVar no está calificado, entonces nombreVar se refiere a un parámetro o variable local del procedimiento, a menos que nombreVar se haya declarado para resolverse de manera diferente a través de uno de los comandos global, variable o upvar.

EJEMPLOS

Almacenar un número aleatorio en la variable r:

set r [expr {rand()}]

Almacenar un mensaje corto en un elemento de matriz:

set miMatriz(msg) "¡Hola, Mundo!"

Almacenar un mensaje corto en un elemento de matriz especificado por una variable:

set nombreElem "msg"
set miMatriz($nombreElem) "¡Hola, Mundo!"

Copiar un valor en la variable out desde una variable cuyo nombre está almacenado en vbl (tenga en cuenta que a menudo es más fácil usar matrices en la práctica en lugar de hacer doble desreferencia):

set in0 "aleatorio pequeño"
set in1 "aleatorio grande"
set vbl in[expr {rand() >= 0.5}]
set out [set $vbl]
