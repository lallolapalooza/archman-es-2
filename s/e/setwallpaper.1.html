setwallpaper(1) Comandos de usuario setwallpaper(1)

NOMBRE

setwallpaper - establece el fondo de escritorio

SINOPSIS

setwallpaper [opciones] [ruta o URL a imagen JPEG o PNG]

DESCRIPCIÓN

setwallpaper establece el fondo de escritorio a la imagen especificada. Soporta tanto rutas de archivos locales como URLs de imágenes remotas. La herramienta detecta automáticamente el entorno de escritorio o gestor de ventanas actual y utiliza el método apropiado para establecer el fondo de escritorio.

OPCIONES

-v o --verbose
Habilita la salida detallada mostrando información sobre la operación.
-m o --mode
Establece el modo del fondo de escritorio: stretch (estirar), center (centrar), tile (mosaico), scale (escalar), además de modos específicos del entorno de escritorio o gestor de ventanas en ejecución. El valor predeterminado es "stretch".
-d o --download
Especifica el directorio de descarga para imágenes obtenidas de URLs. Si no se especifica, se utiliza el directorio de descarga predeterminado del sistema.
-V o --version
Muestra la versión actual.
