SEM_TIMEDWAIT(3P) Manual del programador POSIX SEM_TIMEDWAIT(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sem_timedwait — bloquear un semáforo

SINOPSIS

#include <semaphore.h>
#include <time.h>
int sem_timedwait(sem_t *restrict sem,
    const struct timespec *restrict abstime);

DESCRIPCIÓN

La función sem_timedwait() bloqueará el semáforo referenciado por sem como en la función sem_wait(). Sin embargo, si el semáforo no se puede bloquear sin esperar a que otro proceso o hilo desbloquee el semáforo realizando una función sem_post(), esta espera terminará cuando expire el tiempo de espera especificado.

El tiempo de espera expirará cuando pase la hora absoluta especificada por abstime, medida por el reloj en el que se basan los tiempos de espera (es decir, cuando el valor de ese reloj sea igual o superior a abstime), o si la hora absoluta especificada por abstime ya ha pasado en el momento de la llamada.

El tiempo de espera se basará en el reloj CLOCK_REALTIME. La resolución del tiempo de espera será la resolución del reloj en el que se basa. El tipo de dato timespec se define como una estructura en la cabecera <time.h>.

Bajo ninguna circunstancia fallará la función con un tiempo de espera si el semáforo se puede bloquear inmediatamente. La validez de abstime no necesita ser comprobada si el semáforo se puede bloquear inmediatamente.

VALOR DE RETORNO

La función sem_timedwait() devolverá cero si el proceso llamante realizó con éxito la operación de bloqueo del semáforo en el semáforo designado por sem. Si la llamada no tuvo éxito, el estado del semáforo no habrá cambiado y la función devolverá un valor de -1 y establecerá errno para indicar el error.

ERRORES

La función sem_timedwait() fallará si:

EINVAL
El proceso o hilo se habría bloqueado, y el parámetro abstime especificó un valor de campo de nanosegundos menor que cero o mayor o igual que 1000 millones.
ETIMEDOUT
El semáforo no se pudo bloquear antes de que expirara el tiempo de espera especificado.

La función sem_timedwait() puede fallar si:

EDEADLK
Se detectó una condición de interbloqueo.
EINTR
Una señal interrumpió esta función.
EINVAL
El argumento sem no se refiere a un semáforo válido.

EJEMPLOS

El programa que se muestra a continuación opera sobre un semáforo sin nombre. El programa espera dos argumentos de línea de comandos. El primer argumento especifica un valor de segundos que se utiliza para establecer un temporizador de alarma para generar una señal SIGALRM. Este manejador realiza una sem_post(3) para incrementar el semáforo sobre el que se está esperando en main() usando sem_timedwait(). El segundo argumento de línea de comandos especifica la duración del tiempo de espera, en segundos, para sem_timedwait().

#include <unistd.h>
#include <stdio.h>
#include <stdlib.h>
#include <semaphore.h>
#include <time.h>
#include <assert.h>
#include <errno.h>
#include <signal.h>
sem_t sem;
static void
handler(int sig)
{
    int sav_errno = errno;
    static const char info_msg[] = "sem_post() desde el manejador\n";
    write(STDOUT_FILENO, info_msg, sizeof info_msg - 1);
    if (sem_post(&sem) == -1) {
        static const char err_msg[] = "sem_post() falló\n";
        write(STDERR_FILENO, err_msg, sizeof err_msg - 1);
        _exit(EXIT_FAILURE);
    }
    errno = sav_errno;
}
int
main(int argc, char *argv[])
{
    struct sigaction sa;
    struct timespec ts;
    int s;
    if (argc != 3) {
        fprintf(stderr, "Uso: %s <alarma-segundos> <espera-segundos>\n",
            argv[0]);
        exit(EXIT_FAILURE);
    }
    if (sem_init(&sem, 0, 0) == -1) {
        perror("sem_init");
        exit(EXIT_FAILURE);
    }
    /* Establecer manejador de SIGALRM; configurar temporizador de alarma usando argv[1] */
    sa.sa_handler = handler;
    sigemptyset(&sa.sa_mask);
    sa.sa_flags = 0;
    if (sigaction(SIGALRM, &sa, NULL) == -1) {
        perror("sigaction");
        exit(EXIT_FAILURE);
    }
    alarm(atoi(argv[1]));
    /* Calcular intervalo relativo como tiempo actual más
       número de segundos dado en argv[2] */
    if (clock_gettime(CLOCK_REALTIME, &ts) == -1) {
        perror("clock_gettime");
        exit(EXIT_FAILURE);
    }
    ts.tv_sec += atoi(argv[2]);
    printf("main() a punto de llamar a sem_timedwait()\n");
    while ((s = sem_timedwait(&sem, &ts)) == -1 && errno == EINTR)
        continue;       /* Reintentar si es interrumpido por el manejador */
    /* Comprobar qué sucedió */
    if (s == -1) {
        if (errno == ETIMEDOUT)
            printf("sem_timedwait() expiró\n");
        else
            perror("sem_timedwait");
    } else
        printf("sem_timedwait() tuvo éxito\n");
    exit((s == 0) ? EXIT_SUCCESS : EXIT_FAILURE);
}
