SETVESABLANK(8) Manual del Administrador del Sistema SETVESABLANK(8)

NOMBRE

setvesablank - Activar o desactivar el oscurecimiento de pantalla VESA

SINOPSIS

setvesablank [ [ -b --blanking ] on | ON | off | OFF ] [ -h --help ] [ -v --verbose ]

DESCRIPCIÓN

El programa setvesablank activa o desactiva el oscurecimiento de pantalla VESA.
