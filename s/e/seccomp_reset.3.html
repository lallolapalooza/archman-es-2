Paquete: libseccomp

NOMBRE

seccomp_init, seccomp_reset - Inicializa el estado del filtro seccomp

SINOPSIS

#include <seccomp.h>

typedef void * scmp_filter_ctx;

scmp_filter_ctx seccomp_init(uint32_t def_action);
int seccomp_reset(scmp_filter_ctx ctx, uint32_t def_action);

Enlazar con -lseccomp.

DESCRIPCIÓN

Las funciones seccomp_init() y seccomp_reset() (re)inicializan el estado interno del filtro seccomp, lo preparan para su uso y establecen la acción por defecto según el parámetro def_action. La función seccomp_init() debe ser llamada antes que cualquier otra función de libseccomp, ya que el resto de la API de la biblioteca fallará si el contexto del filtro no se inicializa correctamente. La función seccomp_reset() libera el estado del contexto del filtro existente antes de reinicializarlo y solo puede ser llamada después de una llamada exitosa a seccomp_init(). Si se llama a seccomp_reset() con un filtro NULL, reinicia el estado global de la tarea de la biblioteca, incluyendo cualquier descriptor de archivo de notificación recuperado por seccomp_notify_fd(3). Normalmente esto no es necesario, pero puede ser requerido para seguir usando la biblioteca después de una llamada a fork() o clone() para asegurar que el nivel de API y el estado de notificación del usuario se restablezcan correctamente.

Cuando el llamador termina de configurar el filtro seccomp y lo ha cargado en el kernel, el llamador debe llamar a seccomp_release(3) para liberar todo el estado del contexto del filtro.

Los valores válidos de def_action son los siguientes:

SCMP_ACT_KILL
El hilo será terminado por el kernel con SIGSYS cuando llame a una syscall que no coincida con ninguna de las reglas del filtro seccomp configuradas. El hilo no podrá capturar la señal.
SCMP_ACT_KILL_PROCESS
Todo el proceso será terminado por el kernel con SIGSYS cuando llame a una syscall que no coincida con ninguna de las reglas del filtro seccomp configuradas.
SCMP_ACT_TRAP
Al hilo se le enviará una señal SIGSYS cuando llame a una syscall que no coincida con ninguna de las reglas del filtro seccomp configuradas. Puede capturar esto y cambiar su comportamiento en consecuencia. Al usar SA_SIGINFO con sigaction(2), si_code se establecerá en SYS_SECCOMP, si_syscall se establecerá en la syscall que falló las reglas, y si_arch se establecerá en el AUDIT_ARCH del ABI activo.
SCMP_ACT_ERRNO(uint16_t errno)
El hilo recibirá un valor de retorno de errno cuando llame a una syscall que no coincida con ninguna de las reglas del filtro seccomp configuradas.
SCMP_ACT_TRACE(uint16_t msg_num)
Si el hilo está siendo rastreado y el proceso de rastreo especificó la opción PTRACE_O_TRACESECCOMP en la llamada a ptrace(2), el proceso de rastreo será notificado, a través de PTRACE_EVENT_SECCOMP, y el valor proporcionado en msg_num se podrá recuperar usando la opción PTRACE_GETEVENTMSG.
SCMP_ACT_LOG
El filtro seccomp no tendrá ningún efecto en el hilo que llama a la syscall si no coincide con ninguna de las reglas del filtro seccomp configuradas, pero la syscall se registrará.
SCMP_ACT_ALLOW
El filtro seccomp no tendrá ningún efecto en el hilo que llama a la syscall si no coincide con ninguna de las reglas del filtro seccomp configuradas.

VALOR DE RETORNO

La función seccomp_init() devuelve un contexto de filtro en caso de éxito, NULL en caso de fallo. La función seccomp_reset() devuelve cero en caso de éxito o uno de los siguientes códigos de error en caso de fallo:

-EINVAL
Entrada inválida, ya sea el contexto o la acción es inválida.
-ENOMEM
La biblioteca no pudo asignar suficiente memoria.

EJEMPLOS

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc = -1;
	scmp_filter_ctx ctx;
	ctx = seccomp_init(SCMP_ACT_KILL);
	if (ctx == NULL)
		goto out;
	/* ... */
	rc = seccomp_reset(ctx, SCMP_ACT_KILL);
	if (rc < 0)
		goto out;
	/* ... */
out:
	seccomp_release(ctx);
	return -rc;
}

NOTAS

Aunque el filtro seccomp puede generarse independientemente del kernel, se requiere soporte del kernel para cargar y aplicar el filtro seccomp generado por libseccomp.

El sitio del proyecto libseccomp, con más información y el repositorio de código fuente, se puede encontrar en https://github.com/seccomp/libseccomp. Esta herramienta, así como la biblioteca libseccomp, está actualmente en desarrollo, por favor informe cualquier error en el sitio del proyecto o directamente al autor.
