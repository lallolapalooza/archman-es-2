getsockopt(2) Manual de llamadas al sistema getsockopt(2)

NOMBRE

getsockopt, setsockopt - obtener y establecer opciones en sockets

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/socket.h>
int getsockopt(socklen_t *restrict optlen;
               int sockfd, int level, int optname,
               void optval[_Nullable restrict *optlen],
               socklen_t *restrict optlen);
int setsockopt(socklen_t optlen;
               int sockfd, int level, int optname,
               const void optval[optlen],
               socklen_t optlen);

DESCRIPCIÓN

getsockopt() y setsockopt() manipulan opciones para el socket al que se refiere el descriptor de archivo sockfd. Las opciones pueden existir en múltiples niveles de protocolo; siempre están presentes en el nivel de socket más alto.

Al manipular opciones de socket, se debe especificar el nivel en el que reside la opción y el nombre de la opción. Para manipular opciones en el nivel de la API de sockets, level se especifica como SOL_SOCKET. Para manipular opciones en cualquier otro nivel, se suministra el número de protocolo del protocolo apropiado que controla la opción. Por ejemplo, para indicar que una opción debe ser interpretada por el protocolo TCP, level debe establecerse en el número de protocolo de TCP; consulte getprotoent(3).

Los argumentos optval y optlen se utilizan para acceder a los valores de las opciones para setsockopt(). Para getsockopt(), identifican un búfer en el que se deben devolver los valores para las opciones solicitadas. Para getsockopt(), optlen es un argumento valor-resultado, que inicialmente contiene el tamaño del búfer apuntado por optval y se modifica al regresar para indicar el tamaño real del valor devuelto. Si no se va a suministrar ni devolver ningún valor de opción, optval puede ser NULL.

Optname y cualquier opción especificada se pasan sin interpretación al módulo de protocolo apropiado para su interpretación. El archivo de inclusión <sys/socket.h> contiene definiciones para opciones de nivel de socket, descritas a continuación. Las opciones en otros niveles de protocolo varían en formato y nombre; consulte las entradas correspondientes en la sección 4 del manual.

La mayoría de las opciones de nivel de socket utilizan un argumento int para optval. Para setsockopt(), el argumento debe ser distinto de cero para habilitar una opción booleana, o cero si la opción debe deshabilitarse.

Para una descripción de las opciones de socket disponibles, consulte socket(7) y las páginas del manual del protocolo apropiado.

VALOR DE RETORNO

En caso de éxito, se devuelve cero para las opciones estándar. En caso de error, se devuelve -1 y errno se establece para indicar el error.

Netfilter permite al programador definir opciones de socket personalizadas con manejadores asociados; para tales opciones, el valor de retorno en caso de éxito es el valor devuelto por el manejador.

ERRORES

EBADF
El argumento sockfd no es un descriptor de archivo válido.
EFAULT
La dirección apuntada por optval no está en una parte válida del espacio de direcciones del proceso. Para getsockopt(), este error también puede devolverse si optlen no está en una parte válida del espacio de direcciones del proceso.
EINVAL
optlen inválido en setsockopt(). En algunos casos, este error también puede ocurrir para un valor inválido en optval (por ejemplo, para la opción IP_ADD_MEMBERSHIP descrita en ip(7)).
ENOPROTOOPT
La opción es desconocida en el nivel indicado.
ENOTSOCK
El descriptor de archivo sockfd no se refiere a un socket.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, SVr4, 4.4BSD (apareció por primera vez en 4.2BSD).

ERRORES CONOCIDOS

Varias de las opciones de socket deberían manejarse en niveles inferiores del sistema.
