SETBUF(3P) Manual de Programador POSIX SETBUF(3P)

PRÓLOGO

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

setbuf — asignar almacenamiento en búfer a un flujo

SINOPSIS

#include <stdio.h>
void setbuf(FILE *restrict stream, char *restrict buf);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1-2017 remite al estándar ISO C.

Excepto porque no devuelve ningún valor, la llamada a la función:

setbuf(stream, buf)

será equivalente a:

setvbuf(stream, buf, _IOFBF, BUFSIZ)

si buf no es un puntero nulo, o a:

setvbuf(stream, buf, _IONBF, BUFSIZ)

si buf es un puntero nulo.

VALOR DE RETORNO

La función setbuf() no devolverá un valor.

ERRORES

Aunque la interfaz setvbuf() puede establecer errno de formas definidas, el valor de errno después de una llamada a setbuf() no está especificado.

USO POR PARTE DE LA APLICACIÓN

Una fuente común de errores es la asignación de espacio de búfer como variable "automática" en un bloque de código, y luego no cerrar el flujo en el mismo bloque.

Con setbuf(), la asignación de un búfer de BUFSIZ bytes no implica necesariamente que se utilicen todos los bytes de BUFSIZ para el área del búfer.

Dado que no se requiere que errno permanezca sin cambios en caso de éxito, para detectar y, posiblemente, recuperarse de errores correctamente, las aplicaciones deben utilizar setvbuf() en lugar de setbuf().
