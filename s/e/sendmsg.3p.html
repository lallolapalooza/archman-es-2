SENDMSG(3P) Manual de Programador POSIX SENDMSG(3P)

PROLOGO

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sendmsg — enviar un mensaje a un socket utilizando una estructura de mensaje

SINOPSIS

#include <sys/socket.h>
ssize_t sendmsg(int socket, const struct msghdr *message, int flags);

DESCRIPCION

La función sendmsg() envía un mensaje a través de un socket de modo conectado o sin conexión. Si el socket es de modo sin conexión, el mensaje se enviará a la dirección especificada por msghdr si no se ha establecido previamente una dirección de par. Si se ha preestablecido una dirección de par, el mensaje se enviará a la dirección especificada en msghdr (anulando la dirección de par preestablecida), o la función devolverá -1 y establecerá errno a [EISCONN]. Si el socket es de modo conectado, se ignorará la dirección de destino en msghdr.

La función sendmsg() toma los siguientes argumentos:

socket
Especifica el descriptor de archivo del socket.
message
Punta a una estructura msghdr, que contiene tanto la dirección de destino como los búferes para el mensaje saliente. La longitud y el formato de la dirección dependen de la familia de direcciones del socket. El miembro msg_flags se ignora.
flags
Especifica el tipo de transmisión del mensaje. La aplicación puede especificar 0 o la siguiente bandera:
MSG_EOR
Termina un registro (si es compatible con el protocolo).
MSG_OOB
Envía datos fuera de banda en sockets que admiten datos fuera de banda. El significado y la semántica de los datos fuera de banda son específicos del protocolo.
MSG_NOSIGNAL
Solicita no enviar la señal SIGPIPE si se intenta enviar en un socket orientado a flujo que ya no está conectado. El error [EPIPE] aún se devolverá.

Los campos msg_iov y msg_iovlen de message especifican cero o más búferes que contienen los datos que se van a enviar. msg_iov apunta a un array de estructuras iovec; msg_iovlen se establecerá en la dimensión de este array. En cada estructura iovec, el campo iov_base especifica un área de almacenamiento y el campo iov_len indica su tamaño en bytes. Algunos de estos tamaños pueden ser cero. Los datos de cada área de almacenamiento indicada por msg_iov se envían en orden.

La finalización exitosa de una llamada a sendmsg() no garantiza la entrega del mensaje. Un valor de retorno de -1 solo indica errores detectados localmente.

Si no hay espacio disponible en el socket de envío para contener el mensaje que se va a transmitir y el descriptor de archivo del socket no tiene O_NONBLOCK establecido, la función sendmsg() se bloqueará hasta que haya espacio disponible. Si no hay espacio disponible en el socket de envío para contener el mensaje que se va a transmitir y el descriptor de archivo del socket tiene O_NONBLOCK establecido, la función sendmsg() fallará.

Si el protocolo del socket requiere el protocolo de difusión y la dirección especificada es una dirección de difusión para el protocolo del socket, sendmsg() fallará si la opción SO_BROADCAST no está establecida para el socket.

El socket en uso puede requerir que el proceso tenga los privilegios adecuados para usar la función sendmsg().

VALOR DE RETORNO

Al completarse con éxito, sendmsg() devolverá el número de bytes enviados. De lo contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función sendmsg() fallará si:

EAGAIN o EWOULDBLOCK

El descriptor de archivo del socket está marcado como O_NONBLOCK y la operación solicitada se bloquearía.
EAFNOSUPPORT

Las direcciones de la familia de direcciones especificada no se pueden utilizar con este socket.
EBADF
El argumento socket no es un descriptor de archivo válido.
ECONNRESET
Un par cerró forzosamente una conexión.
EINTR
Una señal interrumpió sendmsg() antes de que se transmitieran datos.
EINVAL
La suma de los valores iov_len desborda un ssize_t.
EMSGSIZE
El mensaje es demasiado grande para enviarlo de una vez (según lo requiere el socket), o el miembro msg_iovlen de la estructura msghdr a la que apunta message es menor o igual a 0 o es mayor que {IOV_MAX}.
ENOTCONN
El socket es de modo conectado pero no está conectado.
ENOTSOCK
El argumento socket no se refiere a un socket.
EOPNOTSUPP
El argumento socket está asociado con un socket que no admite uno o más de los valores establecidos en flags.
EPIPE
El socket está cerrado para escritura, o el socket es de modo conectado y ya no está conectado. En este último caso, y si el socket es de tipo SOCK_STREAM o SOCK_SEQPACKET y la bandera MSG_NOSIGNAL no está establecida, se genera la señal SIGPIPE al hilo de llamada.

Si la familia de direcciones del socket es AF_UNIX, entonces sendmsg() fallará si:

EIO
Ocurrió un error de E/S al leer o escribir en el sistema de archivos.
ELOOP
Existe un bucle en los enlaces simbólicos encontrados durante la resolución de la ruta en la dirección del socket.
ENAMETOOLONG

La longitud de un componente de una ruta es mayor que {NAME_MAX}.
ENOENT
Un componente de la ruta no nombra un archivo existente o la ruta es una cadena vacía.
ENOTDIR
Un componente del prefijo de ruta de la ruta en la dirección del socket nombra un archivo existente que no es ni un directorio ni un enlace simbólico a un directorio, o la ruta en la dirección del socket contiene al menos un carácter no-<barra> y termina con uno o más caracteres de <barra> finales y el último componente de la ruta nombra un archivo existente que no es ni un directorio ni un enlace simbólico a un directorio.

La función sendmsg() puede fallar si:

EACCES
Se niega el permiso de búsqueda para un componente del prefijo de ruta; o se niega el acceso de escritura al socket con nombre.
EDESTADDRREQ

El socket no es de modo conectado y no tiene su dirección de par establecida, y no se especificó ninguna dirección de destino.
EHOSTUNREACH

No se puede alcanzar el host de destino (probablemente porque el host está apagado o un enrutador remoto no puede alcanzarlo).
EIO
Ocurrió un error de E/S al leer o escribir en el sistema de archivos.
EISCONN
Se especificó una dirección de destino y el socket ya está conectado.
ENETUNREACH
Se detectó que la red de destino no es alcanzable desde el host local.
ENOBUFS
El sistema está bajo presión de memoria o el búfer de red está lleno. La operación no se puede completar hasta que el sistema libere recursos. Tenga en cuenta que esto es diferente de EAGAIN o EWOULDBLOCK, que indican que la operación se bloquearía si no fuera por el indicador O_NONBLOCK.
ENOMEM
No hay suficiente memoria del kernel disponible para satisfacer la solicitud.
ENOPROTOOPT
Se especificó una opción o nivel desconocido.
ESOCKTNOSUPPORT
La familia de direcciones especificada no está soportada en este sistema.
ESTALE
El archivo al que hace referencia el socket remoto ya no está disponible y el cliente de red no puede recuperarse.

ERRORS

The sendmsg() function may fail if:

EACCES
The sum of the lengths of the control messages is larger than the system limit (as defined by the SO_SND_CLI_LEN socket option).
EAGAIN
The socket is marked non-blocking and the send buffer is full.
EBADF
The file descriptor fd is not a valid open file descriptor.
ECONNREFUSED
A remote host refused to allow the connection. This may happen if the socket is connected and the remote host has sent a reset.
EDESTADDRREQ
The socket is not connected, and no destination address was specified with msg_name.
EFAULT
msg_name, msg_iov, or msg_control point to invalid memory.
EINTR
The operation was interrupted by a signal before any data was sent.
EINVAL
The socket is not of a supported type, or the msg_iovlen argument is less than or equal to 0, or the socket has been shut down.
EISCONN
The socket is connected, and the msg_name argument was not NULL.
ENETDOWN
The local network interface used to reach the destination is down.
ENETUNREACH

No route to the network is present.
ENOBUFS
Insufficient resources were available in the system to perform the operation.
ENOMEM
Insufficient memory was available to fulfill the request.

If the address family of the socket is AF_UNIX, then sendmsg() may fail if:

ELOOP
More than {SYMLOOP_MAX} symbolic links were encountered during resolution of the pathname in the socket address.
ENAMETOOLONG

The length of a pathname exceeds {PATH_MAX}, or pathname resolution of a symbolic link produced an intermediate result with a length that exceeds {PATH_MAX}.
