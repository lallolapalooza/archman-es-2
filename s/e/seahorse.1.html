SEAHORSE(1) Comandos de usuario SEAHORSE(1)

NOMBRE

seahorse - Contraseñas y Claves

SINOPSIS

seahorse [OPCIONES...] [ARCHIVOS...]

DESCRIPCIÓN

Seahorse es una interfaz gráfica para gestionar y usar claves de cifrado, contraseñas y certificados. Actualmente soporta claves PGP (usando GPG/GPGME) y claves SSH. Su objetivo es proporcionar una Herramienta de Gestión de Claves fácil de usar, junto con una interfaz sencilla para operaciones de cifrado.

OPCIONES

-?, --help

Muestra un breve texto de ayuda y sale.

--help-all

Mostrar todas las opciones de ayuda

--help-gtk

Mostrar todas las opciones de GTK

OPCIONES DE APLICACIÓN

-v, --version

Versión de esta aplicación

--display=PANTALLA

Pantalla X a usar
