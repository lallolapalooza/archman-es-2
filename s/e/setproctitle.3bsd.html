NOMBRE

setproctitle — establece el título del proceso

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <unistd.h> (Ver libbsd(7) para el uso de inclusión.)
void
setproctitle_init(int argc, char *argv[], char *envp[]);

void
setproctitle(const char *fmt, ...);

DESCRIPCIÓN

La rutina de biblioteca setproctitle() establece el título del proceso que aparece en el comando ps(1).

La rutina de biblioteca setproctitle_init() solo necesita ser llamada (antes de cualquier llamada a setproctitle() y con los argumentos de main()), si el soporte de constructor automático no se ha enlazado a través del archivo pkgconf de libbsd-ctor.

El título se establece a partir del nombre del ejecutable, seguido del resultado de una expansión de estilo printf(3) de los argumentos según lo especificado por el argumento fmt. Si el argumento fmt comienza con un carácter “-”, se omite el nombre del ejecutable.

Si fmt es NULL, se restaura el título del proceso.

EJEMPLOS

Para establecer el título en un demonio para indicar su actividad:

setproctitle("hablando con %s", inet_ntoa(addr));

VER TAMBIÉN

ps(1), w(1), kvm(3), kvm_getargv(3), printf(3)

ESTÁNDARES

La función setproctitle() es implícitamente no estándar. Otros métodos para hacer que la línea de comandos del comando ps(1) cambie, incluyendo copiar sobre la cadena argv[0], también son implícitamente no portables. Es preferible usar una función setproctitle() proporcionada por el sistema operativo si está presente.

Desafortunadamente, es posible que existan otras convenciones de llamada a otras versiones de setproctitle(), aunque el autor no ha encontrado ninguna hasta ahora. Se cree que esta es la convención predominante.

Se cree que la implementación es compatible con otros sistemas, incluyendo NetBSD y BSD/OS.

HISTORIA

La función setproctitle() apareció por primera vez en NetBSD 1.0 y FreeBSD 2.2. Otros sistemas operativos tienen funciones similares.

La función setproctitle_init() es una extensión de libbsd no presente en los BSD; evite usarla en código portable.

AUTORES

Peter Wemm ⟨peter@FreeBSD.org⟩ robó la idea del código fuente de Sendmail 8.7.3 de Eric Allman ⟨eric@sendmail.org⟩.

BUGS

Nunca pase una cadena con datos proporcionados por el usuario como formato sin usar ‘%s’. Un atacante puede insertar especificadores de formato en la cadena para dañar su pila, lo que lleva a un posible agujero de seguridad. Esto es cierto incluso si la cadena fue construida usando una función como snprintf(), ya que la cadena resultante aún puede contener especificadores de conversión suministrados por el usuario para su posterior interpolación por setproctitle().

Siempre use el modismo seguro adecuado:

setproctitle("%s", cadena);
