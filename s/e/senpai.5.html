senpai(5) Formato de Archivos Manual senpai(5)

NOMBRE

senpai - Formato y configuración de archivo

DESCRIPCIÓN

Un archivo de configuración de senpai es un archivo scfg. Véase https://git.sr.ht/~emersion/scfg.

Algunas configuraciones son requeridas, otras son opcionales.

CONFIGURACIONES

address (requerido)

La dirección (host[:puerto]) del servidor IRC. senpai usa conexiones TLS por defecto a menos que especifiques la opción tls a false. Las conexiones TLS por defecto usan el puerto 6697, el texto plano usa el puerto 6667.

Se puede especificar un esquema opcional (esquema://host[:puerto]):

  • irc:// es el valor implícito por defecto, TLS se habilita o deshabilita según el valor de configuración tls.
  • ircs:// habilita TLS.
  • irc+insecure:// deshabilita TLS (IRC en texto plano).
  • ircs+insecure:// habilita TLS pero omite la verificación del certificado TLS. Esto protege contra ataques MITM pasivos pero no contra ataques MITM activos.

nickname (requerido)

Tu apodo (nickname), enviado con un mensaje IRC NICK. No debe contener espacios ni dos puntos (:).

realname

Tu nombre real, o en realidad solo un campo que estará disponible para otros y que puede contener espacios y dos puntos. Enviado con el mensaje IRC USER. Por defecto, se usa el valor de nick.

username

Tu nombre de usuario, enviado con el mensaje IRC USER y también usado para la autenticación SASL. Por defecto, se usa el valor de nick.

password

Tu contraseña, usada para la autenticación SASL. Véase también password-cmd.

password-cmd comando [argumentos...]

Alternativamente a proporcionar tu contraseña de autenticación SASL directamente en texto plano, puedes especificar un comando que se ejecutará para obtener la contraseña en tiempo de ejecución. Esto es útil si almacenas tus contraseñas en un archivo separado (probablemente cifrado) usando `gpg` o un gestor de contraseñas de línea de comandos como pass o gopass. Si se proporciona un password-cmd, se ignorará el valor de password y la primera línea de la salida de password-cmd se usará para el inicio de sesión.

El comando y los argumentos ya están entre comillas por scfg, por lo que no es necesario poner comillas adicionales a toda la cadena del comando. Por ejemplo:

password-cmd pass "Messaging/irc"

channel

Una lista separada por espacios de nombres de canales a los que senpai se unirá automáticamente al inicio y tras la reconexión del servidor. Esta directiva se puede especificar varias veces.

Esta directiva no debe usarse al usar un bouncer, ya que el bouncer ya recuerda y une a senpai a sus canales guardados automáticamente.

highlight

Una lista separada por espacios de palabras clave que activarán una notificación y un indicador de visualización cuando sean dichas por otros. Esta directiva se puede especificar varias veces.

Por defecto, senpai usará tu apodo actual.

on-highlight-beep

Habilita el envío del carácter de campana (BEL) cuando eres resaltado. Deshabilitado por defecto.

pane-widths { ... }

Configura el ancho de varios paneles de la interfaz de usuario.

Los anchos de los paneles se establecen como subdirectivas de la directiva principal pane-widths:

pane-widths {
    nicknames 16
}
Esta directiva admite las siguientes subdirectivas:

nicknames

El número de celdas que ocupa la columna de apodos en la línea de tiempo. Por defecto, 14.

channels

El número de celdas que ocupa la columna de canales en pantalla. Por defecto, 16. Usa el valor especial 0 para hacer la lista de canales horizontal. Si el valor es negativo, la lista de canales estará horizontal por defecto y tomará el valor de ancho positivo (opuesto) cuando se active con F7.

members

El número de celdas que ocupa la columna de la lista de miembros del canal en pantalla. Por defecto, 16. Usa el valor especial 0 para deshabilitar. Si el valor es negativo, la lista de miembros estará deshabilitada por defecto y tomará el valor de ancho positivo (opuesto) cuando se active con F8.

text

El ancho máximo de línea del texto del mensaje, en número de celdas. Por defecto, el valor es cero, lo que significa que no hay máximo. Útil para mantener un ancho de línea legible en pantallas grandes.

tls

Habilita el cifrado TLS. Por defecto, true.

typings

Envía notificaciones de escritura que permiten a otros saber cuándo estás escribiendo un mensaje. Por defecto, true.

mouse

Habilita o deshabilita el soporte del ratón. Por defecto, true.

colors { ... }

Configuraciones de colores para diferentes elementos de la interfaz de usuario.

Los colores se pueden establecer por nombre ("red"), por número (de 0 a 255, para los 256 colores de terminal por defecto; -1 significa por defecto), o por color verdadero hexadecimal RGB (#rrggbb).

Los colores se establecen como subdirectivas de la directiva principal colors:

colors {
    prompt green
}
Subdirectiva Descripción
prompt <color> color para el prompt de ">" que aparece en modo de comando
unread <color> color de primer plano para nombres de búfer no leídos en las listas de búferes
status [...] color de primer plano para líneas de eventos de estado (por ejemplo, unirse, salir, cambios de nick) en los búferes, véase la tabla a continuación
nicks [...] esquema de color para los nicks de usuario, véase la tabla a continuación
Subdirectiva de status Descripción
status <color> muestra eventos de estado con el color especificado
status disabled oculta eventos de estado
Subdirectiva de nicks Descripción
nicks base muestra nicks con 16 colores diferentes (por defecto)
nicks extended muestra nicks con 256 colores diferentes
nicks fixed [<others>] muestra nicks con un color fijo, especificando opcionalmente los colores para otros nicks
nicks self <self> muestra el nick propio con un color fijo especificado (se puede añadir junto con otras directivas)

debug

Avanzado. Descarga todos los datos enviados y recibidos al búfer de inicio, útil para depuración. Por defecto, false.

-transient

Avanzado. Ejecuta una instancia efímera sin lecturas/escrituras en disco (excepto la configuración inicial). Puede ser útil para instancias públicas. Por defecto, false.

-local-integrations

Avanzado. Habilita integraciones con el sistema local (por ejemplo, notificaciones a través de DBus). Puede ser útil deshabilitarlo en sistemas previstos para ser usados a través de SSH. Por defecto, true.

on-highlight-path

Avanzado. senpai te notificará por defecto sin necesidad de un script de resaltado personalizado. Ruta alternativa a un script de shell que se ejecutará cuando seas resaltado. Por defecto, senpai busca un script de shell de resaltado en $XDG_CONFIG_HOME/senpai/highlight. Si no se encuentra ningún archivo en esa ruta y no se proporciona una ruta alternativa, la ejecución del comando de resaltado se deshabilita.

Si no está configurado, $XDG_CONFIG_HOME por defecto es ~/.config/.

¡Los scripts de shell DEBEN ASEGURARSE de que las variables aparezcan ENTRE COMILLAS en el archivo de script, O ESTARÁS ABIERTO A ATAQUES DE INYECCIÓN DE SHELL. Los scripts de shell también deben asegurarse de que caracteres como '*' y '?' no se expandan.

senpai.5.en — Arch Linux man pages

NAME

senpai.5 — Configuration for senpai(1)

DESCRIPTION

Configuration files for senpai(1) are located in ~/.config/senpai/senpai.conf.

The configuration file uses a simple key-value format. Lines starting with # are ignored. Empty lines are also ignored.

The following settings are available:

address
The network address of the IRC server to connect to. This can be a hostname or an IP address. It can optionally include a port number (e.g., irc.libera.chat:6697).
bind
Binds a command to a key combination. For example: bind ^T ^X quit will bind Ctrl+T Ctrl+X to the quit command. Modifiers are ^ (Ctrl) and M- (Alt). See senpai(1) for more details.
channel
Joins the specified channel after connecting to the server. This setting can be specified multiple times. It can also take a password argument, like channel "#mychannel" "mysecretpassword".
colors
Configure colors. Available options are:
extended
Enable extended colors for nicks.
none
Disable all colors.
colorcmd
Configure colors for commands. Default is enabled.
colorjoin
Configure colors for join messages. Default is enabled.
colorpart
Configure colors for part messages. Default is enabled.
colorquit
Configure colors for quit messages. Default is enabled.
colornick
Configure colors for nick changes. Default is enabled.
colorprivmsg
Configure colors for private messages. Default is enabled.
colorpubmsg
Configure colors for public messages. Default is enabled.
colornotice
Configure colors for notices. Default is enabled.
coloraction
Configure colors for actions. Default is enabled.
colorerror
Configure colors for errors. Default is enabled.
colorinfo
Configure colors for informational messages. Default is enabled.
colorstatus
Configure colors for status messages. Default is enabled.
dcc-accept-timeout
Timeout in seconds for accepting DCC connections. Default is 30.
dcc-bind-address
The address to bind DCC connections to. Defaults to 0.0.0.0.
dcc-bind-port
The port range to bind DCC connections to. Defaults to 1024-65535.
dcc-listen
Listen for incoming DCC connections. Default is enabled.
dcc-max-redirs
Maximum number of DCC redirects allowed. Default is 5.
dcc-timeout
Timeout in seconds for DCC transfers. Default is 300.
encoding
The character encoding to use for communication with the IRC server. Defaults to utf-8.
host-ignores
A comma-separated list of hostnames to ignore when displaying user hostmasks.
hostname
The hostname to send to the IRC server. Defaults to the system hostname.
ignore
A list of nicks to ignore. Messages from these nicks will not be displayed.
notify
A comma-separated list of events for which to send desktop notifications. Available events are privmsg, notice, mention, join, part, quit, nickchange. By default, no notifications are sent.
notify-program
The program to use for sending desktop notifications. Defaults to notify-send.
notify-timeout
The timeout in milliseconds for desktop notifications. Defaults to 5000.
pane-widths
Set the widths of the different panes in the main interface. This is a block setting, see below.
password
The password to use for connecting to the IRC server. This is generally not recommended for security reasons. Use password-cmd instead.
password-cmd
A command to execute to retrieve the password. The output of the command will be used as the password.
port
The port number to connect to the IRC server. Defaults to 6667.
realname
The real name to send to the IRC server. Defaults to senpai.
sasl-mechanism
The SASL mechanism to use. Supported mechanisms are PLAIN, EXTERNAL, SCRAM-SHA-1, SCRAM-SHA-256.
sasl-password
The password to use for SASL authentication. Use sasl-password-cmd instead if possible.
sasl-password-cmd
A command to execute to retrieve the SASL password.
sasl-username
The username to use for SASL authentication. If not specified, the nickname will be used.
server-alts
A comma-separated list of alternative server addresses to try if the primary address fails.
status-msg
The status message to send to the IRC server.
strip-color
Strip color codes from messages. Default is enabled.
strip-underline
Strip underline formatting from messages. Default is enabled.
strip-bold
Strip bold formatting from messages. Default is enabled.
strip-italic
Strip italic formatting from messages. Default is enabled.
strip-reverse
Strip reverse formatting from messages. Default is enabled.
strip-monospace
Strip monospace formatting from messages. Default is enabled.
timeout
The connection timeout in seconds. Default is 10.
tls
Enable or disable TLS/SSL support. Default is auto, which tries to connect using TLS if the server supports it on the specified port.
tls-ca-dir
Directory containing trusted CA certificates for TLS verification.
tls-ca-path
Path to a trusted CA certificate file for TLS verification.
tls-cert
Path to the client certificate file for TLS authentication.
tls-key
Path to the client private key file for TLS authentication.
tls-verify
Whether to verify the server's certificate. Default is yes.
ui-theme
Path to a UI theme file.
url-open
A command to open URLs. Use %u as a placeholder for the URL.
username
The username to send to the IRC server. Defaults to the nickname.
away-notify
Send a notice to users who send you a message while you are away. Default is enabled.
away-msg
The message to display when you are away.
away-auto-reconnect
Automatically reconnect when returning from away status. Default is enabled.

The following block settings are available:

colors
Configure colors for different parts of the UI. 
colors {
    nicks black-on-white
    channels blue
    messages green
}
pane-widths
Set the widths of the different panes in the main interface. 
pane-widths {
    nicknames 10
    channels 16
    members 16
}
The available panes are nicknames, channels, members, input, messages.

NOTIFICATION ESCAPING

When passing notification strings to notify-send(1), some notification daemons might interpret \ as escape sequences, causing them to disappear or trigger unintended side-effects (like newlines).

To work around this, you can double the backslash:

#!/bin/sh
escape() {
    printf "%s" "$1" | sed 's#\\#\\\\#g'
}
notify-send "[$BUFFER] $SENDER" "$(escape "$MESSAGE")"

EXAMPLES

A minimal configuration file to connect to Libera.Chat as "Guest123456":

address irc.libera.chat
nickname Guest123456

A more advanced configuration file that fetches a password from an external program, changes the width of some panes, and enables more colors for user nicks:

address irc.libera.chat
nickname Guest123456
username senpai
realname "Guest von Lenon"
password-cmd gopass show irc/guest # use your favorite CLI password solution here
channel "#rahxephon"
pane-widths {
    nicknames 10
    channels 16
    members 16
}
colors {
    nicks extended
}
