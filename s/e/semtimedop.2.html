semop(2) Manual de llamadas al sistema semop(2)

NOMBRE

semop, semtimedop - operaciones de semáforos de System V

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/sem.h>
int semop(int semid, struct sembuf *sops, size_t nsops);
int semtimedop(int semid, struct sembuf *sops, size_t nsops,
               const struct timespec *_Nullable timeout);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

semtimedop():

    _GNU_SOURCE

DESCRIPCIÓN

Cada semáforo en un conjunto de semáforos de System V tiene los siguientes valores asociados:


unsigned short  semval;   /* valor del semáforo */
unsigned short  semzcnt;  /* # esperando a cero */
unsigned short  semncnt;  /* # esperando a incremento */
pid_t           sempid;   /* PID del proceso que modificó por última vez
                             el valor del semáforo */

semop() realiza operaciones en semáforos seleccionados en el conjunto indicado por semid. Cada uno de los nsops elementos en el array apuntado por sops es una estructura que especifica una operación a realizar en un solo semáforo. Los elementos de esta estructura son de tipo struct sembuf, que contiene los siguientes miembros:


unsigned short sem_num;  /* número de semáforo */
short          sem_op;   /* operación del semáforo */
short          sem_flg;  /* banderas de operación */

Las banderas reconocidas en sem_flg son IPC_NOWAIT y SEM_UNDO. Si una operación especifica SEM_UNDO, se deshace automáticamente cuando el proceso termina.

El conjunto de operaciones contenidas en sops se realiza en el orden del array y de forma atómica, es decir, las operaciones se realizan como una unidad completa o no se realizan en absoluto. El comportamiento de la llamada al sistema si no todas las operaciones se pueden realizar inmediatamente depende de la presencia de la bandera IPC_NOWAIT en los campos individuales de sem_flg, como se indica a continuación.

Cada operación se realiza en el semáforo número sem_num del conjunto de semáforos, donde el primer semáforo del conjunto tiene el número 0. Hay tres tipos de operación, que se distinguen por el valor de sem_op.

Si sem_op es un entero positivo, la operación añade este valor al valor del semáforo (semval). Además, si se especifica SEM_UNDO para esta operación, el sistema resta el valor sem_op del valor de ajuste del semáforo (semadj) para este semáforo. Esta operación siempre puede proceder; nunca obliga a un hilo a esperar. El proceso que llama debe tener permiso de alteración en el conjunto de semáforos.

Si sem_op es cero, el proceso debe tener permiso de lectura en el conjunto de semáforos. Esta es una operación de "esperar a cero": si semval es cero, la operación puede proceder inmediatamente. De lo contrario, si se especifica IPC_NOWAIT en sem_flg, semop() falla con errno establecido en EAGAIN (y ninguna de las operaciones en sops se realiza). De lo contrario, semzcnt (el contador de hilos que esperan hasta que el valor de este semáforo sea cero) se incrementa en uno y el hilo duerme hasta que ocurra uno de los siguientes:

•
semval se convierte en 0, momento en el que se decrementa el valor de semzcnt.
•
Se elimina el conjunto de semáforos: semop() falla, con errno establecido en EIDRM.
•
El hilo que llama captura una señal: se decrementa el valor de semzcnt y semop() falla, con errno establecido en EINTR.

Si sem_op es menor que cero, el proceso debe tener permiso de alteración en el conjunto de semáforos. Si semval es mayor o igual al valor absoluto de sem_op, la operación puede proceder inmediatamente: se resta el valor absoluto de sem_op de semval y, si se especifica SEM_UNDO para esta operación, el sistema añade el valor absoluto de sem_op al valor de ajuste del semáforo (semadj) para este semáforo. Si el valor absoluto de sem_op es mayor que semval, y se especifica IPC_NOWAIT en sem_flg, semop() falla, con errno establecido en EAGAIN (y ninguna de las operaciones en sops se realiza). De lo contrario, semncnt (el contador de hilos que esperan a que el valor de este semáforo aumente) se incrementa en uno y el hilo duerme hasta que ocurra uno de los siguientes:

•
semval se vuelve mayor o igual al valor absoluto de sem_op: la operación procede ahora, como se describió anteriormente.
•
Se elimina el conjunto de semáforos del sistema: semop() falla, con errno establecido en EIDRM.
•
El hilo que llama captura una señal: se decrementa el valor de semncnt y semop() falla, con errno establecido en EINTR.

En caso de éxito, el valor sempid para cada semáforo especificado en el array apuntado por sops se establece en el ID de proceso del llamante. Además, sem_otime se establece en la hora actual.

semtimedop()

semtimedop() se comporta de manera idéntica a semop(), excepto en aquellos casos en los que el hilo que llama dormiría, la duración de ese sueño se limita por la cantidad de tiempo transcurrido especificado por la estructura timespec cuya dirección se pasa en el argumento timeout. (Este intervalo de sueño se redondeará al grano del reloj del sistema, y los retrasos de programación del kernel significan que el intervalo puede excederse por una pequeña cantidad). Si se ha alcanzado el límite de tiempo especificado, semtimedop() falla con errno establecido en EAGAIN (y ninguna de las operaciones en sops se realiza). Si el argumento timeout es NULL, entonces semtimedop() se comporta exactamente como semop().

Tenga en cuenta que si semtimedop() es interrumpido por una señal, lo que hace que la llamada falle con el error EINTR, el contenido de timeout permanece sin cambios.

VALOR DE RETORNO

En caso de éxito, semop() y semtimedop() devuelven 0. En caso de error, devuelven -1 y establecen errno para indicar el error.

ERRORES

E2BIG
El argumento nsops es mayor que SEMOPM, el número máximo de operaciones permitidas por llamada al sistema.
EACCES
El proceso que llama no tiene los permisos necesarios para realizar las operaciones de semáforo especificadas y no tiene la capacidad CAP_IPC_OWNER en el espacio de nombres de usuario que rige su espacio de nombres IPC.
EAGAIN
Una operación no pudo proceder inmediatamente y o bien se especificó IPC_NOWAIT en sem_flg o bien expiró el límite de tiempo especificado en timeout.
EFAULT
Una dirección especificada en el argumento sops o timeout no es accesible.
EFBIG
Para alguna operación, el valor de sem_num es menor que 0 o mayor o igual al número de semáforos en el conjunto.
EIDRM
Se eliminó el conjunto de semáforos.
EINTR
Mientras estaba bloqueado en esta llamada al sistema, el hilo capturó una señal; ver signal(7).
EINVAL
El conjunto de semáforos no existe, o semid es menor que cero, o nsops tiene un valor no positivo.
ENOMEM
El sem_flg de alguna operación especificó SEM_UNDO y el sistema no tiene suficiente memoria para asignar la estructura de deshacer.
