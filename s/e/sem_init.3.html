sem_init(3) Manual de Funciones de Biblioteca sem_init(3)

NOMBRE

sem_init - inicializa un semáforo sin nombre

BIBLIOTECA

Biblioteca POSIX threads (libpthread, -lpthread)

SINOPSIS

#include <semaphore.h>
int sem_init(sem_t *sem, int pshared, unsigned int value);

DESCRIPCIÓN

sem_init() inicializa el semáforo sin nombre en la dirección apuntada por sem. El argumento value especifica el valor inicial para el semáforo.

El argumento pshared indica si este semáforo se compartirá entre los hilos de un proceso, o entre procesos.

Si pshared tiene el valor 0, el semáforo se comparte entre los hilos de un proceso y debe ubicarse en alguna dirección visible para todos los hilos (por ejemplo, una variable global o una variable asignada dinámicamente en el heap).

Si pshared no es cero, el semáforo se comparte entre procesos y debe ubicarse en una región de memoria compartida (ver shm_open(3), mmap(2) y shmget(2)). (Dado que un hijo creado por fork(2) hereda los mapeos de memoria de su padre, también puede acceder al semáforo). Cualquier proceso que pueda acceder a la región de memoria compartida puede operar sobre el semáforo utilizando sem_post(3), sem_wait(3), y así sucesivamente.

Inicializar un semáforo que ya ha sido inicializado resulta en un comportamiento indefinido.

VALOR DEVUELTO

sem_init() devuelve 0 en caso de éxito; en caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EINVAL
value excede SEM_VALUE_MAX.
ENOSYS
pshared no es cero, pero el sistema no soporta semáforos compartidos entre procesos (ver sem_overview(7)).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
sem_init () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

Curiosamente, POSIX.1-2001 no especifica el valor que debe devolver una llamada exitosa a sem_init(). POSIX.1-2008 rectifica esto, especificando el retorno cero en caso de éxito.

EJEMPLOS

Ver shm_open(3) y sem_wait(3).

VER TAMBIÉN

sem_destroy(3), sem_post(3), sem_wait(3), sem_overview(7)
