SETREGID(3P) Manual de programador POSIX SETREGID(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

setregid — establecer IDs de grupo real y efectivo

SINOPSIS

#include <unistd.h>
int setregid(gid_t rgid, gid_t egid);

DESCRIPCIÓN

La función setregid() establece los IDs de grupo real y efectivo del proceso que llama.

Si rgid es -1, el ID de grupo real no se cambiará; si egid es -1, el ID de grupo efectivo no se cambiará.

Los IDs de grupo real y efectivo pueden establecerse a diferentes valores en la misma llamada.

Solo un proceso con privilegios apropiados puede establecer el ID de grupo real y el ID de grupo efectivo a cualquier valor válido.

Un proceso no privilegiado puede establecer el ID de grupo real al ID de grupo establecido guardado de una de las funciones de la familia exec, o el ID de grupo efectivo al ID de grupo establecido guardado o al ID de grupo real.

Si se está estableciendo el ID de grupo real (rgid no es -1), o se está estableciendo el ID de grupo efectivo a un valor distinto del ID de grupo real, entonces el ID de grupo establecido guardado del proceso actual se establecerá igual al nuevo ID de grupo efectivo.

Los IDs de grupo suplementarios del proceso que llama permanecen sin cambiar.

VALOR DE RETORNO

Al completarse con éxito, se devolverá 0. De lo contrario, se devolverá -1 y se establecerá errno para indicar el error, y ninguno de los IDs de grupo se cambiarán.

ERRORES

La función setregid() fallará si:

EINVAL
El valor del argumento rgid o egid es inválido o está fuera de rango.
EPERM
El proceso no tiene los privilegios apropiados y se solicitó un cambio distinto de cambiar el ID de grupo real al ID de grupo establecido guardado, o cambiar el ID de grupo efectivo al ID de grupo real o al ID de grupo establecido guardado.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE LA APLICACIÓN

Si un proceso no privilegiado con ID de grupo establecido cambia su ID de grupo efectivo a su ID de grupo real, solo puede restablecer su ID de grupo efectivo al valor anterior si rgid era -1 en la llamada a setregid(), ya que el ID de grupo establecido guardado no se cambia en ese caso. Si rgid era igual al ID de grupo real en la llamada a setregid(), entonces el ID de grupo establecido guardado también se habrá cambiado al ID de usuario real.

JUSTIFICACIÓN

Versiones anteriores de este estándar no especificaban si el ID de grupo establecido guardado se veía afectado por las llamadas a setregid(). Esta versión especifica la práctica común existente que constituye una característica de seguridad importante. La capacidad de establecer tanto el ID de grupo efectivo como el ID de grupo establecido guardado igual que el ID de grupo real significa que cualquier debilidad de seguridad en el código que se ejecute después de ese punto no puede resultar en la ejecución de código malicioso con el ID de grupo efectivo anterior. Las aplicaciones privilegiadas ya podían hacer esto utilizando solo setgid(), pero para las aplicaciones no privilegiadas el único método estándar disponible es utilizar esta característica de setregid().
