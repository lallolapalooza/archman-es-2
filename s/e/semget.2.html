semget(2) Manual de llamadas al sistema semget(2)

NOMBRE

semget - obtener un identificador de conjunto de semáforos System V

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/sem.h>

int semget(key_t key, int nsems, int semflg);

DESCRIPCIÓN

La llamada al sistema semget() devuelve el identificador del conjunto de semáforos System V asociado con el argumento key. Puede ser utilizada tanto para obtener el identificador de un conjunto de semáforos previamente creado (cuando semflg es cero y key no tiene el valor IPC_PRIVATE), como para crear un nuevo conjunto.

Se crea un nuevo conjunto de nsems semáforos si key tiene el valor IPC_PRIVATE o si no existe ningún conjunto de semáforos asociado con key y IPC_CREAT está especificado en semflg.

Si semflg especifica tanto IPC_CREAT como IPC_EXCL y ya existe un conjunto de semáforos para key, entonces semget() falla con errno establecido a EEXIST. (Esto es análogo al efecto de la combinación O_CREAT | O_EXCL para open(2)).

Al crear un nuevo conjunto de semáforos, los 9 bits menos significativos del argumento semflg definen los permisos (para el propietario, grupo y otros) para el conjunto de semáforos. Estos bits tienen el mismo formato y el mismo significado que el argumento mode de open(2) (aunque los permisos de ejecución no son significativos para los semáforos, y los permisos de escritura significan permiso para alterar los valores de los semáforos).

Al crear un nuevo conjunto de semáforos, semget() inicializa la estructura de datos asociada al conjunto, semid_ds (ver semctl(2)), de la siguiente manera:

•
sem_perm.cuid y sem_perm.uid se establecen al ID de usuario efectivo del proceso que llama.
•
sem_perm.cgid y sem_perm.gid se establecen al ID de grupo efectivo del proceso que llama.
•
Los 9 bits menos significativos de sem_perm.mode se establecen a los 9 bits menos significativos de semflg.
•
sem_nsems se establece al valor de nsems.
•
sem_otime se establece a 0.
•
sem_ctime se establece a la hora actual.

El argumento nsems puede ser 0 (no importa) cuando no se está creando un conjunto de semáforos. De lo contrario, nsems debe ser mayor que 0 y menor o igual al número máximo de semáforos por conjunto de semáforos (SEMMSL).

Si el conjunto de semáforos ya existe, se verifican los permisos.

VALOR DE RETORNO

En caso de éxito, semget() devuelve el identificador del conjunto de semáforos (un entero no negativo). En caso de fallo, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EACCES
Existe un conjunto de semáforos para key, pero el proceso que llama no tiene permiso para acceder al conjunto, y no tiene la capacidad CAP_IPC_OWNER en el espacio de nombres de usuario que rige su espacio de nombres IPC.
EEXIST
Se especificaron IPC_CREAT y IPC_EXCL en semflg, pero ya existe un conjunto de semáforos para key.
EINVAL
nsems es menor que 0 o mayor que el límite del número de semáforos por conjunto de semáforos (SEMMSL).
EINVAL
Ya existe un conjunto de semáforos correspondiente a key, pero nsems es mayor que el número de semáforos en ese conjunto.
ENOENT
No existe ningún conjunto de semáforos para key y semflg no especificó IPC_CREAT.
ENOMEM
Se debe crear un conjunto de semáforos pero el sistema no tiene suficiente memoria para la nueva estructura de datos.
ENOSPC
Se debe crear un conjunto de semáforos pero se excedería el límite del sistema para el número máximo de conjuntos de semáforos (SEMMNI), o el número máximo de semáforos en todo el sistema (SEMMNS).

ESTANDARES

POSIX.1-2024.

HISTORIA

SVr4, POSIX.1-2001.

NOTAS

IPC_PRIVATE no es un campo de flags sino de tipo key_t. Si se usa este valor especial para key, la llamada al sistema ignora todos los bits excepto los 9 menos significativos de semflg y crea un nuevo conjunto de semáforos (en caso de éxito).

Inicialización de semáforos

Los valores de los semáforos en un conjunto recién creado son indeterminados. (POSIX.1-2001 y POSIX.1-2008 son explícitos sobre este punto, aunque POSIX.1-2008 señala que una versión futura del estándar puede requerir que una implementación inicialice los semáforos a 0). Aunque Linux, al igual que muchas otras implementaciones, inicializa los valores de los semáforos a 0, una aplicación portable no puede depender de esto: debe inicializar explícitamente los semáforos a los valores deseados.

La inicialización se puede hacer usando la operación SETVAL o SETALL de semctl(2). Cuando varios procesos no saben quién inicializará el conjunto primero, se puede usar la comprobación de un sem_otime distinto de cero en la estructura de datos asociada recuperada por una operación IPC_STAT de semctl(2) para evitar condiciones de carrera.

Límites de semáforos

Los siguientes límites en los recursos del conjunto de semáforos afectan la llamada semget():

SEMMNI
Límite en todo el sistema para el número de conjuntos de semáforos. Antes de Linux 3.19, el valor por defecto de este límite era 128. Desde Linux 3.19, el valor por defecto es 32,000. En Linux, este límite se puede leer y modificar a través del cuarto campo de /proc/sys/kernel/sem.
SEMMSL
Número máximo de semáforos por ID de semáforo. Antes de Linux 3.19, el valor por defecto de este límite era 250. Desde Linux 3.19, el valor por defecto es 32,000. En Linux, este límite se puede leer y modificar a través del primer campo de /proc/sys/kernel/sem.
SEMMNS
Límite en todo el sistema para el número de semáforos: depende de la política (en Linux, este límite se puede leer y modificar a través del segundo campo de /proc/sys/kernel/sem). Tenga en cuenta que el número de semáforos en todo el sistema también está limitado por el producto de SEMMSL y SEMMNI.

ERRORES CONOCIDOS

La elección del nombre IPC_PRIVATE quizás fue desafortunada, IPC_NEW mostraría más claramente su función.

EJEMPLOS

El programa que se muestra a continuación utiliza semget() para crear un nuevo conjunto de semáforos o recuperar el ID de un conjunto existente. Genera la key para semget() usando ftok(3). Los dos primeros argumentos de línea de comandos se utilizan como argumentos pathname y proj_id para ftok(3). El tercer argumento de línea de comandos es un entero que especifica el argumento nsems para semget(). Las opciones de línea de comandos se pueden utilizar para especificar los flags IPC_CREAT (-c) y IPC_EXCL (-x) para la llamada a semget(). El uso de este programa se demuestra a continuación.

EJEMPLOS

Primero creamos dos archivos que se usarán para generar claves usando ftok(3), creamos dos conjuntos de semáforos usando esos archivos y luego listamos los conjuntos usando ipcs(1):


$ touch mi_clave mi_clave2;
$ ./t_semget -c mi_clave p 1;
ID = 9
$ ./t_semget -c mi_clave2 p 2;
ID = 10
$ ipcs -s;
------ Arrays de semáforos --------
clave      semid      propietario      perms      nsems
0x7004136d 9          mtk        600        1
0x70041368 10         mtk        600        2

A continuación, demostramos que cuando a semctl(2) se le da la misma clave (generada por los mismos argumentos para ftok(3)), devuelve el ID del conjunto de semáforos ya existente:


$ ./t_semget -c mi_clave p 1;
ID = 9

Finalmente, demostramos el tipo de colisión que puede ocurrir cuando a ftok(3) se le dan argumentos de nombre_archivo diferentes que tienen el mismo número de inodo:


$ ln mi_clave enlace;
$ ls -i1 enlace mi_clave;
2233197 enlace
2233197 mi_clave
$ ./t_semget enlace p 1;       # Genera la misma clave que 'mi_clave'
ID = 9

Código fuente del programa

/* t_semget.c
   Con licencia según la Licencia Pública General de GNU v2 o posterior.
*/
#include <stdio.h>
#include <stdlib.h>
#include <sys/ipc.h>
#include <sys/sem.h>
#include <unistd.h>
static void
uso(const char *pname)
{
    fprintf(stderr, "Uso: %s [-cx] nombre_archivo id_proyecto num_sems\n",
            pname);
    fprintf(stderr, "    -c           Usar flag IPC_CREAT\n");
    fprintf(stderr, "    -x           Usar flag IPC_EXCL\n");
    exit(EXIT_FAILURE);
}
int
main(int argc, char *argv[])
{
    int    semid, nsems, flags, opt;
    key_t  key;
    flags = 0;
    while ((opt = getopt(argc, argv, "cx")) != -1) {
        switch (opt) {
        case 'c': flags |= IPC_CREAT;   break;
        case 'x': flags |= IPC_EXCL;    break;
        default:  uso(argv[0]);
        }
    }
    if (argc != optind + 3)
        uso(argv[0]);
    key = ftok(argv[optind], argv[optind + 1][0]);
    if (key == -1) {
        perror("ftok");
        exit(EXIT_FAILURE);
    }
    nsems = atoi(argv[optind + 2]);
    semid = semget(key, nsems, flags | 0600);
    if (semid == -1) {
        perror("semget");
        exit(EXIT_FAILURE);
    }
    printf("ID = %d\n", semid);
    exit(EXIT_SUCCESS);
}
