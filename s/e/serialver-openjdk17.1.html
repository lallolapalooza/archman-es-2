SERIALVER(1) Comandos JDK SERIALVER(1)

NOMBRE

serialver - devuelve el serialVersionUID para una o más clases en un formato adecuado para copiar en una clase en evolución

SINOPSIS

serialver [opciones] [nombres-de-clase]

opciones
Representa las opciones de línea de comandos para el comando serialver. Ver OPCIONES PARA SERIALVER.
nombres-de-clase
Las clases para las que se devolverá el serialVersionUID.

DESCRIPCIÓN

El comando serialver devuelve el serialVersionUID para una o más clases en un formato adecuado para copiar en una clase en evolución. Cuando se llama sin argumentos, el comando serialver imprime una línea de uso.

OPCIONES PARA SERIALVER

-classpath ruta-archivos
Establece la ruta de búsqueda de clases y recursos de la aplicación. Separe las clases y recursos con dos puntos (:).
-Jopción
Pasa la opción especificada a la Máquina Virtual Java, donde opción es una de las opciones descritas en la página de referencia del lanzador de aplicaciones Java. Por ejemplo, -J-Xms48m establece la memoria de inicio en 48 MB.

NOTAS

El comando serialver carga e inicializa las clases especificadas en su máquina virtual y, de forma predeterminada, no establece un gestor de seguridad. Si el comando serialver se va a ejecutar con clases no confiables, entonces se puede establecer un gestor de seguridad con la siguiente opción:

-J-Djava.security.manager

Cuando sea necesario, se puede especificar una política de seguridad con la siguiente opción:

-J-Djava.security.policy=archivo-política
