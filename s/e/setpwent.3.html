getpwent(3) Manual de funciones de biblioteca getpwent(3)

NOMBRE

getpwent, setpwent, endpwent - obtener entrada del archivo de contraseñas

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/types.h>
#include <pwd.h>
struct passwd *getpwent(void);
void setpwent(void);
void endpwent(void);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

getpwent(), setpwent(), endpwent():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

La función getpwent() devuelve un puntero a una estructura que contiene los campos desglosados de un registro de la base de datos de contraseñas (por ejemplo, el archivo de contraseñas local /etc/passwd, NIS y LDAP). La primera vez que se llama a getpwent(), devuelve la primera entrada; posteriormente, devuelve entradas sucesivas.

La función setpwent() rebobina al principio de la base de datos de contraseñas.

La función endpwent() se utiliza para cerrar la base de datos de contraseñas después de que se haya realizado todo el procesamiento.

La estructura passwd se define en <pwd.h> de la siguiente manera:


struct passwd {
    char   *pw_name;       /* nombre de usuario */
    char   *pw_passwd;     /* contraseña de usuario */
    uid_t   pw_uid;        /* ID de usuario */
    gid_t   pw_gid;        /* ID de grupo */
    char   *pw_gecos;      /* información del usuario */
    char   *pw_dir;        /* directorio principal */
    char   *pw_shell;      /* programa shell */
};

Para más información sobre los campos de esta estructura, ver passwd(5).

VALOR DE RETORNO

La función getpwent() devuelve un puntero a una estructura passwd, o NULL si no hay más entradas o ocurrió un error. Si ocurre un error, errno se establece para indicar el error. Si se desea verificar errno después de la llamada, debe establecerse a cero antes de la llamada.

El valor de retorno puede apuntar a un área estática y puede ser sobrescrito por llamadas posteriores a getpwent(), getpwnam(3), o getpwuid(3). (No pase el puntero devuelto a free(3).)

ERRORES

EINTR
Se capturó una señal; ver signal(7).
EIO
Error de E/S.
EMFILE
Se alcanzó el límite por proceso del número de descriptores de archivo abiertos.
ENFILE
Se alcanzó el límite a nivel de sistema del número total de archivos abiertos.
ENOMEM
Memoria insuficiente para asignar la estructura passwd.
ERANGE
Espacio de búfer insuficiente suministrado.

FICHEROS

/etc/passwd
archivo de base de datos de contraseñas local

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
getpwent () Seguridad en hilos MT-Unsafe race:pwent race:pwentbuf locale
setpwent (), endpwent () Seguridad en hilos MT-Unsafe race:pwent locale

En la tabla anterior, pwent en race:pwent significa que si alguna de las funciones setpwent(), getpwent(), o endpwent() se utilizan en paralelo en diferentes hilos de un programa, entonces podrían ocurrir carreras de datos.

VERSIÓNES

El campo pw_gecos no está especificado en POSIX, pero está presente en la mayoría de las implementaciones.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001, SVr4, 4.3BSD.

VER TAMBIÉN

fgetpwent(3), getpw(3), getpwent_r(3), getpwnam(3), getpwuid(3), putpwent(3), passwd(5)
