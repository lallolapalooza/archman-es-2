getenv(3) Manual de Funciones de Biblioteca getenv(3)

NOMBRE

getenv, secure_getenv - obtener una variable de entorno

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
char *getenv(const char *name);
char *secure_getenv(const char *name);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

secure_getenv():

    _GNU_SOURCE

DESCRIPCIÓN

La función getenv() busca en la lista de entorno la variable de entorno name y devuelve un puntero a la cadena value correspondiente.

La función secure_getenv() es igual que getenv() excepto que devuelve NULL en casos donde se requiere una "ejecución segura". La ejecución segura se requiere si alguna de las siguientes condiciones fue verdadera cuando el programa ejecutado por el proceso llamante se cargó:

•
el ID de usuario efectivo del proceso no coincidía con su ID de usuario real o el ID de grupo efectivo del proceso no coincidía con su ID de grupo real (típicamente, esto es el resultado de ejecutar un programa set-user-ID o set-group-ID);
•
el bit de capacidad efectiva estaba configurado en el archivo ejecutable; o
•
el proceso tiene un conjunto de capacidades permitidas no vacío.

La ejecución segura también puede ser requerida si se activa por algunos módulos de seguridad de Linux.

La función secure_getenv() está destinada a su uso en bibliotecas de propósito general para evitar vulnerabilidades que podrían ocurrir si programas set-user-ID o set-group-ID confiaran accidentalmente en el entorno.

VALOR DE RETORNO

La función getenv() devuelve un puntero al valor en el entorno, o NULL si no hay coincidencia.

NOTAS

Las cadenas en la lista de entorno son del tipo nombre=valor.

Como se implementa típicamente, getenv() devuelve un puntero a una cadena dentro de la lista de entorno. El llamante debe tener cuidado de no modificar esta cadena, ya que eso cambiaría el entorno del proceso.

La implementación de getenv() no se requiere que sea reentrante. La cadena a la que apunta el valor de retorno de getenv() puede estar asignada estáticamente y puede ser modificada por una llamada posterior a getenv(), putenv(3), setenv(3), o unsetenv(3).

El modo de "ejecución segura" de secure_getenv() está controlado por el flag AT_SECURE contenido en el vector auxiliar pasado del kernel al espacio de usuario.
