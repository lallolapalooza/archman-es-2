SEM_INIT(3P) Manual de Programador de POSIX SEM_INIT(3P)

PROLOGO

Esta página del manual forma parte del Manual de Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sem_init — inicializa un semáforo sin nombre

SINOPSIS

#include <semaphore.h>
int sem_init(sem_t *sem, int pshared, unsigned value);

DESCRIPCION

La función sem_init() inicializará el semáforo sin nombre al que se refiere sem. El valor del semáforo inicializado será value. Después de una llamada exitosa a sem_init(), el semáforo podrá ser utilizado en llamadas posteriores a sem_wait(), sem_timedwait(), sem_trywait(), sem_post() y sem_destroy(). Este semáforo permanecerá utilizable hasta que sea destruido.

Si el argumento pshared tiene un valor distinto de cero, entonces el semáforo es compartido entre procesos; en este caso, cualquier proceso que pueda acceder al semáforo sem puede usar sem para realizar operaciones sem_wait(), sem_timedwait(), sem_trywait(), sem_post() y sem_destroy().

Si el argumento pshared es cero, entonces el semáforo es compartido entre hilos del proceso; cualquier hilo en este proceso puede usar sem para realizar operaciones sem_wait(), sem_timedwait(), sem_trywait(), sem_post() y sem_destroy().

Consulte la Sección 2.9.9, Copias de Objetos de Sincronización y Mapeos Alternativos para obtener requisitos adicionales.

Intentar inicializar un semáforo ya inicializado da como resultado un comportamiento indefinido.

VALOR DE RETORNO

Al completarse con éxito, la función sem_init() inicializará el semáforo en sem y devolverá 0. De lo contrario, devolverá -1 y establecerá errno para indicar el error.

ERRORES

La función sem_init() fallará si:

EINVAL
El argumento value excede {SEM_VALUE_MAX}.
ENOSPC
Se ha agotado un recurso necesario para inicializar el semáforo, o se ha alcanzado el límite de semáforos ({SEM_NSEMS_MAX}).
EPERM
El proceso no tiene los privilegios adecuados para inicializar el semáforo.
