NOMBRE

seccomp_release - Liberar el estado del filtro seccomp

SINOPSIS

#include <seccomp.h>

typedef void * scmp_filter_ctx;

void seccomp_release(scmp_filter_ctx ctx);

Enlazar con -lseccomp.

DESCRIPCIÓN

Libera el filtro seccomp en ctx que fue inicializado por primera vez con seccomp_init(3) o seccomp_reset(3) y libera cualquier memoria asociada con el contexto del filtro seccomp dado. Cualquier filtro seccomp cargado en el kernel no se ve afectado.

VALOR DE RETORNO

No devuelve un valor.

EJEMPLOS

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc;
	scmp_filter_ctx ctx;
	ctx = seccomp_init(SCMP_ACT_KILL);
	if (ctx == NULL)
		return 1;
	/* ... */
	seccomp_release(ctx);
	return 0;
}

NOTAS

Aunque el filtro seccomp se puede generar independientemente del kernel, se requiere soporte del kernel para cargar y aplicar el filtro seccomp generado por libseccomp.

El sitio del proyecto libseccomp, con más información y el repositorio de código fuente, se puede encontrar en https://github.com/seccomp/libseccomp. Esta herramienta, así como la biblioteca libseccomp, se encuentran actualmente en desarrollo, por favor, informe cualquier error en el sitio del proyecto o directamente al autor.
