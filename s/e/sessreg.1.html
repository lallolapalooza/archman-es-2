NOMBRE

sessreg - gestiona entradas utmpx/wtmpx para clientes que no son init

SINOPSIS

sessreg [-w archivo-wtmpx] [-u archivo-utmpx] [-L archivo-lastlog]
    [-l nombre-línea] [-h nombre-host] [-s número-slot]
    [-x archivo-Xservers] [-t archivo-ttys] [-V] [-a] [-d] nombre-usuario

DESCRIPCIÓN

Sessreg es un programa sencillo para gestionar entradas utmpx/wtmpx y lastlog para sesiones xdm.

Esta versión de sessreg está construida utilizando las interfaces modernas POSIX pututxline(3c), que ya no requieren el número de slot, el archivo ttys ni las asignaciones del archivo Xservers. Para compatibilidad con versiones anteriores y otros sistemas operativos, se aceptan las banderas -s, -t y -x, pero se ignoran.

USO

En Xstartup, coloque una llamada como:

       sessreg -a -l $DISPLAY -x /etc/X11/xdm/Xservers $USER

y en Xreset:

       sessreg -d -l $DISPLAY -x /etc/X11/xdm/Xservers $USER

OPCIONES

-w archivo-wtmpx
Esto especifica un archivo wtmpx alternativo, en lugar de /var/log/wtmp. El nombre especial "none" deshabilita la escritura de registros en el archivo wtmpx.
-u archivo-utmpx
Esto especifica un archivo utmpx alternativo, en lugar de /var/run/utmp. El nombre especial "none" deshabilita la escritura de registros en el archivo utmpx.
-L archivo-lastlog
Esto especifica un archivo lastlog alternativo, en lugar de /var/log/lastlog, si la plataforma soporta archivos lastlog. El nombre especial "none" deshabilita la escritura de registros en el archivo lastlog.
-l nombre-línea
Esto describe el nombre de "línea" de la entrada. Para sesiones de terminal, este es el segmento de ruta final del nombre de archivo del dispositivo de terminal (por ejemplo, ttyd0). Para sesiones X, probablemente debería ser el nombre de pantalla local dado a la sesión del usuario (por ejemplo, :0). Si no se especifica ninguno, el nombre del terminal se determinará con ttyname(3) y se le eliminarán los componentes iniciales.
-h nombre-host
Esto se establece para indicar que la sesión se inició desde un host remoto. En el uso típico de xdm, esta opción no se utiliza.
-s número-slot
Esta opción se acepta por compatibilidad, pero no hace nada en esta versión de sessreg.
-x archivo-Xservers
Esta opción se acepta por compatibilidad, pero no hace nada en esta versión de sessreg.
-t archivo-ttys
Esta opción se acepta por compatibilidad, pero no hace nada en esta versión de sessreg.
-V, --version
Esta opción hace que el comando imprima su versión y salga.
-a
Esta sesión debe añadirse a utmpx/wtmpx.
-d
Esta sesión debe eliminarse de utmpx/wtmpx. Se debe especificar uno de -a/-d.

VER TAMBIÉN

xdm(1), utmpx(5), wtmpx(5)
