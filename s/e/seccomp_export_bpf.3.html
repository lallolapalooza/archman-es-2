NOMBRE

seccomp_export_bpf, seccomp_export_pfc - Exportar el filtro seccomp

SINOPSIS

#include <seccomp.h>

typedef void * scmp_filter_ctx;

int seccomp_export_bpf(const scmp_filter_ctx ctx, int fd);
int seccomp_export_pfc(const scmp_filter_ctx ctx, int fd);

Enlazar con -lseccomp.

DESCRIPCIÓN

Las funciones seccomp_export_bpf() y seccomp_export_pfc() generan y exportan el filtro seccomp actual en formato BPF (Berkeley Packet Filter) o PFC (Pseudo Filter Code). La salida de seccomp_export_bpf() es adecuada para cargarla en el kernel, mientras que la salida de seccomp_export_pfc() es legible por humanos y está destinada principalmente como herramienta de depuración para desarrolladores que utilizan libseccomp. Ambas funciones escriben el filtro en el descriptor de archivo fd.

El contexto del filtro ctx es el valor devuelto por la llamada a seccomp_init(3).

Si bien los dos formatos de salida están garantizados que son funcionalmente equivalentes para la configuración de filtro seccomp dada, las instrucciones del filtro y su orden no están garantizadas que sean las mismas en ambos formatos BPF y PFC.

VALOR DE RETORNO

Devuelve cero en caso de éxito o uno de los siguientes códigos de error en caso de fallo:

-ECANCELED
Hubo un fallo del sistema más allá del control de la biblioteca.
-EFAULT
Fallo interno de libseccomp.
-EINVAL
Entrada inválida, ya sea el contexto o el token de arquitectura no son válidos.
-ENOMEM
La biblioteca no pudo asignar suficiente memoria.

Si el atributo de filtro SCMP_FLTATR_API_SYSRAWRC es distinto de cero, pueden devolverse códigos de error adicionales al llamador; estos códigos de error adicionales son los valores negativos de errno devueltos por el sistema. Lamentablemente, libseccomp no puede garantizar estos valores de retorno.

EJEMPLOS

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc = -1;
	scmp_filter_ctx ctx;
	int filter_fd;
	ctx = seccomp_init(SCMP_ACT_KILL);
	if (ctx == NULL)
		goto out;
	/* ... */
	filter_fd = open("/tmp/seccomp_filter.bpf", O_WRONLY);
	if (filter_fd == -1) {
		rc = -errno;
		goto out;
	}
	rc = seccomp_export_bpf(ctx, filter_fd);
	if (rc < 0) {
		close(filter_fd);
		goto out;
	}
	close(filter_fd);
	/* ... */
out:
	seccomp_release(ctx);
	return -rc;
}

NOTAS

Si bien el filtro seccomp se puede generar independientemente del kernel, se requiere soporte del kernel para cargar y aplicar el filtro seccomp generado por libseccomp.

El sitio del proyecto libseccomp, con más información y el repositorio de código fuente, se puede encontrar en https://github.com/seccomp/libseccomp. Esta herramienta, así como la biblioteca libseccomp, está actualmente en desarrollo; por favor, informe cualquier error en el sitio del proyecto o directamente al autor.
