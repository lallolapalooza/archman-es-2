setbuf(3) Manual de Funciones de Biblioteca setbuf(3)

NOMBRE

setbuf, setbuffer, setlinebuf, setvbuf - operaciones de almacenamiento en búfer de flujo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
int setvbuf(size_t size;
            FILE *restrict stream, char buf[restrict size],
            int mode, size_t size);
void setbuf(FILE *restrict stream, char *restrict buf);
void setbuffer(size_t size;
            FILE *restrict stream, char buf[restrict size],
            size_t size);
void setlinebuf(FILE *stream);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

setbuffer(), setlinebuf():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE

DESCRIPCIÓN

Los tres tipos de almacenamiento en búfer disponibles son sin búfer, con búfer de bloque y con búfer de línea. Cuando un flujo de salida no tiene búfer, la información aparece en el archivo o terminal de destino tan pronto como se escribe; cuando tiene búfer de bloque, se guardan muchos caracteres y se escriben como un bloque; cuando tiene búfer de línea, se guardan caracteres hasta que se emite una nueva línea o se lee entrada de cualquier flujo conectado a un dispositivo de terminal (típicamente stdin). La función fflush(3) puede usarse para forzar la salida del bloque de forma anticipada. (Ver fclose(3)).

Normalmente, todos los archivos tienen búfer de bloque. Si un flujo se refiere a una terminal (como lo hace normalmente stdout), tiene búfer de línea. El flujo de error estándar stderr siempre está sin búfer por defecto.

La función setvbuf() puede usarse en cualquier flujo abierto para cambiar su búfer. El argumento mode debe ser una de las siguientes tres macros:

_IONBF
sin búfer
_IOLBF
búfer de línea
_IOFBF
búfer completo

Excepto para archivos sin búfer, el argumento buf debe apuntar a un búfer de al menos size bytes de longitud; este búfer se usará en lugar del búfer actual. Si el argumento buf es NULL, solo se afecta el modo; se asignará un nuevo búfer en la próxima operación de lectura o escritura. La función setvbuf() puede usarse solo después de abrir un flujo y antes de que se hayan realizado otras operaciones sobre él.

Las otras tres llamadas son, en efecto, simplemente alias de llamadas a setvbuf(). La función setbuf() es exactamente equivalente a la llamada


setvbuf(stream, buf, buf ? _IOFBF : _IONBF, BUFSIZ);

La función setbuffer() es la misma, excepto que el tamaño del búfer depende del llamador, en lugar de ser determinado por el BUFSIZ predeterminado. La función setlinebuf() es exactamente equivalente a la llamada:


setvbuf(stream, NULL, _IOLBF, 0);

VALOR DE RETORNO

La función setvbuf() devuelve 0 si tiene éxito. Devuelve un valor distinto de cero si falla (mode es inválido o la solicitud no puede ser satisfecha). Puede establecer errno en caso de fallo.

Las otras funciones no devuelven un valor.

ADVERTENCIAS

POSIX señala que el valor de errno no se especifica después de una llamada a setbuf() y además señala que, dado que el valor de errno no se requiere que permanezca sin cambios después de una llamada exitosa a setbuf(), las aplicaciones deberían usar setvbuf() en su lugar para detectar errores.

ERRORES

Debes asegurarte de que el espacio al que apunta buf todavía exista para cuando se cierre stream, lo cual también ocurre al terminar el programa. Por ejemplo, lo siguiente es inválido:

#include <stdio.h>
int
main(void)
{
    char buf[BUFSIZ];
    setbuf(stdout, buf);
    printf("Hola, mundo!\n");
    return 0;
}
