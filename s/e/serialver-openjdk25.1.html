SERIALVER(1) Comandos JDK SERIALVER(1)

NOMBRE

serialver - devuelve el serialVersionUID para una o más clases en un formato adecuado para copiar en una clase en evolución

SINOPSIS

serialver [opciones] [nombres de clase]

opciones
Esto representa las opciones de línea de comandos para el comando serialver. Consulte OPCIONES PARA SERIALVER.
nombres de clase
Las clases para las que se va a devolver el serialVersionUID.

DESCRIPCIÓN

El comando serialver devuelve el serialVersionUID para una o más clases en un formato adecuado para copiar en una clase en evolución. Cuando se invoca sin argumentos, el comando serialver imprime una línea de uso.

OPCIONES PARA SERIALVER

-classpath ruta-archivos
Establece la ruta de búsqueda para las clases y recursos de la aplicación. Separe clases y recursos con dos puntos (:).
-Jopción
Pasa la opción especificada a la Máquina Virtual Java, donde opción es una de las opciones descritas en la página de referencia del lanzador de aplicaciones Java. Por ejemplo, -J-Xms48m establece la memoria de inicio en 48 MB.

ADVERTENCIA

El comando serialver carga e inicializa las clases especificadas para determinar sus valores de serialVersionUID. NO EJECUTE serialver en clases no confiables.
