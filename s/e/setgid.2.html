setgid(2) Manual de llamadas al sistema setgid(2)

NOMBRE

setgid - establecer la identidad de grupo

LIBRERÍA

Librería C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int setgid(gid_t gid);

DESCRIPCIÓN

setgid() establece el ID de grupo efectivo del proceso llamante. Si el proceso llamante tiene privilegios (más precisamente: tiene la capacidad CAP_SETGID en su espacio de nombres de usuario), el ID de grupo real y el ID de grupo de conjunto guardado también se establecen.

En Linux, setgid() se implementa de forma similar a la versión POSIX con la característica _POSIX_SAVED_IDS. Esto permite que un programa set-group-ID que no sea set-user-ID-root elimine todos sus privilegios de grupo, realice un trabajo no privilegiado y luego vuelva a activar el ID de grupo efectivo original de manera segura.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
El ID de grupo especificado en gid no es válido en este espacio de nombres de usuario.
EPERM
El proceso llamante no tiene privilegios (no tiene la capacidad CAP_SETGID en su espacio de nombres de usuario), y gid no coincide con el ID de grupo real ni con el ID de grupo de conjunto guardado del proceso llamante.

VERSIÓNES

Diferencias entre librería C/kernel

A nivel de kernel, los ID de usuario y los ID de grupo son un atributo por hilo. Sin embargo, POSIX requiere que todos los hilos de un proceso compartan las mismas credenciales. La implementación de hilos NPTL maneja los requisitos de POSIX proporcionando funciones de envoltura para las diversas llamadas al sistema que cambian los UID y GID del proceso. Estas funciones de envoltura (incluida la de setgid()) emplean una técnica basada en señales para garantizar que cuando un hilo cambia las credenciales, todos los demás hilos del proceso también cambien sus credenciales. Para obtener detalles, consulte nptl(7).

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, SVr4.

La llamada al sistema setgid() original de Linux solo soportaba ID de grupo de 16 bits. Posteriormente, Linux 2.4 añadió setgid32() que soportaba ID de 32 bits. La función de envoltura setgid() de glibc maneja de forma transparente la variación entre versiones del kernel.

VER TAMBIÉN
