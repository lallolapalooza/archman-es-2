NOMBRE

seatd - Un demonio de gestión de asientos

SINOPSIS

seatd [opciones]

OPCIONES

-h

Mostrar mensaje de ayuda y salir.

-n <fd>

FD para notificar la preparación. Se escribirá una sola línea nueva y se cerrará el fd cuando seatd esté listo para servir solicitudes. Esto es compatible con el protocolo de notificación de s6.

-u <usuario>

Usuario al que pertenecerá el socket de seatd.

-g <grupo>

Grupo al que pertenecerá el socket de seatd.

-l <nivel_de_registro>

Nivel de registro a utilizar. Debe ser uno de debug, info, error o silent. Por defecto es error.

-v

Mostrar el número de versión y salir.

DESCRIPCIÓN

seatd proporciona gestión centralizada de asientos, mediando el acceso a recursos compartidos como pantallas y dispositivos de entrada en un entorno multi-sesión y multi-asiento.

seatd opera a través de un socket de dominio UNIX, con libseat proporcionando el lado del cliente del protocolo.

La ubicación del socket para seatd se establece en tiempo de compilación.

ENTORNO

SEATD_VTBOUND

Si se establece en "0", el asiento no se vinculará a una VT.

VER TAMBIÉN

La biblioteca libseat, <libseat.h>, seatd-launch(1)

AUTORES

Mantenido por Kenny Levinsen <contact@kl.wtf>, quien cuenta con la ayuda de otros colaboradores de código abierto. Para más información sobre el desarrollo de seatd, consulte https://sr.ht/~kennylevinsen/seatd.
