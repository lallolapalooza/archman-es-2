SERIALVIEW(1) Manual de comandos generales SERIALVIEW(1)

NOMBRE

serialview - Emulador de terminal para uCsim

SINOPSIS

serialview -i <nombre de archivo> -o <nombre de archivo> -L n -a <patrón> -A <respuesta> -IOh

DESCRIPCIÓN

serialview es un emulador de terminal simple que se puede usar con uCsim.

OPCIONES

-i nombre de archivo
nombre de archivo es la tubería de entrada serie del controlador. Los caracteres escritos en el panel de entrada se escribirán en este archivo.
-o nombre de archivo
nombre de archivo es la tubería de salida serie del controlador. El contenido de este archivo se presenta en el panel de salida.
-I
Usa un filtro hexadecimal en la entrada. Solo se aceptan caracteres hexadecimales en el panel de entrada. Dos caracteres se combinan en un código hexadecimal y el valor se escribe en la tubería de entrada.
-O
Usa un filtro hexadecimal en la salida. El contenido de la tubería de salida se presenta como un volcado hexadecimal. La opción -L se puede usar para establecer cuántos bytes se imprimen en una línea.
-a patrón
patrón es una cadena que se reconoce en el flujo de salida y se responde automáticamente enviando una cadena de respuesta (ver opción -A). La cadena puede tener el formato de una cadena C, los caracteres no ASCII pueden escaparse al estilo C.
-A respuesta
respuesta es una cadena que se envía cuando se detecta un patrón (ver opción -a) en la salida del simulador. Esta cadena de respuesta se escribe en la tubería de entrada, pero no se muestra en el panel de entrada.
-L n
Establece la longitud de línea del volcado hexadecimal en el panel de salida (por defecto=8).
-h
Muestra un resumen de las opciones.

Cuando no se proporcionan opciones, las tuberías de entrada y salida se crean en /tmp y se nombran respectivamente in y out

VER TAMBIÉN

sdcc(1), ucsim(1).
