SETFONT(8) Manual del Administrador del Sistema SETFONT(8)

NOMBRE

setfont - carga la fuente de la pantalla de consola EGA/VGA

SINOPSIS

setfont [-O fuente+umap.orig] [-o fuente.orig] [-om cmap.orig] [-ou umap.orig] [-N] [fuente.nueva ...] [-m cmap] [-u umap] [-C consola] [-hH] [-f] [-v] [-V]

DESCRIPCIÓN

El comando setfont lee una fuente del archivo fuente.nueva y la carga en el generador de caracteres EGA/VGA, y opcionalmente genera la fuente anterior. También puede cargar varias tablas de mapeo y generar las versiones anteriores.

Si no se proporcionan argumentos (o solo la opción -N para algún número N), entonces se carga una fuente predeterminada (8xN) (ver abajo). Se pueden proporcionar varias fuentes pequeñas, todas conteniendo una tabla Unicode, y setfont las combinará y cargará la unión. Uso típico:

setfont
Cargar una fuente predeterminada.
setfont drdos8x16
Cargar una fuente dada (aquí la fuente drdos de 448 glifos).
setfont cybercafe -u cybercafe
Cargar una fuente dada que no tiene un mapa Unicode y proporcionar uno explícitamente.
setfont LatArCyrHeb-19 -m 8859-2
Cargar una fuente dada (aquí una fuente de 512 glifos que combina varios conjuntos de caracteres) e indicar que el conjunto de caracteres local es ISO 8859-2.

Nota: si una fuente tiene más de 256 glifos, solo se pueden usar 8 de 16 colores simultáneamente. Puede empeorar la percepción de la consola (pérdida de intensidad e incluso algunos colores).

FORMATOS DE FUENTE

El formato estándar de fuente de Linux es la fuente PSF. Tiene una cabecera que describe las propiedades de la fuente como el tamaño del carácter, seguida de los mapas de bits de los glifos, opcionalmente seguida por una tabla de mapeo Unicode que proporciona el valor Unicode para cada glifo. Se reconocen varios otros formatos de fuente (obsoletos). Si el archivo de entrada tiene formato de página de código (probablemente con sufijo .cp), que contiene tres fuentes con tamaños p. ej. 8x8, 8x14 y 8x16, entonces se debe usar una de las opciones -8, -14 o -16 para seleccionar una. Los archivos de fuente en bruto son archivos binarios de 256*N bytes, que contienen imágenes de bits para cada uno de los 256 caracteres, un byte por línea de escaneo y N bytes por carácter (0 < N <= 32). La mayoría de las fuentes tienen un ancho de 8 bits, pero con el dispositivo framebuffer (fb) se pueden usar otros anchos.

ALTURA DE FUENTE

El programa setfont no tiene conocimiento incorporado de los modos de video EGA/VGA, sino que simplemente solicita al kernel que cargue la ROM de caracteres de la tarjeta de video con ciertos mapas de bits. Sin embargo, desde Linux 1.3.1, el kernel sabe lo suficiente sobre los modos de video EGA/VGA como para seleccionar una distancia de línea diferente. La altura predeterminada del carácter será el número N inferido de la fuente o especificado por opción. Sin embargo, el usuario puede especificar una altura de carácter diferente H usando la opción -h.

MAPAS DE CONSOLA

Varias asignaciones están involucradas en el camino desde la salida del programa de usuario hasta la visualización de la consola. Si la consola está en modo utf8 (ver unicode_start(1)) entonces el kernel espera que la salida del programa de usuario esté codificada como UTF-8 (ver utf-8(7)), y la convierte a Unicode (ucs2). De lo contrario, se utiliza una tabla de traducción desde la salida de 8 bits del programa a valores Unicode de 16 bits. Dicha tabla de traducción se llama un mapa de consola Unicode. Hay cuatro de ellas: tres integradas en el kernel, la cuarta se puede configurar usando la opción -m de setfont. Una secuencia de escape elige entre estas cuatro tablas; después de cargar un cmap, setfont generará la secuencia de escape Esc ( K que la convierte en la traducción activa.

Argumentos adecuados para la opción -m son, por ejemplo, 8859-1, 8859-2, ..., 8859-15, cp437, ..., cp1250.

Dado el valor Unicode del símbolo a mostrar, el kernel encuentra el glifo correcto en la fuente usando la información de mapeo Unicode de la fuente y lo muestra.

Las fuentes antiguas no tienen información de mapeo Unicode, y para manejarlas existen mapas directos a fuente (también cargados usando -m) que proporcionan una correspondencia entre bytes de usuario y posiciones de fuente. La correspondencia más común es la dada en el archivo trivial (donde los valores de bytes de usuario se usan directamente como posiciones de fuente). Otras correspondencias son a veces preferibles ya que el hardware de video de PC espera caracteres de línea de dibujo en ciertas posiciones de fuente.

Proporcionar un argumento -m none inhibe la carga y activación de una tabla de mapeo. El mapa de consola anterior se puede guardar en un archivo usando la opción -om archivo. Estas opciones de setfont hacen que mapscrn(8) sea obsoleto. (Sin embargo, puede ser útil leer esa página del manual.)

MAPAS DE FUENTE UNICODE

La correspondencia entre los glifos en la fuente y los valores Unicode se describe mediante una tabla de mapeo Unicode. Muchas fuentes tienen una tabla de mapeo Unicode incluida en el archivo de fuente, y se puede indicar una tabla explícita usando la opción -u. El programa setfont cargará dicha tabla de mapeo Unicode, a menos que se proporcione un argumento -u none. La tabla de mapeo Unicode anterior se guardará como parte del archivo de fuente guardado cuando se usa la opción -O. Se puede guardar en un archivo separado usando la opción -ou archivo. Estas opciones de setfont hacen que loadunimap(8) sea obsoleto.

La tabla de mapeo Unicode debe asignar algún glifo al valor de `carácter faltante' U+fffd, de lo contrario los caracteres faltantes no se traducen, lo que da un resultado generalmente muy confuso.

Generalmente no se necesita ninguna tabla de mapeo, y una tabla de mapeo Unicode ya está incluida en la fuente (a veces esto se indica con la extensión .psfu), por lo que la mayoría de los usuarios no necesitan preocuparse por el significado y funcionamiento precisos de estas tablas de mapeo.

Se puede agregar una tabla de mapeo Unicode a una fuente psf usando psfaddtable(1).

OPCIONES

-N, --predeterminado8x=N
Cargar fuente predeterminada (predeterminada8xN).
-hN, --altura-fuente=N
Anular la altura de la fuente. La opción corta no debe tener un espacio entre el prefijo y el número.
-d, --doble
Duplica el tamaño de la fuente, replicando todos sus píxeles vertical y horizontalmente. Esto es adecuado para pantallas de alta densidad de píxeles (por ejemplo, "4k") en las que las fuentes estándar son demasiado pequeñas para ser fácilmente legibles. Debido a las limitaciones del kernel, esto solo es adecuado para fuentes de 16x16 o más pequeñas.
-o, --fuente-salida=ARCHIVO
Guardar la fuente anterior en ARCHIVO.
-om, --mapa-consola-salida=ARCHIVO
Almacenar el mapa de consola en ARCHIVO.
-ou, --mapa-unicode-salida=ARCHIVO
Guardar el mapa Unicode anterior en ARCHIVO.
-O, --fuente-completa-salida=ARCHIVO
Guardar la fuente y el mapa Unicode anteriores en ARCHIVO.
-m, --mapa-consola=ARCHIVO
Cargar el mapa de consola o el mapa de consola Unicode desde ARCHIVO.
-u, --mapa-unicode=ARCHIVO
Cargar la tabla Unicode que describe la fuente desde ARCHIVO.
-C, --consola=DISPOSITIVO
Establecer la fuente para la consola indicada. (Puede requerir permisos de root.)
-f, --forzar
Forzar carga del mapa unicode: Setfont`emite la llamada al sistema para cargar el mapa unicode incluso si el mapa especificado está vacío. Esto puede ser útil en casos inusuales.
-R, --restablecer
Restablecer la pantalla f

EJEMPLOS

Para cargar la fuente estándar de 8 píxeles de alto:

# setfont -8

Para cargar una fuente de 16 píxeles de alto desde un archivo:

# setfont -h16 /usr/share/kbd/consolefonts/LatGrkCyr-8x16.psfu.gz

Para guardar la fuente actual en un archivo antes de cargar una nueva:

# setfont -o original.psf
# setfont newfont.psf

Para guardar tanto la fuente como el mapa Unicode actual en un solo archivo:

# setfont -O original_full.psf
# setfont newfont.psf

Para cargar una fuente y su mapa Unicode correspondiente desde un archivo:

# setfont LatGrkCyr-8x16.psfu

Para cargar una fuente sin mapa Unicode y luego especificar uno:

# setfont -u /usr/share/kbd/consoletrans/cp437.uni myfont.fnt

OPTIONS

-f, --font FONT
Use FONT as the console font. The FONT argument should be the name of a font file. The font search path is defined by the environment variables FONTDIR and UNICODEDIR. If no font is specified, the font specified by the setfont command in the system startup scripts (e.g. in rc.local) is used.
-u, --unicode
Load the Unicode font mapping from the font file. If the font file doesn't contain Unicode mapping, the system will try to load it from a file with the same name as the font but with extension .uni or .cp. This option is enabled by default when using unicode_start.
-U, --no-unicode
Disable Unicode font mapping. This is the default.
-k, --keep
Don't clear the screen when setting the font. This is useful when switching fonts to keep the display unchanged.
-i, --ignore-errors
Ignore font loading errors and continue.
-m, --map SCREENMAP
Load the screen mapping from SCREENMAP. This is usually used for keyboard layout translation. The screen map files are searched in /usr/share/kbd/consoletrans.
-o, --no-map
Disable screen mapping. This is the default.
-c, --charset CHARSET
Set the character set to CHARSET. This option is relevant for some font formats that support multiple character sets. The available character sets depend on the font file.
-s, --swap
Swap the meaning of the video-card specific bits for character attributes. This can be used to map Unicode characters to the video memory. This option is mainly used to set the default font and Unicode mapping to the bootup defaults.
-v, --verbose
Be verbose.
-V, --version
Print version and exit.
-h, --help
Print a message describing the options and exit.

NOTE

PC video hardware allows one to use the "intensity" bit either to indicate brightness, or to address 512 (instead of 256) glyphs in the font. So, if the font has more than 256 glyphs, the console will be reduced to 8 (instead of 16) colors.

FILES

/usr/share/kbd/consolefonts
The default font directory.
/usr/share/kbd/unimaps
The default directory for Unicode maps.
/usr/share/kbd/consoletrans
The default directory for screen mappings.

The default font is a file default (or default8xN if the -N option was given for some number N) perhaps with suitable extension (like .psf).
