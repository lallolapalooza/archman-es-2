setbuf(3) Manual de Funciones de Biblioteca setbuf(3)

NOMBRE

setbuf, setbuffer, setlinebuf, setvbuf - operaciones de bufferización de flujos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
int setvbuf(size_t size;
            FILE *restrict stream, char buf[restrict size],
            int mode, size_t size);
void setbuf(FILE *restrict stream, char *restrict buf);
void setbuffer(size_t size;
            FILE *restrict stream, char buf[restrict size],
            size_t size);
void setlinebuf(FILE *stream);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

setbuffer(), setlinebuf():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE

DESCRIPCIÓN

Los tres tipos de bufferización disponibles son sin buffer, con buffer de bloque y con buffer de línea. Cuando un flujo de salida no tiene buffer, la información aparece en el archivo o terminal de destino tan pronto como se escribe; cuando tiene buffer de bloque, se guardan muchos caracteres y se escriben como un bloque; cuando tiene buffer de línea, los caracteres se guardan hasta que se emite un salto de línea o se lee entrada de cualquier flujo conectado a un dispositivo de terminal (típicamente stdin). La función fflush(3) puede usarse para forzar la salida del bloque anticipadamente. (Ver fclose(3)).

Normalmente, todos los archivos tienen buffer de bloque. Si un flujo se refiere a una terminal (como lo hace normalmente stdout), tiene buffer de línea. El flujo de error estándar stderr siempre está sin buffer por defecto.

La función setvbuf() puede usarse en cualquier flujo abierto para cambiar su buffer. El argumento mode debe ser una de las siguientes tres macros:

_IONBF
sin buffer
_IOLBF
buffer de línea
_IOFBF
buffer completo

Excepto para archivos sin buffer, el argumento buf debe apuntar a un buffer de al menos size bytes de longitud; este buffer se usará en lugar del buffer actual. Si el argumento buf es NULL, solo se ve afectado el modo; se asignará un nuevo buffer en la próxima operación de lectura o escritura. La función setvbuf() puede usarse solo después de abrir un flujo y antes de que se hayan realizado otras operaciones sobre él.

Las otras tres llamadas son, en efecto, simplemente alias para llamadas a setvbuf(). La función setbuf() es exactamente equivalente a la llamada


setvbuf(stream, buf, buf ? _IOFBF : _IONBF, BUFSIZ);

La función setbuffer() es la misma, excepto que el tamaño del buffer es decidido por el llamador, en lugar de ser determinado por el valor predeterminado BUFSIZ. La función setlinebuf() es exactamente equivalente a la llamada:


setvbuf(stream, NULL, _IOLBF, 0);

VALOR DE RETORNO

La función setvbuf() devuelve 0 si tiene éxito. Devuelve un valor distinto de cero si falla (mode es inválido o la solicitud no puede ser satisfecha). Puede establecer errno en caso de fallo.

Las otras funciones no devuelven valor.

ADVERTENCIAS

POSIX señala que el valor de errno no está especificado después de una llamada a setbuf() y además señala que, dado que no se requiere que el valor de errno se mantenga sin cambios después de una llamada exitosa a setbuf(), las aplicaciones deben usar setvbuf() en su lugar para detectar errores.

ERRORES

Debe asegurarse de que el espacio al que apunta buf siga existiendo para cuando se cierre stream, lo cual también ocurre al terminar el programa. Por ejemplo, lo siguiente es inválido:

#include <stdio.h>
int
main(void)
{
    char buf[BUFSIZ];
    setbuf(stdout, buf);
    printf("Hola, mundo!\n");
    return 0;
}

setbuf(3) - CONTENIDO DE LA PÁGINA DEL MANUAL

#include <stdio.h>

void setbuf(FILE *stream, char *buf);

DESCRIPCIÓN

La función setbuf establece el método de buffer para el archivo stream. Si buf es un puntero NULL, entonces el buffering para stream se deshabilita. Si buf no es un puntero NULL, entonces buf debe apuntar a un buffer de tamaño BUFSIZ, y el buffer se utiliza para el buffering del archivo stream. El buffer predeterminado para los flujos de salida de texto se descarta cuando se encuentra un salto de línea, y el buffer predeterminado para los flujos de entrada de texto se descarta cuando se lee una línea completa. Si se proporciona un búfer por el usuario, la entrega se realiza en cada llamada de escritura de bajo nivel para stream.

VALOR DE RETORNO

setbuf no devuelve ningún valor.

EJEMPLO

Este ejemplo muestra cómo deshabilitar el buffering para un archivo. 

#include <stdio.h>

int main(void) {
    FILE *fp = fopen("test.txt", "w");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    // Deshabilitar el buffering para el archivo
    setbuf(fp, NULL);

    fprintf(fp, "This is a test line.\n");

    fclose(fp);
    return 0;
}
