SETVBUF(3P) Manual de Programador POSIX SETVBUF(3P)

PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación en Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

setvbuf — asignar búfer a un flujo

SINOPSIS

#include <stdio.h>
int setvbuf(FILE *restrict stream, char *restrict buf, int type,
    size_t size);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1-2017 remite al estándar ISO C.

La función setvbuf() puede usarse después de que el flujo apuntado por stream se asocie con un archivo abierto pero antes de que se realice cualquier otra operación (que no sea una llamada fallida a setvbuf()) sobre el flujo. El argumento type determina cómo se almacenará en búfer stream, de la siguiente manera:

*
{_IOFBF} causará que la entrada/salida se almacene completamente en búfer.
*
{_IOLBF} causará que la entrada/salida se almacene en búfer de línea.
*
{_IONBF} causará que la entrada/salida no se almacene en búfer.

Si buf no es un puntero nulo, el arreglo al que apunta puede ser usado en lugar de un búfer asignado por setvbuf() y el argumento size especifica el tamaño del arreglo; de lo contrario, size puede determinar el tamaño de un búfer asignado por la función setvbuf(). El contenido del arreglo en cualquier momento no está especificado.

Para obtener información sobre flujos, consulte la Sección 2.5, Flujos de E/S estándar.

VALOR DE RETORNO

Al completarse con éxito, setvbuf() devolverá 0. De lo contrario, devolverá un valor distinto de cero si se proporciona un valor inválido para type o si la solicitud no puede ser atendida, y puede establecer errno para indicar el error.

ERRORES

La función setvbuf() puede fallar si:

EBADF
El descriptor de archivo subyacente a stream no es válido.

USO POR LA APLICACIÓN

Una fuente común de error es asignar espacio de búfer como una variable "automática" en un bloque de código, y luego no cerrar el flujo en el mismo bloque.

Con setvbuf(), la asignación de un búfer de size bytes no implica necesariamente que todos los bytes de size se utilicen para el área del búfer.

Las aplicaciones deben tener en cuenta que muchas implementaciones solo proporcionan almacenamiento en búfer de línea en la entrada de terminales.
