setjmp.h(0P) Manual del programador POSIX setjmp.h(0P)

PRÓLOGO

Esta página del manual es parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

setjmp.h — declaraciones de entorno de pila

SINOPSIS

#include <setjmp.h>

DESCRIPCIÓN

Parte de la funcionalidad descrita en esta página de referencia amplía el estándar ISO C. Las aplicaciones definirán la macro de prueba de características apropiada (consulte el volumen de Interfaces del Sistema de POSIX.1‐2017, Sección 2.2, El Entorno de Compilación) para habilitar la visibilidad de estos símbolos en esta cabecera.

La cabecera <setjmp.h> definirá los tipos de arreglo jmp_buf y sigjmp_buf.

Se declararán las siguientes como funciones y también pueden definirse como macros. Se proporcionarán prototipos de función.

void   _longjmp(jmp_buf, int);
void   longjmp(jmp_buf, int);
void   siglongjmp(sigjmp_buf, int);

Las siguientes pueden declararse como funciones, o definirse como macros, o ambas. Si se declaran funciones, se proporcionarán prototipos de función.

int    _setjmp(jmp_buf);
int    setjmp(jmp_buf);
int    sigsetjmp(sigjmp_buf, int);
