self(n)

Paquete: tcl

Licencias: TCL

self(n) Comandos TclOO self(n)

NOMBRE

self - introspección de llamada de método

SINOPSIS

package require TclOO
self ?subcomando?

DESCRIPCIÓN

El comando self, que solo debe usarse desde el contexto de una llamada a un método (es decir, dentro del cuerpo de un método, constructor o destructor), se utiliza para permitir que el método descubra información sobre cómo se llamó. Toma un argumento, subcomando, que le indica qué tipo de información se desea realmente; si se omite, el resultado será el mismo que si se invocara self object. Los subcomandos soportados son:

self call
Esto devuelve una lista de dos elementos que describe las implementaciones de métodos utilizadas para implementar la cadena de llamadas actual. El primer elemento es el mismo que informaría info object call para el método actual (excepto que esto también informa valores útiles desde dentro de constructores y destructores, cuyos nombres se informan como <constructor> y <destructor> respectivamente), y el segundo elemento es un índice en la lista del primer elemento que indica qué implementación real se está ejecutando actualmente (la primera implementación en ejecutarse siempre está en el índice 0).
self caller
Cuando el método fue invocado desde dentro de otro método de objeto, este subcomando devuelve una lista de tres elementos que describe el objeto y el método contenedor. El primer elemento describe el objeto o clase que declara el método, el segundo elemento es el nombre del objeto sobre el que se invocó el método contenedor, y el tercer elemento es el nombre del método (con las cadenas <constructor> y <destructor> indicando constructores y destructores respectivamente).
self class
Esto devuelve el nombre de la clase dentro de la cual se definió el método actual. Tenga en cuenta que esto cambiará a medida que se recorra la cadena de implementaciones de métodos con next, y que si el método se definió en un objeto, esto fallará.

Si desea la clase del objeto actual, necesita usar esta otra construcción:

info object class [self object]
self filter
Cuando se invoca dentro de un filtro, este subcomando devuelve una lista de tres elementos que describe el filtro. El primer elemento da el nombre del objeto o clase que declaró el filtro (tenga en cuenta que esto puede ser diferente del objeto o clase que proporcionó la implementación del filtro), el segundo elemento es object o class dependiendo de si la entidad declarante fue un objeto o una clase, y el tercer elemento es el nombre del filtro.
self method
Esto devuelve el nombre del método actual (con las cadenas <constructor> y <destructor> indicando constructores y destructores respectivamente).
self namespace
Esto devuelve el nombre del espacio de nombres único del objeto sobre el que se invocó el método.
self next
Cuando se invoca desde un método que no está al final de una cadena de llamadas (es decir, donde el comando next invocará una implementación de método real), este subcomando devuelve una lista de dos elementos que describe el siguiente elemento en la cadena de llamadas de métodos; el primer elemento es el nombre de la clase u objeto que declara la siguiente parte de la cadena de llamadas, y el segundo elemento es el nombre del método (con las cadenas <constructor> y <destructor> indicando constructores y destructores respectivamente). Si se invoca desde un método que está al final de una cadena de llamadas, este subcomando devuelve una cadena vacía.
self object
Esto devuelve el nombre del objeto sobre el que se invocó el método.
self target
Cuando se invoca dentro de una implementación de filtro, este subcomando devuelve una lista de dos elementos que describe el método que se está filtrando. El primer elemento será el nombre del declarante del método, y el segundo elemento será el nombre real del método.

EJEMPLOS

Este ejemplo muestra el uso básico de self para proporcionar información sobre el objeto actual:

oo::class create c {
    method foo {} {
        puts "este es el objeto [self]"
    }
}
c create a
c create b
a foo                → imprime "este es el objeto ::a"
b foo                → imprime "este es el objeto ::b"

Esto demuestra cómo se ve una cadena de llamadas de métodos y cómo recorrerla cambia el índice en ella:

oo::class create c {
    method x {} {
        puts "Cls: [self call]"
    }
}
c create a
oo::objdefine a {
    method x {} {
        puts "Obj: [self call]"
        next
        puts "Obj: [self call]"
    }
}
a x     → Obj: {{method x object method} {method x ::c method}} 0
        → Cls: {{method x object method} {method x ::c method}} 1
        → Obj: {{method x object method} {method x ::c method}} 0

VER TAMBIÉN
