NOMBRE

seccomp_syscall_priority - Prioriza las llamadas al sistema en el filtro seccomp

SINOPSIS

#include <seccomp.h>

typedef void * scmp_filter_ctx;

int SCMP_SYS(nombre_syscall);

int seccomp_syscall_priority(scmp_filter_ctx ctx,
                             int syscall, uint8_t priority);

Enlazar con -lseccomp.

DESCRIPCIÓN

La función seccomp_syscall_priority() proporciona una pista de prioridad al generador de filtros seccomp en libseccomp para que las llamadas al sistema de mayor prioridad se coloquen antes en el código del filtro seccomp, de modo que incurran en menos sobrecarga a expensas de las llamadas al sistema de menor prioridad. La prioridad de una llamada al sistema se puede establecer independientemente de si existen reglas para esa llamada al sistema; la biblioteca recordará la prioridad y se le asignará a la llamada al sistema cuando se cree una regla para ella.

Si bien es posible especificar el valor de syscall directamente utilizando los valores estándar __NR_syscall, para garantizar un funcionamiento correcto en múltiples arquitecturas, se recomienda encarecidamente utilizar en su lugar la macro SCMP_SYS(). Consulte la sección de EJEMPLOS más abajo.

El parámetro priority toma un valor de 8 bits que varía de 0 a 255; un valor más alto representa una prioridad más alta.

El contexto del filtro ctx es el valor devuelto por la llamada a seccomp_init().

VALOR DEVUELTO

La macro SCMP_SYS() devuelve un valor adecuado para usar como valor de syscall en seccomp_syscall_priority().

La función seccomp_syscall_priority() devuelve cero en caso de éxito o uno de los siguientes códigos de error en caso de fallo:

-EDOM
Fallo específico de la arquitectura.
-EFAULT
Fallo interno de libseccomp.
-EINVAL
Entrada inválida, ya sea el contexto o el token de arquitectura no es válido.
-ENOMEM
La biblioteca no pudo asignar suficiente memoria.

EJEMPLOS

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc = -1;
	scmp_filter_ctx ctx;
	ctx = seccomp_init(SCMP_ACT_KILL);
	if (ctx == NULL)
		goto out;
	/* ... */
	rc = seccomp_syscall_priority(ctx, SCMP_SYS(read), 200);
	if (rc < 0)
		goto out;
	/* ... */
out:
	seccomp_release(ctx);
	return -rc;
}

NOTAS

Aunque el filtro seccomp puede generarse independientemente del núcleo, se requiere soporte del núcleo para cargar y aplicar el filtro seccomp generado por libseccomp.

El sitio del proyecto libseccomp, con más información y el repositorio de código fuente, se puede encontrar en https://github.com/seccomp/libseccomp. Esta herramienta, así como la biblioteca libseccomp, se encuentra actualmente en desarrollo, por favor reporte cualquier error en el sitio del proyecto o directamente al autor.
