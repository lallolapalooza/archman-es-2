seteuid(2) Manual de llamadas al sistema seteuid(2)

NOMBRE

seteuid, setegid - establecer el ID de usuario o grupo efectivo

LIBRERÍA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int seteuid(uid_t euid);
int setegid(gid_t egid);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

seteuid(), setegid():

    _POSIX_C_SOURCE >= 200112L
        || /* glibc <= 2.19: */ _BSD_SOURCE

DESCRIPCIÓN

seteuid() establece el ID de usuario efectivo del proceso llamante. Los procesos no privilegiados solo pueden establecer el ID de usuario efectivo al ID de usuario real, al ID de usuario efectivo o al ID de usuario guardado.

Exactamente lo mismo ocurre con setegid() con "grupo" en lugar de "usuario".

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece la variable errno para indicar el error.

Nota: hay casos en los que seteuid() puede fallar incluso cuando el llamante es UID 0; omitir la comprobación de un retorno de error de seteuid() es un grave error de seguridad.

ERRORES

EINVAL
El ID de usuario o grupo de destino no es válido en este espacio de nombres de usuario.
EPERM
En el caso de seteuid(): el proceso llamante no tiene privilegios (no tiene la capacidad CAP_SETUID en su espacio de nombres de usuario) y euid no coincide con el ID de usuario real actual, el ID de usuario efectivo actual o el ID de usuario guardado.
En el caso de setegid(): el proceso llamante no tiene privilegios (no tiene la capacidad CAP_SETGID en su espacio de nombres de usuario) y egid no coincide con el ID de grupo real actual, el ID de grupo efectivo actual o el ID de grupo guardado.

VERSIÓNES

Establecer el ID de usuario (grupo) efectivo al ID de usuario (ID de grupo) guardado es posible desde Linux 1.1.37 (1.1.38). En un sistema arbitrario, se debe comprobar _POSIX_SAVED_IDS.

Bajo glibc 2.0, seteuid(euid) es equivalente a setreuid(-1, euid) y, por lo tanto, puede cambiar el ID de usuario guardado. Bajo glibc 2.1 y posteriores, es equivalente a setresuid(-1, euid, -1) y, por lo tanto, no cambia el ID de usuario guardado. Observaciones análogas se aplican a setegid(), con la diferencia de que el cambio en la implementación de setregid(-1, egid) a setresgid(-1, egid, -1) ocurrió en glibc 2.2 o 2.3 (dependiendo de la arquitectura del hardware).

Según POSIX.1, seteuid() (setegid()) no necesita permitir que euid (egid) sea el mismo valor que el ID de usuario (grupo) efectivo actual, y algunas implementaciones no lo permiten.

DIFERENCIAS librería C/kernel

En Linux, seteuid() y setegid() se implementan como funciones de biblioteca que llaman, respectivamente, a setresuid(2) y setresgid(2).

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, 4.3BSD.

VER TAMBIÉN

geteuid(2), setresuid(2), setreuid(2), setuid(2), capabilities(7), credentials(7), user_namespaces(7)
