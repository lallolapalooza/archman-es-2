encrypt(3) Manual de funciones de biblioteca encrypt(3)

NOMBRE

encrypt, setkey, encrypt_r, setkey_r - cifrar mensajes de 64 bits

BIBLIOTECA

Biblioteca de hash de contraseñas (libcrypt, -lcrypt)

SINOPSIS

#define _XOPEN_SOURCE       /* Ver feature_test_macros(7) */
#include <unistd.h>
[[deprecated]] void encrypt(char block[64], int edflag);
#define _XOPEN_SOURCE       /* Ver feature_test_macros(7) */
#include <stdlib.h>
[[deprecated]] void setkey(const char *key);
#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <crypt.h>
[[deprecated]] void setkey_r(const char *key, struct crypt_data *data);
[[deprecated]] void encrypt_r(char *block, int edflag,
                              struct crypt_data *data);

DESCRIPCIÓN

Estas funciones cifran y descifran mensajes de 64 bits. La función setkey() establece la clave utilizada por encrypt(). La clave key utilizada aquí es un array de 64 bytes, cada uno de los cuales tiene un valor numérico de 1 o 0. Los bytes key[n] donde n=8*i-1 se ignoran, de modo que la longitud efectiva de la clave es de 56 bits.

La función encrypt() modifica el buffer pasado, codificando si edflag es 0, y decodificando si se pasa 1. Al igual que el argumento key, también block es una representación de vector de bits del valor real que se codifica. El resultado se devuelve en ese mismo vector.

Estas dos funciones no son reentrables, es decir, los datos de la clave se guardan en almacenamiento estático. Las funciones setkey_r() y encrypt_r() son las versiones reentrables. Utilizan la siguiente estructura para almacenar los datos de la clave:


struct crypt_data {
    char keysched[16 * 8];
    char sb0[32768];
    char sb1[32768];
    char sb2[32768];
    char sb3[32768];
    char crypt_3_buf[14];
    char current_salt[2];
    long current_saltbits;
    int  direction;
    int  initialized;
};

Antes de llamar a setkey_r(), establezca data->initialized a cero.

VALOR DE RETORNO

Estas funciones no devuelven ningún valor.

ERRORES

Establezca errno a cero antes de llamar a las funciones anteriores. En caso de éxito, errno no se modifica.

ENOSYS
La función no se proporciona. (Por ejemplo, debido a restricciones de exportación anteriores de EE. UU.).

HISTORIAL

Eliminado en glibc 2.28.

Debido a que emplean el algoritmo de cifrado de bloque DES, que ya no se considera seguro, estas funciones se eliminaron de glibc. Las aplicaciones deberían pasarse a una biblioteca de criptografía moderna, como libgcrypt.

encrypt()
setkey()
POSIX.1-2001, SUS, SVr4.

Disponibilidad en glibc

Ver crypt(3).

Características en glibc

En glibc 2.2, estas funciones utilizan el algoritmo DES.

EJEMPLOS

#define _XOPEN_SOURCE
#include <crypt.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(void)
{
    char key[64];
    char orig[9] = "eggplant";
    char buf[64];
    char txt[9];
    for (size_t i = 0; i < 64; i++) {
        key[i] = rand() & 1;
    }
    for (size_t i = 0; i < 8; i++) {
        for (size_t j = 0; j < 8; j++) {
            buf[i * 8 + j] = orig[i] >> j & 1;
        }
        setkey(key);
    }
    printf("Antes de cifrar: %s\n", orig);
    encrypt(buf, 0);
    for (size_t i = 0; i < 8; i++) {
        for (size_t j = 0, txt[i] = '\0'; j < 8; j++) {
            txt[i] |= buf[i * 8 + j] << j;
        }
        txt[8] = '\0';
    }
    printf("Después de cifrar:  %s\n", txt);
    encrypt(buf, 1);
    for (size_t i = 0; i < 8; i++) {
        for (size_t j = 0, txt[i] = '\0'; j < 8; j++) {
            txt[i] |= buf[i * 8 + j] << j;
        }
        txt[8] = '\0';
    }
    printf("Después de descifrar:  %s\n", txt);
    exit(EXIT_SUCCESS);
}
