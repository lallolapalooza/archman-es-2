SEMGET(3P) Manual del programador POSIX SEMGET(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual correspondiente de Linux para obtener detalles sobre el comportamiento de Linux) o la interfaz puede no estar implementada en Linux.

NOMBRE

semget — obtener conjunto de semáforos XSI

SINOPSIS

#include <sys/sem.h>
int semget(key_t key, int nsems, int semflg);

DESCRIPCIÓN

La función semget() opera sobre semáforos XSI (consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 4.17, Semáforo). No está especificado si esta función interactúa con las instalaciones de comunicación entre procesos en tiempo real definidas en la Sección 2.8, Tiempo Real.

La función semget() devolverá el identificador del semáforo asociado con key.

Se creará un identificador de semáforo con su estructura de datos asociada semid_ds y su conjunto de semáforos nsems (consulte <sys/sem.h>) para key si se cumple una de las siguientes condiciones:

*
El argumento key es igual a IPC_PRIVATE.
*
El argumento key aún no tiene un identificador de semáforo asociado y (semflg &IPC_CREAT) es distinto de cero.

Al crearse, la estructura de datos semid_ds asociada con el nuevo identificador de semáforo se inicializa de la siguiente manera:

*
En la estructura de permisos de operación sem_perm.cuid, sem_perm.uid, sem_perm.cgid y sem_perm.gid se establecerán al ID de usuario efectivo y al ID de grupo efectivo, respectivamente, del proceso que llama.
*
Los 9 bits de orden inferior de sem_perm.mode se establecerán a los 9 bits de orden inferior de semflg.
*
La variable sem_nsems se establecerá al valor de nsems.
*
La variable sem_otime se establecerá a 0 y sem_ctime se establecerá a la hora actual, como se describe en la Sección 2.7.1, Descripción general de IPC.
*
La estructura de datos asociada a cada semáforo en el conjunto no necesita ser inicializada. La función semctl() con el comando SETVAL o SETALL se puede utilizar para inicializar cada semáforo.

VALOR DEVUELTO

Al completarse con éxito, semget() devolverá un entero no negativo, es decir, un identificador de semáforo; de lo contrario, devolverá -1 y establecerá errno para indicar el error.

ERRORES

La función semget() fallará si:

EACCES
Existe un identificador de semáforo para key, pero los permisos de operación especificados por los 9 bits de orden inferior de semflg no se concederían; consulte la Sección 2.7, Comunicación entre procesos XSI.
EEXIST
Existe un identificador de semáforo para el argumento key pero ((semflg &IPC_CREAT) &&(semflg &IPC_EXCL)) es distinto de cero.
EINVAL
El valor de nsems es menor o igual a 0 o mayor que el límite impuesto por el sistema, o existe un identificador de semáforo para el argumento key, pero el número de semáforos en el conjunto asociado con él es menor que nsems y nsems no es igual a 0.
ENOENT
No existe un identificador de semáforo para el argumento key y (semflg &IPC_CREAT) es igual a 0.
ENOSPC
Se va a crear un identificador de semáforo pero se superaría el límite impuesto por el sistema sobre el número máximo de semáforos permitidos en todo el sistema.

Las siguientes secciones son informativas.

EJEMPLOS

Consulte semop().

USO EN APLICACIONES

La Extensión de Tiempo Real POSIX define interfaces alternativas para la comunicación entre procesos. Los desarrolladores de aplicaciones que necesiten utilizar IPC deben diseñar sus aplicaciones de manera que los módulos que utilizan las rutinas de IPC descritas en la Sección 2.7, Comunicación entre procesos XSI puedan modificarse fácilmente para utilizar las interfaces alternativas.

FUNDAMENTO

Ninguno.

DIRECCIONES FUTURAS

Una versión futura puede requerir que el valor de los miembros semval, sempid, semncnt y semzcnt de todos los semáforos en un conjunto de semáforos se inicialice a cero cuando una llamada a semget() cree un conjunto de semáforos. Muchas implementaciones de semáforos ya lo hacen y simplifica enormemente lo que una aplicación debe hacer para inicializar un conjunto de semáforos.
