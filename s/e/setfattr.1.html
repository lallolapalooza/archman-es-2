SETFATTR(1) Utilidades de Archivos SETFATTR(1)

NOMBRE

setfattr - establece atributos extendidos de objetos del sistema de archivos

SINOPSIS

setfattr [-h] -n nombre [-v valor] ruta...
setfattr [-h] -x nombre ruta...
setfattr [-h] --restaurar=archivo

DESCRIPCIÓN

El comando setfattr asocia un nuevo valor con un nombre de atributo extendido nombre para cada archivo especificado.

OPCIONES

-n nombre, --nombre=nombre
Especifica el nombre del atributo extendido a establecer.
-v valor, --valor=valor
Especifica el nuevo valor del atributo extendido. Hay tres métodos disponibles para codificar el valor. Si la cadena dada está entre comillas dobles, la cadena interna se trata como texto. En ese caso, las barras invertidas y las comillas dobles tienen significados especiales y deben escaparse con una barra invertida precedente. Cualquier carácter de control puede codificarse como una barra invertida seguida de tres dígitos como su código ASCII en octal. Si la cadena dada comienza con 0x o 0X, expresa un número hexadecimal. Si la cadena dada comienza con 0s o 0S, se espera codificación base64. Consulte también la opción --codificación de getfattr(1).
-x nombre, --eliminar=nombre
Elimina completamente el atributo extendido nombrado.
-h, --no-seguir-enlaces
No seguir enlaces simbólicos. Si ruta es un enlace simbólico, no se sigue, sino que es el propio inodo el que se modifica.
--restaurar=archivo
Restaura los atributos extendidos desde el archivo. El archivo debe tener el formato generado por el comando getfattr con la opción --volcar. Si se proporciona un guion (-) como nombre de archivo, setfattr lee desde la entrada estándar.
--raw
No decodificar el valor del atributo. Se puede usar para establecer valores obtenidos con getfattr --solo-valores.
--version
Imprime la versión de setfattr y sale.
--ayuda
Imprime la ayuda que explica las opciones de la línea de comandos.
--
Fin de las opciones de la línea de comandos. Todos los parámetros restantes se interpretan como nombres de archivo, incluso si comienzan con un guion.

EJEMPLOS

Añadir un atributo extendido al espacio de nombres del usuario:

$ setfattr -n user.foo -v bar archivo.txt

Para añadir la suma MD5 del archivo como un atributo extendido:

# setfattr -n trusted.md5sum -v d41d8cd98f00b204e00998ecf8427e archivo.txt
