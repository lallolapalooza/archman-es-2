SETXKBMAP(1) Manual de Comandos Generales SETXKBMAP(1)

NOMBRE

setxkbmap - establecer el teclado usando la Extensión de Teclado X

SINOPSIS

setxkbmap [ args ] [ layout [ variant [ option ... ] ] ]

DESCRIPCIÓN

El comando setxkbmap configura el teclado para usar la disposición determinada por las opciones especificadas en la línea de comandos.

Un mapa de teclado XKB se construye a partir de varios componentes que se compilan solo cuando es necesario. El código fuente de todos los componentes se encuentra en /usr/share/X11/xkb.

OPCIONES

-compat nombre
Especifica el nombre del componente del mapa de compatibilidad utilizado para construir una disposición de teclado.
-config archivo
Especifica el nombre de un archivo de configuración XKB que describe el teclado que se va a utilizar.
-device dispositivo
Especifica el ID numérico del dispositivo de entrada que se actualizará con la nueva disposición del teclado. Si no se especifica, se actualiza el dispositivo de teclado principal del servidor X.
-display display
Especifica la pantalla que se actualizará con la nueva disposición del teclado.
-geometry nombre
Especifica el nombre del componente de geometría utilizado para construir una disposición de teclado.
-help
Imprime un mensaje que describe la entrada válida para setxkbmap.
-I directorio
Añade un directorio a la lista de directorios que se utilizarán para buscar los archivos de disposición o reglas especificados.
-keycodes nombre
Especifica el nombre del componente de códigos de tecla utilizado para construir una disposición de teclado.
-keymap nombre
Especifica el nombre de la descripción del mapa de teclas utilizado para construir una disposición de teclado.
-layout nombre
Especifica el nombre de la disposición utilizada para determinar los componentes que componen la descripción del teclado. La opción -layout solo puede usarse una vez. Se pueden especificar varias disposiciones como una lista separada por comas.
-model nombre
Especifica el nombre del modelo de teclado utilizado para determinar los componentes que componen la descripción del teclado. Solo se puede especificar un modelo en la línea de comandos.
-option nombre
Especifica el nombre de una opción para determinar los componentes que componen la descripción del teclado; se pueden especificar varias opciones, una por cada opción -option. Tenga en cuenta que setxkbmap añade las opciones especificadas en la línea de comandos a las opciones que se establecieron previamente (guardadas en las propiedades de la ventana raíz). Si desea reemplazar todas las opciones especificadas previamente, use la opción -option con un argumento vacío primero.
-print
Con esta opción setxkbmap simplemente imprime los nombres de los componentes en un formato aceptable por xkbcomp (un compilador de mapas de teclas XKB) y sale. La opción se puede usar para pruebas en lugar de una opción detallada y en casos en los que se necesite ejecutar tanto setxkbmap como xkbcomp en cadena (ver abajo).
-query
Con esta opción setxkbmap simplemente imprime las reglas, el modelo, la disposición, la variante y las opciones actuales, y luego sale.
-rules archivo
Especifica el nombre del archivo de reglas utilizado para resolver la disposición y el modelo solicitados a un conjunto de nombres de componentes.
-symbols nombre
Especifica el nombre del componente de símbolos utilizado para construir una disposición de teclado.
-synch
Fuerza la sincronización de las solicitudes X.
-types nombre
Especifica el nombre del componente de tipos utilizado para construir una disposición de teclado.
-variant nombre
Especifica qué variante de la disposición del teclado se debe utilizar para determinar los componentes que componen la descripción del teclado. La opción -variant solo puede usarse una vez. Se pueden especificar múltiples variantes como una lista separada por comas y se emparejarán con las disposiciones especificadas con -layout.
-verbose|-v [nivel]
Especifica el nivel de detalle en los mensajes de salida. Los niveles válidos van de 0 (menos detallado) a 10 (más detallado). El nivel de detalle por defecto es 5. Si no se especifica ningún nivel, cada opción -v o -verbose aumenta el nivel en 1.
-version
Imprime el número de versión del programa.

USO CON xkbcomp

Si tiene un servidor X y un shell cliente ejecutándose en ordenadores diferentes y algunos archivos de configuración XKB en esas máquinas son diferentes, puede tener problemas al especificar un mapa de teclado por nombre de modelo, disposición y opciones. Esto se debe a que setxkbmap convierte sus argumentos a nombres de archivos de configuración XKB de acuerdo con los archivos que se encuentran en el ordenador cliente, luego envía estos nombres de archivo al servidor donde xkbcomp tiene que componer un mapa de teclado completo usando los archivos que tiene el servidor. Por lo tanto, si los conjuntos de archivos difieren de alguna manera, los nombres que setxkbmap genera pueden ser inaceptables en el lado del servidor. Puede resolver este problema ejecutando también xkbcomp en el lado del cliente. Con la opción -print, setxkbmap simplemente imprime los nombres de los archivos en un formato apropiado a su salida estándar y esta salida se puede enviar directamente a la entrada de xkbcomp. Por ejemplo, el comando

setxkbmap us -print | xkbcomp - $DISPLAY

realiza ambos pasos en la misma máquina (cliente) y carga un mapa de teclado en el servidor.

XWAYLAND

Xwayland es un servidor X que utiliza un Compositor Wayland como backend. Xwayland actúa como una capa de traducción entre el protocolo X y el protocolo Wayland, pero no gestiona los mapas de teclado; estos son manejados por el Compositor Wayland.

Cambiar el mapa de teclado con setxkbmap no es compatible con Xwayland. En la mayoría de los casos, usar setxkbmap en Xwayland es indicativo de un error en un script de shell y setxkbmap imprimirá una advertencia. Utilice los métodos de configuración XKB nativos del Compositor Wayland en su lugar.

setxkbmap(1)

setxkbmap - set the keyboard mapping and behaviors

SYNOPSIS

setxkbmap [ options ] [ layout [ variant [ option ... ] ] ]

DESCRIPTION

The setxkbmap program is used to set the keyboard mapping for the X server. The keyboard mapping determines which symbols are generated by which keys and which modifiers (like Shift, Control, Alt, etc.) are active. This program can also be used to set keyboard behaviors, such as the auto-repeat rate or the way LEDs are handled.

The layout parameter specifies the primary layout to be used (e.g., "us" for US English, "de" for German, "fr" for French). The optional variant parameter allows for further customization within a layout (e.g., "dvorak" for the Dvorak layout within the US English set). Additional option parameters can be used to specify further configurations, such as the behavior of the Compose key or the layout switching behavior.

If no layout is specified, setxkbmap will attempt to reset the keyboard to the default settings as defined by the X server's configuration.

OPTIONS

-layout layout[,variant]
Specifies the keyboard layout and an optional variant. This option can be specified multiple times to define multiple layouts.
-variant variant
Specifies the variant of the current layout. This option can be specified multiple times.
-option option
Specifies a keyboard option. This option can be specified multiple times. Common options include:
  • grp:alt_shift_toggle: Switch layout with Alt+Shift.
  • grp:ctrl_shift_toggle: Switch layout with Ctrl+Shift.
  • grp:win_space_toggle: Switch layout with Win+Space.
  • compose:ralt: Set Right Alt as Compose key.
  • caps:swapescape: Swap Caps Lock and Escape keys.
-print
Prints the current keyboard configuration to standard output.
-query
Queries the current keyboard configuration and prints it to standard output.
-verbose level
Sets the verbosity level for output.
-help
Displays a help message and exits.

USING WITH xkbcomp

While setxkbmap is convenient for simple configuration changes, more complex or persistent keyboard configurations are often managed using xkbcomp(1). You can generate an xkbcomp-compatible file using setxkbmap -print and then modify it to create a custom configuration file.

XWAYLAND

On systems using Wayland with XWayland, setxkbmap may still influence the keyboard layout for X11 applications running under XWayland. However, the primary keyboard configuration for native Wayland applications is typically managed by the Wayland compositor itself.
