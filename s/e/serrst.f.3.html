SERRST

Propósito:

!>
!> SERRST prueba las salidas de error para SSYTRD, SSYTD2, SORGTR, SORMTR, SSPTRD,
!> SOPGTR, SOPMTR, SSTEQR, SSTERF, SSTEBZ, SSTEIN, SPTEQR, SSBTRD,
!> SSYEV, SSYEVX, SSYEVD, SSBEV, SSBEVX, SSBEVD,
!> SSPEV, SSPEVX, SSPEVD, SSTEV, SSTEVX, SSTEVD, y SSTEDC.
!> SSYEVD_2STAGE, SSYEVR_2STAGE, SSYEVX_2STAGE,
!> SSYEV_2STAGE, SSBEV_2STAGE, SSBEVD_2STAGE,
!> SSBEVX_2STAGE, SSYTRD_2STAGE, SSYTRD_SY2SB,
!> SSYTRD_SB2ST
!>

Parámetros

PATH 
!>          PATH es CHARACTER*3
!>          El nombre de ruta LAPACK para las rutinas a probar.
!>

NUNIT

!>          NUNIT es INTEGER
!>          El número de unidad para la salida.
!>
