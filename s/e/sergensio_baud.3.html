DESCRIPCIÓN

Maneja varias funciones del puerto serial.

CONTROLES DEL PUERTO SERIAL

En un sergensio cliente, estas funciones establecen varios ajustes en el puerto serial. El ajuste no se realiza necesariamente de inmediato, ya que puede ser necesario enviarlo como un mensaje. Si proporciona una función de finalización (done), esta se llamará cuando se sepa que la operación de establecimiento se ha completado. La operación de establecimiento puede no funcionar (el hardware puede no soportarla, etc.); la función de finalización informará el valor actual del ajuste.

Si solo desea el valor actual del ajuste, puede pasar un cero a todas las funciones a continuación y solo se informará el valor en la función de finalización.

Existen funciones bloqueantes para todas estas opciones; consulte sergensio_b_alloc(3) para obtener más detalles. Todas estas son no bloqueantes.

sergensio_baud - Establece la velocidad en baudios al valor entero. No todos los
sistemas y hardware soportan todas las velocidades en baudios; consulte la función de finalización para ver a qué velocidad se estableció realmente.
sergensio_datasize - Establece el tamaño de los datos; se soportan 5, 6, 7, 8.
sergensio_parity - Establece el valor de paridad
sergensio_stopbits - Establece el número de bits de parada, ya sea 1 o 2.
sergensio_flowcontrol - Establece el tipo de control de flujo de salida.
sergensio_iflowcontrol - Establece el tipo de control de flujo de entrada.
sergensio_sbreak - Activa o desactiva la señal de interrupción (break).
sergensio_dtr - Establece el valor de DTR.
sergensio_rts - Establece el valor de RTS.

sergensio_send_break - Envía una señal de interrupción (break) (activada por un momento y luego desactivada) en la línea.

En un gensio servidor, las funciones anteriores se utilizan para responder a un evento que establece el valor. Pase el valor real. El valor de finalización se ignora en el servidor.

DESCRIPTION

These functions control the serial port parameters of a serial gensio.

SERIAL PORT PARAMETERS

The following functions set the basic serial port parameters:

sergensio_baud
Set the baud rate of the serial port.
sergensio_get_baud
Get the current baud rate of the serial port.
sergensio_parity
Set the parity of the serial port. The possible values for parity are SERGENSIO_PARITY_NONE, SERGENSIO_PARITY_EVEN, SERGENSIO_PARITY_ODD, SERGENSIO_PARITY_MARK, and SERGENSIO_PARITY_SPACE.
sergensio_stopbits
Set the number of stop bits. The possible values are SERGENSIO_STOPBITS_1, SERGENSIO_STOPBITS_1_5, and SERGENSIO_STOPBITS_2.
sergensio_byte_size
Set the number of data bits per byte. The possible values are SERGENSIO_BYTESIZE_5, SERGENSIO_BYTESIZE_6, SERGENSIO_BYTESIZE_7, and SERGENSIO_BYTESIZE_8.

FLOW CONTROL

The following functions control flow control:

sergensio_rts_cts
Enable or disable RTS/CTS hardware flow control.
sergensio_xon_xoff
Enable or disable XON/XOFF software flow control.
sergensio_disable_flow_control
Disable all flow control.
sergensio_enable_flow_control
Enable flow control. This is the default state.
sergensio_get_flowcontrol_state
Get the current flow control state. state will be set to SERGENSIO_FLOWCONTROL_NONE, SERGENSIO_FLOWCONTROL_RTSCTS, or SERGENSIO_FLOWCONTROL_XONXOFF.

LINE AND MODEM STATES

These functions deal with the line and modem states.

sergensio_set_line_state
Set the line state mask. This is used for controlling things like break signals. The bits are defined in sergensio.h.
sergensio_get_line_state
Get the line state mask.
sergensio_get_modem_state
Get the current modem state. The bits are defined in sergensio.h.
sergensio_set_modem_state
Set the modem state. This is used for controlling the modem control lines like RTS and DTR.
sergensio_get_sigmask
Get the signal mask. This mask determines which signals will cause a line state event.
sergensio_set_sigmask
Set the signal mask.

TERMINAL SIZE

sergensio_get_term_size
Get the terminal size (rows and columns).
sergensio_set_term_size
Set the terminal size.

OTHER SERIAL PORT CONTROLS

These functions perform other miscellaneous serial port operations.

sergensio_flush
Flush all data from buffers to the serial port.
sergensio_send_break
Send a short break signal on the serial port. The length is implementation dependent.

MODEM CONTROL SIGNALS FOR IPMISOL

On a connection that is on the modem side of the serial port (like ipmisol), there are a different set of control commands, the above may or may not work.

Instead, use the following. Note that passing 0 to these may or may not return the current value, they may return an error.

sergensio_cts - Set the CTS value to auto (managed by the hardware) or
off (tell the other end not to send d<ata).
sergensio_dcd_rts - Set the DCD and RTS value to be enabled or disabled.
sergensio_ri - Set the ring indicator value to be enabled or disabled.

SIGNATURE

Though not really part of serial port control, the telnet RFC2217 spec has a signature that can be used to identify the server. The sergensio_signature function fetches the signature (on the client side) or reponsed to a request for the signature (on the server side).

STATE FUNCTIONS

On the client side, the serial port state functions set the state information the user is interested in receiving. For instance, if the user wants to know about parity errors, they could set SERGENSIO_LINESTATE_OVERRUN_ERR in the linestate and they would receive linestate events with parity errors.

On the server side, these are used to report state information. The gensio itself doesn't track what the client has requested, that is up to the server code itself.

sergensio_linestate - Various information (mostly error) about what
has happened on the serial line. Not all sergensios support requesting this information.
sergensio_modemstate - CTS, DSR, RI, and CD line on the serial port.
On the client side, the user should set what values they want to received with that _CHANGED values. The other values are ignored on the client side. On the server side, this is used to report current values and which values have changed to cause the report.

OTHER SERIAL PORT CONTROLS

These function do other miscellaneous functions on a serial port.

sergensio_flowcontrol_state - Tell the remote end of the serial port to
stop sending using flow control.
sergensio_flush - Flush all data from buffers to the serial port.
sergensio_send_break - Send a short break signal on the serial port.
The length is implementation dependent.

RETURN VALUES

Zero is returned on success, or a gensio error on failure.
