session-keyring(7) Manual de Información Miscelánea session-keyring(7)

NOMBRE

session-keyring - keyring compartido de sesión para procesos

DESCRIPCIÓN

El keyring de sesión es un keyring utilizado para anclar claves en nombre de un proceso. Normalmente es creado por pam_keyinit(8) cuando un usuario inicia sesión y se añadirá un enlace que se refiere al user-keyring(7). Opcionalmente, PAM(7) puede revocar el keyring de sesión al cerrar sesión. (En configuraciones típicas, PAM sí realiza esta revocación.) El keyring de sesión tiene el nombre (descripción) _ses.

Se define un valor especial de número de serie, KEY_SPEC_SESSION_KEYRING, que puede utilizarse en lugar del número de serie real del keyring de sesión del proceso que llama.

Desde la utilidad keyctl(1), '@s' puede usarse en lugar de un ID numérico de clave de manera similar.

El keyring de sesión de un proceso se hereda a través de clone(2), fork(2) y vfork(2). El keyring de sesión se conserva a través de execve(2), incluso cuando el ejecutable tiene el bit set-user-ID o set-group-ID o tiene capacidades. El keyring de sesión se destruye cuando el último proceso que se refiere a él sale.

Si un proceso no tiene un keyring de sesión cuando se accede a él, entonces, bajo ciertas circunstancias, el user-session-keyring(7) se adjuntará como keyring de sesión y bajo otras circunstancias se creará un nuevo keyring de sesión. (Ver user-session-keyring(7) para más detalles.)

Operaciones especiales

La biblioteca keyutils proporciona las siguientes operaciones especiales para manipular keyrings de sesión:

keyctl_join_session_keyring(3)
Esta operación permite al llamante cambiar el keyring de sesión al que se suscribe. El llamante puede unirse a un keyring existente con un nombre especificado (descripción), crear un nuevo keyring con un nombre dado, o pedir al kernel que cree un nuevo keyring de sesión "anónimo" con el nombre "_ses". (Esta función es una interfaz para la operación KEYCTL_JOIN_SESSION_KEYRING de keyctl(2).)
keyctl_session_to_parent(3)
Esta operación permite al llamante hacer que el keyring de sesión del proceso padre sea el mismo que el suyo. Para que esto tenga éxito, el proceso padre debe tener atributos de seguridad idénticos y debe ser monohilo. (Esta función es una interfaz para la operación KEYCTL_SESSION_TO_PARENT de keyctl(2).)

Estas operaciones también están expuestas a través de la utilidad keyctl(1) como:


keyctl session
keyctl session - [<prog> <arg1> <arg2> ...]
keyctl session <name> [<prog> <arg1> <arg2> ...]

y:


keyctl new_session
