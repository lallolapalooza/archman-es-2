seccomp_attr_get(3)

Paquete: libseccomp

Licencias: LGPL-2.1-only

seccomp_attr_set(3) Documentación de libseccomp seccomp_attr_set(3)

NOMBRE

seccomp_attr_set, seccomp_attr_get - Gestionar los atributos del filtro seccomp

SINOPSIS

#include <seccomp.h>

typedef void * scmp_filter_ctx;
enum scmp_filter_attr;

int seccomp_attr_set(scmp_filter_ctx ctx,
                     enum scmp_filter_attr attr, uint32_t value);
int seccomp_attr_get(scmp_filter_ctx ctx,
                     enum scmp_filter_attr attr, uint32_t *value);

Enlazar con -lseccomp.

DESCRIPCIÓN

La función seccomp_attr_set() establece los diferentes atributos del filtro seccomp, mientras que la función seccomp_attr_get() obtiene los atributos del filtro. Los atributos del filtro seccomp son valores ajustables que afectan cómo se comporta la biblioteca al generar y cargar el filtro seccomp en el kernel. Los atributos se restablecen a sus valores predeterminados cada vez que se inicializa o restablece el filtro mediante seccomp_init(3) o seccomp_reset(3).

El contexto del filtro ctx es el valor devuelto por la llamada a seccomp_init(3).

Los valores válidos de attr son los siguientes:

SCMP_FLTATR_ACT_DEFAULT
La acción predeterminada del filtro especificada en la llamada a seccomp_init(3) o seccomp_reset(3). Este atributo es de solo lectura.
SCMP_FLTATR_ACT_BADARCH
La acción del filtro que se toma cuando el filtro cargado no coincide con la arquitectura de la aplicación en ejecución. Predeterminado a la acción SCMP_ACT_KILL.
SCMP_FLTATR_CTL_NNP
Una bandera para especificar si la funcionalidad NO_NEW_PRIVS debe habilitarse antes de cargar el filtro seccomp en el kernel. Establecer esto en desactivado (value == 0) da como resultado ninguna acción, lo que significa que la carga del filtro seccomp en el kernel fallará si falta CAP_SYS_ADMIN y NO_NEW_PRIVS no se ha establecido externamente. Predeterminado a activado (value == 1).
SCMP_FLTATR_CTL_TSYNC
Una bandera para especificar si el kernel debe intentar sincronizar los filtros entre todos los hilos en seccomp_load(3). Si el kernel no puede sincronizar todos los hilos, la operación de carga fallará. Esta bandera solo está disponible en Linux Kernel 3.17 o superior; intentar habilitar esta bandera en kernels anteriores resultará en un error. Predeterminado a desactivado (value == 0).
SCMP_FLTATR_API_TSKIP
Una bandera para especificar si libseccomp debe permitir la creación de reglas de filtro para la llamada al sistema -1. El valor de la llamada al sistema -1 puede ser utilizado por programas de rastreo para omitir invocaciones específicas de llamadas al sistema, ver seccomp(2) para más información. Predeterminado a desactivado (value == 0).
SCMP_FLTATR_CTL_LOG
Una bandera para especificar si el kernel debe registrar todas las acciones del filtro tomadas, excepto la acción SCMP_ACT_ALLOW. Predeterminado a desactivado (value == 0).
SCMP_FLTATR_CTL_SSB
Una bandera para deshabilitar las mitigaciones de Speculative Store Bypass para este filtro. Predeterminado a desactivado (value == 0).
SCMP_FLTATR_CTL_OPTIMIZE
Una bandera para especificar el nivel de optimización del filtro seccomp. Por defecto, libseccomp genera un conjunto de sentencias ´if´ secuenciales para cada regla en el filtro. seccomp_syscall_priority(3) se puede utilizar para priorizar el orden para la causa predeterminada. La optimización de árbol binario ordena por números de llamada al sistema y genera una traversa de filtro consistente de O(log n) para cada regla en el filtro. El árbol binario puede ser ventajoso para filtros grandes. Tenga en cuenta que seccomp_syscall_priority(3) se ignora cuando SCMP_FLTATR_CTL_OPTIMIZE == 2.

Los diferentes niveles de optimización se describen a continuación:

0
Valor reservado, no utilizado actualmente.
1
Reglas ordenadas por prioridad y complejidad (PREDETERMINADO).
2
Árbol binario ordenado por número de llamada al sistema.
SCMP_FLTATR_API_SYSRAWRC
Una bandera para especificar si libseccomp debe pasar códigos de error del sistema al llamador en lugar del predeterminado -ECANCELED. Predeterminado a desactivado (value == 0).

VALOR DE RETORNO

Devuelve cero en caso de éxito o uno de los siguientes códigos de error en caso de fallo:

-EACCES
El establecimiento del atributo con el valor dado no está permitido.
-EEXIST
El atributo no existe.
-EINVAL
Entrada inválida, ya sea el contexto o el token de arquitectura son inválidos.
-EOPNOTSUPP
La biblioteca no soporta la operación particular.

EJEMPLOS

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc = -1;
	scmp_filter_ctx ctx;
	ctx = seccomp_init(SCMP_ACT_ALLOW);
	if (ctx == NULL)
		goto out;
	/* ... */
	rc = seccomp_attr_set(ctx, SCMP_FLTATR_ACT_BADARCH, SCMP_ACT_TRAP);
	if (rc < 0)
		goto out;
	/* ... */
out:
	seccomp_release(ctx);
	return -rc;
}

NOTAS

Aunque el filtro seccomp puede generarse independientemente del kernel, se requiere soporte del kernel para cargar y aplicar el filtro seccomp generado por libseccomp.

El sitio del proyecto libseccomp, con más información y el repositorio de código fuente, se puede encontrar en https://github.com/seccomp/libseccomp. Esta herramienta, así como la biblioteca libseccomp, se encuentra actualmente en desarrollo, por favor informe cualquier error en el sitio del proyecto o directamente al autor.

seccomp_attr_get(3) - ArchWiki

NAME

seccomp_attr_get - get seccomp filter attribute

SYNOPSIS

int seccomp_attr_get(struct scmp_filter_context *ctx, enum scmp_filter_attr attr, void *val);

DESCRIPTION

The seccomp_attr_get() function retrieves the value of a seccomp filter attribute. The attribute is specified by the attr argument, and the value is returned in the buffer pointed to by the val argument.

The ctx argument is a pointer to a struct scmp_filter_context structure, which represents the seccomp filter context.

The possible values for the attr argument are:

  • SCMP_FILTER_ATTR_SIZE: Returns the size of the filter.
  • SCMP_FILTER_ATTR_MAX_SYSCALL: Returns the maximum syscall number.
  • SCMP_FILTER_ATTR_ACTIONS: Returns the default actions for the filter.

The format of the returned value in val depends on the attribute requested.

RETURN VALUE

On success, seccomp_attr_get() returns 0. On error, it returns a negative value, and errno is set to indicate the error.

ERRORS

The following errors are possible:

  • EINVAL: Invalid attribute or context.
  • ENOMEM: Not enough memory to retrieve the attribute.

EXAMPLE

#include <stdio.h>
#include <stdlib.h>
#include <sys/seccomp.h>

int main() {
    struct scmp_filter_context *ctx;
    unsigned int size;
    int ret;

    ctx = seccomp_init(SCMP_ACT_ALLOW);
    if (ctx == NULL) {
        perror("seccomp_init");
        return 1;
    }

    ret = seccomp_attr_get(ctx, SCMP_FILTER_ATTR_SIZE, &size);
    if (ret < 0) {
        perror("seccomp_attr_get");
        seccomp_free(ctx);
        return 1;
    }

    printf("Filter size: %u\n", size);

    seccomp_free(ctx);
    return 0;
}
