SETCAP(8) Manual del Administrador del Sistema SETCAP(8)

NOMBRE

setcap - establecer capacidades de archivo

SINOPSIS

setcap [-q] [-n <uid_root>] [-v] {capacidades|-|-r} nombre_archivo [ ... capacidadesN archivoN ]

DESCRIPCIÓN

En ausencia de la opción -v (verificar) setcap establece las capacidades de cada nombre_archivo especificado a las capacidades especificadas. El argumento opcional -n <uid_root> puede ser usado para establecer la capacidad de archivo para usar solo en un espacio de nombres de usuario con este propietario de ID de usuario root. La opción -v se usa para verificar que las capacidades especificadas están actualmente asociadas con el archivo. Si se suministran -v y -n, el argumento -n <uid_root> también se verifica.

El conjunto de capacidades se especifica en el formato descrito en cap_text_formats(7).

El string especial de capacidad, '-', puede ser usado para indicar que las capacidades se leen de la entrada estándar. En tales casos, el conjunto de capacidades se termina con una línea en blanco.

El string especial de capacidad, '-r', se usa para eliminar un conjunto de capacidades de un archivo. Tenga en cuenta que establecer un conjunto de capacidades vacío no es lo mismo que eliminarlo. Un conjunto vacío puede usarse para garantizar que un archivo no se ejecute con privilegio a pesar de que los conjuntos ambientales+heredables predominantes otorgarían capacidades a los binarios ejecutados.

El '-f', se usa para forzar la finalización incluso cuando se considera una operación inválida de alguna manera. Esto puede afectar a '-r' y al establecimiento de capacidades de archivo que el kernel no podrá entender.

La bandera -q se usa para hacer que el programa sea menos verboso en su salida.

CÓDIGO DE SALIDA

El programa setcap saldrá con un código de salida de 0 si tiene éxito. En caso de fallo, el código de salida es 1.
