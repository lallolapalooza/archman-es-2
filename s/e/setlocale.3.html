setlocale(3) Manual de Funciones de Biblioteca setlocale(3)

NOMBRE

setlocale - establecer la configuración regional actual

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <locale.h>
char *setlocale(int category, const char *_Nullable locale);

DESCRIPCIÓN

La función setlocale() se utiliza para establecer o consultar la configuración regional actual del programa.

Si locale no es NULL, la configuración regional actual del programa se modifica según los argumentos. El argumento category determina qué partes de la configuración regional actual del programa deben modificarse.

Categoría Gobierna
LC_ALL Todas las configuraciones regionales
LC_ADDRESS Formato de direcciones y elementos relacionados con la geografía (*)
LC_COLLATE Ordenación de cadenas
LC_CTYPE Clasificación de caracteres
LC_IDENTIFICATION Metadatos que describen la configuración regional (*)
LC_MEASUREMENT Configuración relacionada con las mediciones (métrico frente a consuetudinario de EE. UU.) (*)
LC_MESSAGES Mensajes en lenguaje natural localizables
LC_MONETARY Formato de valores monetarios
LC_NAME Formato de saludos para personas (*)
LC_NUMERIC Formato de valores numéricos no monetarios
LC_PAPER Configuración relacionada con el tamaño de papel estándar (*)
LC_TELEPHONE Formatos a utilizar con servicios telefónicos (*)
LC_TIME Formato de valores de fecha y hora

Las categorías marcadas con un asterisco en la tabla anterior son extensiones de GNU. Para más información sobre estas categorías de configuración regional, consulte locale(7).

El argumento locale es un puntero a una cadena de caracteres que contiene la configuración requerida de category. Dicha cadena es una constante conocida como "C" o "da_DK" (ver más abajo), o una cadena opaca que fue devuelta por otra llamada a setlocale().

Si locale es una cadena vacía, "", cada parte de la configuración regional que deba modificarse se establecerá según las variables de entorno. Los detalles dependen de la implementación. Para glibc, primero (independientemente de category), se inspecciona la variable de entorno LC_ALL, luego la variable de entorno con el mismo nombre que la categoría (ver la tabla anterior) y, finalmente, la variable de entorno LANG. Se utiliza la primera variable de entorno existente. Si su valor no es una especificación de configuración regional válida, la configuración regional no cambia y setlocale() devuelve NULL.

La configuración regional "C" o "POSIX" es una configuración regional portátil; existe en todos los sistemas conformes.

Un nombre de configuración regional tiene típicamente el formato idioma[_territorio][.codepage][@modificador], donde idioma es un código de idioma ISO 639, territorio es un código de país ISO 3166 y codepage es un identificador de conjunto de caracteres o codificación como ISO-8859-1 o UTF-8. Para obtener una lista de todas las configuraciones regionales compatibles, intente "locale -a" (ver locale(1)).

Si locale es NULL, la configuración regional actual solo se consulta, no se modifica.

Al inicio del programa principal, la configuración regional portátil "C" se selecciona como predeterminada. Un programa puede hacerse portátil a todas las configuraciones regionales llamando:


setlocale(LC_ALL, "");

después de la inicialización del programa, y luego:

•
utilizando los valores devueltos por una llamada a localeconv(3) para información dependiente de la configuración regional;
•
utilizando las funciones de caracteres multibyte y anchos para el procesamiento de texto si MB_CUR_MAX > 1;
•
utilizando strcoll(3) y strxfrm(3) para comparar cadenas; y
•
utilizando wcscoll(3) y wcsxfrm(3) para comparar cadenas de caracteres anchos.

VALOR DE RETORNO

Una llamada exitosa a setlocale() devuelve una cadena opaca que corresponde a la configuración regional establecida. Esta cadena puede estar asignada en almacenamiento estático. La cadena devuelta es tal que una llamada posterior con esa cadena y su categoría asociada restaurará esa parte de la configuración regional del proceso. El valor de retorno es NULL si la solicitud no se puede cumplir.
