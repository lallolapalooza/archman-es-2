setfsent(3) Manual de Funciones de Biblioteca setfsent(3)

NOMBRE

setfsent, getfsent, getfsspec, getfsfile, endfsent - gestionar entradas fstab

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <fstab.h>
int setfsent(void);
struct fstab *getfsent(void);
void endfsent(void);
struct fstab *getfsfile(const char *punto_montaje);
struct fstab *getfsspec(const char *archivo_especial);

DESCRIPCIÓN

Estas funciones leen del archivo /etc/fstab. El struct fstab se define como:


struct fstab {
    char       *fs_spec;       /* nombre del dispositivo de bloque */
    char       *fs_file;       /* punto de montaje */
    char       *fs_vfstype;    /* tipo de sistema de archivos */
    char       *fs_mntops;     /* opciones de montaje */
    const char *fs_type;       /* opción rw/rq/ro/sw/xx */
    int         fs_freq;       /* frecuencia de volcado, en días */
    int         fs_passno;     /* número de pase en volcado paralelo */
};

Aquí, el campo fs_type contiene (en un sistema *BSD) una de las cinco cadenas "rw", "rq", "ro", "sw", "xx" (lectura-escritura, lectura-escritura con cuota, solo lectura, swap, ignorar).

La función setfsent() abre el archivo cuando es necesario y lo posiciona en la primera línea.

La función getfsent() analiza la siguiente línea del archivo. (Después de abrirlo cuando es necesario).

La función endfsent() cierra el archivo cuando es necesario.

La función getfsspec() busca en el archivo desde el principio y devuelve la primera entrada encontrada para la cual el campo fs_spec coincide con el argumento archivo_especial.

La función getfsfile() busca en el archivo desde el principio y devuelve la primera entrada encontrada para la cual el campo fs_file coincide con el argumento punto_montaje.

VALOR DE RETORNO

En caso de éxito, las funciones getfsent(), getfsfile() y getfsspec() devuelven un puntero a un struct fstab, mientras que setfsent() devuelve 1. En caso de fallo o fin de archivo, estas funciones devuelven NULL y 0, respectivamente.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
endfsent (), setfsent () Seguridad de hilos MT-Unsafe race:fsent
getfsent (), getfsspec (), getfsfile () Seguridad de hilos MT-Unsafe race:fsent locale

VERSIÓNES

Varios sistemas operativos tienen estas funciones, por ejemplo, *BSD, SunOS, Digital UNIX, AIX (que también tiene un getfstype()). HP-UX tiene funciones con los mismos nombres, que sin embargo usan una struct checklist en lugar de una struct fstab, y llama obsoletas a estas funciones, superadas por getmntent(3).

ESTÁNDARES

Ninguno.

HISTORIA

La función getfsent() apareció en 4.0BSD; las otras cuatro funciones aparecieron en 4.3BSD.

NOTAS

Estas funciones no son seguras para hilos.

Dado que Linux permite montar un dispositivo especial de bloque en varios lugares, y dado que varios dispositivos pueden tener el mismo punto de montaje, donde el último dispositivo con un punto de montaje dado es el interesante, mientras que getfsfile() y getfsspec() solo devuelven la primera ocurrencia, estas dos funciones no son adecuadas para su uso en Linux.

VER TAMBIÉN

getmntent(3), fstab(5)
