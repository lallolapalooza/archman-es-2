semaphore.h(0P) Manual del programador POSIX semaphore.h(0P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

semaphore.h — semáforos

SINOPSIS

#include <semaphore.h>

DESCRIPCIÓN

El encabezado <semaphore.h> definirá el tipo sem_t, utilizado en la realización de operaciones de semáforo. El semáforo puede implementarse utilizando un descriptor de archivo, en cuyo caso las aplicaciones podrán abrir al menos un total de {OPEN_MAX} archivos y semáforos.

El encabezado <semaphore.h> definirá la constante simbólica SEM_FAILED que tendrá el tipo sem_t *.

Lo siguiente se declarará como funciones y también podrá definirse como macros. Se proporcionarán prototipos de función.

int    sem_close(sem_t *);
int    sem_destroy(sem_t *);
int    sem_getvalue(sem_t *restrict, int *restrict);
int    sem_init(sem_t *, int, unsigned);
sem_t *sem_open(const char *, int, ...);
int    sem_post(sem_t *);
int    sem_timedwait(sem_t *restrict, const struct timespec *restrict);
int    sem_trywait(sem_t *);
int    sem_unlink(const char *);
int    sem_wait(sem_t *);

La inclusión del encabezado <semaphore.h> puede hacer visibles símbolos definidos en los encabezados <fcntl.h> y <time.h>.
