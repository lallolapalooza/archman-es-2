setup(2) Manual de Llamadas al Sistema setup(2)

NOMBRE

setup - configura dispositivos y sistemas de archivos, monta el sistema de archivos raíz

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
[[deprecated]] int setup(void);

DESCRIPCIÓN

setup() se llama una vez desde dentro de linux/init/main.c. Llama a funciones de inicialización para dispositivos y sistemas de archivos configurados en el kernel y luego monta el sistema de archivos raíz.

Ningún proceso de usuario puede llamar a setup(). Cualquier proceso de usuario, incluso un proceso con permisos de superusuario, recibirá EPERM.

VALOR DE RETORNO

setup() siempre devuelve -1 para un proceso de usuario.

ERRORES

EPERM
Siempre, para un proceso de usuario.

ESTANDARES

Linux.

VERSIONES

Eliminada en Linux 2.1.121.

La secuencia de llamada variaba: en algunos momentos setup() ha tenido un único argumento void *BIOS y en otros un único argumento int magic.
