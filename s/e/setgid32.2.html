setgid(2) Manual de llamadas al sistema setgid(2)

NOMBRE

setgid - establecer la identidad de grupo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int setgid(gid_t gid);

DESCRIPCIÓN

setgid() establece el ID de grupo efectivo del proceso llamante. Si el proceso llamante tiene privilegios (más precisamente: tiene la capacidad CAP_SETGID en su espacio de nombres de usuario), también se establecen el GID real y el GID guardado.

En Linux, setgid() se implementa de forma similar a la versión POSIX con la característica _POSIX_SAVED_IDS. Esto permite que un programa con el bit set-group-ID, que no sea root con el bit set-user-ID, se deshaga de todos sus privilegios de grupo, realice algún trabajo sin privilegios y luego vuelva a activar el ID de grupo efectivo original de forma segura.

VALOR DE RETORNO

Si la operación es exitosa, devuelve cero. En caso de error, devuelve -1 y la variable errno se establece para indicar el error.

ERRORES

EINVAL
El ID de grupo especificado en gid no es válido en este espacio de nombres de usuario.
EPERM
El proceso llamante no tiene privilegios (no tiene la capacidad CAP_SETGID en su espacio de nombres de usuario) y gid no coincide con el ID de grupo real ni con el ID de grupo guardado del proceso llamante.

VERSIÓNES

Diferencias entre la biblioteca C y el kernel

A nivel de kernel, los IDs de usuario y de grupo son un atributo por hilo. Sin embargo, POSIX requiere que todos los hilos de un proceso compartan las mismas credenciales. La implementación de hilos NPTL maneja los requisitos de POSIX proporcionando funciones de envoltura para las diversas llamadas al sistema que cambian los UIDs y GIDs de los procesos. Estas funciones de envoltura (incluida la de setgid()) emplean una técnica basada en señales para garantizar que cuando un hilo cambia sus credenciales, todos los demás hilos del proceso también cambian sus credenciales. Para más detalles, consulte nptl(7).

ESTANDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, SVr4.

La llamada al sistema setgid() original de Linux solo soportaba IDs de grupo de 16 bits. Posteriormente, Linux 2.4 añadió setgid32() que soportaba IDs de 32 bits. La función de envoltura setgid() de glibc maneja de forma transparente la variación entre las versiones del kernel.
