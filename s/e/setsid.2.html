setsid(2) Manual de Llamadas al Sistema setsid(2)

NOMBRE

setsid - crea una sesión y establece el ID del grupo de procesos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
pid_t setsid(void);

DESCRIPCIÓN

setsid() crea una nueva sesión si el proceso que la llama no es un líder de grupo de procesos. El proceso que llama se convierte en el líder de la nueva sesión (es decir, su ID de sesión se hace igual a su ID de proceso). El proceso que llama también se convierte en el líder del grupo de procesos de un nuevo grupo de procesos en la sesión (es decir, su ID de grupo de procesos se hace igual a su ID de proceso).

El proceso que llama será el único proceso en el nuevo grupo de procesos y en la nueva sesión.

Inicialmente, la nueva sesión no tiene una terminal de control. Para obtener detalles sobre cómo una sesión adquiere una terminal de control, vea credentials(7).

VALOR DE RETORNO

En caso de éxito, se devuelve el ID (nuevo) de sesión del proceso que llama. En caso de error, se devuelve (pid_t) -1 y se establece errno para indicar el error.

ERRORES

EPERM
El ID del grupo de procesos de algún proceso coincide con el PID del proceso que llama. Por lo tanto, en particular, setsid() falla si el proceso que llama ya es un líder de grupo de procesos.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, SVr4.

NOTAS

Un hijo creado a través de fork(2) hereda el ID de sesión de su padre. El ID de sesión se conserva a través de una ejecución de execve(2).

Un líder de grupo de procesos es un proceso cuyo ID de grupo de procesos coincide con su PID. No permitir que un líder de grupo de procesos llame a setsid() evita la posibilidad de que un líder de grupo de procesos se coloque en una nueva sesión mientras que otros procesos del grupo de procesos permanecen en la sesión original; tal escenario rompería la estricta jerarquía de dos niveles de sesiones y grupos de procesos. Para estar seguro de que setsid() tendrá éxito, llame a fork(2) y haga que el padre se salga con _exit(2), mientras que el hijo (que por definición no puede ser un líder de grupo de procesos) llama a setsid().

Si una sesión tiene una terminal de control, y el indicador CLOCAL para esa terminal no está establecido, y ocurre una desconexión de terminal, entonces se envía una señal SIGHUP al líder de la sesión.

Si un proceso que es líder de sesión termina, se envía una señal SIGHUP a cada proceso del grupo de procesos en primer plano de la terminal de control.

VER TAMBIÉN

setsid(1), getsid(2), setpgid(2), setpgrp(2), tcgetsid(3), credentials(7), sched(7)
