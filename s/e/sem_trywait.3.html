sem_wait(3) Manual de funciones de biblioteca sem_wait(3)

NOMBRE

sem_wait, sem_timedwait, sem_trywait - bloquear un semáforo

BIBLIOTECA

Biblioteca de hilos POSIX (libpthread, -lpthread)

SINOPSIS

#include <semaphore.h>
int sem_wait(sem_t *sem);
int sem_trywait(sem_t *sem);
int sem_timedwait(sem_t *restrict sem,
                  const struct timespec *restrict abs_timeout);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

sem_timedwait():

    _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

sem_wait() decrementa (bloquea) el semáforo apuntado por sem. Si el valor del semáforo es mayor que cero, entonces el decremento procede y la función retorna inmediatamente. Si el semáforo actualmente tiene el valor cero, entonces la llamada se bloquea hasta que sea posible realizar el decremento (es decir, el valor del semáforo aumenta por encima de cero), o un manejador de señales interrumpe la llamada.

sem_trywait() es lo mismo que sem_wait(), excepto que si el decremento no se puede realizar inmediatamente, la llamada retorna un error (errno establecido a EAGAIN) en lugar de bloquearse.

sem_timedwait() es lo mismo que sem_wait(), excepto que abs_timeout especifica un límite en la cantidad de tiempo que la llamada debe bloquearse si el decremento no se puede realizar inmediatamente. El argumento abs_timeout apunta a una estructura timespec(3) que especifica un tiempo de espera absoluto en segundos y nanosegundos desde la Época, 1970-01-01 00:00:00 +0000 (UTC).

Si el tiempo de espera ya ha expirado en el momento de la llamada, y el semáforo no se pudo bloquear inmediatamente, entonces sem_timedwait() falla con un error de tiempo de espera (errno establecido a ETIMEDOUT).

Si la operación se puede realizar inmediatamente, entonces sem_timedwait() nunca falla con un error de tiempo de espera, independientemente del valor de abs_timeout. Además, la validez de abs_timeout no se verifica en este caso.

VALOR DE RETORNO

Todas estas funciones retornan 0 en caso de éxito; en caso de error, el valor del semáforo no se modifica, se retorna -1 y se establece errno para indicar el error.

ERRORES

EAGAIN
(sem_trywait()) La operación no se pudo realizar sin bloquearse (es decir, el semáforo tiene actualmente el valor cero).
EINTR
La llamada fue interrumpida por un manejador de señales; ver signal(7).
EINVAL
sem no es un semáforo válido.
EINVAL
(sem_timedwait()) El valor de abs_timeout.tv_nsecs es menor que 0, o mayor o igual a 1000 millones.
ETIMEDOUT
(sem_timedwait()) La llamada expiró antes de que el semáforo pudiera ser bloqueado.

EJEMPLOS

El programa (algo trivial) que se muestra a continuación opera en un semáforo sin nombre. El programa espera dos argumentos de línea de comandos. El primer argumento especifica un valor en segundos que se utiliza para establecer un temporizador de alarma para generar una señal SIGALRM. Este manejador realiza un sem_post(3) para incrementar el semáforo sobre el que se está esperando en main() usando sem_timedwait(). El segundo argumento de la línea de comandos especifica la duración del tiempo de espera, en segundos, para sem_timedwait(). Lo siguiente muestra lo que sucede en dos ejecuciones diferentes del programa:


$ ./a.out 2 3
A punto de llamar a sem_timedwait()
sem_post() desde el manejador
sem_timedwait() tuvo éxito
$ ./a.out 2 1
A punto de llamar a sem_timedwait()
sem_timedwait() expiró

Fuente del programa

#include <err.h>
#include <errno.h>
#include <semaphore.h>
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <unistd.h>
#include <assert.h>
sem_t sem;
static void
handler(int sig)
{
    write(STDOUT_FILENO, "sem_post() from handler\n", 24);
    if (sem_post(&sem) == -1) {
        write(STDERR_FILENO, "sem_post() failed\n", 18);
        _exit(EXIT_FAILURE);
    }
}
int
main(int argc, char *argv[])
{
    struct sigaction sa;
    struct timespec ts;
    int s;
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <alarm-secs> <wait-secs>\n",
                argv[0]);
        exit(EXIT_FAILURE);
    }
    if (sem_init(&sem, 0, 0) == -1)
        err(EXIT_FAILURE, "sem_init");
    /* Establecer el manejador de SIGALRM; establecer el temporizador de alarma usando argv[1].  */
    sa.sa_handler = handler;
    sigemptyset(&sa.sa_mask);
    sa.sa_flags = 0;
    if (sigaction(SIGALRM, &sa, NULL) == -1)
        err(EXIT_FAILURE, "sigaction");
    alarm(atoi(argv[1]));
    /* Calcular el intervalo relativo como tiempo actual más
       el número de segundos dado en argv[2].  */
    if (clock_gettime(CLOCK_REALTIME, &ts) == -1)
        err(EXIT_FAILURE, "clock_gettime");
    ts.tv_sec += atoi(argv[2]);
    printf("%s() a punto de llamar a sem_timedwait()\n", __func__);
    while ((s = sem_timedwait(&sem, &ts)) == -1 && errno == EINTR)
        continue;       /* Reiniciar si es interrumpido por el manejador.  */
    /* Comprobar qué sucedió.  */
    if (s == -1) {
        if (errno == ETIMEDOUT)
            printf("sem_timedwait() expiró\n");
        else
            perror("sem_timedwait");
    } else
        printf("sem_timedwait() tuvo éxito\n");
    exit((s == 0) ? EXIT_SUCCESS : EXIT_FAILURE);
}
