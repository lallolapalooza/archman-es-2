SEMCTL(3P) Manual del programador POSIX SEMCTL(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

semctl — operaciones de control de semáforos XSI

SINOPSIS

#include <sys/sem.h>
int semctl(int semid, int semnum, int cmd, ...);

DESCRIPCION

semctl() opera sobre semáforos XSI (consulte el volumen Definiciones Base de POSIX.1‐2017, Sección 4.17, Semáforo). No se especifica si esta función interactúa con las instalaciones de comunicación entre procesos en tiempo real definidas en la Sección 2.8, Tiempo Real.

semctl() proporciona una variedad de operaciones de control de semáforos según lo especificado por cmd. El cuarto argumento es opcional y depende de la operación solicitada. Si es necesario, es de tipo union semun, que la aplicación deberá declarar explícitamente:

union semun {
    int val;
    struct semid_ds *buf;
    unsigned short  *array;
} arg;

Cada operación se realizará de forma atómica.

Las siguientes operaciones de control de semáforos especificadas por cmd se ejecutan con respecto al semáforo especificado por semid y semnum. El nivel de permiso requerido para cada operación se muestra junto a cada comando; consulte la Sección 2.7, Comunicación entre procesos XSI. Los nombres simbólicos para los valores de cmd se definen en la cabecera <sys/sem.h>:

GETVAL
Devuelve el valor de semval; consulte <sys/sem.h>. Requiere permiso de lectura.
SETVAL
Establece el valor de semval a arg.val, donde arg es el valor del cuarto argumento de semctl(). Cuando este comando se ejecuta correctamente, el valor semadj correspondiente al semáforo especificado en todos los procesos se borra. Además, la marca de tiempo sem_ctime se establecerá a la hora actual, como se describe en la Sección 2.7.1, Descripción general de IPC. Requiere permiso de alteración; consulte la Sección 2.7, Comunicación entre procesos XSI.
GETPID
Devuelve el valor de sempid. Requiere permiso de lectura.
GETNCNT
Devuelve el valor de semncnt. Requiere permiso de lectura.
GETZCNT
Devuelve el valor de semzcnt. Requiere permiso de lectura.

Los siguientes valores de cmd operan sobre cada semval en el conjunto de semáforos:

GETALL
Devuelve el valor de semval para cada semáforo en el conjunto de semáforos y lo coloca en el array apuntado por arg.array, donde arg es el cuarto argumento de semctl(). Requiere permiso de lectura.
SETALL
Establece el valor de semval para cada semáforo en el conjunto de semáforos de acuerdo con el array apuntado por arg.array, donde arg es el cuarto argumento de semctl(). Cuando este comando se ejecuta correctamente, los valores semadj correspondientes a cada semáforo especificado en todos los procesos se borran. Además, la marca de tiempo sem_ctime se establecerá a la hora actual, como se describe en la Sección 2.7.1, Descripción general de IPC. Requiere permiso de alteración.

Los siguientes valores de cmd también están disponibles:

IPC_STAT
Coloca el valor actual de cada miembro de la estructura de datos semid_ds asociada con semid en la estructura apuntada por arg.buf, donde arg es el cuarto argumento de semctl(). Los contenidos de esta estructura se definen en <sys/sem.h>. Requiere permiso de lectura.
IPC_SET
Establece el valor de los siguientes miembros de la estructura de datos semid_ds asociada con semid al valor correspondiente que se encuentra en la estructura apuntada por arg.buf, donde arg es el cuarto argumento de semctl():
sem_perm.uid
sem_perm.gid
sem_perm.mode

Los bits de modo especificados en la Sección 2.7.1, Descripción general de IPC se copian en los bits correspondientes de sem_perm.mode asociados con semid. Los valores almacenados de cualquier otro bit no están especificados. La marca de tiempo sem_ctime se establecerá a la hora actual, como se describe en la Sección 2.7.1, Descripción general de IPC.

Este comando solo puede ser ejecutado por un proceso que tenga un ID de usuario efectivo igual al de un proceso con privilegios apropiados o al valor de sem_perm.cuid o sem_perm.uid en la estructura de datos semid_ds asociada con semid.

IPC_RMID
Elimina el identificador de semáforo especificado por semid del sistema y destruye el conjunto de semáforos y la estructura de datos semid_ds asociada con él. Este comando solo puede ser ejecutado por un proceso que tenga un ID de usuario efectivo igual al de un proceso con privilegios apropiados o al valor de sem_perm.cuid o sem_perm.uid en la estructura de datos semid_ds asociada con semid.

VALOR DE RETORNO

Si tiene éxito, el valor devuelto por semctl() depende de cmd de la siguiente manera:

GETVAL
El valor de semval.
GETPID
El valor de sempid.
GETNCNT
El valor de semncnt.
GETZCNT
El valor de semzcnt.
Todos los demás
0.

De lo contrario, semctl() devolverá -1 y establecerá errno para indicar el error.

ERRORES

semctl() fallará si:

EACCES
Se deniega el permiso de operación al proceso que llama; consulte la Sección 2.7, Comunicación entre procesos XSI.
EINVAL
El valor de semid no es un identificador de semáforo válido, o el valor de semnum es menor que 0 o mayor o igual que sem_nsems, o el valor de cmd no es un comando válido.
EPERM
El argumento cmd es igual a IPC_RMID o IPC_SET y el ID de usuario efectivo del proceso que llama no es igual al de un proceso con privilegios apropiados y no es igual al valor de sem_perm.cuid o sem_perm.uid en la estructura de datos asociada con semid.
ERANGE
El argumento cmd es igual a SETVAL o SETALL y el valor al que se debe establecer semval es mayor que el máximo impuesto por el sistema.
