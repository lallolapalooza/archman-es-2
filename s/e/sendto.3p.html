sendto(3p)

SENDTO(3P) Manual de Programador de POSIX SENDTO(3P)

PROLOGO

Esta página del manual forma parte del Manual de Programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sendto — enviar un mensaje a un socket

SINOPSIS

#include <sys/socket.h>
ssize_t sendto(int socket, const void *message, size_t length,
    int flags, const struct sockaddr *dest_addr,
    socklen_t dest_len);

DESCRIPCION

La función sendto() enviará un mensaje a través de un socket de modo conectado o sin conexión.

Si el socket es de modo sin conexión, el mensaje se enviará a la dirección especificada por dest_addr si no se ha establecido previamente una dirección de par preestablecida. Si se ha preestablecido una dirección de par, se enviará el mensaje a la dirección especificada por dest_addr (anulando la dirección de par preestablecida), o la función devolverá -1 y establecerá errno en [EISCONN].

Si el socket es de modo conectado, se ignorará dest_addr.

La función sendto() toma los siguientes argumentos:

socket
Especifica el descriptor de archivo del socket.
message
Apunta a un búfer que contiene el mensaje que se enviará.
length
Especifica el tamaño del mensaje en bytes.
flags
Especifica el tipo de transmisión del mensaje. Los valores de este argumento se forman combinando lógicamente cero o más de las siguientes banderas:
MSG_EOR
Termina un registro (si el protocolo lo soporta).
MSG_OOB
Envía datos fuera de banda en sockets que soportan datos fuera de banda. El significado y la semántica de los datos fuera de banda son específicos del protocolo.
MSG_NOSIGNAL
Solicita no enviar la señal SIGPIPE si se intenta enviar en un socket orientado a flujos que ya no está conectado. El error [EPIPE] todavía se devolverá.
dest_addr
Apunta a una estructura sockaddr que contiene la dirección de destino. La longitud y el formato de la dirección dependen de la familia de direcciones del socket.
dest_len
Especifica la longitud de la estructura sockaddr apuntada por el argumento dest_addr.

Si el protocolo del socket soporta broadcast y la dirección especificada es una dirección broadcast para el protocolo del socket, sendto() fallará si la opción SO_BROADCAST no está establecida para el socket.

El argumento dest_addr especifica la dirección del objetivo.

El argumento length especifica la longitud del mensaje.

La finalización exitosa de una llamada a sendto() no garantiza la entrega del mensaje. Un valor de retorno de -1 indica solo errores detectados localmente.

Si no hay espacio disponible en el socket de envío para contener el mensaje a transmitir y el descriptor de archivo del socket no tiene O_NONBLOCK establecido, sendto() se bloqueará hasta que haya espacio disponible. Si no hay espacio disponible en el socket de envío para contener el mensaje a transmitir y el descriptor de archivo del socket tiene O_NONBLOCK establecido, sendto() fallará.

El socket en uso puede requerir que el proceso tenga los privilegios adecuados para usar la función sendto().

VALOR DE RETORNO

Tras una finalización exitosa, sendto() devolverá el número de bytes enviados. De lo contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función sendto() fallará si:

EAFNOSUPPORT

Las direcciones en la familia de direcciones especificada no se pueden usar con este socket.
EAGAIN o EWOULDBLOCK

El descriptor de archivo del socket está marcado como O_NONBLOCK y la operación solicitada bloquearía.
EBADF
El argumento socket no es un descriptor de archivo válido.
ECONNRESET
Una conexión fue cerrada forzosamente por un par.
EINTR
Una señal interrumpió sendto() antes de que se transmitiera ningún dato.
EMSGSIZE
El mensaje es demasiado grande para ser enviado de una vez, como requiere el socket.
ENOTCONN
El socket es de modo conectado pero no está conectado.
ENOTSOCK
El argumento socket no se refiere a un socket.
EOPNOTSUPP
El argumento socket está asociado con un socket que no soporta uno o más de los valores establecidos en flags.
EPIPE
El socket está cerrado para escritura, o el socket es de modo conectado y ya no está conectado. En este último caso, y si el socket es de tipo SOCK_STREAM o SOCK_SEQPACKET y la bandera MSG_NOSIGNAL no está establecida, se genera la señal SIGPIPE al hilo que llama.

Si la familia de direcciones del socket es AF_UNIX, entonces sendto() fallará si:

EIO
Ocurrió un error de E/S al leer o escribir en el sistema de archivos.
ELOOP
Existe un bucle en los enlaces simbólicos encontrados durante la resolución de la ruta en la dirección del socket.
ENAMETOOLONG

La longitud de un componente de una ruta es mayor que {NAME_MAX}.
ENOENT
Un componente de la ruta no nombra un archivo existente o la ruta es una cadena vacía.
ENOTDIR
Un componente de la ruta de prefijo de la ruta en la dirección del socket nombra un archivo existente que no es ni un directorio ni un enlace simbólico a un directorio, o la ruta en la dirección del socket contiene al menos un carácter distinto de <barra> y termina con uno o más caracteres de <barra> finales y el último componente de la ruta nombra un archivo existente que no es ni un directorio ni un enlace simbólico a un directorio.

La función sendto() puede fallar si:

EACCES
Se deniegan los permisos de búsqueda para un componente de la ruta de prefijo; o se deniega el acceso de escritura al socket con nombre.
EDESTADDRREQ

El socket no es de modo conectado y no tiene establecida su dirección de par, y no se especificó ninguna dirección de destino.
EHOSTUNREACH

No se puede alcanzar el host de destino (probablemente porque el host está caído o un enrutador remoto no puede alcanzarlo).
EINVAL
El argumento dest_len no es una longitud válida para la familia de direcciones.
EIO
Ocurrió un error de E/S al leer o escribir en el sistema de archivos.
EISCONN
Se especificó una dirección de destino y el socket ya está conectado.

ERRORS

The sendto() function may fail if:

EACCES
Access permissions are denied for the requested address.
EAGAIN
The socket is marked non-blocking and the requested output operation would block.
EALREADY
A connection is already in progress for the socket.
EBADF
The fildes argument is not a valid file descriptor.
ECONNREFUSED
A remote host refused to allow the network connection.
DESTADDRREQ
The socket is not bound to an address, and the peer address is not specified.
EFAULT
The buf argument points to memory outside the process's address space.
EINTR
The operation was interrupted by delivery of a signal before the call returned.
EINVAL
The socket is not in a connected state and no address was supplied.
EISCONN
The socket is already connected.
ENETDOWN
The local network interface used to reach the destination is down.
ENETUNREACH

No route to the network is present.
ENOBUFS
Insufficient resources were available in the system to perform the operation.
ENOMEM
Insufficient memory was available to fulfill the request.

If the address family of the socket is AF_UNIX, then sendto() may fail if:

ELOOP
More than {SYMLOOP_MAX} symbolic links were encountered during resolution of the pathname in the socket address.
ENAMETOOLONG

The length of a pathname exceeds {PATH_MAX}, or pathname resolution of a symbolic link produced an intermediate result with a length that exceeds {PATH_MAX}.

APPLICATION USAGE
