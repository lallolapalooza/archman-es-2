SETSID(3P) Manual de Programador POSIX SETSID(3P)

PROLOG

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

setsid — crear sesión y establecer el ID del grupo de procesos

SINOPSIS

#include <unistd.h>
pid_t setsid(void);

DESCRIPCIÓN

La función setsid() creará una nueva sesión, si el proceso que la llama no es un líder de grupo de procesos. Al regresar, el proceso que la llama será el líder de sesión de esta nueva sesión, será el líder del grupo de procesos de un nuevo grupo de procesos y no tendrá una terminal de control. El ID del grupo de procesos del proceso que la llama se establecerá igual al ID del proceso del proceso que la llama. El proceso que la llama será el único proceso en el nuevo grupo de procesos y el único proceso en la nueva sesión.

VALOR DE RETORNO

Al completarse con éxito, setsid() devolverá el valor del nuevo ID del grupo de procesos del proceso que la llama. De lo contrario, devolverá -1 y establecerá errno para indicar el error.

ERRORES

La función setsid() fallará si:

EPERM
El proceso que llama ya es un líder de grupo de procesos, o el ID del grupo de procesos de un proceso distinto al que llama coincide con el ID del proceso que llama.

JUSTIFICACIÓN

La función setsid() es similar a la función setpgrp() de System V. System V, sin control de trabajos, agrupa procesos en grupos de procesos y crea nuevos grupos de procesos a través de setpgrp(); solo un grupo de procesos puede formar parte de una sesión de inicio de sesión.

El control de trabajos permite que varios grupos de procesos dentro de una sesión de inicio de sesión. Para limitar las acciones de control de trabajos de modo que solo puedan afectar a los procesos de la misma sesión de inicio de sesión, este volumen de POSIX.1‐2017 agrega el concepto de una sesión que se crea a través de setsid(). La función setsid() también crea el grupo de procesos inicial contenido en la sesión. Se pueden crear grupos de procesos adicionales a través de la función setpgid(). Un grupo de procesos de System V correspondería a una sesión POSIX que contiene un solo grupo de procesos POSIX. Tenga en cuenta que esta función requiere que el proceso que llama no sea un líder de grupo de procesos. La forma habitual de asegurarse de que esto sea cierto es crear un nuevo proceso con fork() y hacer que llame a setsid(). La función fork() garantiza que el ID del proceso del nuevo proceso no coincide con ningún ID de grupo de procesos existente.
