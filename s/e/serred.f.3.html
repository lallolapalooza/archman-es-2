subroutine serred (character*3 path, integer nunit)

SERRED

Propósito:

!>
!> SERRED prueba las salidas de error para las rutinas de control de autovalores para
!> matrices REALES:
!>
!> PATH  driver   descripción
!> ----  ------   -----------
!> SEV   SGEEV    encuentra autovalores/autovectores para A no simétrica
!> SES   SGEES    encuentra autovalores/forma de Schur para A no simétrica
!> SVX   SGEEVX   SGEEV + balanceo y estimación de condición
!> SSX   SGEESX   SGEES + balanceo y estimación de condición
!> SBD   SGESVD   calcula SVD de una matriz M-por-N A
!>       SGESDD   calcula SVD de una matriz M-por-N A (por dividir y
!>                conquistar)
!>       SGEJSV   calcula SVD de una matriz M-por-N A donde M >= N
!>       SGESVDX  calcula SVD de una matriz M-por-N A (por bisección
!>                e iteración inversa)
!>       SGESVDQ  calcula SVD de una matriz M-por-N A (con un precondicionamiento
!>                QR)
!>

Parámetros

PATH 
!>          PATH es CHARACTER*3
!>          El nombre de ruta LAPACK para las rutinas a probar.
!>

NUNIT

!>          NUNIT es INTEGER
!>          El número de unidad para la salida.
!>
