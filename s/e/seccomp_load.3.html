NOMBRE

seccomp_load - Cargar el filtro seccomp actual en el kernel

SINOPSIS

#include <seccomp.h>

typedef void * scmp_filter_ctx;

int seccomp_load(scmp_filter_ctx ctx);

Enlazar con -lseccomp.

DESCRIPCIÓN

Carga el filtro seccomp proporcionado por ctx en el kernel; si la función tiene éxito, el nuevo filtro seccomp estará activo cuando la función retorne.

Dado que es posible tener múltiples filtros seccomp apilados para una tarea dada (definida como un proceso o un hilo), es importante recordar que cada uno de los filtros cargados para una tarea dada se ejecuta cuando se realiza una llamada al sistema y la regla "más estricta" es la regla que se aplica. En el caso de seccomp, "más estricta" se define como la acción con el valor más bajo (por ejemplo, SCMP_ACT_KILL es "más estricta" que SCMP_ACT_ALLOW).

VALOR DE RETORNO

Devuelve cero en caso de éxito o uno de los siguientes códigos de error en caso de fallo:

-ECANCELED
Hubo un fallo del sistema más allá del control de la biblioteca.
-EFAULT
Fallo interno de libseccomp.
-EINVAL
Entrada inválida, ya sea el contexto o el token de arquitectura es inválido.
-ENOMEM
La biblioteca no pudo asignar suficiente memoria.
-ESRCH
No se pudo cargar el filtro debido a problemas con los hilos.

Si el atributo de filtro SCMP_FLTATR_API_SYSRAWRC es distinto de cero, entonces se pueden devolver códigos de error adicionales al llamador; estos códigos de error adicionales son los valores errno negativos devueltos por el sistema. Desafortunadamente, libseccomp no puede hacer ninguna garantía sobre estos valores de retorno.

EJEMPLOS

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc = -1;
	scmp_filter_ctx ctx;
	ctx = seccomp_init(SCMP_ACT_KILL);
	if (ctx == NULL)
		goto out;
	/* ... */
	rc = seccomp_load(ctx);
	if (rc < 0)
		goto out;
	/* ... */
out:
	seccomp_release(ctx);
	return -rc;
}

NOTAS

Si bien el filtro seccomp se puede generar independientemente del kernel, se requiere soporte del kernel para cargar y aplicar el filtro seccomp generado por libseccomp.

El sitio del proyecto libseccomp, con más información y el repositorio de código fuente, se puede encontrar en https://github.com/seccomp/libseccomp. Esta herramienta, así como la biblioteca libseccomp, está actualmente en desarrollo, por favor, informe cualquier error en el sitio del proyecto o directamente al autor.
