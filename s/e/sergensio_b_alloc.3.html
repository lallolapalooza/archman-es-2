DESCRIPCIÓN

Estas son equivalentes a las funciones no bloqueantes (sin el _b), pero se bloquean esperando los resultados. Como toda E/S síncrona, esto puede conllevar un riesgo de interbloqueo, por lo que deben usarse con cuidado.

Para usarlas, primero debe asignar una estructura de datos de bloqueo de sergensio usando sergensio_b_alloc para usarla en las otras funciones. El valor asignado solo se puede usar para una operación a la vez. Cuando haya terminado con él, debe liberarlo con sergensio_b_free.

Con estas funciones, pasa un puntero al valor que desea establecer. Si el valor al que apunta es cero, el valor no se establece, solo se obtiene. Si la función devuelve sin error, el valor actual real se devuelve en el destino del puntero pasado.

Tenga en cuenta que estas no requieren gensio_set_sync para funcionar, y pueden mezclarse con operaciones no bloqueantes.

Consulte las diversas funciones no bloqueantes para obtener detalles sobre los valores y lo que significan.

VALORES DE RETORNO

Se devuelve cero en caso de éxito, o un error de gensio en caso de fallo.
