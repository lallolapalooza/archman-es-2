seek(n) Comandos integrados de Tcl seek(n)

NOMBRE

seek - Cambia la posición de acceso para un canal abierto

SINOPSIS

seek idCanal offset ?origen?

DESCRIPCIÓN

Cambia la posición de acceso actual para idCanal.

idCanal debe ser un identificador para un canal abierto, como un canal estándar de Tcl (stdin, stdout o stderr), el valor de retorno de una invocación de open o socket, o el resultado de un comando de creación de canal proporcionado por una extensión de Tcl.

Los argumentos offset y origen especifican la posición en la que se realizará la próxima lectura o escritura para idCanal. Offset debe ser un entero (que puede ser negativo) y origen debe ser una de las siguientes opciones:

inicio
La nueva posición de acceso será offset bytes desde el inicio del archivo o dispositivo subyacente.
actual
La nueva posición de acceso será offset bytes desde la posición de acceso actual; un offset negativo mueve la posición de acceso hacia atrás en el archivo o dispositivo subyacente.
fin
La nueva posición de acceso será offset bytes desde el final del archivo o dispositivo. Un offset negativo coloca la posición de acceso antes del final del archivo, y un offset positivo coloca la posición de acceso después del final del archivo.

El argumento origen tiene como valor predeterminado inicio.

El comando vacía toda la salida en búfer del canal antes de que el comando devuelva el control, incluso si el canal está en modo no bloqueante. También descarta cualquier entrada en búfer y no leída. Este comando devuelve una cadena vacía. Ocurre un error si este comando se aplica a canales cuyo archivo o dispositivo subyacente no admite la búsqueda.

Tenga en cuenta que los valores de offset son desplazamientos de bytes, no de caracteres. Tanto seek como tell operan en términos de bytes, no de caracteres, a diferencia de read.

EJEMPLOS

Leer un archivo dos veces:

set f [open archivo.txt]
set data1 [read $f]
seek $f 0
set data2 [read $f]
close $f
# $data1 eq $data2 si el archivo no fue modificado

Leer los últimos 10 bytes de un archivo:

set f [open archivo.data]
# Esto está garantizado que funcione con datos binarios pero
# puede fallar con otras codificaciones...
fconfigure $f -translation binary
seek $f -10 end
set data [read $f 10]
close $f
