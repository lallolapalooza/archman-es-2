SETKEYCODES(8) Manual del Administrador del Sistema SETKEYCODES(8)

NOMBRE

setkeycodes - carga entradas de la tabla de mapeo de escáner-código a código de tecla del kernel

SINOPSIS

setkeycodes [opciones] escáner código_tecla ...

DESCRIPCIÓN

El comando setkeycodes lee sus argumentos de dos en dos, siendo cada par de argumentos un escáner (dado en hexadecimal) y un código de tecla (dado en decimal). Para cada par de este tipo, indica al controlador del teclado del kernel que asigne el escáner especificado al código de tecla especificado.

Este comando solo es útil para personas con teclados ligeramente inusuales, que tienen algunas teclas que producen escáneres que el kernel no reconoce.

TEORÍA

El teclado PC habitual produce una serie de escáneres para cada pulsación y liberación de tecla. (Los escáneres se muestran con showkey -s, véase showkey(1).) El kernel analiza este flujo de escáneres y lo convierte en un flujo de códigos de tecla (eventos de pulsación/liberación de tecla). (Los códigos de tecla se muestran con showkey.) Aparte de unos pocos escáneres con significado especial, y aparte de la secuencia producida por la tecla Pausa, y aparte de los escáneres relacionados con el estado de mayúsculas, y aparte del bit de subida/bajada de tecla, el flujo de escáneres consiste en escáneres sin escape xx (7 bits) y escáneres con escape e0 xx (8+7 bits). A estos escáneres o pares de escáneres se les puede asignar un código de tecla correspondiente (en el rango 1-127). Por ejemplo, si tiene una tecla Macro que produce e0 6f según showkey(1), el comando

setkeycodes e06f 112
le asignará el código de tecla 112, y entonces loadkeys(1) podrá ser usado para definir la función de esta tecla.

Algunos kernels más antiguos pueden tener codificado en duro un rango bajo de escáneres a los códigos de tecla equivalentes; setkeycodes fallará cuando intente reasignar estos.

KERNELS 2.6

En los kernels 2.6, los códigos de tecla están en el rango 1-255, en lugar de 1-127. (Podría ser mejor limitarse al rango 1-239).

En los kernels 2.6, el modo crudo, o modo escáner, no es muy crudo en absoluto. El código devuelto por showkey -s cambiará después de usar setkeycodes. Un error del kernel. Véase también showkey(1).

OPCIONES

-C, --console=DEV
el dispositivo de consola a utilizar.
-V, --version
mostrar número de versión.
-h, --help
mostrar este mensaje de uso.

ERRORES

Los códigos de tecla de X no tienen nada que ver con los de Linux. Las teclas inusuales se pueden hacer visibles bajo Linux, pero no bajo X.

VER TAMBIÉN

dumpkeys(1), loadkeys(1), showkey(1), getkeycodes(8)
