SETLOCALE(3P) Manual del programador de POSIX SETLOCALE(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

setlocale — establece la configuración regional del programa

SINOPSIS

#include <locale.h>
char *setlocale(int category, const char *locale);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función setlocale() selecciona la parte apropiada de la configuración regional global, según lo especificado por los argumentos category y locale, y se puede utilizar para cambiar o consultar toda la configuración regional global o partes de ella. El valor LC_ALL para category nombra toda la configuración regional global; otros valores para category nombran solo una parte de la configuración regional global:

LC_COLLATE
Afecta al comportamiento de las expresiones regulares y las funciones de ordenación.
LC_CTYPE
Afecta al comportamiento de las expresiones regulares, la clasificación de caracteres, las funciones de conversión de caracteres y las funciones de caracteres anchos.
LC_MESSAGES
Afecta a las expresiones de respuesta afirmativa y negativa devueltas por nl_langinfo() y a la forma en que se localizan los catálogos de mensajes. También puede afectar al comportamiento de las funciones que devuelven o escriben cadenas de mensajes.
LC_MONETARY
Afecta al comportamiento de las funciones que manejan valores monetarios.
LC_NUMERIC
Afecta al comportamiento de las funciones que manejan valores numéricos.
LC_TIME
Afecta al comportamiento de las funciones de conversión de fecha y hora.

El argumento locale es un puntero a una cadena de caracteres que contiene el ajuste requerido de category. El contenido de esta cadena depende de la implementación. Además, los siguientes valores preestablecidos de locale se definen para todos los ajustes de category:

"POSIX"
Especifica el entorno mínimo para la traducción del lenguaje C llamado configuración regional POSIX. La configuración regional POSIX es la configuración regional global predeterminada al entrar en main().
"C"
Equivalente a "POSIX".
""
Especifica un entorno nativo definido por la implementación. La determinación del nombre de la nueva configuración regional para la categoría especificada depende del valor de las variables de entorno asociadas, LC_* y LANG; consulte el volumen de Definiciones Base de POSIX.1‐2017, Capítulo 7, Configuración regional y Capítulo 8, Variables de entorno.
Un puntero nulo
Indica a setlocale() que consulte la configuración actual de la configuración regional global y devuelva el nombre de la configuración regional si category no es LC_ALL, o una cadena que codifica el/los nombre/s de la configuración regional para todas las categorías individuales si category es LC_ALL.

Establecer todas las categorías de la configuración regional global es similar a establecer sucesivamente cada categoría individual de la configuración regional global, excepto que toda la verificación de errores se realiza antes de realizar cualquier acción. Para establecer todas las categorías de la configuración regional global, se puede invocar setlocale() como:

setlocale(LC_ALL, "");

En este caso, setlocale() primero verificará que los valores de todas las variables de entorno que necesita según las reglas de precedencia (descritas en el volumen de Definiciones Base de POSIX.1‐2017, Capítulo 8, Variables de entorno) indiquen configuraciones regionales compatibles. Si el valor de alguna de estas búsquedas de variables de entorno produce una configuración regional que no es compatible (y no nula), setlocale() devolverá un puntero nulo y la configuración regional global no se modificará. Si todas las variables de entorno nombran configuraciones regionales compatibles, setlocale() procederá como si se hubiera llamado para cada categoría, utilizando el valor apropiado de la variable de entorno asociada o del predeterminado definido por la implementación si no existe tal valor.

La configuración regional global establecida mediante setlocale() solo se utilizará en los hilos para los que no se haya establecido ninguna configuración regional actual mediante uselocale() o cuya configuración regional actual se haya establecido en la configuración regional global mediante uselocale(LC_GLOBAL_LOCALE).

La implementación se comportará como si ninguna función definida en este volumen de POSIX.1‐2017 llamara a setlocale().

La función setlocale() no necesita ser segura para hilos.

VALOR DE RETORNO

Al completarse con éxito, setlocale() devolverá la cadena asociada a la categoría especificada para la nueva configuración regional. En caso contrario, setlocale() devolverá un puntero nulo y la configuración regional global no se modificará.

Un puntero nulo para locale hará que setlocale() devuelva un puntero a la cadena asociada a la category especificada para la configuración regional global actual. La configuración regional global no se modificará.

La cadena devuelta por setlocale() es tal que una llamada posterior con esa cadena y su category asociada restaurará esa parte de la configuración regional global. La aplicación no debe modificar la cadena devuelta. El puntero de cadena devuelto puede invalidarse o el contenido de la cadena puede sobrescribirse por una llamada posterior a setlocale(). El puntero devuelto también puede invalidarse si el hilo que llama termina.

ERRORES

No se definen errores.

USO POR LA APLICACIÓN

El siguiente código ilustra cómo un programa puede inicializar el entorno internacional para un idioma, modificando selectivamente la configuración regional global para que las expresiones regulares y las operaciones de cadena se puedan aplicar a texto registrado en un idioma diferente:

setlocale(LC_ALL, "De");
setlocale(LC_COLLATE, "Fr@dict");

Los programas internacionalizados pueden iniciar operaciones de idioma de acuerdo con la configuración de variables de entorno (consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización) llamando a setlocale() de la siguiente manera:

setlocale(LC_ALL, "");

Cambiar la configuración de LC_MESSAGES no tiene ningún efecto en los catálogos que ya han sido abiertos por llamadas a catopen().

Para poder utilizar diferentes configuraciones de configuración regional mientras se ejecutan varios hilos, las aplicaciones deben usar uselocale() en lugar de setlocale().

NAME

setlocale, newlocale, duplocale, freelocale - set locale information

SYNOPSIS

#include <locale.h>
char *setlocale(int category, const char *locale);
locale_t newlocale(int category_mask, const char *locale, locale_t locale);
locale_t duplocale(locale_t locale);
void freelocale(locale_t loc);

DESCRIPTION

The setlocale() function shall determine the influence of the locale categories on the behavior of the program. When called with a non-NULL value for the locale argument, it may modify the program's locale.

The category argument is a bitmask that specifies the categories that are to be set.

The locale argument is a string that specifies the locale to be used for the given category.

The following locale categories are defined:

LC_ALL
Specifies all locale categories.
LC_COLLATE
Affects the behavior of string collation functions (such as strxfrm() and strcoll()).
LC_CTYPE
Affects the behavior of character classification and conversion functions (such as isalpha(), islower(), toupper(), tolower(), mblen(), mbstowcs(), mbtowc(), wcstomb(), wctomb(), and the behavior of character handling functions in the other categories).
LC_MESSAGES
Affects the format and content of response messages generated by diagnostic and informative messages.
LC_MONETARY
Affects the locale's representation of monetary values.
LC_NUMERIC
Affects the locale's representation of numeric values (such as the decimal point character).
LC_TIME
Affects the representation of time and date (such as strftime()).

If the locale argument is a null pointer, the current setting of the specified category is queried. If the locale argument is not a null pointer, it is a pointer to a string that specifies the locale to be set.

The newlocale() function adds the ability to create new locales. It takes a bitmask of category masks as the category_mask argument. The locale argument is a string that specifies the locale to be used for the specified categories. If the locale argument is NULL, the locale is determined by the value of the corresponding environment variables. The existing argument is a locale_t object to be duplicated, or LC_GLOBAL_LOCALE. If the existing argument is LC_GLOBAL_LOCALE, the current global locale is used as the basis for the new locale.

The duplocale() function creates a duplicate of an existing locale object. This is useful for managing thread-specific locales.

The freelocale() function frees the memory associated with a locale object created by newlocale().

RETURN VALUE

Upon successful setting of the locale, setlocale() returns the string that corresponds to the new locale setting for the specified category. If the locale argument is NULL, it returns the string that corresponds to the current locale setting for the specified category. The returned string points to an array internal to the function. The program should not modify this array. The value can be used as an argument in a subsequent call to setlocale() to restore the locale.

If the locale setting fails, setlocale() returns a null pointer and the program's locale is unchanged. The program can then use the errno variable to determine the cause of the error.

Upon successful creation of a new locale, newlocale() returns a non-NULL locale_t object that represents the new locale. If the creation fails, it returns ((locale_t) -1).

Upon successful duplication of a locale, duplocale() returns a non-NULL locale_t object that represents the duplicated locale. If duplication fails, it returns ((locale_t) -1).

The freelocale() function does not return a value.

ERRORS

The setlocale() function may fail if:

EINVAL
The value of the category argument is invalid, or the specified locale cannot be set for the specified category.

The newlocale() function may fail if:

EINVAL
The value of the category_mask argument is invalid, or the specified locale cannot be set for the specified category.
ENOMEM
Insufficient memory is available.

The duplocale() function may fail if:

EINVAL
The value of the locale argument is invalid.
ENOMEM
Insufficient memory is available.

EXAMPLES

To set the locale for all categories to the French locale, using the ISO-8859-1 codeset:

char *current_locale;
current_locale = setlocale(LC_ALL, "fr_FR.ISO-8859-1");
if (current_locale == NULL) {
    fprintf(stderr, "Could not set locale.\n");
    exit(EXIT_FAILURE);
}

To query the current locale for the LC_TIME category:

char *current_time_locale;
current_time_locale = setlocale(LC_TIME, NULL);
if (current_time_locale == NULL) {
    fprintf(stderr, "Could not get time locale.\n");
    exit(EXIT_FAILURE);
}
printf("Current time locale is: %s\n", current_time_locale);

To create a new locale object for the French locale and use it:

locale_t new_locale;
new_locale = newlocale(LC_ALL, "fr_FR.ISO-8859-1", (locale_t)0);
if (new_locale == (locale_t)-1) {
    fprintf(stderr, "Could not create new locale.\n");
    exit(EXIT_FAILURE);
}
// Use the new locale
// ...
freelocale(new_locale);

APPLICATION USAGE

When calling setlocale() to query the current locale, the return value points to a static area. If the program intends to save this value to restore the locale later, it must copy the returned string to an array of char.

The POSIX standard specifies that the C locale (which provides a minimal international environment) is always available. Thus, setlocale() with the string "C" is guaranteed to succeed.

Calling setlocale() with an empty string (""). is equivalent to setting the locale according to the environment variables.

The newlocale(), duplocale(), and freelocale() functions provide a way to manage multiple locales, which is particularly useful for multi-threaded applications.

RATIONALE

The setlocale() function is used to query and set the program's locale. The locale affects various aspects of program behavior, including character classification, string collation, number and monetary formatting, and time formatting.

The setlocale() function can be used in two primary ways:

  1. Querying the international environment:

    Call setlocale() with a specific category and a null pointer as the locale. This returns a string representing the current locale setting for that category. This string can be used later to restore the locale.

  2. Setting the international environment:

    Call setlocale() with a specific category and a string specifying the desired locale. This attempts to set the locale for the given category. If successful, it returns the name of the locale that was set. If unsuccessful, it returns a null pointer.

The special value LC_ALL can be used to set or query all locale categories at once.

The string argument for setting the locale can be a specific locale name (e.g., "fr_FR.ISO-8859-1"), the string "C" (for the default POSIX locale), or an empty string "" (to use the locale specified by environment variables).

The newlocale(), duplocale(), and freelocale() functions were introduced in POSIX.1-2008 to provide more fine-grained control over locale management, especially in multi-threaded environments. They allow the creation, duplication, and destruction of locale objects, enabling thread-specific locales without affecting the global locale.

The behavior of setlocale() in these two areas is described below. Since it is difficult to describe the behavior in words, examples are used to illustrate the behavior of specific uses.

To query the international environment, setlocale() is invoked with a specific category and the null pointer as the locale. The null pointer is a special directive to setlocale() that tells it to query rather than set the international environment. The following syntax is used to query the name of the international environment:

setlocale({LC_ALL, LC_COLLATE, LC_CTYPE, LC_MESSAGES, LC_MONETARY, \
    LC_NUMERIC, LC_TIME},(char *) NULL);

The setlocale() function shall return the string corresponding to the current international environment. This value may be used by a subsequent call to setlocale() to reset the international environment to this value. However, it should be noted that the return value from setlocale() may be a pointer to a static area within the function and is not guaranteed to remain unchanged (that is, it may be modified by a subsequent call to setlocale()). Therefore, if the purpose of calling setlocale() is to save the value of the current international environment so it can be changed and reset later, the return value should be copied to an array of char in the calling program.

There are three ways to set the international environment with setlocale():

setlocale(category, string)

This usage sets a specific category in the international environment to a specific value corresponding to the value of the string. A specific example is provided below:
setlocale(LC_ALL, "fr_FR.ISO-8859-1");

In this example, all categories of the international environment are set to the locale corresponding to the string "fr_FR.ISO-8859-1", or to the French language as spoken in France using the ISO/IEC 8859‐1:1998 standard codeset.

If the string does not correspond to a valid locale, setlocale() shall return a null pointer and the international environment is not changed. Otherwise, setlocale() shall return the name of the locale just set.

setlocale(category, "C")

The ISO C standard states that one locale must exist on all conforming implementations. The name of the locale is C and corresponds to a minimal international environment needed to support the C programming language.
setlocale(category, "")

This sets a specific category to an implementation-defined default. This corresponds to the value of the environment variables.
