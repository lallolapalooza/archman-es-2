NOMBRE

seatd-launch - Inicia un proceso con su propia instancia de seatd

SINOPSIS

seatd-launch [opciones] [--] comando

OPCIONES

-l <nivel_log>

Nivel de registro que se pasará a seatd. Consulte seatd(1) para obtener información sobre los niveles de registro disponibles.

-h

Muestra el mensaje de ayuda y sale.

-v

Muestra el número de versión y sale.

DESCRIPCIÓN

seatd-launch inicia una instancia de seatd con una ruta de socket dedicada, espera a que esté lista e inicia el comando especificado con SEATD_SOCK configurado adecuadamente. Una vez que el comando especificado termina, la instancia de seatd también se termina.

seatd requiere privilegios de root para realizar sus tareas. Esto se puede lograr a través del SUID de seatd-launch o ejecutando seatd-launch como root. seatd-launch reducirá los privilegios del usuario efectivo al usuario real antes de ejecutar el comando especificado. Si el usuario real es root, esto es simplemente una no-operación. Solo debe ejecutar seatd-launch como root si tiene la intención de que el comando especificado también se ejecute como root.

seatd-launch cumple un propósito similar al backend "builtin" de libseat, pero es superior a él por dos razones:

1.
El comando especificado nunca se ejecuta como root
2.
Se utiliza el ejecutable seatd estándar y el backend libseat

ESTADO DE SALIDA

seatd-launch sale con el estado de su hijo. Cuando el hijo termina por una señal N, seatd-launch sale con el estado 128 + N.

Si seatd-launch falla debido a otro error, sale con un estado distinto de cero.

VER TAMBIÉN

La biblioteca libseat, <libseat.h>, seatd(1)
