sem_post(3) Manual de funciones de biblioteca sem_post(3)

NOMBRE

sem_post - desbloquea un semáforo

BIBLIOTECA

Biblioteca POSIX threads (libpthread, -lpthread)

SINOPSIS

#include <semaphore.h>
int sem_post(sem_t *sem);

DESCRIPCIÓN

sem_post() incrementa (desbloquea) el semáforo apuntado por sem. Si el valor del semáforo resultante se vuelve mayor que cero, entonces otro proceso o hilo bloqueado en una llamada a sem_wait(3) será despertado y procederá a bloquear el semáforo.

VALOR DE RETORNO

sem_post() devuelve 0 si tiene éxito; en caso de error, el valor del semáforo no se modifica, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EINVAL
sem no es un semáforo válido.
EOVERFLOW
El valor excedería SEM_VALUE_MAX.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
sem_post () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

NOTAS

sem_post() es seguro para señales asíncronas: se puede llamar de forma segura dentro de un manejador de señales.

EJEMPLOS

Ver sem_wait(3) y shm_open(3).

VER TAMBIÉN

sem_getvalue(3), sem_wait(3), sem_overview(7), signal-safety(7)
