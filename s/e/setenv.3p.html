SETENV(3P) Manual del Programador POSIX SETENV(3P)

PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

setenv — añadir o cambiar variable de entorno

SINOPSIS

#include <stdlib.h>
int setenv(const char *envname, const char *envval, int overwrite);

DESCRIPCIÓN

La función setenv() actualizará o añadirá una variable en el entorno del proceso que la llama. El argumento envname apunta a una cadena que contiene el nombre de una variable de entorno que se va a añadir o modificar. La variable de entorno se establecerá al valor al que apunta envval. La función fallará si envname apunta a una cadena que contiene un carácter '='. Si la variable de entorno nombrada por envname ya existe y el valor de overwrite es distinto de cero, la función devolverá éxito y el entorno se actualizará. Si la variable de entorno nombrada por envname ya existe y el valor de overwrite es cero, la función devolverá éxito y el entorno permanecerá sin cambios.

La función setenv() actualizará la lista de punteros a la que apunta environ.

Las cadenas descritas por envname y envval son copiadas por esta función.

La función setenv() no tiene por qué ser segura para hilos.

VALOR DE RETORNO

Al completarse con éxito, se devolverá cero. De lo contrario, se devolverá -1, se establecerá errno para indicar el error y el entorno permanecerá sin cambios.

ERRORES

La función setenv() fallará si:

EINVAL
El argumento envname apunta a una cadena vacía o apunta a una cadena que contiene un carácter '='.
ENOMEM
No había suficiente memoria disponible para añadir una variable o su valor al entorno.

USO POR LA APLICACIÓN

Consulte exec() para ver las restricciones sobre cómo cambiar el entorno en aplicaciones multihilo.

FUNDAMENTO

Pueden producirse resultados imprevistos si setenv() cambia la variable externa environ. En particular, si el argumento opcional envp para main() está presente, no se modifica, y por lo tanto puede apuntar a una copia obsoleta del entorno (al igual que cualquier otra copia de environ). Sin embargo, aparte de la restricción mencionada, los desarrolladores del estándar pretendían que se soportara el método tradicional de recorrer el entorno a través del puntero environ.

Se decidió que setenv() debía ser requerida por esta versión porque aborda una funcionalidad que faltaba y no impone una carga significativa al implementador.

Hubo un considerable debate sobre si se debía requerir la función putenv() de System V o la función setenv() de BSD como función obligatoria. Se eligió la función setenv() porque permitía la implementación de la función unsetenv() para eliminar variables ambientales, sin especificar una interfaz adicional. La función putenv() está disponible como parte de la opción XSI.

Los desarrolladores del estándar consideraron exigir que setenv() indicara un error cuando una llamada a la misma resultara en la superación de {ARG_MAX}. El requisito fue rechazado ya que la condición podría ser temporal, y la aplicación eventualmente reduciría el tamaño del entorno. El éxito o fracaso final depende del tamaño en el momento de una llamada a exec, que devuelve una indicación de esta condición de error.

Consulte también la sección FUNDAMENTO de getenv().

Impulsado por Acerca de Arch Linux

Arch Linux es una distribución de Linux independiente, desarrollada con un enfoque en la simplicidad, la modernidad, el pragmatismo, el centrismo del usuario y la versatilidad.

Los objetivos principales de Arch Linux son la simplicidad, un código elegante y bien mantenido, y el control del usuario. Esto se traduce en un sistema que es fácil de usar una vez que el usuario está familiarizado con él y entiende su funcionamiento, pero que requiere una cierta curva de aprendizaje.

Arch Linux se distribuye como una imagen ISO mínima que contiene un sistema de base y un número muy limitado de paquetes seleccionados. El usuario está entonces invitado a construir el sistema deseado instalando solo los paquetes que necesita.

La filosofía de Arch Linux se resume en el principio KISS (Keep It Simple, Stupid).

Comunidad

La comunidad de Arch Linux es muy activa y proporciona ayuda a través de foros, un foro y una Wiki completa.

Paquetes

Arch Linux utiliza un gestor de paquetes llamado Pacman. Pacman es un gestor de paquetes binarios avanzado que puede manejar dependencias y actualizaciones del sistema.

El Repositorio de Paquetes de Arch Linux contiene miles de paquetes binarios, los cuales son compilados y mantenidos por el equipo de Arch Linux.

Para paquetes no disponibles en los repositorios oficiales, existe el Arch User Repository (AUR), una comunidad que proporciona scripts de compilación (PKGBUILDs) que permiten compilar paquetes desde el código fuente utilizando makepkg y luego instalarlos con Pacman.
