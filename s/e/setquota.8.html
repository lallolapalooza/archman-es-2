SETQUOTA(8) Manual del Administrador del Sistema SETQUOTA(8)

NOMBRE

setquota - establecer cuotas de disco

SINOPSIS

setquota [ -rm ] [ -u | -g | -P ] [ -F formato_cuota ] nombre limite-suave-bloques limite-duro-bloques limite-suave-inodes limite-duro-inodes -a | sistema_archivos...

setquota [ -rm ] [ -u | -g | -P ] [ -F formato_cuota ] [ -p nombre_prototipo ] nombre -a | sistema_archivos...

setquota -b [ -rm ] [ -u | -g | -P ] [ -F formato_cuota ] -a | sistema_archivos...

setquota -t [ -u | -g | -P ] [ -F formato_cuota ] periodo-gracia-bloques periodo-gracia-inodes -a | sistema_archivos...

setquota -T [ -u | -g | -P ] [ -F formato_cuota ] nombre periodo-gracia-bloques periodo-gracia-inodes -a | sistema_archivos...

DESCRIPCIÓN

setquota es un editor de cuotas de línea de comandos. El sistema de archivos, el nombre de usuario/grupo/proyecto y las nuevas cuotas para este sistema de archivos se pueden especificar en la línea de comandos. Tenga en cuenta que si se proporciona un número en lugar de un nombre de usuario/grupo/proyecto, se trata como un UID/GID/ID de proyecto.

-r, --remote
Editar también cuotas remotas, usar rpc.rquotad en el servidor remoto para establecer la cuota. Esta opción solo está disponible si las herramientas de cuotas se compilaron con soporte habilitado para establecer cuotas a través de RPC.
-m, --no-mixed-pathnames
Actualmente, las rutas de los puntos de montaje de NFSv4 se envían sin la barra inicial en la ruta. rpc.rquotad utiliza esto para reconocer los montajes NFSv4 y anteponer correctamente la pseudoraíz del sistema de archivos NFS a la ruta. Si especifica esta opción, setquota siempre enviará rutas con una barra inicial. Esto puede ser útil por razones de compatibilidad, pero tenga en cuenta que la cuota sobre RPC dejará de funcionar si está utilizando el nuevo rpc.rquotad.
-F, --format=formato_cuota
Realizar el establecimiento para el formato especificado (es decir, no realizar la autodetección del formato). Los nombres de formato posibles son: vfsold Formato de cuota original con UIDs / GIDs de 16 bits, vfsv0 Formato de cuota con UIDs / GIDs de 32 bits, uso de espacio de 64 bits, límites de uso de inodos de 32 bits, vfsv1 Formato de cuota con límites y uso de cuotas de 64 bits, rpc (cuota sobre NFS), xfs (cuota en sistema de archivos XFS)
-u, --user
Establecer cuotas de usuario para el usuario especificado. Este es el predeterminado.
-g, --group
Establecer cuotas de grupo para el grupo especificado.
-P, --project
Establecer cuotas de proyecto para el proyecto especificado.
-p, --prototype=nombre_prototipo
Utilizar la configuración de cuotas del usuario, grupo o proyecto nombre_prototipo para establecer la cuota para el usuario, grupo o proyecto especificado.
--always-resolve
Siempre intente traducir el nombre de usuario / grupo / proyecto a uid / gid / ID de proyecto, incluso si el nombre está compuesto solo de dígitos.
-b, --batch
Leer la información a establecer desde stdin (el formato de entrada es nombre limite-suave-bloques limite-duro-bloques limite-suave-inodes limite-duro-inodes). Se ignoran las líneas vacías y las líneas que comienzan con #.
-c, --continue-batch
Si el análisis de una línea de entrada en modo batch falla, continúe procesando la siguiente línea.
-t, --edit-period
Establecer los períodos de gracia para usuarios/grupos/proyectos. Los tiempos periodo-gracia-bloques y periodo-gracia-inodes se especifican en segundos.
-T, --edit-times
Alterar los tiempos para usuarios/grupos/proyectos individuales cuando se aplica el límite suave. Los tiempos periodo-gracia-bloques y periodo-gracia-inodes se especifican en segundos o pueden ser la cadena 'unset'.
-a, --all
Recorrer todos los sistemas de archivos con cuotas en /etc/mtab y realizar el establecimiento.

limite-suave-bloques y limite-duro-bloques se interpretan como múltiplos de bloques de kibibyte (1024 bytes) por defecto. Los símbolos K, M, G y T se pueden adjuntar al valor numérico para expresar kibibytes, mebibytes, gibibytes y tebibytes.

limite-suave-inodes y limite-duro-inodes se interpretan literalmente. Los símbolos k, m, g y t se pueden adjuntar al valor numérico para expresar múltiplos de 10^3, 10^6, 10^9 y 10^12 inodos.

Para deshabilitar una cuota, establezca el parámetro correspondiente a 0. Para cambiar cuotas para varios sistemas de archivos, invoque una vez por cada sistema de archivos.

Solo el superusuario puede editar cuotas.

ARCHIVOS

aquota.user o aquota.group
archivo de cuota en la raíz del sistema de archivos (cuota versión 2, sistemas de archivos no-XFS)
quota.user o quota.group
archivo de cuota en la raíz del sistema de archivos (cuota versión 1, sistemas de archivos no-XFS)
/etc/mtab
tabla de sistemas de archivos montados
