securetty(5) Manual de formatos de archivo securetty(5)

NOMBRE

securetty - lista de terminales en las que se permite iniciar sesión a root

DESCRIPCIÓN

El archivo /etc/securetty contiene los nombres de las terminales (una por línea, sin el prefijo /dev/) que se consideran seguras para la transmisión de ciertos tokens de autenticación.

Es utilizado por (algunas versiones de) login(1) para restringir las terminales en las que root tiene permitido iniciar sesión. Consulte login.defs(5) si utiliza el conjunto de herramientas shadow.

En sistemas con PAM habilitado, es utilizado para el mismo propósito por pam_securetty(8) para restringir las terminales en las que se aceptan contraseñas vacías.

ARCHIVOS

/etc/securetty

VER TAMBIÉN

login(1), login.defs(5), pam_securetty(8)
