setbuf(3) Manual de funciones de biblioteca setbuf(3)

NOMBRE

setbuf, setbuffer, setlinebuf, setvbuf - operaciones de almacenamiento en búfer de flujos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
int setvbuf(size_t size;
            FILE *restrict stream, char buf[restrict size],
            int mode, size_t size);
void setbuf(FILE *restrict stream, char *restrict buf);
void setbuffer(size_t size;
            FILE *restrict stream, char buf[restrict size],
            size_t size);
void setlinebuf(FILE *stream);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

setbuffer(), setlinebuf():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE

DESCRIPCIÓN

Los tres tipos de almacenamiento en búfer disponibles son sin búfer, con búfer de bloque y con búfer de línea. Cuando un flujo de salida no tiene búfer, la información aparece en el archivo o terminal de destino tan pronto como se escribe; cuando tiene búfer de bloque, se guardan muchos caracteres y se escriben como un bloque; cuando tiene búfer de línea, los caracteres se guardan hasta que se emite un salto de línea o se lee entrada de cualquier flujo conectado a un dispositivo de terminal (típicamente stdin). La función fflush(3) se puede usar para forzar la salida del bloque de forma anticipada. (Ver fclose(3)).

Normalmente, todos los archivos tienen búfer de bloque. Si un flujo se refiere a una terminal (como lo hace normalmente stdout), tiene búfer de línea. El flujo de error estándar stderr siempre está sin búfer por defecto.

La función setvbuf() se puede usar en cualquier flujo abierto para cambiar su búfer. El argumento mode debe ser una de las siguientes tres macros:

_IONBF
sin búfer
_IOLBF
con búfer de línea
_IOFBF
con búfer completo

Excepto para archivos sin búfer, el argumento buf debe apuntar a un búfer de al menos size bytes de longitud; este búfer se usará en lugar del búfer actual. Si el argumento buf es NULL, solo se ve afectado el modo; se asignará un nuevo búfer en la próxima operación de lectura o escritura. La función setvbuf() solo se puede usar después de abrir un flujo y antes de que se hayan realizado otras operaciones sobre él.

Las otras tres llamadas son, en efecto, simplemente alias para llamadas a setvbuf(). La función setbuf() es exactamente equivalente a la llamada


setvbuf(stream, buf, buf ? _IOFBF : _IONBF, BUFSIZ);

La función setbuffer() es la misma, excepto que el tamaño del búfer es hasta el del llamador, en lugar de ser determinado por el predeterminado BUFSIZ. La función setlinebuf() es exactamente equivalente a la llamada:


setvbuf(stream, NULL, _IOLBF, 0);

VALOR DE RETORNO

La función setvbuf() devuelve 0 si tiene éxito. Devuelve un valor distinto de cero si falla (mode es inválido o la solicitud no se puede satisfacer). Puede establecer errno en caso de fallo.

Las otras funciones no devuelven ningún valor.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
setbuf (), setbuffer (), setlinebuf (), setvbuf () Seguridad de hilos MT-Safe

ADVERTENCIAS

POSIX señala que el valor de errno no está especificado después de una llamada a setbuf() y señala además que, dado que no se requiere que el valor de errno permanezca sin cambios después de una llamada exitosa a setbuf(), las aplicaciones deberían usar setvbuf() en su lugar para detectar errores.

ERRORES

Debes asegurarte de que el espacio al que apunta buf siga existiendo cuando stream se cierre, lo que también ocurre al terminar el programa. Por ejemplo, lo siguiente es inválido:

#include <stdio.h>
int
main(void)
{
    char buf[BUFSIZ];
    setbuf(stdout, buf);
    printf("Hola, mundo!\n");
    return 0;
}

UF(3)

NOMBRE

uf - Permite el acceso y la modificación de la configuración de iptables y NFT.

SINOPSIS

uf [opciones] [acción] [argumentos]

DESCRIPCIÓN

uf es una herramienta para la gestión de la configuración del firewall de Linux. Permite configurar tanto iptables como nftables.

OPCIONES

-h, --help

Muestra el mensaje de ayuda y sale.

-v, --version

Muestra la información de la versión y sale.

-c, --config archivo

Utiliza el archivo de configuración especificado en lugar del predeterminado.

-f, --force

Fuerza la aplicación de la configuración, incluso si hay errores de validación.

ACCIONES

load [archivo]

Carga la configuración del firewall desde el archivo especificado (o el archivo de configuración predeterminado).

save [archivo]

Guarda la configuración actual del firewall en el archivo especificado (o el archivo de configuración predeterminado).

show [tabla] [cadena]

Muestra la configuración actual del firewall. Si se especifican tabla y cadena, muestra solo esa tabla y cadena.

flush [tabla]

Elimina todas las reglas de la tabla especificada (o de todas las tablas si no se especifica).

add tabla cadena regla

Añade una nueva regla a la tabla y cadena especificadas.

delete tabla cadena regla

Elimina una regla de la tabla y cadena especificadas.

set tabla cadena propiedad valor

Establece una propiedad de la tabla o cadena especificada.

EJEMPLOS

uf load /etc/ufw/myrules.conf

Carga la configuración del firewall desde el archivo /etc/ufw/myrules.conf.

uf save

Guarda la configuración actual del firewall en el archivo de configuración predeterminado.

uf show filter

Muestra todas las reglas de la tabla filter.

uf flush mangle

Elimina todas las reglas de la tabla mangle.

uf add filter INPUT -p tcp --dport 22 -j ACCEPT

Añade una regla a la tabla filter, cadena INPUT, que permite el tráfico TCP entrante en el puerto 22.

uf delete filter INPUT -p tcp --dport 22 -j ACCEPT

Elimina la regla anterior de la tabla filter, cadena INPUT.

VER TAMBIÉN

iptables(8), nft(8), ufw(8)
