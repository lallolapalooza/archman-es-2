setxattr(2) Manual de llamadas al sistema setxattr(2)

NOMBRE

setxattr, lsetxattr, fsetxattr - establecer el valor de un atributo extendido

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/xattr.h>
int setxattr(const char *path, const char *name,
               const void *value, size_t size, int flags);
int lsetxattr(const char *path, const char *name,
               const void *value, size_t size, int flags);
int fsetxattr(int fd, const char *name,
               const void *value, size_t size, int flags);

DESCRIPCIÓN

Los atributos extendidos son pares de nombre:valor asociados con los inodos (archivos, directorios, enlaces simbólicos, etc.). Son extensiones de los atributos normales que están asociados con todos los inodos del sistema (es decir, los datos de stat(2)). Se puede encontrar una descripción completa de los conceptos de atributos extendidos en xattr(7).

setxattr() establece el valor del atributo extendido identificado por name y asociado con la path dada en el sistema de archivos. El argumento size especifica el tamaño (en bytes) de value; se permite un valor de longitud cero.

lsetxattr() es idéntica a setxattr(), excepto en el caso de un enlace simbólico, donde el atributo extendido se establece en el propio enlace, no en el archivo al que se refiere.

fsetxattr() es idéntica a setxattr(), solo que el atributo extendido se establece en el archivo abierto al que se refiere fd (devuelto por open(2)) en lugar de path.

Un nombre de atributo extendido es una cadena terminada en nulo. El name incluye un prefijo de espacio de nombres; puede haber varios espacios de nombres, disjuntos, asociados con un inodo individual. El value de un atributo extendido es un bloque de datos de texto o binarios arbitrarios de longitud especificada.

Por defecto (es decir, flags es cero), el atributo extendido se creará si no existe, o se reemplazará el valor si el atributo ya existe. Para modificar estas semánticas, se puede especificar uno de los siguientes valores en flags:

XATTR_CREATE
Realiza una creación pura, que falla si el atributo nombrado ya existe.
XATTR_REPLACE
Realiza una operación de reemplazo pura, que falla si el atributo nombrado no existe ya.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EDQUOT
Los límites de cuota de disco significaron que no quedaba espacio suficiente para almacenar el atributo extendido.
EEXIST
Se especificó XATTR_CREATE, y el atributo ya existe.
ENODATA
Se especificó XATTR_REPLACE, y el atributo no existe.
ENOSPC
No queda espacio suficiente para almacenar el atributo extendido.
ENOTSUP
El prefijo de espacio de nombres de name no es válido.
ENOTSUP
El sistema de archivos no admite atributos extendidos, o están deshabilitados.
EPERM
El archivo está marcado como inmutable o de solo adición. (Ver FS_IOC_SETFLAGS(2const).)

Además, pueden ocurrir los errores documentados en stat(2).

ERANGE
El tamaño de name o value excede un límite específico del sistema de archivos.

ESTÁNDARES

Linux.

HISTORIA

Linux 2.4, glibc 2.3.
