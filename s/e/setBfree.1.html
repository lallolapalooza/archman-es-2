SETBFREE(1) Comandos de usuario SETBFREE(1)

NOMBRE

setBfree - órgano tonewheel DSP

SINOPSIS

setBfree [ OPCIONES ] [ propiedad=valor ... ]

DESCRIPCIÓN

setBfree - órgano tonewheel DSP

setBfree es un sintetizador de software controlado por MIDI diseñado para imitar el sonido y las propiedades de los órganos electromecánicos y los dispositivos de modificación de sonido que dieron fama mundial a los nombres y productos de Laurens Hammond y Don Leslie.

OPCIONES

-c <archivo>, --config <archivo>
Cargar archivo de configuración alternativo sobre el predeterminado
-C, --noconfig
No leer el archivo de configuración predeterminado; los valores predeterminados integrados todavía se establecen.
-d, --dumpcc
Imprimir una lista de mapeos MIDI-CC al inicio
-D, --noCC
No cargar el mapa CC predeterminado al inicio
-h
Imprimir texto de ayuda breve
-H, --help
Imprimir texto de ayuda completo con lista de parámetros
-l <pgm>
Cargar un preset de programa MIDI al inicio (puede anular configuraciones previas dadas con -r, -U,..)
-M <archivo>, --midnam <archivo>
Exportar el mapeo de controlador actual a un archivo .midnam
-p <archivo>, --program <archivo>
Cargar archivo de programa alternativo sobre el predeterminado
-P, --noprogram
No leer el archivo de programa predeterminado; los programas integrados también se borran.
-r, --randomize
Aleatorizar el preset inicial (¡extravagante pero cierto!)
-U, --upper <configuración de drawbar>
Especificar la configuración inicial de drawbar, para el manual superior como 9 dígitos. Ej: 808000000
-V, --version
Imprimir información de la versión

Información General:

La configuración consta de dos partes: programa (pgm) y configuración (cfg).
La configuración estática de las propiedades del instrumento se define en un archivo .cfg. No es necesario especificar un archivo de configuración, ya que todos los parámetros configurables tienen valores predeterminados integrados. Se pueden anular al inicio usando pares 'propiedad=valor' o cargando un archivo .cfg específico. Como implica el nombre /estático/, las propiedades solo se pueden configurar al inicio de la aplicación. Sin embargo, muchas de las propiedades simplemente definen el valor inicial de configuraciones que se pueden modificar posteriormente durante la reproducción. Las que se pueden modificar dinámicamente están marcadas con un asterisco (*)
Las propiedades se modifican enviando comandos de control MIDI (CC) al sintetizador. El mapeo de CCs a funciones se puede modificar estableciendo la propiedad "midi.controller.{upper|lower|pedal}.<CC>=<función>". Los nombres de función son equivalentes a los nombres de propiedad. Ej: "midi.controller.upper.22=overdrive.outputgain" asigna la ganancia del overdrive al CC MIDI 22 en el canal MIDI 1 (superior) (Nota: cada función solo se puede asignar una vez, sin embargo, los CC MIDI se pueden reutilizar y activar múltiples funciones al mismo tiempo).
Los programas básicamente definen 'accesos directos'. Cargar un programa suele ser equivalente a enviar una serie de CCs. Los programas se utilizan comúnmente para definir instrumentos (por ejemplo, configuraciones de drawbar para imitar una flauta) o proporcionar puntos de escala (por ejemplo, reverb=64). Hay algunos comandos especiales que solo están disponibles al recuperar un programa (configuraciones aleatorias, división de manuales, activación de overdrive).
Los programas se definen en un archivo .pgm y son fijos después de iniciar la aplicación. Se activan enviando mensajes MIDI de cambio de programa (también conocidos como 'presets'). Se ignoran los bancos MIDI. Por lo tanto, se pueden especificar como máximo 127 programas.
Al inicio, se evalúan 'default.cfg' y 'default.pgm' en $XDG_CONFIG_HOME/setBfree/ (predeterminado: $HOME/.config/setBfree/), si los archivos existen, a menos que se proporcionen las opciones '--noconfig' o '--noprogram'. Se puede cargar un archivo de configuración o programa adicional utilizando la opción '-c' y '-p' respectivamente.
Ejemplo de configuración: "/usr/share/setBfree/cfg/default.cfg"
Ejemplo de programa: "/usr/share/setBfree/pgm/default.pgm"

Propiedades del Instrumento:

A continuación se muestra una lista de pares propiedad-valor disponibles y sus valores predeterminados. El valor predeterminado se omite "(-)" para las propiedades que contienen una matriz de valores.
Los identificadores de tipo son: 'S': cadena de texto, 'I': entero, 'F': flotante, 'D': flotante de doble precisión.
Las propiedades marcadas con un asterisco (*) están disponibles como funciones CC MIDI. Cuando se usan como CC, los valores 0-127 (datos MIDI) se mapean a un rango de valores apropiado para la función. En archivos de configuración o en la línea de comandos, debe usar el tipo especificado, por ejemplo: "osc.temperament=gear60 osc.wiring-crosstalk=0.2"

NAME

setBfree - A polyphonic effets processor

SYNOPSIS

setBfree [OPTION…]

DESCRIPTION

setBfree is a software rotary speaker simulator. It is designed to emulate the sound of a Leslie speaker, which is often used with Hammond organs. The effect is achieved by rotating horns and a rotating bass speaker, which cause frequency-dependent Doppler effects.

This manual page documents the configuration parameters of setBfree.

OPTIONS

Configuration parameters can be set on the command line or in a configuration file. Command-line parameters override file settings.

Parameters are grouped into sections.

Parameters for 'Leslie Simulation':

rotary.horn.rate
D* (0.5)
Horn rotor speed.
rotary.horn.acceleration
D* (1.0)
Horn rotor acceleration.
rotary.drum.rate
D* (0.2)
Drum rotor speed.
rotary.drum.acceleration
D* (1.0)
Drum rotor acceleration.
rotary.mode
I* (0)
Rotary mode: 0 = stereo, 1 = stereo with front-left / rear-right emphasis, 2 = mono.
rotary.crossover
D* (500.0)
Crossover frequency for the horn and drum rotors.
rotary.levels.drum
D* (0.7)
Drum rotor volume level.
rotary.levels.horn
D* (0.8)
Horn rotor volume level.
rotary.levels.crossover
D* (0.9)
Crossover volume level.

Additional MIDI Control-Command Functions:

These properties can not be modified directly, but are meant to be mapped to MIDI-controllers (see "General Information" above) e.g. "midi.controller.upper.70=upper.drawbar16".
{upper|lower|pedal}.drawbar<NUM>
I* (-)
where <NUM> is one of [16, 513, 8, 4, 223, 2, 135 , 113, 1]. Set MIDI-Controller IDs to adjust given drawbar. -- The range is inversely mapped to the position of the drawbar, so that fader-like controllers work in reverse, like real drawbars. Note that the MIDI controller values are quantized into 0 ... 8 to correspond to the nine discrete positions of the original drawbar system: 0:8 (loudest), 1-15:7, 16-31:6, 32-47:5, 48-63:4, 64-79:3, 80-92:2, 96-110:1, 111-127:0(off)
