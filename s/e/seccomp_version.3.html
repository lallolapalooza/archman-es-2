NOMBRE

seccomp_version - Consultar la información de la versión de libseccomp

SINOPSIS

#include <seccomp.h>

struct scmp_version {
	unsigned int major;
	unsigned int minor;
	unsigned int micro;
}

const struct scmp_version *seccomp_version(void);

Enlazar con -lseccomp.

DESCRIPCIÓN

Las funciones seccomp_version() y seccomp_reset() devuelven un puntero a una estructura scmp_version que contiene la información de la versión de la biblioteca libseccomp cargada actualmente. Las aplicaciones que necesiten verificar que están enlazadas con una versión específica de libseccomp en tiempo de ejecución pueden utilizar esta función.

El llamador no debe intentar liberar la estructura scmp_version devuelta cuando termine de usarla.

VALOR DE RETORNO

La función seccomp_version() devuelve un puntero a una estructura scmp_version en caso de éxito, NULL en caso de fallo. El llamador no debe intentar liberar la estructura devuelta.

EJEMPLOS

#include <seccomp.h>
int main(int argc, char *argv[])
{
	const struct scmp_version *ver;
	ver = seccomp_version();
	if (ver == NULL)
		goto err;
	/* ... */
	return 0;
err:
	return 1;
}

NOTAS

Aunque el filtro seccomp se puede generar independientemente del kernel, se requiere soporte del kernel para cargar y aplicar el filtro seccomp generado por libseccomp.

El sitio del proyecto libseccomp, con más información y el repositorio de código fuente, se puede encontrar en https://github.com/seccomp/libseccomp. Esta herramienta, así como la biblioteca libseccomp, se encuentra actualmente en desarrollo; por favor, informe de cualquier error en el sitio del proyecto o directamente al autor.
