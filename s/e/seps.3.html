la_constants(3) - LAPACK

NAME

la_constants - LAPACK constants

SYNOPSIS

 USE la_constants

 IMPLICIT NONE

Detailed Description

This module defines constants related to LAPACK operations. These include constants for single-precision (sp) and double-precision (dp) floating-point numbers, such as:

  • `szero`, `sone`, `stwo`, `sthree`, `sfour`, `seight`, `sten`: Basic real constants.
  • `shalf`: Half of the single-precision one.
  • `sp`: The kind parameter for single-precision real numbers.
  • `sprefix`: Prefix character for single-precision constants ('S').
  • `sulp`: Machine epsilon for single-precision.
  • `seps`: Half of machine epsilon for single-precision.
  • `ssafmin`: Smallest representable positive normalized single-precision number.
  • `ssafmax`: Largest representable positive normalized single-precision number.
  • `ssmlnum`: Smallest magnitude number in single-precision.
  • `ssrtmin`: Square root of `ssmlnum`.
  • `sssml`: Smallest magnitude positive number for which 1.0+x is not equal to 1.0.
  • `stsml`: Smallest magnitude positive number for which 1.0+x is not equal to 1.0, using ceiling calculation.
  • `ssbig`: Largest magnitude negative number.
  • `stbig`: Threshold for overflow in single-precision.
  • `srtmax`: Square root of `ssafmax`.
  • `szero`, `sone`, `stwo`, `sthree`, `sfour`, `seight`, `sten`: Basic real constants.
  • `dzero`, `done`, `dtwo`, `dthree`, `dten`: Basic double-precision real constants.
  • `dhalf`: Half of the double-precision one.
  • `dp`: The kind parameter for double-precision real numbers.
  • `dprefix`: Prefix character for double-precision constants ('D').
  • `dulp`: Machine epsilon for double-precision.
  • `dsafmin`: Smallest representable positive normalized double-precision number.
  • `dsafmax`: Largest representable positive normalized double-precision number.
  • `dsmlnum`: Smallest magnitude number in double-precision.
  • `dtsml`: Smallest magnitude positive number for which 1.0+x is not equal to 1.0, using ceiling calculation.
  • `dssml`: Smallest magnitude positive number for which 1.0+x is not equal to 1.0.
  • `dtbig`: Threshold for overflow in double-precision.
  • `dsbig`: Largest magnitude negative number.
  • `zzero`, `zone`, `zhalf`: Basic double-precision complex constants.
  • `zprefix`: Prefix character for double-precision complex constants ('Z').
