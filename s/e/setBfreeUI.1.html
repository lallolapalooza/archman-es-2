NOMBRE

setBfree - Interfaz gráfica de usuario (GUI) para el órgano de ruedas tonales DSP

SINOPSIS

setBfreeUI

DESCRIPCIÓN

setBfree - Interfaz gráfica de usuario (GUI) para el órgano de ruedas tonales DSP

setBfree es un sintetizador de software controlado por MIDI, diseñado para imitar el sonido y las propiedades de los órganos electromecánicos y los dispositivos de modificación de sonido que dieron fama mundial a los nombres y productos de Laurens Hammond y Don Leslie.

Esta GUI no toma argumentos de línea de comandos. Consulte setBfree(1) para ver las opciones de línea de comandos y la documentación completa.

ARCHIVOS DE CONFIGURACIÓN

setBfreeUI lee $XDG_CONFIG_HOME/setBfree/default.cfg y $XDG_CONFIG_HOME/setBfree/default.pgm al inicio. Consulte setBfree(1) para obtener más detalles.
