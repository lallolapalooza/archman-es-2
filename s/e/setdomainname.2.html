getdomainname(2) Manual de llamadas al sistema getdomainname(2)

NOMBRE

getdomainname, setdomainname - obtener/establecer nombre de dominio NIS

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int getdomainname(size_t size;
                  char name[size], size_t size);
int setdomainname(size_t size;
                  const char name[size], size_t size);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

getdomainname(), setdomainname():

    Desde glibc 2.21:
        _DEFAULT_SOURCE
    En glibc 2.19 y 2.20:
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Hasta e incluyendo glibc 2.19:
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPCIÓN

Estas funciones se utilizan para acceder o modificar el nombre de dominio NIS del sistema anfitrión. Más precisamente, operan sobre el nombre de dominio NIS asociado al espacio de nombres UTS del proceso que realiza la llamada.

setdomainname() establece el nombre de dominio al valor proporcionado en el array de caracteres name. El argumento size especifica el número de bytes en name. (Por lo tanto, name no requiere un byte nulo de terminación).

getdomainname() devuelve el nombre de dominio terminado en nulo en el array de caracteres name, que tiene un tamaño de size bytes. Si el nombre de dominio terminado en nulo requiere más de len bytes, getdomainname() devuelve los primeros len bytes (glibc) o genera un error (libc).

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

setdomainname() puede fallar con los siguientes errores:

EFAULT
name apuntaba fuera del espacio de direcciones del usuario.
EINVAL
size era negativo o demasiado grande.
EPERM
El llamador no tenía la capacidad CAP_SYS_ADMIN en el espacio de nombres de usuario asociado a su espacio de nombres UTS (ver namespaces(7)).

getdomainname() puede fallar con los siguientes errores:

EINVAL
Para getdomainname() bajo libc: name es NULL o name es igual o más largo que size bytes.

VERSIONES

En la mayoría de las arquitecturas de Linux (incluyendo x86), no hay una llamada al sistema getdomainname(); en su lugar, glibc implementa getdomainname() como una función de biblioteca que devuelve una copia del campo domainname devuelto por una llamada a uname(2).

ESTÁNDARES

Ninguno.

HISTORIA

Desde Linux 1.0, el límite en el tamaño de un nombre de dominio, incluyendo el byte nulo de terminación, es de 64 bytes. En kernels más antiguos, era de 8 bytes.

VER TAMBIÉN

gethostname(2), sethostname(2), uname(2), uts_namespaces(7)
