NOMBRE

seccomp_api_get, seccomp_api_set - Gestionar el nivel de API de libseccomp

SINOPSIS

#include <seccomp.h>

const unsigned int seccomp_api_get(void);
int seccomp_api_set(unsigned int level);

Enlazar con -lseccomp.

DESCRIPCIÓN

La función seccomp_api_get() devuelve un entero que representa la funcionalidad ("nivel de API") proporcionada por el kernel en ejecución actual. Es importante tener en cuenta que, si bien seccomp_api_get() puede ser llamada varias veces, el kernel solo se consulta la primera vez para ver qué funcionalidad se admite; todas las llamadas posteriores a seccomp_api_get() devuelven un valor en caché.

La función seccomp_api_set() permite a los llamantes forzar el nivel de API al valor proporcionado; sin embargo, esto es casi siempre una mala idea y se desaconseja firmemente el uso de esta función.

Los diferentes valores de nivel de API se describen a continuación:

0
Valor reservado, no utilizado actualmente.
1
Soporte de nivel base.
2
El atributo de filtro SCMP_FLTATR_CTL_TSYNC es compatible y libseccomp utiliza la llamada al sistema seccomp(2) para cargar el filtro seccomp en el kernel.
3
El atributo de filtro SCMP_FLTATR_CTL_LOG y la acción SCMP_ACT_LOG son compatibles.
4
El atributo de filtro SCMP_FLTATR_CTL_SSB es compatible.
5
La acción SCMP_ACT_NOTIFY y las API de notificación son compatibles.
6
Se admite el uso simultáneo de SCMP_FLTATR_CTL_TSYNC y las API de notificación.

VALOR DE RETORNO

La función seccomp_api_get() devuelve un entero que representa el nivel de API compatible. La función seccomp_api_set() devuelve cero en caso de éxito, valores negativos en caso de fallo.

EJEMPLOS

#include <seccomp.h>
int main(int argc, char *argv[])
{
	unsigned int api;
	api = seccomp_api_get();
	switch (api) {
	case 2:
		/* ... */
	default:
		/* ... */
	}
	return 0;
err:
	return 1;
}

NOTAS

Aunque el filtro seccomp puede generarse independientemente del kernel, se requiere soporte del kernel para cargar y aplicar el filtro seccomp generado por libseccomp.

El sitio del proyecto libseccomp, con más información y el repositorio de código fuente, se puede encontrar en https://github.com/seccomp/libseccomp. Esta herramienta, así como la biblioteca libseccomp, están actualmente en desarrollo; por favor, informe de cualquier error en el sitio del proyecto o directamente al autor.
