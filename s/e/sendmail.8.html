SENDMAIL(8) Manual del Administrador del Sistema SENDMAIL(8)

NOMBRE

sendmail — un encolador de correo para smtpd(8)

SINOPSIS

sendmail [-tv] [-F nombre] [-f remitente] destinatario ...

DESCRIPCIÓN

La utilidad sendmail es un encolador local para el demonio smtpd(8), compatible con mailwrapper(8). El mensaje se lee desde la entrada estándar (stdin) hasta que sendmail encuentra un fin de archivo. El encolador sendmail no está diseñado para ser utilizado directamente para enviar correo, sino a través de una interfaz conocida como agente de usuario de correo.

A menos que se especifique la opción opcional -t, se deben especificar uno o más destinatarios en la línea de comandos.

Las opciones son las siguientes:

-F nombre
Establece el nombre completo del remitente.
-f remitente
Establece la dirección del remitente.
-t
Lee los campos To:, Cc: y Bcc: del mensaje para obtener los destinatarios. El campo Bcc: se eliminará antes de enviar.
-v
Habilita la salida detallada.

Para mantener la compatibilidad con la implementación de Sendmail, Inc. de sendmail, se aceptan varias otras opciones, pero no tienen ningún efecto.

ESTADO DE SALIDA

La utilidad sendmail sale con 0 en caso de éxito, y >0 si ocurre un error.

VER TAMBIÉN

smtpctl(8), smtpd(8)
