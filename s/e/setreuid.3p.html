SETREUID(3P) Manual del programador POSIX SETREUID(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

setreuid — establecer IDs de usuario real y efectivo

SINOPSIS

#include <unistd.h>
int setreuid(uid_t ruid, uid_t euid);

DESCRIPCIÓN

La función setreuid() establecerá los IDs de usuario real y efectivo del proceso actual a los valores especificados por los argumentos ruid y euid. Si ruid o euid es -1, el ID de usuario efectivo o real correspondiente del proceso actual se mantendrá sin cambios.

Un proceso con privilegios apropiados puede establecer cualquier ID a cualquier valor. Un proceso sin privilegios solo puede establecer el ID de usuario efectivo si el argumento euid es igual al ID de usuario real, efectivo o guardado del proceso.

Si se está estableciendo el ID de usuario real (ruid no es -1), o se está estableciendo el ID de usuario efectivo a un valor que no es igual al ID de usuario real, entonces el ID de usuario guardado del proceso actual se establecerá igual al nuevo ID de usuario efectivo.

No está especificado si a un proceso sin privilegios apropiados se le permite cambiar el ID de usuario real para que coincida con el ID de usuario efectivo o el ID de usuario guardado del proceso.

VALOR DE RETORNO

Al completarse con éxito, se devolverá 0. De lo contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función setreuid() fallará si:

EINVAL
El valor del argumento ruid o euid es inválido o está fuera de rango.
EPERM
El proceso actual no tiene los privilegios apropiados, y se intentó cambiar el ID de usuario efectivo a un valor distinto del ID de usuario real o el ID de usuario guardado, o se intentó cambiar el ID de usuario real a un valor no permitido por la implementación.

Las siguientes secciones son informativas.

EJEMPLOS

Establecer el ID de Usuario Efectivo al ID de Usuario Real

El siguiente ejemplo establece el ID de usuario efectivo del proceso llamante al ID de usuario real, para que los archivos creados posteriormente sean propiedad del usuario actual. También establece el ID de usuario efectivo guardado al ID de usuario real, por lo que cualquier intento futuro de establecer el ID de usuario efectivo a su valor anterior fallará.

#include <unistd.h>
#include <sys/types.h>
...
setreuid(getuid(), getuid());
...

USO DE LA APLICACIÓN

Ninguno.

FUNDAMENTO

Versiones anteriores de este estándar no especificaban si el ID de usuario efectivo guardado se veía afectado por las llamadas a setreuid(). Esta versión especifica la práctica común existente que constituye una característica de seguridad importante. La capacidad de establecer tanto el ID de usuario efectivo como el ID de usuario efectivo guardado para que sean iguales al ID de usuario real significa que cualquier debilidad de seguridad en el código que se ejecuta después de ese punto no puede resultar en la ejecución de código malicioso con el ID de usuario efectivo anterior. Las aplicaciones privilegiadas ya podían hacer esto usando solo setuid(), pero para las aplicaciones sin privilegios, el único método estándar disponible es utilizar esta característica de setreuid().
