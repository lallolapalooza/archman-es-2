sem_getvalue(3) Manual de funciones de biblioteca sem_getvalue(3)

NOMBRE

sem_getvalue - obtener el valor de un semáforo

BIBLIOTECA

Biblioteca POSIX threads (libpthread, -lpthread)

SINOPSIS

#include <semaphore.h>
int sem_getvalue(sem_t *restrict sem, int *restrict sval);

DESCRIPCIÓN

sem_getvalue() coloca el valor actual del semáforo apuntado por sem en el entero apuntado por sval.

Si uno o más procesos o hilos están bloqueados esperando a bloquear el semáforo con sem_wait(3), POSIX.1 permite dos posibilidades para el valor devuelto en sval: o se devuelve 0; o un número negativo cuyo valor absoluto es el recuento del número de procesos e hilos actualmente bloqueados en sem_wait(3). Linux adopta el comportamiento anterior.

VALOR DEVUELTO

sem_getvalue() devuelve 0 en caso de éxito; en caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
sem no es un semáforo válido. (La implementación de glibc actualmente no verifica si sem es válido.)

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
sem_getvalue () Seguridad de hilos MT-Safe

ESTANDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

NOTAS

El valor del semáforo puede haber cambiado ya en el momento en que sem_getvalue() devuelve.

VER TAMBIÉN

sem_post(3), sem_wait(3), sem_overview(7)
