NOMBRE

secfixes-check - Un linter para las declaraciones secfixes de Alpine Linux en APKBUILDs

SINOPSIS

secfixes-check <apkbuild...>

DESCRIPCIÓN

secfixes-check es un linter para las declaraciones secfixes dentro de los APKBUILDs. Lee el archivo proporcionado en cada argumento de la línea de comandos y verifica violaciones de políticas para secfixes, además de validar el yaml intentando cargarlo con el módulo 'lyaml' de lua. Consulte alint(5) en la sección secfixes-check para obtener una explicación de cada violación que secfixes-checks detecta.

secfixes-check imprimirá las violaciones de políticas y saldrá con el código que corresponde al número de violaciones encontradas. Si no se encuentran violaciones, no se imprimirá nada y secfixes-check saldrá con el código 0.

SALIDA

secfixes-check imprimirá en la salida estándar cada vez que se encuentre una violación de política en el siguiente formato:

SEVERIDADCERTEZA:[TAG]:RUTA::MENSAJE
  • SEVERIDAD se refiere a cuán severa es una violación, variando de S a M.
  • CERTEZA se refiere a cuán probable es que no sea un falso positivo, variando de C a P.
  • TAG se refiere a la etiqueta de la violación, consulte alint(5) para más detalles.
  • RUTA se refiere a la ruta que se le dio a apkbuild-lint para verificar.
  • MENSAJE es un mensaje corto destinado a que los humanos sepan cuál es la violación.
