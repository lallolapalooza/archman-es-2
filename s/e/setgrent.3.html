getgrent(3) Manual de funciones de biblioteca getgrent(3)

NOMBRE

getgrent, setgrent, endgrent - obtener entrada del archivo de grupo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/types.h>
#include <grp.h>
struct group *getgrent(void);
void setgrent(void);
void endgrent(void);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

setgrent():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

getgrent(), endgrent():

    Desde glibc 2.22:
        _XOPEN_SOURCE >= 500 || _DEFAULT_SOURCE
    glibc 2.21 y anteriores
        _XOPEN_SOURCE >= 500
            || /* Desde glibc 2.12: */ _POSIX_C_SOURCE >= 200809L
            || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

La función getgrent() devuelve un puntero a una estructura que contiene los campos desglosados de un registro en la base de datos de grupos (por ejemplo, el archivo de grupo local /etc/group, NIS y LDAP). La primera vez que se llama a getgrent(), devuelve la primera entrada; posteriormente, devuelve entradas sucesivas.

La función setgrent() rebobina al principio de la base de datos de grupos, para permitir escaneos repetidos.

La función endgrent() se utiliza para cerrar la base de datos de grupos después de que se haya realizado todo el procesamiento.

La estructura group se define en <grp.h> como sigue:


struct group {
    char   *gr_name;        /* nombre del grupo */
    char   *gr_passwd;      /* contraseña del grupo */
    gid_t   gr_gid;         /* ID del grupo */
    char  **gr_mem;         /* array terminado en NULL de punteros
                               a nombres de miembros del grupo */
};

Para obtener más información sobre los campos de esta estructura, consulte group(5).

VALOR DE RETORNO

La función getgrent() devuelve un puntero a una estructura group, o NULL si no hay más entradas o ocurre un error.

En caso de error, errno puede establecerse. Si se desea comprobar errno después de la llamada, debe establecerse a cero antes de la llamada.

El valor de retorno puede apuntar a un área estática y puede ser sobrescrito por llamadas posteriores a getgrent(), getgrgid(3), o getgrnam(3). (No pase el puntero devuelto a free(3).)

ERRORES

EAGAIN
El servicio no estuvo disponible temporalmente; inténtelo de nuevo más tarde. Para los backends NSS en glibc, esto indica un error temporal al hablar con el backend. El error puede corregirse; se sugiere reintentar más tarde.
EINTR
Se capturó una señal; ver signal(7).
EIO
Error de E/S.
EMFILE
Se ha alcanzado el límite por proceso en el número de descriptores de archivo abiertos.
ENFILE
Se ha alcanzado el límite a nivel de sistema en el número total de archivos abiertos.
ENOENT
No se puede encontrar un archivo de entrada necesario. Para los backends NSS en glibc, esto indica que el backend no está configurado correctamente.
ENOMEM
Memoria insuficiente para asignar la estructura group.
ERANGE
Espacio de búfer insuficiente proporcionado.

ARCHIVOS

/etc/group
archivo de base de datos de grupos local

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
getgrent () Seguridad de hilos MT-Unsafe race:grent race:grentbuf locale
setgrent (), endgrent () Seguridad de hilos MT-Unsafe race:grent locale

En la tabla anterior, grent en race:grent significa que si alguna de las funciones setgrent(), getgrent() o endgrent() se utilizan en paralelo en diferentes hilos de un programa, se podrían producir condiciones de carrera de datos.
