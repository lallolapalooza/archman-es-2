semind(1) Manual de Comandos Generales semind(1)

NOMBRE

semind - Indexador Semántico para C

SINOPSIS

semind [opciones]
semind [opciones] add [opciones de comando] [--] [opciones del compilador] [archivos...]
semind [opciones] rm [opciones de comando] patrón
semind [opciones] search [opciones de comando] [patrón]
semind [opciones] search [opciones de comando] (-e|-l) nombrearchivo:númlinea:columna

DESCRIPCIÓN

semind es la herramienta tipo cscope fácil de usar basada en sparse/dissect. A diferencia de cscope, se ejecuta después del preprocesador y, por lo tanto, no puede indexar el código filtrado por ifdef's, pero por otro lado, comprende cómo se utiliza el símbolo y puede rastrear el uso de los miembros de las estructuras.

SUBCOMANDOS

add
genera o actualiza el archivo de índice semántico.
rm
elimina archivos del índice por patrón. El patrón es un patrón comodín de glob(7).
search
consulta información sobre un símbolo por patrón. El patrón es un patrón comodín de glob(7).

OPCIONES COMUNES

-D, --database=ARCHIVO
especifica el archivo de base de datos (por defecto: ./semind.sqlite).
-v, --verbose
muestra información sobre lo que se está haciendo.
-h, --help
muestra este texto y sale.

OPCIONES ADD

--include-local-syms
incluye en el índice los símbolos locales.

OPCIONES SEARCH

-f, --format=CADENA
especifica un formato de salida. Por defecto: '(%m) %f\t%l\t%c\t%C\t%s' (ver FORMATO más abajo).
-p, --path=PATRON
busca símbolos solo en los directorios especificados.
-m, --mode=MODO
busca solo el tipo de acceso especificado (ver MODO más abajo).
-k, --kind=TIPO
especifica un tipo de símbolo (ver TIPO más abajo).
-e, --explain
muestra qué sucede en la posición del archivo especificada;
-l, --location
muestra el uso de símbolos desde una posición de archivo específica;
-v, --verbose
muestra información sobre lo que se está haciendo;
-h, --help
muestra este texto y sale.

FORMATO

%m
modo de acceso en formato legible por humanos (ver MODO más abajo).
%f
nombre del archivo.
%l
número de línea.
%c
número de columna.
%C
el nombre de la función en la que ocurre el símbolo.
%n
nombre del símbolo.
%s
línea de código fuente. El indexador no guarda las líneas de código fuente. Se leen del archivo durante la búsqueda.

TIPO

f
función
s
struct
m
miembro de struct

MODO

El MODO se muestra como una cadena de 3 letras. La primera letra denota la parte de la dirección, la 2da. - el acceso por valor, la 3ra. - el acceso por puntero. Un valor especial 'def' significa la definición de un símbolo.

r
lectura
w
escritura
m
lectura y escritura
