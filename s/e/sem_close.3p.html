SEM_CLOSE(3P) Manual del programador POSIX SEM_CLOSE(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

sem_close — cerrar un semáforo con nombre

SINOPSIS

#include <semaphore.h>
int sem_close(sem_t *sem);

DESCRIPCIÓN

La función sem_close() indicará que el proceso de llamada ha terminado de usar el semáforo con nombre indicado por sem. Los efectos de llamar a sem_close() para un semáforo sin nombre (uno creado por sem_init()) no están definidos. La función sem_close() desasignará (es decir, hará que esté disponible para su reutilización por una posterior llamada a sem_open() por parte de este proceso) cualquier recurso del sistema asignado por el sistema para uso de este proceso para este semáforo. El efecto del uso posterior del semáforo indicado por sem por parte de este proceso no está definido. Si algún hilo en el proceso de llamada está actualmente bloqueado en el semáforo, el comportamiento no está definido. Si el semáforo no ha sido eliminado con una llamada exitosa a sem_unlink(), entonces sem_close() no tiene ningún efecto sobre el estado del semáforo. Si la función sem_unlink() se ha invocado exitosamente para name después de la llamada más reciente a sem_open() con O_CREAT para este semáforo, entonces cuando todos los procesos que han abierto el semáforo lo cierren, el semáforo ya no será accesible.

VALOR DE RETORNO

Al completarse con éxito, se devolverá el valor cero. En caso contrario, se devolverá el valor -1 y se establecerá errno para indicar el error.

ERRORES

La función sem_close() puede fallar si:

EINVAL
El argumento sem no es un descriptor de semáforo válido.
