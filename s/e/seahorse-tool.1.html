NOMBRE

seahorse-tool - Cifrado de archivos PGP/GnuPG para el Escritorio GNOME

SINOPSIS

seahorse-tool [ OPCIÓN... ]

DESCRIPCIÓN

Seahorse es una aplicación GNOME para gestionar claves de cifrado. seahorse-tool te permite cifrar, descifrar o firmar archivos. Está integrado en el menú contextual de Nautilus, pero también se puede usar desde la línea de comandos.

OPCIONES

Opciones de ayuda

-?, --help
Mostrar resumen de todas las opciones y salir.
--usage
Mostrar mensaje de uso breve y salir.

Opciones de aplicación

-i ARCHIVO, --import ARCHIVO
Importar claves desde el ARCHIVO.
-c ARCHIVO, --encrypt ARCHIVO
Cifrar ARCHIVO.
-f ARCHIVO, --sign ARCHIVO
Firmar ARCHIVO con la clave predeterminada.
-n ARCHIVO, --encrypt-sign ARCHIVO
Cifrar y firmar ARCHIVO con la clave predeterminada.
-d ARCHIVO, --decrypt ARCHIVO
Descifrar ARCHIVO cifrado.
-v ARCHIVO, --verify ARCHIVO
Verificar firma ARCHIVO.
-T, --uri-list
Leer lista de URIs en la entrada estándar.
--version
Mostrar información de versión y salir.
-h, --help
Mostrar opciones de ayuda.

Opciones adicionales

Además, se aplican las opciones de línea de comandos habituales de GTK+ y GNOME. Consulta la salida de --help para obtener detalles.
