setuid(2) Manual de llamadas al sistema setuid(2)

NOMBRE

setuid - establecer la identidad del usuario

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int setuid(uid_t uid);

DESCRIPCIÓN

setuid() establece el ID de usuario efectivo del proceso llamador. Si el proceso llamador tiene privilegios (más precisamente: si el proceso tiene la capacidad CAP_SETUID en su espacio de nombres de usuario), también se establecen el UID real y el ID de usuario establecido guardado.

En Linux, setuid() se implementa de forma similar a la versión POSIX con la característica _POSIX_SAVED_IDS. Esto permite que un programa con el ID de usuario establecido (distinto de root) renuncie a todos sus privilegios de usuario, realice un trabajo no privilegiado y luego vuelva a activar el ID de usuario efectivo original de manera segura.

Si el usuario es root o el programa tiene el bit set-user-ID establecido para root, se debe tener especial cuidado: setuid() verifica el ID de usuario efectivo del llamador y, si es el superusuario, todos los ID de usuario relacionados con el proceso se establecen en uid. Después de que esto ocurra, es imposible que el programa recupere los privilegios de root.

Por lo tanto, un programa set-user-ID-root que desee renunciar temporalmente a los privilegios de root, asumir la identidad de un usuario no privilegiado y luego recuperar los privilegios de root después, no puede utilizar setuid(). Puedes lograr esto con seteuid(2).

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

Nota: existen casos en los que setuid() puede fallar incluso cuando el llamador es UID 0; es un grave error de seguridad omitir la comprobación de un retorno de fallo de setuid().

ERRORES

EAGAIN
La llamada cambiaría el UID real del llamador (es decir, uid no coincide con el UID real del llamador), pero hubo una falla temporal al asignar las estructuras de datos del kernel necesarias.
EAGAIN
uid no coincide con el ID de usuario real del llamador y esta llamada superaría el límite de recursos RLIMIT_NPROC del llamador para el número de procesos que pertenecen al ID de usuario real uid. Desde Linux 3.1, este caso de error ya no ocurre (pero las aplicaciones robustas deberían verificar este error); vea la descripción de EAGAIN en execve(2).
EINVAL
El ID de usuario especificado en uid no es válido en este espacio de nombres de usuario.
EPERM
El usuario no tiene privilegios (Linux: no tiene la capacidad CAP_SETUID en su espacio de nombres de usuario) y uid no coincide con el UID real o el ID de usuario establecido guardado del proceso llamador.

VERSIÓNES

diferencias biblioteca C/kernel

A nivel de kernel, los IDs de usuario y los IDs de grupo son un atributo por hilo. Sin embargo, POSIX requiere que todos los hilos de un proceso compartan las mismas credenciales. La implementación de hilos NPTL maneja los requisitos POSIX proporcionando funciones de envoltura para las diversas llamadas al sistema que cambian los UID y GID del proceso. Estas funciones de envoltura (incluida la de setuid()) emplean una técnica basada en señales para garantizar que cuando un hilo cambia las credenciales, todos los demás hilos del proceso también cambien sus credenciales. Para obtener detalles, consulte nptl(7).

ESTANDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, SVr4.

No del todo compatible con la llamada 4.4BSD, que establece todos los IDs de usuario real, guardado y efectivo.

La llamada al sistema original setuid() de Linux solo admitía IDs de usuario de 16 bits. Posteriormente, Linux 2.4 agregó setuid32() que admite IDs de 32 bits. La función de envoltura setuid() de glibc maneja transparentemente la variación entre versiones del kernel.

NOTAS

Linux tiene el concepto de ID de usuario del sistema de archivos, normalmente igual al ID de usuario efectivo. La llamada setuid() también establece el ID de usuario del sistema de archivos del proceso llamador. Consulte setfsuid(2).

Si uid es diferente del UID efectivo anterior, se prohibirá al proceso dejar volcados de núcleo (core dumps).

VER TAMBIÉN
