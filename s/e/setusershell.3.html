getusershell(3) Manual de Funciones de Biblioteca getusershell(3)

NOMBRE

getusershell, setusershell, endusershell - obtener shells de usuario permitidas

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
char *getusershell(void);
void setusershell(void);
void endusershell(void);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

getusershell(), setusershell(), endusershell():

    Desde glibc 2.21:
        _DEFAULT_SOURCE
    En glibc 2.19 y 2.20:
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Hasta glibc 2.19 incluido:
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPCIÓN

La función getusershell() devuelve la siguiente línea del archivo /etc/shells, abriendo el archivo si es necesario. La línea debe contener la ruta de un shell de usuario válido. Si /etc/shells no existe o no se puede leer, getusershell() se comporta como si /bin/sh y /bin/csh estuvieran listados en el archivo.

La función setusershell() rebobina /etc/shells.

La función endusershell() cierra /etc/shells.

VALOR DE RETORNO

La función getusershell() devuelve NULL al final del archivo.

ARCHIVOS

/etc/shells

ATRIBUTOS
