SECRET-TOOL(1) Comandos de usuario SECRET-TOOL(1)

NOMBRE

secret-tool - Almacenar y recuperar contraseñas

SINOPSIS

secret-tool store --label='Etiqueta' {atributo} {valor} ...

secret-tool lookup {atributo} {valor} ...

secret-tool clear {atributo} {valor} ...

secret-tool search [--all]{atributo} {valor} ...

DESCRIPCIÓN

secret-tool es una herramienta de línea de comandos que se puede usar para almacenar y recuperar contraseñas.

Cada contraseña se almacena en un elemento. Los elementos se identifican de forma única por un conjunto de claves y valores de atributos. Almacenar una contraseña requiere especificar pares únicos de nombres y valores de atributos, y al recuperar una contraseña se proporcionan los mismos pares de nombres y valores de atributos.

ALMACENAR

Para almacenar una contraseña, ejecute secret-tool con el argumento store. También debe especificar una etiqueta para la contraseña con el argumento --label. Esta etiqueta se mostrará en el gestor de contraseñas.

Asegúrese de pasar un conjunto único de nombres y valores de atributos al almacenar una contraseña. Si los atributos coinciden con un elemento ya existente, se actualizará en lugar de crear un nuevo elemento.

Si se invoca desde una terminal o tty, se le pedirá la contraseña a almacenar y solo se aceptará una línea.

Una contraseña a almacenar también se puede canalizar a través de stdin. La contraseña será el contenido de stdin hasta EOF. Si proporciona un salto de línea a través de stdin, se almacenará como parte de la contraseña.

RECUPERAR

Para recuperar una contraseña, ejecute secret-tool con el argumento lookup. Especifique los mismos nombres y pares de valores de atributos que proporcionó al almacenar la contraseña.

Si varios elementos coinciden con el atributo proporcionado, se devolverá la primera contraseña que ya esté desbloqueada. Si es necesario, se desbloqueará un elemento.

Al imprimir la contraseña en una terminal o tty, se agregará un salto de línea adicional después de la contraseña.

BORRAR

Para eliminar una contraseña, ejecute secret-tool con el argumento clear. Especifique los mismos nombres y pares de valores de atributos que proporcionó al almacenar la contraseña.

Se eliminarán todos los elementos desbloqueados que coincidan con los atributos.

BUSCAR

Este comando busca e imprime detalles sobre los elementos coincidentes en el servicio secreto. Especifique los mismos pares de atributos y valores que proporcionó al almacenar la contraseña. Puede usar las siguientes opciones:

--all

Devuelve todos los resultados coincidentes, en lugar de solo uno de los resultados. Sin esta opción, se imprimirá la primera coincidencia desbloqueada devuelta por el servicio.

--unlock

Desbloquea los elementos que están bloqueados y luego imprime sus detalles. Sin esta opción, se omiten los elementos bloqueados.

ESTADO DE SALIDA

En caso de éxito se devuelve 0, en caso contrario un código de fallo distinto de cero.

EJEMPLOS

Ejemplo 1. Almacenar, recuperar y borrar una contraseña

$ secret-tool store --label='Mi contraseña' clave1 valor1 clave2 valor2
Contraseña: hunter2
$ secret-tool lookup clave1 valor1 clave2 valor2
hunter2
$ secret-tool clear clave1 valor1 clave2 valor2

ERRORES

Se puede acceder al rastreador de errores visitando el sitio web https://gitlab.gnome.org/GNOME/libsecret/issues. Antes de enviar un informe de error, verifique que tiene la última versión de secret-tool. Muchos errores (mayores y menores) se corrigen en cada versión, y si la suya está desactualizada, el problema puede que ya esté resuelto.
