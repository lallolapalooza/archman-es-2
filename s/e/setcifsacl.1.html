SETCIFSACL(1) General Commands Manual SETCIFSACL(1)

NAME

setcifsacl - Usuarios de ayuda para alterar componentes de un descriptor de seguridad para Common Internet File System (CIFS)

SYNOPSIS

setcifsacl [-v|-U|-a|-A|-D|-M|-S|-o|-g] "{uno o más ACE o un SID}" {objeto del sistema de archivos}

DESCRIPTION

Esta herramienta forma parte del paquete cifs-utils.

setcifsacl es un programa de ayuda en el espacio de usuario para el sistema de archivos cliente CIFS de Linux. Está destinado a alterar una ACL o establecer el SID del propietario/grupo de un descriptor de seguridad para un objeto del sistema de archivos. Si un descriptor de seguridad a establecer se aplica o no, lo determina el servidor CIFS/SMB.

Este programa utiliza un plugin para manejar el mapeo de nombres de usuario y grupo a SIDs. /etc/cifs-utils/idmap-plugin debería ser un enlace simbólico que apunte al plugin correcto a utilizar.

OPTIONS

-h
Imprime el mensaje de uso y sale.
-v
Imprime el número de versión y sale.
-U
Aplica acciones de edición de ACE (-a, -D, -M, -S) a SACL (ACL de auditoría). Las acciones se aplican a DACL si no se especifica -U.
-a
Añade uno o más ACE a una ACL de un descriptor de seguridad. Se añade un ACE incluso si el mismo ACE ya existe en la ACL.
-A
Añade uno o más ACE a la ACL de un descriptor de seguridad, manteniendo el orden preferido de los ACE. El orden preferido de los ACE se describe en la siguiente documentación:
https://docs.microsoft.com/en-us/windows/win32/secauthz/order-of-aces-in-a-dacl
-D
Elimina uno o más ACE de una ACL de un descriptor de seguridad. Se debe coincidir todo el ACE con un ACE existente en la ACL para que los ACE listados sean eliminados.
-M
Modifica uno o más ACE de una ACL de un descriptor de seguridad. El SID y el tipo se utilizan para hacer coincidir los ACE existentes que se modificarán con la lista de ACE especificados.
-S
Establece una ACL de descriptor de seguridad con la lista de ACE. La ACL existente se reemplaza completamente con los ACE especificados.
-o
Establece el SID del propietario a uno especificado como argumento de línea de comandos.
-g
Establece el SID del grupo a uno especificado como argumento de línea de comandos.

El SID del propietario/grupo se puede especificar como un nombre o un valor de SID raw. Cada entrada ACE comienza con "ACL:". Uno o más ACE se especifican entre comillas dobles. Múltiples ACE se separan por una coma.

Los siguientes campos de un ACE DACL se pueden modificar con valores posibles:

  • SID - Un nombre o un valor de SID raw.
  • tipo - ALLOWED (0x0), DENIED (0x1), OBJECT_ALLOWED (0x5), OBJECT_DENIED (0x6)
  • flags - OBJECT_INHERIT_FLAG (OI o 0x1), CONTAINER_INHERIT_FLAG (CI o 0x2), NO_PROPAGATE_INHERIT_FLAG (NI o 0x4), INHERIT_ONLY_FLAG (IO o 0x8), INHERITED_ACE_FLAG (IA o 0x10) o una combinación/OR de estos valores.
  • mask - Ya sea FULL, CHANGE, READ, una combinación de R W X D P O, o un valor hexadecimal.

Los siguientes campos de un ACE SACL se pueden modificar con valores posibles:

  • SID - Un nombre o un valor de SID raw.
  • tipo - AUDIT (0x2), AUDIT_OBJECT (0x7), AUDIT_CALLBACK (0xD), AUDIT_CALLBACK_OBJECT (0xF), MANDATORY_LABEL (0x11), RESOURCE_ATTRIBUTE (0x12), SCOPED_POLICY_ID (0x13)
  • flags - SUCCESSFULL_ACCESS (SA o 0x40), FAILED_ACCESS (FA o 0x80)
  • mask - Ya sea FULL, CHANGE, READ, una combinación de R W X D P O, o un valor hexadecimal.

EXAMPLES

Añadir un ACE

setcifsacl -a "ACL:CIFSTESTDOM\user2:DENIED/0x1/D" <nombre_del_archivo>

setcifsacl -a "ACL:CIFSTESTDOM\user1:ALLOWED/OI|CI|NI/D" <nombre_del_archivo>

setcifsacl -U -a "ACL:CIFSTESTDOM\user1:AUDIT/SA/D" <nombre_del_archivo>

Añadir un ACE y reordenar la ACL

setcifsacl -A "ACL:CIFSTESTDOMuser3:ALLOWED/OI/FULL" <nombre_del_archivo> setcifsacl -A "ACL:CIFSTESTDOMuser2:DENIED/0x1/D" <nombre_del_archivo> setcifsacl -A "ACL:CIFSTESTDOMuser1:ALLOWED/OI|CI|NI/D" <nombre_del_archivo>

Después de establecer los ACE mencionados anteriormente, la salida de getcifsacl es la siguiente: ACL:CIFSTESTDOMuser2:DENIED/0x1/D ACL:CIFSTESTDOMuser3:ALLOWED/OI/FULL ACL:CIFSTESTDOMuser1:ALLOWED/OI|CI|NI/D

Eliminar un ACE

setcifsacl -D "ACL:S-1-1-0:0x1/OI/0x1201ff" <nombre_del_archivo>

setcifsacl -U -D "ACL:S-1-1-0:0x2/FA/0xf01ff" <nombre_del_archivo>

Modificar un ACE

setcifsacl -M "ACL:CIFSTESTDOM\user1:ALLOWED/0x1f/CHANGE" <nombre_del_archivo>

setcifsacl -U -M "ACL:CIFSTESTDOM\user1:AUDIT_OBJECT/SA/CHANGE" <nombre_del_archivo>

Establecer una ACL

setcifsacl -S "ACL:CIFSTESTDOM\Administrator:0x0/0x0/FULL,ACL:CIFSTESTDOM\user2:0x0/0x0/FULL" <nombre_del_archivo>

setcifsacl -U -S "ACL:CIFSTESTDOM\Administrator:AUDIT/SA/FULL,ACL:CIFSTESTDOM\user2:0x7/0x80/FULL" <nombre_del_archivo>

Establecer SID del propietario

setcifsacl -o "S-1-5-21-3338130290-3403600371-1423429424-2102" <nombre_del_archivo>

Establecer SID del grupo

setcifsacl -g " <Administrators@BUILTIN> " <nombre_del_archivo>

NOTAS

El soporte del kernel para las utilidades getcifsacl/setcifsacl se introdujo inicialmente en el kernel 2.6.37.
