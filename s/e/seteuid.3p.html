SETEUID(3P) Manual del programador POSIX SETEUID(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

seteuid — establecer el ID de usuario efectivo

SINOPSIS

#include <unistd.h>
int seteuid(uid_t uid);

DESCRIPCIÓN

Si uid es igual al ID de usuario real o al ID de usuario efectivo guardado, o si el proceso tiene privilegios apropiados, seteuid() establecerá el ID de usuario efectivo del proceso que llama a uid; el ID de usuario real y el ID de usuario efectivo guardado permanecerán sin cambios.

La función seteuid() no afectará a la lista de grupos suplementarios de ninguna manera.

VALOR DE RETORNO

Al completarse con éxito, se devolverá 0; de lo contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función seteuid() fallará si:

EINVAL
El valor del argumento uid es inválido y no es compatible con la implementación.
EPERM
El proceso no tiene los privilegios apropiados y uid no coincide con el ID de usuario real o el ID de usuario efectivo guardado.
