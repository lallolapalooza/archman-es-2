servertool(1) Herramientas Java IDL y RMI-IIOP servertool(1)

NOMBRE

servertool - Proporciona una interfaz fácil de usar para que los desarrolladores registren, anulen el registro, inicien y detengan un servidor persistente.

SINOPSIS

servertool -ORBInitialPort puertodenombredeservidor [ opciones ] [ comandos ]
opciones
Las opciones de la línea de comandos. Ver Opciones.
comandos
Los comandos de la línea de comandos. Ver Comandos.

DESCRIPCIÓN

El comando servertool proporciona la interfaz de línea de comandos para que los desarrolladores registren, anulen el registro, inicien y detengan un servidor persistente. Los comandos de línea de comandos le permiten obtener diversa información estadística sobre el servidor. Ver Comandos.

OPCIONES

-ORBInitialHost servidordenombredeservidor

Esta opción es obligatoria. Especifica la máquina host en la que se ejecuta el servidor de nombres y escucha las solicitudes entrantes. El valor servidordenombredeservidor debe especificar el puerto en el que se está ejecutando orb y escuchando las solicitudes. El valor por defecto es localhost cuando no se especifica esta opción. Si orbd y servertool se ejecutan en máquinas diferentes, entonces debe especificar el nombre o la dirección IP del host en el que se está ejecutando orbd.

Nota: En Oracle Solaris, debe convertirse en usuario root para iniciar un proceso en un puerto inferior a 1024. Oracle recomienda que utilice un número de puerto superior o igual a 1024 para el valor puertodenombredeservidor.

-Jopción

Pasa opción a la Máquina Virtual Java, donde opción es una de las opciones descritas en la página de referencia para el lanzador de aplicaciones Java. Por ejemplo, -J-Xms48m establece la memoria de inicio en 48 MB. Ver java(1).

COMANDOS

Puede iniciar el comando servertool con o sin un comando de línea de comandos.

•
Si no especificó un comando al iniciar servertool, entonces la herramienta de línea de comandos mostrará el prompt de servertool donde puede ingresar comandos: servertool >.
•
Si especifica un comando al iniciar servertool, entonces la Herramienta de Servidor Java IDL iniciará, ejecutará el comando y saldrá.
register -server nombre-de-clase-servidor -classpath rutadeacceso-a-servidor [ -applicationName nombre-aplicación -args args-para-servidor -vmargs indicadores-para-JVM ]
Registra un nuevo servidor persistente con el Demonio de Objeto de Solicitud (ORBD). Si el servidor no está ya registrado, entonces se registra y activa. Este comando provoca que se llame a un método de instalación en la clase main del servidor identificado por la opción -server. El método de instalación debe ser public static void install(org.omg.CORBA.ORB). El método install es opcional y permite a los desarrolladores proporcionar su propio comportamiento de instalación del servidor, como la creación de un esquema de base de datos.
unregister -serverid id-servidor | -applicationName nombre-aplicación
Anula el registro de un servidor del ORBD ya sea por su ID de servidor o por su nombre de aplicación. Este comando provoca que se llame a un método de desinstalación en la clase main del servidor identificado por la opción -server. El método uninstall debe ser public static void uninstall(org.omg.CORBA.ORB). El método uninstall es opcional y permite a los desarrolladores proporcionar su propio comportamiento de desinstalación del servidor, como deshacer el comportamiento del método install.
getserverid -applicationName nombre-aplicación
Devuelve el ID del servidor que corresponde al valor nombre-aplicación.
list
Lista información sobre todos los servidores persistentes registrados con el ORBD.
listappnames
Lista los nombres de aplicación de todos los servidores actualmente registrados con el ORBD.
listactive
Lista información sobre todos los servidores persistentes que fueron iniciados por el ORBD y que se están ejecutando actualmente.
locate -serverid id-servidor | -applicationName nombre-aplicación [ -endpointType tipo-punto-final ]
Localiza los puntos finales (puertos) de un tipo específico para todos los ORBs creados por un servidor registrado. Si un servidor no se está ejecutando aún, entonces se activa. Si no se especifica un valor para tipo-punto-final, entonces se devuelve el punto final plano/no protegido asociado a cada ORB en un servidor.
locateperorb -serverid id-servidor | -applicationName nombre-aplicación [ -orbid nombre-orb ]
Localiza todos los puntos finales (puertos) registrados por un Objeto de Solicitud de Broker (ORB) específico de un servidor registrado. Si un servidor no se está ejecutando aún, entonces se activa. Si no se especifica un orbid, entonces el valor por defecto de "" se asigna al orbid. Si se crean ORBs con un orbid de cadena vacía, entonces se devuelven todos los puertos registrados por él.
orblist -serverid id-servidor | -applicationName nombre-aplicación
Lista el ORBId de los ORBs definidos en un servidor. Un ORBId es el nombre de cadena para el ORB creado por el servidor. Si el servidor no se está ejecutando aún, entonces se activa.
shutdown -serverid id-servidor | -applicationName nombre-aplicación
Apaga un servidor activo que está registrado con ORBD. Durante la ejecución de este comando, el método shutdown definido en la clase especificada por el parámetro -serverid o -applicationName también se llama para apagar el proceso del servidor.
startup -serverid id-servidor | -applicationName nombre-aplicación
Inicia o activa un servidor que está registrado con ORBD. Si el servidor no se está ejecutando, entonces este comando inicia el servidor. Si el servidor ya se está ejecutando, entonces se muestra un mensaje de error.
help
Lista todos los comandos disponibles para el servidor a través del comando servertool.
quit
Sale del comando servertool.
