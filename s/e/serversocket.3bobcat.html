FBB::ServerSocket(3bobcat) Socket de servidor FBB::ServerSocket(3bobcat)

NOMBRE

FBB::ServerSocket - Socket de servidor que acepta solicitudes de conexión de Internet

SINOPSIS

#include <bobcat/serversocket>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

Un FBB::ServerSocket puede ser construido para escuchar solicitudes de conexión de Internet o del host local. Las solicitudes de conexión pueden ser aceptadas en modos bloqueante o no bloqueante. Cuando se acepta una conexión, se devuelve un socket que puede ser utilizado para leer información del cliente que solicitó la conexión o para escribir información en él. El socket que se pone a disposición es un descriptor de archivo que puede ser utilizado para inicializar un std::istream y/o std::ostream. El std::istream se utiliza para leer información del proceso cliente; el std::ostream se utiliza para enviar información al proceso cliente. Dado que un socket puede considerarse un descriptor de archivo, las clases FBB::IFdStream, FBB::IFdStreamBuf, FBB::OFdStream y FBB::OFdStreamBuf disponibles pueden ser utilizadas provechosamente aquí. Tenga en cuenta que tener un socket disponible no significa que defina el protocolo de comunicación. Sigue siendo responsabilidad del programador cumplir con un protocolo existente o implementar un protocolo a medida. Esta última situación implica que la secuencia de operaciones de entrada y salida está definida por el programador.

Un socket de servidor de Dominio Unix puede ser definido usando FBB::LocalServerSocket.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

FBB::SocketBase

CONSTRUCTOR

o
ServerSocket(size_t port):
Este constructor inicializa un objeto FBB::ServerSocket, que escuchará conexiones en el puerto especificado. La construcción del socket no significa que el objeto FBB::ServerSocket esté realmente escuchando conexiones. Para empezar a escuchar, se debe usar el miembro listen().

Los constructores de copia y de movimiento (y los operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de FBB::SocketBase (y por lo tanto de FBB::InetAddress) están disponibles, ya que FBB::ServerSocket hereda de FBB::SocketBase.

o
void listen(size_t backlog = 5, bool blocking = true):
El miembro listen() define la forma en que FBB::ServerSocket escuchará a los clientes que solicitan una conexión. Solo puede usarse una vez con un FBB::ServerSocket. Se lanza un objeto FBB::Exception si la escucha falla, si el constructor no pudo crear un socket, o si la clase base SocketBase no pudo ser construida correctamente.
El parámetro backlog del miembro listen() define el tamaño de la cola interna del FBB::ServerSocket en la que se pueden almacenar las solicitudes de conexión a la espera de ser atendidas. Cuando hay backlog solicitudes esperando y llega otra solicitud, esa solicitud se pierde.
El segundo parámetro del miembro, blocking, se utiliza para controlar el modo de bloqueo. Por defecto, se utiliza el bloqueo, y listen() esperará hasta que se establezca una conexión. Esto está bien en situaciones donde los clientes se conectan infrecuentemente y durante intervalos de tiempo relativamente cortos. De lo contrario, en programas más complejos, se puede usar un objeto FBB::Selector para detectar la entrada en el socket del servidor y/o en varios sockets de cliente.
o
SocketBase accept():
El miembro accept() devuelve un objeto FBB::SocketBase que contiene información sobre el cliente cuya solicitud de conexión fue aceptada. El valor del socket del objeto FBB::SocketBase puede usarse para inicializar flujos que se pueden usar para comunicarse con el cliente. En programas más complejos, el FBB::SocketBase podría pasarse a una clase derivada de FBB::Fork, manejando la comunicación con el hijo como un proceso (hijo) separado.

EJEMPLO

Ver también el ejemplo de clientsocket(3bobcat).

    #include <iostream>
    #include <string>
    #include <bobcat/serversocket>
    #include <bobcat/ifdstream>
    #include <bobcat/ofdstream>
    using namespace std;
    using namespace FBB;
    int main(int argc, char **argv)
    try
    {
        if (argc == 1)
        {
            cerr << "Proporcione el número de puerto del servidor\n";
            return 1;
        }
        size_t portnr = stoul(argv[1]);
        ServerSocket server(portnr);
        cerr << "el servidor escucha en el puerto " << argv[1] << endl;
        cerr << "serversocket devuelve:\n" <<
            "dirección = " << server.dottedDecimalAddress() << "\n"
            "puerto    = " << server.port() << endl;
        int fd = server.socket();       // abre el descriptor del socket
        cout << "El descriptor de archivo del socket es " << fd << "\n"
            "El servidor termina cuando recibe una "
                                        "única `q’ en una línea\n"
            "Una conexión se termina cuando ya no se recibe "
                                        "ninguna entrada.\n"
            "Entonces es posible otra conexión" << endl;
        server.listen();                // escucha en modo bloqueante
        while (true)
        {
            SocketBase fdb = server.accept();
            int fd = fdb.socket();
            cerr << "FD del cliente = " << fd << ", " << endl <<
                    "dirección = " << fdb.dottedDecimalAddress() << ", " <<
                    endl <<
                    "comunicación a través del puerto " << fdb.port() << endl;
            IFdStream in(fd);           // flujo para leer del cliente
            OFdStream out(fd);          // flujo para escribir al cliente
            string cmd;
            while (getline(in, cmd))
            {
                cout << "Recibido: " << cmd << endl;
                out << "Recibido: " << cmd << "\r" << endl;
                if (cmd[0] == ’q’)
                    return 0;
            }
            cout << "Listo para otra conexión\n";
        }
    }
    catch (Exception const &err)
    {
        cerr <<
            err.what() << endl <<
            "El socket del servidor en el puerto " << argv[1] <<
            " no se puede abrir" << endl;
        return -1;
    }
