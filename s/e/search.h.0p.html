PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

search.h — tablas de búsqueda

SINOPSIS

#include <search.h>

DESCRIPCIÓN

El archivo de cabecera <search.h> definirá el tipo ENTRY para la estructura entry que contendrá los siguientes miembros:

char    *key
void    *data

y definirá ACTION y VISIT como tipos de datos de enumeración mediante definiciones de tipo como las siguientes:

enum { FIND, ENTER } ACTION;
enum { preorder, postorder, endorder, leaf } VISIT;

El archivo de cabecera <search.h> definirá el tipo size_t tal como se describe en <sys/types.h>.

Las siguientes funciones se declararán como funciones y también podrán definirse como macros. Se proporcionarán prototipos de función.

int    hcreate(size_t);
void   hdestroy(void);
ENTRY *hsearch(ENTRY, ACTION);
void   insque(void *, void *);
void  *lfind(const void *, const void *, size_t *,
          size_t, int (*)(const void *, const void *));
void  *lsearch(const void *, void *, size_t *,
          size_t, int (*)(const void *, const void *));
void   remque(void *);
void  *tdelete(const void *restrict, void **restrict,
          int(*)(const void *, const void *));
void  *tfind(const void *, void *const *,
          int(*)(const void *, const void *));
void  *tsearch(const void *, void **,
          int(*)(const void *, const void *));
void   twalk(const void *,
          void (*)(const void *, VISIT, int ));
