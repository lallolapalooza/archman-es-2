NOMBRE

seccomp_merge - Fusionar dos filtros seccomp

SINOPSIS

#include <seccomp.h>

typedef void * scmp_filter_ctx;

int seccomp_merge(scmp_filter_ctx dst, scmp_filter_ctx src);

Enlazar con -lseccomp.

DESCRIPCIÓN

La función seccomp_merge() fusiona el filtro seccomp en src con el filtro en dst y almacena el resultado en el filtro dst. Si tiene éxito, el filtro seccomp src se libera y se libera toda la memoria interna asociada con el filtro; no es necesario llamar a seccomp_release(3) en src y el llamante debe descartar cualquier referencia al filtro.

Para fusionar dos filtros seccomp, ambos filtros deben tener los mismos valores de atributo y no tener arquitecturas superpuestas.

VALOR DE RETORNO

Devuelve cero en caso de éxito o uno de los siguientes códigos de error en caso de fallo:

-EDOM
No se pueden fusionar los filtros debido a problemas de arquitectura, por ejemplo, incompatibilidades de orden de bytes (endian).
-EEXIST
La arquitectura ya existe en el filtro.
-EINVAL
Uno de los filtros es inválido.
-ENOMEM
La biblioteca no pudo asignar suficiente memoria.

EJEMPLOS

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc = -1;
	scmp_filter_ctx ctx_32, ctx_64;
	ctx_32 = seccomp_init(SCMP_ACT_KILL);
	if (ctx_32 == NULL)
		goto out_all;
	ctx_64 = seccomp_init(SCMP_ACT_KILL);
	if (ctx_64 == NULL)
		goto out_all;
	if (seccomp_arch_exist(ctx_32, SCMP_ARCH_X86) == -EEXIST) {
		rc = seccomp_arch_add(ctx_32, SCMP_ARCH_X86);
		if (rc != 0)
			goto out_all;
		rc = seccomp_arch_remove(ctx_32, SCMP_ARCH_NATIVE);
		if (rc != 0)
			goto out_all;
	}
	if (seccomp_arch_exist(ctx_64, SCMP_ARCH_X86_64) == -EEXIST) {
		rc = seccomp_arch_add(ctx_64, SCMP_ARCH_X86_64);
		if (rc != 0)
			goto out_all;
		rc = seccomp_arch_remove(ctx_64, SCMP_ARCH_NATIVE);
		if (rc != 0)
			goto out_all;
	}
	/* ... */
	rc = seccomp_merge(ctx_64, ctx_32);
	if (rc != 0)
		goto out_all;
	/* NOTA: el filtro 'ctx_32' ya no es válido en este punto */
	/* ... */
out:
	seccomp_release(ctx_64);
	return -rc;
out_all:
	seccomp_release(ctx_32);
	goto out;
}

NOTAS

Aunque el filtro seccomp puede generarse independientemente del núcleo, se requiere soporte del núcleo para cargar y aplicar el filtro seccomp generado por libseccomp.

El sitio del proyecto libseccomp, con más información y el repositorio de código fuente, se puede encontrar en https://github.com/seccomp/libseccomp. Esta herramienta, así como la biblioteca libseccomp, se encuentra actualmente en desarrollo; por favor, informe de cualquier error en el sitio del proyecto o directamente al autor.
