NOMBRE

setconf - cambia configuraciones en archivos de texto

SINOPSIS

setconf nombre_archivo clave valor [cadena_final para un valor multilínea]

DESCRIPCIÓN

Si existe un archivo de texto con campos como estos:

CC=gcc

lights := on

compileToday: true

anumber = 42

cabal ==1.2.3

Setconf puede cambiar los valores por otros. El valor relacionado con la primera clave encontrada será cambiado al valor proporcionado.

Por ejemplo, CC es una clave y gcc es un valor.

EJEMPLOS

setconf
Sale con código de error 1

setconf Makefile.defaults NETSURF_USE_HARU_PDF NO
En Makefile.defaults, establece NETSURF_USE_HARU_PDF a NO

setconf Makefile CC gcc
Establece CC=gcc en Makefile

setconf PKGBUILD sha256sums "('123abc' 'abc123')" ')'
En el archivo PKGBUILD, establece el valor para las claves sha256sums a
('123abc' 'abc123') independientemente de cuántas líneas abarque el valor
anterior, ya que se proporciona la cadena final ')'.

setconf app.py NUMS "[1, 2, 3]" ']'
Reemplazo multilínea, reemplazando el texto desde el valor que pertenece
a la clave NUMS hasta la cadena final ] con el valor [1, 2, 3],
independientemente de cuántas líneas abarque el valor anterior.

setconf my.conf x=1
Establece x a 1 en my.conf, incluso si my.conf usa una asignación diferente,
como x := 42, x : 42, x == 42, x :: 42 o x => 42.

setconf -a server.ini 'Z => 99'
Añade Z => 99 a server.ini

setconf --add rolling.conf N 1000
Añade N=1000. Crea el archivo si es necesario.

setconf test.file y-=0.1
Disminuye y en 0.1.

setconf values.conf x+=2
Aumenta x en 2.

setconf -d linux/printk.h CONSOLE_LOGLEVEL_DEFAULT=4
Cambia #define CONSOLE_LOGLEVEL_DEFAULT a 4

setconf -u kernel_config CONFIG_ULTRIX_PARTITION=y
Descomenta y establece CONFIG_ULTRIX_PARTITION=y, incluso si el valor original
tiene el sufijo "no está establecido". Previsto para su uso con la configuración del kernel de Linux.

OPCIONES

-v o --version
muestra el número de versión actual
-h o --help
muestra información de uso breve
-t o --test
realiza pruebas internas de autocomprobación
-a o --add
añade una opción, si no está presente. Debe ir seguido de un nombre de archivo y un par clave/valor.
-d o --define
cambia un valor #define de una sola línea
-u o --uncomment
descomenta una clave antes de cambiar el valor

POR QUÉ

Tiene como objetivo resolver un pequeño problema correctamente en lugar de mil problemas a medias, en el verdadero espíritu UNIX.

Crea una línea que es muy fácil de leer, a diferencia de usar sed para la misma tarea.

Debe quedar claro por la sintaxis lo que se está haciendo.

Solo un pequeño ejecutable, no un paquete grande.

VER TAMBIÉN

sed(1) make(1)

ERRORES

Hasta ahora, solo errores desconocidos. Los errores se pueden informar en https://github.com/xyproto/setconf/issues.
