NOMBRE

sensors - mostrar información de los sensores

SINOPSIS

sensors [ opciones ] [ chips ]
sensors -s [ chips ]
sensors --bus-list

DESCRIPCIÓN

sensors se utiliza para mostrar las lecturas actuales de todos los chips de sensores.
sensors -s se utiliza para establecer todos los límites según se especifica en el archivo de configuración.
sensors --bus-list se utiliza para generar declaraciones de bus adecuadas para el archivo de configuración.

OPCIONES

-c, --config-file archivo-config
Especificar un archivo de configuración. Si no se especifica ningún archivo, se utiliza el archivo de configuración predeterminado de libsensors. Use `-c /dev/null` para deshabilitar temporalmente este archivo de configuración predeterminado.
-h, --help
Imprimir un texto de ayuda y salir.
-s, --set
Evaluar todas las declaraciones `set' en el archivo de configuración y salir. Debe ser `root' para hacer esto. Si no se especifica este parámetro, no se evalúa ninguna declaración `set'.
-A, --no-adapter
No mostrar el adaptador para cada chip.
-u
Salida en bruto. Este modo es adecuado para depuración y para el procesamiento posterior de la salida por scripts. También es útil al escribir un archivo de configuración, ya que muestra los nombres de entrada en bruto que deben referenciarse en el archivo de configuración.
-j
Salida Json.
-J
Nueva salida json. Este modo es adecuado para el procesamiento posterior de la salida por scripts.
-v, --version
Imprimir la versión del programa y salir.
-f, --fahrenheit
Imprimir las temperaturas en grados Fahrenheit en lugar de Celsius.
--bus-list
Generar declaraciones de bus adecuadas para usar en sensors.conf. Dichas declaraciones de bus solo son necesarias si tiene varios chips que comparten la misma dirección en diferentes buses del mismo tipo. Dado que los números de bus generalmente no son estables entre reinicios, estas declaraciones le permiten referirse a cada bus por su nombre en lugar de por números.
-n, --allow-no-sensors
No fallar si no se encuentran sensores. El mensaje de error se imprimirá en el registro.

ARCHIVOS

/etc/sensors3.conf
/etc/sensors.conf

El archivo de configuración a nivel de sistema. Consulte sensors.conf(5) para obtener más detalles.

VER TAMBIÉN

sensors.conf(5), sensors-detect(8).
