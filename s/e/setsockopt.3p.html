SETSOCKOPT(3P) Manual del programador POSIX SETSOCKOPT(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

setsockopt — establecer las opciones del socket

SINOPSIS

#include <sys/socket.h>
int setsockopt(int socket, int level, int option_name,
    const void *option_value, socklen_t option_len);

DESCRIPCIÓN

La función setsockopt() establecerá la opción especificada por el argumento option_name, en el nivel de protocolo especificado por el argumento level, al valor al que apunta el argumento option_value para el socket asociado con el descriptor de archivo especificado por el argumento socket.

El argumento level especifica el nivel de protocolo en el que reside la opción. Para establecer opciones en el nivel de socket, especifique el argumento level como SOL_SOCKET. Para establecer opciones en otros niveles, proporcione el identificador level apropiado para el protocolo que controla la opción. Por ejemplo, para indicar que una opción es interpretada por TCP (Protocolo de Control de Transporte), establezca level en IPPROTO_TCP según se define en la cabecera <netinet/in.h>.

El argumento option_name especifica una única opción a establecer. Puede ser una de las opciones de nivel de socket definidas en <sys_socket.h> y descritas en la Sección 2.10.16, Uso de Opciones. Si option_name es igual a SO_RCVTIMEO o SO_SNDTIMEO y la implementación admite el establecimiento de la opción, no se especifica si la struct timeval a la que apunta option_value se almacena tal como se proporciona en esta función o si se redondea para alinearse con la resolución del reloj que se está utilizando. Si se llama a setsockopt() con option_name igual a SO_ACCEPTCONN, SO_ERROR o SO_TYPE, el comportamiento no se especifica.

VALOR DE RETORNO

Al completarse con éxito, setsockopt() devolverá 0. De lo contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función setsockopt() fallará si:

EBADF
El argumento socket no es un descriptor de archivo válido.
EDOM
Los valores de tiempo de espera de envío y recepción son demasiado grandes para caber en los campos de tiempo de espera de la estructura del socket.
EINVAL
La opción especificada no es válida en el nivel de socket especificado o el socket ha sido cerrado.
EISCONN
El socket ya está conectado y una opción especificada no se puede establecer mientras el socket está conectado.
ENOPROTOOPT

La opción no es compatible con el protocolo.
ENOTSOCK
El argumento socket no se refiere a un socket.

La función setsockopt() puede fallar si:

ENOMEM
No había suficiente memoria disponible para completar la operación.
ENOBUFS
No hay suficientes recursos disponibles en el sistema para completar la llamada.

USO EN APLICACIONES

La función setsockopt() proporciona a un programa de aplicación los medios para controlar el comportamiento del socket. Un programa de aplicación puede utilizar setsockopt() para asignar espacio de búfer, controlar tiempos de espera o permitir transmisiones de datos de socket. La cabecera <sys/socket.h> define las opciones de nivel de socket disponibles para setsockopt().

Pueden existir opciones en múltiples niveles de protocolo. Las opciones SO_ siempre están presentes en el nivel de socket más alto.
