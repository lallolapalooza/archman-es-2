SPEAKUPCONF(1) Comandos de usuario SPEAKUPCONF(1)

NOMBRE

speakupconf - script para cargar/guardar todas las variables en speakup

SINOPSIS

speakupconf guardar|cargar

DESCRIPCIÓN

Speakupconf es un script que guarda y restaura las variables personalizables de speakup.

Si se ejecuta como root, guarda en /etc/speakup, o, si se ejecuta como un usuario, guarda en $HOME/.speakup. Esto significa que cada usuario puede tener configuraciones únicas de speakup.
