SPLITINDEX(1) Comandos de usuario SPLITINDEX(1)

NOMBRE

splitindex - página del manual para splitindex 0.2a

SINOPSIS

splitindex.pl [OPCIÓN] ... ARCHIVO-INTERMEDIO-INDICE [OPCIÓN-MAKEINDEX] ...

splitindex [OPCIÓN] ... ARCHIVO-INTERMEDIO-INDICE [OPCIÓN-MAKEINDEX] ...

java splitindex [OPCIÓN] ... ARCHIVO-INTERMEDIO-INDICE [OPCIÓN-MAKEINDEX] ...

tex splitindex

DESCRIPCIÓN

splitindex 0.2a Copyright (c) 2002 Markus Kohm <kohm@gmx.de>

Divide un único archivo índice intermedio en múltiples archivos índice sin procesar.

Ejemplo: splitindex.pl foo.idx.

OPCIONES

-h, --help
muestra esta ayuda y termina
-m, --makeindex NOMBREPROG
llama a NOMBREPROG en lugar del predeterminado `makeindex'.
-i, --identify EXPRESIÓN
usa la EXPRESIÓN regular para hacer coincidir entradas (ver también la opción --resultis y --suffixis). El valor predeterminado es `^(\\indexentry)\[([^]]*)\](.*)$'.
-r, --resultis PATRÓN
crea una línea para ser escrita a partir del PATRÓN después de hacer coincidir líneas (ver también la opción --identify). El valor predeterminado es `$1$3'.
-s, --suffixis PATRÓN
crea un sufijo para ser usado a partir del PATRÓN después de hacer coincidir líneas (ver también la opción --identify). El valor predeterminado es `-$2'.
-v, --verbose
sea más verboso (se puede usar varias veces para aumentar la verbosidad)
--version
muestra la versión y termina

VER TAMBIÉN

La documentación completa para splitindex se mantiene como un manual de LaTeX. Si los programas texdoc y splitindex están correctamente instalados en su sitio, el comando

texdoc splitidx

debería darle acceso al manual completo.
