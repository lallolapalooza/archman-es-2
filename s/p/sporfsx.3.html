SPORFSX

Propósito:

!>
!>    SPORFSX mejora la solución calculada de un sistema de ecuaciones
!>    lineales cuando la matriz de coeficientes es simétrica definida
!>    positiva, y proporciona cotas de error y estimaciones de error
!>    hacia atrás para la solución. Además de la cota de error global,
!>    el código proporciona la cota de error componente a componente
!>    máxima si es posible. Ver los comentarios de ERR_BNDS_NORM y
!>    ERR_BNDS_COMP para detalles sobre las cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta rutina, como se describe en
!>    los argumentos EQUED y S a continuación. En este caso, la
!>    solución y las cotas de error devueltas son para el sistema
!>    original no equilibrado.
!> 
!>     Algunos parámetros opcionales se agrupan en la matriz PARAMS.
!>     Estas configuraciones determinan cómo se realiza el refinamiento,
!>     pero a menudo los valores predeterminados son aceptables. Si los
!>     predeterminados son aceptables, los usuarios pueden pasar
!>     NPARAMS = 0, lo que evita que el código fuente acceda al
!>     argumento PARAMS.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y las cotas de error correctamente.
!>       = 'N':  Sin equilibrado
!>       = 'Y':  Equilibrado de filas y columnas, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>               El lado derecho B se ha modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>     La matriz simétrica A. Si UPLO = 'U', la parte superior
!>     triangular de A de N por N contiene la parte triangular superior
!>     de la matriz A, y la parte triangular estrictamente inferior de A
!>     no se referencia. Si UPLO = 'L', la parte inferior
!>     triangular de A de N por N contiene la parte triangular inferior
!>     de la matriz A, y la parte triangular estrictamente superior de A
!>     no se referencia.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array REAL, dimension (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, tal como se calculó por SPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

S

!>          S es array REAL, dimension (N)
!>     Los factores de escala para A. Si EQUED = 'Y', A se multiplica a
!>     la izquierda y derecha por diag(S). S es un argumento de entrada
!>     si FACT = 'F'; de lo contrario, S es un argumento de salida. Si
!>     FACT = 'F' y EQUED = 'Y', cada elemento de S debe ser positivo.
!>     Si S es de salida, cada elemento de S es una potencia de la base.
!>     Si S es de entrada, cada elemento de S debe ser una potencia de
!>     la base para garantizar una solución y estimaciones de error
!>     fiables. El escalado por potencias de la base no causa errores
!>     de redondeo a menos que el resultado sea un infrayacente o un
!>     desbordamiento. Los errores de redondeo durante el escalado
!>     conducen a refinar con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden
!>     no ser fiables.
!>

B

!>          B es array REAL, dimension (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array REAL, dimension (LDX,NRHS)
!>     En la entrada, la matriz solución X, tal como se calculó por SGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Condición número escalado recíproco. Esta es una estimación del
!>     número de condición de Skeel recíproco de la matriz A después
!>     del equilibrado (si se realizó). Si esto es menor que la precisión
!>     de la máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error puede
!>     seguir siendo pequeño incluso si este número es muy pequeño y la
!>     matriz parece mal condicionada.
!>

BERR

!>          BERR es array REAL, dimension (NRHS)
!>     Error relativo componente a componente hacia atrás. Este es el
!>     error relativo componente a componente hacia atrás de cada vector
!>     solución X(j) (es decir, el cambio relativo más pequeño en cualquier
!>     elemento de A o B que haga que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de cotas de error a devolver para cada lado derecho
!>     y cada tipo (global o componente a componente). Ver ERR_BNDS_NORM y
!>     ERR_BNDS_COMP a continuación.
!>

ERR_BNDS_NORM

NAME

sporfsx — Improve the accuracy of a computed solution to a system of equations.

SYNOPSIS

SUBROUTINE SPORFSX(
     UPLO, JOB , N , NRHS , AP , AFAC , IPIV , B , SB , X , SX ,
     ERR_BNDS_NORM , ERR_BNDS_COMP , NPARAMS , PARAMS , WORK , IWORK ,
     INFO
)
CHARACTER*(1) UPLO, JOB
INTEGER N, NRHS, NPARAMS, INFO
REAL AP( * ), AFAC( * ), B( * ), SB( * ), X( * ), SX( * ),
     PARAMS( * ), WORK( * )
INTEGER IPIV( * ), IWORK( * )
REAL ERR_BNDS_NORM( * ), ERR_BNDS_COMP( * )

Function/Subroutine Documentation

The purpose of sporfsx is to improve the accuracy of a computed solution to a system of linear equations.

This subroutine can be used to compute error bounds and an iterative refinement solution to the system of equations Ax = B, where A is a symmetric positive definite matrix, possibly banded.

The subroutine takes as input a matrix A, a right-hand side vector B, and an initial solution X. It returns an improved solution X, and estimates of the error in X.

Parameters

UPLO

     UPLO is CHARACTER*1
     = 'U': Upper triangle of A is stored and will be used in
            computation.
     = 'L': Lower triangle of A is stored and will be used in
            computation.

JOB

     JOB is CHARACTER*1
     = 'N': No error bounds are computed.
     = 'E': Error bounds are computed, but not refined.
     = 'C': Error bounds are computed and refined.
     = 'S': Compute error bounds using a componentwise approach.
     See the comments below on ERR_BNDS_NORM and ERR_BNDS_COMP for
     more details on the error bounds computed.

N

     N is INTEGER
     The order of the matrix A.  N >= 0.

NRHS

     NRHS is INTEGER
     The number of right-hand sides, i.e., the number of columns of
     the matrix B. NRHS >= 0.

AP

     AP is REAL array, dimension (2*N - 1) * N if packed
     Before entry, AP must contain the packed matrix A. For UPLO = 'U',
     the array must contain the upper triangular matrix A. For UPLO = 'L',
     the array must contain the lower triangular matrix A.
     See "LAPACK Working Note 149" for details of the packing
     format.

AFAC

     AFAC is REAL array, dimension (2*N - 1) * N if packed
     On exit, AFAC is overwritten by the factorization of A.
     See "LAPACK Working Note 149" for details of the packing
     format.

IPIV

     IPIV is INTEGER array, dimension (N)
     On exit, IPIV contains the pivot indices of the factorization.
     IPIV[i] = k means that the 1x1 pivot was in row k,
     and that k is in row i.

B

     B is REAL array, dimension (LD B, NRHS)
     On entry, the N x NRHS matrix of right-hand sides.
     On exit, B is overwritten by the solution to the system of
     equations, X.

SB

     SB is REAL array, dimension (LD B, NRHS)
     On entry, SB contains the right-hand sides for scaling the
     solution X. It is used to compute the componentwise error
     bounds. Usually SB = B.

X

     X is REAL array, dimension (LD X, NRHS)
     On entry, X contains the initial solution to the system of
     equations Ax = B.
     On exit, X contains the refined solution. If JOB = 'N', then X
     is unchanged.

SX

     SX is REAL array, dimension (LD X, NRHS)
     On exit, SX contains the scaled solution X. If JOB = 'N', then SX
     is not accessed.

ERR_BNDS_NORM

     ERR_BNDS_NORM is REAL array, dimension (NRHS, N_ERR_BNDS)
     For each right-hand side, this array contains information about
     various error bounds and condition numbers corresponding to the
     normwise relative error, which is defined as follows:
     Normwise relative error in the ith solution vector:
                       norm(XTRUE(i) - X(i))
                -------------------------------------
                        norm(X(i))
     The array is indexed by the right-hand side i (on which the
     normwise relative error depends), and the type of error
     information as described below. There currently are up to three
     pieces of information returned for each right-hand side. If
     normwise accuracy is not requested (JOB = 'N'), then
     ERR_BNDS_NORM is not accessed. If N_ERR_BNDS < 3, then at most
     the first (:,N_ERR_BNDS) entries are returned.
     The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
     right-hand side.
     The second index in ERR_BNDS_NORM(:,err) contains the following
     three fields:
     err = 1  boolean. Trust the answer if the
              reciprocal condition number is less than the threshold
              sqrt(n) * slamch('Epsilon').
     err = 2  error bound: The estimated forward error,
              almost certainly within a factor of 10 of the true error
              so long as the next entry is greater than the threshold
              sqrt(n) * slamch('Epsilon'). This error bound should only
              be trusted if the previous boolean is true.
     err = 3  Reciprocal condition number: Estimated normwise
              reciprocal condition number.  Compared with the threshold
              sqrt(n) * slamch('Epsilon') to determine if the error
              estimate is . These reciprocal condition
              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
              appropriately scaled matrix Z.
              Let Z = S*A, where S scales each row by a power of the
              radix so all absolute row sums of Z are approximately 1.
     See Lapack Working Note 165 for further details and extra
     cautions.

ERR_BNDS_COMP

     ERR_BNDS_COMP is REAL array, dimension (NRHS, N_ERR_BNDS)
     For each right-hand side, this array contains information about
     various error bounds and condition numbers corresponding to the
     componentwise relative error, which is defined as follows:
     Componentwise relative error in the ith solution vector:
                    abs(XTRUE(j,i) - X(j,i))
             max_j ----------------------
                         abs(X(j,i))
     The array is indexed by the right-hand side i (on which the
     componentwise relative error depends), and the type of error
     information as described below. There currently are up to three
     pieces of information returned for each right-hand side. If
     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
     the first (:,N_ERR_BNDS) entries are returned.
     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
     right-hand side.
     The second index in ERR_BNDS_COMP(:,err) contains the following
     three fields:
     err = 1  boolean. Trust the answer if the
              reciprocal condition number is less than the threshold
              sqrt(n) * slamch('Epsilon').
     err = 2  error bound: The estimated forward error,
              almost certainly within a factor of 10 of the true error
              so long as the next entry is greater than the threshold
              sqrt(n) * slamch('Epsilon'). This error bound should only
              be trusted if the previous boolean is true.
     err = 3  Reciprocal condition number: Estimated componentwise
              reciprocal condition number.  Compared with the threshold
              sqrt(n) * slamch('Epsilon') to determine if the error
              estimate is . These reciprocal condition
              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
              appropriately scaled matrix Z.
              Let Z = S*(A*diag(x)), where x is the solution for the
              current right-hand side and S scales each row of
              A*diag(x) by a power of the radix so all absolute row
              sums of Z are approximately 1.
     See Lapack Working Note 165 for further details and extra
     cautions.

NPARAMS

     NPARAMS is INTEGER
     Specifies the number of parameters set in PARAMS.  If <= 0, the
     PARAMS array is never referenced and default values are used.

PARAMS

     PARAMS is REAL array, dimension NPARAMS
     Specifies algorithm parameters.  If an entry is < 0.0, then
     that entry will be filled with default value used for that
     parameter.  Only positions up to NPARAMS are accessed; defaults
     are used for higher-numbered parameters.
       PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
            refinement or not.
         Default: 1.0
            = 0.0:  No refinement is performed, and no error bounds are
                    computed.
            = 1.0:  Use the double-precision refinement algorithm,
                    possibly with doubled-single computations if the
                    compilation environment does not support DOUBLE
                    PRECISION.
              (other values are reserved for future use)
       PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
            computations allowed for refinement.
         Default: 10
         Aggressive: Set to 100 to permit convergence using approximate
                     factorizations or factorizations other than LU. If
                     the factorization uses a technique other than
                     Gaussian elimination, the guarantees in
                     err_bnds_norm and err_bnds_comp may no longer be
                     trustworthy.
       PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
            will attempt to find a solution with small componentwise
            relative error in the double-precision algorithm.  Positive
            is true, 0.0 is false.
         Default: 1.0 (attempt componentwise convergence)

WORK

     WORK is REAL array, dimension (4*N)

IWORK

     IWORK is INTEGER array, dimension (N)

INFO

     INFO is INTEGER
       = 0:  Successful exit. The solution to every right-hand side is
         guaranteed.
       < 0:  If INFO = -i, the i-th argument had an illegal value
       > 0 and <= N:  U(INFO,INFO) is exactly zero.  The factorization
         has been completed, but the factor U is exactly singular, so
         the solution and error bounds could not be computed. RCOND = 0
         is returned.
       = N+J: The solution corresponding to the Jth right-hand side is
         not guaranteed. The solutions corresponding to other right-
         hand sides K with K > J may not be guaranteed as well, but
         only the first such right-hand side is reported. If a small
         componentwise error is not requested (PARAMS(3) = 0.0) then
         the Jth right-hand side is the first with a normwise error
         bound that is not guaranteed (the smallest J such
         that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
         the Jth right-hand side is the first with either a normwise or
         componentwise error bound that is not guaranteed (the smallest
         J such that either ERR_BNDS_NORM(J,1) = 0.0 or
         ERR_BNDS_COMP(J,1) = 0.0). See the definition of
         ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
         about all of the right-hand sides check ERR_BNDS_NORM or
         ERR_BNDS_COMP.
