subrutina spstf2 (uplo, n, a, lda, piv, rank, tol, work, info)


SPSTF2 calcula la factorización de Cholesky con pivoteo completo de una matriz real simétrica semidefinida positiva.

Documentación de Función/Subrutina

subrutina spstf2 (character uplo, integer n, real, dimension( lda, * ) a, integer lda, integer, dimension( n ) piv, integer rank, real tol, real, dimension( 2*n ) work, integer info)

SPSTF2 calcula la factorización de Cholesky con pivoteo completo de una matriz real simétrica semidefinida positiva.

Propósito:

!>
!> SPSTF2 calcula la factorización de Cholesky con pivoteo completo
!> de una matriz real simétrica semidefinida positiva A.
!>
!> La factorización tiene la forma
!>    P**T * A * P = U**T * U ,  si UPLO = 'U',
!>    P**T * A * P = L  * L**T,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es triangular inferior, y
!> P se almacena como el vector PIV.
!>
!> Este algoritmo no intenta verificar que A es semidefinida positiva.
!> Esta versión del algoritmo llama a BLAS de nivel 2.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          A la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular de n por n contenida en A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia.  Si UPLO = 'L', la
!>          parte inferior triangular de n por n contenida en A contiene la
!>          parte triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>
!>          A la salida, si INFO = 0, el factor U o L de la factorización de
!>          Cholesky como se describió anteriormente.
!>

PIV

!>          PIV es array INTEGER, dimension (N)
!>          PIV es tal que las entradas distintas de cero son P( PIV(K), K ) = 1.
!>

RANK

!>          RANK es INTEGER
!>          El rango de A dado por el número de pasos que completó el algoritmo.
!>

TOL

!>          TOL es REAL
!>          Tolerancia definida por el usuario. Si TOL < 0, se usará
!>          N*U*MAX( A( K,K ) ). El algoritmo termina en el paso (K-1)
!>          si el pivote <= TOL.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

WORK

!>          WORK es array REAL, dimension (2*N)
!>          Espacio de trabajo.
!>

INFO

!>          INFO es INTEGER
!>          < 0: Si INFO = -K, el K-ésimo argumento tuvo un valor ilegal.
!>          = 0: el algoritmo se completó con éxito.
!>          > 0: la matriz A es deficiente en rango con rango calculado
!>               como se devuelve en RANK, o no es semidefinida positiva.
!>               Consulte la Sección 7 de la Nota de Trabajo #161 de LAPACK
!>               para obtener más información.
!>
