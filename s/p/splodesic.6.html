NOMBRE

splodesic - Una esfera geodésica experimenta una serie de erupciones.

SINOPSIS

splodesic [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id número] [--no-wander] [--no-spin] [--fps] [--delay número] [--speed número] [--depth número]

DESCRIPCIÓN

Una esfera geodésica experimenta una serie de erupciones.

OPCIONES

--visual visual
Especifica qué visual usar. Los valores permitidos son el nombre de una clase visual o el número de identificación (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--wander | --no-wander
Si el objeto debe deambular por la pantalla.
--spin | --no-spin
Si el objeto debe girar.
--fps | --no-fps
Si se debe mostrar un contador de fotogramas por segundo en la parte inferior de la pantalla.
--delay número
Retraso por fotograma, en microsegundos. Predeterminado: 30000 (0.03 segundos).
--speed número
Frecuencia de las erupciones. 2.0 significa el doble de frecuente, 0.5 significa la mitad de frecuente.
--depth número
Profundidad (frecuencia) de la geodésica. 0 - 5. Predeterminado: 4.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
