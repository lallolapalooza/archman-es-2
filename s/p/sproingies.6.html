sproingies(6) Manual de XScreenSaver sproingies(6)

NOMBRE

sproingies - ¡Q-Bert se encuentra con Marble Madness!

SINOPSIS

sproingies [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id número] [--count número] [--delay número] [--size número] [--no-fall] [--wireframe] [--fps]

DESCRIPCIÓN

¡Q-Bert se encuentra con Marble Madness!

OPCIONES

--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de ID (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--count número
Cuántos sproingies dibujar a la vez. Valor predeterminado: 5.
--delay número
Retraso por fotograma, en microsegundos. Valor predeterminado: 25000 (0.03 segundos).
--size número
Cuánto escalar la imagen. Valor predeterminado 0 (pantalla completa).
--no-fall
Hacer que los sproingies sean "inteligentes", para que no se caigan por el borde.
--wireframe
Renderizar en modo alambre en lugar de sólido.
--fps
Muestra la tasa de fotogramas actual, la carga de la CPU y el número de polígonos.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
