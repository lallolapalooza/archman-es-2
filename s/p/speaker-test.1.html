SPEAKER-TEST(1) Manual de comandos generales SPEAKER-TEST(1)

NOMBRE

speaker-test - generador de tono de prueba de altavoces por línea de comandos para ALSA

SINOPSIS

speaker-test [-opciones]

DESCRIPCIÓN

speaker-test genera un tono que puede usarse para probar los altavoces de un ordenador.

Por defecto, speaker-test probará el dispositivo *predeterminado*. Si deseas probar otro dispositivo de sonido, primero deberás obtener una lista de todas las tarjetas de sonido de tu sistema y los dispositivos asociados a esas tarjetas. Ten en cuenta que puede haber, por ejemplo, un dispositivo para sonido analógico, uno para sonido digital y uno para sonido HDMI. Para obtener la lista de tarjetas y dispositivos disponibles, puedes ejecutar aplay -L.

$ aplay -L
null
    Descarta todas las muestras (reproducción) o genera muestras cero (captura)
default:CARD=ICH5
    Intel ICH5, Intel ICH5
    Dispositivo de audio predeterminado
front:CARD=ICH5,DEV=0
    Intel ICH5, Intel ICH5
    Altavoces frontales
surround40:CARD=ICH5,DEV=0
    Intel ICH5, Intel ICH5
    Salida envolvente 4.0 a altavoces frontales y traseros
(...)

En el ejemplo anterior, hay cuatro dispositivos listados: null, default, front y surround40. Por lo tanto, si deseas probar el último dispositivo, puedes ejecutar speaker-test -Dsurround40:ICH5 -c 6. La opción -c indicará que los seis canales de audio del dispositivo deben ser probados.

OPCIONES

-c | --channels NUM
NUM canales en la transmisión
-D | --device NOMBRE
Nombre del dispositivo PCM NOMBRE
-f | --frequency FREQ
onda sinusoidal de FREQ Hz
--help
Imprimir ayuda de uso
-b | --buffer TIEMPO
Usar un tamaño de búfer de TIEMPO microsegundos. Si se proporciona 0, se usa el tamaño máximo del búfer. El valor predeterminado es 0.
-p | --period TIEMPO
Usar un tamaño de período de TIEMPO microsegundos. Si se proporciona 0, se usa el número de períodos dado por la opción -P. El valor predeterminado es 0.
-P | --nperiods PERIODOS
Usar número de períodos. El valor predeterminado es 4.
-r | --rate TAZA
transmisión de TAZA Hz
-t | --test pink|st2095|sine|wav
-t pink significa usar ruido rosa (predeterminado).

El ruido rosa es ruido perceptualmente uniforme; es decir, suena a todas las frecuencias a la vez. Si puedes escuchar algún tono, puede indicar resonancias en tu sistema de altavoces o habitación.

-t st2095 significa usar ruido rosa con banda limitada a -18.5dB AES FS, generado según SMPTE ST-2095:1-2015. Además de la localización de altavoces, puede usarse para la calibración del sistema, por ejemplo, 85dB para drivers de cine, con un +10dB adicional para subwoofers. Según la especificación, está destinado "a ser utilizado en la calibración del nivel de presión sonora y la respuesta electroacústica de un sistema de cadena B de cine". Ten en cuenta que las frecuencias de muestreo inferiores a 48 KHz están fuera del alcance de la especificación, y se intentará construir un filtro de frecuencia reducida.

-t sine significa usar onda sinusoidal.

-t wav significa reproducir archivos WAV, ya sean archivos predefinidos o proporcionados a través de la opción -w.

Puedes pasar el número del 1 al 3 como compatibilidad hacia atrás.

-l | --nloops CUENTA

Especifica el número de bucles. Cero significa ejecutar infinitamente.

Cuando se proporciona la opción -s con un canal válido, speaker-test realizará siempre un solo disparo sin bucle.

-s | --speaker CANAL
Realiza una prueba de altavoz de un solo disparo para el canal dado. El número de canal comienza en 1. El número de canal corresponde a izquierda, derecha, trasera-izquierda, trasera-derecha, centro, LFE, lateral-izquierda, lateral-derecha, etc.

Por ejemplo, cuando se pasa 1, prueba solo el canal izquierdo una vez en lugar de ambos canales con bucle.

-w | --wavfile ARCHIVO
Utiliza el archivo WAV dado para la reproducción en lugar de los archivos WAV predefinidos.
-W | --wavdir DIRECTORIO
Especifica el directorio que contiene los archivos WAV para la reproducción. La ruta predeterminada es /usr/share/sounds/alsa.
-m | --chmap MAPA
Pasa el mapa de canales para anular. Si se requiere la reproducción en un orden de canal o posiciones de canal específicas, pasa las cadenas de posición de canal a esta opción.
-X | --force-frequency
Permite que la FREQ proporcionada esté fuera del rango predeterminado de 30-8000Hz. Todavía se aplica un mínimo de 1Hz.

EJEMPLOS DE USO

Produce sonido estéreo desde un conector estéreo:

  speaker-test -Dplug:front -c2

Produce sonido para 4 altavoces desde dos conectores estéreo:

  speaker-test -Dplug:surround40 -c4

Produce sonido para altavoces 5.1 desde tres conectores estéreo:

  speaker-test -Dplug:surround51 -c6

Para enviar un tono agradable y grave de 75Hz al Woofer y luego salir sin tocar ningún otro altavoz:

  speaker-test -Dplug:surround51 -c6 -s1 -f75

Para hacer una prueba de altavoces 2.1 usando la salida spdif (coaxial u óptica):

  speaker-test -Dplug:spdif -c2

Reproducir en el orden de frontal-derecho y frontal-izquierdo desde el PCM frontal

  speaker-test -Dplug:front -c2 -mFR,FL
