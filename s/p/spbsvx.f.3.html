subroutine spbsvx (character fact, character uplo, integer n, integer kd, integer nrhs, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldafb, * ) afb, integer ldafb, character equed, real, dimension( * ) s, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SPBSVX calcula la solución del sistema de ecuaciones lineales A * X = B para otras matrices

Propósito:

!>
!> SPBSVX utiliza la factorización de Cholesky A = U**T*U o A = L*L**T para
!> calcular la solución de un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz de banda simétrica positiva definida de NxN y X
!> e B son matrices de NxNRHS.
!>
!> También se proporcionan cotas de error en la solución y una estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Si el sistema se equilibrará o no depende del
!>    escalado de la matriz A, pero si se utiliza el equilibrado, A se
!>    sobrescribe con diag(S)*A*diag(S) y B con diag(S)*B.
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**T * U,  si UPLO = 'U', o
!>       A = L * L**T,  si UPLO = 'L',
!>    donde U es una matriz de banda triangular superior y L es una matriz de banda triangular inferior.
!>
!> 3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina retorna con INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz
!>    A.  Si el recíproco del número de condición es menor que la precisión de la máquina,
!>    se retorna INFO = N+1 como una advertencia, pero la rutina
!>    continúa resolviendo para X y calculando cotas de error como
!>    se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    matriz y calcular cotas de error y estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes
!>    del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          proporciona o no en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AFB contiene la forma factorizada de A.
!>                  Si EQUED = 'Y', la matriz A ha sido equilibrada
!>                  con factores de escala dados por S.  AB y AFB no
!>                  serán modificados.
!>          = 'N':  La matriz A se copiará a AFB y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará a AFB y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es array REAL, dimension (LDAB,N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda simétrica
!>          A, almacenado en las primeras KD+1 filas del array, excepto
!>          si FACT = 'F' y EQUED = 'Y', entonces A debe contener la
!>          matriz equilibrada diag(S)*A*diag(S).  La j-ésima columna de A
!>          se almacena en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) para max(1,j-KD)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(N,j+KD).
!>          Ver más abajo para más detalles.
!>
!>          En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>          diag(S)*A*diag(S).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array A.  LDAB >= KD+1.
!>

AFB

!>          AFB es array REAL, dimension (LDAFB,N)
!>          Si FACT = 'F', entonces AFB es un argumento de entrada y en la entrada
!>          contiene el factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T de la matriz de banda
!>          A, en el mismo formato de almacenamiento que A (ver AB). Si EQUED = 'Y',
!>          entonces AFB es la forma factorizada de la matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AFB es un argumento de salida y en la salida
!>          retorna el factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T.
!>
!>          Si FACT = 'E', entonces AFB es un argumento de salida y en la salida
!>          retorna el factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T de la matriz A equilibrada
!>          (ver la descripción de A para la forma de la
!>          matriz equilibrada).
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal del array AFB.  LDAFB >= KD+1.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'Y':  Se realizó equilibrado, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

S

!>          S es array REAL, dimension (N)
!>          Los factores de escala para A; no se accede si EQUED = 'N'.  S es
!>          un argumento de entrada si FACT = 'F'; de lo contrario, S es un argumento
!>          de salida.  Si FACT = 'F' y EQUED = 'Y', cada elemento de S
!>          debe ser positivo.
!>

B

!>          B es array REAL, dimension (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B de NxNRHS.
!>          En la salida, si EQUED = 'N', B no se modifica; si EQUED = 'Y',
!>          B se sobrescribe con diag(S) * B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array REAL, dimension (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de NxNRHS para
!>          el sistema original de ecuaciones.  Tenga en cuenta que si EQUED = 'Y',
!>          A y B se modifican en la salida, y la solución del
!>          sistema equilibrado es inv(diag(S))*X.
!>

NAME


spbsvx


solve a real symmetric positive definite banded system of linear
    equations with error bounding and iterative refinement






SYNOPSIS


SUBROUTINE SPBSVX(
     FACT, UPLO, N, KD, NRHS, AB, LDAB, B, LDB, X, LDX, RCOND, FERR,
     BERR, WORK, IWORK, INFO
    )

    LOGICAL FACT
    CHARACTER UPLO
    INTEGER N, KD, NRHS, LDAB, LDB, LDX, INFO
    REAL AB( LDAB, * ), B( LDB, * ), X( LDX, * ), RCOND, FERR( * ),
         BERR( * ), WORK( * )
    INTEGER IWORK( * )







Function/Subroutine Documentation


SPBSVX uses the diagonal pivoting Cholesky factorization to
    compute the solution to a set of linear equations ABX = B for a symmetric
    positive definite banded matrix A.


SPBSVX is the real version for FEBRUARY matrices.


Arguments




FACT


CHARACTER


Specifies whether or not the factorization of the matrix A
        is supplied.


Possible values:




'F'


On entry, FACT = 'F' means that the factorization of A is supplied
            on the array AB. The routine SPBSVX will not recompute the
            factorization.


'N'


On entry, FACT = 'N' means that the factorization of A will be
            computed by the routine.






UPLO


CHARACTER


Specifies whether the upper or lower triangular part of the
        band matrix A is stored. Possible values:




'U'


Specifies that A is upper triangular. Only the upper triangle of
            the matrix is needed.


'L'


Specifies that A is lower triangular. Only the lower triangle of
            the matrix is needed.






N


INTEGER


The order of the matrix A. The number of rows and columns in the
        band matrix A.


N >= 0.




KD


INTEGER


The number of super-diagonals and sub-diagonals of the band
        matrix A.


0 <= KD < N.




NRHS


INTEGER


The number of right-hand sides, i.e. the number of columns of the
        matrices B and X.


NRHS >= 0.




AB


REAL array, dimension (LDAB,*)


The factorized band matrix A, stored in band format.
        The dimensions of AB are (LDAB, N) if FACT = 'F', and (LDAB, N)
        if FACT = 'N'.


If UPLO = 'U', AB(kd+1,j) contains the element A(j,j) and
        AB(kd+1-i,j) contains the element A(j-i,j) for 1 <= i <= kd.


If UPLO = 'L', AB(1,j) contains the element A(j,j) and
        AB(i,j) contains the element A(i,j) for kd+1 <= i <= N.


If FACT = 'N', AB is used to store the factored matrix U (or L)
        from the Cholesky factorization A = U**T * D * U (or A = L * D * L**T).




LDAB


INTEGER


The leading dimension of the array AB. LDAB >= kd + 1.




B


REAL array, dimension (LDB, NRHS)


The right-hand side matrix of size N x NRHS.




LDB


INTEGER


The leading dimension of the array B. LDB >= max(1,N).




X


REAL array, dimension (LDX, NRHS)


On exit, the solution matrix of size N x NRHS.




LDX


INTEGER


The leading dimension of the array X. LDX >= max(1,N).




RCOND


REAL


The estimate of the reciprocal condition number of the matrix
        A after equilibration (if done). If RCOND is less than the
        machine precision (in particular, if RCOND = 0), the matrix
        is singular to working precision. This condition is
        indicated by a return code of INFO > 0.




FERR


REAL array, dimension (NRHS)


The estimated forward error bound for each solution vector
        X(j) (the j-th column of the solution matrix X). If XTRUE is the true solution corresponding to X(j), FERR(j)
        is an estimated upper bound for the magnitude of the largest
        element in (X(j) - XTRUE) divided by the magnitude of the
        largest element in X(j). The estimate is as reliable as
        the estimate for RCOND, and is almost always a slight
        overestimate of the true error.




BERR


REAL array, dimension (NRHS)


The componentwise relative backward error of each solution
        vector X(j) (i.e., the smallest relative change in
        any element of A or B that makes X(j) an exact solution).




WORK


REAL array, dimension (3*N)




IWORK


INTEGER array, dimension (N)




INFO


INTEGER


= 0: successful exit


< 0: if INFO = -i, the i-th argument had an illegal value


> 0: if INFO = i, and i is


<= N: the leading principal minor of order i of A
        is not positive, so the factorization could not
        be completed, and the solution has not been
        computed. RCOND = 0 is returned.


= N+1: U is nonsingular, but RCOND is less than machine
        precision, meaning that the matrix is singular
        to working precision. Nevertheless, the
        solution and error bounds are computed because
        there are a number of situations where the
        computed solution can be more accurate than the
        value of RCOND would suggest.

Further Details:




The band storage scheme is illustrated by the following example, when
N = 6, KD = 2, and UPLO = 'U':

Two-dimensional storage of the symmetric matrix A:

   a11  a12  a13
        a22  a23  a24
             a33  a34  a35
                  a44  a45  a46
                       a55  a56
(aij=conjg(aji))         a66

Band storage of the upper triangle of A:

   *    *   a13  a24  a35  a46
   *   a12  a23  a34  a45  a56
  a11  a22  a33  a44  a55  a66

Similarly, if UPLO = 'L' the format of A is as follows:

  a11  a22  a33  a44  a55  a66
  a21  a32  a43  a54  a65   *
  a31  a42  a53  a64   *    *

Array elements marked * are not used by the routine.
