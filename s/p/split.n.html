Paquete: tcl

split(n) Comandos integrados de Tcl split(n)

NOMBRE

split - Dividir una cadena en una lista Tcl adecuada

SINOPSIS

split cadena ?caracteresDeDivision?

DESCRIPCIÓN

Devuelve una lista creada dividiendo cadena en cada carácter que se encuentre en el argumento caracteresDeDivision. Cada elemento de la lista resultante consistirá en los caracteres de cadena que se encuentren entre las instancias de los caracteres de caracteresDeDivision. Se generarán elementos de lista vacíos si cadena contiene caracteres adyacentes en caracteresDeDivision, o si el primer o último carácter de cadena está en caracteresDeDivision. Si caracteresDeDivision es una cadena vacía, cada carácter de cadena se convierte en un elemento separado de la lista resultante. CaracteresDeDivision usa por defecto los caracteres de espacio en blanco estándar.

EJEMPLOS

Dividir un nombre de grupo de USENET en sus componentes jerárquicos:

split "comp.lang.tcl" .
      → comp lang tcl

Ver cómo el comando split divide en *cada* carácter de caracteresDeDivision, lo que puede resultar en pérdida de información si no se tiene cuidado:

split "alpha beta gamma" "temp"
      → al {ha b} {} {a ga} {} a

Extraer las palabras de una lista de una cadena que no es una lista bien formada:

split "Ejemplo con {llave de desequilibrio de carácter"
      → Ejemplo con \{llave de desequilibrio de carácter

Dividir una cadena en sus caracteres constituyentes

split "Hola mundo" {}
      → H o l a { } m u n d o

ANÁLISIS DE ARCHIVOS ORIENTADOS A REGISTROS

Analizar un archivo Unix /etc/passwd, que consiste en una entrada por línea, y cada línea consta de una lista de campos separados por dos puntos:

## Leer el archivo
set fid [open /etc/passwd]
set content [read $fid]
close $fid
## Dividir en registros por saltos de línea
set records [split $content "\n"]
## Iterar sobre los registros
foreach rec $records {
    ## Dividir en campos por dos puntos
    set fields [split $rec ":"]
    ## Asignar campos a variables e imprimir algunos...
    lassign $fields \
            nombreUsuario contraseña uid grupo nombreLargo directorioInicio shell
    puts "$nombreLargo usa [file tail $shell] como shell de inicio de sesión"
}
