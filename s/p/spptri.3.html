subrutina spptri (carácter uplo, entero n, real, dimensión( * ) ap, entero info)

SPPTRI

Propósito:

!>
!> SPPTRI calcula la inversa de una matriz simétrica definida positiva real A
!> utilizando la factorización de Cholesky A = U**T*U o A = L*L**T
!> calculada por SPPTRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El factor triangular superior se almacena en AP;
!>          = 'L':  El factor triangular inferior se almacena en AP.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es array REAL, dimensión (N*(N+1)/2)
!>          En la entrada, el factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T, empaquetado por columnas como
!>          un array lineal. La j-ésima columna de U o L se almacena en el
!>          array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) para j<=i<=n.
!>
!>          En la salida, la parte triangular superior o inferior de la inversa
!>          (simétrica) de A, sobrescribiendo el factor de entrada U o L.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el elemento (i,i) del factor U o L es
!>                cero, y la inversa no pudo ser calculada.
!>
