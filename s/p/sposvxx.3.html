SPOSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PO

Propósito:

!>
!>    SPOSVXX utiliza la factorización de Cholesky A = U**T*U o A = L*L**T
!>    para calcular la solución a un sistema real de ecuaciones lineales
!>    A * X = B, donde A es una matriz simétrica definida positiva de N por N
!>    y X y B son matrices de N por NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normativos como de
!>    componente máximo. SPOSVXX devolverá una solución con un error garantizado
!>    diminuto (O(eps) donde eps es la precisión de la máquina de trabajo) a
!>    menos que la matriz esté muy mal condicionada, en cuyo caso se devuelve
!>    una advertencia. También se calculan y devuelven los números de condición
!>    relevantes.
!>
!>    SPOSVXX acepta factorizaciones y factores de ecualización proporcionados
!>    por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada anterior
!>    a SPOSVXX también producirá una solución con errores de O(eps) o
!>    advertencias, pero no podemos hacer esa afirmación para factorizaciones
!>    y factores de ecualización proporcionados por el usuario en general si
!>    difieren de lo que SPOSVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para ecualizar
!>    el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Dependiendo de si el sistema se ecualizará o no, dependerá del
!>    escalado de la matriz A, pero si se usa la ecualización, A se
!>    sobrescribe con diag(S)*A*diag(S) y B con diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después de la ecualización si FACT = 'E') como
!>       A = U**T* U,  si UPLO = 'U', o
!>       A = L * L**T,  si UPLO = 'L',
!>    donde U es una matriz triangular superior y L es una matriz triangular
!>    inferior.
!>
!>    3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina devuelve INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz
!>    A (ver argumento RCOND). Si la inversa del número de condición
!>    es menor que la precisión de la máquina, la rutina continúa resolviendo
!>    para X y calculando límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la rutina utilizará refinamiento iterativo para intentar obtener un error
!>    y límites de error pequeños. El refinamiento calcula el residuo con
!>    al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó la ecualización, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes de
!>    la ecualización.
!> 
!>     Algunos parámetros opcionales se agrupan en la matriz PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados
!>     son aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que
!>     el código fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona en la entrada, y si no, si la matriz A debe ser
!>     ecualizada antes de ser factorizada.
!>       = 'F':  En la entrada, AF contiene la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               ecualizada con factores de escala dados por S.
!>               A y AF no se modifican.
!>       = 'N':  La matriz A se copiará en AF y se factorizará.
!>       = 'E':  La matriz A se ecualizará si es necesario, luego
!>               se copiará en AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>     En la entrada, la matriz simétrica A, excepto si FACT = 'F' y EQUED =
!>     'Y', entonces A debe contener la matriz ecualizada
!>     diag(S)*A*diag(S).  Si UPLO = 'U', la parte superior triangular N por N
!>     de A contiene la parte triangular superior de la
!>     matriz A, y la parte estrictamente triangular inferior de A no se
!>     referencia. Si UPLO = 'L', la parte inferior triangular N por N
!>     de A contiene la parte triangular inferior de la matriz A, y
!>     la parte estrictamente triangular superior de A no se referencia.
!>     A no se modifica si FACT = 'F' o 'N', o si FACT = 'E' y EQUED =
!>     'N' en la salida.
!>
!>     En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array REAL, dimension (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene el factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, en el mismo formato de almacenamiento
!>     que A. Si EQUED .ne. 'N', entonces AF es la forma factorizada
!>     de la matriz ecualizada diag(S)*A*diag(S).
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>     devuelve el factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T de la matriz original
!>     A.
!>
!>     Si FACT = 'E', entonces AF es un argumento de salida y en la salida
!>     devuelve el factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T de la matriz ecualizada
!>     A (consulte la descripción de A para conocer la forma de la
!>     matriz ecualizada).
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de ecualización que se realizó.
!>       = 'N':  Sin ecualización (siempre verdadero si FACT = 'N').
!>       = 'Y':  Tanto la ecualización de filas como la de columnas

Function/Subroutine Documentation

SPOSVXX uses the Left Plus Right (LPR) factorization to compute the solution to a set of linear equations A*X = B, where A is a symmetric positive definite matrix.

LPR factorization is a block factorization which is numerically stable and works for a wider range of matrices than LU or Cholesky factorization.
