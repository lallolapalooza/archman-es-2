Documentación de la Función/Subrutina

subroutine spocon (character uplo, integer n, real, dimension( lda, * ) a, integer lda, real anorm, real rcond, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SPOCON

Propósito:

!>
!> SPOCON estima el recíproco del número de condición (en la
!> norma 1) de una matriz real simétrica definida positiva utilizando la
!> factorización de Cholesky A = U**T*U o A = L*L**T calculada por SPOTRF.
!>
!> Se obtiene una estimación de norm(inv(A)), y se calcula el recíproco del
!> número de condición como RCOND = 1 / (ANORM * norm(inv(A))).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T, tal como se calcula por SPOTRF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

ANORM

!>          ANORM es REAL
!>          La norma 1 (o norma infinito) de la matriz simétrica A.
!>

RCOND

!>          RCOND es REAL
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es un array REAL, de dimensión (3*N)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
