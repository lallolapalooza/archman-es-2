subroutine sppsvx (character fact, character uplo, integer n, integer nrhs, real, dimension( * ) ap, real, dimension( * ) afp, character equed, real, dimension( * ) s, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SPPSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices OTRAS

Propósito:

!>
!> SPPSVX utiliza la factorización de Cholesky A = U**T*U o A = L*L**T para
!> calcular la solución a un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz simétrica definida positiva de N por N almacenada en
!> formato empaquetado y X y B son matrices de N por NRHS.
!>
!> También se proporcionan cotas de error en la solución y una estimación de
!> la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Si el sistema se equilibrará o no depende de la
!>    escalada de la matriz A, pero si se utiliza el equilibrado, A se
!>    sobrescribe con diag(S)*A*diag(S) y B con diag(S)*B.
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**T* U,  si UPLO = 'U', o
!>       A = L * L**T,  si UPLO = 'L',
!>    donde U es una matriz triangular superior y L es una matriz triangular
!>    inferior.
!>
!> 3. Si el menor principal principal de orden i no es positivo,
!>    entonces la subrutina retorna con INFO = i. De lo contrario, la forma
!>    factorizada de A se utiliza para estimar el número de condición de la
!>    matriz A. Si el recíproco del número de condición es menor que la
!>    precisión de la máquina, se retorna INFO = N+1 como advertencia, pero
!>    la subrutina aún procede a resolver para X y calcular cotas de error
!>    como se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular cotas de error y estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes de
!>    el equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          suministra en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AFP contiene la forma factorizada de A.
!>                  Si EQUED = 'Y', la matriz A ha sido equilibrada
!>                  con factores de escala dados por S. AP y AFP no
!>                  se modificarán.
!>          = 'N':  La matriz A se copiará en AFP y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AFP y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es array REAL, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          simétrica A, empaquetado columna a columna en un array lineal,
!>          excepto si FACT = 'F' y EQUED = 'Y', entonces A debe contener
!>          la matriz equilibrada diag(S)*A*diag(S). La j-ésima columna de A
!>          se almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver detalles más abajo. A no se modifica si
!>          FACT = 'F' o 'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>          En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>          diag(S)*A*diag(S).
!>

AFP

!>          AFP es array REAL, dimensión (N*(N+1)/2)
!>          Si FACT = 'F', entonces AFP es un argumento de entrada y en la
!>          entrada contiene el factor triangular U o L de la
!>          factorización de Cholesky A = U**T*U o A = L*L**T, en el mismo
!>          formato de almacenamiento que A. Si EQUED .ne. 'N', entonces AFP
!>          es la forma factorizada de la matriz equilibrada A.
!>
!>          Si FACT = 'N', entonces AFP es un argumento de salida y en la
!>          salida devuelve el factor triangular U o L de la
!>          factorización de Cholesky A = U**T * U o A = L * L**T de la
!>          matriz original A.
!>
!>          Si FACT = 'E', entonces AFP es un argumento de salida y en la
!>          salida devuelve el factor triangular U o L de la
!>          factorización de Cholesky A = U**T * U o A = L * L**T de la
!>          matriz equilibrada A (ver la descripción de AP para la forma de la
!>          matriz equilibrada).
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'Y':  Se realizó el equilibrado, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario,
!>          es un argumento de salida.
!>

S

!>          S es array REAL, dimensión (N)
!>          Los factores de escala para A; no se accede si EQUED = 'N'. S es
!>          un argumento de entrada si FACT = 'F'; de lo contrario, S es un
!>          argumento de salida. Si FACT = 'F' y EQUED = 'Y', cada elemento de S
!>          debe ser positivo.
!>

B

!>          B es array REAL, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho de N por NRHS.
!>          En la salida, si EQUED = 'N', B no se modifica; si EQUED = 'Y',
!>          B se sobrescribe con diag(S) * B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array REAL, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS
!>          al sistema original de ecuaciones.  Tenga en cuenta que si EQUED = 'Y',
!>          A y B se modifican en la salida, y la solución al
!>          sistema equilibrado es inv(diag(S))*X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La estimación del recíproco del número de condición de la matriz
!>          A después del equilibrado (si se realizó). Si RCOND es menor que la
!>          precisión de la máquina (en particular, si RCOND = 0), la matriz
!>          es singular con precisión de trabajo. Esta condición se
!>          indica con un código de retorno de INFO > 0.
!>

FERR

!>          FERR es REAL, dimensión (NRHS)
!>          El error estimado hacia atrás para cada columna de la solución
!>          en X, que se mide por el número de veces que se estima que la
!>          residual es mayor que la unidad.  Por ejemplo, si FERR(j) = 1+eps,
!>          entonces la norma de la residual de la solución
!>          de X(j) es aproximadamente igual a eps veces la norma de A(j)
!>          más la norma de B(j).
!>

BERR

!>          BERR es REAL, dimensión (NRHS)
!>          El error estimado hacia adelante para cada solución X(j), tal que
!>          norma(X(j) - X_tru(j)) / norma(X(j)) <= BERR(j), donde X_tru(j) es
!>          la solución verdadera.  Las cotas de error solo son confiables si
!>          la matriz A es bien condicionada o si el equilibrio se ha
!>          realizado (ver RCOND).
!>

WORK

!>          WORK es REAL array, dimensión (LRWORK)
!>          LWORK.  Si FACT = 'E', LRWORK >= max(2*N, N*N) y si
!>          FACT = 'N' ó 'F', LRWORK >= N.
!>          Routines that call this routine are very likely to want to use
!>          the optional dimension LRWORK in the call to them.
!>
!>          work es un array de trabajo.
!>

IWORK

!>          IWORK es INTEGER array, dimensión (N)
!>          work es un array de trabajo.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Ejecución correcta.
!>          > 0:  Si INFO = i y 1 <= i <= N, entonces la subrutina encontró que
!>                el i-ésimo menor principal principal de A era menor o igual
!>                que cero, por lo que la descomposición de Cholesky no se pudo
!>                continuar.
!>          = N+1: La matriz es singular a la precisión de trabajo. Se puede
!>                 calcular una solución, pero las cotas de error y la
!>                 estimación del número de condición no son confiables.
!>

!>          FERR es un array REAL, de dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan fiable como
!>          la estimación para RCOND, y es casi siempre un ligero
!>          sobrestimación del error verdadero.
!>

BERR

!>          BERR es un array REAL, de dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga de X(j) una solución exacta).
!>

WORK

!>          WORK es un array REAL, de dimensión (3*N)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, y i es
!>                <= N: el menor principal principal de orden i de A
!>                       no es positivo, por lo que la factorización no pudo
!>                       completarse y la solución no se ha
!>                       calculado. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión de la máquina,
!>                       lo que significa que la matriz es singular
!>                       para la precisión de trabajo. Sin embargo, la
!>                       solución y los límites de error se calculan porque
!>                       hay varias situaciones en las que la
!>                       solución calculada puede ser más precisa que el
!>                       valor de RCOND sugeriría.
!>
