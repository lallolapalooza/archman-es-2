Documentación de función/subrutina

subroutine spot01 (character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldafac, * ) afac, integer ldafac, real, dimension( * ) rwork, real resid)

SPOT01

Propósito:

!>
!> SPOT01 reconstruye una matriz definida positiva simétrica A a partir de
!> su factorización L*L' o U'*U y calcula el residuo
!>    norm( L*L' - A ) / ( N * norm(A) * EPS ) o
!>    norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> donde EPS es la epsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          La matriz simétrica original A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N)
!>

AFAC

!>          AFAC es un array REAL, dimensión (LDAFAC,N)
!>          En la entrada, el factor L o U de la factorización L * L**T o U**T * U
!>          de A.
!>          Sobreescrito con la matriz reconstruida y, a continuación, con
!>          la diferencia L * L**T - A (o U**T * U - A).
!>

LDAFAC

!>          LDAFAC es INTEGER
!>          La dimensión principal del array AFAC.  LDAFAC >= max(1,N).
!>

RWORK

!>          RWORK es un array REAL, dimensión (N)
!>

RESID

!>          RESID es REAL
!>          Si UPLO = 'L', norm(L * L**T - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U**T * U - A) / ( N * norm(A) * EPS )
!>
