speedtest-cli(1) Manual de Comandos Generales speedtest-cli(1)

NOMBRE

speedtest-cli - Interfaz de línea de comandos para probar el ancho de banda de Internet usando speedtest.net

SINOPSIS

speedtest-cli [OPCIÓN...]

DESCRIPCIÓN

Speedtest.net es un servicio web para probar tu conexión de banda ancha descargando un archivo de un servidor speedtest.net cercano en la web. Esta herramienta te permite acceder al servicio desde la línea de comandos.

Speedtest mini es una versión del servidor Speedtest.net que puedes alojar localmente.

OPCIONES

Uso: speedtest-cli [OPCIÓN...]

Opciones de Ayuda

-h, --help

Muestra el uso de la herramienta.

Opciones

--no-download

No realizar prueba de descarga

--no-upload

No realizar prueba de subida

--single

Usar solo una conexión en lugar de múltiples. Esto simula una transferencia de archivos típica.

--bytes

Mostrar valores en bytes en lugar de bits. No afecta la imagen generada por --share, ni la salida de --json o --csv

--share

Generar y proporcionar una URL a la imagen de resultados de speedtest.net, no se muestra con --csv

--simple

Suprimir salida detallada, solo mostrar información básica

--csv

Suprimir salida detallada, solo mostrar información básica en formato CSV. Velocidades listadas en bit/s y no afectadas por --bytes

--csv-delimiter CSV_DELIMITER

Delimitador de un solo carácter a usar en la salida CSV. Por defecto ","

--csv-header

Imprimir encabezados CSV

--json

Suprimir salida detallada, solo mostrar información básica en formato JSON. Velocidades listadas en bit/s y no afectadas por --bytes

--list

Mostrar una lista de servidores speedtest.net ordenados por distancia

--server SERVER

Especificar un ID de servidor para probar. Se puede suministrar varias veces

--exclude EXCLUDE

Excluir un servidor de la selección. Se puede suministrar varias veces

--mini MINI

URL del servidor Speedtest Mini

--source SOURCE

Dirección IP de origen a la que enlazarse

--timeout TIMEOUT

Tiempo de espera HTTP en segundos. Por defecto 10

--secure

Usar HTTPS en lugar de HTTP al comunicarse con servidores operados por speedtest.net

--no-pre-allocate

No preasignar datos de subida. La preasignación está habilitada por defecto para mejorar el rendimiento de la subida. Para sistemas con memoria insuficiente, usar esta opción para evitar un MemoryError

--version

Mostrar el número de versión y salir

EJEMPLOS

Encontrar automáticamente el servidor más cercano y comenzar las pruebas

speedtest-cli

Especificar pruebas contra el servidor 1491

speedtest-cli --server 1491

Pruebas contra Speedtest Mini

speedtest-cli --mini 172.18.66.1
