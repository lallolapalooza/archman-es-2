SPLIT(1) Comandos de usuario SPLIT(1)

NOMBRE

split - dividir un archivo en partes

SINOPSIS

split [OPCIÓN]... [ARCHIVO [PREFIJO]]

DESCRIPCIÓN

Genera fragmentos del ARCHIVO en PREFIXaa, PREFIXab, ...; el tamaño predeterminado es 1000 líneas y el prefijo predeterminado es 'x'.

Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar.

Los argumentos obligatorios para las opciones largas son también obligatorios para las opciones cortas.

-a, --suffix-length=N
genera sufijos de longitud N (predeterminado 2)
--additional-suffix=SUFIJO
añade un SUFIJO adicional a los nombres de archivo
-b, --bytes=TAMAÑO
pone TAMAÑO bytes por archivo de salida
-C, --line-bytes=TAMAÑO
pone como máximo TAMAÑO bytes de registros por archivo de salida
-d
usa sufijos numéricos empezando en 0, no alfabéticos
--numeric-suffixes[=DESDE]
igual que -d, pero permite establecer el valor inicial
-x
usa sufijos hexadecimales empezando en 0, no alfabéticos
--hex-suffixes[=DESDE]
igual que -x, pero permite establecer el valor inicial
-e, --elide-empty-files
no genera archivos de salida vacíos con '-n'
--filter=COMANDO
escribe al comando de shell COMANDO; el nombre del archivo es $FILE
-l, --lines=NÚMERO
pone NÚMERO de líneas/registros por archivo de salida
-n, --number=CHUNKS
genera CHUNKS archivos de salida; ver explicación abajo
-t, --separator=SEP
usa SEP en lugar de nueva línea como separador de registros; '\0' (cero) especifica el carácter NUL
-u, --unbuffered
copia inmediatamente la entrada a la salida con '-n r/...'
--verbose
imprime un diagnóstico justo antes de que se abra cada archivo de salida
--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale

El argumento TAMAÑO es un entero y unidad opcional (ejemplo: 10K es 10*1024). Las unidades son K,M,G,T,P,E,Z,Y,R,Q (potencias de 1024) o KB,MB,... (potencias de 1000). También se pueden usar prefijos binarios: KiB=K, MiB=M, y así sucesivamente.

CHUNKS puede ser:

N
divide en N archivos basándose en el tamaño de la entrada
K/N
salida del K-ésimo de N a la salida estándar
l/N
divide en N archivos sin dividir líneas/registros
l/K/N
salida del K-ésimo de N a la salida estándar sin dividir líneas/registros
r/N
similar a 'l' pero usa distribución aleatoria
r/K/N
similar pero solo saliendo el K-ésimo de N a la salida estándar

NAME

split - break a file into pieces

SYNOPSIS

split [OPTION]... [INPUT [OUTPUT]]

DESCRIPTION

Write each INPUT (or standard input if absent) to OUTPUT. Suffixes are added to form names of output files. If OUTPUT is not specified, it defaults to 'x'. If INPUT is not specified, standard input is used.

By default, each file is 1000 lines. See SIZE below.

Mandatory arguments are long only.

OPTIONS

-a, --suffix-length=N use suffixes of length N (default 2)

-b, --bytes=SIZE create smaller files of SIZE bytes

-C, --line-bytes=SIZE create smaller files of SIZE bytes each, but try to pack the last file of each line

-d, --numeric-suffixes[=FROM] use numeric suffixes starting at FROM (default 0)

-e, --electronic-suffix append '.' followed by a hex digit to suffixes

-f, --force output even if the input file is empty

-l, --lines=NUMBER create smaller files with NUMBER lines each

-m, --multiple-file-group write all output files to the same directory

-p, --separator=RE use RE to find split points

-t, --tape-length=SIZE create smaller files of SIZE bytes; like -b but do not align reads to block boundaries

--help display this help and exit

--version output version information and exit

SIZE is a number and an optional suffix: K=1024, M=1024*1024, G=1024*1024*1024. B is ignored.

- <INPUT read from standard input, write to standard output

- >OUTPUT read from standard input, write to file named OUTPUT

INPUT > OUTPUT read from INPUT, write to file named OUTPUT

INPUT >> OUTPUT read from INPUT, append to file named OUTPUT

INPUT >>> OUTPUT read from INPUT, append to file named OUTPUT

EXAMPLES

To split a file named myfile.txt into pieces of 1000 lines each, creating files named xaa, xab, etc.:

split -l 1000 myfile.txt

To split a file named myfile.txt into pieces of 10000 bytes each, creating files named myfile.aa, myfile.ab, etc.:

split -b 10000 -d -a 2 myfile.txt myfile.

To split a file named myfile.txt into pieces of approximately 1000 bytes each, creating files named myfile.aa, myfile.ab, etc.:

split -C 1000 myfile.txt myfile.
