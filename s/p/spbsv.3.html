Documentación de Función/Subrutina

subrutina spbsv (carácter uplo, entero n, entero kd, entero nrhs, real, dimensión( ldab, * ) ab, entero ldab, real, dimensión( ldb, * ) b, entero ldb, entero info)

SPBSV calcula la solución al sistema de ecuaciones lineales A * X = B para matrices OTRAS

Propósito:

!>
!> SPBSV calcula la solución a un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz de banda simétrica positiva definida de N por N y X
!> y B son matrices de N por NRHS.
!>
!> La descomposición de Cholesky se utiliza para factorizar A como
!>    A = U**T * U,  si UPLO = 'U', o
!>    A = L * L**T,  si UPLO = 'L',
!> donde U es una matriz de banda triangular superior, y L es una matriz de banda
!> triangular inferior, con el mismo número de superdiagonales o
!> subdiagonales que A.  La forma factorizada de A se utiliza entonces para resolver el
!> sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AB

!>          AB es arreglo REAL, dimensión (LDAB,N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda
!>          simétrica A, almacenado en las primeras KD+1 filas del arreglo. El
!>          j-ésima columna de A se almacena en la j-ésima columna del arreglo AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) para max(1,j-KD)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(N,j+KD).
!>          Ver más abajo para más detalles.
!>
!>          En la salida, si INFO = 0, el factor triangular U o L de la
!>          factorización de Cholesky A = U**T*U o A = L*L**T de la matriz de banda
!>          A, en el mismo formato de almacenamiento que A.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del arreglo AB.  LDAB >= KD+1.
!>

B

!>          B es arreglo REAL, dimensión (LDB,NRHS)
!>          En la entrada, la matriz de lado derecho B de N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el menor principal líder de orden i
!>                de A no es positivo, por lo que la factorización no pudo
!>                completarse y la solución no se ha calculado.
!>

Detalles adicionales:

!>
!>  El esquema de almacenamiento de banda se ilustra con el siguiente ejemplo, cuando
!>  N = 6, KD = 2, y UPLO = 'U':
!>
!>  En la entrada:                       En la salida:
!>
!>      *    *   a13  a24  a35  a46      *    *   u13  u24  u35  u46
!>      *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56
!>     a11  a22  a33  a44  a55  a66     u11  u22  u33  u44  u55  u66
!>
!>  De manera similar, si UPLO = 'L', el formato de A es el siguiente:
!>
!>  En la entrada:                       En la salida:
!>
!>     a11  a22  a33  a44  a55  a66     l11  l22  l33  l44  l55  l66
!>     a21  a32  a43  a54  a65   *      l21  l32  l43  l54  l65   *
!>     a31  a42  a53  a64   *    *      l31  l42  l53  l64   *    *
!>
!>  Los elementos del arreglo marcados con * no son utilizados por la rutina.
!>
