subroutine spotrf (character uplo, integer n, real, dimension( lda, * ) a, integer lda, integer info)

SPOTRF

Propósito:

!>
!> SPOTRF calcula la factorización de Cholesky de una matriz real simétrica
!> positiva definida A.
!>
!> La factorización tiene la forma
!>    A = U**T * U,  si UPLO = 'U', o
!>    A = L  * L**T,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es triangular inferior.
!>
!> Esta es la versión de bloques del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la parte
!>          triangular superior de N-por-N de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la parte
!>          triangular inferior de N-por-N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>
!>          En la salida, si INFO = 0, el factor U o L de la factorización de
!>          Cholesky A = U**T*U o A = L*L**T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el menor principal de orden i
!>                no es positivo, y la factorización no pudo completarse.
!>
