DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina sporfs (character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SPORFS

Propósito:

!>
!> SPORFS mejora la solución calculada de un sistema de ecuaciones
!> lineales cuando la matriz de coeficientes es simétrica definida positiva,
!> y proporciona cotas de error y estimaciones de error hacia atrás para
!> la solución.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array REAL, dimension (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte superior
!>          triangular N-por-N principal de A contiene la parte superior
!>          triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia.  Si UPLO = 'L', la parte
!>          inferior triangular N-por-N principal de A contiene la parte
!>          inferior triangular de la matriz A, y la parte estrictamente
!>          superior triangular de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array REAL, dimension (LDAF,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T, tal como se calculó con SPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

B

!>          B es un array REAL, dimension (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array REAL, dimension (LDX,NRHS)
!>          En la entrada, la matriz solución X, tal como se calculó con
!>          SPOTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es un array REAL, dimension (NRHS)
!>          La cota del error hacia adelante estimada para cada vector
!>          solución X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento
!>          más grande en (X(j) - XTRUE) dividido por la magnitud del
!>          elemento más grande en X(j). La estimación es tan fiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array REAL, dimension (NRHS)
!>          El error relativo componente a componente hacia atrás de cada
!>          vector solución X(j) (es decir, el cambio relativo más pequeño
!>          en cualquier elemento de A o B que haga que X(j) sea una
!>          solución exacta).
!>

WORK

!>          WORK es un array REAL, dimension (3*N)
!>

IWORK

!>          IWORK es un array INTEGER, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros Internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
