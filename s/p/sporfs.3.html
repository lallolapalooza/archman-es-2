subrutina sporfs (carácter uplo, entero n, entero nrhs, real, dimensión( lda, * ) a, entero lda, real, dimensión( ldaf, * ) af, entero ldaf, real, dimensión( ldb, * ) b, entero ldb, real, dimensión( ldx, * ) x, entero ldx, real, dimensión( * ) ferr, real, dimensión( * ) berr, real, dimensión( * ) work, entero, dimensión( * ) iwork, entero info)

SPORFS

Propósito:

!>
!> SPORFS mejora la solución calculada de un sistema de ecuaciones lineales
!> cuando la matriz de coeficientes es simétrica positiva definida,
!> y proporciona límites de error y estimaciones de error hacia atrás para la
!> solución.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte superior triangular
!>          N-por-N principal de A contiene la parte superior triangular
!>          de la matriz A, y la parte estrictamente triangular inferior de A
!>          no se referencia.  Si UPLO = 'L', la parte inferior triangular
!>          N-por-N principal de A contiene la parte inferior triangular
!>          de la matriz A, y la parte estrictamente superior triangular de A
!>          no se referencia.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array REAL, dimensión (LDAF,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T, tal como se calculó por SPOTRF.
!>

LDAF

!>          LDAF es ENTERO
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

B

!>          B es un array REAL, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array REAL, dimensión (LDX,NRHS)
!>          En la entrada, la matriz solución X, tal como se calculó por SPOTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es un array REAL, dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector solución
!>          X(j) (la columna j de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado de la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como la estimación para
!>          RCOND, y casi siempre es una ligera sobreestimación del error real.
!>

BERR

!>          BERR es un array REAL, dimensión (NRHS)
!>          El error relativo componente a componente hacia atrás de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array REAL, dimensión (3*N)
!>

IWORK

!>          IWORK es un array ENTERO, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>

Parámetros Internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
