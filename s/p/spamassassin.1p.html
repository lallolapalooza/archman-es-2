NOMBRE

spamassassin - filtro de correo electrónico extensible utilizado para identificar spam

DESCRIPCIÓN

SpamAssassin es un filtro de correo electrónico inteligente que utiliza una diversa gama de pruebas para identificar correo masivo no solicitado, más comúnmente conocido como "spam". Estas pruebas se aplican a las cabeceras y al contenido del correo electrónico para clasificarlo utilizando métodos estadísticos avanzados. Además, SpamAssassin tiene una arquitectura modular que permite emplear rápidamente otras tecnologías contra el spam y está diseñado para una fácil integración en prácticamente cualquier sistema de correo electrónico.

SINOPSIS

Para facilitar el acceso, el manual de SpamAssassin se ha dividido en varias secciones. Si tiene la intención de leerlas directamente por primera vez, el orden sugerido tenderá a reducir el número de referencias directas.

Hay disponible documentación adicional extensa para SpamAssassin, principalmente en el sitio web y el wiki de SpamAssassin.

Debería poder ver la documentación de SpamAssassin con su programa man(1) o perldoc(1).

ARCHIVOS DE CONFIGURACIÓN

La base de reglas de SpamAssassin, las plantillas de texto y el texto de descripción de reglas se cargan desde los archivos de configuración.

Los datos de configuración predeterminados se cargan desde el primer directorio existente en:

/var/lib/spamassassin/4.000001
/usr/share/spamassassin
/usr/share/spamassassin
/usr/local/share/spamassassin
/usr/share/spamassassin

Los datos de configuración específicos del sitio se utilizan para anular cualquier valor que ya se haya establecido. Esto se carga desde el primer directorio existente en:

/etc/mail/spamassassin
/usr/etc/mail/spamassassin
/usr/etc/spamassassin
/usr/local/etc/spamassassin
/usr/pkg/etc/spamassassin
/usr/etc/spamassassin
/etc/mail/spamassassin
/etc/spamassassin

Desde esos directorios, SpamAssassin primero leerá los archivos que terminan en ".pre" en orden léxico y luego leerá los archivos que terminan en ".cf" en orden léxico (la mayoría de los archivos comienzan con dos números para hacer obvio el orden de clasificación).

En otras palabras, leerá init.pre primero, luego 10_default_prefs.cf antes de 50_scores.cf y 20_body_tests.cf antes de 20_head_tests.cf. Las opciones en archivos posteriores anularán a los archivos anteriores.

Las preferencias individuales del usuario se cargan desde la ubicación especificada en la línea de comandos de "spamassassin", "sa-learn" o "spamd" (consulte la página del manual respectiva para más detalles). Si la ubicación no se especifica, se utiliza ~/.spamassassin/user_prefs si existe. SpamAssassin creará ese archivo si aún no existe, utilizando user_prefs.template como plantilla. Ese archivo se buscará en:

/etc/mail/spamassassin
/usr/etc/mail/spamassassin
/usr/share/spamassassin
/etc/spamassassin
/etc/mail/spamassassin
/usr/local/share/spamassassin
/usr/share/spamassassin

ETIQUETADO

Las dos secciones siguientes detallan el etiquetado y marcado predeterminados que se realizan para los mensajes al ejecutar "spamassassin" o "spamc" con "spamd" en la configuración predeterminada.

Nota: antes de la modificación y adición de cabeceras, se eliminan todas las cabeceras que comienzan con "X-Spam-" para evitar travesuras de los spammers y también para evitar posibles problemas causados por invocaciones previas de SpamAssassin.

ETIQUETADO PARA CORREOS SPAM

Por defecto, todos los mensajes con una puntuación calculada de 5.0 o superior se etiquetan como spam.

Si un mensaje entrante se etiqueta como spam, en lugar de modificar el mensaje original, SpamAssassin creará un nuevo mensaje de informe y adjuntará el mensaje original como una parte MIME de tipo message/rfc822 (asegurando que el mensaje original se conserve por completo y sea más fácil de recuperar).

El nuevo mensaje de informe hereda las siguientes cabeceras (si están presentes) del mensaje de spam original:

Cabecera From:
Cabecera To:
Cabecera Cc:
Cabecera Subject:
Cabecera Date:
Cabecera Message-ID:

Las cabeceras anteriores se pueden modificar si se proporciona la opción relevante "rewrite_header" (consulte "Mail::SpamAssassin::Conf" para más información).

Por defecto, estas cabeceras de mensaje se añaden al spam:

Cabecera X-Spam-Flag:
Establecida en "YES".

Las cabeceras que se añaden son totalmente configurables a través de la opción "add_header" (consulte "Mail::SpamAssassin::Conf" para más información).

texto del cuerpo del mensaje de spam
El informe de SpamAssassin se añade a la parte superior del cuerpo del mensaje, si el mensaje se marca como spam.

TAGGING

SpamAssassin agrega varias cabeceras a un mensaje para indicar si es spam y qué tan probable es que sea spam. Si no se especifica lo contrario en la configuración, estas cabeceras son:

cabecera X-Spam-Checker-Version
La versión y subversión de SpamAssassin y el host donde se ejecutó SpamAssassin.
cabecera X-Spam-Level
Una serie de caracteres "*" donde cada uno representa un punto de puntuación completo.
cabecera X-Spam-Status
Una cadena, "(Sí|No), score=nn required=nn tests=xxx,xxx autolearn=(ham|spam|no|unavailable|failed)" se establece en esta cabecera para reflejar el estado del filtro. Para la primera palabra, "Sí" significa spam y "No" significa ham (no spam).

Las cabeceras que se agregan son completamente configurables a través de la opción "add_header" (ver "Mail::SpamAssassin::Conf" para más información).

INSTALACIÓN

El comando spamassassin es parte del módulo Perl Mail::SpamAssassin. Instálelo como un módulo Perl normal, usando "perl -MCPAN -e shell", o a mano.

Tenga en cuenta que no es posible utilizar la variable de entorno "PERL5LIB" para afectar dónde SpamAssassin encuentra sus módulos Perl, debido a las limitaciones impuestas por las verificaciones de seguridad "taint" de Perl.

Para más detalles sobre cómo instalar, por favor lea el archivo "INSTALL" de la distribución de SpamAssassin.
