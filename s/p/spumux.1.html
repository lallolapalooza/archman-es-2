NOMBRE

spumux - genera y multiplexa subtítulos en un flujo de programa mpeg2 existente

SINOPSIS

spumux [ -m dvd | -m cvd | -m svcd ] [ -s flujo ] [ -v nivel ] [ -P ] [ --nomux ] [ --nodvdauthor-data ] archivo < mpeg > mpeg-con-subtitulos

DESCRIPCIÓN

spumux codifica los subtítulos y los multiplexa en el flujo de programa mpeg2.

-m modo
Establece la codificación para los subtítulos. Puede ser dvd, cvd o svcd. El valor predeterminado es dvd.
-s flujo
Establece el ID del flujo de subtítulos. El valor predeterminado es 0.
-v nivel
Establece el nivel de verbosidad.
-P
Habilita una barra de progreso.
--nomux
Deshabilita la lectura de un flujo MPEG desde la entrada estándar. En su lugar, la salida contendrá solo el flujo de subpicture.
--nodvdauthor-data
Deshabilita el paso de información de color y botones a dvdauthor.

Aquí tienes un archivo de configuración de ejemplo:

<subpictures>
   <stream>
      <spu start="tiempo-inicio" [ end="tiempo-fin" ] [ image="imagen.png" ]
           [ highlight="imagen.png" ] [ select="imagen.png" ]
           [ transparent="especificación-color" ] [ force="yes" ]
           [ autooutline="infer" [ outlinewidth="ancho" ]
             [ autoorder="rows" | autoorder="columns" ] ]
           [ xoffset="coord-x" yoffset="coord-y" ] >
         <button [ name="nombre" ] [ x0="x0" ] [ y0="y0" ] [ x1="x1" ]
                 [ y1="y1" ] [ up="nombre" ] [ down="nombre" ]
                 [ left="nombre" ] [ right="nombre" ] />
         <action [ name="nombre" ] [ x0="x0" ] [ y0="y0" ] [ x1="x1" ]
                 [ y1="y1" ] />
      </spu>
   </stream>
</subpictures>

Cada imagen de subtítulo se describe mediante una etiqueta <spu>. Los atributos start y end (opcional) describen cuándo se mostrará el subtítulo en la pantalla, en formato "HH:MM:SS.CS". El atributo image describe la imagen principal del subtítulo, que puede ser un archivo PNG o BMP. Si tu imagen no es una imagen a pantalla completa, puedes usar xoffset e yoffset para mover la imagen. En caso de que el autor no pueda utilizar un formato gráfico con canal alfa, se puede usar el atributo transparent para describir qué color se volverá completamente transparente. Para ver los formatos válidos de especificación-color, consulta ESPECIFICANDO COLORES más abajo. Si quieres forzar la visualización del subtítulo, independientemente de si el usuario ha activado los subtítulos o no, puedes usar la etiqueta force. Cuando estés creando menús, la etiqueta force es obligatoria.

Los atributos y etiquetas restantes están relacionados con la creación de menús. El atributo highlight muestra cómo se ven todos los botones cuando están resaltados (es decir, cuando usas las flechas en el menú), y el atributo select muestra cómo se ven todos los botones cuando están seleccionados (es decir, durante los 1-2 segundos después de presionar Enter en el menú). Si alguno de estos (o el atributo image) se omite, spumux crea una imagen en blanco (completamente transparente). Obviamente, se debe especificar al menos una etiqueta.

Para ayudar en la creación de botones, el atributo autooutline indica a spumux que infiera dónde se encuentran los botones. Lo hace intentando dibujar rectángulos alrededor de una composición de las imágenes highlight y select que no se crucen con ningún píxel opaco o semiopaco. Para admitir botones de texto, el atributo outlinewidth permite especificar el ancho del rectángulo que se prueba. Rectángulos más anchos no podrán encajar entre las letras. Finalmente, autoorder describe cómo ordenar los botones detectados automáticamente, lo cual es importante para los botones seleccionados numéricamente y para mapear botones a nombres de botón o a nombres implícitos.

Las etiquetas button y action describen los botones (objetos visualmente seleccionables en la pantalla) y las acciones (comandos que se ejecutan tan pronto como se presiona la tecla asociada en el control remoto). Si estás utilizando la función autooutline, solo diseñando botones, estás satisfecho con la navegación de botones inferida y puedes lidiar con el simplista sistema de nombres, entonces en realidad ni siquiera necesitas especificar ningún botón o acción. De lo contrario, sigue leyendo.

El atributo name se utiliza para dar a un botón o acción un nombre fácil de referenciar. Por defecto, se numeran secuencialmente empezando por "1". Los nombres up, down, left y right describen qué botón o acción debe asociarse a la tecla correspondiente cuando el botón actual está resaltado, aunque si se omiten, spumux utilizará un algoritmo razonablemente inteligente para determinar a qué botones moverse.

Las coordenadas (x0,y0) describen la esquina superior izquierda inclusiva, mientras que las coordenadas (x1,y1) describen la esquina inferior derecha EXCLUSIVA. Las coordenadas comienzan en 0,0 para la esquina superior izquierda. Idealmente, las coordenadas y0 e y1 deberían ser pares, para que los bordes del botón abarquen completamente dos líneas de escaneo entrelazadas, incluso si no hay datos en la línea de escaneo adicional. Algunos reproductores de DVD rellenarán la línea de escaneo adicional si no se especifica; spumux se esfuerza por garantizar que sea transparente, pero no hay garantía.

MANEJO DE SUBTÍTULOS BASADOS EN TEXTO

Spumux también es capaz de manejar subtítulos de texto, que serán renderizados a gráficos por spumux. Se admiten muchos formatos de texto diferentes (deben ser no gráficos): .sub, .srt, .ssa, .smi, .rt, .txt, .aqt, .jss, .js, ass. Spumux intentará determinar el formato automáticamente.

Si se procesan subtítulos basados en texto, no se pueden definir otros flujos; los botones u otros elementos deben procesarse en un pase adicional con spumux, utilizando otro archivo xml.

El siguiente archivo .xml muestra las etiquetas disponibles y sus configuraciones predeterminadas. Solo la etiqueta textsub es obligatoria; se utilizan los valores predeterminados si la etiqueta específica no se especifica.

<subpictures [format="NTSC|PAL"]>
   <stream>
      <textsub filename="demo1.srt" characterset="UTF-8"
         fontsize="28.0" font="arial" fill-color="especificación-color"
         outline-color="especificación-color" outline-thickness="3.0"
         shadow-offset="0, 0" shadow-color="especificación-color"
         horizontal-alignment="left"  vertical-alignment="bottom"
         left-margin="60" right-margin="60"
         top-margin="20" bottom-margin="30" subtitle-fps="fps"
         movie-fps="fps"
         movie-width="720" movie-height="altura" aspect="4:3"
         force="yes"
      />
   </stream>
</subpictures>

La etiqueta textsub define la configuración para la renderización de texto a gráficos.

El atributo filename define la ruta y el nombre del archivo de subtítulos de texto de entrada; este es el único atributo obligatorio.

El atributo characterset define el conjunto de caracteres a utilizar; los conjuntos de caracteres disponibles se pueden encontrar en http://www.gnu.org/software/libiconv.

El atributo fontsize define el tamaño de la fuente en unidades de fuente. El atributo font define la fuente utilizada. Spumux buscará la fuente utilizando Fontconfig si está disponible, de lo contrario la usará como un nombre de archivo en sistemas Linux y buscará en los directorios windows/fonts y el subdirectorio spumux del directorio principal de cygwin/mingw y en el directorio de ejecución para la ejecución basada en Windows para la fuente especificada. ¿Buscas fuentes gratuitas? Una lista está aquí http://www.microsoft.com/typography/links/links.asp?type=free&part=1 (esto es solo sobre fuentes, no sobre sistemas operativos).

El atributo fill-color especifica el color a utilizar para rellenar el interior del texto, mientras que outline-color especifica el color del borde del contorno a dibujar alrededor de cada carácter, para destacarlo de

DESCRIPTION

The attributes below can be used on any spumux element (spu, video, button, menu, etc.).

The fill-color and outline-color attributes specify the colors used for the fill and the outline of the text, respectively. The outline-thickness attribute specifies the thickness of this outline. For the valid formats for color-spec, see SPECIFYING COLORS below. The default fill color is white and the default outline color is black.

The shadow-offset and shadow-color attributes specify a shadow effect to be applied to the text. The shadow-offset is specified as 2 signed integers, being the horizontal and vertical offset respectively, with positive values being to the right and down. For the valid formats for color-spec, see SPECIFYING COLORS below. The default shadow color is black.

The horizontal-alignment attribute defines the horizontal alignment of the subtitles. Options are: "left", "right", "center" and "default". The "default" value causes spumux to use the attribute that is in the text subtitle file if the format supports such an attribute.

The vertical-alignment attribute defines the vertical alignment. Options are: "top", "center" and "bottom".

The margin attributes define the minimum blank pixel space between the border of the image and the border of the subtitle lines.

The subtitle-fps is needed for subtitle formats which use frame numbers rather than fractional seconds for specifying subtitle times, while the movie-fps is the frame rate of the movie onto which the subtitles are being multiplexed; if omitted, both of these default to 29.97 for NTSC and 25 for PAL.

Having separate subtitle-fps and movie-fps attributes make it possible for spumux to recalculate the subtitle timing if these are not the same.

The movie-width and movie-height attributes define the maximum size of the subtitle page, these shouldn't be larger than the size of the video frame (720x480 for NTSC, 720x576 for PAL), normally they are the same. Some DVD players prefer subtitle frames that are 2 or 4 pixels smaller in height. If omitted, the default movie width is 720 and the height is 2 pixels less than the video frame height.

The aspect attribute lets you specify whether the video aspect ratio is 16:9 (widescreen) or 4:3. This, together with the video format, is used to adjust the rendering of the text to ensure it appears undistorted.

The force option allows you to force the display of the subtitle, regardless of whether the user has enabled subtitles or not.

SPECIFYING COLORS

Colors for image transparency and text fill and outlines can be specified in a number of ways:

•
As a color name, e.g. "green". You can use most of the color names listed at http://www.imagemagick.org/script/color.php.
•
As a hexadecimal string preceded by a "#", similar to HTML format, e.g. "#FF8080". The number of digits must be a multiple of 3; the first group specifies the red component, the second green, and the third blue.
•
As the name of a color space, followed by one to four component values in parentheses, e.g. "hsv(120, 50%, 90%)".

Valid color spaces are "gray" (1 component), "graya" (2 components), "hsl" (3 components), "hsla" (4 components), "hsv" (3 components), "hsva" (4 components), "rgb" (3 components) and "rgba" (4 components). Each component can be specified as either a percentage of the maximum value suffixed by "%", or an absolute value in the range 0-360 for hues, 0-255 for everything else. For color space names ending with "a", the last component is the alpha (transparency) value.
