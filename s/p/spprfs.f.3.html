SPPRFS

Propósito:

!>
!> SPPRFS mejora la solución calculada para un sistema de ecuaciones
!> lineales cuando la matriz de coeficientes es simétrica definida positiva
!> y empaquetada, y proporciona cotas de error y estimaciones de error hacia atrás
!> para la solución.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es un array REAL, dimension (N*(N+1)/2)
!>          El triángulo superior o inferior de la matriz simétrica A,
!>          empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

AFP

!>          AFP es un array REAL, dimension (N*(N+1)/2)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T, tal como se calculó por SPPTRF/CPPTRF,
!>          empaquetado por columnas en un array lineal con el mismo formato que A
!>          (ver AP).
!>

B

!>          B es un array REAL, dimension (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array REAL, dimension (LDX,NRHS)
!>          En la entrada, la matriz solución X, tal como se calculó por SPPTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es un array REAL, dimension (NRHS)
!>          La cota del error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada de la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividida por la magnitud del elemento más grande
!>          en X(j). La estimación es tan fiable como la estimación para RCOND,
!>          y casi siempre es una ligera sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array REAL, dimension (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector
!>          solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array REAL, dimension (3*N)
!>

IWORK

!>          IWORK es un array INTEGER, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Parámetros internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
