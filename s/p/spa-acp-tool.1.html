NOMBRE

spa-acp-tool - La utilidad de depuración de perfiles ALSA de PipeWire

SINOPSIS

spa-acp-tool [OPCIONES] [COMANDO]

DESCRIPCIÓN

Herramienta de depuración para ejercitar el código de sondeo de perfiles de tarjeta ALSA, sin ejecutar PipeWire.

Puede usarse para depurar problemas donde PipeWire tiene perfiles de tarjeta ALSA que funcionan incorrectamente.

OPCIONES

-h | --help

Mostrar ayuda

-v | --verbose

Aumentar el nivel de verbosidad en uno

-c NÚMERO | --card NÚMERO

Seleccionar qué tarjeta sondear

-p | --properties

Propiedades adicionales para pasar a ACP, por ejemplo, clave=valor ....

COMANDOS

help | h

Mostrar comandos disponibles

quit | q

Salir

card ID | c ID

Sondear tarjeta

info | i

Listar información de la tarjeta

list | l

Listar todos los objetos

list-verbose | lv

Listar todos los datos

list-profiles [ID] | lpr [ID]

Listar perfiles

set-profile ID | spr ID

Activar un perfil

list-ports [ID] | lp [ID]

Listar puertos

set-port ID | sp ID

Activar un puerto

list-devices [ID] | ld [ID]

Listar dispositivos disponibles

get-volume ID | gv ID

Obtener volumen de un dispositivo

set-volume ID VOL | v ID VOL

Establecer volumen en un dispositivo

inc-volume ID | v+ ID

Incrementar volumen en un dispositivo

dec-volume ID | v- ID

Decrementar volumen en un dispositivo

get-mute ID | gm ID

Obtener estado de silencio de un dispositivo

set-mute ID VAL | sm ID VAL

Establecer silencio en un dispositivo

toggle-mute ID | m ID

Alternar silencio en un dispositivo
