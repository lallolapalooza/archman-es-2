SPEEXENC(1) Comandos de usuario SPEEXENC(1)

NOMBRE

speexenc - La implementación de referencia del codificador Speex.

SINOPSIS

speexenc [opciones] archivo_entrada archivo_salida

DESCRIPCIÓN

Codifica el archivo de entrada usando Speex. Puede leer archivos WAV o archivos crudos.

archivo_entrada puede ser:

nombrearchivo.wav
archivo wav
nombrearchivo.*
Archivo PCM crudo (cualquier extensión que no sea .wav)
-
stdin

archivo_salida puede ser:

nombrearchivo.spx
Archivo Speex
-
stdout

OPCIONES

-n, --narrowband
Archivo de entrada de banda estrecha (8 kHz)
-w, --wideband
Archivo de entrada de banda ancha (16 kHz)

-u, --ultra-wideband "Banda ultra ancha" (32 kHz) archivo de entrada

--quality n
Calidad de codificación (0-10), por defecto 8
--bitrate n
Tasa de bits de codificación (usa una tasa de bits n o menor)
--vbr
Habilitar tasa de bits variable (VBR)
--abr rate
Habilitar tasa de bits promedio (ABR) a rate bps
--vad
Habilitar detección de actividad de voz (VAD)
--dtx
Habilitar transmisión discontinua basada en archivos (DTX)
--comp n
Establecer complejidad de codificación (0-10), por defecto 3
--nframes n
Número de fotogramas por paquete Ogg (1-10), por defecto 1
--comment
Añadir la cadena dada como un comentario adicional. Esto puede usarse múltiples veces
--author
Autor de esta pista
--title
Título para esta pista
-h, --help
Esta ayuda
-v, --version
Información de versión
-V
Modo verboso (mostrar tasa de bits)

Opciones de entrada cruda:

--rate n
Frecuencia de muestreo para entrada cruda
--stereo
Considerar entrada cruda como estéreo
--le
Entrada cruda es little-endian
--be
Entrada cruda es big-endian
--8bit
Entrada cruda es sin signo de 8 bits
--16bit
Entrada cruda es con signo de 16 bits

La entrada PCM cruda por defecto es de 16 bits, little-endian, mono

Más información disponible en el sitio de Speex: http://www.speex.org

Por favor, informe de errores a la lista de correo `speex-dev@xiph.org'.
