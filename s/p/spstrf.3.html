Documentación de Función/Subrutina

subrutina spstrf (carácter uplo, entero n, real, dimensión( lda, * ) a, entero lda, entero, dimensión( n ) piv, entero rank, real tol, real, dimensión( 2*n ) work, entero info)

SPSTRF calcula la factorización de Cholesky con pivoteo completo de una matriz real simétrica semidefinida positiva.

Propósito:

!>
!> SPSTRF calcula la factorización de Cholesky con pivoteo
!> completo de una matriz real simétrica semidefinida positiva A.
!>
!> La factorización tiene la forma
!>    P**T * A * P = U**T * U ,  si UPLO = 'U',
!>    P**T * A * P = L  * L**T,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es triangular inferior, y
!> P se almacena como vector PIV.
!>
!> Este algoritmo no intenta verificar que A sea semidefinida positiva.
!> Esta versión del algoritmo llama a BLAS de nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CARÁCTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada.
!>          = 'U': Triangular superior
!>          = 'L': Triangular inferior
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es matriz REAL, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular de N por N de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia.  Si UPLO = 'L', la
!>          parte inferior triangular de N por N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>
!>          En la salida, si INFO = 0, el factor U o L de la factorización
!>          de Cholesky como se describe arriba.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

PIV

!>          PIV es array ENTERO, dimensión (N)
!>          PIV es tal que las entradas no nulas son P( PIV(K), K ) = 1.
!>

RANK

!>          RANK es ENTERO
!>          El rango de A dado por el número de pasos que completó el
!>          algoritmo.
!>

TOL

!>          TOL es REAL
!>          Tolerancia definida por el usuario. Si TOL < 0, entonces se
!>          usará N*U*MAX( A(K,K) ). El algoritmo termina en el paso
!>          (K-1) si el pivote <= TOL.
!>

WORK

!>          WORK es array REAL, dimensión (2*N)
!>          Espacio de trabajo.
!>

INFO

!>          INFO es ENTERO
!>          < 0: Si INFO = -K, el K-ésimo argumento tenía un valor ilegal.
!>          = 0: el algoritmo se completó con éxito, y
!>          > 0: la matriz A es bien deficiente en rango con rango calculado
!>               como se devuelve en RANK, o no es semidefinida positiva.
!>               Consulte la Sección 7 de LAPACK Working Note #161 para
!>               más información.
!>
