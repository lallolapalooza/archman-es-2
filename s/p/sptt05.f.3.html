Documentación de Función/Subrutina

subrutina sptt05 (integer n, integer nrhs, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real, dimension( ldxact, * ) xact, integer ldxact, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) reslts)

SPTT05

Propósito:

!>
!> SPTT05 prueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones A*X = B, donde A es una
!> matriz simétrica tridiagonal de orden n.
!>
!> RESLTS(1) = prueba del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta relación no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( NZ*EPS + (*) ), donde
!>             (*) = NZ*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>             y NZ = número máximo de no ceros en cualquier fila de A, más 1
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de filas de las matrices X, B y XACT, y el
!>          orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X, B y XACT.
!>          NRHS >= 0.
!>

D

!>          D es array REAL, dimension (N)
!>          Los n elementos diagonales de la matriz tridiagonal A.
!>

E

!>          E es array REAL, dimension (N-1)
!>          Los (n-1) elementos subdiagonales de la matriz tridiagonal A.
!>

B

!>          B es array REAL, dimension (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array REAL, dimension (LDX,NRHS)
!>          Los vectores de solución calculados. Cada vector se almacena
!>          como una columna de la matriz X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

XACT

!>          XACT es array REAL, dimension (LDX,NRHS)
!>          Los vectores de solución exactos. Cada vector se almacena
!>          como una columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es INTEGER
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR es array REAL, dimension (NRHS)
!>          Los límites de error directo estimados para cada vector de
!>          solución X. Si XTRUE es la solución verdadera, FERR limita la
!>          magnitud de la entrada más grande en (X - XTRUE) dividida por
!>          la magnitud de la entrada más grande en X.
!>

BERR

!>          BERR es array REAL, dimension (NRHS)
!>          El error residual componente a componente de cada vector de
!>          solución (es decir, el cambio relativo más pequeño en cualquier
!>          entrada de A o B que haga de X una solución exacta).
!>

RESLTS

!>          RESLTS es array REAL, dimension (2)
!>          El máximo sobre los vectores de solución NRHS de las
!>          relaciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!>
