subrutina spbt02 (character uplo, integer n, integer kd, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldx, * ) x, integer ldx, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) rwork, real resid)

SPBT02

Propósito:

!>
!> SPBT02 calcula el residuo para una solución de un sistema de ecuaciones
!> de banda simétrico A*x = b:
!>    RESID = norm( B - A*X ) / ( norm(A) * norm(X) * EPS)
!> donde EPS es la precisión de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de super-diagonales de la matriz A si UPLO = 'U',
!>          o el número de sub-diagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos. NRHS >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          La matriz de banda simétrica original A.  Si UPLO = 'U', la
!>          parte triangular superior de A se almacena como una matriz de banda;
!>          si UPLO = 'L', la parte triangular inferior de A se almacena. Las
!>          columnas de la parte triangular apropiada se almacenan en las columnas
!>          de A y las diagonales del triángulo se almacenan en las filas
!>          de A. Ver SPBTRF para más detalles.
!>

LDA

!>          LDA es INTEGER.
!>          La dimensión principal del array A.  LDA >= max(1,KD+1).
!>

X

!>          X es un array REAL, dimensión (LDX,NRHS)
!>          Los vectores de solución calculados para el sistema de ecuaciones
!>          lineales.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.   LDX >= max(1,N).
!>

B

!>          B es un array REAL, dimensión (LDB,NRHS)
!>          A la entrada, los vectores del lado derecho para el sistema de
!>          ecuaciones lineales.
!>          A la salida, B se sobrescribe con la diferencia B - A*X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

RWORK

!>          RWORK es un array REAL, dimensión (N)
!>

RESID

!>          RESID es REAL
!>          El máximo sobre el número de lados derechos de
!>          norm(B - A*X) / ( norm(A) * norm(X) * EPS ).
!>
