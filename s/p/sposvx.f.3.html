subroutine sposvx (character fact, character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, character equed, real, dimension( * ) s, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SPOSVX calcula la solución del sistema de ecuaciones lineales A * X = B para matrices PO

Propósito:

!>
!> SPOSVX utiliza la factorización de Cholesky A = U**T*U o A = L*L**T para
!> calcular la solución de un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz simétrica definida positiva de N por N y X y B
!> son matrices de N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación de la
!> condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Si el sistema se equilibrará o no depende de la escala de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe por diag(S)*A*diag(S)
!>    y B por diag(S)*B.
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**T* U,  si UPLO = 'U', o
!>       A = L * L**T,  si UPLO = 'L',
!>    donde U es una matriz triangular superior y L es una matriz triangular
!>    inferior.
!>
!> 3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina regresa con INFO = i. De lo contrario, la forma
!>    factorizada de A se utiliza para estimar el número de condición de la
!>    matriz A. Si la recíproca del número de condición es menor que la
!>    precisión de la máquina, se devuelve INFO = N+1 como advertencia, pero
!>    la rutina aún continúa resolviendo X y calculando límites de error como
!>    se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    la matriz y calcular límites de error y estimaciones de error hacia
!>    atrás para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes
!>    del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          suministra en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AF contiene la forma factorizada de A.
!>                  Si EQUED = 'Y', la matriz A ha sido equilibrada
!>                  con factores de escala dados por S. A y AF no
!>                  serán modificadas.
!>          = 'N':  La matriz A se copiará en AF y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A, excepto si FACT = 'F' y
!>          EQUED = 'Y', entonces A debe contener la matriz equilibrada
!>          diag(S)*A*diag(S). Si UPLO = 'U', la parte superior
!>          N-por-N de A contiene la parte triangular superior de la matriz A,
!>          y la parte estrictamente triangular inferior de A no se referencia.
!>          Si UPLO = 'L', la parte inferior N-por-N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia. A no se modifica si
!>          FACT = 'F' o 'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>          En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe por
!>          diag(S)*A*diag(S).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array REAL, dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la
!>          entrada contiene el factor triangular U o L de la factorización
!>          de Cholesky A = U**T*U o A = L*L**T, en el mismo formato de
!>          almacenamiento que A. Si EQUED .ne. 'N', entonces AF es la forma
!>          factorizada de la matriz equilibrada diag(S)*A*diag(S).
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la
!>          salida devuelve el factor triangular U o L de la factorización
!>          de Cholesky A = U**T*U o A = L*L**T de la matriz original A.
!>
!>          Si FACT = 'E', entonces AF es un argumento de salida y en la
!>          salida devuelve el factor triangular U o L de la factorización
!>          de Cholesky A = U**T*U o A = L*L**T de la matriz A equilibrada
!>          (ver la descripción de A para la forma de la matriz equilibrada).
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'Y':  Se realizó el equilibrado, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

S

!>          S es array REAL, dimensión (N)
!>          Los factores de escala para A; no se accede si EQUED = 'N'. S es
!>          un argumento de entrada si FACT = 'F'; de lo contrario, S es un
!>          argumento de salida. Si FACT = 'F' y EQUED = 'Y', cada elemento de S
!>          debe ser positivo.
!>

B

!>          B es array REAL, dimensión (LDB,NRHS)
!>          En la entrada, la matriz de lados derechos B de N por NRHS.
!>          En la salida, si EQUED = 'N', B no se modifica; si EQUED = 'Y',
!>          B se sobrescribe por diag(S) * B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array REAL, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS a
!>          el sistema original de ecuaciones. Tenga en cuenta que si EQUED = 'Y',
!>          A y B se modifican en la salida, y la solución al sistema
!>          equilibrado es inv(diag(S))*X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>
>

RCOND

!> RCOND es REAL
!> La estimación del número de condición recíproco de la matriz
!> A después de la   equilibración (si se hizo). Si RCOND es menor que la
!> precisión de la máquina (en particular, si RCOND = 0), la matriz
!> es singular con precisión de trabajo. Esta condición se
!> indica con un código de retorno de INFO > 0.
!>

FERR

!> FERR es un array REAL, de dimensión (NRHS)
!> El límite de error hacia adelante estimado para cada vector de solución
!> X(j) (la j-ésima columna de la matriz de solución X).
!> Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!> es un límite superior estimado para la magnitud del elemento más grande
!> en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!> en X(j). La estimación es tan confiable como
!> la estimación para RCOND, y es casi siempre una ligera
!> sobreestimación del error verdadero.
!>

BERR

!> BERR es un array REAL, de dimensión (NRHS)
!> El error hacia atrás relativo componente a componente de cada vector de solución
!> X(j) (es decir, el menor cambio relativo en
!> cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!> WORK es un array REAL, de dimensión (3*N)
!>

IWORK

!> IWORK es un array INTEGER, de dimensión (N)
!>

INFO

!> INFO es INTEGER
!> = 0: salida exitosa
!> < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!> > 0: si INFO = i, e i es
!> <= N: el menor principal principal de orden i de A
!>       no es positivo, por lo que la factorización no pudo
!>       ser completada, y la solución no ha sido
!>       calculada. Se devuelve RCOND = 0.
!> = N+1: U es no singular, pero RCOND es menor que la precisión de la
!>        máquina, lo que significa que la matriz es singular
!>        con precisión de trabajo. Sin embargo, la
!>        solución y los límites de error se calculan porque
!>        hay una serie de situaciones en las que la
!>        solución calculada puede ser más precisa que el
!>        valor que sugeriría RCOND.
!>
