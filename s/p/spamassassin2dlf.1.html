NOMBRE

spamassassin2dlf - convierte el registro de SpamAssassin a formato DLF de Lire spamfilter

SINOPSIS

spamassassin2dlf

DESCRIPCIÓN

Este programa convierte los archivos de registro syslog de SpamAssassin (http://spamassassin.org/) al formato DLF de Lire spamfilter.

LIMITACIONES

El host de origen no se utiliza (todavía) porque no hay forma de vincular el proceso receptor y sus procesos hijos.

EJEMPLOS

Para procesar un registro como el producido por SpamAssassin:

$ spamassassin2dlf < spamd-log

spamassassin2dlf rara vez se usará por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report spamassassin < /var/log/spamd-log

ERRORES

Esta página del manual debería incluir un fragmento de ejemplo de un archivo de registro de SpamAssassin.
