SPHINX-AUTOGEN(1) Sphinx SPHINX-AUTOGEN(1)

NOMBRE

sphinx-autogen - Generar páginas de plantilla de autodocumentación

SINOPSIS

sphinx-autogen [opciones] <archivo_fuente> ...

DESCRIPCIÓN

sphinx-autogen es una herramienta para la generación automática de fuentes de Sphinx que, utilizando la extensión autodoc, documentan elementos incluidos en listados de autosummary.

OPCIONES

-o <directorio_salida>
Directorio donde colocar el archivo de salida. Si no existe, se crea. Por defecto, es el valor pasado a la opción :toctree:.
-s <sufijo>, --suffix <sufijo>
Sufijo por defecto a usar para los archivos generados. Por defecto es rst.
-t <plantillas>, --templates <plantillas>
Directorio de plantillas personalizado. Por defecto es None.
-i, --imported-members
Documentar miembros importados.
-a, --respect-module-all
Documentar exactamente los miembros en el atributo __all__ de un módulo.
--remove-old
Eliminar archivos existentes en el directorio de salida que ya no se generan.

EJEMPLO

Dada la siguiente estructura de directorios:

docs
├── index.rst
└── ...
foobar
├── foo
│   └── __init__.py
└── bar
    ├── __init__.py
    └── baz
        └── __init__.py

y asumiendo que docs/index.rst contenía lo siguiente:

Módulos
=======
.. autosummary::
   :toctree: modules
   foobar.foo
   foobar.bar
   foobar.bar.baz

Si ejecuta lo siguiente:

$ PYTHONPATH=. sphinx-autogen docs/index.rst

entonces los siguientes archivos de plantilla se crearán en docs:

docs
├── index.rst
└── modules
    ├── foobar.bar.rst
    ├── foobar.bar.baz.rst
    └── foobar.foo.rst

y cada uno de esos archivos contendrá una directiva autodoc y algo de información adicional.
