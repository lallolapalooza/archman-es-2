SPRINGGRAPH(1) Manual de Comandos Generales SPRINGGRAPH(1)

NOMBRE

springgraph - renderiza un grafo desde un archivo .dot

SINOPSIS

springgraph [OPCIONES] < archivo-entrada.dot > archivo-salida.png

DESCRIPCIÓN

Springgraph leerá un archivo .dot que describe un grafo, el cual, para cada nodo, especifica su nombre y con qué otros nodos está conectado, y luego renderizará un grafo. La salida es un archivo PNG. Cada nodo se dibuja como una elipse y cada conexión se dibuja como una flecha. La colocación de los nodos es el resultado de que todos los nodos se alejan unos de otros, mientras que todos los nodos que están conectados se acercan unos a otros. Este movimiento se repite hasta que se estabiliza.

Springgraph fue escrito como una alternativa a neato, que forma parte de graphviz. Intenta leer los mismos archivos .dot utilizados por graphviz, pero actualmente solo admite un número limitado de atributos de nodo (label y fillcolor) y solo puede manejar dos nodos por definición de borde ("nodo1 -> nodo2", no "nodo1 -> nodo2 -> nodo3").

OPCIONES

springgraph acepta las siguientes opciones:

-p
Crea un archivo que puede ser renderizado con POV-Ray
-v
crea un archivo VRML
-s
esta opción especifica la escala. Todas las ubicaciones de los nodos se multiplican por este valor. Aumenta la escala para eliminar superposiciones de nodos. Disminuye la escala para hacer el grafo más pequeño.
-t
hace que el fondo de la imagen resultante sea transparente.
-b
establece el color de fondo de la imagen, especifícalo en formato RRGGBB, en dígitos hexadecimales, p. ej., FFFFFF es blanco, 000000 es negro, FF0000 es rojo, ...
-l
establece el color de la línea, mismo formato que el color de fondo
-h
muestra el resumen de uso

EJEMPLO


digraph {
"rene" -> "myon";
"mvo" -> "rene";
}
