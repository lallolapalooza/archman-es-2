Documentación de la Función/Subrutina

subrutina sposv (carácter uplo, entero n, entero nrhs, real, dimensión( lda, * ) a, entero lda, real, dimensión( ldb, * ) b, entero ldb, entero info)

SPOSV calcula la solución del sistema de ecuaciones lineales A * X = B para matrices PO

Propósito:

!>
!> SPOSV calcula la solución de un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz simétrica positiva definida de N por N y X y B
!> son matrices de N por NRHS.
!>
!> La descomposición de Cholesky se utiliza para factorizar A como
!>    A = U**T* U,  si UPLO = 'U', o
!>    A = L * L**T,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es una matriz triangular
!> inferior.  La forma factorizada de A se utiliza entonces para resolver el
!> sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es ENTERO
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior de N por N de A contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior
!>          de A no se referencia.  Si UPLO = 'L', la parte inferior de
!>          N por N de A contiene la parte triangular inferior de la matriz
!>          A, y la parte estrictamente triangular superior de A no se
!>          referencia.
!>
!>          En la salida, si INFO = 0, el factor U o L de la factorización
!>          de Cholesky A = U**T*U o A = L*L**T.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array REAL, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho de N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el menor principal líder de orden i
!>                de A no es positivo, por lo que la factorización no pudo
!>                completarse y la solución no se ha calculado.
!>
