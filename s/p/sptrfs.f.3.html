Documentación de Función/Subrutina

subroutine sptrfs (integer n, integer nrhs, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) df, real, dimension( * ) ef, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer info)

SPTRFS

Propósito:

!>
!> SPTRFS mejora la solución calculada para un sistema de ecuaciones
!> lineales cuando la matriz de coeficientes es simétrica definida positiva
!> y tridiagonal, y proporciona cotas de error y estimaciones de error hacia atrás
!> para la solución.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

D

!>          D es un array REAL, dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal A.
!>

E

!>          E es un array REAL, dimensión (N-1)
!>          Los (n-1) elementos subdiagonales de la matriz tridiagonal A.
!>

DF

!>          DF es un array REAL, dimensión (N)
!>          Los n elementos diagonales de la matriz diagonal D de la
!>          factorización calculada por SPTTRF.
!>

EF

!>          EF es un array REAL, dimensión (N-1)
!>          Los (n-1) elementos subdiagonales del factor bidiagonal unitario
!>          L de la factorización calculada por SPTTRF.
!>

B

!>          B es un array REAL, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array REAL, dimensión (LDX,NRHS)
!>          En la entrada, la matriz solución X, tal como se calculó con SPTTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es un array REAL, dimensión (NRHS)
!>          La cota de error hacia adelante para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada de la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j).
!>

BERR

!>          BERR es un array REAL, dimensión (NRHS)
!>          El error relativo componente a componente hacia atrás de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!>

WORK

!>          WORK es un array REAL, dimensión (2*N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Parámetros internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
