NOMBRE

spuunmux - desmultiplexa subtítulos de un flujo de programa mpeg2 existente

SINOPSIS

spuunmux [ archivo de entrada ] [ archivo de entrada ... ]

DESCRIPCIÓN

spuunmux desmultiplexa subtítulos de un flujo de programa mpeg2 existente

OPCIONES

-o nombre
nombre base para el script y las imágenes. Por defecto es sub.
-v nivel
nivel de verbosidad. sub. Por defecto es 0.
-f
redimensiona las imágenes a tamaño completo, que es 720x480 para NTSC, 720x576 para PAL.
-F PAL|NTSC
especifica el formato de vídeo, que se utiliza para calcular las dimensiones del tamaño completo para -f.
-s flujo
número del subflujo a extraer. Por defecto es 0.
-p archivo
nombre del archivo con la paleta de dvd. Si el archivo de paleta termina en .rgb, se trata como color RGB, de lo contrario como color YCbCr.
-h
imprime esta ayuda
-V
imprime el número de versión

USO

spuunmux archivo_entrada1 archivo_entrada2

desmultiplexa subtítulos de un flujo de programa mpeg2 existente. Para usar la entrada estándar para desmultiplexar, use - para el archivo de entrada:

play_cell GoldFinger.iso 1 1 6 | spuunmux -

ADVERTENCIAS

Ninguna.

ERRORES

Ninguno.
