Documentación de la función/subrutina

subroutine spoequb (integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real scond, real amax, integer info)

SPOEQUB

Propósito:

!>
!> SPOEQUB calcula factores de escala de filas y columnas destinados a equilibrar una
!> matriz simétrica definida positiva A y reducir su número de condición
!> (con respecto a la dos-norma). S contiene los factores de escala,
!> S(i) = 1/sqrt(A(i,i)), elegidos para que la matriz escalada B con
!> elementos B(i,j) = S(i)*A(i,j)*S(j) tenga unos en la diagonal. Esta
!> elección de S pone el número de condición de B dentro de un factor N del
!> número de condición más pequeño posible sobre todos los escalados diagonales
!> posibles.
!>
!> Esta rutina difiere de SPOEQU al restringir los factores de escala
!> a una potencia de la base. Salvo desbordamiento y subdesbordamiento, escalar por
!> estos factores no introduce errores de redondeo adicionales. Sin embargo, las
!> entradas diagonales escaladas ya no son aproximadamente 1 sino que yacen
!> entre sqrt(radix) y 1/sqrt(radix).
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          La matriz simétrica definida positiva N por N cuyos factores de escala
!>          se van a calcular. Solo se referencian los elementos diagonales de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

S

!>          S es array REAL, dimension (N)
!>          Si INFO = 0, S contiene los factores de escala para A.
!>

SCOND

!>          SCOND es REAL
!>          Si INFO = 0, S contiene la razón del S(i) más pequeño al
!>          S(i) más grande. Si SCOND >= 0.1 y AMAX no es ni demasiado
!>          grande ni demasiado pequeño, no merece la pena escalar con S.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto del elemento de matriz más grande. Si AMAX está muy
!>          cerca del desbordamiento o muy cerca del subdesbordamiento, la matriz
!>          debería escalarse.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el i-ésimo elemento diagonal es no positivo.
!>
