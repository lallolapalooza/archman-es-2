NAME

spinbox - Create and manipulate 'spinbox' value spinner widgets

SYNOPSIS

spinbox pathName ?options?

STANDARD OPTIONS

DESCRIPTION

The spinbox command creates a new window (given by the pathName argument) and makes it into a spinbox widget. Additional options, described above, may be specified on the command line or in the option database to configure aspects of the spinbox such as its colors, font, and relief. The spinbox command returns its pathName argument. At the time this command is invoked, there must not exist a window named pathName, but pathName's parent must exist.

VALIDACIÓN

La validación funciona configurando la opción -validatecommand a un script que se evaluará de acuerdo con la opción -validate de la siguiente manera:

none
Por defecto. Esto significa que no se realizará ninguna validación.
focus
El -validatecommand se llamará cuando el spinbox reciba o pierda el foco.
focusin
El -validatecommand se llamará cuando el spinbox reciba el foco.
focusout
El -validatecommand se llamará cuando el spinbox pierda el foco.
key
El -validatecommand se llamará cuando el spinbox se edite.
all
El -validatecommand se llamará para todas las condiciones anteriores.

Es posible realizar sustituciones de porcentaje en los scripts -validatecommand y -invalidcommand, tal como lo haría en un script bind. Se reconocen las siguientes sustituciones:

%d
Tipo de acción: 1 para insertar, 0 para eliminar, o -1 para validación de foco, forzada o por textvariable.
%i
Índice del carácter a insertar/eliminar, si lo hay, de lo contrario -1.
%P
El valor del spinbox después de la edición. Si está configurando el widget spinbox para tener un nuevo textvariable, este será el valor de ese textvariable.
%s
El valor actual del spinbox antes de la edición.
%S
La cadena de texto que se está insertando/eliminando, si la hay. De lo contrario, es una cadena vacía.
%v
El tipo de validación actualmente establecido.
%V
El tipo de validación que activó la devolución de llamada (key, focusin, focusout, forzada).
%W
El nombre del widget spinbox.

En general, el -textvariable y el -validatecommand pueden ser peligrosos de mezclar. Se han superado todos los problemas para que el uso de -validatecommand no interfiera con el comportamiento tradicional del widget spinbox. El uso de -textvariable para fines de solo lectura nunca causará problemas. El peligro surge cuando se intenta establecer -textvariable a algo que -validatecommand no aceptaría, lo que hace que -validate se convierta en none (el -invalidcommand no se activará). Lo mismo ocurre cuando ocurre un error al evaluar el -validatecommand.

Principalmente, ocurrirá un error cuando -validatecommand o -invalidcommand encuentren un error en su script al evaluarlo o cuando -validatecommand no devuelva un valor booleano de Tcl válido. La opción -validate también se establecerá en none cuando edite el widget spinbox desde dentro de -validatecommand o -invalidcommand. Dichas ediciones anularán la que se estaba validando. Si desea editar el valor del widget durante la validación y aún tener la opción -validate establecida, debe incluir el comando

     %W config -validate %v
en el -validatecommand o -invalidcommand (desde el cual estaba editando el widget spinbox). También se recomienda no establecer un -textvariable asociado durante la validación, ya que eso puede hacer que el widget spinbox se desincronice con el -textvariable.

Además, la opción -validate se establecerá en none cuando el valor del spinbox cambie debido al ajuste de -from o -to y el -validatecommand devuelva falso. Por ejemplo,

     spinbox pathName -from 1 -to 10 -validate all -vcmd {return 0}
establecerá de hecho la opción -validate a none porque el valor predeterminado del spinbox se cambia (debido a las opciones -from y -to) a un valor no aceptado por el script de validación.

Además, se realiza una validación forzada al invocar cualquier botón de giro del spinbox. Si el script de validación devuelve falso en esta situación, la opción -validate se establecerá automáticamente en none.

COMANDO WIDGET

El comando spinbox crea un nuevo comando Tcl cuyo nombre es pathName. Este comando puede usarse para invocar varias operaciones en el widget. Tiene la siguiente forma general:

pathName option ?arg arg ...?
La option y los arg determinan el comportamiento exacto del comando.

ÍNDICES

Muchos de los comandos de widget para spinboxes toman uno o más índices como argumentos. Un índice especifica un carácter particular en la cadena del spinbox, de cualquiera de las siguientes maneras:

número
Especifica el carácter como un índice numérico, donde 0 corresponde al primer carácter de la cadena.
anchor
Indica el punto de anclaje para la selección, que se establece con los comandos de widget select from y select adjust.
end
Indica el carácter justo después del último en la cadena del spinbox. Esto equivale a especificar un índice numérico igual a la longitud de la cadena del spinbox.
insert
Indica el carácter adyacente e inmediatamente posterior al cursor de inserción.
sel.first
Indica el primer carácter de la selección. Es un error usar esta forma si la selección no está en la ventana del spinbox.
sel.last
Indica el carácter justo después del último de la selección. Es un error usar esta forma si la selección no está en la ventana del spinbox.
@número
En esta forma, número se trata como una coordenada x en la ventana del spinbox; se utiliza el carácter que abarca esa coordenada x. Por ejemplo, "@0" indica el carácter más a la izquierda en la ventana.

Se pueden usar abreviaturas para cualquiera de las formas anteriores, por ejemplo, "e" o "sel.f". En general, los índices fuera de rango se redondean automáticamente al valor legal más cercano.

SUBCOMANDOS

Los siguientes comandos son posibles para los widgets spinbox:

pathName bbox índice
Devuelve una lista de cuatro números que describen el cuadro delimitador del carácter dado por índice. Los dos primeros elementos de la lista dan las coordenadas x e y de la esquina superior izquierda del área de la pantalla que cubre el carácter (en píxeles relativos al widget) y los dos últimos elementos dan el ancho y la altura del carácter, en píxeles. El cuadro delimitador puede referirse a una región fuera del área visible de la ventana.
pathName cget opción
Devuelve el valor actual de la opción de configuración dada por opción. Opción puede tener cualquiera de los valores aceptados por el comando spinbox.
pathName configure ?opción? ?valor opción valor ...?
Consulta o modifica las opciones de configuración del widget. Si no se especifica ninguna opción, devuelve una lista que describe todas las opciones disponibles para pathName (consulte Tk_ConfigureInfo para obtener información sobre el formato de esta lista). Si se especifica opción sin valor, el comando devuelve una lista que describe la opción nombrada (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica ninguna opción). Si se especifican uno o más pares opción-valor, el comando modifica la(s) opción(es) del widget dada(s) para que tengan el(los) valor(es) dado(s); en este caso, el comando devuelve una cadena vacía. Opción puede tener cualquiera de los valores aceptados por el comando spinbox.
pathName delete primero ?último?
Elimina uno o más elementos del spinbox. Primero es el índice del primer carácter a eliminar, y último es el índice del carácter justo después del último a eliminar. Si último no se especifica, por defecto es primero+1, es decir, se elimina un solo carácter. Este comando devuelve una cadena vacía.
pathName get
Devuelve la cadena del spinbox.
pathName icursor índice
Hace que el cursor de inserción se muestre justo antes del carácter dado por índice. Devuelve una cadena vacía.
pathName identify x y
Devuelve el nombre del elemento de la ventana correspondiente a las coordenadas x e y en el spinbox. El valor de retorno es uno de: none, buttondown, buttonup, entry.

COMMANDS

pathName index index
Devuelve el índice numérico correspondiente a index.
pathName insert index string
Inserta los caracteres de string justo antes del carácter indicado por index. Devuelve una cadena vacía.
pathName invoke element
Hace que el elemento especificado, ya sea buttondown o buttonup, sea invocado, activando la acción asociada a él.
pathName scan option args
Este comando se utiliza para implementar el escaneo en los spinboxes. Tiene dos formas, dependiendo de option:
pathName scan mark x
Registra x y la vista actual en la ventana del spinbox; se utiliza en conjunción con los comandos posteriores de scan dragto. Típicamente este comando se asocia con la pulsación de un botón del ratón en el widget. Devuelve una cadena vacía.
pathName scan dragto x
Este comando calcula la diferencia entre su argumento x y el argumento x del último comando scan mark para el widget. Luego ajusta la vista hacia la izquierda o la derecha en 10 veces la diferencia en las coordenadas x. Este comando se asocia típicamente con eventos de movimiento del ratón en el widget, para producir el efecto de arrastrar el spinbox a alta velocidad a través de la ventana. El valor de retorno es una cadena vacía.
pathName selection option arg
Este comando se utiliza para ajustar la selección dentro de un spinbox. Tiene varias formas, dependiendo de option:
pathName selection adjust index
Localiza el extremo de la selección más cercano al carácter dado por index, y ajusta ese extremo de la selección para que esté en index (es decir, incluyéndolo pero sin ir más allá de index). El otro extremo de la selección se convierte en el punto de anclaje para los comandos posteriores de select to. Si la selección no está actualmente en el spinbox, entonces se crea una nueva selección para incluir los caracteres entre index y el punto de anclaje de selección más reciente, inclusive. Devuelve una cadena vacía.
pathName selection clear
Borra la selección si está actualmente en este widget. Si la selección no está en este widget, entonces el comando no tiene ningún efecto. Devuelve una cadena vacía.
pathName selection element ?element?
Establece o obtiene el elemento seleccionado actualmente. Si se especifica un elemento de botón giratorio, se mostrará presionado.
pathName selection from index
Establece el punto de anclaje de la selección justo antes del carácter dado por index. No cambia la selección. Devuelve una cadena vacía.
pathName selection present
Devuelve 1 si hay caracteres seleccionados en el spinbox, 0 si no hay nada seleccionado.
pathName selection range start end
Establece la selección para incluir los caracteres que comienzan con el índice por start y terminan con el que está justo antes de end. Si end se refiere al mismo carácter que start o a uno anterior, entonces la selección del spinbox se borra.
pathName selection to index
Si index está antes del punto de anclaje, establece la selección para los caracteres desde index hasta el punto de anclaje, sin incluirlo. Si index es el mismo que el punto de anclaje, no hace nada. Si index está después del punto de anclaje, establece la selección para los caracteres desde el punto de anclaje hasta index, sin incluirlo. El punto de anclaje se determina por el comando select from o select adjust más reciente en este widget. Si la selección no está en este widget, entonces se crea una nueva selección utilizando el punto de anclaje más reciente especificado para el widget. Devuelve una cadena vacía.
pathName set ?string?
Si se especifica string, el spinbox intentará establecerse a este valor, de lo contrario, simplemente devuelve la cadena del spinbox. Si la validación está activada, ocurrirá al establecer la cadena.
pathName validate
Este comando se utiliza para forzar una evaluación del -validatecommand independientemente de las condiciones especificadas por la opción -validate. Esto se hace estableciendo temporalmente la opción -validate a all. Devuelve 0 o 1.
pathName xview args
Este comando se utiliza para consultar y cambiar la posición horizontal del texto en la ventana del widget. Puede tomar cualquiera de las siguientes formas:
pathName xview
Devuelve una lista que contiene dos elementos. Cada elemento es una fracción real entre 0 y 1; juntos describen el tramo horizontal que es visible en la ventana. Por ejemplo, si el primer elemento es .2 y el segundo elemento es .6, el 20% del texto del spinbox está fuera de la pantalla hacia la izquierda, el 40% central es visible en la ventana, y el 40% del texto está fuera de la pantalla hacia la derecha. Estos son los mismos valores que se pasan a las barras de desplazamiento a través de la opción -xscrollcommand.
pathName xview index
Ajusta la vista en la ventana para que el carácter dado por index se muestre en el borde izquierdo de la ventana.
pathName xview moveto fraction
Ajusta la vista en la ventana para que el carácter fraction del camino a través del texto aparezca en el borde izquierdo de la ventana. Fraction debe ser una fracción entre 0 y 1.
pathName xview scroll number what
Este comando desplaza la vista en la ventana hacia la izquierda o la derecha de acuerdo con number y what. Number debe ser un entero. What debe ser units o pages o una abreviatura de uno de estos. Si what es units, la vista se ajusta hacia la izquierda o la derecha en number caracteres de ancho promedio en la pantalla; si es pages, la vista se ajusta en number pantallas completas. Si number es negativo, los caracteres más a la izquierda se vuelven visibles; si es positivo, los caracteres más a la derecha se vuelven visibles.

DEFAULT BINDINGS

Tk crea automáticamente enlaces de clase para los spinboxes que les dan el siguiente comportamiento predeterminado. En las descripciones a continuación, "palabra" se refiere a un grupo contiguo de letras, dígitos o caracteres "\_", o cualquier carácter individual que no sea estos.

[1]
Hacer clic en el botón 1 del ratón posiciona el cursor de inserción justo antes del carácter debajo del cursor del ratón, establece el foco de entrada en este widget y borra cualquier selección en el widget. Arrastrar con el botón 1 del ratón traza una selección entre el cursor de inserción y el carácter bajo el ratón.
[2]
Hacer doble clic con el botón 1 del ratón selecciona la palabra debajo del ratón y posiciona el cursor de inserción al principio de la palabra. Arrastrar después de un doble clic trazará una selección que consta de palabras completas.
[3]
Hacer triple clic con el botón 1 del ratón selecciona todo el texto en el spinbox y posiciona el cursor de inserción antes del primer carácter.
[4]
Los extremos de la selección se pueden ajustar arrastrando con el botón 1 del ratón mientras se mantiene presionada la tecla Shift; esto ajustará el extremo de la selección que estaba más cerca del cursor del ratón cuando se presionó el botón 1. Si el botón se hace doble clic antes de arrastrar, la selección se ajustará en unidades de palabras completas.
[5]
Hacer clic con el botón 1 del ratón mientras se mantiene presionada la tecla Control posicionará el cursor de inserción en el spinbox sin afectar la selección.
[6]
Si se escriben caracteres de impresión normales en un spinbox, se insertan en la posición del cursor de inserción.
[7]
La vista en el spinbox se puede ajustar arrastrando con el botón central del ratón (botón 2, o botón 3 en TkAqua). Si se hace clic en el botón central del ratón sin mover el ratón, la selección se copia en el spinbox en la posición del cursor del ratón.
[8]
Si el ratón se saca del spinbox por los lados izquierdo o derecho mientras se presiona el botón 1, el spinbox se desplazará automáticamente para hacer visible más texto (si hay más texto fuera de la pantalla en el lado donde el ratón salió de la ventana).
[9]
Las teclas Izquierda y Derecha mueven el cursor de inserción un carácter hacia la izquierda o la derecha; también borran cualquier selección en el spinbox y establecen el anclaje de la selección. Si se presiona Izquierda o Derecha con la tecla Shift presionada, entonces el cursor de inserción se mueve y la selección se extiende para incluir el nuevo carácter. Control-Izquierda y Control-Derecha mueven el cursor de inserción por palabras, y Control-Shift-Izquierda y Control-Shift-Derecha mueven el cursor de inserción por palabras y también extienden la selección. Control-b y Control-f se comportan igual que Izquierda y Derecha, respectivamente. Meta-b y Meta-f se comportan igual que Control-Izquierda y Control-Derecha, respectivamente.
[10]
La tecla Inicio, o Control-a, moverá el cursor de inserción al principio del spinbox y borrará cualquier selección en el spinbox. Shift-Inicio mueve el cursor de inserción al principio del spinbox y también extiende la selección hasta ese punto.
[11]
La tecla Fin, o Control-e, moverá el cursor de inserción al final del spinbox y borrará cualquier selección en el spinbox. Shift-Fin mueve el cursor al final y extiende la selección hasta ese punto.

spinbox(n) — Manual Page

NAME

spinbox — a widget that allows the user to enter a value from a fixed range of values

SYNOPSIS

ttk::spinbox ?options? ?value?

STANDARD OPTIONS

      -command, -cursor, -exportselection, -font, -foreground, -height, -image,
      -inheritable, -invcmd, -justify, -orient, -padX, -padY, -relief, -repeatdelay,
      -repeatinterval, -setgrid, -state, -takefocus, -textvariable, -underline,
      -use, -width

See the ttk::widget man page for details on the standard options.

WIDGET-SPECIFIC OPTIONS

-command cmd
Specifies a command to be invoked whenever the spinbox value is changed by typing or by the up/down arrows. The current value of the spinbox is passed as an argument to the command.
-increment amount
Specifies the amount to add or subtract from the current value when the up and down arrows are pressed. This defaults to 1. The type of the value should be a number.
-from first
Specifies the minimum value for the spinbox. This value must be a number.
-to last
Specifies the maximum value for the spinbox. This value must be a number.
-values valueList
Specifies a list of values that the spinbox can take. If this option is specified, the -from, -to and -increment options are ignored. The spinbox will cycle through the list of values when the up and down arrows are pressed.
-wrap boolean
Specifies whether the spinbox should wrap around. If true, moving past the end will wrap to the beginning, and moving before the beginning will wrap to the end. This defaults to false.

DESCRIPTION

The ttk::spinbox widget is a combination of a text entry widget and a pair of small buttons, that allow a user to select a value from a predefined range. The spinbox can also be used as a text entry with up and down arrows to move through a list of values.

The spinbox displays a value, which can be edited by the user. The range of editable values can be restricted using the -from, -to, -increment, and -values options.

The default behavior of the spinbox allows the user to type any value into the text entry. If the -from, -to, or -values options are specified, the spinbox will attempt to constrain the user's input to the specified range or list.

The spinbox supports the following validation commands:

  • -validate: Specifies when validation should occur. Legal values are none, focus, key, focusin, focusout, all.
  • -vcmd: Specifies the validation command. This command is invoked before the change is made. It is passed the new value as an argument. If the command returns true, the change is allowed. Otherwise, the change is disallowed.
  • -invcmd: Specifies the invalid command. This command is invoked when the validation command returns false.

VALIDATION

The spinbox widget supports the same validation mechanisms as the standard ttk::entry widget.

WIDGET COMMAND

The spinbox command can be used to query or modify the spinbox's configuration. The command may be invoked in the following ways:

spinbox cmd ?arg ...?

The following commands are available for spinbox widgets:

activate
Activates the spinbox. This is equivalent to calling the widget command with no arguments.
cget option
Returns the current value of the given configuration option.
configure ?option? ?value? ?option value ...?
Modifies the configuration options of the widget. If no option is specified, it returns a list describing all of the widget's options. If one option is specified, it returns the value of that option.
delete first ?last?
Deletes the characters from index first to index last (inclusive). If last is not specified, it defaults to first. Index representation is the same as for the ttk::entry widget.
get
Returns the current text in the spinbox.
icursor index
Moves the insertion cursor to the position specified by index. Returns the actual index of the insertion cursor.
insert index string
Inserts string at the position specified by index. Returns the actual index of the insertion cursor.
scan cmd ?arg ...?
Controls the automatic scanning, used when the mouse button is held down over the spinbox buttons. cmd can be dragto or mark.
selection cmd ?arg ...?
Controls the selection within the spinbox. cmd can be clear, copy, cut, from, insert, range, select, to.
validate
Forces validation of the current content of the spinbox. Returns true if the content is valid, false otherwise.
xview ?args?
Provides the standard view control mechanism for managing the visible portion of the spinbox's text. See the ttk::entry man page for details.

DEFAULT BINDINGS

The spinbox widget has the following default bindings:

[1]
The mouse button 1 press and release events bind to the up and down arrows respectively. Pressing either arrow button will move the insertion cursor up or down by the amount specified by the -increment option, or cycle through the values specified by the -values option.
[2]
The Left, Right, Home, End, PageUp, and PageDown keys are bound to move the insertion cursor within the spinbox.
[3]
The Backspace, Delete, Control-d, Control-h, Meta-d keys are bound to delete characters or words within the spinbox.
[4]
The Control-k key is bound to delete all characters to the right of the insertion cursor.
[5]
The Control-t key is bound to transpose the two characters to the right of the insertion cursor.
[6]
The Control-y key is bound to insert the contents of the clipboard at the position of the insertion cursor.
[7]
The Control-/ key is bound to select all the text in the spinbox.
[8]
The Control-\ key is bound to clear any selection in the spinbox.
[9]
The F16 (Copy) or Meta-w keys are bound to copy the selection to the clipboard.
[10]
The F20 (Cut) or Control-w keys are bound to cut the selection to the clipboard and delete the selection.
[11]
The F18 (Paste) or Control-y keys are bound to insert the contents of the clipboard at the position of the insertion cursor.
[12]
The Select key and Control-Space set the selection anchor to the position of the insertion cursor. They do not affect the current selection. Shift-Select and Control-Shift-Space adjust the selection to the current position of the insertion cursor, selecting from the anchor to the insertion cursor if there was not any selection previously.
[13]
Control-/ selects all the text in the spinbox.
[14]
Control-\ clears any selection in the spinbox.
[15]
The F16 key (labelled Copy on many Sun workstations) or Meta-w copies the selection in the widget to the clipboard, if there is a selection.
[16]
The F20 key (labelled Cut on many Sun workstations) or Control-w copies the selection in the widget to the clipboard and deletes the selection. If there is no selection in the widget then these keys have no effect.
[17]
The F18 key (labelled Paste on many Sun workstations) or Control-y inserts the contents of the clipboard at the position of the insertion cursor.
[18]
The Delete key deletes the selection, if there is one in the spinbox. If there is no selection, it deletes the character to the right of the insertion cursor.
[19]
The BackSpace key and Control-h delete the selection, if there is one in the spinbox. If there is no selection, it deletes the character to the left of the insertion cursor.
[20]
Control-d deletes the character to the right of the insertion cursor.
[21]
Meta-d deletes the word to the right of the insertion cursor.
[22]
Control-k deletes all the characters to the right of the insertion cursor.
[23]
Control-t reverses the order of the two characters to the right of the insertion cursor.

If the spinbox is disabled using the -state option, then the spinbox's view can still be adjusted and text in the spinbox can still be selected, but no insertion cursor will be displayed and no text modifications will take place.

The behavior of spinboxes can be changed by defining new bindings for individual widgets or by redefining the class bindings.
