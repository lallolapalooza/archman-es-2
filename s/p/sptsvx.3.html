DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subrutina sptsvx (carácter fact, entero n, entero nrhs, real, dimensión( * ) d, real, dimensión( * ) e, real, dimensión( * ) df, real, dimensión( * ) ef, real, dimensión( ldb, * ) b, entero ldb, real, dimensión( ldx, * ) x, entero ldx, real rcond, real, dimensión( * ) ferr, real, dimensión( * ) berr, real, dimensión( * ) work, entero info)

SPTSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PT

Propósito:

!>
!> SPTSVX utiliza la factorización A = L*D*L**T para calcular la solución
!> a un sistema real de ecuaciones lineales A*X = B, donde A es una matriz
!> tridiagonal simétrica definida positiva de N por N y X y B son
!> matrices de N por NRHS.
!>
!> También se proporcionan cotas de error para la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', la matriz A se factoriza como A = L*D*L**T, donde L
!>    es una matriz bidiagonal inferior unitaria y D es diagonal. La
!>    factorización también puede considerarse de la forma
!>    A = U**T*D*U.
!>
!> 2. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina devuelve INFO = i. De lo contrario, la forma
!>    factorizada de A se utiliza para estimar el número de condición de la
!>    matriz A. Si la inversa del número de condición es menor que la
!>    precisión de la máquina, se devuelve INFO = N+1 como advertencia,
!>    pero la rutina continúa para resolver para X y calcular las cotas
!>    de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la matriz solución
!>    calculada y calcular cotas de error y estimaciones de error hacia
!>    atrás para la misma.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A se ha suministrado
!>          en la entrada o no.
!>          = 'F':  En la entrada, DF y EF contienen la forma factorizada de A.
!>                  D, E, DF y EF no se modificarán.
!>          = 'N':  La matriz A se copiará en DF y EF y
!>                  se factorizará.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

D

!>          D es un array REAL de dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal A.
!>

E

!>          E es un array REAL de dimensión (N-1)
!>          Los n-1 elementos subdiagonales de la matriz tridiagonal A.
!>

DF

!>          DF es un array REAL de dimensión (N)
!>          Si FACT = 'F', entonces DF es un argumento de entrada y en la entrada
!>          contiene los n elementos diagonales de la matriz diagonal D
!>          de la factorización L*D*L**T de A.
!>          Si FACT = 'N', entonces DF es un argumento de salida y en la salida
!>          contiene los n elementos diagonales de la matriz diagonal D
!>          de la factorización L*D*L**T de A.
!>

EF

!>          EF es un array REAL de dimensión (N-1)
!>          Si FACT = 'F', entonces EF es un argumento de entrada y en la entrada
!>          contiene los n-1 elementos subdiagonales del factor unitario
!>          bidiagonal L de la factorización L*D*L**T de A.
!>          Si FACT = 'N', entonces EF es un argumento de salida y en la salida
!>          contiene los n-1 elementos subdiagonales del factor unitario
!>          bidiagonal L de la factorización L*D*L**T de A.
!>

B

!>          B es un array REAL de dimensión (LDB,NRHS)
!>          La matriz del lado derecho B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array REAL de dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La condición recíproca de la matriz A. Si RCOND
!>          es menor que la precisión de la máquina (en particular, si
!>          RCOND = 0), la matriz es singular para la precisión de trabajo.
!>          Esta condición se indica mediante un código de retorno INFO > 0.
!>

FERR

!>          FERR es un array REAL de dimensión (NRHS)
!>          La cota de error hacia adelante para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento
!>          más grande en X(j).
!>

BERR

!>          BERR es un array REAL de dimensión (NRHS)
!>          El error relativo componente a componente hacia atrás de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en cualquier
!>          elemento de A o B que hace que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array REAL de dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  el menor principal principal de orden i de A
!>                       no es positivo, por lo que la factorización no pudo
!>                       completarse y la solución no se ha calculado. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión de la
!>                       máquina, lo que significa que la matriz es singular
!>                       para la precisión de trabajo. Sin embargo, la
!>                       solución y las cotas de error se calculan porque
!>                       hay una serie de situaciones en las que la
!>                       solución calculada puede ser más precisa que el
!>                       valor de RCOND sugeriría.
!>
