SPHINX-QUICKSTART(1) Sphinx SPHINX-QUICKSTART(1)

NOMBRE

sphinx-quickstart - Generador de plantillas de documentación de Sphinx

SINOPSIS

sphinx-quickstart

DESCRIPCIÓN

sphinx-quickstart es una herramienta interactiva que hace algunas preguntas sobre tu proyecto y luego genera un directorio de documentación completo y un archivo Makefile de muestra para usar con sphinx-build(1).

OPCIONES

-q, --quiet
Modo silencioso que omite el asistente interactivo para especificar opciones. Esta opción requiere las opciones -p, -a y -v.
-h, --help, --version
Muestra el resumen de uso o la versión de Sphinx.

Opciones de Estructura

--sep
Si se especifica, separa los directorios de origen y compilación.
--no-sep
Si se especifica, crea el directorio de compilación dentro del directorio de origen.
--dot=DOT
Dentro del directorio raíz, se crearán dos directorios más; "_templates" para plantillas HTML personalizadas y "_static" para hojas de estilo personalizadas y otros archivos estáticos. Puedes ingresar otro prefijo (como ".") para reemplazar el guion bajo.

Opciones Básicas del Proyecto

-p PROJECT, --project=PROJECT
Se establecerá el nombre del proyecto. (ver project).
-a AUTHOR, --author=AUTHOR
Nombres de los autores. (ver copyright).
-v VERSION
Versión del proyecto. (ver version).
-r RELEASE, --release=RELEASE
Edición del proyecto. (ver release).
-l LANGUAGE, --language=LANGUAGE
Idioma de los documentos. (ver language).
--suffix=SUFFIX
Sufijo de archivo de origen. (ver source_suffix).
--master=MASTER
Nombre del documento principal. (ver root_doc).

Opciones de Extensión

--ext-autodoc
Habilita la extensión sphinx.ext.autodoc.
--ext-doctest
Habilita la extensión sphinx.ext.doctest.
--ext-intersphinx
Habilita la extensión sphinx.ext.intersphinx.
--ext-todo
Habilita la extensión sphinx.ext.todo.
--ext-coverage
Habilita la extensión sphinx.ext.coverage.
--ext-imgmath
Habilita la extensión sphinx.ext.imgmath.
--ext-mathjax
Habilita la extensión sphinx.ext.mathjax.
--ext-ifconfig
Habilita la extensión sphinx.ext.ifconfig.
--ext-viewcode
Habilita la extensión sphinx.ext.viewcode.
--ext-githubpages
Habilita la extensión sphinx.ext.githubpages.
--extensions=EXTENSIONS
Habilita extensiones arbitrarias.

Opciones de Creación de Makefile y Batchfile

--use-make-mode (-m), --no-use-make-mode (-M)
Makefile/make.bat utiliza (o no utiliza) el modo make. El valor predeterminado es usar, lo que genera un Makefile/make.bat más conciso.

Cambiado en la versión 1.5: el modo make es el valor predeterminado.

Cambiado en la versión 7.3: El soporte para deshabilitar el modo make será eliminado en Sphinx 8.

Eliminado en la versión 8.0: La opción --no-use-make-mode. La opción --use-make-mode ya no tiene efecto.

--makefile, --no-makefile
Crea (o no crea) el makefile.
--batchfile, --no-batchfile
Crea (o no crea) el batchfile

Plantillas de proyecto

Añadido en la versión 1.5: Opciones de plantillas de proyecto para sphinx-quickstart

-t, --templatedir=TEMPLATEDIR
Directorio de plantillas para los archivos de plantilla. Puedes modificar las plantillas de los archivos de proyecto de sphinx generados por quickstart. Se permiten los siguientes archivos de plantilla Jinja2:
  • root_doc.rst.jinja
  • conf.py.jinja
  • Makefile.jinja
  • Makefile.new.jinja
  • make.bat.jinja
  • make.bat.new.jinja

En detalle, por favor consulta los archivos de plantilla del sistema que Sphinx proporciona. (sphinx/templates/quickstart)

-d NAME=VALUE
Define una variable de plantilla

    sphinx-quickstart(1)

    NOMBRE

    sphinx-quickstart - asistente para crear una estructura de proyecto Sphinx

    SINOPSIS

    sphinx-quickstart [-h|--help] [-q|--quiet] [-V|--version] [path]

    DESCRIPCIÓN

    sphinx-quickstart es un script que crea la estructura básica de un proyecto Sphinx. Sphinx es un sistema de documentación que utiliza reStructuredText (reST) para escribir la documentación y genera salida en varios formatos (HTML, PDF, man pages, etc.).

    El script te guiará a través de una serie de preguntas para configurar tu proyecto, como:

    • El directorio de destino para el proyecto.
    • El nombre del proyecto.
    • El nombre del autor o autores.
    • La versión del proyecto.
    • El prefijo para los archivos fuente (normalmente `_`).
    • Si se deben crear archivos de ejemplo.
    • Si se deben crear subdirectorios para incluir archivos y imágenes.
    • Si se deben habilitar extensiones comunes de Sphinx.

    Una vez que el script ha recopilado la información necesaria, creará la estructura de directorios y los archivos de configuración básicos (como `conf.py` y `index.rst`) para tu proyecto Sphinx.

    OPCIONES

    -h, --help: Muestra un mensaje de ayuda y sale.

    -q, --quiet: Ejecuta el script en modo silencioso, sin hacer preguntas interactivas. Utiliza los valores predeterminados o los proporcionados por otras opciones.

    -V, --version: Muestra la versión de Sphinx y sale.

    path: El directorio donde se creará el proyecto Sphinx. Si no se proporciona, se te pedirá que introduzcas la ruta.

    EJEMPLOS

    Para crear un nuevo proyecto Sphinx en el directorio actual y responder a las preguntas interactivamente:

    sphinx-quickstart

    Para crear un nuevo proyecto Sphinx en el directorio `mi_proyecto` y responder a las preguntas interactivamente:

    sphinx-quickstart mi_proyecto

    Para crear un nuevo proyecto Sphinx en el directorio `mi_proyecto` utilizando valores predeterminados (modo silencioso):

    sphinx-quickstart --quiet mi_proyecto

    ARCHIVOS

    conf.py
    El archivo de configuración principal de Sphinx, donde se establecen muchas opciones del proyecto.
    index.rst
    El archivo de entrada principal para la documentación. Suele contener la tabla de contenidos principal.
    Makefile y make.bat
    Scripts para facilitar la compilación de la documentación (por ejemplo, para generar HTML o PDF).
