NOMBRE

spline - interpola conjuntos de datos usando splines con tensión

SINOPSIS

spline [ opciones ] [ archivos ]

DESCRIPCIÓN

spline lee conjuntos de datos de la entrada estándar o de uno o más archivos, y ajusta una curva suave (una "spline") a cada conjunto de datos. Se escribe una versión interpolada de cada conjunto de datos, que consiste en puntos de la curva suave, a la salida estándar.

A menos que se utilicen las opciones -a o -A (ver más abajo), cada conjunto de datos debe ser una secuencia de valores para una función valorada en vector de una sola variable escalar. Es decir, cada conjunto de datos debe ser una secuencia de puntos de datos, dados como valores alternos de t e y. t es una variable independiente escalar e y es una variable dependiente valorada en vector. La dimensionalidad de y se especifica con la opción -d (la dimensionalidad por defecto es 1). Entre cada punto de datos y el siguiente, t debe aumentar.

Un archivo de entrada puede contener más de un conjunto de datos. Si un archivo de entrada está en formato ASCII (el predeterminado), sus conjuntos de datos deben estar separados por líneas en blanco. Los valores t e y de los puntos de datos en cada conjunto de datos pueden organizarse arbitrariamente, siempre que estén separados por espacios en blanco. Además de los conjuntos de datos, un archivo de entrada puede contener cualquier número de líneas de comentarios, que deben comenzar con el carácter de comentario `#'. Las líneas de comentarios se ignoran. No se tratan como en blanco, es decir, no interrumpen un conjunto de datos en curso.

Las opciones y los nombres de archivo pueden intercalarse en la línea de comandos, pero las opciones se procesan antes de leer los nombres de archivo. Si se ve --, se interpreta como el final de las opciones. Si no se especifican nombres de archivo, o si se encuentra el nombre de archivo -, se lee la entrada estándar.

El tipo de interpolación y el formato de los archivos de entrada y salida se pueden seleccionar mediante opciones de línea de comandos.

OPCIONES

Opciones relacionadas con la interpolación

-f

--filtro
Utiliza un algoritmo de interpolación local (el algoritmo cúbico de Bessel), de modo que spline pueda usarse como filtro en tiempo real. La pendiente de la curva interpoladora en cada punto de un conjunto de datos se elegirá ajustando una función cuadrática a ese punto y a los dos puntos adyacentes del conjunto de datos. Si se especifica -f, entonces la opción -t, aunque opcional de lo contrario, debe usarse también. Además, si se especifica -f, entonces las opciones -k, -p y -T no pueden usarse.
Si -f *no* se especifica, entonces se usará el algoritmo de interpolación predeterminado (global).
-k k

--condición-límite k
Establece el parámetro de condición límite para cada spline construida en k. (El valor predeterminado es 1.0.) En cada uno de sus componentes, la spline satisfará las dos condiciones límite y"[0]=ky"[1] e y"[n]=ky"[n-1]. Aquí y[0] e y[1] significan los valores de un componente especificado de la variable dependiente valorada en vector y en los dos primeros puntos de un conjunto de datos, y y[n-1] e y[n] los valores en los dos últimos puntos. Establecer k a cero producirá una spline "natural", es decir, una que tiene curvatura cero en los dos extremos del conjunto de datos. La opción -k no puede usarse si se especifica -f o -p.
-n n

--número-de-intervalos n
Subdivide el intervalo sobre el cual ocurre la interpolación en n subintervalos. El número de puntos de datos calculados y escritos en la salida será n+1. El valor predeterminado para n es 100.
-p

--periódico
Construye una spline periódica. Si se especifica esta opción, los valores y para el primer y el último punto de cada conjunto de datos deben ser iguales. Las opciones -f y -k no pueden usarse si se especifica -p.
-T tensión

--tensión tensión
Cada curva interpoladora será una spline con tensión. Esta opción establece el valor de tensión (el valor predeterminado es 0.0).
Si tensión es igual a cero, la curva será una spline cúbica a trozos. Aumentar la tensión por encima de cero hace que la curva sea más "cerrada" y reduce la probabilidad de puntos de inflexión inesperados. Esto se debe a que entre cada par de puntos sucesivos de un conjunto de datos, la curva satisfará la ecuación diferencial de cuarto orden y""=sgn(tensión)*(tensión^2)y" en cada uno de sus componentes. A medida que tensión aumenta hasta el infinito positivo, convergerá a una línea poligonal. La opción -T no puede usarse si se especifica -f.
-t tmin tmax [tsaltos]

--tsaltos tmin tmax [tsaltos]
Para cada conjunto de datos, establezca el intervalo sobre el cual ocurre la interpolación entre tmin y tmax. Si no se especifica tsaltos, el intervalo se dividirá en el número de subintervalos especificado por la opción -n.
Si la opción -t no se usa, el intervalo sobre el cual ocurre la interpolación será el rango completo de la variable independiente en el conjunto de datos. La opción -t siempre debe usarse si se usa la opción -f para solicitar un comportamiento similar a un filtro (ver arriba).

Opciones relacionadas con el formato

-d dimension

--ydimension dimension
Establece la dimensionalidad de la variable dependiente y en los archivos de entrada y salida a dimension. La dimensión predeterminada es 1.
-I formato-datos

--formato-entrada formato-datos
Establece el formato de datos para el(los) archivo(s) de entrada a formato-datos, que puede ser uno de los siguientes.
a
ASCII formato (predeterminado). Cada archivo es una secuencia de números de punto flotante, interpretados como las coordenadas t e y de los puntos de datos sucesivos en un conjunto de datos. Si y tiene d dimensiones, habrá d+1 números por punto. Las coordenadas t e y de un punto no tienen por qué aparecer en la misma línea, y los puntos no tienen por qué aparecer en líneas diferentes. Pero si ocurre una línea en blanco (es decir, se ven dos saltos de línea sucesivos), se interpreta como el final de un conjunto de datos y el comienzo del siguiente.
f
Formato binario de precisión simple. Cada archivo es una secuencia de números de punto flotante, interpretados como las coordenadas t e y de los puntos de datos sucesivos en un conjunto de datos. Si y tiene d dimensiones, habrá d+1 números por punto. Los conjuntos de datos sucesivos están separados por una única ocurrencia de la cantidad FLT_MAX, que es el número de punto flotante de precisión simple más grande posible. En la mayoría de las máquinas, esto es aproximadamente 3.4x10^38.

NAME

spline

interpolate data using cubic splines

SYNOPSIS

spline [-] [-a [step_size [lower_limit]]] [-d d] [-f format] [-F] [-i] [-I format] [-n num_out] [-o outfile] [-O format] [-p tension] [-P significant-digits] [-r] [-s] [-t tension] [-x x] [-y y] [infile]

spline [--help] [--version]

DESCRIPTION

The spline program interpolates a dataset using cubic splines. It reads data from infile (standard input if none is given), and writes the interpolated data to outfile (standard output if none is given).

The data consists of a sequence of points, each specified by one or more floating-point numbers. The first number is the independent variable, usually denoted by t. The subsequent numbers are the dependent variable, usually denoted by y. This y may be multi-dimensional, up to d dimensions.

The program can read data in several formats, and can write data in several formats. It can also generate points automatically, and can generate more points than are present in the input, to provide a smoother interpolation.

Input/Output Formats

a
ASCII format. Each line is a point, with numbers separated by whitespace. The first number is t, and the subsequent numbers are the coordinates of y. If y is d-dimensional, there will be d+1 numbers for each point. This is the default format for both input and output.
d
Double precision ASCII format. Same as `a', but the numbers are printed with full double precision.
f
Float ASCII format. Same as `a', but the numbers are printed with single precision.
-D

--double-precision
Output floating point numbers in double precision. This takes effect only if the output file is written in `a' format, i.e., in ASCII. By default, output is in single precision.
-I data-format

--input-format data-format
Set the data format for the input file to be data-format. The default is `a', i.e., ASCII format.
q
Single occurrence of DBL_MAX (see below). This format is not supported for input.
-Q

--quiet
Suppress the output of informational messages, such as the number of input and output points.
i
Integer binary format. Each file is a sequence of integers, interpreted as the t and y coordinates of the successive data points in a dataset. If y is d-dimensional, there will be d+1 numbers for each point. Successive datasets are separated by a single occurrence of the quantity INT_MAX, which is the largest possible integer. On most machines this is 2^31-1.
-a [step_size [lower_limit]]

--auto-abscissa [step_size [lower_limit]]
Automatically generate values for t, the independent variable (the default values of step_size and lower_limit are 1.0 and 0.0, respectively).
Irrespective of data format (`a', `f', `d', or `i'), this option specifies that the values of t are missing from the input file: the dataset(s) to be read contain only values of y, the dependent variable. So if y is d-dimensional, there will be only d numbers for each point. The increment from each t value to the next will be step_size, and the first t value will be lower_limit. This option is useful, e.g., when interpolating curves rather than functions.
-A

--auto-dist-abscissa
Automatically generate values for t, the independent variable. This is a variant form of the -a option. The increment from each t value to the next will be the distance in d-dimensional space between the corresponding y values, and the first t value will be 0.0. That is, t will be "polygonal arclength". This option is useful when interpolating curves rather than functions.
-O data-format

--output-format data-format
Set the data format for the output file to be data-format. The interpretation of data-format is the same as for the -I option. The default is `a', i.e., ASCII format.
-P significant-digits

--precision significant-digits
Set the numerical precision for the t and y values in the output file to be significant-digits. This takes effect only if the output file is written in `a' format, i.e., in ASCII. significant-digits must be a positive integer (the default is 6).
-s

--suppress-abscissa
Omit the independent variable t from the output file; for each point, supply only the dependent variable y. If y is d-dimensional, there will be only d numbers for each point, not d+1. This option is useful when interpolating curves rather than functions.

Informational Options

--help
Print a list of command-line options, and exit.
--version
Print the version number of spline and the plotting utilities package, and exit.

EXAMPLES

Typing

echo 0 0 1 1 2 0 | spline

will produce on standard output an interpolated dataset consisting of 101 data points. If graphed, this interpolated dataset will yield a parabola.

It is sometimes useful to interpolate between a sequence of arbitrarily placed points in d-dimensional space, i.e., to "spline a curve" rather than a function. The -a and -s options are used for this. For example,

echo 0 0 1 0 1 1 0 1 | spline -d 2 -a -s

will produce on standard output a 101-point dataset that interpolates between the four points (0,0), (1,0), (1,1), and (0,1). The -d 2 option specifies that the dependent variable y is two-dimensional. The -a option specifies that the t values are missing from the input and should be automatically generated. The -s option specifies that the t values should be stripped from the output.

AUTHORS

The algorithms for constructing splines under tension are similar to those used in the FITPACK subroutine library, and are ultimately due to Alan K. Cline (cline@cs.utexas.edu).
