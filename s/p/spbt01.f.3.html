Documentación de Función/Subrutina

subrutina spbt01 (character uplo, integer n, integer kd, real, dimension( lda, * ) a, integer lda, real, dimension( ldafac, * ) afac, integer ldafac, real, dimension( * ) rwork, real resid)

SPBT01

Propósito:

!>
!> SPBT01 reconstruye una matriz de banda simétrica definida positiva A a partir de
!> su factorización L*L' o U'*U y calcula el residuo
!>    norm( L*L' - A ) / ( N * norm(A) * EPS ) o
!>    norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> donde EPS es la epsilon de máquina, L' es la transpuesta conjugada de
!> L, y U' es la transpuesta conjugada de U.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de super-diagonales de la matriz A si UPLO = 'U',
!>          o el número de sub-diagonales si UPLO = 'L'.  KD >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          La matriz de banda simétrica original A.  Si UPLO = 'U', la
!>          parte triangular superior de A se almacena como una matriz de banda; si
!>          UPLO = 'L', la parte triangular inferior de A se almacena.  Las
!>          columnas del triángulo apropiado se almacenan en las columnas
!>          de A y las diagonales del triángulo se almacenan en las filas
!>          de A.  Ver SPBTRF para más detalles.
!>

LDA

!>          LDA es INTEGER.
!>          La dimensión principal del array A.  LDA >= max(1,KD+1).
!>

AFAC

!>          AFAC es un array REAL, de dimensión (LDAFAC,N)
!>          La forma factorizada de la matriz A.  AFAC contiene el factor
!>          L o U de la factorización L*L' o U'*U en formato de almacenamiento de banda,
!>          tal como se calcula por SPBTRF.
!>

LDAFAC

!>          LDAFAC es INTEGER
!>          La dimensión principal del array AFAC.
!>          LDAFAC >= max(1,KD+1).
!>

RWORK

!>          RWORK es un array REAL, de dimensión (N)
!>

RESID

!>          RESID es REAL
!>          Si UPLO = 'L', norm(L*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U'*U - A) / ( N * norm(A) * EPS )
!>
