NOMBRE

spamassassin - script de filtrado frontal simple para SpamAssassin

SINOPSIS

spamassassin [opciones] [ < mensaje_correo | ruta ... ]

spamassassin -d [ < mensaje_correo | ruta ... ]

spamassassin -r [ < mensaje_correo | ruta ... ]

spamassassin -k [ < mensaje_correo | ruta ... ]

spamassassin -W|-R [ < mensaje_correo | ruta ... ]

Opciones:

-L, --local                       Solo pruebas locales (sin pruebas en línea)
-r, --report                      Reportar mensaje como spam
-k, --revoke                      Revocar mensaje como spam
-d, --remove-markup               Eliminar marcado de spam de un mensaje
-C ruta, --configpath=ruta, --config-file=ruta
                                  Ruta al directorio de configuración estándar
--siteconfigpath=ruta             Ruta para configuraciones del sitio
                                  (def: /etc/mail/spamassassin)
--cf='línea de configuración'                Línea adicional de configuración
--pre='línea de configuración'               Línea adicional de ".pre" (prepuesta a la configuración)
-x, --nocreate-prefs              No crear archivo de preferencias de usuario
-e, --exit-code                   Salir con un código de salida distinto de cero si el
                                  mensaje probado era spam
--mbox                            leer mensajes en formato mbox
--mbx                             leer mensajes en formato UW mbx
-t, --test-mode                   Pasa el mensaje y añade un informe extra
                                  al final
--lint                            Revisar el conjunto de reglas: reportar errores de sintaxis
-W, --add-to-welcomelist          Añadir direcciones en el correo a la lista de bienvenida persistente
--add-to-blocklist                Añadir direcciones en el correo a la lista de bloqueo persistente
-R, --remove-from-welcomelist     Eliminar todas las direcciones encontradas en el correo de la
                                  lista de direcciones persistente
--add-addr-to-welcomelist=dir       Añadir dir a la lista de bienvenida persistente
--add-addr-to-blocklist=dir       Añadir dir a la lista de bloqueo persistente
--remove-addr-from-welcomelist=dir Eliminar dir de la lista de bienvenida persistente
-u nombre_usuario, --username=nombre_usuario  Anular el nombre de usuario tomado del entorno de ejecución
                                  utilizado con SQL
-4 --ipv4only, --ipv4-only, --ipv4 Usar IPv4, deshabilitar el uso de IPv6 para DNS, etc.
-6                                Usar IPv6, deshabilitar el uso de IPv4 siempre que sea posible
--progress                        Mostrar barra de progreso
-D, --debug [área,...]            Mostrar mensajes de depuración
-V, --version                     Mostrar versión
-h, --help                        Mostrar mensaje de uso

DESCRIPCIÓN

spamassassin es un filtro frontal simple para SpamAssassin.

Utilizando la base de reglas de SpamAssassin, emplea una amplia gama de pruebas heurísticas sobre las cabeceras del correo y el texto del cuerpo para identificar "spam", también conocido como correo masivo no solicitado. Una vez identificado, el correo se etiqueta como spam para su posterior filtrado utilizando la aplicación de agente de usuario de correo propia del usuario.

Las operaciones de etiquetado predeterminadas que se realizan se detallan en "ETIQUETADO" en spamassassin.

Por defecto, los mensajes se leen desde STDIN (< mensaje_correo), o desde archivos y directorios especificados (ruta ...). Se asume que STDIN y los archivos están en formato de archivo, con un solo mensaje por archivo. Se asume que los directorios están en un formato donde cada archivo en el directorio contiene un solo mensaje (los directorios no se recorren recursivamente y se omiten los nombres de archivo que contienen espacios en blanco o que comienzan con "." o ","). Las opciones --mbox y --mbx pueden anular el formato asumido, consulte la información de OPCIÓN correspondiente a continuación.

Los archivos comprimidos con gzip/bzip2/xz/lz4/lzip/lzo se descomprimen automáticamente. Consulte "Mail::SpamAssassin::ArchiveIterator" para más detalles.

Tenga en cuenta que SpamAssassin no está diseñado para escanear mensajes muy grandes. No se deben alimentar mensajes de más de ~10-20 MB a SpamAssassin, ya que el consumo de memoria aumentará rápidamente.

OPCIONES

-e, --error-code, --exit-code
Salir con un código de error distinto de cero si se determina que el mensaje es spam.
-h, --help
Mostrar mensaje de ayuda y salir.
-V, --version
Mostrar versión y salir.
-t, --test-mode
Modo de prueba. Pasar el mensaje y añadir un informe extra. Tenga en cuenta que el texto del informe asume que el mensaje es spam, ya que en uso normal solo es visible en ese caso. Preste atención a la puntuación en su lugar.

Si ejecuta esto con -d, primero se eliminará el marcado de SpamAssassin del mensaje antes de probarlo.

-r, --report
Reportar este mensaje como spam verificado manualmente. Esto enviará el mensaje de correo leído desde STDIN a varias bases de datos de bloqueo de spam. Actualmente, estas son Distributed Checksum Clearinghouse "https://www.dcc-servers.net/dcc/", Pyzor "https://www.pyzor.org/", Vipul's Razor "http://razor.sourceforge.net/", y SpamCop "https://www.spamcop.net/".

Si el mensaje contiene marcado de SpamAssassin, el marcado se eliminará automáticamente antes de enviarlo. Los módulos de soporte para DCC, Pyzor y Razor deben estar instalados para que el spam sea reportado a cada servicio. Los informes de SpamCop tendrán mayor efecto si se registra y se configura la opción "spamcop_to_address".

El mensaje también se enviará a los sistemas de aprendizaje de SpamAssassin; actualmente este es el sistema interno de filtrado estadístico bayesiano (las reglas BAYES). (Tenga en cuenta que si simplemente desea realizar aprendizaje estadístico y no desea reportar correo a terceros, debería usar directamente el comando "sa-learn" en su lugar).

-k, --revoke
Revocar este mensaje. Esto revocará el mensaje de correo leído desde STDIN de varias bases de datos de bloqueo de spam. Actualmente, estas son Vipul's Razor.

El soporte de revocación para Distributed Checksum Clearinghouse, Pyzor y SpamCop no está disponible actualmente.

Si el mensaje contiene marcado de SpamAssassin, el marcado se eliminará automáticamente antes de enviarlo. Los módulos de soporte para Razor deben estar instalados para que el spam sea revocado del servicio.

El mensaje también se enviará como 'ham' (no spam) a los sistemas de aprendizaje de SpamAssassin; actualmente este es el sistema interno de filtrado estadístico bayesiano (las reglas BAYES). (Tenga en cuenta que si simplemente desea realizar aprendizaje estadístico y no desea reportar correo a terceros, debería usar directamente el comando "sa-learn" en su lugar).

--lint
Comprueba la sintaxis (lint) del conjunto de reglas y archivos de configuración, reportando erratas y reglas que no compilan correctamente. Sale con 0 si no hay errores, o mayor que 0 si se encuentran errores.
-W, --add-to-welcomelist
Anteriormente --add-to-whitelist, que funcionará indistintamente hasta la versión 4.1.

Añade todas las direcciones de correo electrónico, en las cabeceras y el cuerpo del mensaje de correo leído desde STDIN, a una lista de bienvenida de direcciones persistente. Tenga en cuenta que debe estar ejecutando "spamassassin" o "spamd" con un plugin de lista de direcciones persistente habilitado para que esto funcione.

--add-to-blocklist
Anteriormente --add-to-blacklist, que funcionará indistintamente hasta la versión 4.1.

Añade todas las direcciones de correo electrónico, en las cabeceras y el cuerpo del mensaje de correo leído desde STDIN, a la lista de bloqueo de direcciones persistente. Tenga en cuenta que debe estar ejecutando "spamassassin" o "spamd" con una lista de direcciones persistente habilitada para que esto funcione.

-R, --remove-from-welcomelist
Anteriormente --remove-from-whitelist, que funcionará indistintamente hasta la versión 4.1.

Elimina todas las direcciones de correo electrónico, en las cabeceras y el cuerpo del mensaje de correo leído desde STDIN, de la lista de bienvenida de direcciones persistente. Tenga en cuenta que debe estar ejecutando "spamassassin" o "spamd" con un plugin de lista de direcciones persistente habilitado para que esto funcione.
