subrutina recursiva spotrf2 (character uplo, integer n, real, dimension( lda, * ) a, integer lda, integer info)

SPOTRF2

Propósito:

!>
!> SPOTRF2 calcula la factorización de Cholesky de una matriz real simétrica
!> definida positiva A utilizando el algoritmo recursivo.
!>
!> La factorización tiene la forma
!>    A = U**T * U,  si UPLO = 'U', o
!>    A = L  * L**T,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es triangular inferior.
!>
!> Esta es la versión recursiva del algoritmo. Divide
!> la matriz en cuatro submatrices:
!>
!>        [  A11 | A12  ]  donde A11 es n1 por n1 y A22 es n2 por n2
!>    A = [ -----|----- ]  con n1 = n/2
!>        [  A21 | A22  ]       n2 = n-n1
!>
!> La subrutina se llama a sí misma para factorizar A11. Actualiza y escala A21
!> o A12, actualiza A22 y luego se llama a sí misma para factorizar A22.
!>
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          A la entrada, la matriz simétrica A. Si UPLO = 'U', la parte
!>          superior triangular de N por N de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la parte
!>          inferior triangular de N por N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>
!>          A la salida, si INFO = 0, el factor U o L de la factorización de
!>          Cholesky A = U**T*U o A = L*L**T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el menor principal de orden i
!>                no es positivo, y la factorización no pudo ser
!>                completada.
!>
