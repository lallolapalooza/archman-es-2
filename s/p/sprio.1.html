sprio(1) Comandos de Slurm sprio(1)

NOMBRE

sprio - ver los factores que componen la prioridad de planificación de un trabajo

SINOPSIS

sprio [OPCIONES...]

DESCRIPCIÓN

sprio se utiliza para ver los componentes de la prioridad de planificación de un trabajo cuando está instalado el plugin de prioridad multifactorial. sprio es una utilidad de solo lectura que extrae información del plugin de prioridad multifactorial. Por defecto, sprio devuelve información para todos los trabajos pendientes. Existen opciones para mostrar trabajos específicos por ID de trabajo y nombre de usuario.

OPCIONES

-M, --clusters=<cadena>
El clúster al que se emitirán los comandos. Solo se puede especificar un nombre de clúster. Tenga en cuenta que el slurmdbd debe estar activo para que esta opción funcione correctamente, a menos que se ejecute en una federación con FederationParameters=fed_display configurado o con la opción --federation establecida. Esta opción establece implícitamente la opción --local.
--federation
Mostrar trabajos en federación si es miembro de una.
-o, --format=<formato_salida>
Especificar la información que se mostrará, su tamaño y posición (justificado a la derecha o a la izquierda). Los formatos predeterminados cuando todos los factores tienen pesos distintos de cero son
predeterminado
"%.15i %9r %.10Y %.10S %.10A %.10B %.10F %.10J %.10P %.10Q %20T"
-l, --long
"%.15i %9r %.8u %.8o %.10Y %.10S %.10A %.10B %.10F %.10J %.10P %.10n %.10Q %.11N %.20T";

El formato de cada campo es "%[.][tamaño]tipo".

tamaño
es el tamaño mínimo del campo. Si no se especifica tamaño, se utilizará el necesario para imprimir la información.
.
indica que la salida debe estar justificada a la izquierda. Por defecto, la salida está justificada a la derecha.

Las especificaciones de tipo válidas incluyen:

%a
Prioridad de edad normalizada
%A
Prioridad de edad ponderada
%b
Prioridad de asociación normalizada
%B
Prioridad de asociación ponderada
%c
Nombre del clúster. Solo aplicable a clústeres federados
%f
Prioridad de fair-share normalizada
%F
Prioridad de fair-share ponderada
%i
ID del trabajo
%j
Prioridad de tamaño de trabajo normalizada
%J
Prioridad de tamaño de trabajo ponderada
%n
Nombre de la QOS
%N
Ajuste de nice
%o
Nombre de la cuenta
%p
Prioridad de partición normalizada
%P
Prioridad de partición ponderada
%q
Prioridad de calidad de servicio normalizada
%Q
Prioridad de calidad de servicio ponderada
%r
Nombre de la partición
%S
Prioridad administrativa ponderada.
%t
Prioridades TRES normalizadas
%T
Prioridades TRES ponderadas
%u
Nombre de usuario de un trabajo
%Y
Prioridad del trabajo
%y
Prioridad del trabajo normalizada
--help
Imprimir un mensaje de ayuda que describe todas las opciones de sprio.
-j, --jobs=<lista_id_trabajos>
Solicita una lista de IDs de trabajos separados por comas para mostrar. Por defecto, se muestran todos los trabajos. Dado que el argumento de esta opción es opcional, para un análisis correcto, la opción de una sola letra debe ir seguida inmediatamente por el valor y no incluir un espacio entre ellos. Por ejemplo: "-j1008,1009" y no "-j 1008,1009".
--local
Mostrar solo trabajos locales de este clúster. Ignorar otros clústeres en esta federación (si los hay). Anula --federation.
-l, --long
Informar sobre más información disponible para los trabajos seleccionados.
-h, --noheader
No imprimir una cabecera en la salida.
-n, --norm
Mostrar los factores de prioridad normalizados para los trabajos seleccionados.
-p, --partition=<lista_particiones>
Solicita una lista de particiones separadas por comas para mostrar. Por defecto, se muestran todas las particiones.
--sibling
Mostrar todos los trabajos hermanos en un clúster federado. Sin esta opción en un clúster federado, cada trabajo en cada partición tendrá su prioridad y sus componentes informados para un solo clúster. Cada trabajo hermano en los diversos clústeres de la federación puede tener una prioridad diferente, que no se informará sin usar esta opción. Añade implícitamente "%c" (nombre del clúster) al formato de salida.
-S, --sort=<lista_ordenacion>
Especificación del orden en que se deben informar los trabajos. Utiliza la misma especificación de campo que <formato_salida>. Se pueden realizar múltiples ordenaciones listando varios campos de ordenación separados por comas. Las especificaciones de campo pueden ir precedidas por "+" o "-"

; para ascendente (predeterminado) o descendente respectivamente. Por ejemplo, una <lista_de_ordenación> de "u,r,-y" ordenará los informes de prioridad de trabajos por nombre de usuario, nombre de partición y prioridad descendente del trabajo, en ese orden. La <lista_de_ordenación> predeterminada es "i" (id de trabajo ascendente).
--usage
Imprime un breve mensaje de ayuda que lista las opciones de sprio.
-u, --user=<lista_de_usuarios>
Solicita trabajos de una lista de usuarios separada por comas. La lista puede consistir en nombres de usuario o números de identificación de usuario.
-v, --verbose
Informa detalles de las acciones de sprio.
-V, --version
Imprime la información de la versión y sale.
-w, --weights
Muestra los pesos configurados para cada factor. Esto es solo para fines informativos. Los datos reales del trabajo se suprimen.

RENDIMIENTO

Ejecutar sprio envía una llamada a procedimiento remoto a slurmctld. Si llegan muchas llamadas de sprio u otros comandos cliente de Slurm que envían llamadas a procedimiento remoto al daemon slurmctld a la vez, puede resultar en una degradación del rendimiento del daemon slurmctld, posiblemente resultando en una denegación de servicio.

No ejecute sprio u otros comandos cliente de Slurm que envían llamadas a procedimiento remoto a slurmctld desde bucles en scripts de shell u otros programas. Asegúrese de que los programas limiten las llamadas a sprio al mínimo necesario para la información que intenta recopilar.

VARIABLES DE ENTORNO

Si no se especifica una opción de línea de comandos correspondiente, sprio utilizará el valor de las siguientes variables de entorno.

SLURM_CLUSTERS
Igual que --clusters
SLURM_CONF
La ubicación del archivo de configuración de Slurm.
SLURM_DEBUG_FLAGS
Especifica las banderas de depuración que usará sprio. Consulte DebugFlags en la página del manual de slurm.conf(5) para obtener una lista completa de banderas. La variable de entorno tiene precedencia sobre la configuración en slurm.conf.
SPRIO_FEDERATION
Igual que --federation
SPRIO_FORMAT
Igual que -o <formato_de_salida>, --format=<formato_de_salida>
SPRIO_LOCAL
Igual que --local
SPRIO_SIBLING
Igual que --sibling

EJEMPLOS

Imprimir la lista de todos los trabajos pendientes con sus prioridades ponderadas
$ sprio
  JOBID   PRIORITY        AGE  FAIRSHARE    JOBSIZE  PARTITION        QOS
  65539      62664          0      51664       1000      10000          0
  65540      62663          0      51663       1000      10000          0
  65541      62662          0      51662       1000      10000          0
Imprimir la lista de todos los trabajos pendientes con sus prioridades normalizadas
$ sprio -n
  JOBID PRIORITY   AGE        FAIRSHARE  JOBSIZE    PARTITION  QOS
  65539 0.00001459 0.0007180  0.5166470  1.0000000  1.0000000  0.0000000
  65540 0.00001459 0.0007180  0.5166370  1.0000000  1.0000000  0.0000000
  65541 0.00001458 0.0007180  0.5166270  1.0000000  1.0000000  0.0000000
Imprimir las prioridades de trabajo para trabajos específicos
$ sprio --jobs=65548,65547
  JOBID   PRIORITY        AGE  FAIRSHARE    JOBSIZE  PARTITION        QOS
  65547      62078          0      51078       1000      10000          0
  65548      62077          0      51077       1000      10000          0
Imprimir las prioridades de trabajo para trabajos de usuarios específicos
$ sprio --users=fred,sally
  JOBID     USER  PRIORITY       AGE  FAIRSHARE   JOBSIZE  PARTITION     QOS
  65548     fred     62079         1      51077      1000      10000       0
  65549    sally     62080         1      51078      1000      10000       0
Imprimir los pesos configurados para cada componente de prioridad
$ sprio -w
  JOBID   PRIORITY        AGE  FAIRSHARE    JOBSIZE  PARTITION        QOS
  Weights                1000     100000       1000      10000          1
