subroutine spbsvx (character fact, character uplo, integer n, integer kd, integer nrhs, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldafb, * ) afb, integer ldafb, character equed, real, dimension( * ) s, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SPBSVX calcula la solución al sistema de ecuaciones lineales A * X = B para otras matrices

Propósito:

!>
!> SPBSVX utiliza la factorización de Cholesky A = U**T*U o A = L*L**T para
!> calcular la solución de un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz de banda simétrica positiva definida de N por N y X
!> e B son matrices de N por NRHS.
!>
!> También se proporcionan cotas de error para la solución y una estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Si el sistema se va a equilibrar o no depende de la escala de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe por diag(S)*A*diag(S) y B por diag(S)*B.
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**T * U,  si UPLO = 'U', o
!>       A = L * L**T,  si UPLO = 'L',
!>    donde U es una matriz de banda triangular superior, y L es una matriz de banda triangular inferior.
!>
!> 3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina devuelve INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz
!>    A. Si la inversa del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina
!>    continúa resolviendo X y calculando cotas de error como
!>    se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    matriz y calcular cotas de error y estimaciones de error hacia atrás
!>    para la misma.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes del
!>    equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          suministra en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AFB contiene la forma factorizada de A.
!>                  Si EQUED = 'Y', la matriz A ha sido equilibrada
!>                  con factores de escala dados por S. AB y AFB no
!>                  serán modificados.
!>          = 'N':  La matriz A se copiará en AFB y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AFB y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es array REAL, dimension (LDAB,N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda simétrica
!>          A, almacenado en las primeras KD+1 filas del array, excepto
!>          si FACT = 'F' y EQUED = 'Y', entonces A debe contener la
!>          matriz equilibrada diag(S)*A*diag(S). La j-ésima columna de A
!>          se almacena en la j-ésima columna del array AB como sigue:
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) para max(1,j-KD)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(N,j+KD).
!>          Ver más abajo para más detalles.
!>
!>          En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe por
!>          diag(S)*A*diag(S).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array A.  LDAB >= KD+1.
!>

AFB

!>          AFB es array REAL, dimension (LDAFB,N)
!>          Si FACT = 'F', entonces AFB es un argumento de entrada y en la entrada
!>          contiene el factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T de la matriz de banda
!>          A, en el mismo formato de almacenamiento que A (ver AB). Si EQUED = 'Y',
!>          entonces AFB es la forma factorizada de la matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AFB es un argumento de salida y en la salida
!>          devuelve el factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T.
!>
!>          Si FACT = 'E', entonces AFB es un argumento de salida y en la salida
!>          devuelve el factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T de la matriz equilibrada A (ver la descripción de A para la forma de la
!>          matriz equilibrada).
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal del array AFB.  LDAFB >= KD+1.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre cierto si FACT = 'N').
!>          = 'Y':  Se realizó el equilibrado, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

S

!>          S es array REAL, dimension (N)
!>          Los factores de escala para A; no se accede si EQUED = 'N'. S es
!>          un argumento de entrada si FACT = 'F'; de lo contrario, S es un argumento de
!>          salida. Si FACT = 'F' y EQUED = 'Y', cada elemento de S
!>          debe ser positivo.
!>

B

!>          B es array REAL, dimension (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B de N por NRHS.
!>          En la salida, si EQUED = 'N', B no se modifica; si EQUED = 'Y',
!>          B se sobrescribe por diag(S) * B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array REAL, dimension (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS
!>          del sistema original de ecuaciones. Tenga en cuenta que si EQUED = 'Y',
!>          A y B se modifican en la salida, y la solución del
!>          sistema equilibrado es inv(diag(S))*X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          El estimador de la inversa del número de condición de la matriz
!>          A, calculada por la rutina spocon. Si spocon devuelve un valor
!>          menor que la precisión de la máquina, entonces la matriz es singular.
!>

FERR

!>          FERR es REAL, dimension (NRHS)
!>          La estimación del error hacia adelante para cada columna de X,
!>          que es la razón del error hacia atrás estimado y el peso de la
!>          norma de la solución calculada: FERR(j) = (cond(A)*EPS)*norm(X-X_computado)/norm(X_computado)
!>          donde EPS es la precisión de la máquina.
!>

BERR

!>          BERR es REAL, dimension (NRHS)
!>          El error hacia atrás estimado para cada columna de X,
!>          que es la razón de la norma del error residual hacia atrás
!>          y la norma de la matriz B (o diag(S)*B si el equilibrado se usó).
!>          BERR(j) = norm( residual(j) ) / norm(B)
!>

WORK

!>          WORK es REAL array, dimension (LWORK)
!>          En la salida, WORK(1) contiene el valor mínimo de LWORK.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1, 2*N).
!>          Para obtener un rendimiento óptimo, LWORK >= N + NB*KD, donde NB es
!>          el tamaño de bloque de la transformación de Householder.
!>

IWORK

!>          IWORK es INTEGER array, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Ejecución correcta.
!>          < 0: Si INFO = -i, la i-ésima entrada del argumento de procesamiento fue
!>               ilegal. Por ejemplo, si abs(INFO) = 1, entonces el valor de la
!>               primera entrada fue ilegal. Se puede encontrar una descripción de los
!>               argumentos de procesamiento en la documentación de cada rutina.
!>          > 0: Si INFO = i y i <= N, entonces la factorización de Cholesky falló y el
!>               factor i,i del elemento de la matriz fue cero o no fue
!>               positivo definido.  Por lo tanto, la matriz no es de Cholesky
!>               factorizable y el sistema no tiene solución única.
!>               Si INFO = N+1, la factorización de Cholesky se completó, pero la
!>               matriz es casi singular. Por lo tanto, la solución
!>               puede no ser confiable.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La estimación del número de condición recíproca de la matriz
!>          A después de la 
¡equilibración (si se realizó)! Si RCOND es menor que la
!>          precisión de la máquina (en particular, si RCOND = 0), la matriz
!>          es singular con precisión de trabajo.  Esta condición se
!>          indica con un código de retorno de INFO > 0.
!>

FERR

!>          FERR es un array REAL, de dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j).  La estimación es tan confiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array REAL, de dimensión (NRHS)
!>          El error residual relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array REAL, de dimensión (3*N)
!>

IWORK

!>          IWORK es un array ENTERO, de dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  el menor principal principal de orden i de A
!>                       no es positivo, por lo que la factorización no pudo
!>                       completarse y la solución no se ha
!>                       calculado. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión de la
!>                       máquina, lo que significa que la matriz es singular
!>                       con precisión de trabajo.  Sin embargo, la
!>                       solución y los límites de error se calculan porque
!>                       hay una serie de situaciones en las que la
!>                       solución calculada puede ser más precisa que el
!>                       valor de RCOND sugeriría.
!>
