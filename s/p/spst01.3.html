SPST01

Propósito:

!>
!> SPST01 reconstruye una matriz semidefinida positiva simétrica A
!> a partir de sus factores L o U y la matriz de permutación P y calcula
!> el residuo
!>    norm( P*L*L'*P' - A ) / ( N * norm(A) * EPS ) o
!>    norm( P*U'*U*P' - A ) / ( N * norm(A) * EPS ),
!> donde EPS es la epsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          La matriz simétrica original A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N)
!>

AFAC

!>          AFAC es un array REAL, de dimensión (LDAFAC,N)
!>          El factor L o U de la factorización L*L' o U'*U
!>          de A.
!>

LDAFAC

!>          LDAFAC es INTEGER
!>          La dimensión principal del array AFAC.  LDAFAC >= max(1,N).
!>

PERM

!>          PERM es un array REAL, de dimensión (LDPERM,N)
!>          Se sobrescribe con la matriz reconstruida, y luego con la
!>          diferencia P*L*L'*P' - A (o P*U'*U*P' - A)
!>

LDPERM

!>          LDPERM es INTEGER
!>          La dimensión principal del array PERM.
!>          LDAPERM >= max(1,N).
!>

PIV

!>          PIV es un array INTEGER, de dimensión (N)
!>          PIV es tal que las entradas distintas de cero son
!>          P( PIV( K ), K ) = 1.
!>

RWORK

!>          RWORK es un array REAL, de dimensión (N)
!>

RESID

!>          RESID es REAL
!>          Si UPLO = 'L', norm(L*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U'*U - A) / ( N * norm(A) * EPS )
!>

RANK

!>          RANK es INTEGER
!>          número de valores singulares distintos de cero de A.
!>
