Documentación de la función/subrutina

subrutina sptt02 (integer n, integer nrhs, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldx, * ) x, integer ldx, real, dimension( ldb, * ) b, integer ldb, real resid)

SPTT02

Propósito:

!>
!> SPTT02 calcula el residuo para la solución de un sistema simétrico
!> de ecuaciones tridiagonales:
!>    RESID = norm(B - A*X) / (norm(A) * norm(X) * EPS),
!> donde EPS es la epsilon de la máquina.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

D

!>          D es un array REAL, dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal A.
!>

E

!>          E es un array REAL, dimensión (N-1)
!>          Los n-1 elementos subdiagonales de la matriz tridiagonal A.
!>

X

!>          X es un array REAL, dimensión (LDX,NRHS)
!>          La matriz de n por nrhs de vectores solución X.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

B

!>          B es un array REAL, dimensión (LDB,NRHS)
!>          En la entrada, la matriz de n por nrhs de vectores del lado derecho B.
!>          En la salida, B se sobrescribe con la diferencia B - A*X.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

RESID

!>          RESID es REAL
!>          norm(B - A*X) / (norm(A) * norm(X) * EPS)
!>
