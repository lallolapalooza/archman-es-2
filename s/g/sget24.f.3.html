!>    SGET24 comprueba el problema del valor propio (forma de Schur) no simétrico
!>    conductor experto SGEESX.
!>
!>    Si COMP = .FALSO., las primeras 13 de las siguientes pruebas se realizarán
!>    en la matriz de entrada A, y también las pruebas 14 y 15
!>    si LWORK es suficientemente grande.
!>    Si COMP = .VERDADERO., se realizarán las 17 pruebas.
!>
!>    (1)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>           (sin ordenar los valores propios)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de los vectores propios de Schur, y T está en forma de Schur
!>      (sin ordenar los valores propios).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (sin ordenar los valores propios).
!>
!>    (4)     0     si WR+sqrt(-1)*WI son los valores propios de T
!>            1/ulp en caso contrario
!>            (sin ordenar los valores propios)
!>
!>    (5)     0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenar los valores propios)
!>
!>    (6)     0     si valores_propios(con VS) = valores_propios(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenar los valores propios)
!>
!>    (7)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>            (con ordenación de los valores propios)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de los vectores propios de Schur, y T está en forma de Schur
!>      (con ordenación de los valores propios).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (con ordenación de los valores propios).
!>
!>    (10)    0     si WR+sqrt(-1)*WI son los valores propios de T
!>            1/ulp en caso contrario
!>            Si hay suficiente espacio de trabajo, comparar también WR, WI con y
!>            sin números de condición recíprocos
!>            (con ordenación de los valores propios)
!>
!>    (11)    0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            Si hay suficiente espacio de trabajo, comparar también T con y sin
!>            números de condición recíprocos
!>            (con ordenación de los valores propios)
!>
!>    (12)    0     si valores_propios(con VS) = valores_propios(sin VS),
!>            1/ulp en caso contrario
!>            Si hay suficiente espacio de trabajo, comparar también VS con y sin
!>            números de condición recíprocos
!>            (con ordenación de los valores propios)
!>
!>    (13)    si la ordenación funcionó y SDIM es el número de
!>            valores propios que fueron SELECCIONADOS
!>            Si hay suficiente espacio de trabajo, comparar también SDIM con y
!>            sin números de condición recíprocos
!>
!>    (14)    si RCONDE es el mismo, sin importar si VS y/o RCONDV fueron calculados
!>
!>    (15)    si RCONDV es el mismo, sin importar si VS y/o RCONDE fueron calculados
!>
!>    (16)  |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>       RCONDE es el número de condición promedio recíproco del valor propio
!>       calculado por SGEESX y RCDEIN (el valor verdadero precalculado)
!>       se proporciona como entrada. cond(RCONDE) es el número de condición
!>       de RCONDE, y tiene en cuenta los errores en el cálculo de RCONDE,
!>       de modo que la cantidad resultante debería ser O(ULP). cond(RCONDE)
!>       se da esencialmente por norm(A)/RCONDV.
!>
!>    (17)  |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>       RCONDV es el número de condición recíproco del subespacio invariante derecho
!>       calculado por SGEESX y RCDVIN (el valor verdadero precalculado)
!>       se proporciona como entrada. cond(RCONDV) es el número de condición
!>       de RCONDV, y tiene en cuenta los errores en el cálculo de RCONDV,
!>       de modo que la cantidad resultante debería ser O(ULP).
!>       cond(RCONDV) se da esencialmente por norm(A)/RCONDE.
!>

Function/Subroutine Documentation

Purpose

!> subroutine sget24
!>
!>   Purpose is to check routine sgeesx.f, which computes the eigenvalues
!>   and Schur vectors of a real matrix A, and optionally computes
!>   reciprocal condition numbers for the eigenvalues and the right
!>   invariant subspace.
!>
!>   The condition number is computed using the Schur vectors and
!>   reciprocal condition numbers from subroutine sgecon.f, which is
!>   called by sgeesx.f.
!>
!>   The tests are performed using the information computed by sgeesx.f.
!>   The computed values are compared with the values computed by sget24.f
!>   using a fixed number of pairs of eigenvalues and Schur vectors.
!>
!>   The selected eigenvalues and Schur vectors are from the set of all
!>   eigenvalues and Schur vectors, sorted by increasing real part.
!>
!>   The definition of the condition number is from [1].
!>
!>   References:
!>   [1] Golub G.H. and Van Loan Ch.F. "Matrix Computations"
!>       The Johns Hopkins University Press, Baltimore, Maryland, 1983.
!>       Page 429.
!>
!>   Arguments
!>
!>   N is INTEGER
!>     The order of the matrix A.  0 <= N <= NMAX.
!>
!>   A is REAL array, dimension (LDA, N)
!>     On entry, the N-by-N matrix of the original system.
!>     On exit, the contents of A are destroyed.
!>
!>   LDA is INTEGER
!>     The leading dimension of A.  LDA >= max(1, N).
!>
!>   SELECT is LOGICAL array, dimension (N)
!>     On entry, SELECT determines which eigenvalues and Schur vectors are
!>     selected. If SELECT(I) is .TRUE., then the I-th eigenvalue and
!>     Schur vector are selected.
!>
!>   WR is REAL array, dimension (N)
!>     On exit, WR contains the real parts of the eigenvalues of A,
!>     sorted by increasing real part.
!>
!>   WI is REAL array, dimension (N)
!>     On exit, WI contains the imaginary parts of the eigenvalues of A,
!>     sorted by increasing real part.
!>     WI(I) is always non-negative.
!>
!>   VS is REAL array, dimension (LDVS, N)
!>     On exit, VS contains the computed Schur vectors of A,
!>     such that A * VS = VS * T, where T is the upper triangular matrix
!>     of eigenvalues.
!>     The Schur vectors are normalized so that the absolute value of
!>     the largest element in each column is 1.
!>
!>   LDVS is INTEGER
!>     The leading dimension of VS. LDVS >= max(1, N).
!>
!>   TRI is REAL array, dimension (N)
!>     On exit, TRI contains the diagonal elements of the matrix T, which
!>     are the eigenvalues of A.
!>
!>   LWORK is INTEGER
!>     The number of entries in WORK to be passed to SGEESX.
!>     This must be at least 3*N, and N+N**2 if tests 14--16 are to
!>     be performed.
!>
!>   IWORK is INTEGER array, dimension (N*N)
!>
!>   BWORK is LOGICAL array, dimension (N)
!>
!>   INFO is INTEGER
!>     = 0:  successful exit
!>     < 0:  if -INFO was an illegal value for INFO( I ).
!>     > 0:  if the QR algorithm did not converge, and INFO=I.
!>
!>

Description

!> SGET24 is a subroutine that checks the correctness of the subroutine
!> SGEESX. SGEESX computes the eigenvalues and Schur vectors of a real
!> matrix A, and optionally computes reciprocal condition numbers for the
!> eigenvalues and the right invariant subspace.
!>
!> The subroutine SGET24 checks the correctness of the eigenvalues and
!> Schur vectors computed by SGEESX. It also checks the accuracy of the
!> reciprocal condition numbers for the eigenvalues and the right
!> invariant subspace.
!>
!> The subroutine SGET24 performs 17 tests on the output of SGEESX.
!> The tests are described in the documentation for SGEESX.
!>
!> The subroutine SGET24 uses the following arrays:
!>
!> WR TMP
!>          WRTMP is REAL array, dimension (N)
!>
!> WITMP
!>          WITMP is REAL array, dimension (N)
!>
!>          Like WR, WI, these arrays contain the eigenvalues of A,
!>          but sorted by increasing real part.
!>
!> VS
!>          VS is REAL array, dimension (LDVS, N)
!>          VS holds the computed Schur vectors.
!>
!> LDVS
!>          LDVS is INTEGER
!>          Leading dimension of VS. Must be at least max(1, N).
!>
!> VS1
!>          VS1 is REAL array, dimension (LDVS, N)
!>          VS1 holds another copy of the computed Schur vectors.
!>
!> RCDEIN
!>          RCDEIN is REAL
!>          When COMP = .TRUE. RCDEIN holds the precomputed reciprocal
!>          condition number for the average of selected eigenvalues.
!>
!> RCDVIN
!>          RCDVIN is REAL
!>          When COMP = .TRUE. RCDVIN holds the precomputed reciprocal
!>          condition number for the selected right invariant subspace.
!>
!> NSLCT
!>          NSLCT is INTEGER
!>          When COMP = .TRUE. the number of selected eigenvalues
!>          corresponding to the precomputed values RCDEIN and RCDVIN.
!>
!> ISLCT
!>          ISLCT is INTEGER array, dimension (NSLCT)
!>          When COMP = .TRUE. ISLCT selects the eigenvalues of the
!>          input matrix corresponding to the precomputed values RCDEIN
!>          and RCDVIN. For I=1, ... ,NSLCT, if ISLCT(I) = J, then the
!>          eigenvalue with the J-th largest real part is selected.
!>          Not referenced if COMP = .FALSE.
!>
!> RESULT
!>          RESULT is REAL array, dimension (17)
!>          The values computed by the 17 tests described above.
!>          The values are currently limited to 1/ulp, to avoid
!>          overflow.
!>
!> WORK
!>          WORK is REAL array, dimension (LWORK)
!>
!> LWORK
!>          LWORK is INTEGER
!>          The number of entries in WORK to be passed to SGEESX. This
!>          must be at least 3*N, and N+N**2 if tests 14--16 are to
!>          be performed.
!>
!> IWORK
!>          IWORK is INTEGER array, dimension (N*N)
!>
!> BWORK
!>          BWORK is LOGICAL array, dimension (N)
!>
!> INFO
!>          INFO is INTEGER
!>          If 0,  successful exit.
!>          If <0, input parameter -INFO had an incorrect value.
!>          If >0, SGEESX returned an error code, the absolute
!>                 value of which is returned.
!>
