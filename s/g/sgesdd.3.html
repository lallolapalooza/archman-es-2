subroutine sgesdd (character jobz, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldvt, * ) vt, integer ldvt, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

SGESDD

Propósito:

!>
!> SGESDD calcula la descomposición en valores singulares (SVD) de una matriz real
!> M por N, A, calculando opcionalmente los vectores singulares izquierdos y derechos.
!> Si se desean vectores singulares, utiliza un algoritmo de divide y vencerás.
!>
!> La SVD se escribe:
!>
!>      A = U * SIGMA * transpose(V)
!>
!> donde SIGMA es una matriz M por N que es cero excepto por sus
!> min(m,n) elementos diagonales, U es una matriz ortogonal M por M, y
!> V es una matriz ortogonal N por N. Los elementos diagonales de SIGMA
!> son los valores singulares de A; son reales y no negativos, y
!> se devuelven en orden descendente. Las primeras min(m,n) columnas de
!> U y V son los vectores singulares izquierdos y derechos de A.
!>
!> Nótese que la rutina devuelve VT = V**T, no V.
!>
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          Especifica opciones para calcular toda o parte de la matriz U:
!>          = 'A':  todas las M columnas de U y todas las N filas de V**T se
!>                  devuelven en los arrays U y VT;
!>          = 'S':  las primeras min(M,N) columnas de U y las primeras
!>                  min(M,N) filas de V**T se devuelven en los arrays U
!>                  y VT;
!>          = 'O':  Si M >= N, las primeras N columnas de U se sobrescriben
!>                  en el array A y todas las filas de V**T se devuelven en
!>                  el array VT;
!>                  de lo contrario, todas las columnas de U se devuelven en
!>                  el array U y las primeras M filas de V**T se sobrescriben
!>                  en el array A;
!>          = 'N':  no se calculan columnas de U ni filas de V**T.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  N >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz M por N A.
!>          En la salida,
!>          si JOBZ = 'O',  A se sobrescribe con las primeras N columnas
!>                          de U (los vectores singulares izquierdos, almacenados
!>                          por columnas) si M >= N;
!>                          A se sobrescribe con las primeras M filas
!>                          de V**T (los vectores singulares derechos, almacenados
!>                          por filas) en caso contrario.
!>          si JOBZ .ne. 'O', el contenido de A se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

S

!>          S es un array REAL, dimensión (min(M,N))
!>          Los valores singulares de A, ordenados de tal manera que S(i) >= S(i+1).
!>

U

!>          U es un array REAL, dimensión (LDU,UCOL)
!>          UCOL = M si JOBZ = 'A' o JOBZ = 'O' y M < N;
!>          UCOL = min(M,N) si JOBZ = 'S'.
!>          Si JOBZ = 'A' o JOBZ = 'O' y M < N, U contiene la matriz ortogonal
!>          M por M U;
!>          si JOBZ = 'S', U contiene las primeras min(M,N) columnas de
!>          U (los vectores singulares izquierdos, almacenados por columnas);
!>          si JOBZ = 'O' y M >= N, o JOBZ = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U.  LDU >= 1; si
!>          JOBZ = 'S' o 'A' o JOBZ = 'O' y M < N, LDU >= M.
!>

VT

!>          VT es un array REAL, dimensión (LDVT,N)
!>          Si JOBZ = 'A' o JOBZ = 'O' y M >= N, VT contiene la matriz ortogonal
!>          N por N V**T;
!>          si JOBZ = 'S', VT contiene las primeras min(M,N) filas de
!>          V**T (los vectores singulares derechos, almacenados por filas);
!>          si JOBZ = 'O' y M < N, o JOBZ = 'N', VT no se referencia.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del array VT.  LDVT >= 1;
!>          si JOBZ = 'A' o JOBZ = 'O' y M >= N, LDVT >= N;
!>          si JOBZ = 'S', LDVT >= min(M,N).
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo;
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo. El tamaño
!>          óptimo para el array WORK se calcula y se almacena en WORK(1),
!>          y no se realiza ningún otro trabajo excepto la comprobación de
!>          argumentos.
!>
!>          Sea mx = max(M,N) y mn = min(M,N).
!>          Si JOBZ = 'N', LWORK >= 3*mn + max( mx, 7*mn ).
!>          Si JOBZ = 'O', LWORK >= 3*mn + max( mx, 5*mn*mn + 4*mn ).
!>          Si JOBZ = 'S', LWORK >= 4*mn*mn + 7*mn.
!>          Si JOBZ = 'A', LWORK >= 4*mn*mn + 6*mn + mx.
!>          Estos no son mínimos estrictos en todos los casos; ver comentarios
!>          dentro del código.
!>          Para un buen rendimiento, LWORK generalmente debería ser mayor;
!>          se recomienda una consulta.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (8*min(M,N))
!>

INFO

!>          INFO es INTEGER
!>          <  0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = -4:  si A tenía una entrada NAN.
!>          >  0:  SBDSDC no convergió, el proceso de actualización falló.
!>          =  0:  salida exitosa.
!>

NOMBRE

sgesdd - Descomposición en valores singulares de una matriz real general.

SINOPSIS

SUBROUTINE SGESDD( JOBZ, M, N, A, LDA, S, U, LDU, VT, LDVT, WORK, LWORK, IWORK, INFO )

CHARACTER JOBZ

INTEGER M, N, LDA, LDU, LDVT, LWORK, INFO

REAL A( LDA, * ), S( * ), U( LDU, * ), VT( LDVT, * ), WORK( * )

INTEGER IWORK( * )

DESCRIPCIÓN

SGESDD calcula la descomposición en valores singulares (SVD) de una matriz real general A de la forma:

A = U * S * VT

donde S es una matriz diagonal real, U es una matriz ortogonal por columnas, y VT es una matriz ortogonal por filas.

S contiene los valores singulares de A, ordenados de mayor a menor.

SGESDD utiliza un enfoque de "divide y vencerás" para calcular la SVD.

ARGUMENTOS

  • JOBZ (entrada) - Indica si calcular U y VT.
    • 'A': Calcula todos los U y VT.
    • 'S': Calcula U y VT si M >= N.
    • 'O': Calcula U y VT si M <= N.
    • 'N': No calcula U ni VT.
  • M (entrada) - Número de filas de A.
  • N (entrada) - Número de columnas de A.
  • A (entrada/salida) - Matriz de dimensiones (M, N). En la salida, contiene información sobre U y VT si JOBZ != 'N'.
  • LDA (entrada) - Longitud de la primera dimensión de A.
  • S (salida) - Array de dimensiones (MIN(M, N)). Contiene los valores singulares de A.
  • U (salida) - Matriz de dimensiones (M, M) o (M, K) si JOBZ = 'A' o 'S', donde K = MIN(M,N). Contiene las columnas ortogonales de U.
  • LDU (entrada) - Longitud de la primera dimensión de U.
  • VT (salida) - Matriz de dimensiones (K, N) o (N, N) si JOBZ = 'A' o 'O', donde K = MIN(M,N). Contiene las filas ortogonales de VT.
  • LDVT (entrada) - Longitud de la primera dimensión de VT.
  • WORK (salida) - Array de trabajo. El tamaño mínimo de WORK se puede determinar llamando a SGESDD con LWORK = -1.
  • LWORK (entrada) - Longitud del array WORK.
  • IWORK (salida) - Array de enteros de trabajo. El tamaño mínimo de IWORK se puede determinar llamando a SGESDD con LWORK = -1.
  • INFO (salida) -
    • 0: Éxito.
    • <0: Uno de los argumentos de entrada no válidos.
    • >0: El algoritmo de "divide y vencerás" falló en converger; el elemento i del array S es cero.
