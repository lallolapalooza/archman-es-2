SGGEV3 calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE (algoritmo bloqueado)

Propósito:

!>
!> SGGEV3 calcula para un par de matrices reales no simétricas de N por N (A,B)
!> los valores propios generalizados, y opcionalmente, los vectores propios generalizados izquierdos y/o derechos.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar
!> lambda o una relación alpha/beta = lambda, tal que A - lambda*B es
!> singular. Se suele representar como el par (alpha,beta), ya que
!> hay una interpretación razonable para beta=0, e incluso para ambos
!> siendo cero.
!>
!> El vector propio derecho v(j) correspondiente al valor propio lambda(j)
!> de (A,B) satisface
!>
!>                  A * v(j) = lambda(j) * B * v(j).
!>
!> El vector propio izquierdo u(j) correspondiente al valor propio lambda(j)
!> de (A,B) satisface
!>
!>                  u(j)**H * A  = lambda(j) * u(j)**H * B .
!>
!> donde u(j)**H es la transpuesta conjugada de u(j).
!>
!>

Parámetros

JOBVL 
!>          JOBVL es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados izquierdos;
!>          = 'V':  calcular los vectores propios generalizados izquierdos.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados derechos;
!>          = 'V':  calcular los vectores propios generalizados derechos.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VL y VR.  N >= 0.
!>

A

!>          A es un array REAL, dimension (LDA, N)
!>          En la entrada, la matriz A en el par (A,B).
!>          En la salida, A ha sido sobrescrita.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es un array REAL, dimension (LDB, N)
!>          En la entrada, la matriz B en el par (A,B).
!>          En la salida, B ha sido sobrescrita.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHAR

!>          ALPHAR es un array REAL, dimension (N)
!>

ALPHAI

!>          ALPHAI es un array REAL, dimension (N)
!>

BETA

!>          BETA es un array REAL, dimension (N)
!>          En la salida, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, serán
!>          los valores propios generalizados. Si ALPHAI(j) es cero, entonces
!>          el j-ésimo valor propio es real; si es positivo, entonces el j-ésimo y
!>          el (j+1)-ésimo valores propios forman un par conjugado complejo, con
!>          ALPHAI(j+1) negativo.
!>
!>          Nota: los cocientes ALPHAR(j)/BETA(j) y ALPHAI(j)/BETA(j)
!>          pueden fácilmente desbordarse o subdesbordarse, y BETA(j) puede incluso ser cero.
!>          Por lo tanto, el usuario debe evitar calcular ingenuamente la relación
!>          alpha/beta. Sin embargo, ALPHAR y ALPHAI siempre serán menores
!>          que la norma(A) en magnitud y usualmente comparables, y
!>          BETA siempre será menor que la norma(B) y usualmente comparable.
!>

VL

!>          VL es un array REAL, dimension (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios generalizados izquierdos u(j) se almacenan uno
!>          después de otro en las columnas de VL, en el mismo orden que
!>          sus valores propios. Si el j-ésimo valor propio es real, entonces
!>          u(j) = VL(:,j), la j-ésima columna de VL. Si el j-ésimo y
!>          el (j+1)-ésimo valores propios forman un par conjugado complejo, entonces
!>          u(j) = VL(:,j)+i*VL(:,j+1) y u(j+1) = VL(:,j)-i*VL(:,j+1).
!>          Cada vector propio se escala de modo que el componente más grande tenga
!>          abs(parte real)+abs(parte imaginaria)=1.
!>          No referenciado si JOBVL = 'N'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array REAL, dimension (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios generalizados derechos v(j) se almacenan uno
!>          después de otro en las columnas de VR, en el mismo orden que
!>          sus valores propios. Si el j-ésimo valor propio es real, entonces
!>          v(j) = VR(:,j), la j-ésima columna de VR. Si el j-ésimo y
!>          el (j+1)-ésimo valores propios forman un par conjugado complejo, entonces
!>          v(j) = VR(:,j)+i*VR(:,j+1) y v(j+1) = VR(:,j)-i*VR(:,j+1).
!>          Cada vector propio se escala de modo que el componente más grande tenga
!>          abs(parte real)+abs(parte imaginaria)=1.
!>          No referenciado si JOBVR = 'N'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal de la matriz VR. LDVR >= 1, y
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK es un array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= MAX(1,8*N).
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          sólo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1,...,N:
!>                La iteración QZ falló. No se han calculado vectores propios,
!>                pero ALPHAR(j), ALPHAI(j), y BETA(j) deberían ser correctos para j=INFO+1,...,N.
!>          > N:  =N+1: fallo de iteración QZ en SLAQZ0.
!>                =N+2: retorno de error de STGEVC.
!>

sggev3(3)

sggev3 - This subroutine computes the eigenvalues and, optionally, the left and right eigenvectors of a generalized eigenvalue problem \(Ax - \lambda Bx = 0\).

The function is called by sggeev.

NAME

sggev3

SYNOPSIS

SUBROUTINE SGGEV3( COMPQ, COMPZ, N, A, LDA, B, LDB, ALPHAR, ALPHAI, BETA, Q, LDQ, Z, LDZ, WORK, LWORK, INFO )

   CHARACTER * 1              :: COMPQ
   CHARACTER * 1              :: COMPZ
   INTEGER                    :: N
   REAL,    DIMENSION( LDA, * ) :: A
   INTEGER                    :: LDA
   REAL,    DIMENSION( LDB, * ) :: B
   INTEGER                    :: LDB
   REAL,    DIMENSION( * )      :: ALPHAR
   REAL,    DIMENSION( * )      :: ALPHAI
   REAL,    DIMENSION( * )      :: BETA
   REAL,    DIMENSION( LDQ, * ) :: Q
   INTEGER                    :: LDQ
   REAL,    DIMENSION( LDZ, * ) :: Z
   INTEGER                    :: LDZ
   REAL,    DIMENSION( * )      :: WORK
   INTEGER                    :: LWORK
   INTEGER                    :: INFO

Function/Subroutine Documentation

SGGEV3 computes the eigenvalues and, optionally, the left and right eigenvectors of a generalized eigenvalue problem \(Ax = \lambda Bx\).

Arguments

  • COMPQ - CHARACTER*1. Specifies whether to compute the left eigenvectors:
    • 'N' = Do not compute eigenvectors.
    • 'V' = Compute eigenvectors.
  • COMPZ - CHARACTER*1. Specifies whether to compute the right eigenvectors:
    • 'N' = Do not compute eigenvectors.
    • 'V' = Compute eigenvectors.
  • N - INTEGER. The order of the matrices A and B.
  • A - REAL, DIMENSION (LDA,*)
  • LDA - INTEGER. The leading dimension of A.
  • B - REAL, DIMENSION (LDB,*)
  • LDB - INTEGER. The leading dimension of B.
  • ALPHAR - REAL, DIMENSION (*)
  • ALPHAI - REAL, DIMENSION (*)
  • BETA - REAL, DIMENSION (*)
  • Q - REAL, DIMENSION (LDQ,*)
  • LDQ - INTEGER. The leading dimension of Q.
  • Z - REAL, DIMENSION (LDZ,*)
  • LDZ - INTEGER. The leading dimension of Z.
  • WORK - REAL, DIMENSION (*)
  • LWORK - INTEGER. The dimension of the array WORK.
  • INFO - INTEGER.
    • 0: successful exit
    • <0: if INFO = -i, then the i-th argument had an illegal value.
    • >0: if INFO = i, then i eigenvectors (and optionally general matrix pairs) failed to converge.

Details

The generalized eigenvalue problem is to find the eigenvalues \(\lambda\) and the corresponding left and right eigenvectors \(u\) and \(v\) of the generalized eigenvalue problem \(Ax = \lambda Bx\).

  • If \(B\) is non-singular, the eigenvalues are the same as the eigenvalues of the matrix \(C = B^{-1}A\).
  • If \(B\) is singular, the eigenvalues are the same as the eigenvalues of the matrix \(C\) which is obtained from the QR factorization of \(B\).
The algorithm used is based on the QR algorithm.
