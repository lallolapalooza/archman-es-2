subrutina sget40 (real rmax, integer lmax, integer, dimension( 2 ) ninfo, integer knt, integer nin)

SGET40

Propósito:

!>
!> SGET40 prueba STGEXC, una rutina para intercambiar bloques adyacentes (ya sean
!> de 1x1 o 2x2) en la diagonal de un lápiz en forma de Schur generalizada real.
!> Por lo tanto, STGEXC calcula matrices ortogonales Q y Z tales que
!>
!>     Q' * ( [ A B ], [ D E ] ) * Z  = ( [ C1 B1 ], [ F1 E1 ] )
!>          ( [ 0 C ]  [   F ] )        ( [ 0  A1 ]  [    D1]  )
!>
!> donde (C1,F1) es similar a (C,F) y (A1,D1) es similar a (A,D).
!> Se asume que tanto (A,D) como (C,F) están en forma estándar
!> y (A1,D1) y (C1,F1) se devuelven con las
!> mismas propiedades.
!>

Parámetros

RMAX 
!>          RMAX es REAL
!>          Valor de la razón de prueba más grande.
!>

LMAX

!>          LMAX es INTEGER
!>          Número de ejemplo donde se logró la razón de prueba más grande.
!>

NINFO

!>          NINFO es un array de INTEGER, dimensión (2)
!>          NINFO( 1 ) = STGEXC sin acumulación devolvió INFO no cero
!>          NINFO( 2 ) = STGEXC con acumulación devolvió INFO no cero
!>

KNT

!>          KNT es INTEGER
!>          Número total de ejemplos probados.
!>

NIN

!>          NIN es INTEGER
!>          Número de unidad lógica de entrada.
!>
