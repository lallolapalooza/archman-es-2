DESCRIPCIÓN

sg_vector_create() asigna e inicializa un nuevo vector de statgrab con `initial_used` elementos listos para su uso. Inicialmente se asigna espacio para `alloc_count` elementos (para evitar demasiadas llamadas a realloc() durante futuras llamadas a sg_vector_resize()). El valor de `block_size` debe ser una potencia de 2; se redondea a la siguiente potencia de 2 si no lo es. Si `alloc_count` no es un múltiplo de `block_size`, se redondea al múltiplo de `block_size` siguiente. Devuelve un puntero al vector recién creado.

sg_vector_clear() destruye todos los elementos contenidos en el vector dado. A diferencia de sg_vector_resize( x, 0 ), el tamaño asignado del vector no se modifica.

sg_vector_resize() aumenta o disminuye la cantidad de elementos asignados en el vector especificado. La cantidad de elementos asignados es siempre un múltiplo del parámetro de inicialización `block_size`. En el caso especial en que se llama a sg_vector_resize() con 0 en el argumento `new_count`, el vector se libera después de que todos los elementos del vector hayan sido destruidos. Devuelve el puntero al vector redimensionado.

sg_vector_free() destruye todos los elementos del vector y desasigna el almacenamiento perteneciente al vector dado.

sg_vector_clone() clona todos los elementos del vector dado en un nuevo vector creado con la misma especificación que el referenciado. Devuelve un puntero al vector clonado.

sg_vector_clone_into() clona todos los elementos del vector fuente dado en el vector destino dado. El vector destino debe estar creado para el mismo tipo de dato de elemento que el vector fuente. Devuelve un código de error distinto de SG_ERROR_NONE si algo salió mal.

sg_vector_compute_diff() calcula un vector de diferencia entre el vector que contiene las estadísticas actuales y otro vector que contiene estadísticas más antiguas. Si un elemento existe en el vector actual pero no en el opuesto, se clona en el vector resultado. Si un elemento existe solo en el vector opuesto, no aparece en el vector destino. sg_vector_compute_diff() devuelve un código de error distinto de SG_ERROR_NONE si algo salió mal.

sg_prove_vector() prueba si un puntero a un vector realmente apunta a un vector. En caso de que el puntero del vector apunte a datos corruptos, el programa se aborta. Cuando sg_prove_vector() retorna, devuelve SG_ERROR_NONE.

sg_get_nelements() devuelve el número de elementos que el área de datos dada, abarcada por un vector de statgrab, contiene. La cabecera del vector se calcula internamente a partir del puntero dado al primer elemento del vector.

sg_free_stats_buf() libera el vector que abarca el área de datos dada.

NOTAS

Excepto sg_get_nelements() y sg_free_stats_buf(), ninguna de las funciones anteriores puede ser llamada desde fuera de las fuentes de libstatgrab. Las estructuras y APIs documentadas pueden cambiar sin previo aviso. La descripción de todas las demás APIs está destinada a ser leída solo por desarrolladores de libstatgrab.

Cada vector se crea a partir de dos elementos: la información del vector y la lista de elementos:

template <class T, class Impl>
struct sg_vector {
        size_t used_count;
        size_t alloc_count;
        size_t block_shift;
        Impl vector_implementation;
        T elements[alloc_count];
};

Por supuesto, esto no es C válido, por lo que la solución fue ser astuto:

typedef struct sg_vector {
	size_t used_count;
	size_t alloc_count;
	size_t block_shift;
	struct sg_vector_init_info info;
} sg_vector;
struct sg_vector_size_helper {
	struct sg_vector v;
	long long ll;
};
#define VECTOR_SIZE offsetof(struct sg_vector_size_helper,ll)
/* Return the data ptr of a vector */
#define VECTOR_DATA(vector) \
	(vector ? (void *)(((char *)vector)+VECTOR_SIZE) : NULL)
#define VECTOR_ADDR_ARITH(ptr) \
	(sg_vector *)(((char *)(ptr))-VECTOR_SIZE)
/* Return the vector for a data */
#define VECTOR_ADDRESS(ptr) \
	((ptr) ? (SG_ERROR_NONE == sg_prove_vector(VECTOR_ADDR_ARITH(ptr)) ? VECTOR_ADDR_ARITH(ptr) : NULL ) : NULL)

Esto también permite a las funciones de usuario como sg_get_nelements() y sg_free_stats_buf() cambiar fácilmente entre la estructura del vector y el contenido.

LA ESTRUCTURA DE ESPECIALIZACIÓN DEL VECTOR

Como se mencionó, la implementación del vector utiliza estrategias del concepto de programación orientada a objetos llamado "polimorfismo". Un vector se describe mediante un pequeño objeto que contiene atributos inherentes como el tamaño del elemento y un conjunto de "métodos virtuales" para realizar tareas relacionadas con los elementos, como inicializar o destruir elementos.

typedef void (*vector_init_function)(void *item);
typedef sg_error (*vector_copy_function)(const void *src, void *dst);
typedef sg_error (*vector_compute_diff_function)(void *dst, const void *src);
typedef int (*vector_compare_function)(const void *a, const void *b);
typedef void (*vector_destroy_function)(void *item);
struct sg_vector_init_info {
        size_t item_size;
        vector_init_function init_fn;
        vector_copy_function copy_fn;
        vector_compute_diff_function compute_diff_fn;
        vector_compare_function compare_fn;
        vector_destroy_function destroy_fn;
};

Las instancias de `struct sg_vector_init_info` se inicializan conceptualmente de forma estática utilizando la macro del preprocesador VECTOR_INIT_INFO_FULL_INIT(type) o VECTOR_INIT_INFO_EMPTY_INIT(type). Aquí hay algunos ejemplos para demostrar cómo está pensado:

Inicialización de la descripción del vector de estadísticas de CPU

Inicialización de la descripción del vector de estadísticas de Información del Host

NAME

sg_vector_resize, VECTOR_CREATE, VECTOR_CLEAR, VECTOR_CREATE_OR_RESIZE, VECTOR_UPDATE, VECTOR_ITEM_COUNT - manipulación de vectores de datos

SYNOPSIS

void sg_vector_resize(struct sg_vector *vector, size_t new_count);

struct sg_vector * sg_vector_create(size_t alloc_count, size_t initial_used, const struct sg_vector_init_info *init_info);

void sg_vector_clear(struct sg_vector *vector);

struct sg_vector * sg_vector_create_or_resize(struct sg_vector **vectorptr, size_t new_count, identifier type);

void sg_vector_update(struct sg_vector **vectorptr, size_t new_count, datatype *data, identifier datatype);

size_t sg_vector_item_count(struct sg_vector *vector);

struct sg_vector * VECTOR_CREATE(identifier type, size_t initial_count);

void VECTOR_CLEAR(struct sg_vector *vector);

struct sg_vector * VECTOR_CREATE_OR_RESIZE(struct sg_vector *vector, size_t new_count, identifier type);

void VECTOR_UPDATE(struct sg_vector **vectorptr, size_t new_count, datatype *data, identifier datatype);

size_t VECTOR_ITEM_COUNT(struct sg_vector *vector);

DESCRIPTION

Estas macros proporcionan una interfaz de alto nivel para la manipulación de vectores de datos dinámicos utilizados dentro de la biblioteca libstatgrab.

sg_vector_resize() cambia el tamaño del vector proporcionado a la cantidad de elementos especificados por new_count.

sg_vector_create() crea un nuevo vector. alloc_count especifica el número inicial de elementos que se asignarán. initial_used especifica el número inicial de elementos que se consideran en uso. init_info es un puntero a una estructura que proporciona información específica del tipo para la inicialización del vector.

sg_vector_clear() elimina todos los elementos del vector, pero conserva la memoria asignada.

sg_vector_create_or_resize() crea el vector si el puntero proporcionado es NULL, o lo redimensiona si ya existe. new_count especifica el tamaño deseado del vector. type especifica el tipo de datos que contendrá el vector, utilizado para seleccionar la información de inicialización adecuada.

sg_vector_update() es una macro de conveniencia que llama a VECTOR_CREATE_OR_RESIZE y luego actualiza los datos del primer elemento del vector resultante. Maneja la limpieza en caso de errores durante la creación o redimensionamiento del vector.

sg_vector_item_count() devuelve el número de elementos actualmente en uso en el vector. Si el puntero del vector es NULL, devuelve 0.

VECTOR_CREATE()

VECTOR_CREATE() llama a sg_vector_create() con alloc_count = block_size y initial_used = 0, utilizando la información de inicialización del vector de especialización del tipo type.

VECTOR_CLEAR()

VECTOR_CLEAR() simplemente llama a sg_vector_clear(). Esta macro existe solo por conformidad.

VECTOR_CREATE_OR_RESIZE()

VECTOR_CREATE_OR_RESIZE() llama a sg_vector_create() cuando el puntero del vector dado apunta a NULL o a sg_vector_resize() en caso contrario. Devuelve el resultado de la función apropiada.

VECTOR_UPDATE()

VECTOR_UPDATE() llama a VECTOR_CREATE_OR_RESIZE() y establece los datos al primer elemento del vector resultante si se obtiene un puntero no NULL, de lo contrario a NULL. Cuando VECTOR_CREATE_OR_RESIZE() devuelve un puntero NULL y new_count no es igual a 0 (cero), se ejecutan las instrucciones de la macro VECTOR_UPDATE_ERROR_CLEANUP para limpiar antes de devolver desde la subrutina actual con el error que ha ocurrido.

VECTOR_ITEM_COUNT()

VECTOR_ITEM_COUNT() devuelve 0 para un vector no existente (vector == NULL) y el número de elementos contenidos en caso contrario.

RETURN VALUES

Además de los códigos de error, los valores de retorno, si los hay, son siempre un puntero a estructuras de vector (struct sg_vector *).
