subrutina sget51 (integer itype, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldv, * ) v, integer ldv, real, dimension( * ) work, real result)

SGET51

Propósito:

!>
!>      SGET51  generalmente verifica una descomposición de la forma
!>
!>              A = U B V'
!>
!>      donde ' significa transpuesta y U y V son ortogonales.
!>
!>      Específicamente, si ITYPE=1
!>
!>              RESULT = | A - U B V' | / ( |A| n ulp )
!>
!>      Si ITYPE=2, entonces:
!>
!>              RESULT = | A - B | / ( |A| n ulp )
!>
!>      Si ITYPE=3, entonces:
!>
!>              RESULT = | I - UU' | / ( n ulp )
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de pruebas a realizar.
!>          =1: RESULT = | A - U B V' | / ( |A| n ulp )
!>          =2: RESULT = | A - B | / ( |A| n ulp )
!>          =3: RESULT = | I - UU' | / ( n ulp )
!>

N

!>          N es INTEGER
!>          El tamaño de la matriz. Si es cero, SGET51 no hace nada.
!>          Debe ser al menos cero.
!>

A

!>          A es un array REAL, dimensión (LDA, N)
!>          La matriz original (sin factorizar).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. Debe ser al menos 1
!>          y al menos N.
!>

B

!>          B es un array REAL, dimensión (LDB, N)
!>          La matriz factorizada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. Debe ser al menos 1
!>          y al menos N.
!>

U

!>          U es un array REAL, dimensión (LDU, N)
!>          La matriz ortogonal en el lado izquierdo de la
!>          descomposición.
!>          No se referencia si ITYPE=2
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U. LDU debe ser al menos N y
!>          al menos 1.
!>

V

!>          V es un array REAL, dimensión (LDV, N)
!>          La matriz ortogonal en el lado izquierdo de la
!>          descomposición.
!>          No se referencia si ITYPE=2
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de V. LDV debe ser al menos N y
!>          al menos 1.
!>

WORK

!>          WORK es un array REAL, dimensión (2*N**2)
!>

RESULT

!>          RESULT es REAL
!>          Los valores calculados por la prueba especificada por ITYPE.
!>          El valor está actualmente limitado a 1/ulp, para evitar desbordamientos.
!>          Los errores se marcan con RESULT=10/ulp.
!>
