subrutina sgtt02 (character trans, integer n, integer nrhs, real, dimension( * ) dl, real, dimension( * ) d, real, dimension( * ) du, real, dimension( ldx, * ) x, integer ldx, real, dimension( ldb, * ) b, integer ldb, real resid)

SGTT02

Propósito:

!>
!> SGTT02 calcula el residuo para la solución de un sistema tridiagonal
!> de ecuaciones:
!>    RESID = norm(B - op(A)*X) / (norm(op(A)) * norm(X) * EPS),
!> donde EPS es la epsilon de la máquina.
!> La norma utilizada es la norma 1.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER
!>          Especifica la forma del residuo.
!>          = 'N':  B - A    * X  (Sin transpuesta)
!>          = 'T':  B - A**T * X  (Transpuesta)
!>          = 'C':  B - A**H * X  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

DL

!>          DL es un array REAL, de dimensión (N-1)
!>          Los elementos sub-diagonales (n-1) de A.
!>

D

!>          D es un array REAL, de dimensión (N)
!>          Los elementos diagonales de A.
!>

DU

!>          DU es un array REAL, de dimensión (N-1)
!>          Los elementos super-diagonales (n-1) de A.
!>

X

!>          X es un array REAL, de dimensión (LDX,NRHS)
!>          En la entrada, los vectores de solución calculados X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

B

!>          B es un array REAL, de dimensión (LDB,NRHS)
!>          En la entrada, los vectores del lado derecho para el sistema de
!>          ecuaciones lineales.
!>          En la salida, B se sobrescribe con la diferencia B - op(A)*X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

RESID

!>          RESID es REAL
!>          norm(B - op(A)*X) / (norm(op(A)) * norm(X) * EPS)
!>
