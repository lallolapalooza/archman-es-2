NOMBRE

sgml2lyx - crear salida LyX desde un archivo fuente SGML DTD de LinuxDoc

SINOPSIS

sgml2lyx [opción-genérica...] archivo[.sgml]

DESCRIPCIÓN

sgml2lyx es una forma antigua y obsoleta del comando convertidor lyx de LinuxDoc-Tools (su nombre puede ser engañoso, ya que no es una herramienta para ninguna DTD SGML, solo soporta la DTD SGML LinuxDoc). Se recomienda usar ahora la nueva forma linuxdoc -B lyx. Convierte un archivo fuente SGML DTD de LinuxDoc a salida LyX. La salida aparecerá en archivo.lyx donde archivo es el nombre del archivo fuente SGML.

El par atributo/valor "output=lyx" se establece para condicionales.

OPCIONES

sgm2lyx acepta todas las opciones genéricas descritas en linuxdoc(1).

archivo
El archivo fuente SGML, llamado archivo o archivo.sgml

ARCHIVOS

Se utilizan muchos archivos y ejecutables en /usr/share/linuxdoc-tools y /usr/bin.

ERRORES

Ninguno conocido.

AUTOR
