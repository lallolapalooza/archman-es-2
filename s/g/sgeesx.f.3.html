DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subrutina sgeesx (character jobvs, character sort, external select, character sense, integer n, real, dimension( lda, * ) a, integer lda, integer sdim, real, dimension( * ) wr, real, dimension( * ) wi, real, dimension( ldvs, * ) vs, integer ldvs, real rconde, real rcondv, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, logical, dimension( * ) bwork, integer info)

SGEESX calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> SGEESX calcula para una matriz real no simétrica A de N por N, los
!> valores propios, la forma de Schur real T y, opcionalmente, la matriz de
!> vectores de Schur Z. Esto da la factorización de Schur A = Z*T*(Z**T).
!>
!> Opcionalmente, también ordena los valores propios en la diagonal de
!> la forma de Schur real para que los valores propios seleccionados estén
!> en la parte superior izquierda;
!> calcula un número recíproco de condición para el promedio de los
!> valores propios seleccionados (RCONDE); y calcula un número recíproco de
!> condición para el subespacio invariante derecho correspondiente a los
!> valores propios seleccionados (RCONDV). Las columnas principales de Z forman una
!> base ortonormal para este subespacio invariante.
!>
!> Para una explicación más detallada de los números recíprocos de condición RCONDE
!> y RCONDV, consulte la Sección 4.10 de la Guía del Usuario de LAPACK (donde
!> estas cantidades se llaman s y sep respectivamente).
!>
!> Una matriz real está en forma de Schur real si es superior cuasi-triangular
!> con bloques de 1x1 y 2x2. Los bloques de 2x2 se normalizarán en la
!> forma
!>           [  a  b  ]
!>           [  c  a  ]
!>
!> donde b*c < 0. Los valores propios de tal bloque son a +- sqrt(bc).
!>

Parámetros

JOBVS 
!>          JOBVS es CHARACTER*1
!>          = 'N': No se calculan vectores de Schur;
!>          = 'V': Se calculan vectores de Schur.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se deben ordenar o no los valores propios en la
!>          diagonal de la forma de Schur.
!>          = 'N': Los valores propios no se ordenan;
!>          = 'S': Los valores propios se ordenan (ver SELECT).
!>

SELECT

!>          SELECT es una FUNCIÓN LOGICAL de dos argumentos REALES
!>          SELECT debe ser declarada EXTERNAL en la subrutina de llamada.
!>          Si SORT = 'S', SELECT se utiliza para seleccionar valores propios para ordenar
!>          en la parte superior izquierda de la forma de Schur.
!>          Si SORT = 'N', SELECT no se referencia.
!>          Un valor propio WR(j)+sqrt(-1)*WI(j) se selecciona si
!>          SELECT(WR(j),WI(j)) es verdadero; es decir, si se selecciona uno de un
!>          par conjugado complejo de valores propios, entonces ambos
!>          se seleccionan. Tenga en cuenta que un valor propio complejo seleccionado puede no
!>          seguir satisfaciendo SELECT(WR(j),WI(j)) = .TRUE. después de ordenar, ya que
!>          la ordenación puede cambiar el valor de los valores propios
!>          complejos (especialmente si el valor propio no tiene condición).
!>          en este caso, INFO puede establecerse en N+3 (ver INFO abajo).
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué números recíprocos de condición se calculan.
!>          = 'N': No se calcula ninguno;
!>          = 'E': Se calcula solo para el promedio de los valores propios seleccionados;
!>          = 'V': Se calcula solo para el subespacio invariante derecho seleccionado;
!>          = 'B': Se calcula para ambos.
!>          Si SENSE = 'E', 'V' o 'B', SORT debe ser igual a 'S'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array REAL, dimension (LDA, N)
!>          En la entrada, la matriz N por N A.
!>          En la salida, A se sobrescribe con su forma de Schur real T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de ordenar)
!>                         para los cuales SELECT es verdadero. (Pares conjugados complejos
!>                         para los cuales SELECT es verdadero para cualquiera de los
!>                         valores propios se cuentan como 2.)
!>

WR

!>          WR es un array REAL, dimension (N)
!>

WI

!>          WI es un array REAL, dimension (N)
!>          WR y WI contienen las partes real e imaginaria, respectivamente,
!>          de los valores propios calculados, en el mismo orden en que aparecen
!>          en la diagonal de la forma de Schur de salida T. Los pares conjugados
!>          complejos de valores propios aparecen consecutivamente con el
!>          valor propio que tiene la parte imaginaria positiva primero.
!>

VS

!>          VS es un array REAL, dimension (LDVS,N)
!>          Si JOBVS = 'V', VS contiene la matriz ortogonal Z de vectores de Schur.
!>          Si JOBVS = 'N', VS no se referencia.
!>

LDVS

!>          LDVS es INTEGER
!>          La dimensión principal del array VS. LDVS >= 1, y si
!>          JOBVS = 'V', LDVS >= N.
!>

RCONDE

!>          RCONDE es REAL
!>          Si SENSE = 'E' o 'B', RCONDE contiene el número recíproco
!>          de condición para el promedio de los valores propios seleccionados.
!>          No se referencia si SENSE = 'N' o 'V'.
!>

RCONDV

!>          RCONDV es REAL
!>          Si SENSE = 'V' o 'B', RCONDV contiene el número recíproco
!>          de condición para el subespacio invariante derecho seleccionado.
!>          No se referencia si SENSE = 'N' o 'E'.
!>

WORK

!>          WORK es un array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,3*N).
!>          Además, si SENSE = 'E', 'V' o 'B',
!>          LWORK >= N+2*SDIM*(N-SDIM), donde SDIM es el número de
!>          valores propios seleccionados calculados por esta rutina.
!>          Tenga en cuenta que N+2*SDIM*(N-SDIM) <= N+N*N/2. Tenga en cuenta también que solo se
!>          devuelve un error si LWORK < max(1,3*N), pero si SENSE = 'E' o 'V' o
!>          'B', esto puede no ser suficiente.
!>          Para un buen rendimiento, LWORK generalmente debe ser mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los límites superiores para los tamaños óptimos de los
!>          arrays WORK y IWORK, devuelve estos valores como las primeras
!>          entradas de los arrays WORK y IWORK, y XERBLA no emite mensajes de error
!>          relacionados con LWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimension (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          LIWORK >= 1; si SENSE = 'V' o 'B', LIWORK >= SDIM*(N-SDIM).
!>          Tenga en cuenta que SDIM*(N-SDIM) <= N*N/4. Tenga en cuenta también que solo se
!>          devuelve un error si LIWORK < 1, pero si SENSE = 'V' o 'B', esto
!>          puede no ser suficiente.
!>
