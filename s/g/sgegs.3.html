subroutine sgegs (character jobvsl, character jobvsr, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) alphar, real, dimension( * ) alphai, real, dimension( * ) beta, real, dimension( ldvsl, * ) vsl, integer ldvsl, real, dimension( ldvsr, * ) vsr, integer ldvsr, real, dimension( * ) work, integer lwork, integer info)

SGEGS calcula los valores propios, la forma de Schur real y, opcionalmente, los vectores de Schur izquierdos y/o derechos de un par de matrices reales (A,B)

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina SGGES.
!>
!> SGEGS calcula los valores propios, la forma de Schur real y, opcionalmente,
!> los vectores de Schur izquierdos y/o derechos de un par de matrices reales
!> (A,B).
!> Dadas dos matrices cuadradas A y B, la factorización de Schur real generalizada
!> tiene la forma
!>
!>   A = Q*S*Z**T,  B = Q*T*Z**T
!>
!> donde Q y Z son matrices ortogonales, T es triangular superior, y S
!> es una matriz cuasi-triangular superior con bloques diagonales de 1x1 y 2x2,
!> los bloques de 2x2 corresponden a pares conjugados de valores propios de (A,B).
!> Las columnas de Q son los vectores de Schur izquierdos y las columnas de Z
!> son los vectores de Schur derechos.
!>
!> Si solo se necesitan los valores propios de (A,B), se debe usar la rutina
!> de control SGEGV. Consulte SGEGV para una descripción de los valores
!> propios del problema de valores propios generalizado no simétrico
!> (GNEP).
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur izquierdos;
!>          = 'V':  calcular los vectores de Schur izquierdos (devueltos en VSL).
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur derechos;
!>          = 'V':  calcular los vectores de Schur derechos (devueltos en VSR).
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR.  N >= 0.
!>

A

!>          A es array REAL, dimension (LDA, N)
!>          En la entrada, la matriz A.
!>          En la salida, la matriz cuasi-triangular superior S de la
!>          factorización de Schur generalizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es array REAL, dimension (LDB, N)
!>          En la entrada, la matriz B.
!>          En la salida, la matriz triangular superior T de la factorización
!>          de Schur generalizada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHAR

!>          ALPHAR es array REAL, dimension (N)
!>          Las partes reales de cada escalar alfa que define un valor propio
!>          de GNEP.
!>

ALPHAI

!>          ALPHAI es array REAL, dimension (N)
!>          Las partes imaginarias de cada escalar alfa que define un
!>          valor propio de GNEP.  Si ALPHAI(j) es cero, entonces el j-ésimo
!>          valor propio es real; si es positivo, entonces el j-ésimo y (j+1)-ésimo
!>          valores propios son un par conjugado complejo, con
!>          ALPHAI(j+1) = -ALPHAI(j).
!>

BETA

!>          BETA es array REAL, dimension (N)
!>          Los escalares beta que definen los valores propios de GNEP.
!>          En conjunto, las cantidades alfa = (ALPHAR(j),ALPHAI(j)) y
!>          beta = BETA(j) representan el j-ésimo valor propio del par de
!>          matrices (A,B), en una de las formas lambda = alpha/beta o
!>          mu = beta/alpha. Dado que lambda o mu pueden desbordarse,
!>          no deben, en general, calcularse.
!>

VSL

!>          VSL es array REAL, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', la matriz de vectores de Schur izquierdos Q.
!>          No referenciada si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL es INTEGER
!>          La dimensión principal de la matriz VSL. LDVSL >=1, y
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR es array REAL, dimension (LDVSR,N)
!>          Si JOBVSR = 'V', la matriz de vectores de Schur derechos Z.
!>          No referenciada si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR es INTEGER
!>          La dimensión principal de la matriz VSR. LDVSR >= 1, y
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK es array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,4*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>          Para calcular el valor óptimo de LWORK, llame a ILAENV para obtener
!>          los tamaños de bloque (para SGEQRF, SORMQR y SORGQR). Luego calcule:
!>          NB  -- MAX de los tamaños de bloque para SGEQRF, SORMQR y SORGQR
!>          El LWORK óptimo es  2*N + N*(NB+1).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite ningún mensaje
!>          de error relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          = 1,...,N:
!>                La iteración QZ falló.  (A,B) no están en forma de Schur,
!>                pero ALPHAR(j), ALPHAI(j), y BETA(j) deberían ser correctos
!>                para j=INFO+1,...,N.
!>          > N:  errores que usualmente indican problemas de LAPACK:
!>                =N+1: retorno de error de SGGBAL
!>                =N+2: retorno de error de SGEQRF
!>                =N+3: retorno de error de SORMQR
!>                =N+4: retorno de error de SORGQR
!>                =N+5: retorno de error de SGGHRD
!>                =N+6: retorno de error de SHGEQZ (aparte de iteración fallida)
!>                =N+7: retorno de error de SGGBAK (cálculo de VSL)
!>                =N+8: retorno de error de SGGBAK (cálculo de VSR)
!>                =N+9: retorno de error de SLASCL (varios lugares)
!>

NAME

sgegs - the general, complex, single-precision Jacobi generalized eigenvalue problem

SYNOPSIS

SUBROUTINE SGEGS(A, LDA, B, LDB, ALPHA, BETA, WORK, LWORK, INFO)

This subroutine is part of the LAPACK library.

Function/Subroutine Documentation

SGEGS computes the eigenvalues and Schur vectors of a pair of general matrices (A, B).

Arguments:

  • A: REAL (kind=4) array, dimension (LDA, N). On entry, the first N columns of A contain the matrix A.
  • LDA: INTEGER. The leading dimension of the array A.
  • B: REAL (kind=4) array, dimension (LDB, N). On entry, the first N columns of B contain the matrix B.
  • LDB: INTEGER. The leading dimension of the array B.
  • ALPHA: REAL (kind=4) array, dimension (N). On exit, ALPHA(j) is related to the j-th eigenvalue.
  • BETA: REAL (kind=4) array, dimension (N). On exit, BETA(j) is related to the j-th eigenvalue.
  • WORK: REAL (kind=4) array, dimension (LWORK). Workspace array.
  • LWORK: INTEGER. The dimension of the array WORK.
  • INFO: INTEGER.
    • 0: successful exit
    • <0: if INFO = -i, the i-th argument had an illegal value
    • >0: if INFO = i, the i-th step of the QR iteration failed to converge

See the LAPACK documentation for detailed information on the algorithm and usage.
