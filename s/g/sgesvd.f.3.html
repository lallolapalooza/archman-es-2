SGESVD calcula la descomposición en valores singulares (SVD) de una matriz GE real

Propósito:

!>
!> SGESVD calcula la descomposición en valores singulares (SVD) de una matriz real
!> M-por-N A, calculando opcionalmente los vectores singulares izquierdos y/o derechos.
!> La SVD se escribe
!>
!>      A = U * SIGMA * transpose(V)
!>
!> donde SIGMA es una matriz M-por-N que es cero excepto por sus
!> min(m,n) elementos diagonales, U es una matriz ortogonal M-por-M, y
!> V es una matriz ortogonal N-por-N. Los elementos diagonales de SIGMA
!> son los valores singulares de A; son reales y no negativos, y
!> se devuelven en orden descendente. Las primeras min(m,n) columnas de
!> U y V son los vectores singulares izquierdos y derechos de A.
!>
!> ¡Tenga en cuenta que la rutina devuelve V**T, no V!
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          Especifica opciones para calcular toda o parte de la matriz U:
!>          = 'A':  se devuelven todas las M columnas de U en el array U:
!>          = 'S':  se devuelven las primeras min(m,n) columnas de U (los vectores singulares
!>                  izquierdos) en el array U;
!>          = 'O':  se sobrescriben las primeras min(m,n) columnas de U (los vectores singulares
!>                  izquierdos) en el array A;
!>          = 'N':  no se calculan columnas de U (no hay vectores singulares izquierdos).
!>

JOBVT

!>          JOBVT es CHARACTER*1
!>          Especifica opciones para calcular toda o parte de la matriz
!>          V**T:
!>          = 'A':  se devuelven todas las N filas de V**T en el array VT;
!>          = 'S':  se devuelven las primeras min(m,n) filas de V**T (los vectores singulares
!>                  derechos) en el array VT;
!>          = 'O':  se sobrescriben las primeras min(m,n) filas de V**T (los vectores singulares
!>                  derechos) en el array A;
!>          = 'N':  no se calculan filas de V**T (no hay vectores singulares derechos).
!>
!>          JOBVT y JOBU no pueden ser ambos 'O'.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  N >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, la matriz M-por-N A.
!>          En la salida,
!>          si JOBU = 'O',  A se sobrescribe con las primeras min(m,n)
!>                          columnas de U (los vectores singulares izquierdos,
!>                          almacenados por columnas);
!>          si JOBVT = 'O', A se sobrescribe con las primeras min(m,n)
!>                          filas de V**T (los vectores singulares derechos,
!>                          almacenados por filas);
!>          si JOBU .ne. 'O' y JOBVT .ne. 'O', el contenido de A
!>                          se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

S

!>          S es array REAL, dimension (min(M,N))
!>          Los valores singulares de A, ordenados de modo que S(i) >= S(i+1).
!>

U

!>          U es array REAL, dimension (LDU,UCOL)
!>          (LDU,M) si JOBU = 'A' o (LDU,min(M,N)) si JOBU = 'S'.
!>          Si JOBU = 'A', U contiene la matriz ortogonal M-por-M U;
!>          Si JOBU = 'S', U contiene las primeras min(m,n) columnas de
!>          U (los vectores singulares izquierdos, almacenados por columnas);
!>          Si JOBU = 'N' o 'O', U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U.  LDU >= 1; si
!>          JOBU = 'S' o 'A', LDU >= M.
!>

VT

!>          VT es array REAL, dimension (LDVT,N)
!>          Si JOBVT = 'A', VT contiene la matriz ortogonal N-por-N
!>          V**T;
!>          Si JOBVT = 'S', VT contiene las primeras min(m,n) filas de
!>          V**T (los vectores singulares derechos, almacenados por filas);
!>          Si JOBVT = 'N' o 'O', VT no se referencia.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del array VT.  LDVT >= 1; si
!>          JOBVT = 'A', LDVT >= N; si JOBVT = 'S', LDVT >= min(M,N).
!>

WORK

!>          WORK es array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo;
!>          si INFO > 0, WORK(2:MIN(M,N)) contiene los elementos de la
!>          superdiagonal no convergentes de una matriz bidiagonal intermedia B
!>          cuya diagonal está en S (no necesariamente ordenada). B
!>          satisface A = U * B * VT, por lo que tiene los mismos valores singulares
!>          que A, y vectores singulares relacionados por U y VT.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= MAX(1,5*MIN(M,N)) para las rutas (ver comentarios dentro del código):
!>             - RUTA 1  (M mucho mayor que N, JOBU='N')
!>             - RUTA 1t (N mucho mayor que M, JOBVT='N')
!>          LWORK >= MAX(1,3*MIN(M,N)+MAX(M,N),5*MIN(M,N)) para las otras rutas
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si SBDSQR no convergió, INFO especifica cuántas
!>                superdiagonales de una forma bidiagonal intermedia B
!>                no convergieron a cero. Ver la descripción de WORK
!>                arriba para más detalles.
!>

sgesvd(3) - Manual de Arch Linux

NAME

SGESVD - Encuentra los valores singulares y los vectores singulares del siguiente problema de valores/vectores singulares de una matriz real de orden general.

SYNOPSIS

SUBROUTINE SGESVD(
     JOBU, JOBVT, M, N, A, LDA, S, U, LDU, VT, LDVT, WORK, LWORK, INFO
)
    LOGICAL, INTENT(IN) :: JOBU, JOBVT
    INTEGER, INTENT(IN) :: M, N, LDA, LDU, LDVT, LWORK, INFO
    REAL, DIMENSION(*,*), INTENT(INOUT) :: A
    REAL, DIMENSION(:), INTENT(OUT) :: S
    REAL, DIMENSION(:,:), INTENT(OUT) :: U
    REAL, DIMENSION(:,:), INTENT(OUT) :: VT
    REAL, DIMENSION(:), INTENT(OUT) :: WORK
    INTEGER, INTENT(OUT) :: INFO

Function/Subroutine Documentation

SGESVD calcula los valores singulares y los vectores singulares de una matriz real de orden general A de la siguiente forma:

A = U * S * VT

donde S es una matriz diagonal rectangular, la diagonal contiene los valores singulares no negativos de A, ordenados de mayor a menor, y U y VT son matrices unitarias. Los vectores singulares derechos (columnas de VT) y los vectores singulares izquierdos (columnas de U) son los vectores singulares correspondientes.

Parámetros:

  • JOBU (LOGICAL, INTENT(IN)):
    Indica si se calcularán los vectores singulares izquierdos (vectores singulares de A**T * A).
    - TRUE.: Los vectores singulares izquierdos U se calculan y se devuelven.
    - FALSE.: No se calculan los vectores singulares izquierdos U.
  • JOBVT (LOGICAL, INTENT(IN)):
    Indica si se calcularán los vectores singulares derechos (vectores singulares de A * A**T).
    - TRUE.: Los vectores singulares derechos VT se calculan y se devuelven.
    - FALSE.: No se calculan los vectores singulares derechos VT.
  • M (INTEGER, INTENT(IN)):
    Número de filas de la matriz A. 0 <= M.
  • N (INTEGER, INTENT(IN)):
    Número de columnas de la matriz A. 0 <= N.
  • A (REAL, DIMENSION(*,*), INTENT(INOUT)):
    Matriz de orden M x N. En la salida, A contiene información sobre las matrices U y VT, si se solicitaron.
  • LDA (INTEGER, INTENT(IN)):
    Longitud de la primera dimensión de A. LDA = max(1, M).
  • S (REAL, DIMENSION(:), INTENT(OUT)):
    Array de longitud min(M,N). Contiene los valores singulares de A en orden descendente.
  • U (REAL, DIMENSION(:,:), INTENT(OUT)):
    Array de orden M x M. Si JOBU es TRUE, U contiene las columnas ortonormales de los vectores singulares izquierdos de A.
  • LDU (INTEGER, INTENT(IN)):
    Longitud de la primera dimensión de U. LDU = max(1, M).
  • VT (REAL, DIMENSION(:,:), INTENT(OUT)):
    Array de orden N x N. Si JOBVT es TRUE, VT contiene las columnas ortonormales de los vectores singulares derechos de A. Por lo tanto, VT es la transpuesta de V.
  • LDVT (INTEGER, INTENT(IN)):
    Longitud de la primera dimensión de VT. LDVT = max(1, N).
  • WORK (REAL, DIMENSION(:), INTENT(OUT)):
    Array de trabajo. El tipo de dato es REAL.
  • LWORK (INTEGER, INTENT(IN)):
    Longitud del array WORK. Para una determinación correcta del tamaño de LWORK, se llama a SGESVDPARAM.
  • INFO (INTEGER, INTENT(OUT)):
    INFO = 0: ejecución correcta.
    INFO < 0: si el k-ésimo argumento, contando desde 1, tiene un valor ilegal.
    INFO > 0: si el algoritmo de convergencia no ha convergido; el valor de INFO indica el número de elementos en S que no han calculado sus valores singulares correctamente.
