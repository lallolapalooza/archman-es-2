sg_get_error_details(3)

Paquete: libstatgrab

Licencias: LGPL, GPL

sg_get_error(3) sg_get_error(3)

NOMBRE

sg_get_error, sg_get_error_arg, sg_get_error_errno, sg_str_error, sg_get_error_details, sg_strperror - obtener el último estado de error

SINOPSIS

#include <statgrab.h>


sg_error sg_get_error
(void);


const char *sg_get_error_arg
(void);


int sg_get_error_errno
(void);


sg_error sg_get_error_details
(sg_error_details *err_details);


const char *sg_str_error
(sg_error code);


char *sg_strperror
(char **buf, const sg_error_details * const err_details);

DESCRIPCIÓN

Existen cuatro funciones para obtener información sobre el último error ocurrido: sg_get_error, sg_get_error_arg, sg_get_error_errno y sg_get_error_details. Las funciones restantes están destinadas a mejorar la interfaz máquina-humano (por ejemplo, el registro de errores o un cuadro de mensaje): sg_str_error proporciona un nombre de error legible por humanos y sg_strperror prepara un mensaje de error completo para imprimir.

El argumento de error (sg_get_error_arg) se almacena por hilo y se reutiliza cada vez que ocurre un error. Si se pretende un uso posterior, duplicarlo es una estrategia adecuada. Lo mismo ocurre con el `error_arg` de `sg_error_details` proporcionado por sg_get_error_details.

Cuando alguien llama a la función sg_get_error_details con un puntero NULL, el último error se sobrescribe con uno nuevo que describe que sg_get_error_details se ha llamado con argumentos inválidos. Tenga cuidado.

Se permite llamar a la función sg_strperror con o sin detalles de error recopilados (err_details es NULL). En este último caso, el último error ocurrido en este hilo se utiliza para preparar el mensaje de error. Tenga en cuenta que el puntero del búfer debe ser distinto de NULL (apuntar a un valor l de `char *` existente), pero el valor l de `char *` al que apunta debe ser NULL. Cuando se invoca correctamente, solo hay dos posibles condiciones de error que pueden hacer fallar a sg_strperror: ENOMEM (sin memoria) y EINVAL (código de error inválido).

Ejemplo

if( NULL == sg_get_cpu_stats() ) {
    char *buf = NULL;
    if( NULL != sg_strperror( &buf, NULL ) ) {
        fprintf( stderr, "error al obtener estadísticas de CPU: %s\n", buf );
        free(buf);
        exit(255);
    }
    else {
        fprintf( stderr, "error al obtener estadísticas de CPU e información de error\n" );
        exit(255);
    }
}

VALORES DE RETORNO

Los detalles del error contienen la siguiente información:

typedef struct sg_error_details {
        sg_error error;
        int errno_value;
        const char *error_arg;
} sg_error_details;
error
El código de error de la biblioteca statgrab.
errno_value
El código de error del sistema operativo.
error_arg
Información adicional establecida cuando se informó el error.
