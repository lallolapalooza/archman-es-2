sg_get_swap_stats(3)

Paquete: libstatgrab

Licencias: LGPL, GPL

sg_get_mem_stats(3) sg_get_mem_stats(3)

NOMBRE

sg_get_mem_stats, sg_get_mem_stats_r, sg_free_mem_stats, sg_get_swap_stats, sg_get_swap_stats_r, sg_free_swap_stats - obtener estadísticas de VM

SINOPSIS

#include <statgrab.h>


sg_mem_stats *sg_get_mem_stats
(size_t *entries);


sg_mem_stats *sg_get_mem_stats_r
(size_t *entries);


sg_error sg_free_mem_stats
(sg_mem_stats *data);


sg_swap_stats *sg_get_swap_stats
(size_t *entries);


sg_swap_stats *sg_get_swap_stats_r
(size_t *entries);


sg_error sg_free_swap_stats
(sg_swap_stats *data);

DESCRIPCIÓN

Las estadísticas de memoria se acceden a través de la función sg_get_mem_stats() y la función sg_get_mem_stats_r(). Ambas devuelven un puntero a un búfer sg_mem_stats. Tenga en cuenta que esta estadística no necesita mapear todo el uso de memoria física, representa la memoria real utilizable por el sistema operativo.

Las estadísticas de intercambio se acceden a través de la función sg_get_swap_stats() y la función sg_get_swap_stats_r(). Ambas devuelven un puntero a un búfer sg_swap_stats.

Atajo de API

función devuelve propietario de los datos
sg_get_mem_stats sg_mem_stats * libstatgrab (local del hilo)
sg_get_mem_stats_r sg_mem_stats * llamador
sg_get_swap_stats sg_swap_stats * libstatgrab (local del hilo)
sg_get_swap_stats_r sg_swap_stats * llamador

El búfer sg_mem_stats recibido de sg_get_mem_stats_r() y el búfer sg_swap_stats recibido de sg_get_swap_stats_r() deben liberarse utilizando sg_free_mem_stats() o sg_free_swap_stats(), respectivamente, cuando ya no se necesiten. El llamador es responsable de hacerlo.

En el sistema operativo FreeBSD se requieren privilegios elevados para acceder a las estadísticas de intercambio. Hacer que el programa tenga el grupo kmem debería ser suficiente. Los programas que se ejecutan como root no tendrán este problema.

VALORES DE RETORNO

Las llamadas al sistema de VM pueden devolver un puntero a sg_mem_stats o sg_swap_stats.

typedef struct{
        unsigned long long total;
        unsigned long long free;
        unsigned long long used;
        unsigned long long cache;
        time_t systime;
} sg_mem_stats;
total
La cantidad total de memoria real en bytes.
libre
La cantidad libre de memoria real en bytes.
usado
La cantidad usada de memoria real en bytes.
caché
La cantidad de memoria real en bytes utilizada para el almacenamiento en caché.
systime
la marca de tiempo cuando se recopilaron las estadísticas anteriores en segundos desde la época
typedef struct {
        unsigned long long total;
        unsigned long long used;
        unsigned long long free;
        time_t systime;
} sg_swap_stats;
total
El espacio de intercambio total en bytes.
usado
El intercambio usado en bytes.
libre
El intercambio libre en bytes.
systime
La marca de tiempo cuando se recopilaron las estadísticas anteriores en segundos desde la época

PENDIENTE

Añadir una función para mantener abierto el descriptor de archivo a las estructuras de memoria del kernel. Hacer esto permitiría que los privilegios elevados se descarten desde el principio.
