subroutine sgesvx (carácter fact, carácter trans, entero n, entero nrhs, real, dimensión( lda, * ) a, entero lda, real, dimensión( ldaf, * ) af, entero ldaf, entero, dimensión( * ) ipiv, carácter equed, real, dimensión( * ) r, real, dimensión( * ) c, real, dimensión( ldb, * ) b, entero ldb, real, dimensión( ldx, * ) x, entero ldx, real rcond, real, dimensión( * ) ferr, real, dimensión( * ) berr, real, dimensión( * ) work, entero, dimensión( * ) iwork, entero info)

SGESVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GE

Propósito:

!>
!> SGESVX utiliza la factorización LU para calcular la solución de un sistema real
!> de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz N por N y X y B son matrices N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Si el sistema se va a equilibrar o no depende del escalado de la matriz A,
!>    pero si se usa el equilibrado, A se sobrescribe con diag(R)*A*diag(C) y B con
!>    diag(R)*B (si TRANS='N') o diag(C)*B (si TRANS = 'T' o 'C').
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>       A = P * L * U,
!>    donde P es una matriz de permutación, L es una matriz triangular inferior unitaria,
!>    y U es triangular superior.
!>
!> 3. Si algún U(i,i)=0, de modo que U es exactamente singular, la rutina
!>    devuelve INFO = i. De lo contrario, la forma factorizada de A se utiliza
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina continúa
!>    resolviendo para X y calculando los límites de error como se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular los límites de error y las estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') de modo
!>    que resuelva el sistema original antes del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se proporciona
!>          en la entrada, y si no, si la matriz A debe equilibrarse antes de
!>          factorizarla.
!>          = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>                  Si EQUED no es 'N', la matriz A ha sido
!>                  equilibrada con los factores de escala dados por R y C.
!>                  A, AF e IPIV no se modifican.
!>          = 'N':  La matriz A se copiará a AF y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará a AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transposición)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada compleja, aunque aquí es real)
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz A de N por N.  Si FACT = 'F' y EQUED
!>          no es 'N', entonces A debe haber sido equilibrada por los
!>          factores de escala en R y/o C.  A no se modifica si FACT = 'F' o
!>          'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>          En la salida, si EQUED .ne. 'N', A se escala de la siguiente manera:
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array REAL, dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>          contiene los factores L y U de la factorización
!>          A = P*L*U tal como fue calculada por SGETRF. Si EQUED .ne. 'N', entonces
!>          AF es la forma factorizada de la matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>          devuelve los factores L y U de la factorización A = P*L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces AF es un argumento de salida y en la salida
!>          devuelve los factores L y U de la factorización A = P*L*U
!>          de la matriz equilibrada A (ver la descripción de A para
!>          la forma de la matriz equilibrada).
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene los índices de pivote de la factorización A = P*L*U
!>          calculada por SGETRF; la fila i de la matriz fue intercambiada con
!>          la fila IPIV(i).
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = P*L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = P*L*U
!>          de la matriz equilibrada A.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'R':  Equilibrado de filas, es decir, A ha sido premultiplicada por
!>                  diag(R).
!>          = 'C':  Equilibrado de columnas, es decir, A ha sido postmultiplicada
!>                  por diag(C).
!>          = 'B':  Equilibrado de filas y columnas, es decir, A ha sido
!>                  reemplazada por diag(R) * A * diag(C).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

R

real general band matrix inverse, solving

SYNOPSIS

SUBROUTINE SGESVX(
   FACT, TRANS, EQUED, N, NRHS,
   A, LDA, B, LDB, C, D, E, F,
   X, LDX, RCOND, FERR, BERR,
   WORK, IWORK, INFO
)
INTEGER N, NRHS, LDA, LDB, LDX, INFO
REAL A(LDA,*), B(LDB,*), C(*), D(*), E(*), F(*)
REAL X(LDX,*), RCOND, FERR(*), BERR(*)
REAL WORK(MAX(1,4*N))
INTEGER IWORK(N)
CHARACTER FACT, TRANS, EQUED

Function/Subroutine Documentation

This subroutine solves a real general band system of linear equations, A*X = B, A*X = B, or A**T*X = B, or A**H*X = B, depending on the values of TRANS and EQUED.

It uses the partial pivoting LU decomposition of A to compute the solution.

Equilibration is performed only if FACT = 'E'. Sgesvx is the elemental routine corresponding to the subroutine SGEEQU and the decomposition routine SGESV.

The condition number of the matrix A is estimated and the forward error bound is returned.

Arguments:

FACT

FACT is CHARACTER*1
  Specifies whether or not the equilibration factors computed by SGEEQU
  are supplied.
  = 'F': On entry, A, LDA, B, LDB, C, D, E, F, X, LDX, RCOND, FERR, BERR,
         WORK, and IWORK contain the information necessary to solve the
         system of equations.  The following procedure is followed:
            1. If EQUED = 'R' or 'B', scale B by diag(C) and diag(R).
            2. Apply the factorization to A.
            3. Apply the factorization to B.
            4. Solve the scaled system.
            5. Apply the scaling factors to the solution.
         On exit, the information necessary to solve the system of equations
         is returned in the arrays A, LDA, C, D, E, F, X, LDX, RCOND, FERR,
         BERR, WORK, and IWORK.
  = 'N': On entry, the factorization of A is not available, and the
         following procedure is followed:
            1. If EQUED = 'R' or 'B', scale B by diag(C) and diag(R).
            2. Compute the L and U factorization of A.
            3. Compute the condition number estimate RCOND.
            4. Apply the factorization to B.
            5. Solve the scaled system.
            6. Apply the scaling factors to the solution.
         On exit, the factors of A and the information to solve the system
         of equations are returned in the arrays A, LDA, C, D, E, F, X, LDX,
         RCOND, FERR, BERR, WORK, and IWORK.
  = 'E': On entry, the factorization of A is available and the
         equilibration factors C, D, E, F are supplied. The following
         procedure is followed:
            1. If EQUED = 'R' or 'B', scale B by diag(C) and diag(R).
            2. Apply the factorization to B.
            3. Solve the scaled system.
            4. Apply the scaling factors to the solution.
         On exit, the factors of A and the information to solve the system
         of equations are returned in the arrays A, LDA, C, D, E, F, X, LDX,
         RCOND, FERR, BERR, WORK, and IWORK.

TRANS

TRANS is CHARACTER*1
  Specifies the form of the system of equations:
  = 'N': A*X = B         (No transpose)
  = 'T': A**T*X = B      (Transpose)
  = 'C': A**H*X = B      (Conjugate transpose)

EQUED

EQUED is CHARACTER*1
  Specifies the form of equilibration whose factors are supplied if
  FACT = 'F'.
  = 'N': None of the scaling in the equations is done.
  = 'R': Scale A by diag(R) and B by diag(R).
  = 'C': Scale A by diag(C) and B by diag(C).
  = 'B': Scale A by diag(R) and diag(C).

N

N is INTEGER
  The order of the matrix A.  N >= 0.

NRHS

NRHS is INTEGER
  The number of right hand sides, i.e., the number of columns of the
  matrices B, X, D, E, F. NRHS >= 0.

A

A is REAL array, dimension (LDA,N)
  On entry, the N-by-N band matrix A.
  On exit, if FACT = 'N', A is overwritten by details of its LU factorization.
  If FACT = 'E', A is not available on exit.
  If FACT = 'F', A is not available on exit.

LDA

LDA is INTEGER
  The leading dimension of the array A.  LDA >= max(1,N).

B

B is REAL array, dimension (LDB,NRHS)
  On entry, the N-by-NRHS right hand side matrix B.
  On exit, B is overwritten by the solution matrix X if FACT = 'N'.
  If FACT = 'E' or 'F', B is not available on exit.

LDB

LDB is INTEGER
  The leading dimension of the array B.  LDB >= max(1,N).

C

C is REAL array, dimension (N)
  On entry, if EQUED = 'C' or 'B', C contains the diagonal elements of
  the scaling matrix R.  If EQUED = 'N' or 'R', C is not accessed.
  On exit, if FACT = 'N', C contains the diagonal elements of the scaling
  matrix R.  If FACT = 'E', C is not available on exit.
  If FACT = 'F', C is not available on exit.
  If FACT = 'N' and EQUED = 'C' or 'B', each element of C must be positive.

D

D is REAL array, dimension (N)
  On entry, if EQUED = 'R' or 'B', D contains the diagonal elements of
  the scaling matrix R.  If EQUED = 'N' or 'C', D is not accessed.
  On exit, if FACT = 'N', D contains the diagonal elements of the scaling
  matrix C.  If FACT = 'E', D is not available on exit.
  If FACT = 'F', D is not available on exit.
  If FACT = 'N' and EQUED = 'R' or 'B', each element of D must be positive.

E

E is REAL array, dimension (N)
  On entry, if EQUED = 'C' or 'B', E contains the diagonal elements of
  the scaling matrix C. If EQUED = 'N' or 'R', E is not accessed.
  On exit, if FACT = 'N', E contains the diagonal elements of the scaling
  matrix R. If FACT = 'E', E is not available on exit.
  If FACT = 'F', E is not available on exit.
  If FACT = 'N' and EQUED = 'C' or 'B', each element of E must be positive.

F

F is REAL array, dimension (N)
  On entry, if EQUED = 'R' or 'B', F contains the diagonal elements of
  the scaling matrix C. If EQUED = 'N' or 'C', F is not accessed.
  On exit, if FACT = 'N', F contains the diagonal elements of the scaling
  matrix C. If FACT = 'E', F is not available on exit.
  If FACT = 'F', F is not available on exit.
  If FACT = 'N' and EQUED = 'R' or 'B', each element of F must be positive.

X

X is REAL array, dimension (LDX,NRHS)
  On entry, the N-by-NRHS right hand side matrix B.
  On exit,
  if EQUED = 'N', B is not modified;
  if TRANS = 'N' and EQUED = 'R' or 'B', B is overwritten by
  diag(R)*B;
  if TRANS = 'T' or 'C' and EQUED = 'C' or 'B', B is
  overwritten by diag(C)*B.

LDB

LDB is INTEGER
  The leading dimension of the array B.  LDB >= max(1,N).

RCOND

RCOND is REAL
  The estimate of the reciprocal condition number of the matrix
  A after equilibration (if done). If RCOND is less than the
  machine precision (in particular, if RCOND = 0), the matrix
  is singular to working precision.  This condition is
  indicated by a return code of INFO > 0.

FERR

FERR is REAL array, dimension (NRHS)
  The estimated forward error bound for each solution vector
  X(j) (the j-th column of the solution matrix X).
  If XTRUE is the true solution corresponding to X(j), FERR(j)
  is an estimated upper bound for the magnitude of the largest
  element in (X(j) - XTRUE) divided by the magnitude of the
  largest element in X(j).  The estimate is as reliable as
  the estimate for RCOND, and is almost always a slight
  overestimate of the true error.

BERR

BERR is REAL array, dimension (NRHS)
  The componentwise relative backward error of each solution
  vector X(j) (i.e., the smallest relative change in
  any element of A or B that makes X(j) an exact solution).

WORK

WORK is REAL array, dimension (MAX(1,4*N))
  On exit, WORK(1) contains the reciprocal pivot growth
  factor norm(A)/norm(U). The infinity norm is
  used. If WORK(1) is much less than 1, then the stability
  of the LU factorization of the (equilibrated) matrix A
  could be poor. This also means that the solution X, condition
  estimator RCOND, and forward error bound FERR could be
  unreliable. If factorization fails with 0<INFO<=N, then
  WORK(1) contains the reciprocal pivot growth factor for the
  leading INFO columns of A.

IWORK

IWORK is INTEGER array, dimension (N)

INFO

INFO is INTEGER
  = 0:  successful exit
  < 0:  if INFO = -i, the i-th argument had an illegal value
  > 0:  if INFO = i, and i is
        <= N:  U(i,i) is exactly zero.  The factorization has
               been completed, but the factor U is exactly
               singular, so the solution and error bounds
               could not be computed. RCOND = 0 is returned.
        = N+1: U is nonsingular, but RCOND is less than machine
               precision, meaning that the matrix is singular
               to working precision.  Nevertheless, the
               solution and error bounds are computed because
               there are a number of situations where the
               computed solution can be more accurate than the
               value of RCOND would suggest.
