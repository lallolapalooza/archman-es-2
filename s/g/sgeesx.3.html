subroutine sgeesx (character jobvs, character sort, external select, character sense, integer n, real, dimension( lda, * ) a, integer lda, integer sdim, real, dimension( * ) wr, real, dimension( * ) wi, real, dimension( ldvs, * ) vs, integer ldvs, real rconde, real rcondv, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, logical, dimension( * ) bwork, integer info)

SGEESX calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> SGEESX calcula para una matriz real N-por-N no simétrica A, los
!> valores propios, la forma de Schur real T, y, opcionalmente, la matriz de
!> vectores de Schur Z. Esto da la factorización de Schur A = Z*T*(Z**T).
!>
!> Opcionalmente, también ordena los valores propios en la diagonal de
!> la forma de Schur real de modo que los valores propios seleccionados
!> estén en la parte superior izquierda;
!> calcula un número recíproco de condición para el promedio de
!> los valores propios seleccionados (RCONDE); y calcula un número recíproco de condición
!> para el subespacio invariante derecho correspondiente a los
!> valores propios seleccionados (RCONDV). Las columnas principales de Z forman una
!> base ortonormal para este subespacio invariante.
!>
!> Para más explicaciones sobre los números recíprocos de condición RCONDE
!> y RCONDV, véase la Sección 4.10 de la Guía del Usuario de LAPACK (donde
!> estas cantidades se llaman s y sep respectivamente).
!>
!> Una matriz real está en forma de Schur real si es quasi-triangular superior
!> con bloques de 1x1 y 2x2. Los bloques de 2x2 se estandarizarán en la forma
!> [  a  b  ]
!> [  c  a  ]
!>
!> donde b*c < 0. Los valores propios de tal bloque son a +- sqrt(bc).
!>

Parámetros

JOBVS 
!>          JOBVS es CHARACTER*1
!>          = 'N': No se calculan vectores de Schur;
!>          = 'V': Se calculan vectores de Schur.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se deben ordenar o no los valores propios en la
!>          diagonal de la forma de Schur.
!>          = 'N': Los valores propios no se ordenan;
!>          = 'S': Los valores propios se ordenan (ver SELECT).
!>

SELECT

!>          SELECT es una FUNCIÓN LOGICA de dos argumentos REALES
!>          SELECT debe declararse EXTERNAL en la subrutina llamante.
!>          Si SORT = 'S', SELECT se utiliza para seleccionar valores propios
!>          a ordenar en la parte superior izquierda de la forma de Schur.
!>          Si SORT = 'N', SELECT no se referencia.
!>          Un valor propio WR(j)+sqrt(-1)*WI(j) se selecciona si
!>          SELECT(WR(j),WI(j)) es verdadero; es decir, si se selecciona uno
!>          de un par conjugado complejo de valores propios, entonces ambos
!>          se seleccionan. Tenga en cuenta que un valor propio complejo seleccionado
!>          puede que ya no satisfaga SELECT(WR(j),WI(j)) = .TRUE. después de
!>          ordenarlo, ya que el ordenamiento puede cambiar el valor de los
!>          valores propios complejos (especialmente si el valor propio no es
!>          condicionado); en este caso, INFO puede establecerse en N+3 (ver INFO abajo).
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué números recíprocos de condición se calculan.
!>          = 'N': No se calcula ninguno;
!>          = 'E': Se calcula solo para el promedio de los valores propios seleccionados;
!>          = 'V': Se calcula solo para el subespacio invariante derecho seleccionado;
!>          = 'B': Se calcula para ambos.
!>          Si SENSE = 'E', 'V' o 'B', SORT debe ser igual a 'S'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA, N)
!>          En la entrada, la matriz N-por-N A.
!>          En la salida, A se sobrescribe con su forma de Schur real T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de ordenar)
!>                         para los cuales SELECT es verdadero. (Los pares
!>                         conjugados complejos para los cuales SELECT es
!>                         verdadero para cualquiera de los valores propios se
!>                         cuentan como 2.)
!>

WR

!>          WR es un array REAL, dimensión (N)
!>

WI

!>          WI es un array REAL, dimensión (N)
!>          WR y WI contienen las partes real e imaginaria, respectivamente,
!>          de los valores propios calculados, en el mismo orden en que
!>          aparecen en la diagonal de la forma de Schur de salida T. Los pares
!>          conjugados complejos de valores propios aparecen consecutivamente con
!>          el valor propio con la parte imaginaria positiva primero.
!>

VS

!>          VS es un array REAL, dimensión (LDVS,N)
!>          Si JOBVS = 'V', VS contiene la matriz ortogonal Z de vectores de Schur.
!>          Si JOBVS = 'N', VS no se referencia.
!>

LDVS

!>          LDVS es INTEGER
!>          La dimensión principal del array VS. LDVS >= 1, y si
!>          JOBVS = 'V', LDVS >= N.
!>

RCONDE

!>          RCONDE es REAL
!>          Si SENSE = 'E' o 'B', RCONDE contiene el número recíproco
!>          de condición para el promedio de los valores propios seleccionados.
!>          No se referencia si SENSE = 'N' o 'V'.
!>

RCONDV

!>          RCONDV es REAL
!>          Si SENSE = 'V' o 'B', RCONDV contiene el número recíproco
!>          de condición para el subespacio invariante derecho seleccionado.
!>          No se referencia si SENSE = 'N' o 'E'.
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,3*N).
!>          Además, si SENSE = 'E' o 'V' o 'B',
!>          LWORK >= N+2*SDIM*(N-SDIM), donde SDIM es el número de
!>          valores propios seleccionados calculados por esta rutina.
!>          Tenga en cuenta que N+2*SDIM*(N-SDIM) <= N+N*N/2. Tenga en cuenta
!>          también que solo se devuelve un error si LWORK < max(1,3*N),
!>          pero si SENSE = 'E' o 'V' o 'B', esto puede no ser suficiente.
!>          Para un buen rendimiento, LWORK generalmente debe ser mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula los límites superiores de los tamaños óptimos
!>          de los arrays WORK e IWORK, devuelve estos valores como las primeras
!>          entradas de los arrays WORK e IWORK, y XERBLA no emite mensajes de
!>          error relacionados con LWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          LIWORK >= 1; si SENSE = 'V' o 'B', LIWORK >= SDIM*(N-SDIM).
!>          Tenga en cuenta que SDIM*(N-SDIM) <= N*N/4. Tenga en cuenta
!>          también que solo se devuelve un error si LIWORK < 1, pero si
!>          SENSE = 'V' o 'B', esto puede no ser suficiente.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>

NAME


sgeesx - computes for the general complex matrix A, the eigenvalues and Schur
   factor (complex-vector). It also optionally computes the matrix of eigenvectors,
   the matrix of Schur vectors, and the condition numbers for the eigenvalues and
   right eigenvectors.

Function/Subroutine Documentation


SGEESX computes the eigenvalues and Schur factorization of a
   real matrix A. It also provides options for computing the left and right
   eigenvectors, sorting eigenvalues, and calculating condition numbers for the
   eigenvalues and eigenvectors.


Arguments



   
JOBVSL

   

      
JOBVSL is CHARACTER*1
   = 'N': do not compute the Schur vectors of A from the left.
   = 'V': compute the Schur vectors of A from the left.
   The Schur vectors are the columns of the matrix V of Schur
   factorization V*B*V**H, where B is the upper quasi-triangular matrix.
   

   

   
JOBVSR

   

      
JOBVSR is CHARACTER*1
   = 'N': do not compute the Schur vectors of A from the right.
   = 'V': compute the Schur vectors of A from the right.
   The Schur vectors are the columns of the matrix V of Schur
   factorization V*A*V**H, where V is the orthogonal matrix.
   

   

   
SORT

   

      
SORT is CHARACTER*1
   = 'N': ignore the SELECT logical array.
   = 'S': sort eigenvalues such that the selected ones are in the
   top left corner.
   

   

   
SELECT

   

      
SELECT is LOGICAL array, dimension (N)
   Elements of the array SELECT indicate whether or not a selected
   eigenvalue is to be sorted in the upper left corner of the Schur
   form:
   = TRUE: the i-th eigenvalue is selected.
   = FALSE: the i-th eigenvalue is not selected.
   If SORT = 'N', then the elements of SELECT are ignored.
   If SORT = 'S', then the eigenvalues with SELECT = TRUE are
   moved to the top left of the combined Schur form.
   

   

   
N

   

      
N is INTEGER
   The order of the matrix A. N >= 0.
   

   

   
A

   

      
A is REAL array, dimension (LDA, N)
   On entry, the N-by-N matrix A.
   On exit, A has been overwritten by its upper quasi-triangular
   Schur Schur form.
   

   

   
LDA

   

      
LDA is INTEGER
   The leading dimension of the array A. LDA >= max(1,N).
   

   

   
DUMMY

   

      
DUMMY is REAL array, dimension (LDVSL, N)
   If JOBVSL = 'V', DUMMY contains the left Schur vectors (left eigenvectors
   if the eigenvalues are sorted).
   If JOBVSL = 'N', the array DUMMY is not referenced.
   

   

   
LDVSL

   

      
LDVSL is INTEGER
   The leading dimension of the array DUMMY. LDVSL >= max(1,N).
   

   

   
DUMMY

   

      
DUMMY is REAL array, dimension (LDVSR, N)
   If JOBVSR = 'V', DUMMY contains the right Schur vectors (right eigenvectors
   if the eigenvalues are sorted).
   If JOBVSR = 'N', the array DUMMY is not referenced.
   

   

   
LDVSR

   

      
LDVSR is INTEGER
   The leading dimension of the array DUMMY. LDVSR >= max(1,N).
   

   

   
RCONDE

   

      
RCONDE is REAL array, dimension (N)
   RCONDE(I) is an estimate of the reciprocal condition number of the i-th
   eigenvalue.
   

   

   
RCONDV

   

      
RCONDV is REAL array, dimension (N)
   RCONDV(I) is an estimate of the reciprocal condition number of the i-th
   right eigenvector.
   

   

   
INFO

   

      
INFO is INTEGER
   = 0: successful exit
   < 0: if INFO = -i, the i-th argument had an illegal value.
   > 0: if INFO = i, and i is
      <= N: the QR algorithm failed to compute all the
            eigenvalues; elements 1:ILO-1 and i+1:N of WR and WI
            contain those eigenvalues which have converged; if
            JOBVS = 'V', VS contains the transformation which
            reduces A to its partially converged Schur form.
      = N+1: the eigenvalues could not be reordered because some
            eigenvalues were too close to separate (the problem
            is very ill-conditioned);
      = N+2: after reordering, roundoff changed values of some
            complex eigenvalues so that leading eigenvalues in
            the Schur form no longer satisfy SELECT=.TRUE.  This
            could also be caused by underflow due to scaling.
   

   




Description


   This routine is deprecated. Use SGEES instead.
   


The routine computes the eigenvalues and Schur factorization of a
   general real matrix A. The Schur factorization is an upper quasi-triangular
   matrix T such that A = Q*T*Q**T, where Q is an orthogonal matrix. The
   eigenvalues are the diagonal elements of T.


The routine also has options for computing the Schur vectors (columns
   of Q), sorting the eigenvalues, and computing condition numbers for the
   eigenvalues and the right eigenvectors.


The condition number estimates are computed using the routines SGECON,
   and DGECON, and they are based on the norm of the matrix and its inverse.


The routine returns the computed eigenvalues in the array WR and WI.
   The Schur vectors are returned in the array VS.


If the routine detects an error, it returns a negative value for INFO,
   indicating the position of the erroneous argument.


If the routine fails to compute all eigenvalues, it returns a positive
   value for INFO, indicating the number of eigenvalues that failed to converge.


The routine may also return INFO = N+1 or INFO = N+2 if the eigenvalues
   cannot be reordered or if roundoff errors cause issues during reordering.


The routine also computes reciprocal condition numbers for the eigenvalues
   and right eigenvectors. These are returned in the arrays RCONDE and RCONDV,
   respectively.


The routine only calculates upper bounds on the optimal sizes of the
   arrays WORK and IWORK, returns these values as the first entries of the
   WORK and IWORK arrays, and no error messages
   related to LWORK or LIWORK are issued by XERBLA.



BWORK


   BWORK is LOGICAL array, dimension (N)
   Not referenced if SORT = 'N'.



INFO


   INFO is INTEGER
   = 0: successful exit
   < 0: if INFO = -i, the i-th argument had an illegal value.
   > 0: if INFO = i, and i is
      <= N: the QR algorithm failed to compute all the
            eigenvalues; elements 1:ILO-1 and i+1:N of WR and WI
            contain those eigenvalues which have converged; if
            JOBVS = 'V', VS contains the transformation which
            reduces A to its partially converged Schur form.
      = N+1: the eigenvalues could not be reordered because some
            eigenvalues were too close to separate (the problem
            is very ill-conditioned);
      = N+2: after reordering, roundoff changed values of some
            complex eigenvalues so that leading eigenvalues in
            the Schur form no longer satisfy SELECT=.TRUE.  This
            could also be caused by underflow due to scaling.
