Documentación de la función/subrutina

subrutina sggrqf (integer m, integer p, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) taua, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) taub, real, dimension( * ) work, integer lwork, integer info)

SGGRQF

Propósito:

!>
!> SGGRQF calcula una factorización RQ generalizada de una matriz M-por-N A
!> y una matriz P-por-N B:
!>
!>             A = R*Q,        B = Z*T*Q,
!>
!> donde Q es una matriz ortogonal N-por-N, Z es una matriz ortogonal P-por-P,
!> y R y T asumen una de las siguientes formas:
!>
!> si M <= N,  R = ( 0  R12 ) M,   o si M > N,  R = ( R11 ) M-N,
!>                  N-M  M                           ( R21 ) N
!>                                                      N
!>
!> donde R12 o R21 es triangular superior, y
!>
!> si P >= N,  T = ( T11 ) N  ,   o si P < N,  T = ( T11  T12 ) P,
!>                 (  0  ) P-N                         P   N-P
!>                    N
!>
!> donde T11 es triangular superior.
!>
!> En particular, si B es cuadrada y no singular, la factorización GRQ
!> de A y B da implícitamente la factorización RQ de A*inv(B):
!>
!>              A*inv(B) = (R*inv(T))*Z**T
!>
!> donde inv(B) denota el inverso de la matriz B, y Z**T denota la
!> transpuesta de la matriz Z.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B. N >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, la matriz M-por-N A.
!>          En la salida, si M <= N, el triángulo superior de la submatriz
!>          A(1:M,N-M+1:N) contiene la matriz triangular superior R de M-por-M;
!>          si M > N, los elementos en y por encima de la (M-N)-ésima subdiagonal
!>          contienen la matriz trapezoidal superior R de M-por-N; los elementos restantes,
!>          junto con el array TAUA, representan la matriz ortogonal
!>          Q como un producto de reflectores elementales (ver Detalles Adicionales).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

TAUA

!>          TAUA es array REAL, dimension (min(M,N))
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz ortogonal Q (ver Detalles Adicionales).
!>

B

!>          B es array REAL, dimension (LDB,N)
!>          En la entrada, la matriz P-por-N B.
!>          En la salida, los elementos en y por encima de la diagonal del array
!>          contienen la matriz trapezoidal superior T de min(P,N)-por-N (T es
!>          triangular superior si P >= N); los elementos por debajo de la diagonal,
!>          junto con el array TAUB, representan la matriz ortogonal Z como un
!>          producto de reflectores elementales (ver Detalles Adicionales).
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,P).
!>

TAUB

!>          TAUB es array REAL, dimension (min(P,N))
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz ortogonal Z (ver Detalles Adicionales).
!>

WORK

!>          WORK es array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,N,M,P).
!>          Para un rendimiento óptimo, LWORK >= max(N,M,P)*max(NB1,NB2,NB3),
!>          donde NB1 es el tamaño de bloque óptimo para la factorización RQ
!>          de una matriz M-por-N, NB2 es el tamaño de bloque óptimo para la
!>          factorización QR de una matriz P-por-N, y NB3 es el tamaño de bloque óptimo
!>          para una llamada a SORMRQ.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INF0= -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - taua * v * v**T
!>
!>  donde taua es un escalar real, y v es un vector real con
!>  v(n-k+i+1:n) = 0 y v(n-k+i) = 1; v(1:n-k+i-1) se almacena en la salida en
!>  A(m-k+i,1:n-k+i-1), y taua en TAUA(i).
!>  Para formar Q explícitamente, use la subrutina LAPACK SORGRQ.
!>  Para usar Q para actualizar otra matriz, use la subrutina LAPACK SORMRQ.
!>
!>  La matriz Z se representa como un producto de reflectores elementales
!>
!>     Z = H(1) H(2) . . . H(k), donde k = min(p,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - taub * v * v**T
!>
!>  donde taub es un escalar real, y v es un vector real con
!>  v(1:i-1) = 0 y v(i) = 1; v(i+1:p) se almacena en la salida en B(i+1:p,i),
!>  y taub en TAUB(i).
!>  Para formar Z explícitamente, use la subrutina LAPACK SORGQR.
!>  Para usar Z para actualizar otra matriz, use la subrutina LAPACK SORMQR.
!>
