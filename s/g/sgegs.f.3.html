subroutine sgegs (character jobvsl, character jobvsr, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) alphar, real, dimension( * ) alphai, real, dimension( * ) beta, real, dimension( ldvsl, * ) vsl, integer ldvsl, real, dimension( ldvsr, * ) vsr, integer ldvsr, real, dimension( * ) work, integer lwork, integer info)

SGEGS calcula los valores propios, la forma de Schur real y, opcionalmente, los vectores de Schur izquierdos y/o derechos de un par de matrices reales (A,B)

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina SGGES.
!>
!> SGEGS calcula los valores propios, la forma de Schur real, y, opcionalmente,
!> los vectores de Schur izquierdos y/o derechos de un par de matrices reales (A,B).
!> Dadas dos matrices cuadradas A y B, la factorización de Schur real generalizada
!> tiene la forma
!>
!>   A = Q*S*Z**T,  B = Q*T*Z**T
!>
!> donde Q y Z son matrices ortogonales, T es triangular superior y S
!> es una matriz cuasi-triangular superior con bloques diagonales de 1x1 y 2x2,
!> los bloques de 2x2 corresponden a pares conjugados de valores propios de (A,B).
!> Las columnas de Q son los vectores de Schur izquierdos y las columnas de Z son los vectores de Schur derechos.
!>
!> Si solo se necesitan los valores propios de (A,B), se debe usar la rutina de
!> conducción SGEGV en su lugar. Consulte SGEGV para una descripción de los
!> valores propios del problema de valores propios generalizado no simétrico
!> (GNEP).
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur izquierdos;
!>          = 'V':  calcular los vectores de Schur izquierdos (devueltos en VSL).
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur derechos;
!>          = 'V':  calcular los vectores de Schur derechos (devueltos en VSR).
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA, N)
!>          En la entrada, la matriz A.
!>          En la salida, la matriz cuasi-triangular superior S de la
!>          factorización de Schur generalizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es array REAL, dimensión (LDB, N)
!>          En la entrada, la matriz B.
!>          En la salida, la matriz triangular superior T de la
!>          factorización de Schur generalizada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHAR

!>          ALPHAR es array REAL, dimensión (N)
!>          Las partes reales de cada escalar alfa que define un valor propio
!>          del GNEP.
!>

ALPHAI

!>          ALPHAI es array REAL, dimensión (N)
!>          Las partes imaginarias de cada escalar alfa que define un
!>          valor propio del GNEP.  Si ALPHAI(j) es cero, entonces el j-ésimo
!>          valor propio es real; si es positivo, entonces el j-ésimo y (j+1)-ésimo
!>          valores propios son un par conjugado complejo, con
!>          ALPHAI(j+1) = -ALPHAI(j).
!>

BETA

!>          BETA es array REAL, dimensión (N)
!>          Los escalares beta que definen los valores propios del GNEP.
!>          Juntos, las cantidades alpha = (ALPHAR(j),ALPHAI(j)) y
!>          beta = BETA(j) representan el j-ésimo valor propio del par
!>          de matrices (A,B), en una de las formas lambda = alpha/beta o
!>          mu = beta/alpha.  Dado que lambda o mu pueden desbordarse,
!>          en general no deben calcularse.
!>

VSL

!>          VSL es array REAL, dimensión (LDVSL,N)
!>          Si JOBVSL = 'V', la matriz de vectores de Schur izquierdos Q.
!>          No referenciado si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL es INTEGER
!>          La dimensión principal de la matriz VSL. LDVSL >=1, y
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR es array REAL, dimensión (LDVSR,N)
!>          Si JOBVSR = 'V', la matriz de vectores de Schur derechos Z.
!>          No referenciado si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR es INTEGER
!>          La dimensión principal de la matriz VSR. LDVSR >= 1, y
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK es array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,4*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>          Para calcular el valor óptimo de LWORK, llame a ILAENV para obtener
!>          los tamaños de bloque (para SGEQRF, SORMQR y SORGQR). Luego calcule:
!>          NB  -- MAX de los tamaños de bloque para SGEQRF, SORMQR y SORGQR
!>          El LWORK óptimo es  2*N + N*(NB+1).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1,...,N:
!>                La iteración QZ falló.  (A,B) no están en forma de Schur,
!>                pero ALPHAR(j), ALPHAI(j) y BETA(j) deberían ser
!>                correctos para j=INFO+1,...,N.
!>          > N:  errores que usualmente indican problemas de LAPACK:
!>                =N+1: retorno de error de SGGBAL
!>                =N+2: retorno de error de SGEQRF
!>                =N+3: retorno de error de SORMQR
!>                =N+4: retorno de error de SORGQR
!>                =N+5: retorno de error de SGGHRD
!>                =N+6: retorno de error de SHGEQZ (aparte de la iteración fallida)
!>                =N+7: retorno de error de SGGBAK (cálculo de VSL)
!>                =N+8: retorno de error de SGGBAK (cálculo de VSR)
!>                =N+9: retorno de error de SLASCL (varios lugares)
!>

NAME

sgegs - computes the Schur factorization of a pair of general matrices (A, B)

SYNOPSIS

    SUBROUTINE SGEGS(A, LDA, B, LDB, ALPHA, BETA, Q, LDQ, Z, LDZ, WORK, LWORK, INFO)
        INTEGER          LDA, LDB, LDQ, LDZ, LWORK, INFO
        REAL             A(LDA, *)
        REAL             B(LDB, *)
        REAL             ALPHA(*)
        REAL             BETA(*)
        REAL             Q(LDQ, *)
        REAL             Z(LDZ, *)
        REAL             WORK(*)

Function/Subroutine Documentation

SGEGS computes the Schur factorization of a pair of general matrices (A, B), enabling you to solve the generalized eigenvalue problem Ax = λBx. The Schur factorization is defined as: A = Q ZT T B = Q U ZT where: - T is an upper triangular matrix. - U is an upper triangular matrix. - Q and Z are orthogonal matrices. The generalized eigenvalues are computed from the diagonal elements of T and U. Specifically, the i-th generalized eigenvalue λi is given by: λi = ALPHA(i) / BETA(i) This routine is part of the LAPACK (Linear Algebra PACKage) library.

Arguments

  • A: (Input/Output) The first general matrix A. On exit, A is overwritten by T.
  • LDA: (Input) The leading dimension of A.
  • B: (Input/Output) The second general matrix B. On exit, B is overwritten by U.
  • LDB: (Input) The leading dimension of B.
  • ALPHA: (Output) An array of size min(M, N) containing the diagonal elements of the upper triangular matrix derived from T.
  • BETA: (Output) An array of size min(M, N) containing the diagonal elements of the upper triangular matrix derived from U.
  • Q: (Output) The orthogonal matrix Q.
  • LDQ: (Input) The leading dimension of Q.
  • Z: (Output) The orthogonal matrix Z.
  • LDZ: (Input) The leading dimension of Z.
  • WORK: (Output) Workspace array.
  • LWORK: (Input) The dimension of the WORK array.
  • INFO: (Output) Integer.
    • 0: successful exit
    • <0: if INFO = -i, the i-th argument had an illegal value
    • 1: ...
    • 2: ...
    • 3: ...
    • 4: ...
    • 5: ...

Notes

The computation involves several steps, including balancing the matrices, applying Givens rotations to introduce zeros, and then reducing to Hessenberg triangular form.
