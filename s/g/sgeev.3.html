Documentación de la función/subrutina

subroutine sgeev (character jobvl, character jobvr, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) wr, real, dimension( * ) wi, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, real, dimension( * ) work, integer lwork, integer info)

SGEEV calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE

Propósito:

!>
!> SGEEV calcula para una matriz real no simétrica N-por-N A, los
!> valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos.
!>
!> El vector propio derecho v(j) de A satisface
!>                  A * v(j) = lambda(j) * v(j)
!> donde lambda(j) es su valor propio.
!> El vector propio izquierdo u(j) de A satisface
!>               u(j)**H * A = lambda(j) * u(j)**H
!> donde u(j)**H denota la transpuesta conjugada de u(j).
!>
!> Los vectores propios calculados se normalizan para tener una norma euclidiana
!> igual a 1 y el componente real más grande.
!>

Parámetros

JOBVL 
!>          JOBVL es CHARACTER*1
!>          = 'N': no se calculan los vectores propios izquierdos de A;
!>          = 'V': se calculan los vectores propios izquierdos de A.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N': no se calculan los vectores propios derechos de A;
!>          = 'V': se calculan los vectores propios derechos de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz N-por-N A.
!>          En la salida, A ha sido sobrescrita.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

WR

!>          WR es un array REAL, dimensión (N)
!>

WI

!>          WI es un array REAL, dimensión (N)
!>          WR y WI contienen las partes real e imaginaria,
!>          respectivamente, de los valores propios calculados.  Los pares
!>          de valores propios conjugados complejos aparecen consecutivamente
!>          con el valor propio que tiene la parte imaginaria positiva primero.
!>

VL

!>          VL es un array REAL, dimensión (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios izquierdos u(j) se almacenan
!>          uno tras otro en las columnas de VL, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVL = 'N', VL no se referencia.
!>          Si el j-ésimo valor propio es real, entonces u(j) = VL(:,j),
!>          la j-ésima columna de VL.
!>          Si el j-ésimo y (j+1)-ésimo valores propios forman un par
!>          conjugado complejo, entonces u(j) = VL(:,j) + i*VL(:,j+1) y
!>          u(j+1) = VL(:,j) - i*VL(:,j+1).
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.  LDVL >= 1; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array REAL, dimensión (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios derechos v(j) se almacenan
!>          uno tras otro en las columnas de VR, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVR = 'N', VR no se referencia.
!>          Si el j-ésimo valor propio es real, entonces v(j) = VR(:,j),
!>          la j-ésima columna de VR.
!>          Si el j-ésimo y (j+1)-ésimo valores propios forman un par
!>          conjugado complejo, entonces v(j) = VR(:,j) + i*VR(:,j+1) y
!>          v(j+1) = VR(:,j) - i*VR(:,j+1).
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.  LDVR >= 1; si
!>          JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,3*N), y
!>          si JOBVL = 'V' o JOBVR = 'V', LWORK >= 4*N.  Para un buen
!>          rendimiento, LWORK generalmente debe ser mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          > 0:  si INFO = i, el algoritmo QR no pudo calcular todos los
!>                valores propios, y no se calcularon vectores propios;
!>                los elementos i+1:N de WR y WI contienen valores propios que
!>                han convergido.
!>
