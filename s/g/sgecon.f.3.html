Documentación de Función/Subrutina

subroutine sgecon (character norm, integer n, real, dimension( lda, * ) a, integer lda, real anorm, real rcond, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SGECON

Propósito:

!>
!> SGECON estima el recíproco del número de condición de una matriz real
!> general A, en la norma 1 o en la norma infinito, utilizando la
!> factorización LU calculada por SGETRF.
!>
!> Se obtiene una estimación para norm(inv(A)), y el recíproco del número
!> de condición se calcula como
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica si se requiere el número de condición en norma 1 o
!>          en norma infinito:
!>          = '1' o 'O':  Norma 1;
!>          = 'I':         Norma infinito.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          Los factores L y U de la factorización A = P*L*U
!>          tal como se calcularon por SGETRF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

ANORM

!>          ANORM es REAL
!>          Si NORM = '1' o 'O', la norma 1 de la matriz original A.
!>          Si NORM = 'I', la norma infinito de la matriz original A.
!>

RCOND

!>          RCOND es REAL
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK es un array REAL, de dimensión (4*N)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>                Los NaN son valores ilegales para ANORM, y se propagan a
!>                la salida del parámetro RCOND.
!>                El infinito es ilegal para ANORM, y se propaga a la salida
!>                del parámetro RCOND como 0.
!>          = 1:  si RCOND = NaN, o
!>                   RCOND = Inf, o
!>                   la norma calculada de la inversa de A es 0.
!>                En este último caso, se devuelve RCOND = 0.
!>
