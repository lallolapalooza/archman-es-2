subroutine sgges3 (character jobvsl, character jobvsr, character sort, external selctg, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, integer sdim, real, dimension( * ) alphar, real, dimension( * ) alphai, real, dimension( * ) beta, real, dimension( ldvsl, * ) vsl, integer ldvsl, real, dimension( ldvsr, * ) vsr, integer ldvsr, real, dimension( * ) work, integer lwork, logical, dimension( * ) bwork, integer info)

SGGES3 calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE (algoritmo bloqueado)

Propósito:

!>
!> SGGES3 calcula para un par de matrices reales no simétricas N por N (A,B),
!> los valores propios generalizados, la forma de Schur generalizada (S,T),
!> opcionalmente, las matrices izquierda y/o derecha de vectores de Schur (VSL y
!> VSR). Esto da la factorización de Schur generalizada
!>
!>          (A,B) = ( (VSL)*S*(VSR)**T, (VSL)*T*(VSR)**T )
!>
!> Opcionalmente, también ordena los valores propios para que un clúster seleccionado
!> de valores propios aparezca en los bloques diagonales principales de la matriz
!> cuasi-triangular superior S y la matriz triangular superior T. Las columnas
!> principales de VSL y VSR forman entonces una base ortonormal para los
!> correspondientes subespacios de eigendecomposicion (deflating subspaces)
!> izquierdo y derecho.
!>
!> (Si solo se necesitan los valores propios generalizados, use el controlador
!> SGGEV en su lugar, que es más rápido.)
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una relación alpha/beta = w, tal que A - w*B es singular. Usualmente se
!> representa como el par (alpha,beta), ya que hay una interpretación razonable
!> para beta=0 o ambos siendo cero.
!>
!> Un par de matrices (S,T) está en forma de Schur generalizada si T es
!> triangular superior con diagonal no negativa y S es bloque triangular superior
!> con bloques de 1x1 y 2x2. Los bloques de 1x1 corresponden a valores propios
!> generalizados reales, mientras que los bloques de 2x2 de S serán
!>
!>          [ a b ]
!>          [ c d ]
!>
!> se hace haciendo que los elementos correspondientes de T tengan la forma:
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> y el par de bloques 2x2 correspondientes en S y T tendrá un par complejo
!> conjugado de valores propios generalizados.
!>
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur izquierdos;
!>          = 'V':  calcular los vectores de Schur izquierdos.
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur derechos;
!>          = 'V':  calcular los vectores de Schur derechos.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se deben ordenar o no los valores propios en la
!>          diagonal de la forma de Schur generalizada.
!>          = 'N':  Los valores propios no se ordenan;
!>          = 'S':  Los valores propios se ordenan (ver SELCTG);
!>

SELCTG

!>          SELCTG es una FUNCIÓN LOGICA de tres argumentos REALES
!>          SELCTG debe declararse EXTERNAL en la subrutina llamante.
!>          Si SORT = 'N', SELCTG no se referencia.
!>          Si SORT = 'S', SELCTG se utiliza para seleccionar los valores
!>          propios que se ordenarán en la parte superior izquierda de la
!>          forma de Schur.
!>          Un valor propio (ALPHAR(j)+ALPHAI(j))/BETA(j) se selecciona si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) es verdadero; es decir, si
!>          se selecciona uno de un par complejo conjugado de valores
!>          propios, entonces ambos valores propios complejos se seleccionan.
!>
!>          Tenga en cuenta que en el caso mal condicionado, un valor propio
!>          seleccionado puede que ya no cumpla SELCTG(ALPHAR(j),ALPHAI(j),
!>          BETA(j)) = .TRUE. después de ordenar. INFO se establecerá en N+2
!>          en este caso.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR. N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA, N)
!>          En la entrada, la primera del par de matrices.
!>          En la salida, A ha sido sobrescrita por su forma de Schur
!>          generalizada S.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. LDA >= max(1,N).
!>

B

!>          B es un array REAL, de dimensión (LDB, N)
!>          En la entrada, la segunda del par de matrices.
!>          En la salida, B ha sido sobrescrita por su forma de Schur
!>          generalizada T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de
!>          ordenar) para los cuales SELCTG es verdadero. (Los pares
!>          complejos conjugados para los cuales SELCTG es verdadero para
!>          cualquiera de los valores propios cuentan como 2.)
!>

ALPHAR

!>          ALPHAR es un array REAL, de dimensión (N)
!>

ALPHAI

!>          ALPHAI es un array REAL, de dimensión (N)
!>

BETA

!>          BETA es un array REAL, de dimensión (N)
!>          En la salida, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, serán
!>          los valores propios generalizados. ALPHAR(j) + ALPHAI(j)*i,
!>          y BETA(j), j=1,...,N son las diagonales de la forma de Schur
!>          compleja (S,T) que resultaría si los bloques diagonales de
!>          2x2 de la forma de Schur real de (A,B) se redujeran aún más a
!>          forma triangular usando transformaciones unitarias complejas
!>          de 2x2.
!>          Si ALPHAI(j) es cero, entonces el j-ésimo valor propio es real;
!>          si es positivo, entonces el j-ésimo y (j+1)-ésimo valores
!>          propios son un par complejo conjugado, con ALPHAI(j+1) negativo.
!>
!>          Nota: los cocientes ALPHAR(j)/BETA(j) y ALPHAI(j)/BETA(j)
!>          pueden fácilmente sobrefloar o subfloar, y BETA(j) puede incluso
!>          ser cero.
!>          Por lo tanto, el usuario debe evitar calcular la relación
!>          ingenua.
!>          Sin embargo, ALPHAR y ALPHAI siempre serán menores y
!>          generalmente comparables con norm(A) en magnitud, y BETA siempre
!>          menor y generalmente comparable con norm(B).
!>

VSL

!>          VSL es un array REAL, de dimensión (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contendrá los vectores de Schur izquierdos.
!>          No se referencia si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL es INTEGER
!>          La dimensión principal de la matriz VSL. LDVSL >=1, y
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR es un array REAL, de dimensión (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contendrá los vectores de Schur derechos.
!>          No se referencia si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR es INTEGER
!>          La dimensión principal de la matriz VSR. LDVSR >= 1, y
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N = 0, LWO
RK >= 1, de lo contrario LWORK >= 6*N+16. !> Para un buen rendimiento, LWORK generalmente debe ser mayor. !> !> Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina !> solo calcula el tamaño óptimo del array WORK, devuelve !> este valor como la primera entrada del array WORK, y no hay ningún mensaje de error !> relacionado con LWORK emitido por XERBLA. !>

BWORK

!>          BWORK es un array LOGICAL, de dimensión (N)
!>          No referenciado si SORT = 'N'.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1,...,N:
!>                La iteración QZ falló. (A,B) no están en forma de Schur,
!>                pero ALPHAR(j), ALPHAI(j) y BETA(j) deberían
!>                ser correctos para j=INFO+1,...,N.
!>          > N:  =N+1: falló otra cosa que la iteración QZ en SLAQZ0.
!>                =N+2: después de la reorganización, el redondeo cambió los valores de
!>                      algunos valores propios complejos de manera que los valores propios principales
!>                      en la forma de Schur generalizada ya no satisfacen SELCTG=.TRUE. Esto también
!>                      podría ser causado por escalado.
!>                =N+3: falló la reorganización en STGSEN.
!>
