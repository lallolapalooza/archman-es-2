SGGESX calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> SGGESX calcula para un par de matrices reales no simétricas N-por-N
!> (A,B), los valores propios generalizados, la forma real de Schur (S,T), y,
!> opcionalmente, las matrices izquierda y/o derecha de vectores de Schur (VSL y
!> VSR). Esto da la factorización de Schur generalizada
!>
!>      (A,B) = ( (VSL) S (VSR)**T, (VSL) T (VSR)**T )
!>
!> Opcionalmente, también ordena los valores propios para que un clúster seleccionado
!> de valores propios aparezca en los bloques diagonales principales de la matriz
!> superior cuasi-triangular S y la matriz triangular superior T; calcula
!> un número recíproco de condición para el promedio de los valores propios
!> seleccionados (RCONDE); y calcula un número recíproco de condición para
!> los subespacios de deflexión derecha e izquierda correspondientes a los
!> valores propios seleccionados (RCONDV). Las columnas principales de VSL y VSR forman
!> una base ortonormal para los subespacios propios (de deflexión) izquierdo y
!> derecho correspondientes.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una razón alpha/beta = w, tal que A - w*B es singular. Suele representarse
!> como el par (alpha,beta), ya que hay una interpretación razonable para beta=0
!> o para que ambos sean cero.
!>
!> Un par de matrices (S,T) está en forma de Schur generalizada real si T es
!> triangular superior con diagonal no negativa y S es de bloques superior
!> triangular con bloques de 1x1 y 2x2. Los bloques de 1x1 corresponden
!> a valores propios generalizados reales, mientras que los bloques de 2x2 de S serán
!>
!>      [ a  b ]
!>      [ c  d ]
!>
!> por hacer que los elementos correspondientes de T tengan la forma:
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> y el par de bloques de 2x2 correspondientes en S y T tendrá un par
!> de valores propios generalizados complejos conjugados.
!>
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur izquierdos;
!>          = 'V':  calcular los vectores de Schur izquierdos.
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur derechos;
!>          = 'V':  calcular los vectores de Schur derechos.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se ordenan o no los valores propios en la
!>          diagonal de la forma de Schur generalizada.
!>          = 'N':  Los valores propios no se ordenan;
!>          = 'S':  Los valores propios se ordenan (ver SELCTG).
!>

SELCTG

!>          SELCTG es una FUNCIÓN LÓGICA de tres argumentos REALES
!>          SELCTG debe declararse EXTERNA en la subrutina llamante.
!>          Si SORT = 'N', SELCTG no se referencia.
!>          Si SORT = 'S', SELCTG se usa para seleccionar los valores propios a ordenar
!>          en la parte superior izquierda de la forma de Schur.
!>          Un valor propio (ALPHAR(j)+ALPHAI(j))/BETA(j) se selecciona si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) es verdadero; es decir, si
!>          uno de un par de valores propios complejos conjugados se selecciona,
!>          entonces ambos valores propios complejos se seleccionan.
!>          Tenga en cuenta que un valor propio complejo seleccionado puede que ya no satisfaga
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) = .TRUE. después de ordenar,
!>          ya que el ordenamiento puede cambiar el valor de los valores propios
!>          complejos (especialmente si el valor propio está mal condicionado), en este
!>          caso INFO se establece en N+3.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué números recíprocos de condición se calculan.
!>          = 'N':  No se calcula ninguno;
!>          = 'E':  Calculado solo para el promedio de los valores propios seleccionados;
!>          = 'V':  Calculado solo para los subespacios de deflexión seleccionados;
!>          = 'B':  Calculado para ambos.
!>          Si SENSE = 'E', 'V', o 'B', SORT debe ser igual a 'S'.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR. N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA, N)
!>          En la entrada, la primera del par de matrices.
!>          En la salida, A ha sido sobrescrita por su forma de Schur
!>          generalizada S.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. LDA >= max(1,N).
!>

B

!>          B es un array REAL, de dimensión (LDB, N)
!>          En la entrada, la segunda del par de matrices.
!>          En la salida, B ha sido sobrescrita por su forma de Schur
!>          generalizada T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de ordenar)
!>          para los cuales SELCTG es verdadero. (Los pares conjugados complejos para los cuales
!>          SELCTG es verdadero para alguno de los valores propios cuentan como 2).
!>

ALPHAR

!>          ALPHAR es un array REAL, de dimensión (N)
!>

ALPHAI

!>          ALPHAI es un array REAL, de dimensión (N)
!>

BETA

!>          BETA es un array REAL, de dimensión (N)
!>          En la salida, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, serán
!>          los valores propios generalizados. ALPHAR(j) + ALPHAI(j)*i
!>          y BETA(j), j=1,...,N son las diagonales de la forma de Schur compleja
!>          (S,T) que resultaría si los bloques diagonales de 2x2
!>          de la forma real de Schur de (A,B) se redujeran aún más a
!>          forma triangular usando transformaciones unitarias complejas de 2x2.
!>          Si ALPHAI(j) es cero, entonces el j-ésimo valor propio es real; si
!>          es positivo, entonces el j-ésimo y (j+1)-ésimo valores propios son un
!>          par conjugado complejo, con ALPHAI(j+1) negativo.
!>
!>          Nota: los cocientes ALPHAR(j)/BETA(j) y ALPHAI(j)/BETA(j)
!>          pueden fácilmente desbordarse o subdesbordarse, y BETA(j) puede incluso ser cero.
!>          Por lo tanto, el usuario debe evitar calcular la razón ingenuamente.
!>          Sin embargo, ALPHAR y ALPHAI serán siempre menores y
!>          generalmente comparables con norm(A) en magnitud, y BETA siempre
!>          menor y generalmente comparable con norm(B).
!>

VSL

!>          VSL es un array REAL, de dimensión (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contendrá los vectores de Schur izquierdos

Function/Subroutine Documentation

Input Parameters

JOBVSL
CHARACTER

Specifies whether to compute the left Schur vectors of A.

    = 'N': do not compute the left Schur vectors.
    = 'V': compute the left Schur vectors VSL.
JOBVSR
CHARACTER

Specifies whether to compute the right Schur vectors of A.

    = 'N': do not compute the right Schur vectors.
    = 'V': compute the right Schur vectors VSR.
SORT
CHARACTER

Specifies whether to sort the eigenvalues.

    = 'N': do not sort eigenvalues. SL, SR, ALPHAR, ALPHAI and BETA
           remain in the original order.
    = 'S': sort eigenvalues such that the selected eigenvalues (in some
           sense) are in the top left corner of the generalized Schur
           form.
    eigenvalues are sorted according to the criteria in SELCTG.
SELCTG
LOGICAL FUNCTION of (ALPHAR, ALPHAI, BETA)

Specifies whether to select eigenvalues.

    If SORT = 'S', SELCTG is used to select eigenvalues to be sorted in
    the leading positions.
    SELCTG(alphar, alphai, beta) returns .TRUE. if the i-th eigenvalue
    (alphar(i), alphai(i), beta(i)) is selected, and .FALSE. otherwise.
    If SORT = 'N', SELCTG is not referenced.
N
INTEGER

The order of the matrices A and B. N >= 0.

A
REAL array, dimension (LDA, * )

The first upper quasi-triangular matrix of the pair (A,B).

LDA
INTEGER

The leading dimension of the array A. LDA >= max(1,N).

B
REAL array, dimension (LDB, * )

The second upper quasi-triangular matrix of the pair (A,B).

LDB
INTEGER

The leading dimension of the array B. LDB >= max(1,N).

ALPHAR
REAL array, dimension ( * )

The real parts of the complex eigenvalues of the pair (A,B).

ALPHAI
REAL array, dimension ( * )

The imaginary parts of the complex eigenvalues of the pair (A,B).

    The eigenvalues are (ALPHAR(I) + i*ALPHAI(I)) / BETA(I).
BETA
REAL array, dimension ( * )

The eigenvalues of the pair (A,B).

    The eigenvalues are (ALPHAR(I) + i*ALPHAI(I)) / BETA(I).
VSL
REAL array, dimension (LDVSL, N)

If JOBVSL = 'V', VSL is the desired matrix of left Schur vectors.

Not referenced if JOBVSL = 'N'.

LDVSL
INTEGER

The leading dimension of the matrix VSL. LDVSL >= 1, and if JOBVSL = 'V', LDVSL >= N.

VSR
REAL array, dimension (LDVSR, N)

If JOBVSR = 'V', VSR will contain the right Schur vectors.

Not referenced if JOBVSR = 'N'.

LDVSR
INTEGER

The leading dimension of the matrix VSR. LDVSR >= 1, and if JOBVSR = 'V', LDVSR >= N.

RCONDE
REAL array, dimension ( 2 )

If SENSE = 'E' or 'B', RCONDE(1) and RCONDE(2) contain the reciprocal condition numbers for the average of the selected eigenvalues.

Not referenced if SENSE = 'N' or 'V'.

RCONDV
REAL array, dimension ( 2 )

If SENSE = 'V' or 'B', RCONDV(1) and RCONDV(2) contain the reciprocal condition numbers for the selected deflating subspaces.

Not referenced if SENSE = 'N' or 'E'.

WORK
REAL array, dimension (MAX(1,LWORK))

On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK
INTEGER

The dimension of the array WORK.

    If N = 0, LWORK >= 1, else if SENSE = 'E', 'V', or 'B',
    LWORK >= max( 8*N, 6*N+16, 2*SDIM*(N-SDIM) ), else
    LWORK >= max( 8*N, 6*N+16 ).
    Note that 2*SDIM*(N-SDIM) <= N*N/2.
    Note also that an error is only returned if
    LWORK < max( 8*N, 6*N+16), but if SENSE = 'E' or 'V' or 'B'
    this may not be large enough.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the bound on the optimal size of the WORK array and the minimum size of the IWORK array, returns these values as the first entries of the WORK and IWORK arrays, and no error message related to LWORK or LIWORK is issued by XERBLA.

IWORK
INTEGER array, dimension (MAX(1,LIWORK))

On exit, if INFO = 0, IWORK(1) returns the minimum LIWORK.

LIWORK
INTEGER

The dimension of the array IWORK.

    If SENSE = 'N' or N = 0, LIWORK >= 1, otherwise
    LIWORK >= N+6.

If LIWORK = -1, then a workspace query is assumed; the routine only calculates the bound on the optimal size of the WORK array and the minimum size of the IWORK array, returns these values as the first entries of the WORK and IWORK arrays, and no error message related to LWORK or LIWORK is issued by XERBLA.

BWORK
LOGICAL array, dimension (N)

Not referenced if SORT = 'N'.

INFO
INTEGER

= 0: successful exit < 0: if INFO = -i, the i-th argument had an illegal value. = 1,...,N: The QZ iteration failed. (A,B) are not in Schur form, but ALPHAR(j), ALPHAI(j), and BETA(j) should be correct for j=INFO+1,...,N. > N: =N+1: other than QZ iteration failed in SHGEQZ =N+2: after reordering, roundoff changed values of some complex eigenvalues so that leading eigenvalues in the Generalized Schur form no longer satisfy SELCTG=.TRUE. This could also be caused due to scaling. =N+3: reordering failed in STGSEN.

Further Details:

    An approximate (asymptotic) bound on the average absolute error of
    the selected eigenvalues is

    EPS * norm((A, B)) / RCONDE( 1 ).

    An approximate (asymptotic) bound on the maximum angular error in
    the computed deflating subspaces is

    EPS * norm((A, B)) / RCONDV( 2 ).

    See LAPACK User's Guide, section 4.11 for more information.
