DESCRIPCIÓN

Las funciones sg_get_process_stats proporcionan estadísticas sobre los procesos en ejecución actualmente. Ambas funciones, sg_get_process_stats() y sg_get_process_stats_r(), toman un parámetro opcional de entradas, que apunta (cuando se proporciona) a un size_t para obtener el número de entradas del vector devuelto.

Las funciones sg_get_process_count_of() y sg_get_process_count_r() proporcionan una vista agregada de la tabla de procesos: entregan la cantidad de procesos por estado de proceso. sg_get_process_count() es en realidad una macro preprocesador para compatibilidad hacia atrás y llama a sg_get_process_count_of() con el parámetro pcs de sg_entire_process_count para emular el comportamiento hasta la versión 0.17.

Atajo de API

función devuelve propietario de los datos
sg_get_process_stats sg_process_stats * libstatgrab (local del hilo)
sg_get_process_stats_r sg_process_stats * llamador
sg_get_process_count_of sg_process_count * libstatgrab (local del hilo)
sg_get_process_count_r sg_process_count * llamador

Los vectores sg_process_stats recibidos de sg_get_process_stats_r() o los resúmenes sg_process_count recibidos de sg_get_process_count_r deben liberarse usando sg_free_process_stats() o sg_free_process_count(), respectivamente. El llamador es responsable de hacerlo cuando los datos ya no son necesarios.

Estas funciones comparan dos entradas sg_process_stats y devuelven un int para representar cuál es mayor. El uso principal de estas funciones es ser pasadas a qsort para ordenar sg_process_stats por el tipo dado.

Ejemplo

size_t entries;
sg_process_stats *proc_stats = NULL;
while( NULL != ( proc_stats = sg_get_process_stats_r(&entries) ) ) {
    /* ordenar entradas comparando el identificador del proceso */
    qsort( proc_stats, entries, sizeof(proc_stats[0]), &sg_process_compare_pid );
    show_proc_stats( proc_stats );
    sg_free_process_stats( proc_stats );
}

VALORES DE RETORNO

La estructura devuelta por sg_get_process_stats es de tipo sg_process_stats.

typedef struct {
        char *process_name;
        char *proctitle;
        pid_t pid;    /* identificador del proceso */
        pid_t parent; /* PID del padre */
        pid_t pgid;   /* PID del líder del grupo de procesos */
        pid_t sessid; /* ID de sesión del proceso */
        uid_t uid;
        uid_t euid;
        gid_t gid;
        gid_t egid;
        unsigned long long context_switches;
        unsigned long long voluntary_context_switches;
        unsigned long long involuntary_context_switches;
        unsigned long long proc_size; /* en bytes */
        unsigned long long proc_resident; /* en bytes */
        time_t start_time; /* Cuándo se inició el proceso */
        time_t time_spent; /* tiempo de ejecución en segundos */
        double cpu_percent;
        int nice;
        sg_process_state state;
        time_t systime;
} sg_process_stats;

typedef enum {
        SG_PROCESS_STATE_RUNNING,
        SG_PROCESS_STATE_SLEEPING,
        SG_PROCESS_STATE_STOPPED,
        SG_PROCESS_STATE_ZOMBIE,
        SG_PROCESS_STATE_UNKNOWN
} sg_process_state;
process_name
El nombre del comando que se ejecutó. El contenido de este campo depende en gran medida del sistema operativo subyacente; algunos almacenan el nombre base del ejecutable que se pasa a la llamada del sistema exec(2), otros la ruta completa. La mayoría de los sistemas operativos restringen el tamaño de este campo; algunos, como la familia *BSD, a un valor muy bajo de 15 bytes.

Este campo suele ser inmutable para los procesos del espacio de usuario.

proctitle
La línea de comandos (el "título") del proceso. Tenga en cuenta que esto puede ser modificado por el proceso, por lo que no se garantiza que sea la línea de comandos original.
pid
El ID del proceso.
parent
El PID del proceso padre.
pgid
El PID del líder del grupo de procesos.
sessid
ID de sesión a la que pertenece el proceso.
uid
El ID del usuario con el que se está ejecutando el proceso.
euid
El ID del usuario efectivo con el que se está ejecutando el proceso.
gid
El ID del grupo con el que se está ejecutando el proceso.
egid
El ID del grupo efectivo con el que se está ejecutando el proceso.
context_switches
El número de cambios de contexto de este proceso (voluntarios e involuntarios).
voluntary_context_switches
El número de cambios de contexto voluntarios de este proceso (por ejemplo, llamando a sched_yield() o sleep()).
involuntary_context_switches
El número de cambios de contexto involuntarios de este proceso (por ejemplo, tiempo de ejecución agotado o señal enviada).
proc_size
El tamaño de la memoria virtual del proceso en bytes.
proc_resident
El tamaño del proceso que reside en memoria.
start_time
La hora en que se inició el proceso en segundos desde la época.
time_spent
El número de segundos que el proceso ha estado en ejecución (tiempo de usuario+sistema, sin el tiempo dedicado por procesos hijos).
cpu_percent
El porcentaje actual de CPU que está utilizando el proceso.
nice
El valor nice del proceso.
state
El estado actual del proceso. Ver sg_process_state para los valores permitidos.
systime
El tiempo en segundos desde la época del momento en que se creó la estadística actual. Esto puede ser (pero no tiene por qué ser) el mismo momento para todas las entradas devueltas, independientemente de si se obtienen con una instantánea o se arman a partir de algún tipo de procfs.

La estructura devuelta por sg_get_process_count_of y sg_get_process_count_r es de tipo sg_process_count.

typedef enum sg_process_count_source {
        sg_entire_process_count,
        sg_last_process_count
} sg_process_count_source;

typedef struct{
        unsigned long long total;
        unsigned long long running;
        unsigned long long sleeping;
        unsigned long long stopped;
        unsigned long long zombie;
        unsigned long long unknown;
        time_t systime;
}sg_process_count;
total
El número total de procesos.
running
El número de procesos en ejecución.
sleeping
El número de procesos en espera.
stopped
El número de procesos detenidos.
zombie
El número de procesos zombis.
unknown
El número de procesos que no coinciden con ninguna de las categorías mencionadas anteriormente.
systime
El tiempo en segundos desde la época del momento en que se creó la estadística actual.

ERRORES

La primera llamada a sg_get_process_count_of(sg_last_process_count) devolverá lo mismo que sg_get_process_count_of(sg_entire_process_count).

Las funciones de comparación existen más por compatibilidad retroactiva que por mejoras de funcionalidad. La flexibilidad limitada (por ejemplo, orden inverso) y la falta de oportunidades de optimización para el compilador llevan a la recomendación de implementar las rutinas de comparación requeridas localmente.
