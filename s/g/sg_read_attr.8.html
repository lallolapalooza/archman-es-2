NOMBRE

sg_read_attr - enviar comando SCSI READ ATTRIBUTE

SINOPSIS

sg_read_attr [--cache] [--enumerate] [--ea=EA] [--filter=FL] [--first=FAI] [--help] [--hex] [--in=FN] [--lvn=LVN] [--maxlen=LEN] [--pn=PN] [--quiet] [--raw] [--readonly] [--sa=SA] [--verbose] [--version] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI READ ATTRIBUTE a DISPOSITIVO y muestra los datos devueltos. Este comando se introdujo en SPC-3 revisión 1 y, por lo tanto, es aplicable a todos los dispositivos SCSI. En la práctica, se utiliza principalmente para sistemas de cinta. Esta utilidad se basa en el borrador del estándar SPC-5, revisión 17 (spc5r17.pdf).

OPCIONES

Los argumentos de las opciones largas son obligatorios también para las opciones cortas.

-c, --cache
establece el bit CACHE en el cdb de READ ATTRIBUTE. Esto instruye al servidor del dispositivo a devolver los atributos cacheados. Por defecto, ese bit está borrado, lo que instruye al servidor del dispositivo a no devolver los atributos cacheados.
-e, --enumerate
enumera todos los atributos y acciones de servicio conocidos. Los atributos incluyen un identificador, longitud, formato y un nombre según lo definido por T10. Si se proporciona DISPOSITIVO, se ignora.
-E, --ea=EA
donde EA es una dirección de elemento que se coloca en el cdb de READ ATTRIBUTE. Este campo solo se encuentra en los borradores de SMC-2 y SMC-3 para cambiadores de medios, generalmente asociados con bibliotecas de cintas. Por defecto, este campo se establece en cero.
-f, --filter=FL
donde FL es un identificador de atributo en el rango de 0 a 65535 o -1. Los identificadores de atributos suelen darse en hexadecimal, en cuyo caso el número hexadecimal debe prefijarse con "0x" o tener una "h" al final. "-1" es el valor predeterminado y significa 'coincidir con todo'; para todos los demás valores de FL, solo se muestra el atributo coincidente.
-F, --first=FAI
donde FAI es el campo "primer identificador de atributo" en el cdb. Parece que la intención de este campo es que solo se devuelvan los atributos cuyos identificadores sean iguales o mayores que FAI. El valor predeterminado de FAI es cero. Los atributos se devuelven en orden ascendente de identificador.
-h, --help
muestra el mensaje de uso y luego sale.
-H, --hex
muestra la respuesta en hexadecimal en stdout. Cuando se usa una vez, toda la respuesta se muestra en hexadecimal ASCII con una dirección inicial (comenzando en 0) en cada línea. Cuando se usa dos veces, cada descriptor de atributo en la respuesta se muestra por separado en hexadecimal. Cuando se usa tres veces, toda la respuesta se muestra en hexadecimal sin dirección inicial (en cada línea).
La salida generada por '-HHH' (o --hex usado tres veces) puede ser redirigida a un archivo. Ese archivo estará en un formato adecuado para que --in=FN lo use en una invocación posterior.
-i, --in=FN
FN se trata como un nombre de archivo (o '-' para stdin) que contiene hexadecimal ASCII o binario que representa la respuesta a un comando READ ATTRIBUTE con acción de servicio 0x0 (es decir, valores de atributo (obtener)). Cuando se da esta opción, DISPOSITIVO (si también se da) se ignora.
Por defecto, se asume que FN contiene hexadecimal ASCII organizado como bytes delimitados por espacios, tabulaciones o comas. Se ignoran todos los caracteres desde (e incluyendo) "#" hasta el final de la línea. Si la opción --raw también se da, se asume que FN contiene datos binarios. Cuando se da la opción --raw, después de procesar la entrada, la variable interna raw se restablece a 0, por lo que no tiene efecto en la salida.
Dado que la respuesta de READ ATTRIBUTE no contiene el número de acción de servicio al que responde, se debe dar --sa=SA (si no, se asume la acción de servicio 0 (valores de atributo).
-l, --lvn=LVN
donde LVN se coloca en el campo "número de volumen lógico" del cdb. El valor predeterminado es cero, que se requiere que sea el número de volumen lógico si el dispositivo solo tiene un volumen.
-m, --maxlen=LEN
donde LEN es la longitud (máxima) de la respuesta en bytes. Se coloca en el campo "longitud de asignación" del cdb. Si no se da (o LEN es cero), se utilizan 8192. El valor máximo permitido de LEN es 1048576.
-p, --pn=PN
donde PN se coloca en el campo "número de partición" del cdb. Si el DISPOSITIVO solo tiene una partición, su número de partición debe ser cero. El valor predeterminado de PN es cero.
-q, --quiet
esta opción reduce la cantidad de información mostrada. Por ejemplo, cuando se usa una vez (SA=0), suprime la línea de encabezado que anuncia la salida de atributos; cuando se usa dos veces, suprime el nombre de cada atributo, dejando solo los valores (o cadenas) de atributos asociados.
-r, --raw
muestra la respuesta SCSI (es decir, el búfer de datos de salida) en binario (a stdout).
-R, --readonly
abre el DISPOSITIVO en modo de solo lectura (por ejemplo, en Unix con la bandera O_RDONLY). El valor predeterminado es abrirlo en modo de lectura/escritura.
-s, --sa=SA
donde SA se coloca en el campo "acción de servicio" del cdb. Se aceptan valores de 0 a 63, con un valor predeterminado de 0. spc5r08.pdf define cinco acciones de servicio: 0 para valores de atributos; 1 para una lista de atributos (nombres, no valores), 2 para la lista de volúmenes lógicos; 3 para la lista de particiones; 4 está restringido para SMC-3; y 5 para la lista de atributos compatibles.
Alternativamente, se puede dar un acrónimo para SA. El acrónimo debe ser uno de "av", "al", "lvl", "pn", "smc" o "sa" para las acciones de servicio 0 a 5 respectivamente. Los acrónimos también se pueden dar en mayúsculas.
-v, --verbose
aumenta el nivel de verbosidad (es decir, salida de depuración).
-V, --version
imprime la cadena de versión y luego sale.

NOTAS

Solo los sistemas de cinta parecen implementar el comando SCSI READ ATTRIBUTE. La gran mayoría de su definición está en el estándar SPC, por lo que otros tipos de dispositivos podrían usarlo.

Gran parte de la información proporcionada por READ ATTRIBUTE también se puede encontrar en páginas devueltas por LOG SENSE (ver la utilidad sg_logs) y en las páginas VPD devueltas por el comando INQUIRY.

EJEMPLOS

Para listar los atributos de una unidad de cinta cuyo DISPOSITIVO es /dev/sg1 , se podría usar lo siguiente:


# sg_read_attr -s al /dev/sg1
Lista de atributos:
Capacidad restante en partición [MiB]
Capacidad máxima en partición [MiB]
Indicadores TapeAlert
Número de carga
Espacio MAM restante [B]
Organización asignadora
Código de densidad de formato
...

Para verificar el número de particiones:


# sg_read_attr -s pl /dev/sg1
Lista de números de partición:
Número de primera partición: 0
Número de particiones disponibles: 2

Y para ver los valores de los atributos (que es la acción de servicio predeterminada):


# sg_read_attr /dev/sg1
Valores de atributos:
Capacidad restante en partición [MiB]: 1386103
Capacidad máxima en partición [MiB]: 1386103
Indicadores TapeAlert: 0
....

Para redirigir la respuesta de valores de atributos a un archivo para su posterior decodificación:


# sg_read_attr -HHH /dev/sg1 > av.hex

Y más tarde la respuesta contenida en el archivo av.hex podría ser decodificada

NAME

sg_read_attr - read attribute values from a SCSI device

SYNOPSIS

sg_read_attr [OPTIONS] DEVICE

DESCRIPTION

This utility reads one or more attribute values from the given SCSI device. The attributes are described in the SCSI Read Attribute command, SBC-4 draft.

OPTIONS

-d, --desc
print textual description of attribute names and values. Supported for most standard attributes.
-h, --help
print out the usage message then exit.
-H, --hex
output the values in hexadecimal.
-n, --num=attr_id
only read the attribute with the given numerical attr_id (a decimal integer). If this option is not given, all readable attributes are read.
-o, --out=file
write the output to the given file instead of stdout.
-r, --raw
output the raw attribute value bytes. Useful for further processing.
-s, --short
short form: print less verbose output.
-v, --verbose
increase the verbosity of the output.
-V, --version
print the version string and then exit.

NOTES

The Read Attribute command was introduced in SBC-4.

To get a list of standard attribute IDs, use `sg_vpd -a`. The command `sg_read_attr -d` will print attribute names and values when available.

EXAMPLES


# sg_read_attr -d /dev/sg0
Attribute values:
Attribute_group: 0x00, Attribute_id: 0x01 (In_use_power_condition)
Property: 0x00 (Non-volatile)
Attribute_value: 0x01 (Active power condition)
Attribute_type: 0x01 (Read-only)
Attribute_name: In use power condition
In use power condition: Active power condition

# sg_read_attr -s -d -o av.txt /dev/sdb
Written 12 bytes to av.txt

# cat av.txt
Attribute values:
Remaining capacity in partition [MiB]: 1386103
Maximum capacity in partition [MiB]: 1386103
TapeAlert flags: 0
....

EXIT STATUS

The exit status of sg_read_attr is 0 when it is successful. Otherwise see the sg3_utils(8) man page.
