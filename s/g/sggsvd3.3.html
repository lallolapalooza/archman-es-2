Documentación de la función/subrutina

subrutina sggsvd3 (character jobu, character jobv, character jobq, integer m, integer n, integer p, integer k, integer l, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) alpha, real, dimension( * ) beta, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldv, * ) v, integer ldv, real, dimension( ldq, * ) q, integer ldq, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

SGGSVD3 calcula la descomposición en valores singulares generalizada (GSVD) de una matriz real M por N A y una matriz real P por N B:

Propósito:

!>
!> SGGSVD3 calcula la descomposición en valores singulares generalizada (GSVD)
!> de una matriz real M por N A y una matriz real P por N B:
!>
!>       U**T*A*Q = D1*( 0 R ),    V**T*B*Q = D2*( 0 R )
!>
!> donde U, V y Q son matrices ortogonales.
!> Sea K+L = el rango numérico efectivo de la matriz (A**T,B**T)**T,
!> entonces R es una matriz triangular superior no singular de K+L por K+L, D1 y
!> D2 son matrices M por (K+L) y P por (K+L) respectivamente de las siguientes
!> estructuras:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) en la salida.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N), y R33 se almacena
!>   ( 0  R22 R23 )
!>   en B(M-K+1:L,N+M-K-L+1:N) en la salida.
!>
!> La rutina calcula C, S, R y, opcionalmente, las matrices de
!> transformaciones ortogonales U, V y Q.
!>
!> En particular, si B es una matriz B no singular N por N, entonces la GSVD de
!> A y B da implícitamente la SVD de A*inv(B):
!>                      A*inv(B) = U*(D1*inv(D2))*V**T.
!> Si ( A**T,B**T)**T  tiene columnas ortonormales, entonces la GSVD de A y B es
!> también igual a la descomposición CS de A y B. Además, la GSVD
!> puede usarse para derivar la solución del problema de valores propios:
!>                      A**T*A x = lambda* B**T*B x.
!> En alguna literatura, la GSVD de A y B se presenta en la forma
!>                  U**T*A*X = ( 0 D1 ),   V**T*B*X = ( 0 D2 )
!> donde U y V son ortogonales y X es no singular, D1 y D2 son
!> ``diagonales''. La forma GSVD anterior se puede convertir a la forma
!> posterior tomando la matriz no singular X como
!>
!>                      X = Q*( I   0    )
!>                            ( 0 inv(R) ).
!>

NAME

sggsvd3 - SGGV3 computes the singular value decomposition of a general matrix.

SYNOPSIS

  call sggsvd3( JOBA, JOBB, M, N, P, A, LDA, B, LDB, TOLEAR, TOLB,
                U, LDU, V, LDV, X, INFO )

  subroutine sggsvd3( JOB A, JOB B, M, N, P, A, LDA, B, LDB, TOLEAR,
                TOLB, U, LDU, V, LDV, X, INFO )

      CHARACTER(1) JOB A, JOB B
      INTEGER M, N, P, LDA, LDB, LDU, LDV, INFO
      REAL A( LDA, * ), B( LDB, * ), TOLEAR, TOLB, U( LDU, * ),
     $     V( LDV, * ), X( * )

Function/Subroutine Documentation

Given two matrices A and B, the subroutine sggsvd3 computes for them an

Orthogonal matrices U and V such that

A = U*S1*VT and B = V*S2*VT

or

A = U*S1*YT and B = V*S2*YT

where S1 and S2 are the diagonal matrices with non-negative real values S1 = diag(X) and S2 = diag(0), and Y is an orthogonal matrix.

S1 is an M-by-N matrix, S2 is a P-by-N matrix. The diagonal entries of X are the singular values. Note that the order of the singular values is descending.

Input Parameters

JOB A
CHARACTER(1). Specifies whether to compute the left singular vectors (U).
  • ='U': The left singular vectors (rows of U) are computed and returned in the array U.
  • ='N': The left singular vectors are not computed.
JOB B
CHARACTER(1). Specifies whether to compute the right singular vectors (V).
  • ='V': The right singular vectors (rows of V) are computed and returned in the array V.
  • ='N': The right singular vectors are not computed.
M
INTEGER. The number of rows of A. 0 <= M.
N
INTEGER. The number of columns of A. 0 <= N.
P
INTEGER. The number of rows of B. 0 <= P.
A
REAL array, dimension (LDA, K), where K = max(M,N).

On entry, the M-by-N matrix A.

On exit, the rows of A are determined by JOB A and JOB B.

LDA
INTEGER. The leading dimension of the array A. LDA >= max(1,M).
B
REAL array, dimension (LDB, K), where K = max(P,N).

On entry, the P-by-N matrix B.

On exit, the rows of B are determined by JOB A and JOB B.

LDB
INTEGER. The leading dimension of the array B. LDB >= max(1,P).
TOLEAR
REAL.

Desired tolerance for the singular values of A. If TOLEAR < 0, TOLER = MAX(M,N)*MACHEPS*norm(A).

TOLB
REAL.

Desired tolerance for the singular values of B. If TOLB < 0, TOLB = MAX(P,N)*MACHEPS*norm(B).

U
REAL array, dimension (LDU, M).

On exit, if JOB A = 'U', U contains the left singular vectors (rows of U), and the left singular vectors (columns of U) are returned in the array U.

If JOB A = 'N', U is not used.

LDU
INTEGER. The leading dimension of the array U. LDU >= max(1,M).
V
REAL array, dimension (LDV, K), where K = max(P,N).

On exit, if JOB B = 'V', V contains the right singular vectors (rows of V).

If JOB B = 'N', V is not used.

LDV
INTEGER. The leading dimension of the array V. LDV >= max(1,P).
X
REAL array, dimension (min(M,N,P)).

On exit, the singular values (the diagonal entries of S1).

INFO
INTEGER.
  • = 0: success.
  • < 0: if INFO = -i, the i-th argument had an illegal value.
  • > 0: failure.

Output Parameters

  WORK  REAL array, dimension (LWORK)
!>          The dimension of the array WORK. LWORK >= 1.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>          On exit, IWORK stores the sorting information. More
!>          precisely, the following loop will sort ALPHA
!>             for I = K+1, min(M,K+L)
!>                 swap ALPHA(I) and ALPHA(IWORK(I))
!>             endfor
!>          such that ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if INFO = 1, the Jacobi-type procedure failed to
!>                converge.  For further details, see subroutine STGSJA.
!>

Internal Parameters:

  TOLA    REAL
  TOLB    REAL
          TOLA and TOLB are the thresholds to determine the effective
          rank of (A**T,B**T)**T. Generally, they are set to
                  TOLA = MAX(M,N)*norm(A)*MACHEPS,
                  TOLB = MAX(P,N)*norm(B)*MACHEPS.
          The size of TOLA and TOLB may affect the size of backward
          errors of the decomposition.
