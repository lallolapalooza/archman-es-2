SGML2HTML(1) Manual de comandos generales SGML2HTML(1)

NOMBRE

sgml2html - crear salida HTML a partir de un archivo fuente SGML con la DTD LinuxDoc

SINOPSIS

sgml2html [opción-genérica...] [--split 0|1|2 ] [--toc 0|1|2 ] [--dosnames] [--imagebuttons] archivo[.sgml]

DESCRIPCIÓN

sgml2html es una forma antigua y obsoleta del comando de conversión html de LinuxDoc-Tools (su nombre puede ser engañoso, ya que no es una herramienta para ninguna DTD SGML, solo soporta la DTD SGML LinuxDoc). Se recomienda usar la nueva forma linuxdoc -B html ahora. Esto convierte un archivo fuente SGML con la DTD LinuxDoc a salida HTML. La salida aparecerá en el archivo de nivel superior archivo.html y archivo-n.html para cada sección, donde archivo es el nombre del archivo fuente SGML y n es el nombre de la sección.

El par atributo/valor "output=html" se establece para condicionales.

OPCIONES

sgml2html acepta todas las opciones genéricas descritas en linuxdoc(1), y las siguientes opciones específicas:

--split, -s
Nivel al que dividir los documentos fuente. 0 = no dividir, 1 = dividir por secciones principales, 2 = dividir por subsecciones.
--toc, -T
Nivel al que generar el índice.
0 = no generar índice en absoluto,
1 = incluye secciones principales(/capítulos/partes),
2 = incluye subsecciones.
--dosnames, -h
Usar ".htm" en lugar de ".html" como extensión de
--imagebuttons, -I
Usar los iconos de imagen de flecha "siguiente", "anterior" y "contenido" incluidos en /usr/share/linuxdoc-tools como botones de navegación.
--footer, -F
Usar el archivo especificado como pie de página en cada archivo html resultante. El pie de página por defecto es simplemente plano 
 </BODY>\n </HTML>\n
--header, -H
Usar el archivo especificado como la parte superior del encabezado en cada archivo html resultante. Nota: esta no es la parte completa del encabezado, es decir, el título y los enlaces (siguiente, anterior, contenido) del encabezado por defecto se conservan. El valor por defecto es 
 <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 3.2 Final//EN">\n
 <HTML>\n <HEAD>\n
archivo
El archivo fuente SGML, llamado archivo o archivo.sgml.

ARCHIVOS

Se utilizan muchos archivos y ejecutables en /usr/share/linuxdoc-tools y /usr/bin.

ERRORES

Ninguno conocido.
