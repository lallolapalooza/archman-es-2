NOMBRE

sg_get_user_stats, sg_get_user_stats_r, sg_free_user_stats - obtener las estadísticas de los usuarios conectados actualmente

SINOPSIS

#include <statgrab.h>


sg_user_stats *sg_get_user_stats
(size_t *entries);


sg_user_stats *sg_get_user_stats_r
(size_t *entries);


sg_error sg_free_user_stats
(sg_user_stats *data);

DESCRIPCIÓN

El módulo de estadísticas de usuario proporciona información sobre los usuarios conectados. Cada inicio de sesión se trata por separado. Ambas funciones de obtención de estadísticas, sg_get_user_stats() y sg_get_user_stats_r(), devuelven un vector de sg_user_stats con entries elementos.

Acceso directo a la API

función retorna propietario de los datos
sg_get_user_stats sg_user_stats * libstatgrab (local al hilo)
sg_get_user_stats_r sg_user_stats * llamador

El vector sg_user_stats recibido de sg_get_user_stats_r() debe liberarse usando sg_free_user_stats() cuando ya no se necesite. El llamador es responsable de hacerlo.

VALORES DE RETORNO

La estructura devuelta es de tipo sg_user_stats.

typedef struct {
        char *login_name;
        char *record_id;
        size_t record_id_size;
        char *device;
        char *hostname;
        pid_t pid;
        time_t login_time;
        time_t systime;
} sg_user_stats;
login_name
El nombre de usuario que se utilizó para iniciar sesión.
record_id
Identificador del registro de la base de datos de host que contiene información de inicio de sesión (no necesariamente terminado en null).
record_id_size
Tamaño del identificador del registro.
device
Nombre del dispositivo (por ejemplo, "pts/0") del tty asignado a la sesión de inicio de sesión.
hostname
Nombre de host (remoto) desde donde el usuario ha iniciado sesión, por ejemplo, "infoterm7.some.kind.of.domain.local", "localhost", "10.42.17.4" o ":0.0" (en caso de un inicio de sesión local a través de un nuevo xterm).
pid
Identificador del proceso que realizó la entrada en la base de datos de usuarios conectados.
login_time
Marca de tiempo (tiempo en segundos desde la época) cuando el usuario inició sesión.
systime
La marca de tiempo cuando se recopilaron las estadísticas anteriores en segundos desde la época.
