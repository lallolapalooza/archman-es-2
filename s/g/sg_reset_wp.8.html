NOMBRE

sg_reset_wp - envía el comando SCSI RESET WRITE POINTER

SINOPSIS

sg_reset_wp [--all] [--count=ZC] [--help] [--verbose] [--version] [--zone=ID] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI RESET WRITE POINTER al DISPOSITIVO. Este comando se describe en el estándar ZBC (INCITS 536-2016) y en los borradores de los documentos ZBC-2 en T10 (por ejemplo, zbc2r12.pdf).

OPCIONES

Los argumentos de las opciones largas son obligatorios también para las opciones cortas.

-a, --all
establece el campo ALL en el cdb. Esto causa una operación de reinicio del puntero de escritura de todas las zonas abiertas y zonas completas. Cuando se da esta opción, la opción --zone=ID se ignora. Se requiere esta opción o la opción --zone=ID.
-C, --count=ZC
ZC se coloca en el campo Zone Count (Conteo de Zonas) en el cdb del comando RESET WRITE POINTER soportado por esta utilidad. ZC debe ser un valor de 0 a 65535 (0xffff) inclusive.
La acción que toma el DISPOSITIVO con esta opción depende de si la opción --all está establecida. Consulte la descripción del comando RESET WRITE POINTER (por ejemplo, la sección 5.9, tabla 46 en zbc2r12.pdf).
-h, --help
muestra el mensaje de uso y luego sale.
-v, --verbose
aumenta el nivel de verbosidad (es decir, salida de depuración).
-V, --version
imprime la cadena de versión y luego sale.
-z, --zone=ID
donde ID se coloca en el campo ZONE ID del cdb. Un ID de zona es una dirección de bloque lógico (LBA) de inicio de zona. Esto causa una operación de reinicio del puntero de escritura en la zona identificada por el campo ZONE ID. El valor predeterminado es 0. Se requiere esta opción o la opción --all. Se asume que ID está en decimal a menos que esté prefijado con '0x' o tenga una 'h' al final, que indican hexadecimal.

NOTAS

El parámetro de registro Zones Emptied (Zonas Vacías) en la página de registro Statistics Log (Estadísticas) del Dispositivo de Bloque Zonificado cuenta el número de veces que se ha invocado (con éxito) el comando RESET WRITE POINTER.

ESTADO DE SALIDA

El estado de salida de sg_reset_wp es 0 cuando es exitoso. De lo contrario, consulte la página del manual sg3_utils(8).
