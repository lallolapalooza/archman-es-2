Documentación de Función/Subrutina

subroutine sgemmtr (character uplo, character transa, character transb, integer n, integer k, real alpha, real, dimension(lda,*) a, integer lda, real, dimension(ldb,*) b, integer ldb, real beta, real, dimension(ldc,*) c, integer ldc)

SGEMMTR

Propósito:

!>
!> SGEMMTR  realiza una de las operaciones de matriz-matriz
!>
!>    C := alpha*op( A )*op( B ) + beta*C,
!>
!> donde  op( X ) es una de:
!>
!>    op( X ) = X   o   op( X ) = X**T,
!>
!> alpha y beta son escalares, y A, B y C son matrices, con op( A )
!> una matriz de n por k,  op( B )  una matriz de  k por n y  C una matriz de n por n.
!> Por lo tanto, la rutina solo accede y actualiza la parte triangular superior o inferior
!> de la matriz resultado C. Este comportamiento puede ser utilizado si
!> se sabe que la matriz resultante C es simétrica.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la parte triangular inferior o superior
!>           de C es accedida y actualizada.
!>
!>              UPLO = 'L' o 'l', se usa la parte triangular inferior de C.
!>
!>              UPLO = 'U' o 'u', se usa la parte triangular superior de C.
!>

TRANSA

!>          TRANSA es CHARACTER*1
!>           Al entrar, TRANSA especifica la forma de op( A ) a utilizar en
!>           la multiplicación de matrices de la siguiente manera:
!>
!>              TRANSA = 'N' o 'n',  op( A ) = A.
!>
!>              TRANSA = 'T' o 't',  op( A ) = A**T.
!>
!>              TRANSA = 'C' o 'c',  op( A ) = A**T.
!>

TRANSB

!>          TRANSB es CHARACTER*1
!>           Al entrar, TRANSB especifica la forma de op( B ) a utilizar en
!>           la multiplicación de matrices de la siguiente manera:
!>
!>              TRANSB = 'N' o 'n',  op( B ) = B.
!>
!>              TRANSB = 'T' o 't',  op( B ) = B**T.
!>
!>              TRANSB = 'C' o 'c',  op( B ) = B**T.
!>

N

!>          N es INTEGER
!>           Al entrar,  N especifica el número de filas y columnas de
!>           la matriz C, el número de columnas de op(B) y el número
!>           de filas de op(A).  N debe ser al menos cero.
!>

K

!>          K es INTEGER
!>           Al entrar,  K  especifica  el número de columnas de la matriz
!>           op( A ) y el número de filas de la matriz op( B ). K debe
!>           ser al menos  cero.
!>

ALPHA

!>          ALPHA es REAL.
!>           Al entrar, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array REAL, de dimensión ( LDA, ka ), donde ka es
!>           k  cuando  TRANSA = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de entrar con  TRANSA = 'N' o 'n',  la parte líder  n por k
!>           del array  A  debe contener la matriz  A,  en caso contrario
!>           la parte líder  k por m  del array  A  debe contener la
!>           matriz A.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A tal como se declara
!>           en el programa (sub)llamador. Cuando  TRANSA = 'N' o 'n',
!>           LDA debe ser al menos  max( 1, n ), en caso contrario LDA debe ser
!>           al menos  max( 1, k ).
!>

B

!>          B es un array REAL, de dimensión ( LDB, kb ), donde kb es
!>           n  cuando  TRANSB = 'N' o 'n',  y es  k  en caso contrario.
!>           Antes de entrar con  TRANSB = 'N' o 'n',  la parte líder  k por n
!>           del array  B  debe contener la matriz  B,  en caso contrario
!>           la parte líder  n por k  del array  B  debe contener la
!>           matriz B.
!>

LDB

!>          LDB es INTEGER
!>           Al entrar, LDB especifica la primera dimensión de B tal como se declara
!>           en el programa (sub)llamador. Cuando  TRANSB = 'N' o 'n',
!>           LDB debe ser al menos  max( 1, k ), en caso contrario LDB debe ser
!>           al menos  max( 1, n ).
!>

BETA

!>          BETA es REAL.
!>           Al entrar,  BETA  especifica el escalar  beta.  Cuando  BETA  se
!>           suministra como cero, entonces C no necesita ser establecida al entrar.
!>

C

!>          C es un array REAL, de dimensión ( LDC, N )
!>           Antes de entrar, la parte líder  n por n  del array  C debe
!>           contener la matriz  C,  excepto cuando  beta  es cero, en cuyo
!>           caso C no necesita ser establecida al entrar.
!>           Al salir, la parte superior o inferior triangular de la matriz
!>           C  se sobrescribe con la matriz n por n
!>           ( alpha*op( A )*op( B ) + beta*C ).
!>

LDC

!>          LDC es INTEGER
!>           Al entrar, LDC especifica la primera dimensión de C tal como se declara
!>           en el programa (sub)llamador.   LDC  debe  ser  al menos
!>           max( 1, n ).
!>
