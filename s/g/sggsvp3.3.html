SGGSVP3

Propósito:

!>
!> SGGSVP3 calcula matrices ortogonales U, V y Q tales que
!>
!>                    N-K-L  K    L
!>  U**T*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**T*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> donde la matriz A12 de K por K y la matriz B13 de L por L son no singulares
!> triangulares superiores; A23 es triangular superior de L por L si M-K-L >= 0,
!> de lo contrario, A23 es trapezoidal superior de (M-K) por L. K+L = el rango
!> numérico efectivo de la matriz (M+P)-por-N (A**T,B**T)**T.
!>
!> Esta descomposición es el paso de preprocesamiento para calcular la
!> Descomposición de Valores Singulares Generalizados (GSVD), véase la subrutina
!> SGGSVD3.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U':  se calcula la matriz ortogonal U;
!>          = 'N':  U no se calcula.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'V':  se calcula la matriz ortogonal V;
!>          = 'N':  V no se calcula.
!>

JOBQ

!>          JOBQ es CHARACTER*1
!>          = 'Q':  se calcula la matriz ortogonal Q;
!>          = 'N':  Q no se calcula.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.
!>

A

!>          A es arreglo REAL, dimension (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, A contiene la matriz triangular (o trapezoidal)
!>          descrita en la sección Propósito.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1,M).
!>

B

!>          B es arreglo REAL, dimension (LDB,N)
!>          En la entrada, la matriz B de P por N.
!>          En la salida, B contiene la matriz triangular descrita en
!>          la sección Propósito.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B. LDB >= max(1,P).
!>

TOLA

!>          TOLA es REAL
!>

TOLB

!>          TOLB es REAL
!>
!>          TOLA y TOLB son los umbrales para determinar el rango numérico
!>          efectivo de la matriz B y un subbloque de A. Generalmente,
!>          se establecen como
!>             TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          El tamaño de TOLA y TOLB puede afectar los errores de retroceso
!>          de la descomposición.
!>

K

!>          K es INTEGER
!>

L

!>          L es INTEGER
!>
!>          En la salida, K y L especifican la dimensión de los subbloques
!>          descritos en la sección Propósito.
!>          K + L = rango numérico efectivo de (A**T,B**T)**T.
!>

U

!>          U es arreglo REAL, dimension (LDU,M)
!>          Si JOBU = 'U', U contiene la matriz ortogonal U.
!>          Si JOBU = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del arreglo U. LDU >= max(1,M) si
!>          JOBU = 'U'; LDU >= 1 en caso contrario.
!>

V

!>          V es arreglo REAL, dimension (LDV,P)
!>          Si JOBV = 'V', V contiene la matriz ortogonal V.
!>          Si JOBV = 'N', V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del arreglo V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 en caso contrario.
!>

Q

!>          Q es arreglo REAL, dimension (LDQ,N)
!>          Si JOBQ = 'Q', Q contiene la matriz ortogonal Q.
!>          Si JOBQ = 'N', Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del arreglo Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q'; LDQ >= 1 en caso contrario.
!>

IWORK

!>          IWORK es arreglo INTEGER, dimension (N)
!>

TAU

!>          TAU es arreglo REAL, dimension (N)
!>

WORK

!>          WORK es arreglo REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK >= 1.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del arreglo
!>          WORK, devuelve este valor como la primera entrada del arreglo
!>          WORK y XERBLA no emite ningún mensaje de error relacionado con
!>          LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
