DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine sgehrd (integer n, integer ilo, integer ihi, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SGEHRD

Propósito:

!>
!> SGEHRD reduce una matriz general real A a la forma de Hessenberg superior H por
!> una transformación de similitud ortogonal:  Q**T * A * Q = H .
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>
!>          Se asume que A ya es triangular superior en las filas
!>          y columnas 1:ILO-1 y IHI+1:N. ILO e IHI son normalmente
!>          establecidos por una llamada previa a SGEBAL; de lo contrario,
!>          deberían establecerse a 1 y N respectivamente. Ver Detalles Adicionales.
!>          1 <= ILO <= IHI <= N, si N > 0; ILO=1 e IHI=0, si N=0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, la matriz general N por N a reducir.
!>          En la salida, la parte triangular superior y la primera subdiagonal de A
!>          se sobrescriben con la matriz de Hessenberg superior H, y los
!>          elementos debajo de la primera subdiagonal, con el array TAU,
!>          representan la matriz ortogonal Q como un producto de
!>          reflejos elementales. Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

TAU

!>          TAU es array REAL, dimension (N-1)
!>          Los factores escalares de los reflejos elementales (ver Detalles
!>          Adicionales). Los elementos 1:ILO-1 e IHI:N-1 de TAU se establecen a
!>          cero.
!>

WORK

!>          WORK es array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.  LWORK >= max(1,N).
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Autor

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de (ihi-ilo)
!>  reflejos elementales
!>
!>     Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real, y v es un vector real con
!>  v(1:i) = 0, v(i+1) = 1 y v(ihi+1:n) = 0; v(i+2:ihi) se almacena en la
!>  salida en A(i+2:ihi,i), y tau en TAU(i).
!>
!>  El contenido de A se ilustra con el siguiente ejemplo, con
!>  n = 7, ilo = 2 e ihi = 6:
!>
!>  en la entrada,                        en la salida,
!>
!>  ( a   a   a   a   a   a   a )    (  a   a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      h   h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  v4  h   h   h )
!>  (                         a )    (                          a )
!>
!>  donde 'a' denota un elemento de la matriz original A, 'h' denota un
!>  elemento modificado de la matriz de Hessenberg superior H, y 'vi' denota un
!>  elemento del vector que define H(i).
!>
!>  Este archivo es una ligera modificación de la subrutina SGEHRD de LAPACK-3.0
!>  que incorpora mejoras propuestas por Quintana-Orti y
!>  Van de Geijn (2006). (Ver SLAHR2.)
!>
