Documentación de la Función/Subrutina

subroutine sgesvdq (character joba, character jobp, character jobr, character jobu, character jobv, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldv, * ) v, integer ldv, integer numrank, integer, dimension( * ) iwork, integer liwork, real, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer lrwork, integer info)

SGESVDQ calcula la descomposición en valores singulares (SVD) de una matriz GE real de M por N, donde M >= N. La SVD de A se escribe como [++] [xx] [x0] [xx] A = U * SIGMA * V^*, [++] = [xx] * [ox] * [xx] [++] [xx] donde SIGMA es una matriz diagonal de N por N, U es una matriz ortonormal de M por N, y V es una matriz ortogonal de N por N. Los elementos diagonales de SIGMA son los valores singulares de A. Las columnas de U y V son las columnas izquierda y derecha de los vectores singulares de A, respectivamente.

Propósito:

!> SGESVDQ calcula la descomposición en valores singulares (SVD) de una real
!> M-por-N matriz A, donde M >= N. La SVD de A se escribe como
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> donde SIGMA es una matriz diagonal N-por-N, U es una matriz ortonormal M-por-N
!> y V es una matriz ortogonal N-por-N. Los elementos diagonales
!> de SIGMA son los valores singulares de A. Las columnas de U y V son las
!> izquierda y derecha de los vectores singulares de A, respectivamente.
!>

!>  JOBA es CHARACTER*1
!>  Especifica el nivel de precisión en la SVD calculada
!>  = 'A' La precisión solicitada corresponde a tener el error de retroceso
!>        acotado por || delta A ||_F <= f(m,n) * EPS * || A ||_F,
!>        donde EPS = SLAMCH('Epsilon'). Esto autoriza a CGESVDQ a
!>        truncar el factor triangular calculado en una factorización
!>        QR reveladora de rango siempre que la parte truncada esté por debajo del
!>        umbral del orden de EPS * ||A||_F. Este es un nivel de truncamiento agresivo.
!>  = 'M' De manera similar a 'A', pero el truncamiento es más suave:
!>        solo se permite cuando hay una caída en la diagonal del
!>        factor triangular en la factorización QR. Este es un nivel de truncamiento medio.
!>  = 'H' Se solicita alta precisión. No se intenta determinar el rango numérico basado
!>        en la factorización QR reveladora de rango.
!>  = 'E' Igual que 'H', y además se estima el número de condición de A escalada por columnas
!>        y se devuelve en  RWORK(1).
!>        N^(-1/4)*RWORK(1) <= ||pinv(A_scaled)||_2 <= N^(1/4)*RWORK(1)

!>        movimiento de datos adicional. Recomendado para robustez numérica.

NAME

sgesvdq - Computes the singular value decomposition (SVD) of a real general matrix A.

SYNOPSIS

    SUBROUTINE SGESVDQ( JOBU, JOBV, JOBR, JOBA, M, N, A, LDA, S, U, LDU, V, LDV,
                        IWORK, LIWORK, WORK, LWORK, RWORK, LRWORK, INFO )
    INTEGER M, N, LDA, LDU, LDV, LIWORK, LWORK, LRWORK, INFO
    REAL    A( LDA, * ), S( * ), U( LDU, * ), V( LDV, * ), WORK( * ),
            RWORK( * )
    CHARACTER*1 JOBU, JOBV, JOBR, JOBA

Function/Subroutine Documentation

This subroutine computes the singular value decomposition (SVD) of a real general M-by-N matrix A. The SVD is A = U*S*V^T, where S is an M-by-N diagonal matrix with non-negative diagonal entries (the singular values), and U and V are orthogonal matrices with M-by-M and N-by-N dimensions, respectively. The columns of U are the left singular vectors, and the columns of V are the right singular vectors.

Algorithm Description:

    The routine SGESVDQ is a hybrid QR-based SVD algorithm. It is based on
    a rank-revealing QR factorization of the input matrix A. The algorithm
    consists of the following steps:
    1. Rank-revealing QR factorization:
       A = Q * R, where Q is orthogonal and R is upper trapezoidal.
       The rank of A is determined from the diagonal entries of R.
    2. Bidiagonalization:
       The upper trapezoidal matrix R is reduced to bidiagonal form B by
       applying orthogonal transformations:
       R = X * B * Y^T, where B is upper bidiagonal.
    3. SVD of bidiagonal matrix:
       The SVD of B is computed:
       B = U_B * S * V_B^T.
    4. Reconstruction of singular vectors:
       The singular vectors of A are reconstructed from the singular vectors
       of B and the orthogonal transformations from the previous steps.
       U = Q * X * U_B
       V = Y * V_B
    This algorithm is designed to provide high accuracy, especially for
    rank-deficient or ill-conditioned matrices.

Parameters:

!>  JOBU    (CHARACTER*1)
!>          Specifies whether to compute the left singular vectors (U).
!>          = 'A': The full M x M orthogonal matrix U is returned.
!>          = 'S': The M x K orthogonal matrix U is returned, where K = min(M,N).
!>          = 'U': The M x K rectangular matrix U is returned, where K = min(M,N).
!>          = 'R': The M x K matrix U is returned, where K is the effective
!>                 rank of A.
!>          = 'N': No singular vectors are computed.
!>
!>  JOBV    (CHARACTER*1)
!>          Specifies whether to compute the right singular vectors (V).
!>          = 'A': The full N x N orthogonal matrix V is returned.
!>          = 'S': The N x K orthogonal matrix V is returned, where K = min(M,N).
!>          = 'U': The N x K rectangular matrix V is returned, where K = min(M,N).
!>          = 'R': The N x K matrix V is returned, where K is the effective
!>                 rank of A.
!>          = 'N': No singular vectors are computed.
!>
!>  JOBR    (CHARACTER*1)
!>          Specifies whether to compute the R factor from the initial QR
!>          decomposition.
!>          = 'N': R is not returned.
!>          = 'T': The upper trapezoidal factor R is returned in A on exit.
!>
!>  JOBA    (CHARACTER*1)
!>          Specifies whether to compute the scaled condition number estimate.
!>          = 'E': Compute the scaled condition number estimate.
!>          = 'N': Do not compute the scaled condition number estimate.
!>
!>  M       (INTEGER)
!>          The number of rows of the matrix A. M >= 0.
!>
!>  N       (INTEGER)
!>          The number of columns of the matrix A. N >= 0.
!>
!>  A       (REAL array, dimension (LDA, N))
!>          On entry, the M x N matrix whose SVD is to be computed.
!>          On exit, A is overwritten by values generated during the computation.
!>          If JOBR = 'T', A contains the upper trapezoidal factor R.
!>
!>  LDA     (INTEGER)
!>          The leading dimension of the array A. LDA >= max(1, M).
!>
!>  S       (REAL array, dimension (min(M,N)))
!>          On exit, the singular values of A, sorted in descending order.
!>          The k-th singular value is computed as S(k).
!>
!>  U       (REAL array, dimension (LDU, K))
!>          On exit,
!>          If JOBU = 'A', U contains the M x M orthogonal matrix of left singular
!>                   vectors.
!>          If JOBU = 'S', U contains the M x K orthogonal matrix of left singular
!>                   vectors, where K = min(M,N).
!>          If JOBU = 'U', U contains the M x K matrix of left singular vectors.
!>          If JOBU = 'R', U contains the M x K matrix of left singular vectors,
!>                   where K is the effective rank of A.
!>          If JOBU = 'N', U is not used.
!>
!>  LDU     (INTEGER)
!>          The leading dimension of the array U.
!>          LDU >= max(1, M) if JOBU = 'A'.
!>          LDU >= max(1, M) if JOBU = 'S' or 'U'.
!>          LDU >= max(1, M) if JOBU = 'R' and M > 0.
!>
!>  V       (REAL array, dimension (LDV, K))
!>          On exit,
!>          If JOBV = 'A', V contains the N x N orthogonal matrix of right singular
!>                   vectors.
!>          If JOBV = 'S', V contains the N x K orthogonal matrix of right singular
!>                   vectors, where K = min(M,N).
!>          If JOBV = 'U', V contains the N x K matrix of right singular vectors.
!>          If JOBV = 'R', V contains the N x K matrix of right singular vectors,
!>                   where K is the effective rank of A.
!>          If JOBV = 'N', V is not used.
!>
!>  LDV     (INTEGER)
!>          The leading dimension of the array V.
!>          LDV >= max(1, N) if JOBV = 'A'.
!>          LDV >= max(1, N) if JOBV = 'S' or 'U'.
!>          LDV >= max(1, N) if JOBV = 'R' and N > 0.
!>
!>  IWORK   (INTEGER array, dimension (LIWORK))
!>          Workspace array.
!>          On exit, IWORK(1:N) contains column pivoting permutation of the
!>          rank revealing QR factorization.
!>          If JOBP = 'P', IWORK(N+1:N+M-1) contains the indices of the sequence
!>          of row swaps used in row pivoting. These can be used to restore the
!>          left singular vectors in the case JOBU = 'F'.
!>
!>          If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
!>          IWORK(1) returns the minimal LIWORK.
!>
!>  LIWORK  (INTEGER)
!>          The dimension of the array IWORK.
!>          LIWORK >= N + M - 1,     if JOBP = 'P' and JOBA .NE. 'E';
!>          LIWORK >= N              if JOBP = 'N' and JOBA .NE. 'E';
!>          LIWORK >= N + M - 1 + N, if JOBP = 'P' and JOBA = 'E';
!>          LIWORK >= N + N          if JOBP = 'N' and JOBA = 'E'.
!>
!>          If LIWORK = -1, then a workspace query is assumed; the routine
!>          only calculates and returns the optimal and minimal sizes
!>          for the WORK, IWORK, and RWORK arrays, and no error
!>          message related to LWORK is issued by XERBLA.
!>
!>  WORK    (REAL array, dimension (max(2, LWORK)))
!>          Workspace array.
!>          On exit, if, on entry, LWORK.NE.-1, WORK(1:N) contains parameters
!>          needed to recover the Q factor from the QR factorization computed by
!>          SGEQP3.
!>
!>          If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
!>          WORK(1) returns the optimal LWORK, and
!>          WORK(2) returns the minimal LWORK.
!>
!>  LWORK   (INTEGER)
!>          The dimension of the array WORK. It is determined as follows:
!>          Let  LWQP3 = 3*N+1,  LWCON = 3*N, and let
!>          LWORQ = { MAX( N, 1 ),  if JOBU = 'R', 'S', or 'U'
!>                  { MAX( M, 1 ),  if JOBU = 'A'
!>          LWSVD = MAX( 5*N, 1 )
!>          LWLQF = MAX( N/2, 1 ), LWSVD2 = MAX( 5*(N/2), 1 ), LWORLQ = MAX( N, 1 ),
!>          LWQRF = MAX( N/2, 1 ), LWORQ2 = MAX( N, 1 )
!>          Then the minimal value of LWORK is:
!>          = MAX( N + LWQP3, LWSVD )        if only the singular values are needed;
!>          = MAX( N + LWQP3, LWCON, LWSVD ) if only the singular values are needed,
!>                                   and a scaled condition estimate requested;
!>
!>          = N + MAX( LWQP3, LWSVD, LWORQ ) if the singular values and the left
!>                                   singular vectors are requested;
!>          = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) if the singular values and the left
!>                                   singular vectors are requested, and also
!>                                   a scaled condition estimate requested;
!>
!>          = N + MAX( LWQP3, LWSVD )        if the singular values and the right
!>                                   singular vectors are requested;
!>          = N + MAX( LWQP3, LWCON, LWSVD ) if the singular values and the right
!>                                   singular vectors are requested, and also
!>                                   a scaled condition etimate requested;
!>
!>          = N + MAX( LWQP3, LWSVD, LWORQ ) if the full SVD is requested with JOBV = 'R';
!>                                   independent of JOBR;
!>          = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) if the full SVD is requested,
!>                                   JOBV = 'R' and, also a scaled condition
!>                                   estimate requested; independent of JOBR;
!>          = MAX( N + MAX( LWQP3, LWSVD, LWORQ ),
!>         N + MAX( LWQP3, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ) ) if the
!>                         full SVD is requested with JOBV = 'A' or 'V', and
!>                         JOBR ='N'
!>          = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ),
!>         N + MAX( LWQP3, LWCON, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ ) )
!>                         if the full SVD is requested with JOBV = 'A' or 'V', and
!>                         JOBR ='N', and also a scaled condition number estimate
!>                         requested.
!>          = MAX( N + MAX( LWQP3, LWSVD, LWORQ ),
!>         N + MAX( LWQP3, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) ) if the
!>                         full SVD is requested with JOBV = 'A', 'V', and JOBR ='T'
!>          = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ),
!>         N + MAX( LWQP3, LWCON, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) )
!>                         if the full SVD is requested with JOBV = 'A' or 'V', and
!>                         JOBR ='T', and also a scaled condition number estimate
!>                         requested.
!>          Finally, LWORK must be at least two: LWORK = MAX( 2, LWORK ).
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates and returns the optimal and minimal sizes
!>          for the WORK, IWORK, and RWORK arrays, and no error
!>          message related to LWORK is issued by XERBLA.
!>
!>  RWORK   (REAL array, dimension (max(1, LRWORK)))
!>          Workspace array.
!>          On exit,
!>          1. If JOBA = 'E', RWORK(1) contains an estimate of the condition
!>          number of column scaled A. If A = C * D where D is diagonal and C
!>          has unit columns in the Euclidean norm, then, assuming full column rank,
!>          N^(-1/4) * RWORK(1) <= ||pinv(C)||_2 <= N^(1/4) * RWORK(1).
!>          Otherwise, RWORK(1) = -1.
!>          2. RWORK(2) contains the number of singular values computed as
!>          exact zeros in SGESVD applied to the upper triangular or trapezoidal
!>          R (from the initial QR factorization). In case of early exit (no call to
!>          SGESVD, such as in the case of zero matrix) RWORK(2) = -1.
!>
!>          If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
!>          RWORK(1) returns the minimal LRWORK.
!>
!>  LRWORK  (INTEGER)
!>          The dimension of the array RWORK.
!>          If JOBP ='P', then LRWORK >= MAX(2, M).
!>          Otherwise, LRWORK >= 2
!>
!>          If LRWORK = -1, then a workspace query is assumed; the routine
!>          only calculates and returns the optimal and minimal sizes
!>          for the WORK, IWORK, and RWORK arrays, and no error
!>          message related to LWORK is issued by XERBLA.

Further Details:

    1. The data movement (matrix transpose) is coded using simple nested
    DO-loops because BLAS and LAPACK do not provide corresponding subroutines.
    Those DO-loops are easily identified in this source code - by the CONTINUE
    statements labeled with 11**. In an optimized version of this code, the
    nested DO loops should be replaced with calls to an optimized subroutine.
    2. This code scales A by 1/SQRT(M) if the largest ABS(A(i,j)) could cause
    column norm overflow. This is the minial precaution and it is left to the
    SVD routine (CGESVD) to do its own preemptive scaling if potential over-
    or underflows are detected. To avoid repeated scanning of the array A,
    an optimal implementation would do all necessary scaling before calling
    CGESVD and the scaling in CGESVD can be switched off.
    3. Other comments related to code optimization are given in comments in the
    code, enclosed in [[double brackets]].
