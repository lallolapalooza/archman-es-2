NOMBRE

sg_z_act_query - enviar un comando SCSI ZONE ACTIVATE o ZONE QUERY

SINOPSIS

sg_z_act_query [--activate] [--all] [--force] [--help] [--hex] [--inhex=FN] [--maxlen=LEN] [--num=ZS] [--other=ZDID] [--query] [--raw] [--verbose] [--version] [--zone=ID] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI ZONE ACTIVATE o ZONE QUERY al DISPOSITIVO. Si no se da la opción --activate, se envía un comando ZONE QUERY. Estos comandos se añadieron en la revisión 4 del borrador ZBC-2 (zbc2r04.pdf).

Ambos comandos tienen cdb_s y respuestas similares, por lo que ambos se incluyen en esta utilidad. La diferencia es que solo el comando ZONE ACTIVATE activará o desactivará zonas. Ambos comandos realizarán una "Verificación de operaciones de activación" tal como se define en ZBC-2.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-A, --activate
envía un comando ZONE ACTIVATE al DISPOSITIVO. Por defecto (es decir, sin esta opción) se envía un comando ZONE QUERY.
-a, --all
establece el campo ALL en el cdb.
-f, --force
al decodificar la respuesta a este comando, se realizan ciertas comprobaciones de sanidad y, si fallan, se envía un mensaje a stderr y se establece un estado de salida distinto de cero. Si se proporciona esta opción, se omiten dichas comprobaciones de sanidad.
-h, --help
muestra el mensaje de uso y sale.
-H, --hex
muestra la respuesta en hexadecimal en stdout. Cuando se usa una vez, toda la respuesta se muestra en hexadecimal ASCII con una dirección inicial (a partir de 0) en cada línea. Cuando se usa dos veces, cada descriptor de activación de zona en la respuesta se muestra por separado en hexadecimal. Cuando se usa tres veces, toda la respuesta se muestra en hexadecimal sin dirección inicial (en cada línea).
El formato de salida cuando se usa esta opción tres veces es adecuado para una posterior invocación con la opción --inhex=FN.
-i, --inhex=FN
donde FN es el nombre de un archivo cuyo contenido se asume que es hexadecimal ASCII. Si también se proporciona DISPOSITIVO, se ignora DISPOSITIVO, se emite una advertencia y la utilidad continúa decodificando el archivo llamado FN. Consulte la sección "FORMATOS HEXADECIMAL, BINARIO Y JSON" en la página del manual de sg3_utils para más información. Si también se usa la opción --raw, el contenido de FN se trata como binario.
Por defecto, se asume que la respuesta es de un comando ZONE QUERY, pero eso no debería importar ya que la respuesta de los comandos ZONE ACTIVATE y ZONE QUERY tiene la misma forma.
-m, --maxlen=LEN
donde LEN es la longitud de respuesta (máxima) en bytes. Se coloca en el campo "longitud de asignación" del cdb. Si no se proporciona (o LEN es cero), se usan 8192. El valor máximo permitido de LEN es 1048576.
El borrador del estándar prohíbe longitudes de asignación menores a 64.
-n, --num=ZS
donde ZS se coloca en el campo "Número de zonas" del cdb. Esta opción generalmente se ignora si se proporciona la opción --all. Si no se proporciona la opción --all, el valor por defecto de este campo es 1.
-o, --other=ZDID
donde el valor ZDID se colocará en el campo "Otro ID de dominio de zona" del cdb que se enviará al DISPOSITIVO.
-q, --query
provoca que se envíe el comando ZONE QUERY al DISPOSITIVO. Dado que esta es la acción por defecto, esta opción generalmente no es necesaria. Si se proporcionan tanto esta opción como la opción --activate, se informará un error (y no se enviará ningún comando).
-r, --raw
muestra la respuesta en binario (a stdout) a menos que también se proporcione la opción --inhex=FN. En ese caso, el nombre del archivo de entrada (FN) se decodifica como binario (y la salida NO está en binario (pero puede ser hexadecimal)).
-v, --verbose
aumenta el nivel de verbosidad (es decir, la salida de depuración).
-V, --version
imprime la cadena de versión y sale.
-z, --zone=ID
donde ID se coloca en el campo ZONE ID del cdb. Un ID de zona es una dirección de bloque lógico (LBA) de inicio de zona. El valor por defecto es 0. Se asume que ID está en decimal a menos que esté precedido por '0x' o tenga una 'h' al final, que indican hexadecimal. El valor máximo que se puede dar es 2^64 - 2. En el improbable caso de querer dar 2^64 - 1, introduzca "-1".

ESTADO DE SALIDA

El estado de salida de sg_z_act_query es 0 cuando tiene éxito. De lo contrario, consulte la página del manual de sg3_utils(8).
