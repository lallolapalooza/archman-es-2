Documentación de Función/Subrutina

subroutine sgbsvx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, real, dimension( * ) r, real, dimension( * ) c, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SGBSVX calcula la solución del sistema de ecuaciones lineales A * X = B para matrices GB

Propósito:

!>
!> SGBSVX utiliza la factorización LU para calcular la solución de un sistema
!> de ecuaciones lineales reales A * X = B, A**T * X = B, o A**H * X = B,
!> donde A es una matriz de banda de orden N con KL subdiagonales y KU
!> superdiagonales, y X y B son matrices N por NRHS.
!>
!> También se proporcionan cotas de error para la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Los siguientes pasos son realizados por esta subrutina:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Si el sistema se va a equilibrar o no depende del escalado de la
!>    matriz A, pero si se utiliza el escalado, A se sobrescribe con
!>    diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del escalado si FACT = 'E') como
!>       A = L * U,
!>    donde L es un producto de matrices de permutación y triangulares inferiores
!>    unitaria con KL subdiagonales, y U es triangular superior con
!>    KL+KU superdiagonales.
!>
!> 3. Si algún U(i,i)=0, haciendo que U sea exactamente singular, la rutina
!>    devuelve INFO = i. De lo contrario, la forma factorizada de A se utiliza
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina continúa
!>    resolviendo para X y calculando cotas de error como se describe a
!>    continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    matriz y calcular cotas de error y estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se utilizó el escalado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para que
!>    resuelva el sistema original antes del escalado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se proporciona
!>          en la entrada, y si no, si la matriz A debe ser equilibrada
!>          antes de ser factorizada.
!>          = 'F':  En la entrada, AFB y IPIV contienen la forma factorizada
!>                  de A. Si EQUED no es 'N', la matriz A ha sido
!>                  equilibrada con factores de escala dados por R y C.
!>                  AB, AFB e IPIV no se modifican.
!>          = 'N':  La matriz A se copiará en AFB y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AFB y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B     (Sin transposición)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta)
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es array REAL, dimensión (LDAB,N)
!>          En la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>          La j-ésima columna de A se almacena en la j-ésima columna del
!>          array AB de la siguiente manera:
!>          AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+kl)
!>
!>          Si FACT = 'F' y EQUED no es 'N', entonces A debe haber sido
!>          equilibrada por los factores de escala en R y/o C. AB no se
!>          modifica si FACT = 'F' o 'N', o si FACT = 'E' y
!>          EQUED = 'N' en la salida.
!>
!>          En la salida, si EQUED .ne. 'N', A se escala de la siguiente manera:
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array REAL, dimensión (LDAFB,N)
!>          Si FACT = 'F', entonces AFB es un argumento de entrada y en la entrada
!>          contiene detalles de la factorización LU de la matriz de banda
!>          A, tal como la calcula SGBTRF. U se almacena como una matriz de banda
!>          triangular superior con KL+KU superdiagonales en las filas 1 a KL+KU+1,
!>          y los multiplicadores utilizados durante la factorización se almacenan
!>          en las filas KL+KU+2 a 2*KL+KU+1. Si EQUED .ne. 'N', entonces AFB
!>          es la forma factorizada de la matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AFB es un argumento de salida y en la salida
!>          devuelve detalles de la factorización LU de A.
!>
!>          Si FACT = 'E', entonces AFB es un argumento de salida y en la salida
!>          devuelve detalles de la factorización LU de la matriz equilibrada
!>          A (ver la descripción de AB para la forma de la matriz
!>          equilibrada).
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal del array AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene los índices de pivote de la factorización A = L*U
!>          tal como la calcula SGBTRF; la fila i de la matriz se intercambió
!>          con la fila IPIV(i).
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = L*U
!>          de la matriz A equilibrada.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Specifies whether or not the scaling of the matrix A has been
!>          done.
!>          = 'N': No scaling was done.
!>          = 'R': Row scaling was done, i.e., A was replaced by diag(R)*A.
!>          = 'C': Column scaling was done, i.e., A was replaced by A*diag(C).
!>          = 'B': Both row and column scaling were done, i.e., A was replaced
!>                 by diag(R)*A*diag(C).
!>
!>          On entry if FACT = 'F', EQUED specifies any row and column scaling
!>          applied to the matrix A in the factored form AFB.
!>          On exit if FACT = 'E', EQUED is set to 'R', 'C' or 'B' depending
!>          on the result of scaling A.
!>

R

!>          R is REAL array, dimension (N)
!>          The array R. If EQUED = 'R' or 'B', the array R contains the
!>          row and/or column scaling factors for the matrix A. The letter
!>          used for the i-th element of R depends on whether the i-th
!>          equation was scaled:
!>          EQUED = 'R':  R(i) = largest element in row i.
!>          EQUED = 'C':  C(j) = largest element in row j.
!>          EQUED = 'B':  R(i) = largest element in row i.
!>

C

!>          C is REAL array, dimension (N)
!>          The array C. If EQUED = 'C' or 'B', the array C contains the
!>          row and/or column scaling factors for the matrix A. The letter
!>          used for the i-th element of C depends on whether the i-th
!>          equation was scaled:
!>          EQUED = 'C':  C(j) = largest element in row j.
!>          EQUED = 'B':  C(j) = largest element in column j.
!>

B

!>          B is REAL array, dimension (LDB,NRHS)
!>          On entry, the N-by-NRHS matrix of right hand sides (B) and the
!>          load-balancing lower and upper bandwidths of the matrix A.
!>
!>          If FACT = 'F' and EQUED is not 'N', then the elements of B must
!>          be scaled corresponding to the equilibration of A.
!>
!>          On exit, if FACT = 'N' or 'E', B has been modified for the
!>          equations to be solved:
!>             if EQUED = 'R' or 'B', B is replaced by diag(R)*B
!>             if EQUED = 'C' or 'B', B is replaced by diag(C)*B
!>          The solution X will be computed for the system with these
!>          modified right-hand sides.
!>
!>          On exit, if FACT = 'F', B is not modified.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

X

!>          X is REAL array, dimension (LDX,NRHS)
!>          On exit, X is the N-by-NRHS solution matrix of the system
!>          A*X = B.
!>
!>          If FACT = 'F' and EQUED is not 'N', the solution X will be
!>          scaled corresponding to the equilibration of A.
!>
!>          On exit, if FACT = 'F' and EQUED .ne. 'N', the solution X is
!>          scaled to the original equation.
!>

LDX

!>          LDX is INTEGER
!>          The leading dimension of the array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND is REAL
!>          On exit, RCOND is an estimate of the reciprocal of the condition
!>          number of the matrix A (1/cond(A)). The matrix A is close to
!>          singular if RCOND <= EPS, where EPS is the machine epsilon
!>          times the smallest representable positive number.
!>

FERR

!>          FERR is REAL array, dimension (NRHS)
!>          On exit, FERR(j) is an estimate of the forward error bound for
!>          the j-th solution vector, that is, the relative error in the
!>          j-th solution computed by SGBSVX.  err(j) = norm(X - Xsub(j)) /
!>          norm(X), where Xsub(j) is the j-th solution computed by the
!>          routine.
!>

BERR

!>          BERR is REAL array, dimension (NRHS)
!>          On exit, BERR(j) is the componentwise relative backward error
!!>          of the j-th solution computed by SGBSVX. berr(j) = max(abs(A*X - B)) /
!>          (norm(A) * norm(X) * eps) of the system A*X = B.
!>

WORK

!>          WORK is REAL array, dimension (LWORK)
!>          On exit, if INFO = 0, WORK(1) contains the minimum value of
!>          LWORK required for that run.

!>
!>          Workspace for temporary storage.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK must be at least
!>          max(1, 2*N).
!>          If LWORK = -1, then only a dimension check is performed and
!>          an array of the correct size is returned.
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>          Local array for pivot indices.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  Successful exit. The factorization has been completed,
!>                and the optimal completion of the remainder of the task
!>                has been performed.
!>          < 0:  If INFO = -i, the i-th argument had an internal error.
!>                0 <= INFO <= N:  If INFO = i, and i < N, then U(i,i) is
!>                zero.  The factorization has been completed, but I is
!>                singular.
!>          = N+1: The array B has been potentially modified for
!>                 equilibration. The solution has been computed, but
!>                 RCOND is less than machine epsilon. A few examples of
!>                 this include RCOND <= zero or the matrix is extremely
!>                 close to singular.
!>

NAME

SGBSVX - sgbsvx

SYNOPSIS

SUBROUTINE SGBSVX( FACT, TRANS, N, ML, MU, NRHS, AB, LDAB, AFB, LDAFB,
                 IPIV, EQUED, R, C, B, LDB, X, LDX, RCOND, FERR, BERR,
                 WORK, IWORK, INFO )

Function/Subroutine Documentation

SGBSVX is a LAPACK routine that computes the solution to a general band system of linear band matrix equations

A * X = B

or the 

A**T * X = B

or

A**H * X = B

where A is an N-by-N band matrix with ML subdiagonals and MU superdiagonals, X and B are N-by-NRHS, and A**T is the transpose of A, and A**H is the conjugate transpose of A.

The routine `sgbsvx` first:

  • if GETRF is called to factorize the matrix A.
  • then, if some later columns of A are inaccurate, the correction will be done with the help of forward elimination and backward substitution.

Before actually computing the solution, the routine can also optionally compute a detailed error analysis.

I. Background

The general band matrix is one where the non-zero entries of the matrix A are contained within a diagonal band, the width of which is defined by the subdiagonals ML and the superdiagonals MU.

II. Equilibrarion

Before solving for X, the routine can optionally equilibrate the matrix A. To equilibrate a matrix means to multiply it on the left by a diagonal matrix R and/or on the right by a diagonal matrix C so that the corresponding maximum absolute row or column entries are all equal. This equilibration is done by means of the scaling of the matrix A by the diagonal matrices R and C. That is, A is replaced by diag(R) * A * diag(C). This diagonal scaling will help in producing a better conditioned system towards the solution of the original system.

III. Condition Number

The routine estimates the condition number of the matrix A in the 1-norm. The condition number is the number of times more accurate the solution X is than the given right hand side B. If the condition number is Bignum, the system is said to be ill-conditioned. The routine returns an estimate of the reciprocal condition number, RCOND, which is the value of 1/cond(A).

IV. Forward Error Analysis

The routine provides forward error estimates for the solution X. If XTRUE is the true solution corresponding to X, then FERR(j) is an estimated upper bound for the magnitude of the largest element in (X(j) - XTRUE) divided by the magnitude of the largest element in X(j). The estimate is as reliable as the estimate for RCOND. It is almost always a slight overestimate of the true error.

V. Backward Error Analysis

The routine also provides component-wise backward error estimates for the solution X. BERR(j) is the smallest relative perturbation in the coefficients of A and B that makes X(j) an exact solution to the perturbed system.

FACT

         FACT is CHARACTER*1
         Specifies the preconditioner type.
         = 'E':  Solution obtained by solving the symmetrically
                 equilibrated system using the factorization computed
                 and saved by SGBSV.
         = 'N':  Compute the factorization of the matrix A.
         = 'F':  Compute the factorization of the matrix A.

TRANS

         TRANS is CHARACTER*1
         Specifies the form of the system of equations:
         = 'N':  A * X = B        (No transpose)
         = 'T':  A**T * X = B     (Transpose)
         = 'C':  A**H * X = B     (Conjugate transpose)

N

         N is INTEGER
         The number of linear equations, the number of columns, and the
         number of rows of the matrix A. N >= 0.

ML

         ML is INTEGER
         The number of subdiagonals of the matrix A.  0 <= ML < N.

MU

         MU is INTEGER
         The number of superdiagonals of the matrix A.  0 <= MU < N.

NRHS

         NRHS is INTEGER
         The number of right hand sides, i.e. the number of columns of the
         matrices B and X.  NRHS >= 0.

AB

         AB is REAL array, dimension (LDAB,N)
         On entry, the unit cubed band matrix A, in band storage
         format. The columns of the band matrix are stored in the columns
         of the array AB, and the local indices of the diagonals are
         in the rows of AB. The number of rows of AB is LDAB.
         See below for more details on band storage format.
         On exit, if FACT = 'N' or 'F', AB is overwritten by details of
         its LU factorization.

LDAB

         LDAB is INTEGER
         The number of rows of the array AB. LDAB >= ML + MU + 1.

AFB

         AFB is REAL array, dimension (LDAFB,N)
         On entry, the unit cubed band matrix A, in band storage
         format. The columns of the band matrix are stored in the columns
         of the array AFB, and the local indices of the diagonals are
         in the rows of AFB. The number of rows of AFB is LDAFB.
         On exit, if FACT = 'E', AFB is not accessed. If FACT = 'N' or 'F',
         AFB is overwritten by details of its LU factorization.
         The accuracy of the solution depends on the accuracy of the
         factorization in AFB.

LDAFB

         LDAFB is INTEGER
         The number of rows of the array AFB. LDAFB >= ML + MU + 1.

IPIV

         IPIV is INTEGER array, dimension (N)
         On exit, if FACT = 'N' or 'F', IPIV contains the pivot indices
         of the factorization. IPIV[i] = k means that row i of the
         factor was interchanged with row k of the factor.
         If FACT = 'E', IPIV is not accessed.

EQUED

         EQUED is CHARACTER*1
         Specifies the form of equilibration that was done.
         = 'N':  No equilibration (always true if FACT = 'N').
         = 'R':  Row equilibration, i.e., A has been premultiplied by
                 diag(R).
         = 'C':  Column equilibration, i.e., A has been postmultiplied
                 by diag(C).
         = 'B':  Both row and column equilibration, i.e., A has been
                 replaced by diag(R) * A * diag(C).
         EQUED is an input argument if FACT = 'F'; otherwise, it is an
         output argument.

R

         R is REAL array, dimension (N)
         The row scale factors for A.  If EQUED = 'R' or 'B', A is
         multiplied on the left by diag(R); if EQUED = 'N' or 'C', R
         is not accessed.  R is an input argument if FACT = 'F';
         otherwise, R is an output argument.  If FACT = 'F' and
         EQUED = 'R' or 'B', each element of R must be positive.

C

         C is REAL array, dimension (N)
         The column scale factors for A.  If EQUED = 'C' or 'B', A is
         multiplied on the right by diag(C); if EQUED = 'N' or 'R', C
         is not accessed.  C is an input argument if FACT = 'F';
         otherwise, C is an output argument.  If FACT = 'F' and
         EQUED = 'C' or 'B', each element of C must be positive.

B

         B is REAL array, dimension (LDB,NRHS)
         On entry, the right hand side matrix B.
         On exit,
         if EQUED = 'N', B is not modified;
         if TRANS = 'N' and EQUED = 'R' or 'B', B is overwritten by
         diag(R)*B;
         if TRANS = 'T' or 'C' and EQUED = 'C' or 'B', B is
         overwritten by diag(C)*B.

LDB

         LDB is INTEGER
         The leading dimension of the array B.  LDB >= max(1,N).

X

         X is REAL array, dimension (LDX,NRHS)
         If INFO = 0 or INFO = N+1, the N-by-NRHS solution matrix X
         to the original system of equations.  Note that A and B are
         modified on exit if EQUED .ne. 'N', and the solution to the
         equilibrated system is inv(diag(C))*X if TRANS = 'N' and
         EQUED = 'C' or 'B', or inv(diag(R))*X if TRANS = 'T' or 'C'
         and EQUED = 'R' or 'B'.

LDX

         LDX is INTEGER
         The leading dimension of the array X.  LDX >= max(1,N).

RCOND

         RCOND is REAL
         The estimate of the reciprocal condition number of the matrix
         A after equilibration (if done).  If RCOND is less than the
         machine precision (in particular, if RCOND = 0), the matrix
         is singular to working precision.  This condition is
         indicated by a return code of INFO > 0.

FERR

         FERR is REAL array, dimension (NRHS)
         The estimated forward error bound for each solution vector
         X(j) (the j-th column of the solution matrix X).
         If XTRUE is the true solution corresponding to X(j), FERR(j)
         is an estimated upper bound for the magnitude of the largest
         element in (X(j) - XTRUE) divided by the magnitude of the
         largest element in X(j).  The estimate is as reliable as
         the estimate for RCOND, and is almost always a slight
         overestimate of the true error.

BERR

         BERR is REAL array, dimension (NRHS)
         The componentwise relative backward error of each solution
         vector X(j) (i.e., the smallest relative change in
         any element of A or B that makes X(j) an exact solution).

WORK

         WORK is REAL array, dimension (MAX(1,3*N))
         On exit, WORK(1) contains the reciprocal pivot growth
         factor norm(A)/norm(U). The  norm is
         used. If WORK(1) is much less than 1, then the stability
         of the LU factorization of the (equilibrated) matrix A
         could be poor. This also means that the solution X, condition
         estimator RCOND, and forward error bound FERR could be
         unreliable. If factorization fails with 0<INFO<=N, then
         WORK(1) contains the reciprocal pivot growth factor for the
         leading INFO columns of A.

IWORK

         IWORK is INTEGER array, dimension (N)

INFO

         INFO is INTEGER
         = 0:  successful exit
         < 0:  if INFO = -i, the i-th argument had an illegal value
         > 0:  if INFO = i, and i is
                <= N:  U(i,i) is exactly zero.  The factorization
                       has been completed, but the factor U is exactly
                       singular, so the solution and error bounds
                       could not be computed. RCOND = 0 is returned.
                = N+1: U is nonsingular, but RCOND is less than machine
                       precision, meaning that the matrix is singular
                       to working precision.  Nevertheless, the
                       solution and error bounds are computed because
                       there are a number of situations where the
