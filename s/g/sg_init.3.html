NOMBRE

sg_init, sg_snapshot, sg_shutdown, sg_drop_privileges - inicializa libstatgrab

SINOPSIS

#include <statgrab.h>


void sg_log_init
(const char *properties_pfx, const char *env_name, const char *argv0);


sg_error sg_init
(int ignore_init_errors);


sg_error sg_snapshot
(void);


sg_error sg_shutdown
(void);


sg_error sg_drop_privileges
(void);

DESCRIPCIÓN

sg_init() inicializa la biblioteca statgrab y establece el contador de inicialización en 1, si aún no se ha hecho, o incrementa el contador de inicialización. Si se llama por primera vez (de hecho: si se llama cuando el contador de inicialización es 0), se invoca el constructor (rutina de inicialización) de cada componente registrado, se inicializan algunas variables globales, se inicializan los semáforos de exclusión mutua solicitados, etc. sg_init() está protegido por el mutex llamado "statgrab".

sg_log_init() permite una configuración de registro de interés individual para la aplicación. Está destinado a proyectos con varias aplicaciones o comandos que pueden tener diferentes anexos. Tenga en cuenta que sg_log_init debe llamarse antes que sg_init, pero después de que su aplicación haya inicializado el marco de registro.

sg_snapshot() es solo para Win32 y probablemente desaparecerá.

sg_shutdown() decrementa el contador de inicialización. Si el contador llega a cero, se llaman los destructores de los componentes, se destruyen los semáforos de exclusión mutua (excepto "statgrab"), etc. sg_shutdown() está protegido por el mutex llamado "statgrab".

sg_drop_privileges() reduce los privilegios elevados.

VALORES DE RETORNO

Todas las funciones devuelven un código de error de statgrab. SG_ERROR_NONE cuando todo está bien o el código de error apropiado de un constructor/destructor.

EJEMPLO

Secuencia típica de inicialización/desinicialización al usar con log4cplus:

static void *l4cplus_initializer;
static void
cleanup_logging(void)
{
       log4cplus_deinitialize(l4cplus_initializer);
}
int
main(int argc, char const *argv[])
{
    l4cplus_initializer = log4cplus_initialize();
    atexit((void (*)(void))cleanup_logging);
    sg_log_init("saidar", "SAIDAR_LOG_PROPERTIES", argv[0]);
    sg_init(1);
    if(sg_drop_privileges() != 0) {
	die("Failed to drop setuid/setgid privileges");
    }
    do_something();
    sg_shutdown();
    return 0;
}
