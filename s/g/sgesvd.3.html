subroutine sgesvd (character jobu, character jobvt, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldvt, * ) vt, integer ldvt, real, dimension( * ) work, integer lwork, integer info)

SGESVD calcula la descomposición en valores singulares (SVD) de matrices GE

Propósito:

!>
!> SGESVD calcula la descomposición en valores singulares (SVD) de una matriz
!> real A de M por N, calculando opcionalmente los vectores singulares
!> izquierdo y/o derecho. La SVD se escribe
!>
!>      A = U * SIGMA * transpose(V)
!>
!> donde SIGMA es una matriz de M por N que es cero excepto por sus
!> elementos diagonales min(m,n), U es una matriz ortogonal M por M, y
!> V es una matriz ortogonal N por N. Los elementos diagonales de SIGMA
!> son los valores singulares de A; son reales y no negativos, y
!> se devuelven en orden descendente. Las primeras min(m,n) columnas de
!> U y V son los vectores singulares izquierdo y derecho de A.
!>
!> ¡Tenga en cuenta que la rutina devuelve V**T, no V!
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          Especifica las opciones para calcular todo o parte de la matriz U:
!>          = 'A':  se devuelven todas las M columnas de U en el array U:
!>          = 'S':  se devuelven las primeras min(m,n) columnas de U (los vectores
!>                  singulares izquierdos) en el array U;
!>          = 'O':  se sobrescriben las primeras min(m,n) columnas de U (los vectores
!>                  singulares izquierdos) en el array A;
!>          = 'N':  no se calculan columnas de U (ningún vector singular izquierdo).
!>

JOBVT

!>          JOBVT es CHARACTER*1
!>          Especifica las opciones para calcular todo o parte de la matriz
!>          V**T:
!>          = 'A':  se devuelven todas las N filas de V**T en el array VT;
!>          = 'S':  se devuelven las primeras min(m,n) filas de V**T (los vectores
!>                  singulares derechos) en el array VT;
!>          = 'O':  se sobrescriben las primeras min(m,n) filas de V**T (los vectores
!>                  singulares derechos) en el array A;
!>          = 'N':  no se calculan filas de V**T (ningún vector singular derecho).
!>
!>          JOBVT y JOBU no pueden ser ambos 'O'.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida,
!>          si JOBU = 'O',  A se sobrescribe con las primeras min(m,n)
!>                          columnas de U (los vectores singulares
!>                          izquierdos, almacenados por columnas);
!>          si JOBVT = 'O', A se sobrescribe con las primeras min(m,n)
!>                          filas de V**T (los vectores singulares
!>                          derechos, almacenados por filas);
!>          si JOBU .ne. 'O' y JOBVT .ne. 'O', el contenido de A
!>                          se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

S

!>          S es un array REAL, de dimensión (min(M,N))
!>          Los valores singulares de A, ordenados de tal manera que S(i) >= S(i+1).
!>

U

!>          U es un array REAL, de dimensión (LDU,UCOL)
!>          (LDU,M) si JOBU = 'A' o (LDU,min(M,N)) si JOBU = 'S'.
!>          Si JOBU = 'A', U contiene la matriz ortogonal M por M U;
!>          si JOBU = 'S', U contiene las primeras min(m,n) columnas de U
!>          (los vectores singulares izquierdos, almacenados por columnas);
!>          si JOBU = 'N' o 'O', U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U.  LDU >= 1; si
!>          JOBU = 'S' o 'A', LDU >= M.
!>

VT

!>          VT es un array REAL, de dimensión (LDVT,N)
!>          Si JOBVT = 'A', VT contiene la matriz ortogonal N por N
!>          V**T;
!>          si JOBVT = 'S', VT contiene las primeras min(m,n) filas de
!>          V**T (los vectores singulares derechos, almacenados por filas);
!>          si JOBVT = 'N' o 'O', VT no se referencia.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del array VT.  LDVT >= 1; si
!>          JOBVT = 'A', LDVT >= N; si JOBVT = 'S', LDVT >= min(M,N).
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo;
!>          si INFO > 0, WORK(2:MIN(M,N)) contiene los elementos de la
!>          superdiagonal de una matriz bidiagonal intermedia B
!>          cuya diagonal está en S (no necesariamente ordenada). B
!>          satisface A = U * B * VT, por lo que tiene los mismos valores
!>          singulares que A, y vectores singulares relacionados por U y VT.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= MAX(1,5*MIN(M,N)) para las rutas (ver comentarios dentro del código):
!>             - RUTA 1  (M mucho mayor que N, JOBU='N')
!>             - RUTA 1t (N mucho mayor que M, JOBVT='N')
!>          LWORK >= MAX(1,3*MIN(M,N)+MAX(M,N),5*MIN(M,N)) para las otras rutas
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún
!>          mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si SBDSQR no convergió, INFO especifica cuántas
!>                superdiagonales de una forma bidiagonal intermedia B
!>                no convergieron a cero. Consulte la descripción de WORK
!>                anteriormente para obtener detalles.
!>

NOMBRE

sgesvd - Calcula la descomposición en valores singulares de una matriz real general.

SINOPSIS

SUBROUTINE SGESVD(JOBU, JOBV, M, N, A, LDA, S, U, LDU, V, LDV, WORK, LWORK, INFO)

Documentación de Función/Subrutina

SGESVD calcula la descomposición en valores singulares (SVD) de una matriz real general $A$, de dimensiones $M \times N$. La SVD se define como $A = S U \Sigma V^T$, donde $S$ es una matriz ortogonal $M \times M$, $U$ es una matriz ortogonal $M \times M$, $\Sigma$ es una matriz diagonal $M \times N$ con elementos diagonales no negativos, y $V$ es una matriz ortogonal $N \times N$. Los elementos diagonales de $\Sigma$ son los valores singulares de $A$, ordenados de mayor a menor.

Parámetros:

  • JOBU (CHARACTER*1): Indica si se deben calcular los vectores singulares izquierdos (U).
  • JOBV (CHARACTER*1): Indica si se deben calcular los vectores singulares derechos (V).
  • M (INTEGER): Número de filas de la matriz A.
  • N (INTEGER): Número de columnas de la matriz A.
  • A (REAL*4 array, dimension (LDA,N)): Matriz de entrada.
  • LDA (INTEGER): Longitud de la primera dimensión de A.
  • S (REAL*4 array, dimension (MIN(M,N))): Array de salida para los valores singulares.
  • U (REAL*4 array, dimension (LDU, M) o (LDU, K) si JOBU='S'): Matriz de salida para los vectores singulares izquierdos.
  • LDU (INTEGER): Longitud de la primera dimensión de U.
  • V (REAL*4 array, dimension (LDV, N) o (LDV, K) si JOBV='S'): Matriz de salida para los vectores singulares derechos.
  • LDV (INTEGER): Longitud de la primera dimensión de V.
  • WORK (REAL*4 array, dimension (LWORK)): Array de trabajo.
  • LWORK (INTEGER): Longitud del array de trabajo WORK.
  • INFO (INTEGER): Entero de salida. Si INFO es 0, la ejecución fue exitosa. Si INFO es negativo, indica un error en el parámetro especificado. Si INFO es positivo, indica que el algoritmo de convergencia del subprograma de bidiagonalización reducida no convergió.

SGESVD es parte de la biblioteca LAPACK (Linear Algebra PACKage).
