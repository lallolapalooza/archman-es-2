NOMBRE

sg_senddiag - realiza un comando SCSI SEND DIAGNOSTIC

SINOPSIS

sg_senddiag [--doff] [--extdur] [--help] [--hex] [--list] [--maxlen=LEN] [--page=PG] [--pf] [--raw=H,H...] [--raw=-] [--selftest=ST] [--test] [--timeout=SECS] [--uoff] [--verbose] [--version] DISPOSITIVO

sg_senddiag [-doff] [-e] [-h] [-H] [-l] [-pf] [-raw=H,H...] [-raw=-] [-s=ST] [-t] [-T=SECS] [-uoff] [-v] [-V] [-?] DISPOSITIVO

DESCRIPCIÓN

Esta utilidad envía un comando SCSI SEND DIAGNOSTIC al DISPOSITIVO. Puede ejecutar auto-pruebas, encontrar páginas de diagnóstico soportadas o enviar páginas de diagnóstico arbitrarias.

Cuando se dan las opciones --list y un DISPOSITIVO, la utilidad envía un comando SCSI RECEIVE DIAGNOSTIC RESULTS para obtener la respuesta (es decir, los números de página de las páginas de diagnóstico soportadas).

Cuando se da la opción --list sin un DISPOSITIVO, se lista un conjunto de nombres de páginas de diagnóstico y sus números, conocidos por esta utilidad.

Esta utilidad soporta dos sintaxis de línea de comandos; la preferida se muestra primero en la sinopsis y se explica en esta sección. Una sección posterior sobre la sintaxis antigua de línea de comandos describe el segundo grupo de opciones.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-d, --doff
establece el bit Device Offline (DevOffL) (por defecto está limpio). Solo es significativo cuando la opción --test se establece para la auto-prueba predeterminada. Cuando se establece, otras operaciones en cualquier unidad lógica controlada por este servidor de dispositivo (target) pueden verse afectadas (retrasadas) mientras una auto-prueba predeterminada está en curso.
-e, --extdur
emite la duración esperada extendida de la auto-prueba. La duración se da en segundos (y minutos entre paréntesis). Esta cifra se obtiene de la página de modo 0xa (es decir, la página de modo de control).
-h, --help
imprime el mensaje de uso y sale.
-H, --hex
emite la respuesta de RECEIVE DIAGNOSTIC RESULTS en hexadecimal en lugar de decodificarla. Solo la página de diagnóstico Páginas de Diagnóstico Soportadas (es decir, page_code=0) se decodifica; otras páginas (por ejemplo, las usadas por SES) se emiten en hexadecimal.
Si se usa --hex una vez, la salida hexadecimal tiene una dirección relativa al principio de cada línea. Si se usa --hex dos veces, entonces se muestra ASCII a la derecha de cada línea hexadecimal. Si se usa --hex tres o más veces, solo se emite el hexadecimal, en pares de dos caracteres (es decir, un byte) separados por espacios y hasta 16 bytes por línea. Esta última forma, si se coloca en un archivo o se canaliza a otra invocación, es adecuada para la opción --raw=-.
-l, --list
cuando también se proporciona un DISPOSITIVO, lista los nombres de todas las páginas de diagnóstico soportadas por este dispositivo. La solicitud se envía a través de un comando SEND DIAGNOSTIC (con el bit "pF" activado) y la respuesta se obtiene mediante un comando RECEIVE DIAGNOSTIC RESULTS. Cuando se usa en ausencia de un argumento --list, se lista un conjunto de nombres de páginas de diagnóstico y sus números, conocidos por esta utilidad.
-m, --maxlen=LEN
donde LEN es el valor colocado en el campo de longitud de la lista de parámetros de un comando SEND DIAGNOSTIC o en el campo de longitud de asignación de un comando RECEIVE DIAGNOSTIC RESULTS. Esto solo ocurre cuando las otras opciones implican que habrá datos enviados o recibidos por el comando. El valor predeterminado es 4096 bytes. LEN no puede exceder 65535 o 0xffff en hexadecimal.
-O, --old
Cambia a opciones de estilo antiguo. Úsala como primera opción.
-P, --page=PG
donde PG es el campo del código de página del comando RECEIVE DIAGNOSTIC RESULTS. Si se proporciona esta opción, se activa el bit PCV en ese comando. Cuando se proporciona esta opción, no se envía ningún comando SEND DIAGNOSTIC (a diferencia de --list). Si PG es 0, la respuesta se decodifica como si fuera la página de diagnóstico de páginas de diagnóstico soportadas de SPC. Otros valores de PG (es decir, de 1 a 255) tienen sus respuestas emitidas en hexadecimal.
-p, --pf
establece el bit Page Format (PF). Por defecto está limpio (es decir, 0) a menos que se proporcione la opción --list, en cuyo caso el bit Page Format se establece (según lo requerido por SPC-3).
-r, --raw=H,H...
cadena de números hexadecimales separados por comas, cada uno de los cuales debería resolverse en un valor de byte (es decir, de 0 a ff inclusive). También se permite una cadena de bytes hexadecimales separada por un solo espacio, pero la lista debe estar entre comillas. Esta secuencia forma una página de diagnóstico que se enviará con el comando SCSI SEND DIAGNOSTIC. Lo más probable es que también se deba proporcionar la opción --pf.
-r, --raw=-
lee una secuencia de bytes desde la entrada estándar. La secuencia puede estar separada por comas, espacios, tabulaciones o saltos de línea (nueva línea). Si una línea contiene "#", los caracteres restantes de esa línea se ignoran. De lo contrario, cada carácter que no sea un separador debería resolverse en un valor de byte (es decir, de 0 a ff inclusive). Esta secuencia forma una página de diagnóstico que se enviará con el comando SCSI SEND DIAGNOSTIC. Lo más probable es que también se deba proporcionar la opción --pf.
-s, --selftest=ST
donde ST es el código de auto-prueba. El valor predeterminado es 0, que está inactivo. Algunos otros valores:
1 : auto-prueba corta en segundo plano
2 : auto-prueba extendida en segundo plano
4 : aborta una auto-prueba (en segundo plano) que está en curso
5 : auto-prueba corta en primer plano
6 : auto-prueba extendida en primer plano

Esta opción es mutuamente excluyente con la auto-prueba predeterminada (es decir, no se pueden tener (ST > 0) y --test).

-t, --test
establece el bit de auto-prueba predeterminada (_default_ Self Test). Por defecto está limpio (0). La opción --selftest=ST no debe estar activa junto con esta opción. Las opciones --doff y/o --uoff se pueden usar con esta opción.
-T, --timeout=SECS
donde SECS es un valor de tiempo de espera (en segundos) para operaciones de auto-prueba en primer plano. El valor predeterminado es 7200 segundos (2 horas) y cualquier valor de SECS menor que el predeterminado se ignora.
-u, --uoff
establece el bit Unit Offline (UnitOffL) (por defecto está limpio). Solo es significativo cuando la opción --test se establece para la auto-prueba predeterminada. Cuando se establece, otras operaciones en esta unidad lógica pueden verse afectadas (retrasadas) mientras una auto-prueba predeterminada está en curso. Algunos dispositivos (por ejemplo, discos Fujitsu) realizan más pruebas cuando este bit está activado.
-v, --verbose
aumenta el nivel de verbosidad. Se puede usar varias veces.
-V, --version
imprime la cadena de versión y sale.

NOTAS

Todos los dispositivos deberían soportar la auto-prueba predeterminada. Los códigos de auto-prueba 'corta' deberían completarse en 2 minutos o menos. La duración máxima de los códigos de auto-prueba 'extendida' es específica del proveedor (por ejemplo, poco más de 10 minutos con los discos del autor). Los códigos de auto-prueba en primer plano esperan hasta que se completan, mientras que los códigos de auto-prueba en segundo plano regresan inmediatamente. Los resultados de ambos códigos de auto-prueba en primer plano y en segundo plano se colocan en la página de registro de 'resultados de auto-prueba' (ver sg_logs(8)). El tiempo de espera del comando SCSI para esta utilidad se establece en 60 minutos para permitir auto-pruebas extendidas lentas en primer plano.

Si el DISPOSITIVO es un disco, no se deben montar sistemas de archivos que residan en ese disco durante una auto-prueba en primer plano. La razón es que otros comandos SCSI pueden ponerse en cola detrás de la auto-prueba en primer plano y agotar el tiempo de espera.

Cuando se proporciona la opción --raw=H,H..., las auto-pruebas no deberían ser sel

NAME

sg_senddiag - send a SCSI SEND DIAGNOSTIC command

SYNOPSIS

sg_senddiag [OPTIONS] DEVICE

DESCRIPTION

This utility sends a SCSI SEND DIAGNOSTIC command to the given DEVICE. The command is often used for self-testing of SCSI devices or for reading/writing diagnostic pages.

The default action is to send a SCSI SEND DIAGNOSTIC command requesting the device to perform its default self-test. The device will report back the expected duration of this self-test.

To send a specific diagnostic page (e.g., for self-test or to query specific device information) the --raw=H,H... option (or -raw=H,H... in older versions) should be used. The Page Format (PF) bit in the CDB will be set by default when using --raw.

OPTIONS

--device=DEVICE
-d, --doff
Sets the Device Offline (DevOffL) bit in the CDB. Defaults to clear (0). Only significant when the default self-test is requested (i.e., no specific diagnostic page is being sent).
-e, --extdur
Outputs the extended self-test duration received from the device. The default is to output the standard duration.
-f, --force
Forces the command to be sent even if some potential issues are detected (e.g., device busy). Use with caution.
-h, --help
Print usage information and exit.
--hex
Output the response from RECEIVE DIAGNOSTIC RESULTS in hex rather than attempting to decode it.
-H, --hex
Same as --hex.
-l, --list
List the names and codes of diagnostic pages supported by the device. This requires sending a SEND DIAGNOSTIC command with the Page Format (PF) bit set and then reading the response with RECEIVE DIAGNOSTIC RESULTS. If no DEVICE is given, lists diagnostic pages known to this utility.
-O, --old
Use the older command-line option syntax. This is useful for compatibility with older scripts or versions of sg3_utils.
-o, --off
Same as -uoff (Unit Offline).
--pf
Set the Page Format (PF) bit in the CDB. This is generally required when sending or requesting specific diagnostic pages. Defaults to set if --raw or --list is used, otherwise defaults to clear.
-p, --pf
Same as --pf.
-r=H,H..., --raw=H,H...
Sends a diagnostic page specified by the comma-separated list of hex bytes (00-ff). The Page Format (PF) bit is usually set automatically with this option. The first byte is the diagnostic page code.
-r=-, --raw=-
Reads the diagnostic page data from standard input. Data can be comma-, space-, tab-, or newline-separated. Lines starting with '#' are ignored.
-s=ST, --self-test=ST
Specifies the self-test code (ST). Common values:
  • 0: No self-test (default)
  • 1: Background short self-test
  • 2: Background extended self-test
  • 4: Abort background self-test
  • 5: Foreground short self-test
  • 6: Foreground extended self-test
This option is mutually exclusive with the default self-test (-t).
-t, --test
Requests the device to perform its default self-test. The -s option should not be used with this option.
-T=SECS, --timeout=SECS
Sets the timeout in seconds for the SCSI command. Defaults to 60 seconds. Relevant mainly for foreground self-tests.
-u, --uoff
Sets the Unit Offline (UnitOffL) bit in the CDB. Defaults to clear (0). Only significant when the default self-test is requested.
-v, --verbose
Increase the level of verbosity. Can be used multiple times.
-V, --version
Print out version string and exit.
-?
Output usage message and exit.

NOTES

To send or receive specific diagnostic pages, the --pf (i.e. "page format") option should be given. The length of the diagnostic page to be sent is derived from the number of bytes given to the --raw=H,H... option. The diagnostic page code (number) should be the first byte of the sequence (i.e. as dictated by SPC-3 diagnostic page format). See the EXAMPLES section below.

Arbitrary diagnostic pages can be read (in hex) with the sg_ses(8) utility (not only those defined in SES-2).

If the utility is used with no options (e.g. "sg_senddiag /dev/sg1") Then a degenerate SCSI SEND DIAGNOSTIC command is sent with zero in all its fields apart from the opcode. Some devices report this as an error while others ignore it. It is not entirely clear from SPC-3 if it is invalid to send such a command.

In the 2.4 series of Linux kernels the DEVICE must be a SCSI generic (sg) device. In the 2.6 series block devices (e.g. SCSI disks and DVD drives) can also be specified.

To access SCSI enclosures see the sg_ses(8) utility. sg_ses uses the SCSI SEND DIAGNOSTIC and RECEIVE DIAGNOSTIC RESULTS commands as outlined in the SES-2 (draft) standard.

EXIT STATUS

The exit status of sg_senddiag is 0 when it is successful. Otherwise see the sg3_utils(8) man page.

OLDER COMMAND LINE OPTIONS

The options in this section were the only ones available prior to sg3_utils version 1.23 . Since then this utility defaults to the newer command line options which can be overridden by using --old (or -O) as the first option. See the ENVIRONMENT VARIABLES section for another way to force the use of these older command line options.

-doff
set the Device Offline (DevOffL) bit (default is clear). Only significant when -t option is set for the default self-test. Equivalent to --doff in the main description.
-e
outputs the expected extended self-test duration. Equivalent to --extdur in the main description.
-h
outputs response from RECEIVE DIAGNOSTIC RESULTS in hex rather than decode it.
-H
outputs response from RECEIVE DIAGNOSTIC RESULTS in hex rather than decode it.
-l
when a DEVICE is also given lists the names of all diagnostic pages supported by this device. The request is sent via a SEND DIAGNOSTIC command (with the "pf" bit set) and the response is fetched by a RECEIVE DIAGNOSTIC RESULTS command. When used in the absence of a DEVICE argument then a list of diagnostic page names and their numbers, known by this utility, are listed.
-N, --new
Switch to the newer style options.
-pf
set Page Format (PF) bit. By default it is clear (i.e. 0) unless the -l option is given in which case the Page Format bit is set (as required by SPC-3).
-raw=H,H...
string of comma separated hex numbers each of which should resolve to a byte value (i.e. 0 to ff inclusive). This sequence forms a diagnostic page to be sent with the SCSI SEND DIAGNOSTIC command. Mostly likely the -pf option should also be given.
-raw=-
reads sequence of bytes from stdin. The sequence may be comma, space, tab or linefeed (newline) separated. If a line contains "#" then the remaining characters on that line are ignored. Otherwise each non separator character should resolve to a byte value (i.e. 0 to ff inclusive). This sequence forms a diagnostic page to be sent with the SCSI SEND DIAGNOSTIC command. Mostly likely the -pf option should also be given.
-s=ST
where ST is the self-test code. The default value is 0 which is inactive. A value of 1 selects a background short self-test; 2 selects a background extended self-test; 5 selects a foreground short self-test; 6 selects a foreground extended test. A value of 4 will abort a (background) self-test that is in progress. This option is mutually exclusive with default self-test (i.e. -t).
-t
sets the _default_ Self Test (SelfTest) bit. By default this is clear (0). The -s=ST option should not be active together with this option. Both the -doff and/or -uoff options can be used with this option.
-T=SECS
where SECS is a timeout value (in seconds) for foreground self-test operations. See the --timeout=SECS option above.
-uoff
set the Unit Offline (UnitOffL) bit (default is clear). Equivalent to --uoff in the main description.
-v
increase level of verbosity. Can be used multiple times.
-V
print out version string then exit.
-?
output usage message. Ignore all other parameters.

EXAMPLES

The examples sub-directory in the sg3_utils packages contains two example scripts that turn on the CJTPAT (jitter pattern) on some SAS disks (one script for each phy). One possible invocation for phy 1 is:


sg_senddiag --pf --raw=- /dev/sg2 < sdiag_sas_p1_cjtpat.txt

There is also an example script that turns on the IDLE pattern. Once a test pattern has been started it can be turned off by resetting the phy or with the STOP phy pattern function:


sg_senddiag --pf --raw=- /dev/sg2 < sdiag_sas_p1_stop.txt

ENVIRONMENT VARIABLES

Since sg3_utils version 1.23 the environment variable SG3_UTILS_OLD_OPTS can be given. When it is present this utility will expect the older command line options. So the presence of this environment variable is equivalent to using --old (or -O) as the first command line option.
