SGEDMD calcula la Descomposición de Modos Dinámicos (DMD) para un par de matrices de instantáneas de datos.

Propósito:

!>    SGEDMD calcula la Descomposición de Modos Dinámicos (DMD) para
!>    un par de matrices de instantáneas de datos. Para las matrices
!>    de entrada X e Y tales que Y = A*X con una matriz A inaccesible,
!>    SGEDMD calcula un cierto número de pares de Ritz de A utilizando
!>    la extracción estándar de Rayleigh-Ritz de un subespacio
!>    de range(X) que se determina utilizando los vectores singulares
!>    izquierdos líderes de X. Opcionalmente, SGEDMD devuelve los residuos
!>    de los pares de Ritz calculados, la información necesaria para
!>    un refinamiento de los vectores de Ritz, o los vectores propios de
!>    la DMD Exacta.
!>    Para más detalles ver las referencias listadas
!>    a continuación. Para más detalles de la implementación ver [3].
!>

Referencias:

!>        and experimental data,

!>        decompositions: analysis and enhancements,

!>    'S' :: Las matrices de instantáneas de datos X e Y se multiplican
!>           por una matriz diagonal D de modo que X*D tenga columnas
!>           no nulas unitarias (en la norma 2 euclidiana).

!>           cero y la i-ésima columna correspondiente de Y es

REIG

!>    REIG (salida) REAL(KIND=WP) array N por 1
!>    Las K entradas principales (K<=N) de REIG contienen
!>    las partes reales de los autovalores calculados
!>    REIG(1:K) + sqrt(-1)*IMEIG(1:K).
!>    Ver las descripciones de K, IMEIG y Z.
!>

IMEIG

!>    IMEIG (salida) REAL(KIND=WP) array N por 1
!>    Las K entradas principales (K<=N) de IMEIG contienen
!>    las partes imaginarias de los autovalores calculados
!>    REIG(1:K) + sqrt(-1)*IMEIG(1:K).
!>    Los autovalores se determinan de la siguiente manera:
!>    Si IMEIG(i) == 0, entonces el autovalor correspondiente es
!>    real, LAMBDA(i) = REIG(i).
!>    Si IMEIG(i)>0, entonces el par conjugado complejo
!>    de autovalores es
!>    LAMBDA(i)   = REIG(i) + sqrt(-1)*IMAG(i)
!>    LAMBDA(i+1) = REIG(i) - sqrt(-1)*IMAG(i)
!>    Es decir, los pares conjugados complejos tienen índices consecutivos
!>    (i,i+1), con la parte imaginaria positiva listada primero.
!>    Ver las descripciones de K, REIG y Z.
!>

Z

!>    Z (espacio de trabajo/salida) REAL(KIND=WP) array M por N
!>    Si JOBZ =='V' entonces
!>       Z contiene vectores de Ritz reales como sigue:
!>       Si IMEIG(i)=0, entonces Z(:,i) es un vector propio de
!>       el i-ésimo valor de Ritz; ||Z(:,i)||_2=1.
!>       Si IMEIG(i) > 0 (y IMEIG(i+1) < 0) entonces
!>       [Z(:,i) Z(:,i+1)] abarcan un subespacio invariante y
!>       los valores de Ritz extraídos de este subespacio son
!>       REIG(i) + sqrt(-1)*IMEIG(i) y
!>       REIG(i) - sqrt(-1)*IMEIG(i).
!>       Los vectores propios correspondientes son
!>       Z(:,i) + sqrt(-1)*Z(:,i+1) y
!>       Z(:,i) - sqrt(-1)*Z(:,i+1), respectivamente.
!>       || Z(:,i:i+1)||_F = 1.
!>    Si JOBZ == 'F', entonces las descripciones anteriores se aplican a
!>    las columnas de X(:,1:K)*W(1:K,1:K), donde las columnas
!>    de W(1:k,1:K) son los vectores propios calculados del
!>    cociente de Rayleigh K-por-K. Las columnas de W(1:K,1:K)
!>    tienen una estructura similar: Si IMEIG(i) == 0 entonces
!>    X(:,1:K)*W(:,i) es un vector propio, y si IMEIG(i)>0
!>    entonces X(:,1:K)*W(:,i)+sqrt(-1)*X(:,1:K)*W(:,i+1) y
!>         X(:,1:K)*W(:,i)-sqrt(-1)*X(:,1:K)*W(:,i+1)
!>    son los vectores propios de LAMBDA(i), LAMBDA(i+1).
!>    Ver las descripciones de REIG, IMEIG, X y W.
!>

LDZ

!>    LDZ (entrada) INTEGER , LDZ >= M
!>    La dimensión principal del array Z.
!>

RES

!>    RES (salida) REAL(KIND=WP) array N por 1
!>    RES(1:K) contiene los residuos para los K pares de Ritz calculados.
!>    Si LAMBDA(i) es real, entonces
!>       RES(i) = || A * Z(:,i) - LAMBDA(i)*Z(:,i))||_2.
!>    Si [LAMBDA(i), LAMBDA(i+1)] es un par conjugado complejo
!>    entonces
!>    RES(i)=RES(i+1) = || A * Z(:,i:i+1) - Z(:,i:i+1) *B||_F
!>    donde B = [ real(LAMBDA(i)) imag(LAMBDA(i)) ]
!>              [-imag(LAMBDA(i)) real(LAMBDA(i)) ].
!>    Se cumple que
!>    RES(i)   = || A*ZC(:,i)   - LAMBDA(i)  *ZC(:,i)   ||_2
!>    RES(i+1) = || A*ZC(:,i+1) - LAMBDA(i+1)*ZC(:,i+1) ||_2
!>    donde ZC(:,i)   =  Z(:,i) + sqrt(-1)*Z(:,i+1)
!>          ZC(:,i+1) =  Z(:,i) - sqrt(-1)*Z(:,i+1)
!>    Ver la descripción de REIG, IMEIG y Z.
!>

B

!>    B (salida) REAL(KIND=WP)  array M por N.
!>    SI JOBF =='R', B(1:M,1:K) contiene A*U(:,1:K), y puede
!>    ser usado para calcular los vectores refinados; ver más
!>    detalles en las referencias proporcionadas.
!>    Si JOBF == 'E', B(1:M,1;K) contiene
!>    A*U(:,1:K)*W(1:K,1:K), que son los vectores del
!>    DMD Exacto, hasta el escalado por los inversos de los autovalores.
!>    Si JOBF =='N', entonces B no se referencia.
!>    Ver las descripciones de X, W, K.
!>

LDB

!>    LDB (entrada) INTEGER, LDB >= M
!>    La dimensión principal del array B.
!>

W

NAME


sgedmd.f90 — computes the singular value decomposition (SVD) of a general
    real matrix.






SYNOPSIS


 SUBROUTINE SGEDMD( JOBS, TRANSPOSE, M, N, A, LDA, B, LDB, Q, LDQ,
 &                   Z, ZD, LWORK, IWORK, LIWORK, INFO )



Parameters:




JOBS


CHARACTER*1.&gt;


     Specifies whether to compute the left singular vectors of the matrix
     A, or the left singular vectors of the matrix B.
     = 'N': neither is computed.
     = 'A': all left singular vectors are computed.
     = 'S': only the first min(M,N) left singular vectors are computed.
     = 'C': the first min(M,N) left singular vectors are computed.



TRANSPOSE


CHARACTER*1.&gt;


     Specifies whether to transpose the matrix B.
     = 'N': no transpose. B is used as is.
     = 'T': transpose. B^T is used.



M


INTEGER.&gt;


     The number of rows of the matrix A. M >= 0.



N


INTEGER.&gt;


     The number of columns of the matrix A. N >= 0.



A


REAL array, dimension (LDA, N).&gt;


     The m-by-n matrix A.



LDA


INTEGER.&gt;


     The leading dimension of the array A. LDA >= max(1,M).



B


REAL array, dimension (LDB, N).&gt;


     The m-by-n matrix B.



LDB


INTEGER.&gt;


     The leading dimension of the array B. LDB >= max(1,M).



Q


REAL array, dimension (LDQ, K).&lt;


     The m-by-k matrix Q containing the left singular vectors, where
     k = min(M,N) if JOBS = 'S' or 'C', and k = M if JOBS = 'A'.
     Q is not used if JOBS = 'N'.



LDQ


INTEGER.&gt;


     The leading dimension of the array Q. LDQ >= max(1,M).



Z


REAL array, dimension (max(1,N)).&lt;


     The vector Z of length N containing the right singular vectors.
     Z is not computed if N=0.



ZD


REAL array, dimension (max(1,M)).&lt;


     The vector ZD of length M containing the diagonal elements of the
     right singular vectors.
     ZD is not computed if M=0.



LWORK


INTEGER.&gt;


     The dimension of the array WORK.
     If LWORK = -1, then only a workspace query is performed, and Z, ZD,
     and INFO are not used. The minimal and optimal sizes for WORK are
     returned in WORK(1) and WORK(2) respectively.
     In general, the minimal length of WORK is:
     If TRANSPOSE == 'N':
         if JOBS == 'N':
             LWORK >= MAX(1, 2*M + 2*N)
         if JOBS == 'S':
             LWORK >= MAX(1, 2*M + N + MIN(M,N))
         if JOBS == 'A':
             LWORK >= MAX(1, 2*M + N + M)
         if JOBS == 'C':
             LWORK >= MAX(1, 2*M + N + MIN(M,N))
     If TRANSPOSE == 'T':
         if JOBS == 'N':
             LWORK >= MAX(1, 3*M + 2*N)
         if JOBS == 'S':
             LWORK >= MAX(1, 3*M + N + MIN(M,N))
         if JOBS == 'A':
             LWORK >= MAX(1, 3*M + N + M)
         if JOBS == 'C':
             LWORK >= MAX(1, 3*M + N + MIN(M,N))
     LWORK must be long enough for easy checking. In any case, LWORK >= 2.
     If on entry LWORK = -1, then a workspace query is
     assumed and the procedure only computes the minimal
     and the optimal workspace lengths for both WORK and
     IWORK. See the descriptions of WORK and IWORK.



IWORK


INTEGER workspace/output. dimension (LIWORK).


     Workspace that is required only if WHTSVD equals
     2 , 3 or 4 . (See the description of WHTSVD).
     If on entry LWORK =-1 or LIWORK=-1, then the
     minimal length of IWORK is computed and returned in
     IWORK(1).



LIWORK


INTEGER.&gt;


     The minimal length of the workspace vector IWORK.
     If WHTSVD == 1, then only IWORK(1) is used; LIWORK >=1
     If WHTSVD == 2, then LIWORK >= MAX(1,8*MIN(M,N))
     If WHTSVD == 3, then LIWORK >= MAX(1,M+N-1)
     If WHTSVD == 4, then LIWORK >= MAX(3,M+3*N)
     If on entry LIWORK = -1, then a workspace query is
     assumed and the procedure only computes the minimal
     and the optimal workspace lengths for both WORK and
     IWORK. See the descriptions of WORK and IWORK.



INFO


INTEGER.&lt;


     -i < 0 :: On entry, the i-th argument had an
               illegal value
        = 0 :: Successful return.
        = 1 :: Void input. Quick exit (M=0 or N=0).
        = 2 :: The SVD computation of X did not converge.
              Suggestion: Check the input data and/or
              repeat with different WHTSVD.
        = 3 :: The computation of the eigenvalues did not
              converge.
        = 4 :: If data scaling was requested on input and
              the procedure found inconsistency in the data
              such that for some column index i,
              X(:,i) = 0 but Y(:,i) /= 0, then Y(:,i) is set
              to zero if JOBS=='C'. The computation proceeds
              with original or modified data and warning
              flag is set with INFO=4.
