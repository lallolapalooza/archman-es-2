Documentación de Función/Subrutina

subrutina sglmts (integer n, integer m, integer p, real, dimension( lda, * ) a, real, dimension( lda, * ) af, integer lda, real, dimension( ldb, * ) b, real, dimension( ldb, * ) bf, integer ldb, real, dimension( * ) d, real, dimension( * ) df, real, dimension( * ) x, real, dimension( * ) u, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real result)

SGLMTS

Propósito:

!>
!> SGLMTS prueba SGGGLM - una subrutina para resolver el problema del
!> modelo lineal generalizado.
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de filas de las matrices A y B.  N >= 0.
!>

M

!>          M es ENTERO
!>          El número de columnas de la matriz A.  M >= 0.
!>

P

!>          P es ENTERO
!>          El número de columnas de la matriz B.  P >= 0.
!>

A

!>          A es un array REAL, dimension (LDA,M)
!>          La matriz A de N por M.
!>

AF

!>          AF es un array REAL, dimension (LDA,M)
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A, AF. LDA >= max(M,N).
!>

B

!>          B es un array REAL, dimension (LDB,P)
!>          La matriz A de N por P.
!>

BF

!>          BF es un array REAL, dimension (LDB,P)
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal de los arrays B, BF. LDB >= max(P,N).
!>

D

!>          D es un array REAL, dimension( N )
!>          En la entrada, el lado izquierdo de la GLM.
!>

DF

!>          DF es un array REAL, dimension( N )
!>

X

!>          X es un array REAL, dimension( M )
!>          vector solución X en el problema GLM.
!>

U

!>          U es un array REAL, dimension( P )
!>          vector solución U en el problema GLM.
!>

WORK

!>          WORK es un array REAL, dimension (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es un array REAL, dimension (M)
!>

RESULT

!>          RESULT es REAL
!>          La razón de prueba:
!>                           norm( d - A*x - B*u )
!>            RESULT = -----------------------------------------
!>                     (norm(A)+norm(B))*(norm(x)+norm(u))*EPS
!>
