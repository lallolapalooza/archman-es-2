SGGSVD3 calcula la descomposición en valores singulares (SVD) para OTRAS matrices

Documentación de Función/Subrutina

subrutina sggsvd3 (character jobu, character jobv, character jobq, integer m, integer n, integer p, integer k, integer l, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) alpha, real, dimension( * ) beta, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldv, * ) v, integer ldv, real, dimension( ldq, * ) q, integer ldq, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

SGGSVD3 calcula la descomposición en valores singulares generalizada (GSVD)
de una matriz real M por N A y una matriz real P por N B:

Propósito:

!>
!> SGGSVD3 calcula la descomposición en valores singulares generalizada (GSVD)
!> de una matriz real M por N A y una matriz real P por N B:
!>
!>       U**T*A*Q = D1*( 0 R ),    V**T*B*Q = D2*( 0 R )
!>
!> donde U, V y Q son matrices ortogonales.
!> Sea K+L = el rango numérico efectivo de la matriz (A**T,B**T)**T,
!> entonces R es una matriz triangular superior no singular de K+L por K+L, D1 y
!> D2 son matrices M por (K+L) y P por (K+L) y de las
!> siguientes estructuras, respectivamente:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) al salir.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N), y R33 se almacena
!>   ( 0  R22 R23 )
!>   en B(M-K+1:L,N+M-K-L+1:N) al salir.
!>
!> La subrutina calcula C, S, R y, opcionalmente, las matrices de
!> transformación ortogonal U, V y Q.
!>
!> En particular, si B es una matriz cuadrada no singular N por N, entonces la GSVD
!> de A y B da implícitamente la SVD de A*inv(B):
!>                      A*inv(B) = U*(D1*inv(D2))*V**T.
!> Si ( A**T,B**T)**T  tiene columnas ortonormales, entonces la GSVD de A y B
!> es también igual a la descomposición CS de A y B. Además, la GSVD
!> puede usarse para derivar la solución del problema de valores
!> propios:
!>                      A**T*A x = lambda* B**T*B x.
!> En alguna literatura, la GSVD de A y B se presenta en la forma
!>                  U**T*A*X = ( 0 D1 ),   V**T*B*X = ( 0 D2 )
!> donde U y V son ortogonales y X es no singular, D1 y D2 son
!> ``diagonales''. La forma anterior de GSVD se puede convertir a la forma
!> posterior tomando la matriz no singular X como
!>
!>                      X = Q*( I   0    )
!>                            ( 0 inv(R) ).
!>

NAME

SGGSVD3

Singular value decomposition of a general rectangular matrix pair (real matrix)

SYNOPSIS

SUBROUTINE SGGSVD3(
   JOBU, JOBV, JOBQ,
   M, N, P,
   A, LDA,
   B, LDB,
   S, E,
   U, LDU,
   V, LDV,
   Q, LDQ,
   WORK, LWORK,
   IWORK, INFO
)
      CHARACTER * 1   JOBU, JOBV, JOBQ
      INTEGER         M, N, P, LDA, LDB, LDU, LDV, LDQ, LWORK, INFO
      REAL            A(LDA,*), B(LDB,*), S(*), E(*), U(LDU,*), V(LDV,*), Q(LDQ,*), WORK(*)
      INTEGER         IWORK(*)

Function/Subroutine Documentation

SGGSVD3 computes the singular value decomposition of a general rectangular matrix pair (A, B).

A and B are assumed to have dimension M-by-N and P-by-N respectively, and there are N singular values.

The singular values are returned in S, with E. The entries of E are zero.

SGGSVD3 computes an optional unitary matrix U, an optional unitary matrix V, and an optional unitary matrix Q such that

A = U * S * Q
B = V * E * Q

where S is a real diagonal matrix with real positive diagonal entries (the singular values of the pair (A, B) are the diagonal entries of S). E is a real diagonal matrix with real positive diagonal entries.

The routine is the same as SGGSVD, except that it uses an unblocked implementation.

Arguments:

JOBU    (input) CHARACTER*1
        = 'U': The unitary matrix U is computed.
        = 'N': Do not compute the unitary matrix U.

JOBV    (input) CHARACTER*1
        = 'V': The unitary matrix V is computed.
        = 'N': Do not compute the unitary matrix V.

JOBQ    (input) CHARACTER*1
        = 'Q': The unitary matrix Q is computed.
        = 'N': Do not compute the unitary matrix Q.

M       (input) INTEGER
        The number of rows of A.  M >= 0.

N       (input) INTEGER
        The number of columns of A and the number of columns of B. N >= 0.

P       (input) INTEGER
        The number of rows of B. P >= 0.

A       (input/output) REAL array, dimension (LDA, N)
        On entry, the M-by-N matrix A.
        On exit, A is overwritten by the results of the decomposition.

LDA     (input) INTEGER
        The leading dimension of the array A. LDA >= max(1, M).

B       (input/output) REAL array, dimension (LDB, N)
        On entry, the P-by-N matrix B.
        On exit, B is overwritten by the results of the decomposition.

LDB     (input) INTEGER
        The leading dimension of the array B. LDB >= max(1, P).

S       (output) REAL array, dimension (N)
        On exit, the singular values of the pair (A, B), sorted in
        descending order. The diagonal entries of the matrix S in the
        decomposition are given by S(I) for I = 1..N.

E       (output) REAL array, dimension (N)
        On exit, the remaining diagonal entries of the matrix E in the
        decomposition, sorted in descending order. The diagonal entries
        of the matrix E in the decomposition are given by E(I) for
        I = 1..N.

U       (output) REAL array, dimension (LDU, N)
        If JOBU = 'U', U is an M-by-M unitary matrix that satisfies
        the condition A = U*S*Q.
        If JOBU = 'N', U is not used.

LDU     (input) INTEGER
        The leading dimension of the array U. LDU >= max(1, M).

V       (output) REAL array, dimension (LDV, P)
        If JOBV = 'V', V is a P-by-P unitary matrix that satisfies
        the condition B = V*E*Q.
        If JOBV = 'N', V is not used.

LDV     (input) INTEGER
        The leading dimension of the array V. LDV >= max(1, P).

Q       (output) REAL array, dimension (LDQ, N)
        If JOBQ = 'Q', Q is an N-by-N unitary matrix that satisfies
        A = U*S*Q and B = V*E*Q.
        If JOBQ = 'N', Q is not used.

LDQ     (input) INTEGER
        The leading dimension of the array Q. LDQ >= max(1, N).

WORK    (workspace) REAL array, dimension (LWORK)
        On exit, if INFO = 0, WORK(1) contains the optimal LWORK.

LWORK   (input) INTEGER
        The dimension of array WORK. LWORK >= 1.

        If LWORK = -1, then a workspace query is assumed; the routine
        only calculates the optimal size of the WORK array, returns
        this value as the first entry of the WORK array, and no error
        message related to LWORK is issued by XERBLA.

IWORK   (output) INTEGER array, dimension (N)
        On exit, IWORK stores the sorting information. More
        precisely, the following loop will sort ALPHA
           for I = K+1, min(M,K+L)
               swap ALPHA(I) and ALPHA(IWORK(I))
           endfor
        such that ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).

INFO    (output) INTEGER
        = 0:  successful exit.
        < 0:  if INFO = -i, the i-th argument had an illegal value.
        > 0:  if INFO = 1, the Jacobi-type procedure failed to
              converge.  For further details, see subroutine STGSJA.

Internal Parameters:

 TOLA    REAL
 TOLB    REAL
         TOLA and TOLB are the thresholds to determine the effective
         rank of (A**T,B**T)**T. Generally, they are set to
                  TOLA = MAX(M,N)*norm(A)*MACHEPS,
                  TOLB = MAX(P,N)*norm(B)*MACHEPS.
         The size of TOLA and TOLB may affect the size of backward
         errors of the decomposition.
