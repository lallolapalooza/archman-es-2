NOMBRE

sg_stpg - enviar comando SCSI SET TARGET PORT GROUPS

SINOPSIS

sg_stpg [--activo] [--ayuda] [--hex] [--desconectado] [--optimizado] [--raw] [--en espera] [--estado=E,E...] [--tp=P,P...] [--no-disponible] [--verboso] [--version] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI SET TARGET PORT GROUPS a DISPOSITIVO. Esta utilidad tiene diferentes modos dependiendo de si se proporciona la opción --tp=.

Si se proporciona --tp=, entonces el bloque de parámetros del comando SET TARGET PORT GROUPS se construye con un descriptor para cada elemento de la lista proporcionada a --tp=. El valor del estado de acceso asimétrico correspondiente se toma de la lista --estado= o, si no se proporciona, de una de las opciones de estado explícitas (por ejemplo, --no-disponible), utilizada repetidamente si es necesario.

Si no se proporciona --tp=, entonces se envía una secuencia de comandos SCSI al DISPOSITIVO, que precede al comando SET TARGET PORT GROUPS. Primero se envía un INQUIRY para obtener la página VPD de identificación del dispositivo y encontrar el grupo de puertos de destino (primario) asociado con DISPOSITIVO. Luego se emite un comando REPORT TARGET PORT GROUPS para encontrar el estado actual y si se admite la transición al estado solicitado. Si es así, se envía el comando SET TARGET PORT GROUPS.

El acceso a los grupos de puertos de destino se describe en SPC-4 en www.t10.org en las secciones 5.8 y 5.16 (en la revisión 36e con fecha 2012/8/24). El comando SET TARGET PORT GROUPS también se describe en la sección 6.45 de ese documento.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas. Las opciones están organizadas en orden alfabético según el nombre de la opción larga.

-a, --activo
establecer estado activo/no optimizado.
-h, --ayuda
mostrar el mensaje de uso y luego salir.
-H, --hex
mostrar la respuesta al comando REPORT TARGET PORT GROUPS en hexadecimal y luego salir.
-O, -l, --desconectado
establecer estado desconectado. Este es el estado apropiado para establecer un puerto de destino antes de eliminar el dispositivo. Tenga en cuenta que se debe proporcionar un identificador de puerto de destino relativo con este estado (en lugar de un identificador de grupo de puertos de destino que todos los demás estados toman).
-o, --optimizado
establecer estado activo/optimizado. Si no se proporcionan otras opciones de estado o la opción --tp=, el estado activo/optimizado es el estado predeterminado.
-r, --raw
mostrar la respuesta al comando REPORT TARGET PORT GROUPS en binario a stdout y luego salir.
-s, --en espera
establecer estado en espera. El grupo de puertos aceptará los comandos listados para el estado "no disponible" más los comandos LOG SELECT/SENSE, MODE SELECT/SENSE, RECEIVE DIAGNOSTIC RESULTS, SEND DIAGNOSTIC, PERSISTENT RESERVE IN/OUT.
-S, --estado=E,E...
especifica una lista separada por comas (un elemento o más) de estados. Se puede dar un número o una abreviatura. Un número se asume como un número decimal a menos que vaya precedido por "0x" o tenga una "h" al final, en cuyo caso se asume un valor hexadecimal. Solo se aceptan los valores 0, 1, 2, 3 o 14. Las abreviaturas aceptadas son "an", "ao", "o", "s" o "u"; que representan activo/no optimizado(1), activo/optimizado(0), desconectado(14), en espera(2) o no disponible(3) respectivamente.
-t, --tp=P,P...
especifica una lista separada por comas (un elemento o más). Cada elemento es un identificador de grupo de puertos de destino (cuando el estado correspondiente es distinto de "desconectado") o un identificador de puerto de destino relativo (cuando el estado correspondiente es "desconectado"). Cada elemento se asume como un número decimal a menos que vaya precedido por "0x" o tenga una "h" al final, en cuyo caso se asume un valor hexadecimal.
-u, --no-disponible
establecer estado no disponible. El grupo de puertos solo deberá aceptar los comandos INQUIRY, REPORT LUNS, REPORT/SET TARGET PORT GROUPS, REQUEST SENSE y READ/WRITE BUFFER.
-v, --verboso
aumentar el nivel de verbosidad (es decir, salida de depuración).
-V, --version
imprimir la cadena de versión y luego salir.

NOTAS

El comando SET TARGET PORT GROUPS debe ser compatible siempre que el valor TPGS en una respuesta INQUIRY estándar sea 2 o 3. [Ver con la utilidad sg_inq.]

Observe que el estado desconectado se denomina "estado de acceso asimétrico de puerto de destino secundario" y toma un identificador de puerto de destino relativo (es decir, actúa sobre un solo puerto de destino). Todos los demás estados se denominan "estados de acceso asimétrico de puerto de destino primario" y cada uno toma un identificador de grupo de puertos de destino (es decir, actúa sobre uno o más puertos de destino).

Cuando se proporciona --tp=, se debe proporcionar el mismo número de elementos a la opción --estado=. Si se dan más de un elemento a la lista --tp= y no se proporciona un número igual de elementos a la opción --estado=, entonces si solo se especifica un estado, este se repetirá.

ESTADO DE SALIDA

El estado de salida de sg_stpg es 0 cuando tiene éxito. De lo contrario, consulte la página del manual sg3_utils(8).

NOMBRE

sg_stpg - Imprime información sobre un dispositivo SCSI

SINOPSIS

sg_stpg [OPCIONES] dispositivo

DESCRIPCIÓN

sg_stpg imprime información sobre un dispositivo SCSI, incluida su información de páginas de parámetros.

OPCIONES

-h, --help
Imprime el mensaje de ayuda y sale.
-v, --verbose
Aumenta el nivel de verbosidad.

EJEMPLOS

sg_stpg /dev/sg0

Esto imprimirá información sobre el dispositivo en /dev/sg0.
