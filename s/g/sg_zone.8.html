NOMBRE

sg_zone - enviar un comando de modificación de zona SCSI

SINOPSIS

sg_zone [--all] [--close] [--count=ZC] [--element=EID] [--finish] [--help] [--open] [--remove] [--sequentialize] [--timeout=SE] [--verbose] [--version] [--zone=ID] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI OPEN ZONE, CLOSE ZONE, FINISH ZONE, REMOVE ELEMENT AND MODIFY ZONES o SEQUENTIALIZE ZONE al DISPOSITIVO. Todos excepto los dos últimos se encuentran en el estándar ZBC (INCITS 536-2016). El comando REMOVE ELEMENT AND MODIFY ZONES se añadió en zbc2r07 mientras que el comando SEQUENTIALIZE ZONE se añadió en zbc2r01b.

Se puede elegir una y solo una de las opciones --open, --close, --finish, --remove y --sequentialize.

Los comandos REPORT ZONES, REPORT REALMS y REPORT ZONE DOMAINS se pueden acceder a través de la utilidad sg_rep_zones. Los comandos ZONE ACTIVATE y ZONE QUERY se pueden acceder a través de la utilidad sg_z_act_query. El comando RESET WRITE POINTER se puede acceder a través de la utilidad sg_reset_wp.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-a, --all
establece el campo ALL en el cdb.
-c, --close
hace que se envíe el comando CLOSE ZONE al DISPOSITIVO.
-C, --count=ZC
ZC se coloca en el campo Zone Count (Contador de Zonas) en el cdb de los cuatro comandos soportados por esta utilidad. ZC debe ser un valor de 0 a 65535 (0xffff) inclusive.
-e, --element=EID
donde EID es un identificador de elemento que es un entero sin signo de 32 bits comenzando en uno. Este campo se usa por el comando REMOVE ELEMENT AND MODIFY ZONES y su valor por defecto es cero (lo cual es inválido). Por lo tanto, el usuario necesita proporcionar un identificador de elemento válido cuando se usa --remove.
-f, --finish
hace que se envíe el comando FINISH ZONE al DISPOSITIVO.
-h, --help
muestra el mensaje de uso y luego sale.
-o, --open
hace que se envíe el comando OPEN ZONE al DISPOSITIVO.
-r, --remove
hace que se envíe el comando REMOVE ELEMENT AND MODIFY ZONES al DISPOSITIVO. En la práctica, también se necesita proporcionar --element=EID.
-S, --sequentialize
hace que se envíe el comando SEQUENTIALIZE ZONE al DISPOSITIVO.
-t, --timeout=SE
donde SE es el tiempo de espera del comando en segundos. El valor por defecto es 60 segundos y si se da 0, se mapea a 60. Una forma alternativa es --tmo=SE.
-v, --verbose
incrementa el nivel de verbosidad (es decir, salida de depuración).
-V, --version
imprime la cadena de versión y luego sale.
-z, --zone=ID
donde ID se coloca en el campo ZONE ID del cdb. Un id de zona es una dirección de bloque lógico (LBA) de inicio de zona. El valor por defecto es 0. Se asume que ID está en decimal a menos que esté prefijado con '0x' o tenga una 'h' al final, que indican hexadecimal.

NOTAS

Después de que un comando REMOVE ELEMENT AND MODIFY ZONES ha completado, se dice que el elemento en cuestión está des pobla do y las zonas afectadas se colocan en la condición de zona 'offline'.

SBC-4 tiene un comando similar a REMOVE ELEMENT AND MODIFY ZONES llamado REMOVE ELEMENT AND TRUNCATE. La diferencia es que este último "cambia la asociación entre LBAs y bloques físicos" y el primero no cambia esa asociación. En ambos casos, los elementos des pobla dos que tienen el bit 'Restoration Allowed' (RALWD) establecido (ver sg_get_elem_status) pueden ser restaurados con el comando RESTORE ELEMENTS AND REBUILD (ver sg_rem_rest_elem).

ESTADO DE SALIDA

El estado de salida de sg_zone es 0 cuando tiene éxito. De lo contrario, consulte la página del manual sg3_utils(8).
