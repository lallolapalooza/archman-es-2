SGGSVD calcula la descomposición en valores singulares (SVD) para OTRAS matrices

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina SGGSVD3.
!>
!> SGGSVD calcula la descomposición en valores singulares generalizada (GSVD)
!> de una matriz real M por N, A, y una matriz real P por N, B:
!>
!>       U**T*A*Q = D1*( 0 R ),    V**T*B*Q = D2*( 0 R )
!>
!> donde U, V y Q son matrices ortogonales.
!> Sea K+L = el rango numérico efectivo de la matriz (A**T,B**T)**T,
!> entonces R es una matriz triangular superior no singular de K+L por K+L, D1 y
!> D2 son matrices de M por (K+L) y P por (K+L) respectivamente y de las
!> siguientes estructuras:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) en la salida.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N), y R33 se almacena
!>   ( 0  R22 R23 )
!>   en B(M-K+1:L,N+M-K-L+1:N) en la salida.
!>
!> La rutina calcula C, S, R y, opcionalmente, las matrices de
!> transformación ortogonal U, V y Q.
!>
!> En particular, si B es una matriz B no singular de N por N, entonces la GSVD de
!> A y B da implícitamente la SVD de A*inv(B):
!>                      A*inv(B) = U*(D1*inv(D2))*V**T.
!> Si ( A**T,B**T)**T  tiene columnas ortonormales, entonces la GSVD de A y B es
!> también igual a la descomposición CS de A y B. Además, la GSVD
!> se puede utilizar para derivar la solución del problema de valores
!> propios:
!>                      A**T*A x = lambda* B**T*B x.
!> En alguna literatura, la GSVD de A y B se presenta en la forma
!>                  U**T*A*X = ( 0 D1 ),   V**T*B*X = ( 0 D2 )
!> donde U y V son ortogonales y X es no singular, D1 y D2 son
!> ``diagonales''. La forma GSVD anterior se puede convertir a la forma
!> posterior tomando la matriz no singular X como
!>
!>                      X = Q*( I   0    )
!>                            ( 0 inv(R) ).
!>

Function/Subroutine Documentation

This routine computes the singular value decomposition (SVD) of a general rectangular matrix A and a general rectangular matrix B, in the form

A = U*S1*X**T

B = V*S2*X**T

where

  S1 is a(M,N)

with

  S1 = ( diag(ALPHA(1), ..., ALPHA(K))      0     )
       (          0                    0     )

and

  S2 is p(P,N)

with

  S2 = ( diag(BETA(1), ..., BETA(K))        0     )


K is the number of computed singular values (non-zero values of
  ALPHA and BETA).


X is a rectangular matrix of size (N,N) which is upper
  triangular.


U is an (M,M) orthogonal matrix.


V is a (P,P) orthogonal matrix.


ALPHA and BETA are computed diagonal entries of S1 and S2. The
  singular values of A and B are approximately the values of ALPHA(I)/BETA(I)
  (or the values of ALPHA(I) if BETA(I) is close to zero).


The routine SGGsvd is an interface to the subroutine SGGsvd3.


Arguments


    
  
  • A
    • 



          A is REAL array, dimension (LDA, N)
          The M-by-N matrix A.



    
  
  • LDA
    • 



          LDA is INTEGER
          The leading dimension of the array A. LDA is at least max(1,M).



    
  
  • B
    • 



          B is REAL array, dimension (LDB, N)
          The P-by-N matrix B.



    
  
  • LDB
    • 



          LDB is INTEGER
          The leading dimension of the array B. LDB is at least max(1,P).



    
  
  • ALPHA
    • 



          ALPHA is REAL array, dimension (N)
          On exit, ALPHA(i) contains the i-th diagonal element of S1.
          The singular values of A and B are approximately the values
          of ALPHA(i)/BETA(i) (or the values of ALPHA(i) if BETA(i) is
          close to zero).



    
  
  • BETA
    • 



          BETA is REAL array, dimension (N)
          On exit, BETA(i) contains the i-th diagonal element of S2.
          The singular values of A and B are approximately the values
          of ALPHA(i)/BETA(i) (or the values of ALPHA(i) if BETA(i) is
          close to zero).



    
  
  • U
    • 



          U is REAL array, dimension (LDU, M)
          On exit, U is an M-by-M orthogonal matrix which contains the
          left singular vectors.



    
  
  • LDU
    • 



          LDU is INTEGER
          The leading dimension of the array U. LDU is at least max(1,M).



    
  
  • V
    • 



          V is REAL array, dimension (LDV, P)
          On exit, V is a P-by-P orthogonal matrix which contains the
          right singular vectors.



    
  
  • LDV
    • 



          LDV is INTEGER
          The leading dimension of the array V. LDV is at least max(1,P).



    
  
  • X
    • 



          X is REAL array, dimension (LDX, N)
          On exit, X is an N-by-N upper triangular matrix.



    
  
  • LDX
    • 



          LDX is INTEGER
          The leading dimension of the array X. LDX is at least max(1,N).



    
  
  • WORK
    • 



          WORK is REAL array, dimension (LWORK)
          On exit, WORK(1) contains the optimal value of LWORK.



    
  
  • LWORK
    • 



          LWORK is INTEGER
          The dimension of the array WORK. LWORK must be at least
          max(1, 3*N + 2*MAX(M,P) + 2*MIN(M,P)).
          For optimum performance, LWORK is at least
          MAX(3*N + 2*MAX(M,P) + 2*MIN(M,P), N + 2*MAX(M,P) + 2*MIN(M,P) + 1).



    
  
  • IWORK
    • 



          IWORK is INTEGER array, dimension (LIWORK)
          On exit, IWORK stores the sorting information. More
          precisely, the following loop will sort ALPHA
             for I = K+1, min(M,K+L)
                 swap ALPHA(I) and ALPHA(IWORK(I))
             endfor
          such that ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).



    
  
  • INFO
    • 



          INFO is INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value.
          > 0:  if INFO = 1, the Jacobi-type procedure failed to
                converge.  For further details, see subroutine STGSJA.




Internal Parameters:




  TOLA    REAL
  TOLB    REAL
          TOLA and TOLB are the thresholds to determine the effective
          rank of (A**T,B**T)**T. Generally, they are set to
                   TOLA = MAX(M,N)*norm(A)*MACHEPS,
                   TOLB = MAX(P,N)*norm(B)*MACHEPS.
          The size of TOLA and TOLB may affect the size of backward
          errors of the decomposition.
