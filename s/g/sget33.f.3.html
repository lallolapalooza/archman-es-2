subrutina sget33 (real rmax, integer lmax, integer ninfo, integer knt)

SGET33

Propósito:

!>
!> SGET33 prueba SLANV2, una rutina para poner bloques de 2x2 en
!> forma estándar. En otras palabras, calcula una rotación de dos por dos
!> [[C,S]
!> [-S,C]] donde en
!>
!>    [ C S ][T(1,1) T(1,2)][ C -S ] = [ T11 T12 ]
!>    [-S C ][T(2,1) T(2,2)][ S  C ]   [ T21 T22 ]
!>
!> ya sea
!>    1) T21=0 (valores propios reales), o
!>    2) T11=T22 y T21*T12<0 (valores propios complejos conjugados).
!> También verificamos que el residuo sea pequeño.
!>

Parámetros

RMAX 
!>          RMAX es REAL
!>          Valor de la razón de prueba más grande.
!>

LMAX

!>          LMAX es INTEGER
!>          Número de ejemplo donde se alcanzó la razón de prueba más grande.
!>

NINFO

!>          NINFO es INTEGER
!>          Número de ejemplos devueltos con INFO .NE. 0.
!>

KNT

!>          KNT es INTEGER
!>          Número total de ejemplos probados.
!>
