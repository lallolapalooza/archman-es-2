subroutine sgelsy (integer m, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, integer, dimension( * ) jpvt, real rcond, integer rank, real, dimension( * ) work, integer lwork, integer info)

SGELSY resuelve sistemas sobredeterminados o subdeterminados para matrices GE

Propósito:

!>
!> SGELSY calcula la solución de norma mínima para un problema de mínimos
!> cuadrados lineales reales:
!>     minimizar || A * X - B ||
!> utilizando una factorización ortogonal completa de A. A es una matriz M por N
!> que puede ser de rango deficiente.
!>
!> Se pueden manejar varios vectores de mano derecha b y vectores solución x
!> en una sola llamada; se almacenan como las columnas de la matriz B de mano
!> derecha M por NRHS y la matriz solución X de N por NRHS.
!>
!> La rutina primero calcula una factorización QR con pivoteo de columnas:
!>     A * P = Q * [ R11 R12 ]
!>                 [  0  R22 ]
!> con R11 definida como la submatriz principal más grande cuyo número de
!> condición estimado es menor que 1/RCOND. El orden de R11, RANK,
!> es el rango efectivo de A.
!>
!> Luego, R22 se considera despreciable, y R12 se aniquila
!> por transformaciones ortogonales desde la derecha, llegando a la
!> factorización ortogonal completa:
!>    A * P = Q * [ T11 0 ] * Z
!>                [  0  0 ]
!> La solución de norma mínima es entonces
!>    X = P * Z**T [ inv(T11)*Q1**T*B ]
!>                 [        0         ]
!> donde Q1 consiste en las primeras RANK columnas de Q.
!>
!> Esta rutina es básicamente idéntica a la xGELSX original excepto por
!> tres diferencias:
!>   o La llamada a la subrutina xGEQPF ha sido sustituida por la
!>     llamada a la subrutina xGEQP3. Esta subrutina es una versión Blas-3
!>     de la factorización QR con pivoteo de columnas.
!>   o La matriz B (la mano derecha) se actualiza con Blas-3.
!>   o La permutación de la matriz B (la mano derecha) es más rápida y
!>     más simple.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de manos derechas, es decir, el número de
!>          columnas de las matrices B y X. NRHS >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, A ha sido sobrescrita con detalles de su
!>          factorización ortogonal completa.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es array REAL, dimension (LDB,NRHS)
!>          En la entrada, la matriz B de mano derecha M por NRHS.
!>          En la salida, la matriz solución X de N por NRHS.
!>          Si M = 0 o N = 0, B no se referencia.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,M,N).
!>

JPVT

!>          JPVT es array INTEGER, dimension (N)
!>          En la entrada, si JPVT(i) .ne. 0, la i-ésima columna de A se permuta
!>          al frente de AP, de lo contrario la columna i es una columna libre.
!>          En la salida, si JPVT(i) = k, entonces la i-ésima columna de AP
!>          era la k-ésima columna de A.
!>

RCOND

!>          RCOND es REAL
!>          RCOND se utiliza para determinar el rango efectivo de A, que
!>          se define como el orden de la submatriz triangular
!>          principal más grande R11 en la factorización QR con pivoteo de A,
!>          cuyo número de condición estimado es < 1/RCOND.
!>

RANK

!>          RANK es INTEGER
!>          El rango efectivo de A, es decir, el orden de la submatriz
!>          R11. Esto es lo mismo que el orden de la submatriz T11
!>          en la factorización ortogonal completa de A.
!>          Si NRHS = 0, RANK = 0 en la salida.
!>

WORK

!>          WORK es array REAL, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          La estrategia sin bloques requiere que:
!>             LWORK >= MAX( MN+3*N+1, 2*MN+NRHS ),
!>          donde MN = min( M, N ).
!>          El algoritmo de bloques requiere que:
!>             LWORK >= MAX( MN+2*N+NB*(N+1), 2*MN+NB*NRHS ),
!>          donde NB es un límite superior del tamaño del bloque devuelto
!>          por ILAENV para las rutinas SGEQP3, STZRZF, STZRQF, SORMQR,
!>          y SORMRZ.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
