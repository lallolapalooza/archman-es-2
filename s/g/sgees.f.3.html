Documentación de la función/subrutina

subroutine sgees (character jobvs, character sort, external select, integer n, real, dimension( lda, * ) a, integer lda, integer sdim, real, dimension( * ) wr, real, dimension( * ) wi, real, dimension( ldvs, * ) vs, integer ldvs, real, dimension( * ) work, integer lwork, logical, dimension( * ) bwork, integer info)

SGEES calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> SGEES calcula para una matriz real no simétrica A de tamaño N*N, los
!> valores propios, la forma de Schur real T y, opcionalmente, la matriz de
!> vectores de Schur Z. Esto da la factorización de Schur A = Z*T*(Z**T).
!>
!> Opcionalmente, también ordena los valores propios en la diagonal de la
!> forma de Schur real para que los valores propios seleccionados estén en la
!> parte superior izquierda. Las columnas principales de Z forman entonces una
!> base ortonormal para el subespacio invariante correspondiente a los
!> valores propios seleccionados.
!>
!> Una matriz está en forma de Schur real si es superior cuasi-triangular con
!> bloques de 1x1 y 2x2. Los bloques de 2x2 se estandarizarán en la forma
!>         [  a  b  ]
!>         [  c  a  ]
!>
!> donde b*c < 0. Los valores propios de tal bloque son a +- sqrt(bc).
!>

Parámetros

JOBVS 
!>          JOBVS es CHARACTER*1
!>          = 'N': Los vectores de Schur no se calculan;
!>          = 'V': Se calculan los vectores de Schur.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si los valores propios deben ordenarse o no en la
!>          diagonal de la forma de Schur.
!>          = 'N': Los valores propios no se ordenan;
!>          = 'S': Los valores propios se ordenan (ver SELECT).
!>

SELECT

!>          SELECT es una FUNCIÓN LOGICAL de dos argumentos REALES
!>          SELECT debe declararse EXTERNAL en la subrutina llamante.
!>          Si SORT = 'S', SELECT se usa para seleccionar valores propios a
!>          ordenar en la parte superior izquierda de la forma de Schur.
!>          Si SORT = 'N', SELECT no se referencia.
!>          Un valor propio WR(j)+sqrt(-1)*WI(j) se selecciona si
!>          SELECT(WR(j),WI(j)) es verdadero; es decir, si uno de un par de
!>          valores propios conjugados complejos se selecciona, entonces ambos
!>          valores propios complejos se seleccionan.
!>          Tenga en cuenta que un valor propio complejo seleccionado puede no
!>          cumplir SELECT(WR(j),WI(j)) = .TRUE. después de ordenarlo, ya que
!>          el ordenamiento puede cambiar el valor de los valores propios
!>          complejos (especialmente si el valor propio está mal condicionado);
!>          en este caso INFO se establece en N+2 (ver INFO a continuación).
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz A de tamaño N*N.
!>          En la salida, A ha sido sobrescrita por su forma de Schur real T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de
!>                         ordenar) para los cuales SELECT es verdadero. (Los
!>                         pares conjugados complejos para los cuales SELECT es
!>                         verdadero para cualquiera de los valores propios se
!>                         cuentan como 2.)
!>

WR

!>          WR es un array REAL, de dimensión (N)
!>

WI

!>          WI es un array REAL, de dimensión (N)
!>          WR y WI contienen las partes real e imaginaria,
!>          respectivamente, de los valores propios calculados en el mismo orden
!>          en que aparecen en la diagonal de la forma de Schur de salida T.
!>          Los pares conjugados complejos de valores propios aparecerán
!>          consecutivamente con el valor propio que tiene la parte imaginaria
!>          positiva primero.
!>

VS

!>          VS es un array REAL, de dimensión (LDVS,N)
!>          Si JOBVS = 'V', VS contiene la matriz ortogonal Z de vectores de Schur.
!>          Si JOBVS = 'N', VS no se referencia.
!>

LDVS

!>          LDVS es INTEGER
!>          La dimensión principal del array VS. LDVS >= 1; si
!>          JOBVS = 'V', LDVS >= N.
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) contiene el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,3*N).
!>          Para un buen rendimiento, LWORK generalmente debe ser mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK y XERBLA
!>          no emite ningún mensaje de error relacionado con LWORK.
!>

BWORK

!>          BWORK es un array LOGICAL, de dimensión (N)
!>          No se referencia si SORT = 'N'.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: si INFO = i, y i es
!>             <= N: el algoritmo QR no pudo calcular todos los
!>                   valores propios; los elementos 1:ILO-1 y i+1:N de WR y WI
!>                   contienen aquellos valores propios que han convergido; si
!>                   JOBVS = 'V', VS contiene la matriz que reduce A
!>                   a su forma de Schur parcialmente convergida.
!>             = N+1: los valores propios no pudieron ser reordenados porque
!>                   algunos valores propios estaban demasiado cerca para
!>                   separarse (el problema está muy mal condicionado);
!>             = N+2: después de reordenar, el redondeo cambió los valores de
!>                   algunos valores propios complejos de modo que los valores
!>                   propios principales en la forma de Schur ya no cumplen
!>                   SELECT=.TRUE. Esto también podría ser causado por un
!>                   subdesbordamiento debido al escalado.
!>
