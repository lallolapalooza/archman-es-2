Documentación de la función/subrutina

subroutine sgelq (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) t, integer tsize, real, dimension( * ) work, integer lwork, integer info)

SGELQ

Propósito:

!>
!> SGELQ calcula una factorización LQ de una matriz real M por N, A:
!>
!>    A = ( L 0 ) *  Q
!>
!> donde:
!>
!>    Q es una matriz ortogonal N por N;
!>    L es una matriz triangular inferior M por M;
!>    0 es una matriz cero M por (N-M), si M < N.
!>
!>

Parámetros

M 
!>          M es un ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es un ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz M por N, A.
!>          En la salida, los elementos en y por debajo de la diagonal del array
!>          contienen la matriz trapecial inferior M por min(M,N), L
!>          (L es triangular inferior si M <= N);
!>          los elementos por encima de la diagonal se utilizan para almacenar parte de la
!>          estructura de datos para representar Q.
!>

LDA

!>          LDA es un ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

T

!>          T es un array REAL, de dimensión (MAX(5,TSIZE))
!>          En la salida, si INFO = 0, T(1) devuelve el TSIZE óptimo (o mínimo
!>          o óptimo, si se asume una consulta). Ver TSIZE para detalles.
!>          El resto de T contiene parte de la estructura de datos utilizada para representar Q.
!>          Si se desea aplicar o construir Q, entonces se necesita mantener T
!>          (además de A) y pasarlo a subrutinas posteriores.
!>

TSIZE

!>          TSIZE es un ENTERO
!>          Si TSIZE >= 5, la dimensión del array T.
!>          Si TSIZE = -1 o -2, se asume una consulta de espacio de trabajo. La rutina
!>          solo calcula los tamaños de los arrays T y WORK, devuelve estos
!>          valores como las primeras entradas de los arrays T y WORK, y XERBLA
!>          no emite ningún mensaje de error relacionado con T o WORK.
!>          Si TSIZE = -1, la rutina calcula el tamaño óptimo de T para
!>          un rendimiento óptimo y devuelve este valor en T(1).
!>          Si TSIZE = -2, la rutina calcula el tamaño mínimo de T y
!>          devuelve este valor en T(1).
!>

WORK

!>          (espacio de trabajo) array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) contiene el LWORK óptimo (o mínimo
!>          o óptimo, si se asumió una consulta).
!>          Ver LWORK para detalles.
!>

LWORK

!>          LWORK es un ENTERO
!>          La dimensión del array WORK. LWORK >= 1.
!>          Si LWORK = -1 o -2, se asume una consulta de espacio de trabajo. La rutina
!>          solo calcula los tamaños de los arrays T y WORK, devuelve estos
!>          valores como las primeras entradas de los arrays T y WORK, y XERBLA
!>          no emite ningún mensaje de error relacionado con T o WORK.
!>          Si LWORK = -1, la rutina calcula el tamaño óptimo de WORK para
!>          un rendimiento óptimo y devuelve este valor en WORK(1).
!>          Si LWORK = -2, la rutina calcula el tamaño mínimo de WORK y
!>          devuelve este valor en WORK(1).
!>

INFO

!>          INFO es un ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales

!>
!> El objetivo de la interfaz es dar máxima libertad a los desarrolladores para
!> crear cualquier algoritmo de factorización LQ que deseen. La L triangular
!!> (trapecial) debe almacenarse en la parte inferior de A. La parte inferior de A
!> y el array T pueden usarse para almacenar cualquier información relevante para aplicar o
!> construir el factor Q. El array WORK puede desecharse de forma segura después de la salida.
!>
!> Precaución: No se debe esperar que los tamaños de T y WORK sean los mismos de una
!> implementación de LAPACK a otra, o incluso de una ejecución a otra.
!> Se necesita una consulta de espacio de trabajo (para T y WORK) en cada ejecución. Sin embargo,
!> para una ejecución dada, el tamaño de T y WORK son fijos y no cambiarán
!> de una consulta a otra.
!>
!>

Detalles adicionales particulares para esta implementación de LAPACK:

!>
!> Estos detalles son particulares para esta implementación de LAPACK. Los usuarios no deben
!> darlos por sentados. Estos detalles pueden cambiar en el futuro y no son probablemente
!> ciertos para otra implementación de LAPACK. Estos detalles son relevantes si se desea
!> intentar entender el código. No forman parte de la interfaz.
!>
!> En esta versión,
!>
!>          T(2): tamaño de bloque de fila (MB)
!>          T(3): tamaño de bloque de columna (NB)
!>          T(6:TSIZE): estructura de datos necesaria para Q, calculada por
!>                           SLASWLQ o SGELQT
!>
!>  Dependiendo de las dimensiones de la matriz M y N, y de los tamaños de bloque
!>  de fila y columna MB y NB devueltos por ILAENV, SGELQ utilizará
!>  SLASWLQ (si la matriz es corta y ancha) o SGELQT para calcular
!>  la factorización LQ.
!>
