SGERFSX

Propósito:

!>
!>    SGERFSX mejora la solución calculada de un sistema de ecuaciones
!>    lineales y proporciona cotas de error y estimaciones de error
!>    hacia atrás para la solución. Además de la cota de error normwise,
!>    el código proporciona una cota de error componente a componente
!>    máxima si es posible. Ver los comentarios para ERR_BNDS_NORM y
!>    ERR_BNDS_COMP para detalles de las cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta rutina, como se describe por
!>    los argumentos EQUED, R y C a continuación. En este caso, la
!>    solución y las cotas de error devueltas son para el sistema
!>    original no equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS.
!>     Estas configuraciones determinan cómo se realiza el refinamiento,
!>     pero a menudo los valores predeterminados son aceptables. Si los
!>     valores predeterminados son aceptables, los usuarios pueden pasar
!>     NPARAMS = 0, lo que evita que el código fuente acceda al argumento
!>     PARAMS.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transpuesta)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y las cotas de error correctamente.
!>       = 'N':  Sin equilibrado
!>       = 'R':  Equilibrado de filas, es decir, A ha sido premultiplicada
!>               por diag(R).
!>       = 'C':  Equilibrado de columnas, es decir, A ha sido postmultiplicada
!>               por diag(C).
!>       = 'B':  Equilibrado tanto de filas como de columnas, es decir, A ha sido
!>               reemplazada por diag(R) * A * diag(C).
!>               El lado derecho B se ha modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>     La matriz original A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array REAL, dimension (LDAF,N)
!>     Los factores L y U de la factorización A = P*L*U
!>     calculados por SGETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>     Los índices de pivote de SGETRF; para 1<=i<=N, la fila i de la
!>     matriz se intercambió con la fila IPIV(i).
!>

R

!>          R es array REAL, dimension (N)
!>     Los factores de escala de fila para A.  Si EQUED = 'R' o 'B', A se
!>     multiplica a la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede.
!>     Si se accede a R, cada elemento de R debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. La
!>     multiplicación por potencias de la base no causa errores de
!>     redondeo a menos que el resultado sea subdesbordamiento o
!>     desbordamiento. Los errores de redondeo durante el escalado
!>     llevan a refinar con una matriz que no es equivalente a la matriz
!>     de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

C

!>          C es array REAL, dimension (N)
!>     Los factores de escala de columna para A.  Si EQUED = 'C' o 'B', A se
!>     multiplica a la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede.
!>     Si se accede a C, cada elemento de C debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. La
!>     multiplicación por potencias de la base no causa errores de
!>     redondeo a menos que el resultado sea subdesbordamiento o
!>     desbordamiento. Los errores de redondeo durante el escalado
!>     llevan a refinar con una matriz que no es equivalente a la matriz
!>     de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es array REAL, dimension (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array REAL, dimension (LDX,NRHS)
!>     En la entrada, la matriz solución X, tal como la calculó SGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Condición inversa escalada. Esta es una estimación de la
!>     condición inversa de Skeel de la matriz A después del
!>     equilibrado (si se realizó). Si esto es menor que la precisión
!>     de la máquina (en particular, si es cero), la matriz es singular
!>     a precisión de trabajo. Tenga en cuenta que el error aún puede ser
!>     pequeño incluso si este número es muy pequeño y la matriz parece
!>     mal condicionada.
!>

BERR

!>          BERR es array REAL, dimension (NRHS)
!>     Error relativo componente a componente hacia atrás. Este es el
!>     error relativo componente a componente de cada vector solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B
!>     que haga de X(j) una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de cotas de error a devolver para cada lado derecho
!>     y cada tipo (normwise o componente a componente). Ver ERR_BNDS_NORM y
!>     ERR_BNDS_COMP a continuación.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es array REAL, dimension (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     La matriz se indexa por el tipo de er

# Documentation for sgerfsx # Function/Subroutine Documentation sgerfsx: description: |

SGERFSX computes the error bounds for the solution of a real system of linear equations $$ AX = B $$ where $$ A $$ is a general matrix and $$ X $$ is the solution obtained from SGERFS.

Iterative refinement is used to possibly improve the accuracy of $$ X $$ and to allow for a more accurate estimate of the error in $$ X $$.

parameters: # Input parameters - name: 'UPLO' type: 'CHARACTER*1' description: | Specifies whether the matrix A is upper or lower triangular.
  • 'U': Upper triangular
  • 'L': Lower triangular
- name: 'TRANS' type: 'CHARACTER*1' description: | Specifies the form of the system of equations.
  • 'N': $$ AX = B $$ (No transpose)
  • 'T': $$ A^T X = B $$ (Transpose)
  • 'C': $$ A^H X = B $$ (Conjugate transpose)
- name: 'EQUED' type: 'CHARACTER*1' description: | Specifies the form of equilibration computed by SGEEQU or SGEEQU.
  • 'N': No equilibration
  • 'R': Row equilibration
  • 'C': Column equilibration
  • 'B': Both row and column equilibration
This parameter must be the same as the parameter EQUED supplied to SGETRF. - name: 'N' type: 'INTEGER' description: The order of the matrix A. N ≥ 0. - name: 'NRHS' type: 'INTEGER' description: The number of right-hand sides, i.e., the number of columns of the matrices B and X. NRHS ≥ 0. - name: 'A' type: 'REAL array, dimension (LDA,N)' description: The coefficient matrix A. - name: 'LDA' type: 'INTEGER' description: The leading dimension of the array A. LDA ≥ max(1,N). - name: 'AF' type: 'REAL array, dimension (LDA,N)' description: | The factors L and U from the factorization of A (or A^T or A^H).
  • 'U': Upper triangular matrix of the factorization

- name: 'LAF' type: 'INTEGER' description: The leading dimension of the array AF. The first index in ERR_BNDS_NORM(i,:) corresponds to the ith right-hand side. The second index contains three fields:
  • err = 1: Boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').
  • err = 2: Error bound. The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.
  • err = 3: Reciprocal condition number. Estimated normwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is trustworthy.

  • err = 1: Boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').

  • PARAMS(LA_LINRX_ITREF_I = 1): Whether to perform iterative refinement or not.
    • Default: 1.0
    • = 0.0: No refinement is performed, and no error bounds are computed.
    • = 1.0: Use the double-precision refinement algorithm, possibly with doubled-single computations if the compilation environment does not support DOUBLE PRECISION.
    • (other values are reserved for future use)
  • PARAMS(LA_LINRX_ITHRESH_I = 2): Maximum number of residual computations allowed for refinement.

    • Aggressive: Set to 100 to permit convergence using approximate factorizations or factorizations other than LU. If the factorization uses a technique other than Gaussian elimination, the guarantees in err_bnds_norm and err_bnds_comp may no longer be trustworthy.

  • = 0: Successful exit. The solution to every right-hand side is guaranteed.
  • < 0: If INFO = -i, the i-th argument had an illegal value.
  • > 0 and <= N: U(INFO,INFO) is exactly zero. The factorization has been completed, but the factor U is exactly singular, so the solution and error bounds could not be computed. RCOND = 0 is returned.
