subroutine sggesx (character jobvsl, character jobvsr, character sort, external selctg, character sense, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, integer sdim, real, dimension( * ) alphar, real, dimension( * ) alphai, real, dimension( * ) beta, real, dimension( ldvsl, * ) vsl, integer ldvsl, real, dimension( ldvsr, * ) vsr, integer ldvsr, real, dimension( 2 ) rconde, real, dimension( 2 ) rcondv, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, logical, dimension( * ) bwork, integer info)

SGGESX calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> SGGESX calcula para un par de matrices reales no simétricas N por N
!> (A,B), los valores propios generalizados, la forma real de Schur (S,T), y,
!> opcionalmente, las matrices izquierda y/o derecha de vectores de Schur (VSL y
!> VSR). Esto da la factorización generalizada de Schur
!>
!>      (A,B) = ( (VSL) S (VSR)**T, (VSL) T (VSR)**T )
!>
!> Opcionalmente, también ordena los valores propios para que un clúster seleccionado
!> de valores propios aparezca en los bloques diagonales principales de la matriz
!> cuasi-triangular superior S y la matriz triangular superior T; calcula
!> un número de condición recíproco para el promedio de los valores propios seleccionados
!> (RCONDE); y calcula un número de condición recíproco para los subespacios de
!> deflexión derecha e izquierda correspondientes a los valores propios seleccionados
!> (RCONDV). Las columnas principales de VSL y VSR forman entonces una base ortonormal
!> para los correspondientes subespacios (de deflexión) izquierdos y derechos.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una razón alpha/beta = w, tal que A - w*B es singular. Usualmente se representa
!> como el par (alpha,beta), ya que hay una interpretación razonable para beta=0 o
!> para ambos siendo cero.
!>
!> Un par de matrices (S,T) está en forma de Schur real generalizada si T es
!> triangular superior con diagonal no negativa y S es bloque triangular superior
!> con bloques de 1x1 y 2x2. Los bloques de 1x1 corresponden a valores propios
!> generalizados reales, mientras que los bloques de 2x2 de S serán
!> al hacer que los elementos correspondientes de T tengan la forma:
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> y el par de bloques de 2x2 correspondientes en S y T tendrá un par
!> conjugado complejo de valores propios generalizados.
!>
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcula los vectores de Schur izquierdos;
!>          = 'V':  calcula los vectores de Schur izquierdos.
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcula los vectores de Schur derechos;
!>          = 'V':  calcula los vectores de Schur derechos.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se ordenan o no los valores propios en la
!>          diagonal de la forma generalizada de Schur.
!>          = 'N':  Los valores propios no se ordenan;
!>          = 'S':  Los valores propios se ordenan (ver SELCTG).
!>

SELCTG

!>          SELCTG es una FUNCIÓN LÓGICA de tres argumentos REALES
!>          SELCTG debe declararse EXTERNAL en la subrutina de llamada.
!>          Si SORT = 'N', SELCTG no se referencia.
!>          Si SORT = 'S', SELCTG se utiliza para seleccionar los valores propios a ordenar
!>          en la parte superior izquierda de la forma de Schur.
!>          Un valor propio (ALPHAR(j)+ALPHAI(j))/BETA(j) se selecciona si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) es verdadero; es decir, si uno
!>          de un par conjugado complejo de valores propios es seleccionado,
!>          entonces ambos valores propios complejos son seleccionados.
!>          Tenga en cuenta que un valor propio complejo seleccionado puede que ya no satisfaga
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) = .TRUE. después de la ordenación,
!>          ya que la ordenación puede cambiar el valor de los valores propios
!>          complejos (especialmente si el valor propio está mal condicionado), en cuyo
!>          caso INFO se establece en N+3.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué números de condición recíprocos se calculan.
!>          = 'N':  No se calcula ninguno;
!>          = 'E':  Calculado solo para el promedio de los valores propios seleccionados;
!>          = 'V':  Calculado solo para los subespacios de deflexión seleccionados;
!>          = 'B':  Calculado para ambos.
!>          Si SENSE = 'E', 'V', o 'B', SORT debe ser igual a 'S'.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR. N >= 0.
!>

A

!>          A es un array REAL, dimension (LDA, N)
!>          A la entrada, el primero del par de matrices.
!>          A la salida, A ha sido sobrescrito por su forma generalizada de Schur
!>          S.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. LDA >= max(1,N).
!>

B

!>          B es un array REAL, dimension (LDB, N)
!>          A la entrada, el segundo del par de matrices.
!>          A la salida, B ha sido sobrescrito por su forma generalizada de Schur
!>          T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de la ordenación)
!>          para los cuales SELCTG es verdadero. (Los pares conjugados complejos para los
!>          cuales SELCTG es verdadero para cualquiera de los valores propios cuentan como 2.)
!>

ALPHAR

!>          ALPHAR es un array REAL, dimension (N)
!>

ALPHAI

!>          ALPHAI es un array REAL, dimension (N)
!>

BETA

!>          BETA es un array REAL, dimension (N)
!>          A la salida, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, serán
!>          los valores propios generalizados. ALPHAR(j) + ALPHAI(j)*i
!>          y BETA(j),j=1,...,N son las diagonales de la forma de Schur compleja
!>          (S,T) que resultaría si los bloques diagonales de 2x2
!>          de la forma real de Schur de (A,B) se redujeran aún más a
!>          forma triangular usando transformaciones unitarias complejas de 2x2.
!>          Si ALPHAI(j) es cero, entonces el j-ésimo valor propio es real; si
!>          es positivo, entonces el j-ésimo y (j+1)-ésimo valores propios son un
!>          par conjugado complejo, con ALPHAI(j+1) negativo.
!>
!>          Nota: los cocientes ALPHAR(j)/BETA(j) y ALPHAI(j)/BETA(j)
!>          pueden fácilmente sobrefluir o subfluir, y BETA(j) puede incluso ser cero.
!>          Por lo tanto, el usuario debe evitar calcular ingenuamente el cociente.
!>          Sin embargo, ALPHAR y ALPHAI siempre serán menores y
!>          generalmente comparables con norm(A) en magnitud, y BETA siempre
!>          menor y generalmente comparable con norm(B).
!>

VSL

!>          VSL es un array REAL, dimension (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contendrá los vectores

NAME

sggesx - computes for the generalized eigenvalue problem Ax = λBx the generalized eigenvalues, and optionally, the left and right Schur vectors.

SYNOPSIS

        SUBROUTINE SGGESX( MATRIX_A_IS_TRANSPOSED, MATRIX_B_IS_TRANSPOSED,
                       SORT, SELECT,
                       A, LDA, B, LDB,
                       ALPHAR, ALPHAI, BETA,
                       ACOMPQ, BCOMPQ,
                       Q, LDQ, Z, LDZ,
                       FORCML, FORCVL, FORCMR, FORCVR,
                       RCONDE, RCONDV, WORK, LWORK, IWORK, LIWORK,
                       BWORK, INFO )
        !
        INTEGER INFO
        LOGICAL BWORK(*)
        REAL A( LDA, * ), B( LDB, * ), ACOMPQ( * ), BCOMPQ( * ),
       $         ALPHAR( * ), ALPHAI( * ), BETA( * ), RCONDE( * ),
       $         RCONDV( * ), WORK( * )
        INTEGER LDA, LDB, LDQ, LDZ, LWORK, LIWORK
        CHARACTER(1) FORCML, FORCVL, FORCMR, FORCVR
        CHARACTER(1) MATRIX_A_IS_TRANSPOSED, MATRIX_B_IS_TRANSPOSED,
       $             SORT, SELECT

Function/Subroutine Documentation

This subroutine is part of the LAPACK routines for solving the generalized eigenvalue problem Ax = λBx.

Parameters

MATRIX_A_IS_TRANSPOSED

MATRIX_A_IS_TRANSPOSED is CHARACTER*1
= 'T': A is transposed;
= 'N': A is not transposed.

MATRIX_B_IS_TRANSPOSED

MATRIX_B_IS_TRANSPOSED is CHARACTER*1
= 'T': B is transposed;
= 'N': B is not transposed.

SORT

SORT is CHARACTER*1
= 'S': compute all eigenvalues, and select those satisfying SELECT.
= 'N': compute all eigenvalues, do not select any.

SELECT

SELECT is a FUNCTION returning a LOGICAL value, and has the following specification: 

                                    LOGICAL FUNCTION SELECT(AR, AI, BETA)
                                    REAL AR, AI, BETA

If SORT = 'S', SELECT is used to select eigenvalues which satisfy the selection criterion. If SELECT(AR, AI, BETA) is true, then the eigenvalue AR + i*AI ----- BETA is selected.
If SORT = 'N', SELECT is not referenced.

A

A is REAL array, dimension (LDA, N)
On entry, the matrix A in the pencil (A, B).
On exit, if gio = 0, A is overwritten by the upper triangular matrix R of the generalized Schur decomposition.

LDA

LDA is INTEGER
The leading dimension of A. LDA >= max(1,N).

B

B is REAL array, dimension (LDB, N)
On entry, the matrix B in the pencil (A, B).
On exit, if gio = 0, B is overwritten by the upper triangular matrix S of the generalized Schur decomposition.

LDB

LDB is INTEGER
The leading dimension of B. LDB >= max(1,N).

ALPHAR

ALPHAR is REAL array, dimension (N)
On exit, ALPHAR(I) and ALPHAI(I) are the real and imaginary parts, respectively, of the I-th generalized eigenvalue of the pencil (A, B).

ALPHAI

ALPHAI is REAL array, dimension (N)
On exit, ALPHAI(I) is the imaginary part of the I-th generalized eigenvalue. If ALPHAI(I) is zero, then the eigenvalue is real.

BETA

BETA is REAL array, dimension (N)
On exit, BETA(I) is the I-th generalized eigenvalue. BETA(I) is always real.
The generalized eigenvalues are computed as the ratio ALPHAR(I) / BETA(I) (complex):
ALPHAR(I) + i*ALPHAI(I) ------------------- BETA(I)
If ALPHA and BETA are both zero, the eigenvalue is undefined.

ACOMPQ

ACOMPQ is REAL array, dimension (N)
On exit, ACOMPQ(I) is the imaginary part of the I-th computed generalized eigenvalue.
Not referenced if COMPQ = 'N'.

BCOMPQ

BCOMPQ is REAL array, dimension (N)
On exit, BCOMPQ(I) is the I-th computed generalized eigenvalue.
Not referenced if COMPQ = 'N'.

Q

Q is REAL array, dimension (LDQ, N)
On exit, Q contains the left Schur vectors.
Not referenced if JOBVL = 'N'.

LDQ

LDQ is INTEGER
The leading dimension of Q. LDQ >= 1.
If JOBVL = 'V', LDQ >= N.

Z

Z is REAL array, dimension (LDZ, N)
On exit, Z contains the right Schur vectors.
Not referenced if JOBVR = 'N'.

LDZ

LDZ is INTEGER
The leading dimension of Z. LDZ >= 1.
If JOBVR = 'V', LDZ >= N.

FORCML

FORCML is CHARACTER*1
= 'F': Force left Schur vector computation.
= 'R': Skip left Schur vector computation.

FORCVL

FORCVL is CHARACTER*1
= 'L': Compute left Schur vectors if JOBVL = 'V'.
= 'N': Skip left Schur vector computation.

FORCMR

FORCMR is CHARACTER*1
= 'F': Force right Schur vector computation.
= 'R': Skip right Schur vector computation.

FORCVR

FORCVR is CHARACTER*1
= 'L': Compute right Schur vectors if JOBVR = 'V'.
= 'N': Skip right Schur vector computation.

RCONDE

RCONDE is REAL array, dimension ( 2 )
If SENSE = 'E' or 'B', RCONDE(1) and RCONDE(2) contain the reciprocal condition numbers for the average of the selected eigenvalues.
Not referenced if SENSE = 'N' or 'V'.

RCONDV

RCONDV is REAL array, dimension ( 2 )
If SENSE = 'V' or 'B', RCONDV(1) and RCONDV(2) contain the reciprocal condition numbers for the selected deflating subspaces.
Not referenced if SENSE = 'N' or 'E'.

WORK

WORK is REAL array, dimension (MAX(1,LWORK))
On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

LWORK is INTEGER
The dimension of the array WORK.
If N = 0, LWORK >= 1, else if SENSE = 'E', 'V', or 'B', LWORK >= max( 8*N, 6*N+16, 2*SDIM*(N-SDIM) ), else LWORK >= max( 8*N, 6*N+16 ).
Note that 2*SDIM*(N-SDIM) <= N*N/2.
Note also that an error is only returned if LWORK < max( 8*N, 6*N+16), but if SENSE = 'E' or 'V' or 'B' this may not be large enough.
If LWORK = -1, then a workspace query is assumed; the routine only calculates the bound on the optimal size of the WORK array and the minimum size of the IWORK array, returns these values as the first entries of the WORK and IWORK arrays, and no error message related to LWORK or LIWORK is issued by XERBLA.

IWORK

IWORK is INTEGER array, dimension (MAX(1,LIWORK))
On exit, if INFO = 0, IWORK(1) returns the minimum LIWORK.

LIWORK

LIWORK is INTEGER
The dimension of the array IWORK.
If SENSE = 'N' or N = 0, LIWORK >= 1, otherwise LIWORK >= N+6.
If LIWORK = -1, then a workspace query is assumed; the routine only calculates the bound on the optimal size of the WORK array and the minimum size of the IWORK array, returns these values as the first entries of the WORK and IWORK arrays, and no error message related to LWORK or LIWORK is issued by XERBLA.

BWORK

BWORK is LOGICAL array, dimension (N)
Not referenced if SORT = 'N'.

INFO

INFO is INTEGER
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value.
= 1,...,N: The QZ iteration failed. (A,B) are not in Schur form, but ALPHAR(j), ALPHAI(j), and BETA(j) should be correct for j=INFO+1,...,N.
> N: =N+1: other than QZ iteration failed in SHGEQZ
=N+2: after reordering, roundoff changed values of some complex eigenvalues so that leading eigenvalues in the Generalized Schur form no longer satisfy SELCTG=.TRUE. This could also be caused due to scaling.
=N+3: reordering failed in STGSEN.
