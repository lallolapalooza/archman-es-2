Documentación de la Función/Subrutina

subrutina sgemv (character trans, integer m, integer n, real alpha, real, dimension(lda,*) a, integer lda, real, dimension(*) x, integer incx, real beta, real, dimension(*) y, integer incy)

SGEMV

Propósito:

!>
!> SGEMV  realiza una de las operaciones de matriz-vector
!>
!>    y := alpha*A*x + beta*y,   o   y := alpha*A**T*x + beta*y,
!>
!> donde alpha y beta son escalares, x e y son vectores y A es una
!> matriz de m por n.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>           A la entrada, TRANS especifica la operación a realizar como
!>           sigue:
!>
!>              TRANS = 'N' o 'n'   y := alpha*A*x + beta*y.
!>
!>              TRANS = 'T' o 't'   y := alpha*A**T*x + beta*y.
!>
!>              TRANS = 'C' o 'c'   y := alpha*A**T*x + beta*y.
!>

M

!>          M es INTEGER
!>           A la entrada, M especifica el número de filas de la matriz A.
!>           M debe ser al menos cero.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el número de columnas de la matriz A.
!>           N debe ser al menos cero.
!>

ALPHA

!>          ALPHA es REAL
!>           A la entrada, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array REAL, de dimensión ( LDA, N )
!>           Antes de la entrada, la parte principal de m por n del array A debe
!>           contener la matriz de coeficientes.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A según
!>           declarada en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, m ).
!>

X

!>          X es un array REAL, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( m - 1 )*abs( INCX ) ) en caso contrario.
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x.
!>

INCX

!>          INCX es INTEGER
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>

BETA

!>          BETA es REAL
!>           A la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           proporciona como cero, Y no necesita ser establecida a la entrada.
!>

Y

!>          Y es un array REAL, de dimensión al menos
!>           ( 1 + ( m - 1 )*abs( INCY ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ) en caso contrario.
!>           Antes de la entrada con BETA distinto de cero, el array Y incrementado
!>           debe contener el vector y. A la salida, Y se sobrescribe con el
!>           vector y actualizado.
!>           Si m o n es cero, entonces Y no se referencia y la función
!>           realiza un retorno rápido.
!>

INCY

!>          INCY es INTEGER
!>           A la entrada, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>
