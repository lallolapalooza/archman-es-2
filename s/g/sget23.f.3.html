Propósito

!>
!>    SGET23  verifica el controlador del problema de valores propios no simétricos SGEEVX.
!>    Si COMP = .FALSE., se realizarán las primeras 8 de las siguientes pruebas en la matriz de entrada A, y también la prueba 9 si LWORK es
!>    suficientemente grande.
!>    Si COMP es .TRUE., se realizarán las 11 pruebas.
!>
!>    (1)     | A * VR - VR * W | / ( n |A| ulp )
!>
!>      Aquí VR es la matriz de vectores propios derechos unitarios.
!>      W es una matriz diagonal por bloques, con un bloque de 1x1 para cada
!>      valor propio real y un bloque de 2x2 para cada par conjugado
!>      complejo. Si los valores propios j y j+1 son un par conjugado complejo,
!>      tal que WR(j) = WR(j+1) = wr e WI(j) = - WI(j+1) = wi, entonces el
!>      bloque de 2 x 2 correspondiente al par será:
!>
!>              (  wr  wi  )
!>              ( -wi  wr  )
!>
!>      Un bloque así multiplicando una matriz n x 2  ( ur ui ) a la
!>      derecha será lo mismo que multiplicar  ur + i*ui  por  wr + i*wi.
!>
!>    (2)     | A**H * VL - VL * W**H | / ( n |A| ulp )
!>
!>      Aquí VL es la matriz de vectores propios izquierdos unitarios, A**H es la
!>      transpuesta conjugada de A, y W es como se describió anteriormente.
!>
!>    (3)     | |VR(i)| - 1 | / ulp y componente real más grande
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp y componente real más grande
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!>    (5)     0 si W(completo) = W(parcial), 1/ulp en caso contrario
!>
!>      W(completo) denota los valores propios calculados cuando también se calculan VR, VL, RCONDV
!>      y RCONDE, y W(parcial) denota los valores propios calculados cuando solo se calculan algunos de VR, VL, RCONDV y
!>      RCONDE.
!>
!>    (6)     0 si VR(completo) = VR(parcial), 1/ulp en caso contrario
!>
!>      VR(completo) denota los vectores propios derechos calculados cuando también se calculan VL, RCONDV
!>      y RCONDE, y VR(parcial) denota el resultado
!>      cuando solo se calculan algunos de VL y RCONDV.
!>
!>    (7)     0 si VL(completo) = VL(parcial), 1/ulp en caso contrario
!>
!>      VL(completo) denota los vectores propios izquierdos calculados cuando también se calculan VR, RCONDV
!>      y RCONDE, y VL(parcial) denota el resultado
!>      cuando solo se calculan algunos de VR y RCONDV.
!>
!>    (8)     0 si SCALE, ILO, IHI, ABNRM (completo) =
!>                 SCALE, ILO, IHI, ABNRM (parcial)
!>            1/ulp en caso contrario
!>
!>      SCALE, ILO, IHI y ABNRM describen cómo se equilibra la matriz.
!>      (completo) es cuando también se calculan VR, VL, RCONDE y RCONDV, y
!>      (parcial) es cuando algunos no se calculan.
!>
!>    (9)     0 si RCONDV(completo) = RCONDV(parcial), 1/ulp en caso contrario
!>
!>      RCONDV(completo) denota los recíprocos de los números de condición de los
!>      vectores propios derechos calculados cuando también se calculan VR, VL y RCONDE. RCONDV(parcial) denota los recíprocos de los números de
!>      condición calculados cuando solo se calculan algunos de VR, VL y RCONDE.
!>
!>   (10)     |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>      RCONDV es el recíproco del número de condición de los vectores propios derechos
!>      calculado por SGEEVX y RCDVIN (el valor verdadero precalculado)
!>      se proporciona como entrada. cond(RCONDV) es el número de condición de
!>      RCONDV, y tiene en cuenta los errores en el cálculo de RCONDV, de modo
!>      que la cantidad resultante debe ser O(ULP). cond(RCONDV)
!>      es esencialmente dado por norm(A)/RCONDE.
!>
!>   (11)     |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>      RCONDE es el recíproco del número de condición de los valores propios
!>      calculado por SGEEVX y RCDEIN (el valor verdadero precalculado)
!>      se proporciona como entrada. cond(RCONDE) es el número de condición de
!>      RCONDE, y tiene en cuenta los errores en el cálculo de RCONDE, de modo
!>      que la cantidad resultante debe ser O(ULP). cond(RCONDE)
!>      es esencialmente dado por norm(A)/RCONDV.
!>

Parámetros

COMP 
!>          COMP es LOGICAL
!>          COMP describe qué pruebas de entrada realizar:
!>            = .FALSE. si los números de condición calculados no deben
!>                      ser probados contra RCDVIN y RCDEIN
!>            = .TRUE.  si deben compararse
!>

BALANC

!>          BALANC es CHARACTER
!>          Describe la opción de balanceo a probar.
!>            = 'N' para no permutar ni escalar diagonalmente
!>            = 'P' para permutar pero sin escalar diagonalmente
!>            = 'S' para no permutar pero escalar diagonalmente
!>            = 'B' para permutar y escalar diagonalmente
!>

JTYPE

!>          JTYPE es INTEGER
!>          Tipo de matriz de entrada. Se utiliza para etiquetar la salida si ocurre un error.
!>

THRESH

!>          THRESH es REAL
!>          Una prueba se contará si el valor calculado,
!>          como se describe anteriormente, excede THRESH. Tenga en cuenta que el error
!>          se escala para que sea O(1), por lo que THRESH debe ser un múltiplo razonablemente
!>          pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          o del tamaño de la matriz. Debe ser al menos cero.
!>

ISEED

!>          ISEED es un array INTEGER, dimension (4)
!>          Si COMP = .FALSE., la semilla del generador de números aleatorios
!>          utilizada para producir la matriz.
!>          Si COMP = .TRUE., ISEED(1) = el número del ejemplo.
!>          Se utiliza para etiquetar la salida si ocurre un error.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve INFO no igual a 0.)
!>

N

!>          N es INTEGER
!>          La dimensión de A. N debe ser al menos 0.
!>

A

!>          A es un array REAL, dimension (LDA,N)
!>          Se utiliza para contener la matriz cuyos valores propios se van a
!>          calcular.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A y H. LDA debe ser al
!>
