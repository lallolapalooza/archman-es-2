subrutina sgesc2 (n, a, lda, rhs, ipiv, jpiv, scale)

SGESC2 resuelve un sistema de ecuaciones lineales utilizando la factorización LU con pivoteo completo calculada por sgetc2.

Documentación de la función/subrutina

subrutina sgesc2 (entero n, real, dimensión( lda, * ) a, entero lda, real, dimensión( * ) rhs, entero, dimensión( * ) ipiv, entero, dimensión( * ) jpiv, real scale)

SGESC2 resuelve un sistema de ecuaciones lineales utilizando la factorización LU con pivoteo completo calculada por sgetc2.

Propósito:

!>
!> SGESC2 resuelve un sistema de ecuaciones lineales
!>
!>           A * X = scale* RHS
!>
!> con una matriz general N-por-N A utilizando la factorización LU con
!> pivoteo completo calculada por SGETC2.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          En la entrada, la parte LU de la factorización de la matriz
!>          N-por-N A calculada por SGETC2:  A = P * L * U * Q
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1, N).
!>

RHS

!>          RHS es un array REAL, dimensión (N).
!>          En la entrada, el vector del lado derecho b.
!>          En la salida, el vector solución X.
!>

IPIV

!>          IPIV es un array ENTERO, dimensión (N).
!>          Los índices de pivote; para 1 <= i <= N, la fila i de la
!>          matriz ha sido intercambiada con la fila IPIV(i).
!>

JPIV

!>          JPIV es un array ENTERO, dimensión (N).
!>          Los índices de pivote; para 1 <= j <= N, la columna j de la
!>          matriz ha sido intercambiada con la columna JPIV(j).
!>

SCALE

!>          SCALE es REAL
!>           En la salida, SCALE contiene el factor de escala. SCALE se elige
!>           0 <= SCALE <= 1 para evitar desbordamientos en la solución.
!>
