NOMBRE

osx - Un conversor de SGML a XML

SINOPSIS

osx [-CeghnRvx] [-anombre] [-Aarquitectura] [-bcodificacion] [-carchivo_catalogo] [-ddirectorio] [-Ddirectorio] [-inombre] [-farchivo] [-larchivo_dtd] [-wtipo_advertencia] [-xopcion_salida_xml...] [sysid...]

DESCRIPCIÓN

osx convierte SGML a XML. osx analiza y valida el documento SGML contenido en

y escribe un documento XML equivalente en la salida estándar. osx advertirá sobre construcciones SGML que no tienen un equivalente en XML.

Parte de un Sistema SGML Conforme a la Norma Internacional ISO 8879 -- Lenguaje de Marcado Generalizado Estándar. Un sistema de Instalaciones Extendidas SGML Conforme al Anexo A de la Norma Internacional ISO/IEC 10744 -- Lenguaje de Estructuración Basado en Hipermedia/Tiempo.

OPCIONES

Las siguientes opciones están disponibles:

-anombre, --activar=nombre

Hace que el doctype o el nombre de enlace nombre esté activo.

-Anombre, --arquitectura=nombre

Analiza con respecto a la arquitectura nombre.

-bcodificacion, --codificacion=codificacion

Utiliza la codificacion BCTF para la salida. Por defecto, osx utiliza UTF-8.

-csysid, --catalogo=sysid

Mapea identificadores públicos y nombres de entidades a identificadores del sistema utilizando el archivo de entrada de catálogo cuyo identificador de sistema es sysid.

-C, --catalogs

Esto tiene el mismo efecto que en onsgmls(1).

-ddirectorio, --ubicacion_salida_entidades=directorio

Coloca los archivos de salida en el directorio.

-Ddirectorio, --directorio=directorio

Busca en el directorio los archivos especificados en los identificadores de sistema. Esto tiene el mismo efecto que en onsgmls(1).

-e, --abrir-entidades

Describe las entidades abiertas en los mensajes de error.

-Emax_errores, --max-errores=max_errores

Abandona después de max_errores errores.

-farchivo, --archivo_errores=archivo

Redirige los errores al archivo. Esto es útil principalmente con shells que no admiten la redirección de stderr.

-g, --abrir-elementos

Describe los elementos abiertos en los mensajes de error.

-h, --ayuda

Muestra un texto de ayuda y sale.

-inombre, --incluir=nombre

Esto tiene el mismo efecto que en onsgmls(1).

-larchivo_dtd, --ubicacion_dtd=archivo_dtd

Especifica que el archivo XML resultante debe cumplir con el DTD en archivo_dtd.

-n, --numeros-errores

Muestra los números de error en los mensajes de error.

--referencias

Muestra las referencias en los mensajes de error.

-R, --restringido

Esto tiene el mismo efecto que en onsgmls(1).

-v, --version

Imprime el número de versión y sale.

-wtipo, --advertencia=tipo

Controla las advertencias y los errores según el tipo. Esto tiene el mismo efecto que en onsgmls(1).

-xopcion_salida_xml, --opcion-salida-xml=opcion_salida_xml

Controla la salida XML según el valor de opcion_salida_xml de la siguiente manera:

no-nl-in-tag No usar saltos de línea dentro de las etiquetas de inicio. Normalmente, osx utiliza saltos de línea dentro de las etiquetas de inicio para reducir la probabilidad de líneas excesivamente largas.

id Salida de declaraciones de atributos para atributos ID.

notation Salida de declaraciones para notaciones.

ndata Salida de declaraciones para entidades de datos externos. XML requiere que estas sean NDATA. osx advertirá sobre entidades de datos externas CDATA y SDATA y las emitirá como entidades NDATA.

cdata Utiliza secciones CDATA de XML para secciones marcadas como CDATA y para elementos con un contenido declarado como CDATA.

comment Salida de declaraciones de comentarios. Las declaraciones de comentarios en el DTD no se emitirán.

lower Prefiere minúsculas. Los nombres que fueron sujetos a sustitución de mayúsculas por SGML se convertirán a minúsculas. Esto no incluye nombres reservados; XML requiere que estos estén en mayúsculas.

pi-escape Escapa &<> en el contenido de las instrucciones de procesamiento utilizando las entidades amp, lt y gt. Esto permite que las instrucciones de procesamiento contengan la cadena >?, pero requiere que las aplicaciones manejen los escapes.

empty Utiliza la sintaxis <e/> para los tipos de elementos e declarados como EMPTY.

attlist Emite una declaración ATTLIST para cada elemento que especifique el tipo de todos los atributos. El valor predeterminado será siempre #IMPLIED.

report-input-sources Emite una instrucción de procesamiento para informar cuándo se abre o se cierra una fuente de entrada distinta del archivo principal en la instancia. No informa ningún cambio de fuente de entrada en el DTD.

report-entities Emite una instrucción de procesamiento para informar cuándo se ha resuelto una referencia a una entidad externa en la instancia. No informa ninguna resolución de entidades en el DTD.

no-expand-external Conserva las entidades externas, escribe un archivo controlador de declaraciones llamado "extEntities.dtf" e incluye ese archivo en el subconjunto interno de la instancia.

no-expand-internal Conserva las entidades internas, escribe un archivo controlador de declaraciones llamado "intEntities.dtf" e incluye ese archivo en el subconjunto interno de la instancia.

no-external-decl No incluye el archivo controlador de declaraciones de entidades externas en el subconjunto interno de la instancia.

no-internal-decl No incluye el archivo controlador de declaraciones de entidades internas en el subconjunto interno de la instancia.

no-output-outside-outdir Al conservar entidades externas, no escriba archivos de salida fuera del directorio de salida especificado ("." por defecto). En otras palabras, si el identificador del sistema de una entidad externa incluye suficientes instancias de ".." para que osx escriba un archivo fuera (por encima) del directorio de salida, salga (por defecto, osx emitirá una advertencia pero escribirá el archivo y continuará.

no-overwrite Al conservar entidades internas o externas, se escribirán múltiples archivos de salida. Si se especifica esta opción, no sobrescriba los archivos existentes; en su lugar, intente añadir un número al final del nombre de archivo original para crear un nombre de archivo único. Salga con un error si ya existen demasiados (100) archivos de este tipo.

preserve-case Conserva las mayúsculas y minúsculas según lo especificado en el DTD para los nombres de elementos; nombres de atributos; valores de atributos que son listas de tokens.

sdata-as-pis Al traducir entidades SDATA (ya sea expandiéndolas o proporcionando una definición para ellas en el subconjunto interno de la salida), exprésalas como instrucciones de procesamiento en lugar de como entidades internas generales.

Se permiten múltiples opciones -x.

sgml2xml

NAME

sgml2xml - Convertidor de SGML a XML

SYNOPSIS

sgml2xml [opciones] [archivo SGML]

DESCRIPTION

sgml2xml es una herramienta que convierte documentos SGML (Standard Generalized Markup Language) a XML (Extensible Markup Language). Esto puede ser útil para migrar documentos SGML existentes a formatos XML modernos, lo que permite aprovechar las herramientas y ecosistemas de XML.

La herramienta analiza el archivo SGML de entrada, aplica las reglas definidas en las DTD (Document Type Definitions) asociadas y genera una salida XML bien formada.

OPTIONS

sgml2xml soporta varias opciones para controlar el proceso de conversión. Algunas de las opciones comunes incluyen:

  • -o : Especifica el nombre del archivo de salida. Si no se proporciona, la salida se imprimirá en la salida estándar.
  • -d : Especifica un directorio donde buscar las DTDs.
  • -E: No mostrar errores de análisis.
  • -s: No mostrar advertencias.
  • --help: Mostrar mensaje de ayuda.
  • --version: Mostrar información de la versión.

Para una lista completa de opciones, consulte la documentación de la herramienta o ejecute sgml2xml --help.
