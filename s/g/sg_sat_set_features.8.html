NOMBRE

sg_sat_set_features - utiliza el comando ATA SET FEATURES a través de una capa de traducción SCSI a ATA (SAT)

SINOPSIS

sg_sat_set_features [--count=CO] [--ck_cond] [--extended] [--feature=FEA] [--help] [--lba=LBA] [--len={16|12}] [--readonly] [--verbose] [--version] DISPOSITIVO

DESCRIPCIÓN

Esta utilidad envía un comando ATA SET FEATURES al DISPOSITIVO. Este comando se utiliza para cambiar la configuración de dispositivos ATA no de paquete (es decir, discos) y de paquete (por ejemplo, unidades de CD/DVD). En lugar de enviar el comando SET FEATURES directamente al dispositivo, se envía a través de un transporte SCSI que se supone contiene una capa de traducción SCSI a ATA (SAT). La SATL puede estar en un controlador del sistema operativo, en el firmware de la controladora de host o en algún recinto externo.

El estándar SAT (SAT ANSI INCITS 431-2007, borrador anterior: sat-r09.pdf en www.t10.org) define dos comandos SCSI "ATA PASS-THROUGH": uno que utiliza un "cdb" de 16 bytes y otro con un cdb de 12 bytes. Esta utilidad, por defecto, utiliza la variante de cdb de 16 bytes. SAT-2 también es un estándar: SAT-2 ANSI INCITS 465-2010 y el borrador anterior es sat2r09.pdf. El proyecto SAT-3 ha comenzado y el borrador más reciente es sat3r05b.pdf.

Las características se pueden leer utilizando la utilidad sg_sat_identify, que utiliza el comando ATA IDENTIFY DEVICE (para dispositivos no de paquete) o IDENTIFY PACKET DEVICE (para dispositivos de paquete).

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-c, --count=CO
el número CO se coloca en el campo "count" (recuento) del comando ATA SET FEATURES. Solo algunos subcomandos (un término utilizado para el valor colocado en el campo "feature") requieren que se establezca el campo de recuento. El valor predeterminado que se coloca en el campo "count" es 0.
-C, --ck_cond
establece el bit CK_COND en el cdb ATA PASS-THROUGH de SCSI. La configuración predeterminada está clara (es decir, 0). Cuando está establecido, la SATL debería generar un buffer de *sense* que contenga un descriptor de resultado ATA independientemente de si el comando ATA tuvo éxito o falló. Cuando está claro, la SATL solo debería generar un buffer de *sense* que contenga un descriptor de resultado ATA si el comando ATA falló.
-e, --extended
permite números LBA extendidos (es decir, mayores de 32 bits). Este valor se habilita automáticamente para números LBA grandes, pero se puede habilitar explícitamente incluso para números LBA pequeños con esta opción.
-f, --feature=FEA
el valor FEA se coloca en el campo "feature" (característica) del comando ATA SET FEATURES. El término "subcomando" se utiliza a veces para este valor. El valor predeterminado que se coloca en el campo "feature" es 0, que está reservado y, por lo tanto, no debería cambiar nada. Dos ejemplos comunes son 2h para habilitar la caché de escritura y 82h para deshabilitarla.
-h, --help
muestra el mensaje de uso resumiendo las opciones de la línea de comandos y luego sale. Ignora DISPOSITIVO si se proporciona.
-L, --lba=LBA
el número LBA se coloca en el campo "lba" del comando ATA SET FEATURES. Solo algunos subcomandos (un término utilizado para el valor colocado en el campo "feature") requieren que se establezca el campo lba. Este valor típicamente no es una "dirección de bloque lógico", como podría implicar el acrónimo. El valor predeterminado que se coloca en el campo "lba" es 0. El valor máximo permitido para LBA es 0xfffffffe (o 0xffffff si es --len=12).
-l, --len={16|12}
esta es la longitud del cdb de SCSI utilizado para los comandos ATA PASS-THROUGH. El argumento puede ser 16 o 12. El valor predeterminado es 16. Algunos transportes SCSI no pueden transmitir comandos SCSI de más de 12 bytes.
-r, --readonly
hace que el DISPOSITIVO se abra con la bandera de solo lectura (O_RDONLY en Unix). La acción predeterminada es abrir el DISPOSITIVO con la bandera de lectura/escritura (O_RDWR en Unix). En algunos casos, el envío de comandos de gestión de energía a unidades ATA se ve frustrado por acciones del SO al cerrar() si el DISPOSITIVO se abrió con la bandera de lectura/escritura (por ejemplo, el SO podría pensar que necesita vaciar algo en el disco).
-v, --verbose
aumenta el nivel de verbosidad.
-V, --version
imprime la cadena de versión

NOTAS

En la serie 2.4 de los kernels de Linux, el DISPOSITIVO debe ser un dispositivo genérico SCSI (sg). En las series 2.6 y 3, también se pueden especificar dispositivos de bloque (por ejemplo, discos y DVDs ATAPI). Por ejemplo, "sg_inq /dev/sda" funcionará en los kernels de la serie 2.6. A partir de lk 2.6.6, también se pueden utilizar otros nombres de dispositivo de "carácter" SCSI (por ejemplo, "/dev/st0m"). Antes de lk 2.6.29, el almacenamiento masivo USB limitaba los datos de *sense* a 18 bytes, lo que hacía que la opción --ck_cond produjera resultados extraños (truncados).

ESTADO DE SALIDA

El estado de salida de sg_sat_set_features es 0 cuando tiene éxito. De lo contrario, consulte la página del manual sg3_utils(8).
