subroutine sgedmdq (jobs, jobz, jobr, jobq, jobt, jobf, whtsvd, m, n, f, ldf, x, ldx, y, ldy, nrnk, tol, k, reig, imeig, z, ldz, res, b, ldb, v, ldv, s, lds, work, lwork, iwork, liwork, info)
SGEDMDQ calcula la Descomposición de Modos Dinámicos (DMD) para un par de matrices de instantáneas de datos.

Documentación de Función/Subrutina

SGEDMDQ calcula la Descomposición de Modos Dinámicos (DMD) para un par de matrices de instantáneas de datos.

Propósito:

!>    SGEDMDQ calcula la Descomposición de Modos Dinámicos (DMD) para
!>    un par de matrices de instantáneas de datos, utilizando una compresión
!>    basada en factorización QR de los datos. Para las matrices de entrada
!>    X e Y tal que Y = A*X con una matriz A inaccesible, SGEDMDQ calcula
!>    un cierto número de pares de Ritz de A utilizando la extracción estándar
!>    de Rayleigh-Ritz de un subespacio de range(X) que se determina usando
!>    los vectores singulares izquierdos principales de X. Opcionalmente, SGEDMDQ
!>    devuelve los residuos de los pares de Ritz calculados, la información
!>    necesaria para un refinamiento de los vectores de Ritz, o los
!>    autovectores de la DMD Exacta.
!>    Para más detalles ver las referencias listadas abajo.
!>    Para más detalles de la implementación ver [3].
!>

Referencias:

!>    [1] P. Schmid: Dynamic mode decomposition of numerical
!>        and experimental data,
!>        Journal of Fluid Mechanics 656, 5-28, 2010.
!>    [2] Z. Drmac, I. Mezic, R. Mohr: Data driven modal
!>        decompositions: analysis and enhancements,
!>        SIAM J. on Sci. Comp. 40 (4), A2253-A2285, 2018.
!>    [3] Z. Drmac: A LAPACK implementation of the Dynamic
!>        Mode Decomposition I. Technical report. AIMDyn Inc.
!>        and LAPACK Working Note 298.
!>    [4] J. Tu, C. W. Rowley, D. M. Luchtenburg, S. L.
!>        Brunton, N. Kutz: On Dynamic Mode Decomposition:
!>        Theory and Applications, Journal of Computational
!>        Dynamics 1(2), 391 -421, 2014.
!>

Parámetros

JOBS 
!>    JOBS (entrada) CHARACTER*1
!>    Determina si las instantáneas de datos iniciales se escalan
!>    por una matriz diagonal. Las instantáneas de datos son las columnas
!>    de F. Las N-1 columnas principales de F se denotan X y las
!>    N-1 columnas siguientes se denotan Y.
!>    'S' :: Las matrices de instantáneas de datos X e Y se multiplican
!>           con una matriz diagonal D de tal forma que X*D tenga columnas
!>           unitarias (en la norma Euclidiana 2).
!>    'C' :: Las instantáneas se escalan como en la opción 'S'.
!>           Si se encuentra que una i-ésima columna de X es un vector
!>           cero y la correspondiente i-ésima columna de Y es no nula,
!>           entonces la i-ésima columna de Y se establece a cero y se
!>           eleva una bandera de advertencia.
!>    'Y' :: Las matrices de instantáneas de datos X e Y se multiplican
!>           por una matriz diagonal D de tal forma que Y*D tenga columnas
!>           unitarias (en la norma Euclidiana 2).
!>    'N' :: No hay escalado de datos.
!>

JOBZ

!>    JOBZ (entrada) CHARACTER*1
!>    Determina si se calcularán los autovectores (modos de Koopman).
!>    'V' :: Se calcularán los autovectores (modos de Koopman)
!>           y se devolverán en la matriz Z.
!>           Ver la descripción de Z.
!>    'F' :: Los autovectores (modos de Koopman) se devolverán
!>           en forma factorizada como el producto Z*V, donde Z
!>           es ortonormal y V contiene los autovectores
!>           del cociente de Rayleigh correspondiente.
!>           Ver las descripciones de F, V, Z.
!>    'Q' :: Los autovectores (modos de Koopman) se devolverán
!>           en forma factorizada como el producto Q*Z, donde Z
!>           contiene los autovectores de la compresión del
!>           operador subyacente discretizado sobre el tramo
!>           de las instantáneas de datos. Ver las descripciones de F, V, Z.
!>           Q proviene de la factorización QR inicial.
!>    'N' :: No se calculan los autovectores.
!>

JOBR

!>    JOBR (entrada) CHARACTER*1
!>    Determina si se calcularán los residuos.
!>    'R' :: Los residuos para los pares de autovalores calculados se
!>           calcularán y se almacenarán en el array RES.
!>           Ver la descripción de RES.
!>           Para que esta opción sea legal, JOBZ debe ser 'V'.
!>    'N' :: No se calculan los residuos.
!>

JOBQ

JOBQ (entrada) CHARACTER*1 Especifica si se debe calcular y devolver explícitamente la matriz ortogonal de la factorización QR. 'Q' :: La matriz Q de la factorización QR de la matriz de instantáneas de datos se calcula y se almacena en la matriz F. Consulte la descripción de F. 'N' :: La matriz Q no se calcula explícitamente. JOBT (entrada) CHARACTER*1 Especifica si se debe devolver el factor triangular superior de la factorización QR. 'R' :: La matriz R de la factorización QR de la matriz de instantáneas de datos F se devuelve en la matriz Y. Consulte la descripción de Y y Detalles adicionales. 'N' :: La matriz R no se devuelve. JOBF (entrada) CHARACTER*1 Especifica si se debe almacenar información necesaria para el postprocesamiento (por ejemplo, para calcular vectores de Ritz refinados). 'R' :: La matriz necesaria para el refinamiento de los vectores de Ritz se calcula y se almacena en la matriz B. Consulte la descripción de B. 'E' :: Los autovectores no escalados del DMD exacto se calculan y se devuelven en la matriz B. Consulte la descripción de B. 'N' :: No se calcula ningún dato de refinamiento de autovectores. Para ser útil a la salida, esta opción necesita JOBQ='Q'. WHTSVD (entrada) INTEGER, WHSTVD en { 1, 2, 3, 4 } Permite la selección del algoritmo SVD de la biblioteca LAPACK. 1 :: SGESVD (el algoritmo QR SVD) 2 :: SGESDD (el algoritmo Divide and Conquer; si hay suficiente espacio de trabajo disponible, esta es la opción más rápida) 3 :: SGESVDQ (el SVD QR precondicionado; esta y la 4 son las opciones más precisas) 4 :: SGEJSV (el SVD Jacobi precondicionado; esta y la 3 son las opciones más precisas) Para los cuatro métodos anteriores, es posible una diferencia significativa en la precisión de los valores singulares pequeños si las instantáneas varían en norma de manera que X esté severamente mal condicionada. Si los valores singulares pequeños (menores que EPS*||X||) son de interés y JOBS=='N', entonces las opciones (3, 4) dan los resultados más precisos, donde la opción 4 es ligeramente mejor y con un trasfondo teórico más sólido. Si JOBS=='S', es decir, las columnas de X se normalizan, entonces todos los métodos dan resultados casi igualmente precisos. M (entrada) INTEGER, M >= 0 La dimensión del espacio de estados (el número de filas de F). N (entrada) INTEGER, 0 <= N <= M El número de instantáneas de datos de una sola trayectoria, tomadas en tiempos discretos equidistantes. Este es el número de columnas de F. F (entrada/salida) REAL(KIND=WP) array M-por-N > A la entrada, las columnas de F son la secuencia de instantáneas de datos de una sola trayectoria, tomadas en tiempos discretos equidistantes. Se asume que las normas de las columnas de F están en el rango de los números de punto flotante normalizados. < A la salida, Si JOBQ == 'Q', la matriz F contiene la matriz ortogonal/factor de la factorización QR de la matriz de instantáneas de datos inicial F. Consulte la descripción de JOBQ. Si JOBQ == 'N', las entradas en F estrictamente debajo de la diagonal principal contienen, columna a columna, la información sobre los vectores de Householder, tal como los devuelve SGEQRF. La información restante para restaurar la matriz ortogonal de la factorización QR inicial se almacena en WORK(1:N). Consulte la descripción de WORK. LDF (entrada) INTEGER, LDF >= M La dimensión principal de la matriz F. X (espacio de trabajo/salida) REAL(KIND=WP) array MIN(M,N)-por-(N-1) X se utiliza como espacio de trabajo para contener representaciones de las N-1 instantáneas principales en la base ortonormal calculada en la factorización QR de F. A la salida, las columnas principales K de X contienen los K vectores singulares izquierdos principales del contenido descrito anteriormente de X. Para elevarlos al espacio de los vectores singulares izquierdos U(:,1:K) de los datos de entrada, multiplique previamente con el factor Q de la factorización QR inicial. Consulte las descripciones de F, K, V y Z. LDX (entrada) INTEGER, LDX >= N La dimensión principal de la matriz X. Y (espacio de trabajo/salida) REAL(KIND=WP) array MIN(M,N)-por-(N-1) Y se utiliza como espacio de trabajo para contener representaciones de las N-1 instantáneas finales en la base ortonormal calculada en la factorización QR de F. A la salida, Si JOBT == 'R', Y contiene el factor triangular superior MIN(M,N)-por-N de la factorización QR de la matriz de instantáneas de datos F. LDY (entrada) INTEGER, LDY >= N La dimensión principal de la matriz Y. NRNK (entrada) INTEGER Determina el modo de cálculo del rango numérico, es decir, cómo truncar los valores singulares pequeños de la matriz de entrada X. A la entrada, si NRNK = -1 :: el i-ésimo valor singular sigma(i) se trunca si sigma(i) <= TOL*sigma(1) Esta opción es recomendada. NRNK = -2 :: el i-ésimo valor singular sigma(i) se trunca si sigma(i) <= TOL*sigma(i-1) Esta opción se incluye con fines de I+D. Requiere una SVD de alta precisión, que puede no ser factible. El rango numérico se puede forzar utilizando un valor positivo de NRNK de la siguiente manera: 0 < NRNK <= N-1 :: se utilizarán como máximo NRNK valores singulares más grandes. Si el número de valores singulares distintos de cero calculados es menor que NRNK, entonces solo se utilizarán esos valores distintos de cero y la dimensión realmente utilizada será menor que NRNK. El número real de valores singulares distintos de cero se devuelve en la variable K. Consulte la descripción de K. TOL (entrada) REAL(KIND=WP), 0 <= TOL < 1 La tolerancia para truncar valores singulares pequeños. Consulte la descripción de NRNK. K (salida) INTEGER, 0 <= K <= N La dimensión de la base SVD/POD para las N-1 instantáneas de datos principales (columnas de F) y el número de pares de Ritz calculados. El valor de K se determina según la regla establecida por los parámetros NRNK y TOL. Consulte las descripciones de NRNK y TOL. REIG (salida) REAL(KIND=WP) array (N-1)-por-1 Las K entradas principales (K<=N) de REIG contienen las partes reales de los valores propios calculados REIG(1:K) + sqrt(-1)*IMEIG(1:K). Consulte las descripciones de K, IMEIG, Z. IMEIG (salida) REAL(KIND=WP) array (N-1)-por-1 Las K entradas principales (K<N) de REIG contienen las partes imaginarias de los valores propios calculados REIG(1:K) + sqrt(-1)*IMEIG(1:K). Los valores propios se determinan de la siguiente manera: Si IMEIG(i) == 0, entonces el valor propio correspondiente es real, LAMBDA(i) = REIG(i). Si IMEIG(i)>0, entonces el par de valores propios conjugados complejos correspondiente es LAMBDA(i) = REIG(i) + sqrt(-1)*IMAG(i) LAMBDA(i+1) = REIG(i) - sqrt(-1)*IMAG(i) Es decir, los pares conjugados complejos tienen índices consecutivos (i,i+1), con la parte imaginaria positiva listada primero. Consulte las descripciones de K, REIG, Z. Z (espacio de trabajo/salida) REAL(KIND=WP) array M-por-(N-1) Si JOBZ =='V' entonces Z contiene vectores de Ritz reales de la siguiente manera: Si IMEIG(i)=0, entonces Z(:,i) es un autovector del i-ésimo valor de Ritz. Si IMEIG(i) > 0 (y IMEIG(i+1) < 0) entonces [Z(:,i) Z(:,i+1)] abarcan un subespacio invariante y los valores de Ritz extraídos de este subespacio son REIG(i) + sqrt(-1)*IMEIG(i) y REIG(i) - sqrt(-1)*IMEIG(i). Los autovectores correspondientes son Z(:,i) + sqrt(-1)*Z(:,i+1) y Z(:,i) - sqrt(-1)*Z(:,i+1), respectivamente. Si JOBZ == 'F', entonces las descripciones anteriores se aplican a las columnas de Z*V, donde las columnas de V son los autovectores del cociente de Rayleigh K-por-K, y Z es ortonormal. Las columnas de V tienen una estructura similar: Si IMEIG(i) == 0 entonces Z*V(:,i) es un autovector, y si IMEIG(i) > 0 entonces Z*V(:,i)+sqrt(-1)*Z*V(:,i+1) y Z*V(:,i)-sqrt(-1)*Z*V(:,i+1) son los autovectores de LAMBDA(i), LAMBDA(i+1). Consulte las descripciones de REIG, IMEIG, X y V. LDZ (entrada) INTEGER, LDZ >= M La dimensión principal de la matriz Z. RES (salida) REAL(KIND=WP) array (N-1)-por-1 RES(1:K) contiene los residuos de los K pares de Ritz calculados. Si LAMBDA(i) es real, entonces RES(i) = || A * Z(:,i) - LAMBDA(i)*Z(:,i))||_2. Si [LAMBDA(i), LAMBDA(i+1)] es un par conjugado complejo entonces RES(i)=RES(i+1) = || A * Z(:,i:i+1) - Z(:,i:i+1) *B||_F donde B = [ real(LAMBDA(i)) imag(LAMBDA(i)) ] [-imag(LAMBDA(i)) real(LAMBDA(i)) ]. Se cumple que RES(i) = || A*ZC(:,i) - LAMBDA(i) *ZC(:,i) ||_2 RES(i+1) = || A*ZC(:,i+1) - LAMBDA(i+1)*ZC(:,i+1) ||_2 donde ZC(:,i) = Z(:,i) + sqrt(-1)*Z(:,i+1) ZC(:,i+1) = Z(:,i) - sqrt(-1)*Z(:,i+1) Consulte la descripción de Z. B (salida) REAL(KIND=WP) array MIN(M,N)-por-(N-1). SI JOBF =='R', B(1:N,1:K) contiene A*U(:,1:K), y puede utilizarse para calcular los vectores refinados; consulte más detalles en las referencias proporcionadas. Si JOBF == 'E', B(1:N,1;K) contiene A*U(:,1:K)*W(1:K,1:K), que son los vectores del DMD exacto, hasta el escalado por los inversos de los valores propios. En ambos casos, el contenido de B se puede elevar a la dimensión original de los datos de entrada multiplicando previamente con el factor Q de la factorización QR inicial. Aquí A denota una compresión del operador subyacente. Consulte las descripciones de F y X. Si JOBF =='N', entonces B no se referencia. LDB (entrada) INTEGER, LDB >= MIN(M,N) La dimensión principal de la matriz B. V (espacio de trabajo/salida) REAL(KIND=WP) array (N-1)-por-(N-1) A la salida, V(1:K,1:K) contiene los K autovectores del cociente de Rayleigh. Los autovectores de un par conjugado complejo de valores propios se devuelven en forma real como se explica en la descripción de Z. Los vectores de Ritz (devueltos en Z) son el producto de X y V; consulte las descripciones de X y Z.

NAME

sgedmdq — computes the singular value decomposition (SVD) of a submatrix, or the SVD of a general matrix with a matrix pencil.

SYNOPSIS

SUBROUTINE SGEDMDQ(
     JOBV, JOBQ, JOBZ, M, N, K, F, LD F, V, LDV, S, LDS, WORK, LWORK, IWORK, LIWORK, INFO
    )
CHARACTER(LEN=1) JOBV, JOBQ, JOBZ
INTEGER M, N, K, LDF, LDV, LDS, LWORK, LIWORK, INFO
REAL(KIND=WP) F( LDF, * ), V( LDV, * ), S( LDS, * ), WORK( * )
INTEGER IWORK( * )

Function/Subroutine Documentation

Parameters

JOBV
CHARACTER(LEN=1).

Specifies whether to compute the singular vectors V.

  • JOBV = 'N': do not compute V.
  • JOBV = 'V': compute V from the SVD of F.
JOBQ
CHARACTER(LEN=1).

Specifies whether to compute the singular vectors U.

  • JOBQ = 'N': do not compute U.
  • JOBQ = 'Q': compute U from the SVD of F.
JOBZ
CHARACTER(LEN=1).

Specifies whether to compute the eigenvalue decomposition of S*S or S*S**T.

  • JOBZ = 'N': the array S is not used.
  • JOBZ = 'V': the array S is used for the matrix Rayleigh quotient. This content is overwritten during the eigenvalue decomposition by SGEEV.
  • JOBZ = 'F': the array S is used for the matrix Rayleigh quotient. This content is overwritten during the eigenvalue decomposition by SGEEV.
M
INTEGER.

The number of rows of the matrix F.

M >= 0.

N
INTEGER.

The number of columns of the matrix F.

N >= 0.

K
INTEGER.

The number of columns of the matrix F(1:M,1:K) which are used to compute the SVD. K must be less than N.

0 <= K <= N

On output, K is set to MIN(M,N).

F
REAL(KIND=WP) F(LDF, *).

The input M-by-N matrix.

On exit, F is overwritten by the elementary reflectors which represent the matrix V.

LDF
INTEGER.

The leading dimension of the array F.

LDF >= MAX(1,M).

V
REAL(KIND=WP) V(LDV, *).

The (N-1)-by-(N-1) matrix V.

If JOBV = 'V', V contains the singular vectors of F(1:M,1:N-1).

LDV
INTEGER.

The leading dimension of the array V.

LDV >= N-1.

S
REAL(KIND=WP) S(LDS, *).

The array S(1:K,1:K) is used for the matrix Rayleigh quotient. This content is overwritten during the eigenvalue decomposition by SGEEV.

See the description of K.

LDS
INTEGER.

The leading dimension of the array S.

LDS >= N-1.

WORK
REAL(KIND=WP) WORK(LWORK).

On exit,

WORK(1:MIN(M,N)) contains the scalar factors of the elementary reflectors as returned by SGEQRF of the M-by-N input matrix F.

WORK(MIN(M,N)+1:MIN(M,N)+N-1) contains the singular values of the input submatrix F(1:M,1:N-1).

If the call to SGEDMDQ is only workspace query, then WORK(1) contains the minimal workspace length and WORK(2) is the optimal workspace length. Hence, the length of work is at least 2.

See the description of LWORK.

LWORK
INTEGER.

The minimal length of the workspace vector WORK.

LWORK is calculated as follows:

Let MLWQR = N (minimal workspace for SGEQRF[M,N])

MLWDMD = minimal workspace for SGEDMD (see the description of LWORK in SGEDMD) for snapshots of dimensions MIN(M,N)-by-(N-1)

MLWMQR = N (minimal workspace for SORMQR['L','N',M,N,N])

MLWGQR = N (minimal workspace for SORGQR[M,N,N])

Then

LWORK = MAX(N+MLWQR, N+MLWDMD)

is updated as follows:

if JOBZ == 'V' or JOBZ == 'F' THEN

LWORK = MAX( LWORK, MIN(M,N)+N-1 +MLWMQR )

if JOBQ == 'Q' THEN

LWORK = MAX( LWORK, MIN(M,N)+N-1+MLWGQR)

If on entry LWORK = -1, then a workspace query is assumed and the procedure only computes the minimal and the optimal workspace lengths for both WORK and IWORK. See the descriptions of WORK and IWORK.

IWORK
INTEGER IWORK(LIWORK).

Workspace that is required only if WHTSVD equals 2, 3 or 4. (See the description of WHTSVD).

If on entry LWORK =-1 or LIWORK=-1, then the minimal length of IWORK is computed and returned in IWORK(1). See the description of LIWORK.

LIWORK
INTEGER.

The minimal length of the workspace vector IWORK.

If WHTSVD == 1, then only IWORK(1) is used; LIWORK >=1

Let M1=MIN(M,N), N1=N-1. Then

If WHTSVD == 2, then LIWORK >= MAX(1,8*MIN(M1,N1))

If WHTSVD == 3, then LIWORK >= MAX(1,M1+N1-1)

If WHTSVD == 4, then LIWORK >= MAX(3,M1+3*N1)

If on entry LIWORK = -1, then a workspace query is assumed and the procedure only computes the minimal and the optimal workspace lengths for both WORK and IWORK. See the descriptions of WORK and IWORK.

INFO
INTEGER.

On exit, INFO contains:

-i < 0 :: On entry, the i-th argument had an illegal value

= 0 :: Successful return.

= 1 :: Void input. Quick exit (M=0 or N=0).

= 2 :: The SVD computation of X did not converge. Suggestion: Check the input data and/or repeat with different WHTSVD.

= 3 :: The computation of the eigenvalues did not converge.

= 4 :: If data scaling was requested on input and the procedure found inconsistency in the data such that for some column index i,

X(:,i) = 0 but Y(:,i) /= 0, then Y(:,i) is set to zero if JOBS=='C'. The computation proceeds with original or modified data and warning flag is set with INFO=4.
