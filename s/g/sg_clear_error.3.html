sg_set_error(3) sg_set_error(3)

NOMBRE

sg_set_error, sg_set_error_with_errno, sg_set_error_with_errno_code, sg_clear_error - establece la condición de error

SINOPSIS

#include <statgrab.h>


sg_error sg_set_error
(sg_error code, const char *arg);


sg_error sg_set_error_with_errno
(sg_error code, const char *arg);


sg_error sg_set_error_with_errno_code
(sg_error code, const char *arg, int errno_value);


void sg_clear_error
(void);

DESCRIPCIÓN

sg_set_error() establece la condición de error ocurrida junto con un argumento. El argumento suele ser descriptivo, por ejemplo, el nombre del archivo que no se pudo abrir.

sg_set_error_with_errno() establece la condición de error ocurrida junto con un argumento y el valor de la variable errno de las bibliotecas del sistema. El argumento suele ser descriptivo, por ejemplo, el nombre de la llamada sysctl() fallida.

sg_set_error_with_errno_code() establece la condición de error ocurrida junto con un argumento y un valor de error de una llamada a una biblioteca del sistema que no establece el valor errno (por ejemplo, las llamadas pthread_*). El argumento suele ser descriptivo, por ejemplo, el nombre del mutex que no se pudo bloquear.

sg_clear_error() borra la condición de error actual.
