DESCRIPCIÓN

Estas son las categorías de datos entregadas por el módulo de estadísticas de CPU: sg_get_cpu_stats() y sg_get_cpu_stats_r() entregan contadores de CPU nativos desde que la máquina se inició, sg_get_cpu_stats_diff() y sg_get_cpu_stats_diff_between() entregan contadores de CPU nativos entre dos llamadas a sg_get_cpu_stats() y sg_get_cpu_percents_of() y sg_get_cpu_percents_r() entregan contadores relativos correlacionados de CPU (donde el total es 100%).

Atajo de API

función retorna propietario de los datos
sg_get_cpu_stats sg_cpu_stats * libstatgrab (local del hilo)
sg_get_cpu_stats_r sg_cpu_stats * llamador
sg_get_cpu_stats_diff sg_cpu_stats * libstatgrab (local del hilo)
sg_get_cpu_stats_diff_between sg_cpu_stats * llamador
sg_get_cpu_percents_of sg_cpu_percents * libstatgrab (local del hilo)
sg_get_cpu_percents_r sg_cpu_percents * llamador

El búfer sg_cpu_stats recibido de sg_get_cpu_stats_r() y el sg_get_cpu_stats_diff_between(), así como el búfer sg_cpu_percents recibido de sg_get_cpu_percents_r(), deben ser liberados usando sg_free_cpu_stats() o sg_free_cpu_percents(), respectivamente, cuando ya no sean necesarios. El llamador es responsable de hacerlo.

El valor almacenado (los "ticks") variará entre sistemas operativos. Por ejemplo, Solaris tiene un total de 100 por segundo, mientras que Linux tiene sustancialmente más. Además, diferentes sistemas operativos almacenan información diferente; no encontrarás cpu nice en Solaris, por ejemplo.

Los sistemas modernos deberán proporcionar información sobre la resolución de los ticks del reloj invocando sysconf(_SC_CLK_TCK).

VALORES DE RETORNO

Hay dos estructuras devueltas por las funciones de estadísticas de CPU.

typedef struct {
        unsigned long long user;
        unsigned long long kernel;
        unsigned long long idle;
        unsigned long long iowait;
        unsigned long long swap;
        unsigned long long nice;
        unsigned long long total;
        unsigned long long context_switches;
        unsigned long long voluntary_context_switches;
        unsigned long long involuntary_context_switches;
        unsigned long long syscalls;
        unsigned long long interrupts;
        unsigned long long soft_interrupts;
        time_t systime;
} sg_cpu_stats;

typedef struct {
        double user;
        double kernel;
        double idle;
        double iowait;
        double swap;
        double nice;
        time_t time_taken;
} sg_cpu_percents;
user kernel idle iowait swap nice total
Los diferentes estados de la CPU.
context_switches voluntary_context_switches involuntary_context_switches syscalls interrupts soft_interrupts
Las diferentes acciones del programa en la CPU.
systime time_taken
El tiempo tomado en segundos desde la última llamada a la función, o el tiempo del sistema.
