NOMBRE

sg_get_config - envía el comando SCSI GET CONFIGURATION (MMC-4 +)

SINOPSIS

sg_get_config [--breve] [--actual] [--ayuda] [--hex] [--hex-interior] [--lista] [--crudo] [--lectura-solo] [--rt=RT] [--inicio=FC] [--verboso] [--version] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI GET CONFIGURATION a DISPOSITIVO y decodifica la respuesta. La respuesta incluye las características y perfiles del dispositivo. Típicamente, estos dispositivos son reproductores de CD, DVD, HD-DVD y BD que pueden (pero no necesariamente) tener medios en ellos. Estos dispositivos pueden estar conectados a través de transportes ATAPI, USB o IEEE 1394. En tales casos, son dispositivos "SCSI" solo en el sentido de que utilizan el conjunto de comandos "Multi-Media command" (MMC). MMC es un conjunto de comandos SCSI especializado cuya definición se puede encontrar en https://www.t10.org .

Esta utilidad se basa en los estándares borradores MMC-4 y posteriores. Consulte la sección 5 sobre "Características y Perfil para dispositivos Multi_Media" para obtener más información sobre parámetros de características y perfiles específicos. El manual del producto del fabricante también puede ser útil.

Dado que las grabadoras de DVD y BD modernas admiten muchas características y perfiles, la salida decodificada de esta utilidad puede ser grande. Hay varias formas de reducir la salida. Si se utiliza la opción --breve, solo se muestran los nombres de las características y los parámetros de las características no se decodifican. Alternativamente, si solo una característica es de interés, esta combinación de opciones es apropiada: "--rt=2 --inicio=FC". Otra posibilidad es mostrar solo las características que son relevantes para los medios en la unidad (es decir, "actuales") con la opción "--rt=1".

OPCIONES

Los argumentos para opciones largas son obligatorios también para las opciones cortas.

-b, --breve
muestra los nombres de las características pero no decodifica los parámetros de esas características. Cuando se usa con --lista, muestra los nombres de las características conocidas pero no los nombres de los perfiles conocidos.
-c, --actual
muestra las características marcadas como actuales. Esta opción es equivalente a '--rt=1'.
-h, --ayuda
muestra el mensaje de uso y luego sale.
-H, --hex
muestra la respuesta en hexadecimal (no decodifica la respuesta).
-i, --hex-interior
decodifica hasta el nivel del nombre de la característica y luego muestra los datos de cada característica en hexadecimal.
-l, --lista
lista todos los nombres de características y perfiles conocidos. Ignora el nombre del dispositivo (si se proporciona). Simplemente lista los nombres de las características y perfiles (seguidos de sus valores hexadecimales) que esta utilidad conoce. Si --breve también se proporciona, entonces solo se listan los nombres de las características.
-q, --lectura-solo
abre el DISPOSITIVO en modo de solo lectura en lugar de lectura-escritura, que es el valor predeterminado. El controlador sg de Linux necesita acceso de lectura-escritura para el comando SCSI GET CONFIGURATION, pero otros métodos de acceso pueden requerir acceso de solo lectura.
-r, --rt=RT
donde RT es el campo de ese nombre en el cdb GET CONFIGURATION. Los valores permitidos son 0, 1, 2 o 3. La acción del comando también depende del valor dado a la opción --inicio=FC. El valor predeterminado es 0. Cuando RT es 0, se devuelven todas las características, independientemente de su actualidad (cuyo código de característica sea mayor o igual a FC dado a --inicio=). Cuando RT es 1, se devuelven todas las características actuales (cuyo código de característica sea mayor o igual a FC). Cuando RT es 2, se devuelve la característica cuyo código de característica es igual a FC, si existe. Cuando RT es 3, la respuesta está reservada (probablemente genere un error de "campo ilegal en cdb"). Para simplificar los significados de los valores de RT son:
0 : todas las características, actuales o no
1 : solo características actuales
2 : solo la característica cuyo código es FC
3 : reservado
-R, --crudo
muestra la respuesta en binario (a stdout). Tenga en cuenta que la forma corta es -R, a diferencia de la mayoría de las otras utilidades de este paquete que usan -r para esta acción.
-s, --inicio=FC
donde FC es el valor del código de característica. Esta opción funciona estrechamente con la opción --rt=RT. El valor FC está en el rango de 0 a 65535 (0xffff) inclusive. Su valor predeterminado es 0. Un valor prefijado con "0x" (o una 'h' al final) se interpreta como hexadecimal.
-v, --verboso
aumenta el nivel de verbosidad (es decir, salida de depuración).
-V, --version
imprime la cadena de versión y luego sale.

NOTAS

Existen múltiples versiones de los estándares (borradores) de MMC: MMC [1997], MMC-2 [2000], MMC-3 [2002], MMC-4 y MMC-5. Los tres primeros son ahora estándares ANSI INCITS con el año en que se convirtieron en estándares entre paréntesis. El borrador inmediatamente anterior a la estandarización se puede encontrar en https://www.t10.org . En el estándar MMC inicial no había comando GET CONFIGURATION y la información relevante se obtenía de la "página de modo de capacidades de CD y estado mecánico" (página de modo 0x2a). Más tarde se renombró a "página de modo de capacidades MM y estado mecánico" y se ha quedado obsoleta en MMC-4 y MMC-5. El comando GET CONFIGURATION se introdujo en MMC-2 y se ha convertido en un reemplazo para esa página de modo. Las nuevas características, como el soporte para medios "BD" (blue ray), solo se pueden encontrar utilizando el comando GET CONFIGURATION. Por lo tanto, los reproductores de CD más antiguos pueden no admitir el comando GET CONFIGURATION, en cuyo caso se puede verificar la página de modo "Capacidades MM..." con sdparm(8), sginfo(8) o sg_modes(8).

En la serie 2.4 de los kernels de Linux, el DISPOSITIVO debe ser un dispositivo genérico SCSI (sg). En la serie 2.6, también se pueden especificar dispositivos de bloque. Por ejemplo, "sg_get_config /dev/hdc" funcionará en los kernels de la serie 2.6 siempre que /dev/hdc sea un dispositivo ATAPI. En la serie 2.6 los grabadores de DVD externos conectados a través de USB se pueden consultar con "sg_get_config /dev/scd1", por ejemplo.

ESTADO DE SALIDA

El estado de salida de sg_get_config es 0 cuando tiene éxito. De lo contrario, consulte la página del manual de sg3_utils(8).

NOMBRE

sg_get_config - Obtener la configuración de un dispositivo SCSI.

SINOPSIS

sg_get_config [--cmdenq=ACTION] [--descriptor=DESC] [--extended=ARG] [--help] [--hex] [--inquiry=INQUIRY] [--len=LEN] [--page=PG] [--save] [--verbose=LEVEL] [--version] DEVICE

DESCRIPCIÓN

Este programa envía un comando SCSI MODE SENSE (directo o en modo 6) al dispositivo especificado por DEVICE y muestra la información de configuración recuperada.

Los dispositivos SCSI que soportan el comando MODE SENSE también suelen soportar el comando MODE SELECT. El comando MODE SENSE se utiliza para recuperar parámetros de configuración (o "páginas de control") de un dispositivo SCSI. Estas páginas de control son específicas de cada dispositivo.

Por defecto, este programa envía un comando MODE SENSE (en modo 10) para obtener la página de control 0x3f (información de dispositivo).

OPCIONES

--cmdenq=ACTION
Envía el comando directamente en lugar de usar el comando SCSI PASS THROUGH. Los valores de ACTION son "direct" y "queued". "direct" es el valor por defecto.
--descriptor=DESC
Establece el bit LLBAA (Logical Block Address) en la cabecera del modo. Si se establece, la cabecera del modo contendrá una dirección de bloque lógico. DESC debe ser un entero entre 0 y 255.
--extended=ARG
Establece el bit de página extendida en la cabecera del modo. ARG debe ser un entero entre 0 y 255.
--help
Imprime la información de ayuda y sale.
--hex
Imprime la salida en formato hexadecimal.
--inquiry=INQUIRY
Establece el campo INQUIRY del modo. INQUIRY debe ser un entero entre 0 y 255.
--len=LEN
Establece la longitud de la solicitud de modo. LEN debe ser un entero entre 0 y 65535. Por defecto es 255.
--page=PG
Especifica la página de control que se va a consultar. PG puede ser un número entero o un código hexadecimal precedido por "0x". Si no se especifica, la página 0x3f se utiliza por defecto.
--save
Guarda los parámetros de control en el dispositivo.
--verbose=LEVEL
Establece el nivel de verbosidad. LEVEL puede ser un entero entre 0 y 4.
--version
Imprime la información de la versión y sale.

NOTAS

Este programa se puede utilizar para consultar y, opcionalmente, modificar los parámetros de configuración de un dispositivo SCSI. Por ejemplo, se puede utilizar para ajustar la configuración de caché, las opciones de error, etc.

El uso del bit --save sin especificar una página de control guardará la configuración actual en la página 0x3f.

ESTADO DE SALIDA

Devuelve 0 si la operación fue exitosa, o un código de error en caso contrario.
