Documentación de Función/Subrutina

subroutine sgemlq (character side, character trans, integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) t, integer tsize, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer lwork, integer info)

SGEMLQ

Propósito:

!>
!>     SGEMLQ sobrescribe la matriz real general M por N, C, con
!>
!>                    SIDE = 'L'     SIDE = 'R'
!>    TRANS = 'N':      Q * C          C * Q
!>    TRANS = 'T':      Q**T * C       C * Q**T
!>    donde Q es una matriz real ortogonal definida como el producto
!>    de reflectores elementales en bloque calculados por la
!>    factorización LQ corta y ancha (SGELQ).
!>
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**T desde la Izquierda;
!>          = 'R': aplicar Q o Q**T desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transposición, aplicar Q;
!>          = 'T':  Transpuesta, aplicar Q**T.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >=0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A es un array REAL, de dimensión
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          Parte de la estructura de datos para representar Q tal como la devuelve SGELQ.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,K).
!>

T

!>          T es un array REAL, de dimensión (MAX(5,TSIZE)).
!>          Parte de la estructura de datos para representar Q tal como la devuelve SGELQ.
!>

TSIZE

!>          TSIZE es INTEGER
!>          La dimensión del array T. TSIZE >= 5.
!>

C

!>          C es un array REAL, de dimensión (LDC,N)
!>          En la entrada, la matriz M por N, C.
!>          En la salida, C es sobrescrita por Q*C o Q**T*C o C*Q**T o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          (espacio de trabajo) array DOUBLE PRECISION, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK mínimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo. La rutina
!>          solo calcula el tamaño del array WORK, devuelve este
!>          valor como WORK(1), y XERBLA no emite ningún mensaje de error relacionado con WORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

!>  la factorización LQ.
!>  Esta versión de SGEMLQ usará SLAMSWLQ o SGEMLQT para
!>  multiplicar la matriz Q por otra matriz.
