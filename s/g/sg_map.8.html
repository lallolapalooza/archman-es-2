NOMBRE

sg_map - muestra el mapeo entre dispositivos sg de Linux y otros dispositivos SCSI

SINOPSIS

sg_map [-a] [-h] [-i] [-n] [-scd] [-sd] [-sr] [-st] [-V] [-x]

DESCRIPCIÓN

A veces resulta difícil determinar a qué dispositivo SCSI se refiere un nombre de dispositivo sg (por ejemplo, /dev/sg0). Este comando recorre los dispositivos sg y encuentra el nombre del dispositivo de disco, cdrom o cinta SCSI correspondiente (si existe). Los escáneres son un ejemplo de dispositivos SCSI que no tienen un nombre de dispositivo SCSI alternativo aparte de su nombre de dispositivo sg.

Esta utilidad está obsoleta y no ha sido actualizada en años; solo se corregirán errores muy obvios. A menos que se esté utilizando una versión muy antigua de Linux (por ejemplo, serie 2.4 o anterior), utilice una utilidad como lsscsi(8) o las facilidades que ofrece udev(8).

OPCIONES

-a
asume que los dispositivos sg tienen nombres de dispositivo alfabéticos y recorre /dev/sga, /dev/sgb, etc. El valor predeterminado es el escaneo numérico. Tenga en cuenta que los nodos de dispositivo sg con un índice alfabético están obsoletos desde la serie 2.2 del kernel de Linux.
-h
imprime el mensaje de uso y sale.
-i
además, realiza una consulta INQUIRY estándar y muestra las cadenas de proveedor, producto y revisión para los dispositivos encontrados.
-n
asume que los dispositivos sg tienen nombres de dispositivo numéricos y recorre /dev/sg0, /dev/sg1, etc. El valor predeterminado es el escaneo numérico.
-scd
muestra mapeos a nombres de dispositivo cdrom SCSI de la forma /dev/scd0, /dev/scd1, etc.
-sd
muestra mapeos a nombres de dispositivo de disco SCSI.
-sr
muestra mapeos a nombres de dispositivo cdrom SCSI de la forma /dev/sr0, /dev/sr1, etc.
-st
muestra mapeos a nombres de dispositivo de cinta SCSI.
-V
imprime la cadena de versión y sale (sin más preámbulos).
-x
después de cada nombre de dispositivo sg activo, hay cinco dígitos: <número_host> <bus> <id_scsi> <lun> <tipo_scsi>

NOTAS

Si no se proporcionan opciones que comiencen con "-s", se muestra el mapeo a todos los nombres de dispositivo de disco, cdrom y cinta SCSI.

Si el sistema de archivos de dispositivos (devfs) está presente, se emite una línea que lo indica. La jerarquía scsi "nativa" de devfs facilita el establecimiento de la relación entre un nombre de dispositivo sg y cualquier nombre de dispositivo de disco, cdrom o cinta correspondiente. Esto reemplaza la necesidad de este comando. Sin embargo, muchas aplicaciones continuarán buscando nombres de dispositivo SCSI de Linux en sus ubicaciones tradicionales. [Devfs proporciona un demonio de compatibilidad llamado devfsd cuya configuración predeterminada vuelve a agregar los nombres de dispositivo de Linux en sus ubicaciones tradicionales.

Muy a menudo, la información de mapeo se puede derivar observando la salida del comando: "sg_map". Sin embargo, si se han agregado dispositivos desde el arranque, esto puede ser engañoso.

En la serie 2.6 del kernel de Linux, algo parecido al mapeo que muestra esta utilidad se puede encontrar analizando sysfs. La principal diferencia es que el análisis de sysfs mostrará el mapeo entre nodos sg y otros nodos de dispositivo SCSI en términos de números mayor y menor. Si bien el mayor 8, menor 16 generalmente será /dev/sdb, esto no es necesariamente así. Las facilidades asociadas con udev pueden asignar al mayor 8, menor 16 otro nombre de nodo de dispositivo. Esta versión de sg_map se ha ampliado para manejar nombres de nodos de dispositivo de disco dispersos de la forma "/dev/sd<str>" donde <str> puede ser uno de [a-z,aa-zz,aaa-zzz]. Consulte la utilidad sg_map26 para obtener una forma más precisa (es decir, menos escaneo de directorios) para mapear entre nombres de dispositivo sg y nombres de nivel superior; incluido el hallazgo de nombres definidos por el usuario.

Esta utilidad se escribió en un momento en que la conexión en caliente de dispositivos SCSI no era compatible con Linux. Utilizaba un algoritmo simple para escanear los nodos de dispositivo sg en orden numérico o alfabético ascendente, deteniéndose después de que hubiera 5 errores consecutivos.

En la serie 2.6 del kernel de Linux, esta utilidad utiliza sysfs para encontrar qué nodos de dispositivo sg están activos y solo los comprueba. Por lo tanto, puede haber grandes "agujeros" en la numeración de los nodos de dispositivo sg (por ejemplo, después de que se haya eliminado un adaptador) y aún así se listarán todos los nodos de dispositivo sg activos. Esta utilidad asume que los nodos de dispositivo sg se nombran utilizando las convenciones normales y busca desde /dev/sg0 hasta /dev/sg4095 inclusive.

EJEMPLOS

Mi sistema tiene un disco SCSI, un grabador de CD y un reproductor de DVD:
$ sg_map
# Nota: el sistema de archivos pseudo devfs está presente
/dev/sg0 /dev/sda
/dev/sg1 /dev/sr0
/dev/sg2 /dev/sr1

Para encontrar qué nombre de dispositivo sg corresponde al disco:
$ sg_map -sd
# Nota: el sistema de archivos pseudo devfs está presente
/dev/sg0 /dev/sda
/dev/sg1
/dev/sg2

La opción "-x" produce la siguiente salida:
sg_map -x
# Nota: el sistema de archivos pseudo devfs está presente
/dev/sg0 1 0 1 0 0 /dev/sda
/dev/sg1 2 0 4 0 5 /dev/sr0
/dev/sg2 2 0 6 0 5 /dev/sr1

Cuando se agrega un escáner SCSI, la salida se convierte en:
$ sg_map
# Nota: el sistema de archivos pseudo devfs está presente
/dev/sg0 /dev/sda
/dev/sg1 /dev/sr0
/dev/sg2 /dev/sr1
/dev/sg3

Por eliminación, /dev/sg3 debe ser el escáner.

ESTADO DE SALIDA

El estado de salida de sg_map es 0 cuando tiene éxito. De lo contrario, consulte la página del manual de sg3_utils(8).

NOMBRE

sg_map - Mapper de escaneo de SCSI para dispositivos de disco y CD-ROM

SINOPSIS

sg_map [OPTIONS]... [DEVICE]...

DESCRIPCIÓN

sg_map es una utilidad para listar y analizar los dispositivos de disco, CD-ROM y cinta que se encuentran en el sistema. La información se obtiene leyendo los archivos del directorio /proc/scsi/scsi.

OPCIONES

  • -d, --device=DEVICE: Especifica un dispositivo SCSI para examinar.
  • -h, --help: Muestra un mensaje de ayuda y sale.
  • -v, --verbose: Modo detallado. Muestra información adicional sobre los dispositivos.
  • -a, --all: Muestra todos los dispositivos, incluso los que no son de disco o CD-ROM (por ejemplo, cintas).
  • -c, --cdrom: Muestra solo los dispositivos CD-ROM.
  • -k, --keep-open: Mantiene los dispositivos abiertos al final del escaneo. Esto puede ser útil si se van a realizar otras operaciones en los mismos dispositivos.
  • -o, --output=FILE: Guarda la salida en el archivo especificado.
  • -p, --probe: Realiza una sondeo adicional de los dispositivos SCSI.
  • -s, --scsi-level: Muestra el nivel de SCSI de los dispositivos.
  • -t, --tape: Muestra solo los dispositivos de cinta.
  • -u, --unload: Descarga los dispositivos especificados.
  • -V, --version: Muestra la información de la versión y sale.

ESTADO DE SALIDA

0 si la operación fue exitosa, 1 si ocurrió un error.

EJEMPLOS

Listar todos los dispositivos de disco:

sg_map

Listar solo los dispositivos CD-ROM:

sg_map -c

Listar todos los dispositivos SCSI (incluyendo cintas) en modo detallado:

sg_map -av
