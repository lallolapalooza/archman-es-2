subrutina sget38 (real, dimension( 3 ) rmax, integer, dimension( 3 ) lmax, integer, dimension( 3 ) ninfo, integer knt, integer nin)

SGET38

Propósito:

!>
!> SGET38 prueba STRSEN, una rutina para estimar números de condición de un
!> cluster de valores propios y/o su subespacio invariante derecho asociado
!>
!> Las matrices de prueba se leen de un archivo con unidad lógica NIN.
!>

Parámetros

RMAX 
!>          RMAX es un array REAL, dimension (3)
!>          Valores de las ratios de prueba más grandes.
!>          RMAX(1) = residuos más grandes de SHST01 o comparando
!>                    llamadas diferentes a STRSEN
!>          RMAX(2) = error más grande en el recíproco de los números
!>                    de condición teniendo en cuenta su condicionamiento
!>          RMAX(3) = error más grande en el recíproco de los números
!>                    de condición no teniendo en cuenta su condicionamiento
!>                    (puede ser mayor que RMAX(2))
!>

LMAX

!>          LMAX es un array INTEGER, dimension (3)
!>          LMAX(i) es el número de ejemplo donde se logra la ratio de prueba
!>          más grande RMAX(i). También:
!>          Si SGEHRD devuelve INFO no nulo en el ejemplo i, LMAX(1)=i
!>          Si SHSEQR devuelve INFO no nulo en el ejemplo i, LMAX(2)=i
!>          Si STRSEN devuelve INFO no nulo en el ejemplo i, LMAX(3)=i
!>

NINFO

!>          NINFO es un array INTEGER, dimension (3)
!>          NINFO(1) = No. de veces que SGEHRD devolvió INFO no nulo
!>          NINFO(2) = No. de veces que SHSEQR devolvió INFO no nulo
!>          NINFO(3) = No. de veces que STRSEN devolvió INFO no nulo
!>

KNT

!>          KNT es INTEGER
!>          Número total de ejemplos probados.
!>

NIN

!>          NIN es INTEGER
!>          Número de unidad lógica de entrada.
!>
