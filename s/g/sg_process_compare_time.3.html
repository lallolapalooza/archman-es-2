DESCRIPCIÓN

Las funciones sg_get_process_stats proporcionan estadísticas sobre los procesos actualmente en ejecución. Ambas funciones, sg_get_process_stats() y sg_get_process_stats_r(), toman un parámetro opcional de entradas, que apunta (cuando se proporciona) a un size_t para obtener el número de entradas del vector devueltas.

Las funciones sg_get_process_count_of() y sg_get_process_count_r() proporcionan una vista agregada de la tabla de procesos: entregan la cantidad de procesos por estado de proceso. sg_get_process_count() es en realidad una macro preprocesador para compatibilidad hacia atrás y llama a sg_get_process_count_of() con el parámetro pcs de sg_entire_process_count para emular el comportamiento hasta la versión 0.17.

Atajo de API

función devuelve propietario de los datos
sg_get_process_stats sg_process_stats * libstatgrab (local del hilo)
sg_get_process_stats_r sg_process_stats * llamador
sg_get_process_count_of sg_process_count * libstatgrab (local del hilo)
sg_get_process_count_r sg_process_count * llamador

Los vectores de sg_process_stats recibidos de sg_get_process_stats_r() o los resúmenes de sg_process_count recibidos de sg_get_process_count_r() deben liberarse usando sg_free_process_stats() o sg_free_process_count(), respectivamente. El llamador es responsable de hacerlo cuando los datos ya no son necesarios.

sg_process_compare_time

Estas funciones comparan dos entradas de sg_process_stats y devuelven un int para representar cuál es mayor. El uso principal de estas funciones es ser pasadas a qsort para ordenar sg_process_stats por el tipo dado.

Ejemplo

size_t entries;
sg_process_stats *proc_stats = NULL;
while( NULL != ( proc_stats = sg_get_process_stats_r(&entries) ) ) {
    /* ordenar las entradas comparando el identificador del proceso */
    qsort( proc_stats, entries, sizeof(proc_stats[0]), &sg_process_compare_pid );
    show_proc_stats( proc_stats );
    sg_free_process_stats( proc_stats );
}

VALORES DE RETORNO

La estructura devuelta por sg_get_process_stats es de tipo sg_process_stats.

typedef struct {
        char *process_name;
        char *proctitle;
        pid_t pid;    /* identificador del proceso */
        pid_t parent; /* PID del padre */
        pid_t pgid;   /* PID del líder del grupo de procesos */
        pid_t sessid; /* ID de sesión del proceso al que pertenece */
        uid_t uid;
        uid_t euid;
        gid_t gid;
        gid_t egid;
        unsigned long long context_switches;
        unsigned long long voluntary_context_switches;
        unsigned long long involuntary_context_switches;
        unsigned long long proc_size; /* en bytes */
        unsigned long long proc_resident; /* en bytes */
        time_t start_time; /* Cuándo se inició el proceso */
        time_t time_spent; /* tiempo activo en segundos */
        double cpu_percent;
        int nice;
        sg_process_state state;
        time_t systime;
} sg_process_stats;

typedef enum {
        SG_PROCESS_STATE_RUNNING,
        SG_PROCESS_STATE_SLEEPING,
        SG_PROCESS_STATE_STOPPED,
        SG_PROCESS_STATE_ZOMBIE,
        SG_PROCESS_STATE_UNKNOWN
} sg_process_state;
process_name
El nombre del comando que se ejecutó. El contenido de este campo depende en gran medida del sistema operativo subyacente; algunos almacenan el nombre base del ejecutable que se pasa a la llamada del sistema exec(2), otros la ruta completa. La mayoría de los sistemas operativos restringen el tamaño de este campo; algunos, como la familia *BSD, a un valor muy bajo de 15 bytes.

Este campo suele ser inmutable para los procesos del espacio de usuario.

proctitle
La línea de comandos (el "título") del proceso. Tenga en cuenta que esto puede ser modificado por el proceso, por lo que no se garantiza que sea la línea de comandos original.
pid
El identificador del proceso.
parent
El identificador del proceso padre.
pgid
El identificador del proceso líder del grupo de procesos.
sessid
Identificador de la sesión a la que pertenece el proceso.
uid
El ID del usuario con el que se está ejecutando el proceso.
euid
El ID del usuario efectivo con el que se está ejecutando el proceso.
gid
El ID del grupo con el que se está ejecutando el proceso.
egid
El ID del grupo efectivo con el que se está ejecutando el proceso.
context_switches
El número de cambios de contexto de este proceso (voluntarios e involuntarios).
voluntary_context_switches
El número de cambios de contexto voluntarios de este proceso (por ejemplo, al llamar a sched_yield() o sleep()).
involuntary_context_switches
El número de cambios de contexto involuntarios de este proceso (por ejemplo, fin de la rebanada de tiempo o envío de señal).
proc_size
El tamaño de la memoria virtual del proceso en bytes.
proc_resident
El tamaño de la memoria residente (física) del proceso en bytes.
start_time
La hora en que se inició el proceso, según el formato time_t. Utilice gmtime(3) o localtime(3) para convertirlo a una estructura struct tm. O bien utilice ctime(3) para convertirlo a una cadena.
time_spent
El tiempo total que el proceso ha estado en ejecución (en segundos).
cpu_percent
El porcentaje de tiempo de CPU utilizado por este proceso.
nice
El valor de "nice" del proceso. Valores más bajos significan mayor prioridad.
state
El estado actual del proceso. Consulte sg_process_state.
systime
El tiempo que el proceso ha pasado en el modo de núcleo (kernel mode).

La estructura sg_process_count está definida como sigue:

typedef struct {
        sg_process_count_source source;
        unsigned long long running;
        unsigned long long sleeping;
        unsigned long long stopped;
        unsigned long long zombie;
        unsigned long long total;
} sg_process_count;
source
Indica desde dónde se obtuvieron los datos del proceso. Vea sg_process_count_source.
running
Número de procesos en estado SG_PROCESS_STATE_RUNNING.
sleeping
Número de procesos en estado SG_PROCESS_STATE_SLEEPING.
stopped
Número de procesos en estado SG_PROCESS_STATE_STOPPED.
zombie
Número de procesos en estado SG_PROCESS_STATE_ZOMBIE.
total
Número total de procesos.

Las funciones de comparación sg_process_compare_* devuelven un valor negativo si el primer argumento es menor que el segundo, cero si son iguales y un valor positivo si el primer argumento es mayor que el segundo.

Los comparadores sg_process_compare_pid, sg_process_compare_uid y sg_process_compare_gid reciben punteros a pid_t, uid_t y gid_t respectivamente. Los comparadores sg_process_compare_name, sg_process_compare_proctitle, sg_process_compare_size, sg_process_compare_res, sg_process_compare_cpu y sg_process_compare_time reciben punteros a sg_process_stats.

DESCRIPTION

These functions are used to compare two sg_process structures. They are intended to be used with the standard C library function qsort(3).

The sg_process structure is defined as:

typedef struct{
        unsigned long long total;
        unsigned long long running;
        unsigned long long sleeping;
        unsigned long long stopped;
        unsigned long long zombie;
        unsigned long long unknown;
        time_t systime;
}sg_process;
proc_resident
El tamaño del proceso que reside en memoria.
start_time
El momento en que el proceso ha sido iniciado en segundos desde la época.
time_spent
El número de segundos que el proceso ha estado ejecutándose (tiempo de usuario + sistema, sin el tiempo dedicado por procesos hijos).
cpu_percent
El porcentaje actual de CPU que está utilizando el proceso.
nice
El valor nice del proceso.
state
El estado actual del proceso. Ver sg_process_state para los valores permitidos.
systime
El tiempo en segundos desde la época del momento en que se creó la estadística presente. Este puede ser (pero no tiene por qué ser) el mismo momento para todas las entradas devueltas, independientemente de si se obtienen con una instantánea o se arman a partir de algún tipo de procfs.

La estructura devuelta por sg_get_process_count_of y sg_get_process_count_r es de tipo sg_process_count.

typedef enum sg_process_count_source {
        sg_entire_process_count,
        sg_last_process_count
} sg_process_count_source;

typedef struct{
        unsigned long long total;
        unsigned long long running;
        unsigned long long sleeping;
        unsigned long long stopped;
        unsigned long long zombie;
        unsigned long long unknown;
        time_t systime;
}sg_process_count;
total
El número total de procesos.
running
El número de procesos en ejecución.
sleeping
El número de procesos durmiendo.
stopped
El número de procesos detenidos.
zombie
El número de procesos zombie.
unknown
El número de procesos que no coinciden con ninguna de las categorías mencionadas anteriormente.
systime
El tiempo en segundos desde la época del momento en que se creó la estadística presente.

BUGS

La primera llamada a sg_get_process_count_of(sg_last_process_count) devolverá lo mismo que sg_get_process_count_of(sg_entire_process_count).

Las funciones de comparación existen más por compatibilidad hacia atrás que por mejoras de funcionalidad. La flexibilidad limitada (por ejemplo, orden inverso) y la falta de oportunidades de optimización para el compilador llevan a la recomendación de implementar las rutinas de comparación requeridas localmente.
