SGEEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE

Propósito:

!>
!> SGEEVX calcula para una matriz real N-por-N no simétrica A, los
!> valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos.
!>
!> Opcionalmente también, calcula una transformación de balanceo para mejorar
!> el condicionamiento de los valores propios y vectores propios (ILO, IHI,
!> SCALE y ABNRM), los recíprocos de los números de condición para los valores
!> propios (RCONDE), y los recíprocos de los números de condición para los
!> vectores propios derechos (RCONDV).
!>
!> El vector propio derecho v(j) de A satisface
!>                  A * v(j) = lambda(j) * v(j)
!> donde lambda(j) es su valor propio.
!> El vector propio izquierdo u(j) de A satisface
!>               u(j)**H * A = lambda(j) * u(j)**H
!> donde u(j)**H denota la transpuesta conjugada de u(j).
!>
!> Los vectores propios calculados se normalizan para tener una norma euclidiana
!> igual a 1 y el componente real más grande.
!>
!> Balancear una matriz significa permutar las filas y columnas para hacerla
!> más cercana a triangular superior, y aplicar una transformación de similitud
!> diagonal D * A * D**(-1), donde D es una matriz diagonal, para
!> hacer que sus filas y columnas tengan normas más cercanas y los números de
!> condición de sus valores propios y vectores propios sean menores. Los
!> recíprocos de los números de condición calculados corresponden a la matriz
!> balanceada. Las permutaciones de filas y columnas no cambiarán los números de
!> condición (en aritmética exacta), pero la escala diagonal sí lo hará. Para
!> una explicación más detallada del balanceo, véase la sección 4.10.2 de la
!> Guía del Usuario de LAPACK.
!>

Parámetros

BALANC 
!>          BALANC es CHARACTER*1
!>          Indica cómo la matriz de entrada debe ser escalada
!>          diagonalmente y/o permutada para mejorar el condicionamiento de sus
!>          valores propios.
!>          = 'N': No escalar ni permutar diagonalmente;
!>          = 'P': Realizar permutaciones para hacer la matriz más cercana a
!>                 triangular superior. No escalar diagonalmente;
!>          = 'S': Escalar la matriz diagonalmente, es decir, reemplazar A por
!>                 D*A*D**(-1), donde D es una matriz diagonal elegida
!>                 para hacer que las filas y columnas de A sean más iguales en
!>                 norma. No permutar;
!>          = 'B': Escalar diagonalmente y permutar A.
!>
!>          Los recíprocos de los números de condición calculados serán para la matriz
!>          después del balanceo y/o permutación. Las permutaciones no cambian
!>          los números de condición (en aritmética exacta), pero el balanceo sí.
!>

JOBVL

!>          JOBVL es CHARACTER*1
!>          = 'N': los vectores propios izquierdos de A no se calculan;
!>          = 'V': los vectores propios izquierdos de A se calculan.
!>          Si SENSE = 'E' o 'B', JOBVL debe ser 'V'.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N': los vectores propios derechos de A no se calculan;
!>          = 'V': los vectores propios derechos de A se calculan.
!>          Si SENSE = 'E' o 'B', JOBVR debe ser 'V'.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué recíprocos de números de condición se calculan.
!>          = 'N': No se calcula ninguno;
!>          = 'E': Calculado solo para valores propios;
!>          = 'V': Calculado solo para vectores propios derechos;
!>          = 'B': Calculado para valores propios y vectores propios derechos.
!>
!>          Si SENSE = 'E' o 'B', también deben calcularse los vectores propios
!>          izquierdos y derechos (JOBVL = 'V' y JOBVR = 'V').
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, la matriz A de N-por-N.
!>          En la salida, A ha sido sobrescrita. Si JOBVL = 'V' o
!>          JOBVR = 'V', A contiene la forma de Schur real de la
!>          versión balanceada de la matriz de entrada A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

WR

!>          WR es array REAL, dimension (N)
!>

WI

!>          WI es array REAL, dimension (N)
!>          WR y WI contienen las partes real e imaginaria,
!>          respectivamente, de los valores propios calculados. Los
!>          pares de valores propios conjugados complejos aparecerán consecutivamente
!>          con el valor propio con parte imaginaria positiva primero.
!>

VL

!>          VL es array REAL, dimension (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios izquierdos u(j) se almacenan uno
!>          después de otro en las columnas de VL, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVL = 'N', VL no se referencia.
!>          Si el j-ésimo valor propio es real, entonces u(j) = VL(:,j),
!>          la j-ésima columna de VL.
!>          Si el j-ésimo y (j+1)-ésimo valores propios forman un par
!>          conjugado complejo, entonces u(j) = VL(:,j) + i*VL(:,j+1) y
!>          u(j+1) = VL(:,j) - i*VL(:,j+1).
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es array REAL, dimension (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios derechos v(j) se almacenan uno
!>          después de otro en las columnas de VR, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVR = 'N', VR no se referencia.
!>          Si el j-ésimo valor propio es real, entonces v(j) = VR(:,j),
!>          la j-ésima columna de VR.
!>          Si el j-ésimo y (j+1)-ésimo valores propios forman un par
!>          conjugado complejo, entonces v(j) = VR(:,j) + i*VR(:,j+1) y
!>          v(j+1) = VR(:,j) - i*VR(:,j+1).
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR. LDVR >= 1; y si
!>          JOBVR = 'V', LDVR >= N.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI son valores enteros determinados cuando A fue
!>          balanceada. El A balanceado(i,j) = 0 si I > J y
!>          J = 1,...,ILO-1 o I = IHI+1,...,N.
!>

SCALE

!>          SCALE es array REAL, dimension (N)
!>          Detalles de las permutaciones y factores de escala aplicados
!>          al balancear A. Si P(j) es el índice de la fila y columna
!>          intercambiada con la fila y columna j, y D(j) es el factor de
!>          escala aplicado a la fila y columna j, entonces
!>          SCALE(J) = P(J),    para J = 1,...,ILO-1
!>                   = D(J),    para J = ILO,...,IHI
!>

NAME

sgeevx - Computes for the general complex matrix A the eigenvalues and, optionally, the left and right eigenvectors, and the condition numbers for the eigenvalues and eigenvectors.

SYNOPSIS

SUBROUTINE SGEEVX(
     CHARACTER*1        JOBVL, CHARACTER*1        JOBVR, CHARACTER*1        SENSE,
     INTEGER            N,
     REAL,              DIMENSION(*)             A,
     INTEGER            LDA,
     REAL,              DIMENSION(*)             WR,
     REAL,              DIMENSION(*)             WI,
     REAL,              DIMENSION(*)             VL,
     INTEGER            LDVL,
     REAL,              DIMENSION(*)             VR,
     INTEGER            LDVR,
     INTEGER            ILO,
     INTEGER            IHI,
     REAL               SCALE,
     REAL,              DIMENSION(*)             ABNRM,
     REAL,              DIMENSION(*)             RCONDE,
     REAL,              DIMENSION(*)             RCONDV,
     REAL,              DIMENSION(*)             WORK,
     INTEGER            LWORK,
     INTEGER,          DIMENSION(*)             IWORK,
     INTEGER            INFO )

Function/Subroutine Documentation

JOBVL

!>          JOBVL is CHARACTER*1
!>          = 'N':  no left eigenvectors are computed.
!>          = 'V':  the left eigenvectors are computed.
!>

JOBVR

!>          JOBVR is CHARACTER*1
!>          = 'N':  no right eigenvectors are computed.
!>          = 'V':  the right eigenvectors are computed.
!>

SENSE

!>          SENSE is CHARACTER*1
!>          = 'N':  none of the reciprocal condition numbers is computed.
!>          = 'E':  reciprocal condition number for selected eigenvalues only.
!>          = 'V':  reciprocal condition number for selected right eigenvectors only.
!>          = 'B':  both reciprocal condition numbers for selected eigenvalues
!>                  and selected right eigenvectors.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N).
!>          On entry, the n-by-n matrix A.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

WR

!>          WR is REAL array, dimension (N).
!>

WI

!>          WI is REAL array, dimension (N).
!>          On exit, the real and imaginary parts, respectively, of the
!>          eigenvalues. Each real eigenvalue is returned as a zero imaginary
!>          part, and each n*n complex conjugate pair of eigenvalues is
!>          returned as two consecutive real eigenvalues, w(i) and w(i+1),
!>          with w(i+1) = -w(i). WR(j) and WI(j) together represent the
!>          eigenvalue lambda(j).
!>

VL

!>          VL is REAL array, dimension (LDVL,N).
!>          If JOBVL = 'V', VL contains the left eigenvectors of A, with the
!>          j-th eigenvector in the j-th column of VL.
!>          If JOBVL = 'N', VL is not referenced.
!>

LDVL

!>          LDVL is INTEGER
!>          The leading dimension of the array VL.
!>          If JOBVL = 'V', then LDVL >= max(1,N).
!>

VR

!>          VR is REAL array, dimension (LDVR,N).
!>          If JOBVR = 'V', VR contains the right eigenvectors of A, with the
!>          j-th eigenvector in the j-th column of VR.
!>          If JOBVR = 'N', VR is not referenced.
!>

LDVR

!>          LDVR is INTEGER
!>          The leading dimension of the array VR.
!>          If JOBVR = 'V', then LDVR >= max(1,N).
!>

ILO

!>          ILO is INTEGER
!>          IHI is INTEGER
!>          IlO and IHI are integers such that in the array A, the complex
!>          eigenvalue is on the diagonal rows ILO to IHI. If A is nxn, then
!>          1 <= ILO <= IHI <= n.
!>          The computation of eigenvectors and condition numbers is restricted
!>          to this submatrix.
!>

SCALE

!>          SCALE is REAL
!>          The scaling factor computed by DLAMCH.
!>

ABNRM

!>          ABNRM is REAL
!>          The one-norm of the balanced matrix (the maximum
!>          of the sum of absolute values of elements of any column).
!>

RCONDE

!>          RCONDE is REAL array, dimension (N)
!>          RCONDE(j) is the reciprocal condition number of the j-th
!>          eigenvalue.
!>

RCONDV

!>          RCONDV is REAL array, dimension (N)
!>          RCONDV(j) is the reciprocal condition number of the j-th
!>          right eigenvector.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.   If SENSE = 'N' or 'E',
!>          LWORK >= max(1,2*N), and if JOBVL = 'V' or JOBVR = 'V',
!>          LWORK >= 3*N.  If SENSE = 'V' or 'B', LWORK >= N*(N+6).
!>          For good performance, LWORK must generally be larger.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (2*N-2)
!>          If SENSE = 'N' or 'E', not referenced.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if INFO = i, the QR algorithm failed to compute all the
!>                eigenvalues, and no eigenvectors or condition numbers
!>                have been computed; elements 1:ILO-1 and i+1:N of WR
!>                and WI contain eigenvalues which have converged.
!>
