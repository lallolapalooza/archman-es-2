subrutina sgghd3 (character compq, character compz, integer n, integer ilo, integer ihi, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldq, * ) q, integer ldq, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer info)

SGGHD3

Propósito:

!>
!> SGGHD3 reduce un par de matrices reales (A,B) a la forma de Hessenberg generalizada
!> usando transformaciones ortogonales, donde A es una matriz general y B es triangular superior.
!> La forma del problema de valores propios generalizado es
!>    A*x = lambda*B*x,
!> y B se convierte típicamente en triangular superior calculando su factorización QR
!> y moviendo la matriz ortogonal Q al lado izquierdo de la ecuación.
!>
!> Esta subrutina reduce simultáneamente A a una matriz de Hessenberg H:
!>    Q**T*A*Z = H
!> y transforma B a otra matriz triangular superior T:
!>    Q**T*B*Z = T
!> para reducir el problema a su forma estándar
!>    H*y = lambda*T*y
!> donde y = Z**T*x.
!>
!> Las matrices ortogonales Q y Z se determinan como productos de rotaciones de Givens.
!> Pueden formarse explícitamente o postmultiplicarse en las matrices de entrada Q1 y Z1,
!> de modo que
!>
!>      Q1 * A * Z1**T = (Q1*Q) * H * (Z1*Z)**T
!>
!>      Q1 * B * Z1**T = (Q1*Q) * T * (Z1*Z)**T
!>
!> Si Q1 es la matriz ortogonal de la factorización QR de B en la ecuación original
!> A*x = lambda*B*x, entonces SGGHD3 reduce el problema original a la forma generalizada
!> de Hessenberg.
!>
!> Esta es una variante bloqueada de SGGHRD, que utiliza multiplicaciones de matriz-matriz
!> para partes del cálculo con el fin de mejorar el rendimiento.
!>

Parámetros

COMPQ 
!>          COMPQ es CHARACTER*1
!>          = 'N': no calcular Q;
!>          = 'I': Q se inicializa a la matriz identidad y se devuelve la matriz
!>                 ortogonal Q;
!>          = 'V': Q debe contener una matriz ortogonal Q1 en la entrada y se devuelve
!>                 el producto Q1*Q.
!>

COMPZ

!>          COMPZ es CHARACTER*1
!>          = 'N': no calcular Z;
!>          = 'I': Z se inicializa a la matriz identidad y se devuelve la matriz
!>                 ortogonal Z;
!>          = 'V': Z debe contener una matriz ortogonal Z1 en la entrada y se devuelve
!>                 el producto Z1*Z.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B. N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>
!>          ILO e IHI marcan las filas y columnas de A que se reducirán. Se asume que
!>          A ya es triangular superior en las filas y columnas 1:ILO-1 y IHI+1:N.
!>          ILO e IHI suelen ser establecidos por una llamada previa a SGGBAL; de lo
!>          contrario, deben establecerse en 1 y N respectivamente.
!>          1 <= ILO <= IHI <= N, si N > 0; ILO=1 e IHI=0, si N=0.
!>

A

!>          A es un array REAL, dimensión (LDA, N)
!>          En la entrada, la matriz general N-por-N a reducir.
!>          En la salida, el triángulo superior y la primera subdiagonal de A se
!>          sobrescriben con la matriz de Hessenberg superior H, y el resto se
!>          establece a cero.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array REAL, dimensión (LDB, N)
!>          En la entrada, la matriz triangular superior N-por-N B.
!>          En la salida, la matriz triangular superior T = Q**T B Z. Los elementos
!>          debajo de la diagonal se establecen a cero.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

Q

!>          Q es un array REAL, dimensión (LDQ, N)
!>          En la entrada, si COMPQ = 'V', la matriz ortogonal Q1, típicamente de
!>          la factorización QR de B.
!>          En la salida, si COMPQ='I', la matriz ortogonal Q, y si COMPQ = 'V',
!>          el producto Q1*Q.
!>          No referenciado si COMPQ='N'.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.
!>          LDQ >= N si COMPQ='V' o 'I'; LDQ >= 1 en caso contrario.
!>

Z

!>          Z es un array REAL, dimensión (LDZ, N)
!>          En la entrada, si COMPZ = 'V', la matriz ortogonal Z1.
!>          En la salida, si COMPZ='I', la matriz ortogonal Z, y si COMPZ = 'V',
!>          el producto Z1*Z.
!>          No referenciado si COMPZ='N'.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.
!>          LDZ >= N si COMPZ='V' o 'I'; LDZ >= 1 en caso contrario.
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1.
!>          Para un rendimiento óptimo, LWORK >= 6*N*NB, donde NB es el
!>          tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve este valor
!>          como la primera entrada del array WORK y XERBLA no emite ningún mensaje
!>          de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
