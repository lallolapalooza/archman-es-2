sgml2latex(1)

Paquete: linuxdoc-tools

Licencias: GPL

SGML2LATEX(1) Manual de comandos generales SGML2LATEX(1)

NOMBRE

sgml2latex - crea salida LaTeX, DVI, PostScript o PDF desde un archivo fuente SGML DTD LinuxDoc

SINOPSIS

sgml2latex [opción-genérica...] [--output=tex|dvi|ps|pdf] [--bibtex] [--makeindex] [--pagenumber=n] --quick [--latex=hlatexp|platex] [--dvips=dvips|dvi2ps] [--verbosity=n] archivo[.sgml]

DESCRIPCIÓN

sgml2latex es una forma antigua y obsoleta del comando del conversor latex de LinuxDoc-Tools (su nombre puede ser engañoso, ya que no es una herramienta para ninguna DTD SGML, solo soporta la DTD SGML LinuxDoc). Se recomienda cambiar a la nueva forma linuxdoc -B latex ahora. Convierte un archivo fuente SGML DTD LinuxDoc a salida LaTeX, usando el analizador nsgmls(1) o onsgmls(1), y el traductor sgmlsasp(1). Usando la salida LaTeX, y el formateador de texto latex(1), puedes crear salida DVI, y salida PostScript usando el conversor dvips(1). La salida aparecerá en archivo.tex para la salida LaTeX, archivo.dvi para la salida DVI, o archivo.ps para la salida PostScript, donde archivo es el nombre del archivo fuente SGML.

Usando la salida LaTeX, y el formateador de texto pdflatex(1), puedes crear una bonita salida PDF, adecuada para ver con visores PDF como xpdf(1), acroread(1) o ghostview(1).

El par atributo/valor "output=latex2e" se establece para condicionales.

OPCIONES

sgml2latex acepta todas las opciones genéricas descritas en linuxdoc(1), y las siguientes opciones específicas:

--output=fmt, -o
Especifica el formato de salida deseado. El especificador fmt puede ser ``tex'', ``dvi'', ``ps'', o ``pdf''.

Nota: Esta versión no sobrescribe/elimina los archivos intermedios: archivo tex para salida dvi, o archivos tex/dvi para salida ps. Este es un comportamiento diferente al de SGML-Tools 1.0.9 original, por lo que se le advierte aquí.

--bibtex, -b
Procesa el TeX generado con bibtex(1).
--makeindex, -m
Genera un archivo de índice TeX adecuado para procesar con makeindex(1) a partir de etiquetas <idx> y <cdx> presentes en el fuente SGML.
--pagenumber, -n
Establece el número de página de inicio en el archivo DVI o PS de salida.
--quick, -q
Realiza solo un pase de formato LaTeX. Esto a menudo no es suficiente para producir una salida final (debido a referencias, etc.) pero es útil para detectar errores de TeX y problemas de justificación.
--pass, -P
El argumento de la opción de pasada se inserta justo después del preámbulo LaTeX generado por la etiqueta del tipo de documento. Especifica el formato de salida deseado. El especificador fmt puede ser ``tex'', ``dvi'', ``ps'', o ``pdf''.
--latex=comando_alternativo_latex, -x
Esta opción es actualmente para coreano y japonés. El comando_alternativo_latex puede ser ``latex'' (por defecto), ``hlatexp'' (para coreano), ``platex'' o ``jlatex'' (para japonés). Esta opción se puede usar para renderizar documentos en coreano usando HLaTeXp, o para renderizar documentos en japonés usando pLaTeX/jLaTeX. Si no, HLaTeX debe estar instalado para renderizar documentos en coreano. Por otro lado, los documentos en japonés se pueden renderizar con jLaTeX (que es el valor por defecto cuando se especifica ``-c nippon''), así que si ya tienes jLaTeX, puede que no necesites instalar pLaTeX.
--dvips=comando_alternativo_dvips, -s
Esta opción es actualmente para japonés. El comando_alternativo_dvips puede ser ``dvips'' o ``dvi2ps''. Si no sabes esto, entonces puede que no necesites esta opción.
--verbosity, -V
Establece la verbosidad. '0' (por defecto) mostrará información sobre la ejecución de LaTeX solo en caso de errores. '1' siempre mostrará información para la última ejecución. '2' mostrará información para todas las ejecuciones.
archivo
El archivo fuente SGML, nombrado como archivo o archivo.sgml
