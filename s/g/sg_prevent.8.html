NOMBRE

sg_prevent - envía el comando SCSI PREVENT ALLOW MEDIUM REMOVAL

SINOPSIS

sg_prevent [--allow] [--help] [--prevent=PC] [--verbose] [--version] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI PREVENT ALLOW MEDIUM REMOVAL al DISPOSITIVO. La acción predeterminada de esta utilidad es prevenir la extracción o expulsión del medio de una unidad. Esto se hace ignorando el comando SCSI START STOP UNIT (ver sg_start) e ignorando el botón de expulsión en la unidad cuando el usuario lo presiona. Las unidades que contienen discos extraíbles, cartuchos de cinta o medios de cd/dvd suelen implementar este comando. La definición de los "códigos de prevención" para este comando difiere entre discos y cintas (cubiertos por SBC-3 y SSC-3) y unidades de cd/dvd (cubiertos por MMC-5). Los "códigos de prevención" descritos aquí provienen de MMC-5.

OPCIONES

Los argumentos de las opciones largas son obligatorios también para las opciones cortas.

-a, --allow
permite la extracción del medio. Esto es equivalente a establecer '--prevent=2'. No se puede usar con la opción --prevent=PC (es decir, o no usar opciones (por lo tanto, previene la extracción), usar esta opción o --prevent=PC).
-h, --help
muestra el mensaje de uso y luego sale.
-p, --prevent=PC
donde PC es un valor de código de prevención. Los valores definidos son: 0 permite la extracción, 1 previene la extracción (predeterminado), 2 permite la extracción persistente mientras que 3 previene la extracción persistente. "Persistente" en este contexto significa que el iniciador (puerto) que utiliza correctamente el código 3 bloquea a otros iniciadores (puertos) para permitir la extracción. Un estado de "prevención persistente" puede ser borrado por el propietario permitiendo la extracción persistente (código 2) o un ciclo de alimentación (o cualquier cosa que reinicie el dispositivo (LU)) o algunos comandos especiales (por ejemplo, varias acciones de servicio de Reserva Persistente de Salida, ver SPC-3).
-v, --verbose
aumenta el nivel de verbosidad (es decir, salida de depuración).
-V, --version
imprime la cadena de versión y luego sale.

ESTADO DE SALIDA

El estado de salida de sg_prevent es 0 cuando tiene éxito. De lo contrario, consulte la página del manual de sg3_utils(8).
