DESCRIPCIÓN

sg_vector_create() asigna e inicializa un nuevo vector statgrab con elementos `initial_used` listos para su uso. Se asigna espacio inicialmente para `alloc_count` elementos (para evitar demasiadas llamadas a `realloc()` durante las posteriores llamadas a `sg_vector_resize()`). El valor de `block_size` debe ser una potencia de 2, se redondea a la siguiente potencia de 2 cuando no lo es. Si `alloc_count` no es múltiplo de `block_size`, se redondea al múltiplo de `block_size` más cercano. Devuelve un puntero al vector recién creado.

sg_vector_clear() destruye todos los elementos contenidos en el vector dado. A diferencia de `sg_vector_resize( x, 0 )`, el tamaño asignado del vector no se modifica.

sg_vector_resize() aumenta o disminuye la cantidad de elementos asignados en el vector especificado. La cantidad de elementos asignados es siempre un múltiplo del parámetro de inicialización `block_size`. En el caso especial, si se llama a `sg_vector_resize()` con 0 como argumento `new_count`, el vector se libera después de que todos los elementos del vector hayan sido destruidos. Devuelve un puntero al vector redimensionado.

sg_vector_free() destruye todos los elementos del vector y libera el almacenamiento perteneciente al vector dado.

sg_vector_clone() clona todos los elementos del vector dado en un nuevo vector creado con la misma especificación que el referenciado. Devuelve un puntero al vector clonado.

sg_vector_clone_into() clona todos los elementos del vector fuente dado en el vector destino dado. El vector destino debe estar creado para el mismo tipo de datos de elemento que el vector fuente. Devuelve un código de error distinto de SG_ERROR_NONE si algo salió mal.

sg_vector_compute_diff() calcula un vector de diferencia entre el vector que contiene las estadísticas actuales y otro vector que contiene estadísticas más antiguas. Si un elemento existe en el vector actual pero no en el opuesto, se clona en el vector resultado. Si un elemento existe solo en el vector opuesto, no aparece en el vector destino. sg_vector_compute_diff() devuelve un código de error distinto de SG_ERROR_NONE si algo salió mal.

sg_prove_vector() prueba si un puntero a un vector apunta realmente a un vector. En caso de que el puntero del vector dado apunte a datos corruptos, el programa se aborta. Cuando `sg_prove_vector()` devuelve, retorna SG_ERROR_NONE.

sg_get_nelements() devuelve el número de elementos que el área de datos dada, abarcada por un vector statgrab, contiene. La cabecera del vector se calcula internamente a partir del puntero dado al primer elemento del vector.

sg_free_stats_buf() libera el vector que abarca el área de datos dada.

NOTAS

Excepto `sg_get_nelements()` y `sg_free_stats_buf()`, ninguna de las funciones anteriores puede ser llamada desde fuera de las fuentes de libstatgrab. Las estructuras y APIs documentadas pueden cambiar sin previo aviso. La descripción de todas las demás APIs está destinada a ser leída únicamente por los desarrolladores de libstatgrab.

Cada vector se crea a partir de dos elementos: la información del vector y la lista de elementos:

template <class T, class Impl>
struct sg_vector {
        size_t used_count;
        size_t alloc_count;
        size_t block_shift;
        Impl vector_implementation;
        T elements[alloc_count];
};

Por supuesto, esto no es C válido, por lo que ser astuto fue la solución:

typedef struct sg_vector {
	size_t used_count;
	size_t alloc_count;
	size_t block_shift;
	struct sg_vector_init_info info;
} sg_vector;
struct sg_vector_size_helper {
	struct sg_vector v;
	long long ll;
};
#define VECTOR_SIZE offsetof(struct sg_vector_size_helper,ll)
/* Devuelve el puntero de datos de un vector */
#define VECTOR_DATA(vector) \
	(vector ? (void *)(((char *)vector)+VECTOR_SIZE) : NULL)
#define VECTOR_ADDR_ARITH(ptr) \
	(sg_vector *)(((char *)(ptr))-VECTOR_SIZE)
/* Devuelve el vector para unos datos */
#define VECTOR_ADDRESS(ptr) \
	((ptr) ? (SG_ERROR_NONE == sg_prove_vector(VECTOR_ADDR_ARITH(ptr)) ? VECTOR_ADDR_ARITH(ptr) : NULL ) : NULL)

Esto también permite que funciones de usuario como `sg_get_nelements()` y `sg_free_stats_buf()` cambien fácilmente entre la estructura del vector y el contenido.

LA ESTRUCTURA DE ESPECIALIZACIÓN DEL VECTOR

Como se mencionó, la implementación del vector utiliza estrategias del concepto de programación orientada a objetos llamado "polimorfismo". Un vector se describe mediante un pequeño objeto que contiene atributos inherentes como el tamaño del elemento y un conjunto de "métodos virtuales" para realizar tareas relacionadas con los elementos, como inicializar o destruir elementos.

typedef void (*vector_init_function)(void *item);
typedef sg_error (*vector_copy_function)(const void *src, void *dst);
typedef sg_error (*vector_compute_diff_function)(void *dst, const void *src);
typedef int (*vector_compare_function)(const void *a, const void *b);
typedef void (*vector_destroy_function)(void *item);
struct sg_vector_init_info {
        size_t item_size;
        vector_init_function init_fn;
        vector_copy_function copy_fn;
        vector_compute_diff_function compute_diff_fn;
        vector_compare_function compare_fn;
        vector_destroy_function destroy_fn;
};

Las instancias de `struct sg_vector_init_info` se inicializan conceptualmente de forma estática utilizando la macro preprocesador `VECTOR_INIT_INFO_FULL_INIT(type)` o `VECTOR_INIT_INFO_EMPTY_INIT(type)`. Aquí hay algunos ejemplos para demostrar cómo está previsto:

Inicialización de la descripción del vector de estadísticas de CPU

DESCRIPTION

The statgrab library uses vectors to store collections of data. These vectors are dynamically allocated and resized.

The following macros are available to manipulate these vectors:

VECTOR_CREATE(size_t count, identifier type)
Creates a new vector with the specified number of elements of the given type. The memory for the vector and its elements is allocated. The initial number of elements to allocate is set to count.
VECTOR_CLEAR(struct sg_vector *vector)
Clears the specified vector, freeing any memory allocated for its elements. The vector itself is not freed.
VECTOR_CREATE_OR_RESIZE(struct sg_vector *vector, size_t new_count, identifier type)
If the provided vector is NULL, this macro calls sg_vector_create to create a new vector with new_count elements of the specified type. If the vector is not NULL, it calls sg_vector_resize to resize the existing vector to hold new_count elements. The macro returns a pointer to the (potentially new) vector structure.
VECTOR_UPDATE(struct sg_vector **vectorptr, size_t new_count, datatype *data, identifier datatype)
This macro is used to update the contents of a vector. It first calls VECTOR_CREATE_OR_RESIZE to ensure the vector has enough space for new_count elements. If the vector is successfully created or resized, and data is not NULL, it copies the data from the provided data pointer into the vector. If an error occurs during vector creation or resizing and new_count is not zero, the macro VECTOR_UPDATE_ERROR_CLEANUP is invoked to handle the error cleanup. The datatype parameter specifies the type of data being stored in the vector.
VECTOR_ITEM_COUNT(struct sg_vector *vector)
Returns the number of elements currently stored in the specified vector. If the vector is NULL, it returns 0.

NOTES

VECTOR_CREATE() calls sg_vector_create() with alloc_count = block_size and initial_used = 0 using the vector specialisation type##_vector_init_info.

VECTOR_CLEAR() simply calls sg_vector_clear(). This macro exists only for conformity.

VECTOR_CREATE_OR_RESIZE() calls sg_vector_create() when the given vector pointer points to NULL or sg_vector_resize() otherwise. The result of the appropriate function is returned.

VECTOR_UPDATE() calls VECTOR_CREATE_OR_RESIZE() and sets data to the first element of the resulting vector when a non-NULL pointer got, to NULL otherwise. When VECTOR_CREATE_OR_RESIZE() returns a NULL pointer and new_count is not equal to 0 (zero), the instructions from the macro VECTOR_UPDATE_ERROR_CLEANUP are executed to cleanup before returning from current subroutine with the error which has been occurred.

VECTOR_ITEM_COUNT() returns 0 for a non-existing vector (vector == 0) and the number of containing elements otherwise.

RETURN VALUES

Beside error codes, the return values, if any, are always a pointer to vector structures (struct sg_vector *).
