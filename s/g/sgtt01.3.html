Documentación de Función/Subrutina

subrutina sgtt01 (integer n, real, dimension( * ) dl, real, dimension( * ) d, real, dimension( * ) du, real, dimension( * ) dlf, real, dimension( * ) df, real, dimension( * ) duf, real, dimension( * ) du2, integer, dimension( * ) ipiv, real, dimension( ldwork, * ) work, integer ldwork, real, dimension( * ) rwork, real resid)

SGTT01

Propósito:

!>
!> SGTT01 reconstruye una matriz tridiagonal A a partir de su factorización LU
!> y calcula el residuo
!>    norm(L*U - A) / ( norm(A) * EPS ),
!> donde EPS es la epsilon de la máquina.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

DL

!>          DL es un array REAL, dimensión (N-1)
!>          Los elementos sub-diagonales (n-1) de A.
!>

D

!>          D es un array REAL, dimensión (N)
!>          Los elementos diagonales de A.
!>

DU

!>          DU es un array REAL, dimensión (N-1)
!>          Los elementos super-diagonales (n-1) de A.
!>

DLF

!>          DLF es un array REAL, dimensión (N-1)
!>          Los multiplicadores (n-1) que definen la matriz L de la
!>          factorización LU de A.
!>

DF

!>          DF es un array REAL, dimensión (N)
!>          Los n elementos diagonales de la matriz triangular superior U de
!>          la factorización LU de A.
!>

DUF

!>          DUF es un array REAL, dimensión (N-1)
!>          Los elementos (n-1) de la primera super-diagonal de U.
!>

DU2

!>          DU2 es un array REAL, dimensión (N-2)
!>          Los elementos (n-2) de la segunda super-diagonal de U.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Los índices de pivote; para 1 <= i <= n, la fila i de la matriz fue
!>          intercambiada con la fila IPIV(i).  IPIV(i) siempre será
!>          i o i+1; IPIV(i) = i indica que no se requirió un intercambio de fila.
!>

WORK

!>          WORK es un array REAL, dimensión (LDWORK,N)
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.  LDWORK >= max(1,N).
!>

RWORK

!>          RWORK es un array REAL, dimensión (N)
!>

RESID

!>          RESID es REAL
!>          El residuo escalado:  norm(L*U - A) / (norm(A) * EPS)
!>
