SGGSVD calcula la descomposición en valores singulares (SVD) para OTRAS matrices

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina SGGSVD3.
!>
!> SGGSVD calcula la descomposición en valores singulares generalizada (GSVD)
!> de una matriz real M por N, A, y una matriz real P por N, B:
!>
!>       U**T*A*Q = D1*( 0 R ),    V**T*B*Q = D2*( 0 R )
!>
!> donde U, V y Q son matrices ortogonales.
!> Sea K+L = el rango numérico efectivo de la matriz (A**T,B**T)**T,
!> entonces R es una matriz triangular superior no singular de K+L por K+L, D1 y
!> D2 son matrices de M por (K+L) y P por (K+L) respectivamente y de las
!> siguientes estructuras:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) en la salida.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N), y R33 se almacena
!>   ( 0  R22 R23 )
!>   en B(M-K+1:L,N+M-K-L+1:N) en la salida.
!>
!> La rutina calcula C, S, R y opcionalmente las matrices de transformación
!> ortogonales U, V y Q.
!>
!> En particular, si B es una matriz B no singular de N por N, entonces la GSVD de
!> A y B proporciona implícitamente la SVD de A*inv(B):
!>                      A*inv(B) = U*(D1*inv(D2))*V**T.
!> Si ( A**T,B**T)**T  tiene columnas ortonormales, entonces la GSVD de A y B es
!> también igual a la descomposición CS de A y B. Además, la GSVD
!> puede usarse para derivar la solución del problema de valores propios:
!>                      A**T*A x = lambda* B**T*B x.
!> En alguna literatura, la GSVD de A y B se presenta en la forma
!>                  U**T*A*X = ( 0 D1 ),   V**T*B*X = ( 0 D2 )
!> donde U y V son ortogonales y X es no singular, D1 y D2 son
!> ``diagonales''. La forma GSVD anterior puede convertirse a la forma posterior
!> tomando la matriz no singular X como
!>
!>                      X = Q*( I   0    )
!>                            ( 0 inv(R) ).
!>

NAME

SGGVD — computes the generalized singular value decomposition of an upper triangular matrix.

                        Q( LDQ, * ), WORK( * ), Z( LDZ, * )
  INTEGER           :: IWORK( * )

Function/Subroutine Documentation

This subroutine is part of the LAPACK package.

SGGVD computes the generalized singular value decomposition (GSVD) of an upper triangular matrix A and an upper triangular matrix B.

The GSVD is defined by the equation

 A = Q * SIGMA_A * Z**T
 B = Q * SIGMA_B * Z**T

where Z is an orthogonal matrix, and Q and SIGMA_A, SIGMA_B are matrices.

SIGMA_A and SIGMA_B have the following structure:

 SIGMA_A = ( I  0  0 )
           ( 0  S  0 )
           ( 0  0  0 )

 SIGMA_B = ( 0  0  0 )
           ( 0  T  0 )
           ( 0  0  I )

Here I is the identity matrix. S and T are diagonal matrices with diagonal entries satisfying

 S(i,i) = alpha_i >= 0,
 T(i,i) = beta_i >= 0,

such that

 alpha_i**2 + beta_i**2 = 1.

The diagonal entries of SIGMA_A and SIGMA_B partition the diagonal entries of A and B. The diagonal entries of S and T are computed implicitly as functions of the diagonal entries of A and B.

Specifically, let K be the effective rank of the matrix (A**T, B**T)**T. The subroutine computes

 alpha_i / beta_i

for the I-th generalized singular value.

On exit, Q and Z are orthogonal matrices.

Input Parameters:

 ITYPE  CHARACTER*1.
        Specifies the form of the GSVD:
        = 'U':  Compute the GSVD A = U*S*Z**T, B = V*T*Z**T.
                Q is an orthogonal matrix, and Z is an orthogonal matrix.
        = 'N':  Compute the GSVD A = U*S*Z**T, B = V*T*Z**T.
                Q is not computed. Z is an orthogonal matrix.
        = 'V':  Compute the GSVD A = U*S*Z**T, B = V*T*Z**T.
                Q is an orthogonal matrix. Z is not computed.
        = 'X':  Compute the GSVD A = U*S*Z**T, B = V*T*Z**T.
                Q and Z are not computed.

 JOBZ   CHARACTER*1.
        = 'V':  Compute the vectors described by JOBZ.
        = 'N':  Do not compute the vectors described by JOBZ.

 M      INTEGER.
        The number of rows of A and B. M >= 0.

 N      INTEGER.
        The number of columns of A and B. N >= 0.

 A      (input) REAL array, dimension (LDA, K).
        On entry, the M-by-N upper trapezoidal matrix A.

 LDA    INTEGER.
        The leading dimension of the array A. LDA >= max(1, M).

 B      (input) REAL array, dimension (LDB, K).
        On entry, the M-by-N upper trapezoidal matrix B.

 LDB    INTEGER.
        The leading dimension of the array B. LDB >= max(1, M).

 LDQ    INTEGER.
        The leading dimension of the array Q. LDQ >= max(1, M).

 LDZ    INTEGER.
        The leading dimension of the array Z. LDZ >= max(1, N).

 WORK   (workspace) REAL array, dimension (LWORK).
        On exit, WORK(1) is the minimum required dimension LWORK.

 LWORK  INTEGER.
        The dimension of the array WORK. LWORK >= 1.
        For optimum performance, LWORK should be at least
        max( M, N, 2*max(M,N) ) + 2*max(M,N).

Output Parameters:

 ALPHA  (output) REAL array, dimension (K).
        See BETA for information about this array.

 BETA   (output) REAL array, dimension (K).
        On exit, ALPHA and BETA contain the diagonal entries of the matrices
        SIGMA_A and SIGMA_B.
        The generalized singular values are alpha_i / beta_i.
        alpha_i**2 + beta_i**2 = 1.
        Note that if beta_i = 0, then alpha_i = 1. If alpha_i = 0, then
        beta_i = 1.
        On exit, the arrays ALPHA and BETA contain the diagonal entries of
        SIGMA_A and SIGMA_B respectively.

 Q      (output) REAL array, dimension (LDQ, M).
        If JOBZ = 'V', Q is an orthogonal matrix such that
        A = Q * SIGMA_A * Z**T and B = Q * SIGMA_B * Z**T.
        If JOBZ = 'N', Q is not computed.

 Z      (output) REAL array, dimension (LDZ, N).
        If JOBZ = 'V', Z is an orthogonal matrix such that
        A = Q * SIGMA_A * Z**T and B = Q * SIGMA_B * Z**T.
        If JOBZ = 'N', Z is not computed.

 IWORK  (workspace) INTEGER array, dimension (M).
        On exit, IWORK stores the sorting information. More
        precisely, the following loop will sort ALPHA
            for I = K+1, min(M,K+L)
                swap ALPHA(I) and ALPHA(IWORK(I))
            endfor
        such that ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).

 INFO   INTEGER.
        = 0:  successful exit
        < 0:  if INFO = -i, the i-th argument had an illegal value.
        > 0:  if INFO = 1, the Jacobi-type procedure failed to
              converge.  For further details, see subroutine STGSJA.

Internal Parameters:

 TOLA    REAL
 TOLB    REAL
        TOLA and TOLB are the thresholds to determine the effective
        rank of (A**T,B**T)**T. Generally, they are set to
                 TOLA = MAX(M,N)*norm(A)*MACHEPS,
                 TOLB = MAX(P,N)*norm(B)*MACHEPS.
        The size of TOLA and TOLB may affect the size of backward
        errors of the decomposition.
