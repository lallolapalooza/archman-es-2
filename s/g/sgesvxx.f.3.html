SGESVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GE

Propósito:

!>
!>    SGESVXX utiliza la factorización LU para calcular la solución a un
!>    sistema lineal real de ecuaciones  A * X = B,  donde A es una
!>    matriz de N por N y X y B son matrices de N por NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto globales como
!>    del componente máximo. SGESVXX devolverá una solución con un pequeño
!>    error garantizado (O(eps) donde eps es la precisión de máquina de trabajo)
!>    a menos que la matriz sea muy mal condicionada, en cuyo caso se devuelve
!>    una advertencia. También se calculan y devuelven los números de condición
!>    relevantes.
!>
!>    SGESVXX acepta factorizaciones y factores de 
¡

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Si el sistema se equilibrará o no depende del escalado de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe con diag(R)*A*diag(C)
!>    y B con diag(R)*B (si TRANS='N') o diag(C)*B (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular inferior
!>    unitaria y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U sea exactamente singular, la
!>    subrutina regresa con INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz A (véase
!>    el argumento RCOND). Si la inversa del número de condición es menor que
!>    la precisión de máquina, la subrutina aún continúa resolviendo para X
!>    y calculando los límites de error como se describe a continuación.
!>
!>    4. Se resuelve el sistema de ecuaciones para X utilizando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la subrutina utilizará refinamiento iterativo para intentar obtener un
!>    error pequeño y límites de error. El refinamiento calcula el residual
!>    al menos al doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') de modo
!>    que resuelva el sistema original antes del equilibrado.
!> 
!>     Algunos parámetros opcionales se agrupan en el array PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados
!>     son aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que
!>     el código fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona en la entrada, y si no, si la matriz A debe
!>     equilibrarse antes de factorizarse.
!>       = 'F':  En la entrada, AF y IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A se ha
!>               equilibrado con los factores de escala dados por R y C.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará en AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará en AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta Conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>     En la entrada, la matriz N por N A. Si FACT = 'F' y EQUED
!>     no es 'N', entonces A debe haber sido equilibrada por los
!>     factores de escala en R y/o C.
!>     A no se modifica si FACT = 'F' o
!>     'N', o si FACT = 'E' y EQUED = 'N' a la salida.
!>
!>     A la salida, si EQUED .ne. 'N', A se escala de la siguiente manera:
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array REAL, dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene los factores L y U de la factorización
!>     A = P*L*U calculada por SGETRF. Si EQUED .ne. 'N', entonces
!>     AF es la forma factorizada de la matriz A equilibrada.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y a la salida
!>     devuelve los factores L y U de la factorización A = P*L*U
!>     de la matriz A original.
!>
!>     Si FACT = 'E', entonces AF es un argumento de salida y a la salida
!>     devuelve los factores L y U de la factorización A = P*L*U
!>     de la matriz A equilibrada (ver la descripción de A para
!>     la forma de la matriz equilibrada).
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>     contiene los índices de pivote de la factorizació
LAPACK routine SGESVX

NAME

SGESVX — General routine for solving a general linear system of equations A*X = B.

PURPOSE

The purpose of SGESVX is to solve the general linear system A*X = B, using a general matrix A. Error bounds on the solution are computed, and if the matrix A is singular or near-singular, and IPIV is not used, then the least squares solution is computed.

This routine uses the Full Pivoting LU factorization of A, A = P*L*U, to solve the system.

PARAMETERS

FACT CHARACTER*1

Specifies the form of the problem to be solved.
= 'E': Solve the equations A*X = B for the equilibrated matrix A.
= 'F': Solve the equations A*X = B for the original matrix A; the arrays U, L, and IPIV are input and not recomputed.
= 'N': Compute the LU factorization of A and solve the equations A*X = B.
= 'S': Solve the equations A*X = B for the scaled matrix A.
TRANS CHARACTER*1

Specifies the form of the system to be solved.
= 'N': Solve A*X = B.
= 'T': Solve AT*X = B.
= 'C': Solve AH*X = B, where AH is the conjugate transpose of A.
'T' and 'C' are equivalent for real matrices.
N INTEGER

The order of the matrix A. N >= 0.
NRHS INTEGER

The number of right hand side vectors, i.e., the number of columns in the arrays B and X. NRHS >= 0.
A REAL array, dimension (LDA,N)

On entry, the array A contains the matrix whose LU factorization is to be computed, unless FACT = 'F', 'E', or 'S', in which case the factored or equilibrated matrix A is supplied.

On exit, if FACT = 'N', A is overwritten by values generated during the execution of the LU factorization. If FACT = 'E', 'F', or 'S', A is unchanged.
LDA INTEGER

The leading dimension of the array A. LDA >= max(1,N).
IPIV INTEGER array, dimension (min(N+1,N))

Details of the interchanges in the LU factorization of A.
If FACT = 'E', 'N', or 'S', IPIV is an output argument and on exit contains the pivot indices from the factorization A = P*L*U of the original matrix A.
If FACT = 'F', IPIV is an input argument. In this case, the arrays U and L must also be supplied, and the LU factorization is not computed.
EQUED CHARACTER*1

Specifies the form of equilibration that was done.
= 'N': No equilibration (always true if FACT = 'N').
= 'R': Row equilibration, i.e., A has been premultiplied by diag(R).
= 'C': Column equilibration, i.e., A has been postmultiplied by diag(C).
= 'B': Both row and column equilibration, i.e., A has been replaced by diag(R) * A * diag(C).
EQUED is an input argument if FACT = 'F'; otherwise, it is an output argument.
R REAL array, dimension (N)

The row scale factors for A. If EQUED = 'R' or 'B', A is multiplied on the left by diag(R); if EQUED = 'N' or 'C', R is not accessed. R is an input argument if FACT = 'F'; otherwise, R is an output argument. If FACT = 'F' and EQUED = 'R' or 'B', each element of R must be positive. If R is output, each element of R is a power of the radix. If R is input, each element of R should be a power of the radix to ensure a reliable solution and error estimates. Scaling by powers of the radix does not cause rounding errors unless the result underflows or overflows. Rounding errors during scaling lead to refining with a matrix that is not equivalent to the input matrix, producing error estimates that may not be reliable.
C REAL array, dimension (N)

The column scale factors for A. If EQUED = 'C' or 'B', A is multiplied on the right by diag(C); if EQUED = 'N' or 'R', C is not accessed. C is an input argument if FACT = 'F'; otherwise, C is an output argument. If FACT = 'F' and EQUED = 'C' or 'B', each element of C must be positive. If C is output, each element of C is a power of the radix. If C is input, each element of C should be a power of the radix to ensure a reliable solution and error estimates. Scaling by powers of the radix does not cause rounding errors unless the result underflows or overflows. Rounding errors during scaling lead to refining with a matrix that is not equivalent to the input matrix, producing error estimates that may not be reliable.
B REAL array, dimension (LDB,NRHS)

On entry, the N-by-NRHS right hand side matrix B.

On exit, if EQUED = 'N', B is not modified; if TRANS = 'N' and EQUED = 'R' or 'B', B is overwritten by diag(R)*B; if TRANS = 'T' or 'C' and EQUED = 'C' or 'B', B is overwritten by diag(C)*B.
LDB INTEGER

The leading dimension of the array B. LDB >= max(1,N).
X REAL array, dimension (LDX,NRHS)

If INFO = 0, the N-by-NRHS solution matrix X to the original system of equations. Note that A and B are modified on exit if EQUED .ne. 'N', and the solution to the equilibrated system is inv(diag(C))*X if TRANS = 'N' and EQUED = 'C' or 'B', or inv(diag(R))*X if TRANS = 'T' or 'C' and EQUED = 'R' or 'B'.
LDX INTEGER

The leading dimension of the array X. LDX >= max(1,N).
RCOND REAL

Reciprocal scaled condition number. This is an estimate of the reciprocal Skeel condition number of the matrix A after equilibration (if done). If this is less than the machine precision (in particular, if it is zero), the matrix is singular to working precision. Note that the error may still be small even if this number is very small and the matrix appears ill- conditioned.
RPVGRW REAL

Reciprocal pivot growth. On exit, this contains the reciprocal pivot growth factor norm(A)/norm(U). The norm is used. If this is much less than 1, then the stability of the LU factorization of the (equilibrated) matrix A could be poor. This also means that the solution X, estimated condition numbers, and error bounds could be unreliable. If factorization fails with 0<INFO<=N, then this contains the reciprocal pivot growth factor for the leading INFO columns of A. In SGESVX, this quantity is returned in WORK(1).
BERR REAL array, dimension (NRHS)

Componentwise relative backward error. This is the componentwise relative backward error of each solution vector X(j) (i.e., the smallest relative change in any element of A or B that makes X(j) an exact solution).
N_ERR_BNDS INTEGER

Number of error bounds to return for each right hand side and each type (normwise or componentwise). See ERR_BNDS_NORM and ERR_BNDS_COMP below.
ERR_BNDS_NORM REAL array, dimension (NRHS, N_ERR_BNDS)

For each right-hand side, this array contains information about various error bounds and condition numbers corresponding to the normwise relative error, which is defined as follows:

Normwise relative error in the ith solution vector: max_j (abs(XTRUE(j,i) - X(j,i))) ------------------------------ max_j abs(X(j,i))

The array is indexed by the type of error information as described below. There currently are up to three pieces of information returned.

The first index in ERR_BNDS_NORM(i,:) corresponds to the ith right-hand side.

The second index in ERR_BNDS_NORM(:,err) contains the following three fields:

err = 1 boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').

err = 2 error bound: The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.

err = 3 Reciprocal condition number: Estimated normwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z. Let Z = S*A, where S scales each row by a power of the radix so all absolute row sums of Z are approximately 1. See Lapack Working Note 165 for further details and extra cautions.
ERR_BNDS_COMP REAL array, dimension (NRHS, N_ERR_BNDS)

For each right-hand side, this array contains information about various error bounds and condition numbers corresponding to the componentwise relative error, which is defined as follows:

Componentwise relative error in the ith solution vector: abs(XTRUE(j,i) - X(j,i)) max_j ---------------------- abs(X(j,i))

The array is indexed by the right-hand side i (on which the componentwise relative error depends), and the type of error information as described below. There currently are up to three pieces of information returned for each right-hand side. If componentwise accuracy is not requested (PARAMS(3) = 0.0), then ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most the first (:,N_ERR_BNDS) entries are returned.

The first index in ERR_BNDS_COMP(i,:) corresponds to the ith right-hand side.

The second index in ERR_BNDS_COMP(:,err) contains the following three fields:

err = 1 boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').

err = 2 error bound: The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.

err = 3 Reciprocal condition number: Estimated componentwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z. Let Z = S*(A*diag(x)), where x is the solution for the current right-hand side and S scales each row of A*diag(x) by a power of the radix so all absolute row sums of Z are approximately 1. See Lapack Working Note 165 for further details and extra cautions.
NPARAMS INTEGER

Specifies the number of parameters set in PARAMS. If <= 0, the PARAMS array is never referenced and default values are used.
PARAMS REAL array, dimension NPARAMS

Specifies algorithm parameters. If an entry is < 0.0, then that entry will be filled with default value used for that parameter. Only positions up to NPARAMS are accessed; defaults are used for higher-numbered parameters.

PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative refinement or not. Default: 1.0 = 0.0: No refinement is performed, and no error bounds are computed. = 1.0: Use the double-precision refinement algorithm, possibly with doubled-single computations if the compilation environment does not support DOUBLE PRECISION. (other values are reserved for future use)

PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual computations allowed for refinement. Default: 10
WORK REAL array, dimension (max(1,2*N))

Workspace array. On exit, if INFO=0, WORK(1) contains the reciprocal pivot growth factor.
INFO INTEGER

INTEGER
= 0: Successful exit. The solution X has been computed, and error bounds have been computed and are usually reliable. > 0: If INFO = k, and k <= N, then the LU factorization failed to complete because the rank of the (equilibrated) matrix A is less than k. The solution X is computed in the least squares sense, and error bounds are computed but may not be reliable. > 0: If INFO = k, and k > N, then the LU factorization failed to complete because the rank of the (equilibrated) matrix A is less than N. The solution X is computed in the least squares sense, and error bounds are computed but may not be reliable.

RETURNS

None

DESCRIPTION

This routine is a driver routine for solving a general linear system of equations.

It uses the Full Pivoting LU factorization of A, A = P*L*U, to solve the system.

If FACT = 'N', the routine first computes the LU factorization of A.

If FACT = 'E' or 'S', the routine first equilibrates the matrix A.

If FACT = 'F', the routine assumes that A has already been factorized, and that the factored form is supplied.

The routine then computes the solution X to A*X = B, along with error bounds.
