NOMBRE

sg_get_page_stats, sg_get_page_stats_r, sg_get_page_stats_diff, sg_get_page_stats_diff_between, sg_free_page_stats - obtener estadísticas de paginación

SINOPSIS

#include <statgrab.h>


sg_page_stats *sg_get_page_stats
(size_t *entries);


sg_page_stats *sg_get_page_stats_r
(size_t *entries);


sg_page_stats *sg_get_page_stats_diff
(size_t *entries);


sg_page_stats *sg_get_page_stats_diff_between
(const sg_page_stats *cur, const sg_page_stats *last, size_t *entries);


sg_error sg_free_page_stats
(sg_page_stats *data);

DESCRIPCIÓN

El módulo de estadísticas de página entrega el número de páginas cargadas y descargadas, ya sea desde que la máquina se inició (por las funciones sg_get_page_stats() y sg_get_page_stats_r()) o la diferencia entre dos estadísticas medidas (por las funciones sg_get_page_stats_diff() y sg_get_page_stats_diff_between()).

La función sg_get_page_stats_diff() calcula la diferencia entre la última llamada a la función sg_get_page_stats() en este hilo (las estadísticas de la llamada anterior se guardan y sg_get_page_stats() se llama inmediatamente después de esto).

Atajo de la API

función retorna propietario de los datos
sg_get_page_stats sg_page_stats * libstatgrab (local del hilo)
sg_get_page_stats_r sg_page_stats * llamador
sg_get_page_stats_diff sg_page_stats * libstatgrab (local del hilo)
sg_get_page_stats_diff_between sg_page_stats * llamador

El búfer sg_page_stats recibido de sg_get_page_stats_r() y sg_get_page_stats_diff_between() debe liberarse usando sg_free_page_stats() cuando ya no se necesite. El llamador es responsable de hacerlo.

VALORES DE RETORNO

typedef struct{
        unsigned long long pages_pagein;
        unsigned long long pages_pageout;
        time_t systime;
}sg_page_stats;
pages_pagein
El número de páginas cargadas en memoria.
pages_pageout
El número de páginas descargadas de memoria (a swap).
systime
La marca de tiempo cuando se recopilaron las estadísticas anteriores en segundos desde la época o el período de tiempo durante el cual se transfirieron pages_pagein y pages_pageout.

ERRORES

Solaris no parece informar con precisión. Informa el número de páginas cargadas en memoria, no necesariamente desde el swap. Esta funcionalidad no se considera completamente confiable.
