subroutine sgerqf (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SGERQF

Propósito:

!>
!> SGERQF calcula una factorización RQ de una matriz real M por N, A:
!> A = R * Q.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz M por N, A.
!>          En la salida,
!>          si m <= n, la triangular superior del sub-array
!>          A(1:m,n-m+1:n) contiene la matriz triangular superior R de M por M;
!>          si m >= n, los elementos en y por encima de la (m-n)-ésima sub-diagonal
!>          contienen la matriz trapezoidal superior R de M por N;
!>          los elementos restantes, junto con el array TAU, representan la
!>          matriz ortogonal Q como un producto de min(m,n)
!>          transformaciones de Householder elementales (ver Detalles Adicionales).
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es un array REAL, de dimensión (min(M,N))
!>          Los factores escalares de las transformaciones elementales (ver Detalles
!>          Adicionales).
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, y LWORK >= M en caso contrario.
!>          Para un rendimiento óptimo, LWORK >= M*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          sólo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Autor

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de transformaciones de Householder
!>  elementales:
!>
!>     Q = H(1) H(2) . . . H(k), donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real, y v es un vector real con
!>  v(n-k+i+1:n) = 0 y v(n-k+i) = 1; v(1:n-k+i-1) se almacena en la salida en
!>  A(m-k+i,1:n-k+i-1), y tau en TAU(i).
!>
