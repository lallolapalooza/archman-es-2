NOMBRE

sg_rep_density - envía el comando SCSI REPORT DENSITY SUPPORT

SINOPSIS

sg_rep_density [--ayuda] [--hex] [--enhex=FN] [--maxlen=LONGITUD] [--media] [--raw] [--readonly] [--typem] [--verbose] [--version] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI REPORT DENSITY a DISPOSITIVO y muestra los datos devueltos. Este comando es específico de las unidades de cinta. Este comando se encuentra en el borrador del estándar SSC-5, revisión 6 (ssc5r06.pdf). Este comando estaba presente en el estándar SSC-2 (ANSI INCITS 380-2003).

Por defecto, esta utilidad solicita los descriptores de código de densidad compatibles con el DISPOSITIVO (por ejemplo, una unidad de cinta) y decodifica la respuesta. Si se proporciona la opción --typem, obtiene los descriptores de tipo de medio compatibles con el DISPOSITIVO y decodifica la respuesta. Cuando se proporciona la opción --media, se obtienen los descriptores de código de densidad o tipo de medio compatibles con el medio dentro del DISPOSITIVO (por ejemplo, un cartucho de cinta).

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-h, --ayuda
muestra el mensaje de uso y luego sale.
-H, --hex
muestra la respuesta en hexadecimal en stdout. Cuando se usa una vez, la respuesta completa se muestra en hexadecimal ASCII, prefijada por una dirección (comenzando en 0) en cada línea. Cuando se usa dos veces, la respuesta completa se muestra en hexadecimal sin una dirección inicial (en cada línea).
Usar esta opción tres veces producirá una salida que puede ser redirigida a un archivo y posteriormente dada a otra invocación usando la opción --enhex=FN.
-i, --enhex=FN
donde FN es un nombre de archivo cuyo contenido se asume que está en hexadecimal ASCII. Si DISPOSITIVO también se proporciona, entonces DISPOSITIVO se ignora, se emite una advertencia y la utilidad continúa, decodificando el archivo llamado FN. Consulte la sección "FORMATOS HEXADECIMAL, BINARIO Y JSON" en la página del manual de sg3_utils para obtener más información. Si la opción --raw también se proporciona, el contenido de FN se trata como binario.
-m, --maxlen=LONGITUD
donde LONGITUD es la longitud (máxima) de la respuesta en bytes. Se coloca en el campo "longitud de asignación" del cdb. Si no se proporciona (o LONGITUD es cero), se usan 8192. El valor máximo permitido de LONGITUD es 65535.
-M, --media
establece el bit MEDIA en el cdb, lo que hace que los códigos de densidad (o tipos de medio) compatibles con el cartucho de cinta en la unidad se coloquen en la respuesta. El valor predeterminado es solicitar los códigos de densidad (o tipos de medio) compatibles con la propia unidad de cinta.
Si no hay "medio" (por ejemplo, cartucho de cinta) presente en la unidad, el comando SCSI fallará con una clave de sentido de "no está listo".
-r, --raw
muestra la respuesta SCSI (es decir, el búfer de datos de salida) en binario (a stdout) a menos que se proporcione la opción --enhex=FN.
Cuando se usa junto con la opción --enhex=FN, el contenido de FN se trata como binario (en lugar de hexadecimal).
-R, --readonly
abre el DISPOSITIVO en modo de solo lectura (por ejemplo, en Unix con el flag O_RDONLY). El valor predeterminado es abrirlo en modo de lectura/escritura.
-t, --typem
establece el bit MEDIUM TYPE en el cdb, lo que hace que los tipos de medio compatibles con la unidad de cinta (o cartucho de cinta) se coloquen en la respuesta. El valor predeterminado es solicitar los códigos de densidad.
-v, --verbose
aumenta el nivel de verbosidad (es decir, salida de depuración).
-V, --version
imprime la cadena de versión y luego sale.

ESTADO DE SALIDA

El estado de salida de sg_rep_density es 0 cuando es exitoso. De lo contrario, consulte la página del manual de sg3_utils(8).
