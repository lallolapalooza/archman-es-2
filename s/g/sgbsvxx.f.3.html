SGBSVXX calcula la solución del sistema de ecuaciones lineales A * X = B para matrices GB

Propósito:

!>
!>    SGBSVXX utiliza la factorización LU para calcular la solución de un
!>    sistema real de ecuaciones lineales A * X = B, donde A es una
!>    matriz de N por N y X y B son matrices de N por NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normativos como
!>    componentes máximos. SGBSVXX devolverá una solución con un error
!>    garantizado minúsculo (O(eps) donde eps es la precisión de la máquina de trabajo)
!>    a menos que la matriz esté muy mal condicionada, en cuyo caso se devuelve una advertencia.
!>    También se calculan y devuelven los números de condición relevantes.
!>
!>    SGBSVXX acepta factorizaciones y factores de 
es
!>    proporcionados por el usuario; consulte las definiciones de las
!>    opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada
!>    anterior a SGBSVXX también producirá una solución con errores de O(eps)
!>    o advertencias, pero no podemos hacer esa afirmación para factorizaciones
!>    y factores de 
es
!>    proporcionados por el usuario si difieren de lo que SGBSVXX produciría
!>    por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para
!>    equilibrar el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Si el sistema se equilibrará o no depende del escalado de la matriz A,
!>    pero si se utiliza el 
es
!>    , A se sobrescribe con diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del 
es
!>    si FACT = 'E') como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular inferior unitaria,
!>    y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U sea exactamente singular, entonces la
!>    subrutina retorna con INFO = i. De lo contrario, la forma factorizada de A
!>    se utiliza para estimar el número de condición de la matriz A (ver
!>    argumento RCOND). Si el recíproco del número de condición es menor que la
!>    precisión de la máquina, la subrutina aún continúa para resolver X
!>    y calcular los límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la subrutina utilizará refinamiento iterativo para intentar obtener un error
!>    y límites de error pequeños. El refinamiento calcula el residuo a
!>    al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el 
es
!>    , la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para que
!>    resuelva el sistema original antes del 
es
!>    .
!> 

!>     Algunos parámetros opcionales están agrupados en el array PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo los
!>     valores predeterminados son aceptables. Si los valores predeterminados son
!>     aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que el
!>     código fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT is CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se proporciona
!>     en la entrada, y si no, si la matriz A debe ser
!>     equilibrada antes de factorizarla.
!>       = 'F':  En la entrada, AF y IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con factores de escala dados por R y C.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará en AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará en AF y se factorizará.
!>

TRANS

!>          TRANS is CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N is INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

KL

!>          KL is INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU is INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB is REAL array, dimension (LDAB,N)
!>     En la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>     La j-ésima columna de A se almacena en la j-ésima columna del
!>     array AB como sigue:
!>     AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU) <= i <= min(N,j+kl)
!>
!>     Si FACT = 'F' y EQUED no es 'N', entonces AB debe haber sido
!>     equilibrada por los factores de escala en R y/o C. AB no se
!>     modifica si FACT = 'F' o 'N', o si FACT = 'E' y
!>     EQUED = 'N' en la salida.
!>
!>     En la salida, si EQUED .ne. 'N', A se escala como sigue:
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB is INTEGER
!>     La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB is REAL array, dimension (LDAFB,N)
!>     Si FACT = 'F', entonces AFB es un argumento de entrada y en la entrada
!>     contiene detalles de la factorización LU de la matriz de banda
!>     A, tal como la calcula SGBTRF. U se almacena como una matriz triangular superior
!>     de banda con KL+KU superdiagonales en las filas 1 a KL+KU+1,
!!>     y los multiplicadores utilizados durante la factorización se almacenan
!>     en las filas KL+KU+2 a 2*KL+KU+1. Si EQUED .ne. 'N', entonces AFB es
!>     la forma factorizada de

Function/Subroutine Documentation

sgbsvxx performs a general band solve Ab = x, and computes error bounds on the solution.

Arguments

TRANS
CHARACTER*1.

Specifies the form of the system of equations:

‘N’:

A x = b (No transpose)

‘T’:

AT x = b (Transpose)

‘C’:

AH x = b (Conjugate transpose)

N

INTEGER. The order of the band matrix A. N >= 0.

NB

INTEGER. The number of right hand sides.

M

INTEGER. The number of rows of the band matrix A. M >= 0.

KD

INTEGER. The number of super-diagonals of A. KD >= 0.

KL

INTEGER. The number of sub-diagonals of A. KL >= 0.

KU

INTEGER. The number of super-diagonals of A. KU >= 0.

A

REAL array, dimension (LDA, K+1) where K = max(KU, KD) is the number of super- and sub-diagonals.

Before entry, the leading M-by-N band matrix A, supplied column by column with relative to the main diagonal. The rest of the matrix is not specified.

After entry, A is overwritten by details of the factorization.

LDA

INTEGER. The leading dimension of the array A. LDA >= max(1,M).

B

REAL array, dimension (LDB, NB).

Before entry, the right-hand-side matrix of size M-by-NB. See also APPLY.

LDB

INTEGER. The leading dimension of the array B. LDB >= max(1,M).

Q

REAL array, dimension (LDQ, N).

Before entry, the N-by-N matrix Q. (Q must be orthogonal or unitary).

After entry, Q is overwritten by the inverse of Q. See also APPLY.

LDQ

INTEGER. The leading dimension of the array Q. LDQ >= max(1,N).

X

REAL array, dimension (LDX, NB).

After entry, the solution matrix M-by-NB.

LDX

INTEGER. The leading dimension of the array X. LDX >= max(1,M).

WORK

REAL array, dimension (4*N)

LWORK

INTEGER. The dimension of the array WORK.

LWORK >= 4*N.

IWORK

INTEGER array, dimension (N)

WORK2

REAL array, dimension (N)

INFO

INTEGER. = 0: Successful exit. The solution to every right-hand side is guaranteed.

< 0: If INFO = -i, the i-th argument had an illegal value

> 0 and <= N: U(INFO,INFO) is exactly zero. The factorization has been completed, but the factor U is exactly singular, so the solution and error bounds could not be computed. RCOND = 0 is returned.

= N+J: The solution corresponding to the Jth right-hand side is not guaranteed. The solutions corresponding to other right- hand sides K with K > J may not be guaranteed as well, but only the first such right-hand side is reported. If a small componentwise error is not requested (PARAMS(3) = 0.0) then the Jth right-hand side is the first with a normwise error bound that is not guaranteed (the smallest J such that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0) the Jth right-hand side is the first with either a normwise or componentwise error bound that is not guaranteed (the smallest J such that either ERR_BNDS_NORM(J,1) = 0.0 or ERR_BNDS_COMP(J,1) = 0.0). See the definition of ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information about all of the right-hand sides check ERR_BNDS_NORM or ERR_BNDS_COMP.

Description

The routine solves the band system of linear equations A*x = b, and then computes the normwise backward error, the componentwise backward error, and the condition number and its error estimate. An estimate is given for the condition number of the band system.

See.

LAPACK Working Note 373 for more information.

An example of how to call this function can be found in Section 3.3.5 of LAPACK Working Note 373.

Also see the following.

Parameters

Only positions up to NPARAMS are accessed; defaults are used for higher-numbered parameters.

       PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
            refinement or not.
         Default: 1.0
            = 0.0:  No refinement is performed, and no error bounds are
                    computed.
            = 1.0:  Use the double-precision refinement algorithm,
                    possibly with doubled-single computations if the
                    compilation environment does not support DOUBLE
                    PRECISION.
              (other values are reserved for future use)

       PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
            computations allowed for refinement.
         Default: 10
         Aggressive: Set to 100 to permit convergence using approximate
                     factorizations or factorizations other than LU. If
                     the factorization uses a technique other than
                     Gaussian elimination, the guarantees in
                     err_bnds_norm and err_bnds_comp may no longer be
                     trustworthy.

       PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
            will attempt to find a solution with small componentwise
            relative error in the double-precision algorithm.  Positive
            is true, 0.0 is false.
         Default: 1.0 (attempt componentwise convergence)
