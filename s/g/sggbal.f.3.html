Documentación de la función/subrutina

subrutina sggbal (character job, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, integer ilo, integer ihi, real, dimension( * ) lscale, real, dimension( * ) rscale, real, dimension( * ) work, integer info)

SGGBAL

Propósito:

!>
!> SGGBAL equilibra un par de matrices reales generales (A,B). Esto
!> implica, primero, permutar A y B mediante transformaciones de
!> semejanza para aislar los valores propios en los primeros 1 a ILO-1 y
!> los últimos IHI+1 a N elementos en la diagonal; y segundo, aplicar una
!> transformación de semejanza diagonal a las filas y columnas ILO a IHI
!> para que las filas y columnas sean lo más cercanas posible en norma. Ambos
!> pasos son opcionales.
!>
!> El equilibrado puede reducir la norma 1 de las matrices y mejorar la
!> precisión de los valores propios y/o vectores propios calculados en el
!> problema de valores propios generalizado A*x = lambda*B*x.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica las operaciones a realizar en A y B:
!>          = 'N':  ninguna:  simplemente establecer ILO = 1, IHI = N, LSCALE(I) = 1.0
!>                  y RSCALE(I) = 1.0 para i = 1,...,N.
!>          = 'P':  solo permutar;
!>          = 'S':  solo escalar;
!>          = 'B':  permutar y escalar.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz A de entrada.
!>          En la salida, A se sobrescribe con la matriz equilibrada.
!>          Si JOB = 'N', A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array REAL, de dimensión (LDB,N)
!>          En la entrada, la matriz B de entrada.
!>          En la salida, B se sobrescribe con la matriz equilibrada.
!>          Si JOB = 'N', B no se referencia.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI se establecen a enteros tales que en la salida
!>          A(i,j) = 0 y B(i,j) = 0 si i > j y
!>          j = 1,...,ILO-1 o i = IHI+1,...,N.
!>          Si JOB = 'N' o 'S', ILO = 1 e IHI = N.
!>

LSCALE

!>          LSCALE es un array REAL, de dimensión (N)
!>          Detalles de las permutaciones y factores de escala aplicados
!>          al lado izquierdo de A y B. Si P(j) es el índice de la
!>          intercambio de fila con la fila j, y D(j)
!>          es el factor de escala aplicado a la fila j, entonces
!>            LSCALE(j) = P(j)    para J = 1,...,ILO-1
!>                      = D(j)    para J = ILO,...,IHI
!>                      = P(j)    para J = IHI+1,...,N.
!>          El orden en que se realizan los intercambios es N a IHI+1,
!>          luego 1 a ILO-1.
!>

RSCALE

!>          RSCALE es un array REAL, de dimensión (N)
!>          Detalles de las permutaciones y factores de escala aplicados
!>          al lado derecho de A y B. Si P(j) es el índice de la
!>          intercambio de columna con la columna j, y D(j)
!>          es el factor de escala aplicado a la columna j, entonces
!>            LSCALE(j) = P(j)    para J = 1,...,ILO-1
!>                      = D(j)    para J = ILO,...,IHI
!>                      = P(j)    para J = IHI+1,...,N.
!>          El orden en que se realizan los intercambios es N a IHI+1,
!>          luego 1 a ILO-1.
!>

WORK

!>          WORK es un array REAL, de dimensión (lwork)
!>          lwork debe ser al menos max(1,6*N) cuando JOB = 'S' o 'B', y
!>          al menos 1 cuando JOB = 'N' o 'P'.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
