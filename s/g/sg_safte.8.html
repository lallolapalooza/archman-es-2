NOMBRE

sg_safte - accede al dispositivo de enclosure tolerante a fallos SCSI (SAF-TE)

SINOPSIS

sg_safte [--config] [--devstatus] [--encstatus] [--flags] [--help] [--hex] [--insertions] [--raw] [--usage] [--verbose] [--version] DISPOSITIVO

DESCRIPCIÓN

Obtiene el estado del enclosure (a través de un comando SCSI READ BUFFER). El DISPOSITIVO debe ser un dispositivo SAF-TE, que puede ser un controlador de array de almacenamiento (tipo de dispositivo periférico de INQUIRY 0xc) o un dispositivo procesador genérico (tipo de dispositivo periférico de INQUIRY 0x3).

Si no se proporcionan opciones (solo el argumento DISPOSITIVO), se informa del estado general del enclosure según lo informado por la opción --config.

OPCIONES

Los argumentos de las opciones largas son obligatorios también para las opciones cortas. Las opciones están ordenadas alfabéticamente según el nombre de la opción larga.

-c, --config
emitirá un CDB de Leer Configuración del Enclosure (READ BUFFER ID 0) al dispositivo, lo que devuelve una lista de los recursos de hardware del enclosure.
-d, --devstatus
emitirá un CDB de Leer Estado de Ranura del Dispositivo (READ BUFFER ID 4) al dispositivo, lo que devuelve información sobre el estado actual de cada unidad o ranura.
-s, --encstatus
emitirá un CDB de Leer Estado del Enclosure (READ BUFFER ID 1) al dispositivo, lo que devuelve el estado operativo de los componentes.
-f, --flags
emitirá un CDB de Leer Flags Globales (READ BUFFER ID 5) al dispositivo, que lee el estado más reciente de los flags globales del dispositivo procesador RAID.
-h, --help
muestra el mensaje de uso y luego sale.
-H, --hex
muestra la respuesta a un comando READ BUFFER en hexadecimal ASCII en la salida estándar. Si se usa una vez, muestra la respuesta del primer comando READ BUFFER (es decir, con buffer_id=0). Esta debería ser la configuración del enclosure. Si se usa dos veces (o más), se muestra la respuesta a comandos READ BUFFER subsiguientes.
-i, --insertions
emitirá un CDB de Leer Inserciones de Dispositivo (READ BUFFER ID 3) al dispositivo, lo que devuelve información sobre el número de veces que se han insertado dispositivos mientras el sistema RAID estaba encendido.
-r, --raw
muestra la respuesta a un comando READ BUFFER en binario en la salida estándar. Si se usa una vez, muestra la respuesta del primer comando READ BUFFER (es decir, con buffer_id=0). Esta debería ser la configuración del enclosure. Si se usa dos veces (o más), se muestra la respuesta a comandos READ BUFFER subsiguientes.
-u, --usage
emitirá un CDB de Leer Estadísticas de Uso (READ BUFFER ID 2) al dispositivo, que devuelve información sobre el tiempo total de uso y el número de ciclos de encendido del dispositivo RAID.
-v, --verbose
aumenta el nivel de verbosidad (es decir, salida de depuración).
-V, --version
imprime la cadena de versión y luego sale.

NOTAS

Esta implementación se basa en el documento de revisión intermedia con fecha 19970414 y denominado "SR041497.pdf". Por lo tanto, es bastante antiguo. Intel y nStor son los autores. Intel tiene un archivo zip que contiene este y otros documentos relacionados en la sección "SAF-TE: SCSI Accessed Fault Tolerant Enclosures Interface Specification" de esta página:

https://www.intel.com/content/www/us/en/servers/ipmi/ipmi-technical-resources.html

Una funcionalidad similar es proporcionada por los dispositivos SES (SCSI Enclosure Services) de SPC-4 (tipo de dispositivo periférico 0xd), que pueden ser consultados con la utilidad sg_ses.

EJEMPLOS

Para ver la configuración:


sg_safte /dev/sg1

Para ver el estado de las ranuras de los dispositivos:


sg_safte --devstatus /dev/sg1

ESTADO DE SALIDA

El estado de salida de sg_safte es 0 cuando tiene éxito. En caso contrario, consulte la página del manual sg3_utils(8).
