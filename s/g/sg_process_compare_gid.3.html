DESCRIPCIÓN

Las funciones sg_get_process_stats proporcionan estadísticas sobre los procesos en ejecución actualmente. Ambas funciones, sg_get_process_stats() y sg_get_process_stats_r(), toman un parámetro opcional de entradas, que apunta (cuando se proporciona) a un size_t para obtener el número de entradas del vector devueltas.

Las funciones sg_get_process_count_of() y sg_get_process_count_r() proporcionan una vista agregada de la tabla de procesos; entregan la cantidad de procesos por estado de proceso. sg_get_process_count() es en realidad una macro preprocesador para compatibilidad con versiones anteriores y llama a sg_get_process_count_of() con el parámetro pcs de sg_entire_process_count para emular el comportamiento hasta la versión 0.17.

Atajo de API

función devuelve propietario de datos
sg_get_process_stats sg_process_stats * libstatgrab (local del hilo)
sg_get_process_stats_r sg_process_stats * llamador
sg_get_process_count_of sg_process_count * libstatgrab (local del hilo)
sg_get_process_count_r sg_process_count * llamador

Los vectores sg_process_stats recibidos de sg_get_process_stats_r() o los resúmenes sg_process_count recibidos de sg_get_process_count_r deben liberarse usando sg_free_process_stats() o sg_free_process_count(), respectivamente. El llamador es responsable de hacerlo cuando los datos ya no son necesarios.

Estas funciones comparan dos entradas sg_process_stats y devuelven un int para representar cuál es mayor. El uso principal de estas funciones es ser pasadas a qsort para ordenar los sg_process_stats por el tipo dado.

Ejemplo

size_t entries;
sg_process_stats *proc_stats = NULL;
while( NULL != ( proc_stats = sg_get_process_stats_r(&entries) ) ) {
    /* ordenar entradas comparando el identificador del proceso */
    qsort( proc_stats, entries, sizeof(proc_stats[0]), &sg_process_compare_pid );
    show_proc_stats( proc_stats );
    sg_free_process_stats( proc_stats );
}

VALORES DE RETORNO

La estructura devuelta por sg_get_process_stats es de tipo sg_process_stats.

typedef struct {
        char *process_name;
        char *proctitle;
        pid_t pid;    /* identificador del proceso */
        pid_t parent; /* PID del padre */
        pid_t pgid;   /* PID del líder del grupo de procesos */
        pid_t sessid; /* ID de sesión a la que pertenece el proceso */
        uid_t uid;
        uid_t euid;
        gid_t gid;
        gid_t egid;
        unsigned long long context_switches;
        unsigned long long voluntary_context_switches;
        unsigned long long involuntary_context_switches;
        unsigned long long proc_size; /* en bytes */
        unsigned long long proc_resident; /* en bytes */
        time_t start_time; /* Cuándo se inició el proceso */
        time_t time_spent; /* tiempo de ejecución en segundos */
        double cpu_percent;
        int nice;
        sg_process_state state;
        time_t systime;
} sg_process_stats;

typedef enum {
        SG_PROCESS_STATE_RUNNING,
        SG_PROCESS_STATE_SLEEPING,
        SG_PROCESS_STATE_STOPPED,
        SG_PROCESS_STATE_ZOMBIE,
        SG_PROCESS_STATE_UNKNOWN
} sg_process_state;
process_name
El nombre del comando que se ejecutó. El contenido de este campo depende en gran medida del sistema operativo subyacente; algunos almacenan el nombre base que el ejecutable pasa a la llamada del sistema exec(2), otros la ruta completa. La mayoría de los sistemas operativos restringen el tamaño de este campo; algunos, como la familia *BSD, a un valor muy bajo de 15 bytes.

Este campo suele ser inmutable para los procesos del espacio de usuario.

proctitle
La línea de comandos (el "título") del proceso. Tenga en cuenta que esto puede ser modificado por el proceso, por lo que no se garantiza que sea la línea de comandos original.
pid
El identificador del proceso.
parent
El PID del proceso padre.
pgid
El PID del líder del grupo de procesos.
sessid
El ID de sesión del proceso.
uid
El ID del usuario con el que se está ejecutando el proceso.
euid
El ID del usuario efectivo con el que se está ejecutando el proceso.
gid
El ID del grupo con el que se está ejecutando el proceso.
egid
El ID del grupo efectivo con el que se está ejecutando el proceso.
context_switches
El número de cambios de contexto de este proceso (voluntarios e involuntarios).
voluntary_context_switches
El número de cambios de contexto voluntarios de este proceso (p. ej., al llamar a sched_yield() o sleep()).
involuntary_context_switches
El número de cambios de contexto involuntarios de este proceso (p. ej., cuota de tiempo agotada o señal enviada).
proc_size
El tamaño de memoria virtual del proceso en bytes.
proc_resident
El tamaño de memoria residente del proceso en bytes.
start_time
El tiempo (segundos desde la época) en que se inició el proceso.
time_spent
El tiempo de CPU total consumido por este proceso desde su inicio, en segundos.
cpu_percent
El porcentaje de uso de CPU del proceso.
nice
El valor "nice" del proceso, que afecta su prioridad de programación.
state
El estado actual del proceso, según lo definido por sg_process_state. Los valores posibles son:
SG_PROCESS_STATE_RUNNING
El proceso se está ejecutando o listo para ejecutarse.
SG_PROCESS_STATE_SLEEPING
El proceso está esperando a que ocurra un evento.
SG_PROCESS_STATE_STOPPED
El proceso ha sido detenido (p. ej., por una señal).
SG_PROCESS_STATE_ZOMBIE
El proceso ha terminado pero su entrada de tabla de procesos aún no ha sido liberada por su padre.
SG_PROCESS_STATE_UNKNOWN
El estado del proceso es desconocido.
systime
Tiempo de sistema acumulado para el proceso en segundos.

Las funciones sg_get_process_count_of() y sg_get_process_count_r() devuelven un puntero a una estructura sg_process_count. Esta estructura se define a continuación:

typedef struct {
        unsigned long long total;
        unsigned long long running;
        unsigned long long sleeping;
        unsigned long long stopped;
        unsigned long long zombie;
} sg_process_count;
total
El número total de procesos en el sistema.
running
El número de procesos actualmente en estado RUNNING.
sleeping
El número de procesos actualmente en estado SLEEPING.
stopped
El número de procesos actualmente en estado STOPPED.
zombie
El número de procesos actualmente en estado ZOMBIE.

Las funciones sg_get_process_stats() y sg_get_process_stats_r() devuelven un puntero a un array de estructuras sg_process_stats. El parámetro entries contendrá el número de elementos en el array devuelto.

Las funciones sg_get_process_count(), sg_get_process_count_of() y sg_get_process_count_r() devuelven un puntero a una estructura sg_process_count que contiene un recuento agregado de procesos por estado.

Las funciones de comparación (p. ej., sg_process_compare_pid()) devuelven un entero negativo si el primer argumento es menor que el segundo, cero si son iguales y un entero positivo si el primer argumento es mayor que el segundo.

Las funciones que devuelven datos (p. ej., sg_get_process_stats_r() y sg_get_process_count_r()) devuelven NULL si ocurre un error.

Las funciones de liberación (p. ej., sg_free_process_stats()) devuelven SG_ERROR_NONE si tiene éxito, o un código de error sg_error si falla.
