NOMBRE

sg_referrals - envía el comando SCSI REPORT REFERRALS

SINOPSIS

sg_referrals [--ayuda] [--hex] [--lba=LBA] [--maxlen=LEN] [--one-segment] [--raw] [--readonly] [--verbose] [--version] DISPOSITIVO

DESCRIPCIÓN

Envía el comando SCSI REPORT REFERRALS al DISPOSITIVO y muestra la respuesta. Este comando se introdujo en la revisión 24 del borrador de SBC-3 y los dispositivos que soportan referencias deberían soportar este comando.

La acción por defecto es decodificar la respuesta para todos los descriptores de referencia de segmentos de datos de usuario. La cantidad de salida se puede reducir con las opciones --lba y --one-segment.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-h, --ayuda
muestra el mensaje de uso y luego sale.
-H, --hex
muestra la respuesta a este comando en hexadecimal ASCII.
-l, --lba=LBA
donde LBA es la Dirección de Bloque Lógico (LBA) en el primer segmento de datos de usuario para el cual el DISPOSITIVO debe informar los datos del parámetro de referencias.
-m, --maxlen=LEN
donde LEN es la longitud (máxima) de la respuesta en bytes. Se coloca en el campo "longitud de asignación" del cdb. Si no se proporciona, se usan 256. 256 es suficiente espacio para la cabecera de respuesta y los descriptores de segmento de datos de usuario.
-s, --one-segment
informa solo el segmento de datos de usuario del segmento especificado por el parámetro LBA.
-r, --raw
muestra la respuesta en binario (a stdout).
-R, --readonly
abre el DISPOSITIVO en modo solo lectura (por ejemplo, en Unix con la bandera O_RDONLY). El valor por defecto es abrirlo en modo lectura-escritura.
-v, --verbose
aumenta el nivel de verbosidad (es decir, salida de depuración). La salida adicional causada por esta opción se envía a stderr.
-V, --version
imprime la cadena de versión y luego sale.

NOTAS

Para una discusión sobre referencias, véase la sección 4.25 de sbc3r25.pdf en https://www.t10.org (o la sección correspondiente de un borrador posterior).

ESTADO DE SALIDA

El estado de salida de sg_referrals es 0 cuando tiene éxito. De lo contrario, véase la página del manual sg3_utils(8).
