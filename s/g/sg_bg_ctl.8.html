NOMBRE

sg_bg_ctl - enviar comando SCSI BACKGROUND CONTROL

SINOPSIS

sg_bg_ctl [--ctl=CTL] [--help] [--time=TN] [--verbose] [--version] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI BACKGROUND CONTROL al DISPOSITIVO. Este comando se encontró por primera vez en el borrador del estándar SBC-4 revisión 8 (sbc4r08.pdf). Se puede utilizar para iniciar y detener 'operaciones de fondo avanzadas' en el DISPOSITIVO. Solo los dispositivos aprovisionados en recursos o thin-provisioned (unidades lógicas que son típicamente discos (de estado sólido)) admiten este comando. Esas operaciones de fondo avanzadas a menudo incluyen operaciones de tipo recolección de basura que pueden degradar el rendimiento del disco mientras se realizan.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-c, --ctl=CTL
CTL es el valor colocado en el campo BO_CTL del comando BACKGROUND CONTROL (cdb). Es un campo de dos bits, por lo que tiene 4 variantes: 0 no cambia las operaciones de fondo avanzadas iniciadas por el host; 1 inicia estas operaciones; 2 detiene estas operaciones y 3 está reservado. El valor predeterminado es 0.
-h, --help
muestra el mensaje de uso y luego sale.
-t, --time=TN
TN es un tiempo máximo (con una unidad de 100 ms o 1/10 de segundo) durante el cual pueden ocurrir operaciones de fondo avanzadas. Este valor se ignora si el argumento CTL es distinto de 1. El valor predeterminado es 0, lo que significa que no hay límite de tiempo máximo. Solo se pueden dar valores de 0 a 255 (que son 25.5 segundos). Este valor se coloca en el campo BO_TIME del comando BACKGROUND CONTROL.
-v, --verbose
aumenta el nivel de verbosidad (es decir, salida de depuración).
-V, --version
imprime la cadena de versión y luego sale.

NOTAS

Según T10, el soporte para 'operaciones de control de fondo' se indica con el bit BOCS establecido en la página de VPD de características del dispositivo de bloque [0xb1]. La configuración del bit BOCS se puede verificar con las utilidades sg_vpd y sdparm (y es de solo lectura). Existe una página de modo de control de operaciones de fondo [0xa, 0x6] con un campo BO_MODE para modificar la acción de esta operación. El campo BO_MODE se puede acceder y posiblemente modificar con la utilidad sdparm. El campo BO_STATUS se puede encontrar en la página de registro de operaciones de fondo [0x15, 0x2] y se puede ver con la utilidad sg_logs.

El borrador actual que describe esta área es SBC-4 revisión 10 (sbc4r10.pdf) en la cláusula 4.33. Contiene el siguiente ejemplo de una operación de fondo: "Las operaciones de fondo avanzadas pueden incluir operaciones de borrado de bloques NAND, operaciones de lectura de medios y operaciones de escritura de medios (por ejemplo, recolección de basura), que pueden afectar el tiempo de respuesta de las solicitudes normales de lectura o escritura del cliente de la aplicación."

ESTADO DE SALIDA

El estado de salida de sg_bg_ctl es 0 cuando tiene éxito. De lo contrario, consulte la página del manual sg3_utils(8).
