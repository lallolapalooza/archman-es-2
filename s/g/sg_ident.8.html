NOMBRE

sg_ident - enviar comando SCSI REPORT/SET IDENTIFYING INFORMATION

SINOPSIS

sg_ident [--ascii] [--clear] [--help] [--itype=IT] [--raw] [--set] [--verbose] [--version] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI REPORT IDENTIFYING INFORMATION o SET IDENTIFYING INFORMATION a DISPOSITIVO. Antes de SPC-4 (revisión 7) estos comandos se llamaban REPORT DEVICE IDENTIFIER y SET DEVICE IDENTIFIER respectivamente. Los dispositivos SCSI que soportan estos dos comandos permiten a los usuarios escribir (establecer) información de identificación y reportarla en algún momento posterior. La información es persistente (es decir, almacenada en algún medio no volátil dentro del dispositivo SCSI que sobrevivirá a un corte de energía).

Normalmente el espacio asignado para la información es limitado: SPC-4 (revisión 7) establece que para el tipo de información 0, la longitud mínima es de 64 bytes y la máxima es de 512 bytes. Para otros tipos de información (1 a 126 inclusive) la longitud máxima es de 256 bytes. Además, los tipos de información 1 a 126 (inclusive) deben contener una cadena UTF-8 terminada en nulo. El autor ha visto discos más antiguos que solo soportan 16 bytes.

La acción por defecto cuando no se dan opciones es invocar el comando Report Identifying Information con el tipo de información por defecto a cero. Los informes de error se envían a stderr. Por defecto, la información se muestra en ASCII-HEX (hasta 16 bytes por línea) con una representación ASCII a la derecha, reemplazando los caracteres no imprimibles con puntos.

OPCIONES

Los argumentos para las opciones largas son obligatorios para las opciones cortas también.

-A, --ascii
invoca el comando Report Identifying Information y si se encuentra algo, lo interpreta como ASCII (o UTF-8, que depende de la configuración regional) y muestra la información en stdout.
-C, --clear
invoca el comando Set Identifying Information con una longitud de información de cero. Esto tiene el efecto de borrar la información existente.
-h, --help
muestra el mensaje de uso y luego sale.
-i, --itype=IT
donde IT es el tipo de información. Por defecto es cero. El valor máximo es 127, que es especial y no se puede usar con --set o --clear. El tipo de información 127 (si se soporta) hace que el comando REPORT IDENTIFYING INFORMATION responda con una lista de tipos de información disponibles y sus longitudes máximas en bytes. Los tipos de información impares entre 3 y 125 (inclusive) no deben usarse (ya que colisionan con el estándar SCC-2).
-r, --raw
invoca el comando Report Identifying Information y si se encuentra algo, envía la información (que puede ser binaria) a stdout. No se envía nada más a stdout, sin embargo, los informes de error, si los hay, se envían a stderr.
-S, --set
primero lee stdin hasta detectar un EOF y luego invoca el comando Set Identifying Information para establecer como información lo que se ha recuperado de stdin. La cantidad de datos leídos debe tener una longitud entre 1 y 512 bytes (inclusive).
-v, --verbose
aumenta el nivel de verbosidad (es decir, salida de depuración).
-V, --version
imprime la cadena de versión y luego sale.

Esta utilidad permite a los usuarios escribir su propia información de identificación en sus dispositivos SCSI. Hay varios otros tipos de descriptores (o designadores) que el usuario no puede cambiar. Estos incluyen el comando SCSI INQUIRY con sus cadenas estándar de identificación de fabricante y producto, y el nivel de revisión del producto; además de la gran cantidad de información proporcionada por la página de "Device Identification" VPD (ver sg_vpd). También existe el comando READ MEDIA SERIAL NUMBER (ver sg_rmsn). El conjunto de comandos MMC-4 para CD y DVD tiene una característica de "número de serie del medio" (0x109) [y una característica de "número de serie de la unidad lógica"]. Estos se pueden ver con la utilidad sg_get_config.

EJEMPLOS

Primero, para ver si existe una información cuyo formato es desconocido (para el tipo de información 0), no use opciones:


# sg_ident /dev/sdb
00 31 32 33 34 35 36 37 38 39 30 1234567890

Si es ASCII, se puede mostrar como tal:


# sg_ident --ascii /dev/sdb
1234567890

La información se puede copiar a un archivo, borrar y luego reafirmar con esta secuencia:


# sg_ident --raw /dev/sdb > t
# sg_ident --clear /dev/sdb
# cat t | sg_ident --set /dev/sdb

ESTADO DE SALIDA

El estado de salida de sg_ident es 0 cuando tiene éxito. De lo contrario, consulte la página del manual sg3_utils(8).
