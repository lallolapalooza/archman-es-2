Documentación de la Función/Subrutina

subrutina sgerqs (integer m, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( ldb, * ) b, integer ldb, real, dimension( lwork ) work, integer lwork, integer info)

SGERQS

Propósito:

!>
!> Calcula una solución de norma mínima
!>     min || A*X - B ||
!> usando la factorización RQ
!>     A = R*Q
!> calculada por SGERQF.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= M >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de B.  NRHS >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          Detalles de la factorización RQ de la matriz original A,
!>          devueltos por SGERQF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= M.
!>

TAU

!>          TAU es un array REAL, de dimensión (M)
!>          Detalles de la matriz ortogonal Q.
!>

B

!>          B es un array REAL, de dimensión (LDB,NRHS)
!>          En la entrada, los vectores del lado derecho para el sistema lineal.
!>          En la salida, los vectores solución X. Cada vector solución
!>          está contenido en las filas 1:N de una columna de B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

WORK

!>          WORK es un array REAL, de dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.  LWORK debe ser al menos NRHS,
!>          y debería ser al menos NRHS*NB, donde NB es el tamaño del bloque
!>          para este entorno.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
