subrutina sgelsd (m, n, nrhs, a, lda, b, ldb, s, rcond, rank, work, lwork, iwork, info)
SGELSD calcula la solución de norma mínima para un problema de mínimos cuadrados lineales para matrices GE

Documentación de función/subrutina

subrutina sgelsd (integer m, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) s, real rcond, integer rank, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

SGELSD calcula la solución de norma mínima para un problema de mínimos cuadrados lineales real

Propósito:

!>
!> SGELSD calcula la solución de norma mínima para un problema de mínimos cuadrados lineales real
!>     minimizando la norma 2 de | b - A*x |
!> utilizando la descomposición en valores singulares (SVD) de A. A es una matriz M por N
!> que puede ser de rango deficiente.
!>
!> Se pueden manejar varios vectores de mano derecha b y vectores de solución x en una
!> sola llamada; se almacenan como las columnas de la matriz B de mano derecha M por NRHS
!> y la matriz de solución X de N por NRHS.
!>
!> El problema se resuelve en tres pasos:
!> (1) Reducir la matriz de coeficientes A a forma bidiagonal con
!>     transformaciones de Householder, reduciendo el problema original a un
!>     (BLS)
!> (2) Resolver el BLS usando un enfoque de división y conquista.
!> (3) Aplicar todas las transformaciones de Householder hacia atrás para resolver
!>     el problema de mínimos cuadrados original.
!>
!> El rango efectivo de A se determina tratando como cero aquellos
!> valores singulares que son menores que RCOND multiplicado por el valor singular más grande.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de manos derechas, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, A ha sido destruida.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es array REAL, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B de mano derecha M por NRHS.
!>          En la salida, B se sobrescribe con la matriz de solución X de N por NRHS.
!>          Si m >= n y RANK = n, la suma de cuadrados residual
!>          para la solución en la i-ésima columna se da por la suma de
!>          cuadrados de los elementos n+1:m en esa columna.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,max(M,N)).
!>

S

!>          S es array REAL, dimensión (min(M,N))
!>          Los valores singulares de A en orden decreciente.
!>          El número de condición de A en la norma 2 = S(1)/S(min(m,n)).
!>

RCOND

!>          RCOND es REAL
!>          RCOND se utiliza para determinar el rango efectivo de A.
!>          Los valores singulares S(i) <= RCOND*S(1) se tratan como cero.
!>          Si RCOND < 0, se utiliza la precisión de la máquina en su lugar.
!>

RANK

!>          RANK es INTEGER
!>          El rango efectivo de A, es decir, el número de valores singulares
!>          que son mayores que RCOND*S(1).
!>

WORK

!>          WORK es array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK debe ser al menos 1.
!>          La cantidad mínima exacta de espacio de trabajo necesario depende de M,
!>          N y NRHS. Mientras LWORK sea al menos
!>              12*N + 2*N*SMLSIZ + 8*N*NLVL + N*NRHS + (SMLSIZ+1)**2,
!>          si M es mayor o igual que N o
!>              12*M + 2*M*SMLSIZ + 8*M*NLVL + M*NRHS + (SMLSIZ+1)**2,
!>          si M es menor que N, el código se ejecutará correctamente.
!>          SMLSIZ es devuelto por ILAENV y es igual al tamaño máximo
!>          de los subproblemas en la parte inferior del árbol de cómputo
!>          (generalmente alrededor de 25), y
!>             NLVL = MAX( 0, INT( LOG_2( MIN( M,N )/(SMLSIZ+1) ) ) + 1 )
!>          Para un buen rendimiento, LWORK generalmente debería ser mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK y
!>          el tamaño mínimo del array IWORK, y devuelve estos valores como
!>          las primeras entradas de los arrays WORK e IWORK, y ningún mensaje de error
!>          relacionado con LWORK es emitido por XERBLA.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (MAX(1,LIWORK))
!>          LIWORK >= max(1, 3*MINMN*NLVL + 11*MINMN),
!>          donde MINMN = MIN( M,N ).
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK mínimo.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  el algoritmo para calcular la SVD no convergió;
!>                si INFO = i, i elementos fuera de la diagonal de una forma
!>                bidiagonal intermedia no convergieron a cero.
!>
