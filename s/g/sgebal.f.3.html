DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina sgebal (character job, integer n, real, dimension( lda, * ) a, integer lda, integer ilo, integer ihi, real, dimension( * ) scale, integer info)

SGEBAL

Propósito:

!>
!> SGEBAL equilibra una matriz real general A. Esto implica, primero,
!> permutar A mediante una transformación de similitud para aislar los
!> valores propios en los primeros 1 a ILO-1 y los últimos IHI+1 a N elementos en la
!> diagonal; y segundo, aplicar una transformación de similitud diagonal
!> a las filas y columnas ILO a IHI para que las filas y columnas tengan normas lo
!> más cercanas posible. Ambos pasos son opcionales.
!>
!> El equilibrado puede reducir la norma 1 de la matriz y mejorar la
!> precisión de los valores propios y/o vectores propios calculados.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica las operaciones a realizar en A:
!>          = 'N':  ninguna: simplemente establecer ILO = 1, IHI = N, SCALE(I) = 1.0
!>                  para i = 1,...,N;
!>          = 'P':  solo permutar;
!>          = 'S':  solo escalar;
!>          = 'B':  permutar y escalar.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, dimensionado (LDA,N)
!>          A la entrada, la matriz de entrada A.
!>          A la salida, A se sobrescribe con la matriz equilibrada.
!>          Si JOB = 'N', A no se referencia.
!>          Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI se establecen en enteros tales que a la salida
!>          A(i,j) = 0 si i > j y j = 1,...,ILO-1 o I = IHI+1,...,N.
!>          Si JOB = 'N' o 'S', ILO = 1 y IHI = N.
!>

SCALE

!>          SCALE es un array REAL, dimensionado (N)
!>          Detalles de las permutaciones y factores de escala aplicados a
!>          A.  Si P(j) es el índice de la fila y columna intercambiada
!>          con la fila y columna j y D(j) es el factor de escala
!>          aplicado a la fila y columna j, entonces
!>          SCALE(j) = P(j)    para j = 1,...,ILO-1
!>                   = D(j)    para j = ILO,...,IHI
!>                   = P(j)    para j = IHI+1,...,N.
!>          El orden en que se realizan los intercambios es de N a IHI+1,
!>          luego de 1 a ILO-1.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles Adicionales:

!>
!>  Las permutaciones consisten en intercambios de filas y columnas que
!>  ponen la matriz en la forma
!>
!>             ( T1   X   Y  )
!>     P A P = (  0   B   Z  )
!>             (  0   0   T2 )
!>
!>  donde T1 y T2 son matrices triangulares superiores cuyos valores propios se encuentran
!>  a lo largo de la diagonal. Los índices de columna ILO y IHI marcan las columnas de
!>  inicio y fin de la submatriz B. El equilibrado consiste en aplicar
!>  una transformación de similitud diagonal inv(D) * B * D para que las
!>  normas 1 de cada fila de B y su columna correspondiente sean casi iguales.
!>  La matriz de salida es
!>
!>     ( T1     X*D          Y    )
!>     (  0  inv(D)*B*D  inv(D)*Z ).
!>     (  0      0           T2   )
!>
!>  La información sobre las permutaciones P y la matriz diagonal D
!>  se devuelve en el vector SCALE.
!>
!>  Esta subrutina se basa en la rutina BALANC de EISPACK.
