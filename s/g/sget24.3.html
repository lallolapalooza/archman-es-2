Propósito:

!>
!>    SGET24 comprueba el problema del autovalor (forma de Schur) no simétrico
!>    conductor experto SGEESX.
!>
!>    Si COMP = .FALSE., las primeras 13 de las siguientes pruebas se realizarán
!>    en la matriz de entrada A, y también las pruebas 14 y 15
!>    si LWORK es suficientemente grande.
!>    Si COMP = .TRUE., se realizarán las 17 pruebas.
!>
!>    (1)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>           (sin ordenación de autovalores)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de autovectores de Schur, y T está en forma de Schur
!>      (sin ordenación de autovalores).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (sin ordenación de autovalores).
!>
!>    (4)     0     si WR+sqrt(-1)*WI son autovalores de T
!>            1/ulp en caso contrario
!>            (sin ordenación de autovalores)
!>
!>    (5)     0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de autovalores)
!>
!>    (6)     0     si autovalores(con VS) = autovalores(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de autovalores)
!>
!>    (7)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de autovectores de Schur, y T está en forma de Schur
!>      (con ordenación de autovalores).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (con ordenación de autovalores).
!>
!>    (10)    0     si WR+sqrt(-1)*WI son autovalores de T
!>            1/ulp en caso contrario
!>            Si el espacio de trabajo es suficiente, también compara WR, WI con y
!>            sin números de condición recíprocos
!>            (con ordenación de autovalores)
!>
!>    (11)    0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            Si el espacio de trabajo es suficiente, también compara T con y sin
!>            números de condición recíprocos
!>            (con ordenación de autovalores)
!>
!>    (12)    0     si autovalores(con VS) = autovalores(sin VS),
!>            1/ulp en caso contrario
!>            Si el espacio de trabajo es suficiente, también compara VS con y sin
!>            números de condición recíprocos
!>            (con ordenación de autovalores)
!>
!>    (13)    si la ordenación funcionó y SDIM es el número de
!>            autovalores que fueron SELECCIONADOS
!>            Si el espacio de trabajo es suficiente, también compara SDIM con y
!>            sin números de condición recíprocos
!>
!>    (14)    si RCONDE es el mismo sin importar si VS y/o RCONDV se calcularon
!>
!>    (15)    si RCONDV es el mismo sin importar si VS y/o RCONDE se calcularon
!>
!>    (16)  |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>       RCONDE es el número de condición promedio recíproco de autovalores
!>       calculado por SGEESX y RCDEIN (el valor verdadero precalculado)
!>       se proporciona como entrada. cond(RCONDE) es el número de condición
!>       de RCONDE, y tiene en cuenta los errores al calcular RCONDE,
!>       de modo que la cantidad resultante debe ser O(ULP). cond(RCONDE)
!>       se da esencialmente por norm(A)/RCONDV.
!>
!>    (17)  |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>       RCONDV es el número de condición recíproco del subespacio invariante derecho
!>       calculado por SGEESX y RCDVIN (el valor verdadero precalculado)
!>       se proporciona como entrada. cond(RCONDV) es el número de condición
!>       de RCONDV, y tiene en cuenta los errores al calcular RCONDV,
!>       de modo que la cantidad resultante debe ser O(ULP).
!>       cond(RCONDV) se da esencialmente por norm(A)/RCONDE.
!>

SGET24 Esta rutina se utiliza para comprobar la precisión de las subrutinas de cálculo de autovalores/autovectores de LAPACK.
Función/Documentación de subrutina SGET24 SGET24 es una subrutina de FORTRAN 77. Realiza 17 pruebas de precisión para la subrutina SGEESX de LAPACK. Las pruebas se basan en la documentación de las subrutinas de cálculo de autovalores/autovectores de LAPACK. Arguments: CHARACTER*1 JOBZ Indica si calcular autovectores. CHARACTER*1 COMPQ Indica si calcular los vectores de Schur. INTEGER N El orden de la matriz A. N >= 0. REAL A(LDA,N) Matriz de entrada de dimensiones N x N. INTEGER LDA Dimensión líder de A. LDA >= max(1, N). REAL WR, WI Arrays de dimensiones (N). Contienen los autovalores de A. REAL VS(LDVS,N) Array de dimensiones (LDVS,N). Contiene los vectores de Schur de A. INTEGER LDVS Dimensión líder de VS. LDVS >= max(1, N). REAL RCOND El número de condición recíproco de la matriz A. INTEGER SELCTG Array de dimensiones (N). Indica qué autovalores seleccionar para el cálculo de los vectores invariantes de subespacio derecho. REAL WKSCHUR(N,N) Array de trabajo de dimensiones (N,N). REAL WKSUP(N) Array de trabajo de dimensiones (N). INTEGER LWORK Longitud de WORK. LWORK >= max(3*N, N+N**2). INTEGER IWORK(N) Array de trabajo de dimensiones (N). LOGICAL BWORK(N) Array de trabajo de dimensiones (N). INTEGER INFO Si es 0, la ejecución fue exitosa. Si es <0, el parámetro de entrada -INFO tenía un valor incorrecto. Si es >0, SGEESX devolvió un código de error, cuyo valor absoluto se devuelve. WRTMP WRTMP es un array REAL, de dimensiones (N) WITMP WITMP es un array REAL, de dimensiones (N) Al igual que WR, WI, estos arrays contienen los autovalores de A, pero ordenados por parte real creciente. VS VS es un array REAL, de dimensiones (LDVS, N) VS contiene los vectores de Schur calculados. LDVS LDVS es INTEGER Dimensión líder de VS. Debe ser al menos max(1, N). VS1 VS1 es un array REAL, de dimensiones (LDVS, N) VS1 contiene otra copia de los vectores de Schur calculados. RCDEIN RCDEIN es REAL Cuando COMP = .TRUE. RCDEIN contiene el recíproco precalculado del número de condición para el promedio de los autovalores seleccionados. RCDVIN RCDVIN es REAL Cuando COMP = .TRUE. RCDVIN contiene el recíproco precalculado del número de condición para el subespacio invariante derecho seleccionado. NSLCT NSLCT es INTEGER Cuando COMP = .TRUE. el número de autovalores seleccionados correspondientes a los valores precalculados RCDEIN y RCDVIN. ISLCT ISLCT es un array INTEGER, de dimensiones (NSLCT) Cuando COMP = .TRUE. ISLCT selecciona los autovalores de la matriz de entrada correspondientes a los valores precalculados RCDEIN y RCDVIN. Para I=1, ... ,NSLCT, si ISLCT(I) = J, entonces el autovalor con el J-ésimo valor real más grande se selecciona. No se hace referencia si COMP = .FALSE. RESULT RESULT es un array REAL, de dimensiones (17) Los valores calculados por las 17 pruebas descritas anteriormente. Los valores se limitan actualmente a 1/ulp, para evitar desbordamientos. WORK WORK es un array REAL, de dimensiones (LWORK) LWORK LWORK es INTEGER El número de entradas en WORK a pasar a SGEESX. Esto debe ser al menos 3*N, y N+N**2 si las pruebas 14-16 van a ser realizadas. IWORK IWORK es un array INTEGER, de dimensiones (N*N) BWORK BWORK es un array LOGICAL, de dimensiones (N) INFO Si es 0, salida exitosa. Si es <0, el parámetro de entrada -INFO tenía un valor incorrecto. Si es >0, SGEESX devolvió un código de error, el valor absoluto del cual se devuelve.
