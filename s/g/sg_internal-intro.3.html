NOMBRE

sg_internal-intro - obtener estadísticas del sistema

SINOPSIS

#include "tools.h"

DESCRIPCIÓN

La biblioteca statgrab está organizada en componentes, donde cada componente contiene funciones interrelacionadas. Otros componentes se dan a conocer al componente global llenando una estructura sg_comp_init y agregándola a la lista comp_info en src/libstatgrab/globals.c. Ver sg_comp_init(3) para detalles.

El componente de gestión de errores es mixto, parcialmente público (obtener estado de error), parcialmente privado (modificar estado de error). El último error se mantiene por hilo una vez que la inicialización del componente de error se ejecuta una vez.

La gestión de memoria se realiza a través de los componentes vector y tools. La gestión de memoria abarca la gestión optimizada de vectores (creación, redimensionamiento, liberación, comparación, ...) y la gestión dinámica de almacenamiento (gestión mejorada de cadenas).
