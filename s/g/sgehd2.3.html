Documentación de Función/Subrutina

subrutina sgehd2 (integer n, integer ilo, integer ihi, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer info)

SGEHD2 reduce una matriz general cuadrada real a la forma de Hessenberg superior utilizando un algoritmo no bloqueado.

Propósito:

!>
!> SGEHD2 reduce una matriz general real A a la forma de Hessenberg superior H por
!> una transformación de semejanza ortogonal:  Q**T * A * Q = H .
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>
!>          Se asume que A ya es triangular superior en las filas
!>          y columnas 1:ILO-1 e IHI+1:N. ILO e IHI son normalmente
!>          establecidos por una llamada previa a SGEBAL; de lo contrario, deberían
!>          ser establecidos a 1 y N respectivamente. Ver Detalles Adicionales.
!>          1 <= ILO <= IHI <= max(1,N).
!>

A

!>          A es un array REAL, de dimensión (LDA,N)
!>          En la entrada, la matriz general n por n a reducir.
!>          En la salida, el triángulo superior y la primera subdiagonal de A
!>          se sobrescriben con la matriz de Hessenberg superior H, y los
!>          elementos debajo de la primera subdiagonal, con el array TAU,
!>          representan la matriz ortogonal Q como un producto de
!>          reflejos elementales. Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

TAU

!>          TAU es un array REAL, de dimensión (N-1)
!>          Los factores escalares de los reflejos elementales (ver Detalles
!>          Adicionales).
!>

WORK

!>          WORK es un array REAL, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de (ihi-ilo) reflejos
!>  elementales
!>
!>     Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real, y v es un vector real con
!>  v(1:i) = 0, v(i+1) = 1 y v(ihi+1:n) = 0; v(i+2:ihi) se almacena en la
!>  salida en A(i+2:ihi,i), y tau en TAU(i).
!>
!>  El contenido de A se ilustra con el siguiente ejemplo, con
!>  n = 7, ilo = 2 e ihi = 6:
!>
!>  en la entrada,                    en la salida,
!>
!>  ( a   a   a   a   a   a   a )    (  a   a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      h   h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  v4  h   h   h )
!>  (                         a )    (                          a )
!>
!>  donde a denota un elemento de la matriz original A, h denota un
!>  elemento modificado de la matriz de Hessenberg superior H, y vi denota un
!>  elemento del vector que define H(i).
!>
