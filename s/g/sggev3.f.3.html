subrutina sggev3 (character jobvl, character jobvr, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) alphar, real, dimension( * ) alphai, real, dimension( * ) beta, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, real, dimension( * ) work, integer lwork, integer info)

SGGEV3 calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE (algoritmo en bloques)

Propósito:

!>
!> SGGEV3 calcula para un par de matrices reales no simétricas N por N (A,B)
!> los valores propios generalizados, y opcionalmente, los vectores propios
!> generalizados izquierdos y/o derechos.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar
!> lambda o una relación alpha/beta = lambda, tal que A - lambda*B es
!> singular. Se representa usualmente como el par (alpha,beta), ya que
!> hay una interpretación razonable para beta=0, e incluso para ambos
!> siendo cero.
!>
!> El vector propio derecho v(j) correspondiente al valor propio lambda(j)
!> de (A,B) satisface
!>
!>                  A * v(j) = lambda(j) * B * v(j).
!>
!> El vector propio izquierdo u(j) correspondiente al valor propio lambda(j)
!> de (A,B) satisface
!>
!>                  u(j)**H * A  = lambda(j) * u(j)**H * B .
!>
!> donde u(j)**H es la transpuesta conjugada de u(j).
!>
!>

Parámetros

JOBVL 
!>          JOBVL es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados izquierdos;
!>          = 'V':  calcular los vectores propios generalizados izquierdos.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados derechos;
!>          = 'V':  calcular los vectores propios generalizados derechos.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VL y VR.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA, N)
!>          En la entrada, la matriz A en el par (A,B).
!>          En la salida, A ha sido sobrescrita.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es array REAL, dimensión (LDB, N)
!>          En la entrada, la matriz B en el par (A,B).
!>          En la salida, B ha sido sobrescrita.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHAR

!>          ALPHAR es array REAL, dimensión (N)
!>

ALPHAI

!>          ALPHAI es array REAL, dimensión (N)
!>

BETA

!>          BETA es array REAL, dimensión (N)
!>          En la salida, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, serán
!>          los valores propios generalizados. Si ALPHAI(j) es cero, entonces
!>          el j-ésimo valor propio es real; si es positivo, entonces el j-ésimo y
!>          el (j+1)-ésimo valores propios son un par conjugado complejo, con
!>          ALPHAI(j+1) negativo.
!>
!>          Nota: los cocientes ALPHAR(j)/BETA(j) y ALPHAI(j)/BETA(j)
!>          pueden fácilmente sobrefloar o subfloar, y BETA(j) puede incluso ser cero.
!>          Por lo tanto, el usuario debe evitar calcular ingenuamente la relación
!>          alpha/beta. Sin embargo, ALPHAR y ALPHAI siempre serán menores
!>          que y usualmente comparables con norm(A) en magnitud, y
!>          BETA siempre menor que y usualmente comparable con norm(B).
!>

VL

!>          VL es array REAL, dimensión (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios generalizados izquierdos u(j) se
!>          almacenan uno tras otro en las columnas de VL, en el mismo orden que
!>          sus valores propios. Si el j-ésimo valor propio es real, entonces
!>          u(j) = VL(:,j), la j-ésima columna de VL. Si el j-ésimo y
!>          el (j+1)-ésimo valores propios forman un par conjugado complejo, entonces
!>          u(j) = VL(:,j)+i*VL(:,j+1) y u(j+1) = VL(:,j)-i*VL(:,j+1).
!>          Cada vector propio se escala para que el componente más grande tenga
!>          abs(parte real)+abs(parte imaginaria)=1.
!>          No referenciado si JOBVL = 'N'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es array REAL, dimensión (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios generalizados derechos v(j) se
!>          almacenan uno tras otro en las columnas de VR, en el mismo orden que
!>          sus valores propios. Si el j-ésimo valor propio es real, entonces
!>          v(j) = VR(:,j), la j-ésima columna de VR. Si el j-ésimo y
!>          el (j+1)-ésimo valores propios forman un par conjugado complejo, entonces
!>          v(j) = VR(:,j)+i*VR(:,j+1) y v(j+1) = VR(:,j)-i*VR(:,j+1).
!>          Cada vector propio se escala para que el componente más grande tenga
!>          abs(parte real)+abs(parte imaginaria)=1.
!>          No referenciado si JOBVR = 'N'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal de la matriz VR. LDVR >= 1, y
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK es array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= MAX(1,8*N).
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1,...,N:
!>                La iteración QZ falló. No se han calculado vectores propios,
!>                pero ALPHAR(j), ALPHAI(j), y BETA(j) deberían ser correctos
!>                para j=INFO+1,...,N.
!>          > N:  =N+1: falló la iteración QZ en SLAQZ0.
!>                =N+2: retorno de error de STGEVC.
!>

NOMBRE

SGGEV3 - resuelve el problema generalizado de valores propios generalizados A*x = lambda*B*x.

SINAPSIS

SUBROUTINE SGGEV3(A, B, ALPHA, BETA, VL, VR, WORK, LWORK, INFO)

Documentación de Función/Subrutina

SGGEV3 resuelve el problema de valores propios generalizado generalizado,

    A*x = lambda*B*x

donde A y B son matrices de n por n, y x es un vector de n por 1.

SGGEV3 calcula los valores propios escalados (ALPHA(i), BETA(i)) para cada i, de modo que

    ALPHA(i) = lambda(i) * BETA(i).


La función devuelve valores propios escalados para que la magnitud de los BETA(i) sea
siempre 1 o 0.


Una solución completa para el problema de valores propios generalizado es la siguiente:


    (A - lambda*B)*x = 0


Cada par (lambda, x) se llama valor propio y vector propio generalizado correspondiente.


Si beta(i) es distinto de cero, entonces lambda(i) = alpha(i)/beta(i) es un valor propio
de la matriz generalizada A*inv(B), y si beta(i) es distinto de cero, entonces
lambda(i) = alpha(i)/beta(i) es un valor propio de la matriz generalizada
inv(A)*B.


SGGEV3 también calcula los vectores propios generalizados izquierdos VL y los vectores
propios generalizados derechos VR de la matriz generalizada A*inv(B):


    y'*A = lambda*y'*B,  o  y'*A*x = lambda*y'*B*x
    A*x = lambda*B*x


donde y' denota la transpuesta de y.


Los vectores propios generalizados están normalizados de modo que


    if beta(i) = 0,     lambda(i) = 0,        y'(i)*A = 0
    if beta(i) = 1,     lambda(i) = alpha(i),   y'(i)*A = alpha(i)*y'(i)*B


Si beta(i) es distinto de cero, entonces lambda(i) = alpha(i)/beta(i) es un valor propio
de la matriz generalizada A*inv(B), y si beta(i) es distinto de cero, entonces
lambda(i) = alpha(i)/beta(i) es un valor propio de la matriz generalizada
inv(A)*B.


Los vectores propios generalizados se normalizan de modo que


    (VL' * A * VR) = D(ALPHA)
    (VL' * B * VR) = D(BETA)


donde D(ALPHA) y D(BETA) son matrices diagonales con los valores propios escalados
en las diagonales.


La normalización de los vectores propios generalizados es tal que


    VL'*A*VR = ALPHA
    VL'*B*VR = BETA


donde ALPHA y BETA son matrices diagonales con los valores propios escalados en las
diagonales.


La normalización de los vectores propios generalizados es tal que


    VL'*A*VR = diag(ALPHA)
    VL'*B*VR = diag(BETA)


Si el problema de valores propios generalizado está bien condicionado, entonces se pueden
calcular vectores propios generalizados izquierdos y derechos normalizados VL y VR de
tal manera que


    A*VR = B*VR*diag(ALPHA/BETA)
    VL'*A = diag(ALPHA/BETA)*VL'*B


y


    VL'*VR = I.


La normalización de los vectores propios generalizados es tal que


    VL'*A*VR = diag(ALPHA)
    VL'*B*VR = diag(BETA)


Si el problema de valores propios generalizado está bien condicionado, entonces se pueden
calcular vectores propios generalizados izquierdos y derechos normalizados VL y VR de
tal manera que


    A*VR = B*VR*diag(ALPHA/BETA)
    VL'*A = diag(ALPHA/BETA)*VL'*B


y


    VL'*VR = I.


Parámetros:


  A: REAL (precisión simple) de tamaño (LDA, N).
     La matriz de n por n en la primera ecuación.

  B: REAL (precisión simple) de tamaño (LDB, N).
     La matriz de n por n en la segunda ecuación.

  ALPHA: REAL (precisión simple) de tamaño (N).
     Contiene los numeradores de los valores propios escalados.

  BETA: REAL (precisión simple) de tamaño (N).
     Contiene los denominadores de los valores propios escalados.

  VL: REAL (precisión simple) de tamaño (LDVL, N).
     Si JOBVL = 'V', entonces VL contiene los vectores propios generalizados
     izquierdos. Los vectores propios generalizados izquierdos se normalizan
     de tal manera que VL'*A*VR = ALPHA y VL'*B*VR = BETA.

  VR: REAL (precisión simple) de tamaño (LDVR, N).
     Si JOBVR = 'V', entonces VR contiene los vectores propios generalizados
     derechos. Los vectores propios generalizados derechos se normalizan
     de tal manera que VL'*A*VR = ALPHA y VL'*B*VR = BETA.

  WORK: REAL (precisión simple) de tamaño (LWORK).
     Área de trabajo de llamada.

  LWORK: INTEGER.
     Tamaño del array WORK.

  INFO: INTEGER.
     = 0: éxito
