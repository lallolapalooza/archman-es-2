SGGSVP

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina SGGSVP3.
!>
!> SGGSVP calcula matrices ortogonales U, V y Q tales que
!>
!>                    N-K-L  K    L
!>  U**T*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**T*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> donde la matriz A12 de K por K y la matriz B13 de L por L no son singulares
!> y son triangulares superiores; A23 es triangular superior L por L si M-K-L >= 0,
!> de lo contrario A23 es trapezoidal superior de (M-K) por L. K+L = el rango
!> numérico efectivo de la matriz (A**T,B**T)**T de (M+P)-por-N.
!>
!> Esta descomposición es el paso de preprocesamiento para calcular la
!> Descomposición de Valores Singulares Generalizada (GSVD), ver la subrutina
!> SGGSVD.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U':  Se calcula la matriz ortogonal U;
!>          = 'N':  U no se calcula.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'V':  Se calcula la matriz ortogonal V;
!>          = 'N':  V no se calcula.
!>

JOBQ

!>          JOBQ es CHARACTER*1
!>          = 'Q':  Se calcula la matriz ortogonal Q;
!>          = 'N':  Q no se calcula.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B. P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B. N >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, la matriz M por N A.
!>          En la salida, A contiene la matriz triangular (o trapezoidal)
!>          descrita en la sección Propósito.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es array REAL, dimension (LDB,N)
!>          En la entrada, la matriz P por N B.
!>          En la salida, B contiene la matriz triangular descrita en
!>          la sección Propósito.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,P).
!>

TOLA

!>          TOLA es REAL
!>

TOLB

!>          TOLB es REAL
!>
!>          TOLA y TOLB son los umbrales para determinar el rango numérico
!>          efectivo de la matriz B y un subbloque de A. Generalmente,
!>          se establecen en
!>             TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          El tamaño de TOLA y TOLB puede afectar los errores de retroceso
!>          de la descomposición.
!>

K

!>          K es INTEGER
!>

L

!>          L es INTEGER
!>
!>          En la salida, K y L especifican la dimensión de los subbloques
!>          descritos en la sección Propósito.
!>          K + L = rango numérico efectivo de (A**T,B**T)**T.
!>

U

!>          U es array REAL, dimension (LDU,M)
!>          Si JOBU = 'U', U contiene la matriz ortogonal U.
!>          Si JOBU = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M) si
!>          JOBU = 'U'; LDU >= 1 en caso contrario.
!>

V

!>          V es array REAL, dimension (LDV,P)
!>          Si JOBV = 'V', V contiene la matriz ortogonal V.
!>          Si JOBV = 'N', V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 en caso contrario.
!>

Q

!>          Q es array REAL, dimension (LDQ,N)
!>          Si JOBQ = 'Q', Q contiene la matriz ortogonal Q.
!>          Si JOBQ = 'N', Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q'; LDQ >= 1 en caso contrario.
!>

IWORK

!>          IWORK es array INTEGER, dimension (N)
!>

TAU

!>          TAU es array REAL, dimension (N)
!>

WORK

!>          WORK es array REAL, dimension (max(3*N,M,P))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>

NOMBRE

sggsvp - Proporciona el vector (o los vectores) de la solución de menor norma de un sistema lineal s.p.d. o s.e.m.i.d.

SINOPSIS

SUBROUTINE SGGVSP(
  SOL, N, M, NB, D, E, V, W, X, Y, Z, LDV, LDW, WORK, LWORK, INFO)

Documentación de función/subrutina

Esta subrutina se utiliza en el álgebra lineal para resolver sistemas de ecuaciones lineales. Específicamente, encuentra la solución de norma mínima para un sistema lineal que puede ser simétrico definido positivo (s.p.d.) o simétrico semi-definido positivo (s.e.m.i.d.).

Los parámetros de la subrutina son:

  • SOL: Carácter. Indica el tipo de solución a calcular.
  • N: Entero. El número de filas de las matrices de entrada.
  • M: Entero. El número de columnas de las matrices de entrada.
  • NB: Entero. El tamaño del bloque.
  • D: Real de precisión simple. Vector que contiene información sobre la matriz A.
  • E: Real de precisión simple. Vector que contiene información sobre la matriz B.
  • V: Real de precisión simple. Matriz de salida.
  • W: Real de precisión simple. Matriz de salida.
  • X: Real de precisión simple. Matriz de entrada.
  • Y: Real de precisión simple. Matriz de entrada.
  • Z: Real de precisión simple. Matriz de entrada.
  • LDV: Entero. Longitud de la primera dimensión de V.
  • LDW: Entero. Longitud de la primera dimensión de W.
  • WORK: Real de precisión simple. Vector de trabajo.
  • LWORK: Entero. Longitud del vector de trabajo.
  • INFO: Entero. Indicador de error.

La subrutina calcula el vector (o vectores) de la solución de menor norma para sistemas lineales específicos, utilizando algoritmos de álgebra lineal numérica.
