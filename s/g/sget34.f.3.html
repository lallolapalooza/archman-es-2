subrutina sget34 (real rmax, integer lmax, integer, dimension( 2 ) ninfo, integer knt)

SGET34

Propósito:

!>
!> SGET34 prueba SLAEXC, una rutina para intercambiar bloques adyacentes (ya sea
!> de 1 por 1 o de 2 por 2) en la diagonal de una matriz en forma de Schur real.
!> Por lo tanto, SLAEXC calcula una matriz ortogonal Q tal que
!>
!>     Q' * [ A B ] * Q  = [ C1 B1 ]
!>          [ 0 C ]        [ 0  A1 ]
!>
!> donde C1 es similar a C y A1 es similar a A. Se asume que tanto A como C
!> están en forma estándar (entradas diagonales iguales y signos diferentes
!> en las entradas fuera de la diagonal), y A1 y C1 se devuelven con las
!> mismas propiedades.
!>
!> El código de prueba verifica estas últimas afirmaciones, así como que
!> el residuo en la ecuación anterior sea pequeño.
!>

Parámetros

RMAX 
!>          RMAX es REAL
!>          Valor de la relación de prueba más grande.
!>

LMAX

!>          LMAX es INTEGER
!>          Número de ejemplo donde se logró la relación de prueba más grande.
!>

NINFO

!>          NINFO es un array de tipo INTEGER, dimensionado (2)
!>          NINFO(J) es el número de ejemplos donde ocurrió INFO=J.
!>

KNT

!>          KNT es INTEGER
!>          Número total de ejemplos probados.
!>
