subroutine sgbsvx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, real, dimension( * ) r, real, dimension( * ) c, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SGBSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GB

Propósito:

!>
!> SGBSVX utiliza la factorización LU para calcular la solución a un sistema real
!> de ecuaciones lineales A * X = B, A**T * X = B, o A**H * X = B,
!> donde A es una matriz de banda de orden N con KL subdiagonales y KU
!> superdiagonales, y X y B son matrices N por NRHS.
!>
!> También se proporcionan cotas de error para la solución y una estimación de la condición.
!>

Descripción:

!>
!> Los siguientes pasos son realizados por esta subrutina:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Si el sistema se equilibrará o no depende del
!>    escalado de la matriz A, pero si se utiliza el equilibrado, A se
!>    sobrescribe con diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>       A = L * U,
!>    donde L es un producto de matrices de permutación y triangulares inferiores unitarias
!>    con KL subdiagonales, y U es triangular superior con
!>    KL+KU superdiagonales.
!>
!> 3. Si algún U(i,i)=0, de modo que U es exactamente singular, la rutina
!>    regresa con INFO = i. De lo contrario, la forma factorizada de A se utiliza
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    INFO = N+1 se devuelve como una advertencia, pero la rutina aún continúa
!>    para resolver X y calcular cotas de error como se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    matriz y calcular cotas de error y estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para
!>    que resuelva el sistema original antes del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          suministra en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AFB y IPIV contienen la forma factorizada de
!>                  A.  Si EQUED no es 'N', la matriz A ha sido
!>                  equilibrada con factores de escala dados por R y C.
!>                  AB, AFB e IPIV no se modifican.
!>          = 'N':  La matriz A se copiará en AFB y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AFB y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B     (Sin transponer)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada / Hermítica)
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es array REAL, dimensión (LDAB,N)
!>          En la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>          La j-ésima columna de A se almacena en la j-ésima columna del
!>          array AB de la siguiente manera:
!>          AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+kl)
!>
!>          Si FACT = 'F' y EQUED no es 'N', entonces A debe haber sido
!>          equilibrada por los factores de escala en R y/o C. AB no
!>          se modifica si FACT = 'F' o 'N', o si FACT = 'E' y
!>          EQUED = 'N' a la salida.
!>
!>          A la salida, si EQUED .ne. 'N', A se escala de la siguiente manera:
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array REAL, dimensión (LDAFB,N)
!>          Si FACT = 'F', entonces AFB es un argumento de entrada y en la entrada
!>          contiene detalles de la factorización LU de la matriz de banda
!>          A, tal como fue calculada por SGBTRF. U se almacena como una matriz triangular superior
!>          de banda con KL+KU superdiagonales en las filas 1 a KL+KU+1,
!>          y los multiplicadores utilizados durante la factorización se almacenan
!>          en las filas KL+KU+2 a 2*KL+KU+1. Si EQUED .ne. 'N', entonces AFB
!>          es la forma factorizada de la matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AFB es un argumento de salida y en la salida
!>          devuelve detalles de la factorización LU de A.
!>
!>          Si FACT = 'E', entonces AFB es un argumento de salida y en la salida
!>          devuelve detalles de la factorización LU de la matriz A equilibrada
!>          (ver la descripción de AB para la forma de la
!>          matriz equilibrada).
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal del array AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene los índices de pivote de la factorización A = L*U
!>          tal como fue calculada por SGBTRF; la fila i de la matriz fue intercambiada
!>          con la fila IPIV(i).
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = L*U
!>          de la matriz A equilibrada.
!>

EQUED

!>          EQUED es CHARACTER*1
!>

R

!>          R es un array REAL, de dimensión (N)
!>          Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A se
!>          multiplica por la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>          no se accede. R es un argumento de entrada si FACT = 'F';
!>          de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>          EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>

C

!>          C es un array REAL, de dimensión (N)
!>          Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A se
!>          multiplica por la derecha por diag(C); si EQUED = 'N' o 'R', C
!>          no se accede. C es un argumento de entrada si FACT = 'F';
!>          de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>          EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>

B

!>          B es un array REAL, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida,
!>          si EQUED = 'N', B no se modifica;
!>          si TRANS = 'N' y EQUED = 'R' o 'B', B se sobrescribe con
!>          diag(R)*B;
!>          si TRANS = 'T' o 'C' y EQUED = 'C' o 'B', B se
!>          sobrescribe con diag(C)*B.
!>

LDB

!>          LDB es un INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array REAL, de dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz de solución N-por-NRHS X
!>          del sistema original de ecuaciones. Tenga en cuenta que A y B se
!>          modifican en la salida si EQUED .ne. 'N', y la solución del
!>          sistema equilibrado es inv(diag(C))*X si TRANS = 'N' y
!>          EQUED = 'C' o 'B', o inv(diag(R))*X si TRANS = 'T' o 'C'
!>          y EQUED = 'R' o 'B'.
!>

LDX

!>          LDX es un INTEGER
!>          La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es un REAL
!>          La estimación del número de condición recíproco de la matriz
!>          A después del equilibrado (si se realizó). Si RCOND es menor que la
!>          precisión de la máquina (en particular, si RCOND = 0), la matriz
!>          es singular para la precisión de trabajo. Esta condición
!>          se indica con un código de retorno INFO > 0.
!>

FERR

!>          FERR es un array REAL, de dimensión (NRHS)
!>          El límite de error directo estimado para cada vector de solución
!>          X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la verdadera solución correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como
!>          la estimación de RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array REAL, de dimensión (NRHS)
!>          El error residual relativo componente a componente de cada vector de solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,3*N))
!>          En la salida, WORK(1) contiene el factor de crecimiento del pivote recíproco
!>          norm(A)/norm(U). Se utiliza la norma . Si WORK(1) es mucho menor que 1,
!>          entonces la estabilidad
!>          de la factorización LU de la matriz A (equilibrada)
!>          podría ser pobre. Esto también significa que la solución X, el estimador
!>          de condición RCOND y el límite de error directo FERR podrían ser
!>          poco confiables. Si la factorización falla con 0<INFO<=N, entonces
!>          WORK(1) contiene el factor de crecimiento del pivote recíproco para las
!>          columnas INFO principales de A.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (N)
!>

INFO

!>          INFO es un INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  U(i,i) es exactamente cero. La factorización
!>                       se ha completado, pero el factor U es exactamente
!>                       singular, por lo que la solución y los límites de error
!>                       no pudieron calcularse. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión
!>                       de la máquina, lo que significa que la matriz es singular
!>                       para la precisión de trabajo. Sin embargo, la
!>                       solución y los límites de error se calculan porque
!>                       hay una serie de situaciones en las que la
