Documentación de Función/Subrutina

subrutina sgegv (character jobvl, character jobvr, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) alphar, real, dimension( * ) alphai, real, dimension( * ) beta, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, real, dimension( * ) work, integer lwork, integer info)

SGEGV calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos de un par de matrices reales (A,B).

Propósito:

!>
!> Esta subrutina está obsoleta y ha sido reemplazada por la subrutina SGGEV.
!>
!> SGEGV calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos de un par de matrices reales (A,B).
!> Dadas dos matrices cuadradas A y B,
!> el problema de valores propios generalizado no simétrico (GNEP) consiste en encontrar los
!> valores propios lambda y los correspondientes vectores propios (no nulos) x
!> tales que
!>
!>    A*x = lambda*B*x.
!>
!> Una forma alternativa es encontrar los valores propios mu y los correspondientes
!> vectores propios y tales que
!>
!>    mu*A*y = B*y.
!>
!> Estas dos formas son equivalentes con mu = 1/lambda y x = y si
!> ni lambda ni mu son cero. Para tratar el caso en que
!> lambda o mu sean cero o pequeños, se devuelven dos valores alpha y beta para
!> cada valor propio, tales que lambda = alpha/beta y
!> mu = beta/alpha.
!>
!> Los vectores x e y de las ecuaciones anteriores son vectores propios derechos del
!> par de matrices (A,B). Los vectores u y v que satisfacen
!>
!>    u**H*A = lambda*u**H*B  o  mu*v**H*A = v**H*B
!>
!> son vectores propios izquierdos de (A,B).
!>
!> Nota: esta subrutina realiza sobre A y B
!>

Parámetros

JOBVL 
!>          JOBVL es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados izquierdos;
!>          = 'V':  calcular los vectores propios generalizados izquierdos (devueltos
!>                  en VL).
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados derechos;
!>          = 'V':  calcular los vectores propios generalizados derechos (devueltos
!>                  en VR).
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VL y VR.  N >= 0.
!>

A

!>          A es array REAL, dimension (LDA, N)
!>          En la entrada, la matriz A.
!>          Si JOBVL = 'V' o JOBVR = 'V', entonces a la salida A
!>          contiene la forma de Schur real de A de la factorización
!>          de Schur generalizada del par (A,B) después del balanceo.
!>          Si no se calcularon vectores propios, entonces solo los bloques
!>          diagonales de la forma de Schur serán correctos. Ver SGGHRD y
!>          SHGEQZ para más detalles.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es array REAL, dimension (LDB, N)
!>          En la entrada, la matriz B.
!>          Si JOBVL = 'V' o JOBVR = 'V', entonces a la salida B contiene la
!>          matriz triangular superior obtenida de B en la factorización
!>          de Schur generalizada del par (A,B) después del balanceo.
!>          Si no se calcularon vectores propios, entonces solo los elementos de
!>          B correspondientes a los bloques diagonales de la forma de Schur de
!>          A serán correctos. Ver SGGHRD y SHGEQZ para más detalles.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHAR

!>          ALPHAR es array REAL, dimension (N)
!>          Las partes reales de cada escalar alpha que define un valor propio de
!>          GNEP.
!>

ALPHAI

!>          ALPHAI es array REAL, dimension (N)
!>          Las partes imaginarias de cada escalar alpha que define un
!>          valor propio de GNEP. Si ALPHAI(j) es cero, entonces el j-ésimo
!>          valor propio es real; si es positivo, entonces el j-ésimo y
!>          (j+1)-ésimo valores propios son un par conjugado complejo, con
!>          ALPHAI(j+1) = -ALPHAI(j).
!>

BETA

!>          BETA es array REAL, dimension (N)
!>          Los escalares beta que definen los valores propios de GNEP.
!>
!>          Juntos, las cantidades alpha = (ALPHAR(j),ALPHAI(j)) y
!>          beta = BETA(j) representan el j-ésimo valor propio del
!>          par de matrices (A,B), en una de las formas lambda = alpha/beta o
!>          mu = beta/alpha. Dado que lambda o mu pueden desbordarse,
!>          generalmente no deben calcularse.
!>

VL

!>          VL es array REAL, dimension (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios generalizados izquierdos u(j) se almacenan
!>          en las columnas de VL, en el mismo orden que sus valores propios.
!>          Si el j-ésimo valor propio es real, entonces u(j) = VL(:,j).
!>          Si los j-ésimo y (j+1)-ésimo valores propios forman un par conjugado
!>          complejo, entonces
!>             u(j) = VL(:,j) + i*VL(:,j+1)
!>          y
!>            u(j+1) = VL(:,j) - i*VL(:,j+1).
!>
!>          Cada vector propio se escala para que su componente más grande tenga
!>          abs(parte real) + abs(parte imaginaria) = 1, excepto para los vectores propios
!>          correspondientes a un valor propio con alpha = beta = 0, que
!>          se establecen a cero.
!>          No se hace referencia si JOBVL = 'N'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es array REAL, dimension (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios generalizados derechos x(j) se almacenan
!>          en las columnas de VR, en el mismo orden que sus valores propios.
!>          Si el j-ésimo valor propio es real, entonces x(j) = VR(:,j).
!>          Si los j-ésimo y (j+1)-ésimo valores propios forman un par conjugado
!>          complejo, entonces
!>            x(j) = VR(:,j) + i*VR(:,j+1)
!>          y
!>            x(j+1) = VR(:,j) - i*VR(:,j+1).
!>
!>          Cada vector propio se escala para que su componente más grande tenga
!>          abs(parte real) + abs(parte imaginaria) = 1, excepto para los valores propios
!>          correspondientes a un valor propio con alpha = beta = 0, que
!>          se establecen a cero.
!>          No se hace referencia si JOBVR = 'N'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal de la matriz VR. LDVR >= 1, y
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK es array REAL, dimension (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,8*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>          Para calcular el valor óptimo de LWORK, llame a ILAENV para obtener
!>          los tamaños de bloque (para SGEQRF, SORMQR y SORGQR). Luego calcule:
!>          NB  -- MAX de los tamaños de bloque para SGEQRF, SORMQR y SORGQR;
!>          El LWORK óptimo es:
!>              2*N + MAX( 6*N, N*(NB+1) ).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la subrutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje
!>          de error relacionado con LWORK.
!>

NAME

sgegv - Computes the generalized eigenvalues and eigenvectors of a real matrix pair (A, B).

SYNOPSIS

SUBROUTINE SGEGV(
     JOBVL, JOBVR, N, A, LDA, B, LDB, ALPHAR, ALPHAI, BETA, VL, LDVL,
     VR, LDVR, WORK, INFO)


 CHARACTER          JOBVL, JOBVR
    INTEGER            LDA, LDB, LDVL, LDVR, N
    REAL               A( LDA, * ), ALPHAR( * ), ALPHAI( * ), BETA( * ),
     VL( LDVL, * ), VR( LDVR, * ), WORK( * )

C interface

void sgegv_( char *jobvl, char *jobvr, integer *n, real *a,
             integer *lda, real *b, integer *ldb, real *alphar,
             real *alphai, real *beta, real *vl, integer *ldvl,
             real *vr, integer *ldvr, real *work, integer *info );

Function/Subroutine Documentation

SGEGV computes for an N-by-N real matrix pair (A, B), the generalized eigenvalues and, optionally, the generalized eigenvectors.

A generalized eigenvalue for this pair is of the form A*x = lambda*B*x and a generalized eigenvector x.

The equation A*x = lambda*B*x is equivalent to the ordinary eigenvalue problem A*inv(B)*x = lambda*x, if B is invertible. It is also equivalent to inv(A)*B*x = (1/lambda)*x, if A is invertible. If B is singular, then B*x = 0 and A*x = lambda*B*x implies A*x = 0. The eigenvalues lambda are computed such that they are always finite. The algorithm is based on QZ method.

Parameters

JOBVL

Character. JOBVL = 'N': Do not compute the left generalized eigenvectors; returned is not needed.

JOBVL = 'V': Compute the left generalized eigenvectors; returned VL is the matrix of left generalized eigenvectors such that VL*A = ALPHAR*VR**H + ALPHAI*VR**H*i*B, where VR is the matrix of right generalized eigenvectors.

JOBVR

Character. JOBVR = 'N': Do not compute the right generalized eigenvectors; returned is not needed.

JOBVR = 'V': Compute the right generalized eigenvectors; returned VR is the matrix of right generalized eigenvectors such that A*VR = B*VR* (ALPHAR + ALPHAI*i)*inv(BETA).

N

Integer. The order of the matrices A and B. N >= 0.

A

Real array, dimension (LDA, N).

On entry, the leading N-by-N part of this array must contain the matrix A.

On exit, if JOBVL = 'V' or JOBVR = 'V', the leading N-by-N part of A contains the real Schur form of A and B.

LDA

Integer. The leading dimension of A. LDA >= max(1, N).

B

Real array, dimension (LDB, N).

On entry, the leading N-by-N part of this array must contain the matrix B.

On exit, the leading N-by-N part of B contains the upper triangular matrix derived from B.

LDB

Integer. The leading dimension of B. LDB >= max(1, N).

ALPHAR

Real array, dimension (N).

ALPHAR and ALPHAI contain the real and imaginary parts, respectively, of the complex generalized eigenvalues.

For each i, the generalized eigenvalue lambda = (ALPHAR(i) + ALPHAI(i)*i) / BETA(i).

ALPHAI

Real array, dimension (N).

BETA

Real array, dimension (N).

BETA contains the real generalized eigenvalues.

For each i, the generalized eigenvalue lambda = (ALPHAR(i) + ALPHAI(i)*i) / BETA(i).

BETA(i) is always real. If BETA(i) = 0, then the corresponding eigenvalue is infinite. In the case of a finite eigenvalue, BETA(i) is normalized to be non-negative and.

If ALPHAI(i) is non-zero, then lambda = (ALPHAR(i) + ALPHAI(i)*i)/BETA(i) is a complex eigenvalue. If ALPHAI(i) is zero, then lambda = ALPHAR(i)/BETA(i) is a real eigenvalue.

VL

Real array, dimension (LDVL, N).

If JOBVL = 'V', VL contains the left generalized eigenvectors.

If JOBVL = 'N', VL is not used.

LDVL

Integer. The leading dimension of VL. LDVL >= N.

VR

Real array, dimension (LDVR, N).

If JOBVR = 'V', VR contains the right generalized eigenvectors.

If JOBVR = 'N', VR is not used.

LDVR

Integer. The leading dimension of VR. LDVR >= N.

WORK

Real array, dimension (LWORK).

On exit, WORK(1) contains the minimum dimensions LWORK.

LWORK

Integer. The dimension of the array WORK. LWORK >= max(1, 4*N).

For optimal performance, LWORK is computed by SGEGV.

If LWORK = -1, then only the LWORK is computed and stored in WORK(1).

INFO

Integer.

= 0: successful exit.

< 0: If INFO = -i, then the i-th argument had an illegal value.

> 0: The QZ iteration failed.

= N+1: Error return from SGGBAL.

= N+2: Error return from SGEQRF.

= N+3: Error return from SORMQR.

= N+4: Error return from SORGQR.

= N+5: Error return from SGGHRD.

= N+6: Error return from SHGEQZ (other than failed iteration).

= N+7: Error return from STGEVC.

= N+8: Error return from SGGBAK (computing VL).

= N+9: Error return from SGGBAK (computing VR).

= N+10: Error return from SLASCL (various calls).

= N+11: Error return from STRSNA.

= N+12: Error return from STGSYL.

Further Details:

!>
!>  Balancing
!>  ---------
!>
!>  This driver calls SGGBAL to both permute and scale rows and columns
!>  of A and B.  The permutations PL and PR are chosen so that PL*A*PR
!>  and PL*B*R will be upper triangular except for the diagonal blocks
!>  A(i:j,i:j) and B(i:j,i:j), with i and j as close together as
!>  possible.  The diagonal scaling matrices DL and DR are chosen so
!>  that the pair  DL*PL*A*PR*DR, DL*PL*B*PR*DR have elements close to
!>  one (except for the elements that start out zero.)
!>
!>  After the eigenvalues and eigenvectors of the balanced matrices
!>  have been computed, SGGBAK transforms the eigenvectors back to what
!>  they would have been (in perfect arithmetic) if they had not been
!>  balanced.
!>
!>  Contents of A and B on Exit
!>  -------- -- - --- - -- ----
!>
!>  If any eigenvectors are computed (either JOBVL='V' or JOBVR='V' or
!>  both), then on exit the arrays A and B will contain the real Schur
!>  form[*] of the  versions of A and B.  If no eigenvectors
!>  are computed, then only the diagonal blocks will be correct.
!>
!>  [*] See SHGEQZ, SGEGS, or read the book ,
!>      by Golub & van Loan, pub. by Johns Hopkins U. Press.
!>
