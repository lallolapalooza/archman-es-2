Documentación de Función/Subrutina

subrutina sggevx (character balanc, character jobvl, character jobvr, character sense, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( * ) alphar, real, dimension( * ) alphai, real, dimension( * ) beta, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, integer ilo, integer ihi, real, dimension( * ) lscale, real, dimension( * ) rscale, real abnrm, real bbnrm, real, dimension( * ) rconde, real, dimension( * ) rcondv, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, logical, dimension( * ) bwork, integer info)

SGGEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE

Propósito:

!>
!> SGGEVX calcula para un par de matrices reales N por N (A,B) no simétricas
!> los valores propios generalizados y, opcionalmente, los vectores propios
!> generalizados izquierdos y/o derechos.
!>
!> Opcionalmente también, calcula una transformación de balanceo para mejorar
!> el condicionamiento de los valores propios y los vectores propios (ILO, IHI,
!> LSCALE, RSCALE, ABNRM, y BBNRM), los recíprocos de los números de condición
!> para los valores propios (RCONDE), y los recíprocos de los números de condición
!> para los vectores propios derechos (RCONDV).
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar
!> lambda o una razón alpha/beta = lambda, tal que A - lambda*B es
!> singular. Se representa usualmente como el par (alpha,beta), ya que
!> hay una interpretación razonable para beta=0, e incluso para ambos
!> siendo cero.
!>
!> El vector propio derecho v(j) correspondiente al valor propio lambda(j)
!> de (A,B) satisface
!>
!>                  A * v(j) = lambda(j) * B * v(j) .
!>
!> El vector propio izquierdo u(j) correspondiente al valor propio lambda(j)
!> de (A,B) satisface
!>
!>                  u(j)**H * A  = lambda(j) * u(j)**H * B.
!>
!> donde u(j)**H es la transpuesta conjugada de u(j).
!>
!>

Parámetros

BALANC 
!>          BALANC es CHARACTER*1
!>          Especifica la opción de balanceo a realizar.
!>          = 'N':  no escalar ni permutar diagonalmente;
!>          = 'P':  solo permutar;
!>          = 'S':  solo escalar;
!>          = 'B':  permutar y escalar ambas.
!>          Los recíprocos de los números de condición calculados serán para las
!>          matrices después de permutar y/o balancear. La permutación no
!>          cambia los números de condición (en aritmética exacta), pero
!>          el balanceo sí lo hace.
!>

JOBVL

!>          JOBVL es CHARACTER*1
!>          = 'N':  no computar los vectores propios generalizados izquierdos;
!>          = 'V':  computar los vectores propios generalizados izquierdos.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N':  no computar los vectores propios generalizados derechos;
!>          = 'V':  computar los vectores propios generalizados derechos.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué recíprocos de números de condición se computan.
!>          = 'N': no se computa ninguno;
!>          = 'E': se computa solo para valores propios;
!>          = 'V': se computa solo para vectores propios;
!>          = 'B': se computa para valores propios y vectores propios.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VL, y VR.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA, N)
!>          En la entrada, la matriz A en el par (A,B).
!>          En la salida, A ha sido sobrescrita. Si JOBVL='V' o JOBVR='V'
!>          o ambas, entonces A contiene la primera parte de la forma de Schur
!>          real de las versiones de entrada de A y B.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es array REAL, dimensión (LDB, N)
!>          En la entrada, la matriz B en el par (A,B).
!>          En la salida, B ha sido sobrescrita. Si JOBVL='V' o JOBVR='V'
!>          o ambas, entonces B contiene la segunda parte de la forma de Schur
!>          real de las versiones de entrada de A y B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHAR

!>          ALPHAR es array REAL, dimensión (N)
!>

ALPHAI

!>          ALPHAI es array REAL, dimensión (N)
!>

BETA

!>          BETA es array REAL, dimensión (N)
!>          En la salida, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, serán
!>          los valores propios generalizados.  Si ALPHAI(j) es cero, entonces
!>          el j-ésimo valor propio es real; si es positivo, entonces el j-ésimo y
!>          el (j+1)-ésimo valores propios son un par conjugado complejo, con
!>          ALPHAI(j+1) negativo.
!>
!>          Nota: los cocientes ALPHAR(j)/BETA(j) y ALPHAI(j)/BETA(j)
!>          pueden fácilmente sobrefloar o subfloar, y BETA(j) puede incluso ser cero.
!>          Por lo tanto, el usuario debe evitar computar ingenuamente el cociente
!>          ALPHA/BETA. Sin embargo, ALPHAR y ALPHAI siempre serán menores
!>          y usualmente comparables con norm(A) en magnitud, y
!>          BETA siempre menor y usualmente comparable con norm(B).
!>

VL

!>          VL es array REAL, dimensión (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios generalizados izquierdos u(j) se
!>          almacenan uno tras otro en las columnas de VL, en el mismo orden que
!>          sus valores propios. Si el j-ésimo valor propio es real, entonces
!>          u(j) = VL(:,j), la j-ésima columna de VL. Si el j-ésimo y
!>          el (j+1)-ésimo valores propios forman un par conjugado complejo, entonces
!>          u(j) = VL(:,j)+i*VL(:,j+1) y u(j+1) = VL(:,j)-i*VL(:,j+1).
!>          Cada vector propio se escalará para que el componente de mayor magnitud
!>          tenga abs(parte real) + abs(parte imaginaria) = 1.
!>          No referenciado si JOBVL = 'N'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es array REAL, dimensión (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios generalizados derechos v(j) se
!>          almacenan uno tras otro en las columnas de VR, en el mismo orden que
!>          sus valores propios. Si el j-ésimo valor propio es real, entonces
!>          v(j) = VR(:,j), la j-ésima columna de VR. Si el j-ésimo y
!>          el (j+1)-ésimo valores propios forman un par conjugado complejo, entonces
!>          v(j) = VR(:,j)+i*VR(:,j+1) y v(j+1) = VR(:,j)-i*VR(:,j+1).
!>          Cada vector propio se escalará para que el componente de mayor magnitud
!>          tenga abs(parte real) + abs(parte imaginaria) = 1.
!>          No referenciado si JOBVR = 'N'.
!>

LDVR

NAME

                    
sggevx - Computes the generalized eigenvalues and, optionally, eigenvectors of a real matrix pair (A, B), balancing the matrix pair and optionally computing the condition numbers for the eigenvalues and eigenvectors.

                

                

                    
SYNOPSIS

                    
SUBROUTINE SGGEVX(
       BALANCE, JOBVL, JOBVR, SENSE, N, A, LDA, B, LDB,
       ALPHA, BETA, VL, LDVL, VR, LDVR, ILO, IHI, LSCALE, RSCALE,
       ABNRM, BBNRM, RCONDE, RCONDV, WORK, LWORK, IWORK, BWORK, INFO
    )
    CHARACTER * 1      BALANCE
    CHARACTER * 1      JOBVL
    CHARACTER * 1      JOBVR
    CHARACTER * 1      SENSE
    INTEGER            N
    REAL               A( LDA, * ), B( LDB, * ), VL( LDVL, * ), VR( LDVR, * )
    REAL               ALPHA( * ), BETA( * )
    INTEGER            LDA, LDB, LDVL, LDVR
    INTEGER            ILO, IHI
    REAL               LSCALE( * ), RSCALE( * )
    REAL               ABNRM, BBNRM
    REAL               RCONDE( * ), RCONDV( * )
    REAL               WORK( * )
    INTEGER            LWORK
    INTEGER            IWORK( * )
    LOGICAL            BWORK( * )
    INTEGER            INFO

                

                

                    
Function/Subroutine Documentation

                    
BALANCE

                    
!>          BALANCE is CHARACTER*1
!>          Specifies whether to balance the matrix pair before computing
!>          the generalized Schur factorization.
!>          = 'N': No balancing is done.
!>          = 'P': Rows and columns of A and B are permuted but not scaled.
!>          = 'S': Rows and columns of A and B are scaled but not permuted.
!>          = 'B': Rows and columns of A and B are permuted and scaled.
!> 

                    
JOBVL

                    
!>          JOBVL is CHARACTER*1
!>          Specifies whether to compute the left generalized eigenvectors
!>          of A and B.
!>          = 'N': Left generalized eigenvectors are not computed.
!>          = 'V': Left generalized eigenvectors are computed.
!> 

                    
JOBVR

                    
!>          JOBVR is CHARACTER*1
!>          Specifies whether to compute the right generalized eigenvectors
!>          of A and B.
!>          = 'N': Right generalized eigenvectors are not computed.
!>          = 'V': Right generalized eigenvectors are computed.
!> 

                    
SENSE

                    
!>          SENSE is CHARACTER*1
!>          Specifies which reciprocal condition numbers are to be computed:
!>          = 'N': None are computed.
!>          = 'E': Reciprocal condition numbers for eigenvalues only.
!>          = 'V': Reciprocal condition numbers for eigenvectors only.
!>          = 'B': Reciprocal condition numbers for both eigenvalues and
!>                 eigenvectors.
!> 

                    
N

                    
!>          N is INTEGER
!>          The order of the matrices A and B.  N >= 0.
!> 

                    
A

                    
!>          A is REAL array, dimension (LDA,*)
!>          On entry, the upper triangular part of A contains the matrix A.
!>          On exit, A is an upper triangular matrix. If JOBVL='V' or JOBVR='V',
!>          A contains the transformation matrix used in the reduction of A.
!> 

                    
LDA

                    
!>          LDA is INTEGER
!>          The leading dimension of A. LDA >= max(1,N).
!> 

                    
B

                    
!>          B is REAL array, dimension (LDB,*)
!>          On entry, the upper triangular part of B contains the matrix B.
!>          On exit, B is an upper triangular matrix. If JOBVL='V' or JOBVR='V',
!>          B contains the orthogonal matrix used in the reduction of B.
!> 

                    
LDB

                    
!>          LDB is INTEGER
!>          The leading dimension of B. LDB >= max(1,N).
!> 

                    
ALPHA

                    
!>          ALPHA is REAL array, dimension (N)
!>          BETA is REAL array, dimension (N)
!>          On exit, the arrays ALPHA and BETA contain the numerator and
!>          denominator of the generalized eigenvalues
!>          (alpha_j / beta_j), in no particular order.
!>          Thus, alpha_j / beta_j = omega_j.
!>          Note that only the real parts of the generalized eigenvalues
!>          are given by ALPHA, and BETA is always positive.
!> 

                    
VL

                    
!>          VL is REAL array, dimension (LDVL, N)
!>          If JOBVL = 'V', VL contains the left generalized eigenvectors.
!>          The k-th column VL(*,k) is the eigenvector corresponding to the
!>          k-th generalized eigenvalue (ALPHA(k), BETA(k)).
!>          If JOBVL = 'N', VL is not referenced.
!> 

                    
LDVL

                    
!>          LDVL is INTEGER
!>          The leading dimension of the array VL.
!>          If JOBVL = 'V', LDVL >= max(1,N).
!> 

                    
VR

                    
!>          VR is REAL array, dimension (LDVR, N)
!>          If JOBVR = 'V', VR contains the right generalized eigenvectors.
!>          The k-th column VR(*,k) is the eigenvector corresponding to the
!>          k-th generalized eigenvalue (ALPHA(k), BETA(k)).
!>          If JOBVR = 'N', VR is not referenced.
!> 

                    
LDVR

                    
!>          LDVR is INTEGER
!>          The leading dimension of the array VR.
!>          If JOBVR = 'V', LDVR >= max(1,N).
!> 

                    
ILO

                    
!>          ILO is INTEGER
!> 

                    
IHI

                    
!>          IHI is INTEGER
!>          ILO and IHI are integer values such that on exit
!>          A(i,j) = 0 and B(i,j) = 0 if i > j and
!>          j = 1,...,ILO-1 or i = IHI+1,...,N.
!>          If BALANC = 'N' or 'S', ILO = 1 and IHI = N.
!> 

                    
LSCALE

                    
!>          LSCALE is REAL array, dimension (N)
!>          Details of the permutations and scaling factors applied
!>          to the left side of A and B.  If PL(j) is the index of the
!>          row interchanged with row j, and DL(j) is the scaling
!>          factor applied to row j, then
!>            LSCALE(j) = PL(j)  for j = 1,...,ILO-1
!>                      = DL(j)  for j = ILO,...,IHI
!>                      = PL(j)  for j = IHI+1,...,N.
!>          The order in which the interchanges are made is N to IHI+1,
!>          then 1 to ILO-1.
!> 

                    
RSCALE

                    
!>          RSCALE is REAL array, dimension (N)
!>          Details of the permutations and scaling factors applied
!>          to the right side of A and B.  If PR(j) is the index of the
!>          column interchanged with column j, and DR(j) is the scaling
!>          factor applied to column j, then
!>            RSCALE(j) = PR(j)  for j = 1,...,ILO-1
!>                      = DR(j)  for j = ILO,...,IHI
!>                      = PR(j)  for j = IHI+1,...,N
!>          The order in which the interchanges are made is N to IHI+1,
!>          then 1 to ILO-1.
!> 

                    
ABNRM

                    
!>          ABNRM is REAL
!>          The one-norm of the balanced matrix A.
!> 

                    
BBNRM

                    
!>          BBNRM is REAL
!>          The one-norm of the balanced matrix B.
!> 

                    
RCONDE

                    
!>          RCONDE is REAL array, dimension (N)
!>          If SENSE = 'E' or 'B', the reciprocal condition numbers of
!>          the eigenvalues, stored in consecutive elements of the array.
!>          For a complex conjugate pair of eigenvalues two consecutive
!>          elements of RCONDE are set to the same value. Thus RCONDE(j),
!>          RCONDV(j), and the j-th columns of VL and VR all correspond
!>          to the j-th eigenpair.
!>          If SENSE = 'N' or 'V', RCONDE is not referenced.
!> 

                    
RCONDV

                    
!>          RCONDV is REAL array, dimension (N)
!>          If SENSE = 'V' or 'B', the estimated reciprocal condition
!>          numbers of the eigenvectors, stored in consecutive elements
!>          of the array. For a complex eigenvector two consecutive
!>          elements of RCONDV are set to the same value. If the
!>          eigenvalues cannot be reordered to compute RCONDV(j),
!>          RCONDV(j) is set to 0; this can only occur when the true
!>          value would be very small anyway.
!>          If SENSE = 'N' or 'E', RCONDV is not referenced.
!> 

                    
WORK

                    
!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!> 

                    
LWORK

                    
!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,2*N).
!>          If BALANC = 'S' or 'B', or JOBVL = 'V', or JOBVR = 'V',
!>          LWORK >= max(1,6*N).
!>          If SENSE = 'E', LWORK >= max(1,10*N).
!>          If SENSE = 'V' or 'B', LWORK >= 2*N*N+8*N+16.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!> 

                    
IWORK

                    
!>          IWORK is INTEGER array, dimension (N+6)
!>          If SENSE = 'E', IWORK is not referenced.
!> 

                    
BWORK

                    
!>          BWORK is LOGICAL array, dimension (N)
!>          If SENSE = 'N', BWORK is not referenced.
!> 

                    
INFO

                    
!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          = 1,...,N:
!>                The QZ iteration failed.  No eigenvectors have been
!>                calculated, but ALPHAR(j), ALPHAI(j), and BETA(j)
!>                should be correct for j=INFO+1,...,N.
!>          > N:  =N+1: other than QZ iteration failed in SHGEQZ.
!>                =N+2: error return from STGEVC.
!>

Further Details:

                    

                        
!>
!>  Balancing a matrix pair (A,B) includes, first, permuting rows and
!>  columns to isolate eigenvalues, second, applying diagonal similarity
!>  transformation to the rows and columns to make the rows and columns
!>  as close in norm as possible. The computed reciprocal condition
!>  numbers correspond to the balanced matrix. Permuting rows and columns
!>  will not change the condition numbers (in exact arithmetic) but
!>  diagonal scaling will.  For further explanation of balancing, see
!>  section 4.11.1.2 of LAPACK Users' Guide.
!>
!>  An approximate error bound on the chordal distance between the i-th
!>  computed generalized eigenvalue w and the corresponding exact
!>  eigenvalue lambda is
!>
!>       chord(w, lambda) <= EPS * norm(ABNRM, BBNRM) / RCONDE(I)
!>
!>  An approximate error bound for the angle between the i-th computed
!>  eigenvector VL(i) or VR(i) is given by
!>
!>       EPS * norm(ABNRM, BBNRM) / DIF(i).
!>
!>  For further explanation of the reciprocal condition numbers RCONDE
!>  and RCONDV, see section 4.11 of LAPACK User's Guide.
!>
