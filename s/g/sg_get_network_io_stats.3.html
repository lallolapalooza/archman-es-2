NOMBRE

sg_get_network_io_stats, sg_get_network_io_stats_r, sg_get_network_io_stats_diff, sg_get_network_io_stats_diff_between, sg_free_network_io_stats, sg_network_io_compare_name - obtener estadísticas de red

#include <statgrab.h>


sg_network_io_stats *sg_get_network_io_stats
(size_t *entries);

(size_t *entries);


sg_network_io_stats *sg_get_network_io_stats_diff
(size_t *entries);


sg_network_io_stats *sg_get_network_io_stats_diff_between
(const sg_network_io_stats *cur, const sg_network_io_stats *last, size_t *entries);


sg_error sg_free_network_io_stats
(sg_network_iface_stats *data);


int sg_network_io_compare_name
(const void *va, const void *vb);

DESCRIPCIÓN

Las funciones sg_get_network_io_stats proporcionan estadísticas de E/S de interfaz de red por interfaz. Todas las funciones de obtención y diferencia (`get`- y `diff`-functions) toman un parámetro opcional `entries`, que apunta (cuando se proporciona) a un `size_t` para tomar el número de entradas del vector devueltas.

Las funciones sg_get_network_io_stats() y sg_get_network_io_stats_r() entregan las estadísticas de E/S desde que la interfaz se adjuntó al sistema. Las funciones sg_get_network_io_stats_diff() y sg_get_network_io_stats_diff_between() entregan la diferencia entre dos llamadas a sg_get_network_io_stats() o sg_get_network_io_stats_r(), respectivamente.

Atajo de API

función retorna propietario de los datos
sg_get_network_io_stats sg_network_io_stats * libstatgrab (local del hilo)
sg_get_network_io_stats_r sg_network_io_stats * llamador
sg_get_network_io_stats_diff sg_network_io_stats * libstatgrab (local del hilo)
sg_get_network_io_stats_diff_between sg_network_io_stats * llamador

Los vectores sg_network_io_stats recibidos de sg_get_network_io_stats_r() o sg_get_network_io_stats_diff_between() deben liberarse usando sg_free_network_io_stats() cuando ya no sean necesarios. El llamador es responsable de hacerlo.

Adicionalmente, hay una función de soporte para qsort(3) disponible: sg_network_io_compare_name().

Ejemplo

size_t entries;
sg_network_io_stats *network_stats = NULL;
while( NULL != ( network_stats = sg_get_network_io_stats_diff(&entries) ) ) {
    /* ordenar interfaz por nombre */
    qsort( network_stats, entries, sizeof(network_stats[0]), &sg_network_io_compare_name );
    show_network_io_stats( network_stats );
}

sg_get_network_io_stats devuelve el tráfico de red almacenado en el kernel, que contiene la cantidad de datos transferidos desde que el dispositivo se conectó. En algunas plataformas, como Solaris 7, este valor se almacena en un entero de 32 bits, por lo que se desborda cuando alcanza los 4 GB. Otras plataformas, como Solaris 8, almacenan el valor en un entero de 64 bits, que se desborda cerca de los 17 millones de terabytes. La función sg_get_network_io_stats_diff() y la función sg_get_network_io_stats_diff_between() tienen en cuenta estos desbordamientos e intentan detectarlos cuando se calcula la diferencia.

VALORES DE RETORNO

Todas las estadísticas de red devuelven un puntero a una estructura de tipo sg_network_io_stats.

typedef struct {
        char *interface_name;
        unsigned long long tx;
        unsigned long long rx;
        unsigned long long ipackets;
        unsigned long long opackets;
        unsigned long long ierrors;
        unsigned long long oerrors;
        unsigned long long collisions;
        time_t systime;
} sg_network_io_stats;
interface_name
El nombre conocido por el sistema operativo. (por ejemplo, en linux podría ser eth0, en AIX en0 y en FreeBSD fxp0)
tx
El número de bytes transmitidos.
rx
El número de bytes recibidos.
ipackets
El número de paquetes recibidos.
opackets
El número de paquetes transmitidos.
ierrors
El número de errores de recepción.
oerrors
El número de errores de transmisión.
collisions
El número de colisiones.
systime
La marca de tiempo cuando se recopilaron las estadísticas anteriores en segundos desde la época o el período de tiempo durante el cual se transfirieron tx y rx.

ERRORES GRAVES

sg_get_network_io_stats_diff y sg_get_network_io_stats_diff_between comparan dos listas de estadísticas de E/S relacionadas con interfaces de red. Cada entrada que aparece solo en la segunda lista se pasa a la lista resultante como si se hubiera comparado con una entrada con todos los valores de estadísticas establecidos en 0. Esto implica que, en la primera llamada, sg_get_network_io_stats_diff devolverá lo mismo que sg_get_network_io_stats.

En sistemas operativos que solo almacenan 32 bits de datos, existe un problema si los valores se desbordan dos veces. Por ejemplo, en Solaris 7, si se transfieren 9 GB y el sistema operativo se desborda a los 4 GB, la función sg_get_network_io_stats_diff devolverá 5 GB.
