Documentación de la Función/Subrutina

subroutine sgemqr (character side, character trans, integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) t, integer tsize, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer lwork, integer info)

SGEMQR

Propósito:

!>
!> SGEMQR sobrescribe la matriz general real M por N C con
!>
!>                      SIDE = 'L'     SIDE = 'R'
!>     TRANS = 'N':      Q * C          C * Q
!>     TRANS = 'T':      Q**T * C       C * Q**T
!>
!> donde Q es una matriz ortogonal real definida como el producto
!> de reflectores elementales bloqueados calculados por la factorización QR
!> delgada (SGEQR)
!>
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**T desde la Izquierda;
!>          = 'R': aplicar Q o Q**T desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': Sin transponer, aplicar Q;
!>          = 'T': Transpuesta, aplicar Q**T.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >=0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A es array REAL, dimension (LDA,K)
!>          Parte de la estructura de datos para representar Q tal como la devuelve SGEQR.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T es array REAL, dimension (MAX(5,TSIZE)).
!>          Parte de la estructura de datos para representar Q tal como la devuelve SGEQR.
!>

TSIZE

!>          TSIZE es INTEGER
!>          La dimensión del array T. TSIZE >= 5.
!>

C

!>          C es array REAL, dimension (LDC,N)
!>          En la entrada, la matriz C de M por N.
!>          En la salida, C se sobrescribe con Q*C o Q**T*C o C*Q**T o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>         (espacio de trabajo) array REAL, dimension (MAX(1,LWORK))
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo. La rutina
!>          solo calcula el tamaño del array WORK, devuelve este
!>          valor como WORK(1), y XERBLA no emite ningún mensaje de error relacionado con WORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Detalles Adicionales

!> darlos por sentados. Estos detalles pueden cambiar en el futuro y es poco probable
!> que sean ciertos para otra implementación de LAPACK. Estos detalles son relevantes si uno quiere

!>
!> En esta versión,
!>
!>          T(2): tamaño del bloque de filas (MB)
!>          T(3): tamaño del bloque de columnas (NB)
!>          T(6:TSIZE): estructura de datos necesaria para Q, calculada por
!>                           SLATSQR o SGEQRT
!>
!>  Dependiendo de las dimensiones de la matriz M y N, y de los tamaños de bloque
!>  de fila y columna MB y NB devueltos por ILAENV, SGEQR utilizará SLATSQR
!>  (si la matriz es delgada y alta) o SGEQRT para calcular
!>  la factorización QR.
!>  Esta versión de SGEMQR utilizará SLAMTSQR o SGEMQRT para
!>  multiplicar la matriz Q por otra matriz.
!>  Más detalles en SLAMTSQR o SGEMQRT.
!>
!>
