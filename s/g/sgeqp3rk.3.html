subroutine sgeqp3rk (integer m, integer n, integer nrhs, integer kmax, real abstol, real reltol, real, dimension( lda, * ) a, integer lda, integer k, real maxc2nrmk, real relmaxc2nrmk, integer, dimension( * ) jpiv, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

SGEQP3RK calcula una factorización QR truncada de Householder con pivoteo de columnas de una matriz real m por n A utilizando BLAS de Nivel 3 y sobrescribe una matriz real m por nrhs B con Q**T * B.

Propósito:

!>
!> SGEQP3RK realiza dos tareas simultáneamente:
!>
!> Tarea 1: La rutina calcula una factorización QR truncada (rango K) o de rango completo
!> con pivoteo de columnas de una matriz real M por N A utilizando BLAS de Nivel 3. K es el número de columnas
!> que se factorizaron, es decir, el rango de factorización de
!> la R factorizada, K <= min(M,N).
!>
!>  A * P(K) = Q(K) * R(K)  =
!>
!>        = Q(K) * ( R11(K) R12(K) ) = Q(K) * (   R(K)_aproximada    )
!>                 ( 0      R22(K) )          ( 0  R(K)_residual ),
!>
!> donde:
!>
!>  P(K)            es una matriz de permutación N por N;
!>  Q(K)            es una matriz ortogonal M por M;
!>  R(K)_aproximada   = ( R11(K), R12(K) ) es una aproximación de rango K de la
!>                    matriz R de rango completo con R11(K) triangular superior K por K
!>                    y R12(K) rectangular K por N. Las entradas diagonales
!>                    de R11(K) aparecen en orden no creciente de valor absoluto, y los valores absolutos de todas ellas
!>                    superan la norma 2 de columna máxima de R22(K)
!>                    hasta el error de redondeo.
!>  R(K)_residual = R22(K) es el residuo de una aproximación de rango K
!>                    de la matriz R de rango completo. Es una
!>                    matriz rectangular (M-K) por (N-K);
!>  0               es una matriz cero (M-K) por K.
!>
!> Tarea 2: Al mismo tiempo, la rutina sobrescribe una matriz real M por NRHS
!> B con Q(K)**T * B utilizando BLAS de Nivel 3.
!>
!> =====================================================================
!>
!> Las matrices A y B se almacenan en la entrada en el array A como
!> los bloques izquierdo y derecho A(1:M,1:N) y A(1:M, N+1:N+NRHS)
!> respectivamente.
!>
!>                                  N     NRHS
!>             array_A   =   M  [ mat_A, mat_B ]
!>
!> Los criterios de truncamiento (es decir, cuándo detener la factorización)
!> pueden ser cualquiera de los siguientes:
!>
!>   1) El parámetro de entrada KMAX, el número máximo de columnas
!>      KMAX a factorizar, es decir, el rango de factorización se limita
!>      a KMAX. Si KMAX >= min(M,N), el criterio no se utiliza.
!>
!>   2) El parámetro de entrada ABSTOL, la tolerancia absoluta para
!>      la norma 2 de columna máxima del residuo de la matriz R22(K). Esto
!>      significa que la factorización se detiene si esta norma es menor o
!>      igual a ABSTOL. Si ABSTOL < 0.0, el criterio no se utiliza.
!>
!>   3) El parámetro de entrada RELTOL, la tolerancia para la norma 2
!>      de columna máxima de la matriz residual R22(K) dividida
!>      por la norma 2 de columna máxima de la matriz original A, que
!>      es igual a abs(R(1,1)). Esto significa que la factorización se detiene
!>      cuando la relación de la norma 2 de columna máxima de R22(K) a
!>      la norma 2 de columna máxima de A es menor o igual a RELTOL.
!>      Si RELTOL < 0.0, el criterio no se utiliza.
!>
!>   4) En caso de que los criterios de parada ABSTOL o RELTOL no se utilicen,
!>      y cuando la matriz residual R22(K) es una matriz cero en algún
!>      paso de factorización K. (Este criterio de parada es implícito.)
!>
!>  El algoritmo se detiene cuando cualquiera de estas condiciones se satisface primero,
!>  de lo contrario, se factoriza toda la matriz A.
!>
!>  Para factorizar toda la matriz A, utilice los valores
!>  KMAX >= min(M,N), ABSTOL < 0.0 y RELTOL < 0.0.
!>
!>  La rutina devuelve:
!>     a) Q(K), R(K)_aproximada = ( R11(K), R12(K) ),
!>        R(K)_residual = R22(K), P(K), es decir, las matrices resultantes
!>        de la factorización; P(K) se representa mediante JPIV,
!>        ( si K = min(M,N), R(K)_aproximada es la matriz R completa,
!>        y no hay matriz residual R(K)_residual);
!>     b) K, el número de columnas que se factorizaron,
!>        es decir, rango de factorización;
!>     c) MAXC2NRMK, la norma 2 de columna máxima de la matriz
!>        residual R(K)_residual = R22(K),
!>        ( si K = min(M,N), MAXC2NRMK = 0.0 );
!>     d) RELMAXC2NRMK igual a MAXC2NRMK dividido por MAXC2NRM, la norma 2
!>        de columna máxima de la matriz original A, que es igual
!>        a abs(R(1,1)), ( si K = min(M,N), RELMAXC2NRMK = 0.0 );
!>     e) Q(K)**T * B, la matriz B con la transformación ortogonal
!>        Q(K)**T aplicada a la izquierda.
!>
!> La matriz de permutación N por N P(K) se almacena en formato compacto en
!> el array de enteros JPIV. Para 1 <= j <= N, la columna j
!> de la matriz A fue intercambiada con la columna JPIV(j).
!>
!> La matriz ortogonal M por M Q se representa como un producto
!> de transformaciones de Householder elementales
!>
!>     Q(K) = H(1) *  H(2) * . . . * H(K),
!>
!> donde K es el número de columnas que se factorizaron.
!>
!> Cada H(j) tiene la forma
!>
!>     H(j) = I - tau * v * v**T,
!>
!> donde 1 <= j <= K y
!>   I    es una matriz identidad M por M,
!>   tau  es un escalar real,
!>   v    es un vector real con v(1:j-1) = 0 y v(j) = 1.
!>
!> v(j+1:M) se almacena a la salida en A(j+1:M,j) y tau en TAU(j).
!>
!> Consulte la sección Detalles adicionales para obtener más información.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de
!>          columnas de la matriz B. NRHS >= 0.
!>

KMAX

!>          KMAX es INTEGER
!>
!>          El primer criterio de parada de la factorización. KMAX >= 0.
!>
!>          El número máximo de columnas de la matriz A a factorizar,
!>          es decir, el rango máximo de factorización.
!>
!>          a) Si KMAX >= min(M,N), entonces este criterio de parada
!>                no se utiliza, la rutina factoriza columnas
!>                dependiendo de ABSTOL y RELTOL.
!>
!>          b) Si KMAX = 0, entonces este criterio de parada se
!>                satisface en la entrada y la rutina sale inmediatamente.
!>                Esto significa que la factorización no se realiza,
!>                las matrices A y B no se modifican, y
!>                la matriz A es en sí misma el residuo.
!>

ABSTOL

!>          ABSTOL es REAL
!>
!>          El segundo criterio de parada de la factorización, no puede ser NaN.
!>
!>          La tolerancia absoluta (umbral de parada) para
!>          la norma 2 de columna máxima del residuo de la matriz R22(K).
!>          El algoritmo converge (detiene la factorización) cuando
!>          la norma 2 de columna máxima del residuo de la matriz R22(K)
!>          es menor o igual a ABSTOL. Sea SAFMIN = SLAMCH('S').
!>
!>          a) Si ABSTOL es NaN, no se realiza ningún cálculo
!>                y XERBLA emite un mensaje de error ( INFO = -5 ).
!>
!>          b) Si ABSTOL < 0.0, entonces este criterio de parada no se
!>                utiliza, la rutina factoriza columnas dependiendo
!>                de KMAX y RELTOL.
!>                Esto incluye el caso ABSTOL = -Inf.



SGEQP3RK — LAPACK routine






























SGEQRK




SGEQRK computes the rank-revealing QR factorization of a real M-by-N
matrix A, with column pivoting, using a blocked QR algorithm.
It is a subroutine of the real general matrix computational routines.


The rank-revealing QR factorization is intended to find the rank of a matrix
and to determine an accurate solution to within machine precision.


The algorithm used is described in:





  A. Bunse-Gerstner, R. Byers, V. Mehrmann, and H. Voigt.
  "Rank-revealing QR-factorizations.


The routine performs the following factorization:


A = Q * R



where Q is an M-by-M orthogonal matrix, and R is an M-by-N
upper-trapezoidal matrix.


The subroutine is called as follows:


CALL SGEQRK( M, N, MB, NB, A, LDA, JPVT, TAU, WORK, LWORK, INFO )



Parameters






M




M is INTEGER


The number of rows of the matrix A. M >= 0.



N




N is INTEGER


The number of columns of the matrix A. N >= 0.



MB




MB is INTEGER


The number of rows of the block (panels). MB >= 0.



NB


NB




NB is INTEGER


The number of columns of the block (panels). NB >= 0.



A




A is REAL array, dimension (LDA,N)


On entry: the M-by-N matrix A to be factorized.
On exit:

    

  • 
The elements on and above the diagonal of the array
A contain the M-by-N upper trapezoidal matrix R.

    • 

  • 
The elements below the diagonal contain the factors of the
orthogonal matrix Q.

    • 





LDA




LDA is INTEGER


The leading dimension of the array A. LDA >= max(1,M).



JPVT




JPVT is INTEGER array, dimension (N)


On entry: contains the initial permutation of the columns of A.
On exit: contains the permutation of the columns of A.
Jpvt(i) = k means that the k-th column of the initial matrix A
is in the i-th column of the current matrix A.



TAU




TAU is REAL array, dimension (min(M,N))


On exit: contains the scalar factors of the elementary reflectors.



WORK




WORK is REAL array, dimension (LWORK)





On entry



If LWORK = -1, then WORK is an input array that is not
used.



On exit



WORK(1) contains the optimal LWORK.







LWORK




LWORK is INTEGER


The dimension of the array WORK. LWORK >= 1.



For optimal performance



LWORK >= (MB*NB + max(MB,NB)) * max(min(M,N),NB)





If LWORK = -1, then LWORK is an input parameter that
when set to -1 indicated that the workspace query has been
performed. The routine returns the optimal workspace size in
WORK(1).




INFO




INFO is INTEGER



    

  • 
INFO = 0: successful exit.

    • 

  • 
INFO < 0: If INFO = -i, the i-th argument had an illegal
value.

    • 

  • 
INFO > 0: If INFO = i, and 1 <= i <= N, then the i-th
column of A is linearly dependent on the preceding columns.
The factorization has been completed, but the rank of the
matrix A is less than i.

    •

Detalles Adicionales:

!> SGEQP3RK se basa en el mismo algoritmo de factorización QR de Householder
!> BLAS3 con pivote de columna que en la rutina SGEQP3, que utiliza
!> la rutina SLARFG para generar reflectores de Householder
!> para la factorización QR.
!>
!> También podemos escribir:
!>
!>   A = A_aprox(K) + A_residual(K)
!>
!> La matriz de aproximación de bajo rango A(K)_aprox de
!> la factorización QR truncada de rango K de la matriz A es:
!>
!>   A(K)_aprox = Q(K) * ( R(K)_aprox ) * P(K)**T
!>                        (     0     0 )
!>
!>               = Q(K) * ( R11(K) R12(K) ) * P(K)**T
!>                        (      0      0 )
!>
!> El residuo A_residual(K) de la matriz A es:
!>
!>   A_residual(K) = Q(K) * ( 0              0 ) * P(K)**T =
!>                          ( 0  R(K)_residual )
!>
!>                 = Q(K) * ( 0        0 ) * P(K)**T
!>                          ( 0   R22(K) )
!>
!> La factorización truncada (rango K) garantiza que
!> la norma 2 de columna máxima de A_residual(K) es menor
!> o igual a MAXC2NRMK hasta el error de redondeo.
!>
!> NOTA: Una aproximación de los vectores nulos
!>       de A se puede calcular fácilmente a partir de R11(K)
!>       y R12(K):
!>
!>       Null( A(K) )_aprox = P * ( inv(R11(K)) * R12(K) )
!>                                 (         -I           )
!>
