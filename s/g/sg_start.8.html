NOMBRE

sg_start - envía el comando SCSI START STOP UNIT: iniciar, detener, cargar o expulsar medio

SINOPSIS

sg_start [0] [1] [--eject] [--help] [--fl=FL] [--immed] [--load] [--loej] [--mod=PC_MOD] [--noflush] [--pc=PC] [--readonly] [--start] [--stop] [--verbose] [--version] DISPOSITIVO

sg_start [--eject] [--fl=FL] [-i] [--imm=0|1] [--load] [--loej] [--mod=PC_MOD] [--noflush] [--pc=PC] [-r] [--start] [--stop] [-v] [-V] [0|1] DISPOSITIVO

DESCRIPCIÓN

sg_start envía un comando SCSI START STOP UNIT al DISPOSITIVO con las opciones seleccionadas. Las opciones más utilizadas son --stop para apagar un disco y --start para encender un disco. Usar --start en un disco que ya está girando no tiene consecuencias. También hay un control más granular con la "condición de energía": activo, inactivo o en espera. Esto se establece con la opción --pc=PC. En algunos contextos, el estado de "detenido" puede considerarse una condición de energía adicional.

Los dispositivos que contienen medios extraíbles como CD/DVD pueden usar la opción --loej para cargar el medio cuando se usa junto con --start (es decir, cargar el medio y luego encenderlo). Alternativamente, --loej puede usarse para expulsar el medio cuando se usa junto con --stop (es decir, apagar y luego expulsar el medio). De forma más sencilla, la carga o expulsión de un medio extraíble se puede solicitar con la opción --load o --eject.

Si no se proporciona ninguna opción o argumento, se asume --start; como sugiere el nombre de la utilidad.

Esta utilidad admite dos sintaxis de línea de comandos; la preferida se muestra primero en la sinopsis y se explica en esta sección. Una sección posterior sobre la sintaxis de línea de comandos antigua describe el segundo grupo de opciones.

Nota de Linux: es mejor no usar un nombre de dispositivo de bloque estándar (por ejemplo, /dev/sdc) con la opción --stop. Utilice un nodo de dispositivo sg o bsg en su lugar (consulte lsscsi(8)). La capa de bloque a veces notará que el disco se apaga y decidirá: "eso no está bien" y lo volverá a encender.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

0
misma acción que --stop.
1
misma acción que --start.
-e, --eject
detiene el medio y lo expulsa de la unidad. Solo apropiado para un dispositivo con medio extraíble. Puede ser ignorado (previsto), ver más abajo. Tenga en cuenta que esta es una operación que se puede realizar en una unidad de cinta o reproductor de CD/DVD/BD, ¡no en un disco duro o SSD!
-h, --help
imprime el mensaje de uso y luego sale.
-f, --fl=FL
establece el número de capa de formato para que el disco "salte" (definido en MMC-5). Los valores de FL pueden ser de 0 a 3. Cuando se elige esta opción, los bits FL, LoEj y Start se establecen en el cdb según lo requerido por MMC-5; por lo tanto, el usuario no necesita establecer las opciones --start y/o --load.
-i, --immed
establece el bit IMM en el comando START STOP UNIT para que esta utilidad regrese inmediatamente y no espere a que el medio complete la acción solicitada. El valor predeterminado es esperar hasta que el medio complete la acción solicitada antes de regresar.
-l, --load
carga el medio en la unidad y la inicia. Solo apropiado para un medio extraíble.
-L, --loej
establece el bit LOEJ en el comando START STOP UNIT. Esto carga el medio cuando la unidad se inicia o lo expulsa cuando la unidad se detiene (es decir, funciona en conjunto con el bit START en el cdb). Esta opción se ignora si 'pc > 0'. El valor predeterminado está desactivado (es decir, no intente cargar ni expulsar medios). Si no se proporciona una indicación de inicio/parada (es decir, ni --start ni --stop) y se proporciona esta opción, se asume una acción de carga e inicio.
-m, --mod=PC_MOD
donde PC_MOD es el valor del 'modificador de condición de energía'. 0 a 15 (inclusive) son válidos y 0 es el valor predeterminado. Este campo de 'modificador de condición de energía' en el cdb se agregó después de sbc3r13.
-n, --noflush
no realice un volcado a medios (por ejemplo, como lo hace SYNCHRONIZE CACHE) antes de una variante de esta utilidad que limita el acceso a los medios. El uso de la opción --stop es un ejemplo de algo que limita el acceso a los medios. Este campo 'noflush' en el cdb se agregó después de sbc3r13.
-O, --old
Cambiar a opciones de estilo antiguo. Úselo como primera opción.
-p, --pc=PC
donde PC es el valor de las 'condiciones de energía'. 0 a 15 (inclusive) son válidos. El valor predeterminado es 0. Cuando '--pc=0', las opciones --eject, --load, --loej, --start y --stop están activas. Algunos valores comunes son 1 para la condición de energía "activa" (SBC); 2 para la condición de energía inactiva; 3 para la condición de energía en espera; 5 para la condición de energía de suspensión (MMC); 7 para LU_CONTROL (SBC), 0xa (decimal 10) para FORCE_IDLE_0 (SBC) y 0xb (decimal 11) para FORCE_STANDBY_0 (SBC). Consulte los borradores recientes de SBC-3, MMC-5 y SAS en www.t10.org para obtener más información.
-r, --readonly
abre el DISPOSITIVO en modo de solo lectura. Puede ser necesario en Linux para detener una intrusiva activación si el DISPOSITIVO es un disco ATA. La intrusiva activación puede ocurrir al final de este comando, anulando el efecto de la opción --stop.
-s, --start
inicia (enciende) el DISPOSITIVO. Esto establece el bit START en el cdb. Usar esta opción en un dispositivo ya iniciado no tiene consecuencias. En ausencia de otras opciones, esta opción es el valor predeterminado (es decir, establece el bit cdb START).
-S, --stop
detiene (apaga) el DISPOSITIVO. Esto borra el bit START en el cdb. Esta operación se realiza típicamente en un disco duro o SSD. En el caso de un SSD, se pondrá en modo de bajo consumo y puede requerir una operación de inicio posterior antes de que se reanuden las operaciones normales de E/S.
-v, --verbose
aumenta el nivel de verbosidad. Se puede usar varias veces.
-V, --version
imprime la cadena de versión y sale.

NOTAS

Para evitar confusiones, solo se debe proporcionar una de las opciones 0, 1, --eject, --load, --start y --stop.

Existe una página de modo asociada de "condición de energía" (0x1a) en la que se pueden establecer valores de tiempo para la transición a los estados inactivo o en espera después de un período de inactividad. La utilidad sdparm se puede utilizar para ver la página de modo de condición de energía y, si es necesario, modificarla. Si un DISPOSITIVO se encuentra en estado de condición de energía inactiva o en espera, un comando REQUEST SENSE (consulte la utilidad sg_requests) debería arrojar una clave de sentido de "sin sentido" y un código de sentido adicional de "Condición de baja energía activada" en dispositivos SCSI recientes.

La expulsión de medios extraíbles (por ejemplo, 'sg_start --eject /dev/hdd' donde el DISPOSITIVO es una unidad de CD/DVD ATAPI) puede ser impedida por un comando SCSI PREVENT ALLOW MEDIUM REMOVAL previo (consulte sg_prevent). En este caso, esta utilidad debería fallar con un error generado por el dispositivo: solicitud ilegal / eliminación de medios prohibida. Esto se puede anular usando sg_prevent o, por ejemplo, 'sdparm --command=unlock /dev/hdd'.

El comando SCSI TEST UNIT READY se puede usar para averiguar si un DISPOSITIVO está listo para transferir datos. Si los medios giratorios están detenidos o aún están alcanzando la velocidad, el comando TEST UNIT READY arrojará una clave de sentido de "no listo" y un código de sentido adicional más informativo. Consulte la utilidad sg_turs.

En la serie 2.4 de los kernels de Linux, el DISPOSITIVO debe ser un dispositivo genérico SCSI (sg). En la serie 2.6, también se pueden especificar dispositivos de bloque (por ejemplo, discos SCSI y unidades de DVD). Por ejemplo, "sg_start 0 /dev/sda" funcionará en el ker de la serie 2.6

sg_start(8) — Arch Linux

NAME

sg_start — start, stop, eject or load medium in a SCSI (or ATA) device

SYNOPSIS

sg_start [OPTIONS] DEVICE

DESCRIPTION

This utility sends a START STOP UNIT SCSI command (or equivalent ATA command) to the given DEVICE. This command can be used to start (spin up), stop (spin down), eject, or load the medium within a drive. Many CD/DVD/Blu-ray drives and some disk drives support this command.

Newer SCSI standards (like SBC-3) have added options to this command to control power conditions and other features. This utility provides access to these newer features, as well as the basic start/stop/eject functionality.

OPTIONS

This utility supports both the older style command line options (prior to sg3_utils version 1.23) and the newer style. By default, it uses the newer style. The older style can be selected with the --old option (or -O).

-h, --help
Output help information and exit.
-O, --old
Use older command line options. See the OLDER COMMAND LINE OPTIONS section below.
-v, --verbose=LEVEL
Increase or decrease the level of verbosity of the output. Can be given multiple times, e.g. -vv.
-V, --version
Output version string and exit.
--cmd=SCSI_CMD
Perform a specific SCSI START STOP UNIT command sequence. This is intended for advanced users and debugging. SCSI_CMD is a space separated list of hex bytes representing the command.
--eject
Eject the medium from the drive. Sets the Eject (EJT) bit and the Stop (ST) bit. This is the default action if neither start nor stop operations are specified.
--fl=FL
Set the Format Layer (FL) field. Used with CD/DVD/Blu-ray media to specify a track to start playing from. Value is 0 to 255.
--imm=0|1
Set the Immediate (IMM) bit. If set (1), the command returns immediately after the START STOP UNIT command is accepted by the device, without waiting for the operation (e.g. spin down) to complete. Default is 0 (wait for completion).
--load
Load the medium into the drive and start it. Sets the Load (LD) bit and the Start (ST) bit.
--loej
Set the Load/Eject (LOEJ) bit. If combined with a start operation, it loads and starts. If combined with a stop operation, it stops and ejects. If used alone, it defaults to stop and eject.
--mod=PC_MOD
Set the Power Condition Modifier (PCMOD) field. Value is 0 to 15. This field is part of the newer power management extensions.
--noflush
Do not perform a cache flush before stopping the device. This is useful in situations where a flush is not needed or might interfere with the stop operation.
--pc=PC
Set the Power Condition (PC) field. Value is 0 to 15. This field is part of the newer power management extensions and controls the power state the device should enter.
--readonly, -r
Set the Read-Only (RO) bit. This typically prevents writes to the medium. May be useful for ATA disks.
--start
Start (spin up) the device. Sets the Start (ST) bit.
--stop
Stop (spin down) the device. Sets the Stop (ST) bit.
--wce
Set the Write Cache Enable (WCE) bit. This is usually used in conjunction with a stop operation to ensure data is flushed from the cache to the media before stopping.

NOTES

In the Linux 2.6 series, especially with ATA disks, using this utility to stop (spin down) a disk may not be sufficient and other mechanisms will start the disk again some time later. The user might additionally mark the disk as "offline" with 'echo offline > /sys/block/sda/device/state' where sda is the block name of the disk. To restart the disk "offline" can be replaced with "running". Note that once the 'state' is set to offline, no SCSI commands can be sent to the device until it is set back to running. Also stopping a disk via a pass-through interface (e.g. /dev/sg1 or /dev/bsg/1:0:0:0) may reduce unwanted side effects (such as restarting it again when this utility completes).

EXIT STATUS

The exit status of sg_start is 0 when it is successful. Otherwise see the sg3_utils(8) man page.

OLDER COMMAND LINE OPTIONS

The options in this section were the only ones available prior to sg3_utils version 1.23 . Since then this utility defaults to the newer command line options which can be overridden by using --old (or -O) as the first option. See the ENVIRONMENT VARIABLES section for another way to force the use of these older command line options.

Note that the action of --loej is slightly different in the older interface: when neither --start nor --stop (nor proxies for them) are given, --loej performs an eject operation. In the same situation the newer interface will perform a load operation.

Earlier versions of sg_start had a '-s' option to perform a SYNCHRONIZE CACHE command before the START STOP UNIT command was issued. According to recent SBC-2 drafts this is done implicitly if required. Hence the '-s' option has been dropped.

All options, other than '-v' and '-V', can be given with a single "-". For example: "sg_start -stop /dev/sda" and "sg_start --stop /dev/sda" are equivalent. The single "-" form is for backward compatibility.

0
stop (spin-down) DEVICE.
1
start (spin-up) DEVICE.
--eject
stop the medium and eject it from the drive.
--fl=FL
sets the format layer number for the disc to "jump" to (defined in MMC-5).
-i
sets the IMM bit on the START STOP UNIT command so this utility will return immediately and not wait for the media to spin down. Same effect as '--imm=1'. The default action (without this option or a '--imm=1' option) is to wait until the media spins down before returning.
--imm=0|1
when the immediate bit is 1 then this utility returns immediately after the DEVICE has received the command. When this option is 0 (the default) then the utility returns once the command has completed its action (i.e. it waits until the device is started or stopped).
--load
load the medium in the drive and start it.
--loej
sets the LOEJ bit in the START STOP UNIT cdb. When a "start" operation is indicated, then a load and start is performed. When a "stop" operation is indicated, then a stop and eject is performed. When neither a "start" or "stop" operation is indicated does a stop and eject. [Note that the last action differs from the new interface in which the option of this name defaults to load and start.]
-N, --new
Switch to the newer style options.
--mod=PC_MOD
where PC_MOD is the 'power condition modifier' value. 0 to 15 (inclusive) are valid and 0 is the default. This field was added after sbc3r13.
--noflush
do not perform a flush to media (e.g. like SYNCHRONIZE CACHE does) before a variant of this utility that limits access to the media. Using the --stop option is an example of something that limits access to the media. This field was added after sbc3r13.
--pc=PC
where PC is the 'power condition' value (in hex). 0 to f (inclusive) are valid. Default value is 0.
-r
see the --readonly option above. May be useful for ATA disks.
--start
start (spin-up) DEVICE.
--stop
stop (spin-down) DEVICE. Same meaning as "0" argument.
-v
verbose: outputs SCSI command in hex to console before with executing it. '-vv' and '-vvv' are also accepted yielding greater verbosity.
-V
print out version string then exit.

ENVIRONMENT VARIABLES

Since sg3_utils version 1.23 the environment variable SG3_UTILS_OLD_OPTS can be given. When it is present this utility will expect the older command line options. So the presence of this environment variable is equivalent to using --old (or -O) as the first command line option.
