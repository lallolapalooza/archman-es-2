SGTSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GT

Propósito:

!>
!> SGTSVX utiliza la factorización LU para calcular la solución a un sistema real
!> de ecuaciones lineales A * X = B o A**T * X = B,
!> donde A es una matriz tridiagonal de orden N y X e B son matrices N-por-NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación de la
!> condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza la descomposición LU para factorizar la matriz A
!>    como A = L * U, donde L es un producto de matrices de permutación y
!>    bidiagonales unitarias, y U es triangular superior con no ceros solo en
!>    la diagonal principal y las dos superdiagonales principales.
!>
!> 2. Si algún U(i,i)=0, de modo que U sea exactamente singular, la rutina
!>    retorna con INFO = i. De lo contrario, la forma factorizada de A se utiliza
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se retorna INFO = N+1 como advertencia, pero la rutina aún continúa
!>    para resolver X y calcular los límites de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la matriz solución calculada
!>    y calcular límites de error y estimaciones de error hacia atrás para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A se ha suministrado o no
!>          en la entrada.
!>          = 'F':  DLF, DF, DUF, DU2 e IPIV contienen la forma factorizada
!>                  de A; DL, D, DU, DLF, DF, DUF, DU2 e IPIV no se
!>                  modificarán.
!>          = 'N':  La matriz se copiará en DLF, DF y DUF
!>                  y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transposición)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

DL

!>          DL es un array REAL, dimensión (N-1)
!>          Los elementos subdiagonales (n-1) de A.
!>

D

!>          D es un array REAL, dimensión (N)
!>          Los n elementos diagonales de A.
!>

DU

!>          DU es un array REAL, dimensión (N-1)
!>          Los elementos superdiagonales (n-1) de A.
!>

DLF

!>          DLF es un array REAL, dimensión (N-1)
!>          Si FACT = 'F', entonces DLF es un argumento de entrada y en la entrada
!>          contiene los multiplicadores (n-1) que definen la matriz L de
!>          la factorización LU de A calculada por SGTTRF.
!>
!>          Si FACT = 'N', entonces DLF es un argumento de salida y en la salida
!>          contiene los multiplicadores (n-1) que definen la matriz L de
!>          la factorización LU de A.
!>

DF

!>          DF es un array REAL, dimensión (N)
!>          Si FACT = 'F', entonces DF es un argumento de entrada y en la entrada
!>          contiene los elementos diagonales n de la matriz triangular superior
!>          U de la factorización LU de A.
!>
!>          Si FACT = 'N', entonces DF es un argumento de salida y en la salida
!>          contiene los elementos diagonales n de la matriz triangular superior
!>          U de la factorización LU de A.
!>

DUF

!>          DUF es un array REAL, dimensión (N-1)
!>          Si FACT = 'F', entonces DUF es un argumento de entrada y en la entrada
!>          contiene los elementos (n-1) de la primera superdiagonal de U.
!>
!>          Si FACT = 'N', entonces DUF es un argumento de salida y en la salida
!>          contiene los elementos (n-1) de la primera superdiagonal de U.
!>

DU2

!>          DU2 es un array REAL, dimensión (N-2)
!>          Si FACT = 'F', entonces DU2 es un argumento de entrada y en la entrada
!>          contiene los elementos (n-2) de la segunda superdiagonal de
!>          U.
!>
!>          Si FACT = 'N', entonces DU2 es un argumento de salida y en la salida
!>          contiene los elementos (n-2) de la segunda superdiagonal de
!>          U.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene los índices de pivote de la factorización LU de A calculada
!>          por SGTTRF.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización LU de A;
!>          la fila i de la matriz se intercambió con la fila IPIV(i).
!>          IPIV(i) siempre será i o i+1; IPIV(i) = i indica que no se requirió
!>          un intercambio de filas.
!>

B

!>          B es un array REAL, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B de N-por-NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array REAL, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N-por-NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La estimación del número de condición recíproco de la matriz
!>          A.  Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular con precisión de trabajo.
!>          Esta condición se indica con un código de retorno de
!>          INFO > 0.
!>

FERR

SYNOPSIS

SUBROUTINE SGTSVX(FACT, TRANS, N, NRHS, DL, D, DU, DLU, DUU,

Parameters:

FACT
CHARACTER*1. Specifies whether or not the factorization of the matrix A is supplied.
'E'
The matrix A has just been factorized by SGTTRF.
'N'
The matrix A has not been factorized, and is factorized here.
TRANS
CHARACTER*1. Specifies the form of the system of equations:
'N'
A x = B (No transpose)
'T'
AT x = B (Transpose)
'C'
AH x = B (Conjugate transpose)
N
INTEGER. The order of the matrix A. N >= 0.
NRHS
INTEGER. The number of right hand side vectors, i.e., the number of columns in the arrays B and X. NRHS >= 0.
DL
REAL array, dimension (N-1)
D
REAL array, dimension (N)
DU
REAL array, dimension (N-1)
DLU
REAL array, dimension (N-2)
DUU
REAL array, dimension (N-2)
DV
REAL array, dimension (N-1)
DVU
REAL array, dimension (N-1)
DVUU
REAL array, dimension (N-2)
DVDU
REAL array, dimension (N-1)
DVDUU
REAL array, dimension (N-2)
B
REAL array, dimension (LDB,NRHS)
On entry, the right hand side matrix.

On exit, if UPLO = 'U', B is overwritten by values computed by some transformation of the vector X. If UPLO = 'L', B is overwritten by values computed by some transformation of the vector X.

LDB
INTEGER. The leading dimension of array B. LDB >= max(1, N).
X
REAL array, dimension (LDX,NRHS)
On exit, the solution matrix X to the system of equations.
LDX
INTEGER. The leading dimension of array X. LDX >= max(1, N).
RCOND
REAL.
The estimate of the reciprocal condition number of the matrix A. The matrix A is close to singular if RCOND is small.
BERR
REAL array, dimension (NRHS)
The componentwise relative backward error of each solution vector X(j) (i.e., the smallest relative change in any element of A or B that makes X(j) an exact solution).
WORK
REAL array, dimension (3*N)
IWORK
INTEGER array, dimension (N)
INFO
INTEGER.
= 0
successful exit
< 0
if INFO = -i, the i-th argument had an illegal value
> 0
if INFO = i, and i is
<= N
U(i,i) is exactly zero. The factorization has not been completed unless i = N, but the factor U is exactly singular, so the solution and error bounds could not be computed. RCOND = 0 is returned.
= N+1
U is nonsingular, but RCOND is less than machine precision, meaning that the matrix is singular to working precision. Nevertheless, the solution and error bounds are computed because there are a number of situations where the computed solution can be more accurate than the value of RCOND would suggest.
