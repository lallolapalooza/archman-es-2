Documentación de Función/Subrutina

subroutine sgesvdq (character joba, character jobp, character jobr, character jobu, character jobv, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldv, * ) v, integer ldv, integer numrank, integer, dimension( * ) iwork, integer liwork, real, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer lrwork, integer info)

SGESVDQ calcula la descomposición en valores singulares (SVD) de una matriz real M-por-N A, donde M >= N, utilizando un método QR precondicionado con QR.

Propósito:

!>
!> SGESVDQ calcula la descomposición en valores singulares (SVD) de una matriz
!> real M-por-N A, donde M >= N. La SVD de A se escribe como
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> donde SIGMA es una matriz diagonal N-por-N, U es una matriz ortonormal M-por-N,
!> y V es una matriz ortogonal N-por-N. Los elementos diagonales
!> de SIGMA son los valores singulares de A. Las columnas de U y V son los
!> vectores singulares izquierdos y derechos de A, respectivamente.
!>

Parámetros

JOBA 
!>  JOBA es CHARACTER*1
!>  Especifica el nivel de precisión en la SVD calculada
!>  = 'A' La precisión solicitada corresponde a tener el error hacia atrás
!>        acotado por || delta A ||_F <= f(m,n) * EPS * || A ||_F,
!>        donde EPS = SLAMCH('Epsilon'). Esto autoriza a CGESVDQ a
!>        truncar el factor triangular calculado en una factorización QR
!>        que revela el rango siempre que la parte truncada esté por debajo del
!>        umbral del orden de EPS * ||A||_F. Este es un nivel de truncamiento agresivo.
!>  = 'M' De manera similar a 'A', pero el truncamiento es más suave:
!>        solo se permite cuando hay una caída en la diagonal del
!>        factor triangular en la factorización QR. Este es un nivel de truncamiento medio.
!>  = 'H' Se solicita alta precisión. No se intenta ninguna determinación de rango numérico basada
!>        en la factorización QR que revela el rango.
!>  = 'E' Igual que 'H', y además se estima el número de condición de A escalada por columnas
!>        y se devuelve en  RWORK(1).
!>        N^(-1/4)*RWORK(1) <= ||pinv(A_escalada)||_2 <= N^(1/4)*RWORK(1)
!>

JOBP

!>  JOBP es CHARACTER*1
!>  = 'P' Las filas de A se ordenan en orden decreciente con respecto a
!>        ||A(i,:)||_\infty. Esto mejora la precisión numérica a costa de
!>        movimiento de datos adicional. Recomendado para robustez numérica.
!>  = 'N' Sin pivoteo de filas.
!>

JOBR

!>          JOBR es CHARACTER*1
!>          = 'T' Después de la factorización QR pivoteada inicial, SGESVD se aplica a
!>          la R**T transpuesta del factor triangular R calculado. Esto implica
!>          algo de movimiento de datos adicional (transposiciones de matrices). Útil para
!>          experimentos, investigación y desarrollo.
!>          = 'N' El factor triangular R se proporciona como entrada a SGESVD. Esto puede ser
!>          preferible ya que implica menos movimiento de datos.
!>

JOBU

!>          JOBU es CHARACTER*1
!>          = 'A' Todos los M vectores singulares izquierdos se calculan y se devuelven en
!>          la matriz U. Ver la descripción de U.
!>          = 'S' o 'U' N = min(M,N) vectores singulares izquierdos se calculan y se devuelven
!>          en la matriz U. Ver la descripción de U.
!>          = 'R' Se determina el rango numérico NUMRANK y solo se calculan NUMRANK vectores singulares izquierdos
!>          y se devuelven en la matriz U.
!>          = 'F' Los N vectores singulares izquierdos se devuelven en forma factorizada como el
!>          producto del factor Q de la factorización QR inicial y los
!>          N vectores singulares izquierdos de (R**T , 0)**T. Si se utiliza pivoteo de filas,
!>          entonces la información necesaria sobre el pivoteo de filas se almacena en
!>          IWORK(N+1:N+M-1).
!>          = 'N' Los vectores singulares izquierdos no se calculan.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'A', 'V' Todos los N vectores singulares derechos se calculan y se devuelven en
!>          la matriz V.
!>          = 'R' Se determina el rango numérico NUMRANK y solo se calculan NUMRANK vectores singulares derechos
!>          y se devuelven en la matriz V. Esta opción solo se permite si JOBU = 'R' o JOBU = 'N'; de lo contrario, es ilegal.
!>          = 'N' Los vectores singulares derechos no se calculan.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  M >= N >= 0.
!>

A

!>          A es un array REAL de dimensiones LDA x N
!>          En la entrada, la matriz de entrada A.
!>          En la salida, si JOBU .NE. 'N' o JOBV .NE. 'N', el triángulo inferior de A contiene
!>          los vectores de Householder almacenados por SGEQP3. Si JOBU = 'F', estos vectores de Householder
!>          junto con WORK(1:N) pueden usarse para restaurar los factores Q de la
!>          factorización QR pivoteada inicial de A. Ver la descripción de U.
!>

LDA

!>          LDA es INTEGER.
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

S

!>          S es un array REAL de dimensión N.
!>          Los valores singulares de A, ordenados de tal manera que S(i) >= S(i+1).
!>

U

!>          U es un array REAL, dimensión
!>          LDU x M si JOBU = 'A'; ver la descripción de LDU. En este caso,
!>          en la salida, U contiene los M vectores singulares izquierdos.
!>          LDU x N si JOBU = 'S', 'U', 'R'; ver la descripción de LDU. En este
!>          caso, U contiene los N o los NUMRANK vectores singulares izquierdos principales.
!>          LDU x N si JOBU = 'F'; ver la descripción de LDU. En este caso U
!>          contiene una matriz ortogonal N x N que puede usarse para formar los vectores singulares izquierdos.
!>          Si JOBU = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER.
!>          La dimensión principal del array U.
!>          Si JOBU = 'A', 'S', 'U', 'R',  LDU >= max(1,M).
!>          Si JOBU = 'F',                 LDU >= max(1,N).
!>          De lo contrario,                     LDU >= 1.
!>

V

!>          V es un array REAL, dimensión
!>          LDV x N si JOBV = 'A', 'V', 'R' o si JOBA = 'E' .
!>          Si JOBV = 'A', o 'V',  V contiene la matriz ortogonal N-por-N  V**T;
!>          Si JOBV = 'R', V contiene las primeras NUMRANK filas de V**T (los vectores singulares derechos,
!>          almacenados fila a fila, de los NUMRANK valores singulares más grandes).
!>          Si JOBV = 'N' y JOBA = 'E', V se usa como espacio de trabajo.
!>          Si JOBV = 'N', y JOBA.NE.'E', V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si JOBV = 'A', 'V', 'R',  o JOBA = 'E', LDV >= max(1,N).
!>          De lo contrario,                               LDV >= 1.
!>

NUMRANK

!>          NUMRANK es INTEGER
!>          NUMRANK es el rango numérico determinado por primera vez después de la factorización
!>          QR que revela el rango, siguiendo la estrategia especificada por la

NAME


sgesvdq - Computes the singular value decomposition (SVD) of a
  real M-by-N matrix A, say A = U*S*V^T.






SYNOPSIS


 SUBROUTINE SGESVDQ( JOBA, JOBV, JOBR, JOBP, M, N, A, LDA, S, U, LDU,
                     VT, LDVT, IWORK, LIWORK, WORK, LWORK, RWORK, LRWORK,
                     INFO )
 


 INTEGER INFO
 REAL A( LDA, * ), S( * ), U( LDU, * ), VT( LDVT, * ),
      WORK( * ), RWORK( * )
 INTEGER LDA, LDU, LDVT, LIWORK, LWORK, LRWORK, M, N
 CHARACTER * 1 JOBA, JOBV, JOBR, JOBP
 






Function/Subroutine Documentation


Purpose


!>
!> The subroutine SGESVDQ computes the singular value decomposition (SVD)
!> of a real M-by-N matrix A, say A = U*S*V^T.
!>
!> The subroutine SGESVDQ uses a rank revealing QR factorization followed by
!> QR algorithm for matrices of size N*N. In addition to the SVD, the
!> routine can also compute the condition number estimate of A.
!>
!> The rank of A is returned in the argument NUMRANK.
!>
!> The condition number estimate is returned in RWORK(1).
!>
!> Details:
!>   The SVD is computed using a QR factorization of A, followed by the QR
!>   algorithm applied to the upper triangular matrix R. The vectors U and V
!>   are computed using the inverse QR factorization of R.
!>
!>   The routine SGESVDQ is a hybrid algorithm that uses a rank revealing QR
!>   factorization for determining the rank and for providing a good initial
!>   matrix for the QR algorithm.
!>
!>   The condition number estimate is computed using a technique based on the
!>   rank revealing QR factorization.
!>
!>   The accuracy of the SVD computation is governed by the following choices:
!>   - JOBA: determines whether to compute singular values and singular vectors.
!>   - JOBV: determines whether to compute the left singular vectors U and
!>     the right singular vectors V.
!>   - JOBR: determines whether to use randomized QR factorization.
!>   - JOBP: determines whether to use column pivoting in the QR factorization.
!>
!> Arguments:
!>
!>   JOBA: CHARACTER*1.
!>     Specifies the computation of the singular values:
!>     = 'E': Compute the singular values only.
!>     = 'R': Compute the singular values and the rank.
!>     = 'S': Compute the singular values, the rank, and a scaled condition
!>            number estimate.
!>     = 'A': Compute the singular values, the rank, and the scaled condition
!>            number estimate and all the singular vectors.
!>
!>   JOBV: CHARACTER*1.
!>     Specifies the computation of the left singular vectors U and the
!>     right singular vectors V:
!>     = 'N': Do not compute U and V.
!>     = 'R': Compute the right singular vectors V, and the left singular
!>            vectors U.
!>     = 'A': Compute the full SVD, including U and V.
!>     = 'S': Compute the singular values and the singular vectors U and V.
!>            The singular vectors may be more accurate than the ones computed
!>            by calling SGESVD.
!>     = 'U': Compute the singular values and the singular vectors U.
!>            The singular vectors may be more accurate than the ones computed
!>            by calling SGESVD.
!>
!>   JOBR: CHARACTER*1.
!>     Specifies the use of randomized QR factorization:
!>     = 'N': No randomized QR factorization.
!>     = 'T': Use randomized QR factorization.
!>
!>   JOBP: CHARACTER*1.
!>     Specifies the use of column pivoting in the QR factorization:
!>     = 'N': Do not use column pivoting.
!>     = 'P': Use column pivoting.
!>
!>   M: INTEGER.
!>     The number of rows of the matrix A. M >= 0.
!>
!>   N: INTEGER.
!>     The number of columns of the matrix A. N >= 0.
!>
!>   A: REAL array, dimension (LDA, N).
!>     On entry, the M-by-N matrix A.
!>     On exit, if JOBA = 'E', 'R', 'S', or 'A', A is overwritten by the
!>     upper triangular matrix R from the QR factorization of A.
!>
!>   LDA: INTEGER.
!>     The leading dimension of the array A. LDA >= max(1, M).
!>
!>   S: REAL array, dimension (min(M,N)).
!>     On exit, the singular values, sorted in descending order.
!>     S(i) >= 0.
!>
!>   U: REAL array, dimension (LDU, K).
!>     K = min(M,N) if JOBV = 'S', 'U'.
!>     K = M if JOBV = 'A'.
!>     On exit, if JOBV = 'S', 'U', or 'A', the orthogonal matrix U
!>     containing the left singular vectors.
!>     If JOBV = 'R', U is not used.
!>
!>   LDU: INTEGER.
!>     The leading dimension of the array U.
!>     If JOBV = 'S' or 'U', LDU >= max(1, M).
!>     If JOBV = 'A', LDU >= max(1, M).
!>     If JOBV = 'R', LDU is not used.
!>
!>   VT: REAL array, dimension (LDVT, N).
!>     On exit, if JOBV = 'A' or 'R', the orthogonal matrix V containing
!>     the right singular vectors.
!>     VT is V transpose.
!>     If JOBV = 'S' or 'U', VT is not used.
!>
!>   LDVT: INTEGER.
!>     The leading dimension of the array VT.
!>     If JOBV = 'A' or 'R', LDVT >= max(1, N).
!>     If JOBV = 'S' or 'U', LDVT is not used.
!>
!>   IWORK: INTEGER array, dimension (max(1, LIWORK)).
!>     On exit, IWORK(1:N) contains column pivoting permutation of the
!>     rank revealing QR factorization.
!>     If JOBP = 'P', IWORK(N+1:N+M-1) contains the indices of the sequence
!>     of row swaps used in row pivoting. These can be used to restore the
!>     left singular vectors in the case JOBU = 'F'.
!>
!>     If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
!>     IWORK(1) returns the minimal LIWORK.
!>
!>   LIWORK: INTEGER.
!>     The dimension of the array IWORK.
!>     LIWORK >= N + M - 1,     if JOBP = 'P' and JOBA .NE. 'E';
!>     LIWORK >= N              if JOBP = 'N' and JOBA .NE. 'E';
!>     LIWORK >= N + M - 1 + N, if JOBP = 'P' and JOBA = 'E';
!>     LIWORK >= N + N          if JOBP = 'N' and JOBA = 'E'.
!>
!>     If LIWORK = -1, then a workspace query is assumed; the routine
!>     only calculates and returns the optimal and minimal sizes
!>     for the WORK, IWORK, and RWORK arrays, and no error
!>     message related to LWORK is issued by XERBLA.
!>
!>   WORK: REAL array, dimension (max(2, LWORK)), used as a workspace.
!>     On exit, if, on entry, LWORK.NE.-1, WORK(1:N) contains parameters
!>     needed to recover the Q factor from the QR factorization computed by
!>     SGEQP3.
!>
!>     If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
!>     WORK(1) returns the optimal LWORK, and
!>     WORK(2) returns the minimal LWORK.
!>
!>   LWORK: INTEGER.
!>     The dimension of the array WORK. It is determined as follows:
!>     Let  LWQP3 = 3*N+1,  LWCON = 3*N, and let
!>     LWORQ = { MAX( N, 1 ),  if JOBU = 'R', 'S', or 'U'
!>             { MAX( M, 1 ),  if JOBU = 'A'
!>     LWSVD = MAX( 5*N, 1 )
!>     LWLQF = MAX( N/2, 1 ), LWSVD2 = MAX( 5*(N/2), 1 ), LWORLQ = MAX( N, 1 ),
!>     LWQRF = MAX( N/2, 1 ), LWORQ2 = MAX( N, 1 )
!>     Then the minimal value of LWORK is:
!>     = MAX( N + LWQP3, LWSVD )        if only the singular values are needed;
!>     = MAX( N + LWQP3, LWCON, LWSVD ) if only the singular values are needed,
!>                              and a scaled condition estimate requested;
!>
!>     = N + MAX( LWQP3, LWSVD, LWORQ ) if the singular values and the left
!>                               singular vectors are requested;
!>     = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) if the singular values and the left
!>                               singular vectors are requested, and also
!>                               a scaled condition estimate requested;
!>
!>     = N + MAX( LWQP3, LWSVD )        if the singular values and the right
!>                               singular vectors are requested;
!>     = N + MAX( LWQP3, LWCON, LWSVD ) if the singular values and the right
!>                               singular vectors are requested, and also
!>                               a scaled condition etimate requested;
!>
!>     = N + MAX( LWQP3, LWSVD, LWORQ ) if the full SVD is requested with JOBV = 'R';
!>                               independent of JOBR;
!>     = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) if the full SVD is requested,
!>                               JOBV = 'R' and, also a scaled condition
!>                               estimate requested; independent of JOBR;
!>     = MAX( N + MAX( LWQP3, LWSVD, LWORQ ),
!>    N + MAX( LWQP3, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ) ) if the
!>                    full SVD is requested with JOBV = 'A' or 'V', and
!>                    JOBR ='N'
!>     = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ),
!>    N + MAX( LWQP3, LWCON, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ ) )
!>                    if the full SVD is requested with JOBV = 'A' or 'V', and
!>                    JOBR ='N', and also a scaled condition number estimate
!>                    requested.
!>     = MAX( N + MAX( LWQP3, LWSVD, LWORQ ),
!>    N + MAX( LWQP3, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) ) if the
!>                    full SVD is requested with JOBV = 'A', 'V', and JOBR ='T'
!>     = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ),
!>    N + MAX( LWQP3, LWCON, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) )
!>                    if the full SVD is requested with JOBV = 'A' or 'V', and
!>                    JOBR ='T', and also a scaled condition number estimate
!>                    requested.
!>     Finally, LWORK must be at least two: LWORK = MAX( 2, LWORK ).
!>
!>     If LWORK = -1, then a workspace query is assumed; the routine
!>     only calculates and returns the optimal and minimal sizes
!>     for the WORK, IWORK, and RWORK arrays, and no error
!>     message related to LWORK is issued by XERBLA.
!>
!>   RWORK: REAL array, dimension (max(1, LRWORK)).
!>     On exit,
!>     1. If JOBA = 'E', RWORK(1) contains an estimate of the condition
!>     number of column scaled A. If A = C * D where D is diagonal and C
!>     has unit columns in the Euclidean norm, then, assuming full column rank,
!>     N^(-1/4) * RWORK(1) <= ||pinv(C)||_2 <= N^(1/4) * RWORK(1).
!>     Otherwise, RWORK(1) = -1.
!>     2. RWORK(2) contains the number of singular values computed as
!>     exact zeros in SGESVD applied to the upper triangular or trapezoidal
!>     R (from the initial QR factorization). In case of early exit (no call to
!>     SGESVD, such as in the case of zero matrix) RWORK(2) = -1.
!>
!>     If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
!>     RWORK(1) returns the minimal LRWORK.
!>
!>   LRWORK: INTEGER.
!>     The dimension of the array RWORK.
!>     If JOBP ='P', then LRWORK >= MAX(2, M).
!>     Otherwise, LRWORK >= 2
!>
!>     If LRWORK = -1, then a workspace query is assumed; the routine
!>     only calculates and returns the optimal and minimal sizes
!>     for the WORK, IWORK, and RWORK arrays, and no error
!>     message related to LWORK is issued by XERBLA.
!>
!>   INFO: INTEGER.
!>     = 0:  successful exit.
!>     < 0:  if INFO = -i, the i-th argument had an illegal value.
!>     > 0:  if SBDSQR did not converge, INFO specifies how many superdiagonals
!>     of an intermediate bidiagonal form B (computed in SGESVD) did not
!>     converge to zero.
!>



Further Details:




!>
!>   1. The data movement (matrix transpose) is coded using simple nested
!>   DO-loops because BLAS and LAPACK do not provide corresponding subroutines.
!>   Those DO-loops are easily identified in this source code - by the CONTINUE
!>   statements labeled with 11**. In an optimized version of this code, the
!>   nested DO loops should be replaced with calls to an optimized subroutine.
!>   2. This code scales A by 1/SQRT(M) if the largest ABS(A(i,j)) could cause
!>   column norm overflow. This is the minial precaution and it is left to the
!>   SVD routine (CGESVD) to do its own preemptive scaling if potential over-
!>   or underflows are detected. To avoid repeated scanning of the array A,
!>   an optimal implementation would do all necessary scaling before calling
!>   CGESVD and the scaling in CGESVD can be switched off.
!>   3. Other comments related to code optimization are given in comments in the
!>   code, enclosed in [[double brackets]].
!>
