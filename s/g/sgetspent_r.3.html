SHADOW(3) Llamadas a biblioteca SHADOW(3)

NOMBRE

shadow, getspnam - rutinas del archivo de contraseñas cifradas

SINTAXIS

#include <shadow.h>

struct spwd *getspent();

struct spwd *getspnam(char *name);

void setspent();

void endspent();

struct spwd *fgetspent(FILE *fp);

struct spwd *sgetspent(char *cp);

int putspent(struct spwd *p, FILE *fp);

int lckpwdf();

int ulckpwdf();

DESCRIPCIÓN

shadow manipula el contenido del archivo de contraseñas cifradas, /etc/shadow. La estructura en el archivo #include es:

struct spwd {
      char		*sp_namp; /* nombre de inicio de sesión del usuario */
      char		*sp_pwdp; /* contraseña cifrada */
      long int		sp_lstchg; /* último cambio de contraseña */
      long int		sp_min; /* días hasta que se permite el cambio. */
      long int		sp_max; /* días antes de que se requiera el cambio */
      long int		sp_warn; /* días de advertencia de expiración */
      long int		sp_inact; /* días antes de que la cuenta esté inactiva */
      long int		sp_expire; /* fecha de expiración de la cuenta */
      unsigned long int	sp_flag; /* reservado para uso futuro */
}

Los significados de cada campo son:

•sp_namp - puntero al nombre de usuario terminado en nulo
•sp_pwdp - puntero a la contraseña terminada en nulo
•sp_lstchg - días desde el 1 de enero de 1970 en que se cambió la contraseña por última vez
•sp_min - días antes de los cuales no se puede cambiar la contraseña
•sp_max - días después de los cuales se debe cambiar la contraseña
•sp_warn - días antes de que expire la contraseña en los que se advierte al usuario de la próxima expiración
•sp_inact - días después de que expira la contraseña en los que la cuenta se considera inactiva y deshabilitada
•sp_expire - días desde el 1 de enero de 1970 en que se deshabilitará la cuenta
•sp_flag - reservado para uso futuro

DESCRIPCIÓN

getspent, getspname, fgetspent y sgetspent devuelven un puntero a una struct spwd. getspent devuelve la siguiente entrada del archivo, y fgetspent devuelve la siguiente entrada del flujo dado, que se supone que es un archivo del formato correcto. sgetspent devuelve un puntero a una struct spwd utilizando la cadena proporcionada como entrada. getspnam busca desde la posición actual en el archivo una entrada que coincida con name.

setspent y endspent pueden usarse para comenzar y finalizar, respectivamente, el acceso al archivo de contraseñas cifradas.

Las rutinas lckpwdf y ulckpwdf deben usarse para asegurar el acceso exclusivo al archivo /etc/shadow. lckpwdf intenta adquirir un bloqueo usando pw_lock hasta por 15 segundos. Continúa intentando adquirir un segundo bloqueo usando spw_lock durante el resto de los 15 segundos iniciales. Si alguno de los intentos falla después de un total de 15 segundos, lckpwdf devuelve -1. Cuando se adquieren ambos bloqueos, se devuelve 0.

DIAGNÓSTICOS

Las rutinas devuelven NULL si no hay más entradas disponibles o si ocurre un error durante el procesamiento. Las rutinas que tienen int como valor de retorno devuelven 0 para éxito y -1 para fallo.

ADVERTENCIAS

Estas rutinas solo pueden ser utilizadas por el superusuario, ya que el acceso al archivo de contraseñas cifradas está restringido.
