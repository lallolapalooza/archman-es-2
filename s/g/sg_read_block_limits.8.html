NOMBRE

sg_read_block_limits - envía el comando SCSI READ BLOCK LIMITS

SINOPSIS

sg_read_block_limits [--ayuda] [--hex] [--mloi] [--raw] [--solo-lectura] [--verbose] [--version] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI READ BLOCK LIMITS al DISPOSITIVO y muestra la respuesta. Este comando está definido para cintas (unidades) y su descripción se encuentra en los documentos SSC en https://www.t10.org .

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-h, --ayuda
muestra el mensaje de uso y luego sale.
-H, --hex
muestra la respuesta en hexadecimal (en lugar de decodificarla).
-m, --mloi
establece el bit MLOI en el comando READ BLOCK LIMITS y si eso tiene éxito, muestra el valor del Identificador de Objeto Lógico Máximo (MLOI). El bit MLOI se introdujo en el borrador ssc4r02.pdf.
-r, --raw
muestra la respuesta en binario a la salida estándar.
-R, --solo-lectura
abre el DISPOSITIVO en modo de solo lectura. El valor predeterminado es abrirlo en modo de lectura y escritura.
-v, --verbose
aumenta el nivel de verbosidad (es decir, salida de depuración).
-V, --version
imprime la cadena de versión y luego sale.

ESTADO DE SALIDA

El estado de salida de sg_read_block_limits es 0 cuando tiene éxito. De lo contrario, consulte la página del manual de sg3_utils(8).

EJEMPLOS

Normalmente está bien no usar ninguna opción. Aquí hay una invocación (en la primera línea después del prompt del comando "#") seguida de una salida típica:


# sg_read_block_limits /dev/st0
Resultados de Read Block Limits:
Tamaño mínimo de bloque: 1 byte(s)
Tamaño máximo de bloque: 16777215 byte(s), 16383 KB, 15 MB
Granularidad: 0
