SGEMQRT

Propósito:

!>
!> SGEMQRT sobrescribe la matriz general real M por N, C, con
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q C            C Q
!> TRANS = 'T':   Q**T C            C Q**T
!>
!> donde Q es una matriz ortogonal real definida como el producto de K
!> reflectores elementales:
!>
!>       Q = H(1) H(2) . . . H(K) = I - V T V**T
!>
!> generada usando la representación compacta WY tal como la devuelve SGEQRT.
!>
!> Q es de orden M si SIDE = 'L' y de orden N si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**T desde la Izquierda;
!>          = 'R': aplicar Q o Q**T desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': Sin transposición, aplicar Q;
!>          = 'T': Transpuesta, aplicar Q**T.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

NB

!>          NB es INTEGER
!>          El tamaño del bloque utilizado para el almacenamiento de T.  K >= NB >= 1.
!>          Este debe ser el mismo valor de NB utilizado para generar T
!>          en SGEQRT.
!>

V

!>          V es un array REAL, dimensión (LDV,K)
!>          La i-ésima columna debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como devuelve
!>          SGEQRT en las primeras K columnas de su argumento de array A.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T es un array REAL, dimensión (LDT,K)
!>          Los factores triangulares superiores de los reflectores de bloque
!>          tal como devuelve SGEQRT, almacenados como una matriz NB por N.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.  LDT >= NB.
!>

C

!>          C es un array REAL, dimensión (LDC,N)
!>          A la entrada, la matriz C de M por N.
!>          A la salida, C es sobrescrita por Q C, Q**T C, C Q**T o C Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array REAL. La dimensión de WORK es
!>           N*NB si SIDE = 'L', o  M*NB si SIDE = 'R'.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
