subrutina sget37 (real, dimension( 3 ) rmax, integer, dimension( 3 ) lmax, integer, dimension( 3 ) ninfo, integer knt, integer nin)

SGET37

Propósito:

!>
!> SGET37 prueba STRSNA, una rutina para estimar los números de condición de
!> los valores propios y/o los vectores propios derechos de una matriz.
!>
!> Las matrices de prueba se leen de un archivo con el número de unidad lógica NIN.
!>

Parámetros

RMAX 
!>          RMAX es un array REAL, dimensión (3)
!>          Valor de la mayor relación de prueba.
!>          RMAX(1) = mayor relación que compara diferentes llamadas a STRSNA
!>          RMAX(2) = mayor error en los números de condición recíprocos
!>                    tomando en cuenta su condicionamiento
!>          RMAX(3) = mayor error en los números de condición recíprocos
!>                    sin tomar en cuenta su condicionamiento (puede ser mayor que RMAX(2))
!>

LMAX

!>          LMAX es un array INTEGER, dimensión (3)
!>          LMAX(i) es el número de ejemplo donde se logra la mayor relación de prueba
!>          RMAX(i). También:
!>          Si SGEHRD devuelve INFO no nulo en el ejemplo i, LMAX(1)=i
!>          Si SHSEQR devuelve INFO no nulo en el ejemplo i, LMAX(2)=i
!>          Si STRSNA devuelve INFO no nulo en el ejemplo i, LMAX(3)=i
!>

NINFO

!>          NINFO es un array INTEGER, dimensión (3)
!>          NINFO(1) = No. de veces que SGEHRD devolvió INFO no nulo
!>          NINFO(2) = No. de veces que SHSEQR devolvió INFO no nulo
!>          NINFO(3) = No. de veces que STRSNA devolvió INFO no nulo
!>

KNT

!>          KNT es INTEGER
!>          Número total de ejemplos probados.
!>

NIN

!>          NIN es INTEGER
!>          Número de unidad lógica de entrada
!>
