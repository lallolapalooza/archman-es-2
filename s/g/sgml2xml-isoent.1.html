NOMBRE

sgml2xml-isoent - Convierte SGML a XML con soporte para entidades ISO

SINOPSIS


sgml2xml-isoent
[documento-sgml]

DESCRIPCIÓN

sgml2xml-isoent convierte un documento SGML a XML, con soporte para las entidades ISO. Esto se hace utilizando sgml2xml(1) del paquete SP (o osx(1) del paquete OpenSP), y la declaración para la versión XML de las entidades ISO se añade a la salida. Esto significa que la salida de esta conversión debería funcionar tal cual con cualquier herramienta XML.

Este programa se utiliza a menudo para procesar documentos SGML DocBook con herramientas basadas en XML. En particular, db2x_xsltproc(1) llama a este programa como parte de su opción --sgml. Por otro lado, probablemente no sea útil para migrar un archivo de texto SGML fuente a XML, ya que la conversión altera el formato original.

Dado que la versión XML de las entidades ISO se referencia directamente, no a través de un DTD, esta herramienta también funciona con tipos de documento distintos de DocBook.

NOTAS

Las entidades ISO se referencian utilizando los identificadores públicos ISO 8879:1986//ENTITIES//...//EN//XML. Los catálogos utilizados al analizar el documento convertido deben resolver estas entidades a la ubicación apropiada (en el sistema de archivos local). Si las entidades no se resuelven en el catálogo, entonces la opción de último recurso es obtener los archivos de entidad del sitio web de http://www.docbook.org/.
