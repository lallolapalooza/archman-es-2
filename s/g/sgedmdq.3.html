SGEDMDQ calcula la Descomposición de Modos Dinámicos (DMD) para un par de matrices de instantáneas de datos.

Propósito:

!>    SGEDMDQ calcula la Descomposición de Modos Dinámicos (DMD) para
!>    un par de matrices de instantáneas de datos, utilizando una compresión
!>    basada en factorización QR de los datos. Para las matrices de entrada
!>    X e Y tales que Y = A*X con una matriz A inaccesible, SGEDMDQ calcula
!>    un cierto número de pares de Ritz de A utilizando la extracción estándar
!>    de Rayleigh-Ritz de un subespacio de range(X) que se determina utilizando
!>    los vectores singulares izquierdos principales de X. Opcionalmente, SGEDMDQ
!>    devuelve los residuos de los pares de Ritz calculados, la información
!>    necesaria para un refinamiento de los vectores de Ritz, o los
!>    autovalores del DMD Exacto.
!>    Para más detalles, véanse las referencias a continuación. Para más
!>    detalles de la implementación véase [3].
!>

Referencias:

!>    [1] P. Schmid: Dynamic mode decomposition of numerical
!>        and experimental data,
!>        Journal of Fluid Mechanics 656, 28-5, 2010.
!>    [2] Z. Drmac, I. Mezic, R. Mohr: Data driven modal
!>        decompositions: analysis and enhancements,
!>        SIAM J. on Sci. Comp. 40 (4), A2253-A2285, 2018.
!>    [3] Z. Drmac: A LAPACK implementation of the Dynamic
!>        Mode Decomposition I. Technical report. AIMDyn Inc.
!>        and LAPACK Working Note 298.
!>    [4] J. Tu, C. W. Rowley, D. M. Luchtenburg, S. L.
!>        Brunton, N. Kutz: On Dynamic Mode Decomposition:
!>        Theory and Applications, Journal of Computational
!>        Dynamics 1(2), 391 -421, 2014.
!>

Parámetros

JOBS 
!>    JOBS (entrada) CHARACTER*1
!>    Determina si las instantáneas de datos iniciales se escalan
!>    por una matriz diagonal. Las instantáneas de datos son las columnas
!>    de F. Las N-1 columnas principales de F se denominan X y las
!>    N-1 columnas posteriores se denominan Y.
!>    'S' :: Las matrices de instantáneas de datos X e Y se multiplican
!>           con una matriz diagonal D de modo que X*D tenga columnas
!>           no nulas unitarias (en la norma 2 Euclidiana).
!>    'C' :: Las instantáneas se escalan como en la opción 'S'.
!>           Si se encuentra que una i-ésima columna de X es un vector
!>           cero y la i-ésima columna correspondiente de Y es no nula,
!>           entonces la i-ésima columna de Y se establece a cero y se
!>           genera una bandera de advertencia.
!>    'Y' :: Las matrices de instantáneas de datos X e Y se multiplican
!>           por una matriz diagonal D de modo que Y*D tenga columnas
!>           no nulas unitarias (en la norma 2 Euclidiana).
!>    'N' :: No hay escalado de datos.
!>

JOBZ

!>    JOBZ (entrada) CHARACTER*1
!>    Determina si se calcularán los autovectores (modos de Koopman).
!>    'V' :: Se calcularán los autovectores (modos de Koopman)
!>           y se devolverán en la matriz Z.
!>           Véase la descripción de Z.
!>    'F' :: Se devolverán los autovectores (modos de Koopman)
!>           en forma factorizada como el producto Z*V, donde Z
!>           es ortonormal y V contiene los autovectores
!>           del cociente de Rayleigh correspondiente.
!>           Véanse las descripciones de F, V, Z.
!>    'Q' :: Se devolverán los autovectores (modos de Koopman)
!>           en forma factorizada como el producto Q*Z, donde Z
!>           contiene los autovectores de la compresión del
!>           operador subyacente discretizado sobre el espacio
!>           de las instantáneas de datos. Véanse las descripciones
!>           de F, V, Z. Q proviene de la factorización QR inicial.
!>    'N' :: No se calculan los autovectores.
!>

JOBR

!>    JOBR (entrada) CHARACTER*1
!>    Determina si se calcularán los residuos.
!>    'R' :: Se calcularán los residuos de los pares de autovalores
!>           calculados y se almacenarán en el array RES.
!>           Véase la descripción de RES.
!>           Para que esta opción sea legal, JOBZ debe ser 'V'.
!>    'N' :: No se calculan los residuos.
!>

JOBQ

!> JOBQ (entrada) CHARACTER*1 !> Especifica si se debe calcular y devolver explícitamente la !> matriz ortogonal de la factorización QR. !> 'Q' :: La matriz Q de la factorización QR de la matriz !> instantánea de datos se calcula y se almacena en la !> matriz F. Consulte la descripción de F. !> 'N' :: La matriz Q no se calcula explícitamente. !>

JOBT

!>    JOBT (entrada) CHARACTER*1
!>    Especifica si se debe devolver el factor triangular superior
!>    de la factorización QR.
!>    'R' :: La matriz R de la factorización QR de la matriz
!>           instantánea de datos F se devuelve en la matriz Y.
!>           Consulte la descripción de Y y Detalles adicionales.
!>    'N' :: La matriz R no se devuelve.
!>

JOBF

!>    JOBF (entrada) CHARACTER*1
!>    Especifica si se debe almacenar la información necesaria para
!>    el postprocesamiento (por ejemplo, el cálculo de vectores de
!>    Ritz refinados).
!>    'R' :: La matriz necesaria para el refinamiento de los vectores
!>           de Ritz se calcula y se almacena en la matriz B.
!>           Consulte la descripción de B.
!>    'E' :: Se calculan los vectores propios sin escalar del DMD
!>           exacto y se devuelven en la matriz B. Consulte la
!>           descripción de B.
!>    'N' :: No se calcula información de refinamiento de vectores
!>           propios.
!>    Para ser útil a la salida, esta opción requiere JOBQ='Q'.
!>

WHTSVD

!>    WHTSVD (entrada) INTEGER, WHSTVD en { 1, 2, 3, 4 }
!>    Permite la selección del algoritmo SVD de la biblioteca
!>    LAPACK.
!>    1 :: SGESVD (el algoritmo SVD QR)
!>    2 :: SGESDD (el algoritmo Divide and Conquer; si hay suficiente
!>         espacio de trabajo disponible, esta es la opción más
!>         rápida)
!>    3 :: SGESVDQ (el SVD QR precondicionado; esta y la 4 son las
!>         opciones más precisas)
!>    4 :: SGEJSV (el SVD de Jacobi precondicionado; esta y la 3 son
!>         las opciones más precisas)
!>    Para los cuatro métodos anteriores, es posible una diferencia
!>    significativa en la precisión de los valores singulares
!>    pequeños si las instantáneas varían en norma de tal manera que X
!>    sea severamente mal condicionado. Si los valores singulares
!>    pequeños (menores que EPS*||X||) son de interés y JOBS=='N',
!>    entonces las opciones (3, 4) dan los resultados más precisos,
!>    donde la opción 4 es ligeramente mejor y con un trasfondo
!>    teórico más sólido.
!>    Si JOBS=='S', es decir, las columnas de X se normalizarán,
!>    entonces todos los métodos dan resultados casi igualmente
!>    precisos.
!>

M

!>    M (entrada) INTEGER, M >= 0
!>    La dimensión del espacio de estados (el número de filas de F)
!>

N

!>    N (entrada) INTEGER, 0 <= N <= M
!>    El número de instantáneas de datos de una sola trayectoria,
!>    tomadas en tiempos discretos equidistantes. Este es el número
!>    de columnas de F.
!>

F

!>    F (entrada/salida) REAL(KIND=WP) matriz M por N
!>    > A la entrada,
!>    las columnas de F son la secuencia de instantáneas de datos
!>    de una sola trayectoria, tomadas en tiempos discretos
!>    equidistantes. Se asume que las normas de columna de F están
!>    en el rango de los números de punto flotante normalizados.
!>    < A la salida,
!>    Si JOBQ == 'Q', la matriz F contiene la matriz ortogonal/factor
!>    de la factorización QR de la matriz instantánea de datos F.
!>    Consulte la descripción de JOBQ.
!>    Si JOBQ == 'N', las entradas en F estrictamente debajo de la
!>    diagonal principal contienen, por columnas, la información sobre
!>    los vectores de Householder, tal como los devuelve SGEQRF. La
!>    información restante para restaurar la matriz ortogonal de la
!>    factorización QR inicial se almacena en WORK(1:N). Consulte la
!>    descripción de WORK.
!>

LDF

!>    LDF (entrada) INTEGER, LDF >= M
!>    La dimensión principal de la matriz F.
!>

X

!>    X (espacio de trabajo/salida) REAL(KIND=WP) MIN(M,N) por (N-1)
!>    matriz
!>    X se utiliza como espacio de trabajo para contener
!>    representaciones de las N-1 instantáneas principales en la
!>    base ortonormal calculada en la factorización QR de F.
!>    A la salida, las K columnas principales de X contienen las K
!>    columnas principales de vectores singulares izquierdos del
!>    contenido de X descrito anteriormente. Para llevarlas al
!>    espacio de los vectores singulares izquierdos U(:,1:K) de los
!>    datos de entrada, multiplique previamente con el factor Q de
!>    la factorización QR inicial. Consulte las descripciones de F,
!>    K, V y Z.
!>

LDX

!>    LDX (entrada) INTEGER, LDX >= N
!>    La dimensión principal de la matriz X
!>

Y

!>    Y (espacio de trabajo/salida) REAL(KIND=WP) MIN(M,N) por (N-1)
!>    matriz
!>    Y se utiliza como espacio de trabajo para contener
!>    representaciones de las N-1 instantáneas finales en la
!>    base ortonormal calculada en la factorización QR de F.
!>    A la salida,
!>    Si JOBT == 'R', Y contiene el factor triangular superior
!>    MIN(M,N) por N de la factorización QR de la matriz
!>    instantánea de datos F.
!>

LDY

!>    LDY (entrada) INTEGER , LDY >= N
!>    La dimensión principal de la matriz Y
!>

NRNK

!>    NRNK (entrada) INTEGER
!>    Determina el modo de cálculo del rango numérico, es decir,
!>    cómo truncar los valores singulares pequeños de la matriz
!>    de entrada X. A la entrada, si
!>    NRNK = -1 :: el i-ésimo valor singular sigma(i) se trunca
!>                 si sigma(i) <= TOL*sigma(1)
!>                 Se recomienda esta opción.
!>    NRNK = -2 :: el i-ésimo valor singular sigma(i) se trunca
!>                 si sigma(i) <= TOL*sigma(i-1)
!>                 Esta opción se incluye para fines de I+D.
!>                 Requiere SVD de alta precisión, que puede
!>                 no ser factible.
!>    El rango numérico se puede forzar utilizando un valor
!>    positivo de NRNK de la siguiente manera:
!>    0 < NRNK <= N-1 :: se utilizarán como máximo NRNK valores
!>    singulares más grandes. Si el número de valores singulares
!>    no nulos calculados es menor que NRNK, entonces solo se
!>    utilizarán esos valores no nulos y la dimensión realmente
!>    utilizada será menor que NRNK. El número real de valores
!>    singulares no nulos se devuelve en la variable K. Consulte la
!>    descripción de K.
!>

TOL

!>    TOL (entrada) REAL(KIND=WP), 0 <= TOL < 1
!>    La tolerancia para truncar valores singulares pequeños.
!>    Consulte la descripción de NRNK.
!>

K

!>    K (salida) INTEGER, 0 <= K <= N
!>    La dimensión de la base SVD/POD para las N-1 instantáneas
!>    de datos principales (columnas de F) y el número de pares
!>    de Ritz calculados. El valor de K se determina según la
!>    regla establecida por los parámetros NRNK y TOL. Consulte las
!>    descripciones de NRNK y TOL.
!>

REIG

!>    REIG (salida) REAL(KIND=WP) (N-1) por 1 matriz
!>    Las K entradas principales (K<=N) de REIG contienen las
!>    partes reales de los valores propios calculados
!>    REIG(1:K) + sqrt(-1)*IMEIG(1:K).
!>    Consulte las descripciones de K, IMEIG, Z.
!>

IMEIG

!>    IMEIG (salida) REAL(KIND=WP) (N-1) por 1 matriz
!>    Las K entradas principales (K<N) de REIG contienen las
!>    partes imaginarias de los valores propios calculados
!>    REIG(1:K) + sqrt(-1)*IMEIG(1:K).
!>    Los valores propios se determinan de la siguiente manera:
!>    Si IMEIG(i) == 0, entonces el valor propio correspondiente es
!>    real, LAMBDA(i) = REIG(i).
!>    Si IMEIG(i)>0, entonces el par conjugado complejo de valores
!>    propios es
!>    LAMBDA(i)   = REIG(i) + sqrt(-1)*IMAG(i)
!>    LAMBDA(i+1) = REIG(i) - sqrt(-1)*IMAG(i)
!>    Es decir, los pares conjugados complejos tienen índices
!>    consecutivos (i,i+1), con la parte imaginaria positiva
!>    listada primero.
!>    Consulte las descripciones de K, REIG, Z.
!>

Z

!>    Z (espacio de trabajo/salida) REAL(KIND=WP) M por (N-1) matriz
!>    Si JOBZ =='V' entonces
!>       Z contiene vectores de Ritz reales de la siguiente manera:
!>       Si IMEIG(i)=0, entonces Z(:,i) es un vector propio del
!>       i-ésimo valor de Ritz.
!>       Si IMEIG(i) > 0 (y IMEIG(i+1) < 0) entonces
!>       [Z(:,i) Z(:,i+1)] abarcan un subespacio invariante y
!>       los valores de Ritz extraídos de este subespacio son
!>       REIG(i) + sqrt(-1)*IMEIG(i) y
!>       REIG(i) - sqrt(-1)*IMEIG(i).
!>       Los vectores propios correspondientes son
!>       Z(:,i) + sqrt(-1)*Z(:,i+1) y
!>       Z(:,i) - sqrt(-1)*Z(:,i+1), respectivamente.
!>    Si JOBZ == 'F', entonces las descripciones anteriores se aplican
!>    a las columnas de Z*V, donde las columnas de V son los vectores
!>    propios del cociente de Rayleigh K por K, y Z es ortonormal.
!>    Las columnas de V tienen una estructura similar:
!>    Si IMEIG(i) == 0 entonces Z*V(:,i) es un vector propio, y si
!>    IMEIG(i) > 0 entonces Z*V(:,i)+sqrt(-1)*Z*V(:,i+1) y
!>                      Z*V(:,i)-sqrt(-1)*Z*V(:,i+1)
!>    son los vectores propios de LAMBDA(i), LAMBDA(i+1).
!>    Consulte las descripciones de REIG, IMEIG, X y V.
!>

LDZ

!>    LDZ (entrada) INTEGER , LDZ >= M
!>    La dimensión principal de la matriz Z.
!>

RES

!>    RES (salida) REAL(KIND=WP) (N-1) por 1 matriz
!>    RES(1:K) contiene los residuos para los K pares de Ritz
!>    calculados.
!>    Si LAMBDA(i) es real, entonces
!>       RES(i) = || A * Z(:,i) - LAMBDA(i)*Z(:,i))||_2.
!>    Si [LAMBDA(i), LAMBDA(i+1)] es un par conjugado complejo
!>    entonces
!>    RES(i)=RES(i+1) = || A * Z(:,i:i+1) - Z(:,i:i+1) *B||_F
!>    donde B = [ real(LAMBDA(i)) imag(LAMBDA(i)) ]
!>              [-imag(LAMBDA(i)) real(LAMBDA(i)) ].
!>    Se cumple que
!>    RES(i)   = || A*ZC(:,i)   - LAMBDA(i)  *ZC(:,i)   ||_2
!>    RES(i+1) = || A*ZC(:,i+1) - LAMBDA(i+1)*ZC(:,i+1) ||_2
!>    donde ZC(:,i)   =  Z(:,i) + sqrt(-1)*Z(:,i+1)
!>          ZC(:,i+1) =  Z(:,i) - sqrt(-1)*Z(:,i+1)
!>    Consulte la descripción de Z.
!>

B

!>    B (salida) REAL(KIND=WP) MIN(M,N) por (N-1) matriz.
!>    SI JOBF =='R', B(1:N,1:K) contiene A*U(:,1:K), y puede
!>    utilizarse para calcular los vectores refinados; consulte
!>    más detalles en las referencias proporcionadas.
!>    Si JOBF == 'E', B(1:N,1;K) contiene
!>    A*U(:,1:K)*W(1:K,1:K), que son los vectores del DMD
!>    exacto, hasta el escalado por los valores propios inversos.
!>    En ambos casos, el contenido de B se puede llevar a la
!>    dimensión original de los datos de entrada multiplicando
!>    previamente por el factor Q de la factorización QR inicial.
!>    Aquí A denota una compresión del operador subyacente.
!>    Consulte las descripciones de F y X.
!>    Si JOBF =='N', entonces B no se referencia.
!>

LDB

!>    LDB (entrada) INTEGER, LDB >= MIN(M,N)
!>    La dimensión principal de la matriz B.
!>

V

!>    V (espacio de trabajo/salida) REAL(KIND=WP) (N-1) por (N-1) matriz
!>    A la salida, V(1:K,1:K) contiene los K vectores propios del
!>    cociente de Rayleigh. Los vectores propios de un par conjugado
!>    complejo de valores propios se devuelven en forma real tal
!>    como se explica en la descripción de Z. Los vectores de Ritz
!>    (devueltos en Z) son el producto de X y V; consulte las
!>    descripciones de X y Z.
!>
sgedmdq(3) - LAPACK - Arch Linux

NAME

sgedmdq - computes the singular value decomposition (SVD) of a real matrix X, and optionally the SVD of a matrix Y of the same dimensions.

SYNOPSIS

CALL SGEDMDQ(
     JOBX, JOBY, JOBZ, JOBQ, M, N, F, LD F,     V, LDV,
     S, LDS, WORK, LWORK, IWORK, LIWORK, INFO
     )

Function/Subroutine Documentation

JOBX (input) CHARACTER*1

>    Specifies the computation of the SVD of the input matrix F.
>    = 'N': The SVD of F is not computed.
>    = 'S': The SVD of F is computed.
>

JOBY (input) CHARACTER*1

>    Specifies the computation of the SVD of the input matrix Y.
>    = 'N': The SVD of Y is not computed.
>    = 'S': The SVD of Y is computed.
>

JOBZ (input) CHARACTER*1

>    Specifies whether to compute the left singular vectors of F.
>    = 'N': Left singular vectors are not computed.
>    = 'V': Left singular vectors are computed.
>    = 'F': Left singular vectors are computed and returned in V.
>

JOBQ (input) CHARACTER*1

>    Specifies whether to compute the right singular vectors of F.
>    = 'N': Right singular vectors are not computed.
>    = 'Q': Right singular vectors are computed.
>

M (input) INTEGER

>    The number of rows of the matrices F and Y. M >= 0.
>

N (input) INTEGER

>    The number of columns of the matrices F and Y. N >= 0.
>

F (input/output) REAL(KIND=WP) array, dimension (LDF,N)

>    On entry, the M-by-N matrix for which the SVD is desired.
>    On exit, if JOBX = 'S', F is overwritten by its left singular
>    vectors, so that on exit F(i,j) is the i-th element of the
>    j-th left singular vector.
>    If JOBZ = 'V', F contains the left singular vectors.
>    If JOBZ = 'F', F contains the left singular vectors.
>

LDF (input) INTEGER

>    The leading dimension of the array F. LDF >= max(1,M).
>

V (output) REAL(KIND=WP) array, dimension (LDV,N)

>    On exit,
>    If JOBZ = 'V', V contains the left singular vectors of F.
>    If JOBZ = 'F', V contains the left singular vectors of F.
>    If JOBQ = 'Q', V contains the right singular vectors of F.
>

LDV (input) INTEGER

>    The leading dimension of the array V. LDV >= N-1
>

S (output) REAL(KIND=WP) (N-1)-by-(N-1) array

>    The array S(1:K,1:K) is used for the matrix Rayleigh
>    quotient. This content is overwritten during
>    the eigenvalue decomposition by SGEEV.
>    See the description of K.
>

LDS (input) INTEGER

>    The leading dimension of the array S.
>

WORK (workspace/output) REAL(KIND=WP) LWORK-by-1 array

>    On exit,
>    WORK(1:MIN(M,N)) contains the scalar factors of the
>    elementary reflectors as returned by SGEQRF of the
>    M-by-N input matrix F.
>    WORK(MIN(M,N)+1:MIN(M,N)+N-1) contains the singular values of
>    the input submatrix F(1:M,1:N-1).
>    If the call to SGEDMDQ is only workspace query, then
>    WORK(1) contains the minimal workspace length and
>    WORK(2) is the optimal workspace length. Hence, the

>    See the description of LWORK.

LWORK (input) INTEGER

>    The minimal length of the  workspace vector WORK.
>    LWORK is calculated as follows:
>    Let MLWQR  = N (minimal workspace for SGEQRF[M,N])
>        MLWDMD = minimal workspace for SGEDMD (see the
>                 description of LWORK in SGEDMD) for
>                 snapshots of dimensions MIN(M,N)-by-(N-1)
>        MLWMQR = N (minimal workspace for
>                   SORMQR['L','N',M,N,N])
>        MLWGQR = N (minimal workspace for SORGQR[M,N,N])
>    Then
>    LWORK = MAX(N+MLWQR, N+MLWDMD)
>    is updated as follows:
>       if   JOBZ == 'V' or JOBZ == 'F' THEN
>            LWORK = MAX( LWORK,MIN(M,N)+N-1 +MLWMQR )
>       if   JOBQ == 'Q' THEN
>            LWORK = MAX( LWORK,MIN(M,N)+N-1+MLWGQR)
>    If on entry LWORK = -1, then a workspace query is
>    assumed and the procedure only computes the minimal
>    and the optimal workspace lengths for both WORK and
>    IWORK. See the descriptions of WORK and IWORK.
>

IWORK (workspace/output) INTEGER array, dimension (LIWORK)

>    Workspace that is required only if WHTSVD equals
>    2 , 3 or 4. (See the description of WHTSVD).
>    If on entry LWORK =-1 or LIWORK=-1, then the
>    minimal length of IWORK is computed and returned in
>    IWORK(1). See the description of LIWORK.
>

LIWORK (input) INTEGER

>    The minimal length of the workspace vector IWORK.
>    If WHTSVD == 1, then only IWORK(1) is used; LIWORK >=1
>    Let M1=MIN(M,N), N1=N-1. Then
>    If WHTSVD == 2, then LIWORK >= MAX(1,8*MIN(M1,N1))
>    If WHTSVD == 3, then LIWORK >= MAX(1,M1+N1-1)
>    If WHTSVD == 4, then LIWORK >= MAX(3,M1+3*N1)
>    If on entry LIWORK = -1, then a worskpace query is
>    assumed and the procedure only computes the minimal
>    and the optimal workspace lengths for both WORK and
>    IWORK. See the descriptions of WORK and IWORK.
