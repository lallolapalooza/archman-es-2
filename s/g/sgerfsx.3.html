subrutina sgerfsx (carácter trans, carácter equed, entero n, entero nrhs, real, dimensión( lda, * ) a, entero lda, real, dimensión( ldaf, * ) af, entero ldaf, entero, dimensión( * ) ipiv, real, dimensión( * ) r, real, dimensión( * ) c, real, dimensión( ldb, * ) b, entero ldb, real, dimensión( ldx , * ) x, entero ldx, real rcond, real, dimensión( * ) berr, entero n_err_bnds, real, dimensión( nrhs, * ) err_bnds_norm, real, dimensión( nrhs, * ) err_bnds_comp, entero nparams, real, dimensión( * ) params, real, dimensión( * ) work, entero, dimensión( * ) iwork, entero info)

SGERFSX

Propósito:

!>
!>    SGERFSX mejora la solución calculada de un sistema de ecuaciones
!>    lineales y proporciona límites de error y estimaciones de error hacia atrás
!>    para la solución. Además del límite de error normwise, el código
!>    proporciona el límite de error componente a componente máximo si es posible. Ver
!>    los comentarios para ERR_BNDS_NORM y ERR_BNDS_COMP para detalles de los
!>    límites de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido equilibrado
!>    antes de llamar a esta rutina, como se describe en los argumentos EQUED, R
!>    y C a continuación. En este caso, la solución y los límites de error devueltos
!>    son para el sistema original no equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en la matriz PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados son aceptables, los usuarios
!>     pueden pasar NPARAMS = 0, lo que evita que el código fuente acceda
!>     al argumento PARAMS.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y los límites de error correctamente.
!>       = 'N':  Sin equilibrado
!>       = 'R':  Equilibrado de filas, es decir, A ha sido premultiplicada por
!>               diag(R).
!>       = 'C':  Equilibrado de columnas, es decir, A ha sido postmultiplicada
!>               por diag(C).
!>       = 'B':  Equilibrado tanto de filas como de columnas, es decir, A ha sido
!>               reemplazada por diag(R) * A * diag(C).
!>               El lado derecho B ha sido modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es REAL array, dimensión (LDA,N)
!>     La matriz original N por N, A.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es REAL array, dimensión (LDAF,N)
!>     Los factores L y U de la factorización A = P*L*U
!>     calculados por SGETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es INTEGER array, dimensión (N)
!>     Los índices de pivote de SGETRF; para 1<=i<=N, la fila i de la
!>     matriz fue intercambiada con la fila IPIV(i).
!>

R

!>          R es REAL array, dimensión (N)
!>     Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A es
!>     multiplicada a la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede.
!>     Si se accede a R, cada elemento de R debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. El escalado por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado sea subdesbordamiento o desbordamiento. Los errores de redondeo durante el escalado
!>     conducen a un refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

C

!>          C es REAL array, dimensión (N)
!>     Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A es
!>     multiplicada a la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede.
!>     Si se accede a C, cada elemento de C debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. El escalado por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado sea subdesbordamiento o desbordamiento. Los errores de redondeo durante el escalado
!>     conducen a un refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es REAL array, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es REAL array, dimensión (LDX,NRHS)
!>     En la entrada, la matriz solución X, calculada por SGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Condición escalada recíproca. Esta es una estimación de la
!>     condición recíproca de Skeel de la matriz A después de
!>     el equilibrado (si se realizó). Si es menor que la precisión de la máquina
!>     (en particular, si es cero), la matriz es singular
!>     para la precisión de trabajo. Tenga en cuenta que el error aún puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal condicionada.
!>

BERR

!>          BERR es REAL array, dimensión (NRHS)
!>     Error relativo componente a componente hacia atrás. Este es el
!>     error relativo componente a componente de cada vector solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     hace que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada lado derecho
!>     y cada tipo (normwise o componente a componente). Ver ERR_BNDS_NORM y
!>     ERR_BNDS_COMP a continuación.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es REAL array, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define como sigue:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     La matriz se indexa por el tipo de err

NAME

sgerfsx - sgerfsx computes the error bounds for the solution of a system of linear equations `A*X = B` for a general system.

SYNOPSIS

SUBROUTINE SGERFSX(
     MATRIX_LAYOUT, TRANSPOSE, N, NRHS, RA, LDA, SA,
     LSA, SB, LSB, X, LDX, BERR, N_ERR_BNDS,
     ERR_BNDS_NORM, ERR_BNDS_COMP, NPARAMS, PARAMS,
     WORK, IWORK, INFO
)
 INTEGER :: MATRIX_LAYOUT
 CHARACTER :: TRANSPOSE
 INTEGER :: N, NRHS, LDA, LSA, LSB, LDX, N_ERR_BNDS, NPARAMS, INFO
 REAL, DIMENSION( LDA, * ) :: RA
 REAL, DIMENSION( LSA, * ) :: SA
 REAL, DIMENSION( LSB, * ) :: SB
 REAL, DIMENSION( LDX, * ) :: X
 REAL, DIMENSION( * ) :: BERR
 REAL, DIMENSION( *, * ) :: ERR_BNDS_NORM, ERR_BNDS_COMP
 REAL, DIMENSION( * ) :: PARAMS
 REAL, DIMENSION( * ) :: WORK
 INTEGER, DIMENSION( * ) :: IWORK

Function/Subroutine Documentation

SGERFSX computes the error bounds for the solution of a system of linear equations A*X = B for a general system.

It is assumed that the input matrix RA is factored by a preliminary call to SGETRF.

Arguments

MATRIX_LAYOUT

    MATRIX_LAYOUT is INTEGER
    Specifies the layout of the matrices RA, SA, SB, X and the arrays
    ERR_BNDS_NORM, ERR_BNDS_COMP.
    = 0: Row-major arrays
    = 1: Column-major arrays

TRANSPOSE

    TRANSPOSE is CHARACTER*1
    Specifies the form of the system of equations:
    = 'N':  A * X = B     (No transpose)
    = 'T':  A**T * X = B  (Transpose)
    = 'C':  A**H * X = B  (Conjugate transpose)

N

    N is INTEGER
    The number of linear equations, i.e., the dimension of the matrix A.
    N >= 0.

NRHS

    NRHS is INTEGER
    The number of right hand sides, i.e., the number of vectors B.
    NRHS >= 0.

RA

    RA is REAL array, dimension (LDA, k)
    The factors L and U from the factorization of A or A**T or A**H.
    k is N if MATRIX_LAYOUT = 0 (Row-major) and k is N if MATRIX_LAYOUT = 1 (Column-major).

LDA

    LDA is INTEGER
    The leading dimension of the array RA.
    If MATRIX_LAYOUT = 0 (Row-major), LDA >= max(1, N).
    If MATRIX_LAYOUT = 1 (Column-major), LDA >= max(1, N).

SA

    SA is REAL array, dimension (LSA, k)
    The inverse of the matrix A or A**T or A**H.
    k is N if MATRIX_LAYOUT = 0 (Row-major) and k is N if MATRIX_LAYOUT = 1 (Column-major).

LSA

    LSA is INTEGER
    The leading dimension of the array SA.
    If MATRIX_LAYOUT = 0 (Row-major), LSA >= max(1, N).
    If MATRIX_LAYOUT = 1 (Column-major), LSA >= max(1, N).

SB

    SB is REAL array, dimension (LSB, k)
    The inverse of the matrix A or A**T or A**H.
    k is N if MATRIX_LAYOUT = 0 (Row-major) and k is N if MATRIX_LAYOUT = 1 (Column-major).

LSB

    LSB is INTEGER
    The leading dimension of the array SB.
    If MATRIX_LAYOUT = 0 (Row-major), LSB >= max(1, N).
    If MATRIX_LAYOUT = 1 (Column-major), LSB >= max(1, N).

X

    X is REAL array, dimension (LDX, k)
    The solution vectors for the system of equations.
    k is NRHS if MATRIX_LAYOUT = 0 (Row-major) and k is NRHS if MATRIX_LAYOUT = 1 (Column-major).

LDX

    LDX is INTEGER
    The leading dimension of the array X.
    If MATRIX_LAYOUT = 0 (Row-major), LDX >= max(1, NRHS).
    If MATRIX_LAYOUT = 1 (Column-major), LDX >= max(1, N).

BERR

    BERR is REAL array, dimension (NRHS)
    The componentwise relative backward error of the solution X for each
    right-hand side B. If PARAMS(3) = 0, then BERR is not accessed.

N_ERR_BNDS

    N_ERR_BNDS is INTEGER
    The number of error bounds and condition numbers computed for each
    right-hand side.
    If MATRIX_LAYOUT = 0 (Row-major), N_ERR_BNDS = min(3, I).
    If MATRIX_LAYOUT = 1 (Column-major), N_ERR_BNDS = min(3, I).
    I is the number of error bounds and condition numbers computed.

ERR_BNDS_NORM

    ERR_BNDS_NORM is REAL array, dimension (NRHS, N_ERR_BNDS)
    The array contains information about the normwise relative error of
    the solution corresponding to each right hand side.
    The first index in ERR_BNDS_NORM(i,:) corresponds to the ith right-hand side.
    The second index in ERR_BNDS_NORM(:,err) contains the following three fields:
    err = 1  boolean. Trust the answer if the reciprocal condition number
             is less than the threshold sqrt(n) * slamch('Epsilon').
    err = 2  error bound: The estimated forward error, almost certainly within
             a factor of 10 of the true error so long as the next entry is
             greater than the threshold sqrt(n) * slamch('Epsilon'). This
             error bound should only be trusted if the previous boolean is true.
    err = 3  Reciprocal condition number: Estimated normwise reciprocal
             condition number. Compared with the threshold sqrt(n) *
             slamch('Epsilon') to determine if the error estimate is
             trustworthy. These reciprocal condition numbers are
             1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately
             scaled matrix Z.
             Let Z = S*A, where S scales each row by a power of the radix so
             all absolute row sums of Z are approximately 1.
    See Lapack Working Note 165 for further details and extra cautions.

ERR_BNDS_COMP

    ERR_BNDS_COMP is REAL array, dimension (NRHS, N_ERR_BNDS)
    The array contains information about the componentwise relative error
    of the solution corresponding to each right hand side.
    The first index in ERR_BNDS_COMP(i,:) corresponds to the ith right-hand side.
    The second index in ERR_BNDS_COMP(:,err) contains the following three fields:
    err = 1  boolean. Trust the answer if the reciprocal condition number
             is less than the threshold sqrt(n) * slamch('Epsilon').
    err = 2  error bound: The estimated forward error, almost certainly within
             a factor of 10 of the true error so long as the next entry is
             greater than the threshold sqrt(n) * slamch('Epsilon'). This
             error bound should only be trusted if the previous boolean is true.
    err = 3  Reciprocal condition number: Estimated componentwise reciprocal
             condition number. Compared with the threshold sqrt(n) *
             slamch('Epsilon') to determine if the error estimate is
             trustworthy. These reciprocal condition numbers are
             1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately
             scaled matrix Z.
             Let Z = S*(A*diag(x)), where x is the solution for the current
             right-hand side and S scales each row of A*diag(x) by a power of
             the radix so all absolute row sums of Z are approximately 1.
    See Lapack Working Note 165 for further details and extra cautions.

NPARAMS

    NPARAMS is INTEGER
    Specifies the number of parameters set in PARAMS. If <= 0, the
    PARAMS array is never referenced and default values are used.

PARAMS

    PARAMS is REAL array, dimension NPARAMS
    Specifies algorithm parameters. If an entry is < 0.0, then that entry
    will be filled with default value used for that parameter. Only
    positions up to NPARAMS are accessed; defaults are used for
    higher-numbered parameters.
    PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
         refinement or not.
         Default: 1.0
         = 0.0:  No refinement is performed, and no error bounds are
                 computed.
         = 1.0:  Use the double-precision refinement algorithm,
                 possibly with doubled-single computations if the
                 compilation environment does not support DOUBLE
                 PRECISION.
           (other values are reserved for future use)
    PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
         computations allowed for refinement.
         Default: 10
         Aggressive: Set to 100 to permit convergence using approximate
                     factorizations or factorizations other than LU. If
                     the factorization uses a technique other than
                     Gaussian elimination, the guarantees in
                     err_bnds_norm and err_bnds_comp may no longer be
                     trustworthy.
    PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
         will attempt to find a solution with small componentwise
         relative error in the double-precision algorithm. Positive
         is true, 0.0 is false.
         Default: 1.0 (attempt componentwise convergence)

WORK

    WORK is REAL array, dimension (4*N)

IWORK

    IWORK is INTEGER array, dimension (N)

INFO

    INFO is INTEGER
    = 0:  Successful exit. The solution to every right-hand side is
          guaranteed.
    < 0:  If INFO = -i, the i-th argument had an illegal value
    > 0 and <= N:  U(INFO,INFO) is exactly zero. The factorization
          has been completed, but the factor U is exactly singular, so
          the solution and error bounds could not be computed. RCOND = 0
          is returned.
    = N+J: The solution corresponding to the Jth right-hand side is
          not guaranteed. The solutions corresponding to other right-
          hand sides K with K > J may not be guaranteed as well, but
          only the first such right-hand side is reported. If a small
          componentwise error is not requested (PARAMS(3) = 0.0) then
          the Jth right-hand side is the first with a normwise error
          bound that is not guaranteed (the smallest J such
          that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
          the Jth right-hand side is the first with either a normwise or
          componentwise error bound that is not guaranteed (the smallest
          J such that either ERR_BNDS_NORM(J,1) = 0.0 or
          ERR_BNDS_COMP(J,1) = 0.0). See the definition of
          ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
          about all of the right-hand sides check ERR_BNDS_NORM or
          ERR_BNDS_COMP.
