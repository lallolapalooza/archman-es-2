DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subrutina sgges (character jobvsl, character jobvsr, character sort, external selctg, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, integer sdim, real, dimension( * ) alphar, real, dimension( * ) alphai, real, dimension( * ) beta, real, dimension( ldvsl, * ) vsl, integer ldvsl, real, dimension( ldvsr, * ) vsr, integer ldvsr, real, dimension( * ) work, integer lwork, logical, dimension( * ) bwork, integer info)

SGGES calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> SGGES calcula para un par de matrices reales no simétricas de N por N (A,B),
!> los valores propios generalizados, la forma de Schur generalizada (S,T),
!> opcionalmente, las matrices izquierda y/o derecha de vectores de Schur (VSL y
!> VSR). Esto da la factorización de Schur generalizada
!>
!>          (A,B) = ( (VSL)*S*(VSR)**T, (VSL)*T*(VSR)**T )
!>
!> Opcionalmente, también ordena los valores propios para que un clúster seleccionado
!> de valores propios aparezca en los bloques diagonales principales de la matriz superior
!> cuasi-triangular S y la matriz triangular superior T. Las columnas principales de VSL y VSR
!> forman entonces una base ortonormal para los correspondientes subespacios propios
!> izquierdos y derechos (subespacios de deflexión).
!>
!> (Si solo se necesitan los valores propios generalizados, utilice el controlador
!> SGGEV en su lugar, que es más rápido).
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una razón alpha/beta = w, tal que A - w*B es singular. Normalmente se
!> representa como el par (alpha,beta), ya que hay una interpretación razonable
!> para beta=0 o ambos siendo cero.
!>
!> Un par de matrices (S,T) está en forma de Schur generalizada real si T es
!> triangular superior con diagonal no negativa y S es de bloques triangular superior
!> con bloques de 1x1 y 2x2. Los bloques de 1x1 corresponden a valores propios
!> generalizados reales, mientras que los bloques de 2x2 de S serán
!> haciendo que los elementos correspondientes de T tengan la forma:
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> y el par de bloques correspondientes de 2x2 en S y T tendrán un par
!> de valores propios generalizados complejos conjugados.
!>
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur izquierdos;
!>          = 'V':  calcular los vectores de Schur izquierdos.
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur derechos;
!>          = 'V':  calcular los vectores de Schur derechos.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se ordenan o no los valores propios en la
!>          diagonal de la forma de Schur generalizada.
!>          = 'N':  los valores propios no están ordenados;
!>          = 'S':  los valores propios están ordenados (ver SELCTG);
!>

SELCTG

!>          SELCTG es una FUNCIÓN LOGICAL de tres argumentos REALES
!>          SELCTG debe declararse EXTERNA en la subrutina llamante.
!>          Si SORT = 'N', SELCTG no se referencia.
!>          Si SORT = 'S', SELCTG se usa para seleccionar valores propios a ordenar
!>          en la parte superior izquierda de la forma de Schur.
!>          Un valor propio (ALPHAR(j)+ALPHAI(j))/BETA(j) se selecciona si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) es verdadero; es decir, si uno
!>          de un par de valores propios complejos conjugados es seleccionado,
!>          entonces ambos valores propios complejos son seleccionados.
!>
!>          Tenga en cuenta que en el caso mal condicionado, un valor propio
!>          complejo seleccionado puede ya no satisfacer SELCTG(ALPHAR(j),ALPHAI(j),
!>          BETA(j)) = .TRUE. después de ordenar. INFO debe establecerse en N+2
!>          en este caso.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR. N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA, N)
!>          En la entrada, la primera del par de matrices.
!>          En la salida, A ha sido sobrescrita por su forma de Schur
!>          generalizada S.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. LDA >= max(1,N).
!>

B

!>          B es un array REAL, de dimensión (LDB, N)
!>          En la entrada, la segunda del par de matrices.
!>          En la salida, B ha sido sobrescrita por su forma de Schur
!>          generalizada T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de ordenar)
!>          para los que SELCTG es verdadero. (Los pares complejos conjugados para los que
!>          SELCTG es verdadero para cualquiera de los valores propios cuentan como 2).
!>

ALPHAR

!>          ALPHAR es un array REAL, de dimensión (N)
!>

ALPHAI

!>          ALPHAI es un array REAL, de dimensión (N)
!>

BETA

!>          BETA es un array REAL, de dimensión (N)
!>          En la salida, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, serán
!>          los valores propios generalizados. ALPHAR(j) + ALPHAI(j)*i,
!>          y BETA(j), j=1,...,N son las diagonales de la forma de Schur compleja
!>          (S,T) que resultaría si los bloques diagonales de 2x2
!>          de la forma de Schur real de (A,B) se redujeran aún más a
!>          forma triangular usando transformaciones unitarias complejas de 2x2.
!>          Si ALPHAI(j) es cero, entonces el j-ésimo valor propio es real; si
!>          es positivo, entonces el j-ésimo y (j+1)-ésimo valores propios son un
!>          par complejo conjugado, con ALPHAI(j+1) negativo.
!>
!>          Nota: los cocientes ALPHAR(j)/BETA(j) y ALPHAI(j)/BETA(j)
!>          pueden fácilmente sobreflo o subflo, y BETA(j) puede incluso ser cero.
!>          Por lo tanto, el usuario debe evitar calcular ingenuamente el cociente.
!>          Sin embargo, ALPHAR y ALPHAI siempre serán menores y
!>          generalmente comparables con norm(A) en magnitud, y BETA siempre
!>          menor y generalmente comparable con norm(B).
!>

VSL

!>          VSL es un array REAL, de dimensión (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contendrá los vectores de Schur izquierdos.
!>          No se referencia si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL es INTEGER
!>          La dimensión principal de la matriz VSL. LDVSL >=1, y
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR es un array REAL, de dimensión (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contendrá los vectores de Schur derechos.
!>          No se referencia si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR es INTEGER
!>          La dimensión principal de la matriz VSR. LDVSR >= 1, y
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N = 0, LWORK >= 1, de lo contrario LWORK >= max(8*N,6*N+16).
!>

NAME

sgges — computes the generalized Schur factorization of a regular pair of general rectangular matrices (A, B)

Function/Subroutine Documentation

SGGEV computes the generalized eigenvalues (&alpha;&alpha;,&beta;&beta;) and, optionally, the left and right generalized eigenvectors for a regular pair of general rectangular matrices (A, B).

The generalized eigenvalues are computed via the generalized Schur factorization.

The relationship between A and B is:

    A*Z = &beta;&beta;*X*D
    B*Z = &alpha;&alpha;*X*D

where

    D is a diagonal matrix, and X and Z are invertible matrices.
    The columns of X and Z are the generalized left and right
    eigenvectors respectively.


Let omega be the complex numbers defined as


    omega = alpha / beta


Then, if beta is non-zero,


    A*Z = omega*B*Z


The generalized eigenvalues omega are computed by the
    routine.


The eigenvalues are computed by computing the generalized
    Schur factorization of A and B:


    A = Q*S*Z**H
    B = Q*T*Z**H


where Q and Z are unitary matrices and S and T are
    upper triangular matrices. The diagonal entries of S and T are the
    generalized eigenvalues of A and B.


If `SORT' = 'S', then the
    eigenvalues are reordered such that the eigenvalues satisfying
    `SELECT' (`j`) = .TRUE. come first.


If `JOBVSL' = 'V', then the
    left eigenvectors are computed.


If `JOBVSR' = 'V', then the
    right eigenvectors are computed.


If `SORT' = 'N', then the eigenvalues
    are not reordered and in particular, they are not computed.


The eigenvalues are computed in the form
    (&alpha;r + i*&alpha;i, &beta;).


The diagonal entries of A and B are computed in
    `ALPHAR', `ALPHAI', and `BETA'.


The matrices VSL and VSR are:


    VSL: unitary matrix whose columns are the left eigenvectors
         `v_l', such that
         `v_l**H * A = omega * v_l**H * B


and


    VSR: unitary matrix whose columns are the right eigenvectors
         `v_r', such that
         `A * v_r = omega * B * v_r


If `SORT' = 'S', then the columns of
    VSL and VSR are the eigenvectors corresponding to the eigenvalues
    satisfying `SELECT' (`j`) = .TRUE.


SGGES is a generic wrapper to the
    non-generic subroutine `SHGEQZ'.




Input Parameters


JOBVSL
    

    • is CHARACTER*1

    • =‘V’: left eigenvectors `v_l' are computed.

    • =‘N’: left eigenvectors `v_l' are not computed.


JOBVSR
    

    • is CHARACTER*1

    • =‘V’: right eigenvectors `v_r' are computed.

    • =‘N’: right eigenvectors `v_r' are not computed.


SORT
    

    • is CHARACTER*1

    • =‘S’: the set of eigenvalues is reordered and
    as specified by `SELECT'.

    • =‘N’: the set of eigenvalues is not reordered.


SELECT
    

    • is LOGICAL array, dimension (N).

    • If `SORT' = 'S', then `SELECT' specifies which eigenvalues
    should be selected to form the left and right Schur bases.


A
    

    • is DOUBLE PRECISION array, dimension (LDA, N).

    • On entry, the leading `n'x`n' upper Hessenberg
    matrix `A'.


LDA
    

    • is INTEGER, dimension of the first dimension of `A'. `LDA'
    >= max(1, N).


B
    

    • is DOUBLE PRECISION array, dimension (LDB, N).

    • On entry, the leading `n'x`n' upper triangular matrix
    `B'.


LDB
    

    • is INTEGER, dimension of the first dimension of `B'. `LDB'
    >= max(1, N).


VSL
    

    • is DOUBLE PRECISION array, dimension (LDVSL, N).


LDVSL
    

    • is INTEGER, dimension of the first dimension of `VSL'.
    `LDVSL' >= 1.


• If `JOBVSL' = 'V', then on exit `VSL' contains the
    left eigenvectors `v_l'.


VSR
    

    • is DOUBLE PRECISION array, dimension (LDVSR, N).


LDVSR
    

    • is INTEGER, dimension of the first dimension of `VSR'.
    `LDVSR' >= 1.


• If `JOBVSR' = 'V', then on exit `VSR' contains the
    right eigenvectors `v_r'.


WORK
    

    • is DOUBLE PRECISION array, dimension (LWORK).


LWORK
    

    • is INTEGER, dimension of the array `WORK'. `LWORK'
    >= `max(1, 3*N)'. For good performance, `LWORK' must generally
    be larger.


• If `LWORK' = -1, then a workspace query is assumed;
    the routine only calculates the optimal size of the `WORK' array,
    returns this value as the first entry of the `WORK' array, and no
    error message related to `LWORK' is issued by `XERBLA'.


BWORK
    

    • is LOGICAL array, dimension (N).

    • Not referenced if `SORT' = 'N'.


INFO
    

    • is INTEGER


    • = 0:  successful exit


    • < 0:  if `INFO' = -i, the i-th argument had an illegal
          value.


    • = 1,...,N:
          The QZ iteration failed.  (A,B) are not in Schur
          form, but `ALPHAR'(j), `ALPHAI'(j), and `BETA'(j) should
          be correct for j=INFO+1,...,N.


    • > N:  =N+1: other than QZ iteration failed in `SHGEQZ'.
          =N+2: after reordering, roundoff changed values of
                some complex eigenvalues so that leading
                eigenvalues in the Generalized Schur form no
                longer satisfy `SELCTG'=.TRUE.  This could also
                be caused due to scaling.


          =N+3: reordering failed in `STGSEN'.
