SGEEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE

Propósito:

!>
!> SGEEVX calcula para una matriz real N por N no simétrica A, los
!> valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos.
!>
!> Opcionalmente, también calcula una transformación de balanceo para mejorar
!> el condicionamiento de los valores propios y vectores propios (ILO, IHI,
!> SCALE y ABNRM), los recíprocos de los números de condición para los valores
!> propios (RCONDE) y los recíprocos de los números de condición para los
!> vectores propios derechos (RCONDV).
!>
!> El vector propio derecho v(j) de A satisface
!>                  A * v(j) = lambda(j) * v(j)
!> donde lambda(j) es su valor propio.
!> El vector propio izquierdo u(j) de A satisface
!>               u(j)**H * A = lambda(j) * u(j)**H
!> donde u(j)**H denota la transpuesta conjugada de u(j).
!>
!> Los vectores propios calculados se normalizan para tener norma Euclidiana
!> igual a 1 y el componente real más grande.
!>
!> Balancear una matriz significa permutar las filas y columnas para hacerla
!> más cercana a ser triangular superior, y aplicar una transformación de
!> similitud diagonal D * A * D**(-1), donde D es una matriz diagonal, para
!> que sus filas y columnas estén más cerca en norma y los números de
!> condición de sus valores propios y vectores propios sean menores. Los
!> recíprocos de los números de condición calculados corresponden a la matriz
!> balanceada. Las permutaciones de filas y columnas no cambiarán los números de
!> condición (en aritmética exacta), pero el escalado diagonal sí lo hará. Para
!> más explicación sobre el balanceo, véase la sección 4.10.2 de la Guía de
!> Usuarios de LAPACK.
!>

Parámetros

BALANC 
!>          BALANC es CHARACTER*1
!>          Indica cómo la matriz de entrada debe ser escalada
!>          diagonalmente y/o permutada para mejorar el
!>          condicionamiento de sus valores propios.
!>          = 'N': No escalar ni permutar diagonalmente;
!>          = 'P': Realizar permutaciones para hacer la matriz más
!>                 cercana a ser triangular superior. No escalar
!>                 diagonalmente;
!>          = 'S': Escalar la matriz diagonalmente, es decir, reemplazar A por
!>                 D*A*D**(-1), donde D es una matriz diagonal elegida
!>                 para que las filas y columnas de A sean más iguales en
!>                 norma. No permutar;
!>          = 'B': Escalar diagonalmente y permutar A.
!>
!>          Los recíprocos de los números de condición calculados serán para la
!>          matriz después del balanceo y/o permutación. La permutación no
!>          cambia los números de condición (en aritmética exacta), pero el
!>          balanceo sí lo hace.
!>

JOBVL

!>          JOBVL es CHARACTER*1
!>          = 'N': no se calculan los vectores propios izquierdos de A;
!>          = 'V': se calculan los vectores propios izquierdos de A.
!>          Si SENSE = 'E' o 'B', JOBVL debe ser = 'V'.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N': no se calculan los vectores propios derechos de A;
!>          = 'V': se calculan los vectores propios derechos de A.
!>          Si SENSE = 'E' o 'B', JOBVR debe ser = 'V'.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué recíprocos de números de condición se calculan.
!>          = 'N': no se calcula ninguno;
!>          = 'E': se calcula solo para valores propios;
!>          = 'V': se calcula solo para vectores propios derechos;
!>          = 'B': se calcula para valores propios y vectores propios derechos.
!>
!>          Si SENSE = 'E' o 'B', también deben calcularse los vectores propios
!>          izquierdos y derechos (JOBVL = 'V' y JOBVR = 'V').
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz N por N A.
!>          En la salida, A ha sido sobrescrita. Si JOBVL = 'V' o
!>          JOBVR = 'V', A contiene la forma de Schur real de la versión
!>          balanceada de la matriz de entrada A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

WR

!>          WR es un array REAL, dimensión (N)
!>

WI

!>          WI es un array REAL, dimensión (N)
!>          WR y WI contienen las partes real e imaginaria,
!>          respectivamente, de los valores propios calculados. Los pares
!>          de valores propios conjugados complejos aparecerán consecutivamente
!>          con el valor propio que tenga la parte imaginaria positiva primero.
!>

VL

!>          VL es un array REAL, dimensión (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios izquierdos u(j) se almacenan
!>          uno tras otro en las columnas de VL, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVL = 'N', VL no se referencia.
!>          Si el j-ésimo valor propio es real, entonces u(j) = VL(:,j),
!>          la j-ésima columna de VL.
!>          Si el j-ésimo y (j+1)-ésimo valores propios forman un par
!>          conjugado complejo, entonces u(j) = VL(:,j) + i*VL(:,j+1) y
!>          u(j+1) = VL(:,j) - i*VL(:,j+1).
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array REAL, dimensión (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios derechos v(j) se almacenan
!>          uno tras otro en las columnas de VR, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVR = 'N', VR no se referencia.
!>          Si el j-ésimo valor propio es real, entonces v(j) = VR(:,j),
!>          la j-ésima columna de VR.
!>          Si el j-ésimo y (j+1)-ésimo valores propios forman un par
!>          conjugado complejo, entonces v(j) = VR(:,j) + i*VR(:,j+1) y
!>          v(j+1) = VR(:,j) - i*VR(:,j+1).
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR. LDVR >= 1; y si
!>          JOBVR = 'V', LDVR >= N.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI son valores enteros determinados cuando A fue
!>          balanceada. La A balanceada(i,j) = 0 si I > J y
!>          J = 1,...,ILO-1 o I = IHI+1,...,N.
!>

SCALE

!>          SCALE es un array REAL, dimensión (N)
!>          Detalles de las permutaciones y factores de escala aplicados
!>          al balancear A. Si P(j) es el índice de la fila y columna
!>          intercambiada con la fila y columna j, y D(j) es el factor de
!>          escala aplicado a la fila y columna j, entonces
!>          SCALE(J) = P(J),    para J = 1,...,ILO-1
!>                   = D(J),    para J = ILO,...,IHI
!>

NAME

sgeevx - Computes the eigenvalues and left and right eigenvectors of a real matrix, with optional balancing and high-accuracy condition number estimation.

SYNOPSIS

SUBROUTINE SGEEVX(
    BALANCE, JOBVL, JOBVR, SENSE, N, A, LDA,
    WR, WI, VL, VlDA, VR, VRDA,
    ILO, IHI, SCALE, ABNRM, RCONDE, RCONDV,
    WORK, LWORK, IWORK, INFO
)
CHARACTER * 1   :: BALANCE, JOBVL, JOBVR, SENSE
INTEGER         :: LDA, VLDA, VRDA, N, ILO, IHI, LWORK
REAL            :: A(LDA, *), WR(*), WI(*), VL(VLDA, *), VR(VRDA, *),
    SCALE(*), ABNRM, RCONDE(*), RCONDV(*), WORK(*)
INTEGER         :: IWORK(*), INFO

Function/Subroutine Documentation

This subroutine computes the eigenvalues and left and right eigenvectors of a real matrix A. It also computes high-accuracy estimates for the reciprocal condition numbers of the eigenvalues and right eigenvectors, with an option to balance the matrix before the eigencomputation.

Arguments

BALANCE

BALANCE is CHARACTER*1
          Specifies whether or not the matrix should be balanced before
          it is processed. See Balancing a general matrix section below.
          = 'N': No balancing is done.
          = 'P': Scaling by multiplication on the left by a diagonal
                 matrix is done.
          = 'S': Scaling by multiplication on the right by a diagonal
                 matrix is done.
          = 'B': Scaling by multiplication on the left and right by a
                 diagonal matrix is done.

JOBVL

JOBVL is CHARACTER*1
          Indicates whether to compute the left eigenvectors.
          = 'N': Do not compute the left eigenvectors.
          = 'V': Compute the left eigenvectors.

JOBVR

JOBVR is CHARACTER*1
          Indicates whether to compute the right eigenvectors.
          = 'N': Do not compute the right eigenvectors.
          = 'V': Compute the right eigenvectors.

SENSE

SENSE is CHARACTER*1
          Determines which reciprocal condition numbers are to be computed.
          = 'N': None are computed.
          = 'E': Computed for the eigenvalues only.
          = 'V': Computed for the right eigenvectors only.
          = 'B': Computed for the eigenvalues and right eigenvectors.

N

N is INTEGER
          The number of rows and columns in the matrix A. N >= 0.

A

A is REAL array, dimension (LDA, N)
          On entry, the n-by-n matrix A.
          On exit, if INFO = 0 and JOBVL = 'V' or JOBVR = 'V', A contains
          the Schur factorization of the balanced matrix A = Q * T * Q**T,
          where Q is the orthogonal matrix of left eigenvectors if JOBVL='V'
          and Q is the orthogonal matrix of right eigenvectors if JOBVR='V'.
          The Schur factorization is computed by the routine ZGEHRD and
          ZUNGHR.

LDA

LDA is INTEGER
          The leading dimension of the array A. LDA >= max(1, N).

WR

WR is REAL array, dimension (N)
          On exit, WR contains the real parts of the eigenvalues.

WI

WI is REAL array, dimension (N)
          On exit, WI contains the imaginary parts of the eigenvalues.
          Each eigenvalue w(j) = (WR(j), WI(j)) satisfies
          w(j) = WR(j) + i*WI(j).

VL

VL is REAL array, dimension (LDVL, N)
          If JOBVL = 'V', VL contains the left eigenvectors of A.
          The normalized eigenvector v(j) is stored in the j-th column of VL,
          v(j) = VL(:,j), such that VL(i,j) is the i-th component of the
          j-th eigenvector.
          If SENSE = 'B' or 'E', VL is used as workspace on exit.
          If JOBVL = 'N', VL is not used.

LDVL

LDVL is INTEGER
          The leading dimension of the array VL. LDVL >= 1. If JOBVL = 'V',
          LDVL >= max(1, N).

VR

VR is REAL array, dimension (LDVR, N)
          If JOBVR = 'V', VR contains the right eigenvectors of A.
          The normalized eigenvector v(j) is stored in the j-th column of VR,
          v(j) = VR(:,j), such that VR(i,j) is the i-th component of the
          j-th eigenvector.
          If SENSE = 'B' or 'V', VR is used as workspace on exit.
          If JOBVR = 'N', VR is not used.

LDVR

LDVR is INTEGER
          The leading dimension of the array VR. LDVR >= 1. If JOBVR = 'V',
          LDVR >= max(1, N).

ILO

ILO is INTEGER
          IHI is INTEGER
          The computed block inlinen ranges 1:ILO-1 and IHI+1:N for the
          eigenvalues are already on the diagonal.
          So, for i in 1:ILO-1 and i in IHI+1:N, the eigenvector v(i) is
          already computed.
          For i in ILO:IHI, the eigenvalues are in the rows and columns
          ILO:IHI of the matrix A.

SCALE

SCALE is REAL array, dimension (N)
          The scaling factors used in balancing the matrix. Only the entries
          from ILO to IHI are used.
          SCALE(i) = 1.0 for i < ILO or i > IHI.
          The order of the interchanges are N to IHI+1, then 1 to ILO-1.

ABNRM

ABNRM is REAL
          The one-norm of the balanced matrix (the maximum
          of the sum of absolute values of elements of any column).

RCONDE

RCONDE is REAL array, dimension (N)
          RCONDE(j) is the reciprocal condition number of the j-th
          eigenvalue.

RCONDV

RCONDV is REAL array, dimension (N)
          RCONDV(j) is the reciprocal condition number of the j-th
          right eigenvector.

WORK

WORK is REAL array, dimension (MAX(1,LWORK))
          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

LWORK is INTEGER
          The dimension of the array WORK.   If SENSE = 'N' or 'E',
          LWORK >= max(1,2*N), and if JOBVL = 'V' or JOBVR = 'V',
          LWORK >= 3*N.  If SENSE = 'V' or 'B', LWORK >= N*(N+6).
          For good performance, LWORK must generally be larger.


          If LWORK = -1, then a workspace query is assumed; the routine
          only calculates the optimal size of the WORK array, returns
          this value as the first entry of the WORK array, and no error
          message related to LWORK is issued by XERBLA.

IWORK

IWORK is INTEGER array, dimension (2*N-2)
          If SENSE = 'N' or 'E', not referenced.

INFO

INFO is INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value.
          > 0:  if INFO = i, the QR algorithm failed to compute all the
                eigenvalues, and no eigenvectors or condition numbers
                have been computed; elements 1:ILO-1 and i+1:N of WR
                and WI contain eigenvalues which have converged.
