subrutina sgeqr2p (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer info)

SGEQR2P calcula la factorización QR de una matriz rectangular general con elementos diagonales no negativos utilizando un algoritmo sin bloques.

Propósito:

!>
!> SGEQR2P calcula una factorización QR de una matriz real m por n A:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> donde:
!>
!>    Q es una matriz ortogonal m por m;
!>    R es una matriz triangular superior n por n con entradas diagonales
!>    no negativas;
!>    0 es una matriz cero (m-n) por n, si m > n.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz m por n A.
!>          En la salida, los elementos en y encima de la diagonal del
!>          array contienen la matriz trapezoidal superior R de min(m,n)
!>          por n (R es triangular superior si m >= n). Las entradas
!>          diagonales de R son no negativas; los elementos debajo de la
!>          diagonal, con el array TAU, representan la matriz ortogonal Q
!>          como un producto de reflectores elementales (ver Detalles Adicionales).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es un array REAL, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales (ver
!>          Detalles Adicionales).
!>

WORK

!>          WORK es un array REAL, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Autor

Univ. de Tennessee

Univ. de California Berkeley

Univ. de Colorado Denver

NAG Ltd.

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real, y v es un vector real con
!>  v(1:i-1) = 0 y v(i) = 1; v(i+1:m) se almacena en la salida en A(i+1:m,i),
!>  y tau en TAU(i).
!>
!> Ver Nota de Trabajo 203 de Lapack para detalles.
!>
