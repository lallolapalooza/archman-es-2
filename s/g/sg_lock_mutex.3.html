sg_lock_mutex(3)

Paquete: libstatgrab

Licencias: LGPL, GPL

sg_lock_mutex(3) sg_lock_mutex(3)

NOMBRE

sg_lock_mutex, sg_unlock_mutex - protege una API del sistema que no es segura para MT (Multithreading)

SINOPSIS

#include <statgrab.h>


sg_error sg_lock_mutex
(char const *mutex_name);


sg_error sg_unlock_mutex
(char const *mutex_name);

DESCRIPCIÓN

VALORES DE RETORNO

Ambas funciones devuelven un código de error de statgrab.

código de error: SG_ERROR_NONE
descripción: Sin error

código de error: SG_ERROR_INVALID_ARGUMENT
descripción: Nombre de mutex desconocido

código de error: SG_ERROR_MUTEX_LOCK
descripción: Error de la biblioteca de hilos, el código de error se establece con el valor entregado

código de error: SG_ERROR_MUTEX_UNLOCK
descripción: Error de la biblioteca de hilos, el código de error se establece con el valor entregado
