NOMBRE

sg_rep_zones - enviar comando SCSI REPORT ZONES, REALMS o ZONE DOMAINS

SINOPSIS

sg_rep_zones [--breve] [--dominio] [--encontrar=ZT] [--forzar] [--ayuda] [--hex] [--enhex=FN] [--json[=JO]] [--archivo-js=JFN] [--localizador=LBA] [--maxlen=LEN] [--num=NUM] [--parcial] [--raw] [--sololec=READONLY] [--reino] [--informe=OPT] [--inicio=LBA] [--estadisticas] [--verbose] [--version] [--wp] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI REPORT ZONES, REPORT REALMS o REPORT ZONE DOMAINS al DISPOSITIVO y decodifica (o simplemente muestra) los datos recibidos. Estos comandos se encuentran en el borrador del estándar ZBC-2, revisión 12 (zbc2r12.pdf). Solo el comando REPORT ZONES está definido en el estándar ZBC original (INCITS 536-2017) y es el predeterminado para esta utilidad.

Se enviará el comando REPORT ZONE DOMAINS (y se decodificará) cuando se proporcione la opción --dominio. Se enviará el comando REPORT REALMS (y se decodificará) cuando se proporcione la opción --reino.

En lugar de enviar un comando SCSI a DISPOSITIVO, si se proporciona la opción --enhex=FN, el contenido del archivo llamado FN se decodifica como hex ASCII (o binario si también se proporciona --raw) y luego se procesa como si fuera la respuesta del comando. Por defecto, se asume la respuesta del comando REPORT ZONES; si se proporciona la opción --dominio o --reino, se asume la respuesta del comando correspondiente.

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-b, --breve
aunque un disco ZBC típicamente limitará el tamaño de la respuesta al comando REPORT ZONES (por ejemplo, debido al campo "longitud de asignación"), esta salida puede ser potencialmente grande. Esta opción solo decodificará y mostrará los campos encontrados en la cabecera de respuesta más los campos del último descriptor en la respuesta actual.
-d, --dominio
enviar o decodificar el comando SCSI REPORT ZONE DOMAINS.
-F, --encontrar=ZT
donde ZT es un número de tipo de zona o una abreviatura de tipo de zona. Si ZT va precedido por '-' o '!', la comprobación de igualdad se invierte a una comprobación de desigualdad. Es decir, realiza: encontrar la primera ocurrencia que no es el tipo de zona dado.
El algoritmo utilizado por esta opción tiene en cuenta las opciones --hex, --maxlen=LEN, --num=NUM, --report=OPT y --inicio=LBA, si se proporcionan, e ignora otras opciones. Actualmente solo está implementado para el comando Report zones. El algoritmo puede llamar al comando Report zones repetidamente, con el bit PARTIAL activado y el campo LBA de inicio de zona incrementándose a medida que avanza. Esto continúa hasta que haya una coincidencia en la condición ZT, se agote --num=NUM o se agote el número de zonas.
Los números y abreviaturas de ZT se enumeran al proporcionar la opción --ayuda dos veces. Advertencia: usar '!' para invertir la condición puede no ser tan práctico ya que el shell (por ejemplo, bash) puede interpretar '!' como si tuviera un significado especial. Colocar comillas simples alrededor de ZT soluciona el problema para el shell bash (por ejemplo, --find='!c' significa encontrar la primera zona cuyo tipo no es convencional).
-f, --forzar
al decodificar la respuesta a este comando, se realizan ciertas comprobaciones de validez y si fallan, se envía un mensaje a stderr y se establece un estado de salida distinto de cero. Si se proporciona esta opción, estas comprobaciones de validez se omiten.
-h, --ayuda
mostrar el mensaje de uso y luego salir. Cuando se proporciona dos veces, se muestra información de uso adicional.
-H, --hex
mostrar la respuesta en hexadecimal en stdout. Cuando se usa una vez, toda la respuesta se muestra en hexadecimal ASCII con una dirección inicial (comenzando en 0) en cada línea. Cuando se usa dos veces, cada descriptor de zona en la respuesta se muestra por separado en hexadecimal. Cuando se usa tres veces, toda la respuesta se muestra en hexadecimal sin una dirección inicial (en cada línea).
Cuando se utiliza esta opción dos veces, puede ser útil con las opciones --breve o --encontrar=ZT para mostrar solo la cabecera y el descriptor de zona en hex que esas dos opciones mostrarían en ASCII en ausencia de la opción --hex.
El formato de salida cuando se proporciona esta opción tres veces es adecuado para una invocación posterior con la opción --enhex=FN.
-i, --enhex=FN
donde FN es un nombre de archivo cuyo contenido se asume que es hexadecimal ASCII. Si también se proporciona DISPOSITIVO, se ignora DISPOSITIVO, se emite una advertencia y la utilidad continúa, decodificando el archivo llamado FN. Consulte la sección "FORMATOS HEX, BINARIO Y JSON" en la página del manual sg3_utils para obtener más información. Si también se proporciona la opción --raw, el contenido de FN se trata como binario.
Tenga en cuenta que, por defecto, esta utilidad asume que el contenido es la respuesta de un comando REPORT ZONES. Utilice la opción --dominio o --reino para decodificar los otros dos comandos.
-j[=JO], --json[=JO]
la salida está en formato JSON en lugar de texto plano. Tenga en cuenta que los argumentos para las formas corta y larga son opcionales y, si están presentes, comienzan con "=" y no se permiten espacios en blanco alrededor de ese "=".
Consulte la página del manual sg3_utils_json o use '?' para JO para obtener un resumen.
-J, --archivo-js=JFN
la salida está en formato JSON y se envía a un archivo llamado JFN. Si ese archivo existe, se trunca. Por defecto, la salida JSON se envía a stdout.
Cuando se proporciona esta opción, la opción --json[=JO] se implica y no es necesario proporcionarla. La opción --json[=JO] aún puede ser necesaria para establecer el parámetro JO a valores no predeterminados.
-l, --localizador=LBA
donde LBA juega un papel similar al de --inicio=LBA. Es el nombre del campo utilizado en los comandos REPORT REALMS y REPORT ZONE DOMAINS.
-m, --maxlen=LEN
donde LEN es la longitud (máxima) de la respuesta en bytes. Se coloca en el campo "longitud de asignación" del cdb. Si no se proporciona (o LEN es cero), se utiliza 16384. El valor máximo permitido de LEN es 2097152.
-n, --num=NUM
donde NUM es el número (máximo) de descriptores de zona a imprimir. El valor predeterminado es cero, que se toma como imprimir todos los descriptores de zona devueltos por el comando REPORT ZONES.
-p, --parcial
establecer el bit PARTIAL en el cdb. Sin el bit PARTIAL activado, un disco ZBC intentará formar una respuesta con todas las zonas desde LBA hasta el final del disco. Si hay un gran número de zonas (por ejemplo, > 10.000), esta gran respuesta se truncará para que no exceda el campo "longitud de asignación" en el cdb (ver --maxlen=LEN). La ventaja de hacer esto es que se puede calcular el número de zonas (restantes) en el disco. La desventaja es la cantidad de tiempo que puede llevar.
Con el bit PARTIAL activado en el cdb, solo se recuperan las zonas implícitas por el campo "longitud de asignación". Esto puede ser considerablemente más rápido que el mismo comando sin el bit PARTIAL activado.
Al iterar a través de las zonas en un disco ZBC, el proceso será más rápido cuando el bit PARTIAL esté activado. Típicamente --inicio=LBA se establece en cero o en [LBA + longitud_zona] de la última zona informada en la iteración anterior.
-r, --raw
mostrar la respuesta en binario (a stdout) a menos que también se proporcione la opción --enhex=FN. En ese caso, el nombre del archivo de entrada (FN) se decodifica como binario (y la salida no está en binario (pero puede ser hex)).
-R, --sololec
abrir el DISPOSITIVO en modo de solo lectura (por ejemplo, en Unix con el flag O_RDONLY).

OPTIONS

-a, --all
report on all zones. By default only zones that are not 'closed' and 'finished' are reported.
-c, --count=NUM
where NUM is the number of zone blocks to report. The default is 1. This option is only relevant when the --transport=SPC-4 option is also given and the zone type is not Report All Zones.
-d, --device=DEVICE
use given special file path to read from (e.g. /dev/sg0). The default is to open it read-write.
-e, --realm
send or decode the SCSI REPORT REALMS command.
-h, --help
output the usage message and exit.
-H, --hex
output the cdb and key sense data in hex.
-i, --interface=INTERF
where INTERF is 'scsi' or 'nvme'. The default is 'scsi'.
-k, --key=KEY
where KEY is the zone realm key, used when reporting realms. Requires --realm.
-l, --long
output in a long format, printing zone type, zone condition and block limits.
-L, --locator=LBA
where LBA is at the start or within the first zone to be reported. The default value is 0. If LBA is not a zone start LBA then the preceding zone start LBA is used for reporting. Assumed to be in decimal unless prefixed with '0x' or has a trailing 'h' which indicate hexadecimal.
The zone start LBA field used in the REPORT ZONES command was changed to the zone domain/realm locator field for the two newer ZBC-2 commands. For this utility --locator=LBA and --start=LBA are interchangeable.
-n, --num=NUM
where NUM is the number of zones to report. The default is to report all matching zones.
-o, --report=OPT
where OPT will become the contents of the REPORTING OPTION field in the cdb. The reporting options differ between REPORT ZONES, REPORT ZONE DOMAINS and REPORT REALMS. If the --help option is given twice ( or the equivalent '-hh') a list of available reporting options (as of writing) for each command is output.
The default value for REPORT ZONES is 0 which means report a list of all zones. Some other values are 1 for list zones with a zone condition of empty; 2 for list zones with a zone condition of implicitly opened; 3 for list zones with a zone condition of explicitly opened; 4 for list zones with a zone condition of closed; 5 for list zones with a zone condition of full; 6 for list zones with a zone condition of read only; 7 for list zones with a zone condition of offline. Other values are 0x10 for list zones with 'RWP recommended' set to true; 0x11 for list zones with non-sequential write resource active set to true, 0x3e for list zones apart from GAP zones, and 0x3f for list zones with a zone condition of 'not write pointer'.
-p, --protection=PROT
sets the protection bits in the cdb. PROT is a decimal, hex or octal value. See the scsi draft standard for details.
-r, --raw
output the data read from the device in raw format.
-s, --start=LBA
where LBA is at the start or within the first zone to be reported. The default value is 0. If LBA is not a zone start LBA then the preceding zone start LBA is used for reporting. Assumed to be in decimal unless prefixed with '0x' or has a trailing 'h' which indicate hexadecimal.
The zone start LBA field used in the REPORT ZONES command was changed to the zone domain/realm locator field for the two newer ZBC-2 commands. For this utility --locator=LBA and --start=LBA are interchangeable.
-S, --statistics
reviews all or a limited number of report zones, collects statistics and prints them (on stdout). The number of zones reviewed may be limited by any combination of --num=NUM, --report=OPT and --start=LBA options. The long option name may be abbreviated to --stats.
-t, --transport=TRP
where TRP is 'SPC-4', 'SPC-3', 'ST'. Defaults to 'SPC-4' for recent kernels, older kernels default to 'SPC-3'. SCSI Transport service action for Zoned Block Commands (ZBC) and Packetized SCSI commands (PSC) can be selected via this option. When set to 'ST' the transport service action is selected by the option given via -o. The default is to open it read-write.
-v, --verbose
increase the level of verbosity, (i.e. debug output).
-V, --version
print the version string and then exit.
-w, --wp
print the write pointer (in hex) only. In the absence of errors, then a hex LBA will be printed on each line, one line for each zone. Can be usefully combined with the --num=NUM and --start=LBA options.

EXIT STATUS

The exit status of sg_rep_zones is 0 when it is successful. Otherwise see the sg3_utils(8) man page.
