SGGSVP

Propósito:

!>
!> Esta subrutina está obsoleta y ha sido reemplazada por la subrutina SGGSVP3.
!>
!> SGGSVP calcula matrices ortogonales U, V y Q tales que
!>
!>                    N-K-L  K    L
!>  U**T*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**T*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> donde la matriz KxK A12 y la matriz LxL B13 son triangulares superiores
!> no singulares; A23 es triangular superior LxL si M-K-L >= 0,
!> de lo contrario, A23 es trapezoidal superior (M-K)xL. K+L = el rango
!> numérico efectivo de la matriz (M+P)xN (A**T,B**T)**T.
!>
!> Esta descomposición es el paso de preprocesamiento para calcular la
!> Descomposición en Valores Singulares Generalizada (GSVD), véase la subrutina
!> SGGSVD.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U':  Se calcula la matriz ortogonal U;
!>          = 'N':  U no se calcula.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'V':  Se calcula la matriz ortogonal V;
!>          = 'N':  V no se calcula.
!>

JOBQ

!>          JOBQ es CHARACTER*1
!>          = 'Q':  Se calcula la matriz ortogonal Q;
!>          = 'N':  Q no se calcula.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B. P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B. N >= 0.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, la matriz MxN A.
!>          En la salida, A contiene la matriz triangular (o trapezoidal)
!>          descrita en la sección Propósito.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es array REAL, dimension (LDB,N)
!>          En la entrada, la matriz PxN B.
!>          En la salida, B contiene la matriz triangular descrita en
!>          la sección Propósito.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,P).
!>

TOLA

!>          TOLA es REAL
!>

TOLB

!>          TOLB es REAL
!>
!>          TOLA y TOLB son los umbrales para determinar el rango numérico
!>          efectivo de la matriz B y un subbloque de A. Generalmente,
!>          se establecen como
!>             TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          El tamaño de TOLA y TOLB puede afectar el tamaño de los errores
!>          posteriores de la descomposición.
!>

K

!>          K es INTEGER
!>

L

!>          L es INTEGER
!>
!>          En la salida, K y L especifican la dimensión de los subbloques
!>          descritos en la sección Propósito.
!>          K + L = rango numérico efectivo de (A**T,B**T)**T.
!>

U

!>          U es array REAL, dimension (LDU,M)
!>          Si JOBU = 'U', U contiene la matriz ortogonal U.
!>          Si JOBU = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M) si
!>          JOBU = 'U'; LDU >= 1 en caso contrario.
!>

V

!>          V es array REAL, dimension (LDV,P)
!>          Si JOBV = 'V', V contiene la matriz ortogonal V.
!>          Si JOBV = 'N', V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 en caso contrario.
!>

Q

!>          Q es array REAL, dimension (LDQ,N)
!>          Si JOBQ = 'Q', Q contiene la matriz ortogonal Q.
!>          Si JOBQ = 'N', Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q'; LDQ >= 1 en caso contrario.
!>

IWORK

!>          IWORK es array INTEGER, dimension (N)
!>

TAU

!>          TAU es array REAL, dimension (N)
!>

WORK

!>          WORK es array REAL, dimension (max(3*N,M,P))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

NAME

sggsvp - calcula los vectores propios y valores propios generalizados de una matriz real simétrica generalizada.

Function/Subroutine Documentation

SGGSVP calcula los vectores propios y valores propios generalizados de una matriz real simétrica generalizada mediante el algoritmo de las dos fases de QZ. Esto es, dada una matriz real simétrica generalizada A y B, calcula las matrices P, Q y Z tal que:

A*Q = P*D*Z**T y B*Q = P*E*Z**T

donde D y E son matrices triangulares por bloques.

Parámetros:

  • JOBU (CHARACTER*1) - Indica si se calculan los vectores propios U.
    • 'N': No se calculan los vectores propios U.
    • 'V': Se calculan los vectores propios U.
  • JOBV (CHARACTER*1) - Indica si se calculan los vectores propios V.
    • 'N': No se calculan los vectores propios V.
    • 'V': Se calculan los vectores propios V.
  • VECT (CHARACTER*1) - Indica si se calculan los vectores propios de la matriz generalizada de la forma A*x = lambda*B*x.
    • 'N': No se calculan los vectores propios.
    • 'S': Se calculan los vectores propios.
  • N (INTEGER) - El orden de las matrices A y B.
  • A (REAL(8)) - Matriz de entrada A.
  • LDA (INTEGER) - El dimensionamiento de la primera dimensión de A.
  • B (REAL(8)) - Matriz de entrada B.
  • LDB (INTEGER) - El dimensionamiento de la primera dimensión de B.
  • TOL (REAL(8)) - Umbral para determinar los valores singulares pequeños.
  • INFO (INTEGER) - Código de salida.
    • 0: Éxito.
    • < 0: Uno de los parámetros de entrada no es válido.
    • > 0: El algoritmo de QZ falló al converger.
