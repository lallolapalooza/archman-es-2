NOMBRE

sg_rem_rest_elem - envía un comando SCSI para eliminar o restaurar un elemento

SINOPSIS

sg_rem_rest_elem [--capacity=RC] [--element=EID] [--help] [--quick] [--remove] [--restore] [--timeout=SE] [--verbose] [--version] DEVICE

DESCRIPCIÓN

Envía un comando SCSI REMOVE ELEMENT AND TRUNCATE [RMEAT] o RESTORE ELEMENTS AND REBUILD [RSEAR] al DEVICE. Dado que ambos comandos tienen un impacto potencialmente enorme en el DEVICE (similar al comando FORMAT UNIT: destruyendo datos y tardando mucho en completarse), primero dan al usuario la oportunidad de reconsiderar (3 veces en 15 segundos) antes de tomar medidas.

A diferencia del comando FORMAT UNIT, estos comandos parecen diseñados para funcionar en segundo plano. Por lo tanto, regresarán rápidamente (aunque sbc5r01.pdf no lo indica) y el disco se colocará en un estado de funcionalidad reducida donde solo se ejecutarán un número especificado de comandos (por ejemplo, INQUIRY y REPORT LUNS) hasta que la operación se complete. Otros comandos recibirán datos de sentido con una clave de sentido de NOT READY y un código de sentido adicional de 'Depopulation in progress' (para RMEAT) o 'Depopulation restoration in progress' (para RSEAR).

El REMOVE ELEMENT AND TRUNCATE tiene un pariente cercano en ZBC-2 llamado comando REMOVE ELEMENT AND MODIFY ZONES [RMEMZ]. Consulte la utilidad sg_zone para una implementación de este último comando.
La diferencia entre RMEAT y RMEMZ es que el primero "cambia la asociación entre los LBA y los bloques físicos" y el segundo no cambia esa asociación. Las zonas afectadas por el comando RMEMZ se colocan en la condición de zona: "Offline".

OPCIONES

Los argumentos para las opciones largas son obligatorios también para las opciones cortas.

-c, --capacity=RC
RC significa Requested Capacity (Capacidad Solicitada) y es el número de bloques lógicos que debería tener el DEVICE después de que se elimine el elemento con el comando RMEAT. El valor predeterminado es 0, lo que permite al DEVICE decidir cuál será la capacidad reducida después de la eliminación del elemento. El comando RSEAR ignora este valor.
-e, --element=EID
donde EID es un identificador de elemento que es un entero sin signo de 32 bits que comienza en uno. Este campo es utilizado por el comando RMEAT e ignorado de lo contrario. El valor predeterminado es cero (lo cual es inválido). Por lo tanto, el usuario debe proporcionar un identificador de elemento válido cuando se usa --remove.
-h, --help
muestra el mensaje de uso y luego sale.
-q, --quick
la acción predeterminada (es decir, cuando no se proporciona esta opción) es dar al usuario 15 segundos para reconsiderar la operación de eliminar o restaurar un elemento en el DEVICE. Cuando se proporciona esta opción, ese paso (es decir, el período de advertencia de 15 segundos) se omite.
-r, --remove
causa que se envíe el comando REMOVE ELEMENT AND TRUNCATE al DEVICE. En la práctica, también se debe proporcionar --element=EID.
-R, --restore
causa que se envíe el comando RESTORE ELEMENTS AND REBUILD al DEVICE.
-t, --timeout=SE
donde SE es el tiempo de espera del comando en segundos. El predeterminado es 60 segundos y si se proporciona 0, se mapea a 60. Una forma larga alternativa es --tmo=SE.
-v, --verbose
aumenta el nivel de verbosidad (es decir, salida de depuración).
-V, --version
imprime la cadena de versión y luego sale.

NOTAS

Una vez que un elemento se elimina con éxito, se denomina "despoblado". Los elementos despoblados que tienen el bit 'Restoration Allowed' (RALWD) establecido (ver sg_get_elem_status) son candidatos para restauraciones futuras.

Un elemento (de almacenamiento) de un disco duro giratorio es un lado de una placa típicamente asociado con una cabeza. Dichos discos duros típicamente tienen múltiples placas con dos cabezas por placa (es decir, una cabeza por cada lado de la placa).

ESTADO DE SALIDA

El estado de salida de sg_rem_rest_elem es 0 cuando tiene éxito. De lo contrario, consulte la página del manual sg3_utils(8).
