sg_get_network_iface_stats(3) sg_get_network_iface_stats(3)

NOMBRE

sg_get_network_iface_stats, sg_get_network_iface_stats_r, sg_free_network_iface_stats, sg_network_iface_compare_name - obtener estadísticas de la interfaz de red

SINOPSIS

#include <statgrab.h>


sg_network_iface_stats *sg_get_network_iface_stats
(size_t *entries);


sg_network_iface_stats *sg_get_network_iface_stats_r
(size_t *entries);


sg_error sg_free_network_iface_stats
(sg_network_iface_stats *data);


int sg_network_iface_compare_name
(const void *va, const void *vb);

DESCRIPCIÓN

Las funciones sg_get_network_iface_stats() y sg_get_network_iface_stats_r() devuelven estadísticas sobre las interfaces de red de la máquina. Específicamente, devuelven la velocidad de la interfaz, el estado dúplex y si está activa actualmente. Ambas funciones toman un parámetro opcional de entradas, que apunta (cuando se proporciona) a un size_t para tomar el número de entradas del vector devueltas.

Acceso directo a la API

función devuelve propietario de los datos
sg_get_network_iface_stats sg_network_iface_stats * libstatgrab (local para el hilo)
sg_get_network_iface_stats_r sg_network_iface_stats * llamador

Los vectores sg_network_iface_stats recibidos de sg_get_network_iface_stats_r() deben liberarse usando sg_free_network_iface_stats() cuando ya no se necesiten. El llamador es responsable de hacerlo.

Además, hay disponible una función de soporte para qsort(3): sg_network_iface_compare_name().

Ejemplo de ordenación

size_t entries;
sg_network_iface_stats *network_iface_stats = NULL;
while( NULL != ( network_iface_stats = sg_get_network_iface_stats(&entries) ) ) {
    /* ordenar entradas alfabéticamente usando el punto de montaje */
    qsort( network_iface_stats, entries, sizeof(network_iface_stats[0]), &sg_network_iface_compare_name );
    show_network_iface_stats( network_iface_stats );
}

VALORES DE RETORNO

La función sg_get_network_iface_stats devuelve un puntero a una estructura de tipo sg_network_iface_stats.

typedef enum{
        SG_IFACE_DUPLEX_FULL,
        SG_IFACE_DUPLEX_HALF,
        SG_IFACE_DUPLEX_UNKNOWN
}sg_iface_duplex;

Nota: El valor SG_IFACE_DUPLEX_UNKNOWN podría significar que el dúplex aún no se ha negociado.

typedef struct {
        char *interface_name;
        int speed;
        sg_iface_duplex duplex;
        int up;
        time_t systime;
} sg_network_iface_stats;
interface_name
El nombre conocido por el sistema operativo. (por ejemplo, en Linux podría ser eth0)
speed
La velocidad de la interfaz, en megabits/segundo.
duplex
El estado dúplex en el que se encuentra la interfaz. Consulte sg_iface_duplex para ver los valores permitidos.
up
Si la interfaz está activa.
systime
La marca de tiempo cuando se recopilaron las estadísticas anteriores en segundos desde la época.

ERRORES

La obtención de detalles específicos puede requerir privilegios elevados; por ejemplo, en Linux, la velocidad de la interfaz no es visible para los procesos no privilegiados.

Las funciones de comparación existen más por compatibilidad con versiones anteriores que por mejoras funcionales. La flexibilidad limitada (por ejemplo, orden inverso) y la falta de oportunidades de optimización para el compilador llevan a la recomendación de implementar las rutinas de comparación requeridas localmente.
