SGML2INFO(1) Manual de Comandos Generales SGML2INFO(1)

NOMBRE

sgml2info - crea salida GNU info a partir de un archivo fuente SGML DTD LinuxDoc

SINOPSIS

sgml2info [opción-genérica...] archivo[.sgml]

DESCRIPCIÓN

sgml2info es una forma antigua y obsoleta del comando conversor de info de LinuxDoc-Tools (su nombre puede ser engañoso, ya que no es una herramienta para ninguna DTD SGML, solo soporta la DTD LinuxDoc SGML). Se recomienda usar ahora la nueva forma linuxdoc -B info. Esto convierte un archivo fuente SGML DTD LinuxDoc a formato GNU info. La salida aparecerá en archivo.info donde archivo es el nombre del archivo fuente SGML.

El par atributo/valor "output=info" se establece para los condicionales.

OPCIONES

sgml2info acepta todas las opciones genéricas descritas en linuxdoc(1).

archivo
especifica el archivo fuente SGML, llamado archivo o archivo.sgml

FICHEROS

Se utilizan muchos archivos y ejecutables en /usr/share/linuxdoc-tools.
