SGESDD

Documentación de Función/Subrutina

subroutine sgesdd (character jobz, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real, dimension( ldu, * ) u, integer ldu, real, dimension( ldvt, * ) vt, integer ldvt, real, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

SGESDD

Propósito:

!>
!> SGESDD calcula la descomposición en valores singulares (SVD) de una matriz
!> real M por N, A, calculando opcionalmente los vectores singulares izquierdo y derecho.
!> Si se desean los vectores singulares, utiliza un algoritmo de divide y vencerás.
!>
!> La SVD se escribe
!>
!>      A = U * SIGMA * transpose(V)
!>
!> donde SIGMA es una matriz M por N que es cero excepto por sus
!> elementos diagonales min(m,n), U es una matriz ortogonal M por M, y
!> V es una matriz ortogonal N por N. Los elementos diagonales de SIGMA
!> son los valores singulares de A; son reales y no negativos, y
!> se devuelven en orden descendente. Las primeras min(m,n) columnas de
!> U y V son los vectores singulares izquierdo y derecho de A.
!>
!> ¡Tenga en cuenta que la rutina devuelve VT = V**T, no V.
!>
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          Especifica las opciones para calcular todo o parte de la matriz U:
!>          = 'A':  todas las M columnas de U y todas las N filas de V**T se
!>                  devuelven en los arrays U y VT;
!>          = 'S':  las primeras min(M,N) columnas de U y las primeras
!>                  min(M,N) filas de V**T se devuelven en los arrays U
!>                  y VT;
!>          = 'O':  Si M >= N, las primeras N columnas de U se sobrescriben
!>                  en el array A y todas las filas de V**T se devuelven en
!>                  el array VT;
!>                  de lo contrario, todas las columnas de U se devuelven en
!>                  el array U y las primeras M filas de V**T se sobrescriben
!>                  en el array A;
!>          = 'N':  no se calculan columnas de U ni filas de V**T.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  N >= 0.
!>

A

!>          A es array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz M por N A.
!>          En la salida,
!>          si JOBZ = 'O',  A se sobrescribe con las primeras N columnas
!>                          de U (los vectores singulares izquierdos, almacenados
!>                          por columnas) si M >= N;
!>                          A se sobrescribe con las primeras M filas
!>                          de V**T (los vectores singulares derechos, almacenados
!>                          por filas) en caso contrario.
!>          si JOBZ .ne. 'O', el contenido de A se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

S

!>          S es array REAL, dimensión (min(M,N))
!>          Los valores singulares de A, ordenados de forma que S(i) >= S(i+1).
!>

U

!>          U es array REAL, dimensión (LDU,UCOL)
!>          UCOL = M si JOBZ = 'A' o JOBZ = 'O' y M < N;
!>          UCOL = min(M,N) si JOBZ = 'S'.
!>          Si JOBZ = 'A' o JOBZ = 'O' y M < N, U contiene la matriz
!>          ortogonal M por M U;
!>          si JOBZ = 'S', U contiene las primeras min(M,N) columnas de U
!>          (los vectores singulares izquierdos, almacenados por columnas);
!>          si JOBZ = 'O' y M >= N, o JOBZ = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U.  LDU >= 1; si
!>          JOBZ = 'S' o 'A' o JOBZ = 'O' y M < N, LDU >= M.
!>

VT

!>          VT es array REAL, dimensión (LDVT,N)
!>          Si JOBZ = 'A' o JOBZ = 'O' y M >= N, VT contiene la
!>          matriz ortogonal N por N V**T;
!>          si JOBZ = 'S', VT contiene las primeras min(M,N) filas de
!>          V**T (los vectores singulares derechos, almacenados por filas);
!>          si JOBZ = 'O' y M < N, o JOBZ = 'N', VT no se referencia.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del array VT.  LDVT >= 1;
!>          si JOBZ = 'A' o JOBZ = 'O' y M >= N, LDVT >= N;
!>          si JOBZ = 'S', LDVT >= min(M,N).
!>

WORK

!>          WORK es array REAL, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo;
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo. El tamaño
!>          óptimo para el array WORK se calcula y se almacena en WORK(1),
!>          y no se realiza ningún otro trabajo excepto la verificación de argumentos.
!>
!>          Sea mx = max(M,N) y mn = min(M,N).
!>          Si JOBZ = 'N', LWORK >= 3*mn + max( mx, 7*mn ).
!>          Si JOBZ = 'O', LWORK >= 3*mn + max( mx, 5*mn*mn + 4*mn ).
!>          Si JOBZ = 'S', LWORK >= 4*mn*mn + 7*mn.
!>          Si JOBZ = 'A', LWORK >= 4*mn*mn + 6*mn + mx.
!>          Estos no son mínimos estrictos en todos los casos; ver comentarios dentro del código.
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor;
!>          se recomienda una consulta.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (8*min(M,N))
!>

INFO

!>          INFO es INTEGER
!>          <  0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = -4:  si A tenía una entrada NAN.
!>          >  0:  SBDSDC no convergió, el proceso de actualización falló.
!>          =  0:  salida exitosa.
!>
