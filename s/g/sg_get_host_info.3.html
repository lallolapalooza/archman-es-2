sg_get_host_info(3)

Paquete: libstatgrab

Licencias: LGPL, GPL

sg_get_host_info(3) sg_get_host_info(3)

NOMBRE

sg_get_host_info, sg_get_host_info_r, sg_free_host_info - obtener estadísticas generales del sistema operativo

SINOPSIS

#include <statgrab.h>


sg_host_info *sg_get_host_info
(size_t *entries);


sg_host_info *sg_get_host_info_r
(size_t *entries);


sg_error sg_free_host_info
(sg_host_info *data);

DESCRIPCIÓN

Estas llamadas devuelven detalles sobre el sistema operativo y la máquina en la que se está ejecutando.

Atajo de la API

función devuelve propietario de los datos
sg_get_host_info sg_host_info * libstatgrab (local al hilo)
sg_get_host_info_r sg_host_info * llamador

El búfer sg_host_info recibido de sg_get_host_info_r() debe ser liberado usando sg_free_host_info() cuando ya no se necesite. El llamador es responsable de hacerlo.

VALORES DE RETORNO

La estructura devuelta es de tipo sg_host_info.

typedef enum {
        sg_unknown_configuration = 0,
        sg_physical_host,
        sg_virtual_machine,
        sg_paravirtual_machine,
        sg_hardware_virtualized
} sg_host_state;

typedef struct{
        char *os_name;
        char *os_release;
        char *os_version;
        char *platform;
        char *hostname;
        unsigned bitwidth;
        sg_host_state host_state;
        unsigned ncpus;
        unsigned maxcpus;
        time_t uptime;
        time_t systime;
}sg_host_info;
os_name
El nombre del sistema operativo. (ej. SunOS o Linux)
os_release
La versión del sistema operativo. (ej. 5.8 o 5.9 o Solaris)
os_version
El nivel de versión del SO.
platform
La plataforma de hardware (arquitectura) en la que se ejecuta el SO.
hostname
El nombre de la máquina.
uptime
El tiempo de actividad de la máquina en segundos.
systime
La marca de tiempo cuando las estadísticas anteriores fueron recopiladas en segundos desde la época
