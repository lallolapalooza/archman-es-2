subroutine sgsvj0 (character*1 jobv, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( n ) d, real, dimension( n ) sva, integer mv, real, dimension( ldv, * ) v, integer ldv, real eps, real sfmin, real tol, integer nsweep, real, dimension( lwork ) work, integer lwork, integer info)

SGSVJ0 pre-procesador para la rutina sgesvj.

Propósito:

!>
!> SGSVJ0 es llamada desde SGESVJ como pre-procesador y ese es su propósito principal.
!> Aplica rotaciones de Jacobi de la misma manera que SGESVJ, pero no verifica la convergencia
!> (criterio de parada). Pocos parámetros de ajuste (marcados con [TP]) están disponibles para el implementador.
!>

Parámetros

JOBV 
!>          JOBV es CHARACTER*1
!>          Especifica si la salida de este procedimiento se utiliza
!>          para calcular la matriz V:
!>          = 'V': el producto de las rotaciones de Jacobi se acumula
!>                 multiplicando a la derecha el array N por N, V.
!>                (Ver la descripción de V.)
!>          = 'A': el producto de las rotaciones de Jacobi se acumula
!>                 multiplicando a la derecha el array MV por N, V.
!>                (Ver las descripciones de MV y V.)
!>          = 'N': las rotaciones de Jacobi no se acumulan.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.
!>          M >= N >= 0.
!>

A

!>          A es un array REAL, dimension (LDA,N)
!>          En la entrada, matriz M por N, A, tal que A*diag(D) representa
!>          la matriz de entrada.
!>          En la salida,
!>          A_salida * D_salida representa la matriz de entrada A*diag(D)
!>          multiplicada a la derecha por una secuencia de rotaciones de Jacobi,
!>          donde el umbral de rotación y el número total de barridos se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Ver las descripciones de D, TOL y NSWEEP.)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

D

!>          D es un array REAL, dimension (N)
!>          El array D acumula los factores de escala de las rotaciones de Jacobi
!>          rápidamente escaladas.
!>          En la entrada, A*diag(D) representa la matriz de entrada.
!>          En la salida, A_salida*diag(D_salida) representa la matriz de entrada
!>          multiplicada a la derecha por una secuencia de rotaciones de Jacobi,
!>          donde el umbral de rotación y el número total de barridos se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Ver las descripciones de A, TOL y NSWEEP.)
!>

SVA

!>          SVA es un array REAL, dimension (N)
!>          En la entrada, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A*diag(D).
!>          En la salida, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A_salida*diag(D_salida).
!>

MV

!>          MV es INTEGER
!>          Si JOBV = 'A', entonces MV filas de V se multiplican a la derecha por una
!>                           secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces MV no se referencia.
!>

V

!>          V es un array REAL, dimension (LDV,N)
!>          Si JOBV = 'V' entonces N filas de V se multiplican a la derecha por una
!>                           secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'A' entonces MV filas de V se multiplican a la derecha por una
!>                           secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V,  LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS es REAL
!>          EPS = SLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN es REAL
!>          SFMIN = SLAMCH('Safe Minimum')
!>

TOL

!>          TOL es REAL
!>          TOL es el umbral para las rotaciones de Jacobi. Para un par
!>          de columnas pivote A(:,p), A(:,q), la rotación de Jacobi se
!>          aplica solo si ABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP es INTEGER
!>          NSWEEP es el número de barridos de rotaciones de Jacobi que se
!>          realizarán.
!>

WORK

!>          WORK es un array REAL, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          LWORK es la dimensión de WORK. LWORK >= M.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, entonces el i-ésimo argumento tenía un valor ilegal.
!>

Detalles Adicionales:

SGSVJ0 se usa solo para permitir que SGESVJ llame a una versión simplificada de sí misma para trabajar en una submatriz de la matriz original.
