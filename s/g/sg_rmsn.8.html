NOMBRE

sg_rmsn - enviar comando SCSI READ MEDIA SERIAL NUMBER

SINOPSIS

sg_rmsn [--help] [--raw] [--readonly] [--verbose] [--version] DISPOSITIVO

DESCRIPCIÓN

Envía un comando SCSI READ MEDIA SERIAL NUMBER al DISPOSITIVO y muestra la respuesta.

Este comando se describe en SPC-3, que se encuentra en www.t10.org. Originalmente se añadió a SPC-3 en la revisión 11 (2003/02/12). No es un comando obligatorio y el autor no ha visto ningún dispositivo SCSI que lo soporte.

OPCIONES

Los argumentos de las opciones largas son obligatorios también para las opciones cortas.

-h, --help
muestra el mensaje de uso y sale.
-r, --raw
envía el número de serie (si se encuentra) a la salida estándar. Esta salida puede contener caracteres no imprimibles (por ejemplo, el número de serie se rellena con NULLs al final para que su longitud sea múltiplo de 4). La acción predeterminada es mostrar el número de serie en HEX ASCII con caracteres ASCII a la derecha. Todos los mensajes de error se envían a stderr.
-R, --readonly
abre el DISPOSITIVO en modo de solo lectura en lugar de lectura-escritura, que es el valor predeterminado. El controlador sg de Linux necesita acceso de lectura-escritura para el comando SCSI READ MEDIA SERIAL NUMBER, pero otros métodos de acceso pueden requerir acceso de solo lectura.
-v, --verbose
aumenta el nivel de verbosidad (es decir, salida de depuración).
-V, --version
muestra la cadena de versión y sale.

NOTAS

La información de identificación del dispositivo también se encuentra en una respuesta INQUIRY estándar y sus páginas VPD (ver sg_vpd). Las páginas VPD relevantes son la "página de identificación del dispositivo" (página VPD 0x83) y la página "número de serie de la unidad" (página VPD 0x80).

El conjunto de comandos MMC-4 para unidades CD/DVD/HD-DVD/BD tiene una característica de "número de serie del medio" (0x109) [y una característica de "número de serie de la unidad lógica"]. Estos se pueden ver con sg_get_config.

ESTADO DE SALIDA

El estado de salida de sg_rmsn es 0 cuando tiene éxito. De lo contrario, consulte la página del manual de sg3_utils(8).
