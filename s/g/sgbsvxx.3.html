subrutina sgbsvxx (carácter fact, carácter trans, entero n, entero kl, entero ku, entero nrhs, real, dimensión( ldab, * ) ab, entero ldab, real, dimensión( ldafb, * ) afb, entero ldafb, entero, dimensión( * ) ipiv, carácter equed, real, dimensión( * ) r, real, dimensión( * ) c, real, dimensión( ldb, * ) b, entero ldb, real, dimensión( ldx , * ) x, entero ldx, real rcond, real rpvgrw, real, dimensión( * ) berr, entero n_err_bnds, real, dimensión( nrhs, * ) err_bnds_norm, real, dimensión( nrhs, * ) err_bnds_comp, entero nparams, real, dimensión( * ) params, real, dimensión( * ) work, entero, dimensión( * ) iwork, entero info)

SGBSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GB

Propósito:

!>
!>    SGBSVXX utiliza la factorización LU para calcular la solución a un
!>    sistema lineal real de ecuaciones  A * X = B,  donde A es una
!>    matriz de N por N y X y B son matrices de N por NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normativos como
!>    de componente máxima. SGBSVXX devolverá una solución con un error
!>    garantizado minúsculo (O(eps) donde eps es la precisión de la máquina
!>    de trabajo) a menos que la matriz esté muy mal condicionada, en cuyo
!>    caso se devuelve una advertencia. También se calculan y devuelven los
!>    números de condición relevantes.
!>
!>    SGBSVXX acepta factorizaciones y factores de ecualización proporcionados
!>    por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada
!>    anterior a SGBSVXX también producirá una solución con errores O(eps)
!>    o advertencias, pero no podemos hacer esa afirmación para
!>    factorizaciones y factores de ecualización proporcionados por el usuario
!>    en general si difieren de lo que SGBSVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para ecualizar
!>    el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Si el sistema se ecualizará o no depende del escalado de la matriz A,
!>    pero si se utiliza la ecualización, A se sobrescribe con
!>    diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N') o diag(C)*B
!>    (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después de la ecualización si FACT = 'E') como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular inferior
!>    unitaria y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U sea exactamente singular, la
!>    rutina devuelve INFO = i. De lo contrario, la forma factorizada de A
!>    se utiliza para estimar el número de condición de la matriz A (ver
!>    argumento RCOND). Si la inversa del número de condición es menor que
!>    la precisión de la máquina, la rutina continúa resolviendo para X
!>    y calculando los límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en
!>    cero), la rutina utilizará el refinamiento iterativo para intentar
!>    obtener un error pequeño y límites de error. El refinamiento calcula
!>    el residuo con al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó la ecualización, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para
!>    que resuelva el sistema original antes de la ecualización.
!> 
!>     Algunos parámetros opcionales se agrupan en la matriz PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados
!>     son aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que
!>     el código fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se proporciona o no
!>     en la entrada, y si no, si la matriz A debe ecualizarse antes de
!>     factorizarse.
!>       = 'F':  En la entrada, AF y IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido ecualizada
!>               con factores de escala dados por R y C.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará en AF y se factorizará.
!>       = 'E':  La matriz A se ecualizará si es necesario, luego
!>               se copiará en AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta Conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es array REAL, dimensión (LDAB,N)
!>     En la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>     La j-ésima columna de A se almacena en la j-ésima columna de
!>     la matriz AB como sigue:
!>     AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+kl)
!>
!>     Si FACT = 'F' y EQUED no es 'N', entonces AB debe haber sido
!>     ecualizada por los factores de escala en R y/o C. AB no se
!>     modifica si FACT = 'F' o 'N', o si FACT = 'E' y
!>     EQUED = 'N' en la salida.
!>
!>     En la salida, si EQUED .ne. 'N', A se escala como sigue:
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal de la matriz AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array REAL, dimensión (LDAFB,N)
!>     Si FACT = 'F', entonces AFB es un argumento de entrada y en la entrada
!>     contiene detalles de la factorización LU de la matriz de banda
!>     A, tal como se calculó con SGBTRF. U se almacena como una matriz
!>     triangular superior de banda con KL+KU superdiagonales en las
!>     filas 1 a KL+KU+1, y los multiplicadores utilizados durante la
!>     factorización se almacenan en las filas KL+KU+2 a 2*KL+KU+1.
!>     Si EQUED .ne. 'N', entonces AFB es la forma factorizada de
La matriz A equilibrada.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y a la salida
!>     devuelve los factores L y U de la factorización A = P*L*U
!>     de la matriz original A.
!>
!>     Si FACT = 'E', entonces AF es un argumento de salida y a la salida
!>     devuelve los factores L y U de la factorización A = P*L*U
!>     de la matriz equilibrada A (ver la descripción de A para
!>     la forma de la matriz equilibrada).
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del array AFB. LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y a la entrada
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     calculada por SGETRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>
!>     Si FACT = 'N', entonces IPIV es un argumento de salida y a la salida
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     de la matriz original A.
!>
!>     Si FACT = 'E', entonces IPIV es un argumento de salida y a la salida
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     de la matriz equilibrada A.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó.
!>       = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>       = 'R':  Equilibrado de filas, es decir, A se ha premultiplicado por
!>               diag(R).
!>       = 'C':  Equilibrado de columnas, es decir, A se ha postmultiplicado
!>               por diag(C).
!>       = 'B':  Equilibrado de filas y columnas, es decir, A ha sido
!>               reemplazado por diag(R) * A * diag(C).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.
!>

R

!>          R es un array REAL, dimensión (N)
!>     Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A se
!>     multiplica a la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede. R es un argumento de entrada si FACT = 'F';
!>     de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>     Si R es de salida, cada elemento de R es una potencia de la base.
!>     Si R es de entrada, cada elemento de R debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. El escalado por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado desborde inferior o superior. Los errores de redondeo durante el escalado
!>     conducen a refinar con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

C

!>          C es un array REAL, dimensión (N)
!>     Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A se
!>     multiplica a la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede. C es un argumento de entrada si FACT = 'F';
!>     de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>     Si C es de salida, cada elemento de C es una potencia de la base.
!>     Si C es de entrada, cada elemento de C debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. El escalado por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado desborde inferior o superior. Los errores de redondeo durante el escalado
!>     conducen a refinar con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es un array REAL, dimensión (LDB,NRHS)
!>     A la entrada, la matriz B de mano derecha de N por NRHS.
!>     A la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si TRANS = 'N' y EQUED = 'R' o 'B', B se sobrescribe con
!>        diag(R)*B;
!>     si TRANS = 'T' o 'C' y EQUED = 'C' o 'B', B se
!>        sobrescribe con diag(C)*B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array REAL, dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz solución X de N por NRHS del sistema original
!>     de ecuaciones. Tenga en cuenta que A y B se modifican a la salida
!>     si EQUED .ne. 'N', y la solución del sistema equilibrado es
!>     inv(diag(C))*X si TRANS = 'N' y EQUED = 'C' o 'B', o
!>     inv(diag(R))*X si TRANS = 'T' o 'C' y EQUED = 'R' o 'B'.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Condición recíproca escalada. Esta es una estimación de la
!>     condición recíproca de Skeel de la matriz A después del
!>     equilibrado (si se realizó). Si esto es menor que la precisión de la máquina
!>     (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.
!>

RPVGRW

!>          RPVGRW es REAL
!>     Crecimiento recíproco del pivote. A la salida, esto contiene el crecimiento recíproco
!>     del pivote factor norm(A)/norm(U). Se utiliza la norma 1. Si esto es mucho menor que 1,
!>     la estabilidad de
!>     la factorización LU de la matriz A (equilibrada) podría ser pobre.
!>     Esto también significa que la solución X, los números de condición estimados
!>     y los límites de error podrían no ser fiables. Si la factorización falla con
!>     0<INFO<=N, entonces esto contiene el factor de crecimiento recíproco del pivote
!>     para las columnas INFO principales de A. En SGESVX, esta cantidad es
!>     devuelta en WORK(1).
!>

BERR

!>          BERR es un array REAL, dimensión (NRHS)
!>     Error relativo residual por componentes. Este es el
!>     error relativo residual por componentes de cada vector solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     hace que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada mano derecha
!>     y cada tipo (normativo o por componentes). Ver ERR_BNDS_NORM y
!>     ERR_BNDS_COMP abajo.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada mano derecha, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normativo, que se define de la siguiente manera:
!>
!>     Error relativo normativo en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array se indexa por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde a la i-ésima
!>     mano derecha.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confíe en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con seguridad dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo debe
!>              ser fiable si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimación normativa
!>              número de condición recíproco. Comparado con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la estimación del error
!>              es . Estos números de condición recíprocos
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base para que todas las sumas de filas absolutas de Z sean aproximadamente 1.
!>
!>     Ver Lapack Working Note 165 para más detalles y precauciones adicionales.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada mano derecha, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo por componentes, que se define de la siguiente manera:
!>
!>     Error relativo por componentes en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array se indexa por la mano derecha i (de la que depende el
!>     error relativo por componentes), y el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas para cada mano derecha. Si
!>     la precisión por componentes no se solicita (PARAMS(3) = 0.0), entonces
!>     ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces como máximo
!>     se devuelven las primeras (:,N_ERR_BNDS) entradas.
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde a la i-ésima
!>     mano derecha.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confíe en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con seguridad dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo debe
!>              ser fiable si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimación por componentes
!>              número de condición recíproco. Comparado con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la estimación del error
!>              es . Estos números de condición recíprocos
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para la
!>              mano derecha actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas las sumas de filas
!>              absolutas de Z sean aproximadamente 1.
!>
!>     Ver Lapack Working Note 165 para más detalles y precauciones adicionales.
!>

NPARAMS

!>          NPARAMS es INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS. Si es <= 0,
!>     el array PARAMS nunca se referencia y se utilizan los valores predeterminados.
!>

PARAMS

!>          PARAMS es un array REAL, dimensión NPARAMS
!>     Especifica los parámetros del algoritmo. Si una entrada es < 0.0, entonces
!>     esa entrada se rellenará con el valor predeterminado utilizado para esa
!>     entrada.
!>

NAME

sgbsvxx - Real General Banded System Solvers

SYNOPSIS

SUBROUTINE SGBSVXX( TRANS, N, KBL, KBU, AB, LDAB, B, LDB, X, LDX, RCOND,
     BERR, RES, WORK, IWORK, INFO )

  CHARACTER(LEN=1) TRANS
  INTEGER N, KBL, KBU, LDAB, LDB, LDX, INFO
  REAL AB( LDAB, * ), B( LDB, * ), X( LDX, * ), RCOND,
     BERR( * ), RES( * ), WORK( * )
  INTEGER IWORK( * )

Function/Subroutine Documentation

SGBSVXX performs a banded general system solve with iterative refinement. It solves a linear system of equations 

A*X = B
where A is a real banded matrix of order N with KBL subdiagonals and KBU superdiagonals, and X and B are matrices of general band width. The routine uses an LU factorization with partial pivoting with iterative refinement to produce a solution X with a high degree of accuracy.

Arguments

TRANS

    TRANS is CHARACTER*1
    = 'N':  Solve system A * X = B, if TRANS = 'N' (No transpose).
    = 'T':  Solve system A**T * X = B, if TRANS = 'T' (Transpose).
    = 'C':  Solve system A**H * X = B, if TRANS = 'C' (Conjugate transpose).
            Note that for real matrices, A**H = A**T.

N

    N is INTEGER
    The order of the matrix A. The number of rows in B and X.

KBL

    KBL is INTEGER
    The number of subdiagonals of the matrix A. KBL >= 0.

KBU

    KBU is INTEGER
    The number of superdiagonals of the matrix A. KBU >= 0.

AB

    AB is REAL array, dimension (LDAB, KBL + KBU + 1)
    On entry, the M x N band matrix A, in conventional storage, given
    in the array, with KBL sub-diagonals and KBU super-diagonals.
    The width of band is KBL + KBU + 1.

LDAB

    LDAB is INTEGER
    The leading dimension of the array AB. LDAB >= KBL + KBU + 1.

B

    B is REAL array, dimension (LDB, NRHS)
    On entry, the right hand side matrix of size N x NRHS.

LDB

    LDB is INTEGER
    The leading dimension of the array B. LDB >= max(N, KBL + KBU + 1).

X

    X is REAL array, dimension (LDX, NRHS)
    On exit, if INFO = 0 or INFO = N+J, the solution matrix to the system
    A * X = B, of size N x NRHS.

LDX

    LDX is INTEGER
    The leading dimension of the array X. LDX >= max(N, KBL + KBU + 1).

RCOND

    RCOND is REAL
    On exit, an estimate of the reciprocal condition number of the matrix A.
    RCOND is not defined if INFO > 0.

BERR

    BERR is REAL array, dimension (NRHS)
    On exit, the estimated forward error bound for each right hand side
    in the solutions X(j), that is, the largest value of the relative error
    || Xj - Xtruej || / || Xtruej ||.

RES

    RES is REAL array, dimension (NRHS)
    On exit, the componentwise error of the computed solution X.
    RES(j) = max | X(i,j) - B(i,j) | / | X(i,j) |  (If X(i,j) = 0,
