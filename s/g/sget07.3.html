Documentación de función/subrutina

subroutine sget07 (character trans, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real, dimension( ldxact, * ) xact, integer ldxact, real, dimension( * ) ferr, logical chkferr, real, dimension( * ) berr, real, dimension( * ) reslts)

SGET07

Propósito:

!>
!> SGET07 prueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones op(A)*X = B, donde A es una
!> matriz general de n por n y op(A) = A o A**T, dependiendo de TRANS.
!>
!> RESLTS(1) = prueba del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta relación no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( (n+1)*EPS + (*) ), donde
!>             (*) = (n+1)*UNFL / (min_i (abs(op(A))*abs(X) +abs(b))_i )
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B     (Sin transpuesta)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>          El número de filas de las matrices X y XACT.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X y XACT.  NRHS >= 0.
!>

A

!>          A es un array REAL, dimension (LDA,N)
!>          La matriz original A de n por n.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array REAL, dimension (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de
!>          ecuaciones lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array REAL, dimension (LDX,NRHS)
!>          Los vectores de solución calculados. Cada vector se almacena
!>          como una columna de la matriz X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

XACT

!>          XACT es un array REAL, dimension (LDX,NRHS)
!>          Los vectores de solución exactos. Cada vector se almacena
!>          como una columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es INTEGER
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR es un array REAL, dimension (NRHS)
!>          Los límites de error hacia adelante estimados para cada vector
!>          de solución X.  Si XTRUE es la solución verdadera, FERR acota la
!>          magnitud de la entrada más grande en (X - XTRUE) dividida por
!>          la magnitud de la entrada más grande en X.
!>

CHKFERR

!>          CHKFERR es LOGICAL
!>          Se establece en .TRUE. para comprobar FERR, .FALSE. para no
!>          comprobar FERR.
!>          Cuando el sistema de prueba está mal condicionado, la
!>          solución en XACT puede ser incorrecta.
!>

BERR

!>          BERR es un array REAL, dimension (NRHS)
!>          El error hacia atrás relativo componente a componente de cada
!>          vector de solución (es decir, el cambio relativo más pequeño en
!>          cualquier entrada de A o B que haga que X sea una solución
!>          exacta).
!>

RESLTS

!>          RESLTS es un array REAL, dimension (2)
!>          El máximo sobre los vectores de solución NRHS de las relaciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( (n+1)*EPS + (*) )
!>
