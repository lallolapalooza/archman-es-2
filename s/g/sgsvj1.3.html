subrutina sgsvj1 (jobv, m, n, n1, a, lda, d, sva, mv, v, ldv, eps, sfmin, tol, nsweep, work, lwork, info)
SGSVJ1 pre-procesador de la subrutina sgesvj, aplica rotaciones de Jacobi dirigidas solo a pivotes particulares.

Documentación de Función/Subrutina

subrutina sgsvj1 (character*1 jobv, integer m, integer n, integer n1, real, dimension( lda, * ) a, integer lda, real, dimension( n ) d, real, dimension( n ) sva, integer mv, real, dimension( ldv, * ) v, integer ldv, real eps, real sfmin, real tol, integer nsweep, real, dimension( lwork ) work, integer lwork, integer info)

SGSVJ1 es un pre-procesador llamado desde SGESVJ y ese es su propósito principal. Aplica rotaciones de Jacobi de la misma manera que SGESVJ, pero se enfoca solo en pivotes particulares y no verifica la convergencia (criterio de parada). Hay pocos parámetros de ajuste (marcados con [TP]) disponibles para el implementador.

Propósito:

!>
!> SGSVJ1 es llamado desde SGESVJ como pre-procesador y ese es su propósito
!> principal. Aplica rotaciones de Jacobi de la misma manera que SGESVJ lo hace,
!> pero se enfoca solo en pivotes particulares y no verifica la convergencia
!> (criterio de parada). Pocos parámetros de ajuste (marcados con [TP]) están
!> disponibles para el implementador.
!>
!> Más detalles
!> ~~~~~~~~~~~~~~~
!> SGSVJ1 aplica algunas pasadas de rotaciones de Jacobi en el espacio de columnas de
!> la matriz de entrada M por N, A. Los pares de pivotes se toman del bloque
!> fuera de la diagonal (1,2) en la matriz de Gram correspondiente N por N, A^T * A.
!> Las entradas de bloque (tiles) del bloque fuera de la diagonal (1,2) están marcadas
!> por las [x] en el siguiente esquema:
!>
!>    | *  *  * [x] [x] [x]|
!>    | *  *  * [x] [x] [x]|    Ciclos de fila en los bloques [x] nblr x nblc.
!>    | *  *  * [x] [x] [x]|    Pivoteo cíclico de fila dentro de cada bloque [x].
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>
!> En términos de las columnas de A, las primeras N1 columnas se rotan 'contra'
!> las N-N1 columnas restantes, intentando aumentar el ángulo entre los
!> subespacios correspondientes. El bloque fuera de la diagonal es N1 x (N-N1)
!> y se divide en bloques (tiles) cuadradas de lado KBL. Aquí, KBL es un parámetro de ajuste.
!> El número de pasadas se da en NSWEEP y el umbral de ortogonalidad
!> se da en TOL.
!>

Parámetros

JOBV 
!>          JOBV es CHARACTER*1
!>          Especifica si la salida de este procedimiento se usa
!>          para calcular la matriz V:
!>          = 'V': el producto de las rotaciones de Jacobi se acumula
!>                 multiplicando por la derecha el array N x N V.
!>                (Ver la descripción de V.)
!>          = 'A': el producto de las rotaciones de Jacobi se acumula
!>                 multiplicando por la derecha el array MV x N V.
!>                (Ver las descripciones de MV y V.)
!>          = 'N': las rotaciones de Jacobi no se acumulan.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.
!>          M >= N >= 0.
!>

N1

!>          N1 es INTEGER
!>          N1 especifica la partición de bloques 2 x 2, las primeras N1 columnas
se rotan 'contra' las N-N1 columnas restantes de A.
!>

A

!>          A es array REAL, dimension (LDA,N)
!>          En la entrada, matriz M x N A, tal que A*diag(D) representa
!>          la matriz de entrada.
!>          En la salida,
!>          A_salida * D_salida representa la matriz de entrada A*diag(D)
!>          multiplicada por la derecha por una secuencia de rotaciones de Jacobi,
donde el
!>          umbral de rotación y el número total de pasadas se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Ver las descripciones de N1, D, TOL y NSWEEP.)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

D

!>          D es array REAL, dimension (N)
!>          El array D acumula los factores de escala de las rotaciones de Jacobi
escaladas rápidamente.
!>          En la entrada, A*diag(D) representa la matriz de entrada.
!>          En la salida, A_salida*diag(D_salida) representa la matriz de entrada
!>          multiplicada por la derecha por una secuencia de rotaciones de Jacobi,
donde el
!>          umbral de rotación y el número total de pasadas se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Ver las descripciones de N1, A, TOL y NSWEEP.)
!>

SVA

!>          SVA es array REAL, dimension (N)
!>          En la entrada, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A*diag(D).
!>          En la salida, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A_salida*diag(D_salida).
!>

MV

!>          MV es INTEGER
!>          Si JOBV = 'A', entonces MV filas de V se multiplican por la derecha por
una secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces MV no se referencia.
!>

V

!>          V es array REAL, dimension (LDV,N)
!>          Si JOBV = 'V', entonces N filas de V se multiplican por la derecha por
una secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'A', entonces MV filas de V se multiplican por la derecha por
una secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V, LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS es REAL
!>          EPS = SLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN es REAL
!>          SFMIN = SLAMCH('Safe Minimum')
!>

TOL

!>          TOL es REAL
!>          TOL es el umbral para las rotaciones de Jacobi. Para un par
!>          A(:,p), A(:,q) de columnas pivote, la rotación de Jacobi se
aplica solo si ABS(COS(ángulo(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP es INTEGER
!>          NSWEEP es el número de pasadas de rotaciones de Jacobi a realizar.
!>

WORK

!>          WORK es array REAL, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          LWORK es la dimensión de WORK. LWORK >= M.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, entonces el i-ésimo argumento tenía un valor ilegal
!>
