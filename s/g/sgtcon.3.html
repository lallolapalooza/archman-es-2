Documentación de la función/subrutina

subroutine sgtcon (character norm, integer n, real, dimension( * ) dl, real, dimension( * ) d, real, dimension( * ) du, real, dimension( * ) du2, integer, dimension( * ) ipiv, real anorm, real rcond, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SGTCON

Propósito:

!>
!> SGTCON estima el recíproco del número de condición de una matriz real
!> tridiagonal A utilizando la factorización LU calculada por
!> SGTTRF.
!>
!> Se obtiene una estimación de norm(inv(A)) y se calcula el recíproco del
!> número de condición como RCOND = 1 / (ANORM * norm(inv(A))).
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica si se requiere el número de condición 1-norma o
!>          el número de condición infinito-norma:
!>          = '1' o 'O':  1-norma;
!>          = 'I':         Infinito-norma.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

DL

!>          DL es un array REAL, dimension (N-1)
!>          Los multiplicadores (n-1) que definen la matriz L de la
!>          factorización LU de A calculada por SGTTRF.
!>

D

!>          D es un array REAL, dimension (N)
!>          Los n elementos diagonales de la matriz triangular superior U de
!>          la factorización LU de A.
!>

DU

!>          DU es un array REAL, dimension (N-1)
!>          Los elementos (n-1) de la primera superdiagonal de U.
!>

DU2

!>          DU2 es un array REAL, dimension (N-2)
!>          Los elementos (n-2) de la segunda superdiagonal de U.
!>

IPIV

!>          IPIV es un array INTEGER, dimension (N)
!>          Los índices de pivote; para 1 <= i <= n, la fila i de la matriz fue
!>          intercambiada con la fila IPIV(i).  IPIV(i) será siempre i o i+1;
!>          IPIV(i) = i indica que no se requirió un intercambio de filas.
!>

ANORM

!>          ANORM es REAL
!>          Si NORM = '1' o 'O', la 1-norma de la matriz original A.
!>          Si NORM = 'I', la infinito-norma de la matriz original A.
!>

RCOND

!>          RCOND es REAL
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la 1-norma de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es un array REAL, dimension (2*N)
!>

IWORK

!>          IWORK es un array INTEGER, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
