subrutina sgesv (n, nrhs, a, lda, ipiv, b, ldb, info)

Documentación de función/subrutina

subroutine sgesv (integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, real, dimension( ldb, * ) b, integer ldb, integer info)

Propósito:

!>
!> SGESV calcula la solución a un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz N por N y X y B son matrices N por NRHS.
!>
!> Se utiliza la descomposición LU con pivoteo parcial e intercambios de filas
!> para factorizar A como
!>    A = P * L * U,
!> donde P es una matriz de permutación, L es triangular inferior unitaria y U es
!> triangular superior. La forma factorizada de A se utiliza entonces para resolver
!> el sistema de ecuaciones A * X = B.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array REAL, dimensión (LDA,N)
!>          En la entrada, la matriz de coeficientes A de N por N.
!>          En la salida, los factores L y U de la factorización
!>          A = P*L*U; los elementos diagonales unitarios de L no se almacenan.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Los índices de pivote que definen la matriz de permutación P;
!>          la fila i de la matriz se intercambió con la fila IPIV(i).
!>

B

!>          B es un array REAL, dimensión (LDB,NRHS)
!>          En la entrada, la matriz de lados derechos B de N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, U(i,i) es exactamente cero. La factorización
!>                se ha completado, pero el factor U es exactamente
!>                singular, por lo que la solución no pudo ser calculada.
!>
