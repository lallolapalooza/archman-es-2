Documentación de la función/subrutina

subrutina sgbt05 (character trans, integer n, integer kl, integer ku, integer nrhs, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real, dimension( ldxact, * ) xact, integer ldxact, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) reslts)

SGBT05

Propósito:

!>
!> SGBT05 prueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones op(A)*X = B, donde A es una
!> matriz de banda general de orden n con kl subdiagonales y ku
!> superdiagonales y op(A) = A o A**T, dependiendo de TRANS.
!>
!> RESLTS(1) = prueba del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta relación no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( NZ*EPS + (*) ), donde
!>             (*) = NZ*UNFL / (min_i (abs(op(A))*abs(X) +abs(b))_i )
!>             y NZ = número máximo de no ceros en cualquier fila de A, más 1
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A    * X = B  (Sin transposición)
!>          = 'T':  A**T * X = B  (Transposición)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>          El número de filas de las matrices X, B y XACT, y el
!>          orden de la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X, B y XACT.
!>          NRHS >= 0.
!>

AB

!>          AB es array REAL, dimension (LDAB,N)
!>          La matriz de banda original A, almacenada en las filas 1 a KL+KU+1.
!>          La j-ésima columna de A se almacena en la j-ésima columna del
!>          array AB como sigue:
!>          AB(ku+1+i-j,j) = A(i,j) para max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

B

!>          B es array REAL, dimension (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array REAL, dimension (LDX,NRHS)
!>          Los vectores de solución calculados. Cada vector se almacena como
!>          una columna de la matriz X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

XACT

!>          XACT es array REAL, dimension (LDX,NRHS)
!>          Los vectores de solución exactos. Cada vector se almacena como
!>          una columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es INTEGER
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR es array REAL, dimension (NRHS)
!>          Los límites de error hacia adelante estimados para cada vector de
!>          solución X. Si XTRUE es la solución verdadera, FERR limita la
!>          magnitud de la entrada más grande en (X - XTRUE) dividida por la
!>          magnitud de la entrada más grande en X.
!>

BERR

!>          BERR es array REAL, dimension (NRHS)
!>          El error residual de componente a componente de cada vector de
!>          solución (es decir, el cambio relativo más pequeño en cualquier
!>          entrada de A o B que hace que X sea una solución exacta).
!>

RESLTS

!>          RESLTS es array REAL, dimension (2)
!>          El máximo sobre los NRHS vectores de solución de las relaciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!>
