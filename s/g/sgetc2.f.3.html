Documentación de función/subrutina

subrutina sgetc2 (entero n, real, dimensión( lda, * ) a, entero lda, entero, dimensión( * ) ipiv, entero, dimensión( * ) jpiv, entero info)

SGETC2 calcula la factorización LU con pivoteo completo de la matriz general n por n.

Propósito:

!>
!> SGETC2 calcula una factorización LU con pivoteo completo de la
!> matriz A de n por n. La factorización tiene la forma A = P * L * U * Q,
!> donde P y Q son matrices de permutación, L es triangular inferior con
!> elementos diagonales unitarios y U es triangular superior.
!>
!> Este es el algoritmo BLAS de Nivel 2.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array REAL, de dimensión (LDA, N)
!>          En la entrada, la matriz A de n por n a factorizar.
!>          En la salida, los factores L y U de la factorización
!>          A = P*L*U*Q; los elementos diagonales unitarios de L no se almacenan.
!>          Si U(k, k) parece ser menor que SMIN, U(k, k) recibe el
!>          valor de SMIN, es decir, se da un sistema perturbado no singular.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array ENTERO, de dimensión(N).
!>          Los índices de pivote; para 1 <= i <= N, la fila i de la
!>          matriz se ha intercambiado con la fila IPIV(i).
!>

JPIV

!>          JPIV es un array ENTERO, de dimensión(N).
!>          Los índices de pivote; para 1 <= j <= N, la columna j de la
!>          matriz se ha intercambiado con la columna JPIV(j).
!>

INFO

!>          INFO es ENTERO
!>           = 0: salida exitosa
!>           > 0: si INFO = k, es probable que U(k, k) cause un desbordamiento si
!>                intentamos resolver para x en Ax = b. Por lo tanto, U se
!>                perturba para evitar el desbordamiento.
!>
