subrutina sgbrfsx (carácter trans, carácter equed, entero n, entero kl, entero ku, entero nrhs, real, dimensión( ldab, * ) ab, entero ldab, real, dimensión( ldafb, * ) afb, entero ldafb, entero, dimensión( * ) ipiv, real, dimensión( * ) r, real, dimensión( * ) c, real, dimensión( ldb, * ) b, entero ldb, real, dimensión( ldx , * ) x, entero ldx, real rcond, real, dimensión( * ) berr, entero n_err_bnds, real, dimensión( nrhs, * ) err_bnds_norm, real, dimensión( nrhs, * ) err_bnds_comp, entero nparams, real, dimensión( * ) params, real, dimensión( * ) work, entero, dimensión( * ) iwork, entero info)

SGBRFSX

Propósito:

!>
!>    SGBRFSX mejora la solución calculada de un sistema de ecuaciones
!>    lineales y proporciona cotas de error y estimaciones de error hacia
!>    atrás para la solución. Además de la cota de error normwise, el código
!>    proporciona la cota de error componente a componente máxima si es posible.
!>    Consulte los comentarios para ERR_BNDS_NORM y ERR_BNDS_COMP para
!>    detalles sobre las cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta subrutina, como se describe
!>    por los argumentos EQUED, R y C a continuación. En este caso, la
!>    solución y las cotas de error devueltas son para el sistema
!>    original no equilibrado.
!> 
!>     Algunos parámetros opcionales se agrupan en la matriz PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados
!>     son aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que el
!>     código fuente acceda al argumento PARAMS.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transpuesta)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta subrutina. Esto es necesario para calcular
!>     la solución y las cotas de error correctamente.
!>       = 'N':  Sin equilibrado
!>       = 'R':  Equilibrado de filas, es decir, A se ha premultiplicado por
!>               diag(R).
!>       = 'C':  Equilibrado de columnas, es decir, A se ha postmultiplicado
!>               por diag(C).
!>       = 'B':  Equilibrado de filas y columnas, es decir, A se ha
!>               reemplazado por diag(R) * A * diag(C).
!>               El lado derecho B se ha modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es REAL array, dimensión (LDAB,N)
!>     La matriz de banda original A, almacenada en las filas 1 a KL+KU+1.
!>     La j-ésima columna de A se almacena en la j-ésima columna de la
!>     matriz AB como sigue:
!>     AB(ku+1+i-j,j) = A(i,j) para max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal de la matriz AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es REAL array, dimensión (LDAFB,N)
!>     Detalles de la factorización LU de la matriz de banda A, tal como
!>     se calculó con SGBTRF. U se almacena como una matriz triangular superior
!>     de banda con KL+KU superdiagonales en las filas 1 a KL+KU+1, y
!>     los multiplicadores utilizados durante la factorización se almacenan en
!>     las filas KL+KU+2 a 2*KL+KU+1.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal de la matriz AFB.  LDAFB >= 2*KL*KU+1.
!>

IPIV

!>          IPIV es INTEGER array, dimensión (N)
!>     Los índices de pivote de SGETRF; para 1<=i<=N, la fila i de la
!>     matriz fue intercambiada con la fila IPIV(i).
!>

R

!>          R es REAL array, dimensión (N)
!>     Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A se
!>     multiplica por la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede. R es un argumento de entrada si FACT = 'F';
!>     de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>     Si R es una salida, cada elemento de R es una potencia de la base.
!>     Si R es una entrada, cada elemento de R debe ser una potencia de la base
!>     para asegurar una solución y estimaciones de error fiables. El escalado por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado sea subdesbordamiento o desbordamiento. Los errores de redondeo
!>     durante el escalado conducen a un refinamiento con una matriz que no es
!>     equivalente a la matriz de entrada, produciendo estimaciones de error que
!>     pueden no ser fiables.
!>

C

!>          C es REAL array, dimensión (N)
!>     Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A se
!>     multiplica por la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede. C es un argumento de entrada si FACT = 'F';
!>     de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>     Si C es una salida, cada elemento de C es una potencia de la base.
!>     Si C es una entrada, cada elemento de C debe ser una potencia de la base
!>     para asegurar una solución y estimaciones de error fiables. El escalado por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado sea subdesbordamiento o desbordamiento. Los errores de redondeo
!>     durante el escalado conducen a un refinamiento con una matriz que no es
!>     equivalente a la matriz de entrada, produciendo estimaciones de error que
!>     pueden no ser fiables.
!>

B

!>          B es REAL array, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal de la matriz B.  LDB >= max(1,N).
!>

X

!>          X es REAL array, dimensión (LDX,NRHS)
!>     En la entrada, la matriz solución X, tal como la calculó SGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal de la matriz X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Condición recíproca escalada. Esta es una estimación del
!>     número de condición de Skeel recíproco de la matriz A después
!>     del equilibrado (si se realizó). Si este valor es menor que la
!>     precisión de la máquina (en particular, si es cero), la matriz es singular
!>     para la precisión de trabajo. Tenga en cuenta que el error puede ser
!>     aún pequeño incluso si este número

NAME

sgbrfsx

enhanced real general band matrix iterative refinement routines

SYNOPSIS

SUBROUTINE SG BRFSX(
     UPLO, TRANSPOSE, DIAG,
     N, NRHS, KBLAS, KBACH,
     AB, LDAB, B, LDB,
     X, LDX, FERR, BERR,
     N_ERR_BNDS, ERR_BNDS_NORM, ERR_BNDS_COMP,
     NPARAMS, PARAMS,
     WORK, IWORK, INFO )
CHARACTER(LEN=1) :: UPLO, TRANSPOSE, DIAG
INTEGER :: N, NRHS, KBLAS, KBACH, LDAB, LDB, LDX, N_ERR_BNDS, NPARAMS, INFO
REAL :: AB( LDAB, * ), B( LDB, * ), X( LDX, * ), FERR( * ), BERR( * ), ERR_BNDS_NORM( NRHS, * ), ERR_BNDS_COMP( NRHS, * ), PARAMS( * )
INTEGER :: IWORK( * )
REAL :: WORK( * )

Function/Subroutine Documentation

SG BRFSX performs iterative refinement operations for a general band matrix problem.

It solves the system of linear equations AB*X = B, AB*X = B, or AB**T*X = B, where:

  • AB is a real general band matrix of order N with KBLAS subdiagonals and KBACH superdiagonals.
  • B is a real matrix of order N x NRHS.
  • X is a real matrix of order N x NRHS.

It returns the solution X, and error bounds on the accuracy of the solutions.

The routine uses a factorization of AB computed by SGBTRF(3) (not given here), and it uses iterative refinement to improve the computed solution.

The error bounds provided are normwise and componentwise relative error bounds.

Arguments

UPLO

    UPLO is CHARACTER*1
    Specifies whether the matrix AB is upper or lower triangular banded.
    = 'U': AB is upper triangular banded.
    = 'L': AB is lower triangular banded.

TRANSPOSE

    TRANSPOSE is CHARACTER*1
    Specifies the form of the system of equations:
    = 'N': Solve A*X = B, if UPLO = 'U'; solve A**T*X = B, if UPLO = 'L'.
    = 'T': Solve A**T*X = B, if UPLO = 'U'; solve A*X = B, if UPLO = 'L'.
    = 'C': Equivalent to 'T' for real matrices.

DIAG

    DIAG is CHARACTER*1
    Specifies whether or not the matrix is upper or lower triangular banded
    and a condition on the diagonal elements.
    = 'U': AB is upper triangular banded and the diagonal elements of the
           upper triangular banded matrix are assumed to be 1.0.
    = 'N': AB is upper or lower triangular banded and the diagonal elements
           of the upper or lower triangular banded matrix are not assumed to be 1.0.

N

    N is INTEGER
    The order of the matrix AB.  N >= 0. If N = 0, the routine does nothing.

NRHS

    NRHS is INTEGER
    The number of right hand sides, i.e., the number of columns of the
    matrices B and X. NRHS >= 0.

KBLAS

    KBLAS is INTEGER
    The number of subdiagonals within the band of AB. KBLAS >= 0.

KBACH

    KBACH is INTEGER
    The number of superdiagonals within the band of AB. KBACH >= 0.

AB

    AB is REAL array, dimension (LDAB, N)
    On entry, the N x N band matrix AB. The column index is assumed to be the
    linear index running from left to right. The row index is assumed to be
    the linear index running from top to bottom. The band matrix is stored in
    such a way that AB(j,k) is stored in the entry AB(kblase+1-j+k, k) for
    UPLO = 'U' and AB(j,k) is stored in the entry AB(j-kbach+1,k) for
    UPLO = 'L'.

LDAB

    LDAB is INTEGER
    The leading dimension of the array AB. LDAB >= KBLAS + KBACH + 1.

B

    B is REAL array, dimension (LDB, NRHS)
    On entry, the right hand side matrix B.
    On exit, B has been overwritten.

LDB

    LDB is INTEGER
    The leading dimension of the array B. LDB >= max(N,NRHS).

X

    X is REAL array, dimension (LDX, NRHS)
    On exit, if INFO = 0, X contains the solution matrix X to the system of
    equations. This solution may be highly accurate. See the discussion of
    BERR and FERR below.

LDX

    LDX is INTEGER
    The leading dimension of the array X. LDX >= max(N,NRHS).

FERR

    FERR is REAL array, dimension (NRHS)
    On exit, FERR(j) is an estimate of the relative forward error in the
    j-th solution vector X(*,j), and is computed at only the coarse grid
    level. This estimate is computed without the benefit of iterative
    refinement. FERR(j) is computed by forming the residual R = B - A*X in
    double precision and then dividing by the scaling factor used in the
    normwise error computation. FERR(j) is only defined if INFO = 0.

BERR

    BERR is REAL array, dimension (NRHS)
    Componentwise relative backward error. This is the
    componentwise relative backward error of each solution vector X(j)
    (i.e., the smallest relative change in any element of A or B that
    makes X(j) an exact solution).

N_ERR_BNDS

    N_ERR_BNDS is INTEGER
    Number of error bounds to return for each right hand side
    and each type (normwise or componentwise). See ERR_BNDS_NORM and
    ERR_BNDS_COMP below.

ERR_BNDS_NORM

    ERR_BNDS_NORM is REAL array, dimension (NRHS, N_ERR_BNDS)
    For each right-hand side, this array contains information about
    various error bounds and condition numbers corresponding to the
    normwise relative error, which is defined as follows:

    Normwise relative error in the ith solution vector:
            max_j (abs(XTRUE(j,i) - X(j,i)))
           ------------------------------
                 max_j abs(X(j,i))

    The array is indexed by the type of error information as described
    below. There currently are up to three pieces of information
    returned.

    The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
    right-hand side.

    The second index in ERR_BNDS_NORM(:,err) contains the following
    three fields:
    err = 1  boolean. Trust the answer if the
             reciprocal condition number is less than the threshold
             sqrt(n) * slamch('Epsilon').

    err = 2  error bound: The estimated forward error,
             almost certainly within a factor of 10 of the true error
             so long as the next entry is greater than the threshold
             sqrt(n) * slamch('Epsilon'). This error bound should only
             be trusted if the previous boolean is true.

    err = 3  Reciprocal condition number: Estimated normwise
             reciprocal condition number.  Compared with the threshold
             sqrt(n) * slamch('Epsilon') to determine if the error
             estimate is . These reciprocal condition
             numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
             appropriately scaled matrix Z.
             Let Z = S*A, where S scales each row by a power of the
             radix so all absolute row sums of Z are approximately 1.

    See Lapack Working Note 165 for further details and extra
    cautions.

ERR_BNDS_COMP

    ERR_BNDS_COMP is REAL array, dimension (NRHS, N_ERR_BNDS)
    For each right-hand side, this array contains information about
    various error bounds and condition numbers corresponding to the
    componentwise relative error, which is defined as follows:

    Componentwise relative error in the ith solution vector:
                   abs(XTRUE(j,i) - X(j,i))
            max_j ----------------------
                        abs(X(j,i))

    The array is indexed by the right-hand side i (on which the
    componentwise relative error depends), and the type of error
    information as described below. There currently are up to three
    pieces of information returned for each right-hand side. If
    componentwise accuracy is not requested (PARAMS(3) = 0.0), then
    ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
    the first (:,N_ERR_BNDS) entries are returned.

    The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
    right-hand side.

    The second index in ERR_BNDS_COMP(:,err) contains the following
    three fields:
    err = 1  boolean. Trust the answer if the
             reciprocal condition number is less than the threshold
             sqrt(n) * slamch('Epsilon').

    err = 2  error bound: The estimated forward error,
             almost certainly within a factor of 10 of the true error
             so long as the next entry is greater than the threshold
             sqrt(n) * slamch('Epsilon'). This error bound should only
             be trusted if the previous boolean is true.

    err = 3  Reciprocal condition number: Estimated componentwise
             reciprocal condition number.  Compared with the threshold
             sqrt(n) * slamch('Epsilon') to determine if the error
             estimate is . These reciprocal condition
             numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
             appropriately scaled matrix Z.
             Let Z = S*(A*diag(x)), where x is the solution for the
             current right-hand side and S scales each row of
             A*diag(x) by a power of the radix so all absolute row
             sums of Z are approximately 1.

    See Lapack Working Note 165 for further details and extra
    cautions.

NPARAMS

    NPARAMS is INTEGER
    Specifies the number of parameters set in PARAMS.  If <= 0, the
    PARAMS array is never referenced and default values are used.

PARAMS

    PARAMS is REAL array, dimension NPARAMS
    Specifies algorithm parameters.  If an entry is < 0.0, then
    that entry will be filled with default value used for that
    parameter.  Only positions up to NPARAMS are accessed; defaults
    are used for higher-numbered parameters.

      PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
           refinement or not.
        Default: 1.0
           = 0.0:  No refinement is performed, and no error bounds are
                   computed.
           = 1.0:  Use the double-precision refinement algorithm,
                   possibly with doubled-single computations if the
                   compilation environment does not support DOUBLE
                   PRECISION.
             (other values are reserved for future use)

      PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
           computations allowed for refinement.
        Default: 10
         Aggressive: Set to 100 to permit convergence using approximate
                     factorizations or factorizations other than LU. If
                     the factorization uses a technique other than
                     Gaussian elimination, the guarantees in
                     err_bnds_norm and err_bnds_comp may no longer be
                     trustworthy.

      PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
           will attempt to find a solution with small componentwise
           relative error in the double-precision algorithm.  Positive
           is true, 0.0 is false.
        Default: 1.0 (attempt componentwise convergence)

WORK

    WORK is REAL array, dimension (4*N)

IWORK

    IWORK is INTEGER array, dimension (N)

INFO

    INFO is INTEGER
      = 0:  Successful exit. The solution to every right-hand side is
        guaranteed.
      < 0:  If INFO = -i, the i-th argument had an illegal value
      > 0 and <= N:  U(INFO,INFO) is exactly zero.  The factorization
        has been completed, but the factor U is exactly singular, so
        the solution and error bounds could not be computed. RCOND = 0
        is returned.
      = N+J: The solution corresponding to the Jth right-hand side is
        not guaranteed. The solutions corresponding to other right-
        hand sides K with K > J may not be guaranteed as well, but
        only the first such right-hand side is reported. If a small
        componentwise error is not requested (PARAMS(3) = 0.0) then
        the Jth right-hand side is the first with a normwise error
        bound that is not guaranteed (the smallest J such
        that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
        the Jth right-hand side is the first with either a normwise or
        componentwise error bound that is not guaranteed (the smallest
        J such that either ERR_BNDS_NORM(J,1) = 0.0 or
        ERR_BNDS_COMP(J,1) = 0.0). See the definition of
        ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
        about all of the right-hand sides check ERR_BNDS_NORM or
        ERR_BNDS_COMP.
