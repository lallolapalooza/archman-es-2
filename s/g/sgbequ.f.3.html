SGBEQU

Documentación de Función/Subrutina

subrutina sgbequ (integer m, integer n, integer kl, integer ku, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) r, real, dimension( * ) c, real rowcnd, real colcnd, real amax, integer info)

SGBEQU

Propósito:

!>
!> SGBEQU calcula los escalados de fila y columna destinados a equilibrar una
!> matriz de banda M por N, A, y reducir su número de condición. R devuelve los
!> factores de escala de fila y C los factores de escala de columna, elegidos para intentar
!> que el elemento más grande de cada fila y columna de la matriz B, con
!> elementos B(i,j)=R(i)*A(i,j)*C(j), tenga valor absoluto 1.
!>
!> R(i) y C(j) están restringidos a estar entre SMLNUM = número seguro más pequeño
!> y BIGNUM = número seguro más grande. El uso de estos factores de escala
!> no garantiza la reducción del número de condición de A, pero
!> funciona bien en la práctica.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A. KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A. KU >= 0.
!>

AB

!>          AB es array REAL, dimension (LDAB,N)
!>          La matriz de banda A, almacenada en las filas 1 a KL+KU+1. La columna j
!>          de A se almacena en la columna j del array AB como
!>          sigue:
!>          AB(ku+1+i-j,j) = A(i,j) para max(1,j-ku) <= i <= min(m,j+kl).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB. LDAB >= KL+KU+1.
!>

R

!>          R es array REAL, dimension (M)
!>          Si INFO = 0, o INFO > M, R contiene los factores de escala de fila
!>          para A.
!>

C

!>          C es array REAL, dimension (N)
!>          Si INFO = 0, C contiene los factores de escala de columna para A.
!>

ROWCND

!>          ROWCND es REAL
!>          Si INFO = 0 o INFO > M, ROWCND contiene la relación del
!>          R(i) más pequeño con el R(i) más grande. Si ROWCND >= 0.1 y
!>          AMAX no es ni demasiado grande ni demasiado pequeño, no vale la pena
!>          escalar con R.
!>

COLCND

!>          COLCND es REAL
!>          Si INFO = 0, COLCND contiene la relación del
!>          C(i) más pequeño con el C(i) más grande. Si COLCND >= 0.1, no vale la pena
!>          escalar con C.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto del elemento de matriz más grande. Si AMAX está muy
!>          cerca del desbordamiento o muy cerca de la subfuente, la matriz
!>          debería escalarse.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= M:  la i-ésima fila de A es exactamente cero
!>                >  M:  la (i-M)-ésima columna de A es exactamente cero
!>
