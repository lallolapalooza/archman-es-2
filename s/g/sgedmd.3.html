SGEDMD calcula la Descomposición de Modos Dinámicos (DMD) para un par de matrices de instantáneas de datos.

Propósito:

!>    SGEDMD calcula la Descomposición de Modos Dinámicos (DMD) para
!>    un par de matrices de instantáneas de datos. Para las matrices
!>    de entrada X e Y tales que Y = A*X con una matriz A inaccesible,
!>    SGEDMD calcula un cierto número de pares de Ritz de A utilizando
!>    la extracción estándar de Rayleigh-Ritz de un subespacio
!>    de range(X) que se determina utilizando los vectores singulares
!>    izquierdos principales de X. Opcionalmente, SGEDMD devuelve los
!>    residuos de los pares de Ritz calculados, la información necesaria
!>    para un refinamiento de los vectores de Ritz, o los vectores propios de
!>    la DMD Exacta.
!>    Para más detalles véanse las referencias a continuación. Para más
!>    detalles de la implementación véase [3].
!>

!>    Las K entradas principales (K<=N) de REIG contienen
!>    las partes reales de los valores propios calculados
!>    REIG(1:K) + sqrt(-1)*IMEIG(1:K).
!>    Ver las descripciones de K, IMEIG y Z.
!>

IMEIG

!>    IMEIG (salida) REAL(KIND=WP) matriz N por 1
!>    Las K entradas principales (K<=N) de IMEIG contienen
!>    las partes imaginarias de los valores propios calculados
!>    REIG(1:K) + sqrt(-1)*IMEIG(1:K).
!>    Los valores propios se determinan como sigue:
!>    Si IMEIG(i) == 0, entonces el valor propio correspondiente es
!>    real, LAMBDA(i) = REIG(i).
!>    Si IMEIG(i)>0, entonces el par conjugado complejo
!>    de valores propios es
!>    LAMBDA(i)   = REIG(i) + sqrt(-1)*IMAG(i)
!>    LAMBDA(i+1) = REIG(i) - sqrt(-1)*IMAG(i)
!>    Es decir, los pares conjugados complejos tienen índices
!>    consecutivos (i,i+1), con la parte imaginaria positiva
!>    listada primero.
!>    Ver las descripciones de K, REIG y Z.
!>

Z

!>    Z (espacio de trabajo/salida) REAL(KIND=WP) matriz M por N
!>    Si JOBZ =='V' entonces
!>       Z contiene vectores de Ritz reales como sigue:
!>       Si IMEIG(i)=0, entonces Z(:,i) es un vector propio de
!>       el i-ésimo valor de Ritz; ||Z(:,i)||_2=1.
!>       Si IMEIG(i) > 0 (y IMEIG(i+1) < 0) entonces
!>       [Z(:,i) Z(:,i+1)] abarcan un subespacio invariante y
!>       los valores de Ritz extraídos de este subespacio son
!>       REIG(i) + sqrt(-1)*IMEIG(i) y
!>       REIG(i) - sqrt(-1)*IMEIG(i).
!>       Los vectores propios correspondientes son
!>       Z(:,i) + sqrt(-1)*Z(:,i+1) y
!>       Z(:,i) - sqrt(-1)*Z(:,i+1), respectivamente.
!>       || Z(:,i:i+1)||_F = 1.
!>    Si JOBZ == 'F', entonces las descripciones anteriores se aplican a
!>    las columnas de X(:,1:K)*W(1:K,1:K), donde las columnas
!>    de W(1:k,1:K) son los vectores propios calculados del
!>    cociente de Rayleigh K-por-K. Las columnas de W(1:K,1:K)
!>    tienen una estructura similar: Si IMEIG(i) == 0 entonces
!>    X(:,1:K)*W(:,i) es un vector propio, y si IMEIG(i)>0
!>    entonces X(:,1:K)*W(:,i)+sqrt(-1)*X(:,1:K)*W(:,i+1) y
!>         X(:,1:K)*W(:,i)-sqrt(-1)*X(:,1:K)*W(:,i+1)
!>    son los vectores propios de LAMBDA(i), LAMBDA(i+1).
!>    Ver las descripciones de REIG, IMEIG, X y W.
!>

LDZ

!>    LDZ (entrada) INTEGER , LDZ >= M
!>    La dimensión principal de la matriz Z.
!>

RES

!>    RES (salida) REAL(KIND=WP) matriz N por 1
!>    RES(1:K) contiene los residuos para los K pares de Ritz calculados.
!>    Si LAMBDA(i) es real, entonces
!>       RES(i) = || A * Z(:,i) - LAMBDA(i)*Z(:,i))||_2.
!>    Si [LAMBDA(i), LAMBDA(i+1)] es un par conjugado complejo
!>    entonces
!>    RES(i)=RES(i+1) = || A * Z(:,i:i+1) - Z(:,i:i+1) *B||_F
!>    donde B = [ real(LAMBDA(i)) imag(LAMBDA(i)) ]
!>              [-imag(LAMBDA(i)) real(LAMBDA(i)) ].
!>    Se cumple que
!>    RES(i)   = || A*ZC(:,i)   - LAMBDA(i)  *ZC(:,i)   ||_2
!>    RES(i+1) = || A*ZC(:,i+1) - LAMBDA(i+1)*ZC(:,i+1) ||_2
!>    donde ZC(:,i)   =  Z(:,i) + sqrt(-1)*Z(:,i+1)
!>          ZC(:,i+1) =  Z(:,i) - sqrt(-1)*Z(:,i+1)
!>    Ver la descripción de REIG, IMEIG y Z.
!>

B

!>    B (salida) REAL(KIND=WP) matriz M por N.
!>    SI JOBF =='R', B(1:M,1:K) contiene A*U(:,1:K), y puede
!>    ser usado para calcular los vectores refinados; ver más
!>    detalles en las referencias proporcionadas.
!>    Si JOBF == 'E', B(1:M,1;K) contiene
!>    A*U(:,1:K)*W(1:K,1:K), que son los vectores de

NAME

        
sgedmd - routine to compute the singular value decomposition (SVD) of a
            real matrix X.

    

    

        
SYNOPSIS

        
      SUBROUTINE SGEDMD ( JOBX, JOBY, JOBU, JOBV, M, N, X, LDX, Y, LDY,
     $                       A, LDA, B, LDB, TOL, INFO )
      CHARACTER*1     JOBX, JOBY, JOBU, JOBV
      INTEGER         M, N, LDX, LDY, LDA, LDB, INFO
      REAL            X( LDX, * ), Y( LDY, * ), A( LDA, * ), B( LDB, * ),
     $                TOL

    

    

        
Function/Subroutine Documentation

        
This routine is designed to compute the SVD of a general
            real matrix X, and possibly its SVD based on the generalized
            eigenvalue problem (GEP). The routine can compute:

        
    
            
  • the singular values of X.
    • 
            
  • the singular values and the right singular vectors of X.
    • 
            
  • the singular values and the left singular vectors of X.
    • 
            
  • the singular values and the singular vectors of X.
    • 
            
  • the singular values of X based on the GEP:
                
                A*x = lambda*B*x
    
                where A and B are n x n matrices, and lambda are the
                eigenvalues.
    • 
            
  • the singular values of X based on the GEP:
                
                A*x = lambda*B*x
    
                and the right singular vectors of X.
    • 
            
  • the singular values of X based on the GEP:
                
                A*x = lambda*B*x
    
                and the left singular vectors of X.
    • 
            
  • the singular values of X based on the GEP:
                
                A*x = lambda*B*x
    
                and the singular vectors of X.
    • 
        

        
The input matrix X is of size m x n.

        
The generalized eigenvalue problem requires that both A and B
            are square matrices of the same size.

        
The routine implements the algorithm described in:

Report #7

        
This routine is part of the LAPACK routines for solving
            generalized eigenvalue problems.

        
The routine computes the singular value decomposition (SVD)
            of a real matrix X. The SVD is a factorization of the form

        
        X = U * S * V^T
        

        
where U is an m x m orthogonal matrix, S is an m x n
            rectangular diagonal matrix with non-negative real numbers
            sigma_i on the diagonal, and V is an n x n orthogonal matrix. The
            diagonal entries sigma_i are the singular values of X.

        
The routine can also compute the singular values based on
            the generalized eigenvalue problem (GEP):

        
        A*x = lambda*B*x
        

        
where A and B are m x n matrices, and lambda are the
            eigenvalues.

        
The routine implements the algorithm described in:

        
        Z. Drmac and K. R. Musaelian. Improved computations of
        generalized singular value decomposition. ACM Trans. Math.
        Softw., 45(1):1-23, 2019.
        

        
The computation of singular values is based on QR decomposition
            methods.

        
The computation of singular vectors is based on the implicit
            double-shift QR algorithm.

        
The routine follows the LAPACK interface conventions.
