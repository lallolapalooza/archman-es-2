svc_getcaller(3)

rpc(3) Manual de funciones de biblioteca rpc(3)

NOMBRE

rpc - rutinas de biblioteca para llamadas a procedimientos remotos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS Y DESCRIPCION

Estas rutinas permiten a los programas C realizar llamadas a procedimientos en otras máquinas a través de la red. Primero, el cliente llama a un procedimiento para enviar un paquete de datos al servidor. Al recibir el paquete, el servidor llama a una rutina de distribución para realizar el servicio solicitado y luego envía una respuesta. Finalmente, la llamada al procedimiento retorna al cliente.

Para utilizar estas rutinas, incluya el archivo de cabecera <rpc/rpc.h>.

Los prototipos a continuación utilizan los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;
typedef typeof(bool_t (caddr_t resp, struct sockaddr_in *raddr)
    *resultproc_t;

Consulte los archivos de cabecera para ver las declaraciones de los tipos AUTH, CLIENT, SVCXPRT y XDR.

void auth_destroy(AUTH *auth);
Una macro que destruye la información de autenticación asociada con auth. La destrucción generalmente implica la desasignación de estructuras de datos privadas. El uso de auth no está definido después de llamar a auth_destroy().
AUTH *authnone_create(void);
Crea y devuelve un manejador de autenticación RPC que pasa información de autenticación no utilizable con cada llamada a procedimiento remoto. Esta es la autenticación predeterminada utilizada por RPC.
AUTH *authunix_create(char *host, uid_t uid, gid_t gid,
                      int n, gid_t aup_gids[n]);
Crea y devuelve un manejador de autenticación RPC que contiene información de autenticación. El parámetro host es el nombre de la máquina en la que se creó la información; uid es el ID de usuario del usuario; gid es el ID de grupo actual del usuario; n y aup_gids se refieren a una matriz contada de grupos a los que pertenece el usuario. Es fácil suplantar a un usuario.
AUTH *authunix_create_default(void);
Llama a authunix_create() con los parámetros apropiados.
int callrpc(char *host, unsigned long prognum,
            unsigned long versnum, unsigned long procnum,
            xdrproc_t inproc, const char *in,
            xdrproc_t outproc, char *out);
Llama al procedimiento remoto asociado con prognum, versnum y procnum en la máquina, host. El parámetro in es la dirección de los argumentos del procedimiento y out es la dirección donde colocar los resultados; inproc se utiliza para codificar los parámetros del procedimiento y outproc se utiliza para decodificar los resultados del procedimiento. Esta rutina devuelve cero si tiene éxito, o el valor de enum clnt_stat convertido a entero si falla. La rutina clnt_perrno() es útil para traducir estados de error a mensajes.
Advertencia: llamar a procedimientos remotos con esta rutina utiliza UDP/IP como transporte; consulte clntudp_create() para conocer las restricciones. No tiene control sobre los tiempos de espera o la autenticación utilizando esta rutina.
enum clnt_stat clnt_broadcast(unsigned long prognum,
                     unsigned long versnum, unsigned long procnum,
                     xdrproc_t inproc, char *in,
                     xdrproc_t outproc, char *out,
                     resultproc_t eachresult);
Similar a callrpc(), excepto que el mensaje de llamada se difunde a todas las redes de difusión conectadas localmente. Cada vez que recibe una respuesta, esta rutina llama a eachresult(), cuya forma es:

eachresult(char *out, struct sockaddr_in *addr);

donde out es el mismo que out pasado a clnt_broadcast(), excepto que la salida del procedimiento remoto se decodifica allí; addr apunta a la dirección de la máquina que envió los resultados. Si eachresult() devuelve cero, clnt_broadcast() espera más respuestas; de lo contrario, retorna con el estado apropiado.
Advertencia: los sockets de difusión están limitados en tamaño a la unidad de transferencia máxima del enlace de datos. Para ethernet, este valor es de 1500 bytes.
enum clnt_stat clnt_call(CLIENT *clnt, unsigned long procnum,
                    xdrproc_t inproc, char *in,
                    xdrproc_t outproc, char *out,
                    struct timeval tout);
Una macro que llama al procedimiento remoto procnum asociado con el manejador del cliente, clnt, que se obtiene con una rutina de creación de cliente RPC como clnt_create(). El parámetro in es la dirección de los argumentos del procedimiento y out es la dirección donde colocar los resultados; inproc se utiliza para codificar los parámetros del procedimiento y outproc se utiliza para decodificar los resultados del procedimiento; tout es el tiempo permitido para que vuelvan los resultados.
clnt_destroy(CLIENT *clnt);
Una macro que destruye el manejador RPC del cliente. La destrucción generalmente implica la desasignación de estructuras de datos privadas, incluido el propio clnt. El uso de clnt no está definido después de llamar a clnt_destroy(). Si la biblioteca RPC abrió el socket asociado, también lo cerrará. De lo contrario, el socket permanecerá abierto.
CLIENT *clnt_create(const char *host, unsigned long prog,
                    unsigned long vers, const char *proto);
Rutina genérica de creación de cliente. host identifica el nombre del host remoto donde se encuentra el servidor. proto indica qué tipo de protocolo de transporte se va a utilizar. Los valores actualmente admitidos para este campo son "udp" y "tcp". Se establecen tiempos de espera predeterminados, pero se pueden modificar utilizando clnt_control().
Advertencia: usar UDP tiene sus inconvenientes. Dado que los mensajes RPC basados en UDP solo pueden contener hasta 8 Kbytes de datos codificados, este transporte no se puede utilizar para procedimientos que aceptan argumentos grandes o devuelven resultados enormes.
bool_t clnt_control(CLIENT *cl, int req, char *info);
Una macro utilizada para cambiar o recuperar información diversa sobre un objeto cliente. req indica el tipo de operación y info es un puntero a la información. Tanto para UDP como para TCP, los valores admitidos de req y sus tipos de argumento y lo que hacen son:

CLSET_TIMEOUT  struct timeval // establecer tiempo de espera total
CLGET_TIMEOUT  struct timeval // obtener tiempo de espera total

Nota: si establece el tiempo de espera usando clnt_control(), el parámetro de tiempo de espera pasado a clnt_call() se ignorará en todas las llamadas futuras.

CLGET_SERVER_ADDR  struct sockaddr_in
                // obtener la dirección del servidor

Las siguientes operaciones son válidas solo para UDP:

CLSET_RETRY_TIMEOUT  struct timeval // establecer el tiempo de espera de reintento
CLGET_RETRY_TIMEOUT  struct timeval // obtener el tiempo de espera de reintento

El tiempo de espera de reintento es el tiempo que "UDP RPC" espera la respuesta del servidor antes de retransmitir la solicitud.
clnt_freeres(CLIENT * clnt, xdrproc_t outproc, char *out);
Una macro que libera cualquier dato asignado por el sistema RPC/XDR al decodificar los resultados de una llamada RPC. El parámetro out es la dirección de los resultados y outproc es la rutina XDR que describe los resultados. Esta rutina devuelve uno si los resultados se liberaron correctamente y cero en caso contrario.
void clnt_geterr(CLIENT *clnt, struct rpc_er
Una macro que copia el estado de error asociado con el manejador de cliente clnt en la estructura de datos errnum.
void clnt_perrno(int errno);
Una macro que imprime un mensaje de error en la salida estándar de errores que corresponde a la entrada de error RPC errno.
void clnt_perror(CLIENT *clnt, char *s);
Una macro que imprime el mensaje de error asociado con el manejador de cliente clnt en la salida estándar de errores. El parámetro s es una cadena de caracteres que se imprime antes del mensaje de error.
enum clnt_stat clntraw_create(unsigned long prognum,
                       unsigned long versnum, unsigned long procnum,
                       xdrproc_t xdrto, xdrproc_t xdrfrom);
Rutina de creación de cliente para la versión UDP de RPC. Esta rutina es similar a clnt_create() pero utiliza xdrto para codificar los argumentos y xdrfrom para decodificar los resultados.
enum clnt_stat clnttcp_create(struct hostent *h, unsigned long prognum,
                       unsigned long versnum, struct timeval *timeoutp,
                       int *sockp, unsigned long sndsz,
                       unsigned long rcvsze);
Crea un manejador de cliente RPC que utiliza TCP como transporte. h es la estructura hostent para el host remoto; prognum es el número de programa del servidor; versnum es el número de versión del servidor; timeoutp es un puntero a la estructura timeval para el tiempo de espera total de la llamada; sockp es un puntero a un entero que contiene un socket abierto o NULL si se debe crear uno nuevo; sndsz es el tamaño del búfer de envío; rcvsze es el tamaño del búfer de recepción.
enum clnt_stat clntudp_create(struct hostent *h, unsigned long prognum,
                       unsigned long versnum, struct timeval *timeoutp,
                       int *sockp, unsigned long sndsz,
                       unsigned long rcvsze);
Crea un manejador de cliente RPC que utiliza UDP como transporte. Los parámetros son los mismos que para clnttcp_create().
CLIENT *clntudp_bufcreate(struct hostent *h, unsigned long prognum,
                        unsigned long versnum, struct timeval *timeoutp,
                        int *sockp, unsigned long sendsz,
                        unsigned long recvsz);
Similar a clntudp_create(), pero le permite especificar los tamaños de los búferes de envío y recepción.
void clntunix_create(char *path, unsigned long prognum,
                    unsigned long versnum, xdrproc_t inproc,
                    char *in, xdrproc_t outproc, char *out);
Crea un manejador de cliente RPC que utiliza un socket de dominio UNIX como transporte. path es la ruta del socket del servidor.
int registerrpc(unsigned long prognum, unsigned long versnum,
                unsigned long procnum, char *procname,
                xdrproc_t inproc, char *in,
                xdrproc_t outproc, char *out);
Registra una rutina de servidor RPC. prognum, versnum y procnum identifican la rutina; procname es el nombre de la rutina; inproc y outproc son las rutinas XDR para codificar/decodificar argumentos y resultados.
int svc_register(SVCXPRT *transp, unsigned long prognum,
                 unsigned long versnum, xdrproc_t dispatch,
                 unsigned long timeout);
Registra un procedimiento dispatch para el programa RPC prognum versión versnum en el transporte transp. El argumento timeout especifica el tiempo de espera en segundos antes de que el servidor reintente enviar una respuesta en caso de que el cliente no acuse recibo.
void svc_run(void);
Bucle principal del servidor RPC. Esta rutina nunca retorna, sino que espera las solicitudes entrantes y las despacha a los procedimientos registrados.
void svc_unregister(unsigned long prognum, unsigned long versnum);
Anula el registro de un programa RPC registrado previamente.
SVCXPRT *svctcp_create(int sock, unsigned long recvsize,
                      unsigned long sendsize);
Crea un manejador de servidor RPC que utiliza TCP como transporte. sock es el descriptor de archivo del socket en el que se está escuchando; recvsize y sendsize especifican los tamaños de los búferes de recepción y envío.
SVCXPRT *svcfd_create(int fd, unsigned long recvsize,
                     unsigned long sendsize);
Crea un manejador de servidor RPC utilizando el descriptor de archivo fd como transporte. Esto es útil para crear servidores RPC en sistemas que no utilizan sockets TCP o UDP estándar, como pipes nombrados.
SVCXPRT *svcudp_bufcreate(int sock, unsigned long recvsize,
                         unsigned long sendsz);
Crea un manejador de servidor RPC que utiliza UDP como transporte. sock es el descriptor de archivo del socket en el que se está escuchando; recvsize y sendsz especifican los tamaños de los búferes de recepción y envío.
SVCXPRT *svcudp_create(int sock);
Crea un manejador de servidor RPC que utiliza UDP como transporte. sock es el descriptor de archivo del socket en el que se está escuchando.
SVCXPRT *svcunix_create(int sock);
Crea un manejador de servidor RPC que utiliza un socket de dominio UNIX como transporte. sock es el descriptor de archivo del socket en el que se está escuchando.
void xdr_admin(XDR *xdrs, bool_t (*func)(char *, char *),
              char *data);
Establece la función de administración para la rutina XDR. Esto se usa comúnmente para la codificación/decodificación de estructuras de datos complejas.
bool_t xdr_array(XDR *xdrs, char ***fp, unsigned int *size,
                unsigned int maxsize, xdrproc_t xdr_element,
                xdrproc_t xdr_subarray);
Rutina XDR para codificar/decodificar matrices de tamaño variable. fp apunta a un puntero a la matriz; size apunta al tamaño actual de la matriz; maxsize es el tamaño máximo permitido de la matriz; xdr_element es la rutina XDR para los elementos individuales; xdr_subarray se usa para rutinas XDR anidadas.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Rutina XDR para codificar/decodificar un booleano.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *size,
                unsigned int maxsize);
Rutina XDR para codificar/decodificar una cadena de bytes de tamaño fijo.
bool_t xdr_char(XDR *xdrs, char *c);
Rutina XDR para codificar/decodificar un carácter.
bool_t xdr_double(XDR *xdrs, double *dp);
Rutina XDR para codificar/decodificar un número de punto flotante de doble precisión.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Rutina XDR para codificar/decodificar un tipo de enumeración.
void xdr_free(xdrproc_t proc, char *ptr);
Libera la memoria asignada por la rutina XDR proc para la estructura apuntada por ptr. Esto es esencial para evitar fugas de memoria.
bool_t xdr_float(XDR *xdrs, float *fp);
Rutina XDR para codificar/decodificar un número de punto flotante de precisión simple.
bool_t xdr_int(XDR *xdrs, int *ip);
Rutina XDR para codificar/decodificar un entero de 32 bits.
bool_t xdr_long(XDR *xdrs, long *lp);
Rutina XDR para codificar/decodificar un entero largo.
bool_t xdr_longlong_int(XDR *xdrs, long long *llp);
Rutina XDR para codificar/decodificar un entero largo largo (64 bits).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Rutina XDR para codificar/decodificar un bloque de bytes opacos.
bool_t xdr_pointer(XDR *xdrs, char ***pp, unsigned int size,
                  xdrproc_t xdr_element);
Rutina XDR para codificar/decodificar punteros. pp apunta a un puntero al objeto; size es el tamaño del objeto; xdr_element es la rutina XDR para el objeto apuntado.
bool_t xdr_reference(XDR *xdrs, char ***pp, unsigned int size,
                    xdrproc_t xdr_element);
Similar a xdr_pointer(), pero se utiliza para codificar/decodificar referencias a objetos en lugar de punteros.
bool_t xdr_short(XDR *xdrs, short *sp);
Rutina XDR para codificar/decodificar un entero corto.
bool_t xdr_string(XDR *xdrs, char ***sp, unsigned int maxsize);
Rutina XDR para codificar/decodificar una cadena de caracteres terminada en nulo. sp apunta a un puntero a la cadena; maxsize es el tamaño máximo permitido de la cadena.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Rutina XDR para codificar/decodificar un carácter sin signo.
bool_t xdr_u_int(XDR *xdrs, unsigned int *uip);
Rutina XDR para codificar/decodificar un entero sin signo de 32 bits.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Rutina XDR para codificar/decodificar un entero largo sin signo.
bool_t xdr_u_longlong_int(XDR *xdrs, unsigned long long *ullp);
Rutina XDR para codificar/decodificar un entero largo largo sin signo (64 bits).
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Rutina XDR para codificar/decodificar un entero corto sin signo.
bool_t xdr_union(XDR *xdrs, enum_t **dest, char **addr,
                union switch_t *switch_list,
                bool_t (*defaulted)(XDR *, char *));
Rutina XDR para codificar/decodificar uniones discriminadas. dest es un puntero al discriminador; addr es un puntero a la unión; switch_list es la lista de casos para la unión; defaulted es una función que se llama si el discriminador no coincide con ningún caso.
bool_t xdr_vector(XDR *xdrs, char *cp, unsigned int size,
                 unsigned int maxsize, xdrproc_t xdr_element);
Rutina XDR para codificar/decodificar matrices de tamaño fijo. Similar a xdr_array(), pero para matrices de tamaño fijo.
bool_t xdr_void(void);
Rutina XDR dummy que no hace nada. Se utiliza para procedimientos que no tienen argumentos ni resultados.

Consulte los archivos de cabecera <rpc/rpc.h>, <rpc/clnt.h> y <rpc/svc.h> para obtener más detalles sobre estas rutinas.

Una macro que copia la estructura de error del manejador del cliente a la estructura en la dirección errp.
void clnt_pcreateerror(const char *s);
Imprime un mensaje en el error estándar indicando por qué no se pudo crear un manejador RPC de cliente. El mensaje está precedido por la cadena s y dos puntos. Se utiliza cuando falla una llamada a clnt_create(), clntraw_create(), clnttcp_create() o clntudp_create().
void clnt_perrno(enum clnt_stat stat);
Imprime un mensaje en el error estándar correspondiente a la condición indicada por stat. Se utiliza después de callrpc().
clnt_perror(CLIENT *clnt, const char *s);
Imprime un mensaje en el error estándar indicando por qué falló una llamada RPC; clnt es el manejador utilizado para realizar la llamada. El mensaje está precedido por la cadena s y dos puntos. Se utiliza después de clnt_call().
char *clnt_spcreateerror(const char *s);
Similar a clnt_pcreateerror(), excepto que devuelve una cadena en lugar de imprimir en el error estándar.
Errores: devuelve un puntero a datos estáticos que se sobrescriben en cada llamada.
char *clnt_sperrno(enum clnt_stat stat);
Toma los mismos argumentos que clnt_perrno(), pero en lugar de enviar un mensaje al error estándar indicando por qué falló una llamada RPC, devuelve un puntero a una cadena que contiene el mensaje. La cadena termina con un NUEVO LÍNEA.
clnt_sperrno() se utiliza en lugar de clnt_perrno() si el programa no tiene un error estándar (como es muy probable que no tenga un programa que se ejecute como servidor), o si el programador no quiere que el mensaje se imprima con printf(3), o si se va a utilizar un formato de mensaje diferente al soportado por clnt_perrno(). Nota: a diferencia de clnt_sperror() y clnt_spcreateerror(), clnt_sperrno() devuelve un puntero a datos estáticos, pero el resultado no se sobrescribirá en cada llamada.
char *clnt_sperror(CLIENT *rpch, const char *s);
Similar a clnt_perror(), excepto que (como clnt_sperrno()) devuelve una cadena en lugar de imprimir en el error estándar.
Errores: devuelve un puntero a datos estáticos que se sobrescriben en cada llamada.
CLIENT *clntraw_create(unsigned long prognum, unsigned long versnum);
Esta rutina crea un cliente RPC de juguete para el programa remoto prognum, versión versnum. El transporte utilizado para pasar mensajes al servicio es en realidad un búfer dentro del espacio de direcciones del proceso, por lo que el servidor RPC correspondiente debe residir en el mismo espacio de direcciones; véase svcraw_create(). Esto permite simular RPC y adquirir sobrecargas RPC, como tiempos de ida y vuelta, sin ninguna interferencia del kernel. Esta rutina devuelve NULL si falla.
CLIENT *clnttcp_create(struct sockaddr_in *addr,
                unsigned long prognum, unsigned long versnum,
                int *sockp, unsigned int sendsz, unsigned int recvsz);
Esta rutina crea un cliente RPC para el programa remoto prognum, versión versnum; el cliente utiliza TCP/IP como transporte. El programa remoto se encuentra en la dirección de Internet *addr. Si addr->sin_port es cero, entonces se establece en el puerto real en el que el programa remoto está escuchando (se consulta el servicio portmap remoto para obtener esta información). El parámetro sockp es un socket; si es RPC_ANYSOCK, esta rutina abre uno nuevo y establece sockp. Dado que RPC basado en TCP utiliza E/S en búfer, el usuario puede especificar el tamaño de los búferes de envío y recepción con los parámetros sendsz y recvsz; los valores de cero eligen valores predeterminados adecuados. Esta rutina devuelve NULL si falla.
CLIENT *clntudp_create(struct sockaddr_in *addr,
                unsigned long prognum, unsigned long versnum,
                struct timeval wait, int *sockp);
Esta rutina crea un cliente RPC para el programa remoto prognum, versión versnum; el cliente utiliza UDP/IP como transporte. El programa remoto se encuentra en la dirección de Internet addr. Si addr->sin_port es cero, entonces se establece en el puerto real en el que el programa remoto está escuchando (se consulta el servicio portmap remoto para obtener esta información). El parámetro sockp es un socket; si es RPC_ANYSOCK, esta rutina abre uno nuevo y establece sockp. El transporte UDP reenvía el mensaje de llamada en intervalos de tiempo wait hasta que se recibe una respuesta o hasta que la llamada expira. El tiempo total para que la llamada expire se especifica en clnt_call().
Advertencia: dado que los mensajes RPC basados en UDP solo pueden contener hasta 8 Kbytes de datos codificados, este transporte no se puede utilizar para procedimientos que aceptan argumentos grandes o devuelven resultados enormes.
CLIENT *clntudp_bufcreate(struct sockaddr_in *addr,
            unsigned long prognum, unsigned long versnum,
            struct timeval wait, int *sockp,
            unsigned int sendsize, unsigned int recosize);
Esta rutina crea un cliente RPC para el programa remoto prognum, en versnum; el cliente utiliza UDP/IP como transporte. El programa remoto se encuentra en la dirección de Internet addr. Si addr->sin_port es cero, entonces se establece en el puerto real en el que el programa remoto está escuchando (se consulta el servicio portmap remoto para obtener esta información). El parámetro sockp es un socket; si es RPC_ANYSOCK, esta rutina abre uno nuevo y establece sockp. El transporte UDP reenvía el mensaje de llamada en intervalos de tiempo wait hasta que se recibe una respuesta o hasta que la llamada expira. El tiempo total para que la llamada expire se especifica en clnt_call().
Esto permite al usuario especificar el tamaño máximo del paquete para enviar y recibir mensajes RPC basados en UDP.
void get_myaddress(struct sockaddr_in *addr);
Introduce la dirección IP de la máquina en *addr, sin consultar las rutinas de la biblioteca que se ocupan de /etc/hosts. El número de puerto siempre se establece en htons(PMAPPORT).
struct pmaplist *pmap_getmaps(struct sockaddr_in *addr);
Una interfaz de usuario para el servicio portmap, que devuelve una lista de los mapeos actuales de programa RPC a puerto en el host ubicado en la dirección IP *addr. Esta rutina puede devolver NULL. El comando rpcinfo -p utiliza esta rutina.
unsigned short pmap_getport(struct sockaddr_in *addr,
                    unsigned long prognum, unsigned long versnum,
                    unsigned int protocol);
Una interfaz de usuario para el servicio portmap, que devuelve el número de puerto en el que espera un servicio que soporta el número de programa prognum, versión versnum y habla el protocolo de transporte asociado con protocol. El valor de protocol es muy probablemente IPPROTO_UDP o IPPROTO_TCP. Un valor de retorno de cero significa que el mapeo no existe o que el sistema RPC no pudo contactar con el servicio portmap remoto. En este último caso, la variable global rpc_createerr contiene el estado RPC.
enum clnt_stat pmap_rmtcall(struct sockaddr_in *addr,
                    unsigned long prognum, unsigned long versnum,
                    unsigned long procnum,
                    xdrproc_t inproc, char *in,
                    xdrproc_t outproc, char *out,
                    struct timeval tout, unsigned long *portp);
Una interfaz de usuario para el servicio portmap, que instruye a portmap en el host en la dirección IP *addr para realizar una llamada RPC en su nombre a un procedimiento en ese host. El parámetro *portp se modificará al número de puerto del programa si el procedimiento tiene éxito. Las definiciones de otros parámetros se discuten en callrpc() y clnt_call(). Este procedimiento debe utilizarse para hacer un "ping" y nada más. Véase también clnt_broadcast().
bool_t pmap_set(unsigned long prognum, unsigned long versnum,
                int protocol, unsigned short port);
Una interfaz de usuario para el servicio portmap, que establece un mapeo entre el triple [prognum,versnum,protocol] y port en el servicio portmap de la máquina. El valor de protocol es muy probablemente IPPROTO_UDP o IPPROTO_TCP. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Se hace automáticamente por svc_register().
bool_t pmap_unset(unsigned long prognum, unsigned long versnum);
Una interfaz de usuario para el servicio portmap, que destruye todos los mapeos entre el triple [prognum,versnum,*] y los puertos en el servicio portmap de la máquina. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.

                unsigned long procnum, typeof(char *(char *)) *procname,
                xdrproc_t inproc, xdrproc_t outproc);
Registra el procedimiento procname con el paquete de servicios RPC. Si llega una solicitud para el programa prognum, versión versnum y procedimiento procnum, se llama a procname con un puntero a sus parámetros; procname debe devolver un puntero a sus resultados estáticos; inproc se utiliza para decodificar los parámetros mientras que outproc se utiliza para codificar los resultados. Esta rutina devuelve cero si el registro tuvo éxito, -1 en caso contrario.
Advertencia: los procedimientos remotos registrados de esta forma se acceden utilizando la tra de UDP/IP
nsport; ver **svc_udp_create**() para restricciones. 
struct rpc_createerr rpc_createerr;
Una variable global cuyo valor se establece por cualquier rutina de creación de cliente RPC que no tenga éxito. Utilice la rutina **clnt_pcreateerror**() para imprimir la razón.
void svc_destroy(SVCXPRT *xprt);
Una macro que destruye el manejador de transporte del servicio RPC, xprt. La destrucción generalmente implica la desasignación de estructuras de datos privadas, incluido el propio xprt. El uso de xprt no está definido después de llamar a esta rutina.
fd_set svc_fdset;
Una variable global que refleja la máscara de bits del descriptor de archivo de lectura del lado del servicio RPC; es adecuada como parámetro para la llamada al sistema select(2). Esto solo es de interés si un implementador de servicio realiza su propio procesamiento de eventos asíncrono, en lugar de llamar a **svc_run**(). Esta variable es de solo lectura (¡no pase su dirección a select(2)!), pero puede cambiar después de las llamadas a **svc_getreqset**() o cualquier rutina de creación.
int svc_fds;
Similar a **svc_fdset**, pero limitado a 32 descriptores de archivo. Esta interfaz está obsoleta por **svc_fdset**.
svc_freeargs(SVCXPRT *xprt, xdrproc_t inproc, char *in);
Una macro que libera cualquier dato asignado por el sistema RPC/XDR cuando decodificó los argumentos de un procedimiento de servicio usando **svc_getargs**(). Esta rutina devuelve 1 si los resultados se liberaron correctamente y cero en caso contrario.
svc_getargs(SVCXPRT *xprt, xdrproc_t inproc, char *in);
Una macro que decodifica los argumentos de una solicitud RPC asociada con el manejador de transporte del servicio RPC, xprt. El parámetro in es la dirección donde se colocarán los argumentos; inproc es la rutina XDR utilizada para decodificar los argumentos. Esta rutina devuelve uno si la decodificación tiene éxito y cero en caso contrario.
struct sockaddr_in *svc_getcaller(SVCXPRT *xprt);
La forma aprobada de obtener la dirección de red del llamador de un procedimiento asociado con el manejador de transporte del servicio RPC, xprt.
void svc_getreqset(fd_set *rdfds);
Esta rutina solo es de interés si un implementador de servicio no llama a **svc_run**(), sino que implementa procesamiento de eventos asíncronos personalizado. Se llama cuando la llamada al sistema select(2) ha determinado que ha llegado una solicitud RPC en algún(os) socket(s) RPC; rdfds es la máscara de bits del descriptor de archivo de lectura resultante. La rutina regresa cuando se han atendido todos los sockets asociados con el valor de rdfds.
void svc_getreq(int rdfds);
Similar a **svc_getreqset**(), pero limitada a 32 descriptores de archivo. Esta interfaz está obsoleta por **svc_getreqset**().
bool_t svc_register(SVCXPRT *xprt, unsigned long prognum,
                    unsigned long versnum,
                    typeof(void (struct svc_req *, SVCXPRT *)) *dispatch,
                    unsigned long protocol);
Asocia prognum y versnum con el procedimiento de despacho del servicio, dispatch. Si protocol es cero, el servicio no se registra con el servicio **portmap**. Si protocol no es cero, entonces se establece un mapeo del triple [prognum,versnum,protocol] a xprt->xp_port con el servicio **portmap** local (generalmente protocol es cero, **IPPROTO_UDP** o **IPPROTO_TCP**). El procedimiento dispatch tiene el siguiente formato:

dispatch(struct svc_req *request, SVCXPRT *xprt);

La rutina **svc_register**() devuelve uno si tiene éxito y cero en caso contrario.
void svc_run(void);
Esta rutina nunca regresa. Espera a que lleguen solicitudes RPC y llama al procedimiento de servicio apropiado usando **svc_getreq**() cuando llega una. Este procedimiento generalmente está esperando que devuelva una llamada al sistema select(2).
bool_t svc_sendreply(SVCXPRT *xprt, xdrproc_t outproc, char *out);
Llamada por la rutina de despacho de un servicio RPC para enviar los resultados de una llamada a procedimiento remoto. El parámetro xprt es el manejador de transporte asociado con la solicitud; outproc es la rutina XDR que se utiliza para codificar los resultados; y out es la dirección de los resultados. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void svc_unregister(unsigned long prognum, unsigned long versnum);
Elimina todos los mapeos del doble [prognum,versnum] a procedimientos de despacho, y del triple [prognum,versnum,*] al número de puerto.
void svcerr_auth(SVCXPRT *xprt, enum auth_stat why);
Llamada por una rutina de despacho de servicio que se niega a realizar una llamada a procedimiento remoto debido a un error de autenticación.
void svcerr_decode(SVCXPRT *xprt);
Llamada por una rutina de despacho de servicio que no puede decodificar sus parámetros con éxito. Ver también **svc_getargs**().
void svcerr_noproc(SVCXPRT *xprt);
Llamada por una rutina de despacho de servicio que no implementa el número de procedimiento que solicita el llamador.
void svcerr_noprog(SVCXPRT *xprt);
Se llama cuando el programa deseado no está registrado con el paquete RPC. Los implementadores de servicio generalmente no necesitan esta rutina.
void svcerr_progvers(SVCXPRT *xprt, unsigned long low_vers,
                     unsigned long high_vers);
Se llama cuando la versión deseada de un programa no está registrada con el paquete RPC. Los implementadores de servicio generalmente no necesitan esta rutina.
void svcerr_systemerr(SVCXPRT *xprt);
Llamada por una rutina de despacho de servicio cuando detecta un error del sistema que no está cubierto por ningún protocolo en particular. Por ejemplo, si un servicio ya no puede asignar almacenamiento, puede llamar a esta rutina.
void svcerr_weakauth(SVCXPRT *xprt);
Llamada por una rutina de despacho de servicio que se niega a realizar una llamada a procedimiento remoto debido a parámetros de autenticación insuficientes. La rutina llama a **svcerr_auth(xprt, AUTH_TOOWEAK)**.
SVCXPRT *svcfd_create(int fd, unsigned int sendsize,
                      unsigned int recvsize);
Crea un servicio sobre cualquier descriptor de archivo abierto. Típicamente, este descriptor de archivo es un socket conectado para un protocolo de flujo como TCP. sendsize y recvsize indican los tamaños de los búferes de envío y recepción. Si son cero, se elige un valor predeterminado razonable.
SVCXPRT *svcraw_create(void);
Esta rutina crea un transporte de servicio RPC de juguete, al que devuelve un puntero. El transporte es realmente un búfer dentro del espacio de direcciones del proceso, por lo que el cliente RPC correspondiente debe residir en el mismo espacio de direcciones; ver **clntraw_create**(). Esta rutina permite la simulación de RPC y la adquisición de sobrecargas RPC (como los tiempos de ida y vuelta), sin ninguna interferencia del kernel. Esta rutina devuelve NULL si falla.
SVCXPRT *svctcp_create(int sock, unsigned int send_buf_size,
                       unsigned int recv_buf_size);
Esta rutina crea un transporte de servicio RPC basado en TCP/IP, al que devuelve un puntero. El transporte está asociado con el socket sock, que puede ser **RPC_ANYSOCK**, en cuyo caso se crea un nuevo socket. Si el socket no está enlazado a un puerto TCP local, esta rutina lo enlaza a un puerto arbitrario. Al completar, xprt->xp_sock es el descriptor del socket del transporte, y xprt->xp_port es el número de puerto del transporte. Esta rutina devuelve NULL si falla. Dado que RPC basado en TCP utiliza E/S con búfer, los usuarios pueden especificar el tamaño de los búferes; los valores cero eligen valores predeterminados adecuados.
SVCXPRT *svcudp_bufcreate(int sock, unsigned int sendsize,
                          unsigned int recosize);
Esta rutina crea un transporte de servicio RPC basado en UDP/IP, al que devuelve un puntero. El transporte está asociado con el socket sock, que puede ser **RPC_ANYSOCK**, en cuyo caso se crea un nuevo socket. Si el socket no está enlazado a un puerto UDP local, esta rutina lo enlaza a un puerto arbitrario. Al completar, xprt->xp_sock es el descriptor del socket del transporte, y xprt->xp_port es el número de puerto del transporte. Esta rutina devuelve NULL si falla.
Esto permite al usuario especificar el tamaño máximo del paquete para enviar y recibir mensajes RPC basados en UDP.
SVCXPRT *svcudp_create(int sock);
Esta llamada es equivalente a svcudp_bufcreate(sock,SZ,SZ) para algún tamaño predeterminado SZ.

LIBRARY


Support library for Remote Procedure Call (libtirpc)

SYNOPSIS AND DESCRIPTION


struct sockaddr *svc_getcaller(SVCXPRT *xprt);



  

  
The
      svc_getcaller()
      function returns a pointer to the caller's address structure for the
      given RPC service transport handle. The pointer is to static storage
      within the RPC library and may be overwritten by subsequent calls to
      svc_getcaller()
      or other RPC functions.
