NOMBRE

svnserve.conf - Archivo de configuración del repositorio para svnserve

SINOPSIS

ruta_repositorio/conf/svnserve.conf

DESCRIPCIÓN

svnserve.conf controla el comportamiento del demonio svnserve por repositorio. Se encuentra en el subdirectorio conf del repositorio.

La estructura general del archivo es la misma que la de los archivos de configuración de usuarios de Subversion. En el nivel superior hay secciones, que se especifican con palabras entre corchetes; dentro de cada sección hay definiciones de variables del tipo "variable = valor". Las líneas que empiezan con '#' se ignoran. Actualmente, svnserve.conf solo usa una sección llamada "general", y soporta las siguientes variables:

anon-access = none|read|write
Determina el nivel de acceso para los usuarios no autenticados. El acceso write permite todas las operaciones del repositorio. El acceso read permite todas las operaciones excepto la de realizar commits y la de cambiar propiedades de revisión. El acceso none no permite ningún acceso. El nivel predeterminado es read.
auth-access = none|read|write
Determina el nivel de acceso para los usuarios autenticados, utilizando los mismos niveles de acceso que los anteriores. El nivel predeterminado es write.
password-db = nombre_archivo
Establece la ubicación de la base de datos de contraseñas. nombre_archivo puede ser relativo al directorio conf del repositorio. No hay valor predeterminado. La base de datos de contraseñas tiene el mismo formato general que este archivo. Utiliza solo una sección "users"; cada variable dentro de la sección es un nombre de usuario, y cada valor es una contraseña.
authz-db = ruta
La opción authz-db controla la ubicación de las reglas de autorización para el control de acceso basado en rutas. ruta puede ser relativa al directorio conf del repositorio. ruta puede ser una URL relativa al repositorio (^/) o una URL absoluta file:// a un archivo de texto en un repositorio de Subversion. No hay valor predeterminado. Si no especificas un authz-db, no se realiza ningún control de acceso basado en rutas.
realm = nombre_realm
Establece el reino de autenticación del repositorio. Si dos repositorios tienen la misma base de datos de contraseñas, deben tener el mismo reino, y viceversa; esta asociación permite a los clientes usar una única contraseña en caché para varios repositorios. El valor predeterminado del reino es el uuid del repositorio.

EJEMPLO

El siguiente svnserve.conf de ejemplo permite acceso de lectura para usuarios autenticados, ningún acceso para usuarios anónimos, apunta a una base de datos de contraseñas en el mismo directorio y define un nombre de reino.

 [general]
 anon-access = none
 auth-access = read
 password-db = passwd
 realm = Mi Primer Repositorio

El archivo "passwd" se vería así:

 [users]
 joeuser = joepassword
 jayrandom = randomjay
