svn2revisioninc(1) Utilidad para crear el archivo revision.inc desde el repositorio SVN svn2revisioninc(1)

NOMBRE

svn2revisioninc - Utilidad de Lazarus para crear el archivo revision.inc desde el repositorio SVN.

SINOPSIS

svn2revisioninc
svn2revisioninc [Opciones] <ruta del repositorio> <archivo de salida>
svn2revisioninc <ruta del repositorio> [Opciones] <archivo de salida>

DESCRIPCIÓN

svn2revisioninc es utilizado por el sistema de compilación de Lazarus para crear el archivo revision.inc desde el repositorio SVN.

NOTAS

El 1er parámetro sin modificador = <ruta del repositorio> (por defecto es el directorio actual)
El 2do parámetro sin modificador = <archivo de salida> (por defecto es el revision.inc predeterminado)

OPCIONES

-h
Muestra un breve mensaje de ayuda.
--o
Archivo de salida. Esto anula el <archivo de salida>
--c=<nombre>
Nombre de la constante (por defecto RevisionStr ).
--s
escribe la revisión a la salida estándar, no crea el archivo inc
--v
Ser detallado
