CUNBDB1

Propósito:

!>
!> CUNBDB1 bidiagonaliza simultáneamente los bloques de una matriz X
!> alta y delgada con columnas ortonormales:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 es P-por-Q, y X21 es (M-P)-por-Q. Q no debe ser mayor que P,
!> M-P, o M-Q. Las rutinas CUNBDB2, CUNBDB3 y CUNBDB4 manejan casos en
!> los que Q no es la dimensión mínima.
!>
!> Las matrices unitarias P1, P2 y Q1 son P-por-P, (M-P)-por-(M-P),
!> y (M-Q)-por-(M-Q), respectivamente. Se representan implícitamente por
!> vectores de Householder.
!>
!> B11 y B12 son matrices bidiagonales Q-por-Q representadas implícitamente por
!> ángulos THETA, PHI.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>           El número de filas de X11 más el número de filas en X21.
!>

P

!>          P es INTEGER
!>           El número de filas en X11. 0 <= P <= M.
!>

Q

!>          Q es INTEGER
!>           El número de columnas en X11 y X21. 0 <= Q <=
!>           MIN(P,M-P,M-Q).
!>

X11

!>          X11 es array COMPLEX, dimensión (LDX11,Q)
!>           En la entrada, el bloque superior de la matriz X a reducir.
!>           En la salida, las columnas de tril(X11) especifican los
!>           refletores para P1 y las filas de triu(X11,1) especifican los
!>           refletores para Q1.
!>

LDX11

!>          LDX11 es INTEGER
!>           La dimensión principal de X11. LDX11 >= P.
!>

X21

!>          X21 es array COMPLEX, dimensión (LDX21,Q)
!>           En la entrada, el bloque inferior de la matriz X a reducir.
!>           En la salida, las columnas de tril(X21) especifican los
!>           refletores para P2.
!>

LDX21

!>          LDX21 es INTEGER
!>           La dimensión principal de X21. LDX21 >= M-P.
!>

THETA

!>          THETA es array REAL, dimensión (Q)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen
!>           por THETA y PHI. Ver Detalles Adicionales.
!>

PHI

!>          PHI es array REAL, dimensión (Q-1)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen
!>           por THETA y PHI. Ver Detalles Adicionales.
!>

TAUP1

!>          TAUP1 es array COMPLEX, dimensión (P)
!>           Los factores escalares de los reflectores elementales que
!>           definen P1.
!>

TAUP2

!>          TAUP2 es array COMPLEX, dimensión (M-P)
!>           Los factores escalares de los reflectores elementales que
!>           definen P2.
!>

TAUQ1

!>          TAUQ1 es array COMPLEX, dimensión (Q)
!>           Los factores escalares de los reflectores elementales que
!>           definen Q1.
!>

WORK

!>          WORK es array COMPLEX, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>           La dimensión del array WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, entonces se asume una consulta de espacio de
!>           trabajo; la rutina solo calcula el tamaño óptimo del array
!>           WORK, devuelve este valor como la primera entrada del array
!>           WORK y no se emite ningún mensaje de error relacionado con
!>           LWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>           = 0: salida exitosa.
!>           < 0: si INFO = -i, el i-ésimo argumento tenía un valor
!>           ilegal.
!>

Detalles Adicionales:

!>
!>  Los bloques superior-bidiagonales B11, B21 se representan implícitamente
!>  por los ángulos THETA(1), ..., THETA(Q) y PHI(1), ..., PHI(Q-1). Cada
!>  entrada en cada banda bidiagonal es un producto de un seno o coseno de un
!>  THETA con un seno o coseno de un PHI. Ver [1] o CUNCSD para detalles.
!>
!>  P1, P2 y Q1 se representan como productos de reflectores elementales.
!>  Ver CUNCSD2BY1 para detalles sobre cómo generar P1, P2 y Q1 usando
!>  CUNGQR y CUNGLQ.
!>

Referencias:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.

NAME

zunbdb1

reduces a bidiagonal matrix to a diagonal matrix

SYNOPSIS

    SUBROUTINE ZUNBDB1( M, P, Q, X11, LDX11, X21, LDX21, THETA, PHI,
                     TAUP1, TAUP2, TAUQ1, WORK, LWORK, INFO )

CHARACTER * 10 X11, X21, WORK

INTEGER M, P, Q, LDX11, LDX21, LWORK, INFO

DOUBLE PRECISION THETA(*), PHI(*)

COMPLEX*16 TAUP1(*), TAUP2(*), TAUQ1(*)

Detailed Description

!>
!> ZUNBDB1 does the following:
!>
!>   Given a matrix X = [ X11 ]
!>                     [ X21 ]
!>   where X11 is P-by-Q and X21 is (M-P)-by-Q, ZUNBDB1 reduces X
!>   to bidiagonal form.
!>
!>   The algorithm computes the CS decomposition of X. The upper
!>   bidiagonal matrices B11 and B21 are represented implicitly by
!>   angles THETA and PHI.
!>
!>   The unitary matrices P1, P2, and Q1 are represented implicitly by
!>   Householder vectors.
!>
!>   X11 is P-by-Q, and X21 is (M-P)-by-Q. Q must be no larger than P,
!>   M-P, or M-Q. Routines ZUNBDB2, ZUNBDB3, and ZUNBDB4 handle cases in
!>   which Q is not the minimum dimension.
!>
!>   The unitary matrices P1, P2, and Q1 are P-by-P, (M-P)-by-(M-P),
!>   and (M-Q)-by-(M-Q), respectively. They are represented implicitly by
!>   Householder vectors.
!>
!>   B11 and B12 are Q-by-Q bidiagonal matrices represented implicitly by
!>   angles THETA, PHI.
!>
!>

Parameters

M 
!>          M is INTEGER
!>           The number of rows X11 plus the number of rows in X21.
!>

P

!>          P is INTEGER
!>           The number of rows in X11. 0 <= P <= M.
!>

Q

!>          Q is INTEGER
!>           The number of columns in X11 and X21. 0 <= Q <=
!>           MIN(P,M-P,M-Q).
!>

X11

!>          X11 is COMPLEX*16 array, dimension (LDX11,Q)
!>           On entry, the top block of the matrix X to be reduced. On
!>           exit, the columns of tril(X11) specify reflectors for P1 and
!>           the rows of triu(X11,1) specify reflectors for Q1.
!>

LDX11

!>          LDX11 is INTEGER
!>           The leading dimension of X11. LDX11 >= P.
!>

X21

!>          X21 is COMPLEX*16 array, dimension (LDX21,Q)
!>           On entry, the bottom block of the matrix X to be reduced. On
!>           exit, the columns of tril(X21) specify reflectors for P2.
!>

LDX21

!>          LDX21 is INTEGER
!>           The leading dimension of X21. LDX21 >= M-P.
!>

THETA

!>          THETA is DOUBLE PRECISION array, dimension (Q)
!>           The entries of the bidiagonal blocks B11, B21 are defined by
!>           THETA and PHI. See Further Details.
!>

PHI

!>          PHI is DOUBLE PRECISION array, dimension (Q-1)
!>           The entries of the bidiagonal blocks B11, B21 are defined by
!>           THETA and PHI. See Further Details.
!>

TAUP1

!>          TAUP1 is COMPLEX*16 array, dimension (P)
!>           The scalar factors of the elementary reflectors that define
!>           P1.
!>

TAUP2

!>          TAUP2 is COMPLEX*16 array, dimension (M-P)
!>           The scalar factors of the elementary reflectors that define
!>           P2.
!>

TAUQ1

!>          TAUQ1 is COMPLEX*16 array, dimension (Q)
!>           The scalar factors of the elementary reflectors that define
!>           Q1.
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>           The dimension of the array WORK. LWORK >= M-Q.
!>
!>           If LWORK = -1, then a workspace query is assumed; the routine
!>           only calculates the optimal size of the WORK array, returns
!>           this value as the first entry of the WORK array, and no error
!>           message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>           = 0:  successful exit.
!>           < 0:  if INFO = -i, the i-th argument had an illegal value.
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Further Details:

!>
!>  The upper-bidiagonal blocks B11, B21 are represented implicitly by
!>  angles THETA(1), ..., THETA(Q) and PHI(1), ..., PHI(Q-1). Every entry
!>  in each bidiagonal band is a product of a sine or cosine of a THETA
!>  with a sine or cosine of a PHI. See [1] or ZUNCSD for details.
!>
!>  P1, P2, and Q1 are represented as products of elementary reflectors.
!>  See ZUNCSD2BY1 for details on generating P1, P2, and Q1 using ZUNGQR
!>  and ZUNGLQ.
!>

References:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
