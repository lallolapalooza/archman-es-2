uudoc(1) Manual de Comandos Generales uudoc(1)

NOMBRE

uudoc - Imprime las últimas 10 líneas de cada ARCHIVO en la salida estándar. Con más de un ARCHIVO, precede a cada uno con un encabezado que indica el nombre del archivo. Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar. Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

SINOPSIS

uudoc [-c|--bytes] [-f|--follow] [-n|--lines] [--pid] [-q|--quiet] [-s|--sleep-interval] [--max-unchanged-stats] [-v|--verbose] [-z|--zero-terminated] [--use-polling] [--retry] [-F ] [-h|--help] [-V|--version] [archivos]

DESCRIPCIÓN

Imprime las últimas 10 líneas de cada ARCHIVO en la salida estándar. Con más de un ARCHIVO, precede a cada uno con un encabezado que indica el nombre del archivo. Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar. Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

OPCIONES

-c, --bytes
Número de bytes a imprimir
-f, --follow
Imprime el archivo a medida que crece

[posibles valores: descriptor, name]

-n, --lines
Número de líneas a imprimir
--pid <PID>
Con -f, termina después de que el proceso con PID muere
-q, --quiet
Nunca imprime encabezados con nombres de archivo
-s, --sleep-interval <N>
Número de segundos a esperar entre sondeos del archivo cuando se ejecuta con -f
--max-unchanged-stats <N>
Reabre un ARCHIVO que no ha cambiado de tamaño después de N (por defecto 5) iteraciones para ver si ha sido eliminado o renombrado (este es el caso habitual de los archivos de registro rotados); Esta opción solo es significativa cuando se sondea (es decir, con --use-polling) y cuando --follow=name
-v, --verbose
Siempre imprime encabezados con nombres de archivo
-z, --zero-terminated
El delimitador de línea es NUL, no nueva línea
--use-polling
Deshabilita el soporte 'inotify' y usa sondeo en su lugar
--retry
Sigue intentando abrir un archivo si es inaccesible
-F
Igual que --follow=name --retry
-h, --help
Imprime la ayuda
-V, --version
Imprime la versión
[archivos]
