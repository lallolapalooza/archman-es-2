UMAD_SET_ADDR(3) Manual del programador de OpenIB UMAD_SET_ADDR(3)

NOMBRE

umad_set_addr - establece los campos de dirección MAD dentro del búfer umad utilizando el orden del host

SINOPSIS

#include <infiniband/umad.h>

int umad_set_addr(void *umad, int dlid, int dqp, int sl, int qkey);

DESCRIPCIÓN

umad_set_addr() establece los campos de dirección MAD dentro del búfer umad especificado utilizando los campos proporcionados en orden de host. dlid es el LID de destino. dqp es el QP (par de colas) de destino. sl es el SL (nivel de servicio). qkey es la Q_Key (clave de cola).

VALOR DE RETORNO

umad_set_addr() devuelve 0 si tiene éxito y un valor negativo en caso de error. Actualmente, no se indican errores.

VER TAMBIÉN

umad_set_addr_net(3)
