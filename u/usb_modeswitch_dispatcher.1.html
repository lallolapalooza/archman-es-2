USB_MODESWITCH_DISPATCHER(1) Manual de Comandos Generales USB_MODESWITCH_DISPATCHER(1)

NOMBRE

usb_modeswitch_dispatcher - script de envoltura de Linux para usb_modeswitch (no está previsto invocarlo directamente)

SINOPSIS

usb_modeswitch_dispatcher

DESCRIPCIÓN

usb_modeswitch_dispatcher realizará comprobaciones detalladas del dispositivo y, posteriormente, utilizará la utilidad usb_modeswitch, independiente de Linux, junto con el archivo de configuración del dispositivo seleccionado, para cambiar el modo de ciertos dispositivos USB.

Si ningún controlador se hace cargo del dispositivo después del cambio de modo, el dispatcher intentará cargar y vincular el controlador serial "option" a cualquier interfaz USB con clase 0xff, con el fin de hacer que el dispositivo sea utilizable en caso de que aún no sea reconocido por ese controlador. Esto puede funcionar o no.

Este programa es llamado por udev y no está pensado para ser llamado directamente por el usuario.

VER TAMBIÉN
