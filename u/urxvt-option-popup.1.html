NOMBRE

option-popup - menú de opciones

DESCRIPCIÓN

Vincula un menú emergente a Ctrl-Button2 que permite alternar (algunas) opciones en tiempo de ejecución.

Otras extensiones pueden extender este menú emergente insertando una referencia de código en "@{ $term->{option_popup_hook} }", que se llama cada vez que se muestra el menú emergente.

Su único argumento es el menú emergente, que puede ser modificado. Debe devolver nada o una cadena, el valor booleano inicial y una referencia de código. La cadena se usará como texto del botón y la referencia de código se llamará cuando cambie la opción, con el nuevo valor booleano como primer argumento.

Lo siguiente agregará una entrada "miopción" que cambia "$self->{myoption}":

push @{ $self->{term}{option_popup_hook} }, sub {
   ("mi opción" => $myoption, sub { $self->{myoption} = $_[0] })
};
