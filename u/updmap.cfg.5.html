NOMBRE

updmap.cfg - configuración de mapeo/inclusión de fuentes para dvips y similares.

DESCRIPCIÓN

El archivo updmap.cfg es el archivo central de configuración de fuentes de un sistema teTeX y es leído por updmap(1). Describe si y cómo las fuentes deben ser incluidas (o no) en archivos PS/PDF. Esto funciona para fuentes Outline (Postscript Type1) y Bitmap (Postscript Type3) que provienen principalmente de MetaFont.

updmap es una utilidad que crea archivos de configuración de fuentes para dvips(1), pdftex(1), xdvi(1), ps2pk(1), gsftopk(1) y dvipdfmx(1). En un mundo ideal, updmap sería innecesario -- cada uno de estos programas leería el mismo archivo de configuración para saber qué fuentes están disponibles y cómo deben ser tratadas. Sin embargo, tal como están las cosas, cada una de estas herramientas tiene requisitos sutilmente diferentes y por lo tanto necesita su propio archivo de configuración de fuentes. updmap crea archivos de configuración de fuentes para todos estos programas a partir de varias fuentes, a saber, todos los updmap.cfg, permitiéndole mantener fácilmente todos los diferentes archivos de configuración sincronizados.

Ejecutar "updmap --help" mostrará la documentación principal para usar updmap.

dvipsPreferOutline
Configura si dvips (por defecto) debe preferir fuentes bitmap o fuentes outline si ambas están disponibles? Independientemente de esta configuración, las outlines pueden ser forzadas al incluir "p psfonts_t1.map" en un archivo de configuración que dvips lea. Las bitmaps pueden ser forzadas al incluir "p psfonts_pk.map" en un archivo de configuración. Proporcionamos dichos archivos de configuración que pueden ser habilitados a través de dvips -Poutline (o dvips -Ppk, respectivamente).
Los ajustes válidos para dvipsPreferOutline son true / false.

LW35
¿Qué fuentes de las "Basic 35 Laserwriter Fonts" desea utilizar y cómo se eligen los nombres de archivo? Ajustes válidos:
URW: Fuentes URW con nombres de archivo de "vendor" (ej. n019064l.pfb)
URWkb: Fuentes URW con nombres de archivo de "berry" (ej. uhvbo8ac.pfb)
ADOBE: Fuentes Adobe con nombres de archivo de "vendor" (ej. hvnbo___.pfb)
ADOBEkb: Fuentes Adobe con nombres de archivo de "berry" (ej. phvbo8an.pfb)

dvipsDownloadBase35
Configura si dvips (por defecto) debe descargar las 35 fuentes PostScript básicas en el documento (establecer en true) o si estas fuentes deben ser utilizadas desde el intérprete Postscript / impresora (establecer en false).
El usuario puede anular el valor predeterminado especificando dvips -Pdownload35 (o dvips -Pbuiltin35, respectivamente) para descargar las fuentes LW35 (o usar las fuentes incorporadas).
Los ajustes válidos son true / false.

pdftexDownloadBase14
¿Debería pdftex descargar las 14 fuentes PDF básicas? Dado que algunas configuraciones (herramientas PS / PDF / impresoras) utilizan fuentes predeterminadas incorrectas, es más seguro descargar las fuentes. Los archivos PDF se vuelven más grandes, pero ese es el coste.
Los ajustes válidos son true (descargar las fuentes) o false (no descargar las fuentes). Adobe recomienda incrustar todas las fuentes.

pxdviUse
¿Se deben crear archivos de mapa especiales para pxdvi? pxdvi es una adaptación de xdvi con soporte para leer y mostrar archivos generados por la familia de motores ptex.
Los ajustes válidos son true (generar configuración) o false. Ver http://www.tug.org/texlive/updmap-kanji.html para una discusión detallada.

kanjiEmbed
kanjiVariant
Las opciones kanjiEmbed y kanjiVariant especifican reemplazos especiales en las líneas de mapa. En un mapa, la cadena "@kanjiEmbed@" será reemplazada por el valor de esa opción; igualmente para kanjiVariant. De esta manera, los usuarios de TeX japonés pueden seleccionar diferentes fuentes para ser incluidas en la salida final.

Map
Apuntando a un archivo de mapa, que describe un mapeo desde una fuente (llamada en el documento TeX) al archivo pfb que contiene el código Postscript.
Uso: Map nombre_archivo.map

La sintaxis de los archivos de mapa es la misma que utiliza dvips(1), ver la sección "psfonts.map" en el manual de dvips(1).

MixedMap
Similar a Map. Debe usarse cuando existe Type1 y una implementación bitmap de la fuente (la última proviene principalmente de MetaFont). Estas entradas no se usarán en el mapa predeterminado de dvips si dvipsPreferOutline está configurado en false.
Uso: MixedMap nombre_archivo.map

KanjiMap
Similar a Map. Debe usarse para fuentes kanji.
Uso: KanjiMap nombre_archivo.map

El signo # precede a un comentario.

Los archivos de mapa que no deben usarse deben ser comentados usando la cadena #! al principio de la línea. Dichas entradas pueden ser activadas/desactivadas (de-) usando updmap con las opciones --enable y --disable, respectivamente.
