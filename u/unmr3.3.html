Documentación de la Función

subrutina cunmr3 (character side, character trans, integer m, integer n, integer k, integer l, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work, integer info)

CUNMR3 multiplica una matriz general por la matriz unitaria de una factorización RZ determinada por ctzrzf (algoritmo sin bloques).

Propósito:

!>
!> CUNMR3 sobrescribe la matriz compleja general m por n C con
!>
!>       Q * C  si SIDE = 'L' y TRANS = 'N', o
!>
!>       Q**H* C  si SIDE = 'L' y TRANS = 'C', o
!>
!>       C * Q  si SIDE = 'R' y TRANS = 'N', o
!>
!>       C * Q**H si SIDE = 'R' y TRANS = 'C',
!>
!> donde Q es una matriz unitaria compleja definida como el producto de k
!> reflectores elementales
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> tal como devuelve CTZRZF. Q es de orden m si SIDE = 'L' y de orden n
!> si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda
!>          = 'R': aplicar Q o Q**H desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar Q (Sin transposición)
!>          = 'C': aplicar Q**H (Transpuesta conjugada)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

L

!>          L es INTEGER
!>          El número de columnas de la matriz A que contienen
!>          la parte significativa de los reflectores de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ésima fila debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como devuelve
!>          CTZRZF en las últimas k filas de su argumento array A.
!>          A es modificado por la rutina pero restaurado a la salida.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A. LDA >= max(1,K).
!>

TAU

!>          TAU es un array COMPLEX, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como devuelve CTZRZF.
!>

C

!>          C es un array COMPLEX, de dimensión (LDC,N)
!>          A la entrada, la matriz C de m por n.
!>          A la salida, C es sobrescrito por Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión líder del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX, de dimensión
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

NAME

dormr3, sormr3, zormr3 - multiplies a general matrix by a Rizov-Trefethen orthogonal or unitary factor.

SYNOPSIS

All the following subroutines are part of the LAPACK library. They all have the same interface.

    SUBROUTINE DORMR3( SIDE, TRANS, M, N, K, L, A, LDA, TAU, C, LDC, WORK, INFO )
    INTEGER M, N, K, L, LDA, LDC, INFO
    DOUBLE PRECISION A( LDA, * ), TAU( * ), C( LDC, * ), WORK( * )
    CHARACTER * 1 SIDE, TRANS

    SUBROUTINE SORMR3( SIDE, TRANS, M, N, K, L, A, LDA, TAU, C, LDC, WORK, INFO )
    INTEGER M, N, K, L, LDA, LDC, INFO
    REAL A( LDA, * ), TAU( * ), C( LDC, * ), WORK( * )
    CHARACTER * 1 SIDE, TRANS

    SUBROUTINE ZUNMR3( SIDE, TRANS, M, N, K, L, A, LDA, TAU, C, LDC, WORK, INFO )
    INTEGER M, N, K, L, LDA, LDC, INFO
    COMPLEX*16 A( LDA, * ), TAU( * ), C( LDC, * ), WORK( * )
    CHARACTER * 1 SIDE, TRANS

DESCRIPTION

DORMR3 overwrites the general double precision matrix C with

        SIDE = 'L'      SIDE = 'R'
TRANS = 'N'   Q * C         C * Q
TRANS = 'T'   Q**T * C       C * Q**T

where Q is a double precision orthogonal matrix defined as the product of k elementary reflectors

        Q = H(1) H(2) . . . H(k)

as returned by DTZRZF. Q is of order m if SIDE = 'L' and of order n if SIDE = 'R'.

SORMR3 multiplies a general real matrix by the orthogonal matrix from a RZ factorization determined by stzrzf (unblocked algorithm).

Purpose:

!>
!> SORMR3 overwrites the general real m by n matrix C with
!>
!>       Q * C  if SIDE = 'L' and TRANS = 'N', or
!>
!>       Q**T* C  if SIDE = 'L' and TRANS = 'C', or
!>
!>       C * Q  if SIDE = 'R' and TRANS = 'N', or
!>
!>       C * Q**T if SIDE = 'R' and TRANS = 'C',
!>
!> where Q is a real orthogonal matrix defined as the product of k
!> elementary reflectors
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> as returned by STZRZF. Q is of order m if SIDE = 'L' and of order n
!> if SIDE = 'R'.
!>

ZUNMR3 overwrites the general complex matrix C with

        SIDE = 'L'      SIDE = 'R'
TRANS = 'N'   Q * C         C * Q
TRANS = 'C'   Q**H * C       C * Q**H

where Q is a complex unitary matrix defined as the product of k elementary reflectors

        Q = H(1) H(2) . . . H(k)

as returned by ZTZRZF. Q is of order m if SIDE = 'L' and of order n if SIDE = 'R'.

Parameters

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': apply Q or Q**T (or Q**H) from the Left
!>          = 'R': apply Q or Q**T (or Q**H) from the Right
!>

TRANS

!>          TRANS is CHARACTER*1
!>          = 'N': apply Q  (No transpose)
!>          = 'T': apply Q**T (Transpose)
!>                 (applies to DORMR3 and SORMR3 only)
!>          = 'C': apply Q**H (Conjugate transpose)
!>                 (applies to ZUNMR3 only)
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix C. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix C. N >= 0.
!>

K

!>          K is INTEGER
!>          The number of elementary reflectors whose product defines
!>          the matrix Q.
!>          If SIDE = 'L', M >= K >= 0;
!>          if SIDE = 'R', N >= K >= 0.
!>

L

!>          L is INTEGER
!>          The number of rows/columns of A which contain the vectors
!>          which define the elementary reflectors.
!>          If SIDE = 'L', M >= L >= K;
!>          if SIDE = 'R', N >= L >= K.
!>          (L=K for DORMR3, SORMR3, ZUNMR3. This parameter is
!>          kept for consistency with other routines of this type.)
!>

A

!>          A is DOUBLE PRECISION/REAL/COMPLEX*16 array, dimension
!>                               (LDA,M) if SIDE = 'L',
!>                               (LDA,N) if SIDE = 'R'
!>          The i-th row must contain the vector which defines the
!>          elementary reflector H(i), for i = 1,2,...,k, as returned by
!>          DTZRZF/STZRZF/ZTZRZF in the last k rows of its array
!>          argument A.
!>          A is modified by the routine but restored on exit.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,K).
!>

TAU

!>          TAU is DOUBLE PRECISION/REAL/COMPLEX*16 array, dimension (K)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by DTZRZF/STZRZF/ZTZRZF.
!>

C

!>          C is DOUBLE PRECISION/REAL/COMPLEX*16 array, dimension (LDC,N)
!>          On entry, the m-by-n matrix C.
!>          On exit, C is overwritten by Q*C or Q**T*C or C*Q**T or C*Q
!>          (or by Q*C or Q**H*C or C*Q**H or C*Q for ZUNMR3).
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!>

WORK

!>          WORK is DOUBLE PRECISION/REAL/COMPLEX*16 array, dimension
!>                                   (N) if SIDE = 'L',
!!>                                   (M) if SIDE = 'R'
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>

NAME

unmr3 — applies a unitary transformation to a general rectangular matrix

SYNOPSIS

subroutine UNMR3(SIDE, TRANS, M, N, K, L, A, LDA, TAU, X, LDX, WORK, INFO)
    integer :: INFO
    integer :: M, N, K, L, LDA, LDX
    real, dimension( * ) :: TAU, WORK
    complex, dimension( * ) :: A, X
    real, dimension( * ) :: ... real :: ...
    complex, dimension( * ) :: ... complex :: ...
    character(len=1) :: SIDE, TRANS

Description

UNMR3 applies a unitary transformation to a general rectangular matrix, using a blocked algorithm. The unitary transformation $$Q$$ is defined as a product of Householder transformations

Q = H(1) * H(2) * ... * H(K)

where each $$H(i)$$ is a Householder transformation defined as

H(i) = I - tau(i) * v(i) * v(i)**T

or

H(i) = I - tau(i) * v(i) * conjugate(v(i)**T)

The vectors $$v(i)$$ and scalars $$tau(i)$$ are stored in the arrays A and TAU. Q is either a KxM matrix, or a KxN matrix, depending on SIDE.

The matrix Q is not formed explicitly. A block representation is used instead.

Arguments

SIDE CHARACTER*1
Specifies whether Q or $$Q^H$$ is applied to X:
TRANS CHARACTER*1
Specifies the form of the unitary transformation to be applied:
M INTEGER
The number of rows of the matrix X. M >= 0.
N INTEGER
The number of columns of the matrix X. N >= 0.
K INTEGER
The number of rows of the matrix A, and the number of Householder transformations.
L INTEGER
The number of columns of the matrix A. L >= K.
A COMPLEX array, dimension (LDA,K)
On entry, the vectors which define the transformations that form the matrix Q. The elements of the vectors v(i) are stored
LDA INTEGER
The leading dimension of the array A.
TAU COMPLEX array, dimension (K)
On entry, the scalars tau(i) which determine the character of the transformations.
X COMPLEX array, dimension (LDX,N)
On entry, the matrix X to which the transformation is applied.
LDX INTEGER
The leading dimension of the array X.
WORK COMPLEX array, dimension (MAX(M,N,K)*NB)
Workspace array. On exit, WORK(1) is set to the optimal value of NB.
INFO INTEGER
  • INFO = 0: successful exit
  • INFO < 0: if INFO = -i, the i-th argument had an illegal value

Function Documentation

This subroutine is part of the LAPACK library, a standard library for linear algebra computations. It is used in conjunction with routines like GETRF, GETRI, GEQRF, and GELQF for performing matrix factorizations and solving linear systems.

The core idea is to apply a sequence of Householder reflections, represented compactly by the vectors stored in matrix A and scalars in vector TAU, to another matrix X.

The blocked approach is employed for efficiency, especially on modern computer architectures, by processing sub-matrices (blocks) at a time to improve data locality and reduce memory access latency.

The parameters SIDE and TRANS control how the unitary transformation is applied:

SIDE
If 'L', the transformation is applied to the left of X (i.e., Q*X or QH*X).
If 'R', the transformation is applied to the right of X (i.e., X*Q or X*QH).
TRANS
If 'N', the unitary transformation Q is applied.
If 'T', the transpose of the unitary transformation QT is applied.
If 'C', the conjugate transpose of the unitary transformation QH is applied.

The dimensions M, N, K, and L define the sizes of the matrices and the number of transformations involved. LDA and LDX are the leading dimensions of the arrays A and X, respectively, which are important for memory layout in Fortran.

The WORK array provides essential temporary storage for the blocked computations. The routine may also update WORK(1) to suggest an optimal block size (NB) for future calls with similar matrix dimensions.

The INFO parameter is a standard LAPACK output parameter indicating the success or failure of the operation. A negative value signifies an error related to an invalid input argument.

The specific implementation details of the blocked algorithm involve partitioning the matrices and applying Householder transformations in a highly optimized manner to minimize redundant computations and maximize the use of processor caches.

This routine is typically called after a matrix factorization that generates Householder transformations, such as QR decomposition.
