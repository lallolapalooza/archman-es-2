UDADDY(1) librdmacm UDADDY(1)

NOMBRE

udaddy - configuración de datagramas RDMA CM y prueba simple de ping-pong.

SINOPSIS

udaddy [-s dirección_servidor] [-b dirección_enlace] [-c conexiones]
		[-C recuento_mensajes] [-S tamaño_mensaje] [-p espacio_puerto]
udaddy -s dirección_servidor [-b dirección_enlace] [-c conexiones]
		[-C recuento_mensajes] [-S tamaño_mensaje] [-t tos] [-p espacio_puerto]

DESCRIPCIÓN

Establece un conjunto de rutas de comunicación de datagramas RDMA no confiables entre dos nodos utilizando librdmacm, opcionalmente transfiere datagramas entre los nodos y luego cierra la comunicación.

OPCIONES

-s dirección_servidor
El nombre de red o la dirección IP del sistema servidor que espera la comunicación. El nombre o la dirección utilizada deben enrutarse a través de un dispositivo RDMA. El cliente debe especificar esta opción.
-b dirección_enlace
La dirección de red local a la que enlazar. Para enlazar a cualquier dirección con IPv6, use -b ::0 .
-c conexiones
El número de rutas de comunicación a establecer entre el cliente y el servidor. La prueba utiliza comunicación de datagramas no confiables, por lo que no se forman conexiones reales. (predeterminado 1)
-C recuento_mensajes
El número de mensajes a transferir en cada conexión. (predeterminado 10)
-S tamaño_mensaje
El tamaño de cada mensaje transferido, en bytes. Este valor debe ser menor que la MTU del transporte RDMA subyacente, o se producirá un error. (predeterminado 100)
-t tos
Indica el tipo de servicio utilizado para la comunicación. El tipo de servicio depende de la implementación según la configuración de la subred.
-p espacio_puerto
El espacio de puertos de la comunicación de datagramas. Puede ser el espacio de puertos RDMA UDP (0x0111) o IPoIB (0x0002). (predeterminado RDMA_PS_UDP)

NOTAS

El uso básico es iniciar udaddy en un sistema servidor, luego ejecutar udaddy -s nombre_servidor en un sistema cliente.

Dado que esta prueba mapea recursos RDMA al espacio de usuario, los usuarios deben asegurarse de tener recursos del sistema y permisos disponibles. Consulte el archivo README de libibverbs para obtener detalles adicionales.
