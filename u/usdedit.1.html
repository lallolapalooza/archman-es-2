USDEDIT(1) Comandos de usuario USDEDIT(1)

NOMBRE

usdedit - página del manual para usdedit 25.11

DESCRIPCIÓN

uso: usdedit [-h] [-n] [-f] [-p PREFIX] usdFileName

Convierte un archivo legible por usd al formato de texto .usda en una ubicación temporal e invoca un editor sobre él. Después de guardar y salir del editor, el archivo editado se convertirá de nuevo al formato original y SOBRESCRIBIRÁ el archivo original, a menos que proporcione la bandera ""-n"" (--noeffect), en cuyo caso no se guardarán cambios en el archivo original. El editor a utilizar se buscará de la siguiente manera: - variable de entorno USD_EDITOR - variable de entorno EDITOR - emacs en PATH - vim en PATH - notepad en PATH

argumentos posicionales:

usdFileName
El archivo usd a editar.

opciones:

-h, --help
mostrar este mensaje de ayuda y salir
-n, --noeffect
No editar el archivo. Crear el archivo temporal en una ubicación predeterminada guiada por las variables de entorno TMPDIR, TEMP y TMP.
-f, --forcewrite
Anular los permisos del archivo para permitir la escritura.
-p, --prefix PREFIX
Proporcionar un prefijo para el nombre del archivo temporal.
