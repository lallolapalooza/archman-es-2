uu-dd(1) Manual de Comandos Generales uu-dd(1)

NOMBRE

uu-dd - Copiar y, opcionalmente, convertir un recurso del sistema de archivos

SINOPSIS

uu-dd [-h|--help] [-V|--version] [operandos]

DESCRIPCIÓN

Copiar y, opcionalmente, convertir un recurso del sistema de archivos

OPCIONES

-h, --help
Imprimir ayuda
-V, --version
Imprimir versión
[operandos]

EXTRA

### Operandos

- bs=BYTES : leer y escribir hasta BYTES bytes a la vez (por defecto: 512);
sobrescribe ibs y obs. - cbs=BYTES : el 'tamaño de bloque de conversión' en bytes. Se aplica a las
operaciones conv=block y conv=unblock. - conv=CONVS : una lista separada por comas de opciones de conversión o (por razones de
legado) indicadores de archivo. - count=N : dejar de leer la entrada después de N operaciones de lectura del tamaño de ibs
en lugar de continuar hasta el final del archivo (EOF). Consulte iflag=count_bytes si se prefiere detenerse después de N bytes. - ibs=N : el tamaño del búfer utilizado para las lecturas (por defecto: 512) - if=ARCHIVO : el archivo utilizado para la entrada. Cuando no se especifica, se utiliza la entrada estándar (stdin). - iflag=FLAGS : una lista separada por comas de indicadores de entrada que especifican cómo se trata la
fuente de entrada. FLAGS pueden ser cualquiera de los indicadores de entrada o generales
especificados a continuación. - skip=N (o iseek=N) : saltar N registros del tamaño de ibs en la entrada antes de
comenzar las operaciones de copia/conversión. Consulte iflag=seek_bytes si se prefiere saltar N bytes. - obs=N : el tamaño del búfer utilizado para las escrituras (por defecto: 512) - of=ARCHIVO : el archivo utilizado para la salida. Cuando no se especifica, se utiliza la salida estándar (stdout).
- oflag=FLAGS : lista separada por comas de indicadores de salida que especifican cómo se trata la
fuente de salida. FLAGS pueden ser cualquiera de los indicadores de salida o generales
especificados a continuación. - seek=N (o oseek=N) : salta N registros del tamaño de obs en la salida antes de
comenzar las operaciones de copia/conversión. Consulte oflag=seek_bytes si se prefiere saltar N bytes. - status=LEVEL : controla si las estadísticas de volumen y rendimiento se escriben en
stderr.
Cuando no se especifica, dd imprimirá estadísticas al finalizar. Un ejemplo es el siguiente:
```plain
6+0 registros en
16+0 registros de salida
8192 bytes (8,2 kB, 8,0 KiB) copiados, 0,00057009 s,
14,4 MB/s


Las dos primeras líneas son las estadísticas de 'volumen' y la última línea son las
estadísticas de 'rendimiento'.
Las estadísticas de volumen indican el número de lecturas completas y parciales del tamaño de ibs,
o escrituras del tamaño de obs que ocurrieron durante la copia. El formato de las estadísticas de
volumen es <completos>+<parciales>. Si los registros han sido truncados (ver
conv=block), las estadísticas de volumen contendrán el número de registros truncados.


Los valores posibles de LEVEL son:
- progress : Imprime estadísticas de rendimiento periódicas a medida que procede la copia.
- noxfer : Imprime estadísticas de volumen finales, pero no estadísticas de rendimiento.
- none : No imprime ninguna estadística.


La impresión de estadísticas de rendimiento también se activa mediante la señal INFO (donde se admite),
o la señal USR1. Establecer la variable de entorno POSIXLY_CORRECT a cualquier valor
(incluido un valor vacío) hará que se ignore la señal USR1.

### Opciones de Conversión

- ascii : convertir de EBCDIC a ASCII. Esta es la inversa de la opción ebcdic.
Implica conv=unblock. - ebcdic : convertir de ASCII a EBCDIC. Esta es la inversa de la opción ascii.
Implica conv=block. - ibm : convertir de ASCII a EBCDIC, aplicando las convenciones para [, ]
y ~ especificadas en POSIX. Implica conv=block.

- ucase : convertir de minúsculas a mayúsculas. - lcase : convierte de mayúsculas a minúsculas.

- block : para cada nueva línea menor que el tamaño indicado por cbs=BYTES, elimina
la nueva línea y rellena con espacios hasta cbs. Las líneas más largas que cbs se truncan. - unblock : para cada bloque de entrada del tamaño indicado por cbs=BYTES, elimina
los espacios al final a la derecha y los reemplaza con un carácter de nueva línea.

- sparse : intenta buscar la salida cuando un bloque del tamaño de obs consiste
solo en ceros. - swab : intercambia cada par adyacente de bytes. Si hay un número impar de bytes,
se omite el último byte. - sync : rellena cada bloque del tamaño de ibs con ceros. Si se especifica block o unblock,
rellena con espacios en su lugar. - excl : el archivo de salida debe ser creado. Falla si el archivo de salida ya existe.
- nocreat : el archivo de salida no será creado. Falla si el archivo de salida no existe ya.
- notrunc : el archivo de salida no será truncado. Si esta opción no está presente, la salida se truncará al abrirse. - noerror : se ignorarán todos los errores de lectura. Si esta opción no está presente,
dd solo ignorará Error::Interrupted. - fdatasync : los datos se escribirán antes de finalizar. - fsync : los datos y metadatos se escribirán antes de finalizar.

### Indicadores de Entrada

- count_bytes : un valor para count=N se interpretará como bytes. - skip_bytes : un valor para skip=N se interpretará como bytes. - fullblock : espera ibs bytes de cada lectura. Las lecturas de longitud cero todavía se
consideran EOF.

### Indicadores de Salida

- append : abre el archivo en modo de adición. Considere también establecer conv=notrunc. - seek_bytes : un valor para seek=N se interpretará como bytes.

### Indicadores Generales

- direct : usa E/S directa para datos. - directory : falla a menos que la entrada dada (si se usa como iflag) o
la salida (si se usa como oflag) sea un directorio. - dsync : usa E/S síncrona para datos. - sync : usa E/S síncrona para datos y metadatos. - nonblock : usa E/S no bloqueante. - noatime : no actualiza la hora de acceso. - nocache : solicita al SO que elimine la caché. - noctty : no asigna una tty de control. - nofollow : no sigue enlaces del sistema.
