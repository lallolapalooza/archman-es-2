uudoc(1) Manual de Comandos Generales uudoc(1)

NOMBRE

uudoc - Muestra información breve del usuario en sistemas basados en Unix

SINOPSIS

uudoc [-l ] [-b ] [-h ] [-p ] [-s ] [-f ] [-w ] [-i ] [-q ] [--lookup] [--help] [-V|--version] [usuario]

DESCRIPCIÓN

Muestra información breve del usuario en sistemas basados en Unix

OPCIONES

-l
produce salida en formato largo para el(los) USUARIO(s) especificado(s)
-b
omite el directorio de inicio y el shell del usuario en formato largo
-h
omite el archivo de proyectos del usuario en formato largo
-p
omite el archivo plan del usuario en formato largo
-s
produce salida en formato corto, esta es la opción predeterminada
-f
omite la línea de encabezados de columna en formato corto
-w
omite el nombre completo del usuario en formato corto
-i
omite el nombre completo del usuario y el host remoto en formato corto
-q
omite el nombre completo del usuario, el host remoto y el tiempo de inactividad en formato corto
--lookup
intenta canonicalizar los nombres de host a través de DNS
--help
Imprime información de ayuda
-V, --version
Imprime la versión
[usuario]

VERSIÓN
