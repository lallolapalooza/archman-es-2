UMAD_ALLOC(3) Manual del programador de OpenIB UMAD_ALLOC(3)

NOMBRE

umad_alloc - asignar memoria para búferes umad

SINOPSIS

#include <infiniband/umad.h>

void * umad_alloc(int num, size_t size);

DESCRIPCIÓN

umad_alloc() asigna memoria para un array de num búferes umad de size bytes. Tenga en cuenta que size debe incluir el valor de umad_size() más la longitud (MAD_BLOCK_SIZE para MADs normales o la longitud devuelta por umad_recv() para MADs RMPP).

VALOR DE RETORNO

umad_alloc() devuelve NULL si no hay memoria disponible.

VER TAMBIÉN

umad_free(3)
