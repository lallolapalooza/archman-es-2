upscli_set_default_connect_timeout(3)

Paquete: nut

Licencias: GPL-2.0-or-later AND GPL-3.0-or-later

UPSCLI_SET_DEFAULT_C(3) Manual de NUT UPSCLI_SET_DEFAULT_C(3)

NOMBRE

upscli_set_default_connect_timeout - Configura el aspecto del módulo upsclient del tiempo de espera predeterminado para las conexiones iniciales.

SINOPSIS

        #include <upsclient.h>
        int upscli_set_default_connect_timeout(const char *secs);

DESCRIPCIÓN

La función upscli_set_default_connect_timeout() asigna el tiempo de espera predeterminado interno del módulo upsclient para upscli_connect(3) a partir de una cadena C que representa un número de punto flotante no negativo (el análisis inválido se ignora y no modifica el valor almacenado previamente), un argumento nulo establece el tiempo de espera interno en 0, lo que significa bloqueo indefinido (predeterminado de NUT para este método durante al menos 20 años).

Aunque este método se puede llamar explícitamente, se recomienda llamar a upscli_init_default_connect_timeout(3) para una configuración consistente a partir de una serie de fuentes con diferentes prioridades.

VALOR DE RETORNO

La función upscli_set_default_connect_timeout() devuelve 0 en caso de éxito (ya sea si la cadena era nula, por lo que se aplica el valor predeterminado interno de 0, o si su contenido era válido y su valor se aplicó), o -1 si ocurre un error (la cadena no era nula y su contenido no era válido, no es un número, es negativo, etc.).

VER TAMBIÉN

upscli_connect(3), upscli_tryconnect(3), upscli_init_default_connect_timeout(3), upscli_get_default_connect_timeout(3)
