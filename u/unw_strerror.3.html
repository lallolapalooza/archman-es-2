UNW_STRERROR(3libunwind) Biblioteca de programación UNW_STRERROR(3libunwind)

NOMBRE

unw_strerror -- obtener texto correspondiente al código de error

SINOPSIS

#include <libunwind.h>

const char * unw_strerror(int err_code);

DESCRIPCIÓN

La rutina unw_strerror() mapea el (negativo) err_code a un mensaje de texto correspondiente y lo devuelve.

VALOR DE RETORNO

El mensaje que corresponde a err_code o, si el err_code no tiene un mensaje correspondiente, el texto "código de error inválido".

SEGURIDAD DE HILOS Y SEÑALES

unw_strerror() es seguro para hilos y también seguro para usar desde un manejador de señales.
