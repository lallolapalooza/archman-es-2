NOMBRE

uhd_images_downloader - Descargador de firmware/FPGA del controlador de hardware USRP

DESCRIPCIÓN

El paquete UHD es el controlador de hardware universal para productos de Ettus Research. El objetivo de UHD es proporcionar un controlador de host y una API para los productos actuales y futuros de Ettus Research. Los usuarios podrán utilizar el controlador UHD de forma independiente o con aplicaciones de terceros.

Este programa instala los binarios de firmware y FPGA de Ettus Research que coinciden con esta versión del controlador UHD en el sistema anfitrión. Si el paquete uhd-images está instalado, no es necesario ejecutar este instalador.

SINOPSIS

uhd_images_downloader Uso: uhd_images_downloader [opciones]

OPCIONES

Este programa funciona mejor sin argumentos.


-h, --help mostrar este mensaje de ayuda y salir


--download-location=UBICACIÓN_DESCARGA
Establecer una ubicación de descarga personalizada para las imágenes,
[por defecto=/usr/share/uhd/images]


--buffer-size=TAMAÑO_BUFFER
Establecer el tamaño del búfer de descarga, [por defecto=8192]
