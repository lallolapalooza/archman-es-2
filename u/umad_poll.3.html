UMAD_POLL(3) Manual del programador de OpenIB UMAD_POLL(3)

NOMBRE

umad_poll - sondea umad

SINOPSIS

#include <infiniband/umad.h>

int umad_poll(int portid, int timeout_ms);

DESCRIPCIÓN

umad_poll() espera hasta timeout_ms milisegundos a que se reciba un paquete del puerto especificado por portid. Una vez que un paquete está listo para ser leído, la función devuelve 0. Después de eso, el paquete se puede leer usando umad_recv(). De lo contrario, se devuelve -ETIMEDOUT.

Tenga en cuenta que sonear un puerto con éxito no garantiza que la llamada posterior a umad_recv() no sea bloqueante cuando varios hilos estén utilizando el mismo puerto. En su lugar, utilice un parámetro timeout_ms de cero para umad_recv() para asegurar una lectura no bloqueante.

VALOR DEVUELTO

umad_poll() devuelve 0 en caso de éxito y un valor negativo en caso de error, como se indica a continuación:
-EINVAL identificador de puerto o agentid no válido
-ETIMEDOUT la operación de sondeo expiró
-EIO la operación de sondeo falló

VER TAMBIÉN
