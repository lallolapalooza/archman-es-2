CUNGTR

Propósito:

!>
!> CUNGTR genera una matriz unitaria compleja Q que se define como el
!> producto de n-1 reflectores elementales de orden N, como se devuelve
!> por CHETRD:
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U': El triángulo superior de A contiene los reflectores
!>                 elementales de CHETRD;
!>          = 'L': El triángulo inferior de A contiene los reflectores
!>                 elementales de CHETRD.
!>

N

!>          N es INTEGER
!>          El orden de la matriz Q. N >= 0.
!>

A

!>          A es un array COMPLEX, dimension (LDA,N)
!>          En la entrada, los vectores que definen los reflectores
!>          elementales, como se devuelve por CHETRD.
!>          En la salida, la matriz unitaria N por N, Q.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= N.
!>

TAU

!>          TAU es un array COMPLEX, dimension (N-1)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), como se devuelve por CHETRD.
!>

WORK

!>          WORK es un array COMPLEX, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= N-1.
!>          Para un rendimiento óptimo LWORK >= (N-1)*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array
!>          WORK, devuelve este valor como la primera entrada del array
!>          WORK, y XERBLA no emite ningún mensaje de error relacionado
!>          con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

UNGTR(3) - LAPACK

NAME

UNGTR — generates a complex unitary matrix Q

SYNOPSIS

CALL UNGTR(UPLO, N, A, LDA, TAU, WORK, LWORK, INFO)

subroutine ungtr(uplo, n, a, lda, tau, work, lwork, info)

character(len=1) :: uplo
integer :: n
complex(kind=8), dimension(lda, *) :: a
integer :: lda
complex(kind=8), dimension(*) :: tau
complex(kind=8), dimension(*) :: work
integer :: lwork
integer :: info

Description

The **UNGTR** routines are used to compute the non-unitary transformations represented by

A complex unitary matrix Q which is defined as the product of n-1 elementary reflectors of order N, as returned by CHETRD:

  • if UPLO = 'U', Q = H(n-1) ... H(2) H(1),
  • if UPLO = 'L', Q = H(1) H(2) ... H(n-1).

Each H(i) has the form

H(i) = I - tau(i) * v * vH

where tau(i) is a complex scalar and v(i) is a complex vector with zeros in the first i-1 positions. i.e. v(i) is a (n-i+1) by 1 vector.

If UPLO = 'U', then v(i) is stored within the vector

(A(1:i-1, i), tau(i))

and on entry A(1:i-1, i) contains the elements of v(i) and tau(i) as computed by CHETRD. If UPLO = 'L', then v(i) is stored within the

(A(i, i:n), tau(i))

and on entry A(i, i:n) contains the elements of v(i) and tau(i) as computed by CHETRD.

If UPLO = 'U', then A is overwritten by the unitary matrix Q.

If UPLO = 'L', then A is overwritten by the unitary matrix Q.

subroutine SORGTR(CHARACTER UPLO, INTEGER N, REAL, dimension( LDA, * ) A, INTEGER LDA, REAL, dimension( * ) TAU, REAL, dimension( * ) WORK, INTEGER LWORK, INTEGER INFO)

SORGTR

Purpose:

!>
!> SORGTR generates a real orthogonal matrix Q which is defined as the
!> product of n-1 elementary reflectors of order N, as returned by
!> SSYTRD:
!>
!> if UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> if UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U': Upper triangle of A contains elementary reflectors
!>                 from SSYTRD;
!>          = 'L': Lower triangle of A contains elementary reflectors
!>                 from SSYTRD.
!>

N

!>          N is INTEGER
!>          The order of the matrix Q. N >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the vectors which define the elementary reflectors,
!>          as returned by SSYTRD.
!>          On exit, the N-by-N orthogonal matrix Q.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= N.
!>

TAU

!>          TAU is REAL array, dimension (N-1)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by SSYTRD.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,N-1).
!>          For optimum performance LWORK >= (N-1)*NB, where NB is
!>          the optimal blocksize.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
