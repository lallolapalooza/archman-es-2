UMAD_SET_PKEY(3) Manual del programador de OpenIB UMAD_SET_PKEY(3)

NOMBRE

umad_set_pkey - establece el índice pkey dentro del búfer umad

SINOPSIS

#include <infiniband/umad.h>

int umad_set_pkey(void *umad, int pkey_index);

DESCRIPCIÓN

umad_set_pkey() establece el índice pkey dentro del búfer umad especificado.

VALOR DE RETORNO

umad_set_pkey() devuelve 0 si tiene éxito y un valor negativo en caso de error.
