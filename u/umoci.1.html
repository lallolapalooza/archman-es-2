NOMBRE

umoci - umoci modifica imágenes OCI

SINOPSIS

umoci [--help|-h] [--version|-v] [--log={debug|info|warn|error|fatal}] [--verbose] comando [argumentos]

DESCRIPCIÓN

umoci es una herramienta que permite la modificación de alto nivel de un diseño de imagen OCI y sus imágenes etiquetadas. Aunque umoci intenta abstraer las especificidades de la especificación de imagen OCI, se recomienda que los usuarios de esta herramienta lean la especificación ⟨https://github.com/opencontainers/image-spec⟩ para asegurarse de que entienden la idea general.

umoci es único en el sentido de que es, en el momento de escribir esto, la primera herramienta que permite la modificación arbitraria de una imagen OCI de forma de alto nivel (donde todas las diferentes partes (blobs) en una imagen OCI son gestionadas por umoci al realizar una operación de alto nivel como umoci-repack(1)).

OPCIONES GLOBALES

--help, -h
Imprime el enunciado de uso.

--version, -v
Imprime la versión.

--cpu-profile=nombrearchivo
Genera un perfil de CPU durante la ejecución de umoci y lo guarda en nombrearchivo.
Este archivo se almacena en el formato pprof de Go ⟨https://golang.org/pkg/runtime/pprof/⟩ y puede ser analizado usando la herramienta go
tool pprof o herramientas similares.

--log={debug|info|warn|error|fatal}
Establece el nivel de registro. El valor predeterminado es "warn".

--verbose
Alias de --log=info.

COMANDOS

init
Crea un nuevo diseño OCI. Consulte umoci-init(1) para obtener información de uso más detallada.
información.

new
Crea una imagen OCI etiquetada en blanco. Consulte umoci-new(1) para obtener información de uso más detallada.
información.

unpack
Desempaqueta una imagen etiquetada en un paquete de ejecución OCI. Consulte umoci-unpack(1)
para obtener información de uso más detallada.

repack
Empaqueta un paquete de ejecución OCI en una imagen etiquetada. Consulte umoci-repack(1)
para obtener información de uso más detallada.

config
Modifica la configuración de la imagen de una imagen OCI. Consulte umoci-config(1) para
obtener información de uso más detallada.

stat
Muestra información de estado de un manifiesto de imagen. Consulte umoci-stat(1) para
obtener información de uso más detallada.

tag
Crea una nueva etiqueta en una imagen OCI. Consulte umoci-tag(1) para obtener información de uso más detallada.
información.

remove, rm
Elimina una etiqueta de una imagen OCI. Consulte umoci-remove(1) para obtener información de uso más detallada.
información.

list, ls
Lista el conjunto de etiquetas en una imagen OCI. Consulte umoci-list(1) para obtener información de uso más detallada.
información.

gc
Recoge basura de todas las partes (blobs) de imagen OCI sin referencia. Consulte umoci-gc(1) para
obtener información de uso más detallada.
