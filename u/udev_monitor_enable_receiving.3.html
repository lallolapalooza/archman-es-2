udev_monitor_enable_receiving(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

UDEV_MONITOR_RECEIVE_DEVICE(3) udev_monitor_receive_device UDEV_MONITOR_RECEIVE_DEVICE(3)

NOMBRE

udev_monitor_receive_device, udev_monitor_enable_receiving, udev_monitor_set_receive_buffer_size, udev_monitor_get_fd, udev_monitor_get_udev - Consultar y modificar el monitor de dispositivos

SINOPSIS

#include <libudev.h>

struct udev_device *udev_monitor_receive_device(struct udev_monitor *udev_monitor);

int udev_monitor_enable_receiving(struct udev_monitor *udev_monitor);

int udev_monitor_set_receive_buffer_size(struct udev_monitor *udev_monitor, int size);

int udev_monitor_get_fd(struct udev_monitor *udev_monitor);

struct udev *udev_monitor_get_udev(struct udev_monitor *udev_monitor);

VALOR DE RETORNO

En caso de éxito, udev_monitor_receive_device() devuelve un puntero a un dispositivo recién referenciado que se recibió a través del monitor. El llamador es responsable de liberar esta referencia cuando termine. En caso de fallo, devuelve NULL.

En caso de éxito, udev_monitor_enable_receiving() y udev_monitor_set_receive_buffer_size() devuelven un entero mayor que, o igual a, 0. En caso de fallo, se devuelve un código de error negativo.

En caso de éxito, udev_monitor_get_fd() devuelve el descriptor de archivo utilizado por este monitor. En caso de fallo, se devuelve un código de error negativo.

udev_monitor_get_udev() siempre devuelve un puntero al contexto udev con el que está asociado este monitor.

HISTORIA

udev_monitor_receive_device(), udev_monitor_enable_receiving(), udev_monitor_set_receive_buffer_size(), udev_monitor_get_fd(), y udev_monitor_get_udev() se añadieron en la versión 221.
