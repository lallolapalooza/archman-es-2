UPMPDCLI.CONF(5) Upmpdcli UPMPDCLI.CONF(5)

NOMBRE

upmpdcli.conf - documentación de upmpdcli.conf

DESCRIPCIÓN

upmpdcli.conf es el archivo de configuración para upmpdcli(1). Su ubicación debe indicarse al programa ya sea a través de la variable de entorno UPMPD_CONFIG o a través de la opción de línea de comandos -c.

Cada línea en el archivo de configuración contiene un nombre de configuración y su valor, por ejemplo:

logfilename = /tmp/upmpdcli.log

Casi todas las variables de configuración tienen valores predeterminados adecuados, y la distribución del programa incluye un archivo de ejemplo, típicamente instalado en /etc, donde se enumeran y comentan las variables.

Deberías echar un vistazo al manual en línea para obtener información más completa: http://www.lesbonscomptes.com/upmpdcli/upmpdcli-manual.html

PARÁMETROS

logfilename = fn
Nombre del archivo de registro. Por defecto es stderr. Esto también se puede especificar como -d logfilename.
loglevel = int
Nivel de registro. También se puede especificar como -l loglevel.
upnplogfilename = fn
Nombre del archivo de registro para la librería UPnP de bajo nivel (libnpupnp). Este registro no está activo si esta variable no está establecida. Utiliza un valor vacío para que los mensajes vayan a stderr.
upnploglevel = int
Nivel de registro para la librería UPnP de bajo nivel. Por razones históricas, los valores correspondientes son 1 menos que los valores equivalentes para el registro de upmpdcli. 4 es muy verboso.
pkgdatadir = dfn
Directorio de almacenamiento de XML y otros datos constantes. Por defecto: '$prefix/share/upmpdcli' (por ejemplo: '/usr/share/upmpdcli').
pidfile = fn
Nombre del archivo de bloqueo utilizado para almacenar el PID del proceso actual. Solo se utiliza si el proceso es iniciado por el usuario root. Utilizado por el sistema de inicio y para evitar múltiples instancias. La única razón para cambiar el valor es si realmente quieres tener varias instancias en ejecución (cambia también cachedir en este caso).
upnpiface = cstr
Interfaz(ces) de red a utilizar para UPnP. Esto se puede dejar vacío para usar la primera interfaz adecuada encontrada, o establecerlo a un solo carácter "*" para usar todas las interfaces. De lo contrario, establécelo a una lista separada por espacios de nombres de interfaz (usa comillas dobles si los nombres tienen caracteres de espacio incrustados).
upnpip = string
Dirección IP V4 a utilizar para UPnP, alternativa al uso de un nombre de interfaz.
upnpport = int
Número de puerto utilizado para UPnP. libupnp/pupnp utiliza por defecto el primer puerto libre después de 49152. Ten en cuenta que los clientes no necesitan conocer el valor, que se descubre automáticamente.
useipv6 = bool
Habilita el uso de IPV6. Por defecto solo usamos IPV4.
friendlyname = string
"Nombre Amigable" para el Reproductor Multimedia. La mayoría de los Puntos de Control lo mostrarán para identificar al Reproductor. Algunos Puntos de Control OpenHome pueden mostrar el valor 'ohproductroom' en su lugar.
avfriendlyname = string
Nombre amigable específico para el Reproductor Multimedia UPnP/AV. Por defecto es añadir "-av" al valor de friendlyname.
upnpav = bool
Habilita los servicios UPnP AV (0/1). Esto está habilitado por defecto, pero puede ser útil desactivarlo para evitar saturar las opciones de Reproductor si solo usas OpenHome.
openhome = bool
Habilita los servicios OpenHome (0/1). Por defecto es 1, ya que la cola de OpenHome es superior para la mayoría de los usos. Debería haber pocas razones para desactivarlo.
lumincompat = bool
Deshabilita el servicio de Credenciales OpenHome. En algún momento, fue necesario habilitar Lumin para que viera instancias de upmpdcli: por alguna razón desconocida, Lumin 1.10 no descubría upmpdcli con las Credenciales habilitadas.
ohinfotexttodata = bool
Almacena metadatos en la variable "metatext" de OpenHome. Los servicios de Información OpenHome deben contener datos diferentes, principalmente para radios, con datos de radio permanentes (icono, URL, nombre de la radio) establecidos en la variable "Metadata", y la información sobre el título actual registrada en la variable "Metatext". Establecer esta opción hará que upmpdcli almacene cualquier dato Metatext no vacío en la variable Metadata. Esto ayudará a algunos reproductores a mostrar la carátula del álbum para el título actual (por ejemplo, Kazoo).
checkcontentformat = bool
Comprueba que el formato de entrada sea compatible. Extrae la información de protocolinfo de los metadatos de entrada y la compara con nuestros formatos soportados. Establece esta opción a 0 si un punto de control o servidor multimedia envía datos de audio correctos con metadatos incorrectos.
iconpath = fn
Ruta al icono del Reproductor. La imagen será mostrada por los Puntos de Control que la soporten. El protocolo UPnP tiene disposiciones para que un reproductor envíe la URL de un icono descriptivo como parte de la descripción del dispositivo. Debido a las limitaciones actuales (y probablemente permanentes) de *upmpdcli*, el archivo de imagen *debe* ser un archivo png de 64x64 píxeles con 32 bits por píxel. Por defecto: '$pkgdatadir/icon.png'. El icono solo se leerá una vez, cuando upmpdcli se inicie.
saveohcredentials = bool
Guarda los parámetros de inicio de sesión de los servicios de streaming en disco. Esto permite compartir la contraseña con el proxy del servicio de streaming del servidor multimedia upmpdcli, si también lo estás utilizando. Evita tener que introducir la contraseña en el archivo de configuración normal. Dependiendo de tu situación, puedes ver esto como un riesgo de seguridad. El valor por defecto es verdadero, porque no lo veo como un problema real en el caso general.
opensslcmd = fn
Ruta al comando openssl. El servicio OHCredentials necesita openssl 1.1.x o más reciente. Ruta al comando openssl a utilizar si el del sistema (en /usr/bin) es demasiado antiguo. No está configurado por defecto.
cachedir = dfn
Directorio utilizado para almacenar datos cacheados. Actualmente solo se utiliza para los metadatos de la cola OpenHome. El valor por defecto es ~/.cache/upmpdcli para usuarios normales o /var/cache/upmpdcli cuando upmpdcli se inicia como root.
presentationhtml = fn
Ruta al documento HTML de presentación. Puedes cambiarlo para reemplazar la página de presentación por defecto. La página solo se leerá una vez, cuando upmpdcli se inicie. Actualmente no se puede utilizar para actualizaciones de estado (pero supongo que podrías poner una redirección ahí, a algo más dinámico servido por un servidor HTTP real). Por defecto: '$pkgdatadir/presentation.html'.
enablel16 = bool
Anuncia soporte para el formato L16. L16 es un flujo de audio lineal sin procesar de 16 bits y es la fuente de muchos problemas porque no incluye información de identificación. Solía estar deshabilitado por defecto, debido a un error de mpd que resultaba en mucho ruido. Ahora está habilitado por defecto, pero aún se puede deshabilitar si es necesario. Parece que a veces interfiere mal con la función de "transmitir a dispositivo" de win10, por lo que puedes intentar desactivarlo si tienes problemas con esto.
mpdhost = string
Host en el que se ejecuta MPD. Por defecto es localhost. Esto también se puede especificar como -h host
mpdport = int
Puerto IP utilizado por MPD. También se puede especificar como -p port. Por defecto es el puerto normal de MPD, 6600.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

mpdpassword = cadena
Contraseña de MPD. Contraseña para conectarse a MPD (solo es necesaria si el acceso con contraseña está habilitado en el archivo de configuración de MPD).
mpdtimeoutms = entero
Tiempo de espera de la conexión MPD en milisegundos. Si no es cero, los diálogos con mpd expirarán después del valor. Esto permitirá que upmpdcli permanezca responsivo (devuelva errores) si MPD alguna vez se queda colgado.
ownqueue = booleano
Establecer si poseemos la cola de MPD. Si está establecido (activado por defecto), poseemos la cola de MPD y la limpiaremos sin miedo. También se puede especificar como -q 0|1.
onstart = fn
Comando a ejecutar cuando la reproducción está a punto de comenzar. Especifique la ruta completa del programa, por ejemplo, /usr/bin/logger.
onplay = fn
Comando a ejecutar cuando el estado de MPD cambie a "PLAY". Especifique la ruta completa del programa, por ejemplo, /usr/bin/logger.
onpause = fn
Comando a ejecutar cuando el estado de MPD cambie a "PAUSE". Especifique la ruta completa del programa, por ejemplo, /usr/bin/logger.
onstop = fn
Comando a ejecutar cuando el estado de MPD cambie a "STOP". Especifique la ruta completa del programa, por ejemplo, /usr/bin/logger.
onstandby = fn
Comando a ejecutar cuando se llama a la acción setstandby. Especifique la ruta completa del programa. Se llama con un argumento 0/1 para cambiar el estado de espera (1 para activar la espera), y sin argumentos para consultar el estado. En todos los casos, debe imprimir el estado de espera (0/1) en la salida estándar antes de salir.
externalvolumecontrol = fn
Utilice un comando externo para gestionar el volumen del sonido (0/1). Esto se utiliza en el caso en que MPD no pueda controlar el volumen, pero algún otro comando sí pueda, por ejemplo, si tiene un amplificador externo en el que es posible configurar y leer el volumen a través de scripts. Si está configurado, las llamadas a MPD para configurar y leer el volumen serán reemplazadas por ejecuciones de 'onvolumechange' y 'getexternalvolume'.
getexternalvolume = fn
Comando a ejecutar para leer el volumen del sonido. El comando debe escribir un valor numérico de 0 a 100 en la salida estándar.
onvolumechange = fn
Comando a ejecutar para establecer el volumen. Se utiliza cuando está activado 'externalvolumecontrol'. Especifique la ruta completa del programa, que se llama con el volumen como primer argumento, por ejemplo, /some/script 85.
avtautoplay = cadena
Finge automáticamente un comando de Reproducción cuando se establece la pista. El UPnP/AV SetAVTransportURI, utilizado para establecer la pista a reproducir, normalmente no cambia el estado de transporte actual: se requiere un comando de Reproducción explícito para comenzar a reproducir si el transporte estaba detenido. Establecer este parámetro sintetizará un comando de Reproducción después de recibir SetAVTransportURI. Esto es necesario para algunos puntos de control que no envían el comando de Reproducción.
ohproductroom = cadena
El nombre de la habitación donde se encuentra el Producto. Por defecto se establece en "Habitación Principal", se muestra en lugar del "nombre amigable" por algunos puntos de control. ProductRoom se utiliza para agrupar el Producto con otros Productos relacionados en la misma habitación física (por ejemplo, una fuente con un preamplificador). Los Productos que están físicamente vinculados deben compartir siempre el mismo nombre de ProductRoom.
radiolist = fn
Ruta a un archivo externo con definiciones de radio. Las estaciones de radio se pueden definir en este archivo (archivo de configuración principal), o en un archivo externo (o ambos). Usar un archivo externo puede facilitar la distribución a múltiples máquinas, hace las cosas más claras y ahora es el predeterminado. Consulte el archivo distribuido (nombre a continuación) para obtener información sobre cómo definir una estación de radio. En caso de que desee definir radios en el archivo de configuración principal, DEBEN aparecer al final del archivo (ya que se definen como subsecciones, la última de las cuales se extiende hasta el final del archivo).
radioscripts = fn
Directorio de scripts de metadatos de radio. Ruta de un directorio donde se encuentran los scripts utilizados para obtener los metadatos del canal. El valor predeterminado es /usr/share/upmpdcli/radio_scripts. Tenga en cuenta que los scripts siempre se buscan primero en las ubicaciones definidas por $PATH.
ohmanufacturername = cadena
Nombre del fabricante.
ohmanufacturerinfo = cadena
Información del fabricante.
ohmanufacturerurl = cadena
URL del sitio web del fabricante.
ohmanufacturerimageuri = cadena
URI del logotipo del fabricante.
ohmodelname = cadena
Nombre del modelo.
ohmodelinfo = cadena
Información del modelo.
ohmodelurl = cadena
URL del sitio web del modelo.
ohmodelimageuri = cadena
URI del icono del modelo.
ohproductname = cadena
Nombre del producto visible por el usuario. Por defecto, se establece en ModelName.
ohproductinfo = cadena
Información del producto.
ohproducturl = cadena
URL del sitio web del producto. Esta puede ser la página de presentación de UPnP.
ohproductimageuri = cadena
URI de la imagen del producto.
ohmetapersist = booleano
Guardar metadatos de la cola en disco (0/1). Esto permite la persistencia de la información de metadatos entre reinicios, el valor predeterminado es 1, y no hay razón para desactivarlo.
ohmetasleep = entero
Intervalo mínimo (Segundos) entre dos guardados de caché. Aumentar esto puede mejorar la velocidad de carga de la lista de reproducción en un dispositivo lento. El valor predeterminado es iniciar un nuevo guardado tan pronto como el anterior haya terminado (si la lista cambió de nuevo en el intermedio).
msfriendlyname = cadena
Nombre amigable para el Servidor Multimedia (si está habilitado). Por defecto, se añade "-mediaserver" al valor de friendlyname.
msrootalias = cadena
Alias raíz del Servidor Multimedia ID de Objeto. Utilice el contenedor del Servidor Multimedia especificado como raíz. El Punto de Control mostrará directamente este contenedor al conectarse, lo que evitará tener que saltar por los niveles superiores si no los utiliza. (Por ejemplo, la lista de plugins activos si solo hay un plugin). El valor es un ID de objeto UPnP, que lamentablemente no se puede obtener generalmente de los Puntos de Control. Sin embargo, los valores comúnmente útiles son simples: - `0$uprcl$` Acceso directo a la raíz de Medios Locales - `0$uprcl$folders` Acceso directo al árbol de [carpetas] de Medios Locales.

Un alias debe comenzar con `0` (que es el ID de objeto raíz UPnP obligatorio), seguido de `$nombreplugin$` donde _nombreplugin_ podría ser cualquier subdirectorio de `/usr/share/upmpdcli/cdplugins` excepto `pycommon` (por ejemplo, `uprcl`, `qobuz`, `upradios`...), y el resto dependería del tipo de plugin.

plgmicrohttphost = cadena
Nombre de host/dirección IP utilizada en las URLs del proxy. Por defecto, se utiliza la misma host/dirección que el servidor UPnP. Usar localhost/127.0.0.1 en su lugar pierde la capacidad de transmitir a un renderizador remoto, pero permite listas de reproducción portátiles.
plgmicrohttpport = entero
Puerto IP para el servicio local HTTP de tidal/qobuz. Las URLs de las pistas transmitidas desde estos servicios apuntan a un servidor microhttpd local que se ejecuta en este puerto (utiliza redirección a la URL del servicio real cuando realmente se está transmitiendo). El valor predeterminado es 49149.
plgproxymethod = cadena
Decide si proxy (copiar: obtener/servir) o redirigir los streams de los servicios de transmisión. Usar redirección es mucho más eficiente, pero el proxy tiene una instalación para reintentar cuando un stream es descartado por el servicio, lo que parece suceder especialmente con Qobuz.
msiconpath = fn
Ruta al icono del Servidor Multimedia. La imagen será mostrada por los Puntos de Control que la soporten. Debido a las limitaciones actuales (y probablemente permanentes) de *upmpdcli*, el archivo de imagen *debe* ser un archivo png de 64x64 con 32 bits por píxel. Predeterminado: '$pkgdatadir/icon.png'. El icono solo se leerá una vez, cuando se inicie upmpdcli.
webserverdocumentroot = fn
Directorio desde el cual el servidor HTTP interno servirá archivos directamente. Esto está deshabilitado por defecto para compatibilidad con versiones anteriores que nunca sirvieron archivos directamente desde el sistema de archivos. Algunos plugins de Mediaserver solicitan habilitarlo, por ejemplo, para servir archivos de icono (normalmente desde directorios bajo /usr/share/upmpdcli/www).
hrauser = cadena
Nombre de usuario de Hra. Su nombre de inicio de sesión de Hra.
hrapass = cadena
Contraseña de Hra. La contraseña de su cuenta de Hra.
hralang = cadena
Configuración de idioma de Hra (en/de). Algunos mensajes de Highresaudio.

sccvttype = cstr
Método de remuestreo de sc2mpd. Solo se usa para scplaymethod=alsa. sc2mpd usa libsamplerate. El método por defecto es SRC_SINC_FASTEST y una Raspberry Pi 1 es lo suficientemente rápida para usarlo. Valores posibles: SRC_SINC_BEST_QUALITY, SRC_SINC_MEDIUM_QUALITY, SRC_SINC_FASTEST, SRC_ZERO_ORDER_HOLD, SRC_LINEAR. Consulta la documentación de libsamplerate para obtener descripciones. Cualquier cosa por encima de SRC_SINC_FASTEST necesita una CPU seria. BEST_QUALITY usa aproximadamente un 25% de CPU en un core i7 4770T. Obviamente demasiado, de hecho podría no ser sostenible (es casi el 100% de 1 CPU). MEDIUM_QUALITY está alrededor del 10% en la misma máquina, FASTEST es 4-5%. Dado que esto se mide para todo el proceso, probablemente un par de % para la conversión en realidad. NONE desactivará el remuestreo: CPU mínima y la mejor calidad, pero con fallos garantizados de vez en cuando, dependiendo de la desviación de los relojes.
