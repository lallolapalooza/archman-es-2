upscli_list_start(3)

Paquete: nut

UPSCLI_LIST_START(3) Manual de NUT UPSCLI_LIST_START(3)

NOMBRE

upscli_list_start - Inicia la recuperación de múltiples elementos de un UPS

SINOPSIS

        #include <upsclient.h>
        int upscli_list_start(UPSCONN_t *ups, size_t numq, const char **query)

DESCRIPCIÓN

La función upscli_list_start() toma el puntero ups a una estructura de estado UPSCONN_t, y el puntero query a una matriz de numq elementos de consulta. Construye una solicitud formateada correctamente a partir de esos elementos y la transmite a upsd(8).

En caso de éxito, el llamador debe llamar a upscli_list_next(3) para recuperar los elementos de la lista. La omisión de recuperar la lista probablemente provocará que el cliente se desincronice con el servidor debido a datos en búfer.

USOS

Esta función implementa el comando "LIST" en el protocolo. Como resultado, puede usarla para solicitar muchas cosas diferentes del servidor. Algunos ejemplos son:

•LIST UPS
•LIST VAR <ups>
•LIST RW <ups>
•LIST CMD <ups>
•LIST ENUM <ups> <var>
•LIST RANGE <ups> <var>

FORMATO DE LA CONSULTA

Para ver la lista de variables en un UPS llamado su700, el comando del protocolo sería LIST VAR su700. Para iniciar esa lista con esta función, usted poblaría query y numq de la siguiente manera:

        size_t numq;
        const char *query[2];
        query[0] = "VAR";
        query[1] = "su700";
        numq = 2;

Todos los escapes de caracteres especiales y el entrecomillado de elementos con espacios son manejados por esta función.

VERIFICACIÓN DE ERRORES

Esta función verifica la respuesta de upsd(8) contra su consulta. Si no está iniciando una lista, o está iniciando el tipo incorrecto de lista, devolverá un código de error.

Cuando esto sucede, upscli_upserror(3) devolverá UPSCLI_ERR_PROTOCOL.

VALOR DE RETORNO

La función upscli_list_start() devuelve 0 en caso de éxito, o -1 si ocurre un error.
