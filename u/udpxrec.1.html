NOMBRE

udpxrec - una utilidad programable de grabación de tráfico multicast.

SINOPSIS

udpxrec [-v] [-b <tiempo_inicio>] [-e <tiempo_fin>] [-M <tamaño_archivo_max>] [-p <archivo_pid>] [-B <tamaño_buffer_KB>] [-n <incremento_nice>] [-u <segundos_espera>] [-m <direccion_interfaz_multicast>] [-l <archivo_log>] -c <direccion_fuente>:<puerto> <archivo_destino>

DESCRIPCIÓN

udpxrec es una utilidad diseñada para grabar (guardar en un archivo en disco) un segmento de tráfico de red multicast; la cantidad de datos guardados/grabados se puede especificar en longitud (KB) o duración (segundos).

OPCIONES

udpxrec acepta las siguientes opciones:

-v
Habilita la salida detallada [predeterminado = deshabilitado].
-T
NO ejecutar como demonio [predeterminado = demonio si es root].
-m <direccion_interfaz_multicast>
Dirección/interfaz IPv4 de la fuente (multicast) [predeterminado = 0.0.0.0].
-l <archivo_log>
Registrar salida en archivo [predeterminado = stderr].
-n <incremento_nice>
Incremento del valor nice [predeterminado = 0].
-B <tamaño_buffer_KB>
Tamaño del búfer (65536, 32Kb, 1Mb) para datos entrantes (multicast) [predeterminado = 2048 bytes].
-R <mensajes>
Número máximo de mensajes a poner en búfer (-1 = todos) [predeterminado = 1].
-b <tiempo_inicio>
Comenzar a grabar a las [+]dd:hh24:mi.ss, '+' significa tiempo relativo (en N horas/min/seg).
-e <tiempo_fin>
Dejar de grabar a las [+]dd:hh24:mi.ss, '+' significa tiempo relativo (en N horas/min/seg).
-M <tamaño_archivo_max>
Tamaño máximo del archivo de destino.
-p <archivo_pid>
Archivo PID para este proceso [DEBE especificarse si se ejecuta como demonio].
-u <segundos_espera>
Segundos a esperar antes de actualizar sobre cuánto falta para que comience la grabación.

EJEMPLOS

udpxrec -b 15:45.00 -e +2:00.00 -M 1.5Gb -n 2 -B 64K -c 224.0.11.31:5050 /opt/video/tv5.mpg

Comenzar a grabar el canal multicast 224.0.11.31:5050 hoy a las 15:45, terminar de grabar en dos horas o si el tamaño del archivo de destino es >= 1.5 Gb; establecer el búfer del socket a 64Kb; incrementar el valor nice en 2; escribir el video capturado en /opt/video/tv5.mpg.
