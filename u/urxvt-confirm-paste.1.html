NOMBRE

confirm-paste - pide confirmación antes de pegar caracteres de control

DESCRIPCIÓN

Muestra un diálogo de confirmación cuando se detecta un pegado que contiene caracteres de control. El usuario puede elegir "y" para pegar una variante saneada donde se eliminan todos los caracteres de control, "p" para pegar la cadena sin modificar o "n" para descartar la solicitud de pegado completamente.

Esto está pensado principalmente como un mecanismo de defensa en profundidad para protegerse contra el error común del navegador web de seleccionar algún texto pero que el navegador pegue un texto completamente diferente, lo que tiene un potencial de ataque.

También puede ser útil para evitar que pegues accidentalmente grandes cantidades de texto.

DETALLES

Si se pega en la terminal una cadena que contiene caracteres de control unicode (específicamente U+0000 .. U+001F actualmente), esta extensión preguntará si debe ser pegada. Las cadenas sin caracteres de control se pegan sin aviso.

Cuando se pega una versión saneada (opción "y"), las secuencias contiguas de esos caracteres de control se reemplazarán por un solo espacio.

El algoritmo exacto de detección y saneamiento está sujeto a cambios en versiones futuras.
