UMAD_CLASS_STR(3) Manual del programador de OpenIB UMAD_CLASS_STR(3)

NOMBRE

umad_*_str - clase de funciones para devolver representaciones en cadena de enumeraciones

SINOPSIS

#include <infiniband/umad_str.h>

const char * umad_class_str(uint8_t mgmt_class)
const char * umad_method_str(uint8_t mgmt_class, uint8_t method)
const char * umad_attribute_str(uint8_t mgmt_class, be16_t attr_id)
const char * umad_common_mad_status_str(be16_t status)
const char * umad_sa_mad_status_str(be16_t status)

DESCRIPCIÓN

const char * umad_class_str(uint8_t mgmt_class) Devuelve el valor en cadena de la enumeración de clase de gestión.

const char * umad_method_str(uint8_t mgmt_class, uint8_t method) Devuelve el valor en cadena del método para la clase de gestión especificada.

const char * umad_attribute_str(uint8_t mgmt_class, be16_t attr_id) Devuelve el valor en cadena del atributo especificado en `attr_id` según la clase de gestión especificada.

const char * umad_common_mad_status_str(be16_t status) Devuelve el valor en cadena para los estados comunes de MAD.

const char * umad_sa_mad_status_str(be16_t status) Devuelve el valor en cadena para los estados de MAD de SA.

NOTA: No todas las clases son compatibles.

VALOR DE RETORNO

Devuelve representaciones en cadena de los campos especificados.
