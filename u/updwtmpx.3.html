updwtmp(3) Manual de funciones de biblioteca updwtmp(3)

NOMBRE

updwtmp, logwtmp - añadir una entrada al archivo wtmp

BIBLIOTECA

Biblioteca de utilidades del sistema (libutil, -lutil)

SINOPSIS

#include <utmp.h>
void updwtmp(const char *wtmp_path, const struct utmp *ut);
void logwtmp(const char *line, const char *name, const char *host);

DESCRIPCIÓN

updwtmp() añade la estructura utmp ut al archivo wtmp.

logwtmp() construye una estructura utmp utilizando line, name, host, la hora actual y el ID de proceso actual. Luego llama a updwtmp() para añadir la estructura al archivo wtmp.

ARCHIVOS

/var/log/wtmp
base de datos de inicios de sesión de usuarios anteriores

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
updwtmp (), logwtmp () Seguridad de hilos MT-Unsafe sig:ALRM timer

VERSIÓNES

Para mayor consistencia con las otras funciones "utmpx" (véase getutxent(3)), glibc proporciona (desde glibc 2.1):


#define _GNU_SOURCE          /* Véase feature_test_macros(7) */
#include <utmpx.h>
void updwtmpx (const char *wtmpx_path, const struct utmpx *utx);

Esta función realiza la misma tarea que updwtmp(), pero se diferencia en que toma una estructura utmpx como su último argumento.

ESTÁNDARES

Ninguno.

HISTORIA

Solaris, NetBSD.

VER TAMBIÉN

getutxent(3), wtmp(5)
