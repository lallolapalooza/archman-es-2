PROLOG

Esta página del manual forma parte del Manual del Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

unset — anula valores y atributos de variables y funciones

SINOPSIS

unset [-fv] nombre...

DESCRIPCIÓN

Cada variable o función especificada por nombre será anulada.

Si se especifica -v, nombre se refiere a un nombre de variable y el shell la anulará y la eliminará del entorno. Las variables de solo lectura no pueden ser anuladas.

Si se especifica -f, nombre se refiere a una función y el shell anulará la definición de la función.

Si no se especifica ni -f ni -v, nombre se refiere a una variable; si no existe una variable con ese nombre, es indeterminado si se anulará una función con ese nombre, en caso de que exista.

Anular una variable o función que no se anuló previamente no se considerará un error y no provocará que el shell se aborte.

El built-in especial unset soportará el volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2, Directrices de Sintaxis de Utilidades.

Tenga en cuenta que:

VARIABLE=

no es equivalente a una anulación de VARIABLE; en el ejemplo, VARIABLE se establece en "". Además, las variables que se pueden anular no deben malinterpretarse como que incluyen los parámetros especiales (ver Sección 2.5.2, Parámetros Especiales).

USO DE LA APLICACIÓN

Ninguno.

EJEMPLOS

Anular la variable VISUAL:

unset -v VISUAL

Anular las funciones foo y bar:

unset -f foo bar

FUNDAMENTACIÓN

Se consideró omitir la opción -f en favor de una utilidad unfunction, pero los desarrolladores del estándar decidieron mantener la práctica histórica.

La opción -v se introdujo porque System V históricamente utilizaba un solo espacio de nombres para variables y funciones. Cuando unset se usaba sin opciones, System V históricamente anulaba una función o una variable, y no había confusión sobre cuál era la prevista. Una aplicación POSIX portable puede usar unset sin una opción para anular una variable, pero no una función; se debe usar la opción -f.

unset(1p) - Linux manual pages

NOMBRE

unset - eliminar variables y funciones

SINOPSIS

unset [-fv] [-n] [nombre ...]

DESCRIPCIÓN

Elimina variables y funciones. Si se proporciona algún nombre, se eliminarán las variables o funciones especificadas. Si no se proporcionan nombres, se mostrará un mensaje de error.

Las opciones son:

-f
Elimina funciones.
-v
Elimina variables.
-n
No marcar la variable como indirecta.

VALOR DE RETORNO

Se devuelve éxito a menos que se especifique una opción no válida.

CONSECUENCIAS DE LOS ERRORES

Si se especifica una opción no válida, la utilidad terminará con un estado de salida distinto de cero.

USO DE LA APLICACIÓN

El comando unset se utiliza para eliminar variables de entorno o funciones definidas en el shell actual. Es importante tener cuidado al eliminar variables, ya que algunas variables son esenciales para el funcionamiento del sistema o de aplicaciones específicas.

EJEMPLOS

Para eliminar una variable llamada MI_VARIABLE:

unset MI_VARIABLE

Para eliminar una función llamada MI_FUNCION:

unset -f MI_FUNCION

Para eliminar tanto una variable como una función con el mismo nombre:

unset -fv MI_NOMBRE

FUNDAMENTO

La utilidad unset es parte del estándar POSIX para shells. Permite a los usuarios y scripts gestionar el entorno del shell eliminando elementos que ya no son necesarios. Esto puede ser útil para limpiar el espacio de nombres o para revertir cambios realizados en variables.

DIRECCIONES FUTURAS

No hay direcciones futuras específicas para esta utilidad, ya que es una función básica del shell.

VER TAMBIÉN

env(1), export(1), set(1)
