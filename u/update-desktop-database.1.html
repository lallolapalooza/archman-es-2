UPDATE-DESKTOP-DATABASE(1) Manual de comandos generales UPDATE-DESKTOP-DATABASE(1)

NOMBRE

update-desktop-database - Construye una base de datos de caché de tipos MIME manejados por archivos de escritorio

SINOPSIS

update-desktop-database [-q|--quiet] [-v|--verbose] [DIRECTORIO...]

DESCRIPCIÓN

El programa update-desktop-database es una herramienta para construir una base de datos de caché de los tipos MIME manejados por archivos de escritorio.

La base de datos de caché contiene la lista de tipos MIME que pueden ser manejados por archivos de escritorio, así como, para cada tipo MIME, una lista de archivos de escritorio que pueden manejar este tipo MIME. Esta base de datos de caché facilita el trabajo de las aplicaciones que necesitan encontrar una aplicación que pueda abrir un documento de un tipo MIME específico: esas aplicaciones no tendrán que analizar todos los archivos de escritorio existentes en el sistema, y podrán en su lugar analizar esta base de datos de caché.

Si no se especifica ningún DIRECTORIO como argumento, los archivos de escritorio que se procesarán son los instalados en $XDG_DATA_DIRS/applications.

Si se utilizan ambas opciones --quiet y --verbose, entonces --verbose será ignorada.

OPCIONES

Se admiten las siguientes opciones:

-q, --quiet
No mostrar ninguna información sobre el progreso del procesamiento y la actualización.
-v, --verbose
Mostrar más información sobre el progreso del procesamiento y la actualización.

NOTAS

Si se encuentra un tipo MIME inválido, será ignorado y la creación de la base de datos de caché continuará.

El formato de la base de datos de caché es un formato simple de entrada de escritorio, con un grupo MIME Cache, que contiene una clave por tipo MIME. El nombre de la clave es el tipo MIME, y el valor de la clave es la lista de archivos de escritorio que pueden manejar este tipo MIME.

El orden de los archivos de escritorio encontrados para un tipo MIME no es significativo. Por lo tanto, se debe usar un mecanismo externo para determinar cuál es el archivo de escritorio preferido para un tipo MIME.

EJEMPLO

Aquí hay un ejemplo simple de una base de datos de caché:


[MIME Cache]
application/x-shellscript=gedit.desktop;
text/plain=gedit.desktop;gvim.desktop;
video/webm=totem.desktop;

Esta base de datos de caché se crea con tres archivos de escritorio, cada uno contiene una clave MimeType:


gedit.desktop: MimeType=text/plain;application/x-shellscript;
gvim.desktop: MimeType=text/plain;
totem.desktop: MimeType=video/webm;

ARCHIVOS

$XDG_DATA_DIRS/applications/mimeinfo.cache

Este archivo es la base de datos de caché creada por update-desktop-database.

ERRORES

Si encuentra errores en el programa update-desktop-database, por favor repórtelos en https://bugs.freedesktop.org.
