umu(5) Manual de Formatos de Archivo umu(5)

NOMBRE

umu-run - archivo de configuración

DESCRIPCIÓN

umu-run puede leer opcionalmente un archivo de configuración en lugar de leer variables de entorno establecidas desde la línea de comandos. El archivo de configuración para umu-run debe estar escrito en Tom's Obvious Minimal Language (TOML)[1].

En el archivo de configuración, la tabla umu es requerida, así como las claves prefix, proton y exe, las cuales deben ser cadenas básicas. Por ejemplo:

[umu]
prefix = "~/WINE/epic-games-store"
exe = "~/EpicGamesLauncher.exe"
proton = "~/.local/share/Steam/compatibilitytools.d/GE-Proton30"

Después, ejecuta el comando:

$ umu-run --config config.toml

SECCIÓN [umu]

exe

Ruta al ejecutable del juego a ejecutar. El valor debe ser una cadena básica.

proton

Ruta a un directorio de Proton. El valor debe ser una cadena básica.

prefix

Ruta a un directorio de prefijo WINE. El valor debe ser una cadena básica.

game_id

El id de umu que se asignará al juego. Dependiendo del valor asignado, se aplicará una corrección de proton al prefijo si está disponible. Por favor, consulta la base de datos[2] de umu para una lista extendida de ids de juego.

store

La plataforma de distribución del ejecutable. El valor debe ser una cadena básica. Espera los valores: egs, gog, battlenet, amazon, humble, itchio y ubisoft.

launch_args

Argumentos de lanzamiento para el ejecutable. El valor debe ser una cadena básica o un array de cadenas básicas. Al usar una cadena, se asume que cada argumento está separado por espacios.
