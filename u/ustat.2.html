ustat(2) Manual de llamadas al sistema ustat(2)

NOMBRE

ustat - obtener estadísticas del sistema de archivos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/types.h>
#include <unistd.h>    /* libc[45] */
#include <ustat.h>     /* glibc2 */
[[deprecated]] int ustat(dev_t dev, struct ustat *ubuf);

DESCRIPCIÓN

ustat() devuelve información sobre un sistema de archivos montado. dev es un número de dispositivo que identifica un dispositivo que contiene un sistema de archivos montado. ubuf es un puntero a una estructura ustat que contiene los siguientes miembros:


daddr_t f_tfree;      /* Bloques libres totales */
ino_t   f_tinode;     /* Número de inodos libres */
char    f_fname[6];   /* Nombre del sistema de archivos */
char    f_fpack[6];   /* Nombre del paquete del sistema de archivos */

Los dos últimos campos, f_fname y f_fpack, no están implementados y siempre se rellenarán con bytes nulos ('\0').

VALOR DE RETORNO

En caso de éxito, se devuelve cero y la estructura ustat apuntada por ubuf se rellenará. En caso de error, se devuelve -1, y errno se establecerá para indicar el error.

ERRORES

EFAULT
ubuf apunta fuera de su espacio de direcciones accesible.
EINVAL
dev no se refiere a un dispositivo que contenga un sistema de archivos montado.
ENOSYS
El sistema de archivos montado referenciado por dev no soporta esta operación, o cualquier versión de Linux anterior a Linux 1.3.16.

ESTÁNDARES

Ninguno.

HISTORIA

SVr4. Eliminado en glibc 2.28.

ustat() está obsoleto y solo se ha proporcionado por compatibilidad. Todos los programas nuevos deberían usar statfs(2) en su lugar.

NOTAS HP-UX

La versión de HP-UX de la estructura ustat tiene un campo adicional, f_blksize, que es desconocido en otros lugares. HP-UX advierte: Para algunos sistemas de archivos, el número de inodos libres no cambia. Tales sistemas de archivos devolverán -1 en el campo f_tinode. Para algunos sistemas de archivos, los inodos se asignan dinámicamente. Tales sistemas de archivos devolverán el número actual de inodos libres.

VER TAMBIÉN

stat(2), statfs(2)
