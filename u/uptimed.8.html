UPTIMED(8) Manual del Administrador del Sistema UPTIMED(8)

NOMBRE

uptimed - demonio para registrar récords de tiempo de actividad

SINOPSIS

uptimed [ -hbv ] [ -e <email> ] [ -i <intervalo> ] [ -m <contador> ]

DESCRIPCIÓN

Esta página del manual documenta el programa uptimed.

uptimed es un demonio que registra estadísticas sobre el tiempo de actividad de una máquina. Utilice el programa uprecords(1) para obtener estadísticas de récords de tiempo de actividad.

OPCIONES

Estas opciones de línea de comandos anulan los ajustes en el archivo de configuración /etc/uptimed.conf

-h
Mostrar uso
-b
Crear bootid y salir. Esta opción se ignora en sistemas BSD, ya que el kernel BSD mantiene una variable de tiempo de arranque estática en memoria, por lo que Uptimed no necesita almacenar este valor en caché.
-p <archivo>
Escribir PID a pidfile <archivo>
-e <email>
Enviar correo electrónico a <email> en hitos/récords
-i <intervalo>
Usar <intervalo> segundos para el bucle
-m <contador>
Registrar un máximo de <contador> entradas
-t <timespec>
Establecer el tiempo de actividad mínimo para ser considerado un récord
-v
Mostrar información de la versión

VER TAMBIÉN

uprecords(1)
