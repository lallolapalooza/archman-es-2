UCARP(8) Manual del Administrador del Sistema UCARP(8)

NOMBRE

ucarp — Conmutación por error automática de IP

SINOPSIS

ucarp [-i, --interface=INTERFAZ] [-s, --srcip=DIRECCIONIP]
[-v, --vhid=VHID] [-p, --pass=CONTRASEÑA] [-o, --passfile=ARCHIVO_CONTRASEÑA]
[-P, --preempt] [-n, --neutral] [-a, --addr=DIRECCIONIP] [-h, --help]
[-b, --advbase=SEGUNDOS] [-k, --advskew=SESGO] [-u, --upscript=SCRIPT]
[-d, --downscript=SCRIPT] [-r, --deadratio=RATIO] [-z, --shutdown]
[-B, --daemonize] [-f, --facility=FACILIDAD] [-x, --xparam PARAM]
[-S, --ignoreifstate] [-M, --nomcast]

DESCRIPCIÓN

ucarp permite que un par de hosts compartan direcciones IP comunes para proporcionar conmutación por error automática de una dirección de una máquina a otra. Es una implementación portable en espacio de usuario del Protocolo de Redundancia de Direcciones Común (CARP), seguro y libre de patentes, la alternativa de OpenBSD a VRRP.

OPCIONES

ucarp soporta las siguientes opciones de línea de comandos:

-i INTERFAZ --interface=INTERFAZ
La interfaz de red a la que unirse.
-s DIRECCIONIP --srcip=DIRECCIONIP
La dirección IP persistente (IP real) asociada con esta interfaz.
-v VHID --vhid=VHID
El ID del servidor virtual [1-255].
-p CONTRASEÑA --pass=CONTRASEÑA
La contraseña compartida (esta se encripta y no se envía en texto claro).
-o ARCHIVO_CONTRASEÑA --passfile=ARCHIVO_CONTRASEÑA
Archivo desde el cual leer la contraseña compartida. El archivo especificado debe contener la contraseña en la primera línea del archivo.
-P --preempt
Activar la conmutación por error preemptiva. Esto hace que una instancia de ucarp asuma el estado maestro inmediatamente.
-n --neutral
No ejecutar el script de descenso al inicio cuando el estado inicial es backup.
-a DIRECCIONIP --addr=DIRECCIONIP
La dirección IP del servidor virtual.
-h --help
Mostrar un resumen breve de las opciones de la línea de comandos.
-b SEGUNDOS --advbase=SEGUNDOS
Intervalo en segundos en el que ocurrirán los anuncios, (por defecto 1 segundo).
-k SESGO --advskew=SESGO
Sesgo de anuncio [1-255], (por defecto 0).
-u COMANDO --upscript=COMANDO
Especifica el comando a ejecutar después de que ucarp se haya convertido exitosamente en maestro. El nombre de la interfaz se pasa como argumento. Típicamente es un script utilizado para activar la dirección virtual, registrar el resultado, añadir rutas, limpiar entradas de caché ARP, etc.
-d COMANDO --downscript=COMANDO
Especifica el comando que se ejecuta después de que ucarp transicione al estado de backup. El nombre de la interfaz se pasa como argumento. Típicamente es un script utilizado para desactivar la interfaz virtual, registrar la acción, eliminar rutas, etc.
-r RATIO --deadratio=RATIO
Ratio utilizado por el backup para determinar cuánto esperar a un maestro no respondiente antes de considerarlo muerto.
-z --shutdown
El uso de este comando hace que el comando especificado por el argumento -d sea invocado cuando ucarp se apague.
-B --daemonize
Hace que ucarp se desvincule de la terminal y se ejecute en segundo plano como un demonio.
-f --facility
Establece la instalación de syslog, por defecto es daemon.
-x PARAMETRO --xparam=PARAMETRO
Especifica un parámetro adicional que se proporcionará a los scripts de encendido/apagado.
-S --ignoreifstate
Ignorar cables de red desconectados. Esta opción es útil cuando los nodos ucarp están conectados con un cable cruzado. Sin esta opción, el maestro transicionará a backup cuando el otro nodo se apague, ya que ya no tendrá enlace (SIN_PORTADOR).
-M --nomcast
Usar broadcast en lugar de anuncios multicast.

EJEMPLOS

Un host con una IP real de 10.1.1.10 configurado para ser el maestro en una configuración preemptiva con una IP virtual de 10.1.1.252.

    ucarp -i eth0 -s 10.1.1.10 -v 10 -p secret -a 10.1.1.252 \
    --upscript=/usr/local/sbin/vip-up.sh --downscript=/usr/local/sbin/vip-down.sh -P

El backup podría configurarse algo así.

    ucarp -i eth0 -s 10.1.1.11 -v 10 -p secret -a 10.1.1.252 \
    --upscript=/usr/local/sbin/vip-up.sh --downscript=/usr/local/sbin/vip-down.sh

Una máquina con una IP real de 192.168.1.19 es el maestro preferido para una IP virtual de 10.1.12.7, los broadcasts se envían cada 5 segundos.

    ucarp -b 5 -s 192.168.1.19 -v 27 -p mala_contraseña -a 10.1.12.7 \
    -u /usr/local/sbin/vip-up.sh -d /usr/local/sbin/vip-down.sh -z

El standby caliente con una IP de 192.168.1.20 usa el siguiente comando, (nota el sesgo de anuncio de 50 poniéndolo en desventaja y haciendo que la primera máquina sea preferida).

    ucarp -b 5 -k 50 -s 192.168.1.20 -v 27 -p mala_contraseña -a 10.1.12.7 \
    -u /usr/local/sbin/vip-up.sh -d /usr/local/sbin/vip-down.sh -z

SEÑALES

Enviar a SIGUSR1 al proceso ucarp hará que registre una línea de estado en syslog, ej: "Sep 13 12:59:56 localhost ucarp[2654]: [INFO] MASTER en eth0 id 1" o "Sep 13 13:00:25 localhost ucarp[2644]: [INFO] BACKUP en eth0 id 1"

Enviar a SIGUSR2 al proceso ucarp hará que se degrade de maestro a backup, espere 3 segundos, y luego proceda normalmente escuchando a otros maestros, y promoviéndose si es necesario. Esto podría ser útil si desea que otro nodo asuma el rol de maestro.
