unpack200(1) Herramientas de despliegue de Java unpack200(1)

NOMBRE

unpack200 - Transforma un archivo empaquetado producido por pack200(1) en un archivo JAR para el despliegue web.

SINOPSIS

unpack200 [ opciones ] archivo-entrada archivo-JAR
opciones
Las opciones de línea de comandos. Ver Opciones.
archivo-entrada
Nombre del archivo de entrada, que puede ser un archivo gzip empaquetado con pack200 o un archivo pack200. La entrada también puede ser un archivo JAR producido por pack200(1) con un esfuerzo de 0, en cuyo caso el contenido del archivo de entrada se copia al archivo JAR de salida con el marcador Pack200.
archivo-JAR
Nombre del archivo JAR de salida.

DESCRIPCIÓN

El comando unpack200 es una implementación nativa que transforma un archivo empaquetado producido por pack200(1) en un archivo JAR. Un uso típico es el siguiente. En el siguiente ejemplo, el archivo myarchive.jar se produce a partir de myarchive.pack.gz con la configuración predeterminada del comando unpack200.

unpack200 myarchive.pack.gz myarchive.jar

OPCIONES

-Hvalor --deflate-hint=valor

Establece la descompresión a true, false o keep en todas las entradas dentro de un archivo JAR. El modo predeterminado es keep. Si el valor es true o false, la opción --deflate=hint anula el comportamiento predeterminado y establece el modo de descompresión en todas las entradas dentro del archivo JAR de salida.
-r --remove-pack-file

Elimina el archivo pack de entrada.
-v --verbose

Muestra mensajes mínimos. Múltiples especificaciones de esta opción muestran mensajes más detallados.
-q --quiet

Especifica operación silenciosa sin mensajes.
-larchivo --log-file=archivo

Especifica un archivo de registro donde se registran los mensajes de salida.
-? -h --help

Imprime información de ayuda sobre el comando unpack200.
-V --version

Imprime información de versión sobre el comando unpack200.
-Jopción

Pasa la opción a la Máquina Virtual Java, donde opción es una de las opciones descritas en la página de referencia del lanzador de aplicaciones Java. Por ejemplo, -J-Xms48m establece la memoria de inicio en 48 MB. Ver java(1).

NOTAS

Este comando no debe confundirse con el comando unpack. Son productos distintos.

La Especificación de la API de Java SE proporcionada con el JDK es la autoridad que prevalece en caso de discrepancias.

ESTADO DE SALIDA

Los siguientes valores de salida se devuelven: 0 para una finalización exitosa y un valor mayor que 0 cuando ocurrió un error.
