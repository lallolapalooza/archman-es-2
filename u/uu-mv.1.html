uudoc(1) Manual de Comandos Generales uudoc(1)

NOMBRE

uudoc - Mover SOURCE a DEST, o múltiples SOURCE(s) a DIRECTORIO.

SINOPSIS

uudoc [-f|--force] [-i|--interactive] [-n|--no-clobber] [--strip-trailing-slashes] [--backup] [-b ] [-S|--suffix] [--update] [-u ] [-t|--target-directory] [-T|--no-target-directory] [-v|--verbose] [-g|--progress] [-Z ] [--context] [--debug] [-h|--help] [-V|--version] <archivos>

DESCRIPCIÓN

Mover SOURCE a DEST, o múltiples SOURCE(s) a DIRECTORIO.

OPCIONES

-f, --force
no preguntar antes de sobrescribir
-i, --interactive
preguntar antes de sobrescribir
-n, --no-clobber
no sobrescribir un archivo existente
--strip-trailing-slashes
eliminar las barras inclinadas finales de cada argumento SOURCE
--backup[=<CONTROL>]
crear una copia de seguridad de cada archivo de destino existente
-b
similar a --backup pero no acepta un argumento
-S, --suffix <SUFIJO>
reemplazar el sufijo de copia de seguridad habitual
--update
mover solo cuando el archivo SOURCE es más nuevo que el archivo de destino o cuando el archivo de destino falta

[posibles valores: none, all, older, none-fail]

-u
similar a --update pero no acepta un argumento
-t, --target-directory <DIRECTORIO>
mover todos los argumentos SOURCE al DIRECTORIO
-T, --no-target-directory
tratar DEST como un archivo normal
-v, --verbose
explicar lo que se está haciendo
-g, --progress
Mostrar una barra de progreso. Nota: esta función no es compatible con GNU coreutils.
-Z
establecer el contexto de seguridad SELinux del archivo de destino al tipo predeterminado
--context[=<CTX>]
similar a -Z, o si se especifica CTX, establecer el contexto de seguridad SELinux a CTX
--debug
explicar cómo se copia un archivo. Implica -v
-h, --help
Imprimir ayuda
-V, --version
Imprimir versión
<archivos>

EXTRA

Al especificar más de una de las opciones -i, -f, -n, solo la última tendrá efecto.

No mover un no-directorio que tenga un destino existente con la misma marca de tiempo de modificación o más reciente; en su lugar, omitir silenciosamente el archivo sin fallar. Si la operación de mover atraviesa los límites del sistema de archivos, la comparación se realiza con la marca de tiempo de origen truncada a las resoluciones del sistema de archivos de destino y de las llamadas al sistema utilizadas para actualizar las marcas de tiempo; esto evita trabajo duplicado si se ejecutan varios comandos mv -u con el mismo origen y destino. Esta opción se ignora si también se especifica la opción -n o --no-clobber. que proporciona más control sobre qué archivos existentes en el destino se reemplazan, y su valor puede ser uno de los siguientes:

- all Esta es la operación predeterminada cuando no se especifica una opción --update, y resulta en el reemplazo de todos los archivos existentes en el destino. - none Esto es similar a la opción --no-clobber, en el sentido de que no se reemplazan archivos en el destino, pero omitir un archivo tampoco provoca un fallo. - older Esta es la operación predeterminada cuando se especifica --update, y resulta en el reemplazo de archivos si son más antiguos que el archivo fuente correspondiente.

El sufijo de copia de seguridad es '~', a menos que se establezca con --suffix o SIMPLE_BACKUP_SUFFIX. El método de control de versiones puede ser seleccionado a través de la opción --backup o mediante la variable de entorno VERSION_CONTROL. Aquí están los valores:


none, off nunca hacer copias de seguridad (incluso si se proporciona --backup)
numbered, t hacer copias de seguridad numeradas
existing, nil numeradas si existen copias de seguridad numeradas, simples en caso contrario
simple, never siempre hacer copias de seguridad simples
