NOMBRE

unibi_from_mem - construir un objeto de terminal a partir de una entrada terminfo compilada

SINOPSIS

#include <unibilium.h>

unibi_term *unibi_from_mem(const char *p, size_t n);

DESCRIPCIÓN

Esta función analiza una entrada terminfo compilada que comienza en p y tiene una longitud de n bytes, y construye un objeto "unibi_term" a partir de ella. Cuando haya terminado con este objeto, debe llamar a "unibi_destroy" para liberarlo.

"unibi_from_mem" analiza tanto el formato tradicional de terminfo de ncurses (que comienza con los bytes "1A 01") como el formato más reciente de "enteros anchos" (que comienza con los bytes "1E 02").

VALOR DE RETORNO

Un puntero a un nuevo "unibi_term". En caso de fallo, se devuelve "NULL" y se establece "errno".

ERRORES

"EINVAL"
Los bytes a los que apunta p no parecen ser una entrada terminfo válida.
"EFAULT"
n es demasiado pequeño para una entrada terminfo válida.
