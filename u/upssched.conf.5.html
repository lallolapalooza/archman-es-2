NOMBRE

upssched.conf - Configuración del programa temporizador upssched

DESCRIPCIÓN

Este archivo controla las operaciones de upssched(8), el programa auxiliar basado en temporizadores para upsmon(8).

NOTAS IMPORTANTES

•El contenido de este archivo debe ser texto ASCII puro (los códigos de caracteres que no estén en el rango se ignorarán con un mensaje de advertencia).

DIRECTIVAS DE CONFIGURACIÓN

CMDSCRIPT nombre_script

Requerido. Este script se utiliza para invocar comandos cuando se activan los temporizadores. Recibe un único argumento que es el nombre del temporizador que provocó su activación.

PIPEFN nombre_archivo

Requerido. Establece el nombre del archivo del socket que se utilizará para la comunicación entre procesos. Debe estar en un directorio donde los usuarios normales no puedan crear el archivo, debido a la posibilidad de enlaces simbólicos y otras acciones maliciosas.

Precaución

Si estás ejecutando Solaris o un sistema similar, los permisos que upssched establece en este archivo no son suficientes para mantenerte seguro. Si tu sistema operativo ignora los permisos en una FIFO, ¡entonces DEBES colocarlo en un directorio protegido!


Nota

por defecto, upsmon(8) ejecutará upssched como el usuario que hayas definido con RUN_AS_USER en upsmon.conf(5). Asegúrate de que ese usuario pueda crear y escribir archivos en la ruta que utilices para PIPEFN y LOCKFN.

Mi recomendación: crea un directorio especial para upssched, haz que sea propiedad de tu usuario de upsmon, y luego úsalo para ambos.

La versión estándar de upssched.conf se envía con PIPEFN deshabilitado para que visites esta parte de la documentación y pienses en cómo funciona tu sistema antes de potencialmente abrir una brecha de seguridad.

LOCKFN nombre_archivo

Requerido. upssched intenta crear este archivo para evitar una condición de carrera cuando dos eventos se envían desde upsmon casi al mismo tiempo. Este archivo solo existirá brevemente. No debe ser creado por ningún otro proceso.

Deberías colocarlo en el mismo directorio que PIPEFN.

AT tiponotificación nombre_ups comando

Define un manejador para un evento específico tiponotificación en el UPS nombre_ups. nombre_ups puede ser el valor especial * para aplicar este manejador a todos los UPS.

Esto realizará el comando comando cuando el tiponotificación y el nombre_ups coincidan con la actividad actual. Los valores posibles para comando son:

START-TIMER nombre_temporizador intervalo

Inicia un temporizador de intervalo segundos. Cuando se active, pasará el argumento nombre_temporizador como argumento a tu CMDSCRIPT.

Ejemplo:

Inicia un temporizador que se ejecutará cuando cualquier UPS (*) haya estado caído durante 10 segundos

AT COMMBAD * START-TIMER upsgone 10

CANCEL-TIMER nombre_temporizador [cmd]

Cancela un temporizador en ejecución llamado nombre_temporizador, si es posible. Si el temporizador ya pasó, pasa el argumento opcional cmd a CMDSCRIPT.

Ejemplo:

Si un UPS específico (myups@localhost) vuelve a estar en línea, detén el temporizador antes de que se active

AT COMMOK myups@localhost CANCEL-TIMER upsgone

EXECUTE comando

Pasa inmediatamente comando como argumento a CMDSCRIPT.

Ejemplo:

Si cualquier UPS (*) vuelve a la energía de la red, ejecuta ups-back-on-line a través de CMDSCRIPT.

AT ONLINE * EXECUTE ups-back-on-line

Ten en cuenta que se utilizará cualquier AT que coincida tanto con el tiponotificación como con el nombre_ups para el evento actual.

Para obtener una lista completa de los valores posibles de tiponotificación, consulta la sección EVENTOS DE NOTIFICACIÓN en upsmon(8).
