uu_env(1) Manual de comandos generales uu_env(1)

NOMBRE

uu_env - Establece cada NOMBRE a VALOR en el entorno y ejecuta COMANDO

SINOPSIS

uu_env [-i|--ignore-environment] [-C|--chdir] [-0|--null] [-f|--file] [-u|--unset] [-v|--debug]... [-S|--split-string] [-a|--argv0] [--ignore-signal] [-h|--help] [-V|--version] [vars]

DESCRIPCIÓN

Establece cada NOMBRE a VALOR en el entorno y ejecuta COMANDO

OPCIONES

-i, --ignore-environment
comienza con un entorno vacío
-C, --chdir <DIR>
cambia el directorio de trabajo a DIR
-0, --null
termina cada línea de salida con un byte 0 en lugar de una nueva línea (solo válido cuando se imprime el entorno)
-f, --file <PATH>
lee y establece variables desde un archivo de configuración estilo ".env" (antes de cualquier unset y/o set)
-u, --unset <NOMBRE>
elimina la variable del entorno
-v, --debug
imprime información detallada para cada paso de procesamiento
-S, --split-string <S>
procesa y divide S en argumentos separados; se usa para pasar múltiples argumentos en líneas shebang
-a, --argv0 <a>
Anula el argumento cero pasado al comando que se está ejecutando. Sin esta opción se usa un valor predeterminado de `command`.
--ignore-signal <SIG>
establece el manejo de la(s) señal(es) SIG para que no haga nada
-h, --help
Imprime la ayuda
-V, --version
Imprime la versión
[vars]

EXTRA

Un simple - implica -i. Si no hay COMANDO, imprime el entorno resultante.
