UPSC(8) Manual de NUT UPSC(8)

NOMBRE

upsc - Cliente ligero de NUT de solo lectura

SINOPSIS

upsc -l | -L [host]

upsc ups [variable]

upsc -c ups

DESCRIPCIÓN

upsc se proporciona como una forma rápida de consultar el estado de un servidor UPS. Se puede utilizar dentro de scripts de shell y otros programas que necesiten datos de UPS pero no quieran incluir la interfaz completa.

OPCIONES

-l host

Lista todos los nombres de UPS configurados en host, un nombre por línea. El nombre del host por defecto es "localhost". Opcionalmente, puede añadir dos puntos y un número de puerto.

-L host

Al igual que arriba, lista todos los nombres de UPS configurados en host, incluyendo su descripción proporcionada por el upsd(8) remoto desde su ups.conf(5). El nombre del host por defecto es "localhost". Opcionalmente, puede añadir dos puntos y un número de puerto para anular el puerto por defecto.

-c ups

Lista cada cliente conectado en ups, un nombre por línea.

ups

Muestra el estado de ese UPS. El formato para esta opción es nombre_ups[@nombre_host[:puerto]]. El nombre de host por defecto es "localhost".

variable

Muestra solo el valor de esta variable. Por defecto, upsc recupera la lista de variables del servidor y luego muestra el valor de cada una. Esta opción puede ser útil en scripts de shell para evitar una canalización adicional a grep.

OPCIONES COMUNES

-h

Muestra el mensaje de ayuda de la línea de comandos.

-V

Muestra el banner de la versión de NUT. Pueden estar disponibles más detalles si también exporta NUT_DEBUG_LEVEL=1 o un nivel de verbosidad superior.

-W secs

Establece el tiempo de espera para las conexiones de red iniciales (por defecto, son indefinidamente no bloqueantes, o hasta que el sistema interrumpe el intento). Anula la variable de entorno opcional NUT_DEFAULT_CONNECT_TIMEOUT.

EJEMPLOS

Para listar todas las variables en un UPS llamado "myups" en un host llamado "mybox", con upsd(8) ejecutándose en el puerto 1234:

:; upsc myups@mybox:1234
battery.charge: 100.0
battery.voltage: 13.9
battery.voltage.nominal: 13.6
. . .

Para listar los UPS configurados en este sistema, junto con sus descripciones:

:; upsc -L
apc: Back-UPS 500
ppro2: Patriot Pro II

Para recuperar el estado de todos los UPS conectados a mybox, usando sintaxis de Bourne-shell:

:; for UPS in `upsc -l mybox:1234`; do
    upsc $UPS ups.status
done

Para listar los clientes conectados en "myups":

:; upsc -c myups
127.0.0.1
::1
192.168.1.2

MODO DE SCRIPT

Si ejecuta este programa dentro de un script de shell o similar para obtener la lista de dispositivos y variables, solo debe considerar usar la salida de stdout, no stderr.

DIAGNÓSTICOS

upsc imprimirá una lista de nombres de UPS, una lista de todas las variables soportadas y sus valores en el UPS, o un mensaje de error. Si recibe un error, asegúrese de haber especificado un UPS válido en la línea de comandos, de que upsd(8) se está ejecutando realmente en el otro host y de que ningún firewall le está bloqueando.

HISTORIA

Versiones anteriores de este programa utilizaban la biblioteca upsfetch y sockets UDP para comunicarse con upsd. Esta versión de upsc utiliza la nueva biblioteca upsclient, que solo se comunica por TCP. Por eso upsct ya no existe.
