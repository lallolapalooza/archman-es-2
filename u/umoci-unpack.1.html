NOMBRE

umoci unpack - Desempaqueta una etiqueta de imagen OCI en un paquete de ejecución

SINOPSIS

umoci unpack --image=imagen[:etiqueta] [--rootless] [--uid-map=valor] [--uid-map=valor] [--keep-dirlinks] paquete

DESCRIPCIÓN

Extrae todas las capas (de forma determinista) a un paquete de ejecución OCI en la ruta paquete, además de generar una configuración de ejecución OCI que corresponde a la configuración de la imagen. Adicionalmente, se genera una especificación de mtree(8) en el momento del desempaquetado para permitir la generación de diferencias de sistema de archivos mediante umoci-repack(1) y, por lo tanto, permitir la creación de imágenes OCI en capas.

OPCIONES

Las opciones globales se definen en umoci(1).

--image=imagen[:etiqueta]
La etiqueta de la imagen OCI que se extraerá al paquete. imagen debe ser una
ruta a una imagen OCI válida y etiqueta debe ser una etiqueta válida en la imagen. Si
no se proporciona etiqueta, por defecto será "latest".

--rootless
Habilita el soporte de desempaquetado sin privilegios (rootless). Esto permite usar
umoci-unpack(1) y umoci-repack(1) como un usuario no privilegiado. El uso de esta bandera
implica --uid-map=0:$(id -u):1 y --gid-map=0:$(id -g):1, así como
la habilitación de varias características para simular partes del desempaquetado en un intento
de generar una extracción lo más cercana posible del sistema de archivos. Tenga en cuenta que
casi siempre es imposible extraer perfectamente una imagen OCI con
--rootless, pero será lo más cercano posible.

--uid-map=valor
Especifica un mapeo de UID a usar durante el desempaquetado (y reempaquetado) de capas. Esto
se usa de forma similar a user_namespaces(7), y tiene el formato
container:host[:size].

--gid-map=valor
Especifica un mapeo de GID a usar durante el desempaquetado (y reempaquetado) de capas. Esto
se usa de forma similar a user_namespaces(7), y tiene el formato
container:host[:size].

--keep-dirlinks
En lugar de sobrescribir directorios que son enlaces a otros directorios cuando
las capas superiores tienen un directorio explícito, simplemente escribe a través del enlace simbólico.
Esta opción está inspirada en la opción de rsync con el mismo nombre.

EJEMPLO

Lo siguiente descarga una imagen de un registro de docker(1) usando skopeo(1), desempaqueta dicha imagen y luego crea un nuevo contenedor usando el paquete de ejecución OCI extraído con runc(8). Luego, la imagen se reempaqueta con umoci-repack(1).

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
# umoci unpack --image image bundle
# runc run -b bundle ctr
[ sesión del contenedor ]
# umoci repack --image image bundle

Con --rootless también es posible realizar el ejemplo anterior sin privilegios de root. umoci generará una configuración que funciona con contenedores sin privilegios en runc(8).

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
% umoci unpack --image image --rootless bundle
% runc --root $HOME/runc run -b bundle ctr
[ sesión de contenedor sin privilegios ]
% umoci repack --image image --rootless bundle

VER TAMBIÉN

umoci(1), umoci-repack(1), runc(8)

umoci unpack
