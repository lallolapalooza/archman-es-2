USBIP(8) Utilidades de administración del sistema USBIP(8)

NOMBRE

usbipd - Demonio del servidor USB/IP

SINOPSIS

usbipd [opciones]

DESCRIPCIÓN

usbipd proporciona a los clientes USB/IP acceso a dispositivos USB exportados.

Los dispositivos deben exportarse explícitamente usando usbip bind antes de que usbipd los ponga a disposición de otros hosts.

El demonio acepta conexiones de clientes USB/IP en el puerto TCP 3240 por defecto.

OPCIONES

-4, --ipv4

Enlazar a IPv4. El valor predeterminado es ambos.

-6, --ipv6

Enlazar a IPv6. El valor predeterminado es ambos.

-e, --device

Ejecutar en modo dispositivo. En lugar de controlar un dispositivo conectado, crea un UDC virtual para enlazar gadgets.

-D, --daemon

Ejecutar como un proceso demonio.

-d, --debug

Imprimir información de depuración.

-PFILE, --pid FILE

Escribir el ID del proceso en FILE.
Si no se especifica FILE, usa /var/run/usbipd.pid

-tPORT, --tcp-port PORT

Escuchar en el puerto TCP/IP PORT.

-h, --help

Imprimir el mensaje de ayuda del programa y salir.

-v, --version

Mostrar versión.

LIMITACIONES

usbipd no ofrece autenticación ni autorización para USB/IP. Cualquier cliente USB/IP puede conectarse y usar los dispositivos exportados.

EJEMPLOS


servidor:# modprobe usbip-host


servidor:# usbipd -D
- Inicia el demonio usbip.


servidor:# usbip list --local
- Lista las asignaciones de controladores para dispositivos usb.


servidor:# usbip bind --busid=1-2
- Enlaza usbip-host.ko al dispositivo con busid 1-2.
- ¡Un dispositivo usb 1-2 ahora es exportable a otros hosts!
- Usa 'usbip unbind --busid=1-2' cuando quieras detener la exportación y usar el dispositivo localmente.

El siguiente ejemplo muestra el uso del modo dispositivo


servidor:# modprobe usbip-vudc
- Usa la interfaz /sys/class/udc/.
- usbip-host es independiente de este módulo.


servidor:# usbipd -e -D
- Inicia el demonio usbip en modo dispositivo.


servidor:# modprobe g_mass_storage file=/tmp/tmp.img
- Enlaza un gadget a usbip-vudc.
- En este ejemplo, se enlaza un gadget de almacenamiento masivo.


servidor:# usbip list --device
- Lista los gadgets exportados por el servidor usbip local.


servidor:# modprobe -r g_mass_storage
- Desenlaza un gadget de usbip-vudc.
- En este ejemplo, se desenlaza el gadget de almacenamiento masivo anterior.
