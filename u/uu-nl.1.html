NOMBRE

uu-nl - Numera las líneas de los archivos

SINOPSIS

uu-nl [--ayuda] [-b|--numeracion-cuerpo] [-d|--delimitador-seccion] [-f|--numeracion-pie] [-h|--numeracion-encabezado] [-i|--incremento-linea] [-l|--unir-lineas-vacias] [-n|--formato-numero] [-p|--no-renumerar] [-s|--separador-numero] [-v|--numero-linea-inicial] [-w|--ancho-numero] [-V|--version] [archivo]

DESCRIPCIÓN

Numera las líneas de los archivos

OPCIONES

--ayuda
Imprime información de ayuda.
-b, --numeracion-cuerpo <ESTILO>
usa ESTILO para numerar las líneas del cuerpo
-d, --delimitador-seccion <CC>
usa CC para separar páginas lógicas
-f, --numeracion-pie <ESTILO>
usa ESTILO para numerar las líneas del pie de página
-h, --numeracion-encabezado <ESTILO>
usa ESTILO para numerar las líneas del encabezado
-i, --incremento-linea <NUMERO>
incremento del número de línea en cada línea
-l, --unir-lineas-vacias <NUMERO>
agrupa NUMBER líneas vacías contadas como una
-n, --formato-numero <FORMATO>
inserta números de línea según FORMATO

[valores posibles: ln, rn, rz]

-p, --no-renumerar
no reinicia los números de línea en páginas lógicas
-s, --separador-numero <CADENA>
añade CADENA después del número de línea (posible)
-v, --numero-linea-inicial <NUMERO>
primer número de línea en cada página lógica
-w, --ancho-numero <NUMERO>
usa NUMBER columnas para los números de línea
-V, --version
Imprime la versión

EXTRA

ESTILO es uno de:

- a número todas las líneas - t número solo líneas no vacías - n número no hay líneas - pBRE número solo líneas que contienen una coincidencia para la expresión regular básica, BRE

FORMATO es uno de:

- ln justificado a la izquierda, sin ceros iniciales - rn justificado a la derecha, sin ceros iniciales - rz justificado a la derecha, con ceros iniciales
