UPSCLI_LIST_NEXT(3) Manual de NUT UPSCLI_LIST_NEXT(3)

NOMBRE

upscli_list_next - Recuperar elementos de lista de un UPS

SINOPSIS

        #include <upsclient.h>
        int upscli_list_next(
                UPSCONN_t *ups,
                size_t numq,
                const char **query,
                size_t *numa,
                char ***answer)

DESCRIPCIÓN

La función upscli_list_next() toma el puntero ups a una estructura de estado UPSCONN_t, y el puntero query a un array de numq elementos de consulta. Realiza una lectura de la red y espera encontrar otro elemento de lista o el final de una lista.

Debe llamar a upscli_list_start(3) antes de llamar a esta función.

Esta función devolverá 1 y establecerá valores en numa y answer si se recibe un elemento de lista. Si la lista ha terminado, devolverá 0, y los valores en numa y answer no estarán definidos.

Llamar a esta función después de que devuelva algo diferente de 1 es un comportamiento indefinido.

FORMATO DE CONSULTA

No puede cambiar los valores de numq o query entre la llamada a upscli_list_start(3) y la primera llamada a esta función. Tampoco puede cambiar los valores entre llamadas a esta función.

FORMATO DE RESPUESTA

El contenido de numa y answer funciona igual que una llamada a upscli_get(3). Los valores devueltos por upsd(8) son idénticos a una solicitud de elemento único, por lo que esto no es sorprendente.

COMPROBACIÓN DE ERRORES

Esta función comprueba la respuesta de upsd(8) con respecto a su consulta. Si la respuesta no forma parte de la lista que ha solicitado, devolverá un código de error.

Cuando esto sucede, upscli_upserror(3) devolverá UPSCLI_ERR_PROTOCOL.

VALOR DE RETORNO

La función upscli_list_next() devuelve 1 cuando hay datos de lista presentes, 0 si la lista ha terminado, o -1 si ocurre un error.

Es posible tener una lista vacía. La función devolverá 0 en su primera llamada en ese caso.

VER TAMBIÉN

upscli_list_start(3), upscli_strerror(3), upscli_upserror(3)
