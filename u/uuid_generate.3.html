UUID_GENERATE(3) Manual del programador UUID_GENERATE(3)

NOMBRE

uuid_generate, uuid_generate_random, uuid_generate_time, uuid_generate_time_safe - crear un nuevo valor UUID único

SINOPSIS

#include <uuid.h>

void uuid_generate(uuid_t out);
void uuid_generate_random(uuid_t out);
void uuid_generate_time(uuid_t out);
int uuid_generate_time_safe(uuid_t out);
void uuid_generate_md5(uuid_t out, const uuid_t ns, const char *name, size_t len);
void uuid_generate_sha1(uuid_t out, const uuid_t ns, const char *name, size_t len);

DESCRIPCIÓN

La función uuid_generate() crea un nuevo identificador universalmente único (UUID). El UUID se generará basándose en aleatoriedad de alta calidad de getrandom(2), /dev/urandom, o /dev/random si están disponibles. Si no lo están, entonces uuid_generate() utilizará un algoritmo alternativo que usa la hora actual, la dirección MAC de la red local (si está disponible) y datos aleatorios generados utilizando un generador pseudoaleatorio.

La función uuid_generate_random() fuerza el uso del formato UUID completamente aleatorio, incluso si no está disponible un generador de números aleatorios de alta calidad, en cuyo caso se sustituirá un generador pseudoaleatorio. Tenga en cuenta que el uso de un generador pseudoaleatorio puede comprometer la unicidad de los UUID generados de esta manera.

La función uuid_generate_time() fuerza el uso del algoritmo alternativo que utiliza la hora actual y la dirección MAC de la red local (si está disponible). Este algoritmo solía ser el predeterminado para generar UUID, pero debido al uso de la dirección MAC de la red, puede filtrar información sobre cuándo y dónde se generó el UUID. Esto puede causar problemas de privacidad en algunas aplicaciones, por lo que la función uuid_generate() solo usa este algoritmo si no hay una fuente de aleatoriedad de alta calidad disponible. Para garantizar la unicidad de los UUID generados por procesos que se ejecutan simultáneamente, la biblioteca uuid utiliza un contador de estado de reloj global (si el proceso tiene permisos para obtener acceso exclusivo a este archivo) y/o el demonio uuidd(8), si ya se está ejecutando o puede ser iniciado por el proceso (si está instalado y el proceso tiene suficientes permisos para ejecutarlo). Si ninguno de estos dos mecanismos de sincronización puede ser utilizado, es teóricamente posible que dos procesos que se ejecutan simultáneamente obtengan el mismo (o los mismos) UUID. Para saber si el UUID se ha generado de forma segura, utilice uuid_generate_time_safe.

La función uuid_generate_time_safe() es similar a uuid_generate_time(), excepto que devuelve un valor que indica si se ha utilizado alguno de los mecanismos de sincronización (ver arriba).

El UUID tiene 16 bytes (128 bits) de longitud, lo que proporciona aproximadamente 3.4x10^38 valores únicos (hay aproximadamente 10^80 partículas elementales en el universo según Cosmos de Carl Sagan). El nuevo UUID puede considerarse razonablemente único entre todos los UUID creados en el sistema local y entre los UUID creados en otros sistemas en el pasado y en el futuro.

Las funciones uuid_generate_md5() y uuid_generate_sha1() generan un UUID con hash MD5 y SHA1 (predecible) basándose en un UUID conocido que proporciona el espacio de nombres y una cadena binaria arbitraria. Los UUID se ajustan a los UUID V3 y V5 según la RFC-4122 https://tools.ietf.org/html/rfc4122.

VALOR DE RETORNO

El nuevo UUID creado se devuelve en la ubicación de memoria apuntada por out. uuid_generate_time_safe() devuelve cero si el UUID se ha generado de forma segura, -1 en caso contrario.

CONFORME A

Esta biblioteca genera UUID compatibles con OSF DCE 1.1, y UUID V3 y V5 basados en hash compatibles con la RFC-4122 https://tools.ietf.org/html/rfc4122.
