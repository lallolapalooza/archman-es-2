usleep(3) Manual de Funciones de Biblioteca usleep(3)

NOMBRE

usleep - suspender la ejecución durante intervalos de microsegundos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int usleep(useconds_t usec);
Requisitos de la Macro de Prueba de Funcionalidades para glibc (ver feature_test_macros(7)):

usleep():

    Desde glibc 2.12:
        (_XOPEN_SOURCE >= 500) && ! (_POSIX_C_SOURCE >= 200809L)
            || /* glibc >= 2.19: */ _DEFAULT_SOURCE
            || /* glibc <= 2.19: */ _BSD_SOURCE
    Antes de glibc 2.12:
        _BSD_SOURCE || _XOPEN_SOURCE >= 500

DESCRIPCIÓN

La función usleep() suspende la ejecución del hilo que la llama durante (al menos) usec microsegundos. La pausa puede alargarse ligeramente debido a cualquier actividad del sistema o al tiempo dedicado a procesar la llamada o por la granularidad de los temporizadores del sistema.

VALOR DE RETORNO

La función usleep() devuelve 0 si tiene éxito. En caso de error, devuelve -1, y la variable global errno se establece para indicar el error.

ERRORES

EINTR
Interrumpido por una señal; ver signal(7).
EINVAL
usec es mayor o igual a 1000000. (En sistemas donde esto se considera un error.)

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
usleep () Seguridad de hilos MT-Safe

ESTÁNDARES

Ninguno.

HISTORIA

4.3BSD, POSIX.1-2001. POSIX.1-2001 lo declara obsoleto, sugiriendo nanosleep(2) en su lugar. Eliminado en POSIX.1-2008.

En la implementación BSD original, y antes de glibc 2.2.2, el tipo de retorno de esta función es void. La versión POSIX devuelve int, y este es también el prototipo utilizado desde glibc 2.2.2.

Solo el retorno de error EINVAL está documentado por SUSv2 y POSIX.1-2001.

ADVERTENCIAS

La interacción de esta función con la señal SIGALRM, y con otras funciones de temporizador como alarm(2), sleep(3), nanosleep(2), setitimer(2), timer_create(2), timer_delete(2), timer_getoverrun(2), timer_gettime(2), timer_settime(2), ualarm(3) no está especificada.

VER TAMBIÉN

alarm(2), getitimer(2), nanosleep(2), select(2), setitimer(2), sleep(3), ualarm(3), useconds_t(3type), time(7)
