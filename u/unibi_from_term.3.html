NOMBRE

unibi_from_term - lee una entrada terminfo para una terminal nombrada

SINOPSIS

#include <unibilium.h>

unibi_term *unibi_from_term(const char *name);

DESCRIPCIÓN

Esta función localiza el archivo terminfo para name, y luego llama a "unibi_from_file".

Busca en los siguientes lugares:

1.
Si la variable de entorno "TERMINFO" está configurada, se interpreta como el nombre del directorio en el que buscar definiciones de terminal locales antes de verificar en la ubicación estándar.
2.
De lo contrario, se intenta con "$HOME/.terminfo".
3.
Si eso no tuvo éxito y "TERMINFO_DIRS" está configurado, se interpreta como una lista de directorios separados por dos puntos para buscar.
4.
Si "TERMINFO_DIRS" no está configurado, se utiliza un respaldo compilado ("unibi_terminfo_dirs") en su lugar.

VALOR DE RETORNO

Ver unibi_from_file(3).

VER TAMBIÉN

unibilium.h(3), unibi_from_file(3), unibi_terminfo_dirs(3), unibi_destroy(3)
