UPSCLI_SPLITNAME(3) Manual de NUT UPSCLI_SPLITNAME(3)

NOMBRE

upscli_splitname - Divide una definición de UPS en sus componentes

SINOPSIS

        #include <upsclient.h>
        int upscli_splitname(const char *buf, char **upsname,
                char **hostname, int *port)

DESCRIPCIÓN

La función upscli_splitname() toma un puntero a la definición cruda de UPS buf y devuelve punteros a memoria asignada dinámicamente en upsname y hostname. También copia el número de puerto en port.

FORMATO

Una definición de UPS se especifica según este formato:

<nombre_ups>[@<nombre_host>[:<puerto>]]

Cuando no se proporciona el nombre de UPS, esta función imprimirá un error en stderr y devolverá -1 sin cambiar nada.

Las definiciones sin un valor de puerto explícito reciben el valor predeterminado de 3493. El nombre de host predeterminado es "localhost".

USO DE MEMORIA

Debes free(3) los punteros a upsname y hostname cuando hayas terminado con ellos para evitar fugas de memoria.

VALOR DE RETORNO

La función upscli_splitname() devuelve 0 si tiene éxito, o -1 si ocurre un error.
