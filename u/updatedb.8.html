updatedb(8) Manual del Administrador del Sistema updatedb(8)

NOMBRE

updatedb - actualizar una base de datos para plocate

SINOPSIS

updatedb [OPCIÓN]...

DESCRIPCIÓN

updatedb crea o actualiza una base de datos utilizada por locate(1). Si la base de datos ya existe, sus datos se reutilizan para evitar releer directorios que no han cambiado.

updatedb se ejecuta normalmente diariamente desde un systemd.timer(8) para actualizar la base de datos por defecto.

ESTADO DE SALIDA

updatedb sale con estado 0 en caso de éxito, 1 en caso de error.

OPCIONES

Las variables PRUNE_BIND_MOUNTS, PRUNEFS, PRUNENAMES y PRUNEPATHS, que son modificadas por algunas de las opciones, se documentan en detalle en updatedb.conf(5).

-f, --add-prunefs FS
Añade entradas en la lista separada por espacios en blanco FS a PRUNEFS.
-n, --add-prunenames NAMES
Añade entradas en la lista separada por espacios en blanco NAMES a PRUNENAMES.
-e, --add-prunepaths PATHS
Añade entradas en la lista separada por espacios en blanco PATHS a PRUNEPATHS.
--add-single-prunepath PATH
Añade PATH a PRUNEPATHS. Nótese que esta es actualmente la única forma de añadir una ruta con un espacio en ella.
-U, --database-root RUTA
Almacena solo los resultados del escaneo del subárbol del sistema de archivos enraizado en RUTA en la base de datos generada. Todo el sistema de archivos se escanea por defecto.

locate(1) muestra las entradas como nombres de ruta absolutos que no contienen enlaces simbólicos, independientemente de la forma de RUTA.

--debug-pruning
Escribe información de depuración sobre las decisiones de poda en la salida estándar de error.
-h, --help
Escribe un resumen de las opciones disponibles en la salida estándar y sale exitosamente.
-o, --output ARCHIVO
Escribe la base de datos en ARCHIVO en lugar de usar la base de datos por defecto.
--prune-bind-mounts FLAG
Establece PRUNE_BIND_MOUNTS a FLAG, anulando el archivo de configuración.
--prunefs FS
Establece PRUNEFS a FS, anulando el archivo de configuración.
--prunenames NAMES
Establece PRUNENAMES a NAMES, anulando el archivo de configuración.
--prunepaths PATHS
Establece PRUNEPATHS a PATHS, anulando el archivo de configuración.
-l, --require-visibility FLAG
Establece la bandera "requerir visibilidad del archivo antes de informarlo" en la base de datos generada a FLAG.

Si FLAG es 0 o no, o si el archivo de base de datos es legible por "otros" o no pertenece a locate, locate(1) muestra las entradas de la base de datos incluso si el usuario que ejecuta locate(1) no podría haber leído el directorio necesario para encontrar el archivo descrito por la entrada de la base de datos.

Si FLAG es 1 o sí (el valor por defecto), locate(1) comprueba los permisos de los directorios padres de cada entrada antes de informarla al usuario que la invoca. Para hacer que la existencia del archivo esté verdaderamente oculta de otros usuarios, el grupo de la base de datos se establece en locate y los permisos de la base de datos prohíben la lectura a usuarios que no sea a través de locate(1), que tiene el bit set-gid en locate.

Nótese que la bandera de visibilidad solo se comprueba si la base de datos pertenece a locate y no es legible por "otros".

-v, --verbose
Muestra los nombres de ruta de los archivos en la salida estándar, tan pronto como se encuentran.
-V, --version
Escribe información sobre la versión y la licencia de locate en la salida estándar y sale exitosamente.

EJEMPLOS

Para crear una base de datos privada de plocate como un usuario que no sea root, ejecute

updatedb -l 0 -o archivo_db -U directorio_origen
Nótese que todos los usuarios que puedan leer archivo_db pueden obtener la lista completa de archivos en el subárbol de directorio_origen.

ARCHIVOS

/etc/updatedb.conf
Un archivo de configuración. Ver updatedb.conf(5). Utiliza exactamente el mismo formato que el utilizado por updatedb de mlocate(1), por lo que pueden compartirse.
/var/lib/plocate/plocate.db
La base de datos actualizada por defecto.

SEGURIDAD

Las bases de datos creadas con --require-visibility no permiten a los usuarios encontrar nombres de archivos y directorios de otros usuarios, lo que de otro modo no podrían hacer.
