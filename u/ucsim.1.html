-e comando -E -g -G -h -H -I opciones -k num_puerto -l -o colores -p prompt -P -R semilla -s archivo -S opciones -t tipo_cpu -U num_uart -u hw -v -V -w -X freq[k|M] -z num_puerto -Z num_puerto

DESCRIPCIÓN

uCsim es un simulador de microcontroladores y microprocesadores para varias familias de procesadores. Se puede iniciar como el comando ucsim_XXXX, donde XXXX especifica el tipo de procesador simulado. Por ejemplo, ucsim_51 inicia el simulador del microcontrolador Intel MCS51, ucsim_z80 inicia el simulador del microprocesador Zilog Z80, etc.

OPCIONES

Opciones del comando

-a nr
Especifica el tamaño del espacio de variables (por defecto=256).
-b
Tema en blanco y negro (sin color).
-B
Pita en los puntos de interrupción.
-c archivo
Abre la consola de comandos en archivo (usa - para entrada/salida estándar).
-C archivo
Lee los comandos iniciales del archivo y los ejecuta.
-e comando
Ejecuta comando al inicio del programa (antes del archivo de configuración).
-E
Ejecuta, inicia la simulación en modo de emulación.
-g
Ejecuta, inicia la simulación.
-G
Ejecuta, inicia la simulación, sale al detenerse.
-h
Muestra esta ayuda y sale.
-H
Muestra los tipos de CPUs conocidos y sale.
-I opciones
opciones es una lista separada por comas de opciones según la interfaz del simulador. Opciones conocidas son:
if=memoria[direccion] activa la interfaz en la ubicación de memoria dada.
in=archivo especifica el archivo de entrada para IO.
out=archivo especifica el archivo de salida para IO.
-k num_puerto
Usa localhost:num_puerto para IO serial. Esta opción es obsoleta, usa -S en su lugar.
-l
Usa los colores del tema claro (el predeterminado es oscuro).
-o colores
Lista de especificación de colores: qué=colores,... donde colores es una lista separada por : de opciones de color, por ejemplo: prompt=b:blanco:negro (negrita blanco sobre negro).
-p prompt
Especifica la cadena para el prompt.
-P
El prompt es un carácter nulo ('\0').
-q
Modo silencioso (implica -b).
-R semilla
Establece la semilla del generador de números aleatorios.
-s archivo
Conecta la interfaz serial uart0 al archivo. Esta opción es obsoleta, usa -S en su lugar.
-S opciones
opciones es una lista separada por comas de opciones según la interfaz serial. Opciones conocidas son:
uart=nr número de uart (por defecto=0)
in=archivo la entrada serial se leerá del archivo llamado `archivo'.
out=archivo la salida serial se escribirá en `archivo'.
port=nr usa localhost:nr como servidor para la línea serial.
iport=nr usa localhost:nr como servidor para la entrada serial.
oport=nr usa localhost:nr como servidor para la salida serial.
raw realiza comunicación no interactiva incluso en tty.
-t tipo_cpu
Especifica el tipo de controlador. Usa -H para listar los valores posibles.
-U num_uart
Usa la consola estándar como terminal para UART id=num_uart.
-u hw
Usa la consola estándar como pantalla para el hw especificado.
-v
Muestra el número de versión y sale.
-V
Modo detallado.
-w
Flash escribible.
-X freq[k|M]
Frecuencia del cristal (XTAL) en Hz. Usa el sufijo k o M para especificar la frecuencia en kHz o MHz.
-z num_puerto
Escucha en el num_puerto para la consola de comandos.
-Z num_puerto
Escucha en el num_puerto para la consola de comandos (sin consola en stdio).
