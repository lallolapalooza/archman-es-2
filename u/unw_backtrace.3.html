NOMBRE

unw_backtrace -- devuelve el rastreo de pila del programa que llama

SINOPSIS

#include <libunwind.h>

int unw_backtrace(void **buffer, int size);
int unw_backtrace2(void **buffer, int size, unw_context_t *ctxt, int flag);

#include <execinfo.h>

int backtrace(void **buffer, int size);

DESCRIPCIÓN

unw_backtrace() es una rutina conveniente para obtener el rastreo de pila del programa que llama. La rutina rellena hasta size direcciones en la matriz apuntada por buffer. La rutina solo está disponible para desenrollado local.

Tenga en cuenta que muchos sistemas (pero no todos) proporcionan una función prácticamente idéntica llamada backtrace(). El prototipo para esta función se obtiene normalmente incluyendo el archivo de cabecera <execinfo.h> — libunwind no proporciona un prototipo para backtrace(). libunwind aliassa débilmente backtrace() a unw_backtrace(), por lo que cuando un programa que llama a backtrace() se enlaza con libunwind, puede terminar llamando a unw_backtrace().

En caso de que desee obtener el rastreo de pila de un unw_context_t específico, puede llamar a unw_backtrace2 con ese contexto pasando 0 para flag. Si se sabe que el unw_context_t es un marco de señal (es decir, del tercer argumento en un manejador sigaction en linux), unw_backtrace2 se puede usar para recolectar solo los marcos antes del marco de señal pasando el flag UNW_INIT_SIGNAL_FRAME.

VALOR DE RETORNO

La rutina devuelve el número de direcciones almacenadas en la matriz apuntada por buffer. El valor de retorno puede ser cero para indicar que no se almacenaron direcciones.

VER TAMBIÉN

libunwind(3libunwind), unw_step(3libunwind)
