CUNCSD

Propósito

!>
!> CUNCSD calcula la descomposición CS de una matriz unitaria particionada M-por-M X:
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**H
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  S  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 es P-por-Q. Las matrices unitarias U1, U2, V1 y V2 son P-por-P,
!> (M-P)-por-(M-P), Q-por-Q y (M-Q)-por-(M-Q), respectivamente. C y S son
!> matrices diagonales no negativas R-por-R tales que C^2 + S^2 = I, donde
!> R = MIN(P,M-P,Q,M-Q).
!>

Parámetros

JOBU1 
!>          JOBU1 es CHARACTER
!>          = 'Y':      Se calcula U1;
!>          de lo contrario: U1 no se calcula.
!>

JOBU2

!>          JOBU2 es CHARACTER
!>          = 'Y':      Se calcula U2;
!>          de lo contrario: U2 no se calcula.
!>

JOBV1T

!>          JOBV1T es CHARACTER
!>          = 'Y':      Se calcula V1T;
!>          de lo contrario: V1T no se calcula.
!>

JOBV2T

!>          JOBV2T es CHARACTER
!>          = 'Y':      Se calcula V2T;
!>          de lo contrario: V2T no se calcula.
!>

TRANS

!>          TRANS es CHARACTER
!>          = 'T':      X, U1, U2, V1T y V2T se almacenan en orden de
!>                      fila principal;
!>          de lo contrario: X, U1, U2, V1T y V2T se almacenan en orden
!>                      de columna principal.
!>

SIGNS

!>          SIGNS es CHARACTER
!>          = 'O':      El bloque inferior izquierdo se hace no positivo
!>                      (la convención);
!>          de lo contrario: El bloque superior derecho se hace no
!>                      positivo (la convención).
!>

M

!>          M es INTEGER
!>          El número de filas y columnas en X.
!>

P

!>          P es INTEGER
!>          El número de filas en X11 y X12. 0 <= P <= M.
!>

Q

!>          Q es INTEGER
!>          El número de columnas en X11 y X21. 0 <= Q <= M.
!>

X11

!>          X11 es array COMPLEX, dimension (LDX11,Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se
!>          desea.
!>

LDX11

!>          LDX11 es INTEGER
!>          La dimensión principal de X11. LDX11 >= MAX(1,P).
!>

X12

!>          X12 es array COMPLEX, dimension (LDX12,M-Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se
!>          desea.
!>

LDX12

!>          LDX12 es INTEGER
!>          La dimensión principal de X12. LDX12 >= MAX(1,P).
!>

X21

!>          X21 es array COMPLEX, dimension (LDX21,Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se
!>          desea.
!>

LDX21

!>          LDX21 es INTEGER
!>          La dimensión principal de X11. LDX21 >= MAX(1,M-P).
!>

X22

!>          X22 es array COMPLEX, dimension (LDX22,M-Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se
!>          desea.
!>

LDX22

!>          LDX22 es INTEGER
!>          La dimensión principal de X11. LDX22 >= MAX(1,M-P).
!>

THETA

!>          THETA es array REAL, dimension (R), donde R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) y
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 es array COMPLEX, dimension (LDU1,P)
!>          Si JOBU1 = 'Y', U1 contiene la matriz unitaria P-por-P U1.
!>

LDU1

!>          LDU1 es INTEGER
!>          La dimensión principal de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 es array COMPLEX, dimension (LDU2,M-P)
!>          Si JOBU2 = 'Y', U2 contiene la matriz unitaria (M-P)-por-(M-P)
!>          U2.
!>

LDU2

!>          LDU2 es INTEGER
!>          La dimensión principal de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T es array COMPLEX, dimension (LDV1T,Q)
!>          Si JOBV1T = 'Y', V1T contiene la matriz unitaria Q-por-Q
!>          V1**H.
!>

LDV1T

!>          LDV1T es INTEGER
!>          La dimensión principal de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

V2T

!>          V2T es array COMPLEX, dimension (LDV2T,M-Q)
!>          Si JOBV2T = 'Y', V2T contiene la matriz unitaria
!>          (M-Q)-por-(M-Q) V2**H.
!>

LDV2T

!>          LDV2T es INTEGER
!>          La dimensión principal de V2T. Si JOBV2T = 'Y', LDV2T >=
!>          MAX(1,M-Q).
!>

!>          de PHI's no nulos.

LRWORK

!>          La dimensión del array RWORK.
!>
!>          Si LRWORK = -1, se asume una consulta de espacio de trabajo; la rutina

!>          este valor en la primera entrada del array de trabajo y XERBLA no emite ningún mensaje de error
!>          relacionado con LRWORK.
!> 


IWORK


!>          IWORK es un array de tipo INTEGER, de dimensión (M-MIN(P,Q,M-P,M-Q)).
!> 


INFO


!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.

NAME


ZUNCSD


computes the CS decomposition of a partitioned unitary matrix







SYNOPSIS


SUBROUTINE ZUNCSD( JOBU1, JOBU2, JOBV1T, JOBV2T, TRANS, SIGNS, M, P, Q, X11, LDX11, X12, LDX12, X21, LDX21, X22, LDX22, THETA, U1, LDU1, U2, LDU2, V1T, LDV1T, V2T, LDV2T, WORK, LWORK, RWORK, LRWORK, IWORK, INFO )


CHARACTER * 1 JOBU1, JOBU2, JOBV1T, JOBV2T, TRANS, SIGNS


INTEGER M, P, Q, LDX11, LDX12, LDX21, LDX22, LDU1, LDU2, LDV1T, LDV2T, LWORK, LRWORK, INFO


DOUBLE PRECISION THETA( * ), RWORK( * )


COMPLEX*16 X11( LDX11, * ), X12( LDX12, * ), X21( LDX21, * ), X22( LDX22, * ), U1( LDU1, * ), U2( LDU2, * ), V1T( LDV1T, * ), V2T( LDV2T, * ), WORK( * )


INTEGER IWORK( * )







Detailed Description


ZUNCSD computes the CS decomposition of an M-by-M
    partitioned unitary matrix X:


X = [ X11 | X12 ] = [ U1 |    ] [  I  0  0 |  0  0  0 ] [ V1 |    ]**H


    [-----------]   [---------] [  0  C  0 |  0 -S  0 ] [---------]   .


    [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  0  0 -I ] [    | V2 ]


                                [  0  0  0 |  I  0  0 ]


                                [  0  S  0 |  0  C  0 ]


                                [  0  0  I |  0  0  0 ]


X11 is P-by-Q. The unitary matrices U1, U2, V1, and V2 are P-by-P,
    (M-P)-by-(M-P), Q-by-Q, and (M-Q)-by-(M-Q), respectively. C and S are
    R-by-R nonnegative diagonal matrices satisfying C^2 + S^2 = I, in
    which R = MIN(P,M-P,Q,M-Q).


Options




JOBU1


'Y': U1 is computed.


Otherwise: U1 is not computed.


JOBU2


'Y': U2 is computed.


Otherwise: U2 is not computed.


JOBV1T


'Y': V1T is computed.


Otherwise: V1T is not computed.


JOBV2T


'Y': V2T is computed.


Otherwise: V2T is not computed.


TRANS


'T': X, U1, U2, V1T, and V2T are stored in row-major order.


Otherwise: X, U1, U2, V1T, and V2T are stored in column-major order.


SIGNS


'O': The lower-left block is made nonpositive (the
    "other" convention).


Otherwise: The upper-right block is made nonpositive (the default
    convention).




Parameters




M


The number of rows and columns in X.


Constraint: M >= 0.


P


The number of rows in X11 and X12.


Constraint: 0 <= P <= M.


Q


The number of columns in X11 and X21.


Constraint: 0 <= Q <= M.


X11


COMPLEX*16 array, dimension (LDX11,Q).


On entry, part of the unitary matrix whose CSD is desired.


LDX11


The leading dimension of X11.


Constraint: LDX11 >= MAX(1,P).


X12


COMPLEX*16 array, dimension (LDX12,M-Q).


On entry, part of the unitary matrix whose CSD is desired.


LDX12


The leading dimension of X12.


Constraint: LDX12 >= MAX(1,P).


X21


COMPLEX*16 array, dimension (LDX21,Q).


On entry, part of the unitary matrix whose CSD is desired.


LDX21


The leading dimension of X21.


Constraint: LDX21 >= MAX(1,M-P).


X22


COMPLEX*16 array, dimension (LDX22,M-Q).


On entry, part of the unitary matrix whose CSD is desired.


LDX22


The leading dimension of X22.


Constraint: LDX22 >= MAX(1,M-P).


THETA


DOUBLE PRECISION array, dimension (R), in which
    R = MIN(P,M-P,Q,M-Q).


C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) and
    S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).


U1


COMPLEX*16 array, dimension (LDU1,P).


If JOBU1 = 'Y', U1 contains the P-by-P unitary
    matrix U1.


LDU1


The leading dimension of U1.


Constraint: If JOBU1 = 'Y', LDU1 >= MAX(1,P).


U2


COMPLEX*16 array, dimension (LDU2,M-P).


If JOBU2 = 'Y', U2 contains the (M-P)-by-(M-P)
    unitary matrix U2.


LDU2


The leading dimension of U2.

Purpose:




!>
!> ZUNCSD computes the CS decomposition of an M-by-M partitioned
!> unitary matrix X:
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**H
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  0  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 is P-by-Q. The unitary matrices U1, U2, V1, and V2 are P-by-P,
!> (M-P)-by-(M-P), Q-by-Q, and (M-Q)-by-(M-Q), respectively. C and S are
!> R-by-R nonnegative diagonal matrices satisfying C^2 + S^2 = I, in
!> which R = MIN(P,M-P,Q,M-Q).
!>
