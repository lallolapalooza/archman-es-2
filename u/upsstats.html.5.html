UPSSTATS.HTML(5) Manual de NUT UPSSTATS.HTML(5)

NOMBRE

upsstats.html - Plantilla HTML para upsstats basado en web de Network UPS Tools

DESCRIPCIÓN

Este archivo es utilizado por upsstats.cgi(8) para generar páginas de estado. Ciertos comandos son reconocidos y serán reemplazados con varios elementos de estado sobre la marcha.

FORMATO

Los comandos se pueden colocar en cualquier lugar de una línea, pero deben comenzar y terminar con @.

Cualquier carácter extra antes o después de los comandos se pasará sin cambios.

Se permite usar más de un comando en una sola línea, siempre que cada comando tenga su propio carácter de inicio y fin.

Si necesita usar el signo @, utilice la entidad HTML &#64; para evitar que se trate como un carácter de inicio.

CONTROL DE BLOQUES

CONTROL DE BLOQUES - ITERACIÓN

@FOREACHUPS@

Inicia un bloque que se repetirá por cada directiva MONITOR en el hosts.conf(5). Así es como puede generar páginas que monitorean todos sus sistemas simultáneamente.

@ENDFOR@

Finaliza un bloque FOREACHUPS.

CONTROL DE BLOQUES - COINCIDENCIA DE CASOS ESPECÍFICOS

@IFSUPP var@*

Inicia un bloque que solo se imprimirá si la variable var es soportada por la UPS actual. Esto se usa generalmente para suprimir mensajes de "no soportado" evitando por completo la etiqueta y la llamada a la variable.

@IFEQ var valor@

Inicia un bloque si el valor devuelto por la variable var coincide con valor.

@IFBETWEEN varlow varhigh varvalue@

Inicia un bloque si el valor devuelto por la variable varvalue está entre los valores devueltos por las variables varlow y varhigh.

@ELSE@

Si el comando IF anterior no coincidió, realice esto en su lugar.

@ENDIF@

Finaliza un bloque IF/ELSE.

CONTROL DE BLOQUES - EXPRESIONES AVANZADAS

Aunque el analizador es bastante limitado, todavía es posible crear expresiones bastante avanzadas. La clave para esto es el hecho de que múltiples comandos de control de bloques se combinan con AND. Esto se ilustra con un ejemplo (hay más ejemplos disponibles en upsstats.html).

@IFSUPP ambient.humidity@
@IFSUPP ambient.temperature@
Esta UPS conoce tanto la temperatura ambiente como la humedad.
@ELSE@
@IFSUPP ambient.humidity@
Esta UPS solo conoce la humedad ambiente.
@ELSE@
@IFSUPP ambient.temperature@
Esta UPS solo conoce la temperatura ambiente.
@ELSE@
Esta UPS no sabe nada, qué molesto.
@ENDIF@

OTROS COMANDOS

@AMBTEMP@

Inserta la temperatura ambiente en la escala de temperatura actual.

@DATE formato@

Inserta la fecha y hora actuales. La cadena de formato se pasa a strftime, por lo que casi todo es posible. Consulte strftime(3) para ver los valores posibles.

@DEGREES@

Inserta la entidad para grados (°) y ya sea C o F dependiendo de la escala de temperatura actual.

@HOST@

Inserta la designación del host que se está monitoreando, como myups@localhost.

@HOSTDESC@

Inserta la descripción del host desde hosts.conf(5).

@HOSTLINK@

Inserta un enlace a upsstats.cgi con la variable "host" establecida en la UPS actual. Esto solo es útil dentro de un bloque FOREACHUPS.

@IMG nombre_variable @

Inserta un IMG SRC a upsimage.cgi(8) para una de estas variables de estado:

battery.charge

Carga de la batería — un porcentaje

battery.voltage

La carga de la batería en voltios

input.frequency

Frecuencia de la red eléctrica de entrada (Hz)

input.voltage

Voltaje de la red eléctrica de entrada

input.L1-L2.voltage

Voltaje de entrada, L1-L2 (trifásico)

input.L2-L3.voltage

Voltaje de entrada, L2-L3 (trifásico)

input.L3-L1.voltage

Voltaje de entrada, L3-L1 (trifásico)

output.frequency

Frecuencia de la red eléctrica de salida (Hz)

output.voltage

Voltaje de salida (desde la UPS)

output.L1-L2.voltage

Voltaje de salida, L1-L2 (trifásico)

output.L2-L3.voltage

Voltaje de salida, L2-L3 (trifásico)

output.L3-L1.voltage

Voltaje de salida, L3-L1 (trifásico)

output.L1.power.percent

Carga de la UPS, L1 (trifásico)

output.L2.power.percent

Carga de la UPS, L2 (trifásico)

output.L3.power.percent

Carga de la UPS, L3 (trifásico)

ups.load

Carga de la UPS — porcentaje

ups.temperature

Temperatura de la UPS

extra es donde puede poner definiciones adicionales. Ahora mismo, las definiciones válidas son colores para varias partes de las barras dibujadas por upsimage.cgi(8). Los nombres de color posibles son:

back_col

color de fondo

scale_num_col

color del número de escala

summary_col

color del resumen (número en la parte inferior)

ok_zone_maj_col

color de escala mayor para la zona normal ("ok")

ok_zone_min_col

color de escala menor para la zona normal ("ok")

neutral_zone_maj_col

color de escala mayor para la zona neutral

neutral_zone_min_col

color de escala menor para la zona neutral

warn_zone_maj_col

color de escala mayor para la zona de advertencia

warn_zone_min_col

color de escala menor para la zona de advertencia

bar_col

el color de la barra en el medio

Todos los colores son tríos hexadecimales — por ejemplo, 0xff0000 es rojo, 0x00ff00 es verde y 0x0000ff es azul.

Ejemplos:

@IMG battery.charge@
@IMG battery.charge back_col=0xff00ff bar_col=0xaabbcc@
@IMG input.voltage ok_zone_maj_col=0x123456@

@REFRESH@

Inserta la magia del encabezado META para actualizar la página si esa variable ha sido establecida por el navegador. Esto debe estar en la sección HEAD de la página.

@STATUS@

Expande las abreviaturas en la variable ups.status — OL se convierte en "On line", OB se convierte en "On battery", y así sucesivamente.

@STATUSCOLOR@

Inserta tríos de colores rojo, verde o amarillo dependiendo de la gravedad del estado actual de la UPS. Las operaciones normales son verdes, las advertencias como el ajuste/impulso de voltaje o "apagado" son amarillas, y otros eventos como estar en batería o tener una batería baja son rojos.

@VAR nombre_variable@

Inserta el valor actual de la variable de estado nombre_variable en el host que se está monitoreando, o "Not supported".

@RUNTIME@

Inserta el tiempo de ejecución actual, en formato hh:mm:ss.

@TEMPC@

Utiliza la escala Celsius para los datos de temperatura (predeterminado).

@TEMPF@

Utiliza la escala Fahrenheit para los datos de temperatura.

@UPSTEMP@

Inserta la temperatura de la UPS en la escala actual.

@BATTTEMP@

Inserta la temperatura de la batería en la escala actual.

@UTILITYCOLOR@

Obsoleto. Usa IFBET

NAME

upsstats.html – HTML template file for upsstats.cgi

DESCRIPTION

This document describes the format of the upsstats.html file. This file is a template for the HTML output generated by upsstats.cgi(8).

The template file uses a simple substitution mechanism. Lines starting with @ are recognized as variables and are substituted with corresponding values. All other lines are copied verbatim.

FORMATTING

The following variables are available for substitution:

@HOST@
Insert the hostname of the UPS server.
@UPSTYPE@
Insert the type of UPS.
@PRODUCT@
Insert the UPS product name.
@DATE@
Insert the current date and time.
@STATUS@
Insert the current status of the UPS.
@BATTWARN@
Insert the battery warning status.
@LOAD@
Insert the current load on the UPS.
@RUNTIME@
Insert the estimated runtime of the UPS.
@LINEVOLT@
Insert the current line voltage.
@FREQUENCY@
Insert the current line frequency.
@OUTPUTVOLT@
Insert the current output voltage.
@OUTPUTFREQ@
Insert the current output frequency.
@TEMP@
Insert the current temperature.
@MONITOR@
Insert the name of the monitoring application.
@INSTCMD@
Insert the command used to invoke the monitoring application.
@INTERVAL@
Insert the update interval in seconds.
@VERSION@
Insert the version number of the software.

BLOCK CONTROL

The following variables control the inclusion of HTML blocks:

@IFHOST@
Start of a block that is included only if the host parameter is set in the query URL.
@ENDIFHOST@
End of the block started by @IFHOST@.
@IFNHOST@
Start of a block that is included only if the host parameter is *not* set in the query URL.
@ENDIFNHOST@
End of the block started by @IFNHOST@.

For example, to display the host information only when a specific host is requested:

@IFHOST@
<p>Host: @HOST@</p>
@ENDIFHOST@

The @IFNHOST@ and @ENDIFNHOST@ directives work in a similar fashion.

OTHER COMMANDS

The following variables are used for the command line arguments:

@CMDLINE@
Insert the command line arguments used to start upsstats.cgi.

This variable is typically used in conjunction with the @INSTCMD@ variable to provide information about how the CGI script was invoked.

OTHER TEMPLATES

upsstats.cgi(8) will also open a file called upsstats-single.html if you call it with host= set in the query URL. That file uses the same rules and techniques as documented here.
