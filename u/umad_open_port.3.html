UMAD_OPEN_PORT(3) Manual del Programador de OpenIB UMAD_OPEN_PORT(3)

NOMBRE

umad_open_port - abre un puerto de dispositivo InfiniBand para acceso umad

SINOPSIS

#include <infiniband/umad.h>

int umad_open_port(char *ca_name, int portnum);

DESCRIPCIÓN

umad_open_port() abre el puerto portnum del dispositivo IB ca_name para acceso umad. El puerto es seleccionado por la biblioteca si no se proporcionan todos los parámetros (ver umad_get_port() para más detalles).

VALOR DE RETORNO

umad_open_port() devuelve 0 o un valor positivo único de descriptor de dispositivo umad en caso de éxito, y un valor negativo en caso de error, como sigue:
-EOPNOTSUPP La versión de ABI no coincide
-ENODEV No se puede resolver el dispositivo IB
-EINVAL El puerto no es válido (portnum incorrecto o no hay dispositivo umad)
-EIO No se puede abrir el dispositivo umad para este puerto

VER TAMBIÉN

umad_close_port(3), umad_get_cas_names(3), umad_get_port(3)
