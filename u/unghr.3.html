CUNGHR

Propósito:

!>
!> CUNGHR genera una matriz unitaria compleja Q que se define como el
!> producto de IHI-ILO 
reflectores elementales de orden N, tal como los devuelve
!> CGEHRD:
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz Q. N >= 0.
!>

ILO

!>          ILO es ENTERO
!>

IHI

!>          IHI es ENTERO
!>
!>          ILO e IHI deben tener los mismos valores que en la llamada anterior
!>          de CGEHRD. Q es igual a la matriz identidad excepto en la
!>          submatriz Q(ilo+1:ihi,ilo+1:ihi).
!>          1 <= ILO <= IHI <= N, si N > 0; ILO=1 y IHI=0, si N=0.
!>

A

!>          A es matriz COMPLEJA, de dimensión (LDA,N)
!>          En la entrada, los vectores que definen los 
reflectores elementales,
!>          tal como los devuelve CGEHRD.
!>          En la salida, la matriz unitaria N-por-N, Q.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A. LDA >= max(1,N).
!>

TAU

!>          TAU es matriz COMPLEJA, de dimensión (N-1)
!>          TAU(i) debe contener el factor escalar del 
reflector elemental
!>          H(i), tal como lo devuelve CGEHRD.
!>

WORK

!>          WORK es matriz COMPLEJA, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión de la matriz WORK. LWORK >= IHI-ILO.
!>          Para un rendimiento óptimo LWORK >= (IHI-ILO)*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          sólo calcula el tamaño óptimo de la matriz WORK, devuelve
!>          este valor como la primera entrada de la matriz WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

NAME


sorghr, zunghr - generate a orthogonal/unitary matrix that was
   determined by householder reflectors

Detailed
   Description


The routines generate a real or complex unitary matrix Q which is
   defined as the product of IHI-ILO elementary reflectors in the real case and
   IHI-ILO elementary reflectors in the complex case of order N, as returned by
   SGEHRD and ZGEHRD respectively:


Q = H(ilo) H(ilo+1) ... H(ihi-1)


The matrix Q is represented by the elements returned in the matrix
   A.


This routine is an auxiliary routine called by the routines that
   reduce a matrix to upper triangular form.

subroutine sorghr (integer n, integer ilo, integer ihi, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)


SORGHR


Purpose:




!>
!> SORGHR generates a real orthogonal matrix Q which is defined as the
!> product of IHI-ILO elementary reflectors of order N, as returned by
!> SGEHRD:
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!> 




Parameters


N

!>          N is INTEGER
!>          The order of the matrix Q. N >= 0.
!> 


ILO


!>          ILO is INTEGER
!> 


IHI


!>          IHI is INTEGER
!>
!>          ILO and IHI must have the same values as in the previous call
!>          of SGEHRD. Q is equal to the unit matrix except in the
!>          submatrix Q(ilo:ihi,ilo:ihi).
!>          1 <= ILO <= IHI <= N, if N > 0; ILO=1 and IHI=0, if N=0.
!> 


A


!>          A is REAL array, dimension (LDA,N)
!>          On entry, the vectors which define the elementary reflectors,
!>          as returned by SGEHRD.
!>          On exit, the N-by-N orthogonal matrix Q.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!> 


TAU


!>          TAU is REAL array, dimension (N-1)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by SGEHRD.
!> 


WORK


!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!> 


LWORK


!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= IHI-ILO.
!>          For optimum performance LWORK >= (IHI-ILO)*NB, where NB is
!>          the optimal blocksize.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
