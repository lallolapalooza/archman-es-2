NOMBRE

uu-mknod - Crear el archivo especial NOMBRE del tipo dado.

SINOPSIS

uu-mknod [-m|--modo] [-Z ] [--contexto] [-h|--ayuda] [-V|--version] <NOMBRE> <TIPO> [mayor] [menor]

DESCRIPCIÓN

Crear el archivo especial NOMBRE del tipo dado.

OPCIONES

-m, --modo <MODO>
establecer los bits de permiso de archivo a MODO, no a=rw - umask
-Z
establecer el contexto de seguridad SELinux de cada directorio creado al tipo predeterminado
--contexto[=<CTX>]
similar a -Z, o si se especifica CTX, establecer el contexto de seguridad SELinux o SMACK a CTX
-h, --ayuda
Imprimir ayuda
-V, --version
Imprimir versión
<NOMBRE>
nombre del nuevo archivo
<TIPO>
tipo del nuevo archivo (b, c, u o p)
[mayor]
tipo de archivo mayor
[menor]
tipo de archivo menor

EXTRA

Los argumentos obligatorios para las opciones largas son obligatorios también para las opciones cortas. -m, --modo=MODO establecer los bits de permiso de archivo a MODO, no a=rw - umask

Tanto MAYOR como MENOR deben especificarse cuando TIPO es b, c, o u, y deben omitirse cuando TIPO es p. Si MAYOR o MENOR comienzan con 0x o 0X, se interpretan como hexadecimales; de lo contrario, si comienzan con 0, como octales; de lo contrario, como decimales. TIPO puede ser:

- b crear un archivo especial de bloque (con búfer) - c, u crear un archivo especial de caracteres (sin búfer) - p crear un FIFO

NOTA: tu shell puede tener su propia versión de mknod, que usualmente reemplaza a la versión descrita aquí. Por favor, consulta la documentación de tu shell para detalles sobre las opciones que soporta.
