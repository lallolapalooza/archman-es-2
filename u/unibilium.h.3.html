NOMBRE

unibilium.h - Analizador de terminfo ncurses y funciones de utilidad

SINOPSIS

#include <unibilium.h>

DESCRIPCIÓN

Esta biblioteca proporciona funciones y tipos para acceder a las descripciones de terminales en la base de datos terminfo (en el formato utilizado por ncurses). Puede analizar entradas terminfo compiladas desde memoria o archivos, acceder y modificar sus capacidades, y generar nuevas entradas terminfo.

Tipos

Los siguientes tipos se proporcionan:

unibi_term
El tipo principal. Representa una entrada terminfo. La mayoría de las funciones toman un puntero a esta estructura.
unibi_var_t
Un tipo que representa los valores en operaciones de cadenas de formato, que son enteros o cadenas. Su representación exacta no se especifica.

Consulte unibi_var_from_num(3), unibi_var_from_str(3), unibi_num_from_var(3), unibi_str_from_var(3) para saber cómo utilizar valores de este tipo.

Sin embargo, se garantiza que la inicialización a cero de "unibi_var_t" es equivalente a unibi_var_from_num(0).

FUNCIONES

Las siguientes funciones están disponibles:

unibi_new()
Crea y devuelve un nuevo puntero a "unibi_term" vacío.
unibi_destroy()
Libera la memoria asignada a un "unibi_term". No hace nada si se pasa NULL.
unibi_clone()
Devuelve un clon profundo de un "unibi_term" dado.
unibi_parse_file()
Analiza un archivo terminfo dado y devuelve un nuevo "unibi_term". El nombre del archivo debe ser la ruta de un archivo de base de datos terminfo compilado (normalmente en /usr/share/terminfo/x/<nombre_terminal> o /lib/terminfo/<nombre_terminal> ).
unibi_parse_memory()
Analiza una entrada terminfo dada desde la memoria y devuelve un nuevo "unibi_term". La memoria debe contener una entrada terminfo compilada válida.
unibi_load_term()
Carga la entrada terminfo para el terminal especificado por la variable de entorno TERM. Busca en la base de datos terminfo.
unibi_load_termname()
Carga la entrada terminfo para el nombre de terminal especificado. Busca en la base de datos terminfo.
unibi_builtin_terms()
Devuelve una lista de nombres de terminales integrados. La lista está terminada por un puntero NULL.
unibi_load_builtin()
Carga una entrada terminfo integrada especificada.
unibi_name()
Devuelve el nombre del terminal para la entrada terminfo dada.
unibi_get_bool()
Devuelve el valor booleano de la capacidad especificada. Si la capacidad no está definida, devuelve FALSE.
unibi_get_num()
Devuelve el valor numérico de la capacidad especificada. Si la capacidad no está definida, devuelve -1.
unibi_get_str()
Devuelve el valor de cadena de la capacidad especificada. Si la capacidad no está definida, devuelve NULL.
unibi_set_bool()
Establece el valor booleano de la capacidad especificada.
unibi_set_num()
Establece el valor numérico de la capacidad especificada.
unibi_set_str()
Establece el valor de cadena de la capacidad especificada. La cadena proporcionada se clona; la cadena original no se modifica.
unibi_set_str_len()
Establece el valor de cadena de la capacidad especificada, permitiendo especificar la longitud de la cadena. La cadena proporcionada se clona; la cadena original no se modifica.
unibi_str_from_var()
Convierte un "unibi_var_t" en un puntero a una cadena. El puntero devuelto es propiedad de la estructura "unibi_term".
unibi_num_from_var()
Convierte un "unibi_var_t" en un número entero.
unibi_var_from_num()
Crea un "unibi_var_t" a partir de un número entero.
unibi_var_from_str()
Crea un "unibi_var_t" a partir de una cadena. La cadena se clona.
unibi_str_len()
Devuelve la longitud de la cadena de la capacidad especificada. Si la capacidad no está definida, devuelve 0.
unibi_term_bytes()
Calcula el número de bytes necesarios para almacenar la entrada terminfo dada en formato compilado.
unibi_term_to_bytes()
Copia la entrada terminfo dada en formato compilado en el búfer proporcionado.
unibi_interpret_code()
Interpreta una secuencia de escape de terminal codificada por unibi_str_to_code(3). La salida se escribe en el búfer proporcionado.
unibi_str_to_code()
Codifica una cadena de escape de terminal (p. ej., \E[H ) en su forma binaria (p. ej., \x1b[H ).
unibi_escape_string()
Aplica secuencias de escape a una cadena dada para que sea imprimible en una terminal. Por ejemplo, unibi_escape_string("Hello\nWorld") puede devolver "Hello\\nWorld" .
unibi_unescape_string()
Realiza la operación inversa a unibi_escape_string(3).
unibi_get_termtype()
Devuelve el valor de la cadena de la capacidad de terminal incorporada de la base de datos terminfo.
unibi_get_termtype_var()
Similar a unibi_get_termtype(3), pero devuelve un "unibi_var_t".
