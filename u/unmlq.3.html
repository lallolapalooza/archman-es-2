CUNMLQ

Propósito:

!>
!> CUNMLQ sobrescribe la matriz compleja general M-por-N C con
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> donde Q es una matriz unitaria compleja definida como el producto de k
!> reflectores elementales
!>
!>       Q = H(k)**H . . . H(2)**H H(1)**H
!>
!> como se devuelve de CGELQF. Q es de orden M si SIDE = 'L' y de orden N
!> si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda;
!>          = 'R': aplicar Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': Sin transponer, aplicar Q;
!>          = 'C': Transpuesta conjugada, aplicar Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A es un array COMPLEX, dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ésima fila debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, como se devuelve
!>          por CGELQF en las primeras k filas de su array argumento A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,K).
!>

TAU

!>          TAU es un array COMPLEX, dimension (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), como se devuelve por CGELQF.
!>

C

!>          C es un array COMPLEX, dimension (LDC,N)
!>          En la entrada, la matriz M-por-N C.
!>          En la salida, C se sobrescribe con Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N);
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

DESCRIPTION


The routines are complex variants of the algorithms in DORMLQ.
    They are used to transform the matrix C using an orthogonal/unitary matrix Q
    which is defined in terms of Householder reflections.
    The orthogonal/unitary matrix Q is of order M if SIDE = 'L' and of
    order N if SIDE = 'R'. It is formed from the vectors defined in
    the array A, which must be provided by the routines DGEQRF, SGEQRF or
    ZGEQRF.


TRANS = 'N' : apply Q  ($Q \times C$ or $C \times Q$)
    TRANS = 'T' (or 'C' for ZUNMLQ) : apply $Q^T$ (or $Q^H$)
    ($Q^T \times C$ or $C \times Q^T$)


The elementary reflectors whose product defines Q are contained in the
    subarrays of A.


A is used to define the elementary reflectors $H(i)$ which are stored
    in the.


if SIDE = 'L' the vectors are in the columns of A and


if SIDE = 'R' the vectors are in the rows of A.


Details are in the following sections.


DORMLQ


Purpose:




!>
!> DORMLQ overwrites the general real M-by-N matrix C with
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>
!> where Q is a real orthogonal matrix defined as the product of k
!> elementary reflectors
!>
!>       Q = H(k) . . . H(2) H(1)
!>
!> as returned by DGEQRF. Q is of order M if SIDE = 'L' and of order N
!> if SIDE = 'R'.
!> 




Parameters


SIDE

!>          SIDE is CHARACTER*1
!>          = 'L': apply Q or Q**T from the Left;
!>          = 'R': apply Q or Q**T from the Right.
!> 


TRANS


!>          TRANS is CHARACTER*1
!>          = 'N':  No transpose, apply Q;
!>          = 'T':  Transpose, apply Q**T.
!> 


M


!>          M is INTEGER
!>          The number of rows of the matrix C. M >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns of the matrix C. N >= 0.
!> 


K


!>          K is INTEGER
!>          The number of elementary reflectors whose product defines
!>          the matrix Q.
!>          If SIDE = 'L', M >= K >= 0;
!>          if SIDE = 'R', N >= K >= 0.
!> 


A


!>          A is REAL array, dimension
!>                               (LDA,M) if SIDE = 'L',
!>                               (LDA,N) if SIDE = 'R'
!>          The i-th column must contain the vector which defines the
!>          elementary reflector H(i), for i = 1,2,...,k, as returned by
!>          DGEQRF in the first k columns of its array argument A.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,K).
!> 


TAU


!>          TAU is REAL array, dimension (K)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by DGEQRF.
!> 


C


!>          C is REAL array, dimension (LDC,N)
!>          On entry, the M-by-N matrix C.
!>          On exit, C is overwritten by Q*C or Q**T*C or C*Q**T or C*Q.
!> 


LDC


!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!> 


WORK


!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!> 


LWORK


!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          If SIDE = 'L', LWORK >= max(1,N);
!>          if SIDE = 'R', LWORK >= max(1,M).
!>          For good performance, LWORK should generally be larger.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
