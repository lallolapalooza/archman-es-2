NOMBRE

user-dirs.dirs - configuración de directorios de usuario XDG

DESCRIPCIÓN

El archivo $HOME/.config/user-dirs.dirs es un archivo de texto que contiene los valores específicos del usuario para los directorios de usuario XDG. Es creado y actualizado por el comando xdg-user-dirs-update.

Este archivo contiene líneas de la forma

XDG_NOMBRE_DIR=VALOR

Los siguientes nombres son reconocidos:

DESKTOP
DOWNLOAD
TEMPLATES
PUBLICSHARE
DOCUMENTS
MUSIC
PICTURES
VIDEOS

VALOR debe tener la forma "$HOME/Ruta" o "/Ruta".

Las líneas que comienzan con el carácter # son ignoradas.

El formato de user-dirs.dirs está diseñado para permitir la carga directa de este archivo en scripts de shell.

AMBIENTE

XDG_CONFIG_DIRS

El archivo user-dirs.defaults se encuentra en este directorio. El valor predeterminado es /etc/xdg.

VER TAMBIÉN

xdg-user-dirs-update(1)
