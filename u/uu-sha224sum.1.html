NOMBRE

uu-sha224sum - Calcular y verificar resúmenes de mensajes.

SINOPSIS

uu-sha224sum [OPCIONES] [FICHERO]...

DESCRIPCIÓN

Calcular y verificar resúmenes de mensajes.

Este programa calcula resúmenes de mensajes SHA-224 para cada FICHERO. Si no se especifica ningún FICHERO, o si FICHERO es un guión (-), se lee de la entrada estándar.

OPCIONES

-c, --check
leer sumas de verificación de FICHEROs y verificarlas.
--tag
crear una suma de verificación estilo BSD.
-b, --binary
leer en modo binario.
-t, --text
leer en modo texto (por defecto).
-q, --quiet
no imprimir OK para cada archivo verificado correctamente.
-s, --status
no imprimir nada, el código de estado muestra el éxito.
--strict
salir con un valor no nulo para líneas de suma de verificación mal formateadas.
--ignore-missing
no fallar ni informar estado para archivos faltantes.
-w, --warn
advertir sobre líneas de suma de verificación mal formateadas.
-z, --zero
terminar cada línea de salida con NUL, no con nueva línea.
-h, --help
Imprimir ayuda.
-V, --version
Imprimir versión.

VERSIÓN

v(uutils coreutils) 0.4.0

EJEMPLOS

Calcular sumas de verificación para un archivo:

 $ uu-sha224sum archivo.txt
 e7671597205633e619129448616842f36c2873e308007b3a3c21c574  archivo.txt

Calcular sumas de verificación para varios archivos y guardarlas en un archivo:

 $ uu-sha224sum archivo1.txt archivo2.log > sumas.txt

Verificar sumas de verificación a partir de un archivo:

 $ uu-sha224sum -c sumas.txt
 archivo1.txt: OK
 archivo2.log: OK

ESTADO DE SALIDA

La salida es 0 si hubo éxito, y no nulo en caso contrario. Ver el código de salida del argumento -s.

AUTORES
