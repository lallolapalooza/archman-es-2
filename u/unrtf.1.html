NOMBRE

UnRTF - convierte documentos en formato RTF a otros formatos

SINOPSIS

unrtf [opciones] [archivo...]

Opciones: [--nopict] [--noremap] [-P ruta_búsqueda_config] [--html] [--text] [--vt] [--rtf] [--latex] [--help] [--verbose] [--quiet] [--version] [-t archivo_etiquetas]

DESCRIPCIÓN

El programa unrtf es un conversor de Rich Text Format (RTF) a un número creciente de formatos de documento. Actualmente soporta Hypertext Markup Language (HTML), texto plano, texto con códigos VT100, LaTeX, y el propio RTF. Es posible producir archivos troff con llamadas a macros; se proporciona un ejemplo de configuración para troff y el paquete de macros mm. Todos los formatos de salida excepto HTML son "alfa", es decir, limitados y el desarrollo acaba de comenzar. Sin embargo, con HTML, el programa soporta tablas, fuentes, hipervínculos y alineación de párrafos. El soporte de fuentes incluye cambios de cara y tamaño, así como atributos típicos como itálica, negrita, subrayado, tachado, versalitas, mayúsculas, expandir, comprimir y colores de primer plano y fondo. Las imágenes siempre se almacenan en archivos separados en el directorio actual, o pueden ser ignoradas.

A partir de la versión 0.21.0, todo el control de la salida de unrtf se realiza a través de archivos de configuración en tiempo de ejecución. Esto facilita a los usuarios el ajuste fino de la salida y/o la definición de nuevos formatos de salida. Los archivos de configuración se pueden leer de los distribuidos, o de archivos de usuario, buscados en la ruta_búsqueda_config . Tenga en cuenta que el orden de los argumentos -P y de salida es importante. La ruta de búsqueda debe establecerse antes de cualquier argumento que cargue un archivo de configuración si ese archivo no está en el lugar estándar.

La conversión de páginas de códigos se realiza con el paquete iconv(3).

OPCIONES

--nopict
deshabilita el almacenamiento automático de imágenes incrustadas en el directorio actual.
--noremap
deshabilita la conversión de juegos de caracteres (actualmente solo funciona para juegos de caracteres de 8 bits).
--html
selecciona la salida HTML (por defecto).
--rtf
selecciona la salida RTF. La salida resultante a menudo será mucho más pequeña que la entrada.
--text
selecciona la salida de texto plano ASCII.
--vt
selecciona la salida de texto con códigos de escape VT100.
--latex
selecciona la salida de un documento LaTeX.
--verbose
imprime información adicional.
--quiet
suprime la salida de comentarios iniciales
--version
imprime la versión del programa.
-t archivo_etiquetas
especifica el archivo de configuración de salida de etiquetas a utilizar. El comando "unrtf -t html" es funcionalmente idéntico a "unrtf --html". Los archivos de configuración tienen un formato simple. Para cambiar el comportamiento de unrtf, se puede hacer una copia local de un archivo de configuración del sistema y editarla. El archivo de configuración más completo y, por lo tanto, el mejor punto de partida es /usr/share/unrtf/html.conf.
-P ruta_búsqueda_config
especifica los directorios en los que se buscará el archivo de configuración para el formato especificado. La ruta se puede proporcionar como un solo directorio o una lista de directorios separados por dos puntos. El valor predeterminado es /usr/share/unrtf, donde se instalan los archivos de configuración de salida distribuidos.

ARCHIVOS

/usr/share/unrtf/*.conf
– archivos de configuración de salida en tiempo de ejecución.
/usr/share/unrtf/SYMBOL.charmap
– codificación UTF de la fuente SYMBOL utilizada en muchos archivos RTF. Desafortunadamente, el paquete iconv no incluye codificaciones de fuentes. El formato es idéntico a los archivos de página de códigos de iconv.
