UNCPK(1) Manual de Comandos Generales UNCPK(1)

NOMBRE

uncpk - gestiona archivos c64 cpk

SINOPSIS

uncpk [OPCIÓN]... ARCHIVO...

DESCRIPCIÓN

uncpk es una herramienta de archivo para archivos con formato .cpk del Commodore 64.

OPCIONES

c
Crea un archivo.
x
Extrae de un archivo.
l
Lista el contenido del archivo.
a
Añade un archivo al archivo.
v
Salida detallada.
--help
Muestra el resumen de las opciones.
--version
Muestra la versión del programa.

EJEMPLOS

uncpk c foo.cpk bar
Crea el archivo foo.cpk con el archivo único bar dentro del mismo.
uncpk a foo.cpk bar
Añade el archivo bar al archivo foo.cpk (que debe existir previamente).
uncpk x foo.cpk
Extrae todos los archivos del archivo foo.cpk.
uncpk l foo.cpk
Lista el contenido del archivo foo.cpk.
