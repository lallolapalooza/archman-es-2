UBUNTU-DISTRO-INFO(1) Manual de Comandos Generales UBUNTU-DISTRO-INFO(1)

NOMBRE

ubuntu-distro-info - proporciona información sobre las distribuciones de Ubuntu

SINOPSIS

ubuntu-distro-info [OPCIONES]

OPCIONES

--fecha=FECHA
fecha para calcular la versión (por defecto: la época de la variable entorno SOURCE_DATE_EPOCH si está definida, de lo contrario, hoy)
-h, --ayuda
muestra el mensaje de ayuda y sale
-a, --todo
lista todas las versiones conocidas
-y[MILESTONE], --dias[=MILESTONE]
muestra el número de días hasta que la versión especificada alcance el hito especificado. MILESTONE puede ser uno de created, release, eol o eol-server. Si no se especifica ningún hito, se asume release. Para opciones que devuelven una lista, muestra la salida normal seguida de un espacio en blanco y el número de días hasta el hito especificado. Si no se puede calcular el hito (por ejemplo, si se especifica el hito eol-server para una versión que no es de servidor), se muestra la cadena '(unknown)'. A menos que se especifique una de las opciones -c, -f o -r, solo se mostrará el número de días.
-d, --desarrollo
última versión de desarrollo
-l, --ultimo
imprime la última versión de desarrollo. En caso de datos de distribución obsoletos, se imprimirá la última versión estable.
--lts
última versión de soporte a largo plazo (LTS)
--series=SERIE
serie para la cual calcular la versión
-s, --estable
última versión estable
--soportado
lista de todas las versiones soportadas, incluyendo la versión de desarrollo
--soportado-esm
lista de todas las versiones estables soportadas por Ubuntu Advantage
--no-soportado
lista de todas las versiones estables no soportadas
-c, --apodo
imprime el apodo (por defecto)
-r, --version
imprime la versión de lanzamiento
-f, --nombre-completo
imprime el nombre completo

VER TAMBIÉN

debian-distro-info(1), distro-info(1)
