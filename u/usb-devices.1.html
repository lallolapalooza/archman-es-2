usb-devices(1) Utilidades USB de Linux usb-devices(1)

NOMBRE

usb-devices - imprime detalles de dispositivos USB

SINOPSIS

usb-devices

DESCRIPCIÓN

usb-devices es un script de shell que se puede usar para mostrar detalles de los buses USB en el sistema y los dispositivos conectados a ellos.

La salida del script es similar al archivo usb/devices disponible en /proc/bus (si usbfs está montado), o en /sys/kernel/debug (si debugfs está montado allí). El script está diseñado principalmente para ser utilizado si el archivo no está disponible.

En contraste con el archivo usb/devices, este script solo lista las interfaces *activas* (aquellas marcadas con un "*" en el archivo usb/devices) y sus puntos finales.

Tenga en cuenta que puede haber diferencias en la forma en que se ordena la información, así como en el formato de la salida.

VALOR DE RETORNO

Si sysfs no está montado, se devuelve un código de salida distinto de cero.

ARCHIVOS

/sys/bus/usb/devices/usb*
La parte del árbol sysfs que el script recorre para ensamblar la información impresa.
/proc/bus/usb/devices
Ubicación donde normalmente se puede encontrar el archivo usb/devices para kernels de Linux anteriores a 2.6.31, si usbfs está montado.
/sys/kernel/debug/usb/devices
Ubicación donde normalmente se puede encontrar el archivo usb/devices para los kernels de Linux 2.6.31 y posteriores, si debugfs está montado.

VER TAMBIÉN

lsusb(8), usbview(8).
