UGREP-INDEXER(1) Comandos de usuario UGREP-INDEXER(1)

NOMBRE

ugrep-indexer -- indexador de archivos para acelerar la búsqueda recursiva

SINOPSIS

ugrep-indexer [-0...9] [-c|-d|-f] [-I] [-q] [-S] [-s] [-X] [-z] [RUTA]

DESCRIPCIÓN

La utilidad ugrep-indexer indexa recursivamente archivos para acelerar la búsqueda recursiva con los comandos ug --index PATRÓN:

$ ugrep-indexer [-I] [-z]

...
$ ug --index [-I] [-z] [-r|-R] OPCIONES PATRÓN
$ ugrep --index [-I] [-z] [-r|-R] OPCIONES PATRÓN

donde la opción -I o --ignore-binary ignora los archivos binarios, lo cual es recomendado para limitar la sobrecarga de almacenamiento del índice y reducir el tiempo de búsqueda. La opción -z o --decompress indexa y busca archivos comprimidos y de archivo.

La indexación acelera la búsqueda en sistemas de archivos grandes y fríos (no cacheados recientemente en RAM) y sistemas de archivos que son generalmente lentos de buscar. Tenga en cuenta que la indexación puede no acelerar la búsqueda de pocos archivos o la búsqueda recursiva en sistemas de archivos rápidos.

La búsqueda con ug --index es segura y nunca omite archivos modificados que puedan coincidir después de la indexación; el comando ug --index PATRÓN siempre busca archivos y directorios que se añadieron o modificaron después de la indexación. Cuando la opción --stats se utiliza con ug --index, se produce un informe de búsqueda que muestra el número de archivos omitidos que no coinciden con ningún índice y el número de archivos y directorios que se añadieron o modificaron después de la indexación. Tenga en cuenta que la búsqueda con ug --index puede aumentar significativamente el tiempo de inicio cuando se especifican patrones complejos de expresiones regulares que contienen clases de caracteres Unicode grandes combinadas con repeticiones de `*' o `+', lo cual debe evitarse.

ugrep-indexer almacena un archivo de índice oculto en cada directorio indexado. El tamaño de un archivo de índice depende del número de archivos indexados y de la precisión de indexación especificada. Una mayor precisión produce archivos de índice más grandes para mejorar el rendimiento de la búsqueda reduciendo las falsas alarmas (una falsa alarma es una predicción de coincidencia para un archivo cuando el archivo no coincide con el patrón de expresión regular).

ugrep-indexer acepta una RUTA opcional a la raíz del árbol de directorios a indexar. El valor predeterminado es indexar el árbol de directorios del directorio de trabajo actual.

ugrep-indexer actualiza los índices de forma incremental. Para forzar la reindexación, especifique la opción -f o --force. Los índices se eliminan con la opción -d o --delete.

ugrep-indexer puede detenerse y reiniciarse para continuar la indexación en cualquier momento. Los archivos de índice incompletos no causan errores.

Los archivos ASCII, UTF-8, UTF-16 y UTF-32 se indexan y buscan como archivos de texto a menos que su codificación UTF sea inválida. Los archivos con otras codificaciones se indexan como archivos binarios y pueden ser buscados con patrones de expresiones regulares no Unicode utilizando ug --index -U.

Cuando la opción -I o --ignore-binary de ugrep-indexer se especifica, los archivos binarios se ignoran y no se indexan. Evite buscar estos archivos binarios no indexados con ug --index -I utilizando la opción -I.

La opción -X o --ignore-files de ugrep-indexer respeta las reglas de gitignore. Asimismo, evite buscar archivos ignorados no indexados con ug --index --ignore-files utilizando la opción --ignore-files.

Los archivos de archivo y comprimidos se indexan con la opción -z o --decompress de ugrep-indexer. De lo contrario, los archivos de archivo y comprimidos se indexan como archivos binarios o se ignoran con la opción -I o --ignore-binary. Tenga en cuenta que una vez que un archivo de archivo o comprimido se indexa como archivo binario, no se volverá a indexar con la opción -z para indexar el contenido del archivo de archivo o comprimido. Solo se vuelven a indexar los archivos que se modifican después de la indexación, lo que se determina comparando las marcas de tiempo.

Los enlaces simbólicos de archivos se indexan con la opción -S o --dereference-files de ugrep-indexer. Los enlaces simbólicos a directorios nunca se siguen.

Para guardar un archivo de registro del proceso de indexación, especifique la opción -v o --verbose y redirija la salida estándar a un archivo de registro. Todos los mensajes y advertencias se envían a la salida estándar y son capturados por el archivo de registro.

Un archivo de configuración .ugrep-indexer con opciones de configuración se carga cuando está presente en el directorio de trabajo o en el directorio de inicio. Una opción de configuración consiste en el nombre de una opción larga y su argumento cuando sea aplicable.

Las siguientes opciones están disponibles:

-0, -1, -2, -3, ..., -9, --accuracy=DÍGITO
Especifica la precisión de la indexación. Una precisión baja reduce la sobrecarga de almacenamiento de la indexación a costa de una mayor tasa de coincidencias de patrones de falsas alarmas (más ruido). Una alta precisión reduce la tasa de coincidencias de patrones de expresiones regulares de falsas alarmas (menos ruido) a costa de una mayor sobrecarga de almacenamiento de la indexación. Se recomienda una precisión entre 2 y 7. La precisión predeterminada es 4.
-., --hidden
Indexa archivos y directorios ocultos.
-?, --help
Muestra un mensaje de ayuda y sale.
-c, --check
Verifica e informa los índices recursivamente sin reindexar archivos.
-d, --delete
Elimina recursivamente los archivos de índice.
-f, --force
Fuerza la reindexación de archivos, incluso aquellos que ya están indexados.
-I, --ignore-binary
No indexa archivos binarios.
-q, --quiet, --silent
Modo silencioso: no muestra estadísticas de indexación.
-S, --dereference-files
Sigue los enlaces simbólicos a archivos. Los enlaces simbólicos a directorios nunca se siguen.
-s, --no-messages
Modo silencioso: se ignoran los archivos inexistentes e ilegibles, es decir, se suprimen sus mensajes de error y advertencias.
-V, --version
Muestra la versión y sale.
-v, --verbose
Produce salida detallada. Los archivos se marcan como A para archivo, C para comprimido y B para binario o I para binario ignorado. Las eliminaciones se marcan con D.
-X, --ignore-files, --ignore-files=ARCHIVO
No indexa archivos y directorios que coincidan con los globs en ARCHIVO encontrados durante la indexación. El ARCHIVO predeterminado es `.gitignore'. Esta opción se puede repetir para especificar archivos adicionales.
-z, --decompress
Indexa el contenido de archivos comprimidos y de archivo. Los archivos ocultos en los archivos se ignoran a menos que se especifique la opción -. o --hidden. La opción -I o --ignore-binary ignora los archivos binarios comprimidos. Cuando se utiliza con la opción --zmax=NÚM, indexa el contenido de archivos comprimidos y de archivo almacenados dentro de archivos hasta NÚM niveles de profundidad. Formatos de compresión compatibles: gzip (.gz), compress (.Z), zip, 7z, bzip2 (requiere sufijo .bz, .bz2, .bzip2, .tbz, .tbz2, .tb2, .tz2), lzma y xz (requiere sufijo .lzma, .tlz, .xz, .txz), lz4 (requiere sufijo .lz4), zstd (requiere sufijo .zst, .zstd, .tzst), brotli (requiere sufijo .br).
--zmax=NÚM
Cuando se utiliza con la opción -z (--decompress), indexa el contenido de archivos comprimidos y de archivo almacenados dentro de archivos hasta NUM niveles de expansión de profundidad. El valor predeterminado --zmax=1 solo permite indexar archivos sin comprimir almacenados en archivos cpio, pax, tar, zip y 7z; los archivos y archivadores comprimidos se detectan como archivos binarios y se ignoran efectivamente. Especifique --zmax=2 para indexar archivos y archivadores comprimidos almacenados en archivos cpio, pax, tar, zip y 7z. NUM puede variar de 1 a 99 para hasta 99 pasos de descompresión y desarchivado. Aumentar los valores de NUM degrada gradualmente el rendimiento.

ugrep-indexer(1) — ugrep manual

NAME

ugrep-indexer

create, update, and remove ugrep index files

SYNOPSIS

ugrep-indexer [-f|-F] [-s|-S] [-v|-V] [-z|-Z] [-i|-I] [-c] [-d] [-X] [-CMAX] [-GGLOB] [-tFILE] [-uFILE] [-WMAX] [-gDIR] [-LFILE] [-a] [-l] [-n] [-p] [-r] [-x] [-0..-9] [PATH ...]

DESCRIPTION

ugrep-indexer is a utility to create, update, and remove index files for the ugrep(1) utility. Index files are used to speed up searching in large directory trees.

By default, ugrep-indexer recursively scans the specified PATH arguments (or the current directory if none are given) and creates and updates index files in the ._UG#_Store subdirectory of each directory scanned. Index files are used by ugrep(1) to speed up searching.

If -d is specified, ugrep-indexer recursively deletes all index files in the specified PATH arguments (or the current directory if none are given), effectively removing all indexing information.

Index files are text files that store information about files in a directory and its subdirectories. This information includes file names, modification times, and file sizes. ugrep(1) uses this information to quickly identify files that may contain the search query, skipping files that are unlikely to match.

The indexing accuracy can be adjusted with options -0 to -9. Higher values increase accuracy and search speed at the cost of larger index files and longer indexing times. Lower values reduce index file size and indexing time at the cost of lower accuracy and potentially slower searches.

By default, ugrep-indexer only indexes non-binary files. Use the -a option to index all files.

Use the -z option to index files compressed with gzip, bzip2, lzma, or xz, and files stored in archives like zip, tar, and jar. This also includes files stored within compressed archives.

Use the -S option to follow symbolic links to files, but not to directories. This can be useful for indexing files that are symlinked from elsewhere.

Use the -X option to skip files and directories that match the globs in .gitignore, .ugitignore, and .ignore files. This is useful for ignoring build artifacts and other generated files.

Use the -f option to force re-indexing of all files, even if they have not changed since the last indexing. This can be useful if the indexing logic has changed or if you suspect the index files are corrupt.

Use the -v option to display verbose output, showing which files are being indexed and which index files are being created or updated. This is useful for monitoring the indexing process and for debugging.

Use the -c option to perform a quick check of the index files without actually updating them. This can be used to quickly determine if the index files are up to date.

EXIT STATUS

0
Indexes are up to date.
1
Indexing check -c detected missing and outdated index files.

EXAMPLES

Recursively and incrementally index all non-binary files showing progress:

$ ugrep-indexer -I -v

Recursively and incrementally index all non-binary files, including non-binary files stored in archives and in compressed files, showing progress:

$ ugrep-indexer -z -I -v

Incrementally index all non-binary files, including archives and compressed files, show progress, follow symbolic links to files (but not to directories), but do not index files and directories matching the globs in .gitignore:

$ ugrep-indexer -z -I -v -S -X

Force re-indexing of all non-binary files, including archives and compressed files, follow symbolic links to files (but not to directories), but do not index files and directories matching the globs in .gitignore:

$ ugrep-indexer -f -z -I -v -S -X

Same, but decrease index file storage to a minimum by decreasing indexing accuracy from 4 (the default) to 0:

$ ugrep-indexer -f -0 -z -I -v -S -X

Increase search performance by increasing the indexing accuracy from 4 (the default) to 7 at a cost of larger index files:

$ ugrep-indexer -f7zIvSX

Recursively delete all hidden ._UG#_Store index files to restore the directory tree to non-indexed:

$ ugrep-indexer -d
