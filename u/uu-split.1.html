NOMBRE

uu-split - Crear archivos de salida que contienen secciones consecutivas o intercaladas de entrada

SINOPSIS

uu-split [-b|--bytes] [-C|--line-bytes] [-l|--lines] [-n|--number] [--additional-suffix] [--filter] [-e|--elide-empty-files] [-d ] [--numeric-suffixes] [-x ] [--hex-suffixes] [-a|--suffix-length] [--verbose] [-t|--separator] [-h|--help] [-V|--version] [entrada] [prefijo]

DESCRIPCIÓN

Crear archivos de salida que contienen secciones consecutivas o intercaladas de entrada

OPCIONES

-b, --bytes <TAMAÑO>
poner TAMAÑO bytes por archivo de salida
-C, --line-bytes <TAMAÑO>
poner como máximo TAMAÑO bytes de líneas por archivo de salida
-l, --lines <NÚMERO> [predeterminado: 1000]
poner NÚMERO de líneas/registros por archivo de salida
-n, --number <CHUNKS>
generar CHUNKS archivos de salida; ver explicación abajo
--additional-suffix <SUFIJO> [predeterminado: ]
SUFIJO adicional para añadir a los nombres de los archivos de salida
--filter <COMANDO>
escribir al comando de shell COMANDO; el nombre del archivo es $FILE (Actualmente no implementado para Windows)
-e, --elide-empty-files
no generar archivos de salida vacíos con '-n'
-d
usar sufijos numéricos empezando en 0, no alfabéticos
--numeric-suffixes[=<DESDE>]
igual que -d, pero permite establecer el valor de inicio
-x
usar sufijos hexadecimales empezando en 0, no alfabéticos
--hex-suffixes[=<DESDE>]
igual que -x, pero permite establecer el valor de inicio
-a, --suffix-length <N>
generar sufijos de longitud N (predeterminado 2)
--verbose
imprimir un diagnóstico justo antes de abrir cada archivo de salida
-t, --separator <SEP>
usar SEP en lugar de nueva línea como separador de registro; '\\0' (cero) especifica el carácter NUL
-h, --help
Imprimir ayuda
-V, --version
Imprimir versión
[entrada] [predeterminado: -]
[prefijo] [predeterminado: x]

EXTRA

Divide trozos de tamaño fijo de ENTRADA en PREFIXaa, PREFIXab, ...; el tamaño predeterminado es 1000, y el prefijo predeterminado es 'x'. Sin ENTRADA, o cuando ENTRADA es -, lee la entrada estándar.

El argumento TAMAÑO es un entero y una unidad opcional (ejemplo: 10K es 10*1024). Las unidades son K,M,G,T,P,E,Z,Y,R,Q (potencias de 1024) o KB,MB,... (potencias de 1000). También se pueden usar prefijos binarios: KiB=K, MiB=M, y así sucesivamente.

CHUNKS puede ser:

- N dividir en N archivos basándose en el tamaño de entrada - K/N salida Késima de N a stdout - l/N dividir en N archivos sin dividir líneas/registros - l/K/N salida Késima de N a stdout sin dividir líneas/registros - r/N como 'l' pero usar distribución round robin - r/K/N igualmente pero solo salida Késima de N a stdout
