CUNGTSQR_ROW

Propósito:

!>
!> CUNGTSQR_ROW genera una matriz compleja M por N, Q_out, con
!> columnas ortonormales a partir de la salida de CLATSQR. Estas N columnas ortonormales
!> son las primeras N columnas de un producto de matrices unitarias complejas
!> Q(k)_in de orden M, que son devueltas por CLATSQR en
!> un formato especial.
!>
!>      Q_out = primeras_N_columnas_de( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Las matrices de entrada Q(k)_in se almacenan en bloques de filas y columnas en A.
!> Consulte la documentación de CLATSQR para más detalles sobre el formato de
!> Q(k)_in, donde cada Q(k)_in se representa mediante transformaciones de Householder
!> por bloques. Esta rutina llama a una rutina auxiliar CLARFB_GETT,
!> donde el cálculo se realiza en cada bloque individual. El
!> algoritmo primero barre bloques de columnas de tamaño NB de derecha a izquierda
!> comenzando en el bloque de fila inferior y continúa hasta el bloque de fila superior
!> (de ahí _ROW en el nombre de la rutina). Este barrido se realiza en orden inverso al
!> orden en que CLATSQR genera los bloques de salida.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. M >= N >= 0.
!>

MB

!>          MB es INTEGER
!>          El tamaño del bloque de filas utilizado por CLATSQR para devolver
!>          los arrays A y T. MB > N.
!>          (Tenga en cuenta que si MB > M, entonces M se usa en lugar de MB
!>          como tamaño del bloque de filas).
!>

NB

!>          NB es INTEGER
!>          El tamaño del bloque de columnas utilizado por CLATSQR para devolver
!>          los arrays A y T. NB >= 1.
!>          (Tenga en cuenta que si NB > N, entonces N se usa en lugar de NB
!>          como tamaño del bloque de columnas).
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>
!>          En la entrada:
!>
!>             Los elementos en la diagonal y por encima de ella no se utilizan como
!>             entrada. Los elementos por debajo de la diagonal representan la matriz
!>             trapezoidal inferior unitaria por bloques V calculada por CLATSQR
!>             que define las matrices de entrada Q_in(k) (unos en la
!>             diagonal no se almacenan). Consulte CLATSQR para más detalles.
!>
!>          En la salida:
!>
!>             El array A contiene una matriz ortonormal M por N, Q_out,
!>             es decir, las columnas de A son vectores unitarios ortogonales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

T

!>          T es un array COMPLEX,
!>          de dimensión (LDT, N * NIRB)
!>          donde NIRB = Número_de_bloques_de_filas_de_entrada
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Sea NICB = Número_de_bloques_de_columnas_de_entrada
!>                   = CEIL(N/NB)
!>
!>          Los reflectores de bloque triangulares superiores que definen las
!>          matrices de entrada Q_in(k), k=(1:NIRB*NICB). Los bloques
!>          reflectores se almacenan en formato compacto en NIRB bloques
!>          de secuencias de reflectores. Cada una de las NIRB secuencias de bloque
!>          reflector se almacena en un bloque de columna NBxN más grande de T
!>          y consta de NICB bloques de columna triangulares superiores más pequeños NBxNB. Consulte CLATSQR para más detalles sobre el formato
!>          de T.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.
!>          LDT >= max(1,min(NB,N)).
!>

WORK

!>          (espacio de trabajo) array COMPLEX, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= NBLOCAL * MAX(NBLOCAL,(N-NBLOCAL)),
!>          donde NBLOCAL=MIN(NB,N).
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo.
!>          La rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

DLARGTSQR_ROW, SLARGTSQR_ROW, ZLARGTSQR_ROW - Forms the first N columns of an M-by-N real or complex matrix Q, which is implicitly defined by the output of DLATSQR, SLATSQR, or ZLATSQR.

Description

This routine is an auxiliary routine for the QR factorization of a trapezoidal matrix, which involves the generation of an orthonormal matrix Q.

The routines DLARGTSQR_ROW, SLARGTSQR_ROW, and ZLARGTSQR_ROW are used to construct the orthonormal matrix Q from the output of the DLATSQR, SLATSQR, and ZLATSQR routines, respectively. These routines generate an M-by-N matrix Q with orthonormal columns.

The input matrix Q is implicitly defined by a sequence of block Householder transformations stored in a compact format in the arrays A and T. The routines reconstruct the first N columns of the matrix product of these transformations.

The name suffix "_ROW" indicates that the algorithm processes the block reflectors in a specific order, sweeping column blocks from right to left, starting from the bottom row block and moving upwards. This is a reverse order compared to how DLATSQR, SLATSQR, and ZLATSQR generate the blocks.

NAME

UNGTSQR_ROW - constructs a unitary matrix Q from a representation of an upper-trapezoidal matrix T.

SYNOPSIS

 SUBROUTINE UNGTSQR_ROW(M, N, MB, NB, A, LDA, T, LDT, WORK, LWORK, INFO)
 
     INTEGER          MB, NB, LDA, LDT, LWORK, INFO
     COMPLEX*16       A(LDA,*), T(LDT,*), WORK(LWORK)

Detailed Description

UNGTSQR_ROW constructs an M-by-N complex matrix Q with orthonormal columns using the information stored in T and A. The matrix Q is composed of an input matrix Q_in and a matrix R, where R is an M-by-N upper trapezoidal matrix. Specifically, Q = Q_in * R. The input matrix Q_in is determined by the upper triangular block reflectors in T and the lower trapezoidal matrix A. The function computes Q = Q_in*R.

The algorithm performs the matrix-vector multiplication of the matrix Q_in and the upper trapezoidal matrix R.
