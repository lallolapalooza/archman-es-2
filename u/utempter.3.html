UTEMPTER(3) Manual de funciones de biblioteca UTEMPTER(3)

NOMBRE

utempter_add_record, utempter_remove_added_record, utempter_remove_record, utempter_set_helper — interfaz utempter

SINOPSIS

#include <utempter.h>

int
utempter_add_record(int fd, const char *host);

int
utempter_remove_added_record(void);

int
utempter_remove_record(int fd);

void
utempter_set_helper(const char *pathname);

DESCRIPCIÓN

utempter_add_record() la función añade un registro de inicio de sesión a la base de datos para la TTY perteneciente al descriptor de archivo del pseudo-terminal maestro fd, usando el nombre de usuario correspondiente a la ID de usuario real del proceso que llama y el nombre de host opcional host. Esta función inicia un proceso privilegiado para realizar el registro real.

utempter_remove_record() la función marca la sesión de inicio de sesión como cerrada para la TTY perteneciente al descriptor de archivo del pseudo-terminal maestro fd. Esta función inicia un proceso privilegiado para realizar el registro real.

utempter_remove_added_record() la función tiene las mismas propiedades que la función mencionada anteriormente, excepto que utiliza un valor en caché internamente del descriptor de archivo pasado a las funciones de inicio de sesión.

utempter_set_helper() la función cambia la ruta del ayudante predeterminado al valor especificado. El puntero pasado a esta función debe permanecer válido todo el tiempo mientras la interfaz utempter esté en uso.

VALORES DE RETORNO

En caso de error, se devuelve cero. En caso de éxito, se devuelve un valor distinto de cero.

NOTAS

Durante la ejecución del proceso privilegiado iniciado por estas funciones, el manejador de la señal SIGCHLD se establecerá temporalmente en la acción predeterminada.

VER TAMBIÉN

pututline(3), sigaction(3), updwtmp(3).

HISTORIA

Estas funciones aparecieron en ALT Linux Sisyphus en octubre de 2001.
