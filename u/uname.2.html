uname(2) Manual de llamadas al sistema uname(2)

NOMBRE

uname - obtener el nombre e información del kernel actual

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/utsname.h>
int uname(struct utsname *buf);

DESCRIPCIÓN

uname() devuelve información del sistema en la estructura apuntada por buf. La estructura utsname se define en <sys/utsname.h>:


struct utsname {
    char sysname[];    /* Nombre del sistema operativo (ej. "Linux") */
    char nodename[];   /* Nombre dentro de la red de comunicaciones
                          a la que está adjunto el nodo, si existe */
    char release[];    /* Versión del sistema operativo
                          (ej. "2.6.28") */
    char version[];    /* Versión del sistema operativo */
    char machine[];    /* Identificador del tipo de hardware */
#ifdef _GNU_SOURCE
    char domainname[]; /* Nombre del dominio NIS o YP */
#endif
};

La longitud de los arreglos en una estructura utsname no se especifica (ver VERSIONES e HISTORIAL); los campos están terminados por un byte nulo ('\0').

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
buf no es válido.

VERSIÓNES

El miembro domainname (el nombre de dominio NIS o YP) es una extensión de GNU.

La longitud de los campos de la estructura varía. Algunos sistemas operativos o bibliotecas utilizan un valor fijo de 9, 33, 65 o 257. Otros sistemas usan SYS_NMLN, _SYS_NMLN, UTSLEN o _UTSNAME_LENGTH. Claramente, es una mala idea usar cualquiera de estas constantes; simplemente use sizeof(...). SVr4 utiliza 257, "para soportar nombres de host de Internet" —este es el valor más grande que se puede encontrar en la práctica—.

ESTÁNDARES

POSIX.1-2024.

HISTORIAL

POSIX.1-2001, SVr4, 4.4BSD.

Diferencias biblioteca C/kernel

Con el tiempo, los aumentos en el tamaño de la estructura utsname han llevado a tres versiones sucesivas de uname(): sys_olduname() (slot __NR_oldolduname), sys_uname() (slot __NR_olduname) y sys_newuname() (slot __NR_uname). La primera usaba una longitud de 9 para todos los campos; la segunda usaba 65; la tercera también usa 65 pero agrega el campo domainname. La función envoltorio uname() de glibc oculta estos detalles a las aplicaciones, invocando la versión más reciente de la llamada al sistema proporcionada por el kernel.

NOTAS

El kernel tiene incorporado el nombre, la versión, la revisión y el tipo de máquina compatible. A la inversa, el campo nodename es configurado por el administrador para coincidir con la red (este es el llamado "hostname" históricamente en BSD, y se establece mediante sethostname(2)). De manera similar, el campo domainname se establece mediante setdomainname(2).

Parte de la información de utsname también es accesible a través de /proc/sys/kernel/{ostype, hostname, osrelease, version, domainname}.

VER TAMBIÉN

uname(1), getdomainname(2), gethostname(2), uts_namespaces(7)
