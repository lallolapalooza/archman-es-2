uudoc(1) Manual de Comandos Generales uudoc(1)

NOMBRE

uudoc - Crea el(los) DIRECTORIO(s) dado(s) si no existen

SINOPSIS

uudoc [-m|--modo] [-p|--padres] [-v|--verboso] [-Z ] [--contexto] [-h|--ayuda] [-V|--version] <dirs>

DESCRIPCIÓN

Crea el(los) DIRECTORIO(s) dado(s) si no existen

OPCIONES

-m, --modo
establecer el modo de archivo (no implementado en Windows)
-p, --padres
crear directorios padres según sea necesario
-v, --verboso
imprimir un mensaje por cada directorio impreso
-Z
establecer el contexto de seguridad SELinux de cada directorio creado al tipo predeterminado
--contexto <CTX>
similar a -Z, o si se especifica CTX, establecer el contexto de seguridad SELinux o SMACK a CTX
-h, --ayuda
Imprimir ayuda
-V, --version
Imprimir versión
<dirs>

EXTRA

Cada MODO tiene la forma [ugoa]*([-+=]([rwxXst]*|[ugo]))+|[-+=]?[0-7]+.

VERSIÓN

v(uutils coreutils) 0.4.0

uudoc (uutils coreutils) 0.4.0
