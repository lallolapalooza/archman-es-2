subrutina cungr2 (integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer info)

CUNGR2 genera toda o parte de la matriz unitaria Q de una factorización RQ determinada por cgerqf (algoritmo sin bloques).

Propósito:

!>
!> CUNGR2 genera una matriz compleja Q de m por n con filas ortonormales,
!> que se define como las últimas m filas de un producto de k
!>   reflectores elementales de orden n
!>
!>       Q  =  H(1)**H H(2)**H . . . H(k)**H
!>
!> tal como lo devuelve CGERQF.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz Q. N >= M.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. M >= K >= 0.
!>

A

!>          A es un array COMPLEJO, de dimensión (LDA,N)
!>          A la entrada, la fila (m-k+i) debe contener el vector que
!>          define el reflector elemental H(i), para i = 1,2,...,k, tal como
!>          lo devuelve CGERQF en las últimas k filas de su argumento de array
!>          A.
!>          A la salida, la matriz Q de m por n.
!>

LDA

!>          LDA es ENTERO
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEJO, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como lo devuelve CGERQF.
!>

WORK

!>          WORK es un array COMPLEJO, de dimensión (M)
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tiene un valor ilegal
!>

UNGQR2(3) LAPACK

NAME

UNGQR2 - UNGQR2 generates all or part of the unitary matrix Q from a QR factorization determined by CGEQRF (unblocked algorithm)

SYNOPSIS

    SUBROUTINE CUNGQR2( M, N, K, A, LDA, TAU, WORK, INFO )

        INTEGER M, N, K, LDA, INFO

        COMPLEX*16 A( LDA, * ), TAU( * ), WORK( * )
    SUBROUTINE ZUNGQR2( M, N, K, A, LDA, TAU, WORK, INFO )

        INTEGER M, N, K, LDA, INFO

        COMPLEX*16 A( LDA, * ), TAU( * ), WORK( * )

Detailed Description

This routine generates all or part of the unitary matrix Q from a QR factorization determined by cgeqrf (unblocked algorithm).

The unblocked version of the algorithm is used for the computation of the unitary matrix. It is defined as:

Q = H(1) H(2) ... H(K)

    Purpose:
            ZUNGQR2 generates an n by n complex unitary matrix Q which is
            defined by the elements returned in the array A by ZGEQRF.
            ZUNGQR2 is the inverse of ZGECON. ZUNGQR2 is also the inverse
            of ZGERQF.

Arguments:

M

Number of rows of the matrix A. M >= 0.

N

Number of columns of the matrix A. N >= M.

K

The number of elementary reflectors whose product must be formed, with K<=M.

A

On entry, the elements of the array A as returned by ZGEQRF. On exit formation of Q proceeds by decreasing the column index i and replacing passing the columns of the array A by the columns of the equational basis.

LDA

LDA is an LDA>=max(1,M).

TAU

TAU(i) is the factor of the elementary reflector H(i) which is defined by A(i:M,i) in the transformation Z(i)=I-TAU(i)Z(i).

WORK

WORK is COMPLEX*16 array, dimension (M)

INFO

= 0: successful exit

< 0: if INFO = -i, the i-th argument has an illegal value

subroutine ZUNGR2 (integer M, integer N, integer K, complex*16, dimension( LDA, * ) A, integer LDA, complex*16, dimension( * ) TAU, complex*16, dimension( * ) WORK, integer INFO)

ZUNGR2 generates all or part of the unitary matrix Q from an RQ factorization determined by cgerqf (unblocked algorithm).

Purpose:

!>
!> ZUNGR2 generates an m by n complex matrix Q with orthonormal rows,
!> which is defined as the last m rows of a product of k elementary
!> reflectors of order n
!>
!>       Q  =  H(1)**H H(2)**H . . . H(k)**H
!>
!> as returned by ZGERQF.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix Q. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix Q. N >= M.
!>

K

!>          K is INTEGER
!>          The number of elementary reflectors whose product defines the
!>          matrix Q. M >= K >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the (m-k+i)-th row must contain the vector which
!>          defines the elementary reflector H(i), for i = 1,2,...,k, as
!>          returned by ZGERQF in the last k rows of its array argument
!>          A.
!>          On exit, the m-by-n matrix Q.
!>

LDA

!>          LDA is INTEGER
!>          The first dimension of the array A. LDA >= max(1,M).
!>

TAU

!>          TAU is COMPLEX*16 array, dimension (K)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by ZGERQF.
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (M)
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument has an illegal value
!>
