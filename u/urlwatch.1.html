URLWATCH(1) Documentación de urlwatch URLWATCH(1)

NOMBRE

urlwatch - Monitorizar páginas web y la salida de comandos en busca de cambios

SINOPSIS

urlwatch [opciones] [TRABAJO ...]

DESCRIPCIÓN

urlwatch tiene la intención de ayudarte a monitorizar cambios en páginas web y a recibir notificaciones (por correo electrónico, en tu terminal o a través de varios servicios de terceros) de cualquier cambio. La notificación de cambios incluirá la URL que ha cambiado y un diff unificado de lo que ha cambiado.

Consulta urlwatch-intro(7) para una guía de inicio rápido y un tutorial, y urlwatch-cookbook(7) para recetas y trucos de uso.

Esta página del manual describe la herramienta CLI.

argumentos posicionales:
TRABAJO
índices o etiquetas de trabajo(s) a ejecutar. Si se establece --tags, cada TRABAJO es una etiqueta, si no, cada TRABAJO es un índice numerado según el comando --list.
argumentos opcionales:
-h, --help
mostrar este mensaje de ayuda y salir
--tags
usar etiquetas en lugar de índices para seleccionar trabajos a ejecutar
--version
mostrar el número de versión del programa y salir
-v, --verbose
mostrar salida de depuración
archivos y directorios:
--urls ARCHIVO
leer la lista de trabajos (URLs) desde ARCHIVO
--config ARCHIVO
leer la configuración desde ARCHIVO
--hooks ARCHIVO
usar ARCHIVO como módulo de hooks.py
--cache ARCHIVO
usar ARCHIVO como base de datos de caché
Autenticación:
--smtp-login
Introducir contraseña para SMTP (guardar en el gestor de contraseñas)
--xmpp-login
Introducir contraseña para XMPP (guardar en el gestor de contraseñas)
--telegram-chats
Listar chats de telegram a los que se ha unido el bot
--test-reporter REPORTERO
Enviar una notificación de prueba
gestión de lista de trabajos:
--list
listar trabajos
--add TRABAJO
añadir trabajo (clave1=valor1,clave2=valor2,...)
--delete TRABAJO
eliminar trabajo por ubicación o índice
--enable TRABAJO
habilitar trabajo por ubicación o índice
--disable TRABAJO
eliminar trabajo por ubicación o índice
--change_location TRABAJO NUEVA_UBICACIÓN
cambiar la ubicación de un trabajo existente por ubicación o índice
--test-filter TRABAJO
probar la salida del filtro del trabajo por ubicación o índice
--test-diff-filter TRABAJO
probar la salida del filtro de diff del trabajo por ubicación o índice (requiere al menos 2 instantáneas)
--dump-history TRABAJO
volcar datos históricos cacheados para un trabajo
comandos interactivos ($EDITOR/$VISUAL):
--edit
editar lista de URLs/trabajos
--edit-config
editar archivo de configuración
--edit-hooks
editar script de hooks
varios:
--features
listar trabajos/filtros/reporters soportados
--gc-cache LIMITE_RETENCION
eliminar entradas antiguas de caché, manteniendo las últimas RETAIN_LIMIT (por defecto: 1)

ARCHIVOS

$XDG_CONFIG_HOME/urlwatch/urls.yaml
Lista configurada de trabajos y filtros, ver urlwatch-jobs(5) y urlwatch-filters(5)
$XDG_CONFIG_HOME/urlwatch/urlwatch.yaml
Configuración global y de reporters, ver urlwatch-config(5) y urlwatch-reporters(5)
$XDG_CONFIG_HOME/urlwatch/hooks.py
Un módulo de Python 3 que puede implementar nuevos tipos de trabajos, filtros y reporters
$XDG_CACHE_HOME/urlwatch/cache.db
Una base de datos SQLite 3 (minidb) que contiene el historial de estado de los trabajos (para diff)
