utime(2) Manual de Llamadas al Sistema utime(2)

NOMBRE

utime, utimes - cambiar las horas de último acceso y modificación de un archivo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <utime.h>
int utime(const char *path,
          const struct utimbuf *_Nullable times);
#include <sys/time.h>
int utimes(const char *path,
          const struct timeval times[_Nullable 2]);

DESCRIPCIÓN

Nota: las aplicaciones modernas pueden preferir usar las interfaces descritas en utimensat(2).

La llamada al sistema utime() cambia las horas de acceso y modificación del inodo especificado por path a los campos actime y modtime de times respectivamente. La hora de cambio de estado (ctime) se establecerá a la hora actual, incluso si las otras marcas de tiempo no cambian realmente.

Si times es NULL, entonces las horas de acceso y modificación del archivo se establecen a la hora actual.

Se permite cambiar las marcas de tiempo cuando: o bien el proceso tiene privilegios apropiados, o el ID de usuario efectivo coincide con el ID de usuario del archivo, o times es NULL y el proceso tiene permiso de escritura para el archivo.

La estructura utimbuf es:


struct utimbuf {
    time_t actime;       /* hora de acceso */
    time_t modtime;      /* hora de modificación */
};

La llamada al sistema utime() permite especificar marcas de tiempo con una resolución de 1 segundo.

La llamada al sistema utimes() es similar, pero el argumento times se refiere a un array en lugar de una estructura. Los elementos de este array son estructuras timeval, que permiten una precisión de 1 microsegundo para especificar marcas de tiempo. La estructura timeval es:


struct timeval {
    long tv_sec;        /* segundos */
    long tv_usec;       /* microsegundos */
};

times[0] especifica la nueva hora de acceso, y times[1] especifica la nueva hora de modificación. Si times es NULL, entonces, análogamente a utime(), las horas de acceso y modificación del archivo se establecen a la hora actual.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EACCES
Se deniega el permiso de búsqueda para uno de los directorios en el prefijo de ruta de path (ver también path_resolution(7)).
EACCES
times es NULL, el ID de usuario efectivo del llamante no coincide con el propietario del archivo, el llamante no tiene permiso de escritura en el archivo y el llamante no tiene privilegios (Linux: no tiene la capacidad CAP_DAC_OVERRIDE ni la capacidad CAP_FOWNER).
EFAULT
path apunta a una dirección inválida.
ENOENT
path no existe.
EPERM
times no es NULL, el UID efectivo del llamante no coincide con el propietario del archivo y el llamante no tiene privilegios (Linux: no tiene la capacidad CAP_FOWNER).
EROFS
path reside en un sistema de archivos de solo lectura.

ESTÁNDARES

utime()
Ninguno.
utimes()
POSIX.1-2024.

HISTORIA

utime()
SVr4, POSIX.1-2001. Obsoleto en POSIX.1-2008. Eliminado en POSIX.1-2024.
utimes()
4.3BSD, POSIX.1-2001.

NOTAS

Linux no permite cambiar las marcas de tiempo de un archivo inmutable, o establecer las marcas de tiempo a algo que no sea la hora actual en un archivo de solo añadir.
