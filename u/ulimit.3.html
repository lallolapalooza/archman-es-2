ulimit(3) Manual de funciones de biblioteca ulimit(3)

NOMBRE

ulimit - obtener y establecer límites de usuario

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <ulimit.h>
[[deprecated]] long ulimit(int cmd, long newlimit);

DESCRIPCIÓN

Advertencia: esta rutina está obsoleta. Use getrlimit(2), setrlimit(2) y sysconf(3) en su lugar. Para el comando de shell ulimit, consulte bash(1).

La llamada ulimit() obtendrá o establecerá algún límite para el proceso llamante. El argumento cmd puede tener uno de los siguientes valores.

UL_GETFSIZE
Devuelve el límite del tamaño de un archivo, en unidades de 512 bytes.
UL_SETFSIZE
Establece el límite del tamaño de un archivo.
3
(No implementado para Linux.) Devuelve la dirección máxima posible del segmento de datos.
4
(Implementado pero no se proporciona una constante simbólica.) Devuelve el número máximo de archivos que el proceso llamante puede abrir.

VALOR DE RETORNO

En caso de éxito, ulimit() devuelve un valor no negativo. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EPERM
Un proceso no privilegiado intentó aumentar un límite.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
ulimit () Seguridad de hilos Seguro para hilos (MT-Safe)

ESTÁNDARES

POSIX.1-2008.

HISTORIA

SVr4, POSIX.1-2001. POSIX.1-2008 la marca como obsoleta.

VER TAMBIÉN

bash(1), getrlimit(2), setrlimit(2), sysconf(3)
