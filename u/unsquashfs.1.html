UNSQUASHFS(1) Comandos de usuario UNSQUASHFS(1)

NOMBRE

unsquashfs - herramienta para descomprimir, extraer y listar sistemas de archivos squashfs

SINOPSIS

unsquashfs [OPCIONES] SISTEMA_DE_ARCHIVOS [archivos a extraer o excluir (con -excludes) o mostrar (con -cat )]

DESCRIPCIÓN

Squashfs es un sistema de archivos de solo lectura altamente comprimido para Linux. Utiliza compresión gzip/xz/lzo/lz4/zstd para comprimir archivos, inodos y directorios. Los inodos en el sistema son muy pequeños y todos los bloques se empaquetan para minimizar la sobrecarga de datos. Se admiten tamaños de bloque superiores a 4K hasta un máximo de 1 Mbyte (tamaño de bloque predeterminado 128K).

Squashfs está destinado a un uso general de sistemas de archivos de solo lectura, para uso de archivo (es decir, en casos donde se puede usar un archivo .tar.gz) y en sistemas de bloques/memoria restringidos (por ejemplo, sistemas integrados) donde se necesita baja sobrecarga.

OPCIONES

Opciones de extracción (filtrado) del sistema de archivos:

-d RUTA, -dest RUTA
extraer en RUTA, predeterminado "squashfs-root". Esta opción también establece el prefijo utilizado al listar el sistema de archivos.
-max NIVELES, -max-depth NIVELES
descender como máximo NIVELES de directorios al extraer.
-excludes
tratar los archivos en la línea de comandos como archivos de exclusión.
-ex, -exclude-list
lista de archivos a excluir, terminada con ; por ejemplo, archivo1 archivo2 ;.
-extract-file ARCHIVO
lista de directorios o archivos a extraer. Uno por línea.
-exclude-file ARCHIVO
lista de directorios o archivos a excluir. Uno por línea.
-match
abortar si algún archivo de extracción no coincide con nada y no se puede resolver. Implica -missing-symlinks y -no-wildcards.
-follow, -follow-symlinks
seguir enlaces simbólicos en los archivos de extracción y añadir todos los archivos/enlaces simbólicos necesarios para resolver el archivo de extracción. Implica -no-wildcards.
-missing, -missing-symlinks
Unsquashfs abortará si algún enlace simbólico no se puede resolver en -follow-symlinks.
-no-wild, -no-wildcards
no usar coincidencia de comodines en nombres de extracción y exclusión.
-r, -regex
tratar los nombres de extracción como expresiones regulares POSIX en lugar de usar la expansión de comodines del shell (globbing) predeterminada.
-all TIEMPO, -all-time TIEMPO
establecer todas las marcas de tiempo de los archivos en TIEMPO, en lugar del tiempo almacenado en el inodo del sistema de archivos. TIEMPO puede ser un entero de 32 bits sin signo que indica segundos desde la época (1970-01-01) o un valor de cadena que se pasa al comando "date" para analizarlo. Se puede usar cualquier valor de cadena que el comando date reconozca, como "now", "last week" o "Wed Feb 15 21:02:39 GMT 2023".
-cat
mostrar los archivos en la línea de comandos en stdout.
-f, -force
si el directorio de destino ya existe, descender en él y en todos los subdirectorios, y eliminar (borrar) los archivos si ya existen antes de extraerlos en ellos.
-pf ARCHIVO
generar un pseudo archivo equivalente al sistema de archivos Squashfs de entrada, usar - para stdout.

Opciones de información y listado del sistema de archivos:

-s, -stat
mostrar información de la superbloque del sistema de archivos.
-max NIVELES, -max-depth NIVELES
descender como máximo NIVELES de directorios al listar.
-i, -info
imprimir archivos a medida que se extraen.
-li, -linfo
imprimir archivos a medida que se extraen con atributos de archivo (como la salida de ls -l).
-l, -ls
listar el sistema de archivos, pero no extraer archivos.
-ll, -lls
listar el sistema de archivos con atributos de archivo (como la salida de ls -l), pero no extraer archivos.
-lln, -llnumeric
igual que -lls pero con uid y gid numéricos.
-lc
listar el sistema de archivos de forma concisa, mostrando solo archivos y directorios vacíos. No extraer archivos.
-llc
listar el sistema de archivos de forma concisa con atributos de archivo, mostrando solo archivos y directorios vacíos. No extraer archivos.
-full, -full-precision
usar precisión completa al mostrar tiempos, incluyendo segundos. Usar con -linfo, -lls, -lln y -llc.
-UTC
usar UTC en lugar de la zona horaria local al mostrar la hora.
-mkfs-time
mostrar la hora de la superbloque del sistema de archivos, que es un entero de 32 bits sin signo que representa el tiempo en segundos desde la época (1970-01-01).

Opciones de atributos extendidos (xattrs) del sistema de archivos:

-no, -no-xattrs
no extraer xattrs en el sistema de archivos.
-x, -xattrs
extraer xattrs en el sistema de archivos (predeterminado).
-xattrs-exclude REGEX
excluir cualquier nombre de xattr que coincida con REGEX. REGEX es una expresión regular POSIX, por ejemplo, -xattrs-exclude '^user.' excluye xattrs del espacio de nombres de usuario.
-xattrs-include REGEX
incluir cualquier nombre de xattr que coincida con REGEX. REGEX es una expresión regular POSIX, por ejemplo, -xattrs-include '^user.' incluye xattrs del espacio de nombres de usuario.

Opciones de ejecución de Unsquashfs:

-v, -version
mostrar información de versión, licencia y derechos de autor.
-p NÚMERO, -processors NÚMERO
usar NÚMERO de procesadores. Por defecto, usará el número de procesadores disponibles.
-mem TAMAÑO
usar TAMAÑO de memoria física para cachés. Usar K, M o G para especificar Kbytes, Mbytes o Gbytes respectivamente. Predeterminado 512 Mbytes.
-mem-percent PORCENTAJE
usar PORCENTAJE de memoria física para cachés.
-q, -quiet
sin salida detallada.
-n, -no-progress
no mostrar la barra de progreso.
-percentage
mostrar un porcentaje en lugar de la barra de progreso completa. Se puede usar con el diálogo --gauge, etc.
-ig, -ignore-errors
tratar los errores al escribir archivos en la salida como no fatales.
-st, -strict-errors
tratar todos los errores como fatales.
-no-exit, -no-exit-code

NAME

unsquashfs - decompressor for the SquashFS filesystem

SYNOPSIS

unsquashfs [ options ] [ -e|-ex expression ... ] imagefile [ outputdir ]

unsquashfs [ options ] [ -e|-ex expression ... ] imagefile filename ...

DESCRIPTION

unsquashfs is used to uncompress and extract files from a Squashfs filesystem image.

By default, the filesystem is extracted to a directory named "squashfs-root" in the current directory.

If outputdir is specified, the filesystem is extracted to outputdir. If outputdir is specified as ".", the filesystem is extracted to the current directory.

If one or more filename arguments are specified, only those files and directories are extracted. Wildcards are supported within filenames, and if they contain special characters they should be quoted.

The options for unsquashfs are detailed below.

OPTIONS

Extraction options:

-d outputdir
Extract filesystem to outputdir.
-r, -root-squash
Do not change ownership of extracted files. By default, ownership is changed to root and group root.
-p, -no-strip
Do not strip components from the beginning of filenames. By default, leading directories are stripped from filenames so that the first directory in the filesystem is the one specified by outputdir. Use this option if you want to preserve the full pathnames.
-f file
Extract the filesystem to file instead of a directory. Only useful when extracting a single file.
-e expression, -ex expression
Do not extract matching files. See File matching below.
-ef file
Do not extract matching files. See File matching below.
-ep file
Do not extract matching files. See File matching below.
-L, -follow-symlinks
By default, symbolic links are extracted as symbolic links. This option causes symbolic links to be extracted as regular files. If the symbolic link points to a file that is not present in the filesystem, then a regular file will be created but it will be empty.
-O, -no-follow-symlinks
Do not follow symbolic links. This is the default behaviour.
-k, -keep-full-permissions
Do not change ownership of extracted files. By default, ownership is changed to root and group root.
-m, -no-permissions
Do not extract file permissions. By default, file permissions are extracted.
-a, -no-xattrs
Do not extract extended attributes. By default, extended attributes are extracted.
-x REGEX
Only extract extended attributes matching REGEX. See Extended attributes below.
-X REGEX
Do not extract extended attributes matching REGEX. See Extended attributes below.
-max-depth depth
Do not extract files or directories deeper than depth. The default is unlimited depth.

Listing options:

-l, -ls
Output a listing of the filesystem to stdout, in addition to extracting it. The listing is similar to the output of "ls -l -a -l".
-linfo
Output a listing of the filesystem to stdout, but do not extract it. The listing is similar to the output of "ls -l -a -l".
-lc
Output a listing of the filesystem to stdout, but do not extract it. The listing is similar to the output of "ls -a -l".
-llc
Output a listing of the filesystem to stdout, but do not extract it. The listing is similar to the output of "ls -l -a -l".
-n, -no-list
Do not output a listing of the filesystem to stdout. This is the default behaviour.

Error handling options:

-i, -ignore-errors
Do not exit if non-fatal errors occur. By default, unsquashfs exits with status code 2 if non-fatal errors occur.
-s, -strict-errors
Exit if any errors occur. By default, unsquashfs exits with status code 1 if fatal errors occur, and status code 2 if non-fatal errors occur.
-n, -no-exit-code
do not set exit code (to nonzero) on non-fatal errors.

Help options:

-h, -help
print help summary information to pager (or stdout if not a terminal).
-help-option REGEX
print the help information for options matching REGEX to pager (or stdout if not a terminal).
-help-section SECTION
print the help information for section SECTION to pager (or stdout if not a terminal). If SECTION does not exactly match a section name, it is treated as a regular expression, and all section names that match are displayed. Use "list" as section name to get a list of sections and their names.
-help-all
print help information for all Unsquashfs options and sections to pager (or stdout if not a terminal).
-ho REGEX
shorthand alternative to -help-option.
-hs SECTION
shorthand alternative to -help-section.
-ha
shorthand alternative to -help-all.
-no-pager
do not use a pager to output help information.
-cols WIDTH
use WIDTH columns to output help information. Useful if output is not to a terminal.

Miscellaneous options:

-o BYTES, -offset BYTES
skip BYTES at start of FILESYSTEM. Optionally a suffix of K, M or G can be given to specify Kbytes, Mbytes or Gbytes respectively (default 0 bytes).
-fstime
synonym for -mkfs-time.
-e, -ef EXTRACT FILE
synonym for -extract-file.
-exc, -excf EXCLUDE FILE
synonym for -exclude-file.
-L
synonym for -follow-symlinks.
-pseudo-file FILE
alternative name for -pf.

EXIT STATUS

0
The filesystem listed or extracted OK.
1
FATAL errors occurred, e.g. filesystem corruption, I/O errors. Unsquashfs did not continue and aborted.
2
Non-fatal errors occurred, e.g. no support for XATTRs, Symbolic links in output filesystem or couldn't write permissions to output filesystem. Unsquashfs continued and did not abort.

See -ignore-errors, -strict-errors and -no-exit-code options for how they affect the exit status.

DECOMPRESSORS AVAILABLE

gzip, lzo, lz4, xz, zstd, lzma

ENVIRONMENT

SQFS_CMDLINE
If set, this is used as the directory to write the file sqfs_cmdline which contains the command line arguments given to Unsquashfs. Each command line argument is wrapped in quotes to ensure there is no ambiguity when arguments contain spaces. If the file already exists then the command line is appended to the file.
PAGER
If set, this is used as the name of the program used to display the help text. The value can be a simple command or a pathname. The default is /usr/bin/pager.

EXAMPLES

unsquashfs IMAGE.SQFS
Extract IMAGE.SQFS to "squashfs-root" in the current working directory.
unsquashfs -d output IMAGE.SQFS
Extract IMAGE.SQFS to "output" in the current working directory.
unsquashfs -d . IMAGE.SQFS
Extract IMAGE.SQFS to current working directory.
unsquashfs -linfo IMAGE.SQFS
Output a listing of IMAGE.SQFS with file attributes to stdout, while extracting the filesystem to "squashfs-root".
unsquashfs -lls IMAGE.SQFS
Output a listing of IMAGE.SQFS with file attributes to stdout, but do not extract the filesystem. The listing will be prefixed with "squashfs-root".
unsquashfs -d "" -lls IMAGE.SQFS
Output a listing of IMAGE.SQFS with file attributes to stdout, but do not extract the filesystem. The listing will not be prefixed with "squashfs-root".
unsquashfs IMAGE.SQFS fs/squashfs
Extract only the "fs/squashfs" directory.
unsquashfs IMAGE.SQFS "[Tt]est/example*"
Extract all files beginning with "example" inside top level directories called "Test" or "test".
unsquashfs -excludes IMAGE.SQFS "test/*data*.gz"
This will extract everything except for files that match *data*.gz in the test directory. The -excludes option tells Unsquashfs to exclude the files on the command line rather than extract them.
unsquashfs -excludes IMAGE.SQFS "... *.gz"
This will extract everything except for files that match *.gz anywhere in the image. The "..." means this is a non-anchored exclude which matches anywhere.
unsquashfs -ex "test/*data*.gz" ; IMAGE.SQFS test
This uses both extract and exclude options, to tell Unsquashfs to only extract the "test" directory, and to exclude any files within it that match *data*.gz.
unsquashfs -ex "... *.gz" IMAGE.SQFS test
This uses both extract and exclude options, to tell Unsquashfs to only extract the "test" directory, and to exclude files which match "*.gz" anywhere within "test" directory or sub-directories.
unsquashfs -dest output -max-depth 2 IMAGE.SQFS
Extract only the top two levels of IMAGE.SQFS to "output" directory.
unsquashfs -max-depth 2 IMAGE.SQFS "test/*.gz"
Only extract the gzipped files in the test directory.
unsquashfs -llc -max-depth 2 IMAGE.SQFS "test/*.gz"
Output a listing of the gzipped files in the test directory to stdout, but do not extract them.
unsquashfs -no-xattrs IMAGE.SQFS
Do not extract any extended attributes. Any extended attributes in the filesystem will be ignored.
unsquashfs -xattrs-include "^user." IMAGE.SQFS
Filter the extended attributes and only extract extended attributes in the user namespace from the Squashfs filesystem.
unsquashfs -xattrs-exclude "^user." IMAGE.SQFS
Filter the extended attributes and do not extract any extended attributes in the user namespace from the Squashfs filesystem.

Note: when passing wildcarded names to Unsquashfs, they should be quoted (as in the above examples), to ensure that they are not processed by the shell.
