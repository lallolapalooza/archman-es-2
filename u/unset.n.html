NOMBRE

unset - Eliminar variables

SINOPSIS

unset ?-nocomplain? ?--? ?nombre nombre nombre ...?

DESCRIPCIÓN

Este comando elimina una o más variables. Cada nombre es un nombre de variable, especificado de cualquier forma aceptable para el comando set. Si un nombre se refiere a un elemento de un array, entonces ese elemento se elimina sin afectar al resto del array. Si un nombre consiste en un nombre de array sin un índice entre paréntesis, entonces se elimina todo el array. El comando unset devuelve una cadena vacía como resultado. Si se especifica -nocomplain como primer argumento, se suprimen los posibles errores. La opción no puede abreviarse, para desambiguarla de posibles nombres de variables. La opción -- indica el final de las opciones y debe usarse si desea eliminar una variable con el mismo nombre que alguna de las opciones. Si ocurre un error durante la eliminación de la variable, las variables posteriores a la que causó el error no se eliminarán. Un error puede ocurrir cuando la variable nombrada no existe, o el nombre se refiere a un elemento de un array pero la variable es escalar, o el nombre se refiere a una variable en un namespace inexistente.

EJEMPLO

Crear un array que contenga un mapeo de algunos números a sus cuadrados y eliminar los elementos del array para los números no primos:

array set squares {
    1 1    6 36
    2 4    7 49
    3 9    8 64
    4 16   9 81
    5 25  10 100
}
puts "Los cuadrados son:"
parray squares
unset squares(1) squares(4) squares(6)
unset squares(8) squares(9) squares(10)
puts "Los cuadrados primos son:"
parray squares
