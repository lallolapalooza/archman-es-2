NOMBRE

u@PROGRAM_NAME@ - Programa auxiliar de desmontaje para desmontar un sistema de archivos @PACKAGE@

SINOPSIS

u@PROGRAM_NAME@ [-h | --help] [-V | --version]
umount dir

SINOPSIS (solo root)

u@PROGRAM_NAME@ dir

DESCRIPCIÓN

u@PROGRAM_NAME@ es un programa auxiliar de desmontaje. Es llamado por el comando umount(8). Su propósito es evitar que el comando de desmontaje retorne a menos que @PROGRAM_NAME@ haya sincronizado todos sus archivos cacheados con el servidor webdav.

dir es el punto de montaje donde el recurso WebDAV está montado. Puede ser una ruta absoluta o relativa.

Mientras que para los sistemas de archivos locales umount(8) solo retornará cuando todos los datos cacheados se hayan escrito en disco, esto no es automáticamente cierto para un sistema de archivos @PACKAGE@ montado. Con este ayudante de desmontaje, el usuario puede confiar en el comportamiento familiar de umount(8). Para informar al sistema operativo que el sistema de archivos utiliza una conexión de red, siempre debe usar la opción _netdev, al montar un sistema de archivos @PACKAGE@.

Dependiendo de la cantidad de datos y la calidad de la conexión, desmontar un sistema de archivos @PACKAGE@ puede tomar desde unos segundos hasta algunas horas.

Si el demonio @PROGRAM_NAME@ encontró errores graves, u@PROGRAM_NAME@ puede retornar un error en lugar de desmontar el sistema de archivos. En este caso, intente umount -i. La opción -i evitará que umount(8) llame a u@PROGRAM_NAME@.

OPCIONES

-V --version
Muestra la versión.
-h --help
Imprime un mensaje de ayuda.
-f -l -n -r -v -t
Estas opciones son ignoradas. Solo se reconocen por compatibilidad con umount(8).
