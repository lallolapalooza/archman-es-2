Paquete: unibilium

NOMBRE

unibi_dump - convierte un objeto de terminal a datos terminfo compilados

SINOPSIS

#include <unibilium.h>

size_t unibi_dump(const unibi_term *ut, char *p, size_t n);

DESCRIPCIÓN

Esta función crea una entrada terminfo compilada a partir de ut. La salida se escribe en p, que debe tener espacio para al menos n bytes.

Si todas las propiedades numéricas en ut tienen valores que caben en 15 bits, se utiliza el formato terminfo tradicional de ncurses (comenzando con los bytes "1A 01"), de lo contrario, se utiliza el formato más nuevo de "enteros anchos" (comenzando con los bytes "1E 02").

VALOR DE RETORNO

"unibi_dump" devuelve el número de bytes requeridos para almacenar los datos terminfo. Si esto excede n, no se escribe nada en p. Si el objeto de terminal no se puede representar en formato terminfo (por ejemplo, porque la tabla de cadenas sería demasiado grande), el valor de retorno es "SIZE_MAX".

ERRORES

"EINVAL"
ut no se puede convertir al formato terminfo.
"EFAULT"
La entrada terminfo resultante sería más larga que n bytes.

VER TAMBIÉN

unibilium.h(3), unibi_destroy(3), unibi_from_mem(3)
