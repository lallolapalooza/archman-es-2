NOMBRE

umoci list - Listar etiquetas en un layout OCI

SINOPSIS

umoci list --layout=layout

umoci ls --layout=layout

DESCRIPCIÓN

Obtiene la lista de etiquetas definidas en un layout OCI, con un nombre de etiqueta por línea. El orden de salida no está definido.

OPCIONES

--layout=layout
El layout de imágenes OCI del cual obtener la lista de etiquetas. layout debe ser una ruta a un layout OCI válido.

EJEMPLO

Lo siguiente lista el conjunto de etiquetas en un layout copiado de un registro docker(1) usando skopeo(1).

% skopeo copy docker://opensuse/amd64:42.1 oci:ocidir:42.1
% skopeo copy docker://opensuse/amd64:42.2 oci:ocidir:42.2
% skopeo copy docker://opensuse/amd64:latest oci:ocidir:latest
% umoci ls --layout ocidir
42.1
42.2
latest

VER TAMBIÉN
