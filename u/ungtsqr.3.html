CUNGTSQR

Propósito:

!>
!> CUNGTSQR genera una matriz compleja M por N, Q_out, con columnas ortonormales,
!> que son las primeras N columnas de un producto de matrices unitarias complejas
!> de orden M que son devueltas por CLATSQR
!>
!>      Q_out = primeras_N_columnas_de( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Véase la documentación de CLATSQR.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A. M >= N >= 0.
!>

MB

!>          MB es ENTERO
!>          El tamaño del bloque de filas utilizado por CLATSQR para devolver
!>          los arrays A y T. MB > N.
!>          (Tenga en cuenta que si MB > M, entonces M se usa en lugar de MB
!>          como tamaño del bloque de filas).
!>

NB

!>          NB es ENTERO
!>          El tamaño del bloque de columnas utilizado por CLATSQR para devolver
!>          los arrays A y T. NB >= 1.
!>          (Tenga en cuenta que si NB > N, entonces N se usa en lugar de NB
!>          como tamaño del bloque de columnas).
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>
!>          En la entrada:
!>
!>             Los elementos en y por encima de la diagonal no se acceden.
!>             Los elementos por debajo de la diagonal representan la matriz
!>             bloque inferior-trapezoidal unitaria V calculada por CLATSQR
!>             que define las matrices de entrada Q_in(k) (los unos en la
!>             diagonal no se almacenan) (mismo formato que la salida A
!>             por debajo de la diagonal en CLATSQR).
!>
!>          En la salida:
!>
!>             El array A contiene una matriz ortonormal M por N, Q_out,
!>             es decir, las columnas de A son vectores unitarios ortogonales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

T

!>          T es un array COMPLEJO,
!>          dimensión (LDT, N * NIRB)
!>          donde NIRB = Número_de_bloques_de_filas_de_entrada
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Sea NICB = Número_de_bloques_de_columnas_de_entrada
!>                   = CEIL(N/NB)
!>
!>          Los reflectores de bloque triangulares superiores utilizados para definir las
!>          matrices de entrada Q_in(k), k=(1:NIRB*NICB). Los reflectores de bloque
!>          se almacenan en forma compacta en NIRB secuencias de reflectores de bloque.
!>          Cada una de las NIRB secuencias de reflectores de bloque se almacena
!>          en un bloque de columnas más grande de T, de NB por N, y consta de
!>          NICB bloques de columnas más pequeños de NB por NB triangulares superiores.
!>          (mismo formato que la salida T en CLATSQR).
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal del array T.
!>          LDT >= max(1,min(NB1,N)).
!>

WORK

!>          (espacio de trabajo) array COMPLEJO, dimensión (MAX(2,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.  LWORK >= (M+NB)*N.
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo.
!>          La rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

DORGTSQR


Purpose:




!>
!> DORGTSQR generates an M-by-N real matrix Q_out with orthonormal columns,
!> which are the first N columns of a product of real orthogonal
!> matrices of order M which are returned by DLATSQR
!>
!>      Q_out = first_N_columns_of( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> See the documentation for DLATSQR.
!> 




Parameters


M

!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns of the matrix A. M >= N >= 0.
!> 


MB


!>          MB is INTEGER
!>          The row block size used by DLATSQR to return
!>          arrays A and T. MB > N.
!>          (Note that if MB > M, then M is used instead of MB
!>          as the row block size).
!> 


NB


!>          NB is INTEGER
!>          The column block size used by DLATSQR to return
!>          arrays A and T. NB >= 1.
!>          (Note that if NB > N, then N is used instead of NB
!>          as the column block size).
!> 


A


!>          A is REAL array, dimension (LDA,N)
!>
!>          On entry:
!>
!>             The elements on and above the diagonal are not accessed.
!>             The elements below the diagonal represent the unit
!>             lower-trapezoidal blocked matrix V computed by DLATSQR
!>             that defines the input matrices Q_in(k) (ones on the
!>             diagonal are not stored) (same format as the output A
!>             below the diagonal in DLATSQR).
!>
!>          On exit:
!>
!>             The array A contains an M-by-N orthonormal matrix Q_out,
!>             i.e the columns of A are orthogonal unit vectors.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!> 


T


!>          T is REAL array,
!>          dimension (LDT, N * NIRB)
!>          where NIRB = Number_of_input_row_blocks
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Let NICB = Number_of_input_col_blocks
!>                   = CEIL(N/NB)
!>
!>          The upper-triangular block reflectors used to define the
!>          input matrices Q_in(k), k=(1:NIRB*NICB). The block
!>          reflectors are stored in compact form in NIRB block
!>          reflector sequences. Each of NIRB block reflector sequences
!>          is stored in a larger NB-by-N column block of T and consists
!>          of NICB smaller NB-by-NB upper-triangular column blocks.
!>          (same format as the output T in DLATSQR).
!> 


LDT


!>          LDT is INTEGER
!>          The leading dimension of the array T.
!>          LDT >= max(1,min(NB1,N)).
!> 


WORK


!>          (workspace) REAL array, dimension (MAX(2,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!> 


LWORK


!>          LWORK is INTEGER
!>          The dimension of the array WORK.  LWORK >= (M+NB)*N.
!>          If LWORK = -1, then a workspace query is assumed.
!>          The routine only calculates the optimal size of the WORK
!>          array, returns this value as the first entry of the WORK
!>          array, and no error message related to LWORK is issued
!>          by XERBLA.
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>

NAME


zungtsqr — Computes the L*Q factor from a complex partitioned
    QR factorization






SYNOPSIS


SUBROUTINE ZUNGTSQR(
  N, M, K, A, LDA, B, LDB, C, LDC, D, LDD, TAU, WORK, LWORK, INFO
)
INTEGER :: N, M, K, LDA, LDB, LDC, LDD, LWORK, INFO
COMPLEX*16 :: A( LDA, * ), B( LDB, * ), C( LDC, * ), D( LDD, * ), TAU( * ), WORK( * )
INTEGER ::


```





Detailed Description


This routine is part of the LAPACK package.


This routine is the Schur version of the algorithm, and is used
    in other routines to compute the L*Q factor from a complex partitioned
    QR factorization.


Arguments:




N integer, dimension (scalar)
        The number of columns of the matrix A. N >= 0.
M integer, dimension (scalar)
        The number of columns of the matrix B. M >= 0.
K integer, dimension (scalar)
        The number of columns of the matrix C. K >= 0.
        N, M, K define the dimensions of the matrices A, B, C, D.
        The matrix D has dimensions (N + M + K) x (N + M + K).
        The matrix A has dimensions (N + M + K) x N.
        The matrix B has dimensions (N + M + K) x M.
        The matrix C has dimensions (N + M + K) x K.
        Note that D is square, but A, B, C are rectangular.
A complex*16 array, dimension (LDA, N)
        On entry, the L*Q factor for the matrix A.
        On exit, the L*Q factor for the matrix A.
LDA integer, dimension (scalar)
        The leading dimension of the array A. LDA >= max(1, N+M+K).
B complex*16 array, dimension (LDB, M)
        On entry, the L*Q factor for the matrix B.
        On exit, the L*Q factor for the matrix B.
LDB integer, dimension (scalar)
        The leading dimension of the array B. LDB >= max(1, N+M+K).
C complex*16 array, dimension (LDC, K)
        On entry, the L*Q factor for the matrix C.
        On exit, the L*Q factor for the matrix C.
LDC integer, dimension (scalar)
        The leading dimension of the array C. LDC >= max(1, N+M+K).
D complex*16 array, dimension (LDD, N+M+K)
        On entry, the upper triangular matrix for the matrix D.
        On exit, the upper triangular matrix for the matrix D.
LDD integer, dimension (scalar)
        The leading dimension of the array D. LDD >= max(1, N+M+K).
TAU complex*16 array, dimension (min(N, N+M+K))
        On entry, the array TAU of size min(N, N+M+K). TAU contains the
        scalar factors of the elementary reflectors for the triangular
        factorization of the matrix A.
        On exit, the array TAU of size min(N, N+M+K). TAU contains the
        scalar factors of the elementary reflectors for the triangular
        factorization of the matrix A.
WORK complex*16 array, dimension (LWORK)
        On exit, WORK(1) contains the optimal LWORK.
LWORK integer, dimension (scalar)
        The dimension of the array WORK. LWORK >= max(1, N+M+K).
        For optimal efficiency, LWORK >= (N+M+K)*nb, where nb is the
        maximum size of the block in this subroutine.
INFO integer, dimension (scalar)
        = 0:  successful exit
        < 0:  if INFO = -i, the i-th argument had an illegal value
