FBB::User(3bobcat) información del usuario de /etc/passwd FBB::User(3bobcat)

NOMBRE

FBB::User - Proporciona la información del usuario actual de /etc/passwd

SINOPSIS

#include <bobcat/user>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Esta clase recupera la información del usuario actual de la información en /etc/passwd. La clase es una simple clase envoltorio alrededor de la función getpwent(3).

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores, mencionados en esta página del manual, están definidos en el espacio de nombres FBB.

HEREDA DE

-

CONSTRUCTORES

o
User():
El constructor predeterminado determina los datos del usuario actual. Este constructor lanza una excepción Exception si no se completó correctamente porque el nombre de usuario actual no se pudo encontrar en /etc/passwd.
o
User(size_t uid):
Se determinan los datos del usuario cuyo ID de usuario es uid. Si los datos no se pudieron encontrar, se lanza una Exception.
o
User(std::string const &name):
Se determinan los datos del usuario cuyo nombre de usuario es name. Si los datos no se pudieron encontrar, se lanza una Exception.

Están disponibles constructores (y operadores de asignación) de copia y movimiento.

FUNCIONES MIEMBRO

o
size_t eGroupid() const:
Devuelve el ID de grupo efectivo del usuario.
o
size_t eUserid() const:
Devuelve el ID de usuario efectivo del usuario.
o
size_t groupid() const:
Devuelve el ID de grupo del usuario.
o
std::string homedir() const:
Devuelve el directorio de inicio del usuario (incluyendo una barra final /).
o
bool inGroup(size_t gid, bool useEffective = true) const:
Devuelve true si el usuario actual es miembro del grupo gid, de lo contrario, devuelve false. También se comprueba el ID de grupo efectivo del usuario si se especifica useEffective como true (que se proporciona como argumento de función predeterminado).
o
std::string name() const:
Devuelve el nombre de usuario del usuario.
o
std::string password() const:
Devuelve la contraseña cifrada del usuario. Pero consulte también la sección BUGS.
o
std::string realname() const:
Devuelve el nombre real del usuario, tal como aparece en el campo gecos de /etc/passwd.
o
std::string shell() const:
Devuelve el shell del usuario.
o
size_t userid() const:
Devuelve el ID de usuario del usuario.

EJEMPLO

#include <bobcat/user>
#include <iostream>
using namespace std;
using namespace FBB;
int main()
{
    User  user;
    cout << "\n"
        "name       : " << user.name()      << "\n" <<
        "password   : " << user.password()  << "\n" <<
        "user id    : " << user.userid()    << "\n" <<
        "group id   : " << user.groupid()   << "\n" <<
        "real name  : " << user.realname()  << "\n" <<
        "home dir   : " << user.homedir()   << "\n" <<
        "shell      : " << user.shell()     << "\n" << endl;
}

ERRORES

Si el usuario es miembro de varios grupos, groupid() solo devuelve el ID de grupo que aparece en /etc/passwd.

Si se utiliza el cifrado de contraseñas en sombra, la cadena devuelta por password() probablemente no contendrá la contraseña cifrada.

NOMBRE

bobcat - La biblioteca de manipulación de audio de Libre/Audacious.

SINOPSIS

#include <bobcat.h>

DESCRIPCIÓN

La biblioteca bobcat es un conjunto de bibliotecas que proporciona un backend de audio para la aplicación de reproducción de música Audacious. La biblioteca se encarga de la reproducción de audio real y proporciona una API simple para que las aplicaciones la utilicen.

La biblioteca bobcat maneja la decodificación de diversos formatos de audio, la manipulación de transmisiones de audio y la salida a los dispositivos de audio del sistema. También proporciona un conjunto de herramientas para el procesamiento de audio, como efectos, ecualizadores y análisis de audio.

La API está diseñada para ser fácil de usar y flexible, lo que permite a los desarrolladores integrarse sin problemas con sus propias aplicaciones. La biblioteca también está diseñada para ser eficiente y de bajo uso de recursos, lo que la hace adecuada para su uso en una amplia gama de dispositivos.

Para obtener información más detallada sobre el uso de la biblioteca bobcat, consulte la documentación de la API y los ejemplos proporcionados.
