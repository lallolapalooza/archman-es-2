subrutina cung2l (integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer info)

CUNG2L genera toda o parte de la matriz unitaria Q a partir de una factorización QL determinada por cgeqlf (algoritmo no bloqueado).

Propósito:

!>
!> CUNG2L genera una matriz compleja Q de m por n con columnas ortonormales,
!> que se define como las últimas n columnas de un producto de k
!>   reflectores elementales de orden m
!>
!>       Q  =  H(k) . . . H(2) H(1)
!>
!> tal como lo devuelve CGEQLF.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Q. M >= N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. N >= K >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>          En la entrada, la columna (n-k+i) debe contener el vector que
!>          define el reflector elemental H(i), para i = 1,2,...,k, tal
!>          como lo devuelve CGEQLF en las últimas k columnas de su
!>          argumento de array A.
!>          En la salida, la matriz Q de m por n.
!>

LDA

!>          LDA es INTEGER
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEX, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector elemental
!>          H(i), tal como lo devuelve CGEQLF.
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tiene un valor ilegal
!>
