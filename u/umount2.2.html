umount(2) Manual de llamadas al sistema umount(2)

NOMBRE

umount, umount2 - desmontar sistema de archivos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/mount.h>
int umount(const char *target);
int umount2(const char *target, int flags);

DESCRIPCIÓN

umount() y umount2() eliminan la adjunción del sistema de archivos (el más superior) montado en target.

Se requiere privilegios apropiados (Linux: la capacidad CAP_SYS_ADMIN) para desmontar sistemas de archivos.

Linux 2.1.116 añadió la llamada al sistema umount2(), que, al igual que umount(), desmonta un objetivo, pero permite flags adicionales que controlan el comportamiento de la operación:

MNT_FORCE (desde Linux 2.1.116)
Solicita al sistema de archivos que aborte las solicitudes pendientes antes de intentar el desmontaje. Esto puede permitir que el desmontaje se complete sin esperar a un servidor inaccesible, pero podría causar pérdida de datos. Si, después de abortar las solicitudes, algunos procesos todavía tienen referencias activas al sistema de archivos, el desmontaje seguirá fallando. A partir de Linux 4.12, MNT_FORCE solo se admite en los siguientes sistemas de archivos: 9p (desde Linux 2.6.16), ceph (desde Linux 2.6.34), cifs (desde Linux 2.6.12), fuse (desde Linux 2.6.16), lustre (desde Linux 3.11) y NFS (desde Linux 2.1.116).
MNT_DETACH (desde Linux 2.4.11)
Realiza un desmontaje perezoso: hace que el montaje no esté disponible para nuevos accesos, desconecta inmediatamente el sistema de archivos y todos los sistemas de archivos montados debajo de él entre sí y de la tabla de montajes, y realiza realmente el desmontaje cuando el montaje deja de estar ocupado.
MNT_EXPIRE (desde Linux 2.6.8)
Marca el montaje como expirado. Si un montaje no está actualmente en uso, una llamada inicial a umount2() con esta bandera falla con el error EAGAIN, pero marca el montaje como expirado. El montaje permanece expirado mientras no sea accedido por ningún proceso. Una segunda llamada a umount2() especificando MNT_EXPIRE desmonta un montaje expirado. Esta bandera no se puede especificar con MNT_FORCE ni con MNT_DETACH.
UMOUNT_NOFOLLOW (desde Linux 2.6.34)
No desreferencie target si es un enlace simbólico. Esta bandera permite evitar problemas de seguridad en programas set-user-ID-root que permiten a los usuarios no privilegiados desmontar sistemas de archivos.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

Los valores de error que se indican a continuación resultan de errores independientes del tipo de sistema de archivos. Cada tipo de sistema de archivos puede tener sus propios errores especiales y su propio comportamiento especial. Consulte el código fuente del kernel de Linux para obtener detalles.

EAGAIN
Una llamada a umount2() especificando MNT_EXPIRE marcó correctamente un sistema de archivos no ocupado como expirado.
EBUSY
No se pudo desmontar target porque está ocupado.
EFAULT
target apunta fuera del espacio de direcciones del usuario.
EINVAL
target no es un punto de montaje.
EINVAL
target está bloqueado; consulte mount_namespaces(7).
EINVAL
Se llamó a umount2() con MNT_EXPIRE y MNT_DETACH o MNT_FORCE.
EINVAL (desde Linux 2.6.34)
Se llamó a umount2() con un valor de bandera inválido en flags.
ENAMETOOLONG
Una ruta de archivo era más larga que MAXPATHLEN.
ENOENT
Una ruta de archivo estaba vacía o tenía un componente inexistente.
ENOMEM
El kernel no pudo asignar una página libre para copiar nombres de archivo o datos.
EPERM
El llamante no tiene los privilegios requeridos.

ESTÁNDARES

Linux.

HISTORIA

MNT_DETACH y MNT_EXPIRE están disponibles desde glibc 2.11.

La función original umount() se llamaba como umount(device) y devolvía ENOTBLK cuando se llamaba con algo que no fuera un dispositivo de bloque. En Linux 0.98p4, se añadió una llamada umount(dir), para admitir dispositivos anónimos. En Linux 2.3.99-pre7, se eliminó la llamada umount(device), dejando solo umount(dir) (ya que ahora los dispositivos pueden montarse en más de un lugar, especificar el dispositivo no es suficiente).

NOTAS

umount() y montajes compartidos

Los montajes compartidos provocan que cualquier actividad de montaje en un montaje, incluidas las operaciones umount(), se reenvíe a cada montaje compartido en el grupo de pares y a cada montaje esclavo de ese grupo de pares. Esto significa que umount() de cualquier par en un conjunto de montajes compartidos provocará que todos sus pares se desmonten y todos sus esclavos también se desmonten.

Esta propagación de la actividad de desmontaje puede ser particularmente sorprendente en sistemas donde cada montaje se comparte por defecto. En tales sistemas, el montaje enlazado recursivamente del directorio raíz del sistema de archivos a un subdirectorio y luego el desmontaje de ese subdirectorio con MNT_DETACH provocará que cada montaje en el espacio de nombres de montaje se desmonte de forma perezosa.

Para asegurar que umount() no se propague de esta manera, el montaje puede ser remontado usando una llamada a mount(2) con un argumento mount_flags que incluya tanto MS_REC como MS_PRIVATE antes de que se llame a umount().

umount2(2)

desmontar un sistema de archivos

LIBRARY

System V IPC (libucb, -lucb)

SYNOPSIS

#include <sys/mount.h>

int umount2(const char *target, int flags);

DESCRIPTION

umount2() desmonta un sistema de archivos. El argumento target especifica el punto de montaje del sistema de archivos a desmontar. El argumento flags especifica las opciones de desmontaje.

Las siguientes banderas pueden ser especificadas en flags:

MNT_FORCE
Desmonta el sistema de archivos forzosamente. Esto puede provocar pérdida de datos.
MNT_DETACH
Desmonta el sistema de archivos de forma perezosa. Esto significa que el sistema de archivos se desmontará tan pronto como ya no esté en uso. Esto es más seguro que MNT_FORCE.
MNT_EXPIRE
Marca el sistema de archivos como obsoleto. Esto se utiliza con sistemas de archivos de red que pueden estar temporalmente no disponibles.

RETURN VALUE

En caso de éxito, umount2() devuelve 0. En caso de error, devuelve -1 y errno se establece para indicar el error.

ERRORS

EBUSY
El sistema de archivos está ocupado y no se puede desmontar.
EINVAL
El argumento target no es un punto de montaje válido, o las banderas especificadas no son válidas.
ENOTDIR
El argumento target no es un directorio.
ENOENT
El sistema de archivos no se encuentra.
EPERM
El llamante no tiene los privilegios necesarios para desmontar el sistema de archivos.

STANDARDS

Esta función es específica de Linux y no forma parte de ningún estándar POSIX.

HISTORY

La función umount2() se introdujo en el kernel de Linux 2.3.15.

NOTES

El desmontaje forzoso (MNT_FORCE) debe usarse con precaución, ya que puede provocar la pérdida de datos si el sistema de archivos está en uso.

El desmontaje perezoso (MNT_DETACH) es generalmente la opción preferida, ya que es más seguro y garantiza que no se pierdan datos.
