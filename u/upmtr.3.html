CUPMTR

Propósito:

!>
!> CUPMTR sobrescribe la matriz compleja general M por N, C, con
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> donde Q es una matriz unitaria compleja de orden nq, con nq = m si
!> SIDE = 'L' y nq = n si SIDE = 'R'. Q se define como el producto de
!> nq-1 reflexiones elementales, tal como se devuelve por CHPTRD usando
!> almacenamiento empaquetado:
!>
!> si UPLO = 'U', Q = H(nq-1) . . . H(2) H(1);
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(nq-1).
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplica Q o Q**H desde la Izquierda;
!>          = 'R': aplica Q o Q**H desde la Derecha.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U': almacenamiento empaquetado triangular superior utilizado en la
!>                 llamada anterior a CHPTRD;
!>          = 'L': almacenamiento empaquetado triangular inferior utilizado en la
!>                 llamada anterior a CHPTRD.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplica Q;
!>          = 'C':  Transpuesta conjugada, aplica Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

AP

!>          AP es un array de tipo COMPLEX, de dimensión
!>                               (M*(M+1)/2) si SIDE = 'L'
!>                               (N*(N+1)/2) si SIDE = 'R'
!>          Los vectores que definen las reflexiones elementales, tal como
!>          se devuelven por CHPTRD. AP es modificado por la subrutina pero
!>          se restaura a la salida.
!>

TAU

!>          TAU es un array de tipo COMPLEX, de dimensión (M-1) si SIDE = 'L'
!>                                     o (N-1) si SIDE = 'R'
!>          TAU(i) debe contener el factor escalar de la reflexión
!>          elemental H(i), tal como se devuelve por CHPTRD.
!>

C

!>          C es un array de tipo COMPLEX, de dimensión (LDC,N)
!>          A la entrada, la matriz M por N, C.
!>          A la salida, C se sobrescribe con Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array de tipo COMPLEX, de dimensión
!>                                   (N) si SIDE = 'L'
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Detailed Description

This routine is part of the LAPACK routines that deal with the decomposition of general matrices.

The routines are grouped by the type of matrix decomposition they perform. This routine deals with the reduction of a general matrix to Hessenberg form.

The specific routines are:

  • sopmtr

  • zupmtr

SOPMTR

Purpose:

!>
!> SOPMTR overwrites the general real M-by-N matrix C with
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>
!> where Q is a real orthogonal matrix of order nq, with nq = m if
!> SIDE = 'L' and nq = n if SIDE = 'R'. Q is defined as the product of
!> nq-1 elementary reflectors, as returned by SSPTRD using packed
!> storage:
!>
!> if UPLO = 'U', Q = H(nq-1) . . . H(2) H(1);
!>
!> if UPLO = 'L', Q = H(1) H(2) . . . H(nq-1).
!>

Parameters

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': apply Q or Q**T from the Left;
!>          = 'R': apply Q or Q**T from the Right.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U': Upper triangular packed storage used in previous
!>                 call to SSPTRD;
!>          = 'L': Lower triangular packed storage used in previous
!>                 call to SSPTRD.
!>

TRANS

!>          TRANS is CHARACTER*1
!>          = 'N':  No transpose, apply Q;
!>          = 'T':  Transpose, apply Q**T.
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix C. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix C. N >= 0.
!>

AP

!>          AP is REAL array, dimension
!>                               (M*(M+1)/2) if SIDE = 'L'
!>                               (N*(N+1)/2) if SIDE = 'R'
!>          The vectors which define the elementary reflectors, as
!>          returned by SSPTRD.  AP is modified by the routine but
!>          restored on exit.
!>

TAU

!>          TAU is REAL array, dimension (M-1) if SIDE = 'L'
!>                                     or (N-1) if SIDE = 'R'
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by SSPTRD.
!>

C

!>          C is REAL array, dimension (LDC,N)
!>          On entry, the M-by-N matrix C.
!>          On exit, C is overwritten by Q*C or Q**T*C or C*Q**T or C*Q.
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!>

WORK

!>          WORK is REAL array, dimension
!>                                   (N) if SIDE = 'L'
!>                                   (M) if SIDE = 'R'
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
