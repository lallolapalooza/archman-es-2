NOMBRE

update-smart-drivedb - actualizar la base de datos de unidades de smartmontools

SINOPSIS

update-smart-drivedb [OPCIONES] [ARCHIVO DESTINO]

DESCRIPCIÓN

[Esta página del manual está generada para la versión de Linux de smartmontools. No contiene información específica para otras plataformas.]

update-smart-drivedb actualiza /usr/share/smartmontools/drivedb.h o ARCHIVO DESTINO desde las ramas/RELEASE_7_5_DRIVEDB del repositorio SVN de smartmontools.

Las herramientas utilizadas para la descarga son curl(1), wget(1), lynx(1) o svn(1).

El archivo descargado se verifica con la clave GPG/OpenPGP ID 721042C5. El bloque de clave pública está incluido en el script.

El archivo antiguo se conserva si el archivo descargado es idéntico (ignorando las diferencias en la cadena de Id) de lo contrario se mueve a drivedb.h.old.

El archivo antiguo también se conserva si el archivo descargado informa de una versión anterior en la misma rama. Esto puede ser anulado con la opción '--force'. Si la versión de la rama difiere, el archivo siempre se actualiza.

OPCIONES

-s SMARTCTL, --smartctl SMARTCTL
Utiliza el ejecutable smartctl(8) en la ruta SMARTCTL para la comprobación de sintaxis de la base de datos de unidades. La forma '-s -' deshabilita la comprobación de sintaxis. El valor predeterminado es /usr/bin/smartctl.
-t [DIR/]HERRAMIENTA, --tool [DIR/]HERRAMIENTA
Utiliza HERRAMIENTA para la descarga. HERRAMIENTA es una de: curl wget lynx svn. El valor predeterminado es la primera que se encuentra en PATH. Si también se especifica un DIR, el nombre simple de HERRAMIENTA debe comenzar con alguno de los nombres anteriores.
-u UBICACIÓN, --url-of UBICACIÓN
Utiliza la URL de UBICACIÓN para la descarga. UBICACIÓN es una de:
github (espejo de GitHub del repositorio SVN),
sf (navegador de código de Sourceforge),
svn (repositorio SVN),
svni (repositorio SVN a través de HTTP en lugar de HTTPS),
trac (navegador de código de Trac).
El valor predeterminado es svn.
--url URL
Descargar desde URL. Una firma válida de OpenPGP/GPG con extensión '.raw.asc' también debe existir a menos que también se especifique '--no-verify'.
--file ARCHIVO
Copiar desde ARCHIVO local. Una firma válida de OpenPGP/GPG 'ARCHIVO.raw.asc' debe existir también a menos que se especifique '--no-verify'.
--trunk
Descargar desde la rama principal de SVN (trunk). Esto requiere '--no-verify' porque las versiones del trunk no están firmadas.
--branch X.Y
Descargar desde branches/RELEASE_X_Y_DRIVEDB. Esto también selecciona la clave GPG/OpenPGP para ramas antiguas (5.40 a 6.6: ID de clave DFD22559).
--cacert ARCHIVO
Utilizar certificados CA de ARCHIVO para verificar al par.
--capath DIR
Utilizar archivos de certificado CA de DIR para verificar al par.
--insecure
No abortar la descarga si falla la verificación del certificado. Esta opción también es necesaria si se selecciona una URL HTTP con la opción '-u'.
--no-verify
No verificar la firma con GnuPG.
--force
Permitir reversiones. Por defecto, la base de datos no se reemplaza con una versión anterior de la misma rama.
--export-key
Imprimir el bloque de clave pública OpenPGP/GPG.
--dryrun
Imprimir solo los comandos de descarga.
-q, --quiet
Suprimir mensajes informativos.
-v, --verbose
Salida detallada.
-h, --help
Imprimir texto de ayuda.

EJEMPLOS

Actualización regular:

# update-smart-drivedb
/usr/share/smartmontools/drivedb.h 7.2/5225 actualizado a 7.2/5237

Revertir a la versión anterior:

# update-smart-drivedb --force \
  --file /usr/share/smartmontools/drivedb.h.old
/usr/share/smartmontools/drivedb.h 7.2/5237 revertido a 7.2/5225

Descargar la base de datos desde la rama principal de SVN al directorio actual:

$ update-smart-drivedb --trunk --no-verify -s - -u trac drivedb-trunk.h
drivedb-trunk.h 7.3/5254 instalado (NO VERIFICADO)

ESTADO DE SALIDA

El estado de salida es 0 si la base de datos se ha actualizado correctamente o ya está al día. Si ocurre un error, el estado de salida es 1.

ARCHIVOS

utilizado para comprobar la sintaxis de la nueva base de datos de unidades.
/usr/share/smartmontools/drivedb.h
base de datos de unidades actual.
/usr/share/smartmontools/drivedb.h.raw
base de datos de unidades actual con cadena Id de SVN sin expandir.
/usr/share/smartmontools/drivedb.h.raw.asc
archivo de firma.
/usr/share/smartmontools/drivedb.h.*old*
archivos anteriores.
/usr/share/smartmontools/drivedb.h.*error*
archivos nuevos si se rechazan debido a errores.
/usr/share/smartmontools/drivedb.h.lastcheck
archivo vacío creado si el archivo descargado era idéntico.
