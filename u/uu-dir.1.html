uudoc(1) Manual de Comandos Generales uudoc(1)

NOMBRE

uudoc - Lista el contenido de directorios. Ignora por defecto archivos y directorios que comienzan con '.'

SINOPSIS

uudoc [--help] [--format] [-C ] [-l|--long] [-x ] [-T|--tabsize] [-m ] [--zero] [-D|--dired] [--hyperlink] [-1 ] [-o ] [-g ] [-n|--numeric-uid-gid] [--quoting-style] [-N|--literal] [-b|--escape] [-Q|--quote-name] [-q|--hide-control-chars] [--show-control-chars] [--time] [-c ] [-u ] [--hide] [-I|--ignore] [-B|--ignore-backups] [--sort] [-S ] [-t ] [-v ] [-X ] [-U ] [-L|--dereference] [--dereference-command-line-symlink-to-dir] [-H|--dereference-command-line] [-G|--no-group] [--author] [-a|--all] [-A|--almost-all] [-f ] [-d|--directory] [-h|--human-readable] [-k|--kibibytes] [--si] [--block-size] [-i|--inode] [-r|--reverse] [-R|--recursive] [-w|--width] [-s|--size] [--color] [--indicator-style] [-F|--classify] [--file-type] [-p ] [--time-style] [--full-time] [-Z|--context] [--group-directories-first] [-V|--version] [rutas]

DESCRIPCIÓN

Lista el contenido de directorios. Ignora por defecto archivos y directorios que comienzan con '.'

OPCIONES

--help
Imprime información de ayuda.
--format
Establece el formato de visualización.
-C
Muestra los archivos en columnas.
-l, --long
Muestra información detallada.
-x
Lista las entradas en filas en lugar de columnas.
-T, --tabsize <COLS>
Asume tabulaciones cada COLS en lugar de 8
También se puede especificar con la variable de entorno TABSIZE.
-m
Lista las entradas separadas por comas.
--zero
Lista las entradas separadas por caracteres ASCII NUL.
-D, --dired
Genera una salida diseñada para el modo dired (Editor de Directorios) de Emacs
--hyperlink[=<CUÁNDO>] [predeterminado: never]
enlaza los nombres de archivo CUÁNDO

[valores posibles: always, auto, never]

-1
Lista un archivo por línea.
-o
Formato largo sin información de grupo. Idéntico a --format=long con --no-group.
-g
Formato largo sin información de propietario.
-n, --numeric-uid-gid
-l con UID y GID numéricos.
--quoting-style
Establece el estilo de comillas.

[valores posibles: literal, shell, shell-escape, shell-always, shell-escape-always, c, escape]

-N, --literal
Usa el estilo de comillas literal. Equivalente a `--quoting-style=literal`
-b, --escape
Usa el estilo de comillas de escape. Equivalente a `--quoting-style=escape`
-Q, --quote-name
Usa el estilo de comillas C. Equivalente a `--quoting-style=c`
-q, --hide-control-chars
Reemplaza los caracteres de control con '?' si no están escapados.
--show-control-chars
Muestra los caracteres de control "tal cual" si no están escapados.
--time=<campo>
Muestra la hora en <campo>: hora de acceso (-u): atime, access, use; hora de cambio (-t): ctime, status. hora de modificación: mtime, modification. hora de creación: birth, creation;
-c
Si se está utilizando el formato de listado largo (por ejemplo, -l, -o), imprime la hora de cambio de estado (el 'ctime' en el inodo) en lugar de la hora de modificación. Cuando se ordena explícitamente por hora (--sort=time o -t) o cuando no se utiliza un formato de listado largo, ordena según la hora de cambio de estado.
-u
Si se está utilizando el formato de listado largo (por ejemplo, -l, -o), imprime la hora de acceso en lugar de la hora de modificación. Cuando se ordena explícitamente por hora (--sort=time o -t) o cuando no se utiliza un formato de listado largo, ordena según la hora de acceso.
--hide <PATRÓN>
no lista entradas implícitas que coincidan con el PATRÓN shell (anulado por -a o -A)
-I, --ignore <PATRÓN>
no lista entradas implícitas que coincidan con el PATRÓN shell
-B, --ignore-backups
Ignora las entradas que terminan en ~.
--sort=<campo>
Ordena por <campo>: nombre, ninguno (-U), hora (-t), tamaño (-S), extensión (-X) o ancho

[valores posibles: name, none, time, size, version, extension, width]

-S
Ordena por tamaño de archivo, el más grande primero.
-t
Ordena por hora de modificación (el 'mtime' en el inodo), el más reciente primero.
-v
Ordenación natural de números (de versión) en los nombres de archivo.
-X
Ordena alfabéticamente por extensión de entrada.
-U
No ordenar; lista los archivos en el orden en que estén almacenados en el directorio. Esto es especialmente útil al listar directorios muy grandes, ya que no ordenar puede ser notablemente más rápido.
-L, --dereference
Al mostrar información de archivo para un enlace simbólico, muestra información sobre el archivo al que apunta el enlace en lugar del enlace en sí.
--dereference-command-line-symlink-to-dir
No seguir enlaces simbólicos excepto cuando apuntan a directorios y se proporcionan como argumentos de línea de comandos.
-H, --dereference-command-line
No seguir enlaces simbólicos excepto cuando se proporcionan como argumentos de línea de comandos.
-G, --no-group
No mostrar grupo en formato largo.
--author
Muestra el autor en formato largo. En las plataformas compatibles, el autor siempre coincide con el propietario del archivo.
-a, --all
No ignorar archivos ocultos (archivos cuyos nombres comienzan con '.').
-A, --almost-all
En un directorio, no ignorar todos los nombres de archivo que comienzan con '.', solo ignorar '.' y '..'.
-f
Lista todos los archivos en orden de directorio, sin ordenar. Equivalente a -aU. Desactiva --color a menos que se especifique explícitamente.
-d, --directory
Solo lista los nombres de los directorios, en lugar de listar el contenido del directorio. No seguirá los enlaces simbólicos a menos que se especifique uno de los siguientes: `--dereference-command-line (-H)`, `--dereference (-L)`, o `--dereference-command-line-symlink-to-dir`.
-h, --human-readable
Imprime tamaños de archivo legibles por humanos (por ejemplo, 1K 234M 56G).
-

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

k, --kibibytes
Por defecto usa bloques de 1024 bytes para el uso del sistema de archivos; solo se usa con -s y totales por directorio
--si
Imprime tamaños de archivo legibles por humanos usando potencias de 1000 en lugar de 1024.
--block-size=<TAMAÑO_BLOQUE>
Escala los tamaños por TAMAÑO_BLOQUE al imprimirlos
-i, --inode
Imprime el número de índice de cada archivo
-r, --reverse
Invierte cualquier método de ordenación e.g., lista los archivos en orden alfabético inverso, el más reciente primero, el más pequeño primero, o lo que sea.
-R, --recursive
Lista el contenido de todos los directorios de forma recursiva.
-w, --width <COLS>
Asume que la terminal tiene COLS columnas de ancho.
-s, --size
Imprime el tamaño asignado de cada archivo, en bloques
--color
Colorea la salida según el tipo de archivo.

[posibles valores: always, auto, never]

--indicator-style
Añade un indicador con el estilo PALABRA a los nombres de entrada: none (por defecto), slash (-p), file-type (--file-type), classify (-F)

[posibles valores: none, slash, file-type, classify]

-F, --classify[=<cuando>]
Añade un carácter a cada nombre de archivo indicando el tipo de archivo. Además, para archivos regulares que son ejecutables, añade '*'. Los indicadores de tipo de archivo son '/' para directorios, '@' para enlaces simbólicos, '|' para FIFOs, '=' para sockets, '>' para doors, y nada para archivos regulares. cuando puede ser omitido, o uno de:
none - No clasificar. Este es el valor por defecto.
auto - Clasificar solo si la salida estándar es una terminal.
always - Clasificar siempre. Especificar --classify sin cuando es equivalente a --classify=always. Esto no seguirá los enlaces simbólicos listados en la línea de comandos a menos que se especifiquen las opciones --dereference-command-line (-H), --dereference (-L), o --dereference-command-line-symlink-to-dir.

[posibles valores: always, auto, never]

--file-type
Igual que --classify, pero no añade '*'
-p
Añade el indicador / a los directorios.
--time-style <ESTILO_TIEMPO>
formato de tiempo/fecha con -l; ver TIME_STYLE abajo
También se puede especificar con la variable de entorno TIME_STYLE.
--full-time
como -l --time-style=full-iso
-Z, --context
Imprime cualquier contexto de seguridad de cada archivo
--group-directories-first
Agrupa directorios antes que archivos; puede ser aumentado con una opción --sort, pero cualquier uso de --sort=none (-U) deshabilita la agrupación
-V, --version
Imprime la versión
[rutas]

EXTRA

El argumento TIME_STYLE puede ser full-iso, long-iso, iso, locale o +FORMAT. FORMAT se interpreta como en date. La variable de entorno TIME_STYLE también establece el estilo por defecto a usar.
