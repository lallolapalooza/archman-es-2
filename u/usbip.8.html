USBIP(8) Utilidades de Administración del Sistema USBIP(8)

NOMBRE

usbip - gestiona dispositivos USB/IP

SINOPSIS

usbip [opciones] <comando> <argumentos>

DESCRIPCIÓN

En un servidor USB/IP, los dispositivos pueden ser listados, enlazados y desenlazados usando este programa. En un cliente USB/IP, los dispositivos exportados por servidores USB/IP pueden ser listados, adjuntados y desadjuntados.

OPCIONES

--debug

Imprime información de depuración.

--log

Registra en syslog.

--tcp-port PORT

Conecta al puerto PORT en el host remoto (usado para attach y list --remote).

COMANDOS

version

Muestra la versión y sale.

help [comando]

Imprime el mensaje de ayuda del programa, o la ayuda para un comando específico, y luego sale.

attach --remote=<host> --busid=<id_bus>

Adjunta un dispositivo USB remoto.

attach --remote=<host> --device=<id_dispositivo>

Adjunta un gadget USB remoto. Solo se usa cuando el usbipd remoto está en modo dispositivo.

detach --port=<puerto>

Desadjunta un dispositivo/gadget USB importado.

bind --busid=<id_bus>

Hace que un dispositivo sea exportable.

unbind --busid=<id_bus>

Deja de exportar un dispositivo para que pueda ser usado por un controlador local.

list --remote=<host>

Lista los dispositivos USB exportados por un host remoto.

list --device

Lista los gadgets USB del usbip-vudc local. Solo se usa cuando el usbipd local está en modo dispositivo. Ten en cuenta que esto no puede listar los gadgets USB usbip-vudc del usbipd remoto en modo dispositivo.

list --local

Lista los dispositivos USB locales.

port

Lista los dispositivos/gadgets importados.

EJEMPLOS


cliente:# usbip list --remote=servidor
- Lista los dispositivos exportados por el servidor remoto.


cliente:# modprobe vhci-hcd


cliente:# usbip attach --remote=servidor --busid=1-2
- Conecta el dispositivo USB remoto.


cliente:# usbip port
- Lista los dispositivos/gadgets importados.


cliente:# usbip detach --port=0
- Desconecta el dispositivo USB.

El siguiente ejemplo muestra el uso del modo dispositivo


servidor:# usbip list --device
- Lista los gadgets exportados por el servidor usbipd local.


cliente:# modprobe vhci-hcd


cliente:# usbip attach --remote=servidor --device=usbip-vudc.0
- Conecta el gadget USB remoto.


cliente:# usbip port
- Lista los dispositivos/gadgets importados.


cliente:# usbip detach --port=0
- Desconecta el gadget USB.
