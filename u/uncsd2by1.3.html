CUNCSD2BY1

Propósito:

!>
!> CUNCSD2BY1 calcula la descomposición CS de una matriz M por Q, X, con
!> columnas ortonormales que ha sido particionada en una estructura de 2 bloques
!> por 1:
!>
!>                                [  I1 0  0 ]
!>                                [  0  C  0 ]
!>          [ X11 ]   [ U1 |    ] [  0  0  0 ]
!>      X = [-----] = [---------] [----------] V1**T .
!>          [ X21 ]   [    | U2 ] [  0  0  0 ]
!>                                [  0  S  0 ]
!>                                [  0  0  I2]
!>
!> X11 es P por Q. Las matrices unitarias U1, U2 y V1 son P por P,
!> (M-P) por (M-P) y Q por Q, respectivamente. C y S son matrices diagonales
!> no negativas R por R que satisfacen C^2 + S^2 = I, donde
!> R = MIN(P,M-P,Q,M-Q). I1 es una matriz identidad K1 por K1 e I2 es una
!> matriz identidad K2 por K2, donde K1 = MAX(Q+P-M,0), K2 = MAX(Q-P,0).
!>
!>

Parámetros

JOBU1 
!>          JOBU1 es CHARACTER
!>          = 'Y':      Se calcula U1;
!>          de lo contrario:  No se calcula U1.
!>

JOBU2

!>          JOBU2 es CHARACTER
!>          = 'Y':      Se calcula U2;
!>          de lo contrario:  No se calcula U2.
!>

JOBV1T

!>          JOBV1T es CHARACTER
!>          = 'Y':      Se calcula V1T;
!>          de lo contrario:  No se calcula V1T.
!>

M

!>          M es INTEGER
!>          El número de filas en X.
!>

P

!>          P es INTEGER
!>          El número de filas en X11. 0 <= P <= M.
!>

Q

!>          Q es INTEGER
!>          El número de columnas en X11 y X21. 0 <= Q <= M.
!>

X11

!>          X11 es un array COMPLEX, de dimensión (LDX11,Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se desea.
!>

LDX11

!>          LDX11 es INTEGER
!>          La dimensión principal de X11. LDX11 >= MAX(1,P).
!>

X21

!>          X21 es un array COMPLEX, de dimensión (LDX21,Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se desea.
!>

LDX21

!>          LDX21 es INTEGER
!>          La dimensión principal de X21. LDX21 >= MAX(1,M-P).
!>

THETA

!>          THETA es un array REAL, de dimensión (R), donde R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) y
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 es un array COMPLEX, de dimensión (P)
!>          Si JOBU1 = 'Y', U1 contiene la matriz unitaria P por P, U1.
!>

LDU1

!>          LDU1 es INTEGER
!>          La dimensión principal de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 es un array COMPLEX, de dimensión (M-P)
!>          Si JOBU2 = 'Y', U2 contiene la matriz unitaria (M-P) por (M-P),
!>          U2.
!>

LDU2

!>          LDU2 es INTEGER
!>          La dimensión principal de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T es un array COMPLEX, de dimensión (Q)
!>          Si JOBV1T = 'Y', V1T contiene la matriz unitaria Q por Q,
!>          V1**T.
!>

LDV1T

!>          LDV1T es INTEGER
!>          La dimensión principal de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo de los arrays
!>          WORK y RWORK, devuelve este valor como la primera entrada de los
!>          arrays WORK y RWORK, respectivamente, y XERBLA no emite ningún
!>          mensaje de error relacionado con LWORK o LRWORK.
!>

RWORK

!>          RWORK es un array REAL, de dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>          Si INFO > 0 en la salida, RWORK(2:R) contiene los valores PHI(1),
!>          ..., PHI(R-1) que, junto con THETA(1), ..., THETA(R),
!>          definen la matriz en la forma bidiagonal por bloques intermedia
!>          que queda después de la no convergencia. INFO especifica el número
!>          de PHI no nulos.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>
!>          Si LRWORK=-1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo de los arrays
!>          WORK y RWORK, devuelve este valor como la primera entrada de los
!>          arrays WORK y RWORK, respectivamente, y XERBLA no emite ningún
!>          mensaje de error relacionado con LWORK o LRWORK.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (M-MIN(P,M-P,Q,M-Q))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          > 0:  CBBCSD no convergió. Consulte la descripción de WORK
!>                anterior para obtener detalles.
!>

Referencias:

NAME

dorcsd2by1, sorcsd2by1 - computes the CS decomposition of an M-by-Q matrix X that has been partitioned into a 2-by-1 block structure.

SYNOPSIS

subroutine dorcsd2by1 (character jobu1, character jobu2, character jobv1t, integer m, integer p, integer q, double precision, dimension(ldx11,*) x11, integer ldx11, double precision, dimension(ldx21,*) x21, integer ldx21, double precision, dimension(*) theta, double precision, dimension(ldu1,*) u1, integer ldu1, double precision, dimension(ldu2,*) u2, integer ldu2, double precision, dimension(ldv1t,*) v1t, integer ldv1t, double precision, dimension(*) work, integer lwork, integer, dimension(*) iwork, integer info)

DORCSD2BY1

Purpose:

!>
!> DORCSD2BY1 computes the CS decomposition of an M-by-Q matrix X with
!> orthonormal columns that has been partitioned into a 2-by-1 block
!> structure:
!>
!>                                [  I1 0  0 ]
!>                                [  0  C  0 ]
!>          [ X11 ]   [ U1 |    ] [  0  0  0 ]
!>      X = [-----] = [---------] [----------] V1**T .
!>          [ X21 ]   [    | U2 ] [  0  0  0 ]
!>                                [  0  S  0 ]
!>                                [  0  0  I2]
!>
!> X11 is P-by-Q. The orthogonal matrices U1, U2, and V1 are P-by-P,
!> (M-P)-by-(M-P), and Q-by-Q, respectively. C and S are R-by-R
!> nonnegative diagonal matrices satisfying C^2 + S^2 = I, in which
!> R = MIN(P,M-P,Q,M-Q). I1 is a K1-by-K1 identity matrix and I2 is a
!> K2-by-K2 identity matrix, where K1 = MAX(Q+P-M,0), K2 = MAX(Q-P,0).
!>

Parameters

JOBU1 
!>          JOBU1 is CHARACTER
!>          = 'Y':      U1 is computed;
!>          otherwise:  U1 is not computed.
!>

JOBU2

!>          JOBU2 is CHARACTER
!>          = 'Y':      U2 is computed;
!>          otherwise:  U2 is not computed.
!>

JOBV1T

!>          JOBV1T is CHARACTER
!>          = 'Y':      V1T is computed;
!>          otherwise:  V1T is not computed.
!>

M

!>          M is INTEGER
!>          The number of rows in X.
!>

P

!>          P is INTEGER
!>          The number of rows in X11. 0 <= P <= M.
!>

Q

!>          Q is INTEGER
!>          The number of columns in X11 and X21. 0 <= Q <= M.
!>

X11

!>          X11 is DOUBLE PRECISION array, dimension (LDX11,Q)
!>          On entry, part of the orthogonal matrix whose CSD is desired.
!>

LDX11

!>          LDX11 is INTEGER
!>          The leading dimension of X11. LDX11 >= MAX(1,P).
!>

X21

!>          X21 is DOUBLE PRECISION array, dimension (LDX21,Q)
!>          On entry, part of the orthogonal matrix whose CSD is desired.
!>

LDX21

!>          LDX21 is INTEGER
!>          The leading dimension of X21. LDX21 >= MAX(1,M-P).
!>

THETA

!>          THETA is DOUBLE PRECISION array, dimension (R), in which R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) and
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 is DOUBLE PRECISION array, dimension (P)
!>          If JOBU1 = 'Y', U1 contains the P-by-P orthogonal matrix U1.
!>

LDU1

!>          LDU1 is INTEGER
!>          The leading dimension of U1. If JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 is DOUBLE PRECISION array, dimension (M-P)
!>          If JOBU2 = 'Y', U2 contains the (M-P)-by-(M-P) orthogonal
!>          matrix U2.
!>

LDU2

!>          LDU2 is INTEGER
!>          The leading dimension of U2. If JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T is DOUBLE PRECISION array, dimension (Q)
!>          If JOBV1T = 'Y', V1T contains the Q-by-Q matrix orthogonal
!>          matrix V1**T.
!>

LDV1T

!>          LDV1T is INTEGER
!>          The leading dimension of V1T. If JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>          If INFO > 0 on exit, WORK(2:R) contains the values PHI(1),
!>          ..., PHI(R-1) that, together with THETA(1), ..., THETA(R),
!>          define the matrix in intermediate bidiagonal-block form
!>          remaining after nonconvergence. INFO specifies the number
!>          of nonzero PHI's.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the work array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (M-MIN(P,M-P,Q,M-Q))
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  DBBCSD did not converge. See the description of WORK
!>                above for details.
!>

References:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.

SBBCSD

Purpose:

!>
!> SBBCSD computes the CS decomposition of an M-by-Q matrix X with
!> orthonormal columns that has been partitioned into a 2-by-1 block
!> structure:
!>
!>                                [  I1 0  0 ]
!>                                [  0  C  0 ]
!>          [ X11 ]   [ U1 |    ] [  0  0  0 ]
!>      X = [-----] = [---------] [----------] V1**T .
!>          [ X21 ]   [    | U2 ] [  0  0  0 ]
!>                                [  0  S  0 ]
!>                                [  0  0  I2]
!>
!> X11 is P-by-Q. The orthogonal matrices U1, U2, and V1 are P-by-P,
!> (M-P)-by-(M-P), and Q-by-Q, respectively. C and S are R-by-R
!> nonnegative diagonal matrices satisfying C^2 + S^2 = I, in which
!> R = MIN(P,M-P,Q,M-Q). I1 is a K1-by-K1 identity matrix and I2 is a
!> K2-by-K2 identity matrix, where K1 = MAX(Q+P-M,0), K2 = MAX(Q-P,0).
!>

Parameters

JOBU1 
!>          JOBU1 is CHARACTER
!>          = 'Y':      U1 is computed;
!>          otherwise:  U1 is not computed.
!>

JOBU2

!>          JOBU2 is CHARACTER
!>          = 'Y':      U2 is computed;
!>          otherwise:  U2 is not computed.
!>

JOBV1T

!>          JOBV1T is CHARACTER
!>          = 'Y':      V1T is computed;
!>          otherwise:  V1T is not computed.
!>

M

!>          M is INTEGER
!>          The number of rows in X.
!>

P

!>          P is INTEGER
!>          The number of rows in X11. 0 <= P <= M.
!>

Q

!>          Q is INTEGER
!>          The number of columns in X11 and X21. 0 <= Q <= M.
!>

X11

!>          X11 is REAL array, dimension (LDX11,Q)
!>          On entry, part of the orthogonal matrix whose CS decomposition
!>          is desired.
!>

LDX11

!>          LDX11 is INTEGER
!>          The leading dimension of X11. LDX11 >= MAX(1,P).
!>

X21

!>          X21 is REAL array, dimension (LDX21,Q)
!>          On entry, part of the orthogonal matrix whose CS decomposition
!>          is desired.
!>

LDX21

!>          LDX21 is INTEGER
!>          The leading dimension of X21. LDX21 >= MAX(1,M-P).
!>

THETA

!>          THETA is REAL array, dimension (R), in which R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) and
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 is REAL array, dimension (P)
!>          If JOBU1 = 'Y', U1 contains the P-by-P orthogonal matrix U1.
!>

LDU1

!>          LDU1 is INTEGER
!>          The leading dimension of U1. If JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 is REAL array, dimension (M-P)
!>          If JOBU2 = 'Y', U2 contains the (M-P)-by-(M-P) orthogonal
!>          matrix U2.
!>

LDU2

!>          LDU2 is INTEGER
!>          The leading dimension of U2. If JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T is REAL array, dimension (Q)
!>          If JOBV1T = 'Y', V1T contains the Q-by-Q orthogonal matrix
!>          V1**T.
!>

LDV1T

!>          LDV1T is INTEGER
!>          The leading dimension of V1T. If JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>          If INFO > 0 on exit, WORK(2:R) contains the values PHI(1),
!>          ..., PHI(R-1) that, together with THETA(1), ..., THETA(R),
!>          define the matrix in intermediate bidiagonal-block form
!>          remaining after nonconvergence. INFO specifies the number
!>          of nonzero PHI's.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the work array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (M-MIN(P,M-P,Q,M-Q))
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  SBBCSD did not converge. See the description of WORK
!>                above for details.
!>
