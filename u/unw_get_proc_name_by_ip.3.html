NOMBRE

unw_get_proc_name_by_ip -- obtener nombre de procedimiento

SINOPSIS

#include <libunwind.h>

int unw_get_proc_name_by_ip(unw_addr_space_t as, unw_word_t ip, char *bufp, size_t len, unw_word_t *offp, void *arg);

DESCRIPCIÓN

La rutina unw_get_proc_name_by_ip() devuelve el nombre de un procedimiento al igual que unw_get_proc_name(), excepto que el nombre se busca por el puntero de instrucción (IP) en lugar de un cursor.

La rutina espera los siguientes argumentos: `as` es el espacio de direcciones en el que se buscará el puntero de instrucción. Para una búsqueda en el espacio de direcciones local, se puede pasar `unw_local_addr_space` para este argumento. El argumento `ip` es el puntero de instrucción para el cual se debe buscar el nombre del procedimiento. El argumento `bufp` es un puntero a un búfer de caracteres que tiene al menos `len` bytes de longitud. Este búfer se utiliza para devolver el nombre del procedimiento. El argumento `offp` es un puntero a una palabra que se utiliza para devolver el desplazamiento de bytes del puntero de instrucción en relación con el inicio del procedimiento. Por último, `arg` es el argumento del espacio de direcciones que debe utilizarse al acceder al espacio de direcciones. Tiene el mismo propósito que el argumento del mismo nombre para unw_init_remote(). Al acceder al espacio de direcciones local (el primer argumento es `unw_local_addr_space`), se debe pasar `NULL` para este argumento.

Tenga en cuenta que en algunas plataformas no existe una forma confiable de distinguir entre nombres de procedimientos y etiquetas ordinarias. Además, si la información de símbolos se ha eliminado de un programa, los nombres de los procedimientos pueden no estar disponibles o pueden limitarse a los que se exportan a través de una tabla de símbolos dinámica. En tales casos, unw_get_proc_name_by_ip() puede devolver el nombre de una etiqueta o de un procedimiento anterior (cercano). Sin embargo, el desplazamiento devuelto a través de `offp` siempre es relativo al nombre devuelto, lo que garantiza que el valor (dirección) del nombre devuelto más el desplazamiento devuelto siempre será igual al puntero de instrucción `ip`.

VALOR DE RETORNO

Al finalizar correctamente, unw_get_proc_name_by_ip() devuelve 0. En caso contrario, se devuelve el valor negativo de uno de los códigos de error siguientes.

SEGURIDAD DE HILOS Y SEÑALES

unw_get_proc_name_by_ip() es seguro para hilos. Si se pasa el espacio de direcciones local en el argumento `as`, esta rutina también es segura de usar desde un manejador de señales.

ERRORES

UNW_EUNSPEC

Ocurrió un error no especificado.
UNW_ENOINFO

Libunwind no pudo determinar el nombre del procedimiento.
UNW_ENOMEM

El nombre del procedimiento es demasiado largo para caber en el búfer proporcionado. Se ha devuelto una versión truncada del nombre.

Además, unw_get_proc_name_by_ip() puede devolver cualquier error devuelto por la devolución de llamada `access_mem()` (ver unw_create_addr_space(3libunwind)).
