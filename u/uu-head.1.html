uu-head(1) Manual de Comandos Generales uu-head(1)

NOMBRE

uu-head - Imprime las primeras 10 líneas de cada ARCHIVO a la salida estándar. Con más de un ARCHIVO, precede cada uno con una cabecera que da el nombre del archivo. Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar.

Los argumentos obligatorios para las opciones largas son también obligatorios para las opciones cortas.

SINOPSIS

uu-head [-c|--bytes] [-n|--lines] [-q|--quiet] [-v|--verbose] [-z|--zero-terminated] [-h|--help] [-V|--version] [ARCHIVO]

DESCRIPCIÓN

Imprime las primeras 10 líneas de cada ARCHIVO a la salida estándar. Con más de un ARCHIVO, precede cada uno con una cabecera que da el nombre del archivo. Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar.

Los argumentos obligatorios para las opciones largas son también obligatorios para las opciones cortas.

OPCIONES

-c, --bytes <[-]NUM>
imprime los primeros NUM bytes de cada archivo; con el '-', imprime todos excepto los últimos NUM bytes de cada archivo
-n, --lines <[-]NUM>
imprime las primeras NUM líneas en lugar de las primeras 10; con el '-', imprime todas excepto las últimas NUM líneas de cada archivo
-q, --quiet
nunca imprime cabeceras con nombres de archivo
-v, --verbose
siempre imprime cabeceras con nombres de archivo
-z, --zero-terminated
el delimitador de línea es NUL, no nueva línea
-h, --help
Imprime ayuda
-V, --version
Imprime la versión
[ARCHIVO]
