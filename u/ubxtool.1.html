UBXTOOL(1) GPSD Documentation UBXTOOL(1)

NOMBRE

ubxtool - herramienta u-blox

SINOPSIS

ubxtool [OPCIONES} [servidor[:puerto[:dispositivo]]]

ubxtool -h

ubxtool -V

DESCRIPCIÓN

ubxtool es una herramienta para GPS u-blox. Si no tienes un GPS u-blox, puedes dejar de leer ahora.

Esta herramienta opera con tu GPS u-blox a un nivel muy bajo. Para entender ubxtool, primero debes familiarizarte con tu GPS u-blox y la documentación del protocolo binario u-blox. El protocolo u-blox varía mucho dependiendo del modelo de GPS y la revisión del firmware. Usa la documentación de u-blox para tu modelo y firmware.

ubxtool puede decodificar mensajes binarios comunes de u-blox, consultar el estado del GPS, habilitar y deshabilitar funciones del GPS, y enviar comandos generados por el usuario al GPS. Puede leer mensajes binarios de un archivo. Puede leer y escribir directamente a través de un dispositivo serial, o a través de una instancia en ejecución de gpsd.

ubxtool no requiere privilegios de root, excepto quizás para acceder al puerto serial en modo de acceso directo (-f ARCHIVO). Se ejecutará bien como root. Ejecutar bajo sudo causará pérdida de funcionalidad.

OPCIONES

El programa acepta las siguientes opciones:

-?, -h, --help

Hace que ubxtool imprima un mensaje de uso y salga. Úsalo con -v 2 para ver todos los valores de habilitación/deshabilitación y preconfiguraciones. Úsalo con -v 3 para ver además todos los elementos de configuración (largos).

-c COMANDO, --command COMANDO

Envía un comando al GPS. Acepta un parámetro, COMANDO, una lista separada por comas de bytes hexadecimales que especifican la clase, el ID y cualquier carga útil necesaria. La cabecera, la longitud y la suma de verificación se agregan automáticamente.

--device DISPOSITIVO

El DISPOSITIVO en gpsd al que conectarse. Por defecto, todos.

-d OPCION, --disable OPCION

Deshabilita una opción en el GPS. Acepta un parámetro, OPCION, la opción a deshabilitar. Ejecuta "ubxtool -h -v 2" para ver todas las OPCIONES posibles. Algunas OPCIONES posibles son:

BEIDOU

Deshabilita el uso de la constelación BeiDou (COMPASS).

BINARY

Deshabilita el envío de los mensajes binarios básicos.

ECEF

Deshabilita el envío de mensajes binarios ECEF.

GALILEO

Deshabilita el uso de la constelación GALILEO.

GLONASS

Deshabilita el uso de la constelación GLONASS.

GPS

Deshabilita el uso de las constelaciones GPS y QZSS.

NED

Deshabilita el envío de mensajes NED. UBX-NAV-VELNED y UBX-NAV-RELPOSNED.

NMEA

Deshabilita el envío de mensajes NMEA básicos. Los mensajes son GBS, GGA, GSA, GGL, GST, GSV, RMC, VTG y ZDA.

PPS

Deshabilita TIMEPULSE 0.

RAWX

Deshabilita el envío de los mensajes UBX-RXM-RAWX.

SBAS

Deshabilita el uso de la constelación SBAS.

SFRBX

Deshabilita el uso de los mensajes SFRBX.

SURVEYIN

Deshabilita el modo survey-in con TMODE2.

TP

Deshabilita el envío de UBX-TIM-TP.

-e OPCION, --enable OPCION

Habilita una opción en el GPS. Acepta un parámetro, OPCION, la opción a habilitar. -e acepta las mismas OPCIONES que -d, excepto que la acción es habilitar la opción.

-f ARCHIVO, --file ARCHIVO

Conéctate directamente a un archivo o dispositivo. Acepta un parámetro, ARCHIVO, el archivo o dispositivo a abrir. Los archivos se abren en modo de solo lectura. Los dispositivos de caracteres se abren en lectura/escritura, a menos que se proporcione el parámetro -r. Requiere el módulo pyserial.

-g ITEM,CAPA,POSICION,FIN, --getitem ITEM,CAPA,POSICION,FIN

Obtiene el valor de ITEM de CAPA, comenzando en POSICION, hasta FIN pares clave/valor (UBX-CFG-VALGET). Todos los parámetros después de ITEM son opcionales y decimales. Si CAPA está ausente, entonces se solicitan las capas 0, 1, 2 y 7. Ver la sección de ELEMENTOS DE CONFIGURACIÓN.

--host HOST

Conéctate al gpsd en HOST (servidor). Por defecto localhost.

-i puerto, --portid puerto

Especifica el ID de puerto # (interfaz) para comandos relacionados con puertos como UBX_CFG-PRT.

-p PRECONFIGURACION, --preset PRECONFIGURACION

Envía un comando preconfigurado al GPS. Generalmente acepta un parámetro, PRECONFIGURACION, el nombre del comando a enviar. Algunas PRECONFIGURACIONES, como LOG-FINDTIME, aceptan parámetros adicionales separados por comas. Se pueden usar más de un -p.

Solo se muestran aquí las PRECONFIGURACIONES comunes. Para ver la lista completa, incluyendo parámetros opcionales, ejecuta "ubxtool -h -v 2".

COLDBOOT

Reinicio en frío del GPS (UBX-CFG-RST).

HOTBOOT

Reinicio en caliente del GPS (UBX-CFG-RST).

MODEL,modelo

Configura el Modelo de Plataforma Dinámica a modelo. (UBX-CFG-NAV5). modelo es el número decimal del modo deseado.

PMS

Establece la configuración de gestión de energía (UBX-CFG-PMS). "PMS,pow" donde pow es el valor de configuración de energía.

RATE

Establece la tasa de medición y navegación (UBX-CFG-RATE). "RATE,medir,nav" medir es el measRate en milisegundos. El argumento nav es el navRate en ciclos y por defecto es 1.

RESET

Restablece la configuración a los valores por defecto (UBX-CFG-CFG).

SAVE

Guarda la configuración actual (UBX-CFG-CFG).

MON-RESETODO

Restablece el odómetro (UBX-MON-RESETODO).

MON-VER

Consulta la versión del GPS (UBX-MON-VER).

WARMBOOT

Reinicio templado del GPS (UBX-CFG-RST).

La mayoría de los parámetros PRESET son comandos de consulta simples. Simplemente consultan al GPS para que responda con el mensaje asociado. Por ejemplo, "ubxtool -p CFG-GNSS" pide al GPS que responda con un mensaje UBX-CFG-GNSS que describe la configuración GNSS actual. Aumenta la verbosidad de la salida agregando las opciones "-v 2" o "-v 3".

--port PUERTO

Usa PUERTO para conectarte a gpsd. Por defecto 2947.

-P protver, --protver protver

Establece la versión del protocolo a usar para enviar comandos. Mínimo 6 (Antaris 4). Usa "ubxtool -p MON-VER" para ver la versión que tu receptor soporta. Muchos receptores u-blox más nuevos fallarán silenciosamente o de forma extraña si esto no se establece correctamente. Por defecto 10 (u-blox 5).

-r, -readonly

Solo lectura. No envíes nada al GPS.

-R RAW, --rawfile RAW

Guarda todos los datos seriales brutos recibidos del GPS en el archivo RAW.

-s VELOCIDAD, --inspeed VELOCIDAD

Establece la velocidad del puerto serial local a VELOCIDAD bps. Por defecto 9,600 bps.

-S VELOCIDAD, --setspeed VELOCIDAD

Establece la velocidad del puerto serial del GPS a VELOCIDAD bps.

-t, --timestamp

Marca los mensajes decodificados con segundos desde la época. Úsalo dos veces y obtén también la hora UTC.

-v VERBOSIDAD, --verbosity VERBOSIDAD

Establece el nivel de verbosidad a VERBOSIDAD. La verbosidad puede ser de 0 (muy silencioso), 2 (decodificar mensajes), a 4 (muy ruidoso). Por defecto 1.

-V, --version

Imprime la versión de ubxtool y sale.

-w ESPERA, --wait ESPERA

Espera ESPERA segundos antes de salir. Usa 0 para esperar para siempre. Por defecto 2 segundos.

-x ITEM,CAPAS, --delitem ITEM,CAPAS

Elimina el valor del nombre ITEM de CAPAS. El mapa de bits CAPAS es opcional. Por defecto, elimina tanto en las capas BBR como FLASH en el receptor (UBX_CFG-VALDEL). Regresa al valor por defecto del receptor para ese elemento. Ver la sección de ELEMENTOS DE CONFIGURACIÓN.

-z ITEM,VAL,CAPAS, --setitem ITEM,VAL,CAPAS

Establece el valor del nombre ITEM a VAL en CAPAS en el GPS (UBX-CFG-VALSET). VAL y la máscara de bits CAPAS son decimales. ",CAPAS" es opcional. Las CAPAS por defecto son RAM y FLASH. Ver la sección de ELEMENTOS DE CONFIGURACIÓN.

ARGUMENTOS

Por defecto, los clientes recopilan datos del demonio gpsd local que se ejecuta en localhost, utilizando el puerto GPSD por defecto 2947. El argumento opcional de cualquier cliente puede anular este comportamiento: [servidor[:puerto[:dispositivo]]]

Para más explicaciones y ejemplos, consulta la sección ARGUMENTOS de la página del manual gps(1).

ITEMS DE CONFIGURACIÓN

Configurar GPS u-blox con los mensajes de configuración tradicionales está lleno de problemas. Muchos mensajes de configuración interactúan de formas extrañas. Algo tan simple como cambiar la velocidad del puerto serie requiere que leas la configuración actual usando UBX-CFG-PRT para el puerto adecuado, combines el cambio y luego escribas de nuevo el mensaje UBX-CFG-PRT modificado. O simplemente adivines la configuración actual y la sobrescribas toda.

La serie u-blox 9, versión de protocolo 27+, intenta, pero no lo consigue por completo, resolver el problema con los Items de Configuración. Si tu GPS no soporta la versión de protocolo 27+, entonces esta sección no te aplica.

A la mayoría de las variables de configuración del GPS se les ha asignado un ID de Clave de 32 bits. Cada Clave hace referencia a un valor específico. Un receptor típico puede tener más de 1.100 IDs de Clave. A cada ID de Clave se le ha asignado un Nombre de Clave. La mayoría de los Nombres de Clave están documentados por u-blox y soportados por ubxtool. Para ver todos los Nombres de Clave entendidos por ubxtool, ejecuta: "ubxtool -h -v 3".

Para obtener el valor relacionado con un item, usa "-g ITEM".

Para restablecer el valor relacionado con un item a su valor por defecto, usa "-x ITEM".

Para establecer un nombre de ITEM a un valor, usa "-z ITEM,VAL".

Si solo quieres establecer un ITEM en una capa, usa "-z ITEM,VAL,CAPA".

Consulta la sección EJEMPLOS para ver ejemplos concretos.

EJEMPLOS

Todos los ejemplos asumen que UBXOPTS está configurado con la versión de protocolo de tu receptor. Asegúrate de reemplazar "-P 18" con tu versión de prototipo correcta.

export UBXOPTS="-P 18"

Volcar la configuración y el estado del receptor GNSS. El "-w 4" es para dar tiempo extra para que las operaciones se completen.

ubxtool -p CONFIG -p STATUS -w 4 -v 2

Decodificar archivo de registro sin procesar:

ubxtool -r -f ublox-neo-m8n.log

Cambiar la velocidad del puerto GPS del dispositivo en /dev/ttyAMA0 a 230.400 bps:

ubxtool -S 230400 -f /dev/ttyAMA0

Observar todo el ciclo de reinicio del GPS, incluyendo mensajes $GPTXT:

ubxtool -p COLDBOOT -w 20 -v 2

Consultar Constelaciones Habilitadas:

ubxtool -p CFG-GNSS

Volcar datos de gpsd desde un servidor remoto llamado x.example.com:

ubxtool -w 5 x.example.com

CFG-TP5

Algunos de los comandos "-p" y "--preset" pueden aceptar múltiples opciones. Una de ellas es "--preset CFG-TP5".

Sinopsis:

-p CFG-TP5,[tpIdx = 0],[antCableDelay = 2],[rfGroupDelay = 0],[freqPeriod = 1000000],[freqPeriodLock = 1000000],[pulseLenRatio = 0],[pulseLenRatioLock = 100000],[userConfigDelay = 0],[flags = 0x77]

Deja un parámetro posicional vacío para que tome el valor por defecto.

Para establecer el período de pulso a 0.25 s y su duración a 0.1 s:

$ ubxtool -p CFG-TP5,,,,250000,250000,100000,100000

Para establecer el período de pulso a 0.1 s y la duración a 0.1 s en presencia de bloqueo:

$ ubxtool -p CFG-TP5,,,,,100000,,50000

Ejemplos Versión 27+

Los siguientes ejemplos requieren un GPS que soporte el protocolo 27 o superior. Asegúrate de configurar primero tu versión de protocolo:

    export UBXOPTS="-P 32"

Para comprobar el modelo dinámico actual, cambiarlo a 6 (AIR1, Aerotransportado con aceleración <1g), revertir a la configuración predeterminada y verificar que las fallas se restauraron.

$ ubxtool -g CFG-NAVSPG-DYNMODEL
[...]
UBX-CFG-VALGET:
 version 1 layer 0 reserved 0,0
  layers (ram)
    item CFG-NAVSPG-DYNMODEL/0x20110021 val 2
[...]
$ ubxtool -z CFG-NAVSPG-DYNMODEL,6
[...]
UBX-ACK-ACK:
 ACK to Class x6 (CFG) ID x8a (VALSET)
[...]
$ ubxtool -g CFG-NAVSPG-DYNMODEL
[...]
UBX-CFG-VALGET:
 version 1 layer 0 reserved 0,0
  layers (ram)
    item CFG-NAVSPG-DYNMODEL/0x20110021 val 6
[...]
$ ubxtool -x CFG-NAVSPG-DYNMODEL
[...]
UBX-ACK-ACK:
 ACK to Class x6 (CFG) ID x8c (VALDEL)
[...]
$ ubxtool -g CFG-NAVSPG-DYNMODEL
[...]
UBX-CFG-VALGET:
 version 1 layer 0 reserved 0,0
  layers (ram)
    item CFG-NAVSPG-DYNMODEL/0x20110021 val 6

Observe que el DYNMODEL actual se mantuvo en 6 (AIR1). El "-x" solo afecta a la configuración guardada, no a la configuración actual. Para cambiar la configuración actual, debes establecerla con "-z".

Obtener todos los Items de Configuración en un grupo uno por uno podría ser muy tedioso. VAL-GET te permite usar comodines en el número de item y volcar todos los items de un grupo. Para obtener todos los items CFG-TP en ram, los actualmente activos, puedes hacer esto:

$ ubxtool -g CFG-TP,0
[...]
UBX-CFG-VALGET:
 version 1 layer 0 position 0
  layers (ram)
    item CFG-TP-TP1_ENA/0x10050007 val 1
    item CFG-TP-SYNC_GNSS_TP1/0x10050008 val 1
    item CFG-TP-USE_LOCKED_TP1/0x10050009 val 1
[...]

Los verdaderamente masoquistas pueden volcar todos los Items de Configuración usando comodines en el grupo. Volcar los más de 1.000, 64 a la vez, aún podría ser tedioso. El parámetro -g opcionalmente te permite especificar la posición inicial desde la cual obtener, así como la posición final. Para obtener todos los items conocidos y desconocidos soportados por el receptor que están actualmente en ram:

$ ubxtool -g CFG,0,0,1200 | fgrep "item CFG-"
    item CFG-1-1/0x10010001 val 0
    item CFG-1-1/0x10010101 val 0
    item CFG-4-1/0x10040001 val 1
    item CFG-4-2/0x10040002 val 0
    item CFG-4-3/0x10040003 val 0
    item CFG-4-4/0x10040004 val 0
    item CFG-4-9/0x10040009 val 0
    item CFG-TP-TP1_ENA/0x10050007 val 1
    item CFG-TP-SYNC_GNSS_TP1/0x10050008 val 1
[...]

Cambiar CFG,0,0,1200 a CFG,7,0,1200 en su lugar volcaría todos los valores predeterminados de configuración, desde la capa Predeterminada (7).

ENTORNO

Las opciones se pueden colocar en la variable de entorno UBXOPTS. UBXOPTS se procesa antes que las opciones de la línea de comandos.

VALORES DE RETORNO

0

en caso de éxito.

1

en caso de fallo.
