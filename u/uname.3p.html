UNAME(3P) Manual del programador de POSIX UNAME(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

uname — obtener el nombre del sistema actual

SINOPSIS

#include <sys/utsname.h>
int uname(struct utsname *name);

DESCRIPCIÓN

La función uname() almacenará información que identifica el sistema actual en la estructura apuntada por name.

La función uname() utiliza la estructura utsname definida en <sys/utsname.h>.

La función uname() devolverá una cadena que nombra el sistema actual en el array de caracteres sysname. De manera similar, nodename contendrá el nombre de este nodo dentro de una red de comunicaciones definida por la implementación. Los arrays release y version identificarán además el sistema operativo. El array machine contendrá un nombre que identifique el hardware en el que se está ejecutando el sistema.

El formato de cada miembro está definido por la implementación.

VALOR DE RETORNO

Al completarse con éxito, se devolverá un valor no negativo. En caso contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE APLICACIONES

La inclusión del miembro nodename en esta estructura no implica que sea información suficiente para la interfaz con redes de comunicaciones.

RACIONAMIENTO

Los valores de los miembros de la estructura no están limitados a tener relación alguna con la versión de este volumen de POSIX.1‐2017 implementada en el sistema operativo. Una aplicación debería depender en su lugar de _POSIX_VERSION y de las constantes relacionadas definidas en <unistd.h>.

Este volumen de POSIX.1‐2017 no define los tamaños de los miembros de la estructura y permite que sean de diferentes tamaños, aunque la mayoría de las implementaciones los definen todos del mismo tamaño: ocho bytes más un byte para el terminador de cadena. Ese tamaño para nodename no es suficiente para su uso con muchas redes.

La función uname() se originó en System III, System V y implementaciones relacionadas, y no existe en Version 7 o 4.3 BSD. Los valores que devuelve se establecen en el momento de la compilación del sistema en esas implementaciones históricas.

4.3 BSD tiene gethostname() y gethostid(), que devuelven un nombre simbólico y un valor numérico, respectivamente. Existen funciones relacionadas sethostname() y sethostid() que se utilizan para establecer los valores que devuelven las otras dos funciones. Las primeras funciones se incluyen en esta especificación, las últimas no.
