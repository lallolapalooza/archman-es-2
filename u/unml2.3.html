subrutina cunml2 (carácter side, carácter trans, entero m, entero n, entero k, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( * ) tau, complejo, dimensión( ldc, * ) c, entero ldc, complejo, dimensión( * ) work, entero info)

CUNML2 multiplica una matriz general compleja m por n por la matriz unitaria de una factorización LQ determinada por cgelqf (algoritmo no bloqueado).

Propósito:

!>
!> CUNML2 sobrescribe la matriz compleja general m por n C con
!>
!>       Q * C  si SIDE = 'L' y TRANS = 'N', o
!>
!>       Q**H* C  si SIDE = 'L' y TRANS = 'C', o
!>
!>       C * Q  si SIDE = 'R' y TRANS = 'N', o
!>
!>       C * Q**H si SIDE = 'R' y TRANS = 'C',
!>
!> donde Q es una matriz unitaria compleja definida como el producto de k
!> 
!>       Q = H(k)**H . . . H(2)**H H(1)**H
!>
!> reflectores elementales, tal como es devuelta por CGELQF. Q es de orden m
!> si SIDE = 'L' y de orden n si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda
!>          = 'R': aplicar Q o Q**H desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar Q  (Sin transpuesta)
!>          = 'C': aplicar Q**H (Transpuesta conjugada)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A es un array COMPLEX, dimensión
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ésima fila debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como es
!>          devuelto por CGELQF en las primeras k filas de su argumento de
!>          array A.
!>          A se modifica por la rutina pero se restaura al salir.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,K).
!>

TAU

!>          TAU es un array COMPLEX, dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como es devuelto por CGELQF.
!>

C

!>          C es un array COMPLEX, dimensión (LDC,N)
!>          En la entrada, la matriz C de m por n.
!>          En la salida, C se sobrescribe con Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX, dimensión
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detailed Description


The routines compute, with a given vector u and a scalar
    a, the triangular factor of a block reflector, and then use it to
    update a rectangular matrix. The
    DORML2 and SORML2 routines are complex
    versions of SORM22 and DORM22 respectively.


The arguments are described below:




subroutine   dorml2 (character side, character trans, integer m, integer n, integer k,   double precision, dimension( lda, * ) a, integer lda, double precision,   dimension( * ) tau, double precision, dimension( ldc, * ) c, integer ldc,   double precision, dimension( * ) work, integer info)


DORML2 multiplies a general matrix by the orthogonal matrix
    from a LQ factorization determined by dgelqf (unblocked algorithm).


Purpose:




!>
!> DORML2 overwrites the general real m by n matrix C with
!>
!>       Q * C  if SIDE = 'L' and TRANS = 'N', or
!>
!>       Q**T* C  if SIDE = 'L' and TRANS = 'T', or
!>
!>       C * Q  if SIDE = 'R' and TRANS = 'N', or
!>
!>       C * Q**T if SIDE = 'R' and TRANS = 'T',
!>
!> where Q is a real orthogonal matrix defined as the product of k
!> elementary reflectors
!>
!>       Q = H(k) . . . H(2) H(1)
!>
!> as returned by DGELQF. Q is of order m if SIDE = 'L' and of order n
!> if SIDE = 'R'.
!> 




Parameters


SIDE

!>          SIDE is CHARACTER*1
!>          = 'L': apply Q or Q**T from the Left
!>          = 'R': apply Q or Q**T from the Right
!> 


TRANS


!>          TRANS is CHARACTER*1
!>          = 'N': apply Q  (No transpose)
!>          = 'T': apply Q**T (Transpose)
!> 


M


!>          M is INTEGER
!>          The number of rows of the matrix C. M >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns of the matrix C. N >= 0.
!> 


K


!>          K is INTEGER
!>          The number of elementary reflectors whose product defines
!>          the matrix Q.
!>          If SIDE = 'L', M >= K >= 0;
!>          if SIDE = 'R', N >= K >= 0.
!> 


A


!>          A is DOUBLE PRECISION array, dimension
!>                               (LDA,M) if SIDE = 'L',
!>                               (LDA,N) if SIDE = 'R'
!>          The i-th row must contain the vector which defines the
!>          elementary reflector H(i), for i = 1,2,...,k, as returned by
!>          DGELQF in the first k rows of its array argument A.
!>          A is modified by the routine but restored on exit.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,K).
!> 


TAU


!>          TAU is DOUBLE PRECISION array, dimension (K)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by DGELQF.
!> 


C


!>          C is DOUBLE PRECISION array, dimension (LDC,N)
!>          On entry, the m by n matrix C.
!>          On exit, C is overwritten by Q*C or Q**T*C or C*Q**T or C*Q.
!> 


LDC


!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!> 


WORK


!>          WORK is DOUBLE PRECISION array, dimension
!>                                   (N) if SIDE = 'L',
!>                                   (M) if SIDE = 'R'
!> 


INFO


!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>
