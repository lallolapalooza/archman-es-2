USDCHECKER(1) Comandos de Usuario USDCHECKER(1)

NOMBRE

usdchecker - página del manual para usdchecker 25.11

SINOPSIS

usdchecker [OPCIONES] [archivoEntrada]

DESCRIPCIÓN

Utilidad para comprobar el cumplimiento de un escenario USD dado o un paquete USDZ. Actualmente, solo se comprueba la primera muestra de cualquier atributo relevante muestreado en el tiempo. Siempre se realizan comprobaciones generales de USD, y comprobaciones más restrictivas dirigidas al contenido distribuible para el consumidor también se aplican cuando se especifica la opción "--arkit". Para utilizar el antiguo verificador de cumplimiento (obsoleto), proporcione la opción '--useOldComplianceCheckerInterface'.

Posicionales:

archivoEntrada ARCHIVO
Nombre del archivo de entrada a inspeccionar.

OPCIONES

-h,--ayuda
Imprimir este mensaje de ayuda y salir
-s,--saltarVariantes
Si se especifica, solo se comprueban los prims que están presentes en las variantes predeterminadas (es decir, seleccionadas). Cuando esta opción no se especifica, se comprueban los prims en todas las combinaciones posibles de selecciones de variantes.
-p,--soloPaqueteRaíz
Comprobar solo el paquete especificado. Los paquetes anidados, las dependencias y sus contenidos no se validan.
-o,--salida ARCHIVO
El archivo al que se enviarán todas las comprobaciones fallidas. Si no se especifica, las comprobaciones fallidas se enviarán a stdout; si es "stderr", se suprimirá el coloreado de la terminal.
--noAssetChecks
Si se especifica, NO se realizarán comprobaciones adicionales para ayudar a garantizar que el escenario o paquete pueda referenciarse fácilmente y de forma segura en escenarios agregados.
--arkit
Comprobar si el escenario USD dado es compatible con la implementación de USDZ de RealityKit a partir de 2023. Estos activos operan bajo mayores restricciones que los archivos usdz para usos internos más generales, y esta opción intenta garantizar que se cumplen estas restricciones.
-d,--mostrarReglas
Mostrar el conjunto de reglas enumeradas que se están comprobando para el conjunto de opciones dado.
-v,--detallado
Activar el modo de salida detallado.
-t,--estricto
Devolver un código de fallo incluso si solo se emiten advertencias, para un cumplimiento más estricto.
--useOldComplianceCheckerInterface
Usar la interfaz antigua y ahora obsoleta del Verificador de Cumplimiento.
--variantSets TEXT ...
Lista de conjuntos de variantes a validar. Se validan todas las variantes de los conjuntos de variantes dados. Esto también se puede usar con --variants para validar las variantes dadas en combinación con las variantes de los conjuntos de variantes especificados explícitamente. Esta opción solo es válida cuando se utiliza el nuevo marco de validación.
--variants TEXT ...
Lista de pares variantSet:variant separados por comas a validar. Cada conjunto de variantes en la lista se valida por separado. Ejemplo: --variants foo:bar,baz:qux validará foo:bar y baz:qux juntas, pero --variants foo:bar --variants baz:qux validará foo:bar y baz:qux por separado. Esto también se puede usar con --variantSets para validar las variantes dadas en combinación con las variantes de los conjuntos de variantes especificados explícitamente. Esta opción solo es válida cuando se utiliza el nuevo marco de validación.
--disableVariantValidationLimit
Desactivar el límite establecido para restringir el número de llamadas de validación de variantes. Esto es útil cuando el número de variantes es grande y queremos validar todas las combinaciones posibles de variantes. Por defecto, el número de llamadas de validación se limita a 1000. Esta opción solo es válida cuando se utiliza el nuevo marco de validación.
