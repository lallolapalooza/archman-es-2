UMAD_SEND(3) Manual del programador de OpenIB UMAD_SEND(3)

NOMBRE

umad_send - enviar umad

SINOPSIS

#include <infiniband/umad.h>

int umad_send(int portid, int agentid, void *umad, int length, int timeout_ms, int retries);

DESCRIPCIÓN

umad_send() envía length bytes desde el búfer umad especificado desde el puerto especificado por portid, y utilizando el agente especificado por agentid.

El búfer puede contener una transmisión RMPP que es más grande que un único paquete MAD cuando el agentid especifica una clase que utiliza RMPP y las banderas de cabecera indican que RMPP está activo. NOTA: actualmente solo RMPPFlags.Active tiene significado en la cabecera en el espacio de usuario. Todos los demás campos RMPP se ignoran. La sección de datos del búfer se enviará en múltiples paquetes MAD RMPP con cabeceras construidas para el usuario.

timeout_ms controla el comportamiento de los MAD solicitados de la siguiente manera: un valor cero significa no solicitado. Un valor positivo hace que el kernel indique el tiempo de espera en milisegundos. Si no se recibe respuesta dentro del valor especificado, el búfer original se devuelve en el canal de lectura con el campo de estado establecido (a un valor distinto de cero). Un timeout_ms negativo hace que el kernel espere indefinidamente la respuesta. retries indica el número de veces que se intentará reenviar el MAD antes de rendirse.

VALOR DE RETORNO

umad_send() devuelve 0 si tiene éxito; en caso de error, errno se establece y se devuelve un valor negativo como sigue:
-EINVAL manejador de puerto o agentid inválido
-EIO operación de envío fallida
