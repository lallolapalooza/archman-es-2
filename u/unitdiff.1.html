unitdiff(1) Visor de diferencias de unidades FPC unitdiff(1)

NOMBRE

unitdiff - Describe las diferencias en la interfaz de una unidad FPC.

SINOPSIS

unitdiff [ --disable-arguments] [ --disable-private] [ --disable-protected] [ --help] [ --lang=language] [ --list] [ --output=filename] [ --sparse] archivo1 archivo2

Descripción

unitdiff escanea uno o dos archivos fuente de unidades de Free Pascal y o bien lista todos los identificadores disponibles, o describe las diferencias en los identificadores entre las dos unidades.

Uso

Puedes invocar unitdiff con un único argumento obligatorio, el nombre de archivo de entrada. En ese caso, simplemente listará todos los identificadores disponibles.

El uso regular es invocar unitdiff con los argumentos entrada1 entrada2. Mostrará la diferencia en la interfaz entre las dos unidades, o listará los identificadores disponibles en ambas unidades. La salida de unitdiff irá a la salida estándar por defecto.

Opciones

unitdiff tiene algunas opciones, la mayoría opcionales, se usarán valores por defecto en la mayoría de los casos.

--disable-arguments
Si se especifica esta opción, unitdiff no comprobará los argumentos de funciones y procedimientos. Por defecto, estos también se comprueban.
--disable-private
Por defecto, se comprueban los métodos privados de las clases. Si se especifica esta opción, no se comprueban los campos o métodos privados.
--disable-protected
Por defecto, se comprueban los métodos protegidos de las clases. Si se especifica esta opción, no se comprueban los campos o métodos protegidos ni privados.
--help
Emite un texto de ayuda corto y sale.
--lang=language
Establece el idioma para el archivo de salida. Esto principalmente establecerá las cadenas utilizadas para las cabeceras en varias partes de los archivos de documentación (por defecto están en inglés). Actualmente, las opciones válidas son
de
Alemán.
fr
Francés.
nl
Holandés.
--list
Si se especifica esta opción, solo se especificará la lista de identificadores disponibles para la unidad o unidades. Si solo se especifica 1 unidad, esta opción se asume automáticamente.
--output=filename
Esta opción indica a unitdiff dónde debe ir la salida. Si esta opción no se especifica, la salida se envía a la salida estándar (la pantalla).
--sparse
Activa el modo disperso. En este modo, la salida no contendrá los tipos de los identificadores. Solo se escribirán los nombres de los identificadores en la salida. Por defecto, también se escriben las descripciones de tipos.
