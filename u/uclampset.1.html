UCLAMPSET(1) Comandos de usuario UCLAMPSET(1)

NOMBRE

uclampset - manipula los atributos de limitación de utilización del sistema o de un proceso

SINOPSIS

uclampset [opciones] [-m uclamp_min] [-M uclamp_max] comando argumento

uclampset [opciones] [-m uclamp_min] [-M uclamp_max] -p PID

DESCRIPCIÓN

uclampset establece o recupera los atributos de limitación de utilización de un PID existente, o ejecuta comando con los atributos dados.

La limitación de utilización es una nueva característica añadida en la v5.3. Proporciona una pista al planificador sobre el rango permitido de utilización en el que debe operar la tarea.

La utilización de la tarea afecta a la selección de frecuencia y a la colocación de la tarea. Solo el gobernador cpufreq schedutil entiende el manejo de las pistas de limitación de utilización en el momento de escribir esto. Consulte la documentación de su kernel para obtener más información sobre el soporte de otros gobernadores cpufreq.

Si está ejecutando en un sistema heterogéneo asimétrico como big.LITTLE de Arm. La limitación de utilización puede ayudar a sesgar la colocación de tareas. Si la tarea se impulsa de tal manera que el valor util_min es mayor que la capacidad de los núcleos pequeños, entonces el planificador hará todo lo posible para colocarla en un núcleo grande.

Del mismo modo, si util_max es menor o igual a la capacidad de los núcleos pequeños, el planificador aún puede optar por colocarla allí incluso si la utilización real de la tarea está al máximo.

Establecer un valor uclamp_min de tarea distinto de cero impulsará efectivamente la tarea, ya que cuando se ejecute, siempre comenzará desde este valor de utilización.

Al establecer un uclamp_max de tarea por debajo de 1024, se restringirá efectivamente la tarea, ya que cuando se ejecute, nunca podrá superar este valor de utilización.

El rango completo de utilización es: [0:1024]. El valor especial -1 se utiliza para restablecer a los valores predeterminados del sistema.

Consulte la documentación más reciente del kernel para obtener más detalles:

https://kernel.org/doc/html/latest/scheduler/sched-util-clamp.html

OPCIONES

-m

Establece el valor util_min.

-M

Establece el valor util_max.

-a, --all-tasks

Establece o recupera los atributos de limitación de utilización de todas las tareas (hilos) para un PID dado.

-p, --pid

Opera en un PID existente y no inicia una nueva tarea.

-s, --system

Establece o recupera los atributos de limitación de utilización a nivel de sistema.

-R, --reset-on-fork

Establece el indicador SCHED_FLAG_RESET_ON_FORK.

-v, --verbose

Muestra información de estado.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

USO

El comportamiento predeterminado es ejecutar un nuevo comando:

uclampset [-m uclamp_min] [-M uclamp_max] comando [argumentos]

También puede recuperar los atributos de limitación de utilización de una tarea existente:

uclampset -p PID

O establecerlos:

uclampset -p PID [-m uclamp_min] [-M uclamp_max]

O controlar los atributos a nivel de sistema:

uclampset -s [-m uclamp_min] [-M uclamp_max]

PERMISOS

Un usuario debe poseer CAP_SYS_NICE para cambiar los atributos de planificación de un proceso. Cualquier usuario puede recuperar la información de planificación.

NOTAS

Los atributos de limitación de utilización a nivel de sistema están ahí para controlar el rango permitido que las tareas pueden usar. Por predeterminado, tanto uclamp_min como uclamp_max se establecen en 1024. Esto significa que los usuarios pueden establecer los valores de limitación de utilización para sus tareas en todo el rango [0:1024].

Por ejemplo:

uclampset -s -m 512 -M 700

impedirá que cualquier tarea se impulse por encima de 512. Y todas las tareas del sistema estarán limitadas a una utilización de 700. Haciendo efectivamente el rendimiento máximo del sistema en 700.

Consulte la documentación de su kernel para conocer el comportamiento exacto esperado en ese kernel.
