uudoc(1) Manual de Comandos Generales uudoc(1)

NOMBRE

uudoc - paginar o tabular ARCHIVO(s) para imprimir

SINOPSIS

uudoc [--pages] [-h|--header] [-D|--date-format] [-d|--double-space] [-n|--number-lines] [-N|--first-line-number] [-t|--omit-header] [-l|--length] [-r|--no-file-warnings] [-F|--form-feed] [-w|--width] [-W|--page-width] [-a|--across] [--column] [-s|--separator] [-S|--sep-string] [-m|--merge] [-o|--indent] [-J ] [--help] [-V|--version] [archivos]

DESCRIPCIÓN

paginar o tabular ARCHIVO(s) para imprimir

OPCIONES

--pages <PRIMERA_PAGINA[:ULTIMA_PAGINA]>
Comenzar y detener la impresión con la página PRIMERA_PAGINA[:ULTIMA_PAGINA]
-h, --header <CADENA>
Usar la cadena de encabezado para reemplazar el nombre del archivo
en la línea de encabezado.
-D, --date-format <FORMATO>
Usar el FORMATO estilo 'date' para la fecha del encabezado.
-d, --double-space
Producir salida con doble espaciado. Un carácter de <nueva línea>
adicional se produce después de cada <nueva línea> encontrada en la entrada.
-n, --number-lines <[caracter][ancho]>
Proporcionar numeración de líneas de ancho de dígito. El valor por defecto
para ancho, si no se especifica, es 5. El número ocupa las primeras posiciones
de ancho de cada columna de texto o de cada línea de salida -m. Si se proporciona
caracter (cualquier carácter que no sea un dígito), se adjunta al número de
línea para separarlo de lo que sigue. El valor por defecto para caracter es un
<tabulador>. Los números de línea más largos que ancho columnas se truncan.
-N, --first-line-number <NUMERO>
comenzar a contar con NUMERO en la 1ª línea de la primera página impresa
-t, --omit-header
No escribir ni el encabezado de cinco líneas que identifica ni el remolque
de cinco líneas suministrados habitualmente para cada página. Dejar de escribir después
de la última línea de cada archivo sin espaciar hasta el final de la página.
-l, --length <LONGITUD_PAGINA>
Anular las 66 líneas por defecto (número de líneas de texto por defecto 56,
y con -F 63) y restablecer la longitud de la página a líneas. Si líneas no es
mayor que la suma de las profundidades del encabezado y del remolque (en líneas), el
utilitario pr suprimirá tanto el encabezado como el remolque, como si la opción -t
estuviera en efecto.
-r, --no-file-warnings
omitir advertencia cuando un archivo no se puede abrir
-F, --form-feed
Usar un <salto de página> para las nuevas páginas, en lugar del comportamiento
predeterminado que usa una secuencia de <nueva línea>s.
-w, --width <ancho>
Establecer el ancho de la línea a posiciones de columna de ancho para salida
de múltiples columnas de texto solamente. Si la opción -w no se especifica y la
opción -s no se especifica, el ancho por defecto será 72. Si la opción -w no se
especifica y la opción -s se especifica, el ancho por defecto será 512.
-W, --page-width <ancho>
establecer el ancho de página a ANCHO_PAGINA (72) caracteres siempre,
truncar líneas, excepto si la opción -J está establecida, sin interferencia
con -S o -s
-a, --across
Modificar el efecto de la opción - column para que las columnas se llenen
a lo ancho de la página en orden circular (por ejemplo, cuando la columna es 2,
la primera línea de entrada encabeza la columna 1, la segunda encabeza la columna
2, la tercera es la segunda línea en la columna 1, y así sucesivamente).
--column <columna>
Producir salida de múltiples columnas dispuestas en COLUMNA columnas
(el valor por defecto será 1) y se escribe hacia abajo en cada columna en el orden
en que el texto se recibe del archivo de entrada. Esta opción no debe usarse con -m.
Se asumirán las opciones -e y -i para la salida de múltiples columnas de texto. Si
las columnas de texto producen longitudes verticales idénticas no está especificado, pero
una columna de texto nunca excederá la longitud de la página (ver la opción -l).
Cuando se usa con -t, usar el número mínimo de líneas para escribir la salida.
-s, --separator <caracter>
Separar columnas de texto por el carácter único caracter en lugar de por
el número apropiado de <espacios> (el valor por defecto para caracter es el carácter
<tabulador>).
-S, --sep-string <cadena>
separar columnas por CADENA,
sin -S: Separador por defecto <TAB> con -J y <espacio>
en caso contrario (igual que -S\" \"), sin efecto en las opciones de columna
-m, --merge
Fusionar archivos. La salida estándar se formateará de modo que el utilitario
pr escriba una línea de cada archivo especificado por un operando de archivo, lado
a lado en columnas de texto de anchos fijos iguales, en términos del número de posiciones
de columna. Las implementaciones deben soportar la fusión de al menos nueve operandos
de archivo.
-o, --indent <margen>
Cada línea de salida irá precedida por un número de <espacios> de desplazamiento. Si la opción -o no se especifica, el desplazamiento por defecto será cero. El espacio
ocupado es adicional al ancho de la línea de salida (ver la opción -w a continuación).
-J
fusionar líneas completas, desactiva el truncamiento de líneas -W, sin alineación
de columnas, --sep-string[=CADENA] establece separadores
--help
Imprimir información de ayuda
-V, --version
Imprimir versión
[archivos]

EXTRA

Si no se proporcionan ARCHIVO(s), o si ARCHIVO es -, lee la entrada estándar.

Al crear salida de múltiples columnas, las columnas serán de igual ancho. Al usar la opción '-s' para separar columnas, el separador por defecto es un solo carácter de tabulación. Al usar la opción '-S' para separar columnas, el separador por defecto es un solo carácter de espacio.

NAME

uu-pr — print file in USASCII format

SYNOPSIS

uu-pr [file ...]

DESCRIPTION

The uu-pr utility prints files in USASCII format. This is useful for displaying files that may contain non-ASCII characters, such as binary files, in a safe way.

OPTIONS

There are no specific options for uu-pr. It processes all files provided as arguments.

EXTRA

The uu-pr command is part of the `uu` package, which provides utilities for encoding and decoding files using the UU encoding scheme.

VERSION

This man page describes uu-pr version 1.0.
