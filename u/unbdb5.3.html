CUNBDB5

Propósito:

!>
!> CUNBDB5 ortogonaliza el vector columna
!>      X = [ X1 ]
!>          [ X2 ]
!> con respecto a las columnas de
!>      Q = [ Q1 ] .
!>          [ Q2 ]
!> Las columnas de Q deben ser ortonormales.
!>
!> Si la proyección es cero según el criterio de Kahan,
!> se devuelve otro vector del complemento ortogonal.
!> Este vector se elige de forma arbitraria pero determinista.
!>
!>

Parámetros

M1 
!>          M1 es INTEGER
!>           La dimensión de X1 y el número de filas en Q1. 0 <= M1.
!>

M2

!>          M2 es INTEGER
!>           La dimensión de X2 y el número de filas en Q2. 0 <= M2.
!>

N

!>          N es INTEGER
!>           El número de columnas en Q1 y Q2. 0 <= N.
!>

X1

!>          X1 es un array COMPLEX de dimensión (M1)
!>           En la entrada, la parte superior del vector a ortogonalizar.
!>           En la salida, la parte superior del vector proyectado.
!>

INCX1

!>          INCX1 es INTEGER
!>           Incremento para las entradas de X1.
!>

X2

!>          X2 es un array COMPLEX de dimensión (M2)
!>           En la entrada, la parte inferior del vector a
!>           ortogonalizar. En la salida, la parte inferior del vector proyectado.
!>

INCX2

!>          INCX2 es INTEGER
!>           Incremento para las entradas de X2.
!>

Q1

!>          Q1 es un array COMPLEX de dimensión (LDQ1, N)
!>           La parte superior de la matriz base ortonormal.
!>

LDQ1

!>          LDQ1 es INTEGER
!>           La dimensión principal de Q1. LDQ1 >= M1.
!>

Q2

!>          Q2 es un array COMPLEX de dimensión (LDQ2, N)
!>           La parte inferior de la matriz base ortonormal.
!>

LDQ2

!>          LDQ2 es INTEGER
!>           La dimensión principal de Q2. LDQ2 >= M2.
!>

WORK

!>          WORK es un array COMPLEX de dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>           La dimensión del array WORK. LWORK >= N.
!>

INFO

!>          INFO es INTEGER
!>           = 0:  salida exitosa.
!>           < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

NAME

unbdb5.3 —

SYNOPSIS

subroutine SORBDB5 (integer M1, integer M2, integer N, real, dimension(*) X1, integer INCX1, real, dimension(*) X2, integer INCX2, real, dimension(LDQ1,*) Q1, integer LDQ1, real, dimension(LDQ2,*) Q2, integer LDQ2, real, dimension(*) WORK, integer LWORK, integer INFO)

subroutine ZUNBDB5 (integer M1, integer M2, integer N, complex*16, dimension(*) X1, integer INCX1, complex*16, dimension(*) X2, integer INCX2, complex*16, dimension(LDQ1,*) Q1, integer LDQ1, complex*16, dimension(LDQ2,*) Q2, integer LDQ2, complex*16, dimension(*) WORK, integer LWORK, integer INFO)

DESCRIPTION

The subroutines SORBDB5 and ZUNBDB5 are subroutines for orthogonalizing vectors.

subroutine SORBDB5 (integer M1, integer M2, integer N, real, dimension(*) X1, integer INCX1, real, dimension(*) X2, integer INCX2, real, dimension(LDQ1,*) Q1, integer LDQ1, real, dimension(LDQ2,*) Q2, integer LDQ2, real, dimension(*) WORK, integer LWORK, integer INFO)

Purpose:

!>
!> SORBDB5 orthogonalizes the column vector
!>      X = [ X1 ]
!>          [ X2 ]
!> with respect to the columns of
!>      Q = [ Q1 ] .
!>          [ Q2 ]
!> The columns of Q must be orthonormal.
!>
!> If the projection is zero according to Kahan's
!> criterion, then some other vector from the orthogonal complement
!> is returned. This vector is chosen in an arbitrary but deterministic
!> way.
!>
!>

Parameters

M1 
!>          M1 is INTEGER
!>           The dimension of X1 and the number of rows in Q1. 0 <= M1.
!>

M2

!>          M2 is INTEGER
!>           The dimension of X2 and the number of rows in Q2. 0 <= M2.
!>

N

!>          N is INTEGER
!>           The number of columns in Q1 and Q2. 0 <= N.
!>

X1

!>          X1 is REAL array, dimension (M1)
!>           On entry, the top part of the vector to be orthogonalized.
!>           On exit, the top part of the projected vector.
!>

INCX1

!>          INCX1 is INTEGER
!>           Increment for entries of X1.
!>

X2

!>          X2 is REAL array, dimension (M2)
!>           On entry, the bottom part of the vector to be
!>           orthogonalized. On exit, the bottom part of the projected
!>           vector.
!>

INCX2

!>          INCX2 is INTEGER
!>           Increment for entries of X2.
!>

Q1

!>          Q1 is REAL array, dimension (LDQ1, N)
!>           The top part of the orthonormal basis matrix.
!>

LDQ1

!>          LDQ1 is INTEGER
!>           The leading dimension of Q1. LDQ1 >= M1.
!>

Q2

!>          Q2 is REAL array, dimension (LDQ2, N)
!>           The bottom part of the orthonormal basis matrix.
!>

LDQ2

!>          LDQ2 is INTEGER
!>           The leading dimension of Q2. LDQ2 >= M2.
!>

WORK

!>          WORK is REAL array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>           The dimension of the array WORK. LWORK >= N.
!>

INFO

!>          INFO is INTEGER
!>           = 0:  successful exit.
!>           < 0:  if INFO = -i, the i-th argument had an illegal value.
!>
