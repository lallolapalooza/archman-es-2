ucs2any(1) Manual de comandos generales ucs2any(1)

NOMBRE

ucs2any - genera fuentes BDF que contienen subconjuntos de puntos de código ISO 10646-1

SINOPSIS

ucs2any [ +d | -d ] nombre-fuente { archivo-mapeo registro-codificacion } ...

DESCRIPCIÓN

ucs2any permite generar a partir de una fuente BDF codificada en ISO 10646-1 otras fuentes BDF en cualquier codificación posible. De esta manera, se pueden derivar de una única fuente maestra ISO 10646-1 un conjunto completo de fuentes de 8 bits en todas las codificaciones ISO 8859 y varias otras.

OPCIONES

+d
inserta caracteres gráficos DEC VT100 en el rango C0 (por defecto para fuentes verticales, de celda de caracteres).
-d
omite los caracteres gráficos DEC VT100 del rango C0 (por defecto para todos los tipos de fuente excepto las verticales, de celda de caracteres).

OPERANDOS

nombre-fuente
es el nombre de un archivo BDF codificado en ISO 10646-1.
archivo-mapeo
es el nombre de una tabla de conjunto de caracteres como las que se encuentran en <ftp://ftp.unicode.org/Public/MAPPINGS/>. Estos archivos también se pueden encontrar normalmente instalados en el directorio /usr/share/fonts/util.
registro-codificacion
son los valores de campo CHARSET_REGISTRY y CHARSET_ENCODING para el nombre de la fuente (XLFD) de la fuente de destino, separados por un guion.

Se puede especificar cualquier número de pares de operandos archivo-mapeo y registro-codificacion.

EJEMPLO

El comando

ucs2any 6x13.bdf 8859-1.TXT iso8859-1 8859-2.TXT iso8859-2
generará los archivos 6x13-iso8859-1.bdf y 6x13-iso8859-2.bdf.

DIRECCIONES FUTURAS

Con suerte, una futura versión tendrá una instalación similar a ucs2any integrada en el servidor, y recodificará ISO 10646-1 sobre la marcha, porque almacenar las mismas fuentes en muchas codificaciones diferentes es claramente un desperdicio de capacidad de almacenamiento.
