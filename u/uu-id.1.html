uudoc(1) Manual de comandos generales uudoc(1)

NOMBRE

uudoc - Imprime información de usuario y grupo para cada USUARIO especificado, o (cuando USUARIO se omite) para el usuario actual.

SINOPSIS

uudoc [-a|--ignore] [-A ] [-u|--user] [-g|--group] [-G|--groups] [-p ] [-n|--name] [-P ] [-r|--real] [-z|--zero] [-Z|--context] [-h|--help] [-V|--version] [USUARIO]

DESCRIPCIÓN

Imprime información de usuario y grupo para cada USUARIO especificado, o (cuando USUARIO se omite) para el usuario actual.

OPCIONES

-a, --ignore
ignorar, por compatibilidad con otras versiones
-A
Muestra el ID de usuario de auditoría del proceso y otras propiedades de auditoría del proceso, lo que requiere privilegios (no disponible en Linux).
-u, --user
Muestra solo el ID de usuario efectivo como un número.
-g, --group
Muestra solo el ID de grupo efectivo como un número.
-G, --groups
Muestra solo los diferentes IDs de grupo como números separados por espacios en blanco, sin orden particular.
-p
Hace que la salida sea legible por humanos. Cada visualización está en una línea separada.
-n, --name
Muestra el nombre del ID de usuario o grupo para las opciones -G, -g y -u en lugar del número. Si alguno de los números de ID no se puede mapear a nombres, se mostrará el número como de costumbre.
-P
Muestra el id como una entrada del archivo de contraseñas.
-r, --real
Muestra el ID real para las opciones -G, -g y -u en lugar del ID efectivo.
-z, --zero
delimit entradas con caracteres NUL, no espacios en blanco; no permitido en formato predeterminado.
-Z, --context
imprime solo el contexto de seguridad del proceso (no habilitado)
-h, --help
Imprime ayuda.
-V, --version
Imprime la versión.
[USUARIO]

EXTRA

La utilidad id muestra los nombres y IDs numéricos de usuario y grupo del proceso que llama, a la salida estándar. Si los IDs real y efectivo son diferentes, se muestran ambos, de lo contrario, solo se muestra el ID real.

Si se especifica un usuario (nombre de inicio de sesión o ID de usuario), se muestran los IDs de usuario y grupo de ese usuario. En este caso, se asume que los IDs real y efectivo son los mismos.
