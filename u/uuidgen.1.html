UUIDGEN(1) Comandos de usuario UUIDGEN(1)

NOMBRE

uuidgen - crear un nuevo valor UUID

SINOPSIS

uuidgen [opciones]

DESCRIPCIÓN

El programa uuidgen crea (e imprime) un nuevo identificador único universal (UUID) utilizando la biblioteca libuuid(3). El nuevo UUID puede considerarse razonablemente único entre todos los UUID creados en el sistema local, y entre los UUID creados en otros sistemas en el pasado y en el futuro.

Hay tres tipos de UUID que uuidgen puede generar: UUIDs basados en tiempo, UUIDs basados en aleatoriedad y UUIDs basados en hash. Por defecto, uuidgen generará un UUID basado en aleatoriedad si está presente un generador de números aleatorios de alta calidad. De lo contrario, elegirá un UUID basado en tiempo. Es posible forzar la generación de uno de estos dos primeros tipos de UUID utilizando las opciones --random o --time.

El tercer tipo de UUID se genera con las opciones --md5 o --sha1, seguidas de --namespace namespace y --name name. El namespace puede ser un UUID conocido, o un alias para uno de los UUIDs conocidos definidos en RFC 4122, es decir, @dns, @url, @oid, o @x500. El name es un valor de cadena arbitrario. El UUID generado es el digest de la concatenación del UUID del namespace y el valor del nombre, hasheado con los algoritmos MD5 o SHA1. Por lo tanto, es un valor predecible que puede ser útil cuando los UUIDs se utilizan como identificadores o nonces para valores más complejos o valores que no deben revelarse directamente. Consulte la RFC para obtener más información.

OPCIONES

-r, --random

Genera un UUID basado en aleatoriedad. Este método crea un UUID que consiste principalmente en bits aleatorios. Requiere que el sistema operativo tenga un generador de números aleatorios de alta calidad, como /dev/random.

-t, --time

Genera un UUID basado en tiempo. Este método crea un UUID basado en el reloj del sistema más la dirección de hardware ethernet del sistema, si está presente.

-m, --md5

Utiliza MD5 como algoritmo de hash.

-s, --sha1

Utiliza SHA1 como algoritmo de hash.

-6, --time-v6

Genera un UUID basado en tiempo. Este método crea un UUID basado en el reloj del sistema y es lexicográficamente ordenable según la marca de tiempo contenida.

-7, --time-v7

Genera un UUID basado en tiempo. Este método crea un UUID basado en el reloj del sistema y es lexicográficamente ordenable según la marca de tiempo contenida.

-n, --namespace namespace

Genera el hash con el prefijo namespace. El namespace es un UUID, o '@ns' donde "ns" es un UUID predefinido conocido al que se accede por nombre de namespace (ver arriba).

-N, --name name

Genera el hash del name.

-C, --count num

Genera múltiples UUIDs utilizando la capacidad mejorada de libuuid para almacenar en caché UUIDs basados en tiempo, lo que resulta en un rendimiento mejorado. Sin embargo, esto no tiene ninguna importancia para otros tipos de UUID.

-x, --hex

Interpreta el nombre name como una cadena hexadecimal.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

CONFORME A

OSF DCE 1.1

EJEMPLOS

uuidgen --sha1 --namespace @dns --name "www.example.com"
