intmax_t(3type) intmax_t(3type)

NOMBRE

intmax_t, uintmax_t - tipos de enteros básicos de mayor anchura

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <stdint.h>
typedef /* ... */ intmax_t;
typedef /* ... */ uintmax_t;
#define INTMAX_WIDTH  /* ... */
#define UINTMAX_WIDTH INTMAX_WIDTH
#define INTMAX_MAX    /*  2**(INTMAX_WIDTH - 1) - 1  */
#define INTMAX_MIN    /*  - 2**(INTMAX_WIDTH - 1)    */
#define UINTMAX_MAX   /*  2**UINTMAX_WIDTH - 1       */
#define INTMAX_C(c)   c ## /* ... */
#define UINTMAX_C(c)  c ## /* ... */

DESCRIPCIÓN

intmax_t es un tipo de entero con signo capaz de representar cualquier valor de cualquier tipo de entero con signo básico soportado por la implementación. Es capaz de almacenar valores en el rango [INTMAX_MIN, INTMAX_MAX].

uintmax_t es un tipo de entero sin signo capaz de representar cualquier valor de cualquier tipo de entero sin signo básico soportado por la implementación. Es capaz de almacenar valores en el rango [0, UINTMAX_MAX].

Las macros [U]INTMAX_WIDTH se expanden a la anchura en bits de estos tipos.

Las macros [U]INTMAX_MAX se expanden al valor máximo que estos tipos pueden almacenar.

La macro INTMAX_MIN se expande al valor mínimo que intmax_t puede almacenar.

Las macros [U]INTMAX_C() expanden su argumento a una constante entera de tipo [u]intmax_t.

El modificador de longitud para [u]intmax_t para las familias de funciones printf(3) y scanf(3) es j; resultando comúnmente en %jd, %ji, %ju o %jx para imprimir valores [u]intmax_t.

ESTÁNDARES

C11, POSIX.1-2024.

HISTORIAL

C99, POSIX.1-2001.

NOTAS

La siguiente cabecera también proporciona estos tipos: <inttypes.h>.

ERRORES

Estos tipos pueden no ser tan grandes como los tipos enteros extendidos, como __int128

VER TAMBIÉN

int64_t(3type), intptr_t(3type), printf(3), strtoimax(3)
