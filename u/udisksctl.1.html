UDISKSCTL(1) Comandos de usuario UDISKSCTL(1)

NOMBRE

udisksctl - La herramienta de línea de comandos de udisks

SINOPSIS

udisksctl status

udisksctl info {--object-path OBJETO | --block-device DISPOSITIVO | --drive UNIDAD}

udisksctl mount {--object-path OBJETO | --block-device DISPOSITIVO} [--filesystem-type TIPO] [--options OPCIONES...] [--no-user-interaction]

udisksctl unmount {--object-path OBJETO | --block-device DISPOSITIVO} [--force] [--no-user-interaction]

udisksctl unlock {--object-path OBJETO | --block-device DISPOSITIVO} [--no-user-interaction] [--key-file RUTA] [--read-only]

udisksctl lock {--object-path OBJETO | --block-device DISPOSITIVO} [--no-user-interaction]

udisksctl loop-setup --file RUTA [--read-only] [--offset OFFSET] [--size TAMAÑO] [--no-user-interaction]

udisksctl loop-delete {--object-path OBJETO | --block-device DISPOSITIVO} [--no-user-interaction]

udisksctl power-off {--object-path OBJETO | --block-device DISPOSITIVO} [--no-user-interaction]

udisksctl smart-simulate --file RUTA {--object-path OBJETO | --block-device DISPOSITIVO} [--no-user-interaction]

udisksctl monitor

udisksctl dump

udisksctl help

DESCRIPCIÓN

udisksctl es un programa de línea de comandos que se utiliza para interactuar con el proceso del demonio udisksd(8).

COMANDOS

status

Muestra información de alto nivel sobre unidades de disco y dispositivos de bloques.

info

Muestra información detallada sobre OBJETO, DISPOSITIVO o UNIDAD.

mount

Monta un dispositivo. El dispositivo se montará en un subdirectorio en la jerarquía /run/media. Al completarse con éxito, el punto de montaje se imprimirá en la salida estándar.

-t, --filesystem-type

Tipo de sistema de archivos a usar. Si no se especifica, se utilizará el tipo de sistema de archivos autodetectado.

-o, --options

El dispositivo se montará con un conjunto seguro de opciones predeterminadas. Puede influir en las opciones que se pasan al comando mount(8) utilizando esta opción. Tenga en cuenta que solo se permiten opciones seguras; las solicitudes con opciones inherentemente inseguras como suid o dev que permitirían al llamador obtener privilegios adicionales, son rechazadas.

unmount

Desmonta un dispositivo. Esto solo funciona si el dispositivo está montado. La opción --force se puede usar para solicitar que el dispositivo se desmonte incluso si existen referencias activas.

-f, --force

Desmontaje perezoso. Desconecta el sistema de archivos de la jerarquía de archivos ahora y limpia todas las referencias a este sistema de archivos tan pronto como ya no esté ocupado.

unlock

Desbloquea un dispositivo cifrado. La frase secreta se solicitará desde la terminal de control y, tras completarse con éxito, el dispositivo de texto claro se imprimirá en la salida estándar.

--key-file=RUTA

Lee la frase secreta del archivo dado.

lock

Bloquea un dispositivo. Esto solo funciona si el dispositivo es un dispositivo de texto claro respaldado por un dispositivo criptográfico.

loop-setup

Configura un dispositivo de bucle respaldado por ARCHIVO.

-f, --file=ARCHIVO

Archivo para configurar un dispositivo de bucle.

-r, --read-only

Configura un dispositivo de bucle de solo lectura.

-o, --offset=OFFSET

El inicio de los datos se mueve OFFSET bytes dentro del archivo especificado.

-s, --size=TAMAÑO

El final de los datos se establece en no más de TAMAÑO bytes después del inicio de los datos.

loop-delete

Elimina un dispositivo de bucle.

power-off

Organiza que la unidad sea retirada de forma segura y apagada. En el lado del sistema operativo, esto incluye asegurarse de que ningún proceso esté utilizando la unidad, luego solicitar que los búferes y cachés en tránsito se guarden en almacenamiento estable. Los pasos exactos para apagar la unidad dependen de la propia unidad y de la interconexión utilizada. Para unidades conectadas a través de USB, el efecto es que el dispositivo USB se desconfigurará seguido de la desactivación del puerto de concentrador ascendente al que está conectado.

Tenga en cuenta que dado que algunos dispositivos físicos contienen múltiples unidades (por ejemplo, lectores de tarjetas flash 4 en 1 para dispositivos USB), apagar una unidad puede afectar a otras unidades. Por lo tanto, no hay muchas garantías asociadas con la realización de esta acción. Por lo general, el efecto es que la unidad desaparece como si se hubiera desconectado.

smart-simulate

Establece los datos SMART del blob libatasmart proporcionado por ARCHIVO; consulte /usr/share/doc/libatasmart-devel-VERSION/ para ver los blobs distribuidos con libatasmart. Esta es una función de depuración que se utiliza para comprobar que las aplicaciones actúan correctamente cuando un disco falla.

-f, --file=ARCHIVO

Archivo con el blob libatasmart.

monitor

Supervisa el demonio en busca de eventos.

dump

Imprime el estado actual del demonio.

help

Imprime la ayuda y sale.

ESPECIFICACIÓN DE DISPOSITIVO

Para los comandos que requieren un dispositivo como argumento, se pueden usar las siguientes opciones para especificarlo.

-b, --block-device=DISPOSITIVO

Especifica un dispositivo por la ruta de su archivo de dispositivo. Por ejemplo, /dev/sda.

-p, --object-path=OBJETO

Especifica un dispositivo por la ruta del objeto interno de UDisks sin el prefijo /org/freedesktop/UDisks2. Por ejemplo, block_devices/sda para el disco /dev/sda.

-d, --drive=UNIDAD

Especifica una unidad por nombre, por ejemplo, VirtIO_Disk. Actualmente, esto solo se puede usar junto con el comando info.

OPCIONES COMUNES

La opción --no-user-interaction se puede utilizar para solicitar que no ocurra ninguna interacción (como que al usuario se le presente un diálogo de autenticación) al comprobar con polkit(8) si el llamador está autorizado a realizar la acción solicitada.

AUDIENCIA

Este programa no asume que el llamador sea el superusuario; está diseñado para ser utilizado por usuarios no privilegiados y las autorizaciones son comprobadas por el demonio udisks usando polkit(8). Además, este programa no está diseñado para ser utilizado por scripts u otros programas; las opciones/comandos pueden cambiar de forma incompatible en el futuro, incluso en versiones de mantenimiento. Consulte la sección "ESTABILIDAD DE LA API" de udisks(8) para obtener más información.

COMPLETADO EN BASH

udisksctl incluye un script de completado de bash para completar comandos, objetos, dispositivos de bloques y algunas opciones.
