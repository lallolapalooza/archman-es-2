NOMBRE

umoci insert - insertar contenido en una imagen OCI

SINOPSIS

umoci insert --image=imagen[:etiqueta] [--tag=nueva-etiqueta] [--opaque] [--rootless] [--uid-map=valor] [--uid-map=valor] [--no-history] [--history.comment=comentario] [--history.created_by=creado_por] [--history.author=autor] [--history-created=fecha] fuente destino

umoci insert [opciones] --whiteout destino

DESCRIPCIÓN

En la primera forma, inserta el contenido de fuente en la imagen OCI dada por --image -- sobrescribiéndola a menos que especifiques --tag. Esto se hace creando una nueva capa que contiene solo los contenidos de fuente con el nombre de destino. fuente puede ser un archivo o un directorio, y en este último caso se recursará. Si se especifica --opaque, entonces se eliminarán todas las rutas debajo de destino en las capas de imagen anteriores (asumiendo que destino es un directorio).

En la segunda forma, inserta una "entrada de eliminación" en la imagen OCI para destino dentro de la imagen. Esto se hace insertando una capa que contiene solo una entrada de whiteout para la ruta dada.

Ten en cuenta que este comando funciona creando una nueva capa, por lo que no debe usarse para eliminar (o reemplazar) secretos de una imagen ya construida. Consulta umoci-config(1) y --config.volume para saber cómo lograr esto correctamente sin crear capas de imagen con secretos en primer lugar.

Si no se especificó --no-history, se añade una entrada de historial a la imagen OCI etiquetada para este cambio (con las diversas banderas --history. controlando los valores utilizados). Para ver el historial, consulta umoci-stat(1).

OPCIONES

Las opciones globales se definen en umoci(1).

--image=imagen[:etiqueta]
La etiqueta de origen y destino para la inserción de archivo en ruta dentro de
la imagen del contenedor. imagen debe ser una ruta a una imagen OCI válida y etiqueta
debe ser una etiqueta válida en la imagen. Si no se proporciona etiqueta, por defecto
es "latest".

--tag=nueva-etiqueta
Nombre de la etiqueta para la imagen modificada, si no se especifica, la etiqueta original
proporcionada a --image será sobrescrita.

--opaque
(Asumiendo que destino es un directorio.) Añade una entrada de whiteout opaca para destino
para que cualquier ruta hija de destino en capas anteriores sea enmascarada por la nueva
entrada para destino, que solo contendrá los contenidos de fuente. Esto
permite el reemplazo completo de un directorio, en lugar de la fusión de
entradas de directorio.

--whiteout
Añade una entrada de eliminación para destino, para que no esté presente en futuras
extracciones de la imagen.

--rootless
Habilita el soporte de inserción sin root. Esto permite que umoci-insert(1) sea
utilizado por un usuario no privilegiado. El uso de esta bandera implica --uid-map=0:$(id
-u):1 y --gid-map=0:$(id -g):1, así como la habilitación de varias características
para simular partes del proceso de recursión en un intento de generar un
clon lo más parecido posible del sistema de archivos para la inserción.

--uid-map=valor
Especifica un mapeo de UID a usar al insertar archivos. Esto se usa de forma similar
a user_namespaces(7), y tiene el formato
container:host[:size].

--gid-map=valor
Especifica un mapeo de GID a usar al insertar archivos. Esto se usa de forma similar
a user_namespaces(7), y tiene el formato
container:host[:size].

--no-history
Provoca que no se añada ninguna entrada de historial para esta operación. No se
recomienda su uso con umoci-insert(1), ya que resulta en que el historial no
incluya todas las capas de la imagen -- y por lo tanto causará confusión con herramientas
que miran el historial de la imagen.

--history.comment=comentario
Comentario para la entrada de historial correspondiente a esta modificación de la imagen.
Si no se especifica, umoci(1) generará un valor dependiente de la implementación.

--history.created_by=creado_por
Entrada CreatedBy para la entrada de historial correspondiente a esta modificación de
la imagen. Si no se especifica, umoci(1) generará un
valor dependiente de la implementación.

--history.author=autor
Valor del autor para la entrada de historial correspondiente a esta modificación de
la imagen. Si no se especifica, este valor será el valor del autor de la imagen
después de cualquier modificación realizada por esta llamada a umoci-config(1).

--history-created=fecha
Fecha de creación para la entrada de historial correspondiente a estas modificaciones de
la imagen. Debe ser una marca de tiempo formateada ISO8601 (ver date(1)). Si
no se especifica, se usa la hora actual.

EJEMPLO

Lo siguiente inserta un archivo mybinary en la ruta /usr/bin/mybinary y un directorio myconfigdir en la ruta /etc/myconfigdir. Cabe destacar que si /etc/myconfigdir ya existe en la imagen, los contenidos de los dos directorios se fusionan (con la capa más nueva teniendo precedencia).

% umoci insert --image oci:foo mybinary /usr/bin/mybinary
% umoci insert --image oci:foo myconfigdir /etc/myconfigdir

Y en estos ejemplos eliminamos /usr/bin/mybinary y reemplazamos la totalidad de /etc con myetcdir (de modo que ninguna de las antiguas entradas de /etc estará presente en umoci-unpack(1)).

% umoci insert --image oci:foo --whiteout /usr/bin/mybinary
% umoci insert --image oci:foo --opaque myetcdir /etc
