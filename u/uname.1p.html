UNAME(1P) Manual del programador de POSIX UNAME(1P)

PROLOGO

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

uname — devolver el nombre del sistema

SINOPSIS

uname [-amnrsv]

DESCRIPCION

Por defecto, la utilidad uname escribirá el nombre del sistema operativo en la salida estándar. Cuando se especifican opciones, se escribirán símbolos que representan una o más características del sistema en la salida estándar. El formato y el contenido de los símbolos dependen de la implementación. En los sistemas que cumplen con el volumen de Interfaces del Sistema de POSIX.1‐2017, los símbolos escritos serán aquellos soportados por la función uname() tal como se define en el volumen de Interfaces del Sistema de POSIX.1‐2017.

OPCIONES

La utilidad uname se ajustará a las Definiciones Base del volumen de POSIX.1‐2017, Sección 12.2, Directrices de sintaxis de utilidad.

Se soportarán las siguientes opciones:

-a
Comportarse como si se hubieran especificado todas las opciones -mnrsv.
-m
Escribir el nombre del tipo de hardware en el que se está ejecutando el sistema en la salida estándar.
-n
Escribir el nombre de este nodo dentro de una red de comunicaciones definida por la implementación.
-r
Escribir el nivel de versión actual de la implementación del sistema operativo.
-s
Escribir el nombre de la implementación del sistema operativo.
-v
Escribir el nivel de versión actual de esta versión de la implementación del sistema operativo.

Si no se especifican opciones, la utilidad uname escribirá el nombre del sistema operativo, como si se hubiera especificado la opción -s.

OPERANDOS

Ninguno.

ENTRADA ESTÁNDAR

No se utiliza.

ARCHIVOS DE ENTRADA

Ninguno.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de uname:

LANG
Proporcionar un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en una cadena de valor no vacía, anule los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determinar la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en argumentos).
LC_MESSAGES

Determinar la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en la salida de error estándar.
NLSPATH
Determinar la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASINCRONOS

Predeterminado.

SALIDA ESTÁNDAR

Por defecto, la salida será una sola línea del siguiente formato:

"%s\n", <sysname>

Si se especifica la opción -a, la salida será una sola línea del siguiente formato:

"%s %s %s %s %s\n", <sysname>, <nodename>, <release>,
    <version>, <machine>

Se pueden escribir símbolos adicionales definidos por la implementación; todos esos símbolos se escribirán al final de la línea de salida antes del <salto de línea>.

Si se especifican opciones para seleccionar diferentes combinaciones de los símbolos, solo se escribirán esos símbolos, en el orden mostrado para la opción -a. Si un símbolo no se selecciona para su escritura, sus caracteres de <espacio> finales correspondientes tampoco se escribirán.

ERROR ESTÁNDAR

La salida de error estándar se utilizará solo para mensajes de diagnóstico.

ARCHIVOS DE SALIDA

Ninguno.

DESCRIPCIÓN EXTENDIDA

Ninguna.

ESTADO DE SALIDA

Se devolverán los siguientes valores de salida:

 0
La información solicitada se escribió correctamente.
>0
Ocurrió un error.

CONSECUENCIAS DE ERRORES

Predeterminado.

Las siguientes secciones son informativas.

USO DE LA APLICACIÓN

Tenga en cuenta que cualquiera de los símbolos podría incluir caracteres de <espacio> incrustados, lo que podría afectar los algoritmos de análisis si se seleccionan varias opciones para la salida.

El nombre del nodo es típicamente un nombre que el sistema utiliza para identificarse para la dirección de comunicación entre sistemas.

EJEMPLOS

El siguiente comando:

uname -sr

escribe el nombre del sistema operativo y el nivel de versión, separados por uno o más caracteres de <espacio>.

FUNDAMENTACIÓN

Se sugirió que esta utilidad no se puede usar de forma portable ya que el formato de los símbolos depende de la implementación. El grupo de trabajo de POSIX.1 no pudo lograr un consenso sobre la definición de estos formatos en la función subyacente uname(), y no había expectativa de que este volumen de POSIX.1‐2017 tuviera más éxito. Algunas aplicaciones todavía pueden encontrar útil esta utilidad histórica. Por ejemplo, los símbolos podrían usarse para entradas de registro del sistema o para comparación con la entrada del operador o del usuario.
