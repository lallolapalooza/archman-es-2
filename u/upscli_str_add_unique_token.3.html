upscli_str_add_unique_token(3)

Paquete: nut

UPSCLI_STR_ADD_UNIQU(3) Manual de NUT UPSCLI_STR_ADD_UNIQU(3)

NOMBRE

upscli_str_add_unique_token - Añade un token único a un búfer de cadena, con llamadas de retorno opcionales según lo requiera la implementación

SINOPSIS

        #include <upsclient.h>
        int     upscli_str_add_unique_token(char *tgt, size_t tgtsize, const char *token,
                                int (*callback_always)(char *, size_t, const char *),
                                int (*callback_unique)(char *, size_t, const char *) );

DESCRIPCIÓN

La función upscli_str_add_unique_token() toma el puntero tgt a un búfer de caracteres proporcionado por el llamante de tamaño tgtsize, y el puntero token a un token contiguo que debe ser añadido al final del búfer tgt, si no está ya presente.

El contenido de token se limpia de los caracteres de espacio circundantes, y el método se recurre para procesar independientemente cada token separado por espacios dentro (si quedan espacios).

El búfer tgt resultante eventualmente recopilará una cadena compuesta de valores token únicos en orden de primera mención, separados por caracteres de espacio únicos (ASCII 0x20).

Opcionalmente llama a callback_always (si no es NULL) después de verificar la entrada en busca de espacios (y tal vez recursar) y antes de verificar si el token ya está presente, y/o a callback_unique (si no es NULL) después de verificar la unicidad y justo antes de añadir un token recién visto.

•Si dicha llamada de retorno devuelve 0, aborta la adición de token y devuelve -3.

Es responsabilidad del llamante asignar dinámicamente o estáticamente el búfer tgt y liberarlo (free()) si es necesario. En lo que respecta a este método, el búfer puede ser reciclado (en bucles de procesamiento de datos) estableciendo el primer carácter a '\0', convirtiéndolo nuevamente en una cadena vacía.

VALOR DE RETORNO

La función upscli_str_add_unique_token() devuelve un código numérico:

•0 si el valor token ya estaba presente en el búfer tgt;
•1 si token se añadió correctamente;
•-1 si necesitábamos añadir el token, pero no cabía dentro del límite de tgtsize;
•-2 si token o la cadena tgt eran NULL, o si token estaba vacío;
•-3 si el token fue rechazado por el método de llamada de retorno opcional que devolvió 0.
