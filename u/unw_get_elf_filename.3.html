NOMBRE

unw_get_elf_filename -- obtener el nombre del archivo elf de soporte

SINOPSIS

#include <libunwind.h>

int unw_get_elf_filename(unw_cursor_t *cp, char *bufp, size_t len, unw_word_t *offp);

DESCRIPCIÓN

La rutina unw_get_elf_filename() devuelve el nombre del archivo elf de soporte del puntero de instrucción actual que creó el marco de pila identificado por el argumento cp. El argumento bufp es un puntero a un búfer de caracteres que tiene al menos len bytes de longitud. Este búfer se utiliza para devolver el nombre del procedimiento. El argumento offp es un puntero a una palabra que se utiliza para devolver el desplazamiento en bytes del puntero de instrucción guardado en el marco de pila identificado por cp, relativo al inicio del archivo elf. Para sistemas embebidos, la información del símbolo puede haber sido eliminada de un programa, entonces unw_get_proc_name() puede no estar completamente disponible; si el lado del host tiene el programa sin eliminar con información de depuración, entonces se puede usar la herramienta de línea de comandos addr2line en el host para obtener el nombre del archivo fuente y el número de línea del puntero de instrucción, con el nombre del archivo elf en bufp y la dirección en offp.

VALOR DE RETORNO

Al completarse con éxito, unw_get_elf_filename() devuelve 0. De lo contrario, se devuelve el valor negativo de uno de los códigos de error a continuación.

SEGURIDAD DE HILOS Y SEÑALES

unw_get_elf_filename() es seguro para hilos. Si el cursor cp está en el espacio de direcciones local, esta rutina también es segura para usarla desde un manejador de señales.

ERRORES

UNW_EUNSPEC

Ocurrió un error no especificado.
UNW_ENOINFO

Libunwind no pudo determinar el nombre del archivo elf del puntero de instrucción.
UNW_ENOMEM

El nombre del archivo elf es demasiado largo para caber en el búfer proporcionado. Se ha devuelto una versión truncada del nombre.
