NOMBRE

upscli_upserror - Obtener el número de error actual de la conexión

SINOPSIS

        #include <upsclient.h>
        int upscli_upserror(UPSCONN_t *ups);

DESCRIPCIÓN

La función upscli_upserror() toma el puntero ups a una estructura de estado UPSCONN_t y devuelve el valor del número de error interno, si lo hay.

Esto se utiliza típicamente para comprobar ciertos valores de error como UPSCLI_ERR_UNKCOMMAND. Ese error específico se puede utilizar para detectar versiones antiguas de upsd(8) que podrían no admitir un comando determinado.

Algunos mensajes de error tienen significados adicionales, por lo que debes usar upscli_strerror(3) para obtener mensajes de error legibles.

VALOR DEVUELTO

La función upscli_upserror() devuelve uno de los valores UPSCLI_ERR_* de upsclient.h, o 0 si no se ha producido ningún error.

VEASE TAMBIÉN

upscli_readline(3), upscli_sendline(3), upscli_strerror(3)
