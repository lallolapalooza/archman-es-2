UUIDPARSE(1) Comandos de usuario UUIDPARSE(1)

NOMBRE

uuidparse - una utilidad para analizar identificadores únicos

SINOPSIS

uuidparse [opciones] uuid

DESCRIPCIÓN

Este comando analizará las entradas de identificadores únicos de los argumentos de la línea de comandos o de la entrada estándar. Las entradas están separadas por espacios en blanco.

SALIDA

Variantes

NCS Identificador de Network Computing System. Estos fueron los UUIDs originales.
DCE UUIDs del Distributed Computing Environment de la Open Software Foundation (OSF).
Microsoft Identificador globalmente único (GUID) de la plataforma Microsoft Windows.
otra Variante desconocida. Normalmente datos de entrada inválidos.

Tipos

nulo Tipo especial para el cero en el archivo de tipos.
basado en tiempo El tiempo de DCE.
DCE El tiempo y la dirección MAC de DCE.
basado en nombre Hash md5sum de RFC 4122.
aleatorio Aleatorio de RFC 4122.
basado en sha1 Hash sha-1 de RFC 4122.
desconocido Tipo desconocido. Normalmente datos de entrada inválidos.

OPCIONES

-J, --json

Usar formato de salida JSON.

-n, --noheadings

No imprimir una línea de encabezado.

-o, --output

Especificar qué columnas de salida imprimir. Usar --help para obtener una lista de todas las columnas compatibles.

-r, --raw

Usar el formato de salida sin procesar.

-h, --help

Mostrar texto de ayuda y salir.

-V, --version

Mostrar versión y salir.
