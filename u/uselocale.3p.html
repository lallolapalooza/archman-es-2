USELOCALE(3P) Manual del programador POSIX USELOCALE(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

uselocale — usar la configuración regional en el hilo actual

SINOPSIS

#include <locale.h>
locale_t uselocale(locale_t newloc);

DESCRIPCIÓN

La función uselocale() establecerá o consultará la configuración regional actual para el hilo que la llama.

El valor para el argumento newloc será uno de los siguientes:

1.
Un valor devuelto por las funciones newlocale() o duplocale()
2.
El descriptor especial de objeto de configuración regional LC_GLOBAL_LOCALE
3.
(locale_t)0

Si el argumento newloc es (locale_t)0, la configuración regional actual no se modificará; este valor puede usarse para consultar la configuración regional actual. Si el argumento newloc es LC_GLOBAL_LOCALE, cualquier configuración regional específica del hilo para el hilo que llama se desinstalará; el hilo volverá a utilizar la configuración regional global como configuración regional actual, y los cambios en la configuración regional global afectarán al hilo. De lo contrario, la configuración regional representada por newloc se instalará como una configuración regional específica del hilo para ser utilizada como configuración regional actual para el hilo que llama.

Una vez que se haya llamado a la función uselocale() para instalar una configuración regional específica del hilo, el comportamiento de cada interfaz que utilice datos de la configuración regional actual se verá afectado para el hilo que llama. La configuración regional actual para otros hilos no se verá modificada.

VALOR DE RETORNO

Al completarse con éxito, la función uselocale() devolverá un manejador para la configuración regional específica del hilo que estaba en uso como configuración regional actual para el hilo que llama al entrar en la función, o LC_GLOBAL_LOCALE si no se estaba utilizando ninguna configuración regional específica del hilo. De lo contrario, uselocale() devolverá (locale_t)0 y establecerá errno para indicar el error.

ERRORES

La función uselocale() puede fallar si:

EINVAL
newloc no es un objeto de configuración regional válido y no es (locale_t)0.

USO POR LA APLICACIÓN

A diferencia de la función setlocale(), la función uselocale() no permite reemplazar solo algunas categorías de configuración regional. Las aplicaciones que necesiten instalar una configuración regional que difiera solo en algunas categorías deben usar newlocale() para cambiar un objeto de configuración regional equivalente a la configuración regional utilizada actualmente e instalarlo.
