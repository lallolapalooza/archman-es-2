unknown(n) Comandos integrados de Tcl unknown(n)

NOMBRE

unknown - Maneja intentos de usar comandos inexistentes

SINOPSIS

unknown nombreCmd ?arg arg ...?

DESCRIPCIÓN

Este comando es invocado por el intérprete de Tcl cada vez que un script intenta invocar un comando que no existe. La implementación predeterminada de unknown es un procedimiento de biblioteca definido cuando Tcl inicializa un intérprete. Puede anular el unknown predeterminado para cambiar su funcionalidad, o puede registrar un nuevo manejador para espacios de nombres individuales usando el comando namespace unknown. Tenga en cuenta que no hay una implementación predeterminada de unknown en un intérprete seguro.

Si el intérprete de Tcl encuentra un nombre de comando para el cual no hay un comando definido (ni en el espacio de nombres actual, ni en el espacio de nombres global), entonces Tcl verifica la existencia de un manejador de desconocidos para el espacio de nombres actual. Por defecto, este manejador es un comando llamado ::unknown. Si no existe tal comando, el intérprete devuelve un error. Si el comando unknown existe (o se ha registrado un nuevo manejador para el espacio de nombres actual), entonces se invoca con argumentos que consisten en el nombre completamente sustituido y los argumentos del comando inexistente original. El comando unknown típicamente hace cosas como buscar en directorios de bibliotecas un procedimiento de comando con el nombre nombreCmd, o expandir nombres de comandos abreviados a longitud completa, o ejecutar comandos desconocidos automáticamente como subprocesos. En algunos casos (como la expansión de abreviaturas) unknown cambiará ligeramente el comando original y luego (re)ejecutará. El resultado del comando unknown se utiliza como resultado para el comando original inexistente.

La implementación predeterminada de unknown se comporta de la siguiente manera. Primero llama al procedimiento de biblioteca auto_load para cargar el comando. Si esto tiene éxito, ejecuta el comando original con sus argumentos originales. Si la carga automática falla y Tcl se ejecuta interactivamente, entonces unknown llama a auto_execok para ver si hay un archivo ejecutable con el nombre cmd. Si es así, invoca el comando Tcl exec con cmd y todos los args como argumentos. Si cmd no puede ser ejecutado automáticamente, unknown verifica si el comando se invocó en el nivel superior y fuera de cualquier script. Si es así, entonces unknown realiza dos pasos adicionales. Primero, ve si cmd tiene una de las siguientes tres formas: !!, !evento, o ^antiguo^nuevo?^?. Si es así, entonces unknown realiza sustituciones de historial de la misma manera que lo haría csh para estas construcciones. Finalmente, unknown verifica si cmd es una abreviatura única para un comando Tcl existente. Si es así, expande el nombre del comando y ejecuta el comando con los argumentos originales. Si ninguno de los esfuerzos anteriores ha podido ejecutar el comando, unknown genera un error. Si la variable global auto_noload está definida, entonces se omite el paso de carga automática. Si la variable global auto_noexec está definida, entonces se omite el paso de ejecución automática. En circunstancias normales, el valor de retorno de unknown es el valor de retorno del comando que finalmente se ejecutó.

EJEMPLO

Organizar que el comando unknown tenga su comportamiento estándar, excepto por registrar primero el hecho de que no se encontró un comando:

# Guardar el original para poder encadenarlo
rename unknown _original_unknown
# Proporcionar nuestra propia implementación
proc unknown args {
    puts stderr "ADVERTENCIA: comando desconocido: $args"
    uplevel 1 [list _original_unknown {*}$args]
}
