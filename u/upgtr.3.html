subrutina cupgtr (character uplo, integer n, complex, dimension( * ) ap, complex, dimension( * ) tau, complex, dimension( ldq, * ) q, integer ldq, complex, dimension( * ) work, integer info)

CUPGTR

Propósito:

!>
!> CUPGTR genera una matriz unitaria compleja Q que se define como el
!> producto de n-1 reflectores elementales H(i) de orden n, tal como devuelve
!> CHPTRD usando almacenamiento empaquetado:
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U': almacenamiento empaquetado triangular superior utilizado en la
!>                 llamada anterior a CHPTRD;
!>          = 'L': almacenamiento empaquetado triangular inferior utilizado en la
!>                 llamada anterior a CHPTRD.
!>

N

!>          N es INTEGER
!>          El orden de la matriz Q. N >= 0.
!>

AP

!>          AP es un array COMPLEX, dimension (N*(N+1)/2)
!>          Los vectores que definen los reflectores elementales, tal como
!>          devuelve CHPTRD.
!>

TAU

!>          TAU es un array COMPLEX, dimension (N-1)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como devuelve CHPTRD.
!>

Q

!>          Q es un array COMPLEX, dimension (LDQ,N)
!>          La matriz unitaria N por N, Q.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX, dimension (N-1)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detailed Description

ZUPGTR

Purpose:

!>
!> ZUPGTR genera una matriz unitaria compleja Q que se define como el
!> producto de n-1 transformaciones de Householder elementales H(i)
!> de orden n, tal como las devuelve ZHPTRD usando almacenamiento
!> empaquetado:
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U': se usó almacenamiento triangular superior empaquetado en la
!>                 llamada previa a ZHPTRD;
!>          = 'L': se usó almacenamiento triangular inferior empaquetado en la
!>                 llamada previa a ZHPTRD.
!>

N

!>          N es INTEGER
!>          El orden de la matriz Q. N >= 0.
!>

AP

!>          AP es un array COMPLEX*16 de dimensión (N*(N+1)/2)
!>          Los vectores que definen las transformaciones de Householder
!>          elementales, tal como las devuelve ZHPTRD.
!>

TAU

!>          TAU es un array COMPLEX*16 de dimensión (N-1)
!>          TAU(i) debe contener el factor escalar de la transformación de
!>          Householder elemental H(i), tal como la devuelve ZHPTRD.
!>

Q

!>          Q es un array COMPLEX*16 de dimensión (LDQ,N)
!>          La matriz unitaria Q de N por N.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión delantera del array Q. LDQ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16 de dimensión (N-1)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
