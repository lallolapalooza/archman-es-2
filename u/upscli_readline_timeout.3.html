upscli_readline_timeout(3)

Paquete: nut

UPSCLI_READLINE(3) Manual de NUT UPSCLI_READLINE(3)

NOMBRE

upscli_readline, upscli_readline_timeout - Leer una única respuesta de una UPS

SINOPSIS

        #include <upsclient.h>
        #include <time.h> /* o <sys/time.h> en algunas plataformas */
        int upscli_readline(UPSCONN_t *ups, char *buf, size_t buflen);
        int upscli_readline_timeout(UPSCONN_t *ups, char *buf, size_t buflen,
                const time_t timeout);

DESCRIPCIÓN

Las funciones upscli_readline() y upscli_readline_timeout() toman el puntero ups a una estructura de estado UPSCONN_t, reciben una única línea del servidor y copian hasta buflen bytes de la respuesta al búfer buf.

Ocurre cierto análisis de la cadena durante la recepción. En particular, se detectan los mensajes ERR de upsd(8) y esto hará que esta función devuelva -1.

La diferencia entre las dos funciones es que upscli_readline_timeout() permite al llamador decidir la cantidad de tiempo (timeout segundos) después de la cual debe rendirse y devolver, mientras que upscli_readline() no ofrece esta libertad y utiliza el tiempo de espera de red predeterminado de NUT (5 segundos).

VALOR DE RETORNO

Las funciones upscli_readline() y upscli_readline_timeout() devuelven 0 si tienen éxito o -1 si ocurre un error.
