NOMBRE

umoci remove - Elimina etiquetas de imágenes OCI

SINOPSIS

umoci remove --image=imagen[:etiqueta]

umoci rm --image=imagen[:etiqueta]

DESCRIPCIÓN

Elimina la etiqueta dada de la imagen OCI. Los blobs relevantes no se eliminan; para eliminar todos los blobs no utilizados, consulta umoci-gc(1).

OPCIONES

--image=imagen[:etiqueta]
La etiqueta de la imagen OCI de origen a eliminar. imagen debe ser una ruta a una imagen OCI
válida y etiqueta debe ser un nombre de etiqueta válido (umoci-remove(1) no devuelve
un error si la etiqueta no existía). Si no se proporciona etiqueta, se utiliza
"latest" por defecto.

EJEMPLO

Lo siguiente crea una copia de una etiqueta y luego elimina la original.

% umoci tag --image imagen:etiqueta nueva-etiqueta
% umoci rm --image imagen:etiqueta

VER TAMBIÉN

umoci(1), umoci-tag(1), umoci-gc(1)
