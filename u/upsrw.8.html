UPSRW(8) Manual de NUT UPSRW(8)

NOMBRE

upsrw - Herramienta de administración de variables de dispositivo/controlador NUT (Network UPS Tools)

SINOPSIS

upsrw [-l] ups

upsrw -h

upsrw -s variable [-u nombredeusuario] [-p contraseña] [-w] [-t <tiempo_espera>] ups

DESCRIPCIÓN

upsrw le permite ver y cambiar las variables de lectura/escritura dentro de su UPS. Envía comandos a través del servidor upsd(8) a su controlador, que configura el hardware para usted. Debe usar credenciales definidas en el archivo upsd.users(5) en ese servidor de datos con los permisos apropiados.

La lista de variables que le permiten cambiar sus valores se basa en las capacidades de su equipo UPS. No todos los modelos admiten esta función. Típicamente, el hardware más barato no admite ninguna de ellas. Ejecute upsrw con un identificador de UPS para ver qué funcionará para usted.

OPCIONES

-s variable

Especifique la variable que se va a cambiar dentro de la UPS. Para modo desatendido, como en scripts de shell, use el formato VAR=VALOR para especificar tanto la variable como el valor, por ejemplo: 
-s input.transfer.high=129

Sin este argumento, upsrw simplemente mostrará la lista de variables y sus posibles valores.

Algunas variables son cadenas de texto y se pueden establecer en cualquier valor dentro del límite de longitud. Otras son tipos enumerados y solo se pueden establecer en uno de esos valores. Otras pueden estar dentro de un rango de valores permitido. Consulte la lista para saber qué está disponible en su hardware.

-l

Simplemente muestre la lista de variables y sus posibles valores.

Igual que la actividad predeterminada sin el argumento -s, proporcionado para la similitud de CLI con otras herramientas.

-u nombredeusuario

Establezca el nombre de usuario de NUT para la conexión al servidor. Esto es opcional y se le pedirá cuando use la opción -s si no especifica -u en la línea de comandos. Los nombres de usuario de NUT se definen en upsd.users(5) y no están vinculados a nombres de usuario del sistema.

-p contraseña

Establezca la contraseña para autenticarse en el servidor. Esto también es opcional como -u, y se le pedirá si es necesario.

-w

Espere a que se complete la ejecución de la configuración por parte del controlador y devuelva su resultado real del dispositivo. Tenga en cuenta que esta función requiere que tanto upsd(8) como el controlador admitan TRACKING (versión de NUT 2.8.0 o superior), o fallará de lo contrario.

El comando también se bloqueará hasta que se proporcione un resultado real del controlador, o se alcance el tiempo de espera (ver -t).

-t segundos

Establezca un tiempo de espera al usar -w. Por defecto son 10 segundos.

ups

Ver o cambiar la configuración en esta UPS. El formato para esta opción es upsname[@hostname[:puerto]]. El nombre de host predeterminado es "localhost".

OPCIONES COMUNES

-h

Mostrar el mensaje de ayuda de la línea de comandos.

-V

Mostrar el banner de la versión de NUT. Puede haber más detalles disponibles si también exporta NUT_DEBUG_LEVEL=1 o un nivel de verbosidad mayor.

-W secs

Establezca el tiempo de espera para las conexiones de red iniciales (por defecto son indefinidamente no bloqueantes, o hasta que el sistema interrumpa el intento). Anula la variable de entorno opcional NUT_DEFAULT_CONNECT_TIMEOUT.

MODO DESATENDIDO

Si ejecuta este programa dentro de un script de shell o similar para establecer variables, deberá especificar toda la información en la línea de comandos. Esto significa usar -s VAR=VALOR, -u y -p. De lo contrario, presentará un aviso y su programa se colgará.

Esto no es necesario al mostrar la lista, ya que el nombre de usuario y la contraseña no son necesarios para el modo de solo lectura.

Además, si ejecuta este programa dentro de un script de shell o similar, solo debe considerar usar la salida de stdout, no stderr.

DIAGNÓSTICO

upsrw no puede establecer variables en su UPS a menos que proporcione un nombre de usuario y una contraseña válidos. Si recibe errores de "acceso denegado", asegúrese de que su upsd.users(5) tenga una entrada para usted y que el nombre de usuario que está utilizando tenga permisos para ESTABLECER variables.

upsrw sin -w mostraría de manera algo confusa "OK", lo que significa solo que se estableció la conexión con el servidor de datos y que el servidor no rechazó inmediatamente la solicitud debido, por ejemplo, a un nombre de variable de controlador desconocido. Si desea conocer los resultados reales, use las opciones -w (-t NUM) para esperar a que se proporcionen.

FORMATO VALOR

Al usar upsrw para modificar un valor numérico flotante, los valores deben proporcionarse utilizando una representación decimal (base 10) en inglés, es decir, usando un punto, en notación no científica. Por lo tanto, están prohibidos los formatos hexadecimales, los exponentes y la coma como separador de miles.

Por ejemplo: "1200.20" es válido, mientras que "1,200.20" y "1200,20" no lo son.
