uu-stdbuf(1) Manual de Comandos Generales uu-stdbuf(1)

NOMBRE

uu-stdbuf - Ejecuta COMANDO, con operaciones de búfer modificadas para sus flujos estándar.

Los argumentos obligatorios para las opciones largas son obligatorios también para las opciones cortas.

SINOPSIS

uu-stdbuf [-i|--input] [-o|--output] [-e|--error] [-h|--help] [-V|--version] <comando>

DESCRIPCIÓN

Ejecuta COMANDO, con operaciones de búfer modificadas para sus flujos estándar.

Los argumentos obligatorios para las opciones largas son obligatorios también para las opciones cortas.

OPCIONES

-i, --input <MODO>
ajusta el búfer del flujo de entrada estándar
-o, --output <MODO>
ajusta el búfer del flujo de salida estándar
-e, --error <MODO>
ajusta el búfer del flujo de error estándar
-h, --help
Imprime la ayuda
-V, --version
Imprime la versión

EXTRA

Si MODO es 'L' el flujo correspondiente será de línea con búfer. Esta opción no es válida con la entrada estándar.

Si MODO es '0' el flujo correspondiente no tendrá búfer.

De lo contrario, MODO es un número que puede ir seguido de una de las siguientes opciones:

KB 1000, K 1024, MB 1000*1000, M 1024*1024, y así sucesivamente para G, T, P, E, Z, Y. En este caso, el flujo correspondiente tendrá búfer completo con el tamaño del búfer establecido en MODE bytes.

NOTA: Si COMANDO ajusta el búfer de sus flujos estándar (tee lo hace por ejemplo) entonces eso anulará las configuraciones correspondientes cambiadas por stdbuf. También algunos filtros (como dd y cat etc.) no usan flujos para E/S, y por lo tanto no se ven afectados por la configuración de stdbuf.
