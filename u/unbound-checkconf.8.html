NOMBRE

unbound-checkconf - Comprueba el archivo de configuración de Unbound 1.24.2 en busca de errores.

SINOPSIS

unbound-checkconf [-hf] [-o opción] [archivo_conf]

DESCRIPCIÓN

unbound-checkconf comprueba el archivo de configuración del resolver DNS unbound(8) en busca de errores de sintaxis y otros.

Las opciones disponibles son:

-h
Muestra la versión y la ayuda de las opciones de la línea de comandos.
-f
Imprime la ruta completa, con el chroot aplicado. Usar con la opción -o.
-q
Silencia la operación, suprimiendo la salida en caso de éxito.
-o <opción>
Si se proporciona, después de comprobar el archivo de configuración, el valor de esta opción se imprimirá en stdout. Para las opciones deshabilitadas (""), se imprimirá una línea vacía.
archivo_conf
El archivo de configuración a leer con los ajustes para Unbound. Se comprobará. Si se omite, se comprobará el archivo de configuración en la ubicación predeterminada.

CÓDIGO DE SALIDA

El programa unbound-checkconf sale con el código de estado 1 en caso de error, 0 para un archivo de configuración correcto.

ARCHIVOS

/etc/unbound/unbound.conf
Archivo de configuración de Unbound.

VER TAMBIÉN

unbound.conf(5), unbound(8).
