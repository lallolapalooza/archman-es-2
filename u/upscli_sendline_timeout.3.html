upscli_sendline_timeout(3)

Paquete: nut

Licencias: GPL-2.0-or-later AND GPL-3.0-or-later

UPSCLI_SENDLINE(3) Manual de NUT UPSCLI_SENDLINE(3)

NOMBRE

upscli_sendline, upscli_sendline_timeout - Enviar un comando único a una UPS

SINOPSIS

        #include <upsclient.h>
        #include <time.h> /* o <sys/time.h> en algunas plataformas */
        int upscli_sendline(UPSCONN_t *ups, const char *buf, size_t buflen);
        int upscli_sendline_timeout(UPSCONN_t *ups, const char *buf, size_t buflen,
                const time_t timeout);

DESCRIPCIÓN

Las funciones upscli_sendline() y upscli_sendline_timeout() toman el puntero ups a una estructura de estado UPSCONN_t y transmiten un búfer buf de tamaño buflen al servidor.

Los datos en buf deben ser un comando de protocolo completamente formateado, ya que esta función no realiza ningún análisis del búfer.

La diferencia entre las dos funciones es que upscli_sendline_timeout() permite al llamante decidir el tiempo (timeout segundos) después del cual debe rendirse y retornar, mientras que upscli_sendline() no ofrece esta libertad y utiliza un tiempo de espera inmediato (0 segundos).

VALOR DE RETORNO

Las funciones upscli_sendline() y upscli_sendline_timeout() retornan 0 en caso de éxito, o -1 si ocurre un error.
