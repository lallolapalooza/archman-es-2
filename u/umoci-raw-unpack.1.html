NOMBRE

umoci raw unpack - Desempaqueta una etiqueta de imagen OCI en un sistema de archivos raíz

SINOPSIS

umoci raw unpack [banderas de umoci-unpack(1)] sistema_archivos_raiz

DESCRIPCION

Extrae todas las capas (de forma determinista) a un sistema de archivos raíz en la ruta sistema_archivos_raiz. Esta ruta no debe existir previamente.

OPCIONES

Las opciones globales se definen en umoci(1), mientras que las opciones para este subcomando en particular son idénticas a umoci-unpack(1) con la excepción de que se proporciona la ruta sistema_archivos_raiz en lugar de una ruta de bundle.

EJEMPLO

Lo siguiente descarga una imagen de un registro de docker(1) usando skopeo(1), desempaqueta dicha imagen en un sistema de archivos raíz, genera un archivo de configuración de tiempo de ejecución OCI con umoci-raw-runtime-config(1) y luego crea un nuevo contenedor con runc(8).

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
# umoci raw unpack --image image rootfs
# umoci raw runtime-config --image image --rootfs rootfs config.json
# runc run ctr
[ sesión de contenedor ]

Con --rootless también es posible realizar el ejemplo anterior sin privilegios de root. umoci generará una configuración que funciona con contenedores sin root en runc(8).

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
% umoci raw unpack --image image --rootless rootfs
% umoci raw runtime-config --image image --rootfs rootfs --rootless config.json
% runc --root $HOME/runc run ctr
[ sesión de contenedor sin root ]

VER TAMBIÉN

umoci(1), umoci-raw-runtime-config(1), runc(8)

umoci raw
