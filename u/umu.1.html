umu(1) Manual de Comandos Generales umu(1)

NOMBRE

umu-run - Lanzador Unificado para Juegos de Windows en Linux

SINOPSIS

umu-run [ARCHIVO]

umu-run [ARCHIVO [ARG...]]

umu-run [winetricks [ARG...]]

umu-run --config [ARCHIVO]

umu-run --help

ARGUMENTOS POSICIONALES

winetricks

Ejecuta verbos de winetricks[1] (Requiere GE-Proton o UMU-Proton).

Consulta winetricks(1) para más información o abajo para un ejemplo.

OPCIONES

-h, --help

Muestra este mensaje de ayuda.

--config <config>

Ruta al archivo de configuración TOML (Requiere Python 3.11+).

Consulta umu(5) para más información y ejemplos.

DESCRIPCIÓN

El Lanzador Unificado para Juegos de Windows en Linux (umu) fue creado para hacer accesible el Proton[2] de Valve y el proyecto protonfixes[3] fuera del cliente Steam, proporcionando una forma estandarizada para que otros clientes (por ejemplo, Lutris, Heroic Games Launcher, Bottles o Rare) ejecuten juegos a través de Proton y configuren prefijos de WINE.

Como resultado, los clientes:

  • Ya no requieren la instalación de Steam o binarios de Steam
  • Pueden contribuir y beneficiarse automáticamente de protonfixes
  • Pueden ejecutar juegos a través de Proton como si fuera un juego nativo de Steam
  • Pueden hacer referencia a una base de datos unificada en línea de correcciones de juegos (protonfixes)

Puedes ejecutar umu directamente desde un emulador de terminal, o a través de tu lanzador de elección si es compatible.

EJEMPLOS

Ejemplo 1. Ejecutar un juego

$ WINEPREFIX=~/.wine PROTONPATH=~/GE-Proton9-4 umu-run foo.exe

Ejemplo 2. Ejecutar un juego y aplicar un protonfix específico

# Aplica la corrección de Star Citizen al prefijo WINE actual
$ WINEPREFIX=~/.wine GAMEID=umu-starcitizen PROTONPATH=~/GE-Proton9-4 umu-run foo.exe

Ejemplo 3. Ejecutar un juego a través de un archivo de configuración

# config.toml
[umu]
prefix = "~/.wine"
proton = "~/GE-Proton30"
game_id = "0"
exe = "~/foo.exe"
launch_args = ["-opengl", "-SkipBuildPatchPrereq"]
store = "gog"
$ umu-run --config config.toml

Ejemplo 4. Crear un prefijo WINE de umu

$ WINEPREFIX=~/foo PROTONPATH=~/GE-Proton9-4 umu-run ""

Ejemplo 5. Ejecutar un juego y establecer automáticamente Proton

# Utiliza el último UMU-Proton y elimina automáticamente las compilaciones
# antiguas de UMU-Proton
$ WINEPREFIX=~/.wine umu-run foo.exe

Ejemplo 6. Ejecutar un juego y crear automáticamente un prefijo WINE

# Crea el prefijo como $HOME/Games/umu/umu-default y utiliza el último
# UMU-Proton
$ umu-run foo.exe

Ejemplo 7. Ejecutar un juego y establecer explícitamente un verbo de Proton válido

$ WINEPREFIX=~/.wine GAMEID=0 PROTONPATH=~/GE-Proton9-4 PROTON_VERB=waitforexitandrun umu-run foo.exe

Ejemplo 8. Ejecutar un juego y habilitar registros de depuración

$ UMU_LOG=debug WINEPREFIX=~/.wine PROTONPATH=~/GE-Proton9-4 umu-run foo.exe

Ejemplo 9. Ejecutar un juego y establecer un Proton por su nombre de versión

# Busca GE-Proton9-1 en $HOME/.local/share/Steam/compatibilitytools.d
$ WINEPREFIX=~/.wine PROTONPATH=GE-Proton9-1 umu-run foo.exe

Ejemplo 10. Ejecutar un juego y utilizar automáticamente el último GE-Proton

$ WINEPREFIX=~/.wine PROTONPATH=GE-Proton umu-run foo.exe

Ejemplo 11. Ejecutar verbos de winetricks

$ PROTONPATH=GE-Proton umu-run winetricks quartz wmp11 qasf

Ejemplo 12. Ejecutar un juego, pero no aplicar protonfixes

$ GAMEID=umu-genshin PROTONPATH=GE-Proton PROTONFIXES_DISABLE=1 umu-run foo.exe

VARIABLES DE ENTORNO

GAMEID

Opcional. Puede ser un valor arbitrario o un id válido en la umu-database[4]. Si no se establece, el valor predeterminado es umu-default (no aplica ninguna corrección automáticamente).

PROTONPATH

Opcional. Ruta a un directorio de Proton, nombre de versión (por ejemplo, GE-Proton9-5) o nombre en clave (por ejemplo, GE-Proton).

De lo contrario, el valor predeterminado es usar UMU-Proton.

Los nombres en clave válidos incluyen: GE-Proton

WINEPREFIX

Opcional. Ruta a un directorio de prefijo WINE. De lo contrario, el valor predeterminado es $HOME/Games/umu/$GAMEID. Si no se establece GAMEID, el valor predeterminado es $HOME/Games/umu/umu-default.

UMU_LOG

Opcional. Habilita los registros de depuración para el lanzador.

Establecer en 1 para habilitar todos los registros.

STORE

Opcional. Puede ser un valor arbitrario o un id de tienda válido en la umu-database.

PROTON_VERB

Opcional. Debe ser un verbo de Proton válido. De lo contrario, el valor predeterminado es waitforexitandrun.

UMU_RUNTIME_UPDATE

Opcional. Deshabilita las actualizaciones automáticas del Steam Linux Runtime[5].

Establecer en 0 para deshabilitar las actualizaciones.

UMU_NO_PROTON

Opcional. Ejecuta el ejecutable de forma nativa dentro del Steam Linux Runtime. Previsto para juegos nativos de Linux.

Establecer en 1 para ejecutar el ejecutable de forma nativa dentro del SLR.

UMU_HTTP_TIMEOUT

Opcional. Establece el tiempo de espera, en segundos, para cada solicitud HTTP. De lo contrario, el valor predeterminado es 5.

Establecer en 0 para deshabilitar tiempos de espera para solicitudes HTTP. Establecer un entero positivo para anular el valor predeterminado.

UMU_HTTP_RETRIES

Opcional. Número de veces que se reintentarán errores de red posiblemente espurios. De lo contrario, el valor predeterminado es 3.

Establecer en 0 para deshabilitar reintentos para solicitudes HTTP. Establecer un entero positivo para anular el valor predeterminado.
