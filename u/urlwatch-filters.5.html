NOMBRE

urlwatch-filters - Filtrar la salida y los datos de diferencia de los trabajos de urlwatch

SINOPSIS

urlwatch --edit

DESCRIPCIÓN

Cada trabajo puede tener dos etapas de filtrado configuradas, con uno o más filtros procesados uno tras otro:

  • Aplicado a la página descargada antes de diferenciar los cambios (filter)
  • Aplicado al resultado de la diferencia antes de informar los cambios (diff_filter)

Mientras crea su canalización de filtros, puede que desee previsualizar cómo se ve la salida filtrada. Puede hacerlo configurando primero su trabajo y luego ejecutando urlwatch con el comando --test-filter, pasando el índice (desde --list) o la URL/ubicación del trabajo a probar:

urlwatch --test-filter 1   # Probar el primer trabajo de la lista
urlwatch --test-filter https://example.net/  # Probar el trabajo con la URL dada

La salida de este comando será el texto plano filtrado del trabajo; esta es la salida que (en una ejecución real de urlwatch) será la entrada para el algoritmo de diferencia.

El filter solo se aplica al contenido nuevo; el contenido antiguo ya fue filtrado cuando se recuperó. Esto significa que los cambios en filter no son visibles al informar contenido sin cambios (ver Display para más detalles), y la salida de la diferencia será entre (contenido antiguo con el filtro en el momento en que se recuperó el contenido antiguo) y (contenido nuevo con el filtro actual).

Una vez que urlwatch haya recopilado al menos 2 instantáneas históricas de un trabajo (dos estados diferentes de una página web), puede usar la opción de línea de comandos --test-diff-filter para probar la configuración de su diff_filter; esto utilizará datos históricos almacenados en caché localmente.

FILTROS INTEGRADOS

La lista de filtros integrados se puede recuperar usando:

urlwatch --features

En este momento, los siguientes filtros están integrados:

  • beautify: Embellecer HTML
  • css: Filtrar XML/HTML usando selectores CSS
  • csv2text: Convertir CSV a texto plano
  • element-by-class: Obtener todos los elementos HTML por clase
  • element-by-id: Obtener un elemento HTML por su ID
  • element-by-style: Obtener todos los elementos HTML por estilo
  • element-by-tag: Obtener un elemento HTML por su etiqueta
  • format-json: Convertir a JSON formateado
  • grep: Filtrar solo líneas que coincidan con una expresión regular
  • grepi: Eliminar líneas que coincidan con una expresión regular
  • hexdump: Convertir datos binarios a formato de volcado hexadecimal
  • html2text: Convertir HTML a texto plano
  • pdf2text: Convertir PDF a texto plano
  • pretty-xml: Imprimir XML de forma bonita
  • ical2text: Convertir iCalendar https://es.wikipedia.org/wiki/ICalendar a texto plano
  • ocr: Convertir texto en imágenes a texto plano usando Tesseract OCR
  • re.sub: Reemplazar texto con expresiones regulares usando re.sub de Python
  • re.findall: Encontrar todas las coincidencias no superpuestas usando re.findall de Python
  • reverse: Invertir elementos de entrada
  • sha1sum: Calcular la suma de verificación SHA-1 del contenido
  • shellpipe: Filtrar usando un comando de shell
  • sort: Ordenar elementos de entrada
  • remove-duplicate-lines: Eliminar líneas duplicadas (sensible a mayúsculas/minúsculas)
  • strip: Eliminar espacios en blanco al principio y al final
  • striplines: Eliminar espacios en blanco al principio y al final en cada línea
  • xpath: Filtrar XML/HTML usando expresiones XPath
  • jq: Filtrar, transformar y extraer valores de JSON

SELECCIONAR ELEMENTOS DE UNA PÁGINA WEB

Puede seleccionar solo un elemento HTML dado con el filtro integrado, por ejemplo, para extraer <div id="algo">.../<div> de una página, puede usar lo siguiente en su urls.yaml:

url: http://example.org/idtest.html
filter:
  - element-by-id: algo

Además, puede encadenar filtros, por lo que puede ejecutar html2text sobre el resultado:

url: http://example.net/id2text.html
filter:
  - element-by-id: algo
  - html2text

ENCADENAR MÚLTIPLES FILTROS

El archivo de ejemplo urls.yaml también demuestra el uso de filtros integrados, aquí se usan 3 filtros: html2text, line-grep y eliminación de espacios en blanco para obtener solo un campo de información específico de una página web:

url: https://example.net/version.html
filter:
  - html2text
  - grep: "Versión.*actual"
  - strip

EXTRAER SOLO LA ETIQUETA <BODY> DE UNA PÁGINA

Si desea extraer solo la etiqueta del cuerpo, puede usar este filtro:

url: https://example.org/bodytag.html
filter:
  - element-by-tag: body

FILTRAR BASADO EN UNA EXPRESIÓN XPATH

Para filtrar basándose en una expresión XPath https://www.w3.org/TR/1999/REC-xpath-19991116/, puede usar el filtro xpath de esta manera:

url: https://example.net/xpath.html
filter:
  - xpath: /html/body/marquee

Esto filtra solo los elementos <marquee> directamente debajo del elemento <body>, que a su vez debe estar debajo del elemento <html> del documento, eliminando todo lo demás.

Vea la página XPath Examples de Microsoft https://msdn.microsoft.com/en-us/library/ms256086(v=vs.110).aspx para algunos otros ejemplos. También puede encontrar un XPath de un nodo <html> en las herramientas de desarrollador de Chromium/Google Chrome haciendo clic derecho sobre el nodo y seleccionando copiar XPath.

FILTRAR BASADO EN SELECTORES CSS

Para filtrar basándose en un selector CSS https://www.w3.org/TR/2011/REC-css3-selectors-20110929/, puede usar el filtro css de esta manera:

url: https://example.net/css.html
filter:
  - css: ul#groceries > li.unchecked

Esto filtraría solo las etiquetas <li class="unchecked"> directamente debajo de los elementos <ul id="groceries">.

Existen algunas limitaciones y extensiones, como se explica en la documentación de cssselect https://cssselect.readthedocs.io/en/latest/#supported-selectors.

USAR XPATH Y CSS FILTROS CON XML Y EXCLUSIONES

Por defecto, los filtros XPath y CSS están configurados para documentos HTML. Sin embargo, es posible usarlos también para documentos XML (estos ejemplos analizan un feed RSS y filtran solo los títulos y las fechas de publicación):

url: https://example.com/blog/xpath-index.rss
filter:
  - xpath:
      path: '//item/title/text()|//item/pubDate/text()'
      method: xml
url: http://example.com/blog/css-index.rss
filter:
  - css:
      selector: 'item > title, item > pubDate'
      method: xml
  - html2text: re

Para hacer coincidir un elemento en un espacio de nombres XML https://www.w3.org/TR/xml-names/, use un prefijo de espacio de nombres antes del nombre de la etiqueta. Use un : para separar

GESTIÓN DE ESPACIOS DE NOMBRES

You can use namespace prefixes in XPath expressions and the | character in CSS selectors. You can use namespace prefixes in XPath expressions and the | character in CSS selectors.

url: https://example.net/feed/xpath-namespace.xml
filter:
  - xpath:
      path: '//item/media:keywords/text()'
      method: xml
      namespaces:
        media: http://search.yahoo.com/mrss/
url: http://example.org/feed/css-namespace.xml
filter:
  - css:
      selector: 'item > media|keywords'
      method: xml
      namespaces:
        media: http://search.yahoo.com/mrss/
  - html2text

Alternatively, use the XPath expression //*[name()='<tag_name>'] to bypass the namespace entirely.

Another useful option with XPath and CSS filters is exclude. Elements selected by this exclude expression are removed from the final result. For example, the following job will not have any <a> tag in its results:

url: https://example.org/css-exclude.html
filter:
  - css:
      selector: body
      exclude: a

LIMITANDO LOS ELEMENTOS DEVUELTOS POR UN SELECTOR CSS O XPATH

If you only want to return a subset of the items returned by a CSS selector or XPath filter, you can use two additional subfilters:

  • skip: How many elements to skip from the beginning (default: 0)
  • maxitems: How many elements to return at most (default: no limit)

For example, if the page has multiple elements, but you only want to select the second and third matching element (skip the first, and return at most two elements), you can use this filter:

url: https://example.net/css-skip-maxitems.html
filter:
  - css:
      selector: div.cpu
      skip: 1
      maxitems: 2

Gestionando resultados duplicados

If you get multiple results on one page, but you only expected one (e.g. because the page contains both a mobile and desktop version in the same HTML document, and shows/hides one via CSS depending on the viewport size), you can use maxitems: 1 to only return the first item.

CORRIGIENDO REORDENAMIENTOS DE LISTAS CON FILTROS DE SELECTOR CSS O XPATH

In some cases, the ordering of items on a webpage might change regularly without the actual content changing. By default, this would show up in the diff output as an element being removed from one part of the page and inserted in another part of the page.

In cases where the order of items doesn't matter, it's possible to sort matched items lexicographically to avoid spurious reports when only the ordering of items changes on the page.

The subfilter for css and xpath filters is sort, and can be true or false (the default):

url: https://example.org/items-random-order.html
filter:
  - css:
      selector: span.item
      sort: true

FILTRADO DE DOCUMENTOS PDF

To monitor the text of a PDF file, you use the pdf2text filter. It requires the installation of the pdftotext https://github.com/jalan/pdftotext/blob/master/README.md#pdftotext library and any of its OS-specific dependencies https://github.com/jalan/pdftotext/blob/master/README.md#os-dependencies.

This filter must be the first filter in a chain of filters, since it consumes binary data and outputs text data.

url: https://example.net/pdf-test.pdf
filter:
  - pdf2text
  - strip

If the PDF file is password protected, you can specify its password:

url: https://example.net/pdf-test-password.pdf
filter:
  - pdf2text:
      password: urlwatchsecret
  - strip

GESTIÓN DE ENTRADAS CSV

The csv2text filter can be used to turn CSV data to a prettier textual representation This is done by supplying a format_string which is a python format string https://docs.python.org/3/library/string.html#format-string-syntax.

If the CSV has a header, the format string should use the header names lowercased. For example, let's say we have a CSV file containing data like this:

Name;Company
Smith;Initech
Doe;Initech

A possible format string for the above CSV (note the lowercase keys):

Mr {name} works at {company}

If there is no header row, you will need to use the numeric array notation:

Mr {0} works at {1}

You can force the use of numeric indices with the flag ignore_header.

The key has_header can be used to force use the first line or first ignore the first line as header, otherwise csv.Sniffer https://docs.python.org/3/library/csv.html#csv.Sniffer will be used.

ORDENACIÓN DEL CONTENIDO DE LA PÁGINA WEB

Sometimes a web page can have the same data between comparisons but it appears in random order. If that happens, you can choose to sort before the comparison.

url: https://example.net/sorting.txt
filter:
  - sort

The sort filter takes an optional separator parameter that defines the item separator (by default sorting is line-based), for example to sort text paragraphs (text separated by an empty line):

url: http://example.org/paragraphs.txt
filter:
  - sort:
      separator: "\n\n"

This can be combined with a boolean reverse option, which is useful for sorting and reversing with the same separator (using % as separator, this would turn 3%2%4%1 into 4%3%2%1):

url: http://example.org/sort-reverse-percent.txt
filter:
  - sort:
      separator: '%'
      reverse: true

INVERSIÓN DE LÍNEAS O ELEMENTOS SEPARADOS

To reverse the order of items without sorting, the reverse filter can be used. By default it reverses lines:

url: http://example.com/reverse-lines.txt
filter:
  - reverse

This behavior can be changed by using an optional separator string argument (e.g. items separated by a pipe (|) symbol, as in 1|4|2|3, which would be reversed to 3|2|4|1):

url: http://example.net/reverse-separator.txt
filter:
  - reverse: '|'

Alternatively, the filter can be specified more verbose with a dict. In this example "\n\n" is used to separate paragraphs (items that are separated by an empty line):

url: http://example.org/reverse-paragraphs.txt
filter:
  - reverse:
      separator: "\n\n"

SEGUIMIENTO DE PUBLICACIONES DE GITHUB Y ETIQUETAS DE GITLAB

This is an example how to watch the GitHub “releases” page for a given project for the latest release version, to be notified of new releases:

url: https://github.com/tulir/gomuks/releases
filter:
  - xpath:
      path: //*[@class="Link--primary Link"]
      maxitems: 1
  - html2text:

This is the corresponding version for Github tags:

url: https://github.com/thp/urlwatch/tags
filter:
  - xpath:
      path: //*[@class="Link--primary Link"]
      maxitems: 1
  - html2text:

and for Gitlab tags:

url: https://gitlab.com/chinstrap/gammastep/-/tags
filter:
  - xpath: (//a[contains(@class,"item-title ref-name")])[1]
  - html2text

Alternatively, jq can be used for filtering:

url: https://api.github.com/repos/voxpupuli/puppet-rundeck/tags
filter:
  - jq: '.[0].name'

BUSCAR, ELIMINAR O REEMPLAZAR TEXTO USANDO EXPRESIONES REGULARES

You can use re.sub and re.findall to apply regular expressions.

re.sub can be used to remove or replace all non-overlapping instances of matched text. The following example applies the filter 3 times:

1.
Just specifying a string as the value will replace the matches with the empty string.
2.
Simple patterns can be replaced with another string using “pattern” as the expression and “repl” as the replacement.
3.
You can use groups (()) and back-reference them with \1 (etc..) to put groups into the replacement string.

repl defaults to the empty string, which will remove matched strings.

url: https://example.com/regex-substitute.html
filter:
    - re.sub: '\s*href="[^"]*"'
    - re.sub:
        pattern: '<h1>'
        repl: '
'

Example with groups:

url: https://example.com/regex-groups.html
filter:
  - re.sub:
      pattern: '([a-z]+)-([0-9]+)'
      repl: '\2.\1'

Using re.findall is useful for extracting data. The filter will return a list of all non-overlapping matches. By default it returns strings.

url: https://example.com/regex-findall.html
filter:
  - re.findall: '[0-9]+'

If you want to return tuples of captured groups, you can use the group parameter:

url: https://example.com/regex-findall-groups.html
filter:
  - re.findall:
      pattern: '([a-z]+)-([0-9]+)'
      group: true
- re.sub: pattern: '<[^>]+>' repl: '' - re.sub: pattern: '<END OF TAG [^>]*>' repl: '' - re.sub: pattern: '^HEADING 1: ' repl: 'EN TÊTÉ 1: ' - re.sub: pattern: '</([^>]*)>' repl: '<FIN DE BALISE \1>' ```

re.findall se puede usar para encontrar todas las coincidencias no superpuestas de una expresión regular. Cada coincidencia se genera en su propia línea. El siguiente ejemplo aplica el filtro dos veces:

1.
Utiliza un grupo (()) y una referencia posterior (\1) para extraer una fecha de la cadena de entrada.
2.
Divide los números de la fecha en líneas separadas.

Si repl no se especifica, la coincidencia completa se incluirá en la salida.

url: https://example.com/regex-findall.html
filter:
    - re.findall:
        pattern: 'La próxima extracción es el (\d{4}-\d{2}-\d{2}).'
        repl: '\1'
    - re.findall: '\d+'

Nota: Al usar HTML o XML, generalmente es mejor usar selectores CSS o expresiones XPATH. HTML y XML *no se pueden analizar* https://stackoverflow.com/a/1732454/1047040 correctamente usando expresiones regulares. Si el selector CSS o XPATH no puede proporcionar la selección dirigida requerida, usar un filtro html2text primero y luego usar re.findall puede ser un buen patrón.

Si desea habilitar indicadores (por ejemplo, re.MULTILINE) en los filtros re.sub o re.findall, use un "indicador en línea", aquí hay algunos ejemplos:

  • re.MULTILINE: (?m) (Hace que ^ coincida con el inicio de la línea y $ con el final de la línea)
  • re.DOTALL: (?s) (Hace que . también coincida con un salto de línea)
  • re.IGNORECASE: (?i) (Realiza una coincidencia sin distinción entre mayúsculas y minúsculas)

Esto le permite, por ejemplo, eliminar todos los espacios iniciales (solo caracteres de espacio y tabulación):

url: http://example.com/leading-spaces.txt
filter:
  - re.sub: '(?m)^[ \t]*'

USO DE UN SCRIPT DE SHELL COMO FILTRO

Si bien los filtros integrados son potentes para procesar marcado como HTML y XML, en algunos casos es posible que ya sepa cómo filtraría su contenido usando un comando de shell o un script de shell. El filtro shellpipe le permite iniciar un shell y ejecutar comandos personalizados para filtrar el contenido.

Los datos de texto que se filtrarán se escribirán en la entrada estándar (stdin) del proceso del shell y la salida del filtro se tomará de la salida estándar (stdout) del shell.

Por ejemplo, si desea utilizar la herramienta grep con la opción de coincidencia insensible a mayúsculas y minúsculas (-i) y que solo imprima la parte coincidente de la línea (-o), puede especificarlo como un filtro shellpipe:

url: https://example.net/shellpipe-grep.txt
filter:
  - shellpipe: "grep -i -o 'precio: <span>.*</span>'"

Esta característica también le permite usar comandos de una sola línea de sed(1), awk(1) y perl(1) para el procesamiento de texto (por supuesto, se puede usar cualquier herramienta de texto que funcione en un shell). Por ejemplo, este comando de una sola línea de awk(1) antepone el número de línea a cada línea:

url: https://example.net/shellpipe-awk-oneliner.txt
filter:
  - shellpipe: awk '{ print FNR " " $0 }'

También puede usar un comando multilínea para un script de shell más sofisticado (| en YAML denota el inicio de un bloque de texto):

url: https://example.org/shellpipe-multiline.txt
filter:
  - shellpipe: |
      NOMBRE_ARCHIVO=`mktemp`
      # Copia la entrada a un archivo temporal, luego canalízala a través de awk
      tee $NOMBRE_ARCHIVO | awk '/Los números para (.*) son:/,/La próxima extracción es el (.*)./'
      # Analiza el archivo de entrada de alguna otra manera
      echo "Líneas de entrada: $(wc -l $NOMBRE_ARCHIVO | awk '{ print $1 }')"
      rm -f $NOMBRE_ARCHIVO

Dentro del script shellpipe, se establecerán dos variables de entorno para una mayor personalización (esto puede ser útil si tiene un archivo de script de shell externo que se utiliza como filtro para varios trabajos, pero necesita tratar cada trabajo de una manera ligeramente diferente):

Variable de entorno Contenido
$URLWATCH_JOB_NAME El nombre del trabajo (clave name en el YAML de trabajos)
$URLWATCH_JOB_LOCATION La URL del trabajo, o línea de comandos (para trabajos de shell)

CONVERSIÓN DE TEXTO EN IMÁGENES A TEXTO PLANO

El filtro ocr utiliza el motor Tesseract OCR https://github.com/tesseract-ocr para convertir texto en imágenes a texto plano. Requiere la instalación de dos módulos de Python: pytesseract https://github.com/madmaze/pytesseract y Pillow https://python-pillow.org. Se admiten todos los formatos de archivo compatibles con Pillow (PIL).

Este filtro *debe* ser el primer filtro en una cadena de filtros, ya que consume datos binarios y produce datos de texto.

url: https://example.net/ocr-test.png
filter:
  - ocr:
      timeout: 5
      language: eng
  - strip

Los subfiltros timeout y language son opcionales:

  • timeout: Tiempo de espera para el reconocimiento, en segundos (predeterminado: 10 segundos)
  • language: Idioma del texto (por ejemplo, fra o eng+fra, predeterminado: eng)

FILTRADO DE DATOS DE RESPUESTA JSON USANDO SELECTORES JQ

El filtro jq utiliza las vinculaciones de Python para jq https://stedolan.github.io/jq/, un procesador JSON ligero. El uso de este filtro requiere la instalación del módulo opcional de Python jq https://github.com/mwilliamson/jq.py.

url: https://example.net/jobs.json
filter:
   - jq:
      query: '.[].title'

El subfiltro query es opcional:

•
query: Una cadena de filtro jq válida.

Soporta agregaciones, selecciones y operadores integrados como length. Para obtener más información sobre las operaciones permitidas, consulte el Manual de jq https://stedolan.github.io/jq/manual/.

urlwatch-filters.5

urlwatch-filters - Módulos de filtrado de urlwatch

SINOPSIS

Los filtros se definen en la sección [filters] del archivo de configuración de urlwatch (~/.config/urlwatch/urlwatch.conf o /etc/urlwatch/urlwatch.conf).

Se pueden utilizar los siguientes módulos de filtrado.

ESPECIFICACIÓN

Los filtros se declaran con la sintaxis nombre_filtro = ruta_al_modulo. Si se necesita importar varios módulos del mismo tipo, se pueden usar nombres distintos para los filtros, p. ej.: 

[filters]
json_basic = urlwatch_filters.json
json_advanced = urlwatch_filters.json

En este caso, ambos filtros usarán el módulo urlwatch_filters.json, pero se podrán especificar opciones de línea de comandos distintas en la configuración de urlwatch.

HTML strip_tags

Elimina todas las etiquetas HTML del contenido. Utiliza la biblioteca htmlstrip.

Ejemplo: 

[filters]
strip_html = urlwatch_filters.html_strip

LINEBREAK_TO_SPACE

Reemplaza todos los saltos de línea por espacios. 

[filters]
linebreak2space = urlwatch_filters.linebreak_to_space

REPLACE_STRINGS

Reemplaza cadenas de texto. Las cadenas de texto a reemplazar se definen en la opción strings del archivo de configuración.

Ejemplo: 

[filters]
replace_stuff = urlwatch_filters.replace_strings

[replace_stuff]
strings =
    foo = bar
    baz = qux

SESSION_COOKIE

Envía cookies de sesión. Las cookies se definen en la opción cookies del archivo de configuración.

Ejemplo: 

[filters]
session_cookies = urlwatch_filters.session_cookie

[session_cookies]
cookies =
    sessionid=your_session_id
    csrftoken=your_csrf_token

UTILIZANDO UN SCRIPT SHELL COMO FILTRO

Los scripts shell se pueden utilizar como filtros. El script recibe el contenido de la página web a través de stdin y debe imprimir el contenido filtrado en stdout.

Ejemplo: 

[filters]
my_script_filter = urlwatch_filters.shell
script = /path/to/your/script.sh

CONVIRTIENDO TEXTO EN IMÁGENES A TEXTO PLANO

Utiliza tesseract-ocr para extraer texto de las imágenes. Asegúrate de que tesseract esté instalado y de que el idioma deseado esté disponible. 

[filters]
image_to_text = urlwatch_filters.image_to_text

FILTRANDO DATOS DE RESPUESTA JSON UTILIZANDO SELECTORES JQ

Utiliza jq para filtrar datos JSON. Debes especificar el selector jq en la opción jq_selector.

Ejemplo: 

[filters]
json_filter = urlwatch_filters.json

[json_filter]
jq_selector = .items[].title
