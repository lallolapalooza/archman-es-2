unw_set_iterate_phdr_function(3)

Paquete: libunwind

Licencias: MIT

UNW_SET_ITERATE_PHDR_FUNCTION(3libunwind) Biblioteca de programación UNW_SET_ITERATE_PHDR_FUNCTION(3libunwind)

NOMBRE

unw_set_iterate_phdr_function -- establece la implementación de dl_iterate_phdr

SINOPSIS

#include <libunwind.h>

typedef int (*unw_iterate_phdr_callback_t)(struct dl_phdr_info *, size_t, void *);
typedef int (*unw_iterate_phdr_func_t)(unw_iterate_phdr_callback_t, void *);

void unw_set_iterate_phdr_function(unw_addr_space_t as, unw_iterate_phdr_func_t function);

DESCRIPCIÓN

La rutina unw_set_iterate_phdr_function() establece la implementación de dl_iterate_phdr del espacio de direcciones as a la función proporcionada en el argumento function. La función se llamará cada vez que libunwind necesite iterar sobre las cabeceras del programa de la aplicación. Normalmente, esto se hace llamando a dl_iterate_phdr, pero esta función no es segura para señales. Con la ayuda de una implementación personalizada, también es posible almacenar en caché e iterar sobre las cabeceras del programa de manera segura para señales. Sin embargo, la carga recae en el usuario de libunwind.

SEGURIDAD DE HILOS Y SEÑALES

unw_set_iterate_phdr_function() es seguro para hilos. Si se pasa el espacio de direcciones local como argumento as, esta rutina también es segura para su uso desde un manejador de señales.
