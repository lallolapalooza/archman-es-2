uudoc(1) Manual de Comandos Generales uudoc(1)

NOMBRE

uudoc - Encoge o extiende el tamaño de cada archivo al tamaño especificado.

SINOPSIS

uudoc [-o|--io-blocks] [-c|--no-create] [-r|--reference] [-s|--size] [-h|--help] [-V|--version] <ARCHIVO>

DESCRIPCIÓN

Encoge o extiende el tamaño de cada archivo al tamaño especificado.

OPCIONES

-o, --io-blocks
interpreta TAMAÑO como el número de bloques de E/S del archivo en lugar de bytes (NO IMPLEMENTADO)
-c, --no-create
no crear archivos que no existan
-r, --reference <ARCHIVO_REF>
basar el tamaño de cada archivo en el tamaño de ARCHIVO_REF
-s, --size <TAMAÑO>
establecer o ajustar el tamaño de cada archivo según TAMAÑO, que está en bytes a menos que se especifique --io-blocks
-h, --help
Imprimir ayuda
-V, --version
Imprimir versión
<ARCHIVO>

EXTRA

TAMAÑO es un entero con un prefijo opcional y una unidad opcional. Las unidades disponibles (K, M, G, T, P, E, Z e Y) utilizan el siguiente formato:
'KB' => 1000 (kilobytes)
'K' => 1024 (kibibytes)
'MB' => 1000*1000 (megabytes)
'M' => 1024*1024 (mebibytes)
'GB' => 1000*1000*1000 (gigabytes)
'G' => 1024*1024*1024 (gibibytes) TAMAÑO también puede ir precedido por uno de los siguientes para ajustar el tamaño de cada archivo según su tamaño actual:
'+' => extender en
'-' => reducir en
'<' => como máximo
'>' => como mínimo
'/' => redondear hacia abajo al múltiplo de
'%' => redondear hacia arriba al múltiplo de
