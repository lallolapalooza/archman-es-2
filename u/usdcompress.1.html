USDCOMPRESS(1) Comandos de usuario USDCOMPRESS(1)

NOMBRE

usdcompress - página del manual para usdcompress 25.11

DESCRIPCIÓN

uso: usdcompress [-h] -o archivo [-v] [-qp 0-30] [-qt 0-30] [-qn 0-30]

[-cl 0-10] [--preserve_polygons 0|1] [--ignore_opinion_errors] entrada

argumentos posicionales:

entrada
archivo de entrada

opciones:

-h, --help
mostrar este mensaje de ayuda y salir
-o, --out archivo
archivo de salida
-v, --verbose
habilitar modo de salida detallado
-qp 0-30
bits de cuantificación para posiciones
-qt 0-30
bits de cuantificación para texturas
-qn 0-30
bits de cuantificación para normales
-cl 0-10
nivel de compresión, mejor=10

--preserve_polygons 0|1

--ignore_opinion_errors
proceder cuando las opiniones no pueden ser eliminadas
