uudoc(1) Manual de comandos generales uudoc(1)

NOMBRE

uudoc - Copia SOURCE a DEST o múltiples SOURCE a DIRECTORY existente, mientras se establecen los modos de permiso y el propietario/grupo

SINOPSIS

uudoc [--backup] [-b ] [-c ] [-C|--compare] [-d|--directory] [-D ] [-g|--group] [-m|--mode] [-o|--owner] [-p|--preserve-timestamps] [-s|--strip] [--strip-program] [-S|--suffix] [-t|--target-directory] [-T|--no-target-directory] [-v|--verbose] [-P|--preserve-context] [-Z ] [--context] [-h|--help] [-V|--version] [archivos]

DESCRIPCIÓN

Copia SOURCE a DEST o múltiples SOURCE a DIRECTORY existente, mientras se establecen los modos de permiso y el propietario/grupo

OPCIONES

--backup[=<CONTROL>]
crea una copia de seguridad de cada archivo de destino existente
-b
igual que --backup pero no acepta un argumento
-c
ignorado
-C, --compare
compara cada par de archivos de origen y destino, y en algunos casos, no modifica el destino en absoluto
-d, --directory
trata todos los argumentos como nombres de directorio. crea todos los componentes de los directorios especificados
-D
crea todos los componentes principales de DEST excepto el último, luego copia SOURCE a DEST
-g, --group <GRUPO>
establece la propiedad del grupo, en lugar del grupo actual del proceso
-m, --mode <MODO>
establece el modo de permiso (como en chmod), en lugar de rwxr-xr-x
-o, --owner <PROPIETARIO>
establece la propiedad (solo superusuario)
-p, --preserve-timestamps
aplica los tiempos de acceso/modificación de los archivos SOURCE a los archivos de destino correspondientes
-s, --strip
elimina las tablas de símbolos (sin acción en Windows)
--strip-program <PROGRAMA>
programa utilizado para eliminar binarios (sin acción en Windows)
-S, --suffix <SUFIJO>
anula el sufijo de copia de seguridad habitual
-t, --target-directory <DIRECTORIO>
mueve todos los argumentos SOURCE a DIRECTORIO
-T, --no-target-directory
trata DEST como un archivo normal
-v, --verbose
explica lo que se está haciendo
-P, --preserve-context
preserva el contexto de seguridad
-Z
establece el contexto de seguridad SELinux del archivo de destino y de cada directorio creado al tipo predeterminado
--context [<CONTEXTO>]
establece el contexto de seguridad de archivos y directorios
-h, --help
Imprime la ayuda
-V, --version
Imprime la versión
[archivos]
