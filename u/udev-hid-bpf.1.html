NOMBRE

udev-hid-bpf - herramienta cargadora para programas eBPF de HID

SINOPSIS

udev-hid-bpf [--ayuda|--versión] <comando> [args]

DESCRIPCIÓN

udev-hid-bpf es una herramienta cargadora y de utilidad general para programas eBPF de HID. Típicamente es invocada por udev para cargar y descargar programas eBPF de HID que coinciden con un dispositivo dado, pero proporciona comandos para facilitar el desarrollo de nuevos programas eBPF e instalar programas eBPF específicos que no se instalan por defecto.

OPCIONES

--ayuda
Imprime la ayuda y sale
--verbose
Habilita la salida detallada para el comando dado
--version
Imprime la versión y sale

COMANDOS

add [--bpfdir /ruta/al/directorio] dispositivo [/ruta/al/programa.bpf.o]
Invocado por udev cuando se añade un dispositivo. Este comando carga todos los programas eBPF de HID coincidentes para este dispositivo o, si se proporciona un programa, solo ese programa. La lista de programas eBPF coincidentes se almacena en la hwdb de udev.
El conjunto de directorios donde buscar programas eBPF está incorporado, pero se puede ajustar con la opción --bpfdir.
El dispositivo debe especificarse como un syspath.
remove dispositivo
Invocado por udev cuando se elimina un dispositivo. Este comando elimina todos los programas eBPF de HID para este dispositivo.
El dispositivo debe especificarse como un syspath.
list-bpf-programs [--bpfdir /ruta/al/directorio]
Lista los programas eBPF de HID disponibles en los directorios de búsqueda predeterminados (incorporados) o en el directorio dado.
list-devices
Lista los dispositivos HID disponibles.
inspect ruta/al/programa.bpf.o
Inspecciona el programa eBPF dado.
install [opciones] ruta/al/programa.bpf.o
Instala el programa eBPF dado en /etc/udev-hid-bpf con una regla udev correspondiente en /etc/udev/rules.d. Este comando debe usarse para probar un solo programa eBPF o donde una instalación completa de udev-hid-bpf no sea adecuada.
Las siguientes opciones están disponibles para el comando --install:
--dry-run
Haz todo excepto crear directorios y instalar archivos de destino
--install-exe
También instala el ejecutable udev-hid-bpf en $prefix/bin. Si el ejecutable ya existe en esa ruta, esta opción no hace nada.
--force
Sobrescribe archivos existentes con el mismo nombre
--prefix /usr/local
Instala en el prefijo dado. Por defecto, utiliza el prefijo incorporado.
