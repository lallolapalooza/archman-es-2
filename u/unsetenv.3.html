setenv(3) Manual de Funciones de Biblioteca setenv(3)

NOMBRE

setenv - modificar o añadir una variable de entorno

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
int setenv(const char *name, const char *value, int overwrite);
int unsetenv(const char *name);
Requisitos de Macro de Prueba de Características para glibc (ver feature_test_macros(7)):

setenv(), unsetenv():

    _POSIX_C_SOURCE >= 200112L
        || /* glibc <= 2.19: */ _BSD_SOURCE

DESCRIPCIÓN

La función setenv() añade la variable name al entorno con el valor value, si name no existe previamente. Si name ya existe en el entorno, entonces su valor se cambia a value si overwrite es distinto de cero; si overwrite es cero, entonces el valor de name no se cambia (y setenv() devuelve un estado de éxito). Esta función realiza copias de las cadenas apuntadas por name y value (a diferencia de putenv(3)).

La función unsetenv() elimina la variable name del entorno. Si name no existe en el entorno, entonces la función tiene éxito y el entorno no se modifica.

VALOR DE RETORNO

Las funciones setenv() y unsetenv() devuelven cero en caso de éxito, o -1 en caso de error, con errno establecido para indicar el error.

ERRORES

EINVAL
name es NULL, apunta a una cadena de longitud 0, o contiene un carácter '='.
ENOMEM
Memoria insuficiente para añadir una nueva variable al entorno.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
setenv (), unsetenv () Seguridad en hilos MT-Unsafe const:env

ESTANDARES

POSIX.1-2008.

HISTORIAL

POSIX.1-2001, 4.3BSD.

Antes de glibc 2.2.2, unsetenv() se prototipaba para devolver void; las versiones más recientes de glibc siguen el prototipo conforme a POSIX.1 mostrado en la SINOPSIS.

ADVERTENCIAS

POSIX.1 no requiere que setenv() o unsetenv() sean reentrantes.

ERRORES CONOCIDOS

POSIX.1 especifica que si name contiene un carácter '=', entonces setenv() debería fallar con el error EINVAL; sin embargo, las versiones de glibc anteriores a glibc 2.3.4 permitían un signo '=' en name.

VER TAMBIÉN

clearenv(3), getenv(3), putenv(3), environ(7)
