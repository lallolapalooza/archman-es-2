NOMBRE

upscli_ssl - Comprueba el modo SSL para la conexión actual

SINOPSIS

        #include <upsclient.h>
        int upscli_ssl(UPSCONN_t *ups);

DESCRIPCIÓN

La función upscli_ssl() toma el puntero ups a una estructura de estado UPSCONN_t. Sólo devuelve 1 si el soporte SSL ha sido compilado en la biblioteca upsclient(3), y si se habilitó correctamente para esta conexión.

VALOR DE RETORNO

La función upscli_ssl() devuelve 1 si SSL está en ejecución, y 0 si no. Devuelve -1 en caso de error.
