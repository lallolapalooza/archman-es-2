#include <libudev.h>

struct udev_list_entry *udev_device_get_properties_list_entry(struct udev_device *udev_device);

struct udev_list_entry *udev_device_get_tags_list_entry(struct udev_device *udev_device);

struct udev_list_entry *udev_device_get_current_tags_list_entry(struct udev_device *udev_device);

struct udev_list_entry *udev_device_get_sysattr_list_entry(struct udev_device *udev_device);

const char *udev_device_get_property_value(struct udev_device *udev_device, const char *key);

const char *udev_device_get_sysattr_value(struct udev_device *udev_device, const char *sysattr);

int udev_device_set_sysattr_value(struct udev_device *udev_device, const char *sysattr, const char *value);

DESCRIPCIÓN

udev_device_has_tag() devuelve un valor mayor que cero si el objeto de dispositivo especificado tiene la etiqueta indicada asignada. Consulte udev(7) para obtener detalles sobre el concepto de etiquetas. udev_device_has_current_tag() ejecuta una verificación similar, sin embargo, solo determina si la etiqueta indicada se estableció como resultado del evento más reciente visto para el dispositivo. Las etiquetas son "persistentes", es decir, una vez establecidas para un dispositivo, permanecen en él hasta que se desconecta, incluso si las reglas ejecutadas para eventos posteriores del mismo dispositivo ya no las establecen. Cualquier etiqueta para la cual udev_device_has_current_tag() devuelve true, también devolverá true cuando se pase a udev_device_has_tag(), pero lo contrario podría no ser cierto, en caso de que una etiqueta ya no esté configurada por las reglas aplicadas incluso al dispositivo más reciente.

udev_device_get_tags_list_entry() devuelve un objeto udev_list_entry, que encapsula una lista de etiquetas establecidas para el dispositivo especificado. De manera similar, udev_device_get_current_tags_list_entry() devuelve una lista de etiquetas establecidas para el dispositivo especificado como efecto del evento de dispositivo más reciente visto (ver arriba para detalles sobre la diferencia).

VALOR DE RETORNO

En caso de éxito, udev_device_has_tag() y udev_device_has_current_tag() devuelven un valor positivo o **0**, dependiendo de si el dispositivo tiene o no la etiqueta dada. En caso de error, se devuelve un código de error negativo.

En caso de éxito, udev_device_get_devlinks_list_entry(), udev_device_get_properties_list_entry(), udev_device_get_tags_list_entry(), udev_device_get_current_tags_list_entry() y udev_device_get_sysattr_list_entry() devuelven un puntero a la primera entrada de la lista recuperada. Si esa lista está vacía, o si ocurrió un error, se devuelve **NULL**.

En caso de éxito, udev_device_get_property_value() y udev_device_get_sysattr_value() devuelven un puntero a una cadena constante del valor solicitado. En caso de error, se devuelve **NULL**. Los atributos que pueden contener bytes **NUL** no deben recuperarse con udev_device_get_sysattr_value(); en su lugar, léalos directamente de los archivos dentro del syspath del dispositivo.

En caso de éxito, udev_device_set_sysattr_value() devuelve un entero mayor o igual a **0**. En caso de error, se devuelve un código de error negativo. Los valores que contienen bytes **NUL** no deben establecerse con esta función; en su lugar, escríbalos directamente en los archivos dentro del syspath del dispositivo.

HISTORIA
