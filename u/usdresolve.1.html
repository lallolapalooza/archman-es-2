NOMBRE

usdresolve - página del manual para usdresolve 25.11

DESCRIPCIÓN

uso: usdresolve [-h] [--createContextForAsset CREATECONTEXTFORASSET |

--createContextFromString CREATECONTEXTFROMSTRING] [--anchorPath ANCHORPATH] inputPath

Resuelve una ruta de activo utilizando un Resolvedor de Activos USD completamente configurado.

argumentos posicionales:

inputPath
Una ruta de activo que será resuelta por el Resolvedor de Activos USD.

opciones:

-h, --help
mostrar este mensaje de ayuda y salir
--createContextForAsset CREATECONTEXTFORASSET
Ejecuta CreateDefaultContextForAsset con la ruta de activo dada para crear el contexto utilizado para la resolución.
--createContextFromString CREATECONTEXTFROMSTRING
Ejecuta CreateContextFromString con la cadena dada para crear el contexto utilizado para la resolución. Acepta cadenas como [<URI Scheme>:]<Cadena de Configuración> y puede especificarse varias veces. ej: usdresolve --createContextFromString 'config_primary' --createContextFromString 'my_uri_scheme:config_uri'
--anchorPath ANCHORPATH
Ejecuta CreateIdentifier con la ruta de entrada y esta ruta de activo ancla y resuelve el resultado. ej: usdresolve --anchorPath /asset/asset.usd sublayer.usd
