UNI(8) Manual del Administrador del Sistema UNI(8)

NOMBRE

uni - un programa para interactuar con el sistema de configuración UniConf

SINOPSIS

uni get CLAVE [DEFECTO]

uni set CLAVE [VALOR]
uni xset CLAVE [VALOR]

uni keys CLAVE
uni hkeys CLAVE
uni xkeys CLAVE

uni dump CLAVE
uni hdump CLAVE
uni xdump CLAVE

DESCRIPCIÓN

UniConf es el sistema de configuración Único y Verdadero que incluye a todos los demás porque tiene backends y frontends de plugins. O, de forma menos grandilocuente, es un árbol de cadenas ligero, distribuido y cacheable.

uni se utiliza para interactuar directamente con el sistema UniConf. Su uso principal es para fines de diagnóstico, pero puede ser utilizado para añadir soporte UniConf a scripts de shell.

VARIABLE DE ENTORNO

UNICONF
Antes de usar uni, debe indicarle qué moniker de UniConf desea consultar estableciendo esta variable de entorno.

Los monikers se utilizan para contactar con los backends de UniConf, ya sea un servidor uniconfd o un archivo local. Por ejemplo, podrían ser:

• un nombre de archivo (ini:/var/lib/app/config.ini),
• o una dirección de red, (tcp:open.nit.ca:4111).

COMANDOS

get
Recupera el VALOR asociado con la CLAVE proporcionada dentro de la base de datos UniConf. Si se proporciona un DEFECTO, este se devolverá si la CLAVE no tiene un VALOR asociado.
set
Asigna el VALOR proporcionado a la CLAVE proporcionada. UniConf no ofrece ninguna garantía de que la entrada se confirme en toda la base de datos. El próximo comando "get" para esta CLAVE puede no devolver el valor más reciente establecido debido al almacenamiento en caché, o a la existencia de un generador de solo lectura.
xset
Asigna, a la CLAVE proporcionada, el contenido del flujo de entrada estándar. Utilice este comando para canalizar información a la base de datos UniConf.
keys
Lista todas las sub-claves contenidas dentro de la CLAVE proporcionada.
hkeys
Lista todas las sub-claves, recursivamente, contenidas dentro de la CLAVE proporcionada. Dado que cualquier CLAVE puede contener sub-claves, UniConf no ofrece ninguna garantía de que no existan referencias circulares.
xkeys
Lista todas las sub-claves contenidas dentro de la CLAVE proporcionada, que pueden contener comodines. Consulte la sección COMODINES.
dump
Lista todas las sub-claves y sus valores, contenidos dentro de la CLAVE proporcionada.
hdump
Lista todas las sub-claves y sus valores, recursivamente, contenidos dentro de la CLAVE proporcionada.
xdump
Lista todas las sub-claves y sus valores, contenidos dentro de la CLAVE proporcionada, que pueden contener comodines.

COMODINES

Una CLAVE se parece a una ruta normal separada por barras. La raíz del árbol UniConf tiene una CLAVE llamada "/". Las sub-claves se pueden acceder por nombres como "/software/myapp/version".

Con comodines, puedes acceder a más de una clave a la vez.

*
Para acceder a una sub-clave dentro de cualquier nivel de claves, use el asterisco de esta manera: "/software/*/version". Esto recupera todas las claves de "version" que están un nivel por debajo de "/software".
...
Para acceder a una sub-clave en cualquier lugar debajo de una clave, use los puntos suspensivos de esta manera: "/.../version". Esto recupera todas las claves de "version" que están cero o más niveles por debajo de la raíz (es decir, cualquier aparición de "version" dentro de la base de datos).
