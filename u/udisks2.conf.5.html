UDISKS2.CONF(5) Configuración del demonio udisks2 UDISKS2.CONF(5)

NOMBRE

udisks2.conf - El archivo de configuración de udisks2

DESCRIPCIÓN

El proyecto udisks proporciona funcionalidad adicional a través de módulos conectables. Estos plugins se pueden insertar en el demonio ya sea mediante la llamada D-Bus org.freedesktop.UDisks2.Manager.EnableModules() o ejecutando el demonio udisks con la opción de línea de comandos --force-load-modules.

También es posible configurar el comportamiento de carga de módulos a través del archivo de configuración ubicado en /etc/udisks2/udisks2.conf.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración predeterminado udisks2.conf se ve así:

    [udisks2]
    modules=*
    modules_load_preference=ondemand
    [defaults]
    encryption=luks1

modules = <lista de cadenas>

Esta variable controla qué módulos deben cargarse. Puede contener ya sea una lista de módulos separados por comas para cargar o un solo asterisco que representa a todos los módulos.

modules_load_preference = ondemand|onstartup

Esta clave le dice a udisksd cuándo cargar los plugins: ya sea al inicio o bajo demanda mediante la llamada D-Bus org.freedesktop.UDisks2.Manager.EnableModules().

encryption = luks1|luks2

Esta variable controla qué tecnología de cifrado se utilizará por defecto al crear un sistema de archivos cifrado.
