NOMBRE

upterm-upgrade - Actualiza la CLI

SINOPSIS

upterm upgrade [flags]

DESCRIPCIÓN

Actualiza la CLI

OPCIONES

-h, --help[=false] ayuda para upgrade

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] habilita el registro a nivel de depuración (archivo de registro: /build/.upterm/upterm.log).

EJEMPLO

  # Actualiza a la última versión:
  upterm upgrade
  # Actualiza a una versión específica:
  upterm upgrade 0.2.0
