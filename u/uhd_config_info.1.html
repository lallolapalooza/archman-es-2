NOMBRE

uhd_config_info - Información de configuración de compilación del Controlador de Hardware USRP

DESCRIPCIÓN

Imprime información de compilación correspondiente a esta instalación del Controlador de Hardware USRP (UHD).

El paquete UHD es el controlador de hardware universal para los productos de Ettus Research. El objetivo es proporcionar un controlador de anfitrión y una API para los productos actuales y futuros de Ettus Research. Los usuarios podrán utilizar el controlador UHD de forma independiente o con aplicaciones de terceros.

SINOPSIS

uhd_config_info [OPCIONES]

OPCIONES

Imprime la fecha de compilación de esta versión:
--boost-version
Imprime la versión de Boost utilizada:
--build-date
Imprime el compilador de C utilizado:
--c-compiler
Imprime el compilador de C++ utilizado:
--cxx-compiler
Imprime las banderas de compilación de C:
--c-flags
Imprime las banderas de compilación de C++:
--cxx-flags
Imprime los componentes UHD incluidos en esta compilación (delimitados por comas):
--enabled-components
Imprime el prefijo de instalación predeterminado para esta compilación:
--install-prefix
Imprime la versión de libusb utilizada
--libusb-version
Imprime toda la información enumerada anteriormente:
--print-all
Imprime la versión de UHD:
--version
Esta información de ayuda:
--help
