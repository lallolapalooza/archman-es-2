NOMBRE

unibi_dummy - construir un objeto de terminal ficticio

SINOPSIS

#include <unibilium.h>

unibi_term *unibi_dummy(void);

DESCRIPCIÓN

Si desea crear una entrada de terminfo desde cero, utilice esta función para crear un "unibi_term" ficticio. Configure sus capacidades con las diversas funciones "unibi_set_*", obtenga la representación de terminfo con "unibi_dump" y libérela con "unibi_destroy".

VEASE TAMBIÉN

unibilium.h(3), unibi_dump(3), unibi_destroy(3), unibi_from_mem(3)
