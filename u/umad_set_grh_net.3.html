UMAD_SET_GRH_NET(3) Manual del programador de OpenIB UMAD_SET_GRH_NET(3)

NOMBRE

umad_set_grh_net - establece campos GRH dentro del búfer umad usando ordenación de red

SINOPSIS

#include <infiniband/umad.h>

int umad_set_grh_net(void *umad, void *mad_addr);

DESCRIPCIÓN

umad_set_grh_net() establece los campos GRH (grh_present, gid, hop_limit, traffic_class, flow_label) dentro del búfer umad especificado basándose en la dirección mad_addr suministrada. Se espera que los campos de mad_addr proporcionados estén en orden de red. Si el puntero mad_addr suministrado es NULL, no se establece ningún GRH. El argumento mad_addr es un puntero a una estructura ib_mad_addr_t, como se especifica en <infiniband/umad.h>. El argumento umad es un puntero a una estructura ib_user_mad_t, como se especifica en <infiniband/umad.h>.

typedef struct ib_mad_addr {
uint32_t qpn;
uint32_t qkey;
uint16_t lid;
uint8_t  sl;
uint8_t  path_bits;
uint8_t  grh_present;
uint8_t  gid_index;
uint8_t  hop_limit;
uint8_t  traffic_class;
uint8_t  gid[16];
uint32_t flow_label;
} ib_mad_addr_t;
typedef struct ib_user_mad {
uint32_t agent_id;
uint32_t status;
uint32_t timeout_ms;
uint32_t retries;
uint32_t length;
ib_mad_addr_t addr;
uint8_t  data[0];
} ib_user_mad_t;

VALOR DE RETORNO

umad_set_grh_net() devuelve 0 si tiene éxito y un valor negativo en caso de error. Actualmente, no se indican errores.

BUGS CONOCIDOS

No implementado.
