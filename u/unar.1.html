unar(1) Comandos de usuario unar(1)

NOMBRE

unar - extraer el contenido de archivos de archivo

SINOPSIS

unar [OPCIÓN]... ARCHIVO [FICHERO]...

DESCRIPCIÓN

Extrae FICHEROs o el contenido de ARCHIVO.

OPCIONES

-o, -directorio-salida DIRECTORIO
El directorio donde escribir el contenido del archivo. Por defecto, el directorio actual.
-f, -forzar-sobrescritura
Sobrescribe siempre los archivos cuando un archivo a descomprimir ya existe en el disco. Por defecto, el programa pregunta al usuario si es posible, de lo contrario, omite el archivo.
-r, -forzar-renombrar
Renombra siempre los archivos cuando un archivo a descomprimir ya existe en el disco.
-s, -forzar-omitir
Omite siempre los archivos cuando un archivo a descomprimir ya existe en el disco.
-d, -forzar-directorio
Crea siempre un directorio contenedor para el contenido del archivo descomprimido. Por defecto, se crea un directorio si hay más de un archivo o carpeta de nivel superior.
-D, -sin-directorio
Nunca crea un directorio contenedor para el contenido del archivo descomprimido.
-p, -contraseña CONTRASEÑA
La contraseña a usar para descifrar archivos protegidos.
-e, -codificación CODIFICACIÓN
La codificación a usar para los nombres de archivo en el archivo, cuando no se conoce. Si no se especifica, el programa intenta detectar automáticamente la codificación utilizada. Use "help" o "list" como argumento para obtener una lista de todas las codificaciones soportadas.
-E, -codificación-contraseña CODIFICACIÓN
La codificación a usar para la contraseña del archivo, cuando no se conoce. Si no se especifica, se usa la codificación dada por la opción -codificación o la codificación detectada automáticamente.
-i, -índices
En lugar de especificar los archivos a listar como nombres de archivo o patrones comodín, especifíquelos como índices, como los produce lsar.
-nr, -sin-recursión
No intente extraer archivos contenidos en otros archivos. Por ejemplo, al descomprimir un archivo .tar.gz, solo descomprima el archivo .tar y no su contenido.
-t, -copiar-tiempo
Copia la hora de modificación del archivo al directorio contenedor, si se crea uno.
-k, -bifurcaciones visibles|ocultas|omitir
Cómo manejar las bifurcaciones de recursos de Mac OS. visibles crea archivos AppleDouble con la extensión ".rsrc", ocultas crea archivos AppleDouble con el prefijo "._", y omitir descarta todas las bifurcaciones de recursos. Por defecto es visibles.
-q, -silencioso
Ejecutar en modo silencioso.
-v, -versión
Imprimir versión y salir.
-h, -ayuda
Mostrar información de ayuda.
