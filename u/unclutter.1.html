NOMBRE

unclutter-xfixes - reescritura de unclutter usando la extensión X11-Xfixes

SINOPSIS

unclutter [--timeout segundos] [--jitter radio] [--exclude-root] [--ignore-scrolling] [--ignore-buttons botones] [--hide-on-touch] [--fork|-b] [--help|-h] [--version|-v] [--start-hidden]

Argumentos de compatibilidad:

unclutter [--display|-d pantalla] [--idle segundos] [--keystroke] [--grab] [--noevents] [--reset] [--root] [--onescreen] [--not] nombre ...

DESCRIPCIÓN

Oculta el cursor del ratón si no se está utilizando.

Esta versión de unclutter es una reescritura de la original y utiliza la extensión x11-xfixes, lo que significa que no se necesitan ventanas falsas ni captura del puntero. Esto debería funcionar mejor con gestores de ventanas y aplicaciones.

OPCIONES

--timeout segundos

Especifica el número de segundos después de los cuales el cursor debería ocultarse si no se movió ni se presionó ningún botón. (Predeterminado: 5)

--jitter radio

Ignora los movimientos del cursor si el cursor no se ha movido al menos radio píxeles.

--exclude-root

No ocultes el cursor del ratón si está inactivo sobre la ventana raíz y no sobre una ventana real, ya que en este caso no está ocultando nada importante, sino solo el fondo de escritorio.

--ignore-scrolling

Ignora los eventos de desplazamiento del ratón (botones 4 y 5) para que el desplazamiento no muestre el cursor. Este es un atajo para --ignore-buttons 4,5. Si quieres ignorar también el desplazamiento horizontal, usa --ignore-buttons especificando todos los botones manualmente (por ejemplo, 4,5,6,7).

--ignore-buttons

Define los botones del ratón que no muestran el cursor al hacer clic. Puedes pasar varios números de botón separándolos con una coma (,).

--hide-on-touch

Oculta el cursor del ratón en eventos táctiles.

--start-hidden

Inicia el cursor oculto.

--fork|-b

Ejecuta unclutter en segundo plano.

--help|-h

Muestra el uso y sale.

--version|-v

Muestra la versión y sale.

SOLUCIÓN DE PROBLEMAS

--ignore-scrolling no funciona

Esto puede suceder, especialmente en trackpoints, si también se envían otros eventos de botón, por ejemplo, para el desplazamiento horizontal. Puedes intentar añadir algo de "jitter", o verificarlo usando xev -event button. Si también quieres ignorar el desplazamiento horizontal, usa --ignore-buttons en lugar de --ignore-scrolling.

COMPATIBILIDAD

Para poder ser utilizado como un reemplazo directo de unclutter, unclutter-xfixes acepta todos los argumentos de línea de comandos de unclutter, pero ignora la mayoría de ellos.

--display|-d pantalla

Especifica la pantalla X a usar. El mismo efecto se puede lograr configurando la variable de entorno DISPLAY.

--idle segundos

Este argumento se mapea a --timeout.

--keystroke

Este argumento se ignora.

--grab

Este argumento se ignora.

--noevents

Este argumento se ignora.

--reset

Este argumento se ignora.

--root

Este argumento hace lo contrario de --exclude-root. No debería ser necesario, ya que este es el comportamiento predeterminado en unclutter-xfixes.

--onescreen

Este argumento restringe unclutter a la única pantalla especificada en --display o a la pantalla predeterminada de la pantalla.

--not

Este argumento provocará que todos los argumentos que no sean opciones o argumentos de opción se recopilen en una lista que especifica las ventanas de las que no se eliminará el cursor. Estas serán las ventanas en las que un elemento de la lista coincide, en comparación insensible a mayúsculas y minúsculas, con los caracteres iniciales de WM_NAME, o el nombre o clase de WM_CLASS, propiedades de la ventana. (Tenga en cuenta que este argumento se puede dar en cualquier lugar de la línea de comandos).
