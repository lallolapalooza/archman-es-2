UNLINK(1P) Manual del programador POSIX UNLINK(1P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

unlink — llama a la función unlink()

SINOPSIS

unlink archivo

DESCRIPCIÓN

La utilidad unlink realizará la llamada a la función:

unlink(archivo);

Un usuario puede necesitar los privilegios adecuados para invocar la utilidad unlink.

OPCIONES

Ninguna.

𝙊PERANDOS

Se admitirán los siguientes operandos:

archivo
La ruta de un archivo existente.

ENTRADA ESTÁNDAR

No utilizada.

FICHEROS DE ENTRADA

No utilizados.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán a la ejecución de unlink:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización para ver la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de locale.)
LC_ALL
Si se establece en una cadena de valor no vacía, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la locale para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en los argumentos).
LC_MESSAGES

Determina la locale que debe utilizarse para afectar al formato y contenido de los mensajes de diagnóstico escritos en la salida estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

unlink(1)

unlink - Elimina archivos

SINOPSIS

unlink [OPCIÓN]... ARCHIVO...

DESCRIPCIÓN

Elimina cada ARCHIVO especificado. Si un ARCHIVO es un enlace simbólico, elimina el enlace simbólico en lugar del archivo al que apunta.

Si no se especifica ningún ARCHIVO, o si ARCHIVO es un guión (-), unlink lee ARCHIVO uno por uno de la entrada estándar.

OPCIONES

-h, --no-dereference
Nunca seguir enlaces simbólicos. Eliminar los enlaces simbólicos en sí mismos (comportamiento predeterminado).
-P, --physicall
Eliminar el archivo real al que apunta el enlace simbólico.
--help
Mostrar mensaje de ayuda y salir.
--version
Mostrar información sobre la versión y salir.

ESTADO DE SALIDA

Devuelve 0 si todos los enlaces se han eliminado con éxito. De lo contrario, 1.

EJEMPLOS

Eliminar un archivo llamado mi_archivo.txt:

unlink mi_archivo.txt

Eliminar varios archivos:

unlink archivo1.txt archivo2.log otro_archivo.dat

Eliminar un enlace simbólico llamado enlace al archivo archivo_original.txt:

unlink enlace

Eliminar el archivo real al que apunta un enlace simbólico llamado enlace_real:

unlink -P enlace_real
