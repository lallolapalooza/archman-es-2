NOMBRE

usbguard - Interfaz de línea de comandos de USBGuard

SINOPSIS

usbguard [OPCIONES] <subcomando> [OPCIONES-DEL-SUBCOMANDO] ...

usbguard get-parameter nombre

usbguard set-parameter nombre valor

usbguard list-devices

usbguard allow-device id | regla | regla-parcial

usbguard block-device id | regla | regla-parcial

usbguard reject-device id | regla | regla-parcial

usbguard list-rules

usbguard append-rule regla

usbguard remove-rule id

usbguard generate-policy

usbguard watch

usbguard read-descriptor archivo

usbguard add-user nombre

usbguard remove-user nombre

DESCRIPCIÓN

El comando usbguard proporciona una interfaz de línea de comandos (CLI) a una instancia en ejecución de usbguard-daemon(8). También proporciona una herramienta para generar políticas iniciales de USBGuard basadas en los dispositivos USB conectados al sistema.

SUBCOMANDOS

get-parameter [OPCIONES] nombre

Obtener el valor de un parámetro en tiempo de ejecución. El parámetro nombre es uno de InsertedDevicePolicy y ImplicitPolicyTarget.

Opciones disponibles:

-h, --help

Mostrar ayuda.

set-parameter [OPCIONES] nombre valor

Establecer el valor de un parámetro en tiempo de ejecución. El parámetro nombre es uno de InsertedDevicePolicy y ImplicitPolicyTarget.

Opciones disponibles:

-v, --verbose

Imprimir el valor anterior y el nuevo atributo.

-h, --help

Mostrar ayuda.

list-devices [OPCIONES]

Listar todos los dispositivos USB reconocidos por el demonio USBGuard.

Opciones disponibles:

-a, --allowed

Listar dispositivos permitidos.

-b, --blocked

Listar dispositivos bloqueados.

-t, --tree

Listar dispositivos en formato de árbol.

-h, --help

Mostrar ayuda.

allow-device [OPCIONES] < id | regla | regla-parcial >

Autorizar a un dispositivo a interactuar con el sistema. El dispositivo puede ser identificado por un id de dispositivo, una regla o una regla-parcial (regla sin destino). Tanto regla como regla-parcial se pueden usar para permitir múltiples dispositivos a la vez. Tenga en cuenta que id se refiere al ID interno de la regla del dispositivo (el primer número de la salida del comando list-devices) en lugar del atributo ID del dispositivo.

Opciones disponibles:

-p, --permanent

Hacer que la decisión sea permanente. Se agregará una regla de permiso específica del dispositivo a la política actual.

-h, --help

Mostrar ayuda.

block-device [OPCIONES] < id | regla | regla-parcial >

Desautorizar un dispositivo. El dispositivo puede ser identificado por un id de dispositivo, una regla o una regla-parcial (regla sin destino). Tanto regla como regla-parcial se pueden usar para bloquear múltiples dispositivos a la vez. Tenga en cuenta que id se refiere al ID interno de la regla del dispositivo (el primer número de la salida del comando list-devices) en lugar del atributo ID del dispositivo.

Opciones disponibles:

-p, --permanent

Hacer que la decisión sea permanente. Se agregará una regla de bloqueo específica del dispositivo a la política actual.

-h, --help

Mostrar ayuda.

reject-device [OPCIONES] < id | regla | regla-parcial >

Desautorizar y eliminar un dispositivo. El dispositivo puede ser identificado por un id de dispositivo, una regla o una regla-parcial (regla sin destino). Tanto regla como regla-parcial se pueden usar para rechazar múltiples dispositivos a la vez. Tenga en cuenta que id se refiere al ID interno de la regla del dispositivo (el primer número de la salida del comando list-devices) en lugar del atributo ID del dispositivo.

Opciones disponibles:

-p, --permanent

Hacer que la decisión sea permanente. Se agregará una regla de rechazo específica del dispositivo a la política actual.

-h, --help

Mostrar ayuda.

list-rules [OPCIONES]

Listar el conjunto de reglas (política) utilizado por el demonio USBGuard.

Opciones disponibles:

-d, --show-devices

Mostrar todos los dispositivos afectados por la regla específica.

-l, --label etiqueta

Mostrar solo las reglas que tienen una etiqueta específica.

-h, --help

Mostrar ayuda.

append-rule [OPCIONES] regla

Agregar la regla al conjunto de reglas actual.

Opciones disponibles:

-a, --after id

Agregar la nueva regla después de una regla con el id de regla especificado.

-t, --temporary

Hacer que la decisión sea temporal. El archivo de política de reglas no se actualizará.

-h, --help

Mostrar ayuda.

remove-rule [OPCIONES] id

Eliminar una regla identificada por el id de regla del conjunto de reglas.

Opciones disponibles:

-h, --help

Mostrar ayuda.

generate-policy [OPCIONES]

Generar un conjunto de reglas (política) que autorice los dispositivos USB conectados actualmente.

Opciones disponibles:

-p, --with-ports

Generar reglas específicas de puerto para todos los dispositivos. Por defecto, las reglas específicas de puerto se generan solo para dispositivos que no exportan un valor iSerial.

-P, --no-ports-sn

No generar reglas específicas de puerto para dispositivos sin valor iSerial. Sin esta opción, la herramienta agregará un atributo via-port a cualquier dispositivo que no proporcione un número de serie. Esta es una medida de seguridad para limitar la conexión de dispositivos que no se pueden identificar de forma única solo a través de un puerto específico. Esto hace que sea más difícil eludir la política, ya que el dispositivo real ocupará el puerto USB permitido la mayor parte del tiempo.

NAME

usbguard - policy enforcement daemon for USB devices

SYNOPSIS

usbguard [OPTIONS] COMMAND [COMMAND OPTIONS]

usbguard [OPTIONS] COMMAND ARGUMENTS

DESCRIPTION

The usbguard command provides an interface to the USBGuard IPC service. This service allows clients to query the status of USB devices, to receive event notifications and to modify the USBGuard policy.

This command can be used to:

  • Generate an initial policy for USBGuard.
  • Allow or block devices.
  • Modify the policy in runtime.
  • Modify runtime parameters of the daemon.
  • Modify IPC access control settings.
  • Query the status of devices.
  • Listen for IPC events.
  • Read USB device descriptors.

For more information on policies and USBGuard in general, please refer to the usbguard-daemon.conf(5) and usbguard-rules.conf(5) man pages.

SUBCOMMANDS

generate-policy [OPTIONS]

Generate an initial policy file. The generated policy is printed to stdout. Use this command to create a starting point for your policy configuration.

Available options:

-m, --minimum

Generate a policy that only allows already connected devices and nothing else.

-M, --modified

Generate a policy that allows already connected devices and nothing else. This option is deprecated, use --minimum instead.

-a, --allow rule

Add an explicit allow rule for the specified device or device class.

-b, --block rule

Add an explicit block rule for the specified device or device class.

-p, --print-rules

Print the generated rule set to stdout. This is the default behavior.

-c, --output-file file

Write the generated rule set to the specified file instead of stdout.

-s, --system-policy

Generate a policy that trusts the system policy generated by the main usbguard daemon.

-d, --device-policy

Generate a policy that trusts device policies.

-i, --interface-policy

Generate a policy that trusts interface policies.

-P, --per-device-rules

Generate rules for devices based on their unique identifiers.

-S, --static-rules

Generate rules for devices based on their static properties like vendor and product ID.

-X, --no-hashes

Do not generate a hash attribute for each device.

-H, --hash-only

Generate a hash-only policy.

-L, --ldif

Generate an ldif policy for LDAP.

-b, --usbguardbase base

Generate an ldif policy for LDAP with this base. This option is required when --ldif was specified.

-o, --objectclass objectclass

Generate an ldif policy for LDAP with this objectClass.

-n, --name-prefix prefix

Generate an ldif policy for LDAP with this name prefix.

-h, --help

Show help.

watch [OPTIONS]

Watch the IPC interface events and print them to stdout.

Available options:

-w, --wait

Wait for IPC connection to become available.

-o, --once

Wait only when starting, if needed. Exit when the connection is lost.

-e, --exec path

Run an executable file located at path for every event. Pass event data to the process via environment variables.

-h, --help

Show help.

read-descriptor [OPTIONS] file

Read a USB descriptor from a file and print it in human-readable form.

Available options:

-h, --help

Show help.

add-user name [OPTIONS]

Create an IPC access control file allowing the user/group identified by name to use the USBGuard IPC bus. The change takes effect only after restarting the usbguard-daemon(8) instance.

Available options:

-u, --user

The specified name represents a username or UID (default).

-g, --group

The specified name represents a groupname or GID.

-p, --policy privileges

Policy related privileges.

-d, --devices privileges

Device related privileges.

-e, --exceptions privileges

Exceptions related privileges.

-P, --parameters privileges

Run-time parameter related privileges.

-h, --help

Show help.

Privileges:

The privileges are expected to be in the form of a list separated by a colon:

    $ sudo usbguard add-user joe --devices=listen,modify

Consult the usbguard-daemon.conf(5) man-page for a detailed list of available privileges in each section. You can also use ALL instead of privileges to automatically assign all relevant privileges to a given section.

remove-user name [OPTIONS]

Remove an IPC access control file associated with the user/group identified by name. The change takes effect only after restarting the usbguard-daemon(8) instance.

Available options:

-u, --user

The specified name represents a username or UID (default).

-g, --group

The specified name represents a groupname or GID.

-h, --help

Show help.

EXAMPLES

Generating an initial policy:

    $ sudo usbguard generate-policy > rules.conf
    $ vi rules.conf
    (review/modify the rule set)
    $ sudo install -m 0600 -o root -g root rules.conf /etc/usbguard/rules.conf
    $ sudo systemctl restart usbguard

Allow device(s):

    # Allow a device by ID(it is the very first number from the list-devices command output)
    $ sudo usbguard allow-device 10
    # Allow all devices named "Dell Wired Multimedia Keyboard"
    $ sudo usbguard allow-device name \"Dell Wired Multimedia Keyboard\"
