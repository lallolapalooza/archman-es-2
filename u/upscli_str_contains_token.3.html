NOMBRE

upscli_str_contains_token - Verificar que un token único está presente en la cadena

SINOPSIS

        #include <upsclient.h>
        int     upscli_str_contains_token(const char *string, const char *token);

DESCRIPCIÓN

La función upscli_str_contains_token() toma el puntero tgt a un búfer de char * constante proporcionado por el llamador, compuesto por tokens únicos separados por caracteres de espacio simples (ASCII 0x20), y el puntero token a un valor de token presuntamente contiguo que debería encontrarse en el búfer tgt.

VALOR DE RETORNO

La función upscli_str_contains_token() devuelve un código numérico:

•distinto de cero si el valor token se encontró en el búfer tgt (posiblemente rodeado de caracteres de espacio, o al principio/final de la cadena);
•0 si token no se encontró, o si la cadena token o tgt era NULL o vacía.
