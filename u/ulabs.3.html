abs(3) Manual de Funciones de Biblioteca abs(3)

NOMBRE

abs, labs, llabs, imaxabs, uabs, ulabs, ullabs, umaxabs - calcular el valor absoluto de un entero

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
int abs(int j);
long labs(long j);
long long llabs(long long j);
unsigned int uabs(int j);
unsigned long ulabs(long j);
unsigned long long ullabs(long long j);
#include <inttypes.h>
intmax_t imaxabs(intmax_t j);
uintmax_t umaxabs(intmax_t j);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

llabs():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

uabs(), ulabs(), ullabs(), umaxabs():

    _ISOC2Y_SOURCE

DESCRIPCIÓN

Estas funciones calculan el valor absoluto del argumento j del tipo entero apropiado para la función.

VALOR DE RETORNO

Devuelve el valor absoluto del argumento entero, del tipo entero apropiado para la función.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
abs (), labs (), llabs (), imaxabs (), uabs (), ulabs (), ullabs (), umaxabs () Seguridad de hilos MT-Safe

ERRORES

Para abs(), labs(), llabs() y imaxabs(), intentar tomar el valor absoluto del entero más negativo no está definido.
