USDDIFF(1) Comandos de usuario USDDIFF(1)

NOMBRE

usddiff - página del manual para usddiff 25.11

DESCRIPCIÓN

uso: usddiff [-h] [-n] [-f] [-q] archivos [archivos ...]

Compara dos archivos legibles por usd usando un programa de diff seleccionado. Esto se elige buscando la variable de entorno $USD_DIFF. Si no está configurada, consultará la variable de entorno $DIFF. Por último, si ninguna de estas está configurada, intentará usar el programa canónico de Unix, diff. Esto retransmitirá el código de salida del programa diff seleccionado. Al comparar dos archivos usdz, cada archivo contenido en el paquete se examinará individualmente. La variable de entorno $USD_IMAGE_DIFF especifica un programa diff específico para comparar archivos de imagen. La variable de entorno $USD_IMAGE_DIFF_FORMATS especifica los formatos de imagen compatibles utilizando una lista de extensiones de archivo separadas por comas.

argumentos posicionales:

archivos
Los archivos a comparar. Deben ser del tipo DIR DIR, ARCHIVO... DIR, DIR ARCHIVO... o ARCHIVO ARCHIVO.

opciones:

-h, --help
mostrar este mensaje de ayuda y salir
-n, --noeffect
No editar ninguno de los archivos.
-f, --flatten
Componer completamente ambas capas como Usd Stages y aplanarlas en capas únicas.
-q, --brief
No devolver los resultados completos de los diffs. Pasa --brief al comando diff.
