NOMBRE

urlwatch-intro - Introducción al uso básico de urlwatch

INICIO RÁPIDO

1.
Ejecute urlwatch una vez para migrar sus datos antiguos o empezar de cero
2.
Use urlwatch --edit para personalizar trabajos y filtros (urls.yaml)
3.
Use urlwatch --edit-config para personalizar configuraciones y reporters (urlwatch.yaml)
4.
Añada urlwatch a su crontab (crontab -e) para monitorear páginas web periódicamente

El intervalo de comprobación se define por la frecuencia con la que ejecuta urlwatch. Puede usar, por ejemplo, crontab.guru https://crontab.guru para averiguar la expresión de programación para el intervalo de comprobación, recomendamos no más de una vez cada 30 minutos (esto sería */30 * * * *). Si nunca ha usado cron antes, consulte la ayuda del comando crontab https://www.computerhope.com/unix/ucrontab.htm.

En Windows, cron no está instalado por defecto. Use el Programador de Tareas de Windows https://en.wikipedia.org/wiki/Windows_Task_Scheduler en su lugar, o consulte esta pregunta de StackOverflow https://stackoverflow.com/q/132971/1047040 para alternativas.

CÓMO FUNCIONA

Cada vez que ejecuta urlwatch(1), este:

  • recupera la salida de cada trabajo y la filtra
  • la compara con la versión recuperada la vez anterior ("diferencias")
  • si encuentra alguna diferencia, invoca a los reporters habilitados (por ejemplo, reporter de texto, reporter de correo electrónico, ...) para notificarle los cambios

TRABAJOS Y FILTROS

Cada sitio web o comando de shell a monitorear constituye un "trabajo".

Las instrucciones para cada trabajo se encuentran en un archivo de configuración en formato YAML https://yaml.org/spec/. Si tiene más de un trabajo, los separa con una línea que contenga únicamente ---.

Puede editar el archivo de configuración de trabajos y filtros usando:

urlwatch --edit

Si recibe un error, configure su variable de entorno $EDITOR (o $VISUAL) en su shell, por ejemplo:

export EDITOR=/bin/nano

Aunque puede editar el archivo YAML manualmente, usar --edit realizará comprobaciones de sanidad antes de activar el nuevo archivo de configuración.

Clases de Trabajos

Cada trabajo debe tener exactamente una de las siguientes claves, que también define el tipo de trabajo:

  • url recupera lo que es servido por el servidor web (HTTP GET por defecto),
  • navigate usa un navegador sin cabeza para cargar páginas web que requieren JavaScript, y
  • command ejecuta un comando de shell.

Cada trabajo puede tener una clave opcional name para definir un nombre visible por el usuario para el trabajo.

Luego puede usar claves opcionales para controlar finamente varios parámetros del trabajo.

Consulte urlwatch-jobs(5) para obtener información detallada sobre la configuración de trabajos.

Filtros

Puede usar la clave filter para seleccionar uno o más Filtros para aplicar a los datos después de ser recuperados, por ejemplo para:

  • seleccionar HTML: css, xpath, element-by-class, element-by-id, element-by-style, element-by-tag
  • hacer el HTML más legible: html2text, beautify
  • hacer los PDFs legibles: pdf2text
  • hacer el JSON más legible: format-json
  • hacer iCal más legible: ical2text
  • hacer binarios legibles: hexdump
  • simplemente detectar cambios: sha1sum
  • editar texto: grep, grepi, strip, sort, striplines

Estos filtros se pueden encadenar. Como ejemplo, después de recuperar un documento HTML usando la clave url, puede extraer una selección con el filtro xpath, convertirla a texto con html2text, usar grep para extraer solo líneas que coincidan con una expresión regular específica, y luego ordenarlas con sort:

name: "Definición de trabajo de urlwatch de ejemplo"
url: "https://example.dummy/"
https_proxy: "http://dummy.proxy/"
max_tries: 2
filter:
  - xpath: '//section[@role="main"]'
  - html2text:
      method: pyhtml2text
      unicode_snob: true
      body_width: 0
      inline_links: false
      ignore_links: true
      ignore_images: true
      pad_tables: false
      single_line_break: true
  - grep: "líneas que me importan"
  - sort:
---

Consulte urlwatch-filters(5) para obtener información detallada sobre la configuración de filtros.

REPORTERS

urlwatch puede configurarse para hacer algo con su informe además de (o además de) la acción predeterminada de mostrarlo en la consola.

Los reporters se configuran en el archivo de configuración global:

urlwatch --edit-config

Ejemplos de reporters:

  • email (usando SMTP)
  • correo electrónico usando mailgun
  • slack
  • discord
  • pushbullet
  • telegram
  • matrix
  • pushover
  • stdout
  • xmpp
  • shell

Consulte urlwatch-reporters(5) para ver las opciones de configuración de los reporters.
