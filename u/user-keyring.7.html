user-keyring(7) Manual de Información Miscelánea user-keyring(7)

NOMBRE

user-keyring - keyring por usuario

DESCRIPCIÓN

El keyring de usuario es un keyring que se utiliza para anclar claves en nombre de un usuario. Cada UID que el kernel maneja tiene su propio keyring de usuario que es compartido por todos los procesos con esa UID. El keyring de usuario tiene un nombre (descripción) de la forma _uid.<UID> donde <UID> es el ID de usuario del usuario correspondiente.

El keyring de usuario está asociado con el registro que el kernel mantiene para la UID. Entra en existencia al primer intento de acceder al keyring de usuario, al user-session-keyring(7), o al session-keyring(7). El keyring permanece anclado en existencia mientras haya procesos ejecutándose con esa UID real o archivos abiertos por esos procesos permanezcan abiertos. (El keyring también puede ser anclado indefinidamente enlazándolo a otro keyring.)

Típicamente, el keyring de usuario es creado por pam_keyinit(8) cuando un usuario inicia sesión.

El keyring de usuario no es buscado por defecto por request_key(2). Cuando pam_keyinit(8) crea un keyring de sesión, le añade un enlace al keyring de usuario para que el keyring de usuario sea buscado cuando el keyring de sesión lo sea.

Un valor especial de número de serie, KEY_SPEC_USER_KEYRING, se define que puede ser utilizado en lugar del número de serie real del keyring de usuario del proceso que llama.

Desde la utilidad keyctl(1), '@u' puede ser usado en lugar de un ID de clave numérico de manera similar.

Los keyrings de usuario son independientes de clone(2), fork(2), vfork(2), execve(2), y _exit(2), excepto que el keyring se destruye cuando el registro de UID se destruye al salir el último proceso que lo ancla.

Si es necesario que una clave asociada a un usuario exista más allá de la recolección de basura del registro de UID —por ejemplo, para su uso por un script de cron(8)— entonces se debe usar el persistent-keyring(7) en su lugar.

Si un keyring de usuario no existe cuando se accede a él, será creado.
