UL(1) Comandos de usuario UL(1)

NOMBRE

ul - realizar subrayado

SINOPSIS

ul [opciones] [archivo...]

DESCRIPCIÓN

ul lee los archivos nombrados (o la entrada estándar si no se proporcionan) y traduce las ocurrencias de guiones bajos a la secuencia que indica el subrayado para la terminal en uso, según lo especificado por la variable de entorno TERM. Se lee la base de datos terminfo para determinar las secuencias apropiadas para el subrayado. Si la terminal es incapaz de subrayar pero es capaz de un modo destacado, se utiliza este último. Si la terminal puede sobreescribir o maneja el subrayado automáticamente, ul se degenera en cat(1). Si la terminal no puede subrayar, se ignora el subrayado.

OPCIONES

-i, --indicated

El subrayado se indica mediante una línea separada que contiene los guiones `-'; esto es útil cuando desea ver el subrayado presente en un flujo de salida de nroff en una terminal CRT.

-t, -T, --terminal terminal

Anula la variable de entorno TERM con el tipo de terminal especificado.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

AMBIENTE

Se utiliza la siguiente variable de entorno:

TERM

La variable TERM se utiliza para relacionar un dispositivo tty con su descripción de capacidades de dispositivo (ver terminfo(5)). TERM se establece en el momento del inicio de sesión, ya sea por el tipo de terminal predeterminado especificado en /etc/ttys o como lo estableció el usuario en su archivo login durante el proceso de inicio de sesión (ver setenv(3)).

HISTORIA

El comando ul apareció en 3.0BSD.

ERRORES

nroff generalmente genera una serie de retrocesos y subrayados mezclados con el texto para indicar el subrayado. No se realiza ningún intento de optimizar el movimiento hacia atrás.

VER TAMBIÉN

colcrt(1), login(1), man(1), nroff(1), setenv(3), terminfo(5)

REPORTE DE ERRORES

Para informes de errores, utilice el rastreador de problemas https://github.com/util-linux/util-linux/issues.

DISPONIBILIDAD

El comando ul forma parte del paquete util-linux, que puede descargarse de Linux Kernel Archive https://www.kernel.org/pub/linux/utils/util-linux/.
