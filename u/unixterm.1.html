UNIXTERM(1) Manual de Comandos Generales UNIXTERM(1)

NOMBRE

unixterm - (simple) Terminal remota para sockets unix

SINOPSIS

unixterm socket

DESCRIPCIÓN

Un unixterm es una aplicación de terminal para un socket de stream unix.

Ha sido creado como parte del proyecto vde-2: se utiliza como consola remota para vde_switch o para la aplicación wirefilter.

AVISO
