UNGETC(3P) Manual de Programador POSIX UNGETC(3P)

PRÓLOGO

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

ungetc — devuelve un byte al flujo de entrada

SINOPSIS

#include <stdio.h>
int ungetc(int c, FILE *stream);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función ungetc() devolverá el byte especificado por c (convertido a unsigned char) al flujo de entrada apuntado por stream. Los bytes devueltos serán leídos por lecturas posteriores en ese flujo en orden inverso al de su devolución. Una llamada intermedia exitosa (con el flujo apuntado por stream) a una función de posicionamiento de archivo (fseek(), fseeko(), fsetpos(), o rewind()) o fflush() descartará cualquier byte devuelto para el flujo. El almacenamiento externo correspondiente al flujo no se modificará.

Se proporcionará un byte de devolución. Si ungetc() se llama demasiadas veces en el mismo flujo sin una operación de lectura o posicionamiento de archivo intermedia en ese flujo, la operación puede fallar.

Si el valor de c es igual al de la macro EOF, la operación fallará y el flujo de entrada quedará inalterado.

Una llamada exitosa a ungetc() borrará el indicador de fin de archivo para el flujo. El valor del indicador de posición del archivo para el flujo, después de que todos los bytes devueltos hayan sido leídos o descartados llamando a fseek(), fseeko(), fsetpos(), o rewind() (pero no fflush()), será el mismo que tenía antes de que se devolvieran los bytes. El indicador de posición del archivo se decrementa por cada llamada exitosa a ungetc(); si su valor era 0 antes de una llamada, su valor no está especificado después de la llamada.

VALOR DE RETORNO

Al completarse con éxito, ungetc() devolverá el byte devuelto después de la conversión. En caso contrario, devolverá EOF.

No se definen errores.
