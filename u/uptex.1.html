UPTEX(1) Manual de Comandos Generales UPTEX(1)

NOMBRE

ptex, uptex, eptex, euptex - "Publishing TeX" japonés

SINOPSIS

uptex [opciones] [&formato] [archivo|\comandos]

DESCRIPCIÓN

pTeX (ptex) es un motor TeX con extensiones para la composición tipográfica japonesa, incluyendo características relacionadas con las reglas de ruptura de línea, espaciado entre caracteres y escritura vertical. Fue desarrollado inicialmente por ASCII Corporation, con el objetivo de proporcionar un TeX japonés que pudiera ser utilizado para la edición comercial. Para pTeX, el conjunto de caracteres disponible se limita a JIS X 0208, concretamente los niveles 1 y 2 de JIS.

upTeX (uptex) es un pTeX habilitado para Unicode con extensiones para un mejor manejo de documentos multilingües CJK (chino, japonés y coreano). Ha sido desarrollado por Takuji Tanaka desde 2007.

e-pTeX (eptex) es una fusión de e-TeX y pTeX.

e-upTeX (euptex) es una fusión de e-TeX y upTeX.

En las siguientes secciones, nos referiremos a estos motores como (e-)(u)pTeX.

El manejo de los argumentos de línea de comandos de (e-)(u)pTeX es similar al de otros programas TeX en la implementación de web2c.

OPCIONES

Aquí listamos solo las adiciones/eliminaciones de opciones de línea de comandos específicas de (e-)(u)pTeX. Para (u)pTeX, otras opciones son similares a TeX. Para e-(u)pTeX, otras opciones son similares a e-TeX.

Adiciones (soportadas por la biblioteca ptexenc):
-kanji cadena
Establece el código Kanji de entrada japonés. La cadena puede ser euc (EUC-JP), jis (ISO-2022-JP), sjis (Shift_JIS) y utf8 (UTF-8). Para (e-)upTeX, también se permite uptex.
-kanji-internal cadena
Establece el código Kanji interno. La cadena puede ser euc y sjis. Para (e-)upTeX, también se permite uptex.
Eliminaciones:
-enc
En esta versión de (e-)(u)pTeX, las extensiones encTeX no están disponibles.

VER TAMBIÉN

tex(1), etex(1).
Manual de referencia: https://github.com/texjporg/ptex-manual

AUTORES

Esta versión de (e-)(u)pTeX es mantenida por la Comunidad de Desarrollo TeX de Japón https://texjp.org. Para reportar errores, abra un ticket en el repositorio de GitHub https://github.com/texjporg/tex-jp-build, o envíe un correo electrónico a <issue@texjp.org>.
