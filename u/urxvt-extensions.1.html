NOMBRE

urxvt-extensions - lista brevemente las extensiones perl de urxvt

SINOPSIS

urxvt -pe nombre-de-la-extension

DESCRIPCIÓN

Esta página del manual lista brevemente las extensiones de rxvt-unicode disponibles en esta versión de rxvt-unicode. Para obtener información sobre cómo escribir extensiones de urxvt, consulte la página del manual urxvt-extensions.

Las extensiones que utilizan recursos para la configuración se cargan automáticamente cuando sus recursos se especifican como opciones de línea de comandos. Cualquier extensión se puede cargar explícitamente con la opción "-pe".

LISTA DE EXTENSIONES

background - administra el fondo de la terminal

bell-command - ejecuta un comando cuando suena la campana

block-graphics-to-ascii - mapea gráficos de bloques a caracteres ascii

clickthrough - hace que la ventana sea "transparente" con respecto a eventos de entrada

clipboard-osc - implementa la secuencia de comandos del sistema operativo para el portapapeles

confirm-paste - pide confirmación antes de pegar caracteres de control

digital-clock - muestra una superposición de reloj digital

eval - evalúa código perl arbitrario usando acciones

example-refresh-hooks - ejemplo de cómo usar ganchos de actualización

keysym-list - implementa la expansión de "list" de keysym.

kuake - terminal de acceso directo al estilo kuake

matcher - busca cadenas en la salida de la terminal y cambia su representación

option-popup - menú de opciones

overlay-osc - implementa OSC para administrar superposiciones

readline - mejora la edición de readline

remote-clipboard - administra un portapapeles compartido y posiblemente remoto

searchable-scrollback - búsqueda incremental en el historial de desplazamiento

selection - selección más inteligente

selection-autotransform - transforma automáticamente el texto seleccionado

selection-pastebin - subida automática a pastebin

selection-popup - ventana emergente de gestión de selección

selection-to-clipboard - copia la selección al portapapeles cada vez que se realiza una selección

tabbed - interfaz con pestañas para urxvt

xim-onthespot - implementa el comportamiento "on-the-spot" de XIM
