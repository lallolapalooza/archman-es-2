UPTERM(1) Manual de Upterm UPTERM(1)

NOMBRE

upterm - Compartición instantánea de terminal

SINOPSIS

upterm [opciones]

DESCRIPCIÓN

Upterm es una solución de código abierto para compartir sesiones de terminal instantáneamente a través de túneles SSH seguros a Internet público.

Prioridad de configuración (de mayor a menor):
1. Opciones de línea de comandos
2. Variables de entorno (prefijo UPTERM_)
3. Archivo de configuración (ver más abajo)
4. Valores predeterminados

Archivo de configuración:
~/.config/upterm/config.yaml (Linux)
~/Library/Application Support/upterm/config.yaml (macOS)
%LOCALAPPDATA%\upterm\config.yaml (Windows)

Ejecuta 'upterm config path' para ver la ubicación de tu archivo de configuración.
Ejecuta 'upterm config edit' para crear y editar el archivo de configuración.

Variables de entorno:
Todas las opciones se pueden establecer a través de variables de entorno con el prefijo UPTERM_.
Los nombres de las opciones se convierten reemplazando guiones (-) por guiones bajos (_).

Ejemplos:
--hide-client-ip → UPTERM_HIDE_CLIENT_IP=true
--read-only → UPTERM_READ_ONLY=true
--accept → UPTERM_ACCEPT=true

OPCIONES

--debug[=false] habilita el registro a nivel de depuración (archivo de registro: /build/.upterm/upterm.log).

-h, --help[=false] ayuda para upterm

EJEMPLO

  # Aloja una sesión de terminal ejecutando $SHELL, adjuntando la E/S del cliente a la del host:
  $ upterm host
  # Muestra la cadena de conexión SSH para compartir con el(los) cliente(s):
  $ upterm session current
  === SESSION_ID
  Comando:                /bin/bash
  Comando forzado:          n/a
  Host:                   ssh://uptermd.upterm.dev:22
  Sesión SSH:             ssh TOKEN@uptermd.upterm.dev
  # Un cliente se conecta a la sesión del host a través de SSH:
  $ ssh TOKEN@uptermd.upterm.dev
  # Establece opciones a través de variables de entorno:
  $ UPTERM_HIDE_CLIENT_IP=true upterm host
