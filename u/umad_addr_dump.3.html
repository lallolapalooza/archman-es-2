UMAD_ADDR_DUMP(3) Manual del programador de OpenIB UMAD_ADDR_DUMP(3)

NOMBRE

umad_addr_dump - volcar la estructura addr a stderr

SINOPSIS

#include <infiniband/umad.h>

void umad_addr_dump(ib_mad_addr_t *addr);

DESCRIPCIÓN

umad_addr_dump() vuelca la addr dada a stderr. El argumento addr es una estructura ib_mad_addr_t, como se especifica en <infiniband/umad.h>.

typedef struct ib_mad_addr {
uint32_t qpn;
uint32_t qkey;
uint16_t lid;
uint8_t  sl;
uint8_t  path_bits;
uint8_t  grh_present;
uint8_t  gid_index;
uint8_t  hop_limit;
uint8_t  traffic_class;
uint8_t  gid[16];
uint32_t flow_label;
} ib_mad_addr_t;

VALOR DE RETORNO

umad_addr_dump() no devuelve ningún valor.
