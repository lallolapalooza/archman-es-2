urxvt-eval(1) RXVT-UNICODE urxvt-eval(1)

NOMBRE

eval - evaluar código perl arbitrario usando acciones

EJEMPLOS

URxvt.keysym.M-c: eval:selection_to_clipboard
URxvt.keysym.M-v: eval:paste_clipboard
URxvt.keysym.M-V: eval:paste_primary
URxvt.keysym.M-Up: eval:scroll_up 1
URxvt.keysym.M-Down: eval:scroll_down 1
URxvt.keysym.M-Home: eval:scroll_to_top
URxvt.keysym.M-End:  eval:scroll_to_bottom

DESCRIPCIÓN

Añade soporte para evaluar código perl arbitrario usando acciones en recursos keysym. Si una acción de keysym tiene la forma "eval:CADENA", la CADENA especificada se evalúa como una expresión Perl. Mientras que la API completa de urxvt está disponible, los siguientes métodos también se proporcionan para comodidad de los usuarios, ya que implementan acciones básicas:

scroll_up $count
scroll_up_pages $count
scroll_down $count
scroll_down_pages $count
Desplazarse hacia arriba o hacia abajo por $count líneas o páginas.
scroll_to_top
scroll_to_bottom
Desplazarse hasta el principio o el final del búfer de desplazamiento.
selection_to_clipboard
Copiar la selección al CLIPBOARD.
paste_primary
paste_clipboard
Pegar el valor de la selección PRIMARY o CLIPBOARD.
