utf8(3perl) Guía de referencia para programadores de Perl utf8(3perl)

NOMBRE

utf8 - Pragma de Perl para habilitar/deshabilitar UTF-8 (o UTF-EBCDIC) en el código fuente

SINOPSIS

use utf8;
no utf8;
# Convertir la representación interna de un escalar de Perl a/desde UTF-8.
$num_octetos = utf8::upgrade($cadena);
$exito    = utf8::downgrade($cadena[, $fallo_ok]);
# Cambiar cada carácter de un escalar de Perl a/desde una serie de
# caracteres que representan los bytes UTF-8 de cada carácter original.
utf8::encode($cadena);  # "\x{100}"  se convierte en "\xc4\x80"
utf8::decode($cadena);  # "\xc4\x80" se convierte en "\x{100}"
# Convertir un punto de código del conjunto de caracteres nativo de la plataforma
# a Unicode, y viceversa.
$unicode = utf8::native_to_unicode(ord('A')); # devuelve 65 en plataformas
                                              # ASCII y EBCDIC
                                              # $nativo = utf8::unicode_to_native(65);        # devuelve 65 en plataformas
                                              # ASCII; 193 en EBCDIC
$flag = utf8::is_utf8($cadena); # desde Perl 5.8.1
$flag = utf8::valid($cadena);

DESCRIPCIÓN

El pragma "use utf8" le indica al analizador de Perl que permita UTF-8 en el texto del programa en el ámbito léxico actual. El pragma "no utf8" le indica a Perl que vuelva a tratar el texto fuente como bytes literales en el ámbito léxico actual. (En plataformas EBCDIC, técnicamente permite UTF-EBCDIC, y no UTF-8, pero esta distinción es académica, por lo que en este documento se usa el término UTF-8 para significar ambos).

No utilice este pragma para nada más que para indicar a Perl que su script está escrito en UTF-8. Las funciones de utilidad descritas a continuación son utilizables directamente sin "use utf8;".

Debido a que no es posible distinguir de forma fiable UTF-8 de las codificaciones nativas de 8 bits, necesita un Byte Order Mark (BOM) al principio de su código fuente, o "use utf8;", para instruir a Perl.

Cuando UTF-8 se convierta en el formato fuente estándar, este pragma será efectivamente una operación nula.

Vea también los efectos del modificador "-C" y su primo, la variable de entorno "PERL_UNICODE", en perlrun.

Habilitar el pragma "utf8" tiene el siguiente efecto:

•
Los bytes en el texto fuente que no están en el conjunto de caracteres ASCII serán tratados como parte de una secuencia UTF-8 literal. Esto incluye la mayoría de los literales como nombres de identificadores, constantes de cadena y patrones de expresiones regulares constantes.

Tenga en cuenta que si tiene bytes no ASCII y no UTF-8 en su script (por ejemplo, Latin-1 incrustado en sus literales de cadena), "use utf8" no estará contento. Si desea tener tales bytes bajo "use utf8", puede deshabilitar este pragma hasta el final del bloque (o archivo, si está en el nivel superior) con "no utf8;".

Funciones de utilidad

Las siguientes funciones están definidas en el paquete "utf8::" por el núcleo de Perl. No necesita decir "use utf8" para usarlas y de hecho no debería decirlo a menos que realmente quiera tener código fuente en UTF-8.

  • "$num_octetos = utf8::upgrade($cadena)"

    (Desde Perl v5.8.0) Convierte in situ la representación interna de la cadena de una secuencia de octetos en la codificación nativa (Latin-1 o EBCDIC) a UTF-8. La secuencia lógica de caracteres en sí misma no cambia. Si $cadena ya está actualizada, entonces esto es una operación nula. Devuelve el número de octetos necesarios para representar la cadena como UTF-8. Desde Perl v5.38, si $cadena es "undef" no se realiza ninguna acción; antes de eso, se convertiría en definida y de longitud cero.

    Si su código necesita ser compatible con versiones de perl sin "use feature 'unicode_strings';", puede forzar semántica Unicode en una cadena dada:

    # forzar semántica Unicode para $cadena sin la
# característica "unicode_strings"
utf8::upgrade($cadena);

    Por ejemplo:

    # sin uso explícito o implícito de la característica 'unicode_strings'
mi $x = "\xDF";    # LETRA PEQUEÑA LATINA S CON DOBLE S
$x =~ /ss/i;       # no coincidirá
mi $y = uc($x);    # no se convertirá
utf8::upgrade($x);
$x =~ /ss/i;       # coincide
mi $z = uc($x);    # se convierte a "SS"

    Tenga en cuenta que esta función no maneja codificaciones arbitrarias; use Encode en su lugar.

  • "$exito = utf8::downgrade($cadena[, $fallo_ok])"

    (Desde Perl v5.8.0) Convierte in situ la representación interna de la cadena de UTF-8 a la secuencia de octetos equivalente en la codificación nativa (Latin-1 o EBCDIC). La secuencia lógica de caracteres en sí misma no cambia. Si $cadena ya está almacenada como 8 bits nativos, entonces esto es una operación nula. Se puede usar para asegurarse de que la bandera UTF-8 esté desactivada, por ejemplo, cuando desea asegurarse de que la función substr() o length() funcione con el algoritmo de bytes, generalmente más rápido.

    Falla si la secuencia UTF-8 original no se puede representar en los 8 bits nativos de la codificación. En caso de fallo, muere o, si el valor de $fallo_ok es verdadero, devuelve falso.

    Devuelve verdadero en caso de éxito.

    Si su código espera una secuencia de octetos, esto se puede usar para validar que ha recibido una:

    # lanzar una excepción si no es representable como octetos
utf8::downgrade($cadena)
# o manejar su propio error
utf8::downgrade($cadena, 1) or die "la cadena debe ser de octetos";

    Tenga en cuenta que esta función no maneja codificaciones arbitrarias; use Encode en su lugar.

  • utf8::encode($cadena)

    (Desde Perl v5.8.0) Convierte in situ la secuencia de caracteres a la secuencia de octetos correspondiente en UTF-8 extendido de Perl. Es decir, cada carácter (posiblemente ancho) se reemplaza con una secuencia de uno o más caracteres que representan los bytes UTF-8 individuales del carácter. La bandera UTF8 se desactiva. No devuelve nada.

    mi $x = "\x{100}"; # $x contiene un carácter, con ord 0x100
utf8::encode($x);  # $x contiene dos caracteres, con ords (en
                   # plataformas ASCII) 0xc4 y 0x80. En EBCDIC
                   # 1047, esto sería en cambio 0x8C y 0x41.

    Similar a:

    use Encode;
$x = Encode::encode("utf8", $x);

    Tenga en cuenta que esta función no maneja codificaciones arbitrarias; use Encode en su lugar.

  • "$exito = utf8::decode($cadena)"

    (Desde Perl v5.8.0) Intenta convertir in situ la secuencia de octetos codificada en UTF-8 extendido de Perl a la secuencia de caracteres correspondiente. Es decir, reemplaza cada secuencia de caracteres en la cadena cuyos ords representan una secuencia de bytes UTF-8 válida (extendida), con el carácter único correspondiente. La bandera UTF-8 se activa solo si la cadena fuente contiene caracteres UTF-8 de varios bytes. Si $cadena no es válida como UTF-8 extendido, devuelve falso; de lo contrario, devuelve verdadero.

    mi $x = "\xc4\x80"; # $x contiene dos caracteres, con ords
                    # 0xc4 y 0x80
utf8::decode($x);   # En plataformas ASCII, $x contiene un carácter,
                    # con ord 0x100. Dado que estos bytes no son
                    # UTF-EBCDIC legales, en plataformas EBCDIC, $x no
                    # cambia y la función devuelve FALSO.
mi $y = "\xc3\x83\xc2\xab"; Esto se ha codificado dos veces; este
                    # ejemplo es solo para plataformas ASCII
utf8::decode($y);   # Convierte $y a \xc3\xab, devuelve VERDADERO;
utf8::decode($y);   # Convierte más a \xeb, devuelve VERDADERO;
utf8::decode($y);   # Devuelve FALSO, deja $y sin cambios

    Tenga en cuenta que esta función no maneja codificaciones arbitrarias; use Encode en su lugar.

  • "$unicode = utf8::native_to_unicode($punto_de_codigo)"

    (Desde Perl v5.8.0) Esto toma un entero sin signo (que representa el número ordinal de un carácter (o un punto de código) en la plataforma en la que se está ejecutando el programa) y devuelve su equivalente Unicode
