timeout(1) Manual de comandos generales timeout(1)

NOMBRE

timeout - Inicia un COMANDO, y lo termina si sigue ejecutándose después de un INTERVALO.

SINOPSIS

timeout [-f|--foreground] [-k|--kill-after] [-p|--preserve-status] [-s|--signal] [-v|--verbose] [-h|--help] [-V|--version] <duracion> <comando>

DESCRIPCIÓN

Inicia un COMANDO, y lo termina si sigue ejecutándose después de un INTERVALO.

OPCIONES

-f, --foreground
cuando no se ejecuta timeout directamente desde un prompt de shell, permite que el COMANDO lea del TTY y reciba señales TTY; en este modo, los hijos del COMANDO no serán limitados por tiempo
-k, --kill-after
envía también una señal KILL si el COMANDO sigue ejecutándose después de este tiempo desde que se envió la señal inicial
-p, --preserve-status
sale con el mismo estado que el COMANDO, incluso cuando el comando excede el tiempo límite
-s, --signal <SEÑAL>
especifica la señal que se enviará al agotar el tiempo; SEÑAL puede ser un nombre como 'HUP' o un número; consulta 'kill -l' para ver una lista de señales
-v, --verbose
diagnostica en stderr cualquier señal enviada al agotar el tiempo
-h, --help
Imprime la ayuda
-V, --version
Imprime la versión
<duracion>
un número de punto flotante con un sufijo opcional: 's' para segundos (el predeterminado), 'm' para minutos, 'h' para horas o 'd' para días; una duración de 0 deshabilita el tiempo límite asociado
<comando>
un comando a ejecutar con argumentos opcionales

EXTRA

Al agotar el tiempo, envía la señal TERM al COMANDO, si no se ha especificado otra SEÑAL. La señal TERM termina cualquier proceso que no bloquee o capture esa señal. Puede ser necesario usar la señal KILL, ya que esta señal no se puede capturar.

Estado de salida:
124 si el COMANDO agota el tiempo límite y no se especifica --preserve-status
125 si el propio comando timeout falla
126 si se encuentra el COMANDO pero no se puede invocar
127 si no se encuentra el COMANDO
137 si al COMANDO (o al propio timeout) se le envía la señal KILL (9) (128+9)
- el estado de salida del COMANDO en otros casos
