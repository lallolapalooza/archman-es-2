UNICODE_START(1) Manual de comandos generales UNICODE_START(1)

NOMBRE

unicode_start - pone el teclado y la consola en modo unicode

SINOPSIS

unicode_start [fuente [umap]]

DESCRIPCIÓN

El comando unicode_start pondrá el teclado y la consola en modo Unicode (UTF-8).

Para el teclado, esto significa que se pueden asignar valores de 16 bits U+xxxx a las teclas del teclado usando loadkeys(1), y que estos aparezcan como entrada UTF-8 para los programas de usuario. También, que se pueden escribir Alt-xxxx hexadecimales usando el teclado numérico, y de nuevo producir UTF-8.

Para la consola, esto significa que el kernel espera salida UTF-8 de los programas de usuario y muestra la salida en consecuencia.

El parámetro fuente es una fuente que se carga. Debe tener un mapa Unicode incorporado o, si no lo tiene, se puede proporcionar explícitamente como segundo parámetro. Cuando no se especifica ninguna fuente, se mantiene la fuente actual.

NOTA

El modo Unicode es un parámetro con un valor por consola virtual. Sin embargo, normalmente la fuente y el mapa de teclas son comunes a todas las consolas.
