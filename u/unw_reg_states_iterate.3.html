NOMBRE

unw_reg_states_iterate -- obtener información de estado de registros del procedimiento actual

SINOPSIS

#include <libunwind.h>

int unw_reg_states_iterate(unw_cursor_t *cp, unw_reg_states_callbackcb, void *token);

DESCRIPCIÓN

La rutina unw_reg_states_iterate() proporciona información sobre el procedimiento que creó el marco de pila identificado por el argumento cp. El argumento cb es un puntero a una función de tipo unw_reg_states_callback que se utiliza para devolver la información. La función unw_reg_states_callback tiene la siguiente definición:

int ( *unw_reg_states_callback)(void *token, void *reg_states_data, size_t reg_states_data_size, unw_word_t start_ip, unw_word_t end_ip);

La función de devolución de llamada puede invocarse varias veces por cada llamada a unw_reg_states_iterate. Cada llamada está asociada con un rango de direcciones de instrucción y un conjunto de instrucciones sobre cómo actualizar los valores de registro al regresar del procedimiento en ese rango de direcciones. Para cada invocación, los argumentos para la función de devolución de llamada son:

void * token

El valor del token pasado a unw_reg_states_callback.
void * reg_states_data

Un puntero a los datos sobre la actualización de los valores de registro. Estos datos, o una copia de ellos, se pueden pasar a unw_apply_reg_state.
int reg_states_data_size

El tamaño de los datos de actualización de registro.
unw_word_t start_ip

La dirección de la primera instrucción del rango de direcciones.
unw_word_t end_ip

La dirección de la primera instrucción después del final del rango de direcciones.

VALOR DE RETORNO

Al completarse con éxito, unw_reg_states_iterate() devuelve 0. Si la función de devolución de llamada devuelve un valor distinto de cero, eso indica un error y la función se retorna inmediatamente. De lo contrario, se devuelve el valor negativo de uno de los códigos de error a continuación.

SEGURIDAD DE HILOS Y SEÑALES

unw_reg_states_iterate() es segura para hilos. Si el cursor cp está en el espacio de direcciones local, esta rutina también es segura de usar desde un manejador de señales.

ERRORES

UNW_EUNSPEC

Ocurrió un error no especificado.
UNW_ENOINFO

Libunwind no pudo localizar información de desenrollado para el procedimiento.
UNW_EBADVERSION

La información de desenrollado del procedimiento tiene una versión o formato que libunwind no comprende.

Además, unw_reg_states_iterate() puede devolver cualquier error devuelto por la devolución de llamada access_mem() (ver unw_create_addr_space(3libunwind)).

VER TAMBIÉN

libunwind(3libunwind), unw_apply_reg_state(3libunwind)
