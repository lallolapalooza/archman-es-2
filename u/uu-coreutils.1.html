uu-coreutils(1) — Arch Linux man pages

NAME

uu-coreutils - Core utilities

SYNOPSIS

uu-coreutils [OPTION...] [SUBCOMMAND [ARG]...

If SUBCOMMAND is given, run that subcommand.

DESCRIPTION

Core utilities are the basic command-line utilities that are expected to exist on every Unix-like operating system. This package provides an implementation of the GNU coreutils.

The available subcommands are:
