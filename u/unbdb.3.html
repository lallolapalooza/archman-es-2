CUNBDB

Propósito:

!>
!> CUNBDB bidiagonaliza simultáneamente los bloques de una matriz unitaria M-por-M
!> particionada X:
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**H
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0  0  I ]
!>
!> X11 es P-por-Q. Q no debe ser mayor que P, M-P, o M-Q. (Si esto no
!> es así, entonces X debe ser transpuesta y/o permutada. Esto se puede
!> hacer en tiempo constante usando las opciones TRANS y SIGNS. Ver CUNCSD
!> para detalles.)
!>
!> Las matrices unitarias P1, P2, Q1 y Q2 son P-por-P, (M-P)-por-
!> (M-P), Q-por-Q y (M-Q)-por-(M-Q), respectivamente. Están
!> representadas implícitamente por vectores de Householder.
!>
!> B11, B12, B21 y B22 son matrices bidiagonales Q-por-Q representadas
!> implícitamente por los ángulos THETA, PHI.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER
!>          = 'T':      X, U1, U2, V1T y V2T se almacenan en orden de fila;
!>          de lo contrario:  X, U1, U2, V1T y V2T se almacenan en orden de
!>                      columna.
!>

SIGNS

!>          SIGNS es CHARACTER
!>          = 'O':      El bloque inferior izquierdo se hace no positivo (la
!>                       convención);
!>          de lo contrario:  El bloque superior derecho se hace no positivo (la
!>                       convención).
!>

M

!>          M es INTEGER
!>          El número de filas y columnas de X.
!>

P

!>          P es INTEGER
!>          El número de filas en X11 y X12. 0 <= P <= M.
!>

Q

!>          Q es INTEGER
!>          El número de columnas en X11 y X21. 0 <= Q <=
!>          MIN(P,M-P,M-Q).
!>

X11

!>          X11 es array COMPLEX, dimension (LDX11,Q)
!>          En la entrada, el bloque superior izquierdo de la matriz unitaria a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las columnas de tril(X11) especifican los reflectores para P1,
!>             las filas de triu(X11,1) especifican los reflectores para Q1;
!>          si no, TRANS = 'T', y
!>             las filas de triu(X11) especifican los reflectores para P1,
!>             las columnas de tril(X11,-1) especifican los reflectores para Q1.
!>

LDX11

!>          LDX11 es INTEGER
!>          La dimensión principal de X11. Si TRANS = 'N', entonces LDX11 >=
!>          P; si no, LDX11 >= Q.
!>

X12

!>          X12 es array COMPLEX, dimension (LDX12,M-Q)
!>          En la entrada, el bloque superior derecho de la matriz unitaria a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las filas de triu(X12) especifican los primeros P reflectores para
!>             Q2;
!>          si no, TRANS = 'T', y
!>             las columnas de tril(X12) especifican los primeros P reflectores
!>             para Q2.
!>

LDX12

!>          LDX12 es INTEGER
!>          La dimensión principal de X12. Si TRANS = 'N', entonces LDX12 >=
!>          P; si no, LDX11 >= M-Q.
!>

X21

!>          X21 es array COMPLEX, dimension (LDX21,Q)
!>          En la entrada, el bloque inferior izquierdo de la matriz unitaria a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las columnas de tril(X21) especifican los reflectores para P2;
!>          si no, TRANS = 'T', y
!>             las filas de triu(X21) especifican los reflectores para P2.
!>

LDX21

!>          LDX21 es INTEGER
!>          La dimensión principal de X21. Si TRANS = 'N', entonces LDX21 >=
!>          M-P; si no, LDX21 >= Q.
!>

X22

!>          X22 es array COMPLEX, dimension (LDX22,M-Q)
!>          En la entrada, el bloque inferior derecho de la matriz unitaria a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las filas de triu(X22(Q+1:M-P,P+1:M-Q)) especifican los últimos
!>             M-P-Q reflectores para Q2,
!>          si no, TRANS = 'T', y
!>             las columnas de tril(X22(P+1:M-Q,Q+1:M-P)) especifican los últimos
!>             M-P-Q reflectores para P2.
!>

LDX22

!>          LDX22 es INTEGER
!>          La dimensión principal de X22. Si TRANS = 'N', entonces LDX22 >=
!>          M-P; si no, LDX22 >= M-Q.
!>

THETA

!>          THETA es array REAL, dimension (Q)
!>          Las entradas de los bloques bidiagonales B11, B12, B21, B22 se pueden
!>          calcular a partir de los ángulos THETA y PHI. Ver Detalles Adicionales.
!>

PHI

!>          PHI es array REAL, dimension (Q-1)
!>          Las entradas de los bloques bidiagonales B11, B12, B21, B22 se pueden
!>          calcular a partir de los ángulos THETA y PHI. Ver Detalles Adicionales.
!>

TAUP1

!>          TAUP1 es array COMPLEX, dimension (P)
!>          Los factores escalares de los reflectores elementales que definen
!>          P1.
!>

!>          TAUP2 es array COMPLEX, dimension (M-P)
!>          Los factores escalares de los reflectores elementales que definen
!>          P2.
!>

!>          TAUQ1 es array COMPLEX, dimension (Q)

!>          Q1.
!>

TAUQ2

!>          TAUQ2 es array COMPLEX, dimension (M-Q)
!>          Los factores escalares de los reflectores elementales que definen
!>          Q2.
!>

WORK

!>          WORK es array COMPLEX, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= M-Q.
!>

CUNBDB

CUNBDB — Computes the bidiagonal decomposition of a partitioned unitary matrix.

SYNOPSIS

                           TAUP2, TAUQ1, TAUQ2, WORK, LWORK, INFO )

    CHARACTER        TRANS

    INTEGER          LDX12
    INTEGER          LDX21
    INTEGER          LDX22
    INTEGER          LWORK
    INTEGER          M
    INTEGER          P
    INTEGER          Q
    COMPLEX*16       WORK
    COMPLEX*16       X11
    COMPLEX*16       X12
    COMPLEX*16       X21
    COMPLEX*16       X22
    DOUBLE PRECISION PHI
    DOUBLE PRECISION TAUP1
    DOUBLE PRECISION TAUP2
    DOUBLE PRECISION TAUQ1
    DOUBLE PRECISION TAUQ2
    DOUBLE PRECISION THETA

SUBROUTINE CUNBDB( CHARACTER TRANS, CHARACTER SIGNS, INTEGER M, INTEGER P, INTEGER Q, COMPLEX*16, DIMENSION( LDX11, * ) X11, INTEGER LDX11, COMPLEX*16, DIMENSION( LDX12, * ) X12, INTEGER LDX12, COMPLEX*16, DIMENSION( LDX21, * ) X21, INTEGER LDX21, COMPLEX*16, DIMENSION( LDX22, * ) X22, INTEGER LDX22, DOUBLE PRECISION, DIMENSION( * ) THETA, DOUBLE PRECISION, DIMENSION( * ) PHI, DOUBLE PRECISION, DIMENSION( * ) TAUP1, DOUBLE PRECISION, DIMENSION( * ) TAUP2, DOUBLE PRECISION, DIMENSION( * ) TAUQ1, DOUBLE PRECISION, DIMENSION( * ) TAUQ2, COMPLEX*16, DIMENSION( * ) WORK, INTEGER LWORK, INTEGER INFO )

DESCRIPTION

CUNBDB simultaneously bidiagonalizes the blocks of an M-by-M partitioned unitary matrix X:

                                 [ B11 | B12 0  0 ]
     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**T
X = [-----------] = [---------] [----------------] [---------]   .
     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
                                 [  0  |  0  0  I ]

X11 is P-by-Q. Q must be no larger than P, M-P, or M-Q. (If this is not the case, then X must be transposed and/or permuted. This can be done in constant time using the TRANS and SIGNS options. See CUNCSD for details.)

The unitary matrices P1, P2, Q1, and Q2 are P-by-P, (M-P)-by-(M-P), Q-by-Q, and (M-Q)-by-(M-Q), respectively. They are represented implicitly by Householder vectors.

B11, B12, B21, and B22 are Q-by-Q bidiagonal matrices represented implicitly by angles THETA, PHI.

ARGUMENTS

TRANS

TRANS is CHARACTER

= 'T': X, U1, U2, V1T, and V2T are stored in row-major order;

otherwise: X, U1, U2, V1T, and V2T are stored in column-major order.

SIGNS

SIGNS is CHARACTER

= 'O': The lower-left block is made nonpositive (the convention);

otherwise: The upper-right block is made nonpositive (the convention).

M

M is INTEGER

The number of rows and columns in X.

P

P is INTEGER

The number of rows in X11 and X12. 0 <= P <= M.

Q

Q is INTEGER

The number of columns in X11 and X21. 0 <= Q <= MIN(P,M-P,M-Q).

X11

X11 is COMPLEX*16 array, dimension (LDX11,Q)

On entry, the top-left block of the unitary matrix to be reduced. On exit, the form depends on TRANS:

If TRANS = 'N', then
   the columns of tril(X11) specify reflectors for P1,
   the rows of triu(X11,1) specify reflectors for Q1;
else TRANS = 'T', and
   the rows of triu(X11) specify reflectors for P1,
   the columns of tril(X11,-1) specify reflectors for Q1.
LDX11

LDX11 is INTEGER

The leading dimension of X11. If TRANS = 'N', then LDX11 >= P; else LDX11 >= Q.

X12

X12 is COMPLEX*16 array, dimension (LDX12,M-Q)

On entry, the top-right block of the unitary matrix to be reduced. On exit, the form depends on TRANS:

If TRANS = 'N', then
   the rows of triu(X12) specify the first P reflectors for
   Q2;
else TRANS = 'T', and
   the columns of tril(X12) specify the first P reflectors
   for Q2.
LDX12

LDX12 is INTEGER

The leading dimension of X12. If TRANS = 'N', then LDX12 >= P; else LDX11 >= M-Q.

X21

X21 is COMPLEX*16 array, dimension (LDX21,Q)

On entry, the bottom-left block of the unitary matrix to be reduced. On exit, the form depends on TRANS:

If TRANS = 'N', then
   the columns of tril(X21) specify reflectors for P2;
else TRANS = 'T', and
   the rows of triu(X21) specify reflectors for P2.
LDX21

LDX21 is INTEGER

The leading dimension of X21. If TRANS = 'N', then LDX21 >= M-P; else LDX21 >= Q.

X22

X22 is COMPLEX*16 array, dimension (LDX22,M-Q)

On entry, the bottom-right block of the unitary matrix to be reduced. On exit, the form depends on TRANS:

If TRANS = 'N', then
   the rows of triu(X22(Q+1:M-P,P+1:M-Q)) specify the last
   M-P-Q reflectors for Q2,
else TRANS = 'T', and
   the columns of tril(X22(P+1:M-Q,Q+1:M-P)) specify the last
   M-P-Q reflectors for P2.
LDX22

LDX22 is INTEGER

The leading dimension of X22. If TRANS = 'N', then LDX22 >= M-P; else LDX22 >= M-Q.

THETA

THETA is DOUBLE PRECISION array, dimension (Q)

The entries of the bidiagonal blocks B11, B12, B21, B22 can be computed from the angles THETA and PHI. See Further Details.

PHI

PHI is DOUBLE PRECISION array, dimension (Q-1)

The entries of the bidiagonal blocks B11, B12, B21, B22 can be computed from the angles THETA and PHI. See Further Details.

TAUP1

TAUP1 is DOUBLE PRECISION array, dimension (P)

The scalar factors of the elementary reflectors that define P1.

TAUP2

TAUP2 is DOUBLE PRECISION array, dimension (M-P)

The scalar factors of the elementary reflectors that define P2.

TAUQ1

TAUQ1 is DOUBLE PRECISION array, dimension (Q)

The scalar factors of the elementary reflectors that define Q1.

TAUQ2

TAUQ2 is DOUBLE PRECISION array, dimension (M-Q)

The scalar factors of the elementary reflectors that define Q2.

WORK

WORK is COMPLEX*16 array, dimension (LWORK)

LWORK

LWORK is INTEGER

The dimension of the array WORK. LWORK >= M-Q.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

INFO

INFO is INTEGER

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

AUTHOR

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

FURTHER DETAILS

The bidiagonal blocks B11, B12, B21, and B22 are represented
implicitly by angles THETA(1), ..., THETA(Q) and PHI(1), ...,
PHI(Q-1). B11 and B21 are upper bidiagonal, while B21 and B22 are
lower bidiagonal. Every entry in each bidiagonal band is a product
of a sine or cosine of a THETA with a sine or cosine of a PHI. See
[1] or CUNCSD for details.

P1, P2, Q1, and Q2 are represented as products of elementary
reflectors. See CUNCSD for details on generating P1, P2, Q1, and Q2
using CUNGQR and CUNGLQ.

REFERENCES

[1] Brian D. Sutton. Computing the complete CS

decomposition. Numer. Algorithms, 50(1):33-65, 2009.
