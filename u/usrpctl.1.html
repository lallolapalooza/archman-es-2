usrpctl(1) Comandos de Usuario usrpctl(1)

NOMBRE

usrpctl - Herramienta de Configuración de Periféricos del Driver de Hardware USRP

DESCRIPCIÓN

Reporta información detallada sobre los Periféricos de Radio Definida por Software compatibles con UHD adjuntos por USB, red o configuración embebida. Permite la actualización y configuración de los dispositivos adjuntos.

El paquete UHD es el driver universal de hardware para los productos de Ettus Research. El objetivo es proporcionar un driver y una API de host para los productos actuales y futuros de Ettus Research. Los usuarios podrán usar el driver UHD de forma independiente o con aplicaciones de terceros.

Los detalles incluyen nombres de unidad, números de revisión y sensores disponibles en todas las placas base y placas hijas USRP adjuntas.

SINOPSIS

usrpctl [ID] COMANDO [OPCIONES]

ID

ID es el argumento opcional del dispositivo. Se utiliza para definir un conjunto de dispositivos USRP a los que se aplicará el COMANDO. Si se omite ID, el COMANDO se aplica a todos los dispositivos accesibles.

usrpctl entiende el argumento de argumentos de dispositivo utilizado por otras herramientas de UHD como uhd_find_devices.

COMANDO

Es la acción que la herramienta debe realizar. Cada comando puede aplicarse a un solo dispositivo o a un grupo de dispositivos. Los comandos que se ejecutan en un grupo de dispositivos repiten el comando para cada dispositivo.

- Comandos de un solo dispositivo:
- config: Lee/escribe variables de configuración (por ejemplo, dirección IP)
- probe: lee información extendida sobre el USRP - Comandos de múltiples dispositivos:
- update: Actualiza binarios (por ejemplo, imagen FPGA)
- reset: Restablece los subcomponentes especificados del USRP
- find: encuentra todos los USRP disponibles en esta red

OPCIONES

Las opciones no son siempre obligatorias. Depende del COMANDO dado.

comando find

El comando find no toma opciones adicionales. Si no se proporciona ID, escanea el sistema en busca de dispositivos disponibles y compatibles e imprime una lista de los dispositivos descubiertos. La salida es compatible con uhd_find_devices. ID se puede utilizar para reducir la lista de dispositivos descubiertos.

comando probe

Imprime un árbol de propiedades completo:
-tree
El comando probe solo se puede aplicar a un solo dispositivo, así que asegúrate de que
ID identifique exactamente un dispositivo. Sin argumentos, muestra información detallada sobre el dispositivo, como nombre, número de serie, revisión, versión del firmware e información de sensores en la placa base y placas hijas adjuntas.

comando reset

Restablecer MPM:
-mpm
El comando reset restablece subcomponentes especificados de un dispositivo. Si no se
proporciona ID, escanea el sistema en busca de dispositivos disponibles y compatibles y restablece el subcomponente especificado de todos los dispositivos descubiertos.

EJEMPLOS

usrpctl find
encuentra todos los dispositivos compatibles
usrpctl type=x300,product=X310 find
encuentra todos los dispositivos x310
usrpctl name=my_usrp find
encuentra un dispositivo llamado my_usrp
usrpctl addr=192.168.10.2 find
encuentra un dispositivo con la IP dada.
usrpctl addr=192.168.10.2 probe
muestra información del dispositivo para el USRP con la ID dada
usprctl name=my_usrp probe -tree
muestra el árbol de propiedades del dispositivo con el nombre my_usrp
usrpctl addr=192.168.10.2 reset -mpm
Restablece MPM en el dispositivo con la IP dada.
