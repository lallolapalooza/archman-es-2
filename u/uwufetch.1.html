UWUFETCH(1) Una herramienta de información de sistema meme para Linux UWUFETCH(1)

DESCRIPCIÓN

UwUfetch es un programa inspirado en neofetch y ufetch, que toma información del sistema y la imprime en la terminal de una manera UwU, con un logo ASCII o de imagen.

SINOPSIS

uwufetch [OPCIONES] [ARGUMENTOS]

OPCIONES

-c --configuración
puedes cambiar la ruta de la configuración
-d --distro
te permite elegir el logo a imprimir basado en el nombre de la distribución
-h --ayuda
imprime la página de ayuda
-i --imagen
imprime una imagen en lugar del logo ASCII; utiliza una imagen personalizada si se proporciona (desactivado en iOS) funciona en la mayoría de las terminales, lee README.md para más información
-l --listar
imprime una lista de todas las distribuciones soportadas
-r --leer-caché
lee el archivo caché (~/.cache/uwufetch.cache)
-v --versión
imprime la versión actual de uwufetch
-w --escribir-caché
escribe en el archivo caché (~/.cache/uwufetch.cache)

CONFIGURACIÓN

El archivo de configuración a nivel de sistema es /etc/uwufetch/config, y puedes usarlo para configurar uwufetch globalmente o como plantilla para tu propia configuración. El archivo de configuración del usuario se encuentra en $HOME/.config/uwufetch/config (debes crearlo), pero puedes cambiar la ruta usando la opción --configuración.

EJEMPLO

distro=arch
imagen=ruta/a/imagen_personalizada.png
usuario=true
so=true
host=true
kernel=true
cpu=true
gpu=0
gpu=3
gpu=1
ram=true
resolución=true
shell=true
pkgs=true
uptime=true
colores=true

EJEMPLOS

uwufetch -d arch                  # usa el logo ASCII de Arch
uwufetch -i alguna_imagen.png  # imprime una imagen personalizada (no se necesita ruta completa)
uwufetch -id artix              # usa el logo de imagen de Artix (que también es uwu)

DEPENDENCIAS

freecolor
uso de RAM en FreeBSD
libc (requerido)
glibc en sistemas gnu o musl en sistemas no-gnu
viu
imprime imágenes en lugar del logo ASCII
xwininfo
obtiene la resolución de pantalla
lshw
mejor información de GPU
kitty
mejor visualización de imágenes

Todas estas dependencias son opcionales. No hay dependencias requeridas (excepto libc).
