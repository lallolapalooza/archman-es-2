UXTERM(1) Sistema de ventanas X UXTERM(1)

NOMBRE

uxterm - emulador de terminal X para entornos Unicode (UTF-8)

SINOPSIS

uxterm [ opciones-de-xterm ]

DESCRIPCIÓN

uxterm es un script de envoltura alrededor del programa xterm(1) que invoca a este último con la clase de recurso X "UXTerm" establecida. Todos los argumentos para uxterm se pasan a xterm sin procesamiento; las opciones -class y -u8 no deben especificarse ya que son utilizadas por el script de envoltura. Consulte la página del manual de xterm para obtener más información sobre opciones-de-xterm.

La configuración de la configuración regional del entorno (consulte "ENTORNO" a continuación) se utiliza para determinar el conjunto de caracteres de la configuración regional. Si no se puede determinar ninguna configuración regional actual, se asume la configuración regional "en_US" (el idioma inglés tal como se usa en el territorio de los Estados Unidos). La utilidad locale(1) se utiliza para determinar si el sistema admite la configuración regional seleccionada. Si no es así, uxterm saldrá con un error e informará la salida de locale.

Nota: uxterm puede producir resultados inesperados si la configuración regional actual se establece en una que no admita la codificación de caracteres UTF-8, o si las fuentes que utilizan el conjunto de caracteres ISO 10646-1 no están disponibles. En el sistema Debian, el paquete "xfonts-base" proporciona las fuentes que uxterm utiliza por defecto. Para cambiar las fuentes que utiliza uxterm, edite el archivo /usr/share/X11/app-defaults//UXTerm.

Una envoltura similar, koi8rxterm(1), está disponible para entornos KOI8-R.

AMBIENTE

LC_ALL, LC_CTYPE, LANG
Los valores de estas variables se comprueban, en orden, para determinar el conjunto de caracteres utilizado por la configuración regional actual.
