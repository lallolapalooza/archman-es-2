CUNM2R multiplica una matriz general por la matriz unitaria de una factorización QR determinada por cgeqrf (algoritmo sin bloques).

Propósito:

!>
!> CUNM2R sobrescribe la matriz compleja general m por n C con
!>
!>       Q * C  si SIDE = 'L' y TRANS = 'N', o
!>
!>       Q**H* C  si SIDE = 'L' y TRANS = 'C', o
!>
!>       C * Q  si SIDE = 'R' y TRANS = 'N', o
!>
!>       C * Q**H si SIDE = 'R' y TRANS = 'C',
!>
!> donde Q es una matriz unitaria compleja definida como el producto de k
!> reflectores elementales
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> tal como devuelve CGEQRF. Q es de orden m si SIDE = 'L' y de orden n
!> si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda
!>          = 'R': aplicar Q o Q**H desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar Q (Sin transpuesta)
!>          = 'C': aplicar Q**H (Transpuesta conjugada)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,K)
!>          La i-ésima columna debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como lo
!>          devuelve CGEQRF en las primeras k columnas de su argumento
!>          de array A.
!>          A es modificado por la rutina pero restaurado a la salida.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU es un array COMPLEX, dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como lo devuelve CGEQRF.
!>

C

!>          C es un array COMPLEX, dimensión (LDC,N)
!>          A la entrada, la matriz m por n C.
!>          A la salida, C es sobrescrito por Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX, dimensión
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detailed Description

This module contains routines that apply orthogonal transformations to a matrix. The orthogonal transformations are determined by the QR factorization of a matrix A. The routines compute:

    op(Q) * C

or

    C * op(Q)

where C is an m-by-n matrix, and Q is an orthogonal or unitary matrix defined as the product of k elementary reflectors.

The routines differ in the data type of the matrix:

  • DORM2R for double precision real matrices.
  • SORM2R for single precision real matrices.
  • UNM2R for single precision complex matrices.
  • ZUNM2R for double precision complex matrices.

The routines use an unblocked algorithm to perform the matrix-vector multiplication.

The routines have the following parameters:

SIDE
Specifies whether Q or QH is applied from the left or the right.
  • 'L': Q * C or QH * C
  • 'R': C * Q or C * QH
TRANS
Specifies whether Q or QH is applied.
  • 'N': Apply Q (No transpose)
  • 'T': Apply QT (Transpose, for real routines)
  • 'C': Apply QH (Conjugate transpose, for complex routines)
M
The number of rows of the matrix C. Must be non-negative.
N
The number of columns of the matrix C. Must be non-negative.
K
The number of elementary reflectors whose product defines the matrix Q.
  • If SIDE = 'L', M >= K >= 0.
  • If SIDE = 'R', N >= K >= 0.
A
The array containing the vectors that define the elementary reflectors. This array is modified by the routine but restored on exit.
LDA
The leading dimension of the array A.
  • If SIDE = 'L', LDA >= max(1, M).
  • If SIDE = 'R', LDA >= max(1, N).
TAU
The array containing the scalar factors of the elementary reflectors.
C
On entry, the m-by-n matrix C. On exit, C is overwritten by the result of the operation.
LDC
The leading dimension of the array C. LDC >= max(1, M).
WORK
A workspace array. The dimension depends on SIDE:
  • If SIDE = 'L', dimension is (N).
  • If SIDE = 'R', dimension is (M).
INFO
On exit, INFO is 0 if the execution is successful, and less than 0 if an error occurred. If INFO = -i, the i-th argument had an illegal value.

DORM2R multiplies a general real matrix by the orthogonal matrix from a QR factorization determined by dgeqrf (unblocked algorithm).

Purpose:

!>
!> DORM2R overwrites the general real m by n matrix C with
!>
!>       Q * C  if SIDE = 'L' and TRANS = 'N', or
!>
!>       Q**T* C  if SIDE = 'L' and TRANS = 'T', or
!>
!>       C * Q  if SIDE = 'R' and TRANS = 'N', or
!>
!>       C * Q**T if SIDE = 'R' and TRANS = 'T',
!>
!> where Q is a real orthogonal matrix defined as the product of k
!> elementary reflectors
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> as returned by DGEQRF. Q is of order m if SIDE = 'L' and of order n
!> if SIDE = 'R'.
!>

Parameters

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': apply Q or Q**T from the Left
!>          = 'R': apply Q or Q**T from the Right
!>

TRANS

!>          TRANS is CHARACTER*1
!>          = 'N': apply Q  (No transpose)
!>          = 'T': apply Q**T (Transpose)
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix C. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix C. N >= 0.
!>

K

!>          K is INTEGER
!>          The number of elementary reflectors whose product defines
!>          the matrix Q.
!>          If SIDE = 'L', M >= K >= 0;
!>          if SIDE = 'R', N >= K >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,K)
!>          The i-th column must contain the vector which defines the
!>          elementary reflector H(i), for i = 1,2,...,k, as returned by
!>          DGEQRF in the first k columns of its array argument A.
!>          A is modified by the routine but restored on exit.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.
!>          If SIDE = 'L', LDA >= max(1,M);
!>          if SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU is DOUBLE PRECISION array, dimension (K)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by DGEQRF.
!>

C

!>          C is DOUBLE PRECISION array, dimension (LDC,N)
!>          On entry, the m by n matrix C.
!>          On exit, C is overwritten by Q*C or Q**T*C or C*Q**T or C*Q.
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension
!>                                   (N) if SIDE = 'L',
!>                                   (M) if SIDE = 'R'
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>
