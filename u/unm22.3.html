CUNM22 multiplica una matriz general por una matriz unitaria bandeada.

Propósito

!>
!>  CUNM22 sobrescribe la matriz general compleja M por N, C, con
!>
!>                  SIDE = 'L'     SIDE = 'R'
!>  TRANS = 'N':      Q * C          C * Q
!>  TRANS = 'C':      Q**H * C       C * Q**H
!>
!>  donde Q es una matriz unitaria compleja de orden NQ, con NQ = M si
!>  SIDE = 'L' y NQ = N si SIDE = 'R'.
!>  La matriz unitaria Q procesa una estructura de bloques de 2x2
!>
!>         [  Q11  Q12  ]
!>     Q = [            ]
!>         [  Q21  Q22  ],
!>
!>  donde Q12 es una matriz triangular inferior de N1xN1 y Q21 es una
!>  matriz triangular superior de N2xN2.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la izquierda;
!>          = 'R': aplicar Q o Q**H desde la derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  aplicar Q (Sin transponer);
!>          = 'C':  aplicar Q**H (Transpuesta conjugada).
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

N1
N2

!>          N1 es INTEGER
!>          N2 es INTEGER
!>          La dimensión de Q12 y Q21, respectivamente. N1, N2 >= 0.
!>          Se debe cumplir el siguiente requisito:
!>          N1 + N2 = M si SIDE = 'L' y N1 + N2 = N si SIDE = 'R'.
!>

Q

!>          Q es un array de tipo COMPLEX, dimensión
!>                              (LDQ,M) si SIDE = 'L'
!>                              (LDQ,N) si SIDE = 'R'
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.
!>          LDQ >= max(1,M) si SIDE = 'L'; LDQ >= max(1,N) si SIDE = 'R'.
!>

C

!>          C es un array de tipo COMPLEX, dimensión (LDC,N)
!>          En la entrada, la matriz M por N, C.
!>          En la salida, C se sobrescribe con Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array de tipo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N);
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Para un rendimiento óptimo, LWORK >= M*N.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

NAME

dorm22, sorm22, zorm22 - are generally not used, as they are wrappers to implement transpose or conjugate transpose updates of a general matrix.

SYNOPSIS

  SUBROUTINE dorm22( SIDE, TRANS, M, N, N1, N2, A, LDA, TAU, C, LDC, WORK, LWORK, INFO )


  SUBROUTINE sorm22( SIDE, TRANS, M, N, N1, N2, A, LDA, TAU, C, LDC, WORK, LWORK, INFO )


  SUBROUTINE zorm22( SIDE, TRANS, M, N, N1, N2, A, LDA, TAU, C, LDC, WORK, LWORK, INFO )

Detailed Description

This subroutine is intended to be called only by other LAPACK routines which model the matrix-vector multiply by Q.

This routine is not part of the public LAPACK API.

The orthogonal matrix Q is represented by its block Householder reflector vectors, or equivalently by the entries of its upper and lower triangular block factors.

This routine overwrites the general matrix C with:

SIDE = 'L' SIDE = 'R'

TRANS = 'N': Q * C C * Q

TRANS = 'T': Q**T * C C * Q**T

where Q is an orthogonal matrix of order NQ. NQ = M if SIDE = 'L' and NQ = N if SIDE = 'R'.

The orthogonal matrix Q processes a 2-by-2 block structure

Q = [ Q11 Q12 ]

[ Q21 Q22 ]

where Q12 is an N1-by-N1 lower triangular matrix and Q21 is an N2-by-N2 upper triangular matrix.

subroutine dorm22 (character side, character trans, integer m, integer n, integer n1, integer n2, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer lwork, integer info)

DORM22 multiplies a general matrix by a banded orthogonal matrix.

Purpose

!>
!>
!>  DORM22 overwrites the general real M-by-N matrix C with
!>
!>                  SIDE = 'L'     SIDE = 'R'
!>  TRANS = 'N':      Q * C          C * Q
!>  TRANS = 'T':      Q**T * C       C * Q**T
!>
!>  where Q is a real orthogonal matrix of order NQ, with NQ = M if
!>  SIDE = 'L' and NQ = N if SIDE = 'R'.
!>  The orthogonal matrix Q processes a 2-by-2 block structure
!>
!>         [  Q11  Q12  ]
!>     Q = [            ]
!>         [  Q21  Q22  ],
!>
!>  where Q12 is an N1-by-N1 lower triangular matrix and Q21 is an
!>  N2-by-N2 upper triangular matrix.
!>

Parameters

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': apply Q or Q**T from the Left;
!>          = 'R': apply Q or Q**T from the Right.
!>

TRANS

!>          TRANS is CHARACTER*1
!>          = 'N':  apply Q (No transpose);
!>          = 'T':  apply Q**T (Transpose).
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix C. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix C. N >= 0.
!>

N1
N2

!>          N1 is INTEGER
!>          N2 is INTEGER
!>          The dimension of Q12 and Q21, respectively. N1, N2 >= 0.
!>          The following requirement must be satisfied:
!>          N1 + N2 = M if SIDE = 'L' and N1 + N2 = N if SIDE = 'R'.
!>

A

!>          A is REAL array, dimension
!>                              (LDA,N) if SIDE = 'L'
!>                              (LDA,M) if SIDE = 'R'
!>          The entries of the block Householder reflectors,
!>          returned by the routines which compute the factorization of Q.
!>          A is not used if NB = 1.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.
!>          LDA >= max(1,M) if SIDE = 'L'; LDA >= max(1,N) if SIDE = 'R'.
!>

TAU

!>          TAU is REAL array, dimension (min(M,N))
!>          The scalar tau for the Householder reflectors,
!>          returned by the routines which compute the factorization of Q.
!>          TAU is not used if NB = 1.
!>

C

!>          C is REAL array, dimension (LDC,N)
!>          On entry, the M-by-N matrix C.
!>          On exit, C is overwritten by Q*C or Q**T*C or C*Q**T or C*Q.
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          If SIDE = 'L', LWORK >= max(1,N);
!>          if SIDE = 'R', LWORK >= max(1,M).
!>          For optimum performance LWORK >= M*N.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
