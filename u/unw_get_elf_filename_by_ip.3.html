NOMBRE

unw_get_elf_filename_by_ip -- obtener el nombre del archivo ELF subyacente por puntero de instrucción

SINOPSIS

#include <libunwind.h>

int unw_get_elf_filename_by_ip(unw_addr_space_t as, unw_word_t ip, char *bufp, size_t len, unw_word_t *offp, void *arg);

DESCRIPCIÓN

La rutina unw_get_elf_filename_by_ip() devuelve el nombre del archivo ELF subyacente de un puntero de instrucción, al igual que unw_get_elf_filename(), excepto que el nombre se busca por puntero de instrucción (IP) en lugar de por cursor.

La rutina espera los siguientes argumentos: as es el espacio de direcciones en el que se debe buscar el puntero de instrucción. Para una búsqueda en el espacio de direcciones local, se puede pasar unw_local_addr_space para este argumento. El argumento ip es el puntero de instrucción para el que se debe buscar el nombre del archivo ELF. El argumento bufp es un puntero a un búfer de caracteres que tiene al menos len bytes de longitud. Este búfer se utiliza para devolver el nombre del archivo ELF. El argumento offp es un puntero a una palabra que se utiliza para devolver el desplazamiento en bytes del puntero de instrucción relativo al inicio del nombre del archivo ELF. Por último, arg es el argumento del espacio de direcciones que se debe utilizar al acceder al espacio de direcciones. Tiene el mismo propósito que el argumento del mismo nombre para unw_init_remote(). Al acceder al espacio de direcciones local (el primer argumento es unw_local_addr_space), se debe pasar NULL para este argumento.

VALOR DE RETORNO

Al completarse con éxito, unw_get_elf_filename_by_ip() devuelve 0. De lo contrario, se devuelve el valor negativo de uno de los códigos de error a continuación.

SEGURIDAD DE HILOS Y SEÑALES

unw_get_elf_filename_by_ip() es seguro para hilos. Si se pasa el espacio de direcciones local en el argumento as, esta rutina también es segura de usar desde un manejador de señales.

ERRORES

UNW_EUNSPEC

Ocurrió un error no especificado.
UNW_ENOINFO

Libunwind no pudo determinar el nombre del archivo ELF del puntero de instrucción.
UNW_ENOMEM

El nombre del archivo ELF es demasiado largo para caber en el búfer proporcionado. Se ha devuelto una versión truncada del nombre.
