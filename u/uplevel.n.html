uplevel(n)

Paquete: tcl

Licencias: TCL

uplevel(n) Comandos integrados de Tcl uplevel(n)

NOMBRE

uplevel - Ejecuta un script en un frame de pila diferente

SINOPSIS

uplevel ?nivel? arg ?arg ...?

DESCRIPCIÓN

Todos los argumentos arg se concatenan como si se hubieran pasado a concat; el resultado se evalúa entonces en el contexto de variables indicado por nivel. Uplevel devuelve el resultado de esa evaluación.

Si nivel es un entero, indica una distancia (hacia arriba en la pila de llamadas de procedimientos) a moverse antes de ejecutar el comando. Si nivel consiste en # seguido de un número, el número indica un número de nivel absoluto. Si nivel se omite, por defecto es 1. Nivel no puede omitirse si el primer argumento comando comienza con un dígito o con #.

Por ejemplo, supongamos que el procedimiento a fue invocado desde el nivel superior, y que llamó a b, y que b llamó a c. Supongamos que c invoca el comando uplevel. Si nivel es 1 o #2 u omitido, el comando se ejecutará en el contexto de variables de b. Si nivel es 2 o #1, el comando se ejecutará en el contexto de variables de a. Si nivel es 3 o #0, el comando se ejecutará en el nivel superior (solo las variables globales serán visibles).

El comando uplevel hace que el procedimiento invocador desaparezca de la pila de llamadas de procedimientos mientras se ejecuta el comando. En el ejemplo anterior, supongamos que c invoca el comando

uplevel 1 {set x 43; d}

donde d es otro procedimiento Tcl. El comando set modificará la variable x en el contexto de b, y d se ejecutará en el nivel 3, como si fuera llamado desde b. Si a su vez ejecuta el comando

uplevel {set x 42}

entonces el comando set modificará la misma variable x en el contexto de b: el procedimiento c no parece estar en la pila de llamadas cuando d se está ejecutando. El comando info level puede usarse para obtener el nivel del procedimiento actual.

Uplevel hace posible implementar nuevas construcciones de control como procedimientos Tcl (por ejemplo, uplevel podría usarse para implementar la construcción while como un procedimiento Tcl).

Los comandos namespace eval y apply ofrecen otras formas (además de las llamadas a procedimientos) en las que el contexto de nombres de Tcl puede cambiar. Añaden un frame de llamada a la pila para representar el contexto del espacio de nombres. Esto significa que cada comando namespace eval cuenta como otro nivel de llamada para los comandos uplevel y upvar. Por ejemplo, info level 1 devolverá una lista que describe un comando que es o bien la llamada a procedimiento más externa o bien el comando namespace eval más externo. Además, uplevel #0 evalúa un script en el nivel superior en el espacio de nombres más externo (el espacio de nombres global).

EJEMPLO

Como se indicó anteriormente, el comando uplevel es útil para crear nuevas construcciones de control. Este ejemplo muestra cómo (sin manejo de errores) se puede usar para crear un comando do que sea el complemento de while, excepto por realizar siempre la prueba después de ejecutar el cuerpo del bucle:

proc do {body while condition} {
    if {$while ne "while"} {
        error "palabra requerida faltante"
    }
    set conditionCmd [list expr $condition]
    while {1} {
        uplevel 1 $body
        if {![uplevel 1 $conditionCmd]} {
            break
        }
    }
}
