UNCRUSTIFY(1) Comandos de usuario UNCRUSTIFY(1)

NOMBRE

uncrustify - formateador de código fuente C, C++, C#, D, Java y Pawn

SINOPSIS

uncrustify [OPCIONES] [ARCHIVOS]

DESCRIPCIÓN

Si no se especifican archivos de entrada, la entrada se lee desde stdin.
Si se lee desde stdin, debes especificar el idioma usando -l.

Si se usa -F o se especifican archivos en la línea de comandos, el nombre del archivo de salida es PFX + "/" + nombre_archivo + SFX.
A menos, por supuesto, que se utilicen las opciones --replace o --no-backup.

Al leer desde stdin o procesar un único archivo con la opción '-f', la salida se vuelca a stdout, a menos que se redirija con -o ARCHIVO.

Los errores siempre se vuelcan a stderr.

OPCIONES

Opciones básicas:

-c CFG
Utiliza el archivo de configuración CFG, o los valores predeterminados si CFG se establece en '-'.
Si no se especifica, uncrustify usará $UNCRUSTIFY_CONFIG o $HOME/.uncrustify.cfg.
-f ARCHIVO
Procesa el archivo único ARCHIVO, enviando la salida a stdout o al archivo especificado con -o.
-o ARCHIVO
Redirige la salida al ARCHIVO.
Úsalo con -f, --update-config, --update-config-with-doc, --universalindent.
--check
No genera el nuevo texto, en su lugar verifica que nada cambie cuando se procesan los archivos. El estado de cada archivo se imprime en stderr. El código de salida es EXIT_SUCCESS si no hubo cambios, EXIT_FAILURE en caso contrario.
-F ARCHIVO
Lee los archivos a procesar desde ARCHIVO, un nombre de archivo por línea. Si ARCHIVO es ´-´, lee los nombres de archivo desde la entrada estándar en lugar de un archivo.
Puedes crear este archivo usando algo como ´find . -name "*.c" > list.txt´.
Esto no se puede combinar con -f.
--prefix PFX
Antepone PFX a la ruta del nombre de archivo de salida.
Esto no se puede combinar con -f, --replace o --no-backup.
--suffix SFX
Añade SFX al nombre de archivo de salida.
El valor predeterminado es '.uncrustify' si no se especifica ni SFX ni PFX.
Esto no se puede combinar con -f, --replace o --no-backup.
--frag
Asume que la entrada es un fragmento de código y que la primera línea está correctamente indentada.
--replace
Reemplaza los archivos fuente (crea una copia de seguridad).
Esto no se puede combinar con -f, --prefix o --suffix.
--no-backup
Reemplaza archivos, sin copia de seguridad. Útil si los archivos están bajo control de código fuente.
Esto no se puede combinar con -f, --prefix o --suffix.
--if-changed
Escribe en stdout (o crea el ARCHIVO de salida) solo si se detectó un cambio.
--mtime
Preserva la hora de modificación en los archivos reemplazados.
-l
Sobrescribe el idioma: C, CPP, D, CS, JAVA, PAWN, VALA, OC, OC+
-t
Carga un archivo con tipos (generalmente no es necesario)
-q
Modo silencioso: sin salida en stderr (-L anulará esto)

Opciones de configuración/ayuda:

-h -? --help --usage
Imprime este mensaje y sale.
--version
Imprime la versión y sale.
--count-options
Imprime el número de opciones disponibles y sale.
--show-config
Imprime la documentación de las opciones y sale.
--update-config
Genera un nuevo archivo de configuración.
--update-config-with-doc
Genera un nuevo archivo de configuración con comentarios de uso incrustados.
--universalindent
Genera un archivo de configuración para la GUI Universal Indent.
--detect
Detecta la configuración a partir de un archivo fuente. Úsalo con '-f ARCHIVO'. La detección es actualmente bastante limitada.
--tracking space:ARCHIVO
Prepara información de seguimiento de espacios para depuración.
--tracking nl:ARCHIVO
Prepara información de seguimiento de saltos de línea para depuración.
--tracking start:ARCHIVO
Prepara información de seguimiento de inicio de sentencia para depuración. No se puede usar con la opción -o.

Opciones de depuración:

-p ARCHIVO
Vuelca información de depuración en ARCHIVO, o a stdout si ARCHIVO se establece en '-'.
Debe usarse en combinación con '-f ARCHIVO'.
-ds ARCHIVO --dump-steps ARCHIVO
Vuelca información de análisis en varios momentos del proceso de formateo.
Esto crea una serie de archivos llamados 'ARCHIVO_nnn.log', cada uno
correspondiente a un paso de formateo en uncrustify.
El archivo 'ARCHIVO_000.log' enumera las opciones de formateo en uso.
Debe usarse en combinación con '-f ARCHIVO'.
-L SEVERIDAD
Establece la severidad del registro (ver log_levels.h)
-s
Muestra la severidad del registro en los registros.
--decode BANDERA
Imprime BANDERA como texto y sale.

EJEMPLOS

Leer un archivo D desde stdin, salida a stdout.
cat foo.d | uncrustify -q -c my.cfg -l d
Procesar un archivo, salida a stdout.
uncrustify -c my.cfg -d foo.d
Procesar un árbol de fuentes, salida a un árbol diferente.
find src -name "*.[ch]" > files.txt
uncrustify -c my.cfg -F files.txt --prefix out
Procesar un árbol de fuentes en el lugar.
uncrustify -c my.cfg --no-backup $(find src -name "*.[ch]")

NOTAS

Usa comentarios que contengan ' *INDENT-OFF*' y ' *INDENT-ON*' para deshabilitar el procesamiento de partes del archivo fuente.
