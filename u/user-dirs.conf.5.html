NOMBRE

user-dirs.conf - configuración para xdg-user-dirs-update

DESCRIPCIÓN

El archivo /etc/xdg/user-dirs.conf es un archivo de texto que controla el comportamiento del comando xdg-user-dirs-update. Los usuarios pueden tener su propio archivo ~/.config/user-dirs.conf, que anula la configuración global del sistema.

Se reconocen las siguientes claves:

enabled=booleano

Cuando se establece en Falso, xdg-user-dirs-update no cambiará la configuración de los directorios de usuario XDG.

filename_encoding=codificación

Esto establece la codificación de nombres de archivo a utilizar. codificación puede ser un nombre de codificación explícito, como UTF-8, o "locale", lo que significa que se utilizará la codificación de la configuración regional del usuario.

Las líneas que comienzan con un carácter # se ignoran.

AMBIENTE

XDG_CONFIG_DIRS

El archivo user-dirs.conf global del sistema se encuentra en este directorio. El valor predeterminado es /etc/xdg.

XDG_CONFIG_HOME

El archivo user-dirs.conf por usuario se encuentra en este directorio. El valor predeterminado es $HOME/.config.

VER TAMBIÉN

xdg-user-dirs-update(1)
