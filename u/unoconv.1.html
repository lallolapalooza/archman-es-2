NOMBRE

unoconv - convierte cualquier documento desde y hacia cualquier formato soportado por LibreOffice

SINOPSIS

unoconv [opciones] archivo [archivo2 ..]

unoconv --listener [--server SRV] [--port PRT] [--connection CON]

DESCRIPCIÓN

unoconv es una utilidad de línea de comandos que puede convertir cualquier formato de archivo que LibreOffice pueda importar, a cualquier formato de archivo que LibreOffice sea capaz de exportar.

unoconv utiliza los enlaces UNO de LibreOffice para la conversión no interactiva de documentos y, por lo tanto, necesita una instancia de LibreOffice con la que comunicarse. Por lo tanto, si no encuentra una, iniciará su propia instancia para uso temporal. Si se desea, se puede iniciar una instancia de "escucha" para usarla en conexiones posteriores o incluso para conexiones remotas.

OPCIONES

-c, --connection

Cadena de conexión UNO a utilizar por el cliente para conectarse a una instancia de LibreOffice, o utilizada por el oyente para que LibreOffice escuche. 
La cadena de conexión predeterminada es "socket,host=localhost,port=2002;urp;StarOffice.ComponentContext"

-d, --doctype

Especifica el tipo de documento de LibreOffice del formato de salida. Los tipos de documento posibles son: document, graphics, presentation, spreadsheet. 
El tipo de documento predeterminado es 'document'.

-e, --export

Establece opciones específicas del filtro de exportación (relacionadas con el filtro de LibreOffice utilizado). 
por ejemplo, para el filtro de salida PDF se puede especificar: -e PageRange=1-2
Ver la sección *FILTROS DE EXPORTACIÓN*.

-f, --format

Especifica el formato de salida para el documento. Puedes obtener una lista de los formatos de salida posibles por tipo de documento utilizando la opción --show. 
El tipo de documento predeterminado es 'pdf'.

-F, --field

Añade o reemplaza campos de texto definidos por el usuario con un valor. 
por ejemplo, -F Client_Name="Oracle"

-i, --import

Establece opciones específicas de los filtros de importación (relacionadas con el filtro de importación de LibreOffice utilizado según el nombre del archivo de entrada). 
Ver la sección *FILTROS DE IMPORTACIÓN*.

-I, --input-filter-name

Especifica el nombre del filtro de entrada, utilizado cuando la extensión del archivo no coincide con el tipo de archivo. 
por ejemplo, -I odt

-l, --listener

Inicia unoconv como oyente para que los clientes de unoconv se conecten.

-M, --meta

Añade o reemplaza metadatos del documento con un valor. 
por ejemplo, -M Author="Dag Wieers"

-n, --no-launch

Por defecto, si no hay ningún oyente en ejecución, unoconv iniciará su propio oyente (temporal) para asegurarse de que la conversión funcione. Esta opción abortará la conversión si no se encuentra ningún oyente, en lugar de iniciar nuestro propio oyente.

-o, --output

Si el argumento es un directorio, coloca los documentos convertidos en este directorio. Si se proporcionan varios archivos de entrada, úsalo como nombre base (y añade la extensión de salida). De lo contrario, úsalo como el nombre de archivo de salida.

--password

Proporciona una contraseña para descifrar el documento.

--pipe

Utiliza una tubería como mecanismo de conexión alternativo para comunicarse con LibreOffice.

-p, --port

Puerto en el que escuchar (como oyente) o al que conectarse (como cliente). 
El puerto predeterminado es '2002'.

--preserve

Mantiene la marca de tiempo y los permisos del documento original.

-s, --server

Servidor (dirección) en el que escuchar (como oyente) o al que conectarse (como cliente). 
El servidor predeterminado es 'localhost'.

--show

Lista los formatos de salida posibles para usar con -f.

--stdin

Lee el archivo de entrada desde stdin (los nombres de archivo se ignoran si se proporcionan).

--stdout

Imprime el archivo de salida convertido en stdout.

-t, --template

Especifica la plantilla a usar para importar estilos. Esto puede ser muy útil si tienes una identidad corporativa que debes aplicar a cada documento que distribuyes.

-T, --timeout

Cuando unoconv inicia su propio oyente, intenta conectarse a él durante un número de segundos antes de rendirse. Aumentar esto puede ayudar cuando recibes errores aleatorios causados porque el oyente no está listo para aceptar trabajos de conversión.

-v, --verbose

Sé más y más y más detallado.

ARGUMENTOS

Puedes proporcionar uno o más archivos como argumentos para convertir cada uno de ellos al formato de salida especificado.

FILTROS DE IMPORTACIÓN

Dependiendo del archivo de entrada utilizado, unoconv utiliza automáticamente un filtro de importación de LibreOffice diferente. Este filtro de importación puede ser influenciado por la opción -i que, dependiendo del filtro utilizado, acepta diferentes argumentos.

No siempre está claro qué opciones de filtro de importación puedes proporcionar; el diálogo de importación en LibreOffice para el filtro que estás usando puede dar una buena indicación de lo que puedes esperar como opciones de filtro de importación.

La referencia es la documentación de LibreOffice, para hojas de cálculo se describe en: http://wiki.services.openoffice.org/wiki/Documentation/DevGuide/Spreadsheets/Filter_Options pero veremos algunos ejemplos.

OPCIONES DE FILTRO DE IMPORTACIÓN PREDETERMINADAS

El filtro de importación predeterminado para muchas importaciones (por ejemplo, Lotus, dBase o DIF) acepta como único argumento el tipo de codificación de entrada, por lo que si necesitas utf-8 (76) puedes hacer:

-i FilterOptions=76

Para obtener una lista de tipos de codificación posibles, puedes usar el enlace anterior para encontrar las opciones posibles.

•FilterOptions

OPCIONES DE FILTRO DE IMPORTACIÓN DE TEXTO

El filtro de importación de texto acepta una configuración de FilterOptions que contiene la codificación de entrada.

•FilterOptions

OPCIONES DE FILTRO DE IMPORTACIÓN CSV

El filtro de importación CSV acepta una configuración de FilterOptions, el orden es: separador(es),delimitador-de-texto,codificación,primera-fila,formato-de-columna

Por ejemplo, podrías querer usar esto para un documento real separado por comas:

-i FilterOptions=44,34,76,2,1/5/2/1/3/1/4/1

que utilizará una coma (44) como separador de campo, unas comillas dobles (34) como delimitador de texto, UTF-8 (76) para la codificación de entrada, comenzará desde la segunda fila y utilizará los formatos especificados para cada columna (1 significa estándar, 5 significa fecha AÑO/MES/DÍA)

Si deseas usar más de un separador (como un espacio o una tabulación) y usar la codificación del sistema (9), pero sin delimitador de texto, puedes hacer:

-i FilterOptions=9/32,,9,2

Para obtener una lista de tipos de codificación posibles, puedes usar el enlace anterior para encontrar las opciones posibles.

•FilterOptions

FILTROS DE EXPORTACIÓN

En contraste con los filtros de importación, los filtros de exportación pueden tener múltiples opciones con nombre, aunque no siempre está claro qué opciones están disponibles. Todo depende de la versión de LibreOffice. El diálogo de exportación que obtienes en LibreOffice puede darte una pista sobre lo que es posible, cada uno de esos widgets representa una opción.

OPCIONES DE FILTRO DE EXPORTACIÓN DE TEXTO

El filtro de exportación de texto acepta una opción de FilterOptions

NAME

unoconv - convert between alien formats using LibreOffice

SYNOPSIS

unoconv [-f format] [-o output] [--] [input...]
unoconv [-f format] [-o output] [-l | --listener] [-s server] [-p port] [-a address]
unoconv [--list]

DESCRIPTION

unoconv is a command-line tool to convert between different document formats using LibreOffice. It can be used as a standalone program or as a daemon (listener) for multiple conversions.

When unoconv is used as a standalone program, it will start its own LibreOffice instance to perform the conversion. This can be useful for one-off conversions or for systems where you don't want a persistent LibreOffice instance running.

When unoconv is used as a listener, it will start a LibreOffice instance that listens for conversion requests on a specific port. This is useful for handling multiple concurrent conversions or for integrating with other applications that need to perform document conversions.

OPTIONS

-f format
Specifies the output format for the conversion. If not specified, unoconv will try to guess the format from the output file extension.
-o output
Specifies the output file name. If not specified, the output file will be created in the same directory as the input file with the appropriate extension.
-l, --listener
Starts unoconv in listener mode, allowing it to accept conversion requests from other unoconv instances.
-s server
Specifies the server address for the listener. Defaults to localhost.
-p port
Specifies the port number for the listener. Defaults to 2002.
-a address
Specifies the address for the listener to bind to. Defaults to 0.0.0.0.
--list
Lists all available input and output formats.
--
Indicates the end of options. Any arguments following this will be treated as input files.

FILTER OPTIONS

unoconv supports various filters for specific file formats. These filters can be specified using the -e option. The available filters and their options depend on the output format.

CSV EXPORT FILTER OPTIONS

The CSV export filter accepts the following arguments in order: encoding,field-separator,text-delimiter,quote-all-text-cells,save-cell-content-as-shown

For example, to export to a comma-separated file with UTF-8 encoding and double quotes as text delimiters:

-e FilterOptions=44,34,76

This command specifies: field-separator (comma, ASCII 44), text-delimiter (double quote, ASCII 34), and encoding (UTF-8, ASCII 76).

To use a space or tab as a field separator, no text delimiter, and the system's default encoding:

-e FilterOptions=9/32,,9

The number 9 represents the system's default encoding. For a list of available encodings, refer to the LibreOffice documentation.

•FilterOptions

PDF EXPORT FILTER OPTIONS

The PDF export filter offers a wide range of options. For a comprehensive list and detailed explanations, please refer to the LibreOffice wiki: http://wiki.services.openoffice.org/wiki/API/Tutorials/PDF_export

An example of a PDF export option:

-e PageRange=1-2

This exports only pages 1 through 2.

EXAMPLES

Convert an ODT document to PDF:

unoconv -f pdf some-document.odt

Start a listener on the default port (2002):

unoconv --listener &

Then convert documents using the listener:

unoconv -f pdf some-document.odt
unoconv -f doc other-document.odt
unoconv -f jpg some-image.png
unoconv -f xsl some-spreadsheet.csv

Stop the listener (assuming it's the last background job):

kill -15 %-

Start a listener on a specific server and port:

unoconv --listener --server 1.2.3.4 --port 4567

Connect to a remote listener and convert a document:

unoconv --server 1.2.3.4 --port 4567 -f pdf some-document.odt

ENVIRONMENT VARIABLES

UNO_PATH
Specifies the path to the LibreOffice UNO bindings. For example: /opt/libreoffice3.4/basis-link/program

EXIT STATUS

A return status of 0 indicates successful conversion. Non-zero return codes usually indicate errors from LibreOffice or its UNO interface. For detailed error code interpretation, consult the LibreOffice source code:

http://cgit.freedesktop.org/libreoffice/core/tree/tools/inc/tools/errcode.hxx
http://cgit.freedesktop.org/libreoffice/core/tree/svtools/inc/svtools/sfxecode.hxx
http://cgit.freedesktop.org/libreoffice/core/tree/svtools/inc/svtools/soerr.hxx

For example, error code 2074 translates to: Class: 1 (ERRCODE_CLASS_ABORT), Code: 26 (ERRCODE_IO_INVALIDPARAMETER or SVSTREAM_INVALID_PARAMETER).

Error code 3088 translates to: Class: 3 (ERRCODE_CLASS_NOTEXISTS), Code: 16 (ERRCODE_IO_CANTWRITE).

BUGS

unoconv utilizes LibreOffice's UNO bindings. If a usable socket connection is unavailable, it starts its own LibreOffice instance with the appropriate parameters.
