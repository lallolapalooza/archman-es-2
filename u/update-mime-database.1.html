NOMBRE

update-mime-database - un programa para construir la caché de la base de datos Shared MIME-Info

SINOPSIS

update-mime-database -h | -v | [ -V | -n ] MIME-DIR

DESCRIPCIÓN

update-mime-database es un programa responsable de actualizar la caché de la base de datos shared mime-info de acuerdo con el sistema descrito en la especificación de la base de datos Shared MIME-Info del X Desktop Group.

OPCIONES

-h
Imprime un resumen de comandos.
-v
Imprime la información de la versión.
-V
Sea verboso.
-n
Solo actualiza si MIME-DIR/packages/ o un archivo en ese directorio es más nuevo que MIME-DIR/version. Esto es útil para scripts de pre- y post-instalación de paquetes.

ARGUMENTOS

MIME-DIR
Este es el directorio para el cual update-mime-database debe reconstruir la caché. Obligatorio si no se proporciona ninguna de las opciones.
