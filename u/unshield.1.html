NOMBRE

unshield - extraer archivos CAB de un archivo instalador de InstallShield

SINOPSIS

unshield [-c COMPONENTE] [-d DIRECTORIO] [-D NIVEL] [-g GRUPO] [-h] [-i VERSION] [-e CODIFICACION] [-j] [-L] [-O] [-r] [-R] [-V] c|g|l|t|x ARCHIVO_CAB [NOMBRE_ARCHIVO...]

DESCRIPCIÓN

Unshield extrae archivos CAB de instaladores de InstallShield, utilizados para instalar software en máquinas basadas en Microsoft Windows.

OPCIONES

-c COMPONENTE
Listar/extraer solo este componente
-d DIRECTORIO
Extraer archivos a DIRECTORIO
-D NIVEL
Establecer nivel de registro de depuración 0 - Sin registro (predeterminado) 1 - Solo errores 2 - Errores y advertencias 3 - Errores, advertencias y mensajes de depuración
-g GRUPO
Listar/extraer solo este grupo de archivos
-h
Mostrar mensaje de ayuda
-i VERSION
Forzar número de versión de InstallShield (no autodetectar)
Use esta opción si tiene un archivo muy antiguo (generado con InstallShield <= 4) y/o la detección automática falla
-e CODIFICACION
Convertir la codificación de caracteres de los nombres de archivo a la página de códigos local desde CODIFICACION (establece implícitamente -R)
-j
Eliminar rutas (no crear directorios)
-L
Convertir los nombres de archivo y directorio a minúsculas
-O
Usar compresión antigua
-r
Guardar datos en bruto (no descomprimir)
-R
No realizar ninguna conversión en los nombres de archivo y directorio al extraer
-V, --version
Imprimir información de la versión

Comandos:

c
Listar componentes
g
Listar grupos de archivos
l
Listar archivos
t
Probar archivos
x
Extraer archivos

Otros:

ARCHIVO_CAB
El archivo del que listar o extraer contenido
NOMBRE_ARCHIVO
Opcionalmente, especificar nombres de archivos específicos para extraer (se admiten comodines)
