UGREP(1) Comandos de usuario UGREP(1)

NOMBRE

ugrep, ug -- buscador de patrones de archivos

SINOPSIS

ugrep [OPCIONES] [-i|-j] [-Q|PATRÓN] [-e PATRÓN] [-N PATRÓN] [-f ARCHIVO]
[-E|-F|-G|-P|-Z] [-U] [-m [MIN,][MAX]] [--bool [--files|--lines]]
[-r|-R|-1|...|-9|-10|-11|...] [-t TIPOS] [-g GLOBs] [--sort[=CLAVE]]
[-q|-l|-c|-o] [-v] [-n] [-k] [-b] [-A NUM] [-B NUM] [-C NUM] [-y]
[--color[=CUÁNDO]|--colour[=CUÁNDO]] [--pretty] [--pager[=COMANDO]]
[--hexdump|--csv|--json|--xml] [-I] [-z] [--zmax=NUM] [ARCHIVO ...]

DESCRIPCIÓN

La utilidad ugrep busca en cualquier archivo de entrada dado, seleccionando archivos y líneas que coincidan con uno o más patrones especificados como expresiones regulares o como cadenas fijas. Un patrón coincide con múltiples líneas de entrada cuando la expresión regular del patrón coincide con uno o más saltos de línea. Un patrón vacío coincide con todas las líneas. Cada línea de entrada que coincida con al menos uno de los patrones se escribe en la salida estándar.

El comando ug está destinado a la búsqueda interactiva, utilizando un archivo de configuración `.ugrep' ubicado en el directorio de trabajo o, si no se encuentra, en el directorio de inicio, ver CONFIGURACIÓN. ug es equivalente a ugrep --config --pretty --sort para cargar un archivo de configuración, mejorar la salida de la terminal y ordenar los archivos por nombre.

Los comandos ugrep+ y ug+ son los mismos que los comandos ugrep y ug, pero también utilizan filtros para buscar documentos pdf, documentos, libros electrónicos y metadatos de imágenes, cuando las herramientas de filtro correspondientes están instaladas.

Se produce una lista de archivos coincidentes con la opción -l (--files-with-matches). La opción -c (--count) cuenta el número de líneas coincidentes. Cuando se combina con la opción -o, cuenta el número total de coincidencias. Cuando se combina con la opción -m1, (--min-count=1), omite los archivos con cero coincidencias.

La sintaxis de patrón predeterminada es una forma extendida de la sintaxis ERE de POSIX, igual que la opción -E (--extended-regexp). Pruebe ug --help regex para obtener ayuda sobre la sintaxis de patrones y cómo usar conectivas lógicas para especificar consultas de búsqueda booleanas con la opción -% (--bool) para coincidir con líneas y -%% (--bool --files) para coincidir con archivos. Las opciones -F (--fixed-strings), -G (--basic-regexp) y -P (--perl-regexp) especifican otras sintaxis de patrones.

La opción -i (--ignore-case) ignora las mayúsculas y minúsculas en los patrones. La opción -j (--smart-case) habilita -i solo si los patrones de búsqueda se especifican en minúsculas.

La búsqueda difusa (aproximada) se especifica con la opción -Z (--fuzzy) con un argumento opcional para controlar las inserciones, eliminaciones y/o sustituciones de caracteres. Pruebe ug --help fuzzy para obtener ayuda sobre la búsqueda difusa.

Tenga en cuenta que el patrón `.' coincide con cualquier carácter que no sea de nueva línea. El patrón `\n' coincide con un carácter de nueva línea. Se pueden coincidir múltiples líneas con patrones que coinciden con uno o más caracteres de nueva línea.

El patrón vacío `""` coincide con todas las líneas. Otros patrones que coinciden vacíos no lo hacen. Por ejemplo, el patrón `a*` coincidirá con una o más `a`. La opción -Y fuerza coincidencias vacías para compatibilidad con otras herramientas grep.

La opción -f ARCHIVO coincide con patrones especificados en ARCHIVO.

Por defecto, se coinciden patrones Unicode. La opción -U (--ascii o --binary) deshabilita la coincidencia Unicode para la coincidencia de patrones ASCII y binarios. La coincidencia no Unicode es más eficiente.

ugrep acepta entrada de varios formatos de codificación y normaliza la salida a UTF-8. Cuando hay una marca de orden de bytes UTF en la entrada, la entrada se normaliza automáticamente. Se puede especificar un formato de codificación de entrada con la opción --encoding.

Si no se especifican argumentos de ARCHIVO y la entrada estándar se lee desde una terminal, se realizan búsquedas recursivas como si se especificara -r. Para forzar la lectura desde la entrada estándar, especifique `-' como argumento de ARCHIVO.

Los directorios especificados como argumentos de ARCHIVO se buscan sin profundizar en subdirectorios, a menos que se especifique -R, -r, o -2...-9 para buscar subdirectorios recursivamente (hasta la profundidad especificada).

La opción -I (--ignore-binary) ignora los archivos binarios. Un archivo binario es un archivo con contenido no textual. Un archivo con cero bytes o formato UTF inválido se considera binario.

Se ignoran los archivos y directorios ocultos en las búsquedas recursivas. La opción -. (--hidden) incluye archivos y directorios ocultos en las búsquedas recursivas.

Para coincidir con los nombres de los archivos a buscar y los nombres de los directorios a recursar, se pueden especificar una o más de las siguientes opciones. La opción -O especifica una o más extensiones de nombre de archivo a coincidir. La opción -t especifica uno o más tipos de archivo a buscar (-t list muestra una lista de tipos.) La opción -g especifica un patrón glob estilo gitignore para coincidir con nombres de archivo. La opción --ignore-files especifica un archivo con globs estilo gitignore para ignorar directorios y archivos. Pruebe ug --help globs para obtener ayuda sobre la coincidencia de nombres de archivo y directorio. Ver también la sección GLOBBING.

Se buscan archivos comprimidos y archivos con la opción -z (--decompress). Cuando se usa con la opción --zmax=NUM, busca el contenido de archivos comprimidos y archivos almacenados dentro de archivos hasta NUM niveles.

La salida a una terminal para visualización se mejora con --pretty, que está habilitado por defecto con el comando ug.

Se abre una interfaz de usuario de terminal (TUI) de consulta con -Q (--query) para especificar interactivamente patrones de búsqueda y ver resultados de búsqueda. Un argumento PATRÓN requiere -e PATRÓN para iniciar la TUI de consulta con el patrón especificado.

Se habilita un paginador de salida de terminal con --pager que acepta un COMANDO opcional para ver la salida.

Se produce una salida personalizada con la opción --format o --replace. Pruebe ug --help format para obtener ayuda sobre formateo personalizado de la salida. Ver también la sección FORMATO. Los formatos predefinidos incluyen CSV con la opción --csv, JSON con la opción --json y XML con la opción --xml. Se generan volcados hexadecimales con la opción -X (--hex) o con la opción --hexdump para personalizar los volcados hexadecimales.

Un `--' señala el final de las opciones; el resto de los parámetros son argumentos de ARCHIVO, permitiendo que los nombres de archivo comiencen con un carácter `-' .

Las opciones largas pueden comenzar con `--no-' para deshabilitar, cuando sea aplicable.

ug --help QUÉ muestra ayuda sobre las opciones relacionadas con QUÉ.

-A NUM, --after-context=NUM
Salida de NUM líneas de contexto posterior después de las líneas coincidentes. Coloca un --group-separator entre grupos contiguos de coincidencias. Si se especifica -o, salida la coincidencia con contexto para ajustar NUM columnas después de la coincidencia o acorta la coincidencia. Ver también las opciones -B, -C y -y.
-a, --text
Procesa un archivo binario como si fuera texto. Esto es equivalente a la opción --binary-files=text. Esta opción puede generar basura binaria en la terminal, lo que puede tener consecuencias problemáticas si el controlador de terminal interpreta parte de ella como comandos de terminal.
--all, -@

Por ejemplo, -@I busca todos los archivos no binarios y -@. busca todos los archivos, incluidos los ocultos. Si se especifica -o, muestra la coincidencia con contexto para que quepa en NUM columnas antes de la coincidencia o acorta la coincidencia. Ver también las opciones -A, -C y -y.
-b, --byte-offset
El desplazamiento en bytes de una coincidencia de patrón se muestra delante de la línea coincidente respectiva. Cuando se especifican -u o --ungroup, muestra el desplazamiento para cada patrón coincidente en la misma línea. Los desplazamientos de bytes son exactos para entrada ASCII, UTF-8 y binaria sin procesar. De lo contrario, se muestra el desplazamiento en la entrada normalizada UTF-8.
--binary-files=TIPO
Controla la búsqueda y el informe de coincidencias de patrones en archivos binarios. TIPO puede ser `binary', `without-match', `text', `hex' y `with-hex'. El valor predeterminado es `binary' para buscar en archivos binarios y para informar una coincidencia sin mostrarla. `without-match' ignora las coincidencias binarias. `text' trata todos los archivos binarios como texto, lo que puede generar basura binaria en la terminal, lo que puede tener consecuencias problemáticas si el controlador de terminal interpreta parte de ella como comandos. `hex' informa todas las coincidencias en hexadecimal. `with-hex' solo informa coincidencias binarias en hexadecimal, dejando las coincidencias de texto sin cambios. Los archivos que contienen bytes NUL (cero) son binarios y los archivos con codificación UTF no válida son binarios a menos que se especifiquen las opciones -U, --ascii o --binary. Las opciones cortas son -a, -I, -W, -X.
--bool, -%, -%%
Especifica patrones de consulta booleanos. Un patrón de consulta booleano se compone de operadores `AND', `OR', `NOT' y agrupamiento con `(' y `)'. El espaciado entre subpatrones es lo mismo que `AND', `|' es lo mismo que `OR' y un `-` es lo mismo que `NOT'. El operador `OR' se une más fuertemente que `AND'. Por ejemplo, --bool 'A|B C|D' coincide con líneas que tienen (`A' o `B') y (`C' o `D'), --bool 'A -B' coincide con líneas que tienen `A' y no `B'. Los operadores `AND', `OR', `NOT' requieren un espaciado adecuado. Por ejemplo, --bool 'A OR B AND C OR D' coincide con líneas que tienen (`A' o `B') y (`C' o `D'), --bool 'A AND NOT B' coincide con líneas que tienen `A' sin `B'. Los subpatrones entre comillas se coinciden literalmente como cadenas. Por ejemplo, --bool 'A "AND"|"OR"' coincide con líneas que tienen `A' y también `AND' u `OR'. Los paréntesis se utilizan para agrupar. Por ejemplo, --bool '(A B)|C' coincide con líneas que tienen `A' y `B', o líneas con `C'. Tenga en cuenta que todos los subpatrones en un patrón de consulta booleano son expresiones regulares, a menos que se especifique -F. Las opciones -E, -F, -G, -P y -Z se pueden combinar con --bool para coincidir con subpatrones como cadenas o expresiones regulares (-E es el valor predeterminado). Esta opción no se aplica a los patrones -f ARCHIVO. La opción corta doble -%% habilita las opciones --bool y --files. La opción --stats muestra los patrones de búsqueda booleanos aplicados. Ver también las opciones --and, --andnot, --not, --files y --lines.
--break
Añade un salto de línea entre los resultados de diferentes archivos. Esta opción está habilitada por --heading.
-C NUM, --context=NUM
Muestra NUM líneas de contexto precedente y posterior alrededor de cada línea coincidente. Coloca un --group-separator entre grupos contiguos de coincidencias. Si se especifica -o, muestra la coincidencia con contexto para que quepa en NUM columnas antes y después de la coincidencia o acorta la coincidencia. Ver también las opciones -A, -B y -y.
-c, --count
Solo se escribe un recuento de las líneas seleccionadas en la salida estándar. Cuando se especifican -o o -u, cuenta el número de patrones coincidentes. Cuando se especifica -v, cuenta el número de líneas no coincidentes. Cuando se especifica -m1, (con una coma o --min-count=1), cuenta solo los archivos coincidentes sin mostrar cero coincidencias.
--color[=CUÁNDO], --colour[=CUÁNDO]
Resalta el texto coincidente con los colores especificados con la opción --colors o la variable de entorno GREP_COLOR o GREP_COLORS. CUÁNDO puede ser `never', `always' o `auto', donde `auto' resalta las coincidencias solo cuando se muestra en una terminal. El valor predeterminado es `auto'.
--colors=COLORES, --colours=COLORES
Utiliza COLORES para resaltar texto. COLORES es una lista separada por dos puntos de uno o más parámetros `sl=' (línea seleccionada), `cx=' (línea de contexto), `mt=' (texto coincidente), `ms=' (coincidencia seleccionada), `mc=' (contexto de coincidencia), `fn=' (nombre de archivo), `ln=' (número de línea), `cn=' (número de columna), `bn=' (desplazamiento de bytes), `se=' (separador), `qp=' (prompt TUI), `qe=' (errores TUI), `qr=' (regex TUI), `qm=' (caracteres meta de regex TUI), `ql=' (listas y literales de regex TUI), `qb=' (llaves de regex TUI). Los valores de los parámetros son códigos de color SGR ANSI o `k' (negro), `r' (rojo), `g' (verde), `y' (amarillo), `b' (azul), `m' (magenta), `c' (cian), `w' (blanco), o dejar vacío para no usar color. Las mayúsculas especifican colores de fondo. Un color de primer plano y uno de fondo pueden combinarse con propiedades de fuente `n' (normal), `f' (tenue), `h' (resaltado), `i' (invertido), `u' (subrayado). El parámetro `hl' habilita hipervínculos de nombres de archivo. El parámetro `rv' invierte los parámetros `sl=' y `cx=' cuando se especifica la opción -v. Sobrescribe selectivamente GREP_COLORS. Se pueden especificar códigos de parámetros únicos heredados de grep, por ejemplo --colors='7;32' o --colors=ig para establecer ms (coincidencia seleccionada).
--config[=ARCHIVO], ---[ARCHIVO]
Utiliza el ARCHIVO de configuración. El ARCHIVO predeterminado es `.ugrep'. El directorio de trabajo se comprueba primero en busca de ARCHIVO, luego el directorio de inicio. Las opciones especificadas en el ARCHIVO de configuración se analizan primero, seguidas de las opciones restantes especificadas en la línea de comandos. El comando ug carga automáticamente un archivo de configuración `.ugrep' cuando está presente, a menos que se especifique --config=ARCHIVO o --no-config.
--no-config
No cargues automáticamente el archivo de configuración predeterminado .ugrep.
--no-confirm
No confirmes acciones en la TUI de consulta -Q. El valor predeterminado es confirmar.
--cpp
Muestra coincidencias de archivos en C++. Ver también las opciones --format y -u.
--csv
Muestra coincidencias de archivos en CSV. Cuando se especifican -H, -n, -k o -b, se muestran valores adicionales. Ver también las opciones --format y -u.
-D ACCIÓN, --devices=ACCIÓN
Si un archivo de entrada es un dispositivo, FIFO o socket, utiliza ACCIÓN para procesarlo. Por defecto, ACCIÓN es `skip', lo que significa que los dispositivos se omiten silenciosamente. Cuando ACCIÓN es `read', los dispositivos se leen como si fueran archivos ordinarios.
-d ACCIÓN, --directories=ACCIÓN
Si un archivo de entrada es un directorio, utiliza ACCIÓN para procesarlo. Por defecto, ACCIÓN es `skip', es decir, omite silenciosamente los directorios a menos que se especifiquen en la línea de comandos. Cuando ACCIÓN es `read', advierte cuando se leen directorios como entrada. Cuando ACCIÓN es `recurse', lee todos los archivos bajo cada directorio, recursivamente, siguiendo enlaces simbólicos solo si están en la línea de comandos. Esto es equivalente a la opción -r. Cuando ACCIÓN es `dereference-recurse', lee todos los archivos bajo cada directorio, recursivamente, siguiendo enlaces simbólicos. Esto es equivalente a la opción -R.
--delay=RETRASO
Establece el retraso de respuesta de tecla -Q predeterminado. El valor predeterminado es 3 para 300 ms.
--depth=[MIN,][MAX], -1, -2, -3, ... -9, -10, -11, ...
Restringe las búsquedas recursivas de MIN a MAX niveles de directorio de profundidad, donde -1 (--depth=1) busca en la ruta especificada sin recursar en subdirectorios. Las formas cortas -3, -5, -3-5 y -3,5 buscan de 3 a 5 niveles de profundidad. Habilita -r si -R o -r no se especifican.
--dotall
El punto `.' en expresiones regulares coincide con cualquier cosa, incluida la nueva línea. Tenga en cuenta que `.*' coincide con toda la entrada y no debe usarse.
-E, --extended-regexp
Interpreta los patrones como expresiones regulares extendidas (ERE). Este es el valor predeterminado.
-e PATRÓN, --regexp=PATRÓN
Especifica un PATRÓN para buscar en la entrada. Una línea de entrada se selecciona si coincide con alguno de los patrones especificados. Esta opción es útil cuando se utilizan múltiples opciones -e para especificar varios patrones, o cuando un patrón comienza con un guion (`-'), o para especificar un patrón después de la opción -f o después de los argumentos ARCHIVO.

A format string may contain the following escape sequences:

the line number.

the basename of the file name.

the full file name.
%k
the column number of the match.
%t
the file type.

the matched text.
%S
the total number of lines in the file.
%G
the total number of bytes in the file.
%B
the total number of bytes matched in the file.
%H
the total number of lines matched in the file.
%I
the total number of lines not matched in the file.
%K
the total number of bytes not matched in the file.
%l
the line text.
%c
the character number of the match within the line.
%m
the number of the match on the line, starting from 1.
%M
the total number of matches on the line.
%a
the match score (only with fuzzy search).
%z
the compressed file name.
%Z
the password for the compressed file.
%w
the word count.
%b
the byte count.
%e
the number of errors (only with fuzzy search).
%u
only output each file once.
%p
the percentage sign.

Formatted output is written without a terminating newline, unless %~ or \n' is explicitly specified in the format string.

The [TEXT] part of a field is optional and may be omitted. When present, the argument must be placed in [] brackets, for example %[,]F to output a comma, the pathname, and a separator.

%[SEP]$ and %u are switches and do not send anything to the output.

The separator used by the %F, %H, %I, %N, %K, %B, %S and %G fields may be changed by preceding the field by %[SEP]$. When [SEP] is not provided, this reverts the separator to the default separator or the separator specified with --separator.

Formatted output is written for each matching pattern, which means that a line may be output multiple times when patterns match more than once on the same line. If field %u is specified anywhere in a format string, matching lines are output only once, unless option -u, --ungroup is specified or when more than one line of input matched the search pattern.

Additional formatting options:

--format-begin=FORMAT
the FORMAT when beginning the search.
--format-open=FORMAT
the FORMAT when opening a file and a match was found.
--format-close=FORMAT
the FORMAT when closing a file and a match was found.
--format-end=FORMAT
the FORMAT when ending the search.

The context options -A, -B, -C, -y, and display options --break, --heading, --color, -T, and --null have no effect on formatted output.

EXAMPLES

Display lines containing the word patricia in myfile.txt:

$ ugrep -w patricia myfile.txt

Display lines containing the word patricia, ignoring case:

$ ugrep -wi patricia myfile.txt

Display lines approximately matching the word patricia, ignoring case and allowing up to 2 spelling errors using fuzzy search:

$ ugrep -Z2 -wi patricia myfile.txt

Count the number of lines containing patricia, ignoring case:

$ ugrep -cwi patricia myfile.txt

Count the number of words patricia, ignoring case:

$ ugrep -cowi patricia myfile.txt

List lines with amount and a decimal, ignoring case (space is AND):

$ ugrep -i -% 'amount \d+(\.\d+)?' myfile.txt

The same Boolean search query, but with options -e and --and:

$ ugrep -wi -e amount --and '\d+(\.\d+)?' myfile.txt

List all Unicode words in a file:

$ ugrep -o '\w+' myfile.txt

List the laughing face emojis (Unicode code points U+1F600 to U+1F60F):

$ ugrep -o '[\x{1F600}-\x{1F60F}]' myfile.txt

Check if a file contains any non-ASCII (i.e. Unicode) characters:

$ ugrep -q '[^[:ascii:]]' myfile.txt && echo "contains Unicode"

Display the line and column number of FIXME in C++ files using recursive search, with one line of context before and after a matched line:

$ ugrep -C1 -R -n -k -tc++ FIXME

Display the line and column number of FIXME in long Javascript files using recursive search, showing only matches with up to 10 characters of context before and after:

$ ugrep -o -C20 -R -n -k -tjs FIXME

Find blocks of text between lines matching BEGIN and END by using a lazy quantifier *? to match only what is necessary and pattern \n to match newlines:

$ ugrep -n 'BEGIN.*\n(.*\n)*?.*END' myfile.txt

Likewise, list the C/C++ comments in a file and line numbers:

$ ugrep -n -e '//.*' -e '/\*(.*\n)*?.*\*+\/' myfile.cpp

The same, but using predefined pattern c++/comments:

$ ugrep -n -f c++/comments myfile.cpp

List the lines that need fixing in a C/C++ source file by looking for the word FIXME while skipping any FIXME in quoted strings:

$ ugrep -e FIXME -N '"(\\.|\\\r?\n|[^\\\n"])*"' myfile.cpp

The same, but using predefined pattern cpp/zap_strings:

$ ugrep -e FIXME -f cpp/zap_strings myfile.cpp

Find lines with FIXME or TODO, showing line numbers:

$ ugrep -n -e FIXME -e TODO myfile.cpp

Find lines with FIXME that also contain urgent:

$ ugrep -n -e FIXME --and urgent myfile.cpp

The same, but with a Boolean query pattern (a space is AND):

$ ugrep -n -% 'FIXME urgent' myfile.cpp

Find lines with FIXME that do not also contain later:

$ ugrep -n -e FIXME --andnot later myfile.cpp

The same, but with a Boolean query pattern (a space is AND, - is NOT):

$ ugrep -n -% 'FIXME -later' myfile.cpp

Output a list of line numbers of lines with FIXME but not later:

$ ugrep -e FIXME --andnot later --format='%,%n' myfile.cpp

Recursively list all files with both FIXME and LICENSE anywhere in the file, not necessarily on the same line:

$ ugrep -l -%% 'FIXME LICENSE'

Find lines with FIXME in the C/C++ files stored in a tarball:

$ ugrep -z -tc++ -n FIXME project.tgz

Recursively find lines with FIXME in C/C++ files, but do not search any bak and old directories:

$ ugrep -n FIXME -tc++ -g^bak/,^old/

Recursively search for the word copyright in cpio, jar, pax, tar, zip, 7z archives, compressed and regular files, and in PDFs using a PDF filter:

$ ugrep -z -w --filter='pdf:pdftotext % -' copyright

Match the binary pattern A3hhhhA3 (hex) in a binary file without Unicode pattern matching -U (which would otherwise match \xaf as a Unicode character U+00A3 with UTF-8 byte sequence C2 A3) and display the results in hex with --hexdump with C1 to output one hex line before and after each match:

$ ugrep -U --hexdump=C1 '\xa3[\x00-\xff]{2}\xa3' a.out

Hexdump an entire file using a pager for viewing:

$ ugrep -X --pager '' a.out

List all files that are not ignored by one or more .gitignore:

$ ugrep -l '' --ignore-files

List all files containing a RPM signature, located in the rpm directory and recursively below up to two levels deeper (3 levels total):

$ ugrep -3 -l -tRpm '' rpm/

Monitor the system log for bug reports and ungroup multiple matches from matching lines into separate lines:

$ tail -f /var/log/system.log | ugrep -u -i -w bug

Interactive fuzzy search with Boolean search queries:

$ ugrep -Q -l -% -Z2 --sort=best

Display all words in a MacRoman-encoded file that has CR newlines:

$ ugrep --encoding=MACROMAN '\w+' mac.txt

Display options related to "fuzzy" searching:

$ ugrep --help fuzzy
