NOMBRE

unw_get_proc_info_by_ip -- obtener información del procedimiento por IP

SINOPSIS

#include <libunwind.h>

int unw_get_proc_info_by_ip(unw_addr_space_t as, unw_word_t ip, unw_proc_info_t *pip, void *arg);

DESCRIPCIÓN

La rutina unw_get_proc_info_by_ip() devuelve el mismo tipo de información auxiliar sobre un procedimiento que unw_get_proc_info(), excepto que la información se busca por puntero de instrucción (IP) en lugar de por un cursor. Esto es más flexible porque es posible buscar la información de un procedimiento arbitrario, incluso si no forma parte de la cadena de llamadas actual. Sin embargo, al ser más flexible, también tiende a ejecutarse más lentamente (y a menudo mucho más lentamente) que unw_get_proc_info().

La rutina espera los siguientes argumentos: as es el espacio de direcciones en el que se buscará el puntero de instrucción. Para una búsqueda en el espacio de direcciones local, se puede pasar unw_local_addr_space para este argumento. El argumento ip es el puntero de instrucción para el que se buscará la información del procedimiento y pip es un puntero a una estructura de tipo unw_proc_info_t que se utiliza para devolver la información. Por último, arg es el argumento del espacio de direcciones que se utilizará al acceder al espacio de direcciones. Tiene el mismo propósito que el argumento del mismo nombre para unw_init_remote(). Al acceder al espacio de direcciones local (el primer argumento es unw_local_addr_space), se debe pasar NULL para este argumento.

Tenga en cuenta que, a efectos de libunwind, se asume que el código de un procedimiento ocupa un único rango de direcciones contiguas. Por esta razón, siempre es posible describir la extensión de un procedimiento con los miembros start_ip y end_ip. Si una sola función/rutina se divide en varias partes no contiguas, libunwind tratará cada parte como un procedimiento separado.

VALOR DE RETORNO

Al finalizar con éxito, unw_get_proc_info_by_ip() devuelve 0. De lo contrario, se devuelve el valor negativo de uno de los códigos de error a continuación.

SEGURIDAD DE HILOS Y SEÑALES

unw_get_proc_info_by_ip() es seguro para hilos. Si se pasa el espacio de direcciones local en el argumento as, esta rutina también es segura para usar desde un manejador de señales.

ERRORES

UNW_EUNSPEC

Ocurrió un error no especificado.
UNW_ENOINFO

Libunwind no pudo localizar la información de desenredo para el procedimiento.
UNW_EBADVERSION

La información de desenredo para el procedimiento tiene una versión o formato que libunwind no entiende.

Además, unw_get_proc_info_by_ip() puede devolver cualquier error devuelto por la devolución de llamada access_mem() (ver unw_create_addr_space(3libunwind)).
