utmpx.h(0P) Manual del Programador POSIX utmpx.h(0P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

utmpx.h — definiciones de la base de datos de contabilidad de usuarios

SINAPSIS

#include <utmpx.h>

DESCRIPCIÓN

La cabecera <utmpx.h> definirá la estructura utmpx que incluirá al menos los siguientes miembros:

char            ut_user[]  Nombre de inicio de sesión del usuario.
char            ut_id[]    Identificador de proceso de inicialización no especificado.
char            ut_line[]  Nombre del dispositivo.
pid_t           ut_pid     ID de proceso.
short           ut_type    Tipo de entrada.
struct timeval  ut_tv      Hora en que se realizó la entrada.

La cabecera <utmpx.h> definirá el tipo pid_t a través de typedef, como se describe en <sys/types.h>.

La cabecera <utmpx.h> definirá la estructura timeval como se describe en <sys/time.h>.

La inclusión de la cabecera <utmpx.h> también puede hacer visibles todos los símbolos de <sys/time.h>.

La cabecera <utmpx.h> definirá las siguientes constantes simbólicas como posibles valores para el miembro ut_type de la estructura utmpx:

EMPTY
Sin información de contabilidad de usuario válida.
BOOT_TIME
Identifica la hora de arranque del sistema.
OLD_TIME
Identifica la hora en que cambió el reloj del sistema.
NEW_TIME
Identifica la hora después de que cambió el reloj del sistema.
USER_PROCESS
Identifica un proceso.
INIT_PROCESS
Identifica un proceso generado por el proceso init.
LOGIN_PROCESS
Identifica el líder de sesión de un usuario conectado.
DEAD_PROCESS
Identifica un líder de sesión que ha salido.

Se declararán como funciones y también podrán definirse como macros. Se proporcionarán prototipos de funciones.

void          endutxent(void);
struct utmpx *getutxent(void);
struct utmpx *getutxid(const struct utmpx *);
struct utmpx *getutxline(const struct utmpx *);
struct utmpx *pututxline(const struct utmpx *);
void          setutxent(void);
