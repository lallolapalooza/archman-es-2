UPSCLI_CONNECT(3) Manual NUT UPSCLI_CONNECT(3)

NOMBRE

upscli_connect, upscli_tryconnect - Abrir una conexión a un servidor de datos upsd de NUT

SINOPSIS

        #include <upsclient.h>
        /* Abrir una conexión a un servidor de datos upsd de NUT (bloqueante por defecto) */
        int upscli_connect(UPSCONN_t *ups, const char *host, uint16_t port, int flags);
        /* Abrir una conexión a un servidor de datos upsd de NUT con tiempo de espera especificado */
        int upscli_tryconnect(UPSCONN_t *ups, const char *host, uint16_t port, int flags,
                struct timeval * timeout);

DESCRIPCIÓN

La función upscli_connect() toma el puntero ups a una estructura de estado UPSCONN_t y abre una conexión TCP al host en el port dado.

Por defecto, esto realiza un intento de conexión bloqueante (hasta que la capa de transporte del sistema agote el tiempo de espera de la llamada subyacente a select(2)). Un tiempo de espera por defecto a nivel de programa para este método puede configurarse con los métodos upscli_set_default_connect_timeout(3) o upscli_init_default_connect_timeout(3). Para operaciones con un tiempo de espera explícito específico de la operación, utilice en su lugar el método upscli_tryconnect().


Nota

Como parte de la inicialización general, tanto la función upscli_init(3) como la primera llamada a la función upscli_connect(), pueden llamar al método upscli_init_default_connect_timeout(3) (si nunca se usó antes): esto permite que los clientes NUT no modificados (legados) se beneficien consistentemente de la presencia de la variable de entorno NUT_DEFAULT_CONNECT_TIMEOUT para que los intentos de upscli_connect() no sean bloqueantes (como por defecto).

flags puede ser UPSCLI_CONN_TRYSSL para intentar una conexión SSL, o UPSCLI_CONN_REQSSL para requerir una conexión SSL.

Introducido en la versión 2.7, existe un indicador adicional UPSCLI_CONN_CERTVERIF para verificar la firma ofrecida durante el apretón de manos SSL. Este indicador debe usarse junto con las llamadas a upscli_init(3) y/o upscli_add_host_cert(3) antes de conectar para definir un certificado CA con el que verificar.

Si se requiere el modo SSL, esta función solo devolverá éxito si puede establecer una conexión SSL con el servidor. Las razones posibles de fallo incluyen la falta de soporte SSL en el servidor y si el propio upsclient no se ha compilado con soporte SSL.

Debe llamar a upscli_disconnect(3) cuando haya terminado con una conexión, o su programa filtrará lentamente memoria y descriptores de archivos.

VALOR DE RETORNO

La función upscli_connect() modifica la estructura UPSCONN_t y devuelve *0* en caso de éxito, o *-1* si ocurre un error.
