UPRECORDS(1) Manual de comandos generales UPRECORDS(1)

NOMBRE

uprecords - proporciona estadísticas de tiempo de actividad

SINOPSIS

uprecords [ -habBcfkKMsv ] [ -i <intervalo> ] [ -m <conteo> ]

DESCRIPCIÓN

Esta página del manual documenta el programa uprecords.

uprecords es un programa que proporciona estadísticas de récords del programa uptimed(8).

OPCIONES

-h
Mostrar uso
-a
No imprimir códigos ANSI
-b -B
Ordenar por tiempo de arranque, entrada más antigua primero. -B invierte. La opción implica -s. No imprimir códigos ANSI
-c
No mostrar entrada actual si no está entre las principales
-f
Ejecutar continuamente en un bucle
-k -K
Ordenar por nombre de kernel/sistema. -K invierte. La opción implica -s.
-M
Mostrar próximo hito
-s
No imprimir estadísticas adicionales
-i <intervalo>
Usar <intervalo> segundos para el bucle en lugar de 5, implica -f
-m <conteo>
Mostrar un máximo de COUNT entradas principales en lugar de 10
-v
Mostrar información de la versión

VER TAMBIÉN

uptimed(8)
