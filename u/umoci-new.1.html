NOMBRE

umoci new - Crear una etiqueta en blanco en una imagen OCI

SINOPSIS

umoci new --image=imagen[:etiqueta]

DESCRIPCIÓN

Crea una etiqueta en blanco en una imagen OCI. La configuración y el manifiesto de la imagen creada se establecen en valores predeterminados definidos por umoci, sin añadir ningún blob de capa de sistema de archivos a la imagen.

Una vez que se crea una nueva imagen con umoci-new(1), puede usar directamente la imagen con umoci-unpack(1), umoci-repack(1) y umoci-config(1) para modificar la nueva imagen etiquetada como considere oportuno. Esto le permite crear imágenes completamente nuevas desde cero, sin necesidad de una imagen base para empezar.

OPCIONES

Las opciones globales se definen en umoci(1).

--image=imagen[:etiqueta]
El destino de la etiqueta en blanco en la imagen OCI. imagen debe ser una ruta a
una imagen OCI válida, y etiqueta debe ser un nombre de etiqueta válido. Si ya existe una etiqueta con el nombre etiqueta, se sobrescribirá. Si no se proporciona etiqueta, se
establecerá por defecto en "latest".

EJEMPLO

Lo siguiente crea un diseño de imagen OCI completamente nuevo y luego crea una etiqueta en blanco para su posterior manipulación con umoci-repack(1) y umoci-config(1).

% umoci init --layout image
% umoci new --image image:tag

VER TAMBIÉN

umoci(1), umoci-unpack(1), umoci-repack(1), umoci-config(1)

umoci new
