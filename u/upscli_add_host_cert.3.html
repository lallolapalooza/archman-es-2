UPSCLI_ADD_HOST_CERT(3) Manual de NUT UPSCLI_ADD_HOST_CERT(3)

NOMBRE

upscli_add_host_cert - Registrar una regla de seguridad para un host.

SINOPSIS

        #include <upsclient.h>
        void upscli_add_host_cert(
                const char* hostname,
                const char* certname,
                int certverify,
                int forcessl);

DESCRIPCIÓN

La función upscli_add_host_cert() registra una regla de seguridad asociada al hostname. Todas las conexiones a este host utilizan esta regla.

La regla se compone del nombre del certificado certname esperado para el host, certverify si el certificado debe ser validado para el host y forcessl si se debe usar una conexión segura para conectarse al host.

Nota: Esta llamada solo funciona si upsclient se ha compilado con soporte NSS. Si en su lugar se compiló con soporte OpenSSL, esta función contiene una definición vacía y no realizará ninguna acción cuando se llame.

VALOR DE RETORNO

upscli_add_host_cert() no devuelve ningún valor.

VER TAMBIÉN

upscli_init(3), upscli_connect(3), upscli_ssl(3), upscli_strerror(3), upscli_upserror(3)
