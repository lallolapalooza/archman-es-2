NOMBRE

umoci stat - Muestra información de estado sobre una etiqueta de imagen

SINOPSIS

umoci stat --image=imagen[:etiqueta] [--json]

DESCRIPCIÓN

Genera diversas piezas de información de estado sobre una etiqueta de imagen, incluyendo el historial de la imagen.

ADVERTENCIA: No dependas de la salida de esta herramienta. Anteriormente recomendábamos el uso de --json como la interfaz "estable", pero esta interfaz será rediseñada en el futuro.

OPCIONES

Las opciones globales se definen en umoci(1).

--image=imagen[:etiqueta]
La etiqueta de imagen OCI sobre la que se mostrará la información. imagen debe ser una ruta a una
imagen OCI válida y etiqueta debe ser una etiqueta válida en la imagen. Si
no se proporciona etiqueta, se usará por defecto "latest".

--json
Muestra la información de estado como un bloque codificado en JSON.

FORMATO

El formato del bloque --json es el siguiente. Muchos de estos campos provienen de la especificación de imagen OCI ⟨https://github.com/opencontainers/image-spec⟩.

{
  # Este es el conjunto de entradas de historial para la imagen.
  "history": [
    {
      "layer":       <descriptor>, # null si empty_layer es true
      "diff_id":     <diffid>,
      "created":     <created>,
      "created_by":  <created_by>,
      "author":      <author>,
      "empty_layer": <empty_layer>
    }...
  ]
}

En futuras versiones de umoci(1), se podrán añadir campos adicionales a la estructura anterior. Sin embargo, los campos definidos actualmente siempre estarán establecidos (hasta que se realice una versión incompatible hacia atrás).

EJEMPLO

Lo siguiente obtiene información sobre una imagen descargada de un registro de docker(1) usando skopeo(1).

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
% umoci stat --image image
