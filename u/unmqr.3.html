CUNMQR

Purpose:

!>
!> CUNMQR sobrescribe la matriz compleja general M por N de C con
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> donde Q es una matriz unitaria compleja definida como el producto de k
!> reflectores elementales
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> tal como devuelve CGEQRF. Q es de orden M si SIDE = 'L' y de orden N
!> si SIDE = 'R'.
!>

Parameters

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': aplica Q o Q**H desde la Izquierda;
!>          = 'R': aplica Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS is CHARACTER*1
!>          = 'N':  Sin transponer, aplica Q;
!>          = 'C':  Transpuesta conjugada, aplica Q**H.
!>

M

!>          M is INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N is INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K is INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A is COMPLEX array, dimension (LDA,K)
!>          La i-ésima columna debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como se devuelve
!>          por CGEQRF en las primeras k columnas de su argumento de array A.
!>

LDA

!>          LDA is INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU is COMPLEX array, dimension (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como se devuelve por CGEQRF.
!>

C

!>          C is COMPLEX array, dimension (LDC,N)
!>          En la entrada, la matriz M por N de C.
!>          En la salida, C se sobrescribe con Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC is INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK is COMPLEX array, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK is INTEGER
!>          La dimensión del array WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N);
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
