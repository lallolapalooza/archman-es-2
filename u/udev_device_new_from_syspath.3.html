udev_device_new_from_syspath(3)

Paquete: systemd-libs

Licencias: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

UDEV_DEVICE_NEW_FROM_SYSPATH(3) udev_device_new_from_syspath UDEV_DEVICE_NEW_FROM_SYSPATH(3)

NOMBRE

udev_device_new_from_syspath, udev_device_new_from_devnum, udev_device_new_from_subsystem_sysname, udev_device_new_from_device_id, udev_device_new_from_environment, udev_device_ref, udev_device_unref - Crear, adquirir y liberar un objeto de dispositivo udev

SINOPSIS

#include <libudev.h>

struct udev_device *udev_device_new_from_syspath(struct udev *udev, const char *syspath);

struct udev_device *udev_device_new_from_devnum(struct udev *udev, char type, dev_t devnum);

struct udev_device *udev_device_new_from_subsystem_sysname(struct udev *udev, const char *subsystem, const char *sysname);

struct udev_device *udev_device_new_from_device_id(struct udev *udev, const char *id);

struct udev_device *udev_device_new_from_environment(struct udev *udev);

struct udev_device *udev_device_ref(struct udev_device *udev_device);

struct udev_device *udev_device_unref(struct udev_device *udev_device);

DESCRIPCIÓN

udev_device_new_from_syspath(), udev_device_new_from_devnum(), udev_device_new_from_subsystem_sysname(), udev_device_new_from_device_id(), y udev_device_new_from_environment() asignan un nuevo objeto de dispositivo udev y devuelven un puntero a él. Este objeto es opaco y el llamante no debe acceder a él por medios distintos a las funciones proporcionadas por libudev. Inicialmente, el contador de referencias del dispositivo es 1. Puede adquirir referencias adicionales y liberar las referencias obtenidas mediante udev_device_ref() y udev_device_unref(). Una vez que el contador de referencias llega a 0, el objeto del dispositivo se destruye y se libera.

udev_device_new_from_syspath(), udev_device_new_from_devnum(), udev_device_new_from_subsystem_sysname(), y udev_device_new_from_device_id() crean el objeto del dispositivo basándose en la información encontrada en /sys/, anotada con propiedades de la base de datos de dispositivos interna de udev. Un syspath es cualquier subdirectorio de /sys/, con la restricción de que un subdirectorio de /sys/devices (o un enlace simbólico a uno) representa un dispositivo real y, como tal, debe contener un archivo uevent. udev_device_new_from_devnum() toma un tipo de dispositivo, que puede ser b para dispositivos de bloque o c para dispositivos de caracteres, así como un devnum (ver makedev(3)). udev_device_new_from_subsystem_sysname() busca dispositivos basándose en el subsistema y sysname proporcionados (ver udev_device_get_subsystem(3) y udev_device_get_sysname(3)) y udev_device_new_from_device_id() busca dispositivos basándose en el ID del dispositivo proporcionado, que es una cadena especial en una de las siguientes cuatro formas:

Tabla 1. Cadenas de ID de dispositivo

Ejemplo Explicación
b8:2 dispositivo de bloque mayor:menor
c128:1 dispositivo de caracteres mayor:menor
n3 índice de interfaz del dispositivo de red
+sound:card29 subsistema del núcleo de controladores:nombre del dispositivo

udev_device_new_from_environment()
crea un dispositivo a partir del entorno actual (ver environ(7)). Cada par clave-valor se interpreta de la misma manera que si se hubiera recibido en un uevent (ver udev_monitor_receive_device(3)). Las claves DEVPATH, SUBSYSTEM, ACTION y SEQNUM son obligatorias.

VALOR DE RETORNO

En caso de éxito, udev_device_new_from_syspath(), udev_device_new_from_devnum(), udev_device_new_from_subsystem_sysname(), udev_device_new_from_device_id() y udev_device_new_from_environment() devuelven un puntero al dispositivo udev asignado. En caso de error, se devuelve NULL y se establece errno apropiadamente. udev_device_ref() devuelve el argumento que se le pasó, sin modificar. udev_device_unref() siempre devuelve NULL.

HISTORIA

udev_device_new_from_syspath(), udev_device_new_from_devnum(), udev_device_new_from_subsystem_sysname(), udev_device_new_from_device_id(), udev_device_new_from_environment(), udev_device_ref(), y udev_device_unref() se añadieron en la versión 221.
