NOMBRE

usrp_n2xx_simple_net_burner - Grabador de Firmware/FPGA para USRP Serie N

DESCRIPCIÓN

Graba imágenes de firmware y FPGA en dispositivos USRP Serie N conectados. El programa toma una dirección IP como argumento, consulta el dispositivo USRP para identificar su modelo y revisión, y graba las imágenes apropiadas a través de Ethernet.

SINOPSIS

usrp_n2xx_simple_net_burner [OPCIONES]

OPCIONES

Este programa funciona mejor cuando solo se especifica una dirección IP.

Dirección IP del dispositivo:
--addr="Dirección" (predeterminado: 192.168.10.2)
Esta información de ayuda:
--help
Ruta del archivo de firmware personalizado:
--fw="ruta_archivo"
Ruta del archivo de FPGA personalizado:
--fpga="ruta_archivo"
No grabar firmware:
--no-fw
No grabar FPGA:
--no-fpga
Reiniciar automáticamente el dispositivo USRP después de grabar
--auto_reboot
Listar todos los dispositivos USRP sin grabar
--list

EJEMPLOS

Seleccionar un dispositivo USRP con una dirección IP no estándar

usrp_n2xx_simple_net_burner --addr=192.168.10.3
