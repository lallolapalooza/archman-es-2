UNALIAS(1P) Manual del programador POSIX UNALIAS(1P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

unalias — eliminar definiciones de alias

SINOPSIS

unalias nombre-alias...
unalias -a

DESCRIPCIÓN

La utilidad unalias eliminará la definición de cada nombre de alias especificado. Consulte la Sección 2.3.1, Sustitución de alias. Los alias se eliminarán del entorno de ejecución del shell actual; consulte la Sección 2.12, Entorno de ejecución del shell.

OPCIONES

La utilidad unalias cumplirá con el volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2, Directrices de sintaxis de utilidades.

Se admitirá la siguiente opción:

-a
Elimina todas las definiciones de alias del entorno de ejecución del shell actual.

OPERANDOS

Se admitirá el siguiente operando:

nombre-alias
El nombre de un alias a eliminar.

ENTRADA ESTÁNDAR

No se utiliza.

ARCHIVOS DE ENTRADA

Ninguno.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán a la ejecución de unalias:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en un valor de cadena no vacío, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a multibyte en los argumentos).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar al formato y contenido de los mensajes de diagnóstico escritos en la salida estándar de errores.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASINCRONOS

Predeterminado.

SALIDA ESTÁNDAR

No se utiliza.

SALIDA ESTÁNDAR DE ERRORES

La salida estándar de errores se utilizará únicamente para mensajes de diagnóstico.

ARCHIVOS DE SALIDA

Ninguno.

DESCRIPCIÓN EXTENDIDA

Ninguna.

CÓDIGO DE SALIDA

Se devolverán los siguientes valores de salida:

 0
Finalización correcta.
>0
Uno de los operandos nombre-alias especificados no representaba una definición de alias válida, o se produjo un error.

CONSECUENCIAS DE ERRORES

Predeterminado.

Las siguientes secciones son informativas.

USO DE APLICACIONES

Dado que unalias afecta al entorno de ejecución del shell actual, generalmente se proporciona como una función integrada regular del shell.

EJEMPLOS

Ninguno.

RACIONALE

La descripción de unalias se basa en la de las implementaciones históricas de KornShell. Existen diferencias conocidas entre esta y la shell C. La versión de KornShell se adoptó para ser coherente con todas las demás características de KornShell en este volumen de POSIX.1‐2017, como la edición de la línea de comandos.

La opción -a es el equivalente a la forma unalias * de la shell C y se proporciona para abordar preocupaciones de seguridad sobre alias desconocidos que ingresan al entorno de un usuario (o aplicación) a través de la ruta de alias predefinido permitida, definida por la implementación, o como resultado de un archivo ENV. (Aunque unalias podría usarse para simplificar el script de shell "seguro" que se muestra en el raciocino de command, no elimina la necesidad de citar todos los nombres de comando. Una llamada inicial a unalias -a tendría que citarse en caso de que hubiera un alias para unalias).

unalias(1p)

Manual page for unalias(1p)

Name:
unalias - remove alias definitions
Synopsis:

unalias [alias-name ...]

Description:

The unalias utility shall remove alias definitions. If no alias-name operands are specified, unalias shall write an error message to standard error and exit with a non-zero status. Otherwise, for each alias-name specified, the alias definition shall be removed.

Options:

None.

Operands:

The following operand shall be supported:

alias-name

The name of an alias definition to be removed.

STDIN:

Not used.

Input Files:

None.

Environment Variables:

None.

Asynchronous Events:

Asynchronous events are not supported.

STDOUT:

None.

STDERR:

The standard error shall be used to report errors.

Output Files:

None.

Extended Description:

None.

Exit Status:

The exit status shall be greater than zero if no alias-name operands are specified; otherwise, the exit status shall be zero unless an error is encountered.

Consequences of Errors:

No special consequences for errors.

Application Usage:

None.

Examples:

To remove the alias named `ls`, the following command would be used:

unalias ls

To remove aliases named `ll` and `la`, the following command would be used:

unalias ll la
Rationale:

The behavior of unalias is largely determined by the POSIX shell specification. Aliases are a shell feature that allows users to define shortcuts for longer commands. The unalias utility provides a way to remove these shortcuts.

Future Directions:

None.
