subrutina cungbr (character vect, integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CUNGBR

Propósito:

!>
!> CUNGBR genera una de las matrices unitarias complejas Q o P**H
!> determinadas por CGEBRD al reducir una matriz compleja A a forma bidiagonal:
!> A = Q * B * P**H. Q y P**H se definen como productos de
!> reflectores elementales H(i) o G(i) respectivamente.
!>
!> Si VECT = 'Q', se asume que A ha sido una matriz de M-por-K, y Q
!> es de orden M:
!> si m >= k, Q = H(1) H(2) . . . H(k) y CUNGBR devuelve las primeras n
!> columnas de Q, donde m >= n >= k;
!> si m < k, Q = H(1) H(2) . . . H(m-1) y CUNGBR devuelve Q como una
!> matriz de M-por-M.
!>
!> Si VECT = 'P', se asume que A ha sido una matriz de K-por-N, y P**H
!> es de orden N:
!> si k < n, P**H = G(k) . . . G(2) G(1) y CUNGBR devuelve las primeras m
!> filas de P**H, donde n >= m >= k;
!> si k >= n, P**H = G(n-1) . . . G(2) G(1) y CUNGBR devuelve P**H como
!> una matriz de N-por-N.
!>

Parámetros

VECT 
!>          VECT es CHARACTER*1
!>          Especifica si se requiere la matriz Q o la matriz P**H,
!>          tal como se define en la transformación aplicada por CGEBRD:
!>          = 'Q':  generar Q;
!>          = 'P':  generar P**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz Q o P**H a devolver.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Q o P**H a devolver.
!>          N >= 0.
!>          Si VECT = 'Q', M >= N >= min(M,K);
!>          si VECT = 'P', N >= M >= min(N,K).
!>

K

!>          K es INTEGER
!>          Si VECT = 'Q', el número de columnas en la matriz original
!>          M-por-K reducida por CGEBRD.
!>          Si VECT = 'P', el número de filas en la matriz original
!>          K-por-N reducida por CGEBRD.
!>          K >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA,N)
!>          En la entrada, los vectores que definen los reflectores
!>          elementales, como los devuelve CGEBRD.
!>          En la salida, la matriz Q o P**H de M-por-N.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= M.
!>

TAU

!>          TAU es array COMPLEX, dimensión
!>                                (min(M,K)) si VECT = 'Q'
!>                                (min(N,K)) si VECT = 'P'
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i) o G(i), que determina Q o P**H, como
!>          devuelve CGEBRD en su argumento de array TAUQ o TAUP.
!>

WORK

!>          WORK es array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,min(M,N)).
!>          Para un rendimiento óptimo LWORK >= min(M,N)*NB, donde NB
!>          es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Autor

subroutine dorgbr (character vect, integer m, integer n, integer k, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) tau, double precision, dimension( * ) work, integer lwork, integer info)

DORGBR

Purpose:

!>
!> DORGBR generates one of the real orthogonal matrices Q or P**T
!> determined by DGEBRD when reducing a real matrix A to bidiagonal
!> form: A = Q * B * P**T.  Q and P**T are defined as products of
!> elementary reflectors H(i) or G(i) respectively.
!>
!> If VECT = 'Q', A is assumed to have been an M-by-K matrix, and Q
!> is of order M:
!> if m >= k, Q = H(1) H(2) . . . H(k) and DORGBR returns the first n
!> columns of Q, where m >= n >= k;
!> if m < k, Q = H(1) H(2) . . . H(m-1) and DORGBR returns Q as an
!> M-by-M matrix.
!>
!> If VECT = 'P', A is assumed to have been a K-by-N matrix, and P**T
!> is of order N:
!> if k < n, P**T = G(k) . . . G(2) G(1) and DORGBR returns the first m
!> rows of P**T, where n >= m >= k;
!> if k >= n, P**T = G(n-1) . . . G(2) G(1) and DORGBR returns P**T as
!> an N-by-N matrix.
!>

Parameters

VECT 
!>          VECT is CHARACTER*1
!>          Specifies whether the matrix Q or the matrix P**T is
!>          required, as defined in the transformation applied by DGEBRD:
!>          = 'Q':  generate Q;
!>          = 'P':  generate P**T.
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix Q or P**T to be returned.
!>          M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix Q or P**T to be returned.
!>          N >= 0.
!>          If VECT = 'Q', M >= N >= min(M,K);
!>          if VECT = 'P', N >= M >= min(N,K).
!>

K

!>          K is INTEGER
!>          If VECT = 'Q', the number of columns in the original M-by-K
!>          matrix reduced by DGEBRD.
!>          If VECT = 'P', the number of rows in the original K-by-N
!>          matrix reduced by DGEBRD.
!>          K >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          On entry, the vectors which define the elementary reflectors,
!>          as returned by DGEBRD.
!>          On exit, the M-by-N matrix Q or P**T.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!>

TAU

!>          TAU is DOUBLE PRECISION array, dimension
!>                                (min(M,K)) if VECT = 'Q'
!>                                (min(N,K)) if VECT = 'P'
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i) or G(i), which determines Q or P**T, as
!>          returned by DGEBRD in its array argument TAUQ or TAUP.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,min(M,N)).
!>          For optimum performance LWORK >= min(M,N)*NB, where NB
!>          is the optimal blocksize.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>

NOMBRE

ungbr - genera una matriz unitaria superior o inferior triangular (en forma de banda) que contiene una submatriz unitaria B

SINOPSIS

subroutine ungbr(VECT, M, N, K, A, LDA, TAU, WORK, LWORK, INFO)

real*8 FUNCTION ungbr(VECT, M, N, K, A, LDA, TAU, WORK, LWORK, INFO)

Descripción Detallada

Esta rutina genera una matriz unitaria superior o inferior triangular (en forma de banda) que contiene una submatriz unitaria B. Es la rutina inversa de gebak.

ungbr se utiliza para reconstruir el factor Q de una factorización QR o el factor Q de una factorización de valores singulares de una matriz A en forma de banda.

VECT (entrada) CHARACTER*1

M (entrada) INTEGER

N (entrada) INTEGER

K (entrada) INTEGER

A (entrada/salida) COMPLEX*16

LDA (entrada) INTEGER

TAU (entrada) COMPLEX*16

WORK (salida) COMPLEX*16

LWORK (entrada) INTEGER

INFO (salida) INTEGER
