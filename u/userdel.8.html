USERDEL(8) Comandos de gestión del sistema USERDEL(8)

NOMBRE

userdel - eliminar una cuenta de usuario y archivos relacionados

SINOPSIS

userdel [opciones] LOGIN

DESCRIPCIÓN

El comando userdel modifica los archivos de cuenta del sistema, eliminando todas las entradas que hacen referencia al nombre de usuario LOGIN. El usuario nombrado debe existir.

OPCIONES

Las opciones que se aplican al comando userdel son:

-f, --force

Esta opción fuerza la eliminación de la cuenta de usuario y cualquier otra acción solicitada, omitiendo las comprobaciones de seguridad.

Nota: Esta opción es peligrosa y puede dejar su sistema en un estado inconsistente.

-h, --help

Muestra el mensaje de ayuda y sale.

-r, --remove

Los archivos en el directorio personal del usuario se eliminarán junto con el propio directorio personal y el buzón de correo del usuario. Los archivos ubicados en otros sistemas de archivos deberán ser buscados y eliminados manualmente.

El buzón de correo se define mediante la variable MAIL_DIR en el archivo login.defs.

-R, --root CHROOT_DIR

Aplica los cambios en el directorio CHROOT_DIR y utiliza los archivos de configuración del directorio CHROOT_DIR. Solo se admiten rutas absolutas.

-P, --prefix PREFIX_DIR

Aplica los cambios en el directorio PREFIX_DIR y utiliza los archivos de configuración del directorio PREFIX_DIR. Esta opción no realiza chroot y está destinada a preparar un objetivo de compilación cruzada. Algunas limitaciones: los usuarios/grupos NIS y LDAP no se verifican. La autenticación PAM utiliza los archivos del host. Sin soporte SELINUX.

-Z, --selinux-user

Elimina cualquier mapeo de usuario SELinux para el inicio de sesión del usuario.

CONFIGURACIÓN

Las siguientes variables de configuración en /etc/login.defs cambian el comportamiento de esta herramienta:

MAIL_DIR (string)

El directorio del buzón de correo. Esto es necesario para manipular el buzón cuando se modifica o elimina la cuenta de usuario correspondiente. Si no se especifica, se utiliza un valor predeterminado en tiempo de compilación. El parámetro CREATE_MAIL_SPOOL en /etc/default/useradd determina si se debe crear el buzón de correo.

MAIL_FILE (string)

Define la ubicación de los archivos de buzón de correo de los usuarios de forma relativa a su directorio personal.

Las variables MAIL_DIR y MAIL_FILE son utilizadas por useradd, usermod y userdel para crear, mover o eliminar el buzón de correo del usuario.

MAX_MEMBERS_PER_GROUP (number)

Miembros máximos por entrada de grupo. Cuando se alcanza el máximo, se inicia una nueva entrada de grupo (línea) en /etc/group (con el mismo nombre, la misma contraseña y el mismo GID).

El valor predeterminado es 0, lo que significa que no hay límites en el número de miembros en un grupo.

Esta característica (grupo dividido) permite limitar la longitud de las líneas en el archivo de grupo. Esto es útil para asegurar que las líneas para los grupos NIS no sean más largas que 1024 caracteres.

Si necesita imponer dicho límite, puede usar 25.

Nota: los grupos divididos pueden no ser compatibles con todas las herramientas (incluso en el conjunto de herramientas Shadow). No debe utilizar esta variable a menos que realmente la necesite.

USERDEL_CMD (string)

Si se define, este comando se ejecuta al eliminar un usuario. Debe eliminar cualquier trabajo de at/cron/impresión, etc. propiedad del usuario a eliminar (pasado como primer argumento).

No se tiene en cuenta el código de retorno del script.

Aquí hay un script de ejemplo, que elimina los trabajos de cron, at e impresión del usuario:

#! /bin/sh
# Comprobar el argumento requerido.
if [ $# != 1 ]; then
	echo "Uso: $0 nombredeusuario"
	exit 1
fi
# Eliminar trabajos de cron.
crontab -r -u $1
# Eliminar trabajos at.
# Nota: eliminará cualquier trabajo propiedad del mismo UID,
# incluso si fue compartido por un nombre de usuario diferente.
AT_SPOOL_DIR=/var/spool/cron/atjobs
find $AT_SPOOL_DIR -name "[^.]*" -type f -user $1 -delete \;
# Eliminar trabajos de impresión.
lprm $1
# Todo listo.
exit 0

USERGROUPS_ENAB (boolean)

Si se establece en yes, userdel eliminará el grupo del usuario si ya no contiene miembros, y useradd creará por defecto un grupo con el nombre del usuario.

ARCHIVOS

/etc/group

Información de cuentas de grupo.

/etc/login.defs

Configuración del conjunto de contraseñas shadow.

/etc/passwd

Información de cuentas de usuario.

/etc/shadow

Información segura de cuentas de usuario.

/etc/shadow-maint/userdel-pre.d/*, /etc/shadow-maint/userdel-post.d/*

Archivos run-part para ejecutar durante la eliminación de usuarios. La variable de entorno ACTION se poblará con userdel y SUBJECT con el nombre de usuario. userdel-pre.d se ejecutará antes de cualquier eliminación de usuario. userdel-post.d se ejecutará después de la eliminación de usuario. Si un script sale con un valor distinto de cero, la ejecución se terminará.

/etc/subgid

IDs de grupo subordinados por usuario.

/etc/subuid

IDs de usuario subordinados por usuario.

VALORES DE SALIDA

El comando userdel sale con los siguientes valores:

0

éxito

1

no se puede actualizar el archivo de contraseñas

2

sintaxis de comando no válida

6

el usuario especificado no existe

8

usuario actualmente conectado

10

no se puede actualizar el archivo de grupo

12

no se puede eliminar el directorio personal

ADVERTENCIAS

userdel no permitirá eliminar una cuenta si hay procesos en ejecución que pertenezcan a esa cuenta. En ese caso, es posible que deba matar esos procesos o bloquear la contraseña o cuenta del usuario y eliminar la cuenta más tarde. La opción -f puede forzar la eliminación de esta cuenta.

Deberá comprobar manualmente todos los sistemas de archivos para asegurarse de que no queden archivos propiedad de este usuario.

No puede eliminar atributos NIS en un cliente NIS. Esto debe realizarse en el servidor NIS.

Si USERGROUPS_ENAB está definido como yes en /etc/login.defs, userdel eliminará el grupo con el mismo nombre que el usuario. Para evitar inconsistencias en las bases de datos de passwd y group, userdel comprobará que este grupo no se utiliza como grupo primario para otro usuario, y solo advertirá sin eliminar el grupo de lo contrario. La opción -f puede forzar la eliminación de este grupo.
