NOMBRE

uhd_cal_rx_iq_balance - Generar Tabla de Calibración de Balance IQ de RX para un Dispositivo UHD

DESCRIPCIÓN

Los Controladores de Hardware de Radio Definida por Software Universal (UHD) manejan la información de calibración. Esta aplicación reduce el desequilibrio IQ de RX dentro del rango de frecuencia especificado utilizando la fuga de transmisión en la ruta de recepción. Retire todo el hardware externo de los puertos de antena de RF antes de usar esta aplicación. Esto puede tardar hasta varios minutos con la configuración predeterminada.

NOTA: Esta aplicación solo se puede usar con las placas hijas WBX, SBX, XCVR2450 y RFX.

OPCIONES

--help
mensaje de ayuda
--verbose
habilitar algo de verbosidad
--args arg
argumentos de dirección del dispositivo [por defecto = ""]
--tx_wave_freq arg (=507123)
Frecuencia de onda de transmisión en Hz
--tx_wave_ampl arg (=0.69999999999999996)
Amplitud de onda de transmisión en recuentos
--tx_gain arg
Ganancia de TX en dB (se usará la ganancia predeterminada si no se especifica)
--tx_offset arg (=934400)
Desplazamiento del LO de TX del LO de RX en Hz
--freq_start arg
Inicio de frecuencia en Hz (se usará el inicio del rango de frecuencia si no se especifica)
--freq_stop arg
Fin de frecuencia en Hz (se usará el final del rango de frecuencia si no se especifica)
--freq_step arg (=7300000)
Tamaño del paso para el barrido de LO en Hz
--nsamps arg (=10000)
Muestras por captura de datos
