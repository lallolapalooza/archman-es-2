UNICHARSET_EXTRACTOR(1)   UNICHARSET_EXTRACTOR(1)

NOMBRE

unicharset_extractor - Lee archivos de caja (box) o de texto plano para extraer el conjunto de caracteres unicharset.

SINOPSIS

unicharset_extractor [--output_unicharset nombre_archivo] [--norm_mode modo] archivo_o_texto [...]

Donde modo significa: 1=combinar grafemas (usar para guiones latinos y otros simples) 2=dividir grafemas (usar para guiones de la India/Khmer/Myanmar) 3=unicode puro (usar para árabe/hebreo/tailandés/tibetano)

DESCRIPCIÓN

Tesseract necesita conocer el conjunto de caracteres posibles que puede producir. Para generar el archivo de datos del conjunto de caracteres unicharset, utilice el programa unicharset_extractor en archivos de bounding box de páginas de entrenamiento o en un archivo de texto plano:

unicharset_extractor fontfile_1.box fontfile_2.box ...

El conjunto de caracteres unicharset se colocará en el archivo ./unicharset si no se proporciona un nombre de archivo de salida.

NOTA Utilice el modo norm_mode apropiado según el idioma.
