NOMBRE

umoci raw runtime-config - Genera una configuración de tiempo de ejecución OCI para una imagen

SINOPSIS

umoci raw runtime-config --image=imagen[:etiqueta] [--rootfs=rootfs] [--rootless] config

umoci raw config --image=imagen[:etiqueta] [--rootfs=rootfs] [--rootless] config

DESCRIPCIÓN

Genera una nueva configuración de tiempo de ejecución OCI a partir de una imagen, sin extraer el rootfs de dicha imagen. La configuración se escribe en la ruta dada por config, sobrescribiéndola si ya existe. Esta es una de las operaciones realizadas por umoci-unpack(1) al generar el paquete de tiempo de ejecución, pero debido a la sobrecarga de extraer un sistema de archivos raíz, umoci-unpack(1) no es práctico de usar muchas veces si el usuario realmente no quiere usar el sistema de archivos raíz. Algunos campos requieren un sistema de archivos raíz como "fuente de verdad", y se puede especificar un sistema de archivos raíz de origen usando --rootfs. Las otras banderas tienen los mismos efectos que con umoci-unpack(1).

Tenga en cuenta, sin embargo, que la salida de umoci-raw-runtime-config(1) no es necesariamente idéntica a la salida de umoci-unpack(1). Esto es especialmente cierto si no se especifica --rootfs, lo que resulta en que umoci(1) deje los campos en la especificación de tiempo de ejecución con sus valores predeterminados si calcular sus valores requiriera usar el sistema de archivos raíz como fuente de verdad.

OPCIONES

Las opciones globales se definen en umoci(1).

--image=imagen[:etiqueta]
La etiqueta de la imagen OCI que se extraerá en el bundle. imagen debe ser una
ruta a una imagen OCI válida y etiqueta debe ser una etiqueta válida en la imagen. Si
no se proporciona etiqueta, por defecto es "latest".

--rootfs=rootfs
Utiliza rootfs como fuente de verdad secundaria al generar la configuración
de tiempo de ejecución (esto es especialmente importante para la conversión de
Config.User). Si no se especifica, cualquier campo de tiempo de ejecución que
requiera una fuente de verdad secundaria para ser completado se dejará con sus
valores predeterminados. Esto puede resultar en discrepancias entre la salida de
umoci-unpack(1) y umoci-raw-runtime-config(1).

--rootless
Genera una configuración de contenedor sin root, similar a la configuración
producida por umoci-unpack(1) cuando se le proporciona la bandera
--rootless.

EJEMPLO

Lo siguiente descarga una imagen de un registro de docker(1) usando skopeo(1) y luego genera el config.json para esa imagen.

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
% umoci raw runtime-config --image image:latest config.json

Si ya hay un sistema de archivos raíz presente, es posible especificarlo con la bandera --rootfs. Esto utilizará el sistema de archivos raíz para operaciones de conversión que lo requieran.

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
# umoci unpack --image image bundle
% umoci raw runtime-config --image image --rootfs bundle/rootfs config.json
