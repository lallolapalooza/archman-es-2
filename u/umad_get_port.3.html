UMAD_GET_PORT(3) Manual del programador de OpenIB UMAD_GET_PORT(3)

NOMBRE

umad_get_port, umad_release_port - abrir y cerrar un puerto InfiniBand

SINOPSIS

#include <infiniband/umad.h>

int umad_get_port(char *ca_name, int portnum, umad_port_t *port);

int umad_release_port(umad_port_t *port);

DESCRIPCIÓN

umad_get_port() rellena la estructura port con los atributos del puerto IB especificados por ca_name y portnum , o el puerto predeterminado si ca_name es NULL y portnum es cero. Si solo se especifica uno de ca_name y portnum, el otro se usa como filtro. Por ejemplo, pasar un ca_name NULL y 2 para portnum significa obtener un puerto de cualquiera de los dispositivos IB locales, siempre que sea el segundo puerto. Tenga en cuenta que la biblioteca puede usar algún esquema de referencia para admitir el almacenamiento en caché de puertos, por lo tanto, umad_release_port() debe llamarse antes de que se pueda liberar la estructura port. El argumento port es una estructura umad_port_t, como se especifica en <infiniband/umad.h>.

typedef struct umad_port {
char ca_name[UMAD_CA_NAME_LEN];                 /* Nombre del dispositivo */
int portnum;                                    /* Número de puerto físico */
uint base_lid;                                  /* LID base del puerto */
uint lmc;                                       /* LMC del LID */
uint sm_lid;                                    /* LID del SM */
uint sm_sl;                                     /* Nivel de servicio del SM */
uint state;                                     /* Estado lógico del puerto */
uint phys_state;                                /* Estado físico del puerto */
uint rate;                                      /* Tasa de bits del enlace del puerto */
uint64_t capmask;                               /* Máscara de capacidades del puerto */
uint64_t gid_prefix;                            /* Prefijo GID de este puerto */
uint64_t port_guid;                             /* GUID de este puerto */
} umad_port_t;

umad_release_port() libera los recursos que fueron asignados por la función umad_get_port() para el puerto IB especificado.

VALOR DE RETORNO

umad_get_port() y umad_release_port() devuelven 0 si la operación es exitosa y un valor negativo si hay un error.
