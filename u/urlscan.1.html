URLSCAN(1) Manual General de Comandos URLSCAN(1)

NOMBRE

urlscan - examinar las URL en un mensaje de correo electrónico desde una terminal

SINOPSIS

urlscan [opciones] < mensaje

urlscan [opciones] mensaje

DESCRIPCIÓN

urlscan acepta un único mensaje de correo electrónico en la entrada estándar, luego muestra una lista basada en terminal de las URL en el mensaje dado. La selección de una URL utiliza el módulo webbrowser de Python para determinar qué navegador abrir. La variable de entorno BROWSER se usará si está configurada.

urlscan está pensado principalmente para ser utilizado con el lector de correo mutt (1), pero debería funcionar bien con cualquier programa de correo basado en terminal.

urlscan es similar a urlview(1), pero tiene las siguientes características adicionales:

1. Soporte para más codificaciones de mensajes, como quoted-printable y base64.

2. Extracción y visualización del contexto que rodea a cada URL. Alternar la vista de contexto con c. Invertir el orden de visualización de las URL con R.

3. Copiar la URL actual a la selección primaria con P o al portapapeles con C.

4. Las URL se acortan por defecto para caber en una línea. Alternar URL acortadas individuales o todas con s o S.

5. Búsqueda incremental insensible a mayúsculas y minúsculas usando /. El pie de página muestra el término de búsqueda actual. / nuevamente reinicia la búsqueda.

6. Ciclar a través de todas las paletas disponibles (con color y blanco y negro disponibles por defecto) usando p. Ejecutar urlscan -g generará un archivo ~/.config/urlscan/config.json para editar o agregar paletas y asignaciones de teclas adicionales. Ver

http://urwid.org/manual/displayattributes.html#display-attributes

para opciones de color y valores permitidos. Establecer el ancho de pantalla con `--width`.

7. u decodificará la URL resaltada si es necesario.

8. Ejecutar un comando con la URL seleccionada como argumento o canalizar la URL seleccionada a un comando usando los argumentos `--run-safe`, `--run` y `--pipe`.

9. Usar l para ciclar entre si las URL se abren usando el módulo webbrowser de Python (por defecto), xdg-open (si está instalado) o una función pasada en la línea de comandos con `--run-safe` o `--run`. Las funciones `--run` y `--run-safe` respetarán el valor de `--pipe`.

10. F1 muestra el menú de ayuda.

11. Escanear ciertos encabezados de correo electrónico en busca de URL. Actualmente se escanean Link, Archived-At y List-* cuando se pasa `--headers`.

12. Poner en cola múltiples URL para abrirlas y abrirlas todas a la vez con a y o.

OPCIONES

-c, --compact
Modo de visualización compacto; no mostrar el contexto de cada URL.
-d, --dedupe
Eliminar URL duplicadas de la lista de URL.
-E, --regex <expresión>
Usar <expresión> en lugar del conjunto predeterminado de expresiones regulares, para ser utilizado para cualquier tipo de coincidencia. Esto es útil, por ejemplo, al evitar selectivamente enlaces 'mailto:' o cualquier otro patrón que urlscan podría interpretar como URL (como '<nombrearchivo>.<extensión>'). Ejemplo de uso:


$ urlscan --regex 'https?://.+.216

-f, --run-safe <expresión>
Ejecutar <expresión> en lugar de abrir la URL con un navegador. Usar {} en <expresión> para sustituir la URL. Ejemplos:


$ urlscan --run-safe 'tmux set buffer {}'

-g, --genconf
Generar ~/.config/urlscan/config.json con las opciones por defecto.
-H, --nohelp
Iniciar con el menú de encabezado oculto.
--headers
Escanear ciertos encabezados del mensaje en busca de URL. Actualmente se escanean Link, Archived-At y List-*.
-n, --no-browser
Deshabilita la interfaz de selección e imprime los enlaces en la salida estándar. Útil para scripting (implica --compact).
-p, --pipe
Canalizar la URL seleccionada al comando especificado por `--run-safe` o `--run`. Esto se prefiere cuando el comando lo soporta, ya que es más seguro y tolerante a caracteres especiales en la URL. Ejemplo:


$ urlscan --run-safe 'xclip -i' --pipe file.txt

-R, --reverse
Invertir el orden de visualización de las URL.
-r, --run <expresión>
Ejecutar <expresión> en lugar de abrir la URL con un navegador. Usar {} en <expresión> para sustituir la URL. Se pueden usar características del shell como | y >, pero es menos seguro. Ejemplos:


$ urlscan --run 'echo {} | xclip -i' file.txt

-s, --single
Salir de urlscan después de abrir o copiar un solo enlace del navegador.


$ urlscan -s file.txt

-w, --width
Establecer el ancho de pantalla.
-W, --whitespace-off
No mostrar líneas vacías ni elipses.
-C, --colors {true,256,88,16,8,mono}
Establecer el modo de color de urwid. El valor predeterminado es "16". "true" = 2**24 colores y "mono" = 1 color.
-V, --version
Imprimir la versión de urlscan.

INTEGRACIÓN CON MUTT

Para integrar urlscan con mutt, incluye los siguientes dos comandos en ~/.muttrc:

macro index,pager \cb "<pipe-message> urlscan<Enter>" "llamar a urlscan para extraer URL de un mensaje"

macro attach,compose \cb "<pipe-entry> urlscan<Enter>" "llamar a urlscan para extraer URL de un mensaje"

Una vez que estas líneas estén en tu archivo de configuración de mutt, presionar Control-b te permitirá examinar y abrir las URL en el mensaje actualmente seleccionado.

Alternativamente, puedes canalizar un mensaje a urlscan usando el operador '|'. Esto puede ser útil para aplicar una bandera diferente (como las opciones '-d' o '-c').

ASIGNACIONES DE TECLAS

Ejecuta urlscan -g para generar ~/.config/urlscan/config.json. Todas las teclas se listarán. Puedes dejar en su lugar o eliminar cualquiera que no se vaya a modificar.

Para desestablecer una asignación, asígnala a "". Por ejemplo: "P": ""

Las siguientes acciones son compatibles:

add_url -- agregar una URL a la cola (Predeterminado: a)
all_escape -- alternar decodificar todas las URL (Predeterminado: u)
all_shorten -- alternar acortar todas las URL (Predeterminado: S)
bottom -- mover el cursor al último elemento (Predeterminado: G)
clear_screen -- redibujar pantalla (Predeterminado: Ctrl-l)
clipboard -- copiar la URL resaltada al portapapeles usando xsel/xclip (Predeterminado: C)
clipboard_pri -- copiar la URL resaltada a la selección primaria usando xsel/xclip (Predeterminado: P)
context -- mostrar/ocultar contexto (Predeterminado: c)
del_url -- eliminar URL de la c

urlscan(1) — archlinux manual pages

NAME

urlscan

scan URLs from stdin, provide keyboard shortcuts to open them

SYNOPSIS

urlscan [options]

DESCRIPTION

urlscan reads URLs from stdin, sorts them, and presents them in a list. You can then use keyboard shortcuts to open them, and so on.

urlscan supports a variety of palettes, which can be used to change the way the list of URLs is displayed. Palettes can be changed with the palette keybinding.

It can also be integrated with mutt(1) to allow the user to open URLs from email messages.

OPTIONS

The following options are available:

-c, --config file
Use file as the configuration file. See FILES below.
-p, --palette name
Set the initial palette to name.
-h, --help
Show help message and exit.
-v, --version
Show version and exit.

MUTT INTEGRATION

To integrate urlscan with mutt, add the following to your mutt configuration file (~/.mutt/muttrc):

set url_handler=urlscan

set follow_to_current_dir=yes

This will make mutt call urlscan whenever you press the hotkey for opening URLs (default is the Enter key).

KEYBINDINGS

all -- open all URLs in current buffer (Default: a)
down -- cursor down (Default: j)
help_menu -- show/hide help menu (Default: F1)
link_handler -- cycle link handling (webbrowser, xdg-open or custom) (Default: l)
next -- jump to next URL (Default: J)
open_queue -- open all URLs in queue (Default: o)
open_queue_win -- open all URLs in queue in new window (Default: O)
open_url -- open selected URL (Default: space or enter)
palette -- cycle through palettes (Default: p)
previous -- jump to previous URL (Default: K)
quit -- quit (Default: q or Q)
reverse -- reverse display order (Default: R)
shorten -- toggle shorten highlighted URL (Default: s)
top -- move to first list item (Default: g)
up -- cursor up (Default: k)

FILES

$HOME/.config/urlscan/config.json

Only required if additional or modified palettes or keybindings are desired.
