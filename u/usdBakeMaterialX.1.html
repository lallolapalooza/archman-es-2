USDBAKEMATERIALX(1) Comandos de usuario USDBAKEMATERIALX(1)

NOMBRE

usdBakeMaterialX - página del manual para usdBakeMaterialX 25.11

DESCRIPCIÓN

uso: usdBakeMaterialX [-h] [--width WIDTH] [--height HEIGHT] [--hdr]

[--average]
archivoUsdEntrada archivoUsdSalida

Genera un archivo USD actualizado que contiene una variante de material adicional correspondiente a una versión horneada de cada material MaterialX en el archivo USD de entrada. Los materiales horneados se generan utilizando la clase MaterialX::TextureBaker y generarán un archivo mtlx y las texturas asociadas.

argumentos posicionales:

archivoUsdEntrada
Nombre del archivo Usd de entrada.
archivoUsdSalida
Nombre del archivo Usd de salida. El archivo mtlx generado y cualquier imagen generada se guardarán en este directorio.

opciones:

-h, --help
mostrar este mensaje de ayuda y salir
--width ANCHO
Especifica el ancho de las texturas horneadas.
--height ALTO
Especifica el alto de las texturas horneadas.
--hdr
Guarda las imágenes en formato hdr.
--average
Promedia las imágenes horneadas para generar valores constantes.
