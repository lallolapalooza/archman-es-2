unw_get_proc_info(3)

Paquete: libunwind

Licencias: MIT

UNW_GET_PROC_INFO(3libunwind) Librería de programación UNW_GET_PROC_INFO(3libunwind)

NOMBRE

unw_get_proc_info -- obtener información del procedimiento actual

SINOPSIS

#include <libunwind.h>

int unw_get_proc_info(unw_cursor_t *cp, unw_proc_info_t *pip);

DESCRIPCIÓN

La rutina unw_get_proc_info() devuelve información auxiliar sobre el procedimiento que creó el marco de pila identificado por el argumento cp. El argument pip es un puntero a una estructura de tipo unw_proc_info_t que se usa para devolver la información. La estructura unw_proc_info_t tiene los siguientes miembros:

unw_word_t start_ip

La dirección de la primera instrucción del procedimiento. Si no se puede determinar esta dirección (por ejemplo, debido a la falta de información de desenrollado), el miembro start_ip se pone a 0.
unw_word_t end_ip

La dirección de la primera instrucción *después* del final del procedimiento. Si no se puede determinar esta dirección (por ejemplo, debido a la falta de información de desenrollado), el miembro end_ip se pone a 0.
unw_word_t lsda

La dirección del área de datos específica del lenguaje (LSDA). Esta área normalmente contiene información específica del lenguaje necesaria durante el manejo de excepciones. Si el procedimiento no tiene dicha área, este miembro se pone a 0.
unw_word_t handler

La dirección de la rutina de manejo de excepciones. A veces se la llama rutina de *personalidad*. Si el procedimiento no define una rutina de personalidad, el miembro handler se pone a 0.
unw_word_t gp

El puntero global del procedimiento. En plataformas que no utilizan un puntero global, este miembro puede contener un valor indefinido. En todas las demás plataformas, debe establecerse en el valor correcto del puntero global del procedimiento o en 0 si no se puede obtener el puntero global correcto por alguna razón.
unw_word_t flags

Un conjunto de indicadores. Actualmente no hay indicadores independientes del objetivo. Para el objetivo IA-64, el indicador UNW_PI_FLAG_IA64_RBS_SWITCH se establece si el procedimiento puede cambiar el almacenamiento de registro de respaldo.
int format

El formato de la información de desenrollado para este procedimiento. Si la información de desenrollado consiste en información de procedimiento dinámica, format es igual a UNW_INFO_FORMAT_DYNAMIC. Si la información de desenrollado consiste en una tabla de desenrollado (específica del objetivo), es igual a UNW_INFO_FORMAT_TABLE. Todos los demás valores están reservados para uso futuro por libunwind. Este miembro existe para ser utilizado por la devolución de llamada find_proc_info() (ver unw_create_addr_space(3libunwind)). La rutina unw_get_proc_info() puede devolver un valor indefinido en este miembro.
int unwind_info_size

El tamaño de la información de desenrollado en bytes. Este miembro existe para ser utilizado por la devolución de llamada find_proc_info() (ver unw_create_addr_space(3libunwind)). La rutina unw_get_proc_info() puede devolver un valor indefinido en este miembro.
void *unwind_info

El puntero a la información de desenrollado. Si no hay información de desenrollado disponible, este miembro debe establecerse en NULL. Este miembro existe para ser utilizado por la devolución de llamada find_proc_info() (ver unw_create_addr_space(3libunwind)). La rutina unw_get_proc_info() puede devolver un valor indefinido en este miembro.

Tenga en cuenta que para los fines de libunwind, se supone que el código de un procedimiento ocupa un único rango contiguo de direcciones. Por este motivo, siempre es posible describir la extensión de un procedimiento con los miembros start_ip y end_ip. Si una sola función/rutina se divide en varias piezas no contiguas, libunwind tratará cada pieza como un procedimiento separado.

VALOR DE RETORNO

Al completarse con éxito, unw_get_proc_info() devuelve 0. De lo contrario, se devuelve el valor negativo de uno de los siguientes códigos de error.

SEGURIDAD DE HILOS Y SEÑALES

unw_get_proc_info() es seguro para hilos. Si el cursor cp está en el espacio de direcciones local, esta rutina también es segura de usar desde un manejador de señales.

ERRORES

UNW_EUNSPEC

Ocurrió un error no especificado.
UNW_ENOINFO

Libunwind no pudo encontrar información de desenrollado para el procedimiento.
UNW_EBADVERSION

La información de desenrollado del procedimiento tiene una versión o formato que libunwind no entiende.

Además, unw_get_proc_info() puede devolver cualquier error devuelto por la devolución de llamada access_mem() (ver unw_create_addr_space(3libunwind)).
