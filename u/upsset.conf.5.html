NOMBRE

upsset.conf - Configuración para Network UPS Tools upsset.cgi

DESCRIPCIÓN

Este archivo solo cumple una función: permitirle convencer a upsset.cgi(8) de que el directorio CGI de su sistema es seguro. El programa no se ejecutará hasta que este archivo se haya definido correctamente.

NOTAS IMPORTANTES

•El contenido de este archivo debe ser ASCII puro (los códigos de caracteres que no estén en el rango se ignorarán con un mensaje de advertencia).

REQUISITOS DE SEGURIDAD

upsset.cgi(8) le permite probar combinaciones de nombres de usuario y contraseñas. No hay limitación de velocidad, ya que el programa se cierra entre cada solicitud. Tal es la naturaleza de los programas CGI.

Las credenciales se proporcionan a upsset.cgi como parte de su sesión de navegación, por lo que se recomienda encarecidamente configurar HTTPS en el servidor web; las formas de hacerlo están fuera del alcance de este documento.

Normalmente, los atacantes no podrían acceder directamente a su servidor upsd(8), ya que estaría protegido por las directivas LISTEN en su archivo upsd.conf(5), tcp-wrappers (si estaban disponibles cuando se compiló NUT) y, con suerte, la configuración del firewall local de su sistema operativo.

upsset se ejecuta en su servidor web, por lo que upsd lo verá como una conexión de un host en una red interna. No sabrá que la conexión es iniciada realmente por alguien más externo. Por eso debe asegurarlo.

En Apache, puede usar el archivo .htaccess o colocar las directivas en su httpd.conf. Se ve algo así, asumiendo el método .htaccess para versiones anteriores de Apache:

<Files upsset.cgi>
        deny from all
        allow from your.network.addresses
</Files>

Probablemente también tendrá que establecer AllowOverride Limit para este directorio en el archivo de configuración a nivel de servidor.

Apache moderno disfruta de una sintaxis más detallada, así:

ScriptAlias /upsstats.cgi /usr/share/nut/cgi/upsstats.cgi
ScriptAlias /upsset.cgi /usr/share/nut/cgi/upsset.cgi
<Directory "/usr/share/nut/cgi">
      Options +Includes +ExecCGI
      AllowOverride Limit
      <RequireAny>
          Require local
          Require ip aa.bb.cc.dd/nn
      </RequireAny>
</Directory>

Si esto no tiene sentido, deje de leer y no se preocupe por este programa. De todos modos, no es algo que necesite absolutamente.

Suponiendo que ha hecho todo esto y que realmente funciona (¡pruébelo!), entonces puede añadir la siguiente directiva a este archivo:

I_HAVE_SECURED_MY_CGI_DIRECTORY

Si le miente al programa y alguien ataca su upsd a través de su servidor web, no me culpe.
