UPMPDCLI(1) Manual de Comandos Generales UPMPDCLI(1)

NOMBRE

upmpdcli - Interfaz de UPnP Media Renderer para MPD, el Music Player Daemon

SINOPSIS

upmpdcli [opciones]

DESCRIPCIÓN

upmpdcli es un programa que debe ejecutarse permanentemente (típicamente como un demonio, o iniciado al iniciar sesión) y actúa como un UPnP Media Renderer, utilizando el Music Player Daemon, mpd, para reproducir la música. Esto permite integrar MPD, de alta calidad y ampliamente portado, dentro de una red de música basada en UPnP, típicamente con un controlador ejecutándose en una tableta o teléfono.

OPCIONES

Este programa utiliza opciones cortas. A continuación se incluye un resumen de las opciones.

-c archivo_config
Utiliza la configuración de archivo_config. El archivo de configuración tiene un formato simple de nombre = valor y puede establecer los mismos valores que las opciones de línea de comandos (con una prioridad menor). Los nombres de los parámetros son mpdhost, mpdport, friendlyname, logfilename, loglevel, upnpiface, upnpport. El archivo de configuración también se puede usar para establecer la contraseña de MPD (mpdpassword), y la dirección IP de UPnP (en lugar del nombre de la interfaz, upnpip). Ver upmpdcli.conf(5). Tenga en cuenta que si no se proporciona esta opción, no se lee ningún archivo de configuración y el programa se ejecuta completamente a partir de sus valores predeterminados, opciones de línea de comandos y variables de entorno.
-h host
Define la máquina host en la que se ejecuta mpd.
-f nombre_amigable
Establece el nombre que los controladores mostrarán para esta instancia después de buscar en la red.
-p puerto
Define el puerto IP utilizado por mpd.
-q 0|1
Decide si poseemos la cola de MPD (-q 1) o no (-q 0). La poseemos por defecto y la vaciamos sin miedo.
-d archivo_log
Envía mensajes de depuración/rastreo a archivo_log.
-l nivel
Establece la verbosidad del registro (0-4).
-D
Daemonizar (hacer fork y ejecutar en segundo plano). Usar -D para esto es lo contrario de la convención habitual, pero los autores encontraron mejor evitar sorprender a los usuarios ingenuos con una desaparición inesperada del programa...
-i interfaz
Define la interfaz de red a utilizar para UPnP.
-O /0
Inicia los servicios OpenHome ohMedia (especialmente PlayList), o no.
-P puerto
Define el puerto IP a utilizar para UPnP.
