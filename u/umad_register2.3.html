UMAD_REGISTER2(3) Manual del programador de OpenIB UMAD_REGISTER2(3)

NOMBRE

umad_register2 - registrar la clase de gestión y versión especificadas para el puerto

SINOPSIS

#include <infiniband/umad.h>

int umad_register2(int port_fd, struct umad_reg_attr *attr, uint32_t *agent_id);

DESCRIPCIÓN

umad_register2() se registra para un agente MAD utilizando los atributos de registro proporcionados.

port_fd el puerto en el que registrar el agente

attr Los atributos de registro según se definen en la estructura pasada. Consulte a continuación los detalles de esta estructura.

agent_id devuelto en caso de éxito. agent_id identifica el agente MAD del kernel al que se recibe o se va a enviar un MAD. agent_id se devuelve en la cabecera umad "struct ib_user_mad" en la recepción y se especifica en umad_send al enviar.

ESTRUCTURA DE ATRIBUTOS DE REGISTRO

struct umad_reg_attr {
uint8_t    mgmt_class;
uint8_t    mgmt_class_version;
uint32_t   flags;
uint64_t   method_mask[2];
uint32_t   oui;
uint8_t    rmpp_version;
};
mgmt_class
Clase de gestión para la que registrarse.
mgmt_class_version
Versión de la clase de gestión para la que registrarse.
flags
Indicadores de registro. Si un indicador especificado no es compatible con el kernel, se devuelve un error y los indicadores compatibles se devuelven en este campo.
Los indicadores actuales son:
UMAD_USER_RMPP -- indicador para indicar que el kernel no debe procesar
paquetes RMPP. Todos los paquetes RMPP se tratarán como MAD individuales.
El usuario es responsable de implementar el protocolo
RMPP.
method_mask
Una máscara de bits que indica qué métodos no solicitados debe recibir este agente.
Establecer esta matriz a 0 hará que el agente solo reciba
MAD de respuesta para los que se envió una solicitud.
oui
El oui (en orden de host) a utilizar para las clases de proveedor 0x30 - 0x4f.
De lo contrario, se ignora.
rmpp_version
Si la clase admite RMPP y el RMPP del kernel está habilitado (por defecto),
indique qué rmpp_version utilizar.

VALOR DE RETORNO

umad_register2() devuelve 0 en caso de éxito y +ERRNO en caso de fallo.

VEASE TAMBIÉN
