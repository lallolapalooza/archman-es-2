NOMBRE

unw_set_cache_size -- establece el tamaño de la caché de deshacer

SINOPSIS

#include <libunwind.h>

int unw_set_cache_size(unw_addr_space_t as, size_t size, int flag);

DESCRIPCIÓN

La rutina unw_set_cache_size() establece el tamaño de la caché del espacio de direcciones as para que contenga al menos tantos elementos como se indica en el argumento size. Puede contener más elementos según lo determine la implementación. Para deshabilitar la caché, llame a unw_set_caching_policy) con una política de UNW_CACHE_NONE. El argumento flag no se usa actualmente y debe ser 0.

VALOR DE RETORNO

Al completarse con éxito, unw_set_cache_size() devuelve 0. De lo contrario, se devuelve el valor negativo de uno de los siguientes códigos de error.

SEGURIDAD EN HILOS Y SEÑALES

unw_set_cache_size() es seguro para hilos, pero *no* es seguro para usar desde un manejador de señales.

ERRORES

UNW_ENOMEM

No se pudo establecer el tamaño de caché deseado porque la aplicación se ha quedado sin memoria.

VER TAMBIÉN
