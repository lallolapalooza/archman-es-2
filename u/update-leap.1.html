NOMBRE

update-leap - gestor/actualizador de archivos de segundos intercalares

SINOPSIS

update-leap [-flags] [-flag [valor]] [--nombre-opcion[[=| ]valor]]

Todos los argumentos deben ser opciones.

DESCRIPCIÓN

update-leap validará el archivo actualmente en el sistema local y, si es necesario, actualizará el archivo de definición de segundos intercalares.

Normalmente, el archivo se encuentra usando la directiva "leapfile" en ntp.conf(5). Sin embargo, se puede especificar una ubicación alternativa en la línea de comandos.

Si el archivo no existe, no es válido, ha caducado o está a punto de caducar, se descargará una nueva copia. Si la nueva copia se valida, se instalará y NTP se reiniciará (opcionalmente).

Si el archivo actual es aceptable, no se realiza ninguna descarga ni reinicio.

-c también se puede usar para invocar otro script para realizar funciones administrativas, por ejemplo, para copiar el archivo a otros sistemas locales.

Esto se puede ejecutar como un trabajo cron. Como el archivo se actualiza raramente, y los segundos intercalares se anuncian con al menos un mes de antelación (generalmente más), no es necesario ejecutarlo con más frecuencia que aproximadamente cada tres semanas.

Para un comportamiento amigable con cron, defina CRONJOB=1 en el crontab.

Este script depende de$REQUIREDCMDS

OPCIONES

-s cadena, --source-url=cadena

La URL de la copia maestra del archivo de segundos intercalares.

Especifique la URL de la copia maestra para descargar $LEAPSRC

-4, --ipv4

Utilice solo direcciones IPv4 para la resolución de nombres DNS. Esta opción no debe aparecer en combinación con ninguna de las siguientes opciones: ipv6.

-d flotante, --destination=flotante

Nombre de archivo en el sistema local.

El nombre a utilizar para almacenar el archivo de segundos intercalares en el sistema local. $LEAPFILE

-e cadena, --expiration=cadena

Actualizar el archivo de segundos intercalares durante este tiempo antes de que expire.

Especifique cuánto tiempo antes de la expiración se debe actualizar el archivo. Se requieren unidades, por ejemplo, "-e 60 días". Tenga en cuenta que valores más grandes implican actualizaciones más frecuentes. "$PREFETCH"

-f cadena, --ntp-conf-file=cadena

Ubicación del archivo ntp.conf.

Especifique la ubicación de ntp.conf (se utiliza para asegurar que la directiva leapfile esté presente y para el valor predeterminado de leapfile) /etc/ntp.conf

-F, --force-update

Forzar la actualización del archivo de segundos intercalares.

Forzar la actualización incluso si el archivo actual está bien y no está cerca de expirar.

--dont-wait

No esperar pulsación de tecla entre gráficos.
