NOMBRE

uu-od - Volcar archivos en formato octal y otros

SINOPSIS

uu-od [--help] [-A|--address-radix] [-j|--skip-bytes] [-N|--read-bytes] [--endian] [-S|--strings] [-a ] [-b ] [-c ] [-d ] [-D ] [-o ] [-I ] [-L ] [-i ] [-l ] [-x ] [-h ] [-O ] [-s ] [-X ] [-H ] [-e ] [-f ] [-F ] [-t|--format] [-v|--output-duplicates] [-w|--width] [--traditional] [-V|--version] [NOMBRE_ARCHIVO]

DESCRIPCIÓN

Volcar archivos en formato octal y otros

OPCIONES

--help
Imprimir información de ayuda.
-A, --address-radix <RADIX>
Seleccionar la base en la que se imprimen los desplazamientos del archivo.
-j, --skip-bytes <BYTES>
Saltar bytes de entrada antes de formatear y escribir.
-N, --read-bytes <BYTES>
limitar el volcado a BYTES bytes de entrada
--endian <big|little>
orden de bytes a utilizar para formatos de múltiples bytes

[posibles valores: big, little]

-S, --strings [<BYTES>]
imprimir cadenas de al menos BYTES caracteres gráficos. Se asume 3 cuando BYTES no se especifica.
-a
caracteres con nombre, ignorando el bit de orden superior
-b
bytes octales
-c
caracteres ASCII o escapes de barra invertida
-d
unidades decimales sin signo de 2 bytes
-D
unidades decimales sin signo de 4 bytes
-o
unidades octales de 2 bytes
-I
unidades decimales de 8 bytes
-L
unidades decimales de 8 bytes
-i
unidades decimales de 4 bytes
-l
unidades decimales de 8 bytes
-x
unidades hexadecimales de 2 bytes
-h
unidades hexadecimales de 2 bytes
-O
unidades octales de 4 bytes
-s
unidades decimales de 2 bytes
-X
unidades hexadecimales de 4 bytes
-H
unidades hexadecimales de 4 bytes
-e
unidades de precisión doble de punto flotante (64 bits)
-f
unidades de precisión simple de punto flotante (32 bits)
-F
unidades de precisión doble de punto flotante (64 bits)
-t, --format <TIPO>
seleccionar formato o formatos de salida
-v, --output-duplicates
no usar * para marcar supresión de línea
-w, --width [<BYTES>]
imprimir BYTES bytes por línea de salida. Se implican 32 cuando BYTES no se especifica.
--traditional
modo de compatibilidad con una entrada, desplazamiento y etiqueta.
-V, --version
Imprimir versión

EXTRA

Muestra datos en varios formatos legibles por humanos. Si se especifican múltiples formatos, la salida contendrá todos los formatos en el orden en que aparecen en la línea de comandos. Cada formato se imprimirá en una línea nueva. Solo la línea que contiene el primer formato se prefijará con el desplazamiento.

Si no se especifica ningún nombre de archivo, o es "-", se usará la entrada estándar. Después de un "--", no se reconocerán más opciones. Esto permite nombres de archivo que comienzan con un "-".

Si un nombre de archivo es un número válido que se puede usar como desplazamiento en la segunda forma, puede forzar que se reconozca como un nombre de archivo si incluye una opción como "-j0", que solo es válida en la primera forma.

RADIX es uno de o, d, x, n para octal, decimal, hexadecimal o ninguno.

BYTES es decimal por defecto, octal si se prefija con un "0", o hexadecimal si se prefija con "0x". Los sufijos b, KB, K, MB, M, GB, G, multiplicarán el número por 512, 1000, 1024, 1000^2, 1024^2, 1000^3, 1024^3, 1000^2, 1024^2.

DESPLAZAMIENTO y ETIQUETA son octales por defecto, hexadecimales si se prefijan con "0x" o decimales si se añade un sufijo ".". El sufijo "b" se multiplicará por 512.

TIPO contiene una o más especificaciones de formato que consisten en:
a para ASCII de 7 bits imprimible
c para caracteres utf-8 u octal para caracteres indefinidos
d[SIZE] para decimal con signo
f[SIZE] para punto flotante
o[SIZE] para octal
u[SIZE] para decimal sin signo
x[SIZE] para hexadecimal. SIZE es el número de bytes, que puede ser el número 1, 2, 4, 8 o 16,
o C, S, I, L para 1, 2, 4, 8 bytes para tipos enteros,
o F, D, L para 4, 8, 16 bytes para punto flotante. Cualquier especificación de tipo puede tener un sufijo "z", que añadirá un volcado ASCII al
final de la línea.

Si ocurrió un error, se imprimirá un mensaje de diagnóstico en stderr y el código de salida será distinto de cero.
