unibi_get_num(3)

Paquete: unibilium

Licencias: LGPL3

doc::unibi_get_num(3) unibilium doc::unibi_get_num(3)

NOMBRE

unibi_get_bool, unibi_set_bool, unibi_get_num, unibi_set_num, unibi_get_str, unibi_set_str - acceder a las capacidades de un objeto de terminal

SINOPSIS

#include <unibilium.h>

int unibi_get_bool(const unibi_term *ut, enum unibi_boolean b);
void unibi_set_bool(unibi_term *ut, enum unibi_boolean b, int x);

int unibi_get_num(const unibi_term *ut, enum unibi_numeric n);
void unibi_set_num(unibi_term *ut, enum unibi_numeric n, int x);

const char *unibi_get_str(const unibi_term *ut, enum unibi_string s);
void unibi_set_str(unibi_term *ut, enum unibi_string s, const char *x);

DESCRIPCIÓN

Obtener/establecer capacidades booleanas, numéricas y de cadena. Las capacidades numéricas ausentes se representan como -1, las capacidades de cadena ausentes como "NULL".

Tenga en cuenta que "unibi_set_str" simplemente almacena el puntero que se le da; no liberará x ni hará una copia de la cadena.
