NOMBRE

uhd_image_loader - Cargador de imágenes UHD

DESCRIPCIÓN

Graba imágenes de firmware y FPGA en dispositivos Ettus Research conectados.

SINOPSIS

uhd_image_loader [OPCIONES]

OPCIONES

Opciones de listado:
--help
Argumentos del dispositivo y cargador:
--args=""
Ruta del archivo de firmware personalizado:
--fw-path=""
Ruta del archivo FPGA personalizado:
--fpga-path=""
No grabar firmware:
--no-fw
No grabar FPGA:
--no-fpga

ESPECIFICACIÓN DE UN DISPOSITIVO PARTICULAR

Sin argumentos proporcionados a través de la opción args="", esta utilidad iniciará una sesión con el primer dispositivo Ettus Research que encuentre. Los argumentos que se muestran a continuación limitarán la búsqueda de la utilidad para un dispositivo particular:

Todos los dispositivos

Los argumentos name= y serial= se pueden usar para especificar cualquier dispositivo excepto un dispositivo USB no inicializado o un bootloader OctoClock. El argumento type= se puede usar para especificar cualquier dispositivo, como se describe a continuación:

Argumento | Dispositivo

type=usrp2 | USRP N200, USRP N210

type=b200 | USRP B200, USRP B210

type=e3x0 | USRP E310

type=octoclock | OctoClock

NOTA: USRP1, USRP2 y USRP B100 no son compatibles.

Dispositivos de red

Por defecto, esta utilidad comprobará todas las interfaces de red para dispositivos basados en red, pero se puede especificar una dirección IP específica con el argumento addr=.

Dispositivos NI-RIO

Los dispositivos X-Series conectados a través de PCIe se pueden especificar por su recurso NI-RIO a través del argumento resource=, y el puerto RPC a través del cual comunicarse con él se puede especificar con el argumento rpc-port=. No se recomienda el uso de estas opciones, ya que sus valores predeterminados casi siempre se utilizan.

Dispositivos OctoClock

El nombre y número de serie de un OctoClock solo se exponen cuando se carga el firmware, por lo que si el dispositivo solo tiene un bootloader, solo se puede usar el argumento addr= para encontrarlo.

OPCIONES DEL CARGADOR ESPECÍFICAS DEL DISPOSITIVO

Ciertos dispositivos tienen opciones específicas para personalizar su proceso de carga de imágenes, y estas se pueden pasar a través de la opción --args="". Estos argumentos se especifican a continuación:

USRP N200, USRP N210

La opción overwrite-safe sobrescribirá el firmware y las imágenes FPGA del modo seguro del dispositivo. Esto NO SE RECOMIENDA, ya que estas imágenes sirven como copia de seguridad si las imágenes primarias del dispositivo están corruptas.

La opción reset reiniciará automáticamente el dispositivo una vez que finalice el proceso de carga. Cuando el dispositivo se reinicie, tendrá sus nuevas imágenes cargadas.

USRP X300, USRP X310 (Solo Ethernet)

La opción configure reiniciará automáticamente el dispositivo una vez que finalice el proceso de carga. Cuando el dispositivo se reinicie, tendrá su nueva imagen FPGA cargada.

La opción verify indicará al dispositivo que verifique internamente la integridad de la imagen mientras se carga. Esto aumenta enormemente el tiempo de carga.

EJEMPLOS

Cargar solo la imagen FPGA predeterminada en un dispositivo N2x0 específico y reiniciar

uhd_image_loader --args="type=usrp2,addr=192.168.10.2,reset" --no-fw

Cargar una imagen FPGA personalizada en un dispositivo X3x0 específico

uhd_image_loader --args="type=x300,addr=192.168.40.2" --fpga-path="/home/usuario/mi_imagen_fpga_x300.bit"
