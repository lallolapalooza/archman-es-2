unibi_set_ext_str(3)

Paquete: unibilium

Licencias: LGPL3

doc::unibi_set_ext_str(3) unibilium doc::unibi_set_ext_str(3)

NOMBRE

unibi_get_ext_bool, unibi_set_ext_bool, unibi_get_ext_num, unibi_set_ext_num, unibi_get_ext_str, unibi_set_ext_str - acceder a las capacidades extendidas de un objeto terminal

SINOPSIS

#include <unibilium.h>
int unibi_get_ext_bool(const unibi_term *ut, size_t i);
int unibi_get_ext_num(const unibi_term *ut, size_t i);
const char *unibi_get_ext_str(const unibi_term *ut, size_t i);

void unibi_set_ext_bool(unibi_term *ut, size_t i, int b);
void unibi_set_ext_num(unibi_term *ut, size_t i, int v);
void unibi_set_ext_str(unibi_term *ut, size_t i, const char *s);

DESCRIPCIÓN

Obtener/establecer capacidades booleanas, numéricas y de cadena extendidas. i es el índice de la capacidad extendida sobre la que actuar; debe ser menor que unibi_count_ext_bool(ut), unibi_count_ext_num(ut) o unibi_count_ext_str(ut), respectivamente.

Tenga en cuenta que "unibi_set_ext_str" simplemente almacena el puntero que se le da; no liberará s ni hará una copia de la cadena.
