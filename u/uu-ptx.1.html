uudoc(1) Manual de Comandos Generales uudoc(1)

NOMBRE

uudoc - Produce un índice permutado del contenido de archivos. Genera un índice permutado, incluyendo contexto, de las palabras en los archivos de entrada. Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas. Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar. Por defecto es '-F /'.

SINOPSIS

uudoc [-A|--auto-reference] [-G|--traditional] [-F|--flag-truncation] [-M|--macro-name] [-O ] [-T ] [-R|--right-side-refs] [-S|--sentence-regexp] [-W|--word-regexp] [-b|--break-file] [-f|--ignore-case] [-g|--gap-size] [-i|--ignore-file] [-o|--only-file] [-r|--references] [-w|--width] [-h|--help] [-V|--version] [archivo]

DESCRIPCIÓN

Produce un índice permutado del contenido de archivos. Genera un índice permutado, incluyendo contexto, de las palabras en los archivos de entrada. Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas. Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar. Por defecto es '-F /'.

OPCIONES

-A, --auto-reference
genera referencias automáticamente
-G, --traditional
comportarse más como 'ptx' de System V
-F, --flag-truncation <CADENA>
usa CADENA para marcar las truncaciones de línea
-M, --macro-name <CADENA>
nombre de macro a usar en lugar de 'xx'
-O
genera la salida como directivas roff
-T
genera la salida como directivas TeX
-R, --right-side-refs
coloca las referencias a la derecha, no contadas en -w
-S, --sentence-regexp <EXPRESION_REGULAR>
para el final de las líneas o el final de las frases
-W, --word-regexp <EXPRESION_REGULAR>
usa EXPRESION_REGULAR para hacer coincidir cada palabra clave
-b, --break-file <ARCHIVO>
caracteres de separación de palabras en este ARCHIVO
-f, --ignore-case
convierte minúsculas a mayúsculas para ordenar
-g, --gap-size <NÚMERO>
tamaño de la brecha en columnas entre los campos de salida
-i, --ignore-file <ARCHIVO>
lee la lista de palabras a ignorar de este ARCHIVO
-o, --only-file <ARCHIVO>
lee solo la lista de palabras de este ARCHIVO
-r, --references
el primer campo de cada línea es una referencia
-w, --width <NÚMERO>
ancho de salida en columnas, referencia excluida
-h, --help
Imprime la ayuda
-V, --version
Imprime la versión
