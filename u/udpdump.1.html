NOMBRE

udpdump - Proporciona un receptor UDP que recibe paquetes de dispositivos de red (como routers Aruba) y los exporta en formato PCAP.

SINOPSIS

udpdump [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interfaz> ] [ --extcap-config ] [ --capture ] [ --fifo=<ruta a archivo o pipe> ] [ --port=<puerto> ] [ --payload=<tipo> ]

DESCRIPCIÓN

udpdump es una herramienta extcap que proporciona un receptor UDP que escucha los datagramas exportados provenientes de cualquier fuente (como routers Aruba) y los exporta en formato PCAP. Esto proporciona al usuario dos funcionalidades básicas: la primera es tener un oyente que impide que el localhost envíe de vuelta un paquete ICMP de puerto no alcanzable. La segunda es eliminar las capas inferiores (capa 2, IP, UDP) que son inútiles (se utilizan solo como vector de exportación). El formato de los datagramas exportados es EXPORTED_PDU, como se especifica en https://gitlab.com/wireshark/wireshark/-/raw/master/epan/exported_pdu.h

OPCIONES

--help

Imprime los argumentos del programa.

--version

Imprime la versión del programa.

--extcap-interfaces

Lista las interfaces disponibles.

--extcap-interface=<interfaz>

Usa las interfaces especificadas.

--extcap-dlts

Lista los DLT de la interfaz especificada.

--extcap-config

Lista las opciones de configuración de la interfaz especificada.

--capture

Inicia la captura desde la interfaz especificada y la guarda en el lugar especificado por --fifo.

--fifo=<ruta a archivo o pipe>

Guarda el paquete capturado en un archivo o lo envía a través de un pipe.

--port=<puerto>

Establece el puerto del oyente. El puerto 5555 es el predeterminado.

--payload=<tipo>

Establece la carga útil del PDU exportado. Predeterminado: data.

EJEMPLOS

Para ver los argumentos del programa:

udpdump --help

Para ver la versión del programa:

udpdump --version

Para ver las interfaces:

udpdump --extcap-interfaces

Salida de ejemplo

interface {value=udpdump}{display=UDP Listener remote capture}

Para ver los DLT de la interfaz:

udpdump --extcap-interface=udpdump --extcap-dlts

Salida de ejemplo

dlt {number=252}{name=udpdump}{display=Exported PDUs}

Para ver las opciones de configuración de la interfaz:

udpdump --extcap-interface=udpdump --extcap-config

Salida de ejemplo

arg {number=0}{call=--port}{display=Listen port}{type=unsigned}{range=1,65535}{default=5555}{tooltip=The port the receiver listens on}

Para capturar:

udpdump --extcap-interface=randpkt --fifo=/tmp/randpkt.pcapng --capture

Nota

Para detener la captura, presiona CTRL+C o mata/termina la aplicación.
