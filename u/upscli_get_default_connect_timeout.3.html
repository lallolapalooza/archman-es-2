UPSCLI_GET_DEFAULT_C(3) Manual NUT UPSCLI_GET_DEFAULT_C(3)

NOMBRE

upscli_get_default_connect_timeout - Devuelve el tiempo de espera predeterminado del módulo upsclient para las conexiones iniciales.

SINOPSIS

        #include <upsclient.h>
        int upscli_get_default_connect_timeout(struct timeval *ptv);

DESCRIPCIÓN

La función upscli_get_default_connect_timeout() toma el puntero ptv a una struct timeval y devuelve el tiempo de espera de red predeterminado para las conexiones iniciales asignado por última vez con upscli_set_default_connect_timeout(3).

VER TAMBIÉN

upscli_connect(3), upscli_tryconnect(3), upscli_init_default_connect_timeout(3), upscli_set_default_connect_timeout(3)
