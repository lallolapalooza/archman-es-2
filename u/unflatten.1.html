UNFLATTEN(1) Manual de Comandos Generales UNFLATTEN(1)

NOMBRE

unflatten - ajusta grafos dirigidos para mejorar la relación de aspecto del trazado

SINOPSIS

unflatten [-f?] [-llongitud] [-clongitud ] [ -o archivo_salida ] [ archivos ]

DESCRIPCIÓN

unflatten es un preprocesador para dot que se utiliza para mejorar la relación de aspecto de grafos que tienen muchas hojas o nodos desconectados. El trazado habitual para un grafo de este tipo es muy ancho o muy alto. unflatten crea cadenas con aristas invisibles o ajusta el minlen en las aristas para mejorar la compactación del trazado.

OPCIONES

Se admiten las siguientes opciones:

-l longitud
El minlen de las aristas de las hojas se escalona entre 1 y longitud (un entero pequeño).
-f
Aplica la opción -l a los nodos de abanico (fanout) cuyo grado de entrada y salida son ambos 1. Esto ayuda con estructuras como a -> {w x y z} -> b. Esta opción solo funciona si se establece la opción -l.
-c longitud
Agrupa los nodos desconectados en cadenas de hasta longitud aristas.
-o archivo_salida
hace que la salida se escriba en el archivo especificado; por defecto, la salida se escribe en stdout.
-?
Imprime el uso y sale.

OPERANDOS

Se admite el siguiente operando:

archivos
Nombres de archivos que contienen 1 o más grafos en formato dot. Si no se especifica ningún operando de archivos, se utilizará la entrada estándar.
