UUID_IS_NULL(3) Manual del programador UUID_IS_NULL(3)

NOMBRE

uuid_is_null - compara el valor del UUID con el valor NULL

SINOPSIS

#include <uuid.h>

int uuid_is_null(const uuid_t uu);

DESCRIPCIÓN

La función uuid_is_null() compara el valor de la variable UUID proporcionada uu con el valor NULL. Si el valor es igual al UUID NULL, se devuelve 1, de lo contrario se devuelve 0.
