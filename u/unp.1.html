NOMBRE

unp - un frontend de shell para herramientas de descompresión/desempaquetado

SINOPSIS

unp [-u] archivo [ archivos ... ] [ -- argumentos_backend ... ] ucat archivo [ archivos ... ]

unp es un script pequeño con un solo objetivo: Extraer tantos archivos como sea posible, de cualquier tipo y desde cualquier ruta al directorio actual, preservando la estructura de subdirectorios cuando sea necesario. Es una utilidad Haz-Lo-Que-Quiero y ayuda a gestionar varios programas de extracción sin tener que buscar las opciones necesarias para la herramienta particular o preocuparse por la instalación del programa necesario.

Ejecuta unp sin argumentos para ver la lista de formatos de archivo compatibles.

La versión especial ucat actúa como un envoltorio para comandos que pueden enviar los datos extraídos a la salida estándar, como bzip (bzcat), gzip (zcat), tar, zip y otros.

USO

unp extrae uno o más archivos dados como argumentos en la línea de comandos. Adicionalmente, puede pasar algunas opciones a las herramientas backend (como opciones de tar) cuando se añaden después de `--´.

También hay una opción especial (-u) que es muy útil para extraer paquetes Debian. Usando -u, unp extrae primero el paquete (es decir, el archivo ar), luego extrae data.tar.gz en el directorio actual y luego control.tar.gz en control/<nombre_archivo>/.

NOTAS

unp intentará descomprimir en un archivo FILE.unp si tiene problemas con archivos existentes. Pero no cuentes con esta característica, siempre asegúrate de tener espacio de trabajo libre antes de usar unp.

A diferencia de gunzip, que descomprime el archivo en el directorio de destino del archivo fuente, unp utiliza el directorio actual para la salida.
