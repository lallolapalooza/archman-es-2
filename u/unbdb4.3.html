CUNBDB4

Propósito:

!>
!> CUNBDB4 bidiagonaliza simultáneamente los bloques de una matriz X alta y delgada
!> con columnas ortonormales:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 es P por Q, y X21 es (M-P) por Q. M-Q debe ser no mayor que P,
!> M-P, o Q. Las rutinas CUNBDB1, CUNBDB2 y CUNBDB3 manejan casos en
!> los que M-Q no es la dimensión mínima.
!>
!> Las matrices unitarias P1, P2 y Q1 son P-por-P, (M-P)-por-(M-P),
!> y (M-Q)-por-(M-Q) respectivamente. Se representan implícitamente mediante
!> vectores de Householder.
!>
!> B11 y B12 son matrices bidiagonales de (M-Q)x(M-Q) representadas
!> implícitamente por ángulos THETA, PHI.
!>
!>

Parámetros

M 
!>          M es ENTERO
!>           El número de filas de X11 más el número de filas de X21.
!>

P

!>          P es ENTERO
!>           El número de filas en X11. 0 <= P <= M.
!>

Q

!>          Q es ENTERO
!>           El número de columnas en X11 y X21. 0 <= Q <= M y
!>           M-Q <= min(P,M-P,Q).
!>

X11

!>          X11 es un array COMPLEJO, dimensión (LDX11,Q)
!>           En la entrada, el bloque superior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X11) especifican los
!>           refletores para P1 y las filas de triu(X11,1) especifican los
!>           refletores para Q1.
!>

LDX11

!>          LDX11 es ENTERO
!>           La dimensión principal de X11. LDX11 >= P.
!>

X21

!>          X21 es un array COMPLEJO, dimensión (LDX21,Q)
!>           En la entrada, el bloque inferior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X21) especifican los
!>           refletores para P2.
!>

LDX21

!>          LDX21 es ENTERO
!>           La dimensión principal de X21. LDX21 >= M-P.
!>

THETA

!>          THETA es un array REAL, dimensión (Q)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen por
!>           THETA y PHI. Ver Detalles Adicionales.
!>

PHI

!>          PHI es un array REAL, dimensión (Q-1)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen por
!>           THETA y PHI. Ver Detalles Adicionales.
!>

TAUP1

!>          TAUP1 es un array COMPLEJO, dimensión (M-Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           P1.
!>

TAUP2

!>          TAUP2 es un array COMPLEJO, dimensión (M-Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           P2.
!>

TAUQ1

!>          TAUQ1 es un array COMPLEJO, dimensión (Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           Q1.
!>

PHANTOM

!>          PHANTOM es un array COMPLEJO, dimensión (M)
!>           La rutina calcula un vector columna Y de M por 1 que es
!>           ortogonal a las columnas de [ X11; X21 ]. PHANTOM(1:P) y
!>           PHANTOM(P+1:M) contienen vectores de Householder para Y(1:P) y
!>           Y(P+1:M), respectivamente.
!>

WORK

!>          WORK es un array COMPLEJO, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>           La dimensión del array WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>           solo calcula el tamaño óptimo del array WORK, devuelve
!>           este valor como la primera entrada del array WORK, y no se emite ningún mensaje de error
!>           relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO es ENTERO
!>           = 0:  salida exitosa.
!>           < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles Adicionales:

!>
!>  Los bloques superior-bidiagonales B11, B21 se representan implícitamente por
!>  ángulos THETA(1), ..., THETA(Q) y PHI(1), ..., PHI(Q-1). Cada entrada
!>  en cada banda bidiagonal es un producto de un seno o coseno de un THETA
!>  con un seno o coseno de un PHI. Ver [1] o CUNCSD para detalles.
!>
!>  P1, P2 y Q1 se representan como productos de reflectores elementales.
!>  Ver CUNCSD2BY1 para detalles sobre la generación de P1, P2 y Q1 usando CUNGQR
!>  y CUNGLQ.
!>

Referencias:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.

SYNOPSIS

Detailed Description

ZUNBDB4

Purpose:

!>
!> ZUNBDB4 bidiagonaliza simultáneamente los bloques de una matriz alta y delgada
!> X con columnas ortonormales:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 tiene P filas y Q columnas, y X21 tiene (M-P) filas y Q columnas. M-Q
!> debe ser no mayor que P, M-P, o Q. Las rutinas ZUNBDB1, ZUNBDB2, y
!> ZUNBDB3 manejan casos en los que M-Q no es la dimensión mínima.
!>
!> Las matrices unitarias P1, P2, y Q1 son P-por-P, (M-P)-por-(M-P),
!> y (M-Q)-por-(M-Q), respectivamente. Se representan implícitamente por
!> vectores de Householder.
!>
!> B11 y B21 son matrices bidiagonales (M-Q)-por-(M-Q) representadas
!> implícitamente por los ángulos THETA, PHI.
!>
!>

Parameters

M 
!>          M es INTEGER
!>           El número de filas de X11 más el número de filas en X21.
!>

P

!>          P es INTEGER
!>           El número de filas en X11. 0 <= P <= M.
!>

Q

!>          Q es INTEGER
!>           El número de columnas en X11 y X21. 0 <= Q <= M y
!>           M-Q <= min(P,M-P,Q).
!>

X11

!>          X11 es un array COMPLEX*16, dimensión (LDX11,Q)
!>           En la entrada, el bloque superior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X11) especifican los
!>           refletores para P1 y las filas de triu(X11,1) especifican los
!>           refletores para Q1.
!>

LDX11

!>          LDX11 es INTEGER
!>           La dimensión principal de X11. LDX11 >= P.
!>

X21

!>          X21 es un array COMPLEX*16, dimensión (LDX21,Q)
!>           En la entrada, el bloque inferior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X21) especifican los
!>           refletores para P2.
!>

LDX21

!>          LDX21 es INTEGER
!>           La dimensión principal de X21. LDX21 >= M-P.
!>

THETA

!>          THETA es un array DOUBLE PRECISION, dimensión (Q)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen por
!>           THETA y PHI. Ver Detalles Adicionales.
!>

PHI

!>          PHI es un array DOUBLE PRECISION, dimensión (Q-1)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen por
!>           THETA y PHI. Ver Detalles Adicionales.
!>

TAUP1

!>          TAUP1 es un array COMPLEX*16, dimensión (M-Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           P1.
!>

TAUP2

!>          TAUP2 es un array COMPLEX*16, dimensión (M-Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           P2.
!>

TAUQ1

!>          TAUQ1 es un array COMPLEX*16, dimensión (Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           Q1.
!>

PHANTOM

!>          PHANTOM es un array COMPLEX*16, dimensión (M)
!>           La rutina calcula un vector columna Y de tamaño M-por-1 que es
!>           ortogonal a las columnas de [ X11; X21 ]. PHANTOM(1:P) y
!>           PHANTOM(P+1:M) contienen vectores de Householder para Y(1:P) y
!>           Y(P+1:M), respectivamente.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>           La dimensión del array WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, entonces se asume una consulta de espacio de
!>           trabajo; la rutina solo calcula el tamaño óptimo del array
!>           WORK, devuelve este valor como la primera entrada del array
!>           WORK, y XERBLA no emite ningún mensaje de error relacionado
!>           con LWORK.
!>

INFO

!>          INFO es INTEGER
!>           = 0:  salida exitosa.
!>           < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Further Details:

!>
!>  Los bloques super-bidiagonales B11, B21 se representan implícitamente por
!>  los ángulos THETA(1), ..., THETA(Q) y PHI(1), ..., PHI(Q-1). Cada entrada
!>  en cada banda bidiagonal es un producto de un seno o coseno de un THETA
!>  con un seno o coseno de un PHI. Ver [1] o ZUNCSD para más detalles.
!>
!>  P1, P2, y Q1 se representan como productos de reflectores elementales.
!>  Ver ZUNCSD2BY1 para detalles sobre la generación de P1, P2, y Q1 usando
!>  ZUNGQR y ZUNGLQ.
!>
