UEBERZUGPP(1) Manual de comandos generales UEBERZUGPP(1)

NOMBRE

ueberzugpp - muestra imágenes en una terminal

SINOPSIS

ueberzugpp [opciones]

DESCRIPCIÓN

ueberzugpp es un programa destinado a mostrar imágenes en una terminal mediante IPC.

OPCIONES

-h, --help
Muestra el texto de ayuda.
--version
Muestra la versión
--use-escape-codes
Utiliza códigos de escape para obtener las capacidades de la terminal
--no-stdin
No escucha en stdin para comandos
--no-cache
Deshabilita el caché de imágenes redimensionadas
--no-opencv
No utiliza OpenCV, utiliza Libvips en su lugar
-o, --output
Método de salida de imagen, los valores válidos para esto incluyen:
x11 (Puede no estar disponible si se deshabilita en la compilación)
sixel
kitty
iterm2
wayland (Puede no estar disponible si se deshabilita en la compilación)
chafa
-p, --parser
SIN USO, solo presente por compatibilidad hacia atrás
-l, --loader
SIN USO, solo presente por compatibilidad hacia atrás

STDIN

Ueberzugpp lee comandos a través de stdin. O a través del socket unix ubicado en /tmp/ueberzug_.sock

Los comandos deben estar en formato JSON, como se describe en la sección JSON IPC

IPC JSON

Hay dos acciones, add (añadir) y remove (eliminar)

añadir

Esquema JSON de acción

Claves requeridas


action (string)
debe ser add
path (string)
la ruta a la imagen a usar
identifier (string)
un identificador para la imagen, para que pueda ser eliminada con la acción remove
Una de, width/height, o max_width/max_height
width (integer)
ancho de la imagen
max_width (integer)
ancho máximo de la imagen
height (integer)
alto de la imagen
max_height (integer)
alto máximo de la imagen
x (integer)
la posición de la columna en la terminal
y (integer)
la posición de la fila en la terminal

Claves opcionales

scaler (string)
puede ser fit_contain o forced_cover.
Ambos basan la escala en lo que sea mayor, el ancho o el alto de la imagen

eliminar

Esquema JSON de acción

Claves requeridas

action (string)
debe ser remove
identifier (string)
El identificador de la imagen a eliminar

EJEMPLO

Crea un archivo fifo llamado fifo, y ten una imagen en la carpeta actual llamada image.png para que este ejemplo funcione

ueberzugpp layer -o sixel < fifo &

echo '{"path": "./image.png", "action": "add", "identifier": "image", "x": 0, "y": 0, "width": 20, "height": 20}' > fifo
