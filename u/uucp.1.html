uucp(1) Manual de Comandos Generales uucp(1)

NOMBRE

uucp - copia Unix a Unix

SINOPSIS

uucp [ opciones ] archivo-fuente archivo-destino

uucp [ opciones ] archivo-fuente... directorio-destino

DESCRIPCIÓN

El comando uucp copia archivos entre sistemas. Cada argumento archivo es un nombre de ruta en la máquina local o tiene la forma

sistema!ruta

que se interpreta como perteneciente a un sistema remoto. En la primera forma, el contenido del primer archivo se copia al segundo. En la segunda forma, cada archivo de origen se copia al directorio de destino.

Un archivo puede transferirse hacia o desde sistema2 a través de sistema1 usando

sistema1!sistema2!ruta.

Cualquier nombre de ruta que no comience con / o ~ se antepondrá al directorio actual (a menos que se utilice la opción -W o --noexpand); esta ruta resultante no existirá necesariamente en un sistema remoto. Un nombre de ruta que comience con un simple ~ comienza en el directorio público de UUCP; un nombre de ruta que comience con ~nombre comienza en el directorio de inicio del usuario con nombre. El ~ se interpreta en el sistema apropiado. Tenga en cuenta que algunas shells interpretarán un simple ~ al directorio de inicio local antes de que uucp lo vea; para evitar esto, el ~ debe estar entre comillas.

Los metacaracteres de shell ? * [ ] se interpretan en el sistema apropiado, asumiendo que están entre comillas para evitar que la shell los interprete primero.

La copia no se realiza inmediatamente, sino que se pone en cola para el demonio uucico (8); el demonio se inicia inmediatamente a menos que se proporcione el modificador -r o --nouucico. En cualquier caso, la próxima vez que se llame al sistema remoto, los archivos se copiarán.

OPCIONES

Las siguientes opciones pueden ser proporcionadas a uucp.

-c, --nocopy
No copie los archivos de origen locales al directorio de cola. Si se eliminan antes de ser procesados por el demonio uucico (8), la copia fallará. Los archivos deben ser legibles por el demonio uucico (8) y por el usuario que invoca.
-C, --copy
Copie los archivos de origen locales al directorio de cola. Este es el valor predeterminado.
-d, --directories
Cree todos los directorios necesarios al realizar la copia. Este es el valor predeterminado.
-f, --nodirectories
Si algún directorio necesario no existe para la ruta de destino, aborte la copia.
-R, --recursive
Si alguno de los nombres de archivo de origen son directorios, copie su contenido recursivamente al destino (que debe ser un directorio).
-g grade, --grade grade
Establezca el grado del comando de transferencia de archivos. Los trabajos de mayor grado se ejecutan primero. Los grados van de 0...9 A...Z a...z de mayor a menor.
-m, --mail
Reporte la finalización o el fallo de la transferencia de archivos por mail (1).
-n user, --notify user
Reporte la finalización o el fallo de la transferencia de archivos por mail (1) al usuario con nombre en el sistema remoto.
-r, --nouucico
No inicie el demonio uucico (8) inmediatamente; simplemente ponga en cola la transferencia de archivos para su posterior ejecución.
-j, --jobid
Imprima el id del trabajo en la salida estándar. El trabajo puede ser cancelado posteriormente pasando el id del trabajo al modificador -k de uustat (1). Es posible que algunas operaciones complejas produzcan más de un id de trabajo, en cuyo caso cada uno se imprimirá en una línea separada. Por ejemplo 

uucp sys1!~user1/file1 sys2!~user2/file2 ~user3

generará dos trabajos separados, uno para el sistema sys1 y otro para el sistema sys2.
-W, --noexpand
No anteponga a los nombres de ruta relativos remotos el directorio actual.
-t, --uuto
Esta opción es utilizada por el script de shell uuto. Hace que uucp interprete el argumento final como sistema!usuario. Los archivos se envían a ~/receive/USUARIO/LOCAL en el sistema remoto, donde USUARIO proviene del argumento final y LOCAL es el nombre del sistema UUCP local. Además, uucp actuará como si se hubiera especificado --notify usuario.
-x type, --debug type
Active tipos de depuración específicos. Los siguientes tipos son reconocidos: abnormal, chat, handshake, uucp-proto, proto, port, config, spooldir, execute, incoming, outgoing. Solo abnormal, config, spooldir y execute son significativos para uucp.

Se pueden proporcionar varios tipos, separados por comas, y la opción --debug puede aparecer varias veces. También se puede proporcionar un número, que activará esa cantidad de tipos de la lista anterior; por ejemplo, --debug 2 es equivalente a --debug abnormal,chat.

-I file, --config file
Establezca el archivo de configuración a utilizar. Es posible que esta opción no esté disponible, dependiendo de cómo se compiló uucp.
-v, --version
Muestre información de la versión y salga.
--help
Imprima un mensaje de ayuda y salga.

VER TAMBIÉN

mail(1), uux(1), uustat(1), uucico(8)

ERRORES

Algunas de las opciones dependen de las capacidades del demonio uucico (8) en el sistema remoto.

Los modificadores -n y -m no funcionan al transferir un archivo de un sistema remoto a otro.

Los modos de archivo no se conservan, excepto el bit de ejecución. El archivo resultante pertenece al usuario uucp.
