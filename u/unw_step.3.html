NOMBRE

unw_step -- avanzar al siguiente marco de pila

SINOPSIS

#include <libunwind.h>

int unw_step(unw_cursor_t *cp);

DESCRIPCIÓN

La rutina unw_step() avanza el cursor de desenrollado cp al siguiente marco de pila anterior, menos anidado.

VALOR DE RETORNO

Al completarse con éxito, unw_step() devuelve un valor positivo si el cursor actualizado se refiere a un marco de pila válido, o 0 si el marco de pila anterior era el último marco de la cadena. En caso de error, se devuelve el valor negativo de uno de los códigos de error a continuación.

SEGURIDAD DE HILOS Y SEÑALES

unw_step() es seguro para hilos. Si el cursor cp está en el espacio de direcciones local, esta rutina también es segura para su uso desde un manejador de señales.

ERRORES

UNW_EUNSPEC

Ocurrió un error no especificado.
UNW_ENOINFO

Libunwind no pudo localizar la información de desenrollado necesaria para completar la operación.
UNW_EBADVERSION

La información de desenrollado necesaria para completar la operación tiene una versión o formato que libunwind no entiende.
UNW_EINVALIDIP

El puntero de instrucción ("contador de programa") del siguiente marco de pila no es válido (por ejemplo, no está alineado correctamente).
UNW_EBADFRAME

El siguiente marco de pila no es válido.
UNW_ESTOPUNWIND

Devuelto si una llamada a find_proc_info() devolvió -UNW_ESTOPUNWIND.

Además, unw_step() puede devolver cualquier error devuelto por las llamadas de retorno find_proc_info(), get_dyn_info_list_addr(), access_mem(), access_reg() o access_fpreg() (ver unw_create_addr_space(3libunwind)).

VER TAMBIÉN

libunwind(3libunwind), unw_create_addr_space(3libunwind)
