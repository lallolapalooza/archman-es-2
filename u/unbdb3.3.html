CUNBDB3

Propósito:

!>
!> CUNBDB3 bidiagonaliza simultáneamente los bloques de una matriz delgada y alta X con columnas ortonormales:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 es P por Q, y X21 es (M-P) por Q. M-P debe ser no mayor que P,
!!> Q, o M-Q. Las rutinas CUNBDB1, CUNBDB2 y CUNBDB4 manejan casos en
!> los que M-P no es la dimensión mínima.
!>
!> Las matrices unitarias P1, P2 y Q1 son P-por-P, (M-P)-por-(M-P),
!> y (M-Q)-por-(M-Q), respectivamente. Se representan implícitamente por
!> vectores de Householder.
!>
!> B11 y B12 son matrices bidiagonales (M-P)-por-(M-P) representadas
!> implícitamente por los ángulos THETA, PHI.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>           El número de filas de X11 más el número de filas en X21.
!>

P

!>          P es INTEGER
!>           El número de filas en X11. 0 <= P <= M. M-P <= min(P,Q,M-Q).
!>

Q

!>          Q es INTEGER
!>           El número de columnas en X11 y X21. 0 <= Q <= M.
!>

X11

!>          X11 es un array COMPLEX, de dimensión (LDX11,Q)
!>           En la entrada, el bloque superior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X11) especifican los
!>           reflectores para P1 y las filas de triu(X11,1) especifican los
!>           reflectores para Q1.
!>

LDX11

!>          LDX11 es INTEGER
!>           La dimensión principal de X11. LDX11 >= P.
!>

X21

!>          X21 es un array COMPLEX, de dimensión (LDX21,Q)
!>           En la entrada, el bloque inferior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X21) especifican los
!>           reflectores para P2.
!>

LDX21

!>          LDX21 es INTEGER
!>           La dimensión principal de X21. LDX21 >= M-P.
!>

THETA

!>          THETA es un array REAL, de dimensión (Q)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen
!>           por THETA y PHI. Ver Detalles Adicionales.
!>

PHI

!>          PHI es un array REAL, de dimensión (Q-1)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen
!>           por THETA y PHI. Ver Detalles Adicionales.
!>

TAUP1

!>          TAUP1 es un array COMPLEX, de dimensión (P)
!>           Los factores escalares de los reflectores elementales que definen
!>           P1.
!>

TAUP2

!>          TAUP2 es un array COMPLEX, de dimensión (M-P)
!>           Los factores escalares de los reflectores elementales que definen
!>           P2.
!>

TAUQ1

!>          TAUQ1 es un array COMPLEX, de dimensión (Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           Q1.
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>           La dimensión del array WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, entonces se asume una consulta de espacio de
!>           trabajo; la rutina solo calcula el tamaño óptimo del array WORK,
!>           devuelve este valor como la primera entrada del array WORK, y no se
!>           emite ningún mensaje de error relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>           = 0: Salida exitosa.
!>           < 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Autor

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Detalles Adicionales:

!>
!> Los bloques superior-bidiagonales B11, B21 se representan implícitamente
!> por los ángulos THETA(1), ..., THETA(Q) y PHI(1), ..., PHI(Q-1). Cada
!> entrada en cada banda bidiagonal es un producto de un seno o coseno de
!> un THETA con un seno o coseno de un PHI. Ver [1] o CUNCSD para más
!> detalles.
!>
!> P1, P2 y Q1 se representan como productos de reflectores elementales.
!> Ver CUNCSD2BY1 para detalles sobre cómo generar P1, P2 y Q1 usando CUNGQR
!> y CUNGLQ.
!>

Referencias:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.

DORBDB3

Purpose:

!>
!> DORBDB3 simultaneously bidiagonalizes the blocks of a tall and skinny
!> matrix X with orthonormal columns:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 is P-by-Q, and X21 is (M-P)-by-Q. M-P must be no larger than P,
!> Q, or M-Q. Routines DORBDB1, DORBDB2, and DORBDB4 handle cases in
!> which M-P is not the minimum dimension.
!>
!> The orthogonal matrices P1, P2, and Q1 are P-by-P, (M-P)-by-(M-P),
!> and (M-Q)-by-(M-Q), respectively. They are represented implicitly by
!> Householder vectors.
!>
!> B11 and B12 are (M-P)-by-(M-P) bidiagonal matrices represented
!> implicitly by angles THETA, PHI.
!>
!>

Parameters

M 
!>          M is INTEGER
!>           The number of rows X11 plus the number of rows in X21.
!>

P

!>          P is INTEGER
!>           The number of rows in X11. 0 <= P <= M. M-P <= min(P,Q,M-Q).
!>

Q

!>          Q is INTEGER
!>           The number of columns in X11 and X21. 0 <= Q <= M.
!>

X11

!>          X11 is DOUBLE PRECISION array, dimension (LDX11,Q)
!>           On entry, the top block of the matrix X to be reduced. On
!>           exit, the columns of tril(X11) specify reflectors for P1 and
!>           the rows of triu(X11,1) specify reflectors for Q1.
!>

LDX11

!>          LDX11 is INTEGER
!>           The leading dimension of X11. LDX11 >= P.
!>

X21

!>          X21 is DOUBLE PRECISION array, dimension (LDX21,Q)
!>           On entry, the bottom block of the matrix X to be reduced. On
!>           exit, the columns of tril(X21) specify reflectors for P2.
!>

LDX21

!>          LDX21 is INTEGER
!>           The leading dimension of X21. LDX21 >= M-P.
!>

THETA

!>          THETA is DOUBLE PRECISION array, dimension (Q)
!>           The entries of the bidiagonal blocks B11, B21 are defined by
!>           THETA and PHI. See Further Details.
!>

PHI

!>          PHI is DOUBLE PRECISION array, dimension (Q-1)
!>           The entries of the bidiagonal blocks B11, B21 are defined by
!>           THETA and PHI. See Further Details.
!>

TAUP1

!>          TAUP1 is DOUBLE PRECISION array, dimension (P)
!>           The scalar factors of the elementary reflectors that define
!>           P1.
!>

TAUP2

!>          TAUP2 is DOUBLE PRECISION array, dimension (M-P)
!>           The scalar factors of the elementary reflectors that define
!>           P2.
!>

TAUQ1

!>          TAUQ1 is DOUBLE PRECISION array, dimension (Q)
!>           The scalar factors of the elementary reflectors that define
!>           Q1.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>           The dimension of the array WORK. LWORK >= M-Q.
!>
!>           If LWORK = -1, then a workspace query is assumed; the routine
!>           only calculates the optimal size of the WORK array, returns
!>           this value as the first entry of the WORK array, and no error
!>           message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>           = 0:  successful exit.
!>           < 0:  if INFO = -i, the i-th argument had an illegal value.
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Further Details:

!>
!>  The upper-bidiagonal blocks B11, B21 are represented implicitly by
!>  angles THETA(1), ..., THETA(Q) and PHI(1), ..., PHI(Q-1). Every entry
!>  in each bidiagonal band is a product of a sine or cosine of a THETA
!>  with a sine or cosine of a PHI. See [1] or DORCSD for details.
!>
!>  P1, P2, and Q1 are represented as products of elementary reflectors.
!>  See DORCSD2BY1 for details on generating P1, P2, and Q1 using DORGQR
!>  and DORGLQ.
!>

References:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.

NAME

zunbdb3

computes the bidiagonal reduction of a complex upper triangular-to-bidiagonal matrix

SYNOPSIS

SUBROUTINE ZUNBDB3( M, P, Q, X11, LDX11, X21, LDX21, THETA, PHI, TAUP1,
                    TAUP2, TAUQ1, WORK, LWORK, INFO )

Parameters:

  CHARACTER * ( * ) X11, X21, WORK
  INTEGER M, P, Q, LDX11, LDX21, LWORK, INFO
  DOUBLE PRECISION THETA( * ), PHI( * )
  COMPLEX*16 TAUP1( * ), TAUP2( * ), TAUQ1( * )

Detailed Description

This routine is part of the TRiCSD (Triangular Complete reorthogonalized Singular Decomposition) driver routines. It is used to reduce a structured matrix X, where X is partitioned as:

!>      [ X11   0    ]
!> X =  [-----------]
!>      [ X21   X22  ]
!>

to a bidiagonal matrix B, where

!>      [ B11   0    ]
!> B =  [-----------]
!>      [ B21   B22  ]
!>

Here X11 is P-by-Q, X21 is (M-P)-by-Q, and X22 is (M-P)-by-(M-Q). B11 is P-by-P, B21 is (M-P)-by-P, B22 is (M-P)-by-(M-Q). Routines ZUNBDB1, ZUNBDB2, and ZUNBDB4 handle cases in which M-P is not the minimum dimension.

The unitary matrices P1, P2, and Q1 are P-by-P, (M-P)-by-(M-P), and (M-Q)-by-(M-Q), respectively. They are represented implicitly by Householder vectors.

B11 and B12 are (M-P)-by-(M-P) bidiagonal matrices represented implicitly by angles THETA, PHI.

Parameters

M 
!>          M is INTEGER
!>           The number of rows X11 plus the number of rows in X21.
!>

P

!>          P is INTEGER
!>           The number of rows in X11. 0 <= P <= M. M-P <= min(P,Q,M-Q).
!>

Q

!>          Q is INTEGER
!>           The number of columns in X11 and X21. 0 <= Q <= M.
!>

X11

!>          X11 is COMPLEX*16 array, dimension (LDX11,Q)
!>           On entry, the top block of the matrix X to be reduced. On
!>           exit, the columns of tril(X11) specify reflectors for P1 and
!>           the rows of triu(X11,1) specify reflectors for Q1.
!>

LDX11

!>          LDX11 is INTEGER
!>           The leading dimension of X11. LDX11 >= P.
!>

X21

Further Details:

!>
!>  The upper-bidiagonal blocks B11, B21 are represented implicitly by
!>  angles THETA(1), ..., THETA(Q) and PHI(1), ..., PHI(Q-1). Every entry
