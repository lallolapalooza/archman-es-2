uu-ln(1) Manual de Comandos Generales uu-ln(1)

NOMBRE

uu-ln - Crear enlaces entre archivos.

SINOPSIS

uu-ln [--backup] [-b ] [-f|--force] [-i|--interactive] [-n|--no-dereference] [-L|--logical] [-P|--physical] [-s|--symbolic] [-S|--suffix] [-t|--target-directory] [-T|--no-target-directory] [-r|--relative] [-v|--verbose] [-h|--help] [-V|--version] <archivos>

DESCRIPCIÓN

Crear enlaces entre archivos.

OPCIONES

--backup[=<CONTROL>]
crear una copia de seguridad de cada archivo de destino existente
-b
igual que --backup pero no acepta argumento
-f, --force
eliminar los archivos de destino existentes
-i, --interactive
preguntar si eliminar los archivos de destino existentes
-n, --no-dereference
tratar LINK_NAME como un archivo normal si es un enlace simbólico a un directorio
-L, --logical
seguir los TARGET que son enlaces simbólicos
-P, --physical
crear enlaces duros directamente a enlaces simbólicos
-s, --symbolic
crear enlaces simbólicos en lugar de enlaces duros
-S, --suffix <SUFIJO>
sobrescribir el sufijo de copia de seguridad habitual
-t, --target-directory <DIRECTORIO>
especificar el DIRECTORIO en el que crear los enlaces
-T, --no-target-directory
tratar LINK_NAME como un archivo normal siempre
-r, --relative
crear enlaces simbólicos relativos a la ubicación del enlace
-v, --verbose
imprimir el nombre de cada archivo enlazado
-h, --help
Imprimir ayuda
-V, --version
Imprimir versión
<archivos>

EXTRA

En la 1ª forma, crear un enlace a TARGET con el nombre LINK_NAME. En la 2ª forma, crear un enlace a TARGET en el directorio actual. En las 3ª y 4ª formas, crear enlaces a cada TARGET en DIRECTORIO. Crear enlaces duros por defecto, enlaces simbólicos con --symbolic. Por defecto, cada destino (nombre del nuevo enlace) no debe existir previamente. Al crear enlaces duros, cada TARGET debe existir. Los enlaces simbólicos pueden contener texto arbitrario; si se resuelven más tarde, un enlace relativo se interpreta en relación con su directorio padre.

El sufijo de copia de seguridad es '~', a menos que se establezca con --suffix o SIMPLE_BACKUP_SUFFIX. El método de control de versiones puede seleccionarse a través de la opción --backup o de la variable de entorno VERSION_CONTROL. Aquí están los valores:


none, off nunca crear copias de seguridad (incluso si se proporciona --backup)
numbered, t crear copias de seguridad numeradas
existing, nil numeradas si existen copias de seguridad numeradas, simples si no
simple, never siempre crear copias de seguridad simples
