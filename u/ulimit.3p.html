ULIMIT(3P) Manual del programador POSIX ULIMIT(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

ulimit — obtener y establecer límites de procesos

SINOPSIS

#include <ulimit.h>
long ulimit(int cmd, ...);

DESCRIPCIÓN

La función ulimit() controlará los límites de procesos. Los límites de procesos que se pueden controlar con esta función incluyen el tamaño máximo de un archivo que se puede escribir (esto es equivalente a usar setrlimit() con RLIMIT_FSIZE). Los valores de cmd, definidos en <ulimit.h>, incluyen:

UL_GETFSIZE
Devuelve el límite de tamaño de archivo (RLIMIT_FSIZE) del proceso. El límite estará en unidades de bloques de 512 bytes y será heredado por los procesos hijos. Se pueden leer archivos de cualquier tamaño. El valor de retorno será la parte entera del límite de tamaño de archivo suave dividido por 512. Si el resultado no se puede representar como un long, el resultado no está especificado.
UL_SETFSIZE
Establece el límite de tamaño de archivo para las operaciones de salida del proceso al valor del segundo argumento, tomado como un long, multiplicado por 512. Si el resultado desbordara un rlim_t, el valor real establecido no está especificado. Cualquier proceso puede disminuir su propio límite, pero solo un proceso con privilegios apropiados puede aumentar el límite. El valor de retorno será la parte entera del nuevo límite de tamaño de archivo dividido por 512.

La función ulimit() no cambiará la configuración de errno si tiene éxito.

Dado que todos los valores de retorno son permisibles en una situación exitosa, una aplicación que desee verificar situaciones de error debe establecer errno en 0, luego llamar a ulimit() y, si devuelve -1, verificar si errno es distinto de cero.

VALOR DE RETORNO

Al completarse con éxito, ulimit() devolverá el valor del límite solicitado. De lo contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función ulimit() fallará y el límite no se modificará si:

EINVAL
El argumento cmd no es válido.
EPERM
Un proceso que no tiene los privilegios apropiados intenta aumentar su límite de tamaño de archivo.

USO DE LA APLICACIÓN

Dado que la función ulimit() utiliza el tipo long en lugar de rlim_t, esta función no es suficiente para tamaños de archivo en muchos sistemas actuales. Las aplicaciones deben utilizar las funciones getrlimit() o setrlimit() en lugar de la función ulimit() obsoleta.

Ninguno.

DIRECCIONES FUTURAS

La función ulimit() puede eliminarse en una versión futura.
