UDISKIE(8) udiskie UDISKIE(8)

NOMBRE

udiskie - montador automático para medios extraíbles

SINOPSIS

udiskie [OPCIONES]

udiskie-mount [OPCIONES] (-a | DISPOSITIVO...)

udiskie-umount [OPCIONES] (ruta...)

DESCRIPCIÓN

udiskie es un front-end de udisks2 escrito en python. Su propósito principal es el montaje automático de medios extraíbles, como CDs o unidades flash. Tiene notificaciones opcionales de montaje, un icono de bandeja GTK y CLIs a nivel de usuario para operaciones de montaje y desmontaje manuales. Los medios se montarán en un nuevo directorio bajo /media o /run/media/USUARIO/, utilizando el nombre del dispositivo si es posible.

OPCIONES COMUNES

-h, --help

Muestra el mensaje de ayuda y sale.

-V, --version

Muestra el mensaje de ayuda y sale.

-v, --verbose

Salida detallada.

-q, --quiet

Salida silenciosa.

-c ARCHIVO, --config=ARCHIVO

Especifica el archivo de configuración.

-C, --no-config

No utiliza ningún archivo de configuración.

OPCIONES COMPARTIDAS DE MONTAJE Y DEMONIO

-p COMANDO, --password-prompt=COMANDO

Comando de recuperación de contraseña. La cadena se formatea con los atributos del dispositivo como argumentos de palabra clave, por ejemplo: 
-p "zenity --entry --hide-text --text 'Introduce la contraseña para {device_presentation}:'"

-P, --no-password-prompt

Deshabilita el desbloqueo de dispositivos LUKS.

OPCIONES DEL DEMONIO

-a, --automount

Habilita el montaje automático de nuevos dispositivos (por defecto).

-A, --no-automount

Deshabilita el montaje automático de nuevos dispositivos.

-n, --notify

Habilita las notificaciones emergentes (por defecto).

-N, --no-notify

Deshabilita las notificaciones emergentes.

-t, --tray

Muestra el icono de la bandeja.

-s, --smart-tray

Muestra un icono de bandeja que se oculta automáticamente cuando no hay ninguna acción disponible.

-T, --no-tray

Deshabilita el icono de la bandeja (por defecto).

-f PROGRAMA, --file-manager=PROGRAMA

Establece el programa para abrir directorios montados. El valor predeterminado es 'xdg-open'. Pasa una cadena vacía para deshabilitar esta función.

-F, --no-file-manager

Deshabilita el explorador de archivos.

--terminal=PROGRAMA

Establece la línea de comandos del terminal para abrir directorios montados. ¡Por defecto es ninguno! Pasa una cadena vacía para deshabilitar esta función.

--no-terminal

Deshabilita la acción del terminal.

--appindicator

Utiliza AppIndicator3 para el icono de estado. Úsalo en Ubuntu/Unity si no se muestra ningún icono.

--no-appindicator

Utiliza Gtk.StatusIcon para el icono de estado (por defecto).

--password-cache MINUTOS

Almacena en caché las contraseñas de las particiones LUKS y establece el tiempo de espera.

--no-password-cache

Nunca almacena contraseñas en caché (por defecto).

--event-hook COMANDO

Comando a ejecutar en eventos de dispositivo. La cadena de comando se puede formatear utilizando el nombre del evento y la lista de atributos del dispositivo (ver abajo), por ejemplo: 
--event-hook "zenity --info --text '{event}: {device_presentation}'"

--no-event-hook

Sin comando de notificación (por defecto).

OPCIONES DE MONTAJE

-a, --all

Monta todos los dispositivos manejados.

-r, --recursive

Monta recursivamente particiones de texto plano después de desbloquear un dispositivo LUKS. Esto ocurrirá por defecto al ejecutar el demonio udiskie.

-R, --no-recursive

Deshabilita el montaje recursivo (por defecto).

-o OPCIONES, --options=OPCIONES

Establece las opciones de montaje.

OPCIONES DE DESMONTAJE

-a, --all

Desmonta todos los dispositivos manejados.

-d, --detach

Desconecta la unidad, por ejemplo, apagando su puerto físico.

-D, --no-detach

No desconecta la unidad (por defecto).

-e, --eject

Expulsa el medio de la unidad, por ejemplo, CDROM.

-E, --no-eject

No expulsa el medio (por defecto).

-f, --force

Fuerza la eliminación (desmontaje recursivo).

-F, --no-force

No fuerza la eliminación (por defecto).

-l, --lock

Bloquea el dispositivo después de desmontarlo (por defecto).

-L, --no-lock

No bloquea el dispositivo.

EJEMPLO DE USO

Inicia udiskie en ~/.xinitrc:

udiskie &

Desmonta el medio y apaga el dispositivo USB:

udiskie-umount --detach /media/Sticky

Monta todos los medios:

udiskie-mount -a

Monta /dev/sdb1:

udiskie-mount /dev/sdb1

CONFIGURACIÓN

El archivo .config/udiskie/config.yml se puede utilizar para configurar los valores predeterminados de los parámetros de línea de comandos y personalizar further configuraciones. La ruta real puede diferir dependiendo de $XDG_CONFIG_HOME. El formato del archivo es YAML, ver https://en.wikipedia.org/wiki/YAML. Si no quieres instalar PyYAML, es posible usar un archivo JSON equivalente con el nombre config.json en su lugar.

# Este es un archivo de configuración de ejemplo (sin sentido) para udiskie.
program_options:
  # Configura los valores predeterminados para las opciones de línea de comandos
  tray:             auto    # [bool] Habilita el icono de la bandeja. "auto"
                            # significa ocultar automáticamente el icono de la bandeja
                            # cuando no hay dispositivos manejados.
  menu:             flat    # ["flat" | "nested"] Establece el
                            # comportamiento del menú de la bandeja del sistema.
  automount:        false   # [bool] Habilita el montaje automático.
  notify:           true    # [bool] Habilita las notificaciones.
  password_cache:   30      # [int] Caché de contraseñas en minutos. El caché está
                            # deshabilitado por defecto. Se puede deshabilitar
                            # explícitamente estableciéndolo a false
  file_manager:     xdg-open
    # [string] Establece el programa para abrir directorios. Se invocará
    # con la ruta de la carpeta como su último argumento de línea de comandos.
  terminal:         'termite -d'
    # [string] Establece la línea de comandos del terminal para abrir directorios. Se
    # invocará con la ruta de la carpeta como su último argumento de línea de comandos.
  password_prompt: ["gnome-keyring-query", "get", "{id_uuid}"]
    # [string|list] Establece el comando para recuperar contraseñas. Si se especifica
    # como una lista define la matriz ARGV para la llamada al programa. Si
    # se especifica como una cadena, se expandirá de manera similar a un shell. Cada
    # cadena se formateará usando `str.format`. Para una
    # lista de atributos de dispositivo, ver abajo. Los dos valores de cadena especiales
    # "builtin:gui" y "builtin:tty" significan usar el prompt de
    # contraseña incorporado de udiskie.
  event_hook: "zenity --info --text '{event}: {device_presentation}'"
    # [string|list] Establece el comando a ejecutar en cualquier evento de dispositivo.
    # Esto se especifica como `password_prompt`.
device_config:
  # Lista de reglas de opciones de dispositivo. Cada elemento puede coincidir con cualquier combinación de atributos de dispositivo.
  # Además, define la acción resultante (ver abajo).
  # Cualquier regla puede contener múltiples filtros (AND) y múltiples acciones.
  # Solo la primera regla coincidente que define un dado

CONFIGURACIÓN

Este archivo de configuración puede contener las siguientes claves:

daemon
Permite controlar el comportamiento del demonio. Los valores permitidos son true (activar el demonio), false (desactivar el demonio), o un nombre de ruta a un socket de demonio. Si se proporciona un nombre de ruta, se intentará conectar a este socket y no se iniciará un nuevo demonio.
smart_monitoring
Activa o desactiva el monitoreo S.M.A.R.T. El valor predeterminado es true.
automount
Si está activado, los dispositivos que no tengan una regla explícita automount: false serán montados automáticamente cuando aparezcan. El valor predeterminado es true.
show_partitions
Si está activado, las particiones también se mostrarán en el menú de la bandeja. El valor predeterminado es true.
show_in_ui
Si está activado, los dispositivos se mostrarán en el menú de la bandeja, incluso si no son montables o si el automontaje está desactivado. El valor predeterminado es true.
menu
Define qué acciones se muestran en el menú de la bandeja. Se pueden especificar las siguientes acciones: mount, unmount, unlock, terminal, detach, delete, eject, quit. El valor especial all muestra todas las acciones disponibles.
buttons
Define qué botones se muestran en la ventana de notificación. Las acciones disponibles son las mismas que para la opción menu. El valor predeterminado es all.
quickmenu_actions
Similar a menu y buttons, pero se usa para el menú de clic izquierdo si se utiliza el tipo de menú plano.
notification_actions
Define qué acciones se muestran en las notificaciones. Los eventos que no se especifiquen explícitamente muestran el conjunto predeterminado de acciones. Especifique una lista vacía si no desea ver ninguna notificación para el evento especificado.
timeout
Tiempo de espera en segundos para las notificaciones. El valor predeterminado es 1.5.
devices
Lista de reglas de filtro y acción para dispositivos específicos. Cada regla puede contener los siguientes campos:
- device_file: /dev/dm-5    # [filter]
  ignore:      false        # [action] never ignore this device
- id_uuid:                  # [filter] match by device UUID
  - 9d53-13ba               # This rule matches on either of these uids
  - 8675-309a
  options: [noexec, nodev]  # [action] mount options can be given as list
  ignore:  false            # [action] never ignore this device (even if fs=FAT)
  automount: false          # [action] do not automount this device
- id_type: vfat             # [filter] match file system type
  ignore:  true             # [action] ignore all FAT devices
- id_type: ntfs             # [filter] (optional)
  skip: true                # [action] skip all further (even builtin) rules
                            # for all matched devices, and resolve action result
                            # on parent device
- ignore:    True           # never mount/unmount or even show this in the GUI
  automount: False          # show but do not automount this device
  options: []               # additional options to be passed when mounting
- id_uuid: ...              # [filter] match device by UUID
  keyfile: /path/to/keyfile # [action] use keyfile to unlock a luks encrypted
                            # device, bypassing the password prompt
mount_options:              # [deprecated] do not use
ignore_device:              # [deprecated] do not use
notifications:
  # Customize which notifications are shown for how long. Possible
  # values are:
  #   positive number         timeout in seconds
  #   false                   disable
  #   -1                      use the libnotify default timeout
  timeout:          1.5     # set the default for all notifications
  # Specify only if you want to overwrite the default:
  device_mounted:   5       # mount notification
  device_unmounted: false   # unmount notification
  device_added:     false   # device has appeared
  device_removed:   false   # device has disappeared
  device_unlocked:  -1      # encrypted device was unlocked
  device_locked:    -1      # encrypted device was locked
  job_failed:       -1      # mount/unlock/.. has failed
quickmenu_actions: [mount, unmount, unlock, terminal, detach, delete]
  # List of actions to be shown in the quickmenu or the special value 'all'.
  # The quickmenu is shown on left-click if using flat menu type.
notification_actions:
  # Define which actions should be shown on notifications. Note that there
  # are currently only a limited set of actions available for each
  # notification. Events that are not explicitly specified show the default
  # set of actions. Specify an empty list if you don't want to see any
  # notification for the specified event:
  device_mounted:   [browse]
  device_added:     [mount]
icon_names:
  # Customize the icon set used by the tray widget. Each entry
  # specifies a list of icon names. The first installed icon from
  # that list will be used.
  media:   [drive-removable-media, media-optical]
  browse:  [document-open, folder-open]
  terminal: [terminal, terminator, xfce-terminal]
  mount:   [udiskie-mount]
  unmount: [udiskie-unmount]
  unlock:  [udiskie-unlock]
  lock:    [udiskie-lock]
  eject:   [udiskie-eject, media-eject]
  detach:  [udiskie-detach]
  delete:  [udiskie-eject]
  quit:    [application-exit]

Todas las claves son opcionales. Se utilizan valores predeterminados razonables si los deja sin especificar.
