NOMBRE

unw_apply_reg_state -- aplica una actualización de estado de registro a un cursor

SINOPSIS

#include <libunwind.h>

int unw_apply_reg_state(unw_cursor_t *cp, void *reg_states_data);

DESCRIPCIÓN

La rutina unw_apply_reg_state() actualiza los valores de registro de un cursor de acuerdo con las instrucciones en reg_states_data, que se han obtenido llamando a unw_reg_states_iterate.

VALOR DE RETORNO

Al completarse con éxito, unw_apply_reg_state() devuelve 0. De lo contrario, se devuelve el valor negativo de uno de los códigos de error a continuación.

SEGURIDAD DE HILOS Y SEÑALES

unw_apply_reg_state() es seguro para hilos. Si el cursor cp está en el espacio de direcciones local, esta rutina también es segura de usar desde un manejador de señales.

ERRORES

UNW_EUNSPEC

Ocurrió un error no especificado.
UNW_ENOINFO

Libunwind no pudo localizar información de desentrelazado para el procedimiento.
UNW_EBADVERSION

La información de desentrelazado del procedimiento tiene una versión o formato que libunwind no comprende.

Además, unw_apply_reg_state() puede devolver cualquier error devuelto por la devolución de llamada access_mem() (ver unw_create_addr_space(3libunwind)).

VER TAMBIÉN

libunwind(3libunwind), unw_reg_states_iterate(3libunwind)
