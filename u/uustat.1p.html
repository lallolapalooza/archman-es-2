UUSTAT(1P) Manual del programador de POSIX UUSTAT(1P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux) o la interfaz puede no estar implementada en Linux.

NOMBRE

uustat — consulta de estado y control de trabajos de uucp

SINOPSIS

uustat [-q|-k id_trabajo|-r id_trabajo]
uustat [-s sistema] [-u usuario]

DESCRIPCIÓN

La utilidad uustat mostrará el estado de, o cancelará, solicitudes uucp especificadas previamente, o proporcionará información general sobre las conexiones uucp a otros sistemas.

Cuando no se proporcionan opciones, uustat escribirá en la salida estándar el estado de todas las solicitudes uucp emitidas por el usuario actual.

Las implementaciones típicas de esta utilidad requieren una línea de comunicación configurada para usar el volumen de Definiciones Base de POSIX.1-2017, Capítulo 11, Interfaz General de Terminal, pero se pueden usar otros medios de comunicación. En sistemas donde no hay medios de comunicación disponibles (temporal o permanentemente), esta utilidad escribirá un mensaje de error que describe el problema y saldrá con un estado de salida distinto de cero.

OPCIONES

La utilidad uustat se ajustará al volumen de Definiciones Base de POSIX.1-2017, Sección 12.2, Pautas de sintaxis de utilidad.

Se admitirán las siguientes opciones:

-q
Escribe los trabajos en cola para cada máquina.
-k id_trabajo
Cancela la solicitud uucp cuya identificación de trabajo es id_trabajo. La aplicación garantizará que la solicitud uucp cancelada pertenece a la persona que invoca uustat, a menos que ese usuario tenga los privilegios apropiados.
-r id_trabajo
Actualiza el id_trabajo. Los archivos asociados con id_trabajo se tocan para que su tiempo de modificación se establezca en la hora actual. Esto evita que el programa de limpieza elimine el trabajo hasta que el tiempo de modificación del trabajo alcance el límite impuesto por el programa.
-s sistema
Escribe el estado de todas las solicitudes uucp para el sistema remoto sistema.
-u usuario
Escribe el estado de todas las solicitudes uucp emitidas por usuario.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de uustat:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1-2017, Sección 8.2, Variables de internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en un valor de cadena no vacío, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en los argumentos).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar al formato y contenido de los mensajes de diagnóstico escritos en la salida estándar de error, y a los mensajes informativos escritos en la salida estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASINCRÓNICOS

Predeterminado.

SALIDA ESTÁNDAR

La salida estándar consistirá en información sobre cada trabajo seleccionado, en un formato no especificado. La información incluirá al menos el ID del trabajo, el ID o nombre de usuario y el nombre del sistema remoto.

ERROR ESTÁNDAR

El error estándar se utilizará solo para mensajes de diagnóstico.
