USDINITSCHEMA(1) Comandos de usuario USDINITSCHEMA(1)

NOMBRE

usdInitSchema - página del manual para usdInitSchema 25.11

DESCRIPCIÓN

uso: usdInitSchema [-h] [-v] [-q] [--genModuleDeps] [-t RUTA_PLANTILLA]

rutaGenCodigo rutaLibreria [prefijoPxr]

Configura las necesidades de compilación para las clases de esquema. Esto generará plantillas para CMakeLists.txt, __init__.py, schema.usda, module.cpp y un documento de usuario si aún no existen.

argumentos posicionales:

rutaGenCodigo
El directorio de destino donde se generará el código. Puede ser '.' para el directorio actual.
rutaLibreria
La ruta parcial con la que prefijar las sentencias '#include' de los archivos generados para este módulo. Para plugins externos (no de Pixar), recomendamos establecer rutaLibreria a ".", para que las cabeceras dentro del directorio src se incluyan en los archivos generados.
prefijoPxr
Prefijo de la ruta desde pxr a esta librería. Para pxr/usd/usd, el prefijo sería pxr/usd. Omite este argumento para sistemas de compilación que no sean OpenUSD.

opciones:

-h, --help
muestra este mensaje de ayuda y sale
-v, --validate
Verifica que los archivos fuente no hayan cambiado.
-q, --quiet
No muestra texto durante la ejecución.
--genModuleDeps
Genera una plantilla para moduleDeps.cpp. Esta plantilla deberá ser rellenada y mantenida actualizada con las dependencias de la librería si no estás usando el sistema de compilación OpenUSD.
-t, --templates RUTA_PLANTILLA
Directorio que contiene las plantillas de las clases de esquema. [Por defecto: el primer directorio que exista de esta lista: /build/usd /pkg/usd/usr/bin/codegenTemplates:/build/usd/pkg/usd/u sr/lib/usd/usd/resources/codegenTemplates]
