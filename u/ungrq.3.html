CUNGRQ

Propósito:

!>
!> CUNGRQ genera una matriz compleja M por N, Q, con filas ortonormales,
!> la cual se define como las últimas M filas de un producto de K
!> transformaciones elementales de reflexión de orden N
!>
!>       Q  =  H(1)**H H(2)**H . . . H(k)**H
!>
!> tal como es devuelto por CGERQF.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Q. N >= M.
!>

K

!>          K es INTEGER
!>          El número de transformaciones elementales de reflexión cuyo
!>          producto define la matriz Q. M >= K >= 0.
!>

A

!>          A es un array de tipo COMPLEX, de dimensión (LDA,N)
!>          En la entrada, la fila (m-k+i) debe contener el vector que
!>          define la transformación elemental de reflexión H(i), para
!>          i = 1,2,...,k, tal como es devuelto por CGERQF en las últimas k
!>          filas de su array de argumento A.
!>          En la salida, la matriz M por N, Q.
!>

LDA

!>          LDA es INTEGER
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array de tipo COMPLEX, de dimensión (K)
!>          TAU(i) debe contener el factor escalar de la
!>          transformación elemental de reflexión H(i), tal como es
!>          devuelto por CGERQF.
!>

WORK

!>          WORK es un array de tipo COMPLEX, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,M).
!>          Para un rendimiento óptimo, LWORK >= M*NB, donde NB es el
!>          tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          subrutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tiene un valor ilegal
!>

NAME

ungrq — gerqf(3) para matrices complejas

SYNOPSIS

subroutine ungrq(integer m, integer n, integer k, real, dimension( lda, * ) a,
                 integer lda, real, dimension( * ) tau, real, dimension( * ) work,
                 integer lwork, integer info)
subroutine zungrq(integer m, integer n, integer k, complex*16, dimension( lda, * ) a,
                  integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work,
                  integer lwork, integer info)

Detailed Description

The routines SUNGQ and ZUNGRQ generate an M-by-N real or complex matrix Q with orthonormal rows, which is defined as the last M rows of a product of K elementary reflectors of order N

       Q  =  H(1)**T H(2)**T . . . H(k)**T
       Q  =  H(1)**H H(2)**H . . . H(k)**H

as returned by SGERQF or ZGERQF, respectively.

This is a related routine to geqrf and orgqr. SGERQF and ZGERQF compute the QR factorization of a matrix A stored in the last K rows of A, and SUNGQ and ZUNGRQ are the right-hand side update routines.

subroutine sungrq (integer m, integer n, integer k, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SUNGQ

Purpose:

!>
!> SUNGQ generates an M-by-N real matrix Q with orthonormal rows,
!> which is defined as the last M rows of a product of K elementary
!> reflectors of order N
!>
!>       Q  =  H(1)**T H(2)**T . . . H(k)**T
!>
!> as returned by SGERQF.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix Q. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix Q. N >= M.
!>

K

!>          K is INTEGER
!>          The number of elementary reflectors whose product defines the
!>          matrix Q. M >= K >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the (m-k+i)-th row must contain the vector which
!>          defines the elementary reflector H(i), for i = 1,2,...,k, as
!>          returned by SGERQF in the last k rows of its array argument
!>          A.
!>          On exit, the M-by-N matrix Q.
!>

LDA

!>          LDA is INTEGER
!>          The first dimension of the array A. LDA >= max(1,M).
!>

TAU

!>          TAU is REAL array, dimension (K)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by SGERQF.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,M).
!>          For optimum performance LWORK >= M*NB, where NB is the
!>          optimal blocksize.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument has an illegal value
!>
