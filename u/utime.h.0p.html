PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

utime.h — estructura de tiempos de acceso y modificación

SINOPSIS

#include <utime.h>

DESCRIPCIÓN

El archivo de cabecera <utime.h> declarará la estructura utimbuf, que incluirá los siguientes miembros:

time_t    actime    Tiempo de acceso.
time_t    modtime   Tiempo de modificación.

Los tiempos se medirán en segundos desde la Época.

El archivo de cabecera <utime.h> definirá el tipo time_t como se describe en <sys/types.h>.

Lo siguiente se declarará como una función y también puede definirse como una macro. Se proporcionará un prototipo de función.

int utime(const char *, const struct utimbuf *);

Las siguientes secciones son informativas.

USO PARA APLICACIONES

La función utime() solo permite establecer las marcas de tiempo de los archivos a la segunda más cercana. Las aplicaciones deben usar la función utimensat() en su lugar. Consulte <sys/stat.h>.

RACIOCINIO

Ninguno.

DIRECCIONES FUTURAS

Es posible que el archivo de cabecera <utime.h> se elimine en una versión futura.
