UWSM-PLUGINS(3) Manual de funciones de biblioteca UWSM-PLUGINS(3)

NOMBRE

UWSM-plugins - Plugins para el Gestor de Sesiones Universal de Wayland.

DESCRIPCIÓN

Los plugins de shell proporcionan funciones específicas del compositor durante la preparación del entorno.

Ubicados en ${PREFIX}/share/uwsm/plugins/ y nombrados ${__WM_BIN_ID__}.sh, solo deben contener funciones con nombres específicos.

${__WM_BIN_ID__} se deriva del elemento 0 de la línea de comandos del compositor aplicando s/(^[^a-zA-Z]|[^a-zA-Z0-9_])+/_/ y convirtiéndolo a minúsculas.

Se utiliza como ID de plugin y sufijo en los nombres de las funciones.

Variables disponibles para los plugins

__WM_ID__

ID del compositor, primer argumento efectivo de start.
__WM_ID_UNIT_STRING__
ID del compositor escapado para el nombre de unidad systemd.
__WM_BIN_ID__
primer elemento procesado de argv del compositor.
__WM_DESKTOP_NAMES__
nombres de escritorio separados por : de DesktopNames= de la entrada y el argumento de línea de comandos -D.
__WM_FIRST_DESKTOP_NAME__
el primero de los anteriores.
__WM_DESKTOP_NAMES_LOWERCASE__
igual que __WM_DESKTOP_NAMES__, pero en minúsculas.
__WM_FIRST_DESKTOP_NAME_LOWERCASE__
el primero de los anteriores.
__WM_DESKTOP_NAMES_EXCLUSIVE__
(true|false) indica que __WM_DESKTOP_NAMES__ provino del argumento de línea de comandos y están marcados como exclusivos.
__OIFS__
contiene el separador de campos predeterminado del shell (espacio, tabulador, nueva línea) para una restauración conveniente.

Funciones estándar

load_wm_env

función estándar para cargar archivos de entorno
process_config_dirs
itera sobre la jerarquía de configuración XDG y la parte del sistema de la jerarquía de datos XDG (prioridad decreciente)
process_config_dirs_reversed
(llamada por load_wm_env), igual que process_config_dirs pero en orden inverso (prioridad creciente)
in_each_config_dir_reversed
llamada por process_config_dirs_reversed para cada directorio de configuración como $1, carga los archivos uwsm/env, uwsm/env-${desktop}
in_each_config_dir
llamada por process_config_dirs para cada directorio de configuración como $1, no hace nada por el momento
source_file
carga el archivo $1 si existe, proporcionando mensajes para el registro.

Consulta el código dentro de uwsm/main.py para ver más funciones auxiliares.

Funciones que pueden ser añadidas por plugins

quirks__${__WM_BIN_ID__}
llamada antes de cargar el entorno.

Estas funciones se llamarán en lugar de las funciones estándar si se definen:

load_wm_env__${__WM_BIN_ID__}
process_config_dirs_reversed__${__WM_BIN_ID__}
in_each_config_dir_reversed__${__WM_BIN_ID__}
process_config_dirs__${__WM_BIN_ID__}
in_each_config_dir__${__WM_BIN_ID__}

Las funciones originales todavía están disponibles para ser llamadas explícitamente si se necesita un efecto combinado.

Ejemplo:

#!/bin/false
# función para realizar acciones arbitrarias antes de cargar el entorno
quirks__my_cool_wm() {
  # aquí se pueden establecer o anular variables adicionales
  export I_WANT_THIS_IN_SESSION=yes
  unset I_DO_NOT_WANT_THAT
  # o preparar una configuración para el compositor
  # o establecer una variable para modificar qué harán las cargas de uwsm/env, uwsm/env-${__WM_ID__}
  # en la siguiente etapa
  ...
}
in_each_config_dir_reversed__my_cool_wm() {
  # mecanismo personalizado para cargar archivos de entorno (o un stub)
  # reemplaza la función estándar, pero también la queremos
  # así que la llamamos explícitamente
  in_each_config_dir_reversed "$1"
  # y además cargamos nuestro archivo
  source_file "${1}/${__WM_ID__}/env"
}
