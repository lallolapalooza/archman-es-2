VALOR DE RETORNO

En caso de éxito, udev_device_get_syspath(), udev_device_get_sysname(), udev_device_get_sysnum(), udev_device_get_devpath(), udev_device_get_devnode(), udev_device_get_devtype(), udev_device_get_subsystem(), udev_device_get_driver() y udev_device_get_action() devuelven un puntero a una cadena constante que describe la propiedad solicitada. La vida útil de esta cadena está ligada al dispositivo sobre el que se solicitó. En caso de fallo, cada función puede devolver NULL.

En caso de éxito, udev_device_get_devnum() devuelve el tipo de dispositivo del dispositivo pasado. En caso de fallo, se devuelve un tipo de dispositivo con los números menor y mayor establecidos a 0.

udev_device_get_udev() siempre devuelve un puntero válido al contexto de udev al que pertenece este dispositivo.

En caso de éxito, udev_device_get_parent() y udev_device_get_parent_with_subsystem_devtype() devuelven un puntero al dispositivo padre. No se adquiere ninguna referencia adicional a este dispositivo, pero el dispositivo hijo posee una referencia a dicho dispositivo padre. En caso de fallo, se devuelve NULL.

En caso de éxito, udev_device_get_is_initialized() devuelve un 1 o 0, dependiendo de si el dispositivo pasado ya ha sido inicializado por udev o no. En caso de fallo, se devuelve un código de error negativo. Tenga en cuenta que los dispositivos para los que no se definen reglas de udev nunca se reportan como inicializados.
