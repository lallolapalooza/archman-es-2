unshar(1) Comandos de usuario unshar(1)

NOMBRE

unshar - descomprimir un archivo shar

SINOPSIS

unshar [-flags] [-flag [valor]] [--nombre-opcion[[=| ]valor]] [<archivo>...]

Los operandos sobre los que opera este programa se pueden especificar ya sea en la línea de comandos o leer de la entrada estándar, uno por línea. En esa entrada, se eliminan los espacios en blanco iniciales y finales, y se ignoran las líneas en blanco. La entrada estándar no puede ser una terminal.

DESCRIPCIÓN

Unshar escanea los archivos de entrada (típicamente mensajes de correo electrónico) buscando el inicio de un archivo shell. Si no se proporcionan archivos, se procesa la entrada estándar. Luego, pasa cada archivo descubierto a través de una invocación del programa shell para descomprimirlo.

Este programa realizará su función para cada archivo nombrado en la línea de comandos o cada archivo nombrado en una lista leída desde stdin. Los nombres de los argumentos o de la entrada deben ser archivos preexistentes. La lista de entrada puede contener comentarios, que son líneas en blanco o líneas que comienzan con un carácter '#'.

OPCIONES

-d dir, --directorio=dir

descomprimir en el directorio dir.

Los nombres de los archivos de entrada son relativos al directorio actual cuando se inició el programa. Esta opción le indica a unshar que inserte un comando cd <dir> al principio del texto shar escrito al shell.

-c, --sobrescribir

sobrescribir cualquier archivo preexistente.

Esta opción se pasa como una opción al archivo shar. Muchos scripts de archivo shell aceptan un argumento -c para indicar que los archivos existentes deben ser sobrescritos.

-f, --forzar

Este es un alias para la opción --sobrescribir.
-E marca-división, --dividir-en=marca-división

dividir la entrada en líneas de marca-división. La marca-división predeterminada para esta opción es:
exit 0

Con esta opción, unshar aísla cada archivo shell diferente de los otros que se han colocado en el mismo archivo, descomprimiendo cada uno en su turno, desde el principio del archivo hasta el final. Su funcionamiento adecuado se basa en el hecho de que muchos archivos shar terminan con una cadena fácilmente identificable al principio de la última línea.

Por ejemplo, al notar que la mayoría de los `.signatures' tienen un doble guión ("--") en una línea justo antes de ellos, uno puede usar a veces --dividir-en="--". La firma se omitirá, junto con las cabeceras del mensaje siguiente.

-e, --salir-0

dividir la entrada en líneas "exit 0". Esta opción no debe aparecer en combinación con ninguna de las siguientes opciones: dividir-en.

La mayoría de los archivos shell terminan con una línea que consiste únicamente en "exit 0". Esta opción es equivalente a (y entra en conflicto con) --dividir-en="exit 0".

-D, --depurar

depurar el código shell.

Se emitirá "set -x" en el código que el shell interpreta.

-h, --ayuda

Mostrar información de uso y salir.
-!, --mas-ayuda

Pasar la información de uso extendida a través de un paginador.
-R [archivo-cfg], --guardar-opts [=archivo-cfg]

Guardar el estado de las opciones en archivo-cfg. El valor predeterminado es el último archivo de configuración listado en la sección AJUSTES PREDEFINIDOS DE OPCIONES, abajo. El comando saldrá después de actualizar el archivo de configuración.
-r archivo-cfg, --cargar-opts=archivo-cfg, --no-cargar-opts

Cargar opciones desde archivo-cfg. La forma --no-cargar-opts desactivará la carga de archivos config/rc/ini anteriores. --no-cargar-opts se maneja temprano, fuera de orden.
-v [{v|c|n --version [{v|c|n}]}]

Mostrar la versión del programa y salir. El modo predeterminado es `v', una versión simple. El modo `c' imprimirá información de derechos de autor y `n' imprimirá el aviso completo de derechos de autor.

AJUSTES PREDEFINIDOS DE OPCIONES

Cualquier opción que no esté marcada como no preseteable puede ser preestablecida cargando valores de archivos de configuración ("RC" o ".INI"). Se utilizará el archivo "$HOME/.sharrc", si está presente.

ARCHIVOS

Ver AJUSTES PREDEFINIDOS DE OPCIONES para los archivos de configuración.

ESTADO DE SALIDA

Se devolverá uno de los siguientes valores de salida:

0 (EXIT_SUCCESS)

Ejecución exitosa del programa.
1 (EXIT_FAILURE)

Hubo un error en el uso del comando.
2 (EXIT_POPEN_PROBLEM)

no se puede iniciar o escribir en un proceso shell
3 (EXIT_CANNOT_CREATE)

no se puede crear el archivo de salida
4 (EXIT_BAD_DIRECTORY)

la estructura del directorio de trabajo es inválida
5 (EXIT_NOMEM)

fallo de asignación de memoria
6 (EXIT_INVALID)

entrada inválida, no contiene un archivo shar
66 (EX_NOINPUT)

No se pudo cargar un archivo de configuración especificado.
70 (EX_SOFTWARE)

libopts tuvo un error operativo interno. Por favor, repórtelo a autogen-users@lists.sourceforge.net. Gracias.
