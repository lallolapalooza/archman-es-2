USBREDIRECT(1) Comandos de usuario USBREDIRECT(1)

NOMBRE

usbredirect - exportar un dispositivo USB para su uso desde otra máquina (virtual)

SINOPSIS

usbredirect [--device vendor:product] [--to addr:port] [--as addr:port]
usbredirect [--device bus-device] [--to addr:port] [--as addr:port]

DESCRIPCIÓN

usbredirect es un cliente de usbredir para exportar un dispositivo USB ya sea como cliente o servidor TCP, para su uso desde otra máquina (virtual) a través del protocolo usbredir.

Puede especificar el dispositivo USB a exportar por ID USB en el formato <vendorid>:<prodid>.
O puede especificar el dispositivo USB a exportar en el formato <busnum>-<devnum>.

Tenga en cuenta que una instancia de usbredirect solo puede usarse para exportar un único dispositivo USB y se cerrará una vez que el otro lado cierre la conexión. Si desea exportar varios dispositivos, puede iniciar múltiples instancias escuchando en diferentes puertos TCP.
