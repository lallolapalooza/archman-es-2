DESCRIPCIÓN

################################################################################################# # USD_DISABLE_PRIM_DEFINITIONS_FOR_USDGENSCHEMA se sobrescribe a 'true'. Por defecto es 'false'. # ################################################################################################# uso: usdGenSchema [-h] [-v] [-q] [-n NAMESPACE [NAMESPACE ...]]

[-t RUTA_PLANTILLA] [-hts CADENA_TERMINADOR_CABECERA]
[ruta_esquema] [ruta_generacion_codigo]

Genera código de clase de esquema C++ a partir de un archivo USD.

argumentos posicionales:

ruta_esquema
El archivo USD fuente donde se definen las clases de esquema. [Por defecto: ./schema.usda]
ruta_generacion_codigo
El directorio de destino donde se debe generar el código. [Por defecto: .]

opciones:

-h, --help
muestra este mensaje de ayuda y sale
-v, --validate
Verifica que los archivos fuente no han cambiado.
-q, --quiet
No emite texto durante la ejecución.
-n, --namespace NAMESPACE [NAMESPACE ...]
Envuelve el código en el espacio de nombres especificado. Múltiples argumentos se interpretarán como un espacio de nombres anidado. El argumento más a la izquierda se tratará como el espacio de nombres más externo, y el argumento más a la derecha como el más interno.
-t, --templates RUTA_PLANTILLA
Directorio que contiene las plantillas de clases de esquema. [Por defecto: el primer directorio que exista de esta lista: /build/usd /pkg/usd/usr/bin/codegenTemplates:/build/usd/pkg/usd/u sr/lib/usd/usd/resources/codegenTemplates]
-hts, --headerTerminatorString CADENA_TERMINADOR_CABECERA
La cadena utilizada para terminar los archivos de cabecera C++ generados, después de la sección de código personalizado. [Por defecto: #endif]
