LAPACK Documentation: ZUNMRZ(3)

NAME

ZUNMRZ - to form the complex vector $Q \cdot X$ or $X \cdot Q$, where Q is a unitary matrix, as computed by ZGELMRZ.

SYNOPSIS

 subroutine ZUNMRZ(SIDE, TRANS, M, N, K, L, A, LDA, TAU, X, LDX, WORK, LWORK, INFO)
  character(len=1) :: SIDE, TRANS
  integer :: M, N, K, L, LDA, LDX, LWORK, INFO
  complex(8), dimension(lda,*) :: A
  complex(8), dimension(max(1,n)) :: TAU
  complex(8), dimension(ldx,*) :: X
  complex(8), dimension(:), allocatable :: WORK

Detailed Description

ZUNMRZ forms the complex vector $Q \cdot X$ or $X \cdot Q$, which is a part of the algorithm to compute the minimum norm solution of the linear least squares problem to the equation $A \cdot X = B$.

$A$ is an $M$-by-$N$ matrix. It is assumed that $A$ has been factorized by the routine ZGELMRZ.

$Q$ is a unitary matrix of order $M$ if $SIDE = 'L'$ and of order $N$ if $SIDE = 'R'$. $Q$ is defined as the product of $L$ householder vectors $Q = H_1 H_2 \dots H_L$ or $Q = H_L \dots H_2 H_1$.

ZUNMRZ is the interface to ZUNMR3. For details on the parameters and the algorithm, see the documentation of ZUNMR3.

Arguments:

SIDE
CHARACTER*1.

'L': form $Q \cdot X$.

'R': form $X \cdot Q$.

See below for the dimensions of $X$.

TRANS
CHARACTER*1.

'N': form $Q \cdot X$ or $X \cdot Q$.

'C': form $Q^H \cdot X$ or $X \cdot Q^H$.

M
INTEGER.

The number of rows of the matrix $X$; $M \ge 0$. If $SIDE = 'L'$, then the row dimension of $X$ is $M$. If $SIDE = 'R'$, then the row dimension of $X$ is $K$, where $K$ is the number of rows of $A$ if $A$ is $M$-by-$N$. If $SIDE = 'R'$, then $M$ is not used.

N
INTEGER.

The number of columns of the matrix $X$; $N \ge 0$. If $SIDE = 'R'$, then the column dimension of $X$ is $N$. If $SIDE = 'L'$, then the column dimension of $X$ is $K$, where $K$ is the number of columns of $A$ if $A$ is $M$-by-$N$. If $SIDE = 'L'$, then $N$ is not used.

K
INTEGER.

The number of columns of the matrix $A$ if $SIDE = 'L'$, or the number of rows of the matrix $A$ if $SIDE = 'R'$. $K \ge 0$. Essentially, $K$ is the number of columns of $A$ if $A$ is $M \times K$, or the number of rows of $A$ if $A$ is $K \times N$. If $SIDE = 'L'$, then $N$ in the description of the call is the number of columns of $A$. The parameter $N$ here represents the number of columns of $X$. If $SIDE = 'R'$, then $M$ in the description of the call is the number of rows of $A$. The parameter $M$ here represents the number of rows of $X$. Note that $K$ is the length of the vectors in TAU.

L
INTEGER.

The number of rows of the matrix $A$ that contain the Householder vectors. $L \ge 0$. This is the number of Householder vectors used to define $Q$. See also ZGELMRZ. $L$ must be less than or equal to $\min(M, K)$ if $SIDE = 'L'$, and less than or equal to $\min(K, N)$ if $SIDE = 'R'$.

A
COMPLEX*16 dimension (LDA,*).

On entry, the vectors $v$ forming the matrix $V$. $A$ is $M \times K$ if $SIDE = 'L'$, or $K \times N$ if $SIDE = 'R'$. The rows of $A$ specify the vectors $v$ used by the routines ZGELMRZ and ZUNMR3. The first $L$ rows of $A$ contain the Householder vectors $v_i$, and the remaining rows are not referenced.

LDA
INTEGER.

The leading dimension of the array $A$. $LDA \ge \max(1,M)$ if $SIDE = 'L'$, and $LDA \ge \max(1,K)$ if $SIDE = 'R'$. This must match the value passed to ZGELMRZ.

TAU
COMPLEX*16 dimension (max(1,L)).

TAU(i) contains the scalar factor $\tau_i$ of the elementary reflector $H_i$, used by ZGELMRZ and ZUNMR3. See also ZGELMRZ.

X
COMPLEX*16 dimension (LDX,*).

On entry, the matrix $X$. If $SIDE = 'L'$, $X$ is $M \times N$. If $SIDE = 'R'$, $X$ is $K \times N$. On exit, $X$ is overwritten by $Q \cdot X$ or $X \cdot Q$, or their conjugate transposes.

LDX
INTEGER.

The leading dimension of the array $X$. If $SIDE = 'L'$, $LDX \ge \max(1,M)$. If $SIDE = 'R'$, $LDX \ge \max(1,K)$.

WORK
COMPLEX*16 dimension (LWORK).

Workspace array. On exit, if INFO = 0, WORK(1) contains the optimal LWORK.

LWORK
INTEGER.

The dimension of the array WORK. If $SIDE = 'L'$, LWORK $ \ge \max(1,M)$. If $SIDE = 'R'$, LWORK $ \ge \max(1,K)$. For good performance, LWORK should generally be larger.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

INFO
INTEGER.

INFO = 0: successful exit INFO < 0: if INFO = -i, the i-th argument had an illegal value

Function Documentation

ZUNMRZ is a subroutine in LAPACK for forming $Q \cdot X$ or $X \cdot Q$, where $Q$ is a unitary matrix constructed from Householder reflectors. This routine is part of the LAPACK routines for solving linear least squares problems and systems of linear equations using QR or LQ factorization.

The subroutine is an interface to ZUNMR3, which performs the actual computation. The parameters largely mirror those of ZGELMRZ and ZUNMR3.

Key arguments include:

  • SIDE: Determines whether $Q$ multiplies from the left ($Q \cdot X$, 'L') or from the right ($X \cdot Q$, 'R').
  • TRANS: Specifies whether to apply $Q$ ('N') or its conjugate transpose $Q^H$ ('C').
  • M, N: Dimensions of the matrix $X$. Note that these dimensions depend on the value of SIDE and the dimensions of the original matrix $A$ (represented by K).
  • K: Related to the dimensions of matrix $A$. Specifically, if SIDE = 'L', $K$ is the number of columns of $A$; if SIDE = 'R', $K$ is the number of rows of $A$.
  • L: The number of Householder vectors used to define $Q$. This corresponds to the number of significant rows in matrix $A$ that contain the Householder reflectors.
  • A: Contains the Householder vectors $v$ and their associated scalars $\tau$. The first L rows are used.
  • TAU: Contains the scalar factors $\tau_i$ for each Householder reflector.
  • X: The matrix or vector to be multiplied by $Q$ or $Q^H$. This matrix is modified in place.
  • WORK: A workspace array used for intermediate computations. The routine can perform a workspace query by setting LWORK = -1 to determine the optimal size for WORK.
  • INFO: Error flag. INFO = 0 indicates success. A negative value indicates an illegal input argument.

The underlying computation involves applying a sequence of Householder transformations to the matrix $X$. The efficiency of the routine depends on the size of the workspace array WORK, and it is recommended to provide a sufficiently large value for LWORK to ensure optimal performance.

Example usage would typically involve calling ZGELMRZ to obtain the factorization and the TAU coefficients, and then calling ZUNMRZ to reconstruct the matrix $Q$ or apply it to another matrix $X$.
