UMOUNT.NFS(8) Manual del Administrador del Sistema UMOUNT.NFS(8)

NOMBRE

umount.nfs, umount.nfs4 - desmontar un Sistema de Archivos de Red

SINOPSIS

umount.nfs dir [-fvnrlh ]

DESCRIPCIÓN

umount.nfs y umount.nfs4 forman parte del paquete de utilidades de nfs(5), que proporciona funcionalidad de cliente NFS.

umount.nfs4 y umount.nfs están pensados para ser utilizados por el comando umount(8) para desmontar comparticiones NFS. Sin embargo, este subcomando también se puede utilizar como un comando independiente con funcionalidad limitada.

dir es el directorio en el que está montado el sistema de archivos.

OPCIONES

-f
Forzar el desmontaje del sistema de archivos en caso de que el sistema NFS no sea alcanzable.
-v
Ser verboso.
-n
No actualizar /etc/mtab. Por defecto, se crea una entrada en /etc/mtab por cada sistema de archivos montado. Utilice esta opción para omitir la eliminación de una entrada.
-r
En caso de que el desmontaje falle, intentar montar como solo lectura.
-l
Desmontaje perezoso. Desacoplar el sistema de archivos de la jerarquía de sistemas de archivos ahora, y limpiar todas las referencias al sistema de archivos tan pronto como ya no esté ocupado.
-h
Mostrar mensaje de ayuda.

NOTA

Para más información, consulte las páginas del manual nfs(5) y umount(8).

ARCHIVOS

tabla de sistemas de archivos
/etc/mtab
tabla de sistemas de archivos montados
