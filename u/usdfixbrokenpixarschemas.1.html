NOMBRE

usdfixbrokenpixarschemas - página del manual para usdfixbrokenpixarschemas 25.11

DESCRIPCIÓN

uso: usdfixbrokenpixarschemas [-h] [--backup ARCHIVO_RESPALDO] [-v] [archivoEntrada]

Corrige capas de usd / usdz aplicando las correcciones apropiadas definidas en UsdUtils.FixBrokenPixarSchemas. Si el archivo usd dado tiene alguna corrección que guardar, se crea una copia de seguridad para ese archivo. Si se proporciona un paquete usdz, se extrae recursivamente en una ubicación temporal y las correcciones se aplican individualmente en cada capa, que luego se empaquetan en un nuevo paquete usdz, mientras se crea una copia de seguridad del original.

argumentos posicionales:

archivoEntrada
Nombre del archivo de entrada a inspeccionar y corregir.

opciones:

-h, --help
mostrar este mensaje de ayuda y salir
--backup ARCHIVO_RESPALDO
ruta opcional del archivo de copia de seguridad; si no se proporciona, crea un archivo <archivoEntrada>.bck.<usda|usdc|usdz> en la ubicación de archivoEntrada
-v, --verbose
Habilitar modo detallado.
