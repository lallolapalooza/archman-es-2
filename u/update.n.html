update(n) Comandos integrados de Tcl update(n)

NOMBRE

update - Procesar eventos pendientes y callbacks ociosos

SINOPSIS

update ?idletasks?

DESCRIPCIÓN

Este comando se utiliza para poner la aplicación "al día" entrando repetidamente en el bucle de eventos hasta que todos los eventos pendientes (incluidos los callbacks ociosos) se hayan procesado.

Si la palabra clave idletasks se especifica como argumento del comando, entonces no se procesan nuevos eventos ni errores; solo se invocan los callbacks ociosos. Esto hace que las operaciones que normalmente se posponen, como las actualizaciones de pantalla y los cálculos de diseño de ventanas, se realicen de inmediato.

El comando update idletasks es útil en scripts donde se han realizado cambios en el estado de la aplicación y se desea que esos cambios aparezcan en la pantalla de inmediato, en lugar de esperar a que el script finalice. La mayoría de las actualizaciones de pantalla se realizan como callbacks ociosos, por lo que update idletasks provocará que se ejecuten. Sin embargo, hay algunos tipos de actualizaciones que solo ocurren en respuesta a eventos, como los desencadenados por cambios en el tamaño de la ventana; estas actualizaciones no ocurrirán en update idletasks.

El comando update sin opciones es útil en scripts donde está realizando un cálculo de larga duración pero aún desea que la aplicación responda a eventos como interacciones del usuario; si llama ocasionalmente a update, la entrada del usuario se procesará durante la próxima llamada a update.

EJEMPLO

Ejecutar cálculos durante aproximadamente un segundo y luego finalizar:

set x 1000
set done 0
after 1000 set done 1
while {!$done} {
    # ¡Un ejemplo muy tonto!
    set x [expr {log($x) ** 2.8}]
    # Comprueba si se ha alcanzado nuestro límite de tiempo. Esto
    # también daría una oportunidad para atender sockets de red y, si
    # el paquete Tk está cargado, actualizar una interfaz de usuario.
    update
}

VER TAMBIÉN

after(n), interp(n)

PALABRAS CLAVE

entrada/salida asíncrona, evento, vaciar, manejador, ocioso, actualizar
