NOMBRE

unw_set_caching_policy -- establece la política de caché

SINOPSIS

#include <libunwind.h>

int unw_set_caching_policy(unw_addr_space_t as, unw_caching_policy_t policy);

DESCRIPCIÓN

La rutina unw_set_caching_policy() establece la política de caché del espacio de direcciones as a la política especificada por el argumento policy. El argumento policy puede tomar uno de los tres valores posibles:

UNW_CACHE_NONE

Desactiva completamente la caché. Esto también vacía implícitamente el contenido de todas las cachés como si se hubiera llamado a unw_flush_cache().
UNW_CACHE_GLOBAL

Habilita la caché utilizando una caché global compartida por todos los hilos. Si la caché global no está disponible o no es compatible, libunwind puede recurrir al uso de una caché por hilo, como si se hubiera especificado UNW_CACHE_PER_THREAD.
UNW_CACHE_PER_THREAD

Habilita la caché utilizando cachés locales de hilo. Si las cachés locales de hilo no están disponibles o no son compatibles, libunwind puede recurrir al uso de una caché global, como si se hubiera especificado UNW_CACHE_GLOBAL.

Si se habilita la caché, una aplicación debe estar preparada para realizar llamadas apropiadas a unw_flush_cache() cada vez que el destino cambie de una manera que pueda afectar la validez de la información cachead. Por ejemplo, después de descargar (eliminar) una biblioteca compartida, se debería llamar a unw_flush_cache() (al menos) para el rango de direcciones cubierto por la biblioteca compartida.

Para los espacios de direcciones creados a través de unw_create_addr_space(3libunwind), la caché está desactivada por defecto. Para el espacio de direcciones local unw_local_addr_space, la caché está activada por defecto.

VALOR DE RETORNO

Al completarse con éxito, unw_set_caching_policy() devuelve 0. De lo contrario, se devuelve el valor negativo de uno de los siguientes códigos de error.

SEGURIDAD DE HILO Y SEÑAL

unw_set_caching_policy() es seguro para hilos, pero *no* es seguro para usar desde un manejador de señales.

ERRORES

UNW_ENOMEM

La política de caché deseada no se pudo establecer porque la aplicación se quedó sin memoria.
