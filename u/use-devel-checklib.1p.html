NOMBRE

use-devel-checklib - (OBSOLETO)un script para empaquetar Devel::CheckLib con tu código.

DESCRIPCIÓN

Este script está OBSOLETO.

Si necesitas depender de esta biblioteca, deberías usar `configure_requires` en Makefile.PL o Build.PL en su lugar.

ADVERTENCIAS, ERRORES y COMENTARIOS

Este script no ha sido probado a fondo. Deberías comprobar manualmente si ha hecho lo que esperabas después de ejecutarlo.

Si utilizas Module::Build::Compat para escribir un Makefile.PL, entonces necesitarás volver a ejecutar este script cada vez que hayas generado un nuevo Makefile.PL.

Agradezco comentarios sobre mi código, incluyendo críticas constructivas. Los informes de errores deben realizarse utilizando http://rt.cpan.org/ o por correo electrónico.
