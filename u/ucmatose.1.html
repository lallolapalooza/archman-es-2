UCMATOSE(1) librdmacm UCMATOSE(1)

NOMBRE

ucmatose - Conexión RDMA CM y prueba simple de ping-pong.

SINOPSIS

ucmatose [-s dirección_servidor] [-b dirección_enlace]
		[-f formato_dirección] [-P espacio_puertos]
		[-c conexiones] [-C contador_mensajes] [-S tamaño_mensaje] [-a tiempo_espera_ack]
ucmatose -s dirección_servidor [-b dirección_enlace]
		[-f formato_dirección] [-P espacio_puertos]
		[-c conexiones] [-C contador_mensajes] [-S tamaño_mensaje] [-t tos] [-a tiempo_espera_ack]

DESCRIPCIÓN

Establece un conjunto de conexiones RDMA fiables entre dos nodos utilizando librdmacm, opcionalmente transfiere datos entre los nodos y luego desconecta.

OPCIONES

-s dirección_servidor
El nombre de red o la dirección IP del sistema servidor que escucha las conexiones. El nombre o dirección utilizado debe enrutar a través de un dispositivo RDMA. Esta opción debe ser especificada por el cliente.
-b dirección_enlace
La dirección de red local a la que enlazarse. Para enlazar a cualquier dirección con IPv6 use -b ::0 .
-f formato_dirección
Especifica el formato de la dirección del servidor y del enlace. Por defecto, el formato lo determina getaddrinfo() como un nombre de host, una dirección IPv4 o una dirección IPv6. Esta opción puede ser utilizada para indicar que se ha proporcionado un formato de dirección específico. Los valores admitidos para formato_dirección son: name, ip, ipv6 y gid.
-P espacio_puertos
Especifica el espacio de puertos para la conexión. Por defecto, el espacio de puertos es el espacio de puertos TCP de RDMA. (Tenga en cuenta que el espacio de puertos RDMA puede ser independiente del utilizado para IP). Los valores admitidos para espacio_puertos son: tcp e ib.
-c conexiones
El número de conexiones a establecer entre el cliente y el servidor. (por defecto 1)
-C contador_mensajes
El número de mensajes a transferir por cada conexión. (por defecto 10)
-S tamaño_mensaje
El tamaño de cada mensaje transferido, en bytes. (por defecto 100)
-t tos
Indica el tipo de servicio utilizado para la comunicación. El tipo de servicio depende de la implementación según la configuración de la subred.
-a tiempo_espera_ack
Indica el valor del tiempo de espera ACK de la QP que se debe utilizar. El valor se calcula según la fórmula 4.096 * 2^(tiempo_espera_ack) usec.
-m
Prueba la migración de eventos. Migra todos los identificadores de comunicación a un canal de eventos diferente para los eventos de desconexión.

NOTAS

El uso básico consiste en iniciar ucmatose en un sistema servidor y luego ejecutar ucmatose -s nombre_servidor en un sistema cliente.

Dado que esta prueba asigna recursos RDMA al espacio de usuario, los usuarios deben asegurarse de que tienen los recursos y permisos del sistema disponibles. Consulte el archivo README de libibverbs para obtener información adicional.
