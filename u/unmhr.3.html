CUNMHR

Propósito:

!>
!> CUNMHR sobrescribe la matriz compleja general M-por-N C con
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> donde Q es una matriz unitaria compleja de orden nq, con nq = m si
!> SIDE = 'L' y nq = n si SIDE = 'R'. Q se define como el producto de
!> IHI-ILO reflectores elementales, como los devueltos por CGEHRD:
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda;
!>          = 'R': aplicar Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar Q (Sin transpuesta)
!>          = 'C': aplicar Q**H (Transpuesta conjugada)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>
!>          ILO e IHI deben tener los mismos valores que en la llamada previa
!>          de CGEHRD. Q es igual a la matriz unitaria excepto en la
!>          submatriz Q(ilo+1:ihi,ilo+1:ihi).
!>          Si SIDE = 'L', entonces 1 <= ILO <= IHI <= M, si M > 0, y
!>          ILO = 1 y IHI = 0, si M = 0;
!>          si SIDE = 'R', entonces 1 <= ILO <= IHI <= N, si N > 0, y
!>          ILO = 1 y IHI = 0, si N = 0.
!>

A

!>          A es un array COMPLEX, de dimensión
!>                               (LDA,M) si SIDE = 'L'
!>                               (LDA,N) si SIDE = 'R'
!>          Los vectores que definen los reflectores elementales, como
!>          devueltos por CGEHRD.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.
!>          LDA >= max(1,M) si SIDE = 'L'; LDA >= max(1,N) si SIDE = 'R'.
!>

TAU

!>          TAU es un array COMPLEX, de dimensión
!>                               (M-1) si SIDE = 'L'
!>                               (N-1) si SIDE = 'R'
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), como devuelto por CGEHRD.
!>

C

!>          C es un array COMPLEX, de dimensión (LDC,N)
!>          En la entrada, la matriz C M-por-N.
!>          En la salida, C se sobrescribe con Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión líder del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N);
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Para un rendimiento óptimo LWORK >= N*NB si SIDE = 'L', y
!>          LWORK >= M*NB si SIDE = 'R', donde NB es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          sólo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor en la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

DORMHR

Purpose:

!>
!> DORMHR overwrites the general real M-by-N matrix C with
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>
!> where Q is a real orthogonal matrix of order nq, with nq = m if
!> SIDE = 'L' and nq = n if SIDE = 'R'. Q is defined as the product of
!> IHI-ILO elementary reflectors, as returned by DGEHRD:
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>

Parameters

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': apply Q or Q**T from the Left;
!>          = 'R': apply Q or Q**T from the Right.
!>

TRANS

!>          TRANS is CHARACTER*1
!>          = 'N':  No transpose, apply Q;
!>          = 'T':  Transpose, apply Q**T.
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix C. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix C. N >= 0.
!>

ILO

!>          ILO is INTEGER
!>

IHI

!>          IHI is INTEGER
!>
!>          ILO and IHI must have the same values as in the previous call
!>          of DGEHRD. Q is equal to the unit matrix except in the
!>          submatrix Q(ilo+1:ihi,ilo+1:ihi).
!>          If SIDE = 'L', then 1 <= ILO <= IHI <= M, if M > 0, and
!>          ILO = 1 and IHI = 0, if M = 0;
!>          if SIDE = 'R', then 1 <= ILO <= IHI <= N, if N > 0, and
!>          ILO = 1 and IHI = 0, if N = 0.
!>

A

!>          A is REAL array, dimension
!>                               (LDA,M) if SIDE = 'L'
!>                               (LDA,N) if SIDE = 'R'
!>          The vectors which define the elementary reflectors, as
!>          returned by DGEHRD.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.
!>          LDA >= max(1,M) if SIDE = 'L'; LDA >= max(1,N) if SIDE = 'R'.
!>

TAU

!>          TAU is REAL array, dimension
!>                               (M-1) if SIDE = 'L'
!>                               (N-1) if SIDE = 'R'
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by DGEHRD.
!>

C

!>          C is REAL array, dimension (LDC,N)
!>          On entry, the M-by-N matrix C.
!>          On exit, C is overwritten by Q*C or Q**T*C or C*Q**T or C*Q.
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          If SIDE = 'L', LWORK >= max(1,N);
!>          if SIDE = 'R', LWORK >= max(1,M).
!>          For optimum performance LWORK >= N*NB if SIDE = 'L', and
!>          LWORK >= M*NB if SIDE = 'R', where NB is the optimal
!>          blocksize.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>

NAME

ZUNMHR

untranspose a real block reflector in complex form

SYNOPSIS

 SUBROUTINE ZUNMHR(
  SIDE, TRANS, M, N, K, NB, A, LDA, TAU, WORK, LWORK, INFO
 )

 CHARACTER(LEN=1) SIDE, TRANS
 INTEGER M, N, K, NB, LDA, LWORK, INFO
 COMPLEX(8), DIMENSION( * ) A
 COMPLEX(8), DIMENSION( * ) TAU
 COMPLEX(8), DIMENSION( * ) WORK

Detailed Description

This routine is deprecated. Use ZUNMHQR instead.

ZUNMHR applies a complex block reflector H in real form to a complex matrix.

H is an NBY*NBY block reflector, which is stored in the real array A.

This routine is in the deprecated package.

Arguments:

SIDE

SIDE is CHARACTER*1

='L': apply H left)

='R': apply H right)

Only

='L' is supported in this implementation.

TRANS

TRANS is CHARACTER*1

='T': apply H

='C': apply H**H (or H**T)

M

M is INTEGER

The number of rows of the matrix X to which the tra

to which the transformation is applied.

N

N is INTEGER

The number of columns of the matrix X to which the tra

to which the transformation is applied.

K

K is INTEGER

The number of elementary reflectors whose product forms the block reflector H.

Currently K=M if SIDE='L', and K=N if SIDE='R'.

NB

NB is INTEGER

The number of columns of the block reflector X.

A

A is COMPLEX(8), DIMENSION( LDA, K )

On entry, the NBY*NBY block reflector, to be trans

to be transported.

See Further Details.

LDA

LDA is INTEGER

The leading dimension of the array A.

TAU

TAU is COMPLEX(8), DIMENSION( K )

On entry, the scalar tau(i) which were used to generate the block reflector H.

'T': TAU is COMPLEX(8), DIMENSION( K )

'C': TAU is COMPLEX(8), DIMENSION( K )

WORK

WORK is COMPLEX(8), DIMENSION( LWORK )

On exit, WORK(1) contains the optimal LWORK.

LWORK

LWORK is INTEGER

The dimension of the array WORK.

The number of elements in the array WORK.

if SIDE = 'L', LWORK >= max(1,N);

if SIDE = 'R', LWORK >= max(1,M).

For optimum performance LWORK >= N*NB if SIDE = 'L', and

LWORK >= M*NB if SIDE = 'R', where NB is the optimal

blocksize.

If LWORK = -1, then a workspace query is assumed; the routine

only calculates the optimal size of the WORK array, returns

this value as the first entry of the WORK array, and no error

message related to LWORK is issued by XERBLA.

INFO

INFO is INTEGER

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value
