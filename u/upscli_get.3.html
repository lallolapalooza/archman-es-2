Paquete: nut

UPSCLI_GET(3) Manual de NUT UPSCLI_GET(3)

NOMBRE

upscli_get - Recuperar datos de un SAI

SINOPSIS

        #include <upsclient.h>
        int upscli_get(
                UPSCONN_t *ups,
                size_t numq,
                const char **query,
                size_t *numa,
                char ***answer)

DESCRIPCIÓN

La función upscli_get() toma el puntero ups a una estructura de estado UPSCONN_t, y el puntero query a un array de elementos de consulta numq. Construye una solicitud formateada correctamente a partir de esos elementos y la transmite a upsd(8).

En caso de éxito, la respuesta se dividirá en componentes separados. Un puntero a esos componentes se devolverá en answer. El número de componentes de respuesta utilizables se devolverá en numa.

USOS

Esta función implementa el comando "GET" en el protocolo NUT. Como resultado, puede usarla para solicitar muchas cosas diferentes al servidor.

Algunos ejemplos son:

•GET NUMLOGINS <ups>
•GET UPSDESC <ups>
•GET VAR <ups> <var>
•GET TYPE <ups> <var>
•GET DESC <ups> <var>
•GET CMDDESC <ups> <cmd>

FORMATEO DE CONSULTA

Para generar una solicitud para GET NUMLOGINS su700, usted rellenaría query y numq de la siguiente manera:

        size_t numq;
        const char *query[2];
        query[0] = "NUMLOGINS";
        query[1] = "su700";
        numq = 2;

Todo el escape de caracteres especiales y el entrecomillado de elementos con espacios son manejados por esta función.

FORMATEO DE RESPUESTA

La respuesta cruda de upsd a la consulta anterior sería NUMLOGINS su700 1.

Dado que esto se divide por usted, los valores funcionan de la siguiente manera:

        size_t numa;
        numa = 3;
        answer[0] = "NUMLOGINS"
        answer[1] = "su700"
        answer[2] = "1"

Observe que el valor que busca típicamente comienza en answer[numq].

VERIFICACIÓN DE ERRORES

Esta función verificará su consulta contra la respuesta del servidor de datos upsd(8).

Por ejemplo, si envía "VAR" "su700" "ups.status", esperará ver esos al principio de la respuesta.

Si los resultados de upsd no pasan esta prueba insensible a mayúsculas y minúsculas contra su solicitud, esta función devolverá un error. Cuando esto sucede, upscli_upserror(3) devolverá UPSCLI_ERR_PROTOCOL.

VIDA ÚTIL DEL ARRAY DE RESPUESTA

Los punteros contenidos dentro del array answer solo son válidos hasta la próxima llamada a una función upsclient que los referencie. Si necesita usar datos de múltiples llamadas, debe copiarlos a otro lugar primero.

El array answer y sus elementos pueden cambiar de ubicación, por lo que no debe confiar en direcciones anteriores. Solo debe usar las direcciones que fueron devueltas por la llamada más reciente. Tampoco debe intentar usar más de numa elementos en answer. Tal comportamiento no está definido y puede producir datos falsos o un bloqueo.

El array se eliminará después de llamar a upscli_disconnect(3). Cualquier acceso después de ese punto tampoco está definido.

VALOR DE RETORNO

La función upscli_get() devuelve 0 en caso de éxito, o -1 si ocurre un error.

Si upsd se desconecta, es posible que deba manejar o ignorar SIGPIPE para evitar que su programa termine la próxima vez que la biblioteca escriba en el socket desconectado.

El siguiente código en su función de inicialización permitirá que la llamada upscli_get() devuelva un error en ese caso:

        #include <signal.h>
        ...
        signal (SIGPIPE, SIG_IGN);
        ...
