NOMBRE

uil — El compilador del lenguaje de interfaz de usuario

SINOPSIS

uil [opciones ] [archivo]

DESCRIPCIÓN

El comando uil invoca al compilador UIL. El Lenguaje de Interfaz de Usuario (UIL) es un lenguaje de especificación para describir el estado inicial de una interfaz de usuario para una aplicación Motif. La especificación describe los objetos (menús, cuadros de diálogo, etiquetas, botones pulsadores, etc.) utilizados en la interfaz y especifica las rutinas que se llamarán cuando la interfaz cambie de estado como resultado de la interacción del usuario.

archivo
Especifica el archivo que se compilará a través del compilador UIL.
opciones
Especifica una o más de las siguientes opciones:
-Iruta
Esta opción hace que el compilador busque archivos de inclusión en el directorio especificado si los archivos de inclusión no se han encontrado en las rutas que ya se han buscado. Especifique esta opción seguida de una ruta, sin espacios intermedios.
-m
Se lista el código máquina. Esto indica al compilador que coloque en el archivo de listado una descripción de los registros que añadió a la Base de Datos de Interfaz de Usuario (UID). Esto le ayuda a aislar errores. El valor predeterminado es sin código máquina.
-o archivo
Indica al compilador que produzca un UID. Por defecto, UIL crea un UID con el nombre a.uid. El archivo especifica el nombre de archivo para el UID. No se produce ningún UID si el compilador emite algún diagnóstico clasificado como error o grave. Los UID solo son portátiles entre arquitecturas de máquina de igual tamaño.
-s
Indica al compilador que establezca la configuración regional antes de compilar cualquier archivo. La configuración regional se establece de manera dependiente de la implementación. En sistemas basados en C ANSI, la configuración regional generalmente se establece llamando a setlocale(LC_ALL, ""). Si no se especifica esta opción, el compilador no establece la configuración regional.
-v archivo
Indica al compilador que genere un listado. El archivo especifica el nombre de archivo para el listado. Si la opción -v no está presente, el compilador no genera ningún listado. El valor predeterminado es sin listado.
-w
Especifica que el compilador suprima todos los mensajes de advertencia e informativos. Si no se especifica esta opción, se generan todos los mensajes, independientemente de la gravedad.
-wmd archivo
Especifica un archivo de descripción binario del meta-lenguaje de widgets que se utilizará en lugar de la descripción WML predeterminada.
