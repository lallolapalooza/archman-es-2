NOMBRE

url_lfs_rewrite - un reescritor de URL basado en la existencia de archivos locales

SINOPSIS

url_lfs_rewrite [--debug] --local-dir=/var/www/ [opciones]

DESCRIPCIÓN

Dirige todas las solicitudes de archivos que están en un directorio local a un servidor web local que aloja este directorio.

Este programa utiliza el soporte de concurrencia de Squid.

OPCIONES

--debug
Escribe información de depuración en stderr.
--local-dir
Ruta del directorio bajo la cual los scripts buscan archivos.
--to-scheme
Esquema a usar para la URL redirigida. 
Por defecto: http
--to-host
Nombre de dominio a usar para la URL redirigida. 
Por defecto: localhost
--to-path
Ruta de URL a añadir como prefijo para la ruta de la URL redirigida.

Si se establece, debe terminar en '/'.

Por defecto: usa la ruta de la URL original.

PROBLEMAS CONOCIDOS

* El parámetro --local-dir debe terminar con '/'. De lo contrario, no se
encontrarán rutas de archivo.

* Las URL sin nombre de archivo en la ruta pueden coincidir con directorios en el sistema de
archivos local y ser redirigidas erróneamente al servidor web local.

* Cualquier nombre de esquema aceptado por la biblioteca de URL de Perl puede ser utilizado
como parámetro --to-scheme. Sin embargo, solo los esquemas soportados por
Squid funcionarán.

* Las URL que contienen cadenas de consulta no se manejan bien y no se
reescribirán, incluso si el script base o el archivo existe en el sistema
local.

CONFIGURACIÓN

url_rewrite_program /ruta/a/url_lfs_rewrite --local-dir=/var/www/localhost
url_rewrite_children 20 startup=1 idle=1 concurrency=25
url_rewrite_access deny CONNECT
url_rewrite_access deny to_localhost

Este ayudante puede redirigir a cualquier servidor web, pero solo lo hace si existe un archivo que coincida con el segmento de la ruta de la URL en el sistema de archivos local. La configuración normal requiere un servidor web ejecutándose en localhost que sirva archivos desde un disco local (por ejemplo, /var/www/localhost). La configuración de ese servidor web no se cubre aquí.
