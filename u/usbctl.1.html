USBCTL(1) Manual de usbctl USBCTL(1)

NOMBRE

usbctl - Control para deny_new_usb reforzado en Linux

SINOPSIS

usbctl [COMANDO]

DESCRIPCIÓN

Controla los dispositivos USB y la configuración de protección.

COMANDOS

protect, disable, off

Deniega nuevos dispositivos USB (protegido)

unprotect, enable, on

Permite nuevos dispositivos USB (desprotegido)

temporary, temp, tmp

Desactiva temporalmente la protección (por defecto 60 segundos)

check

Sale con código 1 si el USB no está protegido

status

Muestra el estado actual de protección

list, ls

Lista los dispositivos USB conectados actualmente

log

Muestra los eventos USB en el búfer de anillo del kernel

version

Muestra la información de la versión y sale

VERSIÓN

1.2

PÁGINA PRINCIPAL

https://github.com/anthraxx/usbctl
