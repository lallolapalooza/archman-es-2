void data_dump (FILE * f, void * buf, uint32_t n)

Esto vuelca un número de bytes a un volcado textual hexadecimal.

Parámetros

f el archivo al que volcar (por ejemplo, stdout o stderr)
buf un puntero al búfer que contiene los bytes a volcar en formato hexadecimal
n el número de bytes a volcar de este búfer

void data_dump_ascii (FILE * f, void * buf, uint32_t n, uint32_t dump_boundry)

Esto vuelca un número de bytes a un volcado textual hexadecimal, y también imprime la representación ASCII de la cadena para cada línea de bytes. También imprimirá el desplazamiento de la dirección de memoria desde un cierto límite.

Parámetros

f el archivo al que volcar (por ejemplo, stdout o stderr)
buf un puntero al búfer que contiene los bytes a volcar en formato hexadecimal
n el número de bytes a volcar de este búfer
dump_boundry el desplazamiento de la dirección desde el que empezar (normalmente 0)

void device_unknown (const int dev_number, const int id_vendor, const int id_product)

Esto imprime en stdout información sobre un dispositivo DESCONOCIDO, sus IDs y el número de versión de libmtp.

Parámetros

dev_number el número del dispositivo
id_vendor ID del proveedor de la estructura usb_device_desc
id_product ID del producto de la estructura usb_device_desc

Referenciado por LIBMTP_Detect_Raw_Devices() y LIBMTP_Detect_Raw_Devices().
