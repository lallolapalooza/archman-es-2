NOMBRE

umoci tag - Crear etiquetas en imágenes OCI

SINOPSIS

umoci tag --image=imagen[:etiqueta] nueva-etiqueta

DESCRIPCIÓN

Crea una nueva etiqueta que es una copia de etiqueta con el nombre nueva-etiqueta. Si nueva-etiqueta ya existe, será reemplazada. La etiqueta original no se modificará.

OPCIONES

--image=imagen[:etiqueta]
La etiqueta de la imagen OCI de origen de la que se creará una copia. imagen debe ser una ruta a
una imagen OCI válida y etiqueta debe ser una etiqueta válida en la imagen. Si
no se proporciona etiqueta, se usará "latest" por defecto.

EJEMPLO

Lo siguiente intercambia dos etiquetas de imagen en una imagen OCI.

% umoci tag --image imagen:a-cambiar nueva
% umoci tag --image imagen:latest a-cambiar
% umoci tag --image imagen:nueva ultima
% umoci rm --image imagen:nueva
