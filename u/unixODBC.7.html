NOMBRE

unixODBC - Una implementación de ODBC para Unix

DESCRIPCIÓN

ODBC es una especificación abierta que proporciona a los desarrolladores de aplicaciones una API predecible con la que acceder a fuentes de datos. Las fuentes de datos incluyen servidores SQL y cualquier fuente de datos con un controlador ODBC.

Los objetivos del proyecto unixODBC son desarrollar y promover unixODBC como el estándar definitivo para ODBC en plataformas no Windows.

El "Manual del Administrador" con formato HTML que se incluye con unixODBC proporciona detalles adicionales sobre la configuración y el uso para complementar estas páginas del manual.

VARIABLES DE ENTORNO

ODBCSYSINI
Establece la ruta completa al directorio que contiene los archivos de configuración de unixODBC. Por defecto, es '/etc'.
ODBCINSTINI
Establece el nombre del archivo de configuración del controlador de unixODBC. El nombre del archivo es relativo a ODBCSYSINI y por defecto se establece en 'odbcinst.ini'.
ODBCINI
Establece la ruta completa al archivo de configuración de unixODBC a nivel del sistema que contiene los Nombres de Fuentes de Datos (DSN). Por defecto, se establece en '/etc/odbc.ini'.
ODBCINSTUI
Establece el nombre de la biblioteca para la interfaz de usuario. El nombre final que se busca se evalúa como "lib$ODBCINSTUI". Por defecto, esta variable se establece en 'odbcinstQ4', por lo que el nombre de la biblioteca resultante es 'libodbcinstQ4'.
ODBCSEARCH
Establece el modo de configuración y determina dónde buscar los archivos de configuración. Esta variable debe establecerse en uno de ODBC_SYSTEM_DSN, ODBC_USER_DSN u ODBC_BOTH_DSN, que es el valor por defecto.
