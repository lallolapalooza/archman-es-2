NOMBRE

umoci config - Modifica la configuración de una imagen OCI

SINOPSIS

umoci config --image=imagen[:etiqueta] [--tag=nueva-etiqueta] [--no-history] [--history.comment=comentario] [--history.created_by=creado_por] [--history.author=autor] [--history-created=fecha] [--clear=valor] [--config.user=valor] [--config.exposedports=valor] [--config.env=valor] [--config.entrypoint=valor] [--config.cmd=valor] [--config.volume=valor] [--config.label=valor] [--config.workingdir=valor] [--created=valor] [--author=valor] [--architecture=valor] [--os=valor] [--manifest.annotation=valor]

DESCRIPCIÓN

Modifica la configuración y los datos del manifiesto para una imagen OCI etiquetada específica -- sobrescribiéndola a menos que especifique --tag. Si no se especificó --no-history, se añade una entrada de historial a la imagen OCI etiquetada para este cambio (con las diversas banderas --history. controlando los valores utilizados). Para ver el historial, consulte umoci-stat(1).

Tenga en cuenta que la etiqueta de imagen original (el argumento de --image) no se modificará a menos que el destino de umoci-config(1) sea la etiqueta de imagen original.

OPCIONES

Las opciones globales se definen en umoci(1).

--image=imagen[:etiqueta]
La imagen OCI etiquetada de origen cuya configuración será modificada. imagen debe ser
una ruta a una imagen OCI válida y etiqueta debe ser una etiqueta válida en la imagen. Si
no se proporciona etiqueta, se usará por defecto "latest".

--tag=nueva-etiqueta
Nombre de etiqueta para la imagen modificada, si no se especifica, la etiqueta
original proporcionada a --image será sobrescrita.

--no-history
Provoca que no se añada ninguna entrada de historial para esta operación.

--history.comment=comentario
Comentario para la entrada de historial correspondiente a esta modificación de la
configuración de la imagen. Si no se especifica, umoci(1) generará un
valor dependiente de la implementación.

--history.created_by=creado_por
Entrada CreatedBy para la entrada de historial correspondiente a esta modificación de
la configuración de la imagen. Si no se especifica, umoci(1) generará
un valor dependiente de la implementación.

--history.author=autor
Valor del autor para la entrada de historial correspondiente a esta modificación de la
configuración de la imagen. Si no se especifica, este valor será el valor del autor de la imagen
después de cualquier modificación realizada por esta llamada a
umoci-config(1).

--history-created=fecha
Fecha de creación para la entrada de historial correspondiente a estas modificaciones de
la configuración de la imagen. Debe ser una marca de tiempo con formato ISO8601 (ver
date(1)). Si no se especifica, se utiliza la hora actual.

--clear=valor
Elimina todas las entradas preexistentes para una opción de configuración de conjunto o lista dada
(no revertirá ninguna modificación realizada por esta llamada a umoci-config(1)).
Los valores válidos de valor son:

* config.labels
* manifest.annotations
* config.exposedports
* config.env
* config.entrypoint
* config.cmd
* config.volume

Los siguientes comandos establecen sus valores correspondientes en la configuración o manifiesto de la imagen. Para más información, consulte la especificación de la imagen OCI ⟨https://github.com/opencontainers/image-spec⟩.

  • --config.user=valor
  • --config.exposedports=valor
  • --config.env=valor
  • --config.entrypoint=valor
  • --config.cmd=valor
  • --config.volume=valor
  • --config.label=valor
  • --config.workingdir=valor
  • --created=valor
  • --author=valor
  • --architecture=valor
  • --os=valor
  • --manifest.annotation=valor

EJEMPLO

Lo siguiente modifica la configuración de una imagen OCI de varias maneras y sobrescribe la etiqueta original con la nueva imagen.

% umoci config --image image:tag --clear=config.env --config.env="VARIABLE=true" \
	--config.user="user:group" --config.entrypoint=cat --config.cmd=/proc/self/stat \
	--config.label="com.cyphar.umoci=true" --author="Aleksa Sarai <asarai@suse.de>" \
	--os="gnu/hurd" --architecture="lisp" --created="$(date --iso-8601=seconds)"
