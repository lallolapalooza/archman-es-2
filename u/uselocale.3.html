uselocale(3) Manual de funciones de biblioteca uselocale(3)

NOMBRE

uselocale - establece/obtiene la configuración regional para el hilo llamante

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <locale.h>
locale_t uselocale(locale_t newloc);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

uselocale():

    Desde glibc 2.10:
        _XOPEN_SOURCE >= 700
    Antes de glibc 2.10:
        _GNU_SOURCE

DESCRIPCIÓN

La función uselocale() establece la configuración regional actual para el hilo llamante y devuelve la configuración regional anteriormente actual de dicho hilo. Después de una llamada exitosa a uselocale(), cualquier llamada realizada por este hilo a funciones que dependen de la configuración regional operará como si la configuración regional se hubiera establecido en newloc.

El argumento newloc puede tener uno de los siguientes valores:

Un manejador devuelto por una llamada a
newlocale(3) o duplocale(3) La configuración regional actual del hilo llamante se establece en la configuración regional especificada.
El objeto especial de configuración regional
LC_GLOBAL_LOCALE La configuración regional actual del hilo llamante se establece en la configuración regional global determinada por setlocale(3).
(locale_t) 0
La configuración regional actual del hilo llamante no se modifica (y la configuración regional actual se devuelve como resultado de la función).

VALOR DE RETORNO

En caso de éxito, uselocale() devuelve el manejador de configuración regional que fue establecido por la llamada anterior a uselocale() en este hilo, o LC_GLOBAL_LOCALE si no hubo tal llamada anterior. En caso de error, devuelve (locale_t) 0 y establece errno para indicar el error.

ERRORES

EINVAL
newloc no hace referencia a un objeto de configuración regional válido.

ESTANDARES

POSIX.1-2008.

HISTORIAL

glibc 2.3. POSIX.1-2008.

NOTAS

A diferencia de setlocale(3), uselocale() no permite el reemplazo selectivo de categorías de configuración regional individuales. Para emplear una configuración regional que difiere solo en algunas categorías de la configuración regional actual, use llamadas a duplocale(3) y newlocale(3) para obtener un objeto de configuración regional equivalente a la configuración regional actual y modifique las categorías deseadas en ese objeto.

EJEMPLOS

Ver newlocale(3) y duplocale(3).

VER TAMBIÉN

locale(1), duplocale(3), freelocale(3), newlocale(3), setlocale(3), locale(5), locale(7)
