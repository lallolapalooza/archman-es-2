UPSSTATS.CGI(8) Manual de NUT UPSSTATS.CGI(8)

NOMBRE

upsstats.cgi - Visor de estado de UPS basado en web

SINOPSIS

upsstats.cgi


Nota

Como programa CGI, debe ser invocado a través de su servidor web. Si lo ejecuta desde la línea de comandos, se quejará de acceso no autorizado o le mostrará un montón de HTML.

DESCRIPCIÓN

upsstats.cgi utiliza archivos de plantilla para crear páginas web que contienen información de estado del hardware de la UPS. Puede repetir secciones de esas plantillas para monitorizar varias UPS simultáneamente, o centrarse en una única UPS.

Estas plantillas también pueden incluir referencias a upsimage.cgi(8) para mostrar gráficos de niveles de carga de batería, lecturas de voltaje y la carga de la UPS.

CONTROL DE ACCESO

upsstats solo se comunicará con los servidores upsd(8) que hayan sido definidos en su hosts.conf(5). Si se queja de que "El acceso a ese host no está autorizado", revise ese archivo primero.

PLANTILLAS

La página web que se muestra es en realidad una plantilla que contiene comandos para upsstats que se reemplazan por información de estado.

El archivo predeterminado utilizado para la vista general de los dispositivos es upsstats.html.

Al monitorizar una única UPS, el archivo que se muestra es upsstats-single.html.

El formato de estos archivos, incluyendo los comandos posibles, se documenta en upsstats.html(5).

ARCHIVOS

hosts.conf(5), upsstats.html(5), upsstats-single.html

VER TAMBIÉN

upsimage.cgi(8)
