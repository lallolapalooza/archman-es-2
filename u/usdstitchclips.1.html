NOMBRE

usdstitchclips - página del manual para usdstitchclips 25.11

DESCRIPCIÓN

uso: usdstitchclips [-h] [-o OUT] [-c CLIPPATH] [-s STARTTIMECODE]

[-r STRIDE] [-e ENDTIMECODE] [-t] [-p TEMPLATEPATH]
[--clipSet CLIPSET] [--activeOffset ACTIVEOFFSET] [--interpolateMissingClipValues] [-n] usdFiles [usdFiles ...]

Une múltiples archivos USD juntos en uno usando clips de valor. Un ejemplo de comando es:

usdstitchclips --out result.usd --clipPath /World/fx/Particles_Splash clip1.usd clip2.usd

Esto producirá dos archivos, un result.topology.usd y un result.usd.

argumentos posicionales:

usdFiles

opciones:

-h, --help
mostrar este mensaje de ayuda y salir
-o, --out OUT
especificar el nombre del archivo para el archivo de resultado de nivel superior, que también sirve como nombre base para los archivos de topología y manifiesto.
-c, --clipPath CLIPPATH
especificar una ruta de prim donde comenzar a unir datos de clips.
-s, --startTimeCode STARTTIMECODE
especificar el tiempo en el que los clips se activarán
-r, --stride STRIDE
especificar un paso para el componente numérico de los nombres de archivo para metadatos de plantilla
-e, --endTimeCode ENDTIMECODE
especificar el tiempo en el que los clips dejarán de estar activos
-t, --templateMetadata
autorizar metadatos de plantilla de clip en la capa raíz.
-p, --templatePath TEMPLATEPATH
especificar una ruta de activo de plantilla para autorizar
--clipSet CLIPSET
especificar un clipSet con nombre en el que autorizar metadatos de clip, para que se puedan aplicar múltiples conjuntos de clips en la misma prim.
--activeOffset ACTIVEOFFSET
especificar un desplazamiento para los clips basados en plantillas, desplazando el número de fotograma de cada archivo de clip.
--interpolateMissingClipValues
especificar si los valores para clips sin muestras autorizadas se interpolan a partir de clips circundantes si no se autoriza ningún valor predeterminado en ningún clip.
-n, --noComment
no escribir un comentario que especifique cómo se generó el archivo usd
