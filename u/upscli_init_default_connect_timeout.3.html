upscli_init_default_connect_timeout(3)

Paquete: nut

Licencias: GPL-2.0-or-later AND GPL-3.0-or-later

UPSCLI_INIT_DEFAULT_(3) Manual de NUT UPSCLI_INIT_DEFAULT_(3)

NOMBRE

upscli_init_default_connect_timeout - Inicializa el aspecto del módulo upsclient del tiempo de espera de conexión predeterminado.

SINOPSIS

        #include <upsclient.h>
        int upscli_init_default_connect_timeout(
                const char *cli_secs,
                const char *config_secs,
                const char *default_secs);

DESCRIPCIÓN

La función upscli_init_default_connect_timeout() inicializa el aspecto del módulo upsclient del tiempo de espera de conexión predeterminado para upscli_connect(3), lo cual puede ser importante cuando, por ejemplo, los scripts de upsc(8) o la configuración de upsmon(8) se refieren a hosts no responsivos, o cuando la resolución de nombres de host se retrasa, etc. Por defecto, upscli_connect(3) se bloquea indefinidamente en sus intentos de conexión (o hasta que la capa de transporte del sistema interrumpe dicho intento).

Rellena el valor de diferentes fuentes, en su mayoría cadenas de caracteres que representan un número no negativo de punto flotante (el análisis inválido se registra y puede afectar el valor de retorno), cualquiera o todas ellas pueden ser NULL para omitirlas, y en un orden específico (la última coincidencia válida gana):

• 0 incorporado que significa bloqueo indefinido (predeterminado de NUT para este método durante al menos 20 años);
• el número de default_secs como un valor predeterminado preferido (de baja prioridad) incorporado en un cliente NUT particular o de terceros;
• el número de la variable de entorno NUT_DEFAULT_CONNECT_TIMEOUT como una preferencia local del sitio (generalmente preestablecida en nut.conf(5));
• el número de config_secs como un valor predeterminado de archivo de configuración de un cliente NUT particular o de terceros;
• el número de cli_secs como una configuración particular de un cliente NUT o de terceros desde la línea de comandos (mayor prioridad).

Internamente, llama a upscli_set_default_connect_timeout(3) para la mayor parte del procesamiento relacionado con cadenas.

El módulo upsclient rastrea si la función upscli_init_default_connect_timeout() fue llamada y tuvo éxito, para llamarla una vez (si nunca se usó) desde los métodos upscli_connect(3) o upscli_init(3). Esto permite que los clientes NUT no modificados (heredados) se beneficien consistentemente de la presencia de la variable de entorno NUT_DEFAULT_CONNECT_TIMEOUT.

Este rastreo no impide que los programas llamen explícitamente al método cualquier cantidad de veces.

VALOR DE RETORNO

La función upscli_init_default_connect_timeout() devuelve 0 en caso de éxito (ya sea si todas las cadenas eran NULL, por lo que se aplicó el valor predeterminado incorporado, o al menos una de las cadenas que se establecieron era válida y su valor se aplicó), o -1 si ocurre un error (al menos una cadena no era NULL, y ninguna de las cadenas era válida).

VER TAMBIÉN

upscli_connect(3), upscli_tryconnect(3), upscli_set_default_connect_timeout(3), upscli_get_default_connect_timeout(3), upscli_init(3)
