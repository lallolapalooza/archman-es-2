NOMBRE

unw_regname -- obtener nombre de registro

SINOPSIS

#include <libunwind.h>

const char *unw_regname(unw_regnum_t regnum);

DESCRIPCIÓN

La rutina unw_regname() devuelve un nombre imprimible para el registro regnum. Si regnum es un número de registro inválido o no reconocido de otro modo, se devuelve una cadena que consta de tres signos de interrogación. La cadena devuelta se asigna estáticamente y, por lo tanto, se garantiza que permanecerá válida hasta que la aplicación termine.

VALOR DEVUELTO

La rutina unw_regname() no puede fallar y siempre devuelve una cadena válida (no NULL).

SEGURIDAD PARA HILOS Y SEÑALES

La rutina unw_regname() es segura para hilos y también segura para usar desde un manejador de señales.
