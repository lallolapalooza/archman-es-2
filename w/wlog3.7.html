NOMBRE

wLog - Sistema de registro de WinPR

DESCRIPCIÓN

wLog es un sistema de registro configurable y flexible utilizado en todo WinPR y FreeRDP.

El concepto principal es tener una jerarquía de registradores que puedan configurarse de forma independiente.

Apéndices

WLog utiliza diferentes apéndices que definen dónde se deben escribir las salidas del registro. Si la aplicación no configura explícitamente los apéndices, la variable WLOG_APPENDER descrita a continuación puede usarse para elegir un apéndice.

Los siguientes tipos de apéndices están disponibles:

Binario
Escribe los datos del registro en un archivo de formato binario.
Consola
El apéndice de consola escribe en la consola. Dependiendo del sistema operativo en el que se ejecute la aplicación, la salida puede manejarse de forma diferente. Por ejemplo, en Android se utilizaría la impresión de registros.
Archivo
El apéndice de archivo escribe la salida textual en un archivo.
Udp
Este apéndice envía los mensajes de registro a un host remoto predefinido vía UDP.

Si no se establece un destino, se utiliza el predeterminado 127.0.0.1:20000. Para recibir los mensajes de registro, se puede usar netcat. Para recibir el destino predeterminado, se puede usar el siguiente comando: nc -u 127.0.0.1 -p 20000 -l

Syslog
Utiliza syslog para la salida de los mensajes de depuración.
Journald
Este apéndice envía mensajes a journald.

Niveles

Los niveles de WLog son complementarios, el nivel superior siempre incluye los inferiores. La lista de niveles a continuación está de arriba hacia abajo. Arriba el nivel más alto.

TRACE
imprime todo, incluidas las volcamientos de paquetes
DEBUG
mensajes de depuración
INFO
información general
WARN
advertencias
ERROR
errores
FATAL
problemas fatales
OFF
desactiva completamente la salida de wlog

Formatos

El formato que imprime un registrador tiene las siguientes opciones posibles:

lv
nivel de registro
mn
nombre del módulo
fl
nombre del archivo
fn
función
ln
número de línea
pid
id del proceso
tid
id del hilo
yr
año
mo
mes
dw
día de la semana
hr
hora
mi
minuto
se
segundo
ml
milisegundo

Se pueden usar un máximo de 16 opciones por cadena de formato.

Un ejemplo que generalmente establece el prefijo WLOG para xfreerdp sería: WLOG_PREFIX="pid=%pid:tid=%tid:fn=%fn -" xfreerdp /v:xxx

AMBIENTE

WLOG_APPENDER
El tipo de apéndice, los valores aceptados son: CONSOLE, FILE, BINARY, SYSLOG, JOURNALD o UDP
WLOG_PREFIX
configura el prefijo utilizado para la salida del mensaje (ver Formato para más detalles y ejemplos)
WLOG_LEVEL
el nivel para el cual se muestran los mensajes
WLOG_FILTER
establece un filtro para los mensajes de WLog. Solo se imprimen los mensajes filtrados. El formato del filtro es una serie de <nombre del registrador>:<nivel> separados por comas

ejemplo: WLOG_FILTER=core.channel:DEBUG,dummy:TRACE mostrará mensajes de depuración para el registrador core.channel y nivel de trazado para el registrador dummy

WLOG_FILEAPPENDER_OUTPUT_FILE_PATH
Cuando se utiliza el apéndice de archivo, puede contener la ruta del archivo de registro de salida
WLOG_FILEAPPENDER_OUTPUT_FILE_NAME
Cuando se utiliza el apéndice de archivo, puede contener el nombre del archivo de registro de salida
WLOG_JOURNALD_ID
Cuando se utiliza el apéndice de journal de systemd, esta variable contiene el id utilizado con el journal (por defecto el nombre del ejecutable)
WLOG_UDP_TARGET
destino a usar para el apéndice UDP en el formato host:puerto

ERRORES

Por favor, reporte cualquier error utilizando el formulario de reporte de errores en el sitio web de FreeRDP
