WMENU(1) Manual de comandos generales WMENU(1)

NOMBRE

wmenu - menú dinámico para Wayland

SINOPSIS

wmenu [-biPv]
[-f fuente]
[-l líneas]
[-o salida]
[-p indicador]
[-N color] [-n color]
[-M color] [-m color]
[-S color] [-s color]

wmenu-run ...

DESCRIPCIÓN

wmenu es un menú dinámico para Wayland, que lee una lista de elementos separados por saltos de línea desde la entrada estándar (stdin). Cuando el usuario selecciona un elemento y presiona Enter, su elección se imprime en la salida estándar (stdout) y wmenu termina. Escribir texto reducirá los elementos a aquellos que coincidan con los tokens en la entrada.

wmenu-run es una invocación especial de wmenu que lista los programas en el $PATH del usuario y ejecuta el resultado.

OPCIONES

-b

wmenu aparece en la parte inferior de la pantalla.

-i

wmenu compara los elementos del menú sin distinguir mayúsculas y minúsculas.

-P

wmenu no mostrará la entrada del teclado directamente, sino que la reemplazará con asteriscos.

-v

imprime información de la versión en stdout y sale.

-f fuente

define la fuente utilizada. Para más información, ver https://docs.gtk.org/Pango/type_func.FontDescription.from_string.html

-l líneas

wmenu lista los elementos verticalmente, con el número dado de líneas.

-o salida

wmenu se muestra en la salida con el nombre dado.

-p indicador

define el indicador que se mostrará a la izquierda del campo de entrada.

-N RRGGBB[AA]

define el color de fondo normal.

-n RRGGBB[AA]

define el color de primer plano normal.

-M RRGGBB[AA]

define el color de fondo del indicador.

-m RRGGBB[AA]

define el color de primer plano del indicador.

-S RRGGBB[AA]

define el color de fondo de la selección.

-s RRGGBB[AA]

define el color de primer plano de la selección.

USO

wmenu se controla completamente con el teclado. Los elementos se seleccionan usando las teclas de flecha, Av Pág, Re Pág, Inicio y Fin.

Tab

Copia el elemento seleccionado al campo de entrada.

Enter

Confirma la selección. Imprime el elemento seleccionado en stdout y sale, devolviendo éxito.

Ctrl-Enter

Confirma la selección. Imprime el elemento seleccionado en stdout y continúa.

Shift-Enter

Confirma la entrada. Imprime el texto de entrada en stdout y sale, devolviendo éxito.

Escape

Sale sin seleccionar un elemento, devolviendo fallo.

Ctrl-Izquierda

Mueve el cursor al inicio de la palabra actual.

Ctrl-Derecha

Mueve el cursor al final de la palabra actual.
