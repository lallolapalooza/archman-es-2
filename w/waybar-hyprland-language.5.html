waybar-hyprland-language(5) Manual de formatos de archivo waybar-hyprland-language(5)

NOMBRE

waybar - módulo de idioma de hyprland

DESCRIPCIÓN

El módulo language muestra el idioma seleccionado actualmente.

CONFIGURACIÓN

Abordado por hyprland/language

format:
tipo: string
predeterminado: {}
El formato, cómo se debe mostrar la información.

format-<idioma>
tipo: string
Proporciona un nombre alternativo para mostrar por idioma, donde <idioma> es el idioma de tu elección. Se puede pasar varias veces con varios idiomas, como se muestra en el ejemplo a continuación.

keyboard-name:
tipo: string
Especifica qué teclado usar de la salida de dispositivos de hyprctl. Se recomienda usar la opción que comienza con "at-translated-set...".

menu:
tipo: string
Acción que abre el menú emergente.

menu-file:
tipo: string
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: bool
predeterminado: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

{short}: Nombre corto del diseño (p. ej., "us"). Igual a {}.

{shortDescription}: Descripción corta del diseño (p. ej., "en").

{long}: Nombre largo del diseño (p. ej., "Inglés (Dvorak)").

{variant}: Variante del diseño (p. ej., "dvorak").

EJEMPLOS

"hyprland/language": {
	"format": "Idioma: {long}",
	"format-en": "AMÉRICA, ¡ASÍ SE HACE!",
	"format-tr": "As bayrakları",
	"keyboard-name": "at-translated-set-2-keyboard"
}
