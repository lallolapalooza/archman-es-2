Description

This manual page describes the functions and data structures provided by the libcaca library for managing text windows, drawing shapes, and handling events.

The library provides functions to create, free, and manipulate text-based canvases. These canvases can be used to draw text, shapes, and images.

The `caca_conio_text_info` structure is used to store information about the current text cursor position within a window.

Detailed Description

The functions listed in the SYNOPSIS section provide a comprehensive API for creating and managing text-based graphical interfaces. You can create canvases of a specified size, draw various graphical primitives like text, boxes, lines, points, circles, and ellipses. The library also supports drawing images and monitors onto the canvas.

Canvas manipulation functions allow clearing the canvas, inverting its colors, and changing its size. You can also set and get the canvas title, and handle user input events by setting an event handler.

The library offers flexible options for display and rendering, including setting the display width and height, configuring color conversion methods, and choosing dither algorithms.

For importing and exporting data, libcaca supports various formats such as ASCII, UTF-8, RGBA, and native libcaca formats, both from files and memory buffers.

Cursor management functions allow controlling the visibility, position, and shape of the text cursor.

The `caca_conio_text_info` structure contains two members:

unsigned char caca_conio_text_info::curx
The x-coordinate of the cursor in the current window.
unsigned char caca_conio_text_info::cury
The y-coordinate of the cursor in the current window.
