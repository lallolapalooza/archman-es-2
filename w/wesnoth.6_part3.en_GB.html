OPCIONES

Estas son las opciones disponibles para ejecutar el juego desde la línea de comandos:

--algorithm número:valor
selecciona un algoritmo no estándar que será utilizado por el controlador de IA para este bando. El algoritmo se define mediante una etiqueta [ai], que puede ser una etiqueta principal en "data/ai/ais" o "data/ai/dev" o un algoritmo definido por un complemento. Los valores disponibles incluyen: idle_ai y experimental_ai.
--controller número:valor
selecciona el controlador para este bando. Valores disponibles: human, ai y null.
--era valor
usa esta opción para jugar en la era seleccionada en lugar de la era Default. La era se elige por un id. Las eras se describen en el archivo data/multiplayer/eras.cfg.
--exit-at-end
sale una vez que el escenario ha terminado, sin mostrar el diálogo de victoria/derrota que normalmente requiere que el usuario haga clic en Finalizar Escenario. Esto también se utiliza para la evaluación comparativa (benchmarking) de guiones.
--ignore-map-settings
no utilizar la configuración del mapa, utilizar valores predeterminados en su lugar.
--label etiqueta
establece la etiqueta para las IAs.
--multiplayer-repeat valor
repite una partida multijugador valor veces. Es mejor usarlo con --nogui para la evaluación comparativa basada en guiones.
--parm número:nombre:valor
establece parámetros adicionales para este bando. Este parámetro depende de las opciones utilizadas con --controller y --algorithm. Solo debería ser útil para personas que diseñan su propia IA. (aún no documentado completamente)
--scenario valor
selecciona un escenario multijugador por su id. El id del escenario predeterminado es multiplayer_The_Freelands.
--side número:valor
selecciona una facción de la era actual para este bando. La facción se elige por un id. Las facciones se describen en el archivo data/multiplayer.cfg.
--turns valor
establece el número de turnos para el escenario elegido. Por defecto no hay límite de turnos establecido.

CÓDIGO DE SALIDA

El código de salida normal es 0. Un código de salida de 1 indica un error de inicialización (SDL, video, fuentes, etc.). Un código de salida de 2 indica un error con las opciones de la línea de comandos.
Al ejecutar pruebas unitarias (con  -u), el código de salida es diferente. Un código de salida de 0 indica que la prueba pasó, y 1 indica que la prueba falló. Un código de salida de 3 indica que la prueba pasó, pero produjo un archivo de repetición inválido. Un código de salida de 4 indica que la prueba pasó, pero la repetición produjo errores. Estos dos últimos solo se devuelven si no se pasa --noreplaycheck.
