WVUNPACK(1) Manual de comandos generales WVUNPACK(1)

NOMBRE

wvunpack — decodifica archivos codificados con wavpack

SINOPSIS

wvunpack [-opciones] [-o salida] archivo ...

DESCRIPCIÓN

wvunpack decodifica archivos WavPack de vuelta a su forma original sin comprimir. A menos que se anule con el modificador -o, el nombre del archivo de salida será el nombre del archivo fuente con la extensión original del archivo reemplazando la extensión “.wv” de WavPack. También es posible generar audio sin cabeceras usando la opción --raw. Se pueden especificar múltiples archivos de entrada WavPack, lo que resultará en múltiples archivos de salida, y en ese caso se puede usar -o para especificar un directorio de destino alternativo. Un nombre de archivo de “-” especifica stdin o stdout. También es posible exportar a uno de los formatos de archivo alternativos a continuación, pero en ese caso se perderá la información de las cabeceras y trailers originales, incluso si el formato alternativo es el mismo que el formato de origen. Los archivos WavPack se crean generalmente con el programa wavpack.

Si se especifican múltiples archivos de entrada con salida redireccionada (“-o -”), la salida de todos los archivos se concatena. Esto se puede utilizar como una forma fácil de concatenar archivos WavPack (asumiendo que la salida se redirige posteriormente a wavpack), pero solo tiene sentido con salida bruta (--raw) para evitar que las cabeceras se mezclen con los datos de audio.

En máquinas multinúcleo, wvunpack intentará utilizar múltiples hilos para acelerar la operación, a menudo 3 veces o más. Para forzar la operación con un solo hilo, use la opción --no-threads, o use la opción --threads para ajustar finamente el número de hilos utilizados.

FORMATOS DE SALIDA

  • Microsoft RIFF (“.wav”), forzar con --wav, crea RF64 si es > 4 GB
  • Sony Wave64 (“.w64”), forzar con --w64
  • Apple AIFF (“.aif”), forzar con --aif o --aif-le
  • Apple Core Audio (“.caf”), forzar con --caf-be o --caf-le
  • PCM o DSD sin formato (“.raw”), forzar con -r o --raw
  • Philips DSDIFF (“.dff”), forzar con --dsdiff o --dff
  • Sony DSD Stream (“.dsf”), forzar con --dsf

OPCIONES

--aif, --aif-le
forzar salida a Apple AIFF (o AIFF-C/sowt), extensión “.aif”
-b
decodificar ciegamente todos los bloques de transmisión e ignorar la información de longitud
-c
no decodificar audio, sino simplemente extraer la hoja de pistas almacenada en la etiqueta APEv2 a stdout (equivalente a -x “cuesheet”)
-cc
extraer la hoja de pistas almacenada en la etiqueta APEv2 al archivo nombre-fuente.cue en el mismo directorio que el archivo de audio decodificado (equivalente a -xx “cuesheet=%a.cue”)
--caf-be, --caf-le
forzar salida a Core Audio big-endian o little-endian, extensión “.caf”
-d
eliminar el archivo fuente si tiene éxito; ¡usar con precaución!
--dff, --dsdiff
forzar salida a Philips DSDIFF, solo fuente de audio DSD, extensión “.dff”
--dsf
forzar salida a Sony DSF, solo fuente de audio DSD, extensión “.dsf”
-f
no decodificar audio, sino simplemente mostrar información resumida sobre el archivo WavPack a stdout en un formato interpretable por máquina (ver doc/wavpack_doc.html o cli/wvunpack.c para detalles)
--help
mostrar ayuda extendida
-i
ignorar el archivo .wvc (fuerza la descompresión híbrida con pérdidas)
-m
calcular y mostrar la firma MD5; verificar si es sin pérdidas
-n
sin decodificación de audio (usar con -xx para extraer solo etiquetas)
--no-overwrite
Nunca sobrescribir, ni preguntar para sobrescribir, un archivo existente. Esto es útil para reanudar una operación por lotes cancelada y obviamente no se puede mezclar con la opción -y.
--normalize-floats
normalizar audio flotante a +/-1.0 si aún no está normalizado (raramente es el caso, pero altera el audio y falla la verificación MD5)
--no-threads
forzar operación de un solo hilo, equivalente a --threads=1
--no-utf8-convert
dejar las etiquetas de texto extraídas en codificación UTF-8 durante la extracción o visualización
-o ARCHIVO_SALIDA
especificar nombre de archivo de salida (solo si es un archivo fuente único) o directorio de destino (debe existir)
-q
silencioso (mantener la salida de la consola al mínimo)
-r, --raw
forzar decodificación de audio PCM o DSD sin formato omitiendo cabeceras y trailers, resulta en nombre-fuente.raw
--raw-pcm
similar a -r y --raw anteriormente, excepto que el audio DSD se convertirá a PCM de 24 bits (decimación 8x)
-s
no decodificar audio, sino simplemente mostrar información resumida sobre el archivo WavPack a stdout
-ss
no decodificar audio, sino simplemente mostrar información resumida y de etiquetas sobre el archivo WavPack a stdout
--skip=[-][muestra|hh:mm:ss.ss]
comenzar la decodificación en la muestra o índice de tiempo especificado, especificar un ‘-’ hace que la muestra/tiempo sea relativo al final del archivo
-t
copiar la marca de tiempo del archivo de entrada a los archivos de salida
--threads=n
Habilitar (o deshabilitar) la operación multihilo con n=1 (sin hilos) hasta n=12 (hilos máximos). Mejora significativamente el rendimiento de todos los modos, incluida la verificación. Omitir el parámetro seleccionará un número óptimo de hilos.
--until=[+|-][muestra|hh:mm:ss.ss]
detener la decodificación en la muestra o índice de tiempo especificado, especificar un “+” o “-” hace que la muestra/tiempo sea relativo al final del archivo.
-v
verificar el archivo WavPack sin decodificarlo
--wav
forzar salida a Microsoft RIFF (WAV), extensión “.wav”
--w64
forzar salida a Sony Wave64, extensión “.w64”
-x TAG
extraer la etiqueta especificada (como “cuesheet” o “lyrics”) a stdout
-xx TAG[=OUTFILE]
extraer la etiqueta especificada a un archivo, el nombre del archivo de salida por defecto es nombre-fuente.TAG en el mismo directorio que el archivo de audio fuente; se puede especificar un nombre de archivo de salida personalizado, pero no se puede usar para especificar un directorio.
-y
sí a todas las preguntas (sobrescribir)

EJEMPLOS

Decodificar audio.wv a audio.wav:

wvunpack audio.wv

Decodificar audio.wv a output.raw sin cabeceras:

wvunpack -r audio.wv -o output.raw

Decodificar audio.wv y audio2.wv al directorio output/:

mkdir output
wvunpack -o output/ audio.wv audio2.wv

Para ver la información resumida de audio.wv:

wvunpack -s audio.wv

Para verificar audio.wv:

wvunpack -v audio.wv

OPTIONS

--+
‘+’ causa que la muestra/tiempo sea relativo al punto de --skip, especificar ‘-’ causa que la muestra/tiempo sea relativo al EOF
-v
verificar solo los datos fuente (no se crea archivo de salida)
-vv
verificación rápida (sin salida, solo archivos versión 5+)
--version
escribe la versión del programa a stdout
-w, --wav
forzar salida a Microsoft RIFF/RF64, extensión “.wav”
--w64
forzar salida a Sony Wave64, extensión “.w64”
-x “Campo”
no decodificar audio sino extraer el campo de etiqueta especificado a stdout
-xx “Campo[=archivo]”
extraer el campo de etiqueta especificado en un archivo con nombre en el mismo directorio que el archivo de audio decodificado; la especificación opcional del nombre de archivo puede contener ‘%a’ que se reemplaza con el nombre base del archivo de audio, ‘%t’ reemplazado con el nombre del campo de etiqueta (nota: proviene de los datos para etiquetas binarias) y ‘%e’ reemplazado con la extensión del archivo fuente de la etiqueta binaria (o “txt” para etiquetas de texto).
-y
sí a la advertencia de sobrescritura; ¡úsalo con precaución!
-z[n]
no establecer (n = 0 u omitido) o establecer (n = 1) el título de la consola para indicar el progreso (deja "WvUnpack Completed")
