wcscasecmp(3) Manual de funciones de biblioteca wcscasecmp(3)

NOMBRE

wcscasecmp, wcsncasecmp - compara dos cadenas de caracteres anchos, ignorando mayúsculas/minúsculas

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <wchar.h>
int wcscasecmp(const wchar_t *s1, const wchar_t *s2);
int wcsncasecmp(size_t n;
                const wchar_t s1[n], const wchar_t s2[n], size_t n);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

wcscasecmp(), wcsncasecmp():

    Desde glibc 2.10:
        _POSIX_C_SOURCE >= 200809L
    Antes de glibc 2.10:
        _GNU_SOURCE

DESCRIPCIÓN

La función wcscasecmp() es el equivalente en caracteres anchos de la función strcasecmp(3). Compara la cadena de caracteres anchos apuntada por s1 y la cadena de caracteres anchos apuntada por s2, ignorando las diferencias de mayúsculas/minúsculas (towupper(3), towlower(3)).

La función wcsncasecmp() es similar (el equivalente en caracteres anchos de strncasecmp(3)), excepto que compara no más de n caracteres anchos de s1 y s2.

VALOR DE RETORNO

Las funciones wcscasecmp() y wcsncasecmp() devuelven un entero menor que, igual a, o mayor que cero si s1 es, después de ignorar las mayúsculas/minúsculas, menor que, coincide con, o mayor que s2, respectivamente.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
wcscasecmp (), wcsncasecmp () Seguridad en hilos MT-Safe locale

ESTÁNDARES

POSIX.1-2008.

HISTORIA

glibc 2.1.

NOTAS

El comportamiento de wcscasecmp() depende de la categoría LC_CTYPE de la configuración regional actual.

VER TAMBIÉN

strcasecmp(3), wcscmp(3)
