WESSIDE-NG(8) Manual del Administrador del Sistema WESSIDE-NG(8)

NOMBRE

wesside-ng - obtener la clave WEP de una red abierta sin intervención del usuario

SINOPSIS

wesside-ng <opciones>

DESCRIPCIÓN

wesside-ng es una herramienta mágica que incorpora una serie de técnicas para obtener sin problemas una clave WEP en minutos. Primero identifica una red, luego procede a asociarse con ella, obtener datos XOR de PRGA (algoritmo de generación pseudoaleatoria), determinar el esquema IP de la red, reinyectar solicitudes ARP y finalmente determinar la clave WEP. Todo esto se hace sin tu intervención.

OPCIONES

-h
Muestra la pantalla de ayuda.
-i <interfaz>
Nombre de la interfaz inalámbrica. (Obligatorio)
-n <ip de red>
IP de red como en 'quién tiene IP de destino (netip) di IP de origen (myip)'. Por defecto es la IP de origen en la solicitud ARP que se captura y descifra. (Opcional)
-m <mi ip>
'quién tiene IP de destino (netip) di IP de origen (myip)'. Por defecto es la red.123 en la solicitud ARP capturada (Opcional).
-a <mac de origen>
Dirección MAC de origen (Opcional)
-c
No descifrar la clave. ¡Simplemente captura los paquetes hasta que se presione Control-C para detener el programa! (Opcional)
-p <PRGA mín.>
Determina el número mínimo de bytes de PRGA que se recopila. Por defecto son 128 bytes. (Opcional).
-v <MAC de víctima>
Dirección MAC del punto de acceso inalámbrico (Opcional).
-t <umbral>
Por cada número de IVs especificado, reinicia el motor PTW de airecrack-ng (Opcional). Reiniciará PTW cada <umbral> IVs.
-f <canal>
Permite definir el canal más alto para el escaneo. Por defecto es el canal 11 (Opcional).
