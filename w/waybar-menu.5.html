NOMBRE

waybar - propiedad de menú

DESCRIPCIÓN GENERAL

Algunos módulos admiten un 'menú', que permite tener un menú emergente cuando se realiza un clic definido sobre el módulo.

PROPIEDADES

Un módulo que implementa un 'menú' necesita 3 propiedades definidas en su configuración:

menu:
tipo: cadena
Acción que muestra el menú emergente. Las acciones posibles son:

Opción Descripción
on-click Cuando haces clic izquierdo en el módulo
on-click-release Cuando sueltas el botón izquierdo en el módulo
on-double-click Cuando haces doble clic izquierdo en el módulo
on-triple-click Cuando haces triple clic izquierdo en el módulo
on-click-middle Cuando haces clic con el botón central del ratón (rueda) en el módulo
on-click-middle-release Cuando sueltas el botón central del ratón en el módulo
on-double-click-middle Cuando haces doble clic con el botón central del ratón en el módulo
on-triple-click-middle Cuando haces triple clic con el botón central del ratón en el módulo
on-click-right Cuando haces clic derecho en el módulo
on-click-right-release Cuando sueltas el botón derecho en el módulo
on-double-click-right Cuando haces doble clic derecho en el módulo
on-triple-click-right Cuando haces triple clic con el botón central del ratón en el módulo
on-click-backward Cuando haces clic en el módulo usando el botón de retroceso del ratón
on-click-backward-release Cuando sueltas el botón de retroceso del ratón en el módulo
on-double-click-backward Cuando haces doble clic en el módulo usando el botón de retroceso del ratón
on-triple-click-backward Cuando haces triple clic en el módulo usando el botón de retroceso del ratón
on-click-forward Cuando haces clic en el módulo usando el botón de avance del ratón
on-click-forward-release Cuando sueltas el botón de avance del ratón en el módulo
on-double-click-forward Cuando haces doble clic en el módulo usando el botón de avance del ratón
on-triple-click-forward Cuando haces triple clic en el módulo usando el botón de avance del ratón

menu-file:
tipo: cadena
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu.

menu-actions:
tipo: arreglo
Las acciones correspondientes a los botones del menú. Los identificadores de

cada acción deben existir como un id en el 'menu-file' para que se enlacen correctamente.

ARCHIVO DE MENÚ

El archivo de menú es un archivo `.xml` que representa un GtkBuilder. La documentación sobre él se puede encontrar aquí: https://docs.gtk.org/gtk4/class.Builder.html

Aquí, debe haber un elemento de tipo GtkMenu con id "menu". Cada acción en menu-actions se enlaza a los elementos del archivo menu-file por el id de los elementos.

EJEMPLO

Configuración del módulo:

"custom/power": {
	"format" : "⏻ ",
		"tooltip": false,
		"menu": "on-click",
		"menu-file": "~/.config/waybar/power_menu.xml",
		"menu-actions": {
			"shutdown": "shutdown",
			"reboot": "reboot",
			"suspend": "systemctl suspend",
			"hibernate": "systemctl hibernate",
		},
},

~/.config/waybar/power_menu.xml:

<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkMenu" id="menu">
	<child>
		<object class="GtkMenuItem" id="suspend">
			<property name="label">Suspender</property>
        </object>
	</child>
	<child>
        <object class="GtkMenuItem" id="hibernat">
			<property name="label">Hibernar</property>
        </object>
	</child>
    <child>
        <object class="GtkMenuItem" id="shutdown">
			<property name="label">Apagar</property>
        </object>
    </child>
    <child>
      <object class="GtkSeparatorMenuItem" id="delimiter1"/>
    </child>
    <child>
		<object class="GtkMenuItem" id="reboot">
			<property name="label">Reiniciar</property>
		</object>
    </child>
  </object>
</interface>

ESTILIZAR MENÚS

•
menu Estilo para el menú
•
menuitem Estilo para los elementos del menú

EJEMPLO:

menu {
	border-radius: 15px;
	background: #161320;
	color: #B5E8E0;
}
menuitem {
	border-radius: 15px;
}
