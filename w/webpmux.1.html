WEBPMUX(1) Manual de Comandos Generales WEBPMUX(1)

NOMBRE

webpmux - crear archivos WebP animados a partir de imágenes WebP no animadas, extraer fotogramas de imágenes WebP animadas y gestionar metadatos XMP/EXIF y perfiles ICC.

SINOPSIS

webpmux -get OPCIONES_DE_OBTENCIÓN ENTRADA -o SALIDA
webpmux -set OPCIONES_DE_ESTABLECIMIENTO ENTRADA -o SALIDA
webpmux -strip OPCIONES_DE_ELIMINACIÓN ENTRADA -o SALIDA
webpmux -frame OPCIONES_DE_FOTOGRAMA [ -frame ... ] [ -loop NÚMERO_DE_REPETICIONES ]

[ -bgcolor COLOR_DE_FONDO ] -o SALIDA
webpmux -duration OPCIONES_DE_DURACIÓN [ -duration ... ] ENTRADA -o SALIDA
webpmux -info ENTRADA
webpmux [-h|-help]
webpmux -version
webpmux nombre_archivo_argumentos

DESCRIPCIÓN

Esta página del manual documenta el comando webpmux.

webpmux se puede usar para crear/extraer de archivos WebP animados, así como para añadir/extraer/eliminar metadatos XMP/EXIF y perfiles ICC. Si se proporciona un único nombre de archivo (que no comience con el carácter '-') como argumento, los argumentos de la línea de comandos se tokenizarán de este archivo. Esto permite una fácil creación de scripts o el uso de un gran número de argumentos.

OPCIONES

OPCIONES DE OBTENCIÓN (-get):

icc
Obtener perfil ICC.
exif
Obtener metadatos EXIF.
xmp
Obtener metadatos XMP.
fotograma n
Obtener el n-ésimo fotograma de una imagen animada. (n = 0 tiene un significado especial: último fotograma).

OPCIONES DE ESTABLECIMIENTO (-set)

loop nº_repeticiones
Establecer el número de repeticiones en un archivo animado.

Donde: 'nº_repeticiones' debe estar en el rango [0, 65535].

bgcolor A,R,G,B
Establecer el color de fondo del lienzo en un archivo animado.

Donde: 'A', 'R', 'G' y 'B' son enteros en el rango de 0 a 255 que especifican los valores de los componentes Alfa, Rojo, Verde y Azul, respectivamente.

icc archivo.icc
Establecer perfil ICC.

Donde: 'archivo.icc' contiene el perfil ICC que se va a establecer.

exif archivo.exif
Establecer metadatos EXIF.

Donde: 'archivo.exif' contiene los metadatos EXIF que se van a establecer.

xmp archivo.xmp
Establecer metadatos XMP.

Donde: 'archivo.xmp' contiene los metadatos XMP que se van a establecer.

OPCIONES DE ELIMINACIÓN (-strip)

icc
Eliminar perfil ICC.
exif
Eliminar metadatos EXIF.
xmp
Eliminar metadatos XMP.

OPCIONES DE DURACIÓN (-duration)

Modificar la duración de un intervalo específico de fotogramas. Esta opción solo es efectiva en WebP animados y no tiene ningún efecto en un archivo de fotograma único.

duración[,inicio[,fin]]
Donde:
duración es la duración del intervalo en milisegundos (obligatorio). Debe ser no negativo.
inicio es el índice del fotograma de inicio del intervalo (opcional).
fin es el índice del fotograma final (inclusive) del intervalo (opcional).
Los tres usos típicos de esta opción son:

-duration d
establecer la duración a 'd' para toda la animación.
-duration d,f
establecer la duración del fotograma 'f' a 'd'.
-duration d,inicio,fin
establecer la duración a 'd' para todo el intervalo [inicio, fin].

Tenga en cuenta que los fotogramas fuera del intervalo [inicio, fin] permanecerán sin cambios. El valor 'fin' '0' tiene el significado especial de 'último fotograma de la animación'.

Recordatorio:
el indexado de fotogramas comienza en '1'.

OPCIONES DE FOTOGRAMA (-frame)

Crear un archivo WebP animado a partir de múltiples imágenes WebP (no animadas).

archivo_i +di[+xi+yi[+mi[bi]]]
Donde: 'archivo_i' es el i-ésimo fotograma (formato WebP), 'xi','yi' especifican el desplazamiento de la imagen para este fotograma, 'di' es la duración de la pausa antes del siguiente fotograma, 'mi' es el método de disposición para este fotograma (0 para NINGUNO o 1 para FONDO) y 'bi' es el método de mezcla para este fotograma (+b para MEZCLAR o -b para NO_MEZCLAR). El argumento 'bi' puede omitirse y por defecto será +b (MEZCLAR). Además, 'mi' puede omitirse si 'bi' se omite y por defecto será 0 (NINGUNO). Finalmente, si se omiten 'mi' y 'bi', entonces 'xi' e 'yi' pueden omitirse y por defecto serán +0+0.
-loop n
Repetir los fotogramas n veces. 0 indica que los fotogramas deben repetirse infinitamente. El rango válido es de 0 a 65535 [Por defecto: 0 (infinito)].
-bgcolor A,R,G,B
Color de fondo del lienzo.
donde: 'A', 'R', 'G' y 'B' son enteros en el rango de 0 a 255 especificando los valores de los componentes Alfa, Rojo, Verde y Azul, respectivamente [Por defecto: 255,255,255,255].

ENTRADA

Archivo de entrada en formato WebP.

SALIDA (-o)

Archivo de salida en formato WebP.

Nota:

La naturaleza de los datos EXIF, XMP y ICC no se verifica y se asume que son válidos.

ESTADO DE SALIDA

Si no hubo problemas durante la ejecución, webpmux sale con el valor de la constante C EXIT_SUCCESS. Esto suele ser cero.

Si ocurre un error, webpmux sale con el valor de la constante C EXIT_FAILURE. Esto suele ser uno.

EJEMPLOS

Añadir perfil ICC:
webpmux -set icc image_profile.icc in.webp -o icc_container.webp

Extraer perfil ICC:
webpmux -get icc icc_container.webp -o image_profile.icc

Eliminar perfil ICC:
webpmux -strip icc icc_container.webp -o without_icc.webp

Añadir metadatos XMP:
webpmux -set xmp image_metadata.xmp in.webp -o xmp_container.webp

Extraer metadatos XMP:
webpmux -get xmp xmp_container.webp -o image_metadata.xmp

Eliminar metadatos XMP:
webpmux -strip xmp xmp_container.webp -o without_xmp.webp

Añadir metadatos EXIF:
webpmux -set exif image_metadata.exif in.webp -o exif_container.webp

Extraer metadatos EXIF:
webpmux -get exif exif_container.webp -o image_metadata.exif

Eliminar metadatos EXIF:

/> webpmux -strip exif exif_container.webp -o without_exif.webp

Crear un archivo WebP animado a partir de 3 imágenes WebP (no animadas):
webpmux -frame 1.webp +100 -frame 2.webp +100+50+50

-frame 3.webp +100+50+50+1+b -loop 10 -bgcolor 255,255,255,255
-o anim_container.webp

Obtener el segundo fotograma de un archivo WebP animado:
webpmux -get frame 2 anim_container.webp -o frame_2.webp

Usando -get/-set/-strip con nombres de archivo de entrada que comienzan con '-':
webpmux -set icc image_profile.icc -o icc_container.webp -- ---in.webp
webpmux -get icc -o image_profile.icc -- ---icc_container.webp
webpmux -strip icc -o without_icc.webp -- ---icc_container.webp
