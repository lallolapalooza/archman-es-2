NOMBRE

wpctl - CLI de control de WirePlumber

SINOPSIS

wpctl [COMANDO] [OPCIONES_DE_COMANDO]

DESCRIPCIÓN

wpctl es una herramienta de control de línea de comandos para WirePlumber, el gestor de sesiones de PipeWire. Proporciona una interfaz para inspeccionar, controlar y configurar dispositivos de audio y vídeo, nodos y sus propiedades dentro de un servidor de medios PipeWire.

WirePlumber gestiona el enrutamiento de audio y vídeo, la configuración de dispositivos y las políticas de sesión. wpctl permite a los usuarios interactuar con estos componentes, cambiar niveles de volumen, establecer dispositivos predeterminados, inspeccionar propiedades de objetos y modificar configuraciones.

COMANDOS

status

wpctl status [-k|--nick] [-n|--name]

Muestra el estado actual de los objetos en PipeWire, incluyendo dispositivos, sinks, sources, filtros y streams. Muestra una vista jerárquica del sistema de audio/vídeo.

Opciones:
-k, --nick
Muestra los apodos de dispositivos y nodos en lugar de descripciones
-n, --name
Muestra los nombres de dispositivos y nodos en lugar de descripciones

get-volume

wpctl get-volume ID

Muestra información de volumen sobre el nodo especificado, incluyendo el nivel de volumen actual y el estado de silencio.

Argumentos:
ID
ID del nodo o identificador especial (ver IDENTIFICADORES ESPECIALES)

inspect

wpctl inspect ID [-r|--referenced] [-a|--associated]

Muestra información detallada sobre el objeto especificado, incluyendo todas las propiedades y metadatos.

Argumentos:
ID
ID del objeto o identificador especial
Opciones:
-r, --referenced
Muestra los objetos referenciados en las propiedades
-a, --associated
Muestra los objetos asociados

set-default

wpctl set-default ID

Establece el nodo de dispositivo especificado como el destino predeterminado de su tipo (captura o reproducción) para nuevos streams que requieren conexión automática.

Argumentos:
ID
ID del nodo sink o source

set-volume

wpctl set-volume ID VOL[%][-|+] [-p|--pid] [-l LIMIT|--limit LIMIT]

Establece el volumen del nodo especificado.

Argumentos:
ID
ID del nodo, identificador especial o PID (con --pid)
VOL[%][-|+]
Especificación de volumen:
  • VOL - Establece el volumen a un valor específico (1.0 = 100%)
  • VOL% - Establece el volumen a un porcentaje (50% = 0.5)
  • VOL+ - Incrementa el volumen en el valor dado
  • VOL- - Decrementa el volumen en el valor dado
  • VOL%+ - Incrementa el volumen en el porcentaje dado
  • VOL%- - Decrementa el volumen en el porcentaje dado
Opciones:
-p, --pid
Trata el ID como un ID de proceso y afecta a todos los nodos asociados a él
-l LIMIT, --limit LIMIT
Limita el volumen final por debajo de este valor (punto flotante, 1.0 = 100%)
Ejemplos:
Establecer volumen al 50%: wpctl set-volume @DEFAULT_SINK@ 0.5

Incrementar volumen en 10%: wpctl set-volume 42 10%+

Establecer volumen para todos los nodos del PID 1234: wpctl set-volume --pid 1234 0.8

set-mute

wpctl set-mute ID 1|0|toggle [-p|--pid]

Cambia el estado de silencio del nodo especificado.

Argumentos:
ID
ID del nodo, identificador especial o PID (con --pid)
1|0|toggle
Estado de silencio: 1 (silenciar), 0 (activar sonido), o cambiar el estado actual
Opciones:
-p, --pid
Trata el ID como un ID de proceso y afecta a todos los nodos asociados a él

set-profile

wpctl set-profile ID INDEX

Establece el perfil del dispositivo especificado al índice dado.

Argumentos:
ID
ID del dispositivo o identificador especial
INDEX
Índice del perfil (entero, 0 normalmente significa 'apagado')

set-route

wpctl set-route ID INDEX

Establece la ruta del dispositivo especificado al índice dado.

Argumentos:
ID
ID del nodo del dispositivo o identificador especial
INDEX
Índice de ruta (entero, 0 normalmente significa 'apagado')
