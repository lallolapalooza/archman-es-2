NOMBRE

waybar - módulo de espacios de trabajo de hyprland

DESCRIPCIÓN

El módulo workspaces muestra los espacios de trabajo actualmente utilizados en el compositor hyprland.

CONFIGURACIÓN

Abordado por hyprland/workspaces

format:
tipo: string
predeterminado: {id}
El formato, cómo se debe mostrar la información.

format-icons:
tipo: array
Según el ID y el estado del espacio de trabajo, se selecciona el icono correspondiente. Ver icons.

window-rewrite:
tipo: object
Reglas Regex para mapear la clase de la ventana a un icono o método preferido de representación para la ventana de un espacio de trabajo.

Las claves son las reglas, mientras que los valores son los métodos de representación. Los valores pueden usar los marcadores {class} y {title} para usar la clase y/o el título original de la ventana respectivamente. Las reglas pueden especificar `class<...>`, `title<...>`, o ambos para ajustar la coincidencia. Puedes asignar un valor vacío a una regla para que sea ignorada al generar cualquier representación en los espacios de trabajo.
Esta configuración se ignora si workspace-taskbar.enable está establecido en true.

window-rewrite-default:
tipo: string
predeterminado: "?"
El método de representación predeterminado para la ventana de un espacio de trabajo. Esto se usará para las ventanas cuyas clases no coincidan con ninguna de las reglas en window-rewrite.
Esta configuración se ignora si workspace-taskbar.enable está establecido en true.

format-window-separator:
tipo: string
predeterminado: " "
El separador que se utilizará entre las ventanas en un espacio de trabajo.
Esta configuración se ignora si workspace-taskbar.enable está establecido en true.

workspace-taskbar:
tipo: object
Contiene la configuración para la barra de tareas de espacios de trabajo, un modo alternativo para el módulo de espacios de trabajo que muestra los iconos de las ventanas como imágenes en lugar de texto.

enable:
tipo: bool
predeterminado: false
Habilita el modo de barra de tareas de espacios de trabajo.

format:
tipo: string
predeterminado: {icon}
Formato a usar para cada ventana en la barra de tareas de espacios de trabajo. Los marcadores disponibles son {icon} y {title}.

icon-size:
tipo: int
predeterminado: 16
Tamaño de los iconos en la barra de tareas de espacios de trabajo.

icon-theme:
tipo: string | array
predeterminado: []
Tema de iconos a usar para la barra de tareas de espacios de trabajo. Si se proporciona una matriz, el primer tema que se encuentre para un icono dado se usará. Si no se encuentra ningún tema (o la matriz está vacía), se usará el tema de iconos predeterminado.

orientation:
tipo: "horizontal" | "vertical"
predeterminado: horizontal
Dirección en la que se muestra la barra de tareas de espacios de trabajo.

show-special:
tipo: bool
predeterminado: false
Si se establece en true, se mostrarán los espacios de trabajo especiales.

special-visible-only:
tipo: bool
predeterminado: false
Si esto y show-special son true, los espacios de trabajo especiales se mostrarán solo si son visibles.

persistent-only:
tipo: bool
predeterminado: false
Si se establece en true, solo se mostrarán los espacios de trabajo persistentes en la barra.

all-outputs:
tipo: bool
predeterminado: false
Si se establece en false, el grupo de espacios de trabajo se mostrará solo en la salida asignada. En caso contrario, se mostrarán todos los grupos de espacios de trabajo.

active-only:
tipo: bool
predeterminado: false
Si se establece en true, solo se mostrará el espacio de trabajo activo.

move-to-monitor:
tipo: bool
predeterminado: false
Si se establece en true, abre el espacio de trabajo en el monitor actual al hacer clic en un botón de espacio de trabajo.

De lo contrario, el espacio de trabajo se abrirá en el monitor donde estaba previamente asignado. Análogo a usar el despachador `focusworkspaceoncurrentmonitor` en lugar de `workspace` en Hyprland.

ignore-workspaces:
tipo: array
predeterminado: []
Expresiones regulares para hacer coincidir con los nombres de los espacios de trabajo. Si hay una coincidencia, el espacio de trabajo no se mostrará. Esto tiene prioridad sobre show-special, all-outputs, y active-only.

sort-by:
tipo: string
predeterminado: "default"
Si se establece en number, los espacios de trabajo se ordenarán por número.

Si se establece en name, los espacios de trabajo se ordenarán por nombre. Si se establece en id, los espacios de trabajo se ordenarán por id. Si se establece en special-centered, los espacios de trabajo se ordenarán por defecto con los espacios de trabajo especiales en el centro. Si ninguna de las anteriores, los espacios de trabajo se ordenarán con el comportamiento predeterminado.

expand:
tipo: bool
predeterminado: false
Permite que este módulo consuma todo el espacio sobrante dinámicamente.

REEMPLAZOS DE FORMATO

{id}: id del espacio de trabajo asignado por el compositor

{name}: nombre del espacio de trabajo asignado por el compositor

{icon}: Icono, como se define en format-icons.

ICONOS

Además de la coincidencia de nombres de espacios de trabajo, se pueden configurar los siguientes format-icons.

  • default: Se mostrará cuando no se encuentre ninguna coincidencia de cadena y ninguna de las condiciones siguientes tenga iconos definidos.
  • active: Se mostrará cuando el espacio de trabajo esté activo
  • special: Se mostrará en espacios de trabajo especiales no activos
  • empty: Se mostrará en espacios de trabajo persistentes vacíos no activos y no especiales
  • visible: Se mostrará en espacios de trabajo que son visibles pero no activos. Por ejemplo: esto es útil si quieres que tus espacios de trabajo visibles en otros monitores tengan el mismo aspecto que el activo.
  • persistent: Se mostrará en espacios de trabajo persistentes no vacíos

EJEMPLOS

"hyprland/workspaces": {
	"format": "{name}: {icon}",
	"format-icons": {
		"1": "󰎺",
		"2": "󰲒",
		"3": "󰎿",
		"4": "󰃃",
		"5": "󰹀",
		"active": "󰆊",
		"default": "󰽰"
	},
	"persistent-workspaces": {
		"*": 5, // 5 espacios de trabajo por defecto en cada monitor
		"HDMI-A-1": 3 // pero solo tres en HDMI-A-1
	}
}
"hyprland/workspaces": {
	"format": "{name}: {icon}",
	"format-icons": {
		"1": "󰎺",
		"2": "󰲒",
		"3": "󰎿",
		"4": "󰃃",
		"5": "󰹀",
		"active": "󰆊",
		"default": "󰽰"
	},
	"persistent-workspaces": {
		"*": [ 2,3,4,5 ], // 2-5 en cada monitor
		"HDMI-A-1": [ 1 ] // pero solo el espacio de trabajo 1 en HDMI-A-1
	}
}
"hyprland/workspaces": {
	"format": "{name}n{windows}",
	"format-window-separator": "n",
	"window-rewrite-default": "󰖹",
	"window-rewrite": {
		"title<.*youtube.*>": "󰗃", // Ventanas cuyos títulos contienen "youtube"
		"class<firefox>": "󰊯", // Ventanas cuyas clases son "firefox"
		"class<firefox> title<.*github.*>": " GitHub", // Ventanas cuya clase es "firefox" y cuyo título contiene "github". Nota: "class" siempre va primero.
		"foot": "󰋑", // Ventanas que contienen "foot" en su clase o título. Por razones de optimización, solo coincidirá con un título si al menos otra ventana coincide explícitamente con un título.
		"code": "󰅨",
		"title<.* - (.*) - VSCodium>": "codium $1"  // captura parte del título de la ventana y lo formatea en la salida
	}
}

DESCRIPCIÓN

El módulo de espacios de trabajo de Hyprland muestra los espacios de trabajo actuales, los activos y los vacíos, así como los números de los espacios de trabajo. Este módulo está diseñado para ser usado con los espacios de trabajo de Hyprland.

Esto se puede configurar en su archivo de configuración de Waybar (normalmente ~/.config/waybar/config o ~/.config/waybar/config.jsonc).

{
    // ...
    "modules-left": ["hyprland/workspaces"],
    "hyprland/workspaces": {
        "format": "{name}: {icon}",
        "format-icons": {
            "1": "",
            "2": "",
            "3": "",
            "4": "",
            "5": "",
            "default": "",
            "active": "",
            "urgent": ""
        },
        "sort-by-number": true,
        "on-click": "activate-workspace"
    }
    // ...
}

REEMPLAZOS DE FORMATO

  • {name}: el nombre del espacio de trabajo (solo si se usa hyprland/workspaces).
  • {icon}: el icono del espacio de trabajo (si está disponible, de lo contrario el nombre).
  • {windows}: el número de ventanas en el espacio de trabajo.

ICONOS

La configuración anterior usa Font Awesome iconos. Necesitarás tenerlos instalados.

En este módulo, active y urgent se usan para cambiar los iconos de los espacios de trabajo activos y urgentes. los espacios de trabajo, respectivamente.

EJEMPLOS

El código de ejemplo anterior genera algo como esto:

1: 
2: 
3: 
4: 
5: 

Donde el espacio de trabajo 3 está actualmente activo. Para ver el número de ventanas en un espacio de trabajo, simplemente añada {windows} a la cadena de formato:

"format": "{name}: {icon} {windows}"

Esto produciría una salida como:

1:  0
2:  5
3:  12

Estilo

Esto se puede estilizar usando CSS, de forma similar a otros módulos de Waybar. Por ejemplo, para estilizar los botones de espacio de trabajo:

#workspaces button {
    padding: 0 5px;
    color: #ffffff;
}

#workspaces button.active {
    background-color: #64727D;
    color: #282828;
}

#workspaces button.urgent {
    background-color: #eb4d4b;
}

#workspaces button.empty {
    color: #707070;
}

#workspaces button:hover {
    background: #424242;
    box-shadow: inherit;
    text-shadow: inherit;
}

#workspaces .taskbar-window {
    background-color: #000000;
    margin: 0 2px;
    border-radius: 3px;
}
