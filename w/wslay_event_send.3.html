wslay_event_send(3)

Paquete: libwslay

Licencias: MIT

WSLAY_EVENT_SEND(3) wslay WSLAY_EVENT_SEND(3)

NOMBRE

wslay_event_send - Envía cualquier mensaje pendiente

SINOPSIS

#include <wslay/wslay.h>

int wslay_event_send(wslay_event_context_ptr ctx)

DESCRIPCIÓN

wslay_event_send() envía mensajes en cola al par. Al enviar un mensaje, utiliza la función wslay_event_send_callback. Una única llamada a wslay_event_send() envía múltiples mensajes hasta que wslay_event_send_callback establece el código de error WSLAY_ERR_WOULDBLOCK.

Si ctx se inicializa para uso como cliente WebSocket, wslay_event_send() utiliza wslay_event_genmask_callback para obtener una nueva clave de máscara.

Cuando se envía un mensaje en cola usando wslay_event_queue_fragmented_msg(), wslay_event_send() invoca wslay_event_fragmented_msg_callback para ese mensaje.

Después de que se envía el marco de control de cierre, esta función llama a wslay_event_set_write_enabled() con el segundo argumento 0 para deshabilitar la transmisión adicional al par.

Si hay mensajes pendientes, wslay_event_want_write() devuelve 1, de lo contrario devuelve 0.

En caso de un error fatal que resulte en un código de retorno negativo, esta función llama a wslay_event_set_write_enabled() con el segundo argumento 0 para deshabilitar la transmisión adicional al par.

VALOR DE RETORNO

wslay_event_send() devuelve 0 si tiene éxito, o uno de los siguientes códigos de error negativos:

WSLAY_ERR_CALLBACK_FAILURE
La función de devolución de llamada definida por el usuario falló.
WSLAY_ERR_NOMEM
Memoria agotada.

Cuando se devuelve un código de error negativo, la aplicación no debe realizar más llamadas a wslay_event_send() y debe cerrar la conexión WebSocket.

VER TAMBIÉN

wslay_event_queue_fragmented_msg(), wslay_event_set_write_enabled(), wslay_event_want_write()
