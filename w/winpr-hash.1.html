NOMBRE

winpr-hash - Herramienta de hash NTLM

SINOPSIS

winpr-hash -u nombre_usuario -p contraseña [-d dominio] [-f { default | sam }] [-v { 1 | 2 }]

DESCRIPCIÓN

winpr-hash es una pequeña utilidad que se puede utilizar para crear un hash NTLM a partir de un par nombre de usuario y contraseña. El hash creado se puede exportar como hash plano o en formato SAM.

OPCIONES

-u nombre_usuario
El nombre de usuario a utilizar.
-p contraseña
La contraseña a utilizar.
-d dominio
Un parámetro opcional para especificar el dominio del usuario.
-f formato
Especifica el formato de salida. El valor default solo muestra el hash NTLM plano. El segundo formato de salida disponible es sam, que muestra el hash creado en un formato que se puede utilizar en un archivo SAM:

usuario:dominio::hash:::

-v versión
La versión permite especificar la versión NTLM a utilizar. Por defecto se utiliza la versión 1. En caso de utilizar la versión 2, se debe especificar un dominio.

EJEMPLOS

winpr-hash -u usuario -p contraseña -d dominio -f sam -v 2

Crea un hash NTLM versión 2 para usuario con dominio y contraseña, y lo muestra en formato sam.
