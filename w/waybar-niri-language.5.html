NOMBRE

waybar - módulo de lenguaje niri

DESCRIPCIÓN

El módulo language muestra el idioma actualmente seleccionado en niri.

CONFIGURACIÓN

Abordado por niri/language

format:
tipo: cadena
predeterminado: {}
El formato, cómo se debe mostrar la información.

format-<lang>
tipo: cadena
Proporciona un nombre alternativo para mostrar por idioma, donde <lang> es el idioma de tu elección. Se puede pasar varias veces con varios idiomas, como se muestra en el ejemplo a continuación.

menu:
tipo: cadena
Acción que abre el menú emergente.

menu-file:
tipo: cadena
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo GtkMenu con el id menu

menu-actions:
tipo: matriz
Las acciones correspondientes a los botones del menú.

expand:
tipo: booleano
predeterminado: falso
Permite que este módulo consuma dinámicamente todo el espacio sobrante.

REEMPLAZOS DE FORMATO

{short}: Nombre corto del diseño (por ejemplo, "us"). Igual a {}.

{shortDescription}: Descripción corta del diseño (por ejemplo, "en").

{long}: Nombre largo del diseño (por ejemplo, "Inglés (Dvorak)").

{variant}: Variante del diseño (por ejemplo, "dvorak").

EJEMPLOS

"niri/language": {
	"format": "Lang: {long}"
	"format-en": "AMERICA, HELL YEAH!"
	"format-tr": "As bayrakları"
}
