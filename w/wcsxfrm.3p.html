WCSXFRM(3P) Manual del programador de POSIX WCSXFRM(3P)

PROLOG

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

wcsxfrm, wcsxfrm_l — transformación de cadenas de caracteres anchos

SINOPSIS

#include <wchar.h>
size_t wcsxfrm(wchar_t *restrict ws1, const wchar_t *restrict ws2,
    size_t n);
size_t wcsxfrm_l(wchar_t *restrict ws1, const wchar_t *restrict ws2,
    size_t n, locale_t locale);

DESCRIPCIÓN

Para wcsxfrm(): La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es inintencional. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

Las funciones wcsxfrm() y wcsxfrm_l() transformarán la cadena de caracteres anchos apuntada por ws2 y colocarán la cadena de caracteres anchos resultante en el array apuntado por ws1. La transformación será tal que si wcscmp() se aplica a dos cadenas transformadas, devolverá un valor mayor que, igual a, o menor que 0, correspondiente al resultado de wcscoll() y wcscoll_l() aplicados a las mismas dos cadenas de caracteres anchos originales, y la misma categoría LC_COLLATE de la localización actual o del objeto de localización locale, respectivamente. No se colocarán más de n códigos de caracteres anchos en el array resultante apuntado por ws1, incluido el código de carácter ancho nulo terminador. Si n es 0, ws1 puede ser un puntero nulo. Si la copia se realiza entre objetos que se superponen, el comportamiento es indefinido.

Las funciones wcsxfrm() y wcsxfrm_l() no cambiarán la configuración de errno si tienen éxito.

Dado que no se reserva ningún valor de retorno para indicar un error, una aplicación que desee comprobar situaciones de error debe establecer errno a 0, luego llamar a wcsxfrm() o wcsxfrm_l(), y luego comprobar errno.

El comportamiento es indefinido si el argumento locale de wcsxfrm_l() es el objeto de localización especial LC_GLOBAL_LOCALE o no es un identificador de objeto de localización válido.

VALOR DE RETORNO

Las funciones wcsxfrm() y wcsxfrm_l() devolverán la longitud de la cadena de caracteres anchos transformada (sin incluir el código de carácter ancho nulo terminador). Si el valor devuelto es n o mayor, el contenido del array apuntado por ws1 no está especificado.

En caso de error, las funciones wcsxfrm() y wcsxfrm_l() pueden establecer errno, pero no se reserva ningún valor de retorno para indicar un error.

ERRORES

Estas funciones pueden fallar si:

EINVAL
La cadena de caracteres anchos apuntada por ws2 contiene códigos de caracteres anchos fuera del dominio de la secuencia de ordenación.

USO POR LA APLICACIÓN

La función de transformación es tal que dos cadenas de caracteres anchos transformadas pueden ser ordenadas por wcscmp() según la información de la secuencia de ordenación en la localización actual (categoría LC_COLLATE).

El hecho de que cuando n es 0 ws1 puede ser un puntero nulo es útil para determinar el tamaño del array ws1 antes de realizar la transformación.
