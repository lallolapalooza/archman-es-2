NOMBRE

wpa_passphrase - Genera una PSK de WPA a partir de una contraseña ASCII para un SSID

SINOPSIS

wpa_passphrase [ ssid ] [ contraseña ]

DESCRIPCIÓN

wpa_passphrase precalcula entradas PSK para bloques de configuración de red de un archivo wpa_supplicant.conf. Una contraseña ASCII y un SSID se utilizan para generar una PSK de 256 bits.

OPCIONES

ssid
El SSID cuya contraseña debe derivarse.
contraseña
La contraseña a utilizar. Si no se incluye en la línea de comandos, la contraseña se leerá de la entrada estándar.
