wordexp(3) Manual de funciones de biblioteca wordexp(3)

NOMBRE

wordexp, wordfree - realizar expansión de palabras como un shell posix

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <wordexp.h>
int wordexp(const char *restrict s, wordexp_t *restrict p, int flags);
void wordfree(wordexp_t *p);
Requisitos de Macro de Prueba de Características para glibc (ver feature_test_macros(7)):

wordexp(), wordfree():

    _XOPEN_SOURCE

DESCRIPCIÓN

La función wordexp() realiza una expansión similar a la del shell de la cadena s y devuelve el resultado en la estructura apuntada por p. El tipo de datos wordexp_t es una estructura que al menos tiene los campos we_wordc, we_wordv y we_offs. El campo we_wordc es un size_t que indica el número de palabras en la expansión de s. El campo we_wordv es un char** que apunta a la matriz de palabras encontradas. El campo we_offs de tipo size_t se utiliza a veces (dependiendo de flags, ver más abajo) para indicar el número de elementos iniciales en la matriz we_wordv que deben rellenarse con NULL.

La función wordfree() libera la memoria asignada de nuevo. Más precisamente, no libera su argumento, pero sí libera la matriz we_wordv y las cadenas a las que apunta.

El argumento de cadena

Dado que la expansión es la misma que la expansión realizada por el shell (ver sh(1)) de los parámetros de un comando, la cadena s no debe contener caracteres que serían ilegales en los parámetros de un comando de shell. En particular, no debe haber ningún carácter de nueva línea sin escapar ni caracteres |, &, ;, <, >, (, ), {, } fuera de un contexto de sustitución de comando o sustitución de parámetro.

Si el argumento s contiene una palabra que comienza con un carácter de comentario # no citado, entonces no se especifica si esa palabra y todas las palabras siguientes se ignoran, o si el # se trata como un carácter que no es de comentario.

La expansión

La expansión realizada consta de las siguientes etapas: expansión de tilde (reemplazando ~usuario por el directorio de inicio del usuario), sustitución de variables (reemplazando $FOO por el valor de la variable de entorno FOO), sustitución de comandos (reemplazando $(comando) o `comando` por la salida del comando), expansión aritmética, división de campos, expansión de comodines, eliminación de comillas.

El resultado de la expansión de parámetros especiales ($@, $*, $#, $?, $-, $$, $!, $0) no está especificado.

La división de campos se realiza utilizando la variable de entorno $IFS. Si no está establecida, los separadores de campos son espacio, tabulador y nueva línea.

La matriz de salida

La matriz we_wordv contiene las palabras encontradas, seguidas de un NULL.

El argumento flags

El argumento flag es una máscara de bits OR inclusiva de los siguientes valores:

WRDE_APPEND
Añadir las palabras encontradas a la matriz resultante de una llamada anterior.
WRDE_DOOFFS
Insertar we_offs NULLs iniciales en la matriz we_wordv. (Estos no se cuentan en el we_wordc devuelto.)
WRDE_NOCMD
No realizar sustitución de comandos.
WRDE_REUSE
El argumento p resultó de una llamada anterior a wordexp(), y no se llamó a wordfree(). Reutilizar el almacenamiento asignado.
WRDE_SHOWERR
Normalmente, durante la sustitución de comandos, stderr se redirige a /dev/null. Esta bandera especifica que stderr no debe ser redirigido.
WRDE_UNDEF
Considerar un error si se expande una variable de shell indefinida.

VALOR DE RETORNO

En caso de éxito, wordexp() devuelve 0. En caso de error, wordexp() devuelve uno de los siguientes valores distintos de cero:

WRDE_BADCHAR
Ocurrencia ilegal de nueva línea o de uno de los siguientes caracteres: |, &, ;, <, >, (, ), {, }.
WRDE_BADVAL
Se referenció una variable de shell indefinida, y la bandera WRDE_UNDEF nos indicó que consideráramos esto un error.
WRDE_CMDSUB
Se solicitó sustitución de comandos, pero la bandera WRDE_NOCMD nos indicó que consideráramos esto un error.
WRDE_NOSPACE
Sin memoria.
WRDE_SYNTAX
Error de sintaxis del shell, como paréntesis desequilibrados o comillas sin coincidir.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
wordexp () Seguridad en hilos MT-Unsafe race:utent const:env env sig:ALRM timer locale
wordfree () Seguridad en hilos MT-Safe

En la tabla anterior, utent en race:utent significa que si alguna de las funciones setutent(3), getutent(3) o endutent(3) se utiliza en paralelo en diferentes hilos de un programa, podrían producirse condiciones de carrera de datos. wordexp() llama a esas funciones, por lo que usamos race:utent para recordárselo a los usuarios.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001. glibc 2.1.

EJEMPLOS

La salida del siguiente programa de ejemplo es aproximadamente la de "ls [a-c]*.c".

#include <stdio.h>
#include <stdlib.h>
#include <wordexp.h>
int
main(void)
{
    wordexp_t p;
    char **w;
    wordexp("[a-c]*.c", &p, 0);
    w = p.we_wordv;
    for (size_t i = 0; i < p.we_wordc; i++)
        printf("%s\n", w[i]);
    wordfree(&p);
    exit(EXIT_SUCCESS);
}
