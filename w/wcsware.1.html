WCSWARE(1) Comandos de Usuario WCSWARE(1)

NOMBRE

wcsware - Extrae palabras clave WCS de una imagen

SINOPSIS

wcsware [<opción>]... [<archivo_fits>]

DESCRIPCIÓN

wcsware extrae las palabras clave WCS para una imagen del archivo FITS especificado, construye estructuras wcsprm para cada representación de coordenada encontrada y realiza una variedad de operaciones con ellas. Cuenta con una capacidad de "lint" (verificación de conformidad) como una de sus operaciones más útiles.

Por defecto, se permiten todas las extensiones conocidas del estándar FITS WCS, incluido el uso obsoleto. Sin embargo, en modo "lint", se fuerza la estricta conformidad con el estándar.

El archivo FITS puede especificarse según la sintaxis entendida por cfitsio, por ejemplo, "file.fits.gz+1" se refiere a la primera extensión (el segundo HDU) de un archivo FITS comprimido con gzip. Use "-" u omita el nombre del archivo para entrada desde stdin.

OPCIONES

-a<alt>
Especifica una representación de coordenada alternativa (ignorada si solo hay una). También se puede especificar como un índice de base 0 en el rango de 0 a 26, donde las alternativas se ordenan alfabéticamente después de la representación primaria.
-b
Usa wcsbth() para las cabeceras de imagen primarias, normalmente se usa wcspih(). (Implica -i.)
-c
Aplica wcspcx() a la estructura wcsprm para descomponer CDi_ja en PCi_ja y CDELTia.
-cp
Igual que -c, y también reorganiza los ejes.
-C
Igual que -c, descompone CDi_ja si está presente, de lo contrario recompone PCi_ja y CDELTia.
-Cp
Igual que -C, y también reorganiza los ejes.
-f
Aplica wcsfix() a la cabecera.
-h<hdu>
Cambia a la HDU número (base 1) que se espera que contenga un array de imagen. Anula la sintaxis de nombre de archivo extendido de cfitsio. También útil para entrada desde stdin.
-i
Permite palabras clave WCS de cabecera de imagen en cabeceras de tabla binaria.
-l
Valida (lint) los registros de palabras clave WCS en la cabecera FITS especificada para asegurar la conformidad con el estándar WCS. (Implica -s.)
-m
Aplica wcstrim() a la estructura wcsprm.
-o
Usa wcshdo() para traducir la estructura wcsprm a una cabecera FITS y mostrarla.
-p
Muestra la(s) estructura(s) usando wcsprt() (operación por defecto).
-P
Igual que -p pero no muestra una estructura por defecto.
-r
Requiere estricta adherencia al estándar FITS WCS, aunque permite las palabras clave obsoletas de la convención AIPS, CROTAn, EPOCH y VELREF, y también algunos otros usos obsoletos. (Debe seguir a -l si se requiere una verificación de conformidad relajada.)
-s
Requiere estricta adherencia al estándar FITS WCS, desautorizando todas las características obsoletas.
-t
Conciso (con -l), solo informa de los registros WCS rechazados.
-v
Detallado (con -l), también informa de los registros WCS reconocidos.
-w
Convierte coordenadas del mundo, obtenidas desde stdin, a coordenadas de píxel usando wcss2p().
-x
Convierte coordenadas de píxel, obtenidas desde stdin, a coordenadas del mundo usando wcsp2s().
-z
Muestra el tamaño de la estructura wcsprm, incluida la memoria asignada.
