NOMBRE

wineserver - el servidor de Wine

SINOPSIS

wineserver [opciones]

DESCRIPCIÓN

wineserver es un proceso demonio que proporciona a Wine aproximadamente los mismos servicios que el kernel de Windows proporciona en Windows.

wineserver normalmente se inicia automáticamente al lanzar wine(1), por lo que no deberías tener que preocuparte por él. Sin embargo, en algunos casos puede ser útil iniciar wineserver explícitamente con diferentes opciones, como se explica a continuación.

OPCIONES

-d[n], --debug[=n]
Establece el nivel de depuración a n. 0 significa ninguna información de depuración, 1 es el nivel normal y 2 es para una depuración extra detallada. Si no se especifica n, el valor predeterminado es 1. La salida de depuración se enviará a stderr. wine(1) habilitará automáticamente la depuración de nivel normal al iniciar wineserver si la opción +server está establecida en la variable WINEDEBUG.
-f, --foreground
Hace que el servidor permanezca en primer plano para facilitar la depuración, por ejemplo, al ejecutarlo bajo un depurador.
-h, --help
Muestra un mensaje de ayuda.
-k[n], --kill[=n]
Termina el wineserver en ejecución, opcionalmente enviando la señal n. Si no se especifica ninguna señal, envía primero una SIGINT y luego una SIGKILL. La instancia de wineserver que se termina se selecciona en función de la variable de entorno WINEPREFIX.
-p[n], --persistent[=n]
Especifica el retraso de persistencia de wineserver, es decir, el tiempo que el servidor permanecerá en ejecución cuando todos los procesos cliente hayan terminado. Esto evita el coste de apagar e iniciar de nuevo cuando los programas se lanzan en rápida sucesión. El tiempo de espera n está en segundos, el valor predeterminado es 3 segundos. Si no se especifica n, el servidor permanece indefinidamente.
-v, --version
Muestra información de la versión y sale.
-w, --wait
Espera hasta que el wineserver en ejecución termine.

ENTORNO

WINEPREFIX
Si está configurada, el contenido de esta variable se toma como el nombre del directorio donde wineserver almacena sus datos (el valor predeterminado es $HOME/.wine). Todos los procesos de wine que utilizan el mismo wineserver (es decir, el mismo usuario) comparten ciertas cosas como el registro, la memoria compartida y los objetos del kernel. Al establecer WINEPREFIX a diferentes valores para diferentes procesos de Wine, es posible ejecutar un número de sesiones de Wine verdaderamente independientes.

ARCHIVOS

~/.wine
Directorio que contiene datos específicos del usuario gestionados por wine.
/tmp/.wine-uid
Directorio que contiene el socket Unix del servidor y el archivo de bloqueo. Estos archivos se crean en un subdirectorio generado a partir de los números de dispositivo e inodo del directorio WINEPREFIX.

AUTORES

El autor original de wineserver es Alexandre Julliard. Muchas otras personas han contribuido con nuevas funciones y correcciones de errores. Para una lista completa, consulte los registros de confirmación de git.

ERRORES

Los errores se pueden informar en el rastreador de errores de Wine.

DISPONIBILIDAD

wineserver es parte de la distribución de Wine, que está disponible a través de WineHQ, el centro de desarrollo de Wine.
