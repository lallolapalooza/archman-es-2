wofi(1) Manual de Comandos Generales wofi(1)

NOMBRE

wofi - Un lanzador inspirado en rofi para compositores wlroots

SINOPSIS

wofi [opciones]

DESCRIPCIÓN

wofi es un programa de menú inspirado en rofi para compositores wlroots como sway. Está pensado para ser altamente personalizable y flexible con la ayuda de estilos CSS y un modo dmenu que permite una posibilidad infinita de scripts. Wofi puede ejecutarse sin caché en modo dmenu automáticamente invocándolo como dmenu mediante un enlace simbólico.

Wofi fue diseñado específicamente para wlroots y utiliza el protocolo wlr-layer-shell. Si tu compositor no soporta este protocolo o si estás en un entorno que no sea Wayland, wofi debe ejecutarse con --normal-window o fallará. Si deseas ejecutar wofi de esta manera, también puedes colocar normal_window=true en tu archivo de configuración para evitar especificar la opción en la línea de comandos.

OPCIONES

-h, --help
Muestra el mensaje de ayuda y luego sale.
-f, --fork
Crea un proceso hijo para el menú, permitiendo cerrar la terminal que lo ejecuta.
-c, --conf=RUTA
Especifica el archivo de configuración a utilizar.
-s, --style=RUTA
Especifica el archivo CSS a utilizar como hoja de estilos.
-C, --color=RUTA
Especifica el archivo de colores a utilizar.
-d, --dmenu
Ejecuta wofi en modo dmenu.
-S, --show=MODO
Especifica el modo en el que se ejecutará. Una lista de modos se puede encontrar en wofi(7).
-W, --width=ANCHO
Especifica el ancho del menú en píxeles o como porcentaje del tamaño de la pantalla, el valor por defecto es 50%. Se utilizan píxeles a menos que el número termine en %.
-H, --height=ALTURA
Especifica la altura del menú en píxeles o como porcentaje del tamaño de la pantalla, el valor por defecto es 40%. Se utilizan píxeles a menos que el número termine en %.
-p, --prompt=INDICADOR
Establece el indicador que se mostrará en el cuadro de búsqueda, por defecto es el nombre del modo.
-x, --xoffset=DESPLAZAMIENTO
Establece el desplazamiento X desde la ubicación en píxeles, por defecto es 0.
-y, --yoffset=DESPLAZAMIENTO
Establece el desplazamiento Y desde la ubicación en píxeles, por defecto es 0.
-n, --normal-window
Ejecuta wofi en una ventana normal en lugar de usar wlr-layer-shell.
-I, --allow-images
Permite que las secuencias de escape de imágenes sean procesadas y renderizadas.
-m, --allow-markup
Permite que el marcado Pango sea procesado y renderizado.
-k, --cache-file=RUTA
Especifica el archivo de caché para cargar/guardar caché, por defecto es $XDG_CACHE_HOME/wofi-<nombre del modo> donde <nombre del modo> es el nombre del modo. Si no se especifica $XDG_CACHE_HOME se usa ~/.cache.
-t, --term=TERMINAL
Especifica la terminal a utilizar al ejecutar un programa en una terminal. Esto anula el orden de ejecución de terminal predeterminado, que es kitty, alacritty, wezterm, foot, termite, gnome-terminal, weston-terminal en ese orden.
-P, --password [caracter]
Ejecuta wofi en modo contraseña con un carácter opcional para usar. Si no se especifica ningún carácter, se usa * por defecto.
-e, --exec-search
Al activar una búsqueda con Enter se ejecutará la búsqueda, no el primer resultado.
-E, --no-custom-entry
Solo se enviarán entradas a los modos, nunca el contenido del cuadro de búsqueda.
-b, --hide-scroll
Oculta las barras de desplazamiento.
-M, --matching=MODO
Especifica el modo de coincidencia, puede ser contains, strict-contains, multi-contains, o fuzzy. Por defecto es contains.
-i, --insensitive
Habilita la búsqueda sin distinción entre mayúsculas y minúsculas.
-q, --parse-search
Analiza las secuencias de escape de imágenes y Pango, evitando que se usen para la búsqueda.
-v, --version
Muestra la versión y luego sale.
-l, --location=UBICACIÓN
Especifica la ubicación. Consulta wofi(7) para más información. Por defecto es center.
-a, --no-actions
Deshabilita acciones múltiples para los modos que lo soportan.
-D, --define=CLAVE=VALOR
Establece una opción de configuración
-L, --lines=LÍNEAS
Especifica la altura en número de líneas en lugar de píxeles.
-w, --columns=COLUMNAS
Especifica el número de columnas a mostrar, por defecto es 1.
-O, --sort-order=ORDEN
Especifica el orden de clasificación por defecto. Actualmente hay dos órdenes: predeterminado y alfabético. Consulta wofi(7) para más detalles.
-G, --gtk-dark
Indica a wofi que use la variante oscura del tema GTK actual, si está disponible.
-Q, --search
Especifica algo para buscar inmediatamente al abrir
-o, --monitor
Establece el monitor en el que se abrirá
-r, --pre-display-cmd
Si está establecido, la entrada seleccionable no se mostrará tal cual, sino que se mostrará basándose en la salida de este comando, que puede ser cualquier cosa. Se sugiere usarlo con "echo %s | algún_cmd" o "algún_cmd %s", ya que la cadena se reemplaza de forma similar a printf. Esto no afectará la salida de wofi una vez que se haya realizado una selección, permitiéndote mostrar algo diferente a la salida original.
-j, --hide-search
Oculta la barra de búsqueda.

CONFIGURACIÓN

Wofi tiene 3 archivos principales utilizados para la configuración. Todos los archivos son completamente opcionales.

1.
El archivo de configuración, que por defecto es $XDG_CONFIG_HOME/wofi/config.
2.
El archivo CSS, que por defecto es $XDG_CONFIG_HOME/wofi/style.css.
3.
El archivo de colores, que por defecto es la caché de pywal $XDG_CACHE_HOME/wal/colors.

Las 3 rutas se pueden especificar manualmente utilizando la bandera correspondiente de la línea de comandos. En el caso de las 2 últimas, también se pueden especificar en el archivo de configuración.

En caso de que $XDG_CONFIG_HOME no se especifique, por defecto es ~/.config, de manera similar, si $XDG_CACHE_HOME no se especifica, por defecto es ~/.cache.

La información sobre los formatos de estos archivos se puede encontrar en wofi(5).
