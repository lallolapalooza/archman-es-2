writeback.bt(8) Manual del Administrador del Sistema writeback.bt(8)

NOMBRE

writeback.bt - Rastrea eventos de escritura de archivos del sistema con detalles. Usa bpftrace/eBPF.

SINOPSIS

writeback.bt

DESCRIPCIÓN

Esto rastrea cuándo las páginas "sucias" del sistema de archivos se escriben en el disco mediante la escritura del kernel, y muestra detalles, incluyendo cuándo ocurrió el evento y la duración del mismo. Esto puede ser útil para correlacionar estos tiempos con otros problemas de rendimiento, y si hay una coincidencia, sería una pista de que el problema puede ser causado por la escritura. La rapidez con la que el kernel realiza la escritura se puede ajustar: consulte la documentación del kernel, por ejemplo, vm.dirty_writeback_centisecs.

Esto utiliza los puntos de rastreo tracepoint:writeback:writeback_start y tracepoint:writeback:writeback_written.

Dado que esto utiliza BPF, solo el usuario root puede usar esta herramienta.

REQUISITOS

CONFIG_BPF y bpftrace.

EJEMPLOS

Rastrea todos los eventos de escritura con marcas de tiempo y detalles de latencia:
# writeback.bt

CAMPOS

TIEMPO
Hora en que el evento de escritura se completó, en formato %H:%M:%S.
DISPOSITIVO
Nombre del dispositivo en formato de número mayor:menor.
PÁGINAS
Páginas escritas durante la operación de escritura.
RAZÓN
Razón del evento de escritura. Puede ser "background", "vmscan", "sync", "periodic", etc.
ms
Duración del evento de escritura en milisegundos.

SOBRECARGA

Dado que se espera que los eventos de escritura sean infrecuentes (<10/seg), se espera que la sobrecarga de esta herramienta sea insignificante (cercana al 0%).

FUENTE

Esto es de bpftrace.

https://github.com/bpftrace/bpftrace

Busque también en la distribución de bpftrace un archivo _examples.txt complementario que contenga ejemplos de uso, salida y comentarios para esta herramienta.
