NOMBRE

waybar - módulo de idioma de sway

DESCRIPCIÓN

El módulo language muestra la disposición actual del teclado en Sway.

CONFIGURACIÓN

Abordado por sway/language.

format:
tipo: string
predeterminado: {}
El formato, cómo se mostrará el diseño.

hide-single-layout:
tipo: bool
predeterminado: false
Define la visibilidad del módulo si se configura un solo diseño.

tooltip-format:
tipo: string
predeterminado: {}
El formato, cómo se mostrará el diseño en la información sobre herramientas.

tooltip:
tipo: bool
predeterminado: true
Opción para deshabilitar la información sobre herramientas al pasar el ratón.

menu:
tipo: string
Acción que muestra el menú.

menu-file:
tipo: string
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: bool
predeterminado: false
Permite que este módulo consuma todo el espacio sobrante dinámicamente.

REEMPLAZOS DE FORMATO

{short}: Nombre corto del diseño (por ejemplo, "us"). Equivale a {}.

{shortDescription}: Descripción corta del diseño (por ejemplo, "en").

{long}: Nombre largo del diseño (por ejemplo, "Inglés (Dvorak)").

{variant}: Variante del diseño (por ejemplo, "dvorak").

{flag}: Bandera del país del diseño.

EJEMPLOS

"sway/language": {
	"format": "{}",
},
"sway/language": {
	"format": "{short} {variant}",
}
