WORD-LIST-COMPRESS(1) Manual de usuario abreviado de Aspell WORD-LIST-COMPRESS(1)

NOMBRE

word-list-compress - compresor/descompresor de listas de palabras para GNU Aspell

SINOPSIS

word-list-compress c[ompress] | d[ecompress]

DESCRIPCIÓN

word-list-compress comprime o descomprime listas de palabras ordenadas para su uso con el corrector ortográfico GNU Aspell.

COMANDOS

-c, c, compress
Comprime la lista de palabras en texto plano leída desde la entrada estándar.
-d, d, decompress
Descomprime la lista de palabras comprimida leída desde la entrada estándar.

EJEMPLOS

Aquí tienes algunos ejemplos de cómo puedes usar word-list-compress

word-list-compress d <wordlist.cwl >wordlist.txt
Descomprime el archivo wordlist.cwl al archivo de texto wordlist.txt
word-list-compress c <wordlist.wl >wordlist.cwl 2>errors.txt
Comprime wordlist.wl a wordlist.cwl y envía cualquier mensaje de error a un archivo de texto llamado errors.txt
LC_COLLATE=C sort -u <wordlist.txt | word-list-compress c >wordlist.cwl
Ordena una lista de palabras y luego la canaliza a word-list-compress para crear un archivo de palabras binario comprimido wordlist.cwl.
word-list-compress d <words.cwl | aspell create master ./words.rws
Descomprime una lista de palabras y luego la canaliza a aspell(1) para crear una lista de ortografía. Por favor, consulta el manual de información de aspell(1) para un uso y opciones correctos.

CONSEJOS

Word-list-compress se usa mejor con archivos de tipo lista de palabras ordenadas. No es un programa de compresión de propósito general, ya que los archivos resultantes pueden aumentar de tamaño.

Word-list-compress acepta hasta 255 caracteres de texto en el rango {0x21...0xFF}. Si tu lista de palabras requiere un conjunto de caracteres más grande para ciertos idiomas o una longitud mayor para uso múltiple, científico, médico, técnico u otro, se recomienda comprimir tu lista de palabras usando prezip-bin(1)

DIAGNÓSTICOS

Word-list-compress normalmente sale con un código de retorno de 0. Si encuentra un error, se envía un mensaje a la salida de error estándar (stderr) y word-list-compress sale con un valor de retorno distinto de cero. Los mensajes de error se enumeran a continuación:

(muestra el mensaje de ayuda/uso)
Se proporcionó un comando desconocido en la línea de comandos, por lo que word-list-compress muestra un mensaje de uso en la salida de error estándar.
Entrada Corrupta
Esto es solo para el comando de descompresión d. El archivo de entrada tiene un formato desconocido o el archivo/flujo de entrada está corrupto. Puede que tengas alguna salida válida, pero word-list-compress no pudo completar el proceso. Si el archivo de entrada es una lista de palabras comprimida pero no tienes archivo de salida, puede ser una versión más reciente del archivo comprimido prezip-bin(1), si es así, intenta descomprimir el archivo con prezip-bin(1) en su lugar.
Error en los Datos de Salida
La salida está llena, protegida contra escritura o tiene un error y ya no se puede escribir en ella.

VER TAMBIÉN

Aspell está completamente documentado en su manual Texinfo. Consulte la entrada `aspell' en info para obtener una documentación más completa.

REPORTAR ERRORES

Para obtener ayuda, consulte la página principal de Aspell en http://aspell.net y envíe informes de errores/comentarios a la lista de usuarios de Aspell en la dirección anterior.
