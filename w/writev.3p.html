PROLOG

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

writev — escribir un vector

SINOPSIS

#include <sys/uio.h>
ssize_t writev(int fildes, const struct iovec *iov, int iovcnt);

DESCRIPCIÓN

La función writev() será equivalente a write(), excepto como se describe a continuación. La función writev() recopilará datos de salida de los iovcnt buffers especificados por los miembros de la matriz iov: iov[0], iov[1], ..., iov[iovcnt-1]. El argumento iovcnt será válido si es mayor que 0 y menor o igual a {IOV_MAX}, como se define en <limits.h>.

Cada entrada iovec especifica la dirección base y la longitud de un área en memoria de la que se deben escribir los datos. La función writev() escribirá siempre un área completa antes de proceder a la siguiente.

Si fildes se refiere a un archivo regular y todos los miembros iov_len en la matriz apuntada por iov son 0, writev() devolverá 0 y no tendrá ningún otro efecto. Para otros tipos de archivo, el comportamiento no está especificado.

Si la suma de los valores iov_len es mayor que {SSIZE_MAX}, la operación fallará y no se transferirán datos.

VALOR DE RETORNO

Al completarse con éxito, writev() devolverá el número de bytes realmente escritos. De lo contrario, devolverá un valor de -1, el puntero al archivo permanecerá inalterado y errno se establecerá para indicar un error.

ERRORES

Consulte write().

Además, la función writev() fallará si:

EINVAL
La suma de los valores iov_len en la matriz iov desbordaría un ssize_t.

La función writev() puede fallar y establecer errno en:

EINVAL
El argumento iovcnt fue menor o igual a 0, o mayor que {IOV_MAX}.

Las siguientes secciones son informativas.

EJEMPLOS

Escribir datos de una matriz

El siguiente ejemplo escribe datos de los buffers especificados por los miembros de la matriz iov en el archivo asociado con el descriptor de archivo fd.

#include <sys/types.h>
#include <sys/uio.h>
#include <unistd.h>
...
ssize_t bytes_written;
int fd;
char *buf0 = "short string\n";
char *buf1 = "This is a longer string\n";
char *buf2 = "This is the longest string in this example\n";
int iovcnt;
struct iovec iov[3];
iov[0].iov_base = buf0;
iov[0].iov_len = strlen(buf0);
iov[1].iov_base = buf1;
iov[1].iov_len = strlen(buf1);
iov[2].iov_base = buf2;
iov[2].iov_len = strlen(buf2);
...
iovcnt = sizeof(iov) / sizeof(struct iovec);
bytes_written = writev(fd, iov, iovcnt);
...
