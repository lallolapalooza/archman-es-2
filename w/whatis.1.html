WHATIS(1) Utilidades del paginador manual WHATIS(1)

NOMBRE

whatis - muestra descripciones de páginas del manual de una línea

SINOPSIS

whatis [-dlv?V] [-r|-w] [-s lista] [-m sistema[,...]] [-M ruta] [-L locale] [-C archivo] nombre ...

DESCRIPCIÓN

Cada página del manual tiene una breve descripción disponible dentro de ella. whatis busca nombres de páginas del manual y muestra las descripciones de las páginas del manual de cualquier nombre coincidente.

nombre puede contener comodines (-w) o ser una expresión regular (-r). Al usar estas opciones, puede ser necesario citar el nombre o escapar (\) los caracteres especiales para evitar que la shell los interprete.

Las bases de datos index se utilizan durante la búsqueda y son actualizadas por el programa mandb. Dependiendo de tu instalación, esto puede ser ejecutado por un trabajo cron periódico o puede ser necesario ejecutarlo manualmente después de que se hayan instalado nuevas páginas del manual. Para producir una base de datos de texto estilo antiguo whatis a partir de la base de datos relativa index, ejecuta el comando:

whatis -M ruta_man -w '*' | sort > ruta_man/whatis

donde ruta_man es una jerarquía de páginas del manual como /usr/man.

OPCIONES

-d, --debug
Imprime información de depuración.
-v, --verbose
Imprime mensajes de advertencia detallados.
-r, --regex
Interpreta cada nombre como una expresión regular. Si un nombre coincide con cualquier parte de un nombre de página, se realizará una coincidencia. Esta opción hace que whatis sea algo más lento debido a la naturaleza de las búsquedas en la base de datos.
-w, --wildcard
Interpreta cada nombre como un patrón que contiene comodines de estilo de shell. Para que se realice una coincidencia, un nombre expandido debe coincidir con el nombre completo de la página. Esta opción hace que whatis sea algo más lento debido a la naturaleza de las búsquedas en la base de datos.
-l, --long
No trunca la salida al ancho del terminal. Normalmente, la salida se truncará al ancho del terminal para evitar resultados feos de secciones NAME mal escritas.
-s lista, --sections=lista, --section=lista
Busca solo en las secciones del manual dadas. lista es una lista de secciones separada por dos puntos o comas. Si una entrada en lista es una sección simple, por ejemplo "3", entonces la lista de descripciones mostrada incluirá páginas en las secciones "3", "3perl", "3x", y así sucesivamente; mientras que si una entrada en lista tiene una extensión, por ejemplo "3perl", entonces la lista solo incluirá páginas en esa parte exacta de la sección del manual.
-m sistema[,...], --systems=sistema[,...]
Si este sistema tiene acceso a los nombres de páginas del manual de otros sistemas operativos, se puede acceder a ellos usando esta opción. Para buscar los nombres de páginas del manual de NewOS, usa la opción -m NewOS.

El sistema especificado puede ser una combinación de nombres de sistemas operativos separados por comas. Para incluir una búsqueda de los nombres de páginas del manual del sistema operativo nativo, incluye el nombre del sistema man en la cadena de argumentos. Esta opción anulará la variable de entorno $SYSTEM.

-M ruta, --manpath=ruta
Especifica un conjunto alternativo de jerarquías de páginas del manual separadas por dos puntos para buscar. Por defecto, whatis usa la variable de entorno $MANPATH, a menos que esté vacía o no esté configurada, en cuyo caso determinará una ruta de manual apropiada basándose en tu variable de entorno $PATH. Esta opción anula el contenido de $MANPATH.
-L locale, --locale=locale
whatis determinará normalmente tu configuración regional actual mediante una llamada a la función C setlocale(3) que interroga varias variables de entorno, posiblemente incluyendo $LC_MESSAGES y $LANG. Para anular temporalmente el valor determinado, usa esta opción para proporcionar una cadena locale directamente a whatis. Ten en cuenta que no tendrá efecto hasta que comience la búsqueda de páginas. La salida, como el mensaje de ayuda, siempre se mostrará en la configuración regional determinada inicialmente.
-C archivo, --config-file=archivo
Usa este archivo de configuración del usuario en lugar del predeterminado ~/.manpath.
-?, --help
Imprime un mensaje de ayuda y sale.
--usage
Imprime un breve mensaje de uso y sale.
-V, --version
Muestra información de la versión.

ESTADO DE SALIDA

0
Ejecución exitosa del programa.
1
Error de uso, sintaxis o archivo de configuración.
2
Error operacional.
16
No se encontró nada que coincidiera con los criterios especificados.

ENTORNO

SYSTEM
Si $SYSTEM está configurado, tendrá el mismo efecto que si se hubiera especificado como argumento de la opción -m.
MANPATH
Si $MANPATH está configurado, su valor se interpreta como la ruta de búsqueda de jerarquía de páginas del manual separada por dos puntos a utilizar.

Consulta la sección RUTA DE BÚSQUEDA de manpath(5) para el comportamiento predeterminado y los detalles de cómo se maneja esta variable de entorno.

MANWIDTH
Si $MANWIDTH está configurado, su valor se utiliza como el ancho del terminal (ver la opción --long). Si no está configurado, el ancho del terminal se calculará utilizando el valor de $COLUMNS, y ioctl(2) si está disponible, o cayendo de nuevo a 80 caracteres si todo lo demás falla.

ARCHIVOS

/usr/share/man/index.(bt|db|dir|pag)
Una caché de base de datos index global tradicional.
/var/cache/man/index.(bt|db|dir|pag)
Una caché de base de datos index global compatible con FHS.
/usr/share/man/.../whatis
Una base de datos de texto whatis tradicional.
