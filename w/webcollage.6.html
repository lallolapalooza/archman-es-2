NOMBRE

webcollage - un collage de imágenes aleatorias de la World Wide Web

SINOPSIS

webcollage [--display host:display.screen] [--root] [--window-id número] [--window-id id] [--verbose] [--timeout secs] [--delay secs] [--background bg] [--no-output] [--urls-only] [--imagemap nombre-base] [--size AnxAl] [--opacity ratio] [--filter comando] [--filter2 comando] [--http-proxy host[:puerto]] [--dictionary archivo-diccionario] [--directory dir] [--fps]

DESCRIPCIÓN

Este salvapantallas crea collages de imágenes aleatorias de la World Wide Web. Encuentra las imágenes introduciendo palabras aleatorias en varios motores de búsqueda, y luego extrae imágenes (o secciones de imágenes) de las páginas devueltas. Un cliente satisfecho lo describió como "un baño cerebral de cultura pop sin parar".

También puedes verlo en acción en https://www.jwz.org/webcollage/

OPCIONES

webcollage acepta las siguientes opciones:

--root o --window-id número
Dibuja en la ventana especificada. Las imágenes se colocan en la ventana raíz usando el programa xscreensaver-getimage(6).
--verbose o --v
Imprime diagnósticos en stderr. Múltiples interruptores -v aumentan la cantidad de salida. -v imprimirá las URLs de las imágenes y dónde se colocaron; -vv imprimirá cualquier advertencia y todas las URLs que se están cargando; -vvv imprimirá información sobre qué URLs fueron rechazadas; y así sucesivamente.
--timeout segundos
Cuánto esperar a que una URL se complete antes de darse por vencido y pasar a la siguiente. Por defecto 30 segundos.
--delay segundos
Cuánto tiempo esperar entre imágenes. Por defecto 2 segundos. (Recuerda que este programa probablemente pasa mucho tiempo esperando la red).
--background color o archivo
Qué usar para el fondo sobre el cual se pegan las imágenes. Puede ser un nombre de color, una especificación RGB hexadecimal en la forma '#rrggbb', o el nombre de un archivo de imagen.
--size AnxAl
Normalmente, la imagen de salida tendrá el tamaño de la pantalla (o de la ventana de destino). Esto te permite especificar el tamaño deseado.
--opacity ratio
Con qué transparencia pegar las imágenes, siendo 0.0 "completamente transparente" y 1.0 "opaco". Por defecto 0.85. Un valor de alrededor de 0.3 producirá una imagen interesantemente borrosa después de un tiempo.
--no-output
Si se especifica esta opción, no se generará ninguna imagen de salida compuesta. Esto solo es útil cuando se usa junto con --verbose.
--urls-only
Si se especifica esta opción, no se generará ninguna imagen de salida compuesta: en su lugar, se imprimirá una lista de URLs de imágenes en stdout.
--imagemap nombre-base
Si se especifica esta opción, en lugar de escribir una imagen en la ventana raíz, se crearán dos archivos: "base.html" y "base.jpg". El JPEG será el collage; el archivo HTML incluirá esa imagen y una serie de rectángulos clickables que enlazan las sub-imágenes a las páginas en las que se encontraron, como se ve en la versión web de WebCollage en https://www.jwz.org/webcollage/
--filter comando
Filtra todas las imágenes de origen a través de este comando. El comando debe tomar un archivo PPM en stdin y escribir un nuevo archivo PPM en stdout. Una buena opción para un filtro sería: 
webcollage -root -filter 'vidwhacker -stdin -stdout'
--filter2 comando
Filtra la imagen *compuesta* a través de este comando. La opción -filter se aplica a las sub-imágenes; la opción -filter2 se aplica a la imagen final de pantalla completa.
--http-proxy host:puerto
Si debes pasar por un proxy para conectarte a la web, puedes especificarlo con esta opción, o con las variables de entorno $http_proxy o $HTTP_PROXY.
--dictionary archivo
Webcollage normalmente consulta el diccionario de corrección ortográfica del sistema para generar palabras que introducir en los motores de búsqueda. Puedes especificar un diccionario alternativo con esta opción.

Ten en cuenta que, por defecto, webcollage busca imágenes usando varios métodos diferentes, no todos los cuales implican palabras del diccionario, por lo que usar un archivo de diccionario "temático" no será, por sí solo, tan efectivo como podrías esperar.

--directory dir
En lugar de buscar imágenes en la web, usa el contenido del directorio dado.
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU (solo en MacOS).

ENTORNO

DISPLAY
para obtener el host y el número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
http_proxy o HTTP_PROXY
para obtener el host y puerto del proxy HTTP por defecto.

ARCHIVOS Y URLS

/usr/dict/words, /usr/share/lib/dict/words, o /usr/share/dict/words para encontrar las palabras aleatorias que introducir en varios campos de búsqueda, incluyendo Google, Bing, Flickr, Imgur y Tumblr.

SENOS

Internet siendo lo que es, absolutamente cualquier cosa podría aparecer en el collage, incluyendo -- muy posiblemente -- pornografía, o incluso desnudez.

ERRORES

Los GIFs animados no son compatibles: solo se usará el primer fotograma.

VER TAMBIÉN
