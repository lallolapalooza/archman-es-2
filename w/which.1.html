WHICH(1) Manual de comandos generales WHICH(1)

NOMBRE

which - muestra la ruta completa de los comandos (del shell).

SINOPSIS

which [opciones] [--] nombreprograma [...]

DESCRIPCIÓN

Which toma uno o más argumentos. Para cada uno de sus argumentos, imprime en stdout la ruta completa de los ejecutables que se habrían ejecutado si este argumento se hubiera introducido en el prompt del shell. Lo hace buscando un ejecutable o script en los directorios listados en la variable de entorno PATH usando el mismo algoritmo que bash(1).

Esta página del manual se genera a partir del archivo which.texinfo.

OPCIONES

--all, -a
Imprime todos los ejecutables coincidentes en PATH, no solo el primero.
--read-alias, -i
Lee alias de stdin, reportando los coincidentes en stdout. Esto es útil en combinación con el uso de un alias para sí mismo. Por ejemplo
alias which=’alias | which -i’.
--skip-alias
Ignora la opción ‘--read-alias’, si existe. Esto es útil para buscar explícitamente binarios normales, mientras se usa la opción ‘--read-alias’ en un alias o función para which.
--read-functions
Lee definiciones de funciones de shell desde stdin, reportando las coincidentes en stdout. Esto es útil en combinación con el uso de una función de shell para sí mismo. Por ejemplo:
which() { declare -f | which --read-functions $@ }
export -f which
--skip-functions
Ignora la opción ‘--read-functions’, si existe. Esto es útil para buscar explícitamente binarios normales, mientras se usa la opción ‘--read-functions’ en un alias o función para which.
--skip-dot
Omite directorios en PATH que comienzan con un punto.
--skip-tilde
Omite directorios en PATH que comienzan con una tilde y ejecutables que residen en el directorio HOME.
--show-dot
Si un directorio en PATH comienza con un punto y se encontró un ejecutable coincidente para esa ruta, imprime "./nombreprograma" en lugar de la ruta completa.
--show-tilde
Imprime una tilde cuando un directorio coincide con el directorio HOME. Esta opción se ignora cuando which se invoca como root.
--tty-only
Deja de procesar opciones a la derecha si no se está en tty.
--version,-v,-V
Imprime información de versión en la salida estándar y luego sale exitosamente.
--help
Imprime información de uso en la salida estándar y luego sale exitosamente.

VALOR DE RETORNO

Which devuelve el número de argumentos fallidos, o -1 cuando no se dio ningún ‘nombreprograma’.

EJEMPLO

La forma recomendada de usar esta utilidad es agregando un alias (shell C) o una función de shell (shell Bourne) para which como la siguiente:

[ba]sh:


which ()
{
  (alias; declare -f) | /usr/bin/which --tty-only --read-alias --read-functions --show-tilde --show-dot $@
}
export -f which

[t]csh:


alias which ’alias | /usr/bin/which --tty-only --read-alias --show-dot --show-tilde’

Esto imprimirá el ~/ y ./ legibles al iniciar which desde tu prompt, mientras que seguirá imprimiendo la ruta completa cuando se use desde un script:


> which q2
~/bin/q2
> echo $(which q2)
/home/carlo/bin/q2

ERRORES

El directorio HOME se determina buscando la variable de entorno HOME, que se aborta si esta variable no existe. Which considerará dos directorios equivalentes como diferentes cuando uno de ellos contenga una ruta con un enlace simbólico.
