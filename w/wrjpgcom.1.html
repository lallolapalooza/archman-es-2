NOMBRE

wrjpgcom - inserta comentarios de texto en un archivo JPEG

SINOPSIS

wrjpgcom [ -replace ] [ -comment texto ] [ -cfile nombre ] [ nombrearchivo ]

DESCRIPCIÓN

wrjpgcom lee el archivo JPEG/JFIF especificado, o la entrada estándar si no se nombra ningún archivo, y genera un nuevo archivo JPEG/JFIF en la salida estándar. Se agrega un bloque de comentarios al archivo.

El estándar JPEG permite que los bloques de "comentarios" (COM) ocurran dentro de un archivo JPEG. Aunque el estándar no define realmente para qué sirven los bloques COM, se usan ampliamente para almacenar cadenas de texto proporcionadas por el usuario. Esto le permite agregar anotaciones, títulos, términos de índice, etc. a sus archivos JPEG y recuperarlos más tarde como texto. Los bloques COM no interfieren con la imagen almacenada en el archivo JPEG. El tamaño máximo de un bloque COM es 64K, pero puede tener tantos como desee en un archivo JPEG.

wrjpgcom agrega un bloque COM, que contiene el texto que usted proporciona, a un archivo JPEG. Normalmente, el bloque COM se agrega después de cualquier bloque COM existente; pero puede eliminar los bloques COM antiguos si lo desea.

OPCIONES

Los nombres de las opciones se pueden abreviar y no distinguen mayúsculas y minúsculas.

-replace
Elimina cualquier bloque COM existente del archivo.
-comment texto
Proporciona texto para un nuevo bloque COM en la línea de comandos.
-cfile nombre
Lee el texto para el nuevo bloque COM desde un archivo con nombre.

Si solo tiene una línea de texto de comentario para agregar, puede proporcionarla en la línea de comandos con -comment. El texto del comentario debe estar rodeado de comillas para que se trate como un solo argumento. Se pueden leer comentarios más largos desde un archivo de texto.

Si no proporciona ni -comment ni -cfile, entonces wrjpgcom leerá el texto del comentario desde la entrada estándar. (En este caso, DEBE proporcionarse un nombre de archivo de imagen de entrada, para que el archivo JPEG de origen provenga de otro lugar). Puede ingresar múltiples líneas, hasta 64 KB. Escriba un indicador de fin de archivo (generalmente Ctrl-D) para finalizar la entrada de texto del comentario.

wrjpgcom no agregará un bloque COM si la cadena de comentario proporcionada está vacía. Por lo tanto, -replace -comment "" se puede usar para eliminar todos los bloques COM de un archivo.

EJEMPLOS

Agrega un comentario corto a in.jpg, produciendo out.jpg:

wrjpgcom -c "Vista de mi patio trasero" in.jpg > out.jpg

Adjunta un comentario largo previamente almacenado en comment.txt:

wrjpgcom in.jpg < comment.txt > out.jpg

o equivalentemente

wrjpgcom -cfile comment.txt < in.jpg > out.jpg
