NOMBRE

waybar - módulo bluetooth

DESCRIPCIÓN

El módulo bluetooth muestra información sobre un controlador bluetooth y sus conexiones.

CONFIGURACIÓN

Abordado por bluetooth

controller:
tipo: string
Utiliza el controlador con el alias definido. De lo contrario, se utiliza un controlador aleatorio. Se recomienda definirlo cuando hay más de un controlador disponible para el sistema.

format-device-preference:
tipo: array
Una clasificación de dispositivos bluetooth, abordados por sus alias. El orden es de primero mostrado a último mostrado.
Si esta opción de configuración no está definida o ninguno de los dispositivos en la lista está conectado, volverá a mostrar el último dispositivo conectado.

format:
tipo: string
por defecto:  {status}
El formato, cómo se debe mostrar la información. Este formato se utiliza cuando no se especifican otros formatos.

format-disabled:
tipo: string
Este formato se utiliza cuando el controlador mostrado está deshabilitado.

format-off:
tipo: string
Este formato se utiliza cuando el controlador mostrado está apagado.

format-on:
tipo: string
Este formato se utiliza cuando el controlador mostrado está encendido sin dispositivos conectados.

format-connected:
tipo: string
Este formato se utiliza cuando el controlador mostrado está conectado a al menos 1 dispositivo.

format-no-controller:
tipo: string
Este formato se utiliza cuando no se encuentra ningún controlador bluetooth.

format-icons:
tipo: array/object
Basándose en el porcentaje actual de la batería (ver sección CARACTERÍSTICA EXPERIMENTAL DE PORCENTAJE DE BATERÍA), se selecciona el icono correspondiente.
El orden es de bajo a alto. Solo mostrará el icono del porcentaje de batería actual en las opciones de configuración *-connected-battery.
O por el estado si es un objeto. Volverá al estado habilitado si sus derivados no están definidos (encendido, apagado, conectado).

rotate:
tipo: integer
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

max-length:
tipo: integer
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
tipo: integer
La longitud mínima en caracteres que el módulo debe aceptar.

align:
tipo: float
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: string
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir la posición.

on-click:
tipo: string
Comando a ejecutar al hacer clic en el módulo.

on-click-middle:
tipo: string
Comando a ejecutar al hacer clic con la rueda del ratón en el módulo.

on-click-right:
tipo: string
Comando a ejecutar al hacer clic derecho en el módulo.

on-scroll-up:
tipo: string
Comando a ejecutar al desplazarse hacia arriba en el módulo.

on-scroll-down:
tipo: string
Comando a ejecutar al desplazarse hacia abajo en el módulo.

smooth-scrolling-threshold:
tipo: double
Umbral a utilizar al desplazarse.

tooltip:
tipo: bool
por defecto: true
Opción para deshabilitar la información emergente al pasar el ratón por encima.

tooltip-format:
tipo: string
El formato, cómo se debe mostrar la información en la información emergente. Este formato se utiliza cuando no se especifican otros formatos.

tooltip-format-disabled:
tipo: string
Este formato se utiliza cuando el controlador mostrado está deshabilitado.

tooltip-format-off:
tipo: string
Este formato se utiliza cuando el controlador mostrado está apagado.

tooltip-format-on:
tipo: string
Este formato se utiliza cuando el controlador mostrado está encendido sin dispositivos conectados.

tooltip-format-connected:
tipo: string
Este formato se utiliza cuando el controlador mostrado está conectado a al menos 1 dispositivo.

tooltip-format-no-controller:
tipo: string
Este formato se utiliza cuando no se encuentra ningún controlador bluetooth.

tooltip-format-enumerate-connected:
tipo: string
Este formato se utiliza para definir cómo se debe mostrar cada dispositivo conectado dentro del reemplazo de formato device_enumerate en el menú de información emergente.

menu:
tipo: string
Acción que abre el menú.

menu-file:
tipo: string
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: bool
por defecto: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

{status}: Estado del dispositivo bluetooth.

{icon}: Icono, como se define en format-icons.

{num_connections}: Número de conexiones que tiene el controlador mostrado.

{controller_address}: Dirección del controlador mostrado.

{controller_address_type}: Tipo de dirección del controlador mostrado.

{controller_alias}: Alias del controlador mostrado.

{device_address}: Dirección del dispositivo mostrado.

{device_address_type}: Tipo de dirección del dispositivo mostrado.

{device_alias}: Alias del dispositivo mostrado.

{device_enumerate}: Muestra una lista de todos los dispositivos conectados, cada uno en una línea separada. Define el formato de cada dispositivo con las opciones de configuración tooltip-format-enumerate-connected y/o tooltip-format-enumerate-connected-battery. Solo se puede usar en las opciones de formato relacionadas con la información emergente.

CARACTERÍSTICA EXPERIMENTAL DE PORCENTAJE DE BATERÍA

En el momento de escribir esto, las características experimentales de BlueZ deben estar activadas para que las opciones de porcentaje de batería que se enumeran a continuación funcionen.

REEMPLAZO DE FORMATO

{device_battery_percentage}: Porcentaje de batería del dispositivo mostrado si está disponible. Úsalo solo en las opciones de configuración definidas a continuación.

CONFIGURACIÓN

format-connected-battery:
tipo: string
Este formato se utiliza cuando el dispositivo mostrado proporciona su porcentaje de batería.

tooltip-format-connected-battery:
tipo: string
Este formato se utiliza cuando el dispositivo mostrado proporciona su porcentaje de batería.

tooltip-format-enumerate-connected-battery:
tipo: string
Este formato se utiliza para definir cómo se debe mostrar cada dispositivo conectado con batería dentro de la opción de formato device_enumerate.
Cuando esta opción de configuración no está definida, recurrirá a la opción de configuración tooltip-format-enumerate-connected.
