wslay_event_context_free(3)

Paquete: libwslay

Licencias: MIT

WSLAY_EVENT_CONTEXT_FREE(3) wslay WSLAY_EVENT_CONTEXT_FREE(3)

NOMBRE

wslay_event_context_free - Inicializa un contexto de API basado en eventos

SINOPSIS

#include <wslay/wslay.h>

int wslay_event_context_server_init(wslay_event_context_ptr *ctx, const struct wslay_event_callbacks *callbacks, void *user_data)
int wslay_event_context_client_init(wslay_event_context_ptr *ctx, const struct wslay_event_callbacks *callbacks, void *user_data)
void wslay_event_context_free(wslay_event_context_ptr ctx)

DESCRIPCIÓN

La función wslay_event_context_server_init() inicializa un contexto de API basado en eventos para uso de servidor WebSocket. La función wslay_event_context_client_init() inicializa un contexto de API basado en eventos para uso de cliente WebSocket. Si devuelven :c:éxito, ctx apuntará a una estructura que contiene todos los recursos necesarios para procesar transferencias del protocolo WebSocket.

callbacks es un puntero a struct wslay_event_callbacks, que se define de la siguiente manera:

struct wslay_event_callbacks {
    wslay_event_recv_callback                recv_callback;
    wslay_event_send_callback                send_callback;
    wslay_event_genmask_callback             genmask_callback;
    wslay_event_on_frame_recv_start_callback on_frame_recv_start_callback;
    wslay_event_on_frame_recv_chunk_callback on_frame_recv_chunk_callback;
    wslay_event_on_frame_recv_end_callback   on_frame_recv_end_callback;
    wslay_event_on_msg_recv_callback         on_msg_recv_callback;
};

recv_callback

typedef ssize_t (*wslay_event_recv_callback)(wslay_event_context_ptr ctx, uint8_t *buf, size_t len, int flags, void *user_data)

recv_callback es invocada por wslay_event_recv() cuando necesita recibir más datos del par. La implementación de esta función de devolución de llamada debe leer como máximo len bytes de datos del par y almacenarlos en buf, y devolver el número de bytes leídos. flags es siempre 0 en esta versión.

Si hay un error, devuelva -1 y establezca el código de error WSLAY_ERR_CALLBACK_FAILURE usando wslay_event_set_error(). La API basada en eventos de Wslay en general asume E/S no bloqueante. Si la causa del error es EAGAIN o EWOULDBLOCK, establezca WSLAY_ERR_WOULDBLOCK en su lugar. Esto es importante porque indica a wslay_event_recv() que deje de recibir más datos y que retorne.

send_callback

typedef ssize_t (*wslay_event_send_callback)(wslay_event_context_ptr ctx, const uint8_t *data, size_t len, int flags, void *user_data)

send_callback es invocada por wslay_event_send() cuando necesita enviar más datos al par. La implementación de esta función de devolución de llamada debe enviar como máximo len bytes de datos al par y devolver el número de bytes enviados. flags es el OR a nivel de bits de cero o más de las siguientes banderas:

WSLAY_MSG_MORE
Hay más datos para enviar

Proporciona algunas pistas para ajustar el rendimiento y el comportamiento.

Si hay un error, devuelva -1 y establezca el código de error WSLAY_ERR_CALLBACK_FAILURE usando wslay_event_set_error(). La API basada en eventos de Wslay en general asume E/S no bloqueante. Si la causa del error es EAGAIN o EWOULDBLOCK, establezca WSLAY_ERR_WOULDBLOCK en su lugar. Esto es importante porque indica a wslay_event_send() que deje de enviar datos y que retorne.

genmask_callback

typedef int (*wslay_event_genmask_callback)(wslay_event_context_ptr ctx, uint8_t *buf, size_t len, void *user_data)

genmask_callback es invocada por wslay_event_send() cuando necesita una nueva clave de máscara. Como se describe en RFC6455, solo el tráfico del cliente WebSocket está enmascarado, por lo que esta función de devolución de llamada solo es necesaria si se inicializa una API basada en eventos para uso de cliente WebSocket. La implementación de esta función de devolución de llamada debe llenar exactamente len bytes de datos en buf y devolver 0 en caso de éxito. Si hay un error, devuelva -1 y establezca el código de error WSLAY_ERR_CALLBACK_FAILURE usando wslay_event_set_error().

on_frame_recv_start_callback

typedef void (*wslay_event_on_frame_recv_start_callback)(wslay_event_context_ptr ctx, const struct wslay_event_on_frame_recv_start_arg *arg, void *user_data)

on_frame_recv_start_callback es invocada por wslay_event_recv() cuando un nuevo frame comienza a ser recibido. Esta función de devolución de llamada solo se invoca una vez por cada frame. struct wslay_event_on_frame_recv_start_arg se define de la siguiente manera:

struct wslay_event_on_frame_recv_start_arg {
    uint8_t  fin;
    uint8_t  rsv;
    uint8_t  opcode;
    uint64_t payload_length;
};

fin, rsv y opcode son el bit fin y los bits reservados y el opcode de un frame. payload_length es la longitud de carga útil de un frame.

on_frame_recv_chunk_callback

typedef void (*wslay_event_on_frame_recv_chunk_callback)(wslay_event_context_ptr ctx, const struct wslay_event_on_frame_recv_chunk_arg *arg, void *user_data)

on_frame_recv_chunk_callback es invocada por wslay_event_recv() cuando se recibe un fragmento de la carga útil del frame. struct wslay_event_on_frame_recv_chunk_arg se define de la siguiente manera:

struct wslay_event_on_frame_recv_chunk_arg {
    const uint8_t *data;
    size_t         data_length;
};

data apunta a un fragmento de datos de carga útil. data_length es la longitud del fragmento.

on_frame_recv_end_callback

typedef void (*wslay_event_on_frame_recv_end_callback)(wslay_event_context_ptr ctx, void *user_data)

on_frame_recv_end_callback es invocada por wslay_event_recv() cuando un frame se ha recibido completamente.

on_msg_recv_callback

typedef void (*wslay_event_on_msg_recv_callback)(wslay_event_context_ptr ctx, const struct wslay_event_on_msg_recv_arg *arg, void *user_data)

on_msg_recv_callback es invocada por wslay_event_recv() cuando un mensaje se ha recibido completamente. struct wslay_event_on_msg_recv_arg se define de la siguiente manera:

struct wslay_event_on_msg_recv_arg {
    uint8_t        rsv;
    uint8_t        opcode;
    const uint8_t *msg;
    size_t         msg_length;
    uint16_t       status_code;
};

El miembro rsv y el miembro opcode son los bits reservados y el opcode

wslay_event_context_free(3) - Arch manual pages

NAME

wslay_event_context_free - free a wslay_event_context structure

SYNOPSIS

#include <wslay/event.h>

void
wslay_event_context_free(struct wslay_event_context *ctx);

DESCRIPTION

The function wslay_event_context_free() frees all resources allocated for the event-based context object ctx. ctx must have been initialized by either wslay_event_context_server_init() or wslay_event_context_client_init().

The event-based API is a simple event loop API to use wslay. When you receive a message, the callback functions you supplied to wslay_event_context_server_init() or wslay_event_context_client_init() are invoked. The callback function has the following signature:

On receive

typedef int (*wslay_event_on_msg_recv_callback)(
    wslay_event_context_t *ctx, struct wslay_message *msg,
    void *user_data);

On request of sending data

typedef int (*wslay_event_on_msg_send_callback)(
    wslay_event_context_t *ctx, uint8_t *buf, size_t len,
    void *user_data);

The struct wslay_message has the following members:

uint32_t opcode;
int fin;
int rsv;
uint8_t *msg;
size_t msg_length;
uint16_t status_code;

The opcode member is the frame opcode. It can be one of the following values:

WSLAY_TEXT_FRAME
WSLAY_BINARY_FRAME
WSLAY_PING
WSLAY_PONG
WSLAY_CONNECTION_CLOSE
WSLAY_CONTINUATION_FRAME

The fin member is 1 if this is the final fragment in a message, and 0 otherwise.

The rsv member is the value of the reserved bits. The actual reserved bits are extracted from rsv as follows:

rsv1 = (rsv >> 2) & 0x1;
rsv2 = (rsv >> 1) & 0x1;
rsv3 = rsv & 0x1;

The msg member points to the message of the received message. The msg_length member is the length of message. If a message is close control frame, in other words, opcode == WSLAY_CONNECTION_CLOSE, status_code is set to the status code in the close control frame. If no status code is included in the close control frame, status_code set to 0.

rsv = (RSV1 << 2) | (RSV2 << 1) | RSV3

The msg member points to the message of the received message. The msg_length member is the length of message. If a message is close control frame, in other words, opcode == WSLAY_CONNECTION_CLOSE, status_code is set to the status code in the close control frame. If no status code is included in the close control frame, status_code set to 0.

user_data is an arbitrary pointer, which is directly passed to each callback functions as user_data argument.

When initialized event-based API context ctx is no longer used, use wslay_event_context_free() to free any resources allocated for ctx.

RETURN VALUE

wslay_event_context_server_init() and wslay_event_context_client_init() returns 0 if it succeeds, or one of the following negative error codes:

WSLAY_ERR_NOMEM
Out of memory.
