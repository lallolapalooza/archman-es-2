WEBPINGVIS(1) Manual de comandos generales WEBPINGVIS(1)

NOMBRE

webpingvis - visualizar el tiempo de respuesta del servidor Web

SINOPSIS

webpingvis [-CiVz] [-A alineación] [-a archivo] [-h host] [-m máx] [-n archivopmns] [-O tiempo] [-p puerto] [-S tiempo] [-T tiempo] [-t intervalo] [-x versión] [-Z zona_horaria]

DESCRIPCIÓN

webpingvis muestra un resumen de las estadísticas de tiempo de respuesta del servidor Web recopiladas de la infraestructura Performance Co-Pilot (PCP). La visualización se modula por los valores de las métricas de rendimiento recuperadas del host de destino (que está ejecutando pmcd(1) y el agente de dominio de métricas de rendimiento pmdawebping(1)) o del registro de archivos PCP identificado por archivo. La visualización se actualiza cada intervalo segundos (por defecto 2 segundos).

Al igual que en todas las escenas de pmview(1), cuando el ratón se mueve sobre una de las barras, el valor actual y la información de la métrica de esa barra se mostrarán en el cuadro de texto cerca de la parte superior de la pantalla. La altura de las barras es proporcional a los valores de las métricas de rendimiento en relación con el máximo, según lo controlado por el tamaño de las URLs que son recuperadas por pmdawebping(1), y la opción -m (ver más abajo).

Las barras en la escena de webpingvis representan la siguiente información:

Tamaño
Las barras verdes indican los tamaños relativos de los resultados devueltos para cada URL en la carga de trabajo de pmdawebping.
Respuesta
Para cada URL en la carga de trabajo de pmdawebping, se muestran los componentes del tiempo de respuesta del servidor Web (conexión, cabecera y cuerpo) y el tiempo de respuesta total.

A la derecha, los tiempos de los componentes y el tiempo total se suman para todas las URLs en la carga de trabajo de pmdawebping.

Errores
Las cuatro barras rojas de error indican el número de errores de socket, HTTP, HTML u otros que ocurrieron en la última iteración de la carga de trabajo de pmdawebping. Cualquiera de estos errores terminará la solicitud de una URL.

webpingvis utiliza pmview(1), por lo que la interfaz de usuario sigue la descrita para pmview(1), que a su vez muestra la escena dentro de un visor examinador de Inventor. Para el control genérico del visor, consulte ivview(1).

webpingvis pasa la mayoría de las opciones de línea de comandos a pmview(1). Por lo tanto, las opciones de línea de comandos -A, -a, -C, -h, -n, -O, -p, -S, -t, -T, -x, -Z y -z, así como la interfaz de usuario, se describen en la página del manual de pmview(1).

Las opciones específicas de webpingvis son:

-i
Por defecto, los nombres de las URLs no se incluyen como etiquetas en la escena. La opción -i fuerza su inclusión.
-m máx
Cambia el factor de normalización para las barras de tiempo de respuesta. El valor de máx está en unidades de milisegundos y debe ser el valor máximo esperado para el tiempo de respuesta total agregado sobre todas las URLs en la carga de trabajo de pmdawebping. El valor por defecto es 1000 milisegundos.
-V
El archivo de configuración derivado para pmview(1) se escribe en la salida estándar. Esto puede guardarse y usarse directamente con pmview(1) si el usuario desea personalizar la pantalla o modificar algunos de los parámetros de normalización.

ADVERTENCIAS

Como webpingvis ordena las URLs configuradas por tamaño, ejecutar webpingvis poco después de iniciar pmdawebping(1) puede resultar en que las URLs se ordenen incorrectamente, ya que es posible que no hayan sido recuperadas.

El carácter ~ puede no ser analizado correctamente por pmview(1). Por lo tanto, si pmdawebping(1) está recuperando URLs que contienen ~, webpingvis no se iniciará.

ARCHIVOS

$PCP_VAR_DIR/pmns/*
archivos de especificación PMNS por defecto
$PCP_VAR_DIR/config/pmlogger/config.webpingvis
archivo de configuración de pmlogger(1) que se puede usar para crear un archivo PCP adecuado para mostrar con webpingvis
$PCP_VAR_DIR/config/pmchart/Web.Response
Un archivo de configuración de pmchart(1) para monitorizar el tiempo de respuesta del servidor Web

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(4).
