WCTOMB(3P) Manual POSIX para programadores WCTOMB(3P)

PRÓLOGO

Esta página del manual forma parte del Manual POSIX para programadores. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

wctomb — convertir un código de carácter ancho a un carácter

SINOPSIS

#include <stdlib.h>
int wctomb(char *s, wchar_t wchar);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función wctomb() determinará el número de bytes necesarios para representar el carácter correspondiente al código de carácter ancho cuyo valor es wchar (incluyendo cualquier cambio en el estado de desplazamiento). Almacenará la representación del carácter (posiblemente múltiples bytes y cualquier secuencia especial para cambiar el estado de desplazamiento) en el objeto array apuntado por s (si s no es un puntero nulo). Se almacenarán como máximo {MB_CUR_MAX} bytes. Si wchar es 0, se almacenará un byte nulo, precedido por cualquier secuencia de desplazamiento necesaria para restaurar el estado de desplazamiento inicial, y wctomb() quedará en el estado de desplazamiento inicial.

El comportamiento de esta función se ve afectado por la categoría LC_CTYPE de la configuración regional actual. Para una codificación dependiente del estado, esta función se pondrá en su estado inicial mediante una llamada para la cual su argumento puntero de carácter, s, sea un puntero nulo. Las llamadas posteriores con s como distinto de nulo alterarán el estado interno de la función según sea necesario. Una llamada con s como nulo hará que esta función devuelva un valor distinto de cero si las codificaciones tienen dependencia de estado, y 0 en caso contrario. Cambiar la categoría LC_CTYPE deja el estado de desplazamiento de esta función en un estado no especificado.

La función wctomb() no necesita ser segura para hilos.

La implementación se comportará como si ninguna función definida en este volumen de POSIX.1‐2017 llamara a wctomb().

VALOR DE RETORNO

Si s es un puntero nulo, wctomb() devolverá un valor distinto de cero o 0, si las codificaciones de caracteres, respectivamente, tienen o no codificaciones dependientes del estado. Si s no es un puntero nulo, wctomb() devolverá -1 si el valor de wchar no corresponde a un carácter válido, o devolverá el número de bytes que constituyen el carácter correspondiente al valor de wchar.

En ningún caso el valor devuelto será mayor que el valor de la macro {MB_CUR_MAX}.

ERRORES

La función wctomb() fallará si:

EILSEQ
Se detecta un código de carácter ancho inválido.
