WCSTOMBS(3P) Manual del programador POSIX WCSTOMBS(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

wcstombs — convertir una cadena de caracteres anchos a una cadena de caracteres

SINOPSIS

#include <stdlib.h>
size_t wcstombs(char *restrict s, const wchar_t *restrict pwcs,
    size_t n);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La función wcstombs() convertirá la secuencia de códigos de caracteres anchos que se encuentran en el array apuntado por pwcs en una secuencia de caracteres que comienza en el estado de cambio inicial y almacenará estos caracteres en el array apuntado por s, deteniéndose si un carácter excede el límite de n bytes totales o si se almacena un byte nulo. Cada código de carácter ancho se convertirá como si fuera una llamada a wctomb(), excepto que el estado de cambio de wctomb() no se verá afectado.

El comportamiento de esta función se verá afectado por la categoría LC_CTYPE de la configuración regional actual.

No se modificarán más de n bytes en el array apuntado por s. Si se produce una copia entre objetos que se superponen, el comportamiento es indefinido. Si s es un puntero nulo, wcstombs() devolverá la longitud requerida para convertir todo el array independientemente del valor de n, pero no se almacenarán valores.

VALOR DE RETORNO

Si se encuentra un código de carácter ancho que no corresponde a un carácter válido (de uno o más bytes cada uno), wcstombs() devolverá (size_t)-1. De lo contrario, wcstombs() devolverá el número de bytes almacenados en el array de caracteres, sin incluir ningún byte nulo de terminación. El array no se terminará en nulo si el valor devuelto es n.

ERRORES

La función wcstombs() fallará si:

EILSEQ
Un código de carácter ancho no corresponde a un carácter válido.
