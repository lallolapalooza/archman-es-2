NOMBRE

wl_event_queue - Una cola para eventos de objetos wl_proxy.

SINOPSIS

#include <wayland-client-core.h>

Funciones Públicas Miembro


void wl_event_queue_destroy (struct wl_event_queue *queue)

Descripción Detallada

Una cola para eventos de objetos wl_proxy.

Las colas de eventos permiten que los eventos en una pantalla se manejen de manera segura para subprocesos. Ver wl_display para más detalles.

Documentación de Funciones Miembro

void wl_event_queue_destroy (struct wl_event_queue * queue)

Destruye una cola de eventos

Parámetros

queue La cola de eventos a destruir

Destruye la cola de eventos dada. Cualquier evento pendiente en esa cola se descarta.

El objeto wl_display utilizado para crear la cola no debe destruirse hasta que todas las colas de eventos creadas con él se destruyan con esta función.
