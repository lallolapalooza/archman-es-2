WHEREIS(1) Comandos de Usuario WHEREIS(1)

NOMBRE

whereis - localizar los archivos binarios, fuente y de manual de un comando

SINOPSIS

whereis [opciones] [-BMS directorio... -f] nombre...

DESCRIPCIÓN

whereis localiza los archivos binarios, fuente y de manual para los nombres de comandos especificados. Los nombres proporcionados son primero despojados de los componentes de ruta iniciales. Los prefijos de s. resultantes del uso del control de código fuente también se gestionan. whereis intenta luego localizar el programa deseado en los lugares estándar de Linux y en los lugares especificados por $PATH y $MANPATH.

Las restricciones de búsqueda (opciones -b, -m y -s) son acumulativas y se aplican a los patrones de nombre subsiguientes en la línea de comandos. Cualquier nueva restricción de búsqueda reinicia la máscara de búsqueda. Por ejemplo,

whereis -bm ls tr -m gcc

busca archivos binarios y de manual para "ls" y "tr", y solo archivos de manual para "gcc".

Las opciones -B, -M y -S reinician las rutas de búsqueda para los patrones de nombre subsiguientes. Por ejemplo,

whereis -m ls -M /usr/share/man/man1 -f cal

busca archivos de manual de "ls" en todas las rutas predeterminadas, pero para "cal" solo en el directorio /usr/share/man/man1.

OPCIONES

-b

Busca binarios.

-m

Busca manuales.

-s

Busca fuentes.

-u

Muestra solo los nombres de comandos que tienen entradas inusuales. Se dice que un comando es inusual si no tiene solo una entrada de cada tipo explícitamente solicitado. Por lo tanto, 'whereis -m -u *' solicita aquellos archivos en el directorio actual que no tienen archivo de documentación, o más de uno.

-B lista

Limita los lugares donde whereis busca binarios, mediante una lista de directorios separada por espacios en blanco.

-M lista

Limita los lugares donde whereis busca manuales y documentación en formato Info, mediante una lista de directorios separada por espacios en blanco.

-S lista

Limita los lugares donde whereis busca fuentes, mediante una lista de directorios separada por espacios en blanco.

-f

Termina la lista de directorios y señala el comienzo de los nombres de archivo. Debe usarse cuando se utiliza alguna de las opciones -B, -M o -S.

-l

Muestra la lista de rutas de búsqueda efectivas que whereis está utilizando. Cuando ninguna de las opciones -B, -M o -S se especifica, la opción mostrará las rutas codificadas que el comando pudo encontrar en el sistema.

-g

Interpreta los siguientes nombres como patrones de glob(7). whereis siempre compara solo nombres de archivo (también conocido como nombre base) y nunca la ruta completa. Usar nombres de directorio en el patrón no tiene efecto. No olvides que el shell interpreta el patrón cuando se especifica en la línea de comandos sin comillas. Es necesario usar comillas para el nombre, por ejemplo:
whereis -g 'find*'

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

RUTAS DE BÚSQUEDA DE ARCHIVOS

Por defecto, whereis intenta encontrar archivos a partir de rutas codificadas, que se definen con patrones glob. El comando intenta usar el contenido de las variables de entorno $PATH y $MANPATH como ruta de búsqueda predeterminada. La forma más fácil de saber qué rutas se están utilizando es añadir la opción de listado -l. Los efectos de -B, -M y -S se muestran con -l.

ENTORNO

WHEREIS_DEBUG=all

habilita la salida de depuración.

EJEMPLOS

Para encontrar todos los archivos en /usr/bin que no están documentados en /usr/man/man1 o que no tienen fuente en /usr/src:

cd /usr/bin
whereis -u -ms -M /usr/man/man1 -S /usr/src -f *

INFORME DE ERRORES

Para informes de errores, use el rastreador de incidencias https://github.com/util-linux/util-linux/issues.

DISPONIBILIDAD
