WACOM(4) Manual de Controladores de Dispositivos WACOM(4)

NOMBRE

wacom - controlador de entrada Wacom

SINOPSIS

Sección "InputClass"
  Identificador "nombre_dispositivo"
  MatchIsTablet "on"
  MatchDevicePath "ruta_dispositivo"
  Driver "wacom"
  Option "..." " ..."
  ...
EndSection

DESCRIPCIÓN

wacom es un controlador de entrada X para dispositivos Wacom.

El controlador wacom funciona como un dispositivo de entrada de puntero.

HARDWARE SOPORTADO

Este controlador soporta prácticamente todos los dispositivos de tableta que son soportados por el kernel de Linux.

Por favor, consulta https://github.com/linuxwacom para las últimas actualizaciones de los controladores X y del kernel de Wacom.

HOTPLUGGING DE DISPOSITIVOS INTERNO DEL CONTROLADOR

La configuración a través de Section "InputDevice" no se recomienda ya que dichos dispositivos no pueden ser conectados en caliente en tiempo de ejecución. En su lugar, los usuarios deben usar Section "InputClass" como en el ejemplo anterior. La sección InputClass (ver xorg.conf.d(5)) asigna este controlador para el dispositivo, el controlador wacom crea múltiples dispositivos X para cada dispositivo físico, un dispositivo X para cada herramienta disponible. La lista de herramientas es dependiente del hardware. Consulta Option Type como se describe en la sección DETALLES DE CONFIGURACIÓN.

Estos dispositivos específicos de herramienta se conocen como dispositivo padre y dispositivo dependiente. El dispositivo padre es el que presenta el sistema y el que provoca que el servidor X cargue el controlador wacom. Este dispositivo padre provoca la adición automática de varios dispositivos dependientes. Si el dispositivo padre se desconecta o se elimina de cualquier otra forma, los dispositivos dependientes también se eliminarán automáticamente.

Los dispositivos dependientes pueden tener opciones específicas de herramienta asignadas a través de secciones InputClass adicionales. Recomendamos que se utilice una línea MatchDriver wacom en estas secciones además del patrón específico del usuario.

Las directivas de coincidencia son aplicadas por el servidor X antes de que se seleccione el controlador. El nombre de tipo del dispositivo padre se le anexa al controlador. No es posible usar una directiva MatchProduct para coincidir con este nombre de tipo anexado.

DETALLES DE CONFIGURACIÓN

Por favor, consulta xorg.conf(5) o xorg.conf.d(5) para detalles generales de configuración y para opciones que se pueden usar con todos los controladores de entrada. Esta sección solo cubre los detalles de configuración específicos de este controlador.

Múltiples instancias de los dispositivos Wacom pueden coexistir. Cada dispositivo soporta las siguientes entradas:

Opción "Tipo" "stylus"|"eraser"|"cursor"|"pad"|"touch"
establece el tipo de herramienta que representa el dispositivo. Esta opción es obligatoria. Las opciones principales, como "SendCoreEvents" o "AlwaysCore", son innecesarias en Gimp si no necesitas mover el cursor del sistema fuera del área de dibujo de Gimp. "pad" es para las teclas ExpressKeys/barras de menú de las tabletas Intuos 3 o Cintiq 21UX, y los botones, rueda y/o anillo de las tabletas Graphire 4 o Bamboo. Es obligatorio para Intuos3, CintiqV5, Graphire 4 y Bamboo si deseas utilizar funciones de combinación de teclas. "pad" es reportado como una segunda herramienta en el controlador. "touch" es para la tableta con soporte táctil. Actualmente solo unas pocas Tabletas PC tienen esta característica.
Opción "Device" "ruta"
establece la ruta al archivo especial que representa la línea serie donde está conectada la tableta. Debes especificarla para cada subsección con el mismo valor si deseas tener múltiples dispositivos con la misma tableta. Esta opción es obligatoria solo si se utiliza Section "InputDevice" para configuración estática.
Opción "Suppress" "número"
establece el incremento de posición bajo el cual no se transmitirán las coordenadas. Esta entrada solo debe especificarse en la primera subsección de Wacom si tienes múltiples dispositivos para una tableta. Si no especificas esta entrada, se usará el valor predeterminado, que es 2. Para deshabilitar la supresión, la entrada debe especificarse como 0. Cuando se define supresión, se enviará un evento solo cuando al menos una de las siguientes condiciones se cumpla:


el cambio entre la coordenada X actual y la anterior es mayor que suppress;


el cambio entre la coordenada Y actual y la anterior es mayor que suppress;


el cambio entre la presión actual y la anterior es mayor que suppress;


el cambio entre el grado de rotación actual y el anterior del transductor es mayor que suppress;


el cambio entre el valor de rueda absoluto actual y el anterior es igual o mayor que suppress;


el cambio entre el valor de inclinación actual y el anterior es igual a o mayor que suppress (si se soporta inclinación);


el valor de rueda relativo ha cambiado;


el valor del botón ha cambiado;


la proximidad ha cambiado.

Opción "Mode" "Relative"|"Absolute"
establece el modo del dispositivo. El valor predeterminado para lápiz, pad y borrador es Absoluto; cursor es Relativo; táctil por defecto es Relativo para tabletas con touchpad y Absoluto para pantallas táctiles.
Opción "TopX" "número"
coordenada X de la esquina superior de la zona activa. Por defecto es 0.
Opción "TopY" "número"
coordenada Y de la esquina superior de la zona activa. Por defecto es 0.
Opción "BottomX" "número"
coordenada X de la esquina inferior de la zona activa. Por defecto es el ancho de la tableta.
Opción "BottomY" "número"
coordenada Y de la esquina inferior de la zona activa. Por defecto es la altura de la tableta.
Opción "ButtonsOnly" "on"|"off"
deshabilita los eventos de movimiento del dispositivo. Por defecto es off.
Opción "ButtonM" "AC"
reporta una acción AC cuando se presiona el botón M, donde M es uno de los números de botón soportados por el dispositivo, puede ser de 1 a 32. Wacom utiliza un mapeo de botones interno del controlador, donde cualquier botón físico aparece al servidor X como el botón especificado por el mapeo ButtonM. Por lo tanto, si dos botones físicos tienen el mismo mapeo ButtonM, el servidor pensará que son el mismo botón físico. La acción predeterminada reportada al servidor X es un clic de botón de ratón M. Dado que X utiliza los botones 4, 5, 6 y 7 para las cuatro direcciones de desplazamiento, los botones físicos 4 y superiores se mapean a 8 y superiores por defecto. Solo se pueden configurar aquí las pulsaciones de botones simples; para acciones más complejas, usa xsetwacom(1). Para ignorar el clic del botón, es decir, para no reportar ningún evento de clic de botón al servidor X, usa "0" o "button 0".
Opción "TPCButton" "on"|"off"
habilita los botones del lápiz como botones de Tablet PC. Si está habilitado, el lápiz reporta eventos de botón solo cuando su punta está presionada. Si algún botón está presionado, presionar la punta reporta un evento de botón para ese botón. De lo contrario, si ningún botón está presionado, la punta reporta como de costumbre. Por defecto es "on" para Tabletas PC; "off" para todos los demás modelos. Solo disponible en la herramienta lápiz.
Opción "Touch"
> "activado"|"desactivado"
habilita los eventos táctiles para dispositivos táctiles, es decir, el cursor del sistema se mueve cuando el usuario toca la tableta. Predeterminado a "activado" para dispositivos que admiten tacto; "desactivado" para todos los demás modelos.
Opción "Rotar" "CW"|"CCW"|"HALF"|"NONE"
rota la orientación de la tableta en sentido antihorario (CCW) o horario (CW) o 180 grados (HALF). Si tiene mapeos específicos de tableta, es decir, TopX/Y o BottomX/Y, el mapeo se aplicará antes de la rotación. La rotación debe aplicarse al dispositivo principal (generalmente el lápiz óptico), se ignorarán los ajustes de rotación en dispositivos conectados internamente por el controlador (consulte CONEXIÓN INTERNA DE DISPOSITIVOS POR EL CONTROLADOR). El valor predeterminado es "NONE".
Opción "CurvaPresion" "x1,y1,x2,y2"
establece la curva de presión mediante los puntos de control x1, y1, x2 e y2. Sus valores están en el rango de 0 a 100. La curva de presión se interpreta como una curva de Bézier con 4 puntos de control, siendo el primer y último punto de control fijos en las coordenadas 0/0 y 100/100, respectivamente. Los puntos de control intermedios se ajustan con esta configuración y, por lo tanto, definen la forma de la curva. La entrada para la curva lineal (predeterminada) es "0,0,100,100"; una curva ligeramente deprimida (más firme) podría ser "5,0,100,95"; una curva ligeramente elevada (más suave) podría ser "0,5,95,100". La curva de presión solo es aplicable a dispositivos de tipo lápiz óptico o borrador, otros dispositivos no respetan esta configuración.
Opción "Presion2K" "booleano"
reduce el rango de presión al rango de 0 a 2048 para compatibilidad con versiones anteriores con aplicaciones que tienen este rango codificado. Consulte la sección ERRORES. Esta opción no debe usarse a menos que el usuario ejecute una o más aplicaciones que dependan de un rango de presión codificado.
Opción "NivelDebug" "número"
establece el nivel de información de depuración para mensajes específicos de la herramienta. Hay 12 niveles, especificados por los enteros entre 1 y 12. Todos los mensajes de depuración con un nivel menor o igual al "número" se registrarán en el archivo de registro de Xorg. Esta opción solo está disponible si el controlador se compiló con soporte de depuración.
Opción "DebugComun" "número"
establece el nivel de información de depuración para rutas de código comunes (es decir, no específicas de la herramienta) en la tableta. Hay 12 niveles, especificados por los enteros entre 1 y 12. Todos los mensajes de depuración con un nivel menor o igual al "número" se registrarán en el archivo de registro de Xorg. Esta opción solo está disponible si el controlador se compiló con soporte de depuración.
Opción "CapturarDispositivo" "booleano"
establece si el dispositivo de eventos subyacente será capturado por el controlador para evitar que los datos se filtren a /dev/input/mice. Cuando está habilitado, mientras el servidor X se está ejecutando, ningún otro programa podrá leer el flujo de eventos. Predeterminado: "falso".
Opción "ProximidadCursor" "número"
establece la distancia a la que una herramienta relativa se considera fuera de proximidad. Más allá de esta distancia, el cursor dejará de responder al movimiento de la herramienta. El valor predeterminado para los pucks es 10 (Intuos Pro) o 42 (Intuos/Bamboo). El valor predeterminado para los lápices es 30.
Opción "MuestraCruda" "número"
Establece el tamaño de la ventana de muestreo (una ventana de muestreo de promedio móvil) para los puntos de datos brutos de la herramienta de entrada entrantes. Predeterminado: 4, rango de 1 a 20.
Opción "Serie" "número"
establece el número de serie asociado con el dispositivo físico. Esto permite tener varios dispositivos del mismo tipo (es decir, varios lápices). Esta opción solo está disponible en tabletas Wacom V (series Intuos y Cintiq 21U). Para ver a qué número de serie pertenece un dispositivo, debe ejecutar la utilidad xsetwacom, que viene con el paquete linuxwacom.
Opción "SeriesHerramientas" "número[,tipo[,etiqueta]][;...]"
establece la lista de dispositivos con número de serie que deben conectarse dinámicamente para un dispositivo físico. La opción 'tipo' puede ser cualquiera de "pen", "airbrush", "artpen", o "cursor". Esta opción solo está disponible en tabletas Wacom V que son capaces de informar un número de serie. Para ver si un dispositivo conectado es compatible, o para identificar qué número de serie pertenece a un dispositivo, debe ejecutar la utilidad xsetwacom, que viene con este controlador. En términos sencillos, esta opción agregará dispositivos X adicionales para la punta de esta herramienta específica (y borrador, si corresponde). Esto es útil para programas como gimp (que recuerda herramientas basándose en el dispositivo X) para recuperar selecciones de herramientas de dibujo adicionales para un aerógrafo + borrador, un lápiz artístico, un lápiz extra, etc.
Opción "Umbral" "número"
establece el umbral de presión utilizado para generar eventos de botón 1 del lápiz óptico. El umbral se aplica al rango de presión normalizado de [0..2048]. El valor predeterminado es 27.
Opción "Gesto" "booleano"
habilita o deshabilita el soporte de gestos multitáctiles en el controlador del dispositivo. Predeterminado: desactivado a menos que la tableta admita multitáctil. Tenga en cuenta que deshabilitar esta opción puede permitir que el entorno de escritorio detecte gestos multitáctiles en su lugar.
Opción "DistanciaZoom" "número"
Si la Opción "Gesto" está habilitada, esta opción especifica la distancia mínima de movimiento antes de que se reconozca un gesto de zoom.
Opción "DistanciaScroll" "número"
Si la Opción "Gesto" está habilitada, esta opción especifica la distancia mínima de movimiento antes de que se reconozca un gesto de desplazamiento.
Opción "TiempoTap" "número"
Si la Opción "Gesto" está habilitada, esta opción determina el tiempo máximo de un evento táctil para ser reconocido como toque. Una pulsación y liberación de evento más cortas que TiempoTap generan eventos de pulsación y liberación de botón. Las pulsaciones más largas que TiempoTap no generan eventos de botón, solo eventos de movimiento.
Opción "RecalibracionPresion" "booleano"
Permite deshabilitar la recalibración de presión. Predeterminado: verdadero. Si la presión inicial de un dispositivo es != 0, el controlador recalibra el rango de presión. Esto es para tener en cuenta los dispositivos desgastados. La desventaja es que cuando el usuario golpea la tableta con mucha fuerza, la lectura de presión inicial puede no ser cero incluso para un lápiz perfectamente bueno. Si las lecturas de presión consecutivas no son superiores a la presión inicial en un umbral, no se generará ningún evento de botón. Esta opción permite deshabilitar la recalibración.
Opción "UmbralScrollPan" "número"
Especifica la distancia que debe moverse el lápiz (en unidades de tableta) antes de que se genere un evento de desplazamiento cuando se usa la acción "pan". Los valores más pequeños requerirán menos distancia y serán más sensibles. Los valores más grandes requerirán más distancia y serán menos sensibles. Predeterminado: 1300 o 2600 dependiendo de la resolución de la tableta (corresponde a 13 mm de distancia).
Opción "ScrollPanSuaveActivado" "booleano"
Permite deshabilitar el desplazamiento panorámico suave. Predeterminado: verdadero. Si está deshabilitado, el desplazamiento panorámico envía eventos de botón heredados en su lugar. Esta opción existe para compatibilidad con versiones anteriores con aplicaciones que tienen un número limitado de ejes en un dispositivo a 6. Consulte la sección ERRORES para obtener más detalles. Esta opción no debe usarse a menos que el usuario ejecute una o más aplicaciones que no admitan más de seis ejes.

GESTOS TÁCTILES

Un dedo (1FG)

Clic izquierdo: toque, el clic real ocurre después de que transcurre el período TapTime.

Arrastrar con clic izquierdo: toque para seleccionar, toque nuevamente la selección rápidamente (dentro del período TapTime). Luego arrastre. Disponible en touchpads, por ejemplo, BambooPT, no en pantallas táctiles.

Dos dedos (2FG)

Clic derecho: un dedo abajo + toque con el segundo dedo

Desplazamiento vertical: dos dedos uno al lado del otro (en cualquier orientación) moviéndose verticalmente con separación constante inician un desplazamiento vertical. Por defecto del controlador, un gesto hacia arriba resulta en un evento de desplazamiento hacia abajo (el documento se mueve hacia arriba) y un gesto hacia abajo resulta en un evento de desplazamiento hacia arriba (moviendo el documento hacia abajo).

Desplazamiento horizontal: dos dedos uno al lado del otro mantenidos a una distancia constante moviéndose horizontalmente inician un desplazamiento horizontal. Un gesto hacia la izquierda resulta en un evento de desplazamiento hacia la derecha (el documento se mueve hacia la izquierda) y un gesto hacia la derecha resulta en un evento de desplazamiento hacia la izquierda (moviendo el documento hacia la derecha).

Acercar: dos dedos separados uno al lado del otro, juntarlos (pellizcar).

Alejar: dos dedos uno al lado del otro, separarlos. No todas las aplicaciones admiten zoom.

ERRORES

El aumento del rango de presión conduce a un comportamiento inesperado

En la versión 0.34, el rango de presión del controlador aumentó de 2048 pasos a 65536 pasos. El rango del eje de presión se anuncia a través del Protocolo de Entrada X, pero algunas aplicaciones tienen el rango de presión anterior codificado y no pueden manejar valores de presión superiores a 2048. Este es un error de la aplicación, pero para la compatibilidad con versiones anteriores de dichas aplicaciones, este controlador proporciona la Presión

BUGS

The xf86-input-wacom driver does not support the Wacom Graphire 3. The driver does not support the Wacom Cintiq 20WSX or the Wacom Cintiq 21UX. The Wacom Bamboo Fun (CTE-450) is not supported. The Wacom Intuos 4 (PTK-440, PTK-640, PTK-840, PTK-1240) is not supported. These devices are not supported by the kernel's HID-multitouch driver. Users can switch to the kernel's HID-multitouch driver by editing the xorg.conf file. See the xorg.conf(5) manual page for details.

The xorg.conf option PressureLib=true is deprecated. It is recommend that you switch to the xorg.conf option RawRecalculate=true. The driver will automatically detect when the Wacom driver is loaded and will automatically set the RawRecalculate option to true.

The xorg.conf option e2k is deprecated. It is recommend that you switch to the xorg.conf option RawRecalculate=true. The driver will automatically detect when the Wacom driver is loaded and will automatically set the RawRecalculate option to true.

The e2k option to reduce the range to 2048 steps. Note that this setting applies to the device. Once applied, all applications will see the reduced pressure range. It is not possible to provide this setting on a per-application basis.

Smooth panscrolling exceeds the axis limits

In version 1.2.0, the driver's support for smooth panscrolling added two axes to the stylus device, bringing the total axis count to eight. The number of axes is advertised through the X Input Protocol but some applications (notably GIMP 2.xx) cannot handle more than six axes. This is an application bug but for backwards-compatibility with such applications, this driver provides the SmoothPanscrollingEnabled option to disable this feature and thus limit the axis count to six. Note that this setting applies to the device. Once applied, the driver will not send smooth panscroll events at all. It is not possible to provide this setting on a per-application basis.
