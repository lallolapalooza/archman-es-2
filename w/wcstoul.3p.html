WCSTOUL(3P) Manual del programador POSIX WCSTOUL(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

wcstoul, wcstoull — convertir una cadena de caracteres anchos a un entero largo sin signo

SINOPSIS

#include <wchar.h>
unsigned long wcstoul(const wchar_t *restrict nptr,
    wchar_t **restrict endptr, int base);
unsigned long long wcstoull(const wchar_t *restrict nptr,
    wchar_t **restrict endptr, int base);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Las funciones wcstoul() y wcstoull() convertirán la porción inicial de la cadena de caracteres anchos apuntada por nptr a la representación unsigned long y unsigned long long, respectivamente. Primero, descompondrán la cadena de caracteres anchos de entrada en tres partes:

1.
Una secuencia inicial, posiblemente vacía, de códigos de caracteres anchos de espacio en blanco (según lo especificado por iswspace())
2.
Una secuencia sujeto interpretada como un entero representado en alguna base determinada por el valor de base
3.
Una cadena final de caracteres anchos de uno o más códigos de caracteres no reconocidos, incluido el código de carácter ancho nulo de terminación de la cadena de caracteres anchos de entrada

Luego, intentarán convertir la secuencia sujeto a un entero sin signo y devolverán el resultado.

Si base es 0, la forma esperada de la secuencia sujeto es la de una constante decimal, constante octal o constante hexadecimal, cualquiera de las cuales puede ir precedida por un signo '+' o '-'. Una constante decimal comienza con un dígito distinto de cero y consta de una secuencia de dígitos decimales. Una constante octal consta del prefijo '0' seguido opcionalmente por una secuencia de los dígitos '0' a '7' solamente. Una constante hexadecimal consta del prefijo 0x o 0X seguido por una secuencia de dígitos decimales y letras 'a' (o 'A') a 'f' (o 'F') con valores de 10 a 15 respectivamente.

Si el valor de base está entre 2 y 36, la forma esperada de la secuencia sujeto es una secuencia de letras y dígitos que representan un entero con la base especificada por base, opcionalmente precedida por un signo '+' o '-', pero sin incluir un sufijo entero. Las letras de 'a' (o 'A') a 'z' (o 'Z') inclusive se les asignan los valores de 10 a 35; solo se permitirán letras cuyos valores asignados sean menores que los de base. Si el valor de base es 16, los códigos de caracteres anchos 0x o 0X pueden preceder opcionalmente a la secuencia de letras y dígitos, siguiendo el signo si está presente.

La secuencia sujeto se define como la sub-secuencia inicial más larga de la cadena de caracteres anchos de entrada, comenzando con el primer código de carácter ancho que no sea espacio en blanco y tenga la forma esperada. La secuencia sujeto no contiene códigos de caracteres anchos si la cadena de caracteres anchos de entrada está vacía o consta enteramente de códigos de caracteres anchos de espacio en blanco, o si el primer código de carácter ancho que no sea espacio en blanco es distinto de un signo o de una letra o dígito permitidos.

Si la secuencia sujeto tiene la forma esperada y base es 0, la secuencia de códigos de caracteres anchos que comienza con el primer dígito se interpretará como una constante entera. Si la secuencia sujeto tiene la forma esperada y el valor de base está entre 2 y 36, se utilizará como base para la conversión, asignando a cada letra su valor según lo indicado anteriormente. Si la secuencia sujeto comienza con un <guion medio>, el valor resultante de la conversión se negará. Se almacenará un puntero a la cadena final de caracteres anchos en el objeto apuntado por endptr, siempre que endptr no sea un puntero nulo.

En locales distintos de C o POSIX, se pueden aceptar formas de secuencia sujeto adicionales específicas del local.

Si la secuencia sujeto está vacía o no tiene la forma esperada, no se realizará ninguna conversión; el valor de nptr se almacenará en el objeto apuntado por endptr, siempre que endptr no sea un puntero nulo.

Estas funciones no cambiarán la configuración de errno si tienen éxito.

Dado que se devuelven 0, {ULONG_MAX} y {ULLONG_MAX} en caso de error y 0 también es un valor válido en caso de éxito, una aplicación que desee verificar situaciones de error debe establecer errno en 0, luego llamar a wcstoul() o wcstoull(), y luego verificar errno.

VALOR DEVUELTO

Tras una finalización exitosa, las funciones wcstoul() y wcstoull() devolverán el valor convertido, si lo hay. Si no se pudo realizar ninguna conversión, se devolverá 0 y errno puede establecerse para indicar el error. Si el valor correcto está fuera del rango de valores representables, se devolverá {ULONG_MAX} o {ULLONG_MAX} respectivamente y se establecerá errno en [ERANGE].

ERRORES

Estas funciones fallarán si:

EINVAL
El valor de base no es compatible.
ERANGE
El valor a devolver no es representable.

Estas funciones pueden fallar si:

EINVAL
No se pudo realizar ninguna conversión.
