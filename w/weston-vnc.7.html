NOMBRE

weston-vnc - el backend VNC para Weston

SINOPSIS

weston --backend=vnc

DESCRIPCIÓN

El backend VNC permite ejecutar un entorno weston sin la necesidad de hardware gráfico específico o dispositivos de entrada. Los usuarios solo pueden interactuar con weston conectándose mediante el protocolo de framebuffer remoto (RFB).

El backend VNC utiliza Neat VNC para implementar la parte VNC, actúa como un servidor VNC que escucha las conexiones entrantes. Admite diferentes codificaciones para codificar el contenido gráfico, dependiendo de lo que admita el cliente VNC.

El backend VNC no es consciente de múltiples asientos, por lo que si un segundo cliente se conecta al backend, el primer cliente se desconectará.

El cliente VNC debe autenticarse como el usuario que ejecuta weston. Esto requiere un archivo de configuración PAM /etc/pam.d/weston-remote-access.

CONFIGURACIÓN

El backend VNC utiliza las siguientes entradas de weston.ini.

Sección vnc

tasa-de-actualización=tasa
Especifica la tasa de redibujo del escritorio en Hz. Si no se especifica, el valor predeterminado es 60Hz. Cambiar esto puede ser útil si tiene una pantalla más rápida que 60Hz, o si desea reducir las actualizaciones para reducir el tráfico de red.
tls-clave=archivo
El archivo que contiene la clave para la seguridad TLS. Para tener seguridad TLS, también debe proporcionar un archivo que contenga un certificado.
tls-certificado=archivo
El archivo que contiene el certificado para la seguridad TLS. Para tener seguridad TLS, también debe proporcionar un archivo de clave.

Sección salida

nombre=vnc
El nombre vnc se utiliza para identificar la salida VNC.
modo=anchoxalto
Especifica el tamaño (inicial) de la salida.
redimensionable=booleano
Especifica si se permite al cliente VNC redimensionar la salida.

OPCIONES

Cuando se carga el backend VNC, weston entenderá las siguientes opciones de línea de comandos adicionales.

--dirección=dirección
La dirección IP en la que el backend VNC escuchará las conexiones VNC. Por defecto, escucha en 0.0.0.0.
--ancho=ancho
El ancho del framebuffer. Por defecto es 640.
--alto=alto
La altura del framebuffer. Por defecto es 480.
--puerto=puerto
El puerto TCP en el que escuchar las conexiones. Por defecto es 5900.
--vnc-tls-clave=archivo
El archivo que contiene la clave para la seguridad TLS. Para tener seguridad TLS, también debe proporcionar un archivo que contenga un certificado.
--vnc-tls-certificado=archivo
El archivo que contiene el certificado para la seguridad TLS. Para tener seguridad TLS, también debe proporcionar un archivo de clave.
--deshabilitar-seguridad-de-capa-de-transporte
Deshabilita la Seguridad de Capa de Transporte. Si se especifica, VNC se habilitará con autenticación solo por contraseña. Esta opción no se recomienda, ya que crea un riesgo de seguridad.

Generación de material criptográfico para el backend VNC

Puede generar un archivo de clave y certificado para usar con la seguridad TLS utilizando invocaciones típicas de openssl:

$ openssl genrsa -out tls.key 2048
Generando clave privada RSA, módulo de 2048 bits
[...]
$ openssl req -new -key tls.key -out tls.csr
[...]
$ openssl x509 -req -days 365 -signkey tls.key -in tls.csr -out tls.crt
[...]

Obtendrá los archivos tls.key y tls.crt para usarlos con el backend VNC.
