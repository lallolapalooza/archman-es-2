NOMBRE

winemaker - genera una infraestructura de compilación para compilar programas de Windows en Unix

SINOPSIS

winemaker [ --nobanner ] [ --backup | --nobackup ] [ --nosource-fix ]
[ --lower-none | --lower-all | --lower-uppercase ]
[ --lower-include | --nolower-include ] [ --mfc | --nomfc ]
[ --guiexe | --windows | --cuiexe | --console | --dll | --lib ]
[ -Dmacro[=defn] ] [ -Idir ] [ -Pdir ] [ -idll ] [ -Ldir ] [ -llibrary ]
[ --nodlls ] [ --nomsvcrt ] [ --interactive ] [ --single-target name ]
[ --generated-files ] [ --nogenerated-files ]
[ --wine32 ]
directorio_trabajo | archivo_proyecto | archivo_workspace

DESCRIPCIÓN

winemaker es un script de perl diseñado para ayudarte a arrancar el proceso de conversión de tus fuentes de Windows a programas Winelib.

Para hacer esto winemaker puede realizar las siguientes operaciones:

- renombrar tus archivos y directorios fuente a minúsculas en caso de que se hayan transferido completamente en mayúsculas.

- realizar conversiones de DOS a Unix (CRLF a LF).

- escanear las declaraciones de inclusión y las referencias a archivos de recursos para reemplazar las barras invertidas por barras normales.

- durante el paso anterior winemaker también realizará una búsqueda insensible a mayúsculas y minúsculas del archivo referenciado en la ruta de inclusión y reescribirá la declaración de inclusión con la capitalización correcta si es necesario.

- winemaker también verificará otros problemas más exóticos como el uso de #pragma pack, el uso de afxres.h en proyectos no MFC, y más. Siempre que encuentre algo fuera de lo común, te advertirá al respecto.

- winemaker también puede escanear un árbol de directorios completo a la vez, adivinar cuáles son los ejecutables y bibliotecas que estás intentando construir, emparejarlos con los archivos fuente y generar el Makefile correspondiente.

- finalmente winemaker generará un Makefile global para uso normal.

- winemaker conoce los proyectos basados en MFC y generará archivos personalizados.

- winemaker puede leer archivos de proyecto existentes. Admite archivos dsp, dsw, vcproj y sln.

OPCIONES

--nobanner
Desactiva la impresión del banner.
--backup
Realiza una copia de seguridad de todos los archivos fuente modificados. Esta es la opción predeterminada.
--nobackup
No realiza copia de seguridad de los archivos fuente modificados.
--nosource-fix
No intentes corregir los archivos fuente (por ejemplo, conversión de DOS a Unix). Esto evita quejas si los archivos son de solo lectura.
--lower-all
Renombra todos los archivos y directorios a minúsculas.
--lower-uppercase
Solo renombra archivos y directorios que tienen un nombre completamente en mayúsculas. Por lo tanto, HELLO.C sería renombrado pero no World.c.
--lower-none
No renombres archivos y directorios a minúsculas. Ten en cuenta que esto no impide el cambio de nombre de un archivo si su extensión no se puede manejar tal cual, por ejemplo, ".Cxx". Esta es la opción predeterminada.
--lower-include
Cuando el archivo correspondiente a una declaración de inclusión (o cualquier otra forma de referencia de archivo para recursos) no se puede encontrar, convierte ese nombre de archivo a minúsculas. Esta es la opción predeterminada.
--nolower-include
No modifiques la declaración de inclusión si no se encuentra el archivo referenciado.
--guiexe | --windows
Asume una aplicación gráfica cuando se encuentra un destino ejecutable o un destino de tipo desconocido. Esta es la opción predeterminada.
--cuiexe | --console
Asume una aplicación de consola cuando se encuentra un destino ejecutable o un destino de tipo desconocido.
--dll
Asume una dll cuando se encuentra un destino de tipo desconocido, es decir, cuando winemaker no puede determinar si es un ejecutable, una dll o una biblioteca estática.
--lib
Asume una biblioteca estática cuando se encuentra un destino de tipo desconocido, es decir, cuando winemaker no puede determinar si es un ejecutable, una dll o una biblioteca estática.
--mfc
Especifica que los destinos están basados en MFC. En ese caso, winemaker adapta las rutas de inclusión y bibliotecas correspondientemente, y enlaza el destino con la biblioteca MFC.
--nomfc
Especifica que los destinos no están basados en MFC. Esta opción deshabilita el uso de bibliotecas MFC, incluso si winemaker encuentra archivos stdafx.cpp o stdafx.h que harían que habilitara MFC automáticamente si no se especificara ni --nomfc ni --mfc.
-Dmacro[=defn]
Añade la definición de macro especificada a la lista global de definiciones de macros.
-Idir
Añade el directorio especificado a la ruta de inclusión global.
-Pdir
Añade el directorio especificado a la ruta de dll global.
-idll
Añade la biblioteca Winelib a la lista global de bibliotecas Winelib a importar.
-Ldir
Añade el directorio especificado a la ruta de bibliotecas global.
-llibrary
Añade la biblioteca especificada a la lista global de bibliotecas con las que enlazar.
--nodlls
No utiliza el conjunto estándar de bibliotecas Winelib para importaciones. Es decir, cualquier DLL que tu código utilice debe ser pasada explícitamente con opciones -i. El conjunto estándar de bibliotecas es: odbc32.dll, odbccp32.dll, ole32.dll, oleaut32.dll y winspool.drv.
--nomsvcrt
Establece algunas opciones para indicar a winegcc que no compile contra msvcrt. Usa esta opción si tienes archivos cpp que incluyan <string>.
--interactive
Usa el modo interactivo. En este modo winemaker te pedirá que confirmes la lista de destinos para cada directorio, y luego que proporciones opciones específicas del directorio y del destino.
--single-target nombre
Especifica que solo hay un destino, llamado nombre.
--generated-files
Genera el Makefile. Esta es la opción predeterminada.
--nogenerated-files
No genera el Makefile.
--wine32
Genera un destino de 32 bits. Esto es útil en sistemas wow64. Sin esta opción, se utiliza la arquitectura predeterminada.

NAME

winemaker - Winelib project management tool

SYNOPSIS

winemaker [OPTION...] [PROJECT_FILE...]

DESCRIPTION

winemaker is a tool that helps you manage Winelib projects. It can be used to generate Makefiles for your projects, convert them to Winelib projects, and vice versa.

Winelib is a library that allows you to compile Windows applications on Unix-like systems. It provides a set of headers and libraries that mimic the Windows API. This allows you to use your existing Windows development tools (like compilers and debuggers) on Unix-like systems.

winemaker can also convert your Winelib projects back into native Windows projects, making it easier to deploy your applications on Windows.

OPTIONS

The following options are available:

--desktop
Generate a desktop configuration file for the project.
--mfc
Generate Makefiles for an MFC project.
--lower-uppercase
Convert all uppercase filenames to lowercase.
--win32, --win64, --win16
Specify the target Windows architecture (Win32, Win64, or Win16).
--help
Display help information and exit.
--version
Display version information and exit.

EXAMPLES

To generate Makefiles for a Winelib project in the current directory:

$ winemaker .

This command will analyze the source files in the current directory and generate a Makefile suitable for compiling with Winelib.

The option -DSTRICT can be used to specify that the STRICT macro must be set when compiling these sources. For example:

$ winemaker -DSTRICT .

This will generate a Makefile that includes the STRICT macro during compilation.

After generating the Makefile, you can compile the project using:

$ make

If you encounter compilation errors, consult the Winelib User Guide for troubleshooting tips.

For an MFC-based project, use the following commands:

$ winemaker --lower-uppercase --mfc .
$ make

For an existing project file (e.g., myproject.dsp), use:

$ winemaker myproject.dsp
$ make

TODO / BUGS

In some cases, manual editing of the Makefile or source files might be necessary.

If the Windows executable/library is available, winedump could potentially be used to determine its type (graphical or console), linked libraries, and exported functions (for libraries). This information could then be used to configure the corresponding Winelib target.

Currently, winemaker has limitations in detecting the library containing an executable; it must be in the current directory or specified in LD_LIBRARY_PATH.

winemaker does not yet support message files or the message compiler.

Bugs can be reported on the Wine bug tracker.
