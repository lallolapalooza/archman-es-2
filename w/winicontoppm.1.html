NOMBRE

winicontoppm - convierte una imagen .ico de Windows en 1 o más imágenes PPM

SINOPSIS

winicontoppm [-writeands] [-allicons|-bestqual] [-multippm] [-verbose] [archivoicono] [archivodestinopnm]

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

Este programa está esencialmente obsoleto; el más nuevo winicontopam es mejor.

winicontoppm lee un archivo .ico de Microsoft Windows y lo convierte en una o más imágenes PPM.

Un icono de Windows contiene una o más imágenes, en diferentes resoluciones y profundidades de color. Cada imagen tiene una máscara 'and', que contiene datos de transparencia.

Por defecto, la salida va a la Salida Estándar. Si especificas archivodestinopnm, la salida va a uno o más archivos nombrados como sigue. Si es solo un archivo (es decir, especificas la opción -multippm o no especificas -allicons), el nombre del archivo es archivodestinopnm.ppm. Si son varios archivos, sus nombres son archivodestinopnm_1.ppm, archivodestinopnm_2.ppm, etc.


Cuando especificas la opción -writeands, los nombres de archivo anteriores se modifican para incluir la cadena xor como en archivodestinopnm_xor.ppm o archivodestinopnm_xor_1.ppm.

winicontoppm puede convertir imágenes .ico con 1, 4, 8, 24 o 32 bits por píxel. Antes de Netpbm 10.15 (abril de 2003), no podía manejar 24 y 32.

OPCIONES

-writeands
Para cada icono escrito, también escribe la máscara 'and' (transparencia) como un archivo PBM separado. Su nombre tiene el formato archivodestinopnm_and.pbm o archivodestinopnm_and_1.pbm.
-allicons
Extrae todas las imágenes del archivo .ico.

Si no especificas esta ni -bestqual, winicontoppm extrae la primera imagen.

-bestqual
Extrae solo la imagen de mejor calidad (la más grande, luego la de mayor bpp) del archivo .ico.

Si no especificas esta ni -allicons, winicontoppm extrae la primera imagen.

-multippm
Escribe todas las imágenes PPM en un solo archivo.
