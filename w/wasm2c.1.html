NOMBRE

wasm2c — convierte un archivo binario WebAssembly a un archivo fuente y encabezado de C

SINOPSIS

wasm2c [opciones] archivo

DESCRIPCIÓN

wasm2c toma un módulo WebAssembly y produce una fuente y encabezado C equivalentes.

Las opciones son las siguientes:

--help
Imprimir un mensaje de ayuda
--version
Imprimir información de la versión
-v, --verbose
Usar varias veces para más información
-o, --output=NOMBREARCHIVO
Archivo de salida para el archivo fuente C generado, por defecto usa stdout
-n, --module-name=NOMMóDULO
Nombre único para el módulo que se está generando. Este nombre se antepone a cada uno de los símbolos C generados. Por defecto, se utiliza el nombre del módulo de la sección de nombres. Si este no está presente, se usa el nombre del archivo de entrada como predeterminado.
--enable-exceptions
Habilitar manejo experimental de excepciones
--disable-mutable-globals
Deshabilitar importación/exportación de variables globales mutables
--disable-saturating-float-to-int
Deshabilitar operadores flotantes a enteros saturados
--disable-sign-extension
Deshabilitar operadores de extensión de signo
--disable-simd
Deshabilitar soporte SIMD
--enable-threads
Habilitar soporte de hilos
--enable-function-references
Habilitar referencias a funciones tipadas
--disable-multi-value
Deshabilitar multi-valor
--enable-tail-call
Habilitar soporte de llamadas de cola
--disable-bulk-memory
Deshabilitar operaciones de memoria masiva
--disable-reference-types
Deshabilitar tipos de referencia (externref)
--enable-annotations
Habilitar sintaxis de anotaciones personalizadas
--enable-code-metadata
Habilitar metadatos de código
--enable-gc
Habilitar recolección de basura
--enable-memory64
Habilitar memoria de 64 bits
--enable-multi-memory
Habilitar multi-memoria
--enable-extended-const
Habilitar expresiones constantes extendidas
--enable-all
Habilitar todas las características
--no-debug-names
Ignorar nombres de depuración en el archivo binario

EJEMPLOS

Analizar el archivo binario test.wasm y escribir test.c y test.h

$ wasm2c test.wasm -o test.c

Analizar test.wasm, escribir test.c y test.h, pero ignorar los nombres de depuración, si los hay

$ wasm2c test.wasm --no-debug-names -o test.c
