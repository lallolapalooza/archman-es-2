WF-RECORDER(1) Manual de comandos generales WF-RECORDER(1)

NOMBRE

wf-recorder — programa simple de grabación de pantalla para compositores basados en wlroots

SINOPSIS

wf-recorder [-abcCdDefFghlmopPrRvxX] [-a, --audio [=DISPOSITIVO]] [-b, --bframes max_b_frames] [-B, --buffrate buffrate] [-c, --codec codec_salida] [-r, --framerate framerate] [-d, --device dispositivo_codificacion] [--no-dmabuf] [-D, --no-damage] [-f, --file nombre_archivo.ext] [-F cadena_filtro] [-g, --geometry geometria] [-h, --help] [-l, --log] [-m, --muxer muxer] [-L, --list-output] [-o, --output salida] [-p, --codec-param [option_param=valor_opcion]] [-v, --version] [-x, --pixel-format] [--audio-backend backend_audio] [-C, --audio-codec codec_audio_salida] [-P, --audio-codec-param [option_param=valor_opcion]] [-R, --sample-rate tasa_muestreo] [-X, --sample-format formato_muestra] [-y, --overwrite]

DESCRIPCIÓN

wf-recorder es una herramienta creada para grabar tu pantalla en compositores Wayland. Utiliza wlr-screencopy para capturar video y ffmpeg(1) para codificarlo.

En su forma más simple, ejecuta wf-recorder para comenzar a grabar y usa 'Ctrl+C' para detenerte. Esto creará un archivo llamado 'recording.mp4' en el directorio de trabajo actual utilizando el codec predeterminado.

Las opciones son las siguientes:

-a, --audio [=DISPOSITIVO]
Comienza a grabar la pantalla con audio.

El argumento DISPOSITIVO es opcional. En caso de que desees especificar el dispositivo PulseAudio que capturará el audio, puedes ejecutar este comando con el nombre de ese dispositivo. Puedes encontrar tu dispositivo ejecutando

$ pactl list sources | grep Name
-b, --bframes max_b_frames
Establece el número máximo de B-Frames a utilizar.
-B, --buffrate buffrate
Informa al codificador una predicción de la tasa de fotogramas esperada. Esto preserva VFR y resuelve el problema del límite de FPS de algunos codificadores (como svt-av1). Debería establecerse a la misma tasa de fotogramas que la pantalla.
-c, --codec codec_salida
Especifica el códec del video. Soporta salida GIF también.

Para cambiar los parámetros del códec, usa -p nombre_opcion=valor_opcion

-r, --framerate framerate
Establece una tasa de fotogramas constante. Duplicará fotogramas para alcanzarla. Esto hace que el video resultante sea CFR. Resuelve el problema del límite de FPS de algunos codificadores.
-d, --device dispositivo_codificacion
Selecciona el dispositivo a usar al codificar el video.

Algunos controladores informan soporte para datos ‘rgb0’ para entrada vaapi pero en realidad solo soportan yuv. Usa la opción -x yuv420 además de las opciones vaapi para convertir los datos en software, antes de enviarlos a la GPU.

--no-dmabuf
Por defecto, wf-recorder intentará usar solo buffers y copias de GPU si se utiliza un codificador de GPU. Sin embargo, esto puede causar problemas en algunos sistemas. En tales casos, esta opción deshabilitará la copia de GPU y forzará una de CPU.
-D, --no-damage
Por defecto, wf-recorder solicitará un nuevo fotograma al compositor solo cuando la pantalla se actualice. Esto resulta en un archivo de salida mucho más pequeño, que sin embargo tiene una tasa de refresco variable. Cuando esta opción está activada, wf-recorder no utiliza esta optimización y graba continuamente nuevos fotogramas, incluso si no hay actualizaciones en la pantalla.
-f, --file nombre_archivo.ext
Al usar la opción -f, el archivo de salida tendrá el nombre nombre_archivo.ext y el formato del archivo se determinará por la extensión proporcionada. Si la extensión no es reconocida por los muxers de tu instalación de ffmpeg(1), el comando fallará.

Puedes verificar los muxers que tu instalación de ffmpeg(1) soporta ejecutando

$ ffmpeg -muxers
-F, --filter cadena_filtro
Establece el filtro ffmpeg a usar. VAAPI requiere `scale_vaapi=format=nv12:out_range=full` para funcionar.
-g, --geometry geometria_pantalla
Selecciona una parte específica de la pantalla. El formato es "x,y AnH".
-h, --help
Imprime la pantalla de ayuda.
-l, --log
Genera un registro en la terminal actual. Para fines de depuración.
-m, --muxer muxer
Establece el formato de salida a un muxer específico en lugar de detectarlo desde el nombre del archivo.
-L, --list-output
Lista las salidas disponibles.
-o, --output
Especifica la salida donde se grabará el video.
-p, --codec-param [nombre_opcion=valor_opcion]
Cambia un parámetro del códec. Se puede usar varias veces: -p nombre_opcion_1=valor_opcion_1 -p nombre_opcion_2=valor_opcion_2
-v, --version
Imprime la versión de wf-recorder.
-x, --pixel-format
Especifica el formato de píxel que se enviará a ffmpeg. Para la codificación VAAPI, se recomiendan los formatos YUV. Por ejemplo, -x nv12. Para obtener una lista de los formatos de píxel disponibles, ejecuta wf-recorder con la opción -x sin argumentos.
--audio-backend backend_audio
Especifica el backend de audio a usar. Opciones: pulse, pipewire.
-C, --audio-codec codec_audio_salida
Especifica el códec de audio de salida.
-P, --audio-codec-param [option_param=valor_opcion]
Cambia un parámetro del códec de audio. Se puede usar varias veces.
-R, --sample-rate tasa_muestreo
Establece la tasa de muestreo de audio.
-X, --sample-format formato_muestra
Establece el formato de muestreo de audio.
-y, --overwrite
Si un archivo con el mismo nombre ya existe, será sobrescrito.

EJEMPLOS

Grabar la pantalla completa en un archivo llamado recording.mp4 usando el códec H.264 con una tasa de fotogramas de 60 FPS:

$ wf-recorder -c libx264 -r 60 -f recording.mp4

Grabar la pantalla completa con audio capturado del dispositivo PulseAudio alsa_output.pci-0000_00_1f.3.analog-stereo.monitor en un archivo llamado recording.webm usando el códec VP9:

$ wf-recorder -a alsa_output.pci-0000_00_1f.3.analog-stereo.monitor -c libvpx-vp9 -f recording.webm

Grabar un área específica de la pantalla (1920x1080 píxeles en la posición x=100, y=200) usando el códec AV1 y el codificador de hardware VAAPI (si está disponible):

$ wf-recorder -g "100,200 1920x1080" -d /dev/dri/renderD128 -c av1 -p usage=realtime -p tune=live -p tile-columns=4 -p tile-rows=2 -p enable-cdef=1 -p enable-restoration=1

Grabar la pantalla completa en un archivo GIF animado:

$ wf-recorder -f animation.gif

Grabar la pantalla completa solicitando fotogramas solo cuando sea necesario (archivo más pequeño, VRF):

$ wf-recorder -f recording.mp4

Grabar la pantalla completa forzando una tasa de fotogramas constante (CFR):

$ wf-recorder -r 30 -f recording.mp4

OPTIONS

The following options are supported:

-x, --pixel-format pixel_format
Establece el formato de píxeles de salida.

Enumera los formatos disponibles usando

$ ffmpeg -pix_fmts
--audio-backend audio_backend
Especifica el backend de audio que se utilizará cuando se establezca -a.
-C, --audio-codec output_audio_codec
Especifica el códec de audio.
-P, --audio-codec-param [option_name=option_value]
Cambia los parámetros del códec de audio.
-R, --sample-rate sample_rate
Cambia la tasa de muestreo de audio, en HZ. El valor predeterminado es 48000.
-X, --sample-format sample_format
Establece el formato de muestra de audio de salida.

Enumera los formatos disponibles usando

$ ffmpeg -sample_fmts
-y, --overwrite
Fuerza la sobrescritura del archivo de salida sin preguntar.

EJEMPLOS

Para seleccionar una parte específica de la pantalla, puede usar --g geometry o usar https://github.com/emersion/slurp para la selección interactiva del área de la pantalla que se grabará:

$ wf-recorder -g "$(slurp)"

Puede grabar pantalla y sonido simultáneamente con

$ wf-recorder --audio --file=recording_with_audio.mp4

Para especificar un dispositivo de audio, use las opciones --a<DEVICE> o ---audio=<DEVICE>.

Para especificar un códec use la opción -c codec. Para cambiar los parámetros del códec, use la opción -p:

$ wf-recorder -c libx264 -p preset=slow -p crf=18

Para establecer un formato de salida específico, use la opción -m, --muxer. Por ejemplo, para generar una salida a un loopback de video4linux2 puede usar:

$ wf-recorder --muxer=v4l2 --codec=rawvideo --file=/dev/video2

Para usar codificación GPU, use un códec VAAPI (por ejemplo, ‘h264_vaapi’ ) y especifique un dispositivo GPU para usar con la opción -d:

$ wf-recorder -f test-vaapi.mkv -c h264_vaapi -d /dev/dri/renderD128

Algunos controladores informan compatibilidad con ‘rgb0’ datos para entrada ‘vaapi’ pero en realidad solo admiten formatos yuv planares. En este caso, use la opción -x yuv420p además de las opciones ‘vaapi’ para convertir los datos a datos yuv planares antes de enviarlos a la GPU.
