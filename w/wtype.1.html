NOMBRE

wtype - escribir en xdotool para Wayland

SINOPSIS

wtype [TEXTO]

wtype [OPCIÓN_O_TEXTO]... -- [TEXTO]...

wtype [OPCIÓN_O_TEXTO] -

DESCRIPCIÓN

wtype es una herramienta de Wayland que te permite simular la entrada del teclado, similar a xdotool type para X11. Esto se logra a través del protocolo Wayland de teclado virtual.

OPCIONES

El modificador puede ser uno de "shift", "capslock", "ctrl", "logo", "win", "alt", "altgr". Ten en cuenta que los modificadores se sueltan automáticamente una vez que el programa termina.

Las teclas con nombre se resuelven mediante libxkbcommon, los identificadores válidos incluyen "Left" y "Home".

-M  MOD
Presiona el modificador MOD.
-m MOD
Suelta el modificador MOD.
-P TECLA
Presiona la tecla TECLA.
-p TECLA
Suelta la tecla TECLA.
-k TECLA
Escribe (presiona y suelta) la tecla TECLA.
-d TIEMPO
Espera TIME milisegundos entre pulsaciones de teclas al escribir textos. Se puede usar varias veces, por defecto es 0.
-s TIEMPO
Espera TIME milisegundos antes de interpretar las siguientes opciones. Esto se puede usar para realizar secuencias de modificadores más complicadas.
-
Lee el texto a escribir desde la entrada estándar. Esta opción solo puede aparecer una vez.

ERRORES

No se conocen errores.
