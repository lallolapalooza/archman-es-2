NOMBRE

waybar - módulo de etiquetas de dwl

DESCRIPCIÓN

El módulo tags muestra el estado actual de las etiquetas en dwl.

CONFIGURACIÓN

Abordado por dwl/tags

num-tags:
tipo: uint
valor por defecto: 9
El número de etiquetas que se deben mostrar. Máximo 32.

tag-labels:
tipo: array
La etiqueta a mostrar para cada etiqueta.

disable-click:
tipo: bool
valor por defecto: false
Si se establece en falso, puedes hacer clic izquierdo para establecer la etiqueta enfocada. Haz clic derecho para alternar el enfoque de la etiqueta. Si se establece en verdadero, este comportamiento se deshabilita.

expand:
tipo: bool
valor por defecto: false
Permite que este módulo consuma dinámicamente todo el espacio sobrante.

EJEMPLO

"dwl/tags": {
	"num-tags": 5
}

ESTILO

  • #tags button
  • #tags button.occupied
  • #tags button.focused
  • #tags button.urgent

Ten en cuenta que los estados ocupado/enfocado/urgente pueden solaparse. Es decir, una etiqueta puede estar ocupada y enfocada al mismo tiempo.
