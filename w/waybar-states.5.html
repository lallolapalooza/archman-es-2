waybar-states(5) Manual de formatos de archivo waybar-states(5)

NOMBRE

waybar - propiedad de estados

DESCRIPCIÓN GENERAL

Algunos módulos admiten 'states' (estados) que permiten que los valores porcentuales se utilicen como desencadenantes de estilo para aplicar una clase cuando el valor coincide con el valor de estado declarado.

ESTADOS

Cada entrada (estado) consta de un <nombre> (tipo: cadena) y un <valor> (tipo: entero).

•
El estado se puede abordar como una clase CSS en el style.css. El nombre de la clase CSS es el <nombre> del estado. Cada clase se activa cuando el valor actual es igual o inferior al <valor> configurado para el módulo battery, o igual o superior al <valor> configurado para todos los demás módulos.
•
Además, cada estado puede tener su propio formato. Estos se pueden configurar a través de format-<nombre>, o si desea diferenciar un poco más, como format-<estado>-<estado>.

EJEMPLO

"battery": {
	"bat": "BAT2",
	"interval": 60,
	"states": {
		"warning": 30,
		"critical": 15
	},
	"format": "{capacity}% {icon}",
	"format-icons": ["", "", "", "", ""],
	"max-length": 25
}

ESTILIZANDO ESTADOS

•
#battery.<estado> - <estado> se puede definir en la configuración.

EJEMPLO:

  • #battery.warning: { background: orange; }
  • #battery.critical: { background: red; }
