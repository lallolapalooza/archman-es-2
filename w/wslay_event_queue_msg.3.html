wslay_event_queue_msg(3)

Paquete: libwslay

Licencias: MIT

WSLAY_EVENT_QUEUE_MSG(3) wslay WSLAY_EVENT_QUEUE_MSG(3)

NOMBRE

wslay_event_queue_msg - Poner en cola un mensaje para transmisión futura

SINOPSIS

#include <wslay/wslay.h>

int wslay_event_queue_msg(wslay_event_context_ptr ctx, const struct wslay_event_msg *arg)
int wslay_event_queue_msg_ex(wslay_event_context_ptr ctx, const struct wslay_event_msg *arg, uint8_t rsv)

DESCRIPCIÓN

wslay_event_queue_msg() y wslay_event_queue_msg_ex() ponen en cola el mensaje especificado en arg. La struct wslay_event_msg se define como:

struct wslay_event_msg {
    uint8_t        opcode;
    const uint8_t *msg;
    size_t         msg_length;
};

El miembro opcode es el código de operación del mensaje. El miembro msg es el puntero a los datos del mensaje. El miembro msg_length es la longitud de los datos del mensaje.

Esta función soporta tanto mensajes de control como no de control, y el mensaje dado se envía sin fragmentación. Si se necesita fragmentación, use la función wslay_event_queue_fragmented_msg() en su lugar.

Esta función crea una copia de msg de longitud msg_length.

Esta función solo pone en cola un mensaje y no lo envía. La llamada a la función wslay_event_send() envía estos mensajes en cola.

wslay_event_queue_msg_ex() acepta adicionalmente el parámetro rsv, que son bits reservados para enviar. Para establecer bits reservados, use las macros WSLAY_RSV1_BIT, WSLAY_RSV2_BIT y WSLAY_RSV3_BIT. Consulte wslay_event_config_set_allowed_rsv_bits() para ver los bits reservados permitidos para establecer.

VALOR DE RETORNO

wslay_event_queue_msg() y wslay_event_queue_msg_ex() devuelven 0 si tienen éxito, o devuelven los siguientes códigos de error negativos:

WSLAY_ERR_NO_MORE_MSG
No se pudo poner en cola el mensaje dado. Una de las posibles razones es que se ha puesto en cola/enviado un frame de control de cierre y no se permite poner en cola más mensajes.
WSLAY_ERR_INVALID_ARGUMENT
El mensaje dado es inválido; o se establece RSV1 para el frame de control; o se establece un bit en rsv que no está permitido (consulte wslay_event_config_set_allowed_rsv_bits()).
WSLAY_ERR_NOMEM
Sin memoria.

VEASE TAMBIÉN

wslay_event_queue_fragmented_msg(), wslay_event_queue_fragmented_msg_ex(), wslay_event_queue_close()
