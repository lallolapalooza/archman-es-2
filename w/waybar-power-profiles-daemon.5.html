NOMBRE

waybar - módulo power-profiles-daemon

DESCRIPCIÓN

El módulo power-profiles-daemon muestra el perfil activo de power-profiles-daemon y permite ciclar entre los perfiles disponibles al hacer clic.

ARCHIVOS

$XDG_CONFIG_HOME/waybar/config

CONFIGURACIÓN

Opción Tipo Predeterminado Descripción
format cadena "{icon}" Mensaje mostrado en la barra. {icon} y {profile} se sustituyen respectivamente por el icono que representa el perfil activo y su nombre completo.
tooltip-format cadena "Perfil de energía: {profile}nControlador: {driver}" Mensaje mostrado en la descripción emergente del módulo. {icon} y {profile} se sustituyen respectivamente por el icono que representa el perfil activo y su nombre completo.
tooltip booleano verdadero Muestra la descripción emergente.
format-icons objeto Ver valor predeterminado en el ejemplo a continuación. Iconos utilizados para representar los diversos perfiles de energía. Nota: la configuración predeterminada utiliza los iconos de font-awesome. Es posible que desee anularla si no tiene esta fuente instalada en su sistema.
expand: booleano falso Habilita que este módulo consuma todo el espacio sobrante de forma dinámica.

EJEMPLOS DE CONFIGURACIÓN

Visualización compacta (configuración predeterminada):

"power-profiles-daemon": {
  "format": "{icon}",
  "tooltip-format": "Perfil de energía: {profile}nControlador: {driver}",
  "tooltip": true,
  "format-icons": {
    "default": "",
    "performance": "",
    "balanced": "",
    "power-saver": ""
  }
}

Mostrar el nombre completo del perfil:

"power-profiles-daemon": {
  "format": "{icon}   {profile}",
  "tooltip-format": "Perfil de energía: {profile}nControlador: {driver}",
  "tooltip": true,
  "format-icons": {
    "default": "",
    "performance": "",
    "balanced": "",
    "power-saver": ""
  }
}
