wslay_event_recv(3)

Paquete: libwslay

Licencias: MIT

WSLAY_EVENT_RECV(3) wslay WSLAY_EVENT_RECV(3)

NOMBRE

wslay_event_recv - Recibir mensajes

SINOPSIS

#include <wslay/wslay.h>

int wslay_event_recv(wslay_event_context_ptr ctx)

DESCRIPCIÓN

wslay_event_recv() recibe mensajes del par. Al recibir mensajes, utiliza la función wslay_event_recv_callback. Una única llamada a esta función recibe múltiples mensajes hasta que la función wslay_event_recv_callback establece el código de error WSLAY_ERR_WOULDBLOCK.

wslay_event_recv() llama a las siguientes funciones de devolución de llamada para sus respectivos eventos (Ver wslay_event_context_server_init() o wslay_event_context_client_init() para los detalles de cada devolución de llamada).

wslay_event_on_frame_recv_start_callback
Se llama cuando se empieza a recibir un nuevo frame.
wslay_event_on_frame_recv_start_callback
Se llama cuando se empieza a recibir un nuevo frame.
wslay_event_on_frame_recv_chunk_callback
Se llama cuando se recibe un trozo de la carga útil del frame.
wslay_event_on_frame_recv_end_callback
Se llama cuando se recibe un frame completo.
wslay_event_on_msg_recv_callback
Se llama cuando se recibe un mensaje completo.

Cuando se recibe un frame de control de cierre, esta función pone en cola automáticamente un frame de control de cierre. También llama a wslay_event_set_read_enabled() con el segundo argumento 0 para deshabilitar la lectura posterior del par.

Cuando se recibe un frame de control de ping, esta función pone en cola automáticamente un frame de control de pong.

En caso de un error fatal que resulte en un código de retorno negativo, esta función llama a wslay_event_set_read_enabled() con el segundo argumento 0 para deshabilitar la lectura posterior del par.

VALOR DE RETORNO

wslay_event_recv() devuelve 0 si tiene éxito, o uno de los siguientes códigos de error negativos:

WSLAY_ERR_CALLBACK_FAILURE
La función de devolución de llamada definida por el usuario ha fallado.
WSLAY_ERR_NOMEM
Sin memoria.

Cuando se devuelve un código de error negativo, la aplicación no debe realizar más llamadas a wslay_event_recv() y debe cerrar la conexión WebSocket.

VER TAMBIÉN

wslay_event_set_read_enabled()
