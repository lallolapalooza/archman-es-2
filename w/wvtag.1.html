WVTAG(1) Manual de Comandos Generales WVTAG(1)

NOMBRE

wvtag — manipular metadatos de wavpack

SINOPSIS

wvtag [-opciones] archivo ...

DESCRIPCIÓN

wvtag aplica las operaciones de metadatos especificadas a cada uno de los archivos fuente WavPack especificados en este orden: limpiar, importar, eliminar, escribir, extraer, listar. Tenga en cuenta que los metadatos de WavPack se almacenan en etiquetas APEv2, y wvtag importará automáticamente desde una etiqueta ID3v1 si es la única etiqueta presente en el archivo fuente, y esa etiqueta ID3v1 será eliminada y reemplazada por una etiqueta APEv2 si se solicita una edición.

OPCIONES

--allow-huge-tags
permite datos de etiquetas de hasta 16 MB. Incrustar > 1 MB no se recomienda para dispositivos portátiles y puede que no funcione con algunos programas, incluidas versiones antiguas de WavPack.
-c
extrae solo la hoja de pistas (cuesheet) a stdout (equivalente a -x “cuesheet”)
-cc
extrae la hoja de pistas al archivo nombre-fuente.cue en el mismo directorio que el archivo fuente (equivalente a -xx “cuesheet=%a.cue”)
--clean, --clear
limpia todos los elementos de la etiqueta (se hace primero)
-d “Campo”
elimina el elemento de metadatos especificado (texto o binario)
-h, --help
muestra esta ayuda
--import-id3
importa elementos de etiqueta aplicables de la etiqueta ID3v2.3 presente en DSF y posiblemente otros archivos a la etiqueta APEv2. Si hay imágenes de portada de > 1 MB presentes, agregue --allow-huge-tags para incluirlas.
-l, --list
lista todos los elementos de la etiqueta (se hace al final)
--no-utf8-convert
no recodifica las etiquetas pasadas de la codificación local a UTF-8, asume que ya están en UTF-8
-q
Silencioso: minimiza la salida de la consola.
-v, --version
escribe la versión del programa en stdout
-w “Campo=”
elimina el elemento de metadatos especificado (texto o binario)
-w “Campo=Valor”
escribe metadatos de texto especificados a la etiqueta APEv2
-w “Campo=@archivo.ext”
escribe metadatos de texto especificados desde un archivo a la etiqueta APEv2, normalmente se usa para hojas de pistas (cuesheets) y registros incrustados (nombres de campo “Cuesheet” y “Log”)
--write-binary-tag “Campo=@archivo.ext”
escribe el archivo de metadatos binarios especificado a la etiqueta APEv2, normalmente se usa para carátulas de álbum con el nombre de campo especificado “Cover Art (Front)”
-x “Campo”
extrae solo el campo de etiqueta especificado a stdout
-xx “Campo[=nombrearchivo]”
extrae el campo de etiqueta especificado a un archivo con nombre en el mismo directorio que el archivo fuente. Una especificación opcional de nombrearchivo puede contener ‘%a’ que se reemplaza con el nombre base del archivo de audio; ‘%t’ que se reemplaza con el nombre del campo de etiqueta (tenga en cuenta que para etiquetas binarias, esto proviene de los datos); y ‘%e’ que se reemplaza con la extensión del archivo fuente de la etiqueta binaria (o “txt” para una etiqueta de texto).
-y
sí a todas las advertencias; ¡usar con precaución!
