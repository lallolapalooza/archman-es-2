NOMBRE

waybar - módulo de scratchpad de sway

DESCRIPCIÓN

El módulo scratchpad muestra el estado del scratchpad en Sway.

CONFIGURACIÓN

Abordado por sway/scratchpad

format:
tipo: cadena
valor predeterminado: {icon} {count}
El formato, cómo se debe mostrar la información.

show-empty:
tipo: booleano
valor predeterminado: false
Opción para mostrar el módulo cuando el scratchpad está vacío.

format-icons:
tipo: arreglo/objeto
Basado en el número actual de ventanas del scratchpad, se selecciona el icono correspondiente.

tooltip:
tipo: booleano
valor predeterminado: true
Opción para deshabilitar la información emergente al pasar el ratón.

tooltip-format:
tipo: cadena
valor predeterminado: {app}: {title}
El formato, cómo se debe mostrar la información en la información emergente.

menu:
tipo: cadena
Acción que muestra el menú.

menu-file:
tipo: cadena
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: arreglo
Las acciones correspondientes a los botones del menú.

expand:
tipo: booleano
valor predeterminado: false
Permite que este módulo consuma dinámicamente todo el espacio sobrante.

REEMPLAZOS DE FORMATO

{icon}: Icono, como se define en format-icons.

{count}: Número de ventanas en el scratchpad.

{app}: Nombre de la aplicación en el scratchpad.

{title}: Título de la aplicación en el scratchpad.

EJEMPLOS

"sway/scratchpad": {
	"format": "{icon} {count}",
	"show-empty": false,
	"format-icons": ["", "󰋎"],
	"tooltip": true,
	"tooltip-format": "{app}: {title}"
}
