WINETRICKS(1) Gestor de paquetes de Wine WINETRICKS(1)

NOMBRE

winetricks - gestiona entornos virtuales de Windows usando Wine

SINOPSIS

winetricks [opciones] [verbo ... ]

DESCRIPCIÓN

winetricks es una forma sencilla de solucionar problemas comunes en Wine.

Proporciona comandos simples para ajustar la configuración de Wine, descargar e instalar DLL y fuentes de Windows que faltan, o instalar varias aplicaciones con soluciones alternativas apropiadas para la versión actual de Wine.

Se puede usar a través de GUI o línea de comandos. El modo de línea de comandos está pensado tanto para uso interactivo como para ser un bloque de construcción en interfaces de Wine más sofisticadas y en pruebas de regresión automatizadas.

winetricks sin argumentos muestra una GUI usando Zenity o Kdialog.

OPCIONES

--country=CC
Establece el código de país a CC y no detecta tu dirección IP al reintentar descargas
-f, --force
No comprueba si los paquetes ya se instalaron
--gui
Muestra diagnósticos de GUI incluso cuando es controlado por la interfaz de línea de comandos
--gui=OPT
Establece OPT a kdialog o zenity para anular el motor de GUI
--isolate
Instala cada aplicación o juego en su propia "botella" (wineprefix aislado)
--self-update
Actualiza esta aplicación a la última versión
--update-rollback
Revierte la última autoactualización
--no-isolate
No instala cada aplicación o juego en su propia "botella" (comportamiento predeterminado)
--no-clean
No elimina directorios temporales (útil durante la depuración)
--optin
Opta por informar qué verbos utilizas a los mantenedores de Winetricks
--optout
Desactiva la notificación de qué verbos utilizas a los mantenedores de Winetricks
-q, --unattended
No hace preguntas, solo instala automáticamente
-t, --torify
Ejecuta las descargas bajo torify, si está disponible
-v, --verbose
Muestra todos los comandos a medida que se ejecutan
--verify
Ejecuta pruebas (automatizadas) de GUI para verbos, si están disponibles
-h, --help
Muestra este mensaje y sale
-V, --version
Muestra la versión y sale

COMANDOS

apps list
lista verbos en la categoría 'aplicaciones'
benchmarks list
lista verbos en la categoría 'benchmarks'
dlls list
lista verbos en la categoría 'dlls'
fonts list
lista verbos en la categoría 'fonts'
settings list
lista verbos en la categoría 'settings'
list
lista categorías
list-cached
lista verbos cacheados y listos para instalar
list-download
lista verbos que descargan automáticamente
list-manual-download
lista verbos que descargan con algo de ayuda del usuario
list-installed
lista verbos ya instalados
arch=32|64
crea un wineprefix de 32 o 64 bits; esta opción debe darse antes de prefix=foobar y no funcionará en el caso del wineprefix predeterminado.
prefix=foobar
selecciona WINEPREFIX=$HOME/.local/share/wineprefixes/foobar
annihilate
Elimina TODOS LOS DATOS Y APLICACIONES DENTRO DE ESTE WINEPREFIX

EJEMPLOS

Para ver la lista de paquetes disponibles para instalar:
winetricks list-download
Para instalar un paquete:
winetricks 7zip

VARIABLES DE ENTORNO

Wine comprueba varias variables de entorno al inicio:

WINE
Si está configurada, especifica qué binario de wine usar por defecto
WINESERVER
Si está configurada, especifica qué wineserver usar por defecto
WINEPREFIX
Si está configurada, especifica la ubicación del directorio .wine predeterminado ( normalmente $HOME/.wine).
XDG_CACHE_HOME
Si está configurada, es la ruta a la caché de datos de usuario del sistema (predeterminado: $HOME/.cache) W_CACHE ruta a la caché de datos de usuario de Winetricks (predeterminado: $XDG_CACHE_HOME/winetricks}
