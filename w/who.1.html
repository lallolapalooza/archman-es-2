WHO(1) Comandos de Usuario WHO(1)

NOMBRE

who - muestra quién está conectado

SINOPSIS

who [OPCIÓN]... [ ARCHIVO | ARG1 ARG2 ]

DESCRIPCIÓN

Imprime información sobre los usuarios que están actualmente conectados.

-a, --all
igual que -b -d --login -p -r -t -T -u
-b, --boot
hora del último arranque del sistema
-d, --dead
imprime procesos muertos
-H, --heading
imprime una línea de encabezados de columna
-l, --login
imprime procesos de inicio de sesión del sistema
--lookup
intenta canonizar nombres de host a través de DNS
-m
solo el nombre de host y el usuario asociado con la entrada estándar
-p, --process
imprime procesos activos iniciados por init
-q, --count
todos los nombres de inicio de sesión y el número de usuarios conectados
-r, --runlevel
imprime el nivel de ejecución actual
-s, --short
imprime solo nombre, línea y hora (predeterminado)
-t, --time
imprime el último cambio de reloj del sistema
-T, -w, --mesg
agrega el estado del mensaje del usuario como +, - o ?
-u, --users
lista los usuarios conectados
--message
igual que -T
--writable
igual que -T
--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale

Si no se especifica ARCHIVO, se usa /var/run/utmp. /var/log/wtmp como ARCHIVO es común. Si se dan ARG1 ARG2, se presupone -m: 'am i' o 'mom likes' son usuales.
