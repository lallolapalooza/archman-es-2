WEBLOGVIS(1) Manual de Comandos Generales WEBLOGVIS(1)

NOMBRE

weblogvis - visualizar actividad y rendimiento de los registros del servidor Web

SINOPSIS

weblogvis [-bCfiVz] [-A alineación] [-a archivo] [-h host] [-I tiempo] [-m max] [-n archivo_pmns] [-O tiempo] [-p puerto] [-S tiempo] [-t intervalo] [-T tiempo] [-x versión] [-Z zona_horaria] [servidor ...]

DESCRIPCIÓN

weblogvis muestra la actividad del servidor Web extraída de los registros de acceso del servidor Web por el agente Performance Co-Pilot (PCP) pmdaweblog(1). La visualización se modula por los valores de las métricas de rendimiento recuperadas del host objetivo que ejecuta pmcd(1) y el Agente de Dominio de Métricas de Rendimiento pmdaweblog(1) (PMDA(3)), o del registro de archivo PCP identificado por archivo. La visualización se actualiza cada intervalo segundos (predeterminado 2 segundos).

El modo de visualización predeterminado muestra la tasa de solicitudes clasificada por el tamaño de la respuesta de la solicitud, para todos los registros del servidor Web que están siendo monitoreados por pmdaweblog(1). La parte superior de la visualización incluye el tiempo de inactividad y la tasa total de solicitudes de cada servidor Web. La lista de servidores se puede restringir especificando nombres de servidor. Los servidores posibles se enumeran en el archivo de configuración de pmdaweblog(1).

weblogvis utiliza pmview(1), y por lo tanto la interfaz de usuario sigue la descrita para pmview(1), que a su vez muestra la escena dentro de un visor examinador de Inventor.

weblogvis pasa la mayoría de las opciones de línea de comandos a pmview(1). Por lo tanto, las opciones de línea de comandos -A, -a, -C, -h, -n, -O, -p, -S, -t, -T, -x, -Z y -z, y la interfaz de usuario se describen en la página del manual de pmview(1).

OPCIONES DE LÍNEA DE COMANDOS

Las opciones específicas de weblogvis son:

-b
Cambia el modo de visualización para informar bytes por segundo, en lugar de solicitudes por segundo.
-f
Cambia la clasificación de actividad para usar funciones HTTP (Get, Post, Head y Other), en lugar de la clasificación predeterminada por tamaño de resultado de la solicitud. Con esta clasificación, también se muestran las tasas de error de los registros para cada servidor Web.
-i
Etiqueta cada columna con el nombre del servidor Web.
-I tiempo
Cambia el tiempo de inactividad esperado predeterminado para los servidores Web de 3600 segundos (1 hora) a tiempo.
-m max
Cambia el máximo de normalización predeterminado a max bytes/segundo o solicitudes/segundo, dependiendo del modo de visualización. Los valores predeterminados son 500000 bytes por segundo o 100 solicitudes por segundo.
-V
Modo detallado: muestra el archivo de configuración de pmview(1) generado.

ARCHIVOS

$PCP_VAR_DIR/config/pmlogger/config.web
Archivo de configuración de pmlogger(1) que se puede usar para crear un archivo PCP adecuado para su visualización con weblogvis
$PCP_VAR_DIR/config/pmchart/Web.Alarms
Archivo de configuración de pmchart(1) para monitorear condiciones de alarma del servidor Web
$PCP_VAR_DIR/config/pmchart/Web.Requests
Archivo de configuración de pmchart(1) para monitorear solicitudes del servidor Web
$PCP_VAR_DIR/config/pmchart/Web.Volume
Archivo de configuración de pmchart(1) para monitorear el volumen de transacciones del servidor Web
$PCP_PMDAS_DIR/weblog
Directorio de instalación de pmdaweblog(1)

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede usar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(4).
