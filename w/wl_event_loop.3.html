Descripción detallada

Un contexto de bucle de eventos.

Normalmente, creas un contexto de bucle de eventos, le añades fuentes y llamas a wl_event_loop_dispatch() en un bucle para procesar eventos.

struct wl_event_loop * wl_event_loop_create (void )

Crea un nuevo contexto de bucle de eventos

Retorna

Un nuevo objeto de contexto de bucle de eventos.

Esto crea un nuevo contexto de bucle de eventos. Inicialmente, este contexto está vacío. Las fuentes de eventos deben añadirse explícitamente a él.

Normalmente, el bucle de eventos se ejecuta llamando a wl_event_loop_dispatch() en un bucle hasta que el programa termina. Alternativamente, un bucle de eventos puede integrarse en otro bucle de eventos a través de su descriptor de archivo, ver wl_event_loop_get_fd().

void wl_event_loop_destroy (struct wl_event_loop * loop)

Destruye un contexto de bucle de eventos

Parámetros

loop El bucle de eventos que se va a destruir.

Esto emite la señal de destrucción del bucle de eventos, cierra el descriptor de archivo del bucle de eventos y libera `loop`.

Si el bucle de eventos tiene fuentes existentes, estas no pueden eliminarse de forma segura después. Por lo tanto, se debe llamar a wl_event_source_remove() en todas las fuentes de eventos antes de destruir el contexto del bucle de eventos.

int wl_event_loop_dispatch (struct wl_event_loop * loop, int timeout)

Espera eventos y los procesa

Parámetros

loop El bucle de eventos cuyas fuentes se deben esperar.
timeout El tiempo de espera de sondeo en milisegundos.

Retorna

0 para éxito, -1 para error de sondeo (o actualización del temporizador).

Se sondean todas las fuentes de eventos asociadas. Esta función se bloquea hasta que cualquier fuente de eventos entrega un evento (excluyendo las fuentes inactivas), o el tiempo de espera expira. Un tiempo de espera de -1 deshabilita el tiempo de espera, haciendo que la función se bloquee indefinidamente. Un tiempo de espera de cero hace que el sondeo devuelva inmediatamente.

Se procesan todas las fuentes inactivas antes de bloquear. Una fuente inactiva se destruye cuando se procesa. Después de bloquear, se procesan todas las demás fuentes listas. Luego, se vuelven a procesar las fuentes inactivas, en caso de que los eventos procesados crearan fuentes inactivas. Finalmente, se procesan todas las fuentes marcadas con wl_event_source_check() en un bucle hasta que todas sus funciones de procesamiento devuelvan cero.

int wl_event_loop_get_fd (struct wl_event_loop * loop)

Obtiene el descriptor de archivo del bucle de eventos

Parámetros

loop El contexto del bucle de eventos.

Retorna

El descriptor de archivo agregado.

Esta función devuelve el descriptor de archivo agregado, que representa todas las fuentes de eventos (excluyendo las fuentes inactivas) asociadas con el contexto del bucle de eventos dado. Cuando cualquier fuente de eventos pone un evento a disposición, se reflejará en el descriptor de archivo agregado.

Cuando el descriptor de archivo agregado entrega un evento, se puede llamar a wl_event_loop_dispatch() en el bucle de eventos para procesar todos los eventos disponibles.
