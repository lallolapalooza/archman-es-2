NOMBRE

wrc - Compilador de Recursos de Wine

SINOPSIS

wrc [opciones] [archivo_entrada...]

DESCRIPCIÓN

wrc compila recursos desde archivo_entrada a un formato binario compatible con win16 y win32.

El archivo fuente se preprocesa con un preprocesador incorporado compatible con ANSI-C antes de que se compilen los recursos. Ver PREPROCESADOR abajo.

wrc toma una serie de archivo_entrada como argumento. Los recursos se leen de la entrada estándar si no se proporciona archivo_entrada. Si el archivo de salida no se especifica con -o, entonces wrc escribirá la salida a archivo_entrada.res eliminando .rc, o a wrc.tab.res si no se proporcionó ningún archivo_entrada.

OPCIONES

-D, --definir=id[=val]
Define el identificador del preprocesador id con el valor (opcional) val. Ver también PREPROCESADOR abajo.
--depurar=nn
Establece el nivel de depuración a nn. El valor es una máscara de bits que consiste en 1=verboso, 2=volcar internos, 4=seguimiento del analizador de recursos, 8=mensajes del preprocesador, 16=escáner del preprocesador y 32=seguimiento del analizador del preprocesador.
-E
Solo preprocesar. La salida se escribe en la salida estándar si no se seleccionó ningún archivo de salida. La salida es compatible con lo que generaría gcc.
-h, --ayuda
Imprime un mensaje de resumen y sale.
-i, --entrada=archivo
El nombre del archivo de entrada. Si esta opción no se utiliza, wrc utilizará el primer argumento que no sea una opción como nombre del archivo de entrada. Si no hay argumentos que no sean opciones, wrc leerá de la entrada estándar.
-I, --dir-incluir=ruta
Añade ruta a la lista de directorios donde buscar inclusiones. Se permite especificar -I varias veces. Los archivos de inclusión se buscan en el orden en que se especificaron las opciones -I.
La búsqueda es compatible con gcc, en la que los nombres de archivo entre comillas '<>' se buscan exclusivamente a través del conjunto de rutas -I, mientras que los nombres de archivo entre comillas '""' se intentan primero abrir en el directorio actual. Las declaraciones de recursos con referencias a archivos también se ubican de la misma manera.
-J, --formato-entrada=formato
Establece el formato de entrada. Las opciones válidas son 'rc' o 'rc16'. Establecer la entrada en 'rc16' deshabilita el reconocimiento de palabras clave de win32.
-l, --idioma=idioma
Establece el idioma predeterminado a idioma. El valor predeterminado es el idioma neutral 0 (es decir, "LANGUAGE 0, 0").
-m16, -m32, -m64
Genera recursos para plataformas de 16, 32 o 64 bits respectivamente. La única diferencia entre 32 bits y 64 bits es si el símbolo del preprocesador _WIN64 está definido.
--dir-nls=dir
Especifica el directorio donde buscar los archivos NLS que contienen las tablas de mapeo de páginas de códigos.
--nostdinc
No buscar en la ruta de inclusión estándar, buscar archivos de inclusión solo en los directorios especificados explícitamente con la opción -I.
--no-usar-archivo-temporal
Ignorado por compatibilidad con windres.
-o, -fo, --salida=archivo
Escribe la salida en archivo. El valor predeterminado es archivo_entrada.res eliminando .rc o wrc.tab.res si la entrada se lee de la entrada estándar.
-O, --formato-salida=formato
Establece el formato de salida. Los formatos compatibles son po, pot, res y res16. Si esta opción no se especifica, el formato será res por defecto.
En modo po, si se especifica un nombre de archivo de salida debe coincidir con un nombre de idioma conocido, como en_US.po; solo se generarán los recursos para el idioma especificado. Si no se especifica un nombre de archivo de salida, se creará un archivo .po separado para cada idioma encontrado en la entrada.
--pedantic
Habilita advertencias pedantes. Notablemente, la redefinición de declaraciones #define se puede descubrir con esta opción.
--dir-po=dir
Habilita la generación de traducciones de recursos basadas en archivos mo cargados desde el directorio especificado. Ese directorio debe seguir la convención gettext, en particular debe contener un archivo .mo por cada idioma, y un archivo LINGUAS que liste los idiomas disponibles.
-r
Ignorado por compatibilidad con rc.
--preprocesador=programa
Esta opción se puede usar para especificar el preprocesador a utilizar, incluyendo cualquier argumento previo. Si no se especifica, wrc usa su procesador incorporado. Para deshabilitar el preprocesamiento, usa --preprocesador=cat.
--sysroot=dir
Antepone dir a las rutas de inclusión estándar.
--utf8, -u
Establece la página de códigos predeterminada del archivo de entrada a UTF-8.
-U, --desdefinir=id
Desdefine el identificador del preprocesador id. Ten en cuenta que solo las macros definidas hasta este punto se desdefinen con este comando. Sin embargo, esto incluye las macros especiales definidas automáticamente por wrc. Ver también PREPROCESADOR abajo.
--usar-archivo-temporal
Ignorado por compatibilidad con windres.
-v, --verboso
Activa el modo verboso (equivalente a -d 1).
--version
Imprime la versión y sale.

PREPROCESADOR

El preprocesador es compatible con ANSI-C con algunas de las extensiones del preprocesador de gcc.

El preprocesador reconoce estas directivas: #include, #define (tanto simple como macro), #undef, #if, #ifdef, #ifndef, #elif, #else, #endif, #error, #warning, #line, # (directiva de nula y de línea), #pragma (ignorado), #ident (ignorado).

El preprocesador define por defecto varias definiciones:
- RC_INVOKED establecido a 1
- __WRC__ Versión mayor de wrc
- __WRC_MINOR__ Versión menor de wrc
- __WRC_PATCHLEVEL__ Nivel de parche

El modo de compilación Win32 también establece _WIN32 a 1.

Las macros especiales __FILE__, __LINE__, __TIME__ y __DATE__ también se reconocen y se expanden a sus equivalentes respectivos.

SOPORTE DE IDIOMAS

El idioma, la versión y las características se pueden vincular a todos los tipos de recursos que tienen datos en línea, como RCDATA. Esta es una extensión al compilador de recursos de Microsoft, que carece completamente de este soporte. Solo VERSIONINFO no puede tener versiones y características adjuntas, pero los idiomas se propagan correctamente si lo declara correctamente antes de que comience el recurso VERSIONINFO.

Ejemplo:

1 RCDATA DISCARDABLE
LANGUAGE 1, 0
VERSION 312
CHARACTERISTICS 876
{
	1, 2, 3, 4, 5, "y cualquier otro dato que desees"
	'00 01 02 03 04 05 06 07 08'
}

AUTORES

wrc fue escrito por Bertho A. Stultiens y es una reescritura casi completa del primer compilador de recursos de wine (1994) de Martin von Loewis. Tipos de recursos adicionales fueron aportados por Ulrich Czekalla y Albert den Haan. Muchas limpiezas por Dimitrie O. Paun en 2002-2003. Muchos desarrolladores de Wine han contribuido con correcciones de errores.

ERRORES

- El preprocesador reconoce macros de argumentos variables, pero no las expande correctamente.
- La notificación de errores debería ser más precisa, ya que actualmente la columna y el número de línea reportados son los del siguiente token.
- Las opciones de memoria predeterminadas deberían diferir entre win16 y win32.

No hay soporte para:
- RT_DLGINCLUDE, RT_VXD, RT_PLUGPLAY y RT_HTML (formato desconocido)
- El control PUSHBOX no es compatible debido a la falta de funcionalidad original.

Las fuentes se analizan y generan, pero aún no hay soporte para la generación de FONTDIR. El usuario debe proporcionar el recurso FONTDIR en el código fuente para que coincida con los recursos FONT.

Los errores pueden ser reportados en el rastreador de errores de Wine.

DISPONIBILIDAD

wrc es parte de la distribución de Wine, que está disponible a través de WineHQ, el centro de desarrollo de Wine.
