WIDL(1) Manual de desarrolladores de Wine WIDL(1)

NOMBRE

widl - Compilador de Wine Interface Definition Language (IDL)

SINOPSIS

widl [opciones] archivo_IDL
widl [opciones] --dlldata-only nombre1 [nombre2...]

DESCRIPCIÓN

Cuando no se utilizan opciones, el programa generará un archivo de cabecera y, posiblemente, stubs de cliente y servidor, archivos proxy y dlldata, una typelib y un archivo UUID, dependiendo del contenido del archivo IDL. Si se proporciona alguna de las opciones -c, -h, -p, -s, -t, -u o --local-stubs, widl solo generará los archivos solicitados y ningún otro. Cuando se ejecuta con --dlldata-only, widl solo generará un archivo dlldata, y contendrá una lista de los nombres pasados como argumentos. Normalmente, la forma en que se actualiza este archivo es que cada vez que se ejecuta widl, lee cualquier archivo dlldata existente y, si es necesario, lo regenera con la misma lista de nombres, pero incluyendo el archivo proxy actual.

Cuando se ejecuta sin argumentos, widl imprimirá un mensaje de ayuda.

OPCIONES

Opciones generales:

-V
Imprime el número de versión y sale.
-o, --output=nombre
Establece el nombre del archivo de salida. Al generar varios archivos de salida, esto establece solo el nombre base del archivo; los archivos de salida correspondientes se nombrarán entonces infile.h, infile_p.c, etc. Si se especifica un nombre de archivo completo con extensión, solo se generará ese archivo.
-b, --target=cpu-fabricante[-kernel]-os
Establece la arquitectura de destino al compilar de forma cruzada. La especificación del destino tiene el formato estándar de autoconf tal como lo devuelve config.sub.
-m32, -m64, --win32, --win64
Fuerza la arquitectura de destino a 32 bits o 64 bits.
--sysroot=dir
Prefija las rutas de inclusión estándar con dir.
--nostdinc
No buscar en rutas de inclusión estándar como /usr/include y /usr/local/include.

Opciones de archivo de cabecera:

-h
Genera archivos de cabecera. El nombre de archivo de salida predeterminado es infile.h.
--oldnames
Utiliza convenciones de nombres antiguas.

Opciones de biblioteca de tipos:

-t
Genera una biblioteca de tipos. El nombre de archivo de salida predeterminado es infile.tlb. Si el nombre del archivo de salida termina en .res, se genera en su lugar un archivo de recursos binario que contiene la biblioteca de tipos.
-L ruta
Añade un directorio a la ruta de búsqueda de bibliotecas para typelibs importadas. La opción se puede especificar varias veces.
--oldtlb
Genera una biblioteca de tipos en el formato antiguo (formato SLTG).

Opciones de archivo UUID:

-u
Genera un archivo UUID. El nombre de archivo de salida predeterminado es infile_i.c.

Opciones de generación de proxy/stub:

--align=n, --packing=n
Establece el empaquetado de estructuras a n. Los valores soportados son 2, 4 y 8.
-c
Genera un archivo stub de cliente. El nombre de archivo de salida predeterminado es infile_c.c.
-Os
Genera stubs en línea.
-Oi
Genera stubs interpretados al estilo antiguo.
-Oif, -Oic, -Oicf
Genera stubs interpretados completamente al estilo nuevo. Esta es la opción predeterminada.
-p
Genera un proxy. El nombre de archivo de salida predeterminado es infile_p.c.
--prefix-all=prefijo
Prefijo a añadir al nombre de los stubs tanto de cliente como de servidor.
--prefix-client=prefijo
Prefijo a añadir al nombre de los stubs de cliente.
--prefix-server=prefijo
Prefijo a añadir al nombre de los stubs de servidor.
-s
Genera un archivo stub de servidor. El nombre de archivo de salida predeterminado es infile_s.c.
--winrt
Habilita el modo Windows Runtime.
--ns_prefix
Prefija los espacios de nombres con el espacio de nombres ABI.

Opciones de script de registro:

-r
Genera un script de registro. El nombre de archivo de salida predeterminado es infile_r.rgs. Si el nombre del archivo de salida termina en .res, se genera en su lugar un archivo de recursos binario que contiene el script.

Opciones de archivo Dlldata:

--dlldata-only nombre1 [nombre2...]
Regenera el archivo dlldata desde cero utilizando los nombres de proxy especificados. El nombre de archivo de salida predeterminado es dlldata.c.

Opciones de archivo de metadatos:

--winmd
Genera un archivo de metadatos de Windows Runtime. Esto implica el modo --winrt. El nombre de archivo de salida predeterminado es infile.winmd.

Opciones del preprocesador:

-I ruta
Añade un directorio a la ruta de búsqueda de inclusión. Se permiten varios directorios de inclusión.
-D id[=val]
Define la macro preprocesador id con el valor val.
-E
Solo preprocesar.
-N
No preprocesar la entrada.

Opciones de depuración:

-W
Habilita advertencias pedantes.
-d n
Establece el nivel de depuración al entero no negativo n. Si se antepone 0x, se interpretará como un número hexadecimal. Para el significado de los valores, véase la sección DEBUG.

Opciones misceláneas:

-app_config
Ignorado, presente por compatibilidad con midl.
--acf=archivo
Utiliza el archivo de configuración de aplicación especificado.
--local-stubs=archivo
Genera stubs vacíos para métodos call_as/local en una interfaz de objeto y los escribe en archivo.

DEBUG

El nivel de depuración n es una máscara de bits con el siguiente significado:
- 0x01 Indica qué recurso se está analizando (modo detallado)
- 0x02 Muestra estructuras internas
- 0x04 Crea un seguimiento del analizador (yydebug=1)
- 0x08 Mensajes del preprocesador
- 0x10 Mensajes lex del preprocesador
- 0x20 Seguimiento yacc del preprocesador

BUGS

Los errores pueden ser reportados en el rastreador de errores de Wine.
