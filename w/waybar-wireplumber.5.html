NOMBRE

waybar - módulo WirePlumber

DESCRIPCIÓN

El módulo wireplumber muestra el volumen actual reportado por WirePlumber.

CONFIGURACIÓN

format:
tipo: cadena
predeterminado: {volume}%
El formato, cómo se debe mostrar la información. Este formato se utiliza cuando no se especifican otros formatos.

format-muted:
tipo: cadena
Este formato se utiliza cuando el sonido está silenciado.

node-type:
tipo: cadena
predeterminado: Audio/Sink
El tipo de nodo de WirePlumber al que adjuntarse. Use Audio/Source para gestionar micrófonos, etc.

tooltip:
tipo: booleano
predeterminado: verdadero
Opción para deshabilitar la información emergente al pasar el cursor por encima.

tooltip-format:
tipo: cadena
predeterminado: {node_name}
El formato de la información mostrada en la información emergente.

rotate:
tipo: entero
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

states:
tipo: objeto
Una serie de estados de volumen que se activan a ciertos niveles de volumen. Ver waybar-states(5).

max-length:
tipo: entero
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
tipo: entero
La longitud mínima en caracteres que el módulo debe aceptar.

align:
tipo: flotante
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: cadena
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir la posición.

scroll-step:
tipo: flotante
predeterminado: 1.0
La velocidad a la que se cambia el volumen al desplazarse.

on-click:
tipo: cadena
Comando a ejecutar al hacer clic en el módulo.

on-click-middle:
tipo: cadena
Comando a ejecutar al hacer clic con la rueda del ratón en el módulo.

on-click-right:
tipo: cadena
Comando a ejecutar al hacer clic derecho en el módulo.

on-update:
tipo: cadena
Comando a ejecutar cuando el módulo se actualiza.

on-scroll-up:
tipo: cadena
Comando a ejecutar al desplazarse hacia arriba en el módulo. Esto reemplaza el comportamiento predeterminado de control de volumen.

on-scroll-down:
tipo: cadena
Comando a ejecutar al desplazarse hacia abajo en el módulo. Esto reemplaza el comportamiento predeterminado de control de volumen.

max-volume:
tipo: flotante
predeterminado: 100
El volumen máximo que se puede establecer, en porcentaje.

menu:
tipo: cadena
Acción que abre el menú.

menu-file:
tipo: cadena
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: matriz
Las acciones correspondientes a los botones del menú.

REEMPLAZOS DE FORMATO

{volume}: Volumen en porcentaje.

{node_name}: El apodo del nodo tal como lo informa WirePlumber (propiedad node.nick)

EJEMPLOS

Básico:

"wireplumber": {
	"format": "{volume}%",
	"format-muted": "",
	"on-click": "helvum"
}

Widgets separados para Sink y Source

"wireplumber#sink": {
    "format": "{volume}% {icon}",
    "format-muted": "",
    "format-icons": ["", "", ""],
    "on-click": "helvum",
    "on-click-right": "wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle",
    "scroll-step": 5
},
"wireplumber#source": {
    "node-type": "Audio/Source",
    "format": "{volume}% ",
    "format-muted": "",
    "on-click-right": "wpctl set-mute @DEFAULT_AUDIO_SOURCE@ toggle",
    "scroll-step": 5
}
