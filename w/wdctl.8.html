WDCTL(8) Administración del Sistema WDCTL(8)

NOMBRE

wdctl - mostrar estado del watchdog de hardware

SINOPSIS

wdctl [opciones] [dispositivo...]

DESCRIPCIÓN

Muestra el estado del watchdog de hardware. El dispositivo predeterminado es /dev/watchdog. Si se especifican varios dispositivos, la salida se separa por una línea en blanco.

Si el dispositivo ya está en uso o el usuario no tiene permisos para leer del dispositivo, entonces wdctl lee los datos de sysfs. En este caso, la información sobre las características admitidas (flags) puede faltar.

Tenga en cuenta que el número de características de watchdog admitidas depende del hardware.

OPCIONES

-f, --flags lista

Imprime solo los flags especificados.

-F, --noflags

No imprime información sobre los flags.

-I, --noident

No imprime información de identidad del watchdog.

-n, --noheadings

No imprime una línea de encabezado para la tabla de flags.

-o, --output lista

Define las columnas de salida a utilizar en la tabla de flags del watchdog. Si no se especifica ninguna disposición de salida, se utiliza un conjunto predeterminado. Utilice --help para obtener una lista de todas las columnas admitidas.

-O, --oneline

Imprime toda la información deseada en una sola línea en formato de salida clave="valor".

-p, --setpretimeout segundos

Establece el pre-timeout del watchdog en segundos. Un pre-timeout del watchdog es una notificación generada por el watchdog antes de que pueda ocurrir un reinicio del watchdog en caso de que el watchdog no haya sido atendido. Esta notificación es manejada por el kernel y puede configurarse para tomar una acción usando sysfs o mediante --setpregovernor.

-g, --setpregovernor gobernador

Establece el nombre del gobernador del pre-timeout. Para gobernadores disponibles, consulte la salida predeterminada de wdctl.

-r, --raw

Utiliza el formato de salida en bruto.

-s, --settimeout segundos

Establece el timeout del watchdog en segundos.

-T, --notimeouts

No imprime los timeouts del watchdog.

-x, --flags-only

Igual que -I -T.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.
