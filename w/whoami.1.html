WHOAMI(1) Comandos de usuario WHOAMI(1)

NOMBRE

whoami - imprime el nombre de usuario efectivo

SINOPSIS

whoami [OPCIÓN]...

DESCRIPCIÓN

Imprime el nombre de usuario asociado con el ID de usuario efectivo actual. Igual que id -un.

--help
muestra esta ayuda y sale
--version
muestra la información de la versión y sale
