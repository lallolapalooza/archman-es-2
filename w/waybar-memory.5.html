waybar-memory(5) Manual de formatos de archivo waybar-memory(5)

NOMBRE

waybar - módulo de memoria

DESCRIPCIÓN

El módulo memory muestra la utilización actual de la memoria.

CONFIGURACIÓN

Abordado por memory

interval:
tipo: entero
predeterminado: 30
El intervalo en el que se consulta la información.

format:
tipo: cadena
predeterminado: {percentage}%
El formato, cómo se debe mostrar la información.

format-icons:
tipo: array/objeto
Basado en el porcentaje actual, se selecciona el icono correspondiente.
El orden es de bajo a alto. O por el estado si es un objeto.

rotate:
tipo: entero
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

states:
tipo: objeto
Una serie de estados de utilización de memoria que se activan en ciertos umbrales de porcentaje. Ver waybar-states(5).

max-length:
tipo: entero
La longitud máxima en caracteres que debe mostrar el módulo.

min-length:
tipo: entero
La longitud mínima en caracteres que debe aceptar el módulo.

align:
tipo: flotante
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: cadena
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir el posicionamiento.

on-click:
tipo: cadena
Comando a ejecutar al hacer clic en el módulo.

on-click-middle:
tipo: cadena
Comando a ejecutar al hacer clic con la rueda del ratón en el módulo.

on-click-right:
tipo: cadena
Comando a ejecutar al hacer clic derecho en el módulo.

on-update:
tipo: cadena
Comando a ejecutar cuando se actualiza el módulo.

on-scroll-up:
tipo: cadena
Comando a ejecutar al desplazarse hacia arriba en el módulo.

on-scroll-down:
tipo: cadena
Comando a ejecutar al desplazarse hacia abajo en el módulo.

smooth-scrolling-threshold:
tipo: doble
Umbral a utilizar al desplazarse.

tooltip:
tipo: booleano
predeterminado: verdadero
Opción para deshabilitar la información sobre herramientas al pasar el cursor por encima.

menu:
tipo: cadena
Acción que muestra el menú.

menu-file:
tipo: cadena
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: booleano
predeterminado: falso
Permite que este módulo consuma dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

{percentage}: Porcentaje de memoria en uso.

{swapPercentage}: Porcentaje de swap en uso.

{total}: Cantidad total de memoria disponible en GiB.

{swapTotal}: Cantidad total de swap disponible en GiB.

{used}: Cantidad de memoria utilizada en GiB.

{swapUsed}: Cantidad de swap utilizada en GiB.

{avail}: Cantidad de memoria disponible en GiB.

{swapAvail}: Cantidad de swap disponible en GiB.

{swapState}: Señala si el swap está activado o no

EJEMPLOS

"memory": {
	"interval": 30,
	"format": "{}% ",
	"max-length": 10
}

VALORES DE MEMORIA FORMATEADOS

"memory": {
	"interval": 30,
	"format": "{used:0.1f}G/{total:0.1f}G "
}
