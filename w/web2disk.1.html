NOMBRE

web2disk - web2disk

Cada vez que pases argumentos a web2disk que contengan espacios, encierra los argumentos entre comillas. Por ejemplo: "/alguna ruta/con espacios"

[OPCIONES]

--base-dir, -d
Carpeta base en la que se guardará la URL. Por defecto es .
--delay
Intervalo mínimo en segundos entre capturas consecutivas. Por defecto es 0 s
--dont-download-stylesheets
No descargar las hojas de estilo CSS.
--encoding
La codificación de caracteres para los sitios web que intentas descargar. Por defecto se intenta adivinar la codificación.
--filter-regexp
Se ignorará cualquier enlace que coincida con esta expresión regular. Esta opción se puede especificar varias veces, en cuyo caso, mientras cualquier expresión regular coincida con un enlace, se ignorará. Por defecto, no se ignora ningún enlace. Si se especifican tanto la expresión regular de filtro como la de coincidencia, la expresión regular de filtro se aplica primero.
--help, -h
mostrar este mensaje de ayuda y salir
--match-regexp
Solo se seguirán los enlaces que coincidan con esta expresión regular. Esta opción se puede especificar varias veces, en cuyo caso, mientras un enlace coincida con cualquiera de las expresiones regulares, se seguirá. Por defecto, se siguen todos los enlaces.
--max-files, -n
El número máximo de archivos a descargar. Esto solo se aplica a los archivos de las etiquetas <a href>. Por defecto es 9223372036854775807
--max-recursions, -r
Número máximo de niveles a recursar, es decir, profundidad de los enlaces a seguir. Por defecto 1
--timeout, -t
Tiempo de espera en segundos para recibir una respuesta del servidor. Por defecto: 10.0 s
--verbose
Mostrar información de salida detallada. Útil para depuración.
--version
mostrar el número de versión del programa y salir
