NOMBRE

waybar - módulo de control deslizante de retroiluminación

DESCRIPCIÓN

El módulo control deslizante de retroiluminación muestra y controla el brillo actual del dispositivo predeterminado o preferido.

El brillo se puede controlar arrastrando el control deslizante a través de la barra o haciendo clic en una posición específica.

CONFIGURACIÓN

min:
tipo: int
valor por defecto: 0
El valor mínimo de volumen que el control deslizante debe mostrar y establecer.

max:
tipo: int
valor por defecto: 100
El valor máximo de volumen que el control deslizante debe mostrar y establecer.

orientation:
tipo: string
valor por defecto: horizontal
La orientación del control deslizante. Puede ser `horizontal` o `vertical`.

device:
tipo: string
El nombre del dispositivo preferido a controlar. Si se deja vacío, se elegirá un dispositivo automáticamente.

expand:
tipo: bool
valor por defecto: false
Permite que este módulo consuma dinámicamente todo el espacio sobrante.

EJEMPLOS

"modules-right": [
    "backlight/slider",
],
"backlight/slider": {
    "min": 0,
    "max": 100,
    "orientation": "horizontal",
    "device": "intel_backlight"
}

ESTILO

El control deslizante es un componente con múltiples nodos CSS, de los cuales se exponen los siguientes:

#backlight-slider:
Controla el estilo de la caja alrededor del control deslizante y la barra.

#backlight-slider slider:
Controla el estilo del control deslizante.

#backlight-slider trough:
Controla el estilo de la parte de la barra que no se ha rellenado.

#backlight-slider highlight:
Controla el estilo de la parte de la barra que se ha rellenado.

EJEMPLO DE ESTILO

#backlight-slider slider {
    min-height: 0px;
    min-width: 0px;
    opacity: 0;
    background-image: none;
    border: none;
    box-shadow: none;
}
#backlight-slider trough {
    min-height: 80px;
    min-width: 10px;
    border-radius: 5px;
    background-color: black;
}
#backlight-slider highlight {
    min-width: 10px;
    border-radius: 5px;
    background-color: red;
}
