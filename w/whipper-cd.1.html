WHIPPER-CD(1) Manual de Comandos Generales WHIPPER-CD(1)

NOMBRE

whipper-cd - Mostrar y ripear CD-DA y metadatos

SINOPSIS

whipper cd -d <DISPOSITIVO> [subcomando]
whipper cd -h

SUBCOMANDOS

info  Recuperar información sobre el CD insertado actualmente
rip   Ripear el CD
Para más detalles sobre estos subcomandos, consulta sus páginas man correspondientes.

OPCIONES

-h | --help
Mostrar este mensaje de ayuda y salir

-d <DISPOSITIVO> | --device <DISPOSITIVO>
Ruta al dispositivo CD-DA

VER TAMBIÉN

whipper(1), whipper-cd-info(1), whipper-cd-rip(1)
