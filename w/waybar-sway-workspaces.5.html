NOMBRE

waybar - módulo de espacios de trabajo de sway

DESCRIPCIÓN

El módulo workspaces muestra los espacios de trabajo de Sway actualmente en uso.

CONFIGURACIÓN

Abordado por sway/workspaces

all-outputs:
tipo: booleano
predeterminado: falso
Si se establece en falso, los espacios de trabajo solo se mostrarán en la salida en la que se encuentren. Si se establece en verdadero, todos los espacios de trabajo se mostrarán en cada salida.

format:
tipo: cadena
predeterminado: {value}
El formato, cómo debe mostrarse la información.

format-icons:
tipo: array
Basado en el nombre y estado del espacio de trabajo, se selecciona el icono correspondiente. Consulte icons.

disable-scroll:
tipo: booleano
predeterminado: falso
Si se establece en falso, puede desplazarse para cambiar entre espacios de trabajo. Si se establece en verdadero, este comportamiento se deshabilita.

reverse-scroll:
tipo: booleano
predeterminado: falso
Si se establece en falso, desplazarse hacia arriba cambiará al espacio de trabajo anterior y desplazarse hacia abajo cambiará al siguiente espacio de trabajo. Si se establece en verdadero, el comportamiento se invertirá.

disable-click:
tipo: booleano
predeterminado: falso
Si se establece en falso, puede hacer clic para cambiar de espacio de trabajo. Si se establece en verdadero, este comportamiento se deshabilita.

smooth-scrolling-threshold:
tipo: doble
Umbral a utilizar al desplazarse.

disable-scroll-wraparound:
tipo: booleano
predeterminado: falso
Si se establece en falso, al desplazarse por el indicador del espacio de trabajo se volverá al primer espacio de trabajo al llegar al final, y viceversa. Si se establece en verdadero, este comportamiento se deshabilita.

enable-bar-scroll:
tipo: booleano
predeterminado: falso
Si se establece en falso, no puede desplazarse para recorrer los espacios de trabajo desde toda la barra. Si se establece en verdadero, este comportamiento está habilitado.

disable-markup:
tipo: booleano
predeterminado: falso
Si se establece en verdadero, la etiqueta del botón escapará del marcado pango.

current-only:
tipo: booleano
predeterminado: falso
Si se establece en verdadero. Solo se mostrarán los espacios de trabajo enfocados.

persistent-workspaces:
tipo: json (ver abajo)
predeterminado: vacío
Enumera los espacios de trabajo que siempre deben mostrarse, incluso cuando no existen

on-update:
tipo: cadena
Comando a ejecutar cuando el módulo se actualiza.

disable-auto-back-and-forth:
tipo: booleano
Si se deshabilita workspace_auto_back_and_forth al hacer clic en los espacios de trabajo. Si esto se establece en verdadero, hacer clic en un espacio de trabajo en el que ya te encuentras no hará nada, incluso si workspace_auto_back_and_forth está habilitado en la configuración de Sway.

alphabetical_sort:
tipo: booleano
Si se ordenan los espacios de trabajo alfabéticamente. Tenga en cuenta que esto puede hacer que "swaymsg workspace prev/next" se mueva a espacios de trabajo inconsistentes con el orden que se muestra en Waybar.

warp-on-scroll:
tipo: booleano
predeterminado: verdadero
Si se establece en falso, puede desplazarse para cambiar entre espacios de trabajo sin que se active el centrado del ratón. Si se establece en verdadero, este comportamiento se deshabilita.

window-rewrite:
tipo: objeto
Reglas Regex para mapear la clase de ventana a un icono o método preferido de representación para la ventana de un espacio de trabajo.

Las claves son las reglas, mientras que los valores son los métodos de representación. Las reglas pueden especificar `class<...>`, `title<...>`, o ambos para ajustar la coincidencia. Puede asignar un valor vacío a una regla para que se ignore en la generación de cualquier representación en los espacios de trabajo. Para las ventanas de Wayland, `class` se compara con `app_id`, y para las ventanas de X11 con la propiedad `class`.

window-rewrite-default:

tipo: cadena
predeterminado: "?"
El método de representación predeterminado para la ventana de un espacio de trabajo. Se utilizará para las ventanas cuyas clases no coincidan con ninguna de las reglas en window-rewrite.

format-window-separator:
tipo: cadena
predeterminado: " "
El separador que se utilizará entre las ventanas de un espacio de trabajo.

expand:
tipo: booleano
predeterminado: falso
Permite que este módulo consuma todo el espacio sobrante de forma dinámica.

REEMPLAZOS DE FORMATO

{value}: Nombre del espacio de trabajo, tal como lo define sway.

{name}: Número despojado del valor del espacio de trabajo.

{icon}: Icono, tal como se define en format-icons.

{index}: Índice del espacio de trabajo.

{output}: Salida donde se encuentra el espacio de trabajo.

{windows}: Resultado de window-rewrite

ICONOS

Además de la coincidencia del nombre del espacio de trabajo, se pueden establecer los siguientes format-icons.

  • default: Se mostrará cuando no se encuentren coincidencias de cadena.
  • urgent: Se mostrará cuando el espacio de trabajo esté marcado como urgente.
  • focused: Se mostrará cuando el espacio de trabajo esté enfocado.
  • persistent: Se mostrará cuando el espacio de trabajo sea persistente.
  • high-priority-named: Los iconos por nombre se mostrarán siempre para esos espacios de trabajo, independientemente de su estado.

ESPACIOS DE TRABAJO PERSISTENTES

Cada entrada de persistent_workspace nombra un espacio de trabajo que siempre debe mostrarse. Asociado con ese valor hay una lista de salidas que indican dónde debe mostrarse el espacio de trabajo; una lista vacía denota todas las salidas.

"sway/workspaces": {
	"persistent-workspaces": {
		"3": [], // Siempre mostrar un espacio de trabajo con el nombre '3', en todas las salidas si no existe
		"4": ["eDP-1"], // Siempre mostrar un espacio de trabajo con el nombre '4', en la salida 'eDP-1' si no existe
		"5": ["eDP-1", "DP-2"] // Siempre mostrar un espacio de trabajo con el nombre '5', en las salidas 'eDP-1' y 'DP-2' si no existe
	}
}

n.b.: la lista de salidas se puede obtener desde la línea de comandos usando swaymsg -t get_outputs
