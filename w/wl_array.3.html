Descripción detallada

Arreglo dinámico

Un wl_array es un arreglo dinámico que solo puede crecer hasta ser liberado. Está destinado a asignaciones relativamente pequeñas cuyo tamaño es variable o no se conoce de antemano. Si bien la construcción de un wl_array no requiere que todos los elementos sean del mismo tamaño, wl_array_for_each() sí requiere que todos los elementos tengan el mismo tipo y tamaño.

Aumenta el tamaño del arreglo en `size` bytes.

#define wl_array_for_each( pos, array) [related]

Valor:

        for (pos = (array)->data;                                        \
             (array)->size != 0 &&                                       \
             (const char *) pos < ((const char *) (array)->data + (array)->size); \
             (pos)++)

Itera sobre un arreglo.

Esta macro expresa un iterador "for-each" para wl_array. Asigna cada elemento del arreglo a `pos`, que luego puede ser referenciado en un bloque de código posterior. `pos` debe ser un puntero al tipo de elemento del arreglo, y todos los elementos del arreglo deben ser del mismo tipo y tamaño.

Parámetros

pos Cursor al que se asignará cada elemento del arreglo
array Arreglo a iterar
