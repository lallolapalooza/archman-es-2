WHIPPER-CD-INFO(1) Manual de Comandos Generales WHIPPER-CD-INFO(1)

NOMBRE

whipper-cd-info - Recuperar información sobre el CD insertado actualmente

SINOPSIS

whipper cd info [-R <ID_LANZAMIENTO>] [-p] [-c <PAIS>]
whipper cd info -h

OPCIONES

-h | --help
Mostrar este mensaje de ayuda y salir

-R <ID_LANZAMIENTO> | --release-id <ID_LANZAMIENTO>
ID de lanzamiento de MusicBrainz al que coincidir (si hay varios)

-p | --prompt
Preguntar si hay varios lanzamientos que coinciden

-c <PAIS> | --country <PAIS>
Filtrar lanzamientos por país

VER TAMBIÉN

whipper(1), whipper-cd(1), whipper-cd-rip(1)
