NOMBRE

waybar - módulo keyboard-state

DESCRIPCIÓN

El módulo keyboard-state muestra el estado de las teclas Bloq Num, Bloq Mayús y Bloq Despl.

Debes ser miembro del grupo input para usar este módulo.

CONFIGURACIÓN

interval:
Obsoleto, este módulo utiliza el bucle de eventos ahora, el intervalo no tiene efecto.

tipo: entero
predeterminado: 1
El intervalo, en segundos, para consultar el estado del teclado.

format:
tipo: cadena|objeto
predeterminado: {name} {icon}
El formato, cómo se debe mostrar la información. Si es una cadena, el mismo formato se usa para todos los estados del teclado. Si es un objeto, los campos "numlock", "capslock" y "scrolllock" especifican cada uno el formato para el estado correspondiente. Cualquier estado no especificado utiliza el formato predeterminado.

format-icons:
tipo: objeto
predeterminado: {"locked": "locked", "unlocked": "unlocked"}
Según el estado del teclado, se selecciona el icono correspondiente. El mismo conjunto de iconos se usa para Bloq Num, Bloq Mayús y Bloq Despl, pero el icono se selecciona del conjunto de forma independiente para cada uno. Ver icons.

numlock:
tipo: booleano
predeterminado: false
Muestra el estado de Bloq Num.

capslock:
tipo: booleano
predeterminado: false
Muestra el estado de Bloq Mayús.

scrolllock:
tipo: booleano
predeterminado: false
Muestra el estado de Bloq Despl.

device-path:
tipo: cadena
predeterminado: elige el primer dispositivo de entrada válido
Qué dispositivo de entrada libevdev mostrar el estado. Los dispositivos libevdev se pueden encontrar en /dev/input. El dispositivo debe admitir eventos de Bloq Num, Bloq Mayús y Bloq Despl.

binding-keys:
tipo: matriz
predeterminado: [58, 69, 70]
Personaliza la tecla para activar este módulo, el número de la tecla se puede encontrar en /usr/include/linux/input-event-codes.h o ejecutando sudo libinput debug-events --show-keycodes.

expand:
tipo: booleano
predeterminado: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

{name}: Mayús, Num o Despl.

{icon}: Icono, como se define en format-icons.

ICONOS

Se pueden configurar los siguientes format-icons.

  • locked: Se mostrará cuando el estado del teclado esté bloqueado. Predeterminado "locked".
  • unlocked: Se mostrará cuando el estado del teclado no esté bloqueado. Predeterminado "unlocked".

EJEMPLO:

"keyboard-state": {
	"numlock": true,
	"capslock": true,
	"format": "{name} {icon}",
	"format-icons": {
		"locked": "",
		"unlocked": ""
	}
}
