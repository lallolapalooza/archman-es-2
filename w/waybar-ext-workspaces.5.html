waybar-wlr-workspaces(5) Manual de Formatos de Archivo waybar-wlr-workspaces(5)

NOMBRE

waybar - módulo de áreas de trabajo wlr

DESCRIPCIÓN

El módulo workspaces muestra las áreas de trabajo actualmente en uso en el compositor de Wayland.

CONFIGURACIÓN

Abordado por ext/workspaces

format:
tipo: string
predeterminado: {name}
El formato, cómo debe mostrarse la información.

format-icons:
tipo: array
Basado en el nombre y estado del área de trabajo, se selecciona el icono correspondiente. Consulte icons.

sort-by-name:
tipo: bool
predeterminado: true
¿Deben ordenarse las áreas de trabajo por nombre? Los nombres de las áreas de trabajo se ordenarán numéricamente cuando todos los nombres sean números.

sort-by-coordinates:
tipo: bool
predeterminado: false
¿Deben ordenarse las áreas de trabajo por coordenadas?
Tenga en cuenta que si tanto sort-by-name como sort-by-coordinates son verdaderos, se aplicará sort-by-name primero. Si ambos son falsos, se realizará un orden por ID.

sort-by-id:
tipo: bool
predeterminado: false
¿Deben ordenarse las áreas de trabajo por ID? El ID del área de trabajo se ordenará numéricamente cuando todos los ID sean números. Tiene prioridad sobre cualquier otra opción de ordenación.

all-outputs:
tipo: bool
predeterminado: false
Si se establece en falso, el grupo de áreas de trabajo solo se mostrará en la salida asignada. De lo contrario, se mostrarán todos los grupos de áreas de trabajo.

active-only:
tipo: bool
predeterminado: false
Si se establece en verdadero, solo se mostrarán las áreas de trabajo activas o urgentes.

ignore-hidden:
tipo: bool
predeterminado: true
Si se establece en falso, se mostrarán las áreas de trabajo ocultas.

REEMPLAZOS DE FORMATO

{name}: Nombre del área de trabajo asignado por el compositor.

{id}: ID del área de trabajo asignado por el compositor.

{icon}: Icono, como se define en format-icons.

ACCIONES AL HACER CLIC

activate: Cambiar al área de trabajo.

close: Cerrar el área de trabajo.

ICONOS

Además de la coincidencia del nombre del área de trabajo, se pueden establecer los siguientes format-icons.

  • default: Se mostrará cuando no se encuentre ninguna coincidencia de cadena.
  • active: Se mostrará cuando el área de trabajo esté activa.

EJEMPLOS

"ext/workspaces": {
	"format": "{name}: {icon}",
	"on-click": "activate",
	"format-icons": {
		"Workspace 1": "",
		"Workspace 2": "",
		"Workspace 3": "",
		"Workspace 4": "",
		"active": "",
		"default": ""
	},
	"sort-by-id": true
}

Estilo

  • #workspaces
  • #workspaces button
  • #workspaces button.active
  • #workspaces button.urgent
  • #workspaces button.hidden
