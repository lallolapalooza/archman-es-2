waybar-niri-window(5) Manual de formatos de archivo waybar-niri-window(5)

NOMBRE

waybar - módulo de ventana de niri

DESCRIPCIÓN

El módulo window muestra el título de la ventana actualmente enfocada en niri.

CONFIGURACIÓN

Abordado por niri/window

format:
tipo: string
predeterminado: {title}
El formato, cómo debe mostrarse la información. En {} se muestra el título de la ventana actual.

rewrite:
tipo: object
Reglas para reescribir el título de la ventana. Ver reglas de reescritura.

separate-outputs:
tipo: bool
Muestra la ventana activa del monitor al que pertenece la barra, en lugar de la ventana enfocada.

icon:
tipo: bool
predeterminado: false
Opción para ocultar el icono de la aplicación.

icon-size:
tipo: integer
predeterminado: 24
Opción para cambiar el tamaño del icono de la aplicación.

expand:
tipo: bool
predeterminado: false
Habilita este módulo para consumir dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

Consulta la salida de "niri msg windows" para ver ejemplos.

{title}: El título actual de la ventana enfocada.

{app_id}: El ID de aplicación actual de la ventana enfocada.

REGLAS DE REESCRITURA

rewrite es un objeto donde las claves son expresiones regulares y los valores son reglas de reescritura si la expresión coincide. Las reglas pueden contener referencias a las capturas de la expresión.

La expresión regular y el reemplazo siguen las reglas de ECMA-script.

Si ninguna expresión coincide, el título se deja sin cambios.

Las expresiones inválidas (por ejemplo, paréntesis desparejados) se omiten.

EJEMPLOS

"niri/window": {
	"format": "{}",
	"rewrite": {
		"(.*) - Mozilla Firefox": "🌎 $1",
		"(.*) - zsh": "> [$1]"
	}
}

ESTILO

  • #window
  • window#waybar.empty #window Cuando no hay ventanas en el espacio de trabajo

Las siguientes clases se aplican a toda la barra Waybar en lugar de solo al widget de ventana:

  • window#waybar.empty Cuando no hay ventanas en el espacio de trabajo
  • window#waybar.solo Cuando solo hay una ventana en el espacio de trabajo
  • window#waybar.<app-id> Donde app-id es el ID de aplicación de la única ventana en el espacio de trabajo
