wofi-config(3) Manual de funciones de biblioteca wofi-config(3)

NOMBRE

wofi - Funciones de configuración y documentación

DESCRIPCIÓN

Las funciones documentadas aquí se utilizan para manipular mapas que representan entradas de configuración. Se definen en config.h.

FUNCIONES DE CONFIGURACIÓN

Las siguientes funciones se utilizan para trabajar con configuraciones.

void config_put(struct map* map, char* line)
Analiza una sola línea de configuración y inserta el resultado en el mapa

struct map* map - El mapa en el que insertar.

char* line - La línea de configuración a insertar. Debe tener el formato clave=valor.

void config_load(struct map* map, const char* config)
Carga un archivo de configuración en el mapa dado

struct map* map - El mapa en el que cargar la configuración.

const char* config - La ruta a un archivo de configuración. Debe contener líneas con el formato clave=valor.

char* config_get(struct map* config, const char* key, char* def_opt)
Obtiene una entrada de configuración; si la entrada no está establecida, devuelve def_opt.

struct map* config - El mapa del que obtener el valor.

const char* key - La clave a buscar.

char* def_opt - El valor predeterminado que se devolverá si la clave no existe.

int config_get_mnemonic(struct map* config, const char* key, char* def_opt, int num_choices, ...)
Obtiene un valor de enumeración de la configuración. Si el valor no está establecido, devuelve def_opt.

struct map* config - El mapa del que obtener el valor.

const char* key - La clave a buscar.

char* def_opt - El valor predeterminado que se devolverá si la clave no existe.

int num_choices - El número de opciones de enumeración disponibles.

varargs - La lista de opciones de enumeración disponibles.
