WBINFO(1) Comandos de usuario WBINFO(1)

NOMBRE

wbinfo - Consultar información del demonio winbind

SINOPSIS

wbinfo [-a usuario%contraseña] [--all-domains] [--allocate-gid] [--allocate-uid] [-c] [--ccache-save] [--change-user-password] [-D dominio] [--dc-info dominio] [--domain dominio] [--dsgetdcname dominio] [-g] [--getdcname dominio] [--get-auth-user] [-G gid] [--gid-info gid] [--group-info grupo] [--help|-?] [-i usuario] [-I ip] [-K usuario%contraseña] [--krb5ccname cctype] [--lanman] [--logoff] [--logoff-uid uid] [--logoff-user nombreusuario] [--lookup-sids] [-m] [-n nombre] [-N nombre-netbios] [--ntlmv1] [--ntlmv2] [--online-status] [--own-domain] [-p] [-P|--ping-dc] [--pam-logon usuario%contraseña] [-r usuario] [-R|--lookup-rids] [--remove-gid-mapping gid,sid] [--remove-uid-mapping uid,sid] [-s sid] [--separator] [--set-auth-user usuario%contraseña] [--set-gid-mapping gid,sid] [--set-uid-mapping uid,sid] [-S sid] [--sid-aliases sid] [--sid-to-fullname sid] [--sids-to-unix-ids lista_sids] [-t] [-u] [--uid-info uid] [--usage] [--user-domgroups sid] [--user-sidinfo sid] [--user-sids sid] [-U uid] [-V] [--verbose] [-Y sid]

DESCRIPCIÓN

Esta herramienta forma parte de la suite de samba(7).

El programa wbinfo consulta y devuelve información creada y utilizada por el demonio winbindd(8).

El demonio winbindd(8) debe estar configurado y ejecutándose para que el programa wbinfo pueda devolver información.

OPCIONES

-a|--authenticate nombreusuario%contraseña

Intenta autenticar a un usuario a través de winbindd(8). Esto comprueba ambos métodos de autenticación y reporta sus resultados.

Nota
No caiga en la tentación de usar esta funcionalidad para la autenticación en aplicaciones de terceros. Utilice en su lugar ntlm_auth(1).

--allocate-gid

Obtiene un nuevo GID del mapeo de IDs

--allocate-uid

Obtiene un nuevo UID del mapeo de IDs

--all-domains

Lista todos los dominios (confiados y el propio).

-c|--change-secret

Cambia la contraseña de la cuenta de confianza. Puede usarse en conjunción con domain para cambiar las contraseñas de las cuentas de confianza entre dominios.

--change-secret-at controlador-dominio

Cambia la contraseña de la cuenta de confianza en un controlador de dominio específico. Falla si no se puede contactar con el controlador de dominio especificado.

--ccache-save nombreusuario%contraseña

Almacena el usuario y la contraseña para la caché de credenciales.

--change-user-password nombreusuario

Cambia la contraseña de un usuario. Se le pedirá la contraseña antigua y la nueva.

--dc-info dominio

Muestra información sobre el controlador de dominio actual para un dominio.

--domain nombre

Este parámetro establece el dominio en el que se realizarán las operaciones especificadas. Si se usa el nombre de dominio especial '.' para representar el dominio actual al que pertenece winbindd(8). Un '*' como nombre de dominio significa enumerar todos los dominios (NOTA: Esto puede llevar mucho tiempo y consumir mucha memoria).

-D|--domain-info dominio

Muestra la mayor parte de la información que tenemos sobre el dominio especificado.

--dsgetdcname dominio

Encuentra un DC para un dominio.

--gid-info gid

Obtiene información del grupo a partir del GID.

--group-info grupo

Obtiene información del grupo a partir del nombre del grupo.

-g|--domain-groups

Esta opción listará todos los grupos disponibles en el dominio de Windows NT para el que opera el demonio samba(7). Los grupos en todos los dominios confiados pueden ser listados con la opción --domain='*'. Tenga en cuenta que esta operación no asigna IDs de grupo a ningún grupo que no haya sido visto previamente por winbindd(8).

--get-auth-user

Imprime el nombre de usuario y la contraseña utilizados por winbindd(8) durante la configuración de la sesión a un controlador de dominio. El nombre de usuario y la contraseña se pueden establecer usando --set-auth-user. Solo disponible para root.

--getdcname dominio

Obtiene el nombre del DC para el dominio especificado.

-G|--gid-to-sid gid

Intenta convertir un ID de grupo UNIX a un SID de Windows NT. Si el GID especificado no se refiere a uno dentro del rango de GIDs de idmap, la operación fallará.

-?

Imprime un resumen de ayuda breve.

-i|--user-info usuario

Obtiene información del usuario.

-I|--WINS-by-ip ip

La opción -I consulta a winbindd(8) para enviar una solicitud de estado de nodo y obtener el nombre NetBIOS asociado con la dirección IP especificada por el parámetro ip.

-K|--krb5auth nombreusuario%contraseña

Intenta autenticar a un usuario a través de Kerberos.

--krb5ccname KRB5CCNAME

Permite solicitar un tipo específico de caché de credenciales kerberos utilizado para la autenticación.

--lanman

Utiliza criptografía lanman para la autenticación de usuarios.

--logoff

Cierra la sesión de un usuario.

--logoff-uid UID

Define el UID del usuario utilizado durante la solicitud de cierre de sesión.

--logoff-user NOMBREUSUARIO

Define el nombre de usuario utilizado durante la solicitud de cierre de sesión.

--lookup-sids SID1,SID2...

Busca SIDs. Los SIDs deben especificarse como cadenas ASCII en el formato tradicional de Microsoft. Por ejemplo, S-1-5-21-1455342024-3071081365-2475485837-500.

-m|--trusted-domains

Produce una lista de dominios confiados por el servidor Windows NT con el que contacta winbindd(8) al resolver nombres. Esta lista no incluye el dominio de Windows NT del que el servidor es Controlador de Dominio Primario.

-n|--name-to-sid nombre

La opción -n consulta a winbindd(8) para obtener el SID asociado con el nombre especificado. Los nombres de dominio se pueden especificar antes del nombre de usuario usando el carácter separador de winbind. Por ejemplo, CWDOM1/Administrador se refiere al usuario Administrador en el dominio CWDOM1. Si no se especifica ningún dominio, el dominio utilizado es el especificado en el parámetro workgroup de smb.conf(5).

-N|--WINS-by-name nombre

La opción -N consulta a winbindd(8) para consultar el servidor WINS para obtener la dirección IP asociada con el nombre NetBIOS especificado por el parámetro nombre.

--ntlmv1

Utiliza criptografía NTLMv1 para la autenticación de usuarios.

--ntlmv2

Utiliza criptografía NTLMv2 para la autenticación de usuarios. NTLMv2 es el método por defecto, esta opción solo se mantiene por compatibilidad.

--online-status dominio

Muestra si winbind mantiene actualmente una conexión activa o no. Un argumento de dominio opcional limita la salida al estado en línea de un dominio determinado.

--own-domain

Lista el dominio propio.

--pam-logon nombreusuario%contraseña

Intenta autenticar a un usuario de la misma manera que lo haría pam_winbind.

-p|--ping

Comprueba si winbindd(8) sigue activo. Imprime 'succeeded' o 'failed'.

-P|--ping-dc

Emite un comando sin efecto a nuestro DC. Esto comprueba si nuestra conexión de canal seguro a nuestro controlador de dominio sigue activa. Tiene mucho menos impacto que wbinfo -t.

-r|--user-groups nombreusuario

Intenta obtener la lista de IDs de grupo UNIX a los que pertenece el usuario. Esto solo funciona para usuarios definidos en un Controlador de Dominio.

Hay dos escenarios:

1. Usuario autenticado: Cuando el usuario
hasido autenticado, el token de acceso para el usuario se almacena en caché. Las membresías de grupo correctas se devuelven entonces del token de usuario en caché (que puede estar desactualizado).
2.Usuario *NO* autenticado: La información se consulta del controlador de dominio utilizando las credenciales de la cuenta de la máquina que tienen permisos limitados. El resultado es normalmente incompleto y también puede ser incorrecto.

-R|--lookup-rids rid1, rid2, rid3...

Convierte RIDs a nombres. Utiliza una lista de rids separada por comas.

--remove-gid-mapping GID,SID

Elimina un mapeo GID a SID existente de la base de datos.

--remove-uid-mapping UID,SID

Elimina un mapeo UID a SID existente de la base de datos.

-s|--sid-to-name sid

Utiliza -s para resolver un SID a un nombre. Este es el inverso de la opción -n anterior. Los SIDs deben especificarse como cadenas ASCII en el formato tradicional de Microsoft. Por ejemplo, S-1-5-21-1455342024-3071081365-2475485837-500.

--separator

Obtiene el separador winbind activo.

--set-auth-user nombredeusuario%contraseña

Almacena el nombre de usuario y la contraseña utilizados por winbindd(8) durante la configuración de la sesión a un controlador de dominio. Esto permite que winbindd opere en un dominio de Windows 2000 con Restrict Anonymous activado (también conocido como Permisos compatibles solo con servidores Windows 2000).

--set-gid-mapping GID,SID

Crea un mapeo GID a SID en la base de datos.

--set-uid-mapping UID,SID

Crea un mapeo UID a SID en la base de datos.

-S|--sid-to-uid sid

Convierte un SID a un ID de usuario UNIX. Si el SID no corresponde a un usuario UNIX mapeado por winbindd(8), la operación fallará.

--sid-aliases sid

Obtiene alias de SID para un SID dado.

--sid-to-fullname sid

Convierte un SID a un nombre de usuario completo (DOMINIO\nombredeusuario).

--sids-to-unix-ids sid1,sid2,sid3...

Resuelve SIDs a IDs de Unix. Los SIDs deben especificarse como cadenas ASCII en el formato tradicional de Microsoft. Por ejemplo, S-1-5-21-1455342024-3071081365-2475485837-500.

-t|--check-secret

Verifica que la cuenta de confianza de estación de trabajo creada cuando el servidor Samba se agrega al dominio de Windows NT esté funcionando. Puede usarse junto con domain para verificar cuentas de confianza interdominio.

-u|--domain-users

Esta opción listará todos los usuarios disponibles en el dominio de Windows NT para el cual el demonio winbindd(8) está operando. Los usuarios en todos los dominios de confianza se pueden listar con la opción --domain='*'. Tenga en cuenta que esta operación no asigna IDs de usuario a ningún usuario que no haya sido visto previamente por winbindd(8).

--uid-info uid

Obtiene información de usuario para el usuario conectado al ID de usuario UID.

--usage

Imprime un resumen breve de ayuda.

--user-domgroups sid

Obtiene los grupos de dominio del usuario.

--user-sidinfo sid

Obtiene información de usuario por sid.

--user-sids sid

Obtiene los SIDs de grupo de usuario para el usuario.

-U|--uid-to-sid uid

Intenta convertir un ID de usuario UNIX a un SID de Windows NT. Si el UID especificado no se refiere a uno dentro del rango de idmap, la operación fallará.

--verbose

Imprime información adicional sobre los resultados de la consulta.

-Y|--sid-to-gid sid

Convierte un SID a un ID de grupo UNIX. Si el SID no corresponde a un grupo UNIX mapeado por winbindd(8), la operación fallará.

-V|--version

Imprime el número de versión del programa.

-?|--help

Imprime un resumen de las opciones de línea de comandos.

--usage

Muestra un breve mensaje de uso.

ESTADO DE SALIDA

El programa wbinfo devuelve 0 si la operación tuvo éxito, o 1 si la operación falló. Si el demonio winbindd(8) no está funcionando, wbinfo siempre devolverá un fallo.
