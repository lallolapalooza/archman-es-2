winfo(n) Comandos integrados de Tk winfo(n)

NOMBRE

winfo - Devuelve información relacionada con las ventanas

SINOPSIS

winfo opción ?arg arg ...?

DESCRIPCIÓN

El comando winfo se utiliza para recuperar información sobre las ventanas gestionadas por Tk. Puede tomar cualquiera de una serie de formas diferentes, dependiendo del argumento opción. Las formas legales son:

winfo atom ?-displayof ventana? nombre
Devuelve una cadena decimal que da el identificador entero para el átomo cuyo nombre es nombre. Si no existe ningún átomo con el nombre nombre entonces se crea uno nuevo. Si se proporciona la opción -displayof, el átomo se busca en la pantalla de ventana; de lo contrario, se busca en la pantalla de la ventana principal de la aplicación.
winfo atomname ?-displayof ventana? id
Devuelve el nombre textual del átomo cuyo identificador entero es id. Si se proporciona la opción -displayof, el identificador se busca en la pantalla de ventana; de lo contrario, se busca en la pantalla de la ventana principal de la aplicación. Este comando es el inverso del comando winfo atom. Genera un error si no existe dicho átomo.
winfo cells ventana
Devuelve una cadena decimal que da el número de celdas en el mapa de colores para ventana.
winfo children ventana
Devuelve una lista que contiene los nombres de ruta de todos los hijos de ventana. Las ventanas de nivel superior se devuelven como hijos de sus padres lógicos. La lista está en orden de apilamiento, con la ventana más baja primero, excepto para las ventanas de nivel superior que no se devuelven en orden de apilamiento. Utilice el comando wm stackorder para consultar el orden de apilamiento de las ventanas de nivel superior.
winfo class ventana
Devuelve el nombre de la clase para ventana.
winfo colormapfull ventana
Devuelve 1 si se sabe que el mapa de colores para ventana está lleno, 0 en caso contrario. Se sabe que el mapa de colores de una ventana está "lleno" si el último intento de asignar un nuevo color en esa ventana falló y esta aplicación no ha liberado ningún color en el mapa de colores desde la asignación fallida.
winfo containing ?-displayof ventana? rootX rootY
Devuelve el nombre de ruta de la ventana que contiene el punto dado por rootX y rootY. RootX y rootY se especifican en unidades de pantalla (es decir, cualquier forma aceptable para Tk_GetPixels) en el sistema de coordenadas de la ventana raíz (si se está utilizando un gestor de ventanas de raíz virtual, se utiliza el sistema de coordenadas de la ventana de raíz virtual). Si se proporciona la opción -displayof, las coordenadas se refieren a la pantalla que contiene ventana; de lo contrario, se refieren a la pantalla de la ventana principal de la aplicación. Si ninguna ventana en esta aplicación contiene el punto, se devuelve una cadena vacía. También se devuelve una cadena vacía si el punto se encuentra en la barra de título o borde de su ventana de nivel superior más alta dentro de esta aplicación. (Tenga en cuenta que con algunos gestores de ventanas, los bordes pueden ser invisibles). Al seleccionar la ventana contenedora, los hijos tienen mayor prioridad que los padres y, entre hermanos, se elige el más alto en el orden de apilamiento.
winfo depth ventana
Devuelve una cadena decimal que da la profundidad de ventana (número de bits por píxel).
winfo exists ventana
Devuelve 1 si existe una ventana llamada ventana, 0 si no existe tal ventana.
winfo fpixels ventana número
Devuelve un valor de punto flotante que da el número de píxeles en ventana correspondiente a la distancia dada por número. Número puede especificarse en cualquiera de las formas aceptables para Tk_GetScreenMM, como "2.0c" o "1i". El valor devuelto puede ser fraccionario; para un valor entero, use winfo pixels.
winfo geometry ventana
Devuelve la geometría para ventana, en el formato anchoxalto+x+y. Todas las dimensiones están en píxeles.
winfo height ventana
Devuelve una cadena decimal que da la altura de ventana en píxeles. Cuando se crea una ventana por primera vez, su altura será de 1 píxel; la altura será cambiada eventualmente por un gestor de geometría para satisfacer las necesidades de la ventana. Si necesita la altura real inmediatamente después de crear un widget, invoque update para forzar al gestor de geometría a organizarlo, o use winfo reqheight para obtener la altura solicitada de la ventana en lugar de su altura real.
winfo id ventana
Devuelve una cadena hexadecimal que da un identificador de bajo nivel específico de la plataforma para ventana. En plataformas Unix, este es el identificador de ventana de X. En Windows, este es el HWND de Windows. En Macintosh, el valor no tiene significado fuera de Tk.
winfo interps ?-displayof ventana?
Devuelve una lista cuyos miembros son los nombres de todos los intérpretes de Tcl (por ejemplo, todas las aplicaciones basadas en Tk) actualmente registrados para una pantalla determinada. Si se proporciona la opción -displayof, el valor devuelto se refiere a la pantalla de ventana; de lo contrario, se refiere a la pantalla de la ventana principal de la aplicación.
winfo ismapped ventana
Devuelve 1 si ventana está actualmente mapeada, 0 en caso contrario.
winfo manager ventana
Devuelve el nombre del gestor de geometría actualmente responsable de ventana, o una cadena vacía si ventana no es gestionada por ningún gestor de geometría. El nombre suele ser el nombre del comando Tcl para el gestor de geometría, como pack o place. Si el gestor de geometría es un widget, como los lienzos o textos, el nombre es el comando de clase del widget, como canvas.
winfo name ventana
Devuelve el nombre de ventana (es decir, su nombre dentro de su padre, en contraposición a su nombre de ruta completo). El comando winfo name . devolverá el nombre de la aplicación.
winfo parent ventana
Devuelve el nombre de ruta del padre de ventana, o una cadena vacía si ventana es la ventana principal de la aplicación.
winfo pathname ?-displayof ventana? id
Devuelve el nombre de ruta de la ventana cuyo identificador X es id. Id debe ser un entero decimal, hexadecimal u octal y debe corresponder a una ventana en la aplicación que lo invoca. Si se proporciona la opción -displayof, el identificador se busca en la pantalla de ventana; de lo contrario, se busca en la pantalla de la ventana principal de la aplicación.
winfo pixels ventana número
Devuelve el número de píxeles en ventana correspondiente a la distancia dada por número. Número puede especificarse en cualquiera de las formas aceptables para Tk_GetPixels, como "2.0c" o "1i". El resultado se redondea al valor entero más cercano; para un resultado fraccionario, use winfo fpixels.
winfo pointerx ventana
Si el puntero del ratón está en la misma pantalla que ventana, devuelve la coordenada x del puntero, medida en píxeles en la ventana raíz de la pantalla. Si se utiliza una ventana raíz virtual en la pantalla, la posición se mide en la raíz virtual. Si el puntero del ratón no está en la misma pantalla que ventana, se devuelve -1.
winfo pointerxy ventana

Si se está utilizando una ventana raíz virtual en la pantalla, la posición se calcula en la ventana raíz virtual. winfo pointery window
Si el puntero del ratón está en la misma pantalla que window, devuelve la coordenada y del puntero, medida en píxeles en la ventana raíz de la pantalla. Si se está utilizando una ventana raíz virtual en la pantalla, la posición se calcula en la ventana raíz virtual. Si el puntero del ratón no está en la misma pantalla que window, se devuelve -1.
winfo reqheight window
Devuelve una cadena decimal que indica la altura solicitada de window, en píxeles. Este es el valor utilizado por el gestor de geometría de window para calcular su geometría.
winfo reqwidth window
Devuelve una cadena decimal que indica el ancho solicitado de window, en píxeles. Este es el valor utilizado por el gestor de geometría de window para calcular su geometría.
winfo rgb window color
Devuelve una lista que contiene tres valores decimales en el rango de 0 a 65535, que son las intensidades de rojo, verde y azul que corresponden a color en la ventana dada por window. Color puede especificarse en cualquiera de los formatos aceptables para una opción de color.
winfo rootx window
Devuelve una cadena decimal que indica la coordenada x, en la ventana raíz de la pantalla, de la esquina superior izquierda del borde de window (o window si no tiene borde).
winfo rooty window
Devuelve una cadena decimal que indica la coordenada y, en la ventana raíz de la pantalla, de la esquina superior izquierda del borde de window (o window si no tiene borde).
winfo screen window
Devuelve el nombre de la pantalla asociada con window, en el formato nombrePantalla.índicePantalla.
winfo screencells window
Devuelve una cadena decimal que indica el número de celdas en el mapa de colores predeterminado para la pantalla de window.
winfo screendepth window
Devuelve una cadena decimal que indica la profundidad de la ventana raíz de la pantalla de window (número de bits por píxel).
winfo screenheight window
Devuelve una cadena decimal que indica la altura de la pantalla de window, en píxeles.
winfo screenmmheight window
Devuelve una cadena decimal que indica la altura de la pantalla de window, en milímetros.
winfo screenmmwidth window
Devuelve una cadena decimal que indica el ancho de la pantalla de window, en milímetros.
winfo screenvisual window
Devuelve una de las siguientes cadenas para indicar la clase visual predeterminada para la pantalla de window: directcolor, grayscale, pseudocolor, staticcolor, staticgray, o truecolor.
winfo screenwidth window
Devuelve una cadena decimal que indica el ancho de la pantalla de window, en píxeles.
winfo server window
Devuelve una cadena que contiene información sobre el servidor de la pantalla de window. El formato exacto de esta cadena puede variar según la plataforma. Para los servidores X, la cadena tiene el formato “XmayorRmenor proveedor versionProveedor”, donde mayor y menor son los números de versión y revisión proporcionados por el servidor (por ejemplo, X11R5), proveedor es el nombre del proveedor del servidor y versionProveedor es un número de versión entero proporcionado por el servidor.
winfo toplevel window
Devuelve el nombre de ruta de la ventana de nivel superior que contiene a window. En Tk estándar, esta siempre será un widget toplevel, pero las extensiones pueden crear otros tipos de ventanas de nivel superior.
winfo viewable window
Devuelve 1 si window y todos sus ancestros hasta la ventana de nivel superior más cercana están mapeados. Devuelve 0 si alguna de estas ventanas no está mapeada.
winfo visual window
Devuelve una de las siguientes cadenas para indicar la clase visual de window: directcolor, grayscale, pseudocolor, staticcolor, staticgray, o truecolor.
winfo visualid window
Devuelve el identificador X del visual para window.
winfo visualsavailable window ?includeids?
Devuelve una lista cuyos elementos describen los visuales disponibles para la pantalla de window. Cada elemento consiste en una clase visual seguida de una profundidad entera. La clase tiene el mismo formato que el devuelto por winfo visual. La profundidad indica el número de bits por píxel en el visual. Además, si se proporciona el argumento includeids, entonces la profundidad va seguida del identificador X del visual.
winfo vrootheight window
Devuelve la altura de la ventana raíz virtual asociada con window si la hay; de lo contrario, devuelve la altura de la pantalla de window.
winfo vrootwidth window
Devuelve el ancho de la ventana raíz virtual asociada con window si la hay; de lo contrario, devuelve el ancho de la pantalla de window.
winfo vrootx window
Devuelve el desplazamiento x de la ventana raíz virtual asociada con window, en relación con la ventana raíz de su pantalla. Normalmente es cero o negativo. Devuelve 0 si no hay una ventana raíz virtual para window.
winfo vrooty window
Devuelve el desplazamiento y de la ventana raíz virtual asociada con window, en relación con la ventana raíz de su pantalla. Normalmente es cero o negativo. Devuelve 0 si no hay una ventana raíz virtual para window.
winfo width window
Devuelve una cadena decimal que indica el ancho de window en píxeles. Cuando se crea una ventana, su ancho será de 1 píxel; el ancho será cambiado eventualmente por un gestor de geometría para satisfacer las necesidades de la ventana. Si necesita el ancho real inmediatamente después de crear un widget, invoque update para forzar al gestor de geometría a organizarlo, o use winfo reqwidth para obtener el ancho solicitado de la ventana en lugar de su ancho real.
winfo x window
Devuelve una cadena decimal que indica la coordenada x, en el padre de window, de la esquina superior izquierda del borde de window (o window si no tiene borde).
winfo y window
Devuelve una cadena decimal que indica la coordenada y, en el padre de window, de la esquina superior izquierda del borde de window (o window si no tiene borde).

EJEMPLO

Imprimir la posición del puntero del ratón y la ventana sobre la que se encuentra actualmente:

lassign [winfo pointerxy .] x y
puts -nonewline "Puntero del ratón en ($x,$y) que está "
set win [winfo containing $x $y]
if {$win eq ""} {
    puts "sobre ninguna ventana"
} else {
    puts "sobre $win"
}
