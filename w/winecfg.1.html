NOMBRE

winecfg - Editor de configuración de Wine

SINOPSIS

winecfg [opciones]

DESCRIPCIÓN

winecfg es el editor de configuración de Wine. Permite cambiar varios ajustes, como el orden de carga de DLL (nativo frente a integrado), activar un escritorio virtual, configurar unidades de disco y cambiar el controlador de audio de Wine, entre otros. Muchos de estos ajustes se pueden realizar por aplicación, por ejemplo, prefiriendo riched20.dll nativo para wordpad.exe, pero no para notepad.exe.

Si no se proporciona ninguna opción, se iniciará la versión gráfica de winecfg.

OPCIONES

-v [versión], /v [versión]
Establece la versión global de Windows a versión y sale. Si no se especifica versión, muestra la versión global actual de Windows y sale.
-?, /?
Muestra la ayuda, las versiones válidas para versión y sale.

ERRORES

Los errores pueden ser reportados en el rastreador de errores de Wine.

DISPONIBILIDAD

winecfg es parte de la distribución de Wine, que está disponible a través de WineHQ, la sede de desarrollo de Wine.
