NOMBRE

weston-bindings - una lista de atajos de teclado para Weston - el compositor de referencia de Wayland

INTRODUCCIÓN

El shell de escritorio de Weston tiene una serie de atajos de teclado. Se enumeran aquí.

DESCRIPCIÓN

Casi todos los atajos de teclado para Weston incluyen un modificador especificado mod que se determina en el archivo weston.ini(5).
mod + Shift + F

Pone la ventana activa en pantalla completa

mod + K

Cierra la ventana activa

mod + Shift + M

Maximiza la ventana activa

mod + Shift + KEY_LEFT

Coloca la ventana activa a la izquierda.

mod + Shift + KEY_RIGHT

Coloca la ventana activa a la derecha.

mod + Shift + KEY_UP

Coloca la ventana activa arriba.

mod + Shift + KEY_DOWN

Coloca la ventana activa abajo.

mod + Tab

Cambia la ventana activa

Ctrl + Alt + Retroceso

Si es compatible, termina Weston. (Nota: esta combinación a menudo se usa para reiniciar forzosamente Xorg.)

Ctrl + Alt + F

Alterna si Weston está en pantalla completa; solo funciona cuando está anidado bajo un compositor Wayland

Ctrl + Alt + S

Comparte la pantalla de salida, si es posible

Ctrl + Alt + F1/F2/F3/F4/F5/F6/F7/F8

Cambia de terminal virtual, si es posible

Super + S

Realiza una captura de pantalla del escritorio

Super + R

Inicia o detiene la grabación de video del escritorio

ATADOS DE TÁCTIL / RATÓN

También hay una serie de atajos que involucran un ratón:
<Táctil>, <Botón izquierdo>, <Botón derecho>

Activa la ventana en la que se hizo clic

Super + Alt + <Desplazamiento Vertical>

Cambia la opacidad de una ventana

mod + <Botón izquierdo>

Haz clic y arrastra para mover una ventana

mod + Shift + <Botón izquierdo>, mod + <Botón derecho>, mod + <Táctil>

Haz clic y arrastra para redimensionar una ventana

mod + <Botón central>

Rota la ventana (si es compatible)

ATADOS DE DEPURACIÓN

La combinación mod + Shift + Espacio inicia un atajo de depuración. Los atajos de depuración se completan presionando una tecla adicional. Por ejemplo, presionar M puede alternar entre los modos de depuración del renderizador GL. La mayoría de los efectos de depuración se pueden desactivar repitiendo el comando. Los atajos de depuración a menudo están vinculados a backends específicos. A continuación se muestran los atajos de depuración disponibles.

- KEY_D :
Suscribirse al grabador de vuelo.
- KEY_C :
Habilitar/Deshabilitar planos de cursor.
- KEY_V :
Habilitar/Deshabilitar planos superpuestos.
- KEY_Q :
Iniciar el grabador VAAPI.
- KEY_M :
Alterna entre los modos de depuración del renderizador gl: ninguno, wireframe, batches, damage, opaque.
- KEY_R :
Habilita la depuración de repintado para Pixman.
