wikicurses.conf(5) Manual de formatos de archivo wikicurses.conf(5)

NOMBRE

wikicurses - interfaz de curses para MediaWiki

SINOPSIS

/etc/wikicurses.conf

~/.config/wikicurses/config

DESCRIPCIÓN

El archivo de configuración de wikicurses se divide en secciones, siendo la sección "general" la que contiene la configuración general. Todas las demás secciones especifican wikis individuales.

EJEMPLO

[general]
default = Wikipedia
mouse = False
hide_references = False
[keymap]
q = quit
c = contents
o = open
h = back
l = forward
left = back
right = forward
[Wikipedia]
url = http://en.wikipedia.org/w/api.php
username = johndoe
password = 1234
[ArchWiki]
url = https://wiki.archlinux.org/api.php

OPCIONES

general

default

El nombre de la wiki a utilizar por defecto

mouse

Soporte para entrada del ratón. Con esto habilitado, tendrás que mantener presionada la tecla Shift para seleccionar texto.

hide_references

Ocultar la sección de Referencias al final de la página y eliminar las citas del texto.

keymap

Esta sección configura las asignaciones de teclado de wikicurses, en el formato "tecla=comando". El comando puede ser cualquier comando ex soportado por wikicurses.

Otras Secciones

Otras secciones se tratan como entradas de wiki. La url es la url de api.php en la wiki. El nombre de usuario y la contraseña son necesarios para editar.

url

La url a api.php en el sitio de MediaWiki
