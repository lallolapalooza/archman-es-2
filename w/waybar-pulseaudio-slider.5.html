NOMBRE

waybar - módulo de deslizador pulseaudio

DESCRIPCIÓN

El módulo pulseaudio slider muestra y controla el volumen actual del sink o source predeterminado como una barra.

El volumen se puede controlar arrastrando el deslizador sobre la barra o haciendo clic en una posición específica.

CONFIGURACIÓN

min:
tipo: int
predeterminado: 0
El valor mínimo de volumen que el deslizador debe mostrar y establecer.

max:
tipo: int
predeterminado: 100
El valor máximo de volumen que el deslizador debe mostrar y establecer.

orientation:
tipo: string
predeterminado: horizontal
La orientación del deslizador. Puede ser `horizontal` o `vertical`.

expand:
tipo: bool
predeterminado: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

EJEMPLOS

"modules-right": [
    "pulseaudio/slider",
],
"pulseaudio/slider": {
    "min": 0,
    "max": 100,
    "orientation": "horizontal"
}

ESTILO

El deslizador es un componente con varios nodos CSS, de los cuales los siguientes están expuestos:

#pulseaudio-slider:
Controla el estilo de la caja alrededor del deslizador y la barra.

#pulseaudio-slider slider:
Controla el estilo del control deslizante.

#pulseaudio-slider trough:
Controla el estilo de la parte de la barra que no se ha llenado.

#pulseaudio-slider highlight:
Controla el estilo de la parte de la barra que se ha llenado.

EJEMPLO DE ESTILO

#pulseaudio-slider slider {
    min-height: 0px;
    min-width: 0px;
    opacity: 0;
    background-image: none;
    border: none;
    box-shadow: none;
}
#pulseaudio-slider trough {
    min-height: 80px;
    min-width: 10px;
    border-radius: 5px;
    background-color: black;
}
#pulseaudio-slider highlight {
    min-width: 10px;
    border-radius: 5px;
    background-color: green;
}
