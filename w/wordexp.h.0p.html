PROLOG

Esta página del manual es parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

wordexp.h — tipos de expansión de palabras

SINOPSIS

#include <wordexp.h>

DESCRIPCIÓN

La cabecera <wordexp.h> definirá las estructuras y las constantes simbólicas utilizadas por las funciones wordexp() y wordfree().

La cabecera <wordexp.h> definirá el tipo de estructura wordexp_t, que incluirá al menos los siguientes miembros:

size_t   we_wordc  Número de palabras coincidentes de words.
char   **we_wordv  Puntero a la lista de palabras expandidas.
size_t   we_offs   Espacios para reservar al principio de we_wordv.

La cabecera <wordexp.h> definirá las siguientes constantes simbólicas como indicadores para la función wordexp():

WRDE_APPEND
Añade palabras a las generadas previamente.
WRDE_DOOFFS
Número de punteros nulos a prefijar a we_wordv.
WRDE_NOCMD
Falla si se solicita sustitución de comandos.
WRDE_REUSE
El argumento pwordexp fue pasado a una llamada anterior exitosa a wordexp(), y no ha sido pasado a wordfree(). El resultado es el mismo que si la aplicación hubiera llamado a wordfree() y luego a wordexp() sin WRDE_REUSE.
WRDE_SHOWERR
No redirige stderr a /dev/null.
WRDE_UNDEF
Informa de un error al intentar expandir una variable de shell indefinida.

La cabecera <wordexp.h> definirá las siguientes constantes simbólicas como valores de retorno de error:

WRDE_BADCHAR
Uno de los caracteres sin comillas —<nueva línea>, '|', '&', ';', '<', '>', '(', ')', '{', '}'— aparece en words en un contexto inapropiado.
WRDE_BADVAL
Referencia a una variable de shell indefinida cuando WRDE_UNDEF está establecido en flags.
WRDE_CMDSUB
Se solicitó sustitución de comandos cuando WRDE_NOCMD estaba establecido en flags.
WRDE_NOSPACE
Fallo al intentar asignar memoria.
WRDE_SYNTAX
Error de sintaxis de shell, como paréntesis desequilibrados o cadena incompleta.

La cabecera <wordexp.h> definirá el tipo size_t como se describe en <stddef.h>.

Lo siguiente se declarará como funciones y también puede definirse como macros. Se proporcionarán prototipos de función.

int  wordexp(const char *restrict, wordexp_t *restrict, int);
void wordfree(wordexp_t *);
