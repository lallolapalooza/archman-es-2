NOMBRE

wifidump - Proporciona una interfaz para capturar tramas Wi-Fi desde un host remoto a través de SSH.

SINOPSIS

wifidump [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interfaz> ] [ --extcap-config ] [ --extcap-capture-filter=<filtro de captura> ] [ --capture ] [ --fifo=<ruta al archivo o tubería> ] [ --remote-host=<dirección IP> ] [ --remote-port=<puerto TCP> ] [ --remote-username=<nombredeusuario> ] [ --remote-password=<contraseña> ] [ --sshkey=<ruta a la clave pública> ] [ --remote-interface=<interfaz> ] [ --remote-channel-frequency=<frecuencia del canal> ] [ --remote-channel-width=<ancho del canal> ]

wifidump --extcap-interfaces

wifidump --extcap-interface=<interfaz> --extcap-dlts

wifidump --extcap-interface=<interfaz> --extcap-config

wifidump --extcap-interface=<interfaz> --fifo=<ruta al archivo o tubería> --capture --remote-host=mihostremoto --remote-port=22 --remote-username=usuario --remote-interface=eth2 --remote-channel-frequency=5180 --remote-channel-width=40

DESCRIPCIÓN

Wifidump es una herramienta extcap que te permite capturar tráfico Wi-Fi desde un host remoto a través de una conexión SSH utilizando tcpdump. El requisito para capturar tramas Wi-Fi es que el host remoto debe tener los binarios necesarios para administrar y poner la interfaz deseada en modo monitor. Dichos binarios incluyen: ip, iw e iwconfig. Además, dado que el uso del modo monitor y la administración de la interfaz Wi-Fi requieren privilegios de root, el sistema debe estar configurado para permitir que el usuario deseado ejecute estos binarios usando sudo sin ingresar una contraseña.

Típicamente, wifidump no se invoca directamente. En su lugar, se puede configurar a través de la interfaz gráfica de usuario de Wireshark o su línea de comandos. Lo siguiente iniciará Wireshark y comenzará a capturar desde el host remotehost:

$ wireshark '-oextcap.wifidump.remotehost:remotehost' -i wifidump -k

Para controlar explícitamente el comando de captura remota:

$ wireshark '-oextcap.wifidump.remotehost:remotehost' \
            '-oextcap.wifidump.remotechannelfrequency:5180' \
            '-oextcap.wifidump.remotechannelwidth:40' \
            -i wifidump -k

Interfaces soportadas:

1.wifidump

OPCIONES

--help

Imprime los argumentos del programa.

--version

Imprime la versión del programa.

--extcap-interfaces

Lista las interfaces disponibles.

--extcap-interface=<interfaz>

Utiliza las interfaces especificadas.

--extcap-dlts

Lista los DLT de la interfaz especificada.

--extcap-config

Lista las opciones de configuración de la interfaz especificada.

--capture

Inicia la captura desde la interfaz especificada y escribe los datos de paquetes sin procesar en la ubicación especificada por --fifo.

--fifo=<ruta al archivo o tubería>

Guarda los paquetes capturados en un archivo o los envía a través de una tubería.

--remote-host=<host remoto>

La dirección del host remoto para la captura.

--remote-port=<puerto remoto>

El puerto SSH del host remoto.

--remote-username=<nombre de usuario>

El nombre de usuario para la autenticación ssh.

--remote-password=<contraseña>

La contraseña a utilizar (si no se usan ssh-agent y pubkey). ADVERTENCIA: las contraseñas se almacenan en texto plano y son visibles para todos los usuarios en este sistema. Se recomienda usar archivos de clave con un agente SSH.

--sshkey=<ruta a la clave privada SSH>

La ruta a una clave privada para la autenticación.

--remote-interface=<interfaz remota>

La interfaz de red remota desde la cual capturar.

--remote-channel-frequency=<frecuencia del canal remoto>

La frecuencia del canal remoto en MHz.

--remote-channel-width=<ancho del canal remoto>

El ancho del canal remoto en MHz.

--extcap-capture-filter=<filtro de captura>

El filtro de captura. Corresponde al valor proporcionado a través de la opción tshark -f, y al campo Filtro de Captura junto a la lista de interfaces en la interfaz de Wireshark.

DESCRIPCIÓN

Wifidump es una utilidad de captura de paquetes que se ejecuta en el modo de paquete de captura de wireshark(1) y tshark(1).

Se utiliza para capturar paquetes inalámbricos en una interfaz inalámbrica.

Para obtener una lista completa de las opciones de captura, consulte la página de manual de wireshark(1) o dumpcap(1).

OPCIONES

La mayoría de las opciones para wifidump son las mismas que las de dumpcap(1). La principal diferencia es que wifidump se puede usar para capturar paquetes inalámbricos directamente.

-i interface
Especifica la interfaz inalámbrica de la que se capturarán paquetes.
-w file
Escribe los paquetes capturados en el archivo especificado.
-c count
Sale después de capturar count paquetes.

EJEMPLOS

Para capturar paquetes de la interfaz inalámbrica 'wlan0' y guardarlos en el archivo 'capture.pcap':

  $ wifidump -i wlan0 -w capture.pcap

Para capturar 100 paquetes de la interfaz inalámbrica 'wlan0' y mostrarlos en la salida estándar:

  $ wifidump -i wlan0 -c 100

También se puede usar para volcar a interfaces específicas de wifidump-host1 y wifidump-host2. Cada binario mostrará un nombre de interfaz igual al nombre del ejecutable. Aquellos ejecutables que no sean "wifidump" aparecerán como "versión personalizada" en la descripción de la interfaz.
