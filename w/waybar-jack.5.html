NOMBRE

jack - Módulo JACK

DESCRIPCIÓN

El módulo jack muestra el estado actual del servidor JACK.

CONFIGURACIÓN

Abordado por jack

format:
tipo: cadena
predeterminado: {load}%
El formato, cómo se debe mostrar la información. Este formato se utiliza cuando no se especifican otros formatos.

format-connected:
tipo: cadena
Este formato se utiliza cuando el módulo está conectado al servidor JACK.

format-disconnected:
tipo: cadena
Este formato se utiliza cuando el módulo no está conectado al servidor JACK.

format-xrun:
tipo: cadena
Este formato se utiliza durante un intervalo de sondeo cuando el servidor JACK informa de un xrun.

realtime:
tipo: booleano
predeterminado: true
Opción para eliminar privilegios en tiempo real para el cliente JACK abierto por Waybar.

tooltip:
tipo: booleano
predeterminado: true
Opción para deshabilitar la información sobre herramientas al pasar el ratón por encima.

tooltip-format:
tipo: cadena
predeterminado: {bufsize}/{samplerate} {latency}ms
El formato de la información mostrada en la información sobre herramientas.

interval:
tipo: entero
predeterminado: 1
El intervalo en el que se sondea la información.

rotate:
tipo: entero
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

max-length:
tipo: entero
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
tipo: entero
La longitud mínima en caracteres que el módulo debe aceptar.

align:
tipo: flotante
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: cadena
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left' (izquierda), 'right' (derecha) o 'center' (centro) para definir la posición.

on-click:
tipo: cadena
Comando a ejecutar al hacer clic en el módulo.

on-click-middle:
tipo: cadena
Comando a ejecutar al hacer clic con la rueda del ratón en el módulo.

on-click-right:
tipo: cadena
Comando a ejecutar al hacer clic derecho en el módulo.

on-update:
tipo: cadena
Comando a ejecutar cuando el módulo se actualiza.

menu:
tipo: cadena
Acción que muestra el menú emergente.

menu-file:
tipo: cadena
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: booleano
predeterminado: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

{load}: La carga actual de la CPU estimada por JACK.

{bufsize}: El tamaño del búfer de JACK.

{samplerate}: La frecuencia de muestreo a la que se ejecuta el servidor JACK.

{latency}: La duración, en ms, del tamaño de búfer actual.

{xruns}: El número de xruns informados por el servidor JACK desde que se inició Waybar.

EJEMPLOS

"jack": {
	"format": "DSP {}%",
	"format-xrun": "{} xruns",
	"format-disconnected": "DSP off",
	"realtime": true
}
