waybar-privacy(5) Manual de formatos de archivo waybar-privacy(5)

NOMBRE

waybar - módulo de privacidad

DESCRIPCIÓN

El módulo privacy muestra si alguna aplicación está capturando audio, compartiendo
la pantalla o reproduciendo audio.

CONFIGURACIÓN

icon-spacing:
tipo: entero
predeterminado: 4
El espaciado entre cada icono de privacidad.

icon-size:
tipo: entero
predeterminado: 20
El tamaño de cada icono de privacidad.

transition-duration:
tipo: entero
predeterminado: 250
Opción para deshabilitar la información emergente al pasar el ratón por encima.

modules
tipo: arreglo de objetos
predeterminado: [{"type": "screenshare"}, {"type": "audio-in"}]
Qué módulos de privacidad monitorear. Ver CONFIGURACIÓN DE MÓDULOS para
más información.

expand:
tipo: booleano
predeterminado: falso
Permite que este módulo consuma todo el espacio sobrante de forma dinámica.

ignore-monitor
tipo: booleano
predeterminado: verdadero
Ignora transmisiones con la propiedad stream.monitor.

ignore
tipo: arreglo de objetos
predeterminado: []
Transmisiones adicionales a ser ignoradas. Ver CONFIGURACIÓN DE IGNORE para
más información.

CONFIGURACIÓN DE MÓDULOS

type:
tipo: cadena
valores: "screenshare", "audio-in", "audio-out"
Especifica qué módulo usar y configurar.

tooltip:
tipo: booleano
predeterminado: verdadero
Opción para deshabilitar la información emergente al pasar el ratón por encima.

tooltip-icon-size:
tipo: entero
predeterminado: 24
El tamaño de cada icono en la información emergente.

CONFIGURACIÓN DE IGNORE

type:
tipo: cadena

name:
tipo: cadena

EJEMPLOS

"privacy": {
	"icon-spacing": 4,
	"icon-size": 18,
	"transition-duration": 250,
	"modules": [
		{
			"type": "screenshare",
			"tooltip": true,
			"tooltip-icon-size": 24
		},
		{
			"type": "audio-out",
			"tooltip": true,
			"tooltip-icon-size": 24
		},
		{
			"type": "audio-in",
			"tooltip": true,
			"tooltip-icon-size": 24
		}
	],
	"ignore-monitor": true,
	"ignore": [
		{
			"type": "audio-in",
			"name": "cava"
		},
		{
			"type": "screenshare",
			"name": "obs"
		}
	]
},
