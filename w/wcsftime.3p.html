PROLOG

Esta página del manual forma parte del Manual de programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

wcsftime — convertir fecha y hora a una cadena de caracteres anchos

SINOPSIS

#include <wchar.h>
size_t wcsftime(wchar_t *restrict wcs, size_t maxsize,
    const wchar_t *restrict format, const struct tm *restrict timeptr);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función wcsftime() será equivalente a la función strftime(), excepto que:

*
El argumento wcs apunta al elemento inicial de una matriz de caracteres anchos en la que se colocará la salida generada.
*
El argumento maxsize indica el número máximo de caracteres anchos que se colocarán en la matriz de salida.
*
El argumento format es una cadena de caracteres anchos y las especificaciones de conversión se reemplazan por secuencias correspondientes de caracteres anchos. No está especificado si ocurre un error de codificación si la cadena de formato contiene valores wchar_t que no corresponden a miembros del conjunto de caracteres de la configuración regional actual.
*
Los anchos de campo especifican el número de caracteres anchos en lugar del número de bytes.
*
El valor de retorno indica el número de caracteres anchos colocados en la matriz de salida.

Si la copia tiene lugar entre objetos que se solapan, el comportamiento es indefinido.

VALOR DE RETORNO

Si el número total de códigos de caracteres anchos resultantes, incluido el código de carácter ancho nulo terminador, no supera maxsize, wcsftime() devolverá el número de códigos de caracteres anchos colocados en la matriz apuntada por wcs, sin incluir el código de carácter ancho nulo terminador. De lo contrario, se devuelve cero y el contenido de la matriz no se especifica.

ERRORES

No se definen errores.
