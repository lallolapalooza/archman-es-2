waybar-temperature(5) Manual de formatos de archivo waybar-temperature(5)

NOMBRE

waybar - módulo de temperatura

DESCRIPCIÓN

El módulo temperature muestra la temperatura actual de una zona térmica.

CONFIGURACIÓN

Abordado por temperature

thermal-zone:
tipo: entero
La zona térmica, como en /sys/class/thermal/.

hwmon-path:
tipo: cadena
La ruta de la temperatura a usar, por ejemplo, /sys/class/hwmon/hwmon2/temp1_input en lugar de una en /sys/class/thermal/.

Esto también puede ser un array de cadenas. En este caso, waybar comprobará cada elemento del array y usará el primero válido. Esto es adecuado si desea compartir el mismo archivo de configuración entre diferentes máquinas con diferentes configuraciones de hardware.

hwmon-path-abs:
tipo: cadena
La ruta del directorio hwmon del dispositivo, por ejemplo, /sys/devices/pci0000:00/0000:00:18.3/hwmon. (¡Tenga en cuenta que el subdirectorio hwmon/hwmon#, donde # es un número, no forma parte de la ruta!) Debe usarse junto con input-filename.

Esto también puede ser un array de cadenas, para las cuales, simplemente funciona como hwmon-path.

input-filename:
tipo: cadena
El nombre del archivo de temperatura de su hwmon-path-abs, por ejemplo, temp1_input

warning-threshold:
tipo: entero
El umbral antes de que se considere advertencia (Celsius).

critical-threshold:
tipo: entero
El umbral antes de que se considere crítico (Celsius).

interval:
tipo: entero
por defecto: 10
El intervalo en el que se encuestará la información.

format-warning:
tipo: cadena
El formato a usar cuando la temperatura se considera de advertencia

format-critical:
tipo: cadena
El formato a usar cuando la temperatura se considera crítica

format:
tipo: cadena
por defecto: {temperatureC}Â°C
El formato (Celsius/Fahrenheit/Kelvin) en el que se debe mostrar la temperatura.

format-icons:
tipo: array
Según la temperatura actual (Celsius) y critical-threshold si está disponible, se selecciona el icono correspondiente. El orden es de bajo a alto.

tooltip-format:
tipo: cadena
por defecto: {temperatureC}Â°C
El formato para la información sobre herramientas

rotate:
tipo: entero
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

max-length:
tipo: entero
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
tipo: entero
La longitud mínima en caracteres que el módulo debe aceptar.

align:
tipo: flotante
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: cadena
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir la posición.

on-click:
tipo: cadena
Comando a ejecutar cuando se hace clic en el módulo.

on-click-middle:
tipo: cadena
Comando a ejecutar cuando se hace clic con la rueda del ratón en el módulo.

on-click-right:
tipo: cadena
Comando a ejecutar cuando se hace clic derecho en el módulo.

on-update:
tipo: cadena
Comando a ejecutar cuando el módulo se actualiza.

on-scroll-up:
tipo: cadena
Comando a ejecutar al desplazarse hacia arriba en el módulo.

on-scroll-down:
tipo: cadena
Comando a ejecutar al desplazarse hacia abajo en el módulo.

smooth-scrolling-threshold:
tipo: doble
Umbral a usar al desplazarse.

tooltip:
tipo: booleano
por defecto: verdadero
Opción para deshabilitar la información sobre herramientas al pasar el ratón.

menu:
tipo: cadena
Acción que muestra el menú.

menu-file:
tipo: cadena
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: booleano
por defecto: falso
Permite que este módulo consuma dinámicamente todo el espacio sobrante.

REEMPLAZOS DE FORMATO

{temperatureC}: Temperatura en Celsius.

{temperatureF}: Temperatura en Fahrenheit.

{temperatureK}: Temperatura en Kelvin.
