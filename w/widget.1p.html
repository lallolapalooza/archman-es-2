NOMBRE

widget - Demostración de widgets de Perl/Tk

SINOPSIS

widget [ directorio ]

DESCRIPCIÓN

Este script demuestra los diversos widgets proporcionados por Tk, junto con muchas de las características del toolkit Tk. Este archivo solo contiene código para generar la ventana principal de la aplicación, que invoca demostraciones individuales. El código para las demostraciones reales se encuentra en archivos ".pl" separados en el directorio "widget_lib", los cuales son cargados automáticamente por este script según sea necesario.

widget busca en el directorio especificado en la línea de comandos para cargar demostraciones aportadas por el usuario. Si no se especifica ningún nombre de directorio al invocar widget y la variable de entorno WIDTRIB está definida, las demostraciones se cargarán desde el directorio WIDTRIB. Si WIDTRIB no está definida, widget utilizará por defecto el directorio de demostraciones aportadas por el usuario publicado, "widtrib".
