NOMBRE

waybar - módulo de reloj

DESCRIPCIÓN

El módulo clock muestra la fecha y hora actuales

ARCHIVOS

$XDG_CONFIG_HOME/waybar/config
Archivo de configuración por usuario

CONFIGURACIÓN

1. Abordado por clock

Opción Tipo Predeterminado Descripción
interval entero 60 El intervalo en el que se consulta la información
format cadena {:%H:%M} El formato de cómo se deben mostrar la fecha y la hora. Ver opciones de formato a continuación
timezone cadena La zona horaria en la que mostrar la hora, por ejemplo, América/Nueva_York. "" representa la zona horaria local del sistema. Ver la lista no oficial de zonas horarias de Wikipedia https://en.wikipedia.org/wiki/List_of_tz_database_time_zones
timezones lista de cadenas Una lista de zonas horarias (como en timezone) para usar en la visualización de la hora, cambiadas usando la rueda del ratón. No especificar la opción timezone cuando se especifica timezones. "" representa la zona horaria local del sistema
locale cadena Una configuración regional (locale) para usar al mostrar la hora. Destinada a renderizar horas en zonas horarias personalizadas con el idioma y formato adecuados
max-length entero La longitud máxima en caracteres que debe mostrar el módulo
rotate entero Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados)
on-click cadena Comando a ejecutar al hacer clic en el módulo
on-click-middle cadena Comando a ejecutar al hacer clic con el botón central del ratón en el módulo
on-click-right cadena Comando a ejecutar al hacer clic con el botón derecho del ratón en el módulo
on-scroll-up cadena Comando a ejecutar al desplazarse hacia arriba en el módulo
on-scroll-down cadena Comando a ejecutar al desplazarse hacia abajo en el módulo
smooth-scrolling-threshold doble Umbral a utilizar al desplazarse
tooltip booleano true Opción para habilitar la información emergente al pasar el ratón por encima
tooltip-format cadena igual que format Información emergente al pasar el ratón por encima
menu cadena Acción que abre el menú.
menu-file cadena Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo GtkMenu con id menu
menu-actions array Las acciones correspondientes a los botones del menú.
expand: booleano false Permite que este módulo consuma dinámicamente todo el espacio restante.

Vea todas las opciones de formato válidas en strftime(3) o eche un vistazo en https://en.cppreference.com/w/cpp/chrono/duration/formatter

2. Abordado por clock: calendar

Opción Tipo Predeterminado Descripción
mode cadena month Modo de visualización del calendario. Valores posibles: year|month
mode-mon-col entero 3 Relevante para mode=year. Número de meses por fila
weeks-pos cadena La posición donde se mostrarán los números de semana. Deshabilitado cuando está vacío. Valores posibles: left|right
on-scroll entero 1 Valor para desplazarse meses/años hacia adelante/atrás. Puede ser negativo. Se configura en la opción on-scroll

3. Abordado por clock: calendar: format

Opción Tipo Predeterminado Descripción
months cadena El formato se aplica a la cabecera de los meses (enero, febrero,... etc.)
days cadena El formato se aplica a los días
weeks cadena {:%U} El formato se aplica a los números de semana. Cuando el formato del día de la semana no se proporciona, se usa el formato predeterminado: '{:%W}' cuando la semana comienza el lunes, '{:%U}' en caso contrario
weekdays cadena El formato se aplica a la cabecera de las semanas (do, lu,... etc.)
today cadena <b><u>{}</u></b> El formato se aplica a Hoy

Acciones

Cadena Acción
mode Cambia el modo del calendario entre año/mes
tz_up Cambia a la siguiente zona horaria proporcionada
tz_down Cambia a la zona horaria anterior proporcionada
shift_up Cambia al siguiente mes/año del calendario
shift_down Cambia al mes/año anterior del calendario

REEMPLAZOS DE FORMATO

  • {calendar}: Calendario del mes actual
  • {tz_list}: Lista de horas en las zonas horarias restantes, si se establece más de una zona horaria en la configuración
  • {ordinal_date}: El día actual en formato ordinal (inglés), por ejemplo, 21st

Solución de problemas

Si el módulo de reloj está desactivado al inicio con el mensaje de error
locale::facet::_S_create_c_locale name not valid, intente una de las siguientes opciones:

  • compruebe si LC_TIME está configurado correctamente (glibc)
  • establezca la configuración regional a C en el archivo de configuración (musl)

La opción de configuración regional debe estar establecida para que {calendar} utilice el día correcto de inicio de semana, independientemente de la configuración regional del sistema.

Calendario en chino. Alineación

Para tener un calendario chino alineado, hay algunas recomendaciones útiles:

1.
Utilice "WenQuanYi Zen Hei Mono", que se proporciona en la mayoría de las distribuciones de Linux.
2.
Pruebe diferentes tamaños de fuente y encuentre el que mejor le funcione. El tamaño = 9pt debería ser adecuado.
3.
En caso de utilizar la fuente "WenQuanYi Zen Hei Mono", desactive la etiqueta pango de fuente monoespaciada.
