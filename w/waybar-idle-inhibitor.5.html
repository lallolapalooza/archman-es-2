NOMBRE

waybar - módulo idle_inhibitor

DESCRIPCIÓN

El módulo idle_inhibitor puede inhibir el comportamiento de inactividad como el oscurecimiento de la pantalla, el bloqueo y el salvapantallas, también conocido como "modo presentación".

CONFIGURACIÓN

format:
tipo: cadena
El formato, cómo se debe mostrar el estado.

format-icons:
tipo: arreglo
Basado en el estado actual, se selecciona el icono correspondiente.

rotate:
tipo: entero
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

max-length:
tipo: entero
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
tipo: entero
La longitud mínima en caracteres que el módulo debe aceptar.

align:
tipo: flotante
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: cadena
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir la posición.

on-click:
tipo: cadena
Comando a ejecutar al hacer clic en el módulo. Un clic también alterna el estado

on-click-middle:
tipo: cadena
Comando a ejecutar al hacer clic con la rueda del ratón en el módulo.

on-click-right:
tipo: cadena
Comando a ejecutar al hacer clic derecho en el módulo.

on-update:
tipo: cadena
Comando a ejecutar cuando el módulo se actualiza.

on-scroll-up:
tipo: cadena
Comando a ejecutar al desplazarse hacia arriba en el módulo.

on-scroll-down:
tipo: cadena
Comando a ejecutar al desplazarse hacia abajo en el módulo.

smooth-scrolling-threshold:
tipo: doble
Umbral a utilizar al desplazarse.

start-activated:
tipo: booleano
por defecto: falso
Si la inhibición debe activarse al iniciar waybar.

timeout:
tipo: doble
El número de minutos que debe durar la inhibición.

tooltip:
tipo: booleano
por defecto: verdadero
Opción para deshabilitar la información emergente al pasar el ratón por encima.

tooltip-format-activated:
tipo: cadena
Este formato se utiliza cuando la inhibición está activada.

tooltip-format-deactivated:
tipo: cadena
Este formato se utiliza cuando la inhibición está desactivada.

menu:
tipo: cadena
Acción que muestra el menú. No puede ser "on-click".

menu-file:
tipo: cadena
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: arreglo
Las acciones correspondientes a los botones del menú.

expand:
tipo: booleano
por defecto: falso
Permite que este módulo consuma todo el espacio sobrante de forma dinámica.

REEMPLAZOS DE FORMATO

{status}: estado (activado o desactivado)

{icon}: Icono, como se define en format-icons

EJEMPLOS

"idle_inhibitor": {
	"format": "{icon}",
	"format-icons": {
		"activated": "",
		"deactivated": ""
	},
	"timeout": 30.5
}
