Paquete: libwslay

Licencias: MIT

WSLAY_EVENT_CONFIG_SET_CALLBACKS(3) wslay WSLAY_EVENT_CONFIG_SET_CALLBACKS(3)

NOMBRE

wslay_event_config_set_callbacks - Establecer funciones de devolución de llamada

SINOPSIS

#include <wslay/wslay.h>

void wslay_event_config_set_callbacks(wslay_event_context_ptr ctx, const struct wslay_event_callbacks *callbacks)

DESCRIPCIÓN

wslay_event_config_set_callbacks() establece las devoluciones de llamada en ctx. Las devoluciones de llamada establecidas previamente por esta función o por wslay_event_context_server_init() o wslay_event_context_client_init() se reemplazan por callbacks.

VER TAMBIÉN

wslay_event_context_server_init(), wslay_event_context_client_init()
