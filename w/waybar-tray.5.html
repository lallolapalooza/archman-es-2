NOMBRE

waybar - módulo de bandeja (tray)

DESCRIPCIÓN

ADVERTENCIA tray todavía está en beta. Puede haber errores. Pueden ocurrir cambios disruptivos.

CONFIGURACIÓN

Abordado por tray

icon-size:
tipo: entero
Define el tamaño de los iconos de la bandeja.

show-passive-items:
tipo: booleano
predeterminado: falso
Define la visibilidad de los iconos de la bandeja con estado Pasivo.

smooth-scrolling-threshold:
tipo: doble
Umbral a utilizar al desplazarse.

spacing:
tipo: entero
Define el espacio entre los iconos de la bandeja.

reverse-direction:
tipo: booleano
Define si los nuevos iconos de aplicaciones deben agregarse en orden inverso.

on-update:
tipo: cadena
Comando a ejecutar cuando el módulo se actualiza.

expand:
tipo: booleano
predeterminado: falso
Permite que este módulo consuma todo el espacio restante dinámicamente.

EJEMPLOS

"tray": {
	"icon-size": 21,
	"spacing": 10,
  "icons": {
    "blueman": "bluetooth",
    "TelegramDesktop": "$HOME/.local/share/icons/hicolor/16x16/apps/telegram.png"
  }
}
