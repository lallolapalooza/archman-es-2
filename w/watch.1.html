WATCH(1) Manual de Comandos Generales WATCH(1)

NOMBRE

watch - ejecuta un programa periódicamente, mostrando la salida a pantalla completa

SINOPSIS

watch [opción ...] comando

DESCRIPCIÓN

watch ejecuta comando repetidamente, mostrando su salida y errores (la primera pantalla). Esto le permite observar cómo cambia la salida del programa con el tiempo. Por defecto, comando se ejecuta cada 2 segundos y watch se ejecutará hasta ser interrumpido. Una cabecera informa de la hora de inicio y ejecución de comando, así como de su código de salida.

OPCIONES

-b, --beep
Emite un pitido si comando tiene una salida distinta de cero.
-c, --color
Interpreta secuencias de color y estilo ANSI.
-C, --no-color
No interpreta secuencias de color y estilo ANSI.
-d, --differences[=permanente]
Resalta las diferencias entre actualizaciones sucesivas. Si se especifica el argumento opcional permanente, entonces watch mostrará todos los cambios desde la primera iteración.
-e, --errexit
Congela las actualizaciones en caso de error de comando y sale después de presionar una tecla. El código de salida de watch será el código con el que comando sale. Si la señal n es la causa de la terminación de comando, el código de salida será 128 + n.
-g, --chgexit
Sale cuando la salida visible de comando cambia. Los cambios que quedan fuera de pantalla debido a un tamaño de pantalla pequeño o a una salida grande no harán que watch salga.
-n, --interval segundos
Especifica el intervalo de actualización. Los valores menores que 0.1 y mayores que 2678400 (31 días) se convierten a estos límites respectivos. Tanto '.' como ',' funcionan para cualquier configuración regional. La variable de entorno WATCH_INTERVAL puede usarse para establecer de forma persistente un intervalo no predeterminado (siguiendo las mismas reglas y formato).
-p, --precise
Ejecuta comando --interval segundos después de que su ejecución anterior comenzara, en lugar de --interval segundos después de que su ejecución anterior terminara. Si tarda más de --interval segundos en completarse comando, se espera en cualquier caso.
-q, --equexit <ciclos>
Sale cuando la salida de comando no cambia durante el número dado de ciclos.
-r, --no-rerun
No ejecuta el programa al redimensionar la terminal, la salida del programa reaparecerá en el próximo momento de ejecución regular.
-s, --shotsdir
Directorio donde guardar las capturas de pantalla.
-t, --no-title
Desactiva la cabecera que normalmente se muestra en la parte superior de la pantalla.
-w, --no-wrap
Desactiva el salto de línea. Las líneas largas se truncarán en lugar de saltar a la siguiente línea.
-x, --exec
Pasa comando a una llamada exec(3) en lugar de sh -c. El programa se iniciará un poco más rápido. Las funciones del shell (configuración del entorno, expansión de variables y rutas, etc.) no estarán disponibles.
-h, --help
Muestra el texto de ayuda y sale.
-v, --version
Muestra la información de la versión y sale.

CONTROL DE TECLA

barra espaciadora
Ejecuta comando inmediatamente. Si se está ejecutando en el momento, no se interrumpe y su próxima ronda comenzará sin demora.
q
Sale de watch. Actualmente no interrumpe un comando en ejecución (a diferencia de las señales de terminación, como SIGKILL seguido de Ctrl+C).
s
Realiza una captura de pantalla. Se guardará en el directorio de trabajo, a menos que se especifique lo contrario con --shotsdir. Si comando se está ejecutando en el momento, la captura de pantalla se realizará tan pronto como termine.

ESTADO DE SALIDA

0
Éxito. No representa el código de salida de comando.
1
Errores no relacionados con la operación de comando.
2
Errores relacionados con la ejecución y gestión de comando (no su código de salida).
cualquier valor distinto de cero (--errexit)
Con --errexit se devuelve el último código de salida de comando.

ENTORNO

El comportamiento de watch se ve afectado por las siguientes variables de entorno.

WATCH_INTERVAL
Intervalo de actualización, sigue las mismas reglas que la opción de línea de comandos --interval.
COLUMNS
Ancho de caracteres de la pantalla de la terminal. Se establece para anular la autodetección.
LINES
Alto de caracteres de la pantalla de la terminal. Se establece para anular la autodetección.

NOTAS

Se utiliza el procesamiento de opciones POSIX (es decir, el procesamiento de opciones se detiene en el primer argumento que no sea una opción). Esto significa que las banderas después de comando no son interpretadas por watch.

Los caracteres no imprimibles se eliminan de la salida del programa. Utilice cat -v como parte de la tubería del comando si desea verlos.

EJEMPLOS

Para observar los cambios en el contenido de un directorio, puede usar

watch -d ls -l

Si tiene CPUs con frecuencia dinámica y desea observar cómo cambia, pruebe lo siguiente. El comando se pasa al shell, lo que le permite crear la tubería. Las comillas también son una característica del shell.

watch -n1 'grep "^cpu MHz" /proc/cpuinfo | sort -nrk4'

Para monitorear el estado de actividad de sus servidores, guardando una copia de la salida de cada ejecución en un archivo, puede usar esto. El -p hace que el comando se ejecute cada 10 segundos independientemente de cuánto tardó en completarse la ejecución anterior.

watch -n10 -p -d '{ date; for i in 10.0.0.31 10.0.0.32 10.0.0.33; do R=OK; ping -c2 -W2 "$i" &>/dev/null || R=FAIL; echo "$i: $R"; done } | tee -a ~/log'

Puede esperar a que su administrador instale el último kernel con

watch uname -r

ERRORES

Cuando cambian las dimensiones de la terminal, sus cambios de contenido no se registran en la siguiente ejecución de comando. --chgexit no se activará esa vez y el contador de --equexit no se reiniciará, incluso si comando cambia su salida mientras tanto. El resaltado de --differences se reinicia.

REPORTE DE ERRORES

Por favor, envíe los informes de errores a procps@freelists.org.

watch - execute a program periodically, showing output fullscreen

NAME

watch - execute a program periodically, showing output fullscreen

SYNOPSIS

watch [-]n [-d[revers]] [-e] [-E log_file] [-f] [-f] [-f] [-c] [-g] [-h] [-p] [-t] [-u] [-b] [-l] [-n countdown] [-r] [-s] [-o] [-a] [-i] [-x] [--help] [--version] [<command>]

DESCRIPTION

watch runs command in a fullscreen window, repeatedly. The default interval between successive runs is 2 seconds. The output of command replaces the whole screen. The exit status of watch is the exit status of the last instance of command.

By default, watch clears the screen and prints the output of command. It then waits n seconds and repeats. The default value for n is 2 seconds. The value of n must be a positive integer.

watch is useful for monitoring a system or the output of a command that changes frequently.

OPTIONS

-n
Specify the interval between updates in seconds. The default is 2 seconds.
-d, --differences
Highlight differences between successive updates. This option is useful for quickly spotting changes.
-revers
Highlight differences between successive updates in reverse video.
-e, --errexit
Exit the watch utility if the command exits with a non-zero exit status.
-E log_file, --logfile log_file
Log all output to log_file.
-f, --no-batch-mode
Disable batch mode. This means that watch will not exit after the first update.
-c, --color
Interpret ANSI color sequences.
-g, --chg-arg
Exit watch when the command's argument or the command itself changes.
-h, --help
Display a help message and exit.
-p, --precise
Disables the timing adjustment that causes watch to run at precise intervals.
-t, --no-title
Turn off the header that shows the command, interval, and title, that is normally displayed at the top of the screen.
-u, --unicode
Interpret Unicode characters.
-b, --beep
Beep when the command output changes.
-l, --late-watch
Beep when the command output does not change.
-n countdown, --interval countdown
Specify the interval between updates in seconds. The default is 2 seconds.
-r, --no-beep
Disable beeping.
-s, --skip-nodiff
Skip printing the output if it has not changed.
-o, --offline
Do not attempt to reconnect if the connection is lost.
-a, --no-error
Do not exit if the command returns an error.
-i, --ignore-case
Ignore case when comparing output.
-x, --selinux
Enable SELinux context display.
--help
Display a help message and exit.
--version
Display version information and exit.

KEY CONTROL

watch recognizes the following keys:

Ctrl+C
Exit watch.
q
Quit watch.
s
Stop/restart periodic updates.
S
Show the value of the TIMELEFT variable.
f
Leave the header visible.
c
Clear the screen.
r
Re-display the header.
g
Set the update interval.
d
Highlight differences.
h
Show the help screen.
p
Toggle precise timing.
b
Beep on change.
l
Beep on no change.

EXIT STATUS

The exit status of watch is the exit status of the last executed command.

ENVIRONMENT

None.

NOTES

The watch command is useful for monitoring the output of commands that produce changing output, such as network status, disk usage, or system load.

EXAMPLES

Watch the disk usage of the root filesystem every 5 seconds: 

    $ watch -n 5 df -h /

Watch the number of logged-in users every 10 seconds, highlighting differences: 

    $ watch -n 10 -d who
