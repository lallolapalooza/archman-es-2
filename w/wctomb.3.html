wctomb(3) Manual de funciones de biblioteca wctomb(3)

NOMBRE

wctomb - convierte un carácter ancho a una secuencia multibyte

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <stdlib.h>
int wctomb(char *s, wchar_t wc);

DESCRIPCIÓN

Si s no es NULL, la función wctomb() convierte el carácter ancho wc a su representación multibyte y la almacena al principio del array de caracteres apuntado por s. Actualiza el estado de desplazamiento, que se almacena en una variable estática anónima conocida solo por la función wctomb(), y devuelve la longitud de dicha representación multibyte, es decir, el número de bytes escritos en s.

Se escribirán como máximo MB_CUR_MAX bytes en s. El programador debe asegurarse de que hay suficiente espacio para almacenar la secuencia multibyte en s.

Si s es NULL, la función wctomb() restablece el estado de desplazamiento, conocido solo por esta función, a su estado inicial, y devuelve un valor distinto de cero si la codificación tiene un estado de desplazamiento no trivial, o cero si la codificación no tiene estado.

VALOR DE RETORNO

Si s no es NULL, la función wctomb() devuelve el número de bytes que se han escrito en el array de bytes en s. Si wc no se puede representar como una secuencia multibyte (de acuerdo con la configuración regional actual), se devuelve -1.

Si s es NULL, la función wctomb() devuelve un valor distinto de cero si la codificación tiene un estado de desplazamiento no trivial, o cero si la codificación no tiene estado.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, véase attributes(7).

Interfaz Atributo Valor
wctomb () Seguridad de hilos MT-Unsafe race

VERSIÓN

La función wcrtomb(3) proporciona una mejor interfaz para la misma funcionalidad.

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C99.

NOTAS

El comportamiento de wctomb() depende de la categoría LC_CTYPE de la configuración regional actual.

VER TAMBIÉN

MB_CUR_MAX(3), mblen(3), mbstowcs(3), mbtowc(3), wcrtomb(3), wcstombs(3)
