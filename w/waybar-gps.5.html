waybar-gps(5) Manual de usuario waybar-gps(5)

NOMBRE

waybar - módulo gps

DESCRIPCIÓN

Módulo gps para gpsd.

ARCHIVOS

$XDG_CONFIG_HOME/waybar/config
Archivo de configuración por usuario

ARCHIVOS ADICIONALES

libgps se encuentra en:

1.
/usr/lib/libgps.so o /usr/lib64/libgps.so
2.
/usr/lib/pkgconfig/libgps.pc o /usr/lib64/pkgconfig/libgps.pc
3.
/usr/include/gps

CONFIGURACIÓN

format:
tipo: string
predeterminado: {glyph}
El formato del texto.

tooltip:
tipo: bool
predeterminado: true
Opción para deshabilitar la información emergente al pasar el ratón.

tooltip-format:
tipo: string
predeterminado: Juegos en ejecución: {glyph}
El formato del texto de la información emergente.

interval:
tipo: integer
predeterminado: 5
El intervalo en el que se consulta la información del GPS (por ejemplo, velocidad actual).

Las actualizaciones significativas (por ejemplo, el modo de conexión actual) se actualizan inmediatamente.

hide-disconnected:
tipo: bool
predeterminado: true
Define si el módulo debe ocultarse si no hay receptor GPS.

hide-no-fix:
tipo: bool
predeterminado: false
Define si el módulo debe ocultarse si no hay una fijación GPS.

REEMPLAZOS DE FORMATO

{mode}: Modo de fijación

{status}: Tecnología utilizada para la fijación GPS. No todos los receptores GPS informan esto.

{latitude}: Latitud, grados decimales. Puede ser NaN.

{latitude_error}: Incertidumbre de latitud, metros. Puede ser NaN.

{longitude}: Longitud, grados decimales. Puede ser NaN.

{longitude_error}: Incertidumbre de longitud, metros. Puede ser NaN.

{altitude_hae}: Altitud, altura sobre el elipsoide, metros. Puede ser NaN.

{altitude_msl}: Longitud, MSL, metros. Puede ser NaN.

{altitude_error}: Incertidumbre de altitud, metros. Puede ser NaN.

{speed}: Velocidad sobre el terreno, metros/segundo. Puede ser NaN.

{speed_error}: Incertidumbre de velocidad, metros/segundo. Puede ser NaN.

{climb}: Velocidad vertical, metros/segundo. Puede ser NaN.

{climb_error}: Incertidumbre de velocidad vertical, metros/segundo. Puede ser NaN.

{satellites_visible}: Número de satélites visibles desde el receptor GPS.

{satellites_used}: Número de satélites utilizados para la fijación GPS.

EJEMPLOS

"gps": {
	"format": "{mode}",
	"format-disabled": "", // un formato vacío ocultará el módulo
	"format-no-fix": "Sin fijación",
	"format-fix-3d": "{status}",
	"tooltip-format": "{mode}",
	"tooltip-format-no-fix": "{satellites_visible} satélites visibles",
	"tooltip-format-fix-2d": "{satellites_used}/{satellites_visible} satélites usados",
	"tooltip-format-fix-3d": "Altitud: {altitude_hae}m",
	"hide-disconnected": false
}

ESTILO

  • #gps
  • #gps.disabled Aplicado cuando el GPS está deshabilitado.
  • #gps.fix-none Aplicado cuando el GPS está presente, pero no hay fijación.
  • #gps.fix-2d Aplicado cuando hay una fijación 2D.
  • #gps.fix-3d Aplicado cuando hay una fijación 3D.
