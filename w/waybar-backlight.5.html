waybar-backlight(5) Manual de formatos de archivo waybar-backlight(5)

NOMBRE

waybar - módulo de retroiluminación

DESCRIPCIÓN

El módulo backlight muestra el nivel actual de retroiluminación.

CONFIGURACIÓN

interval:
tipo: entero
predeterminado: 2
El intervalo en el que se consulta la información.

format:
tipo: cadena
predeterminado: {percent}%
El formato, cómo se debe mostrar la información. En {} se insertan los datos.

max-length:
tipo: entero
La longitud máxima en caracteres que debe mostrar el módulo.

min-length:
tipo: entero
La longitud mínima en caracteres que debe aceptar el módulo.

align:
tipo: flotante
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: cadena
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir la posición.

rotate:
tipo: entero
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

states:
tipo: objeto
Una serie de estados de retroiluminación que se activan en ciertos niveles de brillo. Ver waybar-states(5).

on-click:
tipo: cadena
Comando a ejecutar cuando se hace clic en el módulo.

on-click-middle:
tipo: cadena
Comando a ejecutar cuando se hace clic con el botón central del ratón en el módulo.

on-click-right:
tipo: cadena
Comando a ejecutar cuando se hace clic derecho en el módulo.

on-update:
tipo: cadena
Comando a ejecutar cuando se actualiza el módulo.

on-scroll-up:
tipo: cadena
Comando a ejecutar al desplazarse hacia arriba en el módulo. Esto reemplaza el comportamiento predeterminado de control de brillo.

on-scroll-down:
tipo: cadena

Comando a ejecutar al desplazarse hacia abajo en el módulo. Esto reemplaza el comportamiento predeterminado de control de brillo.

smooth-scrolling-threshold:
tipo: doble

Umbral a utilizar al desplazarse.

reverse-scrolling:
tipo: booleano
Opción para invertir la dirección del desplazamiento.

scroll-step:
tipo: flotante
predeterminado: 1.0
La velocidad a la que se cambia el brillo al desplazarse.

min-brightness:
tipo: doble
predeterminado: 0.0
El brillo mínimo de la retroiluminación.

menu:
tipo: cadena
Acción que muestra el menú.

menu-file:
tipo: cadena
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: booleano
predeterminado: falso
Permite que este módulo consuma todo el espacio sobrante dinámicamente.

EJEMPLO:

"backlight": {
	"device": "intel_backlight",
	"format": "{percent}% {icon}",
	"format-icons": ["", ""]
}
