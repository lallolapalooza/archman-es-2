NOMBRE

waybar - módulo wlr-taskbar

DESCRIPCIÓN

El módulo taskbar muestra las aplicaciones abiertas actualmente. Este módulo requiere un compositor que implemente la interfaz foreign-toplevel-manager.

CONFIGURACIÓN

Abordado por wlr/taskbar

all-outputs:
tipo: bool
predeterminado: false
Si se establece en false, se mostrarán las aplicaciones en la salida actual de waybar. De lo contrario, se mostrarán todas las aplicaciones.

format:
tipo: string
predeterminado: {icon}
El formato, cómo se debe mostrar la información.

icon-theme:
tipo: array|string
Los nombres de los temas de iconos que se deben utilizar para encontrar un icono. La lista se recorrerá de izquierda a derecha. Si se omite, se utilizará el predeterminado del sistema.

icon-size:
tipo: integer
predeterminado: 16
El tamaño del icono.

markup:
tipo: bool
predeterminado: false
Si se establece en true, se aceptarán etiquetas pango en format y tooltip-format.

tooltip:
tipo: bool
predeterminado: true
Si se establece en false, no se mostrará ninguna tooltip.

tooltip-format:
tipo: string
predeterminado: {title}
El formato, cómo se debe mostrar la información en la tooltip.

active-first:
tipo: bool
predeterminado: false
Si se establece en true, siempre se reordenarán las tareas en la barra de tareas para que la activa actualmente sea la primera. De lo contrario, no se reordenarán.

sort-by-app-id:
tipo: bool
predeterminado: false
Si se establece en true, se agruparán las tareas por su app_id. No se puede usar con 'active-first'.

on-click:
tipo: string
La acción que se activará al hacer clic en el botón de la aplicación con el botón izquierdo del ratón.

on-click-middle:
tipo: string
La acción que se activará al hacer clic en el botón de la aplicación con el botón central del ratón.

on-click-right:
tipo: string
La acción que se activará al hacer clic en el botón de la aplicación con el botón derecho del ratón.

on-update:
tipo: string
Comando a ejecutar cuando se actualice el módulo.

ignore-list:
tipo: array
Lista de app_id/títulos para que sean invisibles.

app_ids-mapping:
tipo: object
Diccionario de app_id a reemplazar con

rewrite:
tipo: object
Reglas para reescribir la salida del formato del módulo. Ver reglas de rewrite.

REEMPLAZOS DE FORMATO

{icon}: El icono de la aplicación.

{name}: El nombre de la aplicación como en el archivo de escritorio si se encuentran los archivos de escritorio apropiados, de lo contrario es igual a {app_id}

{title}: El título de la aplicación.

{app_id}: El app_id (== nombre de la aplicación) de la aplicación.

{state}: El estado (minimizado, maximizado, activo, pantalla completa) de la aplicación.

{short_state}: El estado (minimizar == m, maximizado == M, activo == A, pantalla completa == F) representado como un carácter de la aplicación.

ACCIONES DE CLIC

activate: Traer la aplicación al primer plano.

minimize: Alternar el estado minimizado de la aplicación.

minimize-raise: Traer la aplicación al primer plano o alternar su estado minimizado.

maximize: Alternar el estado maximizado de la aplicación.

fullscreen: Alternar el estado de pantalla completa de la aplicación.

close: Cerrar la aplicación.

REGLAS DE REESCRITURA

rewrite es un objeto donde las claves son expresiones regulares y los valores son reglas de reescritura si la expresión coincide. Las reglas pueden contener referencias a las capturas de la expresión.

La expresión regular y el reemplazo siguen las reglas de ECMA-script.

Si ninguna expresión coincide, la salida del formato se deja sin cambios.

Las expresiones inválidas (por ejemplo, paréntesis no coincidentes) se omiten.

EJEMPLOS

"wlr/taskbar": {
	"format": "{icon}",
	"icon-size": 14,
	"icon-theme": "Numix-Circle",
	"tooltip-format": "{title}",
	"on-click": "activate",
	"on-click-middle": "close",
	"ignore-list": [
	    "Alacritty"
	],
	"app_ids-mapping": {
		"firefoxdeveloperedition": "firefox-developer-edition"
	},
	"rewrite": {
		"Firefox Web Browser": "Firefox",
		"Foot Server": "Terminal"
	}
}
