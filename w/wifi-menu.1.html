NOMBRE

wifi-menu - Conectar interactivamente a una red inalámbrica

SINOPSIS

wifi-menu [-o | --obscure] [INTERFACE]

wifi-menu [-h | --help]

DESCRIPCIÓN

wifi-menu permite conectar interactivamente a una red inalámbrica en INTERFACE usando un perfil de netctl. En caso de no estar disponible ningún perfil de netctl, se puede generar uno. Si solo hay una interfaz inalámbrica disponible, INTERFACE puede omitirse.

wifi-menu solo es capaz de generar perfiles de netctl para configuraciones de red simples. Los perfiles para configuraciones más complejas deben configurarse manualmente. Ver netctl.profile(5) para más información.

OPCIONES

-h, --help

Muestra un breve texto de ayuda y sale.

-o, --obscure

Muestra asteriscos para los caracteres de la contraseña y almacena la contraseña como una clave precompartida hexadecimal.

INTERFACE

La interfaz de red inalámbrica a usar para conectar.

ESTADO DE SALIDA

0

La interfaz se conectó a la red inalámbrica exitosamente.

1

El intento de conexión fue cancelado.

2

El intento de conexión falló.

3

No se encontraron redes inalámbricas.

4

Longitud de contraseña no válida (las claves WEP deben tener entre 8 y 63 caracteres de longitud).

7

Se recibió un código de error inesperado.

255

El comando fue inválido o el intento de conexión fue abortado.

NOTAS

Establecer una conexión puede tardar un minuto. Mientras se establece una conexión, no se muestra nada en pantalla.

Iniciar una conexión en una interfaz controlada por netctl-auto hará que wifi-menu cambie a la red seleccionada. La interfaz continuará siendo controlada por netctl-auto.

ENTORNO

$NETCTL_DEBUG

Si se establece en "yes", se generará salida de depuración.

ARCHIVOS

/etc/netctl

Directorio donde se almacenan los perfiles generados.

VER TAMBIÉN

netctl(1), netctl-auto(1)
