struct wl_resource * wl_resource_create (struct wl_client * cliente, const struct wl_interface * interfaz, int versión, uint32_t id)

Crea un nuevo objeto de recurso.

Parámetros

cliente El cliente propietario del nuevo recurso.
interfaz La interfaz del nuevo recurso.
versión La versión del nuevo recurso.
id El ID del nuevo recurso. Si es 0, se usará un ID disponible.

Los escuchadores añadidos con wl_client_add_resource_created_listener serán notificados al final de esta función.

const char * wl_resource_get_class (const struct wl_resource * recurso)

Recupera el nombre de la interfaz (clase) de un objeto de recurso.

Parámetros

recurso El objeto de recurso.

const struct wl_interface * wl_resource_get_interface (struct wl_resource * recurso)

Obtiene la interfaz de un objeto de recurso.

Parámetros

recurso El objeto de recurso.

Retorna

La interfaz del objeto asociado al recurso.
