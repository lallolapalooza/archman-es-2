NOMBRE

webcheckout - descargar repositorios referenciados en una página web

SINOPSIS

webcheckout [opciones] url [directorio_destino]

DESCRIPCIÓN

webcheckout descarga una url y la analiza, buscando repositorios de control de versiones referenciados por la página. Descarga cada repositorio en un subdirectorio del directorio actual, utilizando el programa VCS apropiado para ese repositorio (git, svn, etc.).

La información sobre los repositorios está incrustada en la página web utilizando el microformato rel=vcs-*, que está documentado en https://joeyh.name/rfc/rel-vcs/.

Si se especifica el parámetro opcional directorio_destino, se pedirá a los programas VCS que descarguen los repositorios en ese directorio. Si hay múltiples repositorios para descargar, cada uno se descargará en un subdirectorio separado del directorio_destino.

OPCIONES

-a, --auth
Prefiere repositorios autenticados. Por defecto, webcheckout utilizará repositorios anónimos cuando sea posible. Si tiene una cuenta que le permite usar repositorios autenticados, es posible que desee usar esta opción.
--no-act, -n
No descargar nada realmente, solo imprimir los comandos que se ejecutarían para descargar los repositorios.
--quiet, -q
Modo silencioso. No imprimir los comandos que se ejecutan. (Sin embargo, los comandos VCS pueden seguir siendo ruidosos).

PRERREQUISITOS

Para usar este programa necesitará muchos programas VCS instalados, obviamente. También depende de los módulos perl LWP y HTML::Parser.

Si está instalado el módulo perl URI, webcheckout puede adivinar heurísticamente lo que quiere decir con URLs parciales, como "kitenet.net/~joey"
