NAME

wpa_cli - Cliente de línea de comandos de WPA

SYNOPSIS

wpa_cli [ -p ruta a sockets de control ] [ -g ruta al socket global ctrl_interface ] [ -i nombre de interfaz ] [ -hvB ] [ -a archivo de acción ] [ -P archivo de PID ] [ -G intervalo de ping ] [ comando ... ]

DESCRIPCIÓN GENERAL

wpa_cli es un programa frontend basado en texto para interactuar con wpa_supplicant. Se utiliza para consultar el estado actual, cambiar la configuración, activar eventos y solicitar entrada interactiva del usuario.

wpa_cli puede mostrar el estado de autenticación actual, el modo de seguridad seleccionado, MIBs dot11 y dot1x, etc. Además, puede configurar algunas variables como parámetros de la máquina de estados EAPOL y activar eventos como la reasociación y el cierre/inicio de sesión IEEE 802.1X. wpa_cli proporciona una interfaz de usuario para solicitar información de autenticación, como nombre de usuario y contraseña, si estos no se incluyen en la configuración. Esto se puede utilizar para implementar, por ejemplo, contraseñas de un solo uso o autenticación genérica basada en tarjeta de tokens, donde la autenticación se basa en un desafío-respuesta que utiliza un dispositivo externo para generar la respuesta.

La interfaz de control de wpa_supplicant se puede configurar para permitir el acceso de usuarios no root (parámetro ctrl_interface GROUP= en el archivo de configuración). Esto hace posible ejecutar wpa_cli con una cuenta de usuario normal.

wpa_cli soporta dos modos: interactivo y línea de comandos. Ambos modos comparten el mismo conjunto de comandos y la principal diferencia es que el modo interactivo proporciona acceso a mensajes no solicitados (mensajes de eventos, solicitudes de nombre de usuario/contraseña).

El modo interactivo se inicia cuando se ejecuta wpa_cli sin incluir el comando como parámetro de línea de comandos. Los comandos se introducen entonces en el prompt de wpa_cli. En el modo de línea de comandos, los mismos comandos se introducen como argumentos de línea de comandos para wpa_cli.

SOLICITUD INTERACTIVA DE PARÁMETROS DE AUTENTICACIÓN

Cuando wpa_supplicant necesita parámetros de autenticación, como nombre de usuario y contraseña, que no están presentes en el archivo de configuración, envía un mensaje de solicitud a todos los programas frontend conectados, por ejemplo, wpa_cli en modo interactivo. wpa_cli muestra estas solicitudes con el prefijo "CTRL-REQ-<tipo>-<id>:<texto>". <tipo> es IDENTITY, PASSWORD, u OTP (contraseña de un solo uso). <id> es un identificador único para la red actual. <texto> es una descripción de la solicitud. En caso de solicitud OTP, incluye el desafío del servidor de autenticación.

La respuesta a estas solicitudes se puede dar con los comandos identity, password y otp. Se necesita copiar el <id> de la solicitud coincidente. Los comandos password y otp se pueden usar independientemente de si la solicitud era para PASSWORD u OTP. La principal diferencia entre estos dos comandos es que los valores proporcionados con password se recuerdan mientras wpa_supplicant esté en ejecución, mientras que los valores proporcionados con otp solo se usan una vez y luego se olvidan, es decir, wpa_supplicant solicitará al frontend un nuevo valor para cada uso. Esto se puede utilizar para implementar listas de contraseñas de un solo uso y autenticación genérica basada en tarjetas de tokens.

Ejemplo de solicitud de contraseña y respuesta coincidente:

CTRL-REQ-PASSWORD-1:Se necesita contraseña para SSID foobar
> password 1 mi_contraseña_secreta

Ejemplo de solicitud de desafío-respuesta genérico de tarjeta de token:

CTRL-REQ-OTP-2:Se necesita desafío 1235663 para SSID foobar
> otp 2 9876

ARGUMENTOS DE COMANDOS

-p ruta
Cambia la ruta donde se deben encontrar los sockets de control.
-g ruta del socket de control
Conecta al socket de control global en la ruta indicada en lugar de un socket de control específico de la interfaz.
-i nombre de interfaz
Especifica la interfaz que se está configurando. Por defecto, elige la primera interfaz encontrada con un socket de control en la ruta del socket.
-h
Ayuda. Muestra un mensaje de uso.
-v
Muestra información de la versión.
-B
Ejecutar como demonio en segundo plano.
-a archivo
Ejecutar en modo demonio ejecutando el archivo de acción basado en eventos de wpa_supplicant. El archivo especificado se ejecutará con el primer argumento establecido en el nombre de la interfaz y el segundo en "CONNECTED" o "DISCONNECTED" dependiendo del evento. Esto se puede utilizar para ejecutar herramientas de red necesarias para configurar la interfaz.

Adicionalmente, tres variables de entorno están disponibles para el archivo: WPA_CTRL_DIR, WPA_ID y WPA_ID_STR. WPA_CTRL_DIR contiene la ruta absoluta al socket ctrl_interface. WPA_ID contiene el identificador único network_id asignado a la red activa, y WPA_ID_STR contiene el contenido de la opción id_str.

-P archivo
Establece la ubicación del archivo PID.
-G intervalo de ping
Establece el intervalo (en segundos) en el que wpa_cli hace ping al supplicant.
comando
Ejecuta un comando. Los comandos disponibles se listan en la siguiente sección.

COMANDOS

Los siguientes comandos están disponibles:

status
obtener el estado actual de WPA/EAPOL/EAP
mib
obtener variables MIB (dot1x, dot11)
help
mostrar esta ayuda de uso
interface [nombre de interfaz]
mostrar interfaces/seleccionar interfaz
level <nivel de depuración>
cambiar el nivel de depuración
license
mostrar la licencia completa de wpa_cli
logoff
cierre de sesión de la máquina de estados EAPOL IEEE 802.1X
logon
inicio de sesión de la máquina de estados EAPOL IEEE 802.1X
set
establecer variables (muestra la lista de variables cuando se ejecuta sin argumentos)
pmksa
mostrar caché PMKSA
reassociate
forzar reasociación
reconfigure
forzar a wpa_supplicant a releer su archivo de configuración
preauthenticate <BSSID>
forzar preautenticación
identity <id de red> <identidad>
configurar identidad para un SSID
password <id de red> <contraseña>
configurar contraseña para un SSID
pin <id de red> <pin>
configurar PIN para un SSID
otp <id de red> <contraseña>
configurar contraseña de un solo uso para un SSID
bssid <id de red> <BSSID>
establecer BSSID preferido para un SSID
list_networks
listar redes configuradas
terminate
terminar wpa_supplicant
quit
salir de wpa_cli
