wikicurses(1) Manual de Comandos Generales wikicurses(1)

NOMBRE

wikicurses - interfaz de curses para MediaWiki

SINOPSIS

wikicurses [-h] [--wiki WIKI] [-d | -f | -p] [búsqueda]

CONTROLES

General

j o flecha abajo

Desplazar hacia abajo

k o flecha arriba

Desplazar hacia arriba

^b o página abajo

Desplazar una página hacia abajo

^f o página arriba

Desplazar una página hacia arriba

g o inicio

Desplazar al principio

G o fin

Desplazar al final

Paginador

c

Abrir tabla de contenidos

o

Abrir cuadro de búsqueda

q o :q[uit]

Salir

:bmark

Marcar página como favorita

:bmarks

Abrir marcadores

:links

Abrir lista de enlaces internos de la página

:iwlinks

Abrir lista de enlaces interwiki de la página

:extlinks

Abrir lista de enlaces externos de la página para abrir en el navegador

:langs

Abrir lista de idiomas en los que está disponible el artículo

:wikis

Abrir lista de wikis configurados, ver wikicurses.conf(5)

:feeds

Abrir una lista de feeds destacados en la wiki actual

:clearcache

Limpia la caché; salir del programa tiene un efecto equivalente

:edit

Editar página de wiki (se abre en $EDITOR)

:help

Mostrar página del manual

:back, h, o flecha izquierda

Retroceder en el historial

:forward, l, o flecha derecha

Avanzar en el historial

:random

Ir a una página aleatoria

/

Buscar página y resaltar texto coincidente. Soporta expresiones regulares.

Menú de Marcadores

x o delete

Eliminar marcador seleccionado

u

Deshacer eliminación

Búsqueda

tab

Autocompletado para el título de la página

OPCIONES

-h, --help

Mostrar mensaje de ayuda

-w, --wiki <wiki>

URL o nombre de la wiki a utilizar

-f, --feed <nombre>

ver feed destacado

--dumpcolors

escribir la configuración de color actual en el archivo de configuración

CONFIGURACIÓN DE COLOR

Para usar colores distintos a los predeterminados, necesitas un archivo llamado ~/.config/wikicurses/colors. Para crear este archivo con la configuración de color actual, ejecuta wikicurses --dumpcolors. Este es un archivo de configuración que contiene varias cosas que se pueden colorear. Cada una permite configurar ajustes de pantalla (negrita, subrayado o destacado), color de primer plano, color de fondo y alineación de texto. Se pueden configurar múltiples ajustes separando con espacios. Las opciones de color son las mismas que en urwid (ver http://urwid.org/manual/displayattributes.html).

VARIABLES DE ENTORNO

HOME, XDG_CONFIG_HOME

Determina dónde buscar y almacenar los archivos de configuración.

EDITOR

El nombre del comando a usar como editor de texto, por defecto es vim.

BROWSER

El nombre del comando a usar como navegador web, por defecto es lynx.

EJEMPLOS

wikicurses Wiki

Buscar "Wiki" en la wiki predeterminada

wikicurses -w ArchWiki Dwm

Buscar "Dwm" en la Wiki de Archlinux, donde "ArchWiki" está configurado en wikicurses.conf(5)

wikicurses -w http://en.wiktionary.org/w/api.php penguin

Buscar "penguin" en Wiktionary

wikicurses -f potd

Abrir feed "potd" (Imagen del Día)
