waybar-sndio(5) Manual de formatos de archivo waybar-sndio(5)

NOMBRE

waybar - módulo sndio

DESCRIPCIÓN

El módulo sndio muestra el volumen actual reportado por sndio(7).

Adicionalmente, puedes controlar el volumen desplazándote hacia arriba o abajo mientras el cursor está sobre el módulo, y haciendo clic en el módulo se activa/desactiva el silencio.

CONFIGURACIÓN

format:
tipo: string
predeterminado: {volume}%
El formato de cómo se debe mostrar la información.

rotate:
tipo: integer
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

max-length:
tipo: integer
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
tipo: integer
La longitud mínima en caracteres que el módulo debe aceptar.

align:
tipo: float
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: string
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir el posicionamiento.

scroll-step:
tipo: int
predeterminado: 5
La velocidad a la que se cambiará el volumen al desplazarse.

on-click:
tipo: string
Comando a ejecutar cuando se hace clic en el módulo.

Esto reemplaza el comportamiento predeterminado de activar/desactivar el silencio.

on-click-middle:
tipo: string
Comando a ejecutar cuando se hace clic con el botón central del ratón en el módulo.

on-click-right:
tipo: string
Comando a ejecutar cuando se hace clic con el botón derecho en el módulo.

on-update:
tipo: string
Comando a ejecutar cuando el módulo se actualiza.

on-scroll-up:
tipo: string
Comando a ejecutar al desplazarse hacia arriba en el módulo.
Esto reemplaza el comportamiento predeterminado de control de volumen.

on-scroll-down:
tipo: string
Comando a ejecutar al desplazarse hacia abajo en el módulo.
Esto reemplaza el comportamiento predeterminado de control de volumen.

smooth-scrolling-threshold:
tipo: double
Umbral a utilizar al desplazarse.

menu:
tipo: string
Acción que muestra el menú.

menu-file:
tipo: string
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: bool
predeterminado: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

{volume}: Volumen en porcentaje.

{raw_value}: Volumen como valor reportado por sndio.

EJEMPLOS

"sndio": {
	"format": "{raw_value} 🎜",
	"scroll-step": 3
}
