WAYLOCK(1) Manual de Comandos Generales WAYLOCK(1)

NOMBRE

waylock - un pequeño bloqueador de pantalla para Wayland

SINOPSIS

waylock [opciones]

DESCRIPCIÓN

Waylock es un pequeño bloqueador de pantalla para compositores Wayland que implementan ext-session-lock-v1. El protocolo ext-session-lock-v1 es significativamente más robusto que los enfoques anteriores de bloqueo de pantalla de Wayland del lado del cliente. Es importante destacar que el bloqueo de pantalla que falla no provoca que la sesión se desbloquee.

OPCIONES

-h

Muestra un mensaje de ayuda y sale.

-version

Muestra el número de versión y sale.

-log-level [error|warning|info|debug]

Establece el nivel de registro de waylock. En el nivel de registro error, solo se registran los errores. En el nivel de registro debug, se registra todo, incluidos los mensajes de depuración detallados.

-fork-on-lock

Se bifurca en segundo plano después de bloquear la sesión. Esto es útil para integrarse con demonios de gestión de inactividad sin competir para bloquear la sesión antes de la suspensión. Con esta opción, waylock saldrá una vez que la sesión se haya bloqueado y sea seguro suspender.

-ready-fd fd

Escribe una nueva línea en el descriptor de archivo fd (un número) después de bloquear y cierra el fd. Esto es útil si se necesita una notificación de bloqueo sin bifurcación; por ejemplo, para integración con un gestor de servicios.

-ignore-empty-password

No envía contraseñas vacías a PAM para su validación cuando se presiona la tecla Enter. En su lugar, no hace nada. Esto puede ser útil si, por ejemplo, la tecla Enter se usa para despertar el ordenador de la suspensión.

-init-color 0xRRGGBB

Establece el color inicial. (predeterminado: 0x002b36)

-input-color 0xRRGGBB

Establece el color utilizado después de la entrada. (predeterminado: 0x6c71c4)

-input-alt-color 0xRRGGBB

Establece el color alternativo utilizado después de la entrada. (el predeterminado es lo que se establece en -input-color)

-fail-color 0xRRGGBB

Establece el color utilizado en caso de fallo de autenticación. (predeterminado: 0xdc322f)

USO

Ejecuta el ejecutable waylock para bloquear la sesión. Todos los monitores se quedarán en blanco con el -init-color. Escribir hace que el color cambie a -input-color. Si se establece -input-alt-color, el color de escritura alternará entre este y el anterior. Esc o Ctrl-U borran toda la entrada actual, mientras que retroceso elimina el último punto de código UTF-8.

Para desbloquear la sesión, escribe tu contraseña y pulsa Enter. Si la contraseña es correcta, waylock desbloqueará la sesión y saldrá. De lo contrario, el color cambiará a -fail-color y podrás intentarlo de nuevo.

Para ejecutar automáticamente waylock después de un cierto tiempo sin entrada o antes de dormir, se puede utilizar la utilidad swayidle(1) o un programa similar. Consulte la página del manual de swayidle(1) para obtener detalles.
