NOMBRE

wander - paseo aleatorio colorido.

SINOPSIS

wander [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id número] [--density número] [--reset número] [--length número] [--delay número] [--circles] [--size número] [--advance número] [--fps]

DESCRIPCIÓN

Dibuja un paseo aleatorio colorido, en varias formas.

OPCIONES

--visual visual
Especifica qué visual usar. Los valores válidos son el nombre de una clase visual o el número de id (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--density número
Densidad. 1 - 30. Valor predeterminado: 2.
--reset número
Número de fotogramas antes de reiniciar. Valor predeterminado: 2500000.
--length número
Número de iteraciones. Valor predeterminado: 25000.
--delay número
Sostenimiento. 0 - 60. Valor predeterminado: 1.
--circles | --no-circles
Si dibujar puntos.
--size número
Tamaño. 0 - 100. Valor predeterminado: 1.
--advance número
Contraste de color. 1 - 100. Valor predeterminado: 1.
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
