waybar-network(5) Manual de formatos de archivo waybar-network(5)

NOMBRE

waybar - módulo de red

DESCRIPCIÓN

El módulo network muestra información sobre las conexiones de red actuales.

CONFIGURACIÓN

Abordado por network

interface:
tipo: string
Utiliza la interfaz definida en lugar de la detección automática. Acepta comodines.

rfkill:
tipo: bool
valor por defecto: true
Si está habilitado, se usará el formato disabled cuando rfkill esté bloqueando las interfaces wlan.

interval:
tipo: integer
valor por defecto: 60
El intervalo en el que se consulta la información de red (por ejemplo, intensidad de la señal).

family:
tipo: string
valor por defecto: ipv4
La familia de direcciones que se utiliza para el reemplazo de formato {ipaddr} y para determinar si hay una conexión de red presente. Establécelo a ipv4_6 para mostrar ambas.

format:
tipo: string
valor por defecto: {ifname}
El formato, cómo se debe mostrar la información. Este formato se utiliza cuando no se especifican otros formatos.

format-ethernet:
tipo: string
Este formato se utiliza cuando se muestra una interfaz ethernet.

format-wifi:
tipo: string
Este formato se utiliza cuando se muestra una interfaz inalámbrica.

format-linked:
tipo: string
Este formato se utiliza cuando se muestra una interfaz enlazada sin dirección IP.

format-disconnected:
tipo: string
Este formato se utiliza cuando la interfaz mostrada está desconectada.

format-disabled:
tipo: string
Este formato se utiliza cuando rfkill está bloqueando las interfaces wlan.

format-icons:
tipo: array/object
Según la intensidad de la señal actual, se selecciona el icono correspondiente.
El orden es de baja a alta. O por el estado si es un objeto.

rotate:
tipo: integer
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

max-length:
tipo: integer
La longitud máxima en caracteres que debe mostrar el módulo.

min-length:
tipo: integer
La longitud mínima en caracteres que debe aceptar el módulo.

align:
tipo: float
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: string
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir la posición.

on-click:
tipo: string
Comando a ejecutar al hacer clic en el módulo.

on-click-middle:
tipo: string
Comando a ejecutar al hacer clic con la rueda del ratón en el módulo.

on-click-right:
tipo: string
Comando a ejecutar al hacer clic derecho en el módulo.

on-update:
tipo: string
Comando a ejecutar cuando se actualiza el módulo.

on-scroll-up:
tipo: string
Comando a ejecutar al desplazarse hacia arriba en el módulo.

on-scroll-down:
tipo: string
Comando a ejecutar al desplazarse hacia abajo en el módulo.

smooth-scrolling-threshold:
tipo: double
Umbral a utilizar al desplazarse.

tooltip:
tipo: bool
valor por defecto: true
Opción para deshabilitar la información emergente al pasar el ratón por encima.

tooltip-format:
tipo: string
El formato, cómo se debe mostrar la información en la información emergente. Este formato se utiliza cuando no se especifican otros formatos.

tooltip-format-ethernet:
tipo: string
Este formato se utiliza cuando se muestra una interfaz ethernet.

tooltip-format-wifi:
tipo: string
Este formato se utiliza cuando se muestra una interfaz inalámbrica.

tooltip-format-disconnected:
tipo: string
Este formato se utiliza cuando la interfaz mostrada está desconectada.

tooltip-format-disabled:
tipo: string
Este formato se utiliza cuando rfkill está bloqueando las interfaces wlan.

menu:
tipo: string
Acción que muestra el menú.

menu-file:
tipo: string
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: bool
valor por defecto: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

{ifname}: Nombre de la interfaz de red.

{ipaddr}: La primera IP de la interfaz.

{gwaddr}: La puerta de enlace predeterminada para la interfaz.

{netmask}: La máscara de subred correspondiente a la IP (V4).

{netmask6}: La máscara de subred correspondiente a la IP (V6).

{cidr}: La máscara de subred correspondiente a la IP (V4) en notación CIDR.

{cidr6}: La máscara de subred correspondiente a la IP (V6) en notación CIDR.

{essid}: Nombre (SSID) de la red inalámbrica.

{bssid}: Dirección MAC (BSSID) del punto de acceso inalámbrico.

{signalStrength}: Intensidad de la señal de la red inalámbrica.

{signaldBm}: Intensidad de la señal de la red inalámbrica en dBm.

{frequency}: Frecuencia de la red inalámbrica en GHz.

{bandwidthUpBits}: Velocidad de subida instantánea en bits/segundo.

{bandwidthDownBits}: Velocidad de bajada instantánea en bits/segundo.

{bandwidthTotalBits}: Velocidad total instantánea en bits/segundo.

{bandwidthUpOctets}: Velocidad de subida instantánea en octetos/segundo.

{bandwidthDownOctets}: Velocidad de bajada instantánea en octetos/segundo.

{bandwidthTotalOctets}: Velocidad total instantánea en octetos/segundo.

{bandwidthUpBytes}: Velocidad de subida instantánea en bytes/segundo.

{bandwidthDownBytes}: Velocidad de bajada instantánea en bytes/segundo.

{bandwidthTotalBytes}: Velocidad total instantánea en bytes/segundo.

{icon}: Icono, tal como se define en format-icons.

EJEMPLOS

"network": {
	"interface": "wlp2s0",
	"format": "{ifname}",
	"format-wifi": "{essid} ({signalStrength}%) ",
	"format-ethernet": "{ifname} ",
	"format-disconnected": "", //Un formato vacío ocultará el módulo.
	"format-disconnected": "",
	"tooltip-format": "{ifname}",
	"tooltip-format-wifi": "{essid} ({signalStrength}%) ",
	"tooltip-format-ethernet": "{ifname} ",
	"tooltip-format-disconnected": "Desconectado",
	"max-length": 50
}

network(5) – waybar module manual

NAME

waybar-network(5) – waybar network module

DESCRIPTION

The network module displays information about network connections. This module is used to display information about the current network status. It is configured in the modules section of the waybar configuration file.

CONFIGURATION

The network module can be configured with the following options:

  • format: The format string for the module. This string can contain format replacements. Default: "{state;icon}"
  • format-alt: The format string for the module when the network is disconnected. Default: "{state;icon}"
  • format-ethernet: The format string for the module when connected via ethernet. Default: "�� {ipaddr;}"
  • format-wifi: The format string for the module when connected via wifi. Default: " {essid} ({signalStrength}%)"
  • tooltip: Whether to display a tooltip when hovering over the module. Default: true
  • tooltip-format: The format string for the tooltip. This string can contain format replacements. Default: "{ipaddr}
    {ifname}
    {macaddr}"
  • max-length: The maximum length of the module's label. Default: 30
  • state: Whether to display the network state. Default: true
  • state-connected: The icon to display when connected. Default: ""
  • state-disconnected: The icon to display when disconnected. Default: "��"

FORMAT REPLACEMENTS

The following format replacements are available:

  • {state}: The current network state (connected/disconnected).
  • {state;icon}: The icon for the current network state.
  • {ipaddr}: The IP address of the current connection.
  • {ssid}: The SSID of the current wifi connection.
  • {signalStrength}: The signal strength of the current wifi connection.
  • {ifname}: The name of the network interface.
  • {macaddr}: The MAC address of the network interface.

EXAMPLES

An example configuration for the network module:

"modules-left": ["network"],

"network": {
    "format": "{state;icon}",
    "state-connected": "",
    "state-disconnected": "��"
}

STYLE

The network module can be styled with the following CSS classes:

  • #network: The main container for the network module.
  • #network.connected: Applied when the network is connected.
  • #network.disconnected: Applied when the network is disconnected.
