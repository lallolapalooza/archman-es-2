NOMBRE

winegcc - Compilador compatible con MinGW de C y C++ de Wine

SINOPSIS

winegcc [opciones] infile...

DESCRIPCIÓN

winegcc es un envoltorio de gcc que intenta proporcionar un compilador compatible con MinGW bajo Linux. Esto es muy útil para los desarrolladores de Win32 que pueden simplemente tomar su código MinGW de Windows y recompilarlo sin modificaciones bajo Winelib en Linux. wineg++ acepta la mayoría de las mismas opciones que winegcc.

El objetivo de winegcc es poder reemplazar simplemente gcc/g++/windres con winegcc/wineg++/wrc en un Makefile de MinGW, y simplemente recompilar la aplicación usando Winelib bajo Wine. Si bien normalmente hay pequeños ajustes que deben hacerse en el código fuente de la aplicación y/o en el Makefile, es muy fácil hacerlos de una manera que sea compatible entre los entornos MinGW y Wine.

Este manual solo documentará las diferencias con gcc; consulte el manual de gcc para obtener más información sobre esas opciones.

OPCIONES

Opciones de gcc: Todas las opciones de gcc son compatibles y se pasan al compilador backend.

-b,--objetivo objetivo
Especifica el triple de arquitectura de destino para la compilación cruzada. winegcc invocará entonces objetivo-gcc en lugar de gcc.
--wine-objdir dir
Especifica el directorio de objetos de Wine. Esto se usa al compilar el propio Wine, para usar las inclusiones y bibliotecas del árbol de compilación.
--winebuild nombre
Especifica la ruta y el nombre del binario winebuild que será lanzado automáticamente por winegcc. Si no se establece, winegcc buscará un archivo llamado winebuild en la ruta. Esto tiene prioridad sobre la variable de entorno WINEBUILD.
-fno-short-wchar
Anula el tipo subyacente para wchar_t al valor predeterminado para el objetivo, en lugar de usar unsigned int corto, que es el valor predeterminado para Win32.
-mconsole
Esta opción pasa '--subsystem console' a winebuild, para compilar aplicaciones de consola. Es el valor predeterminado.
-mno-cygwin
Utiliza la implementación de MSVCRT de Wine, en lugar de enlazar contra la libc del sistema anfitrión. Esto es necesario para la gran mayoría de las aplicaciones Win32, ya que típicamente dependen de varias características de MSVCRT. Este interruptor también es utilizado por el compilador MinGW para enlazar contra MSVCRT en Windows, en lugar de enlazar contra la libc de Cygwin. Compartir la sintaxis con MinGW hace que sea muy fácil escribir Makefiles que funcionen bajo Wine, MinGW+MSYS o MinGW+Cygwin.
-municode
Establece el punto de entrada predeterminado de la aplicación en wmain() Unicode en lugar de main() estándar.
-mwindows
Esta opción agrega -lgdi32, -lcomdlg32 y -lshell32 a la lista de bibliotecas predeterminadas, y pasa '--subsystem windows' a winebuild para compilar aplicaciones gráficas.
-nodefaultlibs
No utilice las bibliotecas del sistema estándar al enlazar. Estas incluyen como mínimo -lkernel32, -luser32, -ladvapi32 y cualquier biblioteca predeterminada utilizada por el compilador backend. La opción -mwindows aumenta la lista de bibliotecas predeterminadas como se describe arriba.
-nostartfiles
No agregue la biblioteca winecrt0 al enlazar.
-Wb,opción
Pasa una opción a winebuild. Si opción contiene comas, se divide en múltiples opciones en las comas.
-Wl,--out-implib,lib.a
Al enlazar una dll, también cree su biblioteca de importación correspondiente.

AMBIENTE

WINEBUILD
Especifica la ruta y el nombre del binario winebuild que será lanzado automáticamente por winegcc. Si no se establece, winegcc buscará un archivo llamado winebuild en la ruta.

DEFINICIONES

winegcc define __WINE__, para código que necesita saber cuándo se está compilando bajo Wine. También define WIN32, _WIN32, __WIN32, __WIN32__, __WINNT y __WINNT__ para compatibilidad con MinGW.

ERRORES

Los atributos dllimport/dllexport no son compatibles en este momento, debido a la falta de soporte para estas características en la versión ELF de gcc.

El enlace estático no es compatible actualmente con las DLL de Wine. Como resultado, las opciones -static, --static y -Wl,-static generarán un error.

Los errores pueden ser reportados en el rastreador de errores de Wine.

DISPONIBILIDAD
