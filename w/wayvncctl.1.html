wayvncctl(1) Manual de comandos generales wayvncctl(1)

NOMBRE

wayvncctl - Un cliente de control de línea de comandos para wayvnc(1)

SINOPSIS

wayvncctl [opciones] [comando [--parámetro valor ...]]

OPCIONES

-S, --socket=<ruta>

Establece la ruta del socket de control de wayvnc. Por defecto: $XDG_RUNTIME_DIR/wayvncctl o /tmp/wayvncctl-$UID

-w, --wait

Espera a que wayvnc se inicie si aún no se está ejecutando. Por defecto: Sal inmediatamente con un error si wayvnc no está ejecutándose.

-r,--reconnect

Si se desconecta mientras espera eventos, espera a que wayvnc se reinicie y se vuelva a registrar para recibir eventos. Por defecto: Sal cuando wayvnc finalice.

-j, --json

Produce salida JSON a stdout.

-V, --version

Muestra información de la versión.

-v,--verbose

Sea más detallado.

-h, --help

Obtiene ayuda sobre el propio comando wayvncctl (enumera estas opciones). No se conecta al socket de control de wayvncctl.

DESCRIPCIÓN

wayvnc(1) permite la interacción en tiempo de ejecución a través de un mecanismo json-ipc de socket unix. Esta utilidad de línea de comandos proporciona una interacción fácil con esos comandos.

Este comando es en gran medida autodocumentado:

  • Ejecutar wayvncctl --help enumera todos los comandos IPC soportados.
  • Ejecutar wayvncctl nombre-comando --help devuelve una descripción del comando dado y sus parámetros disponibles.
  • Ejecutar wayvncctl event-receive --help incluye una lista de todos los nombres de eventos soportados.
  • Ejecutar wayvncctl event-receive --show=nombre-evento devuelve una descripción del evento dado y los campos de datos esperados.

EVENTOS ASÍNCRONOS

Mientras que wayvncctl normalmente termina después de enviar una solicitud y recibir la respuesta correspondiente, el comando event-receive actúa de manera diferente. En lugar de salir inmediatamente, wayvncctl espera cualquier evento del servidor, imprimiendo cada uno en stdout a medida que llegan. Este modo de operación se bloqueará hasta que reciba una señal para terminar, o hasta que el servidor wayvnc termine.

En modo --json, cada evento se imprime en una línea, con un carácter de nueva línea al final, para facilitar la creación de scripts:

$ wayvncctl --json event-receive
{"method":"client-connected","params":{"id":"0x10ef670","address":null,"username":null,"connection_count":1}}
{"method":"client-disconnected","params":{"id":"0x10ef670","address":null,"username":null,"connection_count":0}}

La salida legible por humanos por defecto es un formato multilinea similar a yaml, con dos caracteres de nueva línea entre cada evento:

$ wayvncctl event-receive
client-connected:
  id: 0x10ef670
  address: 192.168.1.18
  connection_count: 1
client-disconnected:
  id: 0x10ef670
  address: 192.168.1.18
  connection_count: 0

TIPOS DE EVENTOS LOCALES ESPECIALES

Especialmente útil cuando se utiliza el modo --wait o --reconnect, wayvncctl generará 2 eventos adicionales no documentados en wayvnc(1):

wayvnc-startup

Se envía cuando se establece una conexión de control de wayvnc exitosa y el registro de eventos se ha realizado correctamente, tanto al inicio como en registros posteriores con --reconnect.

Sin parámetros.

wayvnc-shutdown

Se envía cuando se desconecta la conexión de control de wayvnc, generalmente debido a que wayvnc está saliendo.

Sin parámetros.

EJEMPLOS

Obtener ayuda sobre el comando IPC "output-set":

$ wayvncctl output-set --help
Usage: wayvncctl [options] output-set <output-name> [params]
...

Ciclar a la siguiente salida activa:

$ wayvncctl output-cycle

Obtener información de la versión formateada en JSON:

$ wayvncctl --json version
{"wayvnc":"v0.5.0","neatvnc":"v0.5.1","aml":"v0.2.2"}

Un script que realiza una acción por cada evento de conexión y desconexión de cliente:

#!/bin/bash
connection_count_now() {
    echo "Total clients: $1"
}
while IFS= read -r EVT; do
    case "$(jq -r '.method' <<<"$EVT")" in
        client-*onnected)
            count=$(jq -r '.params.connection_count' <<<"$EVT")
            connection_count_now "$count"
            ;;
        wayvnc-shutdown)
            connection_count_now 0
	    ;;
    esac
done < <(wayvncctl --wait --reconnect --json event-receive)

ENTORNO

Las siguientes variables de entorno tienen un efecto en wayvncctl:

XDG_RUNTIME_DIR

Especifica la ubicación predeterminada para el socket de control de wayvncctl.
