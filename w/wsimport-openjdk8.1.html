wsimport(1) Herramientas de Servicios Web de Java wsimport(1)

NOMBRE

wsimport - Genera artefactos portátiles JAX-WS que se pueden empaquetar en un archivo de aplicación web (WAR) y proporciona una tarea de Ant.

SINOPSIS

wsimport [ opciones ] wsdl
opciones
Las opciones de línea de comandos. Ver Opciones.
wsdl
El archivo que contiene la descripción legible por máquina de cómo se puede llamar al servicio web, qué parámetros espera y qué estructuras de datos devuelve.

DESCRIPCIÓN

El comando wsimport genera los siguientes artefactos portátiles JAX-WS. Estos artefactos se pueden empaquetar en un archivo WAR junto con los documentos WSDL y de esquema, y la implementación del punto final para ser desplegada. El comando wsimport también proporciona una tarea de Ant wsimport, ver la pestaña Herramientas de la página Tarea de Ant de Wsimport en http://jax-ws.java.net/nonav/2.1.1/docs/wsimportant.html

•
Interfaz de Punto Final de Servicio (SEI)
•
Servicio
•
La clase de excepción se mapea desde wsdl:fault (si existe)
•
El Bean de Respuesta Asíncrona se deriva del wsdl:message de respuesta (si existe)
•
Tipos de valor generados por JAXB (clases Java mapeadas desde tipos de esquema)

Para iniciar el comando wsgen, haga lo siguiente:

Oracle Solaris/Linux:

/bin/wsimport.sh -help

Windows:

\bin\wsimport.bat -help

OPCIONES

-d directorio

Especifica dónde colocar los archivos de salida generados.
-b ruta

Especifica archivos de enlace JAX-WS o JAXB externos. Se pueden especificar múltiples archivos de enlace JAX-WS y JAXB con la opción -b. Puede utilizar estos archivos para personalizar nombres de paquetes, nombres de beans, etc. Para obtener más información sobre los archivos de enlace de JAX-WS y JAXB, consulte la sección de la Guía de Usuario de Personalización de WSDL en http://jax-ws.java.net/nonav/2.1.1/docs/wsimportant.html
-B opción_jaxb

Pasa la opción opción_jaxb al compilador de esquemas JAXB.
-catalog

Especifica un archivo de catálogo para resolver referencias de entidades externas. La opción -catalog admite los formatos TR9401, XCatalog y OASIS XML Catalog. Consulte la sección de la Guía de Usuario de Soporte de Catálogos en http://jax-ws.java.net/nonav/2.1.1/docs/catalog-support.html
-extension

Permite extensiones del proveedor. El uso de extensiones puede dar lugar a aplicaciones que no sean portátiles o que no funcionen con otras implementaciones.
-help

Muestra un mensaje de ayuda para el comando wsimport.
-httpproxy: host:puerto

Especifica un servidor proxy HTTP. El valor predeterminado es 8080.
-keep

Conserva los archivos generados.
-p nombre

Especifica un paquete de destino nombre para anular las personalizaciones de enlace WSDL y de esquema, y el algoritmo predeterminado definido en la especificación.
-s directorio

Especifica dónde colocar los archivos fuente generados.
-verbose

Muestra los mensajes del compilador.
-version

Imprime información de la versión.
-wsdllocation ubicación

Especifica el valor de @WebServiceClient.wsdlLocation.
-target

Genera código de acuerdo con la versión de especificación JAX-WS especificada. La versión 2.0 genera código compatible para la especificación JAX-WS 2.0.
-quiet

Suprime la salida del comando wsimport.

Se pueden especificar múltiples archivos de enlace JAX-WS y JAXB utilizando la opción -b, y se pueden usar para personalizar varias cosas, como nombres de paquetes y nombres de beans. Puede encontrar más información sobre los archivos de enlace JAX-WS y JAXB en la documentación de personalización en https://jax-ws.dev.java.net/nonav/2.1.1/docs/customizations.html

OPCIONES NO_ESTáNDAR

-XadditionalHeaders

Mapea cabeceras no enlazadas a un mensaje de solicitud o respuesta a parámetros de métodos Java.
-Xauthfile archivo

La URI WSDL que especifica el archivo que contiene la información de autorización. Esta URI tiene el siguiente formato:

http://nombre-usuario:contraseña@nombre-host/nombre-del-servicio-web>?wsdl.

-Xdebug

Imprime información de depuración.
-Xno-addressing-databinding

Habilita el enlace de W3C EndpointReferenceType a Java.
-Xnocompile

No compila los archivos Java generados.

EJEMPLO

El siguiente ejemplo genera los artefactos Java y compila los artefactos importando http://stockquote.example.com/quote?wsdl

wsimport -p stockquote http://stockquote.example.com/quote?wsdl
