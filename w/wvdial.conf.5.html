WVDIAL.CONF(5) Manual de Formatos de Archivo WVDIAL.CONF(5)

NOMBRE

wvdial.conf - archivo de configuración de wvdial

DESCRIPCIÓN

Cuando wvdial se inicia, primero carga su configuración desde /etc/wvdial.conf, que contiene información básica sobre el puerto del módem, la velocidad y la cadena de inicialización, junto con información sobre su Proveedor de Servicios de Internet (ISP), como el número de teléfono, su nombre de usuario y su contraseña.

El archivo de configuración /etc/wvdial.conf tiene el formato de archivo "ini" de Windows, con secciones nombradas entre corchetes y una serie de pares variable = valor dentro de cada sección.

Aquí hay un archivo de configuración de ejemplo:

[Dialer Defaults]
Modem = /dev/ttyS2
Baud = 57600
Init = ATZ
Init2 = AT S11=50
Phone = 555-4242
Username = apenwarr
Password = mi-contraseña

[Dialer phone2]
Phone = 555-4243

[Dialer shh]
Init3 = ATM0

[Dialer pulse]
Dial Command = ATDP

El archivo de configuración de ejemplo anterior contiene todas las opciones necesarias para ejecutar las dos líneas de comando de ejemplo dadas anteriormente. Aquí hay una lista completa de configuraciones que wvdial entiende:

Modem
La ubicación del dispositivo que wvdial debe usar como su módem. El valor predeterminado es /dev/modem.
Baud
La velocidad a la que wvdial se comunicará con su módem. El valor predeterminado es 57600 baudios.
Init1 ... Init9
wvdial puede usar hasta nueve cadenas de inicialización para configurar su módem. Antes de marcar, estas cadenas se envían al módem en orden numérico. Estas son particularmente útiles cuando se especifican múltiples secciones. Vea el ejemplo anterior que usa Init3 para apagar el altavoz del módem. El valor predeterminado es "ATZ" para Init1.
Phone
El número de teléfono al que desea que wvdial marque. Puede agregar hasta 4 números de teléfono adicionales a los que wvdial marcará en orden, agregando:
Phone1
Phone2
Phone3
Phone4
Dial Prefix
wvdial insertará esta cadena después del comando de marcación y antes del número de teléfono. Por ejemplo, para deshabilitar la espera de llamada (en América del Norte, de todos modos) establezca esto en "*70,".
Dial Command
wvdial usará esta cadena para indicar al módem que marque. El valor predeterminado es "ATDT".
Login
Debe establecer esto en el nombre de usuario que usa en su ISP.
Login Prompt
Si su ISP tiene un procedimiento de inicio de sesión inusual que wvdial no puede descifrar, puede usar esta opción para especificar una solicitud de inicio de sesión. Cuando se reciba esta solicitud de su ISP, wvdial enviará la cadena Login.
Password
Debe establecer esto en la contraseña que usa en su ISP.
Ask Password
Al configurar esta opción, wvdial le pedirá su contraseña en cada llamada. Por lo tanto, no tiene que guardar su contraseña en /etc/wvdial.conf. (Opción agregada por SuSE.)
Password Prompt
Si su ISP tiene un procedimiento de inicio de sesión inusual que wvdial no puede descifrar, puede usar esta opción para especificar una solicitud de contraseña. Cuando se reciba esta solicitud de su ISP, wvdial enviará la cadena Password.
PPPD Path
Si su sistema tiene pppd en un lugar distinto de /usr/sbin/pppd, necesitará configurar esta opción.
Auto DNS
Intenta obtener el Servidor de Nombres de Dominio (DNS) del proveedor. Esta opción está activada ("on") por defecto. (Opción agregada por SuSE.)
Check DNS
Verifica el Servidor de Nombres de Dominio (DNS) después de que se haya establecido la conexión. Esta opción está activada ("on") por defecto. (Opción agregada por SuSE.)
DNS Test1
Primera consulta DNS para la verificación de DNS. (Opción agregada por SuSE.)
DNS Test2
Segunda consulta DNS para la verificación de DNS. (Opción agregada por SuSE.)
Check Def Route
Verifica la ruta predeterminada después de que se haya establecido la conexión. Esta opción está activada ("on") por defecto. (Opción agregada por SuSE.)
Force Address
Esta opción solo se aplica si tiene una dirección IP estática en su ISP, e incluso entonces probablemente no la necesite. Algunos ISP no envían la dirección IP como parte de la negociación PPP. Esta opción fuerza a pppd a usar la dirección que usted le proporcione.
Remote Name
Si su ISP usa autenticación PAP o CHAP, es posible que necesite cambiar esto al nombre de autenticación de su ISP. En la mayoría de los casos, sin embargo, es seguro usar el valor predeterminado, "*".
Carrier Check
wvdial verifica su módem durante el proceso de conexión para asegurarse de que realmente esté en línea. Si tiene un módem peculiar que insiste en que su línea de portadora siempre está caída, puede deshabilitar la verificación de portadora configurando esta opción en "no".
Stupid Mode
Cuando wvdial está en Modo Estúpido, no intenta interpretar ninguna solicitud del servidor de terminal. Inicia pppd inmediatamente después de que el módem se conecta. Aparentemente, hay ISP que realmente le dan una solicitud de inicio de sesión, pero solo funcionan si inicia PPP, en lugar de iniciar sesión. Vaya figura. El Modo Estúpido está (naturalmente) deshabilitado por defecto.
New PPPD
Necesita esta opción si tiene pppd versión 2.3.0 o posterior, para que wvdial cree el archivo /etc/ppp/peers/wvdial. Esta opción está habilitada por defecto, por lo tanto, si tiene una versión anterior de pppd, debe configurarla en `no` (o actualizar pppd).
Default Reply
Cuando wvdial detecta una solicitud, y no ha visto ninguna pista que indique qué debe enviar como respuesta a la solicitud, por defecto envía "ppp". A veces esto es inadecuado. Use esta opción para anular la respuesta predeterminada de la solicitud de wvdial.
Auto Reconnect
Si está habilitado, wvdial intentará restablecer automáticamente una conexión si se desconecta accidentalmente del otro lado. Esta opción está activada ("on") por defecto.
Idle Seconds
Establece el tiempo de espera de desconexión en segundos. Si hay inactividad durante el tiempo especificado, la conexión se cierra. Un tiempo de espera de desconexión de 0 deshabilita esta función.
Abort on Busy
Si está habilitado, wvdial no volverá a intentar la conexión si el módem dice que la línea está ocupada. Esta opción está desactivada ("off") por defecto.
Abort on No Dialtone
Si está habilitado, wvdial no volverá a intentar la conexión si el módem dice que no hay tono de marcación. Esta opción está activada ("on") por defecto.
Dial Attempts
Si el valor está establecido, wvdial saldrá después de ese número de intentos. Si se establece en 0, wvdial seguirá marcando indefinidamente.
Dial Timeout
El tiempo máximo en segundos que wvdial esperará para establecer una conexión. El valor predeterminado es 60 segundos.

El programa wvdialconf(1) se puede utilizar para detectar su módem y completar automáticamente las opciones Modem, Baud e Init/Init2.
