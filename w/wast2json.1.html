NOMBRE

wast2json — convierte un archivo en formato de test de especificación wasm a un archivo JSON y archivos binarios wasm asociados

SINOPSIS

wast2json [opciones] archivo

DESCRIPCIÓN

wast2json Lee un archivo en formato de test de especificación wasm, comprueba si hay errores y lo convierte a un archivo JSON y archivos binarios wasm asociados.

Las opciones son las siguientes:

--help
Imprime este mensaje de ayuda
--version
Imprime información de la versión
-v, --verbose
Usa varias veces para más información
--debug-parser
Activa la depuración del analizador de archivos wast
--enable-exceptions
Habilita el manejo experimental de excepciones
--disable-mutable-globals
Deshabilita la importación/exportación de globales mutables
--disable-saturating-float-to-int
Deshabilita los operadores de flotantes a enteros saturantes
--disable-sign-extension
Deshabilita los operadores de extensión de signo
--disable-simd
Deshabilita el soporte SIMD
--enable-threads
Habilita el soporte de hilos
--enable-function-references
Habilita referencias de función tipadas
--disable-multi-value
Deshabilita multi-valor
--enable-tail-call
Habilita el soporte de llamadas de cola
--disable-bulk-memory
Deshabilita operaciones de memoria masiva
--disable-reference-types
Deshabilita tipos de referencia (externref)
--enable-annotations
Habilita sintaxis de anotación personalizada
--enable-code-metadata
Habilita metadatos de código
--enable-gc
Habilita recolección de basura
--enable-memory64
Habilita memoria de 64 bits
--enable-multi-memory
Habilita multi-memoria
--enable-extended-const
Habilita expresiones constantes extendidas
--enable-all
Habilita todas las características
-o, --output=ARCHIVO
archivo de salida JSON
-r, --relocatable
Crea un binario wasm relocable (adecuado para enlazar con, por ejemplo, lld)
--no-canonicalize-leb128s
Escribe todos los tamaños LEB128 como 5 bytes en lugar de su tamaño mínimo
--debug-names
Escribe nombres de depuración en el archivo binario generado
--no-check
No comprueba módulos inválidos

EJEMPLOS

Analiza spec-test.wast y escribe los archivos en spec-test.json. Los módulos se escriben en spec-test.0.wasm, spec-test.1.wasm, etc.

$ wast2json spec-test.wast -o spec-test.json
