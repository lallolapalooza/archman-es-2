Descripción detallada

Interfaz de objeto de protocolo

Un wl_interface describe la API de un objeto de protocolo definido en la especificación del protocolo Wayland. La implementación del protocolo utiliza un wl_interface dentro de su maquinaria de serialización para codificar las solicitudes del cliente.

El nombre de un wl_interface es el nombre de la interfaz de protocolo correspondiente, y la versión representa la versión de la interfaz. Los miembros method_count y event_count representan el número de métodos (solicitudes) y eventos en los respectivos miembros wl_message.

Por ejemplo, considere una interfaz de protocolo foo, marcada como versión 1, con dos solicitudes y un evento.

<interface name="foo" version="1">
  <request name="a"></request>
  <request name="b"></request>
  <event name="c"></event>
</interface>

Dadas dos matrices wl_message foo_requests y foo_events, un wl_interface para foo podría ser:

struct wl_interface foo_interface = {
        "foo", 1,
        2, foo_requests,
        1, foo_events
};

Nota

El lado del servidor del protocolo puede definir tipos de implementación de interfaz que incorporan el término interface en su nombre. Tenga cuidado de no confundir estas estructuras del lado del servidor con una variable wl_interface cuyo nombre también termina en interface. Por ejemplo, mientras que el servidor puede definir un tipo struct wl_foo_interface, el cliente puede definir una struct wl_interface wl_foo_interface.
