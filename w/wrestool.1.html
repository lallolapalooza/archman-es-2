WRESTOOL(1) Manual de Comandos Generales WRESTOOL(1)

NOMBRE

wrestool - extraer recursos de binarios de Microsoft Windows(R)

SINOPSIS

wrestool [OPCIONES]... [ARCHIVO]...

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando wrestool. Esta página del manual fue escrita para la distribución Debian GNU porque el programa original no tiene una página del manual.

Wrestool lee binarios de Microsoft Windows(R) de 16 o 32 bits y lista o extrae los recursos que contienen. Algunos recursos requieren procesamiento antes de poder ser escritos en archivos; wrestool es capaz de hacer esto con recursos de iconos y cursores.

Los filtros, especificados como opciones de línea de comandos, controlan qué recursos extraer.

OPCIONES

Estos programas siguen la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-').

-x, --extract
Extraer recursos. (Por defecto, los recursos se extraerán a la salida estándar si no se especificó --output.)
-l, --list
Listar recursos (por defecto).
-t, --type=[+|-]ID
Identificador del tipo de recurso de los recursos afectados. Si va precedido de un guion (``-''), el id debe ser numérico; si va precedido de un signo más (``+''), el id debe ser una cadena.

El id de tipo también puede ser el nombre de un tipo de recurso. (Si este es el caso, es posible que no se incluya un signo de guion o más al principio.) Una lista de tipos de recursos se puede encontrar en la sección ``Tipos de recursos''.

-n, --name=[+|-]ID
Identificador del nombre del recurso de los recursos afectados. Al igual que la opción --type, un signo de guion o más al principio controla el tipo de dato del id.
-L, --language=[+|-]ID
Identificador del idioma del recurso. No tiene efecto al procesar bibliotecas de 16 bits.
-a, --all
Realizar la operación en todos los recursos (por defecto).
-o, --output=RUTA
Dónde colocar los recursos extraídos. Si ``RUTA'' no se refiere a un directorio existente y no termina con una barra (``/''), toda la salida se escribirá en el archivo ``RUTA''. (Esto significa que si extraes múltiples recursos, RUTA solo contendrá el último recurso.)
-R, --raw
No analizar el contenido de los recursos - extraer datos crudos. (Es probable que esta opción sea reemplazada por --format=raw en una versión futura de icoutils.)
-v, --verbose
Explicar qué se está haciendo. La opción verbose se puede especificar más de una vez, como ``-vv'', para hacer wrestool aún más detallado.
--help
Mostrar un mensaje de ayuda y salir.
--version
Mostrar información de la versión y salir.

TIPOS DE RECURSOS

El programa wrestool reconoce los tipos de recursos que se enumeran a continuación. Los ids de estos recursos son siempre numéricos y no cadenas.

cursor (1)
Una sola imagen de mapa de bits de cursor. Leída como parte de los recursos group_cursor.
bitmap (2)
Una imagen de mapa de bits.
icon (3)
Una sola imagen de mapa de bits de icono. Leída como parte de los recursos group_icon. Este recurso es similar a los recursos de cursor; los cursores contienen cuatro bytes adicionales de coordenadas del punto interactivo.
menu (4)
Recursos para menús (en menús emergentes y barras de menús). Actualmente wrestool no soporta este tipo de recurso.
dialog (5)
Definiciones (widgets con ubicaciones) para cuadros de diálogo. Actualmente wrestool no soporta este tipo de recurso.
string (6)
El recurso de tabla de cadenas, que contiene un número de cadenas unicode. Actualmente wrestool no soporta este tipo de recurso.
fontdir (7)
El directorio de fuentes, que contiene información sobre un número de recursos de fuentes (8). Los archivos de fuentes no TTF (.FON) son en realidad bibliotecas con recursos en su interior. Actualmente wrestool no soporta este tipo de recurso.
font (8)
Una sola fuente - el contenido de un archivo .FNT. Leído como parte de los recursos fontdir. Actualmente wrestool no soporta este tipo de recurso.
accelerator (9)
Tablas de aceleradores de teclado. Actualmente wrestool no soporta este tipo de recurso.
rcdata (10)
Datos de recursos arbitrarios, definidos por el usuario. No hay restricciones al formato de estos recursos.
messagelist (11)
No soportado.
group_cursor (12)
Un conjunto de cursores. Con algunas modificaciones (y con recursos cursor), este recurso se puede extraer como un archivo .CUR.
group_icon (14)
Un conjunto de iconos. Con algunas modificaciones (y con recursos icon), este recurso se puede extraer como un archivo .ICO.
version (16)
Información de versión, almacenada como datos binarios. Podría extraerse sin modificaciones, pero los datos probablemente sean de poca utilidad. Actualmente wrestool no soporta este tipo de recurso.
dlginclude (17)
No soportado.
plugplay (19)
No soportado.
vxd (20)
No soportado.
anicursor (21)
Cursores animados. Actualmente wrestool no soporta cursores o iconos animados, ni tampoco icotool.
aniicon (22)
Iconos animados. Solo los he visto en Windows(R) 3.x. Actualmente wrestool no soporta cursores o iconos animados, ni tampoco icotool.

EJEMPLOS

Listar todos los recursos en el archivo `write.exe':
$ wrestool -l write.exe
--type=3 --name=1 --lang=1033 [type=icon offset=0x3120 size=752]
--type=3 --name=2 --lang=1033 [type=icon offset=0x3410 size=304]
--type=14 --name=1 --lang=1033 [type=group_icon offset=0x3540 size=34]
--type=16 --name=1 --lang=1033 [type=version offset=0x3564 size=808]

Listar todos los recursos (group-) icon en el archivo `write.exe':
$ wrestool -l --type=group_icon write.exe
--type=14 --name=1 --lang=1033 [type=group_icon offset=0x3540 size=34]

Extraer todos los iconos al directorio actual, nombrando los archivos de destino `write.exe_T_N.ico':
$ wrestool -x --output=. -t14 write.exe
$ ls *.ico
write.exe_14_1.ico
