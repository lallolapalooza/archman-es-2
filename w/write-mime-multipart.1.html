NOMBRE

write-mime-multipart - utilidad para crear archivos mime-multipart, probablemente para su uso a través de datos de usuario y cloud-init.

SINOPSIS

write-mime-multipart [opciones]

DESCRIPCIÓN

Este programa está diseñado para ayudar a escribir datos que puedan ser consumidos por cloud-init. cloud-init lee mime multipart como user-data.

-h | --help
Mostrar mensaje de uso
-o | --output FILE
escribir la salida a FILE [por defecto es stdout]
-z | --gzip
comprimir la salida con gzip
-d | --default DEFTYPE
si no se proporciona, se asume el tipo mime de DEFTYPE [por defecto es 'text/plain']
--delim DELIM
usar el delimitador DELIM [por defecto es ':']

EJEMPLOS


write-mime-multipart --gzip --output=combined-userdata.txt boothook.txt:text/cloud-boothook include-file.txt:text/x-include-url
