NOMBRE

winpr-makecert - Una herramienta para crear certificados X.509.

SINOPSIS

winpr-makecert [-rdp] [-silent] [-live] [-format { crt | pem | pfx }] [-p contraseña] [-n nombre_comun] [-y años] [-m meses] [-len longitud] [-# serial] [-a { md5 | sha1 | sha256 | s384 | sha512 }] [-path ruta_salida] [nombre_salida]

DESCRIPCIÓN

winpr-makecert es una herramienta para generar certificados X.509 inspirada en el comando de Windows MakeCert. winpr-makecert pretende ser compatible con MakeCert en línea de comandos, aunque no todas las opciones son compatibles o están implementadas todavía.

Las características no implementadas no se describen aquí. Están marcadas como "No soportado" en la ayuda de winpr-makecert.

A diferencia de su contraparte de Windows, winpr-makecert, a menos que se proporcione la opción -live, siempre crea y guarda un certificado. Si *nombre_salida* no está configurado, se intenta determinar el nombre del host de la máquina donde se ejecuta el comando.
Advertencia: si el archivo ya existe, se sobrescribirá sin preguntar.

Sin opciones adicionales, los certificados generados tienen las siguientes propiedades:

* 2048 bits de longitud
* sha256 como algoritmo hash
* el nombre del host detectado se usa como nombre común
* una marca de tiempo se usa como número de serie
* período de validez de un año
* guardado en el directorio de trabajo actual en formato crt

OPCIONES

-rdp
Parámetro ficticio. Se puede usar para generar rápidamente un certificado con propiedades predeterminadas sin especificar más parámetros.
-silent
No imprimir el certificado generado en la salida estándar.
-f formato
Se soportan tres formatos: crt, pem y pfx.
*crt* genera la clave y el certificado en archivos separados con las extensiones .key y .crt.
*pem* genera la clave y el certificado en un único archivo con la extensión pem.
Y *pfx* genera la clave y el certificado en un archivo pkcs12 con la extensión .pfx.
-p contraseña
Contraseña a usar si se utiliza el formato pfx.
-live
No escribir la clave/certificado en disco. Cuando se usa desde la línea de comandos, esto puede considerarse como modo "ficticio".
-n nombre_comun
El nombre común a usar en el certificado.
-m meses
Período de validez en meses.
-y años
Período de validez en años. Si se especifican meses y años, el parámetro de mes especificado tendrá precedencia.
-len longitud
Longitud de la clave en bits a usar.
-a { md5 | sha1 | sha256 | s384 | sha512 }
El algoritmo de hash a utilizar.
-# serial
El número de serie a usar para el certificado.
-path
Un directorio donde se debe crear el certificado.
nombre_salida
El nombre base del archivo(s) creado(s). Se añade un sufijo, el sufijo específico del formato, a este nombre.

EJEMPLOS

winpr-makecert -rdp

Crea un certificado con las propiedades predeterminadas, guardado en un archivo en el directorio de trabajo actual en formato crt con el nombre del host. Si el host se llama freerdp, los archivos creados se llamarán freerdp.key y freerdp.crt.

winpr-makecert -len 4096 -a sha384 -path /tmp -# 22 -m 144 -y 1 -format crt mi_certificado

El comando anterior crea el archivo /tmp/mi_certificado.pem que contiene una clave y un certificado con una longitud de 4096. Utilizará sha384 como algoritmo hash. El certificado tiene el número de serie 22 y es válido durante 12 años (144 meses).

ESTADO DE SALIDA

0
Ejecución exitosa del programa.
1
En caso contrario.
