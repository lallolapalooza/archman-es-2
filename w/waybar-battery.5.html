waybar-battery(5) Manual de formatos de archivo waybar-battery(5)

NOMBRE

waybar - módulo de batería

DESCRIPCIÓN

El módulo battery muestra la capacidad actual y el estado (por ejemplo, cargando) de tu batería.

CONFIGURACIÓN

bat:
tipo: string
La batería a monitorear, como en /sys/class/power_supply/ en lugar de detección automática.

adapter:
tipo: string
El adaptador a monitorear, como en /sys/class/power_supply/ en lugar de detección automática.

full-at:
tipo: integer
Define el porcentaje máximo de la batería, para cuando has configurado la batería para que deje de cargar en un nivel inferior para conservarla. Por ejemplo, si has configurado la batería para que se detenga al 80%, ese 80% se convertirá en el nuevo 100%.

design-capacity:
tipo: bool
por defecto: false
Opción para usar la capacidad de diseño de la batería en lugar de su capacidad máxima actual.

interval:
tipo: integer
por defecto: 60
El intervalo en el que se consulta la información.

states:
tipo: object
Un número de estados de batería que se activan en ciertos niveles de capacidad. Ver waybar-states(5).

format:
tipo: string
por defecto: {capacity}%
El formato, cómo se debe mostrar la información.

format-time:
tipo: string
por defecto: {H} h {M} min
El formato, cómo se debe mostrar el tiempo.

format-icons:
tipo: array/object
Basado en la capacidad actual, se selecciona el icono correspondiente.
El orden es de bajo a alto. O por el estado si es un objeto.

max-length:
tipo: integer
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
tipo: integer
La longitud mínima en caracteres que el módulo debe aceptar.

align:
tipo: float
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: string
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir el posicionamiento.

rotate:
tipo: integer
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

on-click:
tipo: string
Comando a ejecutar al hacer clic en el módulo.

on-click-middle:
tipo: string
Comando a ejecutar al hacer clic con la rueda del ratón en el módulo.

on-click-right:
tipo: string
Comando a ejecutar al hacer clic derecho en el módulo.

on-update:
tipo: string
Comando a ejecutar cuando el módulo se actualiza.

on-scroll-up:
tipo: string
Comando a ejecutar al desplazarse hacia arriba en el módulo.

on-scroll-down:
tipo: string
Comando a ejecutar al desplazarse hacia abajo en el módulo.

smooth-scrolling-threshold:
tipo: double
Umbral a usar al desplazarse.

tooltip:
tipo: bool
por defecto: true
Opción para deshabilitar la información emergente al pasar el ratón.

bat-compatibility:
tipo: bool
por defecto: false
Opción para habilitar la compatibilidad de la batería si no se detecta.

menu:
tipo: string
Acción que muestra el menú.

menu-file:
tipo: string
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu.

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: bool
por defecto: false
Permite que este módulo consuma todo el espacio restante de forma dinámica.

events:
tipo: object
Especifica comandos que se ejecutarán en estados específicos de la batería. Ver la sección EVENTOS abajo.

REEMPLAZOS DE FORMATO

{capacity}: Capacidad en porcentaje

{power}: Potencia en vatios

{icon}: Icono, como se define en format-icons.

{time}: Estimación del tiempo hasta que se llene o se vacíe. Ten en cuenta que esto se basa en el consumo de energía en el último tiempo de actualización, no en un promedio.

{cycles}: Cantidad de ciclos de carga que ha visto la batería de mayor capacidad. (Solo Linux)

{health}: El porcentaje de la carga máxima original de la batería de mayor capacidad que aún puede mantener.

FORMATO DE TIEMPO

El módulo battery te permite definir cómo se debe formatear el tiempo a través de format-time.

Los tres argumentos son: {H}: Horas {M}: Minutos {m}: Minutos con ceros iniciales

FORMATOS PERSONALIZADOS

El módulo battery permite definir formatos personalizados basados en hasta dos factores. Se seleccionará el formato que mejor se ajuste.

format-<state>: Con states, se puede establecer un formato personalizado según la capacidad de tu batería.

format-<status>: Con el estado, se puede establecer un formato personalizado según el estado en /sys/class/power_supply/<bat>/status (en minúsculas).

format-<status>-<state>: También puedes establecer un formato personalizado dependiendo de ambos valores.

ESTADOS

  • Cada entrada (state) consta de un <name> (tipo: string) y un <value> (tipo: integer).
  • El estado se puede direccionar como una clase CSS en el archivo style.css. El nombre de la clase CSS es el <name> del estado. Cada clase se activa cuando la capacidad actual es igual o inferior al <value> configurado.
  • Además, cada estado puede tener su propio format. Estos se pueden configurar a través de format-<name>. O si quieres diferenciar un poco más, incluso como format-<status>-<state>. Para más información, consulta custom-formats.

EVENTOS

Cada entrada en el objeto events consta de un <event-name> (tipo: string) y un <command> (tipo: string).
<event-name> puede tener uno de los siguientes formatos:

  • on-<status>-<state>
  • on-<status>-<capacity>

Donde:

  • <status> es charging o discharging,
  • <state> es el nombre de uno de los estados especificados en el objeto states,
  • <capacity> es un valor de nivel de batería (entre 0-100).

EJEMPLOS

"battery": {
	"bat": "BAT2",
	"interval": 60,
	"states": {
		"warning": 30,
		"critical": 15
	},
	"events": {
		"on-discharging-warning": "notify-send -u normal 'Batería Baja'",
		"on-discharging-critical": "notify-send -u critical 'Batería Muy Baja'",
		"on-charging-100": "notify-send -u normal '¡Batería Llena!'"
	},
	"format": "{capacity}% {icon}",
	"format-icons": ["", "", "", "", ""],
	"max-length": 25
}

ESTILO

  • #battery
  • #battery.<status>
•
<status> es el valor de /sys/class/power_supply/<bat>/status en minúsculas.

NOMBRE

waybar-battery - módulo de batería para Waybar

DESCRIPCIÓN

Este módulo muestra información de la batería, como el porcentaje de carga, el tiempo restante y el estado (cargando, descargando, lleno).

CONFIGURACIÓN

Las opciones de configuración para el módulo de batería se especifican en el archivo de configuración de Waybar (normalmente ~/.config/waybar/config).

•
interval: (Integer) Intervalo en segundos entre actualizaciones. Valor por defecto: 60.
•
states: (Object) Permite definir estados personalizados y sus correspondientes clases CSS. Por ejemplo:
"states": {
    "good": 90,
    "warning": 30,
    "critical": 10
}

En este ejemplo, si el porcentaje de batería es mayor o igual a 90, se aplicará la clase CSS good. Si está entre 30 y 90 (excluyendo 90), se aplicará warning. Si es menor a 10, se aplicará critical.

•
format: (String) El formato de salida para el módulo. Ver la sección FORMAT_REPLACEMENTS para más detalles.
•
format-icons: (Object) Un mapa de iconos para diferentes estados de la batería. Las claves pueden ser los nombres de los estados definidos en states, así como charging, discharging, full. El valor por defecto incluye iconos para estos estados.
•
tooltip: (Boolean) Si se muestra la información en un tooltip al pasar el ratón por encima. Por defecto: true.
•
tooltip-format: (String) El formato del tooltip. Ver FORMAT_REPLACEMENTS.
•
power-profiles-action: (String) Comando a ejecutar cuando se hace clic en el módulo. Por defecto: upower -m.

FORMATO DE REEMPLAZOS

Los siguientes reemplazos de formato están disponibles:

•
{percentage}: El porcentaje de la batería (0-100).
•
{time}: El tiempo estimado restante (si se está descargando).
•
{icon}: El icono correspondiente al estado actual de la batería.
•
{status}: El estado actual de la batería (Charging, Discharging, Full, Unknown).

TIEMPO FORMATO

El tiempo restante se muestra en formato HH:MM. Si el tiempo restante es desconocido (por ejemplo, durante la carga o si el sistema no puede determinarlo), este campo estará vacío.

FORMATOS PERSONALIZADOS

Es posible definir un formato completamente personalizado utilizando los reemplazos anteriores. Por ejemplo:

•
"{icon} {percentage}%" mostrará el icono y el porcentaje.
•
"{icon} {percentage}% {time}" mostrará el icono, el porcentaje y el tiempo restante (si está disponible).

ESTADOS

Los estados definidos en la configuración (en la clave states) se utilizan para aplicar clases CSS al módulo. Las clases CSS se generan basándose en estos estados.

•
<state>: El nombre del estado definido en la configuración (por ejemplo, good, warning, critical).
•
La clase CSS aplicada al módulo será battery-<state>. Por ejemplo, si el estado es warning, la clase aplicada será battery-warning.

EVENTOS

El módulo de batería escucha eventos específicos relacionados con la batería. Estos eventos pueden actualizar el estado y la información mostrada sin necesidad de esperar al próximo intervalo de sondeo.

•
battery: Evento principal que contiene información detallada de la batería.

EJEMPLOS

Ejemplo de configuración en ~/.config/waybar/config:

•
Configuración básica:
"modules-left": ["battery"],
"battery": {
    "format": "{icon} {percentage}%",
    "format-icons": {
        "charging": "",
        "discharging": "",
        "full": ""
    }
}
•
Configuración con estados personalizados:
"battery": {
    "states": {
        "good": 80,
        "warning": 20,
        "critical": 10
    },
    "format": "{icon} {percentage}%",
    "format-icons": {
        "good": "",
        "warning": "",
        "critical": "",
        "charging": "",
        "discharging": ""
    }
}

ESTILO

Los módulos de Waybar pueden ser estilizados usando CSS. Las clases CSS aplicadas al módulo de batería incluyen:

•
#waybar.battery: Estilo para todo el módulo de batería.
•
#waybar.battery > label: Estilo para la etiqueta de texto del módulo.
•
#waybar.battery > image: Estilo para la imagen (icono) del módulo, si se utiliza.
•
Además, las clases definidas en states se aplican al módulo, permitiendo estilos condicionales. Por ejemplo:
•
.battery-warning: Se aplica cuando la batería está en estado de advertencia.
•
.battery-critical: Se aplica cuando la batería está en estado crítico.

También se aplican clases generales al Waybar completo, basadas en el estado de la batería:

•
window#waybar.battery-<state>
•
<state> puede ser definido en la configuración, como se mencionó anteriormente.
