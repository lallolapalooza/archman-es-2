NOMBRE

wcstol, wcstoll — convertir una cadena de caracteres anchos a un entero largo

SINOPSIS

#include <wchar.h>
long wcstol(const wchar_t *restrict nptr, wchar_t **restrict endptr,
    int base);
long long wcstoll(const wchar_t *restrict nptr,
    wchar_t **restrict endptr, int base);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones convertirán la porción inicial de la cadena de caracteres anchos apuntada por nptr a long y long long, respectivamente. Primero, descompondrán la cadena de entrada en tres partes:

1.
Una secuencia inicial, posiblemente vacía, de códigos de caracteres anchos de espacio en blanco (según lo especificado por iswspace())
2.
Una secuencia sujeto interpretada como un entero representado en alguna base determinada por el valor de base
3.
Una cadena final de uno o más códigos de caracteres anchos no reconocidos, incluido el código de carácter ancho nulo de terminación de la cadena de caracteres anchos de entrada

Luego intentarán convertir la secuencia sujeto a un entero y devolverán el resultado.

Si base es 0, la forma esperada de la secuencia sujeto es la de una constante decimal, constante octal o constante hexadecimal, cualquiera de las cuales puede ir precedida por un signo '+' o '-'. Una constante decimal comienza con un dígito distinto de cero y consta de una secuencia de dígitos decimales. Una constante octal consta del prefijo '0' seguido opcionalmente por una secuencia de los dígitos '0' a '7' solamente. Una constante hexadecimal consta del prefijo 0x o 0X seguido por una secuencia de dígitos y letras decimales 'a' (o 'A') a 'f' (o 'F') con valores de 10 a 15 respectivamente.

Si el valor de base está entre 2 y 36, la forma esperada de la secuencia sujeto es una secuencia de letras y dígitos que representan un entero con la base especificada por base, precedida opcionalmente por un signo '+' o '-', pero sin incluir un sufijo entero. Las letras de 'a' (o 'A') a 'z' (o 'Z') inclusive se les asignan los valores de 10 a 35; solo se permitirán letras cuyos valores asignados sean menores que el de base. Si el valor de base es 16, las representaciones de código de carácter ancho de 0x o 0X pueden preceder opcionalmente a la secuencia de letras y dígitos, después del signo si está presente.

La secuencia sujeto se define como la sub-secuencia inicial más larga de la cadena de caracteres anchos de entrada, comenzando con el primer código de carácter ancho que no es espacio en blanco y que tiene la forma esperada. La secuencia sujeto no contiene códigos de caracteres anchos si la cadena de caracteres anchos de entrada está vacía o consiste enteramente en códigos de caracteres anchos de espacio en blanco, o si el primer código de carácter ancho que no es espacio en blanco es distinto de un signo o una letra o dígito permitido.

Si la secuencia sujeto tiene la forma esperada y base es 0, la secuencia de códigos de caracteres anchos que comienza con el primer dígito se interpretará como una constante entera. Si la secuencia sujeto tiene la forma esperada y el valor de base está entre 2 y 36, se utilizará como base para la conversión, asignando a cada letra su valor como se indica anteriormente. Si la secuencia sujeto comienza con un <guión-menos>, el valor resultante de la conversión se negará. Se almacenará un puntero a la cadena final de caracteres anchos en el objeto apuntado por endptr, siempre que endptr no sea un puntero nulo.

En configuraciones regionales distintas de la C o POSIX, pueden aceptarse formas adicionales de secuencia sujeto específicas de la configuración regional.

Si la secuencia sujeto está vacía o no tiene la forma esperada, no se realizará ninguna conversión; el valor de nptr se almacenará en el objeto apuntado por endptr, siempre que endptr no sea un puntero nulo.

Estas funciones no cambiarán la configuración de errno si tienen éxito.

Dado que se devuelven 0, {LONG_MIN} o {LLONG_MIN} y {LONG_MAX} o {LLONG_MAX} en caso de error y también son devoluciones válidas en caso de éxito, una aplicación que desee comprobar situaciones de error debe establecer errno en 0, luego llamar a wcstol() o wcstoll(), y luego comprobar errno.

VALOR DE RETORNO

Tras una finalización exitosa, estas funciones devolverán el valor convertido, si lo hay. Si no se pudo realizar ninguna conversión, se devolverá 0 y errno puede establecerse para indicar el error. Si el valor correcto está fuera del rango de valores representables, se devolverá {LONG_MIN}, {LONG_MAX}, {LLONG_MIN} o {LLONG_MAX} (según el signo del valor), y errno se establecerá en [ERANGE].

ERRORES

Estas funciones fallarán si:

EINVAL
El valor de base no es compatible.
ERANGE
El valor a devolver no es representable.

Estas funciones pueden fallar si:

EINVAL
No se pudo realizar ninguna conversión.

NOMBRE

wcstol - convertir una cadena de caracteres anchos a un valor long (tipo long int)

SINOPSIS

#include <wchar.h>

long int wcstol(const wchar_t *nptr, wchar_t **endptr, int base);

DESCRIPCIÓN

La función wcstol convierte el segmento inicial de la cadena de caracteres anchos apuntada por nptr a un valor long int.

Los caracteres anchos son aquellos que pueden ser representados por un objeto wchar_t. El comportamiento de wcstol depende de la configuración regional actual.

La cadena puede contener espacios en blanco iniciales (según lo definido por la categoría LC_CTYPE de la configuración regional) que se ignoran.

Si base es cero, el sistema deduce la base de la cadena de caracteres anchos: si comienza con 0x o 0X, la base es 16; si comienza con 0, la base es 8; de lo contrario, la base es 10. Si base está entre 2 y 36, entonces se utiliza la base especificada. Si base es 16, se permiten los prefijos 0x o 0X.

La conversión se detiene en el primer carácter ancho que no es un dígito en la base especificada, o cuando se alcanza el final de la cadena. Si endptr no es un puntero nulo, se almacena en él un puntero al primer carácter ancho que detuvo la conversión.

Si el valor convertido no se puede representar como un long int, se produce un desbordamiento de entero. En caso de desbordamiento positivo, wcstol devuelve LONG_MAX. En caso de desbordamiento negativo, wcstol devuelve LONG_MIN. En ambos casos, errno se establece en ERANGE.

Si no se puede realizar ninguna conversión (por ejemplo, si nptr apunta a un carácter ancho que no es un dígito válido o si la cadena está vacía), wcstol devuelve 0 y errno puede establecerse en EINVAL.

Si el resultado de la conversión es 0, errno no se ve afectado.

VALOR DE RETORNO

Devuelve el valor long int convertido. En caso de desbordamiento, devuelve LONG_MAX o LONG_MIN. Si no se puede realizar ninguna conversión, devuelve 0.

ERRORES

EINVAL
No se pudo realizar ninguna conversión.
ERANGE
El valor convertido estaba fuera del rango representable por un long int.

EJEMPLOS

Convertir la cadena de caracteres anchos " -4567" a un número entero largo:

wchar_t wstr[] = L"   -4567";
wchar_t *ptr;
long result = wcstol(wstr, &ptr, 10);
// result es -4567
// *ptr es el carácter nulo que termina la cadena

Convertir la cadena de caracteres anchos "0x1a2b" a un entero largo con base 16:

wchar_t wstr[] = L"0x1a2b";
wchar_t *ptr;
long result = wcstol(wstr, &ptr, 16);
// result es 67003
// *ptr es el carácter nulo que termina la cadena

USO DE LA APLICACIÓN

Esta función es parte de la biblioteca estándar C y se utiliza para convertir cadenas de caracteres anchos que representan números enteros a su representación numérica long int. Es especialmente útil cuando se trabaja con texto que no está limitado a caracteres ASCII, como en el soporte para internacionalización.

JUSTIFICACIÓN

La función wcstol proporciona una forma segura y flexible de convertir cadenas de caracteres anchos a enteros largos, gestionando diferentes bases numéricas y detectando errores de conversión y desbordamiento.

DIRECCIONES FUTURAS

No se prevén cambios significativos en el comportamiento o la funcionalidad de wcstol.
