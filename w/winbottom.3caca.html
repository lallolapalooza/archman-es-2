NAME

winbottom - Window structure definition

SYNOPSIS

#include <cacacont.h>

struct caca_conio_text_info

{
  unsigned char x;
  unsigned char y;
  unsigned char *text;
  unsigned char *attr;
  unsigned char width;
  unsigned char height;
  unsigned char curx;
  unsigned char cury;
};

Detailed Description

This structure is used to hold the text buffer information of a window. The text buffer is composed of characters and attributes. The characters are stored in a planar format, where the first width * height bytes contain the characters of the window, and the next width * height bytes contain the attributes of the characters.

The x and y members represent the position of the window on the screen. The width and height members represent the dimensions of the window. The text and attr members are pointers to the character and attribute buffers, respectively. The curx and cury members represent the cursor position within the window.
