WIMDIR(1) Comandos de usuario WIMDIR(1)

NOMBRE

wimdir - Listar los archivos contenidos en una imagen WIM

SINOPSIS

wimdir ARCHIVO_WIM [IMAGEN] [OPCION...]

DESCRIPCIÓN

wimdir, o equivalentemente wimlib-imagex dir, lista los archivos y directorios contenidos en la imagen especificada del archivo Windows Imaging (WIM) ARCHIVO_WIM.

IMAGEN especifica la imagen en ARCHIVO_WIM a listar. Puede ser el índice basado en 1 de una imagen, el nombre de una imagen, o la palabra clave "all" para especificar todas las imágenes. Puede omitirse si ARCHIVO_WIM contiene solo una imagen. Puedes usar wiminfo(1) para listar las imágenes contenidas en ARCHIVO_WIM.

OPCIONES

--path=RUTA
Listar los archivos bajo RUTA en lugar de bajo el directorio raíz.
--detailed
Listar información detallada sobre cada archivo.
--one-file-only
Listar información solo sobre el archivo especificado. Diseñado para usarse con --path y --detailed.
--ref="GLOB"
Patrón glob de archivos de WIM adicionales o partes de WIM divididas para referenciar recursos. Esta opción se puede especificar varias veces. Esta opción solo es útil cuando también se especifica --detailed.

NOTAS

wimdir soporta WIM divididos, pero solo funciona en la primera parte del WIM dividido.

Metadatos detallados como marcas de tiempo y flujos de datos no se muestran a menos que se use la opción --detailed.

EJEMPLOS

Listar todos los archivos y directorios en la primera imagen de 'boot.wim':

wimdir boot.wim 1
