WVDIALCONF(1) Manual de comandos generales WVDIALCONF(1)

NOMBRE

wvdialconf - crea un archivo de configuración para wvdial(1)

SINOPSIS

wvdialconf /etc/wvdial.conf

DESCRIPCIÓN

wvdialconf detecta tu módem, su velocidad máxima y una buena cadena de inicialización, y genera o actualiza el archivo de configuración de wvdial(1) basándose en esta información.

wvdialconf es completamente no interactivo. Aún necesitas editar /etc/wvdial.conf para especificar el número de teléfono, el nombre de usuario y la contraseña de tu cuenta de internet para que wvdial(1) funcione.

Es seguro ejecutar wvdialconf si ya existe un archivo de configuración. En ese caso, solo se cambiarán las opciones Modem, Baud, Init e Init2 en la sección [Dialer Defaults], y solo si la autodetección es exitosa.

ERRORES

Estamos dispuestos a considerar la posibilidad. Háznoslo saber si tienes algún problema enviando un correo electrónico a <wvdial-list@lists.nit.ca>.

DIAGNÓSTICOS

Un estado de salida de 0 significa que se detectó un módem y el archivo de configuración se actualizó correctamente.

Cualquier otro valor significa que algo salió mal y el archivo de configuración no se modificó.
