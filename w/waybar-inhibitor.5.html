NOMBRE

waybar - módulo inhibidor

DESCRIPCIÓN

El módulo inhibitor permite tomar un bloqueo inhibidor que logind proporciona. Consulte systemd-inhibit(1) para obtener más información.

CONFIGURACIÓN

what:
typeof: string or array
El bloqueo o bloqueos inhibidores que se deben tomar cuando están activos. Los bloqueos inhibidores disponibles son idle, shutdown, sleep, handle-power-key, handle-suspend-key, handle-hibernate-key y handle-lid-switch.

format:
typeof: string
El formato, cómo se debe mostrar el estado.

format-icons:
typeof: array
Según el estado actual, se selecciona el icono correspondiente.

rotate:
typeof: integer
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

max-length:
typeof: integer
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
typeof: integer
La longitud mínima en caracteres que el módulo debe aceptar.

align:
typeof: float
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
typeof: string
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir el posicionamiento.

on-click:
typeof: string
Comando a ejecutar cuando se hace clic en el módulo. Un clic también alterna el estado.

on-click-middle:
typeof: string
Comando a ejecutar cuando se hace clic con la rueda del ratón en el módulo.

on-click-right:
typeof: string
Comando a ejecutar cuando se hace clic derecho en el módulo.

on-update:
typeof: string
Comando a ejecutar cuando se actualiza el módulo.

on-scroll-up:
typeof: string
Comando a ejecutar al desplazarse hacia arriba sobre el módulo.

on-scroll-down:
typeof: string
Comando a ejecutar al desplazarse hacia abajo sobre el módulo.

smooth-scrolling-threshold:
typeof: double
Umbral a utilizar al desplazarse.

tooltip:
typeof: bool
default: true
Opción para deshabilitar la información sobre herramientas al pasar el ratón por encima.

menu:
typeof: string
Acción que muestra el menú. No puede ser "on-click".

menu-file:
typeof: string
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
typeof: array
Las acciones correspondientes a los botones del menú.

expand:
typeof: bool
default: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

{status}: estado (activated o deactivated)

{icon}: Icono, como se define en format-icons

EJEMPLOS

"inhibitor": {
	"what": "handle-lid-switch",
	"format": "{icon}",
	"format-icons": {
		"activated": "",
		"deactivated": "0"
	}
}
