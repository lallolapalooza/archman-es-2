NOMBRE

watchgnupg - Leer e imprimir registros de un socket

SINOPSIS

watchgnupg [--force] [--verbose] nombre_socket

DESCRIPCIÓN

La mayoría de las utilidades principales pueden escribir sus archivos de registro en un socket de Dominio Unix si están configuradas de esa manera. watchgnupg es un simple oyente para dicho socket. Mejora la salida con una marca de tiempo y se asegura de que las líneas largas no se intercalen con la salida de registro de otras utilidades. Esta herramienta no está disponible para Windows.

watchgnupg se invoca comúnmente como

watchgnupg

que es una abreviatura de

watchgnupg --force $(gpgconf --list-dirs socketdir)/S.log

Para observar GnuPG ejecutándose con un directorio de inicio diferente, use

watchgnupg --homedir DIR

OPCIONES

watchgnupg entiende estas opciones:

--force
Eliminar un archivo de socket ya existente. Esta opción se usa implícitamente si no se ha proporcionado un nombre de socket en la línea de comandos.
--homedir DIR
Si no se proporciona un nombre de socket en la línea de comandos, pasa DIR a gpgconf para que se utilice el socket de un GnuPG que se ejecute con el directorio de inicio de DIR. Tenga en cuenta que la variable de entorno GNUPGHOME es ignorada por watchgnupg.
--tcp n
En lugar de leer de un socket local, escucha las conexiones en el puerto TCP n. Opcionalmente, también se puede proporcionar un socket de Dominio Unix como segunda fuente. Esta opción no utiliza un nombre de socket predeterminado.
--time-only
No imprimir la parte de la fecha de la marca de tiempo.
--verbose
Habilitar salida de información adicional.
--version
Imprimir la versión del programa y salir.
--help
Mostrar una breve página de ayuda y salir.

EJEMPLOS

$ watchgnupg --time-only

Esto espera conexiones en el socket local (por ejemplo, '/var/run/user/1234/gnupg/S.log') y muestra todas las entradas de registro. Para que esto funcione, la opción log-file debe usarse con todos los módulos cuyos registros se deban mostrar. La entrada sugerida para los archivos de configuración es:

log-file socket://

Si el socket predeterminado, como se indica arriba y se devuelve con "echo $(gpgconf --list-dirs socketdir)/S.log", no es deseado, se puede especificar un nombre de socket arbitrario, por ejemplo 'socket:///home/foo/bar/mysocket'. Para fines de depuración, también es posible realizar registros remotos. Tenga cuidado si utiliza esta función, ya que la información se envía sin cifrar a través de la red. Utilice esta sintaxis en los archivos de configuración:

log-file tcp://192.168.1.1:4711

Puede usar cualquier puerto y no solo 4711 como se muestra arriba; solo se admiten direcciones IP (v4 y v6) y ningún nombre de host. Debe iniciar watchgnupg con la opción tcp. Tenga en cuenta que en Windows, la entrada del registro HKCU\Software\GNU\GnuPG:DefaultLogFile se puede usar para cambiar la salida de registro predeterminada de stderr a lo que se proporcione en esa entrada. Sin embargo, la única entrada útil es un nombre TCP para depuración remota.
