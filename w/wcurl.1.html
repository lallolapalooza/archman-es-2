NOMBRE

wcurl - un simple script de envoltura para curl para descargar archivos fácilmente.

SINOPSIS

wcurl <URL>...

wcurl [--curl-options <OPCIONES_CURL>]... [--dry-run] [--no-decode-filename] [-o|-O|--output <RUTA>] [--] <URL>...

wcurl [--curl-options=<OPCIONES_CURL>]... [--dry-run] [--no-decode-filename] [--output=<RUTA>] [--] <URL>...

wcurl -V|--version

wcurl -h|--help

DESCRIPCIÓN

wcurl es un script de envoltura simple para curl que te permite usar curl para descargar archivos sin tener que recordar ningún parámetro.

Simplemente llama a wcurl con una lista de URLs que deseas descargar y wcurl elegirá valores predeterminados sensatos.

Si necesitas algo más complejo, puedes proporcionar cualquiera de los parámetros soportados por curl a través de la opción --curl-options. Solo ten cuidado, ya que probablemente deberías estar usando curl directamente si tu caso de uso no está cubierto.

Por defecto, wcurl realiza lo siguiente:

* Codifica con porcentaje los espacios en las URLs;
* Descarga múltiples URLs en paralelo
si la versión instalada de curl es >= 7.66.0 (--parallel);
* Usa un número total de 5 conexiones paralelas al mismo protocolo + nombre de host + número de puerto de destino
si la versión instalada de curl es >= 8.16.0 (--parallel-max-host);
* Sigue las redirecciones;
* Elige automáticamente un nombre de archivo como salida;
* Evita sobrescribir archivos
si la versión instalada de curl es >= 7.83.0 (--no-clobber);
* Realiza reintentos;
* Establece la marca de tiempo del archivo descargado
al valor proporcionado por el servidor, si está disponible;
* Usa https por defecto
si la URL no contiene ningún esquema;
* Deshabilita el analizador de globbing de URLs de curl
para que los caracteres {} y [] en las URLs no se traten de forma especial;
* Decodifica con porcentaje el nombre de archivo resultante;
* Usa 'index.html' como nombre de archivo predeterminado
si no hay ninguno en la URL.

OPCIONES

--curl-options, --curl-options=<OPCIONES_CURL>...
Especifica opciones adicionales que se pasarán al invocar curl. Puede especificarse más de una vez.
-o, -O, --output, --output=<RUTA>
Usa la ruta de salida proporcionada en lugar de obtenerla de la URL. Si se proporcionan múltiples URLs, los archivos resultantes comparten el mismo nombre con un número añadido al final (curl >= 7.83.0). Si esta opción se proporciona varias veces, solo se considera el último valor.
--no-decode-filename
No decodificar con porcentaje el nombre de archivo de salida, incluso si la codificación con porcentaje en la URL fue realizada por wcurl, por ejemplo: la URL contenía espacios.
--dry-run
No ejecutar realmente curl, solo imprimir lo que se invocaría.
-V, --version
Imprime la información de la versión.
-h, --help
Imprime el mensaje de ayuda.

CURL_OPTIONS

Cualquier opción soportada por curl puede ser establecida aquí. Esto no es usado por wcurl; en su lugar, se reenvía a la invocación de curl.

URL

URL a ser descargada. Cualquier cosa que no sea un parámetro se considera una URL. Los espacios se codifican con porcentaje y la URL se pasa a curl, que luego realiza el análisis. Puede especificarse más de una vez.

EJEMPLOS

Descargar un solo archivo:

wcurl example.com/filename.txt

Descargar dos archivos en paralelo:

wcurl example.com/filename1.txt example.com/filename2.txt

Descargar un archivo pasando las banderas --progress-bar y --http2 a curl:

wcurl --curl-options="--progress-bar --http2" example.com/filename.txt

* Reanudar una descarga interrumpida. Las opciones necesarias para reanudar la descarga (--clobber --continue-at -) deben ser las últimas opciones especificadas en --curl-options. Ten en cuenta que la única forma de reanudar descargas interrumpidas es permitir que wcurl sobrescriba el archivo de destino:

wcurl --curl-options="--clobber --continue-at -" example.com/filename.txt

Descargar múltiples archivos sin límite de conexiones concurrentes por host (el límite predeterminado es 5):

wcurl --curl-options="--parallel-max-host 0" example.com/filename1.txt example.com/filename2.txt
