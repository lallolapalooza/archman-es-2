NOMBRE

whirlwindwarp - estrellas en movimiento loco

SINOPSIS

whirlwindwarp [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--mono] [--install] [--visual visual] [--points entero] [--tails entero] [--fps]

DESCRIPCIÓN

whirlwindwarp dibuja estrellas moviéndose según varios campos de fuerza (ecuaciones simples en 2D).

¡ADVERTENCIA!

Este salvapantallas puede ser peligroso para tus ojos. ¡Por favor, no lo mires durante mucho tiempo!

OPCIONES

whirlwindwarp acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Si está en una pantalla a color, finge que está en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de ID (decimal o hexadecimal) de un visual específico.
--points entero
El número de estrellas dibujadas (por defecto 400).
--tails entero
La longitud de la cola de cada estrella (por defecto 8).
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
