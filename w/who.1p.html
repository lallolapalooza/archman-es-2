WHO(1P) Manual del Programador POSIX WHO(1P)

PROLOG

Esta página del manual es parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

who — mostrar quién está en el sistema

SINOPSIS

who [-mTu] [-abdHlprt] [archivo]
who [-mu] -s [-bHlprt] [archivo]
who -q [archivo]
who am i
who am I

DESCRIPCIÓN

La utilidad who mostrará diversa información sobre los usuarios accesibles. El dominio de accesibilidad es definido por la implementación.

Según las opciones dadas, who también puede mostrar el nombre del usuario, la línea del terminal, la hora de inicio de sesión, el tiempo transcurrido desde que ocurrió actividad en la línea y el ID de proceso del intérprete de comandos para cada usuario activo del sistema.

OPCIONES

La utilidad who cumplirá con el volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2, Directrices de sintaxis de utilidad.

Las siguientes opciones serán soportadas. Los metavariables, como <línea>, se refieren a los campos descritos en la sección STDOUT.

-a
Procesa la base de datos definida por la implementación o el archivo nombrado con las opciones -b, -d, -l, -p, -r, -t, -T y -u activadas.
-b
Escribe la hora y fecha del último reinicio del sistema. La hora de reinicio del sistema es la hora en la que la implementación puede comenzar a ejecutar procesos.
-d
Escribe una lista de todos los procesos que han expirado y no han sido reiniciados por el proceso del sistema init. El campo <salida> aparecerá para los procesos muertos y contendrá los valores de terminación y salida del proceso muerto. Esto puede ser útil para determinar por qué terminó un proceso.
-H
Escribe encabezados de columna encima de la salida regular.
-l
(La letra ele.) Lista solo aquellas líneas en las que el sistema está esperando que alguien inicie sesión. El campo <nombre> será LOGIN en tales casos. Otros campos serán los mismos que para las entradas de usuario excepto que el campo <estado> no existe.
-m
Muestra solo información sobre el terminal actual.
-p
Lista cualquier otro proceso que esté actualmente activo y que haya sido previamente iniciado por init.
-q
(Rápido.) Lista solo los nombres y el número de usuarios actualmente conectados. Cuando se utiliza esta opción, todas las demás opciones serán ignoradas.
-r
Escribe el nivel de ejecución actual del proceso init.
-s
Lista solo los campos <nombre>, <línea> y <hora>. Este es el caso por defecto.
-t
Indica el último cambio en el reloj del sistema.
-T
Muestra el estado de cada terminal, como se describe en la sección STDOUT.
-u
Escribe el "tiempo inactivo" para cada usuario mostrado además de cualquier otra información. El tiempo inactivo es el tiempo transcurrido desde que ocurrió alguna actividad en el terminal del usuario. El método para determinar esto no está especificado. Esta opción listará solo a aquellos usuarios que estén actualmente conectados. El <nombre> es el nombre de inicio de sesión del usuario. La <línea> es el nombre de la línea tal como se encuentra en el directorio /dev. La <hora> es la hora en que el usuario inició sesión. La <actividad> es el número de horas y minutos transcurridos desde que ocurrió actividad por última vez en esa línea en particular. Un punto indica que el terminal ha visto actividad en el último minuto y por lo tanto está "actual". Si han transcurrido más de veinticuatro horas o la línea no se ha utilizado desde el momento del arranque, la entrada se marcará como <viejo>. Este campo es útil al intentar determinar si una persona está trabajando en el terminal o no. El <pid> es el ID de proceso del proceso de inicio de sesión del usuario.

OPERANDOS

Los siguientes operandos serán soportados:

am i, am I
En la localización POSIX, limita la salida a la descripción del usuario invocador, equivalente a la opción -m. Los argumentos am y i o I deben ser argumentos separados.
archivo
Especifica una ruta de un archivo para sustituir la base de datos definida por la implementación de usuarios conectados que who utiliza por defecto.

STDIN

No utilizado.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de who:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en un valor de cadena no vacío, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en los argumentos).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en el error estándar.
LC_TIME
Determina la localización utilizada para el formato y el contenido de las cadenas de fecha y hora.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.
TZ
Determina la zona horaria utilizada al escribir información de fecha y hora. Si TZ no está establecida o está vacía, se utilizará una zona horaria predeterminada no especificada.

EVENTOS ASÍNCRONOS

Por defecto.

STDOUT

La utilidad who escribirá su formato predeterminado en la salida estándar en un formato definido por la implementación, sujeto únicamente al requisito de contener la información descrita anteriormente.

Los sistemas conformes a XSI escribirán la información predeterminada en la salida estándar en el siguiente formato general:

<nombre>[<estado>]<línea><hora>[<actividad>][<pid>][<comentario>][<salida>]

Para la opción -b, <línea> será "systemboot". El <nombre> no está especificado.

El siguiente formato se utilizará para la opción -T:

"%s %c %s %s\n" <nombre>, <estado del terminal>, <nombre del terminal>,
    <hora de inicio de sesión>

STDOUT

En la configuración regional POSIX, la salida estándar de <who> constará de líneas, una para cada usuario actualmente conectado. Cada línea contendrá la siguiente información, separada por espacios en blanco:

1.
El nombre de inicio de sesión del usuario.
2.
El nombre de la terminal, si es posible determinarlo. Si el acceso de escritura a la terminal está permitido a otros usuarios, se añadirá un carácter '+' al nombre de la terminal. Si el acceso de escritura está denegado a otros usuarios, se añadirá un carácter '-'. Si el estado de acceso de escritura no se puede determinar, se añadirá un carácter '?'. Si la línea no está asociada con una terminal, se imprimirá un carácter de espacio en blanco en lugar del nombre de la terminal.
3.
La hora y la fecha en que el usuario inició sesión, en el formato "%b %e %H:%M", que corresponde a la salida de 
date
con ese formato.
4.
Cualquier argumento especificado en la línea de comandos que no se maneje como una opción (ver OPTIONS).

Si se utiliza la opción -u con -T, el tiempo de inactividad se añadirá al final del formato anterior en un formato no especificado.

El formato de la salida estándar para los argumentos que no son de opción se especifica en la descripción de cada argumento.

El nombre de la terminal es la cadena que se encuentra en la variable de entorno TERM(5) o un nombre derivado del mismo.

El carácter que indica el estado de acceso de escritura de la terminal se especifica en la sección OPERANDS.

La hora de inicio de sesión debe tener el mismo formato que la salida de:

date +"%b %e %H:%M"

El carácter de estado de la terminal es uno de los siguientes:

+
La terminal permite el acceso de escritura a otros usuarios.
-
La terminal deniega el acceso de escritura a otros usuarios.
?
El estado de acceso de escritura de la terminal no se puede determinar.
<space>
Esta entrada no está asociada con una terminal.

En la configuración regional POSIX, la <hora de inicio de sesión> será equivalente en formato a la salida de:

date +"%b %e %H:%M"

Si se utiliza la opción -u con -T, el tiempo de inactividad se añadirá al final del formato anterior en un formato no especificado.

El error estándar se utilizará solo para mensajes de diagnóstico.

APPLICATION USAGE

El nombre init utilizado para el proceso del sistema es el más comúnmente utilizado en sistemas históricos, pero puede variar.

El ``dominio de accesibilidad'' al que se hace referencia es un concepto amplio que permite la interpretación de forma muy segura o incluso para permitir una implementación a nivel de red como el histórico rwho.

RATIONALE

Debido a las diferencias entre las implementaciones históricas, las opciones base proporcionadas fueron un compromiso para permitir a los usuarios trabajar con esas funciones. Los desarrolladores del estándar también consideraron eliminar todas las opciones, pero sintieron que estas opciones ofrecían a los usuarios una funcionalidad valiosa. Opciones adicionales para que coincidan con los sistemas históricos están disponibles en sistemas que cumplen con XSI.

Se reconoce que el comando who puede tener una utilidad limitada, especialmente en un entorno seguro de varios niveles. Sin embargo, los desarrolladores del estándar consideraron que tener un método estándar para determinar la ``accesibilidad'' de otros usuarios ayudaría a la portabilidad del usuario.

No se especificó ningún formato para la salida predeterminada de who para sistemas que no admiten la opción XSI. En un comando orientado al usuario de este tipo, diseñado solo para uso humano, esto no se consideró una deficiencia.

El formato del nombre de la terminal no está especificado, pero las descripciones de ps, talk y write requieren que utilicen el mismo formato.

Es aceptable que una implementación no produzca ninguna salida para una invocación de who mil.
