WIMDELETE(1) Comandos de usuario WIMDELETE(1)

NOMBRE

wimdelete - Eliminar una imagen de un archivo WIM

SINOPSIS

wimdelete ARCHIVO_WIM IMAGEN [OPCIÓN...]

DESCRIPCIÓN

wimdelete, o equivalentemente wimlib-imagex delete, elimina la imagen especificada del archivo Windows Imaging (WIM) ARCHIVO_WIM.

IMAGEN especifica la imagen WIM en ARCHIVO_WIM a eliminar. Puede ser el índice (basado en 1) de una imagen, el nombre de una imagen o la palabra clave "all" para especificar todas las imágenes. Puedes usar wiminfo(1) para listar las imágenes contenidas en ARCHIVO_WIM.

NOTAS

Por defecto, wimdelete reconstruye el WIM eliminando todos los datos de archivo innecesarios. Esto es diferente de ImageX y DISM de Microsoft, que solo eliminarán metadatos del árbol de directorios y datos XML para esta operación. Usa --soft si quieres el otro tipo de eliminación.

wimlib te permite eliminar todas las imágenes de un WIM y tener un WIM con 0 imágenes, aunque un archivo así puede no ser muy útil.

wimdelete no soporta WIMs divididos.

OPCIONES

--check
Antes de eliminar la imagen, verifica la integridad del WIM si hay información de integridad adicional presente. Además, incluye información de integridad adicional en el WIM modificado, incluso si no estaba presente antes.
--include-integrity
Incluye información de integridad adicional en el WIM modificado, es decir, como --check pero sin realizar ninguna verificación previa.
--soft
Realiza una eliminación "suave". Especificar esta bandera anula el comportamiento predeterminado de reconstruir el WIM completo después de eliminar una imagen. En su lugar, solo se realizarán cambios mínimos para eliminar correctamente la imagen del WIM. En particular, todos los recursos de archivo se dejarán intactos, incluso si ya no se hace referencia a ellos. Esto puede no ser lo que deseas, ya que no se ahorrará espacio al eliminar una imagen de esta manera. Sin embargo, wimoptimize puede usarse más tarde para reconstruir un archivo WIM del que se han eliminado imágenes de forma suave.
--unsafe-compact
Compacta el archivo WIM in situ, eliminando "huecos". Esto es eficiente, pero en general esta opción no debe usarse porque una compactación fallida o interrumpida corromperá el archivo WIM. Para más información, consulta la documentación de esta opción para wimoptimize(1).

EJEMPLOS

Elimina la primera imagen de 'boot.wim':

wimdelete boot.wim 1
