WARNQUOTA(8) Manual del Administrador del Sistema WARNQUOTA(8)

NOMBRE

warnquota - enviar correo a usuarios con cuotas excedidas

SINOPSIS

warnquota [ -ugsid ] [ -F formato-cuota ] [ -q tabla-cuotas ] [ -c archivo-config ] [ -a archivo-admins ] [ sistema-archivos... ]

DESCRIPCIÓN

warnquota comprueba la cuota de disco para los sistemas de archivos locales especificados (o para cada sistema de archivos local si no se especifica ninguno) y envía un mensaje de advertencia a los usuarios que han alcanzado su límite blando. Normalmente se ejecuta a través de cron(8).

-F, --format=formato-cuota
Realiza la configuración para el formato especificado (es decir, no realiza la autodetección del formato). Los nombres de formato posibles son: vfsold Formato de cuota original con UIDs / GIDs de 16 bits, vfsv0 Formato de cuota con UIDs / GIDs de 32 bits, uso de espacio de 64 bits, límites y uso de inodos de 32 bits, vfsv1 Formato de cuota con límites y uso de cuotas de 64 bits, xfs Cuota en sistemas de archivos XFS.
-q, --quota-tab=tabla-cuotas
Utiliza tabla-cuotas en lugar de /etc/quotatab como archivo con cadenas de descripción de dispositivos (ver quotatab(5) para la sintaxis).
-c, --config=archivo-config
Utiliza archivo-config en lugar de /etc/warnquota.conf como archivo de configuración (ver warnquota.conf(5) para la sintaxis).
-a, --admins-file=archivo-admins
Utiliza archivo-admins en lugar de /etc/quotagrpadmins como archivo con administradores de los grupos (ver quotagrpadmins(5) para la sintaxis).
-u, --user
comprueba si los usuarios no están excediendo las cuotas (por defecto).
-g, --group
comprueba si los grupos están excediendo las cuotas. Si un grupo excede la cuota, se envía un correo al usuario especificado en /etc/quotagrpadmins.
-s, --human-readable[=unidades]
Intenta informar sobre el espacio utilizado, el número de inodos utilizados y los límites en unidades más apropiadas que las predeterminadas. Las unidades también se pueden especificar explícitamente con un argumento opcional en el formato [ kgt ],[ kgt ] donde el primer carácter especifica las unidades de espacio y el segundo carácter especifica las unidades de inodos.
-i, --no-autofs
ignora los puntos de montaje montados por el automontador.
-d, --no-details
no adjuntar el informe de cuotas en el correo.
