NOMBRE

winbind_krb5_locator - Un plugin para MIT y Heimdal Kerberos para detectar KDCs utilizando semántica de Windows.

DESCRIPCIÓN

Este plugin forma parte de la suite samba(7).

winbind_krb5_locator es un plugin que permite a las bibliotecas MIT y Heimdal Kerberos detectar Servidores Kerberos (para el servicio KDC y kpasswd) utilizando la misma semántica que utilizan otras herramientas de la suite Samba. Esto incluye búsquedas de registros de servicio DNS conscientes de la ubicación y almacenamiento en caché del DC más cercano. El plugin utiliza la API pública de localización proporcionada por la mayoría de las implementaciones modernas de Kerberos.

REQUISITOS

Se requiere MIT Kerberos (al menos la versión 1.5) o Heimdal Kerberos (al menos la versión 1.0).

El plugin consulta el demonio winbindd(8) que necesita ser configurado e iniciado por separado.

El archivo winbind_krb5_locator.so necesita ser copiado manualmente al directorio de plugins de la biblioteca Kerberos del sistema. Para MIT Kerberos, a menudo es: /usr/lib/krb5/plugins/libkrb5/. Para Heimdal Kerberos, a menudo es: /usr/lib/plugin/krb5/. Por favor, compruebe su instalación local de Kerberos para las rutas correctas. No se requiere modificación en /etc/krb5.conf para habilitar el uso de este plugin.

Después de copiar el plugin localizador al directorio de plugins apropiado, debería estar inmediatamente disponible para su uso. Los usuarios deberían poder iniciar sesión (`kinit`) en su entorno Windows kerberizado sin ninguna modificación o configuración manual de servidores en /etc/krb5.conf.
