NOMBRE

waybar-styles - usar hojas de estilo para waybar

DESCRIPCIÓN

Waybar utiliza Hojas de Estilo en Cascada (CSS) para configurar su apariencia.

Utiliza el primer archivo que encuentra en este orden de búsqueda:

  • $XDG_CONFIG_HOME/waybar/style.css
  • ~/.config/waybar/style.css
  • ~/waybar/style.css
  • /etc/xdg/waybar/style.css
  • /etc/xdg/waybar/style.css

EJEMPLO

Una hoja de estilo de ejemplo controlada por el usuario que simplemente cambia el color del reloj a verde sobre negro, manteniendo el resto de la configuración del sistema igual, sería:

@import url("file:///etc/xdg/waybar/style.css")
#clock {
  background: #000000;
  color: #00ff00;
}

Efecto hover

Puedes aplicar un estilo especial a cualquier módulo cuando el cursor pasa sobre él.

#clock:hover {
  background-color: #ffffff;
}

Establecer el estilo del cursor

La mayoría de los tipos de módulos, si no todos, soportan la opción `cursor`. Esto se configura en tu `config.jsonc`. Si se establece en `false`, al pasar el cursor sobre el módulo no se mostrará un cursor de estilo "puntero" (tal como se conoce comúnmente por el estilo CSS web `cursor: pointer`). El comportamiento predeterminado es indicar que hay un evento de interacción disponible.

Hay más tipos de cursores para elegir estableciendo la opción `cursor` a un número, consulta la documentación oficial de Gdk3 para ver todos los tipos de cursores posibles: https://docs.gtk.org/gdk3/enum.CursorType.html. Sin embargo, ten en cuenta que no todas las opciones de cursor listadas pueden estar disponibles en tu sistema. Si intentas usar un cursor que no está disponible, la aplicación se bloqueará.

Ejemplo de cómo deshabilitar el tipo de cursor puntero (`Gdk::Hand2`) en un módulo personalizado:

"custom/my-custom-module": {
    ...
    "cursor": false,
}

Ejemplo de cómo establecer el tipo de cursor a `Gdk::Boat` (según https://docs.gtk.org/gdk3/enum.CursorType.html#boat):

"custom/my-custom-module": {
    ...
    "cursor": 8,
}
