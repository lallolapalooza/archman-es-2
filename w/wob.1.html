NOMBRE

wob - Barra de superposición para Wayland

DESCRIPCIÓN

wob es una barra ligera de superposición para volumen/luz de fondo/progreso/cualquier cosa para Wayland.

SINOPSIS

wob [opciones...]

OPCIONES

-c, --config <archivo>

Ubicación del archivo de configuración.

-v, --verbose

Aumenta la verbosidad de los mensajes, por defecto solo errores y advertencias.

-V, --version

Muestra el número de versión y sale.

-h, --help

Muestra el mensaje de ayuda y sale.

USO

wob lee valores para mostrar desde la entrada estándar en los siguientes formatos:

<valor>

o

<valor> <estilo>

Donde <valor> es un número en el intervalo de 0 a max y <estilo> es un estilo definido en wob.ini(5).

CONFIGURACIÓN

wob busca un archivo de configuración en las siguientes ubicaciones, en este orden:

1. $XDG_CONFIG_HOME/wob/wob.ini 2. ~/.config/wob/wob.ini 3. /etc/wob/wob.ini

Para obtener información sobre el formato del archivo de configuración, consulta wob.ini(5).

ENTORNO

Las siguientes variables de entorno tienen un efecto sobre wob:

WOB_DISABLE_PLEDGE

Desactiva el filtrado de llamadas al sistema seccomp en Linux. Establece esto si tienes problemas para ejecutar wob con herramientas como valgrind.
