WCTRANS(3P) Manual de Programador POSIX WCTRANS(3P)

PRÓLOGO

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

wctrans, wctrans_l — definir mapeo de caracteres

SINOPSIS

#include <wctype.h>
wctrans_t wctrans(const char *charclass);
wctrans_t wctrans_l(const char *charclass, locale_t locale);

DESCRIPCIÓN

Para wctrans(): la funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Las funciones wctrans() y wctrans_l() se definen para nombres de mapeo de caracteres válidos identificados en la configuración regional actual. El charclass es una cadena que identifica un nombre genérico de mapeo de caracteres para el cual se requiere información específica del código. Los siguientes nombres de mapeo de caracteres se definen en todas las configuraciones regionales: tolower y toupper.

Estas funciones devolverán un valor de tipo wctrans_t, que puede usarse como segundo argumento para llamadas posteriores a towctrans() y towctrans_l().

Las funciones wctrans() y wctrans_l() determinarán los valores de wctrans_t de acuerdo con las reglas del conjunto de caracteres codificados definidos por la información de mapeo de caracteres en la configuración regional actual o en la configuración regional representada por locale, respectivamente (categoría LC_CTYPE).

Los valores devueltos por wctrans() serán válidos hasta una llamada a setlocale() que modifique la categoría LC_CTYPE.

Los valores devueltos por wctrans_l() serán válidos solo en llamadas a towctrans_l() con una configuración regional representada por locale con el mismo valor de categoría LC_CTYPE.

El comportamiento no está definido si el argumento locale para wctrans_l() es el objeto de configuración regional especial LC_GLOBAL_LOCALE o no es un identificador de objeto de configuración regional válido.

VALOR DEVUELTO

Las funciones wctrans() y wctrans_l() devolverán 0 y pueden establecer errno para indicar el error si el nombre de mapeo de caracteres dado no es válido para la configuración regional actual (categoría LC_CTYPE); de lo contrario, devolverán un objeto no nulo de tipo wctrans_t que puede usarse en llamadas a towctrans() y towctrans_l().

ERRORES

Estas funciones pueden fallar si:

EINVAL
El nombre de mapeo de caracteres al que apunta charclass no es válido en la configuración regional actual.
