NOMBRE

wchar.h — manejo de caracteres anchos

SINOPSIS

#include <wchar.h>

DESCRIPCIÓN

Parte de la funcionalidad descrita en esta página de referencia amplía el estándar ISO C. Las aplicaciones deberán definir la macro de prueba de características apropiada (consulte el volumen de Interfaces del Sistema de POSIX.1‐2017, Sección 2.2, El Entorno de Compilación) para habilitar la visibilidad de estos símbolos en esta cabecera.

El encabezado <wchar.h> definirá los siguientes tipos:

FILE
Según se describe en <stdio.h>.
locale_t
Según se describe en <locale.h>.
mbstate_t
Un tipo de objeto distinto de un tipo de arreglo que puede contener la información de estado de conversión necesaria para convertir entre secuencias de caracteres (posiblemente multibyte) y caracteres anchos. Si se está utilizando un conjunto de códigos tal que un mbstate_t necesita preservar más de dos niveles de estado reservado, los resultados no están definidos.
size_t
Según se describe en <stddef.h>.
va_list
Según se describe en <stdarg.h>.
wchar_t
Según se describe en <stddef.h>.
wctype_t
Un tipo escalar de un objeto de datos que puede contener valores que representan la clasificación de caracteres específica de la localización.
wint_t
Un tipo entero capaz de almacenar cualquier valor válido de wchar_t o WEOF.

La etiqueta tm se declarará como un tipo de estructura incompleta, cuyo contenido se describe en la cabecera <time.h>.

La implementación deberá soportar uno o más entornos de programación en los que el ancho de wint_t no sea mayor que el ancho del tipo long. Los nombres de estos entornos de programación se pueden obtener utilizando la función confstr() o la utilidad getconf.

El encabezado <wchar.h> definirá las siguientes macros:

WCHAR_MAX
Según se describe en <stdint.h>.
WCHAR_MIN
Según se describe en <stdint.h>.
WEOF
Expresión constante de tipo wint_t que devuelven varias funciones WP para indicar fin de archivo.
NULL
Según se describe en <stddef.h>.

La inclusión del encabezado <wchar.h> puede hacer visibles todos los símbolos de los encabezados <ctype.h>, <string.h>, <stdarg.h>, <stddef.h>, <stdio.h>, <stdlib.h> y <time.h>.

DESCRIPTION

The <wchar.h> header shall define the types clock_t, size_t, and time_t, and the macros and functions described below. It also defines the FILE, fpos_t, and va_list types.

The <wchar.h> header shall define the following macros:

NULL
The implementation shall define NULL to a null pointer constant.
WCHART_MAX
The value of the maximum value of a wint_t.
WEOF
An integer constant expression of type wint_t that is distinct from any value representable by an object of type wchar_t. A null wide character or any other character that cannot be distinguished from a null wide character (when read from an input stream) shall not be represented by WEOF. The implementation shall define WEOF to a value of type wint_t.

The <wchar.h> header shall define the wint_t type.

The <wchar.h> header shall define the mbstate_t type.

The <wchar.h> header shall define the size_t type.

The <wchar.h> header shall define the wchar_t type.

APPLICATION USAGE

The iswblank() function was a late addition to the ISO C standard and was introduced at the same time as the ISO C standard introduced <wctype.h>, which contains all of the isw*() functions. The Open Group Base Specifications had previously aligned with the MSE working draft and had introduced the rest of the isw*() functions into <wchar.h>. For backwards-compatibility, the original set of isw*() functions, without iswblank(), are permitted (as part of the XSI option) in <wchar.h>. For maximum portability, applications should include <wctype.h> in order to obtain declarations for the isw*() functions. This compatibility has been made obsolescent.

RATIONALE

In the ISO C standard, the symbols referenced as XSI extensions are in <wctype.h>. Their presence here is thus an extension.
