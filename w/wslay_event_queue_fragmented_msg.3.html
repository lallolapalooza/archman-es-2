WSLAY_EVENT_QUEUE_FRAGMENTED_MSG(3) wslay WSLAY_EVENT_QUEUE_FRAGMENTED_MSG(3)

NOMBRE

wslay_event_queue_fragmented_msg - Poner en cola un mensaje fragmentado para transmisión futura

SINOPSIS

#include <wslay/wslay.h>

int wslay_event_queue_fragmented_msg(wslay_event_context_ptr ctx, const struct wslay_event_fragmented_msg *arg)
int wslay_event_queue_fragmented_msg_ex(wslay_event_context_ptr ctx, const struct wslay_event_fragmented_msg *arg, uint8_t rsv)

DESCRIPCIÓN

wslay_event_queue_fragmented_msg() y wslay_event_queue_fragmented_msg_ex() ponen en cola un mensaje fragmentado especificado en arg. La struct wslay_event_fragmented_msg se define como:

union wslay_event_msg_source {
    int   fd;
    void *data;
};
struct wslay_event_fragmented_msg {
    uint8_t                             opcode;
    union wslay_event_msg_source        source;
    wslay_event_fragmented_msg_callback read_callback;
};
typedef ssize_t (*wslay_event_fragmented_msg_callback)(wslay_event_context_ptr ctx, uint8_t *buf, size_t len, const union wslay_event_msg_source *source, int *eof, void *user_data)

El miembro opcode es el opcode del mensaje. El miembro source es una unión y normalmente contiene una "fuente" para generar datos del mensaje. read_callback es una función de devolución de llamada llamada por wslay_event_send() para leer datos del mensaje desde source. La implementación de wslay_event_fragmented_msg_callback debe almacenar como máximo len bytes de datos en buf y devolver el número de bytes almacenados. Si se han leído todos los datos (es decir, fin de archivo), establezca *eof en 1. Si no se pueden generar datos en este momento, devuelva 0. Si hay un error, devuelva -1 y establezca el código de error WSLAY_ERR_CALLBACK_FAILURE usando wslay_event_set_error().

Esta función solo admite mensajes no de control. Para tramas de control, use wslay_event_queue_msg() o wslay_event_queue_close().

Esta función simplemente pone en cola un mensaje y no lo envía. La llamada a la función wslay_event_send() envía estos mensajes en cola.

wslay_event_queue_fragmented_msg_ex() acepta adicionalmente el parámetro rsv, que son bits reservados para enviar. Para establecer bits reservados, use las macros WSLAY_RSV1_BIT, WSLAY_RSV2_BIT y WSLAY_RSV3_BIT. Consulte wslay_event_config_set_allowed_rsv_bits() para ver los bits reservados permitidos para establecer.

VALOR DE RETORNO

wslay_event_queue_fragmented_msg() y wslay_event_queue_fragmented_msg_ex() devuelven 0 si tiene éxito, o devuelven los siguientes códigos de error negativos:

WSLAY_ERR_NO_MORE_MSG
No se pudo poner en cola el mensaje dado. Una de las posibles razones es que se ha puesto en cola/enviado una trama de control de cierre y ya no se permite poner en cola más mensajes.
WSLAY_ERR_INVALID_ARGUMENT
El mensaje dado no es válido; o se ha establecido un bit en rsv que no está permitido (consulte wslay_event_config_set_allowed_rsv_bits()).
WSLAY_ERR_NOMEM
Sin memoria.

VER TAMBIÉN

wslay_event_queue_msg(), wslay_event_queue_msg_ex(), wslay_event_queue_close()
