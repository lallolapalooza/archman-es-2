NOMBRE

wikiman - Motor de búsqueda sin conexión para páginas del manual, Arch Wiki, Gentoo Wiki y otra documentación.

SINOPSIS

wikiman [-q] [-a] [-p] [-k] [-c]
[-l <idiomas separados por comas>] [-s <fuentes separadas por comas>]
[-f <buscador difuso>] [-H <visor html>] [-R] <palabra clave>...
wikiman -S
wikiman -W <shell>
wikiman -v
wikiman -h

Si no se proporcionan palabras clave, muestra todas las páginas.

DESCRIPCIÓN

Wikiman es un motor de búsqueda sin conexión para páginas del manual, Arch Wiki, Gentoo Wiki y otra documentación.

Wikiman proporciona una interfaz sencilla para navegar por la documentación sin necesidad de ser exacto y de estar conectado a internet. Esto se logra utilizando búsqueda de texto completo para wikis, coincidencia parcial de nombres y descripciones para páginas del manual, y filtrado difuso para los resultados de búsqueda.

OPCIONES

-l <idiomas separados por comas>
idioma(s) de búsqueda
por defecto: en

-s <fuentes separadas por comas>
fuentes a usar
por defecto: (todas las disponibles)

-f <buscador difuso>
buscador difuso a usar
por defecto: fzf

-q
habilitar modo de búsqueda rápida

-a
habilitar modo de operador AND

-p
deshabilitar vista previa rápida de resultados

-k
mantener abierto después de ver un resultado

-c
mostrar columna de fuente

-H <visor html>
visor para páginas HTML
por defecto: w3m

-R
imprimir salida sin formato

-S
listar fuentes disponibles y salir

-W <shell>
imprimir código de widget para el shell especificado y salir

-v
imprimir versión y salir

-h
mostrar ayuda y salir

CONFIGURACIÓN:

Ubicación del archivo de configuración del usuario por defecto: ~/.config/wikiman/wikiman.conf (si XDG_CONFIG_HOME no está establecido).

Ubicación de la configuración a nivel del sistema: /etc/wikiman.conf

Fuentes

fuentes =

Buscador difuso

fuzzy_finder = fzf

Modo de búsqueda rápida

quick_search = false

Modo de operador AND

and_operator = false

Salida sin formato

raw_output = false

Idioma(s)

man_lang = en

wiki_lang = en

Listar todos los idiomas de man además del inglés (en):
find '/usr/share/man' -maxdepth 1 -type d -not -name 'man*' -printf '%P '

Listar todos los idiomas de Arch Wiki:
find '/usr/share/doc/arch-wiki/html' -maxdepth 1 -type d -printf '%P '

Listar todos los idiomas de la documentación de FreeBSD:
find '/usr/share/doc/freebsd-docs' -maxdepth 1 -type d -printf '%P '

Vista previa TUI

tui_preview = true

TUI mantener abierto

tui_keep_open = false

TUI mostrar columna de fuente

tui_source_column = false

Visor TUI para páginas HTML

tui_html = w3m

FUENTES ADICIONALES:

Directorio de fuentes de usuario por defecto: ~/.config/wikiman/sources (si XDG_CONFIG_HOME no está establecido).

Directorio de fuentes a nivel del sistema: /usr/share/wikiman/sources

Instalar una fuente:

Para instalar una fuente adicional llamada <nombre>, descárgala usando el Makefile de Wikiman:

sudo make install source-<nombre>
