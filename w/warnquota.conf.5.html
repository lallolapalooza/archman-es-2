WARNQUOTA.CONF(5) Manual de formatos de archivo WARNQUOTA.CONF(5)

NOMBRE

warnquota.conf - configuración para warnquota

SINOPSIS

/etc/warnquota.conf

DESCRIPCIÓN

El archivo warnquota.conf almacena una configuración para la herramienta warnquota(8), que se utiliza para notificar a un usuario o grupo que excede sus límites de cuota de disco.

La sintaxis es un nombre de opción seguido de un signo igual y el valor de la opción. Se permiten caracteres de espacio en blanco alrededor de los nombres y valores de las opciones.

Las líneas vacías o las líneas que comienzan con un signo de almohadilla o un punto y coma se ignoran.

El valor de una opción puede estar entre comillas o no. El valor puede abarcar varias líneas siempre que cada línea anterior termine con una barra invertida.

Algunos valores de opción pueden contener secuencias de formato que se expandirán a sus respectivos valores. Se reconocen las siguientes secuencias:

%d
nombre de dominio
%h
nombre del host
%i, %s
nombre de usuario o grupo
%%
carácter % literal
|
carácter de nueva línea

OPCIONES

CC_BEFORE
Enviar a la dirección de copia carbón (CC) solo cuando un usuario tenga menos del tiempo de gracia especificado restante. El valor es un número seguido de una unidad de tiempo. Las unidades conocidas son seconds, minutes, hours y days. Ejemplo: 5 days
CC_TO
Una dirección de correo electrónico para colocar en el encabezado del destinatario de copia carbón (CC:). El valor predeterminado es root.
CHARSET
Define el conjunto de caracteres para los correos electrónicos enviados. El valor predeterminado será el conjunto de caracteres de la configuración regional actual utilizada al ejecutar el comando warnquota, si la configuración regional no es C ni POSIX. De lo contrario, no se especificará ningún conjunto de caracteres en los correos electrónicos.
FROM
Define la dirección de correo electrónico de From:. El valor predeterminado es support@localhost.
GROUP_MESSAGE
Un texto que se envía como cuerpo del correo electrónico si un grupo excede sus límites. Esta opción reconoce secuencias de formato.
GROUP_SIGNATURE
Un texto de firma que se añade a la notificación para un grupo. El valor predeterminado es una explicación general que utiliza los valores SUPPORT y PHONE. Esta opción reconoce secuencias de formato.
LDAP_BASEDN
Nombre distinguido base para consultas LDAP.
LDAP_BINDDN
Nombre distinguido de enlace para consultas LDAP.
LDAP_BINDPW
Contraseña de enlace para consultas LDAP.
LDAP_DEFAULT_MAIL_DOMAIN
Dominio de dirección de correo electrónico predeterminado del usuario buscado si el atributo LDAP dado no especifica ninguno.
LDAP_HOST
Nombre del servidor LDAP al que conectarse si LDAP_URI no está definido.
LDAP_MAIL
Un valor booleano que controla si se debe usar LDAP para buscar la dirección de correo electrónico del usuario. Los valores posibles son true y false. El valor predeterminado es false.
LDAP_MAIL_ATTRIBUTE
El atributo LDAP que contiene la dirección de correo electrónico del usuario.
LDAP_PORT
Número de puerto del servidor LDAP al que conectarse si LDAP_URI no está definido.
LDAP_SEARCH_ATTRIBUTE
El atributo LDAP que contiene el ID del usuario para buscar.
LDAP_URI
La URL del servidor LDAP a utilizar para buscar direcciones de correo electrónico de usuarios. Esta opción tiene prioridad sobre LDAP_HOST y LDAP_PORT. Ejemplo: ldaps://example.com:389/
MESSAGE
El comienzo del texto que se envía como cuerpo del correo electrónico si un usuario excede sus límites. Esta opción reconoce secuencias de formato.
MAIL_CMD
El comando a ejecutar para enviar un correo electrónico. El texto del correo electrónico, incluidos todos los encabezados, se pasa a la entrada estándar del comando. El valor predeterminado es /usr/lib/sendmail -t.
MAILDEV
El dispositivo con cuotas de disco a excluir del envío de notificaciones si hay límites excedidos. Esta opción debe identificar el dispositivo donde se almacenan los buzones de correo para evitar que el MDA local rebote la notificación de warnquota debido a la falta de espacio para almacenar correos electrónicos nuevos. El valor especial any denota todos los dispositivos.
PHONE
El contacto telefónico del soporte al usuario. El valor predeterminado es (xxx) xxx-xxxx o (yyy) yyy-yyyy.
SIGNATURE
El final del cuerpo del correo electrónico si un usuario excede sus límites. El valor predeterminado es una explicación general que utiliza los valores SUPPORT y PHONE. Esta opción reconoce secuencias de formato.
SUBJECT
El texto a colocar en el encabezado Subject:. El valor predeterminado es Disk Quota usage on system.
SUPPORT
El contacto del soporte al usuario. El valor predeterminado es support@localhost.

EJEMPLO

# comentario

FROM = root@example.com
SUPPORT = support@example.com
PHONE = 1234
