NOMBRE

wlfreerdp - cliente de Wayland para FreeRDP

SINOPSIS

wlfreerdp [archivo] [opciones_cliente_por_defecto] [/v:<servidor>[:puerto]] [/version] [/help]

DESCRIPCIÓN

wlfreerdp es un cliente del Protocolo de Escritorio Remoto (RDP) para Wayland, que forma parte del proyecto FreeRDP. Un servidor RDP está integrado en muchas ediciones de Windows. Servidores alternativos incluyen xrdp y VRDP (VirtualBox).

OPCIONES

El cliente de Wayland también soporta muchas de las opciones_cliente_por_defecto que no se describen aquí. Para obtener detalles sobre estas, consulta la página del manual xfreerdp(1).

/v:<servidor>[:puerto]
El nombre de host o IP del servidor, y opcionalmente el puerto, al que conectarse.
/version
Imprime la versión y sale.
/help
Imprime la ayuda y sale.

ESTADO DE SALIDA

no 0
En caso de fallo.
