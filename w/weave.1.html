WEAVE(1) Manual de Comandos Generales WEAVE(1)

NOMBRE

weave - traduce WEB a TeX

SINOPSIS

weave [-x] archivo_web[.web] [{archivo_cambios[.ch]|-} [archivo_salida[.tex]]]

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se puede encontrar en el archivo info o en el manual Web2C: A TeX implementation.

El programa weave se utiliza para crear un archivo TeX para visualizar un programa Web. Se encarga adecuadamente de los detalles tipográficos como el diseño de página y el uso de sangría, cursiva, negrita, etc., y proporciona información exhaustiva de referencias cruzadas que recopila automáticamente. Los argumentos de la línea de comandos son los mismos que para tangle, excepto por la opción: -x indica que se omitan el índice, la lista de nombres de módulos y las páginas de tabla de contenidos. (Sin embargo, se seguirá escribiendo un archivo CONTENTS.tex cuando se procese el archivo TeX, a menos que se redefinan algunas macros en webmac.tex).

El nombre del archivo TeX de salida se forma añadiendo .tex a la raíz del nombre del archivo Web o a partir del tercer argumento. En este caso, puede especificar '-' como archivo de cambios vacío.

Hay varias macros que probablemente deberían ser redefinidas por el programador al principio del archivo Web. Es una buena idea establecer \title al nombre del programa. Y, para generar solo los módulos modificados, se puede escribir \let\maybe=\iffalse (generalmente como el primer cambio en el archivo de cambios).

AMBIENTE

La variable de entorno WEBINPUTS se utiliza para buscar los archivos de entrada, o el valor predeterminado del sistema si WEBINPUTS no está configurado. Consulte tex(1) para obtener detalles sobre la búsqueda.

ARCHIVOS

$TEXMFMAIN/tex/plain/knuth-lib/webmac.tex
Macros de TeX utilizadas por la salida de weave.

VER TAMBIÉN

tangle(1) para referencias, autores y otra información.
