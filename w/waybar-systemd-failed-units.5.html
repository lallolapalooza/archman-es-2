NOMBRE

waybar - módulo de monitorización de unidades fallidas de systemd

DESCRIPCIÓN

El módulo systemd-failed-units muestra el número de unidades de systemd que han fallado.

CONFIGURACIÓN

Abordado por systemd-failed-units

format:
tipo: string
predeterminado: {nr_failed} fallidas
El formato, cómo se debe mostrar la información. Este formato se utiliza cuando no se especifican otros formatos.

format-ok:
tipo: string
Este formato se utiliza cuando no hay unidades fallidas.

user:
tipo: bool
predeterminado: true
Opción para contar las unidades de systemd del usuario.

system:
tipo: bool
predeterminado: true
Opción para contar las unidades de systemd del sistema (PID=1).

hide-on-ok:
tipo: bool
predeterminado: true
Opción para ocultar este módulo cuando no hay unidades fallidas.

menu:
tipo: string
Acción que abre el menú emergente.

menu-file:
tipo: string
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con el id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: bool
predeterminado: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

{nr_failed_system}: Número de unidades fallidas del systemd del sistema (PID=1).

{nr_failed_user}: Número de unidades fallidas del systemd del usuario.

{nr_failed}: Número total de unidades fallidas.

{systemd_state}: Estado de la sesión del sistema systemd

{user_state}: Estado de la sesión del usuario systemd

{overall_state}: Estado general de la sesión del sistema y del usuario. ("Ok" o "Degraded")

EJEMPLOS

"systemd-failed-units": {
	"hide-on-ok": false,
	"format": "✗ {nr_failed}",
	"format-ok": "✓",
	"system": true,
	"user": false,
}
