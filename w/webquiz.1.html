NOMBRE

WebQuiz: un paquete de LaTeX para escribir cuestionarios en línea -

WebQuiz hace posible utilizar LaTeX para escribir cuestionarios interactivos en línea. Los cuestionarios se escriben primero en LaTeX y luego se convierten a HTML usando WebQuiz, que está escrito en python. La conversión de LaTeX a HTML se realiza en segundo plano utilizando TeX4ht. La idea es que puedas producir buenos cuestionarios en línea usando WebQuiz y conocimientos básicos de LaTeX.

WebQuiz está diseñado para ser utilizado desde la línea de comandos. Por ejemplo, si quiz1.tex es un archivo LaTeX para un cuestionario entonces:

latex quiz1
produce un archivo DVI "legible" para el cuestionario
pdflatex quiz1
produce un archivo PDF "legible" para el cuestionario
webquiz quiz1
crea la página web quiz1.html

Si prefieres usar LaTeX desde una GUI para LaTeX, entonces debería ser posible configurarla para usar WebQuiz directamente. Como ejemplo, el manual proporciona algunos detalles sobre cómo hacer esto para TeXShop.

INSTALACIÓN

Para usar WebQuiz necesitas tener instalada una distribución estándar de LaTeX, como TeXLive, que incluya TeX4ht. Además, necesitas tener Python3 instalado. Como WebQuiz usa gráficos vectoriales escalables (SVG), deberías comprobar que todas las dependencias de dvisvgm están instaladas en tu sistema, especialmente si planeas usar gráficos o imágenes.

Una vez que los componentes TeX del paquete WebQuiz hayan sido instalados, puedes instalar los componentes web de WebQuiz usando el siguiente comando, que necesita ser ejecutado desde la línea de comandos:

> webquiz --initialise

Si quieres instalar los componentes web de WebQuiz en un directorio del sistema, necesitas ejecutar este comando desde una cuenta de administrador, así que usa sudo en un sistema tipo Unix. Para más detalles sobre la instalación y configuración de WebQuiz, por favor consulta la Sección 3.2 del manual de WebQuiz.

Por favor, consulta el manual para más detalles sobre cómo inicializar y usar WebQuiz.

INSTALACIÓN DESDE EL ARCHIVO ZIP DE CTAN

Tanto en sistemas tipo Unix (incluyendo macosx) como en sistemas Windows (usando TeXLive o MiKTeX), puedes instalar WebQuiz descargando el archivo zip de WebQuiz desde:

http://mirrors.ctan.org/macros/latex/contrib/webquiz.zip

Para instalar el paquete, descomprime este archivo y cambia al subdirectorio webquiz/scripts y ejecuta:

> webquiz --tex-install

(o webquiz.bat --text-install en Windows). Este comando descomprime los archivos de webquiz en sus ubicaciones estándar en el árbol de instalación de TeX, por lo que debe ejecutarse desde una cuenta de administrador, o usando sudo en un sistema tipo Unix. Aproximadamente lo que hace este comando es lo siguiente:

  • Crea un enlace simbólico, o equivalente, al ejecutable principal de WebQuiz, que es el archivo webquiz.py en el directorio scripts.
  • Copia el directorio latex a algún lugar de la ruta de búsqueda de TeX y luego ejecuta mktexlsr para que LaTeX y WebQuiz puedan encontrar estos archivos.
  • Copia el código python al subdirectorio de scripts de TeX.
  • Copia el subdirectorio de documentación de WebQuiz al subdirectorio doc/latex de TeX.

Si estás usando MiKTeX, puede que necesites abrir la consola de MiKTeX, ir al menú Tareas y luego reconstruir la base de datos de nombres de archivos TeX.

Una vez que los archivos anteriores estén en su lugar, inicializa WebQuiz siguiendo las instrucciones de instalación anteriores.

Principalmente para fines de desarrollo, existe otra opción de línea de comandos no documentada para eliminar estos archivos de TEXMFMAIN:

> sudo webquiz/scripts/webquiz --tex-uninstall

REQUISITOS DEL SISTEMA

Para funcionar, WebQuiz necesita que los siguientes programas estén instalados en tu sistema:

  • Una distribución LaTeX actualizada, como la proporcionada por TeXLive. En particular, necesitas tener TeX4ht y make4ht instalados. Desafortunadamente, desde que se lanzó TeXLive 2018, ha habido un número significativo de actualizaciones en varios paquetes que WebQuiz utiliza, incluyendo actualizaciones a TeX4ht, make4ht, tikz y pstricks. Por esta razón, se recomienda encarecidamente que actualices todos los paquetes desde ctan_ antes de usar WebQuiz_.
  • python3 Al momento de escribir esto, está disponible python 3.7.2.
  • Javascript
  • Si planeas usar pstricks con WebQuiz, o si quieres compilar el manual en línea de WebQuiz, entonces necesitas asegurarte de que ghostscript y dvisvgm estén instalados y configurados correctamente en tu sistema. Consulta el manual de WebQuiz y la documentación de dvisvgm para más detalles.
  • Un servidor web. Para ver cuestionarios en línea, por supuesto, necesitas un servidor web. Como se describe en la sección de Instalación, también necesitarás una copia de los componentes de WebQuiz en tu servidor web usando el comando:

    > webquiz --initialise
