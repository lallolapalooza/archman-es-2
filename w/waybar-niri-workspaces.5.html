NOMBRE

waybar - módulo de espacios de trabajo de niri

DESCRIPCIÓN

El módulo workspaces muestra los espacios de trabajo actualmente utilizados en niri.

CONFIGURACIÓN

Abordado por niri/workspaces

all-outputs:
tipo: bool
predeterminado: false
Si se establece en falso, los espacios de trabajo solo se mostrarán en la salida en la que se encuentren. Si se establece en verdadero, todos los espacios de trabajo se mostrarán en cada salida.

format:
tipo: string
predeterminado: {value}
El formato, cómo se debe mostrar la información.

format-icons:
tipo: array
Basado en el nombre del espacio de trabajo, el índice y el estado, se selecciona el icono correspondiente. Consulte icons.

disable-click:
tipo: bool
predeterminado: false
Si se establece en falso, puede hacer clic para cambiar de espacio de trabajo. Si se establece en verdadero, este comportamiento se deshabilita.

disable-markup:
tipo: bool
predeterminado: false
Si se establece en verdadero, la etiqueta del botón escapará el marcado pango.

current-only:
tipo: bool
predeterminado: false
Si se establece en verdadero, solo se mostrará el espacio de trabajo activo o enfocado.

on-update:
tipo: string
Comando a ejecutar cuando se actualiza el módulo.

expand:
tipo: bool
predeterminado: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

{value}: Nombre del espacio de trabajo, o índice para espacios de trabajo sin nombre, según lo definido por niri.

{name}: Nombre del espacio de trabajo para los espacios de trabajo con nombre.

{icon}: Icono, como se define en format-icons.

{index}: Índice del espacio de trabajo en su salida.

{output}: Salida donde se encuentra el espacio de trabajo.

ICONOS

Además de la coincidencia de nombres de espacio de trabajo, se pueden establecer los siguientes format-icons.

  • default: Se mostrará cuando no se encuentren coincidencias de cadenas.
  • focused: Se mostrará cuando el espacio de trabajo esté enfocado.
  • active: Se mostrará cuando el espacio de trabajo esté activo (visible) en su salida.
  • urgent: Se mostrará cuando el espacio de trabajo tenga ventanas urgentes.
  • empty: Se mostrará cuando el espacio de trabajo esté vacío.

EJEMPLOS

"niri/workspaces": {
	"format": "{icon}",
	"format-icons": {
		// Espacios de trabajo con nombre
		// (debes configurarlos en niri)
		"browser": "",
		"discord": "",
		"chat": "",
		// Iconos por estado
		"active": "",
		"default": ""
	}
}

Estilo

  • #workspaces button
  • #workspaces button.focused: El único espacio de trabajo enfocado.
  • #workspaces button.active: El espacio de trabajo está activo (visible) en su salida.
  • #workspaces button.urgent: El espacio de trabajo tiene una o más ventanas urgentes.
  • #workspaces button.empty: El espacio de trabajo está vacío.
  • #workspaces button.current_output: El espacio de trabajo es de la misma salida que la barra en la que se muestra.
  • #workspaces button#niri-workspace-<nombre>: Espacios de trabajo llamados así, o índice para espacios de trabajo sin nombre.
