NOMBRE

weston-rdp - el backend RDP para Weston

SINOPSIS

weston --backend=rdp

DESCRIPCIÓN

El backend RDP permite ejecutar un entorno weston sin necesidad de hardware gráfico específico o dispositivos de entrada. Los usuarios pueden interactuar con weston simplemente conectándose usando el protocolo RDP.

El backend RDP utiliza FreeRDP para implementar la parte RDP, actuando como un servidor RDP que escucha las conexiones entrantes. Soporta diferentes códecs para codificar el contenido gráfico. Dependiendo de lo que soporte el cliente RDP, el backend codificará las imágenes usando el códec remoteFx, el códec NS o recurrirá a bitmapUpdate crudo.

En cuanto a la seguridad, el backend soporta seguridad RDP o TLS. Las claves y certificados deben proporcionarse al backend dependiendo del tipo de seguridad solicitada. El backend RDP anunciará las opciones de seguridad en función de los archivos proporcionados.

El backend RDP es consciente de multi-asiento, por lo que si dos clientes se conectan al backend, obtendrán su propio asiento.

CONFIGURACIÓN

El backend RDP utiliza las siguientes entradas de weston.ini.

Sección rdp

refresh-rate=tasa
Especifica la tasa de redibujado del escritorio en Hz. Si no se especifica, el valor predeterminado es 60Hz. Cambiar esto puede ser útil si tienes una pantalla más rápida que 60Hz, o si quieres reducir las actualizaciones para disminuir el tráfico de red.
tls-key=archivo
El archivo que contiene la clave para la seguridad TLS. Para tener seguridad TLS también necesitas proporcionar un archivo que contenga un certificado.
tls-cert=archivo
El archivo que contiene el certificado para la seguridad TLS. Para tener seguridad TLS también necesitas proporcionar un archivo de clave.

OPCIONES

Cuando se carga el backend RDP, weston entenderá las siguientes opciones de línea de comandos adicionales.

--address=dirección
La dirección IP en la que el backend RDP escuchará las conexiones RDP. Por defecto, escucha en 0.0.0.0.
--port=puerto
El puerto TCP en el que escuchar las conexiones, por defecto es 3389.
--no-clients-resize
Por defecto, cuando un cliente se conecta al backend RDP, instruirá a weston para que se redimensione a las dimensiones de la resolución anunciada por el cliente. Cuando esta opción está activada, weston forzará al cliente a redimensionarse a su propia resolución.
--no-remotefx-codec
El códec de compresión RemoteFX está habilitado por defecto, pero puede ser necesario deshabilitarlo para solucionar incompatibilidades entre implementaciones. Esta opción puede ser eliminada en el futuro cuando se resuelvan todos los problemas conocidos.
--rdp4-key=archivo
El archivo que contiene la clave RSA para la seguridad RDP. Dado que la seguridad RDP es conocida por ser insegura, esta opción debe evitarse en producción.
--rdp-tls-key=archivo
El archivo que contiene la clave para la seguridad TLS. Para tener seguridad TLS también necesitas proporcionar un archivo que contenga un certificado.
--rdp-tls-cert=archivo
El archivo que contiene el certificado para la seguridad TLS. Para tener seguridad TLS también necesitas proporcionar un archivo de clave.
--external-listener-fd=fd
Especifica un descriptor de archivo heredado del proceso que lanzó weston para escuchar las conexiones de clientes. Solo se deben usar sockets locales (como AF_VSOCK), ya que esto será considerado una conexión local por el backend RDP, y la seguridad TLS y RDP serán eludidas.

Generación de material criptográfico para el backend RDP

Para generar un archivo de clave a usar para la seguridad RDP, necesitas la utilidad winpr-makecert que se incluye con FreeRDP:

$ winpr-makecert -rdp -silent -n rdp-security

Esto creará un archivo rdp-security.key.

Puedes generar un archivo de clave y certificado para usar con la seguridad TLS utilizando invocaciones típicas de openssl:

$ openssl genrsa -out tls.key 2048
Generando clave privada RSA, módulo de 2048 bits
[...]
$ openssl req -new -key tls.key -out tls.csr
[...]
$ openssl x509 -req -days 365 -signkey tls.key -in tls.csr -out tls.crt
[...]

Obtendrás los archivos tls.key y tls.crt para usar con el backend RDP.
