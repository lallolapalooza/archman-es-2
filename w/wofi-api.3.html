wofi-api(3) Manual de funciones de biblioteca wofi-api(3)

NOMBRE

wofi - funciones y documentación de la API

DESCRIPCIÓN

Las funciones documentadas aquí se utilizan para interactuar con wofi. Están definidas en wofi_api.h.

ESTRUCTURAS

struct cache_line {

char* line;
struct wl_list link;
};

FUNCIONES DE API

Las siguientes funciones se utilizan para interactuar con wofi.

char* wofi_parse_image_escapes(const char* text)
Esta función toma texto que contiene secuencias de escape de imágenes y marcación pango y devolverá el texto plano con todo eso eliminado. La cadena devuelta es una nueva asignación y debe ser liberada por el llamador cuando termine con ella.

const char* text - El texto de entrada que contiene secuencias de escape de imágenes y marcación pango.

void wofi_write_cache(struct mode* mode, const char* cmd)
Escribe una entrada en el archivo de caché.

struct mode* mode - El struct mode* dado a la función init() de su modo.

const char* cmd - La entrada a escribir en el archivo de caché. Si esta entrada ya existe, se incrementará el número de veces que se ha escrito.

void wofi_remove_cache(struct mode* mode, const char* cmd)
Elimina una entrada del archivo de caché.

struct mode* mode - El struct mode* dado a la función init() de su modo.

const char* cmd - La entrada a eliminar del archivo de caché. Esto NO decrementa el número de veces que se ha escrito, sino que elimina completamente la entrada.

struct wl_list* wofi_read_cache(struct mode* mode)
Lee la caché y devuelve un struct wl_list* que contiene las entradas. La lista está compuesta por entradas struct cache_line*. La documentación de wayland debe ser consultada para el uso de una wl_list.

struct mode* mode - El struct mode* dado a la función init() de su modo.

struct widget* wofi_create_widget(struct mode* mode, char* text[], char* search_text, char* actions[], size_t action_count)
Crea un widget a partir de la información especificada. Este widget debe ser devuelto por la función get_widget() del modo para ser mostrado.

struct mode* mode - El struct mode* dado a la función init() de su modo.

char* text[] - El array de texto para mostrar en la entrada en wofi. Cada elemento del array representa el texto para 1 acción. El array solo debe ser mayor que 1 si está creando una entrada de acción múltiple. Las entradas de acción múltiple necesitan proporcionar 1 cadena de texto por cada acción que tenga la entrada.

char* search_text - El texto por el que el usuario puede buscar para encontrar este widget.

char* actions[] - El array de acciones para la entrada. Una acción es el texto que se pasa a la función exec() de un modo cuando el usuario selecciona una entrada. Las entradas de acción múltiple necesitan proporcionar 1 cadena de acción por cada acción que tenga la entrada.

size_t action_count - El número de acciones que tendrá la entrada.

void wofi_insert_widgets(struct mode* mode)
Esto volverá a consultar al modo para obtener más widgets.

struct mode* mode - El struct mode* dado a la función init() de su modo.

char* wofi_get_dso_path(struct mode* mode)
Devuelve la ruta a la DSO de este modo si es un modo externo, devuelve NULL en caso contrario.

struct mode* mode - El struct mode* dado a la función init() de su modo.

bool wofi_allow_images(void)
Devuelve true si el usuario habilitó las imágenes, false en caso contrario.
bool wofi_allow_markup(void)
Devuelve true si el usuario habilitó la marcación pango, false en caso contrario.
uint64_t wofi_get_image_size(void)
Devuelve el tamaño de imagen especificado por el usuario, 32 por defecto. Wofi escalará las imágenes por usted, esto es solo informativo y no es requerido, pero puede ser útil si hay varios tamaños disponibles.
bool wofi_mod_shift(void)
Devuelve true si el usuario estaba manteniendo presionada la tecla Shift al seleccionar una entrada, false en caso contrario.
bool wofi_mod_control(void)
Devuelve true si el usuario estaba manteniendo presionada la tecla Control al seleccionar una entrada, false en caso contrario.
void wofi_term_run(const char* cmd)
Ejecuta el comando proporcionado en un emulador de terminal. Se utiliza el siguiente orden para elegir un emulador de terminal: el terminal especificado por el usuario, kitty, alacritty, wezterm, foot, termite, gnome-terminal, weston-terminal. Si ninguno de estos se encuentra, la ejecución fallará.

const char* cmd - El comando a ejecutar, este se invoca haciendo term -- cmd.

void wofi_exit(void)
Esta función es cómo debe llamar para salir de wofi. Comprueba el estado dado y solo establece un código de salida personalizado si pasa EXIT_SUCCESS. Si llama a la función exit() de libc, entonces el código de salida personalizado siempre se utilizará, incluso si se debe informar de un error.
