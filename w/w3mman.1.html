W3MMAN(1) Manual de Comandos Generales W3MMAN(1)

NOMBRE

w3mman - una interfaz a los manuales de referencia en línea a través de w3m(1)

SINOPSIS

w3mman [ -M ruta ] [ [ sección ] página ]
w3mman [ -M ruta ] [ sección ] -k palabra_clave
w3mman -l archivo

DESCRIPCIÓN

w3mman es un script de Perl que utiliza w3m(1) para servir como paginador para los manuales de referencia en línea.

OPCIONES

A continuación se incluye un resumen de las opciones.

-M ruta
Especifica ruta como MANPATH alternativa a usar.
-k palabra_clave
Especifica palabra_clave.
-l archivo
Especifica un archivo.

ENTORNO

Hay dos variables disponibles para depuración.

W3MMAN_W3M
Si W3MMAN_W3M está configurada, su valor se utiliza en lugar de w3m.
W3MMAN_MAN
Si W3MMAN_MAN está configurada, su valor se utiliza en lugar de /usr/bin/man.

ARCHIVOS

/usr/lib/w3m/cgi-bin/w3mman2html.cgi
Convertidor de páginas del manual a HTML.

VER TAMBIÉN

man(1), w3m(1).
