wpaperd-output(5) Manual de formatos de archivo wpaperd-output(5)

NOMBRE

wpaperd-output - formato utilizado por wpaperd para definir las diversas pantallas

DESCRIPCIÓN

El archivo de configuración de wpaperd contiene la información sobre cada pantalla, el fondo de pantalla correspondiente y su configuración. Este archivo se encuentra en XDG_CONFIG_HOME/wpaperd/config.toml (que por defecto es $HOME/.config/wpaperd/config.toml).

SINTAXIS

Este archivo es una configuración TOML simple dividida en secciones, una para cada pantalla.

SECCIÓN

Cada sección se nombra según el identificador de la pantalla. Si estás usando sway, puedes buscar el identificador de salida llamando a:

$ swaymsg -t get_outputs

En Hyprland, puedes hacerlo con:

$ hyprctl monitors

El archivo de configuración de wpaperd se encuentra en `XDG_CONFIG_HOME/wpaperd/config.toml` (que por defecto es `~/.config/wpaperd/config.toml`). Cada sección representa una pantalla diferente y puede contener las siguientes claves:

  • `path`, ruta de la imagen a usar como fondo de pantalla o a un directorio para elegir el fondo de pantalla.
  • `duration`, tiempo que la imagen debe mostrarse hasta que se cambie por una nueva. Admite un formato humano para declarar la duración (por ejemplo, `30s` o `10m`), descrito [aquí](https://docs.rs/humantime/latest/humantime/fn.parse_duration.html). Esto solo es válido cuando la ruta apunta a un directorio. (Opcional)
  • `sorting`, elige el orden de clasificación. Las opciones válidas son `ascending` (ascendente), `descending` (descendente) y `random` (aleatorio), siendo el valor por defecto `random`. Esto solo es válido cuando la ruta apunta a un directorio. (Opcional)
  • `mode`, elige cómo mostrar el fondo de pantalla cuando el tamaño es diferente a la resolución de la pantalla: - `fit` muestra la imagen completa con esquinas negras que cubren el espacio vacío restante - `center` centra la imagen en la pantalla, dejando fuera las esquinas de la imagen que no cabían - `stretch` muestra la imagen completa estirándola para que ocupe toda la pantalla sin dejar ninguna
    esquina negra, cambiando la relación de aspecto - `tile` muestra la imagen múltiples veces horizontal y verticalmente para llenar la pantalla.
  • `transition_time`, cuántos milisegundos debe durar la transición. (Opcional, `300` por defecto).
  • `queue_size`, decide qué tamaño debe tener la cola cuando `path` se establece como un directorio y `sorting` se
    establece como `random`. (Opcional, `10` por defecto).
  • `initial_transition`, si se debe o no hacer una transición desde la pantalla negra inicial (Opcional, `true` por defecto).

SECCIÓN POR DEFECTO

La sección "default" se utilizará como base para toda la configuración de la pantalla; la sección "any" se utilizará para todas las pantallas que no se enumeren explícitamente. Esto permite tener una configuración flexible sin repetir ninguna configuración. wpaperd comprobará la configuración al inicio y cada vez que cambie, y proporcionará ayuda cuando sea incorrecta.

EJEMPLO

La configuración más simple se ve así:

[DP-3]
path = "/home/danyspin97/github_octupus.png"
[DP-4]
path = "/home/danyspin97/Wallpapers"
duration = "30m"

También es posible una configuración más compleja:

[default]
duration = "30m"
mode = "center"
sorting = "ascending"
[any]
path = "/home/danyspin97/default_wallpaper.png"
[DP-3]
path = "/home/danyspin97/Wallpapers"
