WAVPACK(1) Manual de Comandos Generales WAVPACK(1)

NOMBRE

wavpack — codifica archivos de audio a wavpack

SINOPSIS

wavpack [-opciones] [-o salida] archivo ...

DESCRIPCIÓN

wavpack codifica los archivos fuente especificados en archivos WavPack. Los archivos fuente pueden ser de cualquiera de los tipos de formato de archivo listados a continuación, y los datos de audio pueden ser PCM sin comprimir o DSD, dependiendo del formato. También se puede especificar audio crudo (ver --raw-pcm).

A menos que se anule con la opción -o, el nombre del archivo de salida será el nombre del archivo fuente con la extensión del nombre del archivo reemplazada por “.wv”. Se pueden especificar múltiples archivos de entrada, lo que resulta en múltiples archivos WavPack, y en ese caso se puede usar -o para especificar un directorio de destino alternativo. Un nombre de archivo de “-” especifica stdin o stdout.

Al transcodificar desde archivos WavPack existentes, todas las etiquetas se copian y se pueden modificar con argumentos adicionales; a menos que se especifique un archivo o directorio de salida alternativo, los archivos fuente se sobrescriben de forma segura.

En máquinas multinúcleo, wavpack intentará utilizar varios hilos para acelerar la operación, a menudo de manera significativa. Esto no se aplica al modo híbrido (excepto con archivos multicanal). Para forzar la operación de un solo hilo, use la opción --no-threads, o use la opción --threads para ajustar el número de hilos utilizados.

FORMATOS DE ENTRADA

  • Microsoft RIFF, extensión “.wav”, incluyendo variantes BWF y RF64
  • WavPack, extensión “.wv”, operación de transcodificación, etiquetas copiadas
  • Apple AIFF, extensión “.aif”
  • Apple Core Audio, extensión “.caf”
  • Sony Wave64, extensión “.w64”
  • Philips DSDIFF, extensión “.dff”
  • Sony DSD Stream, extensión “.dsf”

OPCIONES

-a
Modo Adobe Audition (CoolEdit) para flotantes de 32 bits
--allow-huge-tags
Permite datos de etiquetas de hasta 16 MB. Incrustar > 1 MB no es recomendable para dispositivos portátiles y puede no funcionar con algunos programas, incluidos versiones anteriores de WavPack.
-bn
Habilita la compresión híbrida, n = 2.0 a 23.9 bits/muestra, o n = 24-9600 kbits/segundo (kbps). Si se especifica esta opción sin la opción -c, entonces la operación es con pérdida. El modo híbrido no es aplicable a audio DSD (solo PCM).
--blocksize=n
especifica el tamaño del bloque en muestras (máx = 131072 y mín = 16 con --merge-blocks, de lo contrario 128)
-c
Crea un archivo de corrección (.wvc) para el modo híbrido, resultando en compresión sin pérdida de 2 archivos. El bitrate se especifica con la opción -bn.
-cc
compresión híbrida máxima (perjudica la calidad con pérdida y la velocidad de decodificación)
-cn
Habilita compresión híbrida sin pérdida (es decir, de 2 archivos), n = 2.0 a 23.9 bits/muestra, o n = 24-9600 kbits/segundo (kbps). Esto es un atajo que combina las opciones -bn y -c. El modo híbrido no es aplicable a audio DSD (solo PCM).
--channel-order=lista
Especifica el orden de canales separado por comas si no es el estándar de Microsoft, que es FL,FR,FC,LFE,BL,BR,FLC,FRC,BC,SL,SR,TC,TFL,TFC,TFR,TBL,TBC,TBR; especifica “...” para indicar que los canales no están asignados a altavoces específicos, o termina la lista con “...” para indicar que cualquier canal más allá de los especificados no está asignado.
--cross-decorr
Usa correlación entre canales en modo híbrido. Activado por defecto en modo sin pérdida y con la opción -cc.
-d
elimina el archivo fuente si tiene éxito; ¡usar con precaución!
-f
modo rápido; introduce una concesión en la relación de compresión
--force-even-byte-depth
Redondea la profundidad de bits especificada en el archivo fuente al siguiente byte completo (por ejemplo, 20 bits se redondean a 24 bits) para manejar casos donde el valor especificado no es correcto (es decir, los bits de relleno no son cero).
-g
modo general/normal, cancela las opciones -f y -h especificadas previamente
-h
alta calidad; mejor relación de compresión, pero ligeramente más lento
-hh
muy alta calidad; mejor compresión, pero más lento; no recomendado en dispositivos de reproducción antiguos
--help
muestra ayuda extendida
-i
Ignora la longitud en la cabecera wav y permite archivos WAV mayores de 4 GB. Intentará corregir la cabecera WAV almacenada en el archivo WavPack; combínala con -r para crear una nueva cabecera en su lugar.
--import-id3
importa elementos de etiqueta aplicables de una etiqueta ID3v2.3 o ID3v2.4 presente en archivos DSF y otros al archivo de etiquetas APEv2. Si hay imágenes de portada de > 1 MB presentes, agrega --allow-huge-tags para incluirlas, y -r si no deseas que las imágenes grandes aparezcan dos veces en el archivo WavPack, aunque esto eliminará toda la etiqueta ID3v2 original.
-jn
anulación de estéreo conjunto (0 = izquierda/derecha, 1 = medio/lado)
-m
calcula y almacena la firma MD5 de los datos de audio crudos
--merge-blocks
fusiona bloques consecutivos con redundancia igual (usado con la opción --blocksize y es útil para archivos generados por el programa lossyWAV o archivos HDCD decodificados)
-n
calcula el ruido de cuantización promedio y pico (solo híbrido, seno de referencia a escala completa)
--no-overwrite
Nunca sobrescribir, ni preguntar para sobrescribir, un archivo existente. Esto es útil para reanudar una operación por lotes cancelada y obviamente no se puede mezclar con la opción -y.
--no-threads
forzar operación de un solo hilo, equivalente a --threads=1
--no-utf8-convert
No recodificar etiquetas pasadas de la codificación local a UTF-8, asumir que ya están en UTF-8.
-o archivo_salida
Especificar un nombre de archivo de salida para un archivo fuente único o un directorio de destino (debe existir) para múltiples archivos.
--optimize-int32
Optimiza la codificación para enteros de 32 bits que se utilizan en la mayoría de los formatos de audio WAV.

OPTIONS

-a
allow modification of WavPack files by appending to existing files or overwriting specific sections.
-a -Encoder
write encoder metadata to APEv2 tag (e.g., “Encoder=WavPack 5.8.0”)
-a -Settings
write user settings metadata to APEv2 tag (e.g., “Settings=-hb384cx3”)
-a “Field=Value”
write the specified text metadata to APEv2 tag
-a “Field=@file.ext”
Write specified text metadata from file to APEv2 tag; normally used for embedded cuesheets and logs (field names “Cuesheet” and “Log”).
--append
append to WavPack files instead of overwriting.
-bn
set the default WavPack bit depth to n (e.g., 16, 20, 24) or the float representation to n (e.g., 32, 64). Without this, WavPack defaults to a float representation that is compatible with the input audio. Use -b 32 for 32-bit float files or -b 64 for 64-bit float files.
-c
create correction files.
-cc
create correction files with extra information.
-ch
copy headers from input files to output files.
--compression-level=n
set the compression level from 0 to 12, where 0 is fastest and 12 is slowest/best. Defaults to 3. Levels 8-12 require SSE.
-d
delete original files after successful processing.
-e
create an external WavPack file, then delete the original.
-f
force overwrite of existing files.
-h
hybrid mode: audio is encoded losslessly, but if the file is too large then a lower bitrate lossy version is created and the original is deleted. This mode is selected based on the desired file size (see -b or -h[n]).
-h[n]
hybrid mode with target bitrate. n is the target bitrate in kbps. If no n is given, a default of 384kbps is used. Note that WavPack is primarily lossless, and this mode is only used when the original file is larger than the target size.
-i
ignore errors during decoding. Not recommended.
-l
set WavPack files to lossless mode. This is the default.
-m
don't delete original files. This is the default.
-n
no wvgain processing is performed.
--optimize-int32
New optimization targeting 32-bit integer audio files that were originally sourced from 32-bit float audio. Can improve compression by 10%, but is only applicable in lossless modes. Resulting files will only decode with 24-bit resolution on older decoders (i.e., technically lossy).
--pair-unassigned-chans
encode unassigned channels into stereo pairs
--pre-quantize=bits
pre-quantize samples to bits depth BEFORE encoding and MD5 calculation (common use would be --pre-quantize=20 for 24-bit or float material recorded with typical converters)
-q
quiet (keep console output to a minimum)
-r
parse headers to determine audio format and length but do not store the headers in the resulting WavPack file (a minimum header will be generated by wvunpack, but some non-audio metadata might be lost)
--raw-pcm
input data is raw pcm (44,100 Hz, 16-bit, 2-channels)
--raw-pcm=sr,bits[f|s|u],chans,[le|be]
Input data is raw pcm with specified sample-rate, bit-depth (float, unsigned, signed), number of channels, and endianness. Defaulted parameters may be omitted, specify bits=1 for DSD.
--raw-pcm-skip=begin[,end]
skip begin bytes before encoding raw PCM (header) and skip end bytes at the EOF (trailer)
-sn
Override default hybrid mode noise shaping where n is a float value between -1.0 and 1.0. Negative values move noise lower in freq, positive values move noise higher in freq; use 0 for no shaping (white noise).
-t
Copy input file's time stamp to output files.
--threads=n
Enable (or disable) multithreaded operation with n=1 (no threading) to n=12 (max threads). Significantly improves the speed of lossless compression on multicore CPUs. In the hybrid modes, only multichannel files can utilize multithreading. Omitting the parameter will select an optimum number of threads.
--use-dns
force use of dynamic noise shaping (hybrid mode only)
-v
verify output file integrity after write (not for piped output)
--version
write program version to stdout
-w -Encoder
write encoder metadata to APEv2 tag (e.g., “Encoder=WavPack 5.8.0”)
-w -Settings
write user settings metadata to APEv2 tag (e.g., “Settings=-hb384cx3”)
-w “Field=Value”
write the specified text metadata to APEv2 tag
-w “Field=@file.ext”
Write specified text metadata from file to APEv2 tag; normally used for embedded cuesheets and logs (field names “Cuesheet” and “Log”).
--write-binary-tag “Field=@file.ext”
Write the specified binary metadata file to APEv2 tag; normally used for cover art with the field name “Cover Art (Front)”.
-x[n]
extra encode processing, n = 0 to 6, default=1; -x0 for no extra processing, -x1 to -x3 to choose best of predefined filters, -x4 to -x6 to generate custom filters (very slow!)
-y
yes to all warnings; use with caution!
-z[n]
don't set (n=0 or omitted) or set (n=1) console title to indicate progress (leaves "WavPack Completed")
