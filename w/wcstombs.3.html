wcstombs(3) Manual de funciones de biblioteca wcstombs(3)

NOMBRE

wcstombs - convierte una cadena de caracteres anchos a una cadena multibyte

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
size_t wcstombs(size_t dsize;
                char dest[restrict dsize], const wchar_t *restrict src,
                size_t dsize);

DESCRIPCIÓN

Si dest no es NULL, la función wcstombs() convierte la cadena de caracteres anchos src a una cadena multibyte comenzando en dest. Se escriben como máximo dsize bytes en dest. La secuencia de caracteres colocados en dest comienza en el estado de desplazamiento inicial. La conversión puede detenerse por tres razones:

•
Se ha encontrado un carácter ancho que no se puede representar como una secuencia multibyte (según la configuración regional actual). En este caso, se devuelve (size_t) -1.
•
El límite de longitud obliga a una parada. En este caso, se devuelve el número de bytes escritos en dest, pero el estado de desplazamiento en este punto se pierde.
•
La cadena de caracteres anchos se ha convertido completamente, incluido el carácter ancho nulo de terminación (L'\0'). En este caso, la conversión termina en el estado de desplazamiento inicial. Se devuelve el número de bytes escritos en dest, excluyendo el byte nulo de terminación ('\0').

El programador debe asegurarse de que haya espacio para al menos dsize bytes en dest.

Si dest es NULL, dsize se ignora y la conversión procede como se describió anteriormente, excepto que los bytes convertidos no se escriben en la memoria y no existe un límite de longitud.

Para evitar el caso 2 anterior, el programador debe asegurarse de que dsize sea mayor o igual que wcstombs(NULL,src,0)+1.

VALOR DE RETORNO

La función wcstombs() devuelve el número de bytes que componen la parte convertida de una secuencia multibyte, sin incluir el byte nulo de terminación. Si se encontró un carácter ancho que no se pudo convertir, se devuelve (size_t) -1.

VERSIONES

ESTANDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C99.

NOTAS

El comportamiento de wcstombs() depende de la categoría LC_CTYPE de la configuración regional actual.
