WORDLIST2DAWG(1)   WORDLIST2DAWG(1)

NOMBRE

wordlist2dawg - convertir una lista de palabras a un DAWG para Tesseract

SINOPSIS

wordlist2dawg LISTADEPALABRAS DAWG lang.unicharset

wordlist2dawg -t LISTADEPALABRAS DAWG lang.unicharset

wordlist2dawg -r 1 LISTADEPALABRAS DAWG lang.unicharset

wordlist2dawg -r 2 LISTADEPALABRAS DAWG lang.unicharset

wordlist2dawg -l <corto> <largo> LISTADEPALABRAS DAWG lang.unicharset

DESCRIPCIÓN

wordlist2dawg(1) convierte una lista de palabras a un Grafo de Palabras Acíclico Dirigido (DAWG, por sus siglas en inglés) para usarlo con Tesseract. Un DAWG es una representación comprimida, eficiente en espacio y tiempo, de una lista de palabras.

OPCIONES

-t Verificar si un archivo dawg dado es equivalente a una lista de palabras dada.

-r 1 Invertir una palabra si contiene un carácter de derecha a izquierda (RTL).

-r 2 Invertir todas las palabras.

-l <corto> <largo> Producir un archivo con varios dawgs dentro, uno para cada palabra de longitud <corto>, <corto+1>,... <largo>

ARGUMENTOS

LISTADEPALABRAS Un archivo de texto plano en UTF-8, una palabra por línea.

DAWG El DAWG de salida que se escribirá.

lang.unicharset El conjunto de caracteres unicharset del idioma. Este es el unicharset generado por mftraining(1).
