NOMBRE

webhttrack - navegador web : copia sitios web a un directorio local

SINOPSIS

webhttrack [ palabra_clave valor [ palabra_clave valor .. ] ]

DESCRIPCIÓN

webhttrack este programa es una interfaz de script para httrack(1) y htsserver(1) , un copiador de sitios web.

EJEMPLOS

webhttrack lang 1

iniciará la interfaz del servidor webhttrack, y el navegador predeterminado del sistema, con "lang" establecido en "inglés" (idioma #1)

ARCHIVOS

/etc/httrack.conf

El archivo de configuración global del sistema.

ENTORNO

HOME
Se está utilizando si definió en /etc/httrack.conf la línea path ~/websites/#

DIAGNÓSTICO

Los errores/advertencias se informan en hts-log.txt ubicado en el directorio de destino.

ERRORES

Por favor, informe de errores a <bugs@httrack.com>. Incluya un ejemplo completo y autocontenido que permita reproducir el error, y diga qué versión de (web)httrack está utilizando. No olvide detallar las opciones utilizadas, la versión del SO y cualquier otra información que considere necesaria.
