WIPEFS(8) Administración del Sistema WIPEFS(8)

NOMBRE

wipefs - borrar una firma de un dispositivo

SINOPSIS

wipefs [opciones] dispositivo...

wipefs [--backup] -o desplazamiento dispositivo...

wipefs [--backup] -a dispositivo...

DESCRIPCIÓN

wipefs puede borrar firmas de sistemas de archivos, RAID o tablas de particiones (cadenas mágicas) del dispositivo especificado para hacer que las firmas sean invisibles para libblkid. wipefs no borra el sistema de archivos en sí ni ningún otro dato del dispositivo.

Cuando se usa sin opciones, wipefs lista todos los sistemas de archivos visibles y los desplazamientos de sus firmas básicas. La salida predeterminada está sujeta a cambios. Por lo tanto, siempre que sea posible, debe evitar el uso de salidas predeterminadas en sus scripts. Defina siempre explícitamente las columnas esperadas utilizando --output lista-de-columnas en entornos donde se requiera una salida estable.

wipefs llama al ioctl BLKRRPART cuando ha borrado una firma de tabla de particiones para informar al kernel sobre el cambio. El ioctl se llama como último paso y cuando todas las firmas especificadas de todos los dispositivos especificados ya han sido borradas. Esta función se puede utilizar para borrar contenido en dispositivos de partición, así como una tabla de particiones en un dispositivo de disco, por ejemplo, mediante wipefs -a /dev/sdc1 /dev/sdc2 /dev/sdc.

Tenga en cuenta que algunos sistemas de archivos y algunas tablas de particiones almacenan varias cadenas mágicas en el dispositivo (por ejemplo, FAT, ZFS, GPT). El comando wipefs (desde la v2.31) lista todos los desplazamientos donde se han detectado cadenas mágicas.

Cuando se utiliza la opción -a, se borran todas las cadenas mágicas que son visibles para libblkid(3). En este caso, wipefs escanea el dispositivo nuevamente después de cada modificación (borrado) hasta que no se encuentre ninguna cadena mágica.

Tenga en cuenta que, de forma predeterminada, wipefs no borra tablas de particiones anidadas en dispositivos que no son de disco completo. Para esto, se requiere la opción --force.

OPCIONES

-a, --all

Borra todas las firmas disponibles. El conjunto de firmas borradas se puede restringir con la opción -t. Cuando se realiza en un dispositivo de disco completo particionado como /dev/sdX, solo borrará las tablas de particiones, no el contenido de las particiones.

-b, --backup[=directorio]

Crea una copia de seguridad de la firma en el archivo wipefs-<nombre_dispositivo>-<desplazamiento>.bak en $HOME o en el directorio especificado como argumento opcional. Para más detalles, consulte la sección EJEMPLOS.

-f, --force

Fuerza el borrado, incluso si el sistema de archivos está montado. Esto es necesario para borrar una firma de tabla de particiones en un dispositivo de bloques.

-J, --json

Utiliza el formato de salida JSON.

--lock[=modo]

Utiliza un bloqueo BSD exclusivo para el dispositivo o archivo en el que opera. El argumento opcional modo puede ser yes, no (o 1 y 0) o nonblock. Si se omite el argumento modo, se utiliza el valor predeterminado de "yes". Esta opción sobrescribe la variable de entorno $LOCK_BLOCK_DEVICE. El valor predeterminado es no usar ningún bloqueo, pero se recomienda evitar colisiones con udevd u otras herramientas.

-i, --noheadings

No imprime una línea de encabezado.

-O, --output lista

Especifica qué columnas de salida imprimir. Usa --help para obtener una lista de todas las columnas compatibles.

-n, --no-act

Realiza todas las acciones excepto la llamada de escritura (write(2)).

-o, --offset desplazamiento

Especifica la ubicación (en bytes) de la firma que debe ser borrada del dispositivo. El número de desplazamiento puede incluir un prefijo "0x"; entonces el número se interpretará como un valor hexadecimal. Es posible especificar múltiples opciones -o.

El argumento desplazamiento puede ir seguido de los sufijos multiplicadores KiB (=1024), MiB (=1024*1024), y así sucesivamente para GiB, TiB, PiB, EiB, ZiB y YiB (el "iB" es opcional, por ejemplo, "K" tiene el mismo significado que "KiB"), o los sufijos KB (=1000), MB (=1000*1000), y así sucesivamente para GB, TB, PB, EB, ZB y YB.

-p, --parsable

Imprime en formato analizable en lugar de imprimible. Codifica todos los caracteres potencialmente inseguros de una cadena en el valor hexadecimal correspondiente precedido por '\x'.

-q, --quiet

Suprime cualquier mensaje después de un borrado de firma exitoso.

-t, --types lista

Limita el conjunto de firmas impresas o borradas. Se puede especificar más de un tipo en una lista separada por comas. La lista o los tipos individuales pueden ir precedidos de 'no' para especificar los tipos en los que no se debe realizar ninguna acción. Para más detalles, consulta mount(8).

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

AMBIENTE

LIBBLKID_DEBUG=all

habilita la salida de depuración de libblkid(3).

LOCK_BLOCK_DEVICE=<modo>

utiliza bloqueo BSD exclusivo. El modo es "1" o "0". Consulta --lock para más detalles.

EJEMPLOS

wipefs /dev/sda*

Imprime información sobre sda y todas las particiones en sda.

wipefs --all --backup /dev/sdb

Borra todas las firmas del dispositivo /dev/sdb y crea un archivo de copia de seguridad de la firma ~/wipefs-sdb-<desplazamiento>.bak para cada firma.

dd if=~/wipefs-sdb-0x00000438.bak of=/dev/sdb seek=$((0x00000438)) bs=1 conv=notrunc

Restaura una firma ext2 desde el archivo de copia de seguridad ~/wipefs-sdb-0x00000438.bak.
