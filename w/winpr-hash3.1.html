NOMBRE

winpr-hash - herramienta de hashing NTLM

SINOPSIS

winpr-hash -u nombre_usuario -p contraseña [-d dominio] [-f { predeterminado | sam }] [-v { 1 | 2 }]

DESCRIPCIÓN

winpr-hash es una pequeña utilidad que se puede utilizar para crear un hash NTLM a partir de un par de nombre de usuario y contraseña. El hash creado se puede generar como hash plano o en formato SAM.

OPCIONES

-u nombre_usuario
El nombre de usuario a utilizar.
-p contraseña
Contraseña a utilizar.
-d dominio
Un parámetro opcional para especificar el dominio del usuario.
-f formato
Especifica el formato de salida. El valor predeterminado genera solo el hash NTLM plano. El segundo formato de salida disponible es sam, que genera el hash creado en un formato que se puede usar en el archivo SAM:

usuario:dominio::hash:::

-v version
La versión permite especificar la versión NTLM a utilizar. El valor predeterminado es usar la versión 1. En caso de usar la versión 2, se necesita especificar un dominio.

EJEMPLOS

winpr-hash -u usuario -p contraseña -d dominio -f sam -v 2

Crea un hash NTLM versión 2 para usuario con dominio y contraseña y lo genera en formato sam.
