NOMBRE

wofi - Nombres de teclas para binds personalizados

DESCRIPCIÓN

Esta es una lista de los nombres de teclas que se pueden usar para vinculaciones personalizadas. Estos se toman de gdk/gdkkeysyms.h con la excepción de los modificadores.

Los modificadores se pueden adjuntar a las teclas anteponiendo el nombre del modificador separado por un guión. Por ejemplo, Shift-J o Ctrl-j. Solo se puede usar un modificador en una vinculación dada.

Ciertas teclas no pueden tener el modificador Shift adjunto, ya que mantener presionado Shift mientras se usan estas teclas provoca que se registre una pulsación de tecla completamente diferente. Por ejemplo, Shift-j no es válido, ya que mantener presionado Shift mientras se pulsa j cambia la tecla a J, por lo que Shift-J debería registrarse en lugar de Shift-j. Este es el caso de todos los caracteres alfanuméricos, así como Tab, que se convierte en ISO_Left_Tab. Esto además significa que los modificadores que no son Shift, como Ctrl, DEBEN usarse con la variante de la tecla que no es Shift. Por ejemplo, Ctrl-J no es válido; se debe usar una j minúscula (sin Shift) para Ctrl y Alt.

Adicionalmente, es posible tener múltiples vinculaciones para una acción separando las vinculaciones con comas. Por ejemplo, vincular una acción a Ctrl-j,Ctrl-h asignará ambas combinaciones de teclas a esa única acción.

MODIFIER NAMES

The following modifier names can be used in keybindings:

  • <Control> or <Ctrl>
  • <Shift>
  • <Alt>
  • <Super> or <Mod4>

KEY NAMES

The following key names can be used in keybindings:

  • Key names are typically the same as those found in Xbindkeys(1).
  • Common keys include:
    • <Return>
    • <Escape>
    • <Tab>
    • <BackSpace>
    • <Delete>
    • <Up>
    • <Down>
    • <Left>
    • <Right>
    • <Home>
    • <End>
    • <Prior> (Page Up)
    • <Next> (Page Down)
    • <Insert>
    • <F1> ... <F12>
    • <KP_Enter> (Numpad Enter)
    • <KP_Multiply>, <KP_Divide>, <KP_Add>, <KP_Subtract>
    • <KP_0> ... <KP_9>
  • The following keys are specific to wofi:
    • Switch_VT_N: Switches to the specified virtual terminal (e.g. Switch_VT_3).
    • Ungrab: Releases any active grab.
    • ClearGrab: Clears the grab on all devices.
    • Next_VMode: Cycles to the next video mode.
    • Prev_VMode: Cycles to the previous video mode.
    • LogWindowTree: Logs the window tree to stderr.
    • LogGrabInfo: Logs grab information to stderr.
