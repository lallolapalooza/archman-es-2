NOMBRE

wl-present - un cliente interactivo para wl-mirror(1)

SINOPSIS

wl-present [OPCIONES] <COMANDO> [argumentos...]

DESCRIPCIÓN

wl-present es un envoltorio alrededor de wl-mirror(1) que utiliza su modo de transmisión junto con pipectl(1) para controlar interactivamente lo que se está capturando.

Los subcomandos de wl-present están diseñados para ser asignados a atajos de teclado en tu compositor de Wayland para un fácil acceso.

COMANDOS

help

Muestra el mensaje de ayuda y sale.

mirror [SALIDA] [OPCIONES]

Inicia wl-mirror(1) capturando SALIDA. Si no se proporciona salida, se utiliza slurp(1) para seleccionar la salida o región a capturar. Si se especifican OPCIONES adicionales, se pasan a wl-mirror.

set-output [SALIDA]

Establece la salida capturada de una sesión de wl-present en ejecución. Si no se proporciona salida, se utiliza slurp(1) para seleccionar la salida a capturar.

set-region [REGIÓN] unset-region

Establece la región capturada de una sesión de wl-present en ejecución. Si no se proporciona región, se utiliza slurp(1) para seleccionar una región a capturar.

set-scaling [ESCALADO]

Establece el modo de escalado de una sesión de wl-present en ejecución. Si no se proporciona región, se utiliza dmenu(1) (o un reemplazo compatible) para seleccionar un modo de escalado.

freeze, unfreeze, toggle-freeze

Establece el estado de congelación de una sesión de wl-present en ejecución.

fullscreen unfullscreen

Establece el estado de pantalla completa de una sesión de wl-present en ejecución.

fullscreen-output [SALIDA]

Establece la salida de destino de pantalla completa de una sesión de wl-present en ejecución, implica fullscreen.

no-fullscreen-output

Anula la salida de destino de pantalla completa previamente establecida de una sesión de wl-present en ejecución, implica unfullscreen.

custom [OPCIONES]

Envía opciones personalizadas a una sesión de wl-present en ejecución. Si no se proporcionan opciones, se utiliza dmenu(1) (o un reemplazo compatible) para seleccionar una opción.

OPCIONES

-n, --name

Utiliza un nombre de tubería alternativo (el predeterminado es wl-present). Esto permite que múltiples instancias de wl-present se ejecuten al mismo tiempo.

VARIABLES DE ENTORNO

WL_PRESENT_DMENU

Anula la implementación de dmenu utilizada. Cuando está configurado, este comando se utiliza para seleccionar opciones en lugar del predeterminado. Cuando no está configurado, wl-present intenta usar wofi(1), wmenu(1), fuzzel(1), rofi(1) y dmenu(1), en este orden.

Ejemplo: WL_PRESENT_DMENU="rofi -dmenu -p present"

WL_PRESENT_PIPECTL

Anula la implementación de pipectl utilizada. Cuando está configurado, este comando se utiliza para enviar opciones a wl-mirror(1) en lugar del predeterminado. Cuando no está configurado, wl-present intenta usar pipectl(1) o un shim de pipectl incluido escrito en bash si pipectl no está disponible.

WL_PRESENT_SLURP

Anula la implementación y las opciones de slurp utilizadas. Cuando está configurado, este comando se utiliza para seleccionar regiones y salidas en lugar del predeterminado. Cuando no está configurado, wl-present intenta usar slurp(1) sin ninguna opción adicional.

Ejemplo: WL_PRESENT_SLURP="slurp -c #859900 -w 2"

WL_PRESENT_PIPE_NAME

Anula el nombre de tubería predeterminado (el predeterminado es wl-present). Esto es equivalente a la opción --name anterior.

Ejemplo: WL_PRESENT_PIPE_NAME=monitor2 wl-present mirror HDMI-A-1
