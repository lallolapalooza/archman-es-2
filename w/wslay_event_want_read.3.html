Paquete: libwslay

Licencias: MIT

WSLAY_EVENT_WANT_READ(3) wslay WSLAY_EVENT_WANT_READ(3)

NOMBRE

wslay_event_want_read - Indica si la biblioteca desea leer más datos

SINOPSIS

#include <wslay/wslay.h>

int wslay_event_want_read(wslay_event_context_ptr ctx)

DESCRIPCIÓN

wslay_event_want_read() se utiliza para saber si la biblioteca desea leer más datos del par. Esto es útil para decidir si esperar a un evento de lectura en funciones de notificación de eventos de E/S como select(2) y poll(2).

VALOR DE RETORNO

wslay_event_want_read() devuelve 1 si la biblioteca desea leer más datos del par, o devuelve 0.

VER TAMBIÉN

wslay_event_want_write(), wslay_event_shutdown_read(), wslay_event_get_read_enabled()
