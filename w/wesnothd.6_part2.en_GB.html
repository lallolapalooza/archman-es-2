CONFIGURACIÓN DEL SERVIDOR

Las siguientes etiquetas se pueden utilizar en el archivo de configuración para controlar el comportamiento del servidor.

versions_accepted
Una lista separada por comas de cadenas de versión que serán aceptadas por el servidor. Se admiten * y ? de los patrones comodín. (el valor predeterminado es la versión correspondiente de wesnoth)
Ejemplo: versions_accepted="*" acepta cualquier cadena de versión.
id
El ID del servidor cuando se utiliza la funcionalidad de base de datos para almacenar información del juego. Generalmente es la versión mayor.menor de los clientes aceptados, como 1.16 o 1.17.

Etiquetas Globales:

[redirect] Una etiqueta para especificar un servidor al que redirigir ciertas versiones de clientes. No se utiliza si versions_accepted no está configurado.

host
La dirección del servidor al que redirigir.
port
El puerto al que conectarse.
version
Una lista separada por comas de versiones a redirigir. Se comporta de la misma manera que versions_accepted en cuanto a patrones comodín.

[ban_time] Una etiqueta para definir palabras clave convenientes para duraciones de tiempo de prohibición temporal.

name
El nombre utilizado para referirse al tiempo de prohibición.
time
La definición de la duración del tiempo. El formato es: %d[%s[%d%s[...]]] donde %s es s (segundos), m (minutos), h (horas), D (días), M (meses) o Y (años) y %d es un número. Si no se proporciona modificador de tiempo, se asumen minutos (m). Ejemplo: time="1D12h30m" da como resultado un tiempo de prohibición de 1 día, 12 horas y 30 minutos.

[proxy] Una etiqueta para indicar al servidor que actúe como proxy y reenvíe las solicitudes del cliente conectado al servidor especificado. Acepta las mismas claves que [redirect].

[user_handler] Configura el manejador de usuarios. Si no hay una sección [user_handler] presente en la configuración, el servidor se ejecutará sin ningún servicio de registro de nicks. Todas las tablas adicionales que son necesarias para que forum_user_handler funcione se pueden encontrar en table_definitions.sql en el repositorio de código fuente de Wesnoth. Requiere soporte mysql habilitado. Para cmake es ENABLE_MYSQL y para scons es forum_user_handler.

db_host
El nombre del host del servidor de base de datos
db_name
El nombre de la base de datos
db_user
El nombre del usuario con el que iniciar sesión en la base de datos
db_password
La contraseña de este usuario
db_users_table
El nombre de la tabla en la que tu foro phpbb guarda sus datos de usuario. Lo más probable es que sea <prefijo-tabla>_users (por ejemplo, phpbb3_users).
db_extra_table
El nombre de la tabla en la que wesnothd guardará sus propios datos sobre usuarios.
db_game_info_table
El nombre de la tabla en la que wesnothd guardará sus propios datos sobre juegos.
db_game_player_info_table
El nombre de la tabla en la que wesnothd guardará sus propios datos sobre los jugadores en un juego.
db_game_modification_info_table
El nombre de la tabla en la que wesnothd guardará sus propios datos sobre las modificaciones utilizadas en un juego.
db_user_group_table
El nombre de la tabla en la que tu foro phpbb guarda los datos de sus grupos de usuarios. Lo más probable es que sea <prefijo-tabla>_user_group (por ejemplo, phpbb3_user_group).
db_connection_history_table
El nombre de la tabla en la que se almacenarán los tiempos de inicio/cierre de sesión. También se utiliza para hacer coincidir IPs con usuarios y viceversa.
db_topics_table
El nombre de la tabla en la que tu foro phpbb guarda la información de sus temas (hilos). Lo más probable es que sea <prefijo-tabla>_topics (por ejemplo, phpbb3_topics).
db_banlist_table
El nombre de la tabla en la que tu foro phpbb guarda los datos de prohibición de usuarios. Lo más probable es que sea <prefijo-tabla>_banlist (por ejemplo, phpbb3_banlist).
mp_mod_group
El ID del grupo del foro que se considerará que tiene autoridad de moderación.

ESTADO DE SALIDA

El estado de salida normal es 0 cuando el servidor se cerró correctamente. Un estado de salida de 2 indica un error con las opciones de la línea de comandos.
