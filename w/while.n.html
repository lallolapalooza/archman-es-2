while(n) Comandos integrados de Tcl while(n)

NOMBRE

while - Ejecuta un script repetidamente mientras se cumpla una condición

SINOPSIS

while prueba cuerpo

DESCRIPCIÓN

El comando while evalúa prueba como una expresión (de la misma manera que expr evalúa su argumento). El valor de la expresión debe ser un valor booleano correcto; si es un valor verdadero, entonces cuerpo se ejecuta pasándolo al intérprete Tcl. Una vez que se ha ejecutado cuerpo, prueba se evalúa de nuevo y el proceso se repite hasta que finalmente prueba se evalúa como un valor booleano falso. Los comandos continue pueden ser ejecutados dentro de cuerpo para terminar la iteración actual del bucle, y los comandos break pueden ser ejecutados dentro de cuerpo para causar la terminación inmediata del comando while. El comando while siempre devuelve una cadena vacía.

Nota: prueba casi siempre debe estar encerrada entre llaves. Si no es así, se realizarán sustituciones de variables antes de que el comando while comience a ejecutarse, lo que significa que los cambios en las variables realizados por el cuerpo del bucle no se considerarán en la expresión. Esto probablemente resultará en un bucle infinito. Si prueba está encerrada entre llaves, las sustituciones de variables se retrasan hasta que se evalúa la expresión (antes de cada iteración del bucle), por lo que los cambios en las variables serán visibles. Para un ejemplo, prueba el siguiente script con y sin las llaves alrededor de $x<10:

set x 0
while {$x<10} {
    puts "x es $x"
    incr x
}

EJEMPLO

Leer líneas de un canal hasta llegar al final del flujo, e imprimirlas con un número de línea prependido:

set lineCount 0
while {[gets $chan line] >= 0} {
    puts "[incr lineCount]: $line"
}
