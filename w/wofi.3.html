NOMBRE

wofi - Funciones y documentación del modo

DESCRIPCIÓN

Wofi proporciona una API en C que se puede utilizar para desarrollar modos de terceros. Estos modos deben compilarse en un objeto compartido que debe colocarse en $XDG_CONFIG_HOME/wofi/plugins. Si $XDG_CONFIG_HOME no está definido, por defecto será ~/.config.

Es muy importante tener en cuenta que esta API no es estable. Es mayoritariamente estable, sin embargo, si surge algo que requiera un cambio sustancial, se realizarán cambios. Esto no debería ocurrir con demasiada frecuencia, pero ha ocurrido en el pasado y podría ocurrir en el futuro.

ARCHIVOS DE ENCABEZADO

Hay 2 archivos de encabezado requeridos para usar la API de wofi: wofi_api.h y map.h. utils.h podría ser útil incluirlo si quieres algunas funciones auxiliares, pero no es requerido. utils.h no se documentará aquí ya que está fuera del alcance de la API del modo.

FUNCIONES DEL MODO

La siguiente lista de funciones son las que se pueden definir dentro de tu modo y que serán llamadas para realizar la configuración y adquirir varias piezas de información del modo.

void init(struct mode* mode, struct map* config)
Definir esta función es requerido. Esta función se llama para configurar tu plugin y proporcionarte varios punteros que se describen a continuación.

struct mode* mode - se utiliza para identificar tu modo, se pasa a un gran número de funciones de la API para identificar tu modo.

struct map* config - todas las opciones de configuración que el usuario definió para tu modo. La información sobre cómo acceder a esto se puede encontrar en wofi-map(3).

void load(struct mode* mode)
Definir esta función es opcional. Esta función se llama antes que todas las demás y proporciona tu puntero de modo lo antes posible.

struct mode* mode - se utiliza para identificar tu modo, se pasa a un gran número de funciones de la API para identificar tu modo.

const char** get_arg_names(void)
Definir esta función es opcional. Esta función se llama para obtener una matriz de opciones de configuración que pueden ser establecidas por el usuario. Todas estas opciones tienen el nombre de tu modo antepuesto, por lo que si tu matriz es, por ejemplo, {"opt1", "opt2"}, las opciones de configuración definidas serán modo-opt1=valor y modo-opt2=valor, donde modo es el nombre del objeto compartido.
size_t get_arg_count(void)
Definir esta función es opcional. Esta función se llama para obtener el número de argumentos devueltos por get_arg_names(void).
void exec(const char* cmd)
Definir esta función es requerida. Esta función se llama cuando el usuario selecciona una entrada.

const char* cmd - La acción registrada para la entrada seleccionada. Si tu modo permite ejecutar búsquedas directamente, este será el contenido de la búsqueda si no existen entradas coincidentes.

struct widget* get_widget(void)
Definir esta función es opcional. Esta función se llama para solicitar el siguiente widget a agregar. Consulte wofi_create_widget() en wofi-api(3) sobre cómo obtener un struct widget*. Se debe devolver NULL para indicar que no hay más widgets disponibles.
bool no_entry(void)
Definir esta función es opcional. Esta función se llama para determinar si este modo admite la ejecución de búsquedas sin entradas coincidentes. El valor por defecto es falso; si deseas permitir que tu modo acepte búsquedas directamente, debes definir esto y devolver verdadero.
