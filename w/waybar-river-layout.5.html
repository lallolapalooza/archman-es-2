waybar-river-layout(5) Manual de formatos de archivo waybar-river-layout(5)

NOMBRE

waybar - módulo de diseño de river

DESCRIPCIÓN

El módulo layout muestra el diseño actual en river.

Puede que no se establezca hasta que se aplique un diseño por primera vez.

CONFIGURACIÓN

Abordado por river/layout

format:
tipo: string
predeterminado: {}
El formato, cómo se debe mostrar la información. En {} se insertan datos.

rotate:
tipo: integer
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

max-length:
tipo: integer
La longitud máxima en caracteres que debe mostrar el módulo.

min-length:
tipo: integer
La longitud mínima en caracteres que debe aceptar el módulo.

align:
tipo: float
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: string
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right', o 'center' para definir la posición.

on-click:
tipo: string
Comando a ejecutar cuando se hace clic en el módulo.

on-click-middle:
tipo: string
Comando a ejecutar cuando se hace clic con el botón central del ratón en el módulo.

on-click-right:
tipo: string
Comando a ejecutar cuando se hace clic con el botón derecho del ratón en el módulo.

menu:
tipo: string
Acción que muestra el menú.

menu-file:
tipo: string
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: bool
predeterminado: false
Permite que este módulo consuma todo el espacio restante dinámicamente.

EJEMPLO

"river/layout": {
	"format": "{}",
	"min-length": 4,
	"align": "right"
}

ESTILO

  • #layout
  • #layout.focused Aplicado cuando la salida a la que pertenece la barra de este módulo está enfocada.
  • #layout.<layout> Aplicado cuando la salida a la que pertenece la barra de este módulo utiliza este diseño.
