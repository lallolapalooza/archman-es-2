NOMBRE

waybar - módulo de ventana de Sway

DESCRIPCIÓN

El módulo window muestra el título de la ventana actualmente enfocada en Sway

CONFIGURACIÓN

Abordado por sway/window

format:
tipo: string
predeterminado: {title}
El formato, cómo se debe mostrar la información.

rotate:
tipo: integer
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

max-length:
tipo: integer
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
tipo: integer
La longitud mínima en caracteres que el módulo debe aceptar.

align:
tipo: float
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: string
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir la posición.

on-click:
tipo: string
Comando a ejecutar cuando se hace clic en el módulo.

on-click-middle:
tipo: string
Comando a ejecutar cuando se hace clic con la rueda del ratón en el módulo.

on-click-right:
tipo: string
Comando a ejecutar cuando se hace clic derecho en el módulo.

on-update:
tipo: string
Comando a ejecutar cuando el módulo se actualiza.

on-scroll-up:
tipo: string
Comando a ejecutar al desplazarse hacia arriba sobre el módulo.

on-scroll-down:
tipo: string
Comando a ejecutar al desplazarse hacia abajo sobre el módulo.

smooth-scrolling-threshold:
tipo: double
Umbral a utilizar al desplazarse.

tooltip:
tipo: bool
predeterminado: true
Opción para deshabilitar la información emergente al pasar el ratón.

all-outputs:
tipo: bool
predeterminado: false
Opción para mostrar la ventana enfocada junto con sus estilos de espacio de trabajo en todas las salidas.

offscreen-css:
tipo: bool
predeterminado: false
Solo efectivo cuando all-outputs es true. Agrega estilo según las ventanas presentes en salidas no enfocadas en lugar de mostrar la ventana enfocada y su estilo.

offscreen-css-text:
tipo: string
Solo efectivo cuando son verdaderos all-outputs y offscreen-style. En pantallas actualmente no enfocadas, muestra el texto dado junto con los estilos de ese espacio de trabajo.

show-focused-workspace-name:
tipo: bool
predeterminado: false
Si el propio espacio de trabajo está enfocado y contiene nodos o floating_nodes, muestra el nombre del espacio de trabajo. Si no está configurado, el texto permanece vacío pero los estilos según los nodos en el espacio de trabajo todavía se aplican.

show-hidden-marks:
tipo: bool
predeterminado: false
Para el reemplazo de formato {marks}, incluye marcas ocultas que comienzan con un guion bajo.

rewrite:
tipo: object
Reglas para reescribir la salida del formato del módulo. Ver reglas de reescritura.

icon:
tipo: bool
predeterminado: false
Opción para ocultar el icono de la aplicación.

icon-size:
tipo: integer
predeterminado: 24
Opción para cambiar el tamaño del icono de la aplicación.

expand:
tipo: bool
predeterminado: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

{title}: El título de la ventana enfocada.

{app_id}: El app_id de la ventana enfocada.

{shell}: El shell de la ventana enfocada. Es 'xwayland' cuando la ventana se ejecuta a través de xwayland, de lo contrario, es 'xdg-shell'.

{marks}: Marcas de la ventana.

REGLAS DE REESCRITURA

rewrite es un objeto donde las claves son expresiones regulares y los valores son reglas de reescritura si la expresión coincide. Las reglas pueden contener referencias a las capturas de la expresión.

La expresión regular y el reemplazo siguen las reglas de ECMA-script.

Si ninguna expresión coincide, la salida del formato se deja sin cambios.

Las expresiones inválidas (por ejemplo, paréntesis no coincidentes) se omiten.

EJEMPLOS

"sway/window": {
	"format": "{}",
	"max-length": 50,
	"rewrite": {
		"(.*) - Mozilla Firefox": "🌎 $1",
		"(.*) - zsh": "> [$1]"
	}
}

ESTILO

•
#window

Las siguientes clases se aplican a Waybar completo en lugar de solo al widget de ventana:

  • window#waybar.empty Cuando no hay ventanas en el espacio de trabajo, o la pantalla no está enfocada y la opción offscreen-css no está configurada.
  • window#waybar.solo Cuando hay una ventana en mosaico en el espacio de trabajo.
  • window#waybar.floating Cuando solo hay ventanas flotantes en el espacio de trabajo.
  • window#waybar.stacked Cuando hay más de una ventana en el espacio de trabajo y el diseño del espacio de trabajo es apilado.
  • window#waybar.tabbed Cuando hay más de una ventana en el espacio de trabajo y el diseño del espacio de trabajo es en pestañas.
  • window#waybar.tiled Cuando hay más de una ventana en el espacio de trabajo y el diseño del espacio de trabajo es splith o splitv.
  • window#waybar.<app_id> Donde app_id es el app_id o el nombre de instancia (como chromium) de la única ventana en el espacio de trabajo.
