NOMBRE

wsdl - Generador de Proxy de Servicios Web de Mono

SINOPSIS

wsdl [opciones] [ruta | url]

DESCRIPCIÓN

wsdl es una herramienta para generar clases proxy que pueden ser utilizadas para acceder a servicios web. La herramienta lee un documento WSDL desde la ruta o URL proporcionada, y descarga esquemas referenciados u otros documentos WSDL si es necesario.

Esta herramienta se utiliza para dirigirse a la API 1.x. Para dirigirse a la API 2.x, por favor, utilice la herramienta wsdl2.

OPCIONES

Las siguientes opciones están disponibles:

-appsettingurlkey:clave -urlkey:clave
Especifica que la URL de los servicios debe leerse de la sección <appsettings> del archivo de configuración, utilizando la clave proporcionada.
-appsettingbaseurl:url , -baseurl:url
Especifica una URL base para el servicio. La URL final se construirá combinando este valor con la URL leída de la opción -appsettingurlkey, y el -type:tipo, ensamblado Genera un proxy para una clase de servicio web compilada. El parámetro URL puede utilizarse para proporcionar la ubicación del servicio. ubicación especificada en el documento WSDL.
-language:idioma , -l
Idioma del código a generar. Puede ser CS para C# (por defecto), Boo para Boo y VB para Visual Basic.
Alternativamente se puede especificar un nombre de tipo completo para un CodeProvider, por
ejemplo, se podría usar esto para generar código para el lenguaje imaginario "MyLan" que tiene el siguiente tipo completo: 
wsdl myservice.wsdl -language:MyLan.MyLanCodeProvider, MyLan.CodeDom, Version=1.0.0.0, Culture=neutral, PublicKeyToken=xxyy'
-namespace:nombre , -n:nombre
El espacio de nombres de las clases generadas. Si no se especifica, se utiliza el espacio de nombres por defecto.
-out:nombrearchivo , -o:nombrearchivo
El archivo de destino para el código generado.
-protocol:protocolo , -p:protocolo
El protocolo para el que generar código. Puede ser Soap (por defecto), HttpGet o HttpPost.
-sample:METODO
Esto mostrará la solicitud XML y la respuesta de las invocaciones de muestra a ese mensaje SOAP. Puede utilizar la opción -protocol: para representar el mensaje en diferentes formas.
-server
Generar un esqueleto de servidor en lugar de un proxy de cliente.
-nologo
Suprimir el logo de inicio.
-u:usuario , -user:usuario
El nombre de usuario a utilizar al conectarse al servidor.
-p:contraseña , -password:contraseña
La contraseña a utilizar al conectarse al servidor.
-d:dominio , -domain:dominio
El dominio a utilizar al conectarse al servidor.
