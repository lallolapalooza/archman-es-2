WESTCOS-TOOL(1) Herramientas OpenSC WESTCOS-TOOL(1)

NOMBRE

westcos-tool - utilidad para manipular estructuras de datos en tarjetas inteligentes westcos

SINOPSIS

westcos-tool [OPCIONES]

DESCRIPCIÓN

La utilidad westcos-tool se utiliza para manipular las estructuras de datos westcos en tarjetas inteligentes / tokens de 2 Ko. Los usuarios pueden crear PIN, claves y certificados almacenados en la tarjeta / token. Se realiza la autenticación del PIN del usuario para las operaciones que la requieren.

OPCIONES

--change-pin, -n

Cambia un PIN almacenado en la tarjeta. Se requiere autenticación del usuario para esta operación.

--certificate archivo, -t archivo

Escribe el archivo de certificado archivo en formato PEM en la tarjeta. Se requiere autenticación del usuario para esta operación.

--finalize, -f

Finaliza la tarjeta. Una vez finalizada, la clave por defecto se invalida, por lo que el PIN y el PUK ya no se podrán cambiar sin autenticación del usuario.

Advertencia, las tarjetas no finalizadas son inseguras porque el PIN se puede cambiar sin autenticación del usuario (suficiente con conocer la clave por defecto).

--generate-key, -g

Genera una clave privada en la tarjeta. La tarjeta no debe haber sido finalizada y se debe haber instalado un PIN (es decir, se debe haber creado el archivo para el PIN, véase la opción -i). Por defecto, la longitud de la clave es de 2048 bits. Se requiere autenticación del usuario para esta operación.

--help, -h

Muestra el mensaje de ayuda en pantalla.

--install-pin, -i

Instala el archivo PIN en la tarjeta. Debes proporcionar un valor de PIN con -x.

--key-length longitud, -l longitud

Cambia la longitud de la clave privada. Usar con -g.

--overwrite-key, -o

Sobrescribe la clave si ya existe una clave en la tarjeta.

--pin-value pin, -x pin --puk-value puk, -y puk

Estas opciones se pueden usar para especificar los valores de PIN/PUK en la línea de comandos. Si el valor se establece en env:VARIABLE, se utiliza el valor de la variable de entorno especificada. Por defecto, el código se solicita en la línea de comandos si es necesario.

Tenga en cuenta que en la mayoría de los sistemas operativos, cualquier usuario puede ver la línea de comandos de cualquier proceso del sistema utilizando utilidades como ps(1). Por lo tanto, debe preferir pasar los códigos a través de una variable de entorno en un sistema no seguro.

--read-file nombrearchivo, -j nombrearchivo

Lee el archivo nombrearchivo de la tarjeta. El archivo se escribe en disco con el nombre nombrearchivo. Se requiere autenticación del usuario para esta operación.

--reader arg, -r arg

Número del lector a utilizar. Por defecto, se utiliza el primer lector con una tarjeta presente. Si arg es un ATR, se elegirá el lector con una tarjeta coincidente.

--unblock-pin, -u

Desbloquea un PIN almacenado en la tarjeta. Se requiere el conocimiento de la Clave de Desbloqueo de PIN (PUK) para esta operación.

--verbose -v

Hace que westcos-tool sea más detallado. Especifique esta bandera varias veces para habilitar la salida de depuración en la biblioteca OpenSC.

--wait, -w

Espera a que se inserte una tarjeta.

--write-file nombrearchivo, -k nombrearchivo

Coloca el archivo con el nombre nombrearchivo del disco a la tarjeta. En la tarjeta, el archivo se escribe con el nombre nombrearchivo. Se requiere autenticación del usuario para esta operación.
