wcsrtombs(3) Manual de funciones de biblioteca wcsrtombs(3)

NOMBRE

wcsrtombs - convertir una cadena de caracteres anchos a una cadena multibyte

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <wchar.h>
size_t wcsrtombs(size_t dsize;
                 char dest[restrict dsize],
                 const wchar_t **restrict src,
                 size_t dsize, mbstate_t *restrict ps);

DESCRIPCIÓN

Si dest no es NULL, la función wcsrtombs() convierte la cadena de caracteres anchos *src a una cadena multibyte comenzando en dest. Se escriben como máximo dsize bytes en dest. El estado de desplazamiento *ps se actualiza. La conversión se realiza efectivamente llamando repetidamente a wcrtomb(dest, *src, ps), siempre que esta llamada tenga éxito, y luego incrementando dest en el número de bytes escritos y *src en uno. La conversión puede detenerse por tres razones:

•
Se ha encontrado un carácter ancho que no puede representarse como una secuencia multibyte (según la configuración regional actual). En este caso, *src apunta al carácter ancho no válido, se devuelve (size_t) -1 y errno se establece en EILSEQ.
•
El límite de tamaño fuerza una parada. En este caso, *src apunta al siguiente carácter ancho a convertir y se devuelve el número de bytes escritos en dest.
•
La cadena de caracteres anchos se ha convertido completamente, incluido el carácter ancho nulo terminador (L'\0'), lo que tiene el efecto secundario de devolver *ps al estado inicial. En este caso, *src se establece en NULL y se devuelve el número de bytes escritos en dest, excluyendo el byte nulo terminador ('\0').

Si dest es NULL, dsize se ignora y la conversión procede como se describe anteriormente, excepto que los bytes convertidos no se escriben en la memoria y no existe un límite de tamaño.

En ambos casos anteriores, si ps es NULL, se utiliza en su lugar un estado estático anónimo conocido solo por la función wcsrtombs().

El programador debe asegurarse de que haya espacio para al menos dsize bytes en dest.

VALOR DE RETORNO

La función wcsrtombs() devuelve el número de bytes que componen la parte convertida de la secuencia multibyte, sin incluir el byte nulo terminador. Si se encontró un carácter ancho que no pudo ser convertido, se devuelve (size_t) -1 y errno se establece en EILSEQ.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C99.

NOTAS

El comportamiento de wcsrtombs() depende de la categoría LC_CTYPE de la configuración regional actual.

Pasar NULL como ps no es seguro para múltiples hilos.
