WSLAY_EVENT_WANT_WRITE(3) wslay WSLAY_EVENT_WANT_WRITE(3)

NOMBRE

wslay_event_want_write - Indica si la biblioteca quiere enviar más datos

SINOPSIS

#include <wslay/wslay.h>

int wslay_event_want_write(wslay_event_context_ptr ctx)

DESCRIPCIÓN

wslay_event_want_write() se utiliza para saber si la biblioteca quiere enviar más datos al par.

Esto es útil para decidir si se deben esperar eventos de escritura en funciones de notificación de eventos de E/S como select(2) y poll(2).

VALOR DE RETORNO

wslay_event_want_write() devuelve 1 si la biblioteca quiere enviar más datos al par, o devuelve 0.

VER TAMBIÉN

wslay_event_want_read(), wslay_event_shutdown_write(), wslay_event_get_write_enabled()
