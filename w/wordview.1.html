wordview(1) Manual de comandos generales wordview(1)

NOMBRE

wordview - muestra texto contenido en archivos MS-Word en la ventana X

SINOPSIS

wordview [ nombrearchivo]

DESCRIPCIÓN

wordview es un simple envoltorio GUI para catdoc(1) que permite navegar por un archivo de Word interactivamente. No permite editar el archivo, pero permite guardar una representación de texto plano (o una versión con algunos comandos TeX) en un archivo.

Si por alguna razón catdoc no reconoce la codificación del archivo correctamente, wordview permite especificar la codificación interactivamente.

OPCIONES

wordview soporta opciones estándar de X, soportadas por wish(1)

RECURSOS X

Los siguientes recursos X pueden ser utilizados para personalizar la apariencia de wordview:

Wordview.Text.Background
color de fondo para la ventana principal
Wordview.Text.Foreground
Color de primer plano para la ventana principal
Wordview.Text.selectBackground
Color de fondo del texto seleccionado
Wordview.Text.selectForeground
Color de primer plano del texto seleccionado
Wordview.Text.Font
Fuente para mostrar el texto. Recomendamos usar una fuente de ancho fijo, como Courier, ya que catdoc(1) está destinado a convertir Word a texto. Se pueden usar nombres de fuentes XLFD o especificaciones de fuentes estilo Tk como {Courier 12pt} para especificar la fuente. Si usa nombres de fuentes XLFD, se recomienda el uso de fuentes Unicode (iso10646-1).
Wordview.Text.findMode
Cómo buscar texto. Esta opción puede tener el valor exact o regexp y especifica si el texto se busca por coincidencia exacta o por expresión regular por defecto. Este comportamiento se puede alternar interactivamente a través de una casilla de verificación en el diálogo de búsqueda.
Wordview.Text.findCase
Esta opción booleana controla si la búsqueda distingue entre mayúsculas y minúsculas. El valor por defecto es no.
Wordview.Menu.highlightBackground
Color de fondo para el elemento de menú resaltado
Wordview.Menu.highlightThickness
Wordview.Menu.activeBackground
Color de fondo del elemento de menú activo.
Wordview.Menu.activeBorderWidth
Ancho (en píxeles) del borde alrededor del elemento de menú resaltado. El valor por defecto es 0, lo que difiere del valor predeterminado global de Tk. Consulte options(n) para más detalles.

Muchas otras opciones de recursos que afectan el comportamiento de los widgets estándar de Tk pueden afectar a wordview. Consulte las páginas del manual de Tcl/Tk para más información.
