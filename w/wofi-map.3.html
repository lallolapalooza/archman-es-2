NOMBRE

wofi - Funciones y documentación de la API de Map

DESCRIPCIÓN

Las funciones documentadas aquí se utilizan para interactuar con la configuración y el mapa de wofi. Se definen en map.h.

FUNCIONES DE MAPA

Las siguientes funciones se utilizan para interactuar con un struct map*

struct map* map_init(void)
Asigna y devuelve un nuevo mapa de cadenas. Los mapas de cadenas solo admiten valores de cadena.
struct map* map_init_void(void)
Asigna y devuelve un nuevo mapa vacío. Un mapa vacío admite valores de cualquier tipo.
void map_free(struct map* map)
Libera el mapa proporcionado y todas sus claves. Los valores solo se liberan si es un mapa de cadenas.
bool map_put(struct map* map, const char* key, char* value)
Devuelve verdadero si el mapa dado es un mapa de cadenas, de lo contrario, devuelve falso e imprime un mensaje en stderr.

struct map* map - El mapa en el que insertar.

const char* key - La clave bajo la cual almacenar el valor. Esta clave se pasa a strdup() antes de guardarla y se liberará al ejecutar map_free().

char* value - El valor a almacenar. Este valor se pasa a strdup() antes de guardarlo y se liberará al ejecutar map_free(). Si el valor es NULL, no se pasará a strdup().

bool map_put_void(struct map* map, const char* key, void* value)
Devuelve verdadero si el mapa dado es un mapa vacío, de lo contrario, devuelve falso e imprime un mensaje en stderr.

struct map* map - El mapa en el que insertar.

const char* key - La clave bajo la cual almacenar el valor. Esta clave se pasa a strdup() antes de guardarla y se liberará al ejecutar map_free().

void* value - El valor a almacenar. Este puntero se almacena en el mapa; el llamador es responsable de liberarlo y no se liberará al ejecutar map_free().

void* map_get(struct map* map, const char* key)
Devuelve el valor almacenado bajo key o NULL si no existe ninguna clave. También se puede devolver NULL si se almacenó allí con map_put() o map_put_void().

struct map* map - El mapa del que obtener el valor.

const char* key - La clave a buscar.

bool map_contains(struct map* map, const char* key)
Devuelve verdadero si la clave existe, falso en caso contrario. Esto se implementa como una comprobación de value != NULL, por lo que un valor NULL se considera inexistente.

struct map* map - El mapa contra el que comprobar.

const char* key - La clave a comprobar.

size_t map_size(struct map* map)
Devuelve el número de entradas en este mapa.

struct map* map - El mapa del que obtener el tamaño.
