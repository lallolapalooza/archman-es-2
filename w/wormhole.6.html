NOMBRE

wormhole - animación de vuelo a través de un agujero de gusano

SINOPSIS

wormhole [--display host:display.screen] [--window] [--visual visual] [--root] [--window-id número] [--stars n] [--delay usecs] [--zspeed n] [--fps]

DESCRIPCIÓN

El programa wormhole muestra una animación de vuelo a través de un túnel rodeado de haces de luz.

OPCIONES

wormhole acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Haz que todas las rocas sean del mismo color.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--stars entero
Número de estrellas a crear en cada bucle de animación.
--zspeed entero
Velocidad a la que pasan los haces de luz.
--delay microsegundos
Número de microsegundos de retardo entre cada fotograma. Predeterminado 10000, lo que significa aproximadamente 1/100 de segundo. Compara y contrasta con --zspeed, arriba.
--fps
Muestra la velocidad de fotogramas actual y la carga de la CPU.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
