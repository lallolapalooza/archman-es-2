WHOWATCH(1) Manual de Comandos Generales WHOWATCH(1)

NOMBRE

whowatch - herramienta de monitoreo de procesos y usuarios interactiva en consola.

DESCRIPCIÓN

Whowatch es una herramienta de monitoreo de usuarios y procesos interactiva en consola. Muestra información sobre los usuarios actualmente conectados a la máquina, en tiempo real. Además de la información estándar (nombre de usuario, tty, host, proceso del usuario), se muestra el tipo de conexión (por ejemplo, telnet o ssh). La visualización de la línea de comandos del usuario se puede cambiar por el tiempo de inactividad del tty. Se puede seleccionar un usuario específico y ver su árbol de procesos, así como el árbol de todos los procesos del sistema. El árbol puede mostrarse con una columna adicional que indica el propietario de cada proceso. En el modo de árbol de procesos, se pueden enviar las señales SIGINT, SIGHUP, SIGTERM y SIGKILL al proceso seleccionado. Matar procesos es tan simple y divertido como borrar líneas en la pantalla.

Whowatch no tiene opciones de línea de comandos ni archivo de configuración. Todas las acciones se realizan en tiempo real presionando las siguientes teclas:

Modo de lista de usuarios:

'arriba' 'abajo'
movimiento del cursor
'i'
alternar entre la línea de comandos del usuario y el tiempo de inactividad
'c'
línea de comandos completa activada/desactivada. Desactivar la línea de comandos completa puede ahorrar tiempo de CPU. También puede proporcionar información adicional sobre el ejecutable del proceso.
'enter'
ver el árbol de procesos del usuario seleccionado.
't'
todos los procesos del sistema (árbol init)

Modo árbol:

'arriba' 'abajo'
movimiento del cursor
'enter'
volver a la lista de usuarios
'o'
mostrar propietarios de procesos
'c'
línea de comandos completa activada/desactivada. Desactivar la línea de comandos completa puede ahorrar tiempo de CPU. También puede proporcionar información adicional sobre el ejecutable del proceso.
'Ctrl-I'
enviar señal INT al proceso seleccionado
'Ctrl-K'
enviar señal KILL al proceso seleccionado
'Ctrl-U'
enviar señal HUP al proceso seleccionado
'Ctrl-T'
enviar señal TERM al proceso seleccionado

PLUGINS

Whowatch tiene la capacidad de cargar plugins durante la ejecución del programa. El plugin imprime información dentro de la ventana de detalles. Los plugins brindan flexibilidad: si se necesita información específica sobre un proceso, usuario o sistema, se podría escribir un programa separado para obtener dicha información. Dado que existen tres tipos de ventanas de detalles (proceso, usuario y sistema), se pueden cargar como máximo tres plugins. Whowatch tiene una API muy simple para escribir plugins.

ARCHIVOS

El programa lee /var/log/wtmp, /var/run/utmp. Bajo Linux, el programa también lee archivos del directorio /proc. Sin acceso de lectura a estos archivos, la funcionalidad de whowatch será limitada o el programa ni siquiera se iniciará.

VER TAMBIÉN

finger(1) ps(1), pstree(1), top(1), w(1), lsof(8), kill(1) killall(1)

BUGS

Debido a la falta de ut_pid en las estructuras utmp y wtmp en los sistemas *BSD, el programa intenta obtener el PID de un shell de inicio de sesión analizando los procesos que controlan la terminal y los nombres de los procesos. Bajo ciertas condiciones, esto puede llevar a resultados incorrectos, es decir, el árbol de procesos asociado con la sesión del usuario será incorrecto.
