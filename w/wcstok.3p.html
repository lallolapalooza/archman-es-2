WCSTOK(3P) Manual de Programador POSIX WCSTOK(3P)

PRÓLOGO

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

wcstok — dividir una cadena de caracteres anchos en tokens

SINOPSIS

#include <wchar.h>
wchar_t *wcstok(wchar_t *restrict ws1, const wchar_t *restrict ws2,
    wchar_t **restrict ptr);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia se alinea con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Una secuencia de llamadas a wcstok() dividirá la cadena de caracteres anchos apuntada por ws1 en una secuencia de tokens, cada uno de los cuales será delimitado por un código de carácter ancho de la cadena de caracteres anchos apuntada por ws2. El argumento ptr apunta a un puntero wchar_t proporcionado por el llamador en el que wcstok() almacenará la información necesaria para continuar escaneando la misma cadena de caracteres anchos.

La primera llamada de la secuencia tendrá ws1 como su primer argumento, y las llamadas posteriores se realizarán con un puntero nulo como primer argumento. La cadena separadora apuntada por ws2 puede ser diferente en cada llamada.

La primera llamada de la secuencia buscará en la cadena de caracteres anchos apuntada por ws1 el primer código de carácter ancho que *no* esté contenido en la cadena separadora actual apuntada por ws2. Si no se encuentra ningún código de carácter ancho de este tipo, entonces no hay tokens en la cadena de caracteres anchos apuntada por ws1 y wcstok() devolverá un puntero nulo. Si se encuentra dicho código de carácter ancho, será el inicio del primer token.

La función wcstok() buscará a partir de ahí un código de carácter ancho que *esté* contenido en la cadena separadora actual. Si no se encuentra ningún código de carácter ancho de este tipo, el token actual se extenderá hasta el final de la cadena de caracteres anchos apuntada por ws1, y las búsquedas posteriores de un token devolverán un puntero nulo. Si se encuentra dicho código de carácter ancho, se sobrescribirá con un carácter ancho nulo, que terminará el token actual. La función wcstok() guardará un puntero al siguiente código de carácter ancho, desde el cual comenzará la siguiente búsqueda de un token.

Cada llamada subsiguiente, con un puntero nulo como valor del primer argumento, comenzará la búsqueda desde el puntero guardado y se comportará como se describe arriba.

La implementación se comportará como si ninguna función llamara a wcstok().

VALOR DE RETORNO

Al completarse con éxito, la función wcstok() devolverá un puntero al primer código de carácter ancho de un token. De lo contrario, si no hay ningún token, wcstok() devolverá un puntero nulo.

ERRORES

No se definen errores.
