NOMBRE

waybar - módulo MPRIS

DESCRIPCIÓN

El módulo mpris muestra los medios que se están reproduciendo actualmente a través de libplayerctl.

CONFIGURACIÓN

player:
tipo: cadena
predeterminado: playerctld
Nombre del reproductor MPRIS al que adjuntarse. Usar el valor predeterminado sigue siempre al reproductor actualmente activo.

ignored-players:
tipo: []cadena
Ignorar actualizaciones de los reproductores listados, cuando se usa playerctld.

interval:
tipo: entero
predeterminado: 0
Actualizar la información MPRIS en un temporizador.

format:
tipo: cadena
predeterminado: {player} ({status}) {dynamic}
El formato del texto.

format-[status]:
tipo: cadena
El formato de texto específico del estado.

tooltip:
tipo: booleano
predeterminado: verdadero
Opción para deshabilitar la información emergente al pasar el ratón por encima.

tooltip-format:
tipo: cadena
predeterminado: {player} ({status}) {dynamic}
El formato del texto de la información emergente.

tooltip-format-[status]:
tipo: cadena
El formato de texto específico del estado para la información emergente.

artist-len:
tipo: entero
Longitud máxima de la etiqueta Artista (los caracteres Unicode de ancho completo/ancho doble cuentan como dos). Establecer a cero para ocultar el artista en la etiqueta `{dynamic}`.

album-len:
tipo: entero
Longitud máxima de la etiqueta Álbum (los caracteres Unicode de ancho completo/ancho doble cuentan como dos). Establecer a cero para ocultar el álbum en la etiqueta `{dynamic}`.

title-len:
tipo: entero
Longitud máxima de la etiqueta Título (los caracteres Unicode de ancho completo/ancho doble cuentan como dos). Establecer a cero para ocultar el título en la etiqueta `{dynamic}`.

dynamic-len:
tipo: entero
Longitud máxima de la etiqueta Dinámica (los caracteres Unicode de ancho completo/ancho doble
cuentan como dos). La etiqueta dinámica no truncará ninguna etiqueta más allá de sus
límites de longitud establecidos, en su lugar, intentará encajar la mayor cantidad posible de
etiquetas disponibles. Se recomienda establecer title-len a
un valor menor o igual a este, para que el título siempre se muestre.

dynamic-order:
tipo: []cadena
predeterminado: ["title", "artist", "album", "position", "length"]
Orden de las etiquetas que se muestran en la etiqueta Dinámica. Las etiquetas de posición y longitud
siempre se combinarán en el formato [{position}/{length}]. El orden
de estas etiquetas en relación con otras etiquetas se determinará en función de la
declaración de la primera de las dos etiquetas. La ausencia en esta lista significa
exclusión forzada.

dynamic-importance-order:
tipo: []cadena
predeterminado: ["title", "artist", "album", "position", "length"]
Prioridad de las etiquetas al truncar la etiqueta Dinámica. Las últimas
serán las primeras en truncarse. La ausencia en esta lista significa inclusión forzada.

dynamic-separator:
tipo: cadena
predeterminado: " - "
Estos caracteres se utilizarán para separar dos etiquetas diferentes, excepto
cuando una de estas etiquetas sea posición y longitud.

truncate-hours:
tipo: booleano
predeterminado: verdadero
Si se deben ocultar las horas cuando la duración del medio es inferior a una hora.

enable-tooltip-len-limits:
tipo: booleano
predeterminado: falso
Opción para habilitar también los límites de longitud para la información emergente. Por defecto, la información emergente ignora todos los límites de longitud.

ellipsis:
tipo: cadena
predeterminado: "…"
Este carácter se utilizará cuando alguna de las etiquetas exceda su longitud máxima.
Si no desea utilizar puntos suspensivos, establezca esto como una cadena vacía.

rotate:
tipo: entero
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

max-length:
tipo: entero
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
tipo: entero
La longitud mínima en caracteres que el módulo debe aceptar.

align:
tipo: flotante
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo se rota, seguirá el flujo del texto.

justify:
tipo: cadena
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left' (izquierda), 'right' (derecha) o 'center' (centro) para definir el posicionamiento.

on-click:
tipo: cadena
predeterminado: play-pause
Sobrescribir las acciones predeterminadas de alternancia.

on-click-middle:
tipo: cadena
predeterminado: previous track
Sobrescribir las acciones predeterminadas de alternancia.

on-click-right:
tipo: cadena
predeterminado: next track
Sobrescribir las acciones predeterminadas de alternancia.

player-icons:
tipo: mapa[cadena]cadena
Permite establecer {player_icon} según la propiedad player-name.

status-icons:
tipo: mapa[cadena]cadena
Permite establecer {status_icon} según el estado del reproductor (playing, paused, stopped).

expand:
tipo: booleano
predeterminado: falso
Permite que este módulo consuma todo el espacio restante dinámicamente.

REEMPLAZOS DE FORMATO

{player}: El nombre del reproductor multimedia actual

{status}: El estado actual (playing, paused, stopped)

{artist}: El artista de la pista actual

{album}: El título del álbum de la pista actual

{title}: El título de la pista actual

{length}: Duración de la pista, formateada como HH:MM:SS

{dynamic}: Usa {artist}, {album},
{title} y {length}, omite automáticamente
los valores vacíos

{player_icon}: Elige un icono de player-icons basado en {player}

{status_icon}: Elige un icono de status-icons basado en {status}

EJEMPLOS

"mpris": {
	"format": "{player_icon} {dynamic}",
	"format-paused": "{status_icon} <i>{dynamic}</i>",
	"player-icons": {
		"default": "▶",
		"mpv": "🎵"
	},
	"status-icons": {
		"paused": "⏸"
	},
	// "ignored-players": ["firefox"]
}
