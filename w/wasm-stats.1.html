NOMBRE

wasm-stats — muestra estadísticas de un módulo

SINOPSIS

wasm-stats [opciones] archivo ...

DESCRIPCIÓN

wasm-stats Lee un archivo en formato binario wasm y muestra estadísticas.

Las opciones son las siguientes:

--help
Imprime un mensaje de ayuda
--version
Imprime información de la versión
-v, --verbose
Úselo varias veces para obtener más información
--enable-exceptions
Habilita el manejo experimental de excepciones
--disable-mutable-globals
Deshabilita la importación/exportación de globales mutables
--disable-saturating-float-to-int
Deshabilita operadores de conversión de punto flotante a entero saturada
--disable-sign-extension
Deshabilita operadores de extensión de signo
--disable-simd
Deshabilita el soporte SIMD
--enable-threads
Habilita el soporte de hilos
--enable-function-references
Habilita referencias de funciones tipadas
--disable-multi-value
Deshabilita multi-valor
--enable-tail-call
Habilita el soporte de llamada final
--disable-bulk-memory
Deshabilita operaciones de memoria bulk
--disable-reference-types
Deshabilita tipos de referencia (externref)
--enable-annotations
Habilita sintaxis de anotación personalizada
--enable-code-metadata
Habilita metadatos de código
--enable-gc
Habilita recolección de basura
--enable-memory64
Habilita memoria de 64 bits
--enable-multi-memory
Habilita multi-memoria
--enable-extended-const
Habilita expresiones constantes extendidas
--enable-all
Habilita todas las características
-o, --output=NOMBRE_ARCHIVO
Archivo de salida para los recuentos de opcodes, por defecto usa stdout
-c, --cutoff=N
Corte para reportar recuentos menores a N
-s, --separator=SEPARADOR
Texto separador entre el elemento y el recuento al reportar recuentos

EJEMPLOS

Analiza el archivo binario test.wasm y escribe el archivo de distribución de opcodes test.dist

$ wasm-stats test.wasm -o test.dist
