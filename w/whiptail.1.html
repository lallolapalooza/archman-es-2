WHIPTAIL(1) Manual de Comandos Generales WHIPTAIL(1)

NOMBRE

whiptail - muestra cuadros de diálogo desde scripts de shell

SINOPSIS

whiptail [ --title título ] [ --backtitle título_fondo ] [ --clear ] [ --default-item cadena ] [ --defaultno ] [ --fb ] [ --nocancel ] [ --yes-button texto ] [ --no-button texto ] [ --ok-button texto ] [ --cancel-button texto ] [ --noitem [ ] --output-fd fd ] [ --separate-output ] [ --scrolltext ] [ --topleft ] opciones_caja

DESCRIPCIÓN

whiptail es un programa que permite presentar una variedad de preguntas o mostrar mensajes utilizando cuadros de diálogo desde un script de shell. Actualmente, se implementan los siguientes tipos de cuadros de diálogo:

Cuadro de sí/no, cuadro de menú, cuadro de entrada, cuadro de mensaje, cuadro de texto, cuadro de información, cuadro de lista de verificación, cuadro de lista de radio, cuadro de medidor y cuadro de contraseña.

OPCIONES

--clear
La pantalla se borrará con el atributo de pantalla al salir. Esto no funciona en un xterm (y sus descendientes) si la conmutación de pantalla alternativa está habilitada, porque en ese caso slang escribe en (y borra) una pantalla alternativa.
--defaultno
El cuadro de diálogo se abrirá con el cursor sobre el botón No.
--default-item cadena
Establece el elemento predeterminado en un cuadro de menú. Normalmente, el primer elemento del cuadro es el predeterminado.
--fb, --fullbuttons
Utiliza botones completos. (Por defecto, whiptail utiliza botones compactos).
--nocancel
El cuadro de diálogo no tendrá un botón Cancelar.
--yes-button texto
Establece el texto del botón Sí.
--no-button texto
Establece el texto del botón No.
--ok-button texto
Establece el texto del botón Aceptar.
--cancel-button texto
Establece el texto del botón Cancelar.
--noitem
Los widgets de menú, lista de verificación y lista de radio mostrarán solo etiquetas, no las cadenas de elementos. El widget de menú aún necesita algún elemento especificado, pero las listas de verificación y de radio esperan solo etiqueta y estado.
--notags
No muestres etiquetas en los widgets de menú, lista de verificación y lista de radio.
--separate-output
Para los widgets de lista de verificación, la salida del resultado es una línea a la vez, sin comillas. Esto facilita el análisis por otro programa.
--output-fd fd
Dirige la salida al descriptor de archivo dado. La mayoría de los scripts de whiptail escriben en la salida estándar de error, pero los mensajes de error también pueden escribirse allí, dependiendo de tu script.
--title título
Especifica una cadena de título que se mostrará en la parte superior del cuadro de diálogo.
--backtitle título_fondo
Especifica una cadena de título de fondo que se mostrará en el fondo, en la parte superior de la pantalla.
--scrolltext
Fuerza la visualización de una barra de desplazamiento vertical.
--topleft
Coloca la ventana en la esquina superior izquierda.
-h, --help
Imprime un mensaje de ayuda y sale.
-v, --version
Imprime información de la versión y sale.
Opciones de Caja
--yesno texto alto ancho
Se mostrará un cuadro de diálogo de sí/no de tamaño alto filas por ancho columnas. La cadena especificada por texto se muestra dentro del cuadro de diálogo. Si esta cadena es demasiado larga para caber en una línea, se dividirá automáticamente en varias líneas en lugares apropiados. La cadena texto también puede contener la subcadena "\n" o caracteres de nueva línea `\n' para controlar explícitamente el salto de línea. Este cuadro de diálogo es útil para hacer preguntas que requieren que el usuario responda sí o no. El cuadro de diálogo tiene un botón Sí y un botón No, entre los cuales el usuario puede alternar presionando la tecla TAB.
--msgbox texto alto ancho
Un cuadro de mensaje es muy similar a un cuadro de sí/no. La única diferencia entre un cuadro de mensaje y un cuadro de sí/no es que un cuadro de mensaje tiene solo un único botón Aceptar. Puedes usar este cuadro de diálogo para mostrar cualquier mensaje que desees. Después de leer el mensaje, el usuario puede presionar la tecla ENTER para que whiptail salga y el script de shell llamador pueda continuar su operación.
--infobox texto alto ancho
Un cuadro de información es básicamente un cuadro de mensaje. Sin embargo, en este caso, whiptail saldrá inmediatamente después de mostrar el mensaje al usuario. La pantalla no se borra cuando whiptail sale, por lo que el mensaje permanecerá en la pantalla hasta que el script de shell llamador lo borre más tarde. Esto es útil cuando deseas informar al usuario que algunas operaciones están en curso y que pueden requerir tiempo para finalizar.
--inputbox texto alto ancho [init]
Un cuadro de entrada es útil cuando deseas hacer preguntas que requieren que el usuario ingrese una cadena como respuesta. Si se proporciona `init`, se utiliza para inicializar la cadena de entrada. Al ingresar la cadena, la tecla Retroceso se puede usar para corregir errores de escritura. Si la cadena de entrada es más larga que el ancho del cuadro de diálogo, el campo de entrada se desplazará. Al salir, la cadena de entrada se imprimirá en stderr.
--passwordbox texto alto ancho [init]
Un cuadro de contraseña es similar a un cuadro de entrada, excepto que el texto que el usuario ingresa no se muestra. Esto es útil al solicitar contraseñas u otra información sensible. Ten en cuenta que si se pasa algo en "init", será visible en la tabla de procesos del sistema para observadores casuales. Además, es muy confuso para el usuario proporcionarle una contraseña predeterminada que no puede ver. Por estas razones, se desaconseja encarecidamente el uso de "init".
--textbox archivo alto ancho
Un cuadro de texto te permite mostrar el contenido de un archivo de texto en un cuadro de diálogo. Es como un visor de archivos de texto simple. El usuario puede moverse por el archivo usando las teclas ARRIBA/ABAJO, PÁGINA ARRIBA/PÁGINA ABAJO y INICIO/FIN disponibles en la mayoría de los teclados. Si las líneas son demasiado largas para mostrarse en el cuadro, las teclas IZQUIERDA/DERECHA se pueden usar para desplazar la región de texto horizontalmente. Para mayor comodidad, también se proporcionan funciones de búsqueda hacia adelante y hacia atrás.
--menu texto alto ancho alto-menu [ etiqueta item ] ...
Como su nombre indica, un cuadro de menú es un cuadro de diálogo que se puede utilizar para presentar una lista de opciones en forma de menú para que el usuario elija. Cada entrada de menú consta de una cadena de etiqueta y una cadena de elemento. La etiqueta da a la entrada un nombre para distinguirla de las demás entradas del menú. El elemento es una breve descripción de la opción que representa la entrada. El usuario puede moverse entre las entradas del menú presionando las teclas ARRIBA/ABAJO, la primera letra de la etiqueta como tecla de acceso rápido. Se muestran alto-menu entradas en el menú a la vez, pero el menú se desplazará si hay más entradas que esa. Cuando whiptail sale, la etiqueta de la opción elegida

NAME

whiptail

display large amounts of text, or create simple dialog boxes

SYNOPSIS

whiptail [--title text] [--backtitle text] [--fb] [--msgbox text height width] [--yesno text height width] [--infobox text height width] [--menu text height width menu-height [tag item]...] [--checklist text height width list-height [tag item status]...] [--radiolist text height width list-height [tag item status]...] [--gauge text height width percent] [--passwordbox text height width [height]] [--textbox text height width [height]]

DESCRIPTION

whiptail is a program that creates interactive dialog boxes from within a shell script. It can be used to display text, ask questions, or prompt for input. It is a replacement for the older dialog program, and provides a more modern interface.

OPTIONS

The following options are supported:

--title text
Specifies the title for the dialog box. This will appear in the border of the box.
--backtitle text
Specifies the text to display along the top of the screen, in the backround. This can be used to provide context or branding.
--fb
This option turns on the functionality that causes whiptail to reread the size of the terminal screen after each dialog box has been drawn. This is useful for dialog boxes that are larger than the screen, or when the dialog box size is dependent on the screen size.
--msgbox text height width
Displays a message box with the given text, height, and width. This is typically used to display information to the user that requires acknowledgment. The user presses the ENTER key to dismiss the message.
--yesno text height width
Displays a message box with Yes and No buttons. This is typically used to ask a yes/no question. The return status is 0 if Yes is pressed, and 1 if No is pressed.
--infobox text height width
Displays an information box. This is similar to a message box, but it does not have any buttons. It is intended for displaying messages that do not require user interaction. The box disappears after the user presses ENTER.
--textbox text height width [height]
Displays the contents of the given text file in a pop-up window. This is useful for displaying longer text, such as license agreements or readme files. The user can scroll through the text using the arrow keys. The user presses the ENTER key to dismiss the text box.
--menu text height width menu-height [tag item]...
Displays a menu box. The user can select an item from the menu using the arrow keys and pressing ENTER. The selected item's tag string is printed to stderr on exit.
--checklist text height width list-height [ tag item status ] ...
A checklist box is similar to a menu box in that there are multiple entries presented in the form of a menu. You can select and deselect items using the SPACE key. The initial on/off state of each entry is specified by status. On exit, a list of the tag strings of those entries that are turned on will be printed on stderr.
--radiolist text height width list-height [ tag item status ] ...
A radiolist box is similar to a menu box. The only difference is that you can indicate which entry is currently selected, by setting its status to on.
--gauge text height width percent
A gauge box displays a meter along the bottom of the box. The meter indicates a percentage. New percentages are read from standard input, one integer per line. The meter is updated to reflect each new percentage. If stdin is XXX, the first following line is a percentage and subsequent lines up to another XXX are used for a new prompt. The gauge exits when EOF is reached on stdin.
--passwordbox text height width [height]
A passwordbox is used to prompt the user for a password. The text entered by the user is not echoed to the screen. The height argument is optional, and if it is not specified, the height will be set to 1. On exit, the password entered by the user will be printed to stderr.

NOTES

whiptail interprets arguments starting with a dash "-" as being arguments. To avoid this, and start some text in, for example, a menubox item, with a dash, whiptail honours the getopt convention of accepting the special argument "--" which means that all following arguments with dashes are to be treated verbatim and not parsed as options.

If the specified height, width, or menu/list-height is zero, whiptail will increase the values as needed in order to display all information.

DIAGNOSTICS

Exit status is 0 if whiptail is exited by pressing the Yes or OK button, and 1 if the No or Cancel button is pressed. Otherwise, if errors occur inside whiptail or whiptail is exited by pressing the ESC key, the exit status is -1.
