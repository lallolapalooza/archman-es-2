NOMBRE

waybar - Módulo upower

DESCRIPCIÓN

El módulo upower muestra la capacidad principal de la batería con todos los demás dispositivos compatibles con upower en la información sobre herramientas.

CONFIGURACIÓN

native-path:
tipo: string
por defecto:
La batería a monitorizar. Consultar la https://upower.freedesktop.org/docs/UpDevice.html#UpDevice--native-path
Se puede obtener usando `upower --dump`

model:
tipo: string
por defecto:
La batería a monitorizar, basada en el modelo. (esta opción se ignora si se proporciona native-path).
Se puede obtener usando `upower --dump`

icon-size:
tipo: integer
por defecto: 20
Define el tamaño de los iconos.

format:
tipo: string
por defecto: {percentage}
El formato del texto.

format-alt:
tipo: string
por defecto: {percentage} {time}
El formato del texto cuando se alterna.

hide-if-empty:
tipo: bool
por defecto: true
Define la visibilidad del módulo si no se encuentran dispositivos.

tooltip:
tipo: bool
por defecto: true
Opción para deshabilitar la información sobre herramientas al pasar el cursor por encima.

tooltip-spacing:
tipo: integer
por defecto: 4
Define el espaciado entre el nombre del dispositivo en la información sobre herramientas y el estado de la batería del dispositivo.

tooltip-padding:
tipo: integer
por defecto: 4
Define el espaciado entre el borde de la ventana de información sobre herramientas y el contenido de la información sobre herramientas.

on-click:
tipo: string
Comando a ejecutar al hacer clic en el módulo.

show-icon:
tipo: bool
por defecto: true
Opción para deshabilitar el icono de la batería.

menu:
tipo: string
Acción que muestra el menú emergente.

menu-file:
tipo: string
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

REEMPLAZOS DE FORMATO

{percentage}: La capacidad de la batería en porcentaje

{time}: Un tiempo estimado hasta que se agote o hasta que se cargue completamente
dependiendo del estado de carga.
