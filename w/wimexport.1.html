WIMEXPORT(1) Comandos de usuario WIMEXPORT(1)

NOMBRE

wimexport - Exportar imagen(es) de un archivo WIM

SINOPSIS

wimexport ARCHIVO_WIM_ORIGEN IMAGEN_ORIGEN ARCHIVO_WIM_DESTINO
[NOMBRE_IMAGEN_DESTINO [DESCRIPCIÓN_IMAGEN_DESTINO]] [OPCIÓN...]

DESCRIPCIÓN

wimexport, o equivalentemente wimlib-imagex export, exporta la imagen especificada desde ARCHIVO_WIM_ORIGEN a ARCHIVO_WIM_DESTINO, cambiando opcionalmente el nombre y/o la descripción de la imagen. Si ARCHIVO_WIM_DESTINO ya existe, la imagen se añadirá al final; de lo contrario, se creará un nuevo archivo WIM para contener la imagen exportada.

IMAGEN_ORIGEN especifica la imagen en ARCHIVO_WIM_ORIGEN a exportar. Puede ser el índice (basado en 1) de una imagen, el nombre de una imagen, o la palabra clave "all" para especificar todas las imágenes. Puedes usar wiminfo(1) para listar las imágenes contenidas en ARCHIVO_WIM_ORIGEN.

Si se especifica, NOMBRE_IMAGEN_DESTINO es el nombre que se le dará a la imagen que se está exportando. El valor predeterminado es su nombre en ARCHIVO_WIM_ORIGEN. Si se especifica, NOMBRE_IMAGEN_DESTINO debe ser un nombre que aún no esté en uso en ARCHIVO_WIM_DESTINO, o la cadena vacía para dejar la imagen sin nombre. NOMBRE_IMAGEN_DESTINO no se puede especificar si se están exportando todas las imágenes ("all").

Si se especifica, DESCRIPCIÓN_IMAGEN_DESTINO es la descripción que se le dará a la imagen que se está exportando. El valor predeterminado es su descripción en ARCHIVO_WIM_ORIGEN.

wimexport soporta la exportación de imágenes desde WIMs independientes, así como desde WIMs divididos y WIMs delta. Consulta WIMS_DIVIDIDOS.

wimexport también soporta la exportación de imágenes desde un WIM no pipable a un WIM pipable o viceversa, o desde un WIM no sólido a un WIM sólido o viceversa. También puede exportar un WIM pipable directamente a la salida estándar si ARCHIVO_WIM_DESTINO se especifica como "-"; consulta --pipable.

OPCIONES

--boot
Marca la imagen exportada como la imagen "arrancable" del WIM; o, si se están exportando múltiples imágenes, haz que la imagen que era la imagen arrancable del WIM de origen también sea la imagen arrancable del WIM de destino.
--check
Antes de exportar la(s) imagen(es), verifica la integridad del WIM de origen, del WIM de destino y de cualquier WIM referenciado siempre que tengan información de integridad adicional presente. También incluye información de integridad adicional en el WIM de destino, incluso si no estaba presente antes.
--nocheck
No incluyas información de integridad adicional en el WIM de destino, incluso si estaba presente antes.
--include-integrity
Incluye información de integridad adicional en el WIM de destino, es decir, como --check pero sin realizar ninguna verificación previa.
--compress=TIPO[:NIVEL]
Especifica el tipo de compresión, y opcionalmente el nivel de compresión para ese tipo de compresión, para ARCHIVO_WIM_DESTINO. Ten en cuenta que si ARCHIVO_WIM_DESTINO ya existe, su tipo de compresión no se puede cambiar con esta opción. Consulta la documentación de esta opción para wimcapture(1) para más detalles.
--chunk-size=TAMAÑO
Establece el tamaño del fragmento de compresión WIM a TAMAÑO. Consulta la documentación de esta opción para wimcapture(1) para más detalles.
--recompress
Fuerza la recompresión de todos los datos exportados, incluso si el WIM de destino utilizará el mismo tipo de compresión que el WIM de origen.
--solid
Crea un archivo "sólido" que comprime múltiples archivos juntos. Esto generalmente resulta en una relación de compresión significativamente mejor, pero tiene desventajas como una menor compatibilidad. Consulta la documentación de esta opción para wimcapture(1) para más detalles.
--solid-compress=TIPO[:NIVEL]
Similar a --compress, pero establece el tipo de compresión utilizado en los recursos sólidos. Consulta la documentación de esta opción para wimcapture(1) para más detalles.
--solid-chunk-size=TAMAÑO
Similar a --chunk-size, pero establece el tamaño del fragmento utilizado en los recursos sólidos. Consulta la documentación de esta opción para wimcapture(1) para más detalles.
--threads=NUM_HILOS
Número de hilos a utilizar para comprimir datos. Predeterminado: autodetectar (número de procesadores).
--rebuild
Si se exporta a un WIM existente, reconstruirlo en lugar de añadirle. La reconstrucción es más lenta pero ahorrará algo de espacio que de otro modo quedaría como un hueco en el WIM. Consulta también wimoptimize(1).
--ref="GLOB"
Glob de archivos de WIMs adicionales o partes de WIMs divididos para referenciar recursos. Consulta WIMS_DIVIDIDOS. Esta opción se puede especificar varias veces. Nota: GLOB aparece entre comillas porque es interpretado por wimexport y puede necesitar ser citado para evitar la expansión del shell.
--pipable
Construye o reconstruye ARCHIVO_WIM_DESTINO como un "WIM pipable" que puede ser aplicado completamente de forma secuencial, incluso desde una tubería (pipe). Consulta wimcapture(1) para más detalles sobre cómo crear WIMs pipables. El valor predeterminado sin esta opción es hacer que ARCHIVO_WIM_DESTINO sea pipable solo si era "-" (salida estándar) o era un WIM pipable existente.
--not-pipable
Reconstruye ARCHIVO_WIM_DESTINO como un WIM normal, no pipable. Esto solo es útil si estás exportando imagen(es) a un WIM pipable pero quieres que se reconstruya como no pipable.
--wimboot
Marca la imagen de destino como compatible con WIMBoot. Además, si se exporta a un nuevo archivo, establece el tipo de compresión al recomendado para WIMBoot (actualmente, XPRESS con fragmentos de 4096 bytes).
--unsafe-compact
Compacta el WIM de destino existente en su lugar y añade cualquier dato nuevo, eliminando los "huecos". Esto es eficiente, pero en general esta opción no debe usarse porque una compactación fallida o interrumpida corromperá el archivo WIM. Para más información, consulta la documentación de esta opción para wimoptimize(1).

WIMS DIVIDIDOS

Puedes usar wimexport para exportar imágenes desde (pero no hacia) un WIM dividido. El argumento ARCHIVO_WIM_ORIGEN debe especificar la primera parte del WIM dividido, mientras que las partes adicionales del WIM dividido deben especificarse en una o más opciones --ref="GLOB". Dado que el globbing está integrado en la opción --ref, normalmente solo se necesita una opción --ref. Por ejemplo, los nombres de las partes del WIM dividido suelen ir así:

mywim.swm
mywim2.swm
mywim3.swm
mywim4.swm
mywim5.swm
Para exportar la primera imagen de este WIM dividido a un archivo WIM nuevo o
existente "other.wim", ejecuta:
wimexport mywim.swm 1 other.wim --ref="mywim*.swm"

NOTAS

Consistencia de datos: Excepto cuando se usa --unsafe-compact, es seguro abortar un comando wimexport a mitad de camino. Sin embargo, después de hacerlo, se recomienda ejecutar wimoptimize en el WIM de destino para eliminar cualquier dato que se haya añadido al archivo WIM físico pero que aún no se haya incorporado a la estructura del WIM, a menos que el WIM se estuviera reconstruyendo (por ejemplo, con --rebuild), en cuyo caso deberías eliminar el archivo temporal sobrante.

wimexport(1) - Arch Linux man pages

NAME

wimexport

export files from a WIM image

SYNOPSIS

wimexport SOURCE_WIM [--image=IMAGE] DEST_WIM [ OPTIONS... ]

wimexport SOURCE_WIM --image=IMAGE [ OPTIONS... ] DEST_WIM

DESCRIPTION

The wimexport utility exports the contents of a specified image within a WIM archive to a new WIM archive. If --image=IMAGE is not specified, then all images in the source WIM are exported, in order, to the destination WIM. The DEST_WIM file will be created if it does not exist. If it already exists, it will be overwritten.

The export process is designed to be efficient. Instead of copying all files from the source image, wimexport generates a new WIM image containing only the files that are not already present in the destination WIM. This is particularly useful when updating WIM images, as it avoids re-copying unchanged files.

OPTIONS

The following options are available:

--compress=TYPE
Specifies the compression type to use for the exported WIM image. Valid types are none, LZX, LZMS, and XPRESS. The default is LZX. For ESD files, LZMS is typically used.
--solid
Creates a solid-compressed WIM archive. In a solid WIM, all files are compressed together as a single block, which can improve compression ratio and read performance, but makes it impossible to extract individual files without processing the entire archive.
--nxs
Creates an NXS archive. This is a variant of solid WIM archives which can be streamed.
--threads=NUM
Sets the number of parallel threads to use for compression. The default is the number of logical CPU cores.

SPLIT WIMS

If the destination WIM is split into multiple files using the --split-size option (see wimlib-imagex(1)), then the exported WIM will also be split into multiple files of the same size.

NOTES

When exporting files to an existing destination WIM, wimexport checks for file content hashes to determine if a file already exists in the destination. This means that only the file contents not already present in the destination WIM will be physically copied. However, a new copy of the image's metadata resource, which describes the image's directory structure, will always be created.

ESD files: wimexport supports solid-compressed WIMs, or "ESD" (.esd) files, except for encrypted ESDs, which must be decrypted first. The source and destination files of wimexport can be solid WIMs, non-solid WIMs, or a combination thereof. If the destination file does not exist, then by default it will be created as solid if the source was solid, or as non-solid if the source was non-solid. To override this, either specify --solid to create a solid WIM (.esd file), or specify --compress=LZX to create a standard non-solid WIM (.wim file).

EXAMPLES

Export the second image of 'boot.wim' to the new WIM file 'new.wim':

wimexport boot.wim 2 new.wim

The above example creates "new.wim" with the same compression type as "boot.wim". If you wish to change the compression type, specify --compress=TYPE; for example:

wimexport boot.wim 2 new.wim --compress=LZX

Export "ESD to WIM" --- that is, solid WIM to non-solid WIM:

wimexport install.esd all install.wim --compress=LZX

Export "WIM to ESD" --- that is, non-solid WIM to solid WIM:

wimexport install.wim all install.esd --solid
