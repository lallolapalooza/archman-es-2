W3M(1) Manual de Comandos Generales W3M(1)

NOMBRE

w3m - un navegador web basado en texto y paginador

SINOPSIS

w3m [OPCIÓN]... [ archivo | URL ]...

DESCRIPCIÓN

w3m es un navegador basado en texto que puede mostrar páginas web locales o remotas, así como otros documentos. Es capaz de procesar tablas y marcos HTML, pero ignora JavaScript y Hojas de Estilo en Cascada. w3m también puede servir como paginador para archivos de texto nombrados como argumentos o pasados por la entrada estándar, y como un explorador de directorios de propósito general.

w3m organiza su contenido en búferes o pestañas, permitiendo una fácil navegación entre ellos. Con la extensión w3m-img instalada, w3m puede mostrar gráficos en línea en páginas web. Y siempre que las capacidades de renderizado HTML de w3m no satisfagan sus necesidades, la URL de destino puede ser transferida a un navegador gráfico con un solo comando.

Para obtener ayuda sobre las opciones de tiempo de ejecución, presione "H" mientras se ejecuta w3m.

ARGUMENTOS

Cuando se le dan uno o más argumentos de línea de comandos, w3m manejará los objetivos según el tipo de contenido. Para la web, w3m obtiene esta información de las cabeceras HTTP; para rutas de sistema de archivos relativas o absolutas, se basa en los nombres de archivo.

Sin argumento, w3m espera datos de la entrada estándar y asume "text/plain" a menos que el usuario proporcione otro tipo MIME.

Si se proporciona sin objetivo y sin objetivo de respaldo (ver, por ejemplo, la opción -v a continuación), w3m saldrá con información de uso.

OPCIONES

Las opciones de línea de comandos se introducen con un solo carácter “-” y pueden tomar un argumento.

Opciones generales

-B
sin otro objetivo definido, usar la página de marcadores para iniciar
-H
usar colores de alta intensidad
-M
pantalla monocromática
-no-mouse
desactivar soporte del ratón
-num
mostrar el número de cada línea
-N
distribuir múltiples argumentos de línea de comandos a pestañas. Por defecto, se utiliza una pila de búferes
-ppc num
ancho de num píxeles por carácter. Rango de 4.0 a 32.0, por defecto 8.0. Valores más grandes harán que las tablas sean más estrechas. ( Implementación no verificada)
-ppl num
altura de num píxeles por línea. Rango de 4.0 a 64.0. ( Implementación no verificada)
-title, -title=TERM
usar el nombre del búfer como cadena de título del terminal. Con TERM especificado, esto establece el estilo de configuración del título correspondientemente
-v
sin otro objetivo definido, dar la bienvenida a los usuarios con una página incorporada
-W
alternar modo de envoltura en búsquedas
-X
no inicializar/desinicializar el terminal
+num
ir a la línea num; solo efectivo para num mayor que el número de líneas en el terminal

Opciones del navegador

-cols num
con stdout como destino; HTML se renderiza a líneas de num caracteres
-cookie, -no-cookie
usar cookies almacenadas y aceptar nuevas, o no hacer ninguna de las dos cosas
-F
renderizar marcos
-graph, -no-graph
usar o no usar caracteres gráficos para dibujar bordes de tablas y marcos HTML
-header cadena
añadir cadena a la solicitud HTTP(S). Se espera que coincida con la sintaxis de cabecera Variable: Valor
-m
Renderizar el cuerpo de los mensajes de Usenet según la cabecera "Content-type"
-no-proxy
no usar proxy
-post archivo
usar método POST para subir datos definidos en archivo. La sintaxis a utilizar es var1=valor1[&var2=valor2]...
-4
Solo IPv4. Corresponde a dns_order=4 en los archivos de configuración
-6
Solo IPv6. Corresponde a dns_order=6 en los archivos de configuración
-insecure
usar opciones de configuración SSL inseguras, alias para -o ssl_cipher=ALL:eNULL:@SECLEVEL=0 -o ssl_min_version=all -o ssl_forbid_method= -o ssl_verify_server=0

Opciones del paginador de texto

-l num
número de líneas conservadas internamente al recibir texto plano desde stdin (por defecto 10.000)
-r
usar notación de careto (caret) para mostrar caracteres de escape especiales (como escapes ANSI o retrocesos estilo nroff para caracteres en negrita y subrayados) en lugar de procesarlos
-s
comprimir líneas en blanco múltiples en una sola
-t num
establecer el ancho de tabulación a num columnas. Sin efecto en stdout

Opciones de tipo de datos/codificación

-I charset
codificación de caracteres definida por el usuario de los datos de entrada
-O charset
codificación de caracteres definida por el usuario de los datos de salida
-T type
caracterización explícita de los datos de entrada por tipo MIME

Opciones para salida de datos, seguidas de salida inmediata

-dump
volcar la página renderizada a stdout. Se establece implícitamente cuando la salida se dirige a un archivo o tubería
-dump_source
volcar el código fuente de la página a stdout
-dump_head
volcar la respuesta de una solicitud HEAD para una URL a stdout
-dump_both
volcar HEAD y código fuente para una URL a stdout
-dump_extra
volcar HEAD, código fuente e información extra para una URL a stdout
-help
mostrar un resumen de las características compiladas y las opciones de línea de comandos
-show-option
mostrar todas las opciones de configuración disponibles
-version
mostrar la versión de w3m

Opciones para anular configuraciones y recursos predeterminados

-bookmark archivo
usar archivo en lugar del predeterminado

Arch Linux, Arch, Baph, ArchBang, Manjaro y las marcas relacionadas son marcas registradas de sus respectivos propietarios.

w3m.1 - Manual de w3m

NOMBRE

w3m - Navegador web y visor de documentos de texto en modo texto

SINOPSIS

w3m [OPCIONES]... [URL]

DESCRIPCIÓN

w3m es un navegador web ligero y un visor de documentos de texto que funciona en la mayoría de las terminales, incluyendo aquellas con soporte de gráficos (como xterm, rxvt, mlterm y gnome-terminal).

w3m puede mostrar HTML, texto plano, PDF (a través de un visor externo), y gráficos incrustados (si el emulador de terminal lo soporta).

ARGUMENTOS

URL
La URL o el nombre de archivo que se va a mostrar. Si no se especifica, se muestra la página de inicio.

OPCIONES

-a
Guardar la página cargada actualmente en el archivo ~/.w3m/bookmark.html
-B
Mostrar la página de marcadores.
-bc
No mostrar la barra de pestañas.
-bookmark file
Usar file en lugar del archivo de marcadores predeterminado ~/.w3m/bookmark.html
-cols number
Establecer el número de columnas de la pantalla.
-config file
Usar file en lugar del archivo de configuración predeterminado.
-cookie
Habilitar el manejo de cookies.
-cookieout file
Escribir cookies en file en lugar de ~/.w3m/cookie
-debug
Usar modo de depuración (solo para depuración).
-display display
Usar el servidor X de pantalla especificado.
-dump
Volcar el contenido de la página a stdout y salir.
-easc
Habilitar el manejo de caracteres extendidos.
-F
Mostrar la lista de enlaces de la página.
-help
Mostrar mensaje de ayuda.
-h
Mostrar mensaje de ayuda.
-I charset
Establecer el conjunto de caracteres de entrada predeterminado.
-inline
No generar código HTML en línea.
-key file
Usar file en lugar del archivo de asignación de teclas predeterminado.
-m
Habilitar el modo de correo.
-M
Habilitar el modo monocromo.
-mailcap file
Usar file en lugar del archivo de configuración de visor externo predeterminado.
-menu file
Usar file en lugar del menú predeterminado.
-mime file
Usar file en lugar del archivo de tipos MIME predeterminado.
-mouse file
Usar file en lugar de la configuración del ratón predeterminada.
-n
No seguir enlaces de la página principal.
-N
Mostrar la página principal.
-o opción=valor
Modificar un elemento de configuración con un valor dado explícitamente; sin opción=valor, es equivalente a -show-option
-O opción=valor
Establecer una opción de configuración; sin opción=valor, es equivalente a -show-option.
-option
Mostrar opciones configurables.
-post
Enviar datos usando el método POST.
-preferscreen
Preferir la salida en pantalla a la salida de archivo.
-r
Cargar la página anterior.
-reqlog
Registrar las cabeceras de la comunicación HTTP en el archivo ~/.w3m/request.log
-s
No mostrar el progreso de carga.
-T mime-type
Tratar la entrada estándar como un tipo MIME especificado.
-title
Establecer el título de la ventana.
-v
Mostrar la página de bienvenida.
-version
Mostrar información de la versión.
-W
Borrar el historial.
-w3mfile file
Usar file como marcador.

EJEMPLOS

Uso similar a un paginador

Combinar fragmentos de código HTML y previsualizar la página
$ cat header.html footer.html | w3m -T text/html
Comparar dos archivos usando pestañas
$ w3m -N config.old config

Uso similar a un navegador

Mostrar contenido web en terminal monocromática
$ w3m -M http://w3m.sourceforge.net
Mostrar gráficos incrustados
$ w3m -o auto_image=TRUE http://w3m.sourceforge.net
Mostrar contenido de Usenet
$ w3m -m nntp://news.aioe.org/comp.os.linux.networking
Subir datos para una URL usando el método POST
$ w3m -post - http://example.com/form.php <<<'a=0&b=1'

Uso similar a un filtro

Convertir un archivo HTML a texto plano con una longitud de línea definida
$ w3m -cols 40 foo.html > foo.txt
Mostrar la página de marcadores como texto con una lista de enlaces añadida
$ w3m -B -o display_link_number=1 > out.txt
Conversión de formato de archivo y codificación de caracteres
$ w3m -T text/html -I EUC-JP -O UTF-8 < foo.html > foo.txt

Iniciar sin entrada

Saludar a los usuarios con una página integrada
$ w3m -v

ENTORNO

w3m reconoce la variable de entorno WWW_HOME como definitoria de un objetivo de respaldo para usar si se invoca sin uno.

Si la variable de entorno W3M_DIR está configurada a un nombre de directorio, w3m almacenará sus archivos de usuario allí en lugar de en el directorio ~/.w3m.

ARCHIVOS

Las ubicaciones predeterminadas de algunos archivos se enumeran a continuación. Estas ubicaciones pueden ser alteradas a través de la variable de entorno W3M_DIR.

~/.w3m/bookmark.html
archivo de marcadores predeterminado
~/.w3m/config
archivo de configuración definido por el usuario; anula /etc/w3m/config
~/.w3m/cookie
caja de galletas; escrita al salir, leída al iniciar
~/.w3m/history
historial del navegador - archivos y URLs visitados
~/.w3m/keymap
asignaciones de teclas definidas por el usuario; anula las asignaciones de teclas predeterminadas
~/.w3m/mailcap
archivo de configuración de visor externo
~/.w3m/menu
menú definido por el usuario; anula el menú predeterminado
~/.w3m/mime.types
archivo de tipos MIME
~/.w3m/mouse
configuración del ratón definida por el usuario
~/.w3m/passwd
archivo de contraseña y nombre de usuario
~/.w3m/pre_form
contiene valores predefinidos para rellenar formularios HTML recurrentes
