wcswidth(3) Manual de funciones de biblioteca wcswidth(3)

NOMBRE

wcswidth - determinar las columnas necesarias para una cadena de caracteres anchos de tamaño fijo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _XOPEN_SOURCE             /* Ver feature_test_macros(7) */
#include <wchar.h>
int wcswidth(const wchar_t *s, size_t n);

DESCRIPCIÓN

La función wcswidth() devuelve el número de columnas necesarias para representar la cadena de caracteres anchos apuntada por s, pero como máximo n caracteres anchos. Si ocurre un carácter ancho no imprimible entre estos caracteres, se devuelve -1.

VALOR DE RETORNO

La función wcswidth() devuelve el número de posiciones de columna para la cadena de caracteres anchos s, truncado a una longitud máxima de n.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
wcswidth () Seguridad de hilos MT-Safe locale

ESTANDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

NOTAS

El comportamiento de wcswidth() depende de la categoría LC_CTYPE de la configuración regional actual.

VER TAMBIÉN

iswprint(3), wcwidth(3)
