NOMBRE

waybar - módulo pulseaudio

DESCRIPCIÓN

El módulo pulseaudio muestra el volumen actual reportado por PulseAudio.

Adicionalmente, puedes controlar el volumen desplazando la rueda del ratón hacia arriba o hacia abajo mientras el cursor está sobre el módulo.

CONFIGURACIÓN

format:
tipo: string
por defecto: {volume}%
El formato, cómo se debe mostrar la información. Este formato se utiliza cuando no se especifican otros formatos.

format-bluetooth:
tipo: string
Este formato se utiliza cuando se usan altavoces bluetooth.

format-muted:
tipo: string
Este formato se utiliza cuando el sonido está silenciado.

format-source:
tipo: string
por defecto: {volume}%
Este formato se usa para la fuente (micrófono).

format-source-muted:
tipo: string
Este formato se utiliza cuando la fuente está silenciada.

format-icons:
tipo: array
Basado en el nombre del puerto actual y el volumen, se selecciona el icono correspondiente. El orden es de bajo a alto. Ver Iconos.

rotate:
tipo: integer
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

states:
tipo: object
Una serie de estados de volumen que se activan en ciertos niveles de volumen. Ver waybar-states(5).

max-length:
tipo: integer
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
tipo: integer
La longitud mínima en caracteres que el módulo debe aceptar.

align:
tipo: float
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: string
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir la posición.

scroll-step:
tipo: float
por defecto: 1.0
La velocidad a la que se cambia el volumen al desplazarse con la rueda.

on-click:
tipo: string
Comando a ejecutar al hacer clic en el módulo.

on-click-middle:
tipo: string
Comando a ejecutar al hacer clic con la rueda del ratón en el módulo.

on-click-right:
tipo: string
Comando a ejecutar al hacer clic derecho en el módulo.

on-update:
tipo: string
Comando a ejecutar cuando el módulo se actualiza.

on-scroll-up:
tipo: string
Comando a ejecutar al desplazarse hacia arriba en el módulo. Esto reemplaza el comportamiento predeterminado de control de volumen.

on-scroll-down:
tipo: string
Comando a ejecutar al desplazarse hacia abajo en el módulo. Esto reemplaza el comportamiento predeterminado de control de volumen.

smooth-scrolling-threshold:
tipo: double
Umbral a usar al desplazarse con la rueda.

reverse-scrolling:
tipo: bool
Opción para invertir la dirección de desplazamiento.

tooltip:
tipo: bool
por defecto: true
Opción para deshabilitar la información emergente al pasar el ratón.

max-volume:
tipo: integer
por defecto: 100
El volumen máximo que se puede establecer, en porcentaje.

ignored-sinks:
tipo: array
Los sinks en esta lista no serán mostrados como sinks activos por Waybar. Las entradas deben ser el campo de descripción del sink.

menu:
tipo: string
Acción que muestra el menú emergente.

menu-file:
tipo: string
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: bool
por defecto: false
Permite que este módulo consuma dinámicamente todo el espacio sobrante.

REEMPLAZOS DE FORMATO

{desc}: Descripción del puerto de PulseAudio, para bluetooth será el nombre del dispositivo.

{volume}: Volumen en porcentaje.

{icon}: Icono, tal como se define en format-icons.

{format_source}: Formato de fuente, format-source, format-source-muted.

ICONOS:

Las siguientes cadenas para format-icons son compatibles.

•
el nombre del dispositivo

Si se encuentran en el nombre del puerto actual de PulseAudio, se seleccionarán los iconos correspondientes.

  • default (Mostrado cuando no se encuentra otro puerto)
  • headphone (auriculares)
  • speaker (altavoz)
  • hdmi
  • headset (auriculares con micrófono)
  • hands-free (manos libres)
  • portable (portátil)
  • car (coche)
  • hifi
  • phone (teléfono)

Adicionalmente, añadir el sufijo -muted a un nombre de dispositivo o puerto hará que el icono se seleccione cuando el dispositivo de audio correspondiente esté silenciado. Esto también se aplica a default.
