wint_t(3type) wint_t(3type)

NOMBRE

wint_t, WEOF - tipo entero capaz de almacenar cualquier wchar_t o WEOF

BIBLIOTECA

Biblioteca estándar de C (libc)

SINOPSIS

#include <wchar.h>
typedef /* ... */  wint_t;
#define WEOF        /* ... */
#include <stdint.h>
#define WINT_WIDTH  /* ... */
#define WINT_MAX    /* ... */
#define WINT_MIN    /* ... */

DESCRIPCIÓN

wint_t es un tipo utilizado en funciones que trabajan con caracteres anchos. Es capaz de almacenar cualquier wchar_t válido o WEOF. Es un tipo entero.

WEOF es utilizado por las funciones de caracteres anchos para indicar el final de un archivo de entrada o un error. Es de tipo wint_t.

ESTÁNDARES

C11, POSIX.1-2024.

HISTORIA

C99, POSIX.1-2001.

La macro WINT_WIDTH se añadió en C23.

NOTAS

La siguiente cabecera también proporciona wint_t y WEOF: <wctype.h>.

VER TAMBIÉN

wchar_t(3type), fputwc(3)
