NOMBRE

wol - Cliente Wake On LAN

SINOPSIS

wol [OPCIÓN] ... DIRECCIÓN-MAC ...

DESCRIPCIÓN

Este manual le introduce a "wol", el cliente Wake On LAN. Enciende remotamente computadoras que soportan la tecnología Magic Packet (también conocida como Wake On LAN).

Algunas estaciones de trabajo soportan la función de contraseña SecureON. Estas máquinas solo se encienden si se proporciona la contraseña correcta. "wol" también proporciona esta función.

OPCIONES

--help
Imprime un resumen de las opciones de la línea de comandos.
-V
--version
Imprime el número de versión de "wol".
-h HOST
--host=HOST
-i HOST
--ipaddr=HOST
Envía un paquete de difusión a esta dirección IP o nombre de host. Esto es importante si su cliente wol es un host multihomed y desea enviar solo a una subred (la dirección IP predeterminada es 255.255.255.255).
-p NUM
--port=NUM
Envía un paquete con este puerto de destino NUM. Esta opción es importante si su filtro de paquetes bloqueara el puerto de destino predeterminado 40000.
-f ARCHIVO
--file=ARCHIVO
Lee direcciones de hardware, direcciones IP/nombres de host, puertos opcionales y contraseña SecureON del archivo ARCHIVO. Si ARCHIVO es -, "wol" lee desde la entrada estándar.
-
Lee direcciones de hardware, direcciones IP, puertos opcionales y contraseña SecureON opcional desde la entrada estándar. Así puede extraer DIRECCIONES-MAC de cualquier fuente y canalizar los datos a "wol".
-v
--verbose
Activa la salida detallada.
-w NUM
--wait=NUM
Espera NUM milisegundos entre Magic Packets. También conocido como paquete de salud de fusible.
--passwd[=PASS]
Envía un paquete mágico con la función de contraseña SecureON. PASS se escribe como x-x-x-x-x-x, donde x es un número hexadecimal entre 0 y ff que representa un byte de la contraseña.

Si no proporciona PASS, "wol" le solicitará una contraseña.

Para configurar la contraseña de su NIC compatible con SecureON, puede usar "ethtool" (http://www.sourceforge.net/projects/gkernel/).
