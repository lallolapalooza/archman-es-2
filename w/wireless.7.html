NOMBRE

wireless - Herramientas inalámbricas y Extensiones Inalámbricas

SINOPSIS

iwconfig
iwpriv -a

DESCRIPCIÓN

Las Extensiones Inalámbricas son una API que permite manipular las interfaces de red LAN inalámbrica. Se compone de una variedad de herramientas y archivos de configuración. Se documenta con más detalle en el HOWTO de LAN Inalámbrica de Linux.
Las Herramientas Inalámbricas se utilizan para cambiar la configuración de las interfaces de red LAN inalámbrica sobre la marcha, para obtener su configuración actual, para obtener estadísticas y diagnosticarlas. Se describen en su propia página man, vea más abajo para referencias.
La configuración inalámbrica es específica de cada distribución de Linux. Esta página man contendrá en el futuro el procedimiento de configuración para algunas distribuciones comunes. Por ahora, consulte el archivo DISTRIBUTIONS.txt incluido con el paquete de Herramientas Inalámbricas.

DEBIAN 3.0

En Debian 3.0 (y posteriores), puede configurar dispositivos de red LAN inalámbrica utilizando la herramienta de configuración de red ifupdown(8).

Archivo :
/etc/network/interfaces
Formato :
wireless-<función> <valor>
wireless-essid Home
wireless-mode Ad-Hoc
Ver también :
/etc/network/if-pre-up.d/wireless-tools
/usr/share/doc/wireless-tools/README.Debian

SuSE 8.0

SuSE 8.0 (y posteriores) ha integrado la configuración inalámbrica en sus scripts de red.

Herramienta :
Yast2
Archivo :
/etc/sysconfig/network/wireless
/etc/sysconfig/network/ifcfg-*
Formato :
WIRELESS_<función>=<valor>
WIRELESS_ESSID="Home"
WIRELESS_MODE=Ad-Hoc
Ver también :
man ifup
info scpm

SCRIPTS ORIGINALES PCMCIA

Si está utilizando los scripts de configuración originales del paquete Pcmcia, puede usar este método.

Archivo :
/etc/pcmcia/wireless.opts
Formato :
*,*,*,*)
ESSID="Home"
MODE="Ad-Hoc"
;;
Ver también :
/etc/pcmcia/wireless
Archivo PCMCIA.txt parte del paquete Wireless Tools
