WCSNCASECMP(3P) Manual del programador POSIX WCSNCASECMP(3P)

PROLOG

Esta página del manual es parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

wcsncasecmp, wcsncasecmp_l — comparación de cadenas de caracteres anchos sin distinción entre mayúsculas y minúsculas

SINOPSIS

#include <wchar.h>
int wcsncasecmp(const wchar_t *ws1, const wchar_t *ws2, size_t n);
int wcsncasecmp_l(const wchar_t *ws1, const wchar_t *ws2,
    size_t n, locale_t locale);

DESCRIPCIÓN

Consulte wcscasecmp().
