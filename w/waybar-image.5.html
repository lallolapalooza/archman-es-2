waybar-image(5) Manual de Formatos de Archivo waybar-image(5)

NOMBRE

waybar - módulo de imagen

DESCRIPCIÓN

El módulo image muestra una imagen desde una ruta.

CONFIGURACIÓN

path:
tipo: cadena
La ruta a la imagen.

exec:
tipo: cadena
La ruta al script, que debería devolver la ruta del archivo de imagen.
Solo se ejecutará si la ruta no está configurada.

size:
tipo: entero
El ancho/alto para renderizar la imagen.

interval:
tipo: entero
El intervalo (en segundos) para volver a renderizar la imagen.
Esto es útil si los contenidos de path cambian.
Si no se define ningún interval, la imagen solo se renderizará una vez.

signal:
tipo: entero
El número de señal utilizado para actualizar el módulo.
Esto se puede usar en lugar de interval si el archivo cambia de forma irregular.
El número es válido entre 1 y N, donde SIGRTMIN+N = SIGRTMAX.

on-click:
tipo: cadena
Comando a ejecutar cuando se hace clic en el módulo.

on-click-middle:
tipo: cadena
Comando a ejecutar cuando se hace clic con la rueda del ratón en el módulo.

on-update:
tipo: cadena
Comando a ejecutar cuando se actualiza el módulo.

on-scroll-up:
tipo: cadena
Comando a ejecutar al desplazarse hacia arriba en el módulo.

on-scroll-down:
tipo: cadena
Comando a ejecutar al desplazarse hacia abajo en el módulo.

smooth-scrolling-threshold:
tipo: doble
Umbral a utilizar al desplazarse.

tooltip:
tipo: booleano
por defecto: true
Opción para habilitar la información sobre herramientas al pasar el ratón.

expand:
tipo: booleano
por defecto: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

SALIDA DEL SCRIPT

Similar al módulo custom, los valores de salida del script están separados por saltos de línea. El siguiente es el formato de salida:

$ruta\n$tooltip

EJEMPLOS

"image#album-art": {
	"path": "/tmp/mpd_art",
	"size": 32,
	"interval": 5,
	"on-click": "mpc toggle"
}
