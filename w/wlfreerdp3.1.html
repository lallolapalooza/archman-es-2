NOMBRE

wlfreerdp - cliente wayland de FreeRDP

SINOPSIS

wlfreerdp [archivo] [opciones_cliente_predeterminadas] [/v:<servidor>[:puerto]] [/version] [/help]

DESCRIPCIÓN

wlfreerdp es un cliente de protocolo de escritorio remoto (RDP) para wayland que forma parte del proyecto FreeRDP. Un servidor RDP está integrado en muchas ediciones de Windows. Servidores alternativos incluidos son ogon, gnome-remote-desktop, xrdp y VRDP (VirtualBox).

OPCIONES

El cliente wayland también admite muchas de las opciones_cliente_predeterminadas que no se describen aquí. Para obtener detalles sobre ellas, consulte la página del manual xfreerdp(1).

/v:<servidor>[:puerto]
El nombre de host o IP del servidor, y opcionalmente el puerto, al que conectarse.
/version
Imprime la versión y sale.
/help
Imprime la ayuda y sale.

ESTADO DE SALIDA

0
Ejecución exitosa del programa.
no 0
En caso de fallo.
