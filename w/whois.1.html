WHOIS(1) Debian GNU/Linux WHOIS(1)

NOMBRE

whois - cliente para el servicio de directorio whois

SINOPSIS

whois [ { -h | --host } HOST ] [ { -p | --port } PUERTO ] [ -abBcdGHIKlLmMrRx ] [ -g FUENTE:PRIMERO-ULTIMO ] [ -i ATTR[,ATTR]... ] [ -s FUENTE[,FUENTE]... ] [ -T TIPO[,TIPO]... ] [ --verbose ] [ --no-recursion ] OBJETO

whois -q PALABRA_CLAVE

whois -t TIPO

whois -v TIPO

whois --help

whois --version

DESCRIPCIÓN

whois busca un objeto en una base de datos RFC 3912.

Esta versión del cliente whois intenta adivinar el servidor correcto al que preguntar por el objeto especificado. Si no se puede hacer una suposición, se conectará a whois.networksolutions.com para identificadores NIC o whois.arin.net para direcciones IPv4 y nombres de red.

OPCIONES

-h
HOST, --host=HOST Conéctate a HOST.
-H
No muestres los descargos de responsabilidad legales que algunos registros suelen mostrar.
-p
PUERTO, --port=PUERTO Conéctate a PUERTO.
-I
Primero consulta whois.iana.org y luego sigue su referencia al servidor whois autoritativo para esa solicitud. Esto funciona para direcciones IP, números AS y dominios. TEN CUIDADO: esto implica que el servidor IANA recibirá tu consulta completa.
--no-recursion
Deshabilita la recursión de los servidores de registro a los de registrante.
--verbose
Sé verboso.
--help
Muestra la ayuda en línea.
--version
Muestra la versión del programa.

Otras opciones son indicadores entendidos por whois.ripe.net y algunos otros servidores tipo RIPE:

-a
También busca en todas las bases de datos duplicadas.
-b
Devuelve rangos breves de direcciones IP con contacto de abuso.
-B
Deshabilita el filtrado de objetos. (Muestra las direcciones de correo electrónico).
-c
Devuelve el rango de direcciones IP más pequeño con una referencia a un objeto irt.
-d
Devuelve también el objeto de delegación DNS inverso.
-g
FUENTE:PRIMERO-ULTIMO Busca actualizaciones de la base de datos FUENTE entre el número de serie de actualización PRIMERO y ULTIMO. Es útil para obtener un flujo de espejo casi en tiempo real.
-G
Deshabilita la agrupación de objetos asociados.
-i
ATTR[,ATTR]... Busca inversamente objetos que tienen atributos asociados. ATTR es el nombre del atributo, mientras que el argumento posicional OBJETO es el valor del atributo.
-K
Devuelve solo los atributos de clave primaria. Una excepción es el atributo members de los objetos set, que siempre se devuelve. Otra excepción son todos los atributos de los objetos organisation, person y role, que nunca se devuelven.
-l
Devuelve el objeto menos específico en un nivel.
-L
Devuelve todos los niveles de objetos menos específicos.
-m
Devuelve todos los objetos más específicos en un nivel.
-M
Devuelve todos los niveles de objetos más específicos.
-q
PALABRA_CLAVE Devuelve información sobre el servidor. PALABRA_CLAVE puede ser version para la versión del servidor, sources para la lista de fuentes de bases de datos o types para la lista de tipos de objetos compatibles.
-r
Deshabilita las búsquedas recursivas de información de contacto.
-R
Deshabilita el seguimiento de referencias y fuerza la muestra del objeto desde la copia local en el servidor.
-s
FUENTE[,FUENTE]... Solicita al servidor que busque objetos duplicados de FUENTE. Las fuentes se delimitan por comas y el orden es significativo. Usa el parámetro -q sources para obtener una lista de fuentes válidas.
-t
TIPO Devuelve la plantilla para un objeto de TIPO.
-T
TIPO[,TIPO]... Restringe la búsqueda a objetos de TIPO. Se separan varios tipos por comas.
-v
TIPO Devuelve la plantilla detallada para un objeto de TIPO.
-x
Busca solo coincidencias exactas en el prefijo de la dirección de red.

NOTAS

Al consultar los servidores del registro fino de los gTLD de Verisign (por ejemplo, .com, .net...) para un dominio, el programa antepondrá automáticamente la palabra clave domain para mostrar solo los registros de dominio. Las palabras clave nameserver o registrar deben usarse para mostrar otros tipos de registros.

Al consultar whois.arin.net para redes IPv4 o IPv6, la longitud de la máscara de red CIDR se eliminará automáticamente de la cadena de consulta.

Al consultar whois.nic.ad.jp para números AS, el programa convertirá automáticamente la solicitud al formato apropiado, insertando un espacio después de la cadena AS.

Al consultar whois.denic.de para nombres de dominio y no se han especificado otras opciones, el programa agregará automáticamente la opción -T dn.

Al consultar whois.dk-hostmaster.dk para nombres de dominio y no se han especificado otras opciones, el programa agregará automáticamente la opción --show-handles.

Las opciones de línea de comandos específicas de RIPE se ignoran al consultar servidores no RIPE. Esto puede ser o no el comportamiento deseado por el usuario. Al usar parámetros de consulta no estándar, las opciones de línea de comandos que no deben ser interpretadas por el cliente deben seguir el separador -- (que marca el inicio de la cadena de consulta).

Si existe el archivo de configuración /etc/whois.conf, se consultará para encontrar un servidor antes de aplicar las reglas normales. Cada línea del archivo debe contener una expresión regular que coincida con el texto de la consulta y el servidor whois a usar, separados por espacios en blanco. Los dominios IDN deben usar el formato ACE.

El protocolo whois no especifica una codificación para los caracteres que no se pueden representar en ASCII y las implementaciones varían enormemente. Si el programa sabe que un servidor específico usa una codificación determinada, si es necesario, transcodificará la salida del servidor a la codificación especificada por la configuración regional actual del sistema.

Los argumentos de la línea de comandos siempre se interpretarán de acuerdo con la configuración regional actual del sistema y se convertirán a la Codificación Compatible con ASCII de IDN.

ENTORNO

LANG
Al consultar whois.nic.ad.jp y whois.jprs.jp se solicita texto en inglés a menos que las variables de entorno LANG o LC_MESSAGES especifiquen una configuración regional japonesa.
WHOIS_OPTIONS
Esta variable de entorno puede ser usada para establecer opciones por defecto. Las opciones deben estar separadas por espacios en blanco. Por ejemplo,
export WHOIS_OPTIONS="-p 43 -h whois.nic.uk".
