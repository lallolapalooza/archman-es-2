waybar-custom(5) Manual de formatos de archivo waybar-custom(5)

NOMBRE

waybar - módulo personalizado

DESCRIPCIÓN

El módulo custom muestra la salida de un script o texto estático. Para mostrar texto estático, especifique solo el campo format.

CONFIGURACIÓN

Abordado por custom/<nombre>

exec:
tipo: string
La ruta al script que debe ejecutarse.

exec-if:
tipo: string
La ruta a un script que determina si el script en exec debe ejecutarse.
Se ejecutará exec si el código de salida de exec-if es igual a 0.

hide-empty-text:
tipo: bool
Deshabilita el módulo cuando la salida está vacía, pero el formato puede contener contenido estático adicional.

exec-on-event:
tipo: bool
predeterminado: true
Si se establece un comando de evento (por ejemplo, on-click o on-scroll-up), se volverá a ejecutar el script después de ejecutar el comando del evento.

return-type:
tipo: string
Ver return-type

interval:
tipo: integer
El intervalo (en segundos) en el que se encuestan las informaciones.
Use once si desea ejecutar el módulo solo al inicio.
Puede actualizarlo manualmente con una señal. Si no se define interval ni signal, se asume que el script de salida se ejecuta en bucle.
Si se define una signal, el script se ejecutará una vez al inicio y solo se actualizará con una señal.

restart-interval:
tipo: integer
El intervalo de reinicio (en segundos).
No se puede usar con la opción interval, por lo que solo con scripts continuos.
Una vez que el script finaliza, se volverá a ejecutar después del restart-interval.

signal:
tipo: integer
El número de señal utilizado para actualizar el módulo.
El número es válido entre 1 y N, donde SIGRTMIN+N = SIGRTMAX.
Si no se define ningún intervalo, una señal será la única forma de actualizar el módulo.

format:
tipo: string
predeterminado: {text}
El formato, cómo se deben mostrar las informaciones. En {text} se insertan los datos.

format-icons:
tipo: array
Basado en el porcentaje establecido, se selecciona el icono correspondiente. El orden es de bajo a alto.

rotate:
tipo: integer
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

max-length:
tipo: integer
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
tipo: integer
La longitud mínima en caracteres que el módulo debe aceptar.

align:
tipo: float
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: string
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir el posicionamiento.

on-click:
tipo: string
Comando a ejecutar al hacer clic en el módulo.

on-click-middle:
tipo: string
Comando a ejecutar al hacer clic con el botón central del ratón en el módulo.

on-click-right:
tipo: string
Comando a ejecutar al hacer clic derecho en el módulo.

on-update:
tipo: string
Comando a ejecutar cuando se actualiza el módulo.

on-scroll-up:
tipo: string
Comando a ejecutar al desplazarse hacia arriba en el módulo.

on-scroll-down:
tipo: string
Comando a ejecutar al desplazarse hacia abajo en el módulo.

smooth-scrolling-threshold:
tipo: double
Umbral a utilizar al desplazarse.

tooltip:
tipo: bool
predeterminado: true
Opción para deshabilitar el tooltip al pasar el ratón por encima.

tooltip-format:
tipo: string
El formato del tooltip. Si se especifica, anula cualquier salida de tooltip del script en exec.
Utiliza los mismos reemplazos de formato que format.

escape:
tipo: bool
predeterminado: false
Opción para habilitar el escape de la salida del script.

menu:
tipo: string
Acción que muestra el menú emergente.

menu-file:
tipo: string
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: bool
predeterminado: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

TIPO DE RETORNO

Cuando return-type se establece en json, Waybar espera que el script exec devuelva sus datos en formato JSON. Debería verse así:

{"text": "$texto", "tooltip": "$tooltip", "class": "$class", "percentage": $porcentaje }

El parámetro class también acepta una matriz de cadenas.

Si no se especifica nada o una opción inválida, Waybar espera la salida estilo i3blocks. Los valores están separados por salto de línea. Debería verse así:

$texto
$tooltip
$class*

class es una clase CSS, para aplicar diferentes estilos en style.css

REEMPLAZOS DE FORMATO

{text}: Salida del script.

{percentage} Porcentaje que se puede establecer a través de un tipo de retorno json.

{icon}: Un icono de 'format-icons' según el porcentaje.

EJEMPLOS

Spotify:

"custom/spotify": {
	"format": " {text}",
	"max-length": 40,
	"interval": 30, // Eliminar esto si tu script es interminable y escribe en bucle
	"exec": "$HOME/.config/waybar/mediaplayer.sh 2> /dev/null", // Script en la carpeta de recursos
	"exec-if": "pgrep spotify",
	"return-type": "json"
}

mpd:

"custom/mpd": {
	"format": "♪ {text}",
	//"max-length": 15,
	"interval": 10,
	"exec": "mpc current",
	"exec-if": "pgrep mpd",
	"on-click": "mpc toggle",
	"on-click-right": "sonata"
}

cmus:

"custom/cmus": {
	"format": "♪ {text}",
	//"max-length": 15,
	"interval": 10,
	"exec": "cmus-remote -C "format_print '%a - %t'"", // artista - título
	"exec-if": "pgrep cmus",
	"on-click": "cmus-remote -u",                        //alternar pausa
	"escape": true                                       //manejar entidades de marcado
}

Pacman

"custom/pacman": {
	"format": "{text}  ",
	"interval": "once",
	"exec": "pacman_packages",
	"on-click": "update-system",
	"signal": 8
}

Pacman Alternativo

"custom/pacman": {
	"format": "{text}  ",
	"interval": 3600,                     // cada hora
	"exec": "checkupdates | wc -l",       // # de actualizaciones
	"exec-if": "exit 0",                  // ejecutar siempre; considerar condiciones de ejecución avanzadas
	"on-click": "termite -e 'sudo pacman -Syu'; pkill -SIGRTMIN+8
{
	"method": "signal",
	"signal": 8
}
```

Puedes usar la señal y actualizar el número de paquetes disponibles con pkill -RTMIN+8 waybar.

ESTILO

  • #custom-<nombre>
  • #custom-<nombre>.<clase>
  • <clase> puede ser establecida por el script. Para más información, consulta tipo-retorno
