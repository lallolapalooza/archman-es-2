wofi-widget-builder(3) Manual de funciones de biblioteca wofi-widget-builder(3)

NOMBRE

wofi - Funciones de la API del constructor de widgets

DESCRIPCIÓN

Las funciones documentadas aquí se utilizan para construir widgets personalizados con más potencia y flexibilidad de las que se permitían anteriormente. Se definen en wofi_widget_builder_api.h

struct widget_builder* wofi_widget_builder_init(struct mode* mode, size_t actions)
Crea múltiples constructores de widgets. El número de constructores creados se especifica mediante actions y se devuelve como una matriz.

struct mode* mode - El struct mode* dado a la función init() de tu modo.

size_t actions - El número de constructores a crear

void wofi_widget_builder_set_search_text(struct widget_builder* builder, char* search_text)
Establece el texto de búsqueda para el widget especificado por el constructor

struct widget_builder* builder - El constructor que contiene el widget para el que se establecerá el texto de búsqueda

char* search_text - El texto que se establecerá como texto de búsqueda

void wofi_widget_builder_set_action(struct widget_builder* builder, char* action)
Establece la acción para el widget especificado por el constructor

struct widget_builder* builder - El constructor que contiene el widget para el que se establecerá la acción

char* action - El texto que se establecerá como acción

void wofi_widget_builder_insert_text(struct widget_builder* builder, char* text, ...)
Inserta texto en el widget especificado por el constructor

struct widget_builder* builder - El constructor que contiene el widget al que se añadirá el texto

char* text - El texto que se añadirá al widget

... - Los nombres de las clases CSS para este texto. La clase que se asignará es .nombre_modo-nombre_css donde nombre_modo es el nombre del modo, es decir, drun, etc. Esto debe tener un terminador NULL

void wofi_widget_builder_insert_text_with_list(struct widget_builder* builder, char* text, struct wl_list* classes)
Inserta texto en el widget especificado por el constructor

struct widget_builder* builder - El constructor que contiene el widget al que se añadirá el texto

char* text - El texto que se añadirá al widget

struct wl_list* classes - Los nombres de las clases CSS para este texto. La clase que se asignará es .nombre_modo-nombre_css donde nombre_modo es el nombre del modo, es decir, drun, etc. Esta lista debe contener nodos de tipo struct css_class.

void wofi_widget_builder_insert_image(struct widget_builder* builder, GdkPixbuf* pixbuf, ...)
Inserta una imagen en el widget especificado por el constructor

struct widget_builder* builder - El constructor que contiene el widget al que se añadirá la imagen

GdkPixbuf* pixbuf - La imagen que se añadirá al widget

... - Los nombres de las clases CSS para esta imagen. La clase que se asignará es .nombre_modo-nombre_css donde nombre_modo es el nombre del modo, es decir, drun, etc. Esto debe tener un terminador NULL

void wofi_widget_builder_insert_image_with_list(struct widget_builder* builder, GdkPixbuf* pixbuf, struct wl_list* classes)
Inserta una imagen en el widget especificado por el constructor

struct widget_builder* builder - El constructor que contiene el widget al que se añadirá la imagen

GdkPixbuf* pixbuf - La imagen que se añadirá al widget

struct wl_list* classes - Los nombres de las clases CSS para esta imagen. La clase que se asignará es .nombre_modo-nombre_css donde nombre_modo es el nombre del modo, es decir, drun, etc. Esta lista debe contener nodos de tipo struct css_class.

struct widget_builder* wofi_widget_builder_get_idx(struct widget_builder* builder, size_t idx)
Obtiene el widget_builder en el índice proporcionado de la matriz

struct widget_builder* builder - La matriz de constructores de la que se obtendrá el constructor

size_t idx - El índice en la matriz a obtener

struct widget* wofi_widget_builder_get_widget(struct widget_builder* builder)
Construye un nuevo widget a partir del constructor especificado, el widget puede ser devuelto por struct widget* get_widget(void)

struct widget_builder* builder - El constructor para el que se construirá un widget

void wofi_widget_builder_free(struct widget_builder* builder)
Libera el constructor especificado

struct widget_builder* builder - El constructor a liberar
