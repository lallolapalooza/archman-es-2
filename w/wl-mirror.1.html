wl-mirror(1) Manual de Comandos Generales wl-mirror(1)

NOMBRE

wl-mirror - un cliente simple de espejo de salida de Wayland

SINOPSIS

wl-mirror [-h,-V,-v,-c,-i,-f,-s S,-b B,-t T,-r R,-S] <salida>

OPCIONES

-h, --help

Muestra el mensaje de ayuda y sale.

-V, --version

Muestra la información de la versión y sale.

-v, --verbose --no-verbose

Habilita o deshabilita el registro de depuración.

-c, --show-cursor --no-show-cursor

Muestra el cursor en la superficie reflejada (habilitado por defecto).

-i, --invert-colors --no-invert-colors

Invierte los colores en la superficie reflejada.

-f, --freeze --unfreeze --toggle-freeze

Congela, desconcongela o alterna la congelación de la imagen actual en la pantalla.

-F, --fullscreen

Abre como una ventana a pantalla completa, o pon la ventana actual a pantalla completa en modo de transmisión.

--no-fullscreen

Abre como una ventana normal (habilitado por defecto), o sal de pantalla completa en modo de transmisión.

--fullscreen-output O

Establece una salida diferente a pantalla completa (por defecto es la salida actual), implica --fullscreen.

--no-fullscreen-output

Restablece la salida de pantalla completa de destino a la salida de la ventana actual, implica --no-fullscreen.

-s f, --scaling fit

Escala para ajustar y si es necesario añade letterboxing (habilitado por defecto).

-s c, --scaling cover

Escala para cubrir y si es necesario recorta la imagen.

-s e, --scaling exact

Usa escalado de múltiplo exacto y si es necesario añade letterboxing.

-s l, --scaling linear

Usa escalado lineal (habilitado por defecto).

-s n, --scaling nearest

Usa escalado de vecino más cercano.

-b B, --backend B

Usa un backend específico de captura de pantalla, ver BACKENDS.

-t T, --transform T

Aplica una transformación personalizada (rotación y volteo), ver TRANSFORMS.

-r R, --region R

Captura una región de pantalla personalizada R, ver REGIONS.

-S, --stream

Acepta un flujo de opciones adicionales en stdin, ver STREAM MODE.

--title T

Especifica un título T personalizado para la ventana del espejo. Este título puede contener marcadores de posición, ver TITLE PLACEHOLDERS

BACKENDS

auto

Intenta automáticamente los backends en orden de eficiencia y utiliza el primero que funcione (habilitado por defecto). El siguiente backend se selecciona automáticamente cuando el backend actual no puede capturar un fotograma 10 veces seguidas.

El orden de recuperación actual es:

  • extcopy-dmabuf (si se compiló con libGBM)
  • screencopy-dmabuf (si se compiló con libGBM)
  • export-dmabuf
  • extcopy-shm
  • screencopy-shm

export-dmabuf

Utiliza el protocolo wlr-export-dmabuf-unstable-v1 para capturar salidas (requiere wlroots). Este backend mantiene los datos de imagen en la GPU y no necesita copias costosas a la CPU y viceversa.

screencopy-dmabuf

Utiliza el protocolo wlr-screencopy-unstable-v1 para capturar salidas (requiere wlroots). Este backend mantiene los datos de imagen en la GPU y no necesita copias costosas a la CPU y viceversa. Este backend requiere que wl-mirror se compile con soporte para asignar DMA-BUFs usando libGBM.

screencopy-shm

Utiliza el protocolo wlr-screencopy-unstable-v1 para capturar salidas (requiere wlroots). Este backend pasa los datos de imagen a través de memoria compartida en la CPU, pero puede tener una mejor compatibilidad con configuraciones complejas de controladores de GPU (por ejemplo, multi-GPU).

screencopy

Intenta automáticamente screencopy-dmabuf o screencopy-shm y utiliza el primero que funcione. La recuperación funciona igual que con auto.

extcopy-dmabuf

Utiliza el protocolo ext-image-copy-capture-v1 para capturar salidas. Este backend mantiene los datos de imagen en la GPU y no necesita copias costosas a la CPU y viceversa. Este backend requiere que wl-mirror se compile con soporte para asignar DMA-BUFs usando libGBM.

extcopy-shm

Utiliza el protocolo ext-image-copy-capture-v1 para capturar salidas. Este backend pasa los datos de imagen a través de memoria compartida en la CPU, pero puede tener una mejor compatibilidad con configuraciones complejas de controladores de GPU (por ejemplo, multi-GPU).

extcopy

Intenta automáticamente extcopy-dmabuf o extcopy-shm y utiliza el primero que funcione. La recuperación funciona igual que con auto.

TRANSFORMACIONES

Las transformaciones se especifican como una lista separada por guiones de volteos seguidos de una cantidad de rotación. Los volteos se aplican antes que las rotaciones, tanto los volteos como las rotaciones son opcionales. Las transformaciones personalizadas se aplican después de ajustarlas a la transformación de salida de Wayland, de modo que si no se aplican transformaciones personalizadas, la superficie reflejada se muestra al derecho.

normal

Sin transformación (transformación por defecto).

flipX, flipY

Voltea la coordenada X o Y de la imagen, es decir, flipX significa que la superficie reflejada tiene el lado izquierdo y derecho intercambiados.

0cw, 90cw, 180cw, 270cw

Aplica una rotación en sentido horario.

0ccw, 90ccw, 180ccw, 270ccw

Aplica una rotación en sentido antihorario.

Las siguientes opciones de transformación se proporcionan para compatibilidad con las transformaciones de sway-output(5):

flipped

Igual que flipX.

0, 90, 180, 270

Igual que 0cw, 90cw, 180cw, 270cw.

REGIONES

Las regiones se especifican en el formato utilizado por la utilidad slurp(1):

'x,y anchoxalto [salida]'

En la sintaxis de slurp(1), esto se especificaría de la siguiente manera (la última parte con %o es opcional):

'%x,%y %wx%h %o'

Al procesar la opción de región, la región se traduce a coordenadas de salida, por lo que cuando la salida se mueve, la región capturada se mueve con ella. Cuando se especifica una región, el argumento posicional salida es opcional.

MODO DE TRANSMISIÓN

En modo de transmisión, wl-mirror interpreta las líneas en stdin como opciones de línea de comandos adicionales.

  • Los argumentos se pueden entrecomillar con comillas simples o dobles, pero cada argumento debe estar completamente entrecomillado.
  • Los argumentos sin comillas se dividen por espacios en blanco.
  • No se implementan secuencias de escape.

Las líneas de opciones en stdin se procesan de forma asíncrona y pueden anular todas las opciones y la salida capturada. El modo de transmisión es utilizado por wl-present(1) para agregar controles interactivos a wl-mirror.

MARCADORES DE POSICIÓN DE TÍTULO

La cadena de título admite los siguientes marcadores de posición:

  • {width}, {height}: tamaño del área reflejada
  • {x}, {y}: desplazamientos en la pantalla
  • {target_width}, {target_height}, {target_output}: información sobre el dispositivo reflejado

Algunos ejemplos quizás útiles:

--title 'Espejo de Salida Wayland {target_output}'

--title '{target_output}:{width}x{height}+{x}+{y}'

--title 'redimensionar establecer {width} {height} mover posición {x} {y}'
