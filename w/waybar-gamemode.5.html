NOMBRE

waybar - módulo gamemode

DESCRIPCIÓN

El módulo gamemode muestra si algún juego o aplicación se está ejecutando con
optimizaciones de Feral Gamemode.

CONFIGURACIÓN

format:
tipo: cadena
predeterminado: {glyph}
El formato del texto.

format-alt:
tipo: cadena
predeterminado: {glyph} {count}
El formato del texto cuando se alterna.

tooltip:
tipo: booleano
predeterminado: true
Opción para deshabilitar la información emergente al pasar el ratón por encima.

tooltip-format:
tipo: cadena
predeterminado: Juegos en ejecución: {glyph}
El formato de texto de la información emergente.

hide-not-running:
tipo: booleano
predeterminado: true
Define si el módulo debe ocultarse si no se están ejecutando juegos.

use-icon:
tipo: booleano
predeterminado: true
Define si el módulo debe mostrar un icono GTK en lugar del glyph especificado

glyph:
tipo: cadena
predeterminado: 
El glifo de icono de cadena a mostrar. Solo visible si use-icon está establecido en false.

icon-name:
tipo: cadena
predeterminado: input-gaming-symbolic
El icono GTK a mostrar. Solo visible si use-icon está establecido en true.

icon-size:
tipo: entero sin signo
predeterminado: 20
Define el tamaño de los iconos.

icon-spacing:
tipo: entero sin signo
predeterminado: 4
Define el espaciado entre el icono y el texto.

expand:
tipo: booleano
predeterminado: false
Permite que este módulo consuma dinámicamente todo el espacio restante.

REEMPLAZOS DE FORMATO

{glyph}: El glifo de icono de cadena a usar en su lugar.

{count}: El número de juegos que se ejecutan con optimizaciones de gamemode .

REEMPLAZOS DE FORMATO DE HERRAMIENTA

{count}: El número de juegos que se ejecutan con optimizaciones de gamemode .

EJEMPLOS

"gamemode": {
	"format": "{glyph}",
	"format-alt": "{glyph} {count}",
	"glyph": "",
	"hide-not-running": true,
	"use-icon": true,
	"icon-name": "input-gaming-symbolic",
	"icon-spacing": 4,
	"icon-size": 20,
	"tooltip": true,
	"tooltip-format": "Juegos en ejecución: {count}"
}
