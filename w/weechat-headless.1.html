WEECHAT-HEADLESS(1) Manual de WeeChat WEECHAT-HEADLESS(1)

NOMBRE

weechat-headless - el cliente de chat extensible (versión sin interfaz gráfica)

SINOPSIS

weechat-headless [-a|--no-connect] [--daemon] [--stdout] [-d|--dir <ruta>] [-t|--temp-dir] [-p|--no-plugin] [-P|--plugins <plugins>] [-r|--run-command <comando>] [-s|--no-script] [--upgrade] [opción-debug...] [plugin:opción...]
weechat-headless [-c|--colors]
weechat-headless [-h|--help]
weechat-headless [-l|--license]
weechat-headless [-v|--version]

DESCRIPCIÓN

WeeChat (Wee Enhanced Environment for Chat) es un cliente de chat gratuito, rápido y ligero, diseñado para muchos sistemas operativos. Es altamente personalizable y extensible con scripts.

El comando weechat-headless ejecuta WeeChat en modo sin interfaz gráfica (headless). Puede ser utilizado para pruebas o para daemonizar WeeChat con la opción "--daemon".

OPCIONES

-a, --no-connect

Deshabilita la conexión automática a servidores cuando WeeChat se está iniciando.

-c, --colors

Muestra los colores predeterminados en la terminal.

--daemon

Ejecuta WeeChat en segundo plano, como un demonio (solo funciona con el comando weechat-headless).

--stdout

Muestra los mensajes de registro en la salida estándar en lugar de escribirlos en un archivo de registro (solo funciona con el comando weechat-headless, no es compatible con la opción "--daemon").

-d, --dir <ruta>

Fuerza un único directorio para todos los archivos de WeeChat (el directorio se crea si no se encuentra). Se pueden proporcionar cuatro directorios, separados por dos puntos (en este orden: config, data, cache, runtime). Si no se proporciona esta opción, se utiliza la variable de entorno WEECHAT_HOME (si no está vacía).

-t, --temp-dir

Crea un directorio temporal para WeeChat y lo elimina al salir (incompatible con la opción "-d").
El nombre del directorio se construye automáticamente por WeeChat, con esta plantilla: "weechat_temp_XXXXXX" (donde "XXXXXX" es aleatorio). Se crea en el primer directorio disponible de esta lista: variable de entorno "TMPDIR", "/tmp" (puede ser diferente según el sistema operativo), variable de entorno "HOME", directorio actual.
El directorio temporal tiene permisos 0700 (solo el propietario puede leer, escribir y ejecutar).

-h, --help

Muestra la ayuda.

-i, --build-info

Muestra información de compilación y sale.

-l, --license

Muestra la licencia de WeeChat.

-p, --no-plugin

Deshabilita la carga automática de plugins.

-P, --plugins <plugins>

Carga solo estos plugins al inicio (ver /help weechat.plugin.autoload). Si se proporciona esta opción, la opción weechat.plugin.autoload no se utiliza.

-r, --run-command <comando>

Ejecuta comando(s) después del inicio; se pueden separar varios comandos por punto y coma, esta opción se puede dar varias veces.

-s, --no-script

Deshabilita la carga automática de scripts.

--upgrade

Actualiza WeeChat usando archivos de sesión generados con el comando /upgrade -quit.

-v, --version

Muestra la versión de WeeChat.

plugin:option

Opción para un plugin.

OPCIONES DE DEPURACIÓN

ADVERTENCIA: ¡estas opciones son solo para fines de depuración, **NO LAS USE EN PRODUCCIÓN!**

--no-dlclose

No llama a la función dlclose después de que los plugins se descargan. Esto es útil con herramientas como Valgrind para mostrar la pila de los plugins descargados.

--no-gnutls

No llama a las funciones init y deinit de la biblioteca GnuTLS. Esto es útil con herramientas como Valgrind y electric-fence, para prevenir errores de memoria de GnuTLS.

--no-gcrypt

No llama a las funciones init y deinit de la biblioteca Gcrypt. Esto es útil con herramientas como Valgrind, para prevenir errores de memoria de Gcrypt.

OPCIONES DE PLUGIN

Para obtener documentación completa sobre las opciones de los plugins, consulte la documentación de los plugins en la Guía del usuario de WeeChat https://weechat.org/doc/.

Con el plugin de IRC, puede conectarse a un servidor con una URL como:

irc[6][s]://[[nombredeusuario][:contraseña]@]servidor[:puerto][/#canal1[,#canal2...]]

Para unirse al canal de soporte IRC de WeeChat con el nick "mi_nick":

irc://mi_nick@irc.libera.chat/#weechat

Las direcciones IPv6 se pueden encerrar entre corchetes para añadir un puerto después de la dirección, por ejemplo:

irc://mi_nick@[2001:db8:0:85a3::ac1f:8001]:6668/#test
