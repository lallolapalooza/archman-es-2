WMCTRL(1) Manual de Comandos Generales WMCTRL(1)

NOMBRE

wmctrl - interactúa con un Gestor de Ventanas compatible con EWMH/NetWM.

SINOPSIS

wmctrl [ opciones | acciones ]...

DESCRIPCIÓN

wmctrl es un comando que puede usarse para interactuar con un gestor de ventanas X compatible con la especificación EWMH/NetWM. wmctrl puede consultar al gestor de ventanas para obtener información, y puede solicitar que se realicen ciertas acciones de gestión de ventanas.

wmctrl se controla completamente mediante sus argumentos de línea de comandos. Los argumentos de línea de comandos se utilizan para especificar la acción a realizar (con opciones que modifican el comportamiento) y cualquier argumento que pueda ser necesario para realizar las acciones.

Las siguientes secciones definen las acciones y opciones soportadas. Los argumentos de las acciones y opciones se escriben en forma de <NOMBREARGUMENTO> en las descripciones a continuación. La sintaxis detallada para escribir los argumentos se encuentra en una sección dedicada a ese propósito.

ACCIONES

Los siguientes argumentos de línea de comandos pueden especificarse para invocar una acción de wmctrl. Solo se puede ejecutar una acción con la invocación del comando wmctrl.

-a <VENTANA>
Cambia al escritorio que contiene la ventana <VENTANA>, eleva la ventana y le da el foco.
-b ( add | remove | toggle),prop1 [,prop2 ]
Añade, elimina o cambia entre dos propiedades de ventana simultáneamente. La ventana que se está modificando debe identificarse con la acción -r. El cambio de propiedad se logra utilizando la solicitud EWMH _NET_WM_STATE. Los nombres de propiedad soportados (para prop1 y prop2) son modal, sticky, maximized_vert, maximized_horz, shaded, skip_taskbar, skip_pager, hidden, fullscreen, above y below. Se soportan dos propiedades para permitir operaciones como maximizar una ventana en modo de pantalla completa. Tenga en cuenta que esta acción consta de exactamente dos argumentos de línea de comandos del shell.
-c <VENTANA>
Cierra la ventana <VENTANA> de forma elegante.
-d
Lista todos los escritorios gestionados por el gestor de ventanas. Se genera una línea de salida por cada escritorio, dividida en columnas separadas por espacios. La primera columna contiene un número entero del escritorio. La segunda columna contiene un carácter '*' para el escritorio actual, de lo contrario contiene un carácter '-'. Las siguientes dos columnas contienen la cadena fija DG: y luego la geometría del escritorio en formato '<ancho>x<alto>' (ej. '1280x1024'). Las siguientes dos columnas contienen la cadena fija VP: y luego la posición de la vista previa en el formato '<x>,<y>' (ej. '0,0'). Las siguientes tres columnas contienen la cadena fija WA: y luego dos columnas con la geometría del área de trabajo como 'X,Y y AxH' (ej. '0,0 1280x998'). El resto de la línea contiene el nombre del escritorio (posiblemente con múltiples espacios).
-e <ARGMOVREDIM>
Redimensiona y mueve una ventana especificada con la acción -r según el argumento <ARGMOVREDIM>.
-g a,l
Cambia la geometría (tamaño común) de todos los escritorios para que tengan a píxeles de ancho y l píxeles de alto. a y l deben ser enteros positivos. Un gestor de ventanas puede ignorar esta solicitud.
-h
Imprime el texto de ayuda sobre el uso del programa.
-I nombre
Establece el nombre del icono (título corto) de la ventana especificada por la acción -r a nombre.
-k ( on | off )
Activa o desactiva el modo de "mostrar escritorio" del gestor de ventanas (si el gestor de ventanas implementa esta función).
-l
Lista las ventanas gestionadas por el gestor de ventanas. Se genera una línea de salida por cada ventana, dividida en columnas separadas por espacios. La primera columna siempre contiene la identidad de la ventana como un entero hexadecimal, y la segunda columna siempre contiene el número del escritorio (se usa un -1 para identificar una ventana fija). Si se especifica la opción -p, la siguiente columna contendrá el PID de la ventana como un entero decimal. Si se especifica la opción -G, seguirán cuatro columnas de enteros: desplazamiento x, desplazamiento y, ancho y alto. La siguiente columna siempre contiene el nombre de la máquina cliente. El resto de la línea contiene el título de la ventana (posiblemente con múltiples espacios en el título).
-m
Muestra información sobre el gestor de ventanas y el entorno.
-n N
Cambia el número de escritorios a N (un entero no negativo).
-N nombre
Establece el nombre (título largo) de la ventana especificada por la acción -r a nombre.
-o x,y
Cambia la vista previa para el escritorio actual. Los valores x e y son desplazamientos numéricos que especifican la posición de la esquina superior izquierda de la vista previa. Un gestor de ventanas puede ignorar esta solicitud.
-r <VENTANA>
Especifica una ventana de destino para una acción.
-R <VENTANA>
Mueve la ventana <VENTANA> al escritorio actual, la eleva y le da el foco.
-s <ESCRITORIO>
Cambia al escritorio <ESCRITORIO>.
-t <ESCRITORIO>
Mueve una ventana especificada con la acción -r al escritorio <ESCRITORIO>.
-T nombre
Establece tanto el nombre (título largo) como el nombre del icono (título corto) de la ventana especificada por la acción -r a nombre. Esta acción es como usar las acciones -N y -I al mismo tiempo (lo que de otro modo sería imposible ya que wmctrl solo puede ejecutar una acción a la vez).

OPCIONES

Las siguientes opciones modifican las acciones predeterminadas, o modifican la interpretación de los argumentos.

-F
Los argumentos de nombre de ventana (<VENTANA>) deben tratarse como títulos de ventana exactos que distinguen entre mayúsculas y minúsculas. Sin estas opciones, los títulos de ventana se consideran subcadenas de mayúsculas/minúsculas ignoradas del título de ventana completo.
-G
Incluye información de geometría en la salida de la acción -l.
-i
Interpreta los argumentos de ventana (<VENTANA>) como un valor numérico en lugar de un nombre de cadena para la ventana. Si el valor numérico comienza con el prefijo '0x', se asume que es un número hexadecimal.
-p
Incluye los PID en la lista de ventanas impresa por la acción -l. Imprime un PID de '0' si la aplicación propietaria de la ventana no lo soporta.
-u
Anula la detección automática y fuerza el modo UTF-8.
-v
Proporciona una salida detallada. Esto es muy útil para depurar wmctrl en sí mismo.
-w [ <SOLUCION>[,<SOLUCION>]... ]
Utiliza las soluciones especificadas en el argumento.
-x
Incluye WM_CLASS en la lista de ventanas o interpreta <VENTANA> como el nombre WM_CLASS.

ARGUMENTOS<DESK>

<DESK>
Un escritorio siempre se especifica mediante un entero que representa los números de escritorio. Los números de escritorio comienzan en 0.
<MVARG>
Un argumento de mover y redimensionar tiene el formato 'g,x,y,w,h'. Los cinco componentes son enteros. El primer valor, g, es la gravedad de la ventana, siendo 0 el valor más común (el valor predeterminado para la ventana). Consulte la especificación EWMH para otros valores.
Los cuatro valores restantes son una especificación de geometría estándar: x,y es la posición de la esquina superior izquierda de la ventana, y w,h es el ancho y alto de la ventana, con la excepción de que el valor de -1 en cualquier posición se interpreta como que el valor de geometría actual no debe modificarse.
<WIN>
Este argumento especifica una ventana que es el objetivo de una acción. Por predeterminado, el argumento se trata como si fuera una cadena, y las ventanas se examinan hasta que se encuentra una con un título que contenga la cadena especificada como subcadena. La coincidencia de subcadenas se realiza sin distinguir entre mayúsculas y minúsculas. La opción -F se puede usar para forzar la coincidencia exacta de títulos que distinguen entre mayúsculas y minúsculas. La opción -i se puede usar para interpretar el destino de la ventana como una identidad numérica de ventana en lugar de una cadena.
La cadena de nombre de ventana :SELECT: se trata de forma especial. Si se utiliza este nombre de ventana, wmctrl espera a que el usuario seleccione la ventana de destino haciendo clic en ella.
La cadena de nombre de ventana :ACTIVE: se puede utilizar para instruir a wmctrl para que utilice la ventana actualmente activa para la acción.
<WORKAROUND>
Actualmente solo hay una solución implementada. Se especifica utilizando la cadena DESKTOP_TITLES_INVALID_UTF8 y provoca la correcta impresión de los títulos de escritorio no ASCII cuando se utiliza Window Maker.

EJEMPLOS

Obtener una lista de ventanas administradas por el administrador de ventanas

wmctrl -l

Obtener una lista de ventanas con información de PID y geometría.

wmctrl -p -G -l

Ir a la ventana con un nombre que contenga 'emacs'

wmctrl -a emacs

Sombrear una ventana con un título que contenga la palabra 'mozilla'

wmctrl -r mozilla -b add,shaded

Cerrar una ventana con título muy específico y que sea "sticky"

wmctrl -F -c 'Debian bug tracking system - Mozilla'

Alternar la "adherencia" de una ventana con una identidad de ventana específica

wmctrl -i -r 0x0120002 -b add,sticky

Cambiar el título de la ventana a una cadena especificada, pero elegir la ventana haciendo clic en ella

wmctrl -r :SELECT: -T "Ventana Seleccionada"

VER TAMBIÉN

zenity(1) es un útil programa de diálogo para crear scripts con wmctrl.

Algunos ejemplos de administradores de ventanas compatibles con EWMH/NetWM incluyen versiones recientes de Enlightenment, Icewm, Kwin, Sawfish y Xfce.
