Descripción detallada

Un único oyente para señales de Wayland.

wl_listener proporciona los medios para escuchar notificaciones de wl_signal. Muchos objetos de Wayland utilizan wl_listener para la notificación de eventos significativos como la destrucción de objetos.

Los clientes deben crear objetos wl_listener manualmente y pueden registrarlos como oyentes de señales usando #wl_signal_add, asumiendo que la señal es directamente accesible. Para estructuras opacas como wl_event_loop, añadir un oyente debe hacerse a través de los métodos acceso proporcionados. Un oyente solo puede escuchar una señal a la vez.

struct wl_listener your_listener;
your_listener.notify = your_callback_method;
// Acceso directo
wl_signal_add(&some_object->destroy_signal, &your_listener);
// Acceso a través de un método de acceso
wl_event_loop *loop = ...;
wl_event_loop_add_destroy_listener(loop, &your_listener);

Si el oyente es parte de una estructura más grande, se puede usar wl_container_of para obtener un puntero a él:

void your_listener(struct wl_listener *listener, void *data)
{
        struct your_data *data;
        your_data = wl_container_of(listener, data, your_member_name);
}

Si necesita eliminar un oyente de una señal, use wl_list_remove().

wl_list_remove(&your_listener.link);
