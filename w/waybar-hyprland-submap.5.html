NOMBRE

waybar - módulo de submapa de hyprland

DESCRIPCIÓN

El módulo submap muestra el submapa activo actualmente, similar a sway/mode.

CONFIGURACIÓN

Abordado por hyprland/submap

format:
tipo: cadena
por defecto: {}
El formato, cómo se debe mostrar la información. En {} se muestra el submapa activo actualmente.

rotate:
tipo: entero
Valor positivo para rotar la etiqueta de texto (en incrementos de 90 grados).

max-length:
tipo: entero
La longitud máxima en caracteres que el módulo debe mostrar.

min-length:
tipo: entero
La longitud mínima en caracteres que el módulo debe aceptar.

align:
tipo: flotante
La alineación de la etiqueta dentro del módulo, donde 0 es alineado a la izquierda y 1 es alineado a la derecha. Si el módulo está rotado, seguirá el flujo del texto.

justify:
tipo: cadena
La alineación del texto dentro de la etiqueta del módulo, permitiendo las opciones 'left', 'right' o 'center' para definir la posición.

on-click:
tipo: cadena
Comando a ejecutar al hacer clic en el módulo.

on-click-middle:
tipo: cadena
Comando a ejecutar al hacer clic con la rueda del ratón en el módulo.

on-click-right:
tipo: cadena
Comando a ejecutar al hacer clic derecho en el módulo.

on-update:
tipo: cadena
Comando a ejecutar cuando se actualiza el módulo.

on-scroll-up:
tipo: cadena
Comando a ejecutar al desplazarse hacia arriba en el módulo.

on-scroll-down:
tipo: cadena
Comando a ejecutar al desplazarse hacia abajo en el módulo.

smooth-scrolling-threshold:
tipo: doble
Umbral a usar al desplazarse.

tooltip:
tipo: booleano
por defecto: true
Opción para deshabilitar la descripción emergente al pasar el ratón.

always-on:
tipo: booleano
por defecto: false
Opción para mostrar el widget incluso cuando no hay un submapa activo.

default-submap
tipo: cadena
por defecto: Default
Opción para establecer el nombre del submapa a mostrar cuando no se está en un submapa activo.

menu:
tipo: cadena
Acción que muestra el menú emergente.

menu-file:
tipo: cadena
Ubicación del archivo descriptor del menú. Debe haber un elemento de tipo

GtkMenu con id menu

menu-actions:
tipo: array
Las acciones correspondientes a los botones del menú.

expand:
tipo: booleano
por defecto: false
Permite a este módulo consumir todo el espacio sobrante de forma dinámica.

EJEMPLOS

"hyprland/submap": {
	"format": "✌️ {}",
	"max-length": 8,
	"tooltip": false
}
