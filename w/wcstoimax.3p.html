WCSTOIMAX(3P) Manual POSIX del Programador WCSTOIMAX(3P)

PRÓLOGO

Esta página del manual forma parte del Manual POSIX del Programador. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

wcstoimax, wcstoumax — convertir una cadena de caracteres anchos a un tipo entero

SINOPSIS

#include <stddef.h>
#include <inttypes.h>
intmax_t wcstoimax(const wchar_t *restrict nptr,
    wchar_t **restrict endptr, int base);
uintmax_t wcstoumax(const wchar_t *restrict nptr,
    wchar_t **restrict endptr, int base);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1-2017 remite al estándar ISO C.

Estas funciones serán equivalentes a las funciones wcstol(), wcstoll(), wcstoul() y wcstoull(), respectivamente, excepto que la porción inicial de la cadena ancha se convertirá a la representación de intmax_t y uintmax_t, respectivamente.

VALOR DE RETORNO

Estas funciones devolverán el valor convertido, si lo hay.

Si no se pudo realizar ninguna conversión, se devolverá cero. Si el valor correcto está fuera del rango de valores representables, se devolverán {INTMAX_MAX}, {INTMAX_MIN} o {UINTMAX_MAX} (de acuerdo con el tipo de retorno y el signo del valor, si lo hay), y errno se establecerá a [ERANGE].

ERRORES

Estas funciones fallarán si:

EINVAL
El valor de base no es compatible.
ERANGE
El valor a devolver no es representable.

Estas funciones pueden fallar si:

EINVAL
No se pudo realizar ninguna conversión.
