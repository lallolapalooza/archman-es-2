wavelan(4) Manual de Controladores de Dispositivos wavelan(4)

NOMBRE

wavelan - controlador de dispositivo AT&T GIS WaveLAN ISA

SINOPSIS

insmod wavelan_cs.o [io=B,B..] [ irq=I,I..] [name=N,N..]

DESCRIPCIÓN

Este controlador está obsoleto: se eliminó en Linux 2.6.35.

wavelan es el controlador de dispositivo de bajo nivel para el adaptador ethernet inalámbrico WaveLAN ISA de NCR / AT&T / Lucent y el RoamAbout DS de Digital (DEC). Este controlador está disponible como módulo o puede compilarse en el kernel. Este controlador soporta múltiples tarjetas en ambas formas (hasta 4) y asigna el siguiente dispositivo ethernet disponible (eth0..eth#) para cada tarjeta encontrada, a menos que se especifique explícitamente un nombre de dispositivo (ver abajo). Este nombre de dispositivo se reportará en el archivo de log del kernel con la dirección MAC, NWID y frecuencia utilizada por la tarjeta.

Parámetros

Esta sección se aplica a la forma de módulo (parámetros pasados en la línea de comandos de insmod(8)). Si el controlador está incluido en el kernel, use la sintaxis ether=IRQ,IO,NAME en la línea de comandos del kernel.

io
Especifica la lista de direcciones base donde buscar tarjetas wavelan (configurado por el interruptor DIP en la tarjeta). Si no especifica ninguna dirección de io, el controlador escaneará las direcciones 0x390 y 0x3E0, lo que podría entrar en conflicto con otro hardware...
irq
Establece la lista de IRQ que cada tarjeta wavelan debe usar (el valor se guarda en almacenamiento permanente para uso futuro).
name
Establece la lista de nombres a usar para cada dispositivo de tarjeta wavelan (nombre utilizado por ifconfig(8)).

Extensiones inalámbricas

Use iwconfig(8) para manipular las extensiones inalámbricas.

NWID (o dominio)

Establece el ID de red [0 a FFFF] o deshabilítalo [off]. Como el NWID se almacena en el Área de Almacenamiento Permanente de la tarjeta, se reutilizará en cualquier invocación posterior del controlador.

Frecuencia y canales

Para el Hardware de 2.4 GHz 2.00, puede establecer la frecuencia especificando uno de los 10 canales definidos (2.412, 2.422, 2.425, 2.4305, 2.432, 2.442, 2.452, 2.460, 2.462 o 2.484) o directamente como un valor numérico. La frecuencia se cambia inmediatamente y de forma permanente. La disponibilidad de la frecuencia depende de las regulaciones...

Estadísticas de espionaje

Establece una lista de direcciones MAC en el controlador (hasta 8) y obtiene la última calidad de enlace para cada una de ellas (ver iwspy(8)).

/proc/net/wireless

status es el estado reportado por el módem. Link quality reporta la calidad de la modulación en el aire (espectro de difusión de secuencia directa) [máx = 16]. Level y Noise se refieren al nivel de señal y al nivel de ruido [máx = 64]. Los contadores de paquetes descartados de cifrado y paquetes descartados varios no están implementados.

ioctl Privado

Puede usar iwpriv(8) para manipular los ioctls privados.

Umbral de calidad y nivel

Le permite definir el umbral de calidad y nivel utilizado por el módem (los paquetes por debajo de este nivel se descartan).

Histograma

Esta funcionalidad hace posible definir un número de intervalos de nivel de señal y contar el número de paquetes recibidos en cada uno de esos intervalos definidos. Esta distribución podría usarse para calcular el valor medio y la desviación estándar del nivel de señal.

Notas específicas

Este controlador no detecta algunas tarjetas Wavelan no-NCR/AT&T/Lucent. Si esto le sucede, debe consultar el código fuente para ver cómo agregar su tarjeta a la rutina de detección.

Algunas de las características mencionadas son opcionales. Puede habilitarlas o deshabilitarlas cambiando banderas en la cabecera del controlador y recompilando.

VER TAMBIÉN
