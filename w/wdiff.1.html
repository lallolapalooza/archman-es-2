WDIFF(1) Comandos de usuario WDIFF(1)

NOMBRE

wdiff - muestra las diferencias de palabras entre archivos de texto

SINOPSIS

wdiff [OPCIÓN]... ARCHIVO1 ARCHIVO2
wdiff -d [OPCIÓN]... [ARCHIVO]

DESCRIPCIÓN

wdiff - Compara palabras en dos archivos e informa las diferencias.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-C, --copyright
muestra el copyright y sale
-1, --no-deleted
inhibe la salida de palabras eliminadas
-2, --no-inserted
inhibe la salida de palabras insertadas
-3, --no-common
inhibe la salida de palabras comunes
-a, --auto-pager
llama automáticamente a un paginador
-d, --diff-input
usa una única entrada diff unificada
-h, --help
muestra esta ayuda y sale
-i, --ignore-case
ignora mayúsculas/minúsculas al comparar
-l, --less-mode
variación del modo de impresión para "less"
-n, --avoid-wraps
no extiende campos a través de nuevas líneas
-p, --printer
sobreescribe como para impresoras
-s, --statistics
indica cuántas palabras se eliminaron, insertaron, etc.
-t, --terminal
usa termcap como para pantallas de terminal
-v, --version
muestra la versión del programa y sale
-w, --start-delete=CADENA
cadena para marcar el inicio de la región de eliminación
-x, --end-delete=CADENA
cadena para marcar el final de la región de eliminación
-y, --start-insert=CADENA
cadena para marcar el inicio de la región de inserción
-z, --end-insert=CADENA
cadena para marcar el final de la región de inserción

COMPATIBILIDAD

Algunas opciones que solían proporcionar alguna funcionalidad única ya no se recomiendan, pero aún se reconocen por motivos de compatibilidad con versiones anteriores.

-K, --no-init-term
Ahora es sinónimo de --terminal, que nunca inicializa la terminal.
