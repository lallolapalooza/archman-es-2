wofi-utils(3) Manual de Funciones de Biblioteca wofi-utils(3)

NOMBRE

wofi - Funciones de utilidad y documentación

DESCRIPCIÓN

Las funciones documentadas aquí son funciones de utilidad general. Se definen en utils.h.

FUNCIONES DE UTILIDAD

Las siguientes funciones son funciones de conveniencia general.

time_t utils_get_time_millis(void)
Devuelve la hora actual de Unix en milisegundos.
void utils_sleep_millis(time_t millis)
Espera la cantidad de tiempo especificada.

time_t millis - El tiempo de espera en milisegundos.

char* utils_concat(size_t arg_count, ...)
Concatena cadenas. El resultado devuelto es de asignación nueva y debe ser liberado por el llamador cuando se termine de usar.

size_t arg_count - El número de argumentos proporcionados

varargs - La lista de cadenas a concatenar.

size_t utils_min(size_t n1, size_t n2)
Devuelve el menor de los dos valores de entrada.

size_t n1 - El primer número.

size_t n2 - El segundo número.

size_t utils_min3(size_t n1, size_t n2, size_t n3)
Devuelve el menor de los tres valores de entrada.

size_t n1 - El primer número.

size_t n2 - El segundo número.

size_t n3 - El tercer número.

size_t utils_distance(const char* haystack, const char* needle)
Calcula la distancia de Levenshtein entre las dos entradas.

const char* haystack - La cadena en la que buscar.

const char* needle - La cadena a buscar.
