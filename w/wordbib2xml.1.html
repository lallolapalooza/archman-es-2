SINOPSIS

formato2xml [OPCIONES] [archivo.formato]

DESCRIPCIÓN

El conjunto de programas bibutils interconvierte entre varios formatos de bibliografía usando el Metadata Object Description Schema (MODS)[2]versión 3.1 de la Biblioteca del Congreso[1]. Por ejemplo, se puede convertir archivos en formato RIS a Bibtex realizando dos transformaciones: RIS>MODS>Bibtex.

Opciones Comunes de Conversión a MODS

Varias banderas disponibles para los programas end2xml, endx2xml, bib2xml, ris2xml, med2xml, y copac2xml. La mayoría de las opciones tienen una versión corta y una larga.

-h --help mostrar ayuda
-v --version mostrar versión
-a --add-refcount añadir "_#", donde # es el número de referencia al id de referencia
-s --single-refperfile poner una referencia por archivo con el número de referencia
-i --input-encoding interpretar el archivo de entrada como usando el conjunto de caracteres solicitado (usar sin argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres
-u --unicode-characters codificar caracteres unicode directamente en el archivo en lugar de como entidades XML
-un --unicode-no-bom igual que -u, pero sin incluir una marca de orden de bytes
-x --xml-entities codificar caracteres unicode como entidades XML (opuesto de -u)
-nl --no-latex no convertir combinaciones de caracteres estilo latex
-s --single-refperfile una referencia por archivo de salida
-d --drop-key no poner la clave de citación en el campo id de mods
-c --corporation-file con un argumento que especifica un archivo que contiene una lista de nombres de corporaciones que se colocarán en <name type="corporate"></name> en lugar de type="personal" y eliminar la manipulación de nombres
-a --asis con un argumento que especifica un archivo que contiene una lista de nombres que se tratarán literalmente
-nt --nosplit-title no dividir títulos en pares TÍTULO/SUBTÍTULO
--verbose salida detallada
--debug salida muy detallada (principalmente para depuración)

bib2xml

bib2xml convierte un archivo de referencias en formato bibtex a un archivo de bibliografía intermedio XML. Especifique los archivos a convertir en la línea de comandos. Los archivos que contengan cadenas de sustitución de bibtex deben especificarse antes de los archivos donde se especifiquen las sustituciones (o en el mismo archivo antes de su uso). Si no se especifican archivos, la información de bibtex se leerá de la entrada estándar.

bib2xml archivo.bib > archivo_salida.xml

biblatex2xml

biblatex2xml convierte un archivo de referencias en formato biblatex (no confundir con bibtex) a un archivo de bibliografía intermedio XML MODS.

biblatex2xml archivo.bib > archivo_salida.xml

copac2xml

copac2xml convierte un archivo de referencias en formato COPAC a un archivo de bibliografía intermedio XML MODS.

end2xml

end2xml convierte un archivo de referencias en formato endnote de texto a un archivo de bibliografía intermedio XML. Este programa no funcionará en la biblioteca binaria; el archivo debe exportarse primero. Los formatos etiquetados de Endnote (exportación en formato "Refer") se parecen al Ejemplo 1, "Archivo de formato refer de ejemplo". Hay instrucciones muy buenas para asegurarse de que está exportando correctamente en http://www.sonnysoftware.com/endnoteimport.html[5]

El uso de end2xml es el mismo que el de bib2xml.

end2xml archivo.end > archivo_salida.xml

ebi2xml

ebi2xml convierte un archivo XML de EBI a un archivo de bibliografía intermedio XML MODS.

endx2xml

endx2xml convierte un archivo de referencias exportado en XML de EndNote a un archivo de bibliografía intermedio XML MODS. Este programa no funcionará en la biblioteca binaria; el archivo debe exportarse primero.

isi2xml

isi2xml convierte un archivo de referencias en formato ISI-web-of-science a un archivo de bibliografía intermedio XML.

El uso de isi2xml es el mismo que el de bib2xml.

isi2xml archivo_entrada.isi > archivo_salida.xml

ris2xml

ris2xml convierte un archivo de referencias en formato RIS a un archivo de bibliografía intermedio XML. El uso de ris2xml es como el de end2xml y bib2xml

ris2xml archivo.ris >	archivo_salida.xml

wordbib2xml

wordbib2xml convierte un archivo de referencias en formato Word2007 a un archivo de bibliografía intermedio XML.

Opciones Comunes de Conversión desde MODS

Casi todas las opciones de los programas de conversión desde MODS son las mismas.

-h --help display help
-v --version display version
-i --input-encoding interpret the input file as using the requested character set (use w/o argument for current list derived from character sets at www.kostis.net[4]) unicode is now a character set option
-u --unicode-characters encode unicode characters directly in the file rather than as XML entities
-un --unicode-no-bom as -u, but don't include a byte order mark
-x --xml-entities encode unicode characters as XML entities (opposite of -u)
-nl --no-latex do not convert latex-style character combinations
-s --single-refperfile one reference per output file
-d --drop-key don't put citation key in the mods id field
-c --corporation-file with argument specifying a file containing a list of corporation names to be placed in <name type="corporate"></name> instead of type="personal" and eliminate name mangling
-a --asis with argument specifying a file containing a list of names to be treated verbatim
-nt --nosplit-title don't split titles into TITLE/SUBTITLE pairs
--verbose verbose output
--debug very verbose output (mostly for debugging)

xml2bib

xml2bib converts a MODS XML bibliography file to a bibtex file. Use standard input and standard output if no files are specified.

xml2bib input_file.xml > output_file.bib

xml2biblatex

xml2biblatex converts a MODS XML bibliography file to a biblatex file.

xml2biblatex input_file.xml > output_file.bib

xml2ris

xml2ris converts a MODS XML bibliography file to a RIS file. Usage is the same as xml2bib.

xml2ris input_file.xml > output_file.ris

xml2end

xml2end converts a MODS XML bibliography file to the Endnote tagged format. Usage is the same as xml2bib.

xml2end input_file.xml > output_file.end

xml2isi

xml2isi converts a MODS XML bibliography file to the ISI format. Usage is the same as xml2bib.

xml2isi input_file.xml > output_file.isi

xml2wordbib

xml2wordbib converts a MODS XML bibliography file to a Word 2007 bibliography file. Usage is the same as xml2bib.

xml2wordbib input_file.xml > output_file.xml

MODSCLEAN

modsclean cleans up MODS XML files. It is used to reformat and re-indent the MODS XML files as well as performing cleanup operations.

Usage is as follows:

modsclean [-h] [-v] [-i input_encoding] [-o output_encoding]
          [-k] [-p prefix] [-t suffix] [-d] [-s]
          [input_file] [output_file]

The default input and output encodings are UTF-8. The default input and output files are standard input and standard output, respectively.

Options:

-h, --help
Display help message and exit.
-v, --version
Display version information and exit.
-i input_encoding, --input-encoding input_encoding
Specify the character encoding of the input file.
-o output_encoding, --output-encoding output_encoding
Specify the character encoding for the output file.
-k, --keep-order
Keep the order of elements as they appear in the input file.
-p prefix, --prefix prefix
Add a namespace prefix to elements.
-t suffix, --suffix suffix
Add a namespace suffix to elements.
-d, --drop-empty
Drop empty elements.
-s, --sort-elements
Sort elements alphabetically.

Opciones Comunes Al Convertir desde MODS

Tenga en cuenta que --output-encoding se refiere al archivo de entrada.

-h --help mostrar ayuda
-v --version mostrar versión
-o --output-encoding interpretar el archivo de entrada como si usara el conjunto de caracteres solicitado (usar sin argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres.
-s --single-refperfile poner una referencia por nombre de archivo según el número de referencia.
-nb --no-bom no escribir Byte Order Mark si se escribe UTF8.

xml2bib

xml2bib convierte la bibliografía XML de MODS en un archivo de referencia con formato bibtex. El uso de xml2bib es el mismo que para otras herramientas.

xml2bib xml_file.xml > output_file.bib

Dado que el formato de referencia BibTeX es bastante flexible y parece tener el mayor número de preferencias personales, también ha acumulado una serie de opciones específicas que no están disponibles para otros formatos.

A partir de la versión 3.24, la salida de xml2bib utiliza etiquetas en minúsculas y tipos de referencia con mayúsculas y minúsculas combinadas para una mejor interacción con otro software. El comportamiento anterior con etiquetas/tipos de referencia en mayúsculas todavía se puede generar utilizando el modificador de línea de comandos -U/--uppercase.

Opciones específicas de xml2bib:

-fc --finalcomma agregar coma final en la salida bibtex para aquellos que la deseen.
-sd --singledash usar un guion en lugar de dos (guion más largo en latex) entre números en la salida de páginas.
-b --brackets usar corchetes en lugar de comillas alrededor de los datos del campo.
-w --whitespace agregar espacios en blanco embellecedores a la salida.
-U --uppercase usar todas las mayúsculas para etiquetas (nombres de campo) y tipos de referencia (comportamiento anterior a la versión 3.24).
-sk --strictkey usar solo caracteres alfanuméricos para las claves de cita de bibtex.

xml2ads

xml2ads convierte la bibliografía XML de MODS al formato de referencia del Sistema de Datos Astrofísicos (ADS) del Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) (que es muy similar al estilo Endnote etiquetado). El uso de xml2ads es el mismo que para otras herramientas.

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convierte la bibliografía XML de MODS a un archivo de bibliografía con formato RIS. El uso de xml2ris es el mismo que para otras herramientas.

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convierte la bibliografía XML de MODS a un archivo de bibliografía Endnote etiquetado (formato refer). El uso de xml2end es el mismo que para otras herramientas.

xml2end xml_file.xml >  output_file.end

xml2wordbib

xml2wordbib convierte la bibliografía XML de MODS a un archivo de bibliografía XML con formato Word 2007. El uso de xml2wordbib es el mismo que para otras herramientas.

xml2wordbib xml_file.xml >  output_file.word.xml

xml2wordbib se llamaba xml2word en versiones de bibutils anteriores a la 3.40. Se cambió el nombre para evitar confusiones con otras herramientas. Esperemos que esto no rompa demasiados scripts ya en uso.
