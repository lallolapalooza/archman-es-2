wcsdup(3) Manual de funciones de la biblioteca wcsdup(3)

NOMBRE

wcsdup - duplicar una cadena de caracteres anchos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <wchar.h>
wchar_t *wcsdup(const wchar_t *s);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

wcsdup():

    Desde glibc 2.10:
        _POSIX_C_SOURCE >= 200809L
    Antes de glibc 2.10:
        _GNU_SOURCE

DESCRIPCIÓN

La función wcsdup() es el equivalente de caracteres anchos de la función strdup(3). Asigna y devuelve una nueva cadena de caracteres anchos cuyo contenido inicial es un duplicado de la cadena de caracteres anchos apuntada por s.

La memoria para la nueva cadena de caracteres anchos se obtiene con malloc(3) y debe liberarse con free(3).

VALOR DE RETORNO

En caso de éxito, wcsdup() devuelve un puntero a la nueva cadena de caracteres anchos. En caso de error, devuelve NULL, con errno establecido para indicar el error.

ERRORES

ENOMEM
No hay suficiente memoria disponible para asignar la cadena duplicada.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
wcsdup () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIA

libc5, glibc 2.0.

VER TAMBIÉN

strdup(3), wcscpy(3)
