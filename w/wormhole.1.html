WORMHOLE(1) Comandos de usuario WORMHOLE(1)

NOMBRE

wormhole - Transfiere datos de forma segura y sencilla entre ordenadores

SINOPSIS

wormhole [OPCIONES] COMANDO [ARGUMENTOS]...

DESCRIPCIÓN

Crea un Agujero de Gusano Mágico y comunícate a través de él.
Los agujeros de gusano se crean pronunciando el mismo CÓDIGO mágico en dos lugares diferentes al mismo tiempo. Los agujeros de gusano son seguros contra cualquiera que no use el mismo código.

OPCIONES

--relay-url URL
servidor de retransmisión de conexión para usar
--transit-helper tcp:HOST:PORT
servidor de retransmisión de tránsito para usar
--dump-timing ARCHIVO.json
(depuración) escribe datos de tiempo en el archivo
--version
Muestra la versión y sale.
--help
Muestra este mensaje y sale.

Comandos:

receive
Recibe un mensaje de texto, archivo o directorio...
send
Envía un mensaje de texto, archivo o directorio

VER TAMBIÉN

wormhole-server(8)
