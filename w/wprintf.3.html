wprintf(3) Manual de Funciones de Biblioteca wprintf(3)

NOMBRE

wprintf, fwprintf, swprintf, vwprintf, vfwprintf, vswprintf - conversión de salida formateada de caracteres anchos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
#include <wchar.h>
int wprintf(const wchar_t *restrict format, ...);
int fwprintf(FILE *restrict stream,
             const wchar_t *restrict format, ...);
int swprintf(size_t n;
             wchar_t wcs[restrict n], size_t n,
             const wchar_t *restrict format, ...);
int vwprintf(const wchar_t *restrict format, va_list args);
int vfwprintf(FILE *restrict stream,
             const wchar_t *restrict format, va_list args);
int vswprintf(size_t n;
             wchar_t wcs[restrict n], size_t n,
             const wchar_t *restrict format, va_list args);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

Todas las funciones mostradas arriba:

    _XOPEN_SOURCE >= 500 || _ISOC99_SOURCE
        || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

La familia de funciones wprintf() es el equivalente de caracteres anchos de la familia de funciones printf(3). Realiza la salida formateada de caracteres anchos.

Las funciones wprintf() y vwprintf() realizan la salida de caracteres anchos a stdout. stdout no debe estar orientado a bytes; ver fwide(3) para más información.

Las funciones fwprintf() y vfwprintf() realizan la salida de caracteres anchos a stream. stream no debe estar orientado a bytes; ver fwide(3) para más información.

Las funciones swprintf() y vswprintf() realizan la salida de caracteres anchos a una matriz de caracteres anchos. El programador debe asegurarse de que haya espacio para al menos n caracteres anchos en wcs.

Estas funciones son como las funciones printf(3), vprintf(3), fprintf(3), vfprintf(3), sprintf(3), vsprintf(3) excepto por las siguientes diferencias:

•
La cadena format es una cadena de caracteres anchos.
•
La salida consiste en caracteres anchos, no bytes.
•
swprintf() y vswprintf() toman un argumento n, mientras que sprintf(3) y vsprintf(3) no lo hacen. (snprintf(3) y vsnprintf(3) toman un argumento n, pero estas funciones no devuelven -1 ante un desbordamiento de búfer en Linux.)

El tratamiento de los caracteres de conversión c y s es diferente:

c
Si no hay un modificador l presente, el argumento int se convierte a un carácter ancho mediante una llamada a la función btowc(3), y se escribe el carácter ancho resultante. Si hay un modificador l presente, se escribe el argumento wint_t (carácter ancho).
s
Si no hay un modificador l presente: se espera que el argumento const char * sea un puntero a una matriz de tipo carácter (puntero a una cadena) que contiene una secuencia de caracteres multibyte que comienza en el estado de desplazamiento inicial. Los caracteres de la matriz se convierten a caracteres anchos (cada uno mediante una llamada a la función mbrtowc(3) con un estado de conversión que comienza en el estado inicial antes del primer byte). Los caracteres anchos resultantes se escriben hasta (pero sin incluir) el carácter ancho nulo de terminación (L'\0'). Si se especifica una precisión, no se escriben más caracteres anchos que el número especificado. Tenga en cuenta que la precisión determina el número de *caracteres anchos* escritos, no el número de *bytes* o *posiciones de pantalla*. La matriz debe contener un byte nulo de terminación ('\0'), a menos que se dé una precisión y esta sea tan pequeña que el número de caracteres anchos convertidos la alcance antes de que se alcance el final de la matriz. Si hay un modificador l presente: se espera que el argumento const wchar_t * sea un puntero a una matriz de caracteres anchos. Los caracteres anchos de la matriz se escriben hasta (pero sin incluir) un carácter ancho nulo de terminación. Si se especifica una precisión, no se escriben más de la cantidad especificada. La matriz debe contener un carácter ancho nulo de terminación, a menos que se dé una precisión y esta sea menor o igual al número de caracteres anchos en la matriz.

VALOR DE RETORNO

Las funciones devuelven el número de caracteres anchos escritos, excluyendo el carácter ancho nulo de terminación en el caso de las funciones swprintf() y vswprintf(). En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

Ver write(2) y putwc(3). Además, puede ocurrir el siguiente error:

EOVERFLOW
El valor a devolver es mayor que INT_MAX.

Las funciones fwprintf() y wprintf() pueden fallar además si:

ENOMEM
No hay suficiente espacio de almacenamiento disponible.

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C99.

NOTAS

El comportamiento de wprintf() y similares depende de la categoría LC_CTYPE de la configuración regional actual.

Si la cadena format contiene caracteres anchos no ASCII, el programa funcionará correctamente solo si la categoría LC_CTYPE de la configuración regional en tiempo de ejecución es la misma que la categoría LC_CTYPE de la configuración regional en tiempo de compilación. Esto se debe a que la representación de wchar_t depende de la plataforma y la configuración regional. (glibc representa los caracteres anchos mediante su punto de código Unicode (ISO/IEC 10646), pero otras plataformas no lo hacen. Además, el uso de nombres de caracteres universales C99 de la forma \unnnn no resuelve este problema). Por lo tanto, en programas internacionalizados, la cadena format debe consistir solo en caracteres anchos ASCII, o debe construirse en tiempo de ejecución de forma internacionalizada (por ejemplo, usando gettext(3) o iconv(3), seguido de mbstowcs(3)).

VER TAMBIÉN

wprintf - escribe una salida con formato en un flujo de anchura

NOMBRE BIBLIOTECA SINAPSIS DESCRIPCIÓN VALOR DE RETORNO ERRORES ATRIBUTOS ESTÁNDARES HISTORIA NOTAS VER TAMBIÉN

NOMBRE

wprintf - escribe una salida con formato en un flujo de anchura

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINAPSIS

#include <stdio.h>
#include <wchar.h>

int wprintf(const wchar_t *format, ...);

DESCRIPCIÓN

La función wprintf es similar a la función printf, pero escribe en el flujo de salida estándar stdout caracteres anchos.

El argumento format es un puntero a una cadena de caracteres anchos que especifica cómo se deben escribir los argumentos subsiguientes. La cadena de formato consiste en cero o más directivas: secuencias de caracteres que no son de marca de porcentaje y marcas de porcentaje que inician secuencias de especificación de conversión.

Las marcas de porcentaje son caracteres que comienzan con %. Las marcas de porcentaje se interpretan de la siguiente manera:

  • Un carácter % seguido de otro carácter % se escribe como un único carácter %.
  • Un carácter % seguido de un carácter de marca de especificación de conversión se interpreta como una especificación de conversión.

Las especificaciones de conversión son de la forma:

%%[flags][width][.precision][length]specifier

Los especificadores de tipo son:

c
El argumento int correspondiente se convierte en un carácter ancho (wchar_t) y se escribe.
ls
El argumento const wchar_t * correspondiente se interpreta como una cadena de caracteres anchos y se escribe.
s
El argumento const char * correspondiente se convierte en una cadena de caracteres anchos utilizando la configuración regional actual y se escribe.
C
Equivalente a lc.
S
Equivalente a ls.
d, i, o, u, x, X
El argumento int correspondiente se convierte en una cadena de caracteres anchos en la base especificada y se escribe.
n
El número de caracteres anchos que se han escrito hasta ahora se almacena en el objeto int * correspondiente.
p
El argumento void * correspondiente se escribe como un puntero.
a, A, e, E, f, F, g, G
El argumento double correspondiente se escribe en formato flotante.
k
Escribe la hora y la fecha actuales en el formato especificado por la configuración regional.
b
Escribe el argumento int como un valor booleano (0 para falso, distinto de cero para verdadero).
w
Escribe el argumento int como un valor booleano (0 para falso, distinto de cero para verdadero).
%
Se escribe un carácter %.

Los indicadores, el ancho y la precisión tienen el mismo significado que en printf.

Las especificaciones de longitud son:

h
short int
l
long int
ll
long long int
L
long double
hh
signed char
z
size_t
t
ptrdiff_t
j
intmax_t

Para los especificadores de tipo de cadena s y ls, la precisión especifica el número máximo de caracteres anchos anchos que se van a escribir.

La configuración regional se utiliza para la conversión de cadenas y para la representación de números.

VALOR DE RETORNO

En caso de éxito, wprintf devuelve el número de caracteres anchos escritos. Si ocurre un error de codificación en la configuración regional, wprintf devuelve -1 y establece errno en EILSEQ. Si se produce un error de escritura, wprintf devuelve -1 y errno se establece para indicar el error.

ERRORES

EILSEQ
Se encontró una secuencia ilegal en la cadena de entrada.
EINVAL
La configuración regional no es válida.
ENOMEM
No hay suficiente memoria disponible.

ESTÁNDARES

wprintf cumple con C99 y POSIX.1-2008.

HISTORIA

wprintf apareció por primera vez en glibc 2.1.

NOTAS

La función wprintf se basa en la configuración regional actual para la conversión de datos. Si la configuración regional no está establecida correctamente, el comportamiento de wprintf puede ser impredecible.

La función wprintf puede ser menos eficiente que printf, ya que requiere la conversión de datos a caracteres anchos.
