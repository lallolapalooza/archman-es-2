QBIPCC.H(3) Manual del programador de libqb QBIPCC.H(3)

NOMBRE

qbipcc.h - API de IPC del cliente.

SINOPSIS

#include <qb/qbipcc.h>

DESCRIPCIÓN

Ciclo de vida de una conexión IPC.

Se establece una conexión IPC con el servidor mediante qb_ipcc_connect(). Esta función se conecta al servidor y solicita que se creen canales para la comunicación. Para desconectarse, el cliente sale o ejecuta la función qb_ipcc_disconnect().

Comunicación síncrona

La función qb_ipcc_sendv_recv() envía una solicitud de vector iovector y recibe una respuesta.

Solicitudes asíncronas del cliente

La función qb_ipcc_sendv() envía una solicitud de vector iovector. La función qb_ipcc_send() envía una solicitud de búfer de mensaje.

Eventos asíncronos del servidor

La función qb_ipcc_event_recv() recibe un mensaje asíncrono fuera de banda. Los mensajes asíncronos se ponen en cola y pueden proporcionar un rendimiento fuera de banda muy alto. Para determinar cuándo llamar a qb_ipcc_event_recv(), se utiliza la llamada qb_ipcc_fd_get() para obtener un descriptor de archivo utilizado en las llamadas del sistema poll() o select().
