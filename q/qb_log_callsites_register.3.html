Licencias: LGPL-2.1-or-later

QB_LOG_CALLSITES_REGISTER(3) Manual del programador de libqb QB_LOG_CALLSITES_REGISTER(3)

NOMBRE

qb_log_callsites_register - Si estás utilizando módulos cargables dinámicamente vía dlopen() y los cargas después de qb_log_init() entonces después de cargar el módulo necesitarás hacer lo siguiente para que los filtros funcionen en ese módulo:

SINOPSIS

#include <qb/qblog.h>

int32_t qb_log_callsites_register(
    struct qb_log_callsite   *_start,
    struct qb_log_callsite   *_stop
);

DESCRIPCIÓN

   _start = dlsym (dl_handle, QB_ATTR_SECTION_START_STR);
_stop = dlsym (dl_handle, QB_ATTR_SECTION_STOP_STR);
qb_log_callsites_register(_start, _stop);

ESTRUCTURAS

Se crea una instancia de esta estructura para cada mensaje de registro con el ID del mensaje.

struct qb_log_callsite {


    const char   *function;

    const char   *filename;

    const char   *format;

    uint8_t       priority;

    uint32_t      lineno;

    uint32_t      targets;

    uint32_t      tags;

    const char   *message_id;
};
