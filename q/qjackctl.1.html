NOMBRE

qjackctl - Interfaz de usuario para controlar JACK (Jack Audio Connection Kit)

SINOPSIS

qjackctl [opciones]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando qjackctl.

QjackCtl se utiliza para controlar el Jack Audio Connection Kit (JACK) y como patchbay para dispositivos ALSA MIDI y JACK MIDI. QjackCtl también tiene soporte para el protocolo de control de transporte de JACK, por lo que puede usarlo para iniciar y detener el transporte de JACK. Una vez que inicia qjackctl, se le presenta una única ventana GUI, los botones son autoexplicativos y tienen tooltips.

OPCIONES

-s, --start

Inicia el servidor de audio JACK inmediatamente

-p, --preset=[etiqueta]

Establece el nombre de la configuración predeterminada

-a, --active-patchbay=[ruta]

Establece el archivo de definición de patchbay activo

-n, --server-name=[etiqueta]

Establece el nombre del servidor de audio JACK predeterminado

-h, --help

Muestra ayuda sobre las opciones de línea de comandos

-v, --version

Muestra información de la versión.
