QB_LIST_EMPTY(3) Manual del programador de libqb QB_LIST_EMPTY(3)

NOMBRE

qb_list_empty - Una prueba rápida para ver si la lista está vacía (apunta a sí misma).

SINOPSIS

#include <qb/qblist.h>

static int32_t qb_list_empty(
    const struct qb_list_head   *head   /* puntero a la cabeza de la lista */
);

PARÁMETROS

head puntero a la cabeza de la lista

DESCRIPCIÓN

ESTRUCTURAS


struct qb_list_head {


    struct   next;

    struct   prev;
};

VALOR DE RETORNO

booleano verdadero/falso
