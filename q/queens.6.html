NOMBRE

queens - salvapantallas de n reinas

SINOPSIS

queens [--display host:display.screen] [--window] [--root] [--window-id número] [--install] [--visual visual] [--delay microsegundos] [--wireframe] [--fps]

DESCRIPCIÓN

El programa queens resuelve el problema de las n reinas (donde, en este programa, N está entre 5 y 10 reinas) utilizando un algoritmo de retroceso sencillo. El problema es: ¿cómo se pueden colocar N reinas en un tablero de ajedrez de NxN de tal manera que ninguna reina pueda atacar a otra?

OPCIONES

queens acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de ID (decimal o hexadecimal) de un visual específico.
--wireframe
Renderiza en modo alambre en lugar de sólido. --fps Muestra la tasa de fotogramas actual, la carga de la CPU y el recuento de polígonos.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

ERRORES

No es infrecuente que estos y otros trucos de OpenGL fallen bajo aceleración de hardware (UtahGLX) y se lleven consigo el servidor X. Las imágenes de textura deben ser de 16x16, 32x32 o 64x64, etc.
