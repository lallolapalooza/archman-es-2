QSAMPLER(1) Manual de Comandos Generales QSAMPLER(1)

NOMBRE

Qsampler - Interfaz gráfica Qt para LinuxSampler

SINOPSIS

qsampler [opciones] [archivo-sesión]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando qsampler.

Qsampler es una aplicación de interfaz gráfica (GUI) para LinuxSampler, escrita en C++ utilizando el framework Qt y Qt Designer. En este momento, solo actúa como una interfaz cliente de referencia para el Protocolo de Control de LinuxSampler (LSCP).

LinuxSampler es un proyecto en desarrollo. El objetivo es producir un sampler de audio gratuito y de código abierto, con características de nivel profesional, comparable tanto a samplers de hardware como a software comercial para Windows/Mac.

La plataforma inicial será Linux, ya que es uno de los sistemas operativos multimedia de código abierto más prometedores. Gracias a varios parches del kernel y al Jack Audio Connection Kit, Linux es capaz actualmente de ofrecer una respuesta MIDI-a-Audio sólida con menos de 5 milisegundos.

OPCIONES

-s, --start

Inicia el servidor linuxsampler localmente

-h, --hostname=[host]

Especifica el nombre de host del servidor linuxsampler (por defecto = localhost)

-p, --port=[puerto]

Especifica el número de puerto del servidor linuxsampler (por defecto = 8888)

-?, --help

Muestra la ayuda sobre las opciones de la línea de comandos

-v, --version

Muestra la información de la versión

ARCHIVOS

La configuración se almacena en ~/.config/rncbc.org/Qsampler.conf
