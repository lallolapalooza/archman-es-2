QB_LOOP_JOB_DEL(3) Manual del programador de libqb QB_LOOP_JOB_DEL(3)

NOMBRE

qb_loop_job_del - Elimina un trabajo del bucle principal.

SINOPSIS

#include <qb/qbloop.h>

int32_t qb_loop_job_del(
    struct qb_loop          *l,            /* puntero a la instancia del bucle */
    enum qb_loop_priority    p,            /* la prioridad */
    void                    *data,         /* datos de usuario pasados a la función de despacho */
    qb_loop_job_dispatch_fn  dispatch_fn   /* función de devolución de llamada */
);

PARÁMETROS

l puntero a la instancia del bucle

p la prioridad

data datos de usuario pasados a la función de despacho

dispatch_fn función de devolución de llamada

DESCRIPCIÓN

Intentará eliminar el trabajo si aún no se ha ejecutado.

ESTRUCTURAS


enum qb_loop_priority {


      QB_LOOP_LOW;

      QB_LOOP_MED;

      QB_LOOP_HIGH;
};

VALOR DE RETORNO

estado (0 == ok, -errno == fallo)

NOTA

esto eliminará el primer trabajo que coincida con los parámetros (prioridad, datos, función de despacho).
