quotactl(2) Manual de Llamadas al Sistema quotactl(2)

NOMBRE

quotactl, quotactl_fd - manipular cuotas de disco

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/quota.h>
#include <xfs/xqm.h> /* Definición de las constantes Q_X* y XFS_QUOTA_*
                        (o <linux/dqblk_xfs.h>; véase NOTAS) */
int quotactl(int op, const char *_Nullable special, int id,
             caddr_t addr);
#include <sys/syscall.h>    /* Definición de las constantes SYS_* */
#include <unistd.h>
int syscall(SYS_quotactl_fd, int fd, int op, int id, caddr_t addr);

Nota: glibc no proporciona un envoltorio para quotactl_fd(), lo que requiere el uso de syscall(2).

DESCRIPCIÓN

El sistema de cuotas se puede utilizar para establecer límites por usuario, por grupo y por proyecto en la cantidad de espacio en disco utilizado en un sistema de archivos. Para cada usuario y/o grupo, se pueden establecer un límite suave y un límite estricto para cada sistema de archivos. El límite estricto no se puede exceder. El límite suave se puede exceder, pero se mostrarán advertencias. Además, el usuario no puede exceder el límite suave durante más de un período de gracia (una semana por defecto) a la vez; después de esto, el límite suave cuenta como un límite estricto.

Las llamadas quotactl() y quotactl_fd() manipulan las cuotas de disco. La diferencia entre estas funciones es la forma en que se especifica el sistema de archivos que se está manipulando; véase la descripción de los argumentos a continuación. Véase NOTAS para saber por qué una variante podría ser preferible a la otra.

El argumento op indica una operación a aplicar al ID de usuario o grupo especificado en id. Para inicializar el argumento op, utilice la macro QCMD(subop, type). El valor type es USRQUOTA, para cuotas de usuario, GRPQUOTA, para cuotas de grupo, o (desde Linux 4.1) PRJQUOTA, para cuotas de proyecto. El valor subop se describe a continuación.

Para quotactl(), el argumento special es un puntero a una cadena terminada en nulo que contiene la ruta del dispositivo especial de bloques (montado) del sistema de archivos que se está manipulando.

Para quotactl_fd(), el argumento fd es un descriptor de archivo (que puede abrirse con la bandera O_PATH) que se refiere a un archivo o directorio en el sistema de archivos que se está manipulando.

El argumento addr es la dirección de una estructura de datos opcional, específica de la operación, que se copia dentro o fuera del sistema. La interpretación de addr se da con cada operación a continuación.

El valor subop es una de las siguientes operaciones:

Q_QUOTAON
Activa las cuotas para un sistema de archivos. El argumento id es el número de identificación del formato de cuota a utilizar. Actualmente, hay tres formatos de cuota compatibles:
QFMT_VFS_OLD
El formato de cuota original.
QFMT_VFS_V0
El formato estándar VFS v0 de cuota, que puede manejar UIDs y GIDs de 32 bits y límites de cuota de hasta 2^42 bytes y 2^32 inodes.
QFMT_VFS_V1
Un formato de cuota que puede manejar UIDs y GIDs de 32 bits y límites de cuota de 2^63 - 1 bytes y 2^63 - 1 inodes.
El argumento addr apunta a la ruta de un archivo que contiene las cuotas para el sistema de archivos. El archivo de cuota debe existir; normalmente se crea con el programa quotacheck(8)
La información de cuota también se puede almacenar en inodos del sistema ocultos para ext4, XFS y otros sistemas de archivos si el sistema de archivos está configurado así. En este caso, no hay archivos de cuota visibles y no es necesario usar quotacheck(8). La información de cuota siempre es mantenida de forma consistente por el sistema de archivos y la operación Q_QUOTAON solo sirve para habilitar la aplicación de los límites de cuota. La presencia de inodos del sistema ocultos con información de cuota se indica mediante la bandera DQF_SYS_FILE en el campo dqi_flags devuelto por la operación Q_GETINFO.
La variante quotactl_fd() de esta llamada al sistema ignora los argumentos addr e id, por lo que la operación Q_QUOTAON de quotactl_fd() solo es adecuada para trabajar con inodos del sistema ocultos.
Esta operación requiere privilegios (CAP_SYS_ADMIN).
Q_QUOTAOFF
Desactiva las cuotas para un sistema de archivos. Los argumentos addr e id se ignoran. Esta operación requiere privilegios (CAP_SYS_ADMIN).
Q_GETQUOTA
Obtiene los límites de cuota de disco y el uso actual para el usuario o grupo id. El argumento addr es un puntero a una estructura dqblk definida en <sys/quota.h> como sigue:

/* uint64_t es un entero sin signo de 64 bits;
   uint32_t es un entero sin signo de 32 bits */
struct dqblk {      /* Definición desde Linux 2.4.22 */
    uint64_t dqb_bhardlimit;  /* Límite absoluto para
                                 bloques de cuota de disco asignados */
    uint64_t dqb_bsoftlimit;  /* Límite preferente para
                                 bloques de cuota de disco */
    uint64_t dqb_curspace;    /* Espacio ocupado actual
                                 (en bytes) */
    uint64_t dqb_ihardlimit;  /* Número máximo de
                                 inodes asignados */
    uint64_t dqb_isoftlimit;  /* Límite preferente de inodes */
    uint64_t dqb_curinodes;   /* Número actual de
                                 inodes asignados */
    uint64_t dqb_btime;       /* Límite de tiempo para uso
                                 excesivo de disco */
    uint64_t dqb_itime;       /* Límite de tiempo para uso
                                 excesivo de archivos */
    uint32_t dqb_valid;       /* Máscara de bits de las
                                 constantes QIF_* */
};
/* Banderas en dqb_valid que indican qué campos en
   la estructura dqblk son válidos.  */
#define QIF_BLIMITS   1
#define QIF_SPACE     2
#define QIF_ILIMITS   4
#define QIF_INODES    8
#define QIF_BTIME     16
#define QIF_ITIME     32
#define QIF_LIMITS    (QIF_BLIMITS | QIF_ILIMITS)
#define QIF_USAGE     (QIF_SPACE | QIF_INODES)
#define QIF_TIMES     (QIF_BTIME | QIF_ITIME)
#define QIF_ALL       (QIF_LIMITS | QIF_USAGE | QIF_TIMES)

El campo dqb_valid es una máscara de bits que se establece para indicar las entradas en la estructura dqblk que son válidas. Actualmente, el kernel rellena todas las entradas de la estructura dqblk y las marca como válidas en el campo dqb_valid. Los usuarios sin privilegios solo pueden recuperar sus propias cuotas; un usuario privilegiado (CAP_SYS_ADMIN) puede recuperar las cuotas de cualquier usuario.
Q_GETNEXTQUOTA (desde Linux 4.6)
Esta operación es la misma que Q_GETQUOTA, pero devuelve información de cuota para el siguiente ID mayor o igual a id que tenga una cuota establecida.
El argumento addr es un puntero a una estructura nextdqblk cuyos campos son como los de dqblk, excepto por la adición de un campo dqb_id que se utiliza para devolver el ID para el que se está devolviendo la información de cuota:

struct nextdqblk {
    uint64_t dqb_bhardlimit;
    uint64_t dqb_bsoftlimit;
    uint64_t dqb_curspace;
    uint64_t dqb_ihardlimit;
    uint64_t dqb_isoftlimit;
    uint64_t dqb_curinodes;
    uint64_t dqb_btime;
    uint64_t dqb_itime;
    uint32_t dqb_valid;
    uint32_t dqb_id;
};

Q_SETQUOTA
Establece la información de cuota para el usuario o grupo id, utilizando la información proporcionada en la estructura dqblk apuntada por addr. El campo dqb_valid de la estructura dqblk indica qué entradas en la estructura han sido establecidas por el llamante. Esta operación reemplaza las operaciones Q_SETQLIM y Q_SETUSE de las interfaces de cuota anteriores. Esta operación requiere privilegios (CAP_SYS_ADMIN).
Q_GETINFO (desde Linux 2.4.22)
Obtener información (como tiempos de gracia) sobre el archivo de cuotas. El argumento addr debería ser un puntero a una estructura dqinfo. Esta estructura se define en <sys/quota.h> de la siguiente manera:

/* uint64_t es un entero sin signo de 64 bits;
   uint32_t es un entero sin signo de 32 bits */
struct dqinfo {         /* Definido desde Linux 2.4.22 */
    uint64_t dqi_bgrace;  /* Tiempo antes de que el límite blando de bloques
                             se convierta en límite estricto */
    uint64_t dqi_igrace;  /* Tiempo antes de que el límite blando de inodos
                             se convierta en límite estricto */
    uint32_t dqi_flags;   /* Banderas para el archivo de cuotas
                             (DQF_*) */
    uint32_t dqi_valid;
};
/* Bits para dqi_flags */
/* Formato de cuota QFMT_VFS_OLD */
#define DQF_ROOT_SQUASH (1 << 0) /* Squash de root habilitado */
              /* Antes de Linux v4.0, esto se había definido
                 privadamente como V1_DQF_RSQUASH */
/* Formato de cuota QFMT_VFS_V0 / QFMT_VFS_V1 */
#define DQF_SYS_FILE    (1 << 16)   /* Cuota almacenada en
                                       un archivo del sistema */
/* Banderas en dqi_valid que indican qué campos en
   la estructura dqinfo son válidos.  */
#define IIF_BGRACE  1
#define IIF_IGRACE  2
#define IIF_FLAGS   4
#define IIF_ALL     (IIF_BGRACE | IIF_IGRACE | IIF_FLAGS)

El campo dqi_valid en la estructura dqinfo indica las entradas de la estructura que son válidas. Actualmente, el kernel completa todas las entradas de la estructura dqinfo y las marca todas como válidas en el campo dqi_valid. El argumento id se ignora.
Q_SETINFO (desde Linux 2.4.22)
Establecer información sobre el archivo de cuotas. El argumento addr debería ser un puntero a una estructura dqinfo. El campo dqi_valid de la estructura dqinfo indica las entradas de la estructura que han sido establecidas por el llamador. Esta operación reemplaza las operaciones Q_SETGRACE y Q_SETFLAGS en las interfaces de cuotas anteriores. El argumento id se ignora. Esta operación requiere privilegios (CAP_SYS_ADMIN).
Q_GETFMT (desde Linux 2.4.22)
Obtener el formato de cuota utilizado en el sistema de archivos especificado. El argumento addr debería ser un puntero a un búfer de 4 bytes donde se almacenará el número de formato.
Q_SYNC
Actualizar la copia en disco de los usos de cuotas para un sistema de archivos. Para quotactl(), si special es NULL, se sincronizan todos los sistemas de archivos con cuotas activas. (quotactl_fd() siempre sincroniza solo un sistema de archivos). En ambos casos, los argumentos addr e id se ignoran.
Q_GETSTATS (soportado hasta Linux 2.4.21)
Obtener estadísticas y otra información genérica sobre el subsistema de cuotas. El argumento addr debería ser un puntero a una estructura dqstats en la que se deben almacenar los datos. Esta estructura se define en <sys/quota.h>. Los argumentos special e id se ignoran.
Esta operación es obsoleta y se eliminó en Linux 2.4.22. Los archivos en /proc/sys/fs/quota/ transportan la información en su lugar.

Para los sistemas de archivos XFS que utilizan el Gestor de Cuotas XFS (XQM), las operaciones anteriores se omiten y se utilizan las siguientes operaciones:

Q_XQUOTAON
Activar las cuotas para un sistema de archivos XFS. XFS proporciona la capacidad de activar/desactivar la aplicación de límites de cuota con contabilidad de cuotas. Por lo tanto, XFS espera que addr sea un puntero a un unsigned int que contiene una combinación bit a bit de las siguientes banderas (definidas en <xfs/xqm.h>):

XFS_QUOTA_UDQ_ACCT  /* Contabilidad de cuotas de usuario */
XFS_QUOTA_UDQ_ENFD  /* Aplicación de límites de cuotas de usuario */
XFS_QUOTA_GDQ_ACCT  /* Contabilidad de cuotas de grupo */
XFS_QUOTA_GDQ_ENFD  /* Aplicación de límites de cuotas de grupo */
XFS_QUOTA_PDQ_ACCT  /* Contabilidad de cuotas de proyecto */
XFS_QUOTA_PDQ_ENFD  /* Aplicación de límites de cuotas de proyecto */

Esta operación requiere privilegios (CAP_SYS_ADMIN). El argumento id se ignora.
Q_XQUOTAOFF
Desactivar las cuotas para un sistema de archivos XFS. Al igual que con Q_QUOTAON, los sistemas de archivos XFS esperan un puntero a un unsigned int que especifica si la contabilidad de cuotas y/o la aplicación de límites deben desactivarse (utilizando las mismas banderas que para la operación Q_XQUOTAON). Esta operación requiere privilegios (CAP_SYS_ADMIN). El argumento id se ignora.
Q_XGETQUOTA
Obtener los límites de cuota de disco y el uso actual para el usuario id. El argumento addr es un puntero a una estructura fs_disk_quota, que se define en <xfs/xqm.h> de la siguiente manera:

/* Todas las unidades de bloques están en BBs (Bloques Básicos) de
   512 bytes.  */
#define FS_DQUOT_VERSION  1  /* fs_disk_quota.d_version */
#define XFS_USER_QUOTA    (1<<0)  /* Tipo de cuota de usuario */
#define XFS_PROJ_QUOTA    (1<<1)  /* Tipo de cuota de proyecto */
#define XFS_GROUP_QUOTA   (1<<2)  /* Tipo de cuota de grupo */
struct fs_disk_quota {
    int8_t   d_version;   /* Versión de esta estructura */
    int8_t   d_flags;     /* XFS_{USER,PROJ,GROUP}_QUOTA */
    uint16_t d_fieldmask; /* Especificador de campo */
    uint32_t d_id;        /* ID de usuario, proyecto o grupo */
    uint64_t d_blk_hardlimit; /* Límite absoluto de
                                 bloques de disco */
    uint64_t d_blk_softlimit; /* Límite preferido de
                                 bloques de disco */
    uint64_t d_ino_hardlimit; /* Número máximo de inodos
                                 asignados */
    uint64_t d_ino_softlimit; /* Límite preferido de inodos */
    uint64_t d_bcount;    /* Número de bloques de disco propiedad del
                             usuario */
    uint64_t d_icount;    /* Número de inodos propiedad del
                             usuario */
    int32_t  d_itimer;    /* Cero si está dentro de los límites de inodos */
                          /* Si no, rechazamos el servicio */
    int32_t  d_btimer;    /* Similar a lo anterior; para
                             bloques de disco */
    uint16_t d_iwarns;    /* Número de advertencias emitidas con
                             respecto al número de inodos */
    uint16_t d_bwarns;    /* Número de advertencias emitidas con
                             respecto a los bloques de disco */
    int32_t  d_padding2;  /* Relleno - para uso futuro */
    uint64_t d_rtb_hardlimit; /* Límite absoluto de bloques de disco
                                 en tiempo real (RT) */
    uint64_t d_rtb_softlimit; /* Límite preferido de bloques de disco
                                 en tiempo real (RT) */
    uint64_t d_rtbcount;  /* Número de bloques en tiempo real propiedad */
    int32_t  d_rtbtimer;  /* Similar a lo anterior; para bloques de disco
                             en tiempo real (RT) */
    uint16_t d_rtbwarns;  /* Número de advertencias emitidas con
                             respecto a los bloques de disco en tiempo real (RT) */
    int16_t  d_padding3;  /* Relleno - para uso futuro */
    char     d_padding4[8];   /* Aún más relleno */
};

Los usuarios sin privilegios solo pueden recuperar sus propias cuotas; un usuario con privilegios (CAP_SYS_ADMIN) puede recuperar las cuotas de cualquier usuario.
Q_XGETNEXTQUOTA (desde Linux 4.6)
Esta operación es la misma que Q_XGETQUOTA, pero devuelve (en la estructura fs_disk_quota apuntada por addr) información de cuota para el siguiente ID mayor o igual a id que tenga una cuota establecida. Tenga en cuenta que dado que fs_disk_quota ya tiene el campo q_id, no se necesita un tipo de estructura separado (a diferencia de las operaciones Q_GETQUOTA y Q_GETNEXTQUOTA).
Q_XSETQLIM
Establecer los límites de cuota de disco para el usuario id. El argumento addr es un puntero a una estructura fs_disk_quota. Esta operación requiere privilegios (CAP_SYS_ADMIN).
Q_XGETQSTAT
Devuelve información específica de cuotas del sistema de archivos XFS en la estructura fs_quota_stat apuntada por addr. Esto es útil para averiguar cuánto espacio se utiliza para almacenar información de cuotas, y también para obtener el estado de activación/desactivación de cuotas de un sistema de archivos XFS local determinado. La estructura fs_quota_stat en sí se define de la siguiente manera:

#define FS_QSTAT_VERSION 1  /* fs_quota_stat.qs_version */
struct fs_qfilestat {
    uint64_t qfs_ino;       /* Número de inodo */
    uint64_t qfs_nblks;     /* Número de BBs
                               bloques de 512 bytes */
    uint32_t qfs_nextents;  /* Número de extents */
};
struct fs_quota_stat {
    int8_t   qs_version; /* Número de versión para
                            cambios futuros */
    uint16_t qs_flags; /* XFS_QUOTA_{U,P,G}DQ_{ACCT,ENFD} */
    int8_t   qs_pad;   /* No utilizado */
    struct fs_qfilestat qs_uquota;  /* Información de almacenamiento de cuota de usuario
                                       */
    struct fs_qfilestat qs_gquota;  /* Información de almacenamiento de cuota de grupo
                                       */
    uint32_t qs_incoredqs;   /* Número de dquots en memoria */
    int32_t  qs_btimelimit;  /* Límite para el temporizador de bloques */
    int32_t  qs_itimelimit;  /* Límite para el temporizador de inodos */
    int32_t  qs_rtbtimelimit;/* Límite para el temporizador de bloques
                                 RT */
    uint16_t qs_bwarnlimit;  /* Límite para el número de advertencias */
    uint16_t qs_iwarnlimit;  /* Límite para el número de advertencias */
};

El argumento id se ignora.
