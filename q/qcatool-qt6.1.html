QCATOOL(1) Arquitectura Criptográfica de Qt (QCA) QCATOOL(1)

NOMBRE

qcatool - herramienta de línea de comandos para la Arquitectura Criptográfica de Qt

DESCRIPCIÓN

qcatool es una herramienta de línea de comandos para realizar diversas operaciones criptográficas con la Arquitectura Criptográfica de Qt (QCA). qcatool también se puede utilizar para probar y depurar QCA.

USO

qcatool tiene una variedad de opciones y comandos. Solo puedes usar un comando, pero puedes usar varios, uno o ningún comando.

OPCIONES

Como se mencionó anteriormente, todas estas son opcionales y se pueden combinar.

--pass=CONTRASEÑA
Especifica la contraseña a usar. Esta es probablemente una mala idea excepto para pruebas, ya que cualquiera puede leer los argumentos de una aplicación de línea de comandos.
--newpass=CONTRASEÑA
Especifica la nueva contraseña a usar para cambiar la contraseña con los comandos key changepass y keybundle changepass. Esto es probablemente una mala idea excepto para pruebas, ya que cualquiera puede leer los argumentos de una aplicación de línea de comandos.
--nonroots=CERTIFICADOS
Especifica certificados adicionales, no confiables, pero que pueden usarse en la ruta de confianza si se puede establecer una confianza apropiada.
--roots=CERTIFICADOS
Especifica certificados adicionales que pueden usarse como certificados confiables (raíz).
--nosys
Deshabilita el uso de los certificados raíz estándar que proporciona el sistema operativo.
--noprompt
Deshabilita la solicitud de contraseñas/frases de contraseña. Si no proporciona la frase de contraseña en la línea de comandos (con --pass o --newpass), esto hará que qcatool aborte el comando si se requiere una contraseña/frase de contraseña.
--ordered
Si se muestran campos de información de certificado (Nombre Distinguido y Nombre Alternativo del Sujeto), muéstrelos en el mismo orden en que están presentes en el certificado en lugar de en un orden ordenado amigable.
--debug
Habilita salida adicional para ayudar a la depuración.
--log-file=NOMBRE_ARCHIVO
Registra en el archivo especificado.
--log-level=NIVEL
Registra en el nivel especificado. El nivel de registro puede estar entre 0 (ninguno) y 8 (el máximo).
--nobundle
Al firmar S/MIME, no incluya la cadena de certificados del firmante dentro de la firma. Esto resulta en una salida de firma más pequeña, pero requiere que el destinatario tenga todos los certificados necesarios para poder verificarla.

COMANDOS

help, --help, -h
Muestra información de uso (ayuda).
version, --version, -v
Muestra información de versión.
plugins
Lista los plugins disponibles. Usa la opción --debug para obtener más información sobre los plugins que se encuentran y cuáles se cargan realmente.
config save [proveedor]
Guarda la configuración del proveedor. Úsalo para que la configuración predeterminada del proveedor se escriba en almacenamiento persistente, que luego puedes editar manualmente.
config edit [proveedor]
Edita la configuración del proveedor. Los cambios se escriben en almacenamiento persistente.
key make rsa|dsa [bits]
Crea un par de claves
key changepass [K]
Añade/cambia/elimina la frase de contraseña de una clave
cert makereq [K]
Crea una solicitud de certificado (CSR)
cert makeself [K]
Crea un certificado autofirmado
cert makereqadv [K]
Versión avanzada de 'makereq'
cert makeselfadv [K]
Versión avanzada de 'makeself'
cert validate [C]
Valida un certificado
keybundle make [K] [C]
Crea un keybundle
keybundle extract [X]
Extrae certificado(s) y clave
keybundle changepass [X]
Cambia la frase de contraseña de un keybundle
keystore list-stores
Lista todos los almacenes de claves disponibles
keystore list [nombre_almacen]
Lista el contenido de un almacén de claves
keystore monitor
Monitorea la disponibilidad de almacenes de claves
keystore export [E]
Exporta el contenido de una entrada del almacén de claves
keystore exportref [E]
Exporta una referencia de entrada del almacén de claves
keystore addkb [nombre_almacen] [cert.p12]
Añade un keybundle a un almacén de claves
keystore addpgp [nombre_almacen] [key.asc]
Añade una clave PGP a un almacén de claves
keystore remove [E]
Elimina un objeto de un almacén de claves
show cert [C]
Examina un certificado
show req [req.pem]
Examina una solicitud de certificado (CSR)
show crl [crl.pem]
Examina una lista de revocación de certificados (CRL)
show kb [X]
Examina un keybundle
show pgp [P|S]
Examina una clave PGP
message sign pgp|pgpdetach|smime [X|S]
Firma un mensaje
message encrypt pgp|smime [C|P]
Cifra un mensaje
message signencrypt [S] [P]
Firma y cifra un mensaje PGP
message verify pgp|smime
Verifica un mensaje
message decrypt pgp|smime ((X) ...)
Descifra un mensaje (S/MIME necesita X)
message exportcerts
Exporta certificados de un mensaje S/MIME

ARGUMENTOS

Los argumentos de los comandos son los siguientes.

K = clave privada.

C = certificado.

X = keybundle.

P = clave pública PGP.

S = clave secreta PGP.

E = entrada genérica.

Estos deben identificarse por un nombre de archivo o una referencia de almacén de claves ("store:obj").
