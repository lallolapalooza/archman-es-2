NOMBRE

qb_rb_chunk_peek - Leer (sin liberar) el último fragmento.

SINOPSIS

#include <qb/qbrb.h>

ssize_t qb_rb_chunk_peek(
    qb_ringbuffer_t   *rb,          /* instancia del buffer circular */
    /*
     * (salida) un puntero al siguiente fragmento a leer (no copiado).
     */
    void             **data_out,
    int32_t            ms_timeout   /* (entrada) tiempo de espera para nuevos datos.*/
);

PARÁMETROS

rb instancia del buffer circular

data_out (salida) un puntero al siguiente fragmento a leer (no copiado).

ms_timeout (entrada) tiempo de espera para nuevos datos.

DESCRIPCIÓN

Esta función es una forma de acceder al siguiente fragmento sin necesidad de un memcpy(). Puedes leer los datos del fragmento en el lugar.

VALOR DE RETORNO

el tamaño del fragmento (0 si el búfer está vacío).

NOTA

Esta función no "extraerá" el fragmento, necesitarás llamar a qb_rb_chunk_reclaim().
