NOMBRE

qmt_rgb2pct - un reemplazo de rgb2pct que no necesita python

SINOPSIS

qmt_rgb2pct [ -v | --version ] [ -h | --help ] [ -n | --ncolors <número>] [ -p | --pct <archivo>] [ -s | --sct <archivo>] fuente destino

DESCRIPCIÓN

Convierte archivos GeoTiff con esquema de color RGB o RGBA a un GeoTiff con difuminado y tabla de colores.

Características principales:
- Lectura opcional de tabla de colores externa
- Guardado opcional de tabla de colores externa
- Conversión de banda alfa a valor sin datos

OPCIONES

-h, --help
Muestra esta ayuda.
-v, --version
Muestra información de la versión.

-n, --ncolors <número>
Número de colores. (predeterminado: 255)

-p, --pct <archivo>
Archivo de paleta de entrada para la tabla de colores (*.vrt)

-s, --sct <archivo>
Guarda la tabla de colores en un archivo de paleta (*.vrt)

fuente
Archivo fuente.

destino
Archivo destino.
