QUOTAON(8) Manual del Administrador del Sistema QUOTAON(8)

NOMBRE

quotaon, quotaoff - activar y desactivar cuotas de sistema de archivos

SINOPSIS

quotaon [ -vugfp ] [ -F nombre-formato ] sistema-de-archivos...
quotaon [ -avugPfp ] [ -F nombre-formato ]

quotaoff [ -vugPp ] [ -x estado ] sistema-de-archivos...
quotaoff [ -avugp ]

DESCRIPCIÓN

quotaon

quotaon anuncia al sistema que las cuotas de disco deben activarse en uno o más sistemas de archivos. Los archivos de cuota del sistema de archivos deben estar presentes en el directorio raíz del sistema de archivos especificado y llamarse aquota.user (para cuotas de usuario versión 2), quota.user (para cuotas de usuario versión 1), aquota.group (para cuotas de grupo versión 2), o quota.group (para cuotas de grupo versión 1).

Los sistemas de archivos XFS son un caso especial: XFS considera la información de cuotas como metadatos del sistema de archivos y utiliza el registro para proporcionar un mayor nivel de garantía de consistencia. Hay dos componentes en el sistema de cuotas de disco XFS: contabilidad y aplicación de límites. Los sistemas de archivos XFS requieren que la contabilidad de cuotas se active en el momento del montaje. Es posible activar y desactivar la aplicación de límites en un sistema de archivos XFS una vez que la contabilidad de cuotas ya está activada. El valor por defecto es activar tanto la contabilidad como la aplicación de límites.

La implementación de cuotas XFS no mantiene la información de cuotas en archivos visibles por el usuario, sino que almacena esta información internamente.

quotaoff

quotaoff anuncia al sistema que las cuotas de disco deben desactivarse en los sistemas de archivos especificados.

OPCIONES

quotaon

-F, --formato=nombre-formato
Reporta cuotas para el formato especificado (es decir, no realizar autodetectado del formato). Los nombres de formato posibles son: vfsold Formato de cuotas original con UID/GID de 16 bits, vfsv0 Formato de cuotas con UID/GID de 32 bits, uso de espacio de 64 bits, uso e límites de inodos de 32 bits, vfsv1 Formato de cuotas con límites y uso de cuotas de 64 bits, xfs (cuota en sistema de archivos XFS)
-a, --all
Todas las cuotas de los sistemas de archivos no-NFS montados automáticamente (sin opción noauto) en /etc/fstab se activarán. Esto se usa normalmente en el arranque para habilitar cuotas.
-v, --verbose
Muestra un mensaje para cada sistema de archivos donde se activan las cuotas.
-u, --usuario
Manipula cuotas de usuario. Este es el valor por defecto.
-g, --grupo
Manipula cuotas de grupo.
-P, --proyecto
Manipula cuotas de proyecto.
-p, --imprimir-estado
En lugar de activar las cuotas, simplemente imprime el estado de las cuotas (es decir, si la cuota está activada o desactivada).
-x, --comando-xfs enforce
Activa la aplicación de límites para sistemas de archivos XFS. Esta es la acción por defecto para cualquier sistema de archivos XFS. Esta opción solo es aplicable a XFS y se ignora silenciosamente para otros tipos de sistemas de archivos.
-f, --off
Hace que quotaon se comporte como si fuera llamado como quotaoff.

quotaoff

-F, --formato=nombre-formato
Reporta cuotas para el formato especificado (es decir, no realizar autodetectado del formato). Los nombres de formato posibles son: vfsold (cuotas versión 1), vfsv0 (cuotas versión 2), xfs (cuota en sistema de archivos XFS)
-a, --all
Fuerza la desactivación de cuotas en todos los sistemas de archivos en /etc/fstab.
-v, --verbose
Muestra un mensaje para cada sistema de archivos afectado.
-u, --usuario
Manipula cuotas de usuario. Este es el valor por defecto.
-g, --grupo
Manipula cuotas de grupo.
-P, --proyecto
Manipula cuotas de proyecto.
-p, --imprimir-estado
En lugar de desactivar las cuotas, simplemente imprime el estado de las cuotas (es decir, si la cuota está activada o desactivada).
-x, --comando-xfs delete
Libera el espacio utilizado para mantener la información de cuotas (mantenida internamente) dentro de XFS. Esta opción solo es aplicable a XFS y se ignora silenciosamente para otros tipos de sistemas de archivos. Solo se puede usar en un sistema de archivos con cuotas previamente desactivadas.
-x, --comando-xfs enforce
Desactiva la aplicación de límites para sistemas de archivos XFS (realiza solo contabilidad de cuotas). Esta es la acción por defecto para cualquier sistema de archivos XFS. Esta opción solo es aplicable a XFS y se ignora silenciosamente para otros tipos de sistemas de archivos.
-x, --comando-xfs account
Esta opción se puede usar para desactivar la contabilidad de cuotas. No es posible activar la contabilidad de cuotas con las herramientas de cuotas. Utilice mount(8) para ello. Esta opción solo es aplicable a sistemas de archivos XFS y se ignora silenciosamente para otros tipos de sistemas de archivos.

NOTAS SOBRE SISTEMAS DE ARCHIVOS XFS

Para activar las cuotas en un sistema de archivos XFS, use la opción de montaje mount(8) o /etc/fstab para activar tanto la contabilidad como la aplicación de límites. La utilidad quotaon no se puede utilizar para este propósito.

Activar las cuotas en un sistema de archivos raíz XFS requiere que las opciones de montaje de cuotas se pasen al kernel en el arranque a través de la opción de arranque de Linux rootflags.

Para desactivar la aplicación de límites de cuotas en cualquier sistema de archivos XFS, primero asegúrese de que tanto la contabilidad de cuotas como la aplicación de límites estén activadas usando repquota -v sistema-de-archivos. Luego, use quotaoff -v sistema-de-archivos para desactivar la aplicación de límites. Esto se puede hacer mientras el sistema de archivos está montado.

Activar la aplicación de límites de cuotas en un sistema de archivos XFS se logra usando quotaon -v sistema-de-archivos. Esto se puede hacer mientras el sistema de archivos está montado.

ARCHIVOS

aquota.user o aquota.group
Archivo de cuotas en la raíz del sistema de archivos (cuotas versión 2, sistemas de archivos no-XFS)
quota.user o quota.group
Archivo de cuotas en la raíz del sistema de archivos (cuotas versión 1, sistemas de archivos no-XFS)
/etc/fstab
sistemas de archivos por defecto
