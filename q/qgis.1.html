NOMBRE

qgis - Sistema de Información Geográfica QGIS

SINOPSIS

qgis [--snapshot nombre_archivo]
[--lang idioma]
[--project archivo_proyecto]
[--extent xmin,ymin,xmax,ymax]
[--width ancho]
[--height alto]
[--nologo]
[--noplugins]
[--optionspath ruta]
[--configpath ruta]
[--help]
[archivo]...
Consulte OPCIONES para una descripción completa.

DESCRIPCIÓN

QGIS es un Sistema de Información Geográfica (SIG) multiplataforma, libre y de código abierto. Las plataformas soportadas incluyen Linux/Unix, Mac OS X y Microsoft Windows. QGIS soporta formatos vectoriales, ráster y de bases de datos. QGIS tiene licencia bajo la Licencia Pública General de GNU.

Algunas de las características principales incluyen:

*Soporte para tablas PostGIS espacialmente habilitadas
*Soporte para shapefiles, coberturas de ArcInfo, Mapinfo y otros formatos
soportados por OGR
*Soporte ráster para un gran número de formatos
*Identificar entidades
*Mostrar tablas de atributos
*Seleccionar entidades
*Digitalización GRASS
*Etiquetado de entidades

OPCIONES

--snapshot nombre_archivo
Crea una imagen instantánea de las capas especificadas y la guarda en nombre_archivo. La instantánea se guarda en formato PNG.
--lang idioma
Establece el idioma utilizado por QGIS. El idioma se especifica usando la cadena locale que coincide con una de las traducciones soportadas por QGIS. Por ejemplo, para usar la traducción alemana, especifique --lang de
--project nombre_archivo
Carga el archivo de proyecto QGIS especificado. Las capas especificadas en el archivo de proyecto se cargan, las capas se simbolizan y se restaura el extremo de la vista.
--extent xmin,ymin,xmax,ymax
Establece el extremo del mapa inicial pasando las coordenadas de ese rectángulo.
--width ancho
Ancho de la instantánea a emitir
--height alto
Alto de la instantánea a emitir
--nologo
Oculta la pantalla de presentación
--noplugins

No restaura los plugins al inicio. Útil si algunos plugins de terceros hacen que QGIS falle durante el inicio.
--optionspath ruta
Utiliza la ruta QSettings dada
--configpath ruta
Utiliza la ruta dada para toda la configuración del usuario
--help

Muestra ayuda breve sobre el uso.
archivo...
Una lista de uno o más archivos que se cargarán en QGIS al inicio. Los archivos deben consistir en un formato de datos soportado por QGIS y solo se pueden cargar formatos basados en disco usando este método. Esto incluye shapefiles, archivos MapInfo y la mayoría de los formatos ráster. Los almacenes de datos que no se pueden cargar de esta manera incluyen capas PostGIS en una base de datos PostgreSQL y datos vectoriales/ráster GRASS.

ARCHIVOS

~/.config/QGIS/qgis.conf
Archivo de preferencias de QGIS. Este archivo almacena el tamaño/ubicación de las ventanas, plugins cargados, opciones del usuario y otras configuraciones de la aplicación.
