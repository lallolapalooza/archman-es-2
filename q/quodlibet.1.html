NOMBRE

quodlibet - gestor y reproductor de bibliotecas de audio

SINOPSIS

quodlibet [ --print-playing | control ]
exfalso [ directorio ]

DESCRIPCIÓN

Quod Libet es un programa de gestión de música. Proporciona varias formas diferentes de ver tu biblioteca de audio, así como soporte para radio por Internet y feeds de audio. Tiene capacidades extremadamente flexibles de edición y búsqueda de etiquetas de metadatos.

Esta página del manual es solo una referencia breve para Quod Libet. La documentación completa está disponible en https://quodlibet.readthedocs.io/en/latest/guide/index.html.

PORTADAS DE ÁLBUM

Las portadas de álbum deben colocarse en el mismo directorio que las canciones a las que se aplican, y tener "folder", "front", o "cover" en sus nombres de archivo. Si desea almacenar varios álbumes en el mismo directorio pero mantener imágenes de portada distintas, el nombre del archivo de imagen apropiado debe contener el valor de la etiqueta labelid, por ejemplo, COCX-32760 cover.jpg.

ETIQUETAS VINCULADAS

Muchos lugares en Quod Libet le permiten usar "etiquetas vinculadas". Las etiquetas vinculadas son dos nombres de etiqueta unidos con un "~" como "title~version" o "album~part". Las etiquetas vinculadas dan como resultado visualizaciones "bonitas" incluso cuando una de las etiquetas falta; por ejemplo, "title~version" resultará en Title - Version cuando una etiqueta de versión esté presente, pero solo Title cuando no lo esté. Puede vincular cualquier número de etiquetas.

SINTAXIS DE BÚSQUEDA

Todas las cajas de búsqueda de Quod Libet admiten búsquedas avanzadas de las siguientes formas:

etiqueta = valor
etiqueta = !valor
etiqueta = "valor&q

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

SINTAXIS DE BÚSQUEDA

tag = /valor/
tag = &(valor1, valor2)
tag = |(valor1, valor2)
!tag = valor
|(tag1 = valor1, tag2 = valor2)
&(tag1 = valor1, tag2 = valor2)
#(etiqueta_numérica < valor)
#(etiqueta_numérica = valor)
#(etiqueta_numérica > valor)

El postfijo 'c' en cadenas o expresiones regulares hace que la búsqueda distinga entre mayúsculas y minúsculas. Los valores numéricos pueden darse como enteros, números de punto flotante, formato MM:SS, o inglés simple, por ejemplo, "3 days", "2 hours".

Ver https://quodlibet.readthedocs.io/en/latest/guide/searching.html.

Todas las etiquetas internas comienzan con un carácter ~. Las etiquetas internas no numéricas son ~basename, ~dirname, ~filename, ~format, ~length, ~people y ~rating. Las etiquetas internas numéricas son ~#added, ~#bitrate, ~#disc, ~#lastplayed, ~#laststarted, ~#length, ~#mtime, ~#playcount, ~#skipcount y ~#track.

Ver https://quodlibet.readthedocs.io/en/latest/guide/tags/internal_tags.html.

RENOMBRAR ARCHIVOS

Quod Libet te permite renombrar archivos basándose en sus etiquetas. En algunos casos, podrías querer alterar el nombre del archivo dependiendo de si ciertas etiquetas están presentes o ausentes, además de sus valores. Un patrón común podría ser

<tracknumber>. <title~version>

Puedes usar un '|' para solo texto cuando una etiqueta está presente:

<tracknumber|<tracknumber>. ><title~version>

También puedes especificar texto literal para usar si la etiqueta está ausente añadiendo otro '|':

<album|<album>|No Album> - <title>

Ver https://quodlibet.readthedocs.io/en/latest/guide/renaming_files.html.

BACKENDS DE AUDIO

Quod Libet usa GStreamer para la reproducción de audio. Intenta leer tu configuración GStreamer de GConf, pero si falla, recurre a osssink. Puedes cambiar la opción de pipeline en ~/.quodlibet/config para usar un sink diferente, o pasar opciones al sink. Por ejemplo, podrías usar esdsink o alsasink device=hw:1.

Ver https://quodlibet.readthedocs.io/en/latest/guide/playback/backends.html.

ARCHIVOS

~/.quodlibet/songs
Un diccionario Python 'pickled' de metadatos en caché. Borrar este archivo eliminará todas las canciones de tu biblioteca.
~/.quodlibet/config
El archivo de configuración de Quod Libet. Este archivo se sobrescribe cuando Quod Libet se cierra.
~/.quodlibet/current
Un archivo de tipo "clave=valor" que contiene información sobre la canción que se está reproduciendo actualmente.
~/.quodlibet/control
Un FIFO conectado a la instancia del programa iniciada más recientemente. --next, --previous, etc., lo usan para controlar el reproductor.
~/.quodlibet/plugins/
Coloca los plugins aquí.
~/.quodlibet/browsers/
Coloca los navegadores de biblioteca personalizados aquí.

Ver https://quodlibet.readthedocs.io/en/latest/guide/interacting.html.
