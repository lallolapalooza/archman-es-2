NOMBRE

qmqpd - Servidor QMQP de Postfix

SINOPSIS

qmqpd [opciones genéricas del demonio de Postfix]

DESCRIPCIÓN


El servidor QMQP de Postfix recibe un mensaje por conexión. Cada mensaje se canaliza a través del demonio cleanup(8) y se coloca en la cola incoming como un único archivo de cola. El programa espera ser ejecutado desde el gestor de procesos master(8).

El servidor QMQP implementa una política de acceso: solo se permite el uso del servicio a hosts clientes explícitamente autorizados.

SEGURIDAD

El servidor QMQP es moderadamente sensible a la seguridad. Se comunica con clientes QMQP y servidores DNS en la red. El servidor QMQP puede ejecutarse en chroot con un privilegio bajo fijo.

DIAGNÓSTICOS


Los problemas y las transacciones se registran en syslogd(8) o postlogd(8).

ERRORES CONOCIDOS


El protocolo QMQP proporciona solo una respuesta del servidor por entrega de mensaje. Por lo tanto, no es posible rechazar destinatarios individuales.

El protocolo QMQP requiere que el servidor reciba el mensaje completo antes de responder. Si un mensaje está mal formado, o si algún componente de cadena de red es más largo de lo aceptable, Postfix responde inmediatamente y cierra la conexión. Se deja al cliente la gestión de la situación.

PARÁMETROS DE CONFIGURACIÓN

Los cambios en main.cf se capturan automáticamente, ya que los procesos de qmqpd(8) se ejecutan durante un tiempo limitado. Utilice el comando "postfix reload" para acelerar un cambio.

El texto a continuación proporciona solo un resumen de los parámetros. Consulte postconf(5) para obtener más detalles, incluidos ejemplos.

DESCRIPCIÓN

El demonio qmqpd implementa el protocolo QMQP (Quick Mail Gateway Protocol). Se utiliza como un servidor QMQP para recibir correo de un cliente QMQP (por ejemplo, Postfix sendmail(1) o el comando endmail(1) de ezmlm).

El demonio qmqpd no tiene una interfaz de línea de comandos interactiva.

SEGURIDAD

El demonio qmqpd espera correo no solicitado de clientes QMQP. Por lo tanto, debe configurarse cuidadosamente para que solo acepte correo de hosts de confianza.

Consulte la documentación de Postfix sobre el control de acceso a la red para obtener detalles.

DIAGNÓSTICO

Los mensajes de error del demonio qmqpd se enviarán al registro del sistema (syslogd).

ERRORES

No se conocen errores.
