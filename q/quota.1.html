QUOTA(1) Manual de comandos generales QUOTA(1)

NOMBRE

quota - mostrar uso y límites de disco

SINOPSIS

quota [ -F nombre-formato ] [ -guqvswi ] [ -l | [ -QAm ]]
quota [ -F nombre-formato ] [ -qvswi ] [ -l | [ -QAm ]] -u usuario...
quota [ -F nombre-formato ] [ -qvswi ] [ -l | [ -QAm ]] -g grupo...
quota [ -F nombre-formato ] [ -qvswi ] [ -l | [ -QAm ]] -P proyecto...
quota [ -F nombre-formato ] [ -qvugQm ] -f sistema-archivos...

DESCRIPCIÓN

quota muestra el uso y los límites de disco de los usuarios. Por defecto, solo se imprimen las cuotas de usuario. Por defecto, el uso del espacio y los límites se muestran en kbytes (y se denominan bloques por razones históricas).

quota informa de las cuotas de todos los sistemas de archivos listados en /etc/mtab. Para los sistemas de archivos montados con NFS, se realiza una llamada a rpc.rquotad en la máquina servidora para obtener la información.

OPCIONES

-F, --formato=nombre-formato
Muestra la cuota para el formato especificado (es decir, no realiza autodetcción del formato). Los nombres de formato posibles son: vfsold Formato de cuota original con UIDs / GIDs de 16 bits, vfsv0 Formato de cuota con UIDs / GIDs de 32 bits, uso de espacio de 64 bits, uso y límites de inodos de 32 bits, vfsv1 Formato de cuota con límites y uso de cuota de 64 bits, rpc (cuota sobre NFS), xfs (cuota en sistema de archivos XFS)
-g, --grupo
Imprime las cuotas de grupo para el grupo del que el usuario es miembro. El argumento opcional grupo restringe la visualización a los grupos especificados.
-u, --usuario
la bandera es equivalente al valor predeterminado.
-P, --proyecto
Imprime las cuotas de proyecto para el proyecto especificado.
-v, --verbose
mostrará las cuotas en los sistemas de archivos donde no se asigna almacenamiento.
-s, --human-readable[=unidades]
la opción hará que quota(1) intente elegir unidades para mostrar los límites, el espacio usado y los inodos usados. Las unidades también se pueden especificar explícitamente mediante un argumento opcional en formato [ kgt ],[ kgt ] donde el primer carácter especifica las unidades de espacio y el segundo carácter especifica las unidades de inodo.
--always-resolve
Siempre intente traducir el nombre de usuario / grupo a uid / gid, incluso si el nombre está compuesto solo de dígitos.
-p, --raw-grace
Cuando el usuario está en período de gracia, informa el tiempo en segundos desde la época en que expira (o ha expirado) su tiempo de gracia. El campo es '0' cuando no hay tiempo de gracia activo. Esto es especialmente útil al analizar la salida por un script.
-i, --no-autofs
ignorar los puntos de montaje montados por el montador automático
-l, --local-only
informar cuotas solo en sistemas de archivos locales (es decir, ignorar los sistemas de archivos montados con NFS).
-A, --all-nfs
informar cuotas para todos los sistemas de archivos NFS, incluso si informan estar en el mismo dispositivo.
-f, --filesystem-list
informar cuotas solo para los sistemas de archivos especificados en la línea de comandos.
--filesystem=ruta
informar cuotas solo para el sistema de archivos ruta. Esta opción se puede especificar varias veces y se informarán cuotas para cada sistema de archivos especificado. A diferencia de la opción de línea de comandos -f, los argumentos restantes como comandos aún se tratan como nombres de usuario / grupo / proyecto para informar.
-m, --no-mixed-pathnames
Actualmente, los nombres de ruta de los puntos de montaje NFSv4 se envían sin una barra inicial en la ruta. rpc.rquotad utiliza esto para reconocer los montajes NFSv4 y anteponer correctamente la pseudoraíz del sistema de archivos NFS a la ruta. Si especifica esta opción, quota siempre enviará rutas con una barra inicial. Esto puede ser útil por razones de compatibilidad, pero tenga en cuenta que la cuota sobre RPC dejará de funcionar si está utilizando el nuevo rpc.rquotad.
-q, --quiet
Imprime un mensaje más breve, que contiene solo información sobre los sistemas de archivos que están fuera de cuota.
-Q, --quiet-refuse
No imprima un mensaje de error si la conexión con rpc.rquotad es rechazada (normalmente esto ocurre cuando rpc.rquotad no se está ejecutando en el servidor).
-w, --no-wrap
No envuelva la línea si el nombre del dispositivo es demasiado largo. Esto puede ser útil al analizar la salida de quota(1) por un script.
--show-mntpoint
Mostrar también el punto de montaje como identificación del sistema de archivos.
--hide-device
No mostrar el nombre del dispositivo en la identificación de un sistema de archivos.

Especificar tanto -g como -u muestra tanto las cuotas de usuario como las cuotas de grupo (para el usuario).

Solo el superusuario puede usar la bandera -u y el argumento opcional usuario para ver los límites de otros usuarios. Además, la visualización del uso y los límites de cuota de proyecto está limitada solo al superusuario. Los usuarios no superusuarios pueden usar la bandera -g y el argumento opcional grupo para ver solo los límites de los grupos de los que son miembros.

La bandera -q tiene prioridad sobre la bandera -v.

DIAGNÓSTICO

Si quota finaliza con un estado distinto de cero, uno o más sistemas de archivos están fuera de cuota.

ARCHIVOS

aquota.user o aquota.group
archivo de cuota en la raíz del sistema de archivos (cuota versión 2, sistemas de archivos no-XFS)
quota.user o quota.group
archivo de cuota en la raíz del sistema de archivos (cuota versión 1, sistemas de archivos no-XFS)
/etc/mtab
sistemas de archivos predeterminados
