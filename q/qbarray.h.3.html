QBARRAY.H(3) Manual del programador de libqb QBARRAY.H(3)

NOMBRE

qbarray.h - Este es un array dinámico (puede crecer, pero sin mover memoria).

SINOPSIS

#include <qb/qbarray.h>

DESCRIPCIÓN

arr = qb_array_create_2(64, sizeof(struct my_struct), 256);
...
res = qb_array_index(arr, idx, (void**)&my_ptr);
if (res < 0) {
     return res;
}
// usa my_ptr, ahora incluso si hay un crecimiento, este puntero será válido.

Actualmente, este tipo de dato abstracto de array dinámico solo puede alojar 2^QB_ARRAY_MAX_INDEX_BITS elementos, y con indexación estándar basada en cero, esto da un rango de índice válido [0, QB_ARRAY_MAX_ELEMENTS), donde la notación denota que se incluye el principio del intervalo y se excluye el final. En otras palabras, el espacio del cliente debe evitar un error al confiar únicamente en el tipo del parámetro max_elements de qb_array_create y/o del parámetro idx de qb_array_index (estos tipos entran en conflicto, de todos modos).

VER TAMBIÉN
