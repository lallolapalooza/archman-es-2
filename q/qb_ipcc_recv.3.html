QB_IPCC_RECV(3) Manual del programador de libqb QB_IPCC_RECV(3)

NOMBRE

qb_ipcc_recv - Recibir una respuesta.

SINOPSIS

#include <qb/qbipcc.h>

ssize_t qb_ipcc_recv(
    qb_ipcc_connection_t   *c,           /* instancia de conexión */
    void                   *msg_ptr,     /* puntero a un buffer de mensaje para recibir */
    size_t                  msg_len,     /* el tamaño del buffer */
    int32_t                 ms_timeout   /* tiempo máximo de espera para una respuesta */
);

PARÁMETROS

c instancia de conexión

msg_ptr puntero a un buffer de mensaje para recibir

msg_len el tamaño del buffer

ms_timeout tiempo máximo de espera para una respuesta

DESCRIPCIÓN

VALOR DE RETORNO

(tamaño recibido, -errno == error)

NOTA

que msg_ptr incluirá una qb_ipc_response_header al principio del mensaje.
