NOMBRE

qpdf - software de transformación de PDF

SINOPSIS

qpdf [ opciones ] nombre_archivo_entrada [ nombre_archivo_salida ]

DESCRIPCIÓN

El programa qpdf se utiliza para convertir un archivo PDF en otro archivo PDF equivalente. Es capaz de realizar una variedad de transformaciones como la linealización (también conocida como optimización web o visualización web rápida), encriptación y desencriptación de archivos PDF. También tiene muchas opciones para inspeccionar o verificar archivos PDF, algunas de las cuales son útiles principalmente para desarrolladores de PDF.

Para un resumen de las opciones de qpdf, ejecute qpdf --help. Un manual completo se puede encontrar en https://qpdf.readthedocs.io.

USO (invocación básica)

Lee un archivo PDF, aplica transformaciones o modificaciones y escribe un nuevo archivo PDF.

Uso: qpdf [archivo_entrada] [opciones] [archivo_salida]
O qpdf --help[={tema|--opción}]

•
archivo_entrada, opciones y archivo_salida pueden estar en cualquier orden siempre que archivo_entrada preceda a archivo_salida.
•
Use --empty en lugar de un archivo de entrada para una entrada vacía de cero páginas.
•
Use --replace-input en lugar de un archivo de salida para sobrescribir el archivo de entrada con la salida.
•
archivo_salida puede ser - para escribir en stdout; leer desde stdin no está soportado.
•
@nombre_archivo es un archivo de argumentos; cada línea se trata como un argumento de línea de comandos separado.
•
@- puede usarse para leer argumentos desde stdin.
•
Las opciones posteriores pueden anular las opciones anteriores si son contradictorias.

Opciones relacionadas:

--empty -- usar archivo vacío como entrada
Úselo en lugar de archivo_entrada para una entrada vacía. Especialmente útil con --pages.
--replace-input -- sobrescribir entrada con salida
Úselo en lugar de archivo_salida para sobrescribir el archivo de entrada con la salida.
--job-json-file -- archivo JSON de trabajo
--job-json-file=archivo

Especifique el nombre de un archivo cuyo contenido se espera que contenga un archivo JSON QPDFJob. Ejecute qpdf --job-json-help para obtener una descripción del formato del archivo de entrada JSON.

ESTADO DE SALIDA (significados de los códigos de salida de qpdf)

Significado de los códigos de salida:

•
0: sin errores ni advertencias
•
1: no utilizado por qpdf pero puede ser utilizado por el shell si no puede invocar qpdf
•
2: errores detectados
•
3: advertencias detectadas, a menos que se proporcione --warning-exit-0

Opciones relacionadas:

--warning-exit-0 -- salir con 0 incluso con advertencias
Use el estado de salida 0 en lugar de 3 cuando haya advertencias presentes. Cuando se combina con --no-warn, las advertencias se ignoran por completo.

COMPLETADO (completado del shell)

El completado del shell es compatible con bash y zsh. Use eval $(qpdf --completion-bash) o eval $(qpdf --completion-zsh) para habilitarlo. La variable de entorno QPDF_EXECUTABLE anula la ruta a qpdf que estos comandos generan.

Opciones relacionadas:

--completion-bash -- habilitar completado de bash
Genera un comando que habilita el completado de bash.
--completion-zsh -- habilitar completado de zsh
Genera un comando que habilita el completado de zsh.

Las opciones generales controlan el comportamiento de qpdf de maneras que no están directamente relacionadas con la operación que está realizando.

Opciones relacionadas:

--password -- contraseña para archivo encriptado
--password=contraseña

--password-file -- leer contraseña de un archivo
--password-file=nombre_archivo

La primera línea del archivo especificado se utiliza como contraseña. Se utiliza en lugar de la opción --password.

--verbose -- imprimir información adicional

CONTROL AVANZADO (ajusta el comportamiento de qpdf)

Las opciones de control avanzado controlan el comportamiento de qpdf de maneras que normalmente nunca necesitaría un usuario, pero que pueden ser útiles para desarrolladores o personas que investigan problemas con archivos específicos.

Opciones relacionadas:

--password-is-hex-key -- proporciona clave de cifrado codificada en hexadecimal
Proporciona la clave de cifrado de archivo subyacente como una cadena codificada en hexadecimal en lugar de proporcionar una contraseña. Esta es una opción experta.
--suppress-password-recovery -- no intentes diferentes codificaciones de contraseña
Suprime el comportamiento habitual de qpdf de intentar diferentes codificaciones de una contraseña que contiene caracteres Unicode no ASCII si el primer intento no tiene éxito.
--password-mode -- ajusta cómo qpdf codifica las contraseñas
--password-mode=modo

Ajusta cómo qpdf controla la codificación de contraseñas Unicode. Las opciones válidas son auto, bytes, hex-bytes y unicode.

--suppress-recovery -- suprime la recuperación de errores
Evita intentar la recuperación cuando se encuentran errores en la tabla de referencias cruzadas o en las longitudes de los flujos de un archivo.
--ignore-xref-streams -- usa tablas xref en lugar de flujos
Ignora cualquier flujo xref en el archivo, recurriendo a tablas xref o activando la recuperación del documento.

TRANSFORMACIÓN (realiza cambios estructurales en PDF)

Las opciones a continuación le indican a qpdf que aplique transformaciones que cambian la estructura sin cambiar el contenido.

Opciones relacionadas:

--linearize -- archivos de salida linealizados (optimizados para web)
Crea archivos de salida linealizados (optimizados para web).
--encrypt -- inicia opciones de cifrado
--encrypt [opciones] --

Ejecuta qpdf --help=encryption para obtener detalles.

--decrypt -- elimina el cifrado del archivo de entrada
Crea un archivo de salida sin cifrar, incluso si el archivo de entrada estaba cifrado. Normalmente, qpdf conserva cualquier cifrado presente en el archivo de entrada. Esta opción anula ese comportamiento.
--remove-restrictions -- elimina restricciones de seguridad del archivo de entrada
Elimina las restricciones asociadas con archivos PDF firmados digitalmente. Esto se puede combinar con --decrypt para permitir la edición libre de archivos previamente firmados/cifrados. Esta opción invalida y deshabilita cualquier firma digital, pero deja intactas sus apariencias visuales.
--copy-encryption -- copia los detalles de cifrado de otro archivo
--copy-encryption=archivo

Copia los detalles de cifrado del archivo especificado en lugar de conservar el cifrado del archivo de entrada. Usa --encryption-file-password para especificar la contraseña del archivo de cifrado.

--encryption-file-password -- proporciona contraseña para --copy-encryption
--encryption-file-password=contraseña

Si el archivo especificado en --copy-encryption requiere una contraseña, utiliza esta opción para proporcionar la contraseña.

--qdf -- permite ver el código PDF en un editor de texto
Crea un archivo PDF adecuado para verlo en un editor de texto e incluso para editarlo. Esto es para editar el código PDF, no el contenido de la página. Todos los flujos que se pueden descomprimir se descomprimen, y los flujos de contenido se normalizan, entre otros cambios. La herramienta complementaria "fix-qdf" se puede usar para reparar archivos QDF editados manualmente. QDF es una característica específica de la herramienta qpdf. Por favor, consulta el capítulo "Modo QDF" en el manual.
--no-original-object-ids -- omite los ID de objeto originales en qdf
Omite los comentarios en un archivo QDF que indican el ID del objeto que un objeto tenía en el archivo original.
--compress-streams -- comprime flujos sin comprimir
--compress-streams=[s|n]

Establecer --compress-streams=n evita que qpdf comprima los flujos sin comprimir. Esto puede ser útil si estás dejando algunos flujos sin comprimir intencionalmente.

--decode-level -- controla qué flujos descomprimir
--decode-level=parámetro

Al descomprimir flujos, controla qué tipos de esquemas de compresión deben descomprimirse:

•
none: no descomprime nada. Este es el valor predeterminado con --json-output.
•
generalized: descomprime flujos comprimidos con un algoritmo de compresión de propósito general. Este es el valor predeterminado excepto cuando se proporciona --json-output.
•
specialized: además de generalized, también descomprime flujos comprimidos con un esquema de compresión de propósito especial pero sin pérdida.
•
all: además de specialized, descomprime flujos comprimidos con esquemas de compresión con pérdida como JPEG (DCT). qpdf no sabe cómo descomprimir todos los esquemas de compresión.
--stream-data -- controla la compresión de flujos
--stream-data=parámetro

Esta opción controla cómo se comprimen los flujos en la salida. Es menos granular que las opciones más nuevas, --compress-streams y --decode-level.

Parámetros:

•
compress: igual que --compress-streams=s --decode-level=generalized
•
preserve: igual que --compress-streams=n --decode-level=none
•
uncompress: igual que --compress-streams=n --decode-level=generalized
--recompress-flate -- descomprime y vuelve a comprimir flate
El esquema de compresión general predeterminado utilizado por PDF es flate, que es el mismo que se usa en zip y gzip. Normalmente, qpdf simplemente los deja en paz. Esta opción le indica a qpdf que descomprima y vuelva a comprimir los flujos comprimidos con flate. Esto puede ser útil cuando se combina con --compression-level.
--compression-level -- establece el nivel de compresión para flate
--compression-level=nivel

Establece un nivel de compresión de 1 (mínimo, más rápido) a 9 (máximo, más lento) al comprimir archivos con flate (utilizado en zip y gzip), que es la compresión predeterminada para la mayoría de los archivos PDF. Necesitas --recompress-flate junto con esta opción si quieres cambiar flujos ya comprimidos.

--jpeg-quality -- establece el nivel de calidad jpeg para jpeg
--jpeg-quality=nivel

Al reescribir imágenes con --optimize-images, establece un nivel de calidad de 0 (más bajo) a 100 (más alto) para escribir nuevas imágenes. Una calidad más alta da como resultado imágenes más grandes, y una calidad más baja da como resultado imágenes más pequeñas. Esta opción solo es efectiva cuando se combina con --optimize-images.

--normalize-content -- corrige saltos de línea en flujos de contenido
--normalize-content=[s|n]

Normaliza los saltos de línea a saltos de línea estilo UNIX en los flujos de contenido PDF, lo cual es útil para verlos en un editor de texto de programador en múltiples plataformas. Esto también se activa con --qdf.

--object-streams -- controla el uso de flujos de objetos
--object-streams=modo

Controla qué hace qpdf con respecto a los flujos de objetos. Opciones:

•
preserve: conserva los flujos de objetos originales, si los hay (el valor predeterminado)
•
disable: crea archivos de salida sin flujos de objetos
•
generate: crea flujos de objetos y comprime objetos cuando sea posible
--preserve-unreferenced -- conserva objetos no referenciados
Conserva todos los objetos del archivo de entrada, incluso si no están referenciados.
--remove-unreferenced-resources -- elimina recursos de página no referenciados
--remove-unreferenced-resources=parámetro

Elimina del diccionario de recursos de una página cualquier recurso que no esté referenciado en el contenido de la página. Parámetros: "auto" (predeterminado), "yes", "no".

--preserve-unreferenced-resources -- usa --remove-unreferenced-resources=no
Sinónimo de --remove-unreferenced-resources=no. Usa ese en su lugar.
--newline-before-endstream -- fuerza un salto de línea antes de endstream
Para un salto de línea adicional antes de endstream. Usar esta opción permite a qpdf conservar PDF/A al reescribir dichos archivos.
--coalesce-contents -- combina flujos de contenido
Si una página tiene una matriz de flujos de contenido, concaténalos en un único flujo de contenido.
--externalize-inline-images -- convierte imágenes en línea a imágenes regulares
Convierte imágenes en línea a imágenes regulares.
--ii-min-bytes -- establece el tamaño mínimo para --externalize-inline-images
--ii-min-bytes=tamaño-en-bytes

No externaliza imágenes en línea más pequeñas que este tamaño. El valor predeterminado es 1024. Usa 0 para no tener mínimo.

--min-version -- establecer versión mínima de PDF
--min-version=versión

Obliga que la versión PDF de la salida sea al menos la versión especificada. El formato del número de versión es "major.minor[.extension-level]", que establece la cabecera de versión a "major.minor" y el nivel de extensión, si se especifica, a "extension-level".

--force-version -- establecer versión de PDF de salida
--force-version=versión

Obliga que la cabecera de versión del archivo PDF de salida sea el valor especificado, incluso si el archivo utiliza características que pueden no estar disponibles en esa versión.

RANGOS DE PÁGINAS (sintaxis de rango de páginas)

Una descripción completa de la sintaxis de rangos de páginas, con ejemplos, se puede encontrar en el manual. En resumen, un rango es una lista separada por comas de grupos. Un grupo es un número o un rango de números separados por un guion. A un grupo se le puede anteponer x para excluir sus miembros del grupo anterior. Un número puede ser uno de:

•
<n> donde <n> representa un número es la página <n>
•
r<n> es la página <n> desde el final
•
z la última página, lo mismo que r1
•
a,b,c páginas a, b, y c
•
a-b páginas de a a b inclusive; si a > b, esto cuenta hacia atrás
•
a-b,xc páginas de a a b excepto la página c
•
a-b,xc-d páginas de a a b excepto las páginas c a d

Puedes añadir :even o :odd para seleccionar cada dos páginas del conjunto resultante de páginas, donde :odd empieza con la primera página y :even empieza con la segunda página. Estas son páginas impares y pares del conjunto resultante, no basadas en los números de página originales.

MODIFICACIÓN (cambiar partes del PDF)

Las opciones de modificación realizan cambios sistemáticos en ciertas partes del PDF, haciendo que el PDF se represente de manera diferente al original.

Opciones relacionadas:

--pages -- inicio de selección de páginas
--pages [--file=]archivo [opciones] [...] --

Ejecuta qpdf --help=page-selection para obtener detalles.

--file -- fuente para páginas
--file=archivo

Especifica el archivo para la operación de página actual. Esto se utiliza con --pages, --overlay, y --underlay y aparece entre la opción y el terminador --. Ejecuta qpdf --help=page-selection para obtener detalles.

--range -- rango de páginas
--range=rango-numérico

Especifica el rango de páginas para la operación de página actual con --pages. Si se omite, se seleccionan todas las páginas. Esto se utiliza con --pages y aparece entre --pages y --. Ejecuta qpdf --help=page-selection para obtener detalles.

--collate -- ordenar con --pages
--collate[=n[,m,...]]

Ordena en lugar de concatenar las páginas especificadas con --pages. Con un parámetro numérico, ordena en grupos de n. El valor predeterminado es 1. Con parámetros numéricos separados por comas, toma n del primer archivo, m del segundo, etc. Ejecuta qpdf --help=page-selection para obtener detalles adicionales.

--split-pages -- escribir páginas en archivos separados
--split-pages[=n]

Esta opción hace que qpdf cree archivos de salida separados para cada página o grupo de páginas en lugar de un único archivo de salida.

Los nombres de archivo se generan a partir del archivo de salida especificado de la siguiente manera:

•
Si la cadena %d aparece en el nombre del archivo de salida, se reemplaza con un rango de páginas rellenado con ceros a partir de 1.
•
De lo contrario, si el nombre del archivo de salida termina en .pdf (sin distinguir mayúsculas y minúsculas), se inserta un rango de páginas rellenado con ceros, precedido por un guion, antes de la extensión del archivo.
•
De lo contrario, al nombre del archivo se le añade un rango de páginas rellenado con ceros precedido por un guion.

Los rangos de páginas son números de página individuales para grupos de una sola página o primero-último para grupos de varias páginas.

--overlay -- inicio de opciones de superposición
--overlay archivo [opciones] --

Superpone páginas de otro archivo PDF sobre la salida. Ejecuta qpdf --help=overlay-underlay para obtener detalles.

--underlay -- inicio de opciones de subposición
--underlay archivo [opciones] --

Coloca páginas de otro archivo PDF debajo de la salida. Ejecuta qpdf --help=overlay-underlay para obtener detalles.

--flatten-rotation -- eliminar rotación del diccionario de página
Para cada página que se rota utilizando la clave /Rotate en el diccionario de la página, elimina la clave /Rotate e implementa la misma semántica de rotación modificando el contenido de la página. Esto puede ser útil si un visor de PDF defectuoso no considera correctamente los metadatos de rotación de página.
--flatten-annotations -- incrustar anotaciones en el contenido
--flatten-annotations=parámetro

Incrusta las anotaciones de página en los flujos de contenido. Esto puede ser necesario en algunos casos al imprimir o dividir archivos. Parámetros: "all", "print", "screen".

--rotate -- rotar páginas
--rotate=[+|-]ángulo[:rango-de-páginas]

Rota las páginas especificadas en múltiplos de 90 grados, especificando ángulos absolutos o relativos. "ángulo" puede ser 0, 90, 180 o 270. Casi siempre querrás usar +ángulo o -ángulo en lugar de solo ángulo, como se explica en el manual. Ejecuta qpdf --help=page-ranges para obtener ayuda con los rangos de páginas.

--generate-appearances -- generar apariencias para campos de formulario
Los campos de formulario PDF constan de valores y apariencias, que pueden ser inconsistentes entre sí si el valor de un campo de formulario se ha modificado sin actualizar su apariencia. Esta opción indica a qpdf que genere nuevos flujos de apariencia. Existen algunas limitaciones, que se explican en el manual.
--optimize-images -- usar compresión eficiente para imágenes
Intenta usar compresión DCT (JPEG) para imágenes que cumplen ciertas restricciones, siempre que hacerlo disminuya el tamaño en bytes de la imagen. Consulte también la ayuda para las siguientes opciones:
--oi-min-width
--oi-min-height
--oi-min-area
--keep-inline-images
--oi-min-width -- ancho mínimo para --optimize-images
--oi-min-width=ancho

No optimices imágenes cuyo ancho sea inferior al valor especificado.

--oi-min-height -- altura mínima para --optimize-images
--oi-min-height=altura

No optimices imágenes cuya altura sea inferior al valor especificado.

--oi-min-area -- área mínima para --optimize-images
--oi-min-area=área-en-píxeles

No optimices imágenes cuya área en píxeles sea inferior al valor especificado.

--keep-inline-images -- excluir imágenes en línea de la optimización
Evita que las imágenes en línea sean consideradas por --optimize-images.
--remove-info -- eliminar información del archivo
Excluye la información del archivo (excepto la fecha de modificación) del archivo de salida.
--remove-metadata -- eliminar metadatos
Excluye los metadatos del archivo de salida.
--remove-page-labels -- eliminar números de página explícitos
Excluye las etiquetas de página (números de página explícitos) del archivo de salida.
--remove-structure -- eliminar metadatos
Excluye el árbol de estructura del archivo de salida.
--set-page-labels -- numerar páginas para todo el documento
--set-page-labels spec-etiqueta ... --

Establece etiquetas de página (números de página explícitos) para todo el archivo. Cada spec-etiqueta tiene el formato

primera-página:[tipo][/prefijo[/inicio]]

donde

•
"primera-página" representa un número de página secuencial utilizando el mismo formato que los rangos de páginas: un número, un número precedido por "r" para indicar la cuenta desde el final, o "z" indicando la última página.
•
"tipo" es uno de: - D: Dígitos arábigos - A: Caracteres alfabéticos mayúsculos - a: Caracteres alfabéticos minúsculos - R: Números romanos mayúsculos - r: Números romanos minúsculos - omitido: el número de página no aparece, aunque el prefijo,
si se especifica, seguirá apareciendo
•
"inicio" debe ser un número >= 1
•
"prefijo" puede ser cualquier cadena y se antepone a cada etiqueta de página.

La primera spec-etiqueta debe tener un valor de primera-página de 1, indicando la primera página del documento. Si se especifican múltiples spec-etiquetas, deben darse en orden creciente.

Si se especifican múltiples spec-etiquetas, deben darse en orden creciente.

Una spec-etiqueta dada hace que las páginas se numeren según ese esquema a partir de primera-página y continuando hasta la siguiente spec-etiqueta o el final del documento. Si desea omitir la numeración a partir de una página determinada, puede usar primera-página: como especificación.

Ejemplo: "1:r 5:D" numeraría las primeras cuatro páginas i a iv, luego las páginas restantes con números arábigos comenzando con 1 y continuando secuencialmente hasta el

final del documento. Para ejemplos adicionales, consulta el manual.

CIFRADO (crear archivos cifrados)

Crea archivos cifrados. Uso:

--encrypt [--user-password=contraseña-usuario] [--owner-password=contraseña-propietario] --bits=longitud-clave [opciones] --

O

--encrypt contraseña-usuario contraseña-propietario longitud-clave [opciones] --

La primera forma, con indicadores para las contraseñas y la longitud de bits, se introdujo en qpdf 11.7.0. Solo la opción --bits es obligatoria. Esta forma te permite usar cualquier texto como contraseña. Si se especifican contraseñas, deben darse antes de la opción --bits.

La segunda forma ha estado en qpdf desde el principio y seguirá siendo compatible. Cualquiera o ambas contraseñas de usuario y propietario pueden ser cadenas vacías.

El parámetro de longitud de clave debe ser 40, 128 o 256. La contraseña de usuario y/o propietario se pueden omitir. Omitir cualquiera de las contraseñas permite abrir el archivo PDF sin contraseña. Especificar el mismo valor para la contraseña de usuario y propietario y especificar una contraseña de propietario vacía se consideran inseguros.

Las opciones de cifrado terminan con "--" por sí solo.

El cifrado de 40 bits no es seguro, al igual que el cifrado de 128 bits sin AES. Usa cifrado de 256 bits a menos que tengas una razón específica para usar un formato inseguro, como pruebas o compatibilidad con visores muy antiguos. Debes usar el indicador --allow-weak-crypto para crear archivos cifrados que usen algoritmos criptográficos inseguros. El indicador --allow-weak-crypto aparece fuera de --encrypt ... -- (antes de --encrypt o después de --).

Las opciones disponibles varían según la longitud de la clave. No todos los lectores respetan todas las restricciones. Diferentes lectores de PDF responden de manera diferente a diversas combinaciones de opciones. A veces, un visor de PDF puede mostrarte restricciones que difieren de lo que seleccionaste. Esto probablemente no sea un error en qpdf.

Opciones para 40 bits solamente:
--annotate=[s|n] Restringe comentarios, relleno de formularios y firma
--extract=[s|n] Restringe la extracción de texto/gráficos
--modify=[s|n] Restringe la modificación del documento
--print=[s|n] Restringe la impresión

Opciones para 128 o 256 bits:
--accessibility=[s|n] Restringe la accesibilidad (generalmente ignorado)
--annotate=[s|n] Restringe los comentarios/relleno de formularios
--assemble=[s|n] Restringe el ensamblaje del documento
--extract=[s|n] Restringe la extracción de texto/gráficos
--form=[s|n] Restringe el relleno de formularios
--modify-other=[s|n] Restringe otras modificaciones
--modify=opcion-modificar Controla el acceso de modificación por nivel
--print=opcion-imprimir Controla el acceso de impresión
--cleartext-metadata Evita el cifrado de metadatos

Para 128 bits solamente:
--use-aes=[s|n] Indica si se debe usar cifrado AES
--force-V4 Fuerza el uso del controlador de cifrado V=4

Para 256 bits solamente:
--force-R5 Fuerza el uso del cifrado R=5 obsoleto
--allow-insecure Permite la contraseña de usuario con contraseña de propietario vacía

Valores para opcion-imprimir:
none No permite la impresión
low Permite solo impresión de baja resolución
full Permite impresión completa

Valores para opcion-modificar:
none Permite ninguna modificación
assembly Permite solo el ensamblaje del documento
form Ensamblaje + relleno de campos de formulario y firma
annotate Formulario + comentarios y modificación de formularios
all Permite modificación completa del documento

Opciones relacionadas:

--user-password -- especificar contraseña de usuario
--user-password=contraseña-usuario

Establece la contraseña de usuario del archivo cifrado.

--owner-password -- especificar contraseña de propietario
--owner-password=contraseña-propietario

Establece la contraseña de propietario del archivo cifrado.

--bits -- especificar longitud de clave de cifrado
--bits={48|128|256}

Especifica la longitud de la clave de cifrado. Para la mejor seguridad, usa siempre una longitud de clave de 256.

--accessibility -- restringir accesibilidad del documento
--accessibility=[s|n]

Esta opción se ignora excepto con formatos de cifrado muy antiguos. La especificación actual de PDF no permite la restricción de la accesibilidad del documento. Esta opción no está disponible con cifrado de 40 bits.

--annotate -- restringir anotación del documento
--annotate=[s|n]

Habilita/deshabilita la modificación de anotaciones, incluidas la realización de comentarios y el relleno de campos de formulario. Para cifrado de 128 y 256 bits, esto también habilita la edición, creación y eliminación de campos de formulario a menos que también se especifique --modify-other=n o --modify=none.

--assemble -- restringir ensamblaje del documento
--assemble=[s|n]

Habilita/deshabilita el ensamblaje del documento (rotación y reordenación de páginas). Esta opción no está disponible con cifrado de 40 bits.

--extract -- restringir extracción de texto/gráficos
--extract=[s|n]

Habilita/deshabilita la extracción de texto/gráficos para fines distintos de la accesibilidad.

--form -- restringir relleno de formularios
--form=[s|n]

Habilita/deshabilita si se permite el relleno de campos de formulario incluso si la modificación de anotaciones está deshabilitada. Esta opción no está disponible con cifrado de 40 bits.

--modify-other -- restringir otras modificaciones
--modify-other=[s|n]

Habilita/deshabilita modificaciones no controladas por --assemble, --annotate o --form. --modify-other=n está implícito por cualquiera de las otras opciones --modify. Esta opción no está disponible con cifrado de 40 bits.

--modify -- restringir modificación del documento
--modify=opcion-modificar

Para archivos de 40 bits, opcion-modificar solo puede ser s o n y controla todos los aspectos de la modificación del documento.

Para cifrado de 128 y 256 bits, los valores de opcion-modificar permiten habilitar y deshabilitar niveles de restricción de manera similar a como lo hacen algunas herramientas de creación de PDF. Los valores de opcion-modificar se mapean a otras combinaciones de opciones de la siguiente manera:

all: permitir modificación completa (predeterminado) annotate: --modify-other=n form: --modify-other=n --annotate=n assembly: --modify-other=n --annotate=n --form=n none: --modify-other=n --annotate=n --form=n --assemble=n

--print -- restringir impresión
--print=opcion-imprimir

Controla qué tipo de impresión está permitido. Para cifrado de 40 bits, opcion-imprimir solo puede ser s o n y habilita o deshabilita toda la impresión. Para cifrado de 128 y 256 bits, opcion-imprimir puede tener los siguientes valores:

none: no permitir impresión low: permitir solo impresión de baja resolución full: permitir impresión completa (predeterminado)

--cleartext-metadata -- no cifrar metadatos
Si se especifica, no cifra los metadatos del documento incluso cuando se cifra el resto del documento. Esta opción no está disponible con cifrado de 40 bits.
--use-aes -- usar AES con cifrado de 128 bits
--use-aes=[s|n]

Habilita/deshabilita el uso del cifrado AES más seguro con cifrado de 128 bits. Especificar --use-aes=s fuerza que la versión del PDF sea al menos 1.6. Esta opción solo está disponible con cifrado de 128 bits. El valor predeterminado es "n" por razones de compatibilidad. Usa cifrado de 256 bits en su lugar.

--allow-insecure -- permitir contraseñas de propietario vacías
Permite la creación de archivos PDF con contraseñas de propietario vacías y contraseñas de usuario no vacías al usar cifrado de 256 bits.
--force-V4 -- forzar V=4 en el diccionario de cifrado
Esta opción es para pruebas y nunca es necesaria en la práctica, ya que qpdf lo hace automáticamente cuando es necesario.
--force-R5 -- usar cifrado R=5 no compatible
Usa un algoritmo de cifrado no documentado, no compatible y obsoleto que solo existió en la versión IX de Acrobat. Esta opción no debe usarse excepto para pruebas de compatibilidad.

SELECCIÓN DE PÁGINAS (seleccionar páginas de uno o más archivos)

Usa la opción --pages para seleccionar páginas de múltiples archivos. Uso:

qpdf in.pdf --pages --file=archivo-entrada [--range=rango-pagina] [--password=contraseña] [...] -- out.pdf

O

qpdf in.pdf --pages archivo-entrada [--password=contraseña] [rango-pagina] [...] -- out.pdf

Entre --pages y el -- que termina la opción de páginas, repite lo siguiente:

--file=nombre-archivo [--range=rango-pagina] [--password=contraseña] [opciones]

Por compatibilidad, el archivo y el rango se pueden especificar posicionalmente. Las versiones de qpdf anteriores a 11.9.0 requieren que --password=contraseña siga inmediatamente al nombre de archivo. En la sintaxis antigua, repite lo siguiente:

nombre-archivo [--password=contraseña] [rango-pagina]

La información a nivel de documento, como esquemas, etiquetas, etc., se toma de in.pdf y se conserva en out.pdf. Puedes usar --empty en lugar de un archivo de entrada para comenzar con un archivo vacío y solo copiar páginas de todos los archivos por igual. Puedes usar "." como atajo para el archivo de entrada principal (si no es --empty). En el ejemplo anterior, "." se referiría a in.pdf.

Usa --password=contraseña para especificar la contraseña de un archivo de entrada protegido con contraseña. Si el mismo archivo de entrada se usa más de una vez, solo necesitas proporcionar la contraseña la primera vez. Si se omite el rango de páginas, se seleccionan todas las páginas.

Ejecuta qpdf --help=page-ranges para obtener ayuda sobre rangos de páginas.

Usa --collate=n para hacer que las páginas se ordenen en grupos de n páginas (predeterminado 1) en lugar de concatenar la entrada. Usa --collate=i,j,k,... para tomar i de la primera, luego j de la segunda, luego k de la tercera, luego i de la primera, etc.

OVERLAY-UNDERLAY (overlay/underlay pages from other PDF files)

Estas opciones permiten que páginas de otro archivo PDF se superpongan o se coloquen debajo de la salida principal. Las páginas superpuestas se dibujan encima de la página de destino y pueden oscurecer la página. Las páginas subyacentes se dibujan debajo de la página de destino. Uso:

{--overlay|--underlay} [--file=]file
[--password=password]
[--to=page-range]
[--from=[page-range]]
[--repeat=page-range]
--

Tenga en cuenta el uso de "--" por sí sola para terminar las opciones de superposición/subyacencia.

Para superponer y subyacer, se especifica un archivo y una contraseña opcional, junto con una serie de rangos de páginas opcionales. El comportamiento predeterminado es que cada página del archivo de superposición o subyacencia se impone en la página correspondiente de la salida principal hasta que se agotan las páginas, y las páginas adicionales se ignoran. También puede dar un rango de páginas con --repeat para que esas páginas se repitan después de que se hayan agotado las páginas originales.

Estas opciones son repetibles. Las páginas se apilarán en el orden de aparición: primero las subyacentes, luego la página original, luego las superpuestas.

Ejecute qpdf --help=page-ranges para obtener ayuda sobre rangos de páginas.

Opciones relacionadas:

--to -- páginas de destino para subyacencia/superposición
--to=page-range

Especifique el rango de páginas en la salida principal para aplicar la superposición/subyacencia. Consulte qpdf --help=page-ranges para obtener ayuda sobre la sintaxis del rango de páginas.

--from -- páginas de origen para subyacencia/superposición
--from=[page-range]

Especifique las páginas del archivo de superposición/subyacencia que se aplican a las páginas de destino. Consulte qpdf --help=page-ranges para obtener ayuda sobre la sintaxis del rango de páginas. El rango de páginas se puede omitir si se usa --repeat.

--repeat -- páginas de superposición/subyacencia para repetir
--repeat=page-range

Especifique las páginas de la superposición/subyacencia que se repiten después de que se hayan agotado las páginas "from". Consulte qpdf --help=page-ranges para obtener ayuda sobre la sintaxis del rango de páginas.

PDF-DATES (PDF date format)

Cuando se requiere una fecha, la fecha debe cumplir con la especificación del formato de fecha PDF, que es "D:yyyymmddhhmmssz" donde "z" es literalmente la letra mayúscula "Z" para UTC o un desplazamiento de zona horaria en el formato "-hh'mm'" o "+hh'mm'". Los desplazamientos de zona horaria negativos indican tiempo antes de UTC. Los desplazamientos positivos indican cuánto después. Por ejemplo, la hora estándar del este de EE. UU. (America/New_York) es "-05'00'", y la hora estándar de la India (Asia/Calcutta) es "+05'30'".

Ejemplos:

•
D:20210207161528-05'00' 7 de febrero de 2021 a las 4:15:28 p.m.
•
D:20210207211528Z 7 de febrero de 2021 a las 21:15:28 UTC

Cuando se usa con --json, esta opción controla si los flujos en la salida JSON deben omitirse, escribirse en línea (codificados en base64) o escribirse en un archivo. Si se elige "file", el archivo será el nombre del archivo de salida al que se le añade -nnn, donde nnn es el número de objeto. El prefijo se puede anular con --json-stream-prefix. El valor predeterminado es "none", excepto cuando se especifica --json-output, en cuyo caso el valor predeterminado es "inline".

--json-stream-prefix -- prefijo para archivos de datos de flujo json
--json-stream-prefix=file-prefix

Cuando se usa con --json-stream-data=file, --json-stream-data=file-prefix establece el prefijo para los archivos de datos de flujo, anulando el predeterminado, que es usar el nombre del archivo de salida. Lo que sea que se proporcione aquí se añadirá con -nnn para crear el nombre del archivo que contendrá los datos para el flujo en el objeto nnn.

--json-output -- aplicar valores predeterminados para la serialización JSON
--json-output[=version]

Implica --json=version. Cambia los valores predeterminados para ciertas opciones para que la salida JSON escrita sea la representación más fiel del PDF original y no contenga claves JSON adicionales. Ver también --json-stream-data, --json-stream-prefix y --decode-level.

--json-input -- el archivo de entrada es qpdf JSON
Trata el archivo de entrada como un archivo JSON en formato qpdf JSON. Consulte la sección "Formato JSON de qpdf" del manual para obtener información sobre cómo usar esta opción.
--update-from-json -- actualizar un PDF desde qpdf JSON
--update-from-json=qpdf-json-file

Actualiza un archivo PDF desde un archivo JSON. Consulte el capítulo "qpdf JSON" del manual para obtener información sobre cómo usar esta opción.

TESTING (opciones para pruebas o depuración)

Las opciones a continuación son útiles al escribir código de prueba automatizado que incluye archivos creados por qpdf o al probar el propio qpdf.

Opciones Relacionadas:

--static-id -- usar un ID de documento fijo
Usa un valor fijo para el ID del documento. Esto es solo para fines de prueba. Nunca lo uses para archivos de producción. Ver también qpdf --help=--deterministic-id.
--static-aes-iv -- usar un vector AES fijo
Usa un vector de inicialización estático para AES-CBC. Esto es solo para fines de prueba, para que los archivos de salida sean reproducibles. Nunca lo uses para archivos de producción. Esta opción no es segura ya que debilita significativamente el cifrado.
--linearize-pass1 -- guardar pasada 1 de la linealización
--linearize-pass1=file

Escribe la primera pasada de linealización en el archivo nombrado. El archivo resultante no es un archivo PDF válido. Esta opción solo es útil para depurar qpdf.

--test-json-schema -- probar json generado contra esquema
Esto es utilizado por el conjunto de pruebas de qpdf para verificar la consistencia entre la salida de qpdf --json y la salida de qpdf --json-help.
--report-memory-usage -- informe de mejor esfuerzo del uso de memoria
Esto es utilizado por el conjunto de pruebas de rendimiento de qpdf para informar la cantidad máxima de memoria utilizada en entornos compatibles.
