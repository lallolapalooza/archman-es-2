NOMBRE

qemu-ga - Agente de Invitado de QEMU

SINOPSIS

qemu-ga [OPCIONES]

DESCRIPCIÓN

El Agente de Invitado de QEMU es un demonio destinado a ejecutarse dentro de máquinas virtuales. Permite al host de virtualización realizar varias operaciones en el invitado, tales como:

  • obtener información del invitado
  • establecer la hora del sistema del invitado
  • leer/escribir un archivo
  • sincronizar y congelar los sistemas de archivos
  • suspender el invitado
  • reconfigurar los procesadores locales del invitado
  • establecer la contraseña del usuario
  • ...

qemu-ga leerá un archivo de configuración del sistema al iniciarse (ubicado en /etc/qemu/qemu-ga.conf por defecto), luego analizará las opciones de configuración restantes en la línea de comandos. Para la misma clave, la última opción gana, pero las listas se acumulan (ver abajo para el formato del archivo de configuración).

Si se define una lista de RPC permitidos en la configuración, todos los RPC se bloquearán por defecto, excepto los de la lista permitida.

Si se define una lista de RPC bloqueados en la configuración, todos los RPC se permitirán por defecto, excepto los de la lista bloqueada.

Si se definen tanto listas de RPC permitidos como bloqueados en la configuración, todos los RPC se bloquearán por defecto, luego se aplicará la lista permitida, seguida de la lista bloqueada.

Mientras los sistemas de archivos están congelados, todos los RPC excepto un conjunto seguro designado serán bloqueados, independientemente de lo que declare la configuración general.

OPCIONES

-c, --config=RUTA
Ruta del archivo de configuración (el valor por defecto es /etc/qemu/qemu-ga.conf, a menos que se anule por la variable de entorno QGA_CONF)
-m, --method=MÉTODO
Método de transporte: uno de unix-listen, virtio-serial, o isa-serial, o vsock-listen (virtio-serial es el valor por defecto).
-p, --path=RUTA
Ruta del dispositivo/socket (el valor por defecto para virtio-serial es /dev/virtio-ports/org.qemu.guest_agent.0, el valor por defecto para isa-serial es /dev/ttyS0). Las direcciones de socket para vsock-listen se escriben como <cid>:<puerto>.
-l, --logfile=RUTA
Establecer la ruta del archivo de registro (el valor por defecto es stderr).
-f, --pidfile=RUTA
Especificar el archivo PID (el valor por defecto es /var/run/qemu-ga.pid).
-F, --fsfreeze-hook=RUTA
Habilitar el hook de fsfreeze. Acepta un argumento opcional que especifica un script para ejecutar en freeze/thaw. El script se llamará con los argumentos 'freeze'/'thaw' correspondientemente (el valor por defecto es /etc/qemu/fsfreeze-hook). Si se usa -F con un argumento, no siga a -F con un espacio (por ejemplo: -F/var/run/fsfreezehook.sh).
-t, --statedir=RUTA
Especificar el directorio para almacenar la información de estado (solo rutas absolutas, el valor por defecto es /var/run).
-v, --verbose
Registrar información de depuración adicional.
-V, --version
Mostrar información de la versión y salir.
-d, --daemon
Demonizar después de iniciarse (desvincularse de la terminal).
-b, --block-rpcs=LISTA
Lista separada por comas de RPC a deshabilitar (sin espacios, usa --block-rpcs=help para listar los RPC disponibles).
-a, --allow-rpcs=LISTA
Lista separada por comas de RPC a habilitar (sin espacios, usa --allow-rpcs=help para listar los RPC disponibles).
-D, --dump-conf
Volcar la configuración en un formato compatible con qemu-ga.conf y salir.
-h, --help
Mostrar esta ayuda y salir.

ARCHIVOS

La sintaxis del archivo de configuración qemu-ga.conf sigue la Especificación de Entrada de Escritorio, aquí hay un resumen rápido: consiste en grupos de pares clave-valor, intercalados con comentarios.

# Muestra de configuración de qemu-ga
[general]
daemonize = 0
pidfile = /var/run/qemu-ga.pid
verbose = 0
method = virtio-serial
path = /dev/virtio-ports/org.qemu.guest_agent.0
statedir = /var/run

La lista de claves sigue las opciones de la línea de comandos:

Clave Tipo de clave
daemon booleano
method cadena
path cadena
logfile cadena
pidfile cadena
fsfreeze-hook cadena
statedir cadena
verbose booleano
block-rpcs lista de cadenas
allow-rpcs lista de cadenas
