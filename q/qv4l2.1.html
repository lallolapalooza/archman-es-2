QV4L2(1) Comandos de usuario QV4L2(1)

NOMBRE

qv4l2 - Una aplicación de banco de pruebas para dispositivos video4linux

SINOPSIS

qv4l2 [-R] [-h] [-d <dispositivo>] [-r <dispositivo>] [-V <dispositivo>] [-S <dispositivo>]

DESCRIPCIÓN

La herramienta qv4l2 se utiliza para probar dispositivos de captura y salida de video4linux, ya sean de video, vbi, radio o swradio. Esta aplicación también puede servir como una aplicación genérica de visor de video/TV o como un generador de video para dispositivos de salida de video.

Sin embargo, no soporta (todavía) transmisiones de video comprimidas aparte de MJPEG

OPCIONES

-d, --dispositivo=<dispositivo>
Utiliza el dispositivo <dispositivo> como dispositivo de video. Si <dispositivo> es un número, entonces se utiliza /dev/video<dispositivo>.
-V, --dispositivo-vbi=<dispositivo>
Utiliza el dispositivo <dispositivo> como dispositivo vbi. Si <dispositivo> es un número, entonces se utiliza /dev/vbi<dispositivo>.
-r, --dispositivo-radio=<dispositivo>
Utiliza el dispositivo <dispositivo> como dispositivo de radio. Si <dispositivo> es un número, entonces se utiliza /dev/radio<dispositivo>.
-S, --dispositivo-sdr=<dispositivo>
Utiliza el dispositivo <dispositivo> como dispositivo SDR. Si <dispositivo> es un número, entonces se utiliza /dev/swradio<dispositivo>.
-R, --raw
Abre el dispositivo en modo raw, es decir, sin utilizar las funciones envoltorio de libv4l2.
-h, --ayuda
Imprime el mensaje de ayuda.

TECLAS DE ACCESO RÁPIDO

Ventana Principal

Ctrl + O
Abrir dispositivo
Ctrl + R
Abrir dispositivo en modo raw
Ctrl + W
Cerrar el dispositivo
Ctrl + V
Iniciar captura
Ctrl + F
Redimensionar la ventana de captura al tamaño del fotograma
Ctrl + Q
Salir de la aplicación

Ventana de Captura

Ctrl + W
Cierra la ventana y detiene la captura
Ctrl + F
Redimensionar la ventana de captura al tamaño del fotograma

ESTADO DE SALIDA

En caso de éxito, devuelve 0. De lo contrario, devolverá el código de error.
