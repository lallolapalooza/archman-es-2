QPWGRAPH(1) Manual de Comandos Generales QPWGRAPH(1)

NOMBRE

qpwgraph - Una interfaz gráfica Qt para el gestor de grafos de PipeWire

SINOPSIS

qpwgraph [opciones] [archivo-patchbay]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando qpwgraph.

qpwgraph es un gestor de grafos dedicado a PipeWire (https://pipewire.org), usando el framework Qt C++ (https://qt.io), basado y muy parecido al de QjackCtl (https://qjackctl.sourceforge.io).

Repositorio de código fuente: https://gitlab.freedesktop.org/rncbc/qpwgraph

OPCIONES

-a, --activated

Patchbay activado.

-x, --exclusive

Patchbay exclusivo.

-m, --minimized

Iniciar minimizado.

-h, --help

Mostrar ayuda sobre las opciones de la línea de comandos

-v, --version

Mostrar información de la versión

ARCHIVOS

La configuración se almacena en ~/.config/rncbc.org/qpwgraph.conf
