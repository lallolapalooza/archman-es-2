qwtchangelog - Novedades en Qwt 6.2

Qt >= 4.8

Se ha eliminado el soporte para Qt < Qt 4.8, se ha añadido soporte para Qt6.

Incluye

Ahora están disponibles archivos de inclusión que coinciden con los nombres de las clases. Por lo tanto, ahora es posible escribir '#include <QwtPlot>' en lugar de 'include qwt_plot.h'

QwtPolar se ha convertido en parte de Qwt

El proyecto QwtPolar ( https://qwtpolar.sourceforge.io ) se ha integrado en Qwt.

El renderizador de texto MathML se ha convertido en su propio proyecto

El código se puede encontrar ahora en https://github.com/uwerat/qwt-mml-dev y está previsto que se convierta en una biblioteca independiente.

Spline

La implementación defectuosa de QwtSpline ha sido reemplazada por un conjunto de clases que ofrecen todo tipo de funcionalidades en torno a las splines.

Se han implementado los algoritmos de aproximación/interpolación de splines más populares:

- Base
- Cardinal
- ParabolicBlending
- Akima
- El que se utiliza en un paquete de oficina propietario
- Cúbica

Mejor soporte OpenGL

Se añadió QwtPlotOpenGLCanvas para admitir la representación en un QOpenGLWidget

Nuevos elementos de gráfico

- QwtPlotVectorField
  Un nuevo tipo de elemento de gráfico para campos vectoriales
- QwtPlotGraphicItem
  Un elemento que muestra una imagen QwtGraphic (por ejemplo, utilizada por QwtPlotSvgItem)

QwtPlotCurve

- QwtPlotCurve::FilterPointsAggressive
  Un algoritmo de eliminación rápido para grandes conjuntos de datos con valores x o y crecientes
- QwtPlotCurve::closestPoint
  Es virtual ahora
- Recorte de líneas
  Incluye ahora el recorte del pintor
- QwtValuePointData
  Se añadió un nuevo tipo de datos, donde los valores x son el índice
- QwtPlotCurve::setSamples
  más tipos de establecedores

QwtPlotSpectrogram

- QwtPlotSpectrogram::setColorTableSize
  Uso de tablas de color RGB individuales
- QwtRasterData::setInterval/interval
  Limpieza de API
- QwtHueColorMap, QwtSaturationValueColorMap
  Nuevos tipos de mapas de color
- QwtMatrixRasterData::BicubicInterpolation
  Se añadió la implementación de interpolación bicúbica
- Manejo de valores NaN
  Los valores NaN se interpretan como huecos, cuando QwtRasterData::WithoutGaps
  no está establecido

Otros cambios

- QwtPlotRenderer
  Uso de QPdfWriter en lugar de QPrinter, cuando sea posible
- Manejo de motores de pintura desconocidos
  No se alinean motores de pintura desconocidos (por ejemplo, EMF), QwtNullPaintDevice no utiliza
  ya QPaintEngine::User
- QwtTransform::LogMin/LogMax
  Se eliminaron LOG_MIN/LOG_MAX (¡los valores difieren!)
- qwt_compat.h
  Eliminado
- qwtFuzzyGreaterOrEqual/qwtFuzzyLessOrEqual
  Eliminado
- qwtGetMin/qwtGetMax
  Eliminado
