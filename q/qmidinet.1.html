QMIDINET(1) Manual de Comandos Generales QMIDINET(1)

NOMBRE

qmidinet - Puerta de enlace de red MIDI a través de multidifusión UDP/IP

SINOPSIS

qmidinet [opciones]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando qmidinet.

QmidiNet es una aplicación de puerta de enlace de red MIDI que envía y recibe datos MIDI (Secuenciador ALSA) a través de la red, utilizando multidifusión UDP/IP.

Se inspiró en multimidicast (http://llg.cubic.org/tools) y fue diseñado para ser compatible con ipMIDI para Windows (http://nerds.de).

OPCIONES

-n, --num-ports=[num-puertos]

Utiliza este número de puertos (por defecto = 1)

-i, --interface=[interfaz]

Utiliza una interfaz de red específica (por defecto = todas)

-u, --address, --udp-addr=[dirección]

Utiliza una dirección de red específica (por defecto = 225.0.0.37)

-p, --port, --udp-port=[puerto]

Utiliza un puerto de red específico (por defecto = 21928)

-a, --alsa-midi[=flag]

Habilita ALSA MIDI (0|1|yes|no|on|off, por defecto = yes)

-j, --jack-midi[=flag]

Habilita JACK MIDI (0|1|yes|no|on|off, por defecto = no)

-g, --no-gui

Deshabilita la interfaz gráfica de usuario (GUI)

-h, --help

Muestra ayuda sobre las opciones de línea de comandos

-v, --version

Muestra información de la versión

ARCHIVOS

La configuración se almacena en ~/.config/rncbc.org/QmidiNet.conf
