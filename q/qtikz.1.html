NOMBRE

qtikz - editor para el lenguaje TikZ

SINOPSIS

qtikz [url | archivo]

DESCRIPCIÓN

QtikZ es una pequeña aplicación para ayudar en la creación de diagramas y dibujos utilizando las macros TikZ del paquete LaTeX "pgf". Consiste en un panel de editor de texto en el que se edita el código TikZ del dibujo y un panel de vista previa que muestra el dibujo tal como lo renderiza latex. El panel de vista previa se puede actualizar en tiempo real. Herramientas, opciones y estilos comunes de dibujo están disponibles en los menús para ayudar en el proceso de codificación.

qtikz no acepta opciones de línea de comandos aparte del nombre del archivo a abrir.

VER TAMBIÉN

La documentación completa para el usuario está disponible a través de Ayuda -> Manual de QtikZ. También puede ejecutar `assistant -collectionFile /usr/share/qtikz/documentation/qtikz.qhc' desde la línea de comandos.
