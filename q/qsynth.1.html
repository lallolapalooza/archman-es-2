QSYNTH(1) Manual de comandos generales QSYNTH(1)

NOMBRE

qsynth - Interfaz gráfica Qt para fluidsynth

SINOPSIS

qsynth [opciones] [soundfonts] [midifiles]

DESCRIPCIÓN

Este manual describe brevemente el comando qsynth.

Qsynth es una aplicación de interfaz gráfica (GUI) para fluidsynth escrita en C++ con el framework Qt, usando Qt Designer. Eventualmente podría evolucionar a una aplicación de gestión de sintetizadores de software que permita al usuario controlar y gestionar una variedad de sintetizadores de línea de comandos, pero por el momento envuelve al excelente FluidSynth.

FluidSynth es un sintetizador de software de línea de comandos basado en la especificación Soundfont.

OPCIONES

-n, --no-midi-in

No crear un controlador MIDI para leer eventos de entrada MIDI [predeterminado = sí]

-m, --midi-driver=[etiqueta]

El nombre del controlador MIDI a usar [oss, alsa, alsa_seq, ...]

-K, --midi-channels=[num]

El número de canales MIDI [predeterminado = 16]

-a, --audio-driver=[etiqueta]

El controlador de audio [alsa,jack,oss,dsound,...]

-j, --connect-jack-outputs

Intentar conectar las salidas de JACK a los puertos físicos

-L, --audio-channels=[num]

El número de canales de audio estéreo [predeterminado = 1]

-G, --audio-groups=[num]

El número de grupos de audio [predeterminado = 1]

-z, --audio-bufsize=[tamaño]

Tamaño de cada búfer de audio

-c, --audio-bufcount=[conteo]

Número de búferes de audio

-r, --sample-rate=[tasa]

Establecer la tasa de muestreo

-R, --reverb[=bandera]

Activar o desactivar la reverberación [1|0|yes|no|on|off, predeterminado = on]

-C, --chorus[=bandera]

Activar o desactivar el coro [1|0|yes|no|on|off, predeterminado = on]

-g, --gain=[ganancia]

Establecer la ganancia maestra [0 < ganancia < 2, predeterminado = 1]

-o, --option [nombre=valor]

Definir un ajuste nombre=valor

-s, --server

Crear e iniciar un servidor [predeterminado = no]

-i, --no-shell

No leer comandos de la shell [ignorado]

-d, --dump

Volcar eventos del enrutador MIDI

-V, --verbose

Imprimir mensajes detallados sobre los eventos MIDI

-h, --help

Mostrar ayuda sobre las opciones de línea de comandos

-v, --version

Mostrar información de la versión

ARCHIVOS

La configuración se almacena en ~/.config/rncbc.org/Qsynth.conf
