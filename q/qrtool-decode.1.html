NOMBRE

qrtool-decode - detectar y decodificar un código QR

SINOPSIS

qrtool decode [OPCIÓN]... [IMAGEN]

DESCRIPCIÓN

Este comando detecta y decodifica un código QR https://www.qrcode.com/ a partir de una imagen ráster o vectorial. Por defecto, el resultado se mostrará en la salida estándar.

Formatos de archivo de imagen compatibles

•BMP https://en.wikipedia.org/wiki/BMP_file_format (si está habilitado en tiempo de compilación)
•DDS https://en.wikipedia.org/wiki/DirectDraw_Surface (si está habilitado en tiempo de compilación)
•Farbfeld https://tools.suckless.org/farbfeld/ (si está habilitado en tiempo de compilación)
•GIF https://en.wikipedia.org/wiki/GIF (si está habilitado en tiempo de compilación)
•Radiance RGBE https://en.wikipedia.org/wiki/RGBE_image_format (si está habilitado en tiempo de compilación)
•ICO <https://en.wikipedia.org/wiki/ICO_(file_format)> (si está habilitado en tiempo de compilación)
•JPEG https://jpeg.org/jpeg/ (si está habilitado en tiempo de compilación)
•OpenEXR https://openexr.com/ (si está habilitado en tiempo de compilación)
•PNG https://en.wikipedia.org/wiki/PNG
•PNM https://netpbm.sourceforge.net/doc/pnm.html (si está habilitado en tiempo de compilación)
•QOI https://qoiformat.org/ (si está habilitado en tiempo de compilación)
•SVG https://www.w3.org/Graphics/SVG/ (si está habilitado en tiempo de compilación)
•TGA https://en.wikipedia.org/wiki/Truevision_TGA (si está habilitado en tiempo de compilación)
•TIFF https://en.wikipedia.org/wiki/TIFF (si está habilitado en tiempo de compilación)
•WebP https://developers.google.com/speed/webp/ (si está habilitado en tiempo de compilación)
•XBM https://en.wikipedia.org/wiki/X_BitMap (si está habilitado en tiempo de compilación)

Use la opción -t para especificar el formato de la imagen. Si no se especifica esta opción, el formato de la imagen se determina basándose en la extensión o en el número mágico.

ARGUMENTOS POSICIONALES

IMAGEN

Archivo de imagen de entrada. Si no se especifica IMAGEN, o si se especifica "-", la imagen se leerá de la entrada estándar. Los formatos de imagen ráster admitidos se basan en los formatos admitidos por la crate https://crates.io/crates/image . El formato de IMAGEN se determina basándose en la extensión o en el número mágico si es posible. Si el formato no se puede determinar, use --type. Tenga en cuenta que la imagen SVG se rasteriza antes de escanear.

OPCIONES

-t, --type FORMATO

El formato de entrada. Si no se especifica FORMATO, el formato se determina basándose en la extensión o en el número mágico.

Los valores posibles son:

bmp

Windows Bitmap. Este valor está disponible si la característica decode-from-bmp está habilitada en tiempo de compilación.

dds

DirectDraw Surface. Este valor está disponible si la característica decode-from-dds está habilitada en tiempo de compilación.

farbfeld

Farbfeld. Este valor está disponible si la característica decode-from-ff está habilitada en tiempo de compilación.

gif

Graphics Interchange Format. Este valor está disponible si la característica decode-from-gif está habilitada en tiempo de compilación.

hdr

Radiance RGBE. Este valor está disponible si la característica decode-from-hdr está habilitada en tiempo de compilación.

ico

Formato de archivo ICO. Este valor también incluye el formato de archivo CUR. Este valor está disponible si la característica decode-from-ico está habilitada en tiempo de compilación.

jpeg

JPEG. Este valor está disponible si la característica decode-from-jpeg está habilitada en tiempo de compilación.

openexr

OpenEXR. Este valor está disponible si la característica decode-from-exr está habilitada en tiempo de compilación.

png

Portable Network Graphics.

pnm

Portable Anymap Format. Este valor está disponible si la característica decode-from-pnm está habilitada en tiempo de compilación.

qoi

Quite OK Image Format. Este valor está disponible si la característica decode-from-qoi está habilitada en tiempo de compilación.

svg

Scalable Vector Graphics. Este valor también incluye la imagen SVG comprimida con gzip. Este valor está disponible si la característica decode-from-svg está habilitada en tiempo de compilación.

tga

Truevision TGA. Este valor está disponible si la característica decode-from-tga está habilitada en tiempo de compilación.

tiff

Tag Image File Format. Este valor está disponible si la característica decode-from-tiff está habilitada en tiempo de compilación.

webp

WebP. Este valor está disponible si la característica decode-from-webp está habilitada en tiempo de compilación.

xbm

X BitMap. Este valor está disponible si la característica decode-from-xbm está habilitada en tiempo de compilación.

--verbose

Imprimir también los metadatos. Se muestran en stderr. Esta opción entra en conflicto con --metadata.

--metadata

Imprimir solo los metadatos. Se muestran en stderr. Esta opción entra en conflicto con --verbose.

-h, --help

Imprimir mensaje de ayuda. La opción corta (-h) imprimirá un mensaje de ayuda condensado mientras que la opción larga (--help) imprimirá un mensaje de ayuda detallado.

-V, --version

Imprimir número de versión.

ESTADO DE SALIDA

0

Ejecución exitosa del programa.

1

Ocurrió un error.

2

Ocurrió un error al analizar los argumentos de la línea de comandos.

Los estados de salida distintos de estos están definidos por <sysexits.h> https://man.openbsd.org/sysexits.

EJEMPLOS

Detectar y decodificar un código QR de la imagen dada:

$ qrtool decode input.png

Decodificar un código QR de la imagen WebP dada:

EJEMPLOS

Decodifica un código QR codificado en un archivo webp:

qrtool decode -t webp input.webp

También imprime los metadatos al decodificar un código QR:

qrtool decode --verbose input.qoi
