QB_MAP_FOREACH(3) Manual del programador de libqb QB_MAP_FOREACH(3)

NOMBRE

qb_map_foreach - Llama a la función dada para cada par clave/valor en el mapa.

SINOPSIS

#include <qb/qbmap.h>

void qb_map_foreach(
    qb_map_t             *map,
    qb_map_transverse_fn  func,
    void                 *user_data
);

DESCRIPCIÓN

La función recibe la clave y el valor de cada par, y el parámetro de datos proporcionado. El mapa se recorre en orden ordenado.

VER TAMBIÉN
