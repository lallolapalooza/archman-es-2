QBMAP.H(3) Manual del programador de libqb QBMAP.H(3)

NOMBRE

qbmap.h - Proporciona una interfaz de mapa a un trie de Patricia, tabla hash o skiplist.

SINOPSIS

#include <qb/qbmap.h>

DESCRIPCIÓN

Ordenación

La tabla hash NO está ordenada, pero el trie y el skiplist sí lo están.

Iteración

A continuación, un ejemplo sencillo de cómo iterar sobre un mapa.

const char *p;
void *data;
qb_map_iter_t *it = qb_map_iter_create(m);
for (p = qb_map_iter_next(it, &data); p; p = qb_map_iter_next(it, &data)) {
    printf("%s > %s0, p, (char*) data);
}
qb_map_iter_free(it);

Se admite la eliminación de elementos dentro del iterador. Pero tenga en cuenta que no libere la memoria del elemento en el iterador. Si necesita liberar los elementos de datos, regístrese para recibir una notificación y libere la memoria allí. Esto es necesario ya que los elementos tienen un recuento de referencias.

qb_map_notify_add(m, NULL, my_map_free_handler,
             QB_MAP_NOTIFY_FREE, NULL);

Notificaciones

Estas le permiten recibir devoluciones de llamada cuando se insertan/eliminan o reemplazan valores.

Coincidencia de prefijos

El trie admite prefijos en el iterador:

it = qb_map_pref_iter_create(m, "aa");
while ((p = qb_map_iter_next(it, &data)) != NULL) {
    printf("%s > %s0, p, (char*)data);
}
qb_map_iter_free(it);

El trie también admite prefijos en las notificaciones: (recuerde pasar QB_MAP_NOTIFY_RECURSIVE a notify_add.

qb_map_notify_add(m, "root", my_map_notification,
            (QB_MAP_NOTIFY_INSERTED|
             QB_MAP_NOTIFY_DELETED|
             QB_MAP_NOTIFY_REPLACED|
             QB_MAP_NOTIFY_RECURSIVE),
            NULL);

NOTA

La tabla hash solo admite notificaciones de eliminación y reemplazo. También hay una devolución de llamada global especial para liberar valores eliminados y reemplazados (QB_MAP_NOTIFY_FREE).
