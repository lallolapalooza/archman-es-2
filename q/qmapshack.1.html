NOMBRE

QMapShack - Mapeo GPS (GeoTiff y vector) y gestión de GPSr

SINOPSIS

qmapshack [ [ -d | --debug ] [ -h | --help ] [ -n | --no-splash ] [ archivos... ]

DESCRIPCIÓN

Mapeo GPS (GeoTiff y vector) y gestión de GPSr. QMapShack proporciona una herramienta versátil para mapas GPS en formato GeoTiff, así como para el formato de mapa vectorial img de Garmin. También puedes ver y editar tus rutas GPX. QMapShack es el sucesor de QLandkarteGT.

Características principales:

- Uso de varios espacios de trabajo.
- Uso de varios mapas en un espacio de trabajo.
- Gestión de datos orientada a proyectos.

OPCIONES

-d, --debug
Ejecutar con salida de depuración.
-h, --help
Muestra el mensaje de ayuda.
-n, --no-splash
Iniciar sin pantalla de presentación.

VER TAMBIÉN

https://github.com/Maproom/qmapshack/wiki/DocMain.
