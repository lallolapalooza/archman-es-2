QB_IPCS_CREATE(3) Manual del programador de libqb QB_IPCS_CREATE(3)

NOMBRE

qb_ipcs_create - Crear un nuevo servidor IPC.

SINOPSIS

#include <qb/qbipcs.h>

qb_ipcs_service_t * qb_ipcs_create(
    const char                        *name,        /* para que los clientes se conecten. */
    int32_t                            service_id,  /* un entero para asociar con el servicio */
    enum qb_ipc_type                   type,        /* tipo de transporte. */
    struct qb_ipcs_service_handlers   *handlers     /* callbacks. */
);

PARÁMETROS

name para que los clientes se conecten.

service_id un entero para asociar con el servicio

type tipo de transporte.

handlers callbacks.

ESTRUCTURAS


struct qb_ipcs_service_handlers {


    qb_ipcs_connection_accept_fn     connection_accept;

    qb_ipcs_connection_created_fn    connection_created;

    qb_ipcs_msg_process_fn           msg_process;

    qb_ipcs_connection_closed_fn     connection_closed;

    qb_ipcs_connection_destroyed_fn  connection_destroyed;
};

VALOR DE RETORNO

la nueva instancia del servicio.
