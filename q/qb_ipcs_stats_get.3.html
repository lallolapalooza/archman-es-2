QB_IPCS_STATS_GET(3) Manual del programador de libqb QB_IPCS_STATS_GET(3)

NOMBRE

qb_ipcs_stats_get - Obtiene las estadísticas del servicio.

SINOPSIS

#include <qb/qbipcs.h>

int32_t qb_ipcs_stats_get(
    qb_ipcs_service_t      *pt,                /* instancia del servicio */
    struct qb_ipcs_stats   *stats,             /* (salida) la estructura de estadísticas */
    int32_t                 clear_after_read   /* borrar estadísticas después de copiarlas en stats */
);

PARÁMETROS

pt instancia del servicio

stats (salida) la estructura de estadísticas

clear_after_read borrar estadísticas después de copiarlas en stats

DESCRIPCIÓN

ESTRUCTURAS


struct qb_ipcs_stats {


    uint32_t  active_connections;

    uint32_t  closed_connections;
};

VALOR DE RETORNO

0 == ok; -errno para indicar un fallo
