QB_MAP_NOTIFY_DEL(3) Manual del Programador de libqb QB_MAP_NOTIFY_DEL(3)

NOMBRE

qb_map_notify_del - Eliminar un notificador del mapa.

SINOPSIS

#include <qb/qbmap.h>

int32_t qb_map_notify_del(
    qb_map_t         *m,       /* la instancia del mapa */
    /*
     * la clave (o prefijo) para adjuntar la notificación.
     */
    const char       *key,
    qb_map_notify_fn  fn,      /* la función de devolución de llamada */
    int32_t           events   /* el tipo de eventos para los que registrarse.*/
);

PARÁMETROS

m la instancia del mapa

key la clave (o prefijo) a la que adjuntar la notificación.

fn la función de devolución de llamada

events el tipo de eventos para los que registrarse.

DESCRIPCIÓN

VALOR DE RETORNO

0 éxito

-errno fallo

NOTA

la clave, la función de devolución de llamada y los eventos deben coincidir con los que añadiste.
