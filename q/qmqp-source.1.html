QMQP-SOURCE(1) Manual de comandos generales QMQP-SOURCE(1)

NOMBRE

qmqp-source - Generador de pruebas QMQP paralelizado

SINOPSIS

qmqp-source [opciones] [inet:]host[:puerto]

qmqp-source [opciones] unix:ruta_de_acceso

DESCRIPCIÓN


qmqp-source se conecta al host y puerto TCP especificados (por defecto 628) y le envía uno o varios mensajes, de forma secuencial o paralela. El programa habla el protocolo QMQP. Se pueden establecer conexiones a servidores de dominio UNIX e IPv4 o IPv6. IPv4 e IPv6 son las opciones por defecto.

Nota: este es un programa de prueba no soportado. No se realiza ningún intento de mantener la compatibilidad entre versiones sucesivas.

Argumentos:

-4
Conectarse al servidor con IPv4. Esta opción no tiene efecto cuando Postfix se compila sin soporte IPv6.
-6
Conectarse al servidor con IPv6. Esta opción no está disponible cuando Postfix se compila sin soporte IPv6.
-c
Mostrar un contador en ejecución que se incrementa cada vez que se completa una entrega.
-C conteo
Cuando un host envía RESET en lugar de SYN|ACK, intentar conteo veces antes de rendirse. El conteo por defecto es 1. Especificar un conteo mayor para solucionar un problema con pilas TCP/IP que envían RESET cuando la cola de escucha está llena.
-f remitente
Usar la dirección del remitente especificada (por defecto: <foo@myhostname>).
-l longitud
Enviar longitud bytes como contenido del mensaje. La longitud incluye las cabeceras del mensaje.
-m conteo_mensajes
Enviar el número especificado de mensajes (por defecto: 1).
-M nombre_host_mi_maquina
Usar el nombre de host o [dirección] especificado en las direcciones del remitente y destinatario por defecto, en lugar del nombre de host de la máquina.
-r conteo_destinatarios
Enviar el número especificado de destinatarios por transacción (por defecto: 1). Los nombres de destinatario se generan anteponiendo un número a la dirección del destinatario.
-s conteo_sesiones
Ejecutar el número especificado de sesiones QMQP en paralelo (por defecto: 1).
-t a
Usar la dirección del destinatario especificada (por defecto: <foo@myhostname>).
-R intervalo
Esperar un período de tiempo aleatorio 0 <= n <= intervalo entre mensajes. Suspender un hilo no afecta a otros hilos de entrega.
-v
Hacer el programa más detallado, con fines de depuración.
-w intervalo
Esperar un tiempo fijo entre mensajes. Suspender un hilo no afecta a otros hilos de entrega.

VER TAMBIÉN
