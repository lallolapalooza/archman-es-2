QALC(1) Manual de Comandos Generales QALC(1)

NOMBRE

qalc - Calculadora potente y fácil de usar desde la línea de comandos

SINOPSIS

qalc [opciones] [expresión]

DESCRIPCIÓN

Qalculate! es una calculadora de escritorio multiplataforma multipropósito. Es fácil de usar pero proporciona una potencia y versatilidad normalmente reservadas para paquetes de matemáticas complicados, así como herramientas útiles para las necesidades diarias (como conversión de divisas y cálculo de porcentajes). Las características incluyen una gran biblioteca de funciones personalizables, cálculos y conversiones de unidades, constantes físicas, cálculos simbólicos (incluyendo integrales y ecuaciones), precisión arbitraria, propagación de incertidumbre, aritmética de intervalos, trazado y una interfaz fácil de usar. qalc es la interfaz de línea de comandos de Qalculate!.

SINTAXIS

Entidades matemáticas:

Números
Son los números regulares compuestos por dígitos 0-9 y un signo decimal — un punto, o una coma si es el punto decimal predeterminado en la configuración regional/idioma utilizado. Si la coma se usa como signo decimal, el punto se mantiene como un signo decimal alternativo, si no se desactiva explícitamente. Los números incluyen enteros, números reales y números complejos. La parte imaginaria de los números complejos se escribe como un número regular seguido de la variable especial "i" (que se puede cambiar a "j"), que representa la raíz cuadrada de -1. Los espacios entre dígitos se ignoran ("5 5 = 55"). "E" (o "e") puede considerarse un atajo para escribir muchos ceros y es equivalente a la multiplicación por 10 elevada a la potencia del valor de la derecha (por ejemplo, "5E3 = 5000"). Los números sexagesimales (y el tiempo) se pueden ingresar directamente usando dos puntos (por ejemplo, "5:30 = 5.5"). Un número precedido inmediatamente por "0b", "0o", "0d" o "0x" se interpreta como un número con base 2, 8, 12 o 16, respectivamente (por ejemplo, "0x3f = 63").

Intervalos
Se puede ingresar un intervalo de números usando la función interval(), la función uncertainty(), o usando "±" o "+/-" (por ejemplo, 5±1 = uncertainty(5, 0.2) = interval(4, 6)). Si la opción de precisión de lectura está activada, los números decimales se interpretan como un intervalo entre los números que normalmente se redondearían al número ingresado (por ejemplo, 1.1 = 1.1±0.05). Si el cálculo de intervalos utilizando la fórmula de varianza está activado

ativado (predeterminado), el intervalo representa la incertidumbre estándar (desviación) del valor.

Vectores y matrices
Una matriz es un arreglo bidimensional rectangular de objetos matemáticos. Los vectores son matrices con una sola fila o columna, y por lo tanto, secuencias unidimensionales de objetos. Los vectores y las matrices se generan mediante varias funciones o utilizando sintaxis en la forma [1 2 3 4] y [1 2; 3 4], con columnas separadas por espacio o coma y filas separadas por punto y coma, o (1, 2, 3, 4) y ((1, 2), (3, 4)). Un vector con una secuencia de números se puede crear usando "..." (por ejemplo, "1...4") o dos puntos (por ejemplo, "[1:4]" o "[1:1:4]" donde el segundo valor especifica el incremento). Un solo elemento de un vector se puede seleccionar colocando el índice (el primer índice es 1) entre paréntesis después de una variable o función (por ejemplo, "v(1)" o "f[1]").

Variables/Constantes
Consulte la lista de variables en el manual de la GUI o usando el comando .I list variables

Funciones
Consulte la lista de funciones en el manual de la GUI o usando el comando .I list functions

Unidades y prefijos
Consulte la lista de unidades y prefijos en el manual de la GUI o usando el comando .I list units. Generalmente se permiten las formas abreviadas, plural y singular de los nombres de unidades y prefijos. Los prefijos deben colocarse inmediatamente antes de la unidad para ser interpretados como prefijos (por ejemplo, 5 mm = 0.005 m, pero 5 m m = 5 m^2). Para mayor comodidad, las unidades permiten omitir el operador de potencia (por ejemplo, 5 m2 = 5 m^2), excluyendo las monedas.

Incógnitas
Las incógnitas son cadenas de texto sin ningún valor asociado. Estas son variables temporales desconocidas con suposiciones predeterminadas. Las incógnitas también se pueden ingresar explícitamente colocando una barra invertida (\) antes de un solo carácter (por ejemplo, 5\a + 2\b) o usando comillas antes y después de una cadena de texto (por ejemplo, 5 "manzanas" + 2 "plátanos"). Si las incógnitas están activadas, los caracteres sin ninguna variable, función o unidad asociada en una expresión se considerarán como una variable incógnita.

Fecha y hora
Los valores de fecha/hora se especifican usando una cadena de texto entre comillas (las comillas no son necesarias para los argumentos de la función), utilizando el formato estándar de fecha y hora (AAAA-MM-DDTHH:MM:SS). También se admiten algunos formatos locales, pero no se recomiendan. Se utiliza la zona horaria local, a menos que se especifique una zona horaria al final de la cadena de tiempo (Z/UTC/GMT o +/-HH:MM). La fecha/hora admite un pequeño subconjunto de operaciones aritméticas. Las unidades de tiempo representan tiempo calendario, en lugar de valores promedio, cuando se suman o restan a una fecha.

Texto
Esta categoría representa una serie de tipos de argumentos de función diferentes, como texto normal y nombres de archivo. Pueden, pero no necesitan, estar entre comillas, excepto cuando contienen el separador de argumentos.

Comentarios
Todo texto después de un signo de almohadilla (por ejemplo, (5*2)/2 #calculando el área del triángulo) se trata como un comentario.

Exponenciación (^, **)
Tenga en cuenta que x^y^z es igual a x^(y^z), y no a (x^y)^z. Tenga en cuenta también que para exponentes no enteros con bases negativas, se devuelve la raíz principal y no la raíz real ((-8)^(1/3) es igual a 1 + 1.73i, y no a -2). Para calcular la raíz real de valores negativos, utilice las funciones cbrt() y root().

Operador de asignación (:=, =)
Guarda la expresión a la derecha del operador como una variable o función (por ejemplo, var1:=5, func1():=x+y, var1=ln(5)+2). Si se omite el punto y coma, la expresión se calcula antes de asignarla a la variable.

Orden de prioridad de evaluación: paréntesis, 10^x, exponenciación, funciones, NOT a nivel de bits, NOT lógico, multiplicación/división/resto, suma paralela, suma/resta, NOT a nivel de bits, desplazamiento a nivel de bits, comparaciones, AND a nivel de bits, XOR a nivel de bits, OR a nivel de bits, AND lógico, OR lógico.

La evaluación de la multiplicación corta/implícita sin ningún signo de multiplicación (por ejemplo, 5x, 5(2+3)) difiere según el modo de análisis. En el modo convencional, la multiplicación implícita no difiere de la multiplicación explícita (12/2(1+2) = 12/2*3 = 18, 5x/5y = 5 * x/5 * y = xy). En el modo de análisis primero multiplicación implícita, la multiplicación implícita se analiza antes que la multiplicación explícita (12/2(1+2) = 12/(2 * 3) = 2, 5x/5y = (5 * x)/(5 * y) = x/y). El modo adaptativo predeterminado funciona como el modo de análisis de multiplicación implícita primero, a menos que se encuentren espacios (1/5x = 1/(5 * x), pero 1/5 x = (1/5) * x). En el modo adaptativo, las expresiones de unidad se analizan por separado (5 m/5 m/s = (5 * m)/(5 * (m/s)) = 1 s). Los argumentos de función sin paréntesis son una excepción, donde la multiplicación implícita delante de variables y unidades se analiza primero, independientemente del modo (sqrt 2x = sqrt(2x)).

En el modo cadena, las expresiones se calculan de izquierda a derecha, ignorando el orden estándar de las operaciones, como el modo de ejecución inmediata de una calculadora tradicional (1+2*3 = (1+2)*3 = 9).

El operador "to" se utiliza para la conversión de unidades y la manipulación de cómo se presenta el resultado. Coloque " to " o una flecha derecha (por ejemplo, "->", pero no ">") seguido de una de las expresiones/comandos que se enumeran a continuación, al final de una expresión.

De manera similar, where (o alternativamente "/.") se puede usar al final (pero antes de "to"), para asignaciones de variables, reemplazos de funciones, etc. (por ejemplo, "x+y where x=1 and y=2", "x^2=4 where x>0", y "sin(5) where sin()=cos()"). Las asignaciones de variables también se pueden colocar antes de la expresión, separadas por coma, por ejemplo, <quote>x=1, y=2, x+y</quote>, pero esta sintaxis es más estricta.

Tenga en cuenta que to y where solo se pueden aplicar a toda la expresión. Todo lo que está antes del operador siempre se trata como la expresión a convertir (o aplicar reemplazo), y todo lo que está después como la expresión de conversión/reemplazo, independientemente de los paréntesis.

NAME

DESCRIPTION

qalculate-gtk is a program that provides a graphical user interface for the libqalculate library. It is a desktop calculator that supports standard arithmetic, unit conversions, physical constants, calculus, algebra, matrices, statistics, time and date calculations, and number base conversions.

The calculation engine of qalculate-gtk is libqalculate. The syntax for mathematical expressions is described below.

The syntax for mathematical expressions is the same as in qalc.
