NOMBRE

quvi-modules - Resumen de los módulos cargables de quvi

DESCRIPCIÓN

quvi-modules son una selección de módulos importables implementados en Lua. Estos módulos están pensados para ser cargados (require) desde libquvi-scripts(7).

Muchos de los módulos están documentados dentro del código. Consulte los módulos individuales para obtener su descripción detallada de las diferentes funciones disponibles.

Los módulos suelen instalarse en

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/common/quvi/

MÓDULOS

quvi/http/cookie

Un conjunto de funciones que envuelven la mayoría de las características de las funciones de quvi.http.cookie. Véase quvi-object(7).

quvi/const

Constantes. Técnicamente, (debido a la especificación del lenguaje Lua) estos no son valores inmutables. Las constantes se utilizan para interactuar con libquvi, p. ej., especificando modos de operación de funciones y comprobando códigos de retorno de libquvi devueltos.

quvi/debug

Una utilidad de salida de mensajes destinada a ser utilizada con fines de depuración. Por defecto, toda la salida de los scripts que utilizan esta utilidad permanece deshabilitada. Para habilitar la salida, defina la variable de entorno LIBQUVI_SCRIPTS_VERBOSE.

quvi/entity

Módulo de conversión de entidades HTML. Convierte las entidades HTML estándar (a ASCII) y cualquier entidad HTML numérica a UTF-8 (utilizando el módulo quvi/html).

quvi/hash

Funciones de envoltura para algunas de las funciones comunes de hash (resumen de mensajes) proporcionadas por quvi-object(7). Tenga en cuenta que estas funciones convierten los datos proporcionados a formato hexadecimal antes de pasarlos a las funciones de hash.

quvi/hex

Funciones para convertir valores desde y hacia formato hexadecimal. Estos se utilizan típicamente junto con las funciones criptográficas de quvi-object(7).

quvi/html

Convierte entidades HTML numéricas a UTF-8. Véase también quvi/entity, que utiliza este módulo.

quvi/lxph

Funciones de utilidad/envoltura de LuaExpat para analizar XML, véase también quvi-modules-3rdparty(7).

quvi/stream

Funciones relacionadas con flujos multimedia.

quvi/time

Funciones relacionadas con el tiempo.

quvi/util

Funciones de utilidad varias.

quvi/youtube

Funciones comunes a YouTube.
