QCMD(1) Manual de Comandos Generales QCMD(1)

NOMBRE

qmv, qcp - Renombrar o copiar archivos rápidamente, editando los nombres de archivo en un editor de texto

SINOPSIS

qcp [OPCIÓN]... [ARCHIVO]...

qmv [OPCIÓN]... [ARCHIVO]...

qcmd --comando=COMANDO [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Esta página del manual describe los comandos qcp, qmv y qcmd.

El programa qmv permite renombrar archivos editando sus nombres en cualquier editor de texto. Cambiando una letra en un documento de texto, se puede cambiar una letra en un nombre de archivo. Como los archivos se listan uno detrás de otro, los cambios comunes se pueden realizar más rápidamente.

El programa qcp funciona como qmv, pero copia archivos en lugar de moverlos.

El programa qmv fue construido pensando en la seguridad: se evitan renombres erróneos causados por errores humanos al realizar tantas comprobaciones como sea posible. Debido a esto, qmv soporta un modo interactivo donde cada paso del procedimiento de renombrado se puede ejecutar manualmente. El valor predeterminado es iniciar qmv en modo no interactivo. Sin embargo, cuando hay un conflicto o error, qmv pasará a modo interactivo (en lugar de perder todos los cambios realizados por el usuario). Para más información sobre el proceso de renombrado y el modo interactivo, véase más abajo. Esto también se aplica a qcp.

El programa qcmd funciona igual que qmv y qcp pero te permite especificar qué comando ejecutar.

El programa ls(1) se utiliza para listar los archivos a renombrar o copiar. Por lo tanto, qmv, qcp y qcmd aceptan algunas opciones de ls.

PROCESO DE RENOMBRADO/COPIADO

El proceso de renombrar o copiar archivos consta de muchos pasos. Estos son:

Listar archivos
Generar una lista de archivos para renombrar a partir de los argumentos de la línea de comandos utilizando ls(1).
Crear un archivo de texto editable
El formato de edición crea un archivo de texto editable con los nombres de archivo.
Iniciar el editor
Iniciar el editor de texto y esperar hasta que el usuario haya terminado de editarlo.
Leer el archivo de texto editado
El formato de edición lee el archivo de texto editado ahora con los nombres de archivo actualizados.
Comprobar renombre y reordenar para resolver conflictos (solo qmv)
Este es un paso complicado que implica las siguientes tareas:

Etiquetar renombrados donde el archivo de destino ya existe, renombrados donde el archivo antiguo ahora falta o es inaccesible, y renombrados donde el nuevo nombre no se modificó. Realizar una ordenación topológica de los renombrados, de modo que el renombrado b->c, a->b sea posible. Resolver referencias cruzadas renombrando a nombres temporales, de modo que el renombrado e->f, f->e (o e->f, f->g, g->e y así sucesivamente) sea posible.

Este paso da como resultado un plan de renombrados.

Mostrar el plan.
Mostrar el plan al usuario.
Aplicar el plan.
Aplicar el plan renombrando o copiando realmente los archivos (a menos que se haya especificado --dummy).

Si ocurre un error durante cualquiera de los pasos anteriores (excepto el primero), qmv/qcp pasa al usuario al modo interactivo. De esta manera no se perderán cambios y los errores se podrán corregir manualmente antes de continuar. Véase más abajo para una descripción del modo interactivo.

OPCIONES

Estos programas siguen la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-').

-a, --all
(Pasado a ls.) No ocultar entradas que comiencen por `.'.
-A, --almost-all
(Pasado a ls.) No listar `.' y `..' implícitos.
-B, --ignore-backups
(Pasado a ls.) No listar entradas implícitas que terminen en `~'.
-c
(Pasado a ls.) Ordenar por ctime (tiempo de la última modificación).
--comando=COMANDO
Ejecutar COMANDO en lugar de mv o cp.
-d, --directory
(Pasado a ls.) Listar entradas de directorio en lugar de contenidos.
-r, --reverse
(Pasado a ls.) Invertir el orden al ordenar.
-R, --recursive
(Pasado a ls.) Listar subdirectorios recursivamente.
-S
(Pasado a ls.) Ordenar por tamaño de archivo.
--sort=PALABRA
(Pasado a ls.) Ordenar por extensión (-X), ninguno (-U), tamaño (-S), tiempo (-t), versión (-v), estado (-c), tiempo (-t), atime (-u), o acceso (-u).
--time=PALABRA
(Pasado a ls.) Si la ordenación se realiza por tiempo (--sort=time), ordenar por atime, acceso, uso, ctime o tiempo de estado.
-t
(Pasado a ls.) Ordenar por tiempo de modificación.
-u
(Pasado a ls.) Ordenar por tiempo de acceso.
-U
(Pasado a ls.) No ordenar; listar entradas en orden de directorio.
-X
(Pasado a ls.) Ordenar alfabéticamente por la extensión de la entrada.
-f, --format=FORMATO
Cambiar el formato de edición del archivo de texto. Ver más abajo para posibles valores.
-o, --options=OPCIONES
Pasar opciones al formato de edición seleccionado. OPCIONES tiene el formato

OPCIÓN[=VALOR][,OPCIÓN[=VALOR]...]

Para una lista de opciones disponibles para cada formato, use --options=help o véase más abajo.

-i, --interactive
Iniciar en modo de comando (véase más abajo para información sobre este modo).
-e, --editor=PROGRAMA
Especificar el programa para editar el archivo de texto. El programa predeterminado se determina buscando la variable de entorno VISUAL, o si esta no está establecida, la variable de entorno EDITOR. Si ninguna de estas está establecida, usar el programa llamado editor.
--ls=PROGRAMA
Especificar la ruta del programa ls. Si omite el directorio, el ejecutable se buscará en los directorios especificados por la variable de entorno PATH.
-v, --verbose
Ser más detallado sobre lo que se está haciendo.
--dummy
Hacer todo como normalmente, excepto renombrar realmente ningún archivo (modo "dummy").
--help
Mostrar resumen de opciones.
--version
Mostrar información de la versión y salir.

FORMATOS DE EDICIÓN

Un formato de edición es responsable de generar un archivo de texto para editarlo, y de parsearlo una vez que ha sido editado. El formato predeterminado es de doble columna, pero existen otros formatos.

No todos los formatos de edición aceptan las mismas opciones. Por lo tanto, es necesario especificarlas usando la opción --options (-o). Esta opción toma una lista de "subopciones" similar a la opción -o en mount(8).

Los formatos de edición disponibles son `single-column' (o `sc'), `dual-column' (o `dc'), y `destination-only' (o `do'). El formato predeterminado es dual-column.

FORMATO DOBLE-COLUMNA

Este es el formato predeterminado y se utiliza para mostrar el nombre original del archivo en la primera columna y el nombre deseado en la segunda columna. Por ejemplo:

#
# Rename files.
#
# Lines starting with '#' are ignored.
#
# The files are listed below. You can edit the second column.
#
# If you want to rename a file, you must change the second column.
#
# If you want to skip renaming a file, you must leave the second column unchanged.
#
# If you want to rename more than one file, you must change more than one line.
#
# WARNING: Any spaces in file names must be escaped with a backslash ('\').
#          This includes spaces between words, and at the beginning of file names.
#
# Original name                    New name
# ---------------------------------------------------------------------------
old-file-name.txt                new-file-name.txt
/path/to/old/file.txt            /path/to/new/file.txt
file\ name\ with\ spaces.txt     file\ name\ with\ spaces\ renamed.txt

Las opciones disponibles para este formato son:

-d, --show-hidden
Mostrar archivos ocultos (que comienzan con un punto). Por defecto, estos archivos se omiten.
-s, --show-spaces
Mostrar nombres de archivo que contienen espacios en la columna de nombres de archivo originales y en la columna de nombres de archivo nuevos, sin escapar los espacios con una barra invertida. Por defecto, los espacios se escapan.

MODO INTERACTIVO

Si se inicia en modo interactivo (con la opción -i o al ocurrir un error), qmv/qcp presentará un menú de opciones:

 qmv-edit/cp: 1/10 files to rename
 Command line: qmv --editor=vim --format=dual-column file1 file2 file3
 Files:
       file1 -> newname1
       file2 -> newname2
       file3 -> newname3

 Enter command (h for help):

Las siguientes teclas tienen significado:

h
Mostrar ayuda. Se lista un menú de comandos.
e
Editar la lista de nombres de archivo de nuevo.
l
Volver a listar los archivos. Útil si el cambio de nombres ha sido muy largo.
r
Volver a comprobar los nombres de archivo y las posibles dependencias.
p
Imprimir el plan de renombrado. Esto es útil para ver el orden en que se realizarán los renombrados.
a
Aplicar el plan de renombrado. Esto es lo mismo que ejecutar qmv/qcp sin la opción -i.
q
Salir. Si hay un plan de renombrado, se le preguntará si quiere aplicarlo primero.
x
Salir sin guardar. Todos los cambios realizados hasta el momento se perderán.

DUAL-COLUMN FORMAT

El formato de columna doble (`dual-column' o `dc') muestra los archivos en dos columnas. Este es el formato predeterminado y recomendado. La columna más a la izquierda suele ser el nombre del archivo de origen (que no debe editarse) y la columna más a la derecha el nombre del archivo de destino.

Opciones soportadas:

swap
Intercambiar la ubicación de los nombres antiguos y nuevos al editar. Es decir, la columna más a la izquierda es ahora el nombre del archivo de destino y la más a la derecha el nombre del archivo de origen.
separate
Poner una línea en blanco entre todos los cambios de nombre.
tabsize=SIZE
Por defecto, se utilizan caracteres de tabulación de tamaño 8 para separar las columnas. Con esta opción, se puede cambiar el ancho de estos caracteres de tabulación.
spaces
Usar caracteres de espacio en lugar de caracteres de tabulación al tabular.
width=WIDTH
Esta opción especifica la posición del carácter (horizontalmente) en la que comienza el segundo nombre de archivo.
autowidth
Normalmente, si el nombre del archivo de origen es más largo que width caracteres, el nombre de destino se imprime en la siguiente línea. Sin embargo, con esta opción habilitada, qmv/qcp ajustará el ancho para que los nombres de archivo de origen y destino se puedan mostrar en una sola línea.

Si se especificó un ancho con width antes de autowidth, ese ancho se utilizará como ancho mínimo.

Ejemplo: Supongamos que se especifica width=10,autowidth. Incluso si todos los nombres de archivo de origen son más cortos que cinco caracteres, el ancho de división sería 10. Si hubiera habido un nombre de archivo más largo que 10 caracteres, el ancho final habría sido superior a 10 caracteres.

Esta opción está habilitada por defecto.

indicator1=TEXT
Texto a colocar antes del primer nombre de archivo (columna).
indicator2=TEXT
Texto a colocar antes del segundo nombre de archivo (columna).
help
Mostrar resumen de las opciones de formato de edición.

SINGLE-COLUMN FORMAT

El formato de columna única (`single-column' o `sc') muestra los archivos en una sola columna: primero el nombre del archivo de origen y en la siguiente línea el nombre del archivo de destino.

Opciones soportadas:

swap
Intercambiar la ubicación de los nombres antiguos y nuevos al editar. Es decir, la primera línea contendrá el nombre del archivo de destino y la siguiente línea el nombre del archivo de origen.
separate
Poner una línea en blanco entre todos los cambios de nombre.
indicator1=TEXT
Texto a colocar antes del primer nombre de archivo.
indicator2=TEXT
Texto a colocar antes del segundo nombre de archivo.
help
Mostrar resumen de las opciones de formato de edición.

DESTINATION-ONLY FORMAT

El formato de solo destino (`destination-only' o `do') muestra los archivos solo con el nombre del archivo de destino, uno en cada línea. Este formato generalmente no se recomienda, ya que la única forma de identificar el nombre del archivo de origen es mirando el número de línea. Pero puede ser útil con algunos editores de texto.

Opciones soportadas:

separate
Poner una línea en blanco entre todos los cambios de nombre (nombres de archivo).

INTERACTIVE MODE

En modo interactivo, qmv/qcp lee comandos del teclado, los analiza y los ejecuta. Esto se hace utilizando GNU readline.

Los siguientes comandos están disponibles:

ls, list [OPTIONS].. [FILES]..
Seleccionar archivos para renombrar. Si no se especifican archivos, seleccionar todos los archivos en el directorio actual. Las opciones aceptadas son aquellas que se pasan a ls(1). Use `help ls' para mostrar una lista de estas.
import FILE
Leer archivos para renombrar de un archivo de texto. Cada línea debe corresponder a un archivo existente para renombrar.
ed, edit
Editar los cambios de nombre en un editor de texto. Si este comando se ha ejecutado antes, y no se especifica `all', solo editar los cambios de nombre con errores.
plan
Mostrar el plan de cambio de nombre actual. (Este plan se crea después de `edit'.)
apply
Aplicar el plan actual, es decir, renombrar archivos. Solo se renombrarán aquellos archivos marcados como OK en el plan.
retry
Si algunos cambios de nombre fallaron anteriormente durante `apply', este comando intentará de nuevo esos cambios de nombre.
show
Mostrar el valor de la variable de configuración especificada, o todas las variables si no se especifica ninguna. Consulte a continuación una lista de variables de configuración.
set VARIABLE VALUE
Establecer el valor de una variable de configuración.
exit, quit
Salir del programa. Si hay cambios no aplicados, se notificará al usuario, y será necesario ejecutar este comando una vez más para salir del programa.
help [ls|usage]
Si se especifica `ls', mostrar opciones de lista. Si se especifica `usage', mostrar opciones de línea de comandos aceptadas. De lo contrario, mostrar ayuda sobre los comandos en modo interactivo.
version
Mostrar información de la versión.

VARIABLES

Las siguientes variables están disponibles en modo interactivo:

dummy BOOLEAN
editor STRING
format STRING
options STRING
Estas variables corresponden a las opciones con el mismo nombre.
tempfile STRING
Esta variable contiene el nombre del archivo temporal que se edita con `edit'. No se puede establecer; solo se puede leer con `show'.

Un valor booleano se especifica como `0', `false', `no', `off' o `1', `true', `yes', y `on'. Las cadenas se especifican sin comillas.

EXAMPLES

Editar nombres de archivos en el directorio actual.
qmv

Editar nombres de archivos con extensión `.c'. Ordenar archivos por tiempo de modificación.
qmv -t *.c

Editar nombres de archivos usando el editor nedit y con un ancho de columna de 100.
qmv -enedit -owidth=100
