QR(1) Herramienta QR de Python QR(1)

NOMBRE

qr - script para crear códigos QR en la línea de comandos

SINOPSIS

qr [--ayuda] [--factoria=FACTORIA] [--optimizar=OPTIMIZAR] [--correccion-errores=NIVEL] [datos]

DESCRIPCIÓN

Este script utiliza el módulo qrcode de python. Puede tomar datos de stdin o de la línea de comandos y generar un código QR. Normalmente generará el código QR como arte ASCII en la terminal. Si la salida se redirige a un archivo, generará la imagen (tipo predeterminado PNG).

OPCIONES

 -h, --ayuda

Muestra un mensaje de ayuda.

 --factoria=FACTORIA

Ruta completa de python a la clase factoría de imágenes para crear la imagen. Puede utilizar los siguientes atajos a las clases factoría de imágenes integradas: pil (predeterminado), png (predeterminado si pillow no está instalado), svg, fragmento-svg, ruta-svg.

 --optimizar=OPTIMIZAR

Optimiza los datos buscando fragmentos de al menos esta cantidad de caracteres que podrían usar un método de codificación más eficiente. Use 0 para desactivar la optimización de fragmentos.

 --correccion-errores=NIVEL

El nivel de corrección de errores a utilizar. Las opciones son L (7%), M (15%, predeterminado), Q (25%) y H (30%).

 datos

Los datos a partir de los cuales se generará el código QR.
