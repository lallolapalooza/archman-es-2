QXGEDIT(1) Manual de Comandos Generales QXGEDIT(1)

NOMBRE

qxgedit - Editor Qt XG

SINOPSIS

qxgedit [opciones] [archivo-syx]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando qxgedit.

QXGEdit es una GUI Qt para editar archivos MIDI System Exclusive para dispositivos XG (por ejemplo, Yamaha DB50XG).

OPCIONES

-h, --help

Mostrar ayuda sobre las opciones de la línea de comandos

-v, --version

Mostrar información de la versión

ARCHIVOS

La configuración se guarda en ~/.config/rncbc.org/QXGEdit.conf

AUTOR
