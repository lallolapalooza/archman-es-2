QBRB.H(3) Manual del programador de libqb QBRB.H(3)

NOMBRE

qbrb.h - Implementa un buffer circular que opera en "trozos", no en bytes.

SINOPSIS

#include <qb/qbrb.h>

DESCRIPCIÓN

Así, se escribe/lee un trozo completo o no se hace nada. Hay dos tipos de buffer circular: normal y de sobreescritura. El de sobreescritura recuperará los trozos más antiguos para dar paso a los nuevos, mientras que la versión normal se negará a escribir un nuevo trozo si el buffer circular está lleno.

Esta implementación es capaz de funcionar entre procesos, pero un proceso solo debe escribir y el otro leer.

El proceso de lectura hará lo siguiente:

     rb = qb_rb_open("test2", 2000, QB_RB_FLAG_SHARED_PROCESS|QB_RB_FLAG_CREATE);
     for (i = 0; i < 200; i++) {
try_read_again:
        l = qb_rb_chunk_read(rb, (void *)out, 32, 1000);
        if (l < 0) {
                goto try_read_again;
        }
     }
     ...
     qb_rb_close(rb);

El proceso de escritura hará lo siguiente:

     rb = qb_rb_open("test2", 2000, QB_RB_FLAG_SHARED_PROCESS);
     for (i = 0; i < 200; i++) {
try_write_again:
        l = qb_rb_chunk_write(rb, &v, sizeof(v));
        if (l < sizeof(v)) {
                goto try_write_again;
        }
     }
     ...
     qb_rb_close(rb);
