QB_LIST_SPLICE(3) Manual del programador de libqb QB_LIST_SPLICE(3)

NOMBRE

qb_list_splice - Une dos listas.

SINOPSIS

#include <qb/qblist.h>

static void qb_list_splice(
    struct qb_list_head   *list,  /* la nueva lista a agregar. */
    struct qb_list_head   *head   /* el lugar donde agregarla en la primera lista.*/
);

PARÁMETROS

list la nueva lista a agregar.

head el lugar donde agregarla en la primera lista.

DESCRIPCIÓN

ESTRUCTURAS


struct qb_list_head {


    struct   next;

    struct   prev;
};

NOTA

La "lista" se reinicializa

VER TAMBIÉN
