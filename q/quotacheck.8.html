quotacheck(8) Manual del Administrador del Sistema quotacheck(8)

NOMBRE

quotacheck - escanea un sistema de archivos en busca de uso de disco, crea, verifica y repara archivos de cuota

SINOPSIS

quotacheck [ -gubcfinvdMmR ] [ -F formato-cuota ] -a | sistema-archivos

DESCRIPCIÓN

quotacheck examina cada sistema de archivos, construye una tabla del uso actual del disco y compara esta tabla con la registrada en el archivo de cuotas de disco para el sistema de archivos (este paso se omite si se especifica la opción -c). Si se detectan inconsistencias, se actualizan tanto el archivo de cuotas como la copia del sistema actual de las cuotas incorrectas (esta última solo ocurre si se verifica un sistema de archivos activo, lo cual no se recomienda). Por defecto, solo se verifican las cuotas de usuario. quotacheck espera que cada sistema de archivos a verificar tenga archivos de cuota llamados [a]quota.user y [a]quota.group ubicados en la raíz del sistema de archivos asociado. Si un archivo no está presente, quotacheck lo creará.

Si el archivo de cuotas está corrupto, quotacheck intenta guardar la mayor cantidad de datos posible. Recuperar los datos puede requerir intervención del usuario. Sin opciones adicionales, quotacheck simplemente saldrá en tal situación. Cuando está en modo interactivo (opción -i), se le pide al usuario su opinión. La opinión también se puede proporcionar desde la línea de comandos (ver opción -n), lo que es útil cuando quotacheck se ejecuta automáticamente (es decir, desde un script) y el fallo es inaceptable.

quotacheck debe ejecutarse cada vez que el sistema arranca y monta sistemas de archivos no válidos. Esto es más probable que ocurra después de una caída del sistema.

Se recomienda encarecidamente ejecutar quotacheck con las cuotas desactivadas para el sistema de archivos. De lo contrario, pueden producirse daños o pérdidas de datos en los archivos de cuotas. Tampoco es aconsejable ejecutar quotacheck en un sistema de archivos activo, ya que el uso real puede cambiar durante el escaneo. Para evitar esto, quotacheck intenta remontar el sistema de archivos en modo de solo lectura antes de comenzar el escaneo. Después de que el escaneo finaliza, vuelve a montar el sistema de archivos en modo de lectura y escritura. Puede deshabilitar esto con la opción -m. También puede hacer que quotacheck ignore el fallo al remontar el sistema de archivos en modo de solo lectura con la opción -M.

OPCIONES

-b, --backup
Fuerza a quotacheck a hacer copias de seguridad del archivo de cuotas antes de escribir los nuevos datos.
-v, --verbose
quotacheck informa de su operación a medida que progresa. Normalmente opera en silencio. Si la opción se especifica dos veces, también se imprime el directorio actual (tenga en cuenta que la impresión puede ralentizar el escaneo mediblemente).
-d, --debug
Habilita el modo de depuración. Proporcionará mucha información que puede usarse para depurar el programa. La salida es muy detallada y el escaneo será lento.
-u, --user
Solo se deben verificar las cuotas de usuario listadas en /etc/mtab o en los sistemas de archivos especificados. Esta es la acción predeterminada.
-g, --group
Solo se deben verificar las cuotas de grupo listadas en /etc/mtab o en los sistemas de archivos especificados.
-c, --create-files
No lea los archivos de cuotas existentes. Simplemente realice un nuevo escaneo y guárdelo en el disco. quotacheck también omite el escaneo de archivos de cuotas antiguos cuando no se encuentran.
-f, --force
Fuerza la verificación y escritura de nuevos archivos de cuotas en sistemas de archivos con cuotas habilitadas. Esto no se recomienda ya que los archivos de cuotas creados pueden no estar sincronizados.
-M, --try-remount
Esta bandera fuerza la verificación del sistema de archivos en modo de lectura y escritura si falla un remontaje. Haga esto solo cuando esté seguro de que ningún proceso escribirá en un sistema de archivos mientras se escanea.
-m, --no-remount
No intente remontar el sistema de archivos en modo de solo lectura. Consulte el comentario con la opción -M.
-i, --interactive
Modo interactivo. Por defecto, quotacheck sale cuando encuentra un error. En modo interactivo, se le pide al usuario que introduzca datos en su lugar. Consulte la opción -n.
-n, --use-first-dquot
Si los archivos de cuotas se corrompen, es posible que existan entradas duplicadas para un ID de usuario o grupo único. Normalmente, en este caso, quotacheck sale o le pide al usuario que introduzca datos. Cuando se establece esta opción, siempre se utiliza la primera entrada encontrada (esta opción también funciona en modo interactivo).
-F, --format=nombre-formato
Verifica y corrige los archivos de cuotas del formato especificado (es decir, no realiza la detección automática de formato). Esto se recomienda ya que la detección podría no funcionar bien en archivos de cuotas corruptos. Los nombres de formato posibles son: vfsold Formato de cuota original con UID / GID de 16 bits, vfsv0 Formato de cuota con UID / GID de 32 bits, uso de espacio de 64 bits, uso y límites de inode de 32 bits, vfsv1 Formato de cuota con límites y uso de cuotas de 64 bits, rpc (cuota sobre NFS), xfs (cuota en sistema de archivos XFS)
-a, --all
Verifica todos los sistemas de archivos montados no NFS en /etc/mtab
-R, --exclude-root
Cuando se utiliza junto con la opción -a, se verifican todas las cuotas de los sistemas de archivos excepto el sistema de archivos raíz.

NOTA

quotacheck solo debe ser ejecutado por el superusuario. Es de suponer que los usuarios no privilegiados no tienen permiso para leer todos los directorios en el sistema de archivos dado.
