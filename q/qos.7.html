NOMBRE

qos - especificación de Calidad de Servicio

DESCRIPCIÓN

Las funciones text2qos y qos2text utilizan el formato descrito en esta página del manual. Dado que todas las herramientas estándar de ATM en Linux utilizan estas funciones para convertir desde o hacia la representación textual de las especificaciones de QOS, también esperan que estén en el mismo formato.

Los parámetros más fundamentales son la clase de tráfico y el tipo de AAL (Capa de Adaptación ATM). Si la conexión es bidireccional, ambas direcciones tienen la misma clase de tráfico y el mismo tipo de AAL. La clase de tráfico y el tipo de AAL son los primeros elementos (en cualquier orden) en una especificación QOS. La clase de tráfico es el único elemento requerido. Si se omite el tipo de AAL, la aplicación proporcionará un valor predeterminado. Se reconocen las siguientes clases de tráfico:

ubr
Unassigned Bit Rate (Tasa de bits no asignada)
cbr
Constant Bit Rate (Tasa de bits constante)
abr
Available Bit Rate (Tasa de bits disponible)

Se reconocen los siguientes tipos de AAL:

aal0
("ATM en crudo")
aal5

Si se especifican tanto la clase de tráfico como el tipo de AAL, estos se separan por una coma.

Si se proporcionan más parámetros, la clase de tráfico y el tipo de AAL deben ir seguidos de dos puntos. Los parámetros de tráfico se pueden especificar de forma independiente para la dirección de transmisión y recepción. Sus listas de parámetros van precedidas de tx: y rx:, respectivamente. Si ambas listas de parámetros están presentes, la lista tx: debe preceder a la lista rx:. Si un parámetro es igual para ambas direcciones, se puede colocar en una lista de parámetros común (sin prefijo). El formato general es el siguiente:

clase_y_aal:lista_comun,tx:lista,rx:lista

Cada lista consta de elementos que especifican un parámetro. Los elementos pueden aparecer en cualquier orden y se separan con comas. Se reconocen los siguientes elementos:

pcr=tasa
es un sinónimo de max_pcr=tasa
max_pcr=tasa
El límite superior para la tasa de celdas pico a asignar. Si se omite, se puede elegir cualquier tasa hasta la velocidad del enlace.
min_pcr=tasa
El límite inferior para la tasa de celdas pico a asignar. Si se omite, se puede elegir cualquier tasa superior a cero.
sdu=tamaño
es un sinónimo de max_sdu=tamaño
max_sdu=tamaño
El tamaño del paquete más grande que se puede enviar o recibir. Si se omite, se utiliza un valor predeterminado dependiente del contexto.

Los valores se especifican de la siguiente manera:

tasa
La tasa (decimal), seguida opcionalmente de una unidad. La unidad puede ir precedida por uno de los multiplicadores k, M o G, que significan 1'000, 1'000'000 o 1'000'000'000, respectivamente. Se reconocen las unidades cps (celdas por segundo) y bps (bits por segundo). Si se omiten el multiplicador y la unidad, se asumen celdas por segundo. Tenga en cuenta que la tasa siempre se convierte a celdas por segundo, por lo que pueden producirse errores de redondeo al especificar la tasa en bits por segundo. Las tasas medidas en bits por segundo se consideran tasas de datos de usuario, es decir, una celda corresponde a 384 bits. La tasa puede ser un valor fraccionario, por ejemplo, 1.3Mbps. Es un error especificar solo un multiplicador sin una unidad. La velocidad del enlace se puede indicar utilizando la palabra clave max como tasa.
tamaño
El número (decimal) de bytes.

Las listas tx: o rx: también pueden contener simplemente el elemento único none, lo que indica que la dirección correspondiente no se utiliza. Es un error especificar none para ambas direcciones.

Tenga en cuenta que las comas nunca deben seguir a los dos puntos u otras comas. Además, no se permiten espacios en blanco dentro de una especificación QOS. Las especificaciones QOS no distinguen entre mayúsculas y minúsculas.

EJEMPLOS

Cada una de las siguientes líneas contiene una especificación QOS válida:

  ubr
  ubr:pcr=100kbps
  cbr,aal0:pcr=64kbps
  CBR:max_pcr=11Mbps,min_pcr=10mbps,sdu=8192
  aal5,ubr:tx:none
  cbr:tx:pcr=30000,rx:none

Las siguientes especificaciones son equivalentes:

  CBR,AAL5:PCR=48Mbps
  cbr,aal5:max_pcr=125000
  cbr,aal5:tx:pcr=125kcps,rx:pcr=125kcps
