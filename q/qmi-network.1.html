QMI-NETWORK(1) Comandos de usuario QMI-NETWORK(1)

NOMBRE

qmi-network - Gestión de red simple de dispositivos QMI

SINOPSIS

qmi-network [OPCIONES] [DISPOSITIVO] [COMANDO]

DESCRIPCIÓN

Gestión de red simple de dispositivos QMI

Comandos:

start
Iniciar conexión de red
stop
Detener conexión de red
status
Consultar estado de conexión de red

OPCIONES

--profile=[RUTA]
Usar el perfil en la ruta especificada
--help
Mostrar opciones de ayuda
--version
Mostrar versión

Notas:

1) [DISPOSITIVO] se proporciona como la ruta completa al dispositivo de carácter cdc-wdm, por ejemplo:
/dev/cdc-wdm0
2) El script qmi-network requiere un perfil para funcionar. A menos que se especifique explícitamente con `--profile', se asume que el archivo está disponible en la siguiente ruta:
/etc/qmi-network.conf
3) El APN a utilizar debe configurarse en el perfil, de la siguiente manera (por ejemplo, asumiendo que el APN se llama 'internet'):
APN=internet
4) Opcionalmente, se pueden proporcionar cadenas de usuario/contraseña APN de la siguiente manera:
APN_USER=usuario APN_PASS=contraseña
5) Opcionalmente, se pueden proporcionar cadenas IP_TYPE de la siguiente manera:
IP_TYPE=[4|6]
6) Si desea indicar al script qmi-network que utilice la configuración de qmi-proxy, puede hacerlo configurando la siguiente línea en el perfil:
PROXY=yes
7) Para indicar al script qmi-network que utilice un ID de perfil ya existente, o para crear uno nuevo sobre la marcha, utilice la siguiente configuración en el perfil:
PERFIL=número
# para usar el perfil-id número
PERFIL=auto
# para crear un perfil temporal sobre la marcha
8) Una vez que el script qmi-network informe de una conexión exitosa, todavía necesitará ejecutar un cliente DHCP en la interfaz de red WWAN asociada.
