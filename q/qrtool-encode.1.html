QRTOOL-ENCODE(1) Manual de comandos generales QRTOOL-ENCODE(1)

NOMBRE

qrtool-encode - codifica datos de entrada en un código QR

SINOPSIS

qrtool encode [OPCIÓN]... [CADENA]

DESCRIPCIÓN

Este comando codifica datos de entrada en un código QR https://www.qrcode.com y lo genera como una imagen PNG, una imagen SVG, una cadena de texto, u otros formatos. Por defecto, el resultado se enviará a la salida estándar.

Este comando leerá hasta los primeros 7.090 bytes de los datos de entrada. La cantidad de datos que puede ser representada por un código QR depende del modo, la versión y el nivel de corrección de errores. La capacidad de almacenamiento se maximiza para la versión 40 y el nivel de corrección de errores L (40-L).

Tabla 1. Capacidad máxima de almacenamiento de caracteres (40-L)

Modo de entrada Máx. caracteres Caracteres posibles
Numérico 7.089 0-9
Alfanumérico 4.296 0-9, A-Z (solo mayúsculas), y pocos símbolos (espacio, $, %, *, +, -, ., /, :)
Byte 2.953 Datos binarios arbitrarios
Kanji 1.817 Cualquier carácter JIS X 0208 de doble byte

Por defecto, este comando codifica los datos de entrada en un código QR con un fondo
negro y blanco, pero esto se puede cambiar especificando --foreground y/o --background. La cadena de color CSS https://www.w3.org/TR/css-color-4/ puede ser especificada como valor para estas opciones.

Tabla 2. Lista de métodos para especificar un color

Formato Ejemplos
Colores con nombre brown, lightslategray
Notaciones hexadecimales #111, #eee8, #a52a2a, #7788997f
Funciones RGB rgb(165 42 42), rgb(119 136 153 / 49.8%)
Funciones HSL hsl(248 39% 39.2%), hsl(0 0% 66.3% / 49.8%)
Función HWB hwb(50.6 0% 0%), hwb(0 66.3% 33.7% / 49.8%)
Función Oklab oklab(50.4% -0.0906 0.0069), oklab(61.9% -0.0120 -0.0302 / 0.5)
Función Oklch oklch(59.41% 0.16 301.29), oklch(61.9% 0.032 248.35 / 49.8%)

Además de un
código QR normal https://www.qrcode.com/codes/model12.html, este comando también puede codificar los datos de entrada en un código QR Micro https://www.qrcode.com/codes/microqr.html y un código rMQR https://www.qrcode.com/codes/rmqr.html.

ARGUMENTOS POSICIONALES

CADENA

Datos de entrada. Si no se especifica CADENA, los datos se leerán de la entrada estándar. CADENA debe ser una cadena UTF-8 válida. Utilice --read-from o lea desde la entrada estándar si toma algo que no sea una cadena UTF-8 válida. Este argumento posicional entra en conflicto con --read-from.

OPCIONES

-o, --output ARCHIVO

Genera el resultado en un archivo.

-r, --read-from ARCHIVO

Lee los datos de entrada desde un archivo. Esta opción entra en conflicto con CADENA.

-s, --size NÚMERO

El tamaño del módulo en píxeles. Si no se especifica esta opción, el tamaño del módulo es 8 cuando el formato de salida es PNG, SVG, EPS o PIC, y 1 en caso contrario.

-l, --error-correction-level NIVEL

Nivel de corrección de errores.

Los valores posibles son:

l

Nivel L. Se pueden restaurar el 7% de las palabras de código.

m

Nivel M. Se pueden restaurar el 15% de las palabras de código. Este es el valor por defecto.

q

Nivel Q. Se pueden restaurar el 25% de las palabras de código.

h

Nivel H. Se pueden restaurar el 30% de las palabras de código.

--level NIVEL

Alias de -l, --error-correction-level.

-v, --symbol-version NÚMERO [NÚMERO]

La versión del símbolo. Si no se especifica esta opción, se elegirá automáticamente la versión mínima necesaria para almacenar los datos. Para códigos QR normales, NÚMERO debe estar entre 1 y 40. Para códigos QR Micro, NÚMERO debe estar entre 1 y 4. Para códigos rMQR, el primer NÚMERO debe ser 7, 9, 11, 13, 15 o 17. El segundo NÚMERO debe ser 27, 43, 59, 77, 99 o 139. 27 solo puede usarse con 11 o 13. Si el tipo de código QR es diferente a rMQR, el segundo NÚMERO se ignora.

--symversion NÚMERO [NÚMERO]

Alias de -v, --symbol-version.

-m, --margin NÚMERO

El ancho del margen. Si no se especifica esta opción, el margen será de 4 para códigos QR normales y de 2 para otros.

-t, --type FORMATO

El formato de la salida.

Los valores posibles son:

png

Portable Network Graphics. Genera una imagen PNG RGBA de 32 bits. Este es el valor por defecto.

svg

Scalable Vector Graphics.

eps

Encapsulated PostScript.

pic

Lenguaje de marcado PIC.

ansi

A la terminal usando secuencias de escape ANSI de 4 bits. Este valor está disponible si la característica output-as-ansi está habilitada en tiempo de compilación.

ansi256

A la terminal usando secuencias de escape ANSI de 8 bits. Este valor está disponible si la característica output-as-ansi está habilitada en tiempo de compilación.

ansi-true-color

A la terminal usando secuencias de escape ANSI de 24 bits. Este valor está disponible si la característica output-as-ansi está habilitada en tiempo de compilación.

ascii

A la terminal como cadena ASCII.

ascii-invert

A la terminal como cadena ASCII. Este valor invierte los colores de primer plano y fondo de ascii y genera la cadena invertida. ASCIIi es un alias para este valor.

unicode

A la terminal como cadena UTF-8. terminal y UTF8 son alias para este valor.

unicode-invert

A UTF-8 string to the terminal. This value inverts los colores de primer plano y fondo de unicode y produce la cadena invertida. UTF8i es un alias para este valor.

--optimize-png [NIVEL]

Establece el nivel de optimización para una imagen PNG. Los niveles más bajos son más rápidos, los niveles más altos ofrecen una mejor compresión. Si no se especifica NIVEL, se asume que se especifica el nivel predeterminado 2. Esta opción está disponible si la función optimize-output-png está habilitada en tiempo de compilación.

Los valores posibles son:

0

Nivel 0. Este valor es el nivel de optimización mínimo.

1

Nivel 1.

2

Nivel 2. Este es el valor predeterminado.

3

Nivel 3.

4

Nivel 4.

5

Nivel 5.

6

Nivel 6. Este valor es el nivel de optimización máximo.

max

Este valor es un alias para el nivel de optimización máximo.

--zopfli [ITERACION]

Utiliza Zopfli para comprimir la imagen PNG. Realiza la compresión durante el número de iteraciones especificado por ITERACION. Si no se especifica ITERACION, se asume que se especifican 15 como número de iteraciones. Esta opción requiere --optimize-png. Esta opción está disponible si la función optimize-output-png está habilitada en tiempo de compilación.

--mode MODO

El modo de salida. Si no se especifica esta opción, se utiliza la codificación óptima. Esta opción requiere --symbol-version.

Los valores posibles son:

numeric

Todos los dígitos.

alphanumeric

Alfanuméricos y pocos símbolos.

byte

Datos binarios arbitrarios.

kanji

Texto Shift JIS.

--variant TIPO

El tipo de código QR.

Los valores posibles son:

normal

Código QR normal. Este es el valor predeterminado.

micro

Código Micro QR.

rmqr

Código rMQR.

--foreground COLOR

Color de primer plano. COLOR toma una cadena de color CSS. La salida en color solo está disponible cuando el formato de salida es PNG, SVG o cualquier secuencia de escape ANSI. Tenga en cuenta que puede realizarse una conversión con pérdida dependiendo del espacio de color compatible con el método para especificar un color, la profundidad de color compatible con el formato de salida, etc. El valor predeterminado es negro.

--background COLOR

Color de fondo. COLOR toma una cadena de color CSS. La salida en color solo está disponible cuando el formato de salida es PNG, SVG o cualquier secuencia de escape ANSI. Tenga en cuenta que puede realizarse una conversión con pérdida dependiendo del espacio de color compatible con el método para especificar un color, la profundidad de color compatible con el formato de salida, etc. El valor predeterminado es blanco.

--verbose

También imprime los metadatos. Se envían a stderr.

-h, --help

Imprime el mensaje de ayuda. La bandera corta (-h) imprimirá un mensaje de ayuda condensado, mientras que la bandera larga (--help) imprimirá un mensaje de ayuda detallado.

-V, --version

Imprime el número de versión.

ESTADO DE SALIDA

0

Ejecución exitosa del programa.

1

Ocurrió un error.

2

Ocurrió un error al analizar los argumentos de la línea de comandos.

Los estados de salida distintos de estos se definen por <sysexits.h> https://man.openbsd.org/sysexits.

EJEMPLOS

Codifica la cadena dada en un código QR:

$ qrtool encode "QR code" > output.png

Codifica el archivo dado y produce la imagen especificada:

$ qrtool encode -o output.png -r go.mod

Codifica a una imagen SVG:

$ qrtool encode -t svg "QR code" > output.svg

Codifica a un código Micro QR:

$ qrtool encode --variant micro "QR code" > output.png

Codifica con los colores especificados:

$ qrtool encode -o output.png --foreground brown --background lightslategray "QR code"
