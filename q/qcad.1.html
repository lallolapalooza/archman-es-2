NOMBRE

qcad - Una aplicación de dibujo con muchas funciones

SINOPSIS

qcad [ opciones ] [ archivos ]

DESCRIPCIÓN

QCAD es una aplicación gratuita y de código abierto para Diseño Asistido por Computadora (CAD) en dos dimensiones (2D). Con QCAD puede crear, estudiar y modificar dibujos técnicos como planos de edificios, interiores, piezas mecánicas o esquemas y diagramas. QCAD se basa en el formato Drawing Interchange File Format (DXF). Dichos archivos DXF son utilizados por muchos otros sistemas CAD profesionales.

QCAD funciona en Windows, Mac OS X y Linux. El código fuente de QCAD se publica bajo la Licencia Pública General de GNU versión 3 (GPLv3), una popular licencia de Código Abierto.

OPCIONES

-ayuda
Muestra esta ayuda.
-version
Muestra la versión de la aplicación.
-config ruta
Lee y almacena la configuración en QCAD3.ini en la ubicación dada en lugar de la ubicación predeterminada.
-locale localidad
Establece la localidad a utilizar (anula el idioma configurado en las preferencias). Por ejemplo, '-locale es' inicia QCAD en español.
-filtro filtro
Abre los siguientes archivos con el filtro de importación explícitamente dado.
-permitir-instancias-multiples
No intente evitar que se ejecuten varias instancias simultáneamente.
-id-app ID
Establece el ID de la aplicación. Varias instancias de la misma aplicación (mismo ID) no pueden ejecutarse simultáneamente a menos que se use -permitir-instancias-multiples.
-re-escanear
Vuelve a escanear la carpeta de scripts en busca de nuevos complementos.
-cargar-scripts-siempre
Fuerza la recarga de scripts cuando se usan. Esto es principalmente útil durante el desarrollo de scripts, para aplicar cambios sin reiniciar QCAD.
-habilitar-depurador-scripts
Habilita el depurador de scripts. NO se recomienda ya que puede causar un comportamiento inesperado al usar QCAD.
-orden-acciones-debug
Imprime información sobre el orden de las acciones en los menús.
-autostart archivo-script
Inicia el archivo de script dado en lugar del predeterminado scripts/autostart.js. Tenga en cuenta que con esta opción, QCAD no se inicia, sino la aplicación implementada en el script dado.
-ejecutar archivo-script [ opciones ]
Ejecuta el archivo de script dado directamente después de iniciar QCAD. Las opciones después del archivo de script se pasan al script.
-archivo-css-gui archivo-CSS
Carga el archivo CSS especificado.
-sin-gui
No usar GUI. X11: no conectarse al servidor X11.
-no-mostrar
Usar pero no mostrar la GUI.
-habilitar-xdata
Habilita el soporte XData (propiedades personalizadas).
-salir
Cierra QCAD, por ejemplo, después de ejecutar el script dado.
