QMIDICTL(1) Manual de Comandos Generales QMIDICTL(1)

NOMBRE

qmidictl - Un controlador remoto MIDI a través de multicast UDP/IP

SINOPSIS

qmidictl [opciones]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando qmidictl.

QmidiCtl es una aplicación de controlador remoto MIDI que envía datos MIDI a través de la red, utilizando multicast UDP/IP. Inspirado en multimidicast (http://llg.cubic.org/tools) y diseñado para ser compatible con ipMIDI para Windows (http://nerds.de).

OPCIONES

-i, --interface=[interfaz]

Utilizar una interfaz de red específica (por defecto = todas)

-u, --address, --udp-addr=[dirección]

Utilizar una dirección de red específica (por defecto = 225.0.0.37)

-p, --port, --udp-port=[puerto]

Utilizar un puerto de red específico (por defecto = 21928)

-m, --mmc-device=[dispositivo-mmc]

Utilizar un número de dispositivo MMC específico (por defecto = 127)

-h, --help

Mostrar ayuda sobre las opciones de línea de comandos

-v, --version

Mostrar información de la versión

ARCHIVOS

La configuración se almacena en ~/.config/rncbc.org/QmidiCtl.conf

VER TAMBIÉN

qmidinet(1)
