QRENCODE(1) Manual de Comandos Generales QRENCODE(1)

NOMBRE

qrencode - Codifica datos de entrada en un código QR y lo guarda como imagen PNG o EPS.

SINOPSIS

qrencode [-o FILENAME] [OPCIÓN]... [CADENA]

DESCRIPCIÓN

Libqrencode es una biblioteca para codificar datos en un símbolo de código QR, un tipo de simbología 2D que puede ser escaneada por terminales portátiles como un teléfono móvil con CCD. La capacidad del código QR es de hasta 7000 dígitos o 4000 caracteres, y tiene alta robustez.

Qrencode es un software utilitario que utiliza libqrencode para codificar datos de cadena en un código QR y guardarlo como imagen PNG o EPS.

OPCIONES

-h, --help
muestra el mensaje de ayuda.
-o FILENAME, --output=FILENAME
escribe la imagen en FILENAME. Si se especifica '-', el resultado se enviará a la salida estándar. Si se proporciona -S, los símbolos estructurados se escribirán en FILENAME-01.png, FILENAME-02.png, ... (el sufijo se elimina de FILENAME, si se especifica)
-r FILENAME, --read-from=FILENAME
lee los datos de entrada de FILENAME.
-s NÚMERO, --size=NÚMERO
especifica el tamaño del punto (píxel). (predeterminado=3)
-l {LMQH}, --level={LMQH}
especifica el nivel de corrección de errores de L (más bajo) a H (más alto). (predeterminado=L)
-v NÚMERO, --symversion=NÚMERO
especifica la versión mínima del símbolo. Consulte VERSIONES DE SÍMBOLOS para más información. (predeterminado=auto)
-m NÚMERO, --margin=NÚMERO
especifica el ancho del margen. (predeterminado=4)
-d NÚMERO, --dpi=NÚMERO
especifica el DPI de la imagen PNG generada. (predeterminado=72)
-t {PNG,PNG32,EPS,SVG,XPM,ANSI,ANSI256,ASCII,ASCIIi,UTF8,UTF8i,ANSIUTF8,ANSIUTF8i,ANSI256UTF8}
--type={PNG,PNG32,EPS,SVG,XPM,ANSI,ANSI256,ASCII,ASCIIi,UTF8,UTF8i,ANSIUTF8,ANSIUTF8i,ANSI256UTF8}
especifica el tipo de imagen generada. (predeterminado=PNG)
-S, --structured
crea símbolos estructurados. El número de versión debe especificarse con '-v'.
-k, --kanji
asume que el texto de entrada contiene kanji (shift-jis).
-c, --casesensitive
codifica caracteres alfabéticos en minúsculas en modo de 8 bits. (predeterminado)
-i, --ignorecase
ignora las distinciones entre mayúsculas y minúsculas y utiliza solo caracteres en mayúsculas.
-8, --8bit
codifica todos los datos en modo de 8 bits. -k, -c y -i se ignorarán.
-M, --micro
codifica en un Micro Código QR. Consulte CÓDIGO QR MICRO para más información.
--rle
habilita la codificación run-length para SVG.
--svg-path
usa una única ruta para dibujar módulos para SVG.
--inline
solo útil para salida SVG, genera un SVG sin la etiqueta XML.
--foreground=RRGGBB[AA]
--background=RRGGBB[AA]
especifica el color de primer plano/fondo en notación hexadecimal. Se admiten formatos de 6 dígitos (RGB) u 8 dígitos (RGBA). La compatibilidad con salida de color solo está disponible en PNG, EPS y SVG.
--strict-version
deshabilita el ajuste automático del número de versión. Si los datos de entrada son demasiado grandes para la versión especificada, el programa saldrá con el código 1.
-V, --version
muestra el número de versión y los derechos de autor de qrencode.
--verbose
muestra información detallada en stderr.
[CADENA]
datos de entrada. Si no se especifica, los datos se tomarán de la entrada estándar.

VERSIONES DE SÍMBOLOS

Las versiones de símbolos de QR Code van de la Versión 1 a la Versión 40. Cada versión tiene una configuración de módulos diferente o un número de módulos, que va desde la Versión 1 (21 x 21 módulos) hasta la Versión 40 (177 x 177 módulos). Cada número de versión superior comprende 4 módulos adicionales por lado por defecto. Consulte http://www.qrcode.com/en/about/version.html para una lista detallada de versiones.

CÓDIGO QR MICRO

Con Micro QR Code, puedes incrustar datos en un área más pequeña que con QR Code, pero la capacidad de datos está fuertemente limitada. Las versiones de símbolos van de la Versión 1 a la 4.

EJEMPLOS

qrencode -l L -v 1 -o output.png 'Hola, mundo!'
codifica en un símbolo de versión 1, nivel L.
qrencode -iSv 1 --output=output.png
lee la entrada estándar y la codifica en símbolos de tipo estructurado y apéndice en modo insensible a mayúsculas/minúsculas.
qrencode -S -v 40 -l L -r bigfile.txt -o output.png
lee los datos de entrada de bigfile.txt y los codifica en un símbolo de versión 40, nivel L.
