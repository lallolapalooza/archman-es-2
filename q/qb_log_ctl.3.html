QB_LOG_CTL(3) Manual del programador de libqb QB_LOG_CTL(3)

NOMBRE

qb_log_ctl - Función principal de control de registro.

SINOPSIS

#include <qb/qblog.h>

int32_t qb_log_ctl(
    /*
     * QB_LOG_SYSLOG, QB_LOG_STDERR o el resultado de qb_log_file_open()
     */
    int32_t           target,
    /*
     * directiva de configuración ("qué configurar") que acepta un argumento
     * int32_t que determina el nuevo valor, a menos que se ignore para una directiva particular
     * por completo (directivas incompatibles: QB_LOG_CONF_IDENT)
     */
    enum qb_log_conf  conf_type,
    /*
     * el nuevo valor para una directiva de configuración que cambia el estado, se ignora
     * de lo contrario
     */
    int32_t           arg
);

PARÁMETROS

target QB_LOG_SYSLOG, QB_LOG_STDERR o el resultado de qb_log_file_open()

conf_type directiva de configuración ("qué configurar") que acepta un argumento int32_t que determina el nuevo valor, a menos que se ignore para una directiva particular por completo (directivas incompatibles: QB_LOG_CONF_IDENT)

arg el nuevo valor para una directiva de configuración que cambia el estado, se ignora de lo contrario
