QSORT(3P) Manual de programador de POSIX QSORT(3P)

PROLOGO

Esta página del manual forma parte del Manual de programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

qsort — ordenar una tabla de datos

SINTAXIS

#include <stdlib.h>
void qsort(void *base, size_t nel, size_t width,
    int (*compar)(const void *, const void *));

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La función qsort() ordenará un array de nel objetos, cuyo elemento inicial es apuntado por base. El tamaño de cada objeto, en bytes, se especifica mediante el argumento width. Si el argumento nel tiene el valor cero, la función de comparación apuntada por compar no se llamará y no se realizará ninguna reorganización.

La aplicación se asegurará de que la función de comparación apuntada por compar no altere el contenido del array. La implementación puede reordenar los elementos del array entre llamadas a la función de comparación, pero no alterará el contenido de ningún elemento individual.

Cuando los mismos objetos (que consisten en width bytes, independientemente de sus posiciones actuales en el array) se pasan más de una vez a la función de comparación, los resultados serán consistentes entre sí. Es decir, definirán un orden total en el array.

El contenido del array se ordenará en orden ascendente según una función de comparación. El argumento compar es un puntero a la función de comparación, que se llama con dos argumentos que apuntan a los elementos que se están comparando. La aplicación se asegurará de que la función devuelva un entero menor que, igual a, o mayor que 0, si el primer argumento se considera respectivamente menor que, igual a, o mayor que el segundo. Si dos miembros se comparan como iguales, su orden en el array ordenado no está especificado.

VALOR DE RETORNO

La función qsort() no devolverá ningún valor.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE LA APLICACIÓN

La función de comparación no necesita comparar todos los bytes, por lo que los datos arbitrarios pueden contenerse en los elementos además de los valores que se comparan.

RACIONALE

El requisito de que cada argumento (en adelante, p) a la función de comparación sea un puntero a elementos del array implica que para cada llamada, para cada argumento por separado, todas las siguientes expresiones son distintas de cero:

((char *)p - (char *)base) % width == 0
(char *)p >= (char *)base
(char *)p < (char *)base + nel * width
