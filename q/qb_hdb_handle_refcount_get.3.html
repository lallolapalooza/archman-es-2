QB_HDB_HANDLE_REFCOUNT_GET(3) Manual del programador de libqb QB_HDB_HANDLE_REFCOUNT_GET(3)

NOMBRE

qb_hdb_handle_refcount_get - Obtiene el recuento de referencias actual.

SINOPSIS

#include <qb/qbhdb.h>

int32_t qb_hdb_handle_refcount_get(
    struct qb_hdb   *hdb,        /* la instancia de la base de datos */
    qb_handle_t      handle_in   /* el manejador */
);

PARÁMETROS

hdb la instancia de la base de datos

handle_in el manejador

DESCRIPCIÓN

ESTRUCTURAS


struct qb_hdb {


    uint32_t    handle_count;

    qb_array_t  handles;

    uint32_t    iterator;

    void      (*destructor)(void *);

    uint32_t    first_run;
};

VALOR DE RETORNO

(>= 0 es el recuento de referencias, -errno para fallo)

VER TAMBIÉN

qb_hdb_handle_get(3), qb_hdb_iterator_reset(3), qb_hdb_handle_create(3), qb_hdb_handle_destroy(3), qb_hdb_iterator_next(3), qb_hdb_nocheck_convert(3), qb_hdb_create(3), qb_hdb_destroy(3), qb_hdb_base_convert(3), qb_hdb_handle_get_always(3), qb_hdb_handle_put(3)
