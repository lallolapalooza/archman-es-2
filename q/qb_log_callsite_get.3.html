QB_LOG_CALLSITE_GET(3) Manual del programador de libqb QB_LOG_CALLSITE_GET(3)

NOMBRE

qb_log_callsite_get - Obtener o crear un sitio de llamada en la posición dada.

SINOPSIS

#include <qb/qblog.h>

struct qb_log_callsite * qb_log_callsite_get(
    const char   *function,  /* nombre de la función de origen */
    const char   *filename,  /* nombre del archivo de origen */
    const char   *format,    /* cadena de formato */
    uint8_t       priority,  /* esto toma prioridades de syslog. */
    uint32_t      lineno,    /* número de línea del archivo */
    uint32_t      tags       /* la etiqueta */
);

PARÁMETROS

function nombre de la función de origen

filename nombre del archivo de origen

format cadena de formato

priority esto toma prioridades de syslog.

lineno número de línea del archivo

tags la etiqueta

DESCRIPCIÓN

El resultado se puede pasar a qb_log_real_()
