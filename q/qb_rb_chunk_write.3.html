QB_RB_CHUNK_WRITE(3) Manual del programador de libqb QB_RB_CHUNK_WRITE(3)

NOMBRE

qb_rb_chunk_write - Escribe un fragmento en el búfer de anillo.

SINOPSIS

#include <qb/qbrb.h>

ssize_t qb_rb_chunk_write(
    qb_ringbuffer_t   *rb,    /* instancia del búfer de anillo */
    const void        *data,  /* (entrada) los datos a escribir */
    size_t             len    /* (entrada) el tamaño del fragmento. */
);

PARÁMETROS

rb instancia del búfer de anillo

data (entrada) los datos a escribir

len (entrada) el tamaño del fragmento.

DESCRIPCIÓN

Esto simplemente llama a qb_rb_chunk_alloc() y luego a qb_rb_chunk_commit().

VALOR DE RETORNO

la cantidad de bytes realmente almacenados en búfer (ya sea len o -1).
