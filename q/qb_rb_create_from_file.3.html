QB_RB_CREATE_FROM_FILE(3) Manual del programador de libqb QB_RB_CREATE_FROM_FILE(3)

NOMBRE

qb_rb_create_from_file - Cargar el buffer de anillos guardado desde un archivo a memoria temporal.

SINOPSIS

#include <qb/qbrb.h>

qb_ringbuffer_t * qb_rb_create_from_file(
    int32_t   fd,     /* archivo con datos de buffer de anillos guardados. */
    uint32_t  flags   /* mismos flags que se pasaron a qb_rb_open()*/
);

PARÁMETROS

fd archivo con datos de buffer de anillos guardados.

flags mismos flags que se pasaron a qb_rb_open()

DESCRIPCIÓN

VALOR DE RETORNO

nueva instancia de buffer de anillos

VER TAMBIÉN
