QBLOG.H(3) libqb Programmer's Manual QBLOG.H(3)

NOMBRE

qblog.h - La API de registro proporciona cuatro partes principales (conceptos básicos, filtrado, hilos y caja negra).

SINOPSIS

#include <qb/qblog.h>

DESCRIPCIÓN

La idea detrás de este sistema de registro no es ser prescriptivo, sino proporcionar un conjunto de herramientas para ayudar al desarrollador a lograr lo que desea de forma rápida y sencilla.

API básica de registro.

Llame a qb_log() para generar un mensaje de registro. Luego, para escribir el mensaje en un lugar significativo, llame a qb_log_ctl() para configurar los destinos.

Uso más simple posible:

main() {
     qb_log_init("simple-log", LOG_DAEMON, LOG_INFO);
        // ...
     qb_log(LOG_WARNING, "watch out");
        // ...
     qb_log_fini();
}

Configuración de destinos de registro.

Un destino de registro puede ser syslog, stderr, la caja negra, stdout o un archivo de texto. Por defecto, solo syslog está habilitado. Si bien esto es habitual para los demonios, rara vez es apropiado para programas ordinarios, que deberían deshabilitarlo cuando se vayan a utilizar otros destinos (ver más abajo):

qb_log_ctl(B_LOG_SYSLOG, QB_LOG_CONF_ENABLED, QB_FALSE);

Para habilitar un destino, haga lo siguiente:

qb_log_ctl(QB_LOG_BLACKBOX, QB_LOG_CONF_ENABLED, QB_TRUE);

syslog, stderr, la caja negra y stdout son estáticos (no necesitan ser creados, solo habilitados o deshabilitados). Sin embargo, puede abrir varios archivos de registro (dentro del rango inclusivo QB_LOG_TARGET_DYNAMIC_START hasta QB_LOG_TARGET_DYNAMIC_END). Para hacer esto, use el siguiente código:

mytarget = qb_log_file_open("/var/log/mylogfile");
qb_log_ctl(mytarget, QB_LOG_CONF_ENABLED, QB_TRUE);

Una vez que sus destinos estén habilitados/abiertos, puede configurarlos como sigue: Configurar el tamaño de la caja negra:

qb_log_ctl(QB_LOG_BLACKBOX, QB_LOG_CONF_SIZE, 1024*10);

Hacer que el registro en archivo sea con hilos:

qb_log_ctl(mytarget, QB_LOG_CONF_THREADED, QB_TRUE);

A veces, los demonios de syslog están (pre)configurados para filtrar mensajes que no exceden una prioridad particular. Cuando este es el destino de registro, la prioridad designada del mensaje se pasa sin cambios, posiblemente resultando en pérdida de mensajes. Para mensajes de hasta importancia LOG_DEBUG, esto se puede solucionar incrementando proporcionalmente las prioridades que se pasarán a syslog (aquí, el paso es tal que LOG_DEBUG se promociona a LOG_INFO):

qb_log_ctl(QB_LOG_SYSLOG, QB_LOG_CONF_PRIORITY_BUMP,
           LOG_INFO - LOG_DEBUG);

Para asegurar que todos los registros a destinos de archivo se sincronicen (mensajes nuevos transferidos expresamente al dispositivo de almacenamiento a medida que llegan, de lo contrario, el valor predeterminado es QB_FALSE):

qb_log_ctl(mytarget, QB_LOG_CONF_FILE_SYNC, QB_TRUE);

Filtrado de mensajes.

Para tener más control sobre qué mensajes de registro van a qué destino, puede aplicar filtros a los destinos. Lo que sucede es que los sitios de llamada deseados tienen el bit correcto establecido. Luego, cuando se genera el mensaje de registro, se envía a los destinos según qué bit esté establecido en el mapa de bits de "destino" del sitio de llamada. Los mensajes se pueden filtrar según:

Así que, para que todos los registros de evil_function() vayan a stderr, haga lo siguiente:

qb_log_filter_ctl(QB_LOG_STDERR, QB_LOG_FILTER_ADD,
             QB_LOG_FILTER_FUNCTION, "evil_function", LOG_TRACE);

Así que, para que todos los registros de totem* (con una prioridad <= LOG_INFO) vayan a stderr, haga lo siguiente:

qb_log_filter_ctl(QB_LOG_STDERR, QB_LOG_FILTER_ADD,
             QB_LOG_FILTER_FILE, "totem", LOG_INFO);

Así que, para que todos los registros con la subcadena "ringbuffer" vayan a stderr, haga lo siguiente:

qb_log_filter_ctl(QB_LOG_STDERR, QB_LOG_FILTER_ADD,
             QB_LOG_FILTER_FORMAT, "ringbuffer", LOG_TRACE);

Registro no bloqueante seguro para hilos.

El registro solo es seguro para hilos cuando se utiliza el registro con hilos. Si planea registrar desde múltiples hilos, debe inicializar el hilo de registro de libqb y usar qb_log_filter_ctl para establecer el indicador QB_LOG_CONF_THREADED en todos los destinos de registro en uso.

Para lograr un registro no bloqueante, de modo que cualquier llamada a write() o syslog() no detenga su programa, también puede usar el registro con hilos.

Uso del registro con hilos:

main() {
     qb_log_init("simple-log", LOG_DAEMON, LOG_INFO);
     qb_log_ctl(QB_LOG_SYSLOG, QB_LOG_CONF_THREADED, QB_TRUE);
        // ...
        daemonize();
        // llamar a esto después de hacer fork()
        qb_log_thread_start();
        // ...
     qb_log(LOG_WARNING, "watch out");
        // ...
     qb_log_fini();
}

Una caja negra para diagnóstico en campo.

Esto almacena mensajes de registro en un búfer circular para que puedan escribirse en un archivo si el programa falla (necesitará capturar SIGSEGV). Estos pueden luego imprimirse fácilmente más tarde.

Uso de la caja negra:

static void sigsegv_handler(int sig)
{
        (void)signal (SIGSEGV, SIG_DFL);
        qb_log_blackbox_write_to_file("simple-log.fdata");
        qb_log_fini();
        raise(SIGSEGV);
}
main() {
     signal(SIGSEGV, sigsegv_handler);
     qb_log_init("simple-log", LOG_DAEMON, LOG_INFO);
     qb_log_filter_ctl(QB_LOG_BLACKBOX, QB_LOG_FILTER_ADD,
                  QB_LOG_FILTER_FILE, "*", LOG_DEBUG);
     qb_log_ctl(QB_LOG_BLACKBOX, QB_LOG_CONF_SIZE, 1024*10);
     qb_log_ctl(QB_LOG_BLACKBOX, QB_LOG_CONF_ENABLED, QB_TRUE);
        // ...
     qb_log(LOG_WARNING, "watch out");
        // ...
     qb_log_fini();
}

Etiquetado de mensajes.

Puede etiquetar mensajes utilizando el segundo argumento de qb_logt() o mediante qb_log_filter_ctl(). Esto se puede usar para agregar información de características o subsistemas a los registros.

const char* my_tags_stringify(uint32_t tags) {
        if (qb_bit_is_set(tags, QB_LOG_TAG_LIBQB_MSG_BIT) {
                return "libqb";
        } else if (tags == 3) {
                return "three";
        } else {
                return "MAIN";
        }
}
main() {
        // ...
        qb_log_tags_stringify_fn_set(my_tags_stringify);
        qb_log_format_set(QB_LOG_STDERR, "[%5g] %p %b");
        // ...
        qb_logt(LOG_INFO, 3, "hello");
        qb_logt(LOG_INFO, 0, "hello");
}


El código anterior producirá:

[libqb] some message
[three] info hello
[MAIN ] info hello

NOTA

la caja negra no está habilitada por defecto.
