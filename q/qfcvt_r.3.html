ecvt_r(3) Manual de funciones de la biblioteca ecvt_r(3)

NOMBRE

ecvt_r, fcvt_r, qecvt_r, qfcvt_r - convertir un número de punto flotante a una cadena

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
[[deprecated]] int ecvt_r(double número, int ndigits,
                          int *restrict decpt, int *restrict sign,
                          char *restrict buf, size_t size);
[[deprecated]] int fcvt_r(double número, int ndigits,
                          int *restrict decpt, int *restrict sign,
                          char *restrict buf, size_t size);
[[deprecated]] int qecvt_r(long double número, int ndigits,
                          int *restrict decpt, int *restrict sign,
                          char *restrict buf, size_t size);
[[deprecated]] int qfcvt_r(long double número, int ndigits,
                          int *restrict decpt, int *restrict sign,
                          char *restrict buf, size_t size);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

ecvt_r(), fcvt_r(), qecvt_r(), qfcvt_r():

    /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPCIÓN

Las funciones ecvt_r(), fcvt_r(), qecvt_r() y qfcvt_r() son idénticas a ecvt(3), fcvt(3), qecvt(3) y qfcvt(3), respectivamente, excepto que no devuelven su resultado en un búfer estático, sino que utilizan el buf suministrado de tamaño size. Ver ecvt(3) y qecvt(3).

VALOR DE RETORNO

Estas funciones devuelven 0 en caso de éxito y -1 en caso contrario.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
ecvt_r (), fcvt_r (), qecvt_r (), qfcvt_r () Seguridad en hilos MT-Safe

ESTANDARES

GNU.

NOTAS

Estas funciones están obsoletas. En su lugar, se recomienda sprintf(3).

VER TAMBIÉN

ecvt(3), qecvt(3), sprintf(3)
