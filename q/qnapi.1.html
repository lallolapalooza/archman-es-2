NOMBRE

qnapi - una herramienta para descargar subtítulos para películas

SINOPSIS

qnapi [opciones] [lista de archivos]

DESCRIPCIÓN

qnapi es un software para la descarga automática y la correspondencia de subtítulos para archivos de películas. Puede usar servicios como napiprojekt.pl, napisy24.pl y opensubtitles.com.

qnapi funciona en dos modos: GUI y CLI. Puede descargar subtítulos simplemente proporcionando las rutas a los archivos de película como argumentos del programa o usar la interfaz gráfica y realizar una acción allí.

ARGUMENTOS


-c, --consola Descargar subtítulos con la consola
-q, --silencioso Descargar subtítulos silenciosamente sin mostrar
ningún mensaje o ventana (implica -d)


-s, --mostrar-lista Mostrar una lista de subtítulos (solo funciona con -c)
-d, --no-mostrar-lista No mostrar una lista de subtítulos
(solo funciona con -c)


-l, --idioma [código] Idioma preferido de los subtítulos
-lb,--idioma-copia [código] Idioma alternativo de los subtítulos
-f, --formato [formato] Seleccionar el formato de archivo de subtítulos de destino
(mDVD,MPL2,SRT,TMP)
-e, --extensión [ext] Seleccionar la extensión de archivo de subtítulos de destino


-o, --opciones Mostrar opciones del programa (solo GUI)
-h, --ayuda Mostrar texto de ayuda
-hl,--ayuda-idiomas Lista de idiomas de subtítulos disponibles
