NOMBRE

qbatomic.h - Operaciones atómicas básicas de enteros y punteros.

SINOPSIS

#include <qb/qbatomic.h>

DESCRIPCIÓN

Las siguientes funciones se pueden utilizar para acceder de forma atómica a enteros y punteros. Se implementan como funciones de ensamblador en línea en la mayoría de las plataformas y utilizan alternativas más lentas en caso contrario. Usarlas a veces puede evitar que utilices un mutex de pthread costoso en rendimiento para proteger el entero o el puntero.

El uso más importante es el conteo de referencias. El uso de qb_atomic_int_inc() y qb_atomic_int_dec_and_test() hace que el conteo de referencias sea una operación muy rápida.

No debes leer directamente enteros o punteros accedidos concurrentemente por múltiples hilos, sino usar las funciones accesoras atómicas en su lugar. Es decir, siempre usa qb_atomic_int_get() y qb_atomic_pointer_get() para las lecturas. Proporcionan los mecanismos de sincronización necesarios, como barreras de memoria, para acceder a ubicaciones de memoria de forma concurrente.

Si estás utilizando estas funciones para algo más que el simple conteo de referencias, realmente deberías ser consciente de las implicaciones de hacerlo. Hay literalmente miles de maneras de autolesionarse. Por lo tanto, si tienes dudas, usa un pthread_mutex. Si no sabes qué son las barreras de memoria, no uses nada más que qb_atomic_int_inc() y qb_atomic_int_dec_and_test().

No es seguro establecer un entero o puntero simplemente asignándole un valor, cuando es accedido concurrentemente por otros hilos con las siguientes funciones. Usa qb_atomic_int_compare_and_exchange() o qb_atomic_pointer_compare_and_exchange() respectivamente.
