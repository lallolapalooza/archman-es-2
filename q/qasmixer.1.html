NOMBRE

qasmixer - Mezclador de sonido de escritorio para ALSA

SINOPSIS

qasmixer [OPCIÓN]...

DESCRIPCIÓN

QasMixer es una aplicación mezcladora de escritorio para el sistema de sonido ALSA de Linux.

OPCIONES

-h, --help
imprime un texto de ayuda.
-c, --card=NÚMERO
selecciona una tarjeta de sonido.
-D, --device=NOMBRE
selecciona un dispositivo mezclador (p. ej., hw:1).
-t, --tray
inicia minimizado en la bandeja.
-n, --no-single
permite múltiples instancias.
-c, --copying
imprime información de copia.
-v, --version
imprime la versión del programa.

NOTAS

QasMixer forma parte de la colección de aplicaciones QasTools.

Está escrito en C++ utilizando las bibliotecas gráficas Qt.

VER TAMBIÉN

alsamixer(1), qasconfig(1), qashctl(1)
