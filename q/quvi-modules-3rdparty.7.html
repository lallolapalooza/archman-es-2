QUVI-MODULES-3RDPA(7) Manual de libquvi-scripts QUVI-MODULES-3RDPA(7)

NOMBRE

quvi-modules-3rdparty - Visión general de los módulos cargables de terceros

DESCRIPCIÓN

Esta es una lista breve de los módulos de terceros cargables que utiliza libquvi-scripts(7). Para más información sobre estos módulos, consulte su documentación de referencia correspondiente.

MÓDULOS DE TERCEROS

LuaBitOp

Lua BitOp es un módulo de extensión C para Lua 5.1/5.2 que añade operaciones bit a bit sobre números.

http://bitop.luajit.org/

LuaExpat

LuaExpat es un analizador XML SAX basado en la biblioteca Expat.

http://matthewwild.co.uk/projects/luaexpat/

LuaJSON

Analizador/codificador JSON para Lua, analiza JSON usando LPEG para velocidad y flexibilidad.

http://www.eharning.us/wiki/luajson/

LuaSocket

LuaSocket es una biblioteca de extensión de Lua que se compone de dos partes: un núcleo C que proporciona soporte para las capas de transporte TCP y UDP, y un conjunto de módulos Lua que añaden soporte para la funcionalidad comúnmente necesaria por las aplicaciones que manejan Internet.

http://w3.impa.br/~diego/software/luasocket/
