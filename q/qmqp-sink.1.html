NOMBRE

qmqp-sink - servidor de prueba QMQP paralelizado

SINOPSIS

qmqp-sink [-46cv] [-x tiempo] [inet:][host]:puerto backlog

qmqp-sink [-46cv] [-x tiempo] unix:nombre_ruta backlog

DESCRIPCIÓN


qmqp-sink escucha en el host (o dirección) y puerto especificados. Recibe mensajes de la red y los descarta. El propósito es medir el rendimiento del cliente QMQP, no la conformidad del protocolo. Las conexiones pueden ser aceptadas en puntos finales IPv4 o IPv6, o en sockets de dominio UNIX. IPv4 y IPv6 son los predeterminados. Este programa es el complemento del programa qmqp-source(1).

Nota: este es un programa de prueba no compatible. No se hace ningún intento de mantener la compatibilidad entre versiones sucesivas.

Argumentos:

-4
Soportar solo IPv4. Esta opción no tiene efecto cuando Postfix se compila sin soporte IPv6.
-6
Soportar solo IPv6. Esta opción no está disponible cuando Postfix se compila sin soporte IPv6.
-c
Muestra un contador en ejecución que se actualiza cada vez que se completa una entrega.
-v
Aumenta la verbosidad. Especifica -v -v para ver parte de la conversación QMQP.
-x tiempo
Termina después de tiempo segundos. Esto es para facilitar las pruebas de fugas de memoria.

VER TAMBIÉN

qmqp-source(1), Generador de mensajes QMQP
