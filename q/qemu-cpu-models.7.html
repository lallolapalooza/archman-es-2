DESCRIPCIÓN

Recomendaciones para la configuración del modelo de CPU KVM en hosts x86

La información que sigue proporciona recomendaciones para configurar modelos de CPU en hosts x86. Los objetivos son maximizar el rendimiento, mientras se protege el SO invitado contra diversas fallas de hardware de CPU, y opcionalmente se habilita la migración en vivo entre hosts con modelos de CPU heterogéneos.

Dos formas de configurar modelos de CPU con QEMU / KVM

1.
Passthrough del host

Esto pasa las características del modelo de CPU del host, el modelo, la revisión, exactamente al invitado. Tenga en cuenta que KVM puede filtrar algunas características del modelo de CPU del host si no se pueden admitir con virtualización. La migración en vivo no es segura cuando se utiliza este modo, ya que libvirt / QEMU no puede garantizar una CPU estable expuesta al invitado entre hosts. Esta es la CPU recomendada para usar, siempre que no se requiera migración en vivo.

2.
Modelo con nombre

QEMU viene con una serie de modelos de CPU predefinidos con nombre, que típicamente se refieren a generaciones específicas de hardware lanzadas por Intel y AMD. Estos permiten que las VMs invitadas tengan un grado de aislamiento de la CPU del host, lo que permite una mayor flexibilidad en la migración en vivo entre hosts con hardware diferente. @end table

En ambos casos, es posible añadir o eliminar opcionalmente características de CPU individuales, para alterar lo que se presenta al invitado por defecto.

Libvirt admite una tercera forma de configurar modelos de CPU conocida como "Modelo de host". Esto utiliza la función de QEMU "Modelo con nombre", seleccionando automáticamente un modelo de CPU similar al de la CPU del host y luego añadiendo características adicionales para aproximar el modelo del host lo más fielmente posible. Esto no garantiza que la familia de CPU, la revisión, etc., coincidan exactamente con la CPU del host, como lo harían con el "Passthrough del host", pero ofrece gran parte del beneficio del passthrough, al tiempo que hace que la migración en vivo sea segura.

La arquitectura x86_64 tiene una serie de niveles de compatibilidad de ABI https://gitlab.com/x86-psABIs/x86-64-ABI/ definidos. Tradicionalmente la mayoría de los sistemas operativos y cadenas de herramientas solo apuntaban a la ABI de línea base original. Se espera que en el futuro los SO y las cadenas de herramientas apunten a ABIs más nuevas. La tabla siguiente ilustra qué niveles de compatibilidad de ABI pueden ser satisfechos por los modelos de CPU de QEMU. Tenga en cuenta que la tabla solo lista las versiones estables a largo plazo de los modelos de CPU (por ejemplo, Haswell-v4). Además de lo que se enumera, también hay muchos alias de modelos de CPU que resuelven a una versión de modelo de CPU diferente, dependiendo del tipo de máquina que se esté utilizando.

Características importantes de CPU para hosts Intel x86

Las siguientes son características importantes de la CPU que deben utilizarse en hosts Intel x86, cuando estén disponibles en la CPU del host. Algunas de ellas requieren configuración explícita para habilitarlas, ya que no están incluidas por defecto en algunos, o todos, de los modelos de CPU nombrados anteriormente. En general, todas estas características se incluyen si se utiliza "Pase directo del host" o "Modelo de host".

pcid
Recomendado para mitigar el costo de la corrección de Meltdown (CVE-2017-5754).

Incluido por defecto en los modelos de CPU Intel Haswell, Broadwell y Skylake.

Debe activarse explícitamente para los modelos de CPU Intel Westmere, SandyBridge e IvyBridge. Tenga en cuenta que algunas CPU Westmere de escritorio/móvil no pueden soportar esta característica.

spec-ctrl
Requerido para habilitar la corrección de Spectre v2 (CVE-2017-5715).

Incluido por defecto en los modelos de CPU Intel con sufijo -IBRS.

Debe activarse explícitamente para los modelos de CPU Intel sin sufijo -IBRS.

Requiere que la microcódigo de la CPU del host soporte esta característica antes de que pueda utilizarse para las CPU invitadas.

stibp
Requerido para habilitar correcciones más robustas de Spectre v2 (CVE-2017-5715) en algunos sistemas operativos.

Debe activarse explícitamente para todos los modelos de CPU Intel.

NAME

qemu-cpu-models - QEMU CPU models

SYNOPSIS

qemu-system-x86_64 -cpu MODEL [options]

qemu-system-x86_64 -cpu host [options]

virsh (using libvirt) with <cpu> element

DESCRIPTION

This manual page lists the CPU models supported by QEMU. It also explains how to specify CPU models and features for various architectures supported by QEMU.

CPU models are defined by a set of features that are exposed to the guest. QEMU provides a way to select these models for various architectures, and for x86 guests, it can also expose a subset of the host CPU features. This allows for greater compatibility and performance tuning.

qemu32

qemu32 se utiliza para invitados i686, cuando no se proporciona el argumento -cpu a QEMU, o no se proporciona <cpu> en el XML de libvirt.

Otras CPUs x86 no recomendadas

Los siguientes modelos de CPU son compatibles con la mayoría de los hosts x86 de AMD e Intel, pero se desaconseja su uso, ya que exponen un conjunto de características muy limitado, lo que impide que los invitados tengan un rendimiento óptimo.

kvm32, kvm64
Procesador KVM común (variantes de 32 y 64 bits).

Modelos heredados solo para compatibilidad histórica con versiones antiguas de QEMU.

486, athlon, phenom, coreduo, core2duo, n270, pentium, pentium2, pentium3
Varios modelos de CPU x86 muy antiguos, la mayoría anteriores a la introducción de la virtualización asistida por hardware, que por lo tanto no deberían ser necesarios para ejecutar máquinas virtuales.

Sintaxis para configurar modelos de CPU

Los ejemplos a continuación ilustran el enfoque para configurar los diversos modelos/características de CPU en QEMU y libvirt.

Línea de comandos de QEMU

Pasarela de host:

qemu-system-x86_64 -cpu host

Pasarela de host con personalización de características:

qemu-system-x86_64 -cpu host,vmx=off,...

Modelos de CPU con nombre:

qemu-system-x86_64 -cpu Westmere

Modelos de CPU con nombre con personalización de características:

qemu-system-x86_64 -cpu Westmere,pcid=on,...

XML de invitado de Libvirt

Pasarela de host:

<cpu mode='host-passthrough'/>

Pasarela de host con personalización de características:

<cpu mode='host-passthrough'>
    <feature name="vmx" policy="disable"/>
    ...
</cpu>

Modelo de host:

<cpu mode='host-model'/>

Modelo de host con personalización de características:

<cpu mode='host-model'>
    <feature name="vmx" policy="disable"/>
    ...
</cpu>

Modelo con nombre:

<cpu mode='custom'>
    <model name="Westmere"/>
</cpu>

Modelo con nombre con personalización de características:

<cpu mode='custom'>
    <model name="Westmere"/>
    <feature name="pcid" policy="require"/>
    ...
</cpu>
