NOMBRE

Quantize - Algoritmo de reducción de color de ImageMagick.

SINOPSIS

#include <magick.h>

DESCRIPCIÓN

Este documento describe cómo ImageMagick realiza la reducción de color en una imagen. Para comprender completamente este documento, usted debería tener conocimiento de las técnicas básicas de imagen y de la estructura de datos de árbol y su terminología.

A efectos de asignación de color, una imagen es un conjunto de n píxeles, donde cada píxel es un punto en el espacio RGB. El espacio RGB es un espacio vectorial tridimensional, y cada píxel, pi, se define por un triple ordenado de coordenadas roja, verde y azul, (ri, gi, bi).

Cada componente de color primario (rojo, verde o azul) representa una intensidad que varía linealmente de 0 a un valor máximo, cmax, que corresponde a la saturación completa de ese color. La asignación de color se define sobre un dominio que consiste en el cubo en el espacio RGB con vértices opuestos en (0,0,0) y (cmax,cmax,cmax). ImageMagick requiere cmax = 255.

El algoritmo mapea este dominio a un árbol en el que cada nodo representa un cubo dentro de ese dominio. En la siguiente discusión, estos cubos se definen por la coordenada de dos vértices opuestos: El vértice más cercano al origen en el espacio RGB y el vértice más alejado del origen.

El nodo raíz del árbol representa todo el dominio, desde (0,0,0) hasta (cmax,cmax,cmax). Cada nivel inferior en el árbol se genera dividiendo el cubo de un nodo en ocho cubos más pequeños de igual tamaño. Esto corresponde a dividir el cubo padre con planos que pasan por los puntos medios de cada arista.

El algoritmo básico opera en tres fases: Clasificación, Reducción y Asignación. La Clasificación construye un árbol de descripción de color para la imagen. La Reducción colapsa el árbol hasta que el número que representa, como máximo, es el número de colores deseados en la imagen de salida. La Asignación define el mapa de color de la imagen de salida y establece el color de cada píxel mediante reclasificación en el árbol reducido. Nuestro objetivo es minimizar las discrepancias numéricas entre los colores originales y los colores cuantificados. Para obtener más información sobre el error de cuantificación, consulte MEDICIÓN DEL ERROR DE REDUCCIÓN DE COLOR más adelante en este documento.

La Clasificación comienza inicializando un árbol de descripción de color con una profundidad suficiente para representar cada color de entrada posible en una hoja. Sin embargo, no es práctico generar un árbol de descripción de color completamente formado en la fase de clasificación para valores realistas de cmax. Si los componentes de color en la imagen de entrada se cuantifican a precisión de k bits, de modo que cmax = 2k-1, el árbol necesitaría k niveles debajo del nodo raíz para permitir la representación de cada color de entrada posible en una hoja. Esto se vuelve prohibitivo porque el número total de nodos del árbol es

        Σ k=1 8k

Un árbol completo requeriría 19,173,961 nodos para k = 8, cmax = 255. Por lo tanto, para evitar construir un árbol completamente poblado, ImageMagick: (1) Inicializa estructuras de datos para los nodos solo cuando se necesitan; (2) Elige una profundidad máxima para el árbol en función del número de colores deseado en la imagen de salida (actualmente log4(tamaño del mapa de colores)+2). Un árbol de esta profundidad generalmente permite la mejor representación de la imagen fuente con la velocidad computacional más rápida y la menor cantidad de memoria. Sin embargo, la profundidad predeterminada es inapropiada para algunas imágenes. Por lo tanto, el llamador puede solicitar una profundidad de árbol específica.

Para cada píxel en la imagen de entrada, la clasificación escanea hacia abajo desde la raíz del árbol de descripción de color. En cada nivel del árbol, identifica el único nodo que representa un cubo en el espacio RGB que contiene el color del píxel. Actualiza los siguientes datos para cada nodo de este tipo:

n1:
Número de píxeles cuyo color está contenido en el cubo RGB que representa este nodo;
n2:
Número de píxeles cuyo color no está representado en un nodo de nivel inferior en el árbol; inicialmente, n2 = 0 para todos los nodos excepto las hojas del árbol.
Sr, Sg, Sb:
Suma de los valores de los componentes rojo, verde y azul para todos los píxeles no clasificados en un nivel inferior. La combinación de estas sumas y n2 caracterizará finalmente el color medio de un conjunto de píxeles representados por este nodo.
E:
La distancia al cuadrado en el espacio RGB entre cada píxel contenido en un nodo y el centro del nodo. Esto representa el error de cuantificación de un nodo.

La Reducción poda repetidamente el árbol hasta que el número de nodos con n2 > 0 sea menor o igual al número máximo de colores permitidos en la imagen de salida. En cada iteración del árbol, selecciona aquellos nodos cuyo valor E sea mínimo para podar y fusiona sus estadísticas de color hacia arriba. Utiliza un umbral de poda, Ep, para gobernar la selección de nodos de la siguiente manera:


Ep = 0
mientras el número de nodos con (n2 > 0) > número máximo de colores requerido
podar todos los nodos tales que E <= Ep
Establecer Ep al mínimo E en los nodos restantes

Esto tiene el efecto de minimizar cualquier error de cuantificación al fusionar dos nodos.

Cuando un nodo a podar tiene descendencia, el procedimiento de poda se invoca recursivamente para podar el árbol desde las hojas hacia arriba. Los valores de n2 Sr, Sg, y Sb en un nodo que se está podando siempre se suman a los datos correspondientes en el padre de ese nodo. Esto retiene las características de color del nodo podado para su posterior promediado.

Para cada nodo, existen n2 píxeles para los cuales ese nodo representa el menor volumen en el espacio RGB que contiene los colores de esos píxeles. Cuando n2 > 0, el nodo definirá de forma única un color en la imagen de salida. Al principio de la reducción, n2 = 0 para todos los nodos excepto las hojas del árbol que representan colores presentes en la imagen de entrada.

El otro recuento de píxeles, n1, indica el número total de colores dentro del volumen cúbico que representa el nodo. Esto incluye n1 - n2 píxeles cuyos colores deben definirse por nodos en un nivel inferior del árbol.

La Asignación genera la imagen de salida a partir del árbol podado. La imagen de salida consta de dos partes: (1) Un mapa de color, que es una matriz de descripciones de color (triples RGB) para cada color presente en la imagen de salida; (2) Una matriz de píxeles, que representa cada píxel como un índice en la matriz del mapa de color.

Primero, la fase de asignación realiza un pase sobre el árbol de descripción de color podado para establecer el mapa de color de la imagen. Para cada nodo con n2 > 0, divide Sr, Sg, y Sb entre n2. Esto produce el color medio de todos los píxeles que no se clasifican más abajo que este nodo. Cada uno de estos colores se convierte en una entrada en el mapa de color.

Finalmente, la fase de asignación reclasifica cada píxel en el árbol podado para identificar el nodo más profundo que contiene el color del píxel. El valor del píxel en la matriz de píxeles se convierte en el índice del color medio de este nodo en el mapa de color.

La evidencia empírica sugiere que las distancias en espacios de color como YUV o YIQ corresponden más estrechamente a las diferencias de color perceptuales que las distancias en el espacio RGB. Estos espacios de color pueden dar mejores resultados al reducir el color de una imagen. Aquí el algoritmo es como se describe, excepto que cada píxel es un punto en el espacio de color alternativo. Para mayor comodidad, los componentes de color se normalizan al rango de 0 a un valor máximo, cmax. La reducción de color puede proceder entonces como se describe.

MEDICIÓN DEL ERROR DE REDUCCIÓN DE COLOR

Dependiendo de la imagen, el error de reducción de color puede ser obvio o invisible. Las imágenes con altas frecuencias espaciales (como cabello o hierba) mostrarán el error mucho menos que las imágenes con áreas grandes de sombreado suave (como rostros). Esto se debe a que los bordes de contorno de alta frecuencia introducidos por el proceso de reducción de color quedan enmascarados por las altas frecuencias en la imagen.

Para medir la diferencia entre la imagen original y la reducida en color (el error total de reducción de color), ImageMagick suma sobre todos los píxeles de una imagen la distancia al cuadrado en el espacio RGB entre cada valor de píxel original y su valor reducido en color. ImageMagick imprime varias mediciones de error, incluido el error medio por píxel, el error medio normalizado y el error máximo normalizado.

La medición del error normalizado se puede utilizar para comparar imágenes. En general

quantize.5 - Arch manual pages

NAME

quantize - Quantize an image to a limited number of colors.

SYNOPSIS

quantize [input_options] image_file [output_options] image_file

DESCRIPTION

The quantize command implements a multi-tap, parallelizable color quantization algorithm. It is useful for reducing the number of distinct colors in an image while minimizing the introduction of artifacts. It is particularly suited for reducing the color count of a true-color image to a level suitable for display on an 8-bit display or for saving in an indexed-color file format.

The color reduction algorithm sorts the colors in the image by intensity, breaking the colors down into a three-dimensional histogram. The algorithm progressively splits the histogram into smaller regions until the desired number of colors is reached. The colors within each region are then averaged to create the representative color for that region.

A number of options are available to control the quantization process, including the desired number of colors, dithering options, and color reduction strategies.

MEASURING COLOR REDUCTION ERROR

The quantize command can compute and report quantization errors, which indicate how closely the quantized image resembles the source image. The closer the mean error is to zero the more the quantized image resembles the source image. Ideally, the error should be perceptually-based, since the human eye is the final judge of quantization quality.

These errors are measured and printed when -verbose and -colors are specified on the command line:

mean error per pixel:
is the mean error for any single pixel in the image.
normalized mean square error:
is the normalized mean square quantization error for any single pixel in the image.

This distance measure is normalized to a range between 0 and 1. It is independent of the range of red, green, and blue values in the image.

normalized maximum square error:
is the largest normalized square quantization error for any single pixel in the image.

This distance measure is normalized to a range between 0 and 1. It is independent of the range of red, green, and blue values in the image.
