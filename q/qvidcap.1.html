QVIDCAP(1) Comandos de usuario QVIDCAP(1)

NOMBRE

qvidcap - Un visor de captura de vídeo v4l2

SINOPSIS

qvidcap [<opciones>]

DESCRIPCIÓN

La herramienta qvidcap se utiliza para probar dispositivos de captura video4linux, ya sea utilizando un dispositivo de vídeo, un archivo o a través de la red. Esta aplicación también puede servir como una aplicación genérica de visualización de vídeo/TV.

No soporta (todavía) transmisiones de vídeo comprimidas distintas de MJPEG

OPCIONES

-d, --device=<dev>
Utiliza el dispositivo <dev> como dispositivo de vídeo. Si <dev> es un número, se usará /dev/video<dev>
-f, --file=<archivo>
Lee los datos de fotogramas crudos del archivo <archivo>
-p, --port[=<puerto>]
Escucha una conexión de red en el puerto dado. El puerto por defecto es 8362
-T, --tpg
Utiliza el generador de patrones de prueba. Si no se especifica -d, -f ni -T, se usará /dev/video0.
-c, --count=<cnt>
Detente después de capturar <cnt> fotogramas
-b, --buffers=<bufs>
Solicita <bufs> búferes (por defecto 4) al transmitir desde un dispositivo de vídeo.
-s, --single-step[=<frm>]
Comenzando desde el fotograma <frm> (por defecto 0), pausa después de mostrar cada fotograma hasta que se presione Espacio.
-C, --colorspace=<c>
Anula el espacio de color. <c> puede ser uno de los siguientes espacios de color: smpte170m, smpte240m, rec709, 470m, 470bg, jpeg, srgb, oprgb, bt2020, dcip3
-X, --xfer-func=<x>
Anula la función de transferencia. <x> puede ser una de las siguientes funciones de transferencia: default, 709, srgb, oprgb, smpte240m, smpte2084, dcip3, none
-Y, --ycbcr-enc=<y>
Anula la codificación Y'CbCr. <y> puede ser una de las siguientes codificaciones Y'CbCr: default, 601, 709, xv601, xv709, bt2020, bt2020c, smpte240m
-Q, --quant=<q>
Anula la cuantificación. <q> puede ser uno de los siguientes métodos de cuantificación: default, full-range, lim-range
-P, --pixelformat=<p>
Para dispositivos de vídeo: establece el formato a este formato de píxel. Para leer desde un archivo: interpreta los datos usando esta configuración de formato de píxel. Ignorado para otros modos. Usa -l para ver la lista de formatos de píxel soportados.
-l, --list-formats
Muestra todos los formatos soportados
-h, --help
Muestra este mensaje de ayuda
-t, --timings
Reporta los tiempos de renderizado de fotogramas
-v, --verbose
Sé más detallado
-R, --raw
Abre el dispositivo en modo crudo
--opengl
Fuerza openGL para mostrar el vídeo
--opengles
Fuerza openGL ES para mostrar el vídeo
Las siguientes opciones son ignoradas al capturar desde un dispositivo de vídeo:
-W,--width=<ancho>
Establece el ancho
-H,--height=<alto>
Establece la altura del fotograma (¡no del campo!)
-A,--padding=<bytes>
Establece relleno horizontal adicional (después del ancho)
--fps=<fps>
Establece fotogramas por segundo (por defecto es 30)
Las siguientes opciones solo son válidas al leer desde un archivo:
-F, --field=<f>
Anula la configuración del campo. <f> puede ser uno de los siguientes diseños de campo: any, none, top, bottom, interlaced, seq_tb, seq_bt, alternate, interlaced_tb, interlaced_bt
--no-loop
Detente al final del archivo, no vuelvas al principio.
--from-frame=<fotograma>
Comienza la reproducción del archivo en el número de fotograma dado (el primer fotograma es el fotograma 0).
Las siguientes opciones son específicas del generador de patrones de prueba:
--list-patterns
Lista los patrones disponibles para usar con --pattern
--pattern=<pat>
Elige el patrón de salida de prueba, por defecto es 0
--square
Muestra un cuadrado en el centro del patrón de prueba de salida
--border
Muestra un borde alrededor del vídeo apilado/con formato carta
--sav
Inserta un código SAV en cada línea
--eav
Inserta un código EAV en cada línea
--pixel-aspect=<aspecto>
Selecciona una relación de aspecto de píxel, por defecto es autodetección. <aspecto> puede ser uno de: square, ntsc, pal
--video-aspect=<aspecto>
Selecciona una relación de aspecto de vídeo, por defecto es usar la relación de aspecto del fotograma. <aspecto> puede ser uno de: 4 x3, 14x9, 16x9, anamorphic
--alpha=<valor-alfa>
Valor a usar para el componente alfa, rango 0-255, por defecto es 0
--alpha-red-only
Usa solo el valor --alpha para los colores rojos, para todos los demás usa 0
--rgb-lim-range
Codifica los valores RGB como rango limitado [16-235] en lugar de rango completo
--hor-speed=<velocidad>
Elige la velocidad para el movimiento horizontal, por defecto es 0 y el rango es [-3...3]
--vert-speed=<velocidad>
Elige la velocidad para el movimiento vertical, por defecto es 0 y el rango es [-3...3]
--perc-fill=<porcentaje>
Porcentaje del fotograma a llenar realmente. El valor por defecto es 100%
Estas opciones utilizan el generador de patrones de prueba para probar el backend de OpenGL:
--test=<contador>
Prueba todos los formatos, cada prueba genera <contador> fotogramas.
--test-mask=<máscara>
Máscara qué pruebas se realizan. <máscara> es una máscara de bits con los siguientes valores:
0x01: Máscara para iterar sobre formatos de píxel
0x02: Máscara para iterar sobre campos
0x04: Máscara para iterar sobre espacios de color
0x08: Máscara para iterar sobre funciones de transferencia
0x10: Máscara para iterar sobre codificaciones Y'CbCr
0x20: Máscara para iterar sobre rangos de cuantificación

TECLAS DE ACCESO DIRECTO

Q
Salir de la aplicación.
P
Ciclar hacia adelante a través de todos los formatos de píxel soportados. Con Shift presionado: ciclar hacia atrás. Con Ctrl presionado: restaurar el formato de píxel original. Solo disponible con --file.
I
Recorre hacia adelante todas las configuraciones de campo entrelazado soportadas. Con Shift presionado: recorre hacia atrás. Con Ctrl presionado: restaura la configuración de campo entrelazado original. Solo disponible con --file.
C
Recorre hacia adelante todos los espacios de color soportados. Con Shift presionado: recorre hacia atrás. Con Ctrl presionado: restaura el espacio de color original.
X
Recorre hacia adelante todas las funciones de transferencia soportadas. Con Shift presionado: recorre hacia atrás. Con Ctrl presionado: restaura la función de transferencia original.
Y
Recorre hacia adelante todas las codificaciones Y'CbCr soportadas. Con Shift presionado: recorre hacia atrás. Con Ctrl presionado: restaura la codificación Y'CbCr original.
H
Recorre hacia adelante todas las codificaciones HSV soportadas. Con Shift presionado: recorre hacia atrás. Con Ctrl presionado: restaura la codificación HSV original.
R
Recorre hacia adelante todos los rangos de cuantificación soportados. Con Shift presionado: recorre hacia atrás. Con Ctrl presionado: restaura el rango de cuantificación original.
Clic Derecho
Abre el menú.
Doble clic izquierdo
Activa o desactiva la pantalla completa.
F
Activa o desactiva la pantalla completa.
ESC
Sale de la pantalla completa.
Espacio
En modo de prueba (--test), presionar Espacio saltará a la siguiente prueba. Al avanzar paso a paso, continuará al siguiente fotograma. Al leer desde un archivo, pausará la reproducción hasta la próxima pulsación de Espacio.
Retroceso
Al avanzar paso a paso, retrocede al fotograma anterior.
Arriba
Reduce la resolución en dos píxeles de altura. Solo disponible cuando "Sobrescribir resolución" está habilitado.
Abajo
Aumenta la resolución en dos píxeles de altura. Solo disponible cuando "Sobrescribir resolución" está habilitado.
Izquierda
Reduce la resolución en dos píxeles de ancho. Solo disponible cuando "Sobrescribir resolución" está habilitado.
Derecha
Aumenta la resolución en dos píxeles de ancho. Solo disponible cuando "Sobrescribir resolución" está habilitado.

ESTADO DE SALIDA

En caso de éxito, devuelve 0. De lo contrario, devolverá el número de errores.

ERRORES

Reportar errores a Hans Verkuil <hverkuil@kernel.org>
