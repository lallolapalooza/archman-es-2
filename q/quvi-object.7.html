QUVI-OBJECT(7) Manual de libquvi QUVI-OBJECT(7)

NOMBRE

quvi-object - Visión general del objeto quvi de libquvi

DESCRIPCIÓN

quvi-object es una colección de funciones de libquvi proporcionadas para libquvi-scripts(7). Estas funciones varían desde funciones HTTP hasta funciones criptográficas. Todas las funciones de quvi-object están implementadas en C.


Nota

El quvi-object no debe confundirse con los quvi-modules(7), que son una selección de módulos importables implementados en Lua. Estos módulos están destinados a ser cargados (require) desde libquvi-scripts(7).

OPCIONES

A cada una de las funciones de quvi-object se le puede pasar un diccionario que define las propiedades de opción adicionales. Las siguientes opciones son soportadas por todas las funciones:

qoo_croak_if_error=<booleano>

Por defecto, la biblioteca termina el proceso si ocurre un error. Estableciendo esta opción a false, registrará el error y continuará la ejecución, dejando el manejo de errores para que el script lo determine. Ver también "VALORES DE RETORNO".

El prefijo qoo es la abreviatura de quvi object option. Las funciones ignorarán cualquier opción desconocida, por ejemplo, las funciones criptográficas ignorarían las opciones HTTP.


Nota

Las opciones se han definido en el quvi/const de quvi-modules(7)

Cripto

Estas opciones son específicas de las funciones quvi.crypto.* del objeto quvi.

qoo_crypto_algorithm=<valor>

Especifica el algoritmo que debe usarse. El valor se espera que sea una cadena, por ejemplo, sha1 o aes256.

qoo_crypto_cipher_flags=<valor>

Especifica las banderas de cifrado (OR bit a bit, ver quvi-modules-3rdparty(7) para operaciones bit a bit) que se usarán con el cifrador. Estos valores son idénticos a los definidos por libgcrypt. Ver el quvi/const de quvi-modules(7) para una lista completa de las banderas de cifrado disponibles.

qoo_crypto_cipher_mode=<valor>

Especifica el modo de cifrado a utilizar. Estos son idénticos a los valores definidos por libgcrypt. Ver el quvi/const de quvi-modules(7) para una lista completa de los modos de cifrado disponibles.

qoo_crypto_cipher_key=<valor>

Se utiliza para especificar la clave de cifrado. Cabe señalar que la clave se espera que se pase en formato hexadecimal. Ver quvi/hex de quvi-modules(7) para las funciones de conversión.

NOTA: La derivación de la clave se deja para que el script la haga

NOTA: La clave no es una contraseña

Ver también: http://www.di-mgt.com.au/cryptokeys.html#passwordpassphraseandkey

HTTP

Estas opciones son específicas de las funciones quvi.http.* del objeto quvi.

qoo_fetch_from_charset=<conjunto de caracteres>

Instruye a la biblioteca a convertir desde este conjunto de caracteres a UTF-8. Usar esta opción puede ser necesario con sitios web que utilizan una codificación específica (no UTF8).

El propósito de esta opción es asegurar que los datos se codifiquen a unicode (UTF-8) antes de que cualquiera de ellos sea analizado y devuelto a la aplicación que utiliza libquvi.

Por defecto, libquvi convierte los datos que están en la codificación utilizada para las cadenas por el runtime de C en la configuración regional actual a UTF-8. SI esto falla, y la opción from charset está establecida, la biblioteca intentará entonces convertir a UTF-8 usando el valor de from charset.

qoo_http_cookie_mode=<valor>

Modifica la configuración de cookies para el manejador de sesión de libcurl. Esta característica envuelve las características de cookies proporcionadas por libcurl_easy_setopt(3). Ver el quvi/const de quvi-modules(7) para una lista completa de los modos de cookies disponibles.

Ver también libcurl-tutorial(3) que cubre el uso de cookies con la biblioteca con mayor detalle.

VALORES DE RETORNO

Cada función de quvi-object devolverá un diccionario que contiene los siguientes valores:

error_message

El mensaje de error, o un valor vacío.

quvi_code

El código devuelto por la biblioteca. Ver también quvi/const de quvi-modules(7).

Consulte la documentación de la función para obtener información sobre los valores adicionales devueltos en el diccionario.

FUNCIONES

Base64

quvi.base64.encode(<texto plano>[,qoo])

Codifica el texto plano a formato base64. El texto plano se espera que se pase en formato hexadecimal. Ver quvi/hex de quvi-modules(7) para las funciones de conversión.

El segundo argumento (qoo) se espera que sea un diccionario de opciones de objeto quvi adicionales, si se definen.

La función devolverá el valor base64 en el diccionario.

quvi.base64.decode(<base64>)

Decodifica el valor base64 a texto plano.

La función devolverá el valor texto plano en el diccionario. El valor se devuelve en formato hexadecimal.

Cripto

La instalación criptográfica del objeto quvi envuelve la criptografía simétrica de libgcrypt y las funciones de hash (resumen de mensajes).


Nota

La disponibilidad de los algoritmos está determinada por libgcrypt y cómo fue compilado.

quvi.crypto.encrypt(<texto plano>, <qoo>)

Cifra el texto plano. El texto plano se espera que se pase en formato hexadecimal. Ver quvi/hex de quvi-modules(7) para las funciones de conversión.

El segundo argumento (qoo) se espera que sea un diccionario que contenga las opciones de cifrado.

La función devolverá el valor texto cifrado en el diccionario. El valor se devuelve en formato hexadecimal.

quvi.crypto.decrypt(<texto cifrado>, <qoo>)

Descifra el texto cifrado. El texto cifrado se espera que se pase en formato hexadecimal. Ver quvi/hex de quvi-modules(7) para las funciones de conversión.

El segundo argumento (qoo) se espera que sea un diccionario que contenga las opciones de cifrado.

La función devolverá el valor texto plano en el diccionario. Este valor se devuelve en formato hexadecimal.

quvi.crypto.hash(<valor>, <qoo>)

Genera un hash a partir del valor. El valor se espera que se pase en formato hexadecimal. Ver quvi/hex de quvi-modules(7) para las funciones de conversión.

El segundo argumento (qoo) se espera que sea un diccionario que contenga las opciones de hash, por ejemplo, el algoritmo que debe usarse.

La función devolverá el valor digest en el diccionario. El valor se devuelve en formato hexadecimal.

HTTP

Las funciones HTTP devolverán response_code junto con los otros "VALORES DE RETORNO", y los valores específicos de la función HTTP.

quvi.http.cookie(<VALOR>,<qoo>)

Modifica la configuración de cookies del manejador de sesión de libcurl que utiliza actualmente libquvi.

El segundo argumento (qoo) se espera que sea un diccionario que contenga las opciones de cookies, por ejemplo, el modo de cookies que debe utilizarse.

La lista completa de los modos de cookies disponibles se puede encontrar en el módulo quvi/const de quvi-modules(7).

MÓDULOS

Este módulo es un wrapper alrededor de una funcionalidad específica de la biblioteca libquvi. Para una descripción general de los módulos, vea quvi-modules(7). Los nombres de los modos se nombran según sus nombres de variables equivalentes de CURLOPT_COOKIE{SESSION,FILE,LIST,JAR}. Para una descripción de cada opción, vea libcurl_easy_setopt(3).

Esta función no devolverá ningún valor adicional en el diccionario.


Nota

libquvi ignorará cualquier llamada a quvi.http.cookie a menos que QUVI_OPTION_ALLOW_COOKIES sea QUVI_TRUE


Nota

libcurl analizará las cookies recibidas y las utilizará en las solicitudes HTTP subsiguientes solo si libquvi QUVI_OPTION_ALLOW_COOKIES es QUVI_TRUE

quvi.http.fetch(<URL>[,qoo])

Recupera una URL a través de una conexión HTTP.

Se espera que el segundo argumento (qoo) sea un diccionario de opciones de objeto quvi adicionales, si se define en absoluto.

La función devolverá el valor data entre los valores del diccionario devuelto.

quvi.http.header(<VALUE>[,qoo])

Agrega, elimina o reemplaza las cabeceras HTTP de libcurl utilizadas internamente.

Se espera que el segundo argumento (qoo) sea un diccionario de opciones de objeto quvi adicionales, si se define en absoluto.

Esta función esencialmente envuelve CURLOPT_HTTPHEADER, y no devolverá ningún valor adicional en el diccionario. Vea curl_easy_setopt(3) para la descripción completa de CURLOPT_HTTPHEADER.


Nota

Para borrar las cabeceras personalizadas, pase "" como VALUE; las cabeceras personalizadas también se borran automáticamente cuando se llama a una función de script de soporte parse.

quvi.http.metainfo(<URL>[,qoo])

Consulta la metainformación HTTP de la URL.

Se espera que el segundo argumento (qoo) sea un diccionario de opciones de objeto quvi adicionales, si se define en absoluto.

La función devolverá los valores content_length y content_type entre los valores del diccionario devuelto.

quvi.http.resolve(<URL>[,qoo])

Resuelve la redirección de una URL.

Se espera que el segundo argumento (qoo) sea un diccionario de opciones de objeto quvi adicionales, si se define en absoluto.

La función devolverá la resolved_url entre los valores del diccionario devuelto. Si la URL no redirigió a otra ubicación, el valor de la resolved_url se dejará vacío.

EJEMPLOS

Base64

•Codificar una cadena Base64: 
local H = require 'quvi/hex'
local s = H.to_hex('foo') -- Pasar en formato hexadecimal
local r = quvi.base64.encode(s)
print(r.base64)
•Invertir el proceso: 
local r = quvi.base64.decode(r.base64)
local s = H.to_str(r.plaintext)

Cripto

•Cifrar texto plano: 
local plaintext = 'f34481ec3cc627bacd5dc3fb08f273e6'
local key = '00000000000000000000000000000000'
local C = require 'quvi/const'
local o = {
  [C.qoo_crypto_cipher_mode] = C.qoco_cipher_mode_cbc,
  [C.qoo_crypto_algorithm] = 'aes',
  [C.qoo_crypto_cipher_key = key
}
local r = quvi.crypto.encrypt(plaintext, o)
print(r.ciphertext)
•Invertir el proceso: 
local r = quvi.crypto.decrypt(r.ciphertext, o)
print(r.plaintext)
•Generar un hash (resumen de mensaje): 
local H = require 'quvi/hex'
local s = H.to_hex('foo') -- Pasar en formato hexadecimal
local C = require 'quvi/const'
local o = { [C.qoo_crypto_algorithm] = 'sha1' }
local r = quvi.crypto.hash(s, o)
print(r.digest)
•Igual que el anterior, pero usando la función abreviada: 
local A = require 'quvi/hash'
local r = A.sha1sum('foo')
print(r)

HTTP

•Volcar las cookies en la memoria a la salida estándar: 
local C = require 'quvi/const'
local o = { [C.qoo_http_cookie_mode] = C.qohco_mode_jar }
local r = quvi.http.cookie('-', o)
•Idéntico a lo anterior pero usando el módulo wrapper: 
local K = require 'quvi/http/cookie'
local r = K.jar('-')
•Recuperar una URL: 
local r = quvi.http.fetch('http://example.com')

r.data ahora contendría el contenido. Si ocurrió un error, por ejemplo, falla de conexión, la biblioteca finalizaría el proceso con un error.

•Igual que lo anterior, pero manejando el error en el script: 
local C = require 'quvi/const'
local o = { [C.qoo_croak_if_error] = false }
local r = quvi.http.fetch('http://example.com', o)
if r.quvi_code ~= C.qerr_ok then
  local s =
    string.format('quvi.http.fetch: %s (libquvi=%d, http/%d)',
                  r.error_message, r.quvi_code, r.response_code)
  error(s)
end

Al establecer qoo_croak_if_error en false, le decimos a la biblioteca que solo registre que ocurrió un error y devuelva el control al script. El manejo del error lo realiza entonces el script.


Nota
Típicamente, los scripts no necesitarán manejar el error
•Forzar la conversión de ISO-8859-1 a UTF-8: 
local C = require 'quvi/const'
local o = { [C.qoo_fetch_from_charset] = 'ISO-8859-1' }
local r = quvi.http.fetch('http://example.com', o)
•Anular la cabecera user-agent en la solicitud HTTP: 
local r = quvi.http.header('User-Agent: foo/1.0')
r = quvi.http.fetch(...)
•Desactivar una cabecera interna en la solicitud HTTP: 
local r = quvi.http.header('Accept:')
r = quvi.http.fetch(...)
•Enviar una cookie en la solicitud HTTP: 
local r = quvi.http.header('Cookie: foo=1')
r = quvi.http.fetch(...)
•Consultar metadatos de una URL: 
local r = quvi.http.metainfo('http://is.gd/SKyg8m')
print(r.content_length, r.content_type)
•Resolver redirección de URL: 
local r = quvi.http.resolve('http://is.gd/SKyg8m')
if #r.resolved_url >0 then
  print('nueva ubicación:', r.resolved_url)
end
