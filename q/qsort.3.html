qsort(3) Manual de funciones de la biblioteca qsort(3)

NOMBRE

qsort, qsort_r - ordenar un arreglo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
void qsort(size_t n, size_t size;
           void base[n * size], size_t n, size_t size,
           typeof(int (const void [size], const void [size]))
               *compar);
void qsort_r(size_t n, size_t size;
           void base[n * size], size_t n, size_t size,
           typeof(int (const void [size], const void [size], void *))
               *compar,
           void *arg);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

qsort_r():

    _GNU_SOURCE

DESCRIPCIÓN

La función qsort() ordena un arreglo con n elementos de tamaño size. El argumento base apunta al inicio del arreglo.

El contenido del arreglo se ordena en orden ascendente de acuerdo con una función de comparación apuntada por compar, la cual es llamada con dos argumentos que apuntan a los objetos que se están comparando.

La función de comparación debe devolver un entero menor que, igual a, o mayor que cero si el primer argumento se considera respectivamente menor que, igual a, o mayor que el segundo. Si dos miembros se comparan como iguales, su orden en el arreglo ordenado es indefinido.

La función qsort_r() es idéntica a qsort() excepto que la función de comparación compar toma un tercer argumento. Se pasa un puntero a la función de comparación a través de arg. De esta manera, la función de comparación no necesita usar variables globales para pasar argumentos arbitrarios, y por lo tanto es reentrante y segura para usar en hilos.

VALOR DE RETORNO

Las funciones qsort() y qsort_r() no devuelven ningún valor.

NOTAS

Para comparar cadenas de caracteres C, la función de comparación puede llamar a strcmp(3), como se muestra en el siguiente ejemplo.

EJEMPLOS

Para un ejemplo de uso, ver el ejemplo en bsearch(3).

Otro ejemplo es el siguiente programa, que ordena las cadenas de caracteres dadas en sus argumentos de línea de comandos:

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
static int
cmpstringp(const void *p1, const void *p2)
{
    /* Los argumentos reales de esta función son "punteros a
       punteros a char", pero los argumentos de strcmp(3) son "punteros
       a char", de ahí el siguiente cast y desreferenciación.  */
    return strcmp(*(const char **) p1, *(const char **) p2);
}
int
main(int argc, char *argv[])
{
    if (argc < 2) {
        fprintf(stderr, "Uso: %s <cadena>...\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    qsort(&argv[1], argc - 1, sizeof(char *), cmpstringp);
    for (size_t j = 1; j < argc; j++)
        puts(argv[j]);
    exit(EXIT_SUCCESS);
}
