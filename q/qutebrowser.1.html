NOMBRE

qutebrowser - un navegador dirigido por teclado, similar a vim, basado en Python y Qt.

SINOPSIS

qutebrowser [-OPCIÓN [...]] [:COMANDO [...]] [URL [...]]

DESCRIPCIÓN

qutebrowser es un navegador enfocado en el teclado con una GUI mínima. Está basado en Python y Qt y es software libre, licenciado bajo la GPL.

Fue inspirado por otros navegadores/complementos como dwb y Vimperator/Pentadactyl.

Ten en cuenta que los comandos y la configuración de qutebrowser no se describen en esta página del manual, sino en la ayuda integrada en qutebrowser. Usa el comando ":help" para mostrarla.

OPCIONES

argumentos posicionales

:comando

Comandos a ejecutar al inicio.

URL

URLs a abrir al inicio (vacío como separador de ventana).

opciones generales

-h, --help

mostrar este mensaje de ayuda y salir

-B DIRECTORIO_BASE, --basedir DIRECTORIO_BASE

Directorio base para todo el almacenamiento.

-C CONFIG, --config-py CONFIG

Ruta a config.py.

-V, --version

Mostrar versión y salir.

-s OPCIÓN VALOR, --set OPCIÓN VALOR

Establecer una configuración temporal para esta sesión.

-r SESIÓN, --restore SESIÓN

Restaurar una sesión con nombre.

-R, --override-restore

No restaurar una sesión aunque se fuera a restaurar.

--target {auto,tab,tab-bg,tab-silent,tab-bg-silent,window,private-window}

Cómo se deben abrir las URLs si ya hay una instancia de qutebrowser en ejecución.

--backend {webkit,webengine}

Qué backend usar.

--qt-wrapper {PyQt6,PyQt5}

Qué wrapper de Qt usar. Esto también se puede configurar mediante la variable de entorno QUTE_QT_WRAPPER. Si ambas están configuradas, el argumento de la línea de comandos tiene precedencia.

--desktop-file-name NOMBRE_ARCHIVO_ESCRITORIO

Establece el nombre base de la entrada de escritorio para esta aplicación. Se usa para establecer el app_id en Wayland. Ver https://doc.qt.io/qt-6/qguiapplication.html#desktopFileName-prop

--untrusted-args

Marca todos los argumentos siguientes como no confiables, lo que garantiza que sean URLs/términos de búsqueda (y no flags o comandos)

argumentos de depuración

-l {critical,error,warning,info,debug,vdebug}, --loglevel {critical,error,warning,info,debug,vdebug}

Anula el nivel de registro de la consola configurado.

--logfilter FILTRO_LOG

Lista separada por comas de cosas que se registrarán en el log de depuración en stdout.

--loglines LÍNEAS_LOG

Cuántas líneas del log de depuración mantener en RAM (-1: ilimitado).

-d, --debug

Activa las opciones de depuración.

--json-logging

Salida de las líneas de log en formato JSON (un objeto por línea).

--nocolor

Desactiva el registro con color.

--force-color

Fuerza el registro con color.

--nowindow

No mostrar la ventana principal.

-T, --temp-basedir

Usar un directorio base temporal.

--no-err-windows

No mostrar ninguna ventana de error (usado para tests/smoke.py).

--qt-arg NOMBRE VALOR

Pasa un argumento con valor a Qt. Por ejemplo, puedes usar --qt-arg geometry 650x555+200+300 para establecer la geometría de la ventana.

--qt-flag FLAG_QT

Pasa un argumento a Qt como flag.

-D FLAGS_DEBUG, --debug-flag FLAGS_DEBUG

Pasa el nombre de la característica de depuración a activar.

ARCHIVOS

•~/.config/qutebrowser/config.py: Archivo de configuración.
•~/.config/qutebrowser/autoconfig.yml: Configuración realizada a través de la GUI.
•~/.config/qutebrowser/quickmarks: Quickmarks guardados.
•~/.local/share/qutebrowser/: Diversa información de estado.
•~/.cache/qutebrowser/: Datos temporales.

Nota: qutebrowser cumple con la especificación XDG basedir. Si XDG_CONFIG_HOME, XDG_DATA_HOME o XDG_CACHE_HOME están configurados en el entorno, se usan los directorios configurados allí en lugar de los valores predeterminados anteriores.

ERRORES

Los errores se registran en el rastreador de incidencias de Github en https://github.com/qutebrowser/qutebrowser/issues.

Si encuentras un error, usa el comando integrado :report para crear un informe de error con toda la información necesaria.

Si lo prefieres, también puedes escribir a la lista de correo en qutebrowser@lists.qutebrowser.org.

Para errores de seguridad, contacta con security@qutebrowser.org (o si deseas cifrado GPG, contacta con me@the-compiler.org con el ID GPG 0x916EB0C8FD55A072).

Alternativamente, informa de una vulnerabilidad a través de la función de notificación privada de GitHub.

qutebrowser(1)

NOMBRE

qutebrowser - Un navegador web con teclado

SINOPSIS

qutebrowser [OPCIONES] [URL]

DESCRIPCIÓN

qutebrowser es un navegador web que se enfoca en la usabilidad con el teclado. Su interfaz de usuario se inspira en el popular editor de texto Vim.

OPCIONES

No hay opciones de línea de comandos disponibles.

ARCHIVOS

Los archivos de configuración se encuentran en $HOME/.config/qutebrowser/.
