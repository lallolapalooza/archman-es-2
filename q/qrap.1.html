qrap(1) Manual de Comandos Generales qrap(1)

NOMBRE

qrap - envoltorio temporal de qemu que conecta un socket de dominio UNIX a un descriptor de archivo

SINOPSIS

qrap [FDNUM QEMU_CMD] [QEMU_ARG]...

DESCRIPCIÓN

qrap es un envoltorio, diseñado específicamente para su uso con qemu(1) y passt(1), que conecta un socket de dominio UNIX a un descriptor de archivo y ejecuta qemu(1) con los argumentos proporcionados.

Se sondea una instancia en ejecución de passt(1) buscando sockets de dominio UNIX, respondiendo a una solicitud ARP simulada, con nombres que comienzan desde /tmp/passt_1.socket hasta /tmp/passt_64.socket.

Si los dos primeros argumentos no son un número de socket y un comando, es decir, FDNUM y QEMU_CMD respectivamente, qrap intentará localizar un ejecutable de qemu en PATH y modificará la línea de comandos para especificar un dispositivo de red y un backend netdev para su uso con passt(1).

Si qrap modifica la línea de comandos, eliminará cualquier dispositivo de red potencialmente conflictivo, es decir, cualquier opción -netdev o -net, o cualquier opción -device con un argumento que comience por virtio-net-pci,, virtio-net-ccw,, e1000,, e1000e,, o rtl8139,.

EJEMPLOS

Iniciar qemu pasando explícitamente su nombre de comando y un número de socket

$ ./qrap 5 kvm test.qcow2 -m 1024 -display none -nodefaults -nographic -net socket,fd=5 -net nic,model=virtio

Iniciar qemu sin nombre de comando ni número de socket, modificando los argumentos

$ ./qrap test.qcow2 -m 1024 -display none -nodefaults -nographic

NOTAS

Este envoltorio es temporal: el commit de qemu 13c6be96618c ("net: stream: add unix socket") introduce soporte nativo para sockets AF_UNIX, y debería incluirse en qemu a partir de la versión 7.2. Permanecerá un poco más de tiempo para dar a los usuarios suficiente tiempo para migrar.
