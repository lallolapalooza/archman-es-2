NOMBRE

osd_cat - visor de archivos en pantalla X

SINOPSIS

osd_cat [OPCIÓN] [ARCHIVO]...
osd_cat -b porcentaje|barra [OPCIÓN]

DESCRIPCIÓN

Muestra ARCHIVO, o la entrada estándar, en la pantalla X.

-p, --pos=POS
Esta opción le dice a osd_cat dónde mostrar el texto. POS puede ser top (arriba), middle (medio) o bottom (abajo). El valor predeterminado es top.
-o, --offset=DESPLAZAMIENTO
Esta opción especifica el DESPLAZAMIENTO desde la parte superior o inferior de la pantalla donde se muestra el texto. El valor predeterminado es 0.
-A, --align=ALINEACIÓN
Esta opción le dice a osd_cat dónde mostrar el texto. ALINEACIÓN puede ser left (izquierda), right (derecha) o center (centro). El valor predeterminado es left.
-i, --indent=DESPLAZAMIENTO
Esta opción especifica la INDENTACIÓN desde la izquierda de la pantalla donde se muestra el texto. El valor predeterminado es 0.
-f, --font=TIPO DE LETRA
Esta opción especifica el TIPO DE LETRA que se utilizará para mostrar el texto. El valor predeterminado es fixed.
-c, --color=COLOR
Esta opción especifica el COLOR que se utilizará para mostrar el texto. El valor predeterminado es red.
-d, --delay=TIEMPO
Esta opción especifica el número de segundos que se muestra el texto. El valor predeterminado es 5 segundos.
-l, --lines=LÍNEAS
Esta opción especifica el número de LÍNEAS para desplazar la visualización. El valor predeterminado es 5.
-s, --shadow=DESPLAZAMIENTO
Esta opción especifica el DESPLAZAMIENTO de la sombra del texto. El valor predeterminado es 0, lo que significa que no se crea ninguna sombra de texto.
-S, --shadowcolour=COLOR
Esta opción especifica el COLOR de la sombra del texto. El valor predeterminado es black.
-O, --outline=ANCHO
Esta opción especifica el ANCHO del contorno del texto. El valor predeterminado es 0, lo que significa que no hay contorno.
-u, --outlinecolour=COLOR
Esta opción especifica el COLOR del contorno del texto. El valor predeterminado es black.
-a, --age[=TIEMPO_DESPLAZAMIENTO]
Esta opción afecta al redibujado de la pantalla. Si pasan TIEMPO_DESPLAZAMIENTO segundos antes de que una nueva línea esté lista (por ejemplo, está leyendo desde una tubería), todas las líneas se borrarán a la vez en lugar de desplazarse a medida que las nuevas líneas reemplazan a las viejas. El valor predeterminado es 0.
Cuando no se proporciona explícitamente TIEMPO_DESPLAZAMIENTO, se utiliza el valor actual de DELAY.
-w, --wait
Esta opción también afecta al redibujado de la pantalla. Cuando hay datos listos para ser mostrados en pantalla, esta opción hará que osd_cat espere hasta que la pantalla esté vacía. Una alternativa al desplazamiento.
-b, --barmode=TIPO
Le permite mostrar una barra de porcentaje o deslizante en lugar de solo texto. TIPO puede ser percentage (porcentaje) o slider (barra deslizante). En este modo no se lee texto de ningún archivo, pero se pueden usar las siguientes opciones:
-P, --percentage=PORCENTAJE
Esta opción especifica la posición de la barra de porcentaje / deslizante. PORCENTAJE puede estar en el rango de 0 a 100, el valor predeterminado es 50.
-T, --text=TEXTO
Esta opción especifica un TEXTO opcional que se muestra encima de la barra de porcentaje. El valor predeterminado está vacío, por lo que no se muestra texto adicional.
-h, --help
muestra la ayuda (que a menudo está más actualizada) y sale

Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar.
