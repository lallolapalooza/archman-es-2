NOMBRE

openpgp-tool - utilidad para acceder a los datos visibles de tarjetas inteligentes OpenPGP y tokens compatibles

SINOPSIS

openpgp-tool [OPCIONES]

DESCRIPCIÓN

La utilidad openpgp-tool se utiliza para acceder a datos de tarjetas inteligentes OpenPGP v1.1 y v2.0 y tokens compatibles como, por ejemplo, GPF CryptoStick v1.x, que podrían no estar presentes en objetos PKCS#15 pero sí disponibles en archivos personalizados en la tarjeta. Los datos pueden imprimirse en pantalla o ser utilizados por otros programas a través de variables de entorno.

OPCIONES

--card-info, -C

Muestra información de la tarjeta.

--del-key arg

Elimina la clave indicada por arg. arg puede ser 1, 2, 3 o all.

--do arg, -d arg

Vuelca el objeto de datos privados (DO) indicado por arg. arg puede tener el formato x, 10x, o 010x para acceder al DO 010x, donde x es 1, 2, 3 o 4.

--erase, -E

Borra (es decir, reinicia) la tarjeta.

--exec prog, -x prog

Ejecuta el programa dado con los datos en variables de entorno.

--gen-key arg, -G arg

Genera una clave con el ID dado como arg. arg puede ser uno de 1, 2 o 3.

--help, -h

Imprime el mensaje de ayuda en pantalla.

--key-info, -K

Muestra información de las claves en la tarjeta.

--key-type keytype, -t keytype

Especifica el tipo de clave a generar. Los valores soportados para keytype son rsa para RSA con 2048 bits, rsaLONGITUD para RSA con una longitud de bits de LONGITUD. Si no se especifica, por defecto es rsa2048.

--pin pin

Esta opción puede usarse para especificar el valor del PIN en la línea de comandos. Si el valor se establece a env:VARIABLE, se usa el valor de la variable de entorno especificada. Por defecto, se solicita el código en la línea de comandos si es necesario.

Tenga en cuenta que en la mayoría de los sistemas operativos, cualquier usuario puede mostrar la línea de comandos de cualquier proceso en el sistema utilizando utilidades como ps(1). Por lo tanto, debería preferir pasar los códigos a través de una variable de entorno en un sistema no seguro.

--pretty

Imprime los valores en formato legible.

--raw

Imprime los valores en formato crudo, tal como están almacenados en la tarjeta.

--reader arg, -r arg

Número del lector a usar. Por defecto, se utiliza el primer lector con una tarjeta presente. Si arg es un ATR, se elegirá el lector con una tarjeta que coincida.

--user-info, -U

Muestra información del titular de la tarjeta.

--verify pintype

Verifica el PIN (CHV1, CHV2 o CHV3).

--version, -V

Imprime la versión de la utilidad y sale.

--verbose, -v

Operación detallada. Úselo varias veces para habilitar la salida de depuración.

--wait, -w

Espera a que se inserte una tarjeta.
