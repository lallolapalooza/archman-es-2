NOMBRE

osinfo-query - Consultar información en la base de datos

SINOPSIS

osinfo-query [OPCIONES...] TIPO [CONDICIÓN-1 [CONDICIÓN-2 ...]]

DESCRIPCIÓN

El comando "osinfo-query" permite extraer información de la base de datos. TIPO puede ser uno de "os", "platform", "device", o "deployment". Si no se especifican condiciones, se listarán todas las entidades del tipo dado.

# Listar todos los sistemas operativos
$ osinfo-query os
 ID corto           | Nombre     ...
--------------------+-----------
 centos-6.0         | CentOS 6.0 ...
 centos-6.1         | CentOS 6.1 ...
 ...

Las condiciones permiten filtrar basándose en propiedades específicas de una entidad. Por ejemplo, para filtrar solo distribuciones del Proyecto Fedora, usa

# Listar todos los sistemas operativos
$ osinfo-query os vendor="Fedora Project"
 ID corto           | Nombre          ...
--------------------+--------------
 fedora1            | Fedora Core 1 ...
 fedora2            | Fedora Core 2 ...
 ...

El conjunto de campos que se imprimen se puede controlar usando el argumento de línea de comandos --fields:

# Listar todos los sistemas operativos
$ osinfo-query --fields=short-id,version os vendor="Fedora Project"
 ID corto           | Versión
--------------------+----------
 fedora1            | 1
 fedora2            | 2
 ...

OPCIONES

-s PROPIEDAD, --sort-key PROPIEDAD
Establecer la clave de ordenación de datos. Por defecto ordena por la primera columna
-f PROPIEDAD1,PROPIEDAD2,..., --fields PROPIEDAD1,PROPIEDAD2,...
Establecer la visibilidad de las propiedades en la salida

NOMBRES DE PROPIEDADES

OS

Los nombres de propiedad válidos para el tipo "os" son:

short-id
El identificador corto del SO
name
El nombre largo del SO
version
La cadena de versión del SO
family
La familia del kernel del SO
vendor
El proveedor del SO
release-date
La fecha de lanzamiento del SO
eol-date
La fecha de fin de vida del SO
codename
El nombre en clave del SO
id
El identificador del SO

PLATFORM

Los nombres de propiedad válidos para el tipo "platform" son:

short-id
El identificador corto de la plataforma
name
El nombre largo de la plataforma
version
La cadena de versión de la plataforma
vendor
El proveedor de la plataforma
release-date
La fecha de lanzamiento de la plataforma
eol-date
La fecha de fin de vida de la plataforma
codename
El nombre en clave de la plataforma
id
El identificador de la plataforma

DEVICE

Los nombres de propiedad válidos para el tipo "device" son:

name
El nombre del dispositivo
product
El nombre del producto del dispositivo
product-id
La cadena del ID del producto del dispositivo
vendor
El nombre del proveedor del dispositivo
vendor-id
La cadena del ID del proveedor del dispositivo
class
La clase del tipo de dispositivo
bus
El tipo de bus del dispositivo
id
El identificador del dispositivo

DEPLOYMENT

Los nombres de propiedad válidos para el tipo "deployment" son:

id
El identificador del despliegue

ESTADO DE SALIDA

El estado de salida será 0 si se encontraron entradas coincidentes, o 1 si no se encontraron coincidencias.
