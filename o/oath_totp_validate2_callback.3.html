NOMBRE

oath_totp_validate2_callback - función API

SINOPSIS

#include <oath.h>

int oath_totp_validate2_callback(const char * secret, size_t secret_length, time_t now, unsigned time_step_size, time_t start_offset, unsigned digits, size_t window, int * otp_pos, oath_validate_strcmp_function strcmp_otp, void * strcmp_handle);

ARGUMENTOS

const char * secret
la cadena del secreto compartido
size_t secret_length
longitud de secret
time_t now
valor de tiempo Unix para calcular el TOTP
unsigned time_step_size
parámetro del sistema de paso de tiempo (típicamente 30)
time_t start_offset
tiempo Unix desde cuándo empezar a contar los pasos de tiempo (típicamente 0)
unsigned digits
número de dígitos solicitados en el OTP
size_t window
cuántos OTP después del contador de inicio probar
int * otp_pos
posición de búsqueda de salida en la ventana de búsqueda (puede ser NULL).
oath_validate_strcmp_function strcmp_otp
puntero a función a una función similar a strcmp.
void * strcmp_handle
manejador del llamador que se pasará a strcmp_otp.

DESCRIPCIÓN

Valida un OTP según el algoritmo OATH TOTP según RFC 6238.

La validación se implementa generando un número de OTPs potenciales y realizando una llamada a la función strcmp_otp, para comparar el OTP potencial contra el otp dado. Tiene el siguiente prototipo:

int (*oath_validate_strcmp_function) (void *handle, const char *test_otp);

La función debe ser similar a strcmp en que devuelve 0 solo en coincidencias. Difiere al permitir el uso de códigos de retorno negativos como indicación de fallos internos en la función de devolución de llamada. Los valores positivos indican una falta de coincidencia del OTP.

Esta interfaz de devolución de llamada es útil cuando no se pueden comparar OTPs directamente usando strcmp normal, sino que, por ejemplo, solo se tiene un OTP hasheado. Normalmente, pasarías el OTP hasheado en strcmp_handle y dejarías que tu implementación de strcmp_otp hashee el OTP test_otp usando el mismo hash, y luego compararías los resultados.

Actualmente solo se admiten longitudes de OTP de 6, 7 u 8 dígitos. Esta restricción puede eliminarse en versiones futuras, aunque algunas limitaciones son inherentes al protocolo.

DEVUELVE

Devuelve el valor absoluto de la posición en la ventana OTP (cero es la primera posición), o OATH_INVALID_OTP si no se encontró ningún OTP en la ventana OTP, o un código de error.
