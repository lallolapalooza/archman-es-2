OPENVT(1) Manual de comandos generales OPENVT(1)

NOMBRE

openvt - iniciar un programa en una nueva terminal virtual (VT).

SINOPSIS

openvt [-c vtnumber] [OPCIONES] [--] comando

DESCRIPCIÓN

openvt encontrará la primera VT disponible y ejecutará en ella el comando especificado con sus opciones de comando, entrada, salida y error estándar dirigidos a esa terminal. La ruta de búsqueda actual ($PATH) se utiliza para encontrar el comando solicitado. Si no se especifica ningún comando, se utiliza la variable de entorno $SHELL.

OPCIONES

-c, --consola=NÚMEROVT
Utiliza el número de VT dado y no el primero disponible. Tenga en cuenta que debe tener acceso de escritura a la VT proporcionada para que esto funcione.
-f, --forzar
Forzar la apertura de una VT sin comprobar si ya está en uso.
-e, --ejecutar
Ejecuta directamente el comando dado, sin crear un proceso hijo. Esta opción está pensada para su uso en /etc/inittab.
-s, --cambiar
Cambiar a la nueva VT al iniciar el comando. La VT del nuevo comando se convertirá en la nueva VT actual.
-u, --usuario
Determina el propietario de la VT actual y ejecuta login como ese usuario. Adecuado para ser llamado por init. No debe usarse con -c o -l.
-l, --inicio_sesion
Hacer que el comando sea un shell de inicio de sesión. Se antepone un guion al nombre del comando a ejecutar.
-v, --verboso
Ser un poco más detallado.
-w, --esperar
esperar a que el comando se complete. Si se usan -w y -s juntos, openvt volverá a la terminal de control cuando el comando se complete.
-V, --versión
mostrar la versión del programa y salir.
-h, --ayuda
mostrar este texto y salir.
--
fin de las opciones para openvt.

NOTA

Si openvt está compilado con getopt_long() y desea establecer opciones para el comando a ejecutar, debe proporcionar el separador de opciones -- antes del comando.

EJEMPLOS

openvt se puede usar para iniciar un shell en la próxima VT libre, utilizando el comando:

openvt bash
Para iniciar el shell como un shell de inicio de sesión, utilice:
openvt -l bash
Para obtener una lista detallada, debe proporcionar el separador --:
openvt -- ls -l

HISTORIAL

Anteriormente, openvt se llamaba open. Fue escrito por Jon Tombs <jon@gtex02.us.es> o <jon@robots.ox.ac.uk>. La idea de -w es de "sam".
