openssl-genpkey(1ssl)

Paquete: openssl

Licencias: Apache-2.0

OPENSSL-GENPKEY(1ssl) OpenSSL OPENSSL-GENPKEY(1ssl)

NOMBRE

openssl-genpkey - genera una clave privada o un par de claves

SINOPSIS

openssl genpkey [-help] [-out nombre_archivo] [-outpubkey nombre_archivo] [-outform DER|PEM] [-verbose] [-quiet] [-pass arg] [-algoritmo_cifrado] [-paramfile archivo] [-algorithm alg] [-pkeyopt opt:valor] [-genparam] [-text] [-rand archivos] [-writerand archivo] [-engine id]

[-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq] [-config archivo_config]

DESCRIPCIÓN

Este comando genera una clave privada o un par de claves.

OPCIONES

-help
Imprime un mensaje de uso.
-out nombre_archivo
Salida de la clave privada al archivo especificado. Si este argumento no se especifica, se usa la salida estándar.
-outpubkey nombre_archivo
Salida de la clave pública al archivo especificado. Si este argumento no se especifica, la clave pública no se genera.
-outform DER|PEM
El formato de salida, excepto cuando se usa -genparam; el valor por defecto es PEM. Ver openssl-format-options(1) para detalles.

Cuando se usa -genparam, -outform se ignora.

-verbose
Salida de "puntos de estado" mientras se generan las claves.
-quiet
No salgas "puntos de estado" mientras generas claves.
-pass arg
Fuente de la contraseña del archivo de salida. Para más información sobre el formato de arg, ver openssl-passphrase-options(1).
-algoritmo_cifrado
Cifra la clave privada usando el algoritmo especificado. El algoritmo puede ser especificado usando un nombre aceptado por la función EVP_get_cipherbyname(). Por ejemplo, usa la sintaxis -aes-128-cbc para especificar el algoritmo de cifrado AES con una clave de 128 bits en modo CBC.
-algorithm alg
Algoritmo de clave pública a usar, como RSA, DSA, DH o DHX. Si se usa, esta opción debe preceder a cualquier opción de -pkeyopt. Las opciones -paramfile y -algorithm son mutuamente excluyentes. Los módulos (engines) o proveedores pueden añadir algoritmos además de los integrados estándar.

Los nombres de algoritmos integrados válidos para la generación de claves privadas son RSA, RSA-PSS, EC, X25519, X448, ED25519, ED448, ML-DSA y ML-KEM.

Los nombres de algoritmos integrados válidos para la generación de parámetros (ver la opción -genparam) son DH, DSA y EC.

Ten en cuenta que el nombre de algoritmo X9.42 DH puede ser usado como sinónimo de claves DHX y PKCS#3 se refiere a Claves DH. Algunas opciones no se comparten entre claves DH y DHX.

-pkeyopt opt:valor
Establece la opción del algoritmo de clave pública opt a valor. El conjunto exacto de opciones soportadas depende del algoritmo de clave pública usado y su implementación. Ver "OPCIONES DE GENERACIÓN DE CLAVES" y "OPCIONES DE GENERACIÓN DE PARÁMETROS" abajo para más detalles.

Para listar los valores opt posibles para un algoritmo, usa: openssl genpkey -algorithm XXX -help

-genparam
Genera un conjunto de parámetros en lugar de una clave privada. Si se usa, esta opción debe preceder a cualquier opción de -algorithm, -paramfile o -pkeyopt.
-paramfile nombre_archivo
Algunos algoritmos de clave pública generan una clave privada basándose en un conjunto de parámetros. Estos pueden ser proporcionados usando esta opción. Si se usa esta opción, el algoritmo de clave pública se determina por los parámetros. Si se usa, esta opción debe preceder a cualquier opción de -pkeyopt. Las opciones -paramfile y -algorithm son mutuamente excluyentes.
-text
Imprime una representación textual (no cifrada) de las claves privadas y públicas y los parámetros junto con la estructura PEM o DER.
-rand archivos, -writerand archivo
Ver "Opciones de Estado Aleatorio" en openssl(1) para detalles.
-engine id
Ver "Opciones de Módulo (Engine)" en openssl(1). Esta opción está obsoleta.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Ver "Opciones de Proveedor" en openssl(1), provider(7) y property(7).
-config archivo_config
Ver "Opción de Configuración" en openssl(1).

OPCIONES DE GENERACIÓN DE CLAVES

Las opciones soportadas por cada algoritmo e implementación de un algoritmo pueden variar. Las opciones para las implementaciones de OpenSSL se detallan a continuación. No hay opciones de generación de claves definidas para los algoritmos X25519, X448, ED25519 o ED448.

Opciones de Generación de Claves RSA

rsa_keygen_bits:numbits
El número de bits de la clave generada. Si no se especifica, se usa 2048.
rsa_keygen_primes:numprimes
El número de primos de la clave generada. Si no se especifica, se usa 2.
rsa_keygen_pubexp:value
El valor del exponente público RSA. Puede ser un valor decimal o hexadecimal grande si va precedido por "0x". El valor por defecto es 65537.

Opciones de Generación de Claves RSA-PSS

Nota: por defecto, una clave RSA-PSS no tiene restricciones de parámetros.

rsa_keygen_bits:numbits, rsa_keygen_primes:numprimes, rsa_keygen_pubexp:value
Estas opciones tienen el mismo significado que para el algoritmo RSA.
rsa_pss_keygen_md:digest
Si se establece, la clave está restringida y solo puede usar digest para firmar.
rsa_pss_keygen_mgf1_md:digest
Si se establece, la clave está restringida y solo puede usar digest como parámetro MGF1.
rsa_pss_keygen_saltlen:len
Si se establece, la clave está restringida y len especifica la longitud mínima de la sal (salt).

Opciones de Generación de Parámetros EC

Las opciones de generación de parámetros EC son las mismas que para la generación de claves. Vea "Opciones de Generación de Claves EC" arriba.

NOTAS

Se recomienda el uso del programa genpkey sobre las utilidades específicas del algoritmo porque se pueden usar opciones de algoritmo adicionales y algoritmos proporcionados por ENGINE.

EJEMPLOS

Generar una clave privada RSA usando parámetros predeterminados:

openssl genpkey -algorithm RSA -out key.pem

Cifrar la clave privada de salida usando AES de 128 bits y la frase contraseña "hello":

openssl genpkey -algorithm RSA -out key.pem -aes-128-cbc -pass pass:hello

Generar una clave RSA de 2048 bits usando 3 como exponente público:

openssl genpkey -algorithm RSA -out key.pem \
    -pkeyopt rsa_keygen_bits:2048 -pkeyopt rsa_keygen_pubexp:3

Generar parámetros DSA de 2048 bits que puedan ser validados: Los valores de salida para gindex y seed son requeridos para propósitos de validación de claves y no se guardan en el archivo pem de salida).

openssl genpkey -genparam -algorithm DSA -out dsap.pem -pkeyopt pbits:2048 \
    -pkeyopt qbits:224 -pkeyopt digest:SHA256 -pkeyopt gindex:1 -text

Generar clave DSA a partir de parámetros:

openssl genpkey -paramfile dsap.pem -out dsakey.pem

Generar clave DH de 4096 bits usando el grupo de primos seguros ffdhe4096:

openssl genpkey -algorithm DH -out dhkey.pem -pkeyopt group:ffdhe4096

Generar clave DH X9.42 de 2048 bits con subgrupo de 256 bits usando el grupo3 RFC5114:

openssl genpkey -algorithm DHX -out dhkey.pem -pkeyopt dh_rfc5114:3

Generar una clave DH usando un archivo de parámetros DH:

openssl genpkey -paramfile dhp.pem -out dhkey.pem

Generar parámetros DH para el grupo de primos seguros ffdhe2048:

openssl genpkey -genparam -algorithm DH -out dhp.pem -pkeyopt group:ffdhe2048

Generar parámetros DH X9.42 de 2048 bits con subgrupo de 224 bits usando el grupo2 RFC5114:

openssl genpkey -genparam -algorithm DHX -out dhp.pem -pkeyopt dh_rfc5114:2

Generar parámetros DH X9.42 de 2048 bits con subgrupo de 224 bits usando la generación de claves FIP186-4:

openssl genpkey -genparam -algorithm DHX -out dhp.pem -text \
    -pkeyopt pbits:2048 -pkeyopt qbits:224 -pkeyopt digest:SHA256 \
    -pkeyopt gindex:1 -pkeyopt dh_paramgen_type:2

Generar parámetros DH X9.42 de 1024 bits con subgrupo de 160 bits usando la generación de claves FIP186-2:

openssl genpkey -genparam -algorithm DHX -out dhp.pem -text \
    -pkeyopt pbits:1024 -pkeyopt qbits:160 -pkeyopt digest:SHA1 \
    -pkeyopt gindex:1 -pkeyopt dh_paramgen_type:1

Generar parámetros DH de 2048 bits:

openssl genpkey -genparam -algorithm DH -out dhp.pem \
    -pkeyopt dh_paramgen_prime_len:2048

Generar parámetros DH de 2048 bits usando un generador:

openssl genpkey -genparam -algorithm DH -out dhpx.pem \
    -pkeyopt dh_paramgen_prime_len:2048 \
    -pkeyopt dh_paramgen_type:1

Generar parámetros EC:

openssl genpkey -genparam -algorithm EC -out ecp.pem \
       -pkeyopt ec_paramgen_curve:secp384r1 \
       -pkeyopt ec_param_enc:named_curve

Generar clave EC a partir de parámetros:

openssl genpkey -paramfile ecp.pem -out eckey.pem

Generar clave EC directamente:

openssl genpkey -algorithm EC -out eckey.pem \
       -pkeyopt ec_paramgen_curve:P-384 \
       -pkeyopt ec_param_enc:named_curve

Generar una clave privada X25519:

openssl genpkey -algorithm X25519 -out xkey.pem

Generar una clave privada ED448:

openssl genpkey -algorithm ED448 -out xkey.pem

Generar una clave privada ML-DSA-65:

openssl genpkey -algorithm ML-DSA-65 -out ml-dsa-key.pem

Generar una clave privada ML-KEM-768:

openssl genpkey -algorithm ML-KEM-768 -out ml-kem-key.pem

HISTORIAL

La capacidad de usar nombres de curvas NIST y de generar una clave EC directamente se añadió en OpenSSL 1.0.2. La capacidad de generar claves X25519 se añadió en OpenSSL 1.1.0. La capacidad de generar claves X448, ED25519 y ED448 se añadió en OpenSSL 1.1.1.

La opción -engine fue deprecada en OpenSSL 3.0.

El soporte para ML-DSA y ML-KEM se añadió en OpenSSL 3.5.
