OCAMLCP(1) Manual de Comandos Generales OCAMLCP(1)

NOMBRE

ocamlcp, ocamloptp - Los compiladores de perfilado de OCaml

SINOPSIS

ocamlcp [ opciones de omlac ] [ -P indicadores ] nombre_archivo ...

ocamloptp [ opciones de omlapt ] [ -P indicadores ] nombre_archivo ...

DESCRIPCIÓN

Los comandos ocamlcp y ocamloptp son interfaces para ocamlc(1) y ocamlopt(1) que instrumentan el código fuente, añadiendo código para registrar cuántas veces se llaman las funciones, cuántas veces se toman las ramas de los condicionales, etc. La ejecución del código instrumentado produce un perfil de ejecución en el archivo ocamlprof.dump, que puede ser leído usando ocamlprof(1).

ocamlcp acepta los mismos argumentos y opciones que ocamlc(1) y ocamloptp acepta los mismos argumentos y opciones que ocamlopt(1). Solo hay una excepción: en ambos casos, la opción -pp no es compatible. Si necesita preprocesar sus archivos fuente, tendrá que hacerlo por separado antes de llamar a ocamlcp o ocamloptp.

OPCIONES

Además de las opciones de ocamlc(1) u ocamlopt(1), ocamlcp y ocamloptp aceptan una opción para controlar el tipo de información de perfilado, la opción -Pletras. Las letras indican qué partes del programa deben ser perfiladas:

a
todas las opciones
f
llamadas a funciones: se establece un punto de conteo al principio del cuerpo de cada función
i
if ... then ... else: se establecen puntos de conteo en ambas ramas then y else
l
bucles while, for: se establece un punto de conteo al principio del cuerpo del bucle
m
ramas match: se establece un punto de conteo al principio del cuerpo de cada rama de una coincidencia de patrones
t
ramas try ... with: se establece un punto de conteo al principio del cuerpo de cada rama de un capturador de excepciones

Por ejemplo, compilar con ocamlcp -P film perfila llamadas a funciones, if ... then ... else ..., bucles y coincidencias de patrones.

Llamar a ocamlcp(1) u ocamloptp(1) sin la opción -P por defecto es -P fm, lo que significa que solo se perfilan llamadas a funciones y coincidencias de patrones.

Nota: para compatibilidad con versiones anteriores, ocamlcp(1) también acepta la opción -p con el mismo argumento y significado que -P.
