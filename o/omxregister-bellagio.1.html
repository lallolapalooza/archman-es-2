NOMBRE

omxregister-bellagio - registrar componentes OpenMAX/Bellagio

SINOPSIS

omxregister-bellagio [-v] [-h] [ rutacomponentes ]...

DESCRIPCIÓN

Antes de usar cualquier componente OpenMAX, deben registrarse con el comando omxregister-bellagio.

Por defecto, esto creará un archivo llamado .omxregister bajo el directorio de datos XDG del hogar con todos los componentes encontrados en ${libdir}/bellagio.

OPCIONES

-v
Mostrar una salida detallada, listando todos los componentes registrados.
-h
Mostrar ayuda.
rutacomponentes
Ubicación de los componentes OpenMAX/Bellagio (por defecto ${libdir}/bellagio). Las ubicaciones múltiples deben estar separadas por dos puntos.

ARCHIVOS

$XDG_DATA_HOME/libomxil-bellagio/registry o $OMX_BELLAGIO_REGISTRY.

El archivo de registro de componentes OpenMAX/Bellagio.

AMBIENTE

BELLAGIO_SEARCH_PATH
Esta variable puede establecerse para indicar la(s) ubicación(es) de los componentes.
OMX_BELLAGIO_REGISTRY
Ubicación del registro.
XDG_DATA_HOME
Ubicación del directorio de datos del hogar donde se guarda el registro (si $OMX_BELLAGIO_REGISTRY no está establecido).
