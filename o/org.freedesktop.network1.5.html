NOMBRE

org.freedesktop.network1 - La interfaz D-Bus de systemd-networkd

INTRODUCCIÓN

systemd-networkd.service(8) es un servicio del sistema que gestiona y configura interfaces de red. Esta página describe la interfaz D-Bus.

EL OBJETO MANAGER

El servicio expone las siguientes interfaces en el objeto Manager en el bus:

node /org/freedesktop/network1 {
  interface org.freedesktop.network1.Manager {
    methods:
      ListLinks(out a(iso) links);
      GetLinkByName(in  s name,
                    out i ifindex,
                    out o path);
      GetLinkByIndex(in  i ifindex,
                     out s name,
                     out o path);
      SetLinkNTP(in  i ifindex,
                 in  as servers);
      SetLinkDNS(in  i ifindex,
                 in  a(iay) addresses);
      SetLinkDNSEx(in  i ifindex,
                   in  a(iayqs) addresses);
      SetLinkDomains(in  i ifindex,
                     in  a(sb) domains);
      SetLinkDefaultRoute(in  i ifindex,
                          in  b enable);
      SetLinkLLMNR(in  i ifindex,
                   in  s mode);
      SetLinkMulticastDNS(in  i ifindex,
                          in  s mode);
      SetLinkDNSOverTLS(in  i ifindex,
                        in  s mode);
      SetLinkDNSSEC(in  i ifindex,
                    in  s mode);
      SetLinkDNSSECNegativeTrustAnchors(in  i ifindex,
                                        in  as names);
      RevertLinkNTP(in  i ifindex);
      RevertLinkDNS(in  i ifindex);
      RenewLink(in  i ifindex);
      ForceRenewLink(in  i ifindex);
      ReconfigureLink(in  i ifindex);
      Reload();
      DescribeLink(in  i ifindex,
                   out s json);
      Describe(out s json);
    properties:
      readonly s OperationalState = '...';
      readonly s CarrierState = '...';
      readonly s AddressState = '...';
      readonly s IPv4AddressState = '...';
      readonly s IPv6AddressState = '...';
      readonly s OnlineState = '...';
      @org.freedesktop.DBus.Property.EmitsChangedSignal("const")
      readonly t NamespaceId = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly u NamespaceNSID = ...;
  };
  interface org.freedesktop.DBus.Peer { ... };
  interface org.freedesktop.DBus.Introspectable { ... };
  interface org.freedesktop.DBus.Properties { ... };
};

Proporciona información sobre el gestor.

Propiedades

NamespaceId contiene el número de inodo del espacio de nombres de red en el que se ejecuta el servicio de red. Un cliente puede comparar esto con el número de inodo de su propio espacio de nombres de red para verificar si el servicio gestiona el mismo espacio de nombres de red.

NamespaceNSID contiene el identificador "nsid" que el kernel mantiene para el espacio de nombres de red, si hay uno asignado.

NOMBRE

org.freedesktop.network1 - Gestión de redes systemd

INTRODUCCIÓN

org.freedesktop.network1 es una interfaz de servicio de D-Bus proporcionada por systemd-networkd.service(8) que permite monitorizar y controlar la configuración de red de la máquina.

Esta interfaz está diseñada para ser implementada de forma genérica y no se limita a un subsistema de red específico. Se centra en la representación de conceptos de red de alto nivel, como enlaces, redes, servidores DHCP y clientes DHCP, y proporciona una forma sencilla y consistente de interactuar con ellos.

EL OBJETO MANAGER

El objeto manager principal es /org/freedesktop/network1. Expone la siguiente interfaz:

org.freedesktop.Network1.

Este objeto proporciona métodos para enumerar y obtener información sobre los enlaces, redes y otras entidades de red gestionadas por systemd-networkd.service(8). También permite activar y desactivar redes, y configurar parámetros de red.

EL OBJETO LINK

Los objetos Link representan las interfaces de red físicas y virtuales en el sistema. Se encuentran en la ruta /org/freedesktop/network1/link/<id>, donde <id> es un identificador único para el enlace (por ejemplo, el nombre de la interfaz).

Los objetos Link exponen la interfaz org.freedesktop.Network1.Link, que proporciona información sobre el estado del enlace, como la dirección MAC, el estado de la conexión, la dirección IP configurada, etc.

También expone métodos para configurar el enlace, como establecer una dirección IP estática, configurar DHCP, etc.

EL OBJETO NETWORK

Los objetos Network representan las configuraciones de red aplicadas a uno o más enlaces. Se encuentran en la ruta /org/freedesktop/network1/network/<id>.

Los objetos Network exponen la interfaz org.freedesktop.Network1.Network, que proporciona información sobre la configuración de red, como el nombre de la red, los enlaces asociados, la configuración de DHCP, etc.

Permite activar y desactivar configuraciones de red, y modificar sus parámetros.

EL OBJETO DHCP SERVER

Los objetos DHCP Server representan un servidor DHCP configurado en un enlace. Se encuentran en la ruta /org/freedesktop/network1/dhcp_server/<id>.

Estos objetos exponen la interfaz org.freedesktop.Network1.DHCPv4Server y org.freedesktop.Network1.DHCPv6Server, que proporcionan información sobre el estado del servidor DHCP y las direcciones IP asignadas.

EL OBJETO DHCPV4 CLIENT

Los objetos DHCPv4 Client representan un cliente DHCPv4 configurado en un enlace. Se encuentran en la ruta /org/freedesktop/network1/dhcp_client/ipv4/<id>.

Estos objetos exponen la interfaz org.freedesktop.Network1.DHCPv4Client, que proporciona información sobre el estado del cliente DHCPv4 y la dirección IP obtenida.

EL OBJETO DHCPV6 CLIENT

Los objetos DHCPv6 Client representan un cliente DHCPv6 configurado en un enlace. Se encuentran en la ruta /org/freedesktop/network1/dhcp_client/ipv6/<id>.

Estos objetos exponen la interfaz org.freedesktop.Network1.DHCPv6Client, que proporciona información sobre el estado del cliente DHCPv6 y las direcciones IPv6 obtenidas.

EJEMPLOS

Puedes usar herramientas como networkctl(1) o gdbus(1) para interactuar con esta interfaz D-Bus. Por ejemplo, para listar todos los enlaces de red:

networkctl list

O para obtener información detallada de un enlace específico:

networkctl status eth0

VERSIONAMIENTO

La interfaz D-Bus org.freedesktop.network1 sigue las directrices de versionamiento de D-Bus para garantizar la compatibilidad hacia atrás. Las nuevas características se añaden como nuevas interfaces o métodos/propiedades, y las interfaces antiguas se marcan como obsoletas pero se mantienen disponibles.

Consulta la documentación de D-Bus para más detalles sobre el versionamiento.

HISTORIAL

systemd-networkd y su interfaz D-Bus org.freedesktop.network1 se introdujeron en systemd v215.
