Nombre

org.bluez.AdvertisementMonitorManager - Documentación de la API AdvertisementMonitorManager de BlueZ D-Bus

Interfaz

Servicio
org.bluez
Interfaz
org.bluez.AdvertisementMonitorManager1 [experimental]
Ruta de objeto
/org/bluez/{hci0,hci1,...}

Métodos

void RegistrarMonitor(object aplicación)

Registra la ruta raíz de un conjunto de monitores de anuncios que implementan org.bluez.AdvertisementMonitor(5).

La ruta del objeto de la aplicación junto con la ID de conexión del bus del sistema D-Bus definen la identificación de la aplicación que registra los monitores de anuncios.

Una vez que un cliente registra una ruta raíz a través de este método, el cliente puede exponer/desexponer libremente monitores de anuncios sin volver a registrar la ruta raíz.

Después de su uso, el cliente debe llamar al método DesregistrarMonitor() para invalidar los monitores de anuncios.

Posibles errores:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.YaExiste
org.bluez.Error.Fallo

void DesregistrarMonitor(object aplicación)

Desregistra un conjunto de monitores de anuncios que se registraron previamente con RegistrarMonitor(). El parámetro de ruta del objeto debe coincidir con el mismo valor que se utilizó en el registro.

Tras la desregistro, los monitores de anuncios deberían esperar recibir el método Release() como señal de que los monitores de anuncios han sido desactivados.

Posibles errores:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.NoExiste

Propiedades

array{string} TiposMonitorSoportados [solo lectura]

Esto enumera los tipos de monitores de anuncios compatibles. Una aplicación debería comprobar esto antes de instanciar y exponer un objeto de org.bluez.AdvertisementMonitor(5).

Posibles valores:

"or_patterns"
Patrones con lógica OR aplicada. Con este tipo, la propiedad Patterns debe existir y tener al menos un patrón.

array{string} FuncionalidadesSoportadas [solo lectura]

Esto enumera las funcionalidades de monitorización de anuncios soportadas por bluetoothd(8).

Posibles valores:

"controller-patterns"
Si el controlador es capaz de realizar monitorización de anuncios por patrones, bluetoothd(8) descargará los patrones al controlador para reducir el consumo de energía.
