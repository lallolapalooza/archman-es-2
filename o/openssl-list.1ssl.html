NOMBRE

openssl-list - lista algoritmos y características

SINOPSIS

openssl list [-help] [-verbose] [-select nombre] [-1] [-all-algorithms] [-commands] [-standard-commands] [-digest-algorithms] [-digest-commands] [-kdf-algorithms] [-mac-algorithms] [-random-instances] [-random-generators] [-cipher-algorithms] [-cipher-commands] [-encoders] [-decoders] [-key-managers] [-skey-managers] [-key-exchange-algorithms] [-kem-algorithms] [-tls-groups] [-all-tls-groups] [-tls1_2] [-tls1_3] [-signature-algorithms] [-tls-signature-algorithms] [-asymcipher-algorithms] [-public-key-algorithms] [-public-key-methods] [-store-loaders] [-providers] [-engines] [-disabled] [-objects] [-options comando] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq]

DESCRIPCIÓN

Este comando se utiliza para generar listas de algoritmos o características deshabilitadas.

OPCIONES

-help
Muestra un mensaje de uso.
-verbose
Muestra información adicional. Las opciones que se indican a continuación donde la verbosidad aplica dicen un poco más sobre lo que significa.
-select nombre
Solo lista algoritmos que coinciden con este nombre.
-1
Lista los comandos, digest-commands o cipher-commands en una sola columna. Si se usa, esta opción debe ir primero.
-all-algorithms
Muestra listas de todos los algoritmos. Estos incluyen:
Cifrados asimétricos
Decodificadores
Resúmenes (Digests)
Codificadores
Algoritmos de derivación de claves (KDF)
Métodos de encapsulación de claves (KEM)
Algoritmos de intercambio de claves (KEX)
Gestores de claves
Gestores de claves simétricas
Algoritmos de código de autenticación de mensajes (MAC)
Generadores de números aleatorios (RNG, DRBG)
Algoritmos de firma
Cargadores de almacenamiento
Cifrados simétricos
-commands
Muestra una lista de comandos estándar.
-standard-commands
Lista de comandos estándar.
-digest-commands
Esta opción está obsoleta. Usa digest-algorithms en su lugar.

Muestra una lista de comandos de resumen de mensajes, que se utilizan normalmente como entrada para los comandos openssl-dgst(1) o openssl-speed(1).

-cipher-commands
Esta opción está obsoleta. Usa cipher-algorithms en su lugar.

Muestra una lista de comandos de cifrado, que se utilizan normalmente como entrada para los comandos openssl-enc(1) o openssl-speed(1).

-cipher-algorithms, -digest-algorithms, -kdf-algorithms, -mac-algorithms,
Muestra una lista de algoritmos de cifrado simétrico, resumen, kdf y mac. Consulte "Visualización de nombres de algoritmos" para una descripción de cómo se muestran los nombres.

En modo detallado, los algoritmos proporcionados por un proveedor obtendrán información adicional sobre qué parámetros admite cada implementación.

-random-instances
Lista los detalles del generador de números aleatorios primario, público y privado.
-random-generators
Muestra una lista de generadores de números aleatorios. Consulte "Visualización de nombres de algoritmos" para una descripción de cómo se muestran los nombres.
-encoders
Muestra una lista de codificadores. Consulte "Visualización de nombres de algoritmos" para una descripción de cómo se muestran los nombres.

En modo detallado, los algoritmos proporcionados por un proveedor obtendrán información adicional sobre qué parámetros admite cada implementación.

-decoders
Muestra una lista de decodificadores. Consulte "Visualización de nombres de algoritmos" para una descripción de cómo se muestran los nombres.

En modo detallado, los algoritmos proporcionados por un proveedor obtendrán información adicional sobre qué parámetros admite cada implementación.

-public-key-algorithms
Muestra una lista de algoritmos de clave pública, con cada algoritmo como un bloque de varias líneas, todas excepto la primera están indentadas. Las opciones key-exchange-algorithms, kem-algorithms, signature-algorithms y asymcipher-algorithms mostrarán información similar.
-public-key-methods
Muestra una lista de métodos de clave pública.
-key-managers
Muestra una lista de gestores de claves.
-skey-managers
Muestra una lista de gestores de claves simétricas.
-key-exchange-algorithms
Muestra una lista de algoritmos de intercambio de claves.
-kem-algorithms
Muestra una lista de algoritmos de encapsulación de claves.
-tls-groups
Muestra una lista de los nombres IANA de todos los grupos TLS disponibles (implementados). Por defecto, los grupos listados son los compatibles con TLS 1.3.
-all-tls-groups
Muestra una lista de los nombres de todos los grupos TLS disponibles (implementados), incluidos los alias. Algunos grupos se conocen con varios nombres, por ejemplo, secp256r1 también se conoce como P-256. Por defecto, los grupos listados son los compatibles con TLS 1.3.
-tls1_2
Al listar grupos TLS, lista aquellos compatibles con TLS 1.2
-tls1_3
Al listar grupos TLS, muestra aquellos compatibles con TLS 1.3. TLS 1.3 es la versión de protocolo predeterminada actual, pero la versión predeterminada está sujeta a cambios, por lo que es mejor especificar la versión explícitamente.
-signature-algorithms
Muestra una lista de algoritmos de firma.
-tls-signature-algorithms
Muestra la lista de algoritmos de firma disponibles para los handshakes TLS puestos a disposición por todos los proveedores actualmente activos. El formato de salida está delimitado por dos puntos en una forma directamente utilizable en SSL_CONF_cmd(3) especificando SignatureAlgorithms.
-asymcipher-algorithms
Muestra una lista de algoritmos de cifrado asimétrico.
-store-loaders
Muestra una lista de cargadores de almacenamiento.
-providers

NOMBRE

openssl-list - Mostrar información sobre las funciones y los proveedores cargados.

SINOPSIS

openssl-list [-help] [-verbose] [-debug] [-nextkey] [-providers] [-engines] [-disabled] [-objects] [-options command] [-provider name] [-provider-path path] [-provparam [name:]key=value] [-propquery propq]

DESCRIPCIÓN

El comando openssl-list se utiliza para mostrar información sobre las funciones y los proveedores cargados en el sistema. Permite al usuario inspeccionar qué algoritmos criptográficos, proveedores y objetos están disponibles, así como su estado y configuración.

-help
Muestra un resumen de las opciones de uso.
-verbose
Activa el modo detallado, mostrando información adicional sobre las funciones y los proveedores.
-debug
Activa el modo de depuración, mostrando información detallada para la resolución de problemas.
-nextkey
Muestra una lista de todos los gestores de claves cargados, sus versiones y su estado.
-providers
Muestra una lista de todos los proveedores cargados con sus nombres, versión y estado.

En modo detallado, se mostrará adicionalmente la versión completa y todos los parámetros del proveedor.

-engines
Esta opción está obsoleta.

Muestra una lista de los motores cargados.

-disabled
Muestra una lista de las funciones deshabilitadas, aquellas que fueron compiladas fuera de la instalación.
-objects
Muestra una lista de los objetos integrados, es decir, OIDs con nombres. Se listan en el formato descrito en el "Módulo de Configuración de Objetos ASN1" en config(5).
-options comando
Muestra una lista de dos columnas de las opciones aceptadas por el comando especificado. La primera es el nombre de la opción, y la segunda es una indicación de un solo carácter del tipo de parámetro que acepta, si lo hay. Esta es una opción interna, utilizada para comprobar que la documentación está completa.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Consulte "Opciones del Proveedor" en openssl(1), provider(7) y property(7).

Visualización de nombres de algoritmos

Los nombres de los algoritmos se pueden mostrar de una de las dos maneras siguientes:

Implementaciones heredadas
Las implementaciones heredadas simplemente mostrarán el nombre principal del algoritmo en una línea propia, o en el formato "<foo bar>> para mostrar que "foo" es un alias para el nombre principal, "bar"
Implementaciones proporcionadas
Las implementaciones de un proveedor se muestran de esta manera si la implementación está etiquetada con un solo nombre: 
foo @ bar

o de esta manera si está etiquetada con varios nombres:

{ foo1, foo2 } @bar

En ambos casos, "bar" es el nombre del proveedor.

HISTORIAL

Las opciones -engines, -digest-commands y -cipher-commands quedaron obsoletas en OpenSSL 3.0.

La opción -skey-managers se añadió en OpenSSL 3.5.
