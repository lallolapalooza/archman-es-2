Paquete: oath-toolkit

oath_bin2hex(3) liboath oath_bin2hex(3)

NOMBRE

oath_bin2hex - función de API

SINOPSIS

#include <oath.h>

void oath_bin2hex(const char * binstr, size_t binlen, char * hexstr);

ARGUMENTOS

const char * binstr
datos binarios de entrada
size_t binlen
longitud de los datos binarios de entrada binstr
char * hexstr
cadena de salida con datos hexadecimales, debe tener espacio para 2*binlen+1.

DESCRIPCIÓN

Convierte datos binarios a una cadena terminada en NUL con datos hexadecimales. El hexstr de salida es asignado por el llamador y debe tener espacio para al menos 2*binlen+1, para dar cabida a los datos codificados y al byte NUL de terminación.
