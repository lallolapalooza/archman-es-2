OBJRES(1) Manual de Comandos Generales OBJRES(1)

NOMBRE

objres - compila datos binarios en un archivo objeto.

SINOPSIS

objres [OPCIONES] [SIMBOLO=]FICHERO ...

DESCRIPCIÓN

objres toma como entrada uno o más ficheros que contienen datos binarios, y crea un archivo objeto ELF que exporta el contenido de cada fichero de entrada como un objeto de tiempo de compilación de solo lectura. objres también produce un archivo de cabecera C que declara cada uno de los objetos exportados como un array de unsigned char.

Cada fichero de entrada puede ir precedido por el nombre del símbolo que se asignará a ese objeto binario. Si no se proporciona nombre de símbolo, objres lo derivará del nombre del fichero.

OPCIONES

-o, --output=NOMBRE_FICHERO
Establece el nombre del archivo objeto de destino a NOMBRE_FICHERO. Si se omite esta opción, el nombre de fichero predeterminado se derivará del nombre del símbolo exportado (o del primer símbolo, si hay más de uno).
-h, --header=NOMBRE_FICHERO
Establece el nombre del archivo de cabecera a NOMBRE_FICHERO. Si se omite esta opción, se elegirá un nombre de fichero predeterminado que coincida con el nombre del archivo objeto.
-m, --machine={32|64}
Establece que el archivo objeto de destino sea un objeto ELF de 32 bits o de 64 bits. El tipo predeterminado será el mismo que el del binario objres.
-R, --reference=OBJFILE
Examina el archivo objeto OBJFILE y copia los campos de su cabecera ELF al archivo creado. Por defecto, objres solo se dirigirá a plataformas x86; esta opción permite crear archivos objeto para otras plataformas.
-r, --read-only
Coloca los objetos binarios en memoria de solo lectura. Los objetos se declararán como arrays de unsigned char constantes.
--help
Muestra la ayuda y sale.
--version
Muestra la información de la versión y sale.
