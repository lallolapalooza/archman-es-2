NOMBRE

openssl-configutl - utilidad de ayuda para archivos de configuración de openssl

SINOPSIS

openssl configutl [-help] [-config archivo] [-out archivo] [-noheader]

DESCRIPCIÓN

Los archivos de configuración de openssl del mundo real con uso de la directiva .include son bastante complejos, y existe la necesidad de ver la configuración resultante a nivel de sistema.

Esta herramienta está diseñada para gestionar archivos de configuración de OpenSSL. Actualmente procesa un archivo de configuración con una estructura posiblemente compleja y vuelca un archivo de configuración resultante efectivo, a la salida estándar por defecto.

OPCIONES

-help
Imprime un mensaje de uso.
-config archivo
El archivo de configuración a tratar. Si se omite, se utiliza el compilado o el definido a través de la variable de entorno OPENSSL_CONF.
-out archivo
El archivo de salida a utilizar en lugar de la salida estándar.
-noheader
No imprimir información sobre el archivo de configuración original a procesar.

EJEMPLOS

Volcar el archivo de configuración my.conf procesando todas las directivas .include al archivo result.conf

openssl configutl -config my.conf -out result.conf

VER TAMBIÉN

config(5)

HISTORIA

El comando configutl se añadió en OpenSSL 3.6.
