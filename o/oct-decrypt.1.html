oct-decrypt(1) Manual de comandos generales oct-decrypt(1)

NOMBRE

oct-decrypt - Descifra datos usando una tarjeta

SINOPSIS

oct decrypt <-c|--card> [-p|--user-pin] [-o|--output] [-h|--help] [entrada]

DESCRIPCIÓN

Descifra datos usando una tarjeta

OPCIONES

-c, --card=identificador de tarjeta
Identificador de la tarjeta a usar
-p, --user-pin=archivo del PIN de usuario
Opcionalmente, obtener el PIN de usuario desde un archivo
-o, --output=salida
Archivo de salida (salida estándar si no se establece)
-h, --help
Imprimir ayuda
[entrada]
Archivo de entrada (entrada estándar si no se establece)
