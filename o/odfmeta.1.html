ODFMETA(1) Comandos de usuario ODFMETA(1)



NOMBRE
odfmeta - Listar o cambiar los metadatos de un archivo ODF



SINOPSIS

odfmeta [-l] [-v] [-V] [-c] [-d] [-x campo_metadatos...] [-X campo_metadatos...] [-a campo_metadatos...] [-A campo_metadatos...] [-I campo_metadatos...] [-o ruta] ruta



DESCRIPCIÓN

odfmeta es un programa que listará o cambiará los metadatos de un archivo OpenDocument. Esto es útil para sistemas de control de versiones. Puedes cambiar el título, las palabras clave, la descripción, etc.

“ruta” se asume que es un archivo OpenDocument de tipo texto, hoja de cálculo o presentación.



OPCIONES

-l

Listar (extraer) todos los campos de metadatos conocidos.

-v o -V

Imprimir el número de versión del formato del documento ODF. Si usa -V, imprimirá "version:" antes del número para compatibilidad con -X. El número de versión no se puede modificar.

-c

Hacer que los valores de los campos sean continuos normalizando los espacios en blanco. Puede ser conveniente al posprocesar con utilidades de texto estándar (orientadas a líneas).

-d

Actualizar la fecha de modificación a la fecha y hora actuales.

-x campo_metadatos

Extraer el contenido de este campo de metadatos del archivo. Los nombres de campo conocidos son: fecha-creacion, creador, fecha, descripcion, ciclos-edicion, duracion-edicion, generador, creador-inicial, palabra-clave, idioma, fecha-impresion, impreso-por, tema, titulo, definido-por-usuario. Todos los demás nombres se asumen definidos por el usuario.

-X campo_metadatos

Igual que -x, pero también preserva/incluye el nombre del campo.

-a campo_metadatos

Añadir un campo de metadatos personalizado a los metadatos; pero solo si un campo similar no existe todavía.

-A campo_metadatos

Añadir un campo de metadatos personalizado a los metadatos en cualquier caso.

-I campo_metadatos

Añadir un campo de metadatos personalizado a los metadatos y eliminar cualquier campo similar existente.

-o ruta

Nombre de archivo al que escribir el archivo ODT modificado. Si no se proporciona la opción -o, el archivo ODT se escribirá en la salida estándar.



EJEMPLOS

odfmeta -l archivo-odf.odt
odfmeta -I "titulo:El Pequeño Motor Que Pudo" -A tema:Yo-creo-que-puedo -o nuevofichero.odt fuente.odt



VER TAMBIÉN

formail(1), id3tag(1)



ERRORES

Todas las versiones conocidas de OpenOffice.org solo conservan cuatro elementos de <meta:user-defined>. Si añades más que esos, los perderás la próxima vez que guardes con OpenOffice.org. KOffice solo conserva un elemento de <meta:keyword>.
