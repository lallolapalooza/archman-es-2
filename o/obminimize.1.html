NOMBRE

obminimize — optimiza la geometría, minimiza la energía para una molécula

SINOPSIS

obminimize [OPCIONES] nombre_archivo

DESCRIPCIÓN

La herramienta obminimize se puede usar para minimizar la energía de moléculas dentro de archivos (multi-)moleculares (p. ej., MOL2, etc.)

OPCIONES

Si no se proporciona un nombre de archivo, obminimize mostrará todas las opciones, incluidos los campos de fuerza disponibles.

-n pasos
Especifica el número máximo de pasos (por defecto=2500)
-cg
Usa el algoritmo de gradientes conjugados (por defecto)
-sd
Usa el algoritmo de descenso de gradiente
-c criterio
Establece el criterio de convergencia (por defecto=1e-6)
-ff campo_fuerza
Selecciona el campo de fuerza

EJEMPLOS

Ver las opciones posibles, incluyendo los campos de fuerza disponibles:

obminimize

Minimiza la energía para la(s) molécula(s) en el archivo test.mol2:

obminimize test.mol2

Minimiza la energía para la(s) molécula(s) en el archivo test.mol2 usando el campo de fuerza Ghemical:

obminimize -ff Ghemical test.mol2

Minimiza la energía para la(s) molécula(s) en el archivo test.mol2 realizando como máximo 300 pasos de optimización geométrica

obminimize -n 300 test.mol2

Minimiza la energía para la(s) molécula(s) en el archivo test.mol2 usando el algoritmo de descenso de gradiente y un criterio de convergencia de 1e-5:

obminimize -sd -c 1e-5 test.mol2
