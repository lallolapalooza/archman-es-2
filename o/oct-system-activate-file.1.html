NOMBRE

oct system activate-file - Activar archivo (recuperar del estado de "tarjeta terminada")

SINOPSIS

oct system activate-file [-h|--help]

DESCRIPCIÓN

Activar archivo (recuperar del estado de "tarjeta terminada")

Si una tarjeta está en estado "Terminado", este comando la activa de nuevo. El comando solo se puede realizar si solo hay una tarjeta conectada al sistema y esa tarjeta está en estado terminado.

De lo contrario, se mostrará un mensaje de error.

OPCIONES

-h, --help
Imprimir ayuda (ver un resumen con '-h')
