OSTREE CONFIG(1) configuración de ostree OSTREE CONFIG(1)

NOMBRE

ostree-config - Cambiar la configuración

SINOPSIS

ostree config get {NOMBREGRUPO.NOMBRECLAVE}

ostree config get {--group=NOMBREGRUPO} {NOMBRECLAVE}

ostree config set {NOMBREGRUPO. NOMBRECLAVE} {VALOR}

ostree config set {--group= NOMBREGRUPO} {NOMBRECLAVE} {VALOR}

ostree config unset {NOMBREGRUPO. NOMBRECLAVE}

ostree config unset {--group= NOMBREGRUPO} {NOMBRECLAVE}

DESCRIPCIÓN

•ostree config get muestra el valor de NOMBRECLAVE en el grupo NOMBREGRUPO
•ostree config set establece el valor de NOMBRECLAVE en el grupo NOMBREGRUPO a VALOR.
•ostree config unset elimina la clave NOMBRECLAVE del grupo NOMBREGRUPO para que OSTree utilice el valor predeterminado para ella. No es un error si el NOMBREGRUPO o NOMBRECLAVE especificados no existen.

EJEMPLO

$ ostree config get core.mode

bare

$ ostree config set --group='remote "mi-remoto"' url http://example.com/repo

$ ostree config unset core.lock-timeout-secs

OSTree
