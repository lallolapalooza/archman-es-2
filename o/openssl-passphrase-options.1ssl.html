NOMBRE

openssl-passphrase-options - Opciones de frase de contraseña

SINOPSIS

openssl comando [ opciones ... ] [ parámetros ... ]

DESCRIPCIÓN

Varios comandos de OpenSSL aceptan argumentos de contraseña, típicamente usando -passin y -passout para contraseñas de entrada y salida respectivamente. Estos permiten obtener la contraseña de una variedad de fuentes. Ambas opciones toman un solo argumento cuyo formato se describe a continuación. Si no se proporciona un argumento de contraseña y se requiere una, se le pedirá al usuario que introduzca una: esta generalmente se leerá desde la terminal actual con el eco desactivado.

Tenga en cuenta que la codificación de caracteres puede ser relevante, consulte passphrase-encoding(7).

OPCIONES

Argumentos de opción de frase de contraseña

Los argumentos de frase de contraseña se pueden formatear de la siguiente manera.

pass:contraseña
La contraseña real es contraseña. Dado que la contraseña es visible para utilidades (como 'ps' en Unix) esta forma solo debe usarse donde la seguridad no sea importante.
env:var
Obtiene la contraseña de la variable de entorno var. Dado que el entorno de otros procesos es visible en ciertas plataformas (por ejemplo, ps en ciertos sistemas operativos Unix) esta opción debe usarse con precaución.
file:ruta
Lee la contraseña del archivo especificado ruta, que puede ser un archivo regular, un dispositivo o una tubería con nombre. Solo se lee la primera línea, hasta el carácter de nueva línea, del stream.

Si el mismo argumento ruta se proporciona a los argumentos -passin y -passout, la primera línea se usará para la contraseña de entrada y la siguiente línea se usará para la contraseña de salida.

fd:número
Lee la contraseña del descriptor de archivo número. Esto puede ser útil para enviar datos a través de una tubería, por ejemplo. El mismo manejo de líneas que se describe para file: se aplica a las contraseñas leídas desde descriptores de archivo.

fd: no es compatible con Windows.

stdin
Lee la contraseña de la entrada estándar. El mismo manejo de líneas que se describe para file: se aplica a las contraseñas leídas de la entrada estándar.
