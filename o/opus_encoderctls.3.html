Detailed Description

These are convenience macros for use with the opus_encode_ctl interface.

They are used to generate the appropriate series of arguments for that call, passing the correct type, size and so on as expected for each particular request.

Some usage examples:

int ret;
ret = opus_encoder_ctl(enc_ctx, OPUS_SET_BANDWIDTH(OPUS_AUTO));
if (ret != OPUS_OK) return ret;
opus_int32 rate;
opus_encoder_ctl(enc_ctx, OPUS_GET_BANDWIDTH(&rate));
opus_encoder_ctl(enc_ctx, OPUS_RESET_STATE);

#define OPUS_SET_COMPLEXITY(x)

Sets the encoder complexity. This controls the trade-off between encoding latency and compression efficiency. Higher complexity means more delay and better compression. This is a floating point value between 0 and 10, inclusive, where 10 represents the highest complexity.

#define OPUS_SET_EXPERT_FRAME_DURATION(x)

Configura el uso de tramas de duración variable por parte del codificador. Cuando la duración variable está activada, el codificador es libre de usar un tamaño de trama más corto que el solicitado en la llamada a opus_encode*(). Entonces, el usuario es responsable de verificar cuánta audio se codificó comprobando el byte de ToC del paquete codificado. La parte del audio que no se codificó debe reenviarse al codificador para la siguiente llamada. No utilice esta opción a menos que sepa realmente lo que está haciendo.

#define OPUS_SET_LSB_DEPTH(x)

Configura la profundidad de la señal que se está codificando. Esto es una pista que ayuda al codificador a identificar el silencio y el casi-silencio. Representa el número de bits significativos de intensidad lineal por debajo de los cuales la señal contiene ruido o cuantificación ignorables.

Por ejemplo, OPUS_SET_LSB_DEPTH(14) sería una configuración adecuada para entrada G.711 u-law. OPUS_SET_LSB_DEPTH(16) sería adecuada para entrada PCM lineal de 16 bits con opus_encode_float().

Al usar opus_encode() en lugar de opus_encode_float(), o cuando libopus se compila para punto fijo, el codificador utiliza el mínimo entre el valor establecido aquí y el valor 16.

#define OPUS_SET_MAX_BANDWIDTH(x)

Configura la banda de paso máxima que el codificador seleccionará automáticamente. Las aplicaciones normalmente deberían usar esto en lugar de OPUS_SET_BANDWIDTH (dejándolo en el valor por defecto, OPUS_AUTO). Esto permite a la aplicación establecer un límite superior basado en el tipo de entrada que está proporcionando, pero aún así da al codificador la libertad de reducir la banda de paso cuando la tasa de bits es demasiado baja, para una mejor calidad general.
