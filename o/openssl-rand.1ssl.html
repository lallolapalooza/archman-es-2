NOMBRE

openssl-rand - generar bytes pseudoaleatorios

SINOPSIS

openssl rand [-help] [-out archivo] [-base64] [-hex] [-engine id] [-rand archivos] [-writerand archivo] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq] num[K|M|G|T]

DESCRIPCIÓN

Este comando genera num bytes aleatorios usando un generador de números pseudoaleatorios criptográficamente seguro (CSPRNG). Se puede añadir un sufijo [K|M|G|T] al valor num para indicar que el valor solicitado se escalará como múltiplo de KiB/MiB/GiB/TiB respectivamente. Tenga en cuenta que los sufijos distinguen entre mayúsculas y minúsculas, y que los sufijos representan múltiplos binarios (K = 1024 bytes, M = 1024*1024 bytes, etc).

La cadena 'max' puede sustituir a un valor numérico en num, para solicitar el número máximo de bytes que el CSPRNG puede producir por instanciación. Actualmente, esto está restringido a 2^61 bytes según NIST SP 800-90C.

Los bytes aleatorios se generan utilizando la función RAND_bytes(3), que proporciona un nivel de seguridad de 256 bits, siempre que haya logrado sembrarse con éxito desde una fuente de entropía confiable del sistema operativo. De lo contrario, el comando fallará con un código de error distinto de cero. Para más detalles, consulte RAND_bytes(3), RAND(7) y EVP_RAND(7).

OPCIONES

-help
Imprime un mensaje de uso.
-out archivo
Escribe en archivo en lugar de la salida estándar.
-base64
Realiza la codificación base64 en la salida.
-hex
Muestra la salida como una cadena hexadecimal.
-engine id
Ver "Opciones de motor" en openssl(1). Esta opción está obsoleta.
-rand archivos, -writerand archivo
Ver "Opciones de estado aleatorio" en openssl(1) para detalles.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Ver "Opciones del proveedor" en openssl(1), provider(7) y property(7).

VER TAMBIÉN

openssl(1), RAND_bytes(3), RAND(7), EVP_RAND(7)

HISTORIAL

La opción -engine fue obsoleta en OpenSSL 3.0.
