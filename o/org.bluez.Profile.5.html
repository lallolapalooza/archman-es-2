Métodos

void Release() [noreply]

Este método se llama cuando bluetoothd(8) anula el registro del perfil.

Un perfil puede usarlo para realizar tareas de limpieza. No hay necesidad de anular el registro del perfil, porque cuando se llama a este método, ya ha sido anulado el registro.

void NewConnection(object device, fd, dict fd_properties)

Este método se llama cuando se ha establecido y autorizado una nueva conexión a nivel de servicio.

Posibles valores de fd_properties:

uint16 Versión [opcional]
Versión del perfil.
uint16 Características [opcional]
Características del perfil.

Errores posibles:

org.bluez.Error.Rejected
org.bluez.Error.Canceled
