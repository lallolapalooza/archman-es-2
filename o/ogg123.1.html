NOMBRE

ogg123 - reproduce archivos Ogg y FLAC

SINOPSIS

ogg123 [ -vqrzZVh ] [ -k segundos ] [ -x n-ésimo ] [ -y nveces ] [ -b tamaño_buffer ] [ -d controlador [ -o opción:valor ] [ -f nombre_archivo ] ] archivo ... | directorio ... | URL ...

DESCRIPCIÓN

ogg123 lee archivos de audio Ogg/Vorbis, Ogg/Speex, Ogg/Opus, Ogg/FLAC y FLAC nativos y los decodifica a los dispositivos especificados en la línea de comandos. Por defecto, ogg123 escribe en el dispositivo de sonido estándar, pero la salida se puede enviar a cualquier número de dispositivos. Los archivos se pueden leer desde el sistema de archivos o las URL se pueden transmitir a través de HTTP. Si se proporciona un directorio, se reproducirán todos los archivos que contenga o sus subdirectorios.

OPCIONES

--buffer-audio n
Utiliza un buffer de audio de salida de aproximadamente 'n' kilobytes.
-@ lista_reproduccion, --lista lista_reproduccion
Reproduce todos los archivos nombrados en el archivo 'lista_reproduccion'. La lista de reproducción debe tener un nombre de archivo, nombre de directorio o URL por línea. Se permiten líneas en blanco. Los directorios se tratarán de la misma manera que en la línea de comandos.
-b n, --buffer n
Utiliza un buffer de entrada de aproximadamente 'n' kilobytes. Opción solo para HTTP.
-p n, --prebuffer n
Prebufferiza el 'n' por ciento del buffer de entrada. La reproducción no comenzará hasta que este prebuffer esté completo. Opción solo para HTTP.
-d dispositivo, --dispositivo dispositivo
Especifica el dispositivo de salida. Consulte la sección DISPOSITIVOS para obtener una lista de dispositivos. Se puede especificar cualquier número de dispositivos.
-f nombre_archivo, --archivo nombre_archivo
Especifica el archivo de salida para un dispositivo de archivo especificado previamente con --dispositivo. El nombre de archivo "-" escribe en la salida estándar. Si el archivo ya existe, ogg123 lo sobrescribirá.
-h, --ayuda
Muestra la ayuda del comando.
-k n, --saltar n
Salta los primeros 'n' segundos. 'n' también puede estar en formato minutos:segundos u horas:minutos:segundos.
-K n, --fin n
Detiene la reproducción 'n' segundos desde el inicio de la transmisión. 'n' también puede tener el mismo formato que se usa en la opción --saltar.
-o opcion[:valor], --opcion-dispositivo opcion[:valor]
Establece la opción opcion a valor para el dispositivo anterior. Consulte DISPOSITIVOS para obtener una lista de opciones válidas para cada dispositivo.
-q, --silencioso
Modo silencioso. No se muestran mensajes.
-V, --version
Muestra información de la versión.
-v, --detallado
Aumenta el nivel de detalle.
-x n, --nth
Reproduce cada bloque decodificado 'n-ésimo'. Tiene el efecto de reproducir audio a una velocidad 'n' veces mayor que la normal.
-y n, --nveces
Repite cada bloque reproducido 'n' veces. Tiene el efecto de reproducir audio 'n' veces más lento que la velocidad normal. Puede usarse con -x para velocidades fraccionarias interesantes.
-r, --repetir
Repite la lista de reproducción indefinidamente.
-z, --aleatorio
Reproduce los archivos en orden pseudoaleatorio.
-Z, --aleatorio-infinito
Reproduce los archivos en orden pseudoaleatorio para siempre.

DISPOSITIVOS

ogg123 soporta una variedad de dispositivos de salida de audio a través de libao. Solo estarán disponibles aquellos dispositivos compatibles con la plataforma de destino. La opción -f solo se puede usar con dispositivos que escriben en archivos.

Opciones compatibles con todos los dispositivos:

depuracion
Activa la salida de depuración [si la hay] para un controlador elegido.
matriz:valor
Fuerza un orden específico de canales de salida para un dispositivo dado. valor es una lista separada por comas de nombres de canales estilo AO, por ejemplo, L,R,C,LFE,BL,BR,SL,SR.
detallado
Activa la salida detallada para un controlador elegido. La opción -v también establecerá la opción detallada del controlador.
silencioso
Fuerza al controlador elegido a estar completamente en silencio. Incluso los errores no producirán ninguna salida. -q también establecerá la opción silenciosa del controlador.
aixs
Controlador de salida en vivo de AIX. Opciones:
dev:valor
Establece el dispositivo de salida de AIX a valor
alsa
Controlador de salida en vivo de Advanced Linux Sound Architecture. Opciones:
tiempo_buffer:valor
Anula el tamaño del buffer de hardware predeterminado (en milisegundos).
dev:valor
Etiqueta del dispositivo ALSA a usar. Los ejemplos incluyen "hw:0" para la primera tarjeta de sonido y "hw:1" para la segunda. El controlador alsa normalmente elige automáticamente uno de "surround71", "surround51", "surround40" o "default" dependiendo del número de canales de salida. Para más información, consulte http://alsa.opensrc.org/ALSA+device+labels
tiempo_periodo:valor
Anula el tamaño del período de hardware predeterminado (en microsegundos).
tiempo_periodo:valor
Anula el tamaño del período de hardware predeterminado (en microsegundos).
usar_mmap:valor
valor se establece en "sí" o "no" para anular el valor predeterminado compilado para usar o no usar el acceso al dispositivo mmap. En el pasado, algunos controladores alsa defectuosos se comportaban mejor cuando no usaban acceso mmap, a costa de un ligero aumento en el uso de CPU.
arts
Controlador de salida en vivo del demonio de sonido aRts. Opciones:
multi:valor
valor se establece en "sí" o "no" para permitir la apertura del dispositivo de reproducción aRts para reproducción concurrente múltiple. Aunque el controlador funciona correctamente en modo múltiple, se sabe que ocasionalmente bloquea el propio servidor aRts. El comportamiento predeterminado es "no".
au
Controlador de salida de archivos de audio Sun. Escribe las muestras de audio en formato AU. El formato AU admite la escritura en archivos no buscables como la salida estándar. En tales circunstancias, la cabecera AU especificará el formato de muestra, pero no la longitud de la grabación.
esd
Salida en vivo del demonio de sonido Enlightened Sound Daemon. Opciones:
host:valor
valor especifica el nombre del host donde se está ejecutando esd. Esto puede incluir un número de puerto después de dos puntos, como "whizbang.com:555". (Predeterminado = localhost)
nombre_cliente:valor
Establece el nombre del cliente para el nuevo flujo de audio. Predeterminado "libao client".
irix
Controlador de audio de salida en vivo de IRIX.
macosx
Controlador de salida en vivo de MacOS X 'AUHAL'. Este controlador soporta MacOS X 10.5 y posteriores (10.4 y anteriores usan una interfaz anterior e incompatible).

DEVICES

The following sound drivers are available:

alsa
Advanced Linux Sound Architecture driver. Options:
buffer_time:value
Establece el tamaño del búfer de hardware al equivalente de value milisegundos.
nas
Controlador de salida en vivo Network Audio Server. Opciones:
buf_size:value
Establece el tamaño del búfer de audio en el servidor en bytes.
host:value
Establece la ubicación del servidor NAS; Ver nas(1) para el formato.
null
Controlador nulo. Todos los datos de audio se descartan. (¡Nota: los datos de audio no se escriben en /dev/null!) Podrías usar este controlador para probar la velocidad de decodificación bruta sin sobrecarga de salida.
oss
Controlador Open Sound System para Linux y FreeBSD, versiones 2, 3 y 4. Opciones:
dsp:value
Dispositivo DSP para la tarjeta de sonido. Por defecto es /dev/dsp.
pulse
Controlador de sonido de salida de audio en vivo Pulseaudio. Opciones:
server:value
Especifica la ubicación del servidor Pulseaudio remoto o alternativo.
sink:value
Especifica un sumidero Pulseaudio no predeterminado para el flujo de audio.
raw
Salida de archivo raw. Escribe muestras de audio brutas a un archivo. Opciones:
byteorder:value
Elige el orden de bytes big-endian ("big"), little-endian ("little"), o nativo ("native"). El valor predeterminado es el orden nativo.
roar
Controlador de salida en vivo RoarAudio Daemon. Opciones:
server:value, host:value
Especifica la ubicación del servidor RoarAudio remoto a utilizar.
id:value, dev:value
Especifica un mezclador no predeterminado dentro de un servidor RoarAudio para el flujo de audio.
role:value
Establece la opción de rol para el flujo de audio.
client_name:value
Establece el nombre del cliente para el nuevo flujo de audio. El valor predeterminado es "libao client".
sndio
Controlador de salida en vivo OpenBSD SNDIO. Opciones:
dev:value
Especifica el dispositivo de audio a utilizar para la reproducción.
sun
Controlador de salida en vivo Sun Audio para NetBSD, OpenBSD y Solaris. Opciones:
dev:value
Dispositivo de audio para la tarjeta de sonido. Por defecto es /dev/audio.
wav
Salida de archivo WAV. Escribe los datos de sonido a disco en formato sin comprimir. Si se reproducen varios archivos, todos se concatenarán en el mismo archivo WAV. Los archivos WAV no se pueden escribir en archivos no buscables, como la salida estándar. Usa el formato AU en su lugar.
wmm
Controlador de salida en vivo Windows MultiMedia para Win98 y posteriores. Opciones:
dev:value
Selecciona el dispositivo de audio a utilizar para la reproducción por nombre de dispositivo.
id:value
Selecciona el dispositivo de audio a utilizar para la reproducción por ID de dispositivo (número de tarjeta).

EJEMPLOS

La línea de comandos de ogg123 es bastante flexible, quizás confusamente tanto. Aquí hay algunos ejemplos de líneas de comandos y una explicación de lo que hacen.

Reproducir en la tarjeta de sonido predeterminada:

ogg123 test.ogg

Reproducir todos los archivos del directorio ~/music y sus subdirectorios.

ogg123 ~/music

Reproducir un archivo usando el controlador OSS:

ogg123 -d oss test.ogg

Pasar la opción "dsp" al controlador OSS:

ogg123 -d oss -o dsp:/dev/mydsp

Usar el controlador ESD

ogg123 -d esd test.ogg

Usar el controlador WAV con el archivo de salida, "test.wav":

ogg123 -d wav -f test.wav test.ogg

Escuchar un archivo mientras lo escribe en un archivo WAV:

ogg123 -d oss -d wav -f test.wav test.ogg

Tenga en cuenta que las opciones se aplican al dispositivo declarado a la izquierda:

ogg123 -d oss -o dsp:/dev/mydsp -d raw -f test2.raw -o byteorder:big test.ogg

Realizar una prueba de estrés en su disco duro:

ogg123 -d oss -d wav -f 1.wav -d wav -f 2.wav -d wav -f 3.wav -d wav -f 4.wav -d wav -f 5.wav test.ogg

Crear un efecto de eco con esd y un ordenador lento:

ogg123 -d esd -d esd test.ogg

INTERRUPCIÓN

Puede abortar ogg123 en cualquier momento presionando Ctrl-C. Si está reproduciendo varios archivos, esto detendrá el archivo actual y comenzará a reproducir el siguiente. Si desea abortar la reproducción inmediatamente en lugar de saltar al siguiente archivo, presione Ctrl-C dentro del primer segundo de reproducción de un nuevo archivo.

Tenga en cuenta que el resultado de presionar Ctrl-C podría no ser audible de inmediato, debido al almacenamiento en búfer de datos de audio en el dispositivo de audio. Este retraso depende del sistema, pero generalmente no es más de uno o dos segundos.

ARCHIVOS

/etc/libao.conf
Puede usarse para establecer el dispositivo de salida predeterminado para todos los programas libao.
~/.libao
Archivo de configuración por usuario para anular la configuración del dispositivo de salida a nivel de sistema.

ERRORES

Los archivos WAV canalizados pueden causar un comportamiento extraño en otros programas. Esto se debe a que los archivos WAV almacenan la longitud de los datos en la cabecera. Sin embargo, el controlador de salida no conoce la longitud cuando escribe la cabecera, y no hay ningún valor que signifique "longitud desconocida". Utilice el controlador de salida raw o au si necesita usar ogg123 en un pipe.
