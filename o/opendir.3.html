opendir(3) Manual de funciones de biblioteca opendir(3)

NOMBRE

opendir, fdopendir - abrir un directorio

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/types.h>
#include <dirent.h>
DIR *opendir(const char *name);
DIR *fdopendir(int fd);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

fdopendir():

    Desde glibc 2.10:
        _POSIX_C_SOURCE >= 200809L
    Antes de glibc 2.10:
        _GNU_SOURCE

DESCRIPCIÓN

La función opendir() abre un flujo de directorio correspondiente al directorio name y devuelve un puntero al flujo de directorio. El flujo se posiciona en la primera entrada del directorio.

La función fdopendir() es como opendir(), pero devuelve un flujo de directorio para el directorio al que se refiere el descriptor de archivo abierto fd. Después de una llamada exitosa a fdopendir(), fd es utilizado internamente por la implementación y no debe ser utilizado de otra manera por la aplicación.

VALOR DE RETORNO

Las funciones opendir() y fdopendir() devuelven un puntero al flujo de directorio. En caso de error, se devuelve NULL y errno se establece para indicar el error.

ERRORES

EACCES
Permiso denegado.
EBADF
fd no es un descriptor de archivo válido abierto para lectura.
EMFILE
Se ha alcanzado el límite por proceso del número de descriptores de archivo abiertos.
ENAMETOOLONG
name era demasiado largo.
ENFILE
Se ha alcanzado el límite del sistema para el número total de archivos abiertos.
ENOENT
El directorio no existe, o name es una cadena vacía.
ENOMEM
Memoria insuficiente para completar la operación.
ENOTDIR
name no es un directorio.

ESTÁNDARES

POSIX.1-2008.

ESTÁNDARES

opendir()
SVr4, 4.3BSD, POSIX.1-2001.
fdopendir()
POSIX.1-2008. glibc 2.4.

NOTAS

Las entradas de nombres de archivo se pueden leer de un flujo de directorio utilizando readdir(3).

El descriptor de archivo subyacente del flujo de directorio se puede obtener utilizando dirfd(3).

La función opendir() establece la bandera de cierre al ejecutar para el descriptor de archivo subyacente del DIR *. La función fdopendir() deja sin cambios la configuración de la bandera de cierre al ejecutar para el descriptor de archivo, fd. POSIX.1-200x deja sin especificar si una llamada exitosa a fdopendir() establecerá la bandera de cierre al ejecutar para el descriptor de archivo, fd.

VER TAMBIÉN
