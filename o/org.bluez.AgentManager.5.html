void RegistrarAgente(object agente, string capacidad)

Registra un agente de emparejamiento.

La ruta del objeto define la ruta del agente que se llamará cuando se necesite entrada del usuario y debe implementar la interfaz org.bluez.Agent(5).

Cada aplicación puede registrar su propio agente y para todas las acciones iniciadas por esa aplicación se utiliza su agente.

No es obligatorio que una aplicación registre un agente. Si una aplicación decide no registrar un agente, se utiliza el agente predeterminado. En la mayoría de los casos, esta es una buena idea. Solo las aplicaciones como un asistente de emparejamiento deben registrar su propio agente.

Una aplicación solo puede registrar un agente. No se admiten varios agentes por aplicación.

Valores de capacidad posibles:

""
Como último recurso, se usa "KeyboardDisplay".
"DisplayOnly"
"DisplayYesNo"
"KeyboardOnly"
"NoInputNoOutput"
"KeyboardDisplay"

Errores posibles:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.YaExiste

void AnularRegistroAgente(object agente)

Anula el registro de un agente que se ha registrado previamente usando RegistrarAgente. El parámetro de ruta del objeto debe coincidir con el mismo valor que se utilizó en el registro.

Errores posibles:

org.bluez.Error.NoExiste

void SolicitarAgentePredeterminado(object agente)

Solicita que el agente de la aplicación se convierta en el agente predeterminado. La aplicación debe registrar un agente.

Puede requerirse un permiso especial para convertirse en el agente predeterminado.

Errores posibles:

org.bluez.Error.NoExiste
