NOMBRE

oath_init - función de la API

SINOPSIS

#include <oath.h>

int oath_init( void);

ARGUMENTOS

void

DESCRIPCIÓN

Esta función inicializa la biblioteca OATH. Cada usuario de esta biblioteca necesita llamar a esta función antes de usar otras funciones. Debe llamar a oath_done() cuando ya no necesite la biblioteca OATH.

Tenga en cuenta que esta función también puede inicializar Libgcrypt, si la biblioteca OATH se compila con soporte para libgcrypt y libgcrypt no se ha inicializado antes. Por lo tanto, si desea inicializar libgcrypt manualmente, debe hacerlo antes de llamar a esta función. Esto es útil en casos en los que desea deshabilitar los bloqueos internos de libgcrypt, etc.

RETORNA

En caso de éxito, se devuelve OATH_OK (cero), de lo contrario, se devuelve un código de error.
