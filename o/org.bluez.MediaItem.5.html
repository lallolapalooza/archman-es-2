org.bluez.MediaItem(5)

Paquete: bluez-utils

Licencias: GPL-2.0-only

org.bluez.MediaItem(5) Administración del Sistema Linux org.bluez.MediaItem(5)

Nombre

org.bluez.MediaItem - Documentación de la API D-Bus MediaItem de BlueZ

Interfaz

Servicio
nombre único (Rol de destino) org.bluez (Rol de controlador)
Interfaz
org.bluez.MediaItem1
Ruta del objeto
definible libremente (Rol de destino) [prefijo variable]/{hci0,hci1,...}/dev_{BDRADDR}/player#/item# (Rol de controlador)

Métodos

void Play()

Reproducir elemento

Posibles Errores:

org.bluez.Error.NotSupported
org.bluez.Error.Failed

void AddtoNowPlaying()

Añadir elemento a la lista de reproducción actual

Posibles Errores:

org.bluez.Error.NotSupported
org.bluez.Error.Failed

Propiedades

object Player [sólo lectura]

Ruta del objeto del reproductor al que pertenece el elemento.

string Name [sólo lectura]

Nombre mostrable del elemento.

string Type [sólo lectura]

Tipo de elemento.

Posibles valores:

"video"
"audio"
"folder"

string FolderType [sólo lectura, opcional]

Tipo de carpeta.

Disponible si la propiedad Type es "Folder".

Posibles valores:

"mixed"
"titles"
"albums"
"artists"

boolean Playable [sólo lectura, opcional]

Indica si el elemento se puede reproducir.

Disponible si la propiedad Type es "folder".

dict Metadata [sólo lectura]

Metadatos del elemento.

Posibles valores:

string Title
Nombre del título del elemento.

Disponible si la propiedad Type es "audio" o "video".

string Artist
Nombre del artista del elemento.

Disponible si la propiedad Type es "audio" o "video".

string Album
Nombre del álbum del elemento.

Disponible si la propiedad Type es "audio" o "video".

string Genre
Nombre del género del elemento.

Disponible si la propiedad Type es "audio" o "video".

uint32 NumberOfTracks
Número total de pistas del álbum del elemento.

Disponible si la propiedad Type es "audio" o "video".

uint32 Number
Número del álbum del elemento.

Disponible si la propiedad Type es "audio" o "video".

uint32 Duration
Duración del elemento en milisegundos.

Disponible si la propiedad Type es "audio" o "video".
