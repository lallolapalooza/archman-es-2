OSTREE ADMIN UPGRADE(1) ostree admin upgrade OSTREE ADMIN UPGRADE(1)

NOMBRE

ostree-admin-upgrade - Construye un nuevo árbol a partir del origen actual y lo implementa, si ha cambiado

SINOPSIS

ostree admin upgrade [OPCIONES...]

DESCRIPCIÓN

Descarga la última versión del ref actual desde el servidor de compilación y lo implementa, si ha cambiado. Reinicia la máquina para que los cambios surtan efecto. Estas fases se pueden dividir mediante --pull-only y --deploy-only.

OPCIONES

--os="STATEROOT"

Utiliza una raíz del sistema operativo diferente a la actual.

--pull-only

Solo realiza una extracción en el repositorio; no crea una implementación. Por lo tanto, esta opción se puede usar de forma segura en un trabajo programado en segundo plano con la garantía de no cambiar el estado del sistema.

--deploy-only

Crea una nueva implementación a partir del último commit en el ref de origen rastreado. Esta opción está pensada para ser utilizada por un sistema programado que detectó cambios mediante --pull-only y está listo para implementarlos.

--stage

Realiza la finalización de la implementación al apagar el sistema. Recomendado, y es probable que se convierta en el valor predeterminado en el futuro.

--reboot,-r

Reinicia después de una actualización exitosa.

--kexec,-k

Carga la nueva implementación en kexec después de una actualización exitosa.

--allow-downgrade

Permite la implementación de árboles cronológicamente más antiguos.

--override-commit="CHECKSUM"

Implementa CHECKSUM en lugar del último árbol.

EJEMPLO

$ ostree admin upgrade

        No hay actualización disponible.
