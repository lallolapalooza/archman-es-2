OCTAVE-CLI(1) Manual de comandos generales OCTAVE-CLI(1)

NOMBRE

octave-cli - Un lenguaje interactivo de alto nivel para computaciones numéricas.

SINOPSIS

octave-cli [opciones]... [archivo]

DESCRIPCIÓN

Octave es un lenguaje de alto nivel, principalmente destinado a computaciones numéricas. Proporciona una interfaz de línea de comandos conveniente para resolver problemas lineales y no lineales numéricamente. octave-cli ha sido compilado sin soporte de GUI (Qt), lo que lo hace más pequeño que el ejecutable octave por defecto, pero también lo limita a proporcionar solo la interfaz de línea de comandos (CLI).

OPCIONES

El conjunto completo de opciones de línea de comandos para octave-cli está disponible ejecutando el siguiente comando desde la terminal.

    octave-cli --help

DOCUMENTACIÓN

La documentación principal de Octave está escrita en Texinfo, el sistema de documentación de GNU, que permite utilizar los mismos archivos fuente para producir versiones en línea e impresas del manual.

Puede leer la copia en línea de la documentación de Octave emitiendo el siguiente comando desde dentro de Octave.

    octave:1> doc
Los archivos Info también se pueden leer con un programa independiente como info o xinfo. Las versiones HTML, Postscript o PDF de la documentación también están instaladas en muchos sistemas.

ERRORES

El proyecto Octave mantiene un rastreador de errores en https://bugs.octave.org. Antes de enviar un nuevo elemento, lea las instrucciones en https://www.octave.org/bugs.html sobre cómo enviar un informe útil.

ARCHIVOS

Al iniciar, Octave busca cuatro archivos de inicialización. Cada archivo puede contener cualquier número de comandos válidos de Octave.

octave-home/share/octave/site/m/startup/octaverc
Archivo de inicialización a nivel de sitio que cambia las opciones para todos los usuarios. octave-home es el directorio donde se instaló Octave, como por ejemplo /usr/local.
octave-home/share/octave/version/m/startup/octaverc
Archivo de inicialización a nivel de sitio para Octave versión version.
~/.octaverc
Archivo de inicialización personal del usuario.
.octaverc
Archivo de inicialización específico del proyecto ubicado en el directorio actual.
