NOMBRE

opam admin-add-constraint - Añade restricciones de versión en todas las dependencias hacia un paquete dado

SINOPSIS

opam admin add-constraint [--force] [--packages=PAQUETES] [OPCIÓN]… PAQUETE

DESCRIPCIÓN

Este comando busca en todas las dependencias hacia un paquete dado y les añade una restricción de versión. Es particularmente útil para añadir límites superiores a dependencias existentes cuando se añade una nueva versión principal incompatible de una librería a un repositorio. La nueva restricción de versión se fusiona con la existente y se simplifica si es posible (ej. >=3 & >5 se convierte en >5).

ARGUMENTOS

PAQUETE (requerido)
Un nombre de paquete con una restricción de versión, ej. nombre>=versión. Si no se especifica ninguna restricción de versión, el comando simplemente simplificará las restricciones de versión existentes en las dependencias al paquete nombrado.

OPCIONES

--force
Forzar la actualización de restricciones incluso si la restricción resultante es insatisfactoria (ej. al añadir >3 a la restricción <2). Por defecto, en este caso, se mostrará una advertencia y se mantendrá la restricción existente sin cambios.
-p PAQUETES, --packages=PAQUETES
Solo añadir restricciones para los paquetes dados

OPCIONES COMUNES

Estas opciones son comunes a todos los comandos.

--best-effort
No fallar si no se pueden instalar todos los paquetes solicitados: intentar instalar tantos como sea posible. Nótese que no todos los resolutores externos pueden soportar esta opción (versiones recientes de aspcud o mccs deberían). Esto es equivalente a establecer la variable de entorno $OPAMBESTEFFORT.
--cli=MAYOR.MENOR (ausente=2.4)
Usar la sintaxis y semántica de la interfaz de línea de comandos de MAYOR.MENOR. Previsto para cualquier uso persistente de opam (scripts, posts de blog, etc.), cualquier versión de opam de la misma serie MAYOR se comportará como para la versión MENOR especificada. La bandera no estaba disponible en opam 2.0, así que para seleccionar la CLI 2.0, establece la variable de entorno $OPAMCLI a 2.0 en lugar de usar este parámetro.
--color=CUÁNDO
Colorear la salida. CUÁNDO debe ser uno de siempre, nunca o auto.
--confirm-level=NIVEL
Nivel de confirmación, NIVEL debe ser uno de preguntar, no, sí o sí-inseguro. Puede especificarse más de una vez. Si también se dan --yes o --no, se tiene en cuenta el valor del último --confirm-level. Esto es equivalente a establecer $OPAMCONFIRMLEVEL.
--criteria=CRITERIOS
Especificar preferencias del usuario para la resolución de dependencias para esta ejecución. Sobrescribe $OPAMCRITERIA, $OPAMFIXUPCRITERIA y $OPAMUPGRADECRITERIA. Para detalles sobre el lenguaje soportado y los resolutores externos disponibles, véase http://opam.ocaml.org/doc/External_solvers.html. Una guía general para usar preferencias del resolutor se encuentra en http://www.dicosmo.org/Articles/usercriteria.pdf.
--cudf=NOMBREARCHIVO
Opción de depuración: Guarda las solicitudes CUDF enviadas al resolutor en NOMBREARCHIVO-<n>.cudf donde <n> es la n-ésima llamada al resolutor durante la ejecución de opam.
--debug
Mostrar mensajes de depuración en stderr. Esto es equivalente a establecer $OPAMDEBUG a "true".
--debug-level=NIVEL
Similar a --debug, pero permite especificar el nivel de depuración (--debug lo establece a 1). Equivalente a establecer $OPAMDEBUG a un entero positivo.
--git-version
Mostrar la versión git de opam, si está establecida (es decir, si estás usando una versión de desarrollo), y salir.
--help[=FMT] (predeterminado=auto)
Mostrar esta ayuda en el formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la env var TERM sea dumb o indefinida.
--ignore-pin-depends
Ignorar pines adicionales requeridos por paquetes que se fijan, ya sea manualmente a través de opam pin o a través de opam install DIR. Esto es equivalente a establecer IGNOREPINDEPENDS=true.
--json=NOMBREARCHIVO
Guardar los resultados de la ejecución de opam en un archivo legible por ordenador. Si el nombre del archivo contiene el carácter `%', se reemplazará por un índice que no sobrescribe un archivo existente. Similar a establecer la variable $OPAMJSON.
--no
Responder no a todas las preguntas de sí/no de opam sin preguntar. Ver también --confirm-level. Esto es equivalente a establecer $OPAMNO a "true".
--no-aspcud
Eliminado en 2.1.
--no-auto-upgrade
Al configurar o actualizar un repositorio escrito para una versión anterior de opam (1.2), opam lo convierte internamente al formato actual. Esto deshabilita este comportamiento. Nótese que los repositorios deberían definir su versión de formato en un archivo 'repo' en su raíz, o se asumirá que están en el formato anterior. En cualquier caso, es preferible actualizar los repositorios manualmente usando opam admin upgrade [--mirror URL] cuando sea posible.
-q, --quiet
Deshabilita --verbose.
--root=RAÍZ
Usar RAÍZ como la ruta raíz actual. Esto es equivalente a establecer $OPAMROOT a RAÍZ.
--safe, --readonly
Asegurarse de que nada se actualizará o reescribirá automáticamente. Útil para llamar desde scripts de finalización, por ejemplo. Fallará siempre que se necesite tal operación; también evita esperar bloqueos, omite preguntas interactivas y sobrescribe la variable $OPAMDEBUG. Esto es equivalente a establecer la variable de entorno $OPAMSAFE.
--solver=CMD
Especificar el resolutor CUDF a usar para resolver problemas de instalación de paquetes. Esto es un resolutor predefinido (esta versión de opam soporta builtin-mccs+lp(), builtin-mccs+glpk, builtin-dummy-z3-solver, builtin-0install, aspcud, mccs, aspcud-old, packup), o un comando personalizado que debería contener las variables %{input}%, %{output}%, %{criteria}%, y opcionalmente %{timeout}%. Esto es equivalente a establecer $OPAMEXTERNALSOLVER.
--strict
Fallar siempre que se encuentre un error en la definición de un paquete o en un archivo de configuración. Por defecto, continúa silenciosamente si es posible.
--switch=SWITCH
Usar SWITCH como el cambio de compilador actual. Esto es equivalente a establecer $OPAMSWITCH a SWITCH.
--use-internal-solver
Deshabilitar cualquier resolutor externo y usar el interno (esto requiere que opam se haya compilado con un resolutor interno). Esto es equivalente a establecer $OPAMNOASPCUD o $OPAMUSEINTERNALSOLVER.
-v, --verbose
Ser más verboso. Un -v muestra todos los comandos de paquete, repetir para mostrar también los comandos llamados internamente (ej. tar, curl, patch etc.) Repetir n veces es equivalente a establecer $OPAMVERBOSE a "n".
--version
Mostrar información de versión.
-w, --working-dir
Siempre que se actualicen paquetes vinculados a un directorio local controlado por versión, actualizar al estado de trabajo actual de su fuente en lugar del último estado confirmado, o la referencia a la que apuntan. Como el directorio de origen se copia tal cual, si no está limpio puede resultar en un fallo de compilación de opam. Esto solo afecta a los paquetes listados explícitamente en la línea de comandos. También se puede establecer con $OPAMWORKINGDIR.
-y, --yes
Responder sí a todas las preguntas de sí/no de opam sin preguntar. Ver también --confirm-level. Esto es equivalente a establecer $OPAMYES a "true".

NAME

opam-admin(1)

administer opam switches and repositories

SYNOPSIS

opam admin [COMMAND] [OPTIONS]

DESCRIPTION

This command provides administrative facilities for opam switches and repositories.

ARGUMENTS

COMMAND
The admin command to execute. See below for available commands.

OPTIONS

See opam(1) for common options.

COMMON OPTIONS

These options are available for most commands.

--help
Show help text for the command or subcommand.
-v, --verbose
Increase verbosity.
-q, --quiet
Decrease verbosity.
--log-level=LEVEL
Set the log level to LEVEL (e.g. debug, info, warn, error).
--log-file=FILE
Log to FILE instead of stderr.
--no-install
Do not install any missing dependencies.
--no-depexts
Do not install any system dependencies.
--color=WHEN
Enable or disable colored output. WHEN can be always, never, or auto.
--dot-prefix=DIR
Set the prefix for dot files to DIR.
--root=DIR
Set the root directory for opam configurations and states.
--lib-kind=KIND
Set the library kind to KIND. Can be native, bytecode, or all.
--sync-depth=N
Set the maximum synchronization depth to N.
--recursive
Enable recursive operations.

ENVIRONMENT

See opam(1) for environment variables.

CLI VERSION

This documentation is for opam-admin version 2.4.1.

EXIT STATUS

0
on success.
1
Invalid arguments or general error.
2
Error during package processing (e.g. invalid context (file not following the expected format)).
5
Not found. You requested something (package, version, repository, etc.) that couldn't be found.
10
Aborted. The operation required confirmation, which wasn't given.
15
Could not acquire the locks required for the operation.
20
There is no solution to the user request. This can be caused by asking to install two incompatible packages, for example.
30
Error in package definition, or other metadata files. Using --strict raises this error more often.
31
Package script error. Some package operations were unsuccessful. This may be an error in the packages or an incompatibility with your system. This can be a partial error.
40
Sync error. Could not fetch some remotes from the network. This can be a partial error.
50
Configuration error. Opam or system configuration doesn't allow operation, and needs fixing.
60
Solver failure. The solver failed to return a sound answer. It can be due to a broken external solver, or an error in solver configuration.
99
Internal error. Something went wrong, likely due to a bug in opam itself.
130
User interrupt. SIGINT was received, generally due to the user pressing Ctrl-C.
0
on success.
123
on indiscriminate errors reported on standard error.
124
on command line parsing errors.
125
on unexpected internal errors (bugs).
