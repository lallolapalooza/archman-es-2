NOMBRE

ostree-admin-unlock - Prepara el despliegue actual para hotfix o desarrollo

SINOPSIS

ostree admin unlock [OPCIONES...]

DESCRIPCIÓN

Elimina el montaje bind de solo lectura en /usr y lo reemplaza con un sistema de archivos de superposición (overlay) escribible. Esta invocación predeterminada de "unlock" está destinada a fines de desarrollo/pruebas. Todos los cambios en la superposición se pierden al reiniciar. Sin embargo, este comando también admite "hotfixes", ver más abajo.

OPCIONES

--hotfix

Si se proporciona esta opción, el despliegue actual se clonará como un objetivo de reversión. Esta opción está destinada a cosas como actualizaciones de seguridad de emergencia para componentes del espacio de usuario como sshd. La semántica aquí difiere del modo de desbloqueo de "desarrollo" predeterminado en que los reinicios conservarán cualquier cambio (que es lo que probablemente quieras para hotfixes de seguridad).

--transient

Si se proporciona esta opción, el sistema de archivos de superposición se montará en modo de solo lectura. Todavía puede ser afectado al remontarlo como lectura/escritura en un nuevo espacio de nombres de montaje. Por ejemplo: 
ostree admin unlock --transient
unshare -m -- sh -c 'mount --options-source=disable -o remount,rw /usr && touch /usr/myfile'
