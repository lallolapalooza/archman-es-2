OGONKIFY(1) Manual de Comandos Generales OGONKIFY(1)

NOMBRE

ogonkify - soporte internacional para PostScript

SINOPSIS

ogonkify [-p procset] [-e codificación] [-r Viejo=Nuevo] [-a] [-c] [-h] [-t] [-A] [-C] [-H] [-T] [-AT] [-CT] [-ATH] [-CTH] [-E] [-N] [-M] [-mp] [-SO] [-AX] [-F] [-RS] [--] archivo ...

DESCRIPCIÓN

ogonkify realiza varias modificaciones en archivos PostScript relacionadas con la impresión en diferentes idiomas. Su uso principal es filtrar la salida de Netscape, Mosaic y otros programas para poder imprimir en idiomas que no utilizan la codificación estándar de Europa Occidental (ISO 8859-1).

USO RESUMIDO

Las instrucciones de instalación se proporcionan en el archivo INSTALL. Asumiendo que la instalación se ha completado correctamente, guarde la salida PostScript de Netscape o Mosaic en un archivo, por ejemplo output.ps. Luego imprímalo usando

% ogonkify -AT -N output.ps | lpr
en el caso de Netscape, o
% ogonkify -AT -M output.ps | lpr
en el caso de Mosaic.

Es posible que desee cambiar la opción -AT por -CT para usar una fuente Courier de alta calidad de IBM (a costa de una impresión más lenta).

Una forma alternativa de imprimir desde Netscape es establecer el comando de impresión en el cuadro de diálogo de impresión a:

ogonkify -AT -N | lpr
Para más detalles, consulte la sección USO más abajo.

OPCIONES

-p
Incluye el procset especificado en el archivo de salida.
-e
Establece la codificación de la salida. Por defecto es L2 (ISO 8859-2, también conocido como ISO Latin-2). Otros valores posibles son L1 (ISO 8859-1, también conocido como ISO Latin-1), L3 (ISO 8859-3, también conocido como ISO Latin-3), L4 (ISO 8859-4, también conocido como ISO Latin-4), L5 (ISO 8859-9, también conocido como ISO Latin-5), L6 (ISO 8859-10, también conocido como ISO Latin-6), L7 (ISO 8859-13, también conocido como ISO Latin-7), L9 (ISO 8859-15, también conocido como ISO Latin-9), CP1250 (Página de códigos 1250 de Microsoft, también conocida como CeP), ibmpc (Codificación original de IBM-PC), mac (Codificación de Apple Macintosh) y hp (Codificación Roman de HP).
-r
Usa la fuente Nuevo en lugar de Viejo. Conducirá a una salida fea o ilegible cuando las métricas no coincidan.
-a
Realiza las reasignaciones de fuentes correctas para usar Courier-Ogonki en lugar de Courier (la a significa Adobe Courier). Esto evita la descarga de fuentes a la impresora.
-c
Realiza las reasignaciones de fuentes correctas para usar IBM Courier en lugar de Adobe Courier.
-t
Realiza las reasignaciones de fuentes correctas para usar Times-Roman-Ogonki en lugar de Times-Roman.
-h
Realiza las reasignaciones de fuentes correctas para usar Helvetica-Ogonki en lugar de Helvetica.
-A
Igual que -a pero también descarga las fuentes Courier-Ogonki.
-C
Igual que -c, pero también descarga las fuentes IBM Courier.
-H
Igual que -h, pero también descarga las fuentes Helvetica-xxx-Ogonki.
-T
Igual que -t, pero también descarga las fuentes Times-xxx-Ogonki.
-CT
Equivalente a -C -T.
-CTH
Equivalente a -C -T -H.
-E
Agrega el signo de moneda Euro a todas las fuentes estándar (usar con -e L9).
-N
Realiza el procesamiento de Netscape.
-M
Realiza el procesamiento de Mosaic.
-mp
Realiza el procesamiento de mp. No funcionará con la opción -A (use -C en su lugar).
-SO
Realiza el procesamiento de StarOffice.
-AX
Realiza el procesamiento de ApplixWare.
-F
Realiza el procesamiento de XFig.
-RS
Recodifica las fuentes estándar. Es probable que funcione con aplicaciones que dejan las fuentes en AdobeStandardEncoding, típicamente aplicaciones que ni siquiera admiten la impresión de caracteres.
--
Fin de las opciones.

USO

Supongamos que desea imprimir una página WWW codificada en ISO Latin-2. Netscape insiste obstinadamente en imprimirla como ISO Latin-1. Usando el comando Archivo->Imprimir, haga que Netscape envíe la salida a un archivo, por ejemplo, alamakota.ps.

Como ogonkify está configurado para ISO Latin-2 por defecto, pasarle el PostScript generado por Netscape corregirá la codificación de las fuentes. Es suficiente hacer:

% ogonkify -N <alamakota.ps | lpr

Sin embargo, la mayoría de las impresoras no tienen fuentes con los caracteres necesarios instalados; se descargarán y usarán fuentes sintetizadas en lugar de Courier y Times-Roman con -AT, y se usará una fuente Courier muy buena de IBM con: -CT. Por lo tanto, el comando típicamente será:

% ogonkify -N -AT <alamakota.ps | lpr

o eventualmente

% ogonkify -N -CT <alamakota.ps | lpr

El uso típico con otros programas es:

% ogonkify -M -AT <alamakota.ps | lpr
% ogonkify -mp -AT <alamakota.ps | lpr
% ogonkify -SO -AT <alamakota.ps | lpr
% ogonkify -AX -ATH <alamakota.ps | lpr
% ogonkify -XF -ATH <alamakota.ps | lpr

BUGS

Los caracteres con un 'ogonek' deberían construirse de forma diferente (por ejemplo, el 'ogonek' utilizado con una 'a' debería tener una forma diferente al que se usa con una 'e'.)

Sería mejor parchear los programas de los que tenemos el código fuente que procesar a posteriori el PostScript producido.

El programa está escrito en Perl.

NOTAS

Para ver la salida PostScript con Ghostscript, es posible que necesite ejecutar gs con la opción -dNOPLATFONTS, y ghostview con la opción -arguments -dNOPLATFONTS.

Netscape, IBM, Adobe, PostScript, StarOffice, ApplixWare y posiblemente otros son marcas registradas.

a2ps(1)

NAME

a2ps - Anything to PostScript translator

SYNOPSIS

a2ps [-a] [-b] [-c] [-d] [-e] [-f font] [-l lines] [-n copies] [-o file] [-p printer] [-r] [-s] [-t columns] [-u num] [-F file] [-R file] [-L file] [-P printer] [-M mode] [-B] [-C] [-D] [-E] [-H] [-I] [-O] [-S] [-T] [-X] [-Y] [-Z] [file ...]

DESCRIPTION

a2ps is a filter that converts various types of files into PostScript format. It is particularly good at formatting source code for printing, but it can also handle plain text, troff, and other formats.

Key features include:

  • Syntax highlighting for many programming languages.

  • Automatic detection of file types.

  • Customizable headers and footers, including page numbers and filenames.

  • Support for different fonts and font sizes.

  • Collation and multiple copies.

  • Control over page layout, including columns and margins.

  • Handling of compressed files (e.g., gzip, bzip2).

SUMMARY USAGE

The most common way to use a2ps is:

a2ps [options] [file ...]

If no files are specified, a2ps reads from standard input.

OPTIONS

This is a partial list of the most common options:

-a
Output in ASCII format (no PostScript).
-b
Output in binary format (no PostScript).
-c
Use compressed PostScript.
-d
Do not include date and time in the header.
-e
Escape special characters.
-f font
Specify the font to use (e.g., -f Courier).
-l lines
Set the number of lines per page.
-n copies
Print the specified number of copies.
-o file
Write the output to the specified file instead of standard output.
-p printer
Send the output directly to the specified printer.
-r
Reverse the order of pages.
-s
Use symbolic names for characters.
-t columns
Print in the specified number of columns.
-u num
Set the unique identifier for the document.
-F file
Use the specified file for font definitions.
-R file
Use the specified file for runtime configuration.
-L file
Specify a directory to search for configuration files.
-P printer
Specify the default printer to use.
-M mode
Set the output mode (e.g., -M ps for PostScript).
-B
Print a two-sided document.
-C
Center the text on the page.
-D
Disable syntax highlighting.
-E
Enable error reporting.
-H
Print headers on every page.
-I
Include line numbers.
-O
Output in original format (no conversion).
-S
Use special characters for syntax highlighting.
-T
Print in landscape mode.
-X
Use extended character set.
-Y
Use Y-coordinates for positioning.
-Z
Disable page breaks.

USAGE

To convert a file named myfile.c to PostScript and print it:

a2ps myfile.c | lpr

To convert a file and save the PostScript to output.ps:

a2ps myfile.c -o output.ps

To convert multiple files, adding a header with the filename:

a2ps file1.txt file2.c -H

BUGS

The manual page for a2ps is extensive and covers many options. Refer to the full documentation for details on specific behaviors and potential issues.

NOTES

a2ps is a powerful tool for generating PostScript output from various file formats. Its ability to handle source code with syntax highlighting makes it invaluable for programmers.
