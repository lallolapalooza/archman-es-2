NOMBRE

ossl_store-file - El cargador del esquema 'file' de store

SINOPSIS

#include <openssl/store.h>

DESCRIPCIÓN

El soporte para el esquema 'file' está integrado en "libcrypto". Dado que los archivos vienen en todo tipo de formatos y tipos de contenido, el esquema 'file' tiene su propia capa de funcionalidad llamada "manejadores de archivos", que se utilizan para intentar decodificar diversos tipos de contenidos de archivos.

En caso de que un archivo tenga formato PEM, cada manejador de archivos llamado recibe el nombre PEM (todo lo que sigue a cualquier '"-----BEGIN "') así como posibles encabezados PEM, junto con el cuerpo PEM decodificado. Dado que los archivos con formato PEM pueden contener más de un objeto, los manejadores de archivos se llaman para cada uno de dichos objetos.

Si no se determina que el archivo tenga formato PEM, el contenido se carga en forma cruda en su totalidad y se pasa a los manejadores de archivos disponibles tal cual, sin nombre PEM ni encabezados.

Se espera que cada manejador de archivos maneje contenido PEM y no PEM según corresponda. Algunos pueden rechazar contenido no PEM por razones de determinismo (por ejemplo, hay claves en circulación que se representan como una CADENA DE OCTETOS ASN.1. En forma cruda, no es fácil distinguir esas de cualquier otro dato que venga como una CADENA DE OCTETOS ASN.1, por lo que tales claves serían aceptadas naturalmente solo como archivos PEM).

NOTAS

Cuando sea necesario, el cargador del esquema 'file' requerirá una frase de contraseña utilizando el UI_METHOD que se pasó a través de OSSL_STORE_open(). Se espera que esta frase de contraseña esté codificada en UTF-8, cualquier otra cosa dará un resultado indefinido. Se espera que los archivos hechos accesibles a través de este cargador cumplan estándar con respecto a la codificación de la frase de contraseña. Los archivos que no lo hagan deben regenerarse con una frase de contraseña codificada correctamente. Consulte passphrase-encoding(7) para obtener más información.

VER TAMBIÉN

ossl_store(7), passphrase-encoding(7)
