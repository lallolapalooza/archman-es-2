NOMBRE

opendkim-testkey - Prueba de instalación del filtro DKIM

SINOPSIS

opendkim-testkey [-d dominio] [-s selector] [-k ruta_clave] [-v] [-x archivo_config]

DESCRIPCIÓN

opendkim-testkey verifica la configuración de las claves de firma y verificación (privada y pública) para su uso con opendkim(8).

El programa de prueba leerá un nombre de dominio y un selector de la línea de comandos, archivo de configuración o una tabla de claves, luego consultará y analizará las claves DKIM resultantes, informando cualquier error encontrado.

Si también se proporciona una ruta de clave, el programa de prueba leerá la clave privada con ese nombre e intentará confirmar que la clave privada especificada por ruta_clave (o en la tabla de claves) y la clave pública DKIM recuperada coinciden.

OPCIONES

-d dominio
Nombra el dominio en el que se realizará la firma. Más específicamente, nombra el dominio en el que se encontrará la clave pública que coincide con la clave privada proporcionada. Este parámetro debe proporcionarse explícitamente, o en el archivo de configuración, o a través de una Tabla de Claves (consulte opendkim.conf(5) para obtener detalles).
-k ruta_clave
Especifica la ruta al archivo de clave privada que debe usarse para esta prueba. Este parámetro es opcional.
-s selector
Nombra el selector dentro del dominio especificado cuya clave pública debe recuperarse y probarse, comparándola con la clave privada si se proporciona. Este parámetro debe proporcionarse explícitamente, o en el archivo de configuración, o a través de una Tabla de Claves (consulte opendkim.conf(5) para obtener detalles).
-v
Aumenta la cantidad de salida (verborrea) del programa. Puede especificarse varias veces para una mayor salida.
-x archivo_config
Nombra un archivo de configuración para analizar. Consulte la página del manual opendkim.conf(5) para obtener detalles. Los únicos valores utilizados son Domain, Selector, KeyFile, KeyTable, TrustAnchorFile y ResolverConfig. El valor predeterminado es /etc/opendkim/opendkim.conf.

NOTAS

El programa de prueba también se quejará si el archivo de clave privada es legible por alguien que no sea el usuario que ejecuta el programa.

VERSIÓN
