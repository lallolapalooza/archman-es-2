NOMBRE

ocamldebug - el depurador de OCaml a nivel de código fuente con reproducción.

SINOPSIS

ocamldebug [ opciones ] programa [ argumentos ]

DESCRIPCIÓN

ocamldebug es el depurador de OCaml a nivel de código fuente con reproducción.

Antes de poder utilizar el depurador, el programa debe ser compilado y enlazado con la opción -g: todos los archivos .cmo y .cma que formen parte del programa deben haber sido creados con ocamlc -g, y deben ser enlazados juntos con ocamlc -g.

La compilación con -g no penaliza el tiempo de ejecución de los programas: los archivos objeto y los archivos ejecutables de bytecode son más grandes y tardan más en producirse, pero los archivos ejecutables se ejecutan a la misma velocidad que si se hubieran compilado sin -g.

OPCIONES

A continuación se incluye un resumen de las opciones. Para una descripción completa, consulte la documentación html del paquete ocaml-doc.

-c número
Establece el número máximo de puntos de control simultáneamente activos a número.
-cd dir
Ejecuta el programa depurador desde el directorio de trabajo dir, en lugar del directorio de trabajo actual. (Véase también el comando cd.)
-emacs
Indica al depurador que se está ejecutando bajo Emacs. (Véase El manual del usuario de OCaml para obtener información sobre cómo ejecutar el depurador bajo Emacs.) Implica -machine-readable.
-I directorio
Añade directorio a la lista de directorios en los que se buscan archivos fuente y archivos compilados. (Véase también el comando directory.)
-machine-readable
Imprime información en un formato más adecuado para máquinas en lugar de operadores humanos, cuando sea aplicable. Por ejemplo, al describir una ubicación en un programa, como al imprimir un rastreo inverso, imprime el contador de programa y el desplazamiento de caracteres en un archivo en lugar del nombre del archivo, el número de línea y el desplazamiento de caracteres en esa línea.
-s socket
Utiliza socket para comunicarse con el programa depurado. Consulte la descripción del comando set socket en El manual del usuario de OCaml para conocer el formato de socket.
-version
Imprime la cadena de versión y sale.
-vnum
Imprime el número de versión corto y sale.
-help o --help
Muestra un breve resumen de uso y sale.

ARCHIVO DE INICIALIZACIÓN

Cuando se invoca ocamldebug(1), leerá comandos de un archivo de inicialización antes de ceder el control al usuario. El archivo predeterminado es .ocamldebug en el directorio actual si existe, de lo contrario .ocamldebug en el directorio principal del usuario.

Tenga en cuenta que también puede utilizar el comando source archivo para leer comandos de un archivo.
