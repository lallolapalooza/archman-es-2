NOMBRE

ocamllex - Generador de lexers de OCaml

SINOPSIS

ocamllex [ -o archivo-salida ] [ -ml ] archivo.mll

DESCRIPCIÓN

El comando ocamllex(1) genera lexers de OCaml a partir de un conjunto de expresiones regulares con acciones semánticas asociadas, al estilo de lex(1).

Ejecutar ocamllex(1) sobre el archivo de entrada lexer.mll produce código OCaml para un analizador léxico en el archivo lexer.ml.

Este archivo define una función de análisis léxico por cada punto de entrada en la definición del lexer. Estas funciones tienen los mismos nombres que los puntos de entrada. Las funciones de análisis léxico toman como argumento un buffer de lexer y devuelven el atributo semántico del punto de entrada correspondiente.

Los buffers de lexer son un tipo de dato abstracto implementado en el módulo de biblioteca estándar Lexing. Las funciones Lexing.from_channel, Lexing.from_string y Lexing.from_function crean buffers de lexer que leen desde un canal de entrada, una cadena de caracteres o cualquier función de lectura, respectivamente.

Cuando se usa en conjunción con un parser generado por ocamlyacc(1), las acciones semánticas calculan un valor que pertenece al tipo token definido por el módulo de parsing generado.

OPCIONES

El comando ocamllex(1) reconoce las siguientes opciones:

-ml
Produce código que no utiliza el intérprete de autómatas incorporado de OCaml. En su lugar, el autómata se codifica mediante funciones de OCaml. Esta opción es principalmente útil para depurar ocamllex(1); no se recomienda su uso para lexers de producción.
-o archivo-salida
Especifica el nombre del archivo de salida producido por ocamllex(1). El valor por defecto es el nombre del archivo de entrada, con su extensión reemplazada por .ml.
-q
Modo silencioso. ocamllex(1) normalmente genera mensajes informativos en la salida estándar. Estos se suprimen si se utiliza la opción -q.
o -version
Imprime la cadena de versión y sale.
-vnum
Imprime el número de versión corto y sale.
-help o --help
Muestra un resumen de uso corto y sale.

VER TAMBIÉN
