NOMBRE

ostree-admin-pin - Conservar explícitamente un despliegue en un índice dado

SINOPSIS

ostree admin pin {ÍNDICE}

DESCRIPCIÓN

Asegura que el despliegue en ÍNDICE no se recopilará por defecto. Esto se denomina "fijación". Si se proporciona la opción -u, se deshace una operación de fijación. El ÍNDICE puede ser >= 0 o una de las cadenas booted, pending o rollback.

OPCIONES

--unpin,-u

Deshace una operación de fijación.
