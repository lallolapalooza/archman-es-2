NOMBRE

openssl/core_dispatch.h - Números de dispatch y tipos de función de OpenSSL para proveedores

SINOPSIS

#include <openssl/core_dispatch.h>

DESCRIPCIÓN

El archivo de cabecera <openssl/core_dispatch.h> define todos los números de operación, números de dispatch y tipos de función de interfaz de proveedor disponibles actualmente.

Los números de operación y dispatch se representan con macros, que siguen el siguiente formato:

números de operación
Estas macros tienen el formato "OSSL_OP_nombre_operacion".
números de dispatch
Estas macros tienen el formato "OSSL_FUNC_nombre_operacion_nombre_funcion", donde "nombre_operacion" es el mismo que en la macro para la operación a la que pertenece esta función.

Con cada número de dispatch, hay un tipo de función asociado.

Para más información, por favor consulte provider(7)

VER TAMBIÉN

provider(7)

HISTORIA

Los tipos y macros descritos aquí se añadieron en OpenSSL 3.0.
