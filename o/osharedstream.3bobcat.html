FBB::OSharedStream(3bobcat) std::ostream en memoria compartida FBB::OSharedStream(3bobcat)

NOMBRE

FBB::OSharedStream - operaciones de std::ostream en memoria compartida

SINOPSIS

#include <bobcat/osharedstream>
Opción de enlace: -lpthread -lbobcat

DESCRIPCIÓN

Esta clase ofrece las características de la clase std::ostream, operando en memoria compartida.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

FBB::OSharedBuf (herencia privada),
std::ostream,
FBB::SharedEnum__ (cf. sharedmemory(3bobcat) para una descripción de esta última clase base).

ENUMERACIÓN SIZEUNIT

La enum SizeUnit define las siguientes constantes simbólicas:

kB
kB, que representa 1024 (2**10) bytes de memoria;
MB
MB, que representa 1048576 (2**20 bytes de memoria;
GB
GB, que representa 1073741824 (2**30) bytes de memoria )

CONSTRUCTORES

o
OSharedStream():
El constructor por defecto define un objeto OSharedStream de tipo "stub" que no se puede usar inmediatamente para acceder a la memoria compartida. Para usarlo, primero se debe llamar a su miembro open.
o
OSharedStream(size_t maxSize, SizeUnit sizeUnit, std::ios::openmode openMode = std::ios::out, size_t access = 0600):
Este constructor crea un std::ostream que se interconecta con un segmento de memoria compartida que tiene una capacidad de al menos maxSize * sizeUnit bytes. Por defecto, el segmento de memoria compartida se abre para escritura. Los derechos de acceso de la memoria compartida se definen mediante el parámetro access, utilizando la forma bien conocida (chmod(1)) para definir los derechos de acceso para el propietario, el grupo y los demás, usando dígitos octales. Si la construcción tiene éxito, la memoria compartida está lista para su uso. Si la construcción falla, se lanza una FBB::Exception.
o
OSharedBuf(int id, std::ios::openmode openMode = std::ios::out | std::ios::in):
Este constructor crea un std::istream que se conecta a un segmento de memoria compartida con el ID id. Si la construcción tiene éxito, la memoria compartida está lista para su uso. Si la construcción falla (por ejemplo, no existe ningún segmento de memoria compartida con el ID id), se lanza una FBB::Exception.
Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::istream y std::ostream y los valores enum kB, MB y GB definidos por FBB::OSharedEnum__ están disponibles.
a
FBB::SharedCondition attachSharedCondition(std::ios::off_type offset, std::ios::seekdir origin):
Devuelve un objeto FBB::SharedCondition(3), que se interconecta con una variable de condición compartida ubicada en el offset offset (relativo a origin) en el objeto SharedMemory con el que se interconecta el objeto OSharedStream. Este miembro no altera el valor devuelto por el miembro tellp del stream.
Se lanza una FBB::Exception si no se pudo construir el objeto FBB::SharedCondition.
c
FBB::SharedCondition createSharedCondition():
Devuelve un objeto FBB::SharedCondition(3), que se interconecta con una variable de condición compartida recién creada que se crea en el offset actual del objeto SharedMemory con el que se interconecta el objeto OSharedStream (o en el primer offset del siguiente bloque de datos de memoria compartida, cf. sharedcondition(3bobcat)). Crear un objeto SharedCondition no altera el valor devuelto por el miembro tellp del stream.
Se lanza una FBB::Exception si no se pudo construir el objeto FBB::SharedCondition.
i
int id() const:
Se devuelve el ID del segmento de memoria compartida.
k
void kill():
Sin bloquear la memoria compartida primero, toda la memoria compartida se devuelve al sistema operativo. El objeto FBB::OSharedStream queda inutilizable después de regresar de kill. Otros procesos que estaban utilizando la memoria compartida pueden seguir haciéndolo.
m
void memInfo(std::ostream &out, char const *end = "\n"):
La información sobre el objeto OSharedMemory se inserta en el objeto ostream proporcionado. Se muestran los IDs de los segmentos de memoria compartida, sus tamaños, el número máximo de segmentos de memoria compartida, el número de bytes que se pueden leer de la memoria compartida, y su capacidad real de almacenamiento, etc. Después de la información sobre la memoria compartida, se inserta end en out.
o
void open(size_t maxSize, SizeUnit sizeUnit, std::ios::openmode openMode = std::ios::out, size_t access = 0600):
Este miembro crea un segmento de memoria compartida con una capacidad de al menos maxSize * sizeUnit bytes y conecta el segmento de memoria compartida al FBB::OSharedStream. No existe ni se requiere un miembro close correspondiente. Por defecto, el segmento de memoria compartida se abre para lectura. A diferencia de los modos de apertura utilizados para streams de archivos, crear un stream de memoria compartida con los modos de apertura ios::in está bien. En este caso, se crea el segmento de memoria compartida y, una vez que se ha escrito información en la memoria compartida por otro proceso, se puede leer. Los derechos de acceso de la memoria compartida se definen mediante el parámetro access, utilizando la forma bien conocida (chmod(1)) para definir los derechos de acceso para el propietario, el grupo y los demás, usando dígitos octales. Si la apertura tiene éxito, la memoria compartida está lista para su uso. Si la apertura falla, se lanza una FBB::Exception.
o
void open(int id, std::ios::openmode openMode = std::ios::in | std::ios::out):
Este miembro conecta el objeto FBB::OSharedStream a un segmento de memoria compartida con el ID id. No existe ni se requiere un miembro close correspondiente. Si la apertura tiene éxito, la memoria compartida está lista para su uso. Si la apertura falla (por ejemplo, no existe ningún segmento de memoria compartida con el ID id), se lanza una FBB::Exception.
r
void remove():
Primero se bloquea la memoria compartida. Luego, toda la memoria compartida se devuelve al sistema operativo. El objeto FBB::OSharedStream queda inutilizable después de regresar de remove. Otros procesos que estaban utilizando la memoria compartida pueden seguir haciéndolo.
t
bool truncate(std::streamsize offset):
Si offset no excede el valor devuelto por seekp(0, std::ios::end), este último valor se cambia a offset y se devuelve true. De lo contrario, se devuelve false y el valor devuelto por seekp no se altera. Si el valor devuelto por tellp excedía offset, el valor devuelto por tellp también se reduce a offset.

ERRORES

Tenga en cuenta que, por defecto, las excepciones lanzadas desde dentro de un objeto std::stream son capturadas por el objeto stream, estableciendo su flag ios::failbit. Para permitir que las excepciones salgan de un objeto stream, se puede llamar a su miembro exceptions, por ejemplo, usando:

    myStream.exceptions(ios::failbit | ios::badbit | ios::eofbit);
