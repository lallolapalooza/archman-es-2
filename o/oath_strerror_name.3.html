oath_strerror_name(3)

Paquete: oath-toolkit

Licencias: GPL-3.0-or-later

oath_strerror_name(3) liboath oath_strerror_name(3)

NOMBRE

oath_strerror_name - función de la API

SINOPSIS

#include <oath.h>

const char * oath_strerror_name(int err);

ARGUMENTOS

int err
código de error de liboath

DESCRIPCIÓN

Convierte el código de retorno a una cadena legible por humanos que representa el propio símbolo del código de error. Por ejemplo, oath_strerror_name(OATH_OK) devuelve la cadena "OATH_OK".

Esta cadena se puede utilizar para mostrar un mensaje de diagnóstico al usuario.

Esta función es una de las pocas en la biblioteca que se puede usar sin una llamada exitosa a oath_init().

VALOR DE RETORNO

Devuelve un puntero a una cadena asignada estáticamente que contiene una versión en cadena del código de error err, o NULL si el código de error no se conoce.
