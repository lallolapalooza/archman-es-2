OPTIUPS(8) Manual de NUT OPTIUPS(8)

NOMBRE

optiups - Controlador para UPS Opti-UPS (Viewsonic) y equipos Zinto D (ONLINE-USV)

SINOPSIS

optiups -h

optiups -a NOMBRE_UPS [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del hardware del controlador optiups. Para obtener información sobre el controlador principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

optiups se escribió originalmente para un PowerES 280es en nut-0.45. Se revisó para nut-2.0.1 y se probó con un PowerES 420E. Se espera que funcione con al menos los modelos PowerES, PowerPS y PowerVS.

Este controlador también soporta un Zinto D de ONLINE USV-Systeme AG debido a sus comandos muy similares, pero se desconoce si también funciona con otros UPS de ellos.

Este controlador no funcionará con el cable serie estándar de PowerES. Deberá construir su propio cable de tres conductores:

UPS 6 -> PC 3
UPS 9 -> PC 2
UPS 4 -> PC 5

El cable para Online-USV utiliza el pin UPS 7 (no UPS 4) → PC 5.

ARGUMENTOS ADICIONALES

Este controlador admite la siguiente configuración opcional en el archivo ups.conf(5):

status_only

Solo consulta información crítica de estado. Sin esto, optiups (y todos los controladores de NUT) consultan todo tipo de información del UPS con bastante frecuencia. Probablemente no sea tan frecuente como para causar problemas, por lo que esta opción probablemente no sea muy útil, a menos que tenga una conexión serie inestable o una máquina muy cargada.

nowarn_noimp

No imprime advertencias cuando el UPS informa que una variable no está implementada o no se puede consultar. Sin la opción, recibirá un mensaje enviado a los registros de su sistema cada vez que NUT consulte el UPS. Si especifica nowarn_noimp, este mensaje solo se registrará una vez.

fake_lowbatt

Esto fuerza que el indicador de batería baja sea verdadero. Sin él, si desea probar su UPS, tendrá que desconectarlo y esperar hasta que la batería descienda a un nivel de voltaje bajo/crítico antes de que NUT responda y apague su sistema. Con esta opción, NUT debería apagar el sistema poco después de desconectarlo. Cuando termine de probar, debería eliminar esta opción.

Para pruebas básicas de configuración de apagado, se prefiere el comando upsmon -c fsd.

powerup

El Zinto D de ONLINE-USV no se puede identificar cuando está en modo de espera. Establezca esta opción para permitir que el controlador encienda su UPS Zinto. ¡Esto también encenderá su equipo conectado al UPS!

ERRORES

En el 420E, ups.serial y ups.temperature son características no soportadas. Esto no es un error en NUT ni en el controlador NUT, es solo la forma en que funcionan las cosas con este UPS.
