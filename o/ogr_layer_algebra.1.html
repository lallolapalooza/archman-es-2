OGR_LAYER_ALGEBRA(1) GDAL OGR_LAYER_ALGEBRA(1)

NOMBRE

ogr_layer_algebra - Realiza varias operaciones algebraicas de capas vectoriales

Añadido en la versión 3.6.

SINOPSIS

ogr_layer_algebra [--help] [--help-general]
                    Union|Intersection|SymDifference|Identity|Update|Clip|Erase
                    -input_ds <ruta> [-input_lyr <nombre>]
                    -method_ds <ruta> [-method_lyr <nombre>]
                    -output_ds <ruta> [-output_lyr <nombre>] [-overwrite]
                    [-opt <NOMBRE>=<VALOR>]...
                    [-f <nombre_formato>] [-dsco <NOMBRE>=<VALOR>]... [-lco <NOMBRE>=<VALOR>]...
                    [-input_fields {NONE|ALL|<fld1>,<fl2>,...<fldN>}] [-method_fields {NONE|ALL|<fld1>,<fl2>,...<fldN>}]
                    [-nlt <tipo_geom>] [-a_srs <def_srs>]

DESCRIPCIÓN

ogr_layer_algebra proporciona una utilidad de línea de comandos para realizar varias operaciones algebraicas de capas vectoriales. La utilidad toma una fuente de entrada vectorial y una fuente de método y genera la salida de la operación en el archivo de salida especificado.

NOTA:

ogr_layer_algebra es una utilidad de Python y solo está disponible si las vinculaciones de Python de GDAL están disponibles.
--help
Muestra este mensaje de ayuda y sale
--help-general
Proporciona un breve mensaje de uso para las opciones genéricas de la línea de comandos de GDAL y sale.
<modo>
Donde <modo> es uno de los siete modos disponibles:
•
Union
Una unión es un conjunto de entidades que representan áreas que están en cualquiera de las capas operandos.
•
Intersection
Una intersección es un conjunto de entidades que representan las áreas comunes de dos capas.
•
SymDifference
Una diferencia simétrica es un conjunto de entidades que representan áreas que están en capas operandos pero que no se intersectan.
•
Identity
El método de identidad identifica entidades en la capa de entrada con entidades en la capa de método, posiblemente dividiendo las entidades en varias entidades. Por defecto, la capa resultante tiene atributos de ambas capas operandos.
•
Update
El método de actualización crea una capa que agrega entidades en la capa de entrada desde la capa de método, posiblemente cortando entidades en la capa de entrada. Por defecto, la capa resultante tiene atributos solo de la capa de entrada.
•
Clip
El método de recorte crea una capa que tiene entidades de la capa de entrada recortadas a las áreas de las entidades en la capa de método. Por defecto, la capa resultante tiene atributos de la capa de entrada.
•
Erase
El método de borrado crea una capa que tiene entidades de la capa de entrada cuyas áreas son borradas por las entidades en la capa de método. Por defecto, la capa resultante tiene atributos de la capa de entrada.
-input_ds <ruta>
Ruta del conjunto de datos de entrada para la operación que se va a realizar. Para operaciones que involucran dos conjuntos de datos, este es uno de los conjuntos de datos.
-input_lyr <nombre>
Nombre de la capa de input_ds para la cual se deben realizar las operaciones (Opcional)
-method_ds <ruta>
Ruta del conjunto de datos de método para la operación que se va a realizar. Este es normalmente el conjunto de datos condicional proporcionado a la operación (ej: clip, erase, update). Este es el segundo conjunto de datos en la operación (ej: Union, Intersection, SymDifference).
-method_lyr <nombre>
Nombre de la capa de method_ds para la cual se deben realizar las operaciones (Opcional)
-output_ds <ruta>
Ruta del conjunto de datos de salida para escribir el resultado de las operaciones realizadas por ogr_layer_algebra.
-output_lyr_name <nombre>
Nombre de la capa de output_lyr_name donde se debe escribir el vector de salida. (Opcional)
-overwrite
Indica si el output_ds debe ser sobrescrito con el resultado generado por ogr_layer_algebra.
-opt <NOMBRE>=<VALOR>
Atributos sobre los cuales se debe ejecutar la operación en input_ds y method_ds.
-f <nombre_formato>
Selecciona el formato de salida. Si no se especifica, el formato se infiere de la extensión (anteriormente era ESRI Shapefile). Usa el nombre corto del formato.
-dsco <NOMBRE>=<VALOR>
Opción de creación de conjunto de datos (específica del formato).
-lco <NOMBRE>=<VALOR>
Opción de creación de capa (específica del formato).
-input_fields {NONE|ALL|<fld1>,<fl2>,...<fldN>}
Lista separada por comas de los campos de la capa de entrada a copiar a la capa de salida, si son elegibles según la operación.
-method_fields {NONE|ALL|<fld1>,<fl2>,...<fldN>}
Lista separada por comas de los campos de la capa de método a copiar a la capa de salida, si son elegibles según la operación.
-nlt <tipo_geom>
Define el tipo de geometría para la capa creada. Uno de NONE, GEOMETRY, POINT, LINESTRING, POLYGON, GEOMETRYCOLLECTION, MULTIPOINT, MULTIPOLYGON, GEOMETRY25D, POINT25D, LINESTRING25D, POLYGON25D, GEOMETRYCOLLECTION25D, MULTIPOINT25D, MULTIPOLYGON25D.
-a_srs <def_srs>
Asigna un SRS de salida, pero sin reproyectar.

Los sistemas de referencia de coordenadas que se pueden pasar son cualquiera soportado por la llamada OGRSpatialReference.SetFromUserInput(), que incluye CRS Proyectados, Geográficos o Compuestos EPSG (es decir, EPSG:4296), una definición de CRS en texto conocido (WKT), declaraciones PROJ.4, o el nombre de un archivo .prj que contiene una definición de CRS WKT.

ogr_layer_algebra(1)

NOMBRE

ogr_layer_algebra - La utilidad de línea de comandos para la álgebra de capas de OGR.

SINOPSIS

ogr_layer_algebra [-ro] [-so] [-where<condition>] [-select<field_list>] [-field_as_id<field_name>] [-progress] <input_datasource> <input_layer_name> <output_layer_name> [<output_datasource>]

DESCRIPCIÓN

La utilidad ogr_layer_algebra puede ser usada para calcular algebraicamente un nuevo conjunto de atributos para una capa de salida a partir de uno o más conjuntos de atributos de la capa de entrada.

Actualmente está diseñado para ser usado con capas de entrada con un solo tipo de geometría (por ejemplo, puntos, líneas, polígonos) pero se puede usar para calcular atributos para una capa de salida que tiene una combinación de tipos de geometría si la lógica de cálculo lo permite.

Los cálculos de atributos se especifican en la cadena de entrada de la capa de salida. La sintaxis es similar a la del lenguaje de sentencia SQL.

Los argumentos de línea de comandos son los siguientes:

-ro
Abre la fuente de datos de entrada en modo de solo lectura.
-so
Abre la fuente de datos de salida en modo de solo lectura (para modificar la capa existente).
-where <condition>
Permite filtrar las entidades de la capa de entrada basándose en una condición.
-select <field_list>
Permite seleccionar un subconjunto de atributos de la capa de entrada.
-field_as_id <field_name>
Usa el valor del atributo especificado como ID para las entidades de la capa de salida.
-progress
Muestra la barra de progreso de la operación.
<input_datasource>
La fuente de datos de entrada. Puede ser un nombre de archivo o un nombre de conexión. Si no se especifica, la entrada se leerá de la entrada estándar.
<input_layer_name>
El nombre de la capa de entrada dentro de la fuente de datos de entrada.
<output_layer_name>
El nombre de la capa de salida. Si no existe, se creará.
<output_datasource>
La fuente de datos de salida. Si no se especifica, la salida se escribirá en la salida estándar.

Ejemplo:

ogr_layer_algebra -where "road_class='motorway'" roads.shp motorways_output.shp
ogr_layer_algebra -select "name,length" zones.shp results.csv
ogr_layer_algebra -field_as_id "id" -where "status='active'" devices.shp active_devices.shp
