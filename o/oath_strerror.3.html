oath_strerror(3)

Paquete: oath-toolkit

Licencias: GPL-3.0-or-later

oath_strerror(3) liboath oath_strerror(3)

NOMBRE

oath_strerror - función de la API

SINOPSIS

#include <oath.h>

const char * oath_strerror(int err);

ARGUMENTOS

int err
código de error de liboath

DESCRIPCIÓN

Convierte el código de retorno a una explicación legible por humanos del motivo del código de error particular.

Esta cadena se puede usar para mostrar un mensaje de diagnóstico al usuario.

Esta función es una de las pocas en la biblioteca que se puede usar sin una llamada exitosa a oath_init().

VALOR DE RETORNO

Devuelve un puntero a una cadena asignada estáticamente que contiene una explicación del código de error err.

DESDE

1.8.0
