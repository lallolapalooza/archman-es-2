OGMSPLIT(1) Comandos de usuario OGMSPLIT(1)

NOMBRE

ogmsplit - Divide archivos OGG/OGM en varios archivos OGG/OGM más pequeños

SINOPSIS

ogmsplit [opciones] nombre_entrada

DESCRIPCIÓN

ogmsplit se puede usar para dividir fácilmente un archivo OGM después de un tamaño dado. Se crearán varios archivos OGM que comenzarán cada uno con un keyframe.

nombre_entrada
Usa 'nombre_entrada' como origen.
-o, --output salida
Usa 'salida' como nombre base. Se les añadirán números de parte ascendentes. El valor predeterminado es 'nombre_entrada'. Ejemplos:
1) Si se da -o salida.ogg en la línea de comandos, entonces ogmsplit creará salida-000001.ogg, salida-000002.ogg y así sucesivamente.
2) Si no se da la opción -o y el nombre de la entrada es pelicula.ogm entonces ogmsplit creará pelicula-000001.ogm y así sucesivamente.

El modo de operación se puede establecer con exactamente una de las opciones -s, -t, -c o -p. El modo predeterminado es dividir por tamaño (-s).

-s, --size tamaño
Tamaño en MiB ( = 1024 * 1024 bytes) después del cual se abrirá un nuevo archivo (aproximadamente). El valor predeterminado es 700MiB. El tamaño puede terminar en 'B' para indicar 'bytes' en lugar de 'MiB'.
-t, --time tiempo
Dividir después del tiempo transcurrido dado (aproximadamente). 'tiempo' toma el formato HH:MM:SS.sss o simplemente SS(.sss), p. ej. 00:05:00.000 o 300.000 o simplemente 300.
-c, --cuts cortes
Producir archivos de salida según lo especificado por cortes, una lista de secciones del tipo "inicio-fin" o "inicio+longitud", separadas por comas. Si se omite inicio, se toma por defecto el final del corte anterior. inicio y fin toman el mismo formato que los argumentos para -t.
-n, --num num
No crear más de num archivos separados. El último puede ser más grande que el tamaño deseado. El valor predeterminado es un número ilimitado de archivos. Solo se puede usar con -s o -t.
--frontend
Modo interfaz gráfica. La salida de progreso terminará con \n en lugar de \r.
-p, --print-splitpoints
Solo imprimir los keyframes y el número de bytes encontrados antes de cada uno. Útil para encontrar el punto de división exacto.
-v, --verbose
Ser verboso y mostrar cada paquete OGG. Se puede usar dos veces para aumentar la verbosidad.
-h, --help
Mostrar esta ayuda.
-V, --version
Mostrar información de la versión.

INFORMACIÓN DE CAPÍTULOS

ogmsplit maneja correctamente la información de capítulos. Durante la primera pasada, la información de capítulos, si está presente, se ajustará para que coincida con los archivos de salida generados. Los capítulos que no están contenidos en el archivo de salida actual se eliminarán por completo. Los otros capítulos se renumerarán para comenzar en 1 y sus marcas de tiempo se recalcularán.
Ejemplo: Si tu archivo de origen contiene estos cuatro capítulos:

CHAPTER01=00:00:00.000
CHAPTER01NAME=Capítulo 01
CHAPTER02=00:10:00.000
CHAPTER02NAME=Capítulo 02
CHAPTER03=00:20:00.000
CHAPTER03NAME=Capítulo 03
CHAPTER04=00:25:00.000
CHAPTER04NAME=Capítulo 04

y divides después de 15 minutos, entonces el primer archivo de salida solo contendrá los dos primeros capítulos como se muestra arriba, y el segundo archivo de salida contendrá los dos capítulos restantes y la parte restante del primero:

CHAPTER01=00:00:00.000
CHAPTER01NAME=Capítulo 02 (continuación)
CHAPTER02=00:05:00.000
CHAPTER02NAME=Capítulo 03
CHAPTER03=00:10:00.000
CHAPTER03NAME=Capítulo 04

Ten en cuenta que solo se cambian los nombres de las variables, no los nombres de los capítulos en sí. La excepción es el primer capítulo de los archivos segundo y siguientes, donde se añade "(continuación)" para indicar que este no es el inicio de este capítulo. Si también deseas cambiarlos, tendrás que volver a fusionar el archivo resultante con un nuevo archivo de capítulos.
