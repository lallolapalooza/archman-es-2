FBB::OFilterBuf(3bobcat) filtrado de ostream FBB::OFilterBuf(3bobcat)

NOMBRE

FBB::OFilterBuf - Clase base para el filtrado de std::ostream

SINOPSIS

#include <bobcat/ofilterbuf>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

La clase FBB::OFilterBuf es una especialización de la clase std::streambuf y puede ser utilizada como clase base para clases que implementen el filtrado de ostream.

El filtrado de Ostream se define aquí como el proceso por el cual los caracteres insertados son sometidos a procesamiento antes de ser pasados a otro objeto ostream (filtrado) (o pueden ser rechazados). El filtrado también puede resultar en la inserción de información adicional en el ostream (filtrado).

También es posible el encadenamiento de filtros: el ostream (filtrado) puede usar su propio OFilterBuf para filtrar la información recibida antes de pasarla a otro ostream más.

Como OFilterBuf hereda de std::streambuf, un objeto OFilterBuf puede ser utilizado para proporcionar a un objeto ostream un std::streambuf. La información insertada en dicho stream sigue la siguiente ruta:

o
La información se convierte en caracteres utilizando las facilidades de conversión estándar implementadas por los objetos std::ostream. Por ejemplo, al insertar el valor 123, este valor se convierte en los caracteres ’1’, ’2’ y ’3’, respectivamente.
o
Cada uno de los caracteres se ofrece (en orden) al std::streambuf que está asociado con el objeto ostream. En particular, se llama al miembro overflow() del std::streambuf.
o
La función overflow() por defecto de OFstreamBuf ignora los caracteres, pero las especializaciones pueden sobrescribir overflow() para procesar los caracteres recibidos ad lib.
o
Una función overflow() que sobrescribe tiene acceso al miembro OFstreambuf::out(), que es una referencia al std::ostream que recibe la información filtrada. Para implementar un filtro de copia simple (es decir, todos los caracteres se aceptan tal cual), una clase debe heredar de OFilterBuf proporcionando una implementación que sobrescriba overflow(), por ejemplo, de la siguiente manera: 
    int DerivedClass::overflow(int ch)
    {
        out().put(ch);
    }
A continuación, esta especialización de std::streambuf se puede asociar con un ostream en el que se puede insertar información que se desea `filtrar por copia' (ver la sección EJEMPLO a continuación).

CONSTRUCTORES

Como OFilterBuf debe usarse como clase base, todos sus constructores son protegidos.

o
OFilterBuf():
Este constructor crea un objeto OFilterBuf sin asociarlo a un destino (filtrado) ostream.
o
OFilterBuf(std::string const &fname, openmode mode = std::ios::out):
Este constructor crea un objeto OFilterBuf y abre un objeto std::ofstream privado cuyo nombre de archivo se proporciona y que debería recibir la información filtrada.
o
OFilterBuf(std::ostream &out):
Este constructor crea un objeto OFilterBuf e insertará cualquier información filtrada en el objeto ostream proporcionado.

Los constructores y operadores de asignación de copia y movimiento no están disponibles.

FUNCIONES MIEMBRO PROTEGIDAS

Excepto por los miembros públicos heredados de std::ostreambuf, todos los miembros de OFilterBuf son protegidos.

Las clases derivadas deben proporcionar su propia implementación de int underflow(int ch) para implementar el filtrado.

o
void reset(std::string const &fname, openmode mode = std::ios::out):
Este miembro vacía el std::ostream (filtrado) de destino actual y asocia el objeto OFilterBuf con un objeto std::ofstream cuyo nombre de archivo se proporciona y que debería recibir información posteriormente filtrada.
o
void reset(std::ostream &out):
Este miembro vacía el objeto std::ostream (filtrado) de destino actual y asocia el objeto OFilterBuf con el objeto ostream proporcionado.
o
std::ostream &out() const:
Este miembro está disponible para las clases derivadas para insertar información en el stream de destino (filtrado).

EJEMPLO

    #include <iostream>
    #include <cctype>
    #include <bobcat/ofilterbuf>
    struct NoDigits: public FBB::OFilterBuf
    {
        NoDigits(std::ostream &out)
        :
            OFilterBuf(out)
        {}
        private:
            int overflow(int ch) override
            {
                if (not isdigit(ch))
                    out().put(ch);
                return ch;
            }
    };
    using namespace FBB;
    using namespace std;
    int main()
    {
        NoDigits nod(cout);     // no digits to cout
        ostream out(&nod);
        out << cin.rdbuf();      // rm digits from cin
    }
