ODFIMGIMPORT(1) Comandos de usuario ODFIMGIMPORT(1)



NOMBRE
odfimgimport - Importar imágenes externas



SINOPSIS

odfimgimport [-q] [-o archivo_salida] [archivo_entrada]



DESCRIPCIÓN

Si copias y pegas html desde tu navegador a tu procesador de texto, las imágenes del texto pegado seguirán cargando las imágenes de Internet. Este script importará todas las imágenes al archivo OpenDocument.

Si no proporcionas un archivo de entrada, el programa leerá desde la entrada estándar. Si el programa lee desde la entrada estándar, puede que no sepa cómo resolver nombres de archivo relativos. Si no proporcionas un archivo de salida, el programa importará las imágenes al archivo de entrada.



OPCIONES

-q

Si hay imágenes que no se pueden importar, odfimgimport escribirá cuántas han fallado. La bandera -q evitará eso.

-v

Verboso: Imprime la URL de cada imagen que intenta importar y el resultado.

-o archivo_salida

El archivo donde guardar la salida. "-" es la salida estándar. Por defecto, es el archivo de entrada.



EJEMPLO

odfimgimport -v -o nuevoarchivo.odt archivoantiguo.odt
