oct(1) Manual de comandos generales oct(1)

NOMBRE

oct - Una herramienta para inspeccionar, configurar y usar tarjetas OpenPGP

SINOPSIS

oct [--formato-salida] [--version-salida] [-h|--ayuda] [-V|--version] <subcomandos>

DESCRIPCIÓN

Una herramienta para inspeccionar, configurar y usar tarjetas OpenPGP

OPCIONES

--formato-salida=FORMATO_SALIDA [por defecto: text]
Producir salida en el formato elegido

[valores posibles: json, text, yaml]

--version-salida=VERSION_SALIDA [por defecto: 0.11.0]
Elegir la versión de salida a utilizar, para formatos no textuales
-h, --ayuda
Imprimir ayuda
-V, --version
Imprimir versión

SUBCOMANDOS

oct-list(1)
Enumerar las tarjetas OpenPGP disponibles
oct-status(1)
Mostrar información sobre los datos en una tarjeta
oct-info(1)
Mostrar detalles técnicos sobre una tarjeta
oct-ssh(1)
Mostrar la clave de autenticación de una tarjeta como una clave pública SSH
oct-pubkey(1)
Exportar los datos de la clave en una tarjeta como una clave pública OpenPGP
oct-admin(1)
Administrar datos en una tarjeta (incluyendo claves y metadatos)
oct-pin(1)
Gestión de PIN (cambiar PIN, restablecer PIN bloqueados)
oct-decrypt(1)
Descifrar datos usando una tarjeta
oct-sign(1)
Firmar datos usando una tarjeta
oct-attestation(1)
Gestión de atestaciones (solo Yubico)
oct-system(1)
Inicialización y funcionalidad similar
oct-output-versions(1)
Mostrar versiones de formato de salida compatibles
oct-help(1)
Imprimir este mensaje o la ayuda de los subcomandos dados
