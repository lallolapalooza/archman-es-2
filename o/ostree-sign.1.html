NOMBRE

ostree-sign - Firmar un commit

SINOPSIS

ostree sign [OPCIONES...] {COMMIT} {ID-CLAVE...}

DESCRIPCIÓN

Añadir una nueva firma a un commit. Tenga en cuenta que actualmente, esto añadirá una nueva firma incluso si el commit ya está firmado con una clave dada.

Para `ed25519` y `spki`, existen varios lugares del sistema "conocidos" para claves públicas confiables y revocadas, como se enumera a continuación.

Archivos:

•/etc/ostree/trusted.TIPO-FIRMA
•/etc/ostree/revoked.TIPO-FIRMA
•/usr/share/ostree/trusted.TIPO-FIRMA
•/usr/share/ostree/revoked.TIPO-FIRMA

Directorios que contienen archivos con claves:

•/etc/ostree/trusted.TIPO-FIRMA.d
•/etc/ostree/revoked.TIPO-FIRMA.d
•/usr/share/ostree/trusted.TIPO-FIRMA.d
•/usr/share/ostree/revoked.TIPO-FIRMA.d

El formato de esos archivos depende del mecanismo de firma; para `ed25519`, las claves se almacenan codificadas en base64 por línea, mientras que para `spki` se almacenan en la codificación PEM "PUBLIC KEY".

OPCIONES

ID-CLAVE

para ed25519 y spki:

clave secreta (para firmar) o pública (para verificar) codificada en base64.

para dummy:

cadena ASCII utilizada como clave secreta y clave pública.

--verify

Verificar firmas

-s, --sign-type

Utilizar un mecanismo de firma particular. Actualmente disponibles tipos de firma ed25519, spki y dummy. El valor predeterminado es ed25519.

--keys-file

Leer clave(s) del archivo nombre-archivo. Válido para tipos de firma ed25519 y spki. Este archivo debe contener claves secretas (para firmar) o claves públicas (para verificar) codificadas en base64 por línea.

--keys-dir

Redefinir la ruta del sistema, dónde buscar archivos y subdirectorios con claves conocidas y revocadas.
