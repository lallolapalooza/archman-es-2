Métodos

void RegistrarAgente(objeto agente)

Registra un agente, que debe implementar org.bluez.obex.Agent(5), para solicitar la autorización del usuario para aceptar/rechazar objetos.

El servicio de envío de objetos necesita autorizar cada objeto recibido.

Posibles errores:

org.bluez.obex.Error.AlreadyExists

void AnularRegistroAgente(objeto agente)

Anula el registro del agente que se registró previamente usando RegistrarAgente().

El parámetro de ruta de objeto debe coincidir con el mismo valor que se usó durante el registro.

Posibles errores:

org.bluez.obex.Error.DoesNotExist
