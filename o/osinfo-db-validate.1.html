osinfo-db-validate(1) Herramientas de BD de Osinfo osinfo-db-validate(1)

NOMBRE

osinfo-db-validate - Valida los archivos de datos XML de la base de datos libosinfo

SINOPSIS

osinfo-db-validate [OPCIONES...]

osinfo-db-validate [OPCIONES...] RUTA-LOCAL1 [RUTA-LOCAL2...]

osinfo-db-validate [OPCIONES...] URI1 [URI2...]

DESCRIPCIÓN

La herramienta osinfo-db-validate es capaz de validar los archivos XML en una de las ubicaciones de la base de datos osinfo para cumplir con el esquema RNG.

system
Esta es la ubicación principal de la base de datos a nivel de sistema, destinada a ser utilizada por los distribuidores de sistemas operativos que distribuyen archivos de base de datos en el formato de paquete nativo. Se espera que el esquema RNG esté presente en esta ubicación.
local
Esta es la ubicación secundaria de la base de datos a nivel de sistema, destinada a ser utilizada por los administradores del sistema que desean proporcionar una base de datos actualizada para todos los usuarios. Esta ubicación puede proporcionar una anulación del esquema RNG, de lo contrario se utilizará el esquema RNG de la ubicación del sistema.
user
Esta es la ubicación privada de la base de datos del usuario, destinada a ser utilizada por usuarios locales no privilegiados que deseen proporcionar a las aplicaciones que utilizan una base de datos actualizada. Esta ubicación puede proporcionar una anulación del esquema RNG, de lo contrario se utilizará el esquema RNG de la ubicación local, o en su defecto, la ubicación del sistema.

Si es ejecutado por una cuenta privilegiada (es decir, root), la ubicación de la base de datos local será validada por defecto, de lo contrario, la ubicación user será validada.

Alternativamente, es posible proporcionar directamente una lista de archivos para validar utilizando los argumentos ("RUTA-LOCAL1" o "URI1").

Cualquier error de validación se mostrará en la consola cuando se detecte.

OPCIONES

--user
Anula el comportamiento predeterminado para forzar la validación de archivos de la ubicación de la base de datos user.
--local
Anula el comportamiento predeterminado para forzar la validación de archivos de la ubicación de la base de datos local.
--system
Anula el comportamiento predeterminado para forzar la validación de archivos de la ubicación de la base de datos system.
--dir=RUTA
Anula el comportamiento predeterminado para forzar la validación de archivos del directorio personalizado RUTA.
--root=RUTA
Prefija la ubicación de la base de datos con el directorio raíz dado por "RUTA". Esto es útil cuando se desean validar archivos que están en un entorno chroot o equivalente.
-v, --verbose
Muestra información detallada del progreso al validar archivos

ESTADO DE SALIDA

El estado de salida será 0 si todos los archivos pasaron la validación, o 1 si se encontró un error de validación.
