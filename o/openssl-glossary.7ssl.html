NOMBRE

openssl-glossary - Glosario de OpenSSL

DESCRIPCIÓN

Algoritmo
Las primitivas criptográficas como el hash SHA256 o la encriptación AES se denominan en OpenSSL como "algoritmos". Puede haber más de una implementación para cualquier algoritmo dado disponible para su uso.

crypto(7)

ASN.1, ASN1
ASN.1 ("Abstract Syntax Notation One") es una notación para describir tipos y valores abstractos. Está definido en los documentos ITU-T X.680 a X.683:

https://www.itu.int/rec/T-REC-X.680, https://www.itu.int/rec/T-REC-X.681, https://www.itu.int/rec/T-REC-X.682, https://www.itu.int/rec/T-REC-X.683

Proveedor Base
Un Proveedor de OpenSSL que contiene codificadores y decodificadores para claves de OpenSSL. Todas las implementaciones de algoritmos en el Proveedor Base también están disponibles en el Proveedor Predeterminado.

OSSL_PROVIDER-base(7)

Decodificador
Un decodificador es un tipo de algoritmo utilizado para decodificar claves y parámetros de algún formato externo como PEM o DER.

OSSL_DECODER_CTX_new_for_pkey(3)

Proveedor Predeterminado
Un Proveedor de OpenSSL que contiene las implementaciones de algoritmos de OpenSSL más comunes. Se carga por defecto si no hay ningún otro proveedor disponible. Todas las implementaciones de algoritmos en el Proveedor Base también están disponibles en el Proveedor Predeterminado.

OSSL_PROVIDER-default(7)

DER ("Distinguished Encoding Rules")
DER es una codificación binaria de datos, estructurada según una especificación ASN.1. Esta es una codificación común utilizada para objetos criptográficos como claves privadas y públicas, certificados, CRLs, ...

Está definido en el documento ITU-T X.690:

https://www.itu.int/rec/T-REC-X.690

Codificador
Un codificador es un tipo de algoritmo utilizado para codificar claves y parámetros a algún formato externo como PEM o DER.

OSSL_ENCODER_CTX_new_for_pkey(3)

Obtención Explícita
La Obtención Explícita es un tipo de Obtención (ver Obtención). La Obtención Explícita es cuando se realiza una llamada a una función para obtener un objeto de algoritmo que representa una implementación como EVP_MD_fetch(3) o EVP_CIPHER_fetch(3)
Obtención
Obtención es el proceso de buscar entre las implementaciones de algoritmos disponibles, aplicando criterios de selección (a través de una cadena de consulta de propiedades), y finalmente eligiendo la implementación que se utilizará.

Ver también Obtención Explícita y Obtención Implícita.

crypto(7)

Proveedor FIPS
Un Proveedor de OpenSSL que contiene implementaciones de algoritmos de OpenSSL que han sido validadas según el estándar FIPS 140-2.

OSSL_PROVIDER-FIPS(7)

Obtención Implícita
La Obtención Implícita es un tipo de Obtención (ver Obtención). La Obtención Implícita es cuando se utiliza un objeto de algoritmo sin una implementación asociada, como el valor de retorno de EVP_sha256(3) o EVP_aes_128_cbc(3). Con la obtención implícita, una implementación se obtiene automáticamente utilizando criterios de selección predeterminados la primera vez que se utiliza el algoritmo.
Proveedor Legado
Un Proveedor de OpenSSL que contiene implementaciones de algoritmos que se consideran inseguros o que ya no están en uso común.

OSSL_PROVIDER-legacy(7)

Contexto de Biblioteca
Un Contexto de Biblioteca en OpenSSL está representado por el tipo OSSL_LIB_CTX. Se puede considerar como un ámbito dentro del cual se aplican las opciones de configuración. Si una aplicación no crea explícitamente un contexto de biblioteca, se utiliza el predeterminado. Muchas funciones de OpenSSL pueden tomar un contexto de biblioteca como argumento. Siempre se puede pasar un valor NULL para indicar el contexto de biblioteca predeterminado.

OSSL_LIB_CTX(3)

MSBLOB
MSBLOB es un formato binario específico de Microsoft para claves RSA y DSA, tanto privadas como públicas. Esta forma nunca está protegida con contraseña.
Proveedor Nulo
Un Proveedor de OpenSSL que no contiene implementaciones de algoritmos. Esto puede ser útil para evitar que el proveedor predeterminado se cargue automáticamente en un contexto de biblioteca.

OSSL_PROVIDER-null(7)

Operación
Una operación es un grupo de funciones de OpenSSL con un propósito común, como encriptación o digest.

crypto(7)

PEM ("Privacy Enhanced Message")
PEM es un formato utilizado para codificar contenido binario en una forma amigable para el correo y ASCII. El contenido es una serie de líneas codificadas en base64, rodeadas por marcadores de inicio/fin cada uno en su propia línea. Por ejemplo: 
-----BEGIN PRIVATE KEY-----
MIICdg....
... bhTQ==
-----END PRIVATE KEY-----

Puede aparecer una o más líneas de encabezado opcionales después de la línea de inicio, y su existencia depende del tipo de objeto que se esté escribiendo o leyendo.

Para todos los usos de OpenSSL, se espera que el contenido binario sea una estructura codificada en DER.

Esto está definido en el RFC 1421 de IETF:

https://tools.ietf.org/html/rfc1421

PKCS#8
PKCS#8 es una especificación de estructuras ASN.1 que OpenSSL utiliza para almacenar o transmitir cualquier clave privada de manera agnóstica al tipo de clave. Hay dos estructuras que vale la pena notar para su uso en OpenSSL: una que contiene los datos de la clave en forma no cifrada (conocida como "PrivateKeyInfo") y una estructura contenedora cifrada (conocida como "EncryptedPrivateKeyInfo").

Esto se especifica en el RFC 5208:

https://tools.ietf.org/html/rfc5208

Propiedad
Una propiedad es una forma de clasificar y seleccionar implementaciones de algoritmos. Una propiedad es un par clave/valor expresado como una cadena. Por ejemplo, todas las implementaciones de algoritmos en el proveedor predeterminado tienen la propiedad "provider=default". Una implementación de algoritmo puede tener múltiples propiedades definidas para ella.

Ver también Cadena de Consulta de Propiedades.

property(7)

Cadena de Consulta de Propiedades
Una cadena de consulta de propiedades es una cadena que contiene una secuencia de propiedades que se pueden utilizar para seleccionar una implementación de algoritmo. Por ejemplo, la cadena de consulta "provider=example,foo=bar" seleccionará algoritmos del proveedor "example" que tengan una propiedad "foo" definida para ellos con un valor de "bar".

Las cadenas de consulta de propiedades se utilizan durante la obtención. Ver Obtención.

property(7)

Proveedor
Un proveedor en OpenSSL es un componente que agrupa implementaciones de algoritmos. Los proveedores pueden provenir del propio OpenSSL o de terceros.

provider(7)

PVK
PVK es un formato binario específico de Microsoft para claves privadas RSA y DSA. Esta forma puede estar protegida con contraseña.

NAME

openssl-glossary - Glossary of OpenSSL terms

DESCRIPTION

This man page is a glossary of terms used in OpenSSL documentation.

SubjectPublicKeyInfo
SubjectPublicKeyInfo es una estructura ASN.1 que OpenSSL utiliza para almacenar y transmitir cualquier clave pública de manera independiente del tipo de clave.

Esto se especifica como parte de la especificación para certificados, RFC 5280:

https://tools.ietf.org/html/rfc5280
