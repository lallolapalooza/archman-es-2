oo(3) Documentación de Perl contribuida por el usuario oo(3)

NOMBRE

oo - azúcar sintáctica para oneliners de Moo

SINOPSIS

perl -Moo=Foo -e 'has bar => ( is => q[ro], default => q[baz] ); print Foo->new->bar'
# carga una clase existente y re-"abre" la definición del paquete
perl -Moo=+My::Class -e 'print __PACKAGE__->new->bar'

DESCRIPCIÓN

oo.pm es un filtro de fuente simple que añade "package $name; use Moo;" al principio de tu script, pensado para ser usado en la línea de comandos a través de la opción -M.
