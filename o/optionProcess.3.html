optionProcess(3) Manual del programador optionProcess(3)

NOMBRE

optionProcess - esta es la rutina principal de procesamiento de opciones

SINOPSIS

#include <tus-opts.h>
cc [...] -o archivo_salida archivo_entrada.c -lopts [...]

int optionProcess(tOptions * opts, int a_ct, char ** a_v);

DESCRIPCIÓN

Este es el punto de entrada principal para procesar opciones. Se pretende que este procedimiento se llame una vez al principio de la ejecución de un programa. Dependiendo de las opciones seleccionadas anteriormente, a veces es necesario detener y reiniciar el procesamiento de opciones, o seleccionar conjuntos de opciones completamente diferentes. Esto se puede hacer fácilmente, pero generalmente no querrás hacer esto.

El número de argumentos procesados siempre incluye el nombre del programa. Si uno de los argumentos es "--", se cuenta y el procesamiento se detiene. Si se encontró un error y los errores deben ser tolerados, el valor devuelto es el índice del argumento que causa el error. Un guion por sí solo ("-") también hará que el procesamiento se detenga y *no* se contará entre los argumentos procesados. Un guion por sí solo se trata como un operando. Encontrarse con un operando detiene el procesamiento de opciones.

opts
descriptor de opciones del programa
a_ct
contador de argumentos del programa
a_v
vector de argumentos del programa

VALOR DE RETORNO

el contador de los argumentos procesados

ERRORES

Los errores provocarán la impresión de diagnósticos. Se puede llamar a exit(3) o no. Depende de si las opciones fueron generadas con el atributo "allow-errors", o si se invocaron las macros ERRSKIP_OPTERR o ERRSTOP_OPTERR.
