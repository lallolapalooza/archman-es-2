NOMBRE

gprof - mostrar datos de perfil de gráfico de llamadas

SINOPSIS

gprof [ -[abcDhilLrsTvwxyz] ] [ -[ABCeEfFJnNOpPqQRStZ][nombre] ]
[ -I directorios ] [ -d[num] ] [ -k desde/hasta ]
[ -m conteo-min ] [ -R archivo-mapa ] [ -t longitud-tabla ]

DESCRIPCIÓN

"gprof" produce un perfil de ejecución de programas C, Pascal o Fortran77. El efecto de las rutinas llamadas se incorpora en el perfil de cada llamador. Los datos del perfil se toman del archivo de perfil de gráfico de llamadas (gmon.out por defecto), que es creado por programas compilados con la opción -pg de "cc", "pc" y "f77". La opción -pg también enlaza versiones de las rutinas de la biblioteca que están compiladas para profiling. "Gprof" lee el archivo objeto dado (el valor por defecto es "a.out") y establece la relación entre su tabla de símbolos y el gráfico de llamadas del perfil de gmon.out. Si se especifican varios archivos de perfil, la salida de "gprof" muestra la suma de la información del perfil en los archivos de perfil dados.

"Gprof" calcula la cantidad de tiempo gastado en cada rutina. Luego, estos tiempos se propagan a lo largo de los bordes del gráfico de llamadas. Se descubren ciclos y las llamadas a un ciclo se hacen para compartir el tiempo del ciclo.

Hay varias formas de salida disponibles a partir del análisis.

El perfil plano muestra cuánto tiempo pasó su programa en cada función y cuántas veces se llamó a esa función. Si solo desea saber qué funciones consumen la mayor parte del tiempo de CPU, aquí se indica de forma concisa.

El gráfico de llamadas muestra, para cada función, qué funciones la llamaron, qué otras funciones llamó y cuántas veces. También hay una estimación de cuánto tiempo se gastó en las subrutinas de cada función. Esto puede sugerir lugares donde podría intentar eliminar llamadas a funciones que consumen mucho tiempo.

La lista de código fuente anotado es una copia del código fuente del programa, etiquetada con el número de veces que se ejecutó cada línea del programa.

OPCIONES

Estas opciones especifican qué formato de salida debe producir "gprof".

Muchas de estas opciones toman un symspec opcional para especificar las funciones a incluir o excluir. Estas opciones se pueden especificar varias veces, con diferentes symspecs, para incluir o excluir conjuntos de símbolos.

Especificar cualquiera de estas opciones anula el valor por defecto (-p -q), que imprime un perfil plano y un análisis del gráfico de llamadas para todas las funciones.

"-A[symspec]"
"--fuente-anotada[=symspec]"
La opción -A hace que "gprof" imprima código fuente anotado. Si se especifica symspec, imprima la salida solo para los símbolos coincidentes.
"-b"
"--breve"
Si se proporciona la opción -b, "gprof" no imprime los textos explicativos detallados que intentan explicar el significado de todos los campos en las tablas. Esto es útil si tiene la intención de imprimir la salida o está cansado de ver los textos explicativos.
"-B"
La opción -B hace que "gprof" imprima el análisis del gráfico de llamadas.
"-C[symspec]"
"--conteo-ejecuciones[=symspec]"
La opción -C hace que "gprof" imprima un recuento de funciones y el número de veces que se llamó a cada una. Si se especifica symspec, imprima el recuento solo para los símbolos coincidentes.

Si el archivo de datos de perfil contiene registros de conteo de bloques básicos, especificar la opción -l, junto con -C, hará que se cuenten y muestren los conteos de ejecución de bloques básicos.

"-i"
"--info-archivo"
La opción -i hace que "gprof" muestre información resumida sobre el archivo(s) de datos de perfil y luego salga. Se muestra el número de registros de histograma, gráfico de llamadas y conteo de bloques básicos.
"-I directorios"
"--ruta-directorio=directorios"
La opción -I especifica una lista de directorios de búsqueda en los que encontrar archivos fuente. La variable de entorno GPROF_PATH también se puede utilizar para transmitir esta información. Se utiliza principalmente para la salida de código fuente anotado.
"-J[symspec]"
"--sin-fuente-anotada[=symspec]"
La opción -J hace que "gprof" no imprima código fuente anotado. Si se especifica symspec, "gprof" imprime código fuente anotado, pero excluye los símbolos coincidentes.
"-L"
"--imprimir-ruta"
Normalmente, los nombres de archivo fuente se imprimen suprimiendo el componente de ruta. La opción -L hace que "gprof" imprima la ruta completa de los nombres de archivo fuente, que se determina a partir de la información de depuración simbólica en el archivo de imagen y es relativa al directorio en el que se invocó el compilador.
"-p[symspec]"
"--perfil-plano[=symspec]"
La opción -p hace que "gprof" imprima un perfil plano. Si se especifica symspec, imprima el perfil plano solo para los símbolos coincidentes.
"-P[symspec]"
"--sin-perfil-plano[=symspec]"
La opción -P hace que "gprof" suprima la impresión de un perfil plano. Si se especifica symspec, "gprof" imprime un perfil plano, pero excluye los símbolos coincidentes.
"-q[symspec]"
"--grafico[=symspec]"
La opción -q hace que "gprof" imprima el análisis del gráfico de llamadas. Si se especifica symspec, imprima el gráfico de llamadas solo para los símbolos coincidentes y sus hijos.
"-Q[symspec]"
"--sin-grafico[=symspec]"
La opción -Q hace que "gprof" suprima la impresión del gráfico de llamadas. Si se especifica symspec, "gprof" imprime un gráfico de llamadas, pero excluye los símbolos coincidentes.
"-t"
"--longitud-tabla=num"
La opción -t hace que se listen las num líneas de código fuente más activas en cada archivo fuente cuando la anotación del código fuente está habilitada. El valor por defecto es 10.
"-y"
"--archivos-separados"
Esta opción solo afecta a la salida de código fuente anotado. Normalmente, "gprof" imprime los archivos de código fuente anotado en la salida estándar. Si se especifica esta opción, el código fuente anotado para un archivo llamado ruta/nombrearchivo se genera en el archivo nombrearchivo-ann. Si el sistema de archivos subyacente truncara nombrearchivo-ann de modo que sobrescribiera el nombrearchivo original, "gprof" generaría el código fuente anotado en el archivo nombrearchivo.ann en su lugar (si el nombre de archivo original tiene una extensión, esa extensión se *reemplaza* por .ann).

Output Control Options

"-b"
"--brief"
The "gprof" option -b suppresses the printing of the count of functions and the number of times each was called. If symspec is specified, print tally, but exclude matching symbols.
"-r"
"--function-ordering"
The --function-ordering option causes "gprof" to print a suggested function ordering for the program based on profiling data. This option suggests an ordering which may improve paging, tlb and cache behavior for the program on systems which support arbitrary ordering of functions in an executable.

The exact details of how to force the linker to place functions in a particular order is system dependent and out of the scope of this manual.

"-R map_file"
"--file-ordering map_file"
The --file-ordering option causes "gprof" to print a suggested .o link line ordering for the program based on profiling data. This option suggests an ordering which may improve paging, tlb and cache behavior for the program on systems which do not support arbitrary ordering of functions in an executable.

Use of the -a argument is highly recommended with this option.

The map_file argument is a pathname to a file which provides function name to object file mappings. The format of the file is similar to the output of the program "nm".

c-parse.o:00000000 T yyparse
c-parse.o:00000004 C yyerrflag
c-lang.o:00000000 T maybe_objc_method_name
c-lang.o:00000000 T print_lang_statistics
c-lang.o:00000000 T recognize_objc_keyword
c-decl.o:00000000 T print_lang_identifier
c-decl.o:00000000 T print_lang_type
...

To create a map_file with GNU "nm", type a command like "nm --extern-only --defined-only -v --print-file-name program-name".

"-T"
"--traditional"
The -T option causes "gprof" to print its output in "traditional" BSD style.
"-w width"
"--width=width"
Sets width of output lines to width. Currently only used when printing the function index at the bottom of the call graph.
"-x"
"--all-lines"
This option affects annotated source output only. By default, only the lines at the beginning of a basic-block are annotated. If this option is specified, every line in a basic-block is annotated by repeating the annotation for the first line. This behavior is similar to "tcov"'s -a.
"--demangle[=style]"
"--no-demangle"
These options control whether C++ symbol names should be demangled when printing output. The default is to demangle symbols. The "--no-demangle" option may be used to turn off demangling. Different compilers have different mangling styles. The optional demangling style argument can be used to choose an appropriate demangling style for your compiler.

Analysis Options

"-a"
"--no-static"
The -a option causes "gprof" to suppress the printing of statically declared (private) functions. (These are functions whose names are not listed as global, and which are not visible outside the file/function/block where they were defined.) Time spent in these functions, calls to/from them, etc., will all be attributed to the function that was loaded directly before it in the executable file. This option affects both the flat profile and the call graph.
"-c"
"--static-call-graph"
The -c option causes the call graph of the program to be augmented by a heuristic which examines the text space of the object file and identifies function calls in the binary machine code. Since normal call graph records are only generated when functions are entered, this option identifies children that could have been called, but never were. Calls to functions that were not compiled with profiling enabled are also identified, but only if symbol table entries are present for them. Calls to dynamic library routines are typically not found by this option. Parents or children identified via this heuristic are indicated in the call graph with call counts of 0.
"-D"
"--ignore-non-functions"
The -D option causes "gprof" to ignore symbols which are not known to be functions. This option will give more accurate profile data on systems where it is supported (Solaris and HPUX for example).
"-k from/to"
The -k option allows you to delete from the call graph any arcs from symbols matching symspec from to those matching symspec to.
"-l"
"--line"
The -l option enables line-by-line profiling, which causes histogram hits to be charged to individual source code lines, instead of functions. This feature only works with programs compiled by older versions of the "gcc" compiler. Newer versions of "gcc" are designed to work with the "gcov" tool instead.

If the program was compiled with basic-block counting enabled, this option will also identify how many times each line of code was executed. While line-by-line profiling can help isolate where in a large function a program is spending its time, it also significantly increases the running time of "gprof", and magnifies statistical inaccuracies.

"--inline-file-names"
This option causes "gprof" to print the source file after each symbol in both the flat profile and the call graph. The full path to the file is printed if used with the -L option.
"-m num"
"--min-count=num"
This option affects execution count output only. Symbols that are executed less than num times are suppressed.
"-nsymspec"
"--time=symspec"
The -n option causes "gprof", in its call graph analysis, to only propagate times for symbols matching symspec.
"-Nsymspec"
"--no-time=symspec"
The -n option causes "gprof", in its call graph analysis, not to propagate times for symbols matching symspec.
"-Sfilename"
"--external-symbol-table=filename"
The -S option causes "gprof" to read an external symbol table file, such as /proc/kallsyms, rather than read the symbol table from the given object file (the default is "a.out"). This is useful for profiling kernel modules.
"-z"
"--display-unused-functions"
If you give the -z option, "gprof" will mention all functions in the flat profile, even those that were never called, and that had no time spent in them. This is useful in conjunction with the -c option for discovering which routines were never called.

Miscellaneous Options

"-d[num]"
"--debug[=num]"
The -d num option specifies debugging options. If num is not specified, enable all debugging.
"-h"
"--help"
The -h option prints command line usage.
"-Oname"
"--file-format=name"
Selects the format of the profile data files. Recognized formats are auto (the default), bsd, 4.4bsd, magic, and prof (not yet supported).
"-s"
"--sum"
The -s option causes "gprof" to summarize the information in the profile data files it read in, and write out a profile data file called gmon.sum, which contains all the information from the profile data files that "gprof" read in. The file gmon.sum may be one of the specified input files; the effect of this is to merge the data in the other input files into gmon.sum.

Eventually you can run "gprof" again without -s to analyze the cumulative data in the file gmon.sum.

"-v"
"--version"
The -v flag causes "gprof" to print the current version number, and then exit.

Deprecated Options

These options have been replaced with newer versions that use symspecs.

"-e function_name"
The -e function option tells "gprof" to not print information about the function function_name (and its children...) in the call graph. The function will still be listed as a child of any functions that call it, but its index number will be shown as [not printed]. More than one -e option may be given; only one function_name may be indicated with each -e option.
"-E function_name"
The "-E function" option works like the "-e" option, but time spent in the function (and children who were not called from anywhere else), will not be used to compute the percentages-of-time for the call graph. More than one -E option may be given; only one function_name may be indicated with each -E option.
"-f function_name"
The -f function option causes
"gprof" para limitar el gráfico de llamadas a la función nombre_funcion y sus descendientes (y los descendientes de estos...). Se pueden proporcionar varias opciones -f; solo se puede indicar un nombre_funcion con cada opción -f.
"-F nombre_funcion"
La opción -F funcion funciona de manera similar a la opción "-f", pero solo el tiempo empleado en la función y sus descendientes (y los descendientes de estos...) se utilizará para determinar el tiempo total y los porcentajes de tiempo para el gráfico de llamadas. Se pueden proporcionar varias opciones -F; solo se puede indicar un nombre_funcion con cada opción -F. La opción -F anula la opción -E.

ERRORES

Se muestra la granularidad del muestreo, pero sigue siendo estadística en el mejor de los casos. Asumimos que el tiempo de cada ejecución de una función se puede expresar por el tiempo total de la función dividido por el número de veces que se llama a la función. Por lo tanto, el tiempo propagado a lo largo de los arcos del gráfico de llamadas a los padres de la función es directamente proporcional al número de veces que se atraviesa ese arco.

Los padres que no están perfilados tendrán el tiempo de sus hijos perfilados propagado a ellos, pero aparecerán como invocados espontáneamente en la lista del gráfico de llamadas, y su tiempo no se propagará más allá. De manera similar, los capturadores de señales, aunque perfilados, aparecerán como espontáneos (aunque por razones más oscuras). Los hijos perfilados de los capturadores de señales deberían tener sus tiempos propagados correctamente, a menos que el capturador de señales se haya invocado durante la ejecución de la rutina de perfilado, en cuyo caso todo está perdido.

El programa perfilado debe llamar a "exit"(2) o retornar normalmente para que la información de perfilado se guarde en el archivo gmon.out.
