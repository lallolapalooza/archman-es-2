NOMBRE

oggdec - decodificador simple, archivo Ogg Vorbis a archivo de audio PCM (Wave o RAW).

SINOPSIS

oggdec [ -Qhv ] [ -b bits_por_muestra ] [ -e endianness ] [ -R ] [ -s signedness ] [ -o archivo_salida ] archivo ...

DESCRIPCIÓN

oggdec decodifica archivos Ogg Vorbis a archivos de audio codificados en PCM ("sin comprimir"), en formato Wave o RAW.

Para cada archivo de entrada, oggdec escribe en un nombre de archivo basado en el nombre del archivo de entrada, pero con la extensión cambiada a ".wav" o ".raw" según corresponda.

Si el archivo de entrada se especifica como -, entonces oggdec leerá de la entrada estándar (stdin) y escribirá en la salida estándar (stdout) a menos que se especifique un nombre de archivo de salida. De manera similar, un nombre de archivo de salida de - hará que la salida sea a stdout.

Escribir el formato Wave en la salida estándar es una mala idea. Wave requiere un medio buscable para que la cabecera sea reescrita después de que se hayan escrito todos los datos; stdout no es buscable.

OPCIONES

-Q, --quiet
Suprime la salida del programa.
-h, --help
Imprime el mensaje de ayuda.
-V, --version
Muestra información de la versión.
-b n, --bits=n
Bits por muestra. Los valores válidos son 8 o 16.
-e n, --endian=n
Establece el orden de bytes para la salida de 16 bits. 0 (predeterminado) es little-endian (orden de bytes de Intel). 1 es big-endian (orden de bytes lógico).
-R, --raw
Salida en formato raw. Si no se especifica, escribe un archivo Wave (cabeceras RIFF).
-s n, --sign=n
Establece la signo para la salida. 0 para sin signo, 1 (predeterminado) para con signo.
-o nombre_archivo, --output=nombre_archivo
Escribe la salida en el nombre de archivo especificado. Esta opción solo es válida si se especifica un [archivo] de entrada, o si se utiliza el modo raw.

EJEMPLOS

Decodifica un archivo enabler.ogg a enabler.wav
como 16 bits con signo little-endian (opciones predeterminadas):

oggdec enabler.ogg

Decodifica un archivo enabler.ogg a enabler.raw como 16 bits con signo little-endian sin cabecera:

oggdec --raw enabler.ogg

Decodifica enabler.ogg a enabler.crazymonkey como 8 bits sin signo:

oggdec -b 8 -s 0 -o enabler.crazymonkey enabler.ogg

Decodifica enabler.ogg a enabler.raw como 16 bits con signo big-endian (cualquiera de los siguientes):

oggdec -R -e 1 -b 16 enabler.ogg
oggdec -R -e 1 -b 16 -o enabler.raw - < enabler.ogg
oggdec -R -e 1 -b 16 - < enabler.ogg > enabler.raw

Decodificación masiva (foo.ogg a foo.wav, bar.ogg a bar.wav, quux.ogg a quux.wav, etc.):

oggdec *.ogg
