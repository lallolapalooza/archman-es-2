OGMCAT(1) Comandos de usuario OGMCAT(1)

NOMBRE

ogmcat - Concatenar varios archivos OGG/OGM en un único archivo OGG/OGM grande

SINOPSIS

ogmcat [opciones] -o nombre_salida nombre_entrada1 [nombre_entrada2 [nombre_entrada3 ...]]

DESCRIPCIÓN

ogmcat NO funciona en este momento. Está en desarrollo. Lo he incluido simplemente por pereza (de lo contrario, tendría que quitarlo del Makefile/configuración antes de lanzar esta versión).

ogmcat se puede usar para concatenar varios archivos OGG/OGM en un único archivo grande si son del mismo tipo. Para una descripción más detallada, consulte la sección LIMITACIONES.

-o, --output nombre_salida
Salida a 'nombre_salida'.
nombre_entrada1
Use 'nombre_entrada1', 'nombre_entrada2', etc. como orígenes.
-m, --manualsync n
Especifica un valor de sincronización manual en ms que se agregará a las marcas de tiempo de presentación de cada flujo junto con el valor calculado por el algoritmo de sincronización elegido (ver la opción -s). Esta opción se puede usar para cada archivo de entrada, aunque no tiene efecto si se usa también para el primero.
-s, --sync nr
Utiliza el modo de sincronización nr. Los valores válidos son 0 - 4. El valor predeterminado se muestra en la pantalla de ayuda de ogmcat.
-n, --nosafetychecks
Deshabilita las comprobaciones de seguridad realizadas antes de la concatenación. El archivo resultante puede no ser reproducible. Consulte la sección LIMITACIONES para obtener más detalles.
-v, --verbose
Sea verboso y muestre cada paquete OGG. Se puede usar dos veces para aumentar la verbosidad.
-h, --help
Muestre esta ayuda.
-V, --version
Muestre la información de la versión.

LIMITACIONES

La concatenación de flujos es difícil en el mejor de los casos y puede que incluso sea imposible. Por lo tanto, ogmcat realiza comparaciones muy estrictas entre los flujos contenidos en los archivos de entrada. Las comprobaciones realizadas incluyen:

*
general: Todos los flujos con el mismo número de serie deben ser del mismo tipo (vídeo, audio, audio Vorbis o flujos de texto).
*
general: Si un flujo existe en un archivo, debe existir en los demás archivos también.
*
flujos de vídeo: El FourCC del códec, el ancho, la altura y los FPS deben coincidir.
*
flujos Vorbis: La frecuencia de muestreo y el número de canales deben coincidir.
*
otros flujos de audio: El ID del códec, la frecuencia de muestreo, los bits por muestra y el número de canales deben coincidir.
*
flujos de texto/subtítulos: La 'unidad de tiempo' debe coincidir.

El usuario puede anular forzosamente las últimas cuatro comprobaciones con el parámetro -n. Las comprobaciones marcadas como 'general' no se pueden anular de esta manera.

La sincronización de audio/vídeo puede no ser correcta en el archivo resultante, incluso si los archivos de origen estaban perfectamente sincronizados. El usuario puede experimentar con el parámetro -s, que hace que ogmcat utilice algoritmos ligeramente diferentes para calcular los valores de granulepos para los flujos de audio y texto. El rango de parámetros válidos se imprimirá en la pantalla de ayuda de ogmcat.

Si ninguno de los algoritmos de sincronización proporcionados funciona correctamente, el usuario también puede añadir manualmente un desfase de sincronización utilizando la opción -m para cada archivo de entrada.
