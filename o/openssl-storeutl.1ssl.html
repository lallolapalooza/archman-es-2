Paquete: openssl

Licencias: Apache-2.0

OPENSSL-STOREUTL(1ssl) OpenSSL OPENSSL-STOREUTL(1ssl)

NOMBRE

openssl-storeutl - comando STORE

SINOPSIS

openssl storeutl [-help] [-out archivo] [-noout] [-passin arg] [-text arg] [-r] [-certs] [-keys] [-crls] [-subject arg] [-issuer arg] [-serial arg] [-alias arg] [-fingerprint arg] [-digest] [-engine id] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq] uri

DESCRIPCIÓN

Este comando se puede utilizar para mostrar el contenido (después de la descodificación, según corresponda) obtenido de la URI dada.

OPCIONES

-help
Imprime un mensaje de uso.
-out nombre_archivo
Esto especifica el archivo de salida al que escribir. Se utiliza la salida estándar si esta opción no está presente. El archivo de salida puede ser el mismo que la entrada, lo que lleva a reemplazar el contenido del archivo. Tenga en cuenta que la E/S de archivos no es atómica. El archivo de salida se trunca y luego se escribe.
-noout
esta opción evita la salida de los datos PEM.
-passin arg
la fuente de la contraseña de la clave. Para más información sobre el formato de arg consulte openssl-passphrase-options(1).
-text
Imprime los objetos en formato de texto, de forma similar a la salida -text de openssl-x509(1), openssl-pkey(1), etc.
-r
Obtiene objetos recursivamente cuando sea posible.
-certs
-keys
-crls
Selecciona solo los certificados, claves o CRLs de la URI dada. Sin embargo, si esta URI devolviera un conjunto de nombres (URIs), estos siempre se devuelven.

Tenga en cuenta que todas las opciones deben darse antes del argumento uri.

Tenga en cuenta que -keys selecciona exclusivamente claves privadas, no hay un selector solo para claves públicas.

-subject arg
Busca un objeto que tenga el nombre de sujeto arg.

El arg debe estar formateado como "/tipo0=valor0/tipo1=valor1/tipo2=...". Los caracteres especiales pueden escaparse con "\" (barra invertida), los espacios se conservan. Los valores vacíos están permitidos pero se ignoran para la búsqueda. Es decir, una búsqueda con un valor vacío tendrá el mismo efecto que no especificar el tipo en absoluto. Proporcionar una sola "/" conducirá a una secuencia vacía de RDN (un DN NULL). Los RDN multivaluados se pueden formar colocando un carácter "+" en lugar de "/" entre las Aserciones de Valor de Atributo (AVA) que especifican los miembros del conjunto.

Ejemplo:

"/DC=org/DC=OpenSSL/DC=users/UID=123456+CN=John Doe"

-issuer arg
-serial arg
Busca un objeto que tenga el nombre del emisor y número de serie dados. Estas dos opciones deben usarse juntas. El arg del emisor debe estar formateado como "/tipo0=valor0/tipo1=valor1/tipo2=...", los caracteres pueden escaparse con \ (barra invertida), no se omiten espacios. El arg serial se puede especificar como un valor decimal o un valor hexadecimal si va precedido por "0x".
-alias arg
Busca un objeto que tenga el alias dado.
-fingerprint arg
Busca un objeto que tenga la huella digital dada.
-digest
El resumen que se utilizó para calcular la huella digital dada con -fingerprint.
-engine id
Ver "Opciones de motor" en openssl(1). Esta opción está obsoleta.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Ver "Opciones de proveedor" en openssl(1), provider(7), y property(7).

VER TAMBIÉN

openssl(1)

HISTORIA

Este comando se agregó en OpenSSL 1.1.1.

La opción -engine fue obsoleta en OpenSSL 3.0.
