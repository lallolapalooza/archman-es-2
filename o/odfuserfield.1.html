ODFUSERFIELD(1) Comandos de usuario ODFUSERFIELD(1)



NOMBRE
odfuserfield - Listar o cambiar las declaraciones de campos de usuario en un archivo ODF



SINOPSIS

odfuserfield [-l] [-L] [-x campo...] [-X campo...] [-s campo:valor...] [-o ruta] ruta



DESCRIPCIÓN

Odfuserfield es un programa que lista o cambia las declaraciones de variables de usuario en un archivo OpenDocument. Hay dos tipos de variables en OpenDocument. Las variables simples pueden tomar diferentes valores en diferentes posiciones a lo largo de un documento. Las variables de usuario tienen el mismo valor en todo el documento. Debido a la naturaleza global de estas últimas, es seguro cambiarlas con una aplicación externa.

Utilice odfuserfield para rellenar cartas modelo antes de imprimir o entregar al usuario.

“Ruta” se asume que es un archivo OpenDocument de tipo texto, hoja de cálculo o presentación.



OPCIONES

-l

Lista (extrae) todos los campos de usuario conocidos.

-L

Lista (extrae) todos los campos de usuario conocidos con tipo y valor.

-x campo

Extrae el contenido de este campo del archivo.

-X campo

Igual que -x, pero también preserva/incluye el nombre y el tipo del campo.

-s campo:valor

Establece el valor de un campo de usuario existente. El tipo de campo será el mismo.

-o ruta

Nombre de archivo al que escribir el archivo ODT modificado. Si no se proporciona la opción -o, el archivo ODT se escribirá en la salida estándar (stdout).



EJEMPLO

odfuserfield -L archivo-odf



VER TAMBIÉN

formail(1), id3tag(1)



PENDIENTE

Implementar fórmulas. Consulte la sección 6.3.5 de la especificación OpenDocument v1.0. Esto requiere una sintaxis diferente para los argumentos de -s.
