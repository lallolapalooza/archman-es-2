object, dict ObtenerArchivo(string archivodestino, string archivoorigen)

Copia el contenido del archivo de origen (desde el dispositivo remoto) al archivo de destino (en el sistema de archivos local).

Si se proporciona un archivo de destino vacío, se generará automáticamente un nombre para el archivo temporal.

La ruta devuelta representa la transferencia recién creada, que debe utilizarse para saber si el contenido se ha transferido con éxito o si la operación falla.

Las propiedades de esta transferencia también se devuelven junto con la ruta del objeto, para evitar una llamada a GetProperties, consulte org.bluez.obex.Transfer(5) para ver la lista posible de propiedades.

org.bluez.obex.Error.ArgumentosInvalidos
org.bluez.obex.Error.Fallo

NAME

org.bluez.obex.FileTransfer - BlueZ OBEX File Transfer interface

DESCRIPTION

The org.bluez.obex.FileTransfer interface is exposed by the OBEX File Transfer profile. It provides methods to browse and transfer files and folders.

This interface is typically implemented by a Bluetooth device that supports the OBEX File Transfer profile, such as a mobile phone or a file server.

INTERFACE PROPERTIES

This interface does not define any specific properties.

METHODS

The following methods are available:

ListFolders(path)
Returns a list of folders in the specified path.
ListFiles(path)
Returns a list of files in the specified path.
GetFile(remote_path, local_path)
Downloads the file from the remote device to the local device.
PutFile(local_path, remote_path)
Uploads the file from the local device to the remote device.
CreateFolder(path, folder_name)
Creates a new folder at the specified path.
Delete(path)
Deletes the file or folder at the specified path.
GoTo(path)
Changes the current directory on the remote device.

SIGNALS

This interface does not define any signals.

Interface

The interface name is org.bluez.obex.FileTransfer.
