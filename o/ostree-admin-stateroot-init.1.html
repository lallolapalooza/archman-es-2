NOMBRE

ostree-admin-stateroot-init - Inicializa un stateroot vacío para un sistema operativo dado

SINOPSIS

ostree admin stateroot-init {STATEROOT}

DESCRIPCIÓN

Inicializa un nuevo stateroot (también conocido como "osname") para un sistema operativo. Asegura que los subdirectorios principales de /var (/tmp, /lib, /run y /lock) existan e inicializa el STATEROOT dado como un stateroot de OSTree. Cada ubicación de implementación está compuesta por un único var compartido y un conjunto de implementaciones (chroots).

EJEMPLO

$ ostree admin stateroot-init exampleos

        ostree/deploy/exampleos inicializado como stateroot de OSTree
