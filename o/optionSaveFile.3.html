optionSaveFile(3) Manual del programador optionSaveFile(3)

NOMBRE

optionSaveFile - guarda el estado de las opciones en un archivo

SINOPSIS

#include <tu-opts.h>
cc [...] -o archivo_salida archivo_entrada.c -lopts [...]

void optionSaveFile(tOptions * opts);

DESCRIPCIÓN

Esta rutina guardará el estado del procesamiento de opciones en un archivo. El nombre de ese archivo se puede especificar con el argumento de la opción --save-opts, o añadiendo el atributo rcfile al último atributo homerc. Si no se especificó ningún atributo rcfile, por defecto será .nombre_programarc. Si deseas especificar otro archivo, deberías invocar la macro SET_OPT_SAVE_OPTS(nombre_archivo).

El uso recomendado es el siguiente:

    optionProcess(&progOptions, argc, argv);
    if (quiero_un_lugar_no_estandar_para_esto)
    SET_OPT_SAVE_OPTS("miarchivo");
    optionSaveFile(&progOptions);
opts
descriptor de opciones del programa

ERRORES

Si no se especificó ningún archivo homerc, esta rutina devolverá silenciosamente y no hará nada. Si el archivo de salida no se puede crear o actualizar, se imprimirá un mensaje en stderr y la rutina devolverá.
