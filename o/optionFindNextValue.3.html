optionFindNextValue(3) Manual del programador optionFindNextValue(3)

NOMBRE

optionFindNextValue - encuentra una instancia de opción con valor jerárquico

SINOPSIS

#include <tus-opciones.h>
cc [...] -o archivo_salida archivo_entrada.c -lopciones [...]

const tOptionValue * optionFindNextValue(const tOptDesc * odesc, const tOptionValue * pPrevVal, char const * nombre, char const * valor);

DESCRIPCIÓN

Esta rutina encontrará la siguiente entrada en una opción o configurable de valor anidado. Buscará en la lista y devolverá la siguiente entrada que coincida con los criterios.

odesc
una opción con un tipo de argumento anidado
pPrevVal
la última entrada
nombre
nombre del valor a encontrar
valor
el valor coincidente

VALOR DE RETORNO

una estructura de valor compuesto

ERRORES

El resultado devuelto es NULL y errno se establece:

EINVAL - el pOptValue no apunta a un valor de opción jerárquico válido.

ENOENT - ninguna entrada coincidió con el nombre dado. @end itemize
