org.bluez.MediaFolder(5) Administración del sistema Linux org.bluez.MediaFolder(5)

Nombre

org.bluez.MediaFolder - Documentación de la API de BlueZ D-Bus MediaFolder

Interfaz

Servicio
nombre único (rol de destino) org.bluez (rol de controlador)
Interfaz
org.bluez.MediaFolder1
Ruta de objeto
definible libremente (rol de destino) [prefijo variable]/{hci0,hci1,...}/dev_{BDRADDR}/player# (rol de controlador)

Métodos

objeto Buscar(string valor, dict filtro)

Devuelve un objeto de carpeta que contiene el resultado de la búsqueda.

Para listar los elementos encontrados, utilice el objeto de carpeta devuelto y páselo a CambiarCarpeta.

Posibles errores:

org.bluez.Error.NotSupported
org.bluez.Error.Failed

array{objetos, propiedades} ListarElementos(dict filtro)

Devuelve una lista de los elementos encontrados

Posibles errores:

org.bluez.Error.InvalidArguments
org.bluez.Error.NotSupported
org.bluez.Error.Failed

void CambiarCarpeta(object carpeta)

Cambia la carpeta actual.

Nota: Al cambiar de carpeta, los elementos de la carpeta anterior pueden ser destruidos y tener que ser listados de nuevo, la excepción es la carpeta NowPlaying que siempre debe estar presente mientras el reproductor esté activo.

Posibles errores:

org.bluez.Error.InvalidArguments
org.bluez.Error.NotSupported
org.bluez.Error.Failed

Propiedades

uint32 NumeroDeElementos [solo lectura]

Número de elementos en la carpeta

string Nombre [solo lectura]

Nombre de la carpeta:

Valores posibles:

"/Filesystem/..."
Alcance del sistema de archivos
"/NowPlaying/..."
Alcance de "Reproduciendo ahora"

Nota: La carpeta /NowPlaying podría no aparecer si el reproductor está detenido. Las carpetas creadas por Buscar son virtuales, por lo que una vez que se realiza otra búsqueda o se cambia la carpeta usando CambiarCarpeta, ya no aparecerán.

Filtros

uint32 Inicio
Desplazamiento del primer elemento.

Valor por defecto: 0

uint32 Fin
Desplazamiento del último elemento.

Valor por defecto: NumeroDeElementos

array{string} Atributos
Propiedades del elemento que deben incluirse en la lista.

Valores posibles:

"título", "artista", "álbum", "género", "número-de-pistas", "número", "duración"

Valor por defecto: Todos
