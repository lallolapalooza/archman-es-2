NOMBRE

openssl-ec - Procesamiento de claves EC

SINOPSIS

openssl ec [-help] [-inform DER|PEM|P12|ENGINE] [-outform DER|PEM] [-in nombre_archivo|uri] [-passin arg] [-out nombre_archivo] [-passout arg] [-des] [-des3] [-idea] [-text] [-noout] [-param_out] [-pubin] [-pubout] [-conv_form arg] [-param_enc arg] [-no_public] [-check] [-engine id] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq]

DESCRIPCIÓN

El comando openssl-ec(1) procesa claves EC. Se pueden convertir entre varias formas y sus componentes se pueden imprimir. Nota OpenSSL utiliza el formato de clave privada especificado en 'SEC 1: Elliptic Curve Cryptography' (http://www.secg.org/). Para convertir una clave privada EC de OpenSSL al formato de clave privada PKCS#8, use el comando openssl-pkcs8(1).

OPCIONES

-help
Imprime un mensaje de uso.
-inform DER|PEM|P12|ENGINE
El formato de entrada de la clave; no especificado por defecto. Consulte openssl-format-options(1) para más detalles.
-outform DER|PEM
El formato de salida de la clave; el valor por defecto es PEM. Consulte openssl-format-options(1) para más detalles.

Las claves privadas son de formato SEC1 o PKCS#8. Las claves públicas son un SubjectPublicKeyInfo según se especifica en RFC 3280 de IETF.

-in nombre_archivo|uri
Esto especifica la entrada de la que leer una clave o la entrada estándar si esta opción no se especifica. Si la clave está cifrada, se le pedirá una contraseña.
-out nombre_archivo
Esto especifica el nombre del archivo de salida al que escribir una clave o la salida estándar si no se especifica. Si se configuran opciones de cifrado, se le pedirá una contraseña. El nombre del archivo de salida no debe ser el mismo que el nombre del archivo de entrada.
-passin arg, -passout arg
La fuente de la contraseña para el archivo de entrada y salida. Para más información sobre el formato de arg, consulte openssl-passphrase-options(1).
-des|-des3|-idea
Estas opciones cifran la clave privada con DES, triple DES, IDEA o cualquier otro cifrador soportado por OpenSSL antes de sacarla. Se solicita una contraseña. Si ninguna de estas opciones se especifica, la clave se escribe en texto plano. Esto significa que usar este comando para leer una clave cifrada sin ninguna opción de cifrado puede usarse para eliminar la contraseña de una clave, o configurando las opciones de cifrado puede usarse para añadir o cambiar la contraseña. Estas opciones solo se pueden usar con archivos de salida en formato PEM.
-text
Imprime los componentes y parámetros de la clave pública y privada.
-noout
Esta opción evita la salida de la versión codificada de la clave.
-param_out
Imprime los parámetros de la curva elíptica.
-pubin
Por defecto se lee una clave privada de la entrada. Con esta opción se lee una clave pública en su lugar. Si la entrada no contiene una clave pública sino una clave privada, se usa su parte pública.
-pubout
Por defecto se saca una clave privada. Con esta opción se sacará una clave pública en su lugar. Esta opción se establece automáticamente si la entrada es una clave pública.
-conv_form arg
Esto especifica cómo se convierten los puntos de la curva elíptica en cadenas de octetos. Los valores posibles son: compressed, uncompressed (el valor por defecto) e hybrid. Para más información sobre las formas de conversión de puntos, por favor lea el estándar X9.62. Nota Debido a problemas de patentes, la opción compressed está deshabilitada por defecto para curvas binarias y puede ser habilitada definiendo la macro de preprocesador OPENSSL_EC_BIN_PT_COMP en tiempo de compilación.
-param_enc arg
Esto especifica cómo se codifican los parámetros de la curva elíptica. Los valores posibles son: named_curve, es decir, los parámetros EC se especifican por un OID, o explicit donde los parámetros EC se dan explícitamente (ver RFC 3279 para la definición de las estructuras de parámetros EC). El valor por defecto es named_curve. Nota la alternativa implicitlyCA, según se especifica en RFC 3279, actualmente no está implementada en OpenSSL.
-no_public
Esta opción omite los componentes de la clave pública de la salida de la clave privada.
-check
Esta opción comprueba la consistencia de una clave privada o pública EC.
-engine id
Ver "Opciones de Motor" en openssl(1). Esta opción está obsoleta.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Ver "Opciones de Proveedor" en openssl(1), provider(7), y property(7).

El comando openssl-pkey(1) es capaz de realizar todas las operaciones que este comando puede, así como soportar otros tipos de claves públicas.

EJEMPLOS

La documentación del comando openssl-pkey(1) contiene ejemplos equivalentes a los que se enumeran aquí.

Para cifrar una clave privada usando triple DES:

openssl ec -in key.pem -des3 -out keyout.pem

Para convertir una clave privada de formato PEM a DER:

openssl ec -in key.pem -outform DER -out keyout.der

Para imprimir los componentes de una clave privada a la salida estándar:

openssl ec -in key.pem -text -noout

Para sacar solo la parte pública de una clave privada:

openssl ec -in key.pem -pubout -out pubkey.pem

Para cambiar la codificación de parámetros a explicit:

openssl ec -in key.pem -param_enc explicit -out keyout.pem

Para cambiar la forma de conversión de puntos a compressed:

openssl ec -in key.pem -conv_form compressed -out keyout.pem

VER TAMBIÉN

openssl(1), openssl-pkey(1), openssl-ecparam(1), openssl-dsa(1), openssl-rsa(1)

HISTORIA

La opción -engine fue obsoleta en OpenSSL 3.0.

Las opciones -conv_form y -no_public ya no son compatibles con claves cargadas desde un motor en OpenSSL 3.0.

openssl-ec(1ssl)

NAME

openssl-ec - Elliptic Curve engine

SYNOPSIS

openssl ec [-help] [-inform PEM|DER|NET] [-outform PEM|DER|NET] [-in filename] [-passin arg] [-out filename] [-passout arg] [-text] [-noout] [-pubin] [-pubout] [-conv_form arg] [-check] [-param_enc arg] [-challenge arg] [-primitives] [-engine id] [-provider name] [-provider-ctx ctx] [-propquery propq] [-digest alg]

DESCRIPTION

The openssl ec command is a utility that can be used to manage and process Elliptic Curve keys. It can be used to generate new EC keys, convert them between different formats, and extract public keys from private keys.

It supports various EC key formats, including traditional private and public key formats (PKCS#1, SEC1) and more modern formats like PKCS#8. It can also process keys in different encodings, such as PEM and DER.

The openssl ec command can also be used to perform cryptographic operations using EC keys, such as signing and verification, although these operations are typically performed using higher-level commands like openssl dgst or openssl pkeyutl.

OPTIONS

  • -help: Print a usage message and exit.
  • -inform PEM|DER|NET: Specify the input format.
  • -outform PEM|DER|NET: Specify the output format.
  • -in filename: Read the key from the specified file.
  • -passin arg: The password source for reading encrypted private keys.
  • -out filename: Write the key to the specified file.
  • -passout arg: The password source for writing encrypted private keys.
  • -text: Output the key in a human-readable text format.
  • -noout: Do not output the encoded version of the key.
  • -pubin: Assume the input is a public key.
  • -pubout: Output a public key in the input is a private key.
  • -conv_form arg: Specify the conversion form for the public point (e.g., compressed, uncompressed, hybrid).
  • -check: Check if the private key and corresponding public key are valid.
  • -param_enc arg: Specify the encoding for the parameters (e.g., explicit, named_curve).
  • -challenge arg: Specify a challenge for signature operations.
  • -primitives: Print information about available EC primitives.
  • -engine id: Use a specific engine.
  • -provider name: Use a specific provider.
  • -provider-ctx ctx: Use a specific provider context.
  • -propquery propq: Query properties for selecting algorithms and providers.
  • -digest alg: Use the specified digest algorithm for certain operations.

EXAMPLES

  • Generate a new EC private key and save it to a file: 
    openssl ec -out private_key.pem
  • Convert a DER-encoded private key to PEM format: 
    openssl ec -inform DER -in private_key.der -outform PEM -out private_key.pem
  • Extract the public key from a private key: 
    openssl ec -in private_key.pem -pubout -out public_key.pem
  • Check the validity of a private key and its corresponding public key: 
    openssl ec -in private_key.pem -check

SEE ALSO

openssl(1ssl), openssl-pkey(1ssl), openssl-genpkey(1ssl)

HISTORY

The openssl ec command was first introduced in OpenSSL 0.9.8.
