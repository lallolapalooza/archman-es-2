Paquete: openssl

NOMBRE

openssl-passwd - calcular hashes de contraseñas

SINOPSIS

openssl passwd [-help] [-1] [-apr1] [-aixmd5] [-5] [-6] [-salt cadena] [-in archivo] [-stdin] [-noverify] [-quiet] [-table] [-reverse] [-rand archivos] [-writerand archivo] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq] [contraseña]

DESCRIPCIÓN

Este comando calcula el hash de una contraseña escrita en tiempo de ejecución o el hash de cada contraseña de una lista. La lista de contraseñas se toma del archivo especificado para la opción -in, de stdin para la opción -stdin, o de la línea de comandos, o del terminal en caso contrario.

OPCIONES

-help
Muestra un mensaje de uso.
-1
Utiliza el algoritmo de contraseña BSD 1 basado en MD5 (por defecto).
-apr1
Utiliza el algoritmo apr1 (variante Apache del algoritmo BSD).
-aixmd5
Utiliza el algoritmo AIX MD5 (variante AIX del algoritmo BSD).
-5
-6
Utiliza los algoritmos basados en SHA256 / SHA512 definidos por Ulrich Drepper. Ver https://www.akkadia.org/drepper/SHA-crypt.txt.
-salt cadena
Utiliza la sal especificada. Al leer una contraseña del terminal, esto implica -noverify.
-in archivo
Lee contraseñas del archivo.
-stdin
Lee contraseñas de stdin.
-noverify
No verifica al leer una contraseña del terminal.
-quiet
No muestra advertencias cuando las contraseñas proporcionadas en la línea de comandos se truncan.
-table
En la lista de salida, antepone la contraseña en texto plano y un carácter TAB a cada hash de contraseña.
-reverse
Cuando se usa la opción -table, invierte el orden del texto plano y el hash.
-rand archivos, -writerand archivo
Ver "Opciones de estado aleatorio" en openssl(1) para detalles.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Ver "Opciones de proveedor" en openssl(1), provider(7), y property(7).

EJEMPLOS

% openssl passwd -1 -salt xxxxxxxx password
$1$xxxxxxxx$UYCIxa628.9qXjpQCjM4a.
% openssl passwd -apr1 -salt xxxxxxxx password
$apr1$xxxxxxxx$dxHfLAsjHkDRmG83UXe8K0
% openssl passwd -aixmd5 -salt xxxxxxxx password
xxxxxxxx$8Oaipk/GPKhC64w/YVeFD/

HISTORIAL

La opción -crypt fue eliminada en OpenSSL 3.0.
