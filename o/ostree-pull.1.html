NOMBRE

ostree-pull - Descargar datos de un repositorio remoto

SINOPSIS

ostree pull {REMOTO} [RAMA]

OPCIONES

--commit-metadata-only

Obtener solo los metadatos del commit.

--cache-dir=DIR

Usar un directorio de caché alternativo en DIR.

--disable-fsync

No invocar fsync().

--localcache-repo

Similar a git's clone --reference. Reutilizar el repositorio OSTree proporcionado como caché de objetos local al realizar transferencias HTTP. Puede especificarse varias veces.

--untrusted

No confiar en fuentes locales, verificar sumas de verificación y no enlazar a la fuente.

--disable-static-deltas

No usar deltas estáticos.

--mirror

Escribir refs adecuadas para un espejo, es decir, los refs se almacenan en el directorio heads/ en lugar del directorio remotes/. Esto hace que el repositorio de destino sea adecuado para ser exportado para que otros clientes lo obtengan como un remoto ostree. Si no se especifican refs específicas, se obtendrán todas las refs (el remoto debe tener un archivo de resumen presente).

--subpath=SUBPATH

Obtener solo la subruta proporcionada.

--depth=DEPTH

Recorrer DEPTH padres (-1=infinito) (predeterminado: 0).

--network-retries=N

Especifica cuántas veces se reintentará cada descarga en caso de error (predeterminado: 5).

--disable-retry-on-network-errors

No reintentar en caso de problemas de red, fallar automáticamente en su lugar. (Actualmente solo afecta a libcurl).

--low-speed-limit-bytes=N

La velocidad promedio de transferencia por segundo de una transferencia durante el tiempo establecido a través de 'low-speed-time-seconds' para que libcurl la aborte (predeterminado: 1000).

--low-speed-time-seconds=N

El tiempo en segundos que la velocidad de transferencia debe estar por debajo de la configuración 'low-speed-limit-bytes' para que libcurl la aborte (predeterminado: 30).

--max-outstanding-fetcher-requests=N

La cantidad máxima de conexiones concurrentes permitidas. (predeterminado: 8).

--disable-verify-bindings

Desactivar la verificación de las vinculaciones de metadatos del commit.

DESCRIPCIÓN

Sin la opción --mirror, este comando creará nuevas refs bajo el directorio remotes/REMOTE/ para cada rama obtenida, a menos que ya estén creadas. Dichas refs pueden ser referenciadas por REMOTE:RAMA en subcomandos de ostree (por ejemplo, ostree log origin:exampleos/x86_64/standard).

Este comando puede recuperar solo un commit específico, o llegar a realizar una copia espejo completa del repositorio remoto. Si no se especifica NINGUNA RAMA, se obtienen todas las ramas configuradas.

Una sintaxis especial con el carácter @ permite especificar un commit específico para obtener de una rama. Los casos de uso para esto son algo similares a obtener un git tag específico; uno podría, por ejemplo, guionar una actualización del sistema a una versión conocida como buena, en lugar de la última del proveedor de contenido.

EJEMPLO

$ ostree --repo=repo pull --depth=-1 --mirror nombre_remoto

Realizar una copia espejo completa del remoto. (Esto es probablemente más útil si tu repositorio también está en modo archivo).

$ ostree --repo=repo pull nombre_remoto exampleos/x86_64/standard

Obtener el commit más reciente de exampleos/x86_64/standard.

$ ostree --repo=repo pull nombre_remoto exampleos/x86_64/standard@98ea6e4f216f2fb4b69fff9b3a44842c38686ca685f3f55dc48c5d3fb1107be4

Descargar el commit específico que comienza con 98ea6e como si fuera el commit más reciente para exampleos/x86_64/standard.
