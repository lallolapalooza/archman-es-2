Nombre

org.bluez.obex.ObjectPush - Documentación de la API OBEX ObjectPush de BlueZ D-Bus

Interfaz

Servicio
org.bluez.obex
Interfaz
org.bluez.obex.ObjectPush1
Ruta de objeto
[Ruta del objeto de sesión]

Métodos

objeto, dicc SendFile(string archivo_origen)

Envía un archivo local al dispositivo remoto.

La ruta devuelta representa la transferencia recién creada, que debe usarse para averiguar si el contenido se ha transferido correctamente o si la operación falla.

Las propiedades de esta transferencia también se devuelven junto con la ruta del objeto, para evitar una llamada a GetProperties. Consulte org.bluez.obex.Transfer(5) para ver la lista posible de propiedades.

Errores posibles:

org.bluez.obex.Error.ArgumentosInvalidos
org.bluez.obex.Error.Fallo

objeto, dicc PullBusinessCard(string archivo_destino)

Solicita la tarjeta de visita de un dispositivo remoto y la almacena en el archivo local.

Si se proporciona un archivo de destino vacío, se generará automáticamente un nombre para el archivo temporal.

La ruta devuelta representa la transferencia recién creada, que debe usarse para averiguar si el contenido se ha transferido correctamente o si la operación falla.

Las propiedades de esta transferencia también se devuelven junto con la ruta del objeto, para evitar una llamada a GetProperties. Consulte org.bluez.obex.Transfer(5) para ver la lista posible de propiedades.

Errores posibles:

org.bluez.obex.Error.ArgumentosInvalidos
org.bluez.obex.Error.Fallo

objeto, dicc ExchangeBusinessCards(string archivo_cliente, string archivo_destino)

Envía la tarjeta de visita del cliente al dispositivo remoto y luego recupera la tarjeta de visita remota y la almacena en un archivo local.

Si se proporciona un archivo de destino vacío, se generará automáticamente un nombre para el archivo temporal.

La ruta devuelta representa la transferencia recién creada, que debe usarse para averiguar si el contenido se ha transferido correctamente o si la operación falla.

Las propiedades de esta transferencia también se devuelven junto con la ruta del objeto, para evitar una llamada a GetProperties. Consulte org.bluez.obex.Transfer(5) para ver la lista posible de propiedades.

Errores posibles:

org.bluez.obex.Error.ArgumentosInvalidos
org.bluez.obex.Error.Fallo
