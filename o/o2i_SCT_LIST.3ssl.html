o2i_SCT_LIST(3ssl)

Paquete: openssl

Licencias: Apache-2.0

O2I_SCT_LIST(3ssl) OpenSSL O2I_SCT_LIST(3ssl)

NOMBRE

o2i_SCT_LIST, i2o_SCT_LIST, o2i_SCT, i2o_SCT - decodifica y codifica listas de Marcas de Certificado Firmadas en formato de cable TLS

SINOPSIS

#include <openssl/ct.h>
STACK_OF(SCT) *o2i_SCT_LIST(STACK_OF(SCT) **a, const unsigned char **pp,
                            size_t len);
int i2o_SCT_LIST(const STACK_OF(SCT) *a, unsigned char **pp);
SCT *o2i_SCT(SCT **psct, const unsigned char **in, size_t len);
int i2o_SCT(const SCT *sct, unsigned char **out);

DESCRIPCIÓN

Las funciones SCT_LIST y SCT son muy similares a la familia de funciones i2d y d2i, excepto que convierten desde y hacia el formato de cable TLS, tal como se describe en RFC 6962. Consulte d2i_SCT_LIST(3) para más información sobre cómo se tratan los parámetros y los valores de retorno.

VALORES DE RETORNO

Todas las funciones tienen valores de retorno consistentes con los indicados para d2i_SCT_LIST(3) y i2d_SCT_LIST(3).

VER TAMBIÉN

ct(7), d2i_SCT_LIST(3), i2d_SCT_LIST(3)

HISTORIAL

Estas funciones se añadieron en OpenSSL 1.1.0.
