Paquete: ostree

Licencias: LGPL-2.0-or-later

OSTREE ADMIN(1) ostree admin OSTREE ADMIN(1)

NOMBRE

ostree-admin - Usa uno de los comandos de ostree admin

SINOPSIS

ostree admin {SUBCOMANDO}

DESCRIPCIÓN

Usa subcomandos de ostree admin.

SUBCOMANDOS

•cleanup
•config-diff
•deploy
•init-fs
•instutil
•os-init
•pin
•post-copy
•set-origin
•status
•switch
•undeploy
•unlock
•upgrade

Consulta las páginas del manual para cada subcomando de admin usando, por ejemplo:

$ man ostree-admin cleanup

OPCIONES

--help, -h

Ayuda de uso

--sysroot="RUTA"

Crea un nuevo OSTree sysroot en RUTA

--print-current-dir

Imprime la ruta completa al directorio de despliegue para el despliegue actualmente activo en el sysroot especificado a la salida estándar. Esto es incompatible con la especificación de un subcomando.
