NOMBRE

org.freedesktop.portable1 - La interfaz D-Bus de systemd-portabled

INTRODUCCIÓN

systemd-portabled.service(8) es un servicio del sistema que puede utilizarse para adjuntar, desadjuntar e inspeccionar servicios portátiles. Esta página describe la interfaz D-Bus.

EL OBJETO MANAGER

El servicio expone las siguientes interfaces en el objeto Manager en el bus:

node /org/freedesktop/portable1 {
  interface org.freedesktop.portable1.Manager {
    methods:
      GetImage(in  s image,
               out o object);
      ListImages(out a(ssbtttso) images);
      GetImageOSRelease(in  s image,
                        out a{ss} os_release);
      GetImageMetadata(in  s image,
                       in  as matches,
                       out s image,
                       out ay os_release,
                       out a{say} units);
      GetImageMetadataWithExtensions(in  s image,
                                     in  as extensions,
                                     in  as matches,
                                     in  t flags,
                                     out s image,
                                     out ay os_release,
                                     out a{say} extensions,
                                     out a{say} units);
      GetImageState(in  s image,
                    out s state);
      GetImageStateWithExtensions(in  s image,
                                  in  as extensions,
                                  in  t flags,
                                  out s state);
      AttachImage(in  s image,
                  in  as matches,
                  in  s profile,
                  in  b runtime,
                  in  s copy_mode,
                  out a(sss) changes);
      AttachImageWithExtensions(in  s image,
                                in  as extensions,
                                in  as matches,
                                in  s profile,
                                in  s copy_mode,
                                in  t flags,
                                out a(sss) changes);
      DetachImage(in  s image,
                  in  b runtime,
                  out a(sss) changes);
      DetachImageWithExtensions(in  s image,
                                in  as extensions,
                                in  t flags,
                                out a(sss) changes);
      ReattachImage(in  s image,
                    in  as matches,
                    in  s profile,
                    in  b runtime,
                    in  s copy_mode,
                    out a(sss) changes_removed,
                    out a(sss) changes_updated);
      ReattachImageWithExtensions(in  s image,
                                  in  as extensions,
                                  in  as matches,
                                  in  s profile,
                                  in  s copy_mode,
                                  in  t flags,
                                  out a(sss) changes_removed,
                                  out a(sss) changes_updated);
      RemoveImage(in  s image);
      MarkImageReadOnly(in  s image,
                        in  b read_only);
      SetImageLimit(in  s image,
                    in  t limit);
      SetPoolLimit(in  t limit);
    properties:
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly s PoolPath = '...';
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly t PoolUsage = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly t PoolLimit = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly as Profiles = ['...', ...];
  };
  interface org.freedesktop.DBus.Peer { ... };
  interface org.freedesktop.DBus.Introspectable { ... };
  interface org.freedesktop.DBus.Properties { ... };
};

Métodos

GetImage() puede usarse para obtener la ruta del objeto de imagen de la imagen con el nombre especificado.

ListImages() devuelve una matriz de todas las imágenes conocidas actualmente. Las estructuras de la matriz consisten en los siguientes campos: nombre de la imagen, tipo, indicador de solo lectura, hora de creación, hora de modificación, espacio actual en disco, uso y ruta del objeto de imagen.

GetImageOSRelease() recupera la información de versión del SO de una imagen. Este método devuelve una matriz de pares clave-valor leídos del archivo os-release(5) en la imagen y es útil para identificar el sistema operativo utilizado en un servicio portátil.

GetImageMetadata() recupera metadatos asociados con una imagen. Este método devuelve el nombre de la imagen, el contenido de os-release(5) de la imagen en forma de una matriz (transmisible) de bytes y una lista de unidades portátiles contenidas en la imagen, en forma de una cadena (nombre de unidad) y una matriz de bytes con el contenido.

GetImageMetadataWithExtensions() recupera metadatos asociados con una imagen. Este método es un superconjunto de GetImageMetadata() con la adición de una lista de extensiones como parámetro de entrada, que se superpusieron a la imagen principal a través de AttachImageWithExtensions(). Se devuelven la ruta de cada extensión y una matriz de bytes con el contenido del archivo de versión respectivo, una estructura de este tipo por cada extensión nombrada en los argumentos de entrada.

GetImageState() recupera el estado de la imagen como una de las siguientes cadenas:

•detached
•attached
•attached-runtime
•enabled
•enabled-runtime
•running
•running-runtime

GetImageStateWithExtensions() es un superconjunto de GetImageState(), con soporte adicional para una lista de extensiones como parámetros de entrada, lo cual es necesario para consultar el estado en caso de que la imagen se haya adjuntado de esa manera particular. El parámetro flag no se usa actualmente y está reservado para fines futuros.

AttachImage() adjunta una imagen portátil al sistema. Este método toma una ruta o nombre de imagen, una lista de cadenas que se usarán para buscar archivos de unidad dentro de la imagen (coincidencias parciales o completas), una cadena que indica qué perfil portátil usar para la imagen (ver la propiedad Profiles para una lista de perfiles disponibles), un booleano que indica si adjuntar la imagen solo para la sesión de arranque actual y una cadena que representa el modo de copia preferido (si copiar la imagen o simplemente crear un enlace simbólico) con los siguientes valores posibles:

•(vacío)
•copy
•symlink
•mixed

Si se pasa una cadena vacía, los archivos de configuración de perfil de seguridad e imágenes se enlazarán simbólicamente, mientras que los archivos de unidad se copiarán, copy copiará, symlink preferirá enlazar si es posible (por ejemplo, una unidad tiene que ser copiada de una imagen), y mixed preferirá enlazar los recursos propiedad del SO (por ejemplo, el perfil portátil ubicado dentro del árbol /usr/ del host) pero copiará los recursos propiedad de la imagen portátil (por ejemplo, los archivos de unidad y las imágenes). Este método devuelve la lista de cambios aplicados al sistema (por ejemplo, qué unidad se agregó y ahora está disponible como un servicio del sistema). Cada cambio se representa como un triplete de cadenas: el tipo de cambio aplicado, la ruta en la que se aplicó y la fuente (si la hay). El tipo de cambio aplicado será uno de los siguientes valores posibles:

•copy
•symlink
•write
•mkdir

Tenga en cuenta que una imagen no se puede adjuntar si una unidad que contiene ya está presente en el sistema. Tenga en cuenta que este método devuelve solo después de que todas las operaciones listadas se hayan completado, y debido a las E/S involucradas, puede llevar algún tiempo.

En lugar de la ruta de la imagen, se puede especificar un directorio con la versión ".v/", consulte systemd.v(7) para obtener detalles.

En lugar de la ruta del directorio, se puede especificar un directorio con la versión ".v/", consulte systemd.v(7) para obtener detalles.

AttachImageWithExtensions() adjunta una imagen portátil al sistema. Este método es un superconjunto de AttachImage() con la adición de una lista de extensiones como parámetro de entrada, que se superpondrán a la imagen principal. Cuando se utiliza este método, la desvinculación debe realizarse pasando los mismos argumentos a través del método DetachImageWithExtensions(). Para más detalles sobre esta funcionalidad, consulte la entrada MountImages= en THE MANAGER OBJECT

El servicio expone la siguiente interfaz en el objeto Manager en el bus:

node /org/freedesktop/portable1 {
  interface org.freedesktop.portable1.Manager {
    methods:
      GetOSRelease(out a{ss} os_release);
      GetImageState(in  s name,
                    out s state);
      GetImageStateWithExtensions(in  s name,
                                  in  as extensions,
                                  in  t flags,
                                  out s state);
      AttachImage(in  s name,
                  in  as matches,
                  in  s profile,
                  in  b runtime,
                  in  s copy_mode,
                  out a(sss) changes);
      AttachImageWithExtensions(in  s name,
                                in  as extensions,
                                in  as matches,
                                in  s profile,
                                in  s copy_mode,
                                in  t flags,
                                out a(sss) changes);
      DetachImage(in  s name,
                  in  b runtime,
                  out a(sss) changes);
      DetachImageWithExtensions(in  s name,
                                in  as extensions,
                                in  t flags,
                                out a(sss) changes);
      ReattachImage(in  s name,
                    in  as matches,
                    in  s profile,
                    in  b runtime,
                    in  s copy_mode,
                    out a(sss) changes_removed,
                    out a(sss) changes_updated);
      ReattachImageWithExtensions(in  s name,
                                  in  as extensions,
                                  in  as matches,
                                  in  s profile,
                                  in  s copy_mode,
                                  in  t flags,
                                  out a(sss) changes_removed,
                                  out a(sss) changes_updated);
      RemoveImage(in s name);
      MarkImageReadOnly(in s name,
                        in b read_only);
      SetPoolLimit(in t limit);
      SetImageLimit(in s name,
                    in t limit);
      GetImage(in s name,
               out o object_path);
    properties:
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly t PoolUsage = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly t PoolLimit = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly as Profiles = ...;
  };
  interface org.freedesktop.DBus.Peer { ... };
  interface org.freedesktop.DBus.Introspectable { ... };
  interface org.freedesktop.DBus.Properties { ... };
};

Methods

AttachImage() attaches a portable image. This method takes an image name, a list of patterns to select which units from the image should be attached, an optional profile name to use, and a boolean indicating whether the image should be attached only for the current boot session or persistently. This method returns the list of changes applied to the system (for example, which unit was added and is now available as a system service). Each change is represented as a triplet of strings: the type of change applied, the path on which it was applied, and the source (if any). The type of change applied will be one of the following possible values:

•link

AttachImageWithExtensions() attaches a portable image to the system. This method is a superset of AttachImage() with the addition of a list of extensions as input parameter, which will be overlaid on top of the main image. For more details on this functionality, see the MountImages= entry on systemd.exec(5) and systemd-sysext(8).

DetachImage() detaches a portable image from the system. This method takes an image name and a boolean indicating whether the image to detach was attached only for the current boot session or persistently. This method returns the list of changes applied to the system (for example, which unit was removed and is no longer available as a system service). Each change is represented as a triplet of strings: the type of change applied, the path on which it was applied, and the source (if any). The type of change applied will be one of the following possible values:

•unlink

Note that an image cannot be detached if a unit that it contains is running. Note that this method returns only after all the listed operations are completed, and due to the I/O involved it might take some time.

DetachImageWithExtensions() detaches a portable image from the system. This method is a superset of DetachImage() with the addition of a list of extensions as input parameter, which were overlaid on top of the main image via AttachImageWithExtensions().

ReattachImage() combines the effects of the AttachImage() method and the DetachImage() method. The difference is that it is allowed to reattach an image while one or more of its units are running. The reattach operation will fail if no matching image is attached. The input parameters match the AttachImage() method, and the return parameters are the combination of the return parameters of the DetachImage() method (first array, units that were removed) and the AttachImage() method (second array, units that were updated or added).

ReattachImageWithExtensions() reattaches a portable image to the system. This method is a superset of ReattachImage() with the addition of a list of extensions as input parameter, which will be overlaid on top of the main image. For more details on this functionality, see the MountImages= entry on systemd.exec(5) and systemd-sysext(8).

RemoveImage() removes the image with the specified name.

MarkImageReadOnly() toggles the read-only flag of an image.

SetPoolLimit() sets an overall quota limit on the pool of images.

SetImageLimit() sets a per-image quota limit.

The AttachImageWithExtensions(), DetachImageWithExtensions() and ReattachImageWithExtensions() methods take in options as flags instead of booleans to allow for extendability. SD_SYSTEMD_PORTABLE_FORCE_ATTACH will bypass the safety checks that ensure the units are not running while the image is attached or detached. SD_SYSTEMD_PORTABLE_FORCE_EXTENSION will bypass the check that ensures the extension-release.NAME file in the extension image matches the image name. They are defined as follows:

#define SD_SYSTEMD_PORTABLE_RUNTIME            (UINT64_C(1) << 0)
#define SD_SYSTEMD_PORTABLE_FORCE_ATTACH       (UINT64_C(1) << 1)
#define SD_SYSTEMD_PORTABLE_FORCE_EXTENSION    (UINT64_C(1) << 2)

Properties

PoolPath especifica la ruta del sistema de archivos donde se escriben las imágenes.

PoolUsage especifica el tamaño de uso actual del pool de imágenes en bytes.

PoolLimit especifica el límite de tamaño del pool de imágenes en bytes.

Profiles especifica los perfiles de tiempo de ejecución disponibles para los servicios portátiles.

             out a(sss) changes);

                           in  as matches,
                           in  s profile,
                           in  s copy_mode,

Methods

Los siguientes métodos implementan la misma operación que los métodos respectivos del objeto Manager (ver arriba). Sin embargo, estos métodos operan sobre el objeto de imagen y, por lo tanto, no toman un parámetro de nombre de imagen. Invocar los métodos directamente en el objeto Manager tiene la ventaja de no requerir una llamada a GetImage() para obtener el objeto de imagen para un nombre de imagen específico. Llamar a los métodos en el objeto Manager es, por lo tanto, una optimización de viaje redondo. Lista de métodos:

•GetOSRelease()
•GetMetadata()
•GetMetadataWithExtensions()
•GetState()
•Attach()
•AttachWithExtensions()
•Detach()
•DetachWithExtensions()
•Reattach()
•ReattachWithExtensions()
•Remove()
•MarkReadOnly()
•SetLimit()

Properties

Name especifica el nombre de la imagen.

Path especifica la ruta del sistema de archivos donde se almacena la imagen.

Type especifica el tipo de imagen.

ReadOnly especifica si la imagen es de solo lectura.

CreationTimestamp especifica la marca de tiempo de creación de la imagen.

ModificationTimestamp especifica la marca de tiempo de modificación de la imagen.

Usage especifica el uso del disco de la imagen.

Limit especifica el límite de uso del disco de la imagen.

UsageExclusive especifica el uso del disco de la imagen (exclusivo).

LimitExclusive especifica el límite de uso del disco de la imagen (exclusivo).
