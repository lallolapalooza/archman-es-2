NOMBRE

ostree-commit - Realizar un commit de una nueva revisión

SINOPSIS

ostree commit [OPCIONES...] --branch= {RAMA} [RUTA]

DESCRIPCIÓN

Permite realizar un commit de cambios a una rama. Se requiere la especificación de la rama. El comando imprimirá el checksum de un commit exitoso.

OPCIONES

--subject, -s="ASUNTO"

Asunto de una línea. (opcional)

--body, -m="CUERPO"

Descripción completa. (opcional)

--body-file, -F="ARCHIVO"

Descripción completa del commit desde un archivo. (opcional)

--editor, -e

Abre un editor de texto para la descripción del commit. Usará OSTREE_EDITOR, VISUAL, EDITOR o vi, en orden descendente de preferencia. El commit se abortará si el mensaje se deja vacío.

--branch, -b="RAMA"

Rama. Requerido, a menos que se proporcione --orphan.

--parent="COMMIT"

Checksum del padre o "none" para usar explícitamente sin padre. Si no se especifica, se usará RAMA como padre (sin padre en caso de que RAMA no exista).

--tree="dir=RUTA" o "tar=ARCHIVO_TAR" o "ref=COMMIT"

Superpone el argumento dado como un árbol. Al realizar un commit de un archivo, ARCHIVO_TAR puede especificarse como - para leer el archivo desde la entrada estándar.

--base="REV"

Comienza desde el contenido de un commit. Esto difiere de --tree=ref=REV en que no se aplican modificadores de commit. Esto es generalmente lo que se desea al crear un commit derivado. Esto también se usa para --selinux-policy-from-base.

--add-metadata-string="CLAVE=VALOR"

Añade un par clave/valor a los metadatos. Se puede especificar múltiples veces.

--add-metadata="CLAVE=VALOR"

Añade un par clave/valor a los metadatos, donde CLAVE es una cadena, y VALOR está formateado con g_variant_parse(). Se puede especificar múltiples veces.

--keep-metadata="CLAVE"

Mantiene la CLAVE de metadatos y su VALOR asociado del padre. Se puede especificar múltiples veces.

--add-detached-metadata-string="CLAVE=VALOR"

Añade un par clave/valor a metadatos desvinculados.

--owner-uid="UID"

Establece el ID de usuario de propiedad del archivo.

--owner-gid="GID"

Establece el ID de grupo de propiedad del archivo.

--no-xattrs

No importar atributos extendidos.

--selinux-labeling-epoch0 | 1

Cuando el etiquetado SELinux está habilitado, la época 1 asegura que /usr/etc se etiquete como si fuera /etc.

--bootable

Inyecta metadatos estándar para un árbol de sistema de archivos Linux arrancable.

--link-checkout-speedup

Optimiza para commits de árboles compuestos por enlaces duros en el repositorio.

--tar-autocreate-parents

Al cargar archivos tar, crea automáticamente directorios padre según sea necesario.

--skip-if-unchanged

Si los contenidos no han cambiado desde el commit anterior, no hacer nada.

--consume

Al hacer un commit desde un directorio local (es decir, no un archivo o --tree=ref), asume la propiedad del contenido. Esto puede simplemente implicar eliminarlo, pero si es posible, el contenido puede ser renombrado al repositorio en lugar de crear una nueva copia.

--statoverride="RUTA"

Archivo que contiene la lista de modificaciones para hacer permisos (modo de archivo en decimal, seguido de un espacio, seguido de la ruta del archivo). El modo especificado se combina con el modo original del archivo mediante una operación OR, a menos que vaya precedido por "=".

--skip-list="RUTA"

Archivo que contiene la lista de rutas de archivos a omitir (una ruta por línea).

--table-output

Muestra más información en formato CLAVE: VALOR.

--generate-sizes

Genera información de tamaño junto con los metadatos del commit.

--gpg-sign="ID-CLAVE"

ID de Clave GPG con la que firmar el commit (si se tiene GPGME - GNU Privacy Guard Made Easy).

--gpg-homedir="DIR-CASA"

Directorio principal de GPG a usar al buscar keyrings (si se tiene GPGME - GNU Privacy Guard Made Easy).

--timestamp="TIMESTAMP"

Anula la marca de tiempo del commit a TIMESTAMP.

--orphan

Crea un commit sin escribir en una referencia (rama).

--fsync="POLITICA"

POLITICA es un booleano que especifica si se debe usar fsync o no. Por defecto es verdadero.

-s, --sign-type

Usa un motor de firma particular. Actualmente disponibles tipos de firma ed25519, spki y dummy. El valor predeterminado es ed25519.

--sign-from-file="RUTA"

Esto leerá una clave (correspondiente al --sign-type proporcionado desde la ruta dada. La codificación de la clave depende del motor de firma. Para ed25519 la clave debe estar codificada en base64, para spki debe estar en formato PEM, y para dummy debe ser una cadena ASCII.

--sign="ID-CLAVE"

En código nuevo, evita usar esto ya que pasar claves privadas a través de argumentos de línea de comandos es propenso a fugas en registros y listados de procesos.

El ID-CLAVE es:

para ed25519 y spki:

clave secreta codificada en base64 para firmar el commit.

para dummy:

cadena ASCII utilizada como clave secreta.

EJEMPLO

$ ostree commit --branch=mi-rama --subject="Primer commit"
