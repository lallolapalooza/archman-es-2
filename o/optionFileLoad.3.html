NOMBRE

optionFileLoad - Carga los archivos de configuración localizables, en orden

SINOPSIS

#include <tu-opts.h>
cc [...] -o archivo_salida archivo_entrada.c -lopts [...]

int optionFileLoad(tOptions * opts, char const * prog);

DESCRIPCIÓN

Esta función busca en todos los directorios especificados un archivo de configuración (archivo "rc" o archivo "ini") y procesa cualquier archivo encontrado dos veces. La primera vez, se procesan en orden inverso (el último archivo primero). En ese momento, solo se procesan los configurables de "acción inmediata". Por ejemplo, si el último archivo nombrado especifica no procesar más archivos de configuración, entonces no se procesarán más archivos de configuración. Tal opción en el directorio nombrado primero no tendrá efecto.

Una vez que se han manejado los configurables de acción inmediata, los directorios se manejan en orden normal y ascendente. De esta manera, los archivos de configuración posteriores pueden anular la configuración de los archivos de configuración anteriores.

Consulte la documentación de AutoOpts para una discusión exhaustiva del formato del archivo de configuración.

Los archivos de configuración no encontrados o no descifrables se ignoran simplemente.

opts
descriptor de opciones del programa
prog
nombre del programa

VALOR DE RETORNO

0 -> ÉXITO, -1 -> FALLO

ERRORES

Devuelve el valor "-1" si el descriptor de opciones del programa está desactualizado o es indescifrable. De lo contrario, siempre se devolverá el valor "0".
