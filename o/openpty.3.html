openpty(3) Manual de funciones de la biblioteca openpty(3)

NOMBRE

openpty, login_tty, forkpty - funciones de utilidad de terminal

BIBLIOTECA

Biblioteca de utilidades del sistema (libutil, -lutil)

SINOPSIS

#include <pty.h>
int openpty(int *amaster, int *aslave, char *name,
              const struct termios *termp,
              const struct winsize *winp);
pid_t forkpty(int *amaster, char *name,
              const struct termios *termp,
              const struct winsize *winp);
#include <utmp.h>
int login_tty(int fd);

DESCRIPCIÓN

La función openpty() busca un pseudoterminal disponible y devuelve descriptores de archivo para el maestro y el esclavo en amaster y aslave. Si name no es NULL, el nombre de archivo del esclavo se devuelve en name. Si termp no es NULL, los parámetros de terminal del esclavo se establecerán a los valores en termp. Si winp no es NULL, el tamaño de la ventana del esclavo se establecerá a los valores en winp.

La función login_tty() se prepara para un inicio de sesión en la terminal referida por el descriptor de archivo fd (que puede ser un dispositivo de terminal real, o el esclavo de un pseudoterminal como el devuelto por openpty()) creando una nueva sesión, haciendo que fd sea la terminal de control para el proceso que llama, estableciendo fd para que sean los flujos de entrada, salida y error estándar del proceso actual, y cerrando fd.

La función forkpty() combina openpty(), fork(2) y login_tty() para crear un nuevo proceso que opera en un pseudoterminal. Se devuelve un descriptor de archivo que se refiere al lado maestro del pseudoterminal en amaster. Si name no es NULL, el búfer al que apunta se utiliza para devolver el nombre de archivo del esclavo. Los argumentos termp y winp, si no son NULL, determinarán los atributos de terminal y el tamaño de la ventana del lado esclavo del pseudoterminal.

VALOR DE RETORNO

Si una llamada a openpty(), login_tty() o forkpty() no tiene éxito, se devuelve -1 y errno se establece para indicar el error. De lo contrario, openpty(), login_tty() y el proceso hijo de forkpty() devuelven 0, y el proceso padre de forkpty() devuelve el ID del proceso hijo.

ERRORES

openpty() falla si:

ENOENT
No hay terminales disponibles.

login_tty() falla si ioctl(2) falla al establecer fd como la terminal de control del proceso que llama.

forkpty() falla si falla openpty() o fork(2).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
forkpty (), openpty () Seguridad de hilos MT-Safe locale
login_tty () Seguridad de hilos MT-Unsafe race:ttyname

ESTANDARES

BSD.

HISTORIA

Los modificadores const se añadieron a los argumentos de puntero de estructura de openpty() y forkpty() en glibc 2.8.

Antes de glibc 2.0.92, openpty() devuelve descriptores de archivo para un par de pseudoterminales BSD; desde glibc 2.0.92, primero intenta abrir un par de pseudoterminales UNIX 98, y retrocede a abrir un par de pseudoterminales BSD si falla.

ERRORES CONOCIDOS

Nadie sabe cuánto espacio debe reservarse para name. Por lo tanto, llamar a openpty() o forkpty() con name no NULL puede no ser seguro.

VER TAMBIÉN

fork(2), ttyname(3), pty(7)
