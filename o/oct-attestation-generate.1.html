NOMBRE

oct-attestation-generate - Generar declaración de atestación para una de las ranuras de clave en la tarjeta

SINOPSIS

oct attestation generate <-c|--card> <-k|--key> [-p|--user-pin] [-h|--help]

DESCRIPCIÓN

Generar declaración de atestación para una de las ranuras de clave en la tarjeta

Una declaración de atestación solo se puede generar para ranuras de clave que contienen claves generadas por la tarjeta. Ver 'oct admin generate' y 'oct status -v'.

OPCIONES

-c, --card=identificador de tarjeta
Identificador de la tarjeta a utilizar
-k, --key=Ranura de clave
Ranura de clave a utilizar

[posibles valores: SIG, DEC, AUT]

-p, --user-pin=Archivo PIN de usuario
Opcionalmente, obtener el PIN de usuario de un archivo
-h, --help
Imprimir ayuda (ver un resumen con '-h')
