NOMBRE

ostree-summary - Regenera o visualiza el archivo de metadatos de resumen

SINOPSIS

ostree summary [--gpg-sign=KEYID] [--gpg-homedir=HOMEDIR] [--sign=KEYID] [--sign-type=ENGINE] {--update} [--add-metadata=CLAVE=VALOR...]

ostree summary {--view | --raw}

DESCRIPCIÓN

El archivo de resumen es una forma opcional de metadatos de repositorio de alto nivel que describe las ramas disponibles. Necesita ser regenerado manualmente después de una serie de commits. Entre otras cosas, esto permite actualizar atómicamente múltiples commits.

OPCIONES

--update,-u

Actualiza el archivo de resumen. Esta opción se puede combinar con --add-metadata para añadir campos de metadatos al resumen.

Si el repositorio tiene un ID de colección configurado, la rama ostree-metadata para ese ID de colección también se actualizará con un nuevo commit que contiene los metadatos dados, el cual será firmado si el archivo de resumen está firmado.

--add-metadata,-m=CLAVE=VALOR

Especifica un campo de metadatos adicional para añadir al resumen. Debe estar en el formato CLAVE=VALOR o como dos argumentos separados. Las claves deben ser nombradas para su organización o repositorio usando un prefijo de punto. Los valores deben estar en formato de texto GVariant. Por ejemplo, exampleos.end-of-life "@t 1445385600". Esta opción se puede usar múltiples veces.

--view,-v

Visualiza el contenido del archivo de resumen en un formato legible por humanos.

--raw

Visualiza los bytes brutos del archivo de resumen.

--gpg-sign=KEYID

ID de clave GPG para firmar el resumen.

--gpg-homedir=HOMEDIR

Directorio principal de GPG a usar al buscar llaveros.

--sign-type=ENGINE

Usa un motor de firma particular. Actualmente los tipos de firma disponibles son ed25519 y dummy. El valor predeterminado es ed25519.

--sign="KEY-ID"

Aquí KEY-ID es:

para ed25519:

Clave secreta codificada en base64 para firmar el commit.

para dummy:

Cadena de texto ASCII utilizada como clave secreta.

EJEMPLOS

$ ostree summary -u

$ ostree summary -u -m key="'value'"

$ ostree summary -v
