NOMBRE

ostree-admin-lock-finalization - Cambia si el despliegue preparado se pondrá en cola para el próximo arranque

SINOPSIS

ostree admin lock-finalization [OPCIONES...]

DESCRIPCIÓN

Este comando requiere un despliegue preparado. Por defecto, este comando asegura que el despliegue se establecerá en un estado de "finalización bloqueada", lo que significa que no se pondrá en cola para el próximo arranque por defecto.

Esto es lo mismo que el argumento --lock-finalization para ostree admin deploy, que es la forma recomendada de usar esta característica de manera libre de condiciones de carrera.

Sin embargo, más comúnmente, se usará el argumento --unlock de este comando para desbloquear posteriormente un despliegue que estaba bloqueado para su finalización.

OPCIONES

--sysroot="RUTA"

Ruta al sistema a utilizar en lugar del actual.

--unlock,-u

Desbloquea el estado de finalización del despliegue.
