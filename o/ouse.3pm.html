ouse(3pm)

Paquete: perl-mouse

Licencias: PerlArtistic, GPL

ouse(3pm) Documentación de Perl contribuida por el usuario ouse(3pm)

NOMBRE

ouse - azúcar sintáctico para facilitar las líneas de comando de Mouse

SINOPSIS

# crear una clase Mouse sobre la marcha ...
perl -Mouse=Foo -e 'has bar => ( is=>q[ro], default => q[baz] ); print Foo->new->bar' # imprime baz
# carga una clase existente (Mouse o no-Mouse)
# y reabre la definición del paquete para facilitar
# la depuración/introspección
perl -Mouse=+My::Class -e 'print join ", " => __PACKAGE__->meta->get_method_list'

DESCRIPCIÓN

ouse.pm es un simple filtro de fuente que añade "package $name; use Mouse;" al principio de tu script y se creó enteramente porque escribir perl "-e'package Foo; use Mouse; ...'" me molestaba... especialmente después de acostumbrarme a tener "-Moose" para Moose.

INTERFAZ

"ouse" proporciona un único método y es llamado automáticamente por perl:

"oose->import()">
Pasa un nombre de paquete para importar que será utilizado por el filtro de fuente.

DEPENDENCIAS

Necesitarás Filter::Simple y eventualmente Mouse

INCOMPATIBILIDADES

Ninguna reportada. Pero es un filtro de fuente y podría tener problemas allí.

VER TAMBIÉN

oose para "perl -Moose -e '...'"
