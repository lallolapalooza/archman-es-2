int LIBMTP_Copy_Object (LIBMTP_mtpdevice_t * device, uint32_t object_id, uint32_t storage_id, uint32_t parent_id)

La función copia un objeto de una ubicación en un dispositivo a otra ubicación.

La semántica de copiar una carpeta no está definida en la especificación, pero parece hacer lo correcto cuando se prueba (aunque los dispositivos que implementan esta operación son raros).

Tenga en cuenta que copiar un objeto puede llevar una cantidad de tiempo considerable. MTP no proporciona ningún tipo de mecanismo de progreso, por lo que la operación simplemente se bloqueará durante la duración.

Parámetros

device un puntero al dispositivo donde existe el objeto.
object_id el objeto a copiar.
storage_id el ID del almacenamiento de destino.
parent_id el ID del objeto padre de destino (carpeta). Si el destino es la raíz del almacenamiento, pase '0'.

Retorna

0 si tiene éxito, cualquier otro valor significa fallo.

int LIBMTP_Delete_Object (LIBMTP_mtpdevice_t * device, uint32_t object_id)

Esta función elimina un único archivo, pista, lista de reproducción, carpeta o cualquier otro objeto del dispositivo MTP, identificado por el ID del objeto.

Si elimina una carpeta, no hay garantía de que el dispositivo elimine realmente todos los archivos que estaban en esa carpeta; más bien, se espera que no se eliminen y que aparezcan en las listas de objetos con el padre establecido en un ID de objeto inexistente. La forma segura de hacer esto es eliminar recursivamente todos los archivos (y carpetas) contenidos en la carpeta, y luego la carpeta misma.

Parámetros

device un puntero al dispositivo del que eliminar el objeto.
object_id el objeto a eliminar.

Retorna

0 si tiene éxito, cualquier otro valor significa fallo.

int LIBMTP_Move_Object (LIBMTP_mtpdevice_t * device, uint32_t object_id, uint32_t storage_id, uint32_t parent_id)

La función mueve un objeto de una ubicación en un dispositivo a otra ubicación.

La semántica de mover una carpeta no está definida en la especificación, pero parece hacer lo correcto cuando se prueba (aunque los dispositivos que implementan esta operación son raros).

Tenga en cuenta que mover un objeto puede llevar una cantidad de tiempo considerable, particularmente si se mueve entre almacenamientos. MTP no proporciona ningún tipo de mecanismo de progreso, por lo que la operación simplemente se bloqueará durante la duración.

Parámetros

device un puntero al dispositivo donde existe el objeto.
object_id el objeto a mover.
storage_id el ID del almacenamiento de destino.
parent_id el ID del objeto padre de destino (carpeta). Si el destino es la raíz del almacenamiento, pase '0'.

Retorna

0 si tiene éxito, cualquier otro valor significa fallo.
