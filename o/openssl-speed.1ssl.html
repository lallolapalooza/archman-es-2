NOMBRE

openssl-speed - prueba el rendimiento de la biblioteca

SINOPSIS

openssl speed [-help] [-config nombre_archivo] [-elapsed] [-evp algoritmo] [-hmac algoritmo] [-cmac algoritmo] [-mb] [-aead] [-kem-algorithms] [-signature-algorithms] [-multi num] [-async_jobs num] [-misalign num] [-decrypt] [-primes num] [-seconds num] [-bytes num] [-mr] [-mlock] [-testmode] [-rand archivos] [-writerand archivo] [-engine id] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq] [algoritmo ...]

DESCRIPCIÓN

Este comando se utiliza para probar el rendimiento de los algoritmos criptográficos.

OPCIONES

-help
Muestra un mensaje de uso.
-config nombre_archivo
Especifica el archivo de configuración a utilizar. Opcional; para una descripción del valor predeterminado, consulte "RESUMEN DE COMANDOS" en openssl(1).
-elapsed
Al calcular operaciones o bytes por segundo, utiliza el tiempo de reloj de pared en lugar del tiempo de usuario de la CPU como divisor. Puede ser útil al probar la velocidad de los motores de hardware.
-evp algoritmo
Utiliza el cifrado o el algoritmo de resumen de mensajes especificado a través de la interfaz EVP. Si algoritmo es un cifrado AEAD, entonces puede pasar -aead para evaluar una secuencia similar a TLS. Y si algoritmo es un cifrado capaz de multifrecuencia, por ejemplo, aes-128-cbc-hmac-sha1, entonces -mb medirá la operación de multifrecuencia.

Para ver los algoritmos compatibles con esta opción, utilice "openssl list -digest-algorithms" o "openssl list -cipher-algorithms" comando.

-multi num
Ejecuta múltiples operaciones en paralelo.
-async_jobs num
Habilita el modo asíncrono e inicia el número de trabajos especificado.
-misalign num
Desalinea los búferes por el número especificado de bytes.
-hmac digest
Mide el algoritmo HMAC utilizando el resumen de mensajes especificado.
-cmac cipher
Mide el algoritmo CMAC utilizando el cifrado especificado, por ejemplo, "openssl speed -cmac aes128".
-decrypt
Mide la descifrado en lugar del cifrado. Solo afecta a las pruebas EVP.
-mb
Habilita el modo multifrecuencia en el cifrado con nombre EVP.
-aead
Evalúa el cifrado AEAD con nombre EVP en una secuencia similar a TLS.
-kem-algorithms
Evalúa los algoritmos KEM: generación de claves, encapsulación, desencapsulación.
-signature-algorithms
Evalúa los algoritmos de firma: generación de claves, firma, verificación.
-primes num
Genera una clave RSA de num primos y la utiliza para ejecutar las evaluaciones. Esta opción solo es efectiva si se especifica el algoritmo RSA para probar.
-seconds num
Ejecuta las evaluaciones durante num segundos.
-bytes num
Ejecuta las evaluaciones en búferes de num bytes. Afecta a los cifrados, resúmenes y al CSPRNG. El límite en el tamaño del búfer es INT_MAX - 64 bytes, que para un entero de 32 bits sería 2147483583 bytes.
-mr
Produce el resumen en un formato mecánico y legible por máquina.
-mlock
Bloquea la memoria en RAM para mediciones más deterministas.
-testmode
Ejecuta el comando speed en modo de prueba. Ejecuta solo 1 iteración de cada prueba de algoritmo independientemente de cualquier valor de -seconds. En caso de que alguna operación falle, el comando speed devolverá un resultado de fallo.
-rand archivos, -writerand archivo
Consulte "Opciones de estado aleatorio" en openssl(1) para obtener detalles.
-engine id
Consulte "Opciones de motor" en openssl(1). Esta opción está obsoleta.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Consulte "Opciones de proveedor" en openssl(1), provider(7), y property(7).
algoritmo ...
Si se proporciona algún algoritmo, se prueban esos algoritmos, de lo contrario, se prueba una selección general precompilada.

BUGS

El algoritmo solo se puede seleccionar de un subconjunto precompilado de las cosas que el comando "openssl speed" conoce. Para probar cualquier algoritmo de resumen o cifrado adicional compatible con OpenSSL, use la opción "-evp".

No hay forma de probar la velocidad de algoritmos de clave pública adicionales compatibles con proveedores de terceros con el comando "openssl speed".

HISTORIA

La opción -engine quedó obsoleta en OpenSSL 3.0.

DSA512 se eliminó en OpenSSL 3.2.

La opción -testmode se agregó en OpenSSL 3.4.

NOMBRE

openssl-speed - Realiza pruebas de velocidad de las operaciones de cifrado

SINOPSIS

openssl speed [-multi n] [-elapsed] [-seconds n] [-async n] [cipher ...]

DESCRIPCIÓN

El comando openssl speed mide la velocidad de las operaciones de cifrado y descifrado para varios algoritmos de cifrado. Es útil para comparar el rendimiento de diferentes algoritmos o configuraciones de hardware.

Por defecto, openssl speed realiza pruebas de velocidad para un conjunto predefinido de algoritmos de cifrado comunes. Si se especifican nombres de cipher, solo se probarán esos algoritmos.

OPCIONES

-multi n
Utiliza n hilos para realizar la prueba de velocidad. Por defecto, se utiliza un solo hilo.
-elapsed
Muestra el tiempo transcurrido en lugar del tiempo de CPU.
-seconds n
Realiza las pruebas de velocidad durante n segundos para cada algoritmo.
-async n
Activa la ejecución asíncrona con n operaciones pendientes.

ERRORES

No se conocen errores.

HISTORIAL

El comando openssl speed ha estado disponible en OpenSSL durante mucho tiempo.
