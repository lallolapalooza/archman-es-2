OPAM(1) Manual de Opam OPAM(1)

NOMBRE

opam - gestión de paquetes basada en fuentes

SINOPSIS

opam [COMANDO] …

DESCRIPCIÓN

Opam es un gestor de paquetes. Utiliza las potentes herramientas de mancosi para gestionar dependencias, incluyendo soporte para restricciones de versión, dependencias opcionales y gestión de conflictos. La configuración predeterminada lo enlaza al repositorio oficial de paquetes para OCaml.

Tiene soporte para diferentes repositorios remotos como HTTP, rsync, git, darcs y mercurial. Todo se instala dentro de un directorio local de opam, que puede incluir múltiples prefijos de instalación con diferentes conjuntos de paquetes instalados.

Utilice opam <comando> --help o opam help <comando> para obtener más información sobre un comando específico.

OPCIONES COMUNES

Estas opciones son comunes a todos los comandos.

--best-effort
No fallar si no se pueden instalar todos los paquetes solicitados: intentar instalar tantos como sea posible. Tenga en cuenta que no todos los solucionadores externos pueden soportar esta opción (versiones recientes de aspcud o mccs deberían). Esto es equivalente a establecer la variable de entorno $OPAMBESTEFFORT.
--cli=MAYOR.MENOR (ausente=2.4)
Utiliza la sintaxis y semántica de la interfaz de línea de comandos de MAYOR.MENOR. Diseñado para cualquier uso persistente de opam (scripts, posts de blogs, etc.), cualquier versión de opam de la misma serie MAYOR se comportará como para la versión MENOR especificada. La opción no estaba disponible en opam 2.0, por lo que para seleccionar la CLI 2.0, establezca la variable de entorno $OPAMCLI a 2.0 en lugar de usar este parámetro.
--color=CUÁNDO
Colorea la salida. CUÁNDO debe ser uno de always, never o auto.
--confirm-level=NIVEL
Nivel de confirmación, NIVEL debe ser uno de ask, no, yes o unsafe-yes. Se puede especificar varias veces. Si también se dan --yes o --no, se tiene en cuenta el valor del último --confirm-level. Esto es equivalente a establecer $OPAMCONFIRMLEVEL`.
--criteria=CRITERIOS
Especifica las preferencias del usuario para la resolución de dependencias para esta ejecución. Anula $OPAMCRITERIA, $OPAMFIXUPCRITERIA y $OPAMUPGRADECRITERIA. Para obtener detalles sobre el lenguaje soportado y los solucionadores externos disponibles, consulte http://opam.ocaml.org/doc/External_solvers.html. Una guía general para usar preferencias de solucionador se puede encontrar en http://www.dicosmo.org/Articles/usercriteria.pdf.
--cudf=NOMBRE_ARCHIVO
Opción de depuración: Guarda las solicitudes CUDF enviadas al solucionador en NOMBRE_ARCHIVO-<n>.cudf donde <n> es la n-ésima llamada al solucionador durante la ejecución de opam.
--debug
Imprime mensajes de depuración en stderr. Esto es equivalente a establecer $OPAMDEBUG a "true".
--debug-level=NIVEL
Similar a --debug, pero permite especificar

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

OPTIONS

--debug[=level]
Establece el nivel de depuración (establece en 1 por defecto). Equivalente a establecer $OPAMDEBUG a un entero positivo.
--git-version
Imprime la versión git de opam, si está definida (es decir, estás usando una versión de desarrollo), y sale.
--help[=FMT] (default=auto)
Muestra esta ayuda en el formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la variable del entorno TERM sea dumb o indefinida.
--ignore-pin-depends
Ignora las dependencias adicionales requeridas por los paquetes que se fijan, ya sea manualmente a través de opam pin o a través de opam install DIR. Esto es equivalente a establecer IGNOREPINDEPENDS=true.
--json=FILENAME
Guarda los resultados de la ejecución de opam en un archivo legible por computadora. Si el nombre del archivo contiene el carácter `%`, este será reemplazado por un índice que no sobrescribirá un archivo existente. Similar a establecer la variable $OPAMJSON.
--no
Responde no a todas las preguntas de sí/no de opam sin preguntar. Ver también --confirm-level. Esto es equivalente a establecer $OPAMNO a "true".
--no-aspcud
Eliminado en la versión 2.1.
--no-auto-upgrade
Al configurar o actualizar un repositorio escrito para una versión anterior de opam (1.2), opam lo convierte internamente al formato actual. Esto deshabilita este comportamiento. Tenga en cuenta que los repositorios deben definir su versión de formato en un archivo 'repo' en su raíz, o se asumirá que están en el formato más antiguo. En cualquier caso, es preferible actualizar los repositorios manualmente usando opam admin upgrade [--mirror URL] cuando sea posible.
--no-self-upgrade
Opam se reemplazará a sí mismo con un binario más nuevo encontrado en OPAMROOT/opam si está presente. Esto deshabilita este comportamiento.
-q, --quiet
Deshabilita --verbose.
--root=ROOT
Usa ROOT como la ruta raíz actual. Esto es equivalente a establecer $OPAMROOT a ROOT.
--safe, --readonly
Asegura que nada se actualizará o reescribirá automáticamente. Útil para llamar desde scripts de completado, por ejemplo. Fallará siempre que se necesite una operación de este tipo; también evita esperar bloqueos, omite preguntas interactivas y anula la variable $OPAMDEBUG. Esto es equivalente a establecer la variable de entorno $OPAMSAFE.
--solver=CMD
Especifica el solucionador CUDF a utilizar para resolver problemas de instalación de paquetes. Este es un solucionador predefinido (esta versión de opam soporta builtin-mccs+lp(), builtin-mccs+glpk, builtin-dummy-z3-solver, builtin-0install, aspcud, mccs, aspcud-old, packup), o un comando personalizado que debe contener las variables %{input}%, %{output}%, %{criteria}%, y opcionalmente %{timeout}%. Esto es equivalente a establecer $OPAMEXTERNALSOLVER.
--strict
Falla siempre que se encuentre un error en la definición de un paquete o en un archivo de configuración. Por defecto, continúa silenciosamente si es posible.
--switch=SWITCH
Usa SWITCH como el cambio de compilador actual. Esto es equivalente a establecer $OPAMSWITCH a SWITCH.
--use-internal-solver
Deshabilita cualquier solucionador externo y utiliza el interno (esto requiere que opam se haya compilado con un solucionador interno). Esto es equivalente a establecer $OPAMNOASPCUD o $OPAMUSEINTERNALSOLVER.
-v, --verbose
Sé más verboso. Un -v muestra todos los comandos de paquete, repite para mostrar también los comandos llamados internamente (por ejemplo, tar, curl, patch, etc.). Repetir n veces es equivalente a establecer $OPAMVERBOSE a "n".
--version
Muestra información de la versión.
-w, --working-dir
Siempre que se actualicen paquetes que están vinculados a un directorio local controlado por versiones, actualiza al estado de trabajo actual de su código fuente en lugar del último estado confirmado, o la referencia a la que apuntan. Como el directorio fuente se copia tal cual, si no está limpio, puede resultar en un error de compilación de opam. Esto solo afecta a los paquetes listados explícitamente en la línea de comandos. También se puede establecer con $OPAMWORKINGDIR.
-y, --yes
Responde sí a todas las preguntas de sí/no de opam sin preguntar. Ver también --confirm-level. Esto es equivalente a establecer $OPAMYES a "true".

OPAMBUILDDOC Eliminado en la versión 2.1.

OPAMBUILDTEST Eliminado en la versión 2.1.

OPAMCLI ver opción `--cli'.

OPAMCOLOR cuando se establece en always o never, establece un valor predeterminado para la opción `--color'.

OPAMCONFIRMLEVEL ver opción `--confirm-level`. OPAMCONFIRMLEVEL tiene prioridad sobre OPAMYES y OPAMNO.

OPAMCRITERIA especifica las preferencias del usuario para la resolución de dependencias. El valor predeterminado depende de la versión del solucionador, use `config report' para conocer la configuración actual. Ver también la opción --criteria.

OPAMCUDFTRIM controla el filtrado de paquetes no relacionados durante el preprocesamiento de CUDF.

OPAMDOWNLOADJOBS establece el número máximo de descargas simultáneas.

OPAMDROPWORKINGDIR anula los paquetes actualizados previamente con --working-dir en la actualización. Sin esta variable establecida, opam los mantendría sin cambios a menos que se nombraran explícitamente en la línea de comandos.

OPAMDRYRUN ver opción `--dry-run'.

OPAMEDITOR establece el editor a utilizar para la edición de archivos opam, anula $EDITOR y $VISUAL.

OPAMERRLOGLEN establece el número de líneas de log impresas cuando falla un subproceso. 0 para imprimir todas.

OPAMEXTERNALSOLVER ver opción `--solver'.

OPAMFAKE ver opción `--fake'.

OPAMIGNORECONSTRAINTS ver opción de instalación `--ignore-constraints-on'.

OPAMIGNOREPINDEPENDS ver opción `--ignore-pin-depends'.

OPAMINPLACEBUILD ver opción `--inplace-build'.

OPAMJOBS establece el número máximo de trabajadores paralelos a ejecutar.

OPAMJSON registra la salida json en el archivo dado (usa el carácter `%` para indexar los archivos).

OPAMKEEPBUILDDIR ver opción de instalación `--keep-build-dir'.

OPAMKEEPLOGS le dice a opam que no elimine algunos logs de comandos temporales y algunas copias de seguridad. Esto omite algunos finalizadores y también puede ayudar a obtener backtraces más confiables.

OPAMLOCKED combinación de las opciones `--locked' y `--lock-suffix'.

OPAMLOGS logdir establece el directorio de logs, el valor predeterminado es un directorio temporal en /tmp

OPAMMAKECMD establece el comando `make' del sistema a utilizar.

OPAMMERGEOUT fusiona las salidas de proceso, stderr en stdout.

OPAMNO responde no a cualquier pregunta, ver opciones `--no' y `--confirm-level`. OPAMNO se ignora si OPAMCONFIRMLEVEL o OPAMYES están definidos.

OPAMNOAGGREGATE con `opam admin check', no agrega paquetes.

OPAMNOASPCUD Obsoleto.

OPAMNOAUTOUPGRADE deshabilita la actualización interna automática de repositorios en un formato anterior al actual, en 'update' o 'init'.

OPAMNOCHECKSUMS habilita la opción --no-checksums cuando está disponible.

ENVIRONMENT

The following environment variables are read by opam:

OPAM_CHECK_LOCKS if set to a non-empty value, opam checks all packages for lockfiles.

OPAM_COLORS can be used to set the colours for different opam messages. It's a comma-separated list of key=value pairs. See the opam manual for a list of available keys.

OPAMCOLORS same as OPAM_COLORS.

OPAMCONFIGDIR override the default configuration directory (~/.config/opam).

OPAMCRITERIA default values for the solver's optimisation criteria. See also option --criteria.

OPAMDEBUG If set to a non-empty value, opam will try to print more debug messages. The value is a comma-separated list of component names (e.g. `solver', `repo', etc.).

OPAMDEVMODE if set, opam will select the dev version of the package when available. This is equivalent to passing `--dev-version' to `opam install' and `opam upgrade'.

OPAMDIFF If set to `colored', colourised diffs are displayed. If set to `unified', unified diffs are displayed. If unset, no diffs are displayed.

OPAMDONTCONFIRM if set to a non-empty value, opam will automatically answer yes to any confirmation prompt.

OPAMFILTERALLINSTALLED If set to a non-empty value, `opam list --installed' will also display packages that are not part of the current switch's installation. Previously, the command only listed packages that were installed in the current switch.

OPAMFILTERPROJECTPACKAGES If set to a non-empty value, `opam list --installed' will filter out packages which are part of the project, and thus not explicitly installed in the switch.

OPAMFILTERREMOVED If set to a non-empty value, `opam list --installed' will filter out packages that have been removed from the repositories but are still installed in the switch.

OPAMGLOBALPREFIX overrides the default global prefix (/usr/local).

OPAMHASKELLINSTALL If set to a non-empty value, opam will use the Haskell installation tools (ghc-pkg, etc.) instead of the OCaml ones for handling package installations. This is only useful if you are using Haskell packages within opam.

OPAMHOOK_ACTION Action that is expected to be performed by the hook.

OPAMHOOK_PACKAGE Package name for which the hook is run.

OPAMHOOK_REPOSITORY Repository name for which the hook is run.

OPAMHOOK_SWITCH Switch name for which the hook is run.

OPAMKEEPEMPTYCASE if set, opam will not remove empty directories in the opam root.

OPAMKEEPBUILDDEPFAILURES if set, opam will not remove build directories when the build fails.

OPAMKEEPEMPTYDIRS If set, opam will not remove empty directories within the opam root.

OPAMKEEPEMPTYDIRSANDCASE if set, opam will not remove empty directories and cases in the opam root.

OPAMKEEPGOALS if set, opam will not remove empty directories in the opam root.

OPAMKEEPOLDVERSIONS if set, opam will not remove old versions of packages.

OPAMKEEPPROJECTBUILDDIRS If set, opam will not remove build directories for project packages.

OPAMLEGACYINSTALL if set, opam will use the legacy install command. This is useful for compatibility with older opam versions.

OPAMLOCALPINCONFLICT if set, opam will not complain about pin conflicts between local packages.

OPAMLOCALPINPRIO if set, opam will use the local pin priority instead of the repository pin priority.

OPAMLOG if set, opam will save the build logs into files named after the package and the switch name.

OPAMNO If set to a non-empty value, opam will automatically answer no to any confirmation prompt. This is overridden by OPAMYES.

OPAMNOASSUME if set, opam will not assume any previous installation or configuration. This forces opam to check everything from scratch.

OPAMNOFETCHUPDATE if set, opam will not fetch updates from repositories when performing operations that require them.

OPAMNOSYNC If set to a non-empty value, opam will not sync repositories before performing operations that require them.

OPAMOLDsolver If set, opam will use the old solver instead of the new one. This is useful for compatibility with older opam versions.

OPAMOUTPUTDIR Override the default output directory for logs and build artifacts.

OPAMPKGPRIMOOK if set, opam will not complain about pin conflicts between local packages.

OPAMPKGPRIMOVERRIDE if set, opam will use the local pin priority instead of the repository pin priority.

OPAMPREFEROLDVERSIONS If set, opam will prefer older versions of packages when solving dependencies. This is useful when you want to stick to older versions of packages.

OPAMPROMPTCONFIRM if set, opam will prompt for confirmation before performing any operation. This is the default behavior, unless OPAMYES or OPAMNO are set.

OPAMPROMPTCONFIRMLEVEL If set, opam will prompt for confirmation based on the level specified. Possible values are: `all', `dependencies', `install', `remove', `upgrade', `build', `test', `configure', `native-recipe', `pin`, `unpin', `reinstall`, `update-script`, `install-script`, `uninstall-script`, `build-script`, `test-script`, `configure-script`, `native-recipe-script`, `pin-script`, `unpin-script`, `remove-script`, `update-script`, `upgrade-script`, `depexts`, `doc`, `dev-setup`, `test`, `with-doc`, `with-test`. For example, `OPAMPROMPTCONFIRMLEVEL=install,remove' will prompt for confirmation only for install and remove operations.

OPAMREMOTESUBDIRS if set, opam will look for repositories in subdirectories of the opam root.

OPAMROOT override the default opam root directory (~/.opam).

OPAMSCHOOLMODE if set, opam will not use colors and will display a simpler output.

OPAMSCRIPTFAILURE if set, opam will not abort the build if a package script fails.

OPAMSHELL overrides the default shell used by opam.

OPAMSHOWsolverlog if set, opam will display the solver log after a failed solve attempt.

OPAMSHOWTESTFAILURES if set, opam will display the test failures after a failed test attempt.

OPAMSIGNATURE if set, opam will sign all commits made by opam with the specified GPG key.

OPAMSOLVER specifies the solver to use. Possible values are `builtin-z3', `aspcud', `ocamlfind', `native'. By default, opam uses `builtin-z3'.

OPAMSOLVER_DOWNGRADES if set, the solver will favour downgrades over upgrades. This is useful when you want to keep your system as stable as possible.

OPAMSOLVER_MAXITERATIONS limits the number of iterations of the solver. Default is 1000.

OPAMSOLVER_PROPOSALS if set, opam will not return a solution when they reach timeout; while the solution remains assured to be consistent, there is no guarantee in this case that it fits the expected optimisation criteria. If `true', opam will continue with a warning, if `false' a timeout is an error. Currently only the builtin-z3 backend handles this degraded case.

OPAMSOLVERTIMEOUT change the time allowance of the solver. Default is 60.0, set to 0 for unlimited. Note that all solvers may not support this option.

OPAMSOLVERTOLERANCE changes the tolerance towards the solver choosing an unoptimized solution (i.e. might pull outdated packages). Typical values range from 0.0 (best solution known to the solver) to 1.0 (unoptimized solution). Default is 0.0. This option is useful in case the solver can't find a solution in a reasonable time (see $OPAMSOLVERTIMEOUT). Note that all solvers may not support this option.

OPAMSTATS Removed in 2.4.

OPAMSTATUSLINE display a dynamic status line showing what's currently going on on the terminal. (one of one of always, never or auto)

OPAMSTRICT fail on inconsistencies (file reading, switch import, etc.).

OPAMSWITCH see option `--switch'. Automatically set by `opam env --switch=SWITCH --set-switch'.

OPAMUNLOCKBASE see install option `--unlock-base'.

OPAMUPGRADECRITERIA specifies user preferences for dependency solving when performing an upgrade. Overrides OPAMCRITERIA in upgrades if both are set. See also option --criteria.

OPAMUSEINTERNALSOLVER see option `--use-internal-solver'.

OPAMUSEOPENSSL Removed in 2.2.

OPAMUTF8 use UTF8 characters in output (one of one of always, never or auto). By default `auto', which is determined from the locale).

OPAMUTF8MSGS use extended UTF8 characters (camels) in opam messages. Implies OPAMUTF8. This is set by default on macOS only.

OPAMVALIDATIONHOOK if set, uses the `%{hook%}' command to validate an opam repository update.

OPAMVERBOSE see option `--verbose'.

OPAMVERBOSEON see option --verbose-on

OPAMVERSIONLAGPOWER do not use.

OPAMWITHDEVSETUP see install option `--with-dev-setup'.

OPAMWITHDOC see install option `--with-doc'.

OPAMWITHTEST see install option `--with-test.

OPAMWORKINGDIR see option `--working-dir'.

OPAMYES see options `--yes' and `--confirm-level`. OPAMYES has priority over OPAMNO and is ignored if OPAMCONFIRMLEVEL is set.

OPAMVAR_var overrides the contents of the variable var when substituting `%{var}%` strings in `opam` files.

OPAMVAR_package_var overrides the contents of the variable package:var when substituting `%{package:var}%` strings in `opam` files.

CLI VERSION

All scripts and programmatic invocations of opam should use `--cli' in order to ensure that they work seamlessly with future versions of the opam client. Additionally, blog posts or other documentation can benefit, as it prevents information from becoming stale.

Although opam only supports roots (~/.opam/) for the current version, it does provide backwards compatibility for its command-line interface.

Since CLI version support was only added in opam 2.1, use OPAMCLI to select 2.0 support (as opam 2.0 will just ignore it), and `--cli=2.1' for 2.1 (or later) versions, since an environment variable controlling the parsing of syntax is brittle. To this end, opam displays a warning if OPAMCLI specifies a valid version other than 2.0, and also if `--cli=2.0' is specified.

The command-line version is selected by using the `--cli' option or the OPAMCLI environment variable. `--cli' may be specified morethan once, where the last instance takes precedence. OPAMCLI is only inspected if `--cli' is not given.

EXIT STATUS

As an exception to the following, the `exec' command returns 127 if the command was not found or couldn't be executed, and the command's exit value otherwise.

0
Success, or true for boolean queries.
1
False. Returned when a boolean return value is expected, e.g. when running with --check, or for queries like opam lint.
2
Bad command-line arguments, or command-line arguments pointing to an invalid context (e.g. file not following the expected format).
5
Not found. You requested something (package, version, repository, etc.) that couldn't be found.
10
Aborted. The operation required confirmation, which wasn't given.
15
Could not acquire the locks required for the operation.
20
There is no solution to the user request. This can be caused by asking to install two incompatible packages, for example.
30
Error in package definition, or other metadata files. Using --strict raises this error more often.
31
Package script error. Some package operations were unsuccessful. This may be an error in the packages or an incompatibility with your system. This can be a partial error.
40
Sync error. Could not fetch some remotes from the network. This can be a partial error.
50
Configuration error. Opam or system configuration doesn't allow operation, and needs fixing.
60
Solver failure. The solver failed to return a sound answer. It can be due to a broken external solver, or an error in solver configuration.
99
Internal error. Something went wrong, likely due to a bug in opam itself.
130
User interrupt. SIGINT was received, generally due to the user pressing Ctrl-C.
0
on success.
123
on indiscriminate errors reported on standard error.
124
on command line parsing errors.
125
on unexpected internal errors (bugs).
