NOMBRE

opendmarc-expire - Herramienta de expiración de datos de historial de OpenDMARC

SINOPSIS

opendmarc-expire [opciones]

DESCRIPCIÓN

opendmarc-expire expira registros antiguos de la base de datos que forma parte de la función de informes agregados de OpenDMARC.

OPCIONES

--alltables
Expira registros en todas las tablas en lugar de solo las grandes.
--dbhost=servidor
Intenta conectarse al servidor de base de datos en el servidor nombrado. El valor predeterminado es "localhost".
--dbname=nombre
Solicita una conexión a la base de datos llamada nombre. El valor predeterminado es "opendmarc".
--dbpasswd=contraseña
Intenta autenticarse en el servidor de base de datos utilizando la contraseña especificada. El valor predeterminado es "opendmarc".
--dbport=puerto
Intenta conectarse a la base de datos en el puerto TCP especificado. El valor predeterminado es 3306.
--dbuser=usuario
Intenta autenticarse en el servidor de base de datos como el usuario especificado. El valor predeterminado es "opendmarc".
--expire=dias
Indica el número de días de datos a conservar. El valor predeterminado es 180.
--help
Imprime un mensaje de uso y sale.
--verbose
Solicita salida detallada.
--version
Imprime el número de versión y sale.

VERSIÓN

Esta página del manual cubre la versión de opendmarc-expire que se incluyó con la versión 1.4.2 de OpenDMARC.
