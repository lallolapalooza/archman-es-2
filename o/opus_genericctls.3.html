DESCRIPCIÓN DETALLADA

Estas macros se usan con las llamadas opus_decoder_ctl y opus_encoder_ctl para generar una solicitud particular.

Cuando se llaman en un OpusDecoder se aplican a esa instancia de decodificador en particular. Cuando se llaman en un OpusEncoder se aplican a la configuración correspondiente en esa instancia de codificador, si está presente.

Algunos ejemplos de uso:

int ret;
opus_int32 pitch;
ret = opus_decoder_ctl(dec_ctx, OPUS_GET_PITCH(&pitch));
if (ret == OPUS_OK) return ret;
opus_encoder_ctl(enc_ctx, OPUS_RESET_STATE);
opus_decoder_ctl(dec_ctx, OPUS_RESET_STATE);
opus_int32 enc_bw, dec_bw;
opus_encoder_ctl(enc_ctx, OPUS_GET_BANDWIDTH(&enc_bw));
opus_decoder_ctl(dec_ctx, OPUS_GET_BANDWIDTH(&dec_bw));
if (enc_bw != dec_bw) {
  printf("mismatch de ancho de banda del paquete0);
}

#define OPUS_GET_BANDWIDTH(x)

Obtiene la banda de paso configurada del codificador o la última banda de paso del decodificador.

Ver también

OPUS_SET_BANDWIDTH

Parámetros

x opus_int32 *: Devuelve uno de los siguientes valores:
OPUS_AUTO
(por defecto)
OPUS_BANDWIDTH_NARROWBAND
Banda de paso de 4 kHz
OPUS_BANDWIDTH_MEDIUMBAND
Banda de paso de 6 kHz
OPUS_BANDWIDTH_WIDEBAND
Banda de paso de 8 kHz
OPUS_BANDWIDTH_SUPERWIDEBAND
Banda de paso de 12 kHz
OPUS_BANDWIDTH_FULLBAND
Banda de paso de 20 kHz

#define OPUS_GET_FINAL_RANGE(x)

Obtiene el estado final del codificador entrópico del códec. Esto se utiliza con fines de prueba. El estado del codificador y el decodificador deberían ser idénticos después de codificar una carga útil (suponiendo que no haya corrupción de datos o errores de software)

Parámetros

x opus_uint32 *: Estado del codificador entrópico

#define OPUS_GET_IN_DTX(x)

Obtiene el estado DTX del codificador. Devuelve si el último marco codificado fue una actualización de ruido de confort durante DTX o no se codificó debido a DTX.

Parámetros

x opus_int32 *: Devuelve uno de los siguientes valores:
0
El codificador no está en DTX.
1
El codificador está en DTX.

#define OPUS_GET_PHASE_INVERSION_DISABLED(x)

Obtiene el estado configurado de inversión de fase del codificador.

Ver también

OPUS_SET_PHASE_INVERSION_DISABLED

Parámetros

x opus_int32 *: Devuelve uno de los siguientes valores:
0
Inversión de fase estéreo habilitada (por defecto).
1
Inversión de fase estéreo deshabilitada.

#define OPUS_GET_SAMPLE_RATE(x)

Obtiene la frecuencia de muestreo con la que se inicializó el codificador o decodificador. Esto simplemente devuelve el valor Fs pasado a opus_encoder_init() o opus_decoder_init().

Parámetros

x opus_int32 *: Frecuencia de muestreo del codificador o decodificador.

#define OPUS_RESET_STATE

Reinicia el estado del códec para que sea equivalente a un estado recién inicializado. Esto debe llamarse al cambiar de flujo para evitar que la decodificación de forma consecutiva dé resultados diferentes a la decodificación individual.

#define OPUS_SET_PHASE_INVERSION_DISABLED(x)

Si se establece en 1, deshabilita el uso de inversión de fase para estéreo de intensidad, mejorando la calidad de las mezclas a mono, pero reduciendo ligeramente la calidad estéreo normal. Deshabilitar la inversión de fase en el decodificador no cumple con RFC 6716, aunque no causa ningún problema de interoperabilidad y se espera que se convierta en parte del estándar Opus una vez que RFC 6716 sea actualizado por draft-ietf-codec-opus-update.

Ver también

Parámetros

x opus_int32: Valores permitidos:
0
Habilitar inversión de fase (por defecto).
1
Deshabilitar inversión de fase.

NAME

opus_genericctls

opus_genericctls - Get/set Opus encoder/decoder generic settings

SYNOPSIS

opus_genericctls

#include <opus/opus_types.h>

opus_int32 opus_genericctls(OpusServer *server, OpusGenericControl control, ...);

DESCRIPTION

opus_genericctls

The opus_genericctls function is used to get or set generic settings on an Opus server. The available settings are defined by the OpusGenericControl enumeration.

Arguments:

  • server: A pointer to the Opus server context.
  • control: The generic control parameter to get or set.
  • ...: A variable argument list for the value to be set or a pointer to store the value when getting.

RETURN VALUE

opus_genericctls

Returns 0 on success, or an Opus error code on failure.

NOTES

opus_genericctls

This function provides a generic interface to control various aspects of the Opus encoder and decoder. The specific values and their meanings depend on the OpusGenericControl enumeration. Refer to the Opus documentation for a detailed list of available controls and their associated values.
