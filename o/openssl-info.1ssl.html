NOMBRE

openssl-info - imprime información incorporada de OpenSSL

SINOPSIS

openssl info [-help] [-configdir] [-enginesdir] [-modulesdir ] [-dsoext] [-dirnamesep] [-listsep] [-seeds] [-cpusettings] [-windowscontext]

DESCRIPCIÓN

Este comando se utiliza para imprimir información sobre OpenSSL. La información se escribe exactamente como está, sin texto adicional, lo que la hace útil para scripts.

Como consecuencia, solo se puede elegir un elemento para cada ejecución de este comando.

OPCIONES

-help
Imprime un mensaje de uso.
-configdir
Imprime el directorio predeterminado para los archivos de configuración de OpenSSL.
-enginesdir
Imprime el directorio predeterminado para los módulos de motor de OpenSSL.
-modulesdir
Imprime el directorio predeterminado para los módulos cargables dinámicamente de OpenSSL que no sean módulos de motor.
-dsoext
Imprime la extensión DSO que utiliza OpenSSL.
-dirnamesep
Imprime el carácter separador entre una especificación de directorio y un nombre de archivo. Tenga en cuenta que en algunos sistemas operativos, este no es el mismo que el separador entre elementos de directorio.
-listsep
Imprime el carácter separador de listas de OpenSSL. Esto se utiliza típicamente para construir listas de estilo $PATH ("%PATH%" en Windows).
-seeds
Imprime las fuentes de semilla de aleatoriedad.
-cpusettings
Imprime la información de configuración de CPU de OpenSSL.
-windowscontext
Imprime el contexto de instalación de Windows.

HISTORIA

Este comando se añadió en OpenSSL 3.0.

La opción -windowscontext se añadió en OpenSSL 3.4.
