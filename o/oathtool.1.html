OATHTOOL(1) Comandos de usuario OATHTOOL(1)

NOMBRE

oathtool - Herramienta de contraseña de un solo uso OATH (Open AuTHentication)

SINOPSIS

oathtool [OPCIÓN]... [CLAVE [OTP]]...

DESCRIPCIÓN

Genera y valida contraseñas de un solo uso OATH. CLAVE y OTP es la cadena '-' para leer desde la entrada estándar, '@ARCHIVO' para leer desde el nombre de archivo indicado, o un valor codificado en hexadecimal (no recomendado en sistemas multiusuario).

-h, --help
Imprime la ayuda y sale
-V, --version
Imprime la versión y sale
--hotp
usa el modo HOTP basado en eventos (predeterminado=activado)
--totp[=MODO]
usa el modo TOTP variante en el tiempo (valores "SHA1", "SHA256" o "SHA512") (predeterminado=`SHA1')
-b, --base32
usa codificación base32 de CLAVE en lugar de hexadecimal (predeterminado=desactivado)
-c, --counter=CONTADOR
valor del contador HOTP
-s, --time-step-size=DURACIÓN Duración del paso de tiempo TOTP
(predeterminado=`30s')
-S, --start-time=TIEMPO
cuándo comenzar a contar los pasos de tiempo para TOTP (predeterminado=`1970-01-01 00:00:00 UTC')
-N, --now=TIEMPO
usa este tiempo como el tiempo actual para TOTP (predeterminado=`ahora')
-d, --digits=DÍGITOS
número de dígitos en la contraseña de un solo uso
-w, --window=ANCHO
número de contraseñas de un solo uso adicionales a generar o validar contra
-v, --verbose
explica qué se está haciendo (predeterminado=desactivado)

EJEMPLOS

Para generar una contraseña de un solo uso basada en el tiempo (TOTP) a partir de una clave protegida por GnuPG:


$ gpg --decrypt --quiet ~/.my-totp-secret.asc | oathtool --totp -

Cómo crear el archivo cifrado está fuera del alcance de este manual, consulta gpg(1), sin embargo, los siguientes dos comandos pueden ayudarte a cifrar el secreto simétricamente (usando una contraseña) o asimétricamente (si has creado una clave privada). Deberás proporcionar el secreto desde la terminal después de invocar los comandos.


$ gpg --symmetric > ~/.my-totp-secret.asc
$ gpg --encrypt --default-recipient-self > ~/.my-totp-secret.asc

Para facilitar la lectura, el resto de esta página del manual proporciona la CLAVE y el OTP en la línea de comandos. Ten en cuenta que este uso no se recomienda ya que en la mayoría de los sistemas multiusuario, los parámetros de la línea de comandos de los procesos en ejecución pueden ser vistos por otros usuarios.

Para generar la primera contraseña de un solo uso basada en eventos (HOTP) para una clave completamente cero:


$ echo 00 | oathtool -
328482
$

A veces querrás generar más de una OTP. Para generar 10 contraseñas de un solo uso adicionales basadas en eventos, con la clave secreta utilizada en los ejemplos de RFC 4226, usa el parámetro -w (--window):


$ oathtool -w 10 3132333435363738393031323334353637383930
755224
287082
359152
969429
338314
254676
287922
162583
399871
520489
403154
$

En la última salida, el contador para la primera OTP fue 0, la segunda OTP tuvo un contador de 1, y así sucesivamente hasta 10.

Para usar claves codificadas en Base32 en lugar de hexadecimal, puedes proporcionar el parámetro -b (--base32):


$ oathtool --base32 -w 3 GEZDGNBVGY3TQOJQGEZDGNBVGY3TQOJQ
755224
287082
359152
969429
$

La herramienta ignora los espacios en blanco en los datos base32 y vuelve a añadir relleno si es necesario, por lo tanto, puedes proporcionar claves formateadas como la siguiente.


$ oathtool --base32 --totp "gr6d 5br7 25s6 vnck v4vl hlao re"
977872
$

Para generar una OTP en particular, usa el parámetro -c (--counter) para dar la posición exacta directamente:


$ oathtool -c 5 3132333435363738393031323334353637383930
254676
$

Para validar una contraseña de un solo uso HOTP, proporciona la OTP al final de la línea de comandos:


$ oathtool -w 10 3132333435363738393031323334353637383930 969429
3
$

La salida indica el contador que se utilizó. Funciona comenzando con el contador 0 e incrementando hasta que encuentra una coincidencia (o no), dentro de la ventana proporcionada de 10 OTPs.

La herramienta soporta contraseñas de un solo uso variantes en el tiempo, en el llamado modo TOTP. El uso es similar, pero se debe proporcionar --totp:


$ oathtool --totp 00
943388
$

No te alarmes si no obtienes la misma salida, esto se debe a que la salida depende de la hora actual. Para generar un TOTP para una hora fija en particular, usa el parámetro -N (--now):


$ oathtool --totp --now "2008-04-23 17:42:17 UTC" 00
974945
$

El formato es una cadena de fecha legible por humanos, en formato mayormente libre, como "Dom, 29 Feb 2004 16:21:42 -0800" o "2004-02-29 16:21:42" o incluso "próximo jueves". Es el mismo que se usa como parámetro --date de la herramienta date(1).

El algoritmo MAC predeterminado a usar con TOTP es HMAC-SHA1 y es lo que se usa habitualmente. La herramienta soporta otros dos MACs, a saber, HMAC-SHA256 y HMAC-SHA512. Para usar cualquiera de estos, califica el parámetro --totp con un valor. Usa "SHA256" para HMAC-SHA256 y "SHA512" para HMAC-SHA512. Lo siguiente demuestra la generación de uno de los vectores de prueba de RFC 6238.


$ oathtool --totp=SHA256 --digits=8 --now "2009-02-13 23:31:30 UTC" 3132333435363738393031323334353637383930313233343536373839303132
91819424
$

Puedes generar varios TOTP especificando el parámetro --window, de forma similar a como funciona para HOTP. Los OTP generados aquí serán para el tiempo inicial (normalmente la hora actual) y luego cada paso de tiempo siguiente (por ejemplo, ventana de 30 segundos).


$ oathtool --totp 00 -w5
815120
003818
814756
184042
582326
733842
$

Puedes validar una contraseña de un solo uso TOTP proporcionando el secreto y un parámetro de ventana (número de pasos de tiempo antes o después de la hora actual):


$ oathtool --totp -w 5 00 `oathtool --totp 00`
0
$

De forma similar a la generación de TOTPs, puedes usar un parámetro -N (--now) para especificar el tiempo a usar en lugar del tiempo actual:


$ oathtool --totp --now="2005-03-18 01:58:29 UTC" -w 10000000 3132333435363738393031323334353637383930 89005924
4115227
$

La prueba anterior utiliza valores de la especificación TOTP y pondrá a prueba la herramienta porque la ventana esperada es de alrededor de 4 millones de pasos de tiempo.

Hay dos parámetros del sistema para TOTP: el tamaño del paso de tiempo y el inicio del tiempo.

Por defecto, el tamaño del paso de tiempo es de 30 segundos, lo que significa que obtienes una nueva OTP cada 30 segundos. Puedes modificar esto con el parámetro -s (--time-step-size):


$ oathtool --totp --time-step-size=45s 00
109841
$

Los valores son duraciones ISO-8601 válidas, ver: http://en.wikipedia.org/wiki/ISO_8601#Durations

El inicio del tiempo es normalmente 1970-01-01 00:00:00 UTC, pero puedes cambiarlo usando -S (--start-time):


$ oathtool --totp --start-time "1980-01-01 00:00:00 UTC" 00
273884
$

Para obtener más información sobre lo que utiliza la herramienta, usa el parámetro -v (--verbose). Finalmente, para generar la última OTP (para SHA-1) en la tabla de vectores de prueba de RFC 6238, puedes invocar la herramienta de esta manera:


$ oathtool --totp -v -N "2033-05-18 03:33:20 UTC" -d8 3132333435363738393031323334353637383930
Hex secret: 3132333435363738393031323334353637383930
Base32 secret: GEZDGNBVGY3TQOJQGEZDGNBVGY3TQOJQ
Digits: 8 oathtool(1) — OATH Toolkit 2.6.13

NOMBRE

oathtool — calcula códigos de un solo uso basados en tiempo u HOTP

SINOPSIS

oathtool [-v] [-h] [-V] [-b|-t] [-d digits] [-s secret] [-H hashalgo] [-w window] [-c counter] [-e endtime] [-o otpauth]

DESCRIPCIÓN

oathtool es una utilidad de línea de comandos para calcular códigos de un solo uso (One-Time Password, OTP) para el protocolo OATH (Initiative for Open Authentication). Soporta TOTP (Time-based One-Time Password) y HOTP (HMAC-based One-Time Password).

Los argumentos:

-v
Imprime información detallada sobre el cálculo, incluyendo el tamaño de la ventana, el modo TOTP/HOTP, el tamaño del paso (en segundos para TOTP), la hora de inicio y la hora actual. También imprime el contador calculado y el valor OTP.
-h
Imprime un mensaje de ayuda y sale.
-V
Imprime información de versión y sale.
-b
Calcula un código HOTP. Es el modo por defecto si no se especifica ni -b ni -t.
-t
Calcula un código TOTP.
-d digits
El número de dígitos que debe tener el código OTP. El valor por defecto es 6.
-s secret
La clave secreta utilizada para generar el código OTP. Debe ser una cadena de texto ASCII o hexadecimal. Si la cadena comienza con '0x', se tratará como hexadecimal.
-H hashalgo
El algoritmo de hash utilizado para generar el código OTP. Los algoritmos soportados son MD5, SHA1, SHA256 y SHA512. El valor por defecto es SHA1.
-w window
El tamaño de la ventana de tiempo para la verificación de códigos TOTP. Esto permite que los códigos TOTP sean válidos durante un período de tiempo determinado (la ventana). Por ejemplo, una ventana de 0 significa que solo se valida el código actual. Una ventana de 1 significa que se valida el código actual y el código anterior y el siguiente. El valor por defecto es 0.
-c counter
El valor del contador para la generación de códigos HOTP. Si no se proporciona, el contador se lee desde la entrada estándar.
-e endtime
La hora de finalización para la generación de códigos TOTP. El formato es YYYY-MM-DD HH:MM:SS UTC. Si no se proporciona, se utiliza la hora actual.
-o otpauth
Especifica el URI de autenticación 'otpauth://' para generar el código OTP. Esto es útil para generar códigos QR para aplicaciones móviles.

EJEMPLOS

Generar un código TOTP con la clave secreta '1234567890123456' y un contador de 0:


oathtool -t -s 1234567890123456 -c 0

Generar un código TOTP con la clave secreta '1234567890123456' y la hora actual:


oathtool -t -s 1234567890123456

Generar un código HOTP con la clave secreta '1234567890123456' y un contador de 100:


oathtool -b -s 1234567890123456 -c 100

Generar un código HOTP con la clave secreta '0x1234567890ABCDEF' (hexadecimal) y un contador de 50:


oathtool -b -s 0x1234567890ABCDEF -c 50

Generar un código TOTP con información detallada:


oathtool -v -t -s secret-key -w 1

Salida detallada del ejemplo anterior:


Window size: 1
TOTP mode: SHA1
Step size (seconds): 30
Start time: 1970-01-01 00:00:00 UTC (0)
Time now: 2033-05-18 03:33:20 UTC (2000000000)
Counter: 0x3F940AA (66666666)
69279037
$
