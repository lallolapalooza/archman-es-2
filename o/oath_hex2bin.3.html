oath_hex2bin(3) liboath oath_hex2bin(3)

NOMBRE

oath_hex2bin - función de la API

SINOPSIS

#include <oath.h>

int oath_hex2bin(const char * hexstr, char * binstr, size_t * binlen);

ARGUMENTOS

const char * hexstr
cadena de entrada con datos hexadecimales
char * binstr
cadena de salida que contiene datos binarios, o NULL
size_t * binlen
variable de salida que contiene la longitud necesaria de binstr

DESCRIPCIÓN

Convierte una cadena con datos hexadecimales a datos binarios.

Los datos no hexadecimales no se ignoran, sino que provocan un error OATH_INVALID_HEX.

Si binstr es NULL, entonces binlen se poblará con la longitud necesaria. Si el búfer binstr es demasiado pequeño, se devuelve OATH_TOO_SMALL_BUFFER y binlen contendrá la longitud necesaria.

RETORNA

En caso de éxito, se devuelve OATH_OK (cero), de lo contrario se devuelve un código de error.
