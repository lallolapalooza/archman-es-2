Métodos

void RegistrarPuntoFinal(object punto_final, dict propiedades)

Registra un punto final local para el remitente, el remitente puede registrar tantos puntos finales como desee.

Nota: Si el remitente se desconecta, los puntos finales se anulan automáticamente.

posibles propiedades:

string UUID
UUID del perfil para el que es el punto final.

El UUID debe estar en la lista de UUIDs Soportados.

byte Codec
Número asignado del códec que implementa el punto final. Los valores deben coincidir con la especificación del perfil indicada por el UUID.
uint32_t Proveedor [Opcional]
Identificación de Empresa de Códec Específico del Proveedor, tupla de ID de Códec que implementa el punto final.

Debe establecerse al valor apropiado cuando se utiliza el Códec Específico del Proveedor (0xff).

array{byte} Capacidades
Bloque de capacidades, se usa tal cual, por lo que el tamaño y el orden de bytes deben coincidir.
array{byte} Metadatos [Opcional]
Bloque de metadatos, se usa tal cual, por lo que el tamaño y el orden de bytes deben coincidir.

Posibles Errores:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.NoSoportado
emitido cuando la interfaz para el punto final está deshabilitada

void AnularRegistroPuntoFinal(object punto_final)

Anula el registro del punto final del remitente.

void RegistrarReproductor(object reproductor, dict propiedades)

Registra un objeto reproductor de medios para el remitente, el remitente puede registrar tantos objetos como desee.

El objeto debe implementar al menos org.mpris.MediaPlayer2.Player según se define en la especificación MPRIS 2.2:

http://specifications.freedesktop.org/mpris-spec/latest/

Nota: Si el remitente se desconecta, sus objetos se anulan automáticamente.

Posibles Errores:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.NoSoportado

void AnularRegistroReproductor(object reproductor)

Anula el registro del reproductor de medios del remitente.

void RegistrarAplicacion(object raiz, dict opciones)

Registra puntos finales y objetos de reproductor dentro del objeto raíz, que debe implementar org.freedesktop.DBus.ObjectManager.

La ruta del objeto de la aplicación junto con el ID de conexión del bus del sistema D-Bus definen la identificación de la aplicación.

Posibles errores:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.YaExiste

void AnularRegistroAplicacion(object aplicacion)

Esto anula el registro de los servicios que se registraron previamente.

El parámetro de ruta del objeto debe coincidir con el mismo valor que se utilizó en el registro.

Posibles errores:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.NoExiste

Propiedades

array{string} UUIDsSoportados [solo-lectura]

Lista de UUIDs de 128 bits que representan el registro de Punto Final soportado.

array{string} CaracteristicasSoportadas [solo-lectura]

Lista de cadenas que representan características especiales soportadas.

Posibles valores:

"tx-timestamping"
La marca de tiempo TX de Bluetooth en los sockets de flujo de medios es compatible con BlueZ y el kernel. Las aplicaciones pueden verificar la compatibilidad del kernel para tipos de marcas de tiempo específicos a través de SIOCETHTOOL.
