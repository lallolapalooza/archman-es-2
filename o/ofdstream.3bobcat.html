ofdstream(3bobcat) Flujo de salida de descriptor de archivo ofdstream(3bobcat)

NOMBRE

FBB::Ofdstream - Flujo de salida inicializado por un descriptor de archivo

SINOPSIS

#include <bobcat/ofdstream>

DESCRIPCIÓN

Los objetos FBB::Ofdstream se pueden usar para insertar información en un dispositivo del cual se dispone de su descriptor de archivo.

Los descriptores de archivo no están definidos dentro del contexto de C++, pero se pueden usar en sistemas operativos que soportan el concepto. Tenga en cuenta que el uso de descriptores de archivo introduce dependencias del sistema operativo.

Observe que los sockets se pueden usar como descriptores de archivo.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::ostream

CONSTRUCTORES

o
OFdStream(int fd, size_t n = 1):
El constructor inicializa el objeto para escribir en el descriptor fd, usando un búfer de tamaño n, que por defecto tiene tamaño 1.

Los constructores de copia y movimiento (y operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::ostream están disponibles, ya que FBB::OFdStream hereda de esta clase. No hay miembros adicionales.

EJEMPLO

Consulte la página del manual clientsocket(3bobcat) para ver un ejemplo que muestra cómo usar OFdStream.

ARCHIVOS

bobcat/ofdstream - define la interfaz de la clase

VER TAMBIÉN

bobcat(7), ifdstream(3bobcat), ofdbuf(3bobcat)

ERRORES

El objeto OFdStream utiliza un OFdBuf para su std::streambuf. Este búfer está asociado al descriptor de archivo pasado al constructor de OFdStream. Cuando el objeto OFdStream sale del ámbito, el dispositivo (archivo, socket, etc.) al que se pasó el descriptor de archivo en el constructor de OFdStream no se cierra.
