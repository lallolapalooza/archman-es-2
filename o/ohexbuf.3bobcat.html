FBB::OHexBuf(3bobcat) Escribe valores hexadecimales FBB::OHexBuf(3bobcat)

NOMBRE

FBB::OHexBuf - Escribe caracteres escritos en un ostream como valores hexadecimales

SINOPSIS

#include <bobcat/ohexbuf>
Opción de enlace: -lbobcat

DESCRIPCIÓN

OHexBuf es una especialización de FBB::OFilterBuf que inserta todos los caracteres que recibe en un archivo de destino como valores hexadecimales de 2 caracteres de ancho. Opcionalmente, se puede especificar una longitud máxima de línea.

Tenga en cuenta que toda la información recibida por un objeto OHexBuf se inserta como (una serie de) valores hexadecimales, no solo caracteres simples. Por ejemplo, al insertar el valor 123 se insertan sucesivamente los caracteres ’1’, ’2’ y ’3’, y por lo tanto, esto resultará en que la cadena 313233 se inserte en el flujo de destino.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

FBB::OFilterBuf

CONSTRUCTOR

o
OHexBuf(std::ostream &stream, size_t width = 0, std::string const &separator = ""):
Los caracteres hexadecimales producidos por el objeto OFilterBuf se insertan en stream. Opcionalmente, se puede especificar el ancho máximo de línea (en número de caracteres) usando width. El valor (por defecto) 0 indica que no se solicitan saltos de línea. El parámetro separator define el separador que se inserta entre los valores de caracteres hexadecimales. Por defecto, no se utiliza ningún separador.

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

El destructor escribe cualquier información en el búfer en el flujo de destino y luego vacía el flujo de destino. Finalmente, el destructor restaura las banderas de formato originales del ostream receptor.

FUNCIONES MIEMBRO

Todos los miembros de FBB::OFilterBuf, en particular sus miembros out() y reset, están disponibles, ya que FBB::OHexBuf hereda de esta clase.

o
void eoi():
Este miembro completa la conversión de caracteres hexadecimales actual, borra el separador y deja de utilizar un ancho de línea de salida máximo. En lugar de llamar a este miembro, se puede usar el manipulador eoi (ver más abajo).
o
void separator(bool reset = true):
Este miembro borra el separador que se inserta entre los valores de caracteres hexadecimales. Cuando el parámetro reset se establece en true (que es el valor por defecto) el ancho de salida actual se restablece a 0.
o
void separator(std::string const &separator, bool reset = true):
Este miembro restablece el separador que se inserta entre los valores de caracteres hexadecimales al valor de separator. Cuando el parámetro reset se establece en true (que es el valor por defecto) el ancho de salida actual se restablece a 0.
o
void setWidth(size_t width):
Este miembro establece el ancho de las líneas de salida generadas a width caracteres. No se utiliza un ancho de línea máximo cuando se especifica width = 0.
o
size_t size() const:
Este miembro devuelve el siguiente desplazamiento de columna donde aparecerá el siguiente carácter hexadecimal. Si se solicita un ancho de línea máximo y size() no devuelve 0, entonces la última línea insertada no fue terminada por un carácter ’\n’. Ver también el ejemplo a continuación.
El valor de retorno de este miembro no está definido si no se solicitó un ancho de línea máximo.

MANIPULADOR

o
FBB::eoi:
El manipulador eoi se puede insertar en el ostream para completar la conversión hexadecimal. Actúa de manera idéntica a llamar al miembro end. Si se inserta en un std::ostream normal, no sucede nada.

MIEMBRO ESTÁTICO

o
std::string text2bin(std::string const &in):
Este miembro estático convierte una serie de caracteres hexadecimales generados por un objeto OHexBuf de nuevo a su forma binaria. Por ejemplo, cuando se llama como OHexBuf::text2bin("736d616c6c206976"), la std::string devuelta contendrá 8 caracteres, teniendo respectivamente los valores binarios 0x73, 0x6d, 0x61, 0x6c, 0x6c, 0x20, 0x69 y 0x76.
Esta función no verifica si su argumento está correctamente formado. Un argumento correctamente formado consiste en un número par de caracteres numéricos hexadecimales (’0’ hasta ’9’, ’a’ hasta ’f’ (o en mayúsculas)). Para argumentos mal formados, el valor de retorno no está definido.

EJEMPLO

    #include <iostream>
    #include <bobcat/ohexbuf>
    using namespace std;
    using namespace FBB;
    int main()
    {
        OHexBuf ohex(cout, 40);
        ostream out(&ohex);
        out << cin.rdbuf();
        if (ohex.size())
            cout << ’\n’;
    }
