OCAMLRUN(1) Manual de Comandos Generales OCAMLRUN(1)

NOMBRE

ocamlrun - El intérprete de bytecode de OCaml

SINOPSIS

ocamlrun [ opciones ] nombre_archivo argumento ...

DESCRIPCIÓN

El comando ocamlrun(1) ejecuta archivos de bytecode producidos por la fase de enlazado del comando ocamlc(1).

El primer argumento que no sea una opción se considera el nombre del archivo que contiene el ejecutable de bytecode. (Ese archivo se busca en la ruta de ejecutables, así como en el directorio actual.) Los argumentos restantes se pasan al programa OCaml, en el array de cadenas Sys.argv. El elemento 0 de este array es el nombre del archivo ejecutable de bytecode; los elementos del 1 al n son los argumentos restantes.

En la mayoría de los casos, los archivos ejecutables de bytecode producidos por el comando ocamlc(1) son auto-ejecutables y logran lanzar automáticamente el comando ocamlrun(1) sobre sí mismos.

OPCIONES

Las siguientes opciones de línea de comandos son reconocidas por ocamlrun(1).

-b
Cuando el programa aborta debido a una excepción no capturada, imprime un "rastreo" detallado de la ejecución, mostrando dónde se lanzó la excepción y qué llamadas a funciones estaban pendientes en ese momento. El rastreo solo se imprime si el ejecutable de bytecode contiene información de depuración, es decir, si se compiló y enlazó con la opción -g de ocamlc(1). Esta opción es equivalente a establecer la bandera b en la variable de entorno OCAMLRUNPARAM (ver más abajo).
-I dir
Busca en el directorio dir bibliotecas cargadas dinámicamente, además de la ruta de búsqueda estándar.
-m archivo
Imprime el número mágico del ejecutable de bytecode archivo y sale.
-M
Imprime el número mágico esperado para ejecutables de bytecode por esta versión del runtime y sale.
-p
Imprime los nombres de las primitivas conocidas por esta versión de ocamlrun(1) y sale.
-t
Incrementa el nivel de rastreo para el runtime de depuración (ignorado por el runtime estándar).
-v
Dirige al gestor de memoria para que imprima mensajes detallados en la salida estándar de error. Esto es equivalente a establecer v=63 en la variable de entorno OCAMLRUNPARAM (ver más abajo).
-version
Imprime la cadena de versión y sale.
-vnum
Imprime el número de versión corto y sale.

VARIABLES DE ENTORNO

Las siguientes variables de entorno también son consultadas:

CAML_LD_LIBRARY_PATH
Directorios adicionales para buscar bibliotecas cargadas dinámicamente.
OCAMLLIB
El directorio que contiene la biblioteca estándar de OCaml. (Si OCAMLLIB no está configurado, se usará CAMLLIB.) Se usa para localizar el archivo de configuración ld.conf para la carga dinámica. Si no está configurado, por defecto será el directorio de bibliotecas especificado al compilar OCaml.
OCAMLRUNPARAM
Establece las opciones del sistema de ejecución y los parámetros de recolección de basura. (Si OCAMLRUNPARAM no está configurado, se usará CAMLRUNPARAM.) Esta variable debe ser una secuencia de especificaciones de parámetros separadas por comas. Una especificación de parámetro es una letra, seguida opcionalmente por un signo = , un número decimal (o un número hexadecimal prefijado por 0x), y un multiplicador opcional. Si la letra va seguida de algo más, la opción correspondiente se establece en 1. Las letras desconocidas se ignoran. Las opciones se documentan a continuación; las opciones a,i,l,m,M,n,o,O,s,v,w corresponden a los campos del registro control documentados en El manual del usuario de OCaml, capítulo "Biblioteca estándar", sección "Gc".
a (política_asignación)
La política utilizada para la asignación en el heap de OCaml. Los valores posibles son 0 para la política next-fit, 1 para la política first-fit y 2 para la política best-fit. El valor por defecto es 2. Ver la documentación del módulo Gc para más detalles.
b
Activa la impresión de un rastreo de pila cuando una excepción no capturada aborta el programa. Esta opción no toma ningún argumento.
c
(limpieza_al_salir) Cierra el runtime de forma elegante al salir. La opción también activa la agrupación (pooling) (como en caml_startup_pooled). Este modo puede usarse para detectar fugas con un depurador de memoria de terceros.
h
El tamaño inicial del heap principal (en palabras).
H
Asigna fragmentos de heap usando mmap con páginas grandes. Las páginas grandes están bloqueadas en memoria y no se intercambian.
i (incremento_heap_principal)
El incremento de tamaño por defecto para el heap principal (en palabras si es mayor que 1000, de lo contrario en porcentajes del tamaño del heap).
l (límite_pila)
El límite (en palabras) del tamaño de la pila.
m (ratio_menor_personalizado)
Límite de basura flotante para la memoria fuera del heap mantenida por valores personalizados en el heap menor. Se activa un GC menor cuando esta cantidad de memoria es mantenida por valores personalizados ubicados en el heap menor. Expresado como un porcentaje del tamaño del heap menor. Nota: esto solo se aplica a valores asignados con caml_alloc_custom_mem (p. ej., bigarrays). Por defecto: 100.
M (ratio_mayor_personalizado)
Ratio objetivo de basura flotante respecto al tamaño del heap principal para la memoria fuera del heap mantenida por valores personalizados ubicados en el heap principal. La velocidad del GC se ajusta para intentar usar esta cantidad de memoria para valores muertos que aún no se han recolectado. Expresado como un porcentaje del tamaño del heap principal. El valor por defecto mantiene el tamaño de la basura flotante fuera del heap aproximadamente igual a la sobrecarga dentro del heap. Nota: esto solo se aplica a valores asignados con caml_alloc_custom_mem (p. ej., bigarrays). Por defecto: 44.
n (tamaño_máximo_menor_personalizado)
Cantidad máxima de memoria fuera del heap para cada valor personalizado asignado en el heap menor. Cuando un valor personalizado se asigna en el heap menor y contiene más de esta cantidad de bytes, solo este valor se cuenta contra custom_minor_ratio y el resto se cuenta directamente contra custom_major_ratio. Nota: esto solo se aplica a valores asignados con caml_alloc_custom_mem (p. ej., bigarrays). Por defecto: 8192 bytes.
o (sobrecarga_espacio)
La configuración de velocidad del GC principal.
O (sobrecarga_máxima)
La configuración del disparador de compactación del heap.
p
Activa el soporte de depuración para parsers generados por ocamlyacc. Cuando esta opción está activada, el autómata de pila que ejecuta los parsers imprime un rastreo de sus acciones. Esta opción no toma ningún argumento.
R
Activa la aleatorización de todas las tablas hash por defecto (ver el módulo Hashtbl de la biblioteca estándar). Esta opción no toma ningún argumento.
s (tamaño_heap_menor)
El tamaño del heap menor (en palabras).
t
Establece el nivel de rastreo para el runtime de depuración (ignorado por el runtime estándar).
v (detallado)
Qué mensajes del GC imprimir en la salida de error estándar. Esto es una suma de valores seleccionados de lo siguiente:

0x001 Inicio

ocamlrun(1) - Arch manual pages

NAME

ocamlrun - OCaml bytecode interpreter

SYNOPSIS

ocamlrun [ -option ... ] program [ args ... ]

ocamlrun -v

ocamlrun -version

DESCRIPTION

ocamlrun is the runtime system for OCaml programs compiled with ocamlc(1). It interprets the bytecode generated by the compiler and executes it.

The first argument to ocamlrun (if it is not an option starting with -) is taken as the bytecode program to execute. This program is typically a file named a.out or program.byte. Any further arguments are passed as command-line arguments to the executed program.

If the first argument is -, it is interpreted as the program to execute. This allows ocamlrun to be used with `exec`.

The options described below control the behavior of the runtime system, primarily concerning memory management (garbage collection).

OPTIONS

-param=value
Set the runtime parameter param to value. The recognized parameters are the same as the environment variable CAMLRUNPARAM. The value can be preceded by a multiplier: k (2^10), M (2^20), or G (2^30).

For example, -s=10M sets the initial minor heap size to 10 megabytes.

-help
Print a list of available runtime options and exit.
-version
Print the version of the OCaml runtime system and exit.
-v
Same as -version.

ENVIRONMENT VARIABLES

CAMLRUNPARAM
This environment variable allows to configure the runtime system parameters. The value is a list of param=value pairs, separated by commas. The available parameters are:
c (check_naive_barriers)
Checks that the naive barrier checks are efficient enough. It should be 0 (disabled) or 1 (enabled). (Default: 0)
e (major_bucket_size)
The size in words of the buckets used for major GC slice computation. (Default: 1)
f (major_force_slice)
Forces the computation of the major GC slice size. This option is reserved for the use of the runtime system itself. (Default: 0)
h (heap_size)
Initial size of the heap in words. (Default: 256)
l (stack_size)
Maximum size of the stack in words. (Default: 512)
m (major_slice_size)
The size in words of the major GC slice. (Default: 1024)
p (allocation_chunks)
The size in words of the chunks allocated for stacks and arrays. (Default: 1)
s (minor_heap_size)
Initial size of the minor heap in words. (Default: 256)
t (allocation_threshold)
The allocation threshold triggering a major GC cycle. (Default: 16)
u (major_gcthresh)
The threshold (in words) for triggering a major GC cycle. (Default: 1024)
v (verbose)
A bitmask to control the verbosity of the GC. The bits are:
0x001
End of major GC cycle.
0x002
Minor collection and major GC slice.
0x004
Growing and shrinking of the heap.
0x008
Resizing of stacks and memory manager tables.
0x010
Heap compaction.
0x020
Change of GC parameters.
0x040
Computation of major GC slice size.
0x080
Calling of finalisation functions.
0x100
Startup messages (loading the bytecode executable file, resolving shared libraries).
0x200
Computation of compaction-triggering condition.
0x400
Output GC statistics at program exit, in the same format as Gc.print_stat.
0x800
GC debugging messages.
0x1000
Address space reservation changes.
w (window_size)
Set size of the window used by major GC for smoothing out variations in its workload. This is an integer between 1 and 50. (Default: 1)
W
Print runtime warnings to stderr (such as Channel opened on file dies without being closed, unflushed data, etc.)
The multiplier is k,M, or G, for multiplication by 2^10, 2^20, and 2^30 respectively.

If the option letter is not recognized, the whole parameter is ignored; if the equal sign or the number is missing, the value is taken as 1; if the multiplier is not recognized, it is ignored.

For example, on a 32-bit machine under bash, the command export OCAMLRUNPARAM='s=256k,v=1' tells a subsequent ocamlrun to set its initial minor heap size to 1 megabyte and to print a message at the start of each major GC cycle.

CAMLRUNPARAM
If OCAMLRUNPARAM is not found in the environment, then CAMLRUNPARAM will be used instead. If CAMLRUNPARAM is also not found, then the default values will be used.
PATH
List of directories searched to find the bytecode executable file.
