OPTIRUN(1) Comandos de usuario OPTIRUN(1)

NOMBRE

optirun - ejecuta programas en la tarjeta de video discreta

SINOPSIS

optirun [OPCIÓN]... comando [opciones del comando...]

DESCRIPCIÓN

Ejecuta una aplicación usando la tarjeta de video discreta.

--failsafe
ejecuta un programa incluso si la tarjeta nvidia no está disponible
--no-failsafe
no ejecuta un programa si la tarjeta nvidia no está disponible
--no-xorg
no inicia el servidor X secundario (implica -b none)
-b, --bridge MÉTODO
puente de aceleración/visualización a usar. Los valores válidos son auto, virtualgl y primus. Las opciones --vgl-* solo tienen sentido cuando se usa el puente virtualgl, mientras que las opciones --primus-* se aplican solo cuando se usa el puente primus. Adicionalmente, se reconoce el valor none, y su efecto es agregar rutas a las bibliotecas del controlador a LD_LIBRARY_PATH (útil para aplicaciones nvidia-settings y CUDA)
-c, --vgl-compress MÉTODO
compresión de imagen o transporte a usar con VirtualGL. Los valores válidos para MÉTODO son proxy, jpeg, rgb, xv e yuv. Cambiar esta configuración puede afectar el rendimiento, el uso de la CPU y la calidad de la imagen
--vgl-options OPTS
una lista separada por espacios de opciones de comandos que se pasarán a vglrun. Útil para depurar virtualgl pasando opciones como +tr. Estas OPTS anulan la configuración de optirun, así que tenga cuidado al configurarla
--primus-ldpath RUTA
una lista separada por dos puntos de rutas que se buscan para primus libGL.so.1
-q, --quiet, --silent
suprime todos los mensajes de registro
-v, --verbose
aumenta el nivel de verbosidad de los mensajes de registro. Se puede especificar hasta dos veces (o cinco si se usa --quiet)
--debug
muestra todos los mensajes de registro estableciendo el nivel de verbosidad al máximo
-C, --config ARCHIVO
recupera la configuración de Bumblebee desde ARCHIVO
-d, --display VPANTALLA
encuentra el servidor X de Bumblebee en VPANTALLA. No confunda esta opción con la variable de entorno DISPLAY. Por defecto, la ruta se consulta desde el demonio
-l, --ldpath RUTA
se buscan bibliotecas como libGL.so en RUTA (útil para el controlador nvidia). Por defecto, RUTA se consulta desde el
-s, --socket NOMBRE DE ARCHIVO
usa NOMBRE DE ARCHIVO para la comunicación con el demonio
-h, --help
muestra esta ayuda y sale
--version
muestra información de la versión y sale

EJEMPLOS

optirun glxspheres
Ejecuta la demo gráfica suministrada con Virtual GL.
optirun -c yuv glxspheres
Ejecuta un programa con el método de transporte yuv para un mejor rendimiento.
optirun firefox http://example.com
Ejecuta un programa con argumentos.
