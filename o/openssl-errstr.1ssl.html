NOMBRE

openssl-errstr - buscar códigos de error

SINOPSIS

openssl errstr [-help] código_de_error...

DESCRIPCIÓN

A veces, una aplicación no cargará textos de mensajes de error y solo estarán disponibles las formas numéricas. Este comando se puede usar para mostrar el significado del código hexadecimal. El código hexadecimal son los dígitos hexadecimales después del segundo dos puntos.

OPCIONES

-help
Mostrar un mensaje de uso.

EJEMPLOS

El código de error:

27594:error:2006D080:lib(32)::reason(128)::107:

se puede mostrar con:

openssl errstr 2006D080

para producir el mensaje de error:

error:2006D080:BIO routines::no such file
