oct-admin(1) Manual de comandos generales oct-admin(1)

NOMBRE

oct-admin - Administra datos en una tarjeta (incluyendo claves y metadatos)

SINOPSIS

oct admin <-c|--card> [-P|--admin-pin] [-h|--help] <subcomandos>

DESCRIPCIÓN

Administra datos en una tarjeta (incluyendo claves y metadatos)

OPCIONES

-c, --card=identificador de tarjeta
Identificador de la tarjeta a usar
-P, --admin-pin=Archivo PIN de administrador
Opcionalmente, obtén el PIN de administrador de un archivo
-h, --help
Imprime la ayuda

SUBCOMANDOS

oct-admin-name(1)
Establece el nombre del titular de la tarjeta
oct-admin-url(1)
Establece la URL del certificado
oct-admin-signing-pin-validity(1)
Configura si la presentación del PIN de usuario es válida solo para una operación de firma, o para operaciones de firma ilimitadas
oct-admin-import(1)
Importa una clave en la tarjeta
oct-admin-generate(1)
Genera una clave en la tarjeta
oct-admin-touch(1)
Establece la política táctil de la tarjeta (si es compatible)
oct-admin-help(1)
Imprime este mensaje o la ayuda de los subcomandos dados
oct-admin
