NOMBRE

openxr_runtime_list_json — Una pequeña aplicación OpenXR que informa sobre tu tiempo de ejecución OpenXR en formato JSON

SINOPSIS

openxr_runtime_list_json

DESCRIPCIÓN

openxr_runtime_list_json es una pequeña aplicación no interactiva escrita utilizando la API OpenXR, que emite datos sobre tu tiempo de ejecución a la salida estándar en formato JSON.

No acepta argumentos. Los datos informados están destinados a parecerse al formato de archivo utilizado por OpenXR-Inventory, para que la salida pueda ser redirigida a un archivo y luego editada para realizar actualizaciones en esa base de datos.

CÓDIGO DE SALIDA

La utilidad openxr_runtime_list_json sale con 0 en caso de éxito, y >0 si ocurre un error.
