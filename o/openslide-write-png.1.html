OPENSLIDE-WRITE-PNG(1) Comandos de usuario OPENSLIDE-WRITE-PNG(1)

NOMBRE

openslide-write-png - Escribir una región de una diapositiva virtual a un PNG

SINOPSIS

openslide-write-png [--ayuda] [--versión] archivo-diapositiva x y nivel ancho alto archivo-salida

DESCRIPCIÓN

Escribe una región del nivel especificado de una diapositiva virtual a una imagen PNG. x e y son coordenadas de píxeles en el nivel 0, el nivel de diapositiva de mayor resolución. ancho y alto son dimensiones en píxeles en el nivel especificado.

Las dimensiones de cada nivel de una diapositiva se pueden obtener con openslide-show-properties(1).

OPCIONES

--ayuda
Muestra el resumen de uso.
--versión
Muestra la información de versión y derechos de autor.

ESTADO DE SALIDA

openslide-write-png devuelve 0 en caso de éxito, 1 si ocurrió un error o 2 si los argumentos son inválidos.

NOTAS

openslide-write-png es un comando obsoleto y no se añadirán nuevas funcionalidades. Su reemplazo es el subcomando region read de slidetool(1).
