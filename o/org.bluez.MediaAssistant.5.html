Nombre

org.bluez.MediaAssistant - Documentación de la API MediaAssistant de D-Bus de BlueZ

Interfaz

Servicio
org.bluez
Interfaz
org.bluez.MediaAssistant1
Ruta del objeto
/org/bluez/{hci0,hci1,...}/dev_{BDADDR}/src_{BDADDR}/sid#/bis#

Métodos

void Push(dict propiedades)

Enviar información de flujo al dispositivo remoto.

dict propiedades

Indica las propiedades del flujo que se enviarán al par.

Valores:

array{byte} Metadata [solo ISO]
Ver propiedad Metadata.
dict QoS [solo ISO]
Ver propiedad QoS.
object Dispositivo [solo ISO, Estado=solo local]
Enviar a un dispositivo específico. El dispositivo debe estar conectado y con una sesión BASS activa.

Propiedades

string Estado [solo lectura]

Indica el estado del objeto asistente. Los valores posibles son:

"idle"
el objeto asistente se creó para el flujo
"pending"
el objeto asistente se envió (la información del flujo se envió al par)
"requesting"
el dispositivo remoto requiere Broadcast_Code
"active"
el dispositivo remoto comenzó a recibir el flujo
"local"
el objeto asistente se creó para un flujo local

array{byte} Metadata [lectura/escritura, solo ISO, experimental]

Indica los metadatos del flujo.

dict QoS [lectura/escritura, solo ISO, experimental]

Indica las capacidades de QoS del flujo.

Valores:

byte Encryption
Indica si el flujo está cifrado.

:array{byte} BCode

Indica el código de difusión para descifrar el flujo.
