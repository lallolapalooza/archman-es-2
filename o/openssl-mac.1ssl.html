NOMBRE

openssl-mac - realizar operaciones de Código de Autenticación de Mensajes

SINOPSIS

openssl mac [-help] [-cipher] [-digest] [-macopt] [-in archivo] [-out archivo] [-binary] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq] nombre_mac

DESCRIPCIÓN

Las funciones de código de autenticación de mensajes generan el MAC de un archivo de entrada proporcionado.

OPCIONES

-help
Muestra un mensaje de uso.
-in archivo
Nombre del archivo de entrada para calcular un MAC, o entrada estándar por defecto. La entrada estándar se utiliza si el nombre del archivo es '-'. Se espera que los archivos y la entrada estándar estén en formato binario.
-out archivo
Nombre del archivo de salida, o salida estándar por defecto.
-binary
Salida del MAC en formato binario. Utiliza formato de texto hexadecimal si no se especifica.
-cipher nombre
Utilizado por CMAC y GMAC para especificar el algoritmo de cifrado. Para CMAC debe ser un cifrado en modo CBC, por ejemplo, AES-128-CBC. Para GMAC debe ser un cifrado en modo GCM, por ejemplo, AES-128-GCM.
-digest nombre
Utilizado por HMAC como una cadena alfanumérica (usar si la clave contiene solo caracteres imprimibles). La longitud de la cadena debe cumplir cualquier restricción del algoritmo MAC. Para ver la lista de resúmenes soportados, usar "openssl list -digest-commands".
-macopt nm:v
Pasa opciones al algoritmo MAC. Una lista completa de controles se puede encontrar en la documentación de la implementación de EVP_MAC. Los nombres de parámetros comunes utilizados por EVP_MAC_CTX_get_params() son:
key:cadena
Especifica la clave MAC como una cadena alfanumérica (usar si la clave contiene solo caracteres imprimibles). La longitud de la cadena debe cumplir cualquier restricción del algoritmo MAC. Se debe especificar una clave para cada algoritmo MAC.
hexkey:cadena
Especifica la clave MAC en formato hexadecimal (dos dígitos hexadecimales por byte). La longitud de la clave debe cumplir cualquier restricción del algoritmo MAC. Se debe especificar una clave para cada algoritmo MAC.
iv:cadena
Utilizado por GMAC para especificar un IV como una cadena alfanumérica (usar si el IV contiene solo caracteres imprimibles).
hexiv:cadena
Utilizado por GMAC para especificar un IV en formato hexadecimal (dos dígitos hexadecimales por byte).
size:int
Utilizado por KMAC128 o KMAC256 para especificar una longitud de salida. Los tamaños por defecto son 32 o 64 bytes respectivamente.
custom:cadena
Utilizado por KMAC128 o KMAC256 para especificar una cadena de personalización. Por defecto es la cadena vacía "".
digest:cadena
Esta opción es idéntica a la opción -digest.
cipher:cadena
Esta opción es idéntica a la opción -cipher.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Ver "Opciones de Proveedor" en openssl(1), provider(7), y property(7).
nombre_mac
Especifica el nombre de un algoritmo MAC soportado que se utilizará. Para ver la lista de MACs soportados, usa el comando "openssl list -mac-algorithms".

EJEMPLOS

Para crear un MAC HMAC-SHA1 codificado en hexadecimal de un archivo y escribirlo en la salida estándar:

openssl mac -digest SHA1 \
        -macopt hexkey:000102030405060708090A0B0C0D0E0F10111213 \
        -in msg.bin HMAC

Para crear un MAC SipHash desde un archivo con salida binaria:

openssl mac -macopt hexkey:000102030405060708090A0B0C0D0E0F \
        -in msg.bin -out out.bin -binary SipHash

Para crear un MAC CMAC-AES-128-CBC codificado en hexadecimal desde un archivo:

openssl mac -cipher AES-128-CBC \
        -macopt hexkey:77A77FAF290C1FA30C683DF16BA7A77B \
        -in msg.bin CMAC

Para crear un MAC KMAC128 codificado en hexadecimal con una Cadena de Personalización 'Tag' y una longitud de salida de 16:

openssl mac -macopt custom:Tag -macopt hexkey:40414243444546 \
        -macopt size:16 -in msg.bin KMAC128

Para crear un GMAC-AES-128-GCM con un IV codificado en hexadecimal desde un archivo:

openssl mac -cipher AES-128-GCM -macopt hexiv:E0E00F19FED7BA0136A797F3 \
        -macopt hexkey:77A77FAF290C1FA30C683DF16BA7A77B -in msg.bin GMAC

NOTAS

Los mecanismos MAC disponibles dependerán de las opciones utilizadas al compilar OpenSSL. Usa "openssl list -mac-algorithms" para listarlos.

Name

openssl-mac - MAC (Message Authentication Code) utilities

Synopsis

openssl mac [-help] [-list] [-cipher] [-text] [-hex] [-inform PEM|DER|TXT|ENGINE] [-outform PEM|DER|TXT|ENGINE] [-in filename] [-out filename] [-passin arg] [-passout arg] [-provider arg] [-provider-ctx arg] [-propquery arg] [-nonce_from_file file] [-salt_from_file file] [-key_from_file file] [-iv_from_file file] [-mac_from_file file] [-digest arg] [-cipher_name arg] [-iter arg] [-pbkdf arg] [-md arg] [-mac_key_len arg] [-mac_len arg] [-nonce_len arg] [-salt_len arg] [-tag_len arg] [-pbe arg] [-enc arg] [-debug] [-verbose] [-engine id] [-rand file ...] [-writer file]

Description

The MAC utilities provide the functionality to calculate, verify and retrieve MAC (Message Authentication Code) values for data. A MAC is a small piece of information used to authenticate a message in computing. It is a type of checksum generated through a specific algorithm and a secret key.

The MAC command can be used in several ways:

  • Calculate a MAC for a given input data.
  • Verify a given MAC against calculated MAC for the input data.
  • Retrieve MAC algorithms supported by the OpenSSL library.

The available MAC algorithms depend on the OpenSSL configuration and the loaded cryptographic providers. Some common algorithms include:

  • HMAC (Hash-based Message Authentication Code) using various hash functions like SHA256, SHA512, MD5, etc.
  • CMAC (Cipher-based Message Authentication Code) using block ciphers like AES.
  • Poly1305, a one-time authenticator.

Key Management:

The MAC utilities support various methods for providing the secret key:

  • Directly as a password/passphrase.
  • From a file.
  • From environment variables.
  • Using specific key derivation functions (KDFs) like PBKDF2, HKDF, etc.

Data Input/Output:

Input data can be provided from standard input or a file. The output MAC value can be displayed in hexadecimal format, as raw bytes, or in PEM/DER encoding (for specific MAC types).

Options

-help
Print a usage message.
-list
List all available MAC algorithms.
-cipher
Specify the MAC algorithm to use (e.g., hmac, cmac, poly1305).
-text
Output the MAC in a human-readable format.
-hex
Output the MAC in hexadecimal format.
-inform PEM|DER|TXT|ENGINE
Input format for the key or other parameters.
-outform PEM|DER|TXT|ENGINE
Output format for the MAC.
-in filename
Input file for the data to be authenticated.
-out filename
Output file for the calculated MAC.
-passin arg
Password source for the input key.
-passout arg
Password source for the output key (if applicable).
-provider arg
Specify a cryptographic provider.
-provider-ctx arg
Context for the provider.
-propquery arg
Property query for selecting algorithms.
-nonce_from_file file
Load nonce from a file.
-salt_from_file file
Load salt from a file.
-key_from_file file
Load key from a file.
-iv_from_file file
Load Initialization Vector (IV) from a file.
-mac_from_file file
Load an existing MAC from a file for verification.
-digest arg
Specify the digest algorithm for HMAC (e.g., sha256).
-cipher_name arg
Specify the cipher name for CMAC (e.g., aes-128-cbc).
-iter arg
Number of iterations for key derivation.
-pbkdf arg
Specify the Password-Based Key Derivation Function (PBKDF).
-md arg
Specify the digest algorithm for PBE.
-mac_key_len arg
Desired length of the MAC key.
-mac_len arg
Desired length of the MAC tag.
-nonce_len arg
Desired length of the nonce.
-salt_len arg
Desired length of the salt.
-tag_len arg
Desired length of the authentication tag.
-pbe arg
Specify the Password-Based Encryption algorithm.
-enc arg
Specify encryption parameters.
-debug
Enable debug output.
-verbose
Increase verbosity.
-engine id
Use a specific engine.
-rand file ...
Files containing random data for seeding.
-writer file
Write output to a specific file.

Examples

Calculate an HMAC-SHA256 for a file:

openssl mac -cipher hmac -digest sha256 -in input.txt -keyform hex -pass pass:your_secret_key -out mac.bin

Verify an HMAC-SHA256 against a file:

openssl mac -cipher hmac -digest sha256 -in input.txt -keyform hex -pass pass:your_secret_key -mac_from_file mac.bin

Calculate a CMAC for data using AES-128:

echo "This is the message" | openssl mac -cipher cmac -cipher_name aes-128-cbc -keyform hex -pass pass:your_secret_key -out cmac.bin

List all available MAC algorithms:

openssl mac -list
