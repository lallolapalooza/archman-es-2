options(n) Comandos incorporados de Tk options(n)

NOMBRE

options - Opciones estándar soportadas por los widgets

DESCRIPCIÓN

Esta entrada del manual describe las opciones de configuración comunes soportadas por los widgets del toolkit Tk. No todos los widgets soportan necesariamente todas las opciones (consulte las entradas del manual de los widgets individuales para obtener una lista de las opciones estándar soportadas por ese widget), pero si un widget soporta una opción con uno de los nombres enumerados a continuación, entonces la opción tiene exactamente el efecto descrito a continuación.

En las descripciones a continuación, el «Nombre en línea de comandos» se refiere al modificador utilizado en los comandos de clase y en los comandos de widget configure para establecer este valor. Por ejemplo, si el modificador de línea de comandos de una opción es -foreground y existe un widget .a.b.c, entonces el comando

.a.b.c  configure  -foreground black
puede ser utilizado para especificar el valor black para la opción en el widget .a.b.c. Los modificadores de línea de comandos pueden abreviarse, siempre que la abreviatura no sea ambigua. El «Nombre de la base de datos» se refiere al nombre de la opción en la base de datos de opciones (por ejemplo, en los archivos .Xdefaults). La «Clase de la base de datos» se refiere al valor de clase de la opción en la base de datos de opciones.

Nombre en línea de comandos:	-activebackground
Nombre de la base de datos:	activeBackground
Clase de la base de datos:	Foreground
Especifica el color de fondo a usar al dibujar elementos activos. Un elemento (un widget o una porción de un widget) está activo si el cursor del ratón está posicionado sobre el elemento y al presionar un botón del ratón se producirá alguna acción. Si se ha solicitado el cumplimiento estricto de Motif estableciendo la variable tk_strictMotif, esta opción normalmente se ignorará; se utilizará el color de fondo normal en su lugar. Para algunos elementos en sistemas Windows y Macintosh, el color activo solo se utilizará mientras se presione el botón del ratón 1 sobre el elemento.
Nombre en línea de comandos:	-activeborderwidth
Nombre de la base de datos:	activeBorderWidth
Clase de la base de datos:	BorderWidth
Especifica un valor no negativo que indica el ancho del borde 3D dibujado alrededor de los elementos activos. Consulte anteriormente la definición de elementos activos. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels. Esta opción normalmente solo está disponible en widgets que muestran más de un elemento a la vez (por ejemplo, menús pero no botones).
Nombre en línea de comandos:	-activeforeground
Nombre de la base de datos:	activeForeground
Clase de la base de datos:	Background
Especifica el color de primer plano a usar al dibujar elementos activos. Consulte anteriormente la definición de elementos activos.
Nombre en línea de comandos:	-anchor
Nombre de la base de datos:	anchor
Clase de la base de datos:	Anchor
Especifica cómo se debe mostrar la información en un widget (por ejemplo, texto o un mapa de bits) dentro del widget. Debe ser uno de los valores n, ne, e, se, s, sw, w, nw, o center. Por ejemplo, nw significa mostrar la información de tal manera que su esquina superior izquierda esté en la esquina superior izquierda del widget.
Nombre en línea de comandos:	-background o -bg
Nombre de la base de datos:	background
Clase de la base de datos:	Background
Especifica el color de fondo normal a usar al mostrar el widget.
Nombre en línea de comandos:	-bitmap
Nombre de la base de datos:	bitmap
Clase de la base de datos:	Bitmap
Especifica un mapa de bits para mostrar en el widget, en cualquiera de las formas aceptables para Tk_GetBitmap. La forma exacta en que se muestra el mapa de bits puede verse afectada por otras opciones como -anchor o -justify. Típicamente, si se especifica esta opción, anula otras opciones que especifican un valor de texto para mostrar en el widget, pero esto está controlado por la opción -compound; la opción -bitmap puede restablecerse a una cadena vacía para volver a habilitar una visualización de texto. En los widgets que soportan ambas opciones -bitmap y -image, -image normalmente anulará -bitmap.
Nombre en línea de comandos:	-borderwidth o -bd
Nombre de la base de datos:	borderWidth
Clase de la base de datos:	BorderWidth
Especifica un valor no negativo que indica el ancho del borde 3D a dibujar alrededor del exterior del widget (si se está dibujando dicho borde; la opción -relief normalmente determina esto). El valor también puede usarse al dibujar efectos 3D en el interior del widget. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels.
Nombre en línea de comandos:	-cursor
Nombre de la base de datos:	cursor
Clase de la base de datos:	Cursor
Especifica el cursor del ratón que se utilizará para el widget. El valor puede tener cualquiera de las formas aceptables para Tk_GetCursor. Además, si se especifica una cadena vacía, indica que el widget debe delegar al padre la especificación del cursor.
Nombre en línea de comandos:	-compound
Nombre de la base de datos:	compound
Clase de la base de datos:	Compound
Especifica si el widget debe mostrar texto y mapas de bits/imágenes al mismo tiempo, y si es así, dónde debe colocarse el mapa de bits/imagen en relación con el texto. Debe ser uno de los valores none, bottom, top, left, right, o center. Por ejemplo, el valor (por defecto) none especifica que el mapa de bits o la imagen se mostrarán (si están definidos) en lugar del texto, el valor left especifica que el mapa de bits o la imagen se mostrarán a la izquierda del texto, y el valor center especifica que el mapa de bits o la imagen se mostrarán encima del texto.
Nombre en línea de comandos:	-disabledforeground
Nombre de la base de datos:	disabledForeground
Clase de la base de datos:	DisabledForeground
Especifica el color de primer plano a usar al dibujar un elemento deshabilitado. Si la opción se especifica como una cadena vacía (que es típicamente el caso en pantallas monocromáticas), los elementos deshabilitados se dibujan con el color de primer plano normal pero se atenúan dibujándolos con un patrón de relleno estriado.
Nombre en línea de comandos:	-exportselection
Nombre de la base de datos:	exportSelection
Clase de la base de datos:	ExportSelection
Especifica si una selección en el widget también debe ser la selección X. El valor puede tener cualquiera de las formas aceptadas por Tcl_GetBoolean, como true, false, 0, 1, yes, o no. Si la selección se exporta, seleccionar en el widget anula la selección X actual, seleccionar fuera del widget anula cualquier selección del widget, y el widget responderá a las solicitudes de recuperación de selección cuando tenga una selección. Por lo general, los widgets exportan selecciones por defecto.
Nombre en línea de comandos:	-font
Nombre de la base de datos:	font
Clase de la base de datos:	Font
Especifica la fuente a usar al dibujar texto dentro del widget. El valor puede tener cualquiera de las formas descritas en la página del manual font bajo DESCRIPCIÓN DE FUENTE.
Nombre en línea de comandos:	-foreground o -fg
Nombre de la base de datos:	foreground
Clase de la base de datos:	Foreground
Especifica el color de primer plano normal a usar al mostrar el widget.
Nombre en línea de comandos:	-highlightbackground
Nombre de la base de datos:	highlightBackground
Clase de la base de datos:	HighlightBackground
Especifica el color a mostrar en la región de resaltado de recorrido cuando el widget no tiene el foco de entrada.
Nombre en línea de comandos:	-highlightcolor
Nombre de la base de datos:	highlightColor
Clase de la base de datos:	HighlightColor
Especifica el color a usar para el rectángulo de resaltado de recorrido que se dibuja alrededor del widget cuando tiene el foco de entrada.
Nombre en línea de comandos:	-highlightthickness
Nombre de la base de datos:	highlightThickness
Clase de la base de datos:	HighlightThickness
Especifica un valor no negativo que indica el ancho del rectángulo de resaltado a dibujar alrededor del exterior del widget cuando tiene el foco de entrada. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels. Si el valor es cero, no se dibuja ningún resaltado de foco alrededor del widget.
Nombre en línea de comandos:	-image
Nombre de la base de datos:	image
Clase de la base de datos:	Image
Especifica una imagen para mostrar en el widget, la cual debe haber sido creada con el comando image create. Típicamente, si se especifica la opción -image, anulará otras opciones que especifican un mapa de bits

or valor textual a mostrar en el widget, aunque esto está controlado por la opción -compound; la opción -image puede ser restablecida a una cadena vacía para volver a habilitar una visualización de mapa de bits o de texto. 
Nombre de línea de comandos: -insertbackground
Nombre de base de datos: insertBackground
Clase de base de datos: Foreground
Especifica el color a utilizar como fondo en el área cubierta por el cursor de inserción. Este color normalmente anulará el fondo normal del widget (o el fondo de selección si el cursor de inserción cae en la selección).
Nombre de línea de comandos: -insertborderwidth
Nombre de base de datos: insertBorderWidth
Clase de base de datos: BorderWidth
Especifica un valor no negativo que indica el ancho del borde 3D a dibujar alrededor del cursor de inserción. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels.
Nombre de línea de comandos: -insertofftime
Nombre de base de datos: insertOffTime
Clase de base de datos: OffTime
Especifica un valor entero no negativo que indica el número de milisegundos que el cursor de inserción debe permanecer "apagado" en cada ciclo de parpadeo. Si esta opción es cero, entonces el cursor no parpadea: está siempre encendido.
Nombre de línea de comandos: -insertontime
Nombre de base de datos: insertOnTime
Clase de base de datos: OnTime
Especifica un valor entero no negativo que indica el número de milisegundos que el cursor de inserción debe permanecer "encendido" en cada ciclo de parpadeo.
Nombre de línea de comandos: -insertwidth
Nombre de base de datos: insertWidth
Clase de base de datos: InsertWidth
Especifica un valor no negativo que indica el ancho total del cursor de inserción. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels. Si se ha especificado un borde para el cursor de inserción (usando la opción -insertborderwidth), el borde se dibujará dentro del ancho especificado por la opción -insertwidth.
Nombre de línea de comandos: -jump
Nombre de base de datos: jump
Clase de base de datos: Jump
Para widgets con un control deslizante que se puede arrastrar para ajustar un valor, como las barras de desplazamiento, esta opción determina cuándo se realizan notificaciones sobre los cambios en el valor. El valor de la opción debe ser un booleano de la forma aceptada por Tcl_GetBoolean. Si el valor es falso, las actualizaciones se realizan continuamente mientras se arrastra el control deslizante. Si el valor es verdadero, las actualizaciones se retrasan hasta que se suelta el botón del ratón para finalizar el arrastre; en ese momento se realiza una única notificación (el valor "salta" en lugar de cambiar suavemente).
Nombre de línea de comandos: -justify
Nombre de base de datos: justify
Clase de base de datos: Justify
Cuando hay varias líneas de texto mostradas en un widget, esta opción determina cómo se alinean las líneas entre sí. Debe ser uno de left, center o right. Left significa que los bordes izquierdos de las líneas se alinean, center significa que los centros de las líneas se alinean, y right significa que los bordes derechos de las líneas se alinean.
Nombre de línea de comandos: -orient
Nombre de base de datos: orient
Clase de base de datos: Orient
Para widgets que pueden autoorganizarse con una orientación horizontal o vertical, como las barras de desplazamiento, esta opción especifica qué orientación se debe utilizar. Debe ser horizontal o vertical o una abreviatura de uno de estos.
Nombre de línea de comandos: -padx
Nombre de base de datos: padX
Clase de base de datos: Pad
Especifica un valor no negativo que indica cuánto espacio adicional solicitar para el widget en la dirección X. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels. Al calcular el tamaño de ventana que necesita, el widget añadirá esta cantidad al ancho que normalmente necesitaría (según lo determinado por el ancho de los elementos mostrados en el widget); si el gestor de geometría puede satisfacer esta solicitud, el widget tendrá espacio interno adicional a la izquierda y/o derecha de lo que muestra internamente. La mayoría de los widgets solo usan esta opción para rellenar texto: si muestran un mapa de bits o una imagen, generalmente ignoran las opciones de relleno.
Nombre de línea de comandos: -pady
Nombre de base de datos: padY
Clase de base de datos: Pad
Especifica un valor no negativo que indica cuánto espacio adicional solicitar para el widget en la dirección Y. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels. Al calcular el tamaño de ventana que necesita, el widget añadirá esta cantidad a la altura que normalmente necesitaría (según lo determinado por la altura de los elementos mostrados en el widget); si el gestor de geometría puede satisfacer esta solicitud, el widget tendrá espacio interno adicional arriba y/o abajo de lo que muestra internamente. La mayoría de los widgets solo usan esta opción para rellenar texto: si muestran un mapa de bits o una imagen, generalmente ignoran las opciones de relleno.
Nombre de línea de comandos: -relief
Nombre de base de datos: relief
Clase de base de datos: Relief
Especifica el efecto 3D deseado para el widget. Los valores aceptables son raised, sunken, flat, ridge, solid y groove. El valor indica cómo debe aparecer el interior del widget en relación con su exterior; por ejemplo, raised significa que el interior del widget debe parecer que sobresale de la pantalla, en relación con el exterior del widget.
Nombre de línea de comandos: -repeatdelay
Nombre de base de datos: repeatDelay
Clase de base de datos: RepeatDelay
Especifica el número de milisegundos que se debe mantener presionado un botón o tecla antes de que comience a repetirse automáticamente. Se utiliza, por ejemplo, en las flechas hacia arriba y hacia abajo de las barras de desplazamiento.
Nombre de línea de comandos: -repeatinterval
Nombre de base de datos: repeatInterval
Clase de base de datos: RepeatInterval
Se utiliza junto con -repeatdelay: una vez que comienza la repetición automática, esta opción determina el número de milisegundos entre repeticiones automáticas.
Nombre de línea de comandos: -selectbackground
Nombre de base de datos: selectBackground
Clase de base de datos: Foreground
Especifica el color de fondo a utilizar al mostrar elementos seleccionados.
Nombre de línea de comandos: -selectborderwidth
Nombre de base de datos: selectBorderWidth
Clase de base de datos: BorderWidth
Especifica un valor no negativo que indica el ancho del borde 3D a dibujar alrededor de los elementos seleccionados. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels.
Nombre de línea de comandos: -selectforeground
Nombre de base de datos: selectForeground
Clase de base de datos: Background
Especifica el color de primer plano a utilizar al mostrar elementos seleccionados.
Nombre de línea de comandos: -setgrid
Nombre de base de datos: setGrid
Clase de base de datos: SetGrid
Especifica un valor booleano que determina si este widget controla la cuadrícula de redimensionamiento de su ventana de nivel superior. Esta opción se utiliza típicamente en widgets de texto, donde la información en el widget tiene un tamaño natural (el tamaño de un carácter) y tiene sentido que las dimensiones de la ventana sean números enteros de estas unidades. Estos tamaños de ventana naturales forman una cuadrícula. Si la opción -setgrid se establece en verdadero, el widget se comunicará con el gestor de ventanas de manera que, cuando el usuario redimensione interactivamente la ventana de nivel superior que contiene el widget, las dimensiones de la ventana se mostrarán al usuario en unidades de cuadrícula y el tamaño de la ventana se restringirá a números enteros de unidades de cuadrícula. Consulte la sección GRIDDED GEOMETRY MANAGEMENT en la entrada del manual wm para obtener más detalles.
Nombre de línea de comandos: -takefocus
Nombre de base de datos: takeFocus
Clase de base de datos: TakeFocus
Determina si la ventana acepta el foco durante la navegación por teclado (por ejemplo, Tab y Shift-Tab). Antes de establecer el foco en una ventana, los scripts de navegación consultan el valor de la opción -takefocus. Un valor de 0 significa que la ventana debe omitirse por completo durante la navegación por teclado. 1 significa que la ventana debe recibir el foco de entrada siempre que sea visible (ella y todos sus ancestros estén mapeados). Un valor vacío para la opción significa que los scripts de navegación toman la decisión sobre si enfocar o no en la ventana: el algoritmo actual es omitir la ventana si está deshabilitada, si no tiene enlaces de teclas, o si no es visible. Si el valor tiene alguna otra forma, los scripts de navegación toman el valor, le añaden el nombre de la ventana (con un espacio separador) y evalúan la cadena resultante como un script Tcl. El script debe devolver 0, 1 o una cadena vacía: un valor de 0 o 1 especifica si la ventana recibirá el foco de entrada, y una cadena vacía da como resultado la decisión predeterminada descrita anteriormente. Nota: esta interpretación de la opción está definida completamente por los scripts Tcl que implementan la navegación: las implementaciones de los widgets ignoran completamente la opción, por lo que puede cambiar su significado si redefine los scripts de navegación por teclado.
Nombre de línea de comandos: -text
Nombre de base de datos: text
Clase de base de datos: Text
Especifica una cadena que se mostrará dentro del widget. La forma en que se muestra la cadena depende del widget en particular y puede ser determinada por otras opciones, como -anchor o -justify.
Nombre de línea de comandos: -textvariable
Nombre de base de datos: textVariable
Clase de base de datos: Variable
Especifica el nombre de una variable global. El valor de la variable es una cadena de texto que se mostrará dentro del widget; si el valor de la variable cambia, el widget se actualizará automáticamente para reflejar el nuevo valor. La forma en que se muestra la cadena en el widget depende del widget en particular y puede ser determinada por otras opciones, como -anchor o -justify.
Nombre de línea de comandos: -troughcolor
Nombre de base de datos: troughColor
Clase de base de datos: Background
Especifica el color a utilizar para las áreas rectangulares de la canaleta en widgets como barras de desplazamiento y escalas. Esta opción se ignora para las barras de desplazamiento en Windows (el widget nativo no reconoce esta opción).
Nombre de línea de comandos: -underline
Nombre de base de datos: underline
Clase de base de datos: Underline
Especifica el índice entero de un carácter a subrayar en el widget. Esta opción es utilizada por los enlaces predeterminados para

IMPLEMENTACIÓN_DE_TECLADO

traversal para botones de menú y entradas de menú. 0 corresponde al primer carácter del texto mostrado en el widget, 1 al siguiente carácter, y así sucesivamente.

Nombre de línea de comandos: -wraplength
Nombre de la base de datos: wrapLength
Clase de la base de datos: WrapLength
Para widgets que pueden realizar ajuste de línea de palabras, esta opción especifica la longitud máxima de línea. Las líneas que excedan esta longitud se ajustarán a la siguiente línea, de modo que ninguna línea sea más larga que la longitud especificada. El valor puede especificarse en cualquiera de las formas estándar para distancias de pantalla. Si este valor es menor o igual a 0, entonces no se realiza ningún ajuste: las líneas solo se dividirán en caracteres de nueva línea en el texto.
Nombre de línea de comandos: -xscrollcommand
Nombre de la base de datos: xScrollCommand
Clase de la base de datos: ScrollCommand
Especifica el prefijo de un comando utilizado para comunicarse con las barras de desplazamiento horizontales. Cuando la vista en la ventana del widget cambia (o siempre que ocurra algo más que pueda cambiar la visualización en una barra de desplazamiento, como un cambio en el tamaño total del contenido del widget), el widget generará un comando Tcl concatenando el comando de desplazamiento y dos números. Cada uno de los números es una fracción entre 0 y 1, que indica una posición en el documento. 0 indica el principio del documento, 1 indica el final, .333 indica una posición a un tercio del documento, y así sucesivamente. La primera fracción indica la primera información del documento que es visible en la ventana, y la segunda fracción indica la información justo después de la última porción que es visible. Luego, el comando se pasa al intérprete Tcl para su ejecución. Típicamente, la opción -xscrollcommand consiste en el nombre de ruta de un widget de barra de desplazamiento seguido de “set”, por ejemplo, “.x.scrollbar set”: esto hará que la barra de desplazamiento se actualice cada vez que cambie la vista en la ventana. Si no se especifica esta opción, no se ejecutará ningún comando.
Nombre de línea de comandos: -yscrollcommand
Nombre de la base de datos: yScrollCommand
Clase de la base de datos: ScrollCommand
Especifica el prefijo de un comando utilizado para comunicarse con las barras de desplazamiento verticales. Esta opción se trata de la misma manera que la opción -xscrollcommand, excepto que se utiliza para barras de desplazamiento verticales y es proporcionada por widgets que admiten desplazamiento vertical. Consulte la descripción de -xscrollcommand para obtener detalles sobre cómo se utiliza esta opción.
