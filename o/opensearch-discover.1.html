NOMBRE

opensearch-discover - Encuentra un enlace OpenSearch desde una URL dada.

SINOPSIS

opensearch-discover [-q] [-v] [-t TÍTULO] [-1|-a] [-h] [URL]

DESCRIPCIÓN

Carga la URL dada, la busca en busca de un enlace a una URL de descripción de OpenSearch e imprime esa URL.

OPCIONES

-q, --quiet
No mostrar nada en caso de errores. En este caso, consulte el código de salida para determinar los errores (consulte "DIAGNÓSTICOS").
-v, --verbose
Verboso: muestra títulos con enlaces. Combínelo con -a para ver todas las búsquedas disponibles.
-t TÍTULO, --title=TÍTULO
Solo muestra enlaces que coincidan con TÍTULO, una expresión regular de Perl insensible a mayúsculas y minúsculas. Por ejemplo, -t book coincidiría con Book Search, y -t b.*k coincidiría con Book Search o Baby Springbok.
-1, --first
Solo muestra el primer enlace (coincidente). Este es el valor predeterminado.
-a, --all
Muestra todos los enlaces (coincidentes).
-h, --help
Muestra un breve mensaje de ayuda.

DIAGNÓSTICOS

En caso de éxito, imprime la dirección del archivo de descripción de OpenSearch y devuelve 0.

Si no puede cargar la URL dada, devuelve 1.

Si la URL dada no contiene un enlace a un archivo de descripción de OpenSearch, devuelve 2.

Si faltan módulos Perl necesarios, devuelve 3.

DEPENDENCIAS

Requiere módulos de libwww-perl y HTML::Parser (paquete Debian libhtml-parser-perl).

ERRORES

Ninguno conocido. Por favor, informe de cualquier error encontrado a ianb@erislabs.net

VER TAMBIÉN
