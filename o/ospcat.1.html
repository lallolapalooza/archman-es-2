NOMBRE

ospcat - Imprimir catálogo SGML

SINOPSIS

ospcat [-b nombre] [--bctf=nombre] [-C] [--catalogs] [-c sysid] [--catalog=sysid] [-f] [--error-file=archivo] [-D directorio] [--directory=directorio] [-R] [--restricted] [-v] [-h] [--help] [-P literal] [--public-id=literal] [-S literal] [--system_id=literal] [-p nombre] [--parameter-entity=nombre] [-d nombre] [--doctype=nombre] [-l nombre] [--linktype=nombre] [-e nombre] [--entity=nombre] [-n nombre] [--notation=nombre] [-s nombre] [--declaration=nombre]

DESCRIPCIÓN

ospcat imprime los identificadores de sistema efectivos encontrados en los catálogos en la salida estándar. No comprueba que los identificadores de sistema correspondan a archivos reales. El valor de retorno es 0 si el último identificador de sistema se creó correctamente y 1 en caso contrario.

OPCIONES

Las siguientes opciones están disponibles:

-b nombre, --bctf=nombre

Usar bctf nombre para la salida.

-f archivo, --error-file=archivo

Añadir mensajes de error al archivo archivo.

-v, --version

Mostrar la versión del programa.

-h, --help

Mostrar este texto de ayuda.

-c sysid, --catalog=sysid

Usar catálogo sysid.

-C, --catalogs

Los argumentos son catálogos, usar la entrada DOCUMENT.

-D directorio, --directory=directorio

Buscar archivos en el directorio directorio.

-R, --restricted

Restringir la lectura de archivos (para uso en aplicaciones web).

-P literal, --public-id=literal

Imprimir el id de sistema efectivo para el id público literal.

-S literal, --system-id=literal

Imprimir el id de sistema efectivo para el id de sistema literal.

-p nombre, --parameter-entity=nombre

Imprimir el id de sistema efectivo para la entidad de parámetros nombre.

-d nombre, --doctype=nombre

Imprimir el id de sistema efectivo para el doctype nombre.

-l nombre, --linktype=nombre

Imprimir el id de sistema efectivo para el linktype nombre.

-e nombre, --entity=nombre

Imprimir el id de sistema efectivo para la entidad nombre.

-n nombre, --notation=nombre

Imprimir el id de sistema efectivo para la notación nombre.

-s nombre, --declaration=nombre

Imprimir el id de sistema efectivo para la declaración SGML para el doctype nombre.
