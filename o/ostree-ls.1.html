NOMBRE

ostree-ls - Listar rutas de archivos

SINOPSIS

ostree ls [OPCIONES...] {COMMIT} [RUTAS...]

DESCRIPCIÓN

Imprime una lista de rutas de archivos dentro del commit dado, y dentro de las rutas especificadas si se proporcionan. La primera letra de la salida de línea del archivo especifica el tipo: "-" para archivo regular, "d" para directorio, "l" para enlace simbólico. Ver la sección EJEMPLO para más detalles sobre la salida específica.

OPCIONES

--dironly,-d

No recursar en los argumentos de directorio.

--recursive,-R

Imprimir directorios recursivamente.

--checksum,-C

Imprimir checksum.

--xattrs,-X

Imprimir atributos extendidos.

--nul-filenames-only

Imprimir solo nombres de archivo, separados por NUL.

EJEMPLO

$ ostree ls mi-rama

        d00644 0 0    0 /
        -00644 0 0    2 /helloworld.txt
        d00755 0 0    0 /testdirectory

Aquí, la primera columna es el símbolo del tipo de archivo (como se explica en la sección DESCRIPCIÓN) seguido del tipo de archivo S_IFMT. Las siguientes dos columnas (aquí: 0 0) son respectivamente el ID de usuario y el ID de grupo para el archivo. Después de la separación, el siguiente número representa el tamaño estándar de ese archivo. La columna final es la ruta del archivo.
