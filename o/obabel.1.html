NOMBRE

obabel — un conversor de archivos de datos de química y modelado molecular

SINOPSIS

obabel [-H opciones-de-ayuda]

obabel [OPCIONES] [-i tipo-entrada | -: "cadena-SMILES"] archivo-entrada [-o tipo-salida] -O archivo-salida

DESCRIPCIÓN

obabel es un programa multiplataforma diseñado para interconvertir entre muchos formatos de archivo utilizados en modelado molecular y química computacional y áreas relacionadas.

Open Babel es también un kit de herramientas completo para programadores para desarrollar software de química. Para más información, vea las páginas web de Open Babel http://openbabel.org/.

OPCIONES

Si solo se dan los archivos de entrada y salida, Open Babel adivinará el tipo de archivo a partir de la extensión del nombre del archivo.

-: "cadena-SMILES"
Introduce una cadena SMILES y úsala en lugar de un archivo de entrada. La cadena SMILES debe estar entre comillas. Se pueden usar más de una, y se puede incluir un título de molécula si está entre comillas.
-a opciones
Opciones de entrada específicas del formato. Vea -H ID-formato para las opciones permitidas por un formato particular
--addtotitle
Añade texto al título de la molécula actual
--addformula
Añade la fórmula molecular después del título de la molécula actual
-b
Convierte enlaces dativos: por ejemplo, [N+]([O-])=O a N(=O)=O
-c
Centra las coordenadas atómicas en (0,0,0)
-C
Combina moléculas del primer archivo con otras del mismo nombre
-e
Continúa después de los errores
-d
Elimina hidrógenos
---errorlevel 2
Filtra el nivel de errores y advertencias mostradas:
1 = solo errores críticos
2 = incluye advertencias también (por defecto)
3 = incluye mensajes informativos también
4 = incluye mensajes de registro de auditoría de cambios en los datos
5 = incluye mensajes de depuración también
-f #
Para entradas de múltiples entradas, inicia la importación con la molécula # como la primera entrada
-F
Muestra los tipos de huella digital disponibles
-h
Añade hidrógenos
-H
Muestra información de uso
-H ID-formato
Muestra información de formato y opciones para el formato especificado
-Hall
Muestra información de formato y opciones para todos los formatos
-i<ID-formato>
Especifica el formato de entrada, vea abajo los formatos disponibles
-j
 
--join
Une todas las moléculas de entrada en una única entrada de molécula de salida
-k
Traduce palabras clave de modelado de química computacional (por ejemplo, GAMESS y Gaussian)
-m
Produce múltiples archivos de salida, para permitir:
  • Dividir un archivo de entrada: poner cada molécula en archivos de salida numerados consecutivamente
  • Conversión por lotes: convertir cada uno de múltiples archivos de entrada a un formato de salida especificado
-l #
Para entradas de múltiples entradas, detiene la importación con la molécula # como la última entrada
-o ID-formato
Especifica el formato de salida, vea abajo los formatos disponibles
-O archivo-salida
Especifica el archivo de salida. Esta opción se aplica solo a obabel.
-p
Añade hidrógenos apropiados para el pH (usa transformaciones en phmodel.txt)
--property
Añade o reemplaza una propiedad (por ejemplo, en un archivo MDL SD)
-s SMARTS
Convierte solo las moléculas que coinciden con el patrón SMARTS especificado
--separate
Separa fragmentos desconectados en registros moleculares individuales
-t
Todos los archivos de entrada describen una sola molécula
--title título
Añade o reemplaza el título molecular
-x opciones
Opciones de salida específicas del formato. Vea -H ID-formato para las opciones permitidas por un formato particular
-v SMARTS
Convierte solo las moléculas que **NO** coinciden con el patrón SMARTS especificado
-V
Muestra el número de versión y sale
-z
Comprime la salida con gzip

FORMAT OPTIONS

Individual file formats may have additional formatting options.

Input format options are preceded by 'a', e.g. -as

Output format options are preceded by 'x', e.g. -xn

For further specific information and options, use -H<format-type>
e.g., -Hcml

EXAMPLES

Standard conversion:

obabel ethanol.xyz -Oethanol.pdb
Conversion from a SMI file in STDIN to a Mol2 file written to STDOUT:
obabel -ismi -omol2
Split a multi-molecule file into new1.smi, new2.smi, etc.:
obabel infile.mol -Onew.smi -m
