orca(1) Manual de comandos generales orca(1)

NOMBRE

orca - un lector de pantalla programable

SINOPSIS

orca [opción...]

DESCRIPCIÓN

orca es un lector de pantalla para personas con deficiencias visuales, que proporciona acceso alternativo al escritorio mediante síntesis de voz y braille.

orca funciona con aplicaciones y toolkits que admiten la Interfaz de Proveedor de Servicios de Tecnología de Asistencia (AT-SPI), que es la infraestructura principal de tecnología de asistencia para Linux y Solaris. Las aplicaciones y toolkits que admiten AT-SPI incluyen el toolkit Gtk+ de GNOME, el toolkit Swing de la plataforma Java, LibreOffice, Gecko y WebKitGtk. Se está trabajando en el soporte de AT-SPI para el toolkit Qt de KDE.

OPCIONES

-s, --setup
Al iniciar orca, inicia la configuración basada en GUI.
-u, --user-prefs-dir=nombre_directorio
Al iniciar orca, utiliza nombre_directorio como un directorio alternativo para las preferencias del usuario.
-e, --enable=speech|braille|braille-monitor
Al iniciar orca, fuerza la habilitación de las opciones suministradas.
-d, --disable=speech|braille|braille-monitor
Al iniciar orca, fuerza la deshabilitación de las opciones suministradas.
-l, --list-apps
Imprime los nombres de todas las aplicaciones que se están ejecutando actualmente. Esto se utiliza principalmente para fines de depuración para ver si orca puede comunicarse con la infraestructura de accesibilidad. Tenga en cuenta que si orca ya se está ejecutando, esto no matará el otro proceso de orca. Simplemente listará las aplicaciones en ejecución y verá orca listado dos veces: una para el orca existente y otra para esta instancia.
--debug
Habilita la salida de depuración para orca y envía toda la salida de depuración a un archivo con un nombre del tipo 'debug-YYYY-MM-DD-HH:MM:SS.out' en el directorio actual. La parte YYYY-MM-DD-HH:MM:SS se reemplazará con la fecha y hora actuales.
--debug-file=nombre_archivo
Habilita la salida de depuración para orca y envía toda la salida de depuración al nombre de archivo dado.
-v, --version
Muestra el número de versión de orca y sale.
-h, --help
Muestra la ayuda de orca y sale.
--replace
Reemplaza un proceso orca en ejecución. Por defecto, si orca detecta un proceso orca existente para la misma sesión, no iniciará un nuevo proceso orca. Esta opción matará y limpiará cualquier proceso orca existente y luego iniciará un nuevo orca en su lugar.

CONFIGURACIÓN DEL TECLADO

Orca proporciona dos modos de teclado: diseño de teclado de escritorio y portátil. La tecla Orca_Modifier es Insertar en el diseño de teclado de escritorio y Bloq Mayús en el diseño de teclado portátil.

Orca utiliza los atajos de teclado predeterminados de GNOME para navegar por el escritorio e interactuar con diversas aplicaciones. Los comandos de revisión plana proporcionan un método alternativo de interacción en ciertas aplicaciones inaccesibles. No debe confundirse con la funcionalidad de revisión plana proporcionada por otros lectores de pantalla.

Modo Escritorio

Comandos de revisión plana

Numpad-7 mueve el cursor de revisión plana a la línea anterior y la lee.

Numpad-8 lee la línea actual.

Numpad-9 mueve el cursor de revisión plana a la línea siguiente y la lee.

Numpad-4 mueve el cursor de revisión plana a la palabra anterior y la lee.

Numpad-5 lee la palabra actual.

Numpad-6 mueve el cursor de revisión plana a la palabra siguiente y la lee.

Numpad-1 mueve el cursor de revisión plana al carácter anterior y lo lee.

Numpad-2 lee el carácter actual.

Numpad-3 mueve el cursor de revisión plana al carácter siguiente y lo lee.

Numpad-barra_diagonal realiza un clic izquierdo del ratón en la ubicación del cursor de revisión plana.

Numpad-asterisco realiza un clic derecho del ratón en la ubicación del cursor de revisión plana.

Comandos de marcador

Alt+Insertar+[1-6] asigna un marcador a una ranura numerada. Si ya existe un marcador en la ranura, se reemplazará por el nuevo.

Insertar+[1-6] va a la posición señalada por el marcador vinculado a esta ranura numerada.

Insertar+B y Insertar+Mayús+B se mueve entre los marcadores dados para la aplicación o página dada.

Alt+Insertar+B guarda los marcadores definidos para la aplicación o página actual.

Funciones misceláneas

Numpad+Signo_más
comando 'decir todo'; lee desde la posición actual del cursor hasta el final del documento.

Numpad+Intro
comando '¿Dónde estoy?'; lee información como el título de la ventana actual de la aplicación, así como el nombre del control que tiene el foco.

Insertar+H entra en el 'modo aprender' de orca; presione Escape para salir.

Insertar+Mayús+Retroceso_izquierdo activa o desactiva la supervisión de regiones activas.

Insertar+F lee la información de fuente y atributos para el carácter actual.

Insertar+Espacio Lanza el diálogo de Configuración de orca.

Insertar+Ctrl+Espacio recarga la configuración del usuario y reinicializa los servicios según sea necesario. También lanza el diálogo de Configuración de orca para la aplicación actual.

Insertar+S activa o desactiva la voz.

Insertar+F11 alterna la lectura de tablas, ya sea por celda individual o por fila completa.

Modo Portátil

Comandos de revisión plana

Bloq Mayús+U mueve el cursor de revisión plana a la línea anterior y la lee. Haga doble clic para mover la revisión plana a la parte superior de la ventana actual.

Bloq Mayús+I lee la línea actual. Haga doble clic para leer la línea actual junto con detalles de formato y capitalización.

Bloq Mayús+O mueve el cursor de revisión plana a la línea siguiente y la lee. Haga doble clic para mover la revisión plana a la parte inferior de la ventana actual.

Bloq Mayús+J mueve el cursor de revisión plana a la palabra anterior y la lee. Haga doble clic para mover la revisión plana a la palabra anterior a la actual.

Bloq Mayús+K lee la palabra actual. Haga doble clic para deletrear la palabra. Haga triple clic para escuchar la palabra deletreada fonéticamente.

Bloq Mayús+L mueve el cursor de revisión plana a la palabra siguiente y la lee. Haga doble clic para mover la revisión plana a la palabra inferior a la actual.

Bloq Mayús+M mueve el cursor de revisión plana al carácter anterior y lo lee. Haga doble clic para mover la revisión plana al final de la línea actual.

Bloq Mayús+Coma lee el carácter actual. Haga doble clic para pronunciar el carácter fonéticamente si es una letra.

Bloq Mayús+Punto mueve el cursor de revisión plana al siguiente carácter y lo lee.

Bloq Mayús+7 realiza un clic izquierdo del ratón en la ubicación del cursor de revisión plana.

Bloq Mayús+8 realiza un clic derecho del ratón en la ubicación del cursor de revisión plana.

Alt+Bloq Mayús+B guarda los marcadores definidos para la aplicación o página actual.

NAME

orca

screen reader for the GNOME desktop

SYNOPSIS

orca [-d|--debug] [-e|--enable-global-extras] [-f|--filter <filter>] [-r|--read-only] [-s|--script <script>] [--setup] [--version]

DESCRIPTION

Orca is a free, powerful, flexible, and extensible screen reader that provides auditory and braille feedback for universally accessible computing. Orca is part of the GNOME accessibility technologies.

Orca reads and extracts information from the GNOME accessibility framework. This allows it to provide information about the application window titles, menus, buttons, and other controls that are currently active.

Orca has two primary interaction modes: Desktop Mode and Laptop Mode. These modes provide different keyboard shortcuts for accessing Orca's features.

OPTIONS

-d, --debug
Enable debugging output.
-e, --enable-global-extras
Enable global extras (e.g. menu bar, tool bar, etc.).
-f, --filter <filter>
Load the specified filter.
-r, --read-only
Start Orca in read-only mode. This disables input and command keys.
-s, --script <script>
Load the specified script.
--setup
Launch the Orca setup wizard.
--version
Print version information and exit.

KEYBOARD SETTINGS

Orca can be configured to use either Desktop Mode or Laptop Mode keyboard shortcuts. These modes are selected in the Orca Preferences dialog.

Desktop Mode

Desktop Mode uses the Insert key as the Orca modifier key. When Orca is running, the Insert key is referred to as the Orca key.

Orca+I
Toggle Orca on and off.

Orca+Space
Press and hold the Orca key, press Spacebar, then release both. This will say the text under the mouse pointer.

Orca+UpArrow
Reads the line above the current cursor position.

Orca+DownArrow
Reads the line below the current cursor position.

Orca+LeftArrow
Reads the character to the left of the current cursor position.

Orca+RightArrow
Reads the character to the right of the current cursor position.

Orca+Home
Reads from the beginning of the current line.

Orca+End
Reads to the end of the current line.

Orca+PageUp
Reads the text above the current screen position.

Orca+PageDown
Reads the text below the current screen position.

Orca+Tab
Moves to the next focusable element.

Orca+Shift+Tab
Moves to the previous focusable element.

Orca+Delete
Reads the character under the mouse pointer.

Orca+Ctrl+Delete
Deletes the character under the mouse pointer.

Orca+Enter
'Where am I' command; speaks information such as the title of the current application window, as well as the name of the control that currently has focus.

Orca+H
Enter learn mode (press Escape to exit).

Orca+Shift+Backslash
Toggle live regions monitoring on and off.

Orca+F
Speak font and attribute information for the current character.

Orca+Space
Launch the Orca Configuration dialog.

Orca+Ctrl+Space
Reload user settings and reinitialize services as necessary; also launches the Orca Configuration dialog for the current application.

Orca+S
Toggle speech on and off.

Orca+F11
Toggle the reading of tables, either by single cell or whole row.
