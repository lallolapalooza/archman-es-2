OKULAR(1) Manual del usuario de Okular OKULAR(1)

NOMBRE

okular - un visor de documentos universal

SINOPSIS

okular [opciones_de_okular] [URL]

DESCRIPCIÓN

okular tiene como objetivo mostrar documentos en diferentes formatos.

OPCIONES DE OKULAR

-p, --page número

Abre una página con un número dado en el documento.

--presentation

Inicia el documento en modo presentación.

--print

Inicia con el diálogo de impresión.

--print-and-exit

Inicia con el diálogo de impresión y sale después de imprimir.

--unique

Control de instancia única.

--noraise

Permite evitar que la ventana de Okular se eleve después del inicio.

--find cadena

Intenta encontrar y resaltar una cadena dada en el documento. Solo funciona si solo se proporciona un documento como argumento del comando okular.

--editor-cmd cadena

Establece el comando del editor externo. No puedes establecer el comando del editor en una instancia de Okular ya en ejecución. Ten en cuenta que --unique no es compatible cuando se establece el comando del editor en la línea de comandos.

ARGUMENTOS

URL

Una dirección del documento a abrir. Para PDF, se puede dar como nombre_documento#destino_nombrado donde destino_nombrado es un destino nombrado particular incrustado en el documento.
