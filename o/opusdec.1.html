NOMBRE

opusdec - decodifica audio en formato Opus a Wave o PCM crudo

SINOPSIS

opusdec [ -hV ] [ --quiet ] [ --rate Hz ] [ --force-stereo ] [ --gain dB ] [ --no-dither ] [ --float ] [ --force-wav ] [ --packet-loss pct ] [ --save-range file ] input.opus [ output.wav ]

DESCRIPCIÓN

opusdec decodifica URLs o archivos Opus a Wave o PCM sin compresión.

En las URLs, se admiten los esquemas file, http y https, a menos que el soporte HTTP se haya deshabilitado en tiempo de compilación.

Si el archivo de entrada se especifica como -, entonces opusdec leerá desde stdin. De forma similar, un nombre de archivo de salida - causará que la salida sea a stdout.

Si no se especifica salida, opusdec intentará reproducir el audio en tiempo real si soporta la reproducción de audio en su sistema.

OPCIONES

-h, --help
Mostrar mensaje de ayuda
-V, --version
Mostrar información de la versión
--quiet
Suprime la salida del programa
--rate n

Forzar decodificación a una frecuencia de muestreo de n Hz
--force-stereo

Forzar decodificación a estéreo
--gain n

Ajustar el volumen de salida en n dB, los valores negativos hacen la señal más silenciosa
--no-dither
No aplicar dithering a la salida de 16 bits
--float
Generar muestras de punto flotante de 32 bits en lugar de muestras enteras de 16 bits
--force-wav
Forzar la inclusión de una cabecera Wave en la salida (por ejemplo, para extensiones no-wav y stdout)
--packet-loss n
Simular una pérdida de paquetes Opus aleatoria del n %
--save-range file
Guardar valores de verificación para cada fotograma en un archivo

EJEMPLOS

Decodificar un archivo input.opus a output.wav

opusdec input.opus output.wav

Reproducir un archivo input.opus

opusdec input.opus

Re-codificar un archivo Opus de alta tasa de bits a una tasa más baja

opusdec --force-wav input.opus - | opusenc --bitrate 64 - output.opus

Reproducir un stream http http://icecast.somwhere.org:8000/stream.opus en un sistema con pulseaudio
(presione ctrl-c para salir)

padsp opusdec http://icecast.somwhere.org:8000/stream.opus

ERRORES

Actualmente, Opusdec no rechaza todos los archivos inválidos que debería. Tampoco proporciona una salida muy útil para los archivos corruptos que sí rechaza. Utilice opusinfo(1) para obtener diagnósticos algo mejores.
