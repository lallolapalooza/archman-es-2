NOMBRE

ostree-fsck - Comprueba la consistencia del repositorio

SINOPSIS

ostree fsck [OPCIONES...]

DESCRIPCIÓN

Comprueba el repositorio para verificar la integridad del contenido de los objetos de commit. Busca objetos y metadatos faltantes y corruptos, y valida la estructura del directorio y los metadatos.

OPCIONES

--quiet,-q

Solo muestra mensajes de error.

--delete

Elimina objetos corruptos.

--add-tombstones

Agrega un commit fantasma para commits referenciados pero faltantes.

--verify-bindings

Verifica que los commits a los que apuntan cada ref tengan esa ref en el conjunto de enlaces. Normalmente deberías agregar esta opción; por defecto está desactivada por compatibilidad con versiones anteriores.

--verify-back-refs

Verifica que todas las refs listadas en los enlaces de refs de un commit apunten a ese commit. Esto no se puede usar en repositorios donde el objetivo de las refs cambia con el tiempo a medida que se agregan nuevos commits, pero se puede usar en repositorios que se regeneran desde cero para cada commit. Implica también --verify-bindings.

EJEMPLO

$ ostree fsck

        Enumerando objetos...
        Verificando la integridad del contenido de 2 objetos de commit
        0/2572 objetos
        2571/2572 objetos
