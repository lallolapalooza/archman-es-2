Métodos

void Registrar(string uuid, string puente)

Registra el servidor para el UUID proporcionado.

Cada nueva conexión a este servidor se añadirá a la interfaz de puente.

Valores posibles de uuid:

"panu", "00001115-0000-1000-8000-00805f9b34fb"
Rol de Usuario de Red Personal.
"nap", "00001116-0000-1000-8000-00805f9b34fb"
Rol de Punto de Acceso a Red.
"gn", "00001117-0000-1000-8000-00805f9b34fb"
Rol de Red de Grupo.

Inicialmente no se proporciona ningún SDP de servidor de red. Solo después de este método habrá un registro SDP disponible y el servidor BNEP estará listo para conexiones entrantes.

Errores posibles:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.YaExiste
org.bluez.Error.Fallo

void Anular_registro(string uuid)

Anula el registro del servidor para el UUID proporcionado que fue registrado previamente con el método Registrar().

Todos los servidores se anularán automáticamente cuando la aplicación que llama termine.

Errores posibles:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.Fallo
