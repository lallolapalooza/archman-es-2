OPENSC-EXPLORER(1) Herramientas OpenSC OPENSC-EXPLORER(1)

NOMBRE

opensc-explorer - utilidad interactiva genérica para acceder a funciones de tarjetas inteligentes y tokens de seguridad similares

SINOPSIS

opensc-explorer [OPCIONES] [SCRIPT]

DESCRIPCIÓN

La utilidad opensc-explorer se puede utilizar para realizar operaciones diversas, como explorar el contenido o enviar comandos APDU arbitrarios a una tarjeta inteligente o token de seguridad similar.

Si se proporciona un SCRIPT, opensc-explorer se ejecuta en modo no interactivo, leyendo los comandos de SCRIPT, un comando por línea. Si no se proporciona ningún script, opensc-explorer se ejecuta en modo interactivo, leyendo comandos de la entrada estándar.

OPCIONES

Las siguientes son las opciones de línea de comandos para opensc-explorer. Hay comandos interactivos adicionales disponibles una vez que se está ejecutando.

--card-driver driver, -c driver

Utiliza el controlador de tarjeta dado. El valor predeterminado es la detección automática del controlador de tarjeta correcto. El valor literal ? lista todos los controladores de tarjeta disponibles y termina opensc-explorer.

--mf ruta, -m ruta

Selecciona el archivo referenciado por la ruta dada al arrancar. El valor predeterminado es la ruta al archivo maestro estándar, 3F00. Si ruta está vacía (por ejemplo, opensc-explorer --mf ""), entonces no se selecciona ningún archivo explícitamente.

--reader arg, -r arg

Número del lector a utilizar. Por defecto, se utiliza el primer lector con una tarjeta presente. Si arg es un ATR, se elegirá el lector con una tarjeta coincidente.

--verbose, -v

Hace que opensc-explorer sea más verboso. Especifique este indicador varias veces para habilitar la salida de depuración en la biblioteca opensc.

--wait, -w

Espera a que se inserte una tarjeta.

COMANDOS

opensc-explorer admite comandos con argumentos en su indicador interactivo o en archivos de script pasados a través del parámetro de línea de comandos SCRIPT.

Similar a un shell de comandos como, por ejemplo, bash, cada línea de entrada se divide en palabras separadas por espacios en blanco. De estas palabras, la primera se utiliza como comando, mientras que las restantes se tratan como argumentos para ese comando.

Los siguientes comandos son compatibles:

# ...

Trata la línea como un comentario. Ignora todo hasta el final de la línea introducido por #.

apdu datos...

Envía un comando APDU personalizado a la tarjeta. datos es una serie de secuencias de valores hexadecimales y cadenas entre comillas dobles ("...").

asn1 id-archivo [num-reg] [despl]

Analiza e imprime el contenido codificado en ASN.1 del EF de trabajo especificado por id-archivo. Si se proporciona el parámetro opcional num-reg y el archivo es un EF orientado a registros, analiza e imprime solo el registro indicado por este parámetro. Si se proporciona el parámetro opcional despl, comienza a analizar e imprimir el archivo o registro en el desplazamiento indicado por el valor proporcionado. Si este parámetro no se proporciona, el desplazamiento predeterminado es 0.

cat [id-archivo | sfi:id-corto] [num-reg]

Imprime el contenido del EF de trabajo especificado por id-archivo o el ID de archivo corto id-corto. Si se proporciona el segundo parámetro opcional num-reg, solo imprime el registro indicado por este parámetro. Si no se proporciona ningún argumento, imprime el contenido del EF seleccionado actualmente.

cd {.. | id-archivo | aid:Nombre-DF}

Cambia a otro DF especificado por el argumento proporcionado. Si el argumento dado es .., entonces sube un nivel en la jerarquía del sistema de archivos. Si es un id-archivo, que debe ser un DF directamente debajo del DF actual, entonces cambia a ese DF. Si es un identificador de aplicación dado como aid:Nombre-DF, entonces salta al MF de la aplicación denotada por Nombre-DF.

change CHVref-pin [[pin-antiguo] pin-nuevo]

Cambia el PIN especificado por ref-pin del valor dado por pin-antiguo y cambia su valor a pin-nuevo.

pin-antiguo y pin-nuevo pueden ser secuencias de valores hexadecimales, cadenas entre comillas dobles ("..."), vacías (""), o ausentes. Si están ausentes, los valores se leen del pad de PIN del lector de tarjetas.

Ejemplos:

change CHV2 00:00:00:00:00:00 "clave123"

Cambia el PIN CHV2 al nuevo valor clave123, proporcionando el valor antiguo 00:00:00:00:00:00.

change CHV2 "clave123"

Establece el PIN CHV2 al nuevo valor clave123.

change CHV2

Cambia el PIN CHV2 usando el pad de PIN del lector de tarjetas.

create id-archivo tamaño

Crea un EF nuevo. id-archivo especifica el ID numérico y tamaño el tamaño del EF a crear.

debug [nivel]

Establece el nivel de depuración de OpenSC a nivel.

Si se omite nivel, muestra el nivel de depuración actual.

delete id-archivo

Elimina el EF o DF especificado por id-archivo.

do_get etiqueta-hex [salida]

Copia el contenido del objeto de datos (DO) de la tarjeta especificado por etiqueta-hex al archivo local del ordenador llamado salida.

Si salida no se proporciona, se mostrará el contenido de etiqueta-hex como un volcado hexadecimal.

do_put etiqueta-hex datos

Cambia el contenido del objeto de datos (DO) de la tarjeta especificado por etiqueta-hex a datos.

datos es una secuencia de valores hexadecimales o una cadena entre comillas dobles ("...").

echo cadena...

Imprime las cadenas proporcionadas.

erase

Borra la tarjeta, si la tarjeta lo soporta.

get id-archivo [salida]

Copia un EF a un archivo local. El archivo local se especifica por salida mientras que el archivo de la tarjeta se especifica por id-archivo.

Si se omite salida, el nombre del archivo de salida se derivará de la ruta completa de la tarjeta a id-archivo.

get_record id-archivo num-reg [salida]

Copia un registro de un EF orientado a registros a un archivo local. El archivo local se especifica por salida mientras que el archivo de la tarjeta y el registro se especifican por id-archivo y num-reg,

Si se omite salida, el nombre del archivo de salida se derivará de la ruta completa de la tarjeta a id-archivo y al num-reg.

help [patrón]

Muestra la lista de comandos disponibles, sus opciones y parámetros junto con un breve texto de ayuda. Si se proporciona patrón, los comandos que se muestran se limitan a los que coinciden con patrón.

info [id-archivo]

Muestra los atributos de un archivo especificado por id-archivo. Si no se proporciona id-archivo, se muestran los atributos del archivo actual.

ls [patrón...]

Lista archivos en el DF actual. Si no se proporciona ningún patrón, se listan todos los archivos. Si se proporcionan uno o más patrónes, solo se listan los archivos que coinciden con al menos un patrón.

find [id-inicio [id-fin]]

Encuentra todos los archivos en el DF actual. Los archivos se encuentran seleccionando todos los identificadores de archivo en el rango desde id-inicio hasta id-fin.

Si no se proporcionan, el valor predeterminado para id-inicio es 0000, mientras que el predeterminado para id-fin es FFFF.

find_tags [etiqueta-inicio [etiqueta-fin]]

Encuentra todas las etiquetas de objetos de datos en el contexto actual. Las etiquetas se encuentran utilizando GET DATA en el rango desde etiqueta-inicio hasta etiqueta-fin.

Si no se proporcionan, el valor predeterminado para etiqueta-inicio es 0000, mientras que el predeterminado para etiqueta-fin es FFFF.

mkdir id-archivo tamaño

Crea un DF. id-archivo especifica el ID numérico y tamaño el tamaño del DF a crear.

pin_info tipo-claveid-clave

opensc-explorer(1) — opensc

NAME

opensc-explorer — interactive smart card explorer

SYNOPSIS

opensc-explorer [-v] [-l] [-p pin] [-f file] [-i interface]

DESCRIPTION

The opensc-explorer is an interactive tool to explore the contents of a smart card. It allows the user to send APDU commands to the card and to inspect the card's response. The tool supports file system operations like changing directories, reading files, writing files, creating directories, deleting files and directories.

The tool also provides commands to manage PINs and keys on the card.

The commands are inspired by the OpenSC command-line tools.

OPTIONS

-v, --verbose
Print verbose output from the OpenSC library.

-l, --list-readers
List available smart card readers.

-p pin, --pin pin
Specify the default PIN to be used for card operations. If the card requires a PIN for an operation and this option is provided, the specified PIN will be used. Otherwise, the tool will prompt for the PIN.

-f file, --config-file file
Use the specified configuration file instead of the default one.

-i interface, --interface interface
Use the specified interface to communicate with the card. Possible values are: pcsc, csc, cmac, pkcs11.

COMMANDS

The following commands are available:

cd path

Change the current working directory on the card.

copy file-id input

Copy a local file specified by input to the card file specified by file-id.

create_bin file-id size

Create a binary file with the specified file-id and size.

create_chv file-id [chv_value]

Create a new CHV (Card Holder Verification) entry. If chv_value is given, it is used as the initial value. Otherwise, the value is prompted from the user.

create_df file-id parent-id

Create a new Data File (DF) with the specified file-id under the parent-id directory.

create_elem_file file-id parent-id size

Create an Elementary File (EF) with the specified file-id and size under the parent-id directory.

create_record_file file-id parent-id record-size max-records

Create a record file with the specified file-id and record parameters under the parent-id directory.

delete file-id

Delete the file or directory specified by file-id.

dump [file-id]

Dump the contents of the current directory or the specified file.

get_object object-id [output-file]

Retrieve an object from the card specified by object-id. If output-file is given, write the object to the host computer's file, otherwise display it as hex dump.

help

Display a list of available commands.

hex data

Display the given data as a hex dump.

load_auth key-type key-id key

Load an authentication key into the card.

load_key key-type key-id key

Load a cryptographic key into the card.

load_pin key-type key-id pin

Load a PIN into the card.

ls [path]

List the contents of the current directory or the specified path on the card.

mkdir file-id parent-id

Create a new directory with the specified file-id under the parent-id directory.

mv src-file-id dst-file-id

Move or rename a file or directory on the card.

pin_retry key-type key-id

Get the number of remaining PIN retries for the specified PIN.

put file-id input

Copy a local file to the card. The local file is specified by input while the card file is specified by file-id.

quit

Exit the program.

random count [output-file]

Generate count bytes of random data. If output-file is given, write the data to the host computer's file denoted by it, otherwise show the data as hex dump.

rm file-id

Remove the EF or DF specified by file-id.

unblock CHVpin-ref [puk [new-pin]]

Unblock the PIN denoted by pin-ref using the PUK puk, and potentially change its value to new-pin.

puk and new-pin can be sequences of hexadecimal values, strings enclosed in double quotes ("..."), empty (""), or absent. If absent, the values are read from the card reader's pin pad.

Examples:

unblock CHV2 00:00:00:00:00:00 "foobar"

Unblock PIN CHV2 using PUK 00:00:00:00:00:00 and set it to the new value foobar.

unblock CHV2 00:00:00:00:00:00 ""

Unblock PIN CHV2 using PUK 00:00:00:00:00:00 keeping the old value.

unblock CHV2 "" "foobar"

Set new value of PIN CHV2 to foobar.

unblock CHV2 00:00:00:00:00:00

Unblock PIN CHV2 using PUK 00:00:00:00:00:00. The new PIN value is prompted by pinpad.

unblock CHV2 ""

Set PIN CHV2. The new PIN value is prompted by pinpad.

unblock CHV2

Unblock PIN CHV2. The unblock code and new PIN value are prompted by pinpad.

update_binary file-id offs data

Binary update of the file specified by file-id with the literal data data starting from offset specified by offs.

data can be supplied as a sequence of hexadecimal values or as a string enclosed in double quotes ("...").

update_record file-id rec-nr rec-offs data

Update record specified by rec-nr of the file specified by file-id with the literal data data starting from offset specified by rec-offs.

data can be supplied as a sequence of hexadecimal values or as a string enclosed in double quotes ("...").

verify key-typekey-id [key]

Present a PIN or key to the card, where key-type can be one of CHV, KEY, AUT or PRO. key-id is a number representing the key or PIN reference. key is the key or PIN to be verified, formatted as a colon-separated sequence of hexadecimal values or a string enclosed in double quotes ("...").

If key is omitted, the exact action depends on the card reader's features: if the card readers supports PIN input via a pin pad, then the PIN will be verified using the card reader's pin pad. If the card reader does not support PIN input, then the PIN will be asked interactively.

Examples:

verify CHV2 31:32:33:34:00:00:00:00

Verify CHV2 using the hex value 31:32:33:34:00:00:00:00

verify CHV1 "secret"

Verify CHV1 using the string value secret.

verify KEY2

Verify KEY2, get the value from the card reader's pin pad.

sm {open | close}

Call the card's open or close Secure Messaging handler.
