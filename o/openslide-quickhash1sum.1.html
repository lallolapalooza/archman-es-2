OPENSLIDE-QUICKHASH1SUM(1) Comandos de usuario OPENSLIDE-QUICKHASH1SUM(1)

NOMBRE

openslide-quickhash1sum - Imprimir sumas de verificación quickhash-1 de OpenSlide

SINOPSIS

openslide-quickhash1sum [--ayuda] [--versión] diapositiva...

DESCRIPCIÓN

Imprime las sumas de verificación quickhash-1 de OpenSlide para uno o más archivos de diapositivas virtuales, en un formato similar a sha256sum(1).

quickhash-1 es un hash no criptográfico de 256 bits de un subconjunto de los datos de una diapositiva. Identifica de forma única una diapositiva virtual determinada, pero no se puede utilizar para detectar la corrupción o modificación del archivo de diapositiva.

OPCIONES

--ayuda
Mostrar resumen de uso.
--versión
Mostrar información de versión y derechos de autor.

ESTADO DE SALIDA

openslide-quickhash1sum devuelve 0 en caso de éxito, 1 si no se pudo calcular un quickhash-1, o 2 si los argumentos son inválidos.

NOTAS

openslide-quickhash1sum es un comando obsoleto y no se añadirán nuevas funcionalidades. Su reemplazo es el subcomando slide quickhash1 de slidetool(1).

ERRORES

quickhash-1 no está definido para todos los archivos de diapositivas compatibles con OpenSlide. Si una diapositiva no tiene un quickhash-1, se imprimirá "No hay quickhash-1 disponible".
