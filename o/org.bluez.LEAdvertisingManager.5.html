Nombre

org.bluez.LEAdvertisingManager - Documentación de la API LEAvertisingManager de BlueZ

Interfaz

El Gestor de Publicidad permite a las aplicaciones externas registrar Datos de Publicidad que deben transmitirse a los dispositivos. Los elementos de Datos de Publicidad deben seguir la API de Datos de Publicidad LE descrita anteriormente.

Servicio
org.bluez
Interfaz
org.bluez.LEAdvertisingManager1
Ruta de objeto
/org/bluez/{hci0,hci1,...}

Métodos

void RegistrarPublicidad(objeto publicidad, dict opciones)

Registra un objeto de publicidad para ser enviado a través del canal de publicidad LE.

El servicio debe implementar la interfaz org.bluez.LEAdvertisement(5).

Errores posibles:

org.bluez.Error.ArgumentosInvalidos
Indica que el objeto tiene propiedades inválidas o contradictorias.
org.bluez.Error.YaExiste
Indica que el objeto ya está registrado.
org.bluez.Error.LongitudInvalida
Indica que los datos proporcionados generan un paquete de datos demasiado largo.
org.bluez.Error.NoPermitido
Indica que se ha alcanzado el número máximo de instancias de publicidad.

void AnularRegistroPublicidad(objeto publicidad)

Anula el registro de una publicidad que se haya registrado previamente mediante RegistrarPublicidad().

El parámetro de ruta de objeto debe coincidir con el mismo valor que se utilizó al registrarse.

Errores posibles:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.NoExiste

Propiedades

byte InstanciasActivas [solo_lectura]

Número de instancias de publicidad activas.

byte InstanciasSoportadas [solo_lectura]

Número de instancias de publicidad disponibles.

array{string} InclusionesSoportadas [solo_lectura]

Lista de inclusiones del sistema soportadas.

Posibles valores:

"tx-power"
"appearance"
"local-name"
"rsi"

array{string} CanalesSecundariosSoportados [solo_lectura]

Lista de Canales Secundarios soportados. Los canales secundarios se pueden utilizar para anunciarse con la PHY correspondiente.

Posibles valores:

"1M"
"2M"
"Coded"

dict CapacidadesSoportadas [solo_lectura]

Enumera las capacidades del controlador relacionadas con la publicidad, útiles para el cliente.

Posibles valores:

byte LongitudMaxPub
Longitud máxima de los datos de publicidad
byte LongitudMaxRespuestaEscaneo
Longitud máxima de la respuesta de escaneo de publicidad
int16 PotenciaTxMin
Potencia Tx de publicidad mínima (dBm)
int16 PotenciaTxMax
Potencia Tx de publicidad máxima (dBm)

array{string} CaracteristicasSoportadas [solo_lectura,opcional]

Lista de características de plataforma soportadas. Si no hay características disponibles en la plataforma, la matriz de CaracterísticasSoportadas estará vacía.

Posibles valores:

"CanSetTxPower"
Indica si la plataforma puede especificar la potencia de transmisión en cada instancia de publicidad.
"HardwareOffload"
Indica si las publicidades múltiples se descargarán al controlador.
