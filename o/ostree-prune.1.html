NOMBRE

ostree-prune - Busca objetos inalcanzables

SINOPSIS

ostree prune [OPCIONES...]

DESCRIPCIÓN

Busca objetos inalcanzables en el repositorio actual. Si se encuentran objetos inalcanzables, el comando los elimina para liberar espacio. Si se invoca la opción --no-prune, el comando solo imprimirá los objetos inalcanzables y recomendará eliminarlos.

OPCIONES

--no-prune

Solo muestra los objetos inalcanzables; no los elimina.

--refs-only

Solo calcula la alcanzabilidad a través de referencias.

--delete-commit=COMMIT

Especifica un COMMIT para eliminar.

--keep-younger-than=FECHA

Todos los commits anteriores a FECHA serán eliminados. El formato de FECHA es el mismo que acepta la utilidad GNU date; para más información, consulta la información de date.

--depth=PROFUNDIDAD

Solo recorre PROFUNDIDAD (entero) de antecesores para cada commit (por defecto: -1=infinito).

--static-deltas-only=PROFUNDIDAD

Esta opción actualmente *solo* puede usarse en combinación con --delete-commit. Versiones anteriores de ostree aceptaban silenciosamente la opción sin eso y la ignoraban. Sin embargo, existen casos de uso deseados para eliminar solo deltas estáticos (mientras se retienen los commits), y es probable que en algún momento esta opción sea compatible con casos de uso fuera de solo --delete-commit.

--commit-only

Solo recorre y elimina objetos de commit. Esto deja objetos de metadatos y contenido huérfanos, que pueden limpiarse con otra invocación de prune. Es posible que desee usar esta opción para eliminar de forma efectiva múltiples commits y luego limpiar con un prune más costoso al final.

EJEMPLO

$ ostree prune

        Total objects: 25627
        No unreachable objects
