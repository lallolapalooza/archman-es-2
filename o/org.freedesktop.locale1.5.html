NOMBRE

org.freedesktop.locale1 - La interfaz D-Bus de systemd-localed

INTRODUCCIÓN

systemd-localed.service(8) es un servicio del sistema que puede ser utilizado para controlar la configuración regional y la disposición del teclado del sistema desde programas de usuario. Esta página describe la interfaz D-Bus.

LA API DE D-BUS

El servicio expone las siguientes interfaces en el bus:

nodo /org/freedesktop/locale1 {
  interfaz org.freedesktop.locale1 {
    métodos:
      SetLocale(in  as locale,
                in  b interactive);
      SetVConsoleKeyboard(in  s keymap,
                          in  s keymap_toggle,
                          in  b convert,
                          in  b interactive);
      SetX11Keyboard(in  s layout,
                     in  s model,
                     in  s variant,
                     in  s options,
                     in  b convert,
                     in  b interactive);
    propiedades:
      readonly as Locale = ['...', ...];
      readonly s X11Layout = '...';
      readonly s X11Model = '...';
      readonly s X11Variant = '...';
      readonly s X11Options = '...';
      readonly s VConsoleKeymap = '...';
      readonly s VConsoleKeymapToggle = '...';
  };
  interfaz org.freedesktop.DBus.Peer { ... };
  interfaz org.freedesktop.DBus.Introspectable { ... };
  interfaz org.freedesktop.DBus.Properties { ... };
};

Métodos

Si establece una nueva configuración regional del sistema, se descartarán todas las configuraciones regionales antiguas del sistema y los nuevos ajustes se guardarán en el disco. La configuración regional también se pasará al gestor del sistema y los demonios iniciados posteriormente heredarán la nueva configuración regional del sistema. Tenga en cuenta que los demonios que ya se estén ejecutando no se enterarán del nuevo valor.

El método SetVConsoleKeyboard() puede ser utilizado para establecer el mapeo de teclas para la consola virtual. De manera similar, SetX11Keyboard() puede ser utilizado para establecer el mapeo de teclas por defecto de cualquier servidor X11.

Tenga en cuenta que SetVConsoleKeyboard() aplica instantáneamente el nuevo mapeo de teclas a la consola, mientras que SetX11Keyboard() simplemente establece un valor por defecto que puede ser utilizado por sesiones posteriores.

El argumento booleano convert puede establecerse para convertir opcionalmente la configuración del teclado de la consola a mapeos de teclado X11 y viceversa. Si es verdadero y se utiliza SetVConsoleKeyboard(), se establece la configuración de teclado X11 más cercana para la configuración de consola elegida. Si es verdadero y se utiliza SetX11Keyboard(), se establece la configuración de teclado de consola más cercana para la configuración X11 elegida. Por lo tanto, generalmente es suficiente llamar solo a una de las dos funciones.

Para interfaces gráficas de usuario que necesiten establecer el mapeo del teclado del sistema, simplemente invoque SetX11Keyboard(), establezca convert=true e ignore SetVConsoleKeyboard().

Use la cadena vacía para los parámetros del mapa de teclas que desee no establecer.

Los parámetros booleanos interactive pueden usarse para controlar si polkit[1] preguntará interactivamente al usuario por las credenciales de autenticación si son requeridas.

Señales

Cada vez que el daemon cambie la configuración regional o el mapa de teclas del sistema, se enviarán señales PropertyChanged a los clientes que se hayan suscrito.

Propiedades

La configuración regional del sistema se muestra en la propiedad Locale. Es una matriz que contiene cadenas similares a asignaciones de variables de entorno. Las siguientes cadenas son conocidas: LANG=, LC_CTYPE=, LC_NUMERIC=, LC_TIME=, LC_COLLATE=, LC_MONETARY=, LC_MESSAGES=, LC_PAPER=, LC_NAME=, LC_ADDRESS=, LC_TELEPHONE=, LC_MEASUREMENT=, LC_IDENTIFICATION=.

Las propiedades X11Layout, X11Model, X11Variant y X11Options muestran los valores configurables con SetX11Keyboard() descritos anteriormente (o SetVConsoleKeyboard() con convert=true). Las propiedades VConsoleKeymap y VConsoleKeymapToggle muestran los valores configurables con SetVConsoleKeyboard() (o SetX11Keyboard() con convert=true).

Seguridad

Cambiar la configuración regional o el mapa de teclas del sistema usando esta interfaz se autentica a través de polkit. La acción polkit para SetLocale() es org.freedesktop.locale1.set-locale. La acción polkit para SetX11Keyboard() y SetVConsoleKeyboard() es org.freedesktop.locale1.set-keyboard.

EJEMPLOS

Ejemplo 1. Introspeccionar org.freedesktop.locale1 en el bus

$ gdbus introspect --system \
  --dest org.freedesktop.locale1 \
  --object-path /org/freedesktop/locale1
