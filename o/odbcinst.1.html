NOMBRE

odbcinst - Utilidad de unixODBC para gestionar archivos de configuración

SINOPSIS

odbcinst ACCIÓN OBJETO OPCIONES

DESCRIPCIÓN

odbcinst es una utilidad de línea de comandos que permite a los usuarios que desarrollan scripts de instalación o paquetes para controladores ODBC crear o eliminar fácilmente entradas en odbc.ini y odbcinst.ini.

La utilidad forma parte del componente odbcinst de unixODBC y complementa la biblioteca compartida del mismo nombre (libodbcinst).

OPCIONES

ACCIONES

-i
Instalar un nuevo OBJETO (añadiendo una sección a un archivo de configuración).
-u
Desinstalar un OBJETO existente (eliminando una sección de un archivo de configuración).
-q
Consultar archivos de configuración ODBC e imprimir las opciones disponibles para el OBJETO especificado.
-j
Imprimir la configuración actual de unixODBC, incluyendo las rutas a los archivos de configuración.
-c
Llamar a SQLCreateDataSource.
-m
Llamar a SQLManageDataSources.
--version
Mostrar la versión del programa.

OBJETOS

-d
La ACCIÓN especificada afecta a un controlador (y por lo tanto al archivo de configuración odbcinst.ini).
-s
La ACCIÓN especificada afecta a una fuente de datos (y por lo tanto al archivo de configuración odbc.ini del usuario o del sistema).

OPCIONES

-f ARCHIVO
ARCHIVO es una plantilla que describe la configuración del OBJETO instalado (solo válido con la ACCIÓN -i).
-r
Actuar de la misma manera que con la OPCIÓN -f, pero tomar la entrada estándar como archivo de plantilla.
-n NOMBRE
Especifica el NOMBRE del OBJETO.
-v
Desactivar todos los mensajes de información, advertencia y error.
-l
La fuente de datos especificada es a nivel de sistema. Esta opción solo es válida cuando se usa con el OBJETO -s.
-h
La fuente de datos especificada es específica del usuario. Esta opción solo es válida cuando se usa con el OBJETO -s.

VALORES DE RETORNO

odbcinst devuelve cero en caso de éxito y un valor distinto de cero en caso de fallo.

ARCHIVOS

/etc/odbcinst.ini

Archivo de configuración que contiene todas las definiciones de controladores de base de datos. Ver odbcinst.ini(5) para más información.

/etc/odbc.ini

Archivo de configuración que contiene definiciones de nombres de origen de datos (DSN) a nivel de sistema. Ver odbc.ini(5) para más información.

$HOME/.odbc.ini

Archivo de configuración que contiene definiciones de nombres de origen de datos (DSN) específicos del usuario. Ver odbc.ini(5) para más información.

VER TAMBIÉN

odbcinst.ini(5), odbc.ini(5)
