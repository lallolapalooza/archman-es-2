OPENSC-TOOL(1) Herramientas OpenSC OPENSC-TOOL(1)

NOMBRE

opensc-tool - utilidad genérica para tarjetas inteligentes

SINOPSIS

opensc-tool [OPCIONES]

DESCRIPCIÓN

La utilidad opensc-tool se puede usar desde la línea de comandos para realizar operaciones misceláneas con tarjetas inteligentes, como obtener la ATR de la tarjeta o enviar comandos APDU arbitrarios a una tarjeta.

OPCIONES

--version

Imprime la versión de lanzamiento del paquete OpenSC.

--atr, -a

Imprime la Respuesta a Reset (ATR) de la tarjeta. La salida está en formato de bytes hexadecimales.

--card-driver driver, -c driver

Usa el controlador de tarjeta dado. El valor predeterminado es la auto-detección del controlador de tarjeta correcto. El valor literal ? lista todos los controladores de tarjeta disponibles.

--list-algorithms,

Lista los algoritmos compatibles con la tarjeta.

--info, -i

Imprime información sobre OpenSC, como la versión y los componentes habilitados.

--list-drivers, -D

Lista todos los controladores de tarjeta instalados.

--list-files, -f

Lista recursivamente todos los archivos almacenados en la tarjeta.

--list-readers, -l

Lista todos los lectores configurados.

--name, -n

Imprime el nombre de la tarjeta insertada (controlador).

--get-conf-entry conf, -G conf

Obtiene la clave de configuración, formato: sección:nombre:clave

--set-conf-entry conf, -S conf

Establece la clave de configuración, formato: sección:nombre:clave:valor

--reader arg, -r arg

Número del lector a usar. Por defecto, se usa el primer lector con una tarjeta presente. Si arg es una ATR, se elegirá el lector con una tarjeta coincidente.

--reset [type],

Reinicia la tarjeta en el lector. El tipo de reinicio predeterminado es frío, pero también es posible un reinicio en caliente.

--send-apdu apdu, -s apdu

Envía un APDU arbitrario a la tarjeta en el formato AA:BB:CC:DD:EE:FF.... Usa esta opción varias veces para enviar más de un APDU.

Los controladores de tarjeta integrados pueden enviar APDUs adicionales para detección e inicialización. Para evitar este comportamiento, puedes especificar adicionalmente --card-driver default.

--serial

Imprime el número de serie de la tarjeta (normalmente el ICCSN). La salida está en formato de bytes hexadecimales.

--verbose, -v

Hace que opensc-tool sea más detallado. Especifica esta bandera varias veces para habilitar la salida de depuración en la biblioteca opensc.

--wait, -w

Espera a que se inserte una tarjeta.
