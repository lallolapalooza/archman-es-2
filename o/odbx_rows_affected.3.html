NOMBRE

odbx_rows_affected - Devuelve el número de registros modificados

SINOPSIS

#include <opendbx/api.h>


uint64_t odbx_rows_affected
(odbx_result_t* result);

DESCRIPCIÓN

Devuelve el número de filas que han sido modificadas por la sentencia actual cuyo conjunto de resultados fue obtenido por odbx_result(). Las filas afectadas solo se devuelven para sentencias DELETE, INSERT o UPDATE y su número concreto depende de la implementación de la base de datos. En lugar de devolver el número de filas que coinciden con la cláusula WHERE, MySQL, por ejemplo, solo cuenta las filas cuyos valores realmente han cambiado.

El parámetro result requerido por esta función debe ser un conjunto de resultados válido devuelto por odbx_result() y no debe haber sido alimentado a odbx_result_finish() previamente.

VALOR DE RETORNO

odbx_rows_affected() devuelve el número de filas modificadas en caso de éxito y cero si el servidor de base de datos no alteró ninguna fila. Puede devolverse un valor de cero si la sentencia no coincide con ninguna fila. Algunos servidores de bases de datos como MySQL pueden devolver un número menor de lo esperado porque no modifican registros cuyos valores no cambiarían.

ERRORES

Esta función también devolverá cero si el parámetro result es inválido.

VER TAMBIÉN

odbx_result(), odbx_result_finish()
