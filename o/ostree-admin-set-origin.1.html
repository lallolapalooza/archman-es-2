NOMBRE

ostree-admin-set-origin - Cambiar el "origen" (ubicación para actualizaciones)

SINOPSIS

ostree admin set-origin {NOMBRE_REMOTO} {URL} [RAMA]

DESCRIPCIÓN

Añade un nuevo remoto llamado NOMBRE_REMOTO (si no existe ya). Luego cambia el archivo de origen para el despliegue actual. Esta es la referencia que será "rastreada" y actualizada con ostree admin upgrade.

OPCIONES

--set=CLAVE=VALOR

Establece una opción para el remoto.

--index=ÍNDICE

Cambia el origen del despliegue numerado ÍNDICE (empezando desde 0).

EJEMPLO

$ ostree admin set-origin exampleos http://os.example.com/repo exampleos/10.0/main/router
