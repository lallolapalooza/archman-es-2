NOMBRE

osinfo-db-export - Exportar a un archivo de base de datos de osinfo

SINOPSIS

osinfo-db-export [OPCIONES...] [ARCHIVO-DE-ARCHIVO]

DESCRIPCIÓN

La herramienta osinfo-db-export creará un archivo de archivo de base de datos de osinfo que contiene el contenido de una de las ubicaciones estándar de la base de datos local:

sistema
Esta es la ubicación principal de la base de datos del sistema, destinada al uso por parte de los distribuidores de sistemas operativos que distribuyen archivos de base de datos en el formato de paquete nativo.
local
Esta es la ubicación secundaria de la base de datos del sistema, destinada al uso por parte de los administradores del sistema que desean proporcionar una base de datos actualizada para todos los usuarios.
usuario
Esta es la ubicación de la base de datos privada del usuario, destinada al uso por parte de usuarios locales no privilegiados que desean proporcionar a las aplicaciones que utilizan una base de datos actualizada.

Si se ejecuta por una cuenta privilegiada (es decir, root), la ubicación de la base de datos local se usará por defecto, de lo contrario, se usará la ubicación usuario.

Si no se proporciona ninguna ruta ARCHIVO-DE-ARCHIVO, se utilizará un nombre de archivo generado automáticamente con el formato osinfo-db-$VERSIÓN.tar.xz.

OPCIONES

--user
Anular el comportamiento por defecto para forzar el archivado de archivos desde la ubicación de la base de datos del usuario.
--local
Anular el comportamiento por defecto para forzar el archivado de archivos desde la ubicación de la base de datos local.
--system
Anular el comportamiento por defecto para forzar el archivado de archivos desde la ubicación de la base de datos del sistema.
--dir=RUTA
Anular el comportamiento por defecto para forzar el archivado de archivos desde el directorio personalizado RUTA.
--root=RUTA
Prefijar la ubicación de la base de datos con el directorio raíz dado por "RUTA". Esto es útil cuando se desean archivar archivos que se encuentran en un entorno chroot o equivalente.
--version=VERSIÓN
Establecer la cadena de versión para los archivos en el archivo a VERSIÓN. Si este argumento no se proporciona, la versión se establecerá a la fecha actual en el formato YYYYMMDD.
--license=LICENCIA-ARCHIVO
Añadir "ARCHIVO-DE-LICENCIA" al archivo generado como una entrada llamada "LICENCIA".
-v, --verbose
Mostrar información detallada del progreso al archivar archivos

ESTADO DE SALIDA

El estado de salida será 0 si todos los archivos se empaquetaron correctamente, o 1 si al menos un archivo no pudo ser empaquetado en el archivo.
