ocrfeeder(1) Manual de comandos generales ocrfeeder(1)

NOMBRE

ocrfeeder - sistema de análisis de diseño de documentos y reconocimiento óptico de caracteres.

SINOPSIS

ocrfeeder [OPCIONES]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando ocrfeeder.

OCRFeeder A partir de las imágenes, delineará automáticamente su contenido, distinguirá entre gráficos y texto y realizará OCR sobre estos últimos. Genera múltiples formatos, siendo su formato principal ODT.

OPCIONES

Información general del programa

--version
Mostrar el número de versión del programa y salir
-h, --help
Mostrar mensaje de ayuda y salir

Otras opciones

-i IMAGEN1 [IMAGEN2 ...], --images=IMAGEN1 [IMAGEN2 ...]
Añadir las imágenes especificadas a OCRFeeder después de abrirlo
-d DIRECTORIO, --dir=DIRECTORIO
Añadir todas las imágenes del directorio especificado a OCRFeeder después de abrirlo

ARCHIVOS

~/.config/ocrfeeder/preferences.xml
Archivo de configuración de OCRFeeder

CARPETAS

~/.config/ocrfeeder/engines/
Carpeta para guardar los archivos de configuración de los motores

VER TAMBIÉN

ocrfeeder-cli(1)
