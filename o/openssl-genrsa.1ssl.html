NOMBRE

openssl-genrsa - generar una clave privada RSA

SINOPSIS

openssl genrsa [-help] [-out nombre_archivo] [-passout arg] [-aes128] [-aes192] [-aes256] [-aria128] [-aria192] [-aria256] [-camellia128] [-camellia192] [-camellia256] [-des] [-des3] [-idea] [-F4] [-f4] [-3] [-primes num] [-verbose] [-quiet] [-traditional] [-rand archivos] [-writerand archivo] [-engine id] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq] [num_bits]

DESCRIPCIÓN

Este comando genera una clave privada RSA.

OPCIONES

-help
Muestra un mensaje de uso.
-out nombre_archivo
Exporta la clave al archivo especificado. Si no se proporciona este argumento, se utiliza la salida estándar.
-passout arg
Origen de la contraseña del archivo de salida. Para más información sobre el formato, consulta openssl-passphrase-options(1).
-aes128, -aes192, -aes256, -aria128, -aria192, -aria256, -camellia128, -camellia192, -camellia256, -des, -des3, -idea
Estas opciones cifran la clave privada con el cifrado especificado antes de exportarla. Si no se especifica ninguna de estas opciones, no se utiliza cifrado. Si se utiliza cifrado, se solicitará una contraseña si no se proporciona a través del argumento -passout.
-F4, -f4, -3
El exponente público a utilizar, ya sea 65537 o 3. El valor predeterminado es 65537. La opción -3 ha sido obsoleta.
-primes num
Especifica el número de primos a utilizar al generar la clave RSA. El parámetro num debe ser un entero positivo mayor que 1 y menor que 16. Si num es mayor que 2, la clave generada se denomina clave RSA 'multiprime', definida en RFC 8017.
-verbose
Muestra detalles adicionales sobre las operaciones que se están realizando.
-quiet
Muestra menos detalles sobre las operaciones que se están realizando, lo que puede ser útil durante scripts por lotes y canalizaciones.
-traditional
Escribe la clave utilizando el formato tradicional PKCS#1 en lugar del formato PKCS#8.
-rand archivos, -writerand archivo
Consulta "Opciones de Estado Aleatorio" en openssl(1) para obtener detalles.
-engine id
Consulta "Opciones de Motor" en openssl(1). Esta opción está obsoleta.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Consulta "Opciones de Proveedor" en openssl(1), provider(7) y property(7).
num_bits
El tamaño de la clave privada a generar en bits. Esta debe ser la última opción especificada. El valor predeterminado es 2048 y los valores menores de 512 no están permitidos.

NOTAS

La generación de claves privadas RSA implica esencialmente la generación de dos o más números primos. Al generar una clave privada, se mostrarán varios símbolos para indicar el progreso de la generación. Un . representa cada número que ha pasado una prueba de tamiz inicial, + significa que un número ha pasado una ronda del test de primalidad de Miller-Rabin, * significa que el primo actual inicia un progreso de regeneración debido a algunas pruebas fallidas. Una nueva línea significa que el número ha pasado todas las pruebas de primalidad (el número real depende del tamaño de la clave).

Dado que la generación de claves es un proceso aleatorio, el tiempo necesario para generar una clave puede variar. Pero, en general, más primos reducen el tiempo de generación de una clave.
