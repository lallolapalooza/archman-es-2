ONEFETCH(1) Comandos de usuario ONEFETCH(1)

NOMBRE

onefetch - Herramienta de información de Git en línea de comandos

SINOPSIS

onefetch [OPCIONES] [ENTRADA]

DESCRIPCIÓN

Herramienta de información de Git en línea de comandos

Argumentos:

[ENTRADA]
Ejecutar como si onefetch se hubiera iniciado en <entrada> en lugar del directorio de trabajo actual

OPCIONES

-h, --help

Imprimir ayuda (ver un resumen con '-h')

-V, --version

Imprimir versión

INFORMACIÓN:

-d, --disabled-fields <CAMPO>...

Permite deshabilitar CAMPO(s) para que no aparezcan en la salida

--no-title

Oculta el título

--number-of-authors <NUM>

Número máximo de autores a mostrar
[por defecto: 3]

--number-of-languages <NUM>

Número máximo de lenguajes a mostrar
[por defecto: 6]

--number-of-file-churns <NUM>

Número máximo de cambios de archivo a mostrar
[por defecto: 3]

--churn-pool-size <NUM>

Número mínimo de commits de HEAD utilizados para calcular el resumen de cambios
Por defecto, el valor real no es determinista debido a la computación basada en el tiempo y se mostrará bajo el título de información "Churn (NUM)"

-e, --exclude <EXCLUIR>...

Ignorar todos los archivos y directorios que coincidan con EXCLUIR

--no-bots[=<REGEX>]

Excluir commits [bot]. Usa <REGEX> para anular el patrón predeterminado

--no-merges

Ignora los commits de fusión

-E, --email

Mostrar la dirección de correo electrónico de cada autor

--http-url

Mostrar la URL del repositorio como HTTP

--hide-token

Ocultar el token en la URL del repositorio

--include-hidden

Contar archivos y directorios ocultos

-T, --type <TIPO>...

Filtra la salida por tipo de lenguaje
[por defecto: programación marcado] [valores posibles: programación, marcado, prosa, datos]

FORMATO TEXTO:

-t, --text-colors <X>...

Cambia los colores del texto (X X X...)
Va en orden de título, ~, subrayado, subtítulo, dos puntos e información
Por ejemplo:
'--text-colors 9 10 11 12 13 14'

-z, --iso-time

Utiliza marcas de tiempo con formato ISO 8601

--number-separator <SEPARADOR>

Qué SEPARADOR de miles usar
[por defecto: simple] [valores posibles: simple, coma, espacio, guion bajo]

--no-bold

Desactiva el formato en negrita

ASCII:

--ascii-input <CADENA>

Toma una CADENA no vacía como entrada para reemplazar el logo ASCII
Es posible pasar una CADENA generada mediante sustitución de comandos
Por ejemplo:
'--ascii-input "$(fortune | cowsay -W 25)"'

-c, --ascii-colors <X>...

Colores (X X X...) para imprimir el arte ASCII

-a, --ascii-language <IDIOMA>

Qué arte ASCII del IDIOMA imprimir

--true-color <CUÁNDO>

Especifica cuándo usar color real
Si se establece en automático: el color real se habilitará si es compatible con la terminal
[por defecto: automático] [valores posibles: automático, nunca, siempre]

IMAGEN:

-i, --image <IMAGEN>

Ruta al archivo IMAGEN

--image-protocol <PROTOCOLO>

Qué PROTOCOLO de imagen usar
[valores posibles: kitty, sixel, iterm]

--color-resolution <VALOR>

VALOR de resolución de color a usar con el backend SIXEL
[por defecto: 16] [valores posibles: 16, 32, 64, 128, 256]

VISUALES:

--no-color-palette

Oculta la paleta de colores

--no-art

Oculta el arte ASCII o la imagen si se proporciona

--nerd-fonts

Usa iconos de Nerd Font
Reemplaza los chips de lenguaje con iconos de Nerd Font

DESARROLLADOR:

-o, --output <FORMATO>

Expulsa Onefetch en un formato específico
[valores posibles: json, yaml]

--generate <SHELL>

Si se proporciona, expulsa el archivo de completado para la SHELL dada
[valores posibles: bash, elvish, fish, powershell, zsh]

OTRO:

-l, --languages

Imprime los lenguajes soportados

-p, --package-managers

Imprime los gestores de paquetes soportados
