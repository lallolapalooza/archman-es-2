NOMBRE

oct-pin - Gestión de PIN (cambiar PINs, restablecer PINs bloqueados)

SINOPSIS

oct pin <-c|--card> [-h|--help] <subcomandos>

DESCRIPCIÓN

Gestión de PIN (cambiar PINs, restablecer PINs bloqueados)

Las tarjetas OpenPGP utilizan PINs (contraseñas numéricas) para verificar que un usuario tiene permiso para realizar una operación. Hay dos PINs para la operación normal, PIN de Usuario y PIN de Administrador, y un Código de Restablecimiento opcional.

El PIN de Usuario es necesario para utilizar operaciones criptográficas en una tarjeta (como descifrar o firmar). El PIN de Administrador se necesita para configurar una tarjeta (por ejemplo, para importar una clave OpenPGP a la tarjeta) o para desbloquear el PIN de Usuario. El Código de Restablecimiento solo permite desbloquear el PIN de Usuario. Esto es útil si el usuario no tiene acceso al PIN de Administrador.

Por defecto, en tarjetas no configuradas (o restablecidas de fábrica), el PIN de Usuario suele ser 123456, y el PIN de Administrador es 12345678.

OPCIONES

-c, --card=identificador de tarjeta
Identificador de la tarjeta a utilizar
-h, --help
Imprimir ayuda (ver un resumen con '-h')
