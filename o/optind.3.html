NOMBRE

getopt, getopt_long, getopt_long_only, optarg, optind, opterr, optopt - Analizar opciones de línea de comandos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int getopt(int argc, char *argv[],
           const char *optstring);
extern char *optarg;
extern int optind, opterr, optopt;
#include <getopt.h>
int getopt_long(int argc, char *argv[],
           const char *optstring,
           const struct option *longopts, int *longindex);
int getopt_long_only(int argc, char *argv[],
           const char *optstring,
           const struct option *longopts, int *longindex);

DESCRIPCION

La función getopt() analiza los argumentos de la línea de comandos. Sus argumentos argc y argv son el recuento de argumentos y la matriz tal como se pasan a la función main() en la invocación del programa. Un elemento de argv que comienza con '-' (y no es exactamente "-" o "--") es un elemento de opción. Los caracteres de este elemento (aparte del '-' inicial) son caracteres de opción. Si se llama a getopt() repetidamente, devuelve sucesivamente cada uno de los caracteres de opción de cada uno de los elementos de opción.

La variable optind es el índice del siguiente elemento a procesar en argv. El sistema inicializa este valor a 1. La llamada puede restablecerlo a 1 para reiniciar el escaneo del mismo argv, o al escanear un nuevo vector de argumentos.

Si getopt() encuentra otro carácter de opción, devuelve ese carácter, actualizando la variable externa optind y una variable estática nextchar para que la siguiente llamada a getopt() pueda reanudar el escaneo con el siguiente carácter de opción o el elemento argv.

Si no quedan más caracteres de opción, getopt() devuelve -1. Entonces optind es el índice en argv del primer elemento argv que no es una opción.

optstring es una cadena que contiene los caracteres de opción legítimos. Un carácter de opción legítimo es cualquier carácter visible de un byte de ascii(7) (para el cual isgraph(3) devolvería distinto de cero) que no sea '-', ':' o ';'. Si dicho carácter va seguido de dos puntos, la opción requiere un argumento, por lo que getopt() coloca un puntero al texto siguiente en el mismo elemento argv, o el texto del siguiente elemento argv, en optarg. Dos puntos significan que una opción toma un argumento opcional; si hay texto en el elemento argv actual (es decir, en la misma palabra que el nombre de la opción, por ejemplo, "-oarg"), entonces se devuelve en optarg, de lo contrario optarg se establece en cero. Esta es una extensión de GNU. Si optstring contiene W seguido de un punto y coma, entonces -W foo se trata como la opción larga --foo. (La opción -W está reservada por POSIX.2 para extensiones de implementación.) Este comportamiento es una extensión de GNU, no disponible con bibliotecas anteriores a glibc 2.

Por defecto, getopt() permuta el contenido de argv mientras escanea, de modo que eventualmente todos los no-argumentos queden al final. También se implementan otros dos modos de escaneo. Si el primer carácter de optstring es '+' o la variable de entorno POSIXLY_CORRECT está establecida, entonces el procesamiento de opciones se detiene tan pronto como se encuentra un argumento no-opción. Si '+' no es el primer carácter de optstring, se trata como una opción normal. Si se requiere el comportamiento de POSIXLY_CORRECT en este caso, optstring contendrá dos símbolos '+'. Si el primer carácter de optstring es '-', entonces cada elemento argv no-opción se maneja como si fuera el argumento de una opción con código de carácter 1. (Esto lo utilizan los programas que fueron escritos para esperar opciones y otros elementos argv en cualquier orden y que se preocupan por el orden de los dos.) El argumento especial "--" fuerza el fin del escaneo de opciones sin importar el modo de escaneo.

Mientras procesa la lista de opciones, getopt() puede detectar dos tipos de errores: (1) un carácter de opción que no se especificó en optstring y (2) un argumento de opción faltante (es decir, una opción al final de la línea de comandos sin el argumento esperado). Dichos errores se manejan y se informan de la siguiente manera:

•
Por defecto, getopt() imprime un mensaje de error en la salida estándar de error, coloca el carácter de opción erróneo en optopt y devuelve '?' como resultado de la función.
•
Si el llamador ha establecido la variable global opterr a cero, entonces getopt() no imprime un mensaje de error. El llamador puede determinar que hubo un error probando si el valor de retorno de la función es '?'. (Por defecto, opterr tiene un valor distinto de cero).
•
Si el primer carácter (siguiendo cualquier '+' o '-' opcional descrito anteriormente) de optstring es dos puntos (':'), entonces getopt() tampoco imprime un mensaje de error. Además, devuelve ':' en lugar de '?' para indicar un argumento de opción faltante. Esto permite al llamador distinguir los dos tipos diferentes de errores.

getopt_long() y getopt_long_only()

La función getopt_long() funciona como getopt() excepto que también acepta opciones largas, iniciadas con dos guiones. (Si el programa acepta solo opciones largas, entonces optstring debe especificarse como una cadena vacía (""), no NULL.) Los nombres de opciones largas pueden abreviarse si la abreviatura es única o es una coincidencia exacta con alguna opción definida. Una opción larga puede tomar un parámetro, en la forma --arg=param o --arg param.

longopts es un puntero al primer elemento de una matriz de struct option declarada en <getopt.h> como


struct option {
    const char *name;
    int         has_arg;
    int        *flag;
    int         val;
};

Los significados de los diferentes campos son:

name
es el nombre de la opción larga.
has_arg
es: no_argument (o 0) si la opción no toma un argumento; required_argument (o 1) si la opción requiere un argumento; o optional_argument (o 2) si la opción toma un argumento opcional.
flag
especifica cómo se devuelven los resultados para una opción larga. Si flag es NULL, entonces getopt_long() devuelve val. (Por ejemplo, el programa que llama puede establecer val en el carácter de opción corto equivalente). De lo contrario, getopt_long() devuelve 0, y flag apunta a una variable que se establece en val si se encuentra la opción, pero permanece sin cambios si la opción no se encuentra.
val
es el valor a devolver, o a cargar en la variable apuntada por flag.

El último elemento de la matriz tiene que estar relleno con ceros.

Si longindex no es NULL, apunta a una variable que se establece en el índice de la opción larga relativo a longopts.

getopt_long_only() es como getopt_long(), pero '-' así como "--" pueden indicar una opción larga. Si una opción que comienza con '-' (no "--") no coincide con una opción larga, pero coincide con una opción corta, se analiza como una opción corta en su lugar.

VALOR DE RETORNO

El valor de retorno depende del primer carácter en optstring: si es ':', entonces se devuelve ':'; de lo contrario, se devuelve '?'.

getopt_long() y getopt_long_only() también devuelven el carácter de opción cuando se reconoce una opción corta. Para una opción larga, devuelven val si flag es NULL, y 0 en caso contrario. Los errores y los retornos -1 son los mismos que para getopt(), más '?' para una coincidencia ambigua o un parámetro extralimitado.

ENTORNO

POSIXLY_CORRECT
Si esta variable está configurada, el procesamiento de opciones se detiene tan pronto como se encuentra un argumento que no es una opción.

VERSIONES

POSIX especifica que el argumento del array argv debe ser const, pero estas funciones permutan sus elementos a menos que la variable de entorno POSIXLY_CORRECT esté configurada. const se utiliza en el prototipo real para ser compatible con otros sistemas; sin embargo, esta página no muestra el calificador, para evitar confundir a los lectores.

HISTORIAL

getopt()
POSIX.1-2001 y POSIX.2.

En algunas implementaciones antiguas, getopt() se declaraba en <stdio.h>. SUSv1 permitía que la declaración apareciera en <unistd.h> o <stdio.h>. POSIX.1-1996 marcó el uso de <stdio.h> para este propósito como LEGACY. POSIX.1-2001 no requiere que la declaración aparezca en <stdio.h>.

Versiones muy antiguas de glibc se vieron afectadas por la variable de entorno _PID_GNU_nonoption_argv_flags_.

NOTAS

Un programa que analiza múltiples vectores de argumentos, o que vuelve a analizar el mismo vector más de una vez, y desea utilizar las extensiones de GNU como '+' y '-' al principio de optstring, o cambia el valor de POSIXLY_CORRECT entre análisis, debe reinicializar getopt() restableciendo optind a 0, en lugar del valor tradicional de 1. (Restablecer a 0 fuerza la invocación de una rutina de inicialización interna que vuelve a comprobar POSIXLY_CORRECT y verifica las extensiones de GNU en optstring).

Los argumentos de la línea de comandos se analizan en orden estricto, lo que significa que una opción que requiere un argumento consumirá el siguiente argumento, independientemente de si ese argumento es el argumento de opción especificado correctamente o simplemente la siguiente opción (en el escenario en que el usuario especifica incorrectamente la línea de comandos). Por ejemplo, si optstring se especifica como "1n:" y el usuario especifica incorrectamente los argumentos de la línea de comandos como prog -n -1, la opción -n recibirá el valor optarg "-1", y la opción -1 se considerará no especificada.

EJEMPLOS

getopt()

El siguiente ejemplo trivial utiliza getopt() para manejar dos opciones del programa: -n, sin valor asociado; y -t val, que espera un valor asociado.

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int flags, opt;
    int nsecs, tfnd;
    nsecs = 0;
    tfnd = 0;
    flags = 0;
    while ((opt = getopt(argc, argv, "nt:")) != -1) {
        switch (opt) {
        case 'n':
            flags = 1;
            break;
        case 't':
            nsecs = atoi(optarg);
            tfnd = 1;
            break;
        default: /* '?' */
            fprintf(stderr, "Usage: %s [-t nsecs] [-n] name\n",
                    argv[0]);
            exit(EXIT_FAILURE);
        }
    }
    printf("flags=%d; tfnd=%d; nsecs=%d; optind=%d\n",
           flags, tfnd, nsecs, optind);
    if (optind >= argc) {
        fprintf(stderr, "Expected argument after options\n");
        exit(EXIT_FAILURE);
    }
    printf("name argument = %s\n", argv[optind]);
    /* Other code omitted */
    exit(EXIT_SUCCESS);
}

getopt_long()

El siguiente ejemplo de programa ilustra el uso de getopt_long() con la mayoría de sus características.

#include <getopt.h>
#include <stdio.h>     /* for printf */
#include <stdlib.h>    /* for exit */
int
main(int argc, char *argv[])
{
    int c;
    int digit_optind = 0;
    while (1) {
        int this_option_optind = optind ? optind : 1;
        int option_index = 0;
        static struct option long_options[] = {
            {"add",     required_argument, 0,  0 },
            {"append",  no_argument,       0,  0 },
            {"delete",  required_argument, 0,  0 },
            {"verbose", no_argument,       0,  0 },
            {"create",  required_argument, 0, 'c'},
            {"file",    required_argument, 0,  0 },
            {0,         0,                 0,  0 }
        };
        c = getopt_long(argc, argv, "abc:d:012",
                        long_options, &option_index);
        if (c == -1)
            break;
        switch (c) {
        case 0:
            printf("option %s", long_options[option_index].name);
            if (optarg)
                printf(" with arg %s", optarg);
            printf("\n");
            break;
        case '0':
        case '1':
        case '2':
            if (digit_optind != 0 && digit_optind != this_option_optind)
              printf("digits occur in two different argv-elements.\n");
            digit_optind = this_option_optind;
            printf("option %c\n", c);
            break;
        case 'a':
            printf("option a\n");
            break;
        case 'b':
            printf("option b\n");
            break;
        case 'c':
            printf("option c with value '%s'\n", optarg);
            break;
        case 'd':
            printf("option d with value '%s'\n", optarg);
            break;
        case '?':
            break;
        default:
            printf("?? getopt returned character code 0%o ??\n", c);
        }
    }
    if (optind < argc) {
        printf("non-option ARGV-elements: ");
        while (optind < argc)
            printf("%s ", argv[optind++]);
        printf("\n");
    }
    exit(EXIT_SUCCESS);
}
