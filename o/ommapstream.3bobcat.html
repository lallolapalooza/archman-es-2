FBB::OmmapStream(3bobcat) std::istream usando FBB::MmapBuf como streambuf FBB::OmmapStream(3bobcat)

NOMBRE

FBB::OmmapStream - Flujo de entrada usando mmap(2) a través de FBB::MmapBuf

SINOPSIS

#include <bobcat/ommapstream>

Opción de enlazado: -lbobcat

DESCRIPCIÓN

Los objetos FBB::OmmapStream se utilizan para escribir información en archivos que se ponen a disposición en el espacio de direcciones virtual del proceso que llama. El uso del espacio de direcciones virtual es manejado por la clase FBB::MmapBuf heredada privadamente (clase std::streambuf.

Al mapear archivos en el espacio de direcciones virtual del proceso, el tiempo requerido para procesar dichos archivos generalmente se reduce drásticamente.

Se lanza una std::exception y se escribe un mensaje de error en cerr si la clase base FBB::MmapBuf no puede determinar el tamaño del archivo especificado, o cuando el (des)mapeo no se puede realizar.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::ostream, privadamente de FBB::MmapBuf.

CONSTRUCTORES

o
OmmapStream():
El constructor por defecto simplemente construye un objeto OmmapStream vacío. Para convertirlo en un objeto utilizable, utilice la asignación por movimiento;
o
OmmapStream(std::string const &fname, char const *bufSize = 0, std::ios::openmode openMode = std::ios::out, mode_t mode = 0644):
El constructor inicializa el objeto OmmapStream para un archivo llamado fname.

El parámetro openMode especifica cómo se utiliza fname. Se admiten los modos estándar ios::in, ios::out, ios::trunc, ios::app, y ios::ate.

Por defecto, bfOmmapStream) utiliza un tamaño de búfer de mapeo de 10 veces el tamaño de página estándar (cf. sysconf(3), y el miembro pageSize a continuación). El tamaño del búfer de mapeo también se puede especificar usando el parámetro bufSize. Para especificarlo, use un valor seguido de K, M, o G, que representan, respectivamente, 1024, 1024 * 1024 y 1024 * 1024 * 1024 bytes. El tamaño final del búfer es al menos igual al tamaño de página estándar. Cuando se especifica un valor mayor, el tamaño del búfer utilizado se establece en especificado / pageSize * pageSize.

El parámetro mode especifica el modo de acceso de usuario/grupo/otro que se utiliza cuando el archivo es creado por MmapBuf. Su valor por defecto especifica acceso de lectura/escritura por parte del usuario y acceso de lectura por parte de otros.)

El constructor de movimiento y el operador de asignación de movimiento están disponibles.
El constructor de copia y el operador de asignación de copia no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::istream están disponibles, ya que FBB::OmmapStream hereda de esa clase.

o
size_t bufSize() const:
devuelve el tamaño del búfer t(mmap) utilizado;
o
size_t fileSize() const:
devuelve el tamaño actual del archivo utilizado. El tamaño se actualiza a un tamaño mayor al escribir más allá del tamaño actual del archivo. Una vez que el objeto OmmapStream deja de existir, el tamaño del archivo utilizado se modifica al valor actual de fileSize.
o
size_t pageSize() const:
devuelve el tamaño de página más pequeño utilizado por t(mmap).
