Nombre

org.bluez.GattProfile - Documentación de la API GattProfile de BlueZ D-Bus

Descripción

Instancia local de perfil (cliente GATT). Al registrar este tipo de objeto, una aplicación indica efectivamente soporte para un perfil GATT específico y solicita que se establezcan conexiones automáticas a los dispositivos que lo soportan.

Interfaz

Servicio
<dependiente de la aplicación>
Interfaz
org.bluez.GattProfile1
Ruta de objeto
<dependiente de la aplicación>

Métodos

void Release()

Este método se llama cuando bluetoothd(8) anula el registro del perfil. El perfil puede usarlo para realizar tareas de limpieza.

No es necesario anular el registro del perfil, ya que cuando se llama a este método, ya se ha anulado el registro.

Propiedades

array{string} UUIDs [solo-lectura]

UUIDs de servicio GATT de 128 bits para conectar automáticamente.
