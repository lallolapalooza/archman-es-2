NOMBRE

oath_authenticate_usersfile - Función de la API

SINOPSIS

#include <oath.h>

int oath_authenticate_usersfile(const char * usersfile, const char * username, const char * otp, size_t window, const char * passwd, time_t * last_otp);

ARGUMENTOS

const char * usersfile
cadena con el nombre del archivo de credenciales del usuario, en formato UsersFile
const char * username
cadena con el nombre del usuario
const char * otp
cadena con la contraseña de un solo uso a autenticar
size_t window
cuántas contraseñas de un solo uso pasadas/futuras buscar
const char * passwd
cadena con la contraseña, o NULL para deshabilitar la verificación de contraseña
time_t * last_otp
variable de salida que contiene la última autenticación exitosa

DESCRIPCIÓN

Autentica al usuario llamado username con la contraseña de un solo uso otp y (opcionalmente) la contraseña passwd. Las credenciales se leen (y actualizan) de un archivo de texto llamado usersfile.

Tenga en cuenta que para TOTP, el archivo usersfile solo registrará la última OTP y la usará para asegurarse de que las OTP más recientes no se hayan visto aún al validar una nueva OTP. Esa lógica depende del uso de la misma ventana de búsqueda para el mismo usuario.

RETORNA

Al validar correctamente, se devuelve OATH_OK. Si la otp proporcionada es la misma que la última contraseña de un solo uso autenticada con éxito, se devuelve OATH_REPLAYED_OTP y la marca de tiempo de la última autenticación se devuelve en last_otp. Si la contraseña de un solo uso no se encuentra en la ventana de búsqueda indicada, se devuelve OATH_INVALID_OTP. De lo contrario, se devuelve un código de error.
