ops(3perl) Referencia del programador de Perl ops(3perl)

NOMBRE

ops - Pragma de Perl para restringir operaciones inseguras durante la compilación

SINOPSIS

perl -Mops=:default ...    # solo permite operaciones razonablemente seguras
perl -M-ops=system ...     # deshabilita el opcode 'system'

DESCRIPCIÓN

Dado que el pragma "ops" actualmente tiene un efecto global irreversible, solo es de utilidad práctica significativa con la opción "-M" en la línea de comandos.

Consulte el módulo Opcode para obtener información sobre opcodes, optags, opmasks e información importante sobre seguridad.

VER TAMBIÉN

Opcode, Safe, perlrun
