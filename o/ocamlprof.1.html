NOMBRE

ocamlprof - El perfilador de OCaml

SINOPSIS

ocamlprof [ opciones ] archivo ...

DESCRIPCIÓN

El comando ocamlprof imprime recuentos de ejecución recopilados durante la ejecución de un programa OCaml instrumentado con ocamlcp(1).

Produce una lista fuente de los módulos del programa dados como argumentos donde se han insertado recuentos de ejecución como comentarios. Por ejemplo,

ocamlprof foo.ml

imprime el código fuente del módulo foo, con comentarios que indican cuántas veces se han llamado las funciones de este módulo. Naturalmente, esta información solo es precisa si el archivo fuente no se ha modificado desde que tuvo lugar la ejecución del perfilado.

OPCIONES

-f archivo_volcado
Especifica un archivo de volcado alternativo de información de perfilado.
-F cadena
Especifica una cadena adicional que se imprimirá con la información de perfilado. Por defecto, ocamlprof(1) anotará los programas con comentarios del tipo (* n *) donde n es el valor del contador para un punto de perfilado. Con la opción -F s la anotación será (* sn *)
-impl archivo
Compila el archivo archivo como un archivo de implementación, incluso si su extensión no es .ml.
-intf archivo
Compila el archivo archivo como un archivo de interfaz, incluso si su extensión no es .mli.
-keywords versión+lista
Establece palabras clave según la especificación versión+lista.
-version
Imprime la cadena de versión y sale.
-vnum
Imprime el número de versión corto y sale.
-help o --help
Muestra un breve resumen de uso y sale.

VER TAMBIÉN

El manual del usuario de OCaml, capítulo "Perfilado".
