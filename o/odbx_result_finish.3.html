odbx_result_finish(3)

Paquete: opendbx

Licencias: LGPL

odbx_result_finish(3) OpenDBX odbx_result_finish(3)

NOMBRE

odbx_result_finish, odbx_result_free - Cierra el conjunto de resultados y libera su memoria asignada

SINOPSIS

#include <opendbx/api.h>


int odbx_result_finish
(odbx_result_t* result);


void odbx_result_free
(odbx_result_t* result);

DESCRIPCIÓN

odbx_result_finish() cierra el conjunto de resultados, lo que puede incluir la eliminación de las filas no recuperadas enviadas por el servidor. Libera todos los recursos asignados por odbx_result() y por la biblioteca de base de datos nativa que están adjuntos al resultado, así como la memoria a la que apunta el primer parámetro. Intentar liberar el resultado manualmente usando free() creará fugas de memoria porque contiene más estructuras asignadas dinámicamente y también la memoria del conjunto de resultados asignada por la biblioteca de base de datos nativa. odbx_result_finish() debe llamarse incluso si la instrucción no fue una instrucción tipo SELECT que devolvió filas, ya que puede ser necesario confirmar los cambios realizados por la instrucción.

odbx_result_free() realiza las mismas tareas que odbx_result_finish() pero no puede devolver un error si la tarea no pudo completarse. No debe usarse en aplicaciones que enlazan con la biblioteca OpenDBX versión 1.3.8 o posterior y se eliminará de la biblioteca en una etapa posterior.

result debe ser un conjunto de resultados válido creado por odbx_result() que se devuelve a través de su segundo parámetro. Después de pasarlo a odbx_result_finish() se vuelve inválido y no debe pasarse de nuevo. De lo contrario, puede ocurrir una "liberación doble" y la aplicación puede terminar.

VALOR DE RETORNO

odbx_result_finish() devuelve ODBX_ERR_SUCCESS, o un código de error cuyo valor es menor que cero si alguna de las operaciones no pudo completarse con éxito. Los códigos de error posibles se enumeran en la sección de errores y se pueden pasar a odbx_error() y odbx_error_type() para obtener más detalles.

ERRORES

-ODBX_ERR_BACKEND
La biblioteca de base de datos nativa devolvió un error
-ODBX_ERR_PARAM
El parámetro result es inválido

VER TAMBIÉN
