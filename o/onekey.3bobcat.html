FBB::OneKey(3bobcat) Entrada de una sola pulsación FBB::OneKey(3bobcat)

NOMBRE

FBB::OneKey - Entrada de una sola pulsación, sin requerir `Retorno’

SINOPSIS

#include <bobcat/onekey>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

Los objetos OneKey pueden utilizarse para realizar la `entrada directa del teclado’: una tecla presionada se vuelve disponible sin necesidad de presionar Enter. Los caracteres se obtienen del flujo de entrada estándar. La entrada directa de teclas permanece activa mientras el objeto OneKey exista. Una vez que el objeto se destruye, el flujo de entrada estándar volverá a su modo de operación predeterminado, en el que la entrada se `confirma’ con un carácter de nueva línea.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página de manual están definidos en el espacio de nombres FBB.

HEREDA DE

-

ENUMERACIÓN

La enumeración OneKey::Mode se utiliza para controlar el eco de los caracteres devueltos. Tiene dos valores:

o
OFF: los caracteres devueltos no se reflejan en el flujo de salida estándar;
o
ON: los caracteres devueltos sí se reflejan en el flujo de salida estándar.

CONSTRUCTORES

o
OneKey(OneKey::Mode state = OneKey::OFF):
Este constructor inicializa el objeto de entrada OneKey. Por defecto, los caracteres introducidos no se reflejan. Al construir el objeto con el argumento OneKey::ON, los caracteres introducidos se reflejan en el flujo de salida estándar.
Este constructo lanza una excepción Exception si no se completa correctamente. El constructor puede fallar por las siguientes razones:
o
el flujo de entrada estándar no es un tty (por ejemplo, cuando el flujo de entrada estándar se redirige a un archivo);
o
no se puede determinar el estado actual del flujo de entrada estándar;
o
no se puede cambiar el estado del flujo de entrada estándar al modo de `entrada directa del teclado’.

Los constructores y operadores de asignación de copia y movimiento no están disponibles.

FUNCIONES MIEMBRO

o
int get() const:
Devuelve el siguiente carácter del flujo de entrada estándar, sin necesidad de presionar Enter.
o
void setEcho(OneKey::Mode state):
Cambia el estado de eco del objeto OneKey. El argumento puede ser OneKey::ON o OneKey::OFF.

EJEMPLO

/*
                              driver.cc
*/
#include <iostream>
#include <string>
#include <bobcat/onekey>
using namespace std;
using namespace FBB;
int main()
{
    try
    {
        OneKey onekey;
        cout << "Uso: 1: los siguientes caracteres se reflejarán, 0: sin eco, q: salir\n";
        while (true)
        {
            char c;
            cout << "listo...\n";
            cout << "Carácter recibido ’" << (c = onekey.get()) << "’\n";
            switch (c)
            {
                case ’1’:
                    onekey.setEcho(OneKey::ON);
                break;
                case ’0’:
                    onekey.setEcho(OneKey::OFF);
                break;
                case ’q’:
                return 0;
            }
        }
    }
    catch (exception const &e)
    {
        cout << e.what() << endl;
        return 1;
    }
}
