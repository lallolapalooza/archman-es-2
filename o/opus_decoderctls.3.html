#define OPUS_GET_PITCH(x)

Obtiene el tono del último fotograma decodificado, si está disponible. Esto puede usarse para cualquier algoritmo de postprocesamiento que requiera el uso del tono, por ejemplo, estiramiento/acortamiento temporal. Si el último fotograma no fue sonoro, o si el tono no se codificó en el fotograma, se devuelve cero.

Este CTL solo se implementa para instancias de decodificador.

Parámetros

x opus_int32 *: período de tono a 48 kHz (o 0 si no está disponible)

#define OPUS_SET_GAIN(x)

Configura el ajuste de ganancia del decodificador. Escala la salida decodificada por un factor especificado en unidades de dB Q8. Esto tiene un rango máximo de -32768 a 32767 inclusive, y devuelve OPUS_BAD_ARG en caso contrario. El valor predeterminado es cero, lo que indica que no hay ajuste. Esta configuración sobrevive a reinicios del decodificador.

gain = pow(10, x/(20.0*256))

Parámetros

x opus_int32: Cantidad para escalar la señal PCM en unidades de dB Q8.
