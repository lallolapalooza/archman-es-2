Nombre

org.bluez.LEAdvertisement - Documentación de la API LEAdvertisement de BlueZ D-Bus

Descripción

Los paquetes de publicidad son datos estructurados que se transmiten en los canales de publicidad LE y están disponibles para todos los dispositivos en el rango. Debido al espacio limitado disponible en los paquetes de publicidad LE, el contenido de cada paquete debe controlarse cuidadosamente.

bluetoothd(8) actúa como un almacén para los Datos de Publicidad que se pretenden enviar. Construye los Datos de Publicidad correctos a partir de los datos estructurados y configura el kernel para enviar la publicidad correcta.

Interfaz

Especifica los Datos de Publicidad a transmitir y algunos parámetros de publicidad. Las propiedades que no están presentes no se incluirán en los datos. Los tipos de datos de publicidad requeridos siempre se incluirán. Todas las UUID son versiones de 128 bits en la API, y se utilizarán versiones de 16 o 32 bits de la misma UUID en los datos de publicidad según corresponda.

Métodos

void Release() [noreply]

Este método se llama cuando bluetoothd(8) elimina la Publicidad.

Un cliente puede usarlo para realizar tareas de limpieza. No es necesario llamar a UnregisterAdvertisement() porque cuando se llama a este método, ya se ha desregistrado.

BlueZ

Name

org.bluez.LEAdvertisement - BlueZ LE Advertisement D-Bus interface

Description

This interface is used to define the properties of a LE (Low Energy) advertisement. This interface is intended to be implemented by the BlueZ D-Bus daemon.

The advertisement is published on the Bluetooth adapter once the object is registered. The advertisement will be removed once the object is unregistered.

Applications wanting to register an advertisement should implement this interface and register it under the object path /org/bluez/LEAdvertisement/Ad1 where Ad1 can be any unique identifier.

The org.bluez.LEAdvertisingManager(5) interface is used to register the advertisement.

Interface

The LEAdvertisement interface is defined as follows:

interface org.bluez.LEAdvertisement

uint16 Type [readonly, optional]

Type of advertisement. Possible values are:

0
Broadcast
1
Peripheral
2
Local Name
3
Slave Connection Int

If not specified, it defaults to Broadcast.

uint16 Instance [readonly, optional]

Advertisement instance ID. This must be unique for each registered advertisement that has the same type. If not specified, it defaults to 0.

string[] UUIDs [readonly, optional]

List of Service UUIDs.

string ManufacturerData [readonly, optional]

Dictionary of manufacturer specific data. The keys are the company identifiers. The values are byte arrays representing the data.

Example:

{"0000": [0x01, 0x02]}

string ServiceData [readonly, optional]

Dictionary of service data. The keys are the service UUIDs.

Example:

{"0000": [0x01, 0x02]}

uint16 AdvData [readonly, optional]

If present, it indicates that the advertisement data should be included.

The default value is 0.

uint16 Duration [readonly, optional]

Duration of the advertisement in seconds. If not set, the default is 2 seconds.

If there are other applications advertising no duration is set the default is 2 seconds.

uint16 Timeout [readonly, optional]

Timeout of the advertisement in seconds. This defines the lifetime of the advertisement.

string SecondaryChannel [readonly, optional]

Secondary channel to be used.

Primary channel is always set to "1M" except when "Coded" is set.

Possible value:

"1M" (default)
"2M"
"Coded"

uint32 MinInterval [readonly, optional]

Minimum advertising interval to be used by the advertising set, in milliseconds.

Acceptable values are in the range [20ms, 10,485s].

If the provided MinInterval is larger than the provided MaxInterval, the registration will return failure.

uint32 MaxInterval [readonly, optional]

Maximum advertising interval to be used by the advertising set, in milliseconds.

Acceptable values are in the range [20ms, 10,485s].

If the provided MinInterval is larger than the provided MaxInterval, the registration will return failure.

int16 TxPower [readonly, optional]

Requested transmission power of this advertising set.

The provided value is used only if the "CanSetTxPower" feature is enabled on the org.bluez.LEAdvertisingManager(5).

Values must be in range [-127 to +20], where units are in dBm.
