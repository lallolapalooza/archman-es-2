oct-sign(1) Manual de comandos generales oct-sign(1)

NOMBRE

oct-sign - Firmar datos usando una tarjeta

SINOPSIS

oct sign <-c|--card> [-p|--user-pin] [-h|--help] <subcomandos>

DESCRIPCIÓN

Firmar datos usando una tarjeta

OPCIONES

-c, --card=identificador de tarjeta
Identificador de la tarjeta a usar
-p, --user-pin=archivo PIN de usuario
Opcionalmente, obtener el PIN de usuario de un archivo
-h, --help
Imprimir ayuda

SUBCOMANDOS

oct-sign-detached(1)
Crear una firma separada
oct-sign-cleartext(1)
Crear una firma de texto claro
oct-sign-inline(1)
Crear una firma en línea
oct-sign-help(1)
Imprimir este mensaje o la ayuda de los subcomandos dados
