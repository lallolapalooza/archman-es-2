NOMBRE

openssl-engine - cargar y consultar motores

SINOPSIS

openssl engine [-help] [-v] [-vv] [-vvv] [-vvvv] [-c] [-t] [-tt] [-pre comando] ... [-post comando] ... [motor ...]

DESCRIPCIÓN

Este comando ha sido obsoleto. Se deben utilizar proveedores en lugar de motores.

Este comando se utiliza para consultar el estado y las capacidades de los motores especificados. Los motores pueden especificarse antes y después de todas las demás opciones de línea de comandos. Solo se consultan los especificados.

OPCIONES

-help
Muestra un resumen de opciones.
-v -vv -vvv -vvvv
Proporciona información sobre cada motor especificado. La primera opción enumera todos los comandos de control posibles en tiempo de ejecución; la segunda añade una descripción de cada comando; la tercera añade las opciones de entrada, y la última opción añade las opciones de entrada internas.
-c
Enumera las capacidades de cada motor.
-t
Prueba si cada motor especificado está disponible y muestra la respuesta.
-tt
Muestra un rastreo de error para cualquier motor no disponible.
-pre comando
-post comando
Configuración de motores desde la línea de comandos. El comando -pre se pasa al motor antes de que se cargue y el comando -post se pasa después de que el motor se ha cargado. El comando tiene el formato cmd:val donde cmd es el comando y val es el valor para el comando. Vea el ejemplo a continuación.

Estas dos opciones son acumulativas, por lo que pueden darse más de una vez en el mismo comando.

EJEMPLOS

Para listar todos los comandos disponibles para un motor dinámico:

$ openssl engine -t -tt -vvvv dynamic
(dynamic) Soporte de carga de motores dinámicos
     [ no disponible ]
     SO_PATH: Especifica la ruta a la nueva biblioteca compartida del MOTOR
          (opciones de entrada): STRING
     NO_VCHECK: Especifica continuar incluso si la verificación de la versión falla (booleano)
          (opciones de entrada): NUMERIC
     ID: Especifica un nombre de id. de MOTOR para la carga
          (opciones de entrada): STRING
     LIST_ADD: Si agregar un MOTOR cargado a la lista interna (0=no,1=sí,2=obligatorio)
          (opciones de entrada): NUMERIC
     DIR_LOAD: Especifica si cargar desde directorios 'DIR_ADD' (0=no,1=sí,2=obligatorio)
          (opciones de entrada): NUMERIC
     DIR_ADD: Añade un directorio desde el que se pueden cargar MOTORES
          (opciones de entrada): STRING
     LOAD: Carga el MOTOR especificado por otras configuraciones
          (opciones de entrada): NO_INPUT

Para listar las capacidades del motor rsax:

$ openssl engine -c
(rsax) Soporte del motor RSAX
 [RSA]
(dynamic) Soporte de carga de motores dinámicos

ENTORNO

OPENSSL_ENGINES
La ruta al directorio de motores.

VER TAMBIÉN

openssl(1), config(5)
