o(1) Comandos de usuario o(1)

NOMBRE

o - un editor

SINOPSIS

o nombre_archivo [ NÚMERO_DE_LÍNEA ]

DESCRIPCIÓN

Edita un archivo existente o crea uno nuevo.

OPCIONES

El número de línea puede ir precedido por +, o ser un sufijo del nombre del archivo si va precedido por :.

-c NOMBRE_ARCHIVO o --copy NOMBRE_ARCHIVO
Copia el archivo dado al portapapeles.
-f o --force
Ignora los bloqueos de archivos al abrir archivos.
-l o --last-command
Muestra el último comando de compilación/formato/exportación utilizado.
-m NOMBRE_ARCHIVO o --monitor NOMBRE_ARCHIVO
Monitoriza el archivo dado para detectar cambios y lo abre en modo de solo lectura.
-n o --no-cache
Evita escribir el historial de ubicaciones, el historial de búsqueda, la puntuación más alta del juego y el último comando de compilación/formato/exportación en el directorio de caché.
-p NOMBRE_ARCHIVO o --paste NOMBRE_ARCHIVO
Pega el contenido del portapapeles en el archivo dado. Combina con -f para sobrescribir el archivo.
-e o --clear-locks
Borra todos los bloqueos de archivos.
-o o --ollama
Usa Ollama para la compleción de pestañas con el modelo especificado en la variable de entorno ORBITON_OLLAMA. Esto requiere que Ollama esté en ejecución, ya sea localmente o en el host especificado en la variable de entorno OLLAMA_HOST.
-r o --release
Compila en modo release en lugar de debug siempre que sea aplicable. Esto puede ser útil al editar un archivo CMakeLists.txt y luego presionar Ctrl+Espacio para compilar el proyecto.
-b o --bat
Lista el archivo con resaltado de sintaxis usando el comando bat, si está instalado.
-t o --list
Lista el archivo de forma colorida sin abrirlo para editar.
-b o --build
Compila el archivo dado en lugar de abrirlo para editar.
-F o --format
Formatea el archivo dado en lugar de abrirlo para editar.
-v o --version
Muestra la versión actual.
-h o --help
Muestra información breve de uso.

ATAJOS DE TECLADO

Ctrl+Q
Sale de o.

Ctrl+S
Guarda el archivo.

Ctrl+W
Formatea el archivo actual con goimport o clang-format, dependiendo de la extensión del archivo.
Zig, V, Rust (rustfmt), Haskell (brittany) y Python (autopep8) también son compatibles.
Si está en modo git, cambia la palabra clave del rebase interactivo de git en la línea actual.
Si está en modo Markdown, formatea la tabla bajo el cursor.

Ctrl+A
Ve al inicio del texto, luego al inicio de la línea y luego a la línea anterior.

Ctrl+E
Ve al final de la línea y luego a la siguiente línea.

Ctrl+N
Desplaza hacia abajo 10 líneas o ve a la siguiente coincidencia si hay una búsqueda activa.
Inserta una nueva columna en el editor de tablas Markdown.
Salta a un paréntesis o corchete coincidente si se acaban de usar las teclas de flecha. Ctrl+P
Desplaza hacia arriba 10 líneas o ve a la coincidencia anterior si hay una búsqueda activa.
Elimina una columna vacía en el editor de tablas Markdown.
Salta a un paréntesis o corchete coincidente si se acaban de usar las teclas de flecha.

Ctrl+K
Elimina todos los caracteres hasta el final de la línea. Elimina la línea si está vacía.

Ctrl+G
Salta a la definición, para algunos lenguajes de programación (función experimental) o alterna la barra de estado.

Ctrl+D
Elimina un solo carácter.

Ctrl+O
Abre el menú de comandos, que es una lista de acciones que se pueden realizar.
Si se edita un archivo PKGBUILD y guessica está instalado, habrá una opción de menú para actualizar los campos pkgver y source.
Si pandoc está instalado, puede aparecer una opción de menú para renderizar a PDF.

Ctrl+T
Para C y C++: cambia entre el archivo de encabezado y el de implementación correspondientes.
Para Agda, inserta un símbolo.
Para Markdown, si el cursor está en una tabla, inicia el editor de tablas Markdown.
Para el resto, graba y reproduce pulsaciones de teclas. Presiona Escape para borrar la macro actual.

Ctrl+C
Presiona dos veces para copiar el bloque de texto actual (hasta una línea en blanco o el final del archivo).
Presiona una vez para copiar solo la línea actual.
También cierra el portal.

Ctrl+V
Presiona una vez para pegar solo la primera línea del texto copiado, recortado.
Presiona dos veces para pegar todo el texto copiado, sin recortar.

Ctrl+X
Presiona una vez para cortar solo la línea actual (o eliminarla, si está vacía).
Presiona dos veces para cortar el bloque de texto actual (hasta una línea en blanco o el final del archivo).
También cierra el portal.

Ctrl+B
Salta hacia atrás después de saltar a una definición con `Ctrl+G`.
Marca la línea actual. Presiona de nuevo para eliminar la marca.
Si hay una marca establecida y no estás en la línea marcada, salta a la marca.
Alterna el punto de interrupción si el editor está en modo de depuración.

Ctrl+J
Une líneas.

Ctrl+U
Deshacer (Ctrl+Z también es posible, pero puede enviar la aplicación a segundo plano).

Ctrl+L
Salta a un número de línea o porcentaje específico. Presiona Intro para saltar al principio. Presiona Intro de nuevo para saltar al final.
Presiona una de las letras resaltadas en pantalla para saltar a esa ubicación.

Ctrl+F
Busca una cadena desde la ubicación actual. La búsqueda envuelve y distingue entre mayúsculas y minúsculas.
También hay soporte para reemplazo de texto, después de escribir el término de búsqueda:
Para reemplazar todo, presiona Tab en lugar de Intro, introduce un término de reemplazo y luego presiona Tab.
Para reemplazar una vez, presiona Tab en lugar de Intro, introduce un término de reemplazo y luego presiona Intro.
Busca solo f para encontrar la firma de la función anterior.

Esc
Redibuja la pantalla y borra la última búsqueda.

Ctrl+Espacio
Compila programas Go con `go`.
Compila programas C++ con `cxx`.
Compila programas Rust con `cargo` o `rustc`.
Compila programas Zig con `zig`.
Compila programas Haskell con `ghc`.
Verifica programas Python con `python -m py_compile`.
Compila programas Crystal con `crystal`.
Compila programas Kotlin con `kotlinc`,
o `kotlinc-native` si está disponible.
Compila programas Java con `javac` y `jar`.
Compila programas Scala con `scalac`.
Compila programas Lua con `luac`.
Compila programas Object Pascal con `fpc`.
Compila programas Nim con `nim`.
Compila programas Odin con `odin`.
Compila programas V con `v`.
Compila programas C# con `csc -nollogo -unsafe`.
Compila programas D con `gdc`.
Compila programas Standard ML con `mlton`.
Compila programas OCaml con `ocamlopt`.
Exporta archivos scdoc a man usando `scdoc`.
Exporta archivos asciidoctor a man usando `asciidoctor`.
Compila paquetes de Arch Linux con `makepkg`.
Compila programas Agda con `agda`.
Doble clic para renderizar Markdown a HTML.


El último comando externo utilizado por `o` se puede encontrar en `~/.cache/o/last_command.sh`.

Ctrl+~
Inserta la fecha y hora actuales.


`o` intentará saltar a la ubicación donde está el error y, de lo contrario, mostrará "Success".

Ctrl+Esc
Alterna comentarios de una sola línea para un bloque de código.

Ctrl+_
Inserta un símbolo escribiendo un digrama de 2 letras.
Los dígrafos son los mismos que para ViM.
Para una visión general completa, ver: https://raw.githubusercontent.com/xyproto/digraph/main/digraphs.txt

Ctrl+R
Abre o cierra un portal. Se puede pegar texto.

DESCRIPCIÓN

o es un editor de texto para la terminal que se enfoca en la simplicidad y la usabilidad.

OPCIONES

No hay opciones de línea de comandos para o. Todas las configuraciones se realizan a través de variables de entorno o enlaces de teclado.

ENLACES DE TECLADO

o utiliza un conjunto de enlaces de teclado simplificados para la edición de texto.

Ctrl-s: Guarda el archivo actual.

Ctrl-o: Abre el menú de operaciones (guardar, salir, etc.).

Ctrl-p: Mueve el cursor una línea hacia arriba.

Ctrl-n: Mueve el cursor una línea hacia abajo.

Ctrl-f: Mueve el cursor un carácter hacia la derecha.

Ctrl-b: Mueve el cursor un carácter hacia la izquierda.

Ctrl-u: Pega texto copiado del portapapeles del portal a otro archivo con `ctrl-v`.

Para el modo de "git interactive rebase", cicla las palabras clave del rebase.

ENV

La variable de entorno NO_COLOR puede establecerse en 1 para deshabilitar todos los colores.

Si XTERM_VERSION está configurada (generalmente automáticamente por xterm), se usará el esquema de color "claro".

La variable de entorno ORBITON_OLLAMA puede establecerse en 1 para habilitar la autocompletación de Ollama.

La variable de entorno OLLAMA_HOST especifica el host para el servicio Ollama si se debe usar un servicio no local.

PÁGINA DEL MANUAL (MAN PAGER)

Se puede usar 'o' para ver las páginas del manual estableciendo MANPAGER en "o", por ejemplo, export MANPAGER=o.

¿POR QUÉ?

Quería escribir un editor simple que solo usara códigos de terminal VT100.

VER TAMBIÉN

e3(1) nano(1) micro(1)

BUGS CONOCIDOS

En algunos emuladores de terminal, desplazarse rápidamente hacia arriba o hacia abajo con las teclas de flecha puede hacer que el texto salte (funciona bien en alacritty). Desplácese hacia arriba y hacia abajo con ctrl-n y ctrl-p en su lugar para evitar esto. Presione esc para repintar el texto, si es necesario.

Algunas runas unicode pueden interrumpir el flujo del texto. Esto generalmente no es un problema al editar código y archivos de configuración, pero puede ser un problema al editar archivos que contienen texto en muchos idiomas.

Para algunos emuladores de terminal, si o está ocupado realizando una operación, presionar ctrl-s puede bloquear la terminal. Algunos emuladores de terminal, como konsole, se pueden configurar para deshabilitar este comportamiento. Presione ctrl-q para desbloquear la terminal nuevamente (junto con el desafortunado riesgo de salir de o). También puede usar el menú ctrl-o para guardar y salir.

o puede tener problemas con archivos grandes (de varios MB o más). Para archivos de texto normales o archivos de código fuente, esto no es un problema.

El pegado con clic central del ratón (en lugar de pegar con ctrl-v) puede tener problemas al pegar solo el primer carácter.

La indentación inteligente no siempre es inteligente.
