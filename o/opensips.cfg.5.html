NOMBRE

opensips.cfg - archivo de configuración de opensips

SINOPSIS

/etc/opensips/opensips.cfg

DESCRIPCIÓN

opensips lee los datos de configuración desde /etc/opensips/opensips.cfg (o el archivo especificado con -f en la línea de comandos). El archivo contiene parámetros de configuración global, comandos de carga de módulos y el script que será ejecutado para cada solicitud recibida. Las líneas que comienzan con # o encerradas en /* ... */ se interpretan como comentarios.

Esta página del manual está incompleta. Para más información, por favor, lea la documentación de opensips (https://opensips.org/).
