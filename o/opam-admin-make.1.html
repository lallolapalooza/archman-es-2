OPAM ADMIN-MAKE(1) Manual de administración de Opam OPAM ADMIN-MAKE(1)

NOMBRE

opam admin-make - Un alias para index.

SINOPSIS

opam admin make [--full-urls-txt] [--minimal-urls-txt] [--no-urls-txt] [OPCIÓN]…

DESCRIPCIÓN

opam admin make es un alias para opam admin index.

Ver opam admin index --help para más detalles.

OPCIONES

--full-urls-txt
Genera un 'urls.txt' inclusivo, para un repositorio que será utilizado por versiones de opam anteriores a la 2.0.
--minimal-urls-txt
Genera un archivo 'urls.txt' mínimo, que solo incluye el archivo 'repo'. Esto permite que las versiones de opam anteriores a la 2.0 lean ese archivo, y sean redirigidas correctamente a un repositorio dedicado a su versión, asumiendo que se define un campo 'redirect:' adecuado, en lugar de fallar. Este es el valor por defecto.
--no-urls-txt
No genera un archivo 'urls.txt'. Este archivo de índice ya no es necesario a partir de opam 2.0, pero aún es utilizado por versiones anteriores.

OPCIONES COMUNES

Estas opciones son comunes a todos los comandos.

--best-effort
No fallar si no se pueden instalar todos los paquetes solicitados: intentar instalar tantos como sea posible. Tenga en cuenta que no todos los resolutores externos pueden soportar esta opción (las versiones recientes de aspcud o mccs deberían). Esto es equivalente a establecer la variable de entorno $OPAMBESTEFFORT.
--cli=MAYOR.MENOR (ausente=2.4)
Utiliza la sintaxis y semántica de la interfaz de línea de comandos de MAYOR.MENOR. Dirigido a cualquier uso persistente de opam (scripts, posts de blogs, etc.), cualquier versión de opam en la misma serie MAYOR se comportará como para la versión MENOR especificada. La opción no estaba disponible en opam 2.0, así que para seleccionar la CLI 2.0, establezca la variable de entorno $OPAMCLI a 2.0 en lugar de usar este parámetro.
--color=CUÁNDO
Colorea la salida. CUÁNDO debe ser uno de always, never o auto.
--confirm-level=NIVEL
Nivel de confirmación, NIVEL debe ser uno de ask, no, yes o unsafe-yes. Puede especificarse más de una vez. Si también se dan --yes o --no, se tiene en cuenta el valor del último --confirm-level. Esto es equivalente a establecer $OPAMCONFIRMLEVEL.
--criteria=CRITERIOS
Especifica las preferencias del usuario para la resolución de dependencias para esta ejecución. Anula $OPAMCRITERIA, $OPAMFIXUPCRITERIA y $OPAMUPGRADECRITERIA. Para detalles sobre el lenguaje soportado y los resolutores externos disponibles, ver http://opam.ocaml.org/doc/External_solvers.html. Una guía general para usar preferencias de resolutores se puede encontrar en http://www.dicosmo.org/Articles/usercriteria.pdf.
--cudf=NOMBRE_ARCHIVO
Opción de depuración: Guarda las solicitudes CUDF enviadas al resolutor a NOMBRE_ARCHIVO-<n>.cudf donde <n> es la n-ésima llamada al resolutor durante la ejecución de opam.
--debug
Imprime mensajes de depuración en stderr. Esto es equivalente a establecer $OPAMDEBUG a "true".
--debug-level=NIVEL
Similar a --debug, pero permite especificar el nivel de depuración (--debug lo establece en 1). Equivalente a establecer $OPAMDEBUG a un entero positivo.
--git-version
Imprime la versión git de opam, si está establecida (es decir, si estás usando una versión de desarrollo), y sale.
--help[=FMT] (por defecto=auto)
Muestra esta ayuda en formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la variable TERM sea dumb o indefinida.
--ignore-pin-depends
Ignora pines adicionales requeridos por paquetes que son fijados (pined), ya sea manualmente a través de opam pin o a través de opam install DIR. Esto es equivalente a establecer IGNOREPINDEPENDS=true.
--json=NOMBRE_ARCHIVO
Guarda los resultados de la ejecución de opam en un archivo legible por computadora. Si el nombre del archivo contiene el carácter `%`, será reemplazado por un índice que no sobrescribe un archivo existente. Similar a establecer la variable $OPAMJSON.
--no
Responde no a todas las preguntas de sí/no de opam sin preguntar. Ver también --confirm-level. Esto es equivalente a establecer $OPAMNO a "true".
--no-aspcud
Eliminado en 2.1.
--no-auto-upgrade
Al configurar o actualizar un repositorio que está escrito para una versión anterior de opam (1.2), opam lo convierte internamente al formato actual. Esto deshabilita este comportamiento. Tenga en cuenta que los repositorios deberían definir su versión de formato en un archivo 'repo' en su raíz, o se asumirá que están en el formato antiguo. En cualquier caso, es preferible actualizar los repositorios manualmente usando opam admin upgrade [--mirror URL] cuando sea posible.
-q, --quiet
Deshabilita --verbose.
--root=RAÍZ
Usa RAÍZ como la ruta raíz actual. Esto es equivalente a establecer $OPAMROOT a RAÍZ.
--safe, --readonly
Asegura que nada será actualizado o reescrito automáticamente. Útil para llamar desde scripts de autocompletado, por ejemplo. Fallará siempre que se necesite tal operación; también evita esperar bloqueos, omite preguntas interactivas y anula la variable $OPAMDEBUG. Esto es equivalente a establecer la variable de entorno $OPAMSAFE.
--solver=CMD
Especifica el resolutor CUDF a usar para resolver problemas de instalación de paquetes. Este es un resolutor predefinido (esta versión de opam soporta builtin-mccs+lp(), builtin-mccs+glpk, builtin-dummy-z3-solver, builtin-0install, aspcud, mccs, aspcud-old, packup), o un comando personalizado que debe contener las variables %{input}%, %{output}%, %{criteria}%, y opcionalmente %{timeout}%. Esto es equivalente a establecer $OPAMEXTERNALSOLVER.
--strict
Falla siempre que se encuentre un error en la definición de un paquete o un archivo de configuración. El valor por defecto es continuar silenciosamente si es posible.
--switch=SWITCH
Usa SWITCH como el switch del compilador actual. Esto es equivalente a establecer $OPAMSWITCH a SWITCH.
--use-internal-solver
Deshabilita cualquier resolutor externo y usa el interno (esto requiere que opam haya sido compilado con un resolutor interno). Esto es equivalente a establecer $OPAMNOASPCUD o $OPAMUSEINTERNALSOLVER.
-v, --verbose
Sé más verboso. Una -v muestra todos los comandos de paquetes, repetir para mostrar también los comandos llamados internamente (ej. tar, curl, patch etc.) Repetir n veces es equivalente a establecer $OPAMVERBOSE a "n".
--version
Muestra información de la versión.
-w, --working-dir
Siempre que se actualicen paquetes que están vinculados a un directorio local controlado por versiones, actualiza al estado de trabajo actual de su código fuente en lugar del último estado confirmado, o la referencia a la que apuntan. Como el directorio de código fuente se copia tal cual, si no está limpio puede resultar en un fallo de compilación de opam. Esto solo afecta a los paquetes listados explícitamente en la línea de comandos. También puede establecerse con $OPAMWORKINGDIR.
-y, --yes
Responde sí a todas las preguntas de sí/no de opam sin preguntar. Ver también --confirm-level. Esto es equivalente a establecer $OPAMYES a "true".

OPTIONS

The following environment variables can be set to modify the behavior of opam commands:

OPAM_MAX_JOBS_RECOMMENDED This is not an environment variable, but a value suggested to the user if the number of jobs is too high.

OPAM_BEST_EFFORT When set to true, the solver will try its best to find a solution even if it is not optimal. This is useful when the solver is taking too long to find an optimal solution. The option --best-effort is equivalent to setting this variable.

OPAMBUILDDOC Removed in 2.1.

OPAMBUILDTEST Removed in 2.1.

OPAMCLI See option --cli.

OPAMCOLOR When set to always or never, sets a default value for the --color option.

OPAMCONFIRMLEVEL See option --confirm-level. OPAMCONFIRMLEVEL has priority over OPAMYES and OPAMNO.

OPAMCRITERIA Specifies user *preferences* for dependency solving. The default value depends on the solver version, use `opam config report` to know the current setting. See also option --criteria.

OPAMCUDFFILE Saves the CUDF graph to file-actions-explicit.dot.

OPAMCUDFTRIM Controls the filtering of unrelated packages during CUDF preprocessing.

OPAMCURL Can be used to select a given 'curl' program. See OPAMFETCH for more options.

OPAMDEBUG See options --debug and --debug-level.

OPAMDEBUGSECTIONS If set, limits debug messages to the space-separated list of sections. Sections can optionally have a specific debug level (e.g., CLIENT:2 or CLIENT CUDF:2), but otherwise use --debug-level.

OPAMDIGDEPTH Defines how aggressive the lookup for conflicts during CUDF preprocessing is.

OPAMDOWNLOADJOBS Sets the maximum number of simultaneous downloads.

OPAMDROPWORKINGDIR Overrides packages previously updated with --working-dir on update. Without this variable set, opam would keep them unchanged unless explicitly named on the command-line.

OPAMDRYRUN See option --dry-run.

OPAMEDITOR Sets the editor to use for opam file editing, overrides $EDITOR and $VISUAL.

OPAMERRLOGLEN Sets the number of log lines printed when a sub-process fails. 0 to print all.

OPAMEXTERNALSOLVER See option --solver.

OPAMFAKE See option --fake.

OPAMFETCH Specifies how to download files: either `wget', `curl' or a custom command where variables %{url}%, %{out}%, %{retry}%, %{compress}% and %{checksum}% will be replaced. Overrides the 'download-command' value from the main config file.

OPAMFIXUPCRITERIA Same as OPAMUPGRADECRITERIA, but specific to fixup and reinstall.

OPAMIGNORECONSTRAINTS See install option --ignore-constraints-on.

OPAMIGNOREPINDEPENDS See option --ignore-pin-depends.

OPAMINPLACEBUILD See option --inplace-build.

OPAMJOBS Sets the maximum number of parallel workers to run.

OPAMJSON Logs JSON output to the given file (use character `%' to index the files).

OPAMKEEPBUILDDIR See install option --keep-build-dir.

OPAMKEEPLOGS Tells opam to not remove some temporary command logs and some backups. This skips some finalizers and may also help to get more reliable backtraces.

OPAMLOCKED Combination of --locked and --lock-suffix options.

OPAMLOGS logdir sets the log directory, default is a temporary directory in /tmp

OPAMMAKECMD Sets the system make command to use.

OPAMMERGEOUT Merges process outputs, stderr on stdout.

OPAMNO Answers no to any question asked, see options --no and --confirm-level. OPAMNO is ignored if either OPAMCONFIRMLEVEL or OPAMYES is set.

OPAMNOAGGREGATE With `opam admin check`, don't aggregate packages.

OPAMNOASPCUD Deprecated.

OPAMNOAUTOUPGRADE Disables automatic internal upgrade of repositories in an earlier format to the current one, on 'update' or 'init'.

OPAMNOCHECKSUMS Enables option --no-checksums when available.

OPAMNODEPEXTS Disables system dependencies handling, see option --no-depexts.

OPAMNOENVNOTICE Internal.

OPAMNOSELFUPGRADE See option --no-self-upgrade

OPAMPINKINDAUTO Sets whether version control systems should be detected when pinning to a local path. Enabled by default since 1.3.0.

OPAMPRECISETRACKING Fine-grain tracking of directories.

OPAMPREPRO Set this to false to disable CUDF preprocessing. Less efficient, but might help debugging solver issues.

OPAMREPOSITORYTARRING Internally stores the repositories as tar.gz files. This can be much faster on filesystems that don't cope well with scanning large trees but have good caching in /tmp. However, this is slower in the general case.

OPAMREQUIRECHECKSUMS Enables option --require-checksums when available (e.g., for `opam install`).

OPAMRETRIES Sets the number of tries before failing downloads.

OPAMREUSEBUILDDIR See option --reuse-build-dir.

OPAMROOT See option --root. This is automatically set by `opam env --root=DIR --set-root'.

OPAMROOTISOK Don't complain when running as root.

OPAMSAFE See option --safe.

OPAMSHOW See option --show.

OPAMSKIPUPDATE See option --skip-updates.

OPAMSKIPVERSIONCHECKS Bypasses some version checks. Unsafe, for compatibility testing only.

OPAMSOLVERALLOWSUBOPTIMAL (default `true') Allows some solvers to still return a solution when they reach their timeout; while the solution remains assured to be consistent, there is no guarantee in this case that it fits the expected optimization criteria. If `true', opam will continue with a warning; if `false', a timeout is an error. Currently only the builtin-z3 backend handles this degraded case.

OPAMSOLVERTIMEOUT Changes the time allowance of the solver. Default is 60.0, set to 0 for unlimited. Note that not all solvers may support this option.

OPAMSOLVERTOLERANCE Changes the tolerance towards the solver choosing an unoptimized solution (i.e., might pull outdated packages). Typical values range from 0.0 (best solution known to the solver) to 1.0 (unoptimized solution). Default is 0.0. This option is useful in case the solver can't find a solution in a reasonable time (see $OPAMSOLVERTIMEOUT). Note that not all solvers may support this option.

OPAMSTATS Removed in 2.4.

OPAMSTATUSLINE Displays a dynamic status line showing what's currently going on in the terminal. (One of always, never or auto)

OPAMSTRICT Fails on inconsistencies (file reading, switch import, etc.).

OPAMSWITCH See option --switch. Automatically set by `opam env --switch=SWITCH --set-switch'.

OPAMUNLOCKBASE See install option --unlock-base.

OPAMUPGRADECRITERIA Specifies user *preferences* for dependency solving when performing an upgrade. Overrides OPAMCRITERIA in upgrades if both are set. See also option --criteria.

OPAMUSEINTERNALSOLVER See option --use-internal-solver.

OPAMUSEOPENSSL Removed in 2.2.

OPAMUTF8 Uses UTF8 characters in output (one of always, never or auto). By default `auto', which is determined from the locale).

OPAMUTF8MSGS Uses extended UTF8 characters (camels) in opam messages. Implies OPAMUTF8. This is set by default on macOS only.

OPAMVALIDATIONHOOK If set, uses the `%{hook%}' command to validate an opam repository update.

OPAMVERBOSE See option --verbose.

OPAMVERBOSEON See option --verbose-on

OPAMVERSIONLAGPOWER Do not use.

OPAMWITHDEVSETUP See install option --with-dev-setup.

OPAMWITHDOC See install option --with-doc.

OPAMWITHTEST See install option --with-test.

OPAMWORKINGDIR See option --working-dir.

OPAMYES See options --yes and --confirm-level. OPAMYES has priority over OPAMNO and is ignored if OPAMCONFIRMLEVEL is set.

OPAMVAR_var Overrides the contents of the variable var when substituting `%{var}%` strings in `opam` files.

OPAMVAR_package_var Overrides the contents of the variable package:var when substituting `%{package:var}%` strings in `opam` files.

CLI VERSION

All scripts and programmatic invocations of opam should use `--cli' in order to ensure that they work seamlessly with future versions of the opam client. Additionally, blog posts or other documentation can benefit, as it prevents information from becoming stale.

Although opam only supports roots (~/.opam/) for the current version, it does provide backwards compatibility for its command-line interface.

Since CLI version support was only added in opam 2.1, use OPAMCLI to select 2.0 support (as opam 2.0 will just ignore it), and `--cli=2.1' for 2.1 (or later) versions, since an environment variable controlling the parsing of syntax is brittle. To this end, opam displays a warning if OPAMCLI specifies a valid version other than 2.0, and also if `--cli=2.0' is specified.

The command-line version is selected by using the `--cli' option or the OPAMCLI environment variable. `--cli' may be specified more than once, where the last instance takes precedence. OPAMCLI is only inspected if `--cli' is not given.

EXIT STATUS

As an exception to the following, the `exec' command returns 127 if the command was not found or couldn't be executed, and the command's exit value otherwise.

0
Success, or true for boolean queries.
1
False. Returned when a boolean return value is expected, e.g. when running with --check, or for queries like opam lint.
2
Bad command-line arguments, or command-line arguments pointing to an invalid context (e.g. file not following the expected format).
5
Not found. You requested something (package, version, repository, etc.) that couldn't be found.
10
Aborted. The operation required confirmation, which wasn't given.
15
Could not acquire the locks required for the operation.
20
There is no solution to the user request. This can be caused by asking to install two incompatible packages, for example.

NAME

opam-admin-make(1)

make a new opam repository or update an existing one

SYNOPSIS

opam-admin-make [OPTIONS] [URL] [DIR]

DESCRIPTION

This command creates a new opam repository in DIR (defaulting to the current directory), or updates it if it already exists. If URL is provided, it will be used as the unique remote of the repository.

If the repository already exists, the existing remote will be checked. If it's different from the URL provided, opam will refuse to continue and will ask you to remove the repository first.

If no URL is provided, and the repository exists, the existing remote will be used.

The repository is initialised using opam-admin-tag(1) and it is recommended to use it afterwards to manage the repository's contents.

OPTIONS

--help, -h
Show command help.
--version, -v
Show command version.
--force, -f
Forces the creation of the repository, even if it already exists and the remote is different.
--all-switches
Initialise the repository for all available switches.
--no-check
Skip the checksum check when updating an existing repository.
--strict
Enable strict mode, and fail on non-fatal errors.

COMMON OPTIONS

These options are available on most opam subcommands:

--help, -h
Show command help.
--version, -v
Show command version.
--root DIR
Use OPAMROOT, the main directory of the state, instead of the default (~/.opam).
--data-dir DIR
Use opam data directory DIR instead of the default (<opam root>/state).
--user-conf FILE
Use user configuration FILE instead of the default (~/.opamrc).
--sys-conf FILE
Use system configuration FILE instead of the default (/etc/opam.conf).
--no-sources
Do not read configuration from files.
--quiet, -q
Do not print unnecessary information.
--verbose, -V
Print additional information about the operations.
--debug, -d
Print debugging information.
--log FILE
Log messages to FILE.
--log-level LEVEL
Set the logging LEVEL. Accepted values are: fatal, error, warning, info, debug.
--no-color
Disable coloured output.
--command CMD
Run CMD and exit. This option can be used multiple times.
--jobs N, -j N
Run at most N operations in parallel. Defaults to 1.
--path DIR
Add DIR to the list of directories to search for commands. This option can be used multiple times.
--no-path
Do not search for commands in the directories given by the PATH environment variable.
--wrap-dependencies
When running external commands, opam will wrap them in a shell script that correctly sets up the environment variables, such as OCAMLPATH.
--disable-installation

EXIT STATUS

The exit status is 0 on success, and non-zero otherwise. The following non-zero exit codes are defined:

10
Invalid command line arguments.
11
I/O error. This can be a read/write error, or a file not found.
12
File or directory does not exist.
20
Package definition error. This can be a malformed package definition file, or an invalid field.
21
Cyclic dependency detected.
22
Dependency resolution error. This can be due to missing packages or unspecified versions.
23
Package installation error. This can be due to a failed build or an error during installation.
24
Package removal error. This can be due to a missing package or an error during removal.
25
Switch creation error. This can be due to an existing switch with the same name, or an error during switch creation.
26
Switch removal error. This can be due to a missing switch or an error during switch removal.
27
Switch renaming error. This can be due to a missing switch or an existing switch with the new name.
28
Opamrc error. This can be due to a malformed opamrc file, or an invalid configuration.
29
Opam configuration error. This can be due to missing or invalid configuration files.
30
Error in package definition, or other metadata files. Using --strict raises this error more often.
31
Package script error. Some package operations were unsuccessful. This may be an error in the packages or an incompatibility with your system. This can be a partial error.
40
Sync error. Could not fetch some remotes from the network. This can be a partial error.
50
Configuration error. Opam or system configuration doesn't allow operation, and needs fixing.
60
Solver failure. The solver failed to return a sound answer. It can be due to a broken external solver, or an error in solver configuration.
99
Internal error. Something went wrong, likely due to a bug in opam itself.
130
User interrupt. SIGINT was received, generally due to the user pressing Ctrl-C.
0
on success.
123
on indiscriminate errors reported on standard error.
124
on command line parsing errors.
125
on unexpected internal errors (bugs).
