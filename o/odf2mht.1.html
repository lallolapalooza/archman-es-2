ODF2MHT(1) Comandos de usuario ODF2MHT(1)



NOMBRE
odf2mht - Convertir ODF a archivo HTML



SINOPSIS

odf2mht ruta



DESCRIPCIÓN

Odf2mht es un programa que crea un archivo web encapsulado en MIME (.mht) donde se conservan las imágenes. El archivo puede ser leído por Internet Explorer, MS-Word y muchos programas de correo electrónico como MS-Outlook. Escribirá el archivo web a la salida estándar.

“Ruta” se asume que es un archivo OpenDocument de tipo texto, hoja de cálculo o presentación.



REFERENCIAS

HTTRACK (http://www.httrack.com/) puede crear dichos archivos con la opción -%M.
http://en.wikipedia.org/wiki/MHTML
http://www.dsv.su.se/~jpalme/ietf/mhtml.html
http://users.otenet.gr/~geosp/kmhtconvert/
http://www.faqs.org/rfcs/rfc2557.html



EJEMPLO

odf2mht example.odt >example.mht



ERRORES

IE6 parece tener problemas con archivos MHT grandes.



VER TAMBIÉN

odftools(1), odf2war(1), mailodf(1)
