open(3perl) Guía del programador de Perl open(3perl)

NOMBRE

open - pragma de perl para establecer capas PerlIO por defecto para entrada y salida

SINOPSIS

use open IN  => ':crlf', OUT => ':raw';
open my $in, '<', 'foo.txt' or die "open falló: $!";
my $line = <$in>; # CRLF traducido
close $in;
open my $out, '>', 'bar.txt' or die "open falló: $!";
print $out $line; # sin traducción de bytes
close $out;
use open OUT => ':encoding(UTF-8)';
use open IN  => ':encoding(iso-8859-7)';
use open IO  => ':locale';
# IO implícito sólo para :utf8, :encoding, :locale
use open ':encoding(UTF-8)';
use open ':encoding(iso-8859-7)';
use open ':locale';
# con :std, también afecta a los manejadores estándar globales
use open ':std', ':encoding(UTF-8)';
use open ':std', OUT => ':encoding(cp1252)';
use open ':std', IO => ':raw :encoding(UTF-16LE)';

DESCRIPCIÓN

Se implementa soporte completo para capas de E/S siempre que Perl esté configurado para usar PerlIO como su sistema de E/S (lo cual ha sido el predeterminado desde 5.8, y la única configuración compatible desde 5.16).

El pragma "open" sirve como una de las interfaces para declarar "capas" por defecto (anteriormente conocidas como "disciplinas") para toda la E/S. Cualquier open(), readpipe() (también conocido como qx//) y operadores similares encontrados dentro del alcance léxico de este pragma utilizarán los valores por defecto declarados a través de la variable "${^OPEN}".

Las capas se especifican con un prefijo de dos puntos por convención. Puedes especificar una pila de múltiples capas como una cadena separada por espacios. Consulta PerlIO para obtener más información sobre las capas disponibles.

Con el subpragma "IN" puedes declarar las capas por defecto de los flujos de entrada, y con el subpragma "OUT" puedes declarar las capas por defecto de los flujos de salida. Con el subpragma "IO" (puede omitirse para ":utf8", ":locale" o ":encoding") puedes controlar tanto los flujos de entrada como de salida simultáneamente.

Cuando open() recibe una lista explícita de capas (con la sintaxis de tres argumentos), estas anulan la lista declarada usando este pragma. open() también puede recibir un único dos puntos (:) para un nombre de capa, para anular este pragma y usar el valor por defecto como se detalla en "Valores por defecto y cómo anularlos" en PerlIO.

Para traducir desde y hacia una codificación de texto arbitraria, usa la capa ":encoding". La coincidencia de nombres de codificación en ":encoding" es laxa: no distingue entre mayúsculas y minúsculas, y muchas codificaciones tienen varios alias. Consulta Encode::Supported para obtener detalles y la lista de locales compatibles.

Si quieres establecer tus capas de codificación basándote en las variables de entorno de tu locale, puedes usar la pseudocapa ":locale". Por ejemplo:

$ENV{LANG} = 'ru_RU.KOI8-R';
# el :locale buscará en las variables de entorno del locale como LANG
use open OUT => ':locale';
open(my $out, '>', 'koi8') or die "open falló: $!";
print $out chr(0x430); # LETRA PEQUEÑA CIRÍLICA A = KOI8-R 0xc1
close $out;
open(my $in, '<', 'koi8') or die "open falló: $!";
printf "%#x\n", ord(<$in>); # esto debería imprimir 0xc1
close $in;

La lógica de ":locale" se describe completamente en "El subpragma ":locale"" en encoding, pero en resumen, primero intenta con nl_langinfo(CODESET) y luego adivina a partir de las variables de entorno de locale LC_ALL y LANG. ":locale" también activa implícitamente ":std".

":std" no es una capa sino un subpragma adicional. Cuando se especifica en la lista de importación, activa una funcionalidad adicional de empujar las capas seleccionadas para los manejadores de entrada/salida a los manejadores de archivo estándar (STDIN, STDOUT, STDERR). Si las nuevas capas y la pila de capas existente terminan ambas con una capa ":encoding", la capa ":encoding" existente también se eliminará.

Por ejemplo, si tanto la entrada como la salida se eligen como :encoding(UTF-8), un ":std" significará que STDIN, STDOUT y STDERR también tendrán :encoding(UTF-8) configurado. Por otro lado, si solo la salida se elige en :encoding(koi8r), un ":std" hará que solo STDOUT y STDERR estén en "koi8r".

El efecto de ":std" no es léxico ya que modifica la pila de capas de los manejadores globales. Si deseas aplicar solo este efecto global y no el efecto en los manejadores que se abren en ese ámbito, puedes aislar la llamada a este pragma en su propio ámbito léxico.

{ use open ':std', IO => ':encoding(UTF-8)' }

Antes de Perl 5.34, ":std" solo aplicaba la primera capa proporcionada que fuera ":utf8" o tuviera un argumento de capa, por ejemplo, :encoding(UTF-8). Desde Perl 5.34, aplicará la misma pila de capas que proporciona a "${^OPEN}".

DETALLES DE IMPLEMENTACIÓN

Hay un método de clase en "PerlIO::Layer" "find" que está implementado como código XS. Es llamado por "import" para validar las capas:

PerlIO::Layer::->find("perlio")

El valor de retorno (si está definido) es un objeto Perl, de la clase "PerlIO::Layer" que es creado por el código C en perlio.c. Todavía no hay nada útil que puedas hacer con el objeto a nivel de perl.

VER TAMBIÉN
