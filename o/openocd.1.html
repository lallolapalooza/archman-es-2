OPENOCD(1) Manual de comandos generales OPENOCD(1)

NOMBRE

openocd - Una herramienta gratuita y de código abierto para depuración en chip, programación en sistema y pruebas de boundary-scan para sistemas ARM y MIPS

SINOPSIS

openocd [-fsdlcphv] [--file <nombre_archivo>] [--search <directorio>] [--debug <nivel_depuracion>] [--log_output <nombre_archivo>] [--command <comando>] [--pipe] [--help] [--version]

DESCRIPCIÓN

OpenOCD es una herramienta para depuración en chip, programación en sistema y pruebas de boundary-scan para varios sistemas ARM y MIPS.

El depurador utiliza un maestro de bus JTAG TAP compatible con IEEE 1149-1 para acceder a la funcionalidad de depuración en chip disponible en microcontroladores basados en ARM o soluciones de sistema en chip. Para sistemas MIPS se soporta la interfaz EJTAG.

La interacción del usuario se realiza a través de una interfaz de línea de comandos telnet, un servidor de protocolo remoto gdb (el depurador GNU) y una conexión RPC simplificada que puede usarse para interactuar con el motor Jim Tcl de OpenOCD.

OpenOCD soporta varios tipos diferentes de interfaces/programadores JTAG, por favor, consulte la página de información de openocd para la lista completa.

OPCIONES

-f, --file <nombre_archivo>
Este es un atajo para un comando -c "[script <nombre_archivo>]", utilizando una ruta de búsqueda para cargar el archivo de configuración <nombre_archivo>. Para especificar múltiples archivos de configuración, puede usar múltiples argumentos --file. Si no se incluyen dichas opciones -c, se utilizará el primer archivo de configuración openocd.cfg en la ruta de búsqueda.
-s, --search <directorio>
Añade <directorio> a la ruta de búsqueda utilizada para archivos de configuración y scripts. La ruta de búsqueda comienza con el directorio actual, luego incluye estos directorios adicionales antes de otros componentes como las bibliotecas de scripts estándar de OpenOCD.
-d, --debug <nivel_depuracion>
Establece el nivel de depuración. Los valores posibles son:
* 0 (errores)
* 1 (advertencias)
* 2 (mensajes informativos)
* 3 (mensajes de depuración)
El nivel por defecto es 2.
-l, --log_output <nombre_archivo>
Redirige la salida del registro al archivo <nombre_archivo>. Por defecto, la salida del registro se imprime en stderr.
-c, --command <comando>
Añade el comando <comando> a una lista de comandos ejecutados al inicio del servidor. Tenga en cuenta que necesitará invocar explícitamente init si el comando requiere acceso a un objetivo o memoria flash.
-p, --pipe
Utiliza tuberías (pipes) al comunicarse con gdb.
-h, --help
Muestra un texto de ayuda y sale.
-v, --version
Muestra información de la versión y sale.

ERRORES

Por favor, informe de cualquier error en la lista de correo en openocd-devel@lists.sourceforge.net.
