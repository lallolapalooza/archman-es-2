NOMBRE

ogrtindex - Crea un índice de teselas.

SINOPSIS

--help
Muestra este mensaje de ayuda y sale.
--help-general
Muestra un breve mensaje de uso para las opciones genéricas de línea de comandos de GDAL y sale.
-lnum <n>
Añade la capa número n de cada archivo fuente en el índice de teselas.
-lname <nombre>
Añade la capa llamada nombre de cada archivo fuente en el índice de teselas.
-f <formato_salida>
Selecciona un nombre de formato de salida. Por defecto se crea un shapefile.
-tileindex <nombre_campo>
El nombre a usar para el nombre del dataset. Por defecto es LOCATION.
-write_absolute_path
Los nombres de archivo se escriben con rutas absolutas.
-skip_different_projection
Solo se insertarán las capas con la misma proyección que las capas ya insertadas en el índice de teselas.
-t_srs <srs_objetivo>
La extensión de los archivos de entrada se transformará al sistema de referencia de coordenadas objetivo deseado. Usar esta opción genera archivos que no son compatibles con MapServer < 7.2. Por defecto crea polígonos rectangulares simples en el mismo sistema de referencia de coordenadas que las capas vectoriales de entrada.
-src_srs_name <nombre_campo>
El nombre del campo para almacenar el SRS de cada tesela. Este nombre de campo puede ser usado como el valor de la palabra clave TILESRS en MapServer >= 7.2.
-src_srs_format {AUTO|WKT|EPSG|PROJ}
El formato en el que se debe escribir el SRS de cada tesela. Los formatos disponibles son: AUTO, WKT, EPSG, PROJ.
-accept_different_schemas
Por defecto, ogrtindex comprueba que todas las capas insertadas en el índice tengan los mismos esquemas de atributos. Si se especifica esta opción, esta prueba se deshabilitará. ¡Tenga en cuenta que el índice resultante puede ser incompatible con MapServer!

Si no se proporcionan argumentos -lnum o -lname, se asume que todas las capas de los datasets fuente deben añadirse al índice de teselas como registros independientes.

Si el índice de teselas ya existe, se añadirá a él; de lo contrario, se creará.

EJEMPLOS

Ejemplo 1

Este ejemplo crearía un shapefile (tindex.shp) que contiene un índice de teselas de las capas BL2000_LINK en todos los archivos NTF del directorio wrk:

ogrtindex tindex.shp wrk/*.NTF
