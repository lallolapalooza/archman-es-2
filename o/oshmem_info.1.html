oshmem_info - Muestra información sobre la instalación de OpenSHMEM

SINOPSIS

oshmem_info [opciones]

DESCRIPCIÓN

oshmem_info proporciona información detallada sobre la instalación de OpenSHMEM. Puede ser útil para al menos tres escenarios comunes:

1.
Comprobar la configuración local y ver cómo se instaló OpenSHMEM.
2.
Enviar informes de errores / solicitudes de ayuda a la comunidad de OpenSHMEM (ver Obtener ayuda).
3.
Ver una lista de los plugins de OpenSHMEM instalados y consultar qué parámetros MCA soportan.

NOTA:

oshmem_info muestra por defecto solo unos pocos parámetros MCA (es decir, parámetros de nivel 1). Usa la opción --level para habilitar la visualización de más opciones (ver la sección NIVELES para más información).

OPCIONES

oshmem_info acepta las siguientes opciones:

  • -a, --all: Muestra todas las opciones de configuración y parámetros MCA
  • --arch: Muestra la arquitectura en la que se compiló OpenSHMEM
  • -c, --config: Muestra las opciones de configuración
  • -gmca, --gmca <parametro> <valor>*: Pasa parámetros MCA globales que son aplicables a todos los contextos.
  • -h, --help*: Muestra el mensaje de ayuda / uso
  • --hostname: Muestra el nombre del host en el que se configuró y construyó OpenSHMEM
  • --internal: Muestra parámetros MCA internos (no destinados a ser modificados por los usuarios)
  • --level: Muestra solo variables con un nivel como máximo de este (1-9). El valor por defecto es 1 a menos que se especifique --all sin --level en cuyo caso el valor por defecto es 9. Ver la sección NIVELES para más información.
  • -mca, --mca <parametro> <valor>: Pasa parámetros MCA específicos del contexto; se consideran globales si no se usa --gmca y solo se especifica un contexto.
  • --param <tipo> <componente>: Muestra parámetros MCA. El primer parámetro es el tipo de componente a mostrar; el segundo parámetro es el componente específico a mostrar (o la palabra clave all, que significa "mostrar todos los componentes de este tipo").
  • --parsable: Cuando se usa junto con otros parámetros, la salida se muestra en un formato interpretable por máquinas. --parseable Sinónimo de --parsable.
  • --path <tipo>: Muestra las rutas con las que se configuró OpenSHMEM. Acepta los siguientes parámetros: prefix, bindir, libdir, incdir, pkglibdir, sysconfdir.
  • --pretty: Cuando se usa junto con otros parámetros, la salida se muestra en formato de impresión bonita (por defecto).
  • --selected-only: Muestra solo variables de componentes seleccionados.
  • -V, --version*: Muestra la versión de OpenSHMEM.

NIVELES

1.
Información básica de interés para los usuarios
2.
Información detallada de interés para los usuarios
3.
Toda la información restante de interés para los usuarios
4.
Información básica necesaria para la optimización
5.
Información detallada necesaria para la optimización
6.
Toda la información restante necesaria para la optimización
7.
Información básica para los desarrolladores de OpenSHMEM
8.
Información detallada para los desarrolladores de OpenSHMEM
9.
Toda la información restante para los desarrolladores de OpenSHMEM

EJEMPLOS

shell$ oshmem_info

Muestra la salida por defecto de las opciones y la lista de componentes instalados en formato legible para humanos / impresión bonita.

shell$ oshmem_info --parsable

Muestra la salida por defecto de las opciones y la lista de componentes instalados en formato interpretable por máquinas.

shell$ oshmem_info --param btl openib

Muestra los parámetros MCA del componente BTL "openib" en formato legible para humanos / impresión bonita.

shell$ oshmem_info --param btl openib --parsable

Muestra los parámetros MCA del componente BTL "openib" en formato interpretable por máquinas.

shell$ oshmem_info --path bindir

Muestra el directorio de binarios ("bindir") con el que se configuró OpenSHMEM.

shell$ oshmem_info --version ompi full --parsable

Muestra los números de versión completos de OpenSHMEM (incluyendo los números de versión de ORTE y OPAL) en formato legible por máquinas.

shell$ oshmem_info --version btl major

Muestra el número de versión principal de todos los componentes BTL en formato de impresión bonita.

shell$ oshmem_info --version btl:tcp minor

Muestra el número de versión secundaria del componente BTL TCP en formato de impresión bonita.

shell$ oshmem_info --all

Muestra *toda* la información sobre la instalación de OpenSHMEM, incluyendo todos los componentes que se pueden encontrar, los parámetros MCA que soportan, las versiones de OpenSHMEM y los componentes, etc.
