oath_totp_validate3(3)

oath_totp_validate3(3) liboath oath_totp_validate3(3)

NOMBRE

oath_totp_validate3 - función de API

SINOPSIS

#include <oath.h>

int oath_totp_validate3(const char * secret, size_t secret_length, time_t now, unsigned time_step_size, time_t start_offset, size_t window, int * otp_pos, uint64_t * otp_counter, const char * otp);

ARGUMENTOS

const char * secret
la cadena secreta compartida
size_t secret_length
longitud de secret
time_t now
valor de tiempo Unix para validar el TOTP
unsigned time_step_size
parámetro del sistema de paso de tiempo (típicamente 30)
time_t start_offset
tiempo Unix de cuándo comenzar a contar los pasos de tiempo (típicamente 0)
size_t window
cuántos OTPs después/antes del OTP de inicio probar
int * otp_pos
posición de búsqueda de salida en la ventana de búsqueda (puede ser NULL).
uint64_t * otp_counter
valor del contador utilizado para calcular el valor OTP (puede ser NULL).
const char * otp
el OTP a validar.

DESCRIPCIÓN

Valida un OTP según el algoritmo OATH TOTP según RFC 6238.

Actualmente, solo se admiten OTPs de 6, 7 u 8 dígitos. Estas restricciones pueden eliminarse en versiones futuras, aunque el protocolo inherentemente tiene algunas limitaciones.

DEVUELVE

Devuelve el valor absoluto de la posición en la ventana OTP (cero es la primera posición), o OATH_INVALID_OTP si no se encontró ningún OTP en la ventana OTP, o un código de error.
