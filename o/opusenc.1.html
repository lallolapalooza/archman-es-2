NOMBRE

opusenc - codifica audio en formato Opus

SINOPSIS

opusenc [ -h ] [ -V ] [ --help-picture ] [ --quiet ] [ --bitrate kbit/s ] [ --vbr ] [ --cvbr ] [ --hard-cbr ] [ --music ] [ --speech ] [ --comp complejidad ] [ --framesize 2.5, 5, 10, 20, 40, 60 ] [ --expect-loss porc ] [ --downmix-mono ] [ --downmix-stereo ] [ --no-phase-inv ] [ --max-delay ms ] [ --title 'título de pista' ] [ --artist autor ] [ --album 'título del álbum' ] [ --tracknumber 'número de pista' ] [ --genre género ] [ --date AAAA-MM-DD ] [ --comment etiqueta=valor ] [ --picture nombre_archivo|especificación ] [ --padding n ] [ --discard-comments ] [ --discard-pictures ] [ --raw ] [ --raw-bits bits/muestra ] [ --raw-rate Hz ] [ --raw-chan N ] [ --raw-endianness bandera ] [ --ignorelength ] [ --serial número de serie ] [ --save-range archivo ] [ --set-ctl-int ctl=valor ] archivo_entrada.wav archivo_salida.opus

DESCRIPCIÓN

opusenc lee datos de audio en formato Wave, AIFF, FLAC, Ogg/FLAC o PCM crudo y los codifica en un stream Ogg Opus. Si el archivo de entrada es "-" los datos de audio se leen desde stdin. De igual manera, si el archivo de salida es "-" el stream Ogg Opus se escribe en stdout.

A menos que se silencie, opusenc muestra estadísticas detalladas sobre el progreso de la codificación.

OPCIONES

Opciones generales

-h, --help
Muestra la ayuda del comando
-V, --version
Muestra el número de versión
--help-picture
Muestra ayuda sobre cómo adjuntar carátulas
--quiet
Habilita el modo silencioso. No se muestran mensajes.

Opciones de codificación

--bitrate N.nnn
Establece la tasa de bits objetivo en kbit/s (6-256 por canal)

En modo VBR, esto especifica la tasa promedio para una colección grande y diversa de audio. En modo CVBR y Hard-CBR, especifica la tasa de bits de salida específica.

El valor predeterminado para entradas con una frecuencia de muestreo de 44.1 kHz o superior es de 64 kbit/s por stream mono y 96 kbit/s por par acoplado.

--vbr
Usa codificación de tasa de bits variable (predeterminado)

En modo VBR, la tasa de bits puede subir y bajar libremente dependiendo del contenido para lograr una calidad más consistente.

--cvbr
Usa codificación de tasa de bits variable restringida.

Genera una tasa de bits específica. Este modo es análogo a CBR en codificadores AAC/MP3 y al modo gestionado en codificadores Vorbis. Esto ofrece una calidad menos consistente que el modo VBR pero con una tasa de bits consistente.

--hard-cbr
Usa codificación de tasa de bits constante fija.

Con hard-cbr, cada trama tendrá exactamente el mismo tamaño, similar a cómo funcionan los códecs de voz. Esto ofrece una calidad generalmente inferior, pero es útil donde los cambios de tasa de bits podrían filtrar datos en canales cifrados o en transportes síncronos.

--music
Anula la detección automática y ajusta la codificación de baja tasa de bits para música. Por defecto, la música se detecta automáticamente y la clasificación puede variar con el tiempo.

El ajuste afecta a las tasas de bits bajas que implican compensaciones entre la claridad de la voz y la precisión musical, y no tiene impacto en las tasas de bits típicamente utilizadas para la codificación de música de alta calidad.

--speech
Anula la detección automática y ajusta la codificación de baja tasa de bits para voz. Por defecto, la voz se detecta automáticamente y la clasificación puede variar con el tiempo.

El ajuste afecta a las tasas de bits bajas que implican compensaciones entre la claridad de la voz y la precisión musical, y no tiene impacto en las tasas de bits típicamente utilizadas para la codificación de música de alta calidad.

--comp N
Establece la complejidad computacional de la codificación (0-10, predeterminado: 10). Cero produce las codificaciones más rápidas pero de menor calidad, mientras que 10 produce la mayor calidad pero una codificación más lenta.
--framesize N
Establece el tamaño máximo de trama en milisegundos (2.5, 5, 10, 20, 40, 60, predeterminado: 20)
Los tamaños de trama más pequeños logran menor latencia pero menor calidad a una tasa de bits dada.
Los tamaños mayores a 20ms solo son interesantes a tasas de bits bastante bajas.
--expect-loss N
Establece la pérdida de paquetes esperada en porcentaje (predeterminado: 0)
--downmix-mono
Mezcla hacia mono
--downmix-stereo
Mezcla hacia estéreo (si la entrada tiene >2 canales)
--no-phase-inv
Deshabilita el uso de inversión de fase para estéreo de intensidad. Esto sacrifica algo de calidad estéreo por una mezcla mono de mayor calidad, y es útil al codificar audio estéreo que probablemente se mezclará a mono después de la decodificación.
--max-delay N
Establece el retraso máximo del contenedor en milisegundos (0-1000, predeterminado: 1000)

Opciones de metadatos

--title título
Establece el campo de comentario del título de la pista a título
--artist autor
Establece el campo de comentario del autor a autor. Esto puede usarse múltiples veces para listar autores contribuyentes individualmente. Tenga en cuenta que algunos reproductores de software no muestran varios artistas de forma elegante.
--album álbum
Establece el campo del título del álbum o colección a álbum
--tracknumber N
Establece el campo de comentario del número de pista a N
--date AAAA-MM-DD
Establece el campo de comentario de la fecha a AAAA-MM-DD. Esto puede acortarse a AAAA-MM o AAAA.
--genre género
Establece el campo de comentario del género a género. Esta opción puede especificarse múltiples veces para etiquetar una pista con varios géneros superpuestos.
--comment etiqueta=valor
Agrega un comentario adicional. Esto puede usarse múltiples veces. El argumento debe estar en el formato "etiqueta=valor". Consulte la especificación de vorbis-comment para nombres de etiquetas conocidos: https://www.xiph.org/vorbis/doc/v-comment.html
--picture nombre_archivo|especificación
Adjunta carátulas para la pista.

Se puede usar un nombre_archivo para la obra de arte o una especificación más completa. La imagen se añade a un campo de comentario METADATA_BLOCK_PICTURE similar al utilizado en FLAC. La especificación es una cadena cuyas partes están separadas por caracteres | (barra vertical). Algunas partes pueden dejarse vacías para invocar valores predeterminados. Pasar un nombre de archivo simple es solo una abreviatura de la especificación "||||nombre_archivo".

El formato de especificación es [tipo]|[tipo_media]|[descripción]|[anchoxaltoxprofundidad[/colores]]|nombre_archivo

tipo es un número opcional que describe la naturaleza de la imagen. Los valores definidos provienen de uno de:


0: Otro
1: 'icono de archivo' de 32x32 píxeles (solo PNG)
2: Otro icono de archivo
3: Portada (frontal)
