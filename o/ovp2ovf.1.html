OVP2OVF(1) Manual de Comandos Generales OVP2OVF(1)

NOMBRE

ovp2ovf - convierte un archivo de lista de propiedades virtual en un archivo de fuente virtual y su archivo de métricas de fuente asociado

SINOPSIS

ovp2ovf [OPCIONES] ARCHIVO_OVP[.ovp] [ARCHIVO_OVF[.ovf] [ARCHIVO_OFM[.ofm]]]

DESCRIPCIÓN

ovp2ovf traduce un archivo de lista de propiedades virtual (OVP) legible por humanos, ARCHIVO_OVP, en un archivo de fuente virtual (OVF), ARCHIVO_OVF y su archivo métrico de fuente (OFM) compañero, ARCHIVO_OFM.

El programa también funciona con archivos VP de TeX, produciendo archivos VF y TFM. (ovp2ovf se basa en el código fuente de WEB para vptovf(1).)

OPCIONES

-help
muestra un breve resumen de la sintaxis y las opciones
-verbose
muestra informes de progreso
-version
muestra la información de la versión y sale

ARCHIVOS

ARCHIVO_OFM
Archivo de métricas de fuente Omega (OFM)
ARCHIVO_OVF
Archivo de fuente virtual Omega (OVF)
ARCHIVO_OVP
Archivo de lista de propiedades virtual Omega (OVP)

ERRORES

Envía informes de errores por correo electrónico a https://lists.tug.org/tex-k (lista de correo); es bueno comprobar si el mismo error está presente en vptovf(1).

VER TAMBIÉN

omega(1), ofm2opl(1), ovf2ovp(1), pltotf(1), tftopl(1), vftovp(1), vptovf(1)

AUTOR

Según la documentación de WEB:

VPtoVF es una versión extendida del programa PLtoTF, que forma parte de la biblioteca estándar de TeXware. OVP2OVF es una versión extendida de VPtoVF que permite fuentes mucho más grandes. La idea de una fuente virtual se inspiró en el trabajo de David R. Fuchs, quien diseñó un conjunto similar de convenciones en 1984 mientras desarrollaba un controlador de dispositivo para ArborText, Inc. Escribió un programa algo similar llamado PLFONT.

Los autores principales de Omega fueron John Plaice y Yannis Haralambous. Omega (y Aleph) ahora se mantienen como parte de TeX Live.

Esta página del manual fue escrita por C.M. Connelly para el sistema Debian GNU/Linux. También se mantiene como parte de TeX Live.
