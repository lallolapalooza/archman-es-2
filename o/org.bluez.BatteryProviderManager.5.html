Nombre

org.bluez.BatteryProviderManager - Documentación de la API BatteryProviderManager de BlueZ D-Bus

Descripción

Un proveedor de batería comienza registrándose como proveedor de batería con el método RegisterBatteryProvider() pasando una ruta de objeto como ID del proveedor. Luego, puede empezar a exponer objetos org.bluez.BatteryProvider(5) cuya ruta comience con el ID del proveedor dado. También puede eliminar objetos en cualquier momento. Los objetos y sus propiedades expuestos por los proveedores de batería se reflejarán en la interfaz org.bluez.Battery(5).

bluetoothd(8) dejará de monitorizar estos objetos expuestos y eliminados después de que se llame a UnregisterBatteryProvider para ese ID de proveedor.

Interfaz

Servicio
org.bluez
Interfaz
org.bluez.BatteryProviderManager1
Ruta del objeto
/org/bluez/{hci0,hci1,...}

Métodos

void RegisterBatteryProvider(object provider)

Registra un proveedor de batería. Un proveedor de batería registrado puede entonces exponer objetos con la interfaz org.bluez.BatteryProvider(5).

void UnregisterBatteryProvider(object provider)

Anula el registro de un proveedor de batería registrado previamente con RegisterBatteryProvider(). Después de la anulación del registro, los objetos org.bluez.BatteryProvider(5) proporcionados por este cliente son ignorados por bluetoothd(8).
