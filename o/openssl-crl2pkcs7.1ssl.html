NOMBRE

openssl-crl2pkcs7 - Crear una estructura PKCS#7 a partir de una CRL y certificados

SINOPSIS

openssl crl2pkcs7 [-help] [-inform DER|PEM] [-outform DER|PEM] [-in archivo] [-out archivo] [-certfile archivo] [-nocrl] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq]

DESCRIPCIÓN

Este comando toma una CRL opcional y uno o más certificados y los convierte en una estructura PKCS#7 degenerada de "solo certificados".

OPCIONES

-help
Imprime un mensaje de uso.
-inform DER|PEM
El formato de entrada de la CRL; el valor predeterminado es PEM. Consulte openssl-format-options(1) para más detalles.
-outform DER|PEM
El formato de salida del objeto PKCS#7; el valor predeterminado es PEM. Consulte openssl-format-options(1) para más detalles.
-in archivo
Esto especifica el nombre del archivo de entrada para leer una CRL o la entrada estándar si esta opción no se especifica.
-out archivo
Especifica el nombre del archivo de salida para escribir la estructura PKCS#7 o la salida estándar por defecto.
-certfile archivo
Especifica un nombre de archivo que contiene uno o más certificados en formato PEM. Todos los certificados en el archivo se añadirán a la estructura PKCS#7. Esta opción se puede usar varias veces para leer certificados de varios archivos.
-nocrl
Normalmente se incluye una CRL en el archivo de salida. Con esta opción no se incluye ninguna CRL en el archivo de salida y no se lee ninguna CRL del archivo de entrada.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Consulte "Opciones del Proveedor" en openssl(1), provider(7) y property(7).

EJEMPLOS

Crear una estructura PKCS#7 a partir de un certificado y una CRL:

openssl crl2pkcs7 -in crl.pem -certfile cert.pem -out p7.pem

Crea una estructura PKCS#7 en formato DER sin CRL a partir de varios certificados diferentes:

openssl crl2pkcs7 -nocrl -certfile newcert.pem
       -certfile demoCA/cacert.pem -outform DER -out p7.der

NOTAS

El archivo de salida es una estructura de datos firmada PKCS#7 que contiene ningún firmante y solo certificados y una CRL opcional.

Este comando se puede utilizar para enviar certificados y CAs a Netscape como parte del proceso de inscripción de certificados. Esto implica enviar la salida codificada DER con el tipo MIME application/x-x509-user-cert.

La forma codificada en PEM, con las líneas de encabezado y pie de página eliminadas, se puede utilizar para instalar certificados de usuario y CAs en MSIE utilizando el control Xenroll.
