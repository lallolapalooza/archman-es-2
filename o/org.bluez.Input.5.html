Propiedades

cadena ReconnectMode [solo lectura]

Indica el modo de conectividad del dispositivo HID según se define en la especificación del Perfil HID, Sección 5.4.2.

Este modo se basa en las dos propiedades HIDReconnectInitiate (ver Sección 5.3.4.6) y HIDNormallyConnectable (ver Sección 5.3.4.14) que definen los siguientes cuatro valores posibles:

"none"
No se requiere que el dispositivo y el host restauren la conexión.
"host"
El host HID de Bluetooth restaura la conexión.
"device"
El dispositivo HID de Bluetooth restaura la conexión.
"any"
El dispositivo HID de Bluetooth intentará restaurar la conexión perdida, pero el host HID de Bluetooth también puede restaurar la conexión.
