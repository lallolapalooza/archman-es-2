Paquete: openssl

OSSL_STORE(7ssl) OpenSSL OSSL_STORE(7ssl)

NOMBRE

ossl_store - Funciones de recuperación de almacenamiento

SINOPSIS

#include <openssl/store.h>

DESCRIPCIÓN

General

Un ALMACENAMIENTO es una capa de funcionalidad para recuperar un número de objetos soportados de un repositorio de cualquier tipo, direccionable como un nombre de archivo o como una URI.

La funcionalidad soporta el patrón "abrir un canal al repositorio", "iterar y recuperar un objeto a la vez", y "finalizar cerrando el canal".

Los objetos recuperados se devuelven como un tipo envoltorio OSSL_STORE_INFO, desde el cual se puede recuperar un tipo OpenSSL.

Esquemas URI y cargadores

El soporte para un esquema URI se llama "cargador" de ALMACENAMIENTO, y puede añadirse dinámicamente desde la aplicación que llama o desde un motor cargable.

El soporte para el esquema 'file' está integrado en "libcrypto". Ver ossl_store-file(7) para más información.

UI_METHOD y contraseñas

La API OSS_STORE no hace nada para forzar ningún formato o codificación específico en la contraseña que proporciona el UI_METHOD. Sin embargo, se espera que la contraseña esté codificada en UTF-8. El resultado de cualquier otra codificación no está definido.

EJEMPLOS

Una llamada genérica

#include <openssl/ui.h> /* para UI_get_default_method */
#include <openssl/store.h>
OSSL_STORE_CTX *ctx = OSSL_STORE_open("file:/foo/bar/data.pem",
                       UI_get_default_method(), NULL, NULL, NULL);
/*
 * OSSL_STORE_eof() simula semánticas de archivo para cualquier repositorio para
 * señalar que no se puede esperar más datos
 */
while (!OSSL_STORE_eof(ctx)) {
    OSSL_STORE_INFO *info = OSSL_STORE_load(ctx);
    /*
     * Hacer lo necesario con el OSSL_STORE_INFO,
     * aquí solo un ejemplo
     */
    switch (OSSL_STORE_INFO_get_type(info)) {
    case OSSL_STORE_INFO_CERT:
        /* Imprimir el texto del certificado X.509 */
        X509_print_fp(stdout, OSSL_STORE_INFO_get0_CERT(info));
        /* Imprimir la salida PEM del certificado X.509 */
        PEM_write_X509(stdout, OSSL_STORE_INFO_get0_CERT(info));
        break;
    }
    OSSL_STORE_INFO_free(info);
}
OSSL_STORE_close(ctx);
