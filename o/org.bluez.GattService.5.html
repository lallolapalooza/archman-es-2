Nombre

org.bluez.GattService - Documentación de la API GattService de D-Bus de BlueZ

Descripción

Los servicios locales/servidor y remotos/cliente GATT comparten la misma API de alto nivel de D-Bus.

Local/Servidor se refiere a servicios basados en GATT exportados por un plugin o una aplicación externa.

Remoto/Cliente se refiere a servicios GATT exportados por el par.

Propiedades

cadena UUID [solo-lectura]

UUID del servicio de 128 bits.

booleano Primary [solo-lectura]

Indica si este servicio GATT es primario o no. Si es falso, el servicio es secundario.

objeto Device [solo-lectura, opcional]

Ruta del objeto del dispositivo Bluetooth al que pertenece el servicio. Solo presente en servicios de dispositivos remotos.

array{objeto} Includes [solo-lectura, opcional]

Matriz de rutas de objetos que representan los servicios incluidos de este servicio.

uint16 Handle [solo-lectura] (solo cliente)

Identificador del servicio.

uint16 Handle [lectura-escritura, opcional] (Solo Servidor)

Identificador del servicio. Cuando está disponible en el servidor, intentará utilizarse para asignar en la base de datos, lo que puede fallar; para auto-asignar, se usará el valor 0x0000, lo que provocará que el identificador asignado se establezca una vez registrado.
