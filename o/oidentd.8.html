OIDENTD(8) Manual de usuario de oidentd OIDENTD(8)

NOMBRE

oidentd - demonio Ident flexible y compatible con RFC 1413 con soporte NAT

SINOPSIS

oidentd [OPCIONES]

DESCRIPCIÓN

oidentd implementa el Protocolo de Identificación como se describe en RFC 1413. Por defecto, oidentd responde con el nombre de usuario del propietario de las conexiones. Este comportamiento se puede modificar en oidentd.conf(5) y utilizando las opciones especificadas en este documento.

OPCIONES

-a, --address=DIRECCION

Enlaza a la dirección especificada. Esta opción hace que oidentd escuche las conexiones entrantes solo en la dirección o direcciones especificadas en lugar de en todas las interfaces. Esta opción se puede especificar varias veces para configurar múltiples direcciones.

-c, --charset=JUEGO-DE-CARACTERES

Informa a los clientes que las respuestas Ident utilizan el juego de caracteres especificado, tal como se define en RFC 1340 o sus sucesores. El valor predeterminado es no enviar un juego de caracteres a los clientes.

-C, --config=ARCHIVO

Utiliza el archivo de configuración del sistema especificado. Si no se proporciona esta opción, oidentd utiliza por defecto /usr/local/etc/oidentd.conf. El formato del archivo de configuración del sistema se describe en oidentd.conf(5).

-d, --debug

Muestra mensajes de depuración, incluyendo información detallada de búsqueda que puede ser útil para diagnosticar problemas con búsquedas fallidas. Esta opción solo está disponible si oidentd fue compilado con soporte de depuración.

-e, --error

Oculta los mensajes de error, devolviendo UNKNOWN-ERROR para todos los errores. Esto incluye los errores NO-USER, HIDDEN-USER e INVALID-PORT. Esta opción se puede usar para ocultar el hecho de que oidentd está ocultando respuestas Ident para un usuario.

-f, --forward=[PUERTO]

Reenvía las solicitudes de hosts que se enmascaran a través del servidor en el que se está ejecutando oidentd al host que estableció la conexión correspondiente. El host de destino debe estar ejecutando oidentd con la opción --proxy, o algún servidor Ident que devuelva respuestas estáticas independientemente de la consulta. Si no se especifica ningún puerto, se utiliza el puerto Ident predeterminado (113). Si el reenvío falla, oidentd recurre a la respuesta especificada en oidentd_masq.conf(5). Esta opción implica --masquerade. La opción --masquerade-first se puede usar para reenviar consultas solo si no se especificó ninguna respuesta en oidentd_masq.conf(5).

-g, --group=GRUPO|GID

Ejecuta como el grupo o GID especificado. Si no se proporciona esta opción, oidentd recurre a ejecutarse como "oidentd", "nobody", "nogroup" o GID 65534, en este orden. En sistemas que requieren que oidentd se ejecute como superusuario, se muestra una advertencia y el grupo no se cambia automáticamente.

-h, --help

Imprime un resumen de las opciones y sale.

-i, --foreground

No se bifurca al segundo plano. Esta opción puede ser útil para depurar, o para ejecutar oidentd desde un gestor de servicios como systemd(1) con Type=simple.

-I, --stdio

Lee una única consulta Ident de la entrada estándar, escribe la respuesta en la salida estándar y luego sale. Esta opción puede ser útil para depurar, o cuando se ejecuta oidentd desde un demonio oyente como xinetd(8).

-l, --limit=MAX

Limita el número máximo de conexiones concurrentes al valor especificado. Las conexiones adicionales más allá de este límite se cerrarán inmediatamente sin generar un nuevo proceso. Si no se especifica esta opción, no se aplica ningún límite.

-m, --masquerade

Habilita el soporte para conexiones NAT, permitiendo búsquedas Ident destinadas a hosts que se enmascaran a través del servidor que ejecuta oidentd. Las respuestas Ident para conexiones NAT se pueden configurar en el archivo de configuración oidentd_masq.conf(5).

-M, --masquerade-first

Si existe una entrada que coincide con el host de destino en el archivo de configuración oidentd_masq.conf(5), devuelve la respuesta Ident configurada en lugar de reenviar la consulta. Con esta opción, las consultas se reenvían solo si no se ha configurado ninguna respuesta estática. Si no se especifica esta opción, el comportamiento predeterminado de --forward es reenviar las consultas antes de verificar el archivo oidentd_masq.conf(5). Esta opción implica --forward y --masquerade.

-o, --other=[SO]

Establece una cadena alternativa de sistema operativo para enviar junto con las respuestas Ident. Tenga en cuenta que algunos clientes pueden interpretar las consultas como fallidas cuando se devuelve un sistema operativo desconocido. Si no se especifica esta opción, se utiliza el valor UNIX. Si esta opción se especifica sin un argumento, se devuelve OTHER.

-p, --port=PUERTO

Escucha en el puerto especificado en lugar del puerto 113.

-P, --proxy=ORIGEN

Permite que el host especificado reenvíe consultas a esta instancia utilizando la opción --forward. Si no se especifica --reply, esta opción debe estar habilitada para que oidentd maneje correctamente las conexiones reenviadas.

-q, --quiet

Suprime el registro normal, mostrando solo mensajes críticos.

-r, --reply=RESPUESTA

Cuando una búsqueda falla, envía la respuesta Ident especificada como si hubiera tenido éxito.

-R, --reply-all=RESPUESTA

Envía la respuesta especificada en respuesta a todas las consultas bien formadas. Cuando se utiliza esta opción, los archivos de configuración no se leen y nunca se realizan búsquedas de conexiones. La inicialización privilegiada no se realiza en sistemas que de otro modo la requerirían, por lo que los usuarios no privilegiados pueden ejecutar oidentd con esta opción siempre que tengan permiso para enlazar el puerto solicitado.

-S, --nosyslog

Registra mensajes en el flujo de error estándar, incluso si no es una terminal. Si el error estándar es una terminal, los mensajes se escriben en él por defecto.

-t, --timeout=SEGUNDOS

Cierra las conexiones si no se recibe ninguna consulta Ident dentro del número especificado de segundos. Por defecto, las conexiones se cierran después de 30 segundos.

-u, --user=USUARIO|UID

Ejecuta como el usuario o UID especificado. Si no se proporciona esta opción, oidentd recurre a ejecutarse como "oidentd", "nobody" o UID 65534, en este orden. En sistemas que requieren que oidentd se ejecute como superusuario, se muestra una advertencia y el usuario no se cambia automáticamente.

-v, --version

Imprime la información de versión y compilación y sale.

ARCHIVOS

/usr/local/etc/oidentd.conf

Archivo de configuración del sistema; consulte oidentd.conf(5).

~/.config/oidentd.conf, ~/.oidentd.conf

Archivos de configuración del usuario; consulte oidentd.conf(5).

/usr/local/etc/oidentd_masq.conf

Archivo de configuración de enmascaramiento; consulte oidentd_masq.conf(5).
