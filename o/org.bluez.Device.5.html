Métodos

void Connect()

Conecta todos los perfiles que el dispositivo remoto soporta y que pueden ser conectados y han sido marcados como conectables automáticamente. Si solo un subconjunto de perfiles ya está conectado, intentará conectar los que actualmente no están conectados.

Si al menos un perfil se conectó exitosamente, este método indicará éxito.

Para dispositivos de doble modo, solo se conecta un portador a la vez, las condiciones son en el siguiente orden:

1.
Conecta el portador desconectado si ya está conectado.
2.
Conecta primero el portador emparejado. Si no hay portadores emparejados o ambos son omitidos, comprueba el portador visto más recientemente.
3.
Conecta el último portador utilizado; en caso de que las marcas de tiempo sean las mismas, BR/EDR tiene precedencia, o en caso de que PreferredBearer se haya establecido a un portador específico, se utilizará ese en su lugar.

Posibles errores:

org.bluez.Error.NotReady
org.bluez.Error.Failed
org.bluez.Error.InProgress
org.bluez.Error.AlreadyConnected
org.bluez.Error.BREDR.ProfileUnavailable

void Disconnect()

Desconecta todos los perfiles conectados y luego termina la conexión ACL de bajo nivel.

La conexión ACL se terminará incluso si algunos perfiles no se desconectaron correctamente (por ejemplo, debido a un dispositivo que no responde).

Este método también se puede utilizar para cancelar una llamada Connect anterior antes de que se reciba una respuesta a ella.

Para dispositivos no confiables conectados a través de un portador LE, llamar a este método deshabilitará las conexiones entrantes hasta que se vuelva a llamar al método Connect.

Posibles errores:

org.bluez.Error.NotConnected

void ConnectProfile(string uuid)

Conecta un perfil específico de este dispositivo. El UUID proporcionado es el UUID del servicio remoto para el perfil.

Posibles errores:

org.bluez.Error.Failed
org.bluez.Error.InProgress
org.bluez.Error.InvalidArguments
org.bluez.Error.NotAvailable
org.bluez.Error.NotReady

void DisconnectProfile(string uuid)

Desconecta un perfil específico de este dispositivo. El perfil debe ser un perfil de cliente registrado.

No hay seguimiento de conexión para un perfil, por lo que mientras el perfil esté registrado, esto siempre tendrá éxito.

Posibles errores:

org.bluez.Error.Failed
org.bluez.Error.InProgress
org.bluez.Error.InvalidArguments
org.bluez.Error.NotSupported

void Pair()

Conecta con el dispositivo remoto e inicia el procedimiento de emparejamiento, luego procede con el descubrimiento de servicios.

Si la aplicación ha registrado su propio agente, se utilizará ese agente específico. De lo contrario, utilizará el agente predeterminado.

Solo para aplicaciones como un asistente de emparejamiento tendría sentido tener su propio agente. En casi todos los demás casos, el agente predeterminado manejará esto perfectamente.

En caso de que no haya un agente de aplicación ni un agente predeterminado presente, este método fallará.

Posibles errores:

org.bluez.Error.InvalidArguments
org.bluez.Error.Failed
org.bluez.Error.AlreadyExists
org.bluez.Error.AuthenticationCanceled
org.bluez.Error.AuthenticationFailed
org.bluez.Error.AuthenticationRejected
org.bluez.Error.AuthenticationTimeout
org.bluez.Error.ConnectionAttemptFailed

void CancelPairing()

Cancela una operación de emparejamiento iniciada por el método Pair.

Posibles errores:

org.bluez.Error.DoesNotExist
org.bluez.Error.Failed

array{array{byte}} GetServiceRecords() [experimental]

Devuelve todos los registros de servicios BR/EDR conocidos actualmente para el dispositivo. Cada arreglo de bytes individual representa un registro SDP bruto, tal como se define en la especificación del Protocolo de Descubrimiento de Servicios de Bluetooth.

Este método está destinado únicamente a ser utilizado por capas de compatibilidad como Wine, que necesitan proporcionar acceso a registros SDP brutos para admitir APIs de Bluetooth externas.

Las aplicaciones generales deberían usar en su lugar la API de Perfiles para la funcionalidad relacionada con servicios.

Posibles errores:

org.bluez.Error.Failed

Señales

void Disconnected(string razón, string mensaje)

Esta señal se emite cuando un dispositivo se desconecta, con la razón de la desconexión.

La aplicación cliente podría utilizar esto, dependiendo de la política interna, para intentar reconectarse al dispositivo en caso de tiempo de espera agotado o desconexión desconocida, o para intentar conectarse a otro dispositivo.

Razones posibles:

org.bluez.Reason.Unknown
org.bluez.Reason.Timeout
Tiempo de espera de conexión agotado.

Ha expirado el tiempo de espera de supervisión del enlace para una conexión o el tiempo de espera de sincronización para una transmisión.

org.bluez.Reason.Local
Conexión terminada por el host local.

El dispositivo local terminó la conexión, terminó la sincronización con un transmisor o dejó de transmitir paquetes.

org.bluez.Reason.Remote
Conexión terminada por el host remoto.

Esta desconexión puede deberse a:

  • el usuario en el dispositivo remoto terminó la conexión o dejó de transmitir paquetes,
  • el dispositivo remoto terminó la conexión debido a bajos recursos,
  • el dispositivo remoto terminó la conexión porque el dispositivo está a punto de apagarse.
org.bluez.Reason.Authentication
Conexión terminada debido a una falla de autenticación.
org.bluez.Reason.Suspend
Conexión terminada por el host local para suspensión.

Propiedades

string Address [solo lectura]

La dirección del dispositivo Bluetooth del dispositivo remoto.

string AddressType [solo lectura]

El Tipo de Dirección del dispositivo Bluetooth. Para dispositivos de doble modo y solo BR/EDR, esto se establece por defecto en "public". Los dispositivos LE de modo único pueden tener cualquiera de los dos valores.

Si el dispositivo remoto utiliza privacidad, antes del emparejamiento esto representa el tipo de dirección utilizado para la conexión y la Dirección de Identidad después del emparejamiento.

Valores posibles:

"public"
Dirección pública
"random"
Dirección aleatoria

string Name [solo lectura, opcional]

El nombre remoto de Bluetooth.

Este valor solo está presente por completo. Es mejor usar siempre la propiedad Alias al mostrar el nombre de los dispositivos.

Si la propiedad Alias no está establecida, reflejará este valor, lo que lo hace más conveniente.

string Icon [solo lectura, opcional]

Nombre del icono propuesto según la especificación de nombres de iconos de freedesktop.org.

uint32 Class [solo lectura, opcional]

La clase de dispositivo Bluetooth del dispositivo remoto.

uint16 Appearance [solo lectura, opcional]

Apariencia externa del dispositivo, tal como se encuentra en el servicio GAP.

array{string} UUIDs [solo lectura, opcional]

Lista de UUIDs de 128 bits que representan los servicios remotos disponibles.

boolean Paired [solo lectura]

Indica si el dispositivo remoto está emparejado. Emparejado significa que el proceso de emparejamiento donde los dispositivos intercambian información para establecer una conexión cifrada se ha completado.

boolean Bonded [solo lectura]

Indica si el dispositivo remoto está vinculado. Vinculado significa que la información intercambiada en el proceso de emparejamiento se ha almacenado y se conservará.

boolean Connected [solo lectura]

Indica si el dispositivo remoto está conectado actualmente.

Una señal PropertiesChanged indica cambios en este estado.

boolean Trusted [lectura/escritura]

Indica si el dispositivo remoto se considera confiable.

Esta configuración puede ser modificada por la aplicación.

boolean Blocked [lectura/escritura]

Si se establece en true, se rechazarán inmediatamente todas las conexiones entrantes del dispositivo.

Todos los controladores de dispositivos también se eliminarán y no se explorarán nuevos mientras el dispositivo esté bloqueado.

boolean WakeAllowed [lectura/escritura]

Si se establece en true, se permitirá que este dispositivo active el host desde la suspensión del sistema.

string Alias [lectura/escritura]

El alias de nombre para el dispositivo remoto. El alias se puede usar para tener un nombre diferente y amigable para el dispositivo remoto.

En caso de que no se establezca ningún alias, reflejará el nombre del dispositivo remoto. Establecer una cadena vacía como alias lo revertirá al nombre del dispositivo remoto.

Al restablecer el alias con una cadena vacía, la propiedad volverá por defecto al nombre remoto.

object Adapter [solo lectura]

La ruta del objeto del adaptador al que pertenece el dispositivo.

boolean LegacyPairing [solo lectura]

Establecido en true si el dispositivo solo admite el mecanismo de emparejamiento anterior a la versión 2.1.

Esta propiedad es útil durante el descubrimiento de dispositivos para anticipar si se producirá un emparejamiento heredado o simple si se inicia el emparejamiento.

Tenga en cuenta que esta propiedad puede presentar falsos positivos en el caso de dispositivos Bluetooth 2.1 (o más nuevos) que han deshabilitado el soporte de respuesta extendida de consulta.

boolean CablePairing [solo lectura]

Establecido en true si el dispositivo se emparejó por cable y no admite el enlace canónico con cifrado, por ejemplo, el gamepad Sixaxis.

Si es true, BlueZ establecerá una conexión sin forzar el cifrado.

string Modalias [solo lectura, opcional]

Información del ID del dispositivo remoto en formato modalias utilizado por el kernel y udev.

int16 RSSI [solo lectura, opcional]

Indicador de intensidad de señal recibida del dispositivo remoto (consulta o publicidad).

int16 TxPower [solo lectura, opcional]

Nivel de potencia de transmisión anunciado (consulta o publicidad).

dict ManufacturerData [solo lectura, opcional]

Datos de publicidad específicos del fabricante. Las claves son el ID del fabricante de 16 bits seguido de su valor de matriz de bytes.

dict ServiceData [solo lectura, opcional]

Datos de publicidad de servicio. Las claves son los UUID en formato de cadena seguidos de su valor de matriz de bytes.

bool ServicesResolved [solo lectura]

Indica si la resolución de servicios se ha completado o no.

array{byte} AdvertisingFlags [solo lectura]

Las banderas de datos de publicidad del dispositivo remoto.

Name

org.bluez.Device

Interface

The Device interface exposes information about a remote Bluetooth device.

dict AdvertisingData [readonly]

The Advertising Data of the remote device. Keys are 1 byte AD Type followed by data as byte array.

Note: Only types considered safe to be handled by application are exposed.

Possible values:

<type>
<byte array>

Example:

<Transport Discovery> <Organization Flags...> 0x26 0x01 0x01...

array{object, dict} Sets [readonly, experimental]

The object paths of the sets the device belongs to followed by a dictionary which can contain the following:

byte Rank
Rank of the device in the Set.

string PreferredBearer [readwrite, optional, experimental]

Indicate the preferred bearer when initiating a connection, only available for dual-mode devices.

When changing from "bredr" to "le" the device will be removed from the 'auto-connect' list so it won't automatically be connected when advertising.

Note: Changes only take effect when the device is disconnected.

Possible values:

"last-used"
Connect to last used bearer first. Default.
"bredr"
Connect to BR/EDR first.
"le"
Connect to LE first.
"last-seen"
Connect to last seen bearer first.
