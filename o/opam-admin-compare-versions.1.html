OPAM ADMIN-COMPARE-VERSIONS(1) Manual de administración de Opam OPAM ADMIN-COMPARE-VERSIONS(1)

NOMBRE

opam admin compare-versions - Compara dos versiones de paquete

SINOPSIS

opam admin compare-versions [OPCIÓN]… V0 V1

DESCRIPCIÓN

Este comando compara 2 versiones de paquetes. Por defecto, imprime 'V0 OP V1' en la consola, donde OP está en {<,>,=} tal que la ecuación se cumpla. Cuando se proporciona un operador, la salida se suprime y el resultado de la comparación se verifica contra el operador proporcionado: el comando sale con 0 si la comparación se cumple y con 1 en caso contrario. Por ejemplo:

$ opam admin compare-versions 0.0.9 0.0.10
0.0.9 < 0.0.10
$ opam admin compare-versions 0.0.9 --lt 0.0.10
[0]
$ opam admin compare-versions 0.0.9 --eq 0.0.10
[1]

ARGUMENTOS

V0 (requerido)
Versión del paquete a comparar
V1 (requerido)
Versión del paquete a comparar

OPCIONES

--eq
asegura V0 = V1
--geq
asegura V0 >= V1
--gt
asegura V0 > V1
--leq
asegura V0 <= V1
--lt
asegura V0 < V1
--neq
asegura V0 != V1

OPCIONES COMUNES

Estas opciones son comunes a todos los comandos.

--help[=FMT] (predeterminado=auto)
Muestra esta ayuda en el formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la variable de entorno TERM sea dumb o no esté definida.
--version
Muestra información de la versión.

ENVIRONMENT

Las variables de entorno que se describen a continuación pueden ser utilizadas para personalizar el comportamiento de opam. Algunas de estas variables pueden ser establecidas por el script de inicio de opam (por ejemplo, al ejecutar `opam init').

OPAM_COLOR ver opción `--color'.

OPAM_DEBUG_LOG si se establece, opam registrará toda la información de depuración en el archivo especificado en lugar de enviarla a stderr.

OPAM_ERROR_COLORS ver opción `--error-colors'.

OPAM_KEEP_TEMP_FILES si se establece, opam conservará los archivos temporales después de la ejecución.

OPAM_LOCK_TIMEOUT establece el tiempo de espera en segundos para adquirir bloqueos de opam. El valor predeterminado es 10.

OPAM_LOG_DIR establece el directorio donde se guardarán los registros de compilación. El valor predeterminado es `~/.opam/log'.

OPAM_OPTIONS una lista separada por comas de las opciones a aplicar a todos los comandos de opam. Esto es útil para establecer opciones globales que se apliquen a todos los invocaciones de opam. Por ejemplo, `OPAM_OPTIONS=--debug=true' habilitará el modo de depuración para todas las invocaciones de opam.

OPAM_ROOT especifica la raíz del directorio de opam. El valor predeterminado es `~/.opam'.

OPAM_SHORTCUT_DIRS es una lista de directorios separados por dos puntos que se añadirán al PATH para las compilaciones y para la ejecución de comandos de paquetes.

OPAM_SLOWDOWN simula un aumento de la latencia de red y de la velocidad del disco, añadiendo un retraso aleatorio en cada operación de I/O. Útil para probar el comportamiento de opam en condiciones de red deficientes.

OPAM_SWITCH_PREFIX ver opción `--switch-prefix'.

OPAM_SWITCH_VERSION ver opción `--switch-version'.

OPAM_TARGET ver opción `--target'.

OPAM_USE_SYSTEM_TOOLS si se establece, opam intentará usar herramientas del sistema en lugar de las proporcionadas por el entorno de opam. Esto puede ser útil para depurar problemas relacionados con las herramientas de opam.

OPAM_USE_TLS ver opción `--tls'.

OPAM_VERSION controla la versión del CLI de opam a usar. Útil para pruebas de compatibilidad y para usar versiones antiguas de opam con una nueva instalación.

OPAM_WARNING_ON_DEPRECATED_API ver opción `--warning-on-deprecated-api'.

OPAM_WARN_ON_INVALID_LOCK si se establece, opam emitirá una advertencia si el archivo de bloqueo contiene entradas inválidas. Por predeterminado, esta comprobación se realiza en modo silencioso. Si se establece a `false', una advertencia se considera un error. Actualmente, solo el backend incorporado z3 maneja este caso degradado.

OPAMSOLVERTIMEOUT cambia el tiempo de asignación del solucionador. El valor predeterminado es 60.0, establecido a 0 para ilimitado. Tenga en cuenta que no todos los solucionadores pueden admitir esta opción.

OPAMSOLVERTOLERANCE cambia la tolerancia hacia el solucionador que elige una solución no optimizada (es decir, podría descargar paquetes obsoletos). Los valores típicos van desde 0.0 (la mejor solución conocida por el solucionador) hasta 1.0 (solución no optimizada). El valor predeterminado es 0.0. Esta opción es útil en caso de que el solucionador no pueda encontrar una solución en un tiempo razonable (ver $OPAMSOLVERTIMEOUT). Tenga en cuenta que no todos los solucionadores pueden admitir esta opción.

OPAMSTATS Eliminado en 2.4.

OPAMSTATUSLINE muestra una línea de estado dinámica que indica lo que está sucediendo actualmente en la terminal. (uno de always, never o auto)

OPAMSTRICT falla ante inconsistencias (lectura de archivos, importación de switch, etc.).

OPAMSWITCH ver opción `--switch'. Establecido automáticamente por `opam env --switch=SWITCH --set-switch'.

OPAMUNLOCKBASE ver opción de instalación `--unlock-base'.

OPAMUPGRADECRITERIA especifica las *preferencias* del usuario para la resolución de dependencias al realizar una actualización. Anula OPAMCRITERIA en las actualizaciones si ambas están establecidas. Ver también la opción --criteria.

OPAMUSEINTERNALSOLVER ver opción `--use-internal-solver'.

OPAMUSEOPENSSL Eliminado en 2.2.

OPAMUTF8 utiliza caracteres UTF8 en la salida (uno de always, never o auto). Por defecto `auto', que se determina a partir de la configuración regional).

OPAMUTF8MSGS utiliza caracteres UTF8 extendidos (camellos) en los mensajes de opam. Implica OPAMUTF8. Esto está establecido por defecto solo en macOS.

OPAMVALIDATIONHOOK si está establecido, utiliza el comando `%{hook%}' para validar una actualización del repositorio de opam.

OPAMVERBOSE ver opción `--verbose'.

OPAMVERBOSEON ver opción --verbose-on

OPAMVERSIONLAGPOWER no usar.

OPAMWITHDEVSETUP ver opción de instalación `--with-dev-setup'.

OPAMWITHDOC ver opción de instalación `--with-doc'.

OPAMWITHTEST ver opción de instalación `--with-test.

OPAMWORKINGDIR ver opción `--working-dir'.

OPAMYES ver opciones `--yes' y `--confirm-level'. OPAMYES tiene prioridad sobre OPAMNO y se ignora si OPAMCONFIRMLEVEL está establecido.

OPAMVAR_var anula el contenido de la variable var al sustituir las cadenas `%{var}%' en los archivos `opam'.

CLI VERSION

Todos los scripts e invocaciones programáticas de opam deben usar `--cli' para garantizar que funcionen sin problemas con futuras versiones del cliente opam. Además, las publicaciones de blog u otra documentación pueden beneficiarse, ya que evita que la información quede obsoleta.

Aunque opam solo admite raíces (~/.opam/) para la versión actual, proporciona retrocompatibilidad para su interfaz de línea de comandos.

Dado que la compatibilidad con la versión CLI solo se añadió en opam 2.1, use OPAMCLI para seleccionar la compatibilidad con 2.0 (ya que opam 2.0 simplemente la ignorará) y `--cli=2.1' para versiones 2.1 (o posteriores), ya que una variable de entorno que controla el análisis de la sintaxis es frágil. Para ello, opam muestra una advertencia si OPAMCLI especifica una versión válida distinta de 2.0, y también si se especifica `--cli=2.0'.

La versión de la línea de comandos se selecciona utilizando la opción `--cli' o la variable de entorno OPAMCLI. `--cli' puede especificarse más de una vez, donde la última instancia tiene prioridad. OPAMCLI solo se inspecciona si no se proporciona `--cli'.

EXIT STATUS

Como excepción a lo siguiente, el comando `exec' devuelve 127 si el comando no se encontró o no se pudo ejecutar, y el valor de salida del comando en caso contrario.

0
Éxito, o verdadero para consultas booleanas.
1
Falso. Devuelto cuando se espera un valor booleano, por ejemplo, al ejecutar con --check, o para consultas como opam lint.
2
Argumentos de línea de comandos incorrectos, o argumentos de línea de comandos que apuntan a un contexto inválido (por ejemplo, archivo que no sigue el formato esperado).
5
No encontrado. Solicitó algo (paquete, versión, repositorio, etc.) que no se pudo encontrar.
10
Abortado. La operación requirió confirmación, la cual no se dio.
15
No se pudieron adquirir los bloqueos necesarios para la operación.
20
No hay solución a la solicitud del usuario. Esto puede ser causado por solicitar la instalación de dos paquetes incompatibles, por ejemplo.
30
Error en la definición del paquete, u otros archivos de metadatos. El uso de --strict genera este error con más frecuencia.
31
Error de script del paquete. Algunas operaciones del paquete no fueron exitosas. Esto puede ser un error en los paquetes o una incompatibilidad con su sistema. Esto puede ser un error parcial.
40
Error de sincronización. No se pudieron obtener algunos remotos de la red. Esto puede ser un error parcial.
50
Error de configuración. La configuración de opam o del sistema no permite la operación y necesita ser corregida.
60
Fallo del solucionador. El solucionador no pudo devolver una respuesta sólida. Puede deberse a un solucionador externo dañado o a un error en la configuración del solucionador.
99
Error interno. Algo salió mal, probablemente debido a un error en el propio opam.
130
Interrupción del usuario. Se recibió SIGINT, generalmente debido a que el usuario presionó Ctrl-C.
0
en caso de éxito.
123
en errores indiscriminados reportados en la salida estándar de error.
124
en errores de análisis de línea de comandos.
125
en errores internos inesperados (bugs).
