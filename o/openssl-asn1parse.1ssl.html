NOMBRE

openssl-asn1parse - comando de análisis de ASN.1

SINOPSIS

openssl asn1parse [-help] [-inform DER|PEM|B64] [-in nombre_archivo] [-out nombre_archivo] [-noout] [-offset número] [-length número] [-i] [-oid nombre_archivo] [-dump] [-dlimit num] [-strparse offset] [-genstr cadena] [-genconf archivo] [-strictpem] [-item nombre]

DESCRIPCIÓN

Este comando es una utilidad de diagnóstico que puede analizar estructuras ASN.1. También se puede utilizar para extraer datos de datos con formato ASN.1.

OPCIONES

-help
Imprime un mensaje de uso.
-inform DER|PEM|B64
El formato de entrada; el valor predeterminado es PEM. Consulte openssl-format-options(1) para obtener más detalles.
-in nombre_archivo
El archivo de entrada, el valor predeterminado es la entrada estándar.
-out nombre_archivo
Archivo de salida donde colocar los datos codificados en DER. Si esta opción no está presente, no se generarán datos. Esto es más útil cuando se combina con la opción -strparse.
-noout
No mostrar la versión analizada del archivo de entrada.
-offset número
Desplazamiento inicial para comenzar el análisis, el valor predeterminado es el inicio del archivo.
-length número
Número de bytes a analizar, el valor predeterminado es hasta el final del archivo.
-i
Indenta la salida según la "profundidad" de las estructuras.
-oid nombre_archivo
Un archivo que contiene Identificadores de Objeto (OIDs) adicionales. El formato de este archivo se describe en la sección NOTAS a continuación.
-dump
Volcar datos desconocidos en formato hexadecimal.
-dlimit num
Similar a -dump, pero solo se muestran los primeros num bytes.
-strparse offset
Analiza los octetos de contenido del objeto ASN.1 comenzando en el offset. Esta opción se puede usar varias veces para "profundizar" en una estructura anidada.
-genstr cadena, -genconf archivo
Genera datos codificados basados en cadena, archivo o ambos utilizando el formato de ASN1_generate_nconf(3). Si solo está presente archivo, la cadena se obtiene de la sección predeterminada utilizando el nombre asn1. Los datos codificados se pasan a través del analizador ASN1 y se imprimen como si provinieran de un archivo, por lo que el contenido puede examinarse y escribirse en un archivo utilizando la opción -out.
-strictpem
Si se utiliza esta opción, se ignorará -inform. Sin esta opción, cualquier dato en un archivo de entrada en formato PEM se tratará como codificado en base64 y se procesará, independientemente de si tiene los marcadores BEGIN y END normales de PEM o no. Esta opción ignorará cualquier dato anterior al inicio del marcador BEGIN, o después de un marcador END en un archivo PEM.
-item nombre
Intenta decodificar e imprimir los datos como un ASN1_ITEM nombre. Esto se puede usar para imprimir los campos de cualquier estructura ASN.1 admitida si el tipo es conocido.

Salida

La salida contendrá típicamente líneas como esta:

0:d=0  hl=4 l= 681 cons: SEQUENCE

.....

229:d=3  hl=3 l= 141 prim: BIT STRING
373:d=2  hl=3 l= 162 cons: cont [ 3 ]
376:d=3  hl=3 l= 159 cons: SEQUENCE
379:d=4  hl=2 l=  29 cons: SEQUENCE
381:d=5  hl=2 l=   3 prim: OBJECT            :X509v3 Subject Key Identifier
386:d=5  hl=2 l=  22 prim: OCTET STRING
410:d=4  hl=2 l= 112 cons: SEQUENCE
412:d=5  hl=2 l=   3 prim: OBJECT            :X509v3 Authority Key Identifier
417:d=5  hl=2 l= 105 prim: OCTET STRING
524:d=4  hl=2 l=  12 cons: SEQUENCE

.....

Este ejemplo es parte de un certificado autofirmado. Cada línea comienza con el desplazamiento en decimal. "d=XX" especifica la profundidad actual. La profundidad aumenta dentro del alcance de cualquier SET o SEQUENCE. "hl=XX" indica la longitud de la cabecera (octetos de etiqueta y longitud) del tipo actual. "l=XX" indica la longitud de los octetos de contenido.

La opción -i se puede utilizar para hacer la salida más legible.

Se necesita cierto conocimiento de la estructura ASN.1 para interpretar la salida.

En este ejemplo, el BIT STRING en el desplazamiento 229 es la clave pública del certificado. Los octetos de contenido de este contendrán la información de la clave pública. Esto se puede examinar usando la opción "-strparse 229" para obtener:

  0:d=0  hl=3 l= 137 cons: SEQUENCE
  3:d=1  hl=3 l= 129 prim: INTEGER           :E5D21E1F5C8D208EA7A2166C7FAF9F6BDF2059669C60876DDB70840F1A5AAFA59699FE471F379F1DD6A487E7D5409AB6A88D4A9746E24B91D8CF55DB3521015460C8EDE44EE8A4189F7A7BE77D6CD3A9AF2696F486855CF58BF0EDF2B4068058C7A947F52548DDF7E15E96B385F86422BEA9064A3EE9E1158A56E4A6F47E5897
135:d=1  hl=2 l=   3 prim: INTEGER           :010001

NOTAS

Si un OID no forma parte de la tabla interna de OpenSSL, se representará en forma numérica (por ejemplo, 1.2.3.4). El archivo que se pasa a la opción -oid permite incluir OIDs adicionales. Cada línea consta de tres columnas, la primera columna es el OID en formato numérico y debe ir seguida de espacios en blanco. La segunda columna es el "nombre corto" que es una sola palabra seguida de espacios en blanco. La columna final es el resto de la línea y es el "nombre largo". Ejemplo:

"1.2.3.4 nombreCorto Un nombre largo"

Para cualquier OID con un nombre corto y largo asociado, este comando mostrará el nombre largo.

EJEMPLOS

Analizar un archivo:

openssl asn1parse -in archivo.pem

Analizar un archivo DER:

openssl asn1parse -inform DER -in archivo.der

Generar una simple UTF8String:

openssl asn1parse -genstr 'UTF8:Hola Mundo'

Generar y escribir una UTF8String, no mostrar la salida analizada:

openssl asn1parse -genstr 'UTF8:Hola Mundo' -noout -out utf8.der

Generar usando un archivo de configuración:

openssl asn1parse -genconf asn1.cnf -noout -out asn1.der

Archivo de configuración de ejemplo:

asn1=SEQUENCE:seq_sect
[seq_sect]
field1=BOOL:TRUE
field2=EXP:0, UTF8:alguna cadena aleatoria

ERRORES

Debería haber opciones para cambiar el formato de las líneas de salida. La salida de algunos tipos ASN.1 no se maneja bien (si es que se maneja).
