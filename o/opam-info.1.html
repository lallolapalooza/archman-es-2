OPAM-INFO(1) Manual de Opam OPAM-INFO(1)

NOMBRE

opam-info - Un alias para show.

SINOPSIS

opam info [OPCIÓN]… [PAQUETES]…

DESCRIPCIÓN

opam info es un alias para opam show.

Ver opam show --help para más detalles.

ARGUMENTOS

PAQUETES
Lista de nombres de paquetes, con una versión o restricción opcional, p. ej. `pkg', `pkg.1.0' o `pkg>=0.5'; o nombres de archivos o directorios que contienen la descripción del paquete, con directorio explícito (p. ej. `./foo.opam' o `.')

OPCIONES

--all-versions
Muestra información de todos los paquetes que coinciden con PAQUETES, no restringido a un solo paquete que coincida con las restricciones de PAQUETES.
--empty-fields
Muestra campos que están vacíos. Esto se implica cuando se proporciona --field.
-f CAMPOS, --field=CAMPOS
Solo muestra los valores de estos campos. Los campos se pueden seleccionar entre name, version, package, synopsis, synopsis-or-target, description, <campo>, <campo>:, installed-version, pin, source-hash, opam-file, all-installed-versions, available-versions, all-versions, repository, installed-files, vc-ref, depexts. Se pueden separar varios campos con comas, en cuyo caso se imprimirán los títulos de los campos; el valor sin procesar de cualquier campo de archivo opam se puede consultar combinándolo con --raw
--file=ARCHIVO (ausente=-)
Eliminado en 2.1, use --just-file en su lugar.
--just-file
Carga y muestra información de los archivos dados (los PAQUETES permitidos son rutas de archivo o directorio), sin tener en cuenta los repositorios o el estado del paquete. Esto implica --raw a menos que se use --fields. Solo se pueden consultar campos sin procesar del archivo opam. Si no se proporciona argumento PAQUETES, lee el archivo opam desde la entrada estándar.
--list-files
Lista los archivos instalados por el paquete. Equivalente a --field=installed-files, y solo disponible para paquetes instalados
--no-lint
No emite advertencias o errores de linting al leer desde archivos
--normalise
Imprime los valores de los campos de opam normalizados (sin saltos de línea, sin corchetes implícitos)
--raw
Imprime el archivo opam sin procesar para este paquete
--sort
Ordena los campos de opam
--where
Imprime la ubicación del archivo opam utilizado para este paquete

OPCIONES COMUNES

Estas opciones son comunes a todos los comandos.

--best-effort
No fallar si no se pueden instalar todos los paquetes solicitados: intentar instalar tantos como sea posible. Tenga en cuenta que no todos los solucionadores externos pueden admitir esta opción (versiones recientes de aspcud o mccs deberían hacerlo). Esto es equivalente a establecer la variable de entorno $OPAMBESTEFFORT.
--cli=MAYOR.MENOR (ausente=2.4)
Utiliza la sintaxis y semántica de la interfaz de línea de comandos de MAYOR.MENOR. Previsto para cualquier uso persistente de opam (scripts, publicaciones de blog, etc.), cualquier versión de opam en la misma serie MAYOR se comportará como para la versión MENOR especificada. La bandera no estaba disponible en opam 2.0, por lo que para seleccionar la CLI 2.0, establezca la variable de entorno OPAMCLI a 2.0 en lugar de usar este parámetro.
--color=CUÁNDO
Colorea la salida. CUÁNDO debe ser uno de always, never o auto.
--confirm-level=NIVEL
Nivel de confirmación, NIVEL debe ser uno de ask, no, yes o unsafe-yes. Se puede especificar varias veces. Si también se dan --yes o --no, se tiene en cuenta el valor del último --confirm-level. Esto es equivalente a establecer $OPAMCONFIRMLEVEL.
--criteria=CRITERIOS
Especifica las preferencias del usuario para la resolución de dependencias para esta ejecución. Anula $OPAMCRITERIA, $OPAMFIXUPCRITERIA y $OPAMUPGRADECRITERIA. Para obtener detalles sobre el idioma compatible y los solucionadores externos disponibles, consulte http://opam.ocaml.org/doc/External_solvers.html. Una guía general para usar las preferencias del solucionador se puede encontrar en http://www.dicosmo.org/Articles/usercriteria.pdf.
--cudf=NOMBREARCHIVO
Opción de depuración: Guarda las solicitudes CUDF enviadas al solucionador en NOMBREARCHIVO-<n>.cudf donde <n> es la n-ésima llamada al solucionador durante la ejecución de opam.
--debug
Imprime mensajes de depuración en stderr. Esto es equivalente a establecer $OPAMDEBUG a "true".
--debug-level=NIVEL
Igual que --debug, pero permite especificar el nivel de depuración (--debug lo establece en 1). Equivalente a establecer $OPAMDEBUG a un entero positivo.
--git-version
Imprime la versión git de opam, si está configurada (es decir, si está utilizando una versión de desarrollo), y sale.
--help[=FMT] (predeterminado=auto)
Muestra esta ayuda en formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la variable TERM sea dumb o indefinida.
--ignore-pin-depends
Ignora los pines adicionales requeridos por los paquetes que se fijan, ya sea manualmente a través de opam pin o a través de opam install DIR. Esto es equivalente a establecer IGNOREPINDEPENDS=true.
--json=NOMBREARCHIVO
Guarda los resultados de la ejecución de opam en un archivo legible por máquina. Si el nombre del archivo contiene el carácter `%`, se reemplazará por un índice que no sobrescribirá un archivo existente. Similar a establecer la variable $OPAMJSON.
--no
Responde no a todas las preguntas de sí/no de opam sin preguntar. Ver también --confirm-level. Esto es equivalente a establecer $OPAMNO a "true".
--no-aspcud
Eliminado en 2.1.
--no-auto-upgrade
Al configurar o actualizar un repositorio que está escrito para una versión anterior de opam (1.2), opam lo convierte internamente al formato actual. Esto deshabilita este comportamiento. Tenga en cuenta que los repositorios deben definir su versión de formato en un archivo `repo` en su raíz, o se asumirá que están en el formato anterior. En cualquier caso, es preferible actualizar los repositorios manualmente usando opam admin upgrade [--mirror URL] cuando sea posible.
--no-self-upgrade
Opam se reemplazará a sí mismo con un binario más nuevo encontrado en OPAMROOT/opam si está presente. Esto deshabilita este comportamiento.
-q, --quiet
Deshabilita --verbose.
--root=ROOT
Usa ROOT como la ruta raíz actual. Esto es equivalente a establecer $OPAMROOT a ROOT.
--safe, --readonly
Asegura que nada se actualizará o reescribirá automáticamente. Útil para llamar desde scripts de finalización, por ejemplo. Fallará cuando sea necesaria tal operación; también evita esperar bloqueos, omite preguntas interactivas y anula la variable $OPAMDEBUG. Esto es equivalente a establecer la variable de entorno $OPAMSAFE.
--solver=CMD
Especifica el solucionador CUDF a utilizar para resolver problemas de instalación de paquetes. Este es un solucionador predefinido (esta versión de opam soporta builtin-mccs+lp(), builtin-mccs+glpk, builtin-dummy-z3-solver, builtin-0install, aspcud, mccs, aspcud-old, packup), o un comando personalizado que debe contener las variables %{input}%, %{output}%, %{criteria}%, y opcionalmente %{timeout}%. Esto es equivalente a establecer $OPAMEXTERNALSOLVER.
--strict
Falla siempre que se encuentre un error en la definición de un paquete o en un archivo de configuración. El valor predeterminado es continuar silenciosamente si es posible.
--switch=SWITCH
Usa SWITCH como el switch del compilador actual. Esto es equivalente a establecer $OPAMSWITCH a SWITCH.
--use-internal-solver
Deshabilita cualquier solucionador externo y utiliza el interno (esto requiere que opam tenga

OPTIONS

-a, --all
See --solver. Deprecated, use --solver=all.
-C, --conflicts
Show conflicts instead of packages. Implies --show.
--color[=when]
Use colors for output. when may be auto, always, or never. Defaults to auto.
--confirm-level=level
Set the confirmation level for prompts. Possible values are low, medium, and high. This overrides $OPAMYES and $OPAMNO.
-d, --debug[=section]
Enable debug messages. If section is given, only messages from that section are shown. Can be specified multiple times. See also $OPAMDEBUGSECTIONS.
--debug-level=n
Set the debug level to n (default 1). Higher values mean more verbose output.
-f, --force
Force the operation, for example to recompile a package even if it is already installed.
-h, --help[=topic]
Show help message. If topic is specified, show help for that specific topic (e.g. --help=options).
-I, --include=dir
Add dir to the list of directories to search for package definitions.
-i, --info
Show information about packages instead of commands.
--inplace-build
Build packages in their source directory instead of a temporary build directory. This can be useful for debugging but may lead to unexpected behaviour if the source directory is modified by other means. Can also be set with $OPAMINPLACEBUILD.
--internal-solver
Use the internal solver. Deprecated, use --solver=internal.
--jobs=n
Use n parallel jobs for building and other tasks. Defaults to the number of CPU cores. Can also be set with $OPAMJOBS.
-L, --libpath=dir
Add dir to the list of directories to search for libraries.
-m, --modify
Modify the specified packages.
-n, --dry-run
Show what would be done, without actually doing it.
-N, --no-action
Do nothing, just check for errors.
--no-checksums
Do not check checksums when downloading files. Can also be set with $OPAMNOCHECKSUMS.
--no-depexts
Do not install system dependencies. Can also be set with $OPAMNODEPEXTS.
--no-self-upgrade
Do not perform automatic upgrades of opam itself. Can also be set with $OPAMNOSELFUPGRADE.
-P, --path=dir
Add dir to the list of directories to search for executables.
--patch=file
Apply patch file before building.
-q, --quiet
Suppress informational messages. Use twice for more quietness.
-r, --recursive
Recursively process dependencies.
--repo=name
Use only the repository named name.
--repo-file=file
Use repository defined in file.
-R, --repositories
List available repositories.
--remove=package
Remove specified package. Use --auto-remove to remove unused dependencies.
-s, --solver=name
Use the specified solver. Possible values are internal, builtins, z3, all, none. Defaults to internal. If set to all or builtins, it means to use the internal solver (which has been compiled with a built-in solver). This is equivalent to setting $OPAMNOASPCUD or $OPAMUSEINTERNALSOLVER.
-v, --verbose
Be more verbose. One -v shows all package commands, repeat to also display commands called internally (e.g. tar, curl, patch etc.) Repeating n times is equivalent to setting $OPAMVERBOSE to "n".
--version
Show version information.
-w, --working-dir
Whenever updating packages that are bound to a local, version-controlled directory, update to the current working state of their source instead of the last committed state, or the ref they are pointing to. As source directory is copied as it is, if it isn't clean it may result on a opam build failure. This only affects packages explicitly listed on the command-line. It can also be set with $OPAMWORKINGDIR.
-y, --yes
Answer yes to all opam yes/no questions without prompting. See also --confirm-level. This is equivalent to setting $OPAMYES to "true".

ENVIRONMENT

Opam makes use of the environment variables listed here. Boolean variables should be set to "0", "no", "false" or the empty string to disable, "1", "yes" or "true" to enable.

OPAMALLPARENS surround all filters with parenthesis.

OPAMASSUMEDEPEXTS see option `--assume-depexts'.

OPAMAUTOREMOVE see remove option `--auto-remove'.

OPAMBESTEFFORT see option `--best-effort'.

OPAMBESTEFFORTPREFIXCRITERIA sets the string that must be prepended to the criteria when the `--best-effort' option is set, and is expected to maximise the `opam-query' property in the solution.

OPAMBUILDDOC Removed in 2.1.

OPAMBUILDTEST Removed in 2.1.

OPAMCLI see option `--cli'.

OPAMCOLOR when set to always or never, sets a default value for the `--color' option.

OPAMCONFIRMLEVEL see option `--confirm-level`. OPAMCONFIRMLEVEL has priority over OPAMYES and OPAMNO.

OPAMCRITERIA specifies user preferences for dependency solving. The default value depends on the solver version, use `config report' to know the current setting. See also option --criteria.

OPAMCUDFFILE save the cudf graph to file-actions-explicit.dot.

OPAMCUDFTRIM controls the filtering of unrelated packages during CUDF preprocessing.

OPAMCURL can be used to select a given 'curl' program. See OPAMFETCH for more options.

OPAMDEBUG see options `--debug' and `--debug-level'.

OPAMDEBUGSECTIONS if set, limits debug messages to the space-separated list of sections. Sections can optionally have a specific debug level (for example, CLIENT:2 or CLIENT CUDF:2), but otherwise use `--debug-level'.

OPAMDIGDEPTH defines how aggressive the lookup for conflicts during CUDF preprocessing is.

OPAMDOWNLOADJOBS sets the maximum number of simultaneous downloads.

OPAMDROPWORKINGDIR overrides packages previously updated with --working-dir on update. Without this variable set, opam would keep them unchanged unless explicitly named on the command-line.

OPAMDRYRUN see option `--dry-run'.

OPAMEDITOR sets the editor to use for opam file editing, overrides $EDITOR and $VISUAL.

OPAMERRLOGLEN sets the number of log lines printed when a sub-process fails. 0 to print all.

OPAMEXTERNALSOLVER see option `--solver'.

OPAMFAKE see option `--fake'.

OPAMFETCH specifies how to download files: either `wget', `curl' or a custom command where variables %{url}%, %{out}%, %{retry}%, %{compress}% and %{checksum}% will be replaced. Overrides the 'download-command' value from the main config file.

OPAMFIXUPCRITERIA same as OPAMUPGRADECRITERIA, but specific to fixup and reinstall.

OPAMIGNORECONSTRAINTS see install option `--ignore-constraints-on'.

OPAMIGNOREPINDEPENDS see option `--ignore-pin-depends'.

OPAMINPLACEBUILD see option `--inplace-build'.

OPAMJOBS sets the maximum number of parallel workers to run.

OPAMJSON log json output to the given file (use character `%' to index the files).

OPAMKEEPBUILDDIR see install option `--keep-build-dir'.

OPAMKEEPLOGS tells opam to not remove some temporary command logs and some backups. This skips some finalisers and may also help to get more reliable backtraces.

OPAMLOCKED combination of `--locked' and `--lock-suffix' options.

OPAMLOGS logdir sets log directory, default is a temporary directory in /tmp

OPAMMAKECMD set the system make command to use.

OPAMMERGEOUT merge process outputs, stderr on stdout.

OPAMNO answer no to any question asked, see options `--no` and `--confirm-level`. OPAMNO is ignored if either OPAMCONFIRMLEVEL or OPAMYES is set.

OPAMNOAGGREGATE with `opam admin check', don't aggregate packages.

OPAMNOASPCUD Deprecated.

OPAMNOAUTOUPGRADE disables automatic internal upgrade of repositories in an earlier format to the current one, on 'update' or 'init'.

OPAMNOCHECKSUMS enables option --no-checksums when available.

OPAMNODEPEXTS disables system dependencies handling, see option `--no-depexts'.

OPAMNOENVNOTICE Internal.

OPAMNOSELFUPGRADE see option `--no-self-upgrade'

OPAMPINKINDAUTO sets whether version control systems should be detected when pinning to a local path. Enabled by default since 1.3.0.

OPAMPRECISETRACKING fine grain tracking of directories.

OPAMPREPRO set this to false to disable CUDF preprocessing. Less efficient, but might help debugging solver issue.

OPAMREPOSITORYTARRING internally store the repositories as tar.gz files. This can be much faster on filesystems that don't cope well with scanning large trees but have good caching in /tmp. However this is slower in the general case.

OPAMREQUIRECHECKSUMS Enables option `--require-checksums' when available (e.g. for `opam install').

OPAMRETRIES sets the number of tries before failing downloads.

OPAMREUSEBUILDDIR see option `--reuse-build-dir'.

OPAMROOT see option `--root'. This is automatically set by `opam env --root=DIR --set-root'.

OPAMROOTISOK don't complain when running as root.

OPAMSAFE see option `--safe'.

OPAMSHOW see option `--show'.

OPAMSKIPUPDATE see option `--skip-updates'.

OPAMSKIPVERSIONCHECKS bypasses some version checks. Unsafe, for compatibility testing only.

OPAMSOLVERALLOWSUBOPTIMAL (default `true') allows some solvers to still return a solution when they reach timeout; while the solution remains assured to be consistent, there is no guarantee in this case that it fits the expected optimisation criteria. If `true', opam willcontinue with a warning, if `false' a timeout is an error. Currently only the builtin-z3 backend handles this degraded case.

OPAMSOLVERTIMEOUT change the time allowance of the solver. Default is 60.0, set to 0 for unlimited. Note that all solvers may not support this option.

OPAMSOLVERTOLERANCE changes the tolerance towards the solver choosing an unoptimized solution (i.e. might pull outdated packages). Typical values range from 0.0 (best solution known to the solver) to 1.0 (unoptimized solution). Default is 0.0. This option is useful in case the solver can't find a solution in a reasonable time (see $OPAMSOLVERTIMEOUT). Note that all solvers may not support this option.

OPAMSTATS Removed in 2.4.

OPAMSTATUSLINE display a dynamic status line showing what's currently going on on the terminal. (one of one of always, never or auto)

OPAMSTRICT fail on inconsistencies (file reading, switch import, etc.).

OPAMSWITCH see option `--switch'. Automatically set by `opam env --switch=SWITCH --set-switch'.

OPAMUNLOCKBASE see install option `--unlock-base'.

OPAMUPGRADECRITERIA specifies user preferences for dependency solving when performing an upgrade. Overrides OPAMCRITERIA in upgrades if both are set. See also option --criteria.

OPAMUSEINTERNALSOLVER see option `--use-internal-solver'.

OPAMUSEOPENSSL Removed in 2.2.

OPAMUTF8 use UTF8 characters in output (one of one of always, never or auto). By default `auto', which is determined from the locale).

OPAMUTF8MSGS use extended UTF8 characters (camels) in opam messages. Implies OPAMUTF8. This is set by default on macOS only.

OPAMVALIDATIONHOOK if set, uses the `%{hook%}' command to validate an opam repository update.

OPAMVERBOSE see option `--verbose'.

OPAMVERBOSEON see option --verbose-on

OPAMVERSIONLAGPOWER do not use.

OPAMWITHDEVSETUP see install option `--with-dev-setup'.

OPAMWITHDOC see install option `--with-doc'.

OPAMWITHTEST see install option `--with-test.

OPAMWORKINGDIR see option `--working-dir'.

OPAMYES see options `--yes' and `--confirm-level`. OPAMYES has priority over OPAMNO and is ignored if OPAMCONFIRMLEVEL is set.

OPAMVAR_var overrides the contents of the variable var when substituting `%{var}%` strings in `opam` files.

OPAMVAR_package_var overrides the contents of the variable package:var when substituting `%{package:var}%` strings in `opam` files.

CLI VERSION

All scripts and programmatic invocations of opam should use `--cli' in order to ensure that they work seamlessly with future versions of the opam client. Additionally, blog posts or other documentation can benefit, as it prevents information from becoming stale.

Aunque opam solo admite raíces (~/.opam/) para la versión actual, proporciona compatibilidad retroactiva para su interfaz de línea de comandos.

Dado que la compatibilidad con la versión de la CLI solo se añadió en opam 2.1, use OPAMCLI para seleccionar la compatibilidad 2.0 (ya que opam 2.0 simplemente la ignorará) y `--cli=2.1' para versiones 2.1 (o posteriores), ya que una variable de entorno que controle el análisis de la sintaxis es frágil. Para ello, opam muestra una advertencia si OPAMCLI especifica una versión válida distinta de 2.0, y también si se especifica `--cli=2.0'.

La versión de la línea de comandos se selecciona utilizando la opción `--cli' o la variable de entorno OPAMCLI. `--cli' puede especificarse varias veces, donde la última instancia tiene prioridad. OPAMCLI solo se inspecciona si no se proporciona `--cli'.

ESTADO DE SALIDA

Como excepción a lo siguiente, el comando `exec' devuelve 127 si el comando no se encontró o no se pudo ejecutar, y el valor de salida del comando en caso contrario.

0
Éxito, o verdadero para consultas booleanas.
1
Falso. Devuelto cuando se espera un valor de retorno booleano, por ejemplo, al ejecutar con --check, o para consultas como opam lint.
2
Argumentos de línea de comandos incorrectos, o argumentos de línea de comandos que apuntan a un contexto no válido (por ejemplo, archivo que no sigue el formato esperado).
5
No encontrado. Solicitó algo (paquete, versión, repositorio, etc.) que no se pudo encontrar.
10
Abortado. La operación requirió confirmación, que no se dio.
15
No se pudieron adquirir los bloqueos necesarios para la operación.
20
No hay solución para la solicitud del usuario. Esto puede ser causado por solicitar instalar dos paquetes incompatibles, por ejemplo.
30
Error en la definición del paquete u otros archivos de metadatos. Usar --strict genera este error con más frecuencia.
31
Error en el script del paquete. Algunas operaciones del paquete no tuvieron éxito. Esto puede ser un error en los paquetes o una incompatibilidad con su sistema. Esto puede ser un error parcial.
40
Error de sincronización. No se pudieron obtener algunos remotos de la red. Esto puede ser un error parcial.
50
Error de configuración. La configuración de Opam o del sistema no permite la operación, y necesita ser corregida.
60
Fallo del solucionador. El solucionador no pudo devolver una respuesta correcta. Puede ser debido a un solucionador externo roto, o un error en la configuración del solucionador.
99
Error interno. Algo salió mal, probablemente debido a un error en opam en sí.
130
Interrupción del usuario. Se recibió SIGINT, generalmente debido a que el usuario presionó Ctrl-C.
0
en caso de éxito.
123
en errores indiscriminados reportados en la salida estándar.
124
en errores de análisis de línea de comandos.
125
en errores internos inesperados (bugs).
