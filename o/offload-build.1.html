NOMBRE

offload-build - Construye un PKGBUILD en un servidor remoto usando makechrootpkg

SINOPSIS

offload-build [OPCIONES] — [OPCIONES_ARCHBUILD]

DESCRIPCIÓN

Construye un PKGBUILD en un servidor remoto usando makechrootpkg. Requiere un usuario remoto que pueda ejecutar archbuild de manera no interactiva, por ejemplo, debe poder elevar permisos usando sudo sin contraseña.

OPCIONES

-r, --repo <nombre_repo>

Construye contra un repositorio específico. El valor predeterminado es extra, para construir paquetes usando los repositorios estables a través de extra-x86_64-build.

-a, --arch <arquitectura>

Construye contra una arquitectura específica. El valor predeterminado es x86_64, la única arquitectura soportada oficialmente por Arch Linux.

-s, --server <nombre_host>

Descarga a un servidor de compilación específico. El valor predeterminado es build.archlinux.org, que se utiliza como parte de la cadena de herramientas de compilación para los repositorios oficiales de Arch Linux.

-h, --help

Muestra un texto de ayuda.

PASANDO OPCIONES A ARCHBUILD

Las opciones después de un delimitador — se pasan a archbuild en el sistema remoto. archbuild, a su vez, admite pasar argumentos a makechrootpkg, que a su vez admite pasar opciones a makepkg. Dado que cada uno usa — para delimitar las opciones que se reenvían, asegúrate de escaparlas correctamente:

`offload-build args_offload -- args_archbuild -- args_makechrootpkg -- args_makepkg`

Ejemplo: Para usar una segunda instancia de testing-x86_64-build con otra copia de directorio:

`offload-build -r testing -- -- -l <chroot_copy>`

PÁGINA PRINCIPAL

https://gitlab.archlinux.org/archlinux/devtools
