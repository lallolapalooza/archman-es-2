opj_compress(1)

Paquete: openjpeg2

Licencias: BSD-2-Clause, MIT

opj_compress(1) convierte a archivos jpeg2000 opj_compress(1)

NOMBRE

opj_compress - Este programa lee una imagen de un cierto tipo y la convierte a un archivo jpeg2000. Es parte de la librería OpenJPEG.

Las extensiones de imagen de entrada válidas son .bmp, .pgm, .pgx, .png, .pnm, .ppm, .raw, .tga, .tif. Para PNG y TIF respectivamente, necesita libpng o libtiff.

Las extensiones de imagen de salida válidas son .j2k, .jp2

SINOPSIS

opj_compress -i archivo_entrada.bmp -o archivo_salida.j2k

opj_compress -ImgDir directorio_nombre -OutFor jp2

opj_compress -h Muestra un mensaje de ayuda y sale.

Ver OPCIONES JPWL para opciones especiales

OPCIONES

-b n,n
(Tamaño del bloque de código (ej. -b 32,32). Por defecto: 64 x 64)
-c n
(Tamaño de la precinta (ej. -c 128,128). Por defecto: 2^15 x 2^15)
-cinema2K fps
Codestream conforme al perfil Digital Cinema 2K. Los valores válidos de fps son 24 o 48.
-cinema4K
Codestream conforme al perfil Digital Cinema 4K. No necesita fps: el valor por defecto es 24 fps.
-d X,Y
(Desplazamiento del origen de la imagen (ej. -d 150,300))
-h
Muestra un mensaje de ayuda y sale.
-i nombre
(nombre del archivo de entrada)
-n n
(Número de resoluciones. Por defecto: 6)
-o nombre
(nombre del archivo de salida)
-p nombre
Orden de progresión. nombre puede ser uno de los siguientes: LRCP, RLCP, RPCL, PCRL, CPRL. Por defecto: LRCP.
-q n
psnr diferente para capas sucesivas
Nota: (las opciones -r y -q no se pueden usar juntas)
-r n
diferentes ratios de compresión para capas sucesivas. La tasa especificada para cada nivel de calidad es el factor de compresión deseado.
Nota: (las opciones -r y -q no se pueden usar juntas)
-s X,Y
(factor de submuestreo (ej. -s 2,2). Por defecto: Sin submuestreo en la dirección x o y.
Observación: un submuestreo mayor que 2 puede producir errores.
-t An,Al
(Tamaño de la loseta (ej. -t 512,512) )
-x nombre
(Crear archivo de índice y llenarlo. Por defecto: sin archivo de índice)
-EPH
(Escribir marcador EPH después de cada paquete de cabecera. Por defecto: sin EPH)
-F ancho_raw,alto_raw,comp_raw,profundidad_bits_raw,s_o_u
características de la imagen raw de entrada
-I
(Usar DWT 9-7 irreversible. Por defecto: DWT 5-3 reversible)
-ImgDir nombre_directorio
(directorio que contiene los archivos de entrada)
-M n
cambio de modo con valores: 1, 2, 4, 8, 16, 32. Por defecto: Sin cambio de modo activado.
Significado:
BYPASS(1)
RESET(2)
RESTART(4)
VSC(8)
ERTERM(16)
SEGMARK(32)
Los valores se pueden sumar: RESTART(4) + RESET(2) + SEGMARK(32) = -M 38
-OutFor ext
(extensión para los archivos de salida)
-POC NumParcela=inicioResolucion, inicioComponente, finCapa, finResolucion, finComponente, ordenProgresion
(ver Ejemplos)
-ROI c=n,U=n
índices de cuantificación desplazados hacia arriba para el componente c (0, 1 o 2) con un valor de U (>= 0 y <= 37)
ej. -ROI c=0,U=25
-SOP
(Escribir marcador SOP antes de cada paquete. Por defecto: Sin marcador SOP en el codestream.)
-T X,Y
(Desplazamiento del origen de las losetas (ej. -T 100,75) )
-W
(ver OPCIONES JPWL)

OPCIONES JPWL

Opciones utilizables solo si la librería ha sido compilada con -DUSE_JPWL

-W h<partelosa><=tipo>, s<partelosa><=metodo>, a=<direccion>, z=<tamano>, g=<rango>, p<partelosa:paquete><=tipo>

h selecciona la protección contra errores de cabecera (EPB): tipo puede ser
[0=ninguna 1,ausente=predefinido 16=CRC-16 32=CRC-32 37-128=RS]
si partelosa está ausente, es para cabeceras principales y de loseta
si partelosa está presente, se aplica desde esa loseta
en adelante, hasta la siguiente especificación h<>, o hasta la última partelosa
en el codestream (máx. 16 especificaciones)

p selecciona la protección contra errores de paquete (EEP/UEP con EPBs)
que se aplicará a los datos raw: tipo puede ser
[0=ninguna 1,ausente=predefinido 16=CRC-16 32=CRC-32 37-128=RS]
si partelosa:paquete está ausente, es desde la loseta 0, paquete 0
si partelosa:paquete está presente, se aplica desde esa loseta
y ese paquete en adelante, hasta la siguiente especificación de paquete
o hasta el último paquete en la última partelosa en el stream
(máx. 16 especificaciones)

s habilita la inserción de datos de sensibilidad (ESD): metodo puede ser
[-1=SIN ESD 0=ERROR RELATIVO 1=MSE 2=REDUCCION MSE 3=PSNR
4=INCREMENTO PSNR 5=MAXERR 6=TSE 7=RESERVADO]
si partelosa está ausente, es solo para la cabecera principal
si partelosa está presente, se aplica desde esa loseta
en adelante, hasta la siguiente especificación s<>, o hasta la última partelosa
en el codestream (máx. 16 especificaciones)

g determina el modo de direccionamiento: rango puede ser
[0=PAQUETE 1=RANGO DE BYTES 2=RANGO DE PAQUETES]

a determina el tamaño del direccionamiento de datos: direccion puede ser
2/4 bytes (codestreams pequeños/grandes). Si no se establece, modo automático

z determina el tamaño de los valores de sensibilidad: tamano puede ser
1/2 bytes, para el valor pseudo-flotante transformado

EJEMPLOS

opj_compress -i archivo.bmp -o archivo.j2k -r 20,10,1 (comprime 20x, luego 10x, luego sin pérdidas).

opj_compress -i archivo.ppm -o archivo.j2k -q 30,40,50

opj_compress -i archivo.pgx -o archivo.j2k -POC T1=0,0,1,5,3,CPRL

opj_compress -i lena.raw -o lena.j2k -F 512,512,3,8,u
