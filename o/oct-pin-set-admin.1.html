NOMBRE

oct-pin-set-admin - Establecer PIN de administrador

SINOPSIS

oct pin set-admin [-P|--admin-pin-old] [-Q|--admin-pin-new] [-h|--help]

DESCRIPCIÓN

Establecer PIN de administrador

Establece un nuevo PIN de administrador proporcionando el PIN de administrador actual.

OPCIONES

-P, --admin-pin-old=Archivo PIN de administrador antiguo
Opcionalmente, obtener el PIN de administrador antiguo de un archivo
-Q, --admin-pin-new=Archivo PIN de administrador nuevo
Opcionalmente, obtener el nuevo PIN de administrador de un archivo
-h, --help
Imprimir ayuda (ver un resumen con '-h')
