OCAMLBUILD(1) Manual de Comandos Generales OCAMLBUILD(1)

NOMBRE

ocamlbuild - La herramienta de compilación de proyectos OCaml

SINOPSIS

ocamlbuild [ -Is  dir1,... ] [ -libs lib1,... ] [ -lflags flag1,... ] [ -pp flags ] [ -tags tag1,... ] [ -j  jobs-paralelos ] objetivo.nativo [ -- arg1 arg2 ... ]

(mismas opciones)

DESCRIPCIÓN

ocamlbuild(1) orquesta el proceso de compilación de tu proyecto OCaml. Es similar en función a make(1) excepto que está hecho a medida para compilar automáticamente la mayoría de los proyectos OCaml con muy poca entrada del usuario.

ocamlbuild debe invocarse en la raíz de un árbol de proyecto limpio (por ejemplo, sin archivos de compilación sobrantes). Dadas una o más objetivos a compilar, escanea los subdirectorios requeridos para recopilar información sobre los diversos archivos presentes, ejecutando herramientas como ocamldep(1) para extraer información de dependencias, y recopilando archivos opcionales que ajustan su comportamiento. Los nombres de los objetivos son muy significativos.

NOMBRES DE OBJETIVO

ocamlbuild utiliza un conjunto de convenciones de nombres de objetivos para seleccionar el tipo de objetos a producir. Los nombres de los objetivos son de la forma base.extensión donde base es usualmente el nombre del módulo OCaml subyacente y extensión denota el tipo de objeto a producir a partir de ese archivo -- un ejecutable de código bytecode, un ejecutable nativo, documentación... Por supuesto, extensiones como .cmo, .cma, .cmi... se corresponden con sus contrapartes habituales. Aquí hay una lista de las extensiones específicas de ocamlbuild más importantes:

.native
Ejecutable de código nativo
.byte
Ejecutable de código bytecode
.inferred.mli
Interfaz inferida con ocamlc-i
.docdir/index.html
Documentación HTML generada con ocamldoc

OPCIONES

Las siguientes opciones de línea de comandos son reconocidas por ocamlbuild(1).

-version
Muestra la versión
--version
igual que -version
-vnum
Muestra el número de versión
--vnum
igual que -vnum
-quiet
Hacer lo más silencioso posible
-verbose <nivel>
Establece el nivel de verbosidad en una escala de 0 a 8 (incluido)
-documentation
Mostrar reglas y flags
-log <archivo>
Establecer archivo de log
-no-log
Sin archivo de log
-clean
Elimina el directorio de compilación y otros archivos, y sale
-r
Recorre los directorios por defecto (verdadero: recorrer)
-I <ruta>
Añadir a los directorios de inclusión
-Is <ruta,...>
(igual que el anterior, pero acepta una lista separada por (coma o espacio))
-X <ruta>
Directorio a ignorar
-Xs <ruta,...>
(ídem)
-lib <flag>
Enlazar a esta biblioteca ocaml
-libs <flag,...>
(ídem)
-mod <módulo>
Enlazar a este módulo ocaml
-mods <módulo,...>
(ídem)
-pkg <paquete>
Enlazar a este paquete findlib de ocaml
-pkgs <paquete,...>
(ídem)
-package <paquete>
(ídem)
-syntax <sintaxis>
Especificar sintaxis usando ocamlfind
-lflag <flag>
Añadir a los flags de enlace de ocamlc
-lflags <flag,...>
(ídem)
-cflag <flag>
Añadir a los flags de compilación de ocamlc
-cflags <flag,...>
(ídem)
-docflag <flag>
Añadir a los flags de ocamldoc
-docflags <flag,...>
(ídem)
-yaccflag <flag>
Añadir a los flags de ocamlyacc
-yaccflags <flag,...>
(ídem)
-lexflag <flag>
Añadir a los flags de ocamllex
-lexflags <flag,...>
(ídem)
-ppflag <flag>
Añadir a los flags de preprocesamiento de ocaml
-pp <flag,...>
(ídem)
-tag <tag>
Añadir a las etiquetas por defecto
-tags <tag,...>
(ídem)
-plugin-tag <tag>
Usar esta etiqueta al compilar el plugin myocamlbuild.ml
-plugin-tags <tag,...>
(ídem)
-tag-line <tag>
Usar esta línea de etiquetas (como en _tags)
-show-tags <ruta>
Mostrar etiquetas que se aplican a esta ruta de archivo
-ignore <módulo,...>
No intentar construir estos módulos
-no-links
No crear enlaces de los objetivos finales producidos
-no-skip
No omitir módulos que son requeridos por ocamldep pero no pueden ser construidos
-no-hygiene
No aplicar reglas de verificación de sanidad
-no-plugin
No construir myocamlbuild.ml
-no-stdlib
No ignorar módulos stdlib
-dont-catch-errors
No capturar y mostrar errores (útil para mostrar la pila de llamadas)
-just-plugin
Solo construir myocamlbuild.ml
-byte-plugin
No usar un plugin nativo sino bytecode
-plugin-option
Usar la opción solo cuando se ejecuta el plugin
-sanitization-script
Cambiar el nombre del archivo para el script de sanidad generado
-no-sanitize
No generar script de sanidad
-nothing-should-be-rebuilt
Fallar si algo necesita ser reconstruido
-classic-display
Mostrar comando ejecutado

OPTIONS

-version
Display the version of ocamlbuild and exit.
-setup
Print a configuration file. Default is `~/.ocamlbuild.config`.
-X <option>
Pass option to the underlying OCaml compilers.
-no-hygiene
Disable hygiene checks. This is the old-fashioned way
-use-menhir
Utilizar menhir en lugar de ocamlyacc
-use-jocaml
Utilizar compiladores jocaml en lugar de los de ocaml
-use-ocamlfind
Utilizar el envoltorio 'ocamlfind' en lugar de usar Findlib directamente para determinar los argumentos de la línea de comandos. Usar -no-ocamlfind para deshabilitar. Implica -plugin-use-ocamlfind.
-no-ocamlfind
No utilizar ocamlfind. Implica -plugin-no-ocamlfind.
-plugin-use-ocamlfind
Utilizar el envoltorio 'ocamlfind' para construir myocamlbuild.ml
-plugin-no-ocamlfind
No utilizar ocamlfind para construir myocamlbuild.ml
-toolchain <toolchain>
Establecer la toolchain de Findlib a usar. La toolchain por defecto se utiliza siempre para construir myocamlbuild.ml.
-j <N>
Permitir N trabajos a la vez (0 para ilimitado)
-build-dir <path>
Establecer el directorio de compilación (implica no-links)
-install-lib-dir <path>
Establecer el directorio de bibliotecas de instalación
-install-bin-dir <path>
Establecer el directorio de binarios de instalación
-where
Mostrar el directorio de bibliotecas de instalación
-which <command>
Mostrar la ruta del comando de la herramienta
-ocamlc <command>
Establecer el compilador de bytecode de OCaml
-plugin-ocamlc <command>
Establecer el compilador de bytecode de OCaml utilizado al construir myocamlbuild.ml (solo)
-ocamlopt <command>
Establecer el compilador nativo de OCaml
-plugin-ocamlopt <command>
Establecer el compilador nativo de OCaml utilizado al construir myocamlbuild.ml (solo)
-ocamldep <command>
Establecer la herramienta de dependencias de OCaml
-ocamldoc <command>
Establecer el generador de documentación de OCaml
-ocamlyacc <command>
Establecer la herramienta ocamlyacc
-menhir <command>
Establecer la herramienta menhir (usarla después de -use-menhir)
-ocamllex <command>
Establecer la herramienta ocamllex
-ocamlmklib <command>
Establecer la herramienta ocamlmklib
-ocamlmktop <command>
Establecer la herramienta ocamlmktop
-ocamlrun <command>
Establecer la herramienta ocamlrun
--
Detener el procesamiento de argumentos, los argumentos restantes se pasan al programa del usuario
-help
Mostrar esta lista de opciones
--help
Mostrar esta lista de opciones
