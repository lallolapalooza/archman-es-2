NOMBRE

osage - filtro para dibujar grafos agrupados

SINOPSIS

osage [-(G|N|E)nombre=valor] [-Tidioma] [-larchivo_libreria] [-oarchivo_salida] [-O] [-P] [-v] [-V] [archivos]

DESCRIPCIÓN

osage dibuja grafos agrupados. Como entrada, toma cualquier grafo en formato dot. Dibuja el grafo recursivamente. En cada nivel, habrá una colección de nodos y una colección de subgrafos de clúster. Los internos de cada subgrafo de clúster se disponen, luego los subgrafos de clúster y los nodos en el nivel actual se posicionan uno con respecto al otro, tratando cada subgrafo de clúster como un nodo.

En cada nivel, los nodos y subgrafos de clúster se ven como rectángulos para empaquetar. Actualmente, las aristas se ignoran durante el empaquetamiento. El empaquetamiento se realiza utilizando las funciones de empaquetamiento estándar. En particular, los atributos del grafo pack y packmode controlan la disposición. Cada grafo y clúster puede especificar sus propios valores para estos atributos. Recuerde también que un clúster hereda sus valores de atributo de su grafo padre.

Después de todos los nodos y clústeres, las aristas se enrutan según el valor del atributo splines.

FORMATOS DE SALIDA

Osage utiliza un mecanismo de plugin extensible para sus renderizadores de salida, por lo que para ver qué formatos de salida soporta su instalación de osage, puede usar ``osage -Txxx'' (donde xxx es un formato poco probable) y comprobar el mensaje de advertencia. Además, el mecanismo de plugin soporta múltiples implementaciones de los formatos de salida. Para ver qué variantes están disponibles, use, por ejemplo: ``osage -Tpng:'' y para forzar una variante particular, use, por ejemplo: ``osage -Tpng:gd''

Tradicionalmente, osage soporta los siguientes: -Tps (PostScript), -Tsvg -Tsvgz (Gráficos vectoriales estructurados), -Tfig (Gráficos XFIG), -Tmif (Gráficos FrameMaker), -Thpgl (Plotters HP), y -Tpcl (Impresoras Laserjet), -Tpng -Tgif (gráficos de mapa de bits), -Timap (archivos de mapa de imágenes para servidores httpd para cada nodo o arista que tenga un atributo "href" no nulo), -Tcmapx (mapa de imágenes del lado del cliente para usar en html y xhtml). Formatos de salida adicionales menos comunes o más específicos se pueden encontrar en https://www.graphviz.org/doc/info/output.html.)

Se pueden encontrar plugins alternativos que soportan un formato de salida dado en el mensaje de error resultante de añadir dos puntos (:) al formato. Ej: -Tpng: El primer plugin listado es siempre el predeterminado.

LENGUAJE DE ARCHIVOS DE GRAFO

Aquí hay una sinopsis del lenguaje de archivos de grafo, normalmente usando la extensión .gv, para grafos:

[strict] (graph|digraph) nombre { lista_de_sentencias }
Es el grafo de nivel superior. Si el grafo es strict, entonces no se permiten múltiples aristas entre los mismos pares de nodos. Si es un grafo dirigido, indicado por digraph, entonces el operador_arista debe ser "->". Si es un graph no dirigido, entonces el operador_arista debe ser "--". Las sentencias pueden ser:

nombre=valor;
node [nombre=valor];
edge [nombre=valor];
Establece el atributo predeterminado del grafo, nodo o arista nombre a valor. Cualquier subgrafo, nodo o arista que aparezca después heredará los nuevos atributos predeterminados.

n0 [nombre0=valor0,nombre1=valor1,...]; Crea el nodo n0 (si aún no existe) y establece sus atributos de acuerdo con la lista opcional.

n0 operador_arista n1 operador_arista ... operador_arista nn [nombre0=valor0,nombre1=valor1,...];
Crea aristas entre los nodos n0, n1, ..., nn y establece sus atributos de acuerdo con la lista opcional. Crea nodos según sea necesario.

[subgraph nombre] { lista_de_sentencias }
Crea un subgrafo. Los subgrafos se pueden usar en lugar de n0, ..., nn en las sentencias anteriores para crear aristas. [subgraph nombre] es opcional; si se omite, al subgrafo se le asigna un nombre interno.

Los comentarios pueden ser /*como en C*/ o //como en C++.

Los nombres y valores de los atributos son cadenas normales (estilo C). Las siguientes secciones describen los atributos que controlan la disposición del grafo.

ATRIBUTOS DEL GRAFO

size="x,y" establece el cuadro delimitador del dibujo en pulgadas.

page="x,y" establece la unidad de paginación PostScript.

ratio=f establece la relación de aspecto a f, que puede ser un número de punto flotante o una de las palabras clave fill, compress o auto.

pagedir=[TBLR][TBLR] establece el orden principal y secundario de paginación.

rotate=90 establece el modo horizontal. (orientation=land es compatible con versiones anteriores pero obsoleto).

center=n un valor distinto de cero centra el dibujo en la página.

layers="id:id:id:id" es una secuencia de identificadores de capa para diagramas superpuestos. La variable de matriz PostScript layercolorseq establece la asignación de colores a las capas. El índice más bajo es 1 y cada elemento debe ser una matriz de 3 elementos para ser interpretada como una coordenada de color.

color=valor_color establece el color del primer plano (bgcolor para el fondo).

href="url" la url predeterminada para archivos de mapa de imágenes; en archivos PostScript, la url base para todas las urls relativas, como lo reconocen Acrobat Distiller 3.0 y versiones posteriores.

URL="url" ("URL" es un sinónimo de "href".)

stylesheet="archivo.css" incluye una referencia a una hoja de estilos en las salidas -Tsvg y -Tsvgz. Se ignora en otros formatos.

splines. Si se establece en true, las aristas se dibujan como curvas. Si se establece en polyline, las aristas se dibujan como polilíneas. Si se establece en ortho, las aristas se dibujan como polilíneas ortogonales. En todos estos casos, los nodos pueden no superponerse. Si splines=false o splines=line, las aristas se dibujan como segmentos de línea. El valor predeterminado es false.

ATRIBUTOS DE NODO

height=d o width=d establece la altura o anchura mínima. Añadir fixedsize=true fuerza que sean el tamaño real (las etiquetas de texto se ignoran).

shape=record polygon epsf poligono_incorporado
poligono_incorporado es uno de: plaintext ellipse oval circle egg triangle box diamond trapezium parallelogram house hexagon octagon note tab box3d component. (Los polígonos se definen o modifican por los siguientes atributos de nodo: regular, peripheries, sides, orientation, distortion y skew.) epsf utiliza el atributo shapefile del nodo como el nombre de ruta de un archivo EPSF externo que se cargará automáticamente para la forma del nodo.

label=texto donde texto puede incluir saltos de línea escapados \n, \l, o \r para líneas centradas, justificadas a la izquierda o a la derecha. El valor de la cadena '\N' se reemplazará por el nombre del nodo. El valor de la cadena '\G' se reemplazará por el nombre del grafo. Las etiquetas de registro pueden contener listas de cajas recursivas delimitadas por { | }. Los identificadores de puerto en las etiquetas se separan por corchetes angulares < >. En el archivo del grafo, use dos puntos (por ejemplo, nodo0:puerto28).

fontsize=n establece el tamaño de la fuente de la etiqueta a n puntos.

fontname=nombre establece el nombre de la familia de fuentes de la etiqueta.

color=valor_color establece el color del contorno y el color de relleno predeterminado si style=filled y fillcolor no se especifica.

fillcolor=valor_color establece el color de relleno cuando style=filled. Si no se especifica, el fillcolor cuando style=filled será el mismo que el color del contorno.

fontcolor=valor_color establece el color del texto de la etiqueta.

Un valor_color puede ser "h,s,v" (tono, saturación, brillo) números de punto flotante entre 0 y 1, o un nombre de color X11 como white black red green blue yellow magenta cyan<

NODE ATTRIBUTES

label=text where text may include escaped newlines \n, \l, or \r for centered, left, or right justified lines. If the substring '\N' is found in a label it will be replaced by the node name. If the substring '\G' is found in a label it will be replaced by the graph name.

fontsize=n sets the label type size to n points.

fontname=name sets the label font family name.

fontcolor=colorvalue sets the label text color.

shape=name sets the shape of the node. The default is ellipse. A list of built-in shapes is provided below. If the shape is a polygon, the number of sides can be specified by appending it to the name, e.g. polygon3 for a triangle. Otherwise, the shape is determined by the label. Colors can be specified as X11 color names, like burlywood, or a "#rrggbb" (red, green, blue, 2 hex characters each) value.

style=filled solid dashed dotted bold invis or any Postscript code.

layer=id or id:id or "all" sets the node's active layers. The empty string means no layers (invisible).

The following attributes apply only to polygon shape nodes:

regular=n if n is non‐zero then the polygon is made regular, i.e. symmetric about the x and y axis, otherwise the polygon takes on the aspect ratio of the label. builtin_polygons that are not already regular are made regular by this attribute. builtin_polygons that are already regular are not affected (i.e. they cannot be made asymmetric).

peripheries=n sets the number of periphery lines drawn around the polygon. This value supersedes the number of periphery lines of builtin_polygons.

sides=n sets the number of sides to the polygon. n<3 results in an ellipse. This attribute is ignored by builtin_polygons.

orientation=f sets the orientation of the first apex of the polygon counterclockwise from the vertical, in degrees. f may be a floating point number. The orientation of labels is not affected by this attribute. This attribute is added to the initial orientation of builtin_polygons.

distortion=f sets the amount of broadening of the top and narrowing of the bottom of the polygon (relative to its orientation). Floating point values between -1 and +1 are suggested. This attribute is ignored by builtin_polygons.

skew=f sets the amount of right‐displacement of the top and left‐displacement of the bottom of the polygon (relative to its orientation). Floating point values between -1 and +1 are suggested. This attribute is ignored by builtin_polygons.

href="url" sets the url for the node in imagemap, PostScript and SVG files. The substrings '\N' and '\G' are substituted in the same manner as for the node label attribute. Additionally the substring '\L' is substituted with the node label string.

URL="url" ("URL" is a synonym for "href".)

target="target" is a target string for client‐side imagemaps and SVG, effective when nodes have a URL. The target string is used to determine which window of the browser is used for the URL. Setting it to "_graphviz" will open a new window if it doesn't already exist, or reuse it if it does. If the target string is empty, the default, then no target attribute is included in the output. The substrings '\N' and '\G' are substituted in the same manner as for the node label attribute. Additionally the substring '\L' is substituted with the node label string.

tooltip="tooltip" is a tooltip string for client‐side imagemaps and SVG, effective when nodes have a URL. The tooltip string defaults to be the same as the label string, but this attribute permits nodes without labels to still have tooltips thus permitting denser graphs. The substrings '\N' and '\G' are substituted in the same manner as for the node label attribute. Additionally the substring '\L' is substituted with the node label string.

EDGE ATTRIBUTES

label=text where text may include escaped newlines \n, \l, or \r for centered, left, or right justified lines. If the substring '\T' is found in a label it will be replaced by the tail_node name. If the substring '\H' is found in a label it will be replaced by the head_node name. If the substring '\E' value is found in a label it will be replaced by: tail_node_name->head_node_name If the substring '\G' is found in a label it will be replaced by the graph name. or by: tail_node_name--head_node_name for undirected graphs.

fontsize=n sets the label type size to n points.

fontname=name sets the label font family name.

fontcolor=colorvalue sets the label text color.

style=solid dashed dotted bold invis

color=colorvalue sets the line color for edges.

color=colorvaluelist a ':' separated list of colorvalue creates parallel edges, one edge for each color.

dir=forward back both none controls arrow direction.

tailclip,headclip=false disables endpoint shape clipping.

href="url" sets the url for the node in imagemap, PostScript and SVG files. The substrings '\T', '\H', '\E' and '\G' are substituted in the same manner as for the edge label attribute. Additionally the substring '\L' is substituted with the edge label string.

URL="url" ("URL" is a synonym for "href".)

target="target" is a target string for client‐side imagemaps and SVG, effective when edges have a URL. If the target string is empty, the default, then no target attribute is included in the output. The substrings '\T', '\H', '\E' and '\G' are substituted in the same manner as for the edge label attribute. Additionally the substring '\L' is substituted with the edge label string.

tooltip="tooltip" is a tooltip string for client‐side imagemaps effective when edges have a URL. The tooltip string defaults to be the same as the edge label string. The substrings '\T', '\H', '\E' and '\G' are substituted in the same manner as for the edge label attribute. Additionally the substring '\L' is substituted with the edge label string.

arrowhead,arrowtail=none, normal, inv, dot, odot, invdot, invodot, tee, empty, invempty, open, halfopen, diamond, odiamond, box, obox, crow.

arrowsize (norm_length=10,norm_width=5, inv_length=6,inv_width=7,dot_radius=2)

headlabel,taillabel=string for port labels. labelfontcolor,labelfontname,labelfontsize for head and tail labels. The substrings '\T', '\H', '\E' and '\G' are substituted in the same manner as for the edge label attribute. Additionally the substring '\L' is substituted with the edge label string.

headhref="url" sets the url for the head port in imagemap, PostScript and SVG files. The substrings '\T', '\H', '\E' and '\G' are substituted in the same manner as for the edge label attribute. Additionally the substring '\L' is substituted with the edge label string.

headURL="url" ("headURL" is a synonym for "headhref".)

headtarget="headtarget" is a target string for client‐side imagemaps and SVG, effective when edge heads have a URL. The headtarget string is used to determine which window of the browser is used for the URL. If the headtarget string is empty, the default, then headtarget defaults to the same value as target for the edge. The substrings '\T', '\H', '\E' and '\G' are substituted in the same manner as for the edge label attribute. Additionally the substring '\L' is substituted with the edge label string.

headtooltip="tooltip" is a tooltip string for client‐side imagemaps effective when head ports have a URL. The tooltip string defaults to be the same as the headlabel string. The substrings '\T', '\H', and '\E' are substituted in the same manner as for the edge label attribute. Additionally the substring '\L' is substituted with the edge label string.

tailhref="url" sets the url for the tail port in imagemap, PostScript and SVG files. The substrings '\T', '\H', '\E' and '\G' are substituted in the same manner as for the edge label attribute. Additionally the substring '\L' is substituted with the edge label string.

tailURL="url" ("tailURL" is a synonym for "tailhref".)

tailtarget="tailtarget" is a target string for client‐side imagemaps and SVG, effective when edge tails have a URL. The tailtarget string is used to determine which window of the browser is used for the URL. If the tailtarget string is empty, the default, then tailtarget defaults to the same value as target for the edge. The substrings '\T', '\H', '\E' and '\G' are substituted in the same manner as for the edge label attribute. Additionally the substring '\L' is substituted with the edge label string.

tailtooltip="tooltip" is a tooltip string for client‐side imagemaps effective when tail ports have a URL. The tooltip string defaults to be the same as the taillabel string. The substrings '\T', '\H', '\E' and '\G' are substituted in the same manner as for the edge label attribute. Additionally the substring '\L' is substituted with the edge label string.

labeldistance and port_label_distance set distance; also labelangle (in degrees CCW)

decorate draws line from edge to label.

samehead,sametail aim edges having the same value to the same port, using the average landing point.

layer=id or id:id or "all" sets the edge's active layers. The empty string means no layers (invisible).

(neato‐specific attributes)
w=f sets the weight (spring constant) of an edge to the given floating point value. The default is 1.0; greater values make the edge tend more toward its optimal length.

len=f sets the optimal length of an edge. The default is 1.0.

COMMAND LINE OPTIONS

-G sets a default graph attribute.
-N sets a default node attribute.
-E sets a default edge attribute. Example: -Gsize="7,8" -Nshape=box -Efontsize=8

-lfile loads custom PostScript library files. Usually these define custom shapes or styles. If -l is given by itself, the standard library is omitted.

-Tlang sets the output language as described above.

-O automatically generate output filenames based on the input filename and the -T format.

-ofile write output to file.

-x reduce graph.

-Lg don't use grid.

-LO use old attractive force.

-Lni set number of iterations to i.

-LUi set unscaled factor to i.

-LCv set overlap expansion factor to v

COMMAND LINE OPTIONS

The following command line options are available:

-?
prints the usage and exits.
-K
print the graphs in Dijkstra's form. This is useful for debugging. The output is a sequence of dot commands.
-L
print the graphs in LDS form. This is useful for debugging. The output is a sequence of dot commands.
-T
output the graphs in the specified format. If the format is not specified, the default is dot. Supported formats are listed in the OUTPUT FORMATS section.
-V
(version) prints version information and exits.
-v
(verbose) prints various information useful for debugging.
-?
prints the usage and exits.
-LT[*][v]
set temperature (temperature factor) to v.

-v (verbose) prints various information useful for debugging.

-V (version) prints version information and exits.

-? prints the usage and exits.

EXAMPLES

digraph test123 {
        pack=8
        subgraph cluster0 {
          packmode=array
          x y x0 y0 x1
          subgraph cluster1 {
            m n
          }
        }
        b [shape=box];
        c [label="hello
world",color=blue,fontsize=24,
             fontname="Palatino-Italic",fontcolor=red,style=filled];
        a -> z
        x -> z
        a -> b -> c;
        a -> {x y};
        edge [style=dashed,color=red];
        b -> x;
}
