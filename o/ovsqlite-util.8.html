NOMBRE

ovsqlite-util - Utilidad de manipulación de descripción general para ovsqlite

SINOPSIS

ovsqlite-util [-AFghioO] [-a artículo] [-n newsgrouo] [-p ruta]

DESCRIPCIÓN

ovsqlite-util es una interfaz administrativa para el método de descripción general ovsqlite para INN. Solo funciona en bases de datos de descripción general ovsqlite, no en ningún otro tipo de descripción general de INN. (Consulte los programas dedicados ovdb_stat(8) y tdx-util(8) para los métodos de descripción general ovdb y tradindexed.) Permite al administrador volcar diversa información sobre el estado interno de la descripción general, auditarla en busca de errores y corregir estos errores.

Para auditar toda la base de datos de descripción general en busca de problemas, use -A. Las comprobaciones pueden llevar mucho tiempo, dependiendo del número de newsgroups y artículos presentes en la base de datos de descripción general. Cualquier problema encontrado se informará al error estándar. Use -F para corregir los errores encontrados.

Es seguro ejecutar esta utilidad mientras el servidor está en ejecución. En caso de que se realicen correcciones en la base de datos (al usar la bandera -F), ovsqlite-util pausará adecuadamente el servidor antes de realizar sus operaciones y luego lo reanudará.

El número de registros de descripción general almacenados en la base de datos se puede obtener con el comando "inndf -n".

Como ovsqlite-util abre directamente la base de datos de descripción general ovsqlite, puede tardar más en completarse cuando INN esté en ejecución debido al hecho de que ovsqlite-server puede mantener bloqueos en ciertas tablas, en cuyo caso ovsqlite-util simplemente espera a que se liberen los bloqueos. (El parámetro transtimelimit en ovsqlite.conf controla la duración de una transacción, por lo que puede verificar que no haya establecido un valor demasiado alto).

REQUISITOS

El módulo Perl "DBI" con el controlador "DBD::SQLite" debe estar instalado para que este programa funcione. Están presentes en la mayoría de las distribuciones como un paquete llamado como "libdbd-sqlite3-perl", "perl-DBD-SQLite" o "p5-DBD-SQLite". También se pueden instalar directamente desde CPAN (distribuciones "DBI" y "DBD-SQLite" disponibles en https://metacpan.org/dist/DBI y https://metacpan.org/dist/DBD-SQLite).

Naturalmente, también debe estar en uso una base de datos de descripción general ovsqlite, como se detalla en la página del manual ovsqlite(5).

OPCIONES

-a artículo
El número o números de artículo a los que actuar. artículo es un rango NNTP válido, lo que significa que puede ser un solo número de artículo o un rango de números de artículo (como "1-5"). Se puede omitir el inicio o el final (o ambos) del rango, en cuyo caso se establecerán en el primer o último número de artículo del grupo. Por lo tanto, pasar "-" para artículo es equivalente a no usar la opción -a en absoluto.

Solo útil en combinación con las opciones -g, -o y -O para volcar información de descripción general.

-A
Auditar toda la base de datos de descripción general en busca de problemas. Actualmente, solo se realiza una verificación de consistencia: la verificación de que la marca de agua baja, la marca de agua alta y el recuento de artículos de cada newsgroup coinciden con la realidad de los artículos presentes en la descripción general. No se realizarán cambios en la base de datos, pero los problemas se informarán al error estándar.
-F
Auditar toda la base de datos de descripción general en busca de problemas, corrigiéndolos a medida que se detectan siempre que sea posible. Esto ejecuta las mismas verificaciones que la bandera -A, y corrige los problemas encontrados. El uso de esta opción se encarga de pausar y reanudar INN para que los datos de descripción general no sean modificados por otro proceso durante las operaciones.

Para ver qué cambiaría -F, ejecute ovsqlite-util primero con -A.

-g
Volcar información general de descripción general para un grupo particular. Los campos son, en orden, el número de artículo, la longitud de los datos de descripción general, la hora (en segundos desde la época) en que llegó el artículo al servidor, la hora (en segundos desde la época) en que el artículo debe caducar según su campo de encabezado Expires (o 0 si no hay ningún campo de encabezado Expires), y el token de la API de almacenamiento del artículo.

Si se da esta opción, la opción -n también debe darse para especificar el newsgroup sobre el que actuar.

-i
Volcar información de descripción general relacionada con newsgroup desde la base de datos. Esto contiene información similar al archivo active del servidor, como marcas de agua alta y baja y estado de moderación, y es la información que nnrpd entrega a los clientes.

Los campos son, en orden, el nombre del newsgroup, la marca de agua alta, la marca de agua baja, el recuento de artículos en el grupo, el estado del grupo, la hora (en segundos desde la época) en que se expiró por última vez ese newsgroup (o 0 si expireover aún no se ha ejecutado en él), y el estado de eliminación de ese newsgroup (0 si no está marcado para eliminación durante la próxima expiración, y un valor positivo en caso contrario).

Se puede especificar un newsgroup particular con la opción -n. Si -n no se da, se volcará el índice maestro completo.

-n newsgrouo
Especificar el newsgroup sobre el que actuar, requerido para las opciones -g, -o y -O, y opcional para la opción -i.
-o
Volcar la información de descripción general para un newsgroup, en el mismo formato que se devolvería a los clientes pero con una modificación. Al final de cada entrada se agregarán cuatro datos adicionales: el número de artículo según la información de descripción general etiquetado con "Article:", el token de la API de almacenamiento para ese artículo etiquetado con "Token:", la fecha de llegada de ese artículo al servidor en formato de fecha RFC 5322 etiquetado con "Arrived:" y la fecha de expiración de ese artículo (del campo de encabezado Expires) en formato de fecha RFC 5322 si existe, etiquetado con "Expires:".

Si se da esta opción, la opción -n también debe darse para especificar el newsgroup sobre el que actuar. Por defecto, se vierte toda la información de descripción general para ese newsgroup, pero la opción -a puede darse para restringir el volcado a la información para un solo artículo o un rango de números de artículo.

-O
Volcar la información de descripción general para un newsgroup en el formato utilizado por overchan como entrada. Cada línea comenzará con el token de la API de almacenamiento, la marca de tiempo de llegada en segundos desde la época, la marca de tiempo de expiración en el mismo formato (o 0 si no hay ningún campo de encabezado Expires), y luego los datos de descripción general.

Si se da esta opción, la opción -n también debe darse para especificar el newsgroup sobre el que actuar. Por defecto, se vierte toda la información de descripción general para ese newsgroup, pero la opción -a puede darse para restringir el volcado a la información para un solo artículo o un rango de números de artículo.

-p ruta
Actuar sobre la base de datos de descripción general anclada en ruta, anulando la ruta de descripción general especificada en el parámetro pathoverview en inn.conf.

EJEMPLOS

Volcar información de descripción general relacionada con newsgroup para la base de datos de descripción general en /news/overview, independientemente de la ruta de descripción general especificada en inn.conf:

ovsqlite-util -i -p /news/overview

Volcar información general de descripción general para example.test:

ovsqlite-util -g -n example.test

NAME

ovsqlite-util - manage an overview database

SYNOPSIS

ovsqlite-util [-n database] [-a ranges] [-d message-id] [-e] [-f] [-h] [-m] [-p] [-r] [-s] [-t] [-u] [-v] [-A] [-C character] [-D] [-I message-id] [-L] [-N value] [-O file] [-P field] [-R field] [-S] [-T field] [-X] [-Z]

DESCRIPTION

The ovsqlite-util utility manages the overview database used by INN. The overview database is stored in a SQLite database format, and this utility provides command-line access to perform various operations on it.

The overview database stores information about articles, including subject, from, date, message-id, and other relevant metadata. This information is used by newsreaders to display article summaries and allow users to navigate newsgroups.

By default, ovsqlite-util operates on the overview database specified by the OVERVIEWDB environment variable. If this variable is not set, it defaults to /var/lib/inn/overview.sq3.

REQUIREMENTS

This utility requires the SQLite library to be installed on the system.

OPTIONS

The ovsqlite-util utility accepts the following options:

-n database
Specifies the path to the overview database file to operate on. If not provided, the utility will use the path specified by the OVERVIEWDB environment variable or the default path.
-a ranges
Specifies a range of article numbers to operate on. The format for ranges is a comma-separated list of numbers and ranges, e.g., 1-10,20,30-. A trailing hyphen indicates "from this number to the end".
-d message-id
Deletes the specified article from the overview database.
-e
Enables extended output format, showing more details about the articles.
-f
Forces overwriting existing entries when adding new articles.
-h
Displays a help message and exits.
-m
Modifies existing entries in the overview database. This option is typically used in conjunction with other options to specify the fields to modify.
-p
Prints the contents of the overview database in a human-readable format.
-r
Rebuilds the overview database. This is a potentially time-consuming operation and should be used with caution.
-s
Sorts the overview database by subject.
-t
Truncates the overview database, removing all entries.
-u
Updates existing entries in the overview database. Similar to -m, but specifically for updating.
-v
Enables verbose output, showing more detailed information about the utility's operations.
-A
Audits the entire overview database for any inconsistencies or problems.
-C character
Specifies the character set to use for the overview database. This is useful for handling articles with non-ASCII characters.
-D
Dumps the entire overview database content to standard output.
-I message-id
Inserts a new article into the overview database. The message-id should be the message ID of the article to insert.
-L
Lists all available fields in the overview database.
-N value
Sets the maximum number of articles to retrieve or process. This option is often used in conjunction with other filtering options.
-O file
Reads article information from the specified file and adds it to the overview database. This is typically used when importing articles from an external source.
-P field
Specifies a field to print when dumping or displaying article information.
-R field
Specifies a field to remove or reset when modifying or updating entries.
-S
Performs a sanity check on the overview database.
-T field
Specifies a field to set when adding or modifying entries.
-X
Excludes specific articles from the operation. This option is often used with ranges or other filtering criteria.
-Z
Archives old overview database entries. This is typically used for maintenance and to manage the size of the database.

EXAMPLES

Dump the entire overview database for example.test:

ovsqlite-util -o -n example.test

Dump the overview information for articles 45 and higher in example.test:

ovsqlite-util -o -n example.test -a 45-

Audit the entire overview database for any problems:

ovsqlite-util -A
