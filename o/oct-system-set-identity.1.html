NOMBRE

oct-system-set-identity - Cambiar identidad (solo Nitrokey Start)

SINOPSIS

oct system set-identity <-c|--card> [-h|--help] <identidad>

DESCRIPCIÓN

Cambiar identidad (solo Nitrokey Start)

Un dispositivo Nitrokey Start contiene tres tarjetas OpenPGP virtuales distintas; selecciona la identidad de la tarjeta virtual para activarla.

OPCIONES

-c, --card=ident_tarjeta
Identificador de la tarjeta a usar
-h, --help
Imprimir ayuda (ver un resumen con '-h')
<identidad>
Identidad de la tarjeta virtual a activar

[posibles valores: 0, 1, 2]
