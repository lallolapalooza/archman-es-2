NOMBRE

/etc/odbcinst.ini - Archivo de configuración de controladores de unixODBC

DESCRIPCIÓN

/etc/odbcinst.ini es un archivo de configuración para los controladores de unixODBC.

El archivo se puede actualizar usando la utilidad odbcinst (recomendado) o editándolo manualmente.

FORMATO DEL ARCHIVO

El formato general de archivo .ini es:

[NombreSeccion1]
clave1 = valor1
clave2 = valor2
...
[NombreSeccion2]
clave1 = valor1
clave2 = valor2
...

Cada controlador ODBC tiene su propia sección y puede ser referenciado por el nombre de esa sección en archivos como odbc.ini. Dentro de cada sección, unixODBC también reconoce las siguientes claves de configuración:

Descripción
Una cadena de texto que describe brevemente el controlador.
Controlador
Una ruta en el sistema de archivos a la biblioteca real del controlador.
Configuración
Una ruta en el sistema de archivos a la biblioteca de configuración del controlador.
UsoArchivo
La sección llamada [ODBC] configura opciones globales. Las claves reconocidas en la sección [ODBC] incluyen:
Rastreo
Habilita la salida de rastreo del controlador ODBC, que se escribe en la ruta de archivo especificada por ArchivoRastreo.

Algunos controladores ODBC tienen sus propias opciones de control de rastreo. A diferencia de la opción Rastreo, estas opciones separadas generalmente se especifican a nivel del Nombre de Origen de Datos (DSN).

Rastreo se habilitará si el valor correspondiente contiene alguna variante de mayúsculas/minúsculas de "1", "y", "yes" o "on".

ArchivoRastreo
Especifica la ruta del sistema o patrón de ruta a la que se escribirá la salida de rastreo del controlador ODBC. Esta opción no tiene ningún efecto a menos que Rastreo esté habilitado. La ubicación predeterminada del archivo para la salida de rastreo es /tmp/sql.log.

ADVERTENCIA: Establecer ArchivoRastreo a una ruta escribible por varios usuarios podría no funcionar correctamente, ya que solo el primer usuario podrá crear y abrir el archivo.

ARCHIVOS DE PLANTILLA

Muchos controladores ODBC vienen con plantillas de archivos .ini, que pueden instalarse usando la utilidad odbcinst.

Los archivos de plantilla usan el mismo formato que odbcinst.ini.

EJEMPLOS

Para instalar el controlador PostgreSQL de unixODBC, la siguiente configuración se puede ingresar en odbcinst.ini:

[PostgreSQL]
Descripción = Controlador PostgreSQL para GNU/Linux
Controlador = /usr/lib/psqlodbcw.so
Configuración = /usr/lib/libodbcpsqlS.so
UsoArchivo = 1

Las rutas del controlador pueden variar, dependiendo de su sistema operativo y de si su distribución tiene habilitado multi-arquitectura. Algunos controladores también requieren entradas Controlador64 y Configuración64.

La sección anterior puede ser referenciada en odbc.ini de la siguiente manera:

Controlador = PostgreSQL

La forma recomendada de agregar el controlador PostgreSQL a su sistema es creando un archivo de plantilla que contenga:

[PostgreSQL]
Descripción = Controlador PostgreSQL para GNU/Linux
Controlador = /usr/lib/psqlodbcw.so
Configuración = /usr/lib/libodbcpsqlS.so

y llamando a odbcinst de la siguiente manera:

# odbcinst -i -d -f plantilla.ini
