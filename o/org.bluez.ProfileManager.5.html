Métodos

void RegistrarPerfil(objeto perfil, cadena uuid, diccionario opciones)

Registra el agente del perfil.

La ruta del objeto define la ruta del perfil que se llamará cuando haya una conexión y debe implementar la interfaz org.bluez.Profile(5).

Si una aplicación se desconecta del bus, todos sus perfiles registrados se eliminarán.

Valores posibles de uuid:

"0000111f-0000-1000-8000-00805f9b34fb"
HFP AG, perfil predeterminado. La versión es 1.7, las características del perfil son 0b001001 y el canal RFCOMM es 13. Se requiere autenticación.
"0000111e-0000-1000-8000-00805f9b34fb"
HFP HS, perfil predeterminado. La versión es 1.7, las características del perfil son 0b000000 y el canal RFCOMM es 7. Se requiere autenticación.
"00001112-0000-1000-8000-00805f9b34fb"
HSP AG, perfil predeterminado. La versión es 1.2, el canal RFCOMM es 12 y se requiere autenticación. No admite características, la opción se ignora.
"00001108-0000-1000-8000-00805f9b34fb"
HSP HS, perfil predeterminado. La versión es 1.2, las características del perfil son 0b0 y el canal RFCOMM es 6. Se requiere autenticación.

Las características son un valor de bit, especifica la capacidad de control de volumen remoto (por defecto desactivado).

"<UUID del proveedor>"
UUID definido por el proveedor, sin valores predeterminados, se deben establecer opciones.

Valores posibles de opciones:

cadena Nombre
Nombre legible para humanos para el perfil
cadena Servicio
El UUID de la clase de servicio principal (si es diferente del UUID real del perfil).
cadena Rol
Para perfiles asimétricos que no tienen UUIDs disponibles para identificar únicamente cada lado, este parámetro permite especificar el rol local preciso.

Valores posibles:

"cliente"
"servidor"
uint16 Canal
Número de canal RFCOMM que se utiliza para los UUIDs de cliente y servidor.

Si es aplicable, también se utilizará en el registro SDP.

uint16 PSM
Número PSM que se utiliza para los UUIDs de cliente y servidor.

Si es aplicable, también se utilizará en el registro SDP.

booleano RequerirAutenticacion
Se requiere emparejamiento antes de que se establezcan las conexiones.

No se conectarán dispositivos si no están emparejados.

booleano RequerirAutorizacion
Solicita autorización antes de que se establezca cualquier conexión.
booleano ConexionAutomatica
En el caso de un UUID de cliente, esto forzará la conexión de los canales RFCOMM o L2CAP cuando se conecte un dispositivo remoto.
cadena RegistroServicio
Proporciona un registro SDP manual.
uint16 Version
Versión del perfil (para el registro SDP)
uint16 Caracteristicas
Características del perfil (para el registro SDP)

Errores posibles:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.YaExiste

void AnularRegistroPerfil(objeto perfil)

Anula el registro del objeto de perfil que se registró previamente usando RegistrarPerfil.

El parámetro de ruta del objeto debe coincidir con el mismo valor que se utilizó en el registro.

Errores posibles:

org.bluez.Error.NoExiste
