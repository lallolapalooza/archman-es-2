NOMBRE

openssl-crl - Comando CRL

SINOPSIS

openssl crl [-help] [-inform DER|PEM] [-outform DER|PEM] [-key nombre_archivo] [-keyform DER|PEM|P12] [-dateopt] [-text] [-in nombre_archivo] [-out nombre_archivo] [-gendelta nombre_archivo] [-badsig] [-verify] [-noout] [-hash] [-hash_old] [-fingerprint] [-crlnumber] [-issuer] [-lastupdate] [-nextupdate] [-nameopt opción] [-CAfile archivo] [-no-CAfile] [-CApath dir] [-no-CApath] [-CAstore uri] [-no-CAstore] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]key=valor] [-propquery propq]

DESCRIPCIÓN

Este comando procesa archivos CRL en formato DER o PEM.

OPCIONES

-help
Muestra un mensaje de uso.
-inform DER|PEM
El formato de entrada de la CRL; no especificado por defecto. Ver openssl-format-options(1) para detalles.
-outform DER|PEM
El formato de salida de la CRL; el valor por defecto es PEM. Ver openssl-format-options(1) para detalles.
-key nombre_archivo
La clave privada a utilizar para firmar la CRL.
-keyform DER|PEM|P12
El formato del archivo de clave privada; no especificado por defecto. Ver openssl-format-options(1) para detalles.
-in nombre_archivo
Especifica el nombre del archivo de entrada para leer o la entrada estándar si no se especifica esta opción.
-out nombre_archivo
Especifica el nombre del archivo de salida para escribir o la salida estándar por defecto.
-gendelta nombre_archivo
Genera una comparación de la CRL principal y la especificada aquí.
-badsig
Corrompe la firma antes de escribirla; esto puede ser útil para pruebas.
-dateopt
Especifica el formato de salida de la fecha. Los valores son: rfc_822 e iso_8601. El valor por defecto es rfc_822.
-text
Muestra la CRL en formato de texto.
-verify
Verifica la firma en la CRL. Si la verificación falla, el programa saldrá inmediatamente, es decir, se omitirá el procesamiento de opciones adicionales (por ejemplo, -gendelta).

Esta opción se activa implícitamente si se especifica alguna de las opciones -CApath, -CAfile o -CAstore.

-noout
No muestra la versión codificada de la CRL.
-fingerprint
Muestra la huella digital de la CRL.
-crlnumber
Muestra el número de la CRL.
-hash
Muestra un hash del nombre del emisor. Esto puede usarse para buscar CRLs en un directorio por nombre de emisor.
-hash_old
Muestra el "hash" del nombre del emisor de la CRL utilizando el algoritmo más antiguo utilizado por OpenSSL antes de la versión 1.0.0.
-issuer
Muestra el nombre del emisor.
-lastupdate
Muestra el campo lastUpdate.
-nextupdate
Muestra el campo nextUpdate.
-nameopt opción
Esto especifica cómo se muestran los nombres del sujeto o emisor. Ver openssl-namedisplay-options(1) para detalles.
-CAfile archivo, -no-CAfile, -CApath dir, -no-CApath, -CAstore uri, -no-CAstore
Ver "Trusted Certificate Options" en openssl-verification-options(1) para detalles.
-provider nombre
-provider-path ruta
-provparam [nombre:]key=valor
-propquery propq
Ver "Provider Options" en openssl(1), provider(7), y property(7).

EJEMPLOS

Convertir un archivo CRL de PEM a DER:

openssl crl -in crl.pem -outform DER -out crl.der

Mostrar el formato de texto de un certificado codificado en DER:

openssl crl -in crl.der -text -noout

BUGS

Idealmente, debería ser posible crear una CRL utilizando opciones y archivos apropiados.

VER TAMBIÉN

openssl(1), openssl-crl2pkcs7(1), openssl-ca(1), openssl-x509(1), ossl_store-file(7)

HISTORIAL

Desde OpenSSL 3.3, la opción -verify saldrá con 1 en caso de fallo.

NOMBRE

openssl-crl - Manejar listas de revocación de certificados (CRL)

SINOPSIS

openssl crl -in file -out file -hash_serial -set_serial -m dname -new -text -pretty -fingerprint -dates -subject -issuer -serial -reason -expire -noout -load_cert_crl -CRL2PKCS7 -PKCS72CRL -Crl_sign -signkey file -digest algorithm -verifysig -next_update file -last_update file -copysig -crl_number number -set_issuer -days days -cert file -CAfile file -CApath dir -engine id

DESCRIPCIÓN

El comando openssl crl se utiliza para gestionar Listas de Revocación de Certificados (CRL).

OPCIONES

  • -in file: Especifica el archivo de entrada.
  • -out file: Especifica el archivo de salida.
  • -hash_serial: Calcula el hash SHA1 del nombre distinguido del emisor y el número de serie del certificado para usarlo como nombre de archivo.
  • -set_serial: Establece el número de serie del certificado a revocar.
  • -m dname: Establece el nombre distinguido del emisor.
  • -new: Crea una nueva CRL.
  • -text: Muestra la CRL en formato de texto legible.
  • -pretty: Muestra la CRL en un formato más legible.
  • -fingerprint: Muestra la huella digital de la CRL.
  • -dates: Muestra las fechas de actualización de la CRL.
  • -subject: Muestra el sujeto de los certificados revocados.
  • -issuer: Muestra el emisor de la CRL.
  • -serial: Muestra el número de serie de los certificados revocados.
  • -reason: Muestra la razón de la revocación.
  • -expire: Muestra la fecha de expiración de la CRL.
  • -noout: No muestra la CRL codificada.
  • -load_cert_crl: Carga un certificado o CRL en un objeto.
  • -CRL2PKCS7: Convierte una CRL a un formato PKCS#7.
  • -PKCS72CRL: Convierte un formato PKCS#7 a una CRL.
  • -Crl_sign: Firma la CRL.
  • -signkey file: Especifica la clave privada para firmar la CRL.
  • -digest algorithm: Especifica el algoritmo de digestión para firmar la CRL.
  • -verifysig: Verifica la firma de la CRL.
  • -next_update file: Especifica el archivo que contiene la fecha de la próxima actualización.
  • -last_update file: Especifica el archivo que contiene la fecha de la última actualización.
  • -copysig: Copia la firma de la CRL de entrada a la CRL de salida.
  • -crl_number number: Establece el número de CRL.
  • -set_issuer: Establece el emisor de la CRL.
  • -days days: Establece el número de días hasta la expiración.
  • -cert file: Especifica el certificado del emisor.
  • -CAfile file: Especifica el archivo de certificados de autoridad certificadora (CA).
  • -CApath dir: Especifica el directorio de certificados CA.
  • -engine id: Especifica el motor de encriptación a usar.

EJEMPLOS

Crear una nueva CRL y añadir un certificado revocado:

openssl crl -new -days 365 -set_serial 123456 -m "CN=My CA" -hash_serial -out ca.crl

Mostrar el contenido de una CRL en formato de texto:

openssl crl -in ca.crl -text -noout

Convertir una CRL a formato PKCS#7:

openssl crl -in ca.crl -CRL2PKCS7 -out ca.pkcs7

ERRORES

Los errores conocidos pueden consultarse en la página de errores de OpenSSL.
