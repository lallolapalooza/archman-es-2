NOMBRE

Local_Config - Esquema de la base de datos Local_Config

Esta base de datos es para la configuración local de un ovsdb-server. La base de datos está pensada para ser única, incluso entre múltiples servidores de base de datos agrupados, de modo que la configuración que es local a ese servidor se pueda configurar por separado (por ejemplo, información de conexión).

TABLA Config

La tabla raíz de configuración local para un ovsdb-server. Esta tabla debe tener exactamente una fila.

Clientes de base de datos a los que el servidor de base de datos Open vSwitch debe conectarse o en los que debe escuchar, junto con opciones sobre cómo deben configurarse estas conexiones. Consulte la tabla Connection para obtener más información.

TABLA Connection

Configuración de una conexión de base de datos a un cliente de base de datos Open vSwitch (OVSDB).

Esta tabla configura principalmente el servidor de base de datos Open vSwitch (ovsdb-server).

El servidor de base de datos Open vSwitch puede iniciar y mantener conexiones activas a clientes remotos. También puede escuchar conexiones de base de datos.

Detalles:

Características Principales:
target: cadena (debe ser única en la tabla)
Métodos de conexión para clientes.
Actualmente se admiten los siguientes métodos de conexión:
ssl:host[:puerto]
El puerto SSL/TLS especificado en el host dado host, que puede ser un nombre DNS (si está compilado con la biblioteca unbound) o una dirección IP. Se debe proporcionar una configuración SSL/TLS válida cuando se utiliza esta forma; esta configuración se puede especificar a través de opciones de línea de comandos o la tabla SSL.
Si no se especifica puerto, el valor predeterminado es 6640.
El soporte SSL/TLS es una característica opcional que no siempre se incluye como parte de Open vSwitch.
tcp:host[:puerto]
El puerto TCP especificado en el host dado host, que puede ser un nombre DNS (si está compilado con la biblioteca unbound) o una dirección IP. Si host es una dirección IPv6, envuélvala entre corchetes, por ejemplo, tcp:[::1]:6640.
Si no se especifica puerto, el valor predeterminado es 6640.
pssl:[puerto][:host]
Escucha conexiones SSL/TLS en el puerto TCP especificado puerto. Especifique 0 para puerto para que el kernel elija automáticamente un puerto disponible. Si se especifica host, que puede ser un nombre DNS (si está compilado con la biblioteca unbound) o una dirección IP, las conexiones se restringen a la dirección IP local resuelta o especificada (ya sea una dirección IPv4 o IPv6). Si host es una dirección IPv6, envuélvala entre corchetes, por ejemplo, pssl:6640:[::1]. Si no se especifica host, entonces escucha solo en direcciones IPv4 (pero no IPv6). Se debe proporcionar una configuración SSL/TLS válida cuando se utiliza esta forma, esto se puede especificar a través de opciones de línea de comandos o la tabla SSL.
Si no se especifica puerto, el valor predeterminado es 6640.
El soporte SSL/TLS es una característica opcional que no siempre se incluye como parte de Open vSwitch.
ptcp:[puerto][:host]
Escucha conexiones en el puerto TCP especificado puerto. Especifique 0 para puerto para que el kernel elija automáticamente un puerto disponible. Si se especifica host, que puede ser un nombre DNS (si está compilado con la biblioteca unbound) o una dirección IP, el
a las direcciones IP locales resueltas o especificadas (ya sean IPv4 o IPv6). Si host es una dirección IPv6, envuélvala entre corchetes, por ejemplo, ptcp:6640:[::1]. Si host no se especifica, solo escucha en direcciones IPv4.
Si port no se especifica, se usa el valor predeterminado 6640.
Cuando se configuran varios clientes, los valores de target deben ser únicos. Los valores duplicados de target producen resultados no especificados.
read_only: booleano
true para restringir estas conexiones a transacciones de solo lectura, false para permitirles modificar la base de datos.
role: cadena
Cadena que contiene el nombre del rol para esta entrada de conexión.
Detección y manejo de fallos del cliente:
max_backoff: entero opcional, como mínimo 1,000
Número máximo de milisegundos de espera entre intentos de conexión. El valor predeterminado depende de la implementación.
inactivity_probe: entero opcional
Número máximo de milisegundos de tiempo inactivo en la conexión con el cliente antes de enviar un mensaje de sondeo de inactividad. Si Open vSwitch no se comunica con el cliente durante el número especificado de segundos, enviará un sondeo. Si no se recibe respuesta durante la misma cantidad adicional de tiempo, Open vSwitch asume que la conexión se ha roto e intenta reconectar. El valor predeterminado depende de la implementación. Un valor de 0 deshabilita los sondeos de inactividad.
Estado:

El par clave-valor is_connected se actualiza siempre. Otros pares clave-valor en las columnas de estado pueden actualizarse dependiendo del tipo de target.

Cuando target especifica un método de conexión que escucha conexiones entrantes (por ejemplo, ptcp: o punix:), tanto n_connections como is_connected pueden actualizarse mientras que los pares clave-valor restantes se omiten.

Por otro lado, cuando target especifica una conexión saliente, todos los pares clave-valor pueden actualizarse, excepto los dos pares clave-valor mencionados anteriormente asociados con objetivos de conexión entrante. Estos se omiten.

is_connected: booleano
true si está actualmente conectado a este cliente, false en caso contrario.
status : last_error: cadena opcional
Una descripción legible por humanos del último error en la conexión con el gestor; es decir, strerror(errno). Esta clave existirá solo si ha ocurrido un error.
status : state: cadena opcional, uno de ACTIVE, BACKOFF, CONNECTING, IDLE o VOID
El estado de la conexión con el gestor:
VOID
La conexión está deshabilitada.
BACKOFF
Intentando reconectar a un período creciente.
CONNECTING
Intentando conectar.
ACTIVE
Conectado, el host remoto responde.
IDLE
La conexión está inactiva. Esperando respuesta de mantenimiento.
Estos valores pueden cambiar en el futuro. Se proporcionan solo para ser comprendidos por humanos.
status : sec_since_connect: cadena opcional, que contiene un entero, como mínimo 0
El tiempo transcurrido desde que este cliente se conectó exitosamente por última vez a la base de datos (en segundos). El valor está vacío si el cliente nunca se ha conectado exitosamente.
status : sec_since_disconnect: cadena opcional, que contiene un entero, como mínimo 0
El tiempo transcurrido desde que este cliente se desconectó por última vez de la base de datos (en segundos). El valor está vacío si el cliente nunca se ha desconectado.
status : locks_held: cadena opcional
Lista separada por espacios de los nombres de los bloqueos OVSDB que la conexión mantiene. Se omite si la conexión no mantiene ningún bloqueo.
status : locks_waiting: cadena opcional
Lista separada por espacios de los nombres de los bloqueos OVSDB que la conexión está esperando adquirir actualmente. Se omite si la conexión no está esperando ningún bloqueo.
status : locks_lost: cadena opcional
Lista separada por espacios de los nombres de los bloqueos OVSDB que han sido robados a esta conexión por otro cliente OVSDB. Se omite si no se han robado bloqueos a esta conexión.
status : n_connections: cadena opcional, que contiene un entero, como mínimo 2
Cuando target especifica un método de conexión que escucha conexiones entrantes (por ejemplo, ptcp: o pssl:) y más de una conexión está realmente activa, el valor es el número de conexiones activas. De lo contrario, este par clave-valor se omite.
status : bound_port: cadena opcional, que contiene un entero
Cuando target es ptcp: o pssl:, este es el puerto TCP en el que el servidor OVSDB está escuchando. (Esto es particularmente útil cuando target especifica un puerto de 0, permitiendo al kernel elegir cualquier puerto disponible).
Parámetros de conexión:
other_config : dscp: cadena opcional, que contiene un entero
El Punto de Código de Servicio Diferenciado (DSCP) se especifica utilizando 6 bits en el campo Tipo de Servicio (TOS) en la cabecera IP. DSCP proporciona un mecanismo para clasificar el tráfico de red y proporcionar Calidad de Servicio (QoS) en redes IP. El valor DSCP especificado aquí se utiliza al establecer la conexión entre el gestor y Open vSwitch. Si no se especifica ningún valor, se elige un valor predeterminado de 48. Los valores DSCP válidos deben estar en el rango de 0 a 63.
