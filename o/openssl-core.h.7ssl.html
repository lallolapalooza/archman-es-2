NOMBRE

openssl/core.h - Tipos centrales de OpenSSL

SINOPSIS

#include <openssl/core.h>

DESCRIPCIÓN

El archivo de cabecera <openssl/core.h> define una serie de tipos públicos que se utilizan para la comunicación entre las bibliotecas de OpenSSL y los proveedores de implementación. Estos tipos están diseñados para minimizar la necesidad de un conocimiento íntimo de las estructuras internas entre las bibliotecas de OpenSSL y los proveedores.

Los tipos son:

OSSL_DISPATCH(3)
OSSL_ITEM(3)
OSSL_ALGORITHM(3)
OSSL_PARAM(3)
OSSL_CALLBACK(3)
OSSL_PASSPHRASE_CALLBACK(3)

VER TAMBIÉN

openssl-core_dispatch.h(7)

HISTORIAL

Los tipos descritos aquí se añadieron en OpenSSL 3.0.
