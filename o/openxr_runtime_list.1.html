OPENXR_RUNTIME_LIST(1) Manual de comandos generales OPENXR_RUNTIME_LIST(1)

NOMBRE

openxr_runtime_list — Una aplicación mínima de OpenXR que informa sobre información de tu runtime de OpenXR

SINOPSIS

openxr_runtime_list

DESCRIPCIÓN

openxr_runtime_list es una aplicación mínima de línea de comandos escrita utilizando la API de OpenXR.

No acepta argumentos. Al iniciar, se conecta a tu runtime de OpenXR (si está disponible) e informa los siguientes datos:

  • Nombre del sistema
  • ID del proveedor del sistema
  • ID del sistema
  • Extensiones de instancia disponibles y sus versiones.

CÓDIGO DE SALIDA

La utilidad openxr_runtime_list sale con 0 en caso de éxito, y >0 si ocurre un error.
