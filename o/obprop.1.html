NOMBRE

obprop — imprime propiedades moleculares estándar

SINOPSIS

obprop nombre_archivo

DESCRIPCIÓN

El programa obprop es una herramienta para imprimir un conjunto de propiedades moleculares estándar para todas las moléculas en un archivo. También sirve como código de ejemplo para usar la biblioteca Open Babel (libopenbabel).

El formato de salida incluye:
nombre [Nombre]
fórmula [Fórmula]
peso_mol [Peso Molecular]
masa_exacta [Masa Isotópica]
SMILES_canónico [Cadena]
num_átomos [Número]
num_enlaces [Número]
num_residuos [Número]
secuencia [Secuencia de Residuos]
num_anillos [Número de Anillos (por SSSR)]
logP [Número (partición octanol-agua)]
PSA [Número (área de superficie polar topológica)]
MR [Número (refractividad molar)]
$$$

El "$$$" es el separador entre múltiples entradas moleculares en un archivo

EJEMPLOS

obprop piridinas.sdf

VER TAMBIÉN

obabel(1), obchiral(1), obfit(1), obgrep(1), obrotate(1).
