Nombre

org.bluez.Network - Documentación de la API de Red D-Bus de BlueZ

Interfaz

Servicio
org.bluez
Interfaz
org.bluez.Network1
Ruta de objeto
[prefijo de variable]/{hci0,hci1,...}/dev_{BDADDR}

Métodos

cadena Conectar(cadena uuid)

Se conecta al dispositivo de red y devuelve el nombre de la interfaz de red.

Valores posibles de uuid:

"panu", "00001115-0000-1000-8000-00805f9b34fb"
Rol de Usuario de Red Personal.
"nap", "00001116-0000-1000-8000-00805f9b34fb"
Rol de Punto de Acceso a Red.
"gn", "00001117-0000-1000-8000-00805f9b34fb"
Rol de Red de Grupo.

La conexión se cerrará y el dispositivo de red se liberará al llamar a Desconectar() o cuando el cliente desaparezca del bus de mensajes.

Errores posibles:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.NoSoportado
org.bluez.Error.EnProgreso
org.bluez.Error.Fallo

vacío Desconectar()

Se desconecta del dispositivo de red.

Para abortar un intento de conexión en caso de errores o tiempos de espera en el cliente, se puede llamar a este método.

Errores posibles:

org.bluez.Error.Fallo
org.bluez.Error.NoConectado

Propiedades

booleano Conectado [solo lectura]

Indica si el dispositivo está conectado.

cadena Interfaz [solo lectura, opcional]

Indica el nombre de la interfaz de red cuando esté disponible.

cadena UUID [solo lectura, opcional]

Indica el rol de conexión cuando esté disponible.
