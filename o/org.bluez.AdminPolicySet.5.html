Nombre

org.bluez.AdminPolicySet - Documentación de la API AdminPolicySet de BlueZ D-Bus

Descripción

Esta API proporciona métodos para controlar el comportamiento de bluetoothd(8) como administrador.

La interfaz AdminPolicySet1 proporciona métodos para establecer políticas. Una vez que la política se establece correctamente, afectará a todos los clientes y permanecerá persistentemente incluso después de reiniciar bluetoothd(8). La única forma de borrarla es sobrescribir la política con el mismo método.

Interfaz

Servicio
org.bluez
Interfaz
org.bluez.AdminPolicySet1 [experimental]
Objeto
[prefijo variable]/{hci0,hci1,...}

Métodos

void SetServiceAllowList(array{string} UUIDs)

Establece la lista de servicios permitidos especificando UUIDs de servicios.

Cuando se llama, bluetoothd(8) bloqueará las conexiones entrantes y salientes al servicio no incluido en UUIDs para todos los clientes.

Cualquier llamada posterior a este método sustituirá cualquier valor de lista de permitidos previamente establecido. Llamar a este método con un array vacío permitirá el uso de cualquier UUID de servicio.

El valor predeterminado es un array vacío.
