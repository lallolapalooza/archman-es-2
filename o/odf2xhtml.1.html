ODF2XHTML(1) Comandos de usuario ODF2XHTML(1)



NOMBRE
odf2xhtml - Convertir ODF a HTML



SINOPSIS

odf2xhtml [-p] ruta



DESCRIPCIÓN

odf2xhtml es un programa que creará una página web (.html) a partir del archivo de entrada y escribirá la página web a la salida estándar.

"Ruta" se asume que es un archivo OpenDocument de tipo texto, hoja de cálculo o presentación.



OPCIONES

-p, --plain

La opción -p generará HTML sin CSS.



EJEMPLO

odf2xhtml archivo-odf
