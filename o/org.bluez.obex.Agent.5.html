Interfaz

nombre único
Interfaz

Métodos

void Release()

Este método se llama cuando el demonio obexd(8) desregistra el agente.

Un agente puede usarlo para realizar tareas de limpieza. No es necesario desregistrar el agente, porque cuando se llama a este método ya ha sido desregistrado.

string AuthorizePush(object transfer)

Este método se llama cuando obexd(8) necesita aceptar/rechazar una solicitud de envío de objetos Bluetooth.

Devuelve la ruta completa (incluyendo el nombre del archivo) o el nombre de la carpeta con el sufijo '/' donde se almacenará el objeto.

El objeto de transferencia, ver org.bluez.obex.Transfer(5) contendrá una propiedad `Filename` que contiene la ubicación y el nombre predeterminados que se pueden devolver.

Errores posibles:

org.bluez.obex.Error.Rejected
org.bluez.obex.Error.Canceled

void Cancel()

Este método se llama para indicar que la solicitud del agente falló antes de que se devolviera una respuesta. Cancela la solicitud anterior.
