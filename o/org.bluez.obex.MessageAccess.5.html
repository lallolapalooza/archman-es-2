array{object, dict} ListMessages(string folder, dict filter)

Devuelve una matriz que contiene los objetos de mensajes encontrados en la subcarpeta dada de la carpeta actual, o en la carpeta actual si la carpeta está vacía.

Filtros posibles:

uint16 Offset (por defecto 0)
Desplazamiento del primer elemento.

uint16 MaxCount (por defecto 1024):

Número máximo de elementos.
byte SubjectLength (por defecto 256)
Longitud máxima de la propiedad Subject en el mensaje.
array{string} Fields
Campos del mensaje, por defecto son todos los valores.

Ver ListFilterFields() para valores posibles.

array{string} Types
Filtra los mensajes por tipo.

Valores posibles:

"sms"
"email"
"mms"
string PeriodBegin
Filtra los mensajes por período de inicio.

Valores posibles:

Fecha en formato "YYYYMMDDTHHMMSS".
string PeriodEnd
Filtra los mensajes por período de fin.

Valores posibles:

Fecha en formato "YYYYMMDDTHHMMSS".
boolean Read
Filtra los mensajes por el indicador de lectura.

Valores posibles:

True para leído o False para no leído
string Recipient
Filtra los mensajes por la dirección del destinatario.
string Sender
Filtra los mensajes por la dirección del remitente.
boolean Priority
Filtra los mensajes por el indicador de prioridad.

Valores posibles:

True para alta prioridad o False para no alta prioridad.

Cada mensaje está representado por una ruta de objeto, que implementa la interfaz org.bluez.obex.Message(5), seguida de un diccionario de sus propiedades.

void UpdateInbox(void)

Solicita al dispositivo remoto que actualice su bandeja de entrada.

Errores posibles:

org.bluez.obex.Error.Failed

object, dict PushMessage(string sourcefile, string folder, dict args)

Transfiere un mensaje (en formato bMessage) al dispositivo remoto.

El mensaje se transfiere ya sea a la subcarpeta dada de la carpeta actual, o a la carpeta actual si la carpeta está vacía.

Args posibles: Transparent, Retry, Charset

La ruta devuelta representa la transferencia recién creada, que debe utilizarse para averiguar si el contenido se ha transferido con éxito o si la operación falla.

Las propiedades de esta transferencia también se devuelven junto con la ruta del objeto, para evitar una llamada a GetProperties, ver org.bluez.obex.Transfer(5) para la lista posible de propiedades.

Errores posibles:

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed

Propiedades

Lista de tipos de mensajes admitidos.

Valores posibles:

"EMAIL"
Mensajes de correo electrónico.
"SMS_GSM"
Mensajes cortos GSM.
"SMS_CDMA"
Mensajes cortos CDMA.
"MMS"
Mensajes MMS.
"IM"
Mensajería instantánea.
