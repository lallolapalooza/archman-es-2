NOMBRE

openssl-dhparam - Manipulación y generación de parámetros DH

SINOPSIS

openssl dhparam [-help] [-inform DER|PEM] [-outform DER|PEM] [-in archivo] [-out archivo] [-dsaparam] [-check] [-noout] [-text] [-verbose] [-quiet] [-2] [-3] [-5] [-engine id] [-rand archivos] [-writerand archivo] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq] [numbits]

DESCRIPCIÓN

Este comando se utiliza para manipular archivos de parámetros DH.

Ver "EJEMPLOS" en openssl-genpkey(1) para ejemplos sobre cómo generar una clave usando un grupo de primos seguros nombrados sin generar parámetros intermedios.

OPCIONES

-help
Imprime un mensaje de uso.
-inform DER|PEM, -outform DER|PEM
El formato de entrada y el formato de salida; el predeterminado es PEM. El objeto es compatible con la estructura DHparameter de PKCS#3. Ver openssl-format-options(1) para detalles.
-in archivo
Especifica el archivo de entrada del que leer los parámetros o la entrada estándar si no se especifica esta opción.
-out archivo
Especifica el archivo de salida al que escribir los parámetros. La salida estándar se usa si esta opción no está presente. El nombre del archivo de salida puede ser el mismo que el nombre del archivo de entrada, lo que resulta en el reemplazo del contenido del archivo. Tenga en cuenta que la E/S de archivos no es atómica. El archivo de salida se trunca y luego se escribe.
-dsaparam
Si se usa esta opción, se leen o crean parámetros DSA en lugar de DH; se convierten al formato DH. De lo contrario, se usarán primos seguros (tales que (p-1)/2 también sea primo) para la generación de parámetros DH.

La generación de parámetros DH con la opción -dsaparam es mucho más rápida. Tenga cuidado, ya que con tales parámetros DH de estilo DSA, se debe crear una clave DH nueva para cada uso para evitar ataques de subgrupo pequeño que de lo contrario podrían ser posibles.

-check
Realiza numerosas comprobaciones para ver si los parámetros proporcionados son válidos y muestra una advertencia si no lo son.
-2, -3, -5
El generador a usar, ya sea 2, 3 o 5. Si está presente, se ignora el archivo de entrada y se generan parámetros en su lugar. Si no está presente pero numbits está presente, se generan parámetros con el generador predeterminado 2.
numbits
Esta opción especifica que se debe generar un conjunto de parámetros de tamaño numbits. Debe ser la última opción. Si esta opción está presente, se ignora el archivo de entrada y se generan parámetros en su lugar. Si esta opción no está presente pero sí un generador (-2, -3 o -5), se generan parámetros con una longitud predeterminada de 2048 bits. La longitud mínima es de 512 bits. La longitud máxima es de 10000 bits.
-noout
Esta opción inhibe la salida de la versión codificada de los parámetros.
-text
Esta opción imprime los parámetros DH en formato legible para humanos.
-engine id
Ver "Opciones de Motor" en openssl(1). Esta opción está obsoleta.
-rand archivos, -writerand archivo
Ver "Opciones de Estado Aleatorio" en openssl(1) para detalles.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Ver "Opciones de Proveedor" en openssl(1), provider(7) y property(7).
-verbose
Esta opción habilita la salida de mensajes de progreso, lo cual es útil cuando se ejecutan comandos interactivos que pueden tardar mucho en ejecutarse.
-quiet
Esta opción suprime la salida de mensajes de progreso, lo cual puede ser indeseable en scripts o tuberías por lotes.

NOTAS

Este comando reemplaza a los comandos dh y gendh de versiones anteriores.

VER TAMBIÉN

openssl(1), openssl-pkeyparam(1), openssl-dsaparam(1), openssl-genpkey(1).

HISTORIAL

La opción -engine fue obsoleta en OpenSSL 3.0.

La opción -C fue eliminada en OpenSSL 3.0.
