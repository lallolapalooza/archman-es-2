odbx_lo_open(3)

Paquete: opendbx

Licencias: LGPL

odbx_lo_open(3) OpenDBX odbx_lo_open(3)

NOMBRE

odbx_lo_open - Abre un objeto grande en la base de datos

SINOPSIS

#include <opendbx/api.h>


int odbx_lo_open
(odbx_result_t* result, odbx_lo_t** lo, const char* value);

DESCRIPCIÓN

Algunos sistemas de gestión de bases de datos almacenan grandes cantidades de datos en regiones separadas de la base de datos y el contenido solo se referencia mediante identificadores en las tablas. Los tipos de datos utilizados para esto se llaman Binary Large OBject (BLOB) y Character Large OBject (CLOB) y se pueden encontrar en, por ejemplo, los servidores de bases de datos Firebird y Oracle. La biblioteca OpenDBX proporciona una interfaz de objeto grande para acceder, leer y escribir su contenido a través de las funciones "odbx_lo_*()". Para averiguar si se puede acceder directamente a grandes cantidades de datos o si se debe usar la interfaz de objeto grande, odbx_capabilities() proporciona la respuesta cuando se le alimenta con ODBX_CAP_LO.

El parámetro result debe ser el objeto de resultado creado y devuelto por odbx_result(). Se vuelve inválido después de haber sido proporcionado a odbx_result_finish() y esta función devolverá un error en ese caso. El segundo parámetro, el puntero a un odbx_lo_t*, contendrá el identificador de objeto grande recién creado si odbx_lo_open() tiene éxito. El identificador lo es necesario para todas las demás funciones de la interfaz de objeto grande para que puedan realizar sus operaciones en el contenido referenciado. El último parámetro debe ser el valor de retorno de odbx_field_value(), pero debes verificar los valores NULL antes de alimentar el valor a odbx_lo_open(). De lo contrario, se devolverá un error.

VALOR DE RETORNO

odbx_lo_open() devuelve ODBX_ERR_SUCCESS, o un código de error cuyo valor es menor que cero si alguna de las operaciones no pudo completarse exitosamente. Los posibles códigos de error se enumeran en la sección de errores y se pueden alimentar a odbx_error() y odbx_error_type() para obtener más detalles.

ERRORES

-ODBX_ERR_BACKEND
La biblioteca de base de datos nativa no pudo abrir el objeto grande
-ODBX_ERR_NOMEM
Falló la asignación de memoria adicional requerida

VER TAMBIÉN

odbx_capabilities(), odbx_field_value(), odbx_lo_close(), odbx_lo_read(), odbx_lo_write(), odbx_result()
