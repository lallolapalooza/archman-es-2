odbx_column_type(3)

Paquete: opendbx

Licencias: LGPL

odbx_column_type(3) OpenDBX odbx_column_type(3)

NOMBRE

odbx_column_type - Devuelve el tipo de dato SQL de una columna en el conjunto de resultados actual

SINOPSIS

#include <opendbx/api.h>


int odbx_column_type
(odbx_result_t* result, unsigned long pos);

DESCRIPCIÓN

odbx_column_type() devuelve el tipo de dato de la columna solicitada dentro del conjunto de resultados actual devuelto por odbx_result(). El tipo de columna se aplica a todos los campos en la misma posición de las filas obtenidas a través de odbx_row_fetch(). Las definiciones se basan en el estándar SQL2003 y los tipos de datos del servidor de base de datos deben cumplir con la especificación del estándar. Los tipos de datos proporcionados por las implementaciones de bases de datos que no están cubiertos por el estándar SQL2003 se subsumen como ODBX_TYPE_UNKNOWN.

El parámetro de resultado requerido por esta función debe ser un conjunto de resultados válido devuelto por odbx_result() y no debe haber sido alimentado a odbx_result_finish() antes.

Los índices de columna válidos para la columna solicitada proporcionada a través de pos comienzan en cero y terminan con el valor devuelto por odbx_column_count() menos uno.

VALOR DE RETORNO

Si se devuelve un valor menor que cero, ocurrió un error. Los códigos de error posibles se enumeran en la sección de errores y la aplicación puede recuperar un mensaje textual del error llamando a odbx_error().

Un valor de retorno positivo, incluido cero, indica uno de los tipos de datos compatibles con SQL2003 enumerados a continuación. Antes de la versión 1.1.5 de la biblioteca OpenDBX, los tipos se definían como ODBX_* en lugar de ODBX_TYPE_*. Las definiciones antiguas se conservan por compatibilidad con versiones anteriores, pero ya no deben utilizarse. Se eliminarán en algún momento en el futuro.

Valores numéricos exactos:

•
ODBX_TYPE_BOOLEAN: Valores verdadero/falso
•
ODBX_TYPE_SMALLINT: Entero de 16 bits con signo
•
ODBX_TYPE_INTEGER: Entero de 32 bits con signo
•
ODBX_TYPE_BIGINT: Entero de 64 bits con signo
•
ODBX_TYPE_DECIMAL: Valores numéricos exactos con signo y precisión definida por el usuario

Valores numéricos aproximados:

•
ODBX_TYPE_REAL: Valores numéricos aproximados (con signo) con precisión de 32 bits
•
ODBX_TYPE_DOUBLE: Valores numéricos aproximados (con signo) con precisión de 64 bits
•
ODBX_TYPE_FLOAT: Valores numéricos aproximados (con signo) con precisión definida por el usuario

Valores de cadena:

•
ODBX_TYPE_CHAR: Número fijo de caracteres
•
ODBX_TYPE_NCHAR: Número fijo de caracteres utilizando un conjunto de caracteres nacional
•
ODBX_TYPE_VARCHAR: Número variable de caracteres
•
ODBX_TYPE_NVARCHAR: Número variable de caracteres utilizando un conjunto de caracteres nacional

Objetos grandes:

•
ODBX_TYPE_CLOB: Objeto de texto grande
•
ODBX_TYPE_NCLOB: Objeto de texto grande utilizando un conjunto de caracteres nacional
•
ODBX_TYPE_XML: Árbol XML en formato de texto
•
ODBX_TYPE_BLOB: Objeto binario grande

Valores de fecha y hora:

•
ODBX_TYPE_TIME: Hora incluyendo horas, minutos y segundos
•
ODBX_TYPE_TIME_TZ: Hora con información de zona horaria
•
ODBX_TYPE_TIMESTAMP: Fecha y hora
•
ODBX_TYPE_TIMESTAMP_TZ: Fecha y hora con información de zona horaria
•
ODBX_TYPE_DATE: Fecha incluyendo año, mes y día
•
ODBX_TYPE_INTERVAL: Intervalo de fecha

Arrays y conjuntos:

•
ODBX_TYPE_ARRAY: Array de valores
•
ODBX_TYPE_MULTISET: Arrays asociativos

Enlaces externos:

•
ODBX_TYPE_DATALINK: Localizadores URI como enlaces URL

Específico del proveedor:

•
ODBX_TYPE_UNKNOWN: Tipo de dato específico del proveedor sin representación en SQL2003

ERRORES

-ODBX_ERR_BACKEND
La biblioteca nativa de la base de datos devolvió un error
-ODBX_ERR_PARAM
El parámetro de resultado es NULL o inválido, o el valor de pos está fuera de rango
