NOMBRE

openmpt123 - reproductor de música de módulos en línea de comandos basado en libopenmpt

SINOPSIS

openmpt123 [opciones] [--] archivo1 [archivo2] ...

openmpt123(1)

NAME

openmpt123 - Playback of tracker modules using libopenmpt

SYNOPSIS

openmpt123 [options] [FILE...]

DESCRIPTION

openmpt123 is a command-line player for tracker modules (like .mod, .xm, .s3m, .it, etc.) using the libopenmpt library. It can play files individually or as a playlist.

OPTIONS

-h, --help
Show help message and exit.
-v, --version
Show version information and exit.
-l, --list
List supported file formats and exit.
-p, --playlist
Read file list from standard input.
-o, --output <device>
Audio output device (e.g., "auto", "alsa", "pulse", "jack", "dummy").
-d, --device <device>
Specific audio device name (e.g., "default" for ALSA, "0" for PulseAudio).
-f, --freq <rate>
Audio output frequency in Hz (default: 44100).
-b, --bits <bits>
Audio output bit depth (e.g., 16).
-c, --channels <channels>
Audio output channels (1 for mono, 2 for stereo).
-v, --volume <volume>
Playback volume (0.0 to 1.0).
-s, --seek <position>
Seek to position (in seconds or seconds.milliseconds).
-t, --timeout <seconds>
Exit after a specified number of seconds.
--no-play
Do not play, just process files (useful for testing).
--stdout
Output raw audio data to stdout.
