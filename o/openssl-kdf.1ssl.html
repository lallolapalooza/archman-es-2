NOMBRE

openssl-kdf - realizar operaciones de Función de Derivación de Clave

SINOPSIS

openssl kdf [-help] [-cipher] [-digest] [-mac] [-kdfopt nm:v] [-keylen num] [-out filename] [-binary] [-provider name] [-provider-path path] [-provparam [name:]key=value] [-propquery propq] kdf_name

DESCRIPCIÓN

Las funciones de derivación de claves generan una clave derivada a partir de un secreto o una contraseña.

OPCIONES

-help
Imprime un mensaje de uso.
-keylen num
El tamaño de salida de la clave derivada. Este campo es obligatorio.
-out filename
Nombre del archivo de salida, o salida estándar por defecto.
-binary
Salida de la clave derivada en formato binario. Utiliza formato de texto hexadecimal si no se especifica.
-cipher name
Especifica el cifrador a ser utilizado por el KDF. No todos los KDF requieren un cifrador y es un error usar esta opción en tales casos.
-digest name
Especifica el digest a ser utilizado por el KDF. No todos los KDF requieren un digest y es un error usar esta opción en tales casos. Para ver la lista de digest compatibles, use "openssl list -digest-commands".
-mac name
Especifica el MAC a ser utilizado por el KDF. No todos los KDF requieren un MAC y es un error usar esta opción en tales casos.
-kdfopt nm:v
Pasa opciones al algoritmo KDF. Una lista completa de parámetros se puede encontrar en "PARÁMETROS" en EVP_KDF(3). Nombres de parámetros comunes utilizados por EVP_KDF_CTX_set_params() son:
key:string
Especifica la clave secreta como una cadena alfanumérica (úsela si la clave contiene solo caracteres imprimibles). La longitud de la cadena debe cumplir con cualquier restricción del algoritmo KDF. Se debe especificar una clave para la mayoría de los algoritmos KDF.
hexkey:string
Alternativa a la opción key: donde la clave secreta se especifica en formato hexadecimal (dos dígitos hexadecimales por byte).
pass:string
Especifica la contraseña como una cadena alfanumérica (úsela si la contraseña contiene solo caracteres imprimibles). Se debe especificar una contraseña para PBKDF2 y scrypt.
hexpass:string
Alternativa a la opción pass: donde la contraseña se especifica en formato hexadecimal (dos dígitos hexadecimales por byte).
salt:string
Especifica una sal criptográfica única no secreta como una cadena alfanumérica (úsela si contiene solo caracteres imprimibles). La longitud debe cumplir con cualquier restricción del algoritmo KDF. Se requiere un parámetro de sal para varios algoritmos KDF, como EVP_KDF-PBKDF2(7).
hexsalt:string
Alternativa a la opción salt: donde la sal se especifica en formato hexadecimal (dos dígitos hexadecimales por byte).
info:string
Algunas implementaciones de KDF, como EVP_KDF-HKDF(7), toman un parámetro 'info' para vincular el material de clave derivado a información específica de la aplicación y el contexto. Especifica el argumento info, info fijo, otra info o info compartido como una cadena alfanumérica (úsela si contiene caracteres imprimibles). La longitud debe cumplir con cualquier restricción del algoritmo KDF.
hexinfo:string
Alternativa a la opción info: donde la info se especifica en formato hexadecimal (dos dígitos hexadecimales por byte).
digest:string
Esta opción es idéntica a la opción -digest.
cipher:string
Esta opción es idéntica a la opción -cipher.
mac:string
Esta opción es idéntica a la opción -mac.
-provider name
-provider-path path
-provparam [name:]key=value
-propquery propq
Ver "Opciones de Proveedor" en openssl(1), provider(7), y property(7).
kdf_name
Especifica el nombre de un algoritmo KDF compatible que se utilizará. Los nombres de algoritmos compatibles incluyen TLS1-PRF, HKDF, SSKDF, PBKDF2, SSHKDF, X942KDF-ASN1, X942KDF-CONCAT, X963KDF y SCRYPT.

EJEMPLOS

Usar TLS1-PRF para crear una clave derivada codificada en hexadecimal a partir de una clave secreta y una semilla:

openssl kdf -keylen 16 -kdfopt digest:SHA2-256 -kdfopt key:secret \
            -kdfopt seed:seed TLS1-PRF

Usar HKDF para crear una clave derivada codificada en hexadecimal a partir de una clave secreta, sal e info:

openssl kdf -keylen 10 -kdfopt digest:SHA2-256 -kdfopt key:secret \
            -kdfopt salt:salt -kdfopt info:label HKDF

Usar SSKDF con KMAC para crear una clave derivada codificada en hexadecimal a partir de una clave secreta, sal e info:

openssl kdf -keylen 64 -kdfopt mac:KMAC-128 -kdfopt maclen:20 \
            -kdfopt hexkey:b74a149a161545 -kdfopt hexinfo:348a37a2 \
            -kdfopt hexsalt:3638271ccd68a2 SSKDF

Usar SSKDF con HMAC para crear una clave derivada codificada en hexadecimal a partir de una clave secreta, sal e info:

openssl kdf -keylen 16 -kdfopt mac:HMAC -kdfopt digest:SHA2-256 \
            -kdfopt hexkey:b74a149a -kdfopt hexinfo:348a37a2 \
            -kdfopt hexsalt:3638271c SSKDF

Usar SSKDF con Hash para crear una clave derivada codificada en hexadecimal a partir de una clave secreta, sal e info:

openssl kdf -keylen 14 -kdfopt digest:SHA2-256 \
            -kdfopt hexkey:6dbdc23f045488 \
            -kdfopt hexinfo:a1b2c3d4 SSKDF

Usar SSHKDF para crear una clave derivada codificada en hexadecimal a partir de una clave secreta, hash e ID de sesión:

openssl kdf -keylen 16 -kdfopt digest:SHA2-256 \
            -kdfopt hexkey:0102030405 \
            -kdfopt hexxcghash:06090A \
            -kdfopt hexsession_id:01020304 \
            -kdfopt type:A SSHKDF

Usar PBKDF2 para crear una clave derivada codificada en hexadecimal a partir de una contraseña y sal:

openssl kdf -keylen 32 -kdfopt digest:SHA256 -kdfopt pass:password \
            -kdfopt salt:salt -kdfopt iter:2 PBKDF2

Usar scrypt para crear una clave derivada codificada en hexadecimal a partir de una contraseña y sal:

openssl kdf -keylen 64 -kdfopt pass:password -kdfopt salt:NaCl \
            -kdfopt n:1024 -kdfopt r:8 -kdfopt p:16 \
            -kdfopt maxmem_bytes:10485760 SCRYPT

NOTAS

Los mecanismos KDF disponibles dependerán de las opciones utilizadas al compilar OpenSSL.

VER TAMBIÉN

openssl(1), openssl-pkeyutl(1), EVP_KDF(3), EVP_KDF-SCRYPT(7), EVP_KDF-TLS1_PRF(7), EVP_KDF-PBKDF2(7), EVP_KDF-HKDF(7), EVP_KDF-SS(7), EVP_KDF-SSHKDF(7).

NAME

openssl-kdf - Perform a Key Derivation Function (KDF)

SYNOPSIS

openssl kdf [-help] [-list] [-provider <name>] [-provider-ctx <ctx>] [-digest <name>] [-cipher <name>] [-hex] [-out <file>] [-kdf <name>] [-attr <name>=<value>] [-keylen <len>] [-kdf_ctx <name>] [-iter <count>] [-kmac <mac>] [-fixedoutlen <len>] [-salt <hex>] [-nonce <hex>] [-pwdfile <file>] [-pass <pass>] [-password-file <file>] [-password <pass>] [-mac <mac>] [-maclen <len>] [-pin <pin>] [-pinfile <file>] [-pbkdf2] [-hmac] [-hkdf] [-sshkdf] [-x942kdf] [-x963kdf] [-cmac] [-ansipbmac] [-scrypt] [-argon2] [-sha1 | -sha256 | -sha384 | -sha512 | -md5 | ...] [filename] [password]

DESCRIPTION

The openssl kdf command is used to perform a Key Derivation Function (KDF). KDFs are used to derive cryptographic keys from secrets such as passwords or other shared secrets.

This command can use various KDF algorithms, including PBKDF2, HKDF, SSHKDF, X9.42 KDF, X9.63 KDF, CMAC, and SCrypt.

The output of the KDF can be printed to standard output, saved to a file, or used directly by other OpenSSL commands.

OPTIONS

The following options are available:

-help
Print a usage message and exit.
-list
List the available KDFs and exit.
-provider <name>
Specify the provider to use.
-provider-ctx <ctx>
Specify the provider context.
-digest <name>
Specify the digest algorithm to use (e.g., sha256).
-cipher <name>
Specify the cipher algorithm to use.
-hex
Output the derived key in hexadecimal format.
-out <file>
Write the derived key to the specified file.
-kdf <name>
Specify the KDF algorithm to use (e.g., pbkdf2, hkdf, sshkdf).
-attr <name>=<value>
Set KDF attributes. The available attributes depend on the KDF algorithm.
-keylen <len>
Specify the desired key length in bytes.
-kdf_ctx <name>
Specify the KDF context name.
-iter <count>
Specify the iteration count for PBKDF2.
-kmac <mac>
Specify the KMAC algorithm.
-fixedoutlen <len>
Specify the fixed output length for HKDF.
-salt <hex>
Specify the salt value in hexadecimal format.
-nonce <hex>
Specify the nonce value in hexadecimal format.
-pwdfile <file>
Read the password from the specified file.
-pass <pass>
Specify the password.
-password-file <file>
Read the password from the specified file.
-password <pass>
Specify the password.
-mac <mac>
Specify the MAC algorithm.
-maclen <len>
Specify the MAC length.
-pin <pin>
Specify the PIN.
-pinfile <file>
Read the PIN from the specified file.
-pbkdf2
Use the PBKDF2 algorithm.
-hmac
Use the HMAC algorithm.
-hkdf
Use the HKDF algorithm.
-sshkdf
Use the SSHKDF algorithm.
-x942kdf
Use the X9.42 KDF algorithm.
-x963kdf
Use the X9.63 KDF algorithm.
-cmac
Use the CMAC algorithm.
-ansipbmac
Use the ansi-pbmac algorithm.
-scrypt
Use the SCrypt algorithm.
-argon2
Use the Argon2 algorithm.
-sha1 | -sha256 | -sha384 | -sha512 | -md5 | ...
Specify the digest algorithm to use.
filename
The input file containing the secret to derive the key from. If not specified, the secret is read from standard input.
password
The password to use for key derivation. If not specified, the password is read from standard input or a file specified with -pwdfile or -password-file.

EXAMPLES

Derive a 256-bit key from a password using PBKDF2 with SHA256:

openssl kdf -pbkdf2 -sha256 -iter 100000 -keylen 32 -pass pass:mypassword -salt deadbeef -out key.bin kdf.txt

Derive a key using HKDF:

openssl kdf -hkdf -digest sha256 -keylen 32 -salt 1234 -hex -pass pass:mypassword -out key.hex

NOTES

The specific options and attributes available depend on the KDF algorithm being used. Refer to the OpenSSL documentation for details on each KDF.

When providing passwords, use the pass: prefix for plain text passwords, or use the -passfile or -password-file options to read from a file.

SEE ALSO

EVP_KDF(3), EVP_KDF-PBKDF2(7), EVP_KDF-HKDF(7), EVP_KDF-SSHKDF(7), EVP_KDF-X942-ASN1(7), EVP_KDF-X942-CONCAT(7), EVP_KDF-X963(7)
