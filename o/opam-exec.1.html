OPAM-EXEC(1) Manual de Opam OPAM-EXEC(1)

NOMBRE

opam-exec - Ejecuta un comando en el entorno opam adecuado

SINOPSIS

opam exec [OPCIÓN]… COMANDO [ARG]...…

DESCRIPCIÓN

Ejecuta COMANDO con las variables de entorno correctas. Este comando se puede usar para compilar cruzado entre entornos (`switches`) usando opam config exec --switch=ENTORNO -- COMANDO ARG1 ... ARGn. La expansión de opam tiene lugar en el comando y los argumentos. Si no hay ningún entorno presente en la línea de comandos o en la variable de entorno OPAMSWITCH, OPAMSWITCH no se establece en el entorno de COMANDO.

Este es un atajo y es equivalente a opam config exec.

OPCIONES

--inplace-path
Al actualizar la variable PATH, reemplaza cualquier ruta opam preexistente en el lugar en lugar de poner la nueva ruta al principio. Esto significa que los programas instalados en opam que estaban enmascarados seguirán estando así después de opam env
--no-switch
Ejecuta el comando con las actualizaciones del entorno realizadas por opam revertidas en su lugar.
--set-root
Con los subcomandos env y exec, también establece la variable OPAMROOT, asegurando que futuras llamadas a opam usarán la misma raíz.
--set-switch
Con los subcomandos env y exec, también establece la variable OPAMSWITCH, asegurando que futuras llamadas a opam usarán el mismo entorno que este.

OPCIONES COMUNES

Estas opciones son comunes a todos los comandos.

--best-effort
No fallar si no todos los paquetes solicitados pueden ser instalados: intenta instalar tantos como sea posible. Ten en cuenta que no todos los resolvedores externos pueden soportar esta opción (versiones recientes de aspcud o mccs deberían). Esto es equivalente a establecer la variable de entorno $OPAMBESTEFFORT.
--cli=MAYOR.MENOR (ausente=2.4)
Usa la sintaxis y semántica de la interfaz de línea de comandos de MAYOR.MENOR. Previsto para cualquier uso persistente de opam (scripts, posts de blogs, etc.), cualquier versión de opam en la misma serie MAYOR se comportará como para la versión MENOR especificada. El flag no estaba disponible en opam 2.0, así que para seleccionar la CLI de 2.0, establece la variable de entorno OPAMCLI a 2.0 en lugar de usar este parámetro.
--color=CUÁNDO
Colorea la salida. CUÁNDO debe ser uno de siempre, nunca o auto.
--confirm-level=NIVEL
Nivel de confirmación, NIVEL debe ser uno de preguntar, no, sí o sí-inseguro. Se puede especificar más de una vez. Si también se dan --yes o --no, se toma el valor del último --confirm-level. Esto es equivalente a establecer $OPAMCONFIRMLEVEL`.
--criteria=CRITERIOS
Especifica preferencias del usuario para la resolución de dependencias para esta ejecución. Anula $OPAMCRITERIA, $OPAMFIXUPCRITERIA y $OPAMUPGRADECRITERIA. Para detalles sobre el lenguaje soportado, y los resolvedores externos disponibles, ver http://opam.ocaml.org/doc/External_solvers.html. Una guía general para usar preferencias del resolvedor se puede encontrar en http://www.dicosmo.org/Articles/usercriteria.pdf.
--cudf=NOMBREARCHIVO
Opción de depuración: Guarda las solicitudes CUDF enviadas al resolvedor a NOMBREARCHIVO-<n>.cudf donde <n> es la n-ésima llamada al resolvedor durante la ejecución de opam.
--debug
Imprime mensajes de depuración en stderr. Esto es equivalente a establecer $OPAMDEBUG a "true".
--debug-level=NIVEL
Como --debug, pero permite especificar el nivel de depuración (--debug lo establece a 1). Equivalente a establecer $OPAMDEBUG a un entero positivo.
--git-version
Imprime la versión git de opam, si está establecida (es decir, si estás usando una versión de desarrollo), y sale.
--help[=FORMATO] (predeterminado=auto)
Muestra esta ayuda en el formato FORMATO. El valor FORMATO debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la variable TERM sea dumb o indefinida.
--ignore-pin-depends
Ignora pines adicionales requeridos por paquetes que son fijados (`pinned`), ya sea manualmente a través de opam pin o a través de opam install DIR. Esto es equivalente a establecer IGNOREPINDEPENDS=true.
--json=NOMBREARCHIVO
Guarda los resultados de la ejecución de opam en un archivo legible por computadora. Si el nombre del archivo contiene el carácter `%', será reemplazado por un índice que no sobrescribe un archivo existente. Similar a establecer la variable $OPAMJSON.
--no
Responde no a todas las preguntas de sí/no de opam sin preguntar. Ver también --confirm-level. Esto es equivalente a establecer $OPAMNO a "true".
--no-aspcud
Eliminado en 2.1.
--no-auto-upgrade
Al configurar o actualizar un repositorio escrito para una versión anterior de opam (1.2), opam lo convierte internamente al formato actual. Esto desactiva este comportamiento. Nota que los repositorios deben definir su versión de formato en un archivo 'repo' en su raíz, o se asumirá que están en el formato antiguo. En cualquier caso, es preferible actualizar los repositorios manualmente usando opam admin upgrade [--mirror URL] cuando sea posible.
--no-self-upgrade
Opam se reemplazará a sí mismo con un binario más nuevo encontrado en OPAMROOT/opam si está presente. Esto desactiva este comportamiento.
-q, --quiet
Desactiva --verbose.
--root=RAÍZ
Usa RAÍZ como la ruta raíz actual. Esto es equivalente a establecer $OPAMROOT a RAÍZ.
--safe, --readonly
Asegura que nada será actualizado o reescrito automáticamente. Útil para llamar desde scripts de completado, por ejemplo. Fallará siempre que sea necesaria tal operación; también evita esperar bloqueos, omite preguntas interactivas y anula la variable $OPAMDEBUG. Esto es equivalente a establecer la variable de entorno $OPAMSAFE.
--solver=CMD
Especifica el resolvedor CUDF a usar para resolver problemas de instalación de paquetes. Este es un resolvedor predefinido (esta versión de opam soporta builtin-mccs+lp(), builtin-mccs+glpk, builtin-dummy-z3-solver, builtin-0install, aspcud, mccs, aspcud-old, packup), o un comando personalizado que debe contener las variables %{input}%, %{output}%, %{criteria}%, y opcionalmente %{timeout}%. Esto es equivalente a establecer $OPAMEXTERNALSOLVER.
--strict
Falla siempre que se encuentra un error en la definición de un paquete o un archivo de configuración. El valor predeterminado es continuar silenciosamente si es posible.
--switch=ENTORNO
Usa ENTORNO como el entorno de compilador actual. Esto es equivalente a establecer $OPAMSWITCH a ENTORNO.
--use-internal-solver
Desactiva cualquier resolvedor externo, y usa el interno (esto requiere que opam haya sido compilado con un resolvedor interno). Esto es equivalente a establecer $OPAMNOASPCUD o $OPAMUSEINTERNALSOLVER.
-v, --verbose
Sé más verboso. Una -v muestra todos los comandos de paquetes, repite para mostrar también los comandos llamados internamente (p.ej. tar, curl, patch etc.) Repetir n veces es equivalente a establecer $OPAMVERBOSE a "n".
--version
Muestra la información de la versión.
-w, --working-dir
Siempre que se actualicen paquetes que están ligados a un directorio local controlado por versiones, actualiza al estado de trabajo actual de su código fuente en lugar del último estado confirmado, o la referencia a la que apuntan. Como el directorio fuente se copia tal cual, si no está limpio puede resultar en un fallo de compilación de opam. Esto solo afecta a los paquetes listados explícitamente en la línea de comandos. También se puede establecer con $OPAMWORKINGDIR.
-y, --yes
Responde sí a todas las preguntas de sí/no de opam sin preguntar. Ver también --confirm-level. Esto es equivalente a establecer $OPAMYES a "true".

VARIABLES DE ENTORNO OPAM

Las siguientes variables de entorno pueden ser establecidas para modificar el comportamiento de opam:

OPAMALLPARENS encierra todos los filtros entre paréntesis.

OPAMASSUMEDEPEXTS ver opción `--assume-depexts'.

OPAMAUTOREMOVE ver opción de eliminación `--auto-remove'.

OPAMBESTEFFORT ver opción `--best-effort'.

OPAMBESTEFFORTPREFIXCRITERIA establece la cadena que debe anteceder a los criterios cuando se establece la opción `--best-effort', y se espera que maximice la propiedad `opam-query' en la solución.

OPAMBUILDDOC Eliminado en **2.1**.

OPAMBUILDTEST Eliminado en **2.1**.

OPAMCLI ver opción `--cli'.

OPAMCOLOR cuando se establece en *siempre* o *nunca*, establece un valor predeterminado para la opción `--color'.

OPAMCONFIRMLEVEL ver opción `--confirm-level'. **OPAMCONFIRMLEVEL** tiene prioridad sobre **OPAMYES** y **OPAMNO**.

OPAMCRITERIA especifica las *preferencias* del usuario para la resolución de dependencias. El valor predeterminado depende de la versión del solucionador, utilice `config report' para conocer la configuración actual. Ver también la opción --criteria.

OPAMCUDFFILE guarda el gráfico cudf en el archivo file-actions-explicit.dot.

OPAMCUDFTRIM controla el filtrado de paquetes no relacionados durante el preprocesamiento de CUDF.

OPAMCURL se puede utilizar para seleccionar un programa `curl' determinado. Ver OPAMFETCH para más opciones.

OPAMDEBUG ver opciones `--debug' y `--debug-level'.

OPAMDEBUGSECTIONS si está establecido, limita los mensajes de depuración a la lista de secciones separadas por espacios. Las secciones pueden tener opcionalmente un nivel de depuración específico (por ejemplo, **CLIENT:2** o **CLIENT CUDF:2**), pero de lo contrario utilizan `--debug-level'.

OPAMDIGDEPTH define la agresividad de la búsqueda de conflictos durante el preprocesamiento de CUDF.

OPAMDOWNLOADJOBS establece el número máximo de descargas simultáneas.

OPAMDROPWORKINGDIR anula los paquetes previamente actualizados con **--working-dir** en la actualización. Sin esta variable establecida, opam los mantendría sin cambios a menos que se nombraran explícitamente en la línea de comandos.

OPAMDRYRUN ver opción `--dry-run'.

OPAMEDITOR establece el editor a utilizar para editar archivos opam, anula $EDITOR y $VISUAL.

OPAMERRLOGLEN establece el número de líneas de registro impresas cuando falla un subproceso. 0 para imprimir todas.

OPAMEXTERNALSOLVER ver opción `--solver'.

OPAMFAKE ver opción `--fake'.

OPAMFETCH especifica cómo descargar archivos: `wget', `curl' o un comando personalizado donde las variables **%{url}%**, **%{out}%**, **%{retry}%**, **%{compress}%** y **%{checksum}%** serán reemplazadas. Anula el valor de `download-command' del archivo de configuración principal.

OPAMFIXUPCRITERIA igual que OPAMUPGRADECRITERIA, pero específico para corrección e reinstalación.

OPAMIGNORECONSTRAINTS ver opción de instalación `--ignore-constraints-on'.

OPAMIGNOREPINDEPENDS ver opción `--ignore-pin-depends'.

OPAMINPLACEBUILD ver opción `--inplace-build'.

OPAMJOBS establece el número máximo de trabajadores paralelos a ejecutar.

OPAMJSON registra la salida json en el archivo dado (use el carácter `%' para indexar los archivos).

OPAMKEEPBUILDDIR ver opción de instalación `--keep-build-dir'.

OPAMKEEPLOGS indica a opam que no elimine algunos registros de comandos temporales y algunas copias de seguridad. Esto omite algunos finalizadores y también puede ayudar a obtener backtraces más fiables.

OPAMLOCKED combinación de las opciones `--locked' y `--lock-suffix'.

OPAMLOGS logdir establece el directorio de registros, el valor predeterminado es un directorio temporal en /tmp

OPAMMAKECMD establece el comando make del sistema a usar.

OPAMMERGEOUT fusiona las salidas del proceso, stderr en stdout.

OPAMNO responde no a cualquier pregunta formulada, ver opciones `--no` y `--confirm-level`. **OPAMNO** se ignora si **OPAMCONFIRMLEVEL** u **OPAMYES** está establecido.

OPAMNOAGGREGATE con `opam admin check', no agregar paquetes.

OPAMNOASPCUD Obsoleto.

OPAMNOAUTOUPGRADE deshabilita la actualización automática interna de repositorios en un formato anterior al actual, en 'update' o 'init'.

OPAMNOCHECKSUMS habilita la opción --no-checksums cuando está disponible.

OPAMNODEPEXTS deshabilita el manejo de dependencias del sistema, ver opción `--no-depexts'.

OPAMNOENVNOTICE Interno.

OPAMNOSELFUPGRADE ver opción `--no-self-upgrade'

OPAMPINKINDAUTO establece si los sistemas de control de versiones deben detectarse al fijar a una ruta local. Habilitado por predeterminado desde 1.3.0.

OPAMPRECISETRACKING seguimiento detallado de directorios.

OPAMPREPRO establezca esto en falso para deshabilitar el preprocesamiento de CUDF. Menos eficiente, pero podría ayudar a depurar problemas del solucionador.

OPAMREPOSITORYTARRING almacena internamente los repositorios como archivos tar.gz. Esto puede ser mucho más rápido en sistemas de archivos que no manejan bien el escaneo de árboles grandes pero que tienen buena caché en /tmp. Sin embargo, esto es más lento en el caso general.

OPAMREQUIRECHECKSUMS Habilita la opción `--require-checksums' cuando está disponible (por ejemplo, para `opam install').

OPAMRETRIES establece el número de intentos antes de que fallen las descargas.

OPAMREUSEBUILDDIR ver opción `--reuse-build-dir'.

OPAMROOT ver opción `--root'. Esto se establece automáticamente mediante `opam env --root=DIR --set-root'.

OPAMROOTISOK no se queja al ejecutarse como root.

OPAMSAFE ver opción `--safe'.

OPAMSHOW ver opción `--show'.

OPAMSKIPUPDATE ver opción `--skip-updates'.

OPAMSKIPVERSIONCHECKS omite algunas verificaciones de versión. Inseguro, solo para pruebas de compatibilidad.

OPAMSOLVERALLOWSUBOPTIMAL (predeterminado `true') permite a algunos solucionadores devolver una solución cuando alcanzan el tiempo límite; si bien se garantiza que la solución sea consistente, en este caso no hay garantía de que se ajuste a los criterios de optimización esperados. Si es `true', opam continuará con una advertencia, si es `false' un tiempo límite es un error. Actualmente, solo el backend builtin-z3 maneja este caso degradado.

OPAMSOLVERTIMEOUT cambia el tiempo de asignación del solucionador. El valor predeterminado es 60.0, establecido en 0 para ilimitado. Tenga en cuenta que no todos los solucionadores pueden admitir esta opción.

OPAMSOLVERTOLERANCE cambia la tolerancia hacia el solucionador que elige una solución no optimizada (es decir, podría descargar paquetes obsoletos). Los valores típicos varían de 0.0 (mejor solución conocida por el solucionador) a 1.0 (solución no optimizada). El valor predeterminado es 0.0. Esta opción es útil en caso de que el solucionador no pueda encontrar una solución en un tiempo razonable (ver **$OPAMSOLVERTIMEOUT**). Tenga en cuenta que no todos los solucionadores pueden admitir esta opción.

OPAMSTATS Eliminado en **2.4**.

OPAMSTATUSLINE muestra una línea de estado dinámica que muestra lo que está sucediendo actualmente en la terminal. (uno de **siempre**, **nunca** o **auto**)

OPAMSTRICT falla ante inconsistencias (lectura de archivos, importación de switch, etc.).

OPAMSWITCH ver opción `--switch'. Se establece automáticamente mediante `opam env --switch=SWITCH --set-switch'.

OPAMUNLOCKBASE ver opción de instalación `--unlock-base'.

OPAMUPGRADECRITERIA especifica las *preferencias* del usuario para la resolución de dependencias al realizar una actualización. Anula OPAMCRITERIA en las actualizaciones si ambas están establecidas. Ver también la opción --criteria.

OPAMUSEINTERNALSOLVER ver opción `--use-internal-solver'.

OPAMUSEOPENSSL Eliminado en **2.2**.

OPAMUTF8 utiliza caracteres UTF8 en la salida (uno de **siempre**, **nunca** o **auto**). Por defecto `auto', que se determina a partir de la configuración regional).

OPAMUTF8MSGS utiliza caracteres UTF8 extendidos (camellos) en los mensajes de opam. Implica OPAMUTF8. Esto está establecido por predeterminado solo en macOS.

OPAMVALIDATIONHOOK si está establecido, utiliza el comando `%{hook%}' para validar una actualización de repositorio opam.

OPAMVERBOSE ver opción `--verbose'.

OPAMVERBOSEON ver opción --verbose-on

OPAMVERSIONLAGPOWER no usar.

OPAMWITHDEVSETUP ver opción de instalación `--with-dev-setup'.

OPAMWITHDOC ver opción de instalación `--with-doc'.

OPAMWITHTEST ver opción de instalación `--with-test.

OPAMWORKINGDIR ver opción `--working-dir'.

OPAMYES ver opciones `--yes' y `--confirm-level'. **OPAMYES** tiene prioridad sobre **OPAMNO** y se ignora si **OPAMCONFIRMLEVEL** está establecido.

OPAMVAR_var anula el contenido de la variable var al sustituir cadenas `%{var}%` en archivos `opam`.

OPAMVAR_package_var anula el contenido de la variable package:var al sustituir cadenas `%{package:var}%` en archivos `opam`.

VERSIÓN_CLI

Todos los scripts e invocaciones programáticas de opam deben usar `--cli' para asegurar que funcionen sin problemas con versiones futuras del cliente opam. Además, las publicaciones de blog u otra documentación pueden beneficiarse, ya que evita que la información se desactualice.

Aunque opam solo admite raíces (~/.opam/) para la versión actual, proporciona retrocompatibilidad para su interfaz de línea de comandos.

Dado que la compatibilidad de la versión CLI solo se agregó en opam 2.1, use OPAMCLI para seleccionar soporte 2.0 (ya que opam 2.0 simplemente lo ignorará) y `--cli=2.1' para versiones 2.1 (o posteriores), ya que una variable de entorno que controla el análisis de sintaxis es frágil. Para este fin, opam muestra una advertencia si OPAMCLI especifica una versión válida diferente de 2.0, y también si se especifica `--cli=2.0'.

La versión de la línea de comandos se selecciona utilizando la opción `--cli' o la variable de entorno OPAMCLI. `--cli' puede especificarse más de una vez, donde la última instancia tiene prioridad. OPAMCLI solo se inspecciona si no se proporciona `--cli'.

ESTADO_DE_SALIDA

Como excepción a lo siguiente, el comando `exec' devuelve 127 si el comando no se encontró o no pudo ser ejecutado, y el valor de salida del comando en caso contrario.

0
Éxito, o verdadero para consultas booleanas.
1
Falso. Devuelto cuando se espera un valor de retorno booleano, p. ej., al ejecutar con **--check**, o para consultas como **opam lint**.
2

ESTADO DE SALIDA

1
Malos argumentos de línea de comandos, o argumentos de línea de comandos que apuntan a un contexto inválido (por ejemplo, un archivo que no sigue el formato esperado).
5
No encontrado. Solicitaste algo (paquete, versión, repositorio, etc.) que no se pudo encontrar.
10
Abortado. La operación requería confirmación, la cual no fue dada.
15
No se pudieron adquirir los bloqueos requeridos para la operación.
20
No hay solución para la solicitud del usuario. Esto puede ser causado por solicitar la instalación de dos paquetes incompatibles, por ejemplo.
30
Error en la definición del paquete, u otros archivos de metadatos. El uso de --strict genera este error con mayor frecuencia.
31
Error en el script del paquete. Algunas operaciones del paquete no fueron exitosas. Esto puede ser un error en los paquetes o una incompatibilidad con tu sistema. Puede ser un error parcial.
40
Error de sincronización. No se pudieron obtener algunos remotos de la red. Puede ser un error parcial.
50
Error de configuración. La configuración de Opam o del sistema no permite la operación y necesita ser corregida.
60
Fallo del solucionador. El solucionador no pudo devolver una respuesta válida. Puede deberse a un solucionador externo roto, o a un error en la configuración del solucionador.
99
Error interno. Algo salió mal, probablemente debido a un error en el propio opam.
130
Interrupción del usuario. Se recibió SIGINT, generalmente debido a que el usuario presionó Ctrl-C.
0
en caso de éxito.
123
en errores indiscriminados reportados en la salida estándar.
124
en errores de análisis de línea de comandos.
125
en errores internos inesperados (bugs).
