NOMBRE

opensc.conf - archivo de configuración para OpenSC

DESCRIPCIÓN

OpenSC obtiene datos de configuración de las siguientes fuentes en el siguiente orden:

1. Opciones de línea de comandos
2. Variables de entorno
3. Clave del registro de Windows en HKEY_CURRENT_USER (si está disponible)
4. Clave del registro de Windows en HKEY_LOCAL_MACHINE (si está disponible)
5. Archivo de configuración a nivel de sistema (/etc/opensc.conf)

El archivo de configuración, opensc.conf, se compone de bloques, que, en general, tienen el siguiente formato:

clave [, nombre...] {
	contenido_bloque
}

contenido_bloque es uno o más elementos_bloque donde un elemento_bloque es uno de:

•# cadena_comentario
•clave[, nombre...] = valor;
•bloque

En el nivel raíz, opensc.conf debe contener uno o más bloques de configuración específicos de la aplicación:

app aplicacion {
	contenido_bloque
}

aplicacion especifica uno de:

•nombre_archivo: Bloque de configuración para la aplicación con la ruta de archivo especificada.
•default: Bloque de configuración de reserva para todas las aplicaciones
•opensc-pkcs11: Bloque de configuración para el módulo PKCS#11 (opensc-pkcs11.so)
•onepin-opensc-pkcs11: Bloque de configuración para el módulo one-PIN de PKCS#11 (onepin-opensc-pkcs11.so)
•cardmod: Bloque de configuración para el minidriver de Windows (opensc-minidriver.dll)
•tokend: Bloque de configuración para el tokend de macOS (OpenSC.tokend)
•tool_cardos, tool_cryptoflex, tool_dnie, tool_egk, eidenv, tool_gids, tool_iasecc, tool_netkey, tool_npa, tool_openpgp, opensc-asn1, opensc-explorer, opensc-notify, opensc-tool, piv-tool, pkcs11-tool, pkcs15-crypt, pkcs15-init, pkcs15-tool, tool_sc-hsm, tool_westcos: Bloque de configuración para herramientas de OpenSC

OPCIONES DE CONFIGURACIÓN

debug = num;

Cantidad de información de depuración a imprimir (Predeterminado: 0). Un valor mayor significa más información de depuración.

La variable de entorno OPENSC_DEBUG anula esta configuración.

debug_file = nombre_archivo;

El archivo al que se escribirá la salida de depuración (Predeterminado: stderr). Se reconocen los valores especiales stdout y stderr.

profile_dir = nombre_archivo;

Directorio de perfiles de inicialización/personalización PKCS#15 para pkcs15-init(1) (Predeterminado: /usr/share/opensc).

Si este valor de configuración no se encuentra en Windows, se consulta la clave del registro Software\OpenSC Project\OpenSC\ProfileDir.

disable_colors = bool;

Deshabilita los colores de los mensajes de registro (Predeterminado: falso si está conectado a una consola, verdadero en caso contrario).

disable_popups = bool;

Deshabilita los pop-ups de la GUI integrada (Predeterminado: falso).

enable_default_driver = bool;

Habilita el controlador de tarjeta predeterminado (Predeterminado: falso). El controlador de tarjeta predeterminado se habilita explícitamente para opensc-explorer(1) y opensc-tool(1)

card_drivers = nombre...;

Lista blanca de controladores de tarjetas a cargar al inicio. El valor especial internal (el predeterminado) cargará todos los controladores enlazados estáticamente.

Si se proporciona un controlador desconocido (es decir, no interno o antiguo), se debe escribir un bloque de configuración separado para el controlador. Un valor especial old cargará todos los controladores enlazados estáticamente que puedan eliminarse en el futuro.

La lista de nombres de controladores de tarjetas compatibles se puede obtener de la salida de opensc-tool --list-drivers.

La variable de entorno OPENSC_DRIVER anula esta configuración.

ignored_readers = nombre...;

Lista de lectores a ignorar (Predeterminado: vacío). Si alguna de las cadenas separadas por comas listadas coincide con un nombre de lector (sensible a mayúsculas y minúsculas, coincidencia parcial posible), el lector es ignorado por OpenSC. Utilice opensc-tool --list-readers para ver todos los lectores conectados actualmente.

Ver la sección llamada “Configuración del controlador de lectores de tarjetas inteligentes”.

•dnie: Ver la sección llamada “Opciones de configuración para DNIe”

•eoi: Ver la sección llamada “Opciones de configuración para la tarjeta de DNI electrónica eslovena”

disable_hw_pkcs1_padding = valor;

Deshabilita el relleno PKCS#1 v1.5 en hardware cuando la tarjeta admite operaciones RSA en bruto. Parámetros conocidos:
•no: El relleno PKCS#1 v1.5 está habilitado en hardware cuando la tarjeta lo admite.
•sign: El relleno PKCS#1 v1.5 está deshabilitado solo para firmas (tipo 1 de PKCS#1 v1.5).
•decipher: El relleno PKCS#1 v1.5 está deshabilitado solo para descifrado (tipo 2 de PKCS#1 v1.5).
•both: El relleno PKCS#1 v1.5 está deshabilitado tanto para firmas como para descifrado (tipos 1 y 2 de PKCS#1 v1.5).

(Predeterminado: decipher).

Configuración del Controlador de Lector de Tarjetas Inteligentes

Opciones de Configuración para todos los Controladores de Lector

max_send_size = num; max_recv_size = num;

Limita los tamaños de comando y respuesta (Predeterminado: max_send_size = 255, max_recv_size = 256). Algunos lectores no propagan correctamente sus capacidades de transcepción. max_send_size y max_recv_size permiten establecer los límites manualmente, por ejemplo, para habilitar capacidades de longitud extendida.

enable_escape bool;

Detecta las capacidades del lector con comandos de escape (APDUs envueltos con CLA=0xFF como se define en PC/SC pt. 3 y BSI TR-03119, por ejemplo, para obtener el UID, comandos PIN envueltos y la versión del firmware del lector, predeterminado: falso)

Configuración de Lectores CT-API

module nombrearchivo { ports = nums; }

Carga el módulo CT-API especificado con el número de puertos especificado.

Configuración de Lectores PC/SC

connect_exclusive = bool;

¿Conectarse al lector en modo exclusivo (Predeterminado: falso)? Esta opción no tiene efecto en el minidriver de Windows.

disconnect_action = acción;

Qué hacer al desconectarse de una tarjeta (SCardDisconnect). Los valores válidos son leave, reset, unpower (Predeterminado: leave). Esta opción no tiene efecto en el minidriver de Windows.

transaction_end_action = acción;

Qué hacer al final de una transacción (SCardEndTransaction). Los valores válidos son leave, reset, unpower (Predeterminado: leave). Esta opción no tiene efecto en el minidriver de Windows.

reconnect_action = acción;

Qué hacer al reconectarse a una tarjeta (SCardReconnect). Los valores válidos son leave, reset, unpower (Predeterminado: leave). Esta opción no tiene efecto en el minidriver de Windows.

enable_pinpad = bool;

Habilita el pinpad si se detecta (PC/SC v2.0.2 Parte 10, Predeterminado: verdadero)

fixed_pinlength = num;

Algunos lectores de pinpad solo pueden manejar una longitud exacta del PIN. fixed_pinlength establece este valor para que OpenSC expanda el relleno a esta longitud (Predeterminado: 0, es decir, no fijo).

provider_library = nombrearchivo;

Usa un proveedor PC/SC específico (Predeterminado: libpcsclite.so.1).

Configuración de Lectores OpenCT

readers = num;

Lectores virtuales a asignar (Predeterminado: 2).

Opciones de Configuración para la Tarjeta MyEID

disable_hw_pkcs1_padding = bool;

La tarjeta MyEID puede encapsular internamente los datos (código hash) en una estructura ASN.1 DigestInfo de acuerdo con el algoritmo hash seleccionado (actualmente solo para SHA1). DigestInfo se rellena hasta la longitud del módulo de clave RSA según PKCS#1 v1.5, tipo de bloque 01h. El tamaño de DigestInfo no debe exceder el 40% de la longitud del módulo de clave RSA. Si este límite es insatisfactorio (por ejemplo, alguien necesita RSA 1024 con SHA512), el usuario puede deshabilitar esta función. En este caso, el controlador de la tarjeta hará todo lo necesario antes de enviar los datos (código hash) a la tarjeta.

El relleno PKCS#1 v1.5 en hardware se puede deshabilitar globalmente con la opción disable_hw_pkcs1_padding. Cuando la opción global se usa para deshabilitar el relleno, el relleno se deshabilitará aunque la opción específica de MyEID no lo desactive.

Opciones de Configuración para la Tarjeta de Identidad Alemana

can = valor;

La tarjeta de identidad alemana requiere que se verifique el CAN antes del PIN QES. Sin embargo, esto no forma parte del perfil PKCS#15 de la tarjeta. Por lo tanto, para verificar el PIN QES, en realidad necesitamos ambos. El CAN puede proporcionarse aquí. Si el CAN no se proporciona aquí, se le pedirá en la línea de comandos o en el lector (dependiendo de las capacidades del lector).

st_dv_certificate = nombrearchivo; st_certificate = nombrearchivo; st_key = nombrearchivo;

QES solo es posible con un Lector de Confort (CAT-K), que contiene una clave criptográfica para autenticarse como terminal de firma (ST). Normalmente utilizaremos la capacidad del lector para firmar los datos. Sin embargo, durante el desarrollo, puede especificar certificados y claves suaves para un ST.

Se puede encontrar un ejemplo de PKI en los datos de ejemplo del emulador de tarjeta de identidad alemana[1]

Opciones de Configuración para DNIe

user_consent_enabled = bool;

Configura el mensaje de advertencia al realizar una operación de firma con el DNIe. Solo se utiliza si se compila con --enable-dnie-ui

user_consent_app = nombrearchivo;

Especifica la aplicación pinentry a usar si se configura el mensaje de advertencia para que se muestre usando pinentry (Predeterminado: /usr/bin/pinentry). Solo se utiliza si se compila con --enable-dnie-ui

Opciones de Configuración para la Tarjeta eID Polaca

can = valor;

El CAN (Número de Acceso a la Tarjeta – número de 6 dígitos impreso en la esquina inferior derecha del anverso del documento) es necesario para establecer la conexión con la tarjeta. Puede ser sobrescrito por la variable de entorno EDO_CAN. Actualmente, no es posible configurarlo de ninguna otra manera.

Opciones de Configuración para la Tarjeta eID Eslovena

can = valor;

El CAN (Número de Acceso a la Tarjeta – número de 6 dígitos impreso en la esquina inferior derecha del anverso del documento) es necesario para establecer la conexión con la tarjeta. Puede ser sobrescrito por la variable de entorno EOI_CAN. Dado que el CAN también se almacena en la tarjeta (de forma cifrada), puede usarse para establecer automáticamente una conexión segura, pero solo si se accede a la tarjeta a través de la interfaz de contacto.

Opciones de Configuración para la Tarjeta PIV

Configuración basada en ATR

atrmask = cadenahexadecimal;

La máscara se combina lógicamente con un ATR de tarjeta mediante AND antes de compararla con el valor de referencia ATR anterior. Usar esta máscara permite identificar y configurar múltiples ATR como el mismo modelo de tarjeta.

driver = nombre;

Cuando está habilitado, anula todas las configuraciones posibles de la lista de configuración de tarjetas integrada de los controladores de tarjetas.

name = nombre;

Establece el nombre de la tarjeta para los controladores de tarjetas que lo permiten.

type = num;

Permite establecer el tipo exacto de tarjeta utilizado internamente por el controlador de tarjeta. Los valores permitidos se pueden encontrar en el código fuente de cards.h.

flags = valor...;

Marcas de tarjeta como un valor hexadecimal. Se combinan varios valores mediante OR. Dependiendo del controlador de tarjeta, esto permite ajustar las capacidades en el controlador de tarjeta para su tarjeta.

Opcionalmente, algunos parámetros conocidos se pueden especificar como cadenas:

•rng: Fuente de números aleatorios integrada
•keep_alive: Solicita al controlador de tarjeta que envíe un comando "keep alive" antes de cada transacción para asegurarse de que la aplicación requerida todavía está seleccionada.

pkcs15emu = nombre;

Al usar la emulación PKCS#15, fuerza el controlador de emulación para tarjetas específicas. Requerido para controladores externos, pero también se puede usar con controladores integrados.

force_protocol = valor;

Fuerza la selección del protocolo para tarjetas específicas. Parámetros conocidos:
•t0
•t1
•raw

read_only = bool;

Marca la tarjeta como de solo lectura en la interfaz PKCS#11/Minidriver/BaseCSP (Predeterminado: falso).

md_supports_X509_enrollment = bool;

Indica soporte de inscripción X509 en la interfaz Minidriver/BaseCSP (Predeterminado: falso).

md_guid_as_id = bool;

Usa el GUID generado para la clave como id en la estructura PKCS#15 (Predeterminado: falso, es decir, generado automáticamente)

md_guid_as_label = bool;

Usa el GUID generado para la clave como etiqueta en la estructura PKCS#15 (Predeterminado: falso, es decir, sin etiqueta establecida).

md_supports_container_key_gen = bool;

La tarjeta permite generar pares de claves en la tarjeta (Predeterminado: falso).

md_supports_container_key_import = bool;

La tarjeta permite importar claves privadas (Predeterminado: falso).

md_pinpad_dlg_title = valor;

Título de la ventana del diálogo del teclado PIN (Predeterminado: "Windows Security").

md_pinpad_dlg_icon = nombre_archivo;

Nombre del archivo del icono para el diálogo del teclado PIN; use "" para no mostrar icono (Predeterminado: Icono de tarjeta inteligente incorporado).

md_pinpad_dlg_main = valor;

Instrucción principal del diálogo del teclado PIN (Predeterminado: "OpenSC Smart Card Provider").

md_pinpad_dlg_content_user = valor;

Contenido del diálogo del teclado PIN para el rol "usuario" (Predeterminado: "Please enter your PIN on the PIN pad.").

md_pinpad_dlg_content_user_sign = valor;

Contenido del diálogo del teclado PIN para el rol "user+signature" (Predeterminado: "Please enter your digital signature PIN on the PIN pad.").

md_pinpad_dlg_content_admin = valor;

Contenido del diálogo del teclado PIN para el rol "admin" (Predeterminado: "Please enter your PIN to unblock the user PIN on the PIN pad.")

md_pinpad_dlg_expanded = valor;

Información ampliada del diálogo del teclado PIN (Predeterminado: "This window will be closed automatically after the PIN has been submitted on the PIN pad (timeout typically after 30 seconds).")

md_pinpad_dlg_enable_cancel = bool;

Permite al usuario cancelar el diálogo del teclado PIN (Predeterminado: falso). Si este valor se establece en verdadero, el usuario debe hacer clic en "OK" para iniciar la verificación del PIN en el teclado PIN. El usuario puede elegir el comportamiento predeterminado activando o desactivando la casilla de verificación del diálogo. La configuración se guarda en la ruta completa del programa (program_path) que utiliza OpenSC.

La clave del registro HKCU\Software\OpenSC Project\OpenSC\md_pinpad_dlg_enable_cancel\program_path anula esta configuración con un DWORD establecido en 1 (habilitado) o 0 (deshabilitado).

md_pinpad_dlg_timeout = num;

Tiempo en segundos para que la barra de progreso del diálogo del teclado PIN progrese. 0 elimina la barra de progreso (Predeterminado: 30).

notify_card_inserted = valor; notify_card_inserted_text = valor;

Título y texto de la notificación cuando se inserta la tarjeta (Predeterminado: "Smart card detected", ATR de la tarjeta).

notify_card_removed = valor; notify_card_removed_text = valor;

Título y texto de la notificación cuando se retira la tarjeta (Predeterminado: "Smart card removed", nombre del lector de tarjetas inteligentes).

notify_pin_good = valor; notify_pin_good_text = valor;

Título y texto de la notificación cuando se verifica el PIN (Predeterminado: "PIN verified", "Smart card is unlocked").

notify_pin_bad = valor; notify_pin_bad_text = valor;

Título y texto de la notificación cuando el PIN es incorrecto (Predeterminado: "PIN not verified", "Smart card is locked").

Configuración del Marco PKCS#15

use_file_caching = valor;

Si se deben almacenar en caché los archivos de la tarjeta (por ejemplo, certificados) en el disco en file_cache_dir. Parámetros posibles:
•yes: Almacenar en caché todos los archivos (públicos y privados).
•public: Almacenar en caché solo archivos públicos.
•no: Almacenamiento en caché de archivos deshabilitado.

(Predeterminado: public para los siguientes controladores de tarjetas: atrust-acos (controlador desactivado), belpic, cac1, cac, coolkey, dnie, edo, esteid2018, flex (controlador desactivado), cyberflex (controlador desactivado), gemsafeV1, idprime, itacns, jpki, MaskTech, mcrd (controlador desactivado), npa, nqapplet, tcos y de lo contrario no).

Si el almacenamiento en caché lo realiza un proceso del sistema, los archivos almacenados en caché pueden ser inaccesibles desde la cuenta de usuario. Utilice una ubicación globalmente legible y escribible si desea compartir la información almacenada en caché. Tenga en cuenta que los archivos almacenados en caché pueden contener datos personales como nombre y dirección de correo electrónico.

file_cache_dir = nombre_archivo;

Dónde almacenar en caché los archivos de la tarjeta. Los valores predeterminados son:
•$XDG_CACHE_HOME/opensc/ (Si $XDG_CACHE_HOME está definido)
•$HOME/.cache/opensc/ (Unix)
•$USERPROFILE\.eid-cache\ (Windows)

Si el almacenamiento en caché lo realiza un proceso del sistema, los archivos almacenados en caché pueden ser inaccesibles desde una cuenta de usuario. Utilice una ubicación globalmente legible y escribible si desea compartir la información almacenada en caché. Tenga en cuenta que los archivos almacenados en caché pueden contener datos personales como nombre y dirección de correo electrónico.

El controlador de tarjeta PIV-II admite la lista de objetos de historial de claves y certificados retirados si son legibles en el directorio de caché de archivos. Si la URL del objeto especificado es "http://"nombre_DNS"/""OffCardKeyHistoryFile_en_HEX_ASCII", entonces las búsquedas del archivo OffCardKeyHistoryFile en el directorio de caché.

use_pin_caching = bool;

¿Utilizar almacenamiento en caché de PIN (Predeterminado: verdadero)?

pin_cache_counter = num;

¿Cuántas veces usar un PIN de la caché antes de volver a autenticarlo (Predeterminado: 10)?

pin_cache_ignore_user_consent = bool;

Las aplicaciones PKCS#11 más antiguas que no admiten CKA_ALWAYS_AUTHENTICATE pueden necesitar establecer esto para que las firmas funcionen con algunas tarjetas (Predeterminado: falso).

Se recomienda habilitar también el almacenamiento en caché de PIN utilizando la opción use_pin_caching para que OpenSC pueda proporcionar el PIN para la tarjeta cuando sea necesario.

pin_protected_certificate = valor;

Cómo manejar un certificado protegido por PIN. Parámetros conocidos:
•protect: El certificado permanece protegido por PIN.
•declassify: Permite leer el certificado sin forzar la verificación del PIN.
•ignore: Ignorar certificados protegidos por PIN.

(Predeterminado: ignore en Tokend, de lo contrario protect).

enable_pkcs15_emulation = bool;

Habilitar emulación pkcs15 (Predeterminado: verdadero).

try_emulation_first = bool;

Preferir código de emulación pkcs15 antes del procesamiento normal de pkcs15 (Predeterminado: no). Algunas tarjetas funcionan en modo de solo emulación y no dependen de esta opción.

enable_builtin_emulation = bool;

Habilitar emuladores incorporados (Predeterminado: verdadero).

builtin_emulators = emuladores;

Lista de los emuladores pkcs15 incorporados a probar (Predeterminado: internal)

El valor especial internal intentará todos los emuladores pkcs15 incorporados no deshabilitados.

El valor especial old intentará todos los emuladores pkcs15 deshabilitados.

pkcs11_enable_InitToken = bool;

Habilitar inicialización y reconocimiento de tarjetas (Predeterminado: falso).

emulate nombre { contenidos_bloque }

Opciones de configuración para un emulador PKCS#15 donde nombre es un nombre corto para un controlador de tarjeta externo.

module = nombre_archivo;

Para emuladores pkcs15 cargados desde una biblioteca compartida/DLL externa, debe especificar el nombre de la ruta del módulo y personalizar correctamente el ejemplo de card_atr anterior.

function = nombre;

Obtener el nombre de la función de inicialización del emulador (Predeterminado: sc_pkcs15_init_func_ex)

application cadena_hexadecimal { contenidos_bloque }

Configuración de la aplicación en la tarjeta donde cadena_hexadecimal es el identificador de la aplicación (AID).

type = nombre;

Tipo de aplicación donde nombre es uno de:
•generic
•protected

Se utiliza para distinguir la aplicación de acceso común y la aplicación para la que no se puede obtener autenticación para realizar alguna operación con los procedimientos comunes (por ejemplo, creación de objetos protegida por mensajería segura). Se utiliza por el módulo PKCS#11 configurado para exponer un número restringido de ranuras. (por ejemplo, configurado para exponer solo la ranura PIN de usuario, ranuras PIN de Usuario y Firma, ...)

model = nombre;

No exponer la aplicación en el marco PKCS#15 (Predeterminado: falso)

user_pin = nombre;

Nombre del objeto PIN de usuario que se utilizará como PIN principal.

sign_pin = nombre;

Nombre del objeto PIN que se utilizará para firmar.

Configuración de PKCS#11

max_virtual_slots = num;

Número máximo de ranuras virtuales (Predeterminado: 16). Si hay más ranuras que las definidas aquí, las ranuras restantes se ocultarán de PKCS#11.

slots_per_card = num;

Número máximo de ranuras PIN por tarjeta inteligente (Predeterminado: 4). Si la tarjeta tiene menos PIN que los definidos aquí, el número restante de ranuras estará vacío. Para Firefox, Chrome y Chromium, slots_per_card se establece en 1, para evitar solicitar PINs no relacionados. Típicamente, esto deshabilita efectivamente los PIN y claves de firma.

lock_login = bool;

DESCRIPCIÓN

El archivo de configuración de OpenSC, opensc.conf, permite configurar el comportamiento del módulo PKCS#11 de OpenSC y de otras utilidades de OpenSC.

OPCIONES DE CONFIGURACIÓN

lock_login

Por defecto, el módulo PKCS#11 de OpenSC no bloqueará su tarjeta una vez que se autentique en la tarjeta a través de C_Login (Por defecto: false). Por lo tanto, otros usuarios u otras aplicaciones no tendrán impedimento para conectarse a la tarjeta y realizar operaciones criptográficas (lo que puede ser posible porque ya se ha autenticado con la tarjeta). Esta configuración no es muy segura.

Además, si su tarjeta no está bloqueada, puede encontrar problemas debido a la limitación del framework de OpenSC, que aún no está completamente probado en entornos de múltiples hilos.

Sus configuraciones serán más seguras si elige bloquear su tarjeta. Sin embargo, este comportamiento es una violación conocida de la especificación PKCS#11. Ahora, una vez que una aplicación ha comenzado a usar su tarjeta con C_Login, ninguna otra aplicación puede usarla, hasta que la primera termine y llame a C_Logout o C_Finalize. En el caso de muchas aplicaciones PKCS#11, esto no sucede hasta que salga de la aplicación.

Por lo tanto, es imposible usar varias aplicaciones compatibles con tarjetas inteligentes al mismo tiempo, por ejemplo, no puede ejecutar Firefox y Thunderbird al mismo tiempo, si ambos están configurados para usar su tarjeta inteligente.

atomic = bool;

Por defecto, interactuar con el módulo PKCS#11 de OpenSC puede cambiar el estado del token, por ejemplo, si un usuario ha iniciado o no sesión (Por defecto: false).

Por lo tanto, otros usuarios u otras aplicaciones pueden cambiar o utilizar el estado del token sin saberlo. Otras aplicaciones pueden crear firmas abusando de un inicio de sesión existente o pueden cerrar sesión sin ser notadas.

Con esta configuración habilitada, el estado de inicio de sesión del token se rastrea y se almacena en caché (incluido el PIN). Cada transacción va precedida de la restauración del estado de inicio de sesión. Después de cada transacción, se realiza un cierre de sesión. Esta configuración también habilita por defecto lock_login para deshabilitar el acceso a otras aplicaciones durante las transacciones atómicas.

Tenga en cuenta que cualquier PIN-pad debe estar deshabilitado (ver enable_pinpad), ya que el usuario tendría que introducir su PIN para cada transacción.

init_sloppy = bool;

Con esta configuración deshabilitada, el módulo PKCS#11 de OpenSC inicializará las ranuras disponibles cuando la aplicación llame a C_GetSlotList. Con esta configuración habilitada, las ranuras también se inicializarán cuando se llame a C_GetSlotInfo (Por defecto: true).

Esta configuración es una solución alternativa para Java, que no llama a C_GetSlotList cuando está configurado con una ranura estática en lugar de slotListIndex.

user_pin_unblock_style = mode;

El estilo de desbloqueo del PIN de usuario mode es uno de:
•
none (Por defecto): El desbloqueo del PIN no es posible con la API PKCS#11
•
set_pin_in_unlogged_session: C_SetPIN en sesión no registrada: el PUK se pasa como argumento OldPin de la llamada C_SetPIN.
•
set_pin_in_specific_context: C_SetPIN en la sesión registrada CKU_SPECIFIC_CONTEXT: el PUK se pasa como argumento OldPin de la llamada C_SetPIN.
•
init_pin_in_so_session: C_InitPIN en la sesión registrada CKU_SO: el PIN de usuario 'DESBLOQUEAR' está protegido por SOPIN. (PUK == SOPIN).

create_puk_slot = bool;

Crea una ranura para desbloquear el PIN con PUK (Por defecto: false). De esta manera, la API PKCS#11 puede usarse para iniciar sesión con PUK y cambiar un PIN. Puede causar problemas con algunas aplicaciones como Firefox y Thunderbird.

create_slots_for_pins = mode...;

Nombres simbólicos de los PIN para los que se crean ranuras, donde mode es una lista de:
•
all (Por defecto): Todos los PIN no SO, no de desbloqueo
•
user: El primer PIN global o el primer PIN local
•
sign: El segundo PIN (primer PIN local, segundo PIN global o segundo PIN local)

La tarjeta puede contener más de un PIN o más de una aplicación en la tarjeta con su propio PIN. Normalmente, para acceder a todos ellos con la API PKCS#11 se debe crear una ranura para cada uno. Muchas ranuras pueden ser molestas para algunas aplicaciones de uso común, como FireFox. Este parámetro de configuración permite seleccionar los PIN para los que se creará una ranura PKCS#11.

Solo los PIN inicializados, no SO-PIN, no de desbloqueo están asociados con un nombre simbólico.

Para que el módulo simule el comportamiento del módulo opensc-onepin, la siguiente opción create_slots_for_pins = "user";
