NOMBRE

openssl-srp - mantener el archivo de contraseñas SRP

SINOPSIS

openssl srp [-help] [-verbose] [-add] [-modify] [-delete] [-list] [-name sección] [-srpvfile archivo] [-gn identificador] [-userinfo texto] [-passin arg] [-passout arg] [-engine id] [-rand archivos] [-writerand archivo] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq] [-config archivo de configuración] [usuario ...]

DESCRIPCIÓN

Este comando está obsoleto. Se utiliza para mantener un archivo de SRP (contraseña remota segura). A lo sumo una de las opciones -add, -modify, -delete y -list puede especificarse. Estas opciones toman cero o más nombres de usuario como parámetros y realizan la operación apropiada en el archivo SRP. Para -list, si no se da ningún usuario, se muestran todos los usuarios.

El archivo de configuración a usar, y la sección dentro del archivo, se pueden especificar con las banderas -config y -name, respectivamente.

OPCIONES

-help
Muestra un resumen de las opciones.
-verbose
Genera salida detallada mientras se procesa.
-add
Añade un usuario y un verificador SRP.
-modify
Modifica el verificador SRP de un usuario existente.
-delete
Elimina al usuario del archivo de verificadores.
-list
Lista los usuarios.
-name
La definición SRP particular a usar.
-srpvfile archivo
Si el archivo de configuración no se especifica, -srpvfile puede usarse para especificar el archivo sobre el que operar.
-gn
Especifica los valores g y N, usando una de las resistencias definidas en IETF RFC 5054.
-userinfo
especifica información adicional a añadir al añadir o modificar un usuario.
-passin arg, -passout arg
La fuente de contraseña para el archivo de entrada y salida. Para más información sobre el formato de arg, ver openssl-passphrase-options(1).
-engine id
Ver "Opciones de Motor" en openssl(1). Esta opción está obsoleta.
-rand archivos, -writerand archivo
Ver "Opciones de Estado Aleatorio" en openssl(1) para detalles.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Ver "Opciones de Proveedor" en openssl(1), provider(7), y property(7).
-config archivo de configuración
Ver "Opción de Configuración" en openssl(1).

[-rand archivos] [-writerand archivo]

HISTORIA

La opción -engine fue obsoleta en OpenSSL 3.0.
