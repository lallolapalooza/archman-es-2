NOMBRE

ostree-admin-status - Listar despliegues

SINOPSIS

ostree admin status

DESCRIPCIÓN

Lista los despliegues disponibles para arrancar. Incluye el nombre del sistema operativo (osname), el hash seguido del número de serie del despliegue y la especificación de referencia (refspec). Un asterisco indica el despliegue actualmente arrancado.

OPCIONES

--sysroot="RUTA"

Crear un nuevo sysroot OSTree en RUTA

-V, --verify

Mostrar el estado de verificación del commit

--json

Salida en formato JSON.

-S, --skip-signatures

Omitir firmas en la salida

-D, --is-default

Mostrar la cadena `default` si el despliegue predeterminado es el arrancado, `not-default` si estamos arrancados en un despliegue no predeterminado (por ejemplo, el usuario eligió interactivamente una entrada diferente en el menú del gestor de arranque, o el gestor de arranque hizo reversión automática, etc.). Si no estamos en un sistema OSTree arrancado, se devolverá un error.

-v, --verbose

Mostrar información de depuración durante el procesamiento del comando

--version

Mostrar información de la versión y salir

EJEMPLO

$ ostree admin status

        * gnome-ostree 67e382b11d213a402a5313e61cbc69dfd5ab93cb07.0
            refspec de origen: gnome-ostree/buildmain/x86_64-runtime
          gnome-ostree ce19c41036cc45e49b0cecf6b157523c2105c4de1c.0
            refspec de origen: gnome-ostree/buildmain/x86_64-runtime
