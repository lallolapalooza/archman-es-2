NOMBRE

oggz-diff — Realiza un volcado hexadecimal de los paquetes de dos archivos Ogg y muestra las diferencias

SINOPSIS

oggz-diff [opciones] [OPCIONES_OGGZDUMP] [OPCIONES_DIFF] archivo1.ogg archivo2.ogg

opciones: [--verbose ] [-v | --version ] [-h | --help ]

OPCIONES_OGGZDUMP: [-b | --binary ] [-x | --hexadecimal ] [-c tipo-contenido | --content-type tipo-contenido ] [-s nro-serie | --serialno nro-serie ] [-O | --hide-offset ] [-S | --hide-serialno ] [-G | --hide-granulepos ] [-P | --hide-packetno ]

OPCIONES_DIFF: [-q | --brief ] [-C NUM | --context[=NUM] ] [-u | -U NUM | --unified[=NUM] ] [-e | --ed ] [--normal ] [--rcs ] [-y | --side-by-side ] [-l | --paginate ]

DESCRIPCIÓN

oggz-diff es un script de sh que utiliza oggz-dump para generar volcados hexadecimales de paquetes de cada archivo de entrada, luego muestra la diferencia entre estos volcados utilizando diff.

OPCIONES

oggz-diff reenvía un subconjunto de opciones aceptadas por oggz-dump y diff. Consulte oggz-dump(1) y diff(1) para más detalles.

oggz-dump opciones de formato

-b, --binary
Genera un volcado binario de cada paquete
-x, --hexadeciaml
Genera un volcado hexadecimal de cada paquete

oggz-dump opciones de filtrado

-c tipo-contenido, --content-type tipo-contenido
Vuelca solo los flujos de bits lógicos para un tipo-contenido específico. Ejecute oggz-known-codecs(1) para obtener una lista completa de los códecs conocidos por la versión instalada de oggz.
-s nro-serie, --serialno nro-serie
Vuelca solo el flujo de bits lógico con el nro-serie especificado.
-O, --hide-offset
Oculta el campo de desplazamiento de bytes del preámbulo de cada paquete volcado. Esto es particularmente útil al comparar flujos de bits Ogg que difieren solo en la estructura de página.
-S, --hide-serialno
Oculta el campo nro-serie del preámbulo de cada paquete volcado. Esto es particularmente útil al comparar flujos de bits Ogg que difieren solo en la asignación del nro-serie.
-G, --hide-granulepos
Oculta el campo granulepos del preámbulo de cada paquete volcado.
-P, --hide-packetno
Oculta el campo packetno del preámbulo de cada paquete volcado.

diff opciones

La opción -w (--ignore-all-space) para diff está siempre implícita.

-q, --brief
Muestra solo si los archivos difieren.
-C NUM, --context[=NUM]
Muestra NUM líneas de contexto copiado.
-u, -U NUM, --unified[=NUM]
Muestra NUM (predeterminado 3) líneas de contexto unificado.
-e, --ed
Genera un script de ed.
--normal
Genera una diferencia normal.
--rcs
Genera una diferencia en formato RCS.
-y, --side-by-side
Muestra en dos columnas.
-l, --paginate
Pasa la salida a través de pr para paginarla.

Opciones varias

--verbose
Muestra mensajes detallados.
-v, --version
Muestra la información de la versión y sale.
-h, --help
Muestra la información de uso y sale.
