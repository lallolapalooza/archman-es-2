FBB::OFoldStream(3bobcat) Dobla líneas largas FBB::OFoldStream(3bobcat)

NOMBRE

FBB::OFoldStream - Dobla líneas largas

SINOPSIS

#include <bobcat/ofoldstream>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

FBB::OFoldStream dobla las líneas largas que se escriben en él. El OFoldStream escribe las líneas (dobladas) en un segundo ostream que es utilizado o abierto por el objeto OFoldStream.

Los objetos OFoldStream nunca doblan líneas en medio de series de caracteres no en blanco, sino que siempre rompen una línea en caracteres de espacio en blanco. Las líneas resultantes siempre aparecerán a la derecha de un margen izquierdo configurable y a la izquierda de un margen derecho configurable. Existe una excepción algo patológica a esto: si una palabra es demasiado larga para caber entre los márgenes, entonces la palabra excederá el margen derecho.

La indentación utilizada para los márgenes izquierdos es configurable para ser espacios (por defecto) o tabulaciones. Cuando se utilizan tabulaciones, el ancho de un carácter de tabulación es configurable, usando un valor por defecto de 8 posiciones en el stream de destino.

OFoldStream está implementado como una clase envoltorio alrededor de std::ostream y FBB::OFoldBuf y una descripción más completa del proceso de doblado se puede encontrar en la página del manual ofoldbuf(3bobcat).

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::ostream,
(y privadamente de FBB::OFoldBuf)

ENUMERACIÓN

La enumeración TabsOrBlanks se utiliza para seleccionar tabulaciones o espacios al escribir la indentación. El valor por defecto son espacios. Cuando se seleccionan tabulaciones, el ancho de visualización de los caracteres de tabulación también se puede configurar (utilizando el valor por defecto de 8 posiciones para cada carácter de tabulación). La enumeración tiene dos valores:

o
BLANKS:
El valor por defecto, que indica que el margen izquierdo se especifica y se escribe como un número de espacios;
o
TABS:
Que indica que el margen izquierdo se especifica y se escribe como un número de caracteres de tabulación.

La enumeración TrailingBlanks se utiliza para configurar el objeto OFoldStream con respecto a cualquier espacio en blanco final que pueda aparecer en la última línea. Es el mismo tipo de enumeración que se usa con OFoldBuf (cf. ofoldbuf(3bobcat)) y tiene dos valores:

o
IGNORE_TRAILING_BLANKS:
Esto indica que los espacios en blanco finales que aparecen en la última línea si no está terminada por un salto de línea no se escribirán en el std::ostream de destino. Este es el valor por defecto utilizado por los objetos OFoldStream.
o
KEEP_TRAILING_BLANKS:
Esto indica que los espacios en blanco finales en la última línea si no está terminada por un salto de línea se escribirán en el std::ostream de destino.

CONSTRUCTORES

o
OFoldStream():
Este constructor inicializa un objeto OFoldStream pero no lo asocia con un stream de destino. Utiliza los valores 0, 80, BLANKS y IGNORE_TRAILING_BLANKS para, respectivamente, su margen izquierdo, margen derecho, caracteres del margen izquierdo y modo de manejo de TrailingBlanks.
o
OFoldStream(char const *fname, size_t leftIndent = 0, size_t rightMargin = 80, TabsOrBlanks tob = BLANKS, TrailingBlanks tb = IGNORE_TRAILING_BLANKS):
Este constructor inicializa un objeto OFoldStream y abre (usando std::ios::out) el stream de destino utilizando el nombre especificado como su argumento fname.
o
OFoldStream(std::ostream &stream, size_t leftIndent = 0, size_t rightMargin = 80, TabsOrBlanks tob = BLANKS, TrailingBlanks tb = IGNORE_TRAILING_BLANKS):
Este constructor inicializa un objeto OFoldStream y utiliza como su stream de destino el std::ostream stream.

El destructor escribe cualquier información en búfer en el stream de destino y luego vacía el stream de destino.

Los constructores de copia y movimiento (y operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::ostream están disponibles, ya que FBB::OFoldStream hereda de esta clase.

o
void close():
Este miembro vacía cualquier información pendiente en el stream de destino y luego cierra el stream de destino.
o
void open(char const *fname, openmode mode = std::ios::out):
Este miembro asocia el objeto OFilterStream con un objeto std::ofstream cuyo nombre de archivo se proporciona y que debe recibir la información doblada.
o
void open(std::ostream &out):
Este miembro asocia el objeto OFilterStream con el objeto ostream proporcionado.
o
void setMargins(size_t leftMargin, size_t rightMargin):
Este miembro puede utilizarse para modificar los márgenes de doblado izquierdo y derecho. Tenga en cuenta que el margen izquierdo también puede modificarse utilizando los manipuladores FBB::lm y FBB::mlm.
o
void setTrailingBlanks(TrailingBlanks tb):
Este miembro puede utilizarse para modificar el parámetro TrailingBlanks actualmente en uso.
o
void useBlanks():
Este miembro puede utilizarse para seleccionar espacios que se usarán al insertar márgenes izquierdos.
o
void useTabs(size_t tabWidth = 8):
Este miembro puede utilizarse para seleccionar caracteres de tabulación que se usarán al insertar márgenes izquierdos. El segundo parámetro se utiliza para especificar el ancho de visualización de un carácter de tabulación.

FUNCIONES MIEMBRO ESTÁTICAS

o
size_t leftMargin(std::ostream const &os):
Este miembro devuelve la configuración actual del margen izquierdo del objeto OFoldStream que se le pasa como argumento. El miembro define un parámetro std::ostream ya que en muchos casos el objeto OFoldStream se utilizará en funciones que a su vez definen parámetros std::ostream. Internamente, el std::streambuf del std::ostream se convierte a un OFoldBuf y se lanza una excepción FBB::Exception si la conversión falla.
o
size_t rightMargin(std::ostream const &os):
Este miembro devuelve la configuración actual del margen derecho del objeto OFoldStream que se le pasa como argumento. El parámetro del miembro se convierte de la misma manera que el argumento de leftMargin(): se lanza una excepción FBB::Exception si la conversión falla.

EJEMPLO

#include <iostream>
#include <string>
#include <bobcat/ofoldstream>
using namespace std;
using namespace FBB;
void margins(ostream &out)
{
    cout << OFoldStream::leftMargin(out) << ", " <<
            OFoldStream::rightMargin(out) << endl;
}
int main()
{
    OFoldStream out(cout, 4, 40);
    out << lm(4);
    string line;
    while (getline(cin, line))
        out << line << ’\n’;
    margins(out);
}
