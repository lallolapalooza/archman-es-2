OSTREE ADMIN DEPLOY(1) ostree admin deploy OSTREE ADMIN DEPLOY(1)

NOMBRE

ostree-admin-deploy - Selecciona una revisión como el nuevo despliegue predeterminado

SINOPSIS

ostree admin deploy [OPCIONES...] {REFSPEC}

DESCRIPCIÓN

Toma un commit o REFSPEC de revisión, y pone en cola el nuevo despliegue como predeterminado tras el reinicio.

OPCIONES

--stateroot="STATEROOT"

Usa un stateroot de sistema operativo diferente al actual.

--os="STATEROOT"

Alias de --stateroot.

--origin-file="FILENAME"

Usa FILENAME como origen, que es donde OSTree buscará versiones actualizadas del árbol.

--retain

No eliminar el despliegue anterior.

--retain-pending

No eliminar los despliegues pendientes.

--retain-rollback

No eliminar los despliegues de reversión.

--not-as-default

Añade el nuevo despliegue al final en lugar de al principio.

--lock-finalization

El despliegue no será "finalizado" por defecto al apagar; para ponerlo en cola más tarde, usa ostree admin lock-finalization --unlock.

--karg-proc-cmdline

Importa el /proc/cmdline actual.

--karg="NOMBRE=VALOR"

Establece un argumento del kernel, como root=/dev/sda1; esto anula cualquier argumento anterior con el mismo nombre.

--karg-append="NOMBRE=VALOR"

Añade un argumento del kernel; útil con, por ejemplo, console= que puede usarse varias veces.

--karg-delete="NOMBRE=VALOR"

Elimina un argumento del kernel si existe, puede usarse varias veces.

EJEMPLO

$ ostree admin status

        * gnome-ostree 67e382b11d213a402a5313e61cbc69dfd5ab93cb07.0
            refspec de origen: gnome-ostree/buildmain/x86_64-runtime
          gnome-ostree ce19c41036cc45e49b0cecf6b157523c2105c4de1ce3.0
            refspec de origen: gnome-ostree/buildmain/x86_64-runtime

$ ostree admin deploy gnome-ostree/buildmain/x86_64-runtime

        ostadmin: Creando despliegue /ostree/deploy/gnome-ostree/deploy/7e382b11d213a402a5313e61cbc69dfd5ab93cb07.1
        ostadmin: Procesando /etc: 3 modificados, 0 eliminados, 29 añadidos
        Transacción completada: cambio de arranque: no cambio de número de despliegues: 0)

$ ostree admin status
