OPAM ADMIN-HELP(1) Manual de administración de Opam OPAM ADMIN-HELP(1)

NOMBRE

opam admin-help - Muestra ayuda sobre comandos de administración de opam y subcomandos de administración de opam.

SINOPSIS

opam admin help [--man-format=FMT] [OPCIÓN]… [TEMA]

DESCRIPCIÓN

Imprime ayuda sobre los comandos de administración de opam.

Utilice `opam admin help topics' para obtener la lista completa de temas de ayuda.

ARGUMENTOS

TEMA
El tema sobre el que obtener ayuda.

OPCIONES

--man-format=FMT (ausente=pager)
Muestra la salida en el formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain cuando la variable de entorno TERM es dumb o no está definida.

OPCIONES COMUNES

--help[=FMT] (por defecto=auto)
Muestra esta ayuda en formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain cuando la variable de entorno TERM es dumb o no está definida.
--version
Muestra información de la versión.

ESTADO DE SALIDA

opam admin help sale con:

0
en caso de éxito.
123
en errores indiscriminados reportados en la salida estándar de error.
124
en errores de análisis de línea de comandos.
125
en errores internos inesperados (bugs).
