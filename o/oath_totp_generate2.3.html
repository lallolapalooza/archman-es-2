oath_totp_generate2(3) liboath oath_totp_generate2(3)

NOMBRE

oath_totp_generate2 - función de API

SINOPSIS

#include <oath.h>

int oath_totp_generate2(const char * secret, size_t secret_length, time_t now, unsigned time_step_size, time_t start_offset, unsigned digits, int flags, char * output_otp);

ARGUMENTOS

const char * secret
la cadena de secreto compartido
size_t secret_length
longitud de secret
time_t now
valor de tiempo Unix para calcular el TOTP
unsigned time_step_size
parámetro del sistema de paso de tiempo (típicamente 30)
time_t start_offset
tiempo Unix de cuándo empezar a contar los pasos de tiempo (típicamente 0)
unsigned digits
número de dígitos solicitados en el OTP, excluyendo el checksum
int flags
banderas que indican el modo, una de las oath_totp_flags
char * output_otp
buffer de salida, debe tener espacio para el OTP de salida más un carácter nulo

DESCRIPCIÓN

Genera una contraseña de un solo uso utilizando el algoritmo TOTP variante en el tiempo descrito en RFC 6238. Los parámetros de entrada se toman como valores de tiempo.

El parámetro del sistema time_step_size describe cuánto dura la ventana de tiempo para cada OTP. El valor recomendado es 30 segundos, y puede usar el valor 0 o el símbolo OATH_TOTP_DEFAULT_TIME_STEP_SIZE para indicarlo.

El parámetro del sistema start_offset denota el tiempo Unix en que se empiezan a contar los pasos de tiempo. El valor recomendado es 0, para volver a la época de Unix) y puede usar el símbolo OATH_TOTP_DEFAULT_START_TIME para indicarlo.

El buffer output_otp debe tener espacio para al menos digits caracteres, más uno para el carácter nulo de terminación.

Actualmente, solo los valores 6, 7 y 8 para digits son soportados. Esta restricción puede ser eliminada en versiones futuras.

El parámetro flags puede ser usado para cambiar la función MAC, por ejemplo OATH_TOTP_HMAC_SHA256 o OATH_TOTP_HMAC_SHA512.

DEVUELVE

En caso de éxito, se devuelve OATH_OK (cero), de lo contrario se devuelve un código de error.
