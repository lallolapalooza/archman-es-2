FBB::OFdBuf(3bobcat) Búfer de flujo de salida de descriptor de archivo FBB::OFdBuf(3bobcat)

NOMBRE

FBB::OFdBuf - Búfer de flujo de salida inicializado por un descriptor de archivo

SINOPSIS

#include <bobcat/ofdbuf>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Los objetos FBB::OFdBuf pueden usarse como un std::streambuf de objetos std::ostream para permitir inserciones en un descriptor de archivo.

Los descriptores de archivo no están definidos en el contexto de C++, pero pueden usarse en sistemas operativos que soporten el concepto. Tenga en cuenta que el uso de descriptores de archivo introduce dependencias del sistema operativo.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::streambuf

ENUMERACIÓN

La enumeración pública Mode definida en la clase FBB::OFdStreamBuf tiene los siguientes valores:

c
CLOSE_FD, indicando que el descriptor de archivo utilizado por el objeto debe cerrarse;
c
KEEP_FD (el valor predeterminado) indicando que el descriptor de archivo utilizado por el objeto no debe cerrarse.

CONSTRUCTORES

c
OFdBuf():
Este constructor inicializa el búfer de flujo, sin asociarlo a un descriptor de archivo y sin usar almacenamiento en búfer. El miembro reset puede usarse para asociar el objeto posteriormente con un descriptor de archivo y opcionalmente un tamaño de búfer. Cuando el objeto se destruye o si se llama a la versión sobrecargada sin modo del miembro reset, se cierra el descriptor de archivo.
c
OFdBuf(Mode mode):
Este constructor inicializa el búfer de flujo, sin asociarlo a un descriptor de archivo y sin usar almacenamiento en búfer. El miembro reset puede usarse para asociar el objeto posteriormente con un descriptor de archivo y opcionalmente un tamaño de búfer. Cuando el objeto se destruye o si se llama a la versión sobrecargada sin modo del miembro reset, el argumento Mode determina si el descriptor de archivo se cerrará o permanecerá abierto.
c
OFdBuf(int fd, size_t n = 1):
Este constructor inicializa el búfer de flujo, asociándolo al descriptor de archivo fd y a un tamaño de búfer de retroceso opcional (por defecto de tamaño 1). Cuando se llame a reset posteriormente, o si se destruye el objeto, se cerrará el descriptor de archivo proporcionado.
c
OFdBuf(int fd, size_t n = 1):
Este constructor inicializa el búfer de flujo, asociándolo al descriptor de archivo fd y a un tamaño de búfer de retroceso opcional (por defecto de tamaño 1). Cuando el objeto se destruye o si se llama a la versión sobrecargada sin modo del miembro reset, se cerrará el descriptor de archivo.
c
OFdBuf(int fd, Mode mode, size_t n = 1):
Este constructor inicializa el búfer de flujo, asociándolo al descriptor de archivo fd, un parámetro de cierre de descriptor de archivo y un tamaño de búfer de retroceso opcional (por defecto de tamaño 1). Dependiendo del argumento Mode, el descriptor de archivo utilizado actualmente por el objeto se cerrará o permanecerá abierto cuando se destruya el objeto IFdBuf.

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::streambuf están disponibles, ya que FBB::OFdBuf hereda de esta clase.

c
void eoi():
Se cierra el descriptor de archivo utilizado por OFdBuf, independientemente del Mode que se especificó al construir el objeto OFdBuf. Después de eoi, el objeto OFdBuf ya no puede utilizarse hasta que se haya llamado a uno de sus miembros reset. En lugar de usar este miembro, también se puede usar el manipulador eoi.
c
int fd() const:
Se devuelve el descriptor de archivo utilizado por el objeto OFdBuf. Si el OFdBuf no está asociado a un descriptor de archivo, se devuelve -1.
c
void reset(int xfd, size_t n = 1):
El búfer de flujo se (re)inicializa, utilizando el descriptor de archivo fd y un tamaño de búfer de retroceso opcional (por defecto de tamaño 1). Cuando se llama repetidamente, la especificación Mode utilizada al construir el objeto determina si el descriptor de archivo se cerrará o permanecerá abierto.
c
void reset(int xfd, Mode mode, size_t n = 1):
El búfer de flujo se (re)inicializa, utilizando el descriptor de archivo fd, un parámetro de cierre de descriptor de archivo y un tamaño de búfer de retroceso opcional (por defecto de tamaño 1). Dependiendo del argumento Mode, el descriptor de archivo utilizado actualmente por el objeto se cerrará o permanecerá abierto cuando se destruya el objeto IFdBuf.
c
void warn(bool on):
Cuando on == true, se escribe una advertencia en el flujo de error estándar cuando su miembro sync devuelve -1. Si no se llama explícitamente a warn, se utiliza on == true.

MANIPULADOR

c
FBB::eoi:
El manipulador eoi puede insertarse en el ostream en lugar de llamar al miembro OFdBuf::end. Realiza las mismas acciones que el miembro eoi. Si se inserta en un std::ostream normal, no ocurre nada.

EJEMPLO

#include <unistd.h>
#include <ostream>
#include <string>
#include "../ofdbuf"
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
                           // define un búfer de flujo de 20 o argc[1] caracteres
    OFdBuf buf{ STDOUT_FILENO, argc == 1 ? 20 : stoul(argv[1]) };
    ostream out{ &buf };
    out << "Primera línea, solo para iniciar las inserciones\n" <<
            argv[0] << endl <<          // usando un flush explícito
            argc << "\n"
            "una línea larga para terminar esta declaración de inserciones múltiples\n";
}
