NOMBRE

openssl-dsa - Procesamiento de claves DSA

SINOPSIS

openssl dsa [-help] [-inform DER|PEM] [-outform DER|PEM] [-in archivo] [-passin arg] [-out archivo] [-passout arg] [-aes128] [-aes192] [-aes256] [-aria128] [-aria192] [-aria256] [-camellia128] [-camellia192] [-camellia256] [-des] [-des3] [-idea] [-text] [-noout] [-modulus] [-pubin] [-pubout] [-pvk-strong] [-pvk-weak] [-pvk-none] [-engine id] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq]

DESCRIPCIÓN

Este comando procesa claves DSA. Pueden ser convertidas entre varias formas y sus componentes ser impresos. Nota Este comando usa el formato tradicional compatible con SSLeay para la encriptación de claves privadas: las aplicaciones más nuevas deberían usar el formato PKCS#8 más seguro usando el comando pkcs8

OPCIONES

-help
Imprime un mensaje de uso.
-inform DER|PEM
El formato de entrada de la clave; no especificado por defecto. Vea openssl-format-options(1) para más detalles.
-outform DER|PEM
El formato de salida de la clave; el valor por defecto es PEM. Vea openssl-format-options(1) para más detalles.

Las claves privadas son una secuencia de ASN.1 INTEGERS: la versión (cero), p, q, g, y los componentes de clave pública y privada. Las claves públicas son una estructura SubjectPublicKeyInfo con el tipo DSA.

El formato PEM también acepta datos PKCS#8.

-in archivo
Este especifica el archivo de entrada para leer una clave o la entrada estándar si esta opción no es especificada. Si la clave está encriptada se pedirá una frase de contraseña.
-out archivo
Este especifica el archivo de salida para escribir una clave o la salida estándar si no es especificado. Si se establecen opciones de encriptación se pedirá una frase de contraseña. El archivo de salida no debe ser el mismo que el archivo de entrada.
-passin arg, -passout arg
La fuente de la contraseña para el archivo de entrada y salida. Para más información sobre el formato de arg vea openssl-passphrase-options(1).
-aes128, -aes192, -aes256, -aria128, -aria192, -aria256, -camellia128, -camellia192, -camellia256, -des, -des3, -idea
Estas opciones encriptan la clave privada con el cifrador especificado antes de sacarla. Se solicita una frase de contraseña. Si ninguna de estas opciones se especifica, la clave se escribe en texto plano. Esto significa que este comando puede usarse para eliminar la frase de contraseña de una clave no especificando ninguna opción de encriptación, o para añadir o cambiar la frase de contraseña estableciéndolas. Estas opciones solo pueden ser usadas con archivos de salida en formato PEM.
-text
Imprime los componentes y parámetros de la clave pública y privada.
-noout
Esta opción previene la salida de la versión codificada de la clave.
-modulus
Esta opción imprime el valor del componente de clave pública de la clave.
-pubin
Por defecto, se lee una clave privada de la entrada. Con esta opción se lee una clave pública en su lugar. Si la entrada no contiene una clave pública sino una clave privada, se usa su parte pública.
-pubout
Por defecto, se saca una clave privada. Con esta opción se sacará una clave pública en su lugar. Esta opción se establece automáticamente si la entrada es una clave pública.
-pvk-strong
Habilita el nivel de codificación PVK 'Fuerte' (por defecto).
-pvk-weak
Habilita el nivel de codificación PVK 'Débil'.
-pvk-none
No forzar la codificación PVK.
-engine id
Vea "Opciones de motor" en openssl(1). Esta opción está deprecada.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Vea "Opciones de Proveedor" en openssl(1), provider(7), y property(7).

El comando openssl-pkey(1) es capaz de realizar todas las operaciones que este comando puede, además de soportar otros tipos de clave pública.

EJEMPLOS

La documentación del comando openssl-pkey(1) contiene ejemplos equivalentes a los enumerados aquí.

Para eliminar la frase de contraseña de una clave privada DSA:

openssl dsa -in clave.pem -out clave_salida.pem

Para encriptar una clave privada usando triple DES:

openssl dsa -in clave.pem -des3 -out clave_salida.pem

Para convertir una clave privada de PEM a formato DER:

openssl dsa -in clave.pem -outform DER -out clave_salida.der

Para imprimir los componentes de una clave privada a la salida estándar:

openssl dsa -in clave.pem -text -noout

Para solo sacar la parte pública de una clave privada:

openssl dsa -in clave.pem -pubout -out clave_publica.pem
