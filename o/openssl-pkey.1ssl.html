Paquete: openssl

OPENSSL-PKEY(1ssl) OpenSSL OPENSSL-PKEY(1ssl)

NOMBRE

openssl-pkey - comando para procesar claves públicas o privadas

SINOPSIS

openssl pkey [-help] [-engine id] [-provider name] [-provider-path path] [-provparam [name:]key=value] [-propquery propq] [-check] [-pubcheck] [-in filename|uri] [-inform DER|PEM|P12|ENGINE] [-passin arg] [-pubin] [-out filename] [-outform DER|PEM] [-cifra] [-passout arg] [-traditional] [-pubout] [-noout] [-text] [-text_pub] [-ec_conv_form arg] [-ec_param_enc arg]

DESCRIPCIÓN

Este comando procesa claves públicas o privadas. Pueden ser convertidas entre varias formas y sus componentes impresos.

OPCIONES

Opciones generales

-help
Imprime un mensaje de uso.
-engine id
Ver "Engine Options" en openssl(1). Esta opción está obsoleta.
-provider name
-provider-path path
-provparam [name:]key=value
-propquery propq
Ver "Provider Options" en openssl(1), provider(7), y property(7).
-check
Esta opción comprueba la consistencia de un par de claves para ambos componentes, pública y privada.
-pubcheck
Esta opción comprueba la corrección de una clave pública o del componente público de un par de claves.

Opciones de entrada

-in filename|uri
Esto especifica el archivo de entrada para leer una clave o la entrada estándar si no se especifica esta opción.

Si la entrada de la clave está cifrada y no se proporciona -passin, se solicitará una frase de contraseña.

-inform DER|PEM|P12|ENGINE
El formato de entrada de la clave; no especificado por defecto. Ver openssl-format-options(1) para detalles.
-passin arg
La fuente de contraseña para la entrada de la clave.

Para más información sobre el formato de arg ver openssl-passphrase-options(1).

-pubin
Por defecto se lee una clave privada de la entrada. Con esta opción se lee una clave pública en su lugar. Si la entrada no contiene una clave pública sino una clave privada, se utiliza su parte pública.

Opciones de salida

-out filename
Esto especifica el archivo de salida para guardar la salida codificada y/o de texto de la clave o la salida estándar si no se especifica esta opción. El nombre del archivo de salida puede ser el mismo que el nombre del archivo de entrada, lo que lleva a reemplazar el contenido del archivo. Tenga en cuenta que la E/S de archivos no es atómica. El archivo de salida se trunca y luego se escribe.

Si se establece alguna opción de cifrado pero no se proporciona -passout, se solicitará una frase de contraseña. Cuando la entrada de contraseña se interrumpe, el archivo de salida no se toca.

-outform DER|PEM
El formato de salida de la clave; el valor por defecto es PEM. Ver openssl-format-options(1) para detalles.
-cifra
Cifra la clave privada codificada en PEM con la cifra proporcionada. Cualquier nombre de algoritmo aceptado por EVP_get_cipherbyname() es aceptable como aes128. El cifrado no está soportado para salida DER.
-passout arg
La fuente de contraseña para el archivo de salida.

Para más información sobre el formato de arg ver openssl-passphrase-options(1).

-traditional
Normalmente una clave privada se escribe usando el formato estándar: es el formato PKCS#8 con el algoritmo de cifrado apropiado (si lo hay). Si se especifica la opción -traditional, se usa en su lugar el formato "tradicional" más antiguo.
-pubout
Por defecto se emite la clave privada y pública; esta opción restringe la salida a los componentes públicos. Esta opción se establece automáticamente si la entrada es una clave pública.

Cuando se combina con -text, esto es equivalente a -text_pub.

-noout
No emite la clave en formato codificado.
-text
Emite los diversos componentes de la clave en texto plano (posiblemente en adición a la forma codificada en PEM). Esto no se puede combinar con la salida codificada en formato DER.
-text_pub
Emite en formato de texto solo los componentes de la clave pública (también para claves privadas). Esto no se puede combinar con la salida codificada en formato DER.
-ec_conv_form arg
Esta opción solo se aplica a claves basadas en curvas elípticas.

Esto especifica cómo se convierten los puntos de la curva elíptica en cadenas de octetos. Los valores posibles son: compressed (el valor por defecto), uncompressed y hybrid. Para más información sobre las formas de conversión de puntos, por favor lea el estándar X9.62. Nota Debido a problemas de patentes, la opción compressed está deshabilitada por defecto para curvas binarias y puede ser habilitada definiendo la macro de preprocesador OPENSSL_EC_BIN_PT_COMP en tiempo de compilación.

-ec_param_enc arg
Esta opción solo se aplica a claves públicas y privadas basadas en curvas elípticas.

Esto especifica cómo se codifican los parámetros de la curva elíptica. Los valores posibles son: named_curve, es decir, los parámetros ec se especifican por un OID, o explicit donde los parámetros ec se dan explícitamente (ver RFC 3279 para la definición de las estructuras de parámetros EC). El valor por defecto es named_curve. Nota la alternativa implicitlyCA, como se especifica en RFC 3279, actualmente no está implementada en OpenSSL.

EJEMPLOS

Para eliminar la frase de contraseña de una clave privada:

openssl pkey -in key.pem -out keyout.pem

Para cifrar una clave privada usando triple DES:

openssl pkey -in key.pem -des3 -out keyout.pem

Para convertir una clave privada de formato PEM a DER:

openssl pkey -in key.pem -outform DER -out keyout.der

Para imprimir los componentes de una clave privada en la salida estándar:

openssl pkey -in key.pem -text -noout

Para imprimir los componentes públicos de una clave privada en la salida estándar:

openssl pkey -in key.pem -text_pub -noout

Para emitir solo la parte pública de una clave privada:

openssl pkey -in key.pem -pubout -out pubkey.pem

Para cambiar la codificación de parámetros EC a explicit:

openssl pkey -in key.pem -ec_param_enc explicit -out keyout.pem
