Paquete: libbobcat

FBB::OMutexStream(3bobcat) std::ostream protegido por mutex FBB::OMutexStream(3bobcat)

NOMBRE

FBB::OMutexStream - Ofrece instalaciones de std::ostream protegidas por mutex

SINOPSIS

#include <bobcat/omutexstream>
Opción de enlace: -lbobcat

DESCRIPCIÓN

En programas multihilo, la salida escrita por diferentes hilos en el mismo flujo de salida puede mezclarse debido a los cambios de contexto. Esto se previene usando mutex: antes de escribir en el flujo de salida, se adquiere un bloqueo de mutex, liberando el bloqueo una vez que la salida se completa.

OMutexStream soporta la escritura en flujos de salida mientras maneja los bloqueos de mutex. El objeto OMutexStream en sí mismo se inicializa con el objeto std::ostream para recibir la información escrita en el objeto OMutexStream. Este objeto, como std::cout y std::err, generalmente se define como un objeto accesible globalmente. Al insertar información en el objeto OMutexStream, OMutexStream primero devuelve un objeto OMutexStream::Out, cuyo constructor bloquea el mutex de OMutexStream::Out. La vida útil del objeto OMutexStream::Out termina al final de la instrucción de inserción, y en ese momento su destructor libera el bloqueo.

En muchos casos, esto es apropiado. Especialmente cuando las instrucciones terminan con saltos de línea (’\n’ o endl), esto resulta en una salida limpia. En algunos casos, este enfoque no funciona. Considere la situación en la que la salida se produce por una serie de iteraciones en una declaración for. Para estos casos, OMutexStream ofrece el miembro ostream que devuelve un objeto OMutexStream::Out. Como ese objeto también bloquea el mutex, el bloqueo también permanece activo durante su vida útil. Durante su vida útil, se pueden ejecutar expresiones de inserción OMutexStream separadas. Por ejemplo, el siguiente fragmento de código completará toda la salida, forzando a los hilos competidores a esperar:

    void fun()
    {
        OMutexStream mout{ std::cout }; // crea un objeto OMutexStream
        {
            auto out{ mout.ostream() }  // bloquea el mutex (bloqueo #1)
            mout << "Hola ";           // también bloquea (bloqueo #2, en ;
                                        //             de vuelta a bloqueo #1)
            out << "mundo\n";
        }                               // 'out' libera el bloqueo
    }
Tenga cuidado de restringir la vida útil del objeto devuelto por OMutexStream::ostream().

HEREDA DE

(a través de OMutexStream::Out) std::ostream

CONSTRUCTORES

o
OMutexStream(std::ostream &out):
El objeto OMutexStream se inicializa con un objeto std::ostream.

Se encuentran disponibles constructores y operadores de asignación de copia y movimiento.

OPERADORES SOBRECARGADOS

o
OMutexStream::Out operator<<(OMutexStream const &mstr, Tp &&tp):
Este miembro es una plantilla de función. Su referencia de reenvío se pasa al objeto OMutexStream::Out construido por mstr. Dado que los constructores de OMutexStream::Out bloquean el mutex de la clase, y dado que OMutexStream::Out se deriva de std::ostream, todas las operaciones de inserción y otras operaciones permitidas para std::ostream también se pueden usar para objetos OMutexStream::Out.
o
OMutexStream::Out operator<<(OMutexStream const &mstr, Ret &(*manip)(Ret &os)):
Este miembro también es una plantilla de función. Se utiliza para insertar manipuladores sin argumentos en objetos OMutexStream::Out.

FUNCIONES MIEMBRO

o
OMutexStream::Out ostream() const:
Se devuelve un objeto OMutexStream::Out que ha bloqueado su mutex y mantendrá el bloqueo durante su vida útil. Toda la funcionalidad de la clase std::ostream también se puede utilizar para el objeto OMutexStream::Out devuelto por ostream.
Tenga cuidado de restringir la vida útil del objeto devuelto por OMutexStream::ostream() para evitar bloqueos de mutex innecesariamente largos.

EJEMPLO

#include <iostream>
#include <thread>
#include <chrono>
#include <cstdlib>
#include <cmath>
#include <ctime>
#include <bobcat/omutexstream>
using namespace std;
using namespace FBB;
OMutexStream mout(cout);
void run(int nr)
{
    for (size_t idx = 0; idx != 3; ++idx)
    {
        mout << "hola mundo 1 desde hilo " << nr << ": " <<
                log(rand()) << endl;
        this_thread::sleep_for(
                chrono::milliseconds(200 + rand() % 800));
       mout << "hola mundo 2 desde hilo " << nr << ": " <<
                log(rand()) << ’\n’;
        this_thread::sleep_for(
                chrono::milliseconds(200 + rand() % 800));
    }
    auto out{ mout.ostream() };
    cout << nr << ": " << out.tellp() << ’\n’;
}
int main()
{
    srand(time(0));
    thread t1(run, 1);
    thread t2(run, 2);
    thread t3(run, 3);
    thread t4(run, 4);
    t1.join();
    t2.join();
    t3.join();
    t4.join();
}
