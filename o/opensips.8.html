opensips(8) Servidor SIP de Voz sobre IP opensips(8)

NOMBRE

opensips - servidor SIP (RFC3261, RFC3263) flexible y robusto para Voz sobre IP (VoIP)

SINOPSIS

opensips [ -hcCrRvdDEVT ] [ -f archivo-config ] [ -l dirección ] [ -n num-procesos ] [ -N num-procesos-tcp ] [ -b tam-max-rcv-buf ] [ -m tam-mem-compartida ] [ -w dir-trabajo ] [ -W metodo ] [ -t dir-chroot ] [ -u uid ] [ -g gid ] [ -P archivo-pid ] [ -i ruta-fifo ] [ -x ruta-socket ]

DESCRIPCIÓN

OpenSIPS es un servidor VoIP basado en SIP que se ejecuta en la mayoría de los sistemas operativos tipo Unix. Soporta las capas de transporte UDP, TCP y TLS. Entre sus características se incluyen:

  • Servidor Proxy SIP, Servidor Registrador SIP, Servidor Redireccionador SIP, Servidor de Ubicación SIP, Servidor de Aplicaciones SIP
  • Lenguaje de Procesamiento de Llamadas (RFC3880)
  • Soporte ENUM
  • Trascendencia NAT del lado del servidor
  • Balanceo de carga
  • AAA con base de datos (MySQL, Postgres, Unixodbc) o backend RADIUS
  • audio, video, mensajería instantánea y presencia

OPCIONES

-h
Muestra una breve descripción del uso, incluyendo todas las opciones disponibles.
-c
Verifica el archivo de configuración y muestra la lista de alias e interfaces de escucha.
-C
Similar a -c, pero además verifica las banderas de las funciones exportadas de los bloques de ruta incluidos.
-r
Utiliza DNS para comprobar si es necesario añadir un campo "received=" a un via.
-R
Igual que -r pero utiliza DNS inverso.
-v
Activa la comprobación de host via al reenviar respuestas.
-d
Activa la depuración, múltiples -d aumentan el nivel de depuración.
-D
Ejecuta opensips en primer plano (no se bifurca al modo demonio).
-E
Envía todos los mensajes de registro a stderr.
-T
Desactiva el soporte TCP.
-V
Muestra el número de versión.
-f archivo-config
Lee la configuración de archivo-config (por defecto /etc/opensips/opensips.cfg).
-l dirección
Escucha en la dirección/interfaz especificada. Múltiples -l significan escuchar en múltiples direcciones. El formato de la dirección es [proto:]dirección[:puerto], donde proto = udp|tcp y dirección = host|direccion-ip|nombre-interfaz. Ejemplo: -l localhost, -l udp:127.0.0.1:5080, -l eth0:5062. El comportamiento por defecto es escuchar en todas las interfaces ipv4.
-n num-procesos
Especifica el número de procesos hijos bifurcados por interfaz (por defecto 8).
-N num-procesos-tcp
Especifica el número de procesos hijos bifurcados para manejar las conexiones entrantes TCP (por defecto es igual a -n ).
-b tam-max-rcv-buf
Tamaño máximo del búfer de recepción que no será excedido por el procedimiento de autocomprobación, incluso si el sistema operativo lo permite.
-m tam-mem-compartida
Tamaño de la memoria compartida que se asignará (en Megabytes).
-w dir-trabajo
Especifica el directorio de trabajo. En el muy improbable caso de que opensips falle, el archivo core se generará aquí.
-W metodo
Especifica el método de sondeo.
-t dir-chroot
Fuerza a opensips a hacer chroot después de leer el archivo de configuración.
-u uid
Cambia el ID de usuario bajo el cual se ejecuta opensips.
-g gid
Cambia el ID de grupo bajo el cual se ejecuta opensips.
-P archivo-pid
Crea un archivo que contiene el PID del proceso principal de opensips.
-i ruta-fifo
Crea una fifo, útil para monitorizar el estado de opensips.
-x ruta-socket
Crea un socket Unix, útil para monitorizar el estado de opensips (igual que -i ruta-fifo pero utilizando sockets Unix en su lugar).
