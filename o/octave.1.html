OCTAVE(1) Manual de comandos generales OCTAVE(1)

NOMBRE

octave - Un lenguaje de programación interactivo de alto nivel para cálculos numéricos.

SINOPSIS

octave [opciones]... [archivo]

DESCRIPCIÓN

Octave es un lenguaje de programación científica interactivo de alto nivel. Tiene una potente sintaxis orientada a las matemáticas para resolver problemas numéricamente, así como herramientas integradas de trazado y visualización 2D/3D. Octave proporciona un entorno de desarrollo integrado, ya sea en forma gráfica o de línea de comandos. Los programas también pueden ejecutarse en modo por lotes para procesar datos sin interacción.

OPCIONES

Una lista de las opciones de línea de comandos más útiles para octave está disponible ejecutando el siguiente comando desde la consola.

octave --help

DOCUMENTACIÓN

La documentación principal de Octave está escrita en Texinfo, el sistema de documentación de GNU, que permite utilizar los mismos archivos fuente para producir versiones en línea e impresas del manual.

Puede leer la copia integrada de la documentación de Octave ejecutando el siguiente comando desde dentro de octave.

    octave:1> doc
Los archivos Info también pueden leerse con un programa independiente como info o xinfo. Las versiones HTML, Postscript o PDF de la documentación también están instaladas en muchos sistemas. La última versión de la documentación está disponible en https://docs.octave.org/latest.

ERRORES

El proyecto Octave mantiene un rastreador de errores en https://bugs.octave.org. Antes de enviar un nuevo elemento, por favor, lea las instrucciones en https://www.octave.org/bugs.html sobre cómo enviar un informe útil.

ARCHIVOS

Al iniciar, Octave busca cuatro archivos de inicialización. Cada archivo puede contener cualquier número de comandos válidos de Octave.

octave-home/share/octave/site/m/startup/octaverc
Archivo de inicialización a nivel de sitio que cambia las opciones para todos los usuarios. octave-home es el directorio donde se instaló Octave, como por ejemplo /usr/local.
octave-home/share/octave/version/m/startup/octaverc
Archivo de inicialización a nivel de sitio para la versión de Octave version.
~/.octaverc
Archivo de inicialización personal del usuario.
.octaverc
Archivo de inicialización específico del proyecto ubicado en el directorio actual.
