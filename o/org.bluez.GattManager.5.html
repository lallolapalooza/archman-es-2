Nombre

org.bluez.GattManager - Documentación de la API GattManager de BlueZ D-Bus

Descripción

GATT Manager permite a las aplicaciones externas registrar perfiles y servicios GATT.

Registrar un perfil permite a las aplicaciones suscribirse a servicios remotos/cliente.

Registrar un servicio permite a las aplicaciones publicar un servicio GATT local/servidor, que luego se pone a disposición de dispositivos remotos. Un servicio GATT se representa mediante una jerarquía de objetos D-Bus donde el nodo raíz corresponde a un servicio y los nodos hijos representan características y descriptores que pertenecen a ese servicio. Cada nodo debe implementar una de las interfaces org.bluez.GattService(5), org.bluez.GattCharacteristic(5) o org.bluez.GattDescriptor(5), basado en el atributo que representa. Cada nodo también debe implementar la interfaz estándar de Propiedades D-Bus para exponer sus propiedades. Estos objetos representan colectivamente una definición de servicio GATT.

Para simplificar el registro de servicios, bluetoothd(8) requiere que todos los objetos que pertenecen a un servicio GATT estén agrupados bajo un Gestor de Objetos D-Bus que gestiona únicamente los objetos de ese servicio. Por lo tanto, la interfaz estándar DBus.ObjectManager debe estar disponible en la ruta del objeto del servicio raíz. Una jerarquía de aplicación de ejemplo que contiene dos servicios GATT separados podría verse así:

-> /com/example
  |   - org.freedesktop.DBus.ObjectManager
  |
  -> /com/example/service0
  | |   - org.freedesktop.DBus.Properties
  | |   - org.bluez.GattService1
  | |
  | -> /com/example/service0/char0
  | |     - org.freedesktop.DBus.Properties
  | |     - org.bluez.GattCharacteristic1
  | |
  | -> /com/example/service0/char1
  |   |   - org.freedesktop.DBus.Properties
  |   |   - org.bluez.GattCharacteristic1
  |   |
  |   -> /com/example/service0/char1/desc0
  |       - org.freedesktop.DBus.Properties
  |       - org.bluez.GattDescriptor1
  |
  -> /com/example/service1
    |   - org.freedesktop.DBus.Properties
    |   - org.bluez.GattService1
    |
   -> /com/example/service1/char0
        - org.freedesktop.DBus.Properties
        - org.bluez.GattCharacteristic1

Cuando se registra un servicio, bluetoothd(8) obtendrá automáticamente información sobre todos los objetos utilizando el Gestor de Objetos del servicio. Una vez que un servicio ha sido registrado, los objetos de un servicio no deben eliminarse. Si bluetoothd(8) recibe una señal InterfacesRemoved de un Gestor de Objetos del servicio, anulará el registro del servicio inmediatamente. De manera similar, si la aplicación se desconecta del bus, todos sus servicios registrados se anularán automáticamente. Las señales InterfacesAdded se ignorarán.

Métodos

void RegistrarAplicacion(object application, dict options)

Registra una jerarquía de servicios GATT locales (Servidor GATT) y/o perfiles GATT (Cliente GATT).

La ruta del objeto de la aplicación, junto con el identificador de la conexión del bus del sistema D-Bus, definen la identificación de la aplicación que registra un servicio basado en GATT (org.bluez.GattService(5)) y/o un perfil (org.bluez.GattProfile(5)).

Posibles errores:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.YaExiste

void AnularRegistroAplicacion(object application)

Anula el registro de los servicios y/o perfiles que se han registrado previamente utilizando RegistrarAplicacion(). El parámetro de ruta del objeto debe coincidir con el mismo valor que se utilizó en el registro.

Posibles errores:

org.bluez.Error.ArgumentosInvalidos
org.bluez.Error.NoExiste
