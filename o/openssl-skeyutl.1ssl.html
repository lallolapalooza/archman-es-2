OPENSSL-SKEYUTL(1ssl) OpenSSL OPENSSL-SKEYUTL(1ssl)

NOMBRE

openssl-skeyutl - rutinas para claves simétricas opacas

SINOPSIS

openssl skeyutl [-help] [-cipher cifrador] [-skeymgmt skeymgmt] [-skeyopt opt:valor] [-genkey] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq]

DESCRIPCIÓN

No todas las implementaciones de cifrado admiten claves como bytes crudos. Por ejemplo, los tokens PKCS#11 pueden almacenarlas internamente sin ninguna opción para obtener la representación de bytes crudos.

Esta herramienta está diseñada para gestionar claves simétricas opacas.

OPCIONES

-help
Imprime un mensaje de uso.
-cipher cifrador
El cifrador para el cual se generará la clave.
-skeymgmt skeymgmt
Algunos proveedores pueden admitir objetos de claves simétricas opacas. Para utilizarlos, necesitamos conocer el skeymgmt. Si no se especifica, se utilizará el nombre del cifrador.

Para averiguar el nombre del gestor de claves simétricas adecuado, consulte la salida del comando "openssl list -skey-managers".

-skeyopt opt:valor
Para obtener una clave simétrica opaca existente o generar una nueva, las opciones de clave se especifican como opt:valor. Estas opciones no se pueden usar junto con ninguna opción que implique una clave cruda, ya sea directa o indirectamente.
-genkey
Genera un nuevo objeto de clave opaca.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Ver las "Opciones del Proveedor" en openssl(1), provider(7) y property(7).

VER TAMBIÉN

openssl-enc(1), EVP_SKEY(3)

HISTORIA

El comando skeyutl se añadió en OpenSSL 3.5.
