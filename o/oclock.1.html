OCLOCK(1) Manual de Comandos Generales OCLOCK(1)

NOMBRE

oclock - reloj redondo de X

SINOPSIS

oclock [-opción ... ]

DESCRIPCIÓN

Oclock simplemente muestra la hora actual en una pantalla analógica.

OPCIONES

-fg color
elige un color diferente para las manecillas y la joya del reloj
-bg color
elige un color diferente para el fondo.
-jewel color
elige un color diferente para la joya del reloj.
-minute color
elige un color diferente para la manecilla de los minutos del reloj.
-hour color
elige un color diferente para la manecilla de las horas del reloj.
-backing { WhenMapped Always NotUseful }
selecciona un nivel apropiado de almacenamiento de respaldo.
-geometry geometría
define la geometría inicial de la ventana; véase X(7).
-display pantalla
especifica la pantalla a usar; véase X(7).
-bd color
elige un color diferente para el borde de la ventana.
-bw ancho
elige un ancho diferente para el borde de la ventana. Como el widget Clock cambia bastante su borde, esto se usa más útilmente establecido a cero.
-shape
hace que el reloj use la extensión Shape para crear una ventana ovalada. Esta es la opción predeterminada a menos que el recurso shapeWindow se establezca en falso.
-noshape
hace que el reloj no cambie de forma él mismo ni a sus ancestros para que encajen exactamente en el contorno del reloj.
-transparent
hace que el reloj consista solo en la joya, las manecillas y el borde.
-help
imprime un mensaje de uso y sale.
-version
imprime información de la versión y sale.

COLORES

Si desea que su reloj sea visible en color, incluya lo siguiente en la sección #ifdef COLOR que lea con xrdb:

*customization: -color

Esto hará que oclock recoja los colores del archivo de personalización de color de app-defaults: /usr/lib/X11/app-defaults/Clock-color. A continuación se muestran los colores predeterminados:

Clock*Background: grey
Clock*BorderColor: light blue
Clock*hour: yellow
Clock*jewel: yellow
Clock*minute: yellow
