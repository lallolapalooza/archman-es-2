NOMBRE

odbx-sql - Navaja suiza para comunicarse con bases de datos y shell SQL interactivo

SINOPSIS


odbx-sql
[-?] [-b backend] [-c configfile] [-d database] [-f delimiter] [-h host] [-i] [-k keywordfile] [-p port] [-s separator] [-u username] [-w]

DESCRIPCIÓN

odbx-sql es una utilidad pequeña y flexible para comunicarse con las bases de datos soportadas por la biblioteca OpenDBX. En modo batch, su propósito principal es automatizar tareas en scripts de shell que requieren trabajar con bases de datos. Por otro lado, el modo interactivo proporciona un shell SQL conveniente para modificar el contenido de la base de datos o probar sentencias. El formato de la salida se puede controlar hasta cierto punto definiendo cadenas para separar columnas y delimitar valores de campos.

OPCIONES

-h, --help
Imprime la ayuda, incluyendo una breve descripción de las opciones disponibles.
-b, --backend=nombre
Nombre del backend de base de datos que debe usarse o ruta a la biblioteca backend del driver OpenDBX.
-c, --config=archivo_config
Archivo de configuración con los parámetros necesarios para conectarse a la base de datos. El archivo puede incluir valores para el backend que debe usarse, el nombre del host o la dirección IP (y quizás el puerto si es necesario), el nombre de la base de datos y el usuario y la contraseña. Estos valores deben colocarse en el archivo de configuración para poder acceder a ellos de forma segura desde la ejecución de programas no interactivos sin revelar la contraseña en ningún lugar. Un ejemplo completo de dicho archivo de configuración se puede encontrar en la sección de ejemplos de este manual.
-d, --database=nombre
Nombre de la base de datos en el servidor o ruta al archivo de base de datos en el sistema de archivos local.
-f, --delimiter=caracter
Un solo carácter o cadena que debe rodear los valores de campo que son devueltos por sentencias similares a SELECT y se imprimen en stdout.
-h, --host=nombre
Nombre del host, dirección IP o ruta al archivo de base de datos. También puede ser la ruta a una tubería con nombre para comunicarse con el servidor de base de datos solo localmente.
-i, --interactive
Ejecutar en modo interactivo y proporcionar un shell SQL conveniente en contraposición al modo batch que espera entrada de stdin e imprime resultados en stdout.
-k archivo_palabras_clave
Ubicación de un archivo de palabras clave utilizado para proporcionar autocompletado de palabras clave.
-p, --port=puerto
Nombre o número de puerto TCP/IP en el que escucha el servidor de base de datos. Si este parámetro no se añade en la línea de comandos, la mayoría de las bibliotecas cliente de base de datos usan el valor predeterminado. Muchos, pero no todos, los servidores de bases de datos pueden resolver el número de puerto a partir de su nombre y, para una máxima portabilidad, el valor del parámetro debe ser el número de puerto.
-s separador
Un solo carácter o cadena que debe separar los valores de campo que son devueltos por sentencias similares a SELECT y se imprimen en stdout.
-u, --username=nombre
Nombre del usuario que se envía al servidor de base de datos para autenticación.
-w, --password
Solicitar una contraseña en la línea de comandos.

EJEMPLOS

Archivo de configuración

 backend = mysql
 host = localhost
 port = 3306
 database = test
 username = miusuario
 password = secreto

Inicio en modo interactivo

odbx-sql -c mysql.conf -i

Ejecución de comandos en modo batch

cat stmt.sql | odbx-sql -c mysql.conf

ESTADO DE SALIDA

odbx-sql devuelve 1 si ocurrió un error y 0 si todos los comandos se completaron con éxito o solo se informaron advertencias. Si ocurren advertencias, se escriben en stderr.
