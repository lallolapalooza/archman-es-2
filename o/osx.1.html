Paquete: opensp

Licencias: BSD

OSX(1) Referencia OSX(1)

NOMBRE

osx - Un conversor de SGML a XML

SINOPSIS

osx [-CeghnRvx] [-anombre] [-Aarquitectura] [-bcodificación] [-carchivo_catálogo] [-ddirectorio] [-Ddirectorio] [-inombre] [-farchivo] [-larchivo_dtd] [-wtipo_advertencia] [-xopción_salida_xml...] [sysid...]

DESCRIPCIÓN

osx convierte SGML a XML. osx analiza y valida el documento SGML contenido en

y escribe un documento XML equivalente en la salida estándar. osx advertirá sobre construcciones SGML que no tienen un equivalente en XML.

Parte de un Sistema SGML Conforme al Estándar Internacional ISO 8879 -- Lenguaje de Marcado Generalizado Estándar. Un sistema de Extensiones SGML Conforme al Anexo A del Estándar Internacional ISO/IEC 10744 -- Lenguaje de Estructuración Basado en Hipermedios/Tiempo.

OPCIONES

Las siguientes opciones están disponibles:

-anombre, --activar=nombre

Hace que el doctype o linkname nombre esté activo.

-Anombre, --arquitectura=nombre

Analiza con respecto a la arquitectura nombre.

-bcodificación, --codificacion=codificación

Utiliza la codificación BCTF para la salida. Por defecto osx usa UTF-8.

-csysid, --catalogo=sysid

Mapea identificadores públicos y nombres de entidades a identificadores del sistema usando el archivo de entrada de catálogo cuyo identificador del sistema es sysid.

-C, --catalogos

Esto tiene el mismo efecto que en onsgmls(1).

-ddirectorio, --ubicacion_salida_entidades=directorio

Coloca los archivos de salida en directorio.

-Ddirectorio, --directorio=directorio

Busca en el directorio los archivos especificados en los identificadores del sistema. Esto tiene el mismo efecto que en onsgmls(1).

-e, --entidades-abiertas

Describe las entidades abiertas en los mensajes de error.

-Emax_errores, --max-errores=max_errores

Rendirse después de max_errores errores.

-farchivo, --archivo-errores=archivo

Redirige los errores al archivo. Esto es útil principalmente con shells que no soportan la redirección de stderr.

-g, --elementos-abiertos

Describe los elementos abiertos en los mensajes de error.

-h, --ayuda

Muestra un texto de ayuda y sale.

-inombre, --incluir=nombre

Esto tiene el mismo efecto que en onsgmls(1).

-larchivo_dtd, --ubicacion_dtd=archivo_dtd

Especifica que el archivo XML resultante debe conformarse al DTD en archivo_dtd.

-n, --numeros-error

Muestra los números de error en los mensajes de error.

--referencias

Muestra referencias en los mensajes de error.

-R, --restringido

Esto tiene el mismo efecto que en onsgmls(1).

-v, --version

Imprime el número de versión y sale.

-wtipo, --advertencia=tipo

Controla las advertencias y errores según el tipo. Esto tiene el mismo efecto que en onsgmls(1).

-xopción_salida_xml, --opcion-salida-xml=opción_salida_xml

Controla la salida XML según el valor de opción_salida_xml de la siguiente manera:

no-nl-in-tag No usar saltos de línea dentro de las etiquetas de inicio. Normalmente osx usa saltos de línea dentro de las etiquetas de inicio para reducir la probabilidad de líneas excesivamente largas.

id Imprime declaraciones de atributos para atributos ID.

notation Imprime declaraciones de notaciones.

ndata Imprime declaraciones para entidades de datos externas. XML requiere que estas sean NDATA. osx advertirá sobre entidades de datos externas CDATA y SDATA y las imprimirá como entidades NDATA.

cdata Usa secciones CDATA de XML para secciones marcadas como CDATA y para elementos con un contenido declarado como CDATA.

comment Imprime declaraciones de comentarios. Las declaraciones de comentarios en el DTD no se imprimirán.

lower Prefiere minúsculas. Los nombres que fueron sometidos a sustitución a mayúsculas por SGML se convertirán a minúsculas. Esto no incluye nombres reservados; XML requiere que estos estén en mayúsculas.

pi-escape Escapa &<> en los contenidos de las instrucciones de procesamiento usando las entidades amp, lt y gt. Esto permite que las instrucciones de procesamiento contengan la cadena >?, pero requiere que las aplicaciones manejen los escapes.

empty Usa la sintaxis <e/> para tipos de elementos e declarados como VACÍOS (EMPTY).

attlist Imprime una declaración ATTLIST para cada elemento especificando el tipo de todos los atributos. El valor por defecto siempre será #IMPLIED.

report-input-sources Imprime una instrucción de procesamiento para informar cuándo se abre o cierra una fuente de entrada distinta del archivo principal en la instancia. No informar ningún cambio de fuente de entrada en el DTD.

report-entities Imprime una instrucción de procesamiento para informar cuándo se ha resuelto una referencia a una entidad externa en la instancia. No informar ninguna resolución de entidad en el DTD.

no-expand-external Conserva las entidades externas, escribe un archivo controlador de declaración llamado "extEntities.dtf", e incluye ese archivo en el subset interno de la instancia.

no-expand-internal Conserva las entidades internas, escribe un archivo controlador de declaración llamado "intEntities.dtf", e incluye ese archivo en el subset interno de la instancia.

no-external-decl No incluye el archivo controlador de declaración de entidades externas en el subset interno de la instancia.

no-internal-decl No incluye el archivo controlador de declaración de entidades internas en el subset interno de la instancia.

no-output-outside-outdir Al conservar entidades externas, no escribir archivos de salida fuera del directorio de salida especificado ("." por defecto). En otras palabras, si el identificador del sistema de una entidad externa incluye suficientes instancias de ".." para que osx escriba un archivo fuera (por encima) del directorio de salida, saldrá (por defecto osx emitirá una advertencia pero escribirá el archivo y continuará.

no-overwrite Al conservar entidades internas o externas, se escribirán múltiples archivos de salida. Si se especifica esta opción, no sobrescribir los archivos existentes; en su lugar, intente añadir un número al final del nombre de archivo original para crear un nombre de archivo único. Salga con un error si ya existen demasiados (100) de dichos archivos.

preserve-case Conserva las mayúsculas según lo especificado en el DTD para nombres de elementos; nombres de atributos; valores de atributos que son listas de tokens.

sdata-as-pis Al traducir entidades SDATA (ya sea expandiéndolas o proporcionando una definición para ellas en el subset interno de la salida), exprésalas como instrucciones de procesamiento en lugar de como entidades generales internas.

Se permiten múltiples opciones -x.

OpenJade(1)
Formatting support for SGML/XML documents

NAME

openjade - Formatting support for SGML/XML documents

SYNOPSIS

openjade [ -a ] [ -b ] [ -c ] [ -d catalog ] [ -D directory ] [ -e ] [ -f ] [ -F ] [ -h ] [ -i ] [ -I directory ] [ -l ] [ -m ] [ -M memory ] [ -N ] [ -O output_file ] [ -p ] [ -P ] [ -r ] [ -s ] [ -S size ] [ -t output_mode ] [ -T ] [ -u ] [ -v ] [ -V ] [ -w ] [ -x feature ] [ -X feature ] [ -z ] filename

DESCRIPTION

OpenJade is an implementation of the Jade DSSSL (Document Style Semantics and Specification Language) processing system. It is used to transform SGML and XML documents into various output formats, such as TeX, HTML, and RTF.

The system consists of three main components:

  • jadetex: A formatter for creating TeX output.
  • jadetex.oasis: An extension of jadetex for OASIS documents.
  • tex: The TeX typesetting system.

OpenJade processes SGML or XML documents according to a specified style sheet (DSSSL). The output can be in various formats, with TeX being the most common and powerful.

OPTIONS

OpenJade supports a wide range of options that control its behavior and output. Some of the common options include:

  • -a: Enable automatic entity processing.
  • -b: Force batch mode (suppress interactive prompts).
  • -c catalog: Specify a catalog file for resolving system identifiers.
  • -d directory: Add a directory to the search path for style sheets.
  • -D directory: Add a directory to the search path for DTDs.
  • -e: Enable error recovery.
  • -f: Enable full entity expansion.
  • -F: Disable flood fill for table borders.
  • -h: Print a help message and exit.
  • -i: Enable implicit style sheet loading.
  • -I directory: Add a directory to the search path for input files.
  • -l: Enable lazy evaluation.
  • -m: Enable memory debugging.
  • -M memory: Set the maximum memory allocation.
  • -N: Enable non-validating parsing.
  • -O output_file: Specify the output file name.
  • -p: Enable pretty printing of output.
  • -P: Enable performance optimizations.
  • -r: Enable recursive processing of included files.
  • -s: Enable simple entity handling.
  • -S size: Set the stack size.
  • -t output_mode: Specify the output mode (e.g., dvilj, html, pdf, ps, tex).
  • -T: Enable TeX output.
  • -u: Enable undefined entity handling.
  • -v: Print version information and exit.
  • -V: Enable verbose output.
  • -w: Enable warning messages.
  • -x feature: Enable a specific feature.
  • -X feature: Disable a specific feature.
  • -z: Enable compression for output files.

SEE ALSO

dsssl(1), jadetex(1), tex(1)
