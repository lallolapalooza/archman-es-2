PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

open_memstream, open_wmemstream — abrir un flujo de buffer de memoria dinámico

SINOPSIS

#include <stdio.h>
FILE *open_memstream(char **bufp, size_t *sizep);
#include <wchar.h>
FILE *open_wmemstream(wchar_t **bufp, size_t *sizep);

DESCRIPCIÓN

Las funciones open_memstream() y open_wmemstream() crearán un flujo de E/S asociado con un buffer de memoria asignado dinámicamente. El flujo se abrirá para escritura y será posicionable (seekable).

El flujo asociado con una llamada a open_memstream() será orientado a bytes.

El flujo asociado con una llamada a open_wmemstream() será orientado a caracteres anchos (wide characters).

El flujo mantendrá una posición actual en el buffer asignado y una longitud de buffer actual. La posición se establecerá inicialmente en cero (el inicio del buffer). Cada escritura en el flujo comenzará en la posición actual y moverá esta posición por el número de bytes escritos con éxito para open_memstream() o el número de caracteres anchos escritos con éxito para open_wmemstream(). La longitud se establecerá inicialmente en cero. Si una escritura mueve la posición a un valor mayor que la longitud actual, la longitud actual se establecerá en esta posición. En este caso, se añadirá un carácter nulo para open_memstream() o un carácter nulo ancho para open_wmemstream() al buffer actual. Para ambas funciones, el nulo terminador no se incluye en el cálculo de la longitud del buffer.

Después de una llamada exitosa a fflush() o fclose(), el puntero referenciado por bufp contendrá la dirección del buffer, y la variable apuntada por sizep contendrá el menor valor entre la longitud actual del buffer y el número de bytes para open_memstream(), o el número de caracteres anchos para open_wmemstream(), entre el inicio del buffer y el indicador de posición del archivo actual.

Después de una llamada exitosa a fflush(), el puntero referenciado por bufp y la variable referenciada por sizep solo permanecerán válidos hasta la próxima operación de escritura en el flujo o una llamada a fclose().

Después de una llamada exitosa a fclose(), el puntero referenciado por bufp puede pasarse a free().

VALOR DE RETORNO

Tras una finalización exitosa, estas funciones devolverán un puntero al objeto que controla el flujo. De lo contrario, se devolverá un puntero nulo y se establecerá errno para indicar el error.

ERRORES

Estas funciones fallarán si:

EMFILE
{STREAM_MAX} flujos están actualmente abiertos en el proceso que llama.

Estas funciones pueden fallar si:

EINVAL
bufp o sizep son NULL.
EMFILE
{FOPEN_MAX} flujos están actualmente abiertos en el proceso que llama.
ENOMEM
No se pudo asignar memoria para el flujo o el buffer.

Las siguientes secciones son informativas.

EJEMPLOS

#include <stdio.h>
#include <stdlib.h>
int
main (void)
{
    FILE *stream;
    char *buf;
    size_t len;
    off_t eob;
    stream = open_memstream (&buf, &len);
    if (stream == NULL)
        /* manejar error */ ;
    fprintf (stream, "hola mi mundo");
    fflush (stream);
    printf ("buf=%s, len=%zu\n", buf, len);
    eob = ftello(stream);
    fseeko (stream, 0, SEEK_SET);
    fprintf (stream, "adiós");
    fseeko (stream, eob, SEEK_SET);
    fclose (stream);
    printf ("buf=%s, len=%zu\n", buf, len);
    free (buf);
    return 0;
}

Este programa produce la siguiente salida:

buf=hola mi mundo, len=14
buf=adiós mundo, len=14

USO DE APLICACIÓN

El buffer creado por estas funciones debe ser liberado por la aplicación después de cerrar el flujo, mediante una llamada a free().

RACIONALE

Estas funciones son similares a fmemopen() excepto que la memoria siempre es asignada dinámicamente por la función, y el flujo se abre solo para salida.

NAME

open_memstream - abrir una corriente de memoria para escribir

SYNOPSIS

#include <stdio.h>

FILE *open_memstream(char **bufp, size_t *sizep);

DESCRIPTION

La función open_memstream crea un flujo de memoria que se puede escribir.

Los argumentos bufp y sizep apuntan a variables de tipo char * y size_t respectivamente. Al principio, el puntero de memoria al que apunta bufp puede ser NULL y el valor al que apunta sizep puede ser 0. Cuando se escribe en el flujo, la memoria se asigna dinámicamente según sea necesario.

Se mantiene un puntero al búfer actual y el tamaño del búfer. Después de escribir datos en el flujo, se puede acceder al búfer resultante y a su tamaño a través de los punteros proporcionados.

Cuando el flujo se cierra con fclose, la memoria asignada se libera.

open_memstream se puede usar para generar cadenas o búferes de datos binarios que se almacenan en memoria en lugar de en un archivo.

El comportamiento de open_memstream es similar a la función open_wmemstream, pero open_memstream maneja cadenas de caracteres que terminan en nulo (con un carácter nulo adicional al final).

RETURN VALUE

En caso de éxito, open_memstream devuelve un puntero al objeto FILE creado. En caso de error, devuelve NULL y establece errno para indicar el error.

ERRORS

EINVAL: bufp o sizep es NULL.

ENOMEM: No hay suficiente memoria disponible para asignar el búfer.

EXAMPLES

A continuación se muestra un ejemplo de cómo usar open_memstream:

#include <stdio.h>
#include <stdlib.h>

int main() {
    char *buf = NULL;
    size_t size;
    FILE *mem = open_memstream(&buf, &size);

    if (mem == NULL) {
        perror("open_memstream");
        return 1;
    }

    fprintf(mem, "Hola, ");
    fprintf(mem, "mundo!");
    fflush(mem); // Asegura que los datos se escriban en el búfer

    printf("Buffer: %s\n", buf);
    printf("Size: %zu\n", size);

    fclose(mem); // Libera la memoria asignada

    return 0;
}

STANDARDS

open_memstream es una extensión de GNU y no forma parte de ningún estándar C.

HISTORY

open_memstream apareció por primera vez en la versión 2.12 de GNU Libc.
