optionNextValue(3) Manual del programador optionNextValue(3)

NOMBRE

optionNextValue - obtener el siguiente valor de una lista jerárquica

SINOPSIS

#include <tu-opts.h>
cc [...] -o archivo_salida archivo_entrada.c -lopts [...]

const tOptionValue * optionNextValue(const tOptionValue * pOptValue, const tOptionValue * pOldValue);

DESCRIPCIÓN

Esta rutina devolverá la siguiente entrada después de la entrada proporcionada. Al final de la lista, se devolverá NULL. Si la entrada no se encuentra en la lista, se devolverá NULL y "errno" se establecerá en EINVAL. El "pOldValue" debe haber sido obtenido de una llamada previa a esta rutina o a "opitonGetValue()".

pOptValue
un valor de opción jerárquico
pOldValue
un valor de esta lista

VALOR DE RETORNO

una estructura de valor compuesto

ERRORES

El resultado devuelto es NULL y errno se establece:

EINVAL - el pOptValue no apunta a un valor de opción jerárquico válido o pOldValue no apunta a un miembro de ese valor de opción.

ENOENT - el pOldValue proporcionado apuntaba a la última entrada. @end itemize
