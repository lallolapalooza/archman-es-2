OPAM-INSTALLER(1) Manual de Opam-installer OPAM-INSTALLER(1)

NOMBRE

opam-installer - Maneja la (des)instalación de archivos de paquetes siguiendo las instrucciones de los archivos *.install de opam.

SINOPSIS

opam-installer [OPCIÓN]… [PKG.install]

ARGUMENTOS

PKG.install
El archivo .install de opam del que leer las instrucciones de instalación.

OPCIONES

--docdir=RUTA
Directorio de documentación. Relativo a prefix o absoluto. Por defecto es $prefix/doc.
--help[=FORMATO] (por defecto=auto)
Muestra esta ayuda en formato FORMATO. El valor FORMATO debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la variable de entorno TERM sea dumb o no esté definida.
-i, --install
Instala el paquete (por defecto)
--libdir=RUTA
Directorio de bibliotecas de OCaml. Relativo a prefix o absoluto. Por defecto es $prefix/lib; a veces es preferible establecerlo a $(ocamlc -where).
--mandir=RUTA
Directorio de páginas man. Relativo a prefix o absoluto. Por defecto es $prefix/man.
--name=NOMBRE
Especifica el nombre del paquete. Se utiliza para establecer el directorio de instalación bajo `share/', etc. Por defecto, el nombre base del archivo .install
--prefix=PREFIX (ausente=/usr/local)
El prefijo donde instalar. Puedes usar por ejemplo '$PREFIX' para generar un script reubicable
--script
No ejecuta los comandos, sino que genera un script de shell (experimental)
--stubsdir=RUTA
Directorio de instalación de stubs. Relativo a prefix o absoluto. Por defecto es $libdir/stublibs.
--topdir=RUTA
Directorio de instalación de toplevel. Relativo a prefix o absoluto. Por defecto es $libdir/toplevel.
-u, --uninstall, --remove
Elimina el paquete
--version
Muestra información de la versión.
