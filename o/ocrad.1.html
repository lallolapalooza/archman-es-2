OCRAD(1) Comandos de usuario OCRAD(1)

NOMBRE

ocrad - herramienta de reconocimiento óptico de texto

SINOPSIS

ocrad [opciones] [archivos]

DESCRIPCIÓN

GNU Ocrad es un programa de OCR (Reconocimiento Óptico de Caracteres) basado en un método de extracción de características. Lee imágenes en formatos png o pnm y produce texto en formatos de bytes (8 bits) o UTF-8. Los formatos pbm (mapa de bits), pgm (escala de grises) y ppm (color) se conocen colectivamente como pnm.

Ocrad incluye un analizador de diseño capaz de separar las columnas o bloques de texto que normalmente se encuentran en páginas impresas.

Para obtener mejores resultados, los caracteres deben tener al menos 20 píxeles de altura. Si son más pequeños, pruebe la opción --scale. Escanear la imagen a 300 ppp normalmente produce un tamaño de carácter lo suficientemente bueno para ocrad. Los caracteres fusionados, muy en negrita o muy claros (rotos) normalmente no se reconocen correctamente. Intente evitarlos.

OPCIONES

-h, --help
mostrar esta ayuda y salir
-V, --version
mostrar información de versión y salir
-a, --append
añadir texto al archivo de salida
-c, --charset=<nombre>
intente '--charset=help' para obtener una lista de nombres
-e, --filter=<nombre>
intente '--filter=help' para obtener una lista de nombres
-E, --user-filter=<archivo>
filtro definido por el usuario, consulte el manual para ver el formato
-f, --force
forzar la sobrescritura del archivo de salida
-F, --format=<fmt>
formato de salida (byte, utf8)
-i, --invert
invertir los niveles de la imagen (blanco sobre negro)
-l, --layout
realizar análisis de diseño
-o, --output=<archivo>
colocar la salida en <archivo>
-q, --quiet
suprimir todos los mensajes
-s, --scale=[-]<n>
escalar la imagen de entrada por [1/]<n>
-t, --transform=<nombre>
intente '--transform=help' para obtener una lista de nombres
-T, --threshold=<n>
umbral para la binarización (0.0-1.0)
-u, --cut=<i,s,a,l>
recortar la imagen de entrada por el rectángulo dado
-v, --verbose
ser detallado
-x, --export=<archivo>
exportar resultados en formato ORF a <archivo>

Si no se especifican archivos, o si un archivo es '-', ocrad lee la imagen de la entrada estándar. Si no se especifica la opción -o, ocrad envía el texto a la salida estándar.

Estado de salida: 0 para una salida normal, 1 para problemas ambientales (archivo no encontrado, opciones de línea de comandos inválidas, errores de E/S, etc.), 2 para indicar un archivo de entrada corrupto o inválido, 3 para un error de consistencia interna (por ejemplo, un error) que hizo que ocrad fallara.
