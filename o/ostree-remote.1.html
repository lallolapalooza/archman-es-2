OSTREE REMOTE(1) ostree remote OSTREE REMOTE(1)

NOMBRE

ostree-remote - Controla la configuración de repositorios remotos

SINOPSIS

ostree remote add [OPCIONES...] {NOMBRE} {URL} [RAMA...]

ostree remote delete {NOMBRE}

ostree remote show-url {NOMBRE}

ostree remote list [OPCIONES...] {NOMBRE}

ostree remote gpg-import [OPCIONES...] {NOMBRE} [ID-CLAVE...]

ostree remote gpg-list-keys {NOMBRE}

ostree remote refs {NOMBRE}

ostree remote summary [OPCIONES...] {NOMBRE}

ostree remote add-cookie {NOMBRE} {DOMINIO} {RUTA} {NOMBRE-COOKIE} {VALOR}

ostree remote delete-cookie {NOMBRE} {DOMINIO} {RUTA} {NOMBRE-COOKIE}

ostree remote list-cookies {NOMBRE}

DESCRIPCIÓN

Cambia las configuraciones de los repositorios remotos. NOMBRE se refiere al nombre del remoto.

Los argumentos RAMA del subcomando add especifican las ramas configuradas para el remoto. Ver la sección de ramas en ostree.repo-config(5) para más información.

El subcomando gpg-import puede asociar claves GPG a un repositorio remoto específico para usarlas al extraer commits firmados de ese repositorio (si la verificación GPG está habilitada). El subcomando gpg-list-keys se puede usar para ver las claves GPG actualmente asociadas a un repositorio remoto.

Las claves GPG a importar pueden estar en formato OpenPGP binario o codificado en ASCII. La lista opcional de [ID-CLAVE] puede restringir qué claves se importan de un archivo de keyring o un flujo de entrada. Todas las claves se importan si esta lista se omite. Si no se proporcionan las opciones --keyring ni --stdin, las claves se importan del keyring GPG personal del usuario.

Los diversos comandos relacionados con cookies permiten la gestión de un almacén de cookies específico para el remoto.

OPCIONES ADD

--set="CLAVE=VALOR"

Establece la opción de configuración CLAVE=VALOR para el remoto.

--if-not-exists

No hace nada si el remoto proporcionado ya existe.

--force

Reemplaza el remoto proporcionado si ya existe.

--no-gpg-verify

Deshabilita la verificación GPG.

--gpg-import=ARCHIVO

Importa una o más claves GPG desde un archivo.

Equivalente a ostree remote gpg-import --keyring=ARCHIVO.

--collection-id=ID-COLECCIÓN

Establece el ID de colección para el remoto a un valor proporcionado por el propietario del repositorio, lo que permite que las ramas de este remoto se compartan de igual a igual.

OPCIONES LIST

-u, --show-urls

Muestra las URLs de los remotos en la lista.

OPCIONES REFS

--revision, -r

También imprime las revisiones para cada ref. Las revisiones estarán separadas por un carácter de tabulación.

--cache-dir=DIR

Usa un directorio de caché alternativo en DIR.

OPCIONES GPG-IMPORT

-k, --keyring=ARCHIVO

Importa una o más claves desde un archivo.

Esta opción puede repetirse para importar desde múltiples archivos, pero no puede usarse en combinación con --stdin.

--stdin

Importa una o más claves desde la entrada estándar.

Esta opción no puede usarse en combinación con --keyring.

OPCIONES SUMMARY

--cache-dir=DIR

Usa un directorio de caché alternativo en DIR.

--raw

Muestra los datos de variantes sin procesar.

EJEMPLO

$ ostree remote show-url local

http://192.168.122.1/repo
