Métodos

void Release()

Este método se llama cuando bluetoothd(8) anula el registro del agente.

Un agente puede usarlo para realizar tareas de limpieza. No es necesario anular el registro del agente, ya que cuando se llama a este método, ya se ha anulado su registro.

string RequestPinCode(object device)

Este método se llama cuando bluetoothd(8) necesita obtener el código PIN para una autenticación.

El valor de retorno debe ser una cadena de 1 a 16 caracteres. La cadena puede ser alfanumérica.

Errores posibles:

org.bluez.Error.Rejected
org.bluez.Error.Canceled

void DisplayPinCode(object device, string pincode)

Este método se llama cuando bluetoothd(8) necesita mostrar un código PIN para una autenticación.

Se debe devolver una respuesta vacía. Cuando el código PIN ya no necesita mostrarse, se llamará al método Cancel del agente.

Esto se utiliza durante el proceso de emparejamiento de teclados que no admiten el Emparejamiento Seguro Simple de Bluetooth 2.1, en contraste con DisplayPasskey, que se utiliza para aquellos que sí lo hacen.

Este método solo se llamará una vez, ya que los teclados antiguos no admiten la notificación de escritura.

Tenga en cuenta que el PIN siempre será un número de 6 dígitos, rellenado con ceros hasta 6 dígitos. Esto es para la armonía con la especificación posterior.

Errores posibles:

org.bluez.Error.Rejected
org.bluez.Error.Canceled

uint32 RequestPasskey(object device)

Este método se llama cuando bluetoothd(8) necesita obtener la contraseña para una autenticación.

El valor de retorno debe ser un valor numérico entre 0 y 999999.

Errores posibles:

org.bluez.Error.Rejected
org.bluez.Error.Canceled

void DisplayPasskey(object device, uint32 passkey, uint16 entered)

Este método se llama cuando bluetoothd(8) necesita mostrar una contraseña para una autenticación.

El parámetro entered indica el número de teclas ya escritas en el lado remoto.

Se debe devolver una respuesta vacía. Cuando la contraseña ya no necesita mostrarse, se llamará al método Cancel del agente.

Durante el proceso de emparejamiento, este método puede llamarse múltiples veces para actualizar el valor ingresado.

Tenga en cuenta que la contraseña siempre será un número de 6 dígitos, por lo que la pantalla debe rellenarse con ceros al principio si el valor contiene menos de 6 dígitos.

void RequestConfirmation(object device, uint32 passkey)

Este método se llama cuando bluetoothd(8) necesita confirmar una contraseña para una autenticación.

Para confirmar el valor, se debe devolver una respuesta vacía o un error en caso de que la contraseña sea inválida.

Tenga en cuenta que la contraseña siempre será un número de 6 dígitos, por lo que la pantalla debe rellenarse con ceros al principio si el valor contiene menos de 6 dígitos.

Errores posibles:

org.bluez.Error.Rejected
org.bluez.Error.Canceled

void RequestAuthorization(object device)

Este método se llama para solicitar al usuario que autorice un intento de emparejamiento entrante que, en otras circunstancias, activaría el modelo "solo funciona", o cuando el usuario conectó un dispositivo que implementa el emparejamiento por cable. En este último caso, el dispositivo aún no estaría conectado al adaptador a través de Bluetooth.

Errores posibles:

org.bluez.Error.Rejected
org.bluez.Error.Canceled

void AuthorizeService(object device, string uuid)

Este método se llama cuando bluetoothd(8) necesita autorizar una solicitud de conexión/servicio.

Errores posibles:

org.bluez.Error.Rejected
org.bluez.Error.Canceled

void Cancel()

Este método se llama para indicar que la solicitud del agente falló antes de que se devolviera una respuesta.
