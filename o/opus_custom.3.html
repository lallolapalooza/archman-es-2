Descripción detallada

Opus Custom es una parte opcional de la especificación de Opus y su implementación de referencia que utiliza una API distinta de la API normal y admite tamaños de trama que normalmente no se admiten. Se desaconseja el uso de Opus Custom excepto para aplicaciones muy especiales que necesiten un tamaño de trama distinto de 2.5, 5, 10 o 20 ms (por razones de complejidad o latencia) y donde la interoperabilidad sea menos importante.

Además de las limitaciones de interoperabilidad, el uso de Opus Custom deshabilita una parte sustancial del códec y generalmente reduce la calidad disponible a un bitrate dado. Normalmente, cuando una aplicación necesita un tamaño de trama diferente al del códec, debería almacenar en búfer para que coincida con los tamaños, pero esto añade una pequeña cantidad de retraso que puede ser importante en algunas aplicaciones de muy baja latencia. Algunos transportes (especialmente los de RF de tasa constante) también pueden funcionar mejor con tramas de duraciones particulares.

Libopus solo admite modos personalizados si están habilitados en tiempo de compilación.

La API de Opus Custom es similar a la API normal, pero las llamadas a opus_encoder_create y opus_decoder_create toman un parámetro de modo adicional, que es una estructura producida por una llamada a opus_custom_mode_create. Tanto el codificador como el decodificador deben crear un modo utilizando la misma frecuencia de muestreo (Fs) y tamaño de trama (frame_size), por lo que estos parámetros deben señalizarse fuera de banda o fijarse en una implementación particular.

De manera similar a Opus normal, los modos personalizados admiten el cambio de tamaño de trama sobre la marcha, pero los tamaños disponibles dependen del tamaño de trama particular en uso. Para algunos tamaños de trama iniciales, solo está disponible un cambio sobre la marcha.

DESCRIPTION

The Opus codec is a general-purpose, highly scalable, and extremely efficient interactive audio codec. It is designed to be usable from extremely low bitrates up to high fidelity, low-latency, multi-channel audio.

The standard Opus API can be used directly, but for cases where you want to use Opus inside a larger system, or want to use a specific set of Opus features, the custom API provides a more flexible way to use Opus. This API uses fixed modes (created with opus_custom_mode_create) and then creates encoders and decoders from those modes.

The primary benefit of the custom API is that it allows the application to reuse the mode struct between multiple encoders/decoders. This can save a significant amount of memory and computation when many streams of the same type are needed.

OpusCustomDecoder

Represents a decoder state.

OpusCustomEncoder

Represents an encoder state.

OpusCustomMode

Represents the analysis parameters of an Opus stream. This includes the sampling rate, frame size, and other parameters that define the Opus stream. A OpusCustomMode can be used by multiple encoders and decoders, but it must not be destroyed until all encoders and decoders using it have been destroyed.

opus_custom_decode()

Decodes a frame of Opus-compressed audio.

Parameters

st OpusCustomDecoder*: Decoder state
compressed const unsigned char*: The compressed Opus data.
len int: The number of bytes in the compressed data.
pcm opus_int16*: Output buffer for PCM audio in signed 16-bit format (native endian). This buffer must be large enough to hold frame_size * audio_channels samples.
frame_size int: The number of samples per channel to decode. This must be one of the Opus frame sizes (2.5, 5, 10, 20, 40, 60, 80, 120 ms).
audio_channels int*: Returns the number of channels actually present in the decoded audio.

Returns

Number of samples decoded per channel (interleaved if audio_channels > 1). If negative, an error has occurred (see error codes). If the return value is 0, it means the compressed data was a no-op, and silence was decoded.

int opus_custom_encode (OpusCustomEncoder * st, const opus_int16 * pcm, int frame_size, unsigned char * compressed, int maxCompressedBytes)

Encodes a frame of audio.

Parameters

st OpusCustomEncoder*: Encoder state
pcm opus_int16*: PCM audio in signed 16-bit format (native endian). There must be exactly frame_size samples per channel.
frame_size int: Number of samples per frame of input signal
compressed char *: The compressed data is written here. This may not alias pcm and must be at least maxCompressedBytes long.

Returns
