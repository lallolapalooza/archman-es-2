NOMBRE

octave-config - Recuperación de información de componentes y bibliotecas de GNU Octave

SINOPSIS

octave-config [OPCIÓN]...

DESCRIPCIÓN

octave-config es una herramienta para obtener información de directorios para archivos .oct y .m para octave(1).

OPCIONES

--m-site-dir
Mostrar el directorio principal para archivos de script .m locales o específicos del sitio.
--oct-site-dir
Mostrar el directorio principal para bibliotecas de enlace dinámico .oct locales o específicas del sitio.
-p VAR, --print VAR
Imprimir el valor predeterminado de la variable de configuración de Octave VAR. Las variables reconocidas son:
    API_VERSION                 LOCALARCHLIBDIR
    ARCHLIBDIR                  LOCALFCNFILEDIR
    BINDIR                      LOCALOCTFILEDIR
    CANONICAL_HOST_TYPE         LOCALSTARTUPFILEDIR
    DATADIR                     LOCALVERARCHLIBDIR
    DATAROOTDIR                 LOCALVERFCNFILEDIR
    DEFAULT_PAGER               LOCALVEROCTFILEDIR
    EXEC_PREFIX                 MAN1DIR
    EXEEXT                      MAN1EXT
    FCNFILEDIR                  MANDIR
    IMAGEDIR                    OCTAVE_EXEC_HOME
    INCLUDEDIR                  OCTAVE_HOME
    INFODIR                     OCTDATADIR
    INFOFILE                    OCTDOCDIR
    LIBDIR                      OCTFILEDIR
    LIBEXECDIR                  OCTFONTSDIR
    LOCALAPIARCHLIBDIR          OCTINCLUDEDIR
    LOCALAPIFCNFILEDIR          OCTLIBDIR
    LOCALAPIOCTFILEDIR          STARTUPFILEDIR
    LOCALAPIPKGDIR              VERSION
-v, --version
Mostrar el número de versión de octave(1).
-h, -?, --help
Imprimir mensaje de ayuda.
