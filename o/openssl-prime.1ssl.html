NOMBRE

openssl-prime - calcular números primos

SINOPSIS

openssl prime [-help] [-hex] [-in] [-generate] [-bits num] [-safe] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq] [-checks num] [número ...]

DESCRIPCIÓN

Este comando comprueba si los números especificados son primos.

Si no se proporcionan números en la línea de comandos, se debe utilizar la bandera -generate para generar números primos según los requisitos especificados por las demás banderas.

OPCIONES

-help
Muestra un resumen de opciones.
-hex
Habilita el formato hexadecimal para la salida de la generación de primos o la entrada para la comprobación de primalidad.
-in
Proporciona nombres de archivo que contienen números para la comprobación de primalidad.
-generate
Genera un número primo.
-bits num
Genera un primo con num bits.
-safe
Cuando se usa con -generate, genera un primo "seguro". Si el número generado es n, entonces comprueba que "(n-1)/2" también sea primo.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Consulta "Opciones del Proveedor" en openssl(1), provider(7) y property(7).
-checks num
Este parámetro se ignora.
