openipmicmd(1) Una Interfaz de Comandos IPMI openipmicmd(1)

NOMBRE

openipmicmd - Una Interfaz de Comandos IPMI

SINOPSIS

openipmicmd [-k entrada-a-ejecutar] <parámetros de conexión>

DESCRIPCIÓN

El programa openipmicmd permite a un usuario ejecutar comandos IPMI directos. Puede funcionar con la interfaz directa al controlador OpenIPMI o con interfaces IPMI LAN.

OPCIONES

-k entrada-a-ejecutar
Ejecuta un único comando y sale.
<parámetrosde conexión>
Los parámetros para la conexión dependen del tipo de conexión. Todos ellos se describen en openipmi_conparms (7)

COMANDOS

Una vez iniciado, puedes ejecutar comandos en la interfaz de usuario. Ten en cuenta que los comandos y las respuestas son asíncronos; emites un comando y la interfaz retorna inmediatamente. Cuando llega la respuesta, se mostrará en tu consola. Esto puede parecer un poco extraño, pero IPMI es asíncrono internamente. Ten en cuenta que la opción -k es síncrona, esperará la respuesta o un tiempo de espera antes de retornar.

0f lun netfn cmd [data1 [data2 ...]]
Envía un comando al BMC al que estás conectado.
canal [ipmb] dirección-IPMB lun netfn [seq] cmd [data1 [data2 ...]]
Envía un comando a un dispositivo en el bus IPMB. La cadena "ipmb" es opcional. El seq debe proporcionarse si el netfn es una respuesta (un número impar). Debe ser el mismo número de secuencia que llegó en el comando en la parte "Command Sequence = seq" del comando.
canal 00 dirección-IPMB lun netfn cmd [data1 [data2 ...]]
Envía un comando de difusión a un dispositivo en el bus IPMB.
canal lan handle swid-remoto swid-local lun netfn cmd [data1 [data ...]]
Envía un comando a un dispositivo a través de un canal LAN. Ten en cuenta que esto no es lo mismo que una conexión LAN. Esto envía un mensaje a través de un BMC local a un sistema remoto que está conectado con una conexión LAN.
test_lat contador comando
Ejecuta los comandos dados (uno de los comandos anteriores) contador veces y proporciona el tiempo promedio por comando para ejecutar. Ten en cuenta que "contador" está en hexadecimal.
ayuda
Muestra ayuda.
regcmd netfn cmd
Registra para recibir el comando dado. Si el controlador recibe un comando externo, lo mostrará. Esto solo funciona con conexiones de interfaz de sistema, no funcionará en conexiones LAN.
unregcmd netfn cmd
Elimina un registro de comando.

VER TAMBIÉN

ipmi_ui(1), ipmilan(8), openipmi_conparms(7)

PROBLEMAS CONOCIDOS

La naturaleza asíncrona del programa puede ser molesta.
