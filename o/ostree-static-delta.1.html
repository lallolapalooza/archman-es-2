NOMBRE

ostree-static-delta - Gestionar archivos delta estáticos

SINOPSIS

ostree static-delta list

ostree static-delta show

ostree static-delta delete

ostree static-delta generate {--to=REV} [OPCIONES...]

ostree static-delta apply-offline [OPCIONES...] {RUTA} [ID-CLAVE...]

ostree static-delta verify [OPCIONES...] {DELTA-ESTATICO} [ID-CLAVE...]

DESCRIPCIÓN

Lista y manipula archivos delta estáticos.

OPCIONES DE GENERATE

--from="REV"

Crea un delta a partir de la revisión REV.

--to="REV"

Crea un delta hasta la revisión REV. (Esta opción es obligatoria). El delta es desde el padre de REV, a menos que se especifique lo contrario con --from o --empty.

--empty

Crea un delta desde cero.

--max-usize=SIZE

Tamaño máximo sin comprimir en megabytes.

--sign-type=ENGINE

Usa un motor de firma particular. Actualmente los tipos de firma disponibles son ed25519 y dummy. El valor predeterminado es ed25519.

--sign="ID-CLAVE"

Aquí, ID-CLAVE es:

para ed25519:

clave secreta codificada en base64 para firmar.

para dummy:

cadena de texto ASCII utilizada como clave secreta.

OPCIONES DE APPLY-OFFLINE

ID-CLAVE

para ed25519:

clave pública codificada en base64 para verificar.

para dummy:

cadena de texto ASCII utilizada como clave pública.

--sign-type=ENGINE

Usa un motor de firma particular. Actualmente los tipos de firma disponibles son ed25519 y dummy.

--keys-file

Lee la(s) clave(s) del archivo filename. Válido para el tipo de firma ed25519. Para ed25519, este archivo debe contener clave(s) pública(s) codificadas en base64 por línea para verificar.

--keys-dir

Redefine la ruta del sistema, dónde buscar archivos y subdirectorios con claves conocidas y revocadas.

OPCIONES DE VERIFY

ID-CLAVE

para ed25519:

clave pública codificada en base64 para verificar.

para dummy:

cadena de texto ASCII utilizada como clave pública.

--sign-type=ENGINE

Usa un motor de firma particular. Actualmente los tipos de firma disponibles son ed25519 y dummy. El valor predeterminado es ed25519.

--keys-file

Lee la(s) clave(s) del archivo filename. Válido para el tipo de firma ed25519. Para ed25519, este archivo debe contener clave(s) pública(s) codificadas en base64 por línea para verificar.

--keys-dir

Redefine la ruta del sistema, dónde buscar archivos y subdirectorios con claves conocidas y revocadas.

EJEMPLO

$ ostree static-delta

        (No hay deltas estáticos)
