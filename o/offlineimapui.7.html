NOMBRE

offlineimapui - Las interfaces de usuario

DESCRIPCIÓN

OfflineIMAP viene con diferentes interfaces de usuario, cada una con su propio propósito.

TTYUI

La interfaz TTYUI es para personas que trabajan en terminales. Imprime mensajes de estado básicos y es, en general, amigable para usar en una consola o xterm.

BÁSICO

BÁSICO está diseñado para situaciones en las que OfflineIMAP se ejecutará sin supervisión y se registrará el estado de su ejecución.

Esta interfaz de usuario no es capaz de leer una contraseña desde el teclado; las contraseñas de las cuentas deben especificarse utilizando una de las opciones del archivo de configuración. Por ejemplo, no imprimirá anuncios de suspensión periódicos y tiende a ser un poco menos verboso, en general.

BLINKENLIGHTS

Blinkenlights es una interfaz diseñada para ser elegante, divertida de ver e informativa sobre la imagen general de lo que está haciendo OfflineIMAP.

Blinkenlights contiene una fila de "LEDs" con botones de comando y un registro. El registro muestra más detalles sobre lo que está sucediendo y tiene codificación de colores para que coincida con el color de las luces.

Cada luz en la interfaz Blinkenlights representa un hilo de ejecución, es decir, una tarea particular que OfflineIMAP está realizando en este momento. Los colores indican la tarea que está realizando el hilo particular, y son los siguientes:

•Negro 
indica que el hilo de esta luz ha terminado; se iluminará de nuevo más tarde
cuando comiencen nuevos hilos. Por lo tanto, negro indica inactividad.
•Rojo (Significado 1) 
es el color del hilo del programa principal, que básicamente no hace nada
más que monitorizar a los demás. Podría recordarte a HAL 9000 en 2001.
•Gris 
indica que el hilo está estableciendo una nueva conexión con el servidor
IMAP.
•Morado 
es el color de un hilo de sincronización de cuenta que está monitorizando el
progreso de las carpetas en esa cuenta (no genera E/S).
•Cian 
indica que el hilo está sincronizando una carpeta.
•Verde 
significa que se está cargando la lista de mensajes de una carpeta.
•Azul 
es el color de un hilo controlador de sincronización de mensajes.
•Naranja 
indica que se está copiando un mensaje real. (Usamos fucsia para mensajes
falsos).
•Rojo (significado 2) 
indica que se está eliminando un mensaje.
•Amarillo / naranja brillante 
indica que se están agregando indicadores de mensaje.
•Rosa / rojo brillante 
indica que se están eliminando indicadores de mensaje.
•Rojo / Negro parpadeante 
corresponde al temporizador de cuenta atrás que se ejecuta entre
sincronizaciones.

El nombre de estas interfaces deriva de un fragmento de la historia informática. El Jargon File de Eric Raymond define blinkenlights, en parte, como:

Luces de diagnóstico en el panel frontal de una computadora, especialmente un
dinosaurio. Ahora que los dinosaurios son raros, este término se refiere
generalmente a las luces de estado de un módem, un hub de red o similar.

Este término deriva de la última palabra del famoso letrero en caracteres góticos negros en alemán macarrónico que una vez adornó aproximadamente la mitad de las salas de computadoras en el mundo de habla inglesa. Una versión se ejecutaba en su totalidad como sigue:

ACHTUNG!  ALLES LOOKENSPEEPERS!
Das computermachine ist nicht fuer gefingerpoken und mittengrabben.
Ist easy schnappen der springenwerk, blowenfusen und poppencorken
mit spitzensparken.  Ist nicht fuer gewerken bei das dumpkopfen.
Das rubbernecken sichtseeren keepen das cotten-pickenen hans in das
pockets muss; relaxen und watchen das blinkenlichten.

SILENCIOSO

No generará nada excepto errores y advertencias serias. Al igual que BÁSICO, esta interfaz de usuario no es capaz de leer una contraseña desde el teclado; las contraseñas de las cuentas deben especificarse utilizando una de las opciones del archivo de configuración.

SYSLOG

Syslog está diseñado para situaciones en las que OfflineIMAP se ejecuta como un demonio (por ejemplo, como un servicio systemd --user), pero los errores deben reenviarse al registro del sistema. Al igual que BÁSICO, esta interfaz de usuario no es capaz de leer una contraseña desde el teclado; las contraseñas de las cuentas deben especificarse utilizando una de las opciones del archivo de configuración.

MACHINEUI

MachineUI genera salida en un formato analizable por máquina. Está diseñado para otros programas que interactuarán con OfflineIMAP.
