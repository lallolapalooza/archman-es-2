char* oauth_http_get(const char *u, const char *q)

realizar una solicitud GET HTTP, esperar a que termine y devolver el contenido de la respuesta. (requiere libcurl o un cliente HTTP de línea de comandos)

Si se compila sin libcurl, esta función llama a un ejecutable de línea de comandos definido en la variable de entorno OAUTH_HTTP_GET_CMD - por defecto es curl -sA 'liboauth-agent/0.1' '%u' donde %u se reemplaza por la URL y los parámetros de consulta.

Ejemplo de bash y wget: export OAUTH_HTTP_CMD='wget -q -U 'liboauth-agent/0.1' '%u' '

ADVERTENCIA: esta es una función tentativa. Es conveniente y útil para probar o desarrollar código OAuth. Pero no confíe en que esta función sea una parte estable de esta API. Entre otras cosas, no realiza mucha verificación o manejo de errores..

NOTA: u y q simplemente se concatenan con un '?' en medio, a menos que q sea NULL. en cuyo caso solo se utilizará u.

Parámetros:

u url base para obtener
q cadena de consulta para enviar junto con la solicitud HTTP o NULL.

Devoluciones:

En caso de error se devuelve NULL; de lo contrario, un puntero al contenido de la respuesta del servidor HTTP. Este último debe ser liberado por el llamador.

Obsoleto

usar libcurl - http://curl.haxx.se/libcurl/c/

Ejemplos:
tests/oauthexample.c y tests/oauthtest.c.

char* oauth_http_post (const char * u, const char * p)

realiza una solicitud HTTP POST, espera a que termine y devuelve el contenido de la respuesta. (requiere libcurl o un cliente HTTP de línea de comandos)

Si se compila sin libcurl, esta función llama a un ejecutable de línea de comandos definido en la variable de entorno OAUTH_HTTP_CMD - por defecto es curl -sA 'liboauth-agent/0.1' -d '%p' '%u' donde %p se reemplaza con los postargs y %u se reemplaza con la URL.

Ejemplo bash & wget: export OAUTH_HTTP_CMD='wget -q -U 'liboauth-agent/0.1' &ndash;post-data='%p' '%u' '

NOTA: Esta función utiliza el tipo de contenido HTTP-POST predeterminado de curl: application/x-www-form-urlencoded, que es la única opción permitida por la especificación oauth core 1.0. El código experimental puede usar la variable de entorno para transmitir encabezados o parámetros HTTP personalizados.

ADVERTENCIA: esta es una función tentativa. es conveniente y útil para probar o desarrollar código OAuth. Pero no confíe en que esta función se convierta en una parte estable de esta API. Por un lado, no realiza muchas comprobaciones de errores.

Parámetros:

u URL a consultar
p postargs a enviar junto con la solicitud HTTP.

Retorna:

contenido respondido del servidor HTTP. debe ser liberado por el llamante.

Obsoleto

usa libcurl - http://curl.haxx.se/libcurl/c/

Ejemplos:
tests/oauthexample.c y tests/oauthtest.c.
