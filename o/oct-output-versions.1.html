NOMBRE

oct-output-versions - Muestra las versiones de formato de salida admitidas

SINOPSIS

oct output-versions [-h|--help]

DESCRIPCIÓN

Muestra las versiones de formato de salida admitidas para la salida JSON y YAML.

Marca la actualmente elegida con un asterisco.

OPCIONES

-h, --help
Imprime la ayuda (ver un resumen con '-h')
