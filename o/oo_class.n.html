oo_class(n)

Paquete: tcl

Licencias: TCL

class(n) Comandos TclOO class(n)

NOMBRE

oo::class - clase de todas las clases

SINOPSIS

package require TclOO
oo::class método ?arg ...?

JERARQUÍA DE CLASES

oo::object
   → oo::class

DESCRIPCIÓN

Las clases son objetos que pueden fabricar otros objetos de acuerdo con un patrón almacenado en el objeto fábrica (la clase). Se crea una instancia de la clase llamando a uno de los métodos fábrica de la clase, típicamente create si se está dando un nombre explícito, o new si se va a seleccionar automáticamente un nombre único arbitrario.

La clase oo::class es la clase de todas las clases; cada clase es una instancia de esta clase, que por consiguiente es una instancia de sí misma. Esta clase es una subclase de oo::object, por lo que cada clase es también un objeto. Se pueden definir metaclasses adicionales (es decir, clases de clases) si es necesario, subclasificando oo::class. Tenga en cuenta que el objeto oo::class oculta el método new sobre sí mismo, por lo que las nuevas clases siempre deben crearse utilizando el método create.

CONSTRUCTOR

El constructor de la clase oo::class acepta un argumento opcional que, si está presente, se pasa al comando oo::define (junto con el nombre de la clase recién creada) para permitir que la clase se configure convenientemente en el momento de la creación.

DESTRUCTOR

La clase oo::class no define un destructor explícito. Sin embargo, cuando se destruye una clase, todas sus subclases e instancias también se destruyen, junto con todos los objetos en los que se ha mezclado.

MÉTODOS EXPORTADOS

cls create nombre ?arg ...?
Esto crea una nueva instancia de la clase cls llamada nombre (que se resuelve dentro del espacio de nombres del contexto de llamada si no está completamente calificado), pasando los argumentos, arg ..., al constructor, y (si este devuelve un resultado exitoso) devolviendo el nombre completamente calificado del objeto creado (se ignora el resultado del constructor). Si el constructor falla (es decir, devuelve un resultado no OK) entonces el objeto se destruye y el mensaje de error es el resultado de esta llamada al método.
cls new ?arg ...?
Esto crea una nueva instancia de la clase cls con un nombre único nuevo, pasando los argumentos, arg ..., al constructor, y (si este devuelve un resultado exitoso) devolviendo el nombre completamente calificado del objeto creado (se ignora el resultado del constructor). Si el constructor falla (es decir, devuelve un resultado no OK) entonces el objeto se destruye y el mensaje de error es el resultado de esta llamada al método.

Tenga en cuenta que este método no es exportado por el objeto oo::class en sí mismo, por lo que las clases no deben crearse utilizando este método.

MÉTODOS NO EXPORTADOS

La clase oo::class soporta los siguientes métodos no exportados:

cls createWithNamespace nombre nsNombre ?arg ...?
Esto crea una nueva instancia de la clase cls llamada nombre (que se resuelve dentro del espacio de nombres del contexto de llamada si no está completamente calificado), pasando los argumentos, arg ..., al constructor, y (si este devuelve un resultado exitoso) devolviendo el nombre completamente calificado del objeto creado (se ignora el resultado del constructor). El nombre del espacio de nombres interno de la instancia será nsNombre; es un error si no se puede crear dicho espacio de nombres. Si el constructor falla (es decir, devuelve un resultado no OK) entonces el objeto se destruye y el mensaje de error es el resultado de esta llamada al método.

EJEMPLOS

Este ejemplo define una jerarquía de clases simple y crea una nueva instancia de ella. Luego invoca un método del objeto antes de destruir la jerarquía y mostrar que la destrucción es transitiva.

oo::class create fruta {
    method eat {} {
        puts "¡delicioso!"
    }
}
oo::class create banana {
    superclass fruit
    constructor {} {
        my variable peeled
        set peeled 0
    }
    method peel {} {
        my variable peeled
        set peeled 1
        puts "piel ahora quitada"
    }
    method edible? {} {
        my variable peeled
        return $peeled
    }
    method eat {} {
        if {![my edible?]} {
            my peel
        }
        next
    }
}
set b [banana new]
$b eat               → imprime "piel ahora quitada" y "¡delicioso!"
fruit destroy
$b eat               → error "comando desconocido"
