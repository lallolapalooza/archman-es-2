org.bluez.obex.Transfer(5) Administración del sistema Linux org.bluez.obex.Transfer(5)

Nombre

org.bluez.obex.Transfer - Documentación de la API de transferencia OBEX de BlueZ con D-Bus

Interfaz

Servicio
org.bluez.obex
Interfaz
org.bluez.obex.Transfer1
Ruta del objeto
[ruta del objeto de sesión]/transfer{#}

Métodos

void Cancelar()

Cancela la transferencia actual.

Errores posibles:

org.bluez.obex.Error.NoAutorizado
org.bluez.obex.Error.EnProgreso
org.bluez.obex.Error.Fallido

void Suspender()

Suspende la transferencia.

Errores posibles:

org.bluez.obex.Error.NoAutorizado
org.bluez.obex.Error.NoEnProgreso
Si la transferencia todavía está con Estado "en cola".

void Reanudar()

Reanuda la transferencia previamente suspendida con el uso del método Suspender().

Errores posibles:

org.bluez.obex.Error.NoAutorizado
org.bluez.obex.Error.NoEnProgreso
Si la transferencia todavía está con Estado "en cola".

Propiedades

string Estado [solo-lectura]

Indica el estado actual de la transferencia.

Valores posibles:

"en cola"
"activo"
"suspendido"
"completo"
"error"

object Sesión [solo-lectura]

La ruta del objeto de la sesión a la que pertenece la transferencia.

string Nombre [solo-lectura, opcional]

Nombre del objeto que se está transfiriendo.

Se presentarán el Nombre, el Tipo o ambos.

string Tipo [solo-lectura, opcional]

Tipo del objeto que se está transfiriendo.

Se presentarán el Nombre, el Tipo o ambos.

uint64 Tiempo [solo-lectura, opcional]

Tiempo del objeto que se está transfiriendo si este es proporcionado por la parte remota.

uint64 Tamaño [solo-lectura, opcional]

Tamaño del objeto que se está transfiriendo.

Si el tamaño es desconocido, esta propiedad no estará presente.

uint64 Transferido [solo-lectura, opcional]

Número de bytes transferidos.

Para transferencias con Estado establecido en "en cola", este valor no estará presente.

string NombreArchivo [solo-lectura, opcional]

Nombre completo del archivo que se está recibiendo o enviando.

Para transacciones de envío de objetos entrantes, esta será la ubicación y nombre predeterminados propuestos. Puede ser sobrescrito por AutorizarEnvío() en org.bluez.obex.Agent(5) y luego se actualizará en consecuencia.
