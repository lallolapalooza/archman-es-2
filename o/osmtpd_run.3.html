DESCRIPTION

The osmtpd API is an event based interface for writing smtpd(8) filters. Filter and report callbacks are registered via the osmtpd_register class of functions, followed by osmtpd_run. A callback should return 0 in the case of success, or -1 in the case of error which leads to disconnect of this session.

osmtpd_run starts the communication with the server and transforms network queries to callbacks. Internally it uses event_dispatch(3), which allows filters to be written fully asynchronously.

osmtpd_run

ejecuta un filtro de smtpd

SYNOPSIS

osmtpd_run(ctx, msg, filter, data)

osmtpd_local_message
Un puntero a una estructura struct osmtpd_message que contiene la información del mensaje que se está procesando.
osmtpd_filter_t
Un puntero a la estructura struct osmtpd_filter que describe el filtro que se va a ejecutar.
void *data
Datos específicos del filtro que se pasan al filtro.

DESCRIPTION

La función osmtpd_run ejecuta una cadena de filtros en un mensaje SMTP. El parámetro ctx es un puntero a un contexto de filtro, que contiene información sobre la sesión SMTP y el mensaje actual. El parámetro msg es un puntero a una estructura struct osmtpd_message que contiene los detalles del mensaje. El parámetro filter es un puntero a una estructura struct osmtpd_filter que describe el filtro que se va a ejecutar. El parámetro data son datos específicos del filtro que se pasan al filtro.

La estructura struct osmtpd_message contiene los siguientes campos:

uint32_t need
Un valor de marca que indica qué información está disponible en la estructura struct osmtpd_message. Debe inicializarse con OSMTpd_NEED_MSGID. Si no está disponible, el atributo se establece en 0. Los filtros que necesiten datos específicos del filtro pueden usar osmtpd_local_message y local_message.
char *msgid
El ID del mensaje del mensaje SMTP. osmtpd_need debe inicializarse con OSMTpd_NEED_MSGID. Si no está disponible, el atributo se establece en 0.
char *username
El nombre de usuario con el que la sesión se autenticó correctamente. osmtpd_need debe inicializarse con OSMTpd_NEED_USERNAME. Si no está disponible o la autenticación falló, se establece en NULL.
char *mailfrom
La dirección del remitente del sobre en la transacción SMTP. osmtpd_need debe inicializarse con OSMTpd_NEED_MAILFROM. Si no está disponible, el atributo se establece en NULL.
char *rcptto
La dirección del destinatario del sobre en la transacción SMTP. osmtpd_need debe inicializarse con OSMTpd_NEED_RCPTTO. Este atributo es una matriz terminada en NULL de cadenas de direcciones. Si no está disponible, el primer elemento de la matriz se establece en NULL.
uint64_t evpid
El ID del sobre con el que se está trabajando actualmente. osmtpd_need debe inicializarse con OSMTpd_NEED_EVPID. Si no está disponible, el atributo se establece en 0.
void *local_session
Cualquier dato específico del filtro que deba almacenarse durante la sesión. Se inicializa en la creación de ctx llamando al argumento oncreate de osmtpd_local_session.
void *local_message
Cualquier dato específico del filtro que deba almacenarse durante la transacción del mensaje. Se inicializa en la creación de ctx llamando al argumento oncreate de osmtpd_local_message.

La clase de funciones osmtpd_register_filter debe llamar a una de las funciones osmtpd_filter_proceed, osmtpd_filter_rewrite, osmtpd_filter_reject y osmtpd_filter_disconnect. Esto se puede hacer en la propia función de devolución de llamada o en un momento posterior a través de otra devolución de llamada. Tenga en cuenta que la sesión se bloquea hasta que se llama a osmtpd_filter.

Las excepciones a las opciones de respuesta anteriores son:

•
Las funciones de devolución de llamada de osmtpd_register_filter_connect y osmtpd_register_filter sin argumento no pueden usar osmtpd_filter_rewrite.
•
La función de devolución de llamada de osmtpd_register_filter_dataline solo puede usar osmtpd_filter_dataline.

osmtpd_warn, osmtpd_warnx, osmtpd_err y osmtpd_errx se pueden usar como sustitutos de warn(3), warnx(3), err(3) y errx(3) sin imprimir el nombre del programa en stderr. Además, osmtpd_warn y osmtpd_warnx imprimen el ID de solicitud en la línea de registro cuando ctx no es NULL.
