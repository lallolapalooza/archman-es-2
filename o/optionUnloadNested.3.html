NOMBRE

optionUnloadNested - Desasigna la memoria para un valor anidado

SINOPSIS

#include <tus-opciones.h>
cc [...] -o archivo_salida archivo_entrada.c -lopciones [...]

void optionUnloadNested(tOptionValue const * pOptVal);

DESCRIPCIÓN

Un valor anidado necesita ser desasignado. El puntero proporcionado debe haber sido obtenido de una llamada a configFileLoad() (Ver @pxref{libopts-configFileLoad}).

pOptVal
el valor jerárquico
