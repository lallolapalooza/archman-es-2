NOMBRE

oct-pin-reset-user - Restablecer PIN de usuario con PIN de administrador

SINOPSIS

oct pin reset-user [-P|--admin-pin] [-p|--user-pin-new] [-h|--help]

DESCRIPCIÓN

Restablecer PIN de usuario con PIN de administrador

Establece un nuevo PIN de usuario proporcionando el PIN de administrador. Esto también se puede usar si el PIN de usuario ha sido bloqueado.

OPCIONES

-P, --admin-pin=Archivo PIN de administrador
Opcionalmente, obtener el PIN de administrador de un archivo
-p, --user-pin-new=Archivo nuevo PIN de usuario
Opcionalmente, obtener el nuevo PIN de usuario de un archivo
-h, --help
Imprimir ayuda (ver un resumen con '-h')
oct-pin-reset-user
