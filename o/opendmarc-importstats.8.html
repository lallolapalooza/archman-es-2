NOMBRE

opendmarc-importstats - importar estadísticas/datos históricos de OpenDMARC

SINOPSIS

opendmarc-importstats

DESCRIPCIÓN

opendmarc-importstats es un script de shell bastante trivial, típicamente ejecutado por cron(8), que rota un archivo de estadísticas/datos históricos de OpenDMARC a un nombre de archivo único e intenta importarlo a una base de datos local para su posterior procesamiento ejecutando opendmarc-import(8). En caso de importación exitosa, el archivo único se elimina; en caso de fallo, el script ejecuta ls(1) sobre el archivo y sale sin eliminar el archivo único. La intención de este último paso es que cron genere un mensaje a una persona responsable para que el fallo sea investigado.

VERSIÓN

Esta página del manual cubre la versión de opendmarc-importstats que se incluyó con la versión 1.4.2 de OpenDMARC.
