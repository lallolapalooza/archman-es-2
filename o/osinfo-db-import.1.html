osinfo-db-import(1) Herramientas de base de datos de Osinfo osinfo-db-import(1)

NOMBRE

osinfo-db-import - Importar un archivo de base de datos osinfo

SINOPSIS

osinfo-db-import [OPCIONES...] [ARCHIVO-DE-ARCHIVO]

DESCRIPCIÓN

La herramienta osinfo-db-import tomará un archivo de base de datos osinfo y extraerá su contenido en una de las ubicaciones de base de datos estándar en el host actual:

system
Esta es la ubicación principal de la base de datos a nivel de sistema, destinada a ser utilizada por los distribuidores de sistemas operativos que distribuyen archivos de base de datos en el formato de paquete nativo.
local
Esta es la ubicación secundaria de la base de datos a nivel de sistema, destinada a ser utilizada por los administradores del sistema que deseen proporcionar una base de datos actualizada para todos los usuarios.
user
Esta es la ubicación de la base de datos privada del usuario, destinada a ser utilizada por usuarios locales no privilegiados que deseen proporcionar una base de datos actualizada a las aplicaciones que utilizan.

Si se ejecuta con una cuenta privilegiada (es decir, root), se utilizará la ubicación de la base de datos local por defecto, de lo contrario se utilizará la ubicación user.

Al pasar un ARCHIVO-DE-ARCHIVO que no sea local, solo se admiten los protocolos http:// y https://.

Sin ARCHIVO-DE-ARCHIVO, o cuando ARCHIVO-DE-ARCHIVO sea -, leer desde la entrada estándar.

OPCIONES

--user
Anula el comportamiento predeterminado para forzar la instalación en la ubicación de la base de datos user.
--local
Anula el comportamiento predeterminado para forzar la instalación en la ubicación de la base de datos local.
--system
Anula el comportamiento predeterminado para forzar la instalación en la ubicación de la base de datos system.
--dir=RUTA
Anula el comportamiento predeterminado para forzar la instalación en el directorio personalizado RUTA.
--root=RUTA
Prefija la ubicación de instalación con el directorio raíz dado por "RUTA". Esto es útil cuando se desea instalar en un entorno chroot o equivalente.
--latest
Descarga la última versión de la base de datos osinfo de las versiones oficiales de libosinfo y la instala en la ubicación deseada. La última versión de la base de datos osinfo solo se descarga e instala cuando es más reciente que la instalada en la ubicación deseada. Tenga en cuenta que esta opción es mutuamente excluyente con '--nightly'.
--nightly
Descarga la compilación nocturna (no publicada) de la base de datos osinfo del sitio web de libosinfo y la instala en la ubicación deseada. A diferencia de '--latest', con esta opción el archivo nocturno siempre se descarga e instala independientemente de la versión instalada en la ubicación deseada. Tenga en cuenta que esta opción es mutuamente excluyente con '--latest'.
-v, --verbose
Muestra información de progreso detallada al instalar archivos

ESTADO DE SALIDA

El estado de salida será 0 si todos los archivos se instalaron correctamente, o 1 si al menos un archivo no pudo ser instalado.
