NOMBRE

osinfo-db-path - Informar sobre las ubicaciones de la base de datos

SINOPSIS

osinfo-db-path [OPCIONES...]

DESCRIPCIÓN

La herramienta osinfo-db-path informará sobre las rutas asociadas con las ubicaciones estándar de la base de datos de osinfo:

sistema
Esta es la ubicación principal de la base de datos a nivel de sistema, destinada a ser utilizada por los distribuidores de sistemas operativos que distribuyen archivos de base de datos en el formato de paquete nativo.
local
Esta es la ubicación secundaria de la base de datos a nivel de sistema, destinada a ser utilizada por los administradores del sistema que deseen proporcionar una base de datos actualizada para todos los usuarios.
usuario
Esta es la ubicación de la base de datos privada del usuario, destinada a ser utilizada por usuarios locales no privilegiados que deseen proporcionar a las aplicaciones que utilizan una base de datos actualizada.

Si se ejecuta como una cuenta privilegiada (es decir, root), se informará la ubicación de la base de datos local por defecto, de lo contrario se informará la ubicación del usuario.

OPCIONES

--usuario
Anula el comportamiento por defecto para forzar el informe de la ubicación de la base de datos del usuario.
--local
Anula el comportamiento por defecto para forzar el informe de la ubicación de la base de datos local.
--sistema
Anula el comportamiento por defecto para forzar el informe de la ubicación de la base de datos del sistema.
--dir=RUTA
Anula el comportamiento por defecto para forzar el informe del directorio personalizado RUTA.
--root=RUTA
Prefija la ubicación de la base de datos con el directorio raíz dado por "RUTA". Esto es útil cuando se desean informar rutas relativas a un entorno chroot o equivalente.

ESTADO DE SALIDA

El estado de salida será 0 si se informó la ruta solicitada, o 1 si los argumentos fueron inválidos.
