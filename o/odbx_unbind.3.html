odbx_unbind(3)

Paquete: opendbx

Licencias: LGPL

odbx_unbind(3) OpenDBX odbx_unbind(3)

NOMBRE

odbx_unbind - Desconecta de la base de datos

SINOPSIS

#include <opendbx/api.h>


int odbx_unbind
(odbx_t* handle);

DESCRIPCIÓN

Libera el enlace de la conexión a la base de datos y al usuario asociados por odbx_bind() al objeto de conexión proporcionado. Esto es útil para cambiar a una base de datos diferente o para enlazar a la base de datos con credenciales diferentes. También es posible establecer nuevas opciones relacionadas con la conexión antes de volver a enlazar al servidor de base de datos. Si existe una transacción abierta cuando esta función se ejecuta en el backend de Firebird, se confirmará en la base de datos y se cerrará. El comportamiento de los otros backends para transacciones abiertas puede variar.

Es necesario procesar todos los conjuntos de resultados devueltos por el servidor de base de datos antes de usar esta función. De lo contrario, podría devolver un error dependiendo de la biblioteca cliente nativa de la base de datos y del módulo backend. Esta función debe invocarse antes de llamar a odbx_finish() para evitar fugas de memoria y conexiones dejadas abiertas que podrían bloquear recursos necesarios más adelante.

El parámetro handle debe ser el objeto de conexión creado y devuelto por odbx_init(). Se invalida después de haber sido proporcionado a odbx_finish() y odbx_unbind() devolverá un error en este caso.

VALOR DE RETORNO

odbx_unbind() devuelve ODBX_ERR_SUCCESS, o un código de error cuyo valor es menor que cero si alguna de las operaciones no pudo completarse exitosamente. Los códigos de error posibles se enumeran en la sección de errores y pueden ser alimentados a odbx_error() y odbx_error_type() para obtener más detalles.

ERRORES

-ODBX_ERR_PARAM
handle es NULL o el objeto de conexión proporcionado es inválido

VER TAMBIÉN

odbx_bind(), odbx_error(), odbx_finish()
