Nombre

org.bluez.obex.Synchronization - Documentación de la API de Sincronización OBEX de BlueZ

Interfaz

Servicio
org.bluez.obex
Interfaz
org.bluez.obex.Synchronization1
Ruta de objeto
[Ruta del objeto de sesión]

Métodos

vacío SetLocation(cadena ubicación)

Establece la ubicación del almacén de objetos de la agenda telefónica para otras operaciones. Debe llamarse antes que todas las demás operaciones.

Ubicación posible:

"int" ( "internal" que es el predeterminado )
Almacenar en la memoria interna.
"sim{#}"
Almacenar en la tarjeta SIM número #.

Errores posibles:

org.bluez.obex.Error.ArgumentosInvalidos

objeto, diccionario GetPhonebook(cadena archivoDestino)

Recupera un almacén completo de objetos de agenda telefónica del dispositivo remoto y lo almacena en un archivo local.

Si se proporciona un archivo de destino vacío, se calculará automáticamente un nombre para el archivo temporal.

La ruta devuelta representa la transferencia recién creada, que debe utilizarse para averiguar si el contenido se ha transferido con éxito o si la operación falla.

Las propiedades de esta transferencia también se devuelven junto con la ruta del objeto, para evitar una llamada a GetProperties, consulte org.bluez.obex.Transfer(5) para la lista posible de propiedades.

Errores posibles:

org.bluez.obex.Error.ArgumentosInvalidos
org.bluez.obex.Error.Fallo

objeto, diccionario PutPhonebook(cadena archivoOrigen)

Envía un almacén completo de objetos de agenda telefónica al dispositivo remoto.

La ruta devuelta representa la transferencia recién creada, que debe utilizarse para averiguar si el contenido se ha transferido con éxito o si la operación falla.

Las propiedades de esta transferencia también se devuelven junto con la ruta del objeto, para evitar una llamada a GetProperties, consulte org.bluez.obex.Transfer(5) para la lista posible de propiedades.

Errores posibles:

org.bluez.obex.Error.ArgumentosInvalidos
org.bluez.obex.Error.Fallo
