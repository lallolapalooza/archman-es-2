NOMBRE

Osmo - un organizador personal práctico

SINTAXIS

osmo [opción]

DESCRIPCIÓN

Osmo es un organizador personal práctico, que incluye módulos de calendario, gestor de tareas, agenda y notas. Fue diseñado para ser una herramienta PIM (Gestión de Información Personal) pequeña, fácil de usar y con un buen aspecto para ayudar a gestionar la información personal.

OPCIONES

-c, --calendario
Mostrar una pequeña ventana de calendario
-e, --verificar
Verificar si hay eventos desde la última ejecución
-d, --dias
Número de días a comprobar hacia adelante para eventos (por defecto: 0)
-q, --consulta-mutt=CADENA
Coincidir contactos con la cadena dada
--hoja-de-estilo-html=ARCHIVO
Usar el archivo de hoja de estilos (CSS) especificado para el renderizador HTML. Adecuado para que el contenido en el renderizador HTML coincida con el tema GTK.
-?, --ayuda
Mostrar información de ayuda y salir.

ARCHIVOS

Los archivos se almacenan en las ubicaciones indicadas por las variables de entorno XDG_CONFIG_HOME y XDG_DATA_HOME.

Las ubicaciones por defecto:

$HOME/.config/osmo/config.xml - configuración
$HOME/.local/share/osmo/calendar_notes.xml - grupos de calendario y notas
$HOME/.local/share/osmo/contacts_records.xml - datos de contactos
$HOME/.local/share/osmo/ical_files.xml - archivos iCalendar activos
$HOME/.local/share/osmo/notes_entries.xml - lista de notas
$HOME/.local/share/osmo/notes/*.osm - archivos de datos de notas
$HOME/.local/share/osmo/tasks_entries.xml - datos de tareas

EJEMPLOS

Para ejecutar este programa de la manera estándar, escriba:

osmo

Para ejecutar un pequeño calendario, escriba:

osmo -c

Para verificar eventos para dos días a partir de hoy, escriba:

osmo -e -d 2
