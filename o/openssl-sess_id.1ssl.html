openssl-sess_id(1ssl)

Paquete: openssl

Licencias: Apache-2.0

OPENSSL-SESS_ID(1ssl) OpenSSL OPENSSL-SESS_ID(1ssl)

NOMBRE

openssl-sess_id - Comando de manejo de sesiones SSL/TLS

SINOPSIS

openssl sess_id [-help] [-inform DER|PEM] [-outform DER|PEM|NSS] [-in archivo] [-out archivo] [-text] [-cert] [-noout] [-context ID]

DESCRIPCIÓN

Este comando procesa la versión codificada de la estructura de sesión SSL y opcionalmente imprime detalles de la sesión SSL (por ejemplo, la clave maestra de sesión SSL) en formato legible por humanos. Dado que se trata de una herramienta de diagnóstico que requiere cierto conocimiento del protocolo SSL para usarse correctamente, la mayoría de los usuarios no la necesitarán.

El formato exacto de los datos puede variar entre las versiones de OpenSSL y no está documentado.

OPCIONES

-help
Imprime un mensaje de uso.
-inform DER|PEM, -outform DER|PEM|NSS
Los formatos de entrada y salida; el valor predeterminado es PEM. Consulte openssl-format-options(1) para obtener detalles.

Para la salida NSS, el ID de sesión y la clave maestra se informan en el formato "keylog" de NSS.

-in archivo
Esto especifica el nombre del archivo de entrada para leer la información de la sesión o la entrada estándar de forma predeterminada.
-out archivo
Esto especifica el nombre del archivo de salida para escribir la información de la sesión o la salida estándar si no se especifica esta opción.
-text
Imprime los diversos componentes de clave pública o privada en texto plano, además de la versión codificada.
-cert
Si hay un certificado presente en la sesión, se emitirá usando esta opción; si la opción -text también está presente, se imprimirá en formato de texto.
-noout
Esta opción evita la salida de la versión codificada de la sesión.
-context ID
Esta opción puede establecer el ID de sesión para que la información de sesión de salida utilice el ID proporcionado. El ID puede ser cualquier cadena de caracteres. Esta opción normalmente no se utilizará.

SALIDA

Salida típica:

SSL-Session:
    Protocol  : TLSv1
    Cipher    : 0016
    Session-ID: 871E62626C554CE95488823752CBD5F3673A3EF3DCE9C67BD916C809914B40ED
    Session-ID-ctx: 01000000
    Master-Key: A7CEFC571974BE02CAC305269DC59F76EA9F0B180CB6642697A68251F2D2BB57E51DBBB4C7885573192AE9AEE220FACD
    Key-Arg   : None
    Start Time: 948459261
    Timeout   : 300 (sec)
    Verify return code 0 (ok)

Estos se describen a continuación con más detalle.

Protocol
Este es el protocolo en uso: TLSv1.3, TLSv1.2, TLSv1.1, TLSv1 o SSLv3.
Cipher
El cifrador utilizado; este es el código de cifrado SSL o TLS real, consulte las especificaciones SSL o TLS para obtener más información.
Session-ID
El ID de sesión SSL en formato hexadecimal.
Session-ID-ctx
El contexto del ID de sesión en formato hexadecimal.
Master-Key
Esta es la clave maestra de sesión SSL.
Start Time
Esta es la hora de inicio de la sesión representada como un entero en formato Unix estándar.
Timeout
El tiempo de espera en segundos.
Verify return code
Este es el código de retorno cuando se verifica un certificado de cliente SSL.

NOTAS

Dado que la salida de la sesión SSL contiene la clave maestra, es posible leer el contenido de una sesión cifrada utilizando esta información. Por lo tanto, se deben tomar las precauciones de seguridad adecuadas si la información está siendo emitida por una aplicación "real". Sin embargo, esto está fuertemente desaconsejado y solo debe usarse para fines de depuración.

ERRORES

El cifrador y la hora de inicio deberían imprimirse en formato legible por humanos.
