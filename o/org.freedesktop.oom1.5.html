NOMBRE

org.freedesktop.oom1 - La interfaz D-Bus de systemd-oomd

INTRODUCCIÓN

systemd-oomd.service(8) es un servicio del sistema que implementa un asesino de memoria fuera de rango (OOM) en el espacio de usuario. Esta página describe la interfaz D-Bus.

EL OBJETO MANAGER

El servicio expone las siguientes interfaces en el objeto Manager en el bus:

nodo /org/freedesktop/oom1 {
  interfaz org.freedesktop.oom1.Manager {
    métodos:
      DumpByFileDescriptor(salida h fd);
    señales:
      Killed(s cgroup,
             s reason);
  };
  interfaz org.freedesktop.DBus.Peer { ... };
  interfaz org.freedesktop.DBus.Introspectable { ... };
  interfaz org.freedesktop.DBus.Properties { ... };
};

Métodos

La señal Killed() se envía cuando se mata cualquier cgroup por oomd.

Tenga en cuenta que se añadirán más razones en el futuro, y la tabla siguiente se ampliará en consecuencia.

Tabla 1. Razones de asesinato

Razón Descripción
memory-used La aplicación consumió demasiada memoria y swap.
memory-pressure La aplicación consumió suficiente memoria y swap para causar una ralentización considerable de otras aplicaciones.
