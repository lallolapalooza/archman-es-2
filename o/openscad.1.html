OPENSCAD(1) Manual General de Comandos OPENSCAD(1)

NOMBRE

openscad - entorno CAD gráfico basado en archivos de script

SINOPSIS

openscad [opciones] [archivo]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando openscad.

openscad es un software para crear objetos CAD 3D sólidos. Se enfoca en aspectos CAD en lugar de artísticos.

OpenSCAD se iniciará como un programa gráfico a menos que se especifiquen opciones de exportación (ver abajo). Para el uso de la GUI y una descripción del lenguaje OpenSCAD, consulta el manual del usuario de OpenSCAD en https://en.wikibooks.org/wiki/OpenSCAD_User_Manual. Un tutorial se puede encontrar en https://en.wikibooks.org/wiki/OpenSCAD_Tutorial.

OPCIONES

-o archivo_salida
Exporta el archivo dado a archivo_salida en formato STL, OFF, AMF, 3MF, DXF, SVG o PNG, dependiendo de la extensión del archivo de archivo_salida. Si se da esta opción, no se iniciará la GUI.

Extensiones conocidas: stl, off, amf, 3mf, csg, dxf, svg, png, echo, ast, term, nef3, nefdbg.

Formatos adicionales, que se utilizan principalmente para depuración y pruebas (pero también se pueden usar en automatización), son AST (el archivo de entrada tal como se analiza y serializa nuevamente), CSG (una representación del lenguaje OpenSCAD del archivo de entrada con los cálculos realizados y las llamadas a módulos aplicadas), TERM (la expresión de geometría sólida constructiva que se pasa a OpenCSG). Si archivo_salida es null, no se escribirá ningún archivo de salida, pero el archivo aún se evaluará y todos los comandos echo se escribirán en la salida de error estándar. (El proceso de renderizado aún tendrá lugar si se da la opción --render).

--export-format
Anula el formato del archivo scad exportado cuando se usa la opción -o, el argumento puede ser cualquiera de sus extensiones de archivo soportadas.
-q
Modo silencioso (no imprimir nada excepto errores)
-d archivo.deps
Si se da la opción -d, todos los archivos accedidos durante la exportación se escriben en el archivo deps dado con la sintaxis de un Makefile.
-m comando_make
Si se accede a un archivo no existente durante la operación de OpenSCAD, intentará invocar comando_make archivo_faltante para crear el archivo faltante y luego volver a leerlo.
-D var=val
Esta opción se puede usar para asignar valores constantes a variables de OpenSCAD. El valor de la variable es una expresión, por lo que si se usa este mecanismo para asignar cadenas, se debe tener cuidado de que el shell no consuma las comillas. Se puede dar más de una opción -D.
-p
Archivo de parámetros del personalizador.
-p
Conjunto de parámetros del personalizador.
-v
Imprimir versión.
--render
Si se exporta una imagen, renderiza el modelo completamente. (Por defecto es vista previa)
--preview[=throwntogether]
Si se exporta una imagen, usa una vista previa de OpenCSG (opcionalmente en modo throwntogether para una renderización más rápida).
--animate[=N]
Exporta N fotogramas animados como imágenes PNG.
--view[=axes|crosshairs|edges|scales|wireframe]
Opciones de vista
--csglimit=limit
Si se exporta una imagen como vista previa de OpenCSG, detiene la renderización después de encontrar limit elementos para evitar el uso descontrolado de recursos.
--camera=transx,transy,transz,rotx,roty,rotz,distance
Si se exporta una imagen, usa una cámara Gimbal con los parámetros dados. Rot es la rotación alrededor de los ejes x, y, z, trans es la distancia para mover el objeto en las direcciones x, y, z, y distance es la distancia entre la cámara y el centro del objeto.
--camera=eyex,eyey,eyez,centerx,centery,centerz
Si se exporta una imagen, usa una cámara Vector con los parámetros dados. Los tres primeros son para la posición del Ojo, mientras que los tres siguientes son para el Centro (o objetivo) al que mirará la cámara. El vector 'arriba' no es compatible actualmente.
--viewall
Si se exporta una imagen, ajusta la distancia de la cámara para que quepa todo el diseño en el marco.
--autocenter
Si se exporta una imagen, centra el diseño en el marco.
--imgsize=width,height
Si se exporta una imagen, especifica el ancho y alto en píxeles.
--projection=[o|ortho|p|perspective]
Si se exporta una imagen, especifica si se debe usar proyección ortográfica o de perspectiva.
--colorscheme=esquema
Si se exporta una imagen, usa el esquema de color especificado para la renderización. esquema puede ser cualquiera de Cornfield, Sunset, Metallic, Starnight, BeforeDawn, Nature o DeepOcean Solarized, Tomorrow, Tomorrow 2, Tomorrow Night, Monotone.
--hardwarnings
Detener en la primera advertencia.
--check-parameters=[true|false]
Configura la verificación de parámetros para módulos y funciones de usuario.
--check-parameter-ranges=[true|false]
Configura la verificación de rangos de parámetros para módulos integrados.
--info
Muestra qué versiones de bibliotecas se utilizaron para compilar el programa y qué detalles de OpenGL se descubren.

EJEMPLOS DE LÍNEA DE COMANDOS

Renderiza example001.scad en formato .stl (datos de triángulo en bruto):

openscad -o example001.stl examples/example001.scad

Compila una imagen 2d usando una cámara rotada 25 grados en x y 35 en z, distancia 500, con proyección ortográfica:

openscad -o o.png o.scad --camera=0,0,0,25,0,35,500 --projection=ortho

Establece la variable 'mode' en example017 para que renderice solo las partes de la forma. Exporta a un archivo .dxf.

openscad -o example017.dxf -D'mode="parts"' examples/example017.scad
