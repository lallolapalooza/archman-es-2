OSTREE ADMIN SWITCH(1) ostree admin switch OSTREE ADMIN SWITCH(1)

NOMBRE

ostree-admin-switch - Construye un nuevo árbol a partir del origen actual y lo despliega, si ha cambiado

SINOPSIS

ostree admin switch {REF}

DESCRIPCIÓN

Elige una REF diferente del repositorio remoto actual para seguir. Esta es la ref que será "seguida" y actualizada con ostree admin upgrade. Al igual que una actualización, el estado del sistema operativo se conservará.

OPCIONES

--reboot,-r

Reinicia después de un cambio exitoso.

--kexec,-k

Carga el nuevo despliegue en kexec después de un cambio exitoso.

--os="STATEROOT"

Utiliza una raíz de sistema operativo diferente a la actual.

EJEMPLO

$ ostree admin switch fedostree/20/workstation/gnome/core
