outb(2) Manual de llamadas al sistema outb(2)

NOMBRE

outb, outw, outl, outsb, outsw, outsl, inb, inw, inl, insb, insw, insl, outb_p, outw_p, outl_p, inb_p, inw_p, inl_p - E/S de puerto

void outl(unsigned int valor, unsigned short puerto);

DESCRIPCIÓN

Esta familia de funciones se utiliza para realizar entrada y salida de puerto de bajo nivel. Las funciones out* realizan salida de puerto, las funciones in* realizan entrada de puerto; las funciones con sufijo b son de ancho de byte y las funciones con sufijo w son de ancho de palabra; las funciones con sufijo _p hacen una pausa hasta que la E/S se completa.

Están diseñadas principalmente para uso interno del kernel, pero pueden usarse desde el espacio de usuario.

Debes compilar con -O o -O2 o similar. Las funciones se definen como macros en línea y no se sustituirán sin la optimización habilitada, lo que provocará referencias no resueltas en tiempo de enlace.

Utilizas ioperm(2) o, alternativamente, iopl(2) para indicar al kernel que permita que la aplicación del espacio de usuario acceda a los puertos de E/S en cuestión. No hacer esto provocará que la aplicación reciba un error de fallo de segmentación.

VERSIÓNES

outb() y similares son específicas del hardware. El argumento valor se pasa primero y el argumento puerto se pasa segundo, que es el orden opuesto al de la mayoría de las implementaciones de DOS.

ESTÁNDARES

Ninguno.

VER TAMBIÉN
