Paquete: opendbx

Licencias: LGPL

odbx_capabilities(3) OpenDBX odbx_capabilities(3)

NOMBRE

odbx_capabilities - Consultar capacidades implementadas

SINOPSIS

#include <opendbx/api.h>


int odbx_capabilities
(odbx_t* handle, unsigned int cap);

DESCRIPCIÓN

odbx_capabilities() pregunta al backend asociado al objeto de conexión devuelto por odbx_init() si un determinado conjunto de capacidades está implementado por este backend. Todos los backends deben implementar el conjunto de capacidades básicas y pueden implementar conjuntos funcionales predefinidos adicionales si estos son compatibles con la biblioteca cliente nativa de la base de datos. Esta función puede llamarse en cualquier momento después de que odbx_init() haya devuelto éxito.

El primer parámetro, handle, debe ser el objeto de conexión creado y devuelto por odbx_init(). Este objeto se vuelve inválido tan pronto como se haya pasado a odbx_finish() y odbx_capabilities() devolverá un error en este caso.

cap es el número del conjunto de capacidades según lo definido por las constantes macro en odbx.h. Los nombres de constantes válidos que se pueden suministrar como segundo parámetro a odbx_capabilities() se enumeran a continuación:

-ODBX_CAP_BASIC
El conjunto de funciones principales que deben ser implementadas por todos los backends. Consta de todas las funciones necesarias para conectarse, enviar consultas textuales y procesar resultados simples devueltos desde el servidor de base de datos, así como funciones de manejo de errores.

VALOR DE RETORNO

odbx_capabilities() devuelve ODBX_ENABLE si la capacidad solicitada es compatible, ODBX_DISABLE si la capacidad no es compatible o un código de error cuyo valor es menor que cero si alguno de los parámetros suministrados es inválido. Los códigos de error posibles se enumeran en la sección de errores y se pueden alimentar a odbx_error() y odbx_error_type() para obtener más detalles.

ERRORES

-ODBX_ERR_PARAM
handle es NULL o el objeto de conexión suministrado es inválido

VER TAMBIÉN

odbx_error(), odbx_error_type(), odbx_init()
