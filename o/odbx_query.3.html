odbx_query(3)

Paquete: opendbx

Licencias: LGPL

odbx_query(3) OpenDBX odbx_query(3)

NOMBRE

odbx_query - Envía una sentencia al servidor de base de datos

SINOPSIS

#include <opendbx/api.h>


int odbx_query
(odbx_t* handle, const char* stmt, unsigned long length);

DESCRIPCIÓN

Envía la sentencia dada al servidor de base de datos asociado con el handle por odbx_init() para su ejecución. La sentencia puede contener caracteres no visibles como argumentos en condiciones, pero deben ser escapados usando odbx_escape() antes de añadirlos a la sentencia. ¡Aún más, cada argumento cuya fuente no sea controlada por el programador debe ser escapado primero para evitar ataques de inyección SQL y prevenir daños graves!

Después de invocar odbx_query(), uno o más conjuntos de resultados serán enviados de vuelta por el servidor y estarán disponibles a través de odbx_result(). Antes de que estos conjuntos sean procesados llamando a odbx_row_fetch(), no se pueden enviar más consultas al servidor de base de datos. De lo contrario, odbx_query() devolverá un error del backend de la biblioteca nativa de la base de datos.

El primer parámetro handle es el objeto de conexión creado y devuelto por odbx_init() que se vuelve inválido tan pronto como se suministra a odbx_finish().

La sentencia almacenada en el parámetro stmt debe ser una sentencia válida entendida por el servidor de base de datos receptor y debe terminar con un carácter \0. Algunos backends soportan múltiples sentencias por consulta, lo cual se puede probar llamando a odbx_get_option().

El parámetro length debe contener la longitud de la sentencia en bytes sin el carácter \0 terminador. Si se utilizan juegos de caracteres de tamaño variable como UTF-8, se aplica la misma regla. Esta función no soporta el tipo de carácter ancho (wchar_t) que utiliza dos o cuatro bytes por carácter. Si se alimenta 0 (cero) como parámetro de longitud a la función, calculará el tamaño de la sentencia por sí misma.

VALOR DE RETORNO

odbx_query() devuelve ODBX_ERR_SUCCESS, o un código de error cuyo valor es menor que cero si alguna de las operaciones no pudo ser completada con éxito. Los códigos de error posibles se enumeran en la sección de errores y se pueden alimentar a odbx_error() y odbx_error_type() para obtener más detalles.

ERRORES

-ODBX_ERR_BACKEND
La biblioteca nativa de la base de datos devolvió un error porque no pudo manejar la sentencia correctamente.
-ODBX_ERR_PARAM
handle o stmt son NULL o handle es inválido.
-ODBX_ERR_NOMEM
Falló la asignación de la memoria requerida para la sentencia.

VER TAMBIÉN

odbx_error(), odbx_error_type(), odbx_escape(), odbx_result()
