ODE(1) Utilidades de Trazado de GNU ODE(1)

NOMBRE

ode - solución numérica de ecuaciones diferenciales ordinarias

SINOPSIS

ode [ opciones ] [ archivo ]

DESCRIPCIÓN

ode es una herramienta que resuelve, mediante integración numérica, el problema de valor inicial para un sistema especificado de ecuaciones diferenciales ordinarias de primer orden. Tres esquemas de integración numérica distintos están disponibles: Runge-Kutta-Fehlberg (el predeterminado), Adams-Moulton y Euler. Los esquemas Adams-Moulton y Runge-Kutta están disponibles con tamaño de paso adaptativo.

La operación de ode se especifica mediante un programa, escrito en su lenguaje de entrada. El programa es simplemente una lista de expresiones para las derivadas de las variables a integrar, junto con algunas sentencias de control. Se dan algunos ejemplos en la sección EJEMPLOS.

ode lee el programa desde el archivo especificado, o desde la entrada estándar si no se proporciona nombre de archivo. Si lee desde la entrada estándar, ode se detendrá y saldrá cuando vea un único punto en una línea por sí mismo.

En cada paso de tiempo, los valores de las variables especificadas en el programa se escriben en la salida estándar. Así se producirá una tabla de valores, con cada columna mostrando la evolución de una variable. Si solo hay dos columnas, la salida se puede canalizar a graph(1) o un programa de trazado similar.

OPCIONES

Opciones de entrada

-f archivo

--input-file archivo
Lee la entrada del archivo antes de leer desde la entrada estándar. Esta opción permite trabajar interactivamente, después de leer un fragmento de programa que define el sistema de ecuaciones diferenciales.

Opciones de salida

-p prec

--precision prec
Al imprimir resultados numéricos, usa prec dígitos significativos (el predeterminado es 6). Si se da esta opción, el formato de impresión será notación científica.
-t

--title
Imprime una línea de título al principio de la salida, nombrando las variables en cada columna. Si se da esta opción, el formato de impresión será notación científica.

Opciones del esquema de integración

Las siguientes opciones especifican el esquema de integración numérica. Solo se puede especificar una de las tres opciones básicas -R, -A, -E. La predeterminada es -R (Runge-Kutta-Fehlberg).

-R [tamaño_paso]

--runge-kutta [tamaño_paso]
Usa un algoritmo Runge-Kutta-Fehlberg de quinto orden, con tamaño de paso adaptativo a menos que se especifique un tamaño de paso constante. Cuando se especifica un tamaño de paso constante y no se solicita análisis de error, se utiliza un esquema Runge-Kutta clásico de cuarto orden.
-A [tamaño_paso]

--adams-moulton [tamaño_paso]
Usa un esquema predictor-corrector Adams-Moulton de cuarto orden, con tamaño de paso adaptativo a menos que se especifique un tamaño de paso constante, tamaño_paso. El algoritmo Runge-Kutta-Fehlberg se utiliza para superar puntos 'malos' (si los hay).
-E [tamaño_paso]

--euler [tamaño_paso]
Usa un esquema Euler 'rápido y sucio', con un tamaño de paso constante. El valor predeterminado de tamaño_paso es 0.1. No recomendado para aplicaciones serias.
Las opciones de límite de error -r y -e (ver más abajo) no se pueden usar si se especifica -E.
-h hmin [hmax]

--step-size-bound hmin [hmax]
Usa un límite inferior hmin en el tamaño del paso. El esquema numérico no permitirá que el tamaño del paso sea inferior a hmin. El valor predeterminado es permitir que el tamaño del paso se reduzca hasta el límite de la máquina, es decir, el número de punto flotante de doble precisión distinto de cero más pequeño.
El argumento opcional hmax, si se incluye, especifica un valor máximo para el tamaño del paso. Es útil para evitar que la rutina numérica salte rápidamente sobre una región interesante.

Opciones de límite de error

-r rmax [rmin]

--relative-error-bound rmax [rmin]
La opción -r establece un límite superior para el error relativo de un solo paso. Si se usa la opción -r, el error relativo de un solo paso en cualquier variable dependiente nunca excederá rmax (el valor predeterminado para el cual es 10-9). Si esto ocurre, la solución se abandonará y se imprimirá un mensaje de error. Si el tamaño del paso no es constante, el tamaño del paso se reducirá `adaptativamente', para que el límite superior del error de un solo paso no se viole. Por lo tanto, elegir un límite superior más pequeño para el error de un solo paso causará que se elijan tamaños de paso más pequeños. Opcionalmente, se puede especificar un límite inferior rmin, para indicar cuándo se debe aumentar el tamaño del paso (el valor predeterminado para rmin es rmax/1000).
-e emax [emin]

--absolute-error-bound emax [emin]
Similar a -r, pero limita el error absoluto en lugar del error relativo de un solo paso.
-s

--suppress-error-bound
Suprime el límite superior del error de un solo paso, permitiendo que ode continúe incluso si este límite se excede. Esto puede resultar en grandes errores numéricos.

Opciones informativas

--help
Imprime una lista de opciones de línea de comandos y sale.
--version
Imprime el número de versión de ode y el paquete de utilidades de trazado, y sale.

DIAGNÓSTICOS

Mayormente autoexplicativos. La mayor excepción es `error de sintaxis', lo que significa que hay un error gramatical. Los mensajes de error del lenguaje tienen el formato

ode: nnn: mensaje...

donde `nnn' es el número de línea de entrada que contiene el error. Si se usa la opción -f, la frase "(archivo)" sigue a `nnn' para los errores encontrados dentro del archivo. Posteriormente, cuando ode comienza a leer la entrada estándar, los números de línea se reinician desde 1.

No se hace ningún esfuerzo por recuperarse con éxito de errores sintácticos en la entrada. Sin embargo, hay un pequeño esfuerzo para resincronizar para que se puedan encontrar más de un error en un solo escaneo.

Los errores en tiempo de ejecución provocan un mensaje que describe el problema y la solución se abandona.

EXAMPLES

Here is a simple example:

x' = x
x = 1
print t, x
step 0, 1

This program solves the differential equation x' = x with the initial value x(0) = 1. The solution is x(t) = exp(t). The program will print the values of t and x to standard output. Each line will show the value of the independent variable t, and the variable y, as t is stepped from 0 to 1.

A more sophisticated example would be

sine' = cosine
cosine' = -sine
sine = 0
cosine = 1
print t, sine
step 0, 2*PI

This program solves an initial value problem for a system of two differential equations. The initial value problem turns out to define the sine and cosine functions. The program steps the system over a full period.
