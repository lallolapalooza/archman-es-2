openipmigui(1) Interfaz gráfica de usuario para un sistema IPMI openipmigui(1)

NOMBRE

openipmigui - Interfaz gráfica de usuario para un sistema IPMI

SINOPSIS

openipmigui [--dmsg] [--drawmsg] [--glib12] [--trace] [--logstderr] [-n] [-p preffile]

DESCRIPCIÓN

openipmigui es una interfaz gráfica de usuario que utiliza la biblioteca OpenIPMI. Proporciona una vista estructurada en árbol de los dominios IPMI a los que está conectado.

Por defecto, openipmigui se inicia sin conexiones ni nada similar. Debe abrir conexiones a dominios usted mismo. Sin embargo, puede guardar su configuración actual, los dominios actuales y algunas configuraciones de la GUI; estas se restaurarán automáticamente al inicio.

La ventana principal tiene un árbol a la izquierda y una ventana de registro a la derecha. La ventana de registro captura registros informativos y de error de OpenIPMI. Tenga en cuenta que los eventos no se informan en la ventana de registro; debe abrir una ventana SEL para un dominio para ver los eventos.

OPCIONES

--dmsg
Activa la depuración de mensajes, esto volcará todos los mensajes a la salida de depuración.
--drawmsg
Activa la depuración de mensajes en bruto, esto volcará todos los mensajes de bajo nivel a la salida de depuración. Esto difiere de la depuración normal de mensajes en que también se volcarán todos los mensajes del protocolo, no solo los mensajes IPMI.
--dmem
Activa la depuración de memoria, esto provocará que se comprueben las asignaciones y desasignaciones de memoria. Cuando el programa termine, volcará toda la memoria que no se liberó correctamente (fugas), y los desbordamientos, escrituras en memoria liberada u otros tipos de errores de memoria.
--logstderr
Envía todos los registros a la salida de error estándar además de la consola de la GUI.
--trace
Activa el rastreo de python para que todas las llamadas a procedimientos de python que se ingresan y salen se impriman.
-n
Desactiva la lectura del archivo de preferencias al inicio.
-p preffile
Usa preffile como nombre del archivo de preferencias en lugar de $HOME/.openipmigui.startup.

BARRA DE MENÚ

La barra de menú principal contiene dos menús desplegables: Archivo y Ver.

El menú Archivo contiene los comandos Salir, Abrir Dominio y Guardar Preferencias. El comando Salir hace lo que se describe, y no pregunta para asegurarse de que desea salir. El comando Abrir Dominio es cómo establecer una conexión a un sistema IPMI. El comando Guardar Preferencias almacenará los dominios actuales y la configuración de la ventana principal de la GUI. Estas configuraciones se restaurarán al inicio. Las configuraciones se almacenan en $HOME/.openipmigui.startup; este archivo puede ser eliminado para borrar todas las configuraciones.

El menú Ver contiene comandos para expandir y contraer todo el árbol.

VISTA DE ÁRBOL

La ventana del árbol tiene una lista de nivel superior de todos los dominios a los que OpenIPMI tiene conexiones (o conexión pendiente). Cada dominio se expande en información específica del dominio y una lista de entidades y Controladores de Gestión (MC) para ese dominio.

El clic derecho impulsa la mayoría de las operaciones en la ventana del árbol. Muchos elementos del árbol tienen menús desplegables activados por un clic del botón derecho del ratón. En caso de duda, haga clic.

El color se usa en la GUI para indicar el estado de error, y el sombreado se usa para indicar la disponibilidad. Si un sensor tiene un error, la entrada del árbol para ese sensor cambiará de color. Negro significa sin error, amarillo significa advertencia, rojo significa crítico y azul significa no recuperable. Estos errores se propagan hacia arriba, por lo que la entidad que contiene ese sensor tendrá el mismo color que el error más crítico de los sensores debajo de ella. Lo mismo ocurre con el dominio, tendrá el mismo color que el error más crítico de las entidades debajo de él. De esta manera, si observa el dominio, puede determinar si un sistema tiene problemas con solo la vista de nivel superior, y puede profundizar para encontrar el problema.

Si una entrada del árbol está sombreada, significa que la entrada tiene información que la identifica pero no existe. Por ejemplo, un dominio sin conexión, una entidad que no está presente o un MC que no está presente.

Tenga en cuenta que toda la información visible en el árbol se sondear. Solo se sonde la información visible, por lo que si expone algo al expandir un elemento del árbol o al desplazarse, puede pasar unos segundos antes de que los datos se actualicen.

DOMINIOS

Los dominios contienen diversa información de alto nivel y una agregación de todos los Registros de Eventos del Sistema (SEL) contenidos en ellos. El Tiempo de Re-sondear SEL y el Tiempo de Re-sondear IPMB se pueden establecer mediante clic derecho; estos valores se recuerdan al guardarse y restaurarse. (Tenga en cuenta que estos valores en las entradas específicas del MC no se guardan ni restauran, solo los de nivel de dominio). Hacer clic derecho en el dominio presenta un conjunto de operaciones, incluida la posibilidad de ver el SEL.

ENTIDADES

El elemento Entidades bajo el elemento dominio contiene una lista de las entidades descubiertas para ese dominio. Estas son solo las entidades de nivel superior (las que no están contenidas en otras entidades); las entidades contenidas en otras entidades se enumeran bajo su entidad padre. Esto reduce el desorden para sistemas muy complicados, como ATCA.

Si la entidad es intercambiable en caliente, los comandos de activación y desactivación de intercambio en caliente están disponibles mediante clic derecho en la entidad. Si la entidad tiene información de FRU, también puede verla mediante un comando de clic derecho.

La información bajo una entidad también contiene una lista de sensores y controles para la entidad.

SENSORES

Los sensores están disponibles bajo la entidad a la que pertenecen. La información del sensor está más allá del alcance de este documento, ya que los sensores IPMI son muy complejos. Consulte el documento IPMI de OpenIPMI para obtener información sobre sensores.

Como era de esperar, hacer clic derecho en un sensor presenta las operaciones disponibles para ese sensor.

CONTROLES

Los controles están disponibles bajo la entidad a la que pertenecen. La información de control está más allá del alcance de este documento, ya que los controles IPMI son muy complejos. Consulte el documento IPMI de OpenIPMI para obtener información sobre controles.

Como era de esperar, hacer clic derecho en un control presenta las operaciones disponibles para ese control.

CONTROLADORES DE GESTIÓN (MC)

Un MC es el nodo inteligente en un sistema IPMI. En general, no es necesario conocer los MC para las operaciones normales de sensores y controles IPMI. Sin embargo, necesita acceso a los MC para la configuración del sistema.

Un MC contiene mucha información sobre sí mismo y sus capacidades; esto generalmente es interpretado automáticamente por OpenIPMI, pero la información está disponible para ser vista. Por ejemplo, si un MC contiene un dispositivo SEL, OpenIPMI manejará automáticamente la obtención de eventos de él, pero también puede ver esta configuración en la información del MC.

Un número de operaciones están disponibles en el menú de clic derecho en el MC; la mayoría de estas son autoexplicativas. El MC generalmente se configura a través del comando Información de Canal bajo este.

CONEXIONES

Un conjunto de conexiones para el dominio se lista bajo el dominio. Cada conexión tiene uno o más puertos. El estado de estos puertos se puede ver por color; si un puerto es amarillo (advertencia), está caído. Si una conexión es roja (grave), entonces todos sus puertos están caídos. Si todas las conexiones están caídas, el elemento del árbol "Conexiones" se vuelve azul (crítico).

INFORMACIÓN DE CANAL

Si hace clic derecho en un MC, mostrará una entrada de Información de Canal. Esto se utiliza para configurar la información de red y canal para el MC. MANAGEMENT CONTROLLERS (MCs)

La configuración de un MC se realiza por primera vez cuando se establece una conexión. Los valores de configuración de los MCs se pueden ver en el árbol de la vista del árbol de la página principal. Los valores se muestran como un árbol y cada rama se puede expandir o contraer. Los valores de configuración en la ventana principal son una instantánea del estado del MC en el momento en que se estableció la conexión. Estos valores no se actualizan automáticamente; si desea ver los valores más recientes, deberá volver a establecer la conexión y volver a cargar la página.

Cada rama del árbol de la vista del árbol se puede expandir o contraer. Las ramas que se pueden expandir están marcadas con un pequeño signo + o - al lado de la rama. Hacer clic en el signo + expandirá la rama y hacer clic en el signo - la contraerá. La primera vez que se muestra el árbol, todas las ramas se contraen por defecto. Si una rama tiene un icono especial, esto indica una de las siguientes:

MC
Este es el propio controlador de gestión.
Channel
Este es un canal de comunicación.
Sensor
Este es un sensor.
Control
Este es un control.
User
Este es un usuario.
LAN
Este es un canal LAN.

Si hace clic con el botón derecho en un canal, se mostrará un menú emergente con una lista de comandos que se pueden ejecutar en ese canal. Algunos de los comandos son: Info, User Access, User Info y LAN Config. Seleccionar cualquiera de estos comandos abrirá una nueva ventana que le permitirá ver o modificar la configuración de ese elemento.

La ventana de configuración de un canal muestra la información de ese canal. La configuración está organizada en varias pestañas. La pestaña principal muestra la información general del canal, como su número, nombre y tipo. Las otras pestañas muestran información más detallada, como la configuración de acceso de usuario y la información del usuario.

La configuración de usuario y de acceso de usuario se muestra y se puede modificar en la ventana de configuración del canal. Estos ajustes se pueden cambiar haciendo clic con el botón derecho en ellos. Tenga en cuenta que el cambio no es inmediato; debe usar el botón Guardar en la parte inferior de la ventana para guardar los cambios que ha realizado. Además, hay dos versiones de la configuración de acceso de usuario. Una es volátil y actualizará la configuración actual para el MC, pero si el MC se reinicia, se restaurarán los ajustes no volátiles. Establecer los ajustes no volátiles no provocará un cambio inmediato, pero esos cambios se restaurarán en el próximo reinicio del MC.

Algunos canales tienen información de usuario; puede configurar estos seleccionando ese comando en el menú contextual de un canal.

Los canales LAN también tienen configuración LAN; puede configurar estos seleccionando ese comando en el menú contextual de un canal.

CONNECTIONS

La ventana de conexiones muestra una lista de todas las conexiones establecidas actualmente. Puede conectarse a un nuevo MC seleccionando el comando New Connection en el menú File. Esto abrirá un cuadro de diálogo que le pedirá la dirección IP y el nombre de usuario y la contraseña del MC al que desea conectarse.

Una vez que se haya conectado a un MC, podrá ver la información de ese MC en la ventana principal. La ventana principal muestra la información de los MCs en un formato de árbol. Puede expandir o contraer las ramas del árbol para ver o ocultar la información detallada. La información disponible incluye información sobre los sensores, controles, dominios, entidades y canales del MC.

Puede desconectarse de un MC seleccionando el comando Disconnect en el menú File. Esto cerrará la conexión con el MC.

La ventana de conexiones también muestra información sobre el estado de cada conexión. Por ejemplo, mostrará si la conexión está activa o inactiva. También mostrará la dirección IP y el nombre de usuario del MC al que está conectado.

Esta información se actualiza automáticamente y no es estática. Reflejará el estado actual de las conexiones.

CHANNEL INFO

La ventana Channel Info muestra información sobre el canal seleccionado. Esta información incluye el número de canal, el nombre del canal, el tipo de canal y el estado del canal. También puede ver la configuración de acceso de usuario y la información del usuario para el canal. La información se muestra en formato de solo lectura. Los cambios solo se pueden realizar utilizando los comandos de configuración apropiados.

Tenga en cuenta que la información mostrada aquí es estática y no se actualiza dinámicamente. Reflejará el estado del canal en el momento en que se abrió la ventana. Si la configuración subyacente cambia, esta ventana no se actualizará automáticamente. Deberá volver a abrir la ventana para ver los cambios.

Para configurar canales individuales, expándalos. La configuración de Información es de solo lectura y no se puede cambiar. La configuración de Acceso de usuario se puede cambiar haciendo clic con el botón derecho sobre ella. Tenga en cuenta que el cambio no es inmediato, debe usar el botón Guardar en la parte inferior de la ventana para guardar los cambios que ha realizado. Además, hay dos versiones de la configuración de Acceso de usuario. Una es volátil y actualizará la configuración actual para el MC, pero si el MC se reinicia, se restaurarán los ajustes no volátiles. Establecer los ajustes no volátiles no provocará un cambio inmediato, pero esos cambios se restaurarán en el próximo reinicio del MC.

Algunos canales tienen información de usuario; puede configurar estos seleccionando ese comando en el menú contextual de un canal.

Los canales LAN también tienen configuración LAN; puede configurar estos seleccionando ese comando en el menú contextual de un canal.

USER INFO

Los sistemas IPMI con acceso remoto tienen usuarios que se pueden usar para iniciar sesión. Estos usuarios se configuran mediante el comando User Info en la lista de canales. Tenga en cuenta que algunos ajustes de usuario (el nombre y la contraseña) son globales para todos los canales del MC.

Debido a la especificación IPMI y a algunos errores de implementación desafortunados, existen algunos problemas extraños con esta información. El usuario tiene un valor Habilitado que indica si el usuario está habilitado o no. Cuando se muestra inicialmente, este campo aparece como un "?" porque este campo no es legible. Se mostrará como el valor real cuando se modifique, pero no se cambiará de lo contrario.

También hay un campo de límite de sesión que indica el número máximo de sesiones que un usuario puede realizar. Este campo tampoco es legible y se muestra como un "?" cuando se muestra por primera vez. Este campo está marcado como opcional en la especificación IPMI, lo que significa que el campo no tiene que ser suministrado. Sin embargo, algunas implementaciones requieren que se establezca este campo. Si recibe un error DataLenInv de su sistema al establecer algo, debe establecer el campo en algo para que cualquier valor pueda ser establecido. En general, establecerlo en cero deshabilita el campo y es lo correcto.

LANPARMS

En la visualización del canal en un canal 8023_LAN, hay disponible un comando de configuración LANPARM. Esto extrae todos los parámetros de la LAN y permite establecerlos. Hacer clic con el botón derecho en un elemento permite cambiarlo.

PEFPARMS

Si un MC admite PEF, tendrá un elemento de menú "PEF Parms" en el menú desplegable del MC. Esto extrae todos los parámetros de PEF y permite establecerlos. Hacer clic con el botón derecho en un elemento permite cambiarlo.

SOLPARMS

En la visualización del canal en un canal 8023_LAN, hay disponible un comando de configuración LANPARM si el MC admite SOL (Serial Over LAN). Esto extrae todos los parámetros de la LAN y permite establecerlos. Hacer clic con el botón derecho en un elemento permite cambiarlo.

SOL

En una conexión, hay un elemento de menú "Open SOL". Si el BMC al otro extremo de la conexión admite SOL (Serial Over LAN), entonces puede establecer una conexión serie con el BMC, asumiendo que está configurado correctamente y tiene los derechos adecuados.

Cuando elija esto, obtendrá una nueva conexión con un emulador de terminal VT100/ANSI. La conexión aún no se abrirá, debe abrirla (en "Archivo") para establecer la conexión. Cuando el estado en la parte inferior derecha diga "conectado", estará listo para escribir. Si algo sale mal, la conexión puede caerse y tendrá que reabrirla. También puede cerrar la conexión desde el menú Archivo, o salir del emulador.

El menú "Controles" para la conexión SOL contiene un gran número de ajustes para SOL. Estos le permiten manipular varios valores en el lado remoto de la conexión. Estos son:

Aceptar Entrada
Si está deshabilitado, esto hará que se rechacen los datos del BMC, efectivamente controlando el flujo de datos (suponiendo que el BMC realmente admita esto correctamente, algunos no lo hacen).
Usar Cifrado
Cifrar los datos en la LAN utilizando el cifrado RMCP+ negociado para la conexión. Solo disponible cuando la conexión está cerrada, esto no se puede cambiar dinámicamente.
Usar Autenticación
Autenticar los datos en la LAN utilizando la autenticación RMCP+ negociada para la conexión. Solo disponible cuando la conexión está cerrada, esto no se puede cambiar dinámicamente.
Desactivar CTS/DCD/DSR al conectar
No activar las líneas cuando se realiza una conexión; esto permite que cosas como la velocidad en baudios se establezcan antes de que el dispositivo al otro extremo del puerto serie sepa que hay una conexión.
CTS Habilitable
Si está configurado, el BMC tiene control sobre la línea CTS. De lo contrario, la línea CTS está desactivada.
DCD/DSR Activado
Establece las líneas DCD y DSR.
RI Activado
Activa la línea Indicador de llamada, se puede usar para despertador remoto en algunos sistemas (aunque, con IPMI, uno se preguntaría por qué no usar IPMI para esto).
Establecer tiempo de espera de ACK
Establece el tiempo de espera para un ACK del BMC.
Reintentos de ACK
Establece el número de veces que se reintenta un paquete antes de que se cierre la conexión.
Enviar Break
Envía una señal de interrupción de 300 ms al puerto serie remoto.
Velocidad Serie
Establece la velocidad de transmisión en el puerto serie. No todos los sistemas admiten esto. De hecho, algunos ignoran completamente esta configuración y usan 19.2K. Tenga en cuenta que esta es solo la velocidad volátil. La configuración de la velocidad no volátil se realiza con SOLPARM.
Comportamiento de Alerta Serie
Esto establece qué hacer cuando ocurre una alerta IPMI y sale por el puerto serie de alguna manera. Si se establece en "succeed", la sesión SoL se desconectará cuando salga una alerta.
Limpieza de Cola
Permite limpiar varias colas.
