Nombre

org.bluez.Bearer.LE - Documentación de la API de BlueZ D-Bus Bearer LE

Interfaz

Servicio
org.bluez
Interfaz
org.bluez.Bearer.LE1
Ruta de objeto
[prefijo variable]/{hci0,hci1,...}/dev_{BDADDR}

Métodos

void Conectar() [experimental]

Conecta todos los perfiles LE que el dispositivo remoto soporta y que pueden ser conectados y han sido marcados para auto-conexión. Si solo un subconjunto de perfiles ya está conectado, intentará conectar los que actualmente no están conectados.

Si al menos un perfil se conectó correctamente, este método indicará éxito.

Errores posibles:

org.bluez.Error.NotReady
org.bluez.Error.Failed
org.bluez.Error.InProgress
org.bluez.Error.AlreadyConnected

void Desconectar() [experimental]

Desconecta todos los perfiles conectados y luego termina la conexión ACL-LE de bajo nivel.

La conexión ACL-LE se terminará incluso si algunos perfiles no se desconectaron correctamente, por ejemplo, debido a un dispositivo que se comporta mal.

Este método también se puede utilizar para cancelar una llamada Conectar anterior antes de que se reciba una respuesta.

Para dispositivos no confiables conectados, llamar a este método deshabilitará las conexiones entrantes hasta que se vuelva a llamar al método Conectar.

Errores posibles:

org.bluez.Error.NotConnected

Señales

void Desconectado(string razón, string mensaje) [experimental]

Esta señal se emite cuando un dispositivo se desconecta, con la razón de la desconexión.

Esto podría ser utilizado por la aplicación cliente, dependiendo de la política interna, para intentar reconectarse al dispositivo en caso de tiempo de espera o desconexión desconocida, o para intentar conectarse a otro dispositivo.

Razones posibles:

org.bluez.Reason.Unknown
org.bluez.Reason.Timeout
Tiempo de espera de conexión.

Ha expirado el tiempo de espera de supervisión del enlace para una conexión o el tiempo de espera de sincronización para una transmisión.

org.bluez.Reason.Local
Conexión terminada por el host local.

El dispositivo local terminó la conexión, terminó la sincronización con un transmisor o dejó de transmitir paquetes.

org.bluez.Reason.Remote
Conexión terminada por el host remoto.

Esta desconexión puede deberse a:

  • el usuario en el dispositivo remoto terminó la conexión o dejó de transmitir paquetes,
  • el dispositivo remoto terminó la conexión debido a recursos bajos,
  • el dispositivo remoto terminó la conexión porque el dispositivo está a punto de apagarse.
org.bluez.Reason.Authentication
Conexión terminada debido a un fallo de autenticación.
org.bluez.Reason.Suspend
Conexión terminada por el host local para suspensión.

Propiedades

objeto Adaptador [solo lectura, experimental]

La ruta del objeto del adaptador al que pertenece el conjunto.

booleano Emparejado [solo lectura, experimental]

Indica si el dispositivo remoto está emparejado con el soporte LE.

Emparejado significa que se ha completado el proceso de emparejamiento donde los dispositivos intercambian información para establecer una conexión cifrada.

booleano Vinculado [solo lectura, experimental]

Indica si el dispositivo remoto está vinculado al soporte LE.

Vinculado significa que la información intercambiada en el proceso de emparejamiento se ha almacenado y se conservará.

booleano Conectado [solo lectura, experimental]

Indica si el dispositivo remoto está actualmente conectado al soporte LE.

Una señal PropertiesChanged indica cambios en este estado.
