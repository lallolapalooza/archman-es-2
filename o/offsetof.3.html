offsetof(3) Manual de funciones de la biblioteca offsetof(3)

NOMBRE

offsetof - desplazamiento de un miembro de una estructura

BIBLIOTECA

Biblioteca estándar de C (libc, -lc)

SINOPSIS

#include <stddef.h>
size_t offsetof(type, member);

DESCRIPCIÓN

La macro offsetof() devuelve el desplazamiento del campo member desde el inicio de la estructura type.

Esta macro es útil porque los tamaños de los campos que componen una estructura pueden variar entre implementaciones, y los compiladores pueden insertar diferentes números de bytes de relleno entre campos. Consecuentemente, el desplazamiento de un elemento no se da necesariamente por la suma de los tamaños de los elementos anteriores.

Se producirá un error de compilación si member no está alineado en un límite de byte (es decir, es un campo de bits).

VALOR DE RETORNO

offsetof() devuelve el desplazamiento del member dado dentro del type dado, en unidades de bytes.

ESTANDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C89.

EJEMPLOS

En un sistema Linux/i386, al compilarse usando las opciones por defecto de gcc(1), el siguiente programa produce la siguiente salida:


$ ./a.out
offsets: i=0; c=4; d=8 a=16
sizeof(struct s)=16

Código fuente del programa

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    struct s {
        int i;
        char c;
        double d;
        char a[];
    };
    /* La salida depende del compilador */
    printf("offsets: i=%zu; c=%zu; d=%zu a=%zu\n",
           offsetof(struct s, i), offsetof(struct s, c),
           offsetof(struct s, d), offsetof(struct s, a));
    printf("sizeof(struct s)=%zu\n", sizeof(struct s));
    exit(EXIT_SUCCESS);
}
