NOMBRE

opendmarc-reports - Herramienta de generación de informes agregados de OpenDMARC

SINOPSIS

opendmarc-reports [opciones]

DESCRIPCIÓN

opendmarc-reports extrae datos de una base de datos de OpenDMARC y genera informes agregados periódicos. La base de datos es poblada por un proceso en ejecución de opendmarc-import(8) sobre un archivo de historial de mensajes generado por un filtro opendmarc(8) a medida que llegan y se procesan los mensajes. Esto incluye la recolección de URIs de informes, que este script utiliza para poner los informes a disposición de quienes los solicitan.

OPCIONES

--day
Genera informes en los límites del día. Anula el valor de --interval (ver abajo).
--dbhost=hostname
Especifica el nombre del host en el que se está ejecutando el servidor SQL. Por defecto, usa el valor de la variable de entorno OPENDMARC_DBHOST, o "localhost" si la variable de entorno no está establecida.
--dbname=name
Especifica el nombre de la base de datos SQL a la que se accederá. Por defecto, usa el valor de la variable de entorno OPENDMARC_DB, o "opendmarc" si la variable de entorno no está establecida.
--dbpasswd=password
Especifica la contraseña para la base de datos SQL a la que se accederá. Por defecto, usa el valor de la variable de entorno OPENDMARC_PASSWORD, o "opendmarc" si la variable de entorno no está establecida.
--dbport=port
Especifica el puerto TCP en el que se espera que el servidor SQL esté escuchando. Por defecto, usa el valor de la variable de entorno OPENDMARC_PORT, o 3306 si la variable de entorno no está establecida.
--dbuser=user
Especifica el usuario SQL que se utilizará para acceder a la base de datos. Por defecto, usa el valor de la variable de entorno OPENDMARC_USER, o "opendmarc" si la variable de entorno no está establecida.
--domain=name
Genera un informe (si corresponde) para el dominio especificado, en lugar de comprobarlos todos.
--help
Imprime un mensaje de ayuda y termina.
--interval=secs
Genera informes solo para hosts que no han tenido un informe generado en al menos los últimos secs segundos.
--nodomain=name
Omite la generación de un informe para el dominio especificado. Se puede especificar varias veces para omitir múltiples dominios de informes.
--noupdate
Suprime la marca de la hora de transmisión del informe en la base de datos. Normalmente, esto se haría para evitar que los informes se envíen con demasiada cercanía.
--report-email=addr
Genera informes utilizando la dirección especificada, que se utiliza en el contenido del informe y en la transacción SMTP. Por defecto es "postmaster@HOSTNAME", donde HOSTNAME se reemplaza por el nombre del host que genera el informe.
--report-org=domain
Genera informes utilizando el nombre de dominio especificado como la organización responsable del informe. Esto se utiliza para crear el nombre de archivo del archivo y se incluye en el contenido del informe. Por defecto es el nombre del host que genera el informe.
--smtp-host=host
Hace que los informes se envíen transmitiéndolos por SMTP al host especificado, que puede ser una dirección IP o un nombre de host. Por defecto es "127.0.0.1".
--smtp-port=port
Hace que los informes se envíen transmitiéndolos por SMTP al puerto especificado. Por defecto es 25.
--utc
Instruye a la base de datos para que cambie a la zona horaria UTC al generar la salida. De lo contrario, se utiliza la configuración por defecto de la base de datos.
--verbose
Aumenta la cantidad de verbosidad escrita en la salida estándar.
--version
Imprime el número de versión y sale.
