LIBOFX(1) Comandos de usuario LIBOFX(1)

NOMBRE

libofx - Crea un archivo de solicitud de extracto

SINOPSIS

ofxconnect [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Imprime en la salida estándar el archivo OFX creado basado en las opciones que se le pasan. Actualmente, solo crea un archivo de solicitud de extracto. Puede POSTear esto a un servidor OFX para solicitar un extracto de esa institución financiera para esa cuenta.

-h, --help
Imprime la ayuda y sale.
-V, --version
Imprime la versión y sale.
--fipid=CADENA
Identificador del socio FI (busca fid, org y url en el servidor del socio).
--fid=CADENA
Identificador de la FI.
--org=CADENA
Etiqueta de organización de la FI.
--bank=CADENA
Identificador bancario IBAN.
--broker=CADENA
Identificador del bróker.
--user=CADENA
Nombre de usuario.
--pass=CADENA
Contraseña.
--acct=CADENA
ID de cuenta.
--type=INT
Tipo de cuenta 1=cheques 2=inversión 3=tarjeta de crédito.
--past=LONG
Cuánto tiempo atrás buscar desde hoy (en días).
--url=CADENA
URL a la que POSTear los datos (de lo contrario, se envían a stdout).
--trid=INT
ID de transacción.
Grupo: comando
-s, --statement-req
Solicitud de extracto.
-a, --accountinfo-req
Solicitud de una lista de cuentas.
-p, --payment-req
Solicitud para realizar un pago.
-i, --paymentinquiry-req
Solicitud para consultar el estado de un pago.
-b, --bank-list
Listar todos los bancos conocidos.
-f, --bank-fipid
Listar todos los fipids para un banco dado.
-v, --bank-services
Listar los servicios compatibles para un fipid dado.
--allsupport
Listar todos los bancos que admiten banca en línea.
