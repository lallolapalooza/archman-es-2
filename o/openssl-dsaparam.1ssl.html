NOMBRE

openssl-dsaparam - Manipulación y generación de parámetros DSA

SINOPSIS

openssl dsaparam [-help] [-inform DER|PEM] [-outform DER|PEM] [-in archivo] [-out archivo] [-noout] [-text] [-genkey] [-verbose] [-quiet] [-rand archivos] [-writerand archivo] [-engine id] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq] [num_bits] [num_qbits]

DESCRIPCIÓN

Este comando se utiliza para manipular o generar archivos de parámetros DSA.

La generación de parámetros DSA puede ser un proceso lento y, como resultado, a menudo se utiliza el mismo conjunto de parámetros DSA para generar varias claves distintas.

OPCIONES

-help
Imprime un mensaje de uso.
-inform DER|PEM
El formato de entrada de los parámetros DSA; no especificado por defecto. Consulte openssl-format-options(1) para obtener más detalles.
-outform DER|PEM
El formato de salida de los parámetros DSA; el valor por defecto es PEM. Consulte openssl-format-options(1) para obtener más detalles.

Los parámetros son una secuencia de ASN.1 INTEGERs: p, q, y g. Esto es compatible con la estructura DSS-Parms de RFC 3370.

-in archivo
Este especifica el archivo de entrada para leer los parámetros o la entrada estándar si no se especifica esta opción. Si se incluye el parámetro num_bits, esta opción se ignorará.
-out archivo
Este especifica el archivo de salida para escribir los parámetros. Se utiliza la salida estándar si esta opción no está presente. El nombre del archivo de salida puede ser el mismo que el del archivo de entrada, lo que lleva a reemplazar el contenido del archivo. Tenga en cuenta que la E/S de archivos no es atómica. El archivo de salida se trunca y luego se escribe.
-noout
Esta opción inhibe la salida de la versión codificada de los parámetros.
-text
Esta opción imprime los parámetros DSA en formato legible por humanos.
-genkey
Esta opción generará una DSA utilizando los parámetros especificados o generados.
-verbose
Imprime detalles adicionales sobre las operaciones que se están realizando.
-quiet
Imprime menos detalles sobre las operaciones que se están realizando, lo que puede ser útil durante scripts por lotes y canalizaciones.
-rand archivos, -writerand archivo
Consulte "Opciones de estado aleatorio" en openssl(1) para obtener detalles.
-engine id
Consulte "Opciones de motor" en openssl(1). Esta opción está obsoleta.
num_bits
Este argumento opcional especifica que se debe generar un conjunto de parámetros de tamaño num_bits. Si se incluye este argumento, se ignora el archivo de entrada (si existe).
num_qbits
Este argumento opcional especifica que se debe generar un conjunto de parámetros con un subprimo q de tamaño num_qbits. Debe ser el último argumento. Si se incluye este argumento, se ignora el archivo de entrada (si existe).
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Consulte "Opciones del proveedor" en openssl(1), provider(7), y property(7).

VER TAMBIÉN

openssl(1), openssl-pkeyparam(1), openssl-gendsa(1), openssl-dsa(1), openssl-genrsa(1), openssl-rsa(1)

HISTORIA

La opción -engine fue obsoleta en OpenSSL 3.0.

La opción -C fue eliminada en OpenSSL 3.0.
