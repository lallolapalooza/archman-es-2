optionGetValue(3) Manual del programador optionGetValue(3)

NOMBRE

optionGetValue - obtener un valor específico de una lista jerárquica

SINOPSIS

#include <tus-opts.h>
cc [...] -o archivo_salida archivo_entrada.c -lopts [...]

const tOptionValue * optionGetValue(const tOptionValue * pOptValue, char const * nombreValor);

DESCRIPCIÓN

Esta rutina encontrará una entrada en una opción de valor anidado o configurable. Si "nombreValor" es NULL, se devuelve la primera entrada. De lo contrario, se devuelve la primera entrada con un nombre que coincida exactamente con el argumento. Si no hay ningún valor coincidente, se devuelve NULL y se establece errno en ENOENT. Si el valor de opción proporcionado no es un valor jerárquico, también se devuelve NULL y se establece errno en EINVAL.

pOptValue
un valor jerárquico
nombreValor
nombre del valor a obtener

VALOR DE RETORNO

una estructura de valor compuesto

ERRORES

El resultado devuelto es NULL y errno se establece:

EINVAL - el pOptValue no apunta a un valor de opción jerárquico válido.

ENOENT - ninguna entrada coincidió con el nombre dado. @end itemize
