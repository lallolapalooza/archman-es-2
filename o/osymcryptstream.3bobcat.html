osymcryptstream.3bobcat

FBB::OSymCryptStream(3bobcat) Cifrado/descifrado simétrico FBB::OSymCryptStream(3bobcat)

NOMBRE

FBB::OSymCryptStream - std::ostream que realiza cifrado/descifrado simétrico

SINOPSIS

#include <bobcat/osymcryptstream>
Opción de enlace: -lbobcat -lcrypto

DESCRIPCIÓN

Los objetos FBB::OSymCryptStream se pueden utilizar para cifrar o descifrar información que está disponible en flujos std::istream separados.

La clase OSymCryptStream es una plantilla de clase que utiliza un parámetro no de tipo FBB::CryptType. Los objetos de la clase FBB::OSymCryptStream<FBB::ENCRYPT> cifran la información que reciben; los objetos de la clase FBB::OSymCryptStream<FBB::DECRYPT> descifran la información que reciben.

Se pueden utilizar todos los métodos de cifrado simétrico definidos por la biblioteca OpenSSL que se puedan seleccionar por nombre para cifrar/descifrar información. Para seleccionar un método de cifrado particular, se pasa un identificador al constructor. Por ejemplo, "aes-256-gcm". Para los algoritmos de cifrado actualmente compatibles, ejecute el comando

    openssl list -cipher-algorithms

Los objetos OSymCryptStream leen la información a cifrar/descifrar de una fuente externa (por ejemplo, de objetos std::istream). Los caracteres que son cifrados o descifrados por los objetos OSymCryptStream se escriben en objetos std::ostream que se especifican en tiempo de construcción como referencias ostream o por nombre de archivo.

CONSTRUCTORES

o
OSymCryptStream<CryptType>(std::ostream &outStream, std::string const &cipherName, std::string const &key, std::string const &iv, size_t inBufSize = 100):
Este constructor define un std::streambuf que cifra o descifra los caracteres que recibe.
- Los objetos OSymCryptStream<FBB::ENCRYPT> realizan el cifrado;
- Los objetos OSymCryptStream<FBB::DECRYPT> realizan el descifrado;
- Los objetos OSymCryptStream<CryptType> escriben los caracteres cifrados o descifrados en outStream;
- El método de cifrado a utilizar se especifica mediante el parámetro cipherName. Por ejemplo, "AES-256-GCM";
- La clave simétrica a utilizar se especifica mediante el parámetro key;
- El vector de inicialización se especifica mediante el parámetro iv;
- El búfer utilizado internamente por FBB::OSymCryptStreambuf almacenará inBufSize caracteres. El valor predeterminado es el valor más pequeño que se utiliza. Al especificar un valor bufSize menor, se utiliza el valor predeterminado;
o
OSymCryptStream<CryptType>(std::string const &outStreamName, std::string const &cipherName, std::string const &key, std::string const &iv, size_t inBufSize = 100):
Mismo constructor que el anterior, pero el primer parámetro de este constructor especifica el nombre del archivo que recibirá los caracteres cifrados o descifrados.

Si la construcción falla, se lanza una excepción que menciona la función de openssl que no pudo completarse (ver también errorMsg a continuación).

El constructor de movimiento está disponible; los constructores de copia y los operadores de asignación no están disponibles.

MIEMBROS HEREDADOS

Dado que la clase se deriva públicamente de std::ostream, se pueden utilizar todos los miembros de std::ostream.

MANIPULADOR

o
std::ostream &FBB::eoi(std::ostream &out):
Al insertar el manipulador eoi en un objeto OSymCryptStream, la inserción se considera completa. Completa la inserción de información en el std::ostream especificado en la construcción como primer argumento del OSymCryptStream. De esta manera, no tiene que esperar hasta que el destructor del objeto OSymCryptStream vacíe ese flujo. En el siguiente ejemplo, se ilustra el uso del manipulador eoi (líneas comentadas cerca de la línea 40): 
    //in.seekg(0);              // cuando se active, esto no
    //enc << in.rdbuf();        // será procesado debido a ’<< eoi’
Activar esas líneas no resultará en el procesamiento del flujo in dos veces.

EJEMPLO

#include <iostream>
#include <fstream>
#include <string>
#include <bobcat/osymcryptstream>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
try
{
    if (argc == 1)
    {
        cout << "arg[1]: e - cifrar, d - descifrar,\n"
                "arg[2]: archivo a procesar, arg[3]: archivo procesado\n";
        return 0;
    }
    string key = "0123456789abcdef0123456789abcdef";
    cout << "¿clave de cifrado? ";
    cin >> key;
    while (key.size() < 32)
        key += key;
    string iv = " 0123456789ab" "456";
    char cipherName[] =
        "AES-256-GCM"
        //"AES-256-CBC"
    ;
    ifstream in{ argv[2] };
    ofstream out{ argv[3] };
    if (*argv[1] == ’e’)
    {
        OSymCryptStream<ENCRYPT> enc{ out, cipherName, key, iv, 100 };
            // comentar la línea anterior y descomentar la siguiente
            // para usar el constructor que espera un string como primer argumento:
//      OSymCryptStream<ENCRYPT> enc{ argv[3], cipherName, key, 
//                                    iv, 100 };
        enc << in.rdbuf() << eoi;
        //in.seekg(0);              // cuando se active, esto no
        //enc << in.rdbuf();        // será procesado debido a ’<< eoi’
    }
    else
    {
        OSymCryptStream<DECRYPT> decrypt{ out, cipherName, key, 
                                                           iv, 100 };
            // comentar la línea anterior y descomentar la siguiente
            // para usar el constructor que espera un string como primer argumento:
//      OSymCryptStream<DECRYPT> decrypt{ argv[3], cipherName, key, 
//                                        iv, 100 };
        decrypt << in.rdbuf() << eoi;
    }
}
catch (exception const &exc)
{
    cerr << exc.what() << ’\n’;
}

};

DESCRIPTION

This class is derived from symcryptstream. It provides a symcrypting output byte stream. The data written to the stream is symcrypt-encoded using the provided key before being written to the underlying output stream.

The class handles the generation of a symcrypt initialisation vector (IV) and its prepending to the symcrypt-encoded data. The IV is required to symcrypt-decode the data at the receiving end.

The symcrypt key is passed either as a RC4 object, or as a hex-encoded string.

EXAMPLE

#include <fstream>
#include <iostream>
#include <bobcat/rc4.h>
#include <bobcat/osymcryptstream.h>

int main()
{
    std::ofstream ofs("encrypted.txt");
    char const * const key = "0123456789abcdef"; // 16 bytes key
    RC4 key1(key);

    osymcryptstream os(ofs, key1);

    os << "This is a test string." << std::endl;
    os.flush();

    ofs.close();

    return 0;
}
