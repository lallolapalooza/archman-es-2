odbx_error(3)

Paquete: opendbx

Licencias: LGPL

odbx_error(3) OpenDBX odbx_error(3)

NOMBRE

odbx_error - Devuelve un mensaje de error legible por humanos

SINOPSIS

#include <opendbx/api.h>


char* odbx_error
(odbx_t* handle, int error);

DESCRIPCIÓN

odbx_error() devuelve una cadena de error correspondiente al código de error proporcionado o a la cadena de error generada por la biblioteca de base de datos nativa. Las cadenas de error que se originan en los módulos backend o en las bibliotecas de cliente de bases de datos nativas se borran tan pronto como se llama a la siguiente función odbx_*(). Todas las cadenas de error se asignan estáticamente y no deben modificarse ni liberarse. Si la biblioteca OpenDBX se compila con soporte de idioma nativo y las variables de entorno del usuario se configuran adecuadamente a un idioma compatible, las cadenas que forman parte de la biblioteca OpenDBX se traducen antes de ser devueltas. Esto también puede ser el caso para las cadenas devueltas por las bibliotecas de bases de datos nativas, pero depende de su soporte.

El primer parámetro, handle, es el objeto de conexión creado y devuelto por odbx_init(), que se vuelve inválido tan pronto como se proporciona a odbx_finish(). De todos modos, no es necesario proporcionar un handle válido para errores que utilizan códigos de error distintos de -ODBX_ERR_BACKEND, ya que se devuelven directamente de una matriz de mensajes de error estáticos. Por lo tanto, es posible usar odbx_error() incluso si odbx_init() no tuvo éxito. Si se proporciona -ODBX_ERR_BACKEND en este caso, la cadena de error devuelta será la misma que para un handle inválido.

Casi todas las funciones de la biblioteca OpenDBX devuelven un código de error si alguna de las operaciones no pudo completarse exitosamente. Los códigos devueltos utilizan valores menores que cero para indicar diferentes tipos de errores y estos valores se pueden pasar directamente a odbx_error() para obtener la cadena de error terminada en cero correspondiente.

VALOR DE RETORNO

odbx_error() devuelve una cadena terminada en cero adecuada para ser mostrada al usuario de la aplicación.

ERRORES

Si ocurrió un error de backend y handle es NULL o el objeto de conexión proporcionado es inválido, odbx_error() devuelve la cadena localizada para -ODBX_ERR_PARAM.

VER TAMBIÉN
