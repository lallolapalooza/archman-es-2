NOMBRE

openbox-lxde - script de envoltura para ejecutar openbox para LXDE

SINOPSIS

openbox-lxde

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando openbox-lxde.

openbox-lxde es un script de envoltura que ejecuta openbox con el archivo de configuración específico de LXDE.
