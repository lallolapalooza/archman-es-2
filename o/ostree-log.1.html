NOMBRE

ostree-log - Muestra el registro comenzando desde un commit o ref

SINOPSIS

ostree log [OPCIONES...] {REF}

DESCRIPCIÓN

Muestra un registro de commits a una ref o rama dada. Incluye el checksum del commit, la marca de tiempo y el mensaje del commit.

OPCIONES

--raw

Muestra datos de variante sin procesar.

EJEMPLO

$ ostree log mi-rama

        commit 67e382b11d213a402a5313e61cbc69dfd5ab93cb07fbb8b71c2e84f79fa5d7dc
        Date:  2014-06-12 13:42:54 +0000
            Este es el segundo commit
        commit ce19c41036cc45e49b0cecf6b157523c2105c4de1ce30101def1f759daafcc3e
        Date:  2014-06-12 11:20:08 +0000
            Commit inicial
