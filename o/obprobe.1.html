NOMBRE

obprobe — crear una malla de sonda electrostática

SINOPSIS

obprobe [OPCIONES] tipo c_parcial nombre_archivo

DESCRIPCIÓN

La herramienta obprobe crea una malla alrededor de una molécula, colocando un átomo sonda con un tipo de átomo y carga parcial especificados en cada punto para calcular la energía MMFF94. Esto se puede usar para experimentos de acoplamiento para probar la afinidad de enlace de hidrógeno, potencial electrostático, etc. La salida se envía a la salida estándar utilizando el formato Gaussian Cube.

OPCIONES

Si no se proporciona un nombre de archivo, obprobe dará todas las opciones, incluidas las sondas de ejemplo.

-s tamaño_paso
Establece la resolución de la malla (tamaño_paso).
-p relleno
Establece el relleno: distancia adicional en cada lado de la caja formada por la molécula.
tipo
Tipo de átomo MMFF94.
c_parcial
Carga parcial MMFF94.

EJEMPLOS

Sondear el archivo pyridines.sdf usando un oxígeno de carbonilo, un aceptor de enlace de hidrógeno con carga parcial -0.57:

obprobe 7 -0.57 pyridines.sdf

Sondear el archivo pyridines.sdf usando un átomo de carbono fenilo, un átomo hidrófobo sin carga parcial:

obprobe 37 0.0 pyridines.sdf
