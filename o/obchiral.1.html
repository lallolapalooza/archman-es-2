NOMBRE

obchiral — imprimir información de quiralidad molecular

SINOPSIS

obchiral nombre_archivo

DESCRIPCIÓN

El programa obchiral es una herramienta para imprimir la información de quiralidad de todas las moléculas en un archivo. También sirve como código de ejemplo para usar la biblioteca Open Babel (libopenbabel).

EJEMPLOS

obchiral piridinas.sdf

VER TAMBIÉN

obabel(1), obfit(1), obgrep(1), obprop(1), obrotate(1).
Las páginas web de Open Babel se pueden encontrar en: http://openbabel.org/
