NOMBRE

oct-admin-import - Importar una clave en la tarjeta

SINOPSIS

oct admin import [-s|--sig-fp] [-d|--dec-fp] [-a|--aut-fp] [--key-passphrase] [-h|--help] <ARCHIVO_CLAVE>

DESCRIPCIÓN

Importar una clave en la tarjeta.

La mayoría de las claves se pueden importar sin especificar las huellas digitales de las subclaves. Sin embargo, si la clave contiene más de una subclave con capacidad de firma, descifrado o autenticación, las subclaves deben seleccionarse explícitamente.

Si se proporciona alguna de las opciones, solo se importarán las subclaves seleccionadas en las ranuras seleccionadas.

Las capacidades de las subclaves deben coincidir con la ranura en la que se importa la clave. La ranura DEC solo se puede usar para subclaves con capacidad de cifrado. Las ranuras SIG y AUT se pueden usar para subclaves con capacidad de firma, certificación y autenticación.

OPCIONES

-s, --sig-fp=huella digital de subclave SIG
Opcionalmente, selecciona la subclave a importar en la ranura SIG
-d, --dec-fp=huella digital de subclave DEC
Opcionalmente, selecciona la subclave a importar en la ranura DEC
-a, --aut-fp=huella digital de subclave AUT
Opcionalmente, selecciona la subclave a importar en la ranura AUT
--key-passphrase=CONTRASEÑA_CLAVE
Opcionalmente, proporciona una contraseña para el material de clave secreta cifrada en un archivo
-h, --help
Imprime la ayuda (ver un resumen con '-h')
<ARCHIVO_CLAVE>
Archivo que contiene la clave privada PGP
