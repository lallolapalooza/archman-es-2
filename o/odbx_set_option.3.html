odbx_set_option(3)

Paquete: opendbx

Licencias: LGPL

odbx_set_option(3) OpenDBX odbx_set_option(3)

NOMBRE

odbx_set_option - Cambiar el comportamiento del backend de la base de datos

SINOPSIS

#include <opendbx/api.h>


int odbx_set_option
(odbx_t* handle, unsigned int option, void* value);

DESCRIPCIÓN

Cambia el valor de la opción especificada en el módulo backend o en la biblioteca nativa de la base de datos asociada al manejador por odbx_init(). Antes de intentar establecer una opción, se debe probar con odbx_get_option() primero para asegurar que sea compatible con el backend. Casi todas las opciones deben establecerse antes de conectarse al servidor de base de datos usando odbx_bind() para que surtan efecto.

El primer parámetro, handle, es el objeto de conexión creado y devuelto por odbx_init(), el cual deja de ser válido tan pronto como se proporciona a odbx_finish().

Hay varios valores de opción definidos como constantes con nombre en el archivo de cabecera odbx.h. Las opciones disponibles cuyos valores pueden ser cambiados son:

ODBX_OPT_TLS
Utiliza cifrado para transmitir todos los datos de forma segura a través de la red mediante SSL o TLS. Esta opción se puede establecer a ODBX_TLS_NEVER (el valor predeterminado) para prevenir el cifrado, a ODBX_TLS_ALWAYS para forzar el cifrado y fallar si no se puede utilizar entre la biblioteca cliente y el servidor, o a ODBX_TLS_TRY para usar cifrado si es posible, con la opción de volver a una conexión que no esté cifrada.
ODBX_OPT_MULTI_STATEMENTS
Habilita el servidor de base de datos para aceptar múltiples sentencias en una sola cadena de consulta enviada a través de odbx_query() si el valor de value se establece en ODBX_ENABLE. Sin embargo, podría ser posible deshabilitarlo estableciéndolo en ODBX_DISABLE.
ODBX_OPT_PAGED_RESULTS
Todos los servidores de bases de datos y bibliotecas cliente son capaces de transferir los registros fila por fila. Algunos de ellos también pueden transferir múltiples filas o incluso todas a la vez para minimizar la carga del servidor, el tráfico de red y la latencia. La desventaja de esto es un mayor consumo de memoria. Si los resultados paginados son compatibles con el backend, pasar valores positivos recuperará el número especificado de registros a la vez desde el servidor de base de datos. El valor cero ("0") es especial en este caso, ya que pide al módulo backend que recupere todos los registros a la vez.
ODBX_OPT_COMPRESS
Habilita el tráfico de red comprimido entre el cliente y el servidor de base de datos. Esto puede maximizar el rendimiento si la red es el cuello de botella. Pase una variable entera con ODBX_ENABLE para habilitar la compresión o con ODBX_DISABLE para deshabilitarla para esta conexión.
ODBX_OPT_MODE
Algunos servidores de bases de datos admiten diferentes modos de operación, por ejemplo, modos de cumplimiento con otras implementaciones SQL o lenguajes de consulta completamente diferentes. Esta opción está disponible desde OpenDBX 1.1.4. value debe apuntar a una cadena terminada en cero y para una descripción detallada de los modos de MySQL, mire su sitio web ⟨http://dev.mysql.com/doc/refman/5.0/en/server-sql-mode.html⟩

Si no se indica lo contrario, el tipo de la variable pasada al tercer parámetro value debe ser un puntero a entero. Sus valores deben estar en el rango especificado por la opción que se está cambiando.

VALOR DE RETORNO

odbx_set_option() devuelve ODBX_ERR_SUCCESS, o un código de error cuyo valor es menor que cero si alguna de las operaciones no pudo completarse con éxito. Los códigos de error posibles se enumeran en la sección de errores y pueden ser pasados a odbx_error() y odbx_error_type() para obtener más detalles.

ERRORES

-ODBX_ERR_PARAM
Uno de los parámetros suministrados es inválido o es NULL y esto no está permitido en el módulo backend utilizado o en la biblioteca cliente nativa de la base de datos.
-ODBX_ERR_OPTION
El valor pasado al parámetro option no es uno de los valores listados en este manual. El contenido de value permanece sin cambios si ocurre este error.
-ODBX_ERR_OPTRO
La opción no está destinada a ser cambiada y solo se puede leer a través de odbx_get_option().
-ODBX_ERR_OPTWR
Establecer la opción falló por varias razones. Es muy probable que el valor pasado a través de value no coincidiera con el rango de valores esperados por el backend o la biblioteca nativa de la base de datos.

VER TAMBIÉN

odbx_bind(), odbx_error(), odbx_get_option()
