NOMBRE

ouch - Una utilidad de línea de comandos para comprimir y descomprimir archivos y directorios fácilmente.

SINOPSIS

ouch [-y|--yes] [-n|--no] [-A|--accessible] [-H|--hidden] [-q|--quiet] [-g|--gitignore] [-f|--format] [-p|--password] [-c|--threads] [-h|--help] [-V|--version] <subcomandos>

DESCRIPCIÓN

Una utilidad de línea de comandos para comprimir y descomprimir archivos y directorios fácilmente.

Formatos soportados: tar, zip, gz, 7z, xz/lzma, bz/bz2, bz3, lz4, sz (Snappy), zst, rar y br.

Repositorio: https://github.com/ouch-org/ouch

OPCIONES

-y, --yes
Omitir preguntas [Y/n], por defecto es sí
-n, --no
Omitir preguntas [Y/n], por defecto es no
-A, --accessible
Activar el modo de accesibilidad, reduciendo el ruido visual
También puede especificarse con la variable de entorno ACCESSIBLE.
-H, --hidden
Ignorar archivos ocultos
-q, --quiet
Silenciar la salida
-g, --gitignore
Ignorar archivos que coincidan con los archivos de ignorar de git
-f, --format=FORMATO
Especificar el formato del archivo
-p, --password=CONTRASEÑA
Descomprimir o listar con contraseña
-c, --threads=HILOS
Hilos de trabajo concurrentes
-h, --help
Imprimir ayuda (ver un resumen con '-h')
-V, --version
Imprimir versión

SUBCOMANDOS

ouch-compress(1)
Comprimir uno o más archivos en un archivo de salida
ouch-decompress(1)
Descomprimir uno o más archivos, opcionalmente en otra carpeta
ouch-list(1)
Listar el contenido de un archivo
ouch-help(1)
Imprimir este mensaje o la ayuda de los subcomandos dados
