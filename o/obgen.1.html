NOMBRE

obgen — generar coordenadas 3D para una molécula

SINOPSIS

obgen [OPCIONES] nombre_archivo

DESCRIPCIÓN

La herramienta obgen generará coordenadas 3D para moléculas en un archivo (por ejemplo, archivos SMILES con múltiples moléculas). La estructura resultante se optimizará utilizando el campo de fuerza dado y se verificará la conformación de menor energía mediante una búsqueda de Monte Carlo. La salida se enviará a la salida estándar en formato de archivo SDF.

OPCIONES

Si no se proporciona un nombre de archivo, obgen mostrará todas las opciones, incluidos los campos de fuerza disponibles.

-ff campo_fuerza
Seleccionar el campo de fuerza

EJEMPLOS

Ver las opciones posibles, incluidos los campos de fuerza disponibles:

obgen

Generar coordenadas 3D para la(s) molécula(s) en el archivo test.smi:

obgen test.smi

Generar coordenadas 3D para la(s) molécula(s) en el archivo test.smi utilizando el campo de fuerza UFF:

obgen -ff UFF test.smi
