NOMBRE

oggenc - codifica audio al formato Ogg Vorbis

SINTAXIS

oggenc [ -hrQ ] [ -B tamaño de muestra de entrada cruda ] [ -C número de canales de entrada cruda ] [ -R frecuencia de muestreo de entrada cruda ] [ -b tasa de bits nominal ] [ -m tasa de bits mínima ] [ -M tasa de bits máxima ] [ -q calidad ] [ --resample frecuencia ] [ --downmix ] [ -s serie ] [ -o archivo de salida ] [ -n patrón ] [ -c comentario adicional ] [ -a artista ] [ -t título ] [ -l álbum ] [ -G género ] [ -L archivo de letras ] [ -Y cadena de idioma ] archivos de entrada ...

DESCRIPCIÓN

oggenc lee datos de audio en formato raw, Wave o AIFF y los codifica en un stream Ogg Vorbis. oggenc también puede leer datos de audio de archivos FLAC y Ogg FLAC dependiendo de las opciones de compilación. Si se especifica el archivo de entrada "-", los datos de audio se leen de stdin y el stream Vorbis se escribe en stdout a menos que se use la opción -o para redirigir la salida. Por defecto, los archivos del disco se generan como archivos Ogg Vorbis con el mismo nombre, cambiando la extensión a ".ogg" o ".oga". Esta convención de nombres puede ser anulada por la opción -o (en caso de un archivo) o la opción -n (en caso de varios archivos). Finalmente, si ninguna de estas está disponible, el nombre del archivo de salida será el nombre del archivo de entrada con la extensión (la parte después del último punto) reemplazada por ogg, así archivo.wav se convertirá en archivo.ogg.
Opcionalmente, se pueden incrustar letras en el archivo Ogg, si se compiló el soporte para Kate.
Tenga en cuenta que algunos reproductores antiguos pueden tener problemas para reproducir streams con más de un stream Vorbis (el llamado perfil simple "Vorbis I").

OPCIONES

-h, --help
Muestra la ayuda del comando.
-V, --version
Muestra el número de versión.
-r, --raw
Asume que los datos de entrada son datos de audio raw little-endian sin información de encabezado. Si no se especifican otras opciones, los valores predeterminados son 44.1kHz estéreo de 16 bits. Vea las siguientes tres opciones para cambiar esto.
-B n, --raw-bits=n
Establece el tamaño de muestra de entrada en modo raw en bits. El valor predeterminado es 16.
-C n, --raw-chan=n
Establece el número de canales de entrada en modo raw. El valor predeterminado es 2.
-R n, --raw-rate=n
Establece la frecuencia de muestreo de entrada en modo raw. El valor predeterminado es 44100.
--raw-endianness n
Establece la endianness en modo raw a big-endian (1) o little-endian (0). El valor predeterminado es little-endian.
--utf8        
Informa a oggenc que los Comentarios Vorbis ya están codificados en UTF-8. Útil en situaciones donde el shell está usando alguna otra codificación.
-k, --skeleton
Agrega un bitstream Skeleton. Importante si se pretende que el Ogg de salida contenga streams multiplexados o encadenados. El archivo de salida usa la extensión .oga.
--ignorelength
Soporte para archivos Wave de más de 4 GB y streams de datos stdin.
-Q, --quiet
Modo silencioso. No se muestran mensajes.
-b n, --bitrate=n
Establece la tasa de bits objetivo a n (en kb/s). El codificador intentará codificar aproximadamente a esta tasa de bits. Por defecto, esto sigue siendo una codificación VBR. Vea la opción --managed para forzar una codificación de tasa de bits gestionada a la tasa de bits seleccionada.
-m n, --min-bitrate=n
Establece la tasa de bits mínima a n (en kb/s). Habilita el modo de gestión de tasa de bits (ver --managed).
-M n, --max-bitrate=n
Establece la tasa de bits máxima a n (en kb/s). Habilita el modo de gestión de tasa de bits (ver --managed).
--managed
Establece el modo de gestión de tasa de bits. Esto desactiva la codificación VBR normal, pero permite que el codificador imponga restricciones de tasa de bits fijas o flexibles. Este modo es mucho más lento y puede ser de menor calidad. Es principalmente útil para crear archivos para streaming.
-q n, --quality=n
Establece la calidad de codificación a n, entre -1 (muy bajo) y 10 (muy alto). Este es el modo de operación predeterminado, con un nivel de calidad predeterminado de 3. Se permiten niveles de calidad fraccionales como 2.5. Usar esta opción permite al codificador seleccionar una tasa de bits apropiada basándose en el nivel de calidad deseado.
--resample n
Remuestrea la entrada a la tasa de muestreo dada (en Hz) antes de codificar. Principalmente útil para submuestrear para codificación de menor tasa de bits.
--downmix
Mezcla hacia abajo la entrada de estéreo a mono (no tiene efecto en streams no estéreo). Útil para codificación de menor tasa de bits.
--advanced-encode-option nombreopcion=valor
Establece una opción avanzada. Consulte la sección Opciones Avanzadas para más detalles.
-s, --serial
Fuerza un número de serie específico en el stream de salida. Esto es principalmente útil para pruebas.
--discard-comments
Evita que los comentarios en archivos FLAC y Ogg FLAC se copien al archivo Ogg Vorbis de salida.
-o archivo_salida, --output=archivo_salida
Escribe el stream Ogg Vorbis en archivo_salida (solo válido si se especifica un único archivo de entrada).
-n patrón, --names=patrón
Genera nombres de archivo como esta cadena, con %g, %a, %l, %n, %t, %d reemplazados por género, artista, álbum, número de pista, título y fecha, respectivamente (ver abajo para especificar estos). Además, %% genera un símbolo % literal.
-X, --name-remove=s
Elimina los caracteres especificados de los parámetros para la cadena de formato -n. Esto es útil para asegurar que se generen nombres de archivo legales.
-P, --name-replace=s
Reemplaza los caracteres eliminados por --name-remove con los caracteres especificados. Si esta cadena es más corta que la lista --name-remove, o no se especifica, los caracteres adicionales simplemente se eliminan. La configuración predeterminada para esta opción, y la opción -X anterior, son específicas de la plataforma (y elegidas para asegurar que se generen nombres de archivo legales para cada plataforma).
-c comentario, --comment comentario
Agrega la cadena comentario como un comentario adicional. Esto puede ser utilizado múltiples veces, y todas las instancias se agregarán a cada uno de los archivos de entrada especificados. El argumento debe estar en el formato "etiqueta=valor".
-a artista, --artist artista
Establece el campo de comentario del artista a artista.
-G género, --genre género
Establece el campo de comentario del género a género.
-d fecha, --date fecha
Establece el campo de comentario de fecha al valor dado. Esta debería ser la fecha de grabación.
-N n, --tracknum n
Establece el campo de comentario del número de pista al valor dado.
-t título, --title título
Establece el campo de comentario del título de la pista a título.
-l álbum, --album álbum
Establece el campo de comentario del álbum a álbum.
-L nombrearchivo, --lyrics nombrearchivo
Carga las letras desde nombrearchivo y las codifica en un stream Kate multiplexado con el stream Vorbis. Las letras pueden estar en formato LRC o SRT, y deben estar codificadas en UTF-8 o ASCII plano. Otras codificaciones pueden ser convertidas usando herramientas como iconv o recode. Alternativamente, el mismo sys
temas para comentarios se utilizarán para la conversión entre codificaciones. Se admiten los llamados archivos "LRC mejorados", y un simple cambio de estilo de karaoke se guardará con la letra. Para configuraciones de karaoke más complejas, kateenc(1) debe usarse en su lugar. Al incrustar letras, la extensión de archivo de salida predeterminada es ".oga". Tenga en cuenta que agregar letras a una transmisión habilitará automáticamente Skeleton (consulte la opción -k para obtener más información sobre Skeleton).
-Y idioma-cadena, --idioma-letras idioma-cadena
Establece el idioma para el archivo de letras correspondiente a idioma-cadena. Este debe ser un código de idioma ISO 639-1 (por ejemplo, "en"), o una etiqueta de idioma RFC 3066 (por ejemplo, "en_US"), no un nombre de idioma libre. Los reproductores normalmente reconocerán esta etiqueta estándar y mostrarán el nombre del idioma en su propio idioma. Tenga en cuenta que la longitud máxima de esta etiqueta es de 15 caracteres.

Tenga en cuenta que las opciones -a, -t, -l, -L y -Y se pueden dar varias veces. Se aplicarán, una a cada archivo, en el orden dado. Si hay menos comentarios de álbum, título o artista dados que archivos de entrada, oggenc reutilizará el último para los archivos restantes y emitirá una advertencia en el caso de títulos repetidos.

OPCIONES AVANZADAS DEL CODIFICADOR

Oggenc le permite establecer una serie de opciones avanzadas del codificador utilizando la opción --advanced-encode-option. Estas son solo para usuarios muy avanzados y deben abordarse con precaución. Pueden degradar significativamente la calidad del audio si se usan incorrectamente. No todas estas opciones están documentadas actualmente.

frecuencia_baja_paso=N
Establece la frecuencia de paso bajo a N kHz.
ajuste_ruido_impulso=N
Establece un sesgo de suelo de ruido N (rango de -15. a 0.) para los bloques de impulsos. Un sesgo negativo instruye al codificador a prestar especial atención a la nitidez de los transitorios en el audio codificado. La compensación para una mejor respuesta transitoria es una tasa de bits más alta.
max_bits_duro=N
Establece el máximo de tasa de bits permitido para el archivo codificado en N kilobits por segundo. Esta tasa de bits solo puede excederse cuando hay bits de sobra en la reserva de bits; si la reserva de bits se agota, los fotogramas se mantendrán por debajo de este valor. Esta configuración debe usarse con --managed para tener algún efecto.
min_bits_duro=N
Establece el mínimo de tasa de bits permitido para el archivo codificado en N kilobits por segundo. Esta tasa de bits solo puede quedar por debajo cuando la reserva de bits no está llena; si la reserva de bits está llena, los fotogramas se mantendrán por encima de este valor; si es imposible agregar bits de manera constructiva, el fotograma se rellenará con ceros. Esta configuración debe usarse con --managed para tener algún efecto.
bits_reserva_bits=N
Establece el tamaño total de la reserva de bits en N bits; el tamaño predeterminado de la reserva es igual al número nominal de bits codificados en un segundo (por ejemplo, un archivo de 128 kbps nominal tendrá una reserva de bits de 128000 bits por defecto). Esta opción debe usarse con --managed para tener algún efecto y solo afecta la gestión de tasa de bits mínima y máxima. La codificación de tasa de bits promedio sin límites de tasa de bits duros no utiliza una reserva de bits.
sesgo_reserva_bits=N
Establece el sesgo de comportamiento de la reserva de bits (rango: 0. a 1.). Cuando se establece más cerca de 0, el administrador de tasa de bits intenta acumular bits para su uso futuro en aumentos repentinos de tasa de bits (sesgando hacia una mejor reproducción transitoria). Cuando se establece más cerca de 1, el administrador de tasa de bits descuida los transitorios en favor del uso de bits para pasajes homogéneos. En el medio, el administrador utiliza un enfoque equilibrado. La configuración predeterminada es .2, lo que sesga ligeramente hacia la reproducción transitoria.
bits_promedio=N
Establece la tasa de bits promedio para el archivo en N kilobits por segundo. Cuando se usa sin límites mínimos o máximos duros, esta opción selecciona la codificación de Tasa de Bits Promedio sin reserva, donde el codificador intenta seguir perfectamente una tasa de bits deseada, pero no impone límites estrictos de fluctuación momentánea. Cuando se usa junto con un límite mínimo o máximo, la tasa de bits promedio aún establece la tasa de bits promedio general del archivo, pero funcionará dentro de los límites establecidos por la reserva de bits. Cuando las tasas de bits mínima, máxima y promedio son idénticas, oggenc produce datos Vorbis de Tasa de Bits Constante.
amortiguacion_promedio_bits=N
Establece el tiempo de reacción para el rastreador de tasa de bits promedio en N segundos. Este número representa la reacción más rápida permitida al rastreador de tasa de bits para mantener la tasa de bits al promedio seleccionado. Cuanto más rápido sea el tiempo de reacción, menor será la fluctuación momentánea en la tasa de bits, pero (generalmente) menor será la calidad del audio de salida. Cuanto más lento sea el tiempo de reacción, mayores serán las fluctuaciones de ABR, pero (generalmente) mejor será el audio. Cuando se usa junto con límites de tasa de bits mínimos o máximos, esta opción afecta directamente cuán profunda y cuán rápido el codificador accederá a su reserva de bits; cuanto mayor sea el número, mayor será la demanda sobre la reserva de bits.

La configuración debe ser mayor que cero y el rango útil es aproximadamente de .05 a 10. El valor predeterminado es .75 segundos.

deshabilitar_acoplamiento
Deshabilita el uso del acoplamiento de canales para la codificación multicanal. Actualmente, el codificador normalmente usará el acoplamiento de canales para aumentar aún más la compresión con entradas estéreo y 5.1. Esta opción obliga al codificador a codificar cada canal de forma totalmente independiente, sin acoplamiento con pérdida ni sin pérdida.

EJEMPLOS

Versión más simple. Produce una salida como somefile.ogg:

oggenc somefile.wav

Especificando un nombre de archivo de salida:

oggenc somefile.wav -o out.ogg

Especificando una codificación de alta calidad con un promedio de 256 kbps (pero aún VBR):

oggenc infile.wav -b 256 -o out.ogg

Especificando una tasa de bits máxima y promedio, y aplicándolas:

oggenc infile.wav --managed -b 128 -M 160 -o out.ogg

Especificando calidad en lugar de tasa de bits (a un modo de muy alta calidad):

oggenc infile.wav -q 6 -o out.ogg

Reduciendo el muestreo y mezclando a mono de 11 kHz antes de codificar:

oggenc --resample 11025 --downmix infile.wav -q 1 -o out.ogg

Agregando información sobre la pista:

oggenc somefile.wav -t "El título de la pista" -a "artista que interpretó esto" -l "nombre del álbum" -c "OTROCAMPO=contenido de algún otro campo no admitido explícitamente"

Agregando letras incrustadas:

oggenc somefile.wav --lyrics lyrics.lrc --lyrics-language en -o out.oga

Esto codifica los tres archivos, cada uno con la misma etiqueta de artista/álbum, pero con diferentes etiquetas de título en cada uno. La cadena dada como argumento a -n se utiliza para generar nombres de archivo, como se muestra en la sección anterior. Este ejemplo genera nombres de archivo como "The Tea Party - Touch.ogg":

oggenc -b 192 -a "The Tea Party" -l "Triptych" -t "Touch" track01.wav -t "Underground" track02.wav -t "Great Big Lie" track03.wav -n "%a - %t.ogg"

Codificación desde stdin, a stdout (también puede usar las diversas opciones de etiquetado, como -t, -a, -l, etc.):

oggenc -

ERRORES
