NOMBRE

ostree-init - Inicializa un nuevo repositorio vacío

SINOPSIS

ostree init [OPCIONES...]

DESCRIPCIÓN

Crea un nuevo repositorio vacío.

OPCIONES

--mode="MODO"

Inicializa el repositorio en el modo especificado (bare, bare-user, bare-user-only, archive). El valor predeterminado es bare. Tenga en cuenta que para archive, el archivo de configuración del repositorio tendrá en realidad archive-z2, ya que ese es el nombre histórico.

Consulte el manual para conocer las diferencias entre estos modos. En resumen, el modo bare almacena los archivos tal como están, por lo que pueden enlazarse directamente, bare-user utiliza atributos extendidos para almacenar información de propiedad y atributos extendidos, lo que permite operaciones que no requieren ser root, bare-user-only no almacena información de propiedad y archive almacena los archivos comprimidos, para ser servidos a través de la red.

--collection-id=ID-COLECCIÓN

Establece el ID de colección del repositorio. Los remotos en clones de este repositorio deben configurar el mismo valor para poder descargar referencias que se originaron en este repositorio a través de peer to peer.

Este ID de colección debe ser persistente y globalmente único. Tiene el formato de un nombre DNS inverso (como una interfaz D-Bus). Debe establecerse en un dominio DNS inverso bajo su control.

Esta opción puede omitirse (por defecto) para no admitir la distribución peer to peer para el repositorio. Se puede añadir un ID de colección a un repositorio existente en el futuro para habilitar la distribución peer to peer a partir de ese momento.

Si el ID de colección se cambia para el repositorio en el futuro, la distribución peer to peer de referencias desde el repositorio se interrumpirá para todos los pares que no actualicen su configuración remota al nuevo ID de colección.
