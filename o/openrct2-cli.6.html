OPENRCT2-CLI(6) Manual de Juegos OPENRCT2-CLI(6)

NOMBRE

openrct2-cli — Modo servidor sin cabeza para OpenRCT2

SINOPSIS

openrct2-cli [-h | --help] [-v | --version] [--verbose]

openrct2-cli host uri [--address dirección] [--port puerto] [--password contraseña]

DESCRIPCIÓN

OpenRCT2 soporta un modo sin cabeza donde el juego se ejecutará como una aplicación de consola sin interfaz gráfica. Esto es útil para ejecutar servidores de juego dedicados.

Varios objetos están disponibles en la interfaz de scripting de OpenRCT2 que se pueden modificar desde su CLI:

• cheats Habilitar/deshabilitar varios trucos

• climate Modificar el clima y el tiempo

• console Opciones para interactuar con la consola de salida estándar

• context API central para uso por plugins

• date Obtener o establecer la fecha dentro del juego

• map Manipulación del mapa

• network Gestión del servidor o interacción con clientes

• park APIs para el parque y su gestión

• scenario Información sobre el escenario actual

• titleSequenceManager Crear y editar secuencias de títulos (solo disponible para clientes que no se ejecutan en modo sin cabeza)

• ui APIs para controlar la interfaz de usuario (solo disponible para clientes que no se ejecutan en modo sin cabeza)

Para más información sobre OpenRCT2, sus opciones y capacidades, por favor consulte la página del manual openrct2(6) .

OPCIONES

-h | --help
Imprime un resumen de todas las opciones en la salida estándar y sale.
-v | --version
Muestra la información de la versión y sale.
-n | --no-install
No instala el escenario si se pasa como argumento.
-a | --all
Muestra la ayuda para todos los comandos.
--about
Muestra información sobre openrct2-cli.
--verbose
Imprime información de diagnóstico en la salida estándar.
--port puerto
Puerto a usar para alojar o unirse a un servidor; si no se especifica, se usará el puerto predeterminado 11753.
--address dirección
Dirección a la que enlazarse al alojar un servidor.
--password contraseña
Contraseña necesaria para unirse al servidor.
--user-data-path ruta
Ruta al directorio de datos de usuario (que contiene config.ini)
--openrct2-data-path ruta
Ruta al directorio de datos de OpenRCT2 (que contiene languages)
--rct1-data-path ruta
Ruta al directorio de datos de RollerCoaster Tycoon 1 (que contiene data/csg1.dat)
--rct2-data-path ruta
Ruta al directorio de datos de RollerCoaster Tycoon 2 (que contiene data/g1.dat)

NOTAS

Con el multijugador, podrías encontrarte con algunos errores que no ocurren en el modo de un jugador. Si eso sucede, por favor repórtalo en GitHub si el problema aún no ha sido reportado, y por favor indica si el error solo ocurre en partidas multijugador.

Para que el servidor acepte clientes con éxito, el puerto debe estar abierto en el propio firewall del servidor y en cualquier firewall de router detrás del cual se encuentre el ordenador. Además, si el servidor está detrás de un router con NAT habilitado, el router debe estar configurado para tener el puerto reenviado a la dirección local del servidor.

EJEMPLOS

openrct2-cli host ./my_park.sv6 --port 11753
Ejecuta un servidor sin cabeza para un parque guardado.
$ network.players[1].group = 0
Desde la CLI de un servidor multijugador, establece al primer usuario en unirse como administrador
$ cheats["disableAllBreakdowns"] = true
Desde la CLI, habilita el truco para desactivar todas las averías de atracciones
