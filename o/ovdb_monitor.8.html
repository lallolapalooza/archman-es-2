NOMBRE

ovdb_monitor - Mantenimiento de la base de datos

SINOPSIS

Use ovdb_init para iniciar ovdb_monitor

DESCRIPCIÓN

Cuando se inicia (normalmente por ovdb_init, que es invocado por rc.news), ovdb_monitor crea tres procesos que realizan tareas de mantenimiento de la base de datos. Estos son el punto de control de transacciones (cada 30 segundos), la detección de interbloqueos (cada 30 segundos) y la eliminación del registro de transacciones (cada 45 segundos).

El ID del proceso padre se escribe en ovdb_monitor.pid en el directorio pathrun. Este PID es utilizado por otros comandos de INN para verificar que ovdb_monitor se está ejecutando.

Para detener ovdb_monitor, envíe una señal TERM al ID del proceso en ovdb_monitor.pid. El proceso padre detendrá los tres hijos y esperará su salida antes de salir él mismo. Tenga en cuenta que al ejecutar el comando "rc.news stop" para detener el sistema de noticias, rc.news se encarga automáticamente de detener ovdb_monitor.

HISTORIAL

VER TAMBIÉN
