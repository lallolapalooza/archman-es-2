NOMBRE

ovs-kmod-ctl - Script de inicio de OVS para cargar módulos del kernel

SINOPSIS

ovs-kmod-ctl insert
ovs-kmod-ctl remove
ovs-kmod-ctl help | -h | --help
ovs-kmod-ctl --version
ovs-kmod-ctl version

DESCRIPCIÓN

El programa ovs-kmod-ctl es responsable de insertar y eliminar los módulos del kernel de Open vSwitch. No está diseñado para ser invocado directamente por los administradores del sistema, sino para ser llamado internamente por los scripts de inicio del sistema. El script se utiliza como parte de un dominio de transición SELinux.

Cada uno de los comandos de ovs-kmod-ctl se describe por separado a continuación.

El comando ``insert''

El comando insert carga los módulos del kernel de Open vSwitch, si es necesario. Si esto falla, y el módulo de bridge de Linux está cargado pero no existen bridges, intenta descargar el módulo de bridge e intenta cargar el módulo del kernel de Open vSwitch nuevamente.

El comando ``remove''

El comando remove descarga el módulo del kernel de Open vSwitch (incluido el módulo de compatibilidad de bridge, si está cargado) y cualquier módulo vport asociado.

ESTADO DE SALIDA

ovs-kmod-ctl sale con estado 0 en caso de éxito y distinto de cero en caso de fallo. El comando insert se considera exitoso si los módulos del kernel ya están cargados; el comando remove se considera exitoso si ninguno de los módulos del kernel está cargado.

ENTORNO

Las siguientes variables de entorno afectan a ovs-kmod-ctl:

PATH
ovs-kmod-ctl no codifica la ubicación de ninguno de los programas que ejecuta. ovs-kmod-ctl agregará el sbindir y bindir que se especificaron en el momento de la configuración a PATH, si no están ya presentes.
OVS_LOGDIR

OVS_RUNDIR

OVS_DBDIR

OVS_SYSCONFDIR

OVS_PKGDATADIR

OVS_BINDIR

OVS_SBINDIR
Establecer una de estas variables en el entorno anula la opción de configuración respectiva, tanto para ovs-kmod-ctl en sí como para los otros programas de Open vSwitch que ejecuta.

ARCHIVOS

ovs-kmod-ctl utiliza los siguientes archivos:

ovs-lib
Biblioteca de funciones shell utilizada internamente por ovs-kmod-ctl. Debe estar instalada en el mismo directorio que ovs-kmod-ctl.

EJEMPLO

ovs-kmod-ctl no está diseñado para ser ejecutado manualmente. Sin embargo, los siguientes ejemplos demuestran la carga de los módulos del kernel.

ovs-kmod-ctl insert
Intenta insertar los módulos del kernel de Open vSwitch.
ovs-kmod-ctl remove
Intenta eliminar los módulos del kernel de Open vSwitch.
