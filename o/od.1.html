OD(1) Comandos de usuario OD(1)

NOMBRE

od - volcar archivos en octal y otros formatos

SINOPSIS

od [OPCIÓN]... [ARCHIVO]...
od [-abcdfilosx]... [ARCHIVO] [[+]DESPLAZAMIENTO[.][b]]
od --traditional [OPCIÓN]... [ARCHIVO] [[+]DESPLAZAMIENTO[.][b] [+][ETIQUETA][.][b]]

DESCRIPCIÓN

Escribe una representación inequívoca, bytes en octal por defecto, de ARCHIVO a la salida estándar. Con más de un argumento ARCHIVO, concaténalos en el orden listado para formar la entrada.

Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar.

Si el primer y segundo formato de llamada se aplican ambos, se asume el segundo formato si el último operando comienza con + o (si hay 2 operandos) un dígito. Un operando DESPLAZAMIENTO significa -j DESPLAZAMIENTO. ETIQUETA es la dirección pseudo en el primer byte impreso, incrementada cuando el volcado progresa. Para DESPLAZAMIENTO y ETIQUETA, un prefijo 0x o 0X indica hexadecimal; los sufijos pueden ser . para octal y b para multiplicar por 512.

Los argumentos obligatorios para las opciones largas son obligatorios también para las opciones cortas.

-A, --radix-direccion=RADIX
formato de salida para los offsets del archivo; RADIX es uno de [doxn], para Decimal, Octal, Hex o Ninguno
--endian={big|little}
intercambia los bytes de entrada según el orden especificado
-j, --saltar-bytes=BYTES
salta BYTES bytes de entrada primero
-N, --leer-bytes=BYTES
limita el volcado a BYTES bytes de entrada
-S BYTES, --cadenas[=BYTES]
muestra solo cadenas terminadas en NUL de al menos BYTES (3) caracteres imprimibles
-t, --formato=TIPO
selecciona formato o formatos de salida
-v, --salida-duplicados
no usar * para marcar supresión de línea
-w[BYTES], --ancho[=BYTES]
bytes de salida BYTES por línea de salida; se implican 32 cuando BYTES no se especifica
--traditional
acepta argumentos en la tercera forma anterior
--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale

Las especificaciones de formato tradicionales pueden intercalarse; se acumulan:

-a
igual que -t a, selecciona caracteres con nombre, ignorando el bit de orden superior
-b
igual que -t o1, selecciona bytes octales
-c
igual que -t c, selecciona caracteres imprimibles o escapes de barra invertida
-d
igual que -t u2, selecciona unidades sin signo decimales de 2 bytes
-f
igual que -t fF, selecciona flotantes
-i
igual que -t dI, selecciona enteros decimales
-l
igual que -t dL, selecciona enteros largos decimales
-o
igual que -t o2, selecciona unidades octales de 2 bytes
-s
igual que -t d2, selecciona unidades decimales de 2 bytes
-x
igual que -t x2, selecciona unidades hexadecimales de 2 bytes

TIPO se compone de una o más de estas especificaciones:

a
carácter con nombre, ignorando el bit de orden superior
c
carácter imprimible o escape de barra invertida
d[TAMAÑO]
decimal con signo, TAMAÑO bytes por entero
f[TAMAÑO]
punto flotante, TAMAÑO bytes por flotante
o[TAMAÑO]
octal, TAMAÑO bytes por entero
u[TAMAÑO]
decimal sin signo, TAMAÑO bytes por entero
x[TAMAÑO]
hexadecimal, TAMAÑO bytes por entero

TAMAÑO es un número. Para TIPO en [doux], TAMAÑO también puede ser C para sizeof(char), S para sizeof(short), I para sizeof(int) o L para sizeof(long). Si TIPO es f, TAMAÑO también puede ser B para Brain de 16 bits, H para flotante de media precisión, F para sizeof(float), D para sizeof(double), o L para sizeof(long double).

Añadir un sufijo z a cualquier tipo muestra caracteres imprimibles al final de cada línea de salida.

BYTES es hexadecimal con prefijo 0x o 0X, y puede tener un sufijo multiplicador:

b
512
KB
1000
K
1024
MB
1000*1000
M
1024*1024

y así sucesivamente para G, T, P, E, Z, Y, R, Q. También se pueden usar prefijos binarios: KiB=K, MiB=M, y así sucesivamente.

EJEMPLOS

od -A x -t x1z -v
Mostrar salida en formato hexdump
od -A o -t oS -w16
El formato de salida predeterminado utilizado por od
