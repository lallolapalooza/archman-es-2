OPENTTD(6) Manual de Juegos OPENTTD(6)

NOMBRE

openttd — clon de código abierto del juego de Microprose “Transport Tycoon Deluxe”

SINOPSIS

openttd [-efhQxX] [-b blitter] [-c archivo_config] [-d [nivel | cat=lvl[,...]]] [-D [host][:puerto]] [-g [archivo]] [-G semilla] [-I conjunto_graficos] [-m driver] [-M conjunto_musica] [-n host[:puerto][#empresa]] [-p contraseña] [-P contraseña] [-q partida_guardada] [-r anchoxalto] [-s driver] [-S conjunto_sonido] [-t año] [-v driver]

OPCIONES

-b blitter
Selecciona el blitter blitter; consulta -h para obtener una lista completa.
-c archivo_config
Usa archivo_config en lugar de openttd.cfg.
-d [nivel]
Establece la verbosidad de depuración para todas las categorías a nivel, o 1 si se omite.
-d cat=lvl[,...]
Establece la verbosidad de depuración a lvl para la categoría específica cat.
-D [host][:puerto]
Inicia un servidor dedicado.

El nivel de depuración de red se establecerá en 6. Si quieres cambiar esto, establece -d después de establecer -D.

-e
Inicia en modo editor de mundos.
-f
Se bifurca en segundo plano (solo para servidores dedicados, consulta -D).
-g [archivo]
Carga archivo (puede ser una partida guardada, un escenario o un mapa de altitud) al inicio o inicia un nuevo juego si se omite. archivo debe ser una ruta absoluta o una relativa a la ruta actual o a una de las rutas de búsqueda.
-G semilla
Siembra el generador de números pseudoaleatorios con semilla.
-h
Muestra un resumen de todas las opciones y lista todas las IAs, blitters, drivers de sonido, música y video, conjuntos gráficos y de sonido disponibles.
-I conjunto_graficos
Selecciona el conjunto gráfico conjunto_graficos; consulta -h para obtener una lista completa.
-m driver
Selecciona el driver de música driver; consulta -h para obtener una lista completa.
-M conjunto_musica
Selecciona el conjunto de música conjunto_musica; consulta -h para obtener una lista completa.
-n host[:puerto][#empresa]
Únete a una partida en red, especificando opcionalmente un puerto al que conectarse y la empresa a la que jugar.
-p contraseña
Contraseña utilizada para unirse al servidor. Solo útil con -n.
-P contraseña
Contraseña utilizada para unirse a una empresa. Solo útil con -n.
-q partida_guardada
Escribe información sobre la partida guardada especificada y sale.
-Q
No escanee/cargue archivos NewGRF al iniciar.

Pasar -Q dos veces (es decir, -QQ) deshabilitará completamente el escaneo/carga de NewGRF.

-r anchoxalto
Establece la resolución a ancho × alto píxeles.
-s driver
Selecciona el driver de sonido driver; consulta -h para obtener una lista completa.
-S conjunto_sonido
Selecciona el conjunto de sonido conjunto_sonido; consulta -h para obtener una lista completa.
-t año
Establece el año de inicio a año.
-v driver
Selecciona el driver de video driver; consulta -h para obtener una lista completa.
-x
No guardar automáticamente en el archivo de configuración al salir.
-X
No usar carpetas globales para buscar archivos.

VER TAMBIÉN

Wiki (incluye manual mantenido por la comunidad), Foro, Noticias

HISTORIA

Transport Tycoon Deluxe fue escrito por Chris Sawyer y publicado por Microprose. openttd es una reimplementación gratuita.
