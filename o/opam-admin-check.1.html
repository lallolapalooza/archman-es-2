OPAM ADMIN-CHECK(1) Manual de administración de Opam OPAM ADMIN-CHECK(1)

NOMBRE

opam admin-check - Ejecuta algunas comprobaciones de consistencia en un repositorio

SINOPSIS

opam admin check [OPCIÓN]…

DESCRIPCIÓN

Este comando ejecuta comprobaciones de consistencia en un repositorio e imprime un informe en la salida estándar. Las comprobaciones incluyen paquetes que no son instalables (debido, por ejemplo, a una dependencia faltante) y ciclos de dependencia. El campo 'available' se ignora para estas comprobaciones, es decir, se supone que todos los paquetes están disponibles. Por defecto, se ejecutan todas las comprobaciones.

OPCIONES

--cycles
Realiza la comprobación de ciclos (y deshabilita las otras por defecto)
--installability
Realiza la comprobación de instalabilidad (y deshabilita las otras por defecto)
--obsolete
Análisis de paquetes obsoletos
-s, --short
Solo muestra una lista de paquetes no instalables

OPCIONES COMUNES

Estas opciones son comunes a todos los comandos.

--best-effort
No fallar si no se pueden instalar todos los paquetes solicitados: intenta instalar tantos como sea posible. Nota que no todos los solucionadores externos pueden admitir esta opción (versiones recientes de aspcud o mccs deberían). Esto es equivalente a establecer la variable de entorno $OPAMBESTEFFORT.
--cli=MAYOR.MENOR (ausente=2.4)
Utiliza la sintaxis y semántica de la interfaz de línea de comandos de MAYOR.MENOR. Destinado a cualquier uso persistente de opam (scripts, publicaciones de blog, etc.), cualquier versión de opam de la misma serie MAYOR se comportará como para la versión MENOR especificada. La bandera no estaba disponible en opam 2.0, así que para seleccionar la CLI 2.0, establece la variable de entorno OPAMCLI a 2.0 en lugar de usar este parámetro.
--color=CUÁNDO
Colorea la salida. CUÁNDO debe ser uno de siempre, nunca o automático.
--confirm-level=NIVEL
Nivel de confirmación, NIVEL debe ser uno de preguntar, no, sí o unsafe-yes. Se puede especificar más de una vez. Si también se dan --yes o --no, se tiene en cuenta el valor de la última opción --confirm-level. Esto es equivalente a establecer $OPAMCONFIRMLEVEL.
--criteria=CRITERIA
Especifica las preferencias del usuario para la resolución de dependencias para esta ejecución. Anula $OPAMCRITERIA, $OPAMFIXUPCRITERIA y $OPAMUPGRADECRITERIA. Para obtener detalles sobre el lenguaje admitido y los solucionadores externos disponibles, consulta http://opam.ocaml.org/doc/External_solvers.html. Una guía general sobre el uso de preferencias del solucionador se puede encontrar en http://www.dicosmo.org/Articles/usercriteria.pdf.
--cudf=NOMBREARCHIVO
Opción de depuración: Guarda las solicitudes CUDF enviadas al solucionador en NOMBREARCHIVO-<n>.cudf donde <n> es la n-ésima llamada al solucionador durante la ejecución de opam.
--debug
Imprime mensajes de depuración en stderr. Esto es equivalente a establecer $OPAMDEBUG a "true".
--debug-level=NIVEL
Similar a --debug, pero permite especificar el nivel de depuración (--debug lo establece a 1). Equivalente a establecer $OPAMDEBUG a un entero positivo.
--git-version
Imprime la versión git de opam, si está establecida (es decir, si estás usando una versión de desarrollo), y sale.
--help[=FMT] (predeterminado=automático)
Muestra esta ayuda en el formato FMT. El valor FMT debe ser uno de automático, pager, groff o plain. Con automático, el formato es pager o plain siempre que la variable TERM sea dumb o indefinida.
--ignore-pin-depends
Ignora los pines adicionales requeridos por los paquetes que se fijan, ya sea manualmente a través de opam pin o a través de opam install DIR. Esto es equivalente a establecer IGNOREPINDEPENDS=true.
--json=NOMBREARCHIVO
Guarda los resultados de la ejecución de opam en un archivo legible por máquina. Si el nombre de archivo contiene el carácter `%', se reemplazará por un índice que no sobrescribirá un archivo existente. Similar a establecer la variable $OPAMJSON.
--no
Responde no a todas las preguntas de sí/no de opam sin preguntar. Ver también --confirm-level. Esto es equivalente a establecer $OPAMNO a "true".
--no-aspcud
Eliminado en 2.1.
--no-auto-upgrade
Al configurar o actualizar un repositorio que está escrito para una versión anterior de opam (1.2), opam lo convierte internamente al formato actual. Esto deshabilita este comportamiento. Ten en cuenta que los repositorios deben definir su versión de formato en un archivo 'repo' en su raíz, de lo contrario se asumirá que están en el formato anterior. En cualquier caso, es preferible actualizar los repositorios manualmente usando opam admin upgrade [--mirror URL] cuando sea posible.
-q, --quiet
Deshabilita --verbose.
--root=RAÍZ
Utiliza RAÍZ como la ruta raíz actual. Esto es equivalente a establecer $OPAMROOT a RAÍZ.
--safe, --readonly
Asegúrate de que nada se actualice o reescriba automáticamente. Útil para llamar desde scripts de finalización, por ejemplo. Fallará siempre que se necesite una operación de este tipo; también evita esperar bloqueos, omite preguntas interactivas y anula la variable $OPAMDEBUG. Esto es equivalente a establecer la variable de entorno $OPAMSAFE.
--solver=CMD
Especifica el solucionador CUDF a utilizar para resolver problemas de instalación de paquetes. Este es un solucionador predefinido (esta versión de opam admite builtin-mccs+lp(), builtin-mccs+glpk, builtin-dummy-z3-solver, builtin-0install, aspcud, mccs, aspcud-old, packup), o un comando personalizado que debe contener las variables %{input}%, %{output}%, %{criteria}%, y opcionalmente %{timeout}%. Esto es equivalente a establecer $OPAMEXTERNALSOLVER.
--strict
Falla siempre que se encuentre un error en la definición de un paquete o en un archivo de configuración. Por defecto, continúa silenciosamente si es posible.
--switch=SWITCH
Utiliza SWITCH como el switch de compilador actual. Esto es equivalente a establecer $OPAMSWITCH a SWITCH.
--use-internal-solver
Deshabilita cualquier solucionador externo y utiliza el interno (esto requiere que opam se haya compilado con un solucionador interno). Esto es equivalente a establecer $OPAMNOASPCUD o $OPAMUSEINTERNALSOLVER.
-v, --verbose
Sé más detallado. Una opción -v muestra todos los comandos de paquetes, repite para mostrar también comandos llamados internamente (por ejemplo, tar, curl, patch, etc.) Repetir n veces es equivalente a establecer $OPAMVERBOSE a "n".
--version
Muestra información de la versión.
-w, --working-dir
Siempre que se actualicen paquetes vinculados a un directorio local controlado por versión, actualiza al estado de trabajo actual de su fuente en lugar del último estado confirmado, o la referencia a la que apuntan. Como el directorio de origen se copia tal cual, si no está limpio, podría resultar en un fallo de compilación de opam. Esto solo afecta a los paquetes listados explícitamente en la línea de comandos. También se puede configurar con $OPAMWORKINGDIR.
-y, --yes
Responde sí a todas las preguntas de sí/no de opam sin preguntar. Ver también --confirm-level. Esto es equivalente a establecer $OPAMYES a "true".

AMBIENTE

Opam hace uso de las variables de entorno listadas aquí. Las variables booleanas deben establecerse en "0", "no", "false" o la cadena vacía para deshabilitar, y en "1", "yes" o "true" para habilitar.

OPAMALLPARENS rodea todos los filtros con paréntesis.

OPAMASSUMEDEPEXTS ver la opción `--assume-depexts'.

OPAMAUTOREMOVE ver la opción remove `--auto-remove'.

OPAMBESTEFFORT ver la opción `--best-effort'.

OPAMBESTEFFORTPREFIXCRITERIA establece la cadena que debe prefijarse a los criterios cuando se establece la opción `--best-effort', y se espera que maximice la propiedad `opam-query' en la solución.

OPAMBUILDDOC Eliminado en 2.1.

CLI VERSION

All scripts and programmatic invocations of opam should use `--cli' in order to ensure that they work seamlessly with future versions of the opam client. Additionally, blog posts or other documentation can benefit, as it prevents information from becoming stale.

Although opam only supports roots (~/.opam/) for the current version, it does provide backwards compatibility for its command-line interface.

Since CLI version support was only added in opam 2.1, use OPAMCLI to select 2.0 support (as opam 2.0 will just ignore it), and `--cli=2.1' for 2.1 (or later) versions, since an environment variable controlling the parsing of syntax is brittle. To this end, opam displays a warning if OPAMCLI specifies a valid version other than 2.0, and also if `--cli=2.0' is specified.

The command-line version is selected by using the `--cli' option or the OPAMCLI environment variable. `--cli' may be specified morethan once, where the last instance takes precedence. OPAMCLI is only inspected if `--cli' is not given.

ESTADO DE SALIDA

10
Error al analizar la línea de comandos. Para más detalles, consulte la opción --help.
20
Error de configuración. No se pudo encontrar o inicializar el repositorio principal.
30
Operaciones no exitosas. Esto puede ser un error en los paquetes o una incompatibilidad con su sistema. Este puede ser un error parcial.
40
Error de sincronización. No se pudieron obtener algunos remotos de la red. Este puede ser un error parcial.
50
Error de configuración. La configuración de Opam o del sistema no permite la operación y necesita ser corregida.
60
Fallo del solucionador. El solucionador no pudo devolver una respuesta válida. Puede deberse a un solucionador externo dañado o a un error en la configuración del solucionador.
99
Error interno. Algo salió mal, probablemente debido a un error en el propio opam.
130
Interrupción del usuario. Se recibió SIGINT, generalmente debido a que el usuario presionó Ctrl-C.
0
en caso de éxito.
123
en errores indiscriminados reportados en la salida estándar.
124
en errores de análisis de línea de comandos.
125
en errores internos inesperados (bugs).
