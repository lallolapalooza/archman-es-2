NOMBRE

ostree-checkout - Extraer un commit en un sistema de archivos

SINOPSIS

ostree checkout [OPCIONES...] {COMMIT} [DESTINO]

DESCRIPCIÓN

Extrae el commit dado en el sistema de archivos bajo el directorio DESTINO. Si no se especifica DESTINO, el COMMIT se convertirá en el destino de extracción. Si el destino del COMMIT ya existe, el comando fallará a menos que se seleccione la opción --union.

OPCIONES

--user-mode, -U

No cambie la propiedad de los archivos ni inicialice atributos extendidos.

--subpath="RUTA"

Extraer el subdirectorio RUTA.

--union

Mantener directorios existentes y archivos sin cambios, sobrescribir archivos existentes.

--union-add

Mantener directorios y archivos existentes.

--union-identical

Similar a --union, pero falla si un archivo se reemplaza con un archivo diferente. Añade nuevos archivos y directorios, ignora archivos idénticos y mantiene directorios existentes. Requiere -H.

--whiteouts

Procesa archivos whiteout (estilo Docker).

--process-passthrough-whiteouts

Habilita la extracción de whiteouts de overlayfs en dispositivos de caracteres 0:0. Los whiteouts de overlayfs se codifican dentro de ostree como .ostree-wh.nombre_archivo y se extraen como dispositivos de caracteres 0:0. Esto es útil para transportar almacenamiento de contenedores incrustado en ostree.

--allow-noent

No hacer nada si la ruta especificada no existe.

--from-stdin

Procesa muchas extracciones desde la entrada estándar.

--from-file="ARCHIVO"

Procesa muchas extracciones desde un archivo de entrada.

--fsync="POLÍTICA"

POLÍTICA es un booleano que especifica si se debe usar fsync o no. Por defecto es true.

--require-hardlinks, -H

No recurrir a copias completas si fallan los hardlinks.

--force-copy-zerosized, -z

Esta opción no hace nada; la funcionalidad ahora está siempre activada por defecto.

--force-copy, -C

Nunca usar hardlinks (pero puede usar reflink si está disponible).

--bareuseronly-dirs, -M

Suprime los bits de modo fuera de 0775 para directorios (suid, escribible por todos, etc.).

--skip-list="ARCHIVO"

Omite la extracción de las rutas de archivo absolutas listadas en ARCHIVO, una por línea.

--selinux-policy

Establece etiquetas SELinux basadas en la política en la ruta del sistema de archivos raíz (puede ser /). Esto implica --force-copy.

--composefs

Solo genera un composefs, no un directorio.

--composefs-noverity

Solo genera un composefs, no un directorio; no se incluirán los resúmenes de fsverity. Esto se usa mejor para el uso "oportunista" de composefs.

EJEMPLO

$ ostree checkout my-branch

$ ls

        file1    file2    my-branch
