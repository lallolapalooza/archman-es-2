ol(1) Manual de Comandos Generales ol(1)

NOMBRE

ol - un compilador e intérprete de Owl Lisp

SINOPSIS

ol [opciones] [ruta] ...

DESCRIPCIÓN

Owl Lisp es una variante puramente funcional de R7RS Scheme. Ol se puede utilizar para evaluar programas de forma interactiva y compilarlos a binarios nativos a través de C.

OPCIONES

Este programa sigue la sintaxis habitual de la línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones esenciales de la línea de comandos. La lista completa se muestra en la página de ayuda.

-h, --help
Muestra un resumen de las opciones.
-v, --version
Muestra la versión del programa.
-e, --eval cadena
Evalúa la cadena, imprime su valor y sale con 0 a menos que ocurran errores.
-t, --test cadena
Evalúa la cadena y sale con 1 si el valor es #falso, 0 si es verdadero, o 126 si hay un error.
-o, --output archivo-salida
Compila el archivo dado a fasl o código C, y guarda el resultado en el archivo de salida dado.
-r, --run ruta
Carga el archivo silenciosamente, y llama al último valor con los argumentos restantes de la línea de comandos.
-x, --output-format formato
Elige a qué debe compilar ol la entrada dada. Las opciones válidas actualmente son c y fasl. Normalmente se deduce del sufijo del archivo dado en -o, por lo que no suele ser necesario.
-O0, -O1, -O2
Escribe bytecode plano, compila algunas funciones comunes a C o todo lo posible. Estos solo tienen sentido al compilar a C.
-l, --load ruta
Reanuda la ejecución del estado del programa guardado con suspend.

EJEMPLOS

Crear un binario simple

$ echo '(lambda (args) (for-each print args))' > test.l
$ ol -o test.c test.l
$ gcc -o test test.c
$ ./test foo bar
Compilar en una tubería
$ echo '(lambda (args) (print (cons "I got " args)))' | ol -x c -o - | gcc -x c -o test - && ./test 11 22 33
Cargar vs ejecutar archivos

$ echo '(print "¡Hola, mundo!")' > test.l
$ ol test.l
¡Hola, mundo!
$ echo '(lambda (args) (print "¡Hola, mundo!"))' > test.l
$ ol --run test.l arg1 arg2 arg3
¡Hola, mundo!
