Nombre

org.bluez.GattDescriptor - Documentación de la API GattDescriptor de D-Bus de BlueZ

Descripción

Los descriptores GATT locales/servidor y remotos/cliente comparten la misma API de D-Bus de alto nivel.

Local/Servidor se refiere a los descriptores basados en GATT exportados por un plugin o una aplicación externa.

Remoto/Cliente se refiere a los descriptores GATT exportados por el par.

Nombre

org.bluez.GattDescriptor

Descripción

La interfaz org.bluez.GattDescriptor representa un descriptor GATT. Los descriptores GATT son objetos que contienen información adicional sobre una característica GATT.

Los descriptores GATT pueden ser utilizados para describir el formato, la unidad, o el alcance de los valores de una característica. También pueden contener datos de configuración o control para la característica.

Un descriptor GATT está asociado a una característica GATT y se identifica por su UUID.

Interfaz

Las interfaces D-Bus que se pueden obtener para un descriptor GATT son:

  • org.bluez.GattDescriptor1: Esta interfaz representa el descriptor GATT en sí. Proporciona métodos para leer y escribir el valor del descriptor.
    • ReadValue(dict options): Lee el valor del descriptor. Las opciones pueden incluir un tiempo de espera. Devuelve el valor leído y el tipo de datos.
    • WriteValue(array{byte} value, dict options): Escribe un valor en el descriptor. Las opciones pueden incluir un tiempo de espera.
    • UUID: (Lectura) El UUID del descriptor.
    • Value: (Lectura) El valor actual del descriptor.
