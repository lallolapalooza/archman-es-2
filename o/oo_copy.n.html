copy(n) Comandos de TclOO copy(n)

NOMBRE

oo::copy - crear copias de objetos y clases

SINOPSIS

package require TclOO
oo::copy objetoOrigen ?objetoDestino? ?espacioNombresDestino?

DESCRIPCIÓN

El comando oo::copy crea una copia de un objeto o clase. Toma el nombre del objeto o clase a copiar, objetoOrigen, y opcionalmente el nombre del objeto o clase a crear, objetoDestino, que se resolverá en relación con el espacio de nombres actual si no es un nombre calificado absoluto y espacioNombresDestino, que es el nombre del espacio de nombres que contendrá el estado interno del objeto (comando my, etc.); *no debe* referirse a un espacio de nombres existente. Si se omite objetoDestino o espacioNombresDestino, o se proporciona como una cadena vacía, se elegirá un nuevo nombre. Los nombres, a menos que se especifiquen, se eligen con el mismo algoritmo utilizado por el método new de oo::class. El objeto copiado será de la misma clase que el objeto origen, y tendrá todos sus métodos por objeto copiados. Si es una clase, también tendrá todos los métodos de clase de la clase copiados, pero no tendrá ninguna de sus instancias copiadas.

Después de que objetoDestino haya sido creado y se copien todas las definiciones de su configuración (p. ej., métodos, filtros, mixins), se invocará el método <cloned> de objetoDestino, para permitir la personalización del objeto creado, como la instalación de rastreadores de variables relacionados. El único argumento que se le dará será objetoOrigen. La implementación predeterminada de este método (en oo::object) simplemente copia los procedimientos y variables en el espacio de nombres de objetoOrigen al espacio de nombres de objetoDestino. Si esta llamada al método no devuelve un resultado exitoso (es decir, un error u otro tipo de excepción), entonces objetoDestino será eliminado y se devolverá un error.

El resultado del comando oo::copy será el nombre completamente calificado del nuevo objeto o clase.

EJEMPLOS

Este ejemplo crea un objeto, lo copia, modifica el objeto origen, y luego demuestra que el objeto copiado es efectivamente una copia.

oo::object create src
oo::objdefine src method msg {} {puts foo}
oo::copy src dst
oo::objdefine src method msg {} {puts bar}
src msg              → imprime "bar"
dst msg              → imprime "foo"

VER TAMBIÉN

oo::class(n), oo::define(n), oo::object(n)
