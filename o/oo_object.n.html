oo_object(n) Comandos TclOO oo_object(n)

NOMBRE

oo::object - clase raíz de la jerarquía de clases

SINOPSIS

package require TclOO
oo::object método ?arg ...?

JERARQUÍA DE CLASES

oo::object

DESCRIPCIÓN

La clase oo::object es la clase raíz de la jerarquía de objetos; cada objeto es una instancia de esta clase. Dado que las clases son en sí mismas objetos, también son instancias de esta clase. Los objetos se referencian siempre por su nombre y pueden ser renombrados manteniendo su identidad.

Las instancias de objetos pueden crearse con los métodos create o new del propio objeto oo::object, o invocando esos métodos en cualquiera de los objetos de subclase; ver oo::class para más detalles. La configuración de objetos individuales (es decir, métodos específicos de la instancia, clases mezcladas, etc.) puede controlarse con el comando oo::objdefine.

Cada objeto tiene un espacio de nombres único asociado a él, el espacio de nombres de instancia. Este espacio de nombres contiene todas las variables de instancia del objeto, y será el espacio de nombres actual cada vez que se invoque un método del objeto (incluyendo un método de la clase del objeto). Cuando el objeto es destruido, su espacio de nombres de instancia se elimina. El espacio de nombres de instancia contiene el comando my del objeto, que puede usarse para invocar métodos no exportados del objeto o para crear una referencia al objeto con el fin de invocarla, la cual persiste a través de los cambios de nombre del objeto.

CONSTRUCTOR

La clase oo::object no define un constructor explícito.

DESTRUCTOR

La clase oo::object no define un destructor explícito.

MÉTODOS EXPORTADOS

La clase oo::object soporta los siguientes métodos exportados:

obj destroy
Este método destruye el objeto, obj, sobre el cual se invoca, invocando cualquier destructor en la clase del objeto en el proceso. Es equivalente a usar rename para eliminar el comando del objeto. El resultado de este método es siempre la cadena vacía.

MÉTODOS NO EXPORTADOS

La clase oo::object soporta los siguientes métodos no exportados:

obj eval ?arg ...?
Este método concatena los argumentos, arg, como si fuera con concat, y luego evalúa el script resultante en el espacio de nombres que está asociado de forma única con obj, devolviendo el resultado de la evaluación.

Tenga en cuenta que los comandos internos del objeto como my y self pueden invocarse en este contexto.

obj unknown ?nombreMetodo? ?arg ...?
Este método se llama cuando un intento de invocar el método nombreMetodo en el objeto obj falla. Los argumentos que el usuario proporcionó al método se dan como argumentos arg. Si nombreMetodo está ausente, el objeto fue invocado sin nombre de método alguno (o con cualquier otro argumento). La implementación por defecto (es decir, la definida por la clase oo::object) genera un error adecuado, detallando qué métodos soporta el objeto, dado si el objeto fue invocado por su nombre público o a través del comando my.
obj variable ?nombreVar ...?
Este método organiza para que cada variable llamada nombreVar se enlace desde el espacio de nombres único del objeto obj al contexto del llamador. Por lo tanto, si se invoca desde dentro de un procedimiento, la variable del espacio de nombres en el objeto se enlaza a la variable local en el procedimiento. Cada argumento nombreVar no debe tener separadores de espacio de nombres. El resultado es la cadena vacía.
obj varname nombreVar
Este método devuelve el nombre globalmente calificado de la variable nombreVar en el espacio de nombres único para el objeto obj.
obj <cloned> nombreObjetoOrigen
Este método es utilizado por el comando oo::object para copiar el estado de un objeto a otro. Es responsable de copiar los procedimientos y variables del espacio de nombres del objeto de origen (nombreObjetoOrigen) al objeto actual. No copia ningún otro tipo de comandos ni rastreadores en las variables; eso puede añadirse si se desea sobrescribiendo este método en una subclase.

EJEMPLOS

Este ejemplo demuestra el uso básico de un objeto.

set obj [oo::object new]
$obj foo             → error "método desconocido foo"
oo::objdefine $obj method foo {} {
    my variable count
    puts "bar[incr count]"
}
$obj foo             → imprime "bar1"
$obj foo             → imprime "bar2"
$obj variable count  → error "método desconocido variable"
$obj destroy
$obj foo             → error "comando desconocido obj"
