NOMBRE

opensnoop.bt - Rastrea llamadas al sistema open(). Utiliza bpftrace/eBPF.

SINOPSIS

opensnoop.bt

DESCRIPCIÓN

opensnoop rastrea la llamada al sistema open(), mostrando qué procesos están intentando abrir qué archivos. Esto puede ser útil para determinar la ubicación de archivos de configuración y registro, o para solucionar problemas de aplicaciones que fallan, especialmente al inicio.

Esto funciona rastreando el punto de rastreo de la llamada al sistema open().

Dado que esto utiliza BPF, solo el usuario root puede usar esta herramienta.

REQUISITOS

CONFIG_BPF y bcc.

EJEMPLOS

Rastrea todas las llamadas al sistema open():
# opensnoop.bt

CAMPOS

PID ID del Proceso

TID
ID del Hilo
COMM
Nombre del proceso
FD
Descriptor de archivo (si tuvo éxito), o -1 (si falló)
ERR
Número de error (ver el errno.h del sistema)
PATH
Ruta de apertura

SOBRECARGA

Esto rastrea el punto de rastreo open() e imprime la salida para cada evento. Dado que se espera que la tasa de esto sea generalmente baja (< 1000/s), también se espera que la sobrecarga sea insignificante. Si tiene una aplicación que realiza una gran cantidad de llamadas a open(), pruebe y comprenda la sobrecarga antes de usarla.

FUENTE

Esto es de bpftrace.

https://github.com/bpftrace/bpftrace

También busque en la distribución de bpftrace un archivo _examples.txt complementario que contenga ejemplos de uso, salida y comentarios para esta herramienta.

Esta es una versión de bpftrace de la herramienta bcc del mismo nombre. La herramienta bcc puede ofrecer más opciones y personalizaciones.

https://github.com/iovisor/bcc
