oci.conf(5) Archivo de configuración de Slurm oci.conf(5)

NOMBRE

oci.conf - Archivo de configuración de Slurm para contenedores.

DESCRIPCIÓN

Slurm soporta la llamada a tiempos de ejecución compatibles con OCI. oci.conf es un archivo ASCII que define los parámetros utilizados por la interfaz de tiempo de ejecución OCI. El archivo siempre estará ubicado en el mismo directorio que slurm.conf.

Los nombres de los parámetros no distinguen entre mayúsculas y minúsculas. Cualquier texto que siga a un "#" en el archivo de configuración se trata como un comentario hasta el final de esa línea. Los cambios en el archivo de configuración surten efecto al reiniciar los demonios de Slurm.

PARÁMETROS

Los siguientes parámetros de oci.conf se definen para controlar el comportamiento del argumento --container de salloc, srun y sbatch.

ContainerPath
Especifica un patrón de ruta de sustitución para colocar el directorio temporal de spool por paso. Si esta opción está configurada, la ruta resultante del paquete OCI por tarea se creará como un subdirectorio de esta ruta. Consulte la sección Patrón OCI para obtener detalles sobre la sustitución de patrones.

Por defecto, se crea un subdirectorio generado de forma única para cada paso bajo SlurmdSpoolDir.

CreateEnvFile=(null|newline|disabled)
Crea un archivo de entorno para el contenedor. El archivo tendrá una variable de entorno por línea si el valor es "newline". El archivo tendrá cada variable de entorno terminada por un NUL (también conocido como '\0') si el valor es "null". Si el valor es "disabled", el archivo de entorno no se creará.

El valor "true" se trata como "null" por compatibilidad retroactiva. El valor "false" se trata como "disabled" por compatibilidad retroactiva.

Nota: Cuando CreateEnvFile=newline, cualquier variable de entorno con una nueva línea se omitirá antes de escribirla en el archivo de entorno.

El valor predeterminado es "disabled".

DebugFlags
Anula las banderas de depuración durante las operaciones del contenedor. Consulte debugflags en slurm.conf.

Predeterminado: (desactivado)

DisableCleanup
Desactiva la eliminación de los archivos generados que se entregan al tiempo de ejecución OCI.

Predeterminado: false

DisableHooks
Lista separada por comas de tipos de ganchos (hooks) a deshabilitar.

Predeterminado: permite todos los ganchos.

EnvExclude
Expresión regular extendida para filtrar el entorno. Esto permite excluir variables para evitar variables de entorno no deseadas dentro de los contenedores.

Ejemplo: EnvExclude="^(SLURM_CONF|SLURM_CONF_SERVER)="

Por defecto, no se excluye ninguna variable de entorno.

MountSpoolDir
Patrón de ruta de sustitución para montar ContainerPath dentro del contenedor. Consulte la sección Patrón OCI para obtener detalles sobre el reemplazo de patrones.

Predeterminado: consulte ContainerPath

RunTimeEnvExclude
Expresión regular extendida para filtrar el entorno antes de llamar a cualquier comando RunTime*. Esto permite excluir variables para evitar herencias no deseadas dentro de los tiempos de ejecución OCI.

Ejemplo: RunTimeEnvExclude="^(SLURM_CONF|SLURM_CONF_SERVER)="

Por defecto, no se excluye ninguna variable de entorno.

FileDebug
Anula el nivel de registro de archivos predeterminado durante las operaciones del contenedor. Consulte SlurmdDebug en slurm.conf.

Predeterminado: (desactivado)

IgnoreFileConfigJson=(true|false)
Ignora la existencia de config.json en la ruta del paquete OCI y deshabilita la carga de config.json si está presente.

El valor predeterminado es false.

RunTimeCreate
Patrón para la operación de creación del tiempo de ejecución OCI. Consulte la sección Patrón OCI para obtener detalles sobre la sustitución de patrones.

Predeterminado: (desactivado)

RunTimeDelete
Patrón para la operación de eliminación del tiempo de ejecución OCI. Consulte la sección Patrón OCI para obtener detalles sobre la sustitución de patrones.

Predeterminado: (desactivado)

RunTimeKill
Patrón para la operación de eliminación (kill) del tiempo de ejecución OCI. Consulte la sección Patrón OCI para obtener detalles sobre la sustitución de patrones.

Predeterminado: (desactivado)

RunTimeQuery
Patrón para la operación de consulta (también conocida como estado) del tiempo de ejecución OCI. Consulte la sección Patrón OCI para obtener detalles sobre la sustitución de patrones.

Predeterminado: (desactivado)

RunTimeRun
Patrón para la operación de ejecución del tiempo de ejecución OCI. Esto no se proporciona en la especificación del tiempo de ejecución OCI (<=v1.0) pero lo proporcionan múltiples tiempos de ejecución OCI para simplificar la ejecución de contenedores. Si se proporciona, se usará en lugar de las operaciones de creación e inicio. Evita la necesidad de sondear el estado del contenedor, lo que resulta en menos sobrecarga de monitorización. Consulte la sección Patrón OCI para obtener detalles sobre la sustitución de patrones.

Predeterminado: (desactivado)

RunTimeStart
Patrón para la operación de inicio del tiempo de ejecución OCI. Consulte la sección Patrón OCI para obtener detalles sobre la sustitución de patrones.

Predeterminado: (desactivado)

SrunPath
Ruta absoluta al ejecutable srun.

Predeterminado: (buscar en PATH)

SrunArgs
Argumentos adicionales para pasar a srun. Agregue una entrada SrunArgs por argumento.

Predeterminado: (desactivado)

StdIODebug
Anula el nivel de registro de STDIO predeterminado durante las operaciones del contenedor. Consulte SlurmdDebug en slurm.conf.

Predeterminado: (desactivado)

SyslogDebug
Anula el nivel de registro de syslog predeterminado durante las operaciones del contenedor. Consulte SlurmdSyslogDebug en slurm.conf.

Predeterminado: (desactivado)

Patrón OCI

Todos los patrones OCI reemplazarán los siguientes caracteres:

Reemplazos:

%%
Reemplazar como "%".
%@
Reemplazar como el comando y los argumentos. Cada argumento estará entre comillas simples y escapado.
%b
Reemplazar como la ruta del Bundle OCI.
%e
Reemplazar como la ruta al archivo que contiene el entorno si CreateEnvFile=true.
%j
Reemplazar como el ID numérico del trabajo.
%m
Reemplazar con la ruta del directorio de spool por paso del contenedor según el patrón de ContainerPath. Si ContainerPath no está establecido, se reemplaza con un subdirectorio generado de forma única bajo SlurmdSpoolDir como se define en slurm.conf(5), o por defecto es ""/var/spool/slurmd".
%n
Reemplazar como el nombre del nodo.
%p
Reemplazar como el PID del primer proceso iniciado. Solo para uso en RunTimeKill o RunTimeDelete.
%r
Reemplazar como la ruta original del rootfs.
%s
Reemplazar como el ID numérico del paso.
%t
Reemplazar como el ID numérico de la tarea del paso.
%u
Reemplazar como el nombre de usuario.
%U
Reemplazar como el ID numérico del usuario.
