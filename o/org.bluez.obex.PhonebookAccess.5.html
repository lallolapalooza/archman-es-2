void Select(string location, string phonebook)

Selecciona el objeto de la agenda para otras operaciones.

Debe llamarse antes que todas las demás operaciones.

Almacenar en memoria interna.
"sim{#}"
Almacenar en el número SIM.

Valores posibles de phonebook:

"pb"
Almacenar como contacto.
"ich"
Almacenar como llamada entrante.
"och"
Almacenar como llamada saliente.
"mch"
Almacenar como llamada perdida.
"cch"
Almacenar como una combinación de llamadas entrantes, salientes y perdidas.

Almacenar como entrada de marcación rápida (solo para "internal")

"fav":

Almacenar como entrada de favoritos (solo para "internal")

object, dict PullAll(string targetfile, dict filters)

Devuelve el objeto de agenda completo del servidor PSE en texto plano con formato vcard y lo almacena en un archivo local.

Si se proporciona un archivo de destino vacío, se generará automáticamente un nombre para el archivo temporal.

La ruta devuelta representa la transferencia recién creada, que debe usarse para averiguar si el contenido se ha transferido correctamente o si la operación falla.

Las propiedades de esta transferencia también se devuelven junto con la ruta del objeto, para evitar una llamada a GetProperties, véase org.bluez.obex.Transfer(5) para la lista posible de propiedades.

Filtros posibles:

string Format
Formato de vcard de los elementos.

Valores posibles:

"vcard21" (predeterminado)
"vcard30"
string Order
Orden de los elementos.

Valores posibles:

""
"indexed"
"alphanumeric"
"phonetic"
uint16 Offset (predeterminado 0)
Desplazamiento del primer elemento.
uint16 MaxCount (predeterminado 65535)
Número máximo de elementos.
array{string} Fields (predeterminado todos los campos)
Campos de vcard de los elementos.

Ver ListFilterFields() para los valores posibles.

array{string} FilterAll
Filtra elementos por campos usando lógica AND, no se puede usar junto con FilterAny.

Ver ListFilterFields() para los valores posibles.

array{string} FilterAny
Filtra elementos por campos usando lógica OR, no se puede usar junto con FilterAll.

Ver ListFilterFields() para los valores posibles.

bool ResetNewMissedCalls
Restablece las nuevas llamadas perdidas, solo debe usarse para las carpetas mch y cch.

Errores posibles:

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Forbidden

Name

org.bluez.obex.PhonebookAccess - Bluetooth OBEX Phonebook Access Server

Interface

org.bluez.obex.PhonebookAccess

This interface is intended to be used by the OBEX Phonebook Access Profile (PBAP) server implementation. It provides access to the phone's contacts.

All methods that return string values will return empty strings if the requested information is not available.

Methods that return vCard data return them in vCard 2.1 format.

The Phonebook Access Server provides access to the phone's contacts. It supports multiple phonebook objects.

The main phonebook is always available under the name "telecom/pb.vcf". Other phonebooks (e.g. SIM phonebook) might be available under names like "SIM1/telecom/pb.vcf".

array{string vcard, string name} Search(string field, string value, dict filters)

Searches for entries matching the given condition and return an array of vcard-listing data where every entry consists of a pair of strings containing the vcard handle and the contact name.

Possible field values:

"name" (default)
Search by name.
"number"
Search by number.
"sound"
Search by sound.

value: the string value to search for

Possible filters:

string Order
Contact order.

Possible values:

""
"indexed"
"alphanumeric"
"phonetic"
uint16 Offset
Start offset.
uint16 MaxCount
Maximum number of contacts.
