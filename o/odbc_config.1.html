NOMBRE

odbc_config - Genera información del compilador destinada a ser utilizada al desarrollar un cliente unixODBC

SINOPSIS

odbc_config [--prefix] [--exec-prefix] [--include-prefix] [--lib-prefix] [--bin-prefix] [--version] [--libs] [--static-libs] [--libtool-libs] [--cflags] [--odbcversion] [--odbcini] [--odbcinstini] [--header] [--ulen]

DESCRIPCIÓN

odbc_config proporciona información sobre cómo se compiló unixODBC para su sistema y arquitectura. La información generada es útil para construir clientes de unixODBC y programas similares.

OPCIONES

--prefix
Prefijo para archivos independientes de la arquitectura.
--exec-prefix
Prefijo para archivos dependientes de la arquitectura.
--include-prefix
Directorio que contiene los archivos de cabecera C para unixODBC.
--lib-prefix
Directorio que contiene las bibliotecas compartidas de unixODBC.
--bin-prefix
Directorio que contiene las utilidades de unixODBC.
--version
Versión actual de unixODBC.
--libs
Indicadores del compilador para enlazar bibliotecas dinámicas.
--static-libs
Nombre de archivo absoluto de la biblioteca estática de unixODBC (libodbc.a).
--libtool-libs
Nombre de archivo absoluto de la biblioteca libtool de unixODBC (libodbc.la).
--cflags
Muestra los indicadores del compilador para encontrar archivos de cabecera, así como indicadores y definiciones críticas del compilador utilizadas al compilar la biblioteca libodbc.
--odbcversion
Versión de la especificación ODBC utilizada por unixODBC.
--odbcini
Nombre de archivo absoluto del archivo de configuración DSN a nivel de sistema odbc.ini.
--odbcinstini
Nombre de archivo absoluto del archivo de configuración de controladores de unixODBC odbcinst.ini.
--header
Definiciones de constantes del preprocesador C utilizadas por unixODBC. La salida generada se puede canalizar a un archivo de cabecera C.
--ulen
Indicador del compilador que define SIZEOF_SQLULEN.
