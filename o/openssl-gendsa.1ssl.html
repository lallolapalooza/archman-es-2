Paquete: openssl

NOMBRE

openssl-gendsa - generar una clave privada DSA a partir de un conjunto de parámetros

SINOPSIS

openssl gendsa [-help] [-out nombre_archivo] [-passout arg] [-aes128] [-aes192] [-aes256] [-aria128] [-aria192] [-aria256] [-camellia128] [-camellia192] [-camellia256] [-des] [-des3] [-idea] [-verbose] [-quiet] [-rand archivos] [-writerand archivo] [-engine id] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq] [archivo_parametros]

DESCRIPCIÓN

Este comando genera una clave privada DSA a partir de un archivo de parámetros DSA (que normalmente será generado por el comando openssl-dsaparam(1)).

OPCIONES

-help
Imprime un mensaje de uso.
-out nombre_archivo
Exporta la clave al archivo especificado. Si este argumento no se especifica, se utiliza la salida estándar.
-passout arg
La frase de contraseña utilizada para el archivo de salida. Consulte openssl-passphrase-options(1).
-aes128, -aes192, -aes256, -aria128, -aria192, -aria256, -camellia128, -camellia192, -camellia256, -des, -des3, -idea
Estas opciones cifran la clave privada con el cifrador especificado antes de exportarla. Se solicitará una frase de contraseña. Si no se especifica ninguna de estas opciones, no se utiliza cifrado.

Tenga en cuenta que todas las opciones deben proporcionarse antes del argumento archivo_parametros.

-verbose
Imprime detalles adicionales sobre las operaciones que se están realizando.
-quiet
Imprime menos detalles sobre las operaciones que se están realizando, lo que puede ser útil durante scripts por lotes y tuberías.
-rand archivos, -writerand archivo
Consulte "Opciones de estado aleatorio" en openssl(1) para obtener más detalles.
-engine id
Consulte "Opciones de motor" en openssl(1). Esta opción está obsoleta.
archivo_parametros
El archivo de parámetros DSA a utilizar. Los parámetros de este archivo determinan el tamaño de la clave privada. Los parámetros DSA se pueden generar y examinar utilizando el comando openssl-dsaparam(1).
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Consulte "Opciones de proveedor" en openssl(1), provider(7) y property(7).

NOTAS

La generación de claves DSA es poco más que la generación de números aleatorios, por lo que es mucho más rápida que la generación de claves RSA, por ejemplo.

VER TAMBIÉN

openssl(1), openssl-genpkey(1), openssl-dsaparam(1), openssl-dsa(1), openssl-genrsa(1), openssl-rsa(1)

HISTORIA

La opción -engine fue obsoleta en OpenSSL 3.0.
