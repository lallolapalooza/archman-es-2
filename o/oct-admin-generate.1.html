NOMBRE

oct-admin-generate - Generar una clave en la tarjeta

SINOPSIS

oct admin generate <-o|--output> [--no-dec] [--no-aut] <-u|--userid> [-p|--user-pin] [-h|--help] [algoritmo]

DESCRIPCIÓN

Generar una clave en la tarjeta.

Siempre se crea una clave de firma, las claves de descifrado y autenticación son opcionales.

OPCIONES

-o, --output=salida
Archivo de salida
--no-dec
No crear una clave en la ranura DEC
--no-aut
No crear una clave en la ranura AUT
-u, --userid=ID de usuario
ID de usuario a agregar a la representación del certificado exportado
-p, --user-pin=Archivo PIN de usuario
Opcionalmente, obtener el PIN de usuario de un archivo
-h, --help
Imprimir ayuda (ver un resumen con '-h')
[algoritmo]
Elegir el algoritmo para el material clave a generar en la tarjeta.


Si no se proporciona el parámetro, se utiliza el algoritmo actualmente configurado en la tarjeta.


Las tarjetas específicas admiten un conjunto de algoritmos que pueden diferir entre modelos. En tarjetas modernas,
usa 'oct info' para ver la lista de algoritmos compatibles.

[valores posibles: rsa2048, rsa3072, rsa4096, nistp256, nistp384, nistp521, curve25519]
