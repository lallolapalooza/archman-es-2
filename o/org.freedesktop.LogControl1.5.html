NOMBRE

org.freedesktop.LogControl1 - Interfaz D-Bus para consultar y establecer la configuración de registro

INTRODUCCIÓN

org.freedesktop.LogControl1 es una interfaz genérica que está destinada a ser utilizada por cualquier demonio que permita establecer el nivel y el destino del registro a través de D-Bus. Es implementada por varios demonios que forman parte de la suite de systemd(1).

Se asume que estas configuraciones son globales para todo el programa, por lo que se utiliza una ruta de objeto fija. La interfaz siempre debería estar disponible en la ruta /org/freedesktop/LogControl1.

DESCRIPCIÓN

La siguiente interfaz se expone:

nodo /org/freedesktop/LogControl1 {
  interfaz org.freedesktop.LogControl1 {
    propiedades:
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      @org.freedesktop.systemd1.Privileged("true")
      lecturaescritura s NivelRegistro = '...';
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      @org.freedesktop.systemd1.Privileged("true")
      lecturaescritura s DestinoRegistro = '...';
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      lectura s IdentificadorSyslog = '...';
  };
  interfaz org.freedesktop.DBus.Peer { ... };
  interfaz org.freedesktop.DBus.Introspectable { ... };
  interfaz org.freedesktop.DBus.Properties { ... };
};

Propiedades

NivelRegistro describe el nivel de registro estilo syslog(3), y debería ser uno de "emerg", "alert", "crit", "err", "warning", "notice", "info", "debug", en orden de verbosidad creciente.

DestinoRegistro describe el destino del registro (mecanismo). Debería ser uno de "console" (registrar en la consola o salida estándar), "kmsg" (registrar en el búfer del kernel), "journal" (registrar nativamente en el journal, ver systemd-journald.service(8)), "syslog" (registrar usando la llamada syslog(3)).


Acceso de Escritura

Se supone que las propiedades NivelRegistro y DestinoRegistro son escribibles. Se debe tener cuidado para asegurar que solo clientes con privilegios apropiados puedan modificarlas.

IdentificadorSyslog es una propiedad de solo lectura que muestra el "identificador syslog". Es una cadena corta que identifica el programa que es la fuente de los mensajes de registro que se pasan a la llamada syslog(3).

HERRAMIENTAS

La opción -p/--priority= de journalctl puede usarse para filtrar mensajes de registro por nivel de registro, la opción -t/--identifier= puede usarse por el identificador syslog, y filtros como "_TRANSPORT=syslog", "_TRANSPORT=journal", y "_TRANSPORT=kernel" pueden usarse para filtrar mensajes por el mecanismo a través del cual llegaron a systemd-journald.

Los verbos systemctl log-level y systemctl log-target pueden usarse para consultar y establecer las propiedades NivelRegistro y DestinoRegistro del gestor de servicios. systemctl service-log-level y systemctl service-log-target pueden usarse de manera similar para servicios individuales. (Los servicios deben tener la propiedad BusName= establecida y deben implementar la interfaz descrita aquí. Ver systemd.service(5) para detalles sobre BusName=.)

EJEMPLO

Ejemplo 1. Crear un simple oyente en el bus que implemente LogControl1

/* SPDX-License-Identifier: MIT-0 */
/* Implementa la interfaz LogControl1 según la especificación:
 * https://www.freedesktop.org/software/systemd/man/org.freedesktop.LogControl1.html
 *
 * Compilar con 'cc logcontrol-example.c $(pkg-config --libs --cflags libsystemd)'
 *
 * Para obtener y establecer propiedades a través de busctl:
 *
 * $ busctl --user get-property org.freedesktop.Example \
 *                              /org/freedesktop/LogControl1 \
 *                              org.freedesktop.LogControl1 \
 *                              SyslogIdentifier
 *   s "example"
 * $ busctl --user get-property org.freedesktop.Example \
 *                              /org/freedesktop/LogControl1 \
 *                              org.freedesktop.LogControl1 \
 *                              LogTarget
 *   s "journal"
 * $ busctl --user get-property org.freedesktop.Example \
 *                              /org/freedesktop/LogControl1 \
 *                              org.freedesktop.LogControl1 \
 *                              LogLevel
 *   s "info"
 * $ busctl --user set-property org.freedesktop.Example \
 *                              /org/freedesktop/LogControl1 \
 *                              org.freedesktop.LogControl1 \
 *                              LogLevel \
 *                              "s" debug
 * $ busctl --user get-property org.freedesktop.Example \
 *                              /org/freedesktop/LogControl1 \
 *                              org.freedesktop.LogControl1 \
 *                              LogLevel
 *   s "debug"
 */
#include <errno.h>
#include <stdlib.h>
#include <stdio.h>
#include <syslog.h>
#include <systemd/sd-bus.h>
#include <systemd/sd-journal.h>
#define _cleanup_(f) __attribute__((cleanup(f)))
static int log_error(int log_level, int error, const char *str) {
  sd_journal_print(log_level, "%s falló: %s", str, strerror(-error));
  return error;
}
typedef enum LogTarget {
  LOG_TARGET_JOURNAL,
  LOG_TARGET_KMSG,
  LOG_TARGET_SYSLOG,
  LOG_TARGET_CONSOLE,
  _LOG_TARGET_MAX,
} LogTarget;
static const char* const log_target_table[_LOG_TARGET_MAX] = {
  [LOG_TARGET_JOURNAL] = "journal",
  [LOG_TARGET_KMSG]    = "kmsg",
  [LOG_TARGET_SYSLOG]  = "syslog",
  [LOG_TARGET_CONSOLE] = "console",
};
static const char* const log_level_table[LOG_DEBUG + 1] = {
  [LOG_EMERG]   = "emerg",
  [LOG_ALERT]   = "alert",
  [LOG_CRIT]    = "crit",
  [LOG_ERR]     = "err",
  [LOG_WARNING] = "warning",
  [LOG_NOTICE]  = "notice",
  [LOG_INFO]    = "info",
  [LOG_DEBUG]   = "debug",
};
typedef struct object {
  const char *syslog_identifier;
  LogTarget log_target;
  int log_level;
} object;
static int property_get(
                sd_bus *bus,
                const char *path,
                const char *interface,
                const char *property,
                sd_bus_message *reply,
                void *userdata,
                sd_bus_error *error) {
  object *o = userdata;
  if (strcmp(property, "LogLevel") == 0)
    return sd_bus_message_append(reply, "s", log_level_table[o->log_level]);
  if (strcmp(property, "LogTarget") == 0)
    return sd_bus_message_append(reply, "s", log_target_table[o->log_target]);
  if (strcmp(property, "SyslogIdentifier") == 0)
    return sd_bus_message_append(reply, "s", o->syslog_identifier);
  return sd_bus_error_setf(error,
                           SD_BUS_ERROR_UNKNOWN_PROPERTY,
                           "Propiedad desconocida '%s'",
                           property);
}
static int property_set(
                sd_bus *bus,
                const char *path,
                const char *interface,
                const char *property,
                sd_bus_message *message,
                void *userdata,
                sd_bus_error *error) {
  object *o = userdata;
  const char *value;
  int r;
  r = sd_bus_message_read(message, "s", &value);
  if (r < 0)
    return r;
  if (strcmp(property, "LogLevel") == 0) {
    int i;
    for (i = 0; i < LOG_DEBUG + 1; i++)
      if (strcmp(value, log_level_table[i]) == 0) {
        o->log_level = i;
        setlogmask(LOG_UPTO(i));
        return 0;
      }
    return sd_bus_error_setf(error,
                             SD_BUS_ERROR_INVALID_ARGS,
                             "Valor inválido para LogLevel: '%s'",
                             value);
  }
  if (strcmp(property, "LogTarget") == 0) {
    LogTarget i;
    for (i = 0; i < _LOG_TARGET_MAX; i++)
      if (strcmp(value, log_target_table[i]) == 0) {
        o->log_target = i;
        return 0;
      }
    return sd_bus_error_setf(error,
                             SD_BUS_ERROR_INVALID_ARGS,
                             "Valor inválido para LogTarget: '%s'",
                             value);
  }
  return sd_bus_error_setf(error,
                           SD_BUS_ERROR_UNKNOWN_PROPERTY,
                           "Propiedad desconocida '%s'",
                           property);
}
static const sd_bus_vtable logcontrol1_vtable[] = {
  SD_BUS_VTABLE_START(0),
  SD_BUS_METHOD("Set", "ss", NULL, NULL, 0),
  SD_BUS_METHOD("Get", "s", "s", NULL, 0),
  SD_BUS_PROPERTY_ACCESS("LogLevel", property_get, property_set, 0),
  SD_BUS_PROPERTY_ACCESS("LogTarget", property_get, property_set, 0),
  SD_BUS_PROPERTY_ACCESS("SyslogIdentifier", property_get, NULL, 0),
  SD_BUS_VTABLE_END
};
int main(int argc, char **argv) {
  object o = {
    .syslog_identifier = "example",
    .log_target = LOG_TARGET_JOURNAL,
    .log_level = LOG_INFO,
  };
  sd_bus_slot *slot;
  sd_bus *bus;
  int r;
  r = sd_bus_open_user(&bus);
  if (r < 0) {
    fprintf(stderr, "Fallo al conectarse al bus de usuario: %s\n", strerror(-r));
    goto finish;
  }
  r = sd_bus_add_object_manager(bus, "/", NULL, NULL);
  if (r < 0) {
    log_error(LOG_ERR, r, "No se pudo añadir el gestor de objetos");
    goto finish;
  }
  r = sd_bus_add_object_vtable(bus,
                               "/org/freedesktop/LogControl1",
                               logcontrol1_vtable,
                               &o,
                               NULL,
                               &slot);
  if (r < 0) {
    log_error(LOG_ERR, r, "No se pudo añadir la vtable del objeto");
    goto finish;
  }
  r = sd_bus_request_name(bus, "org.freedesktop.Example", 0);
  if (r < 0) {
    log_error(LOG_ERR, r, "Fallo al solicitar el nombre de la bus");
    goto finish;
  }
  for (;;) {
    r = sd_bus_process(bus, NULL);
    if (r < 0) {
      fprintf(stderr, "Fallo al procesar el bus: %s\n", strerror(-r));
      goto finish;
    }
    if (r && sd_bus_is_paused(bus))
      continue;
    r = sd_bus_wait(bus, (uint64_t)-1);
    if (r < 0) {
      fprintf(stderr, "Fallo al esperar en el bus: %s\n", strerror(-r));
      goto finish;
    }
  }
finish:
  sd_bus_unref(bus);
  return r < 0 ? EXIT_FAILURE : EXIT_SUCCESS;
}

org.freedesktop.LogControl1.5

NAME

org.freedesktop.LogControl1 - D-Bus interface for controlling logging

INTRODUCTION

The LogControl1 interface is intended to provide a standard way for services to control their logging behavior. This is useful for managing the verbosity and destination of logs, especially in system services.

DESCRIPTION

This interface defines properties that control the logging behavior of a service. Specifically, it allows setting the log level and the log target.

The following properties are defined:

LogLevel
A string representing the desired log level. Possible values include "debug", "info", "notice", "warning", "err", "crit", "alert", "emerg". This property is writable.
LogTarget
A string representing the desired log target. Possible values include "journal" (for systemd journal), "syslog" (for traditional syslog), "console" (for standard output/error). This property is writable.
SyslogIdentifier
A string representing the identifier to be used when logging to syslog. This property is read-only and typically set at service startup.

TOOLS

Several tools can be used to interact with services implementing this interface:

journalctl
Can be used to view logs from the systemd journal. It can filter logs based on various criteria, including the service identifier.
systemctl
Can be used to manage system services, including starting, stopping, and restarting them. It can also be used to query the status of services.
gdbus
A command-line tool for interacting with D-Bus services. It can be used to call methods and access properties of D-Bus objects.

EXAMPLE

The following C code demonstrates how to implement the LogControl1 interface using sd_bus_add_object(3):

#include <errno.h>
#include <stdio.h>
#include <syslog.h>
#include <time.h>
#include <unistd.h>
#include <systemd/sd-bus.h>
#include <systemd/sd-journal.h>
#define LOG_ERR_STR "err"
#define LOG_INFO_STR "info"
#define LOG_DEBUG_STR "debug"
#define LOG_TARGET_JOURNAL_STR "journal"
#define LOG_TARGET_SYSLOG_STR "syslog"
#define LOG_TARGET_CONSOLE_STR "console"
typedef struct {
  int log_level;
  int log_target;
  const char *syslog_identifier;
} object;
static inline int log_error(int level, int err, const char *func) {
  const char *msg;
  switch (err) {
  case -EPERM:
    msg = "Operation not permitted";
    break;
  case -ENOENT:
    msg = "No such file or directory";
    break;
  case -EADDRINUSE:
    msg = "Address in use";
    break;
  default:
    msg = strerror(err);
    break;
  }
  sd_journal_print(level, "%s() failed: %s", func, msg);
  return err;
}
static int property_get(sd_bus_message *m, void *userdata,
                        sd_bus_error *ret_error) {
  object *o = userdata;
  const char *key = sd_bus_message_get_property_name(m);
  if (!key)
    return sd_bus_error_setf(ret_error, "org.freedesktop.DBus.Error.InvalidArgs",
                             "Missing property name");
  if (strcmp(key, "LogLevel") == 0)
    return sd_bus_message_append(m, "s",
                                 o->log_level == LOG_DEBUG
                                     ? LOG_DEBUG_STR
                                     : (o->log_level == LOG_INFO
                                            ? LOG_INFO_STR
                                            : LOG_ERR_STR));
  if (strcmp(key, "LogTarget") == 0)
    return sd_bus_message_append(
        m, "s",
        o->log_target == LOG_TARGET_JOURNAL
            ? LOG_TARGET_JOURNAL_STR
            : (o->log_target == LOG_TARGET_SYSLOG ? LOG_TARGET_SYSLOG_STR
                                                  : LOG_TARGET_CONSOLE_STR));
  if (strcmp(key, "SyslogIdentifier") == 0)
    return sd_bus_message_append(m, "s", o->syslog_identifier);
  return sd_bus_error_setf(ret_error, "org.freedesktop.DBus.Error.InvalidArgs",
                           "Unknown property %s", key);
}
static int property_set(sd_bus_message *m, void *userdata,
                        sd_bus_error *ret_error) {
  object *o = userdata;
  const char *key = sd_bus_message_get_property_name(m);
  const char *value;
  int r;
  if (!key)
    return sd_bus_error_setf(ret_error, "org.freedesktop.DBus.Error.InvalidArgs",
                             "Missing property name");
  r = sd_bus_message_read(m, "s", &value);
  if (r < 0)
    return log_error(o->log_level, r, "sd_bus_message_read()");
  if (strcmp(key, "LogLevel") == 0) {
    if (strcmp(value, LOG_DEBUG_STR) == 0)
      o->log_level = LOG_DEBUG;
    else if (strcmp(value, LOG_INFO_STR) == 0)
      o->log_level = LOG_INFO;
    else if (strcmp(value, LOG_ERR_STR) == 0)
      o->log_level = LOG_ERR;
    else
      return sd_bus_error_setf(ret_error,
                               "org.freedesktop.DBus.Error.InvalidArgs",
                               "Invalid log level: %s", value);
    setlogmask(LOG_UPTO(o->log_level));
  } else if (strcmp(key, "LogTarget") == 0) {
    if (strcmp(value, LOG_TARGET_JOURNAL_STR) == 0)
      o->log_target = LOG_TARGET_JOURNAL;
    else if (strcmp(value, LOG_TARGET_SYSLOG_STR) == 0)
      o->log_target = LOG_TARGET_SYSLOG;
    else if (strcmp(value, LOG_TARGET_CONSOLE_STR) == 0)
      o->log_target = LOG_TARGET_CONSOLE;
    else
      return sd_bus_error_setf(ret_error,
                               "org.freedesktop.DBus.Error.InvalidArgs",
                               "Invalid log target: %s", value);
  } else
    return sd_bus_error_setf(ret_error, "org.freedesktop.DBus.Error.InvalidArgs",
                             "Unknown property %s", key);
  /* If the property is changed, we should notify the bus about it. */
  return sd_bus_emit_property_changed(
      m, NULL, sd_bus_message_get_path(m), sd_bus_message_get_interface(m), key);
}
/* https://www.freedesktop.org/software/systemd/man/sd_bus_add_object.html
 */
static const sd_bus_vtable vtable[] = {
  SD_BUS_VTABLE_START(0),
  SD_BUS_WRITABLE_PROPERTY(
    "LogLevel", "s",
    property_get, property_set,
    0,
    0),
  SD_BUS_WRITABLE_PROPERTY(
    "LogTarget", "s",
    property_get, property_set,
    0,
    0),
  SD_BUS_PROPERTY(
    "SyslogIdentifier", "s",
    property_get,
    0,
    SD_BUS_VTABLE_PROPERTY_CONST),
  SD_BUS_VTABLE_END
};
int main(int argc, char **argv) {
  /* The bus should be relinquished before the program terminates. The cleanup
   * attribute allows us to do it nicely and cleanly whenever we exit the
   * block.
   */
  _cleanup_(sd_bus_flush_close_unrefp) sd_bus *bus = NULL;
  object o = {
    .log_level = LOG_INFO,
    .log_target = LOG_TARGET_JOURNAL,
    .syslog_identifier = "example",
  };
  int r;
  /* https://man7.org/linux/man-pages/man3/setlogmask.3.html
   * Programs using syslog() instead of sd_journal can use this API to cut logs
   * emission at the source.
   */
  setlogmask(LOG_UPTO(o.log_level));
  /* Acquire a connection to the bus, letting the library work out the details.
   * https://www.freedesktop.org/software/systemd/man/sd_bus_default.html
   */
  r = sd_bus_default(&bus);
  if (r < 0)
    return log_error(o.log_level, r, "sd_bus_default()");
  /* Publish an interface on the bus, specifying our well-known object access
   * path and public interface name.
   * https://www.freedesktop.org/software/systemd/man/sd_bus_add_object.html
   * https://dbus.freedesktop.org/doc/dbus-tutorial.html
   */
  r = sd_bus_add_object_vtable(bus, NULL,
                               "/org/freedesktop/LogControl1",
                               "org.freedesktop.LogControl1",
                               vtable,
                               &o);
  if (r < 0)
    return log_error(o.log_level, r, "sd_bus_add_object_vtable()");
  /* By default, the service is assigned an ephemeral name. Also add a fixed
   * one, so that clients know whom to call.
   * https://www.freedesktop.org/software/systemd/man/sd_bus_request_name.html
   */
  r = sd_bus_request_name(bus, "org.freedesktop.Example", 0);
  if (r < 0)
    return log_error(o.log_level, r, "sd_bus_request_name()");
  for (;;) {
    /* https://www.freedesktop.org/software/systemd/man/sd_bus_wait.html
     */
    r = sd_bus_wait(bus, UINT64_MAX);
    if (r < 0)
      return log_error(o.log_level, r, "sd_bus_wait()");
    /* https://www.freedesktop.org/software/systemd/man/sd_bus_process.html
     */
    r = sd_bus_process(bus, NULL);
    if (r < 0)
      return log_error(o.log_level, r, "sd_bus_process()");
  }
  /* https://www.freedesktop.org/software/systemd/man/sd_bus_release_name.html
   */
  r = sd_bus_release_name(bus, "org.freedesktop.Example");
  if (r < 0)
    return log_error(o.log_level, r, "sd_bus_release_name()");
  return 0;
}

This creates a simple server on the bus. It implements the LogControl1 interface by providing the required properties and allowing to set the writable ones. It logs at the configured log level using sd_journal_print(3).

Note that when porting this example to other D-Bus libraries it might be necessary to add manual client privilege checks, as they typically do not default to the restrictive defaults of sd-bus, where unprivileged access to properties is controlled via the SD_BUS_VTABLE_UNPRIVILEGED flag that is opt-in rather than opt-out.
