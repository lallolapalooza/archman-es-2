OPENSEARCH-GENQUERY(1) Documentación de Perl aportada por el usuario OPENSEARCH-GENQUERY(1)

NOMBRE

opensearch-genquery - Muestra la URL de una consulta generada a partir de una Descripción de OpenSearch

SINOPSIS

opensearch-genquery [-q] [-H] [-A] [-R] [-c CONTADOR] [-i INDICE] [-p NUMPAG] [-l IDIOMA] [-O CODIF] [-I CODIF] URL TERMINOS DE BUSQUEDA...

DESCRIPCIÓN

Muestra la URL de una consulta generada a partir de un archivo de Descripción de OpenSearch en URL, con los TERMINOS DE BUSQUEDA y otras opciones especificadas.

Si hay varios tipos de búsqueda disponibles, se pueden usar -H, -A y -R para especificar cuál se desea. Por ejemplo, -A -R se puede usar para solicitar una respuesta Atom, o en caso de no encontrarla, recurrir a RSS. Por defecto, se utiliza la primera URL encontrada en el archivo de descripción.

No todos los sitios web implementan todos (o ninguno) de los parámetros opcionales de OpenSearch. Al usarse con esos sitios, las opciones correspondientes se ignorarán silenciosamente.

OPCIONES

-q
No mostrar salida en caso de errores. En este caso, consultar el código de salida para determinar los errores (Ver "DIAGNÓSTICO").
-H
Solicitar respuesta HTML.
-A
Solicitar respuesta Atom.
-R
Solicitar respuesta RSS.

-H, -A y -R se pueden combinar para expresar la prioridad del tipo de respuesta y especificar tipos de respaldo.

-c CONTADOR, --count=CONTADOR
Solicitar CONTADOR resultados.

Parámetro OpenSearch: count.

-i INDICE, --startindex=INDICE
Solicitar que los resultados comiencen en el índice NUM.

Parámetro OpenSearch: startIndex.

-p NUMPAG, --startpage=NUMPAG
Solicitar la página de resultados NUMPAG.

Parámetro OpenSearch: pageIndex.

-l IDIOMA, --language=IDIOMA
Solicitar resultados en IDIOMA. IDIOMA debe ser un código de país ISO de 2 letras (ej. es o en).

Parámetro OpenSearch: language.

-O CODIF, --outputencoding=CODIF
Solicitar resultados codificados en CODIF (por defecto: UTF-8).

Parámetro OpenSearch: outputEncoding.

-I CODIF, --inputencoding=CODIF
Especificar que los términos de búsqueda están codificados en CODIF (por defecto: UTF-8).

Parámetro OpenSearch: inputEncoding.

-h, --help
Mostrar un breve mensaje de ayuda.
--
Fin de las opciones.

DIAGNÓSTICO

El código de salida se puede consultar para determinar los errores, de la siguiente manera:

0 - Éxito.
1 - Error al obtener la URL de Descripción de OpenSearch.
2 - Error al analizar la Descripción de OpenSearch.
3 - No se encontró un tipo de búsqueda coincidente.
4 - No se puede encontrar el módulo Perl WWW::OpenSearch.
5 - Error no manejado del módulo WWW::OpenSearch.

DEPENDENCIAS

Requiere el módulo WWW::OpenSearch (paquete Debian libwww-opensearch-perl).

ERRORES

Solo admite consultas GET.

Por favor, informa de cualquier error encontrado a ianb@erislabs.net

VER TAMBIÉN
