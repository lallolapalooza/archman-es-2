NOMBRE

opendkim-genzone - Herramienta de generación de archivos de zona de clave pública DKIM

SINOPSIS

opendkim-genzone [-C dirección] [-d dominio] [-D] [-E segs] [-F] [-N ns[,...]] [-o archivo] [-r segs] [-R segs] [-s] [-S] [-t segs] [-T segs] [-u] [-v] [-x archivo_conf] [conjunto_datos]

DESCRIPCIÓN

opendkim-genzone genera un archivo adecuado para su uso con named(8) para publicar un conjunto de claves públicas.

El parámetro conjunto_datos debe especificar un conjunto de datos tal como se describe en la página del manual de opendkim(8). Actualmente puede hacer referencia a archivos planos, bases de datos Sleepycat, listas separadas por comas, directorios LDAP o bases de datos SQL. El conjunto_datos puede omitirse si se especifica un archivo de configuración (a través de la opción de línea de comandos -x) que haga referencia a un archivo de configuración que establezca un parámetro KeyTable, en cuyo caso se utilizará ese valor.

El contenido de la base de datos debe estar formateado como se describe para el parámetro KeyTable, descrito en la página del manual de opendkim.conf(5).

OPCIONES

-C contacto
Utiliza contacto como la información de contacto que se usará cuando se genere un registro SOA (ver -S a continuación). Si no se especifica, se utilizará el ID de usuario del usuario que ejecuta y el nombre de host local; si no se puede determinar el usuario que ejecuta, se utilizará "hostmaster".
-d dominio
Restringe la salida a aquellos registros para los que el campo dominio es el dominio especificado.
-D
Añade un sufijo "._domainkey" a los nombres de selector en el archivo de zona.
-E segs
Al generar un registro SOA (ver -S a continuación), utiliza segs como el tiempo de expiración del registro predeterminado. El valor predeterminado es 604800.
-F
Añade un sufijo "._domainkey" y el nombre de dominio a los nombres de selector en el archivo de zona.
-N lista_ns
Especifica una lista de servidores de nombres separada por comas, que se generarán en registros NS antes de los registros TXT. El primer servidor de nombres de esta lista también se utilizará en el registro SOA (si también se especifica -S) como el nombre de host de autoridad.
-o archivo
Envía la salida al archivo especificado en lugar de a la salida estándar.
-r segs
Al generar un registro SOA (ver -S a continuación), utiliza segs como el tiempo de actualización de la zona. El valor predeterminado es 10800.
-R segs
Al generar un registro SOA (ver -S a continuación), utiliza segs como el tiempo de reintento de la zona. El valor predeterminado es 1800.
-s
Extiende la lógica de "-d" para incluir subdominios.
-S
Solicita la generación de un registro SOA al principio de la salida. El contenido de esta salida se puede controlar utilizando las opciones -E, -r, -R, -T. El número de serie se generará basándose en la hora actual.
-t ttl
Pone un valor TTL (tiempo de vida) de ttl en todos los registros generados. Las unidades están en segundos.
-T segs
Al generar un registro SOA (ver -S a continuación), utiliza segs como el TTL predeterminado del registro. El valor predeterminado es 86400.
-u
Produce salida adecuada para ser utilizada como entrada para nsupdate(8).
-v
Aumenta la verbosidad de la salida de depuración escrita en la salida estándar de error.
-x archivo_conf
Nombra un archivo opendkim.conf(5) para leer parámetros específicos de LDAP cuando se proporciona un conjunto de datos LDAP en la línea de comandos. No es necesario para otros tipos de conjuntos de datos. El valor predeterminado es /etc/opendkim/opendkim.conf.
