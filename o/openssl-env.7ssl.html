NOMBRE

openssl-env - Variables de entorno de OpenSSL

DESCRIPCIÓN

Las bibliotecas y comandos de OpenSSL utilizan variables de entorno para anular los valores predeterminados compilados para diversos aspectos de su comportamiento. Para evitar riesgos de seguridad, el entorno no se consulta para variables de entorno sensibles a la seguridad cuando el ejecutable tiene establecido el ID de usuario o el ID de grupo.

CTLOG_FILE
Especifica la ruta a una lista de registros de transparencia de certificados. Ver CTLOG_STORE_new(3).

Esta variable se considera una variable de entorno sensible a la seguridad.

HOME, SYSTEMROOT, USERPROFILE
Ruta que RAND_file_name(3) utiliza como directorio para el nombre del archivo de semilla aleatorio cuando la variable de entorno RANDFILE no está establecida. HOME es la única variable que se considera en sistemas similares a Unix; USERPROFILE y SYSTEMROOT se utilizan como copias de seguridad en plataformas Windows.

La variable HOME se considera una variable de entorno sensible a la seguridad.

HTTPS_PROXY, HTTP_PROXY, NO_PROXY, https_proxy, http_proxy, no_proxy
Especifica un nombre de host proxy. Ver OSSL_HTTP_parse_url(3).

Estas variables se consideran variables de entorno sensibles a la seguridad.

LEGACY_GOST_PKCS12
Afecta la forma en que se genera el MAC en contenedores PKCS#12 para algoritmos GOST. Ver PKCS12_gen_mac(3).

Esta variable se considera una variable de entorno sensible a la seguridad.

OPENSSL
Especifica la ruta al ejecutable openssl. Utilizada por el script rehash (ver "Script Configuration" en openssl-rehash(1)) y por el script CA.pl (ver "NOTES" en CA.pl(1)).

Esta variable no se considera sensible a la seguridad.

OPENSSL_CONF, OPENSSL_CONF_INCLUDE
Especifica la ruta a un archivo de configuración y al directorio para los archivos incluidos. Ver config(5).

Estas variables se consideran variables de entorno sensibles a la seguridad.

OPENSSL_CONFIG
Especifica una opción de configuración y un nombre de archivo para los comandos req y ca invocados por el script CA.pl. Ver CA.pl(1).

Esta variable no se considera sensible a la seguridad.

OPENSSL_DEBUG_DECC_INIT
Solo en VMS: si esta variable está establecida, habilita la salida detallada del análisis de los nombres lógicos "DECC$*", que contienen características del C RTL, durante la inicialización de la biblioteca ("LIB$INITIALIZE"). Si el valor de la variable es superior a 1, produce información sobre cada característica procesada.

Esta variable no se considera sensible a la seguridad.

OPENSSL_ENGINES
Especifica el directorio desde el cual se cargan los motores dinámicos. Ver openssl-engine(1).

Esta variable se considera una variable de entorno sensible a la seguridad.

OPENSSL_MALLOC_FAILURES, OPENSSL_MALLOC_FD, OPENSSL_MALLOC_SEED
Si se compila con depuración, esto permite que la asignación de memoria falle. Ver OPENSSL_malloc(3).

Estas variables no se consideran sensibles a la seguridad.

OPENSSL_MODULES
Especifica el directorio desde el cual se cargan los proveedores criptográficos. De forma equivalente, se puede usar la opción genérica de línea de comandos -provider-path.

Esta variable se considera una variable de entorno sensible a la seguridad.

OPENSSL_SEC_MEM
Inicializa la memoria segura al principio de la aplicación, lo que hace que las llamadas a memoria segura no recurran a llamadas de memoria regular. El valor indica el parámetro size en bytes. El valor puede expresarse en binario, octal, decimal y hexadecimal. Para el formato ver strtol(3). Para más restricciones ver CRYPTO_secure_malloc_init(3).

Esta variable no se considera sensible a la seguridad.

OPENSSL_SEC_MEM_MINSIZE
Una variable opcional utilizada con OPENSSL_SEC_MEM. El valor indica el parámetro minsize en bytes. Se aplica el mismo formato que anteriormente. El valor predeterminado es 0. Para más información ver CRYPTO_secure_malloc_init(3).

Esta variable no se considera sensible a la seguridad.

OPENSSL_TEST_LIBCTX
Esta variable de entorno, solo para pruebas, reconocida por el comando openssl(1), cuando se establece en "1", provoca la creación de un contexto de biblioteca no predeterminado por el comando, para el cual la opción -config tendrá efecto.

Esta variable no se considera sensible a la seguridad.

OPENSSL_TRACE
Por defecto, la función de rastreo de OpenSSL está deshabilitada estáticamente. Para habilitarla, OpenSSL debe compilarse con soporte de rastreo, lo que puede configurarse así: "./config enable-trace".

A menos que el soporte de rastreo de OpenSSL esté generalmente deshabilitado, habilita la salida de rastreo de partes específicas de las bibliotecas de OpenSSL, por nombre. Esta salida generalmente solo tiene sentido si se conocen bien los detalles internos de OpenSSL.

El valor de esta variable de entorno es una lista separada por comas de nombres, con los siguientes disponibles:

ALL
Rastrea todo.
BN_CTX
Rastrea las operaciones del contexto BIGNUM.
CMP
Rastrea la actividad del cliente y servidor CMP.
CONF
Muestra detalles sobre la configuración del proveedor y del motor.
DECODER
Rastrea las operaciones del decodificador.
ENCODER
Rastrea las operaciones del codificador.
ENGINE_REF_COUNT
Los recuentos de referencia en la estructura ENGINE serán monitoreados con una línea generada por cada cambio.
ENGINE_TABLE
La función que utilizan el código RSA, DSA (etc.) para seleccionar los motores registrados, los valores predeterminados de caché y las referencias funcionales (etc.), generará resúmenes de depuración.
HTTP
Rastrea el cliente y servidor HTTP, como los mensajes que se envían y reciben.
INIT
Rastrea la inicialización y limpieza de la biblioteca OpenSSL.
PKCS12_DECRYPT
Rastrea la desencriptación PKCS#12.
PKCS12_KEYGEN
Rastrea la generación de claves PKCS#12.
PKCS5V2
Rastrea la generación de claves PKCS#5 v2.
PROVIDER
Rastrea varias operaciones que se realizan en los proveedores de OpenSSL durante su gestión por parte de la biblioteca (ver provider(7)), como la inicialización, la finalización, los parámetros y las capacidades

DESCRIPTION

Some OpenSSL applications and libraries use environment variables that are not part of the standard POSIX or operating system environment. These are defined by OpenSSL itself.

The following is a list of OpenSSL-specific environment variables:

CORE
Traces core library operations, for example, initialisation, memory allocation, and cleanup.
CRYPTO
Traces cryptographic operations, for example, encryption, decryption, message digest computation, and signature generation/verification.
DL_LOAD
Traces dynamic loading of OpenSSL engine modules.
ERR
Traces error reporting operations.
LOCK
Traces locking operations used for thread safety.
MEM_CHECK
Traces memory allocation and deallocation operations.
METHS
Traces operations related to the method store, that holds pointers to functions provided by various providers. It traces addition, removal, and fetching of methods, retrieval, self-test, and so on.
QUERY
Traces operation related to addition, removal, and fetching of methods in the so-called method store, that holds pointers to functions provided by various providers.
REF_COUNT
Traces reference count changes in various structures, including "BIO", "DH", "DSA", "EC_KEY", "ECX_KEY", "EVP_PKEY", "EVP_SKEY", "RSA", "SSL", "SSL_CTX", "SSL_SESSION", "X509_CRL", "X509_STORE", "X509", and some others.
STORE
Traces STORE operations.
TLS
Traces the TLS/SSL protocol.
TLS_CIPHER
Traces the ciphers used by the TLS/SSL protocol.
TRACE
Traces the OpenSSL trace API itself.
X509V3_POLICY
Generates the complete policy tree at various points during X.509 v3 policy evaluation.

This variable is not considered security-sensitive.

OPENSSL_WIN32_UTF8
If set, then UI_OpenSSL(3) returns UTF-8 encoded strings, rather than ones encoded in the current code page, and the openssl(1) program also transcodes the command-line parameters from the current code page to UTF-8. This environment variable is only checked on Microsoft Windows platforms.
OPENSSL_armcap, OPENSSL_ia32cap, OPENSSL_ppccap, OPENSSL_riscvcap, OPENSSL_s390xcap, OPENSSL_sparcv9cap
OpenSSL supports a number of different algorithm implementations for various machines and, by default, it determines which to use based on the processor capabilities and run time feature enquiry. These environment variables can be used to exert more control over this selection process. See OPENSSL_ia32cap(3), OPENSSL_riscvcap(3), and OPENSSL_s390xcap(3).

These variables are not considered security-sensitive.

OSSL_QFILTER
Used to set a QUIC qlog filter specification. See openssl-qlog(7).

This variable is considered a security-sensitive environment variable.

QLOGDIR
Specifies a QUIC qlog output directory. See openssl-qlog(7).

This variable is considered a security-sensitive environment variable.

RANDFILE
The state file for the random number generator. This should not be needed in normal use. See RAND_load_file(3).

This variable is considered a security-sensitive environment variable.

SSLKEYLOGFILE
Used to produce the standard format output file for SSL key logging. Optionally set this variable to a filename to log all secrets produced by SSL connections. Note, use of the environment variable is predicated on configuring OpenSSL at build time with the enable-sslkeylog feature. The file format standard can be found at https://datatracker.ietf.org/doc/draft-ietf-tls-keylogfile/. Note: the use of SSLKEYLOGFILE poses an explicit security risk. By recording the exchanged keys during an SSL session, it allows any available party with read access to the file to decrypt application traffic sent over that session. Use of this feature should be restricted to test and debug environments only.

This variable is considered a security-sensitive environment variable.

SSL_CERT_DIR, SSL_CERT_FILE
Specify the default directory or file containing CA certificates. See SSL_CTX_load_verify_locations(3).

These variables are considered security-sensitive environment variables, except in openssl-rehash(1), where SSL_CERT_DIR is not considered security-sensitive.

SSL_CIPHER
Used by openssl-s_time(1) in case -cipher option (that allows modifying TLSv1.2 and below cipher list sent by the client) is not provided, for specification of the aforementioned ciphers.

This variable is not considered security-sensitive.

TSGET
Additional arguments for the tsget(1) command.

This variable is not considered security-sensitive.

HISTORY

This section contains environment variables that are no longer considered by the OpenSSL libraries and commands.

HARNESS_OSSL_PREFIX
This environment variable, existed in OpenSSL versions from 1.1.1 up to 3.5, allowed specification of a prefix prepended to each line sent to the stdout by openssl(1), used by the test harness to avoid commingling the command under test output with the output for the TAP consumer.

This variable was not considered security-sensitive.
