Descripción detallada

La API multistream permite combinar flujos Opus individuales en un único paquete, permitiendo el soporte para hasta 255 canales.

A diferencia de un flujo Opus elemental, el codificador y el decodificador deben negociar la configuración de canales antes de que el decodificador pueda interpretar correctamente los datos en los paquetes producidos por el codificador. Se puede calcular cierta información básica, como la duración del paquete, sin ninguna negociación especial.

El formato de los paquetes Opus multistream se define en RFC 7845 y se basa en el enmarcado Opus auto-delimitado descrito en el Apéndice B de RFC 6716. Los paquetes Opus normales son solo un caso degenerado de paquetes Opus multistream, y pueden codificarse o decodificarse con la API multistream estableciendo streams a 1 al inicializar el codificador o el decodificador.

Los flujos Opus multistream pueden contener hasta 255 flujos Opus elementales. Estos pueden ser 'no acoplados' o 'acoplados', lo que indica que el decodificador está configurado para decodificarlos a 1 o 2 canales, respectivamente. Los flujos se ordenan de manera que todos los flujos acoplados aparezcan al principio.

Una tabla de mapeo define qué canal de salida j debe utilizarse para cada canal de entrada/salida (I/O) i. Esta tabla se proporciona típicamente como un array de unsigned char. Sea i = mapping[j] el índice para el canal I/O j. Si i < 2*coupled_streams, entonces el canal I/O j se codifica como el canal izquierdo del flujo (i/2) si i es par, o como el canal derecho del flujo (i/2) si i es impar. De lo contrario, el canal I/O j se codifica como mono en el flujo (i - coupled_streams), a menos que tenga el valor especial 255, en cuyo caso se omite de la codificación por completo (el decodificador lo reproducirá como silencio). Cada valor i debe ser el valor especial 255 o ser menor que streams + coupled_streams.

Los canales de salida especificados por el codificador deben usar el orden de canales de Vorbis. Un decodificador puede desear aplicar una permutación adicional al mapeo que utilizó el codificador para lograr un orden de canales diferente (por ejemplo, para la salida en orden WAV).

Cada paquete multistream contiene un paquete Opus por cada flujo, y todos los paquetes Opus en un solo paquete multistream deben tener la misma duración. Por lo tanto, la duración de un paquete multistream se puede extraer de la secuencia TOC del primer flujo, que se encuentra al principio del paquete, al igual que un flujo Opus elemental:

int nb_samples;
int nb_frames;
nb_frames = opus_packet_get_nb_frames(data, len);
if (nb_frames < 1)
  return nb_frames;
nb_samples = opus_packet_get_samples_per_frame(data, 48000) * nb_frames;

El proceso general de codificación y decodificación procede exactamente igual que en las API normales de Codificador Opus y Decodificador Opus. Consulte su documentación para obtener una descripción general de cómo utilizar las funciones multistream correspondientes.

int opus_multistream_decode (OpusMSDecoder * st, const unsigned char * data, opus_int32 len, opus_int16 * pcm, int frame_size, int decode_fec)

int opus_multistream_decode (OpusMSDecoder * st, const unsigned char * data, opus_int32 len, opus_int16 * pcm, int frame_size, int decode_fec)

Decodifica un paquete Opus multi-stream.

Parámetros

st OpusMSDecoder*: Estado del decodificador multi-stream.
data const unsigned char*: Carga útil de entrada. Use un puntero NULL para indicar pérdida de paquete.
len opus_int32: Número de bytes en la carga útil.
pcm opus_int16*: Señal de salida, con muestras intercaladas. Esto debe contener espacio para frame_size*channels muestras.
frame_size int: El número de muestras por canal de espacio disponible en pcm. Si esto es menor que la duración máxima del paquete (120 ms; 5760 para 48kHz), esta función no será capaz de decodificar algunos paquetes. En el caso de PLC (data==NULL) o FEC (decode_fec=1), entonces frame_size necesita ser exactamente la duración del audio que falta, de lo contrario el decodificador no estará en el estado óptimo para decodificar el siguiente paquete entrante. Para los casos PLC y FEC, frame_size debe ser un múltiplo de 2.5 ms.
decode_fec int: Indicador (0 o 1) para solicitar que se decodifiquen los datos de corrección de errores hacia adelante (FEC) en banda. Si no hay tales datos disponibles, el marco se decodifica como si se hubiera perdido.

Retorna

Número de muestras decodificadas en caso de éxito o un código de error negativo (ver Códigos de error) en caso de fallo.

OpusMSDecoder * opus_multistream_decoder_create (opus_int32 Fs, int channels, int streams, int coupled_streams, const unsigned char * mapping, int * error)

Asigna e inicializa un estado de decodificador multi-stream. Llame a opus_multistream_decoder_destroy() para liberar este objeto cuando haya terminado.

Parámetros

Fs opus_int32: Tasa de muestreo a decodificar (en Hz). Debe ser una de 8000, 12000, 16000, 24000 o 48000.
channels int: Número de canales a producir. Esto debe ser como máximo 255. Puede ser diferente del número de canales codificados (streams + coupled_streams).
streams int: El número total de streams codificados en la entrada. Esto debe ser no más de 255.
coupled_streams int: Número de streams a decodificar como streams acoplados (de 2 canales). Esto no debe ser mayor que el número total de streams. Adicionalmente, el número total de canales codificados (streams + coupled_streams) no debe ser mayor que 255.
mapping const unsigned char[channels]: Mapeo de canales codificados a canales de salida, como se describe en la API de Opus Multi-stream.
error int *: Devuelve OPUS_OK en caso de éxito, o un código de error (ver Códigos de error) en caso de fallo.

int opus_multistream_encode (OpusMSEncoder * st, const opus_int16 * pcm, int frame_size, unsigned char * data, opus_int32 max_data_bytes)

Codifica un marco Opus multi-stream.

Parámetros

st OpusMSEncoder*: Estado del codificador multi-stream.
pcm const opus_int16*: La señal de entrada como muestras intercaladas. Esto debe contener frame_size*channels muestras.
frame_size int: Número de muestras por canal en la señal de entrada. Esto debe ser un tamaño de marco Opus para la tasa de muestreo del codificador. Por ejemplo, a 48 kHz los valores permitidos son 120, 240, 480, 960, 1920 y 2880. Pasar una duración de menos de 10 ms (480 muestras a 48 kHz) impedirá que el codificador utilice los modos LPC o híbrido.
data unsigned char*: Carga útil de salida. Esto debe contener espacio para al menos max_data_bytes.
max_data_bytes opus_int32: Tamaño de la memoria asignada para la carga útil de salida. Esto puede usarse para imponer un límite superior al bitrate instantáneo, pero no debe usarse como el único control de bitrate. Use OPUS_SET_BITRATE para controlar el bitrate.

Retorna

La longitud del paquete codificado (en bytes) en caso de éxito o un código de error negativo (ver Códigos de error) en caso de fallo.
