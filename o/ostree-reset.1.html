OSTREE RESET(1) ostree reset OSTREE RESET(1)

NOMBRE

ostree reset - Restablece una referencia a un commit anterior

SINOPSIS

ostree reset {REF} {REF_A_RESTABLECER}

DESCRIPCIÓN

Dado un commit, este comando restablecerá la referencia a una referencia anterior especificada.

EJEMPLO

$ ostree log mi-rama

        commit 67e382b11d213a402a5313e61cbc69dfd5ab93cb07
        Fecha:  2014-06-12 13:42:54 +0000
            Este es el segundo commit
        commit ce19c41036cc45e49b0cecf6b157523c2105c4de1c
        Fecha:  2014-06-12 11:20:08 +0000
            Commit inicial

$ ostree reset mi-rama mi-rama^

$ ostree log mi-rama

        commit ce19c41036cc45e49b0cecf6b157523c2105c4de1c
        Fecha:  2014-06-12 11:20:08 +0000
            Commit inicial
