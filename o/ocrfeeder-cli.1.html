ocrfeeder-cli(1) Manual de comandos generales ocrfeeder-cli(1)

NOMBRE

ocrfeeder-cli - interfaz de línea de comandos para OCRFeeder, un sistema de análisis de diseño de documentos y reconocimiento óptico de caracteres.

SINOPSIS

ocrfeeder-cli [OPCIONES]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando ocrfeeder-cli.

OCRFeeder Dada las imágenes, delineará automáticamente su contenido, distinguirá entre gráficos y texto y realizará OCR sobre estos últimos. Genera múltiples formatos, siendo su principal ODT.

OPCIONES

Información general del programa

--version
Muestra el número de versión del programa y sale
-h, --help
Muestra el mensaje de ayuda y sale

Opciones requeridas

-o ARCHIVO_SALIDA, --output=ARCHIVO_SALIDA
Nombre para el archivo generado

Otras opciones

-i IMAGEN1 [IMAGEN2 ...], --images=IMAGEN1 [IMAGEN2 ...]
Imágenes a reconocer
-f FORMATO, --format=FORMATO
Formato para el documento generado: PDF, HTML, ODT, TXT o SPDF (PDF con búsqueda)
-e MOTOR, --engine=MOTOR
El motor OCR a utilizar. Las opciones son: GOCR u Ocrad
-l IDIOMA, --language=IDIOMA
El idioma según ISO-639-1. Por ejemplo, "pt" para portugués o "en" para inglés
--window-size=TAMAÑO_VENTANA
Tamaño de ventana deseado para el algoritmo de segmentación de OCRFeeder. Si no se utiliza esta opción, el tamaño de la ventana se calculará automáticamente

CARPETAS

~/.config/ocrfeeder/engines/
Carpeta para almacenar los archivos de configuración de los motores
