operon(1)

OPERON(1) OPERON(1)

NOMBRE

operon - editor de etiquetas de música en línea de comandos

SINOPSIS

operon [--version] [--help] [-v | --verbose] <comando> [<argumento>...]
operon help <comando>

OPCIONES

-h, --help
Muestra la ayuda y sale.
--version
Imprime la versión del programa.
-v, --verbose
Modo detallado.

RESUMEN DE COMANDOS

Editar Etiquetas

add         Añadir un valor de etiqueta
remove      Eliminar un valor de etiqueta
set         Establecer una etiqueta y eliminar valores existentes
clear       Eliminar etiquetas
copy        Copiar etiquetas de un archivo a otro
edit        Editar etiquetas en un editor de texto
fill        Rellenar etiquetas basándose en la ruta del archivo

Mostrar metadatos del archivo

list        Listar etiquetas
info        Listar información del archivo
print       Imprimir etiquetas basándose en el patrón dado

Editar Imágenes Incrustadas

image-extract    Extraer imágenes incrustadas
image-set        Establecer imagen incrustada
image-clear      Eliminar imágenes incrustadas

Misceláneos

tags        Listar todas las etiquetas comunes
help        Mostrar información de ayuda

EDITAR ETIQUETAS

add

Añade una nueva etiqueta <tag> con el valor <value> a todos los archivos.

operon add [-h] <tag> <value> <file>...

-h, --help
Muestra la ayuda y sale.
Ejemplo:
operon add artist 'The Beatles' song1.ogg song2.ogg

remove

Elimina todos los valores de la etiqueta <tag> que coincidan con <value> o la expresión regular <pattern> de todos los archivos.

operon remove [-h] [--dry-run] <tag> (-e <pattern> | <value>) <file>...

-h, --help
Muestra la ayuda y sale.
--dry-run
Imprime los resultados sin modificar ningún archivo.
-e,--regexp <regexp>
Elimina todos los valores de etiqueta que coincidan con la expresión regular dada.
Ejemplo:
operon remove artist 'The Beatles' song.ogg

set

Reemplaza todos los valores de la etiqueta <tag> por <value> en todos los archivos.

operon set [-h] [--dry-run] <tag> <value> <file>...

-h, --help
Muestra la ayuda y sale.
--dry-run
Imprime los resultados sin modificar ningún archivo.
Ejemplo:
operon set artist 'The Beatles' song.ogg

clear

Elimina todas las etiquetas que coincidan con <tag> o la expresión regular <pattern> de todos los archivos. Si se especifica --all, se eliminarán todas las etiquetas conocidas.

operon clear [-h] [--dry-run] (-a | -e <pattern> | <tag>) <file>...

-h, --help
Muestra la ayuda y sale.
--dry-run
Imprime los resultados sin modificar ningún archivo.
-a, --all
Elimina todas las etiquetas.
-e,--regexp <regexp>
Elimina todas las etiquetas que coincidan con la expresión regular dada.
Ejemplo:
operon clear -a song.ogg

operon clear -e 'musicbrainz_.*' song.ogg

operon clear date song.ogg

copy

Copia todas las etiquetas del archivo <source> a <dest>. Todas las etiquetas en <dest> se conservarán. En caso de que el formato de destino no admita el establecimiento de una etiqueta de origen, no se copiarán etiquetas. Para ignorar etiquetas que no son compatibles con el formato de destino, pase --ignore-errors.

operon copy [-h] [--dry-run] [--ignore-errors] <source> <dest>

-h, --help
Muestra la ayuda y sale.
--dry-run
Imprime los resultados sin modificar ningún archivo.
--ignore-errors
Omite las etiquetas que el archivo de destino no soporta.
Ejemplo:
operon copy song.flac song.ogg

edit

Muestra todas las etiquetas en un editor de texto y aplicará cualquier cambio realizado en el texto a las etiquetas. operon utilizará el editor especificado en las variables de entorno VISUAL o EDITOR y, si estas no están configuradas, recurrirá a 'nano'.

operon edit [-h] [--dry-run] <file>...

-h, --help
Muestra la ayuda y sale.
--dry-run
Imprime los resultados sin modificar ningún archivo.
Ejemplo:
VISUAL=vi operon edit song.flac

fill

Rellena etiquetas basándose en las rutas de los archivos y un patrón dado.

operon fill [-h] [--dry-run] <pattern> <file>...

-h, --help
Muestra esta ayuda y sale.
--dry-run
Muestra los cambios, no los aplica.
Ejemplo:
operon fill --dry-run "<tracknumber>. <title>" "01. Was Ist Ist.flac"

MOSTRAR METADATOS DEL ARCHIVO

list

Lista todas las etiquetas, valores y una descripción de cada etiqueta en una tabla.

operon list [-h] [-a] [-t] [-c <c1>,<c2>...] <file>
