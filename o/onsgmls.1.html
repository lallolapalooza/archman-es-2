NOMBRE

onsgmls - Un analizador y validador SGML/XML

SINOPSIS

onsgmls [-BCdeghlnpRrsuvx] [-atipo_enlace] [-Aarquitectura] [-bbctf] [-cid_sistema...] [-Ddirectorio] [-Emax_errores] [-farchivo] [-inombre] [-oopcion_salida...] [-tarchivo] [-wtipo_advertencia...] [id_sistema...]

DESCRIPCIÓN

onsgmls analiza y valida el documento SGML cuya entidad documental se especifica mediante los identificadores de sistema

e imprime en la salida estándar una representación de texto simple de su Conjunto de Información de Estructura de Elementos. (Este es el conjunto de información sobre el cual una aplicación SGML que se ajusta a la estructura debe actuar.) Si se especifica más de un identificador de sistema, las entidades correspondientes se concatenarán para formar la entidad documental. Por lo tanto, la entidad documental puede distribuirse entre varios archivos; por ejemplo, la declaración SGML, el prólogo y la instancia del documento se pueden colocar cada uno en un archivo separado. Si no se especifican identificadores de sistema, onsgmls leerá la entidad documental de la entrada estándar. Un identificador de sistema de línea de comandos - puede usarse para referirse a la entrada estándar. (Normalmente, en un identificador de sistema, se usa <OSFD>0 para referirse a la entrada estándar).

Parte de un Sistema SGML que Cumple con el Estándar Internacional ISO 8879 -- Lenguaje de Marcado Generalizado Estándar. Un sistema de Extensiones SGML que Cumple con el Anexo A del Estándar Interno ISO/IEC 10744 -- Lenguaje de Estructuración Hipermedia/Basado en Tiempo

Las siguientes opciones están disponibles:

-atipo_enlace, --activar=tipo_enlace

Activa el tipo de enlace tipo_enlace. No se exporta toda la información ESIS en este caso: los LPD activos no se informan explícitamente, aunque cada atributo de enlace se califica con el nombre de su tipo de enlace; no hay información sobre los elementos de resultado; cuando hay varias reglas de enlace aplicables al elemento actual, onsgmls siempre elige la primera.

-Aarquitectura, --arquitectura=arquitectura

Analiza con respecto a la arquitectura arquitectura.

-bbctf, --bctf=bctf, -bcodificacion, --codificacion=codificacion

Esto determina la codificación utilizada para la salida. Si está en modo de conjunto de caracteres fijo, especifica el nombre de una codificación; si no, especifica el nombre de un BCTF.

-B, --modo-lote

Modo por lotes. Analiza cada

archivo especificado en la línea de comandos por separado, en lugar de concatenarlos. Esto es útil principalmente con -s.

Si también se especifica -tnombre_archivo, entonces el nombre de archivo especificado se antepondrá al id_sistema para crear el nombre de archivo para el resultado RAST de cada id_sistema.

-cid_sistema, --catalogo=id_sistema

Mapea identificadores públicos y nombres de entidades a identificadores de sistema utilizando el archivo de entrada de catálogo cuyo identificador de sistema es id_sistema. Se permiten múltiples opciones -c. Si hay un archivo de entrada de catálogo llamado catalog en el mismo lugar que la entidad documental, se buscará inmediatamente después de los especificados por -c.

-C, --catalogos

Los

argumentos especifican archivos de catálogo en lugar de la entidad documental. La entidad documental se especifica mediante la primera entrada DOCUMENT en los archivos de catálogo.

-Ddirectorio, --directorio=directorio

Busca en el directorio los archivos especificados en los identificadores de sistema. Se permiten múltiples opciones -D. Consulte la descripción del gestor de almacenamiento osfile para obtener más información sobre la búsqueda de archivos.

-e, --abrir-entidades

Describe las entidades abiertas en los mensajes de error. Los mensajes de error siempre incluyen la posición de la entidad externa abierta más recientemente.

-Emax_errores, --max-errores=max_errores

onsgmls saldrá después de max_errores errores. Si max_errores es 0, no hay límite en el número de errores. El valor predeterminado es 200.

-farchivo, --archivo-errores=archivo

Redirige los errores al archivo. Esto es útil principalmente con shells que no admiten la redirección de stderr.

-g, --abrir-elementos

Muestra los identificadores genéricos de los elementos abiertos en los mensajes de error.

-h, --ayuda

Muestra un mensaje de ayuda y sale.

-inombre, --incluir=nombre

Finge que

<!ENTITY % nombre "INCLUDE">

ocurre al comienzo del subconjunto de declaración de tipo de documento en la entidad del documento SGML. Dado que las definiciones repetidas de una entidad se ignoran, esta definición tendrá prioridad sobre cualquier otra definición de esta entidad en la declaración de tipo de documento. Se permiten múltiples opciones -i. Si la declaración SGML reemplaza el nombre reservado INCLUDE, el nuevo nombre reservado será el texto de reemplazo de la entidad. Típicamente, la declaración de tipo de documento contendrá

<!ENTITY % nombre "IGNORE">

y usará %nombre; en la especificación de la palabra clave de estado de una declaración de sección marcada. En este caso, el efecto de la opción será hacer que la sección marcada no se ignore.

-n, --numeros-errores

Muestra los números de mensaje en los mensajes de error.

-oopcion_salida, --opcion=opcion_salida

Salida de información adicional según opcion_salida:

entity Salida de las definiciones de todas las entidades generales, no solo para entidades de datos o subdocumentos que se referencian o nombran en un atributo ENTITY o ENTITIES.

id Distingue los atributos cuyo valor declarado es ID.

line Salida de comandos L que indican el número de línea actual y el nombre del archivo.

included Salida de un comando i para subelementos incluidos.

empty Salida de un comando e para elementos que no tienen permitido una etiqueta de fin, es decir, aquellos con un contenido declarado de vacío o con un atributo de referencia de contenido.

notation-sysid Salida de un comando f antes de un comando N, si se pudiera generar un identificador de sistema para esa notación.

nonsgml En modo de conjunto de caracteres fijo, salida de secuencias de escape \% para caracteres de datos no SGML. Los caracteres de datos no SGML pueden resultar de referencias a caracteres numéricos.

data-attribute Salida del nombre de la notación y los atributos para atributos DATA. De lo contrario, los atributos DATA se tratan como atributos CDATA. Para más detalles, consulte la cláusula 4.4.3 del Anexo K de ISO 8879.

comment Salida de un comando _ con el contenido de un comentario. Múltiples comentarios en una sola declaración de comentario resultarán en comandos _ distintos, como si los comentarios estuvieran cada uno en una declaración de comentario separada.

omitted Salida de un comando o antes de un comando que fue implícito por el documento de entrada, pero omitido del marcado real. Esto actualmente afecta a los comandos (,), y A.

tagomit Igual que omitted, pero solo para comandos ( y ).

attromit Igual que omitted, pero solo para comandos A.

Se permiten múltiples opciones -o.

-p, --solo-prologo

Analiza solo el prólogo. onsgmls saldrá después de analizar la declaración de tipo de documento. Implica -s.

-R, --restringido

Restringe la lectura de archivos. Esta opción está destinada a ser utilizada con herramientas web basadas en onsgmls (por ejemplo, scripts CGI) para evitar la lectura de archivos arbitrarios en el servidor web. Con esta opción habilitada, onsgmls no leerá ningún archivo local a menos que se encuentre en un directorio (o subdirectorio) especificado por la opción -D o incluido en la variable de entorno SGML_SEARCH_PATH. Como medida de seguridad adicional, esta opción limita los nombres de archivo a los caracteres A-Z, a-z, 0-9, '?', '.', '_', '-' y no permite nombres de archivo que contengan "..". En sistemas con nombres de archivo MS-DOS, también se permiten ':' y '\'.

-s, --sin-salida

Suprime la salida. Los mensajes de error todavía se imprimirán
ed.

-tarchivo, --rast-file=archivo

Escribe en archivo el resultado RAST tal como se define en la norma ISO/IEC 13673:1995 (en realidad, esto aún no es una norma; implementa el borrador intermedio del editor de 1994/08/29, con cambios para implementar la norma ISO/IEC JTC1/SC18/WG8 N1777). La salida normal no se produce.

-v, --version

Imprime el número de versión.

-wtipo, --warning=tipo

Controla las advertencias y los errores. Se permiten múltiples opciones -w. Los siguientes valores de tipo habilitan las advertencias:

xml Advierte sobre construcciones que no están permitidas por XML.

mixed Advierte sobre modelos de contenido mixto que no permiten #PCDATA en ninguna parte.

sgmldecl Advierte sobre diversas construcciones dudosas en la declaración SGML.

should Advierte sobre varias recomendaciones hechas en la norma ISO 8879 a las que el documento no cumple. (Las recomendaciones se expresan con "should", a diferencia de los requisitos que generalmente se expresan con "shall").

default Advierte sobre referencias predeterminadas.

duplicate Advierte sobre declaraciones de entidades duplicadas.

undefined Advierte sobre elementos no definidos: elementos utilizados en el DTD pero no definidos.

unclosed Advierte sobre etiquetas de inicio y fin no cerradas.

empty Advierte sobre etiquetas de inicio y fin vacías.

net Advierte sobre etiquetas de inicio que habilitan la red y etiquetas de fin nulas.

min-tag Advierte sobre etiquetas de inicio y fin minimizadas. Equivalente a la combinación de advertencias unclosed, empty y net.

unused-map Advierte sobre mapas de referencias cortas no utilizados: mapas declarados con una declaración de mapeo de referencias cortas pero nunca utilizados en una declaración de uso de referencia corta en el DTD.

unused-param Advierte sobre entidades de parámetro que están definidas pero no utilizadas en un DTD. Las entidades de parámetro internas no utilizadas cuyo texto es INCLUDE o IGNORE no generarán la advertencia.

notation-sysid Advierte sobre notaciones para las cuales no se pudo generar un identificador de sistema.

all Advierte sobre condiciones que generalmente deberían evitarse (en opinión del autor). Equivalente a: mixed, should, default, undefined, sgmldecl, unused-map, unused-param, empty y unclosed.

immediate-recursion Advierte sobre elementos recursivos inmediatos. Para más detalles, consulte la cláusula 2.2.5 del Anexo K de la norma ISO 8879.

fully-declared Advierte si la instancia del documento no está completamente declarada. Esto tiene el efecto de cambiar la declaración SGML para especificar IMPLYDEF ATTLIST NO ELEMENT NO ENTITY NO NOTATION NO. Para más detalles, consulte la cláusula 2.2.1 del Anexo K de la norma ISO 8879.

fully-tagged Advierte si la instancia del documento no está completamente etiquetada. Esto tiene el efecto de cambiar la declaración SGML para especificar DATATAG NO, RANK NO, OMITTAG NO, SHORTTAG STARTTAG EMPTY NO y SHORTTAG ATTRIB OMITNAME NO. Para más detalles, consulte la cláusula 2.2.2 del Anexo K de la norma ISO 8879.

amply-tagged, amply-tagged-recursive Advierte si la instancia del documento no está suficientemente etiquetada. Los elementos definidos implícitamente pueden ser recursivos inmediatos si se especifica amply-tagged-recursive. Esto tiene el efecto de cambiar la declaración SGML para especificar DATATAG NO, RANK NO, OMITTAG NO, SHORTTAG ATTRIB OMITNAME NO y bien IMPLYDEF ELEMENT ANYOTHER o IMPLYDEF ELEMENT YES. Para más detalles, consulte la cláusula 2.2.4 del Anexo K de la norma ISO 8879.

type-valid Advierte si la instancia del documento no es válida por tipo. Esto tiene el efecto de cambiar la declaración SGML para especificar VALIDITY YES. Para más detalles, consulte la cláusula 2.2.3 del Anexo K de la norma ISO 8879.

entity-ref Advierte sobre referencias a entidades no predefinidas. Esto tiene el efecto de cambiar la declaración SGML para especificar ENTITIES REF NONE. Para más detalles, consulte la cláusula 2.3.2 del Anexo K de la norma ISO 8879.

external-entity-ref Advierte sobre referencias a entidades externas. Esto incluye referencias a un subconjunto DTD externo. Esto tiene el efecto de cambiar la declaración SGML para especificar ENTITIES REF INTERNAL. Para más detalles, consulte la cláusula 2.3.3 del Anexo K de la norma ISO 8879.

integral Advierte si la instancia del documento no está almacenada de forma integral. Esto tiene el efecto de cambiar la declaración SGML para especificar ENTITIES INTEGRAL YES. Para más detalles, consulte la cláusula 2.3.1 del Anexo K de la norma ISO 8879.

Una advertencia puede desactivarse usando su nombre precedido por no-. Así, -wall -wno-duplicate habilitará todas las advertencias excepto las relativas a declaraciones de entidades duplicadas.

Los siguientes valores para tipo_advertencia deshabilitan errores:

no-idref No genere un error para un valor de referencia ID al que ningún elemento tiene como su ID. El efecto será como si cada atributo declarado como valor de referencia ID hubiera sido declarado como un nombre.

no-significant No genere un error cuando un carácter que no es un carácter significativo en la sintaxis concreta de referencia ocurre en un literal en la declaración SGML. Esto puede ser útil en combinación con ciertos conjuntos de pruebas defectuosos.

no-valid No exija que el documento sea válido por tipo. Esto tiene el efecto de cambiar la declaración SGML para especificar VALIDITY NOASSERT y IMPLYDEF ATTLIST YES ELEMENT YES. Una opción de -wvalid tiene el efecto de cambiar la declaración SGML para especificar VALIDITY TYPE y IMPLYDEF ATTLIST NO ELEMENT NO. Si no se especifica ni -wvalid ni -wno-valid, se utilizarán la VALIDEZ y el IMPLYDEF especificados en la declaración SGML.

no-afdr No genere errores cuando se utilicen características de notación AFDR meta-DTD en el DTD. Estos errores se producen normalmente al analizar el DTD, pero se suprimen al analizar meta-DTDs.

-x, --references

Muestra información sobre las cláusulas relevantes (de ISO 8879:1986) en los mensajes de error.

Las siguientes opciones también se admiten por compatibilidad con versiones anteriores de sgmls:

-d

Igual que -wduplicate.

-l

Igual que -oline.

-msysid

Igual que -c.

-r

Igual que -wdefault.

-u

Igual que -wundef.
