OPENBOX(1) Manual de Comandos Generales OPENBOX(1)

NOMBRE

openbox — Un gestor de ventanas minimalista, altamente configurable, de próxima generación con amplio soporte de estándares.

SINOPSIS

openbox [--help] [--version] [--replace] [--reconfigure] [--restart] [--sm-disable] [--sync] [--debug] [--debug-focus] [--debug-xinerama]

DESCRIPCIÓN

Openbox es un gestor de ventanas minimalista, altamente configurable, de próxima generación con amplio soporte de estándares.

Puedes iniciar Openbox de tres maneras:

Si ejecutas un gestor de pantalla como GDM, encontrarás 3 entradas en el menú de tipo de sesión de inicio de sesión para Openbox: GNOME/Openbox, KDE/Openbox y Openbox. Si quieres usar Openbox dentro de GNOME o KDE, puedes elegir la entrada apropiada, y lanzará GNOME o KDE con Openbox como gestor de ventanas.

La tercera opción al iniciar sesión, que es Openbox sin un gestor de sesiones, utiliza el comando openbox-session para iniciar Openbox. Al iniciar sesión, openbox ejecutará el script ~/.config/openbox/autostart.sh si existe, y ejecutará el script a nivel de sistema /etc/xdg/openbox/autostart.sh en caso contrario. Puedes colocar cualquier cosa que quieras ejecutar automáticamente en esos archivos, por ejemplo:

xsetroot -solid grey & 
gnome-settings-daemon &

Asegúrate de que cada línea esté seguida de un "&" o de lo contrario el script se detendrá allí y los comandos posteriores no se ejecutarán. Puedes usar el archivo /etc/xdg/openbox/autostart.sh como ejemplo para crear el tuyo.

El archivo /etc/xdg/openbox/autostart.sh predeterminado ejecuta una serie de cosas con Openbox.

Por último, si usas startx para iniciar tu sesión X, puedes configurar un archivo ~/.xinitrc para ejecutar openbox-session y seguir las mismas instrucciones anteriores con respecto al archivo autostart.sh.

Puedes usar la herramienta obconf para configurar Openbox fácilmente con una interfaz gráfica, sin embargo, es posible una configuración más detallada editando los archivos de configuración a mano.

Los archivos de configuración y menú predeterminados se instalan en /etc/xdg/openbox/, y la configuración del usuario se coloca en ~/.config/openbox/. Puedes copiar la configuración y los menús predeterminados a ~/.config/openbox/ y editarlos a tu gusto.

OPCIONES

Estas son las opciones posibles que acepta openbox:

--help
Muestra un resumen de las opciones de línea de comandos disponibles y sale.
--version
Muestra la versión del programa y sale.
--replace
Reemplaza el gestor de ventanas en ejecución actual.
--config-file ARCHIVO
Especifica la ruta al archivo de configuración a usar.
--reconfigure
Si Openbox ya se está ejecutando en la pantalla, pídele que recargue su configuración.
--restart
Si Openbox ya se está ejecutando en la pantalla, pídele que se reinicie. Esto es útil si has actualizado Openbox y no quieres reiniciar X.
--exit
Sale de Openbox.
--sm-disable
No se conecta al gestor de sesiones.
--sync
Ejecuta en modo síncrono (para depuración).
--startup CMD
Ejecuta CMD después de iniciar.
--debug
Muestra la salida de depuración.
--debug-focus
Muestra la salida de depuración para el manejo del foco.
--debug-session
Muestra la salida de depuración para la gestión de sesiones.
--debug-xinerama
Divide la pantalla en dos regiones xinerama falsas, si xinerama no está ya habilitado. Esto es para depurar el soporte xinerama.
