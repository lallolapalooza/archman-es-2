NOMBRE

ovdb_server - Servidor auxiliar de resumen para nnrpd

SINOPSIS

Use ovdb_init para iniciar ovdb_server

DESCRIPCIÓN

Si el parámetro readserver en ovdb.conf es true, ovdb_init (si no se invoca con el flag -r) iniciará tantos procesos ovdb_server como indique el parámetro numrsprocs.

ovdb_server abre la base de datos de resúmenes y accede a ella en nombre de los procesos lectores de nnrpd.

Para apagar ovdb_server, envíe una señal TERM al ID de proceso mencionado en ovdb_server.pid en pathrun (tenga en cuenta que el script rc.news ya lo hace si se usa para apagar INN). El proceso padre apagará a sus hijos y esperará su salida antes de salir él mismo.

HISTORIA
