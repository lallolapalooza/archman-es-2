Paquete: openssl

Licencias: Apache-2.0

OPENSSL-RSA(1ssl) OpenSSL OPENSSL-RSA(1ssl)

NOMBRE

openssl-rsa - comando de procesamiento de claves RSA

SINOPSIS

openssl rsa [-help] [-inform DER|PEM|P12|ENGINE] [-outform DER|PEM] [-in nombre_archivo|uri] [-passin arg] [-out nombre_archivo] [-passout arg] [-aes128] [-aes192] [-aes256] [-aria128] [-aria192] [-aria256] [-camellia128] [-camellia192] [-camellia256] [-des] [-des3] [-idea] [-text] [-noout] [-modulus] [-traditional] [-check] [-pubin] [-pubout] [-RSAPublicKey_in] [-RSAPublicKey_out] [-pvk-strong] [-pvk-weak] [-pvk-none] [-engine id] [-provider nombre] [-provider-path ruta] [-provparam [nombre:]clave=valor] [-propquery propq]

DESCRIPCIÓN

Este comando procesa claves RSA. Pueden ser convertidas entre varias formas y sus componentes pueden ser impresos.

OPCIONES

-help
Imprime un mensaje de uso.
-inform DER|PEM|P12|ENGINE
El formato de entrada de la clave; no especificado por defecto. Ver openssl-format-options(1) para detalles.
-outform DER|PEM
El formato de salida de la clave; el valor por defecto es PEM. Ver openssl-format-options(1) para detalles.
-traditional
Al escribir una clave privada, usa el formato PKCS#1 tradicional en lugar del formato PKCS#8.
-in nombre_archivo|uri
Especifica la entrada para leer una clave o la entrada estándar si esta opción no se especifica. Si la clave está cifrada se solicitará una contraseña.
-passin arg, -passout arg
La fuente de la contraseña para el archivo de entrada y salida. Para más información sobre el formato de arg ver openssl-passphrase-options(1).
-out nombre_archivo
Especifica el nombre del archivo de salida donde escribir una clave o la salida estándar si esta opción no se especifica. Si se establecen opciones de cifrado se solicitará una contraseña. El nombre del archivo de salida no debe ser el mismo que el nombre del archivo de entrada.
-aes128, -aes192, -aes256, -aria128, -aria192, -aria256, -camellia128, -camellia192, -camellia256, -des, -des3, -idea
Estas opciones cifran la clave privada con el cifrador especificado antes de volcarla. Se solicita una contraseña. Si no se especifica ninguna de estas opciones, la clave se escribe en texto plano. Esto significa que este comando puede ser usado para eliminar la contraseña de una clave no especificando ninguna opción de cifrado, o para añadir o cambiar la contraseña estableciéndolas. Estas opciones solo pueden ser usadas con archivos de salida en formato PEM.
-text
Imprime los varios componentes de la clave pública o privada en texto plano además de la versión codificada.
-noout
Esta opción previene la salida de la versión codificada de la clave.
-modulus
Esta opción imprime el valor del módulo de la clave.
-check
Esta opción comprueba la consistencia de una clave privada RSA.
-pubin
Por defecto se lee una clave privada de la entrada. Con esta opción se lee una clave pública en su lugar. Si la entrada no contiene una clave pública pero sí una clave privada, se utiliza su parte pública.
-pubout
Por defecto se vuelca una clave privada: con esta opción se volcará una clave pública en su lugar. Esta opción se establece automáticamente si la entrada es una clave pública.
-RSAPublicKey_in, -RSAPublicKey_out
Similar a -pubin y -pubout excepto que se usa el formato RSAPublicKey en su lugar.
-pvk-strong
Habilita el nivel de codificación PVK 'Strong' (por defecto).
-pvk-weak
Habilita el nivel de codificación PVK 'Weak'.
-pvk-none
No fuerza la codificación PVK.
-engine id
Ver "Opciones de Motor" en openssl(1). Esta opción está obsoleta.
-provider nombre
-provider-path ruta
-provparam [nombre:]clave=valor
-propquery propq
Ver "Opciones de Proveedor" en openssl(1), provider(7), y property(7).

NOTAS

El comando openssl-pkey(1) es capaz de realizar todas las operaciones que este comando puede, además de soportar otros tipos de clave pública.

EJEMPLOS

La documentación del comando openssl-pkey(1) contiene ejemplos equivalentes a los listados aquí.

Para eliminar la contraseña de una clave privada RSA:

openssl rsa -in clave.pem -out clave_salida.pem

Para cifrar una clave privada usando triple DES:

openssl rsa -in clave.pem -des3 -out clave_salida.pem

Para convertir una clave privada de formato PEM a DER:

openssl rsa -in clave.pem -outform DER -out clave_salida.der

Para imprimir los componentes de una clave privada a la salida estándar:

openssl rsa -in clave.pem -text -noout

Para solo volcar la parte pública de una clave privada:

openssl rsa -in clave.pem -pubout -out pub_clave.pem

Volcar la parte pública de una clave privada en formato RSAPublicKey:

openssl rsa -in clave.pem -RSAPublicKey_out -out pub_clave.pem

ERRORES

Debería haber una opción que maneje automáticamente archivos .key, sin tener que editarlos manualmente.

VER TAMBIÉN

HISTORIA
