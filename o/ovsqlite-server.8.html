NOMBRE

ovsqlite-server - Propietario único de la base de datos ovsqlite

SINOPSIS

ovsqlite-server [-d]

DESCRIPCIÓN

El demonio ovsqlite-server es el único programa que abre la base de datos SQLite de resúmenes. Acepta conexiones de las otras partes de INN que desean operar sobre los datos de resúmenes (innd, nnrpd, expireover, makehistory).

Por lo tanto, este demonio debe iniciarse antes de que cualquier otro proceso pueda acceder a la base de datos de resúmenes. ovsqlite-server es invocado normalmente de forma automática por rc.news al iniciar el sistema de noticias. También es detenido automáticamente por rc.news al detener el sistema de noticias.

En caso de que necesite hablar con este demonio desde Perl, el protocolo binario utilizado para comunicarse con él ha sido implementado en el módulo de Perl "INN::ovsqlite_client". Consulte su página del manual para obtener más información sobre sus posibilidades.

OPCIONES

-d
ovsqlite-server normalmente se pone en segundo plano, redirige su salida y error estándar a archivos de registro, y se desvincula de la terminal. Usar -d evita todo esto, resultando en que los mensajes de registro se escriban en la salida de error estándar; esto es generalmente útil solo para depuración.

ARCHIVOS

ruta-etc/ovsqlite.conf
El archivo de configuración. Ver ovsqlite(5).
ruta-resumenes/ovsqlite.db
El archivo de la base de datos SQLite.
ruta-run/ovsqlite.pid
Almacena el PID del proceso del servidor mientras se está ejecutando.
ruta-run/ovsqlite.sock
Cuando los sockets de dominio Unix están disponibles, el servidor enlaza su socket de escucha a esta ruta.
ruta-run/ovsqlite.port
Cuando los sockets de dominio Unix *no* están disponibles, el servidor enlaza su socket de escucha a un puerto TCP dinámico en la interfaz de loopback IPv4 y almacena el número de puerto en este archivo.

HISTORIA

Implementación inicial de ovsqlite escrita por Bo Lindbergh <2bfjdsla52kztwejndzdstsxl9athp@gmail.com> para InterNetNews.

VER TAMBIÉN

INN::ovsqlite_client(3pm), ovsqlite(5), rc.news(8).
