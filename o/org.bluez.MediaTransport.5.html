org.bluez.MediaTransport1
Ruta del objeto
[prefijo de variable]/{hci0,hci1,...}/dev_{BDADDR}/fd#

Métodos

fd, uint16, uint16 Acquire()

Adquiere el descriptor de archivo del transporte y la MTU para lectura y escritura respectivamente.

Errores posibles:

org.bluez.Error.NotAuthorized
org.bluez.Error.Failed

fd, uint16, uint16 TryAcquire()

Adquiere el descriptor de archivo del transporte solo si el transporte está en estado "pending" en el momento en que BlueZ recibe el mensaje. De lo contrario, no se enviará ninguna solicitud al dispositivo remoto y la función simplemente fallará con org.bluez.Error.NotAvailable.

Errores posibles:

org.bluez.Error.NotAuthorized
org.bluez.Error.Failed
org.bluez.Error.NotAvailable

void Release()

Libera el descriptor de archivo.

void Select()

Aplicable solo para transportes creados por un receptor de transmisión. Esto mueve el transporte de "idle" a "broadcasting".

Esto permite a los llamadores seleccionar a qué BIS sincronizarse a través de un proceso de 2 pasos:

1.
el usuario llama al método, cambiando el estado del transporte a broadcasting
2.
el servidor de audio detecta que el transporte está en estado 'broadcasting' y lo adquiere automáticamente

Errores posibles:

org.bluez.Error.NotAuthorized

void Unselect()

Aplicable solo para transportes creados por un receptor de transmisión. Esto mueve el transporte de "broadcasting" o "active" a "idle".

Esto permite a los llamadores finalizar la sincronización con un BIS a través de un proceso de 2 pasos:

1.
el usuario llama a este método, cambiando el estado del transporte a idle
2.
el servidor de audio detecta este evento y libera el transporte

Errores posibles:

org.bluez.Error.NotAuthorized

Propiedades

object Device [solo lectura]

Objeto del dispositivo al que está conectado el transporte.

string UUID [solo lectura]

UUID del perfil para el que es el transporte.

byte Codec [solo lectura]

Número asignado del códec que soporta el transporte.

Los valores deben coincidir con la especificación del perfil indicado por el UUID.

array{byte} Configuration [solo lectura]

Bloque de configuración, se usa tal cual, por lo que el tamaño y el orden de los bytes deben coincidir.

string State [solo lectura]

Indica el estado del transporte. Los valores posibles son:

"idle"
no transmitiendo
"pending"
transmitiendo pero no adquirido
"broadcasting"
transmitiendo pero no adquirido, aplicable solo para transportes creados por un receptor de transmisión
"active"
transmitiendo y adquirido

uint16 Delay [lectura/escritura, opcional]

Retraso del transporte en unidades de 1/10 de milisegundo; esta propiedad solo es escribible cuando el transporte corresponde a un punto final de receptor y ha sido adquirido por el emisor.

uint16 Volume [lectura/escritura, opcional]

Indica el nivel de volumen del transporte; esta propiedad solo es escribible cuando el transporte ha sido adquirido por el emisor.

Valores posibles:

0-127 (A2DP)
0-255 (BAP)

object Endpoint [solo lectura, opcional, experimental]

Objeto del punto final con el que está asociado el transporte.

uint32 Location [solo lectura, solo ISO, experimental]

Indica la Ubicación de Audio del transporte.

array{byte} Metadata [lectura/escritura, solo ISO, experimental]

Indica los metadatos del transporte.

array{object} Links [solo lectura, opcional, solo CIS, experimental]

Objetos de transporte vinculados con los que está asociado el transporte.

array{object} Links [lectura/escritura, solo BIS, experimental]

Para un receptor de transmisión, el procedimiento de sincronización BIG requiere que se enumeren todas las transmisiones deseadas desde el principio y no se puede reconfigurar posteriormente agregando o eliminando BIS.

Para evitar terminar y recrear la sincronización BIG cada vez que se selecciona un nuevo transporte para adquirir, todos los transportes seleccionados a través de Select deben vincularse.

Cuando se adquiere el primer transporte a través de Transport.Acquire, todos los enlaces se incluyen en el comando de sincronización BIG.

Un transporte adquirido creará y establecerá descriptores de archivo para todos sus enlaces. Luego, cada enlace debe adquirirse por separado para obtener el descriptor de archivo e iniciar la recepción de audio.

dict QoS [lectura/escritura, opcional, solo ISO, experimental]

Calidad de Servicio del transporte.

Name

org.bluez.MediaTransport

Interface

org.bluez.MediaTransport

This interface is used to configure the media transport.

Métodos

AcquireTransport
uint64 acquire_transport(dict options);
Acquires a new transport. The `options` dictionary can contain key-value pairs that are specific to the transport backend. If the transport is acquired successfully, it returns the object path of the new transport. Otherwise, it returns an error.
ReleaseTransport
void release_transport(uint64 transport);
Releases the transport specified by `transport`. This is typically called when the application no longer needs the transport.
SelectConfiguration
void select_configuration(string configuration);
Selects the desired configuration. The `configuration` string is a specific identifier for the configuration that should be used.
SetConfiguration
void set_configuration(string configuration);
Sets the transport configuration to the given `configuration`. The format of the configuration string is backend-specific.
