NOMBRE

ogrlineref - Crear referencia lineal y proporcionar algunos cálculos utilizándola.

SINOPSIS

ogrlineref [--help] [--help-general] [-progress] [-quiet]
           [-f <format_name>] [-dsco <NAME>=<VALUE>]... [-lco <NAME>=<VALUE>]...
           [-create]
           [-l <src_line_datasource_name>] [-ln <layer_name>] [-lf <field_name>]
           [-p <src_repers_datasource_name>] [-pn <layer_name>] [-pm <pos_field_name>] [-pf <field_name>]
           [-r <src_parts_datasource_name>] [-rn <layer_name>]
           [-o <dst_datasource_name>] [-on <layer_name>] [-of <field_name>] [-s <step>]
           [-get_pos] [-x <long>] [-y <lat>]
           [-get_coord] [-m <position>]
           [-get_subline] [-mb <position>] [-me <position>]

DESCRIPCIÓN

El programa ogrlineref se puede utilizar para:

  • crear un archivo de referencia lineal a partir de datos de entrada
  • devolver la distancia "referenciada linealmente" para la proyección de las coordenadas de entrada (punto) en la ruta
  • devolver las coordenadas (punto) en la ruta según la distancia "referenciada linealmente"
  • devolver la porción de la ruta según las distancias de inicio y fin "referenciadas linealmente"

La utilidad ogrlineref crea una referencia lineal - un archivo que contiene segmentos de una cierta longitud (por ejemplo, 1 km en unidades de referencia). El usuario puede obtener coordenadas, distancias referenciadas linealmente o sublíneas (subrutas) de este archivo. La utilidad no requiere los componentes M o Z en la geometría. Los resultados se pueden almacenar en cualquier formato compatible con OGR. También se escribe información en la salida estándar.

--help
Mostrar este mensaje de ayuda y salir
--help-general
Proporciona un breve mensaje de uso para las opciones genéricas de línea de comandos de GDAL y sale.
-progress
Mostrar progreso.
-quiet
Suprimir todos los mensajes excepto errores y resultados.
-f <nombre_formato>
Seleccionar un nombre de formato de salida. El valor predeterminado es crear un shapefile.
-dsco <NOMBRE>=<VALOR>
Opción de creación de conjunto de datos (específico del formato)
-lco <NOMBRE>=<VALOR>
Opción de creación de capa (específico del formato).
-create
Crear el archivo de referencia lineal (polilínea de partes).
-l <src_line_datasource_name>
La ruta a la fuente de datos de línea de entrada (por ejemplo, la carretera)
-ln <nombre_capa>
El nombre de la capa en la fuente de datos
-lf <nombre_campo>
El nombre del campo de valores únicos para separar las líneas de entrada (por ejemplo, el conjunto de carreteras).
-p <src_repers_datasource_name>
La ruta a los puntos de referencia lineales (por ejemplo, los hitos de la carretera)
-pn <nombre_capa>
El nombre de la capa en la fuente de datos
-pm <nombre_campo_pos>
El nombre del campo de distancias a lo largo de la ruta (por ejemplo, valores de hitos)
-pf <nombre_campo>
El nombre del campo de valores únicos para mapear los puntos de referencia de entrada a las líneas.
-r <src_parts_datasource_name>
La ruta al archivo de referencia lineal.
-rn <nombre_capa>
El nombre de la capa en la fuente de datos
-o <dst_datasource_name>
La ruta al archivo de referencia lineal de salida (fuente de datos de polilínea)
-on <nombre_capa>
El nombre de la capa en la fuente de datos
-of <nombre_campo>
El nombre del campo para almacenar los valores únicos de las líneas de entrada
-s <paso>
El tamaño de la parte en unidades lineales
-get_pos
Devolver la posición referenciada linealmente para X, Y de entrada
-x <longitud>
Coordenada X de entrada
-y <latitud>
Coordenada Y de entrada
-get_coord
Devolver punto en la ruta para la distancia lineal de entrada
-m <posición>
La distancia lineal de entrada
-get_subline
Devolver la porción de la ruta de entrada desde y hasta las posiciones lineales de entrada.
-mb <posición>
La distancia lineal de inicio de entrada
-me <posición>
La distancia lineal de fin de entrada

EJEMPLOS

Ejemplo 1

Este ejemplo crearía un shapefile (parts.shp) que contiene los datos necesarios para la referencia lineal (partes de 1 km):

ogrlineref -create -l roads.shp -p references.shp -pm dist -o parts.shp -s 1000 -progress
