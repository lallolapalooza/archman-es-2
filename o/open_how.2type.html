open_how(2type) open_how(2type)

NOMBRE

open_how - cómo abrir una ruta de acceso

BIBLIOTECA

Encabezados del kernel de Linux

SINOPSIS

#include <linux/openat2.h>
struct open_how {
    u64  flags;    /* Indicadores O_* */
    u64  mode;     /* Modo para O_{CREAT,TMPFILE} */
    u64  resolve;  /* Indicadores RESOLVE_* */
    /* ... */
};

DESCRIPCIÓN

Especifica cómo se debe abrir una ruta de acceso.

Los campos son los siguientes:

flags
Este campo especifica los indicadores de creación de archivos y de estado del archivo a usar al abrir el archivo.
mode
Este campo especifica el modo para el nuevo archivo.
resolve
Esta es una máscara de bits de indicadores que modifican la forma en que se resolverán *todos* los componentes de una ruta de acceso (ver path_resolution(7) para información de fondo).

ESTÁNDARES

Linux.

HISTORIA

Se pueden añadir campos adicionales a la estructura, con un valor cero en un nuevo campo que haga que el kernel se comporte como si ese campo de extensión no estuviera presente. Por lo tanto, un usuario *debe* poner a cero esta estructura al inicializarla.
