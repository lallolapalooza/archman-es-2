Descripción detallada

Esta página describe el proceso y las funciones utilizadas para decodificar Opus.

El proceso de decodificación también comienza creando un estado de decodificador. Esto se puede hacer con:

int          error;
OpusDecoder *dec;
dec = opus_decoder_create(Fs, channels, &error);


donde

  • Fs es la frecuencia de muestreo y debe ser 8000, 12000, 16000, 24000 o 48000
  • channels es el número de canales (1 o 2)
  • error contendrá el código de error en caso de fallo (o OPUS_OK en éxito)
  • el valor de retorno es un estado de decodificador recién creado para ser utilizado para la decodificación

Si bien opus_decoder_create() asigna memoria para el estado, también es posible inicializar memoria pre-asignada:

int          size;
int          error;
OpusDecoder *dec;
size = opus_decoder_get_size(channels);
dec = malloc(size);
error = opus_decoder_init(dec, Fs, channels);


donde opus_decoder_get_size() devuelve el tamaño requerido para el estado del decodificador. Tenga en cuenta que las versiones futuras de este código pueden cambiar el tamaño, por lo que no se deben hacer suposiciones al respecto.

El estado del decodificador es siempre continuo en memoria y solo una copia superficial es suficiente para copiarlo (por ejemplo, memcpy())

Para decodificar un fotograma, se debe llamar a opus_decode() u opus_decode_float() con un paquete de datos de audio comprimido:

frame_size = opus_decode(dec, packet, len, decoded, max_size, 0);


donde

  • packet es el array de bytes que contiene los datos comprimidos
  • len es el número exacto de bytes contenidos en el paquete
  • decoded son los datos de audio decodificados en opus_int16 (o float para opus_decode_float())
  • max_size es la duración máxima del fotograma en muestras (por canal) que cabe en el array decoded_frame

opus_decode() y opus_decode_float() devuelven el número de muestras (por canal) decodificadas del paquete. Si ese valor es negativo, ha ocurrido un error. Esto puede ocurrir si el paquete está corrupto o si el búfer de audio es demasiado pequeño para contener el audio decodificado.

Opus es un códec con estado y bloques superpuestos, y como resultado, los paquetes Opus no se codifican independientemente unos de otros. Los paquetes deben pasarse al decodificador de forma serial y en el orden correcto para una decodificación correcta. Los paquetes perdidos se pueden reemplazar con ocultación de pérdidas llamando al decodificador con un puntero nulo y longitud cero para el paquete faltante.

Un único estado de códec solo puede ser accedido por un único hilo a la vez y cualquier bloqueo requerido debe ser realizado por el llamador. Flujos separados deben ser decodificados con estados de decodificador separados y pueden ser decodificados en paralelo a menos que la biblioteca haya sido compilada con NONTHREADSAFE_PSEUDOSTACK definido.

int opus_decode (OpusDecoder * st, const unsigned char * data, opus_int32 len, opus_int16 * pcm, int frame_size, int decode_fec)

Decodifica un paquete Opus.

Parámetros

st OpusDecoder*: Estado del decodificador
data char*: Payload de entrada. Usar un puntero NULL para indicar pérdida de paquete
len opus_int32: Número de bytes en el payload*
pcm opus_int16*: Señal de salida (intercalada si son 2 canales). la longitud es frame_size*channels*sizeof(opus_int16)
frame_size Número de muestras por canal del espacio disponible en pcm. Si esto es menor que la duración máxima del paquete (120 ms; 5760 para 48 kHz), esta función no será capaz de decodificar algunos paquetes. En el caso de PLC (data==NULL) o FEC (decode_fec=1), entonces frame_size necesita ser exactamente la duración del audio que falta, de lo contrario el decodificador no estará en el estado óptimo para decodificar el siguiente paquete entrante. Para los casos de PLC y FEC, frame_size debe ser un múltiplo de 2.5 ms.
decode_fec int: Indicador (0 o 1) para solicitar que se decodifiquen los datos de corrección de errores hacia adelante dentro de la banda. Si no hay tales datos disponibles, el fotograma se decodifica como si se hubiera perdido.

Devuelve

Número de muestras decodificadas o Códigos de error

DESCRIPTION

These functions perform decoding of Opus audio data. The decoder state structure is opaque to the user. For all functions below, the decoder state must be valid. Use opus_decoder_create() to allocate and initialize a state, and opus_decoder_destroy() to free it. If you cannot use malloc, use opus_decoder_get_size() and opus_decoder_init() instead.

opus_decode

Decodes an Opus packet into 16-bit PCM samples.

Parameters

st OpusDecoder*: Decoder state
data char*: Input payload. Use a NULL pointer to indicate packet loss
len opus_int32: Number of bytes in payload
pcm opus_int16*: Output signal (interleaved if 2 channels). Length is frame_size*channels*sizeof(opus_int16)
frame_size Number of samples per channel of available space in pcm. If this is less than the maximum packet duration (120ms; 5760 for 48kHz), this function will not be capable of decoding some packets. In the case of PLC (data==NULL) or FEC (decode_fec=1), then frame_size needs to be exactly the duration of audio that is missing, otherwise the decoder will not be in the optimal state to decode the next incoming packet. For the PLC and FEC cases, frame_size must be a multiple of 2.5 ms.
decode_fec int: Flag (0 or 1) to request that any in-band forward error correction data be decoded. If no such data is available the frame is decoded as if it were lost.

Returns

Number of decoded samples or Error codes

OpusDecoder * opus_decoder_create (opus_int32 Fs, int channels, int * error)

Allocates and initializes a decoder state.

Parameters

Fs opus_int32: Sample rate to decode at (Hz). This must be one of 8000, 12000, 16000, 24000, or 48000.
channels int: Number of channels (1 or 2) to decode
error int*: OPUS_OK Success or Error codes

Internally Opus stores data at 48000 Hz, so that should be the default value for Fs. However, the decoder can efficiently decode to buffers at 8, 12, 16, and 24 kHz so if for some reason the caller cannot use data at the full sample rate, or knows the compressed data doesn't use the full frequency range, it can request decoding at a reduced rate. Likewise, the decoder is capable of filling in either mono or interleaved stereo pcm buffers, at the caller's request.

int opus_decoder_init (OpusDecoder * st, opus_int32 Fs, int channels)

Initializes a previously allocated decoder state. The state must be at least the size returned by opus_decoder_get_size(). This is intended for applications which use their own allocator instead of malloc.

void opus_pcm_soft_clip (float * pcm, int frame_size, int channels, float * softclip_mem)

Aplica suavizado de clipping para llevar una señal flotante al rango [-1,1]. Si la señal ya está en ese rango, no se hace nada. Si hay valores fuera de [-1,1], entonces la señal se recorta de la manera más suave posible para que encaje en el rango y evite crear una distorsión excesiva en el proceso.

Parámetros

pcm float*: Entrada PCM y PCM modificado
frame_size int Número de muestras por canal a procesar
channels int: Número de canales
softclip_mem float*: Memoria de estado para el proceso de suavizado de clipping (un flotante por canal, inicializado a cero)
