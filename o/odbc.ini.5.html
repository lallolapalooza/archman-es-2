NOMBRE

/etc/odbc.ini, $HOME/.odbc.ini - archivos de configuración de fuentes de datos de unixODBC

DESCRIPCIÓN

/etc/odbc.ini es un archivo de configuración a nivel de sistema para Nombres de Fuentes de Datos (DSN) ODBC.

$HOME/.odbc.ini es un archivo de configuración específico del usuario para Nombres de Fuentes de Datos (DSN) ODBC.

Las rutas a ambos archivos de configuración pueden ser anuladas por las opciones de compilación de unixODBC. Ejecute odbcinst -j para determinar las rutas de los archivos de configuración predeterminados en su sistema.

NOTAS

Plantillas

Muchos controladores ODBC vienen con plantillas de archivos .ini. Se recomienda utilizar odbcinst para instalar estas plantillas.

FORMATO DEL ARCHIVO

odbc.ini sigue la convención de sintaxis de archivos ini pseudo-estándar de uno o más [encabezados de sección], cada uno seguido de cero o más atributos clave = valor.

Sección [ODBC Data Sources]

Esta sección obligatoria enumera cada nombre de fuente de datos (DSN) como una clave. Los valores asociados sirven como comentarios. Cada entrada debe coincidir con una [sección] del archivo ini que describe la fuente de datos.

Nombre de fuente de datos [sección]

Cada fuente de datos se identifica por un [encabezado de sección], que es el nombre DSN utilizado por las aplicaciones. Cada sección de definición de DSN puede contener valores para las claves:

• Driver (OBLIGATORIO)
El nombre del controlador ODBC a utilizar para el DSN. El nombre debe coincidir exactamente con el [nombre de sección] de la definición del controlador almacenada en odbcinst.ini (y listada por odbcinst -q -d).
• Description
Descripción de la fuente de datos legible por humanos.
• Database
Nombre o identificador de la base de datos. El significado es específico del controlador y puede especificar una ruta de archivo, una ruta de socket Unix, un identificador relativo a un nombre de servidor, etc.
• Servername
Nombre del servidor. El significado es específico del controlador, pero generalmente especifica un nombre DNS, una dirección de red IP o un identificador de descubrimiento específico del controlador.
Para obtener una lista completa de los parámetros compatibles, consulte el "Manual del administrador" en formato HTML que se incluye con unixODBC, la documentación de su controlador ODBC y cualquier plantilla de fuente de datos proporcionada por su controlador.
