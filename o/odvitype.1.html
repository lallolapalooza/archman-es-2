DVITYPE(1) Manual de Comandos Generales DVITYPE(1)

NOMBRE

dvitype, odvitype - traduce un archivo dvi para humanos

SINOPSIS

dvitype nombre_dvi[.dvi]

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se puede encontrar en el archivo info o en el manual Web2C: Una implementación de TeX.

El programa dvitype traduce un archivo DVI (DeVice Independent) generado por (por ejemplo) tex(1) o gftodvi(1), a un archivo que los humanos pueden leer. También sirve como programa de validación de archivos DVI (es decir, si dvitype puede leerlo, es correcto) y como ejemplo de programa de lectura de DVI para futuros controladores de dispositivos.

El archivo de salida puede incluir todos los comandos, solo los importantes, o ninguno en absoluto (en cuyo caso solo se informan errores). Se puede seleccionar un subintervalo de páginas para la transliteración; la magnificación y la resolución del ``dispositivo de salida'' pueden cambiarse; y así sucesivamente. Todas las opciones se especifican mediante un diálogo en línea.

La extensión .dvi se suministra si se omite de nombre_dvi. La salida va a stdout.

OPCIONES

-dpi=REAL
Establece la resolución a REAL píxeles por pulgada; por defecto 300.0.
-magnification=NÚMERO
Anula la magnificación existente con NÚMERO.
-max-pages=NÚMERO
Procesa NÚMERO páginas; por defecto un millón.
-output-level=NÚMERO
Nivel de verbosidad, de 0 a 4; por defecto 4.
-page-start=ESPEC-PÁGINA
Comienza en ESPEC-PÁGINA, por ejemplo `2' o `5.*.-2'.
-show-opcodes
Muestra los opcodes numéricos (en decimal).

ENTORNO

La variable de entorno TEXFONTS se utiliza para buscar los archivos TFM utilizados en el archivo DVI. Consulte tex(1) para obtener detalles sobre la búsqueda. Si TEXFONTS no está configurado, utiliza el valor predeterminado del sistema.

VER TAMBIÉN

gftype(1), pktype(1).
Donald E. Knuth, TeXware.

AUTORES
