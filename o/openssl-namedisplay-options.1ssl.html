NOMBRE

openssl-namedisplay-options - Opciones de visualización de nombres distinguidos

SINOPSIS

openssl comando [ opciones ... ] [ parámetros ... ]

DESCRIPCIÓN

OpenSSL proporciona un control detallado sobre cómo se muestran los DN de sujeto y emisor. Esto se especifica utilizando la opción -nameopt, que toma una lista separada por comas de opciones del siguiente conjunto. Una opción puede ir precedida por un signo de menos, "-", para desactivarla. Los primeros cuatro argumentos de opción son los más utilizados.

El valor predeterminado es "esc_ctrl,utf8,dump_unknown,dump_der,sep_comma_plus_space,sname".

OPCIONES

Argumentos de opción de formato de nombre

El formato de salida del DN se puede ajustar con las siguientes banderas.

compat
Muestra el nombre utilizando un formato antiguo de versiones anteriores de OpenSSL.
RFC2253
Muestra el nombre utilizando el formato definido en RFC 2253. Es equivalente a esc_2253, esc_ctrl, esc_msb, utf8, dump_nostr, dump_unknown, dump_der, sep_comma_plus, dn_rev y sname.
oneline
Muestra el nombre en una sola línea, utilizando un formato más legible que RFC 2253. Es equivalente a las opciones esc_2253, esc_ctrl, esc_msb, utf8, dump_nostr, dump_der, use_quote, sep_comma_plus_space, space_eq y sname.
multiline
Muestra el nombre en varias líneas. Es equivalente a las opciones esc_ctrl, esc_msb, sep_multiline, space_eq, lname y align.
esc_2253
Escapa los caracteres "especiales" en un campo, según lo requerido por RFC 2253. Es decir, cualquiera de los caracteres ",+"<>;", "#" al principio de una cadena y espacios al principio o al final.
esc_2254
Escapa los caracteres "especiales" en un campo según lo requerido por RFC 2254. Es decir, el carácter NUL y "()*".
esc_ctrl
Escapa los caracteres ASCII no imprimibles, códigos menores que 0x20 (espacio) o mayores que 0x7F (DELETE). Se muestran utilizando la notación RFC 2253 "\XX" donde XX son los dos dígitos hexadecimales que representan el valor del carácter.
esc_msb
Escapa cualquier carácter con el bit más significativo establecido, es decir, con valores mayores que 127, como se describe en esc_ctrl.
use_quote
Escapa algunos caracteres rodeando toda la cadena con comillas, """. Sin esta opción, caracteres especiales individuales van precedidos por una barra invertida, "\".
utf8
Convierte todas las cadenas a formato UTF-8 primero, según lo requerido por RFC 2253. Si el dispositivo de salida es compatible con UTF-8, entonces usar esta opción (y no establecer esc_msb) puede dar la visualización correcta de caracteres multibyte. Si esta opción no está configurada, entonces los caracteres multibyte mayores que 0xFF se mostrarán como "\UXXXX" para 16 bits o "\WXXXXXXXX" para 32 bits. Además, cualquier UTF8Strings se convertirá primero a su forma de carácter.
ignore_type
Esta opción no intenta interpretar caracteres multibyte de ninguna manera. Es decir, los octetos de contenido simplemente se volcán como si un octeto representara cada carácter. Esto es útil para fines de diagnóstico pero resultará en una salida bastante extraña.
show_type
Muestra el tipo de cadena de caracteres ASN1 antes del valor, como "BMPSTRING: Hola Mundo".
dump_der
Cualquier campo que se mostraría en formato hexadecimal se mostrará utilizando la codificación DER del campo. Si no está configurado, solo se muestran los octetos de contenido. En cualquier caso, se utiliza el formato #XXXX... de RFC 2253.
dump_nostr
Volca cadenas que no son de caracteres, como OCTET STRING de ASN.1. Si esta opción no está configurada, los tipos de cadena que no son de caracteres se mostrarán como si cada octeto de contenido representara un solo carácter.
dump_all
Volca todos los campos. Cuando se utiliza junto con dump_der, esto permite determinar de forma inequívoca la codificación DER de la estructura.
dump_unknown
Volca cualquier campo cuyo OID no sea reconocido por OpenSSL.
sep_comma_plus, sep_comma_plus_space, sep_semi_plus_space, sep_multiline
Especifica los separadores de campo. La primera palabra se utiliza entre los Nombres Distinguidos Relativos (RDN) y la segunda entre múltiples Afirmaciones de Valor de Atributo (AVA). Las AVAs múltiples son muy raras y su uso se desaconseja. Las opciones que terminan en "space" colocan adicionalmente un espacio después del separador para hacerlo más legible. El sep_multiline comienza cada campo en su propia línea y utiliza "más espacio" para el separador AVA. También indenta los campos con cuatro caracteres. El valor predeterminado es sep_comma_plus_space.
dn_rev
Invierte los campos del DN según lo requerido por RFC 2253. Esto también invierte el orden de las AVAs múltiples en un campo, pero esto es permisible ya que no hay ordenación en los valores.
nofname, sname, lname, oid
Especifica cómo se muestra el nombre del campo. nofname no muestra el campo en absoluto. sname utiliza la forma de "nombre corto" (CN para commonName, por ejemplo). lname utiliza la forma larga. oid representa el OID en forma numérica y es útil para fines de diagnóstico.
align
Alinea los valores de campo para una salida más legible. Solo utilizable con sep_multiline.
space_eq
Coloca espacios alrededor del signo igual, "=", carácter que sigue al nombre del campo.
