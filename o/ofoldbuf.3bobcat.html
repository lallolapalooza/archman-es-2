FBB::OFoldBuf(3bobcat) Dobla líneas largas FBB::OFoldBuf(3bobcat)

NOMBRE

FBB::OFoldBuf - Dobla líneas largas escritas a ostream

SINOPSIS

#include <bobcat/ofoldbuf>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

FBB::OFoldBuf es una especialización de FBB::OFilterBuf que dobla líneas largas escritas a un objeto std::ostream. El OFoldBuf escribe las líneas (dobladas) a un segundo ostream (el stream de destino que es utilizado o abierto por el objeto OFoldBuf).

Internamente, el OFoldBuf define sus acciones utilizando una pequeña máquina de estados finitos que distingue tres estados (INDENT, WS y NON_WS) y tres categorías de caracteres (\n, otros caracteres de espacio en blanco (espacio), y caracteres que no son espacio). Las nueve combinaciones resultantes de estos dos conjuntos se discuten a continuación.

Los objetos OFoldBuf nunca doblarán líneas en medio de una serie de caracteres no en blanco (llamada `palabra’ abajo) sino que siempre romperán una línea en un carácter de espacio en blanco. Las líneas resultantes siempre aparecerán a la derecha de un margen izquierdo configurable y a la izquierda de un margen derecho configurable. Existe una excepción algo patológica: si una palabra es demasiado larga para caber entre los márgenes, entonces la palabra excederá el margen derecho.

La indentación utilizada para los márgenes izquierdos es configurable a espacios (por defecto) o tabulaciones. Cuando se utilizan tabulaciones, el ancho de un carácter de tabulación es configurable, utilizando un valor por defecto de 8 posiciones en el stream de destino.

Lo que sigue es una descripción de la Máquina de Estados Finitos (FSA) que define lo que sucede cuando varios tipos de caracteres aparecen en sus tres estados. La frase `... se escribe’ significa que la información descrita se escribe en el ostream utilizado o abierto por el objeto OFoldBuf. El estado inicial de OFoldBuf es INDENT:

HEREDA DE

FBB::OFilterBuf

ENUMERACIÓN

La enumeración TabsOrBlanks se utiliza para seleccionar tabulaciones o espacios al escribir la indentación. El valor por defecto es espacios. Cuando se seleccionan tabulaciones, el ancho de visualización de los caracteres de tabulación también se puede configurar (utilizando el valor por defecto de 8 posiciones para cada carácter de tabulación). La enumeración tiene dos valores:

o
BLANKS:
El valor por defecto, que indica que el margen izquierdo se especifica y se escribe como un número de espacios en blanco;
o
TABS:
Que indica que el margen izquierdo se especifica y se escribe como un número de caracteres de tabulación.

La enumeración TrailingBlanks se utiliza para configurar el objeto OFoldBuf con respecto a los espacios en blanco finales que puedan aparecer en la última línea. Estos espacios en blanco finales pueden aparecer en la última línea si no está terminada correctamente con un carácter de nueva línea sino que termina en espacio en blanco. Por defecto, estos caracteres de espacio en blanco se ignoran, pero también pueden conservarse. La enumeración tiene dos valores:

o
IGNORE_TRAILING_BLANKS:
Esto indica que los espacios en blanco finales que aparecen en la última línea si no está terminada por una nueva línea no deben escribirse en el std::ostream de destino. Este es el valor por defecto utilizado por los objetos OFoldBuf.
o
KEEP_TRAILING_BLANKS:
Esto indica que los espacios en blanco finales en la última línea si no está terminada por una nueva línea deben escribirse en el std::ostream de destino.

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

ofoldbuf(3bobcat) — Bobcat 6.06.02

NAME

ofoldbuf

output folder buffer

SYNOPSIS

    #include <bobcat/ofoldbuf>

    namespace FBB
    {
        class OFoldBuf: public std::ostreambuf
        {
            public:
                enum { TAB = 8 };

                OFoldBuf(std::ostream& stream, size_t leftMargin = 0,
                         size_t rightMargin = 78, size_t tabSize = TAB);
                OFoldBuf(std::ostreambuf* buf, size_t leftMargin = 0,
                         size_t rightMargin = 78, size_t tabSize = TAB);
                ~OFoldBuf();

                OFoldBuf& lm(size_t lm);
                OFoldBuf& mlm(size_t mlm);
                OFoldBuf& rm(size_t rm);
                OFoldBuf& tab(size_t tabSize);

                static size_t leftMargin(std::ostreambuf const* buffer);
                static size_t rightMargin(std::ostreambuf const* buffer);
        };
    }

DESCRIPTION

The OFoldBuf class is an extension of std::ostreambuf. It automatically folds lines exceeding a specified line length. The OFoldBuf class wraps an existing output stream buffer, inserting lines breaks where necessary. Lines are folded at spaces or tabs.

The OFoldBuf constructor takes the following arguments:

stream
The output stream whose buffer is to be wrapped.
buf
The output stream buffer to be wrapped.
leftMargin
The number of characters to indent the first line of text. Defaults to 0.
rightMargin
The maximum width of the output lines. Defaults to 78.
tabSize
The display width of a tab character. Defaults to 8.

The lm(), mlm(), rm(), and tab() members allow the margins and tab size to be modified dynamically.

The lm() member sets the left margin. The mlm() member sets the relative left margin. It is added to the left margin. The rm() member sets the right margin. The tab() member sets the tab size.

Each of these members returns a reference to the OFoldBuf object itself, allowing them to be chained.

NAMESPACE

FBB

INHERITS FROM

std::ostreambuf

ENUMERATION

o
size_t TAB = 8:
This member can be used to select tab-characters to be used when inserting left margins. The second parameter is used to specify the display width of a tab-character.

STATIC MEMBER FUNCTIONS

o
size_t leftMargin(std::ostreambuf const *buffer):
This member returns the current left margin setting of the OFoldBuf object passed to it as its argument. The member defines a std::streambuf parameter which is down cast to an OFoldBuf and an FBB::Exception exception is thrown if that cast fails.
o
size_t rightMargin(std::ostreambuf const *buffer):
This member returns the current right margin setting of the OFoldBuf object passed to it as its argument. The member’s parameter is down cast in the same way as leftMargin()’s argument: an FBB::Exception exception is thrown if that cast fails.

EXAMPLE

    #include <iostream>
    #include <ostream>
    #include <string>
    #include <bobcat/ofoldbuf>
    using namespace std;
    using namespace FBB;
    int main()
    {
        OFoldBuf fb(cout, 4, 40);
        ostream out(&fb);
        out << lm(4);
        string line;
        while (getline(cin, line))
            out << line << ’\n’;
    }
