Nombre

org.bluez.obex.Message - Documentación de la API de Mensajes OBEX de BlueZ D-Bus

Interfaz

Servicio
org.bluez.obex
Interfaz
org.bluez.obex.Message1
Ruta del objeto
[ruta del objeto de sesión]/message{#}

Métodos

objeto, diccionario Get(cadena archivodestino, booleano adjunto)

Descarga el mensaje y lo almacena en el archivo de destino.

Si se proporciona un archivo de destino vacío, se generará automáticamente un archivo temporal.

La ruta devuelta representa la transferencia recién creada, que debe utilizarse para saber si el contenido se ha transferido correctamente o si la operación falla.

Las propiedades de esta transferencia también se devuelven junto con la ruta del objeto, para evitar una llamada a GetProperties, consulte org.bluez.obex.Transfer(5) para obtener la lista posible de propiedades.

Errores posibles:

org.bluez.obex.Error.ArgumentosInvalidos
org.bluez.obex.Error.Fallo
