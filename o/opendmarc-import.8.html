NOMBRE

opendmarc-import - Herramienta de importación de datos de informes agregados de OpenDMARC

SINOPSIS

opendmarc-import [opciones]

DESCRIPCIÓN

opendmarc-import lee los datos por mensaje registrados por una instancia de opendmarc(8) y los inserta en una base de datos SQL, para su posterior uso por opendmarc-reports(8) para generar informes agregados.

OPCIONES

--dbhost=hostname
Especifica el nombre del host en el que se está ejecutando el servidor SQL. Por defecto, utiliza el valor de la variable de entorno OPENDMARC_DBHOST, o "localhost" si la variable de entorno no está establecida.
--dbname=nombre
Especifica el nombre de la base de datos SQL a la que se accederá. Por defecto, utiliza el valor de la variable de entorno OPENDMARC_DB, o "opendmarc" si la variable de entorno no está establecida.
--dbpasswd=contraseña
Especifica la contraseña para la base de datos SQL a la que se accederá. Por defecto, utiliza el valor de la variable de entorno OPENDMARC_PASSWORD, o "opendmarc" si la variable de entorno no está establecida.
--dbport=puerto
Especifica el puerto TCP en el que se espera que el servidor SQL esté escuchando. Por defecto, utiliza el valor de la variable de entorno OPENDMARC_PORT, o 3306 si la variable de entorno no está establecida.
--dbuser=usuario
Especifica el usuario SQL que se utilizará para acceder a la base de datos. Por defecto, utiliza el valor de la variable de entorno OPENDMARC_USER, o "opendmarc" si la variable de entorno no está establecida.
--help
Imprime un mensaje de ayuda y termina.
--input=archivo
Lee del archivo especificado en lugar de la entrada estándar (el valor por defecto).
--verbose
Aumenta la cantidad de información detallada que se escribe en la salida estándar.
--version
Imprime el número de versión y sale.
