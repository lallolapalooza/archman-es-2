NOMBRE

oath_done - función de la API

SINOPSIS

#include <oath.h>

int oath_done( void);

ARGUMENTOS

void

DESCRIPCIÓN

Esta función desinicializa la biblioteca OATH, que fue inicializada usando oath_init(). Después de llamar a esta función, ninguna otra función de la biblioteca OATH puede ser llamada excepto para reinicializar la biblioteca usando oath_init().

VALOR DEVUELTO

En caso de éxito, se devuelve OATH_OK (cero), de lo contrario se devuelve un código de error.
