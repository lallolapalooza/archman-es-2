NOMBRE

oath_base32_encode - función de la API

SINOPSIS

#include <oath.h>

int oath_base32_encode(const char * in, size_t inlen, char ** out, size_t * outlen);

ARGUMENTOS

const char * in
cadena de entrada con datos binarios de longitud inlen
size_t inlen
longitud de los datos de entrada in
char ** out
puntero a una cadena de salida recién asignada de longitud outlen, o NULL
size_t * outlen
puntero a la variable de salida que contiene la longitud de out, o NULL

DESCRIPCIÓN

Codifica datos binarios en una cadena con datos base32.

El parámetro in debe contener inlen bytes de datos a codificar. La función asigna una nueva cadena en *out para contener los datos codificados y establece *outlen a la longitud de los datos. La cadena de salida *out está terminada en nulo (ASCII NUL), pero el NUL no se cuenta en *outlen.

Si out es NULL, entonces *outlen se establecerá a lo que habría sido la longitud de *out en caso de una codificación exitosa.

Si el llamador no está interesado en conocer la longitud de los datos de salida out, entonces outlen puede establecerse a NULL.

Está permitido pero inútil tener tanto out como outlen NULL.

DEVUELVE

En caso de éxito, se devuelve OATH_OK (cero). Se devuelve OATH_BASE32_OVERFLOW si la salida fuera demasiado grande para almacenarla, y OATH_MALLOC_ERROR si hay errores de asignación de memoria.
