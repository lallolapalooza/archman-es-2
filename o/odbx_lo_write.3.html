odbx_lo_write(3)

Paquete: opendbx

Licencias: LGPL

odbx_lo_write(3) OpenDBX odbx_lo_write(3)

NOMBRE

odbx_lo_write - Escribe el contenido del búfer en el objeto grande

SINOPSIS

#include <opendbx/api.h>


ssize_t odbx_lo_write
(odbx_lo_t* lo, void* buffer, size_t buflen);

DESCRIPCIÓN

odbx_lo_write() envía los datos proporcionados en el búfer al servidor para almacenarlos dentro del objeto grande. La función se puede llamar más de una vez para agregar partes subsiguientes del contenido al objeto. Si no se trata de un objeto nuevo o vacío, los datos existentes se sobrescribirán y se truncarán al nuevo tamaño. No es posible actualizar solo partes del contenido, ya que algunas bases de datos no admiten la posición del indicador de posición del archivo interno.

El parámetro lo debe ser el manejador del objeto grande creado y devuelto por odbx_lo_open() a través de su segundo parámetro. Se invalida después de haber sido proporcionado a odbx_lo_close() y esta función devolverá un error en este caso. Los datos que se enviarán al servidor se leen de buffer hasta buflen bytes.

VALOR DE RETORNO

odbx_lo_write() devuelve el número de bytes leídos de buffer y enviados al servidor de la base de datos, que puede ser hasta buflen bytes. No se garantiza que el fragmento completo se envíe al servidor, por lo que el tamaño devuelto puede ser menor que el valor en buflen. En caso de error, se devuelve un código cuyo valor es menor que cero si una de las operaciones no pudo completarse con éxito. Los posibles códigos de error se enumeran en la sección de errores y se pueden alimentar a odbx_error() y odbx_error_type() para obtener más detalles.

ERRORES

-ODBX_ERR_BACKEND
La biblioteca de base de datos nativa no pudo escribir en el objeto grande correctamente
-ODBX_ERR_HANDLE
lo es NULL o el manejador del objeto grande proporcionado es inválido

VER TAMBIÉN

odbx_lo_open(), odbx_lo_close()
