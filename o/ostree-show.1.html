NOMBRE

ostree-show - Muestra un objeto de metadatos

SINOPSIS

ostree show [OPCIONES...] {OBJETO}

DESCRIPCIÓN

Dado un objeto, muestra los metadatos de ese objeto. Para una revisión particular, mostrará los datos del commit más reciente de esa revisión.

OPCIONES

--print-related

Muestra los commits "relacionados".

--print-variant-type="TIPO"

Mapea en memoria OBJETO (en este caso un nombre de archivo) a la cadena de tipo GVariant.

--list-metadata-keys

Lista las claves de metadatos disponibles.

--print-metadata-key="CLAVE"

Muestra el valor de cadena de la clave de metadatos.

--list-detached-metadata-keys

Lista las claves de metadatos desvinculados disponibles.

--print-detached-metadata-key="CLAVE"

Muestra el valor de cadena de la clave de metadatos desvinculado.

--print-sizes

Muestra los metadatos de tamaño del commit. Esto solo se admite para commits que contienen metadatos de ostree.sizes. Esto se puede incluir al crear commits con ostree commit --generate-sizes.

--raw

Muestra datos de variante en bruto.

--gpg-homedir="HOMEDIR"

Directorio de inicio de GPG a usar al buscar llaveros (si se tiene GPGME - GNU Privacy Guard Made Easy).

EJEMPLO

$ ostree show my-branch

        commit 67e382b11d213a402a5313e61cbc69dfd5ab93cb07
        Date:  2014-06-12 13:42:54 +0000
