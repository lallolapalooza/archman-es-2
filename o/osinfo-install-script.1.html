NOMBRE

osinfo-install-script - genera un script para instalación automatizada

SINOPSIS

osinfo-install-script [OPCIONES...] ARCHIVO-MEDIO|ID-SO

DESCRIPCIÓN

Genera un script adecuado para realizar una instalación automatizada de "ARCHIVO_MEDIO" o "ID-SO". "ARCHIVO_MEDIO" debe ser una ruta a un instalador o medio de arranque (típicamente un archivo ISO). "ID-SO" debe ser una URI que identifique el sistema operativo, o su ID corto.

Por defecto, se generará un script para una instalación estilo "JEOS".

OPCIONES

--profile=NOMBRE
Elige el perfil del script de instalación. Por defecto es "jeos", pero también puede ser "desktop", o un nombre de perfil específico del sitio.
--installation-source=NOMBRE
Establece la fuente de instalación que se utilizará con el script de instalación. Por defecto es "media", pero también puede ser "network".
--config=clave=valor
Establece el parámetro de configuración "clave" a "valor".
--config-file=archivo-configuracion
Establece los parámetros de configuración de acuerdo con el archivo de configuración proporcionado.

Tenga en cuenta que el uso de --config-file se recomienda encarecidamente si se necesitan establecer contraseñas de usuario o administrador. Proporcionar contraseñas directamente usando --config= es inseguro ya que la contraseña es visible para todos los procesos y usuarios en el mismo host.

CLAVES DE CONFIGURACIÓN

Las siguientes claves de configuración están disponibles:

"hardware-arch"
La arquitectura de hardware
"l10n-timezone"
La zona horaria local
"l10n-keyboard"
La distribución del teclado local
"l10n-language"
El idioma local
"admin-password"
La contraseña del administrador. Esta opción ha sido deprecada, use --config-file para establecer la contraseña del administrador.
"user-password"
La contraseña del usuario. Esta opción ha sido deprecada, use --config-file para establecer la contraseña del usuario.
"user-login"
El nombre de inicio de sesión del usuario
"user-realname"
El nombre real del usuario
"user-autologin"
Si se debe iniciar sesión automáticamente para el usuario
"user-admin"
Si se deben otorgar privilegios de administrador al usuario
"reg-product-key"
La clave de registro del software
"reg-login"
El nombre de usuario del registro del software
"reg-password"
La contraseña del usuario del registro del software

FORMATO DEL ARCHIVO DE CONFIGURACIÓN

El archivo de configuración debe consistir en un archivo que contenga un grupo "install-script" y, debajo de este grupo, pares de "clave"="valor", como se muestra a continuación:

[install-script]
l10n-timezone=GMT
l10n-keyboard=uk
l10n-language=en_GB
admin-password=123456
user-login=berrange
user-password=123456
user-realname="Daniel P Berrange"

USO DE EJEMPLO

Los siguientes usos generan un script kickstart de Fedora 30:

# osinfo-install-script \
       --profile jeos \
       --config-file /ruta/al/archivo/de/configuracion \
       fedora30
# osinfo-install-script \
       --profile jeos \
       --config l10n-timezone=GMT \
       --config l10n-keyboard=uk \
       --config l10n-language=en_GB \
       --config admin-password=123456 \
       --config user-login=berrange \
       --config user-password=123456 \
       --config user-realname="Daniel P Berrange" \
       fedora30

ESTADO DE SALIDA

El estado de salida será 0 si se genera un script de instalación, o 1 en caso de error.
