NOMBRE

opendmarc-params - Herramienta de configuración de parámetros de informes de OpenDMARC

SINOPSIS

opendmarc-params [opciones] dominio

DESCRIPCIÓN

opendmarc-params registra una dirección de informes específica para informes agregados sobre el dominio especificado y la marca como "bloqueada" en la base de datos de solicitudes de informes. Esto se hace para permitir que un administrador fuerce la generación de informes y que se envíen a una dirección específica independientemente de los datos que se encuentren (o no) en el DNS para el dominio especificado.

OPCIONES

--dbhost=host
Intenta conectarse al servidor de base de datos en el host especificado. El valor predeterminado es "localhost".
--dbname=name
Solicita una conexión a la base de datos llamada name. El valor predeterminado es "opendmarc".
--dbpasswd=password
Intenta autenticarse en el servidor de base de datos utilizando la contraseña especificada. El valor predeterminado es "opendmarc".
--dbport=port
Intenta conectarse a la base de datos en el puerto TCP especificado. El valor predeterminado es 3306.
--dbuser=user
Intenta autenticarse en el servidor de base de datos como el usuario especificado. El valor predeterminado es "opendmarc".
--help
Imprime un mensaje de uso y sale.
--rua=string
Establece la URI de informes para el dominio especificado a la cadena proporcionada.
--unlock
Desbloquea el registro para el dominio especificado.
--verbose
Solicita una salida detallada.
--version
Imprime el número de versión y sale.

VERSIÓN
