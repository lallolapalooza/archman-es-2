OBXPROP(1) Manual de comandos generales OBXPROP(1)

NOMBRE

openbox — Un gestor de ventanas minimalista, altamente configurable, de próxima generación con amplio soporte de estándares.

SINOPSIS

openbox [--ayuda] [--display DISPLAY] [--id ID] [--root] [--] [PROPIEDAD ...]

DESCRIPCIÓN

obxprop es una herramienta para mostrar las propiedades de una ventana x.

Esta herramienta tiene una funcionalidad similar a xprop, pero obxprop te permite ver cadenas UTF-8 como texto.

Puedes usar la opción --id para especificar un identificador de ventana, de lo contrario obxprop te permitirá seleccionar una ventana haciendo clic en ella.

Principalmente, esta herramienta existe para que los usuarios de Openbox vean el valor de las propiedades _OB_APP_NAME, _OB_APP_CLASS, _OB_APP_ROLE y _OB_APP_TYPE, que Openbox utiliza para hacer coincidir ventanas con reglas de aplicación definidas por el usuario.

OPCIONES

Estas son las opciones posibles que acepta openbox:

--ayuda
Mostrar un resumen de las opciones disponibles.
--display DISPLAY
Especificar la pantalla X a utilizar.
--id ID
Especificar el identificador de ventana de la ventana cuyas propiedades se mostrarán.

Similar a xprop, puedes pasar uno o más nombres de propiedad para que openbox limite su salida solo a las propiedades solicitadas.
