NOMBRE

openssl-version - imprime información de la versión de OpenSSL

SINOPSIS

openssl version [-help] [-a] [-v] [-b] [-o] [-f] [-p] [-d] [-e] [-m] [-r] [-c] [-w]

DESCRIPCIÓN

Este comando se utiliza para imprimir información de la versión sobre OpenSSL.

OPCIONES

-help
Imprime un mensaje de uso.
-a
Toda la información, esto es lo mismo que establecer todas las demás opciones.
-v
La versión actual de OpenSSL.
-b
La fecha en que se compiló la versión actual de OpenSSL.
-o
Información de opciones: varias opciones establecidas cuando se compiló la biblioteca.
-f
Indicadores de compilación.
-p
Configuración de plataforma.
-d
Configuración de OPENSSLDIR.
-e
Configuración de ENGINESDIR.
-m
Configuración de MODULESDIR.
-r
La configuración de la fuente del generador de números aleatorios.
-c
La información de la configuración de la CPU de OpenSSL.
-w
La variable de tiempo de compilación de OpenSSL OSSL_WINCTX, si está definida. Se utiliza para calcular los nombres de las claves del registro de Windows. Esta opción no está disponible en plataformas que no sean Windows.

HISTORIA

En versiones de OpenSSL anteriores a la 3.4, OpenSSL tenía una limitación con respecto a las macros de tiempo de compilación OPENSSLDIR, MODULESDIR y ENGINESDIR. Estas macros se definían en tiempo de compilación y representaban rutas del sistema de archivos. Esta es una práctica común en sistemas tipo Unix, ya que se esperaba que una compilación dada se instalara en una ubicación predeterminada. Sin embargo, en Windows, no existe tal expectativa, ya que las bibliotecas pueden instalarse en ubicaciones arbitrarias. Se introdujo OSSL_WINCTX como una nueva variable de tiempo de compilación para definir un conjunto de claves de registro identificadas por el nombre openssl-<version>-<ctx>, en el que el valor de <version> se deriva de la cadena de versión en la fuente de openssl y la extensión <ctx> se deriva de la variable OSSL_WINCTX. Los valores de OPENSSLDIR, ENGINESDIR y MODULESDIR se pueden establecer en varias rutas debajo de esta clave para romper el requisito de predecir la ruta de instalación en el momento de la compilación.

NOTAS

La salida de "openssl version -a" se usaría típicamente al enviar un informe de error.
