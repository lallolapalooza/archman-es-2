FBB::OSymCryptStreambuf(3bobcat) Cifrado/descifrado simétrico FBB::OSymCryptStreambuf(3bobcat)

NOMBRE

FBB::OSymCryptStreambuf - std::streambuf que realiza cifrado/descifrado simétrico

SINOPSIS

#include <bobcat/osymcryptstreambuf>
Opción de enlace: -lbobcat -lcrypto

DESCRIPCIÓN

Los objetos FBB::OSymCryptStreambuf pueden ser utilizados como objetos std::streambuf de objetos std::ostream, y cifran o descifran información, que se pone a disposición a través de flujos std::istream separados.

La clase OSymCryptStreambuf es una clase plantilla, que utiliza un parámetro de plantilla no de tipo FBB::CryptType. Los objetos de la clase FBB::OSymCryptStreambuf<FBB::ENCRYPT> cifran la información que reciben, los objetos de la clase FBB::OSymCryptStreambuf<FBB::DECRYPT> descifran la información que reciben.

Todos los métodos de cifrado simétrico definidos por la biblioteca OpenSSL que se pueden seleccionar por nombre se pueden utilizar para cifrar/descifrar información. Para seleccionar un método de cifrado particular se pasa un identificador al constructor. Por ejemplo, "aes-256-gcm". Para una visión general de los algoritmos de cifrado soportados actualmente, ejecute el comando:

    openssl list -cipher-algorithms

Los objetos OSymCryptStreambuf leen la información a cifrar/descifrar de una fuente externa (por ejemplo, de objetos std::istream). Los caracteres que son cifrados o descifrados por los objetos OSymCryptStreambuf se escriben en objetos std::ostream que se especifican en el momento de la construcción como referencias a ostream o por nombre de archivo.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página de manual, están definidos en el espacio de nombres FBB.

HEREDA DE

FBB::OSymCryptBase (público)

La clase FBB::OSymCryptBase es una clase de 'uso interno solamente', derivada de std::streambuf, y por lo tanto OSymCryptStreambuf es una clase std::streambuf.

CONSTRUCTORES

o
OSymCryptStreambuf<CryptType>(std::ostream &outStreambuf, std::string const &cipherName, std::string const &key, std::string const &iv, size_t inBufSize = 100):
Este constructor define un std::streambuf que cifra o descifra los caracteres que recibe.
- Los objetos OSymCryptStreambuf<FBB::ENCRYPT> realizan el cifrado;
- Los objetos OSymCryptStreambuf<FBB::DECRYPT> realizan el descifrado;
- Los objetos OSymCryptStreambuf<CryptType> escriben los caracteres cifrados o descifrados en outStreambuf;
- El método de cifrado a utilizar se especifica mediante el parámetro cipherName. Por ejemplo, "AES-256-GCM";
- La clave simétrica a utilizar se especifica mediante el parámetro key;
- El vector de inicialización se especifica mediante el parámetro iv;
- El búfer utilizado internamente por FBB::OSymCryptStreambufbuf contendrá inBufSize caracteres. El valor por defecto es el valor más pequeño que se utiliza. Al especificar un valor bufSize más pequeño se utiliza el valor por defecto;
o
OSymCryptStreambuf<CryptType>(std::string const &outStreambufName, std::string const &cipherName, std::string const &key, std::string const &iv, size_t inBufSize = 100):
Mismo constructor que el anterior, pero el primer parámetro de este constructor especifica el nombre del archivo donde se recibirán los caracteres cifrados o descifrados.

Si la construcción falla, se lanza una excepción, mencionando la función openssl que no pudo completarse (ver también errorMsg abajo).

El constructor de movimiento está disponible, el constructor de copia y los operadores de asignación no están disponibles.

MIEMBROS HEREDADOS

Dado que la clase se deriva públicamente de std::ostream, se pueden utilizar todos los miembros de std::streambuf.

FUNCIONES MIEMBRO

o
static std::string errorMsg():
Si una función openssl falla, se lanza una excepción que menciona el nombre de la función fallida. En esos casos, se puede llamar a la función errorMsg que devuelve un std::string que contiene el código de error de openssl (devuelto por ERR_get_error) y su representación textual (devuelta por ERR_error_string). Si el código de error reportado es cero, entonces en realidad no ha ocurrido ningún error y la excepción fue informada de forma espuria;
o
static size_t keyLength(std::string const &cipherName):
devuelve la longitud mínima de clave requerida para el cifrado cipherName;
o
static size_t ivLength(std::sting const &cipherName):
devuelve la longitud mínima del vector de inicialización que se requiere para el cifrado cipherName.

Las dos últimas funciones lanzan excepciones si cipherName no contiene el nombre de un algoritmo de cifrado soportado.

MANIPULADOR

o
std::ostream &FBB::eoi(std::ostream &out):
Al insertar el manipulador eoi en un objeto std::ostream que utiliza un streambuf OSymCryptStreambuf, la inserción se considera completada. Completa la inserción de información en el std::ostream especificado en el momento de la construcción como primer argumento del OSymCryptStreambuf. De esta manera, no tiene que esperar hasta que el destructor del objeto OSymCryptStreambuf vacíe ese flujo. El ejemplo proporcionado en la página de manual osymcryptstream(3bobcat) ilustra el uso del manipulador eoi.

EJEMPLO

Ver el ejemplo en la página de manual osymcryptstream(3bobcat). En lugar de definir un OSymCryptStream, se puede definir un OSymCryptStreamBuf, pasando su dirección a un std::ostream que luego puede ser utilizado como el OSymCryptStream usado en el ejemplo.
