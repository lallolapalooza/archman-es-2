NOMBRE

Lynis - Herramienta de auditoría de sistemas y seguridad

SINOPSIS

lynis [modo de escaneo] [otras opciones]

DESCRIPCIÓN

Lynis es una herramienta de auditoría de seguridad para Linux, macOS y otros sistemas basados en UNIX. La herramienta verifica el sistema y la configuración del software para ver si hay margen de mejora en las defensas de seguridad. Todos los detalles se almacenan en un archivo de registro. Los hallazgos y otros datos descubiertos se guardan en un archivo de informe. Esto se puede utilizar para comparar diferencias entre auditorías. Lynis puede ejecutarse interactivamente o como un cronjob. No se requieren permisos de root (por ejemplo, sudo), sin embargo, proporcionan más detalles durante la auditoría.

Las siguientes áreas del sistema pueden ser verificadas:

- Archivos del gestor de arranque
- Archivos de configuración
- Paquetes de software
- Directorios y archivos relacionados con el registro y la auditoría

USO POR PRIMERA VEZ

Al ejecutar Lynis por primera vez, ejecute: lynis audit system

COMANDOS

audit <tipo>
Realiza una auditoría del tipo seleccionado
upload-only
Sube el archivo de informe disponible

Ver la sección AYUDANTES para más comandos.

TIPOS DE ESCANEO

audit system
Realiza una auditoría del sistema, que es la auditoría más común.
audit system remote <host>
Proporciona comandos para realizar un escaneo remoto.

Para más modos de escaneo, ver las utilidades auxiliares.

OPCIONES

--auditor <nombre>
Define el nombre del auditor/pentester. Cuando se usa un nombre completo, añada comillas dobles, como "Tu Nombre".
--cronjob
Realiza un escaneo automático con opciones seguras para cron (sin colores, sin preguntas, sin pausas).
--debug
Muestra información de depuración en pantalla para fines de resolución de problemas.
--developer
Muestra información detallada útil para los desarrolladores al crear pruebas.
--forensics
Realiza la auditoría en un sistema en ejecución o montado (ver --rootdir)
--help
Muestra los comandos disponibles y las opciones más usadas.
--logfile </ruta/al/logfile>
Define la ubicación y el nombre del archivo de registro, en lugar del predeterminado /var/log/lynis.log.
--man
Muestra la página del manual. Útil para sistemas que no tienen la página del manual instalada.
--no-colors
Desactiva la salida en color.
--no-log
Redirige toda la información de registro a /dev/null, evita que la información sensible se escriba en disco.
--no-plugins
No ejecuta ninguno de los complementos habilitados.
--pentest
Ejecuta un escaneo no privilegiado, usualmente utilizado para pruebas de penetración. Algunas de las pruebas se omitirán si requieren permisos de root.
--plugin-dir </ruta/a/plugins>
Define la ubicación donde se pueden encontrar los complementos.
--profile <archivo>
Proporciona un perfil alternativo para realizar el escaneo.
--quick (-Q)
Realiza un escaneo rápido (predeterminado: no espera la entrada del usuario).
--quiet (-q)
Se ejecuta en silencio y no muestra nada en pantalla. También activará el modo rápido.
--report-file <archivo>
Proporciona un nombre alternativo para el archivo de informe.
--reverse-colors
Optimiza la salida de pantalla para fondos claros.
--tests IDS-DE-PRUEBAS
Solo ejecuta las pruebas específicas. Al usar múltiples pruebas, añada comillas alrededor de la línea.
--tests-from-category <categoría>
Las pruebas solo se realizan si pertenecen a la categoría definida. Usa el comando  'show categories' para determinar todas las opciones válidas.
--tests-from-group <grupo>
Similar a --tests-from-category. Solo realiza pruebas de un grupo particular. Usa 'show groups' para determinar las opciones válidas.
--use-cwd
Ejecuta desde el directorio de trabajo actual.
--upload
Sube datos al servidor Lynis Enterprise (opción de perfil: upload=yes).
--verbose
Muestra más detalles en pantalla, como componentes que no se pudieron encontrar. Estos detalles están ocultos por defecto.
--wait
Espera a que el usuario continúe. Esto añade una pausa después de cada sección (a diferencia de --quick).
--warnings-only
Ejecuta en silencio, excepto por mostrar las advertencias.

Se permiten múltiples parámetros, aunque algunos parámetros solo se pueden usar junto con otros. Al ejecutar Lynis sin parámetros, se mostrará la ayuda y el programa saldrá.

AYUDANTES

Lynis tiene ayudantes especiales para realizar ciertas tareas. De esta manera, se utiliza el framework de Lynis, y al mismo tiempo se almacena la mayor parte de la funcionalidad en un archivo separado. Esto acelera la ejecución y mantiene el código limpio.

audit
Ejecuta auditoría en el sistema u otros objetivos
configure <parámetro>
Cambia o añade configuraciones al archivo de configuración
generate <parámetro>
Genera detalles específicos como IDs de host
show <parámetro>
Muestra información, como configuración y rutas
update <parámetro>
Realiza actividades relacionadas con la actualización

Para usar un ayudante, ejecute 'lynis' seguido del nombre del ayudante.

CÓDIGOS DE SALIDA

Lynis utiliza códigos de salida para señalar a cualquier script invocador. Actualmente se utilizan los siguientes códigos:

0
El programa salió normalmente
1
Error fatal
64
Se usó un parámetro desconocido o incompleto
65
Se encontró información incorrecta
66
No se pudo abrir el archivo o directorio
78
Lynis encontró 1 o más advertencias o errores de configuración (con error-on-warnings=yes)
